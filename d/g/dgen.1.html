DGEN(1) Manual de Comandos Generales DGEN(1)

NOMBRE

dgen — emulador de Sega Genesis/Mega Drive

SINOPSIS

dgen [-Pfhmv] [-R (J|U|E)] [-H HZ] [-D NOMBRE_DEMO] [-d NOMBRE_DEMO] [-n USEC] [-p CODIGO,CODIGO...] [-r ARCHIVO_RC] [-X FACTOR_X] [-Y FACTOR_Y] [-S FACTOR] [-g (0|1)] [-G XxY] [-s SLOT] [nombre_rom [...]]

DESCRIPCIÓN

La imagen ROM del archivo nombre_rom se ejecuta, emulada en una Sega Genesis o Mega Drive funcionando en modo NTSC de 60Hz (a menos que se especifique la opción -P, en cuyo caso se usa el modo PAL de 50Hz). nombre_rom debe estar en formato binario plano o SMD, y puede estar comprimido con gzip(1), zip(1), o bzip2(1).

Cuando no se especifica nombre_rom, DGen inicia sin una ROM. Puede cargarse más tarde desde el prompt. Cuando se especifican varios nombre_rom, se ejecutan secuencialmente.

Las opciones son las siguientes:

-H HZ
Usa una tasa de fotogramas personalizada, puede ser usada para acelerar o ralentizar la emulación.
-P
Emula el modo PAL de 50Hz (como se usa en los modelos europeos de Mega Drive).
-R (J|U|E)
Región del emulador. Sin esta opción, DGen usa la primera región mencionada en la cabecera de la ROM. Debería combinarse con -P para el modo PAL. Ver abajo.
(ninguna)
Autodetectar (NTSC, 60Hz)
-P
Autodetectar (PAL, 50Hz)
-R J
Japón (NTSC, 60Hz)
-R J -P
Japón (PAL, 50Hz)
-R E
Europa (NTSC, 60Hz, la música sin duda sonará demasiado rápida)
-R E -P
Europa (PAL, 50Hz)
-R U
América (NTSC, 60Hz)
-R U -P
Igual que -R E -P
-f
Ejecutar en pantalla completa, si es posible.
-h
Mostrar un breve resumen de todas las opciones.
-m
Solo MinGW. Esta opción evita que DGen se desvincule de su consola de control.
-v
Mostrar el número de versión y salir.
-D NOMBRE_DEMO
Reproducir una demo grabada con la opción -d.
-d NOMBRE_DEMO
Grabar una demo del programa en ejecución, que puede ser reproducida después con el modificador -D.
-n USEC
Dormir durante un número de microsegundos después de cada fotograma, para dar tiempo a otros procesos.
-p CODIGO,CODIGO...
Modificar la imagen ROM en memoria, usando códigos de estilo Game Genie o Hex. Los códigos Game Genie tienen el formato ABCD-EFGH y los códigos Hex están en el formato 123456:ABCD. Para especificar más de un código, sepáralos con comas (no uses espacios).
-r ARCHIVO_RC
Analizar otro archivo rc después de $HOME/.dgen/dgenrc. Los valores en el archivo especificado anulan los de los archivos anteriores.
-X FACTOR_X
Escalar la ventana FACTOR_X veces en la dirección X. FACTOR_X debe ser un entero positivo.
-Y FACTOR_Y
Escalar la ventana FACTOR_Y veces en la dirección Y. FACTOR_Y debe ser un entero positivo.
-S FACTOR
Escalar la ventana FACTOR veces en ambas direcciones. FACTOR debe ser un entero positivo.
-g (0|1)
Habilitar/deshabilitar OpenGL (si se compiló).
-G XxY
Tamaño de ventana deseado (ej. 640x480, 800x600, etc.)
-s SLOT
Cargar el estado guardado del slot dado al inicio (0-9)

PROMPT INTERACTIVO

Se puede usar un prompt interactivo minimalista inspirado en vi(1) para realizar varias operaciones descritas a continuación. Se activa presionando dos puntos (:), la tecla por defecto. Se admiten la edición de línea de comandos, el historial y la autocompletación.

Comandos

{salir, exit, q}
Salir, o cargar el siguiente nombre_rom de la línea de comandos, si existe.
{cargar, abrir, enchufar, o} nombre_archivo
Cargar un nombre_archivo de ROM dado.
{descargar, cerrar, desenchufar}
Descargar la ROM actual.
cargar_config nombre_archivo
Cargar la configuración desde el archivo nombre_archivo.
guardar_config nombre_archivo
Guardar la configuración actual en el archivo nombre_archivo.
reset
Reiniciar Genesis.
{empujar_ctv, pop_ctv, none_ctv}
Gestionar la pila de filtros Crap TV (si se compiló).
calibrar número
Calibración interactiva del gamepad especificado (1 o 2). Si no se especifica número, se usa el valor predeterminado 1.
desenlazar enlaze [...]
Eliminar los enlaces especificados (variables prefijadas con "bind_"). Ver dgenrc(5) para más información sobre ellas.
vgmdump iniciar nombre_archivo
 
vgmdump detener
Gestiona el volcado/registro de VGM. Si el segundo argumento es iniciar, el volcado de VGM se iniciará en la ruta especificada por el tercer argumento. Si el segundo argumento es detener, el volcado de VGM se detendrá y se finalizará el volcado.

Variables

Todas las variables de configuración de dgenrc(5) pueden mostrarse y modificarse interactivamente, con efecto inmediato.

{int_nombre, bool_nombre, key_nombre, joy_nombre, ...} {valor}
