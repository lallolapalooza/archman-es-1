subroutine dgelss (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, double precision rcond, integer rank, double precision, dimension( * ) work, integer lwork, integer info)

DGELSS resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Propósito:

!>
!> DGELSS calcula la solución de norma mínima para un problema de
!> mínimos cuadrados lineales reales:
!>
!> Minimizar la norma 2 de | b - A*x |.
!>
!> utilizando la descomposición en valores singulares (SVD) de A. A es una
!> matriz M por N que puede ser de rango deficiente.
!>
!> Se pueden manejar varios vectores del lado derecho b y vectores solución x
!> en una sola llamada; se almacenan como columnas de la matriz B del lado
!> derecho de M por NRHS y la matriz solución X de N por NRHS.
!>
!> El rango efectivo de A se determina tratando como cero aquellos valores
!> singulares que son menores que RCOND multiplicado por el valor singular
!> más grande.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, con dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, las primeras min(m,n) filas de A se sobrescriben con
!>          sus vectores singulares derechos, almacenados fila a fila.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array de DOUBLE PRECISION, con dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de M por NRHS.
!>          En la salida, B se sobrescribe con la matriz solución X de N por NRHS.
!>          Si m >= n y RANK = n, la suma residual de cuadrados
!>          para la solución en la i-ésima columna se da por la suma de
!>          cuadrados de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,max(M,N)).
!>

S

!>          S es un array de DOUBLE PRECISION, con dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la norma 2 = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se utiliza para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se utiliza la precisión de la máquina en su lugar.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, con dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1, y también:
!>          LWORK >= 3*min(M,N) + max( 2*min(M,N), max(M,N), NRHS )
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: el algoritmo para calcular la SVD no convergió;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!>
