Documentación de Función/Subrutina

subroutine dggqrf (integer n, integer m, integer p, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) taua, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) taub, double precision, dimension( * ) work, integer lwork, integer info)

DGGQRF

Propósito:

!>
!> DGGQRF calcula una factorización QR generalizada de una matriz A de N por M
!> y una matriz B de N por P:
!>
!>             A = Q*R,        B = Q*T*Z,
!>
!> donde Q es una matriz ortogonal de N por N, Z es una matriz ortogonal de P por P,
!> y R y T asumen una de las siguientes formas:
!>
!> si N >= M,  R = ( R11 ) M  ,   o si N < M,  R = ( R11  R12 ) N,
!>                 (  0  ) N-M                         N   M-N
!>                    M
!>
!> donde R11 es triangular superior, y
!>
!> si N <= P,  T = ( 0  T12 ) N,   o si N > P,  T = ( T11 ) N-P,
!>                  P-N  N                           ( T21 ) P
!>                                                      P
!>
!> donde T12 o T21 es triangular superior.
!>
!> En particular, si B es cuadrada y no singular, la factorización GQR
!> de A y B da implícitamente la factorización QR de inv(B)*A:
!>
!>              inv(B)*A = Z**T*(inv(T)*R)
!>
!> donde inv(B) denota el inverso de la matriz B, y Z**T denota la
!> transpuesta de la matriz Z.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices A y B. N >= 0.
!>

M

!>          M es INTEGER
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es array DOUBLE PRECISION, dimensión (LDA,M)
!>          En la entrada, la matriz A de N por M.
!>          En la salida, los elementos en y sobre la diagonal del array
!>          contienen la matriz trapezoidal superior R de min(N,M)-por-M (R es
!>          triangular superior si N >= M); los elementos debajo de la diagonal,
!>          con el array TAUA, representan la matriz ortogonal Q como un
!>          producto de min(N,M) reflectores elementales (ver Detalles adicionales).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A. LDA >= max(1,N).
!>

TAUA

!>          TAUA es array DOUBLE PRECISION, dimensión (min(N,M))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal Q (ver Detalles adicionales).
!>

B

!>          B es array DOUBLE PRECISION, dimensión (LDB,P)
!>          En la entrada, la matriz B de N por P.
!>          En la salida, si N <= P, el triángulo superior de la submatriz
!>          B(1:N,P-N+1:P) contiene la matriz triangular superior T de N por N;
!>          si N > P, los elementos en y sobre la (N-P)-ésima subdiagonal
!>          contienen la matriz trapezoidal superior T de N por P; los elementos
!>          restantes, con el array TAUB, representan la matriz ortogonal
!>          Z como un producto de reflectores elementales (ver Detalles adicionales).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B. LDB >= max(1,N).
!>

TAUB

!>          TAUB es array DOUBLE PRECISION, dimensión (min(N,P))
!>          Los factores escalares de los reflectores elementales que
!>          representan la matriz ortogonal Z (ver Detalles adicionales).
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N,M,P).
!>          Para un rendimiento óptimo LWORK >= max(N,M,P)*max(NB1,NB2,NB3),
!>          donde NB1 es el tamaño de bloque óptimo para la factorización QR
!>          de una matriz N por M, NB2 es el tamaño de bloque óptimo para la
!>          factorización RQ de una matriz N por P, y NB3 es el tamaño de bloque
!>          óptimo para una llamada a DORMQR.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal.
!>

Detalles adicionales:

!>
!>  La matriz Q se representa como un producto de reflectores elementales
!>
!>     Q = H(1) H(2) . . . H(k), donde k = min(n,m).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taua * v * v**T
!>
!>  donde taua es un escalar real, y v es un vector real con
!>  v(1:i-1) = 0 y v(i) = 1; v(i+1:n) se almacena en la salida en A(i+1:n,i),
!>  y taua en TAUA(i).
!>  Para formar Q explícitamente, use la subrutina DORGQR de LAPACK.
!>  Para usar Q para actualizar otra matriz, use la subrutina DORMQR de LAPACK.
!>
!>  La matriz Z se representa como un producto de reflectores elementales
!>
!>     Z = H(1) H(2) . . . H(k), donde k = min(n,p).
!>
!>  Cada H(i) tiene la forma
!>
!>     H(i) = I - taub * v * v**T
!>
!>  donde taub es un escalar real, y v es un vector real con
!>  v(p-k+i+1:p) = 0 y v(p-k+i) = 1; v(1:p-k+i-1) se almacena en la salida en
!>  B(n-k+i,1:p-k+i-1), y taub en TAUB(i).
!>  Para formar Z explícitamente, use la subrutina DORGRQ de LAPACK.
!>  Para usar Z para actualizar otra matriz, use la subrutina DORMRQ de LAPACK.
!>
