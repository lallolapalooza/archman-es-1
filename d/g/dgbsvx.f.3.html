Documentación de la Función/Subrutina

subrutina dgbsvx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGBSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!> DGBSVX usa la factorización LU para calcular la solución a un sistema
!> real de ecuaciones lineales A * X = B, A**T * X = B, o A**H * X = B,
!> donde A es una matriz banda de orden N con KL subdiagonales y KU
!> superdiagonales, y X y B son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una
!> estimación de la condición.
!>

Descripción:

!>
!> Esta subrutina realiza los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrio, A es
!>    sobrescrita por diag(R)*A*diag(C) y B por diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar la
!>    matriz A (después del equilibrio si FACT = 'E') como
!>       A = L * U,
!>    donde L es un producto de matrices de permutación y triangulares
!>    inferiores unitarias con KL subdiagonales, y U es triangular
!>    superior con KL+KU superdiagonales.
!>
!> 3. Si algún U(i,i)=0, de modo que U es exactamente singular, entonces la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina continúa
!>    para resolver X y calcular los límites de error como se describe a continuación.
!>
!> 4. Se resuelve el sistema de ecuaciones para X usando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular los límites de error y las estimaciones de error
!>    hacia atrás para la misma.
!>
!> 6. Si se usó el equilibrio, la matriz X es premultiplicada por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelve el sistema original antes del equilibrio.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A es
!>          proporcionada a la entrada, y si no lo es, si la matriz A debe
!>          equilibrarse antes de ser factorizada.
!>          = 'F':  A la entrada, AFB e IPIV contienen la forma factorizada de
!>                  A. Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con los factores de escala dados por R y C.
!>                  AB, AFB e IPIV no son modificadas.
!>          = 'N':  La matriz A será copiada a AFB y factorizada.
!>          = 'E':  La matriz A será equilibrada si es necesario, luego
!>                  copiada a AFB y factorizada.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A. N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A. KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A. KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

AB

!>          AB es un arreglo DOUBLE PRECISION, dimensión (LDAB,N)
!>          A la entrada, la matriz A en almacenamiento banda, en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A es almacenada en la j-ésima columna del
!>          arreglo AB como sigue:
!>          AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU)<=i<=min(N,j+kl)
!>
!>          Si FACT = 'F' y EQUED no es 'N', entonces A debe haber sido
!>          equilibrada por los factores de escala en R y/o C. AB no es
!>          modificada si FACT = 'F' o 'N', o si FACT = 'E' y
!>          EQUED = 'N' a la salida.
!>
!>          A la salida, si EQUED .ne. 'N', A es escalada como sigue:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del arreglo AB. LDAB >= KL+KU+1.
!>

AFB

!>          AFB es un arreglo DOUBLE PRECISION, dimensión (LDAFB,N)
!>          Si FACT = 'F', entonces AFB es un argumento de entrada y a la entrada
!>          contiene detalles de la factorización LU de la matriz banda
!>          A, tal como la calcula DGBTRF. U es almacenada como una matriz
!>          banda triangular superior con KL+KU superdiagonales en las filas 1 a KL+KU+1,
!>          y los multiplicadores usados durante la factorización son almacenados
!>          en las filas KL+KU+2 a 2*KL+KU+1. Si EQUED .ne. 'N', entonces AFB es
!>          la forma factorizada de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AFB es un argumento de salida y a la salida
!>          retorna detalles de la factorización LU de A.
!>
!>          Si FACT = 'E', entonces AFB es un argumento de salida y a la salida
!>          retorna detalles de la factorización LU de la matriz equilibrada
!>          A (véase la descripción de AB para la forma de la
!>          matriz equilibrada).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del arreglo AFB. LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y a la entrada
!>          contiene los índices de pivote de la factorización A = L*U
!>          tal como la calcula DGBTRF; la fila i de la matriz fue intercambiada
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y a la salida
!>          contienes los índices de pivote de la factorización A = L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>          contiene los índices de pivote de la factorización A = L*U
!>          de la matriz ecualizada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de ecualización que se realizó.
!>          = 'N':  Sin ecualización (siempre cierto si FACT = 'N').
!>          = 'R':  Ecualización de filas, es decir, A se ha premultiplicado por
!>                  diag(R).
!>          = 'C':  Ecualización de columnas, es decir, A se ha postmultiplicado
!>                  por diag(C).
!>          = 'B':  Tanto ecualización de filas como de columnas, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>

R

!>          R es un array DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>          multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>          no se accede. R es un argumento de entrada si FACT = 'F';
!>          de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>

C

!>          C es un array DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>          multiplica por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>          no se accede. C es un argumento de entrada si FACT = 'F';
!>          de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del segundo miembro B.
!>          En la salida,
!>          si EQUED = 'N', B no se modifica;
!>          si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>          diag(R)*B;
!>          si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B
!>          se sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS
!>          del sistema original de ecuaciones. Tenga en cuenta que A y B se
!>          modifican en la salida si EQUED .ne. 'N', y la solución al
!>          sistema ecualizado es inv(diag(C))*X si TRANS = 'N' y
!>          EQUED = 'C' o 'B', o inv(diag(R))*X si TRANS = 'T' o 'C'
!>          y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del número de condición recíproco de la matriz
!>          A después de la ecualización (si se hizo). Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular a la precisión de trabajo. Esta condición se
!>          indica mediante un código de retorno de INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución real correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del mayor
!>          elemento en (X(j) - XTRUE) dividida por la magnitud del
!>          mayor elemento en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error real.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,3*N))
!>          En la salida, WORK(1) contiene el factor de crecimiento de pivote recíproco
!>          norm(A)/norm(U). Se usa la norma
!>          . Si WORK(1) es mucho menor que 1, entonces la estabilidad
!>          de la factorización LU de la matriz A (ecualizada) podría ser
!>          deficiente. Esto también significa que la solución X, el estimador de
!>          condición RCOND y la cota de error hacia adelante FERR podrían ser
!>          poco fiables. Si la factorización falla con 0<INFO<=N, entonces
!>          WORK(1) contiene el factor de crecimiento de pivote recíproco para las
!>          primeras INFO columnas de A.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero. La factorización
!>                       se ha completado, pero el factor U es exactamente
!>                       singular, por lo que la solución y las cotas de error
!>                       no se pudieron calcular. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de
!>                       la máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo. Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que la
!>                       que sugeriría el valor de RCOND.
!>
