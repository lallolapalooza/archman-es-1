DGGSV

P

Propósito

: 
!>
!> Esta rutina está obsoleta y ha sido reemplazada por la rutina DGGSVP3.
!>
!> DGGSVP calcula matrices ortogonales U, V y Q de tal forma que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de K-por-K y la matriz B13 de L-por-L son
!> triangulares superiores no singulares; A23 es triangular superior
!> de L-por-L si M-K-L >= 0, de lo contrario A23 es trapezoidal
!> superior de (M-K)-por-L. K+L = el rango numérico efectivo de la
!> matriz (A**T,B**T)**T de (M+P)-por-N.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición en Valores Singulares Generalizada (GSVD), ver la
!> subrutina DGGSVD.
!
>
