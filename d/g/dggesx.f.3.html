DGGESX calcula los eigenvalores, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> DGGESX calcula para un par de matrices reales no simétricas N-por-N
!> (A,B), los eigenvalores generalizados, la forma de Schur real (S,T), y,
!> opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL y
!> VSR). Esto da la factorización de Schur generalizada
!>
!>      (A,B) = ( (VSL) S (VSR)**T, (VSL) T (VSR)**T )
!>
!> Opcionalmente, también ordena los eigenvalores para que un grupo seleccionado
!> de eigenvalores aparezca en los bloques diagonales principales de la matriz
!> superior cuasi-triangular S y la matriz superior triangular T; calcula
!> un número de condición recíproco para el promedio de los eigenvalores
!> seleccionados (RCONDE); y calcula un número de condición recíproco para
!> los subespacios deflantes derecho e izquierdo correspondientes a los eigenvalores seleccionados (RCONDV). Las columnas principales de VSL y VSR entonces forman
!> una base ortonormal para los eigenspaces izquierdo y derecho correspondientes
!> (subespacios deflantes).
!>
!> Un eigenvalor generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Es
!> usualmente representado como el par (alpha,beta), ya que hay una
!> interpretación razonable para beta=0 o para ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur real generalizada si T es
!> triangular superior con diagonal no negativa y S es triangular superior por bloques
!> con bloques 1-por-1 y 2-por-2. Los bloques 1-por-1 corresponden
!> a eigenvalores reales generalizados, mientras que los bloques 2-por-2 de S serán
!> al hacer que los elementos correspondientes de T tengan la
!> forma:
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> y el par de bloques correspondientes 2-por-2 en S y T tendrán un
!> par de eigenvalores generalizados complejos conjugados.
!>
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N': no calcular los vectores de Schur izquierdos;
!>          = 'V': calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N': no calcular los vectores de Schur derechos;
!>          = 'V': calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si ordenar o no los eigenvalores en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N': los eigenvalores no se ordenan;
!>          = 'S': los eigenvalores se ordenan (ver SELCTG).
!>

SELCTG

!>          SELCTG es una FUNCIÓN LÓGICA de tres argumentos DOUBLE PRECISION
!>          SELCTG debe ser declarada EXTERNAL en la subrutina que llama.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se usa para seleccionar eigenvalores para ordenar
!>          a la parte superior izquierda de la forma de Schur.
!>          Un eigenvalor (ALPHAR(j)+ALPHAI(j))/BETA(j) se selecciona si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) es verdadero; es decir, si cualquiera
!>          de un par de eigenvalores complejos conjugados se selecciona,
!>          entonces ambos eigenvalores complejos se seleccionan.
!>          Nótese que un eigenvalor complejo seleccionado puede ya no satisfacer
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) = .TRUE. después de ordenar,
!>          ya que el ordenar puede cambiar el valor de los eigenvalores complejos
!>          (especialmente si el eigenvalor está mal condicionado), en este
!>          caso INFO se establece a N+3.
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N': no se calculan;
!>          = 'E': se calculan solo para el promedio de los eigenvalores seleccionados;
!>          = 'V': se calculan solo para los subespacios deflantes seleccionados;
!>          = 'B': se calculan para ambos.
!>          Si SENSE = 'E', 'V', o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL, y VSR. N >= 0.
!>

A

!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la primera del par de matrices.
!>          En la salida, A ha sido sobrescrita por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A. LDA >= max(1,N).
!>

B

!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, la segunda del par de matrices.
!>          En la salida, B ha sido sobrescrita por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B. LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de eigenvalores (después de ordenar)
!>          para los cuales SELCTG es verdadero. (Los pares de complejos conjugados para los cuales
!>          SELCTG es verdadero para cualquiera de los eigenvalores cuentan como 2.)
!>

ALPHAR

!>          ALPHAR es un arreglo DOUBLE PRECISION, dimensión (N)
!>

ALPHAI

!>          ALPHAI es un arreglo DOUBLE PRECISION, dimensión (N)
!>

BETA

!>          BETA es un arreglo DOUBLE PRECISION, dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los eigenvalores generalizados. ALPHAR(j) + ALPHAI(j)*i
!>          y BETA(j),j=1,...,N son las diagonales de la forma de Schur
!>          compleja (S,T) que resultaría si los bloques diagonales 2-por-2 de
!>          la forma de Schur real de (A,B) se redujeran aún más a
!>          forma triangular usando transformaciones unitarias complejas 2-por-2.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo eigenvalor es real; si
!>          es positivo, entonces los eigenvalores j-ésimo y (j+1)-ésimo son un
!>          par de complejos conjugados, con ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente desbordar o quedar por debajo del rango, y BETA(j) puede incluso ser cero.
!>

NAME

                    
dggesx - Compute the generalized Schur factorization of an upper
                        triangular matrix and estimate the condition numbers of the selected
                        eigenvalues and right generalized eigenvectors.

                

                

                    
SYNOPSIS

                    
SUBROUTINE DGGESX( JOBVSL, JOBVSR, SORT, SELCTG, N, A, LDA, B, LDB,
                                      &       ALPHAR, ALPHAI, BETA, VSL, LDVSL, VSR, LDVSR,
                                      &       RCONDE, RCONDV, WORK, LWORK, IWORK, LIWORK, BWORK,
                                      &       INFO )
  CHARACTER * 1 JOBVSL
  CHARACTER * 1 JOBVSR
  CHARACTER * 1 SORT
  LOGICAL FUNCTION SELCTG( ALPHAR, ALPHAI, BETA )
  INTEGER N
  DOUBLE PRECISION A( LDA, * )
  INTEGER LDA
  DOUBLE PRECISION B( LDB, * )
  INTEGER LDB
  DOUBLE PRECISION ALPHAR( * )
  DOUBLE PRECISION ALPHAI( * )
  DOUBLE PRECISION BETA( * )
  DOUBLE PRECISION VSL( LDVSL, * )
  INTEGER LDVSL
  DOUBLE PRECISION VSR( LDVSR, * )
  INTEGER LDVSR
  DOUBLE PRECISION RCONDE( * )
  DOUBLE PRECISION RCONDV( * )
  DOUBLE PRECISION WORK( * )
  INTEGER LWORK
  INTEGER IWORK( * )
  INTEGER LIWORK
  LOGICAL BWORK( * )
  INTEGER INFO

                

                

                    
Function/Subroutine Documentation

                    
Purpose:

                    

                        
This subroutine computes the generalized Schur factorization of a
real matrix pair (A, B) and updates the inverse of the array
RCONDE and RCONDV (reciprocal condition numbers).


                    

                    
Arguments:

                    

                        
JOBVSL

                        

                            
JOBVSL is CHARACTER*1
  = 'V': compute the left Schur vectors VSL;
  = 'N': do not compute the left Schur vectors VSL.

                        

                        
JOBVSR

                        

                            
JOBVSR is CHARACTER*1
  = 'V': compute the right Schur vectors VSR;
  = 'N': do not compute the right Schur vectors VSR.

                        

                        
SORT

                        

                            
SORT is CHARACTER*1
  = 'S': sort the generalized eigenvalues so that the leading
         ones are selected by SELCTG.
  = 'N': do not sort eigenvalues.

                        

                        
SELCTG

                        

                            
SELCTG is LOGICAL FUNCTION
  If SORT = 'S', SELCTG is used to select the generalized
  eigenvalues to be sorted. SELCTG(ALPHAR, ALPHAI, BETA) returns
  .TRUE. if the i-th generalized eigenvalue (ALPHAR(i), ALPHAI(i),
  BETA(i)) is to be selected (i.e., the i-th eigenvalue is in the
  left generalized eigenspace).
  If SORT = 'N', SELCTG is not referenced.

                        

                        
N

                        

                            
N is INTEGER
  The order of the matrices A and B.  0 <= N.

                        

                        
A

                        

                            
A is DOUBLE PRECISION array, dimension (LDA, N)
  On entry, the matrix A.

                        

                        
LDA

                        

                            
LDA is INTEGER
  The leading dimension of A. LDA >= max(1, N).

                        

                        
B

                        

                            
B is DOUBLE PRECISION array, dimension (LDB, N)
  On entry, the matrix B.

                        

                        
LDB

                        

                            
LDB is INTEGER
  The leading dimension of B. LDB >= max(1, N).

                        

                        
ALPHAR

                        

                            
ALPHAR is DOUBLE PRECISION array, dimension (N)
  ALPHAR and ALPHAI contain the real and imaginary parts,
  respectively, of the complex generalized eigenvalues omega = (alpha,
  beta), each satisfying A*v = omega*B*v, for the generalized
  Schur form. alpha = ALPHAR(i) + ALPHAI(i)i. Note that if ALPHAI(i)
  is zero, then the corresponding eigenvalue is real.
  On exit, ALPHAR and ALPHAI will contain the computed values.
  On exit, if JOBVSL = 'V' and JOBVSR = 'V', VSL and VSR will contain
  the left and right Schur vectors in the columns of VSL and VSR
  respectively.
  On exit, ALPHAR and ALPHAI contain the real parts of the computed
  eigenvalues.
  On exit, BETA contains the computed values of the corresponding
  generalized eigenvalues.
  On exit, if JOBVSL = 'V', VSL will contain the left Schur vectors.
  On exit, if JOBVSR = 'V', VSR will contain the right Schur vectors.

                        

                        
ALPHAI

                        

                            
ALPHAI is DOUBLE PRECISION array, dimension (N)
  See description of ALPHAR.

                        

                        
BETA

                        

                            
BETA is DOUBLE PRECISION array, dimension (N)
  See description of ALPHAR.
  On exit, BETA contains the computed values of the corresponding
  generalized eigenvalues.

                        

                        
VSL

                        

                            
VSL is DOUBLE PRECISION array, dimension (LDVSL,N)
  If JOBVSL = 'V', VSL will contain the left Schur vectors.
  Not referenced if JOBVSL = 'N'.

                        

                        
LDVSL

                        

                            
LDVSL is INTEGER
  The leading dimension of the matrix VSL. LDVSL >=1, and
  if JOBVSL = 'V', LDVSL >= N.

                        

                        
VSR

                        

                            
VSR is DOUBLE PRECISION array, dimension (LDVSR,N)
  If JOBVSR = 'V', VSR will contain the right Schur vectors.
  Not referenced if JOBVSR = 'N'.

                        

                        
LDVSR

                        

                            
LDVSR is INTEGER
  The leading dimension of the matrix VSR. LDVSR >= 1, and
  if JOBVSR = 'V', LDVSR >= N.

                        

                        
RCONDE

                        

                            
RCONDE is DOUBLE PRECISION array, dimension ( 2 )
  If SENSE = 'E' or 'B', RCONDE(1) and RCONDE(2) contain the
  reciprocal condition numbers for the average of the selected
  eigenvalues.
  Not referenced if SENSE = 'N' or 'V'.

                        

                        
RCONDV

                        

                            
RCONDV is DOUBLE PRECISION array, dimension ( 2 )
  If SENSE = 'V' or 'B', RCONDV(1) and RCONDV(2) contain the
  reciprocal condition numbers for the selected deflating
  subspaces.
  Not referenced if SENSE = 'N' or 'E'.

                        

                        
WORK

                        

                            
WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
  On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

                        

                        
LWORK

                        

                            
LWORK is INTEGER
  The dimension of the array WORK.
  If N = 0, LWORK >= 1, else if SENSE = 'E', 'V', or 'B',
  LWORK >= max( 8*N, 6*N+16, 2*SDIM*(N-SDIM) ), else
  LWORK >= max( 8*N, 6*N+16 ).
  Note that 2*SDIM*(N-SDIM) <= N*N/2.
  Note also that an error is only returned if
  LWORK < max( 8*N, 6*N+16), but if SENSE = 'E' or 'V' or 'B'
  this may not be large enough.
  If LWORK = -1, then a workspace query is assumed; the routine
  only calculates the bound on the optimal size of the WORK
  array and the minimum size of the IWORK array, returns these
  values as the first entries of the WORK and IWORK arrays, and
  no error message related to LWORK or LIWORK is issued by
  XERBLA.

                        

                        
IWORK

                        

                            
IWORK is INTEGER array, dimension (MAX(1,LIWORK))
  On exit, if INFO = 0, IWORK(1) returns the minimum LIWORK.

                        

                        
LIWORK

                        

                            
LIWORK is INTEGER
  The dimension of the array IWORK.
  If SENSE = 'N' or N = 0, LIWORK >= 1, otherwise
  LIWORK >= N+6.
  If LIWORK = -1, then a workspace query is assumed; the
  routine only calculates the bound on the optimal size of the
  WORK array and the minimum size of the IWORK array, returns
  these values as the first entries of the WORK and IWORK
  arrays, and no error message related to LWORK or LIWORK is
  issued by XERBLA.

                        

                        
BWORK

                        

                            
BWORK is LOGICAL array, dimension (N)
  Not referenced if SORT = 'N'.

                        

                        
INFO

                        

                            
INFO is INTEGER
  = 0:  successful exit
  < 0:  if INFO = -i, the i-th argument had an illegal value.
  = 1,...,N:
        The QZ iteration failed.  (A,B) are not in Schur
        form, but ALPHAR(j), ALPHAI(j), and BETA(j) should
        be correct for j=INFO+1,...,N.
  > N:  =N+1: other than QZ iteration failed in DHGEQZ
        =N+2: after reordering, roundoff changed values of
              some complex eigenvalues so that leading
              eigenvalues in the Generalized Schur form no
              longer satisfy SELCTG=.TRUE.  This could also
              be caused due to scaling.
        =N+3: reordering failed in DTGSEN.

Further Details:

                    

                        
An approximate (asymptotic) bound on the average absolute error of
the selected eigenvalues is
       EPS * norm((A, B)) / RCONDE( 1 ).
An approximate (asymptotic) bound on the maximum angular error in
the computed deflating subspaces is
       EPS * norm((A, B)) / RCONDV( 2 ).
See LAPACK User's Guide, section 4.11 for more information.
