subrutina dgtrfs (character trans, integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( * ) dlf, double precision, dimension( * ) df, double precision, dimension( * ) duf, double precision, dimension( * ) du2, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGTRFS

Propósito:

!>
!> DGTRFS mejora la solución calculada de un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es tridiagonal, y proporciona
!> límites de error y estimaciones de error hacia atrás para la solución.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos de la subdiagonal de A.
!>

D

!>          D es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los elementos de la diagonal de A.
!>

DU

!>          DU es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos de la superdiagonal de A.
!>

DLF

!>          DLF es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) multiplicadores que definen la matriz L de la
!>          factorización LU de A tal como la calcula DGTTRF.
!>

DF

!>          DF es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los n elementos de la diagonal de la matriz triangular superior U de la
!>          factorización LU de A.
!>

DUF

!>          DUF es un arreglo DOUBLE PRECISION, dimensión (N-1)
!>          Los (n-1) elementos de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un arreglo DOUBLE PRECISION, dimensión (N-2)
!>          Los (n-2) elementos de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) siempre será
!>          i o i+1; IPIV(i) = i indica que no se requirió un intercambio de filas.
!>

B

!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz de miembros derechos B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!>

X

!>          X es un arreglo DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          A la entrada, la matriz de solución X, tal como la calcula DGTTRS.
!>          A la salida, la matriz de solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          El límite estimado del error hacia adelante para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del mayor
!>          elemento en (X(j) - XTRUE) dividido por la magnitud del
!>          mayor elemento en X(j).  La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector
!>          de solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión (3*N)
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
