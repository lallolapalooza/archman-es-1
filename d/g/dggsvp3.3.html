DGGSVP

3

Propósito

: 
!>
!> DGGSVP3 calcula matrices ortogonales U, V y Q tales que
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  si M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  si M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> donde la matriz A12 de tamaño K por K y la matriz B13 de tamaño L por L son
!> triangulares superiores no singulares; A23 es triangular superior de tamaño L
!> por L si M-K-L >= 0, de lo contrario A23 es trapezoidal superior de tamaño
!> (M-K) por L.  K+L = el rango numérico efectivo de la matriz (A**T,B**T)**T
!> de tamaño (M+P) por N.
!>
!> Esta descomposición es el paso de preprocesamiento para calcular la
!> Descomposición de Valor Singular Generalizada (GSVD), véase la subrutina
!> DGGSVD3.
!
>

!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1,P).
!
>

TOL

A 
!>          TOLA es DOUBLE PRECISION
!
>

TOL

B 
!>          TOLB es DOUBLE PRECISION
!>
!>          TOLA y TOLB son los umbrales para determinar el rango numérico
!>          efectivo de la matriz B y de un subbloque de A. Generalmente,
!>          se establecen en
!>             TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar el tamaño de los errores
!>          hacia atrás de la descomposición.
!
>

K 
!>          K es INTEGER
!
>

L 
!>          L es INTEGER
!>
!>          A la salida, K y L especifican la dimensión de los subbloques
!>          descritos en la sección Propósito.
!>          K + L = rango numérico efectivo de (A**T,B**T)**T.
!
>

U 
!>          U es un arreglo DOUBLE PRECISION, dimensión (LDU,M)
