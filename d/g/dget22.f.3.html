DOCUMENTACIÓN DE LA FUNCIÓN/SUBRUTINA

subroutine dget22 (character transa, character transe, character transw, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( lde, * ) e, integer lde, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( * ) work, double precision, dimension( 2 ) result)

DGET22

Propósito:

!>
!> DGET22 realiza una comprobación de vectores propios.
!>
!> La prueba básica es:
!>
!>    RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>
!> usando la norma 1. También comprueba la normalización de E:
!>
!>    RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                 j
!>
!> donde E(j) es el j-ésimo vector propio, y m-norm es la norma máxima de un
!> vector. Si un vector propio es complejo, según lo determinado por WI(j)
!> no cero, entonces la norma máxima del vector ( er + i*ei ) es el máximo
!> de
!>    |er(1)| + |ei(1)|, ... , |er(n)| + |ei(n)|
!>
!> W es una matriz diagonal por bloques, con un bloque de 1 por 1 para cada valor propio real
!> y un bloque de 2 por 2 para cada par conjugado complejo.
!> Si los valores propios j y j+1 son un par conjugado complejo, de modo que
!!> WR(j) = WR(j+1) = wr y WI(j) = - WI(j+1) = wi, entonces el bloque de 2 por 2
!> correspondiente al par será:
!>
!>    (  wr  wi  )
!>    ( -wi  wr  )
!>
!> Dicho bloque multiplicando una matriz de n por 2 ( ur ui ) a la derecha
!> será lo mismo que multiplicar ur + i*ui por wr + i*wi.
!>
!> Para manejar varios esquemas de almacenamiento de vectores propios izquierdos, existen
!> opciones para usar A-transpuesta en lugar de A, E-transpuesta en lugar de E,
!> y/o W-transpuesta en lugar de W.
!>

Parámetros

TRANSA 
!>          TRANSA es CHARACTER*1
!>          Especifica si A se transpone o no.
!>          = 'N':  Sin transponer
!>          = 'T':  Transpuesta
!>          = 'C':  Transpuesta conjugada (= Transpuesta)
!>

TRANSE

!>          TRANSE es CHARACTER*1
!>          Especifica si E se transpone o no.
!>          = 'N':  Sin transponer, los vectores propios están en las columnas de E
!>          = 'T':  Transpuesta, los vectores propios están en las filas de E
!>          = 'C':  Transpuesta conjugada (= Transpuesta)
!>

TRANSW

!>          TRANSW es CHARACTER*1
!>          Especifica si W se transpone o no.
!>          = 'N':  Sin transponer
!>          = 'T':  Transpuesta, usa -WI(j) en lugar de WI(j)
!>          = 'C':  Transpuesta conjugada, usa -WI(j) en lugar de WI(j)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimension (LDA,N)
!>          La matriz cuyos vectores propios están en E.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

E

!>          E es un array DOUBLE PRECISION, dimension (LDE,N)
!>          La matriz de vectores propios. Si TRANSE = 'N', los vectores propios
!>          se almacenan en las columnas de E, si TRANSE = 'T' o 'C', los
!>          vectores propios se almacenan en las filas de E.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal del array E.  LDE >= max(1,N).
!>

WR

!>          WR es un array DOUBLE PRECISION, dimension (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, dimension (N)
!>
!>          Las partes real e imaginaria de los valores propios de A.
!>          Los valores propios puramente reales se indican con WI(j) = 0.
!>          Los pares conjugados complejos se indican con WR(j)=WR(j+1) y
!>          WI(j) = - WI(j+1) distinto de cero; la parte real se asume que está
!>          almacenada en la fila/columna j y la parte imaginaria en
!>          la fila/columna (j+1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimension (N*(N+1))
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimension (2)
!>          RESULT(1) = | A E  -  E W | / ( |A| |E| ulp )
!>          RESULT(2) = max | m-norm(E(j)) - 1 | / ( n ulp )
!>                       j
!>
