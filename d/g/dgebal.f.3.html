subrutina dgebal (carácter job, entero n, doble precisión, dimensión( lda, * ) a, entero lda, entero ilo, entero ihi, doble precisión, dimensión( * ) scale, entero info)

DGEBAL

Propósito:

!>
!> DGEBAL equilibra una matriz real general. Esto implica, primero,
!> permutar A mediante una transformación de semejanza para aislar los
!> valores propios en los primeros 1 a ILO-1 y los últimos IHI+1 a N
!> elementos en la diagonal; y segundo, aplicar una transformación de
!> semejanza diagonal a las filas y columnas ILO a IHI para hacer que
!> las filas y columnas sean lo más cercanas posible en norma. Ambos
!> pasos son opcionales.
!>
!> El equilibrio puede reducir la norma 1 de la matriz y mejorar la
!> precisión de los valores y/o vectores propios calculados.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica las operaciones que se realizarán en A:
!>          = 'N':  ninguna:  simplemente establecer ILO = 1, IHI = N, SCALE(I) = 1.0
!>                  para i = 1,...,N;
!>          = 'P':  solo permutar;
!>          = 'S':  solo escalar;
!>          = 'B':  permutar y escalar ambas cosas.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión (LDA,N)
!>          A la entrada, la matriz de entrada A.
!>          A la salida, A se sobrescribe con la matriz equilibrada.
!>          Si JOB = 'N', A no se referencia.
!>          Ver Detalles adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ILO

!>          ILO es INTEGER
!>

IHI

!>          IHI es INTEGER
!>          ILO e IHI se establecen en enteros tales que a la salida
!>          A(i,j) = 0 si i > j y j = 1,...,ILO-1 o i = IHI+1,...,N.
!>          Si JOB = 'N' o 'S', ILO = 1 y IHI = N.
!>

SCALE

!>          SCALE es un array de DOBLE PRECISIÓN, dimensión (N)
!>          Detalles de las permutaciones y factores de escala aplicados
!>          a A. Si P(j) es el índice de la fila y columna intercambiadas
!>          con la fila y columna j, y D(j) es el factor de escala
!>          aplicado a la fila y columna j, entonces
!>          SCALE(j) = P(j)    para j = 1,...,ILO-1
!>                   = D(j)    para j = ILO,...,IHI
!>                   = P(j)    para j = IHI+1,...,N.
!>          El orden en que se realizan los intercambios es de N a IHI+1,
!>          luego de 1 a ILO-1.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>

Detalles adicionales:

!>
!> Las permutaciones consisten en intercambios de filas y columnas que
!> ponen la matriz en la forma
!>
!>             ( T1   X   Y  )
!>     P A P = (  0   B   Z  )
!>             (  0   0   T2 )
!>
!> donde T1 y T2 son matrices triangulares superiores cuyos valores
!> propios se encuentran a lo largo de la diagonal. Los índices de
!> columna ILO e IHI marcan el inicio y fin de las columnas de la
!> submatriz B. El equilibrio consiste en aplicar una transformación
!> de semejanza diagonal inv(D) * B * D para hacer que las normas 1
!> de cada fila de B y su columna correspondiente sean casi iguales.
!> La matriz de salida es
!>
!>     ( T1     X*D          Y    )
!>     (  0  inv(D)*B*D  inv(D)*Z ).
!>     (  0      0           T2   )
!>
!> La información sobre las permutaciones P y la matriz diagonal D se
!> devuelve en el vector SCALE.
!>
!> Esta subrutina se basa en la rutina EISPACK BALANC.
!>

!>
