DGELS resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Documentación de la Función/Subrutina

subrutina dgels (character trans, integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) work, integer lwork, integer info)

DGELS resuelve sistemas sobredeterminados o subdeterminados de matrices reales GE

Propósito:

!>
!> DGELS resuelve sistemas lineales reales sobredeterminados o subdeterminados
!> que involucran una matriz A de M por N, o su transpuesta, utilizando una
!> factorización QR o LQ de A.
!>
!> Se asume que A tiene rango completo, y solo se proporciona una protección
!> rudimentaria contra matrices de rango deficiente. Esta subrutina solo detecta
!> la deficiencia de rango exacta, donde un elemento diagonal del factor triangular
!> de A es exactamente cero.
!>
!> Es concebible que uno (o más) de los elementos diagonales del factor triangular
!> de A sean números diminutos, sin que esta subrutina señale un error. Las
!> soluciones calculadas para tales matrices casi de rango deficiente pueden
!> ser menos precisas debido a una pérdida de precisión numérica.
!>
!> Se proporcionan las siguientes opciones:
!>
!> 1. Si TRANS = 'N' y m >= n:  encontrar la solución de mínimos cuadrados de
!>    un sistema sobredeterminado, es decir, resolver el problema de mínimos
!>    cuadrados
!>                 minimizar || B - A*X ||.
!>
!> 2. Si TRANS = 'N' y m < n:  encontrar la solución de norma mínima de
!>    un sistema subdeterminado A * X = B.
!>
!> 3. Si TRANS = 'T' y m >= n:  encontrar la solución de norma mínima de
!>    un sistema subdeterminado A**T * X = B.
!>
!> 4. Si TRANS = 'T' y m < n:  encontrar la solución de mínimos cuadrados de
!>    un sistema sobredeterminado, es decir, resolver el problema de mínimos
!>    cuadrados
!>                 minimizar || B - A**T * X ||.
!>
!> Se pueden manejar varios vectores del lado derecho b y vectores solución x
!> en una sola llamada; se almacenan como las columnas de la matriz B de
!> mano derecha M por NRHS y la matriz solución X de N por NRHS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': el sistema lineal involucra A;
!>          = 'T': el sistema lineal involucra A**T.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de
!>          columnas de las matrices B y X. NRHS >=0.
!>

A

!>          A es array DOUBLE PRECISION, dimension (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida,
!>            si M >= N, A se sobrescribe con detalles de su factorización QR
!>                       devuelta por DGEQRF;
!>            si M <  N, A se sobrescribe con detalles de su factorización LQ
!>                       devuelta por DGELQF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es array DOUBLE PRECISION, dimension (LDB,NRHS)
!>          En la entrada, la matriz B de los vectores del lado derecho, almacenada
!>          por columnas; B es M por NRHS si TRANS = 'N', o N por NRHS
!>          si TRANS = 'T'.
!>          En la salida, si INFO = 0, B se sobrescribe con los vectores solución,
!>          almacenados por columnas:
!>          si TRANS = 'N' y m >= n, las filas 1 a n de B contienen los vectores
!>          solución de mínimos cuadrados; la suma de cuadrados residual de la
!>          solución en cada columna se da por la suma de cuadrados de los
!>          elementos N+1 a M en esa columna;
!>          si TRANS = 'N' y m < n, las filas 1 a N de B contienen los vectores
!>          solución de norma mínima;
!>          si TRANS = 'T' y m >= n, las filas 1 a M de B contienen los vectores
!>          solución de norma mínima;
!>          si TRANS = 'T' y m < n, las filas 1 a M de B contienen los vectores
!>          solución de mínimos cuadrados; la suma de cuadrados residual de la
!>          solución en cada columna se da por la suma de cuadrados de los
!>          elementos M+1 a N en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= MAX(1,M,N).
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= max( 1, MN + max( MN, NRHS ) ).
!>          Para un rendimiento óptimo,
!>          LWORK >= max( 1, MN + max( MN, NRHS )*NB ).
!>          donde MN = min(M,N) y NB es el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO =  i, el i-ésimo elemento diagonal del factor
!>                triangular de A es exactamente cero, por lo que A no tiene
!>                rango completo; no se pudo calcular la solución de mínimos
!>                cuadrados.
!>
