DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subroutine dget53 (double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision scale, double precision wr, double precision wi, double precision result, integer info)

DGET53

Propósito:

!>
!> DGET53 comprueba los valores propios generalizados calculados por DLAG2.
!>
!> La prueba básica para un valor propio es:
!>
!>                              | det( s A - w B ) |
!>     RESULTADO =  ---------------------------------------------------
!>               ulp max( s norm(A), |w| norm(B) )*norm( s A - w B )
!>
!> Se realizan dos pruebas:
!>
!> (1)  ulp*max( s*norm(A), |w|*norm(B) )  debe ser al menos
!>      safe_minimum.  Esto asegura que la prueba realizada no sea
!>      esencialmente  det(0*A + 0*B)=0.
!>
!> (2)  s*norm(A) + |w|*norm(B) debe ser menor que 1/safe_minimum.
!>      Esto asegura que  s*A - w*B  no desbordará.
!>
!> Si estas pruebas no se superan, entonces  s  y  w  se escalan y
!> se prueban de todos modos, si es posible.
!>

Parámetros

A 
!>          A es un array DOUBLE PRECISION, dimension (LDA, 2)
!>          La matriz A de 2x2.
!>

LDA

!>          LDA es un INTEGER
!>          La dimensión principal de A. Debe ser al menos 2.
!>

B

!>          B es un array DOUBLE PRECISION, dimension (LDB, N)
!>          La matriz triangular superior B de 2x2.
!>

LDB

!>          LDB es un INTEGER
!>          La dimensión principal de B. Debe ser al menos 2.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          El  s en la fórmula  s A - w B . Se
!>          asume que es no negativo.
!>

WR

!>          WR es DOUBLE PRECISION
!>          La parte real del valor propio  w  en la fórmula
!>          s A - w B .
!>

WI

!>          WI es DOUBLE PRECISION
!>          La parte imaginaria del valor propio  w  en la fórmula
!>          s A - w B .
!>

RESULT

!>          RESULT es DOUBLE PRECISION
!>          Si INFO es 2 o menos, el valor calculado por la prueba
!>             descrita anteriormente.
!>          Si INFO=3, esto será simplemente 1/ulp.
!>

INFO

!>          INFO es INTEGER
!>          =0:  Los datos de entrada pasan las pruebas.
!>          =1:  s*norm(A) + |w|*norm(B) > 1/safe_minimum.
!>          =2:  ulp*max( s*norm(A), |w|*norm(B) ) < safe_minimum
!>          =3:  igual que INFO=2, pero  s  y  w  no pudieron ser escalados para
!>               calcular la prueba.
!>
