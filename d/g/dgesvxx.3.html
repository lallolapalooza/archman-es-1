Documentación de Función/Subrutina

subrutina dgesvxx (character fact, character trans, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGESVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!>    DGESVXX usa la factorización LU para calcular la solución a un
!>    sistema de ecuaciones lineales de doble precisión A * X = B, donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven tanto límites de error en norma
!>    como en componente máximo. DGESVXX devolverá una solución con un error
!>    garantizado muy pequeño (O(eps) donde eps es la precisión de
!>    trabajo de la máquina) a menos que la matriz esté muy mal
!>    condicionada, en cuyo caso se devuelve una advertencia. También se
!>    calculan y devuelven los números de condición relevantes.
!>
!>    DGESVXX acepta factorizaciones y factores de equilibrado
!>    proporcionados por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usando una factorización de una llamada
!>    anterior a DGESVXX también producirá una solución con errores O(eps)
!>    o advertencias, pero no podemos hacer esa afirmación para
!>    factorizaciones y factores de equilibrado proporcionados por el usuario si
!>    difieren de lo que DGESVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para equilibrar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la
!>    rutina retorna con INFO = i. De lo contrario, se usa la forma factorizada
!>    de A para estimar el número de condición de la matriz A (vea
!>    el argumento RCOND). Si el recíproco del número de condición es menor
!>    que la precisión de la máquina, la rutina continúa para resolver
!>    X y calcular los límites de error como se describe a continuación.
!>
!>    4. Se resuelve el sistema de ecuaciones para X usando la forma factorizada
!>    de A.
!>
!>    5. De forma predeterminada (a menos que PARAMS(LA_LINRX_ITREF_I) esté establecido en cero),
!>    la rutina usará refinamiento iterativo para intentar obtener un error
!>    pequeño y límites de error. El refinamiento calcula el residual con al
!>    menos el doble de la precisión de trabajo.
!>
!>    6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0 lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona en la entrada y, si no, si la matriz A debe
!>     equilibrarse antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transponer)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

NHRHS

!>          NRHS es INTEGER
!>     El número de miembros derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>     En la entrada, la matriz A de N por N. Si FACT = 'F' y EQUED no es
!>     'N', entonces A debe haber sido equilibrada por los factores de escala
!>     en R y/o C. A no se modifica si FACT = 'F' o
!>     'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array DOUBLE PRECISION, dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene los factores L y U de la factorización
!>     A = P*L*U como la calcula DGETRF. Si EQUED .ne. 'N', entonces
!>     AF es la forma factorizada de la matriz A equilibrada.
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve los factores L y U de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>     devuelve los factores L y U de la factorizacion A = P*L*U
!>     de la matriz A equilibrada (consulte la descripción de A para
!>     la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>     La dimensión principal del array AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, de dimensión (N)
!>     Si FACT = 'F', entonces IPIV es un argumento de entrada y en la entrada
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     calculada por DGETRF; la fila i de la matriz se intercambió
!>     con la fila IPIV(i).
!>
!>     Si FACT = 'N', entonces IPIV es un argumento de salida y en la salida
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz original A.
!>
!>     Si FACT = 'E', entonces IPIV es un argumento de salida y en la salida
!>     contiene los índices de pivote de la factorización A = P*L*U
!>     de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  No se realizó equilibrado (siempre es cierto si FACT = 'N').
!>       = 'R':  Equilibrado de filas, es decir, A se multiplicó previamente por
!>               diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A se multiplicó posteriormente
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir, A se
!>               reemplazó por diag(R) * A * diag(C).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

R

!>          R es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>     multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es una salida, cada elemento de R es una potencia de la base.
!>     Si R es una entrada, cada elemento de R debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El escalado con
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea un subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

C

!>          C es un array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>     multiplica por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es una salida, cada elemento de C es una potencia de la base.
!>     Si C es una entrada, cada elemento de C debe ser una potencia de la base
!>     para asegurar una solución y estimaciones de error fiables. El escalado con
!>     potencias de la base no causa errores de redondeo a menos que el
!>     resultado sea un subdesbordamiento o desbordamiento. Los errores de redondeo durante el escalado
!>     conducen a un refinamiento con una matriz que no es equivalente a la
!>     matriz de entrada, produciendo estimaciones de error que pueden no ser
!>     fiables.
!>

B

!>          B es un array DOUBLE PRECISION, de dimensión (LDB,NRHS)
!>     En la entrada, la matriz B del lado derecho de N por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe con
!>        diag(R)*B;
!>     si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>        sobrescribe con diag(C)*B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de NRHS columnas N por al sistema
!>     original de ecuaciones. Tenga en cuenta que A y B se modifican en la salida
!>     si EQUED .ne. 'N', y la solución al sistema equilibrado es
!>     inv(diag(C))*X si TRANS = 'N' y EQUED = 'C' o 'B', o
!>     inv(diag(R))*X si TRANS = 'T' o 'C' y EQUED = 'R' o 'B'.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     Condicionamiento recíproco escalado. Esta es una estimación del
!>     condicionamiento recíproco de Skeel de la matriz A después del
!>     equilibrado (si se realizó). Si esto es menor que la precisión de la
!>     máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal condicionada.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     Crecimiento recíproco de pivote. En la salida, esto contiene el factor
!>     de crecimiento de pivote recíproco norm(A)/norm(U). Se utiliza la norma del
!>     máximo. Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (equilibrada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento de pivote recíproco
!>     para las primeras INFO columnas de A. En DGESVX, esta cantidad se
!>     devuelve en WORK(1).
!>

BERR

!>          BERR es un array DOUBLE PRECISION, de dimensión (NRHS)
!>     Error relativo de retroceso componente a componente. Este es el
!>     error relativo de retroceso componente a componente de cada vector solución X(j)
!>     (es decir, el cambio relativo más pequeño en cualquier elemento de A o B que
!>     hace que X(j) sea una solución exacta).
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     Número de límites de error a devolver para cada lado derecho
!>     y cada tipo (norma o componente). Consulte ERR_BNDS_NORM y
!>     ERR_BNDS_COMP a continuación.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo en norma, que se define de la siguiente manera:
!>
!>     Error relativo en norma del i-ésimo vector solución:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     El array se indexa por el tipo de información de error como se describe
!>     a continuación. Actualmente hay hasta tres piezas de información
!>     devueltas.
!>
!>     El primer índice en ERR_BNDS_NORM(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_NORM(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error de avance estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Norma estimada
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si el error
!>              la estimación es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*A, donde S escala cada fila por una potencia de la
!>              base para que todas las sumas de filas absolutas de Z sean aproximadamente 1.
!>
!>     Consulte la Nota de Trabajo 165 de Lapack para obtener más detalles y precauciones adicionales.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es un array DOUBLE PRECISION, de dimensión (NRHS, N_ERR_BNDS)
!>     Para cada lado derecho, este array contiene información sobre
!>     varios límites de error y números de condición correspondientes al
!>     error relativo componente a componente, que se define de la siguiente manera:
!>
!>     Error relativo componente a componente del i-ésimo vector solución:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     El array se indexa por el lado derecho i (del cual depende el
!>     error relativo componente a componente), y el tipo de información de error, como se describe a continuación. Actualmente hay hasta tres
!>     piezas de información devueltas para cada lado derecho. Si
!>     no se solicita precisión componente a componente (PARAMS(3) = 0.0), entonces
!>     no se accede a ERR_BNDS_COMP. Si N_ERR_BNDS < 3, entonces como máximo
!>     se devuelven las primeras (:,N_ERR_BNDS) entradas.
!>
!>     El primer índice en ERR_BNDS_COMP(i,:) corresponde al i-ésimo
!>     lado derecho.
!>
!>     El segundo índice en ERR_BNDS_COMP(:,err) contiene los siguientes
!>     tres campos:
!>     err = 1  booleano. Confía en la respuesta si el
!>              número de condición recíproco es menor que el umbral
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  límite de error: El error de avance estimado,
!>              casi con certeza dentro de un factor de 10 del error real
!>              siempre que la siguiente entrada sea mayor que el umbral
!>              sqrt(n) * dlamch('Epsilon'). Este límite de error solo debe
!>              confiarse si el booleano anterior es verdadero.
!>
!>     err = 3  Número de condición recíproco: Componente estimada
!>              número de condición recíproco. Comparado con el umbral
!>              sqrt(n) * dlamch('Epsilon') para determinar si el error
!>              la estimación es . Estos números de condición recíprocos
!>              son 1 / (norm(Z^{-1},inf) * norm(Z,inf)) para alguna
!>              matriz Z apropiadamente escalada.
!>              Sea Z = S*(A*diag(x)), donde x es la solución para el
!>              lado derecho actual y S escala cada fila de
!>              A*diag(x) por una potencia de la base para que todas las sumas de filas
!>              absolutas de Z sean aproximadamente 1.
!>
!>     Consulte la Nota de Trabajo 165 de Lapack para obtener más detalles y precauciones adicionales.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     Especifica el número de parámetros establecidos en PARAMS. Si es <= 0,
!>     el array PARAMS nunca se accede y se utilizan los valores predeterminados.
!>

PARAMS

!>          PARAMS es un array DOUBLE PRECISION, de dimensión (NPARAMS)
!>     Especifica los parámetros del algoritmo. Si una entrada es < 0.0, entonces
!>     esa entrada se rellenará con el valor predeterminado utilizado para ese
!>     parámetro. Solo se accede a las posiciones hasta NPARAMS; se utilizan valores predeterminados
!>     para parámetros de mayor número.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Si realizar refinamiento iterativo o n

NAME


dgesvxx - dense general system solver with componentwise error bound


SYNOPSIS


    Subroutine dgesvxx( VECT, UPLO, N, NRHS, A, LDA, B, LDB, X, LDX, RCOND,
                      SRCOND, AFAC, LDAFAC, IPIV, EQUED, WORK, LWORK,
                      IWORK, LIWORK, INFO )

        CHARACTER          VECT, UPLO
        INTEGER            N, NRHS, LDA, LDB, LDX, LWORK, LIWORK
        INTEGER            IPIV( * )
        INTEGER            IWORK( * )
        REAL               RCOND, SRCOND
        REAL               A( * ), B( * ), X( * ), AFAC( * )
        CHARACTER*1        EQUED( 1 )
        CHARACTER*1        WORK( * )




Function/Subroutine Documentation


dgesvxx computes the solution to a real double precision
    general system of linear equations:


        A * X = B
    


where A is an N-by-N matrix and X and B are N-by-NRHS matrices.
    The analysis of the solution is done with respect to the component-wise
    relative error. The error bound is computed using the reciprocal of the
    condition number of the coefficient matrix A.




Input Parameters




VECT CHARACTER*1.




Specifies whether to compute the condition number for the
        normal equations.
        = ‘N’: Compute the condition number for the normal equations
        (ATA).
        = ‘T’: Compute the condition number for the transpose of A
        (AT).




UPLO CHARACTER*1.




Specifies whether the matrix A is upper or lower
        triangular.
        = ‘U’: Upper triangle of A is used and lower triangle is
        not referenced.
        = ‘L’: Lower triangle of A is used and upper triangle is
        not referenced.




N INTEGER.




The number of linear equations, i.e., the dimension of
        the matrix A. N >= 0.




NRHS INTEGER.




The number of right hand sides, i.e., the number of
        columns of the matrices B and X. NRHS >= 0.




A REAL array, dimension (LDA,N).




On entry, the N-by-N coefficient matrix A.




LDA INTEGER.




The leading dimension of the array A. LDA >= max(1,N).




B REAL array, dimension (LDB,NRHS).




On entry, the N-by-NRHS right-hand side matrix B.




LDB INTEGER.




The leading dimension of the array B. LDB >= max(1,N).




X REAL array, dimension (LDX,NRHS).




On exit, if INFO = 0 or INFO = N+J, the N-by-NRHS solution
        matrix X. This array may be the same as B.




LDX INTEGER.




The leading dimension of the array X. LDX >= max(1,N).




RCOND REAL.




On exit, an estimate of the reciprocal of the condition
        number of A. RCOND is computed using the LU factorization of A.
        The normwise computation is done using the 1-norm.
        RCOND is computed for the matrix A, not the scaled matrix. If
        RCOND is small, then the matrix A is close to singular and the
        solution X may not be accurate.




SRCOND REAL.




On exit, an estimate of the reciprocal of the condition
        number of the scaled problem. SRCOND is computed for the scaled
        problem. If SRCOND is small, then the scaled problem is close to
        singular and the solution X may not be accurate.




AFAC REAL array, dimension (LDAFAC,N).




On exit, the factors of A.
        If UPLO = ‘U’, then AFAC contains the upper triangular factor U.
        If UPLO = ‘L’, then AFAC contains the lower triangular factor L.




LDAFAC INTEGER.




The leading dimension of the array AFAC. LDAFAC >=
