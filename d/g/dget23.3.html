Propósito:

!>
!>    DGET23  comprueba el controlador del problema de valores propios no simétricos SGEEVX.
!>    Si COMP = .FALSO., se realizarán las 8 primeras de las siguientes pruebas en la
!>    matriz de entrada A, y también la prueba 9 si LWORK es suficiente.
!>    Si COMP es .VERDADERO., se realizarán las 11 pruebas.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de los vectores propios derechos unitarios.
!>      W es una matriz diagonal por bloques, con un bloque de 1x1 para cada
!>      valor propio real y un bloque de 2x2 para cada par conjugado complejo.
!>      Si los valores propios j y j+1 son un par conjugado complejo,
!>      entonces WR(j) = WR(j+1) = wr e WI(j) = - WI(j+1) = wi, entonces el
!>      bloque de 2 x 2 correspondiente al par será:
!>
!>              (  wr  wi  )
!>              ( -wi  wr  )
!>
!>      Un bloque así multiplicando una matriz n x 2 ( ur ui ) por la
!>      derecha será lo mismo que multiplicar ur + i*ui por wr + i*wi.
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de los vectores propios izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como se describe arriba.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y componente real más grande
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y componente real más grande
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     0 si W(completo) = W(parcial), 1/ulp en caso contrario
!>
!>      W(completo) denota los valores propios calculados cuando también se
!>      calculan VR, VL, RCONDV y RCONDE, y W(parcial) denota el resultado
!>      cuando solo se calculan algunos de VR, VL, RCONDV y RCONDE.
!>
!>    (6)     0 si VR(completo) = VR(parcial), 1/ulp en caso contrario
!>
!>      VR(completo) denota los vectores propios derechos calculados cuando
!>      también se calculan VL, RCONDV y RCONDE, y VR(parcial) denota el
!>      resultado cuando solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     0 si VL(completo) = VL(parcial), 1/ulp en caso contrario
!>
!>      VL(completo) denota los vectores propios izquierdos calculados cuando
!>      también se calculan VR, RCONDV y RCONDE, y VL(parcial) denota el
!>      resultado cuando solo se calculan algunos de VR y RCONDV.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (completo) =
!>                 SCALE, ILO, IHI, ABNRM (parcial)
!>            1/ulp en caso contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (completo) es cuando también se calculan VR, VL, RCONDE y RCONDV, y
!>      (parcial) es cuando algunos no se calculan.
!>
!>    (9)     0 si RCONDV(completo) = RCONDV(parcial), 1/ulp en caso contrario
!>
!>      RCONDV(completo) denota los recíprocos de los números de condición de los
!>      vectores propios derechos calculados cuando también se calculan VR, VL y RCONDE.
!>      RCONDV(parcial) denota los recíprocos de los números de condición cuando
!>      solo se calculan algunos de VR, VL y RCONDE.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV es el recíproco del número de condición de los vectores propios
!>      derechos calculado por DGEEVX y RCDVIN (el valor real precalculado)
!>      se proporciona como entrada. cond(RCONDV) es el número de condición de
!>      RCONDV, y tiene en cuenta los errores en el cálculo de RCONDV, de modo
!>      que la cantidad resultante debe ser O(ULP). cond(RCONDV) se da
!>      esencialmente por norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE es el recíproco del número de condición de los valores propios
!>      calculado por DGEEVX y RCDEIN (el valor real precalculado)
!>      se proporciona como entrada. cond(RCONDE) es el número de condición de
!>      RCONDE, y tiene en cuenta los errores en el cálculo de RCONDE, de modo
!>      que la cantidad resultante debe ser O(ULP). cond(RCONDE) se da
!>      esencialmente por norm(A)/RCONDV.
!>

Parámetros

COMP 
!>          COMP es LOGICAL
!>          COMP describe qué pruebas de entrada realizar:
!>            = .FALSO. si los números de condición calculados no se van a
!>                      probar contra RCDVIN y RCDEIN
!>            = .VERDADERO. si se van a comparar
!>

BALANC

!>          BALANC es CHARACTER
!>          Describe la opción de equilibrio que se probará.
!>            = 'N' para ninguna permutación o escalado diagonal
!>            = 'P' para permutación pero sin escalado diagonal
!>            = 'S' para ningún escalado diagonal pero sin permutación
!>            = 'B' para permutación y escalado diagonal
!>

JTYPE

!>          JTYPE es INTEGER
!>          Tipo de matriz de entrada. Se utiliza para etiquetar la salida si ocurre un error.
!>

THRESH

!>          THRESH es DOUBLE PRECISION
!>          Una prueba se contará si la , calculada como
!>          se describe arriba, excede THRESH. Tenga en cuenta que el error
!>          se escala para que sea O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, por ejemplo, 10 o 100. En particular,
!>          no debe depender de la precisión (simple o doble) ni del tamaño
!>          de la matriz. Debe ser al menos cero.
!>

ISEED

!>          ISEED es un array INTEGER, dimensión (4)
!>          Si COMP = .FALSO., la semilla del generador de números aleatorios
!>          utilizada para producir la matriz.
!>          Si COMP = .VERDADERO., ISEED(1) = el número del ejemplo.
!>          Usar

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO distinto de 0.)
!>

N

!>          N es INTEGER
!>          La dimensión de A. N debe ser al menos 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          Se usa para contener la matriz cuyos valores propios deben ser
!>          calculados.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A y H. LDA debe ser al
!>          menos 1 y al menos N.
!>

H

!>          H es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          Otra copia de la matriz de prueba A, modificada por DGEEVX.
!>

WR

!>          WR es un array DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Las partes real e imaginaria de los valores propios de A.
!>          Al salir, WR + WI*i son los valores propios de la matriz en A.
!>

WR1

!>          WR1 es un array DOUBLE PRECISION, dimensión (N)
!>

WI1

!>          WI1 es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Al igual que WR, WI, estos arrays contienen los valores propios de A,
!>          pero aquellos calculados cuando DGEEVX solo calcula una
!>          descomposición parcial de eigenvalores, es decir, no los valores propios y los
!>          vectores propios izquierdo y derecho.
!>

VL

!>          VL es un array DOUBLE PRECISION, dimensión (LDVL,N)
!>          VL contiene los vectores propios izquierdos calculados.
!>

LDVL

!>          LDVL es INTEGER
!>          Dimensión principal de VL. Debe ser al menos max(1,N).
!>

VR

!>          VR es un array DOUBLE PRECISION, dimensión (LDVR,N)
!>          VR contiene los vectores propios derechos calculados.
!>

LDVR

!>          LDVR es INTEGER
!>          Dimensión principal de VR. Debe ser al menos max(1,N).
!>

LRE

!>          LRE es un array DOUBLE PRECISION, dimensión (LDLRE,N)
!>          LRE contiene los vectores propios derechos o izquierdos calculados.
!>

LDLRE

!>          LDLRE es INTEGER
!>          Dimensión principal de LRE. Debe ser al menos max(1,N).
!>

RCONDV

!>          RCONDV es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDV contiene los números de condición recíprocos calculados
!>          para los vectores propios.
!>

RCNDV1

!>          RCNDV1 es un array DOUBLE PRECISION, dimensión (N)
!>          RCNDV1 contiene más números de condición recíprocos calculados
!>          para los vectores propios.
!>

RCDVIN

!>          RCDVIN es un array DOUBLE PRECISION, dimensión (N)
!>          Cuando COMP = .TRUE., RCDVIN contiene los números de condición
!>          recíprocos precalculados para los vectores propios a comparar con
!>          RCONDV.
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDE contiene los números de condición recíprocos calculados
!>          para los valores propios.
!>

RCNDE1

!>          RCNDE1 es un array DOUBLE PRECISION, dimensión (N)
!>          RCNDE1 contiene más números de condición recíprocos calculados
!>          para los valores propios.
!>

RCDEIN

!>          RCDEIN es un array DOUBLE PRECISION, dimensión (N)
!>          Cuando COMP = .TRUE., RCDEIN contiene los números de condición
!>          recíprocos precalculados para los valores propios a comparar con
!>          RCONDE.

SCALE

!>          SCALE es un array DOUBLE PRECISION, dimensión (N)

!>

SCALE1

!>          SCALE1 es un array DOUBLE PRECISION, dimensión (N)
!>          Contiene información que describe el balanceo de la matriz.
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (11)
!>          Los valores calculados por las 11 pruebas descritas arriba.
!>          Los valores están actualmente limitados a 1/ulp, para evitar
!>          desbordamiento.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de entradas en WORK. Este debe ser al menos
!>          3*N, y 6*N+N**2 si se van a realizar las pruebas 9, 10 o 11.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          Si es 0, salida exitosa.
!>          Si es <0, el parámetro de entrada -INFO tenía un valor incorrecto.
