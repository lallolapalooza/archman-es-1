subrutina dgeequ (m, n, a, lda, r, c, rowcnd, colcnd, amax, info)

DGEEQU

Documentación de la función/subrutina

subrutina dgeequ (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision rowcnd, double precision colcnd, double precision amax, integer info)

DGEEQU

Propósito:

!>
!> DGEEQU calcula los factores de escala de filas y columnas destinados a
!> equilibrar una matriz A de M por N y reducir su número de condición. R
!> devuelve los factores de escala de fila y C los factores de escala de
!> columna, elegidos para intentar que el elemento más grande de cada fila
!> y columna de la matriz B con elementos B(i,j)=R(i)*A(i,j)*C(j) tenga
!> un valor absoluto de 1.
!>
!> R(i) y C(j) están restringidos a estar entre SMLNUM = número seguro más
!> pequeño y BIGNUM = número seguro más grande. El uso de estos factores de
!> escala no garantiza la reducción del número de condición de A, pero
!> funciona bien en la práctica.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A. N >= 0.
!>

A

!>          A es un array de DOBLE PRECISIÓN, con dimensión (LDA,N)
!>          La matriz M por N cuyos factores de equilibrado se van a
!>          calcular.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

R

!>          R es un array de DOBLE PRECISIÓN, con dimensión (M)
!>          Si INFO = 0 o INFO > M, R contiene los factores de escala de
!>          fila para A.
!>

C

!>          C es un array de DOBLE PRECISIÓN, con dimensión (N)
!>          Si INFO = 0, C contiene los factores de escala de columna para A.
!>

ROWCND

!>          ROWCND es DOBLE PRECISIÓN
!>          Si INFO = 0 o INFO > M, ROWCND contiene la relación entre el
!>          R(i) más pequeño y el R(i) más grande. Si ROWCND >= 0.1 y AMAX
!>          no es ni demasiado grande ni demasiado pequeño, no vale la pena
!>          escalar con R.
!>

COLCND

!>          COLCND es DOBLE PRECISIÓN
!>          Si INFO = 0, COLCND contiene la relación entre el C(i) más
!>          pequeño y el C(i) más grande. Si COLCND >= 0.1, no vale la pena
!>          escalar con C.
!>

AMAX

!>          AMAX es DOBLE PRECISIÓN
!>          Valor absoluto del elemento de la matriz más grande. Si AMAX
!>          está muy cerca del desbordamiento o muy cerca del subdesbordamiento,
!>          la matriz debe ser escalada.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tuvo un valor ilegal
!>          > 0: si INFO = i, y i es
!>                <= M: la fila i de A es exactamente cero
!>                >  M: la columna (i-M) de A es exactamente cero
!>
