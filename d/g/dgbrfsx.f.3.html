DGBRFSX

Propósito:

!>
!>    DGBRFSX mejora la solución calculada de un sistema de ecuaciones
!>    lineales y proporciona límites de error y estimaciones de error
!>    hacia atrás para la solución. Además del límite de error normwise,
!>    el código proporciona un límite de error máximo componente a
!>    componente si es posible. Ver los comentarios de ERR_BNDS_NORM y
!>    ERR_BNDS_COMP para detalles de los límites de error.
!>
!>    El sistema original de ecuaciones lineales puede haber sido
!>    equilibrado antes de llamar a esta rutina, como se describe
!>    mediante los argumentos EQUED, R y C a continuación. En este caso,
!>    la solución y los límites de error devueltos son para el sistema
!>    original no equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en el array PARAMS.
!>     Estas configuraciones determinan cómo se realiza el refinamiento,
!>     pero a menudo los valores predeterminados son aceptables. Si los
!>     valores predeterminados son aceptables, los usuarios pueden
!>     pasar NPARAMS = 0, lo que evita que el código fuente acceda al
!>     argumento PARAMS.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó en A
!>     antes de llamar a esta rutina. Esto es necesario para calcular
!>     la solución y los límites de error correctamente.
!>       = 'N':  Sin equilibrado
!>       = 'R':  Equilibrado de filas, es decir, A ha sido premultiplicada
!>               por diag(R).
!>       = 'C':  Equilibrado de columnas, es decir, A ha sido postmultiplicada
!>               por diag(C).
!>       = 'B':  Equilibrado tanto de filas como de columnas, es decir,
!>               A ha sido reemplazada por diag(R) * A * diag(C).
!>               El lado derecho B ha sido modificado en consecuencia.
!>

N

!>          N es INTEGER
!>     El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array DOUBLE PRECISION, dimension (LDAB,N)
!>     La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>     La columna j de A se almacena en la columna j del array AB de la
!>     siguiente manera:
!>     AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku) <= i <= min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array DOUBLE PRECISION, dimension (LDAFB,N)
!>     Detalles de la factorización LU de la matriz de banda A, tal
!>     como se calculó con DGBTRF. U se almacena como una matriz de banda
!>     triangular superior con KL+KU superdiagonales en las filas 1 a
!>     KL+KU+1, y los multiplicadores utilizados durante la factorización
!>     se almacenan en las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV es array INTEGER, dimension (N)
!>     Los índices de pivote de DGETRF; para 1 <= i <= N, la fila i de la
!>     matriz se intercambió con la fila IPIV(i).
!>

R

!>          R es array DOUBLE PRECISION, dimension (N)
!>     Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A es
!>     multiplicada a la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>     no se accede. R es un argumento de entrada si FACT = 'F';
!>     de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!>     Si R es una salida, cada elemento de R es una potencia de la base.
!>     Si R es una entrada, cada elemento de R debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El
!>     escalado por potencias de la base no causa errores de redondeo a
!>     menos que el resultado tenga un subdesbordamiento o desbordamiento.
!>     Los errores de redondeo durante el escalado conducen a refinar con
!>     una matriz que no es equivalente a la matriz de entrada, produciendo
!>     estimaciones de error que pueden no ser fiables.
!>

C

!>          C es array DOUBLE PRECISION, dimension (N)
!>     Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A es
!>     multiplicada a la derecha por diag(C); si EQUED = 'N' o 'R', C
!>     no se accede. C es un argumento de entrada si FACT = 'F';
!>     de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>     EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!>     Si C es una salida, cada elemento de C es una potencia de la base.
!>     Si C es una entrada, cada elemento de C debe ser una potencia de la base
!>     para garantizar una solución y estimaciones de error fiables. El
!>     escalado por potencias de la base no causa errores de redondeo a
!>     menos que el resultado tenga un subdesbordamiento o desbordamiento.
!>     Los errores de redondeo durante el escalado conducen a refinar con
!>     una matriz que no es equivalente a la matriz de entrada, produciendo
!>     estimaciones de error que pueden no ser fiables.
!>

B

!>          B es array DOUBLE PRECISION, dimension (LDB,NRHS)
!>     La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array DOUBLE PRECISION, dimension (LDX,NRHS)
!>     En la entrada, la matriz solución X, tal como la calculó DGETRS.
!>     En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal



NAME


DGGBRFDX — Drivers for general band matrix --- factorization

SUBROUTINE DGGBRFDX(
  UPLO, TRANSPOSE, EQUILIZE, FACTORED,

  X, LDX, RCOND, BERR,
  N_ERR_BNDS, ERR_BNDS_NORM, ERR_BNDS_COMP,
  NPARAMS, PARAMS,
  WORK, IWORK, INFO
)

INTEGER :: N, M, NBANDS1, NBANDS2, NRHS, LDAB, LDBB, LDX, N_ERR_BNDS, NPARAMS, INFO
INTEGER, DIMENSION(:) :: IWORK

Function/Subroutine Documentation


DGGBRFDX computes the factors for a general band matrix A and
    solves a system of equations AX = B. It also computes error bounds and
    condition estimates.


This subroutine is a generalized version of DGGBRFD and DGGBRS
    which also computes error bounds, condition estimates and iterative
    refinement.


Arguments




UPLO


CHARACTER(LEN=1). Must be ‘U’ or ‘L’.
    
Specifies whether the matrix A is upper or lower
        triangular.




TRANSPOSE


CHARACTER(LEN=1). Must be ‘N’, ‘T’ or ‘C’.
    
Specifies the form of the system of equations:

    
    
      
  • ‘N’: A * X = B (No transpose)
    • 
      
  • ‘T’: A**T * X = B (Transpose)
    • 
      
  • ‘C’: A**H * X = B (Conjugate transpose)
    • 
    




EQUILIZE


CHARACTER(LEN=1). Must be ‘N’ or ‘Y’.
    
Specifies whether or not to use equilibrium scaling.

    
    
      
  • ‘N’: Equilibration is not performed.
    • 
      
  • ‘Y’: Equilibration is performed.
    • 
    




FACTORED


CHARACTER(LEN=1). Must be ‘N’ or ‘Y’.
    
Specifies whether or not the input factored matrix AB is
        already factored.

    
    
      
  • ‘N’: The factored matrix AB is not given. DGGBRFDX will compute
          the factorization.
    • 
      
  • ‘Y’: The factored matrix AB is given.
    • 
    




N


INTEGER. The order of the band matrix A.


M


INTEGER. The number of rows of the matrix B.


NBANDS1


INTEGER. The number of upper diagonals of the band matrix A.


NBANDS2


INTEGER. The number of lower diagonals of the band matrix A.


NRHS


INTEGER. The number of right hand sides, i.e., the number of
    columns of the matrix B. Also the number of columns in X.


AB


REAL(KIND=8) dimension (LDAB, K), where K = min(N, NBANDS1 + 1).
    
On entry, the array AB contains the matrix A. On exit, if
        FACTORED = ‘N’, the array AB contains the factored matrix. If
        FACTORED = ‘Y’, AB is not accessed.




LDAB


INTEGER. The leading dimension of the array AB. LDAB >= NBANDS1 +
    1.


BB


REAL(KIND=8) dimension (LDBB, NRHS).
    
On entry, the array BB contains the right hand side matrix B.
        On exit, the array BB contains the solution matrix X.




LDBB


INTEGER. The leading dimension of the array BB. LDBB >= max(1, M).


X


REAL(KIND=8) dimension (LDX, NRHS).
    
On exit, the array X contains the solution matrix X.




LDX


INTEGER. The leading dimension of the array X. LDX >= max(1,N).


RCOND


REAL(KIND=8).
    
Reciprocal scaled condition number. This is an estimate of the
        reciprocal Skeel condition number of the matrix A after
        equilibration (if done). If this is less than the machine
        precision (in particular, if it is zero), the matrix is singular
        to working precision. Note that the error may still be small even
        if this number is very small and the matrix appears ill-
        conditioned.




BERR


REAL(KIND=8) dimension (NRHS).
    
Componentwise relative backward error. This is the
        componentwise relative backward error of each solution vector X(j)
        (i.e., the smallest relative change in any element of A or B that
        makes X(j) an exact solution).




N_ERR_BNDS


INTEGER.
    
Number of error bounds to return for each right hand side
        and each type (normwise or componentwise). See ERR_BNDS_NORM and
        ERR_BNDS_COMP below.




ERR_BNDS_NORM


REAL(KIND=8) dimension (NRHS, N_ERR_BNDS).
    
For each right-hand side, this array contains information about
        various error bounds and condition numbers corresponding to the
        normwise relative error, which is defined as follows:

    
Normwise relative error in the ith solution vector:

    
max_j (abs(XTRUE(j,i) - X(j,i)))
    ------------------------------
          max_j abs(X(j,i))

    
The array is indexed by the type of error information as described
        below. There currently are up to three pieces of information
        returned.

    
The first index in ERR_BNDS_NORM(i,:) corresponds to the ith
        right-hand side.

    
The second index in ERR_BNDS_NORM(:,err) contains the following
        three fields:

    
    
      
  • err = 1  boolean. Trust the answer if the
          reciprocal condition number is less than the threshold
          sqrt(n) * dlamch('Epsilon').
    • 
      
  • err = 2  error bound: The estimated forward error,
          almost certainly within a factor of 10 of the true error
          so long as the next entry is greater than the threshold
          sqrt(n) * dlamch('Epsilon'). This error bound should only
          be trusted if the previous boolean is true.
    • 
      
  • err = 3  Reciprocal condition number: Estimated normwise
          reciprocal condition number. Compared with the threshold
          sqrt(n) * dlamch('Epsilon') to determine if the error
          estimate is . These reciprocal condition
          numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
          appropriately scaled matrix Z.
          Let Z = S*A, where S scales each row by a power of the
          radix so all absolute row sums of Z are approximately 1.
    • 
    

    
See Lapack Working Note 165 for further details and extra
        cautions.




ERR_BNDS_COMP


REAL(KIND=8) dimension (NRHS, N_ERR_BNDS).
    
For each right-hand side, this array contains information about
        various error bounds and condition numbers corresponding to the
        componentwise relative error, which is defined as follows:

    
Componentwise relative error in the ith solution vector:

    
               abs(XTRUE(j,i) - X(j,i))
      max_j ----------------------
                  abs(X(j,i))

    
The array is indexed by the right-hand side i (on which the
        componentwise relative error depends), and the type of error
        information as described below. There currently are up to three
        pieces of information returned for each right-hand side. If
        componentwise accuracy is not requested (PARAMS(3) = 0.0), then
        ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
        the first (:,N_ERR_BNDS) entries are returned.

    
The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
        right-hand side.

    
The second index in ERR_BNDS_COMP(:,err) contains the following
        three fields:

    
    
      
  • err = 1  boolean. Trust the answer if the
          reciprocal condition number is less than the threshold
          sqrt(n) * dlamch('Epsilon').
    • 
      
  • err = 2  error bound: The estimated forward error,
          almost certainly within a factor of 10 of the true error
          so long as the next entry is greater than the threshold
          sqrt(n) * dlamch('Epsilon'). This error bound should only
          be trusted if the previous boolean is true.
    • 
      
  • err = 3  Reciprocal condition number: Estimated componentwise
          reciprocal condition number. Compared with the threshold
          sqrt(n) * dlamch('Epsilon') to determine if the error
          estimate is . These reciprocal condition
          numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
          appropriately scaled matrix Z.
          Let Z = S*(A*diag(x)), where x is the solution for the
          current right-hand side and S scales each row of
          A*diag(x) by a power of the radix so all absolute row
          sums of Z are approximately 1.
    • 
    

    
See Lapack Working Note 165 for further details and extra
        cautions.




NPARAMS


INTEGER.
    
Specifies the number of parameters set in PARAMS. If <= 0, the
        PARAMS array is never referenced and default values are used.




PARAMS


REAL(KIND=8) dimension (NPARAMS).
    
Specifies algorithm parameters. If an entry is < 0.0, then
        that entry will be filled with default value used for that
        parameter. Only positions up to NPARAMS are accessed; defaults
        are used for higher-numbered parameters.

    
PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
        refinement or not.
      Default: 1.0D+0
        = 0.0:  No refinement is performed, and no error bounds are
                computed.
        = 1.0:  Use the double-precision refinement algorithm,
                possibly with doubled-single computations if the
                compilation environment does not support DOUBLE
                PRECISION.
          (other values are reserved for future use)

    PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
        computations allowed for refinement.
      Default: 10
      Aggressive: Set to 100 to permit convergence using approximate
                  factorizations or factorizations other than LU. If
                  the factorization uses a technique other than
                  Gaussian elimination, the guarantees in
                  err_bnds_norm and err_bnds_comp may no longer be
                  trustworthy.

    PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
        will attempt to find a solution with small componentwise
        relative error in the double-precision algorithm. Positive
        is true, 0.0 is false.
      Default: 1.0 (attempt componentwise convergence)




WORK


REAL(KIND=8) dimension (4*N).



IWORK


INTEGER dimension (N).



INFO


INTEGER.
    
= 0: Successful exit. The solution to every right-hand side is
        guaranteed.

    
< 0: If INFO = -i, the i-th argument had an illegal value

    
> 0 and <= N: U(INFO,INFO) is exactly zero. The factorization
        has been completed, but the factor U is exactly singular, so
        the solution and error bounds could not be computed. RCOND = 0
        is returned.

    
= N+J: The solution corresponding to the Jth right-hand side is
        not guaranteed. The solutions corresponding to other right-
        hand sides K with K > J may not be guaranteed as well, but
        only the first such right-hand side is reported. If a small
        componentwise error is not requested (PARAMS(3) = 0.0) then
        the Jth right-hand side is the first with a normwise error
        bound that is not guaranteed (the smallest J such
        that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
        the Jth right-hand side is the first with either a normwise or
        componentwise error bound that is not guaranteed (the smallest
        J such that either ERR_BNDS_NORM(J,1) = 0.0 or
        ERR_BNDS_COMP(J,1) = 0.0). See the definition of
        ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
        about all of the right-hand sides check ERR_BNDS_NORM or
        ERR_BNDS_COMP.
