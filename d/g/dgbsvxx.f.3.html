DGBSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GB

Propósito:

!>
!>    DGBSVXX utiliza la factorización LU para calcular la solución a un
!>    sistema de ecuaciones lineales de doble precisión  A * X = B,  donde A es una
!>    matriz N por N y X y B son matrices N por NRHS.
!>
!>    Si se solicita, se devuelven tanto los límites de error normwise como los
!>    límites de error del componente máximo. DGBSVXX devolverá una solución con un error
!>    garantizado minúsculo (O(eps) donde eps es la precisión de la máquina de trabajo)
!>    a menos que la matriz sea muy mal condicionada, en cuyo caso se devuelve una advertencia.
!>    También se calculan y devuelven los números de condición relevantes.
!>
!>    DGBSVXX acepta factorizaciones y factores de 
equilibrado proporcionados por el usuario;
!>    consulta las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada anterior
!>    a DGBSVXX también producirá una solución con errores de O(eps) o advertencias,
!>    pero no podemos afirmar eso para factorizaciones y factores de equilibrado
!>    proporcionados por el usuario en general si difieren de lo que DGBSVXX
!>    produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para equilibrar
!>    el sistema:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Independientemente de si el sistema se equilibrará o no, depende del
!>    escalado de la matriz A, pero si se utiliza el equilibrado, A se
!>    sobrescribe con diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como
!>
!>      A = P * L * U,
!>
!>    donde P es una matriz de permutación, L es una matriz triangular inferior unitaria
!>    y U es triangular superior.
!>
!>    3. Si algún U(i,i)=0, de modo que U sea exactamente singular, entonces la
!>    subrutina retorna con INFO = i. De lo contrario, la forma factorizada de A
!>    se utiliza para estimar el número de condición de la matriz A (ver
!>    argumento RCOND). Si la inversa del número de condición es menor que la
!>    precisión de la máquina, la subrutina continúa resolviendo X
!>    y calculando los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la subrutina utilizará el refinamiento iterativo para intentar obtener un error
!>    pequeño y límites de error. El refinamiento calcula el residuo a
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!> 
!>     Algunos parámetros opcionales están agrupados en el array PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se
!>     proporciona o no en la entrada, y si no, si la matriz A debe ser
!>     equilibrada antes de ser factorizada.
!>       = 'F':  En la entrada, AF e IPIV contienen la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               equilibrada con factores de escala dados por R y C.
!>               A, AF e IPIV no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>     Especifica la forma del sistema de ecuaciones:
!>       = 'N':  A * X = B     (Sin transposición)
!>       = 'T':  A**T * X = B  (Transpuesta)
!>       = 'C':  A**H * X = B  (Transpuesta Conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>     El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>     El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array DOUBLE PRECISION, dimensión (LDAB,N)
!>     En la entrada, la matriz A en almacenamiento de banda, en las filas 1 a KL+KU+1.
!>     La j-ésima columna de A se almacena en la j-ésima columna del
!>     array AB como sigue:
!>     AB(KU+1+i-j,j) = A(i,j) para max(1,j-KU) <= i <= min(N,j+kl)
!>
!>     Si FACT = 'F' y EQUED no es 'N', entonces AB debe haber sido
!>     equilibrada con los factores de escala en R y/o C. AB no
!>     se modifica si FACT = 'F' o 'N', o si FACT = 'E' y
!>     EQUED = 'N' en la salida.
!>
!>     En la salida, si EQUED .ne. 'N', A se escala como sigue:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB es INTEGER
!>     La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es array DOUBLE PRECISION, dimensión (LDAFB,N)
!>     Si FACT = 'F', en la entrada, AFB contiene la forma factorizada LU de A (ver
!>     subrutinas ?GBFA). Si EQUED is not 'N', AFB ha sido escalada
!>     por los factores de escala en R y/o C. AFB no se modifica.
!>
!>     Si FACT = 'N' o 'E', en la salida, AFB contiene la forma factorizada LU
!>     de la matriz A (en la parte superior del array). El resto de AFB
!>     no está definido.
!>

LDAFB

!>          LDAFB es INTEGER
!>     La dimensión principal del array AFB. LDAFB >= max(1, KL+KU+1).
!>

IPIV

!>          IPIV es array INTEGER, dimensión (N)
!>     Si FACT = 'F', en la entrada, contiene detalles de las permutaciones
!>     efectuadas en la factorización de la matriz A. IPIV no se modifica.
!>
!>     Si FACT = 'N' o 'E', en la salida, contiene detalles de las permutaciones
!>     efectuadas por la factorización LU.
!>

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica si la matriz había sido equilibrada previamente.
!>       = 'N': No se realizó ningún equilibrado.
!>       = 'R': Se realizó equilibrado por filas. R se usa y C no.
!>       = 'C': Se realizó equilibrado por columnas. C se usa y R no.
!>       = 'B': Se realizó equilibrado por filas y columnas. R y C se usan.
!>     No modificado en la salida.
!>

R

!>          R es array DOUBLE PRECISION, dimensión (N)
!>     Si EQUED = 'R' o 'B', R contiene los factores de escala de fila.
!>     No modificado en la salida.
!>

C

!>          C es array DOUBLE PRECISION, dimensión (N)
!>     Si EQUED = 'C' o 'B', C contiene los factores de escala de columna.
!>     No modificado en la salida.
!>

B

!>          B es array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>     En la entrada, la matriz N-por-NRHS de los lados derechos del sistema.
!>
!>     Si FACT = 'E' y TRANS = 'N', en la salida, B se sobrescribe con diag(R)*B.
!>
!>     Si FACT = 'E' y TRANS .ne. 'N', en la salida, B se sobrescribe con diag(C)*B.
!>
!>     Si FACT = 'N' o 'F', B no se modifica.
!>

LDB

!>          LDB es INTEGER
!>     La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>     En la salida, la matriz N-por-NRHS. Si el modelo de error calculado
!>     de la norma de cada columna de X es menor o igual que 1, entonces X
!>     es una solución con la norma de error muy pequeña.
!>

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>     En la salida, RCOND es una estimación del número de condición reciproco de la
!>     matriz A. La estimación se calcula en la precisión de trabajo.
!>     RCOND es 0 si el número de condición es infinito o muy grande.
!>

RPVGRW

!>          RPVGRW es DOUBLE PRECISION
!>     En la salida, RPVGRW es el factor de crecimiento de la norma de la
!>     matriz de entrada A.
!>     RPVGRW se usa al calcular el error estimado de la norma.
!>     RPVGRW es 0 si la matriz de entrada A es 0.
!>

BERR

!>          BERR es array DOUBLE PRECISION, dimensión (NRHS)
!>     En la salida, BERR contiene el error estimado de la norma de cada columna
!>     de X, que es un límite superior de la norma del error absoluto.
!>

N_ERR_BNDS

!>          N_ERR_BNDS es INTEGER
!>     El número de límites de error de componente que se calcularán.
!>     Si N_ERR_BNDS = 0, no se calculan límites de error de componente.
!>     Si N_ERR_BNDS = NRHS, se calculan los límites de error de componente para cada
!>     columna de X.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM es array DOUBLE PRECISION, dimensión (NRHS)
!>     Si N_ERR_BNDS >= NRHS, ERR_BNDS_NORM contiene la norma de error estimada
!>     para cada columna de X.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP es array DOUBLE PRECISION, dimensión (NRHS, N)
!>     Si N_ERR_BNDS >= NRHS, ERR_BNDS_COMP contiene el límite superior del error
!>     absoluto para cada componente de cada columna de X.
!>

NPARAMS

!>          NPARAMS es INTEGER
!>     El número de parámetros del array PARAMS.
!>     Si NPARAMS = 0, el array PARAMS se ignora.
!>

PARAMS

!>          PARAMS es array DOUBLE PRECISION, dimensión (NPARAMS)
!>     Parámetros de control para la subrutina.
!>     PARAMS(1) = Umbral de pivotaje para la factorización LU.
!>     PARAMS(2) = Umbral de refinamiento iterativo.
!>     SiPARAMS(2) es 0, el refinamiento iterativo se desactiva.
!>     SiPARAMS(2) es 1, el refinamiento iterativo se activa.
!>     SiPARAMS(2) es 2, el refinamiento iterativo se activa, y la norma de
!>     cada componente de X se comprueba contra el umbral.
!>     Otras configuraciones de PARAMS están disponibles para ajustar el
!>     comportamiento del refinamiento iterativo. Para más detalles, consulta
!>     LA_LINRX_INFO del manual de LAPACK.
!>

WORK

!>          WORK es array DOUBLE PRECISION, dimensión (LWORK)
!>     Espacio de trabajo en el que se realizarán los cálculos.
!>

LWORK

!>          LWORK es INTEGER
!>     El tamaño del array WORK.
!>     Si LWORK = 0, se reserva la cantidad mínima de espacio de trabajo.
!>     En la salida, se devuelve el valor de LWORK requerido.
!>

IWORK

!>          IWORK es array INTEGER, dimensión (LIWORK)
!>     Espacio de trabajo de enteros en el que se realizarán los cálculos.
!>

LIWORK

!>          LIWORK es INTEGER
!>     El tamaño del array IWORK.
!>     Si LIWORK = 0, se reserva la cantidad mínima de espacio de trabajo.
!>     En la salida, se devuelve el valor de LIWORK requerido.
!>

INFO

!>          INFO es INTEGER
!>     = 0: Ejecución exitosa.
!>     < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          Se puede encontrar más información sobre esto en la sección de
!>          argumentos de la subrutina.
!>     > 0: Si INFO = i, y i <= N, entonces la factorización LU no se pudo realizar
!>          porque el elemento i,i de U es cero. La matriz es singular y
!>          la solución no se puede calcular.
!>        Si INFO = i, y i = N + 1, entonces la matriz es muy mal
!>          condicionada. El refinamiento iterativo se ha realizado, pero
!>          la precisión de la solución no está garantizada.
!>        Si INFO = i, y i = N + 2, entonces el refinamiento iterativo ha fallado
!>          y la precisión de la solución no está garantizada.
!>

This subroutine estimates the reciprocal of the condition number of a general band matrix A and tests the accuracy of the solution to a linear system AX = B.

Arguments:

DENSE 
CHARACTER*1. On input, DENSE specifies the form of the matrix A:
    = 'U': A is upper triangular.
    = 'L': A is lower triangular.
    = 'G': A is general.
A 
DOUBLE PRECISION array, dimension (LDA,N). On input, the N x N matrix
    A.
LDA 
INTEGER. The leading dimension of A. LDA >= max(1,N).
TAU 
DOUBLE PRECISION array, dimension (N). On input, contains the scalar
    factor tau(i) of the elementary reflectors H(i) of the factorisation
    A = Q*T, where T is upper triangular.
PIVOT 
INTEGER array, dimension (N). On input, contains the pivot indices
    from the factorization of A. For i=1 to N, row i of A was interchanged
    with row PIVOT(i).
SCALE 
DOUBLE PRECISION array, dimension (N). On input, contains the scaling
    factors R(i) and C(i) respectively, for rows and columns of A.
RCOND 
DOUBLE PRECISION. On output, RCOND is an estimate of the reciprocal of
    the condition number of A. RCOND is zero if A is singular or very
    close to singular.
FERR 
DOUBLE PRECISION array, dimension (NRHS). On output, FERR(j) is an
    estimate of the forward error bound for the j-th solution vector X(j),
    and is computed as: FERR(j) = ( norm(X)_(inf) * RCOND ) /
    (1 - RCOND * norm(Ainv, inf) ) if RCOND is not too small.
BERR 
DOUBLE PRECISION array, dimension (NRHS). On output, BERR(j) is the
    componentwise relative backward error of the j-th solution vector
    X(j).
WORK 
DOUBLE PRECISION array, dimension (LWORK).
IWORK 
INTEGER array, dimension (N).
INFO 
INTEGER.
    = 0: successful exit.
    < 0: if INFO = -i, the i-th argument had an illegal value.
    > 0: if INFO = i, the matrix A is singular and L(i,i) is the
         zero pivot.

The condition number is estimated using a technique based on the method described in "Estimating the Condition Number of a Matrix Without Computing Its Inverse" by W. Chang, ACM Trans. Math. Software, Vol. 6, No. 2, June 1980, pp. 167-171.

Arguments:

FACT 
CHARACTER*1. Specifies the form of the matrix A and the transformations
