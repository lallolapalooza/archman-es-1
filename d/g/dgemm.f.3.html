DGEMM

Documentación de Función/Subrutina

subrutina dgemm (character transa, character transb, integer m, integer n, integer k, double precision alpha, double precision, dimension(lda,*) a, integer lda, double precision, dimension(ldb,*) b, integer ldb, double precision beta, double precision, dimension(ldc,*) c, integer ldc)

DGEMM

Propósito:

!>
!> DGEMM  realiza una de las operaciones de matriz-matriz
!>
!>    C := alpha*op( A )*op( B ) + beta*C,
!>
!> donde  op( X ) es una de
!>
!>    op( X ) = X   o   op( X ) = X**T,
!>
!> alpha y beta son escalares, y A, B y C son matrices, con op( A )
!> una matriz de m por k,  op( B )  una matriz de  k por n y  C una matriz de m por n.
!>

Parámetros

TRANSA 
!>          TRANSA es CHARACTER*1
!>           Al entrar, TRANSA especifica la forma de op( A ) a usar en
!>           la multiplicación de matrices como sigue:
!>
!>              TRANSA = 'N' o 'n',  op( A ) = A.
!>
!>              TRANSA = 'T' o 't',  op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c',  op( A ) = A**T.
!>

TRANSB

!>          TRANSB es CHARACTER*1
!>           Al entrar, TRANSB especifica la forma de op( B ) a usar en
!>           la multiplicación de matrices como sigue:
!>
!>              TRANSB = 'N' o 'n',  op( B ) = B.
!>
!>              TRANSB = 'T' o 't',  op( B ) = B**T.
!>
!>              TRANSB = 'C' o 'c',  op( B ) = B**T.
!>

M

!>          M es INTEGER
!>           Al entrar, M especifica el número de filas de la matriz
!>           op( A ) y de la matriz C. M debe ser al menos cero.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el número de columnas de la matriz
!>           op( B ) y el número de columnas de la matriz C. N debe ser
!>           al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar, K especifica el número de columnas de la matriz
!>           op( A ) y el número de filas de la matriz op( B ). K debe
!>           ser al menos cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           Al entrar, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array de DOUBLE PRECISION, de dimensión ( LDA, ka ), donde ka es
!>           k  cuando  TRANSA = 'N' o 'n',  y es  m  en caso contrario.
!>           Antes de entrar con  TRANSA = 'N' o 'n',  la parte principal de m por k
!>           del array  A  debe contener la matriz  A,  en caso contrario
!>           la parte principal de k por m  del array  A  debe contener la
!>           matriz A.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declaró
!>           en el programa (sub)llamador. Cuando  TRANSA = 'N' o 'n',
!>           LDA debe ser al menos  max( 1, m ), en caso contrario LDA debe ser
!>           al menos  max( 1, k ).
!>

B

!>          B es un array de DOUBLE PRECISION, de dimensión ( LDB, kb ), donde kb es
!>           n  cuando  TRANSB = 'N' o 'n',  y es  k  en caso contrario.
!>           Antes de entrar con  TRANSB = 'N' o 'n',  la parte principal de k por n
!>           del array  B  debe contener la matriz  B,  en caso contrario
!>           la parte principal de n por k  del array  B  debe contener la
!>           matriz B.
!>

LDB

!>          LDB es INTEGER
!>           Al entrar, LDB especifica la primera dimensión de B tal como se declaró
!>           en el programa (sub)llamador. Cuando  TRANSB = 'N' o 'n',
!>           LDB debe ser al menos  max( 1, k ), en caso contrario LDB debe ser
!>           al menos  max( 1, n ).
!>

BETA

!>          BETA es DOUBLE PRECISION.
!>           Al entrar, BETA especifica el escalar beta. Cuando  BETA
!>           se proporciona como cero, C no necesita estar configurada en la entrada.
!>

C

!>          C es un array de DOUBLE PRECISION, de dimensión ( LDC, N )
!>           Antes de entrar, la parte principal de m por n  del array  C debe
!>           contener la matriz  C,  excepto cuando beta es cero, en cuyo
!>           caso C no necesita estar configurada en la entrada.
!>           A la salida, el array C se sobrescribe con la matriz de m por n
!>           ( alpha*op( A )*op( B ) + beta*C ).
!>

LDC

!>          LDC es INTEGER
!>           Al entrar, LDC especifica la primera dimensión de C tal como se declaró
!>           en el programa (sub)llamador. LDC debe ser al menos max( 1, m ).
!>
