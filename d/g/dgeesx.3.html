subrutina dgeesx (character jobvs, character sort, external select, character sense, integer n, double precision, dimension( lda, * ) a, integer lda, integer sdim, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvs, * ) vs, integer ldvs, double precision rconde, double precision rcondv, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

DGEESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> DGEESX calcula para una matriz real N-por-N no simétrica A, los
!> valores propios, la forma real de Schur T y, opcionalmente, la matriz
!> de vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de
!> la forma real de Schur para que los valores propios seleccionados estén
!> en la parte superior izquierda; calcula un número de condición recíproco
!> para el promedio de los valores propios seleccionados (RCONDE); y
!> calcula un número de condición recíproco para el subespacio invariante
!> derecho correspondiente a los valores propios seleccionados (RCONDV).
!> Las columnas principales de Z forman una base ortonormal para este
!> subespacio invariante.
!>
!> Para una mayor explicación de los números de condición recíprocos RCONDE
!> y RCONDV, consulte la Sección 4.10 de la Guía del Usuario de LAPACK
!> (donde estas cantidades se llaman s y sep respectivamente).
!>
!> Una matriz real está en forma real de Schur si es cuasi-triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 2x2 se estandarizarán en la forma
!>           [  a  b  ]
!>           [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de tal bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': No se calculan los vectores de Schur;
!>          = 'V': Se calculan los vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': Los valores propios no se ordenan;
!>          = 'S': Los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICAL de dos argumentos DOUBLE PRECISION
!>          SELECT debe ser declarada EXTERNAL en la subrutina llamante.
!>          Si SORT = 'S', SELECT se utiliza para seleccionar valores propios
!>          para ordenar en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si se selecciona uno
!>          de un par conjugado complejo de valores propios, ambos se seleccionan.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede ya no
!>          cumplir SELECT(WR(j),WI(j)) = .TRUE. después de ordenarlo, ya que
!>          el ordenamiento puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio está mal condicionado);
!>          en este caso INFO puede establecerse en N+3 (ver INFO abajo).
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': Se calcula solo para el subespacio invariante derecho seleccionado;
!>          = 'B': Se calcula para ambos.
!>          Si SENSE = 'E', 'V' o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensiones (LDA, N)
!>          En la entrada, la matriz N-por-N A.
!>          En la salida, A se sobrescribe con su forma real de Schur T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>                         para los cuales SELECT es verdadero. (Los pares
!>                         conjugados complejos para los que SELECT es verdadero
!>                         para cualquiera de los valores propios cuentan como 2.)
!>

WR

!>          WR es un array DOUBLE PRECISION, de dimensiones (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, de dimensiones (N)
!>          WR y WI contienen las partes real e imaginaria, respectivamente,
!>          de los valores propios calculados, en el mismo orden en que
!>          aparecen en la diagonal de la forma de Schur de salida T. Los pares
!>          conjugados complejos de valores propios aparecen consecutivamente con
!>          el valor propio con la parte imaginaria positiva primero.
!>

VS

!>          VS es un array DOUBLE PRECISION, de dimensiones (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del array VS. LDVS >= 1, y si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE es DOUBLE PRECISION
!>          Si SENSE = 'E' o 'B', RCONDE contiene el número de condición
!>          recíproco para el promedio de los valores propios seleccionados.
!>          No se referencia si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es DOUBLE PRECISION
!>          Si SENSE = 'V' o 'B', RCONDV contiene el número de condición
!>          recíproco para el subespacio invariante derecho seleccionado.
!>          No se referencia si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensiones (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,3*N).
!>          Además, si SENSE = 'E' o 'V' o 'B',
!>          LWORK >= N+2*SDIM*(N-SDIM), donde SDIM es el número de
!>          valores propios seleccionados calculados por esta rutina.
!>          Tenga en cuenta que N+2*SDIM*(N-SDIM) <= N+N*N/2. Tenga en cuenta también
!>          que solo se devuelve un error si LWORK < max(1,3*N), pero si SENSE = 'E'
!>          o 'V' o 'B', esto puede no ser suficiente.
!>          Para un buen rendimiento, LWORK generalmente debe ser mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los límites superiores para los
!>          tamaños óptimos de los arrays WORK y IWORK, devuelve estos
!>          valores como las primeras entradas de los arrays WORK y IWORK,
!>          y XERBLA no emite mensajes de error relacionados con LWORK o LIWORK.
!>

IWORK

!>          IWORK es un array INTEGER, de dimensiones (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del array IWORK.
!>          LIWORK >= N.
!>          Si SENSE = 'E', 'V' o 'B', LIWORK >= max(N, 2*SDIM).
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula los límites superiores para los
!>          tamaños óptimos de los arrays WORK y IWORK, devuelve estos
!>          valores como las primeras entradas de los arrays WORK y IWORK,
!>          y XERBLA no emite mensajes de error relacionados con LWORK o LIWORK.
!>

BWORK

!>          BWORK es un array LOGICAL, de dimensiones (N)
!>          Este array se utiliza para la función SELECT.
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución correcta.
!>          < 0: si INFO = -i, el i-ésimo argumento
!>               entonces tenía un valor de entrada ilegal.
!>               Se puede encontrar una descripción de los errores de
!>               argumento de entrada en los argumentos de abajo.
!>          > 0: si INFO = i, y 1 <= i <= N, entonces la
!>               depuración del algoritmo de las condiciones de
!>               ordenamiento fracasó. El formulario Schur T está
!>               correctamente calculado, pero no se puede garantizar
!>               ningún ordenamiento.
!>          Si INFO = N+1, la depuración del algoritmo de Schur fracasó.
!>          Si INFO = N+2, el cálculo del número de condición recíproco
!>               del subespacio invariante derecho fracasó.
!>          Si INFO = N+3, el valor de SELECT cambiado durante el
!>               ordenamiento de los valores propios.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR falló al calcular todas las
!>                   eigenvalores; los elementos 1:ILO-1 e i+1:N de WR y WI
!>                   contienen aquellos eigenvalores que han convergido; si
!>                   JOBVS = 'V', VS contiene la transformación que
!>                   reduce A a su forma de Schur parcialmente convergida.
!>             = N+1: los eigenvalores no pudieron reordenarse porque algunos
!>                   eigenvalores estaban demasiado cerca para separarse (el problema
!>                   está muy mal condicionado);
!>             = N+2: después de reordenar, el redondeo cambió los valores de algunos
!>                   eigenvalores complejos de modo que los eigenvalores principales en
!>                   la forma de Schur ya no satisfacen SELECT=.TRUE. Esto
!>                   también podría ser causado por desbordamiento inferior debido al escalado.
