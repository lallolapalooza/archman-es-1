subrutina dgegs (character jobvsl, character jobvsr, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvsl, * ) vsl, integer ldvsl, double precision, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( * ) work, integer lwork, integer info)

DGEGS calcula los valores propios, la forma real de Schur y, opcionalmente, los vectores de Schur izquierdo y/o derecho de un par de matrices reales

(A,B)

Propósito

:

!> !> Esta rutina está obsoleta y ha sido reemplazada por la rutina DGGES. !> !> DGEGS calcula los valores propios, la forma real de Schur y, !> opcionalmente, los vectores de Schur izquierdo y/o derecho de un par !> de matrices reales (A,B). !> Dadas dos matrices cuadradas A y B, la factorización real generalizada !> de Schur tiene la forma !> !> A = Q*S*Z**T, B = Q*T*Z**T !> !> donde Q y Z son matrices ortogonales, T es triangular superior, y S !> es una matriz cuasi-triangular superior con bloques diagonales de !> tamaño 1x1 y 2x2, los bloques 2x2 corresponden a pares de valores !> propios complejos conjugados de (A,B). Las columnas de Q son los !> vectores de Schur izquierdos y las columnas de Z son los vectores de !> Schur derechos. !> !> Si solo se necesitan los valores propios de (A,B), se debe usar la !> rutina controladora DGEGV en su lugar. Vea DGEGV para una descripción !> de los valores propios del problema de valores propios generalizado !> no simétrico

(GNEP). !>

ALPHA

I 
!>          ALPHAI es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Las partes imaginarias de cada escalar alfa que define un
!>          valor propio del GNEP. Si ALPHAI(j) es cero, entonces el j-ésimo
!>          valor propio es real; si es positivo, entonces el j-ésimo y el
!>          (j+1)-ésimo valores propios son un par complejo conjugado, con
!>          ALPHAI(j+1) = -ALPHAI(j).
!>

BET

A 
!>          BETA es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los escalares beta que definen los valores propios del GNEP.
!>          En conjunto, las cantidades alfa = (ALPHAR(j),ALPHAI(j)) y
!>          beta = BETA(j) representan el j-ésimo valor propio del par
!>          de matrices (A,B), en una de las formas lambda = alfa/beta o
!>          mu = beta/alfa. Dado que lambda o mu pueden desbordarse,
!>          en general no deben calcularse.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= max(1,4*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>          Para calcular el valor óptimo de LWORK, llame a ILAENV para
!>          obtener los tamaños de bloque (para DGEQRF, DORMQR y DORGQR).
!>          Luego calcule:
!>          NB  -- el MÁXIMO de los tamaños de bloque para DGEQRF, DORMQR y DORGQR
!>          El LWORK óptimo es 2*N + N*(NB+1).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló. (A,B) no están en forma
!>                de Schur, pero ALPHAR(j), ALPHAI(j) y BETA(j) deberían
!>                ser correctos para j=INFO+1,...,N.
!>          > N:  errores que generalmente indican problemas de LAPACK:
!>                =N+1: retorno de error de DGGBAL
!>                =N+2: retorno de error de DGEQRF
!>                =N+3: retorno de error de DORMQR
!>                =N+4: retorno de error de DORGQR
!>                =N+5: retorno de error de DGGHRD
!>                =N+6: retorno de error de DHGEQZ (distinto de fallo
!>                                                de iteración)
!>                =N+7: retorno de error de DGGBAK (calculando VSL)
!>                =N+8: retorno de error de DGGBAK (calculando VSR)
!>                =N+9: retorno de error de DLASCL (varios lugares)
