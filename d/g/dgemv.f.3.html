DGEMV

Documentación de Función/Subrutina

subrutina dgemv (character trans, integer m, integer n, double precision alpha, double precision, dimension(lda,*) a, integer lda, double precision, dimension(*) x, integer incx, double precision beta, double precision, dimension(*) y, integer incy)

DGEMV

Propósito:

!>
!> DGEMV  realiza una de las operaciones de matriz-vector
!>
!>    y := alpha*A*x + beta*y,   o   y := alpha*A**T*x + beta*y,
!>
!> donde alpha y beta son escalares, x e y son vectores y A es una
!> matriz de m por n.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>           A la entrada, TRANS especifica la operación a realizar como
!>           sigue:
!>
!>              TRANS = 'N' o 'n'   y := alpha*A*x + beta*y.
!>
!>              TRANS = 'T' o 't'   y := alpha*A**T*x + beta*y.
!>
!>              TRANS = 'C' o 'c'   y := alpha*A**T*x + beta*y.
!>

M

!>          M es INTEGER
!>           A la entrada, M especifica el número de filas de la matriz A.
!>           M debe ser al menos cero.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el número de columnas de la matriz A.
!>           N debe ser al menos cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           A la entrada, ALPHA especifica el escalar alpha.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión ( LDA, N )
!>           Antes de la entrada, la parte principal m por n del array A debe
!>           contener la matriz de coeficientes.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como se
!>           declara en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, m ).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( m - 1 )*abs( INCX ) ) en caso contrario.
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector x.
!>

INCX

!>          INCX es INTEGER
!>           A la entrada, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

BETA

!>          BETA es DOUBLE PRECISION.
!>           A la entrada, BETA especifica el escalar beta. Cuando BETA se
!>           suministra como cero, Y no necesita ser establecida en la entrada.
!>

Y

!>          Y es un array DOUBLE PRECISION, dimensión al menos
!>           ( 1 + ( m - 1 )*abs( INCY ) ) cuando TRANS = 'N' o 'n'
!>           y al menos
!>           ( 1 + ( n - 1 )*abs( INCY ) ) en caso contrario.
!>           Antes de la entrada con BETA distinto de cero, el array Y
!>           incrementado debe contener el vector y. A la salida, Y se sobrescribe con el
!>           vector y actualizado.
!>           Si m o n es cero, entonces Y no se referencia y la función
!>           realiza un retorno rápido.
!>

INCY

!>          INCY es INTEGER
!>           A la entrada, INCY especifica el incremento para los elementos de
!>           Y. INCY no debe ser cero.
!>
