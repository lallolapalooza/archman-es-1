DGET23

Propósito:

!>
!>    DGET23 comprueba el controlador del problema de valores propios no simétrico SGEEVX.
!>    Si COMP = .FALSE., se realizarán las primeras 8 de las siguientes pruebas
!>    en la matriz de entrada A, y también la prueba 9 si LWORK es
!>    suficientemente grande.
!>    Si COMP es .TRUE., se realizarán las 11 pruebas.
!>
!>    (1)     | A * VR - VR * W | / ( n |A| ulp )
!>
!>      Aquí VR es la matriz de vectores propios derechos unitarios.
!>      W es una matriz diagonal por bloques, con un bloque de 1x1 para cada
!>      valor propio real y un bloque de 2x2 para cada par complejo conjugado.
!>      Si los valores propios j y j+1 son un par complejo conjugado,
!>      de modo que WR(j) = WR(j+1) = wr y WI(j) = - WI(j+1) = wi, entonces el
!>      bloque 2 x 2 correspondiente al par será:
!>
!>              (  wr  wi  )
!>              ( -wi  wr  )
!>
!>      Tal bloque multiplicando una matriz n x 2 ( ur ui ) por la
!>      derecha será lo mismo que multiplicar ur + i*ui por wr + i*wi.
!>
!>    (2)     | A**H * VL - VL * W**H | / ( n |A| ulp )
!>
!>      Aquí VL es la matriz de vectores propios izquierdos unitarios, A**H es la
!>      transpuesta conjugada de A, y W es como arriba.
!>
!>    (3)     | |VR(i)| - 1 | / ulp y componente mayor real
!>
!>      VR(i) denota la i-ésima columna de VR.
!>
!>    (4)     | |VL(i)| - 1 | / ulp y componente mayor real
!>
!>      VL(i) denota la i-ésima columna de VL.
!>
!>    (5)     0 si W(full) = W(partial), 1/ulp en caso contrario
!>
!>      W(full) denota los valores propios calculados cuando VR, VL, RCONDV
!>      y RCONDE también se calculan, y W(partial) denota los
!>      valores propios calculados cuando solo se calculan algunos de VR, VL, RCONDV y
!>      RCONDE.
!>
!>    (6)     0 si VR(full) = VR(partial), 1/ulp en caso contrario
!>
!>      VR(full) denota los vectores propios derechos calculados cuando VL, RCONDV
!>      y RCONDE se calculan, y VR(partial) denota el resultado
!>      cuando solo se calculan algunos de VL y RCONDV.
!>
!>    (7)     0 si VL(full) = VL(partial), 1/ulp en caso contrario
!>
!>      VL(full) denota los vectores propios izquierdos calculados cuando VR, RCONDV
!>      y RCONDE se calculan, y VL(partial) denota el resultado
!>      cuando solo se calculan algunos de VR y RCONDV.
!>
!>    (8)     0 si SCALE, ILO, IHI, ABNRM (full) =
!>                 SCALE, ILO, IHI, ABNRM (partial)
!>            1/ulp en caso contrario
!>
!>      SCALE, ILO, IHI y ABNRM describen cómo se equilibra la matriz.
!>      (full) es cuando VR, VL, RCONDE y RCONDV también se calculan, y
!>      (partial) es cuando algunos no se calculan.
!>
!>    (9)     0 si RCONDV(full) = RCONDV(partial), 1/ulp en caso contrario
!>
!>      RCONDV(full) denota los números de condición recíprocos de los
!>      vectores propios derechos calculados cuando VR, VL y RCONDE también
!>      se calculan. RCONDV(partial) denota los números de condición
!>      recíprocos cuando solo se calculan algunos de VR, VL y RCONDE.
!>
!>   (10)     |RCONDV - RCDVIN| / cond(RCONDV)
!>
!>      RCONDV es el número de condición recíproco del vector propio derecho
!>      calculado por DGEEVX y RCDVIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDV) es el número de condición de
!>      RCONDV, y tiene en cuenta los errores al calcular RCONDV, de modo
!>      que la cantidad resultante debería ser O(ULP). cond(RCONDV) es
!>      esencialmente dado por norm(A)/RCONDE.
!>
!>   (11)     |RCONDE - RCDEIN| / cond(RCONDE)
!>
!>      RCONDE es el número de condición recíproco del valor propio
!>      calculado por DGEEVX y RCDEIN (el valor verdadero precalculado)
!>      se proporciona como entrada. cond(RCONDE) es el número de condición
!>      de RCONDE, y tiene en cuenta los errores al calcular RCONDE,
!>      de modo que la cantidad resultante debería ser O(ULP). cond(RCONDE)
!>      es esencialmente dado por norm(A)/RCONDV.
!>

Parámetros

COMP 
!>          COMP es LÓGICO
!>          COMP describe qué pruebas de entrada realizar:
!>            = .FALSE. si los números de condición calculados no deben
!>                      probarse contra RCDVIN y RCDEIN
!>            = .TRUE.  si deben compararse
!>

BALANC

!>          BALANC es CARÁCTER
!>          Describe la opción de equilibrado a probar.
!>            = 'N' para no permutar ni escalar diagonal
!>            = 'P' para permutar pero no escalar diagonal
!>            = 'S' para no permutar pero escalar diagonal
!>            = 'B' para permutar y escalar diagonal
!>

JTYPE

!>          JTYPE es ENTERO
!>          Tipo de matriz de entrada. Se usa para etiquetar la salida si ocurre un error.
!>

THRESH

!>          THRESH es PRECISIÓN DOBLE
!>          Una prueba se contará como fallida si el error, calculado como
!>          se describe arriba, supera THRESH. Tenga en cuenta que el error
!>          está escalado para ser O(1), por lo que THRESH debe ser un múltiplo
!>          razonablemente pequeño de 1, p. ej., 10 o 100. En particular,
!>          no debe depender de la precisión (simple vs. doble)
!>          ni del tamaño de la matriz. Debe ser al menos cero.
!>

ISEED

!>          ISEED es una matriz de ENTEROS, dimensión (4)
!>          Si COMP = .FALSE., la semilla del generador de números aleatorios
!>          usada para producir la matriz.
!>          Si COMP = .TRUE., ISEED(1) = el número del ejemplo.
!>sed para etiquetar la salida si ocurre un error.
!>

NOUNIT

!>          NOUNIT es INTEGER
!>          El número de unidad FORTRAN para imprimir mensajes de error
!>          (por ejemplo, si una rutina devuelve INFO distinto de 0).
!>

N

!>          N es INTEGER
!>          La dimensión de A. N debe ser al menos 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          Se utiliza para almacenar la matriz cuyos valores propios se van a
!>          calcular.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A y H. LDA debe ser
!>          al menos 1 y al menos N.
!>

H

!>          H es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          Otra copia de la matriz de prueba A, modificada por DGEEVX.
!>

WR

!>          WR es un array DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Las partes real e imaginaria de los valores propios de A.
!>          Al salir, WR + WI*i son los valores propios de la matriz en A.
!>

WR1

!>          WR1 es un array DOUBLE PRECISION, dimensión (N)
!>

WI1

!>          WI1 es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Al igual que WR, WI, estos arrays contienen los valores propios de A,
!>          pero aquellos calculados cuando DGEEVX solo calcula una
!>          descomposición de valores propios parcial, es decir, no los valores propios y los vectores propios izquierdos
!>          y derechos.
!>

VL

!>          VL es un array DOUBLE PRECISION, dimensión (LDVL,N)
!>          VL contiene los vectores propios izquierdos calculados.
!>

LDVL

!>          LDVL es INTEGER
!>          Dimensión principal de VL. Debe ser al menos max(1,N).
!>

VR

!>          VR es un array DOUBLE PRECISION, dimensión (LDVR,N)
!>          VR contiene los vectores propios derechos calculados.
!>

LDVR

!>          LDVR es INTEGER
!>          Dimensión principal de VR. Debe ser al menos max(1,N).
!>

LRE

!>          LRE es un array DOUBLE PRECISION, dimensión (LDLRE,N)
!>          LRE contiene los vectores propios derechos o izquierdos calculados.
!>

LDLRE

!>          LDLRE es INTEGER
!>          Dimensión principal de LRE. Debe ser al menos max(1,N).
!>

RCONDV

!>          RCONDV es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDV contiene los números de condición recíprocos calculados
!>          para los vectores propios.
!>

RCNDV1

!>          RCNDV1 es un array DOUBLE PRECISION, dimensión (N)
!>          RCNDV1 contiene más números de condición recíprocos calculados
!>          para los vectores propios.
!>

RCDVIN

!>          RCDVIN es un array DOUBLE PRECISION, dimensión (N)
!>          Cuando COMP = .TRUE., RCDVIN contiene los números de condición recíprocos precalculados
!>          para los vectores propios para ser comparados con
!>          RCONDV.
!>

RCONDE

!>          RCONDE es un array DOUBLE PRECISION, dimensión (N)
!>          RCONDE contiene los números de condición recíprocos calculados
!>          para los valores propios.
!>

RCNDE1

!>          RCNDE1 es un array DOUBLE PRECISION, dimensión (N)
!>          RCNDE1 contiene más números de condición recíprocos calculados
!>          para los valores propios.
!>

RCDEIN

!>          RCDEIN es un array DOUBLE PRECISION, dimensión (N)
!>          Cuando COMP = .TRUE., RCDEIN contiene los números de condición recíprocos precalculados
!>          para los valores propios para ser comparados con
!>          RCONDE.
!>

SCALE

!>          SCALE es un array DOUBLE PRECISION, dimensión (N)
!>          Contiene información que describe el balanceo de la matriz.
!>

SCALE1

!>          SCALE1 es un array DOUBLE PRECISION, dimensión (N)
!>          Contiene información que describe el balanceo de la matriz.
!>

RESULT

!>          RESULT es un array DOUBLE PRECISION, dimensión (11)
!>          Los valores calculados por las 11 pruebas descritas anteriormente.
!>          Los valores se limitan actualmente a 1/ulp, para evitar
!>          desbordamiento.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          El número de elementos en WORK. Debe ser al menos
!>          3*N, y 6*N+N**2 si se van a realizar las pruebas 9, 10 o 11.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (2*N)
!>

INFO

!>          INFO es INTEGER
!>          Si es 0, salida exitosa.
!>          Si es <0, el parámetro de entrada -INFO tenía un valor incorrecto.
!>          Si es >0, DGEEVX devolvió un código de error, cuyo
!>                 valor absoluto se devuelve.
!>
