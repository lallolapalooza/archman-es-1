Documentación de Función/Subrutina

subrutina dgeev (character jobvl, character jobvr, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) work, integer lwork, integer info)

DGEEV calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices GE

Propósito:

!>
!> DGEEV calcula para una matriz A real no simétrica N-por-N, los
!> eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos.
!>
!> El eigenvector derecho v(j) de A satisface
!>                  A * v(j) = lambda(j) * v(j)
!> donde lambda(j) es su eigenvalor.
!> El eigenvector izquierdo u(j) de A satisface
!>               u(j)**H * A = lambda(j) * u(j)**H
!> donde u(j)**H denota el conjugado-transpuesto de u(j).
!>
!> Los eigenvectores calculados están normalizados para tener norma euclidiana
!> igual a 1 y el componente más grande real.
!>

Parámetros

JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N': no se calculan los eigenvectores izquierdos de A;
!>          = 'V': se calculan los eigenvectores izquierdos de A.
!>

JOBVR

!>          JOBVR es CHARACTER*1
!>          = 'N': no se calculan los eigenvectores derechos de A;
!>          = 'V': se calculan los eigenvectores derechos de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A N-por-N.
!>          En la salida, A ha sido sobrescrita.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

WR

!>          WR es un array DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria,
!>          respectivamente, de los eigenvalores calculados.  Los
!>          pares conjugados complejos de eigenvalores aparecen
!>          consecutivamente con el eigenvalor que tiene la parte
!>          imaginaria positiva primero.
!>

VL

!>          VL es un array DOUBLE PRECISION, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los eigenvectores izquierdos u(j) se almacenan uno
!>          tras otro en las columnas de VL, en el mismo orden
!>          que sus eigenvalores.
!>          Si JOBVL = 'N', VL no es referenciada.
!>          Si el j-ésimo eigenvalor es real, entonces u(j) = VL(:,j),
!>          la j-ésima columna de VL.
!>          Si el j-ésimo y el (j+1)-ésimo eigenvalores forman un par
!>          conjugado complejo, entonces u(j) = VL(:,j) + i*VL(:,j+1) y
!>          u(j+1) = VL(:,j) - i*VL(:,j+1).
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.  LDVL >= 1; si
!>          JOBVL = 'V', LDVL >= N.
!>

VR

!>          VR es un array DOUBLE PRECISION, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los eigenvectores derechos v(j) se almacenan uno
!>          tras otro en las columnas de VR, en el mismo orden
!>          que sus eigenvalores.
!>          Si JOBVR = 'N', VR no es referenciada.
!>          Si el j-ésimo eigenvalor es real, entonces v(j) = VR(:,j),
!>          la j-ésima columna de VR.
!>          Si el j-ésimo y el (j+1)-ésimo eigenvalores forman un par
!>          conjugado complejo, entonces v(j) = VR(:,j) + i*VR(:,j+1) y
!>          v(j+1) = VR(:,j) - i*VR(:,j+1).
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.  LDVR >= 1; si
!>          JOBVR = 'V', LDVR >= N.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,3*N), y
!>          si JOBVL = 'V' o JOBVR = 'V', LWORK >= 4*N.  Para un buen
!>          rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el algoritmo QR falló al calcular todos los
!>                eigenvalores, y no se han calculado eigenvectores;
!>                los elementos i+1:N de WR y WI contienen eigenvalores que
!>                han convergido.
!>
