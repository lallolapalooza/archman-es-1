subrutina dgsvj1 (character*1 jobv, integer m, integer n, integer n1, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( n ) d, double precision, dimension( n ) sva, integer mv, double precision, dimension( ldv, * ) v, integer ldv, double precision eps, double precision sfmin, double precision tol, integer nsweep, double precision, dimension( lwork ) work, integer lwork, integer

DGSVJ1 es un preprocesador para la rutina dgesvj, aplica rotaciones Jacobi dirigidas únicamente a pivotes

particulares.

Propósito

: 
!>
!> DGSVJ1 se llama desde DGESVJ como un preprocesador y ese es su principal
!> propósito. Aplica rotaciones Jacobi de la misma manera que DGESVJ, pero
!> se dirige únicamente a pivotes particulares y no comprueba la convergencia
!> (criterio de parada). Hay disponibles algunos parámetros de ajuste (marcados con [TP])
!> para el implementador.
!>
!> Más detalles
!> ~~~~~~~~~~~~~~~
!> DGSVJ1 aplica algunas barridas de rotaciones Jacobi en el espacio de columnas
!> de la matriz de entrada M-por-N A. Los pares de pivotes se toman del bloque
!> fuera de diagonal (1,2) en la matriz de Gram correspondiente N-por-N A^T * A.
!> Las entradas de bloque (tiles) del bloque fuera de diagonal (1,2) están marcadas por los
!> [x] en el siguiente esquema:
!>
!>    | *  *  * [x] [x] [x]|
!>    | *  *  * [x] [x] [x]|    Ciclado de filas en los bloques [x] de nblr-por-nblc.
!>    | *  *  * [x] [x] [x]|    Pivoteo cíclico por filas dentro de cada bloque [x].
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>    |[x] [x] [x] *  *  * |
!>
!> En términos de las columnas de A, las primeras N1 columnas se rotan 'contra'
!> las N-N1 columnas restantes, intentando aumentar el ángulo entre los
!> subespacios correspondientes. El bloque fuera de diagonal es N1-por(N-N1) y está
!> dividido en mosaicos usando mosaicos cuadrados de lado KBL. Aquí, KBL es un parámetro de ajuste.
!> El número de barridas se da en NSWEEP y el umbral de ortogonalidad
!> se da en TOL.
!
>

Parámetro

s
JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se usa
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones Jacobi se acumula
!>                 postmultiplicando el arreglo N-por-N V.
!>                (Vea la descripción de V.)
!>          = 'A': el producto de las rotaciones Jacobi se acumula
!>                 postmultiplicando el arreglo MV-por-N V.
!>                (Vea las descripciones de MV y V.)
!>          = 'N': las rotaciones Jacobi no se acumulan.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!
>

N

1 
!>          N1 es INTEGER
!>          N1 especifica la partición en bloques de 2 x 2, las primeras N1 columnas
!>          se rotan 'contra' las N-N1 columnas restantes de A.
!
>

A 
!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N)
!>          A la entrada, matriz A de M-por-N, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          A la salida,
!>          A_onexit * D_onexit representa la matriz de entrada A*diag(D)
!>          post-multiplicada por una secuencia de rotaciones Jacobi, donde
!>          el umbral de rotación y el número total de barridas se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Vea las descripciones de N1, D, TOL y NSWEEP.)
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,M).
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión (N)
!>          El arreglo D acumula los factores de escala de las rotaciones Jacobi
!>          escaladas rápidas.
!>          A la entrada, A*diag(D) representa la matriz de entrada.
!>          A la salida, A_onexit*diag(D_onexit) representa la matriz de entrada
!>          post-multiplicada por una secuencia de rotaciones Jacobi, donde
!>          el umbral de rotación y el número total de barridas se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Vea las descripciones de N1, A, TOL y NSWEEP.)
!
>

SV

A 
!>          SVA es un arreglo DOUBLE PRECISION, dimensión (N)
!>          A la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          A la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz onexit*diag(D_onexit).
!
>

M

V 
!>          MV es INTEGER
!>          Si JOBV = 'A', entonces las filas MV de V se post-multiplican por una
!>                         secuencia de rotaciones Jacobi.
!>          Si JOBV = 'N', entonces MV no se referencia.
!
>

V 
!>          V es un arreglo DOUBLE PRECISION, dimensión (LDV,N)
!>          Si JOBV = 'V', entonces las filas N de V se post-multiplican por una
!>                         secuencia de rotaciones Jacobi.
!>          Si JOBV = 'A', entonces las filas MV de V se post-multiplican por una
!>                         secuencia de rotaciones Jacobi.
!>          Si JOBV = 'N', entonces V no se referencia.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del arreglo V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!
>

EP

S 
!>          EPS es DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!
>

SFMI

N 
!>          SFMIN es DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!
>

TO

L 
!>          TOL es DOUBLE PRECISION
!>          TOL es el umbral para las rotaciones Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación Jacobi se
!>          aplica solo si DABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!
>

NSWEE

P 
!>          NSWEEP es INTEGER
!>          NSWEEP es el número de barridas de rotaciones Jacobi a
!>          realizar.
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (LWORK)
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          LWORK es la dimensión de WORK. LWORK >= M.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, entonces el i-ésimo argumento tenía un valor ilegal
!
>
