Documentación de Función/Subrutina

subrutina dgqrts (integer n, integer m, integer p, double precision, dimension( lda, * ) a, double precision, dimension( lda, * ) af, double precision, dimension( lda, * ) q, double precision, dimension( lda, * ) r, integer lda, double precision, dimension( * ) taua, double precision, dimension( ldb, * ) b, double precision, dimension( ldb, * ) bf, double precision, dimension( ldb, * ) z, double precision, dimension( ldb, * ) t, double precision, dimension( ldb, * ) bwk, integer ldb, double precision, dimension( * ) taub, double precision, dimension( lwork ) work, integer lwork, double precision, dimension( * ) rwork, double precision, dimension( 4 ) result)

DGQRTS

Propósito

!>
!> DGQRTS prueba DGGQRF, que calcula la factorización GQR de una
!> matriz N-por-M A y una matriz N-por-P B: A = Q*R y B = Q*T*Z.
!>

Parámetros

N 
!>          N es INTEGER
!>          El número de filas de las matrices A y B.  N >= 0.
!>

M

!>          M es INTEGER
!>          El número de columnas de la matriz A.  M >= 0.
!>

P

!>          P es INTEGER
!>          El número de columnas de la matriz B.  P >= 0.
!>

A

!>          A es array de DOUBLE PRECISION, dimension (LDA,M)
!>          La matriz N-por-M A.
!>

AF

!>          AF es array de DOUBLE PRECISION, dimension (LDA,N)
!>          Detalles de la factorización GQR de A y B, como se devuelve
!>          por DGGQRF, ver SGGQRF para más detalles.
!>

Q

!>          Q es array de DOUBLE PRECISION, dimension (LDA,N)
!>          La matriz ortogonal M-por-M Q.
!>

R

!>          R es array de DOUBLE PRECISION, dimension (LDA,MAX(M,N))
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de los arrays A, AF, R y Q.
!>          LDA >= max(M,N).
!>

TAUA

!>          TAUA es array de DOUBLE PRECISION, dimension (min(M,N))
!>          Los factores escalares de los reflectores elementales, como se devuelven
!>          por DGGQRF.
!>

B

!>          B es array de DOUBLE PRECISION, dimension (LDB,P)
!>          En la entrada, la matriz N-por-P A.
!>

BF

!>          BF es array de DOUBLE PRECISION, dimension (LDB,N)
!>          Detalles de la factorización GQR de A y B, como se devuelve
!>          por DGGQRF, ver SGGQRF para más detalles.
!>

Z

!>          Z es array de DOUBLE PRECISION, dimension (LDB,P)
!>          La matriz ortogonal P-por-P Z.
!>

T

!>          T es array de DOUBLE PRECISION, dimension (LDB,max(P,N))
!>

BWK

!>          BWK es array de DOUBLE PRECISION, dimension (LDB,N)
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de los arrays B, BF, Z y T.
!>          LDB >= max(P,N).
!>

TAUB

!>          TAUB es array de DOUBLE PRECISION, dimension (min(P,N))
!>          Los factores escalares de los reflectores elementales, como se devuelven
!>          por DGGRQF.
!>

WORK

!>          WORK es array de DOUBLE PRECISION, dimension (LWORK)
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK, LWORK >= max(N,M,P)**2.
!>

RWORK

!>          RWORK es array de DOUBLE PRECISION, dimension (max(N,M,P))
!>

RESULT

!>          RESULT es array de DOUBLE PRECISION, dimension (4)
!>          Las razones de prueba:
!>            RESULT(1) = norm( R - Q'*A ) / ( MAX(M,N)*norm(A)*ULP)
!>            RESULT(2) = norm( T*Z - Q'*B ) / (MAX(P,N)*norm(B)*ULP)
!>            RESULT(3) = norm( I - Q'*Q ) / ( M*ULP )
!>            RESULT(4) = norm( I - Z'*Z ) / ( P*ULP )
!>
