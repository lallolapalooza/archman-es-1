Documentación de Función/Subrutina

subrutina dgglse (integer m, integer n, integer p, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) c, double precision, dimension( * ) d, double precision, dimension( * ) x, double precision, dimension( * ) work, integer lwork, integer info)

DGGLSE resuelve sistemas sobredeterminados o subdeterminados para matrices OTHER

Propósito:

!>
!> DGGLSE resuelve el problema de mínimos cuadrados con igualdades lineales (LSE):
!>
!>         minimizar || c - A*x ||_2   sujeto a   B*x = d
!>
!> donde A es una matriz de M por N, B es una matriz de P por N, c es un
!> vector M dado, y d es un vector P dado. Se asume que
!> P <= N <= M+P, y
!>
!>          rango(B) = P y  rango( (A) ) = N.
!>                               ( (B) )
!>
!> Estas condiciones aseguran que el problema LSE tiene una solución única,
!> la cual se obtiene usando una factorización RQ generalizada de las
!> matrices (B, A) dada por
!>
!>    B = (0 R)*Q,   A = Z*T*Q.
!>
!> Los llamadores de esta subrutina deben tener en cuenta que las comprobaciones de
!> singularidad/deficiencia de rango implementadas en esta subrutina son rudimentarias.
!> La subrutina DTRTRS llamada por esta subrutina solo señala un fallo debido a
!> singularidad si el problema es exactamente singular.
!>
!> Es concebible que uno (o más) de los factores involucrados en la factorización RQ
!> generalizada del par (B, A) esté subnormalmente cerca de la singularidad sin que
!> esta subrutina señale un error. Las soluciones calculadas para tales problemas
!> casi deficientes en rango pueden ser menos precisas debido a una pérdida de
!> precisión numérica.
!> 
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de las matrices A y B. N >= 0.
!>

P

!>          P es INTEGER
!>          El número de filas de la matriz B. 0 <= P <= N <= M+P.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, los elementos en y sobre la diagonal del array
!>          contienen la matriz trapezoidal superior T de min(M,N) por N.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, el triángulo superior del subarray B(1:P,N-P+1:N)
!>          contiene la matriz triangular superior R de P por P.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!>

C

!>          C es un array DOUBLE PRECISION, dimensión (M)
!>          En la entrada, C contiene el vector del segundo miembro para la
!>          parte de mínimos cuadrados del problema LSE.
!>          En la salida, la suma de residuos de cuadrados para la solución
!>          se da por la suma de los cuadrados de los elementos N-P+1 a M del
!>          vector C.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (P)
!>          En la entrada, D contiene el vector del segundo miembro para la
!>          ecuación restringida.
!>          En la salida, D es destruido.
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (N)
!>          En la salida, X es la solución del problema LSE.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,M+N+P).
!>          Para un rendimiento óptimo LWORK >= P+min(M,N)+max(M,N)*NB,
!>          donde NB es una cota superior para los tamaños de bloque óptimos
!>          para DGEQRF, SGERQF, DORMQR y SORMRQ.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1:  el factor triangular superior R asociado con B en la
!>                factorización RQ generalizada del par (B, A) es exactamente
!>                singular, de modo que rango(B) < P; la solución de mínimos
!>                cuadrados no pudo ser calculada.
!>          = 2:  la parte de (N-P) por (N-P) del factor trapezoidal superior
!>                T asociado con A en la factorización RQ generalizada
!>                del par (B, A) es exactamente singular, de modo que
!>                rango( (A) ) < N; la solución de mínimos cuadrados no pudo
!>                    ( (B) )
!>                ser calculada.
!>
