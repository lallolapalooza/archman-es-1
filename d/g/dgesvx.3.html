subrutina dgesvx (character fact, character trans, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!> DGESVX usa la factorización LU para calcular la solución a un sistema
!> real de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una
!> estimación de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibra o no depende de la
!>    escala de la matriz A, pero si se usa el equilibrado, A es
!>    sobrescrita por diag(R)*A*diag(C) y B por diag(R)*B (si TRANS='N')
!>    o diag(C)*B (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se usa la descomposición LU para factorizar la
!>    matriz A (después del equilibrado si FACT = 'E') como
!>       A = P * L * U,
!>    donde P es una matriz de permutación, L es una matriz triangular
!>    inferior unitaria, y U es triangular superior.
!>
!> 3. Si algún U(i,i)=0, de modo que U es exactamente singular, entonces la rutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se usa
!>    para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de máquina,
!>    se retorna INFO = N+1 como una advertencia, pero la rutina continúa
!>    para resolver X y calcular los límites de error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X usando la forma factorizada
!>    de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular los límites de error y las estimaciones de error
!>    hacia atrás para ella.
!>
!> 6. Si se usó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') de modo
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona a la entrada, y si no, si la matriz A debe
!>          equilibrarse antes de ser factorizada.
!>          = 'F':  A la entrada, AF e IPIV contienen la forma factorizada de A.
!>                  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  A, AF e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará a AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transponer)
!>          = 'C':  A**H * X = B  (Transponer)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA,N)
!>          A la entrada, la matriz A de N por N. Si FACT = 'F' y EQUED no es
!>          'N', entonces A debe haber sido equilibrada por los factores de escala
!>          en R y/o C. A no se modifica si FACT = 'F' o
!>          'N', o si FACT = 'E' y EQUED = 'N' a la salida.
!>
!>          A la salida, si EQUED .ne. 'N', A se escala como sigue:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

AF

!>          AF es un arreglo DOUBLE PRECISION, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y a la entrada
!>          contiene los factores L y U de la factorización
!>          A = P*L*U tal como la calcula DGETRF. Si EQUED .ne. 'N', entonces
!>          AF es la forma factorizada de la matriz equilibrada A.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y a la salida
!>          retorna los factores L y U de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y a la salida
!>          retorna los factores L y U de la factorización A = P*L*U
!>          de la matriz equilibrada A (véase la descripción de A para
!>          la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del arreglo AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un arreglo INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y a la entrada
!>          contiene los índices pivote de la factorización A = P*L*U
!>          tal como la calcula DGETRF; la fila i de la matriz se intercambió
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y a la salida
!>          contiene los índices pivote de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y a la salida
!>          contiene los índices pivote de la factorización A = P*L*U
!>          de la matriz equilibrada A.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre cierto si FACT = 'N').
!>          = 'R':  Equilibrado por filas, es decir, A ha sido premultiplicada por
!>                  diag(R).
!>          = 'C':  Equilibrado por columnas, es decir, A ha sido postmultiplicada
!>                  por diag(C).
!>          = 'B':  Tanto equilibrado por filas como por columnas, es decir, A ha sido
!>                  reemplazada por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!> <


R


!>          R es un array de DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala de fila para A. Si EQUED = 'R' o 'B', A se
!>          multiplica por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>          no se accede. R es un argumento de entrada si FACT = 'F';
!>          de lo contrario, R es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'R' o 'B', cada elemento de R debe ser positivo.







C


!>          C es un array de DOUBLE PRECISION, de dimensión (N)
!>          Los factores de escala de columna para A. Si EQUED = 'C' o 'B', A se
!>          multiplica por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>          no se accede. C es un argumento de entrada si FACT = 'F';
!>          de lo contrario, C es un argumento de salida. Si FACT = 'F' y
!>          EQUED = 'C' o 'B', cada elemento de C debe ser positivo.







B


!>          B es un array de DOUBLE PRECISION, de dimensión (LDB,NRHS)
!>          A la entrada, la matriz B de mano derecha de N por NRHS.
!>          A la salida,
!>          si EQUED = 'N', B no se modifica;
!>          si TRANS = 'N' y EQUED = 'R' o 'B', B se sobrescribe por
!>          diag(R)*B;
!>          si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B se
!>          sobrescribe por diag(C)*B.







LDB


!>          LDB es un INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).







X


!>          X es un array de DOUBLE PRECISION, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS
!>          del sistema original de ecuaciones. Tenga en cuenta que A y B
!>          se modifican a la salida si EQUED .ne. 'N', y la solución del
!>          sistema equilibrado es inv(diag(C))*X si TRANS = 'N' y
!>          EQUED = 'C' o 'B', o inv(diag(R))*X si TRANS = 'T' o 'C'
!>          y EQUED = 'R' o 'B'.







LDX


!>          LDX es un INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).







RCOND


!>          RCOND es DOUBLE PRECISION
!>          La estimación del recíproco del número de condición de la matriz
!>          A después de la 



equilibrio (si se realizó). Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular con precisión de trabajo. Esta condición se
!>          indica con un código de retorno de INFO > 0.







FERR


!>          FERR es un array de DOUBLE PRECISION, de dimensión (NRHS)
!>          El error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la verdadera solución correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y casi siempre es un ligero
!>          sobreestimación del error real.







BERR


!>          BERR es un array de DOUBLE PRECISION, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el menor cambio relativo en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).







WORK


!>          WORK es un array de DOUBLE PRECISION, de dimensión (MAX(1,4*N))
!>          A la salida, WORK(1) contiene el factor de crecimiento del pivote recíproco
!>          norm(A)/norm(U). El 



norma se
!>          utiliza. Si WORK(1) es mucho menor que 1, entonces la estabilidad
!>          de la factorización LU de la matriz A (equilibrada)
!>          podría ser pobre. Esto también significa que la solución X, el estimador de
!>          condición RCOND y la cota de error hacia adelante FERR podrían ser
!>          poco fiables. Si la factorización falla con 0<INFO<=N, entonces
!>          WORK(1) contiene el factor de crecimiento del pivote recíproco para las
!>          columnas principales INFO de A.







IWORK


!>          IWORK es un array de INTEGER, de dimensión (N)







INFO


!>          INFO es un INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, e i es
!>                <= N:  U(i,i) es exactamente cero. La factorización ha
!>                       completado, pero el factor U es exactamente
!>                       singular, por lo que la solución y las cotas de error
!>                       no pudieron calcularse. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión de la
!>                       máquina, lo que significa que la matriz es singular
!>                       con precisión de trabajo. Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay varias situaciones en las que la
!>                       solución calculada puede ser más precisa que la
!>                       que sugeriría el valor de RCOND.
