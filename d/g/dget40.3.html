DGET40

Propósito:

!>
!> DGET40 prueba DTGEXC, una rutina para intercambiar bloques adyacentes (ya sea
!> de 1x1 o 2x2) en la diagonal de un lápiz en forma de Schur generalizada real.
!> Por lo tanto, DTGEXC calcula matrices ortogonales Q y Z tales que
!>
!>     Q' * ( [ A B ], [ D E ] ) * Z  = ( [ C1 B1 ], [ F1 E1 ] )
!>          ( [ 0 C ]  [   F ] )        ( [ 0  A1 ]  [    D1]  )
!>
!> donde (C1,F1) es similar a (C,F) y (A1,D1) es similar a (A,D).
!> Se asume que tanto (A,D) como (C,F) están en forma estándar
!> y (A1,D1) y (C1,F1) se devuelven con las
!> mismas propiedades.
!>

Parámetros

RMAX 
!>          RMAX es DOBLE PRECISIÓN
!>          Valor de la razón de prueba más grande.
!>

LMAX

!>          LMAX es ENTERO
!>          Número de ejemplo donde se logró la razón de prueba más grande.
!>

NINFO

!>          NINFO es un array ENTERO, dimensión (2)
!>          NINFO( 1 ) = DTGEXC sin acumulación devolvió INFO distinto de cero
!>          NINFO( 2 ) = DTGEXC con acumulación devolvió INFO distinto de cero
!>

KNT

!>          KNT es ENTERO
!>          Número total de ejemplos probados.
!>

NIN

!>          NIN es ENTERO
!>          Número de unidad lógica de entrada.
!>
