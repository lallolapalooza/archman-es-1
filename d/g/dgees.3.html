Documentación de Función/Subrutina

subrutina dgees (character jobvs, character sort, external select, integer n, double precision, dimension( lda, * ) a, integer lda, integer sdim, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvs, * ) vs, integer ldvs, double precision, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

DGEES calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> DGEES calcula para una matriz real no simétrica A de N por N, los
!> valores propios, la forma de Schur real T y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de la
!> forma de Schur real de modo que los valores propios seleccionados estén
!> en la parte superior izquierda. Las columnas iniciales de Z forman
!> entonces una base ortonormal para el subespacio invariante correspondiente
!> a los valores propios seleccionados.
!>
!> Una matriz está en forma de Schur real si es una matriz superior
!> cuasitriangular con bloques de 1 por 1 y de 2 por 2. Los bloques de 2 por 2
!> se estandarizarán en la forma
!>         [  a  b  ]
!>         [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de tal bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': no se calculan los vectores de Schur;
!>          = 'V': se calculan los vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': no se ordenan los valores propios;
!>          = 'S': se ordenan los valores propios (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LÓGICA de dos argumentos DOUBLE PRECISION
!>          SELECT debe declararse como EXTERNAL en la subrutina que llama.
!>          Si SORT = 'S', SELECT se usa para seleccionar los valores propios
!>          que se ordenarán a la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si se selecciona uno
!>          de un par de valores propios complejos conjugados, entonces
!>          ambos valores propios complejos se seleccionan.
!>          Nótese que un valor propio complejo seleccionado puede dejar de
!>          cumplir SELECT(WR(j),WI(j)) = .TRUE. después de la ordenación, ya
!>          que la ordenación puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio está mal condicionado);
!>          en este caso INFO se establece a N+2 (ver INFO más abajo).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A de N por N.
!>          En la salida, A ha sido sobrescrita por su forma de Schur real T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de
!>                         ordenar) para los cuales SELECT es verdadero.
!>                         (Los pares de complejos conjugados para los cuales
!>                         SELECT es verdadero para cualquiera de los valores
!>                         propios se cuentan como 2.)
!>

WR

!>          WR es un array DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es un array DOUBLE PRECISION, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria,
!>          respectivamente, de los valores propios calculados en el mismo
!>          orden en que aparecen en la diagonal de la forma de Schur de
!>          salida T. Los pares de valores propios complejos conjugados
!>          aparecerán consecutivamente con el valor propio que tiene la
!>          parte imaginaria positiva primero.
!>

VS

!>          VS es un array DOUBLE PRECISION, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del array VS.  LDVS >= 1; si
!>          JOBVS = 'V', LDVS >= N.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,3*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no
!>          emite ningún mensaje de error relacionado con LWORK.
!>

BWORK

!>          BWORK es un array LÓGICO, dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR falló al calcular todos los
!>                   valores propios; los elementos 1:ILO-1 y i+1:N de WR y WI
!>                   contienen aquellos valores propios que han convergido; si
!>                   JOBVS = 'V', VS contiene la matriz que reduce A
!>                   a su forma de Schur parcialmente convergida.
!>             = N+1: los valores propios no pudieron reordenarse porque algunos
!>                   valores propios estaban demasiado cerca para separarse (el problema
!>                   está muy mal condicionado);
!>             = N+2: después de reordenar, el redondeo cambió los valores de algunos
!>                   valores propios complejos de modo que los valores propios principales en
!>                   la forma de Schur ya no cumplen SELECT=.TRUE. Esto
!>                   también podría ser causado por un desbordamiento inferior debido al escalado.
!>
