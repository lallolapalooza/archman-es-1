Documentación de la función/subrutina

subroutine dgees (character jobvs, character sort, external select, integer n, double precision, dimension( lda, * ) a, integer lda, integer sdim, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvs, * ) vs, integer ldvs, double precision, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

DGEES calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> DGEES calcula para una matriz real no simétrica A de N por N, los
!> valores propios, la forma real de Schur T y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto da la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de
!> la forma real de Schur para que los valores propios seleccionados estén
!> en la parte superior izquierda. Las columnas líderes de Z forman entonces
!> una base ortonormal para el subespacio invariante correspondiente a
!> los valores propios seleccionados.
!>
!> Una matriz está en forma real de Schur si es cuasi-triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 2x2 se estandarizarán en la
!> forma
!>         [  a  b  ]
!>         [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de tal bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': No se calculan vectores de Schur;
!>          = 'V': Se calculan vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': Los valores propios no se ordenan;
!>          = 'S': Los valores propios se ordenan (ver SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LOGICAL de dos argumentos DOUBLE PRECISION
!>          SELECT debe declararse EXTERNAL en la subrutina llamante.
!>          Si SORT = 'S', SELECT se usa para seleccionar valores propios
!>          para ordenar en la parte superior izquierda de la forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si se selecciona uno
!>          de un par de valores propios conjugados complejos, entonces
!>          ambos valores propios complejos son seleccionados.
!>          Tenga en cuenta que un valor propio complejo seleccionado puede que ya
!>          no cumpla SELECT(WR(j),WI(j)) = .TRUE. después de ordenar, ya que
!>          la ordenación puede cambiar el valor de los valores propios
!>          complejos (especialmente si el valor propio está mal condicionado);
!>          en este caso INFO se establece en N+2 (ver INFO abajo).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es una matriz DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A de N por N.
!>          En la salida, A ha sido sobrescrita por su forma real de Schur T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder de la matriz A. LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>                         para los cuales SELECT es verdadero. (Los pares
!>                         conjugados complejos para los cuales SELECT es
!>                         verdadero para uno de los valores propios cuentan como 2.)
!>

WR

!>          WR es una matriz DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es una matriz DOUBLE PRECISION, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria, respectivamente,
!>          de los valores propios calculados en el mismo orden en que
!>          aparecen en la diagonal de la forma de Schur T de salida.
!>          Los pares de valores propios conjugados complejos aparecerán
!>          consecutivamente, con el valor propio que tiene la parte imaginaria
!>          positiva primero.
!>

VS

!>          VS es una matriz DOUBLE PRECISION, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión líder de la matriz VS. LDVS >= 1; si
!>          JOBVS = 'V', LDVS >= N.
!>

WORK

!>          WORK es una matriz DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) contiene el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión de la matriz WORK. LWORK >= max(1,3*N).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de
!>          trabajo; la rutina solo calcula el tamaño óptimo de la matriz
!>          WORK, devuelve este valor como la primera entrada de la matriz
!>          WORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

BWORK

!>          BWORK es una matriz LOGICAL, dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR no pudo calcular todos los
!>                   valores propios; los elementos 1:ILO-1 y i+1:N de WR y WI
!>                   contienen aquellos valores propios que han convergido; si
!>                   JOBVS = 'V', VS contiene la matriz que reduce A
!>                   a su forma de Schur parcialmente convergida.
!>             = N+1: los valores propios no pudieron ser reordenados porque algunos
!>                   valores propios estaban demasiado cerca para separarse (el problema
!>                   está muy mal condicionado);
!>             = N+2: después de reordenar, el error de redondeo cambió los valores de algunos
!>                   valores propios complejos de tal manera que los valores propios líderes
!>                   en la forma de Schur ya no cumplen SELECT=.TRUE. Esto
!>                   también podría ser causado por un subdesbordamiento debido al escalado.
!>

Function/Subroutine Documentation

dgees

The routines `dgees` and `dgeesx` compute the eigenvalues and Schur factorization of a general real matrix A. They also can optionally order the eigenvalues so that selected eigenvalues are on the rightmost side of the real Schur form. The corresponding Schur vectors (conceptually the Schur vectors of A) are returned in the array VS.

The Schur factorization of A is unique except for the ordering of the eigenvalues in the diagonal entries of the matrix T, and for the signs of the corresponding columns of the matrix VS, if VS is requested.

If the Schur factorization of A is A = Q T Q^T, then VS is the matrix Q that orthogonalizes A.

A general matrix A such that A = Q T Q^T, where T is an upper quasi-triangular matrix and Q is an orthogonal matrix. If A is real, then T is real. If A is complex, then T is complex (upper triangular).

The function computes the eigenvalues and optionally the Schur vectors.

The Schur vectors are the columns of the matrix VS that form an orthonormal basis for the invariant subspace corresponding to the selected eigenvalues.

dgeesx

The routine `dgeesx` computes the eigenvalues and Schur factorization of a general real matrix A, and optionally reorders the Schur factorization so that selected eigenvalues are on the rightmost side of the real Schur form. The corresponding Schur vectors are returned in the array VS.

The Schur factorization is A = VS T VS^T, where T is an upper quasi-triangular matrix and VS is an orthogonal matrix.

The eigenvalues are reordered by `dgeesx` according to the input parameter `SELECT`.

The function can also compute the condition numbers for the eigenvalues and eigenvectors.

zgees

The routines `zgees` and `zgeesx` compute the eigenvalues and Schur factorization of a general complex matrix A. They also can optionally order the eigenvalues so that selected eigenvalues are on the rightmost side of the Schur form. The corresponding Schur vectors are returned in the array VS.

The Schur factorization of A is A = Q T Q^H, where T is an upper triangular matrix and Q is a unitary matrix.

The function computes the eigenvalues and optionally the Schur vectors.

zgeesx

The routine `zgeesx` computes the eigenvalues and Schur factorization of a general complex matrix A, and optionally reorders the Schur factorization so that selected eigenvalues are on the rightmost side of the Schur form. The corresponding Schur vectors are returned in the array VS.

The Schur factorization is A = VS T VS^H, where T is an upper triangular matrix and VS is a unitary matrix.

The eigenvalues are reordered by `zgeesx` according to the input parameter `SELECT`.

The function can also compute the condition numbers for the eigenvalues and eigenvectors.
