NOMBRE

dgn_comp - Compilador de mazmorras de NetHack

SINOPSIS

dgn_comp [ archivo ]

Si no se proporcionan argumentos, lee la entrada estándar.

DESCRIPCIÓN

Dgn_comp es un compilador de mazmorras para NetHack versión 3.2 y posteriores. Toma un archivo de descripción como argumento y produce un "script" de mazmorra que será cargado por NetHack en tiempo de ejecución.

El propósito de esta herramienta es proporcionar a los administradores e implementadores de NetHack una forma conveniente de crear una mazmorra personalizada para el juego, sin tener que recompilar el mundo entero.

GRAMÁTICA

DUNGEON: nombre marcadordehuesos ( base , aleatorio ) [ %edad ]

donde nombre es el nombre de la mazmorra, marcadordehuesos es una letra para marcar los archivos de huesos, ( base , aleatorio ) es el número de niveles, y %edad es su porcentaje de probabilidad de ser generado (si está ausente, 100% de probabilidad).

DESCRIPCION: etiqueta

donde etiqueta es actualmente uno de INFIERNAL, LABERINTICO o ROGUE.

ALIGNMENT | LEVALIGN: [ legal | neutral | caotico | noalineado ]

indica la alineación de la mazmorra/nivel (el valor por defecto es no alineado).

ENTRADA: nivel

el punto de entrada de la mazmorra. La conexión de la mazmorra se adjunta en este nivel de la mazmorra dada. Si el valor de nivel es negativo, el nivel de entrada se calcula desde el final de la mazmorra, siendo -1 el último nivel. Si esta línea no está presente en una descripción de mazmorra, el nivel de entrada por defecto es 1.

PROTOFILE: nombre

el nombre prototípico de los archivos de nivel de mazmorra en esta mazmorra. Por ejemplo, el nombre del PROTOFILE para la mazmorra Torre de Vlad es torre.

NIVEL: nombre marcadordehuesos @ ( base , aleatorio ) [ %edad ]

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, ( base , aleatorio ) es la ubicación y %edad es la probabilidad de generación, como se indicó anteriormente.

NIVELALEATORIO: nombre marcadordehuesos @ ( base , aleatorio ) [ %edad ] nivelesaleatorios

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, ( base , aleatorio ) es la ubicación, %edad es la probabilidad de generación, como se indicó anteriormente, y nivelesaleatorios es el número de niveles similares disponibles para elegir.

NIVELCADENA: nombre marcadordehuesos nombre_previo + ( base , aleatorio ) [ %edad ]

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, nombre_previo es el nombre de un nivel definido previamente, ( base , aleatorio ) es el desplazamiento desde el nivel del que se está encadenando, y %edad es la probabilidad de generación.

NIVELCADENAALEATORIO: nombre marcadordehuesos nombre_previo + ( base , aleatorio ) [ %edad ] nivelesaleatorios

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, nombre_previo es el nombre de un nivel definido previamente, ( base , aleatorio ) es el desplazamiento desde el nivel del que se está encadenando, %edad es la probabilidad de generación, y nivelesaleatorios es el número de niveles similares disponibles para elegir.

DESCRIPCIONNIVEL: tipo

donde tipo es el tipo de nivel (ver DESCRIPCIÓN, arriba). El tipo se utiliza para anular cualquier valor preestablecido utilizado para describir toda la mazmorra, solo para este nivel.

RAMA: nombre @ ( base , aleatorio ) [ escalera | no_subir | no_bajar | portal ] [ subir | bajar ]

donde nombre es el nombre de la mazmorra a la que se ramifica, y ( base , aleatorio ) es la ubicación de la rama. Los dos últimos argumentos opcionales son el tipo de rama y la dirección de la rama. El tipo de una rama puede ser una conexión de escalera bidireccional, una conexión de escalera unidireccional o un portal mágico. Una escalera unidireccional se describe mediante los tipos no_subir y no_bajar, que especifican qué dirección de la escalera falta. El tipo de rama por defecto es escalera. La dirección de una escalera puede ser subir o bajar; la dirección no se aplica a los portales. La dirección por defecto es bajar.

RAMACADENA: nombre nombre_previo + ( base , aleatorio ) [ escalera | no_subir | no_bajar | portal ] [ subir | bajar ]

donde nombre es el nombre de la mazmorra a la que se ramifica, nombre_previo es el nombre de un nivel definido previamente y ( base , aleatorio ) es el desplazamiento desde el nivel del que se está encadenando. El tipo y la dirección de rama opcionales son los mismos que se describen anteriormente.

REGLAS GENÉRICAS

Cada mazmorra debe tener un marcadordehuesos único, y cada nivel especial debe tener un marcadordehuesos único dentro de su mazmorra (las letras pueden reutilizarse en diferentes mazmorras). Si el marcadordehuesos tiene el valor especial "none", no se crearán archivos de huesos para ese nivel o mazmorra.

El valor base puede estar en el rango de 1 a MAXLEVEL (tal como se define en global.h).

El valor aleatorio puede estar en el rango de -1 a MAXLEVEL.

Si aleatorio es -1, será reemplazado por el valor (num_dunlevs(mazmorra) - base) durante el proceso de carga (es decir, desde aquí hasta el final de la mazmorra).

Si aleatorio es 0, el nivel se ubica absolutamente en base.

Las ramas no tienen probabilidad. Las mazmorras sí. Si una mazmorra no se genera durante la carga, todos sus niveles y ramas se omiten.

Ningún nivel o rama puede ser encadenado desde un nivel con una probabilidad de generación porcentual. Esto es para prevenir la no resolución durante la carga. Además, ninguna rama puede hacerse desde una mazmorra con una probabilidad de generación porcentual por la misma razón.

Como regla general al usar el compilador de mazmorras:

Si una mazmorra tiene un nombre protofile asociado (p. ej., torre), se utilizará ese archivo.

Si hay un nivel especial presente, anulará la regla anterior y se cargará el archivo apropiado.

Si ninguno de los anteriores está presente, el generador estándar se hará cargo y creará un nivel "normal".

La alineación de un nivel, si está presente, anulará la alineación de la mazmorra en la que existe.

EJEMPLO

Aquí está la sintaxis actual del "lenguaje" del compilador de mazmorras:

#
#	El archivo de descripción de mazmorra para el NetHack original
#	"estándar" de la versión 3.0.
#
DUNGEON:	"The Dungeons of Doom" "D" (25, 5)
LEVEL:		"rogue" "none" @ (15, 4)
LEVEL:		"oracle" "none" @ (5, 7)
LEVEL:		"bigroom" "B" @ (12, 3) 15
LEVEL:		"medusa" "none" @ (20, 5)
CHAINLEVEL:	"castle" "medusa" + (1, 4)
CHAINBRANCH:	"Hell" "castle" + (0, 0) no_down
BRANCH:		"The Astral Plane" @ (1, 0) no_down up
DUNGEON:	"Hell" "H" (25, 5)
DESCRIPTION:	mazelike
DESCRIPTION:	hellish
BRANCH:		"Vlad's Tower" @ (13, 5) up
LEVEL:		"wizard" "none" @ (15, 10)
LEVEL:		"fakewiz" "A" @ (5, 5)
LEVEL:		"fakewiz" "B" @ (10, 5)
LEVEL:		"fakewiz" "C" @ (15, 5)
LEVEL:		"fakewiz" "D" @ (20, 5)
LEVEL:		"fakewiz" "E" @ (25, 5)
DUNGEON:	"Vlad's Tower" "T" (3, 0)
PROTOFILE:	"tower"
DESCRIPTION:	mazelike
ENTRY:		-1
DUNGEON:	"The Astral Plane" "A" (1, 0)
DESCRIPTION:	mazelike
PROTOFILE:	"endgame"

NOTAS:
Las líneas que comienzan con '#' se consideran comentarios.
Un nivel especial debe estar explícitamente alineado. La alineación de la mazmorra en la que se encuentra solo se aplica a los niveles no especiales dentro de esa mazmorra.
