DGELSY resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Documentación de la Función/Subrutina

subrutina dgelsy (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer, dimension( * ) jpvt, double precision rcond, integer rank, double precision, dimension( * ) work, integer lwork, integer info)

DGELSY resuelve sistemas sobredeterminados o subdeterminados para matrices GE

Propósito:

!>
!> DGELSY calcula la solución de norma mínima para un problema real de
!> mínimos cuadrados lineales:
!>     minimizar || A * X - B ||
!> usando una factorización ortogonal completa de A. A es una matriz
!> de M por N que puede ser deficiente en rango.
!>
!> Varios vectores de segundo miembro b y vectores de solución x pueden
!> ser manejados en una sola llamada; se almacenan como las columnas de
!> la matriz de segundo miembro B de M por NRHS y la matriz de solución
!> X de N por NRHS.
!>
!> La rutina primero calcula una factorización QR con pivoteo de columnas:
!>     A * P = Q * [ R11 R12 ]
!>                 [  0  R22 ]
!> con R11 definida como la submatriz inicial más grande cuyo número de
!> condición estimado es menor que 1/RCOND. El orden de R11, RANK,
!> es el rango efectivo de A.
!>
!> Luego, R22 se considera despreciable, y R12 se anula
!> por transformaciones ortogonales desde la derecha, llegando a la
!> factorización ortogonal completa:
!>    A * P = Q * [ T11 0 ] * Z
!>                [  0  0 ]
!> La solución de norma mínima es entonces
!>    X = P * Z**T [ inv(T11)*Q1**T*B ]
!>                 [        0         ]
!> donde Q1 consiste en las primeras RANK columnas de Q.
!>
!> Esta rutina es básicamente idéntica a la original xGELSX excepto
!> por tres diferencias:
!>   o La llamada a la subrutina xGEQPF ha sido sustituida por la
!>     llamada a la subrutina xGEQP3. Esta subrutina es una versión
!>     Blas-3 de la factorización QR con pivoteo de columnas.
!>   o La matriz B (el segundo miembro) se actualiza con Blas-3.
!>   o La permutación de la matriz B (el segundo miembro) es más rápida y
!>     más simple.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de segundos miembros, es decir, el número de
!>          columnas de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          A la entrada, la matriz A de M por N.
!>          A la salida, A ha sido sobrescrita con los detalles de su
!>          factorización ortogonal completa.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          A la entrada, la matriz de segundo miembro B de M por NRHS.
!>          A la salida, la matriz de solución X de N por NRHS.
!>          Si M = 0 o N = 0, B no es referenciada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M,N).
!>

JPVT

!>          JPVT es un array INTEGER, dimensión (N)
!>          A la entrada, si JPVT(i) .ne. 0, la i-ésima columna de A es permutada
!>          al frente de AP, de lo contrario la columna i es una columna libre.
!>          A la salida, si JPVT(i) = k, entonces la i-ésima columna de AP
!>          era la k-ésima columna de A.
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se usa para determinar el rango efectivo de A, que
!>          se define como el orden de la submatriz triangular inicial más grande
!>          R11 en la factorización QR con pivoteo de A,
!>          cuyo número de condición estimado es < 1/RCOND.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el orden de la submatriz
!>          R11. Este es el mismo que el orden de la submatriz T11
!>          en la factorización ortogonal completa de A.
!>          Si NRHS = 0, RANK = 0 en la salida.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          La estrategia sin bloqueo requiere que:
!>             LWORK >= MAX( MN+3*N+1, 2*MN+NRHS ),
!>          donde MN = min( M, N ).
!>          El algoritmo con bloqueo requiere que:
!>             LWORK >= MAX( MN+2*N+NB*(N+1), 2*MN+NB*NRHS ),
!>          donde NB es una cota superior para el tamaño de bloque devuelto
!>          por ILAENV para las rutinas DGEQP3, DTZRZF, STZRQF, DORMQR,
!>          y DORMRZ.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>
