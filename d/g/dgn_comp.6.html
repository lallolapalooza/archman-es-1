NOMBRE

dgn_comp - compilador de mazmorras de NetHack

SINOPSIS

dgn_comp [ archivo ]

Si no se proporcionan argumentos, lee la entrada estándar.

DESCRIPCIÓN

Dgn_comp es un compilador de mazmorras para NetHack versión 3.2 y superior. Toma un archivo de descripción como argumento y produce un "script" de mazmorra que será cargado por NetHack en tiempo de ejecución.

El propósito de esta herramienta es proporcionar a los administradores e implementadores de NetHack una forma conveniente de crear una mazmorra personalizada para el juego, sin tener que recompilar el mundo entero.

GRAMÁTICA

MAZMORRA: nombre marcadordehuesos ( base , aleatorio ) [ %porcentaje ]

donde nombre es el nombre de la mazmorra, marcadordehuesos es una letra para marcar los archivos de huesos, ( base , aleatorio ) es el número de niveles, y %porcentaje es su probabilidad de generación (si está ausente, probabilidad del 100%).

DESCRIPCIÓN: etiqueta

donde etiqueta es actualmente uno de INFIERNAL, LABERÍNTICA, o ROGUELLICA.

ALINEAMIENTO | ALINEAMIENTO_NIVEL: [ legal | neutral | caótico | no_alineado ]

indica la alineación de la mazmorra/nivel (el valor por defecto es no alineado).

ENTRADA: nivel

el punto de entrada de la mazmorra. La conexión de la mazmorra se adjunta en este nivel de la mazmorra dada. Si el valor de nivel es negativo, el nivel de entrada se calcula desde el fondo de la mazmorra, con -1 siendo el último nivel. Si esta línea no está presente en una descripción de mazmorra, el nivel de entrada por defecto es 1.

ARCHIVOPROTO: nombre

el nombre prototípico para los archivos de nivel de mazmorra en esta mazmorra. Por ejemplo, el nombre de ARCHIVOPROTO para la mazmorra Torre de Vlad es torre.

NIVEL: nombre marcadordehuesos @ ( base , aleatorio ) [ %porcentaje ]

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, ( base , aleatorio ) es la ubicación y %porcentaje es la probabilidad de generación, como arriba.

NIVELALEATORIO: nombre marcadordehuesos @ ( base , aleatorio ) [ %porcentaje ] num_niveles_aleatorios

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, ( base , aleatorio ) es la ubicación, %porcentaje es la probabilidad de generación, como arriba, y num_niveles_aleatorios es el número de niveles similares disponibles para elegir.

NIVELENCADENADO: nombre marcadordehuesos nombre_anterior + ( base , aleatorio ) [ %porcentaje ]

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, nombre_anterior es el nombre de un nivel definido previamente, ( base , aleatorio ) es el desplazamiento desde el nivel del que se está encadenando, y %porcentaje es la probabilidad de generación.

NIVELENCADENADOALEATORIO: nombre marcadordehuesos nombre_anterior + ( base , aleatorio ) [ %porcentaje ] num_niveles_aleatorios

donde nombre es el nombre del nivel, marcadordehuesos es una letra para marcar los archivos de huesos, nombre_anterior es el nombre de un nivel definido previamente, ( base , aleatorio ) es el desplazamiento desde el nivel del que se está encadenando, %porcentaje es la probabilidad de generación, y num_niveles_aleatorios es el número de niveles similares disponibles para elegir.

DESC_NIVEL: tipo

donde tipo es el tipo de nivel (ver DESCRIPCIÓN, arriba). El tipo se utiliza para anular cualquier valor preestablecido utilizado para describir toda la mazmorra, solo para este nivel.

RAMA: nombre @ ( base , aleatorio ) [ escalera | no_subir | no_bajar | portal ] [ subir | bajar ]

donde nombre es el nombre de la mazmorra a la que ramifica, y ( base , aleatorio ) es la ubicación de la rama. Los dos últimos argumentos opcionales son el tipo de rama y la dirección de la rama. El tipo de una rama puede ser una conexión de escaleras bidireccional, una conexión de escaleras unidireccional o un portal mágico. Una escalera unidireccional se describe mediante los tipos no_subir y no_bajar, que especifican qué dirección de escalera falta. El tipo de rama por defecto es escalera. La dirección de una escalera puede ser hacia arriba o hacia abajo; la dirección no es aplicable a los portales. La dirección por defecto es bajar.

RAMAENCADENADA: nombre nombre_anterior + ( base , aleatorio ) [ escalera | no_subir | no_bajar | portal ] [ subir | bajar ]

donde nombre es el nombre de la mazmorra a la que ramifica, nombre_anterior es el nombre de un nivel definido previamente y ( base , aleatorio ) es el desplazamiento desde el nivel del que se está encadenando. El tipo y la dirección de rama opcionales son los mismos que se describen anteriormente.

REGLAS GENÉRICAS

Cada mazmorra debe tener un marcadordehuesos único, y cada nivel especial debe tener un marcadordehuesos único dentro de su mazmorra (las letras pueden reutilizarse en diferentes mazmorras). Si el marcadordehuesos tiene el valor especial "ninguno", no se crearán archivos de huesos para ese nivel o mazmorra.

El valor base puede estar en el rango de 1 a MAXNIVEL (definido en global.h).

El valor aleatorio puede estar en el rango de -1 a MAXNIVEL.

Si aleatorio es -1, será reemplazado por el valor (num_niveles_mazmorra(mazmorra) - base) durante el proceso de carga (es decir, desde aquí hasta el final de la mazmorra).

Si aleatorio es 0, el nivel se ubica absolutamente en base.

Las ramas no tienen probabilidad. Las mazmorras sí. Si una mazmorra no se genera durante la carga, todos sus niveles y ramas se omiten.

Ningún nivel o rama puede ser encadenado desde un nivel con una probabilidad de generación porcentual. Esto es para prevenir la no resolución durante la carga. Además, ninguna rama puede hacerse desde una mazmorra con una probabilidad de generación porcentual por la misma razón.

Como regla general al usar el compilador de mazmorras:

Si una mazmorra tiene un nombre de archivoproto asociado (p. ej. torre), se usará ese archivo.

Si está presente un nivel especial, anulará la regla anterior y se cargará el archivo apropiado.

Si no están presentes ninguno de los anteriores, el generador estándar se encargará y creará un nivel "normal".

La alineación de un nivel, si está presente, anulará la alineación de la mazmorra en la que existe.

EJEMPLO

Aquí está la sintaxis actual del "lenguaje" del compilador de mazmorras:

#
#	El archivo de descripción de la mazmorra para el NetHack original
#	estándar de la versión 3.0.
#
MAZMORRA:	"Las Mazmorras de la Perdición" "D" (25, 5)
NIVEL:		"rogue" "ninguno" @ (15, 4)
NIVEL:		"oracle" "ninguno" @ (5, 7)
NIVEL:		"bigroom" "B" @ (12, 3) 15
NIVEL:		"medusa" "ninguno" @ (20, 5)
NIVELENCADENADO:	"castle" "medusa" + (1, 4)
RAMAENCADENADA:	"Hell" "castle" + (0, 0) no_bajar
RAMA:		"El Plano Astral" @ (1, 0) no_bajar subir
MAZMORRA:	"Hell" "H" (25, 5)
DESCRIPCIÓN:	laberíntica
DESCRIPCIÓN:	infernal
RAMA:		"Torre de Vlad" @ (13, 5) subir
NIVEL:		"wizard" "ninguno" @ (15, 10)
NIVEL:		"fakewiz" "A" @ (5, 5)
NIVEL:		"fakewiz" "B" @ (10, 5)
NIVEL:		"fakewiz" "C" @ (15, 5)
NIVEL:		"fakewiz" "D" @ (20, 5)
NIVEL:		"fakewiz" "E" @ (25, 5)
MAZMORRA:	"Torre de Vlad" "T" (3, 0)
ARCHIVOPROTO:	"torre"
DESCRIPCIÓN:	laberíntica
ENTRADA:		-1
MAZMORRA:	"El Plano Astral" "A" (1, 0)
DESCRIPCIÓN:	laberíntica
ARCHIVOPROTO:	"endgame"

NOTAS:
Las líneas que comienzan con '#' se consideran comentarios.
Un nivel especial debe estar explícitamente alineado. La alineación de la mazmorra en la que se encuentra solo se aplica a los niveles no especiales dentro de esa mazmorra.
