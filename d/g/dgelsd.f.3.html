Documentación de Función/Subrutina

subrutina dgelsd (integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) s, double precision rcond, integer rank, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DGELSD calcula la solución de norma mínima a un problema de mínimos cuadrados lineales para matrices GE

Propósito:

!>
!> DGELSD calcula la solución de norma mínima a un problema real de
!> mínimos cuadrados lineales:
!>     minimizar 2-norma(| b - A*x |)
!> usando la descomposición en valores singulares (SVD) de A. A es una
!> matriz M-por-N que puede ser deficiente en rango.
!>
!> Varios vectores de segundo miembro b y vectores solución x pueden
!> ser tratados en una sola llamada; se almacenan como las columnas de
!> la matriz de segundo miembro B de M-por-NRHS y la matriz de solución
!> X de N-por-NRHS.
!>
!> El problema se resuelve en tres pasos:
!> (1) Reducir la matriz de coeficientes A a forma bidiagonal con
!>     transformaciones de Householder, reduciendo el problema original
!>     a un (BLS)
!> (2) Resolver el BLS usando un enfoque de divide y vencerás.
!> (3) Aplicar todas las transformaciones de Householder para resolver
!>     el problema original de mínimos cuadrados.
!>
!> El rango efectivo de A se determina tratando como cero aquellos
!> valores singulares que son menores que RCOND veces el mayor valor
!> singular.
!>
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de A. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de segundos miembros, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          A la entrada, la matriz A de M-por-N.
!>          A la salida, A ha sido destruida.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          A la entrada, la matriz de segundo miembro B de M-por-NRHS.
!>          A la salida, B es sobrescrita por la matriz de solución X
!>          de N-por-NRHS.  Si m >= n y RANK = n, el residuo de suma de
!>          cuadrados para la solución en la i-ésima columna es dado
!>          por la suma de cuadrados de los elementos n+1:m en esa columna.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,max(M,N)).
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (min(M,N))
!>          Los valores singulares de A en orden decreciente.
!>          El número de condición de A en la 2-norma = S(1)/S(min(m,n)).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          RCOND se usa para determinar el rango efectivo de A.
!>          Los valores singulares S(i) <= RCOND*S(1) se tratan como cero.
!>          Si RCOND < 0, se usa la precisión de la máquina en su lugar.
!>

RANK

!>          RANK es INTEGER
!>          El rango efectivo de A, es decir, el número de valores singulares
!>          que son mayores que RCOND*S(1).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK debe ser al menos 1.
!>          La cantidad exacta mínima de espacio de trabajo necesaria depende de M,
!>          N y NRHS. Siempre que LWORK sea al menos
!>              12*N + 2*N*SMLSIZ + 8*N*NLVL + N*NRHS + (SMLSIZ+1)**2,
!>          si M es mayor o igual que N, o
!>              12*M + 2*M*SMLSIZ + 8*M*NLVL + M*NRHS + (SMLSIZ+1)**2,
!>          si M es menor que N, el código se ejecutará correctamente.
!>          SMLSIZ es devuelto por ILAENV y es igual al tamaño máximo
!>          de los subproblemas en la parte inferior del árbol de cálculo
!>          (usualmente alrededor de 25), y
!>             NLVL = MAX( 0, INT( LOG_2( MIN( M,N )/(SMLSIZ+1) ) ) + 1 )
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          LIWORK >= max(1, 3 * MINMN * NLVL + 11 * MINMN),
!>          donde MINMN = MIN( M,N ).
!>          A la salida, si INFO = 0, IWORK(1) devuelve el LIWORK mínimo.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  el algoritmo para calcular el SVD falló en converger;
!>                si INFO = i, i elementos fuera de la diagonal de una forma
!>                bidiagonal intermedia no convergieron a cero.
!>
