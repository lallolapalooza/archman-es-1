DGSVJ

0

preprocesador para la rutina

dgesvj.

Propósito

: 
!>
!> DGSVJ0 se llama desde DGESVJ como un preprocesador y ese es su propósito
!> principal. Aplica rotaciones de Jacobi de la misma manera que DGESVJ, pero
!> no comprueba la convergencia (criterio de parada). Hay disponibles algunos
!> parámetros de ajuste (marcados con [TP]) para el implementador.
!
>

Parámetro

s
JOBV 
!>          JOBV es CHARACTER*1
!>          Especifica si la salida de este procedimiento se utiliza
!>          para calcular la matriz V:
!>          = 'V': el producto de las rotaciones de Jacobi se acumula
!>                 postmultiplicando el array V de N por N.
!>                (Véase la descripción de V.)
!>          = 'A': el producto de las rotaciones de Jacobi se acumula
!>                 postmultiplicando el array V de MV por N.
!>                (Véanse las descripciones de MV y V.)
!>          = 'N': las rotaciones de Jacobi no se acumulan.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.
!>          M >= N >= 0.
!
>

A 
!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N, tal que A*diag(D) representa
!>          la matriz de entrada.
!>          En la salida,
!>          A_onexit * D_onexit representa la matriz de entrada A*diag(D)
!>          post-multiplicada por una secuencia de rotaciones de Jacobi, donde el
!>          umbral de rotación y el número total de barridos se dan en
!>          TOL y NSWEEP, respectivamente.
!>          (Véanse las descripciones de D, TOL y NSWEEP.)
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!
>

D 
!>          D es un array de DOUBLE PRECISION, dimensión (N)
!>          El array D acumula los factores de escala de las rotaciones
!>          de Jacobi escaladas rápidas.
!>          En la entrada, A*diag(D) representa la matriz de entrada.
!>          En la salida, A_onexit*diag(D_onexit) representa la matriz de
!>          entrada post-multiplicada por una secuencia de rotaciones de
!>          Jacobi, donde el umbral de rotación y el número total de
!>          barridos se dan en TOL y NSWEEP, respectivamente.
!>          (Véanse las descripciones de A, TOL y NSWEEP.)
!
>

SV

A 
!>          SVA es un array de DOUBLE PRECISION, dimensión (N)
!>          En la entrada, SVA contiene las normas euclidianas de las columnas de
!>          la matriz A*diag(D).
!>          En la salida, SVA contiene las normas euclidianas de las columnas de
!>          la matriz onexit*diag(D_onexit).
!
>

M

V 
!>          MV es INTEGER
!>          Si JOBV = 'A', entonces MV filas de V se post-multiplican por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces MV no se referencia.
!
>

V 
!>          V es un array de DOUBLE PRECISION, dimensión (LDV,N)
!>          Si JOBV = 'V' entonces N filas de V se post-multiplican por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'A' entonces MV filas de V se post-multiplican por una
!>                           secuencia de rotaciones de Jacobi.
!>          Si JOBV = 'N',   entonces V no se referencia.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del array V,  LDV >= 1.
!>          Si JOBV = 'V', LDV >= N.
!>          Si JOBV = 'A', LDV >= MV.
!
>

EP

S 
!>          EPS es DOUBLE PRECISION
!>          EPS = DLAMCH('Epsilon')
!
>

SFMI

N 
!>          SFMIN es DOUBLE PRECISION
!>          SFMIN = DLAMCH('Safe Minimum')
!
>

TO

L 
!>          TOL es DOUBLE PRECISION
!>          TOL es el umbral para las rotaciones de Jacobi. Para un par
!>          A(:,p), A(:,q) de columnas pivote, la rotación de Jacobi se
!>          aplica solo si DABS(COS(angle(A(:,p),A(:,q)))) > TOL.
!>
NSWEEP

!> NSWEEP es INTEGER !> NSWEEP es el número de barridos de rotaciones de Jacobi a !>

realizar. !> 
WOR
K

!> WORK es un array de DOUBLE PRECISION, dimensión

(LWORK) !> 
LWOR
K

!> LWORK es INTEGER !> LWORK es la dimensión de WORK.

LWORK >= M. !> 
INF
O

!> INFO es INTEGER !> = 0: salida exitosa. !> < 0: si INFO = -i, entonces el i-ésimo

argumento tenía un valor ilegal !>
