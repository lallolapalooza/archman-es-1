Documentación de Función/Subrutina

subroutine dgesvx (character fact, character trans, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGESVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GE

Propósito:

!>
!> DGESVX utiliza la factorización LU para calcular la solución a un sistema
!> de ecuaciones lineales real:
!>    A * X = B,
!> donde A es una matriz N por N y X y B son matrices N por NRHS.
!>
!> También se proporcionan cotas de error en la solución y una estimación de
!> la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para
!>    equilibrar el sistema:
!>       TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>       TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>       TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe con
!>    diag(R)*A*diag(C) y B con diag(R)*B (si TRANS='N') o diag(C)*B
!>    (si TRANS = 'T' o 'C').
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición LU para factorizar
!>    la matriz A (después del equilibrado si FACT = 'E') como:
!>       A = P * L * U,
!>    donde P es una matriz de permutación, L es una matriz triangular inferior
!>    unitaria y U es triangular superior.
!>
!> 3. Si algún U(i,i)=0, de modo que U es exactamente singular, la rutina
!>    devuelve INFO = i. De lo contrario, la forma factorizada de A se
!>    utiliza para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de máquina,
!>    se devuelve INFO = N+1 como advertencia, pero la rutina continúa
!>    resolviendo para X y calculando cotas de error como se describe a
!>    continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>
!> 6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(C) (si TRANS = 'N') o diag(R) (si TRANS = 'T' o 'C') para
!>    que resuelva el sistema original antes del equilibrado.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          proporciona en la entrada, y si no, si la matriz A debe
!>          equilibrarse antes de factorizarse.
!>          = 'F':  En la entrada, AF y IPIV contienen la forma factorizada de A.
!>                  Si EQUED no es 'N', la matriz A ha sido
!>                  equilibrada con factores de escala dados por R y C.
!>                  A, AF e IPIV no se modifican.
!>          = 'N':  La matriz A se copiará en AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará en AF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta)
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimension (LDA,N)
!>          En la entrada, la matriz A de N por N. Si FACT = 'F' y EQUED
!>          no es 'N', entonces A ha sido equilibrada con los factores
!>          de escala en R y/o C. A no se modifica si FACT = 'F' o
!>          'N', o si FACT = 'E' y EQUED = 'N' en la salida.
!>
!>          En la salida, si EQUED .ne. 'N', A se escala de la siguiente manera:
!>          EQUED = 'R':  A := diag(R) * A
!>          EQUED = 'C':  A := A * diag(C)
!>          EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es un array DOUBLE PRECISION, dimension (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la
!>          entrada contiene los factores L y U de la factorización
!>          A = P*L*U calculada por DGETRF. Si EQUED .ne. 'N', entonces
!>          AF es la forma factorizada de la matriz A equilibrada.
!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la
!>          salida devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces AF es un argumento de salida y en la
!>          salida devuelve los factores L y U de la factorización A = P*L*U
!>          de la matriz A equilibrada (ver la descripción de A para
!>          la forma de la matriz equilibrada).
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV es un array INTEGER, dimension (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en la
!>          entrada contiene los índices de pivote de la factorización A = P*L*U
!>          calculada por DGETRF; la fila i de la matriz se intercambió
!>          con la fila IPIV(i).
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en la
!>          salida contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz original A.
!>
!>          Si FACT = 'E', entonces IPIV es un argumento de salida y en la
!>          salida contiene los índices de pivote de la factorización A = P*L*U
!>          de la matriz A equilibrada.
!>

EQUED

!>          EQUED es CHARACTER*1
!>          Especifica la forma de equilibrado que se realizó.
!>          = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>          = 'R':  Equilibrado de filas, es decir, A se ha premultiplicado por
!>                  diag(R).
!>          = 'C':  Equilibrado de columnas, es decir, A se ha postmultiplicado
!>                  por diag(C).
!>          = 'B':  Equilibrado tanto de filas como de columnas, es decir, A ha sido
!>                  reemplazado por diag(R) * A * diag(C).
!>          EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>          argumento de salida.
!>
!>          Si FACT = 'N' o 'E', EQUED es un argumento de salida.
!>

R

!>          R es un array DOUBLE PRECISION, dimension (*)
!>          Si EQUED = 'R' o 'B', R es un array de dimension N que contiene
!>          los factores de escala de fila utilizados para equilibrar la matriz A.
!>          Si EQUED = 'N' o 'C', R no se utiliza.
!>

C

!>          C es un array DOUBLE PRECISION, dimension (*)
!>          Si EQUED = 'C' o 'B', C es un array de dimension N que contiene
!>          los factores de escala de columna utilizados para equilibrar la matriz A.
!>          Si EQUED = 'N' o 'R', C no se utiliza.
!>

B

!>          B es un array DOUBLE PRECISION, dimension (LDB,NRHS)
!>          En la entrada, la matriz N-por-NRHS de lados derechos.
!>          En la salida, si EQUED = 'R' o 'B', B se ha escalado por
!>          diag(R), es decir, B := diag(R)*B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimension (LDX,NRHS)
!>          En la salida, el resultado N-por-NRHS de la solución del sistema.
!>          Si EQUED = 'C' o 'B', X se premultiplica por diag(C) (si TRANS = 'N')
!>          o diag(R) (si TRANS = 'T' o 'C') para que resuelva el sistema
!>          original sin equilibrar.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          En la salida, una estimación del recíproco del número de condición
!>          de la matriz A, calculada antes de la sustitución o
!>          refinamiento iterativo.  Si RCOND está cerca de la máquina
!>          en el límite inferior, la matriz A está cerca de ser singular.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimension (*)
!>          En la salida, un array de dimension NRHS.  FERR(J) estima el
!>          error hacia atrás relativo en la solución X(:,J), el número
!>          más pequeño que aumenta para hacer que la entrada sea
!>          una solución de A*X = B.
!>          Si EQUED = 'N', FERR(J) es una cota superior para la norma
!>          relativa del residuo.
!>          Si EQUED = 'R', 'C', o 'B', FERR(J) es una cota superior para
!>          el error hacia atrás relativo de la solución del sistema
!>          equilibrado.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimension (*)
!>          En la salida, un array de dimension NRHS.  BERR(J) estima el
!>          error hacia adelante relativo en la solución X(:,J).
!>          BERR(J) = norm(abs(X(:,J)-XTRUE(:,J)))/norm(X(:,J))
!>          donde XTRUE es la solución exacta. No se pueden calcular cotas
!>          exactas para BERR(J).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimension (LWORK)
!>          En la salida, la longitud del array WORK requerida para la
!>          exitosa operación de la rutina es la primera entrada, WORK(1).
!>

LWORK

!>          LWORK es INTEGER
!>          La longitud del array WORK. LWORK >= N + N*NB, donde NB es el
!>          tamaño de bloque óptimo de la rutina DGELQF.
!>          Si LWORK = -1, entonces solo se calcula la longitud requerida
!>          para WORK y se devuelve en WORK(1).
!>

IWORK

!>          IWORK es un array INTEGER, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          Si INFO = 0, la ejecución ha sido exitosa.
!>          Si INFO < 0, se ha producido un error en el argumento de entrada
!>          número -INFO.
!>          Si INFO > 0 y INFO <= N, la matriz U es singular y su diagonal
!>          el número U(INFO,INFO) es cero. La factorización ha sido
!>          completada pero no se puede continuar.
!>          Si INFO = N+1, el recíproco del número de condición de la
!>          matriz es menor que la precisión de máquina. La matriz está
!>          cerca de ser singular. La ejecución ha continuado pero la
!>          solución puede no ser fiable.
!>

R 
!>          R es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala de fila para A.  Si EQUED = 'R' o 'B', A es
!>          multiplicado por la izquierda por diag(R); si EQUED = 'N' o 'C', R
!>          no es accedido.  R es un argumento de entrada si FACT = 'F';
!>          de lo contrario, R es un argumento de salida.  Si FACT = 'F' y
!>          EQUED = 'R' o 'B', cada elemento de R debe ser positivo.
!
>

C 
!>          C es un arreglo DOUBLE PRECISION, dimensión (N)
!>          Los factores de escala de columna para A.  Si EQUED = 'C' o 'B', A es
!>          multiplicado por la derecha por diag(C); si EQUED = 'N' o 'R', C
!>          no es accedido.  C es un argumento de entrada si FACT = 'F';
!>          de lo contrario, C es un argumento de salida.  Si FACT = 'F' y
!>          EQUED = 'C' o 'B', cada elemento de C debe ser positivo.
!
>

B 
!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B de tamaño N-por-NRHS.
!>          En la salida,
!>          si EQUED = 'N', B no es modificado;
!>          si TRANS = 'N' y EQUED = 'R' o 'B', B es sobrescrito por
!>          diag(R)*B;
!>          si TRANS = 'T' o 'C' y EQUED = 'C' o 'B', B es
!>          sobrescrito por diag(C)*B.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

X 
!>          X es un arreglo DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz de solución X de tamaño N-por-NRHS
!>          al sistema original de ecuaciones.  Note que A y B son
!>          modificados en la salida si EQUED .ne. 'N', y la solución al
!>          sistema equilibrado es inv(diag(C))*X si TRANS = 'N' y
!>          EQUED = 'C' o 'B', o inv(diag(R))*X si TRANS = 'T' o 'C'
!>          y EQUED = 'R' o 'B'.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!
>

RCON

D 
!>          RCOND es DOUBLE PRECISION
!>          La estimación del número de condición recíproco de la matriz
!>          A después del equilibrado (si se hizo).  Si RCOND es menor que la
!>          precisión de la máquina (en particular, si RCOND = 0), la matriz
!>          es singular a la precisión de trabajo.  Esta condición es
!>          indicada por un código de retorno de INFO > 0.
!
>

FER

R 
!>          FERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          La estimación del límite de error hacia adelante para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una estimación del límite superior para la magnitud del elemento
!>          más grande en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan confiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!
>

BER

R 
!>          BERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector de
!>          solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,4*N))
!>          En la salida, WORK(1) contiene el factor de crecimiento del pivote
!>          recíproco norm(A)/norm(U). Se usa la norma
!>          . Si WORK(1) es mucho menor que 1, entonces la estabilidad
!>          de la factorización LU de la matriz A (equilibrada) podría ser
!>          pobre. Esto también significa que la solución X, el estimador de
!>          condición RCOND, y el límite de error hacia adelante FERR podrían ser
!>          poco confiables. Si la factorización falla con 0<INFO<=N, entonces
!>          WORK(1) contiene el factor de crecimiento del pivote recíproco para
!>          las primeras INFO columnas de A.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (N)
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero.  La factorización ha
!>                       sido completada, pero el factor U es exactamente
!>                       singular, por lo que la solución y los límites de error
!>                       no pudieron ser calculados. Se devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       a la precisión de trabajo.  Sin embargo, la
!>                       solución y los límites de error son calculados porque
!>                       hay una serie de situaciones donde la
!>                       solución calculada puede ser más precisa que el
!>                       valor de RCOND sugeriría.
!>
