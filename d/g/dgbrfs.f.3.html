Documentación de Función/Subrutina

subrutina dgbrfs (character trans, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGBRFS

Propósito:

!>
!> DGBRFS mejora la solución calculada de un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es banda, y proporciona
!> límites de error y estimaciones de error hacia atrás para la solución.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transponer)
!>          = 'T':  A**T * X = B  (Transponer)
!>          = 'C':  A**H * X = B  (Transponer con conjugado = Transponer)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KL

!>          KL es INTEGER
!>          El número de subdiagonales dentro de la banda de A.  KL >= 0.
!>

KU

!>          KU es INTEGER
!>          El número de superdiagonales dentro de la banda de A.  KU >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de miembros derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es un array DOUBLE PRECISION, dimensión (LDAB,N)
!>          La matriz de banda original A, almacenada en las filas 1 a KL+KU+1.
!>          La j-ésima columna de A se almacena en la j-ésima columna del
!>          array AB de la siguiente manera:
!>          AB(ku+1+i-j,j) = A(i,j) para max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB es un array DOUBLE PRECISION, dimensión (LDAFB,N)
!>          Detalles de la factorización LU de la matriz de banda A, tal como
!>          fue calculada por DGBTRF.  U se almacena como una matriz de banda
!>          triangular superior con KL+KU superdiagonales en las filas 1 a KL+KU+1, y
!>          los multiplicadores usados durante la factorización se almacenan en
!>          las filas KL+KU+2 a 2*KL+KU+1.
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB.  LDAFB >= 2*KL*KU+1.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote de DGBTRF; para 1<=i<=N, la fila i de la
!>          matriz fue intercambiada con la fila IPIV(i).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz de miembros derechos B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          En la entrada, la matriz de solución X, tal como fue calculada por DGBTRS.
!>          En la salida, la matriz de solución X mejorada.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El límite estimado de error hacia adelante para cada vector de solución
!>          X(j) (la j-ésima columna de la matriz de solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del
!>          elemento más grande en X(j).  La estimación es tan confiable como
!>          la estimación para RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error relativo hacia atrás componente a componente de cada vector
!>          de solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (3*N)
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>
