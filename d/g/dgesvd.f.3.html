subrutina dgesvd (jobu, jobvt, m, n, a, lda, s, u, ldu, vt, ldvt, work, lwork, info)
DGESVD calcula la descomposición en valores singulares (SVD) para matrices GE

Documentación de Función/Subrutina

subrutina dgesvd (character jobu, character jobvt, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision, dimension( ldu, * ) u, integer ldu, double precision, dimension( ldvt, * ) vt, integer ldvt, double precision, dimension( * ) work, integer lwork, integer info)

DGESVD calcula la descomposición en valores singulares (SVD) para matrices GE

Propósito:

!>
!> DGESVD calcula la descomposición en valores singulares (SVD) de una
!> matriz real M-por-N A, calculando opcionalmente los vectores singulares
!> izquierdos y/o derechos. La SVD se escribe
!>
!>      A = U * SIGMA * transpuesta(V)
!>
!> donde SIGMA es una matriz M-por-N que es cero excepto por sus
!> min(m,n) elementos diagonales, U es una matriz ortogonal M-por-M, y
!> V es una matriz ortogonal N-por-N. Los elementos diagonales de SIGMA
!> son los valores singulares de A; son reales y no negativos, y
!> se devuelven en orden descendente. Las primeras min(m,n) columnas de
!> U y V son los vectores singulares izquierdos y derechos de A.
!>
!> Tenga en cuenta que la rutina devuelve V**T, no V.
!>

Parámetros

JOBU 
!>          JOBU es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz U:
!>          = 'A':  se devuelven todas las M columnas de U en el array U:
!>          = 'S':  se devuelven las primeras min(m,n) columnas de U (los vectores
!>                  singulares izquierdos) en el array U;
!>          = 'O':  las primeras min(m,n) columnas de U (los vectores
!>                  singulares izquierdos) se sobrescriben en el array A;
!>          = 'N':  no se calculan columnas de U (ningún vector
!>                  singular izquierdo).
!>

JOBVT

!>          JOBVT es CHARACTER*1
!>          Especifica opciones para calcular toda o parte de la matriz
!>          V**T:
!>          = 'A':  se devuelven todas las N filas de V**T en el array VT;
!>          = 'S':  se devuelven las primeras min(m,n) filas de V**T (los vectores
!>                  singulares derechos) en el array VT;
!>          = 'O':  las primeras min(m,n) filas de V**T (los vectores
!>                  singulares derechos) se sobrescriben en el array A;
!>          = 'N':  no se calculan filas de V**T (ningún vector
!>                  singular derecho).
!>
!>          JOBVT y JOBU no pueden ser ambos 'O'.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz de entrada A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz de entrada A.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz M-por-N A.
!>          En la salida,
!>          si JOBU = 'O',  A se sobrescribe con las primeras min(m,n)
!>                          columnas de U (los vectores singulares
!>                          izquierdos, almacenados por columnas);
!>          si JOBVT = 'O', A se sobrescribe con las primeras min(m,n)
!>                          filas de V**T (los vectores singulares
!>                          derechos, almacenados por filas);
!>          si JOBU .ne. 'O' y JOBVT .ne. 'O', el contenido de A
!>                          se destruye.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (min(M,N))
!>          Los valores singulares de A, ordenados de modo que S(i) >= S(i+1).
!>

U

!>          U es un array DOUBLE PRECISION, dimensión (LDU,UCOL)
!>          (LDU,M) si JOBU = 'A' o (LDU,min(M,N)) si JOBU = 'S'.
!>          Si JOBU = 'A', U contiene la matriz ortogonal M-por-M U;
!>          si JOBU = 'S', U contiene las primeras min(m,n) columnas de U
!>          (los vectores singulares izquierdos, almacenados por columnas);
!>          si JOBU = 'N' o 'O', U no se referencia.
!>

LDU

!>          LDU es INTEGER
!>          La dimensión principal del array U.  LDU >= 1; si
!>          JOBU = 'S' o 'A', LDU >= M.
!>

VT

!>          VT es un array DOUBLE PRECISION, dimensión (LDVT,N)
!>          Si JOBVT = 'A', VT contiene la matriz ortogonal N-por-N
!>          V**T;
!>          si JOBVT = 'S', VT contiene las primeras min(m,n) filas de
!>          V**T (los vectores singulares derechos, almacenados por filas);
!>          si JOBVT = 'N' o 'O', VT no se referencia.
!>

LDVT

!>          LDVT es INTEGER
!>          La dimensión principal del array VT.  LDVT >= 1; si
!>          JOBVT = 'A', LDVT >= N; si JOBVT = 'S', LDVT >= min(M,N).
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo;
!>          si INFO > 0, WORK(2:MIN(M,N)) contiene los elementos
!>          superdiagonales no convergidos de una matriz bidiagonal
!>          superior B cuya diagonal está en S (no necesariamente
!>          ordenada). B satisface A = U * B * VT, por lo que tiene los
!>          mismos valores singulares que A, y vectores singulares
!>          relacionados por U y VT.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          LWORK >= MAX(1,5*MIN(M,N)) para las rutas (ver comentarios dentro del código):
!>             - RUTA 1  (M mucho mayor que N, JOBU='N')
!>             - RUTA 1t (N mucho mayor que M, JOBVT='N')
!>          LWORK >= MAX(1,3*MIN(M,N) + MAX(M,N),5*MIN(M,N)) para las otras rutas
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si DBDSQR no convergió, INFO especifica cuántas
!>                superdiagonales de una forma bidiagonal intermedia B
!>                no convergieron a cero. Vea la descripción de WORK
!>                arriba para más detalles.
!>
