subrutina dgetc2 (n, a, lda, ipiv, jpiv, info)
DGETC2 calcula la factorización LU con pivoteo completo de la matriz general n-por-n.

Documentación de función/subrutina

subrutina dgetc2 (integer n, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, integer, dimension( * ) jpiv, integer info)

DGETC2 calcula la factorización LU con pivoteo completo de la matriz general n-por-n.

Propósito:

!>
!> DGETC2 calcula una factorización LU con pivoteo completo de la
!> matriz A de n-por-n. La factorización tiene la forma A = P * L * U * Q,
!> donde P y Q son matrices de permutación, L es triangular inferior con
!> elementos diagonales unitarios y U es triangular superior.
!>
!> Este es el algoritmo BLAS de Nivel 2.
!>

Parámetros

N 
!>          N es un ENTERO
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un array de DOBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz A de n-por-n a factorizar.
!>          En la salida, los factores L y U de la factorización
!>          A = P*L*U*Q; los elementos diagonales unitarios de L no se almacenan.
!>          Si U(k, k) parece ser menor que SMIN, U(k, k) recibe el
!>          valor de SMIN, es decir, se da un sistema perturbado no singular.
!>

LDA

!>          LDA es un ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

IPIV

!>          IPIV es un array de ENTEROS, dimensión(N).
!>          Los índices de pivote; para 1 <= i <= N, la fila i de la
!>          matriz ha sido intercambiada con la fila IPIV(i).
!>

JPIV

!>          JPIV es un array de ENTEROS, dimensión(N).
!>          Los índices de pivote; para 1 <= j <= N, la columna j de la
!>          matriz ha sido intercambiada con la columna JPIV(j).
!>

INFO

!>          INFO es un ENTERO
!>           = 0: salida exitosa
!>           > 0: si INFO = k, U(k, k) probablemente causará desbordamiento si
!>                intentamos resolver para x en Ax = b. Por lo tanto, U se perturba para
!>                evitar el desbordamiento.
!>
