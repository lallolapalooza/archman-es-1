subrutina dgges (character jobvsl, character jobvsr, character sort, external selctg, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, integer sdim, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvsl, * ) vsl, integer ldvsl, double precision, dimension( ldvsr, * ) vsr, integer ldvsr, double precision, dimension( * ) work, integer lwork, logical, dimension( * ) bwork, integer info)

DGGES calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> DGGES calcula para un par de matrices reales no simétricas (A,B) de N por N,
!> los valores propios generalizados, la forma de Schur generalizada (S,T),
!> opcionalmente, las matrices izquierda y/o derecha de vectores de Schur (VSL y
!> VSR). Esto da la factorización de Schur generalizada
!>
!>          (A,B) = ( (VSL)*S*(VSR)**T, (VSL)*T*(VSR)**T )
!>
!> Opcionalmente, también ordena los valores propios de modo que un clúster
!> seleccionado de valores propios aparezca en los bloques de diagonal
!> principales de la matriz cuasi-triangular superior S y la matriz triangular
!> superior T. Las columnas principales de VSL y VSR forman entonces una base
!> ortonormal para los correspondientes subespacios (deflactantes) izquierdos y
!> derechos.
!>
!> (Si sólo se necesitan los valores propios generalizados, utilice el controlador
!> DGGEV en su lugar, que es más rápido).
!>
!> Un valor propio generalizado para un par de matrices (A,B) es un escalar w
!> o una razón alpha/beta = w, tal que A - w*B es singular. Normalmente se
!> representa como el par (alpha,beta), ya que hay una interpretación razonable
!> para beta=0 o ambos siendo cero.
!>
!> Un par de matrices (S,T) está en forma de Schur generalizada real si T es
!> triangular superior con diagonal no negativa y S es bloque triangular superior
!> con bloques de 1x1 y 2x2. Los bloques de 1x1 corresponden a valores propios
!> generalizados reales, mientras que los bloques de 2x2 de S serán
!> formando los elementos correspondientes de T de la forma:
!>         [  a  0  ]
!>         [  0  b  ]
!>
!> y el par de bloques de 2x2 correspondientes en S y T tendrá un par
!> de valores propios generalizados complejos conjugados.
!>
!>

Parámetros

JOBVSL 
!>          JOBVSL es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur izquierdos;
!>          = 'V':  calcular los vectores de Schur izquierdos.
!>

JOBVSR

!>          JOBVSR es CHARACTER*1
!>          = 'N':  no calcular los vectores de Schur derechos;
!>          = 'V':  calcular los vectores de Schur derechos.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur generalizada.
!>          = 'N':  Los valores propios no están ordenados;
!>          = 'S':  Los valores propios están ordenados (ver SELCTG);
!>

SELCTG

!>          SELCTG es una FUNCIÓN LOGICAL de tres argumentos DOUBLE PRECISION
!>          SELCTG debe declararse EXTERNAL en la subrutina llamante.
!>          Si SORT = 'N', SELCTG no se referencia.
!>          Si SORT = 'S', SELCTG se utiliza para seleccionar los valores propios
!>          para ordenarlos en la parte superior izquierda de la forma de Schur.
!>          Un valor propio (ALPHAR(j)+ALPHAI(j))/BETA(j) se selecciona si
!>          SELCTG(ALPHAR(j),ALPHAI(j),BETA(j)) es verdadero; es decir, si
!>          se selecciona uno de un par conjugado complejo de valores propios,
!>          entonces ambos valores propios complejos se seleccionan.
!>
!>          Tenga en cuenta que en el caso mal condicionado, un valor propio complejo
!>          seleccionado puede ya no satisfacer SELCTG(ALPHAR(j),ALPHAI(j),
!>          BETA(j)) = .TRUE. después de ordenar. INFO debe establecerse en N+2
!>          en este caso.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A, B, VSL y VSR.  N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, el primero del par de matrices.
!>          En la salida, A ha sido sobrescrito por su forma de Schur
!>          generalizada S.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, el segundo del par de matrices.
!>          En la salida, B ha sido sobrescrito por su forma de Schur
!>          generalizada T.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de ordenar)
!>          para los cuales SELCTG es verdadero. (Los pares conjugados complejos para los
!>          cuales SELCTG es verdadero para cualquiera de los valores propios cuentan como 2).
!>

ALPHAR

!>          ALPHAR es un array DOUBLE PRECISION, dimensión (N)
!>

ALPHAI

!>          ALPHAI es un array DOUBLE PRECISION, dimensión (N)
!>

BETA

!>          BETA es un array DOUBLE PRECISION, dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los valores propios generalizados. ALPHAR(j) + ALPHAI(j)*i,
!>          y BETA(j), j=1,...,N son las diagonales de la forma de Schur compleja
!>          (S,T) que resultaría si los bloques diagonales de 2x2 de
!>          la forma de Schur real de (A,B) se redujeran aún más a
!>          forma triangular utilizando transformaciones unitarias complejas de 2x2.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo valor propio es real; si
!>          es positivo, entonces el j-ésimo y (j+1)-ésimo valores propios son un
!>          par conjugado complejo, con ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente sufrir desbordamiento o subdesbordamiento, y BETA(j) puede
!>          incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la razón.
!>          Sin embargo, ALPHAR y ALPHAI siempre serán menores y
!>          generalmente comparables con norm(A) en magnitud, y BETA siempre
!>          menor y generalmente comparable con norm(B).
!>

VSL

!>          VSL es un array DOUBLE PRECISION, dimensión (LDVSL,N)
!>          Si JOBVSL = 'V', VSL contendrá los vectores de Schur izquierdos.
!>          No referenciado si JOBVSL = 'N'.
!>

LDVSL

!>          LDVSL es INTEGER
!>          La dimensión principal de la matriz VSL. LDVSL >=1, y
!>          si JOBVSL = 'V', LDVSL >= N.
!>

VSR

!>          VSR es un array DOUBLE PRECISION, dimensión (LDVSR,N)
!>          Si JOBVSR = 'V', VSR contendrá los vectores de Schur derechos.
!>          No referenciado si JOBVSR = 'N'.
!>

LDVSR

!>          LDVSR es INTEGER
!>          La dimensión principal de la matriz VSR. LDVSR >= 1, y
!>          si JOBVSR = 'V', LDVSR >= N.
!>

TRABAJO

!>          WORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.
!>          Si N = 0, LWORK >= 1, de lo contrario LWORK >= MAX(8*N,6*N+16).
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!>

BWORK

!>          BWORK es un arreglo LOGICAL, dimensión (N)
!>          No se referencia si SORT = 'N'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló. (A,B) no están en forma
!>                Schur, pero ALPHAR(j), ALPHAI(j), y BETA(j) deberían
!>                ser correctos para j=INFO+1,...,N.
!>          > N:  =N+1: algo distinto a que la iteración QZ falló en DHGEQZ.
!>                =N+2: después de reordenar, el redondeo cambió los valores de
!>                      algunos eigenvalores complejos de manera que los eigenvalores
!>                      principales en la forma Schur Generalizada ya
!>                      no satisfacen SELCTG=.TRUE.. Esto también podría
!>                      ser causado debido al escalado.
!>                =N+3: el reordenamiento falló en DTGSEN.
!>
