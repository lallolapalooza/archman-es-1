subrutina dgeesx (character jobvs, character sort, external select, character sense, integer n, double precision, dimension( lda, * ) a, integer lda, integer sdim, double precision, dimension( * ) wr, double precision, dimension( * ) wi, double precision, dimension( ldvs, * ) vs, integer ldvs, double precision rconde, double precision rcondv, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, logical, dimension( * ) bwork, integer info)

DGEESX calcula los valores propios, la forma de Schur y, opcionalmente, la matriz de vectores de Schur para matrices GE

Propósito:

!>
!> DGEESX calcula para una matriz real no simétrica A de N por N, los
!> valores propios, la forma de Schur real T y, opcionalmente, la matriz de
!> vectores de Schur Z. Esto proporciona la factorización de Schur A = Z*T*(Z**T).
!>
!> Opcionalmente, también ordena los valores propios en la diagonal de la
!> forma de Schur real de modo que los valores propios seleccionados estén
!> en la parte superior izquierda; calcula un número de condición recíproco
!> para el promedio de los valores propios seleccionados (RCONDE); y calcula
!> un número de condición recíproco para el subespacio invariante derecho
!> correspondiente a los valores propios seleccionados (RCONDV). Las
!> columnas principales de Z forman una base ortonormal para este
!> subespacio invariante.
!>
!> Para una explicación más detallada de los números de condición
!> recíprocos RCONDE y RCONDV, véase la Sección 4.10 de la Guía de Usuarios
!> de LAPACK (donde estas cantidades se denominan s y sep respectivamente).
!>
!> Una matriz real está en forma de Schur real si es superior cuasitriangular
!> con bloques de 1 por 1 y 2 por 2. Los bloques de 2 por 2 se estandarizarán en
!> la forma
!>           [  a  b  ]
!>           [  c  a  ]
!>
!> donde b*c < 0. Los valores propios de dicho bloque son a +- sqrt(bc).
!>

Parámetros

JOBVS 
!>          JOBVS es CHARACTER*1
!>          = 'N': No se calculan los vectores de Schur;
!>          = 'V': Se calculan los vectores de Schur.
!>

SORT

!>          SORT es CHARACTER*1
!>          Especifica si se ordenan o no los valores propios en la
!>          diagonal de la forma de Schur.
!>          = 'N': No se ordenan los valores propios;
!>          = 'S': Se ordenan los valores propios (véase SELECT).
!>

SELECT

!>          SELECT es una FUNCIÓN LÓGICA de dos argumentos DOUBLE PRECISION
!>          SELECT debe declararse EXTERNAL en la subrutina que la llama.
!>          Si SORT = 'S', SELECT se utiliza para seleccionar los valores
!>          propios que se ordenarán en la parte superior izquierda de la
!>          forma de Schur.
!>          Si SORT = 'N', SELECT no se referencia.
!>          Un valor propio WR(j)+sqrt(-1)*WI(j) se selecciona si
!>          SELECT(WR(j),WI(j)) es verdadero; es decir, si se selecciona
!>          uno de un par de valores propios conjugados complejos, entonces
!>          se seleccionan ambos. Nótese que un valor propio complejo
!>          seleccionado puede dejar de cumplir SELECT(WR(j),WI(j)) = .TRUE.
!>          después de la ordenación, ya que la ordenación puede cambiar el
!>          valor de los valores propios complejos (especialmente si el
!>          valor propio está mal condicionado); en este caso INFO puede
!>          establecerse a N+3 (véase INFO más abajo).
!>

SENSE

!>          SENSE es CHARACTER*1
!>          Determina qué números de condición recíprocos se calculan.
!>          = 'N': No se calcula ninguno;
!>          = 'E': Se calcula solo para el promedio de los valores propios seleccionados;
!>          = 'V': Se calcula solo para el subespacio invariante derecho seleccionado;
!>          = 'B': Se calcula para ambos.
!>          Si SENSE = 'E', 'V' o 'B', SORT debe ser igual a 'S'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

A

!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA, N)
!>          A la entrada, la matriz A de N por N.
!>          A la salida, A se sobrescribe con su forma de Schur real T.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del arreglo A.  LDA >= max(1,N).
!>

SDIM

!>          SDIM es INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = número de valores propios (después de
!>                         ordenar) para los cuales SELECT es verdadero.
!>                         (Los pares de conjugados complejos para los
!>                         cuales SELECT es verdadero para cualquiera de
!>                         los valores propios se cuentan como 2.)
!>

WR

!>          WR es un arreglo DOUBLE PRECISION, dimensión (N)
!>

WI

!>          WI es un arreglo DOUBLE PRECISION, dimensión (N)
!>          WR y WI contienen las partes real e imaginaria, respectivamente,
!>          de los valores propios calculados, en el mismo orden en que
!>          aparecen en la diagonal de la forma de Schur de salida T. Los
!>          pares de conjugados complejos de valores propios aparecen
!>          consecutivamente con el valor propio que tiene la parte
!>          imaginaria positiva primero.
!>

VS

!>          VS es un arreglo DOUBLE PRECISION, dimensión (LDVS,N)
!>          Si JOBVS = 'V', VS contiene la matriz ortogonal Z de vectores
!>          de Schur.
!>          Si JOBVS = 'N', VS no se referencia.
!>

LDVS

!>          LDVS es INTEGER
!>          La dimensión principal del arreglo VS.  LDVS >= 1, y si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE es DOUBLE PRECISION
!>          Si SENSE = 'E' o 'B', RCONDE contiene el número de condición
!>          recíproco para el promedio de los valores propios seleccionados.
!>          No se referencia si SENSE = 'N' o 'V'.
!>

RCONDV

!>          RCONDV es DOUBLE PRECISION
!>          Si SENSE = 'V' o 'B', RCONDV contiene el número de condición
!>          recíproco para el subespacio invariante derecho seleccionado.
!>          No se referencia si SENSE = 'N' o 'E'.
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK.  LWORK >= max(1,3*N).
!>          Además, si SENSE = 'E' o 'V' o 'B',
!>          LWORK >= N+2*SDIM*(N-SDIM), donde SDIM es el número de
!>          valores propios seleccionados calculados por esta rutina. Nótese
!>          que N+2*SDIM*(N-SDIM) <= N+N*N/2. Nótese también que un error
!>          solo se devuelve si LWORK < max(1,3*N), pero si SENSE = 'E' o
!>          'V' o 'B' esto puede no ser suficiente.
!>          Para un buen rendimiento, LWORK debe ser generalmente mayor.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la
!>          rutina solo calcula límites superiores para los tamaños
!>          óptimos de los arreglos WORK e IWORK, devuelve estos valores
!>          como las primeras entradas de los arreglos WORK e IWORK, y
!>          XERBLA no emite mensajes de error relacionados con LWORK o
!>          LIWORK.
!>

IWORK

!>          IWORK es un arreglo INTEGER, dimensión (MAX(1,LIWORK))
!>          A la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!>

LIWORK

!>          LIWORK es INTEGER
!>          La dimensión del arreglo IWORK.
!>          LIWORK >= 1; si SENSE = 'V' o 'B', LIWORK >= SDIM*(N-SDIM). Nótese que SDIM*(N-SDIM) <= N*N/4. Nótese también que solo se devuelve un error si LIWORK < 1, pero si SENSE = 'V' o 'B' esto puede no ser suficiente.
>
>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la
>          rutina solo calcula límites superiores para los tamaños óptimos de
>          los arreglos WORK e IWORK, devuelve estos valores como las primeras
>          entradas de los arreglos WORK e IWORK, y XERBLA no emite mensajes de
>          error relacionados con LWORK o LIWORK.
>

BWORK

!>          BWORK es un arreglo LOGICAL, dimensión (N).
!>          No se referencia si SORT = 'N'.
>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: si INFO = i, y i es
!>             <= N: el algoritmo QR no logró calcular todos los
!>                   autovalores; los elementos 1:ILO-1 e i+1:N de WR y WI
!>                   contienen aquellos autovalores que han convergido; si
!>                   JOBVS = 'V', VS contiene la transformación que
!>                   reduce A a su forma de Schur parcialmente convergida.
!>             = N+1: los autovalores no pudieron reordenarse porque algunos
!>                   autovalores estaban demasiado cerca para separarlos (el
!>                   problema está muy mal condicionado);
!>             = N+2: después de reordenar, el redondeo cambió los valores de
!>                   algunos autovalores complejos de modo que los autovalores
!>                   principales en la forma de Schur ya no satisfacen
!>                   SELECT=.TRUE.. Esto también podría deberse a un
!>                   desbordamiento por debajo debido al escalado.
!>
