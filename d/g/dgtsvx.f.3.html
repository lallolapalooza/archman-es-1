subrutina dgtsvx (character fact, character trans, integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( * ) dlf, double precision, dimension( * ) df, double precision, dimension( * ) duf, double precision, dimension( * ) du2, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision rcond, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGTSVX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices GT

Propósito:

!>
!> DGTSVX utiliza la factorización LU para calcular la solución a un sistema
!> real de ecuaciones lineales A * X = B o A**T * X = B, donde A es una matriz
!> tridiagonal de orden N y X y B son matrices N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', se utiliza la descomposición LU para factorizar la
!>    matriz A como A = L * U, donde L es un producto de permutación y
!>    matrices bidiagonales inferiores unitarias y U es triangular superior
!>    con elementos no nulos solo en la diagonal principal y las dos
!>    superdiagonales principales.
!>
!> 2. Si algún U(i,i)=0, de modo que U es exactamente singular, la subrutina
!>    retorna con INFO = i. De lo contrario, la forma factorizada de A se
!>    utiliza para estimar el número de condición de la matriz A. Si el
!>    recíproco del número de condición es menor que la precisión de la
!>    máquina, se retorna INFO = N+1 como advertencia, pero la subrutina
!>    continúa resolviendo para X y calculando límites de error como se
!>    describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y obtener los límites de error y las estimaciones de error hacia atrás.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de A ha sido proporcionada
!>          en la entrada.
!>          = 'F':  DLF, DF, DUF, DU2 e IPIV contienen la forma factorizada
!>                  de A; DL, D, DU, DLF, DF, DUF, DU2 e IPIV no serán
!>                  modificados.
!>          = 'N':  La matriz se copiará en DLF, DF y DUF y se factorizará.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transposición)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada = Transpuesta)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los elementos subdiagonales (n-1) de A.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los elementos diagonales n de A.
!>

DU

!>          DU es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los elementos superdiagonales (n-1) de A.
!>

DLF

!>          DLF es un array DOUBLE PRECISION, dimensión (N-1)
!>          Si FACT = 'F', entonces DLF es un argumento de entrada y en
!>          la entrada contiene los multiplicadores (n-1) que definen
!>          la matriz L de la factorización LU de A, calculada por DGTTRF.
!>
!>          Si FACT = 'N', entonces DLF es un argumento de salida y en
!>          la salida contiene los multiplicadores (n-1) que definen la
!>          matriz L de la factorización LU de A.
!>

DF

!>          DF es un array DOUBLE PRECISION, dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en
!>          la entrada contiene los elementos diagonales n de la matriz
!>          triangular superior U de la factorización LU de A.
!>
!>          Si FACT = 'N', entonces DF es un argumento de salida y en
!>          la salida contiene los elementos diagonales n de la matriz
!>          triangular superior U de la factorización LU de A.
!>

DUF

!>          DUF es un array DOUBLE PRECISION, dimensión (N-1)
!>          Si FACT = 'F', entonces DUF es un argumento de entrada y en
!>          la entrada contiene los elementos (n-1) de la primera
!>          superdiagonal de U.
!>
!>          Si FACT = 'N', entonces DUF es un argumento de salida y en
!>          la salida contiene los elementos (n-1) de la primera
!>          superdiagonal de U.
!>

DU2

!>          DU2 es un array DOUBLE PRECISION, dimensión (N-2)
!>          Si FACT = 'F', entonces DU2 es un argumento de entrada y en
!>          la entrada contiene los elementos (n-2) de la segunda
!>          superdiagonal de U.
!>
!>          Si FACT = 'N', entonces DU2 es un argumento de salida y en
!>          la salida contiene los elementos (n-2) de la segunda
!>          superdiagonal de U.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Si FACT = 'F', entonces IPIV es un argumento de entrada y en
!>          la entrada contiene los índices de pivote de la factorización
!>          LU de A calculada por DGTTRF.
!>
!>          Si FACT = 'N', entonces IPIV es un argumento de salida y en
!>          la salida contiene los índices de pivote de la factorización
!>          LU de A; la fila i de la matriz fue intercambiada con la fila
!>          IPIV(i). IPIV(i) siempre será i o i+1; IPIV(i) = i indica que
!>          no se requirió un intercambio de filas.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de tamaño N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de tamaño
!>          N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es DOUBLE PRECISION
!>          La estimación del recíproco del número de condición de la
!>          matriz A. Si RCOND es menor que la precisión de la máquina
!>          (en particular, si RCOND = 0), la matriz es singular con
!>          precisión de trabajo. Esta condición se indica con un código
!>          de retorno de INFO > 0.
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites de error estimados hacia adelante para cada
!>          columna de la solución X. Si I = 1, 2, ..., NRHS, entonces
!>          FERR(I) contendrá una estimación de la distancia relativa
!>          entre la solución calculada X(:,I) y la solución verdadera
!>          de A*X = B, medida en la norma 1.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites de error estimados hacia atrás para cada
!>          columna de la solución X. Si I = 1, 2, ..., NRHS, entonces
!>          BERR(I) contendrá una estimación de la distancia relativa
!>          entre la solución calculada X(:,I) y la solución verdadera
!>          de A*X = B, medida en la norma 1.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (4*N)
!>          Espacio de trabajo utilizado para la factorización y/o
!>          el refinamiento iterativo.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N)
!>          Espacio de trabajo utilizado para el intercambio de pivote.
!>

INFO

!>          INFO es INTEGER
!>          = 0: ejecución correcta.
!>          > 0: si INFO = i y 1 <= i <= N, entonces la factorización LU
!>               falló porque el elemento i,i de U es cero. La matriz
!>               es singular, y la solución no se puede calcular.
!>          = N+1: la matriz es singular a la precisión de trabajo. Se
!>                 calculó una solución, pero no se puede garantizar
!>                 su precisión.
!>

FERR es un array de tipo DOUBLE PRECISION, dimensión (NRHS) !> La cota superior de error hacia adelante estimada para cada !> vector solución X(j) (la j-ésima columna de la matriz solución X). !> Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j) !> es una cota superior estimada para la magnitud del elemento más !> grande en (X(j) - XTRUE) dividida por la magnitud del elemento !> más grande en X(j). La estimación es tan fiable como !> la estimación para RCOND, y casi siempre es una ligera !> sobreestimación del error verdadero. !>

BERR

!>          BERR es un array de tipo DOUBLE PRECISION, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es un array de tipo DOUBLE PRECISION, dimensión (3*N)
!>

IWORK

!>          IWORK es un array de tipo INTEGER, dimensión (N)
!>

INFO

!>          INFO es de tipo INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  U(i,i) es exactamente cero.  La factorización
!>                       no se ha completado a menos que i = N, pero el
!>                       factor U es exactamente singular, por lo que la solución
!>                       y las cotas de error no pudieron ser calculadas.
!>                       Se devuelve RCOND = 0.
!>                = N+1: U no es singular, pero RCOND es menor que la precisión
!>                       de la máquina, lo que significa que la matriz es singular
!>                       hasta la precisión de trabajo.  Sin embargo, la
!>                       solución y las cotas de error se calculan porque
!>                       hay una serie de situaciones en las que la
!>                       solución calculada puede ser más precisa que la
!>                       que sugeriría el valor de RCOND.
!>
