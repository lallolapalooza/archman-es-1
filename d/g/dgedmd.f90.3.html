DGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para un par de matrices de instantáneas de

datos.

Propósito

: 
!>    DGEDMD calcula la Descomposición de Modos Dinámicos (DMD) para
!>    un par de matrices de instantáneas de datos. Para las matrices de
!>    entrada X e Y tales que Y = A*X con una matriz A inaccesible,
!>    DGEDMD calcula un cierto número de pares de Ritz de A usando
!>    la extracción estándar de Rayleigh-Ritz de un subespacio de
!>    el rango(X) que se determina usando los vectores singulares
!>    izquierdos principales de X. Opcionalmente, DGEDMD devuelve los
!>    residuos de los pares de Ritz calculados, la información necesaria para
!>    un refinamiento de los vectores de Ritz, o los autovectores de
!>    el DMD Exacto.
!>    Para más detalles ver las referencias listadas
!>    abajo. Para más detalles de la implementación ver [3].
!
>

Parámetro

s
JOBS 
!>    JOBS (entrada) es CHARACTER*1
!>    Determina si las instantáneas de datos iniciales se escalan
!>    por una matriz diagonal.
!>    'S' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           con una matriz diagonal D de modo que X*D tiene columnas
!>           no nulas unitarias (en la norma euclidiana 2)
!>    'C' :: Las instantáneas se escalan como con la opción 'S'.
!>           Si se encuentra que la i-ésima columna de X es un
!>           vector cero y la i-ésima columna correspondiente de Y es
!>           no nula, entonces la i-ésima columna de Y se establece a
!>           cero y se levanta una bandera de advertencia.
!>    'Y' :: Las matrices de instantáneas de datos X e Y se multiplican
!>           por una matriz diagonal D de modo que Y*D tiene columnas
!>           no nulas unitarias (en la norma euclidiana 2)
!>    'N' :: Sin escalado de datos.
!
>

JOB

Z 
!>    JOBZ (entrada) CHARACTER*1
!>    Determina si los autovectores (modos de Koopman) se
!>    calcularán.
!>    'V' :: Los autovectores (modos de Koopman) se calcularán
!>           y se devolverán en la matriz Z.
!>           Ver la descripción de Z.
!>    'F' :: Los autovectores (modos de Koopman) se devolverán
!>           en forma factorizada como el producto X(:,1:K)*W, donde X
!>           contiene una base POD (vectores singulares izquierdos
!>           principales de la matriz de datos X) y W contiene los autovectores
!>           del cociente de Rayleigh correspondiente.
!>           Ver las descripciones de K, X, W, Z.
!>    'N' :: Los autovectores no se calculan.
!
>

JOB

R 
!>    JOBR (entrada) CHARACTER*1
!>    Determina si calcular los residuos.
!>    'R' :: Los residuos para los auto-pares calculados se
!>           calcularán y almacenarán en el arreglo RES.
!>           Ver la descripción de RES.
!>           Para que esta opción sea legal, JOBZ debe ser 'V'.
!>    'N' :: Los residuos no se calculan.
!
>

JOB

F 
!>    JOBF (entrada) CHARACTER*1
!>    Especifica si almacenar información necesaria para el post-
!>    procesamiento (p. ej., calcular vectores de Ritz refinados)
!>    'R' :: La matriz necesaria para el refinamiento de los vectores
!>           de Ritz se calcula y almacena en el arreglo B.
!>           Ver la descripción de B.
!>    'E' :: Los autovectores sin escalar del DMD Exacto se
!>           calculan y se devuelven en el arreglo B. Ver la
!>           descripción de B.
!>    'N' :: No se calculan datos de refinamiento de autovectores.
!
>

WHTSV

D 
!>    WHTSVD (entrada) INTEGER, WHSTVD en { 1, 2, 3, 4 }
!>    Permite una selección del algoritmo SVD de la
!>    biblioteca LAPACK.
!>    1 :: DGESVD (el algoritmo SVD QR)
!>    2 :: DGESDD (el algoritmo de División y Conquista; si hay suficiente
!>         espacio de trabajo disponible, este es el más rápidoption)
!>    3 :: DGESVDQ (el SVD QR precondicionado; esta y la 4
!>         son las opciones más precisas)
!>    4 :: DGEJSV (el SVD Jacobi precondicionado; esta y la 3
!>         son las opciones más precisas)
!>    Para los cuatro métodos anteriores, es posible una
!>    diferencia significativa en la precisión de los
!>    valores singulares pequeños si las instantáneas varían
!>    en norma de modo que X esté severamente mal
!>    condicionada. Si se interesan los valores singulares
!>    pequeños (menores que EPS*||X||) y JOBS=='N', entonces
!>    las opciones (3, 4) dan los resultados más precisos,
!>    donde la opción 4 es ligeramente mejor y con un
!>    fundamento teórico más sólido.
!>    Si JOBS=='S', es decir, las columnas de X serán
!>    normalizadas, entonces todos los métodos dan resultados
!>    casi igualmente precisos.
!>

M

!>    M (entrada) INTEGER, M>= 0
!>    La dimensión del espacio de estados (la dimensión de
!>    filas de X, Y).
!>

N

!>    N (entrada) INTEGER, 0 <= N <= M
!>    El número de pares de instantáneas de datos
!>    (el número de columnas de X y Y).
!>

X

!>    X (entrada/salida) REAL(KIND=WP) matriz M-por-N
!>    > En la entrada, X contiene la matriz de instantáneas
!>    de datos X. Se asume que las normas de columna de X
!>    están en el rango de los números de punto flotante
!>    normalizados.
!>    < En la salida, las primeras K columnas de X contienen
!>    una base POD, es decir, los primeros K vectores
!>    singulares izquierdos de la matriz de datos de entrada
!>    X, U(:,1:K). Las N columnas de X contienen todos los
!>    vectores singulares izquierdos de la matriz de entrada
!>    X.
!>    Véanse las descripciones de K, Z y W.
!>

LDX

!>    LDX (entrada) INTEGER, LDX >= M
!>    La dimensión principal del array X.
!>

Y

!>    Y (entrada/espacio de trabajo/salida) REAL(KIND=WP)
!>    matriz M-por-N
!>    > En la entrada, Y contiene la matriz de instantáneas
!>    de datos Y
!>    < En la salida,
!>    Si JOBR == 'R', las primeras K columnas de Y contienen
!>    los vectores residuales para los pares de Ritz
!>    calculados.
!>    Véase la descripción de RES.
!>    Si JOBR == 'N', Y contiene los datos de entrada
!>    originales, escalados de acuerdo con el valor de JOBS.
!>

LDY

!>    LDY (entrada) INTEGER , LDY >= M
!>    La dimensión principal del array Y.
!>

NRNK

!>    NRNK (entrada) INTEGER
!>    Determina el modo de calcular el rango numérico,
!>    es decir, cómo truncar los valores singulares pequeños
!>    de la matriz de entrada X. En la entrada, si
!>    NRNK = -1 :: el i-ésimo valor singular sigma(i) se
!>                 trunca si sigma(i) <= TOL*sigma(1).
!>                 Esta opción es recomendada.
!>    NRNK = -2 :: el i-ésimo valor singular sigma(i) se
!>                 trunca si sigma(i) <= TOL*sigma(i-1)
!>                 Esta opción se incluye con fines de I+D.
!>                 Requiere un SVD altamente preciso, lo que
!>                 puede no ser viable.
!>
!>    El rango numérico se puede forzar usando un valor
!>    positivo de NRNK de la siguiente manera:
!>    0 < NRNK <= N :: se usarán a lo sumo los NRNK valores
!>    singulares más grandes. Si el número de valores
!>    singulares distintos de cero calculados es menor que
!>    NRNK, entonces solo se usarán esos valores distintos de
!>    cero y la dimensión realmente usada es menor que NRNK.
!>    El número real de valores singulares distintos de cero
!>    se devuelve en la variable K. Véanse las descripciones
!>    de TOL y K.
!>

TOL

!>    TOL (entrada) REAL(KIND=WP), 0 <= TOL < 1
!>    La tolerancia para truncar los valores singulares
!>    pequeños.
!>    Véase la descripción de NRNK.
!>

K

!>    K (salida) INTEGER,  0 <= K <= N
!>    La dimensión de la base POD para la matriz de
!>    instantáneas de datos X y el número de pares de Ritz
!>    calculados.
!>    El valor de K se determina de acuerdo con la regla
!>    establecida por los parámetros NRNK y TOL.
!>    Véanse las descripciones de NRNK y TOL.
!>

REIG

!>    REIG (salida) REAL(KIND=WP) matriz N-por-1
!>    Las primeras K (K<=N) entradas de REIG contienen
!>    las partes reales de los autovalores calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Véanse las descripciones de K, IMEIG y Z.
!>

IMEIG

!>    IMEIG (salida) REAL(KIND=WP) matriz N-por-1
!>    Las primeras K (K<=N) entradas de IMEIG contienen
!>    las partes imaginarias de los autovalores calculados
!>    REIG(1:K) + sqrt(-1)*IMEIG(1:K).
!>    Los autovalores se determinan de la siguiente manera:
!>    Si IMEIG(i) == 0, entonces el autovalor correspondiente
!>    es real, LAMBDA(i) = REIG(i).
!>    Si IMEIG(i)>0, entonces el par de autovalores
!>    conjugados complejos correspondiente se lee
!>    LAMBDA(i)   = REIG(i) + sqrt(-1)*IMAG(i)
!>    LAMBDA(i+1) = REIG(i) - sqrt(-1)*IMAG(i)
!>    Es decir, los pares conjugados complejos tienen índices
!>    consecutivos (i,i+1), con la parte imaginaria positiva
!>    listada primero.
!>    Véanse las descripciones de K, REIG y Z.
!>

Z

!>    Z (espacio de trabajo/salida) REAL(KIND=WP)  matriz
!>    M-por-N
!>    Si JOBZ =='V' entonces
!>       Z contiene vectores de Ritz reales de la siguiente
!>       manera:
!>       Si IMEIG(i)=0, entonces Z(:,i) es un autovector del
!>       i-ésimo valor de Ritz; ||Z(:,i)||_2=1.
!>       Si IMEIG(i) > 0 (y IMEIG(i+1) < 0) entonces
!>       [Z(:,i) Z(:,i+1)] abarcan un subespacio invariante y
!>       los valores de Ritz extraídos de este subespacio son
!>       REIG(i) + sqrt(-1)*IMEIG(i) y
!>       REIG(i) - sqrt(-1)*IMEIG(i).
!>       Los autovectores correspondientes son
!>       Z(:,i) + sqrt(-1)*Z(:,i+1) y
!>       Z(:,i) - sqrt(-1)*Z(:,i+1), respectivamente.
!>       || Z(:,i:i+1)||_F = 1.
!>    Si JOBZ == 'F', entonces las descripciones anteriores
!>    se aplican a las columnas de X(:,1:K)*W(1:K,1:K),
!>    donde las columnas de W(1:k,1:K) son los autovectores
!>    calculados del cociente de Rayleigh K-por-K. Las
!>    columnas de W(1:K,1:K) están estructuradas de manera
!>    similar: Si IMEIG(i) == 0 entonces X(:,1:K)*W(:,i) es
!>    un autovector, y si IMEIG(i)>0 entonces
!>    X(:,1:K)*W(:,i)+sqrt(-1)*X(:,1:K)*W(:,i+1) y
!>         X(:,1:K)*W(:,i)-sqrt(-1)*X(:,1:K)*W(:,i+1)
!>    son los autovectores de LAMBDA(i), LAMBDA(i+1).
!>    Véanse las descripciones de REIG, IMEIG, X y W.
!>

LDZ

!>    LDZ (entrada) INTEGER , LDZ >= M
!>    La dimensión principal del array Z.
!>

RES

!>    RES (salida) REAL(KIND=WP) matriz N-por-1
!>    RES(1:K) contiene los residuales para los K pares de
!>    Ritz calculados.
!>    Si LAMBDA(i) es real, entonces
!>       RES(i) = || A * Z(:,i) - LAMBDA(i)*Z(:,i))||_2.
!>    Si [LAMBDA(i), LAMBDA(i+1)] es un par conjugado
!>    complejo entonces
!>    RES(i)=RES(i+1) = || A * Z(:,i:i+1) - Z(:,i:i+1) *B||_F
!>    donde B = [ real(LAMBDA(i)) imag(LAMBDA(i)) ]
!>              [-imag(LAMBDA(i)) real(LAMBDA(i)) ].
!>    Se cumple que
!>    RES(i)   = || A*ZC(:,i)   - LAMBDA(i)  *ZC(:,i)   ||_2
!>    RES(i+1) = || A*ZC(:,i+1) - LAMBDA(i+1)*ZC(:,i+1) ||_2
!>    donde ZC(:,i)   =  Z(:,i) + sqrt(-1)*Z(:,i+1)
!>          ZC(:,i+1) =  Z(:,i) - sqrt(-1)*Z(:,i+1)
!>    Véase la descripción de REIG, IMEIG y Z.
!>

B

!>    B (salida) REAL(KIND=WP)  matriz M-por-N.
!>    SI JOBF =='R', B(1:M,1:K) contiene A*U(:,1:K), y puede
!>    usarse para calcular los vectores refinados; véanse más
!>    detalles en las referencias proporcionadas.
!>    Si JOBF == 'E', B(1:M,1;K) contiene
!>    A*U(:,1:K)*W(1:K,1:K), que son los vectores del DMD
!>    Exacto, hasta un escalado por los autovalores inversos.
!>    Si JOBF =='N', entonces B no se referencia.
!>    Véanse las descripciones de X, W, K.
!>

LDB

!>    LDB (entrada) INTEGER, LDB >= M
!>    La dimensión principal del array B.
!>

W

!>    W (espacio de trabajo/salida) REAL(KIND=WP) matriz
!>    N-por-N
!>    En la salida, W(1:K,1:K) contiene los K autovectores
!>    calculados de la matriz cociente de Rayleigh (partes
!>    real e imaginaria para cada par de autovalores
!>    conjugados complejos). Los vectores de Ritz (devueltos
!>    en Z) son el producto de X (que contiene una base POD
!>    para la matriz de entrada X) y W. Véanse las
!>    descripciones de K, S, X y Z.
!>    W también se usa como espacio de trabajo para almacenar
!>    temporalmente los vectores singulares derechos de X.
!>

LDW

!>    LDW (entrada) INTEGER, LDW >= N
!>    La dimensión principal del array W.
!>

S

!>    S (espacio de trabajo/salida) REAL(KIND=WP) matriz
!>    N-por-N
!>    El array S(1:K,1:K) se usa para la matriz cociente de
!>    Rayleigh. Este contenido se sobrescribe durante la
!>    descomposición de autovalores por DGEEV.
!>    Véase la descripción de K.
!>

LDS

!>    LDS (entrada) INTEGER, LDS >= N
!>    La dimensión principal del array S.
!>

WORK

!>    WORK (espacio de trabajo/salida) REAL(KIND=WP)
!>    matriz LWORK-por-1
!>    En la salida, WORK(1:N) contiene los valores singulares
!>    de X (para JOBS=='N') o X escalado por columnas
!>    (JOBS=='S', 'C').
!>    Si WHTSVD==4, entonces WORK(N+1) y WORK(N+2) contienen
!>    el factor de escala WORK(N+2)/WORK(N+1) usado para
!>    escalar X y Y y evitar el desbordamiento en el SVD de
!>    X.
!>    Esto puede ser de interés si la opción de escala está
!>    desactivada y se desean tantos autovalores pequeños
!>    como sea posible con la mayor precisión viable.
!>    Si la llamada a DGEDMD es solo una consulta de espacio
!>    de trabajo, entonces WORK(1) contiene la longitud
!>    mínima del espacio de trabajo y WORK(2) es la longitud
!>    óptima del espacio de trabajo. Por lo tanto, la
!>    longitud del trabajo es al menos 2.
!>    Véase la descripción de LWORK.
!>

LWORK

!>    LWORK (entrada) INTEGER
!>    La longitud mínima del vector de espacio de trabajo
!>    WORK.
!>    LWORK se calcula de la siguiente manera:
!>    Si WHTSVD == 1 ::
!>       Si JOBZ == 'V', entonces
!>       LWORK >= MAX(2, N + LWORK_SVD, N+MAX(1,4*N)).
!>       Si JOBZ == 'N'  entonces
!>       LWORK >= MAX(2, N + LWORK_SVD, N+MAX(1,3*N)).
!>       Aquí LWORK_SVD = MAX(1,3*N+M,5*N) es la longitud
!>       mínima del espacio de trabajo de DGESVD.
!>    Si WHTSVD == 2 ::
!>       Si JOBZ == 'V', entonces
!>       LWORK >= MAX(2, N + LWORK_SVD, N+MAX(1,4*N))
!>       Si JOBZ == 'N', entonces
!>       LWORK >= MAX(2, N + LWORK_SVD, N+MAX(1,3*N))
!>       Aquí LWORK_SVD = MAX(M, 5*N*N+4*N)+3*N*N es la
!>       longitud mínima del espacio de trabajo de DGESDD.
!>    Si WHTSVD == 3 ::
!>       Si JOBZ == 'V', entonces
!>       LWORK >= MAX(2, N+LWORK_SVD,N+MAX(1,4*N))
!>       Si JOBZ == 'N', entonces
!>       LWORK >= MAX(2, N+LWORK_SVD,N+MAX(1,3*N))
!>       Aquí LWORK_SVD = N+M+MAX(3*N+1,
!>                       MAX(1,3*N+M,5*N),MAX(1,N))
!>       es la longitud mínima del espacio de trabajo de
!>       DGESVDQ.
!>    Si WHTSVD == 4 ::
!>       Si JOBZ == 'V', entonces
!>       LWORK >= MAX(2, N+LWORK_SVD,N+MAX(1,4*N))
!>       Si JOBZ == 'N', entonces
!>       LWORK >= MAX(2, N+LWORK_SVD,N+MAX(1,3*N))
!>       Aquí LWORK_SVD = MAX(7,2*M+N,6*N+2*N*N) es la
!>       longitud mínima del espacio de trabajo de DGEJSV.
!>    Las expresiones anteriores no se simplifican para
!>    hacer más transparente el uso de WORK y para facilitar
!>    la comprobación. En cualquier case, LWORK >= 2.
!>    Si en la entrada LWORK = -1, se asume una consulta de espacio de trabajo
!>    y el procedimiento solo calcula las longitudes mínima y óptima
!>    del espacio de trabajo para WORK e IWORK.
!>    Vea las descripciones de WORK e IWORK.
!
>

IWOR

K 
!>    IWORK (espacio de trabajo/salida) Arreglo entero LIWORK-por-1
!>    Espacio de trabajo que se requiere solo si WHTSVD es igual a
!>    2, 3 o 4. (Vea la descripción de WHTSVD).
!>    Si en la entrada LWORK = -1 o LIWORK = -1, se calcula la
!>    longitud mínima de IWORK y se devuelve en
!>    IWORK(1). Vea la descripción de LIWORK.
!
>

LIWOR

K 
!>    LIWORK (entrada) ENTERO
!>    La longitud mínima del vector de espacio de trabajo IWORK.
!>    Si WHTSVD == 1, entonces solo se usa IWORK(1); LIWORK >= 1
!>    Si WHTSVD == 2, entonces LIWORK >= MAX(1,8*MIN(M,N))
!>    Si WHTSVD == 3, entonces LIWORK >= MAX(1,M+N-1)
!>    Si WHTSVD == 4, entonces LIWORK >= MAX(3,M+3*N)
