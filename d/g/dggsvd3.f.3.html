DGGSVD3 calcula la descomposición en valores singulares (SVD) para matrices

OTHER

Propósito

: 
!>
!> DGGSVD3 calcula la descomposición generalizada en valores singulares (GSVD)
!> de una matriz real A de M por N y una matriz real B de P por N:
!>
!>       U**T*A*Q = D1*( 0 R ),    V**T*B*Q = D2*( 0 R )
!>
!> donde U, V y Q son matrices ortogonales.
!> Sea K+L = el rango numérico efectivo de la matriz (A**T,B**T)**T,
!> entonces R es una matriz triangular superior no singular de K+L por K+L, D1 y
!> D2 son matrices de M por (K+L) y P por (K+L) respectivamente y de las
!> siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 =   L ( 0  S )
!>             P-L ( 0  0 )
!>
!>                 N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 )
!>             L (  0    0   R22 )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                   K M-K K+L-M
!>        D1 =   K ( I  0    0   )
!>             M-K ( 0  C    0   )
!>
!>                     K M-K K+L-M
!>        D2 =   M-K ( 0  S    0  )
!>             K+L-M ( 0  0    I  )
!>               P-L ( 0  0    0  )
!>
!>                    N-K-L  K   M-K  K+L-M
!>   ( 0 R ) =     K ( 0    R11  R12  R13  )
!>               M-K ( 0     0   R22  R23  )
!>             K+L-M ( 0     0    0   R33  )
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!>   S = diag( BETA(K+1),  ... , BETA(M) ),
!>   C**2 + S**2 = I.
!>
!>   (R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N), y R33 se almacena
!>   ( 0  R22 R23 )
!>   en B(M-K+1:L,N+M-K-L+1:N) en la salida.
!>
!> La rutina calcula C, S, R y opcionalmente las matrices de transformación
!> ortogonales U, V y Q.
!>
!> En particular, si B es una matriz no singular de N por N, entonces la GSVD de
!> A y B da implícitamente la SVD de A*inv(B):
!>                      A*inv(B) = U*(D1*inv(D2))*V**T.
!> Si ( A**T,B**T)**T tiene columnas ortonormales, entonces la GSVD de A y B es
!> también igual a la descomposición CS de A y B. Además, la GSVD
!> puede usarse para derivar la solución del problema de valores propios:
!>                      A**T*A x = lambda* B**T*B x.
!> En alguna literatura, la GSVD de A y B se presenta en la forma
!>                  U**T*A*X = ( 0 D1 ),   V**T*B*X = ( 0 D2 )
!> donde U y V son ortogonales y X es no singular, D1 y D2 son
!> ``diagonales''.  La forma anterior de la GSVD puede convertirse a la
!> forma posterior tomando la matriz no singular X como
!>
!>                      X = Q*( I   0    )
!>                            ( 0 inv(R) ).
!
>

Parámetro

s
JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  se calcula la matriz ortogonal U;
!>          = 'N':  no se calcula U.
!
>

JOB

V 
!>          JOBV es CHARACTER*1
!>          = 'V':  se calcula la matriz ortogonal V;
!>          = 'N':  no se calcula V.
!
>

JOB

Q 
!>          JOBQ es CHARACTER*1
!>          = 'Q':  se calcula la matriz ortogonal Q;
!>          = 'N':  no se calcula Q.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!
>

P 
!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!
>

K 
!>          K es INTEGER
!
>

L 
!>          L es INTEGER
!>
!>          En la salida, K y L especifican la dimensión de los subbloques
!>          descritos en Propósito.
!>          K + L = rango numérico efectivo de (A**T,B**T)**T.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          En la entrada, la matriz A de M por N.
!>          En la salida, A contiene la matriz triangular R, o parte de R.
!>          Véase Propósito para más detalles.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          En la entrada, la matriz B de P por N.
!>          En la salida, B contiene la matriz triangular R si M-K-L < 0.
!>          Véase Propósito para más detalles.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,P).
!
>

ALPH

A 
!>          ALPHA es un array DOUBLE PRECISION, dimensión (N)
!
>

BET

A 
!>          BETA es un array DOUBLE PRECISION, dimensión (N)
!>
!>          En la salida, ALPHA y BETA contienen los pares de valores singulares
!>          generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = C,
!>            BETA(K+1:K+L)  = S,
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)=C, ALPHA(M+1:K+L)=0
!>            BETA(K+1:M) =S, BETA(M+1:K+L) =1
!>          y
!>            ALPHA(K+L+1:N) = 0
!>            BETA(K+L+1:N)  = 0
!
>

U 
!>          U es un array DOUBLE PRECISION, dimensión (LDU,M)
!>          Si JOBU = 'U', U contiene la matriz ortogonal U de M por M.
!>          Si JOBU = 'N', U no se referencia.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en otro caso.
!
>

V 
!>          V es un array DOUBLE PRECISION, dimensión (LDV,P)
!>          Si JOBV = 'V', V contiene la matriz ortogonal V de P por P.
!>          Si JOBV = 'N', V no se referencia.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en otro caso.
!
>

Q 
!>          Q es un array DOUBLE PRECISION, dimensión (LDQ,N)
!>          Si JOBQ = 'Q', Q contiene la matriz ortogonal Q de N por N.
!>          Si JOBQ = 'N', Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!
>

WOR

K 
!>          WORK es un array de tipo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= 1.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite
!>          ningún mensaje de error relacionado con LWORK por parte de XERBLA.
!
>

IWOR

K 
!>          IWORK es un array de tipo INTEGER, dimensión (N)
!>          Al salir, IWORK almacena la información de ordenación. Más
!>          precisamente, el siguiente bucle ordenará ALPHA
!>             for I = K+1, min(M,K+L)
!>                 swap ALPHA(I) y ALPHA(IWORK(I))
!>             endfor
!>          de modo que ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = 1, el procedimiento de tipo Jacobi no logró
!>                converger. Para más detalles, ver el subrutina DTGSJA.
!
>

Parámetros

Internos: 
!>  TOLA    DOUBLE PRECISION
!>  TOLB    DOUBLE PRECISION
!>          TOLA y TOLB son los umbrales para determinar el rango efectivo
!>          de (A**T,B**T)**T. Generalmente, se establecen como
!>                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
!>                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
!>          El tamaño de TOLA y TOLB puede afectar al tamaño de los errores
!>          hacia atrás de la descomposición.
!
>
