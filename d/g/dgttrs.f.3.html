Documentación de la función/subrutina

subroutine dgttrs (character trans, integer n, integer nrhs, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du, double precision, dimension( * ) du2, integer, dimension( * ) ipiv, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DGTTRS

Propósito:

!>
!> DGTTRS resuelve uno de los sistemas de ecuaciones
!>    A*X = B  o  A**T*X = B,
!> con una matriz tridiagonal A utilizando la factorización LU calculada
!> por DGTTRF.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transposición)
!>          = 'T':  A**T* X = B  (Transposición)
!>          = 'C':  A**T* X = B  (Transposición conjugada = Transposición)
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

DL

!>          DL es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los multiplicadores (n-1) que definen la matriz L de la
!>          factorización LU de A.
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (N)
!>          Los n elementos diagonales de la matriz triangular superior U de
!>          la factorización LU de A.
!>

DU

!>          DU es un array DOUBLE PRECISION, dimensión (N-1)
!>          Los elementos (n-1) de la primera superdiagonal de U.
!>

DU2

!>          DU2 es un array DOUBLE PRECISION, dimensión (N-2)
!>          Los elementos (n-2) de la segunda superdiagonal de U.
!>

IPIV

!>          IPIV es un array INTEGER, dimensión (N)
!>          Los índices de pivote; para 1 <= i <= n, la fila i de la matriz fue
!>          intercambiada con la fila IPIV(i).  IPIV(i) será siempre i o
!>          i+1; IPIV(i) = i indica que no se requirió un intercambio de filas.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          En la entrada, la matriz de vectores del lado derecho B.
!>          En la salida, B se sobrescribe con los vectores solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tuvo un valor ilegal
!>
