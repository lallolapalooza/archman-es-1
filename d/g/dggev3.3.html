Documentación de Función/Subrutin

a

subrutina dggev3 (character jobvl, character jobvr, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) work, integer lwork, integer

info)

DGGEV3 calcula los eigenvalores y, opcionalmente, los eigenvectores izquierdos y/o derechos para matrices GE (algoritmo

bloqueado)

Propósito

: 
!>
!> DGGEV3 calcula para un par de matrices reales no simétricas de N por N (A,B)
!> los eigenvalores generalizados y, opcionalmente, los eigenvectores generalizados
!> izquierdos y/o derechos.
!>
!> Un eigenvalor generalizado para un par de matrices (A,B) es un escalar
!> lambda o una razón alpha/beta = lambda, tal que A - lambda*B es
!> singular. Generalmente se representa como el par (alpha,beta), ya
!> que hay una interpretación razonable para beta=0, e incluso para ambos
!> siendo cero.
!>
!> El eigenvector derecho v(j) correspondiente al eigenvalor lambda(j)
!> de (A,B) satisface
!>
!>                  A * v(j) = lambda(j) * B * v(j).
!>
!> El eigenvector izquierdo u(j) correspondiente al eigenvalor lambda(j)
!> de (A,B) satisface
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B .
!>
!> donde u(j)**H es el conjugado-transpuesto de u(j).
!>
!
>

Parámetro

s
JOBVL 
!>          JOBVL es CHARACTER*1
!>          = 'N':  no calcular los eigenvectores generalizados izquierdos;
!>          = 'V':  calcular los eigenvectores generalizados izquierdos.
!
>

JOBV

R 
!>          JOBVR es CHARACTER*1
!>          = 'N':  no calcular los eigenvectores generalizados derechos;
!>          = 'V':  calcular los eigenvectores generalizados derechos.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices A, B, VL, y VR.  N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA, N)
!>          En la entrada, la matriz A del par (A,B).
!>          En la salida, A ha sido sobrescrita.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal de A.  LDA >= max(1,N).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, la matriz B del par (A,B).
!>          En la salida, B ha sido sobrescrita.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal de B.  LDB >= max(1,N).
!
>

ALPHA

R 
!>          ALPHAR es un array DOUBLE PRECISION, dimensión (N)
!
>

ALPHA

I 
!>          ALPHAI es un array DOUBLE PRECISION, dimensión (N)
!
>

BET

A 
!>          BETA es un array DOUBLE PRECISION, dimensión (N)
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los eigenvalores generalizados.  Si ALPHAI(j) es cero, entonces
!>          el j-ésimo eigenvalor es real; si es positivo, entonces el j-ésimo y
!>          el (j+1)-ésimo eigenvalores son un par complejo conjugado, con
!>          ALPHAI(j+1) negativo.
!>
!>          Nota: los cocientes ALPHAR(j)/BETA(j) y ALPHAI(j)/BETA(j)
!>          pueden fácilmente desbordar o subdesbordar, y BETA(j) puede incluso ser cero.
!>          Por lo tanto, el usuario debe evitar calcular ingenuamente la razón
!>          alpha/beta.  Sin embargo, ALPHAR y ALPHAI siempre serán menores
!>          y generalmente comparables con norm(A) en magnitud, y
!>          BETA siempre menor y generalmente comparable con norm(B).
!
>

V

L 
!>          VL es un array DOUBLE PRECISION, dimensión (LDVL,N)
!>          Si JOBVL = 'V', los eigenvectores izquierdos u(j) se almacenan uno
!>          tras otro en las columnas de VL, en el mismo orden que
!>          sus eigenvalores. Si el j-ésimo eigenvalor es real, entonces
!>          u(j) = VL(:,j), la j-ésima columna de VL. Si el j-ésimo y
!>          el (j+1)-ésimo eigenvalores forman un par complejo conjugado, entonces
!>          u(j) = VL(:,j)+i*VL(:,j+1) y u(j+1) = VL(:,j)-i*VL(:,j+1).
!>          Cada eigenvector se escala de modo que el componente más grande tenga
!>          abs(parte real)+abs(parte imag.)=1.
!>          No se referencia si JOBVL = 'N'.
!
>

LDV

L 
!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL. LDVL >= 1, y
!>          si JOBVL = 'V', LDVL >= N.
!
>

V

R 
!>          VR es un array DOUBLE PRECISION, dimensión (LDVR,N)
!>          Si JOBVR = 'V', los eigenvectores derechos v(j) se almacenan uno
!>          tras otro en las columnas de VR, en el mismo orden que
!>          sus eigenvalores. Si el j-ésimo eigenvalor es real, entonces
!>          v(j) = VR(:,j), la j-ésima columna de VR. Si el j-ésimo y
!>          el (j+1)-ésimo eigenvalores forman un par complejo conjugado, entonces
!>          v(j) = VR(:,j)+i*VR(:,j+1) y v(j+1) = VR(:,j)-i*VR(:,j+1).
!>          Cada eigenvector se escala de modo que el componente más grande tenga
!>          abs(parte real)+abs(parte imag.)=1.
!>          No se referencia si JOBVR = 'N'.
!
>

LDV

R 
!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR. LDVR >= 1, y
!>          si JOBVR = 'V', LDVR >= N.
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER.
!>          La dimensión del array WORK. LWORK >= MAX(1,8*N).
!>          Para un buen rendimiento, LWORK debería ser generalmente mayor.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y no se emite ningún mensaje
!>          de error relacionado con LWORK por parte de XERBLA.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          = 1,...,N:
!>                La iteración QZ falló.  No se han calculado
!>                eigenvectores, pero ALPHAR(j), ALPHAI(j), y BETA(j)
!>                deberían ser correctos para j=INFO+1,...,N.
!>          > N:  =N+1: otro fallo que no sea la iteración QZ en DLAQZ0.
!>                =N+2: retorno de error de DTGEVC.
!
>
