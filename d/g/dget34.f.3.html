subroutine dget34 (doble precisión rmax, entero lmax, entero, dimensión( 2 ) ninfo, entero knt)

DGET34

Propósito:

!>
!> DGET34 prueba DLAEXC, una rutina para intercambiar bloques adyacentes (ya sea
!> de 1x1 o 2x2) en la diagonal de una matriz en forma de Schur real.
!> Por lo tanto, DLAEXC calcula una matriz ortogonal Q tal que
!>
!>     Q' * [ A B ] * Q  = [ C1 B1 ]
!>          [ 0 C ]        [ 0  A1 ]
!>
!> donde C1 es similar a C y A1 es similar a A. Se asume que tanto A como C
!> están en forma estándar (entradas diagonales iguales y
!> signos de diferencia en las entradas no diagonales) y A1 y C1 se devuelven con las
!> mismas propiedades.
!>
!> El código de prueba verifica estas últimas afirmaciones, así como que
!> el residuo en la ecuación anterior es pequeño.
!>

Parámetros

RMAX 
!>          RMAX es DOBLE PRECISIÓN
!>          Valor de la razón de prueba más grande.
!>

LMAX

!>          LMAX es ENTERO
!>          Número de ejemplo donde se alcanzó la razón de prueba más grande.
!>

NINFO

!>          NINFO es matriz ENTERA, dimensión (2)
!>          NINFO(J) es el número de ejemplos donde ocurrió INFO=J.
!>

KNT

!>          KNT es ENTERO
!>          Número total de ejemplos probados.
!>
