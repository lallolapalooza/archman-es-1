NAME

dtinitconf - Crea un archivo de configuración para DNSSEC-Tools

SYNOPSIS

dtinitconf [opciones]

DESCRIPCIÓN

El programa dtinitconf inicializa el archivo de configuración de DNSSEC-Tools. Por defecto, se crea el archivo de configuración real, aunque el usuario puede especificar el archivo creado. Los archivos existentes, ya sea el predeterminado o uno especificado por el usuario, no se sobrescriben a menos que el usuario lo indique explícitamente.

Cada campo de configuración puede especificarse individualmente en la línea de comandos. El usuario también será solicitado para los campos, con valores predeterminados tomados del módulo DNSSEC-Tools defaults.pm. Si se proporciona la opción -noprompt, se creará un archivo de configuración predeterminado (con las excepciones de los argumentos de línea de comandos).

Se crean entradas de configuración para varios programas BIND. Se buscan varias ubicaciones en el sistema para encontrar las ubicaciones de estos programas. Primero, se comprueban los directorios en la variable de entorno path; se guardan los nombres de los directorios que contienen los programas BIND. A continuación, se comprueban varias ubicaciones comunes para los programas BIND; de nuevo, se guardan los nombres de los directorios que contienen los programas BIND. Después de recopilar estos directorios, se presenta esta lista al usuario y puede elegir el conjunto deseado. Si no se encuentran directorios que contengan los programas BIND, se solicita al usuario la ubicación adecuada.

Si el directorio padre del archivo de configuración no existe, se intenta crear el directorio. La propiedad del nuevo directorio se establecerá en root para el propietario y dnssec para el grupo, asumiendo que existe el grupo dnssec. Las comprobaciones de escritibilidad para el directorio no se realizarán si se proporciona la opción -outfile.

OPCIONES

dtinitconf toma opciones que controlan el contenido del nuevo archivo de configuración de DNSSEC-Tools generado. Cada entrada de archivo de configuración tiene una opción de línea de comandos correspondiente. Las opciones, descritas a continuación, están ordenadas en grupos lógicos.

Opciones relacionadas con Claves

Estas opciones tratan diferentes aspectos de la creación y gestión de claves de cifrado.

-algorithm algoritmo
Selecciona el algoritmo criptográfico. El valor del algoritmo debe ser uno que sea reconocido por la versión instalada de dnssec-keygen.
-kskcount KSK-count
El número predeterminado de claves KSK que se crearán para una zona.
-ksklength longitudclave
La longitud predeterminada de la clave KSK a pasar a dnssec-keygen.
-ksklife vidaclave
La duración predeterminada de tiempo entre rotaciones de claves KSK. Esto se mide en segundos. Este valor debe estar dentro del rango de los valores minlife y maxlife.

Este valor se usa solo para la rotación de claves. Las claves no tienen una vida útil en ningún otro sentido.

-maxlife maxlifespan
La duración máxima de tiempo entre rotaciones de claves. Esto se mide en segundos. Los valores ksklife y zsklife deben ser no mayores que este valor.

Este valor se usa solo para la rotación de claves. Las claves no tienen una vida útil en ningún otro sentido.

-minlife minlifespan
La duración mínima de tiempo entre rotaciones de claves. Esto se mide en segundos. Los valores ksklife y zsklife deben ser no menores que este valor.

Este valor se usa solo para la rotación de claves. Las claves no tienen una vida útil en ningún otro sentido.

-zskcount ZSK-count
El número predeterminado de claves ZSK que se crearán para una zona.
-zsklength longitudclave
La longitud predeterminada de la clave ZSK a pasar a dnssec-keygen.
-zsklife vidaclave
La duración predeterminada de tiempo entre rotaciones de claves ZSK. Esto se mide en segundos. Este valor debe estar dentro del rango de los valores minlife y maxlife.

Este valor se usa solo para la rotación de claves. Las claves no tienen una vida útil en ningún otro sentido.

-random generadoraleatorio
El generador de dispositivos aleatorios a pasar a dnssec-keygen.

Opciones relacionadas con Zonas

Estas opciones tratan diferentes aspectos de la firma de zonas.

-endtime tiempofinal
El tiempo de expiración predeterminado de la zona a pasar a dnssec-signzone.

Opciones relacionadas con trustman

Estas opciones tratan diferentes aspectos de la ejecución de trustman.

-genroothints hintsraiz
Se creará un nuevo archivo root.hints en la ubicación especificada. dtinitconf requiere que el archivo no exista ya.

El archivo root.hints se obtiene de http://www.internic.net/zones/named.root. No se considera un error fatal si dtinitconf no puede obtener el archivo. En su lugar, se mostrará un mensaje de advertencia y la creación del archivo de configuración se continuará.

-ta-contact correo
La dirección de correo electrónico del administrador de trustman.
-ta-resolvconf archivoresolv
La ubicación del archivo resolv.conf.
-ta-smtpserver nombrehost
El servidor SMTP para el comando trustman.
-ta-tmpdir nombrehost
El directorio temporal para el comando trustman.

Opciones de BIND

Estas opciones tratan específicamente la funcionalidad proporcionada por BIND.

-rndc rdc-path
rndc es la ruta al comando rndc de BIND.

Opciones de DNSSEC-Tools

Estas opciones tratan específicamente la funcionalidad proporcionada por DNSSEC-Tools.

-admin direccioncorreo
admin es la dirección de correo electrónico del administrador de DNSSEC-Tools. Esta es la dirección predeterminada utilizada por la rutina dt_adminmail().
-archivedir directorio
directorio es el directorio de claves archivadas. Las claves de cifrado antiguas se mueven a este directorio, pero solo si se van a guardar y no borrar.
-autosign
Una bandera que indica que rollerd debería firmar automáticamente los archivos de zona que se encuentran más nuevos que su archivo de zona firmado. Si se especifica -noautosign, esto se establecerá en falso.
-binddir directorio
directorio es el directorio que contiene los programas BIND. Si se especifica la palabra reservada "path", entonces la existencia de los programas BIND no se verifica cuando dtinitconf se ejecuta. En su lugar, se buscarán los directorios PATH del usuario para los programas BIND cuando se ejecuten las herramientas DNSSEC.
-dtdir directorio
directorio es el directorio que contiene los programas DNSSEC-Tools. Si se especifica la palabra reservada "path", entonces la existencia de los programas DNSSEC

Opciones Otras

Estas opciones tratan diferentes aspectos de la configuración general.

-outfile archivo
El nombre del archivo de configuración a crear. Si no se especifica, se creará el archivo predeterminado.
-prompt
Forza el modo de solicitud de entrada, incluso si se proporciona -noprompt.
-quiet
Suprime los mensajes de advertencia y errores.
-version
Mostra la versión de dtinitconf y se sale.
-help
Mostra esta información de ayuda y se sale.

EJEMPLOS

El siguiente comando crea un archivo de configuración predeterminado sin solicitar al usuario:

dtinitconf -noprompt

Los programas de EC-Tools no se verifican cuando dtinitconf se ejecuta. En su lugar, se buscarán los programas de DNSSEC-Tools en los directorios del PATH del usuario cuando se ejecuten esas herramientas.
-entropy_msg
Un indicador que indica que zonesigner debe mostrar un mensaje sobre la generación de entropía. Esto depende principalmente de la implementación de la generación de números aleatorios del sistema.
-mailer-server host
El servidor de correo que será contactado por dt_adminmail(). Esto se pasa a Mail::Send.
-mailer-server mailtype
El tipo de correo que será contactado por dt_adminmail(). Esto se pasa a Mail::Mailer (por medio de Mail::Send.) Cualquier valor reconocido por Mail::Mailer puede usarse aquí.
-noentropy_msg
Un indicador que indica que zonesigner no debe mostrar un mensaje sobre la generación de entropía. Esto depende principalmente de la implementación de la generación de números aleatorios del sistema.
-roll-loadzone
-no-roll-loadzone
Indicadores que indican si rollerd debe hacer que el demonio DNS cargue las zonas.
-roll-logfile logfile
logfile es el archivo de registro del rollerd demonio.
-roll-loglevel loglevel
loglevel es el nivel de registro del rollerd demonio.
-roll-phasemsg length
length es la longitud predeterminada de los mensajes de registro relacionados con las fases utilizados por rollerd. Los valores válidos son "long" y "short", siendo "long" el valor predeterminado.

La longitud larga del mensaje significa que una descripción de la fase será incluida con algunos mensajes de registro. Por ejemplo, la forma larga de un mensaje sobre la fase 3 de rotación de ZSK se verá así: "ZSK phase 3 (Waiting for old zone data to expire from caches)".

La longitud corta del mensaje significa que una descripción de la fase no será incluida con algunos mensajes de registro. Por ejemplo, la forma corta de un mensaje sobre la fase 3 de rotación de ZSK se verá así: "ZSK phase 3".

-roll-sleeptime sleep-time
sleep-time es el tiempo de espera (sleep-time) del rollerd demonio.
-roll-username username
username es el usuario para el cual el rollerd demonio será ejecutado. Si esto es un nombre de usuario, debe corresponder a un uid válido; si es un uid, debe corresponder a un nombre de usuario válido.
-roll-logtz logtz
loglevel es la zona horaria de la marca de tiempo del mensaje para rollerd's logfile.
-zoneerrs error-count
error-count es el recuento máximo de errores para las zonas utilizadas por el rollerd demonio.
-savekeys
Un indicador que indica que las claves antiguas deben moverse al directorio de archivo.
-nosavekeys
Un indicador que indica que las claves antiguas no deben moverse al directorio de archivo, sino que se dejarán en su lugar.
-usegui
Un indicador que indica que la GUI para especificar las opciones de comando puede usarse.
-nousegui
Un indicador que indica que la GUI para especificar las opciones de comando no debe usarse.
-zoneparser parser-module
parser-module es el nombre del módulo de Perl que será utilizado para analizar los archivos de zona. El valor predeterminado está especificado en dnssec_tools_default().

dtinitconf Opciones

Estas opciones tratan específicamente con dtinitconf.

-outfile conffile
El archivo de configuración será escrito en conffile. Si esto no se proporciona, se usará el archivo de configuración predeterminado (como lo devuelve Net::DNS::SEC::Tools::conf::getconffile()).

Si conffile se proporciona como -, el nuevo archivo de configuración será escrito en la salida estándar.

conffile debe ser escribible.

-overwrite
Si -overwrite se especifica, los archivos de salida existentes pueden ser sobrescritos. Sin -overwrite, si se encuentra que el archivo de salida existe, entonces dtinitconf dará un mensaje de error y saldrá.
-noprompt
Si -noprompt se especifica, al usuario no se le pedirá ninguna entrada. El archivo de configuración será creado a partir de las opciones de la línea de comandos y los valores predeterminados de DNSSEC-Tools. Se harán suposiciones para las rutas de BIND, basadas en la variable de entorno PATH.

ADVERTENCIA: Después de usar la -noprompt opción, el archivo de configuración debe ser verificado para asegurarse de que los valores predeterminados son apropiados y aceptables para la instalación.

-template
Si -template se especifica, se crea un archivo de configuración predeterminado. Sin embargo, todas las entradas están comentadas.

Las únicas opciones de línea de comandos que pueden usarse en conjunto con -template son -outfile y -overwrite.

-edit
Si -edit se especifica, el archivo de salida será editado después de que haya sido creado. Se consulta la variable de entorno EDITOR para el editor a usar. Si la variable de entorno EDITOR no está definida, entonces el vi editor será usado.
-verbose
Proporciona salida detallada.
-Version
Muestra la información de versión de dtinitconf y el paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso y sale.
