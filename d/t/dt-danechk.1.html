DT-DANECHK(1) Comandos de usuario DT-DANECHK(1)

NOMBRE

dt-danechk - valida registros TLSA contra certificados SSL.

SINOPSIS

dt-danechk [opciones] NOMBRE_DOMINIO

DESCRIPCIÓN

dt-danechk es una herramienta de diagnóstico que se puede utilizar para probar la validez de un certificado SSL/TLS contra el registro TLSA publicado en el DNS. Para más información sobre TLSA y DANE, consulte RFC 6698.

OPCIONES

-h, --help
Muestra el uso y sale.
-l etiqueta, --label=etiqueta
Esta opción se puede usar para especificar la etiqueta de la política de validación. Si no se proporciona esta opción, se utiliza la política de validador predeterminada.
-x proto, --proto proto
Especifica el protocolo asociado con el certificado TLSA. Los valores posibles para el campo proto son:
  • tcp Protocolo TCP
  • udp Protocolo UDP
  • sc Protocolo SCTP (no soportado)

El valor predeterminado para proto es tcp.

-p puerto, --port=puerto
Especifica el puerto asociado con el certificado TLSA. El valor predeterminado para puerto es 443.
-o, --output=<nivel-depuracion>:<tipo-destino>[:<opciones-destino>]
<nivel-depuracion> es 1-7, correspondiente a los niveles de syslog ALERT-DEBUG <tipo-destino> es uno de file, net, syslog, stderr, stdout <opciones-destino> depende de <tipo-destino>
file:<nombre-archivo> (abierto en modo de añadir)
net[:<nombre-host>:<puerto-host>] (127.0.0.1:1053
syslog[:facilidad] (0-23 (predeterminado 1 USER))
-s, --sync
Realiza búsquedas síncronas. La opción predeterminada es realizar búsquedas asíncronas.
-v ARCHIVO, --dnsval-conf=ARCHIVO
Esta opción se puede usar para especificar la ubicación del archivo de configuración dnsval.conf.
-r ARCHIVO, --resolv-conf=ARCHIVO
Esta opción se puede usar para especificar la ubicación del archivo de configuración resolv.conf que contiene los servidores de nombres a utilizar para las búsquedas.
-i ARCHIVO, --root-hints=ARCHIVO
Esta opción se puede usar para especificar la ubicación del archivo de configuración root.hints, que contiene los servidores de nombres raíz. Esto solo se utiliza cuando no se encuentra ningún servidor de nombres y dt-validate debe realizar búsquedas recursivas por sí mismo.
-V, --version
Muestra la versión y sale.

PRE-REQUISITOS

libval
