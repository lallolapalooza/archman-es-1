Documentación de Función/Subrutina

subroutine dtrevc (character side, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer info)

DTREVC

Propósito:

!>
!> DTREVC calcula algunos o todos los vectores propios (eigenvectors) derechos y/o
!> izquierdos de una matriz cuasi-triangular superior real T.
!> Las matrices de este tipo se producen por la factorización de Schur de
!> una matriz general real: A = Q*T*Q**T, como la calculada por DHSEQR.
!>
!> Los vectores propios derechos x e izquierdos y de T correspondientes
!> a un valor propio w se definen por:
!>
!>    T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los valores propios no se introducen en esta rutina, sino que se leen directamente
!> de los bloques diagonales de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de los vectores propios derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una
!> matriz de entrada. Si Q es el factor ortogonal que reduce una matriz
!> A a la forma de Schur T, entonces Q*X y Q*Y son las matrices de los vectores
!> propios derechos e izquierdos de A.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  solo se calculan los vectores propios derechos;
!>          = 'L':  solo se calculan los vectores propios izquierdos;
!>          = 'B':  se calculan ambos, derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  se calculan todos los vectores propios derechos y/o izquierdos;
!>          = 'B':  se calculan todos los vectores propios derechos y/o izquierdos,
!>                  retrotransformados por las matrices en VR y/o VL;
!>          = 'S':  se calculan vectores propios derechos y/o izquierdos seleccionados,
!>                  como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a calcular.
!>          Si w(j) es un valor propio real, el vector propio real
!>          correspondiente se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          valor propio complejo, el vector propio complejo
!>          correspondiente se calcula si SELECT(j) o SELECT(j+1) es .TRUE., y
!>          a la salida, SELECT(j) se establece a .TRUE. y SELECT(j+1) se establece a
!>          .FALSE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array DOUBLE PRECISION, de dimensión (LDT,N)
!>          La matriz cuasi-triangular superior T en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array DOUBLE PRECISION, de dimensión (LDVL,MM)
!>          En la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (usualmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por DHSEQR).
!>          En la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           valores propios.
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real, y la segunda la imaginaria.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array DOUBLE PRECISION, de dimensión (LDVR,MM)
!>          En la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N por N (usualmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por DHSEQR).
!>          En la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           valores propios.
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la imaginaria.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios.
!>          Si HOWMNY = 'A' o 'B', M se establece a N.
!>          Cada vector propio real seleccionado ocupa una columna y cada
!>          vector propio complejo seleccionado ocupa dos columnas.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (3*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Documentación de Función/Subrutina

DTREVC calcula los autovectores derechos y/o izquierdos de una matriz triangular superior real T.

Los autovectores se calculan utilizando una transformación de similaridad Z * T * inv(Z), donde Z es una matriz de autovectores derechos, o inv(Y) * T * Y donde Y es una matriz de autovectores izquierdos.

La entrada es una matriz triangular superior T de tamaño N por N. La salida son las matrices VL y/o VR que contienen los autovectores correspondientes.

Los argumentos de entrada son:

  • SIDE: Indica si se calculan autovectores izquierdos, derechos o ambos.
    • 'L': Autovectores izquierdos.
    • 'R': Autovectores derechos.
    • 'B': Ambos autovectores izquierdos y derechos.
  • HOWMNY: Indica qué autovectores se calculan.
    • 'A': Todos los autovectores.
    • 'S': Autovectores correspondientes a los autovalores especificados en SELECT.
  • SELECT: Un array lógico de tamaño N. Si HOWMNY es 'S', SELECT(j) especifica si el autovalor j debe incluirse en el cálculo. Si HOWMNY es 'A', SELECT no se utiliza.
  • N: El orden de la matriz triangular T.
  • T: El array de entrada que contiene la matriz triangular superior.
  • LDT: El líder de fila de la matriz T.
  • VL: El array de salida que contiene los autovectores izquierdos.
  • LDVL: El líder de fila de la matriz VL.
  • VR: El array de salida que contiene los autovectores derechos.
  • LDVR: El líder de fila de la matriz VR.
  • MM: El número máximo de columnas que se pueden almacenar en VL y VR.
  • WORK: Un array de trabajo.
  • INFO: Entero. INFO = 0 si la ejecución fue exitosa.
