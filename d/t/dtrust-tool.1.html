NOMBRE

dtrust-tool - muestra información sobre tarjetas de firma D-Trust y elimina la protección de transporte

SINOPSIS

dtrust-tool [OPCIONES]

DESCRIPCIÓN

La utilidad dtrust-tool se utiliza para mostrar información sobre tarjetas de firma D-Trust y para eliminar la protección de transporte inicial.

OPCIONES

--check-transport-protection, -c

En el estado de entrega, la tarjeta está bloqueada por una llamada protección de transporte. Esta opción permite comprobar si la protección de transporte sigue activa. El PIN de Firma solo se puede utilizar si se elimina la protección de transporte.

Inicialmente, la protección de transporte debe estar intacta. Si recibe una tarjeta nueva y la protección de transporte ya estaba rota, no utilice esa tarjeta y póngase en contacto con el fabricante para obtener más información.

Si ha eliminado la protección de transporte, es normal que dtrust-tool informe de que la protección de transporte está rota. Este es el estado de funcionamiento normal. No significa que su tarjeta esté rota.

--help, -h

Muestra el mensaje de ayuda en pantalla.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--pin-status, -s

Muestra el estado de los diversos PIN. El PIN del titular de la tarjeta se utiliza para firmas avanzadas y descifrado. Solo está definido para tarjetas de firma, pero no para tarjetas de sellado. El PIN de Firma se utiliza para firmas cualificadas. Solo se puede utilizar si se desbloquea presentando el PIN de Transporte. Una vez utilizado el PIN de Transporte, no se puede volver a utilizar. El PUK se utiliza para desbloquear el PIN que se ha introducido incorrectamente varias veces.

--unlock-transport-protection, -u

Este comando elimina la protección de transporte. Primero solicita el PIN de Transporte y luego el nuevo valor del PIN de Firma dos veces.

--verbose, -v

Hace que dtrust-tool sea más detallado. Especifique esta opción varias veces para habilitar la salida de depuración en la biblioteca opensc.

--wait, -w

Hace que dtrust-tool espere a que se inserte el token en el lector.
