DTPMLQ

T

Propósito

: 
!>
!> DTPMQRT aplica una matriz ortogonal real Q obtenida de un
!>  reflector de bloque real H a una
!> matriz real general C, que consta de dos bloques A y B.
!
>

Parámetro

s
SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**T desde la izquierda;
!>          = 'R': aplica Q o Q**T desde la derecha.
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplica Q;
!>          = 'T':  Transponer, aplica Q**T.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz B. M >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de la matriz B. N >= 0.
!
>

K 
!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!
>

L 
!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles Adicionales.
!
>

M

B 
!>          MB es INTEGER
!>          El tamaño de bloque utilizado para el almacenamiento de T.  K >= MB >= 1.
!>          Este debe ser el mismo valor de MB utilizado para generar T
!>          en DTPLQT.
!
>

V 
!>          V es un array DOUBLE PRECISION, dimensión (LDV,K)
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, como lo devuelve
!>          DTPLQT en B.  Ver Detalles Adicionales.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= K.
!
>

T 
!>          T es un array DOUBLE PRECISION, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          como los devuelve DTPLQT, almacenados como una matriz MB-por-K.
!
>

LD

T 
!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= MB.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión
!>          (LDA,N) si SIDE = 'L' o
!>          (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A es sobrescrito por el bloque correspondiente de
!>          Q*C o Q**T*C o C*Q o C*Q**T.  Ver Detalles Adicionales.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B es sobrescrito por el bloque correspondiente de
!>          Q*C o Q**T*C o C*Q o C*Q**T.  Ver Detalles Adicionales.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          LDB >= max(1,M).
!
>

WOR

K 
!>          WORK es un array DOUBLE PRECISION. La dimensión de WORK es
!>           N*MB si SIDE = 'L', o  M*MB si SIDE = 'R'.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Detalles

Adicionales: 
!>
!>  Las columnas de la matriz pentagonal V contienen los reflectores elementales
!>  H(1), H(2), ..., H(K); V está compuesta de un bloque rectangular V1 y un
!>  bloque trapezoidal V2:
!>
!>        V = [V1] [V2].
!>
!>
!>  El tamaño del bloque trapezoidal V2 está determinado por el parámetro L,
!>  donde 0 <= L <= K; V2 es trapezoidal inferior, consistente en las primeras L
!>  filas de una matriz triangular superior de K-por-K.  Si L=K, V2 es triangular inferior;
!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si SIDE = 'L':  C = [A]  donde A es K-por-N,  B es M-por-N y V es K-por-M.
!>                      [B]
!>
!>  Si SIDE = 'R':  C = [A B]  donde A es M-por-K, B es M-por-N y V es K-por-N.
!>
!>  La matriz ortogonal real Q se forma a partir de V y T.
!>
!>  Si TRANS='N' y SIDE='L', C es reemplazada en la salida con Q * C.
!>
!>  Si TRANS='T' y SIDE='L', C es reemplazada en la salida con Q**T * C.
!>
!>  Si TRANS='N' y SIDE='R', C es reemplazada en la salida con C * Q.
!>
!>  Si TRANS='T' y SIDE='R', C es reemplazada en la salida con C * Q**T.
!
>
