DTGEVC

Documentación de Función/Subrutina

subrutina dtgevc (character side, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( lds, * ) s, integer lds, double precision, dimension( ldp, * ) p, integer ldp, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer info)

DTGEVC

Propósito:

!>
!> DTGEVC calcula algunos o todos los autovectores derechos y/o izquierdos de
!> un par de matrices reales (S,P), donde S es una matriz cuasitriangular
!> y P es una matriz triangular superior. Este tipo de pares de matrices es producido por
!> la factorización de Schur generalizada de un par de matrices (A,B):
!>
!>    A = Q*S*Z**T,  B = Q*P*Z**T
!>
!> tal como lo calcula DGGHRD + DHGEQZ.
!>
!> El autovector derecho x y el autovector izquierdo y de (S,P)
!> correspondientes a un autovalor w están definidos por:
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los autovalores no son una entrada de esta rutina, sino que se calculan
!> directamente a partir de los bloques diagonales de S y P.
!>
!> Esta rutina devuelve las matrices X y/o Y de autovectores derechos e izquierdos
!> de (S,P), o los productos Z*X y/o Q*Y,
!> donde Z y Q son matrices de entrada.
!> Si Q y Z son los factores ortogonales de la factorización de Schur generalizada
!> de un par de matrices (A,B), entonces Z*X y Q*Y
!> son las matrices de autovectores derechos e izquierdos de (A,B).
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo autovectores derechos;
!>          = 'L': calcular solo autovectores izquierdos;
!>          = 'B': calcular tanto autovectores derechos como izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular todos los autovectores derechos y/o izquierdos;
!>          = 'B': calcular todos los autovectores derechos y/o izquierdos,
!>                 retrotransformados por las matrices en VR y/o VL;
!>          = 'S': calcular los autovectores derechos y/o izquierdos seleccionados,
!>                 especificados por el arreglo lógico SELECT.
!>

SELECT

!>          SELECT es un arreglo LOGICAL, dimensión (N)
!>          Si HOWMNY='S', SELECT especifica los autovectores a ser
!>          calculados. Si w(j) es un autovalor real, el autovector real
!>          correspondiente se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son la parte real y la parte imaginaria de un
!>          autovalor complejo, el autovector complejo correspondiente
!>          se calcula si SELECT(j) o SELECT(j+1) es .TRUE.,
!>          y al salir SELECT(j) se establece en .TRUE. y SELECT(j+1) se
!>          establece en .FALSE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices S y P.  N >= 0.
!>

S

!>          S es un arreglo DOUBLE PRECISION, dimensión (LDS,N)
!>          La matriz cuasitriangular superior S de una factorización de Schur
!>          generalizada, tal como la calcula DHGEQZ.
!>

LDS

!>          LDS es INTEGER
!>          La dimensión principal del arreglo S.  LDS >= max(1,N).
!>

P

!>          P es un arreglo DOUBLE PRECISION, dimensión (LDP,N)
!>          La matriz triangular superior P de una factorización de Schur
!>          generalizada, tal como la calcula DHGEQZ.
!>          Los bloques diagonales de 2 por 2 de P que corresponden a bloques
!>          de 2 por 2 de S deben estar en forma diagonal positiva.
!>

LDP

!>          LDP es INTEGER
!>          La dimensión principal del arreglo P.  LDP >= max(1,N).
!>

VL

!>          VL es un arreglo DOUBLE PRECISION, dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (usualmente la matriz ortogonal Q
!>          de vectores de Schur izquierdos devueltos por DHGEQZ).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de autovectores izquierdos de (S,P);
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los autovectores izquierdos de (S,P) especificados por
!>                      SELECT, almacenados consecutivamente en las columnas de
!>                      VL, en el mismo orden que sus autovalores.
!>
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera conteniendo la
!>          parte real, y la segunda la parte imaginaria.
!>
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del arreglo VL.  LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un arreglo DOUBLE PRECISION, dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Z de N por N (usualmente la matriz ortogonal Z
!>          de vectores de Schur derechos devueltos por DHGEQZ).
!>
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de autovectores derechos de (S,P);
!>          si HOWMNY = 'B' o 'b', la matriz Z*X;
!>          si HOWMNY = 'S' o 's', los autovectores derechos de (S,P)
!>                      especificados por SELECT, almacenados consecutivamente en las
!>                      columnas de VR, en el mismo orden que sus
!>                      autovalores.
!>
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera conteniendo la
!>          parte real y la segunda la parte imaginaria.
!>
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del arreglo VR.  LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arreglos VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arreglos VL y/o VR realmente
!>          usadas para almacenar los autovectores. Si HOWMNY = 'A' o 'B', M
!>          se establece en N. Cada autovector real seleccionado ocupa una
!>          columna y cada autovector complejo seleccionado ocupa dos
!>          columnas.
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión (6*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  el bloque de 2 por 2 (INFO:INFO+1) no tiene un autovalor
!>                complejo.
!>

NAME

    
dtgevc.f - Wise vs. Columnwise Solution Methods:





    
SYNOPSIS

    

!>  ------- --  ---------- -------- -------
!>
!>  Finding a generalized eigenvector consists basically of solving the
!>  singular triangular system
!>
!>   (A - w B) x = 0     (for right) or:   (A - w B)**H y = 0  (for left)
!>
!>  Consider finding the i-th right eigenvector (assume all eigenvalues
!>  are real). The equation to be solved is:
!>       n                   i
!>  0 = sum  C(j,k) v(k)  = sum  C(j,k) v(k)     for j = i,. . .,1
!>      k=j                 k=j
!>
!>  where  C = (A - w B)  (The components v(i+1:n) are 0.)
!>
!>  The  method is:
!>
!>  (1)  v(i) := 1
!>  for j = i-1,. . .,1:
!>                          i
!>      (2) compute  s = - sum C(j,k) v(k)   and
!>                        k=j+1
!>
!>      (3) v(j) := s / C(j,j)
!>
!>  Step 2 is sometimes called the  step, since it is an
!>  inner product between the j-th row and the portion of the eigenvector
!>  that has been computed so far.
!>
!>  The  method consists basically in doing the sums
!>  for all the rows in parallel.  As each v(j) is computed, the
!>  contribution of v(j) times the j-th column of C is added to the
!>  partial sums.  Since FORTRAN arrays are stored columnwise, this has
!>  the advantage that at each step, the elements of C that are accessed
!>  are adjacent to one another, whereas with the rowwise method, the
!>  elements accessed at a step are spaced LDS (and LDP) words apart.
!>
!>  When finding left eigenvectors, the matrix in question is the
!>  transpose of the one in storage, so the rowwise method then
!>  actually accesses columns of A and B at each step, and so is the
!>  preferred method.
!>
