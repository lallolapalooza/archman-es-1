NOMBRE

dtck - Comprueba la validez de los archivos de datos de DNSSEC-Tools.

SINOPSIS

dtck [opciones] [archivo_config_dtck]

DESCRIPCIÓN

dtck comprueba los archivos de datos de DNSSEC-Tools para determinar si las entradas son válidas. dtck comprueba la validez de los archivos de configuración de DNSSEC-Tools, archivos rollrec y archivos keyrec. No realiza la comprobación de archivos por sí mismo, sino que ejecuta programas de comprobación específicos para cada tipo de archivo de datos.

Se consulta un archivo de configuración de dtck para determinar los archivos a comprobar. Este archivo lista los archivos de datos de DNSSEC-Tools y sus tipos. Si no se proporciona un archivo de configuración de dtck en la línea de comandos, dtck solo comprobará el archivo de configuración de DNSSEC-Tools. Esto es equivalente a ejecutar dtconfchk directamente.

ARCHIVO DE CONFIGURACIÓN DTCK

Un archivo de configuración de dtck contiene una lista de los archivos que serán comprobados por dtck. Excepto los comentarios, cada línea tiene el siguiente formato:

palabra_clave archivo directorio

palabra_clave es una de las siguientes: "config", "rollrec" o "keyrec". archivo es la ruta del archivo a comprobar. directorio es el nombre del directorio que contiene archivo y es opcional.

El archivo de configuración de dtck contiene los siguientes tipos de registros:

config
Estas líneas definen los archivos de configuración de DNSSEC-Tools que serán comprobados. El programa dtconfchk se utilizará para verificar estos archivos.
rollrec
Estas líneas definen los archivos rollrec que serán comprobados. El programa rollchk se utilizará para verificar estos archivos.
keyrec
Estas líneas definen los archivos keyrec que serán comprobados. El programa krfcheck se utilizará para verificar estos archivos.
comentarios
Cualquier línea que comience con un octothorpe (#) son líneas de comentario y se ignoran.

OPCIONES

dtck toma dos tipos de opciones. Las opciones del primer tipo son manejadas directamente por dtck, controlando su salida y procesamiento. Las opciones del segundo tipo se pasan a los programas de comprobación de archivos y no son manejadas adicionalmente por dtck.

Opciones Manejadas por dtck

-defcon
Esta opción indica a dtck que añada el archivo de configuración predeterminado de DNSSEC-Tools a la lista de archivos de configuración a comprobar.
-list
Los nombres de los archivos se listarán a medida que se comprueban.
-pretty
Se añadirá una salida aclaratoria a la salida de dtck y de los programas de comprobación de archivos.
-help
Muestra un mensaje de uso.

Opciones No Manejadas por dtck

-count
Los programas de comprobación de archivos mostrarán un recuento final de errores.
-quiet
El programa de comprobación de archivos no producirá ninguna salida.
-verbose
El programa de comprobación de archivos proporcionará una salida detallada.
-Version
Muestra la información de la versión de dtck y del paquete DNSSEC-Tools.
