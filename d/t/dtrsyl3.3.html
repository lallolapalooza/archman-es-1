subrutina dtrsyl3 (character trana, character tranb, integer isgn, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldc, * ) c, integer ldc, double precision scale, integer, dimension( * ) iwork, integer liwork, double precision, dimension( ldswork, * ) swork, integer ldswork, integer

info)

DTRSYL

3

Propósito

: 
!>
!>  DTRSYL3 resuelve la ecuación matricial de Sylvester real:
!>
!>     op(A)*X + X*op(B) = scale*C o
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  donde op(A) = A o A**T, y A y B son ambas cuasi-triangulares
!>  superiores. A es M-por-M y B es N-por-N; el lado derecho C y
!>  la solución X son M-por-N; y scale es un factor de escala de
!>  salida, establecido <= 1 para evitar desbordamiento en X.
!>
!>  A y B deben estar en forma canónica de Schur (como la devuelta
!>  por DHSEQR), es decir, triangular por bloques superior con bloques
!>  diagonales de 1-por-1 y 2-por-2; cada bloque diagonal de 2-por-2
!>  tiene sus elementos diagonales iguales y sus elementos fuera de la
!>  diagonal de signo opuesto.
!>
!>  Esta es la versión por bloques del algoritmo.
!
>

Parámetro

s
TRANA 
!>          TRANA es CHARACTER*1
!>          Especifica la opción op(A):
!>          = 'N': op(A) = A    (Sin transponer)
!>          = 'T': op(A) = A**T (Transponer)
!>          = 'C': op(A) = A**H (Transpuesta conjugada = Transponer)
!
>

TRAN

B 
!>          TRANB es CHARACTER*1
!>          Especifica la opción op(B):
!>          = 'N': op(B) = B    (Sin transponer)
!>          = 'T': op(B) = B**T (Transponer)
!>          = 'C': op(B) = B**H (Transpuesta conjugada = Transponer)
!
>

ISG

N 
!>          ISGN es INTEGER
!>          Especifica el signo en la ecuación:
!>          = +1: resolver op(A)*X + X*op(B) = scale*C
!>          = -1: resolver op(A)*X - X*op(B) = scale*C
!
>

M 
!>          M es INTEGER
!>          El orden de la matriz A, y el número de filas en las
!>          matrices X y C. M >= 0.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz B, y el número de columnas en las
!>          matrices X y C. N >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,M)
!>          La matriz cuasi-triangular superior A, en forma canónica de Schur.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          La matriz cuasi-triangular superior B, en forma canónica de Schur.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!
>

C 
!>          C es un array DOUBLE PRECISION, dimensión (LDC,N)
!>          En la entrada, la matriz del lado derecho C de M-por-N.
!>          En la salida, C es sobrescrita por la matriz solución X.
!
>

LD

C 
!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M)
!
>

SCAL

E 
!>          SCALE es DOUBLE PRECISION
!>          El factor de escala, scale, establecido <= 1 para evitar desbordamiento en X.
!
>

IWOR

K 
!>          IWORK es un array INTEGER, dimensión (MAX(1,LIWORK))
!>          En la salida, si INFO = 0, IWORK(1) devuelve el LIWORK óptimo.
!
>

LIWOR

K 
!>          IWORK es INTEGER
!>          La dimensión del array IWORK. LIWORK >=  ((M + NB - 1) / NB + 1)
!>          + ((N + NB - 1) / NB + 1), donde NB es el tamaño de bloque óptimo.
!>
!>          Si LIWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula la dimensión óptima del array IWORK,
!>          devuelve este valor como la primera entrada del array IWORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LIWORK.
!
>

SWOR

K 
!>          SWORK es un array DOUBLE PRECISION, dimensión (MAX(2, ROWS),
!>          MAX(1,COLS)).
!>          En la salida, si INFO = 0, SWORK(1) devuelve el valor óptimo ROWS
!>          y SWORK(2) devuelve el COLS óptimo.
!
>

LDSWOR

K 
!>          LDSWORK es INTEGER
!>          LDSWORK >= MAX(2,ROWS), donde ROWS = ((M + NB - 1) / NB + 1)
!>          y NB es el tamaño de bloque óptimo.
!>
!>          Si LDSWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula las dimensiones óptimas de la matriz SWORK,
!>          devuelve estos valores como la primera y segunda entrada de la matriz
!>          SWORK, y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          = 1: A y B tienen eigenvalores comunes o muy cercanos; se usaron
!>               valores perturbados para resolver la ecuación (pero las matrices
!>               A y B no se modifican).
!
>
