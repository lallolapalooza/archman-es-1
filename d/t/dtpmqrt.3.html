subrutina dtpmqrt (lado de caracteres, trans de caracteres, entero m, entero n, entero k, entero l, entero nb, doble precisión, dimensión(ldv, *) v, entero ldv, doble precisión, dimensión(ldt, *) t, entero ldt, doble precisión, dimensión(lda, *) a, entero lda, doble precisión, dimensión(ldb, *) b, entero ldb, doble precisión, dimensión(*) trabajo, entero info)

DTPMQRT

Propósito:

!>
!> DTPMQRT aplica una matriz ortogonal real Q obtenida de un reflector
!>  de bloque real H a una matriz real general C, que consta de dos bloques A y B.
!>

Parámetros

LADO 
!>          LADO es CHARACTER*1
!>          = 'L': aplicar Q o Q**T desde la Izquierda;
!>          = 'R': aplicar Q o Q**T desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'T':  Transpuesta, aplicar Q**T.
!>

M

!>          M es ENTERO
!>          El número de filas de la matriz B. M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz B. N >= 0.
!>

K

!>          K es ENTERO
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>

L

!>          L es ENTERO
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles Adicionales.
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= NB >= 1.
!>          Debe ser el mismo valor de NB utilizado para generar T
!>          en CTPQRT.
!>

V

!>          V es una matriz DOUBLE PRECISION, dimensión (LDV,K)
!>          La columna i debe contener el vector que define el reflector
!>          elemental H(i), para i = 1,2,...,k, tal como lo devuelve
!>          CTPQRT en B.  Ver Detalles Adicionales.
!>

LDV

!>          LDV es ENTERO
!>          La dimensión principal de la matriz V.
!>          Si LADO = 'L', LDV >= max(1,M);
!>          Si LADO = 'R', LDV >= max(1,N).
!>

T

!>          T es una matriz DOUBLE PRECISION, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como los devuelve CTPQRT, almacenados como una matriz NB por K.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal de la matriz T.  LDT >= NB.
!>

A

!>          A es una matriz DOUBLE PRECISION, dimensión
!>          (LDA,N) si LADO = 'L' o
!>          (LDA,K) si LADO = 'R'
!>          En la entrada, la matriz A de K por N o M por K.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**T*C o C*Q o C*Q**T.  Ver Detalles Adicionales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.
!>          Si LADO = 'L', LDA >= max(1,K);
!>          Si LADO = 'R', LDA >= max(1,M).
!>

B

!>          B es una matriz DOUBLE PRECISION, dimensión (LDB,N)
!>          En la entrada, la matriz B de M por N.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**T*C o C*Q o C*Q**T.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal de la matriz B.
!>          LDB >= max(1,M).
!>

TRABAJO

!>          TRABAJO es una matriz DOUBLE PRECISION. La dimensión de TRABAJO es
!>           N*NB si LADO = 'L', o  M*NB si LADO = 'R'.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!> Las columnas de la matriz pentagonal V contienen los reflectores
!> elementales H(1), H(2), ..., H(K); V está compuesta por un bloque rectangular V1 y un
!> bloque trapezoidal V2:
!>
!>        V = [V1]
!>            [V2].
!>
!> El tamaño del bloque trapezoidal V2 está determinado por el parámetro L,
!> donde 0 <= L <= K; V2 es trapezoidal superior, que consta de las primeras L
!> filas de una matriz triangular superior K por K.  Si L=K, V2 es triangular superior;
!> si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!> Si LADO = 'L':  C = [A]  donde A es K por N,  B es M por N y V es M por K.
!>                      [B]
!>
!> Si LADO = 'R':  C = [A B]  donde A es M por K, B es M por N y V es N por K.
!>
!> La matriz ortogonal real Q se forma a partir de V y T.
!>
!> Si TRANS='N' y LADO='L', C se reemplaza en la salida con Q * C.
!>
!> Si TRANS='T' y LADO='L', C se reemplaza en la salida con Q**T * C.
!>
!> Si TRANS='N' y LADO='R', C se reemplaza en la salida con C * Q.
!>
!> Si TRANS='T' y LADO='R', C se reemplaza en la salida con C * Q**T.
!>
