DTREVC3

Documentación de Función/Subrutina

subrutina dtrevc3 (character side, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer lwork, integer info)

DTREVC3

Propósito:

!>
!> DTREVC3 calcula algunos o todos los autovectores derechos y/o
!> izquierdos de una matriz real cuasitriangular superior T.
!> Este tipo de matrices son producidas por la factorización de Schur de
!> una matriz real general:  A = Q*T*Q**T, como lo calcula DHSEQR.
!>
!> El autovector derecho x y el autovector izquierdo y de T correspondientes
!> a un autovalor w están definidos por:
!>
!>    T*x = w*x,     (y**T)*T = w*(y**T)
!>
!> donde y**T denota la transpuesta del vector y.
!> Los autovalores no se ingresan a esta rutina, sino que se leen directamente
!> de los bloques diagonales de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de autovectores derechos e
!> izquierdos de T, o los productos Q*X y/o Q*Y, donde Q es una
!> matriz de entrada. Si Q es el factor ortogonal que reduce una matriz
!> A a su forma de Schur T, entonces Q*X y Q*Y son las matrices de autovectores
!> derechos e izquierdos de A.
!>
!> Esto utiliza una versión de BLAS de Nivel 3 de la transformación inversa.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  calcular solo autovectores derechos;
!>          = 'L':  calcular solo autovectores izquierdos;
!>          = 'B':  calcular tanto autovectores derechos como izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  calcular todos los autovectores derechos y/o izquierdos;
!>          = 'B':  calcular todos los autovectores derechos y/o izquierdos,
!>                  transformados inversamente por las matrices en VR y/o VL;
!>          = 'S':  calcular autovectores derechos y/o izquierdos seleccionados,
!>                  como lo indica el arreglo lógico SELECT.
!>

SELECT

!>          SELECT es un arreglo LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los autovectores a ser
!>          calculados.
!>          Si w(j) es un autovalor real, el autovector real correspondiente
!>          se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          autovalor complejo, el autovector complejo correspondiente se
!>          calcula si SELECT(j) o SELECT(j+1) es .TRUE., y
!>          al salir SELECT(j) se establece en .TRUE. y SELECT(j+1) se establece en
!>          .FALSE..
!>          No se referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un arreglo DOUBLE PRECISION, dimensión (LDT,N)
!>          La matriz cuasitriangular superior T en forma canónica de Schur.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del arreglo T. LDT >= max(1,N).
!>

VL

!>          VL es un arreglo DOUBLE PRECISION, dimensión (LDVL,MM)
!>          A la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (usualmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por DHSEQR).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de autovectores izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los autovectores izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           autovalores.
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera conteniendo la
!>          parte real, y la segunda la parte imaginaria.
!>          No se referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del arreglo VL.
!>          LDVL >= 1, y si SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un arreglo DOUBLE PRECISION, dimensión (LDVR,MM)
!>          A la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N por N (usualmente la matriz ortogonal Q
!>          de vectores de Schur devuelta por DHSEQR).
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de autovectores derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los autovectores derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           autovalores.
!>          Un autovector complejo correspondiente a un autovalor complejo
!>          se almacena en dos columnas consecutivas, la primera conteniendo la
!>          parte real y la segunda la parte imaginaria.
!>          No se referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del arreglo VR.
!>          LDVR >= 1, y si SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arreglos VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arreglos VL y/o VR realmente
!>          usadas para almacenar los autovectores.
!>          Si HOWMNY = 'A' o 'B', M se establece en N.
!>          Cada autovector real seleccionado ocupa una columna y cada
!>          autovector complejo seleccionado ocupa dos columnas.
!>

WORK

!>          WORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK >= max(1,3*N).
!>          Para un rendimiento óptimo, LWORK >= N + 2*N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
