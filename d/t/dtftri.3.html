Propósito

!> !> DTFTRI calcula la inversa de una matriz triangular A almacenada en formato RFP. !> !> Esta es una versión del algoritmo

de nivel 3 de BLAS. !>

s

!> TRANSR es CHARACTER*1 !> = 'N': Se almacena el TRANSR Normal de RFP A; !> = 'T': Se almacena el TRANSR Transpuesto

de RFP A. !>
UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!
>

DIA

G 
!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.

>

N !> N es INTEGER !> El orden de la matriz

A. N >= 0. !> A 
!>          A es un array DOUBLE PRECISION, dimensión (0:nt-1);
!>          nt=N*(N+1)/2. En la entrada, el factor triangular de una matriz
!>          Hermitiana Definida Positiva A en formato RFP. El formato RFP es
!>          descrito por TRANSR, UPLO, y N como sigue: Si TRANSR = 'N'
!>          entonces RFP A es (0:N,0:k-1) cuando N es par; k=N/2. RFP A es
!>          (0:N-1,0:k) cuando N es impar; k=N/2. SI TRANSR = 'T' entonces RFP es
!>          la transpuesta de RFP A como se definió cuando
!>          TRANSR = 'N'. El contenido de RFP A es definido por UPLO como
!>          sigue: Si UPLO = 'U' el RFP A contiene los nt elementos de
!>          A empaquetada superior; Si UPLO = 'L' el RFP A contiene los nt
!>          elementos de A empaquetada inferior. El LDA de RFP A es (N+1)/2 cuando
!>          TRANSR = 'T'. Cuando TRANSR es 'N' el LDA es N+1 cuando N es
!>          par y N es impar. Vea la Nota más abajo para más detalles.
!>
!>          En la salida, la inversa (triangular) de la matriz original, en
!>          el mismo formato de almacenamiento.
!>

IN

FO 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = i, A(i,i) es exactamente cero.  La matriz
!>               triangular es singular y su inversa no puede ser calculada.
!>
