subroutine dtgsen (integer ijob, logical wantq, logical wantz, logical, dimension( * ) select, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldz, * ) z, integer ldz, integer m, double precision pl, double precision pr, double precision, dimension( * ) dif, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer liwork, integer info)

DTGSEN

Propósito

!>
!> DTGSEN reordena la descomposición de Schur generalizada real de un par de
!> matrices reales (A, B) (en términos de una transformación de equivalencia
!> ortonormal Q**T * (A, B) * Z), de modo que un clúster seleccionado de
!> autovalores aparezca en los bloques diagonales principales de la matriz
!> cuasi-triangular superior A y la matriz triangular superior B. Las columnas
!> principales de Q y Z forman bases ortonormales de los correspondientes
!> subespacios de autoespacios (deflating subspaces) izquierdo y derecho. (A, B)
!> deben estar en forma canónica de Schur generalizada real (como la devuelta
!> por DGGES), es decir, A es de bloque triangular superior con bloques diagonales
!> de 1x1 y 2x2. B es triangular superior.
!>
!> DTGSEN también calcula los autovalores generalizados
!>
!>             w(j) = (ALPHAR(j) + i*ALPHAI(j))/BETA(j)
!>
!> del par de matrices reordenado (A, B).
!>
!> Opcionalmente, DTGSEN calcula estimaciones de los recíprocos de los números
!> de condición para autovalores y autoespacios. Estos son Difu[(A11,B11),
!> (A22,B22)] y Difl[(A11,B11), (A22,B22)], es decir, la separación(es) entre
!> los pares de matrices (A11, B11) y (A22,B22) que corresponden al clúster
!> seleccionado y a los autovalores fuera del clúster, respectivamente, y las
!> normas de sobre los autoespacios izquierdo y derecho con respecto al clúster
!> seleccionado en el bloque (1,1).
!>

Parámetros

IJOB 
!>          IJOB es INTEGER
!>          Especifica si se requieren números de condición para el clúster de
!>          autovalores (PL y PR) o los subespacios deflacionarios (Difu y Difl):
!>           =0: Solo reordena respecto a SELECT. Sin extras.
!>           =1: Recíprocos de las normas de sobre los autoespacios izquierdo y
!>               derecho con respecto al clúster seleccionado (PL y PR).
!>           =2: Cotas superiores para Difu y Difl. Estimación basada en la norma F
!>               (DIF(1:2)).
!>           =3: Estimación de Difu y Difl. Estimación basada en la norma 1
!>               (DIF(1:2)).
!>               Aproximadamente 5 veces más caro que IJOB = 2.
!>           =4: Calcula PL, PR y DIF (es decir, 0, 1 y 2 anteriores): Versión
!>               económica para obtenerlo todo.
!>           =5: Calcula PL, PR y DIF (es decir, 0, 1 y 3 anteriores)
!>

WANTQ

!>          WANTQ es LOGICAL
!>          .TRUE. : actualiza la matriz de transformación izquierda Q;
!>          .FALSE.: no actualiza Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualiza la matriz de transformación derecha Z;
!>          .FALSE.: no actualiza Z.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          SELECT especifica los autovalores en el clúster seleccionado.
!>          Para seleccionar un autovalor real w(j), SELECT(j) debe establecerse
!>          a .TRUE.. Para seleccionar un par conjugado complejo de autovalores
!>          w(j) y w(j+1), correspondiente a un bloque diagonal de 2x2,
!>          ya sea SELECT(j) o SELECT(j+1) o ambos deben establecerse a
!>          .TRUE.; un par conjugado complejo de autovalores debe ser
!>          incluido en el clúster o excluido.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión(LDA,N)
!>          En la entrada, la matriz A cuasi-triangular superior, con (A, B) en
!>          forma canónica de Schur generalizada real.
!>          En la salida, A es sobrescrita por la matriz reordenada A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, de dimensión(LDB,N)
!>          En la entrada, la matriz B triangular superior, con (A, B) en
!>          forma canónica de Schur generalizada real.
!>          En la salida, B es sobrescrita por la matriz reordenada B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

ALPHAR

!>          ALPHAR es un array DOUBLE PRECISION, de dimensión (N)
!>

ALPHAI

!>          ALPHAI es un array DOUBLE PRECISION, de dimensión (N)
!>

BETA

!>          BETA es un array DOUBLE PRECISION, de dimensión (N)
!>
!>          En la salida, (ALPHAR(j) + ALPHAI(j)*i)/BETA(j), j=1,...,N, serán
!>          los autovalores generalizados. ALPHAR(j) + ALPHAI(j)*i
!>          y BETA(j),j=1,...,N son las diagonales de la forma de Schur compleja
!>          (S,T) que resultaría si los bloques diagonales de 2x2 de la forma
!>          generalizada real de Schur de (A,B) se redujeran aún más a forma
!>          triangular usando transformaciones unitarias complejas.
!>          Si ALPHAI(j) es cero, entonces el j-ésimo autovalor es real; si
!>          es positivo, entonces el j-ésimo y (j+1)-ésimo autovalores son un
!>          par conjugado complejo, con ALPHAI(j+1) negativo.
!>

Q

!>          Q es un array DOUBLE PRECISION, de dimensión (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., Q es una matriz N por N.
!>          En la salida, Q ha sido postmultiplicada por la matriz de
!>          transformación ortogonal izquierda que reordena (A, B); Las M
!>          columnas principales de Q forman bases ortonormales para el par
!>          seleccionado de autoespacios (subespacios deflacionarios) izquierdos.
!>          Si WANTQ = .FALSE., Q no se utiliza.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1;
!>          y si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es un array DOUBLE PRECISION, de dimensión (LDZ,N)
!>          En la entrada, si WANTZ = .TRUE., Z es una matriz N por N.
!>          En la salida, Z ha sido postmultiplicada por la matriz de
!>          transformación ortogonal izquierda que reordena (A, B); Las M
!>          columnas principales de Z forman bases ortonormales para el par
!>          seleccionado de autoespacios (subespacios deflacionarios) izquierdos.
!>          Si WANTZ = .FALSE., Z no se utiliza.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1;
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

M

!>          M es INTEGER
!>          La dimensión del par seleccionado de autoespacios (subespacios
!>          deflacionarios) izquierdos y derechos. 0 <= M <= N.
!>

PL

!>          PL es DOUBLE PRECISION
!>          Si IJOB >= 1, PL es una estimación del recíproco del número de
!>          condición de los autovalores seleccionados.
!>

PR

!>          PR es DOUBLE PRECISION
!>          Si IJOB >= 1, PR es una estimación del recíproco del número de
!>          condición de los autovalores no seleccionados.
!>

DIF

!>          DIF es DOUBLE PRECISION array, dimension (2)
!>          Si IJOB = 2 o 3, DIF(1) es una estimación superior de Difu[(A11,B11),
!>          (A22,B22)] y DIF(2) es una estimación superior de Difl[(A11,B11),
!>          (A22,B22)].
!>          Si IJOB = 4 o 5, DIF(1) y DIF(2) contienen los recíprocos de las
!>          normas de los autoespacios izquierdo y derecho, y DIF(3) es el
!>          número de autovalores seleccionados.
!>

WORK

!>          WORK es DOUBLE PRECISION array, dimension (LWORK)
!>          En la salida, WORK(1) contiene el valor mínimo de LWORK requerido.
!>

LWORK

!>          LWORK es INTEGER
!>          El tamaño del array WORK. LWORK >= 1.
!>          Para la mejor performance, LWORK debería ser al menos
!>          max(1, 2*N, N + 2*NEIG), donde NEIG es el número de autovalores
!>          seleccionados.
!>

IWORK

!>          IWORK es INTEGER array, dimension (LIWORK)
!>

LIWORK

!>          LIWORK es INTEGER
!>          El tamaño del array IWORK. LIWORK >= max(1, N).
!>

INFO

!>          INFO es INTEGER
!>          =0: éxito.
!>          <0: si INFO = -i, la i-ésima argumento no válido fue encontrado.
!>          >0: el algoritmo de reordenamiento falló al converger. Los resultados
!>              no son confiables.
!>

NAME

dtgsen - dtgsen

SYNOPSIS

 subroutine dtgsen( ITYPE, EJOB, JOB, M, N, A, LDA, B, LDB, Q, LDQ, Z, LDZ, PL, PR, DIF, WORK, LWORK, IWORK, LIWORK, INFO )

      DOUBLE PRECISION A( LDA, * ), B( LDB, * ), Q( LDQ, * ), Z( LDZ, * )
      DOUBLE PRECISION PL, PR, DIF( * )
      DOUBLE PRECISION WORK( * )
      INTEGER ITYPE, EJOB, JOB, M, N, LDA, LDB, LDQ, LDZ, LWORK, IWORK( * ), LIWORK, INFO

Function/Subroutine Documentation

This subroutine computes the Schur vectors corresponding to the selected eigenvalues and Schur form of a regular matrix pair (A, B).

Description:

The function computes the eigenvectors and Schur form of a regular matrix pair (A, B) with respect to the selected cluster of eigenvalues.

Let A and B be N-by-N matrices. The generalized Schur decomposition is defined as:

A = Q * S * ZT

B = Q * T * ZT

where Q and Z are orthogonal matrices, and S and T are upper triangular matrices.

DTGSEN computes the Schur vectors and Schur form for the selected eigenvalues. It also computes reciprocal condition numbers for the left and right eigenspaces and estimates of the error in the computed eigenvalues.

Arguments:

ITYPE

INTEGER. Specifies the form of the Schur decomposition.

ITYPE = 0 for the standard generalized Schur decomposition.

ITYPE = 1 for the generalized real Schur decomposition.

EJOB

INTEGER. Specifies the type of eigenvalue selection.

EJOB = 0: Compute all eigenvalues.

EJOB = 1: Compute eigenvalues specified by JOB.

EJOB = 2: Compute eigenvalues to achieve a specified separation.

EJOB = 3: Compute eigenvalues to achieve a specified block size.

JOB

CHARACTER*1. Specifies the type of eigenvector computation.

JOB = 'N': Eigenvectors/Schur vectors are not computed.

JOB = 'E': Eigenvectors/Schur vectors are computed.

M

INTEGER. The number of selected eigenvalues. This argument is relevant only when EJOB = 1, 2, or 3.

N

INTEGER. The order of the matrices A and B.

A

DOUBLE PRECISION array, dimension (LDA, N).

On entry, A contains the upper triangular matrix from the generalized Schur decomposition.

On exit, A is overwritten by the reordered generalized Schur form.

LDA

INTEGER. The leading dimension of the array A.

B

DOUBLE PRECISION array, dimension (LDB, N).

On entry, B contains the upper triangular matrix from the generalized Schur decomposition.

On exit, B is overwritten by the reordered generalized Schur form.

LDB

INTEGER. The leading dimension of the array B.

Q

DOUBLE PRECISION array, dimension (LDQ, N).

On entry, Q contains the orthogonal matrix from the generalized Schur decomposition.

On exit, Q is updated to contain the product Q*U, where U is the orthogonal matrix that reorders the eigenvalues.

LDQ

INTEGER. The leading dimension of the array Q.

Z

DOUBLE PRECISION array, dimension (LDZ, N).

On entry, Z contains the orthogonal matrix from the generalized Schur decomposition.

On exit, Z is updated to contain the product Z*W, where W is the orthogonal matrix that reorders the eigenvalues.

LDZ

INTEGER. The leading dimension of the array Z.

PL

DOUBLE PRECISION.

If IJOB = 1, 4 or 5, PL, PR are lower bounds on the reciprocal of the norm of the left and right eigenspaces with respect to the selected cluster. 0 < PL, PR <= 1.

If M = 0 or M = N, PL = PR = 1.

If IJOB = 0, 2 or 3, PL and PR are not referenced.

PR

DOUBLE PRECISION.

See description for PL.

DIF

DOUBLE PRECISION array, dimension (2).

If IJOB >= 2, DIF(1:2) store the estimates of Difu and Difl.

If IJOB = 2 or 4, DIF(1:2) are F-norm-based upper bounds on Difu and Difl. If IJOB = 3 or 5, DIF(1:2) are 1-norm-based estimates of Difu and Difl.

If M = 0 or N, DIF(1:2) = F-norm([A, B]).

If IJOB = 0 or 1, DIF is not referenced.

WORK

DOUBLE PRECISION array, dimension (MAX(1,LWORK)).

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

INTEGER.

The dimension of the array WORK. LWORK >= 4*N+16.

If IJOB = 1, 2 or 4, LWORK >= MAX(4*N+16, 2*M*(N-M)).

If IJOB = 3 or 5, LWORK >= MAX(4*N+16, 4*M*(N-M)).

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

IWORK

INTEGER array, dimension (MAX(1,LIWORK)).

On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.

LIWORK

INTEGER.

The dimension of the array IWORK. LIWORK >= 1.

If IJOB = 1, 2 or 4, LIWORK >= N+6.

If IJOB = 3 or 5, LIWORK >= MAX(2*M*(N-M), N+6).

If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the IWORK array, returns this value as the first entry of the IWORK array, and no error message related to LIWORK is issued by XERBLA.

INFO

INTEGER.

  • =0: Successful exit.
  • <0: If INFO = -i, the i-th argument had an illegal value.
  • =1: Reordering of (A, B) failed because the transformed matrix pair (A, B) would be too far from generalized Schur form; the problem is very ill-conditioned. (A, B) may have been partially reordered. If requested, 0 is returned in DIF(*), PL and PR.

Further Details:

!>
!>  DTGSEN first collects the selected eigenvalues by computing
!>  orthogonal U and W that move them to the top left corner of (A, B).
!>  In other words, the selected eigenvalues are the eigenvalues of
!>  (A11, B11) in:
!>
!>              U**T*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!>  where N = n1+n2 and U**T means the transpose of U. The first n1 columns
!>  of U and W span the specified pair of left and right eigenspaces
!!>  (deflating subspaces) of (A, B).
!>
!>  If (A, B) has been obtained from the generalized real Schur
!>  decomposition of a matrix pair (C, D) = Q*(A, B)*Z**T, then the
!>  reordered generalized real Schur form of (C, D) is given by
!>
!>           (C, D) = (Q*U)*(U**T*(A, B)*W)*(Z*W)**T,
!>
!>  and the first n1 columns of Q*U and Z*W span the corresponding
!>  deflating subspaces of (C, D) (Q and Z store Q*U and Z*W, resp.).
!>
!>  Note that if the selected eigenvalue is sufficiently ill-conditioned,
!>  then its value may differ significantly from its value before
!>  reordering.
!>
!>  The reciprocal condition numbers of the left and right eigenspaces
!>  spanned by the first n1 columns of U and W (or Q*U and Z*W) may
!>  be returned in DIF(1:2), corresponding to Difu and Difl, resp.
!>
!>  The Difu and Difl are defined as:
!>
!>       Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!>  and
!>       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!>  where sigma-min(Zu) is the smallest singular value of the
!>  (2*n1*n2)-by-(2*n1*n2) matrix
!>
!>       Zu = [ kron(In2, A11)  -kron(A22**T, In1) ]
!>            [ kron(In2, B11)  -kron(B22**T, In1) ].
!>
!>  Here, Inx is the identity matrix of size nx and A22**T is the
!>  transpose of A22. kron(X, Y) is the Kronecker product between
!>  the matrices X and Y.
!>
!>  When DIF(2) is small, small changes in (A, B) can cause large changes
!>  in the deflating subspace. An approximate (asymptotic) bound on the
!>  maximum angular error in the computed deflating subspaces is
!>
!>       EPS * norm((A, B)) / DIF(2),
!>
!>  where EPS is the machine precision.
!>
!>  The reciprocal norm of the projectors on the left and right
!>  eigenspaces associated with (A11, B11) may be returned in PL and PR.
!>  They are computed as follows. First we compute L and R so that
!>  P*(A, B)*Q is block diagonal, where
!>
!>       P = ( I -L ) n1           Q = ( I R ) n1
!>           ( 0  I ) n2    and        ( 0 I ) n2
!>             n1 n2                    n1 n2
!>
!>  and (L, R) is the solution to the generalized Sylvester equation
!>
!>       A11*R - L*A22 = -A12
!>       B11*R - L*B22 = -B12
!>
!>  Then PL = (F-norm(L)**2+1)**(-1/2) and PR = (F-norm(R)**2+1)**(-1/2).
!>  An approximate (asymptotic) bound on the average absolute error of
!>  the selected eigenvalues is
!>
!>       EPS * norm((A, B)) / PL.
!>
!>  There are also global error bounds which valid for perturbations up
!>  to a certain restriction:  A lower bound (x) on the smallest
!>  F-norm(E,F) for which an eigenvalue of (A11, B11) may move and
!!>  coalesce with an eigenvalue of (A22, B22) under perturbation (E,F),
!>  (i.e. (A + E, B + F), is
!>
!>   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!>  An approximate bound on x can be computed from DIF(1:2), PL and PR.
!>
!>  If y = ( F-norm(E,F) / x) <= 1, the angles between the perturbed
!>  (L', R') and unperturbed (L, R) left and right deflating subspaces
!>  associated with the selected cluster in the (1,1)-blocks can be
!>  bounded as
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!>  See LAPACK User's Guide section 4.11 or the following references
!>  for more information.
!>
!>  Note that if the default method for computing the Frobenius-norm-
!>  based estimate DIF is not wanted (see DLATDF), then the parameter
!>  IDIFJB (see below) should be changed from 3 to 4 (routine DLATDF
!>  (IJOB = 2 will be used)). See DTGSYL for more details.
!>
