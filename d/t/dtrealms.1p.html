dtrealms

gestiona

múltiples entornos de rotación de DNSSEC-Tools distintos que se ejecutan simultáneamente. Cada entorno de rotación, llamado un realm, está definido en un archivo de realms. dtrealms usa este archivo para determinar cómo debe inicializarse el entorno de rotación de modo que pueda ejecutarse de forma independiente de los otros entornos de rotación en un sistema particular. Esto es útil para cosas como gestionar colecciones muy grandes de zonas, segregar zonas de

clientes

y pruebas de software. El archivo de realms puede crearse con realminit. Actualmente, el entorno distinto para cada realm debe crearse manualmente. Se espera que pronto esté disponible una herramienta para ayudar con la
