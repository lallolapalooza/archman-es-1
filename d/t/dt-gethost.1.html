DT-GETHOST(1) Comandos de usuario DT-GETHOST(1)

NOMBRE

dt-gethost - programa de prueba de línea de comandos para las funciones val_gethostbyname() (y relacionadas)

SINOPSIS

dt-gethost [opciones] nombre

DESCRIPCIÓN

Esta utilidad es un envoltorio de línea de comandos alrededor de las funciones val_gethostbyname() (y relacionadas). Invoca las funciones val_gethostbyname(), val_gethostbyname_r() y val_gethostbyname2() para los argumentos dados en la línea de comandos y muestra la estructura hostent devuelta, el valor de estado de validación y el valor de la variable h_errno.

El estado de salida para este programa es 1 si la respuesta recibida es confiable, 2 si la respuesta recibida ha sido validada, y -1 en caso de error. El programa devuelve 0 si no se realizó ninguna validación o si el resultado no fue ni confiable ni validado. Los valores de estado confiable y validado se obtienen utilizando las funciones val_istrusted() y val_isvalidated() de libval(3).

OPCIONES

-r, --reentrant
Utiliza la interfaz de consulta reentrante.
-f, --family=[AF_INET|AF_INET6]
Utiliza la familia de direcciones especificada para la consulta.
-o, --output=<nivel-depuracion>:<tipo-destino>[:<opciones-destino>]
<nivel-depuracion> es de 1-7, correspondiente a los niveles de syslog ALERT-DEBUG <tipo-destino> es uno de file, net, syslog, stderr, stdout <opciones-destino> depende de <tipo-destino>
file:<nombre-archivo> (abierto en modo de añadir)
net[:<nombre-host>:<puerto-host>] (127.0.0.1:1053
syslog[:instalación] (0-23 (por defecto 1 USER))
-h, --help
Muestra la ayuda y sale.

PRE-REQUISITOS

libval
