Documentación de la función/subrutina

subroutine dtrmm (character side, character uplo, character transa, character diag, integer m, integer n, double precision alpha, double precision, dimension(lda,*) a, integer lda, double precision, dimension(ldb,*) b, integer ldb)

DTRMM

Propósito:

!>
!> DTRMM  realiza una de las operaciones de matriz-matriz
!>
!>    B := alpha*op( A )*B,   o   B := alpha*B*op( A ),
!>
!> donde  alpha  es un escalar,  B  es una matriz m por n,  A  es una matriz
!> triangular unitaria o no unitaria, superior o inferior, y  op( A )  es una de:
!>
!>    op( A ) = A   o   op( A ) = A**T.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>           A la entrada,  SIDE especifica si  op( A )  multiplica  B  por
!>           la izquierda o por la derecha, como sigue:
!>
!>              SIDE = 'L' o 'l'   B := alpha*op( A )*B.
!>
!>              SIDE = 'R' o 'r'   B := alpha*B*op( A ).
!>

UPLO

!>          UPLO es CHARACTER*1
!>           A la entrada, UPLO especifica si la matriz A es triangular superior
!>           o inferior, como sigue:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANSA

!>          TRANSA es CHARACTER*1
!>           A la entrada, TRANSA especifica la forma de op( A ) a usar en
!>           la multiplicación de matrices, como sigue:
!>
!>              TRANSA = 'N' o 'n'   op( A ) = A.
!>
!>              TRANSA = 'T' o 't'   op( A ) = A**T.
!>
!>              TRANSA = 'C' o 'c'   op( A ) = A**T.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           A la entrada, DIAG especifica si A es unitaria triangular o no
!>           como sigue:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria triangular.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>

M

!>          M es INTEGER
!>           A la entrada, M especifica el número de filas de B. M debe ser
!>           como mínimo cero.
!>

N

!>          N es INTEGER
!>           A la entrada, N especifica el número de columnas de B.  N debe ser
!>           como mínimo cero.
!>

ALPHA

!>          ALPHA es DOUBLE PRECISION.
!>           A la entrada,  ALPHA especifica el escalar  alpha. Cuando  alpha es
!>           cero entonces  A no se referencia y  B no necesita ser establecida antes
!>           de la entrada.
!>

A

!>           A es un array DOUBLE PRECISION, de dimensión ( LDA, k ), donde k es m
!>           cuando  SIDE = 'L' o 'l'  y es  n  cuando  SIDE = 'R' o 'r'.
!>           Antes de la entrada con  UPLO = 'U' o 'u',  la parte triangular superior
!>           principal  k por k del array  A debe contener la matriz triangular superior
!>           y la parte estrictamente triangular inferior de  A  no se referencia.
!>           Antes de la entrada con  UPLO = 'L' o 'l',  la parte triangular inferior
!>           principal  k por k del array  A debe contener la matriz triangular inferior
!>           y la parte estrictamente triangular superior de  A  no se referencia.
!>           Tenga en cuenta que cuando  DIAG = 'U' o 'u',  los elementos diagonales
!>           de  A  tampoco se referencian,  pero se asumen como unidad.
!>

LDA

!>          LDA es INTEGER
!>           A la entrada, LDA especifica la primera dimensión de A tal como se
!>           declara en el programa (sub)llamador.  Cuando  SIDE = 'L' o 'l'  entonces
!>           LDA  debe ser como mínimo  max( 1, m ),  cuando  SIDE = 'R' o 'r'
!>           entonces LDA debe ser como mínimo max( 1, n ).
!>

B

!>          B es un array DOUBLE PRECISION, de dimensión ( LDB, N )
!>           Antes de la entrada,  la parte principal  m por n del array  B debe
!>           contener la matriz  B,  y a la salida se sobrescribe con la
!>           matriz transformada.
!>

LDB

!>          LDB es INTEGER
!>           A la entrada, LDB especifica la primera dimensión de B tal como se
!>           declara en el programa (sub)llamador.  LDB  debe ser como mínimo
!>           max( 1, m ).
!>
