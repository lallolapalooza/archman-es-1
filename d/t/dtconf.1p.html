NOMBRE

dtconf - Muestra el contenido de un archivo de configuración de DNSSEC-Tools

SINOPSIS

dtconf [opciones] [archivo_configuración]

DESCRIPCIÓN

dtconf muestra los pares clave/valor de un archivo de configuración de DNSSEC-Tools. Si no se especifica un archivo de configuración, se mostrará el archivo de configuración del sistema.

Sin la opción -key, dtconf muestra todos los pares clave/valor del archivo de configuración. Los comentarios nunca se muestran. Si se proporciona la opción -key, entonces solo se mostrará ese par clave/valor. Si la clave no está definida, el valor será "(undefined)".

OPCIONES

-key
Se imprimirá el valor de la clave especificada. Si la clave no está definida, el valor se proporcionará como "(undefined)".
-Version
Muestra la información de la versión de dtconf y del paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.
