Documentación de la función/subrutina

subroutine dtpqrt (integer m, integer n, integer l, integer nb, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( * ) work, integer info)

DTPQRT

Propósito:

!>
!> DTPQRT calcula una factorización QR bloqueada de una matriz real
!>  C, que está compuesta por un bloque triangular A y un bloque pentagonal B,
!>  utilizando la representación compacta WY para Q.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B, y el orden de la
!>          matriz triangular A.
!>          N >= 0.
!>

L

!>          L es INTEGER
!>          El número de filas de la parte superior trapezoidal de B.
!>          MIN(M,N) >= L >= 0.  Ver Detalles Adicionales.
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque a utilizar en la QR bloqueada.  N >= NB >= 1.
!>

A

!>          A es un array DOUBLE PRECISION, de dimensión (LDA,N)
!>          En la entrada, la matriz triangular superior N por N, A.
!>          En la salida, los elementos en y encima de la diagonal de la matriz
!>          contienen la matriz triangular superior R.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, de dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M por N, B. Las primeras M-L filas
!>          son rectangulares, y las últimas L filas son trapezoidales superiores.
!>          En la salida, B contiene la matriz pentagonal V.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

T

!>          T es un array DOUBLE PRECISION, de dimensión (LDT,N)
!>          Los reflectores de bloque triangulares superiores almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores.  Ver Detalles Adicionales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.  LDT >= NB.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (NB*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz de (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz triangular superior N por N, y B es una matriz pentagonal
!>  M por N que consiste en una matriz rectangular B1 de (M-L)-por-N en la parte superior
!>  de una matriz trapezoidal superior L por N, B2:
!>
!>               B = [ B1 ]  <- matriz rectangular (M-L)-por-N
!>                   [ B2 ]  <-     matriz trapezoidal superior L por N.
!>
!>  La matriz trapezoidal superior B2 consiste en las primeras L filas de una
!>  matriz triangular superior N por N, donde 0 <= L <= MIN(M,N).  Si L=0,
!>  B es rectangular M por N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada C de (N+M)-por-N
!>
!>               C = [ A ]  <- triangular superior N por N
!>                   [ B ]  <- pentagonal M por N
!>
!>  de modo que W pueda representarse como
!>
!>               W = [ I ]  <- identidad, N por N
!>                   [ V ]  <- M por N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida
!>  en B, que llamamos V arriba.  Note que V tiene la misma forma que B; es decir,
!>
!>               V = [ V1 ] <- matriz rectangular (M-L)-por-N
!>                   [ V2 ] <-     matriz trapezoidal superior L por N.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>
!>  El número de bloques es B = techo(N/NB), donde cada
!>  bloque es de orden NB excepto el último bloque, que es de orden
!>  IB = N - (B-1)*NB.  Para cada uno de los B bloques, se calcula un factor de reflector
!>  de bloque triangular superior: T1, T2, ..., TB. Los T de NB por NB (y IB por IB
!>  para el último bloque) se almacenan en la matriz T de NB por N como
!>
!>               T = [T1 T2 ... TB].
!>
