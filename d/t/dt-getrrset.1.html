DT-GETRRSET(1) Comandos de usuario DT-GETRRSET(1)

NOMBRE

dt-getquery - programa de prueba en línea de comandos para la función val_get_rrset()

SINOPSIS

dt-getquery [opciones] nombre

DESCRIPCIÓN

Esta utilidad es un envoltorio de línea de comandos para la función val_get_rrset(). Invoca la función val_get_rrset() con los argumentos de línea de comandos dados y muestra los datos devueltos y el estado validado, confiable y de no existencia para cada conjunto de registros de recursos devuelto en la respuesta. También se muestra cualquier información sobre alias de nombre. Los valores de estado confiable y validado se obtienen utilizando las funciones val_istrusted() y val_isvalidated() de libval(3).

Este programa devuelve 0 en caso de éxito y -1 en caso de fallo.

OPCIONES

-t <tipo>
Realiza la consulta para el tipo de registro DNS dado
-o, --salida=<nivel-depuracion>:<tipo-destino>[:<opciones-destino>]
<nivel-depuracion> es 1-7, correspondiente a los niveles de syslog ALERT-DEBUG <tipo-destino> es uno de file, net, syslog, stderr, stdout <opciones-destino> depende de <tipo-destino>
file:<nombre-archivo> (abierto en modo de anexión)
net[:<nombre-host>:<puerto-host>] (127.0.0.1:1053
syslog[:facility] (0-23 (por defecto 1 USER))
-h, --ayuda
Muestra la ayuda y sale.

PRE-REQUISITOS

libval
