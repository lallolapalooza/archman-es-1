Documentación de la función/subrutina

subroutine dtrmv (character uplo, character trans, character diag, integer n, double precision, dimension(lda,*) a, integer lda, double precision, dimension(*) x, integer incx)

DTRMV

Propósito:

!>
!> DTRMV realiza una de las operaciones de matriz-vector
!>
!>    x := A*x,   o   x := A**T*x,
!>
!> donde x es un vector de n elementos y A es una matriz triangular superior o
!> inferior, unitaria o no unitaria, de n por n.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la matriz es una matriz triangular
!>           superior o inferior de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica la operación a realizar de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   x := A*x.
!>
!>              TRANS = 'T' o 't'   x := A**T*x.
!>
!>              TRANS = 'C' o 'c'   x := A**T*x.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           Al entrar, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión ( LDA, N )
!>           Antes de entrar con UPLO = 'U' o 'u', la parte triangular
!>           superior principal de n por n del array A debe contener la
!>           matriz triangular superior y la parte triangular estrictamente
!>           inferior de A no se referencia.
!>           Antes de entrar con UPLO = 'L' o 'l', la parte triangular
!>           inferior principal de n por n del array A debe contener la
!>           matriz triangular inferior y la parte triangular estrictamente
!>           superior de A no se referencia.
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos
!>           diagonales de A tampoco se referencian, pero se asumen que son
!>           la unidad.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como
!>           se declara en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>

X

!>          X es un array de DOUBLE PRECISION, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de entrar, el array X incrementado debe contener el vector
!>           x de n elementos. Al salir, X se sobrescribe con el vector
!>           transformado x.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>
