Documentación de la función/subrutina

subrutina dtgsy2 (character trans, integer ijob, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( ldd, * ) d, integer ldd, double precision, dimension( lde, * ) e, integer lde, double precision, dimension( ldf, * ) f, integer ldf, double precision scale, double precision rdsum, double precision rdscal, integer, dimension( * ) iwork, integer pq, integer info)

DTGSY2 resuelve la ecuación generalizada de Sylvester (algoritmo no bloqueado).

Propósito:

!>
!> DTGSY2 resuelve la ecuación generalizada de Sylvester:
!>
!>             A * R - L * B = scale * C                (1)
!>             D * R - L * E = scale * F,
!>
!> usando BLAS de Nivel 1 y 2. Donde R y L son matrices desconocidas M por N,
!> (A, D), (B, E) y (C, F) son pares de matrices dadas de tamaño M por M,
!> N por N y M por N, respectivamente, con entradas reales. (A, D) y (B, E)
!> deben estar en forma canónica generalizada de Schur, es decir, A y B son cuasi triangulares superiores
!> y D y E son triangulares superiores. La solución (R, L)
!> sobrescribe (C, F). 0 <= SCALE <= 1 es un factor de escala de salida
!> elegido para evitar desbordamientos.
!>
!> En notación matricial, resolver la ecuación (1) corresponde a resolver
!> Z*x = scale*b, donde Z se define como
!>
!>        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**T, Im) ],
!>
!> Ik es la matriz identidad de tamaño k y X**T es la transpuesta de X.
!> kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!> En el proceso de resolver (1), resolvemos una serie de tales sistemas
!> donde Dim(In), Dim(In) = 1 o 2.
!>
!> Si TRANS = 'T', resuelve el sistema transpuesto Z**T*y = scale*b para y,
!> lo cual es equivalente a resolver para R y L en
!>
!>             A**T * R  + D**T * L   = scale * C           (3)
!>             R  * B**T + L  * E**T  = scale * -F
!>
!> Este caso se usa para calcular una estimación de Dif[(A, D), (B, E)] =
!> sigma_min(Z) usando comunicación inversa con DLACON.
!>
!> DTGSY2 también (IJOB >= 1) contribuye al cálculo en DTGSYL
!> de un límite superior para la separación entre dos pares de matrices. Entonces
!> las entradas (A, D), (B, E) son sub-pencils del par de matrices en
!> DTGSYL. Ver DTGSYL para detalles.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación generalizada de Sylvester (1).
!>          = 'T': resuelve el sistema 'transpuesto' (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          = 0: solo resuelve (1).
!>          = 1: se calcula una contribución de este subsistema a una estimación de la norma de Frobenius
!>               de la separación entre dos pares de matrices. (se utiliza la estrategia de "look ahead").
!>          = 2: se calcula una contribución de este subsistema a una estimación de la norma de Frobenius
!>               de la separación entre dos pares de matrices. (se utiliza DGECON en subsistemas).
!>          No referenciado si TRANS = 'T'.
!>

M

!>          M es INTEGER
!>          En la entrada, M especifica el orden de A y D, y la dimensión de fila
!>          de C, F, R y L.
!>

N

!>          N es INTEGER
!>          En la entrada, N especifica el orden de B y E, y la dimensión de columna
!>          de C, F, R y L.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA, M)
!>          En la entrada, A contiene una matriz cuasi triangular superior.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A. LDA >= max(1, M).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB, N)
!>          En la entrada, B contiene una matriz cuasi triangular superior.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal de la matriz B. LDB >= max(1, N).
!>

C

!>          C es un array DOUBLE PRECISION, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          ecuación en (1).
!>          En la salida, si IJOB = 0, C ha sido sobrescrito por la
!>          solución R.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal de la matriz C. LDC >= max(1, M).
!>

D

!>          D es un array DOUBLE PRECISION, dimensión (LDD, M)
!>          En la entrada, D contiene una matriz triangular superior.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal de la matriz D. LDD >= max(1, M).
!>

E

!>          E es un array DOUBLE PRECISION, dimensión (LDE, N)
!>          En la entrada, E contiene una matriz triangular superior.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal de la matriz E. LDE >= max(1, N).
!>

F

!>          F es un array DOUBLE PRECISION, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          ecuación en (1).
!>          En la salida, si IJOB = 0, F ha sido sobrescrito por la
!>          solución L.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal de la matriz F. LDF >= max(1, M).
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          En la salida, 0 <= SCALE <= 1. Si 0 < SCALE < 1, las soluciones
!>          R y L (C y F en la entrada) contendrán las soluciones de
!>          un sistema ligeramente perturbado pero las matrices de entrada A, B, D y
!>          E no han sido modificadas. Si SCALE = 0, R y L contendrán las
!>          soluciones del sistema homogéneo con C = F = 0. Normalmente,
!>          SCALE = 1.
!>

RDSUM

!>          RDSUM es DOUBLE PRECISION
!>          En la entrada, la suma de cuadrados de las contribuciones calculadas a
!>          la estimación de Dif- que se está calculando en DTGSYL, donde
!>          el factor de escala RDSCAL (ver abajo) ha sido extraído.
!>          En la salida, la suma de cuadrados correspondiente actualizada con las
!>          contribuciones del subsistema actual.
!>          Si TRANS = 'T', RDSUM no se modifica.
!>          NOTA: RDSUM solo tiene sentido cuando DTGSY2 es llamado por DTGSYL.
!>

RDSCAL

!>          RDSCAL es DOUBLE PRECISION
!>          En la entrada, factor de escala utilizado para prevenir desbordamientos en RDSUM.
!>          En la salida, RDSCAL se actualiza con respecto a las contribuciones actuales
!>          en RDSUM.
!>          Si TRANS = 'T', RDSCAL no se modifica.
!>          NOTA: RDSCAL solo tiene sentido cuando DTGSY2 es llamado por
!>                DTGSYL.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M+N+2)
!>

PQ

!>          PQ es INTEGER
!>          En la salida, el número de subsistemas (de tamaño 2x2, 4x4 y
!>          8x8) resueltos por esta rutina.

NAME

dtgsy2 - solves the generalized Sylvester equation

SYNOPSIS

Subroutine dtgsy2(TRANSA, TRANSB, ISGN, A, LDA, D, LDD, B, LDB, E, LDE, C, LDC,
                 DL, LDL, DR, LDR, INFO)
Parameters
TRANSA
CHARACTER*1.
On entry, TRANSA specifies the form of the first matrix A.

= 'N': Do not transpose A.

= 'T': Transpose A.

= 'C': Conjugate transpose A (unsupported).

TRANSB
CHARACTER*1.
On entry, TRANSB specifies the form of the first matrix B.

= 'N': Do not transpose B.

= 'T': Transpose B.

= 'C': Conjugate transpose B (unsupported).

ISGN
INTEGER.
On entry, ISGN specifies the sign of the solution matrix X.

= 0: X is the solution matrix.

= 1: X is the solution matrix.

A
DOUBLE PRECISION array, dimension (LDA, N).

On entry, the upper triangular matrix A.

LDA
INTEGER.
On entry, LDA is the leading dimension of the array A.
D
DOUBLE PRECISION array, dimension (LDD, N).

On entry, the upper triangular matrix D.

LDD
INTEGER.
On entry, LDD is the leading dimension of the array D.
B
DOUBLE PRECISION array, dimension (LDB, M).

On entry, the upper triangular matrix B.

LDB
INTEGER.
On entry, LDB is the leading dimension of the array B.
E
DOUBLE PRECISION array, dimension (LDE, M).

On entry, the upper triangular matrix E.

LDE
INTEGER.
On entry, LDE is the leading dimension of the array E.
C
DOUBLE PRECISION array, dimension (LDC, M).

On entry, the right hand side matrix C.

On exit, C is overwritten by the solution matrix X.

LDC
INTEGER.
On entry, LDC is the leading dimension of the array C.
DL
DOUBLE PRECISION array, dimension (N).

On exit, the diagonal elements of the upper triangular matrix L.

LDL
INTEGER.
On exit, the number of diagonal elements of L.
DR
DOUBLE PRECISION array, dimension (M).

On exit, the diagonal elements of the upper triangular matrix R.

LDR
INTEGER.
On exit, the number of diagonal elements of R.
INFO
INTEGER.
On exit, if INFO is set to
=0: Successful exit
<0: If INFO = -i, the i-th argument had an illegal value.
>0: The matrix pairs (A, D) and (B, E) have common or very
close eigenvalues.
