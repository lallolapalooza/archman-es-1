subrutina dtpqrt2 (integer m, integer n, integer l, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldt, * ) t, integer ldt, integer info)

DTPQRT2 calcula una factorización QR de una matriz real o compleja "triangular-pentagonal", que está compuesta por un bloque triangular y un bloque pentagonal, utilizando la representación compacta WY para Q.

Propósito:

!>
!> DTPQRT2 calcula una factorización QR de una matriz real
!> C, que está compuesta por un bloque triangular A y un bloque pentagonal B,
!> utilizando la representación compacta WY para Q.
!>

Parámetros

M 
!>          M is INTEGER
!>          El número total de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N is INTEGER
!>          El número de columnas de la matriz B, y el orden de
!>          la matriz triangular A.
!>          N >= 0.
!>

L

!>          L is INTEGER
!>          El número de filas de la parte superior trapezoidal de B.
!>          MIN(M,N) >= L >= 0. Ver Detalles Adicionales.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          En la entrada, la matriz triangular superior N por N, A.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz triangular superior R.
!>

LDA

!>          LDA is INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,N)
!>          En la entrada, la matriz pentagonal M por N, B. Las primeras M-L filas
!>          son rectangulares, y las últimas L filas son trapezoidales superiores.
!>          En la salida, B contiene la matriz pentagonal V. Ver Detalles Adicionales.
!>

LDB

!>          LDB is INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

T

!>          T is DOUBLE PRECISION array, dimension (LDT,N)
!>          El factor triangular superior N por N, T, del reflector de bloque.
!>          Ver Detalles Adicionales.
!>

LDT

!>          LDT is INTEGER
!>          La dimensión principal del array T.  LDT >= max(1,N)
!>

INFO

!>          INFO is INTEGER
!>          = 0: ejecución exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz de (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz triangular superior N-por-N, y B es una matriz pentagonal
!>  M-por-N que consiste en una matriz rectangular (M-L)-por-N, B1, en la parte superior
!>  de una matriz trapezoidal superior L-por-N, B2:
!>
!>               B = [ B1 ]  <- rectangular (M-L)-por-N
!>                   [ B2 ]  <-     trapezoidal superior L-por-N.
!>
!>  La matriz trapezoidal superior B2 consiste en las primeras L filas de una
!>  matriz triangular superior N-por-N, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada C de (N+M)-por-N
!>
!>               C = [ A ]  <- triangular superior N-por-N
!>                   [ B ]  <- pentagonal M-por-N
!>
!>  de modo que W pueda representarse como
!>
!>               W = [ I ]  <- identidad, N-por-N
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W se contiene en la salida en B,
!>  que llamamos V arriba. Nótese que V tiene la misma forma que B; es decir,
!>
!>               V = [ V1 ] <- rectangular (M-L)-por-N
!>                   [ V2 ] <-     trapezoidal superior L-por-N.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>  El reflector de bloque H de (M+N)-por-(M+N) viene dado entonces por
!>
!>               H = I - W * T * W**T
!>
!>  donde W^H es la transpuesta conjugada de W y T es el factor triangular superior
!>  del reflector de bloque.
!>
