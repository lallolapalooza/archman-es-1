Documentación de Función/Subrutina

subrutina dtbt05 (character uplo, character trans, character diag, integer n, integer kd, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * ) reslts)

DTBT05

Propósito:

!>
!> DTBT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz banda triangular.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta proporción no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             y NZ = máx. número de elementos distintos de cero en cualquier fila de A, más 1
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transponer)
!>          = 'T':  A'* X = B  (Transpuesta)
!>          = 'C':  A'* X = B  (Transpuesta conjugada = Transpuesta)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es o no triangular unitaria.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!>

AB

!>          AB es un array DOUBLE PRECISION, dimensión (LDAB,N)
!>          La matriz banda triangular superior o inferior A, almacenada en las
!>          primeras kd+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asume que son 1.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho del sistema de ecuaciones
!>          lineales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como una
!>          columna de la matriz X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

XACT

!>          XACT es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Los vectores de solución exactos. Cada vector se almacena como una
!>          columna de la matriz XACT.
!>

LDXACT

!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites estimados de error hacia adelante para cada vector de
!>          solución X. Si XTRUE es la solución verdadera, FERR acota la magnitud
!>          del elemento más grande en (X - XTRUE) dividida por la magnitud
!>          del elemento más grande en X.
!>

BERR

!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error relativo hacia atrás componente a componente de cada vector
!>          de solución (es decir, el cambio relativo más pequeño en cualquier elemento de A
!>          o B que hace que X sea una solución exacta).
!>

RESLTS

!>          RESLTS es un array DOUBLE PRECISION, dimensión (2)
!>          El máximo sobre los vectores de solución NRHS de las proporciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
