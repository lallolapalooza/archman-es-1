subrutina dtbsv (uplo, trans, diag, n, k, a, lda, x, incx)

DTBSV

DOCUMENTACIÓN DE FUNCIÓN/SUBRUTINA

subrutina dtbsv (carácter uplo, carácter trans, carácter diag, entero n, entero k, doble precisión, dimensión(lda,*) a, entero lda, doble precisión, dimensión(*) x, entero incx)

DTBSV

Propósito:

!>
!> DTBSV  resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz de banda
!> triangular superior o inferior de n por n, unitaria o no unitaria,
!> con ( k + 1 ) diagonales.
!>
!> Esta rutina no incluye pruebas de singularidad o cuasi-singularidad.
!> Dichas pruebas deben realizarse antes de llamar a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la matriz es superior o
!>           triangular inferior de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica las ecuaciones a resolver de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**T*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           Al entrar, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria triangular.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria
!>                                  triangular.
!>

N

!>          N es ENTERO
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

K

!>          K es ENTERO
!>           Al entrar con UPLO = 'U' o 'u', K especifica el número de
!>           superdiagonales de la matriz A.
!>           Al entrar con UPLO = 'L' o 'l', K especifica el número de
!>           subdiagonales de la matriz A.
!>           K debe satisfacer 0 .le. K.
!>

A

!>          A es un array de DOBLE PRECISIÓN, dimensión ( LDA, N )
!>           Antes de entrar con UPLO = 'U' o 'u', la parte principal ( k + 1 )
!>           por n del array A debe contener la parte triangular superior
!>           de banda de la matriz de coeficientes, proporcionada columna
!>           por columna, con la diagonal principal de la matriz en la fila
!>           ( k + 1 ) del array, la primera superdiagonal comenzando en la
!>           posición 2 en la fila k, y así sucesivamente. El triángulo superior
!>           izquierdo k por k del array A no se referencia.
!>           El siguiente segmento de programa transferirá una matriz de
!>           banda triangular superior del almacenamiento de matriz completa
!>           convencional al almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Antes de entrar con UPLO = 'L' o 'l', la parte principal ( k + 1 )
!>           por n del array A debe contener la parte triangular inferior
!>           de banda de la matriz de coeficientes, proporcionada columna
!>           por columna, con la diagonal principal de la matriz en la fila 1
!>           del array, la primera subdiagonal comenzando en la posición 1
!>           en la fila 2, y así sucesivamente. El triángulo inferior derecho
!>           k por k del array A no se referencia.
!>           El siguiente segmento de programa transferirá una matriz de
!>           banda triangular inferior del almacenamiento de matriz completa
!>           convencional al almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos del
!>           array A correspondientes a los elementos diagonales de la matriz
!>           no se referencian, pero se asumen como la unidad.
!>

LDA

!>          LDA es ENTERO
!>           Al entrar, LDA especifica la primera dimensión de A tal como
!>           se declara en el programa llamante (subrutina). LDA debe ser
!>           al menos ( k + 1 ).
!>

X

!>          X es un array de DOBLE PRECISIÓN, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de entrar, el array X incrementado debe contener el
!>           vector del lado derecho b de n elementos. Al salir, X se
!>           sobrescribe con el vector solución x.
!>

INCX

!>          INCX es ENTERO
!>           Al entrar, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
!>
