DTGSJ

A

Propósito

: 
!>
!> DTGSJA calcula la descomposición de valores singulares generalizada (GSVD)
!> de dos matrices reales triangulares superiores (o trapezoidales) A y B.
!>
!> Al entrar, se supone que las matrices A y B tienen las siguientes
!> formas, que pueden ser obtenidas por la subrutina de preprocesamiento DGGSVP
!> a partir de una matriz A general de M por N y una matriz B de P por N:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> donde la matriz A12 de K por K y la matriz B13 de L por L son no singulares
!> triangulares superiores; A23 es triangular superior de L por L si M-K-L >= 0,
!> de lo contrario A23 es trapezoidal superior de (M-K) por L.
!>
!> Al salir,
!>
!>        U**T *A*Q = D1*( 0 R ),    V**T *B*Q = D2*( 0 R ),
!>
!> donde U, V y Q son matrices ortogonales.
!> R es una matriz triangular superior no singular, y D1 y D2 son
!> matrices ``diagonales'', que tienen las siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) al salir.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> donde
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N) y R33 se almacena
!>     (  0  R22 R23 )
!> en B(M-K+1:L,N+M-K-L+1:N) al salir.
!>
!> El cálculo de las matrices de transformación ortogonales U, V o Q
!> es opcional. Estas matrices pueden formarse explícitamente, o pueden
!> ser postmultiplicadas en las matrices de entrada U1, V1 o Q1.
!
>

Parámetro

s
JOBU 
!>          JOBU es CHARACTER*1
!>          = 'U':  U debe contener una matriz ortogonal U1 al entrar, y
!>                  se devuelve el producto U1*U;
!>          = 'I':  U se inicializa con la matriz unidad, y se devuelve
!>                  la matriz ortogonal U;
!>          = 'N':  U no se calcula.

V 
!>          JOBV es CHARACTER*1
!>          = 'V':  V debe contener una matriz ortogonal V1 al entrar, y
!>                  se devuelve el producto V1*V;
!>          = 'I':  V se inicializa con la matriz unidad, y se devuelve
!>                  la matriz ortogonal V;
!>          = 'N':  V no se calcula.
!
>

JOB

Q 
!>          JOBQ es CHARACTER*1
!>          = 'Q':  Q debe contener una matriz ortogonal Q1 al entrar, y
!>                  se devuelve el producto Q1*Q;
!>          = 'I':  Q se inicializa con la matriz unidad, y se devuelve
!>                  la matriz ortogonal Q;
!>          = 'N':  Q no se calcula.
!
>

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!
>

P 
!>          P es INTEGER
!>          El número de filas de la matriz B.  P >= 0.
!
>

N 
!>          N es INTEGER
!>          El número de columnas de las matrices A y B.  N >= 0.
!
>

K 
!>          K es INTEGER
!
>

L 
!>          L es INTEGER
!>
!>          K y L especifican los subbloques en las matrices de entrada A y B:
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) y B13 = B(1:L,N-L+1:N)
!>          de A y B, cuya GSVD va a ser calculada por DTGSJA.
!>          Ver Detalles Adicionales.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          Al entrar, la matriz A de M por N.
!>          Al salir, A(N-K+1:N,1:MIN(K+L,M) ) contiene la matriz
!>          triangular R o parte de R. Ver Propósito para más detalles.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          Al entrar, la matriz B de P por N.
!>          Al salir, si es necesario, B(M-K+1:L,N+M-K-L+1:N) contiene

>

LD

B

>

TOL

A 
!>          TOLA es DOUBLE PRECISION
!
>

TOL

B 
!>          TOLB es DOUBLE PRECISION
!>
!>          TOLA y TOLB son los criterios de convergencia para el procedimiento
!>          de iteración Jacobi-Kogbetliantz. Generalmente, son los mismos
!>          que se usan en el paso de preprocesamiento, digamos
!>              TOLA = max(M,N)*norm(A)*MAZHEPS,
!>              TOLB = max(P,N)*norm(B)*MAZHEPS.
!
>

ALPH

A 
!>          ALPHA es un array DOUBLE PRECISION, dimensión (N)
!
>

BET

A 
!>          BETA es un array DOUBLE PRECISION, dimensión (N)
!>
!>          Al salir, ALPHA y BETA contienen los pares de valores singulares
!>          generalizados de A y B;
!>            ALPHA(1:K) = 1,
!>            BETA(1:K)  = 0,
!>          y si M-K-L >= 0,
!>            ALPHA(K+1:K+L) = diag(C),
!>            BETA(K+1:K+L)  = diag(S),
!>          o si M-K-L < 0,
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:K+L) = 1.
!>          Además, si K+L < N,
!>            ALPHA(K+L+1:N) = 0 y
!>            BETA(K+L+1:N)  = 0.
!
>

U 
!>          U es un array DOUBLE PRECISION, dimensión (LDU,M)
!>          Al entrar, si JOBU = 'U', U dest contener una matriz U1 (usualmente
!>          la matriz ortogonal devuelta por DGGSVP).
!>          En salida,
!>          si JOBU = 'I', U contiene la matriz ortogonal U;
!>          si JOBU = 'U', U contiene el producto U1*U.
!>          Si JOBU = 'N', U no se referencia.
!
>

LD

U 
!>          LDU es INTEGER
!>          La dimensión principal del array U. LDU >= max(1,M) si
!>          JOBU = 'U'; LDU >= 1 en caso contrario.
!
>

V 
!>          V es un array DOUBLE PRECISION, dimensión (LDV,P)
!>          En entrada, si JOBV = 'V', V debe contener una matriz V1 (usualmente
!>          la matriz ortogonal devuelta por DGGSVP).
!>          En salida,
!>          si JOBV = 'I', V contiene la matriz ortogonal V;
!>          si JOBV = 'V', V contiene el producto V1*V.
!>          Si JOBV = 'N', V no se referencia.
!
>

LD

V 
!>          LDV es INTEGER
!>          La dimensión principal del array V. LDV >= max(1,P) si
!>          JOBV = 'V'; LDV >= 1 en caso contrario.
!
>

Q 
!>          Q es un array DOUBLE PRECISION, dimensión (LDQ,N)
!>          En entrada, si JOBQ = 'Q', Q debe contener una matriz Q1 (usualmente
!>          la matriz ortogonal devuelta por DGGSVP).
!>          En salida,
!>          si JOBQ = 'I', Q contiene la matriz ortogonal Q;
!>          si JOBQ = 'Q', Q contiene el producto Q1*Q.
!>          Si JOBQ = 'N', Q no se referencia.
!
>

LD

Q 
!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= max(1,N) si
!>          JOBQ = 'Q'; LDQ >= 1 en caso contrario.
!
>

WOR

K

>

NCYCL

E

O

Detalles 
Adicionales:



!>
!>  DTGSJA esencialmente usa una variante del algoritmo de Kogbetliantz para reducir
!>  la matriz triangular (o trapezoidal) A23 de min(L,M-K)-por-L y la matriz B13 de L-por-L
!>  a la forma:
!>
!>           U1**T *A13*Q1 = C1*R1; V1**T *B13*Q1 = S1*R1,
!>
!>  donde U1, V1 y Q1 son matrices ortogonales, y Z**T es la transpuesta
!>  de Z.  C1 y S1 son matrices diagonales que satisfacen
!>
!>                C1**2 + S1**2 = I,
!>
!>  y R1 es una matriz triangular superior no singular de L-por-L.

!
>
