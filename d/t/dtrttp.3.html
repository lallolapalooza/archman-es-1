Documentación de función/subrutina

subrutina dtrttp (carácter uplo, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) ap, entero info)

DTRTTP copia una matriz triangular del formato estándar completo (TR) al formato estándar empaquetado (TP).

Propósito:

!>
!> DTRTTP copia una matriz triangular A del formato completo (TR) al formato
!> estándar empaquetado (TP).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior.
!>          = 'L':  A es triangular inferior.
!>

N

!>          N es INTEGER
!>          El orden de las matrices AP y A.  N >= 0.
!>

A

!>          A es un array de DOUBLE PRECISION, dimensión (LDA,N)
!>          Al salir, la matriz triangular A.  Si UPLO = 'U', la parte
!>          triangular superior de N por N líder de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior de N por N líder de A contiene la
!>          parte triangular inferior de la matriz A, y la parte
!>          estrictamente triangular superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.  LDA >= max(1,N).
!>

AP

!>          AP es un array de DOUBLE PRECISION, dimensión (N*(N+1)/2)
!>          Al salir, la matriz triangular superior o inferior A, empaquetada
!>          por columnas en un array lineal. La j-ésima columna de A se
!>          almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
