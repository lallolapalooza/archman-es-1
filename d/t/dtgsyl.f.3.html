subrutina dtgsyl (character trans, integer ijob, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldc, * ) c, integer ldc, double precision, dimension( ldd, * ) d, integer ldd, double precision, dimension( lde, * ) e, integer lde, double precision, dimension( ldf, * ) f, integer ldf, double precision scale, double precision dif, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer

info)

DTGSY

L

Propósito

: 
!>
!> DTGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C                 (1)
!>             D * R - L * E = scale * F
!>
!> donde R y L son matrices desconocidas de tamaño m-por-n, (A, D), (B, E) y
!> (C, F) son pares de matrices dadas de tamaño m-por-m, n-por-n y m-por-n,
!> respectivamente, con entradas reales. (A, D) y (B, E) deben estar en
!> forma canónica de Schur generalizada (real), es decir, A, B son
!> cuasitriangulares superiores y D, E son triangulares superiores.
!>
!> La solución (R, L) sobrescribe (C, F). 0 <= SCALE <= 1 es un factor de
!> escala de salida elegido para evitar desbordamientos.
!>
!> En notación matricial (1) es equivalente a resolver Zx = scale b, donde
!> Z se define como
!>
!>            Z = [ kron(In, A)  -kron(B**T, Im) ]         (2)
!>                [ kron(In, D)  -kron(E**T, Im) ].
!>
!> Aquí Ik es la matriz identidad de tamaño k y X**T es la transpuesta de
!> X. kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!>
!> Si TRANS = 'T', DTGSYL resuelve el sistema transpuesto Z**T*y = scale*b,
!> que es equivalente a resolver para R y L en
!>
!>             A**T * R + D**T * L = scale * C           (3)
!>             R * B**T + L * E**T = scale * -F
!>
!> Este caso (TRANS = 'T') se usa para calcular una estimación basada en la
!> norma uno de Dif[(A,D), (B,E)], la separación entre los pares de matrices
!> (A,D) y (B,E), usando DLACON.
!>
!> Si IJOB >= 1, DTGSYL calcula una estimación basada en la norma de Frobenius
!> de Dif[(A,D),(B,E)]. Es decir, el recíproco de una cota inferior del
!> recíproco del valor singular más pequeño de Z. Vea [1-2] para más
!> información.
!>
!> Este es un algoritmo BLAS de nivel 3.
!
>

Parámetro

s
TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resolver la ecuación de Sylvester generalizada (1).
!>          = 'T': resolver el sistema 'transpuesto' (3).
!
>

IJO

B 
!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          = 0: resolver (1) solamente.
!>          = 1: La funcionalidad de 0 y 3.
!>          = 2: La funcionalidad de 0 y 4.
!>          = 3: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>               (se usa la estrategia de anticipación IJOB = 1).
!>          = 4: Solo se calcula una estimación de Dif[(A,D), (B,E)].
!>               (se usa DGECON en subsistemas).
!>          No se referencia si TRANS = 'T'.
!
>

M 
!>          M es INTEGER
!>          El orden de las matrices A y D, y la dimensión de filas de
!>          las matrices C, F, R y L.
!
>

N 
!>          N es INTEGER
!>          El orden de las matrices B y E, y la dimensión de columnas
!>          de las matrices C, F, R y L.
!
>

A 
!>          A es un arreglo DOUBLE PRECISION, dimensión (LDA, M)
!>          La matriz cuasitriangular superior A.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del arreglo A. LDA >= max(1, M).
!
>

B 
!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB, N)
!>          La matriz cuasitriangular superior B.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B. LDB >= max(1, N).
!
>

C 
!>          C es un arreglo DOUBLE PRECISION, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera
!>          ecuación matricial en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, C ha sido sobrescrito por
!>          la solución R. Si IJOB = 3 o 4 y TRANS = 'N', C contiene R,
!>          la solución alcanzada durante el cálculo de la
!>          estimación de Dif.
!
>

LD

C 
!>          LDC es INTEGER
!>          La dimensión principal del arreglo C. LDC >= max(1, M).
!
>

D 
!>          D es un arreglo DOUBLE PRECISION, dimensión (LDD, M)
!>          La matriz triangular superior D.
!
>

LD

D 
!>          LDD es INTEGER
!>          La dimensión principal del arreglo D. LDD >= max(1, M).
!
>

E 
!>          E es un arreglo DOUBLE PRECISION, dimensión (LDE, N)
!>          La matriz triangular superior E.
!
>

LD

E 
!>          LDE es INTEGER
!>          La dimensión principal del arreglo E. LDE >= max(1, N).
!
>

F 
!>          F es un arreglo DOUBLE PRECISION, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda
!>          ecuación matricial en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, F ha sido sobrescrito por
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución alcanzada durante el cálculo de la
!>          estimación de Dif.
!
>

LD

F 
!>          LDF es INTEGER
!>          La dimensión principal del arreglo F. LDF >= max(1, M).
!
>

DI

F 
!>          DIF es DOUBLE PRECISION
!>          En la salida DIF es el recíproco de una cota inferior del
!>          recíproco de la función Dif, es decir, DIF es una cota superior de
!>          Dif[(A,D), (B,E)] = sigma_min(Z), donde Z como en (2).
!>          SI IJOB = 0 o TRANS = 'T', DIF no se modifica.
!
>

SCAL

E 
!>          SCALE es DOUBLE PRECISION
!>          En la salida SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, respectivamente,
!>          a un sistema ligeramente perturbado pero las matrices de entrada A, B, D
!>          y E no han sido cambiadas. Si SCALE = 0, C y F contienen las
!>          soluciones R y L, respectivamente, al sistema homogéneo
!>          con C = F = 0. Normalmente, SCALE = 1.
!
>

WOR

K 
!>          WORK es un arreglo DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!
>

LWOR

K 
!>          LWORK es INTEGER
!>          La dimensión del arreglo WORK. LWORK > = 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del arreglo WORK, devuelve
!>          este valor como la primera entrada del arreglo WORK, y no se emite ningún
!>          mensaje de error relacionado con LWORK por XERBLA.
!
>

IWOR

K 
!>          IWORK es un arreglo INTEGER, dimensión (M+N+6)
!
>

INF

O 
!>          INFO es INTEGER
!>            =0: salida exitosa
!>            <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>            >0: (A, D) y (B, E) tienen eigenvalores comunes o cercanos.
!
>
