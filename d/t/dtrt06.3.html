subrutina dtrt06 (doble precisión rcond, doble precisión rcondc, carácter uplo, carácter diag, entero n, doble precisión, dimensión( lda, * ) a, entero lda, doble precisión, dimensión( * ) work, doble precisión rat)

DTRT06

Propósito:

!>
!> DTRT06 calcula una relación de prueba que compara RCOND (el recíproco
!> del número de condición de una matriz triangular A) y RCONDC, la estimación
!> calculada por DTRCON.  Se utiliza información de la matriz triangular A
!> si una estimación es cero y la otra es distinta de cero para decidir si
!> el subdesbordamiento en la estimación está justificado.
!>

Parámetros

RCOND 
!>          RCOND es DOBLE PRECISION
!>          La estimación del recíproco del número de condición obtenida al
!>          formar la inversa explícita de la matriz A y calcular
!>          RCOND = 1/( norma(A) * norma(inv(A)) ).
!>

RCONDC

!>          RCONDC es DOBLE PRECISION
!>          La estimación del recíproco del número de condición calculada por
!>          DTRCON.
!>

UPLO

!>          UPLO es CARACTER
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CARACTER
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array de DOBLE PRECISION, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte triangular superior
!>          principal de n por n del array A contiene la matriz triangular
!>          superior, y la parte estrictamente triangular inferior de
!>          A no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>          principal de n por n del array A contiene la matriz triangular
!>          inferior, y la parte estrictamente triangular superior de A no se
!>          referencia.  Si DIAG = 'U', los elementos diagonales de A tampoco
!>          se referencian y se asumen como 1.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

WORK

!>          WORK es un array de DOBLE PRECISION, dimensión (N)
!>

RAT

!>          RAT es DOBLE PRECISION
!>          La relación de prueba.  Si tanto RCOND como RCONDC son distintos
!>          de cero,
!>             RAT = MAX( RCOND, RCONDC )/MIN( RCOND, RCONDC ) - 1.
!>          Si RAT = 0, las dos estimaciones son exactamente iguales.
!>
