Documentación de Función/Subrutina

subroutine dtgevc (character side, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( lds, * ) s, integer lds, double precision, dimension( ldp, * ) p, integer ldp, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, double precision, dimension( * ) work, integer info)

DTGEVC

Propósito:

!>
!> DTGEVC calcula algunos o todos los vectores propios derechos y/o izquierdos de
!> un par de matrices reales (S,P), donde S es una matriz cuasi-triangular
!> y P es triangular superior. Los pares de matrices de este tipo son producidos por
!> la factorización de Schur generalizada de un par de matrices (A,B):
!>
!>    A = Q*S*Z**T,  B = Q*P*Z**T
!>
!> como se calcula por DGGHRD + DHGEQZ.
!>
!> El vector propio derecho x y el vector propio izquierdo y de (S,P)
!> correspondientes a un valor propio w se definen por:
!>
!>    S*x = w*P*x,  (y**H)*S = w*(y**H)*P,
!>
!> donde y**H denota la transpuesta conjugada de y.
!> Los valores propios no son una entrada para esta rutina, sino que se calculan
!> directamente a partir de los bloques diagonales de S y P.
!>
!> Esta rutina devuelve las matrices X e/o Y de vectores propios derechos e izquierdos
!> de (S,P), o los productos Z*X e/o Q*Y,
!> donde Z y Q son matrices de entrada.
!> Si Q y Z son los factores ortogonales de la factorización de Schur
!> generalizada de un par de matrices (A,B), entonces Z*X y Q*Y
!> son las matrices de vectores propios derechos e izquierdos de (A,B).
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R': calcular solo vectores propios derechos;
!>          = 'L': calcular solo vectores propios izquierdos;
!>          = 'B': calcular ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular todos los vectores propios derechos y/o izquierdos;
!>          = 'B': calcular todos los vectores propios derechos y/o izquierdos,
!>                 transformados hacia atrás por las matrices en VR y/o VL;
!>          = 'S': calcular vectores propios derechos y/o izquierdos seleccionados,
!>                 especificados por el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, dimension (N)
!>          Si HOWMNY='S', SELECT especifica los vectores propios a calcular.
!>          Si w(j) es un valor propio real, el vector propio real correspondiente
!>          se calcula si SELECT(j) es .TRUE..
!>          Si w(j) y w(j+1) son las partes real e imaginaria de un
!>          valor propio complejo, el vector propio complejo correspondiente
!>          se calcula si SELECT(j) o SELECT(j+1) es .TRUE.,
!>          y a la salida SELECT(j) se establece a .TRUE. y SELECT(j+1) se
!>          establece a .FALSE..
!>          No se hace referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de las matrices S y P. N >= 0.
!>

S

!>          S es un array DOUBLE PRECISION, dimension (LDS,N)
!>          La matriz cuasi-triangular superior S de una factorización de Schur
!>          generalizada, como se calcula por DHGEQZ.
!>

LDS

!>          LDS es INTEGER
!>          La dimensión líder del array S. LDS >= max(1,N).
!>

P

!>          P es un array DOUBLE PRECISION, dimension (LDP,N)
!>          La matriz triangular superior P de una factorización de Schur
!>          generalizada, como se calcula por DHGEQZ.
!>          Los bloques diagonales de 2x2 de P correspondientes a los bloques
!>          de 2x2 de S deben estar en forma diagonal positiva.
!>

LDP

!>          LDP es INTEGER
!>          La dimensión líder del array P. LDP >= max(1,N).
!>

VL

!>          VL es un array DOUBLE PRECISION, dimension (LDVL,MM)
!>          En la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de NxN (generalmente la matriz ortogonal Q
!>          de vectores de Schur izquierdos devuelta por DHGEQZ).
!>          A la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de vectores propios izquierdos de (S,P);
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de (S,P) especificados por
!>                      SELECT, almacenados consecutivamente en las columnas de
!>                      VL, en el mismo orden que sus valores propios.
!>
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>
!>          No se hace referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión líder del array VL. LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array DOUBLE PRECISION, dimension (LDVR,MM)
!>          En la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Z de NxN (generalmente la matriz ortogonal Z
!>          de vectores de Schur derechos devuelta por DHGEQZ).
!>
!>          A la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de vectores propios derechos de (S,P);
!>          si HOWMNY = 'B' o 'b', la matriz Z*X;
!>          si HOWMNY = 'S' o 's', los vectores propios derechos de (S,P)
!>                      especificados por SELECT, almacenados consecutivamente en las
!>                      columnas de VR, en el mismo orden que sus
!>                      valores propios.
!>
!>          Un vector propio complejo correspondiente a un valor propio complejo
!>          se almacena en dos columnas consecutivas, la primera contiene la
!>          parte real y la segunda la parte imaginaria.
!>
!>          No se hace referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión líder del array VR. LDVR >= 1, y si
!>          SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios. Si HOWMNY = 'A' o 'B', M
!>          se establece a N. Cada vector propio real seleccionado ocupa una
!>          columna y cada vector propio complejo seleccionado ocupa dos
!>          columnas.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimension (6*N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa.
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0: el bloque (INFO:INFO+1) de 2x2 no tiene un valor propio complejo.
!>

!>  ---------- -- ---------
!>
!>     WORK( j ) = norma 1 de la j-ésima columna de A, encima de la diagonal
!>     WORK( N+j ) = norma 1 de la j-ésima columna de B, encima de la diagonal
!>     WORK( 2*N+1:3*N ) = parte real del vector propio
!>     WORK( 3*N+1:4*N ) = parte imaginaria del vector propio
!>     WORK( 4*N+1:5*N ) = parte real del vector propio transformado hacia atrás
!>     WORK( 5*N+1:6*N ) = parte imaginaria del vector propio transformado hacia atrás
!>
!>  Rowwi

se vs. Métodos de Solución Columnwise

!>  ------- --  ---------- -------- -------
!>
!>  Encontrar un vector propio generalizado consiste básicamente en resolver el
!>  sistema triangular singular
!>
!>   (A - w B) x = 0     (para la derecha) o:   (A - w B)**H y = 0  (para la izquierda)
!>
!>  Considere encontrar el i-ésimo vector propio derecho (asuma que todos los valores
!>  propios son reales). La ecuación a resolver es:
!>       n                   i
!>  0 = sum  C(j,k) v(k)  = sum  C(j,k) v(k)     para j = i,. . .,1
!>      k=j                 k=j
!>
!>  donde  C = (A - w B)  (Los componentes v(i+1:n) son 0.)
!>
!>  El  método es:
!>
!>  (1)  v(i) := 1
!>  para j = i-1,. . .,1:
!>                          i
!>      (2) calcular  s = - sum C(j,k) v(k)   y
!>                        k=j+1
!>
!>      (3) v(j) := s / C(j,j)
!>
!>  El paso 2 a veces se llama el  paso, ya que es un
!>  producto interno entre la fila j y la porción del vector propio
!>  que se ha calculado hasta ahora.
!>
!>  El  método consiste básicamente en realizar las sumas
!>  para todas las filas en paralelo. A medida que se calcula cada v(j), la
!>  contribución de v(j) multiplicada por la j-ésima columna de C se añade a las
!>  sumas parciales. Dado que los arreglos FORTRAN se almacenan columnwise, esto tiene
!>  la ventaja de que en cada paso, los elementos de C a los que se accede
!>  son adyacentes entre sí, mientras que con el método rowwise, los
!>  elementos accedidos en un paso están espaciados en palabras LDS (y LDP).
!>
!>  Al encontrar vectores propios izquierdos, la matriz en cuestión es la
!>  transpuesta de la que está almacenada, por lo que el método rowwise entonces
!>  realmente accede a las columnas de A y B en cada paso, y por lo tanto es el
!>  método preferido.
!>
