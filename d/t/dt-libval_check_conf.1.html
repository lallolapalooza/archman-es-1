NOMBRE

dt-libval_check_conf - programa de línea de comandos para verificar la validez de los archivos de configuración del validador.

SINOPSIS

dt-libval_check_conf [opciones]

DESCRIPCIÓN

Este programa verifica un archivo de configuración de validador dado en busca de errores de sintaxis. Si no se especifica ningún archivo como opción de línea de comandos, se verifica el archivo predeterminado dnsval.conf.

VALORES DE RETORNO

El programa devuelve 0 en caso de éxito y -1 en caso de fallo.

OPCIONES

-d, --dnsval-conf
Especifica la ubicación del archivo dnsval.conf. Si no se especifica esta opción, se utiliza el archivo dnsval.conf predeterminado reconocido por la biblioteca del validador.
-r, --resolv-conf
Especifica la ubicación del archivo resolv.conf. Si no se especifica esta opción, se utiliza el archivo resolv.conf predeterminado reconocido por la biblioteca del validador.
-i, --root-hints
Especifica la ubicación del archivo root.hints. Si no se especifica esta opción, se utiliza el archivo root.hints predeterminado reconocido por la biblioteca del validador.
-v, --verbose
Muestra mensajes detallados y advertencias asociadas con el proceso de verificación del archivo de configuración del validador.
-h, --help
Muestra un mensaje de ayuda de uso y sale del programa.
