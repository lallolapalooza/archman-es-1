Documentación de Función/Subrutina

subrutina dtgsna (character job, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) s, double precision, dimension( * ) dif, integer mm, integer m, double precision, dimension( * ) work, integer lwork, integer, dimension( * ) iwork, integer info)

DTGSNA

Propósito:

!>
!> DTGSNA estima los números de condición recíprocos para los
!> autovalores y/o autovectores especificados de un par de matrices
!> (A, B) en forma canónica de Schur real generalizada (o de cualquier
!> par de matrices (Q*A*Z**T, Q*B*Z**T) con matrices ortogonales Q y Z,
!> donde Z**T denota la transpuesta de Z.
!>
!> (A, B) debe estar en forma de Schur real generalizada (como la
!> devuelta por DGGES), es decir, A es triangular superior por bloques
!> con bloques diagonales de 1x1 y 2x2. B es triangular superior.
!>
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          autovalores (S) o autovectores (DIF):
!>          = 'E': solo para autovalores (S);
!>          = 'V': solo para autovectores (DIF);
!>          = 'B': tanto para autovalores como para autovectores (S y DIF).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular los números de condición para todos los
!>                 autoempares;
!>          = 'S': calcular los números de condición para los autoempares
!>                 seleccionados especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los autoempares para los
!>          cuales se requieren números de condición. Para seleccionar los
!>          números de condición del autoepar correspondiente a un
!>          autovalor real w(j), SELECT(j) debe establecerse en .TRUE..
!>          Para seleccionar los números de condición correspondientes a un
!>          par de autovalores conjugados complejos w(j) y w(j+1), ya sea
!>          SELECT(j) o SELECT(j+1) o ambos, deben establecerse en .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden del par de matrices cuadradas (A, B). N >= 0.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz cuasitriangular superior A en el par (A,B).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, dimensión (LDB,N)
!>          La matriz triangular superior B en el par (A,B).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

VL

!>          VL es un array DOUBLE PRECISION, dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los autovectores
!>          izquierdos de (A, B), correspondientes a los autoempares
!>          especificados por HOWMNY y SELECT. Los autovectores deben
!>          almacenarse en columnas consecutivas de VL, como los
!>          devueltos por DTGEVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1.
!>          Si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array DOUBLE PRECISION, dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los autovectores
!>          derechos de (A, B), correspondientes a los autoempares
!>          especificados por HOWMNY y SELECT. Los autovectores deben
!>          almacenarse en columnas consecutivas de VR, como los
!>          devueltos por DTGEVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1.
!>          Si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array DOUBLE PRECISION, dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de
!>          los autovalores seleccionados, almacenados en elementos
!>          consecutivos del array. Para un par de autovalores conjugados
!>          complejos, dos elementos consecutivos de S se establecen al
!>          mismo valor. Así, S(j), DIF(j) y las j-ésimas columnas de VL
!>          y VR corresponden todas al mismo autoepar (pero no en general
!>          al j-ésimo autoepar, a menos que se seleccionen todos los
!>          autoempares).
!>          Si JOB = 'V', S no se referencia.
!>

DIF

!>          DIF es un array DOUBLE PRECISION, dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos
!>          estimados de los autovectores seleccionados, almacenados en
!>          elementos consecutivos del array. Para un autovector complejo,
!>          dos elementos consecutivos de DIF se establecen al mismo
!>          valor. Si los autovalores no pueden reordenarse para calcular
!>          DIF(j), DIF(j) se establece a 0; esto solo puede ocurrir
!>          cuando el valor real sería muy pequeño de todos modos.
!>          Si JOB = 'E', DIF no se referencia.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S y DIF. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y DIF utilizados para
!>          almacenar los números de condición especificados; para cada
!>          autovalor real seleccionado se usa un elemento, y para cada
!>          par de autovalores conjugados complejos seleccionado se usan
!>          dos elementos.
!>          Si HOWMNY = 'A', M se establece a N.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, dimensión (MAX(1,LWORK))
!>          Al salir, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' o 'B', LWORK >= 2*N*(N+2)+16.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK,
!>          devuelve este valor como la primera entrada del array WORK, y
!>          XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (N + 6)
!>          Si JOB = 'E', IWORK no se referencia.
!>

INFO

!>          INFO es INTEGER
!>          =0: Salida exitosa
!>          <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!>  El recíproco del número de condición de un autovalor generalizado
!>  w = (a, b) se define como
!>
!>       S(w) = (|u**TAv|**2 + |u**TBv|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  donde u y v son los autovectores izquierdo y derecho de (A, B)
!>  correspondiente a w; |z| denota el valor absoluto del número complejo
!>  y norm(u) denota la norma 2 del vector u.
!>  El par (a, b) corresponde a un eigenvalor w = a/b (= u**TAv/u**TBv)
!>  del par de matrices (A, B). Si tanto a como b son cero, entonces (A B) es
!>  singular y se devuelve S(I) = -1.
!>
!>  Una cota de error aproximada sobre la distancia acoralada entre el i-ésimo
!>  eigenvalor generalizado calculado w y el eigenvalor exacto
!>  correspondiente lambda es
!>
!>       chord(w, lambda) <= EPS * norm(A, B) / S(I)
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El recíproco del número de condición DIF(i) del eigenvector derecho u
!>  y del eigenvector izquierdo v correspondiente al eigenvalor generalizado w
!>  se define de la siguiente manera:
!>
!>  a) Si el i-ésimo eigenvalor w = (a,b) es real
!>
!>     Supongamos que U y V son transformaciones ortogonales tales que
!>
!>              U**T*(A, B)*V  = (S, T) = ( a   *  ) ( b  *  )  1
!>                                        ( 0  S22 ),( 0 T22 )  n-1
!>                                          1  n-1     1 n-1
!>
!>     Entonces el recíproco del número de condición DIF(i) es
!>
!>                Difl((a, b), (S22, T22)) = sigma-min( Zl ),
!>
!>     donde sigma-min(Zl) denota el valor singular más pequeño de la
!>     matriz 2(n-1)-por-2(n-1)
!>
!>         Zl = [ kron(a, In-1)  -kron(1, S22) ]
!>              [ kron(b, In-1)  -kron(1, T22) ] .
!>
!>     Aquí In-1 es la matriz identidad de tamaño n-1. kron(X, Y) es el
!>     producto de Kronecker entre las matrices X e Y.
!>
!>     Nótese que si se desea el método por defecto para calcular DIF(i)
!>     (ver DLATDF), entonces el parámetro DIFDRI (ver abajo) debería
!>     cambiarse de 3 a 4 (se usará la rutina DLATDF(IJOB = 2)).
!>     Ver DTGSYL para más detalles.
!>
!>  b) Si el i-ésimo y el (i+1)-ésimo eigenvalores son un par de conjugados complejos,
!>
!>     Supongamos que U y V son transformaciones ortogonales tales que
!>
!>              U**T*(A, B)*V = (S, T) = ( S11  *   ) ( T11  *  )  2
!>                                       ( 0    S22 ),( 0    T22) n-2
!>                                         2    n-2     2    n-2
!>
!>     y (S11, T11) corresponde al par de eigenvalores conjugados complejos
!>     (w, conjg(w)). Existen matrices unitarias U1 y V1 tales que
!>
!>       U1**T*S11*V1 = ( s11 s12 ) y U1**T*T11*V1 = ( t11 t12 )
!>                      (  0  s22 )                    (  0  t22 )
!>
!>     donde los eigenvalores generalizados son w = s11/t11 y
!>     conjg(w) = s22/t22.
!>
!>     Entonces el recíproco del número de condición DIF(i) está acotado por
!>
!>         min( d1, max( 1, |real(s11)/real(s22)| )*d2 )
!>
!>     donde, d1 = Difl((s11, t11), (s22, t22)) = sigma-min(Z1), donde
!>     Z1 es la matriz compleja 2-por-2
!>
!>              Z1 =  [ s11  -s22 ]
!>                    [ t11  -t22 ],
!>
!>     Esto se hace calculando (usando aritmética real) las
!>     raíces del polinomio característico det(Z1**T * Z1 - lambda I),
!>     donde Z1**T denota la transpuesta de Z1 y det(X) denota
!>     el determinante de X.
!>
!>     y d2 es una cota superior de Difl((S11, T11), (S22, T22)), es decir, una
!>     cota superior de sigma-min(Z2), donde Z2 es (2n-2)-por-(2n-2)
!>
!>              Z2 = [ kron(S11**T, In-2)  -kron(I2, S22) ]
!>                   [ kron(T11**T, In-2)  -kron(I2, T22) ]
!>
!>     Nótese que si se desea el método por defecto para calcular DIF (ver
!>     DLATDF), entonces el parámetro DIFDRI (ver abajo) debería
!>     cambiarse de 3 a 4 (se usará la rutina DLATDF(IJOB = 2)). Ver DTGSYL
!>     para más detalles.
!>
!>  Para cada eigenvalor/vector especificado por SELECT, DIF almacena una
!>  estimación basada en la norma de Frobenius de Difl.
!>
!>  Una cota de error aproximada para el i-ésimo eigenvector calculado VL(i) o
!>  VR(i) viene dada por
!>
!>             EPS * norm(A, B) / DIF(i).
!>
!>  Ver ref. [2-3] para más detalles y referencias adicionales.
!>
