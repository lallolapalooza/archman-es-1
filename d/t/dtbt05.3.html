subrutina dtbt05 (character uplo, character trans, character diag, integer n, integer kd, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * )

reslts)

DTBT0

5

Propósito

: 
!>
!> DTBT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz banda triangular.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( NZ*EPS + (*) ), donde
!>             (*) = NZ*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!>             y NZ = máx. número de elementos distintos de cero en cualquier fila de A, más 1
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transponer)
!>          = 'T':  A'* X = B  (Transponer)
!>          = 'C':  A'* X = B  (Transposición conjugada = Transposición)
!
>

DIA

G 
!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!
>

N 
!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!
>

K

D 
!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!
>

A

B 
!>          AB es un arreglo DOUBLE PRECISION, dimensión (LDAB,N)
!>          La matriz banda triangular superior o inferior A, almacenada en las
!>          primeras kd+1 filas del arreglo. La j-ésima columna de A se almacena
!>          en la j-ésima columna del arreglo AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asume que son 1.
!
>

LDA

B 
!>          LDAB es INTEGER
!>          La dimensión principal del arreglo AB.  LDAB >= KD+1.
!
>

B 
!>          B es un arreglo DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho del sistema de ecuaciones
!>          lineales.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del arreglo B.  LDB >= max(1,N).
!
>

X 
!>          X es un arreglo DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados. Cada vector se almacena como una
!>          columna de la matriz X.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del arreglo X.  LDX >= max(1,N).
!
>

XAC

T 
!>          XACT es un arreglo DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Los vectores de solución exacta. Cada vector se almacena como una
!>          columna de la matriz XACT.
!
>

LDXAC

T 
!>          LDXACT es INTEGER
!>          La dimensión principal del arreglo XACT.  LDXACT >= max(1,N).
!
>

FER

R 
!>          FERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites de error hacia adelante estimados para cada vector de
!>          solución X. Si XTRUE es la solución verdadera, FERR acota la magnitud
!>          de la entrada más grande en (X - XTRUE) dividida por la magnitud
!>          de la entrada más grande en X.
!
>

BER

R 
!>          BERR es un arreglo DOUBLE PRECISION, dimensión (NRHS)
!>          El error relativo hacia atrás componente a componente de cada vector
!>          de solución (es decir, el cambio relativo más pequeño en cualquier
!>          entrada de A o B que hace que X sea una solución exacta).
!
>

RESLT

S 
!>          RESLTS es un arreglo DOUBLE PRECISION, dimensión (2)
!>          El máximo sobre los NRHS vectores de solución de las relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!
>
