DTCONFCHK(1) Documentación de Perl aportada por el usuario DTCONFCHK(1)

NOMBRE

dtconfchk - Comprueba la cordura de un archivo de configuración de DNSSEC-Tools

SINOPSIS

dtconfchk [opciones] [archivo_de_configuración]

DESCRIPCIÓN

dtconfchk comprueba un archivo de configuración de DNSSEC-Tools para determinar si las entradas son válidas. Si no se especifica un archivo de configuración, se verificará el archivo de configuración del sistema.

Sin ninguna opción de visualización, dtconfchk muestra mensajes de error por los problemas encontrados, seguidos de una línea de resumen. Las opciones de visualización aumentarán o disminuirán la cantidad de detalle sobre la cordura del archivo de configuración. En todos los casos, el código de salida es el recuento de errores encontrados en el archivo.

Las pruebas se dividen en cinco grupos: comprobaciones relacionadas con las claves, comprobaciones relacionadas con las zonas, comprobaciones de rutas, comprobaciones de renovación y comprobaciones diversas. Las comprobaciones en cada uno de estos grupos autoexplicativos se describen a continuación.

La entrada de configuración default_keyrec no se comprueba. Esta entrada especifica el nombre de archivo keyrec por defecto y no se espera necesariamente que exista en ningún lugar en particular.

Valores booleanos

El archivo de configuración de DNSSEC-Tools tiene una serie de campos que se espera que contengan valores booleanos. Los valores reconocidos para los booleanos son los siguientes:

valores verdaderos  - 1, true,  t, yes, y
valores falsos - 0, false, f, no,  n

Los valores positivos mayores que 1 se reconocen como valores verdaderos, pero probablemente sería mejor usar 1.

Los valores de texto que no están en el conjunto anterior no son válidos y se traducirán como valores falsos.

Comprobaciones relacionadas con las claves

Se realizan las siguientes comprobaciones relacionadas con las claves:

algorithm
Asegurarse de que el campo algorithm sea válido. Los valores aceptables pueden encontrarse en la página del manual dnssec-keygen .
ksklength
Asegurarse de que el campo ksklength sea válido. Los valores aceptables pueden encontrarse en la página del manual dnssec-keygen . Esto también puede especificarse como ksklen.
ksklife
Asegurarse de que el campo ksklife sea válido. Los valores aceptables pueden encontrarse en la página del manual defaults.pm .
zskcount
Asegurarse de que el campo zskcount sea válido. El recuento de ZSK debe ser positivo.
zsklength
Asegurarse de que el campo zsklength sea válido. Los valores aceptables pueden encontrarse en la página del manual dnssec-keygen . Esto también puede especificarse como zsklen.
zsklife
Asegurarse de que el campo zsklife sea válido. Los valores aceptables pueden encontrarse en la página del manual defaults.pm .
random
Asegurarse de que el campo random sea válido. Este archivo debe ser un archivo de dispositivo de caracteres.

Comprobaciones relacionadas con las zonas

Se realizan las siguientes comprobaciones relacionadas con las zonas:

endtime
Asegurarse de que el campo endtime sea válido. Se asume que este valor está en el formato "+NNNNNN". Hay un límite inferior de dos horas. (Este es un límite artificial por debajo del cual puede no tener sentido tener una hora de finalización.)

Comprobaciones de rutas

Se realizan comprobaciones de rutas para varios comandos de DNSSEC-Tools, varios comandos de BIND y algunos archivos diversos.

Se realizan las siguientes comprobaciones de rutas para los comandos de DNSSEC-Tools:

genkrf
Asegurarse de que el campo genkrf sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
keyarch
Asegurarse de que el campo keyarch sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
rollchk
Asegurarse de que el campo rollchk sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
rollctl
Asegurarse de que el campo rollctl sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
zonesigner
Asegurarse de que el campo zonesigner sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.

Se realizan las siguientes comprobaciones de rutas para las herramientas de BIND:

keygen
Asegurarse de que el campo keygen sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
rndc
Asegurarse de que el campo rndc sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
zonecheck
Asegurarse de que el campo zonecheck sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.
zonesign
Asegurarse de que el campo zonesign sea válido. Si el nombre de archivo comienza con una '/', el archivo debe ser un archivo ejecutable regular.

Se realizan las siguientes comprobaciones de rutas para archivos y directorios diversos:

random
Asegurarse de que el campo random sea válido. El archivo debe ser un archivo de dispositivo de caracteres.
roll_logfile
Asegurarse de que el campo roll_logfile sea un archivo regular.
taresolvconf
Asegurarse de que el campo taresolvconf sea un archivo regular.
tatmpdir
Asegurarse de que el campo tatmpdir sea un directorio.

Comprobaciones del demonio de renovación

Se realizan las siguientes comprobaciones para los valores de rollerd :

autosign
Asegurarse de que la bandera autosign sea un booleano válido.
log_tz
Asegurarse de que el campo log_tz sea 'gmt' o 'local'.
prog_normal
prog_ksk1 ... prog_ksk7
prog_zsk1 ... prog_zsk4
Asegurarse de que los comandos de fase de renovación sean rutas válidas. Cada uno de estos campos es una lista de comandos separados por punto y coma. Se ejecutan comprobaciones de archivo en los comandos para asegurarse de que los comandos existen y son ejecutables. Las opciones y los argumentos de los comandos se ignoran, al igual que la palabra clave default .
roll_loadzone
Asegurarse de que la bandera roll_loadzone sea un booleano válido.
roll_logfile
Asegurarse de que el archivo de registro para rollerd sea válido. Si el archivo existe, debe ser un archivo regular.
roll_loglevel
Asegurarse de que el nivel de registro para rollerd sea razonable. El nivel de registro debe ser uno de los siguientes valores de texto o numéricos: 
tmi        1       Mensajes informativos excesivamente detallados.
expire     3       Se da una cuenta regresiva detallada de la expiración de la zona.
info       4       Mensajes informativos.
phase      6       Estado actual de la zona.
err        8       Mensajes de error.
fatal      9       Errores fatales.

Especificar un nivel de registro particular causará que los mensajes de un valor numérico más alto también se muestre.

roll_sleeptime
Asegurarse de que el rollerd's tiempo de dormir es razonable. rollerd's el tiempo de dormir debe ser de al menos un minuto.
roll_username
Asegurarse de que el nombre de usuario para rollerd es válido. Si es un nombre de usuario, debe ser traducible a un uid; si es un uid, debe traducirse a un nombre de usuario conocido.
zone_errors
Asegurarse de que el recuento de errores de zona sea numérico y 0 o mayor.

Comprobaciones de NSEC3

Se realizan las siguientes comprobaciones para los valores relacionados con NSEC3:

nsec3iter
Asegurarse de que el nsec3iter recuento de iteraciones cae dentro del rango utilizado por dnssec-signzone. Los valores actuales son de 1 a 65535.
nsec3optout
Asegurarse de que el nsec3optout indicador es un booleano válido.
usensec3
Asegurarse de que el usensec3 indicador es un booleano válido.

Comprobaciones diversas

Se realizan las siguientes comprobaciones diversas:

admin-email
Asegurarse de que el admin-email campo está definido y tiene un valor. dtconfchk no intenta validar la dirección de correo electrónico en sí.
archivedir
Asegurarse de que el archivedir directorio es realmente un directorio. Esta comprobación solo se realiza si el savekeys indicador está activado.
entropy_msg
Asegurarse de que el entropy_msg indicador es un booleano válido.
savekeys
Asegurarse de que el savekeys indicador es un booleano válido. Si este indicador está establecido en 1, entonces el archivedir campo también será comprobado.
usegui
Asegurarse de que el usegui indicador es un booleano válido.
zonefile-parser
Asegurarse de que el zonefile-parser indicador es un módulo Perl válido. Esto se comprueba utilizando la funcionalidad "require" de Perl para cargar el módulo especificado.

OPCIONES

-expert
Esta opción omitirá las siguientes comprobaciones: 
- KSK tiene una vida útil más larga que la vida útil
  mínima por defecto del archivo de configuración
- KSK tiene una vida útil más corta que la vida útil
  máxima por defecto del archivo de configuración
- ZSKs tienen una vida útil más larga que la vida útil
  mínima por defecto del archivo de configuración
- ZSKs tienen una vida útil más corta que la vida útil
  máxima por defecto del archivo de configuración
-quiet
No se dará ninguna salida. El número de errores se utilizará como el código de salida.
-summary
Se imprimirá un resumen final de éxito o fallo. El número de errores se utilizará como el código de salida.
-verbose
Se dará el estado de éxito o fallo de cada comprobación. Un + o - prefijo se dará para cada entrada válida e inválida. El número de errores se utilizará como el código de salida.
-Version
Muestra la información de versión para dtconfchk y el paquete DNSSEC-Tools.
-help
Muestra un mensaje de uso.
