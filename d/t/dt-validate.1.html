DT-VALIDATE(1) Comandos de usuario DT-VALIDATE(1)

NOMBRE

dt-validate - Consulta el Sistema de Nombres de Dominio y muestra los resultados del proceso de validación DNSSEC

SINOPSIS

dt-validate [opciones] NOMBRE_DE_DOMINIO

DESCRIPCIÓN

dt-validate es una herramienta de diagnóstico construida sobre el validador DNSSEC. Toma NOMBRE_DE_DOMINIO como argumento y consulta el DNS para ese nombre de dominio. Muestra la serie de respuestas recibidas del DNS y los resultados de validación DNSSEC para cada nombre de dominio. Un examen de las consultas y los resultados de validación puede ayudar a un administrador a descubrir errores en la configuración de DNSSEC de las zonas DNS.

OPCIONES

-c CLASE, --class=CLASE
Esta opción se puede utilizar para especificar la clase DNS del Registro de Recursos consultado. Si no se proporciona esta opción, se utiliza la clase predeterminada IN.
-h, --help
Muestra la ayuda y sale.
-p, --print
Imprime las respuestas y los resultados de validación. Por defecto, dt-validate solo muestra una serie de respuestas y sus resultados de validación en stderr. Cuando se utiliza la opción -p, dt-validate también mostrará el resultado final en stdout.
-t TIPO, --type=TIPO
Esta opción se puede utilizar para especificar el tipo DNS del Registro de Recursos consultado. Si no se proporciona esta opción, dt-validate consultará el registro A para el NOMBRE_DE_DOMINIO dado.
-v ARCHIVO, --dnsval-conf=ARCHIVO
Esta opción se puede utilizar para especificar la ubicación del archivo de configuración dnsval.conf.
-r ARCHIVO, --resolv-conf=ARCHIVO
Esta opción se puede utilizar para especificar la ubicación del archivo de configuración resolv.conf que contiene los servidores de nombres a utilizar para las búsquedas.
-i ARCHIVO, --root-hints=ARCHIVO
Esta opción se puede utilizar para especificar la ubicación del archivo de configuración root.hints, que contiene los servidores de nombres raíz. Esto solo se utiliza cuando no se encuentra ningún servidor de nombres y dt-validate debe realizar búsquedas recursivas por sí mismo.
-S conjunto[:conjunto], --test-suite=conjunto[:conjunto]
Esta opción especifica el conjunto de pruebas (o rango de conjuntos de pruebas) a utilizar para las pruebas internas.
-s, --selftest
Esta opción se puede utilizar para especificar que la aplicación debe realizar sus autocomprobaciones utilizando nombres del conjunto de pruebas configurado.
-T número[:número], --testcase=número[:número]
Esta opción se puede utilizar para ejecutar una prueba específica (o un rango de pruebas) del conjunto de pruebas.
-F archivo, --testcase-conf=archivo
Esta opción se utiliza para especificar el archivo que contiene los casos de prueba.
-l etiqueta, --label=etiqueta
Esta opción se puede utilizar para especificar la política dentro del archivo dnsval.conf a utilizar durante la validación.
-w segundos, --wait=segundos
Esta opción se puede utilizar para ejecutar las consultas especificadas por otras banderas en un bucle, con el intervalo especificado entre consultas sucesivas.
-o, --output=<nivel-depuracion>:<tipo-destino>[:<opciones-destino>]
<nivel-depuracion> es 1-7, correspondiente a los niveles de syslog ALERTA-DEBUG <tipo-destino> es uno de file, net, syslog, stderr, stdout <opciones-destino> depende de <tipo-destino>
file:<nombre-archivo> (abierto en modo de adición)
net[:<nombre-host>:<puerto-host>] (127.0.0.1:1053
syslog[:facility] (0-23 (predeterminado 1 USER))
