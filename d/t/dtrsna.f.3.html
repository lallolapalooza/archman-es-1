subrutina dtrsna (character job, character howmny, logical, dimension( * ) select, integer n, double precision, dimension( ldt, * ) t, integer ldt, double precision, dimension( ldvl, * ) vl, integer ldvl, double precision, dimension( ldvr, * ) vr, integer ldvr, double precision, dimension( * ) s, double precision, dimension( * ) sep, integer mm, integer m, double precision, dimension( ldwork, * ) work, integer ldwork, integer, dimension( * ) iwork, integer

DTRSN

A

Propósito

: 
!>
!> DTRSNA estima los números de condición recíprocos para los
!> autovalores y/o autovectores derechos especificados de una matriz
!> real superior cuasitriangular T (o de cualquier matriz Q*T*Q**T con Q
!> ortogonal).
!>
!> T debe estar en forma canónica de Schur (como la devuelta por DHSEQR), es decir,
!> triangular superior por bloques con bloques diagonales de 1x1 y 2x2; cada
!> bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!
>

Parámetro

s
JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          autovalores (S) o autovectores (SEP):
!>          = 'E': solo para autovalores (S);
!>          = 'V': solo para autovectores (SEP);
!>          = 'B': tanto para autovalores como para autovectores (S y SEP).
!
>

HOWMN

Y 
!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular números de condición para todos los autoemparejamientos;
!>          = 'S': calcular números de condición para los autoemparejamientos seleccionados
!>                 especificados por la matriz SELECT.
!
>

SELEC

T 
!>          SELECT es una matriz LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los autoemparejamientos para los cuales
!>          se requieren números de condición. Para seleccionar números de condición
!>          para el autoemparejamiento correspondiente a un autovalor real w(j),
!>          SELECT(j) debe establecerse en .TRUE.. Para seleccionar números de condición
!>          correspondientes a un par de autovalores complejos conjugados w(j)
!>          y w(j+1), ya sea SELECT(j) o SELECT(j+1) o ambos, deben
!>          establecerse en .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!
>

N 
!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!
>

T 
!>          T es una matriz DOUBLE PRECISION, dimensión (LDT,N)
!>          La matriz superior cuasitriangular T, en forma canónica de Schur.
!
>

LD

T 
!>          LDT es INTEGER
!>          La dimensión principal de la matriz T. LDT >= max(1,N).
!
>

V

L 
!>          VL es una matriz DOUBLE PRECISION, dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener autovectores izquierdos de T
!>          (o de cualquier Q*T*Q**T con Q ortogonal), correspondientes a los
!>          autoemparejamientos especificados por HOWMNY y SELECT. Los autovectores
!>          deben almacenarse en columnas consecutivas de VL, como los devuelve
!>          DHSEIN o DTREVC.
!>          Si JOB = 'V', VL no se referencia.
!
>

LDV

L 
!>          LDVL es INTEGER
!>          La dimensión principal de la matriz VL.
!>          LDVL >= 1; y si JOB = 'E' o 'B', LDVL >= N.
!
>

V

R 
!>          VR es una matriz DOUBLE PRECISION, dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener autovectores derechos de T
!>          (o de cualquier Q*T*Q**T con Q ortogonal), correspondientes a los
!>          autoemparejamientos especificados por HOWMNY y SELECT. Los autovectores
!>          deben almacenarse en columnas consecutivas de VR, como los devuelve
!>          DHSEIN o DTREVC.
!>          Si JOB = 'V', VR no se referencia.
!
>

LDV

R 
!>          LDVR es INTEGER
!>          La dimensión principal de la matriz VR.
!>          LDVR >= 1; y si JOB = 'E' o 'B', LDVR >= N.
!
>

S 
!>          S es una matriz DOUBLE PRECISION, dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          autovalores seleccionados, almacenados en elementos consecutivos de la
!>          matriz. Para un par de autovalores complejos conjugados, dos
!>          elementos consecutivos de S se establecen en el mismo valor. Así
!>          S(j), SEP(j), y las j-ésimas columnas de VL y VR todos
!>          corresponden al mismo autoemparejamiento (pero en general no el
!>          j-ésimo autoemparejamiento, a menos que se seleccionen todos los autoemparejamientos).
!>          Si JOB = 'V', S no se referencia.
!
>

SE

P 
!>          SEP es una matriz DOUBLE PRECISION, dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos estimados de los
!>          autovectores seleccionados, almacenados en elementos consecutivos de la
!>          matriz. Para un autovector complejo, dos
!>          elementos consecutivos de SEP se establecen en el mismo valor. Si
!>          los autovalores no pueden reordenarse para calcular SEP(j), SEP(j)
!>          se establece en 0; esto solo puede ocurrir cuando el valor real sería
!>          muy pequeño de todos modos.
!>          Si JOB = 'E', SEP no se referencia.
!
>

M

M 
!>          MM es INTEGER
!>          El número de elementos en las matrices S (si JOB = 'E' o 'B')
!>           y/o SEP (si JOB = 'V' o 'B'). MM >= M.
!
>

M 
!>          M es INTEGER
!>          El número de elementos de las matrices S y/o SEP realmente
!>          utilizados para almacenar los números de condición estimados.
!>          Si HOWMNY = 'A', M se establece en N.
!
>

WOR

K 
!>          WORK es una matriz DOUBLE PRECISION, dimensión (LDWORK,N+6)
!>          Si JOB = 'E', WORK no se referencia.
!
>

LDWOR

K 
!>          LDWORK es INTEGER
!>          La dimensión principal de la matriz WORK.
!>          LDWORK >= 1; y si JOB = 'V' o 'B', LDWORK >= N.
!
>

IWOR

K 
!>          IWORK es una matriz INTEGER, dimensión (2*(N-1))
!>          Si JOB = 'E', IWORK no se referencia.
!
>

INF

O 
!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!
>

Detalles

adicionales: 
!>
!>  El recíproco del número de condición de un autovalor lambda se
!>  define como
!>
!>          S(lambda) = |v**T*u| / (norm(u)*norm(v))
!>
!>  donde u y v son los autovectores derechos e izquierdos de T correspondientes
!>  a lambda; v**T denota la transpuesta de v, y norm(u)
!>  denota la norma euclidiana. Estos números de condición recíprocos siempre
!>  están entre cero (muy mal condicionado) y uno (muy bien
!>  condicionado). Si n = 1, S(lambda) se define como 1.
!>
!>  Un límite de error aproximado para un autovalor calculado W(i) viene dado por
!>
!>                      EPS * norm(T) / S(i)
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El recíproco del número de condición del autovector derecho u
!>  correspondiente a lambda se define como sigue. Supongamos
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Entonces el número de condición recíproco es
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  donde sigma-min denota el valor singular más pequeño. Aproximamos
!>  el valor singular más pequeño por el recíproco de una estimación de la
!>  norma uno de la inversa de T22 - lambda*I. Si n = 1, SEP(1) se
!>  define como abs(T(1,1)).
!>
!>  Una cota de error aproximada para un autovector derecho calculado VR(i)
!>  viene dada por
!>
!>                      EPS * norm(T) / SEP(i)
!
>
