DTRSV

Documentación de Función/Subrutina

subrutina dtrsv (character uplo, character trans, character diag, integer n, double precision, dimension(lda,*) a, integer lda, double precision, dimension(*) x, integer incx)

DTRSV

Propósito:

!>
!> DTRSV  resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz triangular
!> unitaria, o no unitaria, superior o inferior de n por n.
!>
!> Esta rutina no incluye pruebas de singularidad o casi singularidad.
!> Dichas pruebas deben realizarse antes de llamar a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           En la entrada, UPLO especifica si la matriz es superior o
!>           inferior, de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           En la entrada, TRANS especifica las ecuaciones a resolver de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**T*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           En la entrada, DIAG especifica si A es unitaria o no.
!>
!>              DIAG = 'U' o 'u'   Se asume que A es unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria.
!>

N

!>          N es INTEGER
!>           En la entrada, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

A

!>          A es un array DOUBLE PRECISION, dimensión ( LDA, N )
!>           Antes de la entrada con UPLO = 'U' o 'u', la parte superior
!>           triangular de n por n de A debe contener la matriz triangular
!>           superior y la parte estrictamente triangular inferior de A no
!>           se referencia.
!>           Antes de la entrada con UPLO = 'L' o 'l', la parte inferior
!>           triangular de n por n de A debe contener la matriz triangular
!>           inferior y la parte estrictamente triangular superior de A no
!>           se referencia.
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos
!>           diagonales de A tampoco se referencian, pero se asumen como
!>           unidades.
!>

LDA

!>          LDA es INTEGER
!>           En la entrada, LDA especifica la primera dimensión de A tal como
!>           se declara en el programa (sub)llamador. LDA debe ser al menos
!>           max( 1, n ).
!>

X

!>          X es un array DOUBLE PRECISION, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de la entrada, el array X incrementado debe contener el
!>           vector del lado derecho b de n elementos. A la salida, X se
!>           sobrescribe con el vector solución x.
!>

INCX

!>          INCX es INTEGER
!>           En la entrada, INCX especifica el incremento para los elementos
!>           de X. INCX no debe ser cero.
