NOMBRE

dtd2xsd - Generador de esquemas XML a partir de un documento XML que contiene DTD.

SINOPSIS

dtd2xsd [opciones] archivo-xml-instancia archivo-xsd-opcional

DESCRIPCIÓN

dtd2xsd genera un documento de esquema XML a partir de una definición de tipo de documento (DTD). Por ahora, tienes que especificar un archivo XML de instancia que referencie o contenga la DTD. La DTD en sí misma no es legible con esta pequeña herramienta.

Por defecto, produce el esquema XML resultante en la consola. Si se especifica el parámetro archivo-xsd-opcional, produce el resultado en el archivo especificado.
