Documentación de la función/subrutin

subrutina dtrt05 (character uplo, character trans, character diag, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( ldxact, * ) xact, integer ldxact, double precision, dimension( * ) ferr, double precision, dimension( * ) berr, double precision, dimension( * )

reslts)

DTRT0

5

Propósito

: 
!>
!> DTRT05 prueba los límites de error del refinamiento iterativo para la
!> solución calculada de un sistema de ecuaciones A*X = B, donde A es una
!> matriz triangular n por n.
!>
!> RESLTS(1) = prueba del límite de error
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> Se devuelve un valor grande si esta relación no es menor que uno.
!>
!> RESLTS(2) = residuo de la rutina de refinamiento iterativo
!>           = el máximo de BERR / ( (n+1)*EPS + (*) ), donde
!>             (*) = (n+1)*UNFL / (min_i (abs(A)*abs(X) +abs(b))_i )
!
>

Parámetro

s
UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!
>

TRAN

S 
!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones.
!>          = 'N':  A * X = B  (Sin transponer)
!>          = 'T':  A'* X = B  (Transpuesta)
!>          = 'C':  A'* X = B  (Transpuesta conjugada = Transpuesta)
!
>

DIA

G 
!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es triangular unitaria o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!
>

N 
!>          N es INTEGER
!>          El número de filas de las matrices X, B y XACT, y el
!>          orden de la matriz A.  N >= 0.
!
>

NRH

S 
!>          NRHS es INTEGER
!>          El número de columnas de las matrices X, B y XACT.
!>          NRHS >= 0.
!
>

A 
!>          A es un array DOUBLE PRECISION, dimensión (LDA,N)
!>          La matriz triangular A.  Si UPLO = 'U', la parte triangular
!>          superior n por n principal del array A contiene la matriz
!>          triangular superior, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la parte
!>          triangular inferior n por n principal del array A contiene
!>          la matriz triangular inferior, y la parte estrictamente
!>          triangular superior de A no se referencia.  Si DIAG = 'U',
!>          los elementos diagonales de A tampoco se referencian y se
!>          asume que son 1.
!
>

LD

A 
!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!
>

B 
!>          B es un array DOUBLE PRECISION, dimensión (LDB,NRHS)
!>          Los vectores del lado derecho del sistema de ecuaciones
!>          lineales.
!
>

LD

B 
!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!
>

X 
!>          X es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Los vectores de solución calculados.  Cada vector se almacena
!>          como una columna de la matriz X.
!
>

LD

X 
!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!
>

XAC

T 
!>          XACT es un array DOUBLE PRECISION, dimensión (LDX,NRHS)
!>          Los vectores de solución exacta.  Cada vector se almacena
!>          como una columna de la matriz XACT.
!
>

LDXAC

T 
!>          LDXACT es INTEGER
!>          La dimensión principal del array XACT.  LDXACT >= max(1,N).
!
>

FER

R 
!>          FERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          Los límites estimados del error hacia adelante para cada
!>          vector de solución X.  Si XTRUE es la solución verdadera,
!>          FERR acota la magnitud de la entrada más grande en
!>          (X - XTRUE) dividida por la magnitud de la entrada más
!>          grande en X.
!
>

BER

R 
!>          BERR es un array DOUBLE PRECISION, dimensión (NRHS)
!>          El error relativo hacia atrás componente a componente de
!>          cada vector de solución (es decir, el cambio relativo más
!>          pequeño en cualquier entrada de A o B que hace que X sea
!>          una solución exacta).
!
>

RESLT

S 
!>          RESLTS es un array DOUBLE PRECISION, dimensión (2)
!>          El máximo sobre los vectores de solución NRHS de las
!>          relaciones:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( (n+1)*EPS + (*) )
!
>
