Documentación de la función/subrutina

subrutina dtzrzf (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer info)

DTZRZF

Propósito:

!>
!> DTZRZF reduce la matriz real superior trapezoidal A de M por N ( M<=N )
!> a forma triangular superior mediante transformaciones ortogonales.
!>
!> La matriz superior trapezoidal A se factoriza como
!>
!>    A = ( R  0 ) * Z,
!>
!> donde Z es una matriz ortogonal N por N y R es una matriz triangular
!> superior M por M.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz A.  N >= M.
!>

A

!>          A es un array de DOUBLE PRECISION, dimension (LDA,N)
!>          A la entrada, la parte superior trapezoidal M por N de la matriz
!>          A debe contener la matriz a factorizar.
!>          A la salida, la parte superior triangular M por M de A
!>          contiene la matriz triangular superior R, y los elementos M+1 a
!>          N de las primeras M filas de A, con el array TAU, representan la
!>          matriz ortogonal Z como un producto de M reflectores elementales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array de DOUBLE PRECISION, dimension (M)
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es un array de DOUBLE PRECISION, dimension (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) contiene el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.  LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Más detalles:

!>
!>  La matriz N por N Z puede ser calculada por
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  donde cada Z(k) de N por N se da por
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**T
!>
!>  con v(k) es el k-ésimo vector fila de la matriz M por N
!>
!>     V = ( I   A(:,M+1:N) )
!>
!>  I es la matriz identidad M por M, A(:,M+1:N)
!>  es la salida almacenada en A a la salida de DTZRZF,
!>  y tau(k) es el k-ésimo elemento del array TAU.
!>
!>
