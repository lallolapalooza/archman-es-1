DT-GETNAME(1) Comandos de usuario DT-GETNAME(1)

NOMBRE

dt-getname - programa de prueba de línea de comandos para la función val_getnameinfo()

SINOPSIS

dt-getname [opciones] dirección

DESCRIPCIÓN

Esta utilidad es un envoltorio de línea de comandos para la función val_getnameinfo(). Invoca la función val_getnameinfo() con los argumentos de línea de comandos proporcionados y muestra la información de host y servicio devuelta para el nombre de nodo dado, con un valor de estado de validación.

El estado de salida para este programa es 1 si la respuesta recibida es confiable, 2 si la respuesta recibida está validada y -1 en caso de error. El programa devuelve 0 si no se realizó ninguna validación o si el resultado no fue ni confiable ni validado. Los valores de estado confiable y validado se obtienen utilizando las funciones val_istrusted() y val_isvalidated() de libval(3).

OPCIONES

-p, --puerto
Utiliza el puerto proporcionado. Si se especifica un puerto, no se busca información del servicio.
-F
Utiliza el flag NI_NOFQDN.
-H
Utiliza el flag NI_NUMERICHOST.
-N
Utiliza el flag NI_NAMEREQD.
-S
Utiliza el flag NI_NUMERICSERV.
-D
Utiliza el flag NI_DGRAM.
-o, --salida=<nivel-debug>:<tipo-destino>[:<opciones-destino>]
<nivel-debug> es de 1 a 7, correspondiente a los niveles de syslog ALERT-DEBUG. <tipo-destino> es uno de file, net, syslog, stderr, stdout. <opciones-destino> depende de <tipo-destino>.
file:<nombre-archivo> (abierto en modo de añadir)
net[:<nombre-host>:<puerto-host>] (127.0.0.1:1053)
syslog[:facility] (0-23 (por defecto 1 USER))
-h, --ayuda
Muestra la ayuda y sale.

PRE-REQUISITOS

libval
