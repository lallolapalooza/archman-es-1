RTC_GEOMETRY_TYPE_INSTANCE(3) Núcleos de Ray Tracing de Embree 4 RTC_GEOMETRY_TYPE_INSTANCE(3)

NOMBRE

RTC_GEOMETRY_TYPE_INSTANCE - tipo de geometría de instancia

SINOPSIS

#include <embree4/rtcore.h>
RTCGeometry geometry =
   rtcNewGeometry(device, RTC_GEOMETRY_TYPE_INSTANCE);

DESCRIPCIÓN

Embree soporta la instanciación de escenas utilizando transformaciones afines (matriz 3x3 más traslación). Como la escena instanciada se almacena solo una vez, incluso si se instancia en múltiples ubicaciones, esta característica se puede utilizar para crear escenas muy complejas con una huella de memoria pequeña.

Embree soporta instanciación de un solo nivel y de múltiples niveles. La profundidad máxima de anidamiento de instancias es RTC_MAX_INSTANCE_LEVEL_COUNT; puede configurarse en tiempo de compilación utilizando la constante EMBREE_MAX_INSTANCE_LEVEL_COUNT. Los usuarios deben adaptar esta constante a sus necesidades: las instancias anidadas más profundamente se ignoran silenciosamente en modo de lanzamiento y causan aserciones en modo de depuración.

Las instancias se crean pasando RTC_GEOMETRY_TYPE_INSTANCE a la llamada de la función rtcNewGeometry. La escena instanciada se puede establecer utilizando la llamada rtcSetGeometryInstancedScene y la transformación afín se puede establecer utilizando la función rtcSetGeometryTransform.

Por favor, tenga en cuenta que rtcCommitScene en la escena instanciada debe llamarse primero, seguido por rtcCommitGeometry en la instancia, seguido por rtcCommitScene para la escena de nivel superior que contiene la instancia.

Si un rayo golpea la instancia, los miembros geomID y primID del impacto se establecen en el ID de geometría y el ID primitivo de la primitiva golpeada en la escena instanciada, y el miembro instID del impacto se establece en el ID de geometría de la instancia en la escena de nivel superior.

El esquema de instanciación también se puede implementar utilizando geometrías de usuario. Para lograr esto, el código de geometría de usuario debe establecer el miembro instID del contexto de consulta de rayos en el ID de geometría de la instancia, luego rastrear el rayo transformado y, finalmente, volver a establecer el campo instID del contexto de consulta de rayos en -1. El campo instID es copiado automáticamente por cada intersector de primitiva en el campo instID de la estructura de impacto cuando se golpea la primitiva. Consulte el tutorial de [Geometría de Usuario] para ver un ejemplo.

Para el desenfoque de movimiento de múltiples segmentos, primero se debe especificar el número de pasos de tiempo utilizando la función rtcSetGeometryTimeStepCount. Luego, se puede especificar una transformación para cada paso de tiempo utilizando la función rtcSetGeometryTransform.

Vea los tutoriales [Instanced Geometry] y [Multi Level Instancing] para ver ejemplos de cómo usar instancias.

ESTADO DE SALIDA

En caso de fallo, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcSetGeometryInstancedScene], [rtcSetGeometryTransform]
