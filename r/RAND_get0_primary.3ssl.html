RAND_get0_primary(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RAND_GET0_PRIMARY(3ssl) OpenSSL RAND_GET0_PRIMARY(3ssl)

NOMBRE

RAND_get0_primary, RAND_get0_public, RAND_get0_private, RAND_set0_public, RAND_set0_private - obtener acceso a las instancias globales de EVP_RAND_CTX

SINOPSIS

#include <openssl/rand.h>
EVP_RAND_CTX *RAND_get0_primary(OSSL_LIB_CTX *ctx);
EVP_RAND_CTX *RAND_get0_public(OSSL_LIB_CTX *ctx);
EVP_RAND_CTX *RAND_get0_private(OSSL_LIB_CTX *ctx);
int RAND_set0_public(OSSL_LIB_CTX *ctx, EVP_RAND_CTX *rand);
int RAND_set0_private(OSSL_LIB_CTX *ctx, EVP_RAND_CTX *rand);

DESCRIPCIÓN

La implementación predeterminada de la API RAND (RAND_OpenSSL()) utiliza tres instancias compartidas de DRBG que se acceden a través de la API RAND:

El DRBG público y privado son instancias locales de hilo, que son utilizadas por RAND_bytes() y RAND_priv_bytes(), respectivamente. El DRBG primario es una instancia global, que no está pensada para ser utilizada directamente, pero se utiliza internamente para volver a sembrar las otras dos instancias.

Las tres funciones de obtención proporcionan acceso a las instancias compartidas de DRBG.

Las dos funciones de establecimiento permiten que las instancias públicas y privadas de DRBG sean reemplazadas por otro generador de números aleatorios.

VALORES DE RETORNO

RAND_get0_primary() devuelve un puntero a la instancia DRBG primaria para el OSSL_LIB_CTX ctx dado.

RAND_get0_public() devuelve un puntero a la instancia DRBG pública para el OSSL_LIB_CTX ctx dado.

RAND_get0_private() devuelve un puntero a la instancia DRBG privada para el OSSL_LIB_CTX ctx dado.

RAND_set0_public() y RAND_set0_private() devuelven 1 en caso de éxito y 0 en caso de error.

NOTAS

No es seguro para hilos acceder a la instancia DRBG primaria. La instancia DRBG pública y privada se puede acceder de forma segura, ya que son locales de hilo. Tenga en cuenta, sin embargo, que los cambios en estas dos instancias solo se aplican al hilo actual.

Por esa razón, se recomienda no cambiar la configuración de estas tres instancias directamente. En su lugar, una aplicación debería cambiar la configuración predeterminada para las nuevas instancias de DRBG en el momento de la inicialización, antes de crear hilos adicionales.

Durante la inicialización, es posible cambiar el intervalo de resiembra y el intervalo de tiempo de resiembra. También es posible intercambiar completamente las devoluciones de llamada de resiembra.

Para establecer el tipo de DRBG que se instanciará, use la llamada RAND_set_DRBG_type(3) antes de acceder a la infraestructura de generación de números aleatorios.

Las dos funciones de establecimiento operan en el hilo actual. Si desea utilizar el mismo generador de números aleatorios en todos los hilos, cada hilo debe llamar individualmente a las funciones de establecimiento.

VER TAMBIÉN

EVP_RAND(3), RAND_set_DRBG_type(3)

HISTORIA

RAND_set0_public() y RAND_set0_private() se añadieron en OpenSSL 3.1.

Las funciones restantes se añadieron en OpenSSL 3.0.
