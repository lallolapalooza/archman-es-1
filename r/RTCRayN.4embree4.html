RTCRayN(3) Núcleos de Ray Tracing de Embree 4 RTCRayN(3)

NOMBRE

RTCRayN - paquete de rayos de tamaño en tiempo de ejecución

SINOPSIS

#include <embree4/rtcore_ray.h>
struct RTCRayN;
float& RTCRayN_org_x(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_org_y(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_org_z(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_tnear(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_x(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_y(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_z(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_time (RTCRayN* ray, unsigned int N, unsigned int i);
float&        RTCRayN_tfar (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_mask (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_id   (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_flags(RTCRayN* ray, unsigned int N, unsigned int i);

DESCRIPCIÓN

Cuando el tamaño del paquete de rayos no se conoce en tiempo de compilación (por ejemplo, cuando Embree devuelve un paquete de rayos en la función de devolución de llamada RTCFilterFuncN), Embree utiliza el tipo RTCRayN para los paquetes de rayos. Estos paquetes de rayos solo pueden tener tamaños de 1, 4, 8 o 16. No se utilizará ningún otro tamaño de paquete.

Puede implementar diferentes rutas de código especial para cada uno de estos posibles tamaños de paquete y convertir el rayo al tipo de paquete de rayos apropiado, o implementar una ruta de código general que utilice las funciones auxiliares RTCRayN_XXX para acceder a los componentes del paquete de rayos.

Estas funciones auxiliares reciben un puntero al paquete de rayos (argumento ray), el tamaño del paquete (argumento N) y devuelven una referencia a un componente (por ejemplo, componente x del origen) del i-ésimo rayo del paquete (argumento i).
