RTCBufferType(3) Embree Ray Tracing Kernels 4 RTCBufferType(3)

NOMBRE

RTCFormat - especifica el formato de los datos en los búferes

SINOPSIS

#include <embree4/rtcore_ray.h>
enum RTCBufferType
{
  RTC_BUFFER_TYPE_INDEX            = 0,
  RTC_BUFFER_TYPE_VERTEX           = 1,
  RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE = 2,
  RTC_BUFFER_TYPE_NORMAL           = 3,
  RTC_BUFFER_TYPE_TANGENT          = 4,
  RTC_BUFFER_TYPE_NORMAL_DERIVATIVE = 5,
  RTC_BUFFER_TYPE_GRID                 = 8,
  RTC_BUFFER_TYPE_FACE                 = 16,
  RTC_BUFFER_TYPE_LEVEL                = 17,
  RTC_BUFFER_TYPE_EDGE_CREASE_INDEX    = 18,
  RTC_BUFFER_TYPE_EDGE_CREASE_WEIGHT   = 19,
  RTC_BUFFER_TYPE_VERTEX_CREASE_INDEX  = 20,
  RTC_BUFFER_TYPE_VERTEX_CREASE_WEIGHT = 21,
  RTC_BUFFER_TYPE_HOLE                 = 22,
  RTC_BUFFER_TYPE_TRANSFORM            = 23,
  RTC_BUFFER_TYPE_FLAGS = 32
};

DESCRIPCIÓN

La estructura RTBufferType define ranuras para asignar búferes de datos utilizando las llamadas a la API [rtcSetGeometryBuffer], [rtcSetSharedGeometryBuffer] y [rtcSetNewGeometryBuffer].

Para la mayoría de los tipos de geometría, la ranura RTC_BUFFER_TYPE_INDEX se utiliza para asignar un búfer de índice, mientras que RTC_BUFFER_TYPE_VERTEX se utiliza para asignar el búfer de vértices correspondiente.

La ranura RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE puede utilizarse para asignar datos de vértices adicionales arbitrarios que pueden interpolarse utilizando la llamada a la API [rtcInterpolate].

RTC_BUFFER_TYPE_NORMAL, RTC_BUFFER_TYPE_TANGENT y RTC_BUFFER_TYPE_NORMAL_DERIVATIVE son búferes especiales necesarios para asignar normales, tangentes y derivadas de normales por vértice para algunos tipos de curvas.

El búfer RTC_BUFFER_TYPE_GRID se utiliza para asignar el búfer de primitivas de cuadrícula para geometrías de cuadrícula (consulte [RTC_GEOMETRY_TYPE_GRID]).

RTC_BUFFER_TYPE_FACE, RTC_BUFFER_TYPE_LEVEL, RTC_BUFFER_TYPE_EDGE_CREASE_INDEX, RTC_BUFFER_TYPE_EDGE_CREASE_WEIGHT, RTC_BUFFER_TYPE_VERTEX_CREASE_INDEX, RTC_BUFFER_TYPE_VERTEX_CREASE_WEIGHT y RTC_BUFFER_TYPE_HOLE son búferes especiales necesarios para crear mallas de subdivisión (consulte [RTC_GEOMETRY_TYPE_SUBDIVISION]).

El búfer RTC_BUFFER_TYPE_TRANSFORM se utiliza para proporcionar información de transformación de instancias para geometrías de arreglos de instancias (consulte [RTC_GEOMETRY_TYPE_INSTANCE_ARRAY]).

RTC_BUFFER_TYPE_FLAGS puede utilizarse para añadir indicadores adicionales por primitiva de una geometría, y actualmente solo se utiliza para curvas lineales.
