RSA_blinding_on(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_BLINDING_ON(3ssl) OpenSSL RSA_BLINDING_ON(3ssl)

NOMBRE

RSA_blinding_on, RSA_blinding_off - proteger la operación RSA de ataques de temporización

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int RSA_blinding_on(RSA *rsa, BN_CTX *ctx);
void RSA_blinding_off(RSA *rsa);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas.

RSA es vulnerable a ataques de temporización. En una configuración donde los atacantes pueden medir el tiempo de las operaciones de descifrado o firma RSA, se debe usar el "blinding" (cegamiento) para proteger la operación RSA de ese ataque.

RSA_blinding_on() activa el cegamiento para la clave rsa y genera un factor de cegamiento aleatorio. ctx es NULL o un BN_CTX preasignado e inicializado.

RSA_blinding_off() desactiva el cegamiento y libera la memoria utilizada para el factor de cegamiento.

VALORES DE RETORNO

RSA_blinding_on() devuelve 1 si tiene éxito, y 0 si ocurrió un error.

RSA_blinding_off() no devuelve ningún valor.

HISTORIAL

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
