NOMBRE

RTC_GEOMETRY_TYPE_GRID - tipo de geometría de rejilla

SINOPSIS

#include <embree3/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_GRID);

DESCRIPCIÓN

Las mallas de rejilla se crean pasando RTC_GEOMETRY_TYPE_GRID a la llamada de función rtcNewGeometry, y contienen un array de primitivas de rejilla. Este array de rejillas se puede especificar configurando un buffer de rejilla (con tipo RTC_BUFFER_TYPE_GRID y formato RTC_FORMAT_GRID) y los vértices de la malla de rejilla especificando un buffer de vértices (tipo RTC_BUFFER_TYPE_VERTEX). Consulte rtcSetGeometryBuffer y rtcSetSharedGeometryBuffer para obtener más detalles sobre cómo configurar buffers. El número de primitivas de rejilla en la malla de rejilla se infiere del tamaño del buffer de rejilla.

El buffer de vértices contiene un array de coordenadas de punto flotante de precisión simple x, y, z (formato RTC_FORMAT_FLOAT3), y el número de vértices se infiere del tamaño de ese buffer.

Cada rejilla en el buffer de rejilla es del tipo RTCGrid:

struct RTCGrid
{
  unsigned int startVertexID;
  unsigned int stride;
  unsigned short width,height; 
};

La estructura RTCGrid describe una rejilla 2D de vértices (con respecto al buffer de vértices de la malla de rejilla). Los miembros width y height especifican el número de vértices en la dirección u y v, por ejemplo, establecer width y height a 3 configura una rejilla de vértices de 3x3. El ancho y alto máximos permitidos son 32767. El startVertexID especifica el ID del vértice superior izquierdo en la rejilla de vértices, mientras que el parámetro stride especifica un paso (en número de vértices) para avanzar a la siguiente fila.

Una rejilla de vértices de dimensiones width y height se trata como una rejilla de quads (pares de triángulos) de (width-1) x (height-1), con el mismo manejo de bordes compartidos que para las mallas de quads regulares. Sin embargo, las coordenadas u/v tienen el rango uniforme [0..1] para una rejilla de vértices completa. La dirección u sigue el ancho de la rejilla mientras que la dirección v sigue la altura.

Para desenfoque de movimiento multiespacio, el número de pasos de tiempo debe especificarse primero utilizando la llamada rtcSetGeometryTimeStepCount. Luego, se puede configurar un buffer de vértices para cada paso de tiempo utilizando diferentes ranuras de buffer, y todos estos buffers deben tener el mismo stride y tamaño.

ESTADO DE SALIDA

En caso de fallo se devuelve NULL y se establece un código de error que puede consultarse con rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry]
