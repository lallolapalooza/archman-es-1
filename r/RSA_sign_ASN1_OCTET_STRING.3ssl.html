RSA_sign_ASN1_OCTET_STRING(3ssl)

RSA_SIGN_ASN1_OCTET_STRING(3ssl) OpenSSL RSA_SIGN_ASN1_OCTET_STRING(3ssl)

NOMBRE

RSA_sign_ASN1_OCTET_STRING, RSA_verify_ASN1_OCTET_STRING - Firmas RSA

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido deprecadas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int RSA_sign_ASN1_OCTET_STRING(int dummy, unsigned char *m,
                               unsigned int m_len, unsigned char *sigret,
                               unsigned int *siglen, RSA *rsa);
int RSA_verify_ASN1_OCTET_STRING(int dummy, unsigned char *m,
                                 unsigned int m_len, unsigned char *sigbuf,
                                 unsigned int siglen, RSA *rsa);

DESCRIPCIÓN

Todas las funciones descritas en esta página están deprecadas. Las aplicaciones deberían usar en su lugar las APIs de EVP PKEY.

RSA_sign_ASN1_OCTET_STRING() firma la cadena de octetos m de tamaño m_len usando la clave privada rsa representada en DER usando el relleno PKCS #1. Almacena la firma en sigret y el tamaño de la firma en siglen. sigret debe apuntar a RSA_size(rsa) bytes de memoria.

El parámetro dummy es ignorado.

El generador de números aleatorios debe estar sembrado al llamar a RSA_sign_ASN1_OCTET_STRING(). Si la siembra automática o la resiembra del CSPRNG de OpenSSL falla debido a circunstancias externas (ver RAND(7)), la operación fallará.

RSA_verify_ASN1_OCTET_STRING() verifica que la firma sigbuf de tamaño siglen es la representación DER de una cadena de octetos dada m de tamaño m_len. El parámetro dummy es ignorado. rsa es la clave pública del firmante.

VALORES DE RETORNO

RSA_sign_ASN1_OCTET_STRING() devuelve 1 en caso de éxito, 0 en caso contrario. RSA_verify_ASN1_OCTET_STRING() devuelve 1 en caso de verificación exitosa, 0 en caso contrario.

Los códigos de error pueden obtenerse mediante ERR_get_error(3).

ERRORES

Estas funciones no tienen un propósito reconocible.

VER TAMBIÉN

ERR_get_error(3), RAND_bytes(3), RSA_sign(3), RSA_verify(3), RAND(7)

HISTORIAL

Todas estas funciones fueron deprecadas en OpenSSL 3.0.
