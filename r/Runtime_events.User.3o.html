Módulo User
: sig end

Los eventos de usuario son una forma para que las bibliotecas proporcionen eventos en tiempo de ejecución que puedan ser consumidos por otras herramientas. Estos eventos pueden transportar tipos de datos conocidos o valores personalizados. El número máximo actual de eventos de usuario es 8192.

type tag = ..

El tipo para una etiqueta de evento de usuario. Las etiquetas se utilizan para discriminar entre eventos de usuario del mismo tipo.

type 'value t

El tipo para un evento de usuario. Los eventos de usuario describen su etiqueta, el tipo de datos que transportan y un nombre único basado en cadenas.

val register : string -> tag -> 'value Runtime_events.Type.t -> 'value t

register nombre etiqueta ty registra un nuevo evento con un nombre único, que transporta una etiqueta y valores de tipo ty.

val write : 'value t -> 'value -> unit

write t v emite el valor v para el evento t.

val name : 'a t -> string

name t es el nombre identificador único del evento t.

val tag : 'a t -> tag

tag t es la etiqueta asociada del evento t, cuando se conoce. Un evento puede ser desconocido si no se registró en el programa consumidor.
