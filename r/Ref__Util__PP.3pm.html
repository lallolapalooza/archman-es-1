Ref::Util::PP(3) Documentación de Perl contribuida por el usuario Ref::Util::PP(3)

NOMBRE

Ref::Util::PP - versión puramente Perl de Ref::Util

VERSIÓN

versión 0.204

SINOPSIS

use Ref::Util;

DESCRIPCIÓN

Este módulo proporciona una implementación puramente Perl de las funciones de Ref::Util.

Ref::Util::PP se usará automáticamente si Ref::Util está instalado en un sistema sin compilador C, pero puedes forzar su uso estableciendo tanto $Ref::Util::IMPLEMENTATION como la variable de entorno "PERL_REF_UTIL_IMPLEMENTATION" a "PP".
