NOMBRE

RTC_GEOMETRY_TYPE_INSTANCE - tipo de geometría de instancia

SINOPSIS

#include <embree3/rtcore.h>
RTCGeometry geometry =
   rtcNewGeometry(device, RTC_GEOMETRY_TYPE_INSTANCE);

DESCRIPCIÓN

Embree soporta la instanciación de escenas mediante transformaciones afines (matriz de 3x3 más traslación). Dado que la escena instanciada se almacena solo una vez, incluso si se instancia en múltiples ubicaciones, esta característica puede usarse para crear escenas muy complejas con una huella de memoria pequeña.

Embree soporta instanciación de un solo nivel y de múltiples niveles. La profundidad máxima de anidamiento de instancias es RTC_MAX_INSTANCE_LEVEL_COUNT; puede configurarse en tiempo de compilación usando la constante EMBREE_MAX_INSTANCE_LEVEL_COUNT. Los usuarios deben adaptar esta constante a sus necesidades: las instancias anidadas a mayor profundidad se ignoran silenciosamente en modo de lanzamiento (release), y causan aserciones en modo de depuración (debug).

Las instancias se crean pasando RTC_GEOMETRY_TYPE_INSTANCE a la llamada de función rtcNewGeometry. La escena instanciada se puede establecer usando la llamada rtcSetGeometryInstancedScene, y la transformación afín se puede establecer usando la función rtcSetGeometryTransform.

Por favor, tenga en cuenta que primero se debe llamar a rtcCommitScene en la escena instanciada, seguido de rtcCommitGeometry en la instancia, seguido de rtcCommitScene para la escena de nivel superior que contiene la instancia.

Si un rayo golpea la instancia, los miembros geomID y primID del golpe se establecen al ID de geometría y al ID primitivo del primitivo golpeado en la escena instanciada, y el miembro instID del golpe se establece al ID de geometría de la instancia en la escena de nivel superior.

El esquema de instanciación también se puede implementar usando geometrías de usuario. Para lograr esto, el código de geometría de usuario debe establecer el miembro instID del contexto de intersección al ID de geometría de la instancia, luego trazar el rayo transformado, y finalmente volver a establecer el campo instID del contexto de intersección a -1. El campo instID es copiado automáticamente por cada intersector primitivo en el campo instID de la estructura de golpe cuando se golpea el primitivo. Vea el tutorial [Geometría de Usuario] para un ejemplo.

Para desenfoque de movimiento multisegmento, primero se debe especificar el número de pasos de tiempo usando la función rtcSetGeometryTimeStepCount. Luego, se puede especificar una transformación para cada paso de tiempo usando la función rtcSetGeometryTransform.

Vea los tutoriales [Geometría Instanciada] y [Instanciación Multinivel] para ejemplos de cómo usar instancias.

ESTADO DE SALIDA

En caso de fallo se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcSetGeometryInstancedScene], [rtcSetGeometryTransform]
