NOMBRE

Regexp::Common - Proporciona expresiones regulares comúnmente solicitadas

SINOPSIS

# USO ESTÁNDAR 
use Regexp::Common;
while (<>) {
    /$RE{num}{real}/               and print q{un número};
    /$RE{quoted}/                  and print q{una cadena entre comillas ['"`]};
   m[$RE{delimited}{-delim=>'/'}]  and print q{una secuencia /.../};
    /$RE{balanced}{-parens=>'()'}/ and print q{paréntesis balanceados};
    /$RE{profanity}/               and print q{una palabra #*@%-ing};
}
# INTERFAZ BASADA EN SUBRUTINA
use Regexp::Common 'RE_ALL';
while (<>) {
    $_ =~ RE_num_real()              and print q{un número};
    $_ =~ RE_quoted()                and print q{una cadena entre comillas ['"`]};
    $_ =~ RE_delimited(-delim=>'/')  and print q{una secuencia /.../};
    $_ =~ RE_balanced(-parens=>'()'} and print q{paréntesis balanceados};
    $_ =~ RE_profanity()             and print q{una palabra #*@%-ing};
}
# COINCIDENCIA EN LÍNEA...
if ( $RE{num}{int}->matches($text) ) {...}
# ...Y SUSTITUCIÓN
my $cropped = $RE{ws}{crop}->subs($uncropped);
# PATRONES PERSONALIZADOS
use Regexp::Common 'pattern';
pattern name   => ['name', 'mine'],
        create => '(?i:J[.]?\s+A[.]?\s+Perl-Hacker)',
        ;
my $name_matcher = $RE{name}{mine};
pattern name    => [ 'lineof', '-char=_' ],
        create  => sub {
                       my $flags = shift;
                       my $char = quotemeta $flags->{-char};
                       return '(?:^$char+$)';
                   },
        match   => sub {
                       my ($self, $str) = @_;
                       return $str !~ /[^$self->{flags}{-char}]/;
                   },
        subs   => sub {
                       my ($self, $str, $replacement) = @_;
                       $_[1] =~ s/^$self->{flags}{-char}+$//g;
                  },
        ;
my $asterisks = $RE{lineof}{-char=>'*'};
# DECIDIR QUÉ PATRONES CARGAR.
use Regexp::Common qw /comment number/;  # Patrones de comentario y número.
use Regexp::Common qw /no_defaults/;     # No cargar ningún patrón.
use Regexp::Common qw /!delimited/;      # Todos, pero los patrones delimitados.

DESCRIPCIÓN

Por defecto, este módulo exporta un único hash (%RE) que almacena o genera expresiones regulares comúnmente necesarias (ver "Lista de patrones disponibles").

Existe una sintaxis alternativa, basada en subrutinas, descrita en "Interfaz basada en subrutina".

Sintaxis general para solicitar patrones

Para acceder a un patrón particular, %RE se trata como un hash jerárquico de hashes (de hashes...), donde cada clave sucesiva es un identificador. Por ejemplo, para acceder al patrón que coincide con números reales, se especifica:

$RE{num}{real}

y para acceder al patrón que coincide con enteros:

$RE{num}{int}

Las capas más profundas del hash se utilizan para especificar *flags*: argumentos que modifican el patrón resultante de alguna manera. Las claves utilizadas para acceder a estas capas se prefijan con un signo menos y pueden tener un valor; si se proporciona un valor, se hace usando una clave multidimensional. Por ejemplo, para acceder al patrón que coincide con números reales en base 2 con comas incrustadas separando grupos de tres dígitos (por ejemplo, 10,101,110.110101101):

$RE{num}{real}{-base => 2}{-sep => ','}{-group => 3}

Gracias a la magia de Perl, estas capas de flags pueden especificarse en cualquier orden (¡e incluso intercaladas entre las claves identificadoras!) por lo que se podría obtener el mismo patrón con:

$RE{num}{real}{-sep => ','}{-group => 3}{-base => 2}

o:

$RE{num}{-base => 2}{real}{-group => 3}{-sep => ','}

o incluso:

$RE{-base => 2}{-group => 3}{-sep => ','}{num}{real}

etc.

Tenga en cuenta, sin embargo, que el orden relativo entre las claves identificadoras *es* significativo. Es decir:

$RE{list}{set}

no sería lo mismo que:

$RE{set}{list}

Sintaxis de flags

En versiones anteriores a la 2.113, los flags también podían escribirse como "{"-flag=valor"}". Esto ya no funciona, aunque "{"-flag$;valor"}" todavía lo hace. Sin embargo, "{-flag => 'valor'}" es la sintaxis preferida.

Flags universales

Normalmente, los flags son específicos para un solo patrón. Sin embargo, hay dos flags que todos los patrones pueden especificar.

"-keep"
Por defecto, los patrones proporcionados por %RE no contienen paréntesis de captura. Sin embargo, si se especifica el flag "-keep" (no requiere valor), entonces se capturan las subcadenas significativas que coincide el patrón. Por ejemplo: 
if ($str =~ $RE{num}{real}{-keep}) {
        $number   = $1;
        $whole    = $3;
        $decimals = $5;
}

Se necesita cuidado especial si un patrón "kept" se interpola en una expresión regular más grande, ya que la presencia de otros paréntesis de captura probablemente cambiará las variables de "número" en las que se guardan las subcadenas significativas.

Ver también "Añadiendo nuevas expresiones regulares", que describe cómo crear nuevos patrones con corchetes de captura "opcionales" que responden a "-keep".

"-i"
Algunos patrones o subpatrones solo coinciden con letras minúsculas o mayúsculas. Si se desea hacer coincidir sin distinción entre mayúsculas y minúsculas, una opción es usar el modificador de regexp "/i", o la secuencia especial "(?i)". Pero si se usa la interfaz funcional, no se tiene esta opción. El switch "-i" resuelve este problema; al usarlo, el patrón realizará una coincidencia sin distinción entre mayúsculas y minúsculas.

Interfaz OO y coincidencia/sustitución en línea

Los patrones devueltos por %RE son objetos, así que en lugar de escribir:

if ($str =~ /$RE{some}{pattern}/ ) {...}

puedes escribir:

if ( $RE{some}{pattern}->matches($str) ) {...}

Para la coincidencia, esto no parece tener gran ventaja aparte de la legibilidad (pero ver abajo).

Para sustituciones, tiene otras ventajas significativas. Frecuentemente querrás realizar una sustitución en una cadena sin cambiar la original. La mayoría de la gente usa esto:

$changed = $original;
$changed =~ s/$RE{some}{pattern}/$replacement/;

Los más hábiles usan:

($changed = $original) =~ s/$RE{some}{pattern}/$replacement/;

Regexp::Common te permite escribir esto:

$changed = $RE{some}{pattern}->subs($original=>$replacement);

Aparte de reducir la ansiedad por la precedencia, este enfoque tiene las ventajas añadidas de que el comportamiento de la sustitución puede ser optimizado a partir de la expresión regular, y la cadena de reemplazo puede ser proporcionada por defecto (ver "Añadiendo nuevas expresiones regulares").

Por ejemplo, en la implementación de esta sustitución:

$cropped = $RE{ws}{crop}->subs($uncropped);

la cadena vacía por defecto se proporciona automáticamente, y la sustitución se optimiza para usar:

$uncropped =~ s/^\s+//;
$uncropped =~ s/\s+$//;

en lugar de:

$uncropped =~ s/^\s+|\s+$//g;

Interfaz basada en subrutinas

La interfaz basada en hashes se eligió porque permite interpolar expresiones regulares sin esfuerzo, y porque también permite "curryarlas". Por ejemplo:

my $num = $RE{num}{int};
my $commad     = $num->{-sep=>','}{-group=>3};
my $duodecimal = $num->{-base=>12};

Sin embargo, el uso de hashes vinculados hace que el acceso a los patrones de Regexp::Common sea más lento de lo que podría ser. En contextos donde la impaciencia prevalece sobre la pereza, Regexp::Common proporciona una interfaz adicional basada en subrutinas.

Para cada entrada (sub-)en el hash %RE ("$RE{key1}{key2}{etc}"), hay una subrutina exportable correspondiente: RE_key1_key2_etc(). El nombre de cada subrutina es la combinación separada por guiones bajos del nombre de la clave.

SYNOPSIS

use Regexp::Common;
my $re = Regexp::Common::RE_num();
$string =~ /$re/;
# or
use Regexp::Common qw( RE_num RE_date );
$string =~ RE_num();
$string =~ RE_date(-sep=>'-');
# or
use Regexp::Common 'RE_ALL';
$string =~ RE_comment();
# or
use Regexp::Common 'RE_num_ALL';
$string =~ RE_num_int();
$string =~ RE_num_real();

This module provides a convenient way to use complex and often-used regular expressions. It is not intended to be a complete collection of all possible regular expressions, but rather to provide a useful starting point and a framework for adding your own.

The core of the module is a hash named %RE where each key is the name of a pattern, and the value is a reference to a regular expression object. For example, $RE{number} is a reference to a regular expression that matches numbers.

The patterns can be retrieved from the hash using the standard Perl notation "${RE}{key}". In addition, the module provides a set of exportable subroutines that are shortcuts for retrieving these regular expressions. Thus, instead of writing:

use Regexp::Common;
$string =~ /$RE{number}/;

you can write:

use Regexp::Common qw( RE_num );
$string =~ RE_num();

When called, these subroutines return ordinary "qr"'d regular expressions.

Furthermore, you can pass arguments to these subroutines. These arguments are used to customize the generated regular expression. For example, RE_num_real(-base=>8) will return a regular expression that matches real numbers in base 8.

The arguments are passed as a hash. The keys of the hash are flags that modify the behavior of the pattern. The available flags depend on the specific pattern. Most patterns support a "-keep" flag, which causes the entire match to be captured in group 0. This is the default behaviour.

The arguments are processed by the underlying pattern definition. When a pattern is defined with flags, they are passed to the subroutine that generates the regex. The subroutine can then use these flags to alter the resulting regex. The arguments are passed to the subroutine in its argument list.

Note that the arguments are concatenated using the no-op function, which is the default behavior for concatenation of the non-flag keys that locate the same pattern in %RE. Flags are passed to the subroutine in its argument list. Thus:

use Regexp::Common qw( RE_ws_crop RE_num_real RE_profanity );
$str =~ RE_ws_crop() and die "Surrounded by whitespace";
$str =~ RE_num_real(-base=>8, -sep=>" ") or next;
$offensive = RE_profanity(-keep);
$str =~ s/$offensive/$bad{$1}++; "<expletive deleted>"/ge;

Note that, unlike the hash-based interface (which returns objects), these subroutines return ordinary "qr"'d regular expressions. Hence they do not curry, nor do they provide the OO match and substitution inlining described in the previous section.

It is also possible to export subroutines for all available patterns like so:

use Regexp::Common 'RE_ALL';

Or you can export all subroutines with a common prefix of keys like so:

use Regexp::Common 'RE_num_ALL';

which will export "RE_num_int" and "RE_num_real" (and if you have create more patterns who have first key num, those will be exported as well). In general, RE_key1_..._keyn_ALL will export all subroutines whose pattern names have first keys key1 ... keyn.

Añadiendo nuevas expresiones regulares

Puedes añadir tus propias expresiones regulares al hash %RE en tiempo de ejecución, usando la subrutina exportable "pattern". Espera una lista de pares clave/valor similar a un hash que especifica el comportamiento del patrón. Los diversos pares de argumentos posibles son:

"name => [ @list ]"
Un argumento requerido que especifica el nombre del patrón, y cualquier bandera que pueda tomar, a través de una referencia a una lista de cadenas. Por ejemplo: 
pattern name => [qw( line of -char )],
        # otros argumentos aquí
        ;

Esto especifica una entrada "$RE{line}{of}", que puede tomar una bandera "-char".

Las banderas también pueden especificarse con un valor por defecto, que se utiliza siempre que la bandera se especifica sin un valor explícito (pero no cuando se omite la bandera). Por ejemplo:

pattern name => [qw( line of -char=_ )],
        # el carácter por defecto es '_'
        # otros argumentos aquí
        ;
"create => $sub_ref_or_string"
Un argumento requerido que especifica ya sea una cadena que será devuelta como el patrón: 
pattern name => [qw( line of underscores )],
        create => q/(?:^_+$)/
        ;

o una referencia a una subrutina que será llamada para crear el patrón:

pattern name => [qw( line of -char=_ )],
        create => sub {
                        my ($self, $flags) = @_;
                        my $char = quotemeta $flags->{-char};
                        return '(?:^$char+$)';
                    },
        ;

Si se usa la versión de subrutina, la subrutina será llamada con tres argumentos: una referencia al objeto de patrón en sí, una referencia a un hash que contiene las banderas y sus valores, y una referencia a un array que contiene las claves que no son banderas.

Lo que la subrutina devuelva se convertirá en cadena como patrón.

Sin importar cómo se cree el patrón, se procesa inmediatamente para incluir o excluir paréntesis de captura (de acuerdo con el valor de la bandera "-keep"). Para especificar tales paréntesis de captura "opcionales" dentro de la expresión regular asociada con "create", usa la notación "(?k:...)". Cualquier paréntesis de este tipo se convertirá en "(...)" cuando se especifique la bandera "-keep", o en "(?:...)" cuando no se haga. Es una convención de Regexp::Common que los paréntesis de captura más externos capturen siempre el patrón completo, pero esto no se impone.

"match => $sub_ref"
Un argumento opcional que especifica una subrutina que será llamada cuando se invoque el método "$RE{...}->matches(...)" de este patrón.

La subrutina debe esperar dos argumentos: una referencia al objeto de patrón en sí, y la cadena a comparar.

Debería devolver los mismos tipos de valores que devuelve "m/.../".

pattern name => [qw( line of -char )],
        create => sub {...},
        match => sub {
                        my ($self, $str) = @_;
                        $str !~ /[^$self->{flags}{-char}]/;
                   },
        ;
"subs => $sub_ref"
Un argumento opcional que especifica una subrutina que será llamada cuando se invoque el método "$RE{...}->subs(...)" de este patrón.

La subrutina debe esperar tres argumentos: una referencia al objeto de patrón en sí, la cadena a modificar y el valor a sustituir en ella. El tercer argumento puede ser "undef", indicando que se requiere la sustitución por defecto.

La subrutina debe devolver los mismos tipos de valores que devuelve una "s/.../.../".

Por ejemplo:

pattern name => [ 'lineof', '-char=_' ],
        create => sub {...},
        subs => sub {
                     my ($self, $str, $ignore_replacement) = @_;
                     $_[1] =~ s/^$self->{flags}{-char}+$//g;
                   },
        ;

Nótese que tal subrutina casi siempre necesitará modificar $_[1] directamente.

"version => $minimum_perl_version"
Si se proporciona este argumento, especifica la versión mínima de perl requerida para usar el nuevo patrón. Los intentos de usar el patrón con versiones anteriores de perl generarán un diagnóstico fatal.

Cargando conjuntos específicos de patrones.

Por defecto, todos los conjuntos de patrones listados a continuación están disponibles. Sin embargo, es posible indicar qué conjuntos de patrones deben estar disponibles; los conjuntos deseados se deben dar como argumentos a "use". Alternativamente, también es posible indicar qué conjuntos de patrones no deben estar disponibles; esos conjuntos se darán como argumento a la declaración "use", pero irán precedidos de un signo de exclamación. El argumento no_defaults indica que no se pondrá ninguno de los patrones por defecto a disposición. Esto es útil, por ejemplo, si todo lo que deseas es la subrutina pattern().

Ejemplos:

use Regexp::Common qw /comment number/;  # Patrones de comentarios y números.
use Regexp::Common qw /no_defaults/;     # No cargar ningún patrón.
use Regexp::Common qw /!delimited/;      # Todos, excepto patrones delimitados.

También es posible cargar tu propio conjunto de patrones. Si tienes un módulo "Regexp::Common::my_patterns" que hace que los patrones estén disponibles, puedes hacer que estén disponibles con

use Regexp::Common qw /my_patterns/;

Nótese que los patrones por defecto seguirán estando disponibles; solo si usas no_defaults, o mencionas explícitamente uno de los conjuntos por defecto, los valores por defecto no mencionados no estarán disponibles.

Lista de patrones disponibles

Los patrones listados a continuación están actualmente disponibles. Cada conjunto de patrones tiene su propia página de manual que describe los detalles. Para cada conjunto de patrones llamado name, la página de manual Regexp::Common::name describe los detalles.

Actualmente están disponibles:

Regexp::Common::balanced
Proporciona expresiones regulares para cadenas con delimitadores parentesizados balanceados.
Regexp::Common::comment
Proporciona expresiones regulares para comentarios de varios idiomas (43 idiomas actualmente).
Regexp::Common::delimited
Proporciona expresiones regulares para cadenas delimitadas.
Regexp::Common::lingua
Proporciona expresiones regulares para palíndromos.
Regexp::Common::list
Proporciona expresiones regulares para listas.
Regexp::Common::net
Proporciona expresiones regulares para direcciones IPv4, IPv6 y MAC.
Regexp::Common::number
Proporciona expresiones regulares para números (enteros y reales).
Regexp::Common::profanity
Proporciona expresiones regulares para groserías.
Regexp::Common::whitespace
Proporciona expresiones regulares para espacios en blanco al principio y al final.
Regexp::Common::zip
Proporciona expresiones regulares para códigos postales.

DIAGNOSTICS

'No such subroutine: "%s"'
La interfaz basada en subrutinas no reconoció la subrutina solicitada. A menudo causado por un error tipográfico o un nombre especificado incompletamente.
"Can't create unknown regex: $RE{...}"
Regexp::Common no tiene un generador para el patrón solicitado. A menudo indica un parámetro mal escrito o faltante.
"Perl %f no soporta el patrón $RE{...}. Necesitas Perl %f o posterior"
El patrón solicitado requiere características avanzadas de expresiones regulares (por ejemplo, recursión) que no están disponibles en tu versión de Perl. Es hora de actualizar.
"pattern() requiere argumento: name => [ @list ]"
Cada especificación de patrón definida por el usuario debe tener un nombre.
"pattern() requiere argumento: create => $sub_ref_or_string"
Cada especificación de patrón definida por el usuario debe proporcionar un mecanismo de creación de patrón: ya sea una cadena de patrón o una referencia a una subrutina que devuelve la cadena de patrón.
"Base must be between 1 and 36"
El patrón "$RE{num}{real}{-base=>'N'} utiliza los caracteres [0-9A-Z] para representar los dígitos de varias bases. Por lo tanto, solo produce expresiones regulares para bases de hasta hexatricensimal.
"Must specify delimiter in $RE{delimited}"
El patrón no tiene un delimitador predeterminado. Necesitas escribir: "$RE{delimited}{-delim=>X'} para algún carácter X

NO ES UN ERROR

•
Los diversos patrones no están anclados. Es decir, un patrón como "$RE {num} {int}" coincidirá con "abc4def", porque una subcadena del sujeto coincide. Esto es intencional y no un error. Si quieres que el patrón esté anclado, usa algo como: 
my $integer = $RE {num} {int};
$subj =~ /^$integer$/ and print "Matches!\n";
