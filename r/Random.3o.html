Módulo Random
: sig end

Generadores de números pseudoaleatorios (PRNG).

Con múltiples dominios, cada dominio tiene su propio generador que evoluciona independientemente de los generadores de otros dominios. Cuando se crea un dominio, su generador se inicializa dividiendo el estado del generador asociado con el dominio padre.

En contraste, todos los hilos dentro de un dominio comparten el mismo generador local del dominio. Se pueden crear generadores independientes con la función Random.split y utilizarlos con las funciones del módulo Random.State.

Antes de 5.0 la generación de valores aleatorios utilizaba un algoritmo diferente. Esto afecta a todas las funciones de este módulo que devuelven valores aleatorios.

Funciones básicas

val init : int -> unit

Inicializa el generador local del dominio, utilizando el argumento como semilla. La misma semilla siempre producirá la misma secuencia de números.

val full_init : int array -> unit

Igual que Random.init pero toma más datos como semilla.

val self_init : unit -> unit

Inicializa el generador local del dominio con una semilla aleatoria elegida de forma dependiente del sistema. Si está disponible un generador de números pseudoaleatorios criptográficamente seguro en la máquina host, se usa para proporcionar una semilla altamente aleatoria. De lo contrario, se calcula una semilla menos aleatoria a partir de parámetros del sistema (hora actual, IDs de proceso, estado local del dominio).

val bits : unit -> int

Devuelve 30 bits aleatorios en un entero no negativo.

val int : int -> int

Random.int bound devuelve un entero aleatorio entre 0 (inclusive) y bound (exclusivo). bound debe ser mayor que 0 y menor que 2^30.

Lanza Invalid_argument si bound <= 0 o bound >= 2^30.

val full_int : int -> int

Random.full_int bound devuelve un entero aleatorio entre 0 (inclusive) y bound (exclusivo). bound puede ser cualquier entero positivo.

Si bound es menor que 2^31, entonces Random.full_int bound produce una salida idéntica en sistemas con diferentes tamaños de int.

Si bound es menor que 2^30, entonces Random.full_int bound es igual a Random.int bound.

Si bound es al menos 2^30 (en sistemas de 64 bits, o entornos no estándar como JavaScript), entonces Random.full_int devuelve un valor mientras que Random.int lanza Invalid_argument.

Desde 4.13

Lanza Invalid_argument si bound <= 0.

val int_in_range : min:int -> max:int -> int

Random.int_in_range ~min ~max devuelve un entero aleatorio entre min (inclusive) y max (inclusive). Tanto min como max pueden ser negativos; min debe ser menor o igual que max.

Si ambos límites caben en enteros con signo de 32 bits (es decir, si -2^31 <= min y max < 2^31), entonces int_in_range produce una salida idéntica en sistemas con diferentes tamaños de int.

Desde 5.2

Lanza Invalid_argument si min > max.

Lanza Invalid_argument si bound <= 0.

val float : float -> float

Random.float bound devuelve un número de punto flotante aleatorio entre 0 y bound (inclusive). Si bound es negativo, el resultado es negativo o cero. Si bound es 0, el resultado es 0.

val bool : unit -> bool

Random.bool () devuelve true o false con una probabilidad de 0.5 cada uno.

val bits32 : unit -> Int32.t

Random.bits32 () devuelve 32 bits aleatorios como un entero entre Int32.min_int y Int32.max_int.

Desde 4.14

val bits64 : unit -> Int64.t

Random.bits64 () devuelve 64 bits aleatorios como un entero entre Int64.min_int y Int64.max_int.

Desde 4.14

val nativebits : unit -> Nativeint.t

Random.nativebits () devuelve 32 o 64 bits aleatorios (dependiendo del ancho de bits de la plataforma) como un entero entre Nativeint.min_int y Nativeint.max_int.

Desde 4.14

Funciones avanzadas

Las funciones del módulo Random.State manipulan explícitamente el estado actual del generador aleatorio. Esto permite usar uno o varios PRNGs deterministas, incluso en un programa multihilo, sin interferencias de otras partes del programa.

module State : sig end

val get_state : unit -> State.t

get_state() devuelve una copia nueva del estado actual del generador local del dominio (que es utilizado por las funciones básicas).

val set_state : State.t -> unit

set_state s actualiza el estado actual del generador local del dominio (que es utilizado por las funciones básicas) copiando el estado s en él.

val split : unit -> State.t

Extrae un nuevo estado PRNG del estado actual del generador local del dominio utilizado por las funciones predeterminadas. (El estado del generador local del dominio se modifica.) Ver Random.State.split.

Desde 5.0

NOMBRE

Random - Generadores de números pseudoaleatorios.

Módulo

Random

Documentación

El módulo Random proporciona generadores de números pseudoaleatorios. Los números generados son de 31 bits de ancho.

Los generadores de números aleatorios de este módulo se inicializan sembrando el generador con una función de inicialización específica. Si no se llama a ningún generador, se utiliza un valor predeterminado.

El generador de números aleatorios se inicializa sembrando el generador con la hora actual y la información del proceso. El mismo valor de semilla se utiliza cada vez que se llama a Random.init con el mismo valor. Esto permite obtener resultados reproducibles, lo cual es útil para pruebas y depuración.

Las funciones del módulo Random se basan en el generador de números aleatorios global. Si se desea utilizar varios generadores de números aleatorios independientes, se puede utilizar el módulo Random.State.

Funciones

Random.init : int -> unit
Inicializa el generador de números aleatorios global con la semilla dada.
Random.bool : unit -> bool
Devuelve un valor booleano aleatorio.
Random.int : int -> int
Devuelve un entero aleatorio en el intervalo [0, n-1]. Si n <= 0, devuelve 0.
Random.float : float -> float
Devuelve un flotante aleatorio en el intervalo [0.0, 1.0). Si x <= 0.0, devuelve 0.0.
Random.string : int -> string
Devuelve una cadena aleatoria de longitud dada. Los caracteres de la cadena son elegidos entre 'a' y 'z'.
Random.get_state : unit -> state
Devuelve el estado actual del generador de números aleatorios global.
Random.set_state : state -> unit
Establece el estado del generador de números aleatorios global. Esto es útil para restaurar un estado anterior o para reproducir una secuencia de números aleatorios.

Módulo Random.State

El módulo Random.State proporciona funciones para crear y manipular estados de generadores de números aleatorios independientes.

Funciones

Random.State.make_self_init : unit -> state
Crea un nuevo estado de generador de números aleatorios inicializado con la hora actual y la información del proceso.
Random.State.make : int -> state
Crea un nuevo estado de generador de números aleatorios inicializado con la semilla dada.
Random.State.copy : state -> state
Devuelve una copia del estado dado.
Random.State.next : state -> (int * state)
Devuelve el siguiente entero aleatorio generado por el estado dado y el nuevo estado.
Random.State.bool : state -> bool
Devuelve un valor booleano aleatorio del estado dado.
Random.State.int : state -> int -> int
Devuelve un entero aleatorio en el intervalo [0, n-1] del estado dado. Si n <= 0, devuelve 0.
Random.State.float : state -> float -> float
Devuelve un flotante aleatorio en el intervalo [0.0, 1.0) del estado dado. Si x <= 0.0, devuelve 0.0.
Random.State.string : state -> int -> string
Devuelve una cadena aleatoria de longitud dada del estado dado. Los caracteres de la cadena son elegidos entre 'a' y 'z'.
