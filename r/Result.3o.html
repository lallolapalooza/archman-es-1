Módulo Resultado

Valores de resultado.

Los valores de resultado manejan los resultados de la computación y los errores de manera explícita y declarativa, sin recurrir a excepciones.

Desde 4.08

Resultados

tipo ('a, 'e) t = ('a, 'e) resultado =
| Ok de 'a
| Error de 'e

El tipo para los valores de resultado. Ya sea un valor Ok v o un error Error e .

val ok : 'a -> ('a, 'e) resultado

ok v es Ok v .

val error : 'e -> ('a, 'e) resultado

error e es Error e .

val valor : ('a, 'e) resultado -> por_defecto:'a -> 'a

valor r ~por_defecto es v si r es Ok v y por_defecto en caso contrario.

val obtener_ok : ('a, 'e) resultado -> 'a

obtener_ok r es v si r es Ok v y lanza una excepción en caso contrario.

Lanza Invalid_argument si r es Error _ .

val obtener_ok' : ('a, string) resultado -> 'a

obtener_ok' es como Resultado.obtener_ok pero en caso de error utiliza el mensaje de error para lanzar Invalid_argument .

Desde 5.4

val obtener_error : ('a, 'e) resultado -> 'e

obtener_error r es e si r es Error e y lanza una excepción en caso contrario.

Lanza Invalid_argument si r es Ok _ .

val error_a_fallo : ('a, string) resultado -> 'a

error_a_fallo r es v si r es Ok v y lanza Failure e si r es Error e .

Desde 5.4

val encadenar : ('a, 'e) resultado -> ('a -> ('b, 'e) resultado) -> ('b, 'e) resultado

encadenar r f es f v si r es Ok v y r si r es Error _ .

val unir : (('a, 'e) resultado, 'e) resultado -> ('a, 'e) resultado

unir rr es r si rr es Ok r y rr si rr es Error _ .

val mapear : ('a -> 'b) -> ('a, 'e) resultado -> ('b, 'e) resultado

mapear f r es Ok (f v) si r es Ok v y r si r es Error _ .

val producto : ('a, 'e) resultado -> ('b, 'e) resultado -> ('a * 'b, 'e) resultado

producto r0 r1 es Ok (v0, v1) si r0 es Ok v0 y r1 es Ok v2 y en caso contrario devuelve el error de r0 , si lo hay, o el error de r1 .

Desde 5.4

val mapear_error : ('e -> 'f) -> ('a, 'e) resultado -> ('a, 'f) resultado

mapear_error f r es Error (f e) si r es Error e y r si r es Ok _ .

val reducir : ok:('a -> 'c) -> error:('e -> 'c) -> ('a, 'e) resultado -> 'c

reducir ~ok ~error r es ok v si r es Ok v y error e si r es Error e .

val retraer : ('a, 'a) resultado -> 'a

retraer r es v si r es Ok v o Error v .

Desde 5.4

val iterar : ('a -> unit) -> ('a, 'e) resultado -> unit

iterar f r es f v si r es Ok v y () en caso contrario.

val iterar_error : ('e -> unit) -> ('a, 'e) resultado -> unit

iterar_error f r es f e si r es Error e y () en caso contrario.

Predicados y comparaciones

val es_ok : ('a, 'e) resultado -> bool

es_ok r es true si y solo si r es Ok _ .

val es_error : ('a, 'e) resultado -> bool

es_error r es true si y solo si r es Error _ .

val igual : ok:('a -> 'a -> bool) -> error:('e -> 'e -> bool) -> ('a, 'e) resultado -> ('a, 'e) resultado -> bool

igual ~ok ~error r0 r1 prueba la igualdad de r0 y r1 usando ok y error para comparar respectivamente los valores envueltos por Ok _ y Error _ .

val comparar : ok:('a -> 'a -> int) -> error:('e -> 'e -> int) -> ('a, 'e) resultado -> ('a, 'e) resultado -> int

comparar ~ok ~error r0 r1 ordena totalmente r0 y r1 usando ok y error para comparar respectivamente los valores envueltos por Ok _ y Error _ . Los valores Ok _ son menores que los valores Error _ .

Convirtiendo

val a_opcion : ('a, 'e) resultado -> 'a option

a_opcion r es r como una opción, mapeando Ok v a Some v y Error _ a None .

val a_lista : ('a, 'e) resultado -> 'a list

a_lista r es [v] si r es Ok v y [] en caso contrario.

val a_secuencia : ('a, 'e) resultado -> 'a Seq.t

a_secuencia r es r como una secuencia. Ok v es la secuencia singleton que contiene v y Error _ es la secuencia vacía.
