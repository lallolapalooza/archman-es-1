RTCHitN(3) Embree Ray Tracing Kernels 3 RTCHitN(3)

NOMBRE

RTCHitN - paquete de impacto de tamaño en tiempo de ejecución

SINOPSIS

#include <embree3/rtcore.h>
struct HitN;
float& RTCHitN_Ng_x(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_Ng_y(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_Ng_z(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_u(RTCHitN* hit, unsigned int N, unsigned int i);
float& RTCHitN_v(RTCHitN* hit, unsigned int N, unsigned int i);
unsigned& RTCHitN_primID(RTCHitN* hit, unsigned int N, unsigned int i);
unsigned& RTCHitN_geomID(RTCHitN* hit, unsigned int N, unsigned int i);
unsigned& RTCHitN_instID(RTCHitN* hit, unsigned int N, unsigned int i, unsigned int level);

DESCRIPCIÓN

Cuando el tamaño del paquete de impacto no se conoce en tiempo de compilación (por ejemplo, cuando Embree devuelve un paquete de impacto en la función de devolución de llamada RTCFilterFuncN), Embree utiliza el tipo RTCHitN para los paquetes de impacto. Estos paquetes de impacto solo pueden tener tamaños de 1, 4, 8 o 16. No se utilizará ningún otro tamaño de paquete.

Puede implementar diferentes rutas de código especiales para cada uno de estos tamaños de paquete posibles y convertir el impacto al tipo de paquete de impacto apropiado, o implementar una ruta de código general que utilice las funciones auxiliares RTCHitN_XXX para acceder a los componentes del paquete de impacto.

Estas funciones auxiliares reciben un puntero al paquete de impacto (argumento hit), el tamaño del paquete (argumento N) y devuelven una referencia a un componente (por ejemplo, componente x de Ng) del i-ésimo impacto del paquete (argumento i).
