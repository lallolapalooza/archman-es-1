Regexp::Common::balanced(3) Documentación de Perl contribuida por el usuario Regexp::Common::balanced(3)

NOMBRE

Regexp::Common::balanced -- proporciona expresiones regulares para cadenas con delimitadores de paréntesis equilibrados o delimitadores arbitrarios.

SINOPSIS

use Regexp::Common qw /balanced/;
while (<>) {
    /$RE{balanced}{-parens=>'()'}/
                               and print q{paréntesis equilibrados\n};
}

DESCRIPCIÓN

Por favor, consulte el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No utilice este módulo directamente, sino cárguelo a través de Regexp::Common.

"$RE{balanced}{-parens}"

Devuelve un patrón que coincide con una cadena que comienza con el paréntesis o corchete de apertura especificado, contiene caracteres y subsecuencias de paréntesis anidadas correctamente, y termina en el paréntesis correspondiente.

Se puede especificar más de un tipo de paréntesis:

$RE{balanced}{-parens=>'(){}'}

en cuyo caso todos los tipos de paréntesis especificados deben estar correctamente equilibrados dentro de la cadena.

Desde la versión 2013030901, $1 siempre se establecerá (al subcadena completa coincidente), independientemente de si "{-keep}" se utiliza o no.

"$RE{balanced}{-begin => "inicio"}{-end => "fin"}"

Devuelve un patrón que coincide con una cadena que está correctamente equilibrada utilizando las cadenas inicio y fin como delimitadores de inicio y fin. Se pueden dar múltiples conjuntos de cadenas de inicio y fin separándolas por "|" (que se pueden escapar con una barra invertida).

qr/$RE{balanced}{-begin => "hacer|si|caso"}{-end => "fin|fi|esac"}/

coincidirá con cadenas correctamente equilibradas que comienzan con hacer y terminan con fin, comienzan con si y terminan con fi, o comienzan con caso y terminan con esac.

Si -fin contiene menos casos que -inicio, el último caso de -fin se repite. Si contiene más casos que -inicio, los casos adicionales se ignoran. Si no se proporciona ninguno de -inicio o -fin, o si están vacíos, se asumen -inicio => '(' y -fin => ')'.

Desde la versión 2013030901, $1 siempre se establecerá (a la subcadena completa coincidente), independientemente de si "{-keep}" se utiliza o no.

Nota

Desde la versión 2013030901, el patrón utilizará la construcción recursiva "(?-1)", en lugar de usar la problemática construcción "(??{ })". Esto soluciona un problema que se introdujo en la serie de desarrollo 5.17.
