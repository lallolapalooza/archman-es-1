RSA_print(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_PRINT(3ssl) OpenSSL RSA_PRINT(3ssl)

NOMBRE

RSA_print, RSA_print_fp, DSAparams_print, DSAparams_print_fp, DSA_print, DSA_print_fp, DHparams_print, DHparams_print_fp - imprimir parámetros criptográficos

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int RSA_print(BIO *bp, const RSA *x, int offset);
int RSA_print_fp(FILE *fp, const RSA *x, int offset);
#include <openssl/dsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int DSAparams_print(BIO *bp, const DSA *x);
int DSAparams_print_fp(FILE *fp, const DSA *x);
int DSA_print(BIO *bp, const DSA *x, int offset);
int DSA_print_fp(FILE *fp, const DSA *x, int offset);
#include <openssl/dh.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int DHparams_print(BIO *bp, DH *x);
int DHparams_print_fp(FILE *fp, const DH *x);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_print_params(3) y EVP_PKEY_print_private(3).

Se imprime una salida hexadecimal legible por humanos de los componentes de la clave RSA, parámetros o clave DSA o parámetros DH a bp o fp.

Las líneas de salida están indentadas por offset espacios.

VALORES DE RETORNO

DSAparams_print(), DSAparams_print_fp(), DSA_print(), y DSA_print_fp() devuelven 1 en caso de éxito y 0 o un valor negativo en caso de fallo.

DHparams_print() y DHparams_print_fp() devuelven 1 en caso de éxito, 0 en caso de error.

VER TAMBIÉN

L<EVP_PKEY_print_params(3)>,
L<EVP_PKEY_print_private(3)>,
L<BN_bn2bin(3)>

HISTORIA

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
