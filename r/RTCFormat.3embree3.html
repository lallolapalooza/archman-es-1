NOMBRE

RTCFormat - especifica el formato de los datos en los búferes

SINOPSIS

#include <embree3/rtcore_ray.h>
enum RTCFormat
{
  RTC_FORMAT_UINT,
  RTC_FORMAT_UINT2,
  RTC_FORMAT_UINT3,
  RTC_FORMAT_UINT4,
  RTC_FORMAT_FLOAT,
  RTC_FORMAT_FLOAT2,
  RTC_FORMAT_FLOAT3,
  RTC_FORMAT_FLOAT4,
  RTC_FORMAT_FLOAT5,
  RTC_FORMAT_FLOAT6,
  RTC_FORMAT_FLOAT7,
  RTC_FORMAT_FLOAT8,
  RTC_FORMAT_FLOAT9,
  RTC_FORMAT_FLOAT10,
  RTC_FORMAT_FLOAT11,
  RTC_FORMAT_FLOAT12,
  RTC_FORMAT_FLOAT13,
  RTC_FORMAT_FLOAT14,
  RTC_FORMAT_FLOAT15,
  RTC_FORMAT_FLOAT16,
  RTC_FORMAT_FLOAT3X4_ROW_MAJOR,
  RTC_FORMAT_FLOAT4X4_ROW_MAJOR,
  RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR,
  RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR,
  RTC_FORMAT_GRID,

};

DESCRIPCIÓN

La estructura RTFormat define el formato de los datos almacenados en los búferes de datos proporcionados a Embree mediante las llamadas a la API [rtcSetGeometryBuffer], [rtcSetSharedGeometryBuffer] y [rtcSetNewGeometryBuffer].

Los formatos RTC_FORMAT_UINT/2/3/4 se utilizan para especificar que los búferes de datos almacenan enteros sin signo, o vectores de enteros sin signo de tamaño 2, 3 o 4. Este formato se utiliza típicamente para especificar búferes de índices, por ejemplo, RTC_FORMAT_UINT3 para mallas triangulares.

Los formatos RTC_FORMAT_FLOAT/2/3/4... se utilizan para especificar que los búferes de datos almacenan valores de punto flotante de precisión simple, o vectores de los mismos (tamaño 2,3,4, etc.). Este formato se utiliza típicamente para especificar el formato de los búferes de vértices, por ejemplo, el tipo RTC_FORMAT_FLOAT3 para búferes de vértices de mallas triangulares.

Los formatos RTC_FORMAT_FLOAT3X4_ROW_MAJOR y RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR, especifican una matriz de punto flotante de 3x4 dispuesta en orden de fila principal o de columna principal. Los formatos RTC_FORMAT_FLOAT4X4_ROW_MAJOR y RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR, especifican una matriz de punto flotante de 4x4 dispuesta en orden de fila principal o de columna principal. Estos formatos de matriz se utilizan en la función [rtcSetGeometryTransform] para establecer una matriz de transformación para las geometrías.

RTC_FORMAT_GRID es un formato de datos especial utilizado para especificar primitivas de cuadrícula de diseño RTCGrid al crear geometrías de cuadrícula (ver [RTC_GEOMETRY_TYPE_GRID]).
