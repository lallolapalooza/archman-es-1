Return::Value(3) Documentación de Perl aportada por el usuario Return::Value(3)

NOMBRE

Return::Value - (obsoleto) valores de retorno polimórficos

VERSIÓN

versión 1.666005

SINOPSIS

Se utiliza con la interfaz básica de llamada a función:

use Return::Value;

sub send_over_network {
    my ($net, $send) = @_:
    if ( $net->transport( $send ) ) {
        return success;
    } else {
        return failure "No se pudo transportar la información.";
    }
}

my $result = $net->send_over_network(  "Data" );

# booleano
unless ( $result ) {
    # cadena
    print $result;
}

O bien, construye tu Return::Value como un objeto:

sub build_up_return {
    my $return = failure;

    if ( ! foo() ) {
        $return->string("¡No se puede hacer foo!");
        return $return;
    }

    if ( ! bar() ) {
        $return->string("No se puede hacer bar");
        $return->prop(failures => \@bars);
        return $return;
    }

    # estamos bien si hemos llegado hasta aquí.
    $return++;
    return $return; # ¡éxito!
}

DESCRIPCIÓN

Los valores de retorno polimórficos son una idea horrible, pero esta biblioteca se escribió basándose en la noción de que eran útiles. A menudo, solo queremos saber si algo funcionó o no. Otras veces, nos gustaría saber cuál era el texto del error. Aún otras, podríamos querer saber cuál era el código de error y cuáles eran las propiedades del error. No queremos manejar objetos o estructuras de datos para cada valor de retorno, pero sí queremos comprobar las condiciones de error en nuestro código porque eso es lo que hacen los buenos programadores.

Cuando las funciones tienen éxito, pueden devolver verdadero, o quizás algunos datos útiles. En la búsqueda de proporcionar valores de retorno consistentes, esto se vuelve confuso entre errores complejos e informativos y valores de retorno exitosos.

Este módulo proporciona estas características con una API simplista que debería proporcionarle lo que busca en cada contexto en el que se utiliza un valor de retorno.

Atributos

Todos los valores de retorno tienen un conjunto de atributos que empaquetan la información devuelta. Todos los atributos se pueden acceder o modificar a través de métodos del mismo nombre, a menos que se indique lo contrario. Muchos también se pueden acceder a través de operaciones sobrecargadas en el objeto, como se indica a continuación.

tipo
El tipo de un valor es "success" o "failure" y (obviamente) refleja si el valor está devolviendo éxito o fracaso.
errno
El atributo errno almacena el número de error del valor de retorno. Para resultados de tipo éxito, por defecto es indefinido. Para otros resultados, por defecto es 1.
cadena
El atributo de cadena del valor es un mensaje simple que describe el valor.
datos
El atributo data almacena una referencia a un hash o array, y se puede usar como una forma simple de devolver datos adicionales. Los datos almacenados en el atributo data se pueden acceder al desreferenciar el propio valor de retorno. (Ver abajo.)
prop
El atributo más genérico de todos, prop es un hashref que se puede usar para pasar un número arbitrario de estructuras de datos, al igual que el atributo data. Sin embargo, a diferencia del atributo data, estas estructuras deben recuperarse mediante llamadas a métodos.

NO USE ESTA BIBLIOTECA

Return::Value fue una mala idea. Lamento haberla tenido, lamento haberla seguido adelante y lamento que se haya utilizado en otras bibliotecas útiles. Afortunadamente, no hay muchas cosas que la utilicen. Una de ellas es Email::Send, que también está obsoleta en favor de Email::Sender.

No hay ninguna razón para especificar un nuevo módulo que reemplace a Return::Value. En general, las rutinas deben devolver valores de tipo uniforme o lanzar excepciones. Return::Value intentó ser un tipo uniforme para todas las rutinas, pero tiene un comportamiento tan extraño que termina siendo confuso y poco parecido a Perl.

Los objetos que son falsos son una idea terrible en casi todas las circunstancias, especialmente cuando el objeto tiene propiedades útiles.

Por favor, no use esta biblioteca. Ya se arrepentirá después.

Una versión de esta biblioteca en junio de 2009 prometió que las advertencias de obsolescencia comenzarían a emitirse en junio de 2010. Ahora es diciembre de 2012, y las advertencias se están emitiendo. Se pueden deshabilitar mediante los medios especificados en el código fuente.

FUNCIONES

Se recomienda encarecidamente el uso de la interfaz funcional dentro de las funciones que utilizan "Return::Value" para los valores de retorno. Es simple y directo, y construye todo el valor de retorno en una sola declaración.

success
La función "success" devuelve un "Return::Value" con el tipo "success".

Se pueden pasar parámetros con nombre adicionales para establecer los atributos del objeto devuelto. El primer parámetro, opcional, es el atributo de cadena y no necesita ser nombrado. Todos los demás parámetros deben pasarse por nombre.

# el caso más simple posible
return success;
failure
"failure" es idéntico a "success", pero devuelve un objeto con el tipo "failure"

MÉTODOS

La API de objetos es útil en código que captura objetos "Return::Value".

new
my $return = Return::Value->new(
    type   => 'failure',
    string => "HAS FRACASADO",
    prop   => {
        failed_objects => \@objects,
    },
);

Crea un nuevo objeto "Return::Value". Se pueden usar parámetros con nombre para establecer los atributos del objeto.

bool
print "funcionó" if $result->bool;

Devuelve el resultado en contexto booleano: verdadero para éxito, falso para fracaso.

prop
printf "%s: %s',
  $result->string, join ' ', @{$result->prop('strings')}
    unless $result->bool;

Devuelve las propiedades del valor de retorno. Acepta el nombre de una propiedad devuelta, o devuelve la referencia del hash de propiedades si no se le da nombre.

otros accesores de atributos
Existen accesores simples para los otros atributos del objeto: "type", "errno", "string" y "data".

Sobrecarga

Varios operadores están sobrecargados para objetos "Return::Value". Se enumeran aquí.

Conversión a cadena
print "$result\n";

Se convierte a cadena en el atributo de cadena.

Booleano
print $result unless $result;

Devuelve la representación "bool".

Numérico
También devuelve el valor "bool".
Desreferencia
Desreferenciar el valor como un hash o un array devolverá el valor del atributo de datos, si coincide con ese tipo, o una referencia vacía en caso contrario. Puede comprobar "ref $result->data" para determinar qué tipo de datos (si los hay) se pasaron.
