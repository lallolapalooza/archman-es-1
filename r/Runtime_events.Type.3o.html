type 'a t

El tipo para el contenido de un evento de usuario.

val unit : unit t

Un evento que no tiene datos asociados.

type span =
| Begin
| End

val span : span t

Un evento que tiene un principio y un fin.

val int : int t

Un evento que contiene un valor entero.

val register : encode:(bytes -> 'a -> int) -> decode:(bytes -> int -> 'a) -> 'a t

Registra un tipo personalizado proporcionando un codificador y un decodificador. El codificador escribe el valor en el búfer proporcionado y devuelve el número de bytes escritos. El decodificador recibe una porción del búfer de la longitud especificada y devuelve el valor decodificado.

La longitud máxima del valor es de 1024 bytes.
