NOMBRE

Regexp::Common::profanity -- proporciona expresiones regulares para la grosería

SINOPSIS

use Regexp::Common qw /profanity/;
while (<>) {
    /$RE{profanity}/               and  print "Contiene grosería\n";
}

DESCRIPCIÓN

Por favor, consulta el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No uses este módulo directamente, sino cárgalo a través de Regexp::Common.

$RE{profanity}

Devuelve un patrón que coincide con palabras -- como las "siete grandes" de Carlin -- que son más propensas a ofender. Ten en cuenta que los términos anatómicos correctos se excluyen deliberadamente de la lista.

Bajo "-keep" (ver Regexp::Common):

1$
captura la palabra completa

"$RE{profanity}{contextual}"

Devuelve un patrón que coincide con palabras que son propensas a ofender cuando se usan en contextos específicos, pero que también tienen significados genuinamente inofensivos.

Bajo "-keep" (ver Regexp::Common):

1$
captura la palabra completa
