RAND_bytes(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RAND_BYTES(3ssl) OpenSSL RAND_BYTES(3ssl)

NOMBRE

RAND_bytes, RAND_priv_bytes, RAND_bytes_ex, RAND_priv_bytes_ex, RAND_pseudo_bytes, RAND_set1_random_provider - generar datos aleatorios

SINOPSIS

#include <openssl/rand.h>
int RAND_bytes(unsigned char *buf, int num);
int RAND_priv_bytes(unsigned char *buf, int num);
int RAND_bytes_ex(OSSL_LIB_CTX *ctx, unsigned char *buf, size_t num,
                  unsigned int strength);
int RAND_priv_bytes_ex(OSSL_LIB_CTX *ctx, unsigned char *buf, size_t num,
                       unsigned int strength);
int RAND_set1_random_provider(OSSL_LIB_CTX *ctx, OSSL_PROVIDER *p);

La siguiente función ha sido deprecada desde OpenSSL 1.1.0, y puede ser oculta por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int RAND_pseudo_bytes(unsigned char *buf, int num);

DESCRIPCIÓN

RAND_bytes() genera num bytes aleatorios usando un generador de pseudoaleatorios criptográficamente seguro (CSPRNG) y los almacena en buf. buf NO DEBE ser NULL.

RAND_priv_bytes() tiene la misma semántica que RAND_bytes(). Está pensada para ser utilizada en la generación de valores que deben permanecer privados. Si se usa el RAND_METHOD por defecto, esta función utiliza una instancia de PRNG "privada" separada para que una violación de la instancia de PRNG "pública" no afecte la confidencialidad de estos valores privados, como se describe en RAND(7) y EVP_RAND(7).

RAND_bytes_ex() y RAND_priv_bytes_ex() son iguales que RAND_bytes() y RAND_priv_bytes() excepto que ambas toman parámetros adicionales strength y ctx. Los bytes generados tendrán una fuerza de seguridad de al menos strength bits. El DRBG utilizado para la operación es el DRBG público o privado asociado con el ctx especificado. El parámetro puede ser NULL, en cuyo caso se usa el contexto de la biblioteca por defecto (ver OSSL_LIB_CTX(3). Si el RAND_METHOD por defecto ha sido modificado, por razones de compatibilidad, el RAND_METHOD se utilizará con preferencia y se ignorará el DRBG del contexto de la biblioteca.

RAND_set1_random_provider() especifica un proveedor, prov, que será utilizado por el contexto de la biblioteca ctx para todas las llamadas de generación anteriores en lugar de los DRBG y la fuente de entropía incorporados. Pase NULL para el proveedor para deshabilitar la funcionalidad del proveedor aleatorio. En este caso, se utilizarán los DRBG y la fuente de entropía incorporados. Esta llamada no debe considerarse segura para hilos.

NOTAS

Por defecto, el CSPRNG de OpenSSL soporta un nivel de seguridad de 256 bits, siempre que haya podido sembrarse a sí mismo desde una fuente de entropía confiable. En todas las plataformas principales compatibles con OpenSSL (incluidas las plataformas tipo Unix y Windows), OpenSSL está configurado para sembrar automáticamente el CSPRNG en su primer uso utilizando el generador aleatorio del sistema operativo.

Si la fuente de entropía falla o no está disponible, el CSPRNG entrará en un estado de error y se negará a generar bytes aleatorios. Por esa razón, es importante comprobar siempre el valor de retorno de error de RAND_bytes() y RAND_priv_bytes() y no dar por sentada la aleatoriedad.

En otras plataformas, podría no haber una fuente de entropía confiable disponible o OpenSSL podría haber sido configurado explícitamente para usar fuentes de entropía diferentes. Si tiene dudas sobre la calidad de la fuente de entropía, no dude en preguntar a su proveedor de sistema operativo o publicar una pregunta en GitHub o en la lista de correo de openssl-users.

VALORES DE RETORNO

RAND_bytes() y RAND_priv_bytes() devuelven 1 si tienen éxito, -1 si no es compatible con el método RAND actual, o 0 en caso de otro fallo. El código de error se puede obtener mediante ERR_get_error(3).

RAND_set1_random_provider() devuelve 1 si tiene éxito y 0 en caso de fallo.

VER TAMBIÉN

RAND_add(3), RAND_bytes(3), RAND_priv_bytes(3), ERR_get_error(3), RAND(7), EVP_RAND(7)

HISTORIA

  • RAND_pseudo_bytes() fue deprecada en OpenSSL 1.1.0; use RAND_bytes() en su lugar.
  • La función RAND_priv_bytes() fue añadida en OpenSSL 1.1.1.
  • Las funciones RAND_bytes_ex() y RAND_priv_bytes_ex() fueron añadidas en OpenSSL 3.0
  • La función RAND_set1_random_provider() fue añadida en OpenSSL 3.5
