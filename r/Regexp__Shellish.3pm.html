NOMBRE

Regexp::Shellish - Expresiones regulares tipo shell

SINOPSIS

use Regexp::Shellish qw( :all ) ;
$re = compile_shellish( 'a/c*d' ) ;
## This next one's like 'a*d' except that it'll
## match 'a/d'.
$re = compile_shellish( 'a**d' ) ;
## And here '**' won't match 'a/d', but behaves
## like 'a*d', except for the possibility of high
## cpu time consumption.
$re = compile_shellish( 'a**d', { star_star => 0 } ) ;
## The next two result in identical $re1 and $re2.
## The second is a noop so that Regexp references can
## be easily accomodated.
$re1 = compile_shellish( 'a{b,c}d' ) ;
$re2 = compile_shellish( qr/\A(?:a(?:b|c)d)\Z/ ) ;
@matches = shellish_glob( $re, @possibilities ) ;

DESCRIPCIÓN

Proporciona expresiones regulares tipo shell. Los comodines proporcionados son "?", "*" y "**", donde "**" es como "*" pero coincide con "/". Ver "compile_shellish" para detalles.

La sensibilidad a mayúsculas y minúsculas y construcciones como <**>, "(a*b)" y "{a,b,c}" pueden ser deshabilitadas.

compile_shellish
Compila una cadena que contiene una expresión regular 'shellish', devolviendo una referencia a Regexp. Las referencias a Regexp pasadas se devuelven sin modificar.

Aquí están las reglas de transformación de términos de expresión shellish a términos de expresión regular de perl:

Shellish  Perl RE
========  =======
*         [^/]*
?         .
**        .*               ## a menos que { star_star   => 0 }
...       .*               ## a menos que { dot_dot_dot => 0 }
(         (                ## a menos que { parens => 0 }
)         )                ## a menos que { parens => 0 }
{a,b,c}   (?:a|b|c)        ## a menos que { braces => 0 }
\a        a                ## Estos se escapan y
\*        \*               ## se pasan a quotemeta()

Los comodines tratan los saltos de línea como caracteres normales.

Los paréntesis agrupan en $1..$n, ya que se pasan sin modificar (a menos que se pase la opción parens => 0). Esto es inútil cuando se usa glob_shellish(), sin embargo.

El parámetro final puede ser una referencia a un hash que contenga opciones:

compile_shellish(
   '**',
   {
      anchors        => 0,   ## No pone ^ y $ alrededor de la
                             ## expresión regular resultante
      case_sensitive => 0,   ## Hace que no distinga mayúsculas y minúsculas
      dot_dot_dot    => 0,   ## '...' ahora son solo tres puntos '.'
      star_star      => 0,   ## '**' ahora son dos comodines '*'
      parens         => 0,   ## '(', ')' ahora son caracteres regulares
      braces         => 0,   ## '{', '}' ahora son caracteres regulares
   }
) ;

Ninguna opción afecta a las referencias a Regexp pasadas.

shellish_glob
Pasa una expresión regular y una lista de valores posibles, devuelve una lista de valores coincidentes. 
my @matches = shellish_glob( '*/*', @possibilities ) ;
my @matches = shellish_glob( '*/*', @possibilities, \%options ) ;
