RAND_load_file(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RAND_LOAD_FILE(3ssl) OpenSSL RAND_LOAD_FILE(3ssl)

NOMBRE

RAND_load_file, RAND_write_file, RAND_file_name - Archivo de semilla PRNG

SINOPSIS

#include <openssl/rand.h>
int RAND_load_file(const char *filename, long max_bytes);
int RAND_write_file(const char *filename);
const char *RAND_file_name(char *buf, size_t num);

DESCRIPCIÓN

RAND_load_file() lee un número de bytes del archivo filename y los añade al PRNG. Si max_bytes no es negativo, se leen hasta max_bytes; si max_bytes es -1, se lee el archivo completo (a menos que el archivo no sea un archivo regular, en cuyo caso se intenta leer un número fijo de bytes, 256 en la implementación actual). RAND_load_file() puede leer menos que el archivo completo o el número de bytes solicitado si no cabe en el tipo de valor de retorno. No cargue el mismo archivo varias veces a menos que su contenido haya sido actualizado por RAND_write_file() entre lecturas. Además, tenga en cuenta que filename debe estar adecuadamente protegido para que un atacante no pueda reemplazar o examinar el contenido. Si filename no es un archivo regular, se considera que el usuario es responsable de cualquier efecto secundario, por ejemplo, bloqueo no anticipado o captura de la terminal de control.

RAND_write_file() escribe un número de bytes aleatorios (actualmente 128) en el archivo filename que puede usarse para inicializar el PRNG llamando a RAND_load_file() en una sesión posterior.

RAND_file_name() genera una ruta predeterminada para el archivo de semilla aleatoria. buf apunta a un búfer de tamaño num en el que se almacenará el nombre del archivo.

En todos los sistemas, si la variable de entorno RANDFILE está configurada, su valor se usará como nombre de archivo de semilla. De lo contrario, el archivo se llama ".rnd", ubicado en lugares dependientes de la plataforma:

En Windows (en orden de preferencia)
%HOME%, %USERPROFILE%, %SYSTEMROOT%, C:\
En VMS
SYS$LOGIN:
En todos los demás sistemas
$HOME

Si $HOME (en sistemas no Windows y no VMS) tampoco está configurado, o num es demasiado pequeño para la ruta, ocurre un error.

VALORES DE RETORNO

RAND_load_file() devuelve el número de bytes leídos o -1 en caso de error.

RAND_write_file() devuelve el número de bytes escritos, o -1 si los bytes escritos se generaron sin una inicialización adecuada.

RAND_file_name() devuelve un puntero a buf en caso de éxito, y NULL en caso de error.

VER TAMBIÉN
