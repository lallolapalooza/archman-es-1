Regexp::Common::_support(3) Documentación de Perl aportada por el usuario Regexp::Common::_support(3)

NOMBRE

Regexp::Common::support -- Funciones de soporte para Regexp::Common.

SINOPSIS

use Regexp::Common::_support qw /luhn/;
luhn ($numero)    # Devuelve verdadero/falso.

DESCRIPCIÓN

Este módulo contiene subrutinas para ser usadas por otros módulos de "Regexp::Common". No está pensado para ser usado directamente. Las subrutinas del módulo pueden desaparecer sin previo aviso, o su significado o interfaz pueden cambiar sin previo aviso.

luhn
Esta subrutina devuelve verdadero si su argumento pasa la prueba de suma de verificación de Luhn.

VER TAMBIÉN

http://www.webopedia.com/TERM/L/Luhn_formula.html.
