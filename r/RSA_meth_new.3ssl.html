DESCRIPCION

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deben usar en su lugar las APIs de OSSL_PROVIDER.

El tipo RSA_METHOD es una estructura utilizada para la provisión de implementaciones personalizadas de RSA. Proporciona un conjunto de funciones utilizadas por OpenSSL para la implementación de las diversas capacidades de RSA.

RSA_meth_new() crea una nueva estructura RSA_METHOD. Se le debe proporcionar un nombre único y un conjunto de flags. El nombre debe ser una cadena terminada en NULL, que se duplicará y almacenará en el objeto RSA_METHOD. Es responsabilidad del llamador liberar la cadena original. Las flags se utilizarán durante la construcción de un nuevo objeto RSA basado en este RSA_METHOD. Cualquier nuevo objeto RSA tendrá esas flags establecidas por defecto.

RSA_meth_dup() crea una copia duplicada del objeto RSA_METHOD pasado como parámetro. Esto puede ser útil para crear un nuevo RSA_METHOD basado en uno existente, pero con algunas diferencias.

RSA_meth_free() destruye una estructura RSA_METHOD y libera cualquier memoria asociada a ella. Si el argumento es NULL, no se hace nada.

RSA_meth_get0_name() devolverá un puntero al nombre de este RSA_METHOD. Es un puntero a la cadena de nombre interna y, por lo tanto, no debe ser liberado por el llamador. RSA_meth_set1_name() establece el nombre del RSA_METHOD a name. La cadena se duplica y la copia se almacena en la estructura RSA_METHOD, por lo que el llamador sigue siendo responsable de liberar la memoria asociada con el nombre.

RSA_meth_get_flags() devuelve el valor actual de las flags asociadas con este RSA_METHOD. RSA_meth_set_flags() proporciona la capacidad de establecer estas flags.

Las funciones RSA_meth_get0_app_data() y RSA_meth_set0_app_data() proporcionan la capacidad de asociar datos específicos de la implementación con el RSA_METHOD. Es responsabilidad de la aplicación liberar estos datos antes de que el RSA_METHOD sea liberado mediante una llamada a RSA_meth_free().

RSA_meth_get_sign() y RSA_meth_set_sign() obtienen y establecen respectivamente la función utilizada para crear una firma RSA. Esta función se llamará en respuesta a que la aplicación llame a RSA_sign(). Los parámetros de la función tienen el mismo significado que para RSA_sign().

RSA_meth_get_verify() y RSA_meth_set_verify() obtienen y establecen respectivamente la función utilizada para verificar una firma RSA. Esta función se llamará en respuesta a que la aplicación llame a RSA_verify(). Los parámetros de la función tienen el mismo significado que para RSA_verify().

DESCRIPCIÓN

El objeto RSA_METHOD es una estructura que agrupa las diversas funciones criptográficas utilizadas por la implementación RSA. Los métodos estándares de OpenSSL son utilizados por defecto para las operaciones RSA, pero se pueden registrar métodos personalizados para sustituirlos. Esto es útil, por ejemplo, para implementar el soporte de hardware.

RSA_meth_new() asigna y devuelve un nuevo RSA_METHOD. El parámetro name se almacena y puede ser recuperado más tarde con RSA_meth_get0_name(). Es posible que sea NULL. Si RSA_meth_new() no puede asignar memoria, devuelve NULL.

RSA_meth_dup() duplica un RSA_METHOD existente. Crea una nueva copia del método, incluyendo una copia del nombre.

RSA_meth_free() libera un RSA_METHOD que fue previamente asignado con RSA_meth_new() o RSA_meth_dup().

RSA_meth_set1_name() y RSA_meth_get0_name() establecen y obtienen el nombre asociado con el RSA_METHOD respectivamente. El nombre se copia internamente, por lo que el búfer de entrada puede ser liberado después de la llamada.

RSA_meth_set_flags() y RSA_meth_get_flags() establecen y obtienen un campo de flags arbitrario asociado con el RSA_METHOD respectivamente. El propósito de estos flags es específico del método.

RSA_meth_set_init() y RSA_meth_get_init() obtienen y establecen la función utilizada para inicializar una nueva instancia RSA respectivamente. Esta función será llamada en respuesta a la llamada de la aplicación a RSA_new() (si el RSA_METHOD por defecto actual es este) o RSA_new_method(). Las funciones RSA_new() y RSA_new_method() asignarán la memoria para el nuevo objeto RSA, y se pasará un puntero a esta estructura recién asignada como parámetro a la función. Esta función puede ser NULL.

RSA_meth_set_finish() y RSA_meth_get_finish() obtienen y establecen la función utilizada para destruir una instancia de un objeto RSA respectivamente. Esta función será llamada en respuesta a la llamada de la aplicación a RSA_free(). Se pasa como parámetro un puntero al RSA que se va a destruir. La función de destrucción debe ser usada para la limpieza específica de la implementación de RSA. La memoria para el propio RSA no debe ser liberada por esta función. Esta función puede ser NULL.

RSA_meth_set_sign() y RSA_meth_get_sign() obtienen y establecen la función utilizada para firmar datos con una clave privada RSA. Esta función será llamada en respuesta a la llamada de la aplicación a RSA_sign() y toma los mismos parámetros que esa.

RSA_meth_set_verify() y RSA_meth_get_verify() obtienen y establecen la función utilizada para verificar una firma RSA con una clave pública. Esta función será llamada en respuesta a la llamada de la aplicación a RSA_verify() y toma los mismos parámetros que esa.

RSA_meth_set_keygen() y RSA_meth_get_keygen() obtienen y establecen la función utilizada para generar un nuevo par de claves RSA respectivamente. Esta función será llamada en respuesta a la llamada de la aplicación a RSA_generate_key_ex(). El parámetro para la función tiene el mismo significado que para RSA_generate_key_ex().

RSA_meth_set_multi_prime_keygen() y RSA_meth_get_multi_prime_keygen() obtienen y establecen la función utilizada para generar un nuevo par de claves RSA multiprima respectivamente. Esta función será llamada en respuesta a la llamada de la aplicación a RSA_generate_multi_prime_key(). El parámetro para la función tiene el mismo significado que para RSA_generate_multi_prime_key().

RSA_meth_set_pub_enc(), RSA_meth_get_pub_enc(), RSA_meth_set_pub_dec(), RSA_meth_get_pub_dec(), RSA_meth_set_priv_enc(), RSA_meth_get_priv_enc(), RSA_meth_set_priv_dec(), RSA_meth_get_priv_dec() obtienen y establecen las funciones utilizadas para el cifrado y descifrado de clave pública y privada. Estas funciones serán llamadas en respuesta a la llamada de la aplicación a RSA_public_encrypt(), RSA_private_decrypt(), RSA_private_encrypt() y RSA_public_decrypt() y toman los mismos parámetros que esas.

RSA_meth_set_mod_exp() y RSA_meth_get_mod_exp() obtienen y establecen la función utilizada para las operaciones de exponenciación modular.

RSA_meth_set_mod_exp_crt() y RSA_meth_get_mod_exp_crt() obtienen y establecen la función utilizada para los cálculos de exponenciación modular utilizando el teorema del resto chino (CRT).

Tanto las funciones mod_exp() como bn_mod_exp() son llamadas por el método OpenSSL por defecto durante el cifrado, descifrado, firma y verificación.

VALORES DEVUELTOS

RSA_meth_new() y RSA_meth_dup() devuelven el objeto RSA_METHOD recién asignado o NULL en caso de fallo.

RSA_meth_get0_name() y RSA_meth_get_flags() devuelven el nombre y los flags asociados con el RSA_METHOD respectivamente.

Todas las demás funciones RSA_meth_get_*() devuelven el puntero a función apropiado que se ha establecido en el RSA_METHOD, o NULL si aún no se ha establecido dicho puntero.

RSA_meth_set1_name y todas las funciones RSA_meth_set_*() devuelven 1 en caso de éxito o 0 en caso de fallo.
