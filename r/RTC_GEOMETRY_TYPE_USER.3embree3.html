RTC_GEOMETRY_TYPE_USER(3) Núcleos de Trazado de Rayos Embree 3 RTC_GEOMETRY_TYPE_USER(3)

NOMBRE

RTC_GEOMETRY_TYPE_USER - tipo de geometría de usuario

SINOPSIS

#include <embree3/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_USER);

DESCRIPCIÓN

Las geometrías definidas por el usuario contienen un número de primitivas definidas por el usuario, al igual que las mallas triangulares contienen múltiples triángulos. La forma de las primitivas definidas por el usuario se especifica a través de funciones de devolución de llamada registradas, que permiten extender Embree con tipos de primitivas arbitrarios.

Las geometrías definidas por el usuario se crean pasando RTC_GEOMETRY_TYPE_USER a la llamada a la función rtcNewGeometry. Hay que establecer el número de primitivas (ver rtcSetGeometryUserPrimitiveCount), un puntero de datos de usuario (ver rtcSetGeometryUserData), una función de cierre de límites (ver rtcSetGeometryBoundsFunction), así como funciones de devolución de llamada de intersección (ver rtcSetGeometryIntersectFunction) y oclusión (ver rtcSetGeometryOccludedFunction) definidas por el usuario. La función de límites se utiliza para consultar los límites de todos los pasos de tiempo de una primitiva de usuario, mientras que las funciones de devolución de llamada de intersección y oclusión se llaman para intersecar la primitiva con un rayo. El puntero de datos de usuario se pasa a cada invocación de la devolución de llamada y puede usarse para apuntar a la representación de la geometría de usuario de la aplicación.

La creación de una geometría de usuario típicamente se ve así:

RTCGeometry geometry = rtcNewGeometry(device, RTC_GEOMETRY_TYPE_USER);
rtcSetGeometryUserPrimitiveCount(geometry, numPrimitives);
rtcSetGeometryUserData(geometry, userGeometryRepresentation);
rtcSetGeometryBoundsFunction(geometry, boundsFunction);
rtcSetGeometryIntersectFunction(geometry, intersectFunction);
rtcSetGeometryOccludedFunction(geometry, occludedFunction);

Por favor, eche un vistazo a las funciones rtcSetGeometryBoundsFunction, rtcSetGeometryIntersectFunction y rtcSetGeometryOccludedFunction para implementar las funciones de devolución de llamada.

Las primitivas de una geometría de usuario se ignoran durante el renderizado cuando sus límites están vacíos, por lo tanto, los límites tienen lower>upper en al menos una dimensión.

Vea el tutorial [Geometría de Usuario] para ver un ejemplo de cómo utilizar las geometrías definidas por el usuario.

ESTADO DE SALIDA

En caso de error se devuelve NULL y se establece un código de error que puede consultarse usando rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcSetGeometryUserPrimitiveCount], [rtcSetGeometryUserData], [rtcSetGeometryBoundsFunction], [rtcSetGeometryIntersectFunction], [rtcSetGeometryOccludedFunction]
