NOMBRE

RESET - restaurar el valor de un parámetro en tiempo de ejecución a su valor predeterminado

SINOPSIS

RESET parametro_de_configuracion
RESET ALL

DESCRIPCIÓN

RESET restaura los parámetros en tiempo de ejecución a sus valores predeterminados. RESET es una grafía alternativa para

SET parametro_de_configuracion TO DEFAULT

Consulte SET(7) para más detalles.

El valor predeterminado se define como el valor que tendría el parámetro si nunca se hubiera emitido un SET para él en la sesión actual. La fuente real de este valor podría ser un valor predeterminado compilado, el archivo de configuración, opciones de línea de comandos o configuraciones predeterminadas por base de datos o por usuario. Esto es sutilmente diferente de definirlo como "el valor que tenía el parámetro al inicio de la sesión", ya que si el valor provino del archivo de configuración, se restablecerá a lo que especifique el archivo de configuración en este momento. Vea el Capítulo 19 para más detalles.

El comportamiento transaccional de RESET es el mismo que el de SET: sus efectos serán deshechos por la reversión de transacciones.

PARÁMETROS

parametro_de_configuracion

Nombre de un parámetro en tiempo de ejecución que se puede establecer. Los parámetros disponibles se documentan en el Capítulo 19 y en la página de referencia de SET(7).

ALL

Restablece todos los parámetros en tiempo de ejecución que se pueden establecer a sus valores predeterminados.

EJEMPLOS

Establecer la variable de configuración timezone a su valor predeterminado:

RESET timezone;

COMPATIBILIDAD

RESET es una extensión de PostgreSQL.

VEASE TAMBIÉN
