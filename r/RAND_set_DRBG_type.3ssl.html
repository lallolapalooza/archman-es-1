RAND_set_DRBG_type(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RAND_SET_DRBG_TYPE(3ssl) OpenSSL RAND_SET_DRBG_TYPE(3ssl)

NOMBRE

RAND_set_DRBG_type, RAND_set_seed_source_type - especificar los tipos del generador de números aleatorios global

SINOPSIS

#include <openssl/rand.h>
int RAND_set_DRBG_type(OSSL_LIB_CTX *ctx, const char *drbg, const char *propq,
                       const char *cipher, const char *digest);
int RAND_set_seed_source_type(OSSL_LIB_CTX *ctx, const char *seed,
                              const char *propq);

DESCRIPCIÓN

RAND_set_DRBG_type() especifica el generador de bits aleatorios que se utilizará dentro del contexto de la biblioteca ctx. Se obtendrá un generador del nombre drbg con las propiedades propq. Se instanciará con cipher o digest como su algoritmo criptográfico subyacente. Esto especifica el tipo que se utilizará para las instancias aleatorias primarias, públicas y privadas.

RAND_set_seed_source_type() especifica la fuente de semilla que se utilizará dentro del contexto de la biblioteca ctx. Se obtendrá la fuente de semilla del nombre seed con las propiedades propq y se utilizará para sembrar el generador de bits aleatorios primario.

VALORES DE RETORNO

Estas funciones devuelven 1 en caso de éxito y 0 en caso de fallo.

NOTAS

Estas funciones deben llamarse antes de que los generadores de bits aleatorios se creen por primera vez en el contexto de la biblioteca. Devolverán un error si la llamada se realiza demasiado tarde.

El DRBG predeterminado es "CTR-DRBG" utilizando el cifrado "AES-256-CTR".

La fuente de semilla predeterminada se puede configurar al compilar OpenSSL estableciendo -DOPENSSL_DEFAULT_SEED_SRC=SEED-SRC. Si no se establece, se utiliza "SEED-SRC".

EJEMPLOS

unsigned char bytes[100];
RAND_set_seed_source_type(NULL, "JITTER", NULL);
RAND_bytes(bytes, 100);

VER TAMBIÉN

EVP_RAND(3), RAND_get0_primary(3)

Estas funciones se añadieron en OpenSSL 3.0.
