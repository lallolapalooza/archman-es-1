NOMBRE

R - un lenguaje para análisis de datos y gráficos

SINOPSIS

R [opciones] [< archivo_entrada] [> archivo_salida]
R CMD comando [argumentos]

DESCRIPCIÓN

Inicia R, un sistema para cálculo estadístico y gráficos, con las opciones especificadas, o invoca una herramienta de R a través de la interfaz 'R CMD'.

R es un lenguaje que se parece superficialmente al lenguaje S desarrollado en AT&T Bell Laboratories. Proporciona soporte para una variedad de análisis estadísticos y gráficos. R es un lenguaje de computadora real que contiene una serie de construcciones de control de flujo para iteración y alternancia. Permite a los usuarios agregar funcionalidad adicional definiendo nuevas funciones.

En sistemas que tienen la biblioteca GNU readline(3), R mantendrá un historial de comandos, de modo que los comandos puedan ser recuperados, editados y re-ejecutados.

OPCIONES

La mayoría de las opciones controlan lo que sucede al principio y al final de una sesión de R, en particular qué archivos se leen y escriben, y cuánta memoria se reserva para el proceso de R.

-h, --help
Imprime un mensaje de ayuda corto y sale
--version
Imprime información de versión y sale
--encoding=ENC
Especifica la codificación a utilizar para la entrada estándar

--encoding ENC

RHOME
Imprime la ruta al directorio principal de R y sale
--save
Guarda el espacio de trabajo al final de la sesión
--no-save
No lo guardes
--no-environ
No leer los archivos de entorno del sitio y del usuario
--no-site-file
No leer el archivo Rprofile de todo el sitio
--no-init-file
No leer el perfil R del usuario
--restore
Restaura los objetos guardados previamente al inicio
--no-restore-data
No restaura objetos guardados previamente
--no-restore-history
No restaura el archivo de historial de R
--no-restore
No restaura nada
--vanilla
Combina --no-save, --no-restore, --no-site-file, --no-init-file y --no-environ
--no-readline
No usar readline para la edición de línea de comandos
--max-connections=N
Establece el número máximo de conexiones a N
--max-ppsize=N
Establece el tamaño máximo de la pila de protección a N
--min-nsize=N
Establece el número mínimo de objetos de tamaño fijo ("celdas cons") a N
--min-vsize=N
Establece el mínimo del montículo de vectores a N bytes; '4M' = 4 Megabytes
-q, --quiet
No imprime el mensaje de inicio
--silent
Igual que --quiet
-s, --no-echo
Hace que R se ejecute lo más silenciosamente posible
--interactive
Fuerza una sesión interactiva
--verbose
Imprime más información sobre el progreso
-d, --debugger=NOMBRE
Ejecuta R a través del depurador NOMBRE
--debugger-args=ARGS
Pasa ARGS como argumentos al depurador
-g TIPO, --gui=TIPO
Usa TIPO como GUI; los valores posibles son 'X11' (por defecto) y 'Tk'.
--arch=NOMBRE
Especifica una sub-arquitectura
--args
Omite el resto de la línea de comandos
-f ARCHIVO, --file=ARCHIVO
Toma la entrada de 'ARCHIVO'
-e EXPRESIÓN
Ejecuta 'EXPRESIÓN' y sale

ARCHIVO puede contener espacios pero no metacaracteres del shell.

Comandos:

BATCH
Ejecuta R en modo batch
COMPILE
Compila archivos para su uso con R
SHLIB
Construye una biblioteca compartida para carga dinámica
INSTALL
Instala paquetes adicionales
REMOVE
Elimina paquetes adicionales
build
Construye paquetes adicionales
check
Verifica paquetes adicionales
LINK
Interfaz para crear programas ejecutables
Rprof
Procesa archivos de perfilado de R
Rdconv
Convierte el formato Rd a varios otros formatos
Rd2pdf
Convierte el formato Rd a PDF
Rd2txt
Convierte el formato Rd a texto formateado
Stangle
Extrae código S/R de la documentación de Sweave
Sweave
Procesa la documentación de Sweave
Rdiff
Diferencia la salida de R ignorando encabezados, etc.
config
Obtiene información de configuración sobre R
javareconf
Actualiza las variables de configuración de Java
rtags
Crea archivos de etiquetas estilo Emacs a partir de archivos C, R y Rd

Por favor, utiliza 'R CMD comando --help' para obtener más información sobre el uso de 'comando'.

Las opciones --arch, --no-environ, --no-init-file, --no-site-file y --vanilla se pueden colocar entre R y CMD, para que se apliquen a los procesos R ejecutados por 'comando'

VER TAMBIÉN

La documentación completa de R se proporciona mediante una colección de manuales Texinfo y ayuda individual para objetos R que también está disponible en línea.

Inicia R y escribe ?tema en el prompt de R para obtener información en línea sobre `tema'.

Si se han instalado los manuales procesados, estarán disponibles como archivos DVI y/o PDF en el subdirectorio doc/manual del árbol de directorios de documentación (por defecto `R RHOME`).
