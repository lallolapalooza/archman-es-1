RRDp(3) Documentación Perl aportada por el usuario RRDp(3)

NOMBRE

RRDp - Adjuntar RRDtool desde dentro de un script perl a través de un conjunto de tuberías;

SINOPSIS

use RRDp

RRDp::start ruta al ejecutable de RRDtool

RRDp::cmd línea de comandos de rrdtool

$respuesta = RRDp::read

$estado = RRDp::end

$RRDp::usuario, $RRDp::sistema, $RRDp::real, $RRDp::modo_error, $RRDp::error

DESCRIPCIÓN

Con este módulo puedes comunicarte de forma segura con RRDtool.

Después de cada RRDp::cmd tienes que emitir un comando RRDp::read para obtener la respuesta de RRDtool a tu comando. La respuesta se devuelve como un puntero, para acelerar las cosas. Si el último comando no devolvió ningún dato, RRDp::read devolverá una variable indefinida.

Si importas las variables de RENDIMIENTO a tu espacio de nombres, puedes acceder a las mediciones de rendimiento internas de RRDtool.

use RRDp
Carga el módulo RRDp::pipe.
RRDp::start ruta al ejecutable de RRDtool
inicia RRDtool. El argumento debe ser la ruta al ejecutable de RRDtool.
RRDp::cmd línea de comandos de rrdtool
pasa comandos a RRDtool. Consulta la documentación de RRDtool para más información sobre los comandos de RRDtool.

Nota: Debido a limitaciones de diseño, RRDp::cmd no soporta el comando "graph -"; utiliza en su lugar "graphv -".

$respuesta = RRDp::read
lee la respuesta de RRDtool a tu comando. Ten en cuenta que la variable $respuesta solo contendrá un puntero a los datos devueltos. La razón de esto es que RRDtool puede devolver potencialmente cantidades de datos bastante excesivas y no queremos copiarlas en memoria. Así que cuando quieras acceder al contenido de $respuesta tienes que usar $$respuesta, que desreferencia la variable.
$estado = RRDp::end
termina RRDtool y devuelve el estado de RRDtool...
$RRDp::usuario, $RRDp::sistema, $RRDp::real
estas variables contendrán los totales de tiempo de usuario, tiempo de sistema y tiempo real tal como los ve RRDtool. El tiempo de usuario es el tiempo que RRDtool está ejecutando, el tiempo de sistema es el tiempo dedicado a llamadas al sistema y el tiempo real es el tiempo total que RRDtool ha estado ejecutando.

La diferencia entre usuario + sistema y real es el tiempo dedicado a esperar cosas como el disco duro y la nueva entrada del script Perl.

$RRDp::modo_error y $RRDp::error
Si estableces la variable $RRDp::modo_error al valor 'catch' antes de ejecutar RRDp::read, un posible mensaje de ERROR no provocará que el programa se aborte, sino que se devolverá en esta variable. Si no ocurre ningún error, la variable estará vacía. 
$RRDp::modo_error = 'catch';
RRDp::cmd qw(info file.rrd);
print $RRDp::error if $RRDp::error;

EJEMPLO

use RRDp;
RRDp::start "/usr/local/bin/rrdtool";
RRDp::cmd   qw(create demo.rrd --step 100 
              DS:in:GAUGE:100:U:U
              RRA:AVERAGE:0.5:1:10);
$respuesta = RRDp::read;
print $$respuesta;
($tiempousuario,$tiemposistema,$tiemporeal) =  ($RRDp::usuario,$RRDp::sistema,$RRDp::real);
