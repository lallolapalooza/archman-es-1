NOMBRE

RTC_GEOMETRY_TYPE_USER - tipo de geometría de usuario

SINOPSIS

#include <embree4/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_USER);

DESCRIPCIÓN

Las geometrías definidas por el usuario contienen un número de primitivas definidas por el usuario, al igual que las mallas triangulares contienen múltiples triángulos. La forma de las primitivas definidas por el usuario se especifica a través de funciones de devolución de llamada registradas, que permiten extender Embree con tipos arbitrarios de primitivas.

Las geometrías definidas por el usuario se crean pasando RTC_GEOMETRY_TYPE_USER a la llamada a la función rtcNewGeometry. Es necesario establecer el número de primitivas (ver rtcSetGeometryUserPrimitiveCount), un puntero de datos de usuario (ver rtcSetGeometryUserData), una clausura de función de límites (ver rtcSetGeometryBoundsFunction), así como funciones de devolución de llamada de intersección (ver rtcSetGeometryIntersectFunction) y oclusión (ver rtcSetGeometryOccludedFunction) definidas por el usuario. La función de límites se utiliza para consultar los límites de todos los pasos de tiempo de una primitiva de usuario, mientras que las funciones de devolución de llamada de intersección y oclusión se llaman para intersectar la primitiva con un rayo. El puntero de datos de usuario se pasa a cada invocación de devolución de llamada y puede usarse para apuntar a la representación de la geometría de usuario de la aplicación.

La creación de una geometría de usuario generalmente se ve así:

RTCGeometry geometry = rtcNewGeometry(device, RTC_GEOMETRY_TYPE_USER);
rtcSetGeometryUserPrimitiveCount(geometry, numPrimitives);
rtcSetGeometryUserData(geometry, userGeometryRepresentation);
rtcSetGeometryBoundsFunction(geometry, boundsFunction);
rtcSetGeometryIntersectFunction(geometry, intersectFunction);
rtcSetGeometryOccludedFunction(geometry, occludedFunction);

Por favor, eche un vistazo a las funciones rtcSetGeometryBoundsFunction, rtcSetGeometryIntersectFunction y rtcSetGeometryOccludedFunction para ver la implementación de las funciones de devolución de llamada.

Las primitivas de una geometría de usuario se ignoran durante la renderización cuando sus límites están vacíos, por lo tanto, los límites tienen lower>upper en al menos una dimensión.

Vea el tutorial [Geometría de Usuario] para obtener un ejemplo de cómo usar las geometrías definidas por el usuario.

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry], [rtcSetGeometryUserPrimitiveCount], [rtcSetGeometryUserData], [rtcSetGeometryBoundsFunction], [rtcSetGeometryIntersectFunction], [rtcSetGeometryOccludedFunction]
