NOMBRE

Ref::Util - Funciones de utilidad para comprobar referencias

VERSIÓN

versión 0.204

SINOPSIS

use Ref::Util qw( is_plain_arrayref is_plain_hashref );
if ( is_plain_arrayref( $something ) ) {
    print for @{ $something };
} elsif ( is_plain_hashref( $something ) ) {
    print for sort values %{ $something };
}

DESCRIPCIÓN

Ref::Util introduce varias funciones para ayudar a identificar referencias de una manera más inteligente (y generalmente más rápida). En resumen:

# enfoque convencional             # con Ref::Util
ref( $foo ) eq 'ARRAY'              is_plain_arrayref( $foo )
use Scalar::Util qw( reftype );
reftype( $foo ) eq 'ARRAY'          is_arrayref( $foo )

La diferencia:

  • No hay comparación con una constante de cadena

    Cuando llamas a "ref", convierte la referencia a cadena y luego la compara con alguna constante de cadena (como "ARRAY" o "HASH"). No solo es incómodo, sino frágil, ya que puedes escribir mal la cadena.

    Si usas "reftype" de Scalar::Util, todavía la comparas como una cadena:

    if ( reftype($foo) eq 'ARRAY' ) { ... }
  • Soporta variables bendecidas (blessed)

    Nota: En versiones futuras, la idea es que las funciones predeterminadas utilicen la variación "plain", lo que significa referencias explícitamente no bendecidas.

    Si deseas comprobar explícitamente referencias bendecidas, deberías usar las funciones "is_blessed_*". Habrá una variación "is_any_*" que actuará como las funciones principales actuales: sin importar si está bendecida o no.

    Al llamar a "ref", recibes el tipo de referencia (SCALAR, ARRAY, HASH, etc.) o el paquete en el que está bendecida.

    Al llamar a "is_arrayref" (y similares), compruebas las banderas de la variable, por lo que, incluso si está bendecida, sabes qué tipo de variable está bendecida.

    my $foo = bless {}, 'PKG';
ref($foo) eq 'HASH'; # falla
use Ref::Util 'is_hashref';
my $foo = bless {}, 'PKG';
is_hashref($foo); # funciona

    Por otro lado, en algunas situaciones podría ser mejor excluir explícitamente las referencias bendecidas. El motivo podría ser que el mero hecho de que un objeto esté implementado usando un hash no significa que sea necesariamente correcto tratarlo como un hash. Para estas situaciones, puedes usar "is_plain_hashref" y similares, que tienen los mismos beneficios de rendimiento que "is_hashref".

    También hay una familia de funciones con nombres como "is_blessed_hashref"; estas devuelven verdadero para instancias de objetos bendecidos que están implementados utilizando el tipo subyacente relevante.

  • Soporta variables enlazadas (tied) y magia

    Las variables enlazadas (usadas en Readonly, por ejemplo) son compatibles.

    use Ref::Util qw<is_plain_hashref>;
use Readonly;
Readonly::Scalar my $rh2 => { a => { b => 2 } };
is_plain_hashref($rh2); # éxito

    Ref::Util añadió soporte para esto en 0.100. Antes de esta versión, la prueba fallaría.

  • Ignora la sobrecarga (overloading)

    Estas funciones ignoran los operadores sobrecargados y simplemente comprueban el tipo de variable. Es probable que la sobrecarga nunca sea compatible, ya que la considero problemática y confusa.

    La sobrecarga hace que tus variables sean contenedores opacos y oculta lo que son en lugar de requerir que descubras cómo usarlas. Esto lleva a código que tiene que probar diferentes habilidades (en "eval", para que no crashee) y a interfaces que evitan lo que una persona pensó que harías con una variable. Esto habría estado bien, excepto que no hay una forma clara de introspeccionarlo.

  • Ignora tipos sutiles:

    Los siguientes tipos, proporcionados por "reftype" de Scalar::Util, no son compatibles:

  • "VSTRING"

    Este es un "PVMG" (variable "normal") con una bandera establecida para VSTRINGs. Dado que no es una referencia, no es compatible.

  • "LVALUE"

    Una variable que delega a otro escalar. Dado que no es una referencia, no es compatible.

  • "INVLIST"

    No pude encontrar documentación para este tipo.

Se podría añadir soporte si surge una buena razón.

•
Generalmente rápido

Cuando es posible, Ref::Util usa Ref::Util::XS como su implementación. (Si no tienes un compilador C disponible, usa una implementación pura de Perl que tiene todas las otras ventajas de Ref::Util, pero no es tan rápida).

De hecho, Ref::Util::XS tiene dos implementaciones alternativas disponibles internamente, dependiendo de las características compatibles con la versión de Perl que estés usando. Para Perls que soportan OPs personalizados, realmente añadimos un OP (que es más rápido); para otros Perls, la implementación simplemente llama a una función XS (que sigue siendo más rápida que su equivalente en Perl puro).

Consulta a continuación los resultados de la evaluación comparativa (benchmark).

EXPORTAR

Nada se exporta por defecto. Puedes solicitar subrutinas específicas (descritas a continuación) o solicitar todas las subrutinas a la vez:

use Ref::Util qw<is_scalarref is_arrayref is_hashref ...>;
# o
use Ref::Util ':all';

SUBRUTINAS

is_ref($ref)

Comprueba si es una referencia a cualquier cosa.

is_ref([]);

is_scalarref($ref)

Comprueba si es una referencia escalar.

is_scalarref(\"hello");
is_scalarref(\30);
is_scalarref(\$value);

Ten en cuenta que, aunque una referencia es en sí misma un tipo de valor escalar, una referencia a otra referencia no se trata como una referencia escalar:

!is_scalarref(\\1);

La justificación para esto es doble. Primero, las llamadas que quieren decidir cómo manejar las entradas basándose en su tipo de referencia, generalmente querrán tratar una ref-ref y una ref-escalar de manera diferente. Segundo, esto se acerca más al comportamiento de la función incorporada "ref" y de "reftype" en Scalar::Util, que reportan una ref-ref como "REF" en lugar de "SCALAR".

is_arrayref($ref)

Comprueba si es una referencia de array.

is_arrayref([]);

is_hashref($ref)

Comprueba si es una referencia de hash.

is_hashref({});

is_coderef($ref)

Comprueba si es una referencia de código.

is_coderef( sub {} );

is_regexpref($ref)

Comprueba si es una referencia de expresión regular (regex, regexp).

is_regexpref( qr// );

is_globref($ref)

Comprueba si es una referencia glob.

is_globref( \*STDIN );

is_formatref($ref)

Comprueba si es una referencia de formato.

# configurar formato en STDOUT
format STDOUT =
.
# ahora podemos probarlo
is_formatref( *main::STDOUT{'FORMAT'} );

NAME

Ref::Util - Utilities for checking Perl references.

VERSION

This documentation refers to version 0.204 of Ref::Util.

SYNOPSIS

use Ref::Util qw(
    is_io_ref
    is_refref
    is_plain_scalarref
    is_plain_ref
    is_plain_arrayref
    is_plain_hashref
    is_plain_coderef
    is_plain_globref
    is_plain_formatref
    is_plain_refref
    is_blessed_scalarref
    is_blessed_ref
    is_blessed_arrayref
    is_blessed_hashref
    is_blessed_coderef
    is_blessed_globref
    is_blessed_formatref
    is_blessed_refref
);

DESCRIPTION

This module provides a set of convenient subroutines for checking the type and blessing status of Perl references.

EXPORT

All subroutines are exported by default.

SUBROUTINES

The following subroutines are available:

is_io_ref($ref)
Checks if the argument is an IO reference.
is_refref($ref)
Checks if the argument is a reference to another reference.
is_plain_scalarref($ref)
Checks if the argument is an unblessed scalar reference.
is_plain_ref($ref)
Checks if the argument is an unblessed reference of any type.
is_plain_arrayref($ref)
Checks if the argument is an unblessed array reference.
is_plain_hashref($ref)
Checks if the argument is an unblessed hash reference.
is_plain_coderef($ref)
Checks if the argument is an unblessed code reference.
is_plain_globref($ref)
Checks if the argument is an unblessed glob reference.
is_plain_formatref($ref)
Checks if the argument is an unblessed format reference.
is_plain_refref($ref)
Checks if the argument is an unblessed reference to another reference.
is_blessed_scalarref($ref)
Checks if the argument is a blessed scalar reference.
is_blessed_ref($ref)
Checks if the argument is a blessed reference of any type.
is_blessed_arrayref($ref)
Checks if the argument is a blessed array reference.
is_blessed_hashref($ref)
Checks if the argument is a blessed hash reference.
is_blessed_coderef($ref)
Checks if the argument is a blessed code reference.
is_blessed_globref($ref)
Checks if the argument is a blessed glob reference.
is_blessed_formatref($ref)
Checks if the argument is a blessed format reference.
is_blessed_refref($ref)
Checks if the argument is a blessed reference to another reference.

is_io_ref($ref)

Check for an IO reference.

is_io_ref( *STDOUT{IO} );

is_refref($ref)

Check for a reference to a reference.

is_refref( \[] ); # reference to array reference

is_plain_scalarref($ref)

Check for an unblessed scalar reference.

is_plain_scalarref(\"hello\");
is_plain_scalarref(\30);
is_plain_scalarref(\$value);

is_plain_ref($ref)

Check for an unblessed reference to anything.

is_plain_ref([]);

is_plain_arrayref($ref)

Check for an unblessed array reference.

is_plain_arrayref([]);

is_plain_hashref($ref)

Check for an unblessed hash reference.

is_plain_hashref({});

is_plain_coderef($ref)

Check for an unblessed code reference.

is_plain_coderef( sub {} );

is_plain_globref($ref)

Check for an unblessed glob reference.

is_plain_globref( \*STDIN );

is_plain_formatref($ref)

Check for an unblessed format reference.

# set up format in STDOUT
format STDOUT =
.
# now we can test it
is_plain_formatref(bless *main::STDOUT{'FORMAT'} );

is_plain_refref($ref)

Check for an unblessed reference to a reference.

is_plain_refref( \[] ); # reference to array reference

is_blessed_scalarref($ref)

Check for a blessed scalar reference.

is_blessed_scalarref(bless \$value);

is_blessed_ref($ref)

Check for a blessed reference to anything.

is_blessed_ref(bless [], $class);

is_blessed_arrayref($ref)

Check for a blessed array reference.

is_blessed_arrayref(bless [], $class);

is_blessed_hashref($ref)

Check for a blessed hash reference.

is_blessed_hashref(bless {}, $class);

is_blessed_coderef($ref)

Check for a blessed code reference.

is_blessed_coderef( bless sub {}, $class );

is_blessed_globref($ref)

Check for a blessed glob reference.

is_blessed_globref( bless \*STDIN, $class );

is_blessed_formatref($ref)

Check for a blessed format reference.

# set up format for FH
format FH =
.
# now we can test it
is_blessed_formatref(bless *FH{'FORMAT'}, $class );

is_blessed_refref($ref)

Check for a blessed reference to a reference.

is_blessed_refref( bless \[], $class ); # reference to array reference

BENCHMARKS

Here is a benchmark comparing similar checks.

my $bench = Dumbbench->new(
    target_rel_precision => 0.005,
    initial_runs         => 20,
);
my $amount = 1e7;
my $ref    = [];
$bench->add_instances(
    Dumbbench::Instance::PerlSub->new(
        name => 'Ref::Util::is_plain_arrayref (CustomOP)',
        code => sub {
            Ref::Util::is_plain_arrayref($ref) for ( 1 .. $amount )
        },
    ),
    Dumbbench::Instance::PerlSub->new(
        name => 'ref(), reftype(), !blessed()',
        code => sub {
            ref $ref
                && Scalar::Util::reftype($ref) eq 'ARRAY'
                && !Scalar::Util::blessed($ref)
                for ( 1 .. $amount );
        },
    ),
    Dumbbench::Instance::PerlSub->new(
        name => 'ref()',
        code => sub { ref($ref) eq 'ARRAY' for ( 1 .. $amount ) },
    ),
    Dumbbench::Instance::PerlSub->new(
        name => 'Data::Util::is_array_ref',
        code => sub { is_array_ref($ref) for ( 1 .. $amount ) },
    ),
);

The results:

ref():                                   5.335e+00 +/- 1.8e-02 (0.3%)
ref(), reftype(), !blessed():            1.5545e+01 +/- 3.1e-02 (0.2%)
Ref::Util::is_plain_arrayref (CustomOP): 2.7951e+00 +/- 6.2e-03 (0.2%)
Data::Util::is_array_ref:                5.9074e+00 +/- 7.5e-03 (0.1%)

(Rounded run time per iteration)

A benchmark against Data::Util:

Ref::Util::is_plain_arrayref: 3.47157e-01 +/- 6.8e-05 (0.0%)
Data::Util::is_array_ref:     6.7562e-01 +/- 7.5e-04 (0.1%)
