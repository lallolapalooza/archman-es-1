NOMBRE

Regexp::Common::SEN -- proporciona expresiones regulares para Números Socioeconómicos.

SINOPSIS

use Regexp::Common qw /SEN/;
while (<>) {
    /^$RE{SEN}{USA}{SSN}$/    and  print "Número de Seguridad Social\n";
}

DESCRIPCIÓN

Por favor, consulta el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No uses este módulo directamente, sino cárgalo a través de Regexp::Common.

"$RE{SEN}{USA}{SSN}{-sep}"

Devuelve un patrón que coincide con un Número de Seguridad Social (SSN) estadounidense. Los SSN constan de tres grupos de números, separados por un guión ("-"). Este patrón solo comprueba una estructura válida, es decir, valida si un número es un SSN válido, fue un SSN válido o quizás un SSN válido en el futuro. Hay casi mil millones de SSN posibles, y unos 400 millones están en uso, o han estado en uso.

Si se especifica "-sep=P", el patrón P se utiliza como separador entre los grupos de números.

Bajo "-keep" (ver Regexp::Common):

$1
captura el SSN completo.
$2
captura el primer grupo de dígitos (el número de área).
$3
captura el segundo grupo de dígitos (el número de grupo).
$4
captura el tercer grupo de dígitos (el número de serie).
