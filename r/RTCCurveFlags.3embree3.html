NOMBRE

RTCCurveFlags - banderas por segmento para geometría de curva

SINOPSIS

#include <embree3/rtcore.h>

enum RTCCurveFlags { RTC_CURVE_FLAG_NEIGHBOR_LEFT = (1 << 0), RTC_CURVE_FLAG_NEIGHBOR_RIGHT = (1 << 1) };

DESCRIPCIÓN

El tipo RTCCurveFlags se utiliza para curvas lineales para determinar si existe el segmento vecino izquierdo y/o derecho. Por lo tanto, se adjunta un buffer de tipo RTC_BUFFER_TYPE_FLAGS a la geometría de la curva, que almacena un byte individual por segmento de curva.

Si la bandera RTC_CURVE_FLAG_NEIGHBOR_LEFT en ese byte está habilitada para un segmento de curva, entonces el segmento izquierdo existe (que comienza un vértice antes del vértice de inicio de la curva actual) y el segmento actual se renderiza para unirse correctamente a ese segmento.

Si la bandera RTC_CURVE_FLAG_NEIGHBOR_RIGHT en ese byte está habilitada para un segmento de curva, entonces el segmento derecho existe (que termina un vértice después del vértice final de la curva actual) y el segmento actual se renderiza para unirse correctamente a ese segmento.

Cuando no se especifican correctamente las banderas izquierda y derecha para las curvas lineales, la renderización al final de estas curvas puede no verse correcta, en particular cuando las curvas lineales redondeadas se ven desde el interior.
