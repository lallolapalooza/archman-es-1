NOMBRE

RTC_GEOMETRY_TYPE_GRID - tipo de geometría de cuadrícula

SINOPSIS

#include <embree4/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_GRID);

DESCRIPCIÓN

Las mallas de cuadrícula se crean pasando RTC_GEOMETRY_TYPE_GRID a la llamada a la función rtcNewGeometry, y contienen una matriz de primitivas de cuadrícula. Esta matriz de cuadrículas se puede especificar configurando un búfer de cuadrícula (con tipo RTC_BUFFER_TYPE_GRID y formato RTC_FORMAT_GRID) y los vértices de la malla de cuadrícula configurando un búfer de vértices (tipo RTC_BUFFER_TYPE_VERTEX). Consulte rtcSetGeometryBuffer y rtcSetSharedGeometryBuffer para obtener más detalles sobre cómo configurar los búferes. El número de primitivas de cuadrícula en la malla de cuadrícula se infiere del tamaño del búfer de cuadrícula.

El búfer de vértices contiene una matriz de coordenadas flotantes de precisión simple x, y, z (formato RTC_FORMAT_FLOAT3), y el número de vértices se infiere del tamaño de ese búfer.

Cada cuadrícula en el búfer de cuadrícula es del tipo RTCGrid:

struct RTCGrid
{
  unsigned int startVertexID;
  unsigned int stride;
  unsigned short width,height; 
};

La estructura RTCGrid describe una cuadrícula 2D de vértices (con respecto al búfer de vértices de la malla de cuadrícula). Los miembros width y height especifican el número de vértices en la dirección u y v, por ejemplo, establecer width y height en 3 configura una cuadrícula de vértices de 3x3. El ancho y alto máximos permitidos son 32767. startVertexID especifica el ID del vértice superior izquierdo en la cuadrícula de vértices, mientras que el parámetro stride especifica un paso (en número de vértices) para avanzar a la siguiente fila.

Una cuadrícula de vértices de dimensiones width y height se trata como una cuadrícula de cuadriláteros (pares de triángulos) de (width-1) x (height-1), con el mismo manejo de bordes compartidos que para las mallas de cuadriláteros regulares. Sin embargo, las coordenadas u/v tienen el rango uniforme [0..1] para toda una cuadrícula de vértices. La dirección u sigue el ancho de la cuadrícula, mientras que la dirección v sigue la altura.

Para desenfoque de movimiento multiesegmento, primero se debe especificar el número de pasos de tiempo utilizando la llamada rtcSetGeometryTimeStepCount. Luego, se puede configurar un búfer de vértices para cada paso de tiempo utilizando diferentes ranuras de búfer, y todos estos búferes deben tener el mismo stride y tamaño.

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry]
