RSA_private_encrypt(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_PRIVATE_ENCRYPT(3ssl) OpenSSL RSA_PRIVATE_ENCRYPT(3ssl)

NOMBRE

RSA_private_encrypt, RSA_public_decrypt - operaciones de firma de bajo nivel

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int RSA_private_encrypt(int flen, unsigned char *from,
                        unsigned char *to, RSA *rsa, int padding);
int RSA_public_decrypt(int flen, unsigned char *from,
                       unsigned char *to, RSA *rsa, int padding);

DESCRIPCIÓN

Ambas funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_sign_init_ex(3), EVP_PKEY_sign(3), EVP_PKEY_verify_recover_init(3), y EVP_PKEY_verify_recover(3).

Estas funciones manejan firmas RSA a bajo nivel.

RSA_private_encrypt() firma los flen bytes en from (generalmente un resumen del mensaje con un identificador de algoritmo) usando la clave privada rsa y almacena la firma en to. to debe apuntar a RSA_size(rsa) bytes de memoria.

padding denota uno de los siguientes modos:

RSA_PKCS1_PADDING
Relleno PKCS #1 v1.5. Esta función no maneja el algorithmIdentifier especificado en PKCS #1. Al generar o verificar firmas PKCS #1, se deberían usar RSA_sign(3) y RSA_verify(3).
RSA_NO_PADDING
Firma RSA en crudo. Este modo sólo debería usarse para implementar modos de relleno criptográficamente seguros en el código de la aplicación. Firmar datos de usuario directamente con RSA es inseguro.

RSA_public_decrypt() recupera el resumen del mensaje del digest de flen bytes en from usando la clave pública del firmante rsa. to debe apuntar a una sección de memoria lo suficientemente grande para contener el resumen del mensaje (que es menor que RSA_size(rsa) - 11). padding es el modo de relleno que se utilizó para firmar los datos.

VALORES DE RETORNO

RSA_private_encrypt() devuelve el tamaño de la firma (es decir, RSA_size(rsa)). RSA_public_decrypt() devuelve el tamaño del resumen del mensaje recuperado.

En caso de error, se devuelve -1; los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), RSA_sign(3), RSA_verify(3), EVP_PKEY_sign(3), EVP_PKEY_verify_recover(3)

HISTORIA

Ambas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
