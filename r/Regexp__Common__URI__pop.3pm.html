NOMBRE

Regexp::Common::URI::pop -- Devuelve un patrón para URIs POP.

SINOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{POP}/       and  print "Contiene una URI POP.\n";
}

DESCRIPCIÓN

$RE{URI}{POP}

Devuelve un patrón que coincide con URIs POP, según lo definido por RFC 2384. Las URIs POP tienen la forma:

"pop:" "//" [ usuario [ ";AUTH" ( "*" | tipo_autenticacion ) ] "@" ]
              host [ ":" puerto ]

Bajo "{-keep}", se devuelven los siguientes:

$1
La URI completa.
$2
El esquema.
$3
El usuario, si se proporciona.
$4
El tipo de autenticación, si se proporciona (podría ser un *).
$5
El host.
$6
El puerto, si se proporciona.

REFERENCIAS

[RFC 2384]
Gellens, R.: POP URL Scheme. Agosto de 1998.

VER TAMBIÉN

Regexp::Common::URI para otras URIs compatibles.
