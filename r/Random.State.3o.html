Estas funciones son las mismas que las funciones básicas, excepto que usan (y actualizan) el estado de PRNG dado en lugar del predeterminado.

val split : t -> t

Extrae un nuevo estado de PRNG del estado de PRNG dado (el estado de PRNG dado se modifica). El nuevo PRNG es estadísticamente independiente del PRNG dado. Se pueden extraer datos de ambos PRNG, en cualquier orden, sin riesgo de correlación. Ambos PRNG se pueden dividir posteriormente, arbitrariamente muchas veces.

Desde 5.0

val to_binary_string : t -> string

Serializa el estado del PRNG en una secuencia inmutable de bytes. Ver Random.State.of_binary_string para deserializar.

El tipo string está destinado aquí solo para serialización, la codificación no es legible por humanos y puede que no sea imprimible.

Tenga en cuenta que el formato de serialización puede diferir entre las versiones de OCaml.

Desde 5.1

val of_binary_string : string -> t

Deserializa una secuencia de bytes obtenida al llamar a Random.State.to_binary_string . El estado del PRNG resultante producirá los mismos números aleatorios que el estado que se pasó como entrada a Random.State.to_binary_string .

Desde 5.1

Lanza Failure si la entrada no está en el formato esperado.

Tenga en cuenta que el formato de serialización puede diferir entre las versiones de OCaml.

A diferencia de las funciones proporcionadas por el módulo Marshal , esta función produce un estado válido o falla limpiamente con una excepción Failure . Se puede usar de forma segura en entradas del usuario, no confiables.
