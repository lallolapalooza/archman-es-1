RTCRay(3) Núcleos de Trazado de Rayos Embree 3 RTCRay(3)

NOMBRE

RTCRay - estructura de rayo individual

SINOPSIS

#include <embree3/rtcore_ray.h>
struct RTC_ALIGN(16) RTCRay
{
  float org_x;        // coordenada x del origen del rayo
  float org_y;        // coordenada y del origen del rayo
  float org_z;        // coordenada z del origen del rayo
  float tnear;        // inicio del segmento del rayo
  float dir_x;        // coordenada x de la dirección del rayo
  float dir_y;        // coordenada y de la dirección del rayo
  float dir_z;        // coordenada z de la dirección del rayo
  float time;         // tiempo de este rayo para desenfoque de movimiento
  float tfar;         // fin del segmento del rayo (establecido a la distancia de impacto)
  unsigned int mask;  // máscara del rayo
  unsigned int id;    // ID del rayo
  unsigned int flags; // flags del rayo
};

DESCRIPCIÓN

La estructura RTCRay define el diseño del rayo para un rayo individual. El rayo contiene el origen (miembros org_x, org_y, org_z), el vector de dirección (miembros dir_x, dir_y, dir_z) y el segmento del rayo (miembros tnear y tfar). La dirección del rayo no tiene que estar normalizada, y solo se considera válido el rango de parámetros especificado por el intervalo tnear/tfar.

El segmento del rayo debe estar en el rango [0, ∞], por lo tanto, no se permiten rangos que comiencen detrás del origen del rayo, pero los rangos pueden extenderse hasta el infinito. Para los rayos dentro de un flujo de rayos, tfar < tnear identifica un rayo inactivo.

El rayo además contiene un tiempo de desenfoque de movimiento en el rango [0, 1] (miembro time), una máscara de rayo (miembro mask), un ID de rayo (miembro id) y flags de rayo (miembro flags). La máscara del rayo se puede usar para enmascarar algunas geometrías para algunos rayos (consulte rtcSetGeometryMask para más detalles). El ID del rayo se puede usar para identificar un rayo dentro de una función de devolución de llamada, incluso si el orden de los rayos dentro de un paquete o flujo de rayos ha cambiado. Los flags del rayo están reservados.

El encabezado embree3/rtcore_ray.h define adicionalmente la misma estructura de rayo en un diseño de estructura de arreglos (SOA) para funciones de API que aceptan paquetes de rayos de tamaño 4 (tipo RTCRay4), tamaño 8 (RTCRay8) y tamaño 16 (RTCRay16). El encabezado define además una plantilla RTCRayNt para paquetes de rayos de un tamaño arbitrario en tiempo de compilación.
