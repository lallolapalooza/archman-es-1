NOMBRE

RTC_GEOMETRY_TYPE_TRIANGLE - tipo de geometría de triángulo

SINOPSIS

#include <embree4/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_TRIANGLE);

DESCRIPCIÓN

Las mallas triangulares se crean pasando RTC_GEOMETRY_TYPE_TRIANGLE a la llamada a la función rtcNewGeometry. Los índices de los triángulos se pueden especificar estableciendo un búfer de índices (tipo RTC_BUFFER_TYPE_INDEX) y los vértices de los triángulos estableciendo un búfer de vértices (tipo RTC_BUFFER_TYPE_VERTEX). Consulte rtcSetGeometryBuffer y rtcSetSharedGeometryBuffer para obtener más detalles sobre cómo establecer búferes. El búfer de índices debe contener una matriz de tres índices de 32 bits por triángulo (formato RTC_FORMAT_UINT3) y el número de primitivas se infiere del tamaño de ese búfer. El búfer de vértices debe contener una matriz de coordenadas flotantes de un solo precisión x, y, z (formato RTC_FORMAT_FLOAT3), y el número de vértices se infiere del tamaño de ese búfer. El búfer de vértices puede tener como máximo 16 GB.

La parametrización de un triángulo utiliza el primer vértice p0 como punto base, el vector p1 - p0 como dirección u y el vector p2 - p0 como dirección v. Por lo tanto, los atributos de vértice t0, t1, t2 se pueden interpolar linealmente sobre el triángulo de la siguiente manera:

t_uv = (1-u-v)*t0 + u*t1 + v*t2
     = t0 + u*(t1-t0) + v*(t2-t0)

Luego, se puede configurar un búfer de vértices para cada paso de tiempo utilizando diferentes ranuras de búfer, y todos estos búferes deben tener la misma extensión y tamaño.

Consulte también el tutorial [Geometría de triángulo] para ver un ejemplo de cómo crear mallas triangulares.

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.
