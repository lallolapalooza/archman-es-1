RAND_set_rand_method(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RAND_SET_RAND_METHOD(3ssl) OpenSSL RAND_SET_RAND_METHOD(3ssl)

NOMBRE

RAND_set_rand_method, RAND_get_rand_method, RAND_OpenSSL - seleccionar método RAND

SINOPSIS

#include <openssl/rand.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

RAND_METHOD *RAND_OpenSSL(void);
int RAND_set_rand_method(const RAND_METHOD *meth);
const RAND_METHOD *RAND_get_rand_method(void);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar RAND_set_DRBG_type(3), EVP_RAND(3) y EVP_RAND(7).

Un RAND_METHOD especifica las funciones que OpenSSL utiliza para la generación de números aleatorios.

RAND_OpenSSL() devuelve la implementación predeterminada del RAND_METHOD de OpenSSL. Esta implementación asegura que el estado del PRNG sea único para cada hilo.

Si se carga un ENGINE que proporciona la API RAND, se utilizará en lugar del método devuelto por RAND_OpenSSL(). Esto está obsoleto en OpenSSL 3.0.

RAND_set_rand_method() convierte a meth en el método para uso del PRNG. Si un ENGINE estaba proporcionando el método, se liberará primero.

RAND_get_rand_method() devuelve un puntero al RAND_METHOD actual.

LA ESTRUCTURA RAND_METHOD

typedef struct rand_meth_st {
    int (*seed)(const void *buf, int num);
    int (*bytes)(unsigned char *buf, int num);
    void (*cleanup)(void);
    int (*add)(const void *buf, int num, double entropy);
    int (*pseudorand)(unsigned char *buf, int num);
    int (*status)(void);
} RAND_METHOD;

Los campos apuntan a funciones que se utilizan, en orden, por RAND_seed(), RAND_bytes(), limpieza interna de RAND, RAND_add(), RAND_pseudo_rand() y RAND_status(). Cada puntero puede ser NULL si la función no está implementada.

VALORES DE RETORNO

RAND_set_rand_method() devuelve 1 si tiene éxito y 0 si falla. RAND_get_rand_method() y RAND_OpenSSL() devuelven punteros a los métodos respectivos.

VER TAMBIÉN

EVP_RAND(3), RAND_set_DRBG_type(3), RAND_bytes(3), ENGINE_by_id(3), EVP_RAND(7), RAND(7)

HISTORIAL

Todas estas funciones fueron obsoletas en OpenSSL 3.0.
