RSA_generate_key(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_GENERATE_KEY(3ssl) OpenSSL RSA_GENERATE_KEY(3ssl)

NOMBRE

EVP_RSA_gen, RSA_generate_key_ex, RSA_generate_key, RSA_generate_multi_prime_key - generar par de claves RSA

SINOPSIS

#include <openssl/rsa.h>
EVP_PKEY *EVP_RSA_gen(unsigned int bits);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int RSA_generate_key_ex(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);
int RSA_generate_multi_prime_key(RSA *rsa, int bits, int primes, BIGNUM *e, BN_GENCB *cb);

La siguiente función ha sido marcada como obsoleta desde OpenSSL 0.9.8, y puede ser oculta completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

RSA *RSA_generate_key(int bits, unsigned long e,
                      void (*callback)(int, int, void *), void *cb_arg);

DESCRIPCIÓN

EVP_RSA_gen() genera un nuevo par de claves RSA con un tamaño de módulo de bits.

Todas las funciones descritas a continuación están obsoletas. Las aplicaciones deberían usar en su lugar EVP_RSA_gen(), EVP_PKEY_Q_keygen(3), o EVP_PKEY_keygen_init(3) y EVP_PKEY_keygen(3).

RSA_generate_key_ex() genera un par de claves RSA de 2 primos y lo almacena en la estructura RSA proporcionada en rsa.

RSA_generate_multi_prime_key() genera un par de claves RSA multi-primo y lo almacena en la estructura RSA proporcionada en rsa. El número de primos se da por el parámetro primes. Si la siembra o resiembra automática del CSPRNG de OpenSSL falla debido a circunstancias externas (véase RAND(7)), la operación fallará.

El tamaño del módulo será de longitud bits, el número de primos para formar el módulo será primes, y el exponente público será e. Los tamaños de clave con num < 1024 deberían considerarse inseguros. El exponente es un número impar, típicamente 3, 17 o 65537.

Para mantener un nivel de seguridad adecuado, el número máximo de primes permitido depende de la longitud del módulo en bits:

<1024 | >=1024 | >=4096 | >=8192
------+--------+--------+-------
  2   |   3    |   4    |   5

Una función de callback puede ser usada para proporcionar información sobre el progreso de la generación de la clave. Si cb no es NULL, se llamará usando la función BN_GENCB_call() descrita en la página de BN_generate_prime(3).

RSA_generate_key() es similar a RSA_generate_key_ex() pero espera una función de callback de estilo antiguo; véase BN_generate_prime(3) para información sobre la callback de estilo antiguo.

  • Mientras se genera un número primo aleatorio, se llama como se describe en BN_generate_prime(3).
  • Cuando el n-ésimo primo generado aleatoriamente se rechaza por no ser adecuado para la clave, se llama a BN_GENCB_call(cb, 2, n).
  • Cuando se encuentra un primo p tal que p-1 es relativamente primo a e, se llama como BN_GENCB_call(cb, 3, 0).

El proceso se repite luego para el primo q y otros primos (si los hay) con BN_GENCB_call(cb, 3, i) donde i indica el i-ésimo primo.

VALORES DE RETORNO

EVP_RSA_gen() devuelve un EVP_PKEY o NULL en caso de fallo.

RSA_generate_multi_prime_key() devuelve 1 en caso de éxito o 0 en caso de error. RSA_generate_key_ex() devuelve 1 en caso de éxito o 0 en caso de error. Los códigos de error pueden obtenerse con ERR_get_error(3).

RSA_generate_key() devuelve un puntero a la estructura RSA o NULL si la generación de la clave falla.

ERRORES

BN_GENCB_call(cb, 2, x) se usa con dos significados diferentes.

VER TAMBIÉN

EVP_PKEY_Q_keygen(3) BN_generate_prime(3), ERR_get_error(3), RAND_bytes(3), RAND(7)

HISTORIA

EVP_RSA_gen() se añadió en OpenSSL 3.0. Todas las demás funciones descritas aquí fueron marcadas como obsoletas en OpenSSL 3.0. Para reemplazos véase EVP_PKEY-RSA(7).
