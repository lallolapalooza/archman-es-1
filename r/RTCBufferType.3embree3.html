RTCBufferType(3) Embree Ray Tracing Kernels 3 RTCBufferType(3)

NOMBRE

RTCFormat - especifica el formato de los datos en los búferes

SINOPSIS

#include <embree3/rtcore_ray.h>
enum RTCBufferType
{
  RTC_BUFFER_TYPE_INDEX            = 0,
  RTC_BUFFER_TYPE_VERTEX           = 1,
  RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE = 2,
  RTC_BUFFER_TYPE_NORMAL           = 3,
  RTC_BUFFER_TYPE_TANGENT          = 4,
  RTC_BUFFER_TYPE_NORMAL_DERIVATIVE = 5,
  RTC_BUFFER_TYPE_GRID                 = 8,
  RTC_BUFFER_TYPE_FACE                 = 16,
  RTC_BUFFER_TYPE_LEVEL                = 17,
  RTC_BUFFER_TYPE_EDGE_CREASE_INDEX    = 18,
  RTC_BUFFER_TYPE_EDGE_CREASE_WEIGHT   = 19,
  RTC_BUFFER_TYPE_VERTEX_CREASE_INDEX  = 20,
  RTC_BUFFER_TYPE_VERTEX_CREASE_WEIGHT = 21,
  RTC_BUFFER_TYPE_HOLE                 = 22,
  RTC_BUFFER_TYPE_FLAGS = 32
};

DESCRIPCIÓN

La estructura RTBufferType define ranuras para asignar búferes de datos utilizando las llamadas a la API [rtcSetGeometryBuffer], [rtcSetSharedGeometryBuffer] y [rtcSetNewGeometryBuffer].

Para la mayoría de los tipos de geometría, la ranura RTC_BUFFER_TYPE_INDEX se utiliza para asignar un búfer de índices, mientras que RTC_BUFFER_TYPE_VERTEX se utiliza para asignar el búfer de vértices correspondiente.

La ranura RTC_BUFFER_TYPE_VERTEX_ATTRIBUTE se puede utilizar para asignar datos de vértices adicionales arbitrarios que se pueden interpolar utilizando la llamada a la API [rtcInterpolate].

RTC_BUFFER_TYPE_NORMAL, RTC_BUFFER_TYPE_TANGENT y RTC_BUFFER_TYPE_NORMAL_DERIVATIVE son búferes especiales necesarios para asignar normales, tangentes y derivadas normales por vértice para algunos tipos de curvas.

El búfer RTC_BUFFER_TYPE_GRID se utiliza para asignar el búfer de primitivas de cuadrícula para geometrías de cuadrícula (ver [RTC_GEOMETRY_TYPE_GRID]).

Los búferes RTC_BUFFER_TYPE_FACE, RTC_BUFFER_TYPE_LEVEL, RTC_BUFFER_TYPE_EDGE_CREASE_INDEX, RTC_BUFFER_TYPE_EDGE_CREASE_WEIGHT, RTC_BUFFER_TYPE_VERTEX_CREASE_INDEX, RTC_BUFFER_TYPE_VERTEX_CREASE_WEIGHT y RTC_BUFFER_TYPE_HOLE son búferes especiales necesarios para crear mallas de subdivisión (ver [RTC_GEOMETRY_TYPE_SUBDIVISION]).

RTC_BUFFER_TYPE_FLAGS se puede utilizar para agregar indicadores adicionales por primitiva de una geometría, y actualmente solo se usa para curvas lineales.
