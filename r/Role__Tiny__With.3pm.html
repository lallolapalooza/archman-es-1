NOMBRE

Role::Tiny::With - Interfaz ordenada para consumidores de roles Role::Tiny

SINOPSIS

package Some::Class;
use Role::Tiny::With;
with 'Some::Role';
# El rol está ahora mezclado

DESCRIPCIÓN

Role::Tiny es una herramienta minimalista de composición de roles. Role::Tiny::With proporciona una función with para componer dichos roles.
