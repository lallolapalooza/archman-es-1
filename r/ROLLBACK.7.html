NOMBRE

ROLLBACK - abortar la transacción actual

SINOPSIS

ROLLBACK [ WORK | TRANSACTION ] [ AND [ NO ] CHAIN ]

DESCRIPCIÓN

ROLLBACK revierte la transacción actual y descarta todas las actualizaciones realizadas por la transacción.

PARÁMETROS

WORK
TRANSACTION

Palabras clave opcionales. No tienen efecto.

AND CHAIN

Si se especifica AND CHAIN, se inicia inmediatamente una nueva transacción (no abortada) con las mismas características de transacción (ver SET TRANSACTION (SET_TRANSACTION(7))) que la recién terminada. De lo contrario, no se inicia ninguna transacción nueva.

NOTAS

Use COMMIT para terminar exitosamente una transacción.

Emitir ROLLBACK fuera de un bloque de transacción genera una advertencia y, de lo contrario, no tiene efecto. ROLLBACK AND CHAIN fuera de un bloque de transacción es un error.

EJEMPLOS

Para abortar todos los cambios:

ROLLBACK;

COMPATIBILIDAD

El comando ROLLBACK cumple con el estándar SQL. La forma ROLLBACK TRANSACTION es una extensión de PostgreSQL.

VER TAMBIÉN

BEGIN(7), COMMIT(7), ROLLBACK TO SAVEPOINT (ROLLBACK_TO_SAVEPOINT(7))
