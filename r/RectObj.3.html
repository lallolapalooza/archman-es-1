NOMBRE

RectObj — La clase de widget RectObj

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

RectObj nunca se instancia. Su único propósito es como superclase de soporte para otras clases de widgets.

Clases

RectObj hereda el comportamiento y un recurso de Object.

El puntero de clase es rectObjClass.

El nombre de la clase es RectObj.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widgets utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en tiempo de creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNancestorSensitive
Especifica si el padre inmediato del gadget recibe eventos de entrada. Utilice la función XtSetSensitive si está cambiando el argumento para preservar la integridad de los datos (consulte XmNsensitive). El valor predeterminado es el AND bit a bit de los recursos XmNsensitive y XmNancestorSensitive del padre.
XmNborderWidth
Especifica el ancho del borde colocado alrededor del área de visualización rectangular del RectObj.
XmNheight
Especifica la altura interior (excluyendo el borde) del área de visualización rectangular del RectObj.
XmNsensitive
Determina si un RectObj recibe eventos de entrada. Si un RectObj es sensible, el padre distribuye al gadget todos los eventos de teclado, botones del ratón, movimiento, entrada/salida de ventana y foco. Los gadgets insensibles no reciben estos eventos. Utilice la función XtSetSensitive para cambiar el argumento de sensibilidad. El uso de XtSetSensitive garantiza que si un widget padre tiene XmNsensitive establecido en False, el indicador de sensibilidad del ancestro de todos sus hijos se establecerá de forma apropiada.
XmNwidth
Especifica el ancho interior (excluyendo el borde) del área de visualización rectangular del RectObj.
XmNx
Especifica la coordenada x de la esquina superior izquierda exterior del área de visualización rectangular del RectObj. El valor es relativo a la esquina superior izquierda interior de la ventana padre.
XmNy
Especifica la coordenada y de la esquina superior izquierda exterior del área de visualización rectangular del RectObj. El valor es relativo a la esquina superior izquierda interior de la ventana padre.
