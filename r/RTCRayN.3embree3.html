RTCRayN(3) Núcleos de trazado de rayos de Embree 3 RTCRayN(3)

NOMBRE

RTCRayN - paquete de rayos de tamaño en tiempo de ejecución

SINOSIS

#include <embree3/rtcore_ray.h>

float& RTCRayN_org_y(RTCRayN* ray, unsigned int N, unsigned int i);

float& RTCRayN_tnear(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_x(RTCRayN* ray, unsigned int N, unsigned int i);

unsigned int& RTCRayN_flags(RTCRayN* ray, unsigned int N, unsigned int i);

DESCRIPCIÓN

Cuando el tamaño del paquete de rayos no se conoce en tiempo de compilación (por ejemplo, cuando Embree devuelve un paquete de rayos en la función de callback RTCFilterFuncN), Embree usa el tipo RTCRayN para los paquetes de rayos. Estos paquetes de rayos solo pueden tener tamaños de 1, 4, 8 o 16. No se utilizará ningún otro tamaño de paquete.

Puede implementar diferentes rutas de código especiales para cada uno de estos tamaños de paquete posibles y convertir el rayo al tipo de paquete de rayos apropiado, o implementar una ruta de código general que utilice las funciones de ayuda RTCRayN_XXX para acceder a los componentes del paquete de rayos.

Estas funciones de ayuda toman un puntero al paquete de rayos (argumento ray), el tamaño del paquete (argumento N) y devuelven una referencia a un componente (por ejemplo, componente x del origen) del i-ésimo rayo del paquete (argumento i).
