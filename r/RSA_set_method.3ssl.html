RSA_set_method(3ssl)

Paquete: openssl

RSA_set_method(3ssl) OpenSSL RSA_set_method(3ssl)

NOMBRE

RSA_set_default_method, RSA_get_default_method, RSA_set_method, RSA_get_method, RSA_PKCS1_OpenSSL, RSA_flags, RSA_new_method - seleccionar el método RSA

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor adecuado, ver openssl_user_macros(7):

void RSA_set_default_method(const RSA_METHOD *meth);
const RSA_METHOD *RSA_get_default_method(void);
int RSA_set_method(RSA *rsa, const RSA_METHOD *meth);
const RSA_METHOD *RSA_get_method(const RSA *rsa);
const RSA_METHOD *RSA_PKCS1_OpenSSL(void);
int RSA_flags(const RSA *rsa);
RSA *RSA_new_method(ENGINE *engine);

DESCRIPCIÓN

Todas las funciones descritas en esta página son obsoletas. Las aplicaciones deben usar las APIs OSSL_PROVIDER.

Un RSA_METHOD especifica las funciones que OpenSSL usa para las operaciones RSA. Modificando el método, se pueden usar implementaciones alternativas como acceleradores de hardware. IMPORTANTE: Ver la sección openssl_notes(7) para información importante sobre cómo estas funciones de API de RSA se ven afectadas por llamadas a la API ENGINE.

Inicialmente, el método RSA por defecto es la implementación interna de OpenSSL, como se devuelve por RSA_PKCS1_OpenSSL().

RSA_set_default_method() hace de meth el método por defecto para todas las estructuras de RSA creadas posteriormente. NOTA: Esto es válido solo mientras ningún ENGINE ha sido configurado como por defecto para RSA, por lo que esta función ya no se recomienda. Esta función no es thread-safe y no debe ser llamada simultáneamente con otras funciones de OpenSSL.

RSA_get_default_method() devuelve un puntero al método RSA actual. Sin embargo, el valor significativo de este resultado depende de si se está utilizando la API ENGINE, por lo que esta función ya no se recomienda.

RSA_set_method() selecciona meth para realizar todas las operaciones con la clave rsa. Esto reemplazará el método RSA utilizado por la clave RSA, y si el método anterior fue proporcionado por un ENGINE, el handle a ese ENGINE se liberará durante el cambio. Es posible tener claves RSA que solo funcionen con ciertas implementaciones de RSA (por ejemplo, de un módulo de ENGINE que soporta claves protegidas por hardware), y en esos casos, intentar cambiar el método RSA para la clave puede tener resultados inesperados.

RSA_get_method() devuelve un puntero al método RSA que se está utilizando para rsa. Este método puede o no ser proporcionado por una implementación de ENGINE, pero si lo está, el valor devuelto solo puede ser garantizado si la clave RSA en sí misma es válida y no ha sido cambiada por RSA_set_method().

RSA_flags() devuelve los flags que están activos para el método actual de rsa. Ver la sección openssl_bugs(7).

RSA_new_method() asigna e inicializa una estructura RSA de manera que engine se use para las operaciones RSA. Si engine es NULL, se usa el engine por defecto para las operaciones RSA, y si no hay engine por defecto, se usa el método RSA controlado por RSA_set_default_method().

RSA_flags() devuelve los flags que están activos para el método actual de rsa.

RSA_new_method() asigna e inicializa una estructura RSA de manera que method se use para las operaciones RSA. Si method es NULL, se usa el método por defecto.

LA ESTRUCTURA RSA_METHOD

typedef struct rsa_meth_st
{
    /* nombre de la implementación */
    const char *name;
    /* cifrar */
    int (*rsa_pub_enc)(int flen, unsigned char *from,
                       unsigned char *to, RSA *rsa, int padding);
    /* verificar datos arbitrarios */
    int (*rsa_pub_dec)(int flen, unsigned char *from,
                       unsigned char *to, RSA *rsa, int padding);
    /* firmar datos arbitrarios */
    int (*rsa_priv_enc)(int flen, unsigned char *from,
                        unsigned char *to, RSA *rsa, int padding);
    /* descifrar */
    int (*rsa_priv_dec)(int flen, unsigned char *from,
                        unsigned char *to, RSA *rsa, int padding);
    /* calcular r0 = r0 ^ I mod rsa->n (Puede ser NULL para algunas implementaciones) */
    int (*rsa_mod_exp)(BIGNUM *r0, BIGNUM *I, RSA *rsa);
    /* calcular r = a ^ p mod m (Puede ser NULL para algunas implementaciones) */
    int (*bn_mod_exp)(BIGNUM *r, BIGNUM *a, const BIGNUM *p,
                      const BIGNUM *m, BN_CTX *ctx, BN_MONT_CTX *m_ctx);
    /* llamado al RSA_new */
    int (*init)(RSA *rsa);
    /* llamado al RSA_free */
    int (*finish)(RSA *rsa);
    /*
     * RSA_FLAG_EXT_PKEY        - rsa_mod_exp se llama incluso si p,q,dmp1,dmq1,iqmp
     *                            son NULL
     * RSA_METHOD_FLAG_NO_CHECK - no se verifica la coincidencia entre pub y priv
     */
    int flags;
    char *app_data; /* ?? */
    int (*rsa_sign)(int type,
                    const unsigned char *m, unsigned int m_length,
                    unsigned char *sigret, unsigned int *siglen, const RSA *rsa);
    int (*rsa_verify)(int dtype,
                      const unsigned char *m, unsigned int m_length,
                      const unsigned char *sigbuf, unsigned int siglen,
                      const RSA *rsa);
    /* clave de generación. Si NULL, se utilizará la generación de clave interna */
    int (*rsa_keygen)(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);
} RSA_METHOD;

VALORES DE RETORNO

RSA_PKCS1_OpenSSL(), RSA_PKCS1_null_method(), RSA_get_default_method() y RSA_get_method() devuelven punteros a los respectivos RSA_METHODs.

RSA_set_default_method() no devuelve ningún valor.

RSA_set_method() devuelve un puntero al método RSA antiguo que fue reemplazado. Sin embargo, este valor devuelto probablemente debería ignorarse, ya que si fue proporcionado por un ENGINE, el puntero podría invalidarse en cualquier momento si el ENGINE es desactivado (en realidad, podría ser desactivado como resultado de que RSA_set_method() libere su handle al ENGINE). Por este motivo, el tipo de retorno podría ser reemplazado por una declaración void en una futura versión.

RSA_new_method() devuelve NULL y establece un código de error que puede obtenerse mediante ERR_get_error(3) si la asignación falla. De lo contrario, devuelve un puntero a la estructura recién creada.

ERRORES

El comportamiento de RSA_flags() es una mala característica que se mantiene como es ahora para evitar problemas de compatibilidad. La funcionalidad de RSA, como las funciones de cifrado, está controlada por el valor flags en la propia clave RSA, no por el valor flags en el RSA_METHOD asociado a la clave RSA (que es lo que devuelve esta función). Si el elemento de flags de una clave RSA es cambiado, los cambios se aplicarán a la funcionalidad de RSA pero no se reflejarán en el valor devuelto por RSA_flags() - en efecto, RSA_flags() se comporta más como una función RSA_default_flags() (la cual no existe actualmente).

VER TAMBIÉN

RSA_new(3)

HISTORIA

Todas estas funciones han sido obsoletas en OpenSSL 3.0.

La RSA_null_method(), que era un intento parcial para evitar problemas de patentes, fue reemplazada por siempre devolver NULL en OpenSSL 1.1.1.
