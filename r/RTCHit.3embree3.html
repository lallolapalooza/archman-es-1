RTCHit(3) Núcleos de trazado de rayos Embree 3 RTCHit(3)

NOMBRE

RTCHit - estructura de impacto único

SINOPSIS

#include <embree3/rtcore.h>
struct RTCHit
{
  float Ng_x;                                        // coordenada x de la normal geométrica
  float Ng_y;                                        // coordenada y de la normal geométrica
  float Ng_z;                                        // coordenada z de la normal geométrica
  float u;                                           // coordenada u baricéntrica del impacto
  float v;                                           // coordenada v baricéntrica del impacto
  unsigned int primID;                               // ID de geometría
  unsigned int geomID;                               // ID de primitiva
  unsigned int instID[RTC_MAX_INSTANCE_LEVEL_COUNT]; // ID de instancia
};

DESCRIPCIÓN

El tipo RTCHit define el tipo de resultado de una intersección rayo/primitiva. El impacto contiene la normal geométrica no normalizada en el espacio del objeto en la ubicación del impacto (miembros Ng_x, Ng_y, Ng_z), las coordenadas baricéntricas u/v del impacto (miembros u y v), así como el ID de primitiva (miembro primID), el ID de geometría (miembro geomID) y la pila de IDs de instancia (miembro instID) del impacto. La distancia paramétrica de intersección no se almacena dentro del impacto, sino que se almacena dentro del miembro tfar del rayo.

El encabezado embree3/rtcore_ray.h define adicionalmente la misma estructura de impacto en un diseño de estructura de arreglos (SOA) para paquetes de impacto de tamaño 4 (tipo RTCHit4), tamaño 8 (tipo RTCHit8) y tamaño 16 (tipo RTCHit16). El encabezado define además una plantilla RTCHitNt para paquetes de impacto de un tamaño arbitrario definido en tiempo de compilación.
