RTCRayHit(3) Embree Ray Tracing Kernels 3 RTCRayHit(3)

NOMBRE

RTCRayHit - estructura combinada de rayo/impacto único

SINOPSIS

#include <embree3/rtcore_ray.h>
struct RTCORE_ALIGN(16) RTCRayHit
{
  struct RTCRay ray;
  struct RTCHit hit;
};

DESCRIPCIÓN

La estructura RTCRayHit se utiliza como entrada para las funciones de tipo rtcIntersect y almacena el rayo a intersectar y algunos campos de impacto que contendrán el resultado de la intersección posteriormente.

El encabezado embree3/rtcore_ray.h define además la misma estructura de rayo/impacto en un diseño de estructura de arreglos (SOA) para funciones de API que aceptan paquetes de rayos de tamaño 4 (tipo RTCRayHit4), tamaño 8 (tipo RTCRayHit8) y tamaño 16 (tipo RTCRayHit16). El encabezado define además una plantilla RTCRayHitNt para generar paquetes de rayos/impactos de un tamaño arbitrario en tiempo de compilación.
