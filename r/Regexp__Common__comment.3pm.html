NOMBRE

Regexp::Common::comment -- proporciona expresiones regulares para comentarios.

SINOPSIS

use Regexp::Common qw /comment/;
while (<>) {
    /$RE{comment}{C}/       and  print "Contiene un comentario C\n";
    /$RE{comment}{C++}/     and  print "Contiene un comentario C++\n";
    /$RE{comment}{PHP}/     and  print "Contiene un comentario PHP\n";
    /$RE{comment}{Java}/    and  print "Contiene un comentario Java\n";
    /$RE{comment}{Perl}/    and  print "Contiene un comentario Perl\n";
    /$RE{comment}{awk}/     and  print "Contiene un comentario awk\n";
    /$RE{comment}{HTML}/    and  print "Contiene un comentario HTML\n";
}
use Regexp::Common qw /comment RE_comment_HTML/;
while (<>) {
    $_ =~ RE_comment_HTML() and  print "Contiene un comentario HTML\n";
}

DESCRIPCIÓN

Por favor, consulte el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No utilice este módulo directamente, sino cárguelo a través de Regexp::Common.

Este módulo le proporciona expresiones regulares para comentarios en varios lenguajes.

Algunos idiomas tienen variantes; se describe en los idiomas individuales cómo obtener los patrones para las variantes. A menos que se indique lo contrario, "{-keep}" establece $1, $2, $3 y $4 al comentario completo, al marcador de apertura, al contenido del comentario y al marcador de cierre (para muchos idiomas, este último es una nueva línea) respectivamente.

HTML
En HTML, los comentarios solo aparecen dentro de una declaración de comentario. Una declaración de comentario comienza con un "<!" y termina con un ">". Dentro de esta declaración, tenemos cero o más comentarios. Los comentarios comienzan con "--" y terminan con "--", y opcionalmente están seguidos por espacios en blanco. El patrón "$RE{comment}{HTML}" reconoce esas declaraciones de comentario (y por lo tanto, más que un comentario). Tenga en cuenta que esto no es lo mismo que algo que comienza con "<!--" y termina con "-->", porque lo siguiente coincidirá completamente: 
<!--  Primer  Comentario   --
  --> Segundo Comentario <!--
  --  Tercer  Comentario   -->

No se deje engañar por lo que su navegador favorito considera un comentario HTML.

Si se usa "{-keep}", se devolverán los siguientes elementos:

$1
captura toda la declaración de comentario.
$2
captura el MDO (apertura de declaración de marcado), "<!".
$3
captura el contenido entre el MDO y el MDC.
$4
captura el (último) comentario, sin los guiones que lo rodean.
$5
captura el MDC (cierre de declaración de marcado), ">".

DESCRIPTION

\n

This module provides regular expressions for matching comments in a\nvariety of programming languages.

\n
\n
Ada
\n
Ada comments start with -- and continue\ntill the end of the line.
\n
AWK
\n
AWK comments start with # and continue\ntill the end of the line.
\n
C
\n
C comments start with /* and end with\n*/. They can span multiple lines.
\n
C++
\n
C++ comments start with // and continue\ntill the end of the line.
\n
C#
\n
C# comments start with // and continue\ntill the end of the line. Multi-line comments are possible using the /* ... */ syntax.
\n
Caml
\n
Caml comments start with (* and end\nwith *). They can span multiple lines and nest.
\n
CLISP
\n
CLISP comments start with a semicolon, ;,\nand continue till the end of the line.
\n
Common Lisp
\n
Common Lisp comments start with a semicolon, ;,\nand continue till the end of the line.
\n
Erlang
\n
Erlang comments start with the percent sign, %,\nand continue till the end of the line.
\n
Ezhuzha
\n
Comments in Ezhuzha start with "*" and end with\n*".
\n
Fortran
\n
Fortran comments start with ! or C or\n* in the first column and continue till the end of the\nline.
\n
Go
\n
Go comments come in two forms. Line comments start with //\nand end at the end of the line. Block comments start with /*\nand end with */.
\n
HTML
\n
HTML comments start with <!-- and end with\n-->. They can span multiple lines.
\n
Java
\n
Java comments start with // and continue till\nthe end of the line. Multi-line comments are possible using the /* ... */ syntax.
\n
JavaScript
\n
JavaScript comments start with // and continue\ntill the end of the line. Multi-line comments are possible using the /* ... */ syntax.
\n
Lisp
\n
Comments in Lisp start with a semicolon, ;,\nand continue till the end of the line.
\n
Lua
\n
Lua comments start with -- and continue till\nthe end of the line. Multi-line comments are possible using the --[[ ... ]] syntax.
\n
MATLAB
\n
MATLAB comments start with the percent sign, %,\nand continue till the end of the line.
\n
MetaPost
\n
MetaPost comments start with % and continue till\nthe end of the line.
\n
Objective-C
\n
Objective-C comments start with // and continue\ntill the end of the line. Multi-line comments are possible using the /* ... */ syntax.
\n
Pascal
\n
Pascal comments start with (* and end with\n*). They can span multiple lines.
\n
PHP
\n
PHP comments start with // and continue till\nthe end of the line. Multi-line comments are possible using the /* ... */ syntax.
\n
PL/SQL
\n
In PL/SQL, comments either start with\n-- and run till the end of the line,\nor start with /* and end with\n*/.
\n
Perl
\n
Perl uses comments that start with a\n#, and continue till the end of the\nline.
\n
Portia
\n
The Portia programming language has comments that start with\n//, and last till the end of the\nline.
\n
Python
\n
Python uses comments that start with a\n#, and continue till the end of the\nline.
\n
Q-BAL
\n
Comments in the Q-BAL language start with\n` (a backtick), and contine till the\nend of the line.
\n
QML
\n
In \"QML\", comments start with\n# and last till the end of the line.\nSee http://www.questionmark.com/uk/qml/overview.doc.
\n
R
\n
The statistical language R uses comments that start with a\n# and end with the following new line.\nSee http://www.r-project.org/.
\n
REBOL
\n
Comments for the REBOL language start with\n; and last till the end of the\nline.
\n
Ruby
\n
Comments in Ruby start with #\nand last till the end of the time.
\n
Scheme
\n
Scheme comments start with ;,\nand last till the end of the line. See http://schemers.org/.
\n
shell
\n
Comments in various shells start with a\n# and end at the end of the line.
\n
Shelta
\n
The esotoric language Shelta uses comments that start and end with\na ;. See\nhttp://www.catseye.mb.ca/esoteric/shelta/index.html.
\n
SLIDE
\n
The SLIDE language has two froms of comments. First there is the\nline comment, which starts with a #\nand includes the rest of the line (just like Perl). Second, there is the\nmultiline, nested comment, which are delimited by\n(* and\n*)". Under C{-keep}>, only\n$1 is set, and is set to the entire comment. See\nhttp://www.cs.freedom.nlrkeley.edu/~ug/slide/docs/slide/spec/spec_frame_intro.shtml.
\n
slrn
\n
Configuration files for slrn have comments starting with a\n% and lasting the rest of the\nline.
\n
Smalltalk
\n
Smalltalk uses comments that start and end with a double quote,\n\"\".
\n
SMITH
\n
Comments in the SMITH language start with\n;, and last till the end of the\nline.
\n
Squeak
\n
In the Smalltalk variant Squeak, comments start and end with\n\"\". Double quotes can appear\ninside comments by doubling them.
\n
SQL
\n
Standard SQL uses comments starting with two or more dashes, and\nending at the end of the line.\n

MySQL does not follow the standard. Instead, it allows\ncomments that start with a # or\n-- (that's two dashes and a space)\nending with the following newline, and comments starting with\n/*, and ending with the next\n*/ or\n; that isn't inside single or\ndouble quotes. A pattern for this is returned by\n$RE{comment}{SQL}{MySQL}". With\n"{-keep}", only\n$1 will be set, and it returns the entire\ncomment.

\n
\n
Tcl
\n
In Tcl, comments start with #\nand continue till the end of the line.
\n
TeX
\n
The documentation language TeX uses comments starting with\n% and ending at the end of the\nline.
\n
troff
\n
The document formatting language troff uses comments starting with\n\\", and continuing till the end\nof the line.
\n
Ubercode
\n
The Windows programming language Ubercode uses comments that start\nwith // and continue to the end of the\nline. See http://www.ubercode.com.
\n
vi
\n
In configuration files for the editor vi, one can use comments\nstarting with \"\", and ending at\nthe end of the line.
\n
*W
\n
In the language *W, comments start with\n||, and end with\n!!.
\n
zonefile
\n
Comments in DNS zonefiles start with\n;, and continue till the end of the\nline.
\n
ZZT-OOP
\n
The in-game language ZZT-OOP uses comments that start with a\n' character, and end at the following\nnewline. See\nhttp://dave2.rocketjump.org/rad/zzthelp/lang.html.
