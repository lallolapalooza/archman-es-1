NOMBRE

Regexp::Common::URI::http -- Devuelve un patrón para URIs HTTP.

SINOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{HTTP}/       and  print "Contiene una URI HTTP.\n";
}

DESCRIPCIÓN

$RE{URI}{HTTP}{-scheme}

Proporciona una expresión regular para una URI HTTP según se define en RFC 2396 (sintaxis genérica) y RFC 2616 (HTTP).

Si se especifica "-scheme => P", el patrón P se utiliza como esquema. Por defecto, P es "qr/http/". "https" y "https?" son alternativas razonables.

La sintaxis para una URI HTTP es:

"http:" "//" host [ ":" port ] [ "/" path [ "?" query ]]

Bajo "{-keep}", se devuelven los siguientes:

$1
La URI completa.
$2
El esquema.
$3
El host (nombre o dirección).
$4
El puerto (si existe).
$5
La ruta absoluta, incluyendo la consulta y la barra inicial.
$6
La ruta absoluta, incluyendo la consulta, sin la barra inicial.
$7
La ruta absoluta, sin la consulta ni la barra inicial.
$8
La consulta, sin el signo de interrogación.

REFERENCIAS

[RFC 2396]
Berners-Lee, Tim, Fielding, R., y Masinter, L.: Uniform Resource Identifiers (URI): Generic Syntax. Agosto de 1998.
[RFC 2616]
Fielding, R., Gettys, J., Mogul, J., Frystyk, H., Masinter, L., Leach, P. y Berners-Lee, Tim: Hypertext Transfer Protocol -- HTTP/1.1. Junio de 1999.

VER TAMBIÉN
