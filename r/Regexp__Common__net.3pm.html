NOMBRE

Regexp::Common::net -- proporciona expresiones regulares para direcciones IPv4, IPv6 y MAC.

SINOPSIS

use Regexp::Common qw /net/;
while (<>) {
    /$RE{net}{IPv4}/       and print "Dirección IP en decimal con puntos\n";
    /$RE{net}{IPv4}{hex}/  and print "Dirección IP hexadecimal con puntos\n";
    /$RE{net}{IPv4}{oct}{-sep => ':'}/ and
                           print "Dirección IP octal separada por dos puntos\n";
    /$RE{net}{IPv4}{bin}/  and print "Dirección IP binaria con puntos\n";
    /$RE{net}{MAC}/        and print "Dirección MAC\n";
    /$RE{net}{MAC}{oct}{-sep => " "}/ and
                           print "Dirección MAC octal separada por espacios\n";
}

DESCRIPCIÓN

Por favor, consulta el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No utilices este módulo directamente, sino cárgalo a través de Regexp::Common.

Este módulo te proporciona expresiones regulares para varios estilos de direcciones IPv4, IPv6 y MAC (o ethernet).

"$RE{net}{IPv4}"

Devuelve un patrón que coincide con una dirección IP válida en formato "decimal con puntos". Ten en cuenta que aunque 318.99.183.11 no es una dirección IP válida, sí coincide con "/$RE{net}{IPv4}/", pero esto se debe a que 318.99.183.11 contiene una dirección IP válida, a saber, 18.99.183.11. Para evitar coincidencias no deseadas, es necesario anclar la expresión regular: "/^$RE{net}{IPv4}$/".

Para este patrón y los cuatro siguientes, con "-keep" (ver Regexp::Common):

$1
captura la coincidencia completa
$2
captura el primer componente de la dirección
$3
captura el segundo componente de la dirección
$4
captura el tercer componente de la dirección
$5
captura el componente final de la dirección

"$RE{net}{IPv4}{dec}{-sep}"

Devuelve un patrón que coincide con una dirección IP válida en formato "decimal con puntos". Se permiten ceros iniciales, siempre que cada componente no exceda los 3 dígitos.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/[.]/".

"$RE{net}{IPv4}{strict}{-sep}"

Devuelve un patrón que coincide con una dirección IP válida en formato "decimal con puntos", pero prohíbe cualquier cero inicial.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/[.]/".

"$RE{net}{IPv4}{hex}{-sep}"

Devuelve un patrón que coincide con una dirección IP válida en formato "hexadecimal con puntos", con las letras "A" a "F" en mayúsculas.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/[.]/". "-sep=""" y "-sep=" "" son alternativas útiles.

"$RE{net}{IPv4}{oct}{-sep}"

Devuelve un patrón que coincide con una dirección IP válida en formato "octal con puntos"

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/[.]/".

"$RE{net}{IPv4}{bin}{-sep}"

Devuelve un patrón que coincide con una dirección IP válida en formato "binario con puntos"

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/[.]/".

"$RE{net}{MAC}"

Devuelve un patrón que coincide con una dirección MAC o ethernet válida como hexadecimales separados por dos puntos.

Para este patrón y los cuatro siguientes, con "-keep" (ver Regexp::Common):

$1
captura la coincidencia completa
$2
captura el primer componente de la dirección
$3
captura el segundo componente de la dirección
$4
captura el tercer componente de la dirección
$5
captura el cuarto componente de la dirección
$6
captura el quinto componente de la dirección
$7
captura el sexto y último componente de la dirección

Este patrón, y los cuatro siguientes, tienen un método "subs", que transformará una dirección MAC coincidente a formato canónico. El formato canónico significa que cada componente de la dirección tendrá exactamente dos dígitos hexadecimales (con un cero inicial si es necesario), y los componentes estarán separados por dos puntos.

"$RE{net}{MAC}{dec}{-sep}"

Devuelve un patrón que coincide con una dirección MAC válida como decimales separados por dos puntos.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/:/".

"$RE{net}{MAC}{hex}{-sep}"

Devuelve un patrón que coincide con una dirección MAC válida como hexadecimales separados por dos puntos, con las letras "a" a "f" en minúsculas.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/:/".

"$RE{net}{MAC}{oct}{-sep}"

Devuelve un patrón que coincide con una dirección MAC válida como octales separados por dos puntos.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/:/".

"$RE{net}{MAC}{bin}{-sep}"

Devuelve un patrón que coincide con una dirección MAC válida como binarios separados por dos puntos.

Si se especifica "-sep=P", se utiliza el patrón P como separador. Por defecto, P es "qr/:/".

"$RE{net}{IPv4}"

Returns a pattern matching IPv4 addresses. The pattern matches numbers in the form xxx.xxx.xxx.xxx where each xxx is a decimal number between 0 and 255.

If {-keep} is used, then $1 is set to the matched address, and $2 to $5 are set to the four octets of the address.

Example:

    if ($string =~ /$RE{net}{IPv4}{-keep}/) {
        print "The IP address is $1.\n";
        print "The octets are $2, $3, $4, and $5.\n";
    }

"$RE{net}{IPv6}"

Returns a pattern matching IPv6 numbers. An IPv6 address consists of eight groups of four hexadecimal digits, separated by colons. In each group, leading zeros may be omitted. Two or more consecutive groups consisting of only zeros may be omitted (including any colons separating them), resulting into two sets of groups, separated by a double colon. (Each of the groups may be empty; "::" is a valid address, equal to "0000:0000:0000:0000:0000:0000:0000:0000"). The hex numbers may be in either case.

If the "-sep" option is used, its argument is a pattern that matches the separator that separates groups. This defaults to ":". The "-style" option is used to denote which case the hex numbers may be. The default style, 'HeX' indicates both lower case letters 'a' to 'f' and upper case letters 'A' to 'F' will be matched. The style 'HEX' restricts matching to upper case letters, and 'hex' only matches lower case letters.

If "{-keep}" is used, $1 to $9 will be set. $1 will be set to the matched address, while $2 to $9 will be set to each matched group. If a group is omitted because it contains all zeros, its matching variable will be the empty string.

Example:

"2001:db8:85a3::8a2e:370:7334" =~ /$RE{net}{IPv6}{-keep}/;
print $2;    # '2001'
print $4;    # '85a3'
print $6;    # Empty string
print $8;    # '370'

Perl 5.10 (or later) is required for this pattern.

"$RE{net}{domain}"

Returns a pattern to match domains (and hosts) as defined in RFC 1035. Under I{-keep} only the entire domain name is returned.

RFC 1035 says that a single space can be a domainname too. So, the pattern returned by "$RE{net}{domain}" recognizes a single space as well. This is not always what people want. If you want to recognize domainnames, but not a space, you can do one of two things, either use

/(?! )$RE{net}{domain}/

or use the "{-nospace}" option (without an argument).

RFC 1035 does not allow host or domain names to start with a digits; however, this restriction is relaxed in RFC 1101; this RFC allows host and domain names to start with a digit, as long as the first part of a domain does not look like an IP address. If the "{-rfc1101}" option is given (as in "$RE {net} {domain} {-rfc1101}"), we will match using the relaxed rules.

REFERENCES

RFC 1035
Mockapetris, P.: DOMAIN NAMES - IMPLEMENTATION AND SPECIFICATION. November 1987.
RFC 1101
Mockapetris, P.: DNS Encoding of Network Names and Other Types. April 1987.
