RTCCurveFlags(3) Núcleos de Ray Tracing de Embree 4 RTCCurveFlags(3)

NOMBRE

RTCCurveFlags - flags por segmento para geometría de curva

SINOPSIS

#include <embree4/rtcore.h>
enum RTCCurveFlags
{
  RTC_CURVE_FLAG_NEIGHBOR_LEFT  = (1 << 0), 
  RTC_CURVE_FLAG_NEIGHBOR_RIGHT = (1 << 1) 
};

DESCRIPCIÓN

El tipo RTCCurveFlags se utiliza para curvas lineales para determinar si el segmento vecino izquierdo y/o derecho existen. Por lo tanto, se adjunta un búfer de tipo RTC_BUFFER_TYPE_FLAGS a la geometría de la curva, el cual almacena un byte individual por segmento de curva.

Si el flag RTC_CURVE_FLAG_NEIGHBOR_LEFT en ese byte está habilitado para un segmento de curva, entonces el segmento izquierdo existe (el cual comienza un vértice antes del vértice de inicio de la curva actual) y el segmento actual se renderiza para unirse correctamente a ese segmento.

Si el flag RTC_CURVE_FLAG_NEIGHBOR_RIGHT en ese byte está habilitado para un segmento de curva, entonces el segmento derecho existe (el cual termina un vértice después del vértice final de la curva actual) y el segmento actual se renderiza para unirse correctamente a ese segmento.

Cuando no se especifican correctamente los flags izquierdo y derecho para curvas lineales, la renderización al final de estas curvas puede no verse correcta, en particular cuando las curvas lineales redondeadas se ven desde el interior.
