RTC_GEOMETRY_TYPE_QUAD(3) Núcleos de trazado de rayos Embree 4 RTC_GEOMETRY_TYPE_QUAD(3)

NOMBRE

RTC_GEOMETRY_TYPE_QUAD - tipo de geometría de cuadrilátero

SINOPSIS

#include <embree4/rtcore.h>
RTCGeometry geometry =
  rtcNewGeometry(device, RTC_GEOMETRY_TYPE_QUAD);

DESCRIPCIÓN

Las mallas de cuadriláteros se crean pasando RTC_GEOMETRY_TYPE_QUAD a la llamada de función rtcNewGeometry. Los índices del cuadrilátero se pueden especificar estableciendo un búfer de índices (tipo RTC_BUFFER_TYPE_INDEX) y los vértices del cuadrilátero estableciendo un búfer de vértices (tipo RTC_BUFFER_TYPE_VERTEX). Ver rtcSetGeometryBuffer y rtcSetSharedGeometryBuffer para más detalles sobre cómo establecer búferes. El búfer de índices contiene un array de cuatro índices de 32 bits por cuadrilátero (formato RTC_FORMAT_UINT4), y el número de primitivas se infiere del tamaño de ese búfer. El búfer de vértices contiene un array de coordenadas de punto flotante de precisión simple x, y, z (formato RTC_FORMAT_FLOAT3), y el número de vértices se infiere del tamaño de ese búfer. El búfer de vértices puede tener un tamaño máximo de 16 GB.

Un cuadrilátero se maneja internamente como un par de dos triángulos v0,v1,v3 y v2,v3,v1, con las coordenadas u'/v' del segundo triángulo corregidas por u = 1-u' y v = 1-v' para producir una parametrización de cuadrilátero donde u y v están en el rango de 0 a 1. Por lo tanto, la parametrización de un cuadrilátero utiliza el primer vértice p0 como punto base, y el vector p1 - p0 como dirección u, y p3 - p0 como dirección v. Así, los atributos de vértice t0,t1,t2,t3 pueden interpolarse bilinealmente sobre el cuadrilátero de la siguiente manera:

t_uv = (1-v)((1-u)*t0 + u*t1) + v*((1-u)*t3 + u*t2)

Se admiten mallas mixtas de triángulos/cuadriláteros codificando un triángulo como un cuadrilátero, lo que se puede lograr replicando el último vértice del triángulo (v0,v1,v2 -> v0,v1,v2,v2). De esta manera, el segundo triángulo es una línea (que nunca puede ser alcanzada), y la parametrización del primer triángulo es compatible con la parametrización estándar de triángulos.

Un cuadrilátero cuyos vértices están dispuestos en sentido antihorario tiene su normal geométrica apuntando hacia arriba, fuera de la cara frontal, como se ilustra en la siguiente imagen.

Para desenfoque de movimiento multisegmento, el número de pasos de tiempo debe especificarse primero usando la llamada rtcSetGeometryTimeStepCount. Luego, se puede establecer un búfer de vértices para cada paso de tiempo usando diferentes ranuras de búfer, y todos estos búferes deben tener el mismo stride y tamaño.

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN
