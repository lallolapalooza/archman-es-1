Razor2::Syslog(3) Documentación Perl contribuida por el usuario Razor2::Syslog(3)

NOMBRE

Razor2::Syslog -- Soporte de Syslog para Razor2

SINOPSIS

use Razor2::Syslog;
my $s=new Razor2::Syslog(Facility=>'local4',Priority=>'debug');
$s->send('ver esto en syslog',Priority=>'info');

DESCRIPCIÓN

Este módulo ha sido derivado de Net::Syslog. Se hicieron algunas optimizaciones en Net::Syslog, en particular el soporte para mantener un socket abierto. Lo que sigue es la documentación para Net::Syslog, que se aplica completamente a este módulo.

Net::Syslog implementa el protocolo de reenvío de syslog dentro del host. No pretende reemplazar los módulos Sys::Syslog o Unix::Syslog, sino proporcionar un método para usar syslog cuando un syslogd local no está disponible o cuando no se desea escribir mensajes de syslog en el syslog local.

La llamada new establece valores predeterminados, cualquiera de los cuales puede ser anulado en la llamada send. Las claves (listadas con valores predeterminados) son:

Name            <nombre del script de llamada>
Facility        local5
Priority        err
SyslogPort      514
SyslogHost      127.0.0.1

Las Facilities válidas son: kern, user, mail, daemon, auth, syslog, lpr, news, uucp, cron, authpriv, ftp, local0, local1, local2, local3, local4, local5, local6

Las Priorities válidas son: emerg, alert, crit, err, warning, notice, info, debug
