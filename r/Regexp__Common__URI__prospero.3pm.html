NOMBRE

Regexp::Common::URI::prospero -- Devuelve un patrón para URIs de prospero.

SINOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{prospero}/ and print "Contiene una URI de prospero.\n";
}

DESCRIPCIÓN

$RE{URI}{prospero}

Devuelve un patrón que coincide con URIs de prospero, tal como se definen en RFC 1738. Las URIs de prospero tienen la forma:

"prospero:" "//" host [ ":" port ] "/" path [ fieldspec ] *

Bajo "{-keep}", se devuelven los siguientes:

$1
La URI completa.
$2
El esquema.
$3
El nombre de host.
$4
El puerto, si se proporciona.
$5
La ruta de prospero.
$6
Las especificaciones de campo, si se proporcionan. Puede haber más especificaciones de campo; todas se devolverán en $6.

REFERENCIAS

[RFC 1738]
Berners-Lee, Tim, Masinter, L., McCahill, M.: Uniform Resource Locators (URL). Diciembre de 1994.

VER TAMBIÉN

Regexp::Common::URI para otras URIs admitidas.
