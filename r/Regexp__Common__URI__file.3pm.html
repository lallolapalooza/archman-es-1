Regexp::Common::URI::file(3) Documentación de Perl aportada por el usuario Regexp::Common::URI::file(3)

NOMBRE

Regexp::Common::URI::file -- Devuelve un patrón para URIs de archivo.

SINAPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{file}/       and  print "Contiene una URI de archivo.\n";
}

DESCRIPCIÓN

$RE{URI}{file}

Devuelve un patrón que coincide con URIs de tipo file, según se define en RFC 1738. Las URIs de archivo tienen el formato:

"file:" "//" [ host | "localhost" ] "/" fpath

Bajo "{-keep}", se devuelven los siguientes elementos:

$1
La URI completa.
$2
El esquema.
$3
La parte de la URI que sigue a "file://".
$4
El nombre de host.
$5
El nombre de la ruta, incluida la barra inclinada inicial.
$6
El nombre de la ruta, sin la barra inclinada inicial.

REFERENCIAS

[RFC 1738]
Berners-Lee, Tim, Masinter, L., McCahill, M.: Uniform Resource Locators (URL). Diciembre 1994.

VER TAMBIÉN

Regexp::Common::URI para otras URIs soportadas.
