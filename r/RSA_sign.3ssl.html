RSA_sign(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_SIGN(3ssl) OpenSSL RSA_SIGN(3ssl)

NOMBRE

RSA_sign, RSA_verify - Firmas RSA

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7).

int RSA_sign(int type, const unsigned char *m, unsigned int m_len,
             unsigned char *sigret, unsigned int *siglen, RSA *rsa);
int RSA_verify(int type, const unsigned char *m, unsigned int m_len,
               unsigned char *sigbuf, unsigned int siglen, RSA *rsa);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_PKEY_sign_init(3), EVP_PKEY_sign(3), EVP_PKEY_verify_init(3) y EVP_PKEY_verify(3).

RSA_sign() firma el resumen del mensaje m de tamaño m_len usando la clave privada rsa utilizando RSASSA-PKCS1-v1_5 tal como se especifica en RFC 3447. Almacena la firma en sigret y el tamaño de la firma en siglen. sigret debe apuntar a RSA_size(rsa) bytes de memoria. Tenga en cuenta que PKCS #1 añade metadatos, lo que limita el tamaño de la clave que se puede utilizar. Ver RSA_private_encrypt(3) para operaciones de nivel inferior.

type denota el algoritmo de resumen de mensaje que se utilizó para generar m. Si type es NID_md5_sha1, se crea una firma SSL (resúmenes de mensaje MD5 y SHA1 con relleno PKCS #1 y sin identificador de algoritmo).

RSA_verify() verifica que la firma sigbuf de tamaño siglen coincide con un resumen de mensaje dado m de tamaño m_len. type denota el algoritmo de resumen de mensaje que se utilizó para generar la firma. rsa es la clave pública del firmante.

VALORES DE RETORNO

RSA_sign() devuelve 1 en caso de éxito y 0 en caso de fallo. RSA_verify() devuelve 1 en caso de verificación exitosa y 0 en caso de fallo.

Los códigos de error se pueden obtener mediante ERR_get_error(3).

CONFORME A

SSL, PKCS #1 v2.0

VER TAMBIÉN

ERR_get_error(3), RSA_private_encrypt(3), RSA_public_decrypt(3)

HISTORIA

Todas estas funciones fueron marcadas como obsoletas en OpenSSL 3.0.
