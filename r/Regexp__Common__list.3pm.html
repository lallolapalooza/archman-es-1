NOMBRE

Regexp::Common::list -- proporciona expresiones regulares para listas

SINOPSIS

use Regexp::Common qw /list/;
while (<>) {
    /$RE{list}{-pat => '\w+'}/          and print "Lista de palabras";
    /$RE{list}{-pat =>$RE{num}{real}}/ and print "Lista de números";
}

DESCRIPCIÓN

Por favor, consulta el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No uses este módulo directamente, sino cárgalo a través de Regexp::Common.

"$RE{list}{-pat}{-sep}{-lastsep}"

Devuelve un patrón que coincide con una lista de (al menos dos) subcadenas.

Si se especifica "-pat=P", define el patrón para cada subcadena de la lista. Por defecto, P es "qr/.*?\S/". En Regexp::Common 0.02 o anterior, el patrón por defecto era "qr/.*?/". Pero eso coincidiría con un solo espacio, causando un análisis no deseado de "a, b, and c" como una lista de cuatro elementos en lugar de 3 (con "-word" siendo "(?:and)"). Una consecuencia es que una lista de la forma "a,,b" ya no se analizará. Usa el patrón "qr /.*?/" para poder analizar esto, pero lee la observación anterior.

Si se especifica "-sep=P", define el patrón P que se utilizará como separador entre cada par de subcadenas de la lista, excepto los dos últimos. Por defecto, P es "qr/\s*,\s*/".

Si se especifica "-lastsep=P", define el patrón P que se utilizará como separador entre las dos últimas subcadenas de la lista. Por defecto, P es el mismo que el patrón especificado por el indicador "-sep".

Por ejemplo:

$RE{list}{-pat=>'\w+'}                # coincide con una lista de caracteres de palabra
$RE{list}{-pat=>$RE{num}{real}}       # coincide con una lista de números
$RE{list}{-sep=>"\t"}                 # coincide con una lista separada por tabulaciones
$RE{list}{-lastsep=>',\s+and\s+'}     # coincide con una lista en inglés adecuada

Bajo "-keep":

$1
captura la lista completa
$2
captura el último separador

"$RE{list}{conj}{-word=PATTERN}"

Un alias para "$RE{list}{-lastsep=>'\s*,?\s*PATTERN\s*'}"

Si "-word" no está especificado, el patrón por defecto es "qr/and|or/".

Por ejemplo:

$RE{list}{conj}{-word=>'et'}        # coincide con Jean, Paul, et Satre
$RE{list}{conj}{-word=>'oder'}      # coincide con Bonn, Koln oder Hamburg

"$RE{list}{and}"

Un alias para "$RE{list}{conj}{-word=>'and'}"

"$RE{list}{or}"

Un alias para "$RE{list}{conj}{-word=>'or'}"
