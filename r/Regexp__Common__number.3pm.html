NOMBRE

Regexp::Common::number -- proporciona expresiones regulares para números

SINOPSIS

use Regexp::Common qw /number/;
while (<>) {
    /^$RE{num}{int}$/                and  print "Entero\n";
    /^$RE{num}{real}$/               and  print "Real\n";
    /^$RE{num}{real}{-base => 16}$/  and  print "Real hexadecimal\n";
}

DESCRIPCIÓN

Por favor, consulta el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No uses este módulo directamente, sino cárgalo a través de Regexp::Common.

"$RE{num}{int}{-base}{-sep}{-group}{-places}{-sign}"

Devuelve un patrón que coincide con un número entero.

Si se especifica "-base => B", el entero está en base B, con "2 <= B <= 36". Para bases mayores que 10, se utilizan letras mayúsculas. La base por defecto es 10.

Si se especifica "-sep => P", el patrón P se requiere como marcador de agrupación dentro del número. Si esta opción no se proporciona, no se utiliza ningún marcador de agrupación.

Si se especifica "-group => N", los dígitos entre los marcadores de agrupación deben agruparse en secuencias de exactamente N dígitos. El valor por defecto de N es 3. Si se especifica "-group => N,M", los dígitos entre los marcadores de agrupación deben agruparse en secuencias de al menos N dígitos, y como máximo M dígitos. Esta opción se ignora a menos que se utilice la opción "-sep".

Si se especifica "-places => N", el entero reconocido debe tener exactamente N dígitos. Si se especifica "-places => N,M", el entero debe tener al menos N dígitos y como máximo M dígitos. No hay valor por defecto, lo que significa que los enteros tienen un tamaño ilimitado. Esta opción se ignora si se utiliza la opción "-sep".

Si se utiliza "-sign => P", es un patrón que el signo inicial debe coincidir. Esto por defecto es "[-+]?", lo que significa que el número puede ir precedido opcionalmente por un signo menos o más. Si quieres coincidir con enteros sin signo, usa "$RE{num}{int}{-sign => ''}".

Por ejemplo:

$RE{num}{int}                          # coincide con 1234567
$RE{num}{int}{-sep=>','}               # coincide con 1,234,567
$RE{num}{int}{-sep=>',?'}              # coincide con 1234567 o 1,234,567
$RE{num}{int}{-sep=>'.'}{-group=>4}    # coincide con 1.2345.6789

Bajo "-keep" (ver Regexp::Common):

$1
captura el número completo
$2
captura el signo opcional del número
$3
captura el conjunto completo de dígitos

"$RE{num}{real}{-base}{-radix}{-places}{-sep}{-group}{-expon}"

Devuelve un patrón que coincide con un número de punto flotante.

Si se especifica "-base=N", se asume que el número está en esa base (con A..Z representando los dígitos para 11..36). Por defecto, la base es 10.

Si se especifica "-radix=P", el patrón P se utiliza como punto radix para el número (es decir, el "punto decimal" en base 10). El valor por defecto es "qr/[.]/".

Si se especifica "-places=N", se asume que el número tiene exactamente N lugares después del punto radix. Si se especifica "-places=M,N", se asume que el número tiene entre M y N lugares después del punto radix. Por defecto, el número de lugares no está restringido.

Si se especifica "-sep=P", se requiere el patrón P como marcador de agrupación dentro de la sección pre-radix del número. Por defecto, no se permiten separadores.

Si se especifica "-group=N", los dígitos entre los separadores de agrupación deben agruparse en secuencias de exactamente N caracteres. El valor por defecto de N es 3.

Si se especifica "-expon=P", el patrón P se utiliza como marcador exponencial. El valor por defecto de P es "qr/[Ee]/".

Si se especifica "-sign=P", el patrón P se utiliza para coincidir con el signo inicial (y el signo del exponente). Por defecto es "[-+]?", lo que significa que se puede usar un signo más o menos opcional.

Por ejemplo:

$RE{num}{real}                  # coincide con 123.456 o -0.1234567
$RE{num}{real}{-places=>2}      # coincide con 123.45 o -0.12
$RE{num}{real}{-places=>'0,3'}  # coincide con 123.456 o 0 o 9.8
$RE{num}{real}{-sep=>'[,.]?'}   # coincide con 123,456 o 123.456
$RE{num}{real}{-base=>3'}       # coincide con 121.102

Bajo "-keep":

$1
captura la coincidencia completa
$2
captura el signo opcional del número
$3
captura la mantisa completa
$4
captura la parte entera de la mantisa
$5
captura el punto radix
$6
captura la parte fraccionaria de la mantisa
$7
captura el marcador de exponente opcional
$8
captura el valor completo del exponente
$9
captura el signo opcional del exponente
$10
captura los dígitos del exponente

NAME

Regexp::Common::number - A module for matching numbers.

SYNOPSIS

$RE{num}{decimal}              # matches 123.456 or -0.1234567
$RE{num}{decimal}{-places=>2}      # matches 123.45 or -0.12
$RE{num}{decimal}{-places=>'0,3'}  # matches 123.456 or 0 or 9.8
$RE{num}{decimal}{-sep=>'[,.]?'}   # matches 123,456 or 123.456
$RE{num}{decimal}{-base=>3'}       # matches 121.102
$RE{num}{square}                # matches 4 or 9 or 16 etc.
$RE{num}{roman}                 # matches I, II, III, IV, V, VI, VII, VIII, IX, X etc.

DESCRIPTION

This module provides regular expressions for matching various kinds of numbers.

"$RE{num}{decimal}"

The same as "$RE{num}{real}", except that an exponent isn't allowed. Hence, this returns a pattern matching decimal numbers.

If "-base=N" is specified, the number is assumed to be in that base (with A..Z representing the digits for 11..36). By default, the base is 10.

If "-radix=P" is specified, the pattern P is used as the radix point for the number (i.e. the "decimal point" in base 10). The default is "qr/[.]/".

If "-places=N" is specified, the number is assumed to have exactly N places after the radix point. If "-places=M,N" is specified, the number is assumed to have between M and N places after the radix point. By default, the number of places is unrestricted.

If "-sep=P" specified, the pattern P is required as a grouping marker within the pre-radix section of the number. By default, no separator is allowed.

If "-group=N" is specified, digits between grouping separators must be grouped in sequences of exactly N characters. The default value of N is 3.

For example:

$RE{num}{decimal}                  # matches 123.456 or -0.1234567
$RE{num}{decimal}{-places=>2}      # matches 123.45 or -0.12
$RE{num}{decimal}{-places=>'0,3'}  # matches 123.456 or 0 or 9.8
$RE{num}{decimal}{-sep=>'[,.]?'}   # matches 123,456 or 123.456
$RE{num}{decimal}{-base=>3'}       # matches 121.102

Under "-keep":

$1
captures the entire match
$2
captures the optional sign of the number
$3
captures the complete mantissa
$4
captures the whole number portion of the mantissa
$5
captures the radix point
$6
captures the fractional portion of the mantissa

"$RE{num}{square}"

Returns a pattern that matches a (decimal) square. Because Perl's arithmetic is lossy when using integers over about 53 bits, this pattern only recognizes numbers less than 9000000000000000, if one uses a Perl that is configured to use 64 bit integers. Otherwise, the limit is 2147483647. These restrictions were introduced in versions 2.116 and 2.117 of Regexp::Common. Regardless whether "-keep" was set, the matched number will be returned in $1.

"$RE{num}{roman}"

Returns a pattern that matches an integer written in Roman numbers. Case doesn't matter. There is no unique way of writing Roman numerals, but we will not match anything. We require the Roman numerals to list the symbols in order (largest first). The symbols for thousand ("M"), hundred ("C"), ten ("X"), and one ("I") can not be repeated more than four times. The symbols for five hundred ("D"), fifty ("L"), and five ("V") may not appear more than once. A sequence of four repeated characters may also be written as a subtraction: by using the repeated character just once, and have it followed by the symbol which is 5 or 10 as large. So, four can be written as "IIII", or as "IV", and nine may be written as "VIIII" or "IX". This corresponds to most modern uses of Roman numerals.

The largest number which will be matched is 4999, or "MMMMDCCCCLXXXXVIIII", or "MMMMCMXCIX".

Under "-keep", the number will be captured in $1.
