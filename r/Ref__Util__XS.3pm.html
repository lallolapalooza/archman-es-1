Ref::Util::XS(3) Documentación de Perl aportada por el usuario Ref::Util::XS(3)

NOMBRE

Ref::Util::XS - Implementación XS para Ref::Util

VERSIÓN

versión 0.117

SINOPSIS

use Ref::Util;
# ¡No uses Ref::Util::XS directamente!
if (is_arrayref($something) {
    print for @$something;
}
elsif (is_hashref($something)) {
    print for sort values %$something;
}

DESCRIPCIÓN

Ref::Util::XS es la implementación XS de Ref::Util, que proporciona varias funciones para ayudar a identificar referencias de una manera más conveniente que el enfoque habitual de examinar el valor de retorno de "ref".

Deberías usar Ref::Util::XS instalando Ref::Util en sí: si el sistema en el que lo instalas tiene un compilador C disponible, "Ref::Util::XS" se instalará y se usará automáticamente, proporcionando una mejora significativa de velocidad a todo lo que use "Ref::Util".

Consulta Ref::Util para obtener documentación completa de las funciones disponibles.
