NOMBRE

Regexp::Common::URI::gopher -- Devuelve un patrón para URIs gopher.

SINOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{gopher}/       and  print "Contiene una URI gopher.\n";
}

DESCRIPCIÓN

$RE{URI}{gopher}{-notab}

Las URIs Gopher están mal definidas. Originalmente, RFC 1738 definió las URIs gopher, pero luego fueron redefinidas en un borrador de internet. Uno que expiró en junio de 1997.

El borrador de internet para URIs gopher las define de la siguiente manera:

"gopher:" "//" host [ ":" port ] "/" gopher-type selector
                    [ "%09" search [ "%09" gopherplus_string ]]

Desafortunadamente, un selector se define de tal manera que los caracteres pueden escaparse usando el mecanismo de escape de URI. Esto incluye las tabulaciones, que escapadas son %09. Por lo tanto, la sintaxis no puede distinguir entre una URI que tiene tanto una parte de selector como una de search, y una URI donde el selector incluye una tabulación escapada. (El texto del borrador prohíbe las tabulaciones en el selector, sin embargo).

"$RE{URI}{gopher}" sigue la sintaxis definida. Para desautorizar las tabulaciones escapadas en las partes de selector y search, use "$RE{URI}{gopher}{-notab}".

Existen otras diferencias entre el texto y la sintaxis dada. Según el texto, las cadenas de selector no pueden tener tabulaciones, saltos de línea o retornos de carro. El texto también permite que toda la gopher-path, (la parte después de la barra que sigue al hostport) esté vacía; si está vacía, la barra también puede omitirse. Sin embargo, esto no se refleja en la sintaxis.

Bajo "{-keep}", se devuelven los siguientes:

$1
La URI completa.
$2
El esquema.
$3
El host (nombre o dirección).
$4
El puerto (si existe).
$5
La "gopher-path", la parte después de la / que sigue al host y al puerto.
$6
El tipo gopher.
$7
El selector. (Cuando no se usa "{-notab}", esto incluye la búsqueda y el gopherplus_string, incluyendo las tabulaciones escapadas separadoras).
$8
La búsqueda, si se proporciona. (Solo cuando "{-notab}" se proporciona).
$9
El gopherplus_string, si se proporciona. (Solo cuando "{-notab}" se proporciona).
