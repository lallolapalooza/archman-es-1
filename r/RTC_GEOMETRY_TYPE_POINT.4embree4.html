RTC_GEOMETRY_TYPE_*_POINT(3) Núcleos de trazado de rayos Embree 4 RTC_GEOMETRY_TYPE_*_POINT(3)

NOMBRE

RTC_GEOMETRY_TYPE_SPHERE_POINT -
  esferas de geometría de puntos
RTC_GEOMETRY_TYPE_DISC_POINT -
  puntos de geometría con discos orientados al rayo
RTC_GEOMETRY_TYPE_ORIENTED_DISC_POINT -
  puntos de geometría con discos orientados por normales

SINOPSIS

#include <embree4/rtcore.h>
rtcNewGeometry(device, RTC_GEOMETRY_TYPE_SPHERE_POINT);
rtcNewGeometry(device, RTC_GEOMETRY_TYPE_DISC_POINT);
rtcNewGeometry(device, RTC_GEOMETRY_TYPE_ORIENTED_DISC_POINT);

DESCRIPCIÓN

Se admiten puntos con radios por vértice con representaciones geométricas de esferas, discos orientados al rayo y discos orientados por normales. Estas geometrías de puntos se crean pasando RTC_GEOMETRY_TYPE_SPHERE_POINT, RTC_GEOMETRY_TYPE_DISC_POINT o RTC_GEOMETRY_TYPE_ORIENTED_DISC_POINT a la función rtcNewGeometry. Los vértices de los puntos se pueden especificar a través de un búfer de vértices (RTC_BUFFER_TYPE_VERTEX). Para los discos orientados por normales, se debe especificar además un búfer de normales (RTC_BUFFER_TYPE_NORMAL). Consulte rtcSetGeometryBuffer y rtcSetSharedGeometryBuffer para obtener más detalles sobre cómo establecer búferes.

El búfer de vértices almacena cada vértice de control en forma de una posición de precisión simple y un radio almacenados en orden (x, y, z, r) en la memoria (formato RTC_FORMAT_FLOAT4). El número de vértices se infiere del tamaño de este búfer. De manera similar, el búfer de normales almacena una normal de precisión simple por vértice de control (orden x, y, z y formato RTC_FORMAT_FLOAT3).

En el modo RTC_GEOMETRY_TYPE_SPHERE_POINT, se renderiza una superficie geométrica real para la curva, lo que es más costoso pero permite vistas cercanas.

El modo plano RTC_GEOMETRY_TYPE_DISC_POINT es un modo rápido diseñado para renderizar puntos distantes. En este modo, el punto se renderiza como un disco que mira al rayo.

El modo RTC_GEOMETRY_TYPE_ORIENTED_DISC_POINT es un modo diseñado como un punto intermedio geométricamente entre los discos orientados al rayo y las esferas. En este modo, el punto se renderiza como un disco orientado por normales.

Para todos los tipos de puntos, solo se devuelve la distancia de impacto y la normal geométrica como información de impacto; u y v se establecen en cero.

Para el desenfoque de movimiento de múltiples segmentos, primero se debe especificar el número de pasos de tiempo utilizando la llamada rtcSetGeometryTimeStepCount. Luego, se puede establecer un búfer de vértices para cada paso de tiempo utilizando diferentes ranuras de búfer, y todos estos búferes deben tener la misma zancada y tamaño.

Consulte también el tutorial [Puntos] para ver un ejemplo de cómo crear y usar geometrías de puntos.

ESTADO DE SALIDA

En caso de error, se devuelve NULL y se establece un código de error que se puede consultar con rtcGetDeviceError.

VER TAMBIÉN

[rtcNewGeometry]
