NOMBRE

Regexp::Common::CC -- proporciona patrones para números de tarjetas de crédito.

SINOPSIS

use Regexp::Common qw /CC/;
while (<>) {
    /^$RE{CC}{Mastercard}$/   and  print "Número de tarjeta Mastercard\n";
}

DESCRIPCIÓN

Por favor, consulta el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No uses este módulo directamente, cárgalo a través de Regexp::Common.

Este módulo ofrece patrones para números de tarjetas de crédito de varios tipos principales. Actualmente, las tarjetas soportadas son: Mastercard, Amex, Diners Club y Discover.
