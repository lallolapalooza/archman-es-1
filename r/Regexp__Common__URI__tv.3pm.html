NOMBRE

Regexp::Common::URI::tv -- Devuelve un patrón para URIs de tv.

SINOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{tv}/       and  print "Contiene una URI de tv.\n";
}

DESCRIPCIÓN

"$RE{URI}{tv}"

Devuelve un patrón que reconoce URIs de TV según un borrador de Internet [DRAFT-URI-TV].

Bajo "{-keep}", se devuelven los siguientes elementos:

$1
La URI completa.
$2
El esquema.
$3
El host.

REFERENCIAS

[DRAFT-URI-TV]
Zigmond, D. y Vickers, M: Uniform Resource Identifiers for Television Broadcasts. Diciembre 2000.
[RFC 2396]
Berners-Lee, Tim, Fielding, R., y Masinter, L.: Uniform Resource Identifiers (URI): Generic Syntax. Agosto 1998.

VER TAMBIÉN

Regexp::Common::URI para otras URIs soportadas.
