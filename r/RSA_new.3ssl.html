RSA_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_NEW(3ssl) OpenSSL RSA_NEW(3ssl)

NOMBRE

RSA_new, RSA_free - asignar y liberar objetos RSA

SINOPSIS

#include <openssl/rsa.h>

Las siguientes funciones han sido **obsoletas** desde OpenSSL 3.0, y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

RSA *RSA_new(void);
void RSA_free(RSA *rsa);

DESCRIPCIÓN

RSA_new() asigna e inicializa una estructura RSA. Es equivalente a llamar a RSA_new_method(NULL).

RSA_free() libera la estructura RSA y sus componentes. La clave se borra antes de que la memoria sea devuelta al sistema. Si rsa es NULL, no se hace nada.

VALORES DE RETORNO

Si la asignación falla, RSA_new() devuelve NULL y establece un código de error que puede obtenerse mediante ERR_get_error(3). En caso contrario, devuelve un puntero a la estructura recién asignada.

RSA_free() no devuelve ningún valor.

VER TAMBIÉN

ERR_get_error(3), RSA_generate_key(3), RSA_new_method(3)

HISTORIAL

Todas las funciones descritas aquí fueron obsoletas en OpenSSL 3.0. Para reemplazos, véase EVP_PKEY-RSA(7).
