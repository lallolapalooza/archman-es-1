Regexp::Common::URI::tel(3) Documentación de Perl aportada por el usuario Regexp::Common::URI::tel(3)

NOMBRE

Regexp::Common::URI::tel -- Devuelve un patrón para URIs de teléfono.

SINOSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{tel}/       and  print "Contiene una URI de teléfono.\n";
}

DESCRIPCIÓN

$RE{URI}{tel}

Devuelve un patrón que coincide con URIs tel, según se define en RFC 2806. Bajo "{-keep}", se devuelven los siguientes elementos:

$1
La URI completa.
$2
El esquema.
$3
El número de teléfono, incluyendo posibles complementos como subdirección ISDN, una parte de post-marcado, especificador de área, proveedor de servicios, etc.

"$RE{URI}{tel}{nofuture}"

Como se describe arriba (incluyendo lo que devuelve "{-keep}"), con la excepción de que las extensiones futuras no están permitidas. Sin permitir esas extensiones futuras, resulta mucho más fácil verificar una URI si se ha utilizado la sintaxis correcta para el post-marcado, proveedor de servicios, contexto telefónico, etc., de lo contrario, la expresión regular siempre podría clasificarlas como una extensión futura.

REFERENCIAS

[RFC 1035]
Mockapetris, P.: DOMAIN NAMES - IMPLEMENTATION AND SPECIFICATION. Noviembre de 1987.
[RFC 2396]
Berners-Lee, Tim, Fielding, R., y Masinter, L.: Uniform Resource Identifiers (URI): Generic Syntax. Agosto de 1998.
[RFC 2806]
Vaha-Sipila, A.: URLs for Telephone Calls. Abril de 2000.

VER TAMBIÉN

Regexp::Common::URI para otras URIs soportadas.
