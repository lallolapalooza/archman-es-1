RC4_set_key(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RC4_SET_KEY(3ssl) OpenSSL RC4_SET_KEY(3ssl)

NOMBRE

RC4_set_key, RC4 - Cifrado RC4

SINOPSIS

#include <openssl/rc4.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

void RC4_set_key(RC4_KEY *key, int len, const unsigned char *data);
void RC4(RC4_KEY *key, unsigned long len, const unsigned char *indata,
         unsigned char *outdata);

DESCRIPCIÓN

Todas las funciones descritas en esta página están obsoletas. Las aplicaciones deberían usar en su lugar EVP_EncryptInit_ex(3), EVP_EncryptUpdate(3) y EVP_EncryptFinal_ex(3) o las funciones de descifrado con nombres equivalentes.

Esta biblioteca implementa el cifrado Alleged RC4, que se describe por ejemplo en Applied Cryptography. Se cree que es compatible con RC4[TM], un cifrado propietario de RSA Security Inc.

RC4 es un cifrado de flujo con longitud de clave variable. Típicamente, se utilizan claves de 128 bits (16 bytes) para un cifrado fuerte, pero se han utilizado tamaños de clave más cortos e inseguros debido a las restricciones de exportación.

RC4 consta de una fase de configuración de clave y la fase real de cifrado o descifrado.

RC4_set_key() configura la RC4_KEY key utilizando los len bytes de longitud en data.

RC4() cifra o descifra los len bytes de datos en indata usando key y coloca el resultado en outdata. Las llamadas repetidas a RC4() con la misma key generan un flujo de clave continuo.

Dado que RC4 es un cifrado de flujo (la entrada se combina mediante XOR con un flujo de clave pseudoaleatorio para producir la salida), el descifrado utiliza las mismas llamadas de función que el cifrado.

VALORES DE RETORNO

RC4_set_key() y RC4() no devuelven valores.

NOTA

Las aplicaciones deberían usar las funciones de nivel superior EVP_EncryptInit(3), etc. en lugar de llamar a estas funciones directamente.

Es difícil usar cifrados de flujo de forma segura. Por ejemplo, no realice cifrados múltiples utilizando el mismo flujo de clave.

VER TAMBIÉN
