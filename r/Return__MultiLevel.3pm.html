NOMBRE

Return::MultiLevel - Retornar a través de múltiples niveles de llamada

VERSIÓN

versión 0.08

SINOPSIS

use Return::MultiLevel qw(with_return);
sub inner {
  my ($f) = @_;
  $f->(42);  # retorna implícitamente desde 'with_return' más abajo
  print "No verás esto\n";
}
sub outer {
  my ($f) = @_;
  inner($f);
  print "Tampoco verás esto\n";
}
my $result = with_return {
  my ($return) = @_;
  outer($return);
  die "No se llegó";
};
print $result, "\n";  # 42

DESCRIPCIÓN

Este módulo proporciona una forma de retornar inmediatamente desde una pila de llamadas profundamente anidada. Esto es similar a las excepciones, pero las excepciones no se detienen automáticamente en un marco de destino (y pueden ser capturadas por marcos de pila intermedios usando "eval"). En otras palabras, esto se parece más a setjmp(3)/longjmp(3) que a "die".

Otra forma de pensarlo es que la coderef de "retorno multinivel" representa una continuación de un solo uso / solo hacia arriba.

Funciones

Las siguientes funciones están disponibles (y se pueden importar bajo demanda).

with_return BLOQUE
Ejecuta BLOQUE, pasándole una referencia de código (llamada $return en esta descripción) como un único argumento. Retorna lo que sea que retorne BLOQUE.

Si se llama a $return, provoca un retorno inmediato desde "with_return". Cualquier argumento pasado a $return se convierte en el valor de retorno de "with_return" (si "with_return" está en contexto escalar, retornará el último argumento pasado a $return).

Es un error invocar $return después de que su BLOQUE circundante haya terminado de ejecutarse. En particular, es un error llamar a $return dos veces.

DEPURACIÓN

Este módulo utiliza "unwind" de "Scope::Upper" para hacer su trabajo. Si "Scope::Upper" no está disponible, sustituye su propia implementación pura de Perl. Puedes forzar el uso de la versión pura de Perl independientemente estableciendo la variable de entorno "RETURN_MULTILEVEL_PP" a 1.

Si obtienes el mensaje de error "Intento de reingresar a un marco de llamada muerto", significa que algo ha llamado a un $return desde fuera de su bloque "with_return { ... }". Puedes obtener un trazado de pila de dónde estaba ese "with_return" estableciendo la variable de entorno "RETURN_MULTILEVEL_DEBUG" a 1.

ADVERTENCIAS

No puedes usar este módulo para retornar a través de llamadas implícitas de funciones, como manejadores de señales (como $SIG{ALRM}) o destructores ("sub DESTROY { ... }"). Estas son invocadas automáticamente por perl y no forman parte de la cadena de llamadas normal.
