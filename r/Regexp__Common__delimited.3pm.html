NOMBRE

Regexp::Common::delimited -- proporciona una expresión regular para cadenas delimitadas

SINOPSIS

use Regexp::Common qw /delimited/;
while (<>) {
    /$RE{delimited}{-delim=>'"'}/  and print 'una cadena delimitada por "';
    /$RE{delimited}{-delim=>'/'}/  and print 'una cadena delimitada por \/';
}

DESCRIPCIÓN

Por favor, consulte el manual de Regexp::Common para una descripción general del funcionamiento de esta interfaz.

No utilice este módulo directamente, sino cárguelo a través de Regexp::Common.

"$RE{delimited}{-delim}{-cdelim}{-esc}"

Devuelve un patrón que coincide con una subcadena delimitada por un solo carácter, con escapado interno opcional del delimitador.

Cuando se especifica "-delim =" S>, cada carácter de la secuencia S es un delimitador posible. No hay un delimitador predeterminado, por lo que esta bandera debe especificarse siempre.

Por defecto, el delimitador de cierre es el mismo carácter que el delimitador de apertura. Si esto no se desea, por ejemplo, si desea hacer coincidir una cadena con delimitadores simétricos, puede especificar los delimitadores de cierre con "-cdelim =" S>. Cada carácter de S coincide con el carácter correspondiente proporcionado con la opción "-delim". Si la opción "-cdelim" tiene menos caracteres que la opción "-delim", el último carácter se repite tantas veces como sea necesario. Si la opción "-cdelim" tiene más caracteres que la opción "-delim", los caracteres adicionales se ignoran.

Si se especifica "-esc =" S>, cada carácter de la secuencia S es el delimitador para el carácter correspondiente en la lista "-delim=S". El carácter de escape predeterminado es la barra invertida.

Por ejemplo:

$RE{delimited}{-delim=>'"'}               # coincide con "una cadena delimitada por ""
$RE{delimited}{-delim=>'"'}{-esc=>'"'}    # coincide con "una cadena delimitada por """
$RE{delimited}{-delim=>'/'}               # coincide con /una cadena delimitada por \//
$RE{delimited}{-delim=>q{'"'}}             # coincide con "cadena" o 'cadena'
$RE{delimited}{-delim=>"("}{-cdelim=>")"} # coincide con (cadena)

Bajo "-keep" (ver Regexp::Common):

$1
captura la coincidencia completa
$2
captura el delimitador de apertura
$3
captura la porción delimitada de la cadena
$4
captura el delimitador de cierre

$RE{quoted}{-esc}

Un sinónimo de "$RE {delimited} {-delim => q {'"`}} {...}".

$RE {bquoted} {-esc}

Este es un patrón que coincide con cadenas delimitadas, donde los delimitadores son un conjunto de corchetes coincidentes. Actualmente, esto incluye 85 pares. Incluye los 60 pares de corchetes emparejados bidireccionales, como se indica en http://www.unicode.org/Public/UNIDATA/BidiBrackets.txt.

Los otros 25 pares son las comillas, las comillas dobles, las comillas angulares simples y dobles, las comas gruesas simples y dobles, 4 pares de paréntesis y corchetes de parte superior-inferior, 9 pares de formas de presentación para corchetes verticales y los corchetes de paráfrasis baja, omisión elevada, sustitución, sustitución doble y transposición.

En una futura actualización, se pueden añadir (o eliminar) pares.

Este patrón requiere perl 5.14.0 o superior.

Para una lista completa de pares de corchetes, inspeccione la salida de "Regexp::Common::delimited::bracket_pair ()", que devuelve una lista de arrays de dos elementos, cada uno con los nombres Unicode de pares de delimitadores coincidentes.

El comportamiento de "{-esc => S }" es el mismo que en el patrón "$RE {delimited}".

Si se proporciona "{-keep}", se capturarán las siguientes cosas:

$1
captura la coincidencia completa
$2
captura el delimitador de apertura
$3
captura la porción delimitada de la cadena
$4
captura el delimitador de cierre
