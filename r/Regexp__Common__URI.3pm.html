NOMBRE

Regexp::Common::URI -- proporciona patrones para URIs.

SINOPSIS

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{HTTP}/       and  print "Contiene una URI HTTP.\n";
}

DESCRIPCIÓN

Se admiten patrones para las siguientes URIs: fax, file, FTP, gopher, HTTP, news, NTTP, pop, prospero, tel, telnet, tv y WAIS. Cada una está documentada en la página del manual de Regexp::Common::URI::esquema, para el esquema apropiado (en minúsculas), excepto las URIs de NNTP que se encuentran en Regexp::Common::URI::news.

$RE{URI}

Devuelve un patrón que reconoce cualquiera de las URIs admitidas. Con "{-keep}", solo se devuelve la URI completa (en $1).
