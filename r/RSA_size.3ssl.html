RSA_size(3ssl)

Paquete: openssl

Licencias: Apache-2.0

RSA_SIZE(3ssl) OpenSSL RSA_SIZE(3ssl)

NOMBRE

RSA_size, RSA_bits, RSA_security_bits - obtener el tamaño del módulo RSA o los bits de seguridad

SINOPSIS

#include <openssl/rsa.h>
int RSA_bits(const RSA *rsa);

Las siguientes funciones han sido **obsoletas** desde OpenSSL 3.0, y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, consulte openssl_user_macros(7):

int RSA_size(const RSA *rsa);
int RSA_security_bits(const RSA *rsa);

DESCRIPCIÓN

RSA_bits() devuelve el número de bits significativos.

rsa y rsa->n no deben ser NULL.

Las funciones restantes descritas en esta página están obsoletas. Las aplicaciones deben usar en su lugar EVP_PKEY_get_size(3), EVP_PKEY_get_bits(3) y EVP_PKEY_get_security_bits(3).

RSA_size() devuelve el tamaño del módulo RSA en bytes. Se puede utilizar para determinar cuánta memoria se debe asignar para un valor cifrado con RSA.

RSA_security_bits() devuelve el número de bits de seguridad de la clave rsa dada. Consulte BN_security_bits(3).

VALORES DE RETORNO

RSA_bits() devuelve el número de bits en la clave.

RSA_size() devuelve el tamaño del módulo en bytes.

RSA_security_bits() devuelve el número de bits de seguridad.

VER TAMBIÉN

BN_num_bits(3)

HISTORIAL

Las funciones RSA_size() y RSA_security_bits() fueron obsoletas en OpenSSL 3.0.

La función RSA_bits() se añadió en OpenSSL 1.1.0.
