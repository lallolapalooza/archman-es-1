UFFDIO_CONTINUE(2const) UFFDIO_CONTINUE(2const)

NOMBRE

UFFDIO_CONTINUE - resolver una falta de página menor

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_CONTINUE, struct uffdio_continue *argp);
#include <linux/userfaultfd.h>
struct uffdio_continue {
    struct uffdio_range  range;
                     /* Rango para instalar PTEs y continuar */
    __u64   mode;    /* Flags que controlan el comportamiento de continuar */
    __s64   mapped;  /* Número de bytes mapeados, o error negado */
};

DESCRIPCIÓN

Resuelve una falta de página menor instalando entradas de tabla de páginas para páginas existentes en la caché de páginas.

El siguiente valor puede ser combinado mediante OR bit a bit en mode para cambiar el comportamiento de la operación UFFDIO_CONTINUE:

UFFDIO_CONTINUE_MODE_DONTWAKE
No despertar al hilo que espera la resolución de la falta de página.

El campo mapped es utilizado por el kernel para devolver el número de bytes que fueron efectivamente mapeados, o un error de la misma manera que UFFDIO_COPY. Si el valor devuelto en el campo mapped no coincide con el valor que se especificó en range.len, la operación falla con el error EAGAIN. El campo mapped es solo de salida; no es leído por la operación UFFDIO_CONTINUE.

VALOR DE RETORNO

Esta operación ioctl(2) devuelve 0 en caso de éxito. En este caso, toda el área fue mapeada. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EAGAIN
El número de bytes mapeados (es decir, el valor devuelto en el campo mapped) no es igual al valor especificado en el campo range.len.
EEXIST
Una o más páginas ya estaban mapeadas en el rango dado.
EFAULT
No se encontró ninguna página existente en la caché de páginas para el rango dado.
EINVAL
Ya sea range.start o range.len no eran múltiplos del tamaño de página del sistema; o range.len era cero; o el rango especificado era inválido.
EINVAL
Se especificó un bit inválido en el campo mode.
ENOENT
El proceso que causó la falta ha cambiado su disposición de memoria virtual simultáneamente con una operación UFFDIO_CONTINUE pendiente.
ENOMEM
Falló la asignación de memoria necesaria para configurar los mapeos de la tabla de páginas.
ESRCH
El proceso que causó la falta ha terminado en el momento de una operación UFFDIO_CONTINUE.

ESTÁNDARES

Linux.
