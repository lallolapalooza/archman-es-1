URI__otpauth(3pm)

Paquete: perl-uri

Licencias: PerlArtistic

URI::otpauth(3) Documentación Perl contribuida por el usuario URI::otpauth(3)

NOMBRE

URI::otpauth - Esquema URI para claves secretas para secretos OTP. Generalmente se encuentra en códigos QR

VERSIÓN

Versión 5.29

SINOPSIS

use URI;
# URI optauth a partir de una URI textual
my $uri = URI->new( 'otpauth://totp/Example:alice@google.com?secret=NFZS25DINFZV643VOAZXELLTGNRXEM3UH4&issuer=Example' );
# la misma URI pero creada a partir de argumentos
my $uri = URI::otpauth->new( type => 'totp', issuer => 'Example', account_name => 'alice@google.com', secret => 'is-this_sup3r-s3cr3t?' );

DESCRIPCIÓN

Este esquema URI se define en https://github.com/google/google-authenticator/wiki/Key-Uri-Format/:

SUBRUTINAS/MÉTODOS

"new"

Crea una nueva URI::otpauth. Los argumentos disponibles se enumeran a continuación;

  • account_name - este puede ser el nombre de la cuenta (probablemente una dirección de correo electrónico) utilizado al autenticarse con este secreto. Es un campo opcional.
  • algorithm - esta es la función hash criptográfica https://es.wikipedia.org/wiki/Función_hash_criptográfica que debería usarse. Los valores actuales son SHA1 https://es.wikipedia.org/wiki/SHA-1, SHA256 https://es.wikipedia.org/wiki/SHA-2 o SHA512 https://es.wikipedia.org/wiki/SHA-2. Es un campo opcional y por defecto será SHA1.
  • counter - esto solo se requiere cuando el tipo es HOTP.
  • digits - esto determina la longitud https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#digits del código presentado al usuario. Es un campo opcional y por defecto serán 6 dígitos.
  • issuer - este puede ser la aplicación / sistema https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#issuer al que este secreto puede usarse para autenticarse. Es un campo opcional.
  • label - este es el emisor y el nombre de la cuenta https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#label unidos por un carácter ":". Es un campo opcional.
  • period - este es el período para el cual el código TOTP es válido https://github.com/google/google-authenticator/wiki/Key-Uri-Format/#counter. Es un campo opcional y por defecto serán 30 segundos.
  • secret - esta es la clave <https://es.wikipedia.org/wiki/Clave_(criptografía)> que el algoritmo TOTP https://es.wikipedia.org/wiki/Contraseña_de_un_solo_uso_basada_en_tiempo/HOTP https://es.wikipedia.org/wiki/Contraseña_de_un_solo_uso_basada_en_contraseña utiliza para derivar el valor. Es una cadena de bytes arbitraria y debe permanecer privada. Este campo es obligatorio.
  • type - este puede ser 'hotp https://es.wikipedia.org/wiki/Contraseña_de_un_solo_uso_basada_en_contraseña' o 'totp https://es.wikipedia.org/wiki/Contraseña_de_un_solo_uso_basada_en_tiempo'. Este campo por defecto será 'totp'.

"algorithm"

Obtiene o establece el algoritmo de esta URI otpauth.

"account_name"

Obtiene o establece el nombre de cuenta de esta URI otpauth.

"counter"

Obtiene o establece el contador de esta URI otpauth.

"digits"

Obtiene o establece los dígitos de esta URI otpauth.

"issuer"

Obtiene o establece el emisor de esta URI otpauth.

"label"

Obtiene o establece la etiqueta de esta URI otpauth.

"period"

Obtiene o establece el período de esta URI otpauth.

"secret"

Obtiene o establece el secreto de esta URI otpauth.

"type"

Obtiene o establece el tipo de esta URI otpauth.

my $type = $uri->type('hotp');

CONFIGURACIÓN Y ENTORNO

URI::otpauth no requiere archivos de configuración ni variables de entorno.

DEPENDENCIAS

URI

DIAGNÓSTICOS

"El secreto es un parámetro obligatorio para URI::otpauth"
El parámetro secreto no se detectó para el método URI::otpauth->new().
