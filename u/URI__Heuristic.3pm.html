NOMBRE

URI::Heuristic - Expande URIs utilizando heurísticas

SINOPSIS

use URI::Heuristic qw(uf_uristr);
$u = uf_uristr("example");          # http://www.example.com
$u = uf_uristr("www.sol.no/sol");   # http://www.sol.no/sol
$u = uf_uristr("aas");              # http://www.aas.no
$u = uf_uristr("ftp.funet.fi");     # ftp://ftp.funet.fi
$u = uf_uristr("/etc/passwd");      # file:/etc/passwd

DESCRIPCIÓN

Este módulo proporciona funciones que expanden cadenas en URIs absolutas reales utilizando algunas heurísticas incorporadas. Las cadenas que ya representan URIs absolutas (es decir, que comienzan con una parte "esquema:") nunca se modifican y se devuelven sin cambios. El uso principal de estas funciones es permitir URIs abreviadas similares a lo que muchos navegadores web permiten para URIs escritas por el usuario.

Las siguientes funciones se proporcionan:

uf_uristr($str)
Intenta convertir la cadena de argumento en una cadena URI absoluta correcta. El prefijo "uf_" significa "User Friendly" (amigable para el usuario). En MacOS, asume que cualquier cadena con un esquema de URL común (http, ftp, etc.) es una URL en lugar de una ruta local. Por lo tanto, no nombre sus volúmenes con esquemas de URL comunes y espere que uf_uristr() construya URL de archivo válidas para usted en esos volúmenes, porque no lo hará.
uf_uri($str)
Funciona de la misma manera que uf_uristr(), pero devuelve un objeto "URI".

ENTORNO

Si la parte del nombre de host de una URI no contiene puntos, se realizan ciertas conjeturas calificadas. Estas conjeturas se rigen por las siguientes variables de entorno:

COUNTRY
El código de país de dos letras (ISO 3166) de su ubicación. Si el nombre de dominio de su host termina con dos letras, se toma como el país predeterminado. Consulte también Locale::Country.
HTTP_ACCEPT_LANGUAGE, LC_ALL, LANG
Si COUNTRY no está configurado, se examinan estas variables de entorno estándar y la información de país (no de idioma) que posiblemente se encuentre en ellas se utiliza como país predeterminado.
URL_GUESS_PATTERN
Contiene una lista separada por espacios de patrones de URL a probar. La cadena "ACME" se utiliza por alguna razón como marcador de posición para el nombre del host en la URL proporcionada. Ejemplo: 
URL_GUESS_PATTERN="www.ACME.no www.ACME.se www.ACME.com"
export URL_GUESS_PATTERN

Especificar URL_GUESS_PATTERN deshabilita cualquier regla de conjetura basada en el país. Un URL_GUESS_PATTERN vacío deshabilita cualquier conjetura que involucre búsquedas de nombres de host.
