NOMBRE

Unicode::String - Cadena de caracteres Unicode (UTF-16BE)

SINOPSIS

use Unicode::String qw(utf8 latin1 utf16be);
$u = utf8("cadena");
$u = latin1("cadena");
$u = utf16be("\0s\0t\0r\0i\0n\0g");
print $u->utf32be;   # caracteres de 4 bytes
print $u->utf16le;   # caracteres de 2 bytes + sustitutos
print $u->utf8;      # caracteres de 1-4 bytes

DESCRIPCIÓN

Un objeto "Unicode::String" representa una secuencia de caracteres Unicode. Se proporcionan métodos para convertir entre varios formatos externos (codificaciones) y objetos "Unicode::String", y métodos para manipulaciones comunes de cadenas.

Las funciones utf32be(), utf32le(), utf16be(), utf16le(), utf8(), utf7(), latin1(), uhex(), uchr() pueden ser importadas desde el módulo "Unicode::String" y funcionarán como constructores inicializando cadenas de la codificación correspondiente.

Los objetos "Unicode::String" sobrecargan varios operadores, lo que significa que en la mayoría de los casos pueden ser tratados como cadenas normales.

Internamente, un objeto "Unicode::String" se representa mediante una cadena de números de 2 bytes en orden de bytes de red (big-endian). Esta representación no es visible a través de la API proporcionada, pero podría ser útil conocerla para predecir la eficiencia de los métodos proporcionados.

MÉTODOS

Métodos de clase

Los siguientes métodos de clase están disponibles:

Unicode::String->stringify_as
Unicode::String->stringify_as( $enc )
Este método se utiliza para especificar qué codificación se usará cuando los objetos "Unicode::String" se conviertan implícitamente a y desde cadenas normales.

Si se proporciona un argumento, establece la codificación actual. El argumento debe ser uno de los siguientes: "ucs4", "utf32", "utf32be", "utf32le", "ucs2", "utf16", "utf16be", "utf16le", "utf8", "utf7", "latin1" o "hex". El valor predeterminado es "utf8".

El método stringify_as() devuelve una referencia a la función de codificación actual.

$us = Unicode::String->new
$us = Unicode::String->new( $valor_inicial )
Este es el constructor del objeto. Sin argumento, crea un objeto "Unicode::String" vacío. Si se proporciona un argumento $valor_inicial, se decodifica según la codificación stringify_as() especificada, UTF-8 por defecto.

En general, se recomienda importar y utilizar una de las funciones constructoras específicas de codificación en lugar de invocar este método.

Métodos de codificación

Estos métodos obtienen o establecen el valor del objeto "Unicode::String" pasando cadenas en la codificación correspondiente. Si se pasa un nuevo valor como argumento, establecerá el valor del "Unicode::String", y se devolverá el valor anterior. Si no se pasa ningún argumento, se devolverá el valor actual.

Para ilustrar las codificaciones, mostramos cómo se codifica la cadena de ejemplo de 2 caracteres de "µm" (micrómetro) para cada una.

$us->utf32be
$us->utf32be( $nuevo_valor )
La cadena pasada debe estar en codificación UTF-32 con bytes en orden big-endian. La muestra "µm" es "\0\0\0\xB5\0\0\0m" en esta codificación.

Nombres alternativos para este método son utf32() y ucs4().

$us->utf32le
$us->utf32le( $nuevo_valor )
La cadena pasada debe estar en codificación UTF-32 con bytes en orden little-endian. La muestra "µm" es "\xB5\0\0\0m\0\0\0" en esta codificación.
$us->utf16be
$us->utf16be( $nuevo_valor )
La cadena pasada debe estar en codificación UTF-16 con bytes en orden big-endian. La muestra "µm" es "\0\xB5\0m" en esta codificación.

Nombres alternativos para este método son utf16() y ucs2().

Si la cadena pasada a utf16be() comienza con la marca de orden de bytes Unicode en orden little-endian, el resultado es como si se hubiera llamado a utf16le() en su lugar.

$us->utf16le
$us->utf16le( $nuevo_valor )
La cadena pasada debe estar en codificación UTF-16 con bytes en orden little-endian. La muestra "µm" es "\xB5\0m\0" en esta codificación. Esta es la codificación utilizada por la API de Microsoft Windows.

Si la cadena pasada a utf16le() comienza con la marca de orden de bytes Unicode en orden big-endian, el resultado es como si se hubiera llamado a utf16le() en su lugar.

$us->utf8
$us->utf8( $nuevo_valor )
La cadena pasada debe estar en codificación UTF-8. La muestra "µm" es "\xC2\xB5m" en esta codificación.
$us->utf7
$us->utf7( $nuevo_valor )
La cadena pasada debe estar en codificación UTF-7. La muestra "µm" es "+ALU-m" en esta codificación.

La codificación UTF-7 solo utiliza caracteres US-ASCII normales para la codificación. Esto la hace segura para su transporte a través de protocolos que eliminan bits. Los caracteres fuera del rango US-ASCII se codifican en base64 y '+' se utiliza como carácter de escape. La codificación UTF-7 se describe en RFC 1642.

Si la variable (global) $Unicode::String::UTF7_OPTIONAL_DIRECT_CHARS es TRUE, entonces un rango más amplio de caracteres se codifica como sí mismos. De hecho, es TRUE por defecto. Los caracteres afectados por esto son:

! " # $ % & * ; < = > @ [ ] ^ _ ` { | }
$us->latin1
$us->latin1( $nuevo_valor )
La cadena pasada debe estar en codificación ISO-8859-1. La muestra "µm" es "\xB5m" en esta codificación.

Los caracteres fuera del rango "\x00" .. "\xFF" simplemente se eliminan del valor de retorno del método latin1(). Si desea un mayor control sobre el mapeo de Unicode a ISO-8859-1, utilice la clase "Unicode::Map8". Esta es también la forma de tratar otros conjuntos de caracteres de 8 bits.

$us->hex
$us->hex( $nuevo_valor )
La cadena pasada debe ser ASCII plano donde cada carácter Unicode se representa por la cadena "U+XXXX" y separado por un solo carácter de espacio. El prefijo "U+" es opcional al establecer el valor. La muestra "µm" es "U+00b5 U+006d" en esta codificación.

Operaciones de cadena

Los siguientes métodos están disponibles:

$us->as_string
Convierte un "Unicode::String" a una cadena normal según la configuración de stringify_as(). La codificación predeterminada de stringify_as() es "utf8".
$us->as_num
Convierte un "Unicode::String" a un número. Actualmente, solo se reconocen los dígitos en el rango 0x30 .. 0x39. El plan es soportar eventualmente todos los caracteres numéricos Unicode.
$us->as_bool
Convierte un "Unicode::String" a un valor booleano. Solo la cadena vacía es FALSE. Una cadena que consiste únicamente en el carácter U+0030 se considera TRUE, incluso si Perl considera FALSE a "0".
$us->repeat( $contador )
Devuelve un nuevo "Unicode::String" donde el contenido de $us se repite $contador veces. Esta operación también está sobrecargada como: 
$us x $contador
$us->concat( $otra_cadena )

NAME

Unicode::String - object-oriented interface to Unicode strings

SYNOPSIS

    use Unicode::String qw( :std :custom );
    
    # Constructors
    my $us = Unicode::String->new( "string" );
    my $us = latin1( "string" );
    my $us = utf8( "string" );
    my $us = uhex( "string" );
    my $us = uchar( code );
    
    # Object methods
    $us->append( "string" );
    $us->substr( offset, length );
    $us->length;
    $us->ord;
    $us->chr( code );
    $us->byteswap;
    $us->name;
    
    # Operators
    my $concat = $us1 . $us2;
    $us1 .= $us2;

DESCRIPTION

The "Unicode::String" module provides an object-oriented interface for manipulating Unicode strings.

It supports different character encodings like Latin-1, UTF-8, UCS-2, and UCS-4. The module attempts to handle the differences between these encodings transparently.

$us->new( string )
Constructs a new "Unicode::String" object. If the argument string is a valid "Unicode::String" object, then it is cloned. Otherwise, the argument is assumed to be a byte string, and the constructor attempts to determine its encoding. It first checks if it is a valid UTF-8 string. If not, it assumes it is a Latin-1 string. The constructor also accepts an optional second argument, which specifies the encoding. This should be one of the constants defined in the module (e.g. THIS_IS_UTF8).
$us->concat( other_string )
Concatenates the string $us and the string $other_string. If $other_string is not an "Unicode::String" object, then it is first passed to the Unicode::String->new constructor function. This operation is also overloaded as: 
$us . $other_string
$us->append( other_string )
Appends the string $other_string to the value of $us. If $other_string is not an "Unicode::String" object, then it is first passed to the Unicode::String->new constructor function. This operation is also overloaded as: 
$us .= $other_string
$us->copy
Returns a copy of the current "Unicode::String" object. This operation is overloaded as the assignment operator.
$us->length
Returns the length of the "Unicode::String". Surrogate pairs are still counted as 2.
$us->byteswap
This method will swap the bytes in the internal representation of the "Unicode::String" object.

Unicode reserve the character U+FEFF character as a byte order mark. This works because the swapped character, U+FFFE, is reserved to not be valid. For strings that have the byte order mark as the first character, we can guaranty to get the byte order right with the following code:

$ustr->byteswap if $ustr->ord == 0xFFFE;
$us->unpack
Returns a list of integers each representing an UCS-2 character code.
$us->pack( @uchr )
Sets the value of $us as a sequence of UCS-2 characters with the characters codes given as parameter.
$us->ord
Returns the character code of the first character in $us. The ord() method deals with surrogate pairs, which gives us a result-range of 0x0 .. 0x10FFFF. If the $us string is empty, undef is returned.
$us->chr( $code )
Sets the value of $us to be a string containing the character assigned code $code. The argument $code must be an integer in the range 0x0 .. 0x10FFFF. If the code is greater than 0xFFFF then a surrogate pair created.
$us->name
In scalar context returns the official Unicode name of the first character in $us. In array context returns the name of all characters in $us. Also see Unicode::CharName.
$us->substr( $offset )
$us->substr( $offset, $length )
$us->substr( $offset, $length, $subst )
Returns a sub-string of $us. Works similar to the builtin substr() function.
$us->index( $other )
$us->index( $other, $pos )
Locates the position of $other within $us, possibly starting the search at position $pos.
$us->chop
Chops off the last character of $us and returns it (as a "Unicode::String" object).

FUNCTIONS

The following functions are provided. None of these are exported by default.

byteswap2( $str, ... )
This function will swap 2 and 2 bytes in the strings passed as arguments. If this function is called in void context, then it will modify its arguments in-place. Otherwise, the swapped strings are returned.
"Unicode::String" objects. The provided argument should be encoded correspondingly.
"Unicode::String" object from a string of hex values. See hex() method above for description of the format.
"Unicode::String" object from a Unicode character code. This works similar to perl's builtin chr() function.
