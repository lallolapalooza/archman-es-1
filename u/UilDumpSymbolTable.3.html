UilDumpSymbolTable(llamada de biblioteca) UilDumpSymbolTable(llamada de biblioteca)

NOMBRE

UilDumpSymbolTable — Descarga el contenido de una tabla de símbolos UIL a la salida estándar

SINOPSIS

#include <uil/UilDef.h>

void UilDumpSymbolTable(
sym_entry_type *root_ptr);

DESCRIPCIÓN

La función UilDumpSymbolTable descarga el contenido de un puntero a una tabla de símbolos UIL a la salida estándar.

root_ptr
Especifica un puntero a la entrada raíz de la tabla de símbolos. Este valor se puede obtener de la parte parse_tree_root de la estructura de datos Uil_compile_desc_type devuelta por Uil.

Siguiendo el enlace desde la entrada raíz, puede recorrer todo el árbol de análisis sintáctico. Las entradas de la tabla de símbolos tienen el siguiente formato:

dirección.hexadecimal tipo.símbolo datos.símbolo posición.código.fuente.anterior posición.código.fuente registro.modificación

donde:

dirección.hexadecimal
Especifica la dirección hexadecimal de esta entrada en la tabla de símbolos.
tipo.símbolo
Especifica el tipo de esta entrada de la tabla de símbolos. Algunos tipos posibles son root, module, value, procedure y widget.
datos.símbolo
Especifica datos para la entrada de la tabla de símbolos. Los datos varían según el tipo de la entrada. A menudo contienen punteros a otras entradas de la tabla de símbolos o los datos reales para el tipo de dato.
posición.código.fuente.anterior
Especifica el punto final en el código fuente del elemento de origen anterior.
posición.código.fuente
Especifica el rango de posiciones en el código fuente para este símbolo.

Las estructuras de datos exactas para cada tipo de símbolo se definen en el archivo de inclusión UilSymDef.h. Tenga en cuenta que este archivo se incluye automáticamente cuando una aplicación incluye el archivo UilDef.h.
