User::Identity(3) Documentación aportada por usuarios de Perl User::Identity(3)

NOMBRE

User::Identity - mantener información sobre una persona física

HERENCIA

User::Identity
  es un User::Identity::Item

SINOPSIS

use User::Identity;
my $yo = User::Identity->new(
         'john',
  firstname => 'John',
  surname   => 'Doe'
 );
print $yo->fullName  # imprime "John Doe"
print $yo;           # lo mismo

DESCRIPCIÓN

La distribución "User-Identity" se crea para mantener un conjunto de objetos informativos relacionados con un usuario. El módulo "User::Identity" intenta ser inteligente proporcionando valores predeterminados, conversiones y combinaciones a menudo requeridas.

Esta es una versión de mantenimiento para la interfaz antigua. Lea https://github.com/markov2/perl5-Mail-Box/wiki/ cómo migrar a la versión 4.

Las identidades no implementan ningún tipo de almacenamiento y, por lo tanto, pueden ser creadas por cualquier programa Perl simple o complejo. De esta manera, es más flexible que un archivo XML para almacenar los datos. Por ejemplo, puede decidir almacenar los datos con Data::Dumper, Storable, DBI, AddressBook o lo que sea. Las extensiones para simplificar esta tarea aún están por desarrollarse.

Si necesita más tipos de información de usuario, póngase en contacto con el autor del módulo.

Extiende "DESCRIPCIÓN" en User::Identity::Item.

SOBRECARGADO

Sobrecarga: "" conversión a cadena
Cuando una "User::Identity" se utiliza como cadena, se traduce automáticamente al fullName() del usuario involucrado.

» ejemplo:

my $yo = User::Identity->new(...)
print $yo;          # lo mismo que  print $yo->fullName
print "Soy $yo\n"; # también conversión a cadena

Atributos

Extiende "Atributos" en User::Identity::Item.

$obj->edad()
Calculado desde la fecha de nacimiento hasta el momento actual, como entero. En el día del cumpleaños, el número ya se incrementa.
$obj->nacimiento()
Devuelve la fecha en formato estandarizado: YYYYMMDD, fácil de ordenar y seleccionar. Puede devolver "undef", incluso si dateOfBirth() contiene un valor, simplemente porque el formato no se entiende. El mes o el día pueden contener '00' para indicar que esos valores no se conocen.
$obj->charset()
El conjunto de caracteres preferido del usuario, que por defecto es el valor de la variable de entorno LC_CTYPE.
$obj->cortesia()
La cortesía se utiliza para dirigirse a las personas de manera muy formal. Los valores son como "Sr.", "Sra.", "Sir", "Frau", "Heer", "de heer", "mevrouw". Esto a menudo proporciona una forma de encontrar el género de la persona a la que se dirige.
$obj->dateOfBirth()
Devuelve la fecha de nacimiento, tal como se especificó durante la instanciación.
$obj->description()
Heredado, véase "Atributos" en User::Identity::Item
$obj->firstname()
Devuelve el nombre de pila del usuario. Si no está definido explícitamente, se deriva del apodo y luego se capitaliza si es necesario.
$obj->formalName()
Devuelve un nombre formal para el usuario. Si no se define como parámetro de instanciación (ver new()), se construye a partir de otra información disponible, lo que puede resultar en un nombre incorrecto o incompleto. El resultado se construye a partir de "cortesía iniciales prefijo apellido título".
$obj->fullName()
Si esto no se especifica como valor durante la construcción del objeto, se adivina basándose en otros valores conocidos como "nombre_de_pila prefijo apellido". Si se proporciona un apellido sin nombre de pila, el apodo se toma como nombre de pila. Cuando se proporciona un nombre de pila sin apellido, el apodo se toma como apellido. Si ambos no se proporcionan, entonces se utiliza el apodo como nombre completo.
$obj->gender()
Devuelve el género especificado de la persona, tal como se especificó durante la instanciación, que podría ser como 'Masculino', 'm', 'homme', 'man'. No hay un comportamiento inteligente en esto: se devuelve el valor exacto especificado. Los métodos isMale(), isFemale() y courtesy() son inteligentes.
$obj->initials()
Las iniciales, que pueden derivarse de las primeras letras del nombre de pila.
$obj->isFemale()
Ver isMale(): devuelve "verdadero" si estamos seguros de que el usuario es una mujer.
$obj->isMale()
Devuelve "verdadero" si estamos seguros de que el usuario es hombre. Esto se especifica como género en la instanciación, o se deriva del valor de cortesía. Los métodos isMale e isFemale no son complementarios: ambos pueden devolver "falso" para el mismo usuario, en cuyo caso el género no se determina.
$obj->language()
Puede contener una lista o un solo nombre de idioma, según lo definido por los RFC. Ejemplos son 'en', 'en-GB', 'nl-BE'. El idioma predeterminado es 'en' (inglés).
$obj->name( [$nuevonombre] )
Heredado, véase "Atributos" en User::Identity::Item
$obj->nickname()
Devuelve el apodo del usuario.
$obj->parent()
Heredado, véase "Atributos" en User::Identity::Item
$obj->prefix()
Devuelve el prefijo del nombre del usuario, como "von" o "de".
$obj->surname()
Devuelve el apellido del usuario.
$obj->titles()
Devuelve los títulos del usuario, como "Dr." o "Prof.".

User::Identity::Person(3pm)

NAME

User::Identity::Person - a person identity object

INHERITANCE

Extends User::Identity::Item.

SYNOPSIS

  use User::Identity;

  my $person = User::Identity::Person->new(
      'givenname' => 'Mark',
      'surname'   => 'Overmeer',
  );

  print $person->fullName;       # Mark Overmeer
  print $person->email;         # mark.overmeer@example.com (example)
  print $person->initials;      # M.O.
  print $person->nickname;      # mark (example)
  print $person->email;         # mark.overmeer@example.com (example)

  # Access individual components
  print $person->givenname;     # Mark
  print $person->surname;       # Overmeer
  print $person->prefix;        # undef
  print $person->suffix;        # undef
  print $person->titles;        # undef

  # Add a collection
  my $group = User::Identity::Group->new( name => 'developers' );
  $person->add( $group );

  # Find a collection
  my $found = $person->find( 'developers' );

  # Get the parent object
  my $parent = $person->parent;

DESCRIPTION

This class implements a concrete identity object representing a person. It holds various attributes that describe a person, such as name, titles, and contact information. It also supports collection management, allowing you to group person objects within other identity objects (like groups or organizations).

OVERLOADED

The following operators are overloaded:

~
Stringifies the object to its full name.

METHODS

add($collection, $role)
Adds a collection to this person object. The $role parameter can be used to specify the role of the person within that collection (e.g., 'member', 'admin'). See "Collections" in User::Identity::Item for details.
addCollection( $object | <[$type], %options> )
Inherited, see "Collections" in User::Identity::Item
collection($name)
Inherited, see "Collections" in User::Identity::Item
email()
Returns the primary email address for the person. This is usually constructed from the name components, but can be explicitly set. If no email is known, it returns "undef".
email_list()
Returns a list of all known email addresses for the person.
find($collection, $role)
Inherited, see "Searching" in User::Identity::Item
fullName()
Returns the full name of the person, formatted in a standard way (e.g., Title Prefix GivenName Suffixes Surname, or however the name components are set).
givenname()
Returns the first name(s) or given name(s) of the person. This can be a single name or multiple names/initials.
initials()
Returns the initials of the person, typically derived from the given name and surname.
name()
Returns the name of the person. This is a convenience method that typically returns the value of fullName().
nickname()
Returns a nickname or alias for the person. This can be used for informal references, usernames, email aliases, etc. If no nickname is explicitly specified, it may default to a derived value (e.g., the first name or a part of the email).
parent( [$parent] )
Inherited, see "Collections" in User::Identity::Item
prefix()
Returns any prefixes to the name, such as honorifics (e.g., 'Dr.', 'Hon.').
removeCollection($object|$name)
Inherited, see "Collections" in User::Identity::Item
suffix()
Returns any suffixes to the name, such as academic degrees or generational suffixes (e.g., 'Jr.', 'III', 'Ph.D.').
surname()
Returns the surname or last name of the person.
titles()
Returns any titles associated with the person, such as academic degrees or professional designations (e.g., 'Professor', 'CEO'). This is distinct from prefixes.
type()
Inherited, see "Collections" in User::Identity::Item. Should always return 'Person'.
user()
Inherited, see "Collections" in User::Identity::Item. Returns the parent object if this person is part of a collection.

DIAGNOSTICS

Error: $object is not a collection.
The first argument passed to add() or removeCollection() is not a valid collection object (i.e., it does not extend User::Identity::Collection).
Error: Cannot load collection module for $type ($class).
When using addCollection() with options, the specified $type could not be resolved to a class $class, or the module for $class failed to load or compile.
Error: Creation of a collection via $class failed.
When using addCollection(), the specified class $class loaded successfully, but an object could not be instantiated with the provided options.
Error: Don't know what type of collection you want to add.
When using addCollection(), the first argument was neither a collection object nor a hash reference containing a 'type' key to specify the collection type.
Warning: No collection $name
When using add(), the specified collection $name does not exist and could not be found or created.
