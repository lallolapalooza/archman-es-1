NOMBRE

URI::Escape - Codificar y decodificar caracteres inseguros en por ciento

SINOPSIS

use URI::Escape;
$safe = uri_escape("10% es suficiente\n");
$verysafe = uri_escape("foo", "\0-\377");
$str  = uri_unescape($safe);

DESCRIPCIÓN

Este módulo proporciona funciones para codificar y decodificar en por ciento cadenas de URI según lo definido por RFC 3986. La codificación en por ciento de las URI se llama informalmente "escape de URI". Esta es la terminología utilizada por este módulo, que precede a la formalización de los términos por el RFC en varios años.

Una URI consta de un conjunto restringido de caracteres. El conjunto restringido de caracteres consiste en dígitos, letras y algunos símbolos gráficos elegidos de entre los comunes a la mayoría de las codificaciones de caracteres e instalaciones de entrada disponibles para los usuarios de Internet. Están compuestos por los conjuntos de caracteres "no reservados" y "reservados" según se definen en RFC 3986.

unreserved    = ALPHA / DIGIT / "-" / "." / "_" / "~"
reserved      = ":" / "/" / "?" / "#" / "[" / "]" / "@"
                "!" / "$" / "&" / "'" / "(" / ")"
              / "*" / "+" / "," / ";" / "="

Además, cualquier byte (octeto) puede representarse en una URI mediante una secuencia de escape: un triplete que consiste en el carácter "%" seguido de dos dígitos hexadecimales. Un byte también puede representarse directamente mediante un carácter, utilizando el carácter US-ASCII para ese octeto.

Algunos de los caracteres están *reservados* para su uso como delimitadores o como parte de ciertos componentes de URI. Deben escaparse si se van a tratar como datos ordinarios. Lea RFC 3986 para más detalles.

Las funciones proporcionadas (y exportadas por defecto) desde este módulo son:

uri_escape( $cadena )
uri_escape( $cadena, $inseguro )
Reemplaza cada carácter inseguro en la $cadena con la secuencia de escape correspondiente y devuelve el resultado. La argumento $cadena debe ser una cadena de bytes. La función uri_escape() fallará si se le dan caracteres con código superior a 255. Use uri_escape_utf8() si sabe que tiene tales caracteres o/y desea que los caracteres en el rango 128 .. 255 se traten como UTF-8.

La función uri_escape() toma un segundo argumento opcional que anula el conjunto de caracteres que deben escaparse. El conjunto se especifica como una cadena que se puede usar en una clase de caracteres de expresión regular (entre [ ]). Por ejemplo:

"\\x00-\\x1f\\x7f-\\xff"          # todos los caracteres de control y de bit alto
"a-z"                         # todos los caracteres en minúsculas
"^A-Za-z"                     # todo lo que no sea una letra

El conjunto por defecto de caracteres a escapar es todos aquellos que *no* forman parte de la clase de caracteres "unreserved" mostrada arriba, así como los caracteres reservados. Es decir, el valor por defecto es:

"^A-Za-z0-9\\-\\._~"

El segundo argumento también se puede especificar como un objeto de expresión regular:

qr/[^A-Za-z]/

Cualquier cadena que coincida con esta expresión regular tendrá todos sus caracteres escapados.

uri_escape_utf8( $cadena )
uri_escape_utf8( $cadena, $inseguro )
Funciona como uri_escape(), pero codificará los caracteres como UTF-8 antes de escaparlos. Esto hace que esta función sea capaz de manejar caracteres con código superior a 255 en $cadena. Tenga en cuenta que los caracteres en el rango 128 .. 255 serán escapados de forma diferente por esta función en comparación con lo que haría uri_escape(). Para caracteres en el rango 0 .. 127 no hay diferencia.

Equivalente a:

utf8::encode($cadena);
my $uri = uri_escape($cadena);

Nota: JavaScript tiene una función llamada escape() que produce la secuencia "%uXXXX" para caracteres en el rango 256 .. 65535. Esta función realmente no tiene nada que ver con el escape de URI, pero algunos se confundieron ya que "hace lo correcto" en el rango 0 .. 255. Debido a esto, a veces se ven "URI" con este tipo de escapes. La función JavaScript encodeURIComponent() es similar a uri_escape_utf8().

uri_unescape($cadena,...)
Devuelve una cadena con cada secuencia %XX reemplazada por el byte (octeto) real.

Esto hace lo mismo que:

$cadena =~ s/%([0-9A-Fa-f]{2})/chr(hex($1))/eg;

pero no modifica la cadena en su lugar como lo haría esta RE. Usar la función uri_unescape() en lugar de la RE podría hacer que el código parezca más limpio y requiere escribir menos caracteres.

En una prueba de referencia simple que realicé, llamar a la función (en lugar de la RE en línea anterior) si se escapaban pocos caracteres era aproximadamente un 40% más lento, y aproximadamente un 700% más lento si no se escapaba ninguno. Si va a decodificar muchas veces, podría ser una buena idea incorporar la RE.

Si a la función uri_unescape() se le pasan varias cadenas, cada una se devuelve decodificada.

El módulo también puede exportar el hash %escapes, que contiene el mapeo de los 256 bytes a los códigos de escape correspondientes. Buscar en este hash es más rápido que evaluar "sprintf("%%%02X", ord($byte))" cada vez.
