NOMBRE

URI::Split - Analizar y componer cadenas de URI

SINOPSIS

use URI::Split qw(uri_split uri_join);
($scheme, $auth, $path, $query, $frag) = uri_split($uri);
$uri = uri_join($scheme, $auth, $path, $query, $frag);

DESCRIPCIÓN

Proporciona funciones para analizar y componer cadenas de URI. Las siguientes funciones están disponibles:

($scheme, $auth, $path, $query, $frag) = uri_split($uri)
Descompone una cadena de URI en sus partes componentes. Se devuelve un valor "undef" para aquellas partes que no estén presentes. La parte $path está siempre presente (pero puede ser una cadena vacía) y, por lo tanto, nunca se devuelve como "undef".

No se devuelve ningún valor significativo si esta función se llama en contexto escalar.

$uri = uri_join($scheme, $auth, $path, $query, $frag)
Une una cadena de URI a partir de sus partes. Las partes que faltan se indican pasando "undef" para el argumento correspondiente.

Se aplica un escape mínimo a las partes que contienen caracteres reservados que confundirían a un analizador. Por ejemplo, cualquier ocurrencia de '?' o '#' en $path siempre se escapa, ya que de lo contrario se analizaría de nuevo como consulta o fragmento.

VER TAMBIÉN

URI, URI::Escape
