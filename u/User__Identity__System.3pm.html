NOMBRE

User::Identity::System - sistema físico de una persona

HERENCIA

User::Identity::System
  es un User::Identity::Item

SINOPSIS

use User::Identity;
use User::Identity::System;
my $yo   = User::Identity->new(...);
my $servidor = User::Identity::System->new(...);
$yo->add(system => $servidor);
# Más simple
use User::Identity;
my $yo   = User::Identity->new(...);
my $dir = $yo->add(system => ...);

DESCRIPCIÓN

El objeto "User::Identity::System" contiene la descripción de la presencia del usuario en un sistema. Los sistemas son recopilados por un objeto User::Identity::Collection::Systems.

Casi todos los métodos pueden devolver "undef".

Extiende "DESCRIPCIÓN" en User::Identity::Item.

Crea un nuevo sistema. Puedes especificar un nombre como primer argumento, o en la lista de OPCIONES. Sin un nombre específico, se utiliza la organización como nombre.

description => CADENA
hostname => DOMINIO
El nombre de host del sistema descrito. Se prefiere usar nombres de sistema completos, no abreviaturas. Por ejemplo, es mejor usar "www.tux.aq" que "www" para evitar confusiones.
location => SOBRENOMBRE|OBJETO
El SOBRENOMBRE de una ubicación que está definida para el mismo usuario. También puedes especificar un OBJETO User::Identity::Location.
name => CADENA
os => CADENA
El nombre del sistema operativo que se ejecuta en el servidor. Se aconseja usar los nombres tal como los usa la variable $^O de Perl. Consulta la página del manual perlvar para esta variable, y perlport para los valores posibles.
parent => OBJETO
password => CADENA
La contraseña a utilizar para iniciar sesión. Esta contraseña debe estar sin codificar: directamente utilizable. Ten en cuenta que almacenar contraseñas sin codificar es un alto riesgo de seguridad.
username => CADENA
El nombre de usuario a utilizar para iniciar sesión en este host.

DIAGNÓSTICOS

Error: $object no es una colección.
El primer argumento es un objeto, pero no de una clase que extienda User::Identity::Collection. Llamado desde addCollection()
Error: No se puede cargar el módulo de colección para $tipo ($clase).
O bien el $tipo especificado no existe, o el módulo llamado $clase devuelve errores de compilación. Si el tipo especificado en la advertencia no es el nombre de un paquete, especificaste un sobrenombre que no estaba definido. Quizás olvidaste 'require' el paquete que define el sobrenombre. Llamado desde addCollection()
Error: La creación de una colección a través de $clase falló.
La clase $clase compiló, pero no fue posible crear un objeto de esa clase usando las opciones que especificaste. Llamado desde addCollection()
Error: No se sabe qué tipo de colección quieres añadir.
Si añades una colección, debe ser un objeto de colección o una lista de opciones que se puedan usar para crear un objeto de colección. En este último caso, se debe especificar el tipo de colección. Llamado desde addCollection()
Advertencia: No hay colección $nombre
La colección con $nombre no existe y no se puede crear. Llamado desde add()
