Unicode::Stringprep::Unassigned(3pm) Documentación de Perl aportada por el usuario Unicode::Stringprep::Unassigned(3pm)

NOMBRE

Unicode::Stringprep::Unassigned - Tablas del RFC 3454, Apéndice A

SINOPSIS

@Unicode::Stringprep::Unassigned::A1  # Apéndice A.1

DESCRIPCIÓN

Las tablas se proporcionan como arrays, que contienen pares de puntos de código Unicode (como enteros) que definen el inicio y el final de un rango Unicode.

Este módulo no exporta nada.
