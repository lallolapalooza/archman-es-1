UFFDIO_POISON(2const) UFFDIO_POISON(2const)

NOMBRE

UFFDIO_POISON - marcar un rango de direcciones como "envenenado"

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_POISON, ...);
#include <linux/userfaultfd.h>
struct uffdio_poison {
	struct uffdio_range  range;
	                  /* Rango para instalar marcadores PTE envenenados */
	__u64   mode;     /* Banderas que controlan el comportamiento del envenenamiento */
	__s64   updated;  /* Número de bytes envenenados, o error negado */
};

DESCRIPCIÓN

Marca un rango de direcciones como "envenenado". Los accesos futuros a estas direcciones generarán una señal SIGBUS. A diferencia de MADV_HWPOISON, esto funciona instalando entradas de tabla de páginas, en lugar de "realmente" envenenar las páginas físicas subyacentes. Esto significa que solo afecta a este espacio de direcciones en particular.

El siguiente valor puede ser ORed bit a bit en mode para cambiar el comportamiento de la operación UFFDIO_POISON:

UFFDIO_POISON_MODE_DONTWAKE
No despertar al hilo que espera la resolución de fallos de página.

El campo updated es utilizado por el kernel para devolver el número de bytes que fueron realmente envenenados, o un error de la misma manera que UFFDIO_COPY. Si el valor devuelto en el campo updated no coincide con el valor especificado en range.len, la operación falla con el error EAGAIN. El campo updated es de solo salida; no es leído por la operación UFFDIO_POISON.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En este caso, toda el área fue envenenada.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EAGAIN
El número de bytes mapeados (es decir, el valor devuelto en el campo updated) no es igual al valor especificado en el campo range.len.
EINVAL
O range.start o range.len no eran múltiplos del tamaño de página del sistema; o range.len era cero; o el rango especificado no era válido.
EINVAL
Se especificó un bit inválido en el campo mode.
EEXIST
Una o más páginas ya estaban mapeadas en el rango dado.
ENOENT
El proceso que causó el fallo ha cambiado su disposición de memoria virtual simultáneamente con una operación UFFDIO_POISON pendiente.
ENOMEM
Falló la asignación de memoria para las entradas de tabla de páginas.
ESRCH
El proceso que causó el fallo ha terminado en el momento de una operación UFFDIO_POISON.

Linux.
