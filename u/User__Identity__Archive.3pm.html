User::Identity::Archive(3) Documentación de Perl aportada por el usuario User::Identity::Archive(3)

NOMBRE

User::Identity::Archive - clase base para archivar información de usuarios

HERENCIA

User::Identity::Archive
  es un User::Identity::Item
User::Identity::Archive es extendido por
  User::Identity::Archive::Plain

SINOPSIS

use User::Identity::Archive::Plain;
my $amigos = User::Identity::Archive::Plain->new('amigos');
$amigos->from(\*FH);
$amigos->from('.amigos');

DESCRIPCIÓN

Un archivo almacena colecciones. Depende del tipo de archivo cómo y dónde se hace eso. Algunos archivadores pueden limitar los tipos de selecciones que se pueden almacenar.

Extiende "DESCRIPCIÓN" en User::Identity::Item.

Acceso al archivo

$obj->from($fuente, %options)
Lee definiciones de la $fuente especificada, la cual usualmente puede ser un manejador de archivo o un nombre de archivo. La sintaxis utilizada en la información $fuente depende del archivador.

No todos los archivadores implementan from(), así que podrías querer verificar con UNIVERSAL::can() antes.

» ejemplo:

use User::Identity::Archive::Some;
my $a = User::Identity::Archive::Some->new('xyz');
$a->from(\*STDIN) if $a->can('from');

DIAGNÓSTICOS

Error: $objeto no es una colección.
El primer argumento es un objeto, pero no de una clase que extienda User::Identity::Collection. Lanzado por addCollection()
Error: No se puede cargar el módulo de colección para $tipo ($clase).
O bien el $tipo especificado no existe, o ese módulo llamado $clase devuelve errores de compilación. Si el tipo como se especifica en la advertencia no es el nombre de un paquete, especificaste un apodo que no estaba definido. Quizás olvidaste 'require' el paquete que define el apodo. Lanzado por addCollection()
Error: La creación de una colección a través de $clase falló.
La $clase se compiló, pero no fue posible crear un objeto de esa clase utilizando las opciones que especificaste. Lanzado por addCollection()
Error: No se sabe qué tipo de colección quieres añadir.
Si añades una colección, debe ser un objeto de colección o una lista de opciones que puedan usarse para crear un objeto de colección. En este último caso, se debe especificar el tipo de colección. Lanzado por addCollection()
Advertencia: No hay colección $nombre
La colección con $nombre no existe y no se puede crear. Lanzado por add()
