DESCRIPCIÓN

Un método contiene algunas funciones que implementan el nivel bajo de la Interfaz de Usuario. Estas funciones son:

un abridor
Esta función toma una referencia a una UI y comienza una sesión, por ejemplo, abriendo un canal a un tty, o creando una ventana de diálogo.
un escritor
Esta función toma una referencia a una UI y una cadena UI, y escribe la cadena donde sea apropiado, tal vez al tty, tal vez añadida como una etiqueta de campo en una ventana de diálogo. Tenga en cuenta que esto recibe todas las cadenas asociadas con una UI, una tras otra, por lo que se debe tener cuidado con cuáles utiliza realmente.
un limpiador
Esta función toma una referencia a una UI y limpia todo lo que se ha emitido hasta ahora. Por ejemplo, si el método construye una ventana de diálogo, esto se puede usar para mostrarla realmente y aceptar la entrada finalizada con un botón presionado.
un lector
Esta función toma una referencia a una UI y una cadena UI, y lee el mensaje proporcionado, tal vez desde el tty, tal vez desde un campo en una ventana de diálogo. Tenga en cuenta que esto recibe todas las cadenas asociadas con una UI, una tras otra, por lo que se debe tener cuidado con cuáles utiliza realmente.
un cerrador
Esta función toma una referencia a una UI y cierra la sesión, tal vez cerrando el canal al tty, tal vez destruyendo una ventana de diálogo.

Se espera que todas estas funciones devuelvan 0 en caso de error, 1 en caso de éxito, o -1 para eventos fuera de banda, por ejemplo, si se ha cancelado alguna solicitud (al presionar Ctrl-C, por ejemplo). Solo se espera que el limpiador o el lector devuelvan -1. Si lo devuelven otras funciones, se trata como si se hubiera devuelto 0.

Con respecto al escritor y al lector, no asuma que el primero solo debe escribir y no asuma que el segundo solo debe leer. Esto depende de las necesidades del método.

Por ejemplo, un lector de tty típico no escribiría los mensajes en el escritor, sino que lo haría en el lector, debido a la naturaleza secuencial de las solicitudes en un tty. Así es como lo hace el método UI_OpenSSL().

En contraste, un método que construye una ventana de diálogo añadiría todo el texto del mensaje en el escritor, leería toda la entrada en el limpiador y almacenaría los resultados en algún búfer temporal, y finalmente el lector simplemente recuperaría esos resultados.

La función central que utiliza estas funciones de método es UI_process(), y lo hace en cinco pasos:

1.
Abre la sesión usando la función abridora si está definida. Si ocurre un error, salta al paso 5.
2.
Para cada Cadena UI asociada con la UI, llama a la función escritora si está definida. Si ocurre un error, salta al paso 5.
3.
Limpia todo usando la función limpiadora si está definida. Si ocurre un error, salta al paso 5.
4.
Para cada Cadena UI asociada con la UI, llama a la función lectora si está definida. Si ocurre un error, salta al paso 5.
5.
Cierra la sesión usando la función cerradora si está definida.

UI_create_method() crea un nuevo método UI con un nombre dado.

UI_destroy_method() destruye el método UI dado ui_method.

UI_method_set_opener(), UI_method_set_writer(), UI_method_set_flusher(), UI_method_set_reader() y UI_method_set_closer() establecen las cinco funciones principales del método al puntero de función dado.

UI_method_set_data_duplicator() establece el duplicador y destructor de datos del usuario. Ver UI_dup_user_data(3).

UI_method_set_prompt_constructor() establece el constructor de mensajes. Ver UI_construct_prompt(3).

UI_method_set_ex_data() establece datos específicos de la aplicación con un índice EX_DATA dado. Ver CRYPTO_get_ex_new_index(3) para obtener información general sobre cómo obtener ese índice.

UI_method_get_opener(), UI_method_get_writer(), UI_method_get_flusher(), UI_method_get_reader(), UI_method_get_closer(), UI_method_get_data_duplicator(), UI_method_get_data_destructor() y UI_method_get_prompt_constructor() devuelven las diferentes funciones del método.

UI_method_get_ex_data() devuelve un puntero a los datos específicos de la aplicación asociados con el método.

VALORES DE RETORNO

UI_create_method() devuelve un puntero UI_METHOD en caso de éxito, NULL en caso de error.

UI_method_set_opener(), UI_method_set_writer(), UI_method_set_flusher(), UI_method_set_reader(), UI_method_set_closer(), UI_method_set_data_duplicator() y UI_method_set_prompt_constructor() devuelven 0 en caso de éxito, -1 si el método dado es NULL.

UI_method_set_ex_data() devuelve 1 en caso de éxito y 0 en caso de error (porque CRYPTO_set_ex_data() lo hace).

UI_method_get_opener(), UI_method_get_writer(), UI_method_get_flusher(), UI_method_get_reader(), UI_method_get_closer(), UI_method_get_data_duplicator(), UI_method_get_data_destructor() y UI_method_get_prompt_constructor() devuelven el puntero de función solicitado si está establecido en el método, de lo contrario, NULL.

UI_method_get_ex_data() devuelve un puntero a los datos específicos de la aplicación asociados con el método.

VER TAMBIÉN

UI(3), CRYPTO_get_ex_data(3), UI_STRING(3)

HISTORIA

Las funciones UI_method_set_data_duplicator(), UI_method_get_data_duplicator() y UI_method_get_data_destructor() se añadieron en OpenSSL 1.1.1.
