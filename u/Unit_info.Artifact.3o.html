DOCUMENTACIÓN

Módulo Artifact
: sig end

Artefactos de compilación

type t

Metadatos para un artefacto de compilación individual:

-el nombre del módulo asociado al artefacto

-la ruta del sistema de archivos

-el archivo fuente de entrada si existe

val source_file : t -> Unit_info.filename option

source_file a es el archivo fuente de a si existe.

val prefix : t -> Unit_info.file_prefix

prefix a es el prefijo del nombre de archivo del artefacto de compilación.

val filename : t -> Unit_info.filename

filename u es la ruta del sistema de archivos para un artefacto de compilación.

val modname : t -> Unit_info.modname

modname a es el nombre del módulo del artefacto de compilación.

val from_filename : Unit_info.filename -> t

from_filename filename reconstruye el nombre del módulo lax_modname_from_source filename asociado al artefacto filename .
