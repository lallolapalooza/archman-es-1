NOMBRE

URI::data - URI que contiene datos inmediatos

SINOPSIS

use URI;
$u = URI->new("data:");
$u->media_type("image/gif");
$u->data(scalar(`cat camel.gif`));
print "$u\n";
open(XV, "|xv -") and print XV $u->data;

DESCRIPCIÓN

La clase "URI::data" soporta objetos "URI" pertenecientes al esquema URI data. El esquema URI data está especificado en el RFC 2397. Permite la inclusión de pequeños elementos de datos como datos "inmediatos", como si hubieran sido incluidos externamente. Ejemplos:

data:,Perl%20is%20good
data:image/gif;base64,R0lGODdhIAAgAIAAAAAAAPj8+CwAAAAAI
  AAgAAAClYyPqcu9AJyCjtIKc5w5xP14xgeO2tlY3nWcajmZZdeJcG
  Kxrmimms1KMTa1Wg8UROx4MNUq1HrycMjHT9b6xKxaFLM6VRKzI+p
  KS9XtXpcbdun6uWVxJXA8pNPkdkkxhxc21LZHFOgD2KMoQXa2KMWI
  JtnE2KizVUkYJVZZ1nczBxXlFopZBtoJ2diXGdNUymmJdFMAADs=

"URI" objetos pertenecientes al esquema data soportan los métodos comunes (descritos en URI) y los siguientes dos métodos específicos del esquema:

$uri->media_type( [$new_media_type] )
Se puede usar para obtener o establecer el tipo de medio especificado en la URI. Si no se especifica ningún tipo de medio, se devolverá el valor predeterminado "text/plain;charset=US-ASCII".
$uri->data( [$new_data] )
Se puede usar para obtener o establecer los datos contenidos en la URI. Los datos se pasan sin escapar (en formato binario). La decisión sobre si codificar los datos en base64 en la URI se toma automáticamente, basándose en la codificación que produce la cadena de URI más corta.
