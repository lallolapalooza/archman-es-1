UFFDIO_UNREGISTER(2const) UFFDIO_UNREGISTER(2const)

NOMBRE

UFFDIO_UNREGISTER - anular el registro de un rango de direcciones de memoria de userfaultfd

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_UNREGISTER, const struct uffdio_range *argp);

DESCRIPCIÓN

Anula el registro de un rango de direcciones de memoria de userfaultfd. Las páginas en el rango deben ser “compatibles” (ver UFFDIO_REGISTER(2const)).

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
Ya sea argp->start o los campos argp->len no eran un múltiplo del tamaño de página del sistema; o el campo argp->len era cero; o estos campos eran inválidos de alguna otra manera.
EINVAL
Hubo un mapeo incompatible en el rango de direcciones especificado.
EINVAL
No hubo ningún mapeo en el rango de direcciones especificado.

ESTÁNDARES

Linux.

HISTORIAL

Linux 4.3.

EJEMPLOS

Ver userfaultfd(2).

VER TAMBIÉN

ioctl(2), ioctl_userfaultfd(2), UFFDIO_REGISTER(2const), userfaultfd(2)
