Error: La creación de una colección a través de $clase falló.

Error: No sé qué tipo de colección quieres añadir.

User::Identity::Collection::Emails(3pm)

NAME

User::Identity::Collection::Emails - Represents a collection of email addresses.

INHERITANCE

This is a subclass of User::Identity::Collection.

SYNOPSIS

use User::Identity::Collection::Emails;

my $emails = User::Identity::Collection::Emails->new;

$emails->add( 'example@example.com' );
$emails->add( 'another@example.org' );

my $it = $emails->iterator;
while ( my $email = $it->next ) {
    print "Found email: $email\n";
}

# Fetch a specific email type, if defined
my $primary_email = $emails->get( 'primary' );

# Check if an email exists
if ( $emails->has( 'example@example.com' ) ) {
    print "Email exists.\n";
}

# Remove an email
$emails->remove( 'another@example.org' );

DESCRIPTION

This class represents a collection of email addresses associated with a user. It inherits functionality from the base User::Identity::Collection class and provides specific methods for handling email addresses.

Email addresses can be added to the collection, iterated over, checked for existence, and retrieved. You can also assign types to email addresses, such as 'primary', to identify specific addresses within the collection.

OVERLOADED

None.

METHODS

add( $email, [$type] )
Adds an email address to the collection. An optional type can be specified (e.g., 'primary').
get( [$type] )
Retrieves an email address by its type. If no type is specified, it returns the first email in the collection.
has( $email )
Checks if a given email address exists in the collection.
remove( $email )
Removes a specific email address from the collection.
iterator()
Returns an iterator for the email addresses in the collection.

DIAGNOSTICS

This class does not generate any specific diagnostics beyond those inherited from User::Identity::Collection.
