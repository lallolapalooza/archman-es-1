NOMBRE

URI::ws - Esquema URI para Identificadores de WebSocket

SINOPSIS

use URI::ws;
my $uri = URI->new('ws://example.com/');

DESCRIPCIÓN

Este módulo implementa el esquema URI "ws:" definido en RFC 6455 http://tools.ietf.org/html/rfc6455.

SUBRUTINAS/MÉTODOS

Este módulo hereda el comportamiento de URI::http.
