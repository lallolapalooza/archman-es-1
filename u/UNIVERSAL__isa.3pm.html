UNIVERSAL::isa(3) Documentación de Perl contribuida por el usuario UNIVERSAL::isa(3)

NOMBRE

UNIVERSAL::isa - Intenta recuperarse de personas que llaman a UNIVERSAL::isa como una función

VERSIÓN

versión 1.20171012

SINOPSIS

# desde la shell
echo 'export PERL5OPT=-MUNIVERSAL::isa' >> /etc/profile
# dentro de tu programa
use UNIVERSAL::isa;
# habilita advertencias para todos los usos dudosos de UNIVERSAL::isa
use UNIVERSAL::isa 'verbose';

DESCRIPCIÓN

Cada vez que usas "isa" en UNIVERSAL como una función, un gatito que usa Test::MockObject muere. Normalmente, los gatitos estarían indefensos, pero si usan UNIVERSAL::isa (el módulo cuya documentación estás leyendo), los gatitos pueden vivir mucho tiempo y prosperar.

Este módulo reemplaza "UNIVERSAL::isa" con una versión que asegura que, cuando se llama como función en objetos que sobrescriben "isa", "isa" llamará al método apropiado en esos objetos.

En todos los demás casos, se llama directamente a la "UNIVERSAL::isa" real.

NOTA: Debes usar este módulo solo con fines de depuración. No debe ser una dependencia en código en ejecución.

FUNCIONES

original_isa

Esta subrutina contiene la definición de la definición original de "UNIVERSAL::isa", en caso de que la necesites.

ADVERTENCIAS

Si el pragma de advertencias léxicas está disponible, este módulo emitirá una advertencia por cada invocación indebida de "UNIVERSAL::isa". Silencia estas advertencias diciendo:

no warnings 'UNIVERSAL::isa';

en el ámbito léxico del código indebido.

Después de la versión 1.00, las advertencias solo aparecen cuando el código indebido llama a UNIVERSAL::isa() como función en un invocante para el cual existe un isa() sobrescrito. Estos son verdaderos errores *activos*, y deberías arreglarlos en lugar de depender de este módulo para encontrarlos.

Para obtener advertencias de todos los usos potencialmente peligrosos de UNIVERSAL::isa() como función, no como método (es decir, para *todos* los usos del método como función, que son errores latentes, si no errores que romperán tu código tal como existe ahora), pasa el indicador "verbose" al usar el módulo. Esto puede generar muchas advertencias adicionales, pero son más específicas del error real y generalmente sugieren correcciones apropiadas.

VER TAMBIÉN

Perl::Critic::Policy::BuiltinFunctions::ProhibitUniversalIsa

UNIVERSAL::can para otra discusión del problema en cuestión.

Test::MockObject para un ejemplo de módulo que realmente necesita sobrescribir isa().

Cualquier explicación decente de POO para entender por qué llamar métodos como funciones es una idea increíblemente mala.
