UI_UTIL_read_pw(3ssl)

Paquete: openssl

Licencias: Apache-2.0

UI_UTIL_READ_PW(3ssl) OpenSSL UI_UTIL_READ_PW(3ssl)

NOMBRE

UI_UTIL_read_pw_string, UI_UTIL_read_pw, UI_UTIL_wrap_read_pem_callback - utilidades de interfaz de usuario

SINOPSIS

#include <openssl/ui.h>
int UI_UTIL_read_pw_string(char *buf, int length, const char *prompt,
                           int verify);
int UI_UTIL_read_pw(char *buf, char *buff, int size, const char *prompt,
                    int verify);
UI_METHOD *UI_UTIL_wrap_read_pem_callback(pem_password_cb *cb, int rwflag);

DESCRIPCIÓN

UI_UTIL_read_pw_string() solicita una contraseña, utilizando prompt como mensaje, y la almacena en buf. El tamaño máximo permitido se indica con length, incluido el byte NUL de terminación. Si verify es distinto de cero, la contraseña también se verificará.

UI_UTIL_read_pw() hace lo mismo que UI_UTIL_read_pw_string(), la diferencia es que puede proporcionarle un buffer externo buff para la contraseña de verificación.

UI_UTIL_wrap_read_pem_callback() se puede usar para crear un UI_METHOD temporal que envuelve una función de devolución de llamada de contraseña PEM dada cb. rwflag se usa para especificar si este método se usará para la entrada de contraseña sin (0) o con (1) verificación. Cuando ya no se use, el método devuelto debe liberarse con UI_destroy_method().

NOTAS

UI_UTIL_read_pw_string() y UI_UTIL_read_pw() usan el UI_METHOD predeterminado. Consulte UI_get_default_method(3) y similares para obtener más información.

El resultado de UI_METHOD creado por UI_UTIL_wrap_read_pem_callback() generará cadenas de contraseña en la codificación que genera la función de devolución de llamada de contraseña dada. Las funciones de solicitud de contraseña predeterminadas (aparte de UI_UTIL_read_pw_string() y UI_UTIL_read_pw(), existen PEM_def_callback(), EVP_read_pw_string() y EVP_read_pw_string_min()) utilizan todas el UI_METHOD predeterminado.

VALORES DE RETORNO

UI_UTIL_read_pw_string() y UI_UTIL_read_pw() devuelven 0 en caso de éxito o un valor negativo en caso de error.

UI_UTIL_wrap_read_pem_callback() devuelve una estructura UI_METHOD válida o NULL si ocurrió un error.
