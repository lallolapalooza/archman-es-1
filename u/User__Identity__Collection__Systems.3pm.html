NOMBRE

User::Identity::Collection::Systems - una colección de descripciones de sistemas

HERENCIA

User::Identity::Collection::Systems
  es un User::Identity::Collection
  es un User::Identity::Item

SINOPSIS

DESCRIPCIÓN

El objeto User::Identity::Collection::Systems mantiene un conjunto de objetos User::Identity::System, cada uno describiendo un inicio de sesión para el usuario en algún sistema.

Extiende "DESCRIPCIÓN" en User::Identity::Collection.

DIAGNÓSTICOS

Error: $object no es una colección.
El primer argumento es un objeto, pero no de una clase que extienda User::Identity::Collection. Lanzado por addCollection()
Error: No se puede crear un $tipo para añadir esto a mi colección.
Se especifican algunas opciones para crear un objeto $tipo, que es nativo de esta colección. Sin embargo, por alguna razón esto falló. Lanzado por addRole()
Error: No se puede cargar el módulo de colección para $tipo ($clase).
O el $tipo especificado no existe, o ese módulo llamado $clase devuelve errores de compilación. Si el tipo como se especifica en la advertencia no es el nombre de un paquete, especificaste un apodo que no estaba definido. Quizás olvidaste el 'require' del paquete que define el apodo. Lanzado por addCollection()
Error: No se puede renombrar $nombre a $nombrenuevo: ya existe
Lanzado por renameRole()
Error: No se puede renombrar $nombre a $nombrenuevo: no existe
Lanzado por renameRole()
Error: La creación de una colección a través de $clase falló.
La $clase se compiló, pero no fue posible crear un objeto de esa clase utilizando las opciones que especificaste. Lanzado por addCollection()
Error: No se sabe qué tipo de colección se desea agregar.
Si agregas una colección, debe ser un objeto de colección o una lista de opciones que se puedan usar para crear un objeto de colección. En este último caso, se debe especificar el tipo de colección. Lanzado por addCollection()
Advertencia: No hay colección $nombre
La colección con $nombre no existe y no se puede crear. Lanzado por add()
Error: Tipo incorrecto de rol para $coleccion: requiere un $esperado pero se obtuvo un $tipo
Cada $coleccion agrupa conjuntos de roles de un tipo específico ($esperado). No puedes agregar objetos de un $tipo diferente. Lanzado por addRole()
