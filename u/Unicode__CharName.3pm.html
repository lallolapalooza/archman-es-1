NOMBRE

Unicode::CharName - Buscar nombres de caracteres Unicode

SINOPSIS

use Unicode::CharName qw(uname ublock);
print uname(ord('%')), "\n";
print ublock(0x0300), "\n";

DESCRIPCIÓN

Este módulo proporciona dos funciones llamadas uname() y ublock(). La función uname() devolverá el nombre del carácter Unicode para el código dado (un número entre 0 y 0x10FFFF). Los nombres de caracteres Unicode se escriben en letras mayúsculas ASCII, y son cadenas como:

LATIN CAPITAL LETTER A
LATIN SMALL LETTER A WITH RING ABOVE
CJK UNIFIED IDEOGRAPH 7C80
HANGUL SYLLABLE PWILH

La función ublock() devolverá el nombre del bloque de caracteres Unicode al que pertenece el carácter dado.
