Unicode::Normalize(3perl) Guía de Referencia del Programador de Perl Unicode::Normalize(3perl)

NOMBRE

Unicode::Normalize - Formas de Normalización Unicode

SINOPSIS

(1) usando nombres de función exportados por defecto:

use Unicode::Normalize;
$NFD_string  = NFD($string);  # Forma de Normalización D
$NFC_string  = NFC($string);  # Forma de Normalización C
$NFKD_string = NFKD($string); # Forma de Normalización KD
$NFKC_string = NFKC($string); # Forma de Normalización KC

(2) usando nombres de función exportados bajo demanda:

use Unicode::Normalize 'normalize';
$NFD_string  = normalize('D',  $string);  # Forma de Normalización D
$NFC_string  = normalize('C',  $string);  # Forma de Normalización C
$NFKD_string = normalize('KD', $string);  # Forma de Normalización KD
$NFKC_string = normalize('KC', $string);  # Forma de Normalización KC

DESCRIPCIÓN

Parámetros:

$string se usa como una cadena bajo semántica de caracteres (ver perlunicode).

$code_point debe ser un entero sin signo que represente un punto de código Unicode.

Nota: Entre XSUB y Perl puro, existe una incompatibilidad en la interpretación de $code_point como un número decimal. XSUB convierte $code_point a un entero sin signo, pero Perl puro no lo hace. No use un punto flotante ni un signo negativo en $code_point.

Formas de Normalización

"$NFD_string = NFD($string)"
Devuelve la Forma de Normalización D (formada por descomposición canónica).
"$NFC_string = NFC($string)"
Devuelve la Forma de Normalización C (formada por descomposición canónica seguida de composición canónica).
"$NFKD_string = NFKD($string)"
Devuelve la Forma de Normalización KD (formada por descomposición de compatibilidad).
"$NFKC_string = NFKC($string)"
Devuelve la Forma de Normalización KC (formada por descomposición de compatibilidad seguida de composición **canónica**).
"$FCD_string = FCD($string)"
Si la cadena dada está en forma FCD ("Fast C or D"; ver UTN #5), devuelve la cadena sin modificar; de lo contrario, devuelve una cadena FCD.

Nota: FCD no siempre es única, entonces las formas plurales pueden ser equivalentes entre sí. FCD() devolverá una de estas formas equivalentes.

"$FCC_string = FCC($string)"
Devuelve la forma FCC ("Fast C Contiguous"; ver UTN #5).

Nota: FCC es única, al igual que las cuatro formas de normalización (NF*).

"$normalized_string = normalize($form_name, $string)"
Devuelve la forma de normalización de $form_name.

Como $form_name, se debe dar uno de los siguientes nombres.

'C'  o 'NFC'  para Forma de Normalización C  (UAX #15)
'D'  o 'NFD'  para Forma de Normalización D  (UAX #15)
'KC' o 'NFKC' para Forma de Normalización KC (UAX #15)
'KD' o 'NFKD' para Forma de Normalización KD (UAX #15)
'FCD'          para Forma "Fast C or D"  (UTN #5)
'FCC'          para "Fast C Contiguous" (UTN #5)

Descomposición y Composición

"$decomposed_string = decompose($string [, $useCompatMapping])"
Devuelve la concatenación de la descomposición de cada carácter en la cadena.

Si el segundo parámetro (un booleano) se omite o es falso, la descomposición es canónica; si el segundo parámetro (un booleano) es verdadero, la descomposición es de compatibilidad.

La cadena devuelta no siempre está en forma NFD/NFKD. Puede ser necesario reordenar.

$NFD_string  = reorder(decompose($string));       # eq. a NFD()
$NFKD_string = reorder(decompose($string, TRUE)); # eq. a NFKD()
"$reordered_string = reorder($string)"
Devuelve el resultado de reordenar los caracteres combinados según el Comportamiento de Ordenación Canónica.

Por ejemplo, cuando tiene una lista de cadenas NFD/NFKD, puede obtener la cadena NFD/NFKD concatenada de ellas, diciendo:

$concat_NFD  = reorder(join '', @NFD_strings);
$concat_NFKD = reorder(join '', @NFKD_strings);
"$composed_string = compose($string)"
Devuelve el resultado de la composición canónica sin aplicar ninguna descomposición.

Por ejemplo, cuando tiene una cadena NFD/NFKD, puede obtener su cadena NFC/NFKC, diciendo:

$NFC_string  = compose($NFD_string);
$NFKC_string = compose($NFKD_string);
"($processed, $unprocessed) = splitOnLastStarter($normalized)"
Devuelve dos cadenas: la primera, $processed, es la parte anterior al último iniciador, y la segunda, $unprocessed es la parte posterior a la primera parte. Un iniciador es un carácter que tiene una clase combinada de cero (ver UAX #15).

Tenga en cuenta que $processed puede estar vacío (cuando $normalized no contiene iniciadores o comienza con el último iniciador), y entonces $unprocessed debería ser igual a la totalidad de $normalized.

Cuando tiene una cadena $normalized y una cadena $unnormalized siguiéndola, una simple concatenación es incorrecta:

$concat = $normalized . normalize($form,$unprocessed); # incorrecto!

En lugar de eso, haga esto:

($processed, $unprocessed) = splitOnLastStarter($normalized);
$concat = $processed . normalize($form,$unprocessed.$unnormalized);

splitOnLastStarter() debería ser llamada con un parámetro pre-normalizado $normalized, que esté en la misma forma que el $form que desea.

Si tiene un array de @string que debe ser concatenado y luego normalizado, puede hacerlo así:

my $result = "";
my $unproc = "";
foreach my $str (@string) {
    $unproc .= $str;
    my $n = normalize($form, $unproc);
    my($p, $u) = splitOnLastStarter($n);
    $result .= $p;
    $unproc  = $u;
}
$result .= $unproc;
# en lugar de normalize($form, join('', @string))
"$processed = normalize_partial($form, $unprocessed)"
Un envoltorio para la combinación de normalize() y splitOnLastStarter(). Tenga en cuenta que $unprocessed se modificará como efecto secundario.

Si tiene un array de @string que debe ser concatenado y luego normalizado, puede hacerlo así:

my $result = "";
my $unproc = "";
foreach my $str (@string) {
    $unproc .= $str;
    $result .= normalize_partial($form, $unproc);
}
$result .= $unproc;
# en lugar de normalize($form, join('', @string))
"$processed = NFD_partial($unprocessed)"
Hace lo mismo que "normalize_partial('NFD', $unprocessed)". Tenga en cuenta que $unprocessed se modificará como efecto secundario.
"$processed = NFC_partial($unprocessed)"
Hace lo mismo que "normalize_partial('NFC', $unprocessed)". Tenga en cuenta que $unprocessed se modificará como efecto secundario.
"$processed = NFKD_partial($unprocessed)"
Hace lo mismo que "normalize_partial('NFKD', $unprocessed)". Tenga en cuenta que $unprocessed se modificará como efecto secundario.
"$processed = NFKC_partial($unprocessed)"
Hace lo mismo que "normalize_partial('NFKC', $unprocessed)". Tenga en cuenta que $unprocessed se modificará como efecto secundario.

Verificación Rápida

(ver Anexo 8, UAX #15; y lib/unicore/DerivedNormalizationProps.txt)

Las siguientes funciones verifican si la cadena está en esa forma de normalización.

El resultado devuelto será uno de los siguientes:

YES     La cadena está en esa forma de normalización.
NO      La cadena no está en esa forma de normalización.
MAYBE   Dudoso. Tal vez sí, tal vez no.
"$result = checkNFD($string)"
Devuelve verdadero (1

FUNCTIONS

"$result = checkNFD($string)"
Devuelve verdadero (1) si "YES"; falso ("cadena vacía") si "NO".
"$result = checkNFKD($string)"
Devuelve verdadero (1) si "YES"; falso ("cadena vacía") si "NO".
"$result = checkNFKC($string)"
Devuelve verdadero (1) si "YES"; falso ("cadena vacía") si "NO"; "undef" si "MAYBE".
"$result = checkFCD($string)"
Devuelve verdadero (1) si "YES"; falso ("cadena vacía") si "NO".
"$result = checkFCC($string)"
Devuelve verdadero (1) si "YES"; falso ("cadena vacía") si "NO"; "undef" si "MAYBE".

Nota: Si una cadena no está en FCD, no debe estar en FCC. Así que checkFCC($not_FCD_string) debería devolver "NO".

"$result = check($form_name, $string)"
Devuelve verdadero (1) si "YES"; falso ("cadena vacía") si "NO"; "undef" si "MAYBE".

Como $form_name, se debe dar uno de los siguientes nombres.

'C'  o 'NFC'  para Forma Normalizada C  (UAX #15)
'D'  o 'NFD'  para Forma Normalizada D  (UAX #15)
'KC' o 'NFKC' para Forma Normalizada KC (UAX #15)
'KD' o 'NFKD' para Forma Normalizada KD (UAX #15)
'FCD'          para "Fast C or D" Form  (UTN #5)
'FCC'          para "Fast C Contiguous" (UTN #5)

Nota

En los casos de NFD, NFKD y FCD, la respuesta debe ser "YES" o "NO". La respuesta "MAYBE" puede ser devuelta en los casos de NFC, NFKC y FCC.

Una cadena "MAYBE" debe contener al menos un carácter combinatorio o similar. Por ejemplo, "ACENTO AGUDO COMBINATORIO" tiene la propiedad MAYBE_NFC/MAYBE_NFKC.

Tanto "checkNFC("A\N{ACENTO AGUDO COMBINATORIO}")" como "checkNFC("B\N{ACENTO AGUDO COMBINATORIO}")" devolverán "MAYBE". "A\N{ACENTO AGUDO COMBINATORIO}" no está en NFC (su NFC es "\N{LETRA LATINA MAYÚSCULA A CON ACENTO AGUDO}"), mientras que "B\N{ACENTO AGUDO COMBINATORIO}" está en NFC.

Si quieres comprobar exactamente, compara la cadena con su NFC/NFKC/FCC.

if ($string eq NFC($string)) {
    # $string está exactamente normalizado en NFC;
} else {
    # $string no está normalizado en NFC;
}
if ($string eq NFKC($string)) {
    # $string está exactamente normalizado en NFKC;
} else {
    # $string no está normalizado en NFKC;
}

Datos de Caracter

Estas funciones son la interfaz de los datos de caracteres utilizados internamente. Si solo quieres obtener las formas de normalización Unicode, no necesitas llamarlas tú mismo.

"$canonical_decomposition = getCanon($code_point)"
Si el carácter es canónicamente descomponible (incluyendo Sílabas Hangul), devuelve la descomposición canónica (completa) como una cadena. De lo contrario, devuelve "undef".

Nota: Según el estándar Unicode, la descomposición canónica del carácter que no es canónicamente descomponible es igual al carácter mismo.

"$compatibility_decomposition = getCompat($code_point)"
Si el carácter es compatibilidad descomponible (incluyendo Sílabas Hangul), devuelve la descomposición de compatibilidad (completa) como una cadena. De lo contrario, devuelve "undef".

Nota: Según el estándar Unicode, la descomposición de compatibilidad del carácter que no es compatibilidad descomponible es igual al carácter mismo.

"$code_point_composite = getComposite($code_point_here, $code_point_next)"
Si dos caracteres aquí y el siguiente (como puntos de código) son componibles (incluyendo Jamo/Sílabas Hangul y Exclusiones de Composición), devuelve el punto de código del compuesto.

Si no son componibles, devuelve "undef".

"$combining_class = getCombinClass($code_point)"
Devuelve la clase combinatoria (como entero) del carácter.
"$may_be_composed_with_prev_char = isComp2nd($code_point)"
Devuelve un booleano si el carácter del punto de código especificado puede ser compuesto con el anterior en una cierta composición (incluyendo Composiciones Hangul, pero excluyendo Exclusiones de Composición y Descomposiciones No Iniciadoras).
"$is_exclusion = isExclusion($code_point)"
Devuelve un booleano si el punto de código es una exclusión de composición.
"$is_singleton = isSingleton($code_point)"
Devuelve un booleano si el punto de código es un singleton
"$is_non_starter_decomposition = isNonStDecomp($code_point)"
Devuelve un booleano si el punto de código tiene una Descomposición No Iniciadora.
"$is_Full_Composition_Exclusion = isComp_Ex($code_point)"
Devuelve un booleano de la propiedad derivada Comp_Ex (Full_Composition_Exclusion). Esta propiedad se genera a partir de Exclusiones de Composición + Singletons + Descomposiciones No Iniciadoras.
"$NFD_is_NO = isNFD_NO($code_point)"
Devuelve un booleano de la propiedad derivada NFD_NO (NFD_Quick_Check=No).
"$NFC_is_NO = isNFC_NO($code_point)"
Devuelve un booleano de la propiedad derivada NFC_NO (NFC_Quick_Check=No).
"$NFC_is_MAYBE = isNFC_MAYBE($code_point)"
Devuelve un booleano de la propiedad derivada NFC_MAYBE (NFC_Quick_Check=Maybe).
"$NFKD_is_NO = isNFKD_NO($code_point)"
Devuelve un booleano de la propiedad derivada NFKD_NO (NFKD_Quick_Check=No).
"$NFKC_is_NO = isNFKC_NO($code_point)"
Devuelve un booleano de la propiedad derivada NFKC_NO (NFKC_Quick_Check=No).
"$NFKC_is_MAYBE = isNFKC_MAYBE($code_point)"
Devuelve un booleano de la propiedad derivada NFKC_MAYBE (NFKC_Quick_Check=Maybe).

EXPORT

"NFC", "NFD", "NFKC", "NFKD": por defecto.

"normalize" y otras funciones: bajo petición.

ADVERTENCIAS

Versión de Perl vs. versión de Unicode
Dado que este módulo hace referencia a la base de datos Unicode del núcleo de Perl en el directorio /lib/unicore (o anteriormente /lib/unicode), la versión de Unicode de la normalización implementada por este módulo depende de lo que se haya compilado en tu Perl. La siguiente tabla enumera la versión de Unicode por defecto que viene con varias versiones de Perl. (Es posible cambiar la versión de Unicode en cualquier versión de Perl a cualquier versión anterior de Unicode, por lo que se podría hacer que Unicode 3.2 se utilice en cualquier versión de Perl a partir de 5.8.0. Lee $Config{privlib}/unicore/README.perl para más detalles.

   5.7.2              3.1.0
   5.7.3              3.1.1 (normalización es igual que 3.1.0)
   5.8.0              3.2.0
     5.8.1-5.8.3      4.0.0
     5.8.4-5.8.6      4.0.1 (normalización es igual que 4.0.0)
     5.8.7-5.8.8      4.1.0
   5.10.0             5.0.0

Corrección de mapeo de descomposición
En versiones anteriores de Unicode, un pequeño número de caracteres (todos ellos ideogramas de compatibilidad CJK hasta donde se han encontrado) pueden tener un mapeo de descomposición erróneo (ver lib/unicore/NormalizationCorrections.txt). De todos modos, este módulo no hará referencia a lib/unicore/NormalizationCorrections.txt ni proporcionará ninguna versión específica de normalización. Por lo tanto, este módulo que se ejecuta en una versión anterior de Perl con una base de datos Unicode anterior puede utilizar el mapeo de descomposición erróneo, conformándose ciegamente a la base de datos Unicode.
Definición revisada de composición canónica
En Unicode 4.1.0, la definición D2 de composición canónica (que afecta a NFC y NFKC) ha sido modificada (ver Public Review Issue #29 y UAX #15 reciente). Este módulo ha utilizado la definición más reciente desde la versión 0.07 (31 de oct de 2001). Este módulo no admitirá la normalización según la definición anterior, incluso si la versión de Unicode implementada por Perl es anterior a 4.1.0.
