User::Identity::Location(3) Documentación de Perl contribuida por usuarios User::Identity::Location(3)

NOMBRE

User::Identity::Location - ubicación física de una persona

HERENCIA

User::Identity::Location
  es un User::Identity::Item

SINOPSIS

use User::Identity;
use User::Identity::Location;
my $me   = User::Identity->new(...);
my $addr = User::Identity::Location->new(...);
$me->add(location => $addr);
# Más simple
use User::Identity;
my $me   = User::Identity->new(...);
my $addr = $me->add(location => ...);

DESCRIPCIÓN

El objeto "User::Identity::Location" contiene la descripción de una ubicación física de una persona: hogar, trabajo, viaje. Las ubicaciones son recopiladas por un objeto User::Identity::Collection::Locations.

Casi todos los métodos pueden devolver "undef". Algunos métodos producen resultados específicos del idioma o del país.

Extiende "DESCRIPCIÓN" en User::Identity::Item.

Uno o más números de fax, como phone().
$obj->fullAddress()
Crea una dirección para enviar por correo postal, en el formato normal en el país de destino. Para poder lograr esto, se debe conocer el código del país. Si la ciudad no está especificada o no se proporcionan calle o apartado postal, se devolverá "undef": una dirección incompleta.

$obj->organization()
La organización (por ejemplo, empresa) relacionada con esta ubicación.
$obj->phone()
Uno o más números de teléfono. Por favor, utilice la notación internacional, que comienza con '+', por ejemplo "+31-26-12131". En contexto escalar, solo se produce el primer número. En contexto de lista, se presentan todos los números.
$obj->pobox()
Especificación del apartado de correos. Use "P.O.Box 314", no solo 314.
$obj->poboxPostalCode()
El código postal relacionado con el apartado de correos. Definido por la opción "pobox_pc" de new().
$obj->postalCode()
El código postal es muy dependiente del país. Además, la ubicación del código dentro de la cadena formateada depende del país.
$obj->state()
El estado, que es importante para algunos países pero ciertamente no para los más pequeños. Solo establezca este valor cuando su estado deba aparecer en direcciones impresas.
$obj->street()
Devuelve la dirección de esta ubicación. Desde Perl 5.7.3, puedes usar unicode en cadenas, así que ¿por qué no formatear la dirección correctamente?

User::Identity::Location(3pm)

NAME

User::Identity::Location - defines how to find a user

INHERITANCE

User::Identity::Location(3pm) is a subclass of User::Identity(3pm).

SYNOPSIS

  use User::Identity;
  
  my $id = User::Identity->new(
      remote_host => $host,
      remote_port => $port,
      remote_addr => $ip,
      local_host  => $lhost,
      local_port  => $lport,
      local_addr  => $lip,
  );
  
  # get the location information
  my $location = $id->location;
  
  # retrieve specific information
  my $country_code = $location->country_code;
  my $city_name    = $location->city_name;
  my $country_name = $location->country_name;
  my $continent    = $location->continent;
  my $iso_country  = $location->iso_country;
  my $timezone     = $location->timezone;
  my $latitude     = $location->latitude;
  my $longitude    = $location->longitude;

DESCRIPTION

This module tries to find the geographical location of the user connecting to your system. It uses the IP address of the remote host and queries an external database (like MaxMind) to find the country, city, continent, timezone, etc. where the connection originates.

The database is not part of this distribution. You must obtain it separately. Many GeoIP databases are available for free on the web.

The results of the location lookup are cached so that repeated lookups for the same IP address are fast.

The implementation uses an object oriented approach. A User::Identity object is created for each connection, and the location method on that object returns a User::Identity::Location object.

METHODS

The following methods are implemented by User::Identity::Location:

country_code()
Returns the two-letter country code (e.g. 'US', 'DE', 'FR').
city_name()
Returns the name of the city.
country_name()
Returns the name of the country.
continent()
Returns the name of the continent.
iso_country()
Returns the ISO 3166 numeric country code.
timezone()
Returns the timezone name (e.g. 'America/New_York').
latitude()
Returns the latitude of the location.
longitude()
Returns the longitude of the location.
region_name()
Returns the name of the region (state/province).
postal_code()
Returns the postal code.

DIAGNOSTICS
