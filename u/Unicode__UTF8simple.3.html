Unicode__UTF8simple(3)

Paquete: perl-unicode-utf8simple

Licencias: GPL, PerlArtistic

UTF8simple(3) Documentación de Perl contribuida por el usuario UTF8simple(3)

NOMBRE

Unicode::UTF8simple - Conversiones de/hacia UTF8 desde/hacia conjuntos de caracteres

SINOPSIS

use Unicode::UTF8simple;

my $uref = new Unicode::UTF8simple;
# convertir una cadena (aquí: schön) a una cadena de bytes utf8 
my $utf8string=$uref->toUTF8("iso-8859-1","schön");
# convertir una cadena de utf-8 a la codificación especificada
my $string=$uref->fromUTF8("iso-8859-1",$utf8string);
# obtener una lista de codificaciones soportadas:
my @listOfNames=$uref->enclist();
# comprobar si una codificación dada (aquí gb2312) es soportada
if ($uref->encsup('gb2312')){ ... }

DESCRIPCIÓN

Proporciona conversión UTF-8 para versiones de perl 5.00 y superiores. Fue escrito principalmente para su uso con perl 5.00 a 5.6.0 porque esas versiones de perl no soportan Unicode::MapUTF8 ni Encode.

Unicode::UTF8simple está escrito en perl puro (sin código C) y funcionará con cualquier versión de Perl 5. Es solo un poco más lento que Encode.
