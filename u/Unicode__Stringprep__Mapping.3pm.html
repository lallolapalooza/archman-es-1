Unicode::Stringprep::Mapping(3pm) Documentación de Perl aportada por el usuario Unicode::Stringprep::Mapping(3pm)

NOMBRE

Unicode::Stringprep::Mapping - Tablas del RFC 3454, apéndice B

SINOPSIS

@Unicode::Stringprep::Mapping::B1     # Apéndice B.1
@Unicode::Stringprep::Mapping::B2     # Apéndice B.2
@Unicode::Stringprep::Mapping::B3     # Apéndice B.3

DESCRIPCIÓN

Las tablas se proporcionan como arrays, que contienen pares de un punto de código Unicode (como entero) y cadenas de reemplazo (como cadena perl UTF8).

Este módulo no exporta nada.
