NOMBRE

User::Identity::Item - clase base general para User::Identity

HERENCIA

User::Identity::Item es extendido por
  Mail::Identity
  User::Identity
  User::Identity::Archive
  User::Identity::Collection
  User::Identity::Location
  User::Identity::System

SINOPSIS

DESCRIPCION

La clase base "User::Identity::Item" se extiende en módulos útiles: no tiene uso por sí misma.

MÉTODOS

Constructores

$class->new( [$name], %options )
-Opción     --Default
 description  undef
 name         <requerido>
 parent       undef
description => CADENA
Descripción de formato libre sobre el elemento recopilado.
name => CADENA
Un nombre simple para este elemento. Intente dar un nombre útil en el contexto del tiempo del elemento. Cada vez que busque elementos, necesitará especificar este nombre, por lo que debe ser único y no difícil de manejar en su programa. Por ejemplo, cuando se dirige a una persona, normalmente le dará un apodo.
parent => OBJETO
El objeto que lo encapsula: el objeto que recopila este.

Atributos

$obj->description()
Descripción de formato libre sobre este elemento. Por favor, no añada ningún significado al contenido de este campo: si necesita un atributo adicional, póngase en contacto con el autor del módulo para implementarlo, o extienda el objeto para satisfacer sus necesidades.
$obj->name( [$newname] )
El nuevo nombre de este elemento. Los nombres son únicos dentro de una colección... un segundo objeto con el mismo nombre dentro de cualquier colección destruirá el objeto ya existente con ese nombre.

Cambiar el nombre de un elemento es bastante peligroso. Probablemente deseará llamar a User::Identity::Collection::renameRole() en su lugar.

Colecciones

$obj->add($collection, $role)
El $role se añade a la $collection. El $collection es el nombre de una colección, que se creará automáticamente con addCollection() si es necesario. El $collection también se puede especificar como un objeto de colección existente.

El $role es cualquier cosa que sea aceptable para User::Identity::Collection::addRole() de la colección en cuestión, y se devuelve. El $role típicamente es una lista de parámetros para un rol, o una referencia a un array que contiene estos valores.

» ejemplo:

my $ui   = User::Identity->new(...);
my $home = $ui->add(location => [home => street => '27 Roadstreet', ...] );
my $work = $ui->add(location => work, tel => '+31-2231-342-13', ... );
my $travel = User::Identity::Location->new(travel => ...);
$ui->add(location => $travel);
my $system = User::Identity::Collection::System->new(...);
$ui->add($system => 'localhost');
$obj->addCollection( $object | <[$type], %options> )
Añade una nueva colección de roles a un elemento. Esto se puede lograr de dos maneras: o bien crea un User::Identity::Collection $object usted mismo y luego lo pasa a este método, o bien suministra todas las %options necesarias para crear dicho objeto y se creará para usted. Se devuelve el objeto que se añade, y se puede utilizar para muchos métodos directamente.

Para %options, consulte el tipo específico de colección. Las opciones adicionales se enumeran a continuación.

-Opción--Default
 type    <requerido>
type => CADENA|CLASE
El apodo de una clase de colección o el nombre de CLASE en sí mismo del objeto a crear. Requerido si se debe crear un objeto. Los apodos de tipo predefinidos son "email", "system" y "location".

» ejemplo:

my $me   = User::Identity->new(...);
my $locs = User::Identity::Collection::Locations->new();
$me->addCollection($locs);
my $email = $me->addCollection(type => 'email');
my $email = $me->addCollection('email');
$obj->collection($name)
En contexto escalar, se devuelve el objeto de colección con el $name. En contexto de lista, se devuelven todos los roles dentro de la colección.

» ejemplo:

my @roles = $me->collection('email');        # lista de elementos recopilados
my @roles = $me->collection('email')->roles; # lo mismo de elementos recopilados
my $coll  = $me->collection('email');        # una User::Identity::Collection
$obj->parent( [$parent] )
Devuelve el padre de un Elemento (el elemento envolvente). Puede devolver "undef" si el objeto es autónomo.
$obj->removeCollection($object|$name)
$any->type()
Devuelve un nombre simbólico agradable para el tipo.
$obj->user()
Ir de este objeto a su padre, a su padre, y así sucesivamente, hasta que se encuentre un User::Identity o se haya alcanzado la cima del árbol de objetos.

» ejemplo:

print $email->user->fullName;

Búsqueda

$obj->find($collection, $role)
Devuelve el objeto con el $role especificado dentro de la colección con nombre. La colección se puede especificar como nombre o como objeto.

» ejemplo:

my $role  = $me->find(location => 'work');       # una ubicación
my $role  = $me->collection('location')->find('work'); # lo mismo
my $email = $me->addCollection('email');
$me->find($email => 'work');
$email->find('work');   # lo mismo

DIAGNÓSTICOS

Error: $object no es una colección.
El primer argumento es un objeto, pero no de una clase que extienda User::Identity::Collection. Se crea a través de addCollection()
Error: No se puede cargar el módulo de colección para $type ($class).
O bien el $type especificado no existe, o el módulo llamado $class devuelve errores de compilación. Si el tipo especificado en la advertencia no es el nombre de un paquete, ha especificado un apodo que no estaba definido. Quizás olvidó el 'require' del paquete que define el apodo. Se crea a través de addCollection()
Error: Falló la creación de una colección a través de $class.
La $class se compiló, pero no fue posible crear un objeto de esa clase utilizando las opciones que especificó. Se crea a través de addCollection()
Error: No sé qué tipo de colección desea añadir.
Si añade una colección, debe ser un objeto de colección o una lista de opciones que se puedan utilizar para crear un objeto de colección. En este último caso, se debe especificar el tipo de colección. Se crea a través de addCollection()
Error: Cada elemento requiere un nombre
Tiene que especificar un nombre para cada elemento. Estos nombres deben ser únicos dentro de una colección, pero siéntase libre de dar el mismo nombre a una dirección de correo electrónico y a una ubicación. Se crea a través de

DIAGNOSTICOS

Advertencia: No existe la colección $name
La colección con $name no existe y no se puede crear. Llamada por add()
Advertencia: Opción desconocida $name para un $class
Una opción utilizada no está definida. Consulte la página del manual de la clase para ver qué opciones se aceptan. Llamada por new()
Advertencia: Opciones desconocidas @names para un $class
Más de una opción no está definida. Llamada por new()
