NOMBRE

URI::geo - Esquema URI para identificadores geo

SINOPSIS

use URI;
# URI Geo desde URI textual
my $guri = URI->new( 'geo:54.786989,-2.344214' );
# Desde coordenadas
my $guri = URI::geo->new( 54.786989, -2.344214 );
# Decodificar
my ( $lat, $lon, $alt ) = $guri->location;
my $latitude = $guri->latitude;
# Actualizar
$guri->location( 55, -1 );
$guri->longitude( -43.23 );

DESCRIPCIÓN

De http://geouri.org/:

Cada vez más protocolos y formatos de datos se extienden con métodos
para añadir información geográfica. Sin embargo, todas esas opciones están ligadas
a ese protocolo o formato de datos específico.
Un esquema de Identificador Uniforme de Recursos (URI) dedicado para ubicaciones
geográficas sería independiente de cualquier protocolo, utilizable por cualquier
software/formato de datos que pueda manejar URIs genéricas. Al igual que una
URI "mailto:" lanza tu aplicación de correo favorita hoy en día, una URI "geo:"
podría pronto lanzar tu servicio de mapas favorito, o poner en cola esa ubicación para
un dispositivo de navegación.

SUBRUTINAS/MÉTODOS

"new"

Crea un nuevo URI::geo. Los argumentos deben ser uno de los siguientes:

  • latitud, longitud y opcionalmente altitud
  • una referencia a un array que contenga lat, lon, alt
  • una referencia a un hash con claves adecuadamente nombradas o
  • una referencia a un objeto con accesores adecuadamente nombrados

Para maximizar la probabilidad de que puedas pasar algún objeto que represente una ubicación geográfica y que URI::geo haga lo correcto, probamos varios nombres de accesores diferentes.

Si el objeto tiene un método "latlong" (por ejemplo, Geo::Point) lo usaremos. Si hay un método "location", lo llamaremos. De lo contrario, buscamos accesores llamados "lat", "latitude", "lon", "long", "longitude", "ele", "alt", "elevation" o "altitude" y los usamos.

A menudo, si tienes un objeto o referencia a hash que representa un punto, puedes pasarlo directamente a "new"; así, por ejemplo, esto funcionará:

use URI::geo;
use Geo::Point;
my $pt = Geo::Point->latlong( 48.208333, 16.372778 );
my $guri = URI::geo->new( $pt );

Al igual que esto:

my $guri = URI::geo->new( { lat => 55, lon => -1 } );

Y esto:

my $guri = URI::geo->new( 55, -1 );

Ten en cuenta que también puedes crear un nuevo "URI::geo" pasando una URI Geo a "URI::new":

use URI;
my $guri = URI->new( 'geo:55,-1' );

"location"

Obtiene o establece la ubicación de esta URI geo.

my ( $lat, $lon, $alt ) = $guri->location;
$guri->location( 55.3, -3.7, 120 );

Al establecer la ubicación, es posible pasar cualquiera de los tipos de argumentos que se pueden pasar a "new".

"latitude"

Obtiene o establece la latitud de esta URI geo.

"longitude"

Obtiene o establece la longitud de esta URI geo.

"altitude"

Obtiene o establece la altitud https://en.wikipedia.org/wiki/Geo_URI_scheme#Altitude de esta URI geo. Para eliminar la altitud, establécela a "undef".

"crs"

Obtiene o establece el Sistema de Referencia de Coordenadas https://en.wikipedia.org/wiki/Geo_URI_scheme#Coordinate_reference_systems de esta URI geo. Para eliminar el CRS, establécelo a "undef".

"uncertainty"

Obtiene o establece la incertidumbre https://en.wikipedia.org/wiki/Geo_URI_scheme#Uncertainty de esta URI geo. Para eliminar la incertidumbre, establécela a "undef".

DIAGNÓSTICOS

"Demasiados argumentos"
El método new solo puede aceptar tres parámetros: latitud, longitud y altitud.
"No sé cómo convertir el punto"
El método new no sabe cómo convertir los parámetros proporcionados en un objeto URI::geo.
"Necesito lat, lon o lat, lon, alt"
El método new necesita dos (latitud y longitud) o tres (latitud, longitud y altitud) parámetros en una lista. Cualquier cantidad menor o mayor que esta es un error.
"No existe tal campo: %s"
Este campo no es un campo conocido para el objeto URI::geo.
"URI geo mal formada"
La URI no se puede analizar como una URI
"URI geo mal formada"
La URI no se puede analizar como una URI
"Latitud fuera de rango"
La latitud solo puede estar entre -90 y +90
"Longitud fuera de rango"
La longitud solo puede estar entre -180 y +180
