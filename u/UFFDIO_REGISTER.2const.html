UFFDIO_REGISTER(2const) UFFDIO_REGISTER(2const)

NOMBRE

UFFDIO_REGISTER - registrar un rango de direcciones de memoria con el objeto userfaultfd

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_REGISTER, struct uffdio_register *argp);
#include <linux/userfaultfd.h>
struct uffdio_range {
    __u64  start;   /* Inicio del rango */
    __u64  len;     /* Tamaño del rango (bytes) */
};
struct uffdio_register {
    struct uffdio_range  range;
    __u64                mode;    /* Modo de operación deseado (entrada) */
    __u64                ioctls;  /* ioctl()s disponibles (salida) */
};

DESCRIPCIÓN

Registra un rango de direcciones de memoria con el objeto userfaultfd. Las páginas en el rango deben ser "compatibles". Por favor, consulte la lista de modos de registro a continuación para los backends de memoria compatibles para cada modo.

El campo argp->range define un rango de memoria que comienza en argp->range.start y continúa durante argp->range.len bytes que deben ser manejados por el userfaultfd.

El campo argp->mode define el modo de operación deseado para esta región de memoria. Los siguientes valores pueden combinarse bit a bit para establecer el modo userfaultfd para el rango especificado:

UFFDIO_REGISTER_MODE_MISSING
Rastrea fallos de página en páginas faltantes. Desde Linux 4.3, solo los rangos anónimos privados son compatibles. Desde Linux 4.11, los rangos hugetlbfs y de memoria compartida también son compatibles.
UFFDIO_REGISTER_MODE_WP
Rastrea fallos de página en páginas protegidas contra escritura. Desde Linux 5.7, solo los rangos anónimos privados son compatibles.
UFFDIO_REGISTER_MODE_MINOR
Rastrea fallos de página menores. Desde Linux 5.13, solo los rangos hugetlbfs son compatibles. Desde Linux 5.14, se agregó compatibilidad con rangos shmem.

Si la operación es exitosa, el kernel modifica el campo de máscara de bits argp->ioctls para indicar qué operaciones ioctl(2) están disponibles para el rango especificado. Esta máscara de bits devuelta puede contener los siguientes bits:

1 << _UFFDIO_COPY
La operación UFFDIO_COPY es compatible.
1 << _UFFDIO_WAKE
La operación UFFDIO_WAKE es compatible.
1 << _UFFDIO_WRITEPROTECT
La operación UFFDIO_WRITEPROTECT es compatible.
1 << _UFFDIO_ZEROPAGE
La operación UFFDIO_ZEROPAGE es compatible.
1 << _UFFDIO_CONTINUE
La operación UFFDIO_CONTINUE es compatible.
1 << _UFFDIO_POISON
La operación UFFDIO_POISON es compatible.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EBUSY
Un mapeo en el rango especificado está registrado con otro objeto userfaultfd.
EFAULT
argp se refiere a una dirección que está fuera del espacio de direcciones accesible del proceso llamante.
EINVAL
Se especificó un bit inválido o no compatible en el campo mode; o el campo mode era cero.
EINVAL
No hay ningún mapeo en el rango de direcciones especificado.
EINVAL
range.start o range.len no es un múltiplo del tamaño de página del sistema; o, range.len es cero; o estos campos son inválidos de alguna otra manera.
EINVAL
Había un mapeo incompatible en el rango de direcciones especificado.

ESTÁNDARES

Linux.

HISTORIA
