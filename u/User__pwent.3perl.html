NOMBRE

User::pwent - Interfaz por nombre a las funciones integradas getpw*() de Perl

SINOPSIS

use User::pwent;
my $pw = getpwnam('daemon')       || die "No existe el usuario daemon";
if ( $pw->uid == 1 && $pw->dir =~ m#^/(bin|tmp)?\z#s ) {
    print "gid 1 en el directorio raíz";
}
my $real_shell = $pw->shell || '/bin/sh';
for (my ($fullname, $office, $workphone, $homephone) =
       split /\s*,\s*/, $pw->gecos)
{
   s/&/ucfirst(lc($pw->name))/ge;
}
use User::pwent qw(:FIELDS);
getpwnam('daemon')             || die "No existe el usuario daemon";
if ( $pw_uid == 1 && $pw_dir =~ m#^/(bin|tmp)?\z#s ) {
    print "gid 1 en el directorio raíz";
}
my $pw = getpw($whoever);
use User::pwent qw/:DEFAULT pw_has/;
if (pw_has(qw[gecos expire quota])) { .... }
if (pw_has("name uid gid passwd"))  { .... }
print "La estructura pwd tiene: ", scalar pw_has(), "\n";

DESCRIPCIÓN

Las exportaciones por defecto de este módulo anulan las funciones centrales getpwent(), getpwuid() y getpwnam(), reemplazándolas por versiones que devuelven objetos "User::pwent". Este objeto tiene métodos que devuelven el nombre del campo de la estructura C passwd de pwd.h con el prefijo "pw_" eliminado, a saber: "name", "passwd", "uid", "gid", "change", "age", "quota", "comment", "class", "gecos", "dir", "shell", y "expire". Los campos "passwd", "gecos", y "shell" están marcados (tainted) cuando se ejecutan en modo marcado.

También puede importar todos los campos de la estructura directamente a su espacio de nombres como variables regulares utilizando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto todavía anula sus funciones centrales.) Acceda a estos campos como variables con un prefijo "pw_" delante de sus nombres de método. Por lo tanto, "$passwd_obj->shell" corresponde a $pw_shell si importa los campos.

La función getpw() es una interfaz simple que reenvía un argumento numérico a getpwuid() y el resto a getpwnam().

Para acceder a esta funcionalidad sin las anulaciones centrales, pase a "use" una lista de importación vacía y luego acceda a las funciones con sus nombres completos y calificados. Las funciones integradas siempre están disponibles a través del pseudo-paquete "CORE::".

Especificidades del sistema

Perl cree que ninguna máquina tiene más de uno de "change", "age", o "quota" implementado, ni más de uno de "comment" o "class". Algunas máquinas no admiten "expire", "gecos", o supuestamente, "passwd". Puede llamar a estos métodos sin importar, sin importar en qué máquina se encuentre, pero devuelven "undef" si no están implementados.

Puede preguntar si uno de estos se implementó en el sistema para el que se compiló Perl preguntando a la función importable "pw_has" al respecto. Esta función devuelve verdadero si todos los parámetros son campos compatibles en la plataforma de compilación, falso si uno o más no lo fueron, y genera una excepción si preguntó sobre un campo que Perl nunca sabe cómo proporcionar. Los parámetros pueden estar en una cadena separada por espacios o como argumentos separados. Si no pasa parámetros, la función devuelve la lista de campos de la "struct pwd" compatibles con la biblioteca C de su plataforma de compilación, como una lista en contexto de lista, o una cadena separada por espacios en contexto de escalar. Tenga en cuenta que el hecho de que su biblioteca C tuviera un campo no significa necesariamente que esté completamente implementado en ese sistema.

La interpretación del campo "gecos" varía entre sistemas, pero tradicionalmente contiene 4 campos separados por comas que contienen el nombre completo del usuario, la ubicación de la oficina, el número de teléfono del trabajo y el número de teléfono de casa. Un "&" en el campo gecos debe reemplazarse por el nombre de inicio de sesión del usuario correctamente capitalizado. El campo "shell", si está en blanco, debe asumirse que es /bin/sh. Perl no hace esto por usted. La "passwd" es un cifrado unidireccional, no texto plano, y no se puede descifrar excepto mediante adivinación por fuerza bruta. Los sistemas seguros utilizan un cifrado más seguro que DES. En los sistemas que admiten sistemas de contraseñas shadow, Perl devuelve automáticamente la entrada de contraseña shadow cuando es llamado por un usuario debidamente autorizado, incluso si su biblioteca C subyacente proporcionada por el proveedor no fue lo suficientemente previsora como para darse cuenta de que debería hacerlo.

Consulte passwd(5) y getpwent(3) para obtener detalles.
