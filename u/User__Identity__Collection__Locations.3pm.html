NOMBRE

User::Identity::Collection::Locations - una colección de ubicaciones

HERENCIA

User::Identity::Collection::Locations
  es un User::Identity::Collection
  es un User::Identity::Item

SINOPSIS

DESCRIPCION

El objeto "User::Identity::Collection::Location" mantiene un conjunto de objetos User::Identity::Location, cada uno describiendo una ubicación física.

Extiende "DESCRIPCION" en User::Identity::Collection.

DIAGNÓSTICOS

Error: $object no es una colección.
El primer argumento es un objeto, pero no de una clase que extienda User::Identity::Collection. Lanzado por addCollection()
Error: No se puede crear un $type para añadir a mi colección.
Se especifican algunas opciones para crear un objeto $type, que es nativo de esta colección. Sin embargo, por alguna razón esto falló. Lanzado por addRole()
Error: No se puede cargar el módulo de colección para $type ($class).
O bien el $type especificado no existe, o el módulo llamado $class devuelve errores de compilación. Si el tipo, tal como se especifica en la advertencia, no es el nombre de un paquete, se especificó un apodo que no estaba definido. Quizás olvidó el 'require' del paquete que define el apodo. Lanzado por addCollection()
Error: No se puede renombrar $name a $newname: ya existe
Lanzado por renameRole()
Error: No se puede renombrar $name a $newname: no existe
Lanzado por renameRole()
Error: La creación de una colección a través de $class falló.
La $class compiló, pero no fue posible crear un objeto de esa clase usando las opciones que especificó. Lanzado por addCollection()
Error: No sé qué tipo de colección desea añadir.
Si añade una colección, debe ser un objeto de colección o una lista de opciones que se puedan usar para crear un objeto de colección. En este último caso, se debe especificar el tipo de colección. Lanzado por addCollection()
Advertencia: No hay colección $name
La colección con $name no existe y no se puede crear. Lanzado por add()
Error: Tipo de rol incorrecto para $collection: requiere un $expect pero se obtuvo un $type
Cada $collection agrupa conjuntos de roles de un tipo específico ($expect). No puede añadir objetos de un $type diferente. Lanzado por addRole()
