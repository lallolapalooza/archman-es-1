UFFDIO_WAKE(2const) UFFDIO_WAKE(2const)

NOMBRE

UFFDIO_WAKE - despertar un hilo que espera la resolución de fallos de página

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_WAKE, const struct uffdio_range *argp);

DESCRIPCIÓN

Despierta el hilo que está esperando la resolución de fallos de página en un rango de direcciones de memoria especificado.

La operación UFFDIO_WAKE se utiliza junto con las operaciones UFFDIO_COPY y UFFDIO_ZEROPAGE que tienen el bit UFFDIO_COPY_MODE_DONTWAKE o UFFDIO_ZEROPAGE_MODE_DONTWAKE establecido en el campo mode. El monitor de userfault puede realizar varias operaciones UFFDIO_COPY y UFFDIO_ZEROPAGE en un lote y luego despertar explícitamente el hilo que falla usando UFFDIO_WAKE.

VALOR DE RETORNO

Esta operación ioctl(2) devuelve 0 si tiene éxito. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El campo start o el campo len de la estructura ufdio_range no era un múltiplo del tamaño de página del sistema; o len era cero; o el rango especificado no era válido de otra manera.

ESTANDARES

Linux.

HISTORIA

Linux 4.3.
