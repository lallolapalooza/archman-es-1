User::Identity::Collection(3) Documentación Perl aportada por el usuario User::Identity::Collection(3)

NOMBRE

User::Identity::Collection - clase base para la recopilación de roles de un usuario

HERENCIA

User::Identity::Collection
  es un User::Identity::Item
User::Identity::Collection es extendido por
  User::Identity::Collection::Emails
  User::Identity::Collection::Locations
  User::Identity::Collection::Systems
  User::Identity::Collection::Users

SINOPSIS

use User::Identity;
use User::Identity::Collection;
my $me    = User::Identity->new(...);
my $set   = User::Identity::Collection::Emails->new(...);
$me->addCollection($set);
# Más simple
use User::Identity;
my $me    = User::Identity->new(...);
my $set   = $me->addCollection(type => 'email', ...)
my $set   = $me->addCollection('email', ...)
my @roles = $me->collection('email');  # lista de elementos recopilados
my $coll  = $me->collection('email');  # una User::Identity::Collection
my @roles = $coll->roles;
my @roles = @$coll;                    # lo mismo, por sobrecarga
my $role  = $me->collection('email')->find($coderef);
my $role  = $me->collection('location')->find('work');
my $role  = $me->find(location => 'work');

DESCRIPCION

El objeto "User::Identity::Collection" mantiene un conjunto de objetos relacionados con el usuario. Ayuda a seleccionar estos objetos, lo cual es parcialmente común a todas las colecciones (por ejemplo, cada objeto tiene un nombre, por lo que puedes buscar por nombres), y a veces específico de la extensión de esta colección.

Extensiones implementadas actualmente son:

  • people es una colección de usuarios
  • whereabouts son ubicaciones
  • una mailinglist es una

    colección de direcciones de correo electrónico

  • una network contiene

    grupos de sistemas

Extiende "DESCRIPTION" en User::Identity::Item.

SOBRECARGADO

sobrecarga: "" conversión a cadena
Devuelve el nombre de la colección y una lista ordenada de los elementos definidos.

» ejemplo:

print "$collection\n";  #   location: home, work
sobrecarga: @{} desreferencia de array
Cuando la referencia a un objeto de colección se usa como referencia de array, se mostrará como una lista de roles.

» ejemplo:

my $locations = $ui->collection('location');
foreach my $loc (@$location) ...
print $location->[0];

Mantenimiento de roles

$obj->addRole($role|([$name], %options))
Añade un nuevo rol a esta colección. $role es un objeto del tipo correcto (depende de la extensión de este módulo de qué tipo se trata) o una lista de %options que se usan para crear dicho rol. Las opciones también se pueden pasar como referencia a un ARRAY. Se devuelve el rol añadido.

» ejemplo:

my $uicl = User::Identity::Collection::Locations->new;
my $uil  = User::Identity::Location->new(home => ...);
$uicl->addRole($uil);
$uicl->addRole(  home => address => 'street 32' );
$uicl->addRole( [home => address => 'street 32'] );

Más fácil

$ui      = User::Identity;
$ui->add(location => 'home', address => 'street 32' );
$ui->add(location => [ 'home', address => 'street 32' ] );
$obj->removeRole($role|$name)
Se devuelve el rol eliminado (si existía).
$obj->renameRole( <$role|$oldname>, $newname )
Da al rol un nombre diferente y lo mueve en la colección.
$obj->sorted()
Devuelve los roles ordenados por nombre, alfabéticamente y sensibles a mayúsculas y minúsculas.

Búsqueda

Extiende "Searching" en User::Identity::Item.

$obj->find($name|CODE|undef)
Encuentra el objeto con el $name especificado en esta colección. Con "undef", se devuelve un rol seleccionado aleatoriamente.

Cuando se especifica una referencia de código, todos los roles recopilados se escanean uno tras otro (en orden desconocido). Para cada rol,

CODE->($object, $collection)

se llama. Cuando el "CODE" devuelve "true", se selecciona el rol. En contexto de lista, se devuelven todos los roles seleccionados. En contexto escalar, se devuelve la primera coincidencia y el escaneo se interrumpe inmediatamente. Mejora la base, ver "Searching" en User::Identity::Item

» ejemplo:

my $emails = $ui->collection('emails');
$emails->find('work');
sub find_work($$) {
   my ($mail, $emails) = @_;
   $mail->location->name eq 'work';
}
my @at_work = $emails->find(\&find_work);
my @at_work = $ui->find(location => \&find_work);
my $any     = $ui->find(location => undef );

DIAGNÓSTICOS

Se generan varios mensajes de error de Carp::croak o User::Identity::Error (una sub-clase de Exception::Class).

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

DIAGNÓSTICOS

Error: $object no es una colección.
El primer argumento es un objeto, pero no de una clase que extienda User::Identity::Collection. Lanzado por addCollection()
Error: No se puede crear un $type para añadirlo a mi colección.
Se especifican algunas opciones para crear un objeto $type nativo de esta colección. Sin embargo, por alguna razón esto falló. Lanzado por addRole()
Error: No se puede cargar el módulo de colección para $type ($class).
O el $type especificado no existe, o el módulo llamado $class devuelve errores de compilación. Si el tipo, tal como se especifica en la advertencia, no es el nombre de un paquete, especificaste un apodo que no estaba definido. Quizás olvidaste el 'require' del paquete que define el apodo. Lanzado por addCollection()
Error: No se puede renombrar $name a $newname: ya existe
Lanzado por renameRole()
Error: No se puede renombrar $name a $newname: no existe
Lanzado por renameRole()
Error: La creación de una colección a través de $class falló.
La $class compiló, pero no fue posible crear un objeto de esa clase usando las opciones que especificaste. Lanzado por addCollection()
Error: No se sabe qué tipo de colección deseas añadir.
Si añades una colección, debe ser un objeto de colección o una lista de opciones que se puedan usar para crear un objeto de colección. En este último caso, se debe especificar el tipo de colección. Lanzado por addCollection()
Advertencia: No hay colección $name
La colección con $name no existe y no puede ser creada. Lanzado por add()
Error: Tipo de rol incorrecto para $collection: requiere un $expect pero se obtuvo un $type
Cada $collection agrupa conjuntos de roles de un tipo específico ($expect). No puedes añadir objetos de un $type diferente. Lanzado por addRole()
