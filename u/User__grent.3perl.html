User::grent(3perl) Guía del programador de Perl User::grent(3perl)

NOMBRE

User::grent - Interfaz por nombre a las funciones incorporadas de Perl getgr*()

SINOPSIS

use User::grent;
my $gr = getgrgid(0) or die "No hay grupo cero";
if ( $gr->name eq 'wheel' && @{$gr->members} > 1 ) {
    print "gid zero name wheel, con otros miembros";
} 
use User::grent qw(:FIELDS);
getgrgid(0) or die "No hay grupo cero";
if ( $gr_name eq 'wheel' && @gr_members > 1 ) {
    print "gid zero name wheel, con otros miembros";
} 
my $gr = getgr($quien_sea);

DESCRIPCIÓN

El valor de exportación predeterminado de este módulo reemplaza las funciones principales getgrent(), getgrgid() y getgrnam(), sustituyéndolas por versiones que devuelven objetos "User::grent". Este objeto tiene métodos que devuelven el nombre de campo de estructura de C similarmente llamado desde grp.h; a saber, name, passwd, gid y members (no mem). Los tres primeros devuelven escalares, el último una referencia a una matriz.

También puede importar todos los campos de la estructura directamente a su espacio de nombres como variables regulares usando la etiqueta de importación :FIELDS. (Tenga en cuenta que esto todavía reemplaza sus funciones principales.) Acceda a estos campos como variables que comienzan con un "gr_". Por lo tanto, "$group_obj->gid()" corresponde a $gr_gid si importa los campos. Las referencias a matrices están disponibles como variables de matriz regulares, por lo que "@{ $group_obj->members() }" sería simplemente @gr_members.

La función getgr() es un simple front-end que reenvía un argumento numérico a getgrgid() y el resto a getgrnam().

Para acceder a esta funcionalidad sin los reemplazos principales, pase a "use" una lista de importación vacía y luego acceda a las funciones con sus nombres completos calificados. Por otro lado, los incorporados siguen estando disponibles a través del pseudo-paquete "CORE::".

NOTA

Si bien esta clase se implementa actualmente utilizando el módulo Class::Struct para crear una clase similar a una estructura, no debe confiar en esto.
