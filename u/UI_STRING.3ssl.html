UI_STRING(3ssl)

Paquete: openssl

Licencias: Apache-2.0

UI_STRING(3ssl) OpenSSL UI_STRING(3ssl)

NOMBRE

UI_STRING, UI_string_types, UI_get_string_type, UI_get_input_flags, UI_get0_output_string, UI_get0_action_string, UI_get0_result_string, UI_get_result_string_length, UI_get0_test_string, UI_get_result_minsize, UI_get_result_maxsize, UI_set_result, UI_set_result_ex - Análisis de cadenas de interfaz de usuario

SINOPSIS

#include <openssl/ui.h>
typedef struct ui_string_st UI_STRING;
enum UI_string_types {
    UIT_NONE = 0,
    UIT_PROMPT,                 /* Solicitar una cadena */
    UIT_VERIFY,                 /* Solicitar una cadena y verificar */
    UIT_BOOLEAN,                /* Solicitar una respuesta sí/no */
    UIT_INFO,                   /* Enviar información al usuario */
    UIT_ERROR                   /* Enviar un mensaje de error al usuario */
};
enum UI_string_types UI_get_string_type(UI_STRING *uis);
int UI_get_input_flags(UI_STRING *uis);
const char *UI_get0_output_string(UI_STRING *uis);
const char *UI_get0_action_string(UI_STRING *uis);
const char *UI_get0_result_string(UI_STRING *uis);
int UI_get_result_string_length(UI_STRING *uis);
const char *UI_get0_test_string(UI_STRING *uis);
int UI_get_result_minsize(UI_STRING *uis);
int UI_get_result_maxsize(UI_STRING *uis);
int UI_set_result(UI *ui, UI_STRING *uis, const char *result);
int UI_set_result_ex(UI *ui, UI_STRING *uis, const char *result, int len);

DESCRIPCIÓN

El UI_STRING se crea internamente y se añade a un UI cada vez que se llama a una de las funciones UI_add_input_string(), UI_dup_input_string(), UI_add_verify_string(), UI_dup_verify_string(), UI_add_input_boolean(), UI_dup_input_boolean(), UI_add_info_string(), UI_dup_info_string(), UI_add_error_string() o UI_dup_error_string(). Para un usuario de UI_METHOD, no hay necesidad de saber más. Para un creador de UI_METHOD, es de interés obtener texto de estos objetos UI_STRING, así como añadir resultados a algunos de ellos.

UI_get_string_type() se utiliza para recuperar el tipo del UI_STRING dado.

UI_get_input_flags() se utiliza para recuperar las banderas asociadas con el UI_STRING dado.

UI_get0_output_string() se utiliza para recuperar la cadena real a mostrar (solicitud, información, error, ...).

UI_get0_action_string() se utiliza para recuperar la descripción de la acción asociada con un UI_STRING de tipo UIT_BOOLEAN. Para todos los demás tipos de UI_STRING, se devuelve NULL. Consulte UI_add_input_boolean(3).

UI_get0_result_string() y UI_get_result_string_length() se utilizan para recuperar el resultado de una solicitud y su longitud. Esto solo es útil para cadenas de tipo UIT_PROMPT y UIT_VERIFY. Para todos los demás tipos de UI_STRING, UI_get0_result_string() devuelve NULL y UI_get_result_string_length() devuelve -1.

UI_get0_test_string() se utiliza para recuperar la cadena con la que comparar el resultado de la solicitud. Esto solo es útil para cadenas de tipo UIT_VERIFY. Para todos los demás tipos de UI_STRING, se devuelve NULL.

UI_get_result_minsize() y UI_get_result_maxsize() se utilizan para recuperar el tamaño mínimo y máximo requerido del resultado. Esto solo es útil para cadenas de tipo UIT_PROMPT y UIT_VERIFY. Para todos los demás tipos de UI_STRING, se devuelve -1.

UI_set_result_ex() se utiliza para establecer el valor del resultado de una solicitud y su longitud. Para las cadenas de UI de tipo UIT_PROMPT y UIT_VERIFY, esto establece el resultado recuperable con UI_get0_result_string() copiando el contenido de result si su longitud se ajusta a los requisitos de tamaño mínimo y máximo. Para las cadenas de UI de tipo UIT_BOOLEAN, esto establece el primer carácter del resultado recuperable con UI_get0_result_string() al primer ok_char proporcionado con UI_add_input_boolean() o UI_dup_input_boolean() si el result coincidió con alguno de ellos, o al primero de los cancel_chars si el result coincidió con alguno de ellos, de lo contrario se establece al carácter NUL "\0". Consulte UI_add_input_boolean(3) para obtener más información sobre ok_chars y cancel_chars.

UI_set_result() hace lo mismo que UI_set_result_ex(), pero calcula su longitud internamente. Espera que la cadena termine con un byte NUL, y por lo tanto solo es útil con cadenas normales de C.

VALORES DE RETORNO

UI_get_string_type() devuelve el tipo de cadena de UI.

UI_get_input_flags() devuelve las banderas de cadena de UI.

UI_get0_output_string() devuelve la cadena de salida de la cadena de UI.

UI_get0_action_string() devuelve la cadena de descripción de la acción de la cadena de UI para las cadenas de UI de tipo UIT_BOOLEAN, NULL para cualquier otro tipo.

UI_get0_result_string() devuelve el búfer de resultado de la cadena de UI para las cadenas de UI de tipo UIT_PROMPT y UIT_VERIFY, NULL para cualquier otro tipo.

UI_get_result_string_length() devuelve la longitud del contenido del búfer de resultado de la cadena de UI para las cadenas de UI de tipo UIT_PROMPT y UIT_VERIFY, -1 para cualquier otro tipo.

UI_get0_test_string() devuelve la cadena de descripción de la acción de la cadena de UI para las cadenas de UI de tipo UIT_VERIFY, NULL para cualquier otro tipo.

UI_get_result_minsize() devuelve el tamaño mínimo permitido del resultado para la cadena de UI para cadenas de tipo UIT_PROMPT y UIT_VERIFY, -1 para cualquier otro tipo.

UI_get_result_maxsize() devuelve el tamaño mínimo permitido del resultado para la cadena de UI para cadenas de tipo UIT_PROMPT y UIT_VERIFY, -1 para cualquier otro tipo.

UI_set_result() devuelve 0 en caso de éxito o cuando la cadena de UI es de cualquier tipo que no sea UIT_PROMPT, UIT_VERIFY o UIT_BOOLEAN, -1 en caso de error.
