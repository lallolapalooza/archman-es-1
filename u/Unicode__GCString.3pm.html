Paquete: perl-unicode-linebreak

Unicode::GCString(3) Documentación de Perl aportada por el usuario Unicode::GCString(3)

NOMBRE

Unicode::GCString - Cadena como Secuencia de Clústeres de Caracteres Grafemáticos UAX #29

SINOPSIS

use Unicode::GCString;
$gcstring = Unicode::GCString->new($string);

DESCRIPCIÓN

Unicode::GCString trata las cadenas Unicode como una secuencia de clústeres de caracteres grafemáticos extendidos definidos por el Anexo de Estándares Unicode #29 [UAX #29].

Un clúster de caracteres grafemáticos es una secuencia de uno o más caracteres Unicode que consiste en una base grafemática y opcionalmente uno o más extensores grafemáticos y/o un carácter de "precedencia". Se acerca a lo que la gente considera un carácter.

Interfase Pública

Constructores

new (CADENA, [CLAVE => VALOR, ...])
new (CADENA, [LINEBREAK])
Constructor. Crea una nueva cadena de clústeres de caracteres grafemáticos (objeto Unicode::GCString) a partir de la cadena Unicode CADENA.

Sobre las parejas opcionales CLAVE => VALOR, ver "Opciones" en Unicode::LineBreak. En la segunda forma, el objeto Unicode::LineBreak LINEBREAK controla las características de ruptura.

Nota: La primera forma se introdujo con la versión 2012.10.

copy
Constructor de copia. Crea una copia de la cadena de clústeres de caracteres grafemáticos. La siguiente posición de la nueva cadena se establece al principio.

Tamaños

chars
Método de instancia. Devuelve el número de caracteres Unicode que contiene la cadena de clústeres de caracteres grafemáticos, es decir, la longitud como cadena Unicode.
columns
Método de instancia. Devuelve el número total de columnas de los clústeres de caracteres grafemáticos definidos por la base de datos de caracteres incorporada. Para más detalles, ver "DESCRIPCIÓN" en Unicode::LineBreak.
length
Método de instancia. Devuelve el número de clústeres de caracteres grafemáticos contenidos en la cadena de clústeres de caracteres grafemáticos.

Operaciones como Cadena

as_string
"""OBJETO"""
Método de instancia. Convierte explícitamente la cadena de clústeres de caracteres grafemáticos a una cadena Unicode.
cmp (CADENA)
CADENA "cmp" CADENA
Método de instancia. Compara cadenas. No hay rarezas. Una de las CADENAS puede ser una cadena Unicode.
concat (CADENA)
CADENA "." CADENA
Método de instancia. Concatena CADENAS. Una de las CADENAS puede ser una cadena Unicode. Tenga en cuenta que el número de columnas (ver columns()) o clústeres de caracteres grafemáticos (ver length()) de la cadena resultante no siempre es igual a la suma de ambas cadenas. La siguiente posición de la nueva cadena es la establecida en el valor de la izquierda.
join ([CADENA, ...])
Método de instancia. Une CADENAS insertando la cadena de clústeres de caracteres grafemáticos. Cualquiera de las CADENAS puede ser una cadena Unicode.
substr (OFFSET, [LONGITUD, [REEMPLAZO]])
Método de instancia. Devuelve una subcadena de la cadena de clústeres de caracteres grafemáticos. OFFSET y LONGITUD se basan en clústeres de caracteres grafemáticos. Si se especifica REEMPLAZO, la subcadena se reemplaza por él. REEMPLAZO puede ser una cadena Unicode.

Nota: Este método no puede devolver el lvalue, a diferencia del substr() incorporado.

Operaciones como Secuencia de Clústeres de Caracteres Grafemáticos

as_array
"@{"OBJETO"}"
as_arrayref
Método de instancia. Convierte la cadena de clústeres de caracteres grafemáticos en un array de clústeres de caracteres grafemáticos.
eos
Método de instancia. Comprueba si la posición actual está al final de la cadena de clústeres de caracteres grafemáticos.
item ([OFFSET])
Método de instancia. Devuelve el clúster de caracteres grafemáticos de índice OFFSET. Si no se especificó OFFSET, devuelve el siguiente clúster de caracteres grafemáticos.
next
"<"OBJETO">"
Método de instancia, iterativo. Devuelve el siguiente clúster de caracteres grafemáticos e incrementa la siguiente posición.
pos ([OFFSET])
Método de instancia. Si se especifica el OFFSET opcional, establece la siguiente posición. Devuelve la siguiente posición de la cadena de clústeres de caracteres grafemáticos.

Misceláneo

lbc
Método de instancia. Devuelve la Clase de Ruptura de Línea (Ver Unicode::LineBreak) del primer carácter del primer clúster de caracteres grafemáticos.
lbcext
Método de instancia. Devuelve la Clase de Ruptura de Línea (Ver Unicode::LineBreak) del último extensor grafemático del último clúster de caracteres grafemáticos. Si no hay extensores grafemáticos o su clase es CM, se devolverá el valor de la última base grafemática.

ADVERTENCIAS

  • El clúster de caracteres grafemáticos no debe referirse como "grafema" aunque Larry lo haga.
  • En Perl alrededor de 5.10.1, la conversión implícita de un objeto Unicode::GCString a una cadena Unicode a veces confundía la caché "utf8_mg_pos_cache_update".

    Por ejemplo, en lugar de hacer

    $sub = substr($gcstring, $i, $j);

    haz

    $sub = substr("$gcstring", $i, $j);
$sub = substr($gcstring->as_string, $i, $j);
  • Este módulo implementa el algoritmo *predeterminado* para determinar los límites de los clústeres de caracteres grafemáticos. El mecanismo de adaptación aún no ha sido soportado.

VERSIÓN

Cambios Incompatibles

Release 2013.10
•
El método new() puede tomar un argumento de cadena no Unicode. En este caso, se decodificará mediante el conjunto de caracteres iso-8859-1 (Latin 1). Ese método de versiones anteriores fallaría con entradas no Unicode.

Unicode::GCString(3pm)

NAME

Unicode::GCString - Manipulate Unicode strings for line breaking

SYNOPSIS

use Unicode::GCString;

my $gstring = Unicode::GCString->new("Hello\nWorld");
$gstring->wrap(40);
print $gstring->string;

DESCRIPTION

This module provides a class Unicode::GCString to represent Unicode strings and perform line breaking operations according to the Unicode Line Breaking Algorithm (UAX #14).

It allows you to:

  • Create Unicode::GCString objects from normal strings.
  • Insert line break opportunities.
  • Wrap the string to a specified width.
  • Retrieve the modified string.

The module uses the Unicode Character Database (UCD) to determine character properties and line breaking rules.

CAVEATS

The accuracy of line breaking depends on the correctness and completeness of the Unicode data used by the module. Ensure you are using a recent version of the module and have the necessary Unicode data installed.

Complex scripts or language-specific line breaking rules might require additional logic beyond the standard UAX #14.
