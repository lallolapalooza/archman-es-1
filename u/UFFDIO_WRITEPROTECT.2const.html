UFFDIO_WRITEPROTECT(2const) UFFDIO_WRITEPROTECT(2const)

NOMBRE

UFFDIO_WRITEPROTECT - protege contra escritura o desprotege un rango de memoria registrado con userfaultfd

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_WRITEPROTECT, ...);
#include <linux/userfaultfd.h>
struct uffdio_writeprotect {
    struct uffdio_range  range;  /* Rango para cambiar el permiso de escritura*/
    __u64                mode;   /* Modo para cambiar el permiso de escritura */
};

DESCRIPCIÓN

Protege contra escritura o desprotege un rango de memoria registrado con userfaultfd con el modo UFFDIO_REGISTER_MODE_WP.

Hay dos bits de modo que son compatibles en esta estructura:

UFFDIO_WRITEPROTECT_MODE_WP
Cuando este bit de modo está activado, la llamada ioctl será una operación de protección contra escritura sobre el rango de memoria especificado por range. De lo contrario, será una operación de desprotección contra escritura sobre el rango especificado, que puede ser utilizada para resolver un fallo de página de protección contra escritura de userfaultfd.
UFFDIO_WRITEPROTECT_MODE_DONTWAKE
Cuando este bit de modo está activado, no se despertará a ningún hilo que espere la resolución de fallos de página después de la operación. Esto solo se puede especificar si UFFDIO_WRITEPROTECT_MODE_WP no está especificado.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El campo start o el campo len de la estructura ufdio_range no eran múltiplos del tamaño de página del sistema; o len era cero; o el rango especificado era de otra manera inválido.
EAGAIN
El proceso fue interrumpido; reintente esta llamada.
ENOENT
El rango especificado en range no es válido. Por ejemplo, la dirección virtual no existe, o no está registrada con el modo de protección contra escritura de userfaultfd.
EFAULT
Se encontró un fallo genérico durante el procesamiento.

ESTÁNDARES

Linux.

HISTORIA

Linux 5.7.
