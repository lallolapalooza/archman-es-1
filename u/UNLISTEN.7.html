NOMBRE

UNLISTEN - dejar de escuchar notificaciones

SINOPSIS

UNLISTEN { canal | * }

DESCRIPCIÓN

UNLISTEN se utiliza para eliminar un registro existente de eventos NOTIFY. UNLISTEN cancela cualquier registro existente de la sesión actual de PostgreSQL como oyente en el canal de notificación llamado canal. El comodín especial * cancela todos los registros de oyentes para la sesión actual.

NOTIFY(7) contiene una discusión más extensa sobre el uso de LISTEN y NOTIFY.

PARÁMETROS

canal

Nombre de un canal de notificación (cualquier identificador).

*

Se borran todos los registros de escucha actuales para esta sesión.

NOTAS

Puede dejar de escuchar algo para lo que no estaba escuchando; no aparecerá ninguna advertencia ni error.

Al final de cada sesión, se ejecuta automáticamente UNLISTEN *.

Una transacción que ha ejecutado UNLISTEN no puede prepararse para el commit en dos fases.

EJEMPLOS

Para realizar un registro:

LISTEN virtual;
NOTIFY virtual;
Notificación asíncrona "virtual" recibida del proceso del servidor con PID 8448.

Una vez ejecutado UNLISTEN, los mensajes NOTIFY posteriores serán ignorados:

UNLISTEN virtual;
NOTIFY virtual;
-- no se recibe ningún evento NOTIFY

COMPATIBILIDAD

No existe un comando UNLISTEN en el estándar SQL.

VER TAMBIÉN

LISTEN(7), NOTIFY(7)
