NOMBRE

URI::ldap - Localizadores Uniformes de Recursos LDAP

SINOPSIS

use URI;
$uri = URI->new("ldap:$uri_string");
$dn     = $uri->dn;
$filter = $uri->filter;
@attr   = $uri->attributes;
$scope  = $uri->scope;
%extn   = $uri->extensions;

$uri = URI->new("ldap:");  # empezar vacío
$uri->host("ldap.itd.umich.edu");
$uri->dn("o=University of Michigan,c=US");
$uri->attributes(qw(postalAddress));
$uri->scope('sub');
$uri->filter('(cn=Babs Jensen)');
print $uri->as_string,"\n";

DESCRIPCIÓN

"URI::ldap" proporciona una interfaz para analizar una URI LDAP en sus partes constituyentes y también para construir una URI según lo descrito en RFC 2255.

MÉTODOS

"URI::ldap" admite todos los métodos genéricos y de servidor definidos por URI, además de los siguientes.

Cada uno de los siguientes métodos puede ser utilizado para establecer o obtener el valor en la URI. Los valores se pasan sin escapar. Ninguno de estos devuelve valores indefinidos, pero los elementos sin un valor predeterminado pueden estar vacíos. Si se proporcionan argumentos, se establece un nuevo valor para la parte dada de la URI.

$uri->dn( [$new_dn] )
Establece u obtiene la parte del Nombre Distinguido de la URI. El DN identifica el objeto base de la búsqueda LDAP.
$uri->attributes( [@new_attrs] )
Establece u obtiene la lista de nombres de atributos que son devueltos por la búsqueda.
$uri->scope( [$new_scope] )
Establece u obtiene el alcance a ser utilizado por la búsqueda. El valor puede ser uno de "base", "one" o "sub". Si no se proporciona ninguno en la URI, el valor de retorno por defecto es "base".
$uri->_scope( [$new_scope] )
Igual que scope(), pero no tiene un valor por defecto.
$uri->filter( [$new_filter] )
Establece u obtiene el filtro a ser utilizado por la búsqueda. Si no se proporciona ninguno en la URI, el valor de retorno por defecto es "(objectClass=*)".
$uri->_filter( [$new_filter] )
Igual que filter(), pero no tiene un valor por defecto.
$uri->extensions( [$etype => $evalue,...] )
Establece u obtiene las extensiones utilizadas para la búsqueda. La lista proporcionada debe estar en el formato etype1 => evalue1, etype2 => evalue2,... Esta es también la forma de la lista que se devuelve.
