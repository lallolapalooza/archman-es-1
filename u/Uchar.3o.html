Módulo Uchar
: sig end

Caracteres Unicode.

Desde 4.03

type t

El tipo para caracteres Unicode.

Un valor de este tipo representa un valor escalar Unicode que es un entero en los rangos 0x0000 ... 0xD7FF o 0xE000 ... 0x10FFFF .

val min : t

min es U+0000.

val max : t

max es U+10FFFF.

val bom : t

bom es U+FEFF, el carácter de marca de orden de bytes (BOM).

Desde 4.06

val rep : t

rep es U+FFFD, el carácter de reemplazo.

Desde 4.06

val succ : t -> t

succ u es el valor escalar después de u en el conjunto de valores escalares Unicode.

Lanza Invalid_argument si u es Uchar.max .

val pred : t -> t

pred u es el valor escalar antes de u en el conjunto de valores escalares Unicode.

Lanza Invalid_argument si u es Uchar.min .

val is_valid : int -> bool

is_valid n es true si y solo si n es un valor escalar Unicode (es decir, en los rangos 0x0000 ... 0xD7FF o 0xE000 ... 0x10FFFF ).

val of_int : int -> t

of_int i es i como un carácter Unicode.

Lanza Invalid_argument si i no satisface Uchar.is_valid .

val to_int : t -> int

to_int u es u como un entero.

val is_char : t -> bool

is_char u es true si y solo si u es un carácter OCaml latin1.

val of_char : char -> t

of_char c es c como un carácter Unicode.

val to_char : t -> char

to_char u es u como un carácter latin1 de OCaml.

Lanza Invalid_argument si u no satisface Uchar.is_char .

val equal : t -> t -> bool

equal u u' es u = u' .

val compare : t -> t -> int

compare u u' es Stdlib.compare u u' .

val seeded_hash : int -> t -> int

seeded_hash seed u Una función hash sembrada con el mismo valor de salida que Hashtbl.seeded_hash . Esta función permite que este módulo se pase como argumento al functor Hashtbl.MakeSeeded .

Desde 5.3

val hash : t -> int

Una función hash no sembrada con el mismo valor de salida que Hashtbl.hash . Esta función permite que este módulo se pase como argumento al functor Hashtbl.Make .

Antes de 5.3 El algoritmo de hash era diferente. Use Hashtbl.rebuild para tablas almacenadas que utilizaban esta función de hash.

Herramientas codificadores UTF

type utf_decode

El tipo para resultados de decodificación UTF. Los valores de este tipo representan el resultado de un intento de decodificación de Formato de Transformación Unicode.

val utf_decode_is_valid : utf_decode -> bool

utf_decode_is_valid d es true si y solo si d contiene una decodificación válida.

val utf_decode_uchar : utf_decode -> t

utf_decode_uchar d es el carácter Unicode decodificado por d si utf_decode_is_valid d es true y Uchar.rep en caso contrario.

val utf_decode_length : utf_decode -> int

utf_decode_length d es el número de elementos de la fuente que fueron consumidos por la decodificación d . Esto es siempre estrictamente positivo y menor o igual a 4 . El tipo de elementos de la fuente depende del decodificador real; para los decodificadores de la librería estándar, esta función siempre devuelve una longitud en bytes.

val utf_decode : int -> t -> utf_decode

utf_decode n u es una decodificación UTF válida para u que consumió n elementos de la fuente para la decodificación. n debe ser positivo y menor o igual a 4 (esto no es verificado por el módulo).

val utf_decode_invalid : int -> utf_decode

utf_decode_invalid n es una decodificación UTF inválida que consumió n elementos de la fuente para generar un error. n debe ser positivo y menor o igual a 4 (esto no es verificado por el módulo). La decodificación resultante tiene Uchar.rep como carácter Unicode decodificado.

val utf_8_decode_length_of_byte : char -> int

utf_8_decode_length_of_byte byte es el número de bytes, de 1 a Uchar.max_utf_8_decode_length , que una decodificación UTF-8 válida comenzando con el byte byte consumiría o 0 si byte no puede iniciar una decodificación válida.

Desde 5.4

val max_utf_8_decode_length : int

max_utf_8_decode_length es 4 , el número máximo de bytes que una decodificación UTF-8 válida o inválida puede consumir.

Desde 5.4

val utf_8_byte_length : t -> int

utf_8_byte_length u es el número de bytes necesarios para codificar u en UTF-8.

val utf_16_byte_length : t -> int

utf_16_byte_length u es el número de bytes necesarios para codificar u en UTF-16.
