NOMBRE

URI::icaps - Esquema URI para Identificadores ICAPS

VERSIÓN

Versión 5.20

SINOPSIS

use URI::icaps;
my $uri = URI->new('icaps://icap-proxy.example.com/');

DESCRIPCIÓN

Este módulo implementa el esquema URI "icaps:" definido en RFC 3507 http://tools.ietf.org/html/rfc3507, para el Protocolo de Adaptación de Contenido de Internet https://en.wikipedia.org/wiki/Internet_Content_Adaptation_Protocol.

SUBRUTINAS/MÉTODOS

Este módulo hereda el comportamiento de URI::icap y anula el método securesecure>.

secure

Devuelve 1 ya que icaps es un protocolo seguro
