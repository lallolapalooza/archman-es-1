NOMBRE

URI::smb - Esquema URI de Samba/CIFS

SINOPSIS

my $uri = URI->new('smb://authdomain;user:password@server/share/path');

DESCRIPCIÓN

Este módulo implementa el esquema URI (no oficial) "smb:" descrito en http://www.ubiqx.org/cifs/Appendix-D.html.

SUBRUTINAS/MÉTODOS

puerto_predeterminado

El puerto predeterminado para acceder a servidores de archivos Samba/Windows es 445

usuario

Obtiene o establece la parte del usuario de la URI (sin el authdomain)

dominio_autenticación

Obtiene o establece la parte del dominio de autenticación de la URI. Este valor solo está disponible si el usuario ya está configurado.

nombre_compartido

Método auxiliar para obtener el nombre del recurso compartido a partir de la ruta

DEPENDENCIAS

Ninguna
