NOMBRE

URI::WithBase - URIs que recuerdan su base

SINOPSIS

$u1 = URI::WithBase->new($str, $base);
$u2 = $u1->abs;
$base = $u1->base;
$u1->base( $new_base )

DESCRIPCIÓN

Este módulo proporciona la clase "URI::WithBase". Los objetos de esta clase son como los objetos "URI", pero pueden guardar también su base. La base representa el contexto donde se encontró esta URI y puede ser utilizada para absolutizar o relativizar la URI. Todos los métodos descritos en URI son compatibles con los objetos de "URI::WithBase".

Los métodos proporcionados además de o modificados respecto a los de "URI" son:

$uri = URI::WithBase->new($str, [$base])
El constructor toma una URI base opcional como segundo argumento. Si se proporciona, este argumento inicializa el atributo de base.
$uri->base( [$new_base] )
Puede ser utilizado para obtener o establecer el valor del atributo de base. El valor devuelto, que es el valor anterior, es un objeto URI o "undef".
$uri->abs( [$base_uri] )
El argumento $base_uri ahora es opcional ya que el objeto lleva consigo su base. Se devuelve un nuevo objeto incluso si $uri ya es absoluto (mientras que los objetos URI simples devuelven ellos mismos en ese caso).
$uri->rel( [$base_uri] )
El argumento $base_uri ahora es opcional ya que el objeto lleva consigo su base. Siempre se devuelve un nuevo objeto.
