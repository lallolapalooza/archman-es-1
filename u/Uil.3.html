Uil(llamada_libreria) Uil(llamada_libreria)

NOMBRE

Uil — Invoca el compilador UIL desde dentro de una aplicación

SINOPSIS

#include <uil/UilDef.h>

Uil_status_type Uil(
Uil_command_type *command_desc,
Uil_compile_desc_type **compile_desc,
Uil_continue_type (*message_cb) (),
char *message_data,
Uil_continue_type (*status_cb) (),
char *status_data);

DESCRIPCIÓN

La función Uil proporciona un punto de entrada invocable para el compilador UIL. La interfaz invocable Uil se puede usar para procesar un archivo fuente UIL y para generar archivos UID, así como para devolver una descripción detallada del módulo fuente UIL en forma de tabla de símbolos (árbol de análisis sintáctico).

command_desc
Especifica la línea de comandos de uil.
compile_desc
Devuelve los resultados de la compilación.
message_cb
Especifica una función de devolución de llamada que se invoca cuando el compilador encuentra errores en el código fuente UIL.
message_data
Especifica datos de usuario que se pasan a la función de devolución de llamada de mensajes (message_cb). Tenga en cuenta que este argumento no es interpretado por UIL y se usa exclusivamente por la aplicación que lo llama.
status_cb
Especifica una función de devolución de llamada que se invoca para permitir que las aplicaciones X atiendan eventos X como la actualización de la pantalla. Esta función se llama en varios puntos de control, que se han codificado en el compilador UIL. El argumento status_update_delay en command_desc especifica el número de puntos de control que se deben pasar antes de que se invoque la función status_cb.
status_data
Especifica datos de usuario que se pasan a la función de devolución de llamada de estado (status_cb). Tenga en cuenta que este argumento no es interpretado por el compilador UIL y se usa exclusivamente por la aplicación que lo llama.

A continuación se detallan las estructuras de datos Uil_command_type y Uil_compile_desc_type:

typedef struct Uil_command_type {
char *source_file;
    /* único fuente a compilar */
char *resource_file; /* nombre del archivo de salida */
char *listing_file; /* nombre del archivo de listado */
unsigned int *include_dir_count;
    /* número de directorios en include_dir */
char *((*include_dir) []);
    /* directorio a buscar para archivos de inclusión */
unsigned listing_file_flag: 1;
    /* producir un listado */
unsigned resource_file_flag: 1;
    /* generar salida UID */
unsigned machine_code_flag: 1;
    /* generar código máquina */
unsigned report_info_msg_flag: 1;
    /* reportar mensajes informativos */
unsigned report_warn_msg_flag: 1;
    /* reportar advertencias */
unsigned parse_tree_flag: 1;
    /* generar árbol de análisis sintáctico */
unsigned int status_update_delay;
    /* número de veces que se pasa un punto de estado */
    /* antes de llamar a status_cb */
    /* la función 0 significa que se llama cada vez */
char *database;
    /* nombre del archivo de base de datos */
unsigned database_flag: 1;
    /* leer un nuevo archivo de base de datos */
unsigned use_setlocale_flag: 1;
    /* habilitar llamadas a setlocale */
};
typedef struct Uil_compile_desc_type {
unsigned int compiler_version;
    /* número de versión del compilador */
unsigned int data_version;
    /* número de versión de las estructuras */
char *parse_tree_root; /* salida del árbol de análisis sintáctico */
unsigned int message_count [Uil_k_max_status+1];
/* matriz de recuentos de severidad */
};

A continuación se describe la función de devolución de llamada de mensajes especificada por message_cb:

Uil_continue_type (*message_cb) (message_data, message_number, severity, msg_buffer,
src_buffer, ptr_buffer, loc_buffer, message_count)
        char *message_data;
        int message_number;
        int severity;
        char *msg_buffer, *src_buffer;
        char *ptr_buffer, *loc_buffer;
        int message_count[];

Esta función especifica una función de devolución de llamada que UIL invoca en lugar de imprimir un mensaje de error cuando el compilador encuentra un error en el código fuente UIL. La devolución de llamada debe devolver uno de los siguientes valores:

Uil_k_terminate
Terminar el procesamiento del archivo fuente
Uil_k_continue
Continuar el procesamiento del archivo fuente

Los argumentos son

message_data
Datos suministrados por la aplicación como argumento message_data a la función Uil. UIL no interpreta estos datos de ninguna manera; simplemente los pasa a la devolución de llamada.
message_number
Un índice en una tabla de mensajes de error y severidades para uso interno de UIL.
severity
Un entero que indica la severidad del error. Los valores posibles son las constantes de estado devueltas por la función Uil. Consulte Valor de retorno para obtener más información.
msg_buffer
Una cadena que describe el error.
src_buffer
Una cadena que consta de la línea de código fuente donde ocurrió el error. Esta cadena no siempre está disponible. En este caso, el argumento es NULL.
ptr_buffer
Una cadena que consta de espacios en blanco y un carácter de impresión en la posición de carácter correspondiente a la columna de la línea de código fuente donde ocurrió el error. Esta cadena puede imprimirse debajo de la línea de código fuente para proporcionar una indicación visual de la columna donde ocurrió el error. Esta cadena no siempre está disponible. En este caso, el argumento es NULL.
loc_buffer
Una cadena que identifica el número de línea y el archivo de la línea de código fuente donde ocurrió el error. Esto no siempre está disponible; el argumento es entonces NULL.
message_count
Una matriz de enteros que contiene el número de mensajes de diagnóstico emitidos hasta el momento para cada nivel de severidad. Para encontrar el número de mensajes emitidos para el nivel de severidad actual, use el argumento severity como índice en esta matriz.

A continuación se describe la función de devolución de llamada de estado especificada por status_cb:

Uil_continue_type (*status_cb) (status_data, percent_complete,
        lines_processed, current_file, message_count)
        char *status_data;
        int percent_complete;
        int lines_processed;
        char *current_file;
        int message_count[];

Esta función especifica una función de devolución de llamada que se invoca para permitir que las aplicaciones X atiendan eventos X como la actualización de la pantalla. La devolución de llamada debe devolver uno de los siguientes valores:

Uil_k_terminate
Terminar el procesamiento del archivo fuente
Uil_k_continue
Continuar el procesamiento del archivo fuente

Los argumentos son

status_data
Datos suministrados por la aplicación como argumento status_data a la función Uil. UIL no interpreta estos datos.

NAME

Uil - User Interface Language compiler utility program

SYNOPSIS

Uil [ -I directory ] [ -T file ] [ -t ] [ -t 0 ] [ -t 1 ] [ -v ] [ -o file ] [ -s ] [ -n ] [ -m ] [ -x ] [ uil options ] uil file

DESCRIPTION

The Uil program is a compiler that translates a User Interface Language (UIL) source file into a compiled format that can be used by an application at run time.

The Uil program translates the UIL source file into a binary representation which is then written to the file specified by the -o option. If the -o option is not specified, the name of the output file defaults to the base name of the UIL source file with the extension changed to .uil.

The Uil program also provides a mechanism for generating callback routines. The callback routines generated by the Uil program are skeleton routines which contain only comments and the necessary declarations. The programmer is responsible for filling in the body of these routines.

The Uil program supports the following options:

-I directory
Adds the specified directory to the list of directories that the Uil program searches for imported files. The Uil program searches for imported files in the directories specified by the -I option in the order they are specified. If a file is not found in any of the specified directories, the Uil program searches the current directory.
-T file
Specifies a file to which the Uil program writes a symbol table. The symbol table contains information about the objects defined in the UIL source file. This option is useful for debugging.
-t
Generates a symbol table. This option is equivalent to -T stdout.
-t 0
Generates a symbol table containing only the names of the objects defined in the UIL source file.
-t 1
Generates a symbol table containing the names and types of the objects defined in the UIL source file.
-v
Prints the version of the Uil program to standard output and exits.
-o file
Specifies the name of the output file. If this option is not specified, the name of the output file defaults to the base name of the UIL source file with the extension changed to .uil.
-s
Generates skeleton callback routines. The callback routines are written to a file named after the UIL source file, with the extension .c.
-n
Suppresses the generation of skeleton callback routines. This option is useful when you do not want to generate callback routines.
-m
Specifies that the Uil program should generate message catalog source files. The message catalog source files are written to a file named after the UIL source file, with the extension .msg.
-x
Enables extended error reporting. This option is useful for debugging.

The Uil program also accepts a callback function as an argument. The callback function is called by the Uil program during the compilation process to report the progress of the compilation. The callback function is called with the following arguments:

callback_data
A pointer to user-defined data. This pointer is passed to the callback function by the caller of the Uil function. The Uil function does not interpret this data in any way; it just passes it to the callback.
percent_complete
An integer indicating what percentage of the current source file has been processed so far.
lines_processed
An integer indicating how many lines of the current source file have been read so far.
current_file
A string containing the pathname of the current source file.
message_count
An array of integers containing the number of diagnostic messages issued thus far for each severity level. To find the number of messages issued for a given severity level, use the severity level as the index into this array. The possible severity levels are the status constants returned by the Uil function. See Return Value for more information.

RETURN

This function returns one of the following status return constants:

Uil_k_success_status
The operation succeeded.
Uil_k_info_status
The operation succeeded. An informational message is returned.
Uil_k_warning_status
The operation succeeded. A warning message is returned.
Uil_k_error_status
The operation failed due to an error.
Uil_k_severe_status
The operation failed due to an error.
