UFFDIO_COPY(2const) UFFDIO_COPY(2const)

NOMBRE

UFFDIO_COPY - copia atómicamente un bloque de memoria continuo en el rango registrado de userfault

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/userfaultfd.h>  /* Definición de constantes UFFD* */
#include <sys/ioctl.h>
int ioctl(int fd, UFFDIO_COPY, struct uffdio_copy *argp);
#include <linux/userfaultfd.h>
struct uffdio_copy {
    __u64  dst;   /* Destino de la copia */
    __u64  src;   /* Origen de la copia */
    __u64  len;   /* Número de bytes a copiar */
    __u64  mode;  /* Banderas que controlan el comportamiento de la copia */
    __s64  copy;  /* Número de bytes copiados, o error negado */
};

DESCRIPCIÓN

Copia atómicamente un bloque de memoria continuo en el rango registrado de userfault y opcionalmente despierta al hilo bloqueado.

El siguiente valor puede ser aplicado mediante OR bit a bit en mode para cambiar el comportamiento de la operación UFFDIO_COPY:

UFFDIO_COPY_MODE_DONTWAKE
No despertar al hilo que espera la resolución de falta de página
UFFDIO_COPY_MODE_WP
Copiar la página con permiso de solo lectura. Esto permite al usuario interceptar la siguiente escritura en la página, la cual se bloqueará y generará otro mensaje de userfault de protección de escritura. Esto solo se usa cuando los modos UFFDIO_REGISTER_MODE_MISSING y UFFDIO_REGISTER_MODE_WP están habilitados para el rango registrado.

El campo copy es utilizado por el kernel para devolver el número de bytes que fueron realmente copiados, o un error (un valor negado al estilo de errno). El campo copy es solo de salida; no es leído por la operación UFFDIO_COPY.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En este caso, toda el área fue copiada.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EAGAIN
El número de bytes copiados (es decir, el valor devuelto en el campo copy) no es igual al valor especificado en el campo len.
EINVAL
O bien dst o bien len no eran múltiplos del tamaño de página del sistema, o el rango especificado por src y len o dst y len era inválido.
EINVAL
Se especificó un bit inválido en el campo mode.
ENOENT (desde Linux 4.11)
El proceso que causa la falta de página ha cambiado su disposición de memoria virtual simultáneamente con una operación UFFDIO_COPY pendiente.
ENOSPC (desde Linux 4.11 hasta Linux 4.13)
El proceso que causa la falta de página ha salido en el momento de una operación UFFDIO_COPY.
ESRCH (desde Linux 4.13)
El proceso que causa la falta de página ha salido en el momento de una operación UFFDIO_COPY.
