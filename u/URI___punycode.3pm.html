URI::_punycode(3) Documentación de Perl aportada por el usuario URI::_punycode(3)

NOMBRE

URI::_punycode - codifica cadenas Unicode en Punycode

SINOPSIS

use strict;
use warnings;
use utf8;
use URI::_punycode qw(encode_punycode decode_punycode);
# codificar una cadena unicode
my $punycode = encode_punycode('http://☃.net'); # http://.net-xc8g
$punycode = encode_punycode('bücher'); # bcher-kva
$punycode = encode_punycode('他们为什么不说中文'); # ihqwcrb4cv8a8dqg056pqjye
# decodificar una cadena punycode de nuevo a una cadena unicode
my $unicode = decode_punycode('http://.net-xc8g'); # http://☃.net
$unicode = decode_punycode('bcher-kva'); # bücher
$unicode = decode_punycode('ihqwcrb4cv8a8dqg056pqjye'); # 他们为什么不说中文

DESCRIPCIÓN

URI::_punycode es un módulo para codificar/decodificar cadenas Unicode en Punycode https://tools.ietf.org/html/rfc3492, una codificación eficiente de Unicode para usar con IDNA https://tools.ietf.org/html/rfc5890.

FUNCIONES

Todas las funciones lanzan excepciones en caso de fallo. Puedes "capturarlas" con Syntax::Keyword::Try o Try::Tiny. Las siguientes funciones se exportan por defecto.

encode_punycode

my $punycode = encode_punycode('http://☃.net');  # http://.net-xc8g
$punycode = encode_punycode('bücher'); # bcher-kva
$punycode = encode_punycode('他们为什么不说中文') # ihqwcrb4cv8a8dqg056pqjye

Toma una cadena Unicode (variable marcada como UTF8) y devuelve una codificación Punycode para ella.

decode_punycode

my $unicode = decode_punycode('http://.net-xc8g'); # http://☃.net
$unicode = decode_punycode('bcher-kva'); # bücher
$unicode = decode_punycode('ihqwcrb4cv8a8dqg056pqjye'); # 他们为什么不说中文

Toma una codificación Punycode y devuelve la cadena Unicode original.
