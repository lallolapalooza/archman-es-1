C/POSIX.

Esta extensión de GNU proporciona extensiones para trabajar c

on FILE* de C estándar y descriptores de archivo POSIX. Debe
ser instanciada por el usuario con el tipo de carácter utili
zado en el flujo de archivo, p. ej., stdio_filebuf<char>.
