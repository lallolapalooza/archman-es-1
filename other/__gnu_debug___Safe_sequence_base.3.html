Descripción Detallada

Clase base que soporta el seguimiento de iteradores que referencian una secuencia.

La clase _Safe_sequence_base proporciona soporte básico para el seguimiento de iteradores en una secuencia. Las secuencias que rastrean iteradores deben derivar de _Safe_sequence_base públicamente, para que los iteradores seguros (que heredan de _Safe_iterator_base) puedan adjuntarse a ellas. Esta clase contiene dos listas enlazadas de iteradores, una para iteradores constantes y otra para iteradores mutables, y un número de versión que permite la invalidación muy rápida de todos los iteradores que referencian el contenedor.

Esta clase debe asegurar que ninguna operación sobre ella pueda lanzar una excepción, de lo contrario, las secuencias *seguras* pueden fallar al proporcionar las garantías de seguridad ante excepciones requeridas por el estándar C++.
