Descripción Detallada

Clase base para __pool_alloc.

Utiliza varios asignadores para satisfacer las solicitudes subyacentes (y realiza las menos solicitudes posibles cuando está en modo de grupo de alta velocidad predeterminado).

Propiedades importantes de implementación:

0.
Si se exige a nivel mundial, entonces se asignan objetos de nuevo
1.
Si los clientes solicitan un objeto de tamaño > _S_max_bytes, el objeto resultante se obtendrá directamente de new
2.
En todos los demás casos, asignamos un objeto de tamaño exactamente _S_round_up(tamaño_solicitado). Por lo tanto, el cliente tiene suficiente información de tamaño para que podamos devolver el objeto a la lista libre adecuada sin perder permanentemente parte del objeto.
