NOMBRE

__pmEquivInDom - comprueba si dos dominios de instancia son equivalentes

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>

int __pmEquivInDom(pmInDom a, pmInDom b)

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las APIs de PCP que se garantiza que permanecerán fijas entre lanzamientos, y en algún momento en el futuro podrían no funcionar o proporcionar semánticas diferentes.

DESCRIPCIÓN

Dentro de Performance Co-Pilot (PCP), a cada dominio de instancia se le asigna un Identificador de Dominio de Instancia (pmInDom) único. Internamente, un pmInDom se construye a partir de 2 campos: el número de dominio (del Agente de Dominio de Métricas de Rendimiento, o PMDA asociado) y el número de serie (asignado por el PMDA).

En algunas circunstancias inusuales, diferentes PMDA pueden admitir Dominios de Instancia independientes que son semánticamente equivalentes, por ejemplo, por CPU o por identificador de proceso. __pmEquivInDom proporciona un mecanismo para determinar si el Dominio de Instancia a es equivalente al Dominio de Instancia b.

La "equivalencia" de los Dominios de Instancia se define por un archivo de configuración externo, identificado por la variable de entorno $PCP_INDOM_CONFIG o $PCP_ETC_DIR/pcp/indom.config por defecto. El formato del archivo de configuración se define en la sección CONFIGURACIÓN DEL ARCHIVO a continuación.

Si $PCP_INDOM_CONFIG es una cadena vacía, no se carga ningún mapeo de equivalencia.

CONFIGURACIÓN DEL ARCHIVO

Un archivo de mapeo de equivalencia de Dominio de Instancia se ajusta a la siguiente sintaxis:

1.
Las líneas que comienzan con espacio en blanco opcional, seguido de "#", se consideran comentarios.
2.
Las líneas en blanco se ignoran.
3.
Cada línea restante define un "mapa de equivalencia" con una lista de dominios de instancia separados por espacios en blanco, cada uno que consiste en un número (el número de dominio), un punto "." y un número (el número de serie). Como caso especial para "coincidir todos los números de serie", la parte del número de serie puede ser "*".

El formato de un pmInDom exige que un número de dominio esté en el rango de 0 a 511, y un número de serie numérico esté en el rango de 0 a 4194303.

DIAGNÓSTICOS Y VALORES DE RETORNO

El valor de retorno es 1 si los Dominios de Instancia son equivalentes, de lo contrario 0 si no lo son. En casos raros, se utiliza un valor de retorno de -1 para indicar algún problema (informado en la salida estándar) al abrir o analizar el archivo de configuración.
