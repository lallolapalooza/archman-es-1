Descripción detallada

template<typename _Tp>

class __gnu_cxx::_ExtPtr_allocator< _Tp >"Un asignador de ejemplo que utiliza un tipo de puntero no estándar.

Este asignador especifica que los contenedores utilicen un 'puntero relativo' como su tipo de puntero. (Ver ext/pointer.h) La asignación de memoria en este ejemplo todavía se realiza utilizando std::allocator.
