Descripción Detallada

template<typename _Storage_policy>

class __gnu_cxx::_Pointer_adapter< _Storage_policy >"Lo siguiente proporciona un 'puntero alternativo' que funciona con los contenedores cuando se especifica como el typedef del puntero del asignador.

El tipo de puntero utilizado con los contenedores no tiene que ser esta clase, pero debe soportar las conversiones implícitas, la aritmética de punteros, los operadores de comparación, etc., que soporta esta clase, y evitar generar ambigüedades en tiempo de compilación. Dado que crear un puntero funcional puede ser desafiante, esta plantilla de puntero fue diseñada para envolver un tipo de política de almacenamiento más fácil, de modo que se vuelva reutilizable para crear otros tipos de punteros.

Un punto clave de esta clase es que también permite a los escritores de contenedores 'asumir' que Allocator::pointer es un typedef para un puntero normal. Esta clase soporta la mayoría de las convenciones de un puntero verdadero, y puede, por ejemplo, manejar la conversión implícita a punteros const y a punteros de clase base. Las únicas imposiciones a los escritores de contenedores para soportar punteros extendidos son: 1) usar el typedef Allocator::pointer apropiadamente para los tipos de puntero. 2) si necesita hacer casting de punteros, use las funciones __pointer_cast<> de ext/cast.h. Esto permite que las operaciones de casting de punteros sean sobrecargadas según sea necesario por punteros personalizados.

Nota: El calificador const funciona con este adaptador de puntero de la siguiente manera:

_Tp* == _Pointer_adapter<_Std_pointer_impl<_Tp> >; const _Tp* == _Pointer_adapter<_Std_pointer_impl<const _Tp> >; _Tp* const == const _Pointer_adapter<_Std_pointer_impl<_Tp> >; const _Tp* const == const _Pointer_adapter<_Std_pointer_impl<const _Tp> >;
