__pmLogMetaTypeStr(3)

PMLOGMETATYPESTR(3) Manual de funciones de biblioteca PMLOGMETATYPESTR(3)

NOMBRE

__pmLogMetaTypeStr, __pmLogMetaTypeStr_r - convertir un tipo de registro de metadatos de archivo a una cadena

SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>

const char *__pmLogMetaTypeStr(int type);
char *__pmLogMetaTypeStr_r(int type, char *buf, int buflen);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas entre versiones, y es posible que no funcionen, o que proporcionen una semántica diferente en algún momento futuro.

DESCRIPCIÓN

Dado un tipo numérico de registro de metadatos de archivo (type), __pmLogMetaTypeStr produce el nombre ASCII de ese tipo de registro, o **UNKNOWN** si type no es un tipo de registro válido. La función __pmLogMetaTypeStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debería tener espacio para al menos 17 bytes.

Los ejemplos son DESC (para type igual a 1), INDOM_V2 (para type igual a 2), etc.

NOTAS

Ambas funciones se pueden llamar de forma segura desde contextos con hilos.
