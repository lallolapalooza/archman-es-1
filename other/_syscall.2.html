_syscall(2) Manual de llamadas al sistema _syscall(2)

NOMBRE

_syscall - invocar una llamada al sistema sin soporte de biblioteca (OBSOLETO)

SINOPSIS

#include <linux/unistd.h>
Macro _syscall
llamada al sistema deseada

DESCRIPCIÓN

Lo importante que hay que saber sobre una llamada al sistema es su prototipo. Necesitas saber cuántos argumentos, sus tipos y el tipo de retorno de la función. Hay siete macros que facilitan la llamada real al sistema. Tienen la forma:


_syscallX(tipo,nombre,tipo1,arg1,tipo2,arg2,...)

donde

X es 0–6, que es el número de argumentos que toma la llamada al sistema
tipo es el tipo de retorno de la llamada al sistema
nombre es el nombre de la llamada al sistema
tipoN es el tipo del N-ésimo argumento
argN es el nombre del N-ésimo argumento

Estas macros crean una función llamada nombre con los argumentos que especificas. Una vez que incluyes el _syscall() en tu archivo fuente, llamas a la llamada al sistema por nombre.

ARCHIVOS

/usr/include/linux/unistd.h

ESTÁNDARES

Linux.

HISTORIA

A partir de aproximadamente Linux 2.6.18, las macros _syscall se eliminaron de los archivos de cabecera proporcionados al espacio de usuario. Utiliza syscall(2) en su lugar. (Algunas arquitecturas, notablemente ia64, nunca proporcionaron las macros _syscall; en esas arquitecturas, siempre se requirió syscall(2)).

NOTAS

Las macros _syscall() *no* producen un prototipo. Es posible que tengas que crear uno, especialmente para usuarios de C++.

Las llamadas al sistema no están obligadas a devolver solo códigos de error positivos o negativos. Necesitas leer el código fuente para estar seguro de cómo devolverá los errores. Por lo general, es el negativo de un código de error estándar, por ejemplo, -EPERM. Las macros _syscall() devolverán el resultado r de la llamada al sistema cuando r es no negativo, pero devolverán -1 y establecerán la variable errno a -r cuando r es negativo. Para los códigos de error, consulta errno(3).

Al definir una llamada al sistema, los tipos de argumento *deben* pasarse por valor o por puntero (para agregados como estructuras).

EJEMPLOS

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <linux/unistd.h>       /* para macros _syscallX/cosas relacionadas */
#include <linux/kernel.h>       /* para la struct sysinfo */
_syscall1(int, sysinfo, struct sysinfo *, info);
int
main(void)
{
    struct sysinfo s_info;
    int error;
    error = sysinfo(&s_info);
    printf("código error = %d\n", error);
    printf("Tiempo activo = %lds\nCarga: 1 min %lu / 5 min %lu / 15 min %lu\n"
           "RAM: total %lu / libre %lu / compartida %lu\n"
           "Memoria en buffers = %lu\nSwap: total %lu / libre %lu\n"
           "Número de procesos = %d\n",
           s_info.uptime, s_info.loads[0],
           s_info.loads[1], s_info.loads[2],
           s_info.totalram, s_info.freeram,
           s_info.sharedram, s_info.bufferram,
           s_info.totalswap, s_info.freeswap,
           s_info.procs);
    exit(EXIT_SUCCESS);
}

Salida de ejemplo

uptime = 502034s

RAM: total 15343616 / libre 827392 / compartida 8237056
Memoria en buffers = 5066752
Swap: total 27881472 / libre 24698880
Número de procesos = 40
