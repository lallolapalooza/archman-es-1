Descripción Detallada

template<typename _Tp>

struct __gnu_parallel::_LoserTreeTraits< _Tp >"Rasgos para determinar si el árbol del perdedor debe usar punteros o copias.

El campo "_M_use_pointer" se utiliza para determinar si se deben usar punteros en los árboles del perdedor o si se deben copiar los valores en el árbol del perdedor.

El comportamiento predeterminado es usar punteros si el tipo de dato es 4 veces más grande que el puntero a él.

Especifique para su tipo de dato para personalizar el comportamiento.

Ejemplo:

template<> struct _LoserTreeTraits<int> { static const bool _M_use_pointer = false; };

template<> struct _LoserTreeTraits<heavyweight_type> { static const bool _M_use_pointer = true; };

Parámetros

_Tp tipo para el que se proporcionan los rasgos del árbol del perdedor.

Documentación de Datos Miembro

template<typename _Tp> const bool __gnu_parallel::_LoserTreeTraits< _Tp >::_M_use_pointer [static]

Verdadero si se deben usar punteros en lugar de valores en los árboles del perdedor. El comportamiento predeterminado es usar punteros si el tipo de dato es cuatro veces más grande que el puntero a él.
