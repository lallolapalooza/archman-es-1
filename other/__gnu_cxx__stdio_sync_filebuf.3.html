template<typename _CharT, typename _Traits = std::char_traits<_CharT>> virtual int_type __gnu_cxx::stdio_sync_filebuf< _CharT, _Traits >::overflow (int_type __c = traits_type::eof()) [inline], [protected], [virtual]

Consume datos del búfer; escribe en la secuencia controlada.

Parámetros

__c Un carácter adicional para consumir.

Devuelve

eof() para indicar fallo, algo más (generalmente __c, o not_eof())

Informalmente, esta función se llama cuando el búfer de salida está lleno (o no existe, ya que no es necesario realizar el almacenamiento en búfer). Si existe un búfer, se consume, con algún efecto en la secuencia controlada. (Típicamente, el búfer se escribe en la secuencia sin cambios.) En cualquier caso, el carácter c también se escribe, si __c no es eof().

Para una definición formal de esta función, consulte un buen texto como Langer & Kreft, o [27.5.2.4.5]/3-7.

Se puede crear un streambuf de salida funcional sobrescribiendo solo esta función (no se utilizará área de búfer).

Nota

La versión de la clase base no hace nada, devuelve eof().

Reimplementado de std::basic_streambuf< _CharT, _Traits >.
