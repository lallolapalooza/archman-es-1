PMCONNECTLOGGER(3) Manual de funciones de biblioteca PMCONNECTLOGGER(3)

NOMBRE

__pmConnectLogger - conectarse al puerto de control de un registrador de métricas de rendimiento

C SINOPSIS

#include "pmapi.h"
#include "libpcp.h"

int __pmConnectLogger(const char *hostname, int pid);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas entre las versiones, y pueden no funcionar, o proporcionar semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

Cada instancia del programa de creación de archivos de Performance Co-Pilot (PCP) pmlogger(1) soporta un puerto de control en el que se reciben las solicitudes de __pmControlLog(3) y se envían las respuestas. Opcionalmente, la instancia de pmlogger(1) puede designarse como registrador "primario".

__pmConnectLogger puede usarse para establecer una conexión de puerto de control con la instancia de pmlogger(1) identificada por el ID de proceso pid en el host hostname.

Se soporta un caso especial; para el valor reservado de pid de PM_LOG_PRIMARY_PORT, la conexión solicitada es al puerto de control del registrador "primario", sea cual sea su ID de proceso.

En caso de éxito, __pmConnectLogger devuelve un entero no negativo, que es un descriptor de archivo que puede usarse en la comunicación posterior con la instancia de pmlogger(1), por ejemplo, para __pmControlLog(3).

Dado que el puerto de control de pmlogger(1) no está multiplexado, las aplicaciones que usan __pmConnectLogger deben usar close(2) para terminar la conexión con pmlogger(1) tan pronto como hayan terminado de comunicarse.

Si la aplicación se conecta y la instancia de pmlogger(1) se termina posteriormente, por ejemplo, porque se termina la instancia de pmcd(1) asociada, la aplicación tendrá que reestablecer explícitamente la conexión con una instancia de pmlogger(1) reiniciada llamando nuevamente a __pmConnectLogger.

DIAGNÓSTICOS

PM_ERR_PERMISSION
sin permiso para conectarse a la instancia especificada de pmlogger(1)
-ECONNREFUSED
la instancia designada de pmlogger(1) no existe
-EADDRINUSE
el puerto de control solicitado ya está en uso

VER TAMBIÉN

pmcd(1), pmlc(1), pmlogger(1), PMAPI(3) y __pmControlLog(3).
