99USER.LDIF(5) Manual de formatos de archivo 99USER.LDIF(5)

NOMBRE

/etc/dirsrv/schema/99user.ldif - Archivo LDIF que contiene el esquema LDAP personalizado para 389 Directory Server.

SINOPSIS

/etc/dirsrv/schema/99user.ldif

DESCRIPCIÓN

99user.ldif

Este archivo contiene definiciones de esquema LDAP personalizadas, definidas por el usuario (atributos y objectclasses) utilizadas por el servidor de directorios.

SINTAXIS

attributeTypes: VALOR
objectClasses: VALOR

EJEMPLO

dn: cn=schema
attributeTypes: ( 1.1.1.1.1.1.1 NAME 'miNuevoAtributo' DESC 'Tipo de atributo definido personalizado' SYNTAX 1.3.6.1.4.1.1466.115.121.1.15 SINGLE-VALUE X-ORIGIN
objectClasses: ( 1.1.1.1.1.1.1.2 NAME 'miNuevaClaseObjeto' DESC 'Clase de objeto definida personalizada' SUP top MUST ( miNuevoAtributo ) MAY ( uid $ cn ) X-ORIGIN 'definido-por-el-usuario' )

AUTOR

99user.ldif fue escrito por el Proyecto 389.
