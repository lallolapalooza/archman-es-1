NOMBRE

__ppc_set_ppr_med, __ppc_set_ppr_very_low, __ppc_set_ppr_low, __ppc_set_ppr_med_low, __ppc_set_ppr_med_high - Establecer el Registro de Prioridad del Programa

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/platform/ppc.h>
void __ppc_set_ppr_med(void);
void __ppc_set_ppr_very_low(void);
void __ppc_set_ppr_low(void);
void __ppc_set_ppr_med_low(void);
void __ppc_set_ppr_med_high(void);

DESCRIPCIÓN

Estas funciones proporcionan acceso al Registro de Prioridad del Programa (PPR) en la arquitectura Power.

El PPR es un registro de 64 bits que controla la prioridad del programa. Al ajustar el valor del PPR, el programador puede mejorar el rendimiento del sistema haciendo que los recursos del sistema se utilicen de manera más eficiente, especialmente en situaciones de contención. Los estados no privilegiados disponibles están cubiertos por las siguientes funciones:

__ppc_set_ppr_med()
establece el valor del Registro de Prioridad del Programa a medio (predeterminado).
__ppc_set_ppr_very_low()
establece el valor del Registro de Prioridad del Programa a muy bajo.
__ppc_set_ppr_low()
establece el valor del Registro de Prioridad del Programa a bajo.
__ppc_set_ppr_med_low()
establece el valor del Registro de Prioridad del Programa a medio bajo.

El estado privilegiado medio alto también puede ser establecido durante ciertos intervalos de tiempo por programas en modo problema (no privilegiados), con la siguiente función:

__ppc_set_ppr_med_high()
establece la prioridad del programa a medio alto.

Si la prioridad del programa es medio alta cuando expira el intervalo de tiempo o si se intenta establecer la prioridad a medio alta cuando no está permitido, la prioridad se establece a medio.

NOTAS

Las funciones __ppc_set_ppr_very_low() y __ppc_set_ppr_med_high() se definirán en <sys/platform/ppc.h> si se define _ARCH_PWR8. La disponibilidad de estas funciones se puede comprobar utilizando #ifdef _ARCH_PWR8.
