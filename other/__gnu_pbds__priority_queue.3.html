Descripción Detallada

template<typename _Tv, typename Cmp_Fn = std::less<_Tv>, typename Tag = pairing_heap_tag, typename _Alloc = std::allocator<char>>

class __gnu_pbds::priority_queue< _Tv, Cmp_Fn, Tag, _Alloc >"Una cola de prioridad compuesta por una política específica de heap.

Parámetros de plantilla

_Tv Tipo de valor.
Cmp_Fn Functor de comparación.
Tag Tipo de estructura de datos de instanciación, véase container_tag.
_Alloc Tipo de asignador.

La base se despacha en tiempo de compilación a través de Tag, de las siguientes opciones: binary_heap_tag, binomial_heap_tag, pairing_heap_tag, rc_binomial_heap_tag, thin_heap_tag

Las opciones base son: detail::binary_heap, detail::binomial_heap, detail::pairing_heap, detail::rc_binomial_heap, detail::thin_heap.
