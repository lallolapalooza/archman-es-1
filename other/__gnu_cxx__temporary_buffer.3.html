Descripción Detallada

template<class _ForwardIterator, class _Tp = typename std::iterator_traits<_ForwardIterator>::value_type>

struct __gnu_cxx::temporary_buffer< _ForwardIterator, _Tp >"Esta clase proporciona un comportamiento y semántica similares a las funciones estándar get_temporary_buffer() y return_temporary_buffer(), pero encapsuladas en un tipo que se asemeja vagamente a un contenedor estándar.

Por defecto, un temporary_buffer<Iter> almacena espacio para objetos del tipo al que apunta el iterador Iter. Se construye a partir de un rango típico [first,last) y proporciona las funciones begin(), end(), size(), así como requested_size(). Para tipos no triviales, se utilizarán copias de *first para inicializar el almacenamiento.

Se utiliza malloc para obtener el almacenamiento subyacente.

Al igual que get_temporary_buffer(), no toda la memoria solicitada puede estar disponible. Idealmente, el buffer creado será lo suficientemente grande como para contener una copia de [first,last), pero si size() es menor que requested_size(), entonces esto no sucedió.
