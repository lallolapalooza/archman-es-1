NOMBRE

__pmOverrideLastFd, __pmPrintIPC, __pmResetIPC - Soporte de infraestructura de versión IPC

SINOPSIS EN C

#include "pmapi.h"
#include "libpcp.h"

void __pmOverrideLastFd(int fd);
void __pmPrintIPC(void);
void __pmResetIPC(int fd);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que garantizan permanecer fijas entre versiones, y es posible que no funcionen o que ofrezcan semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

Los canales IPC en todo el marco distribuido de PCP se ven afectados por los cambios de PDU de PCP 2.0 (y posteriores). Estas funciones son la interfaz de los datos globales de gestión de conexiones IPC de libpcp. Estos datos consisten en una tabla hash de estructuras __pmIPC (indexadas por descriptor de archivo) y un descriptor de archivo almacenado en caché y usado más recientemente.

__pmOverrideLastFd es un mecanismo de escape para usar en aquellas situaciones en las que la última obtención de PDU no se realizó a través de los canales habituales (es decir, __pmGetPDU), para garantizar que el descriptor de archivo almacenado en caché sea el descriptor de archivo correcto para la PDU que se está procesando actualmente. Esto se usará típicamente para el procesamiento de PDUs de archivo o donde la información de versión no esté disponible para un descriptor de archivo dado (por ejemplo, inmediatamente antes de un intercambio de versión de PDU).

__pmPrintIPC es una rutina de depuración útil para mostrar una tabla que mapea todos los descriptores de archivo registrados actualmente a sus números de versión de PDU asociados. Las entradas no utilizadas en esta tabla deberían mostrar el valor cero en la columna de versión.

__pmResetIPC restablece la información de versión asociada con el descriptor de archivo dado a un número conocido (inválido). Las búsquedas posteriores en este descriptor de archivo devolverán UNKNOWN_VERSION incrustado dentro de la estructura __pmIPC.

DIAGNÓSTICOS

Un valor de retorno negativo de __pmOverrideLastFd indica que el argumento del descriptor de archivo no está registrado en la tabla hash. Esto típicamente indica el cierre de un canal IPC, por lo que se devuelve PM_ERR_IPC si este es el caso.
