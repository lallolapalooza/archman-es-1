template<typename _Tp> pointer __gnu_cxx::bitmap_allocator< _Tp >::_M_allocate_single_object () [inline]

Asigna memoria para un único objeto de tamaño sizeof(_Tp).

Excepciones

std::bad_alloc. Si no se puede asignar memoria.

Complejidad: La complejidad en el peor caso es O(N), pero ese caso rara vez se presenta. Si y cuando se encuentra este caso particular, los siguientes casos tienen garantizado una complejidad O(1). ¡Por eso esta función funciona muy bien en promedio! Puedes considerar que esta función tiene una complejidad comúnmente referida como: tiempo constante amortizado.

template<typename _Tp> void __gnu_cxx::bitmap_allocator< _Tp >::_M_deallocate_single_object (pointer __p) [inline]

Libera memoria que pertenece a un único objeto de tamaño sizeof(_Tp). Complejidad: O(lg(N)), ¡pero el peor caso no se da a menudo! Esto se debe a que los contenedores suelen liberar memoria cercana entre sí y este caso es manejado en tiempo O(1) por la función de liberación.
