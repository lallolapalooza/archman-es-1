template<typename Key, typename Mapped, typename Hash_Fn, typename Eq_Fn, typename _Alloc, bool Store_Hash, typename Comb_Hash_Fn, typename Resize_Policy>

class __gnu_pbds::detail::cc_ht_map< Key, Mapped, Hash_Fn, Eq_Fn, _Alloc, Store_Hash, Comb_Hash_Fn, Resize_Policy >"Un contenedor basado en hash de encadenamiento de colisiones.

Parámetros de Plantilla

Key Tipo de clave.
Mapped Tipo de mapa.
Hash_Fn Functor de hashing. Por defecto es __gnu_cxx::hash.
Eq_Fn Functor de igualdad. Por defecto std::equal_to<Key>
_Alloc Tipo de asignador.
Store_Hash Si el tipo de clave almacena metadatos adicionales. Por defecto es false.
Comb_Hash_Fn Functor de combinación de hash. Si Hash_Fn es null_type, entonces este es el functor de hash de rango; de lo contrario, este es el functor de hash de rango. XXX(Ver Diseño::Contenedores Basados en Hash::Políticas de Hash.) Por defecto direct_mask_range_hashing.
Resize_Policy Redimensiona el hash. Por defecto es hash_standard_resize_policy, usando hash_exponential_size_policy y hash_load_check_resize_trigger.

Las bases son: detail::hash_eq_fn, Resize_Policy, detail::ranged_hash_fn, detail::types_traits. (Opcional: detail::debug_map_base.)
