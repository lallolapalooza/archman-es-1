PMFREEPROFILE(3) Manual de funciones de biblioteca PMFREEPROFILE(3)

NOMBRE

__pmFreeProfile - liberar un perfil de instancia PMAPI

SINOPSIS C

#include "pmapi.h"
#include "libpcp.h"

void __pmFreeProfile(pmProfile *prof);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas entre versiones, y pueden no funcionar, o pueden proporcionar semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

__pmFreeProfile libera el almacenamiento para el perfil de instancia PMAPI prof, asumiendo que el almacenamiento se asignó usando malloc(3) según el esquema utilizado en __pmDecodeProfile(3).

VER TAMBIÉN

malloc(3), PMAPI(3) y __pmDecodeProfile(3).
