Detailed Description

Const iterator for left child next sibling heap.

This class template provides a const iterator for a left child next sibling heap. It allows you to traverse the elements of the heap without modifying them.

The iterator supports standard iterator operations such as dereferencing (operator* and operator->), incrementing (operator++), decrementing (operator--), arithmetic operations (operator+, operator-, operator+=, operator-=), and comparison operations (operator==, operator!=, operator<, operator>, operator<=, operator>=).
