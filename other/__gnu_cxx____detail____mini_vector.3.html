Descripción detallada

template<typename _Tp>

class __gnu_cxx::__detail::__mini_vector< _Tp >"__mini_vector<> es una versión simplificada del `std::vector<>` completo.

Se debe usar solo para tipos integrados o POD (Plain Old Data). Las diferencias notables son:

1.
No están presentes todas las funciones accesoras.
2.
Se usa SÓLO para POD.
3.
No hay argumento de plantilla Allocator. Utiliza `operator new()` para obtener memoria y `operator delete()` para liberarla. Advertencia: ¡El destructor NO libera la memoria asignada, por lo que es un vector con fuga de memoria!
