PMCHECKATTRIBUTE(3) Manual de funciones de biblioteca PMCHECKATTRIBUTE(3)

NOMBRE

__pmCheckAttribute - verifica el valor de un atributo de conexión de cliente

SINOPSIS C

#include "pmapi.h"
#include "libpcp.h"

int __pmCheckAttribute(__pmAttrKey attr,
const char *value);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas en las versiones, y pueden no funcionar o proporcionar semánticas diferentes en algún momento en el futuro.

DESCRIPCIÓN

Los atributos de conexión se intercambian entre pmcd(1) y las herramientas cliente de PCP al inicio del intercambio de protocolo. Proporcionan información opcional relacionada con una conexión individual, como el nombre de un contenedor específico que está siendo analizado por el cliente.

__pmCheckAttribute verifica que el atributo attr dado sigue la sintaxis esperada para ese tipo de atributo. Esto ayuda a prevenir que contenido malicioso sea aceptado por pmcd, ya que estos atributos pueden ser utilizados posteriormente en analizadores o transferidos a una salida estructurada como formato JSON.

VALORES DE RETORNO

Al presentarse con un atributo no reconocido o un value inválido para el atributo especificado, __pmCheckAttribute devuelve un valor negativo adecuado para ser reportado con pmErrStr(3). De lo contrario, el valor de retorno es cero, indicando éxito.

VER TAMBIÉN

pmdbg(1), PMAPI(3) y pmErrStr(3).
