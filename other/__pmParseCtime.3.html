NOMBRE

__pmParseCtime - convertir cadena ctime(3) a estructura tm

C SINOPSIS

#include "pmapi.h"
#include "libpcp.h"

int __pmParseCtime(const char *cadena,
struct tm *rslt, char **errmsg);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las APIs de PCP que garantizan permanecer fijas entre lanzamientos, y pueden no funcionar, o proporcionar semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

__pmParseCtime invierte la función asctime(3). Acepta una cadena que especifica una hora y rellena la estructura tm proporcionada.

cadena es una fecha y hora completamente especificada en el formato Día MMM DD HH:MM:SS AAAA (ej. "Lun Mar 4 13:07:47 1996") o una fecha y hora parcialmente especificada como "1996", "Mar 1996", "4 Mar 1996", "Mar", "13:07:47", "13:07", "Mar 4 13:07:47", etc. Para una fecha y hora parcialmente especificada, el orden de los campos debe preservarse y los campos faltantes se rellenan a partir de la fecha y hora actuales.

El componente de segundos (SS) puede ser un número de punto flotante, por ejemplo, la hora "13:07:47.5". También se admite el reloj de 12 horas, por lo que "13:07" y "1:07 pm" son equivalentes.

__pmParseCtime devuelve 0 si tiene éxito. Devuelve -1 y un mensaje de error asignado dinámicamente en errmsg si la cadena proporcionada no se puede analizar. Asegúrese de free(3) el mensaje de error.

La estructura tm devuelta en rslt solo debe usarse como argumento para la función __pmtimevalConvert o la función __pmtimespecConvert, ya que contiene información codificada que solo será interpretada correctamente por estas rutinas.
