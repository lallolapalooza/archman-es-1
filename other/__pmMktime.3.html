PMMKTIME(3) Manual de funciones de biblioteca PMMKTIME(3)

NOMBRE

__pmMktime - convierte una estructura tm a una hora del calendario

C SINOPSIS

#include <time.h>
#include "pmapi.h"
#include "libpcp.h"

time_t __pmMktime(struct tm *timeptr);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada únicamente al uso interno por parte de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantizan que permanecerán fijas entre lanzamientos, y es posible que no funcionen, o que proporcionen semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

__pmMktime es muy similar a mktime(3), excepto que la zona horaria utilizada es la "zona horaria de informe" actual (en lugar del esquema predeterminado de la variable de entorno TZ).

Al igual que mktime(3), la hora que se va a convertir se pasa a través de timeptr, y el resultado de la función contiene la hora del calendario (el número de segundos desde las 00:00:00 UTC, 1 de enero de 1970).

La zona horaria de informe actual predeterminada es la definida por la variable de entorno TZ, por lo que __pmMktime y mktime(3) producirán inicialmente conversiones similares.

Utilice pmNewZone(3), pmNewContextZone(3) o pmUseZone(3) para establecer una nueva zona horaria de informe actual que afectará a __pmMktime pero no a mktime(3).
