__pmParseHostSpec(3)

PMPARSEHOSTSPEC(3) Manual de funciones de biblioteca PMPARSEHOSTSPEC(3)

NOMBRE

__pmParseHostSpec, __pmUnparseHostSpec, __pmFreeHostSpec - analizador de especificaciones de host uniformes

SINOPSIS

#include"pmapi.h"
#include"libpcp.h"

int __pmParseHostSpec(const char *string,
__pmHostSpec **hostsp, int *count, char **errmsg);

int __pmUnparseHostSpec(__pmHostSpec *hosts,
int count, char *string, size_t size);

void __pmFreeHostSpec(__pmHostSpec *hosts, int count);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas entre las versiones, y pueden no funcionar, o pueden proporcionar una semántica diferente en algún momento futuro.

DESCRIPCIÓN

__pmParseHostSpec acepta una string que especifica la ubicación del demonio colector de métricas de rendimiento de PCP. La sintaxis de los diversos formatos de esta string se describe en PCPIntro(1), donde también se presentan varios ejemplos.

La sintaxis permite que el nombre de host inicial de pmcd(1) sea seguido opcionalmente por una lista de números de puerto, que se probarán en orden al conectarse a pmcd en ese host. La lista de números de puerto está separada del nombre de host usando dos puntos, y cada puerto de la lista está separado por comas.

Además, se pueden especificar uno o más hosts opcionales de pmproxy(1) (actualmente, solo un host proxy es compatible con los protocolos PCP). Estos están separados entre sí y del componente pmcd usando el carácter @. Estos también pueden ir seguidos de una lista de puertos opcional, utilizando la misma sintaxis separada por comas que antes.

__pmParseHostSpec toma una especificación de host terminada en nulo y devuelve una matriz de estructuras __pmHostSpec, donde la matriz tiene count entradas.

Estas estructuras __pmHostSpec que se devuelven a través de hostsp representan cada host individual en la especificación string y tienen la siguiente declaración:

    typedef struct {
        char    *name;       /* nombre del host (siempre válido) */
        int     *ports;      /* matriz de números de puerto del host */
        int     nports;      /* número de puertos en la matriz de puertos del host */
    } __pmHostSpec;

__pmUnparseHostSpec realiza la operación inversa, creando una representación de string a partir de un número de estructuras hosts. Donde el count de estructuras indicado por hosts es mayor que uno, se utiliza la sintaxis de proxy para indicar una cadena de hosts proxy. El tamaño del búfer de string proporcionado debe ser proporcionado por el llamador usando el parámetro size.

VALOR DE RETORNO

Si la string dada se analiza correctamente, __pmParseHostSpec devuelve cero. En este caso, el almacenamiento dinámico asignado por __pmParseHostSpec puede liberarse llamando a __pmFreeHostSpec utilizando la dirección devuelta por __pmParseHostSpec a través de hosts.

__pmParseHostSpec devuelve PM_ERR_GENERIC y una cadena de mensaje de error asignada dinámicamente en errmsg, si la string dada no se analiza y el puntero errmsg proporcionado por el usuario no es nulo. Asegúrese de free(3) la cadena del mensaje de error en esta situación.

En caso de error, hosts no está definido. En caso de éxito, errmsg no está definido.

En caso de éxito, __pmUnparseHostSpec devuelve un valor positivo que indica el número de caracteres escritos en el búfer proporcionado. Sin embargo, si el búfer proporcionado era demasiado pequeño, se devuelve un código de estado negativo de -E2BIG.
