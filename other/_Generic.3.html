_Generic(3) Manual de Funciones de Biblioteca _Generic(3)

NOMBRE

_Generic - selección de tipo genérico

SINOPSIS

_Generic(expresión, tipo1: e1, ... /*, predeterminado: e */);

DESCRIPCIÓN

_Generic() evalúa la ruta de código bajo el selector de tipo que sea compatible con el tipo de la expresión de control, o predeterminado: si ningún tipo es compatible.

expresión no se evalúa.

Esto es especialmente útil para escribir macros genéricas de tipo, que se comportarán de manera diferente según el tipo del argumento.

ESTANDARES

C11.

HISTORIA

C11.

EJEMPLOS

El siguiente programa demuestra cómo escribir un reemplazo para la función estándar imaxabs(3), que al ser una función no puede realmente proporcionar lo que promete: actualizar sin problemas al tipo más amplio disponible.

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define my_imaxabs  _Generic(INTMAX_C(0),  \
    long:           labs,                  \
    long long:      llabs                  \
/*  long long long: lllabs */              \
)
int
main(void)
{
    off_t  a;
    a = -42;
    printf("imaxabs(%jd) == %jd\n", (intmax_t) a, my_imaxabs(a));
    printf("&imaxabs == %p\n", &my_imaxabs);
    printf("&labs    == %p\n", &labs);
    printf("&llabs   == %p\n", &llabs);
    exit(EXIT_SUCCESS);
}
