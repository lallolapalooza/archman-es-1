NOMBRE

__pmCleanMapDir - eliminar archivos antiguos de un directorio de mapas

C SINOPSIS

#include "pmapi.h"
#include "libpcp.h"

int __pmCleanMapDir(const char *dirname,
const char *special);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada únicamente al uso interno por parte de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las APIs de PCP que se garantiza que permanecerán fijas entre versiones, y pueden no funcionar, o proporcionar una semántica diferente en algún momento futuro.

DESCRIPCIÓN

pmlogger(1) y pmie(1) mantienen directorios de archivos de mapa que proporcionan un mapeo de un identificador de proceso (PID) de pmlogger(1) o pmie(1) a parámetros importantes de esos procesos.

__pmCleanMapDir elimina los archivos "muertos" en estos directorios, específicamente las entradas del directorio en dirname deben seguir estas reglas, de lo contrario __pmCleanMapDir las eliminará:

+
el nombre debe ser numérico, de lo contrario debe ser igual a special (si special no es NULL)
+
para una entrada de directorio numérica debe ser un archivo regular y el nombre debe ser el PID de un proceso en ejecución
+
para una coincidencia con special la entrada del directorio debe ser un enlace simbólico y el último componente del enlace debe ser la codificación ASCII del PID de un proceso en ejecución

Antes de que se realicen estas comprobaciones, __pmCleanMapDir verifica que dirname sea efectivamente un directorio, y que el ID de usuario y el ID de grupo del llamante coincidan con el ID de usuario y el ID de grupo de dirname.

VALORES DE RETORNO

Si ocurre un error grave, __pmCleanMapDir devuelve un valor negativo adecuado para ser informado con pmErrStr(3). De lo contrario, el valor de retorno es el número de entradas que han sido eliminadas.

DIAGNÓSTICOS

Se informarán diagnósticos detallados que describen las acciones de __pmCleanMapDir en la salida de error estándar si la opción de depuración misc está activada, por ejemplo, mediante -D misc desde la línea de comandos.

VER TAMBIÉN

pmdbg(1), PMAPI(3) y pmErrStr(3).
