void std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::_M_set_buffer (streamsize __off) [inline], [protected], [inherited]

Esta función establece los punteros del buffer interno, tanto para el área de obtención (get) como para la de escritura (put). Típicamente:

__off == egptr() - eback() en underflow/uflow (modo de lectura); __off == 0 en overflow (modo de escritura); __off == -1 en open, setbuf, seekoff/pos (modo no confirmado).

NB: epptr() - pbase() == _M_buf_size - 1, ya que _M_buf_size refleja la memoria asignada real y la última celda se reserva para el carácter de desbordamiento de un área de escritura completa.

Referenciado por seekpos() y setbuf().

basic_filebuf< _CharT, encoding_char_traits< _CharT > >::__filebuf_type * std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::close () [inherited]

Cierra el archivo asociado actualmente.

Devuelve

this en caso de éxito, NULL en caso de fallo

Si no hay ningún archivo abierto actualmente, esta función falla inmediatamente.

Si existe un área de buffer de escritura, se llama a overflow(eof) para vaciar todos los caracteres. Luego se cierra el archivo.

Si alguna operación falla, esta función también falla.

basic_filebuf< _CharT, encoding_char_traits< _CharT > >::int_type std::basic_filebuf< _CharT, encoding_char_traits< _CharT > >::overflow (int_type __c = _Traits::eof()) [protected], [virtual], [inherited]

Consume datos del buffer; escribe en la secuencia controlada.

Parámetros

__c Un carácter adicional a consumir.

Devuelve

eof() para indicar fallo, algún otro valor (usualmente __c, o not_eof())

Informalmente, esta función se llama cuando el buffer de salida está lleno (o no existe, ya que el buffering no es necesariamente obligatorio). Si existe un buffer, este es consumido, con algún efecto en la secuencia controlada. (Típicamente, el buffer se escribe en la secuencia tal cual). En ambos casos, el carácter c también se escribe, si __c no es eof().

Para una definición formal de esta función, consulte un buen texto como Langer & Kreft, o [27.5.2.4.5]/3-7.

Se puede crear un streambuf de salida funcional sobrescribiendo solo esta función (no se utilizará ningún área de buffer).

Nota

La versión de la clase base no hace nada, devuelve eof().

    NAME

    std::basic_filebuf — Character stream buffer associated with files.

    SYNOPSIS

    #include <streambuf>

template<typename _CharT,
         typename _Traits = std::char_traits<_CharT> >
class std::basic_filebuf : public std::basic_streambuf<_CharT, _Traits>

    Detailed Description

    This class, by deriving from std::basic_streambuf, encapsulates the necessary information for controlling a stream's buffer, and provides the interface described in that class. It adds file stream-specific functionality.

    The template parameters are:

    _CharT
    The character type of the stream buffer.
    _Traits
    The character traits type. This trait type is expected to possess the same interfacial attributes as std::char_traits.

    The basic_filebuf class is the base class for file stream buffers. It is used in conjunction with the file stream classes (basic_fstream, basic_ifstream, and basic_ofstream).

    The buffer is associated with a C-style file pointer obtained via calls to fopen (or fdopen). The file stream classes use the file stream buffer to manage input and output operations.

    A basic_filebuf object maintains three pointers that define the get and put areas:
    _M_in_beg, _M_in_cur, and _M_in_end for input;
    _M_out_beg, _M_out_cur, and _M_out_end for output.

    When a file stream is constructed, the buffer is initialized. If the file is opened successfully, the pointers are set to define the buffer regions. If the file cannot be opened, the stream will be in a failed state.
