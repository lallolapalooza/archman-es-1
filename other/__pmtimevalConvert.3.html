NOMBRE

__pmtimevalConvert, __pmtimespecConvert - convertir la estructura tm en segundos

C SINOPSIS

#include "pmapi.h"
#include "libpcp.h"

int __pmtimevalConvert(struct tm *tmin,
struct timeval *origin, struct timeval *rslt);

int __pmtimespecConvert(struct tm *tmin,
struct timespec *origin, struct timespec *rslt);

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las APIs de PCP que se garantiza que permanecerán fijas en las diferentes versiones, y pueden no funcionar, o proporcionar semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

__pmtimevalConvert y __pmtimespecConvert aceptan una estructura tm que ha sido rellenada por __pmParseCtime(3) y un punto de tiempo de referencia origin, y rellenan la estructura rslt dada con el tiempo que el usuario quiso decir al especificar una ctime parcial o un intervalo de tiempo positivo o negativo.

Típicamente, el argumento origin es la hora de inicio de un conjunto de archivos PCP, a menos que el usuario especificara un desplazamiento de intervalo negativo, en cuyo caso es la hora de finalización del archivo.

__pmtimevalConvert y __pmtimespecConvert devuelven 0 si tienen éxito. Devuelven -1 y escriben un mensaje de error en stderr, si se detecta un error.

Utilice pmNewZone(3), pmNewContextZone(3) o pmUseZone(3) para establecer una nueva zona horaria actual que afectará a __pmtimevalConvert.

VER TAMBIÉN
