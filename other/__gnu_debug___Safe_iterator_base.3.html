Descripción Detallada

Funcionalidad básica para un iterador seguro.

La clase base _Safe_iterator_base implementa la funcionalidad de un iterador seguro que no es específica de un tipo de iterador particular. Contiene un puntero de vuelta a la secuencia a la que hace referencia, junto con información de versión del iterador y punteros para formar una lista doblemente enlazada de iteradores referenciados por el contenedor.

Esta clase no debe realizar ninguna operación que pueda lanzar una excepción, o las garantías de excepción de los iteradores derivados se romperán.

Inicializa el iterador para que referencie la secuencia apuntada por __seq. __constant es verdadero cuando estamos inicializando un iterador constante, y falso si es un iterador mutable. Tenga en cuenta que __seq puede ser NULL, en cuyo caso el iterador será singular. De lo contrario, el iterador referenciará __seq y será no singular.

unsigned int __gnu_debug::_Safe_iterator_base::_M_version

El número de versión de este iterador. El valor centinela 0 se usa para indicar un iterador invalidado (es decir, uno que es singular debido a una operación en el contenedor). Este número de versión debe ser igual al número de versión en la secuencia referenciada por _M_sequence para que el iterador no sea singular.
