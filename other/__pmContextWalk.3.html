PMCONTEXTWALK(3) Manual de funciones de biblioteca PMCONTEXTWALK(3)

NOMBRE

__pmContextWalk - recorrido de todos los contextos PMAPI

SINOPSIS C

#include "pmapi.h"
#include "libpcp.h"

void (*__pmContextWalkCallback)(void *handle, __pmContext *ctxp);
int __pmContextWalk(void *handle, __pmContextWalkCallback callback,

cc ... -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas entre versiones, y es posible que no funcionen, o que proporcionen semánticas diferentes en algún momento en el futuro.

DESCRIPCIÓN

__pmContextWalk proporciona una forma segura para hilos y bloqueos de procesar cada contexto PMAPI por turno.

Para cada contexto PMAPI válido, se llama a callback con handle pasado desde el llamador de __pmContextWalk y ctxp apuntando a un contexto para el cual se ha adquirido el bloqueo c_lock. El argumento handle es un puntero a un objeto arbitrario que puede ser compartido entre el llamador de __pmContextWalk y la rutina callback, pero que no es accedido de otra manera por __pmContextWalk, por lo que podría ser NULL.

El c_lock por contexto es liberado por __pmContextWalk después de que se llama a callback y no debe ser desbloqueado por callback.

Durante la duración de la llamada a __pmContextWalk, toda la iniciación (a través de pmNewContext(3), pmDupContext (3) o pmReconnectContext(3)) y la finalización (a través de pmDestroyContext(3)) de contextos se bloquea.

VALORES DE RETORNO

__pmContextWalk devuelve el número de contextos procesados y, por lo tanto, el número de veces que se llamó a callback, o un valor negativo adecuado para informar con pmErrStr(3).

VER TAMBIÉN

PMAPI(3), pmDestroyContext(3), pmDupContext(3), pmErrStr(3), pmNewContext(3) y pmReconnectContext(3).
