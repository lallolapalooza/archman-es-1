Descripción Detallada

template<typename Key, typename Mapped, typename Tag, typename Node_Update, typename Policy_Tl, typename _Alloc>

class __gnu_pbds::basic_branch< Key, Mapped, Tag, Node_Update, Policy_Tl, _Alloc >"Una abstracción de contenedor ramificada, similar a un árbol (árbol, trie).

Parámetros de Plantilla

Key Tipo de clave.
Mapped Tipo de mapeo.
Tag Tipo de estructura de datos de instanciación, ver container_tag.
Node_Update Actualiza nodos, restaura invariantes.
Policy_TL Typelist de políticas.
_Alloc Tipo de asignador.

La base se despacha en tiempo de compilación a través de Tag, de las siguientes opciones: tree_tag, trie_tag y sus descendientes.

Las bases opcionales son: detail::ov_tree_map, detail::rb_tree_map, detail::splay_tree_map y detail::pat_trie_map.
