KEYCTL_JOIN_SESSION_KEYRING(2const) KEYCTL_JOIN_SESSION_KEYRING(2const)

NOMBRE

KEYCTL_JOIN_SESSION_KEYRING - reemplaza el keyring de sesión al que se suscribe este proceso con uno nuevo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_JOIN_SESSION_KEYRING,
             char *_Nullable desc);

DESCRIPCIÓN

Reemplaza el keyring de sesión al que se suscribe este proceso con un nuevo keyring de sesión.

Si desc es NULL, se crea un keyring anónimo con la descripción "_ses" y el proceso se suscribe a ese keyring como su keyring de sesión, desplazando el keyring de sesión anterior.

En caso contrario, desc se trata como la descripción (nombre) de un keyring, y el comportamiento es el siguiente:

•
Si existe un keyring con una descripción coincidente, el llamador intentará suscribirse a ese keyring como su keyring de sesión si es posible; si no es posible, se devuelve un error. Para poder suscribirse al keyring, el llamador debe tener permiso de búsqueda sobre el keyring.
•
Si no existe un keyring con una descripción coincidente, entonces se crea un nuevo keyring con la descripción especificada y el proceso se suscribe a ese keyring como su keyring de sesión.

VALOR DEVUELTO

En caso de éxito, el ID del keyring de sesión unido.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

VERSIONES

Hay una envoltura proporcionada en la biblioteca libkeyutils: keyctl_join_session_keyring(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.10.

VER TAMBIÉN

keyctl(2), keyctl_join_session_keyring(3)
