PIO_UNISCRNMAP

SYNOPSIS

¶

struct unimapdesc { ... }

DESCRIPTION

¶

Carga la tabla "user definable" (cuarta) en el kernel que mapea los bytes a Unicodes, que luego se traducen en símbolos de pantalla según la mapa actual de Unicode a fuente cargada. Los Unicodes especiales comenzando por U+F000 pueden usarse directamente a los símbolos de fuente. (Desde Linux 1.3.1.)

RETURN VALUE

¶

En éxito, 0 es devuelto (excepto donde indicado). En error, -1 es devuelto y errno se establece para indicar el error.
