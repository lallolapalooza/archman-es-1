KEYCTL_CHOWN(2const) KEYCTL_CHOWN(2const)

NOMBRE

KEYCTL_CHOWN - cambia la propiedad de una clave

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_CHOWN, key_serial_t key,
             uid_t uid, gid_t gid);

DESCRIPCIÓN

Cambia la propiedad (ID de usuario y grupo) de una clave.

key contiene el ID de la clave. uid contiene el nuevo ID de usuario (o -1 en caso de que el ID de usuario no deba cambiarse). gid contiene el nuevo ID de grupo (o -1 en caso de que el ID de grupo no deba cambiarse).

La clave debe otorgar al llamante permiso setattr.

Para cambiar el UID, o para cambiar el GID a un grupo del que el llamante no sea miembro, el llamante debe tener la capacidad CAP_SYS_ADMIN (ver capabilities(7)).

Si el UID se va a cambiar, el nuevo usuario debe tener suficiente cuota para aceptar la clave. La deducción de cuota se eliminará del usuario anterior al nuevo usuario en caso de que se cambie el UID.

VALOR DEVUELTO

En caso de éxito, se devuelve 0.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

VERSIÓNES

Una envoltura se proporciona en la biblioteca libkeyutils: keyctl_chown(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.10.

VER TAMBIÉN

keyctl(2), keyctl_chown(3)
