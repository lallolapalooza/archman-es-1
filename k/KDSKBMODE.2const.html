ioctl_kd(2) Manual de llamadas al sistema ioctl_kd(2)

NOMBRE

ioctl_kd - ioctls para terminales de consola y consolas virtuales

SINOPSIS

#include <linux/kd.h>  /* Definición de constantes de operación */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones ioctl(2) específicas de Linux son soportadas para terminales de consola y consolas virtuales.

KDGETLED
Obtener el estado de los LEDs. argp apunta a un char. Los tres bits inferiores de *argp se establecen al estado de los LEDs, como sigue:
LED_CAP 0x04 led de bloqueo de mayúsculas
LED_NUM 0x02 led de bloqueo numérico
LED_SCR 0x01 led de bloqueo de desplazamiento
KDSETLED
Establecer los LEDs. Los LEDs se establecen para que correspondan a los tres bits inferiores del entero sin signo en argp. Sin embargo, si se establece un bit de orden superior, los LEDs vuelven a la normalidad: mostrando el estado de las funciones del teclado de bloqueo de mayúsculas, bloqueo numérico y bloqueo de desplazamiento.

Antes de Linux 1.1.54, los LEDs solo reflejaban el estado de las banderas correspondientes del teclado, y KDGETLED/KDSETLED también cambiaban las banderas del teclado. Desde Linux 1.1.54, los LEDs se pueden hacer para mostrar información arbitraria, pero por defecto muestran las banderas del teclado. Los siguientes dos ioctls se utilizan para acceder a las banderas del teclado.

KDGKBLED
Obtener las banderas del teclado Bloq Mayús, Bloq Num, Bloq Despl (no las luces). argp apunta a un char que se establece al estado de la bandera. Los tres bits de orden inferior (máscara 0x7) obtienen el estado actual de la bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) obtienen el estado predeterminado de la bandera. (Desde Linux 1.1.54.)
KDSKBLED
Establecer las banderas del teclado Bloq Mayús, Bloq Num, Bloq Despl (no las luces). argp es un entero sin signo que tiene el estado de la bandera deseado. Los tres bits de orden inferior (máscara 0x7) tienen el estado de la bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) tienen el estado predeterminado de la bandera. (Desde Linux 1.1.54.)
KDGKBTYPE
Obtener el tipo de teclado. Devuelve el valor KB_101, definido como 0x02.
KDADDIO
Añadir puerto de E/S como válido. Equivalente a ioperm(arg,1,1).
KDDELIO
Eliminar puerto de E/S como válido. Equivalente a ioperm(arg,1,0).
KDENABIO
Habilitar E/S a la placa de vídeo. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Inhabilitar E/S a la placa de vídeo. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Establecer modo texto/gráfico. argp es un entero sin signo que contiene uno de:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtener modo texto/gráfico. argp apunta a un int que se establece a uno de los valores mostrados anteriormente para KDSETMODE.
KDMKTONE
Generar tono de duración especificada. Los 16 bits inferiores del entero sin signo en argp especifican el período en ciclos de reloj, y los 16 bits superiores dan la duración en ms. Si la duración es cero, el sonido se apaga. El control se devuelve inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especificaría el pitido normalmente asociado con un ctrl-G. (Por lo tanto, desde Linux 0.99pl1; roto en Linux 2.1.49-50.)
KIOCSOUND
Iniciar o detener la generación de sonido. Los 16 bits inferiores de argp especifican el período en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En cualquier caso, el control se devuelve inmediatamente.
GIO_CMAP
Obtener el mapa de colores predeterminado actual del kernel. argp apunta a un array de 48 bytes. (Desde Linux 1.3.3.)
PIO_CMAP
Cambiar el mapa de colores de texto predeterminado. argp apunta a un array de 48 bytes que contiene, en orden, los valores Rojo, Verde y Azul para los 16 colores de pantalla disponibles: 0 es apagado, y 255 es intensidad completa. Los colores predeterminados son, en orden: negro, rojo oscuro, verde oscuro, marrón, azul oscuro, púrpura oscuro, cian oscuro, gris claro, gris oscuro, rojo brillante, verde brillante, amarillo, azul brillante, púrpura brillante, cian brillante y blanco. (Desde Linux 1.3.3.)
GIO_FONT
Obtiene la fuente de pantalla de 256 caracteres en forma expandida. argp apunta a un array de 8192 bytes. Falla con código de error EINVAL si la fuente actualmente cargada es una fuente de 512 caracteres, o si la consola no está en modo texto.
GIO_FONTX
Obtiene la fuente de pantalla y la información asociada. argp apunta a una struct consolefontdesc (ver PIO_FONTX). Al llamar, el campo charcount debe establecerse al número máximo de caracteres que cabrían en el buffer apuntado por chardata. Al regresar, charcount y charheight se completan con los datos respectivos de la fuente actualmente cargada, y el array chardata contiene los datos de la fuente si el valor inicial de charcount indicó que había suficiente espacio; de lo contrario, el buffer no se modifica y errno se establece a ENOMEM. (Desde Linux 1.3.1.)
PIO_FONT
Establece la fuente de pantalla de 256 caracteres. Carga la fuente en el generador de caracteres EGA/VGA. argp apunta a un mapa de 8192 bytes, con 32 bytes por carácter. Solo los primeros N de ellos se usan para una fuente de 8xN (0 < N <= 32). Esta llamada también invalida el mapeo Unicode.
PIO_FONTX
Establece la fuente de pantalla y la información de renderizado asociada. argp apunta a un

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en la fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de escaneo por
                                  carácter (1-32) */
    char          *chardata;   /* datos de la fuente en
                                  forma expandida */
};

Si es necesario, la pantalla se redimensionará apropiadamente, y se enviará SIGWINCH a los procesos apropiados. Esta llamada también invalida el mapeo Unicode. (Desde Linux 1.3.1.)
PIO_FONTRESET
Restablece la fuente de pantalla, el tamaño y el mapeo Unicode a los valores predeterminados de inicio. argp no se utiliza, pero debe establecerse a NULL para garantizar la compatibilidad con versiones futuras de Linux. (Desde Linux 1.3.28.)
GIO_SCRNMAP
Obtener el mapa de pantalla del kernel. argp apunta a un área de tamaño E_TABSZ, que se carga con las posiciones de fuente utilizadas para mostrar cada carácter. Es probable que esta llamada devuelva información inútil si la fuente actualmente cargada tiene más de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapa de pantalla Unicode completo del kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), que se carga con los Unicodes que representa cada carácter. Un conjunto especial de Unicodes, comenzando en U+F000, se utiliza para representar mapeos de "directo a fuente". (Desde Linux 1.3.1.)
PIO_SCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a símbolos de pantalla de consola. argp apunta a un área de tamaño E_TABSZ.

NAME

KDGKBMODE, KDSKBMODE, KDGKBENT, KDSKBENT, KDGKBSENT, KDSKBSENT, KDGKBDIACR, KDGETKEYCODE, KDSETKEYCODE, KDSIGACCEPT, PIO_UNISCRNMAP, GIO_UNIMAP, PIO_UNIMAP, PIO_UNIMAPCLR - keyboard operations

SYNOPSIS

```c #include <linux/kd.h> long ioctl(int fd, KDGKBMODE, long *mode); long ioctl(int fd, KDSKBMODE, long mode); long ioctl(int fd, KDGKBENT, struct kbentry *entry); long ioctl(int fd, KDSKBENT, const struct kbentry *entry); long ioctl(int fd, KDGKBSENT, struct kbsentry *entry); long ioctl(int fd, KDSKBSENT, const struct kbsentry *entry); long ioctl(int fd, KDGKBDIACR, struct kbdiacrs *diacrs); long ioctl(int fd, KDGETKEYCODE, struct kbkeycode *keycode); long ioctl(int fd, KDSETKEYCODE, const struct kbkeycode *keycode); long ioctl(int fd, KDSIGACCEPT, int signum); long ioctl(int fd, PIO_UNISCRNMAP, const char *user_table); long ioctl(int fd, GIO_UNIMAP, struct unimapdesc *unimap); long ioctl(int fd, PIO_UNIMAP, const struct unimapdesc *unimap); long ioctl(int fd, PIO_UNIMAPCLR, const struct unimapinit *unimap); ```

DESCRIPTION

These ioctl(2) requests control the Linux console keyboard.

PIO_UNISCRNMAP
Loads the "user definable" (fourth) table in the kernel which maps bytes into Unicodes, which are then translated into screen symbols according to the currently loaded Unicode-to-font map. Special Unicodes starting at U+F000 can be used to map directly to the font symbols. (Since Linux 1.3.1.)
GIO_UNIMAP
Get Unicode-to-font mapping from kernel. argp points to a

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

where entries points to an array of

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Since Linux 1.1.92.)
PIO_UNIMAP
Put unicode-to-font mapping in kernel. argp points to a struct unimapdesc. (Since Linux 1.1.92)
PIO_UNIMAPCLR
Clear table, possibly advise hash algorithm. argp points to a

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 if no opinion */
    unsigned short advised_hashstep;  /* 0 if no opinion */
    unsigned short advised_hashlevel; /* 0 if no opinion */
};

(Since Linux 1.1.92.)
KDGKBMODE
Gets current keyboard mode. argp points to a long which is set to one of these:
K_RAW 0x00 /* Raw (scancode) mode */
K_XLATE 0x01 /* Translate keycodes using keymap */
K_MEDIUMRAW 0x02 /* Medium raw (scancode) mode */
K_UNICODE 0x03 /* Unicode mode */
K_OFF 0x04 /* Disabled mode (since Linux 2.6.39) */
KDSKBMODE
Sets current keyboard mode. argp is a long equal to one of the values shown for KDGKBMODE.
KDGKBMETA
Gets meta key handling mode. argp points to a long which is set to one of these:
K_METABIT 0x03 set high order bit
K_ESCPREFIX 0x04 escape prefix
KDSKBMETA
Sets meta key handling mode. argp is a long equal to one of the values shown above for KDGKBMETA.
KDGKBENT
Gets one entry in key translation table (keycode to action code). argp points to a

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

with the first two members filled in: kb_table selects the key table (0 <= kb_table < MAX_NR_KEYMAPS), and kb_index is the keycode (0 <= kb_index < NR_KEYS). kb_value is set to the corresponding action code, or K_HOLE if there is no such key, or K_NOSUCHMAP if kb_table is invalid.
KDSKBENT
Sets one entry in translation table. argp points to a struct kbentry.
KDGKBSENT
Gets one function key string. argp points to a

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string is set to the (null-terminated) string corresponding to the kb_functh function key action code.
KDSKBSENT
Sets one function key string entry. argp points to a struct kbsentry.
KDGKBDIACR
Read kernel accent table. argp points to a

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

where kb_cnt is the number of entries in the array, each of which is a

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Read kernel keycode table entry (scan code to keycode). argp points to a

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode is set to correspond to the given scancode. (89 <= scancode <= 255 only. For 1 <= scancode <= 88, keycode==scancode.) (Since Linux 1.1.63.)
KDSETKEYCODE
Write kernel keycode table entry. argp points to a struct kbkeycode. (Since Linux 1.1.63.)
KDSIGACCEPT
The calling process indicates its willingness to accept the signal argp when it is generated by pressing an appropriate key combination. (1 <= argp <= NSIG). (See spawn_console() in linux/drivers/char/keyboard.c.)

RETURN VALUE

On success, 0 is returned (except where indicated). On failure, -1 is returned, and errno is set to indicate the error.

ERRORS

EINVAL
argp is invalid.

STANDARDS

Linux.
