KEYCTL_INSTANTIATE(2const) KEYCTL_INSTANTIATE(2const)

NOMBRE

KEYCTL_INSTANTIATE, KEYCTL_INSTANTIATE_IOV, KEYCTL_NEGATE, KEYCTL_REJECT - funciones de instanciación de claves

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(size_t n;
             SYS_keyctl, KEYCTL_INSTANTIATE, key_serial_t key,
             const void payload[n], size_t n,
             key_serial_t keyring);
long syscall(size_t n;
             SYS_keyctl, KEYCTL_INSTANTIATE_IOV, key_serial_t key,
             const struct iovec payload[n], unsigned int n,
             key_serial_t keyring);
long syscall(SYS_keyctl, KEYCTL_NEGATE, key_serial_t key,
             unsigned int timeout, key_serial_t keyring);
long syscall(SYS_keyctl, KEYCTL_REJECT, key_serial_t key,
             unsigned int timeout, int error, key_serial_t keyring);

DESCRIPCIÓN

KEYCTL_INSTANTIATE
Instancia (positivamente) una clave no instanciada con una carga útil especificada.
El ID de la clave a instanciar se proporciona en key.
La carga útil de la clave se especifica en el búfer apuntado por payload; el tamaño de ese búfer se especifica en n.
La carga útil puede ser un puntero nulo y el tamaño del búfer puede ser 0 si esto es compatible con el tipo de clave (por ejemplo, si es un keyring).
La operación puede fallar si los datos de la carga útil tienen el formato incorrecto o son inválidos.
Si keyring no es cero, entonces, sujeto a las mismas restricciones y reglas que KEYCTL_LINK(2const), la clave instanciada se enlaza al keyring cuyo ID se especifica en keyring.
El llamador debe tener la clave de autorización apropiada y, una vez que la clave no instanciada ha sido instanciada, la clave de autorización se revoca. En otras palabras, esta operación solo está disponible desde un programa tipo request-key(8). Consulte request_key(2) para obtener una explicación de las claves no instanciadas y la instanciación de claves.
KEYCTL_INSTANTIATE_IOV
Instancia una clave no instanciada con una carga útil especificada a través de un vector de búferes.
Esta operación es la misma que KEYCTL_INSTANTIATE, pero los datos de la carga útil se especifican como un array de estructuras iovec (consulte iovec(3type)).
El puntero al vector de carga útil se especifica en payload. El número de elementos en el vector se especifica en n.
Los argumentos key y keyring se interpretan como para KEYCTL_INSTANTIATE.
KEYCTL_NEGATE
Instancia negativamente una clave no instanciada.
Esta operación es equivalente a la llamada:

keyctl(KEYCTL_REJECT, key, timeout, ENOKEY, keyring);

KEYCTL_REJECT
Marca una clave como instanciada negativamente y establece un temporizador de expiración en la clave. Esta operación proporciona un superconjunto de la funcionalidad de la operación anterior KEYCTL_NEGATE.
El ID de la clave que se va a instanciar negativamente se especifica en key. El argumento timeout especifica la vida útil de la clave, en segundos. El argumento error especifica el error que se devolverá cuando una búsqueda encuentre esta clave; típicamente, es uno de EKEYREJECTED, EKEYREVOKED o EKEYEXPIRED.
Si keyring no es cero, entonces, sujeto a las mismas restricciones y reglas que KEYCTL_LINK(2const), la clave instanciada negativamente se enlaza al keyring cuyo ID se especifica en keyring.
El llamador debe tener la clave de autorización apropiada. En otras palabras, esta operación solo está disponible desde un programa tipo request-key(8). Consulte request_key(2).
El llamador debe tener la clave de autorización apropiada y, una vez que la clave no instanciada ha sido instanciada, la clave de autorización se revoca. En otras palabras, esta operación solo está disponible desde un programa tipo request-key(8). Consulte request_key(2) para obtener una explicación de las claves no instanciadas y la instanciación de claves.

VALOR DE RETORNO

En caso de éxito, se devuelve 0.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

VERSIÓNES

Se proporcionan envolturas en la biblioteca libkeyutils: keyctl_instantiate(3), keyctl_instantiate_iov(3), keyctl_negate(3) y keyctl_reject(3).

ESTÁNDARES
