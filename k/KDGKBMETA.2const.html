ioctl_kd(2) Manual de llamadas al sistema ioctl_kd(2)

NOMBRE

ioctl_kd - llamadas al sistema para terminal de consola y ventanas virtuales

SINOPSIS

#include <linux/kd.h>  /* Definición de constantes de op */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones específicas de Linux ioctl(2) están soportadas para terminales de consola y ventanas virtuales.

KDGETLED
Obtiene el estado de los LEDs. argp apunta a un char. Los tres últimos bits de *argp se establecen en el estado de los LEDs, así como sigue:
LED_CAP 0x04 LED de bloq mayús
LED_NUM 0x02 LED de bloq num
LED_SCR 0x01 LED de bloq desplazamiento
KDSETLED
Establece los LEDs. Los LEDs se establecen según los tres últimos bits de argp (un entero unsigned long). Sin embargo, si un bit más alto está establecido, los LEDs se rebotan a su estado normal: muestran el estado de las funciones de teclado de bloq mayús, bloq num y bloq desplazamiento.

Antes de Linux 1.1.54, los LEDs simplemente reflejaban el estado de las correspondientes flags de teclado, y KDGETLED/KDSETLED también cambiaban las flags de teclado. Desde Linux 1.1.54, los LEDs pueden mostrar información arbitraria, pero por defecto muestran las flags de teclado. Las siguientes dos llamadas de ioctl se usan para acceder a las flags de teclado.

KDGKBLED
Obtener el estado de las flags de teclado: bloq mayús, bloq num, bloq desplazamiento (no LEDs). argp apunta a un char que se establece en el estado de las flags. Los tres bits más bajos (máscara 0x7) muestran el estado actual de las flags, y los bits más bajos del siguiente nibble (máscara 0x70) muestran el estado por defecto de las flags. (Desde Linux 1.1.54).
KDSKBLED
Establecer las flags de teclado: bloq mayús, bloq num, bloq desplazamiento (no LEDs). argp es un entero unsigned long que tiene el estado deseado de las flags. Los tres bits más bajos (máscara 0x7) muestran el estado de las flags, y los bits más bajos del siguiente nibble (máscara 0x70) muestran el estado por defecto de las flags. (Desde Linux 1.1.54).
KDGKBTYPE
Obtener el tipo de teclado. Este devuelve el valor KB_101, definido como 0x02.
KDADDIO
Añadir un puerto de I/O como válido. Equivalente a ioperm(arg,1,1).
KDDELIO
Eliminar un puerto de I/O como válido. Equivalente a ioperm(arg,1,0).
KDENABIO
Habilitar la I/O hacia la placa de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Deshabilitar la I/O hacia la placa de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Establecer modo texto/gráfico. argp es un entero sin signo que contiene uno de los siguientes valores:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtener el modo texto/gráfico. argp apunta a un int que se establece en uno de los valores mostrados anteriormente para KDSETMODE.
KDMKTONE
Generar un tono de longitud especificada. Los 16 bits bajos del entero unsigned long en argp especifican la duración en ciclos de reloj, y los 16 bits superiores dan la duración en milisegundos. Si la duración es cero, el sonido se apaga. El control retorna inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especifica el tono normal asociado con un ctrl-G. (Por lo tanto, desde Linux 0.99pl1; roto en Linux 2.1.49-50).
KIOCSOUND
Comenzar o detener la generación de sonido. Los 16 bits bajos de argp especifican la duración en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En cualquier caso, el control retorna inmediatamente.
GIO_CMAP
Obtener el mapa de color actual del kernel. argp apunta a un array de 48 bytes. (Desde Linux 1.3.3).
PIO_CMAP
Cambiar el mapa de color por defecto en modo texto. argp apunta a un array de 48 bytes que contiene, en orden, los valores de rojo, verde y azul de los 16 colores disponibles en el modo texto: 0 es apagado, y 255 es intensidad máxima. Los colores por defecto son: negro, rojo oscuro, verde oscuro, marrón, azul oscuro, marrón oscuro, cian oscuro, gris claro, gris oscuro, rojo brillante, verde brillante, amarillo, azul brillante, azul oscuro, cian brillante, blanco. (Desde Linux 1.3.3).
GIO_FONT
Obtener el fuente de pantalla de 256 caracteres en forma extendida. argp apunta a un array de 8192 bytes. Falla con error EINVAL si el fuente actual es un fuente de 512 caracteres, o si la consola no está en modo texto.
GIO_FONTX
Obtener el fuente de pantalla y información asociada. argp apunta a un struct consolefontdesc (ver PIO_FONTX). Al llamar, el campo charcount debe estar establecido en el número máximo de caracteres que caben en el buffer apuntado por chardata. Al retornar, los campos charcount y charheight se llenan con los datos respectivos para el fuente actual. El array chardata contiene los datos del fuente si el valor inicial de charcount indicó espacio suficiente; de lo contrario, el buffer se mantiene inalterado y errno se establece en ENOMEM. (Desde Linux 1.3.1).
PIO_FONT
Establecer el fuente de pantalla de 256 caracteres. Carga el fuente en el generador de caracteres EGA/VGA. argp apunta a un mapa de 8192 bytes, con 32 bytes por carácter. Solo los primeros N de ellos se usan para un fuente de 8xN (0 < N <= 32). Esta llamada también invalida el mapeo Unicode.
PIO_FONTX
Establecer el fuente de pantalla e información de renderizado. argp apunta a un

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en el fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de escaneo por carácter (1-32) */
    char          *chardata;   /* datos del fuente en forma extendida */
};

Si es necesario, la pantalla se ajustará adecuadamente y se enviará la señal SIGWINCH a los procesos adecuados. Esta llamada también invalida el mapeo Unicode. (Desde Linux 1.3.1).
PIO_FONTRESET
Restablece el fuente de pantalla, tamaño y mapeo Unicode a los valores predeterminados de arranque. argp no se usa, pero debe ser establecido a NULL para garantizar compatibilidad con versiones futuras de Linux. (Desde Linux 1.3.28).
GIO_SCRNMAP
Obtener el mapeo de pantalla desde el kernel. argp apunta a un área de tamaño E_TABSZ, la cual se carga con las posiciones del fuente usadas para mostrar cada carácter. Esta llamada puede devolver información inútil si el fuente actual es mayor de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapeo completo de pantalla en Unicode desde el kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), la cual se carga con las Unicodes que representan cada carácter. Un conjunto especial de Unicodes, comenzando en U+F000, se usan para representar mapeos "directo a fuente". (Desde Linux 1.3.1).
PIO_SCRNMAP
Carga el mapeo "usado por el usuario" (cuarto) en el kernel que mapea bytes a símbolos de pantalla en el modo consola. argp apunta a un área de tamaño E_TABSZ.
PIO_UNISCRNMAP
Carga el mapeo de pantalla en Unicode "usado por el usuario" (cuarto) en el kernel que mapea bytes a símbolos de pantalla en el modo consola. argp apunta a un área de tamaño E_TABSZ.
PIO_FONTRESET
Restablece el fuente de pantalla, tamaño y mapeo Unicode a los valores predeterminados de arranque. argp no se usa, pero debe ser establecido a NULL para garantizar compatibilidad con versiones futuras de Linux. (Desde Linux 1.3.28).
GIO_SCRNMAP
Obtener el mapeo de pantalla desde el kernel. argp apunta a un área de tamaño E_TABSZ, la cual se carga con las posiciones del fuente usadas para mostrar cada carácter. Esta llamada puede devolver información inútil si el fuente actual es mayor de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapeo completo de pantalla en Unicode desde el kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), la cual se carga con las Unicodes que representan cada carácter. Un conjunto especial de Unicodes, comenzando en U+F000, se usan para representar mapeos "directo a fuente". (Desde Linux 1.3.1).
PIO_SCRNMAP
Carga el mapeo "usado por el usuario" (cuarto) en el kernel que mapea bytes a símbolos de pantalla en el modo consola. argp apunta a un área de tamaño E_TABSZ.
PIO_UNISCRNMAP
Carga el mapeo de pantalla en Unicode "usado por el usuario" (cuarto) en el kernel que mapea bytes a símbolos de pantalla en el modo consola. argp apunta a un área de tamaño E_TABSZ.

Carga la tabla "definible por el usuario" (cuarta) en el núcleo, la cual mapea bytes a caracteres Unicode, que luego se traducen a símbolos de pantalla según el mapa Unicode-a-fuente actualmente cargado. Los caracteres Unicode especiales que comienzan en U+F000 pueden usarse para mapear directamente a los símbolos de la fuente. (Desde Linux 1.3.1.)
GIO_UNIMAP
Obtiene el mapeo de Unicode-a-fuente del núcleo. argp apunta a un

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

donde entries apunta a un array de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Desde Linux 1.1.92.)
PIO_UNIMAP
Pone el mapeo de Unicode-a-fuente en el núcleo. argp apunta a un struct unimapdesc. (Desde Linux 1.1.92)
PIO_UNIMAPCLR
Limpia la tabla, posiblemente sugiere el algoritmo de hash. argp apunta a un

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si no hay opinión */
    unsigned short advised_hashstep;  /* 0 si no hay opinión */
    unsigned short advised_hashlevel; /* 0 si no hay opinión */
};

(Desde Linux 1.1.92.)
KDGKBMODE
Obtiene el modo actual del teclado. argp apunta a un long que se establece a uno de estos:
K_RAW 0x00 /* Modo crudo (scancode) */
K_XLATE 0x01 /* Traduce códigos de tecla usando el mapa de teclas */
K_MEDIUMRAW 0x02 /* Modo crudo medio (scancode) */
K_UNICODE 0x03 /* Modo Unicode */
K_OFF 0x04 /* Modo deshabilitado (desde Linux 2.6.39) */
KDSKBMODE
Establece el modo actual del teclado. argp es un long igual a uno de los valores mostrados para KDGKBMODE.
KDGKBMETA
Obtiene el modo de manejo de la tecla meta. argp apunta a un long que se establece a uno de estos:
K_METABIT 0x03 establece el bit de orden alto
K_ESCPREFIX 0x04 prefijo de escape
KDSKBMETA
Establece el modo de manejo de la tecla meta. argp es un long igual a uno de los valores mostrados arriba para KDGKBMETA.
KDGKBENT
Obtiene una entrada en la tabla de traducción de teclas (código de tecla a código de acción). argp apunta a un

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

con los dos primeros miembros rellenos: kb_table selecciona la tabla de teclas (0 <= kb_table < MAX_NR_KEYMAPS), y kb_index es el código de tecla (0 <= kb_index < NR_KEYS). kb_value se establece al código de acción correspondiente, o K_HOLE si no existe tal tecla, o K_NOSUCHMAP si kb_table es inválido.
KDSKBENT
Establece una entrada en la tabla de traducción. argp apunta a un struct kbentry.
KDGKBSENT
Obtiene una cadena de tecla de función. argp apunta a un

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string se establece a la cadena (terminada en nulo) correspondiente a la acción de la tecla de función número kb_func.
KDSKBSENT
Establece una entrada de cadena de tecla de función. argp apunta a un struct kbsentry.
KDGKBDIACR
Lee la tabla de acentos del núcleo. argp apunta a un

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

donde kb_cnt es el número de entradas en el array, cada una de las cuales es un

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lee una entrada de la tabla de códigos de tecla del núcleo (código de escaneo a código de tecla). argp apunta a un

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode se establece para corresponder al scancodedado. (Solo 89 <= scancode <= 255. Para 1 <= scancode <= 88, keycode==scancode.) (Desde Linux 1.1.63.)
KDSETKEYCODE
Escribe una entrada en la tabla de códigos de tecla del núcleo. argp apunta a un struct kbkeycode. (Desde Linux 1.1.63.)
KDSIGACCEPT
El proceso que llama indica su disposición a aceptar la señal argp cuando se genera al presionar una combinación de teclas apropiada. (1 <= argp <= NSIG). (Ver spawn_console() en linux/drivers/char/keyboard.c.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique). En caso de fallo, se devuelve -1, y errno se establece para indicar el error.

ERRORES

EINVAL
argp es inválido.

ESTÁNDARES

Linux.
