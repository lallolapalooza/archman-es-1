keyctl(2)

Comandos del subsistema de claves de usuario

Julio de 2023

NOMBRE

keyctl - Comandos del subsistema de claves de usuario

BIBLIOTECA

Interfaz de la biblioteca de claves (libkeyutils)

SINOPSIS

#include <keyctl.h>

long keyctl(int operation, ...);

DESCRIPCIÓN

El subsistema de claves de usuario de Linux proporciona un mecanismo para almacenar y recuperar pequeñas "claves" de datos (secretos, certificados, etc.) en el kernel. La interfaz para esto es una llamada al sistemakeyctl().

Hay una gran cantidad de operaciones posibles parakeyctl(), que se pasan en el argumentooperation. La siguiente lista no es exhaustiva:

  • KEYCTL_GET_KEYRING_ID: Obtener el ID de un ID de anillo de claves.
  • KEYCTL_JOIN_SESSION_KEYRING: Unirse a un anillo de claves de sesión.
  • KEYCTL_CREATE: Crear un nuevo tipo de clave.
  • KEYCTL_GET_PERSISTENT: Obtener la clave persistente.
  • KEYCTL_GET_USER: Obtener la clave del usuario.
  • KEYCTL_GET_GROUP: Obtener la clave del grupo.
  • KEYCTL_GET_ROOT: Obtener la clave raíz.
  • KEYCTL_DESCRIBE: Describir una clave.
  • KEYCTL_CLEAR: Borrar un anillo de claves.
  • KEYCTL_LINK: Enlazar una clave a un anillo de claves.
  • KEYCTL_UNLINK: Desenlazar una clave de un anillo de claves.
  • KEYCTL_SEARCH: Buscar una clave en un anillo de claves.
  • KEYCTL_READ: Leer el contenido de una clave.
  • KEYCTL_WRITE: Escribir datos en una clave.
  • KEYCTL_UPDATE: Actualizar el contenido de una clave.
  • KEYCTL_REVOKE: Revocar una clave.
  • KEYCTL_CHOWN: Cambiar el propietario de una clave.
  • KEYCTL_SETperms: Establecer permisos de clave.
  • KEYCTL_PURGE: Purga claves de un tipo dado.
  • KEYCTL_SET_TIMEOUT: Establecer el tiempo de espera de una clave.
  • KEYCTL_ASSUME_AUTHORITY: Asumir autoridad para una clave.
  • KEYCTL_DH_COMPUTE: Calcular una clave DH.
  • KEYCTL_GET_SECURITY: Obtener la etiqueta de seguridad de una clave.
  • KEYCTL_SESSION_TO_PARENT: Copiar la clave de sesión al anillo de claves padre.
  • KEYCTL_REJECT_KEY: Rechazar una clave.
  • KEYCTL_MICRO Sleep: Dormir durante un corto período.
  • KEYCTL_IMPRINT_MKKEY: Imprimir una clave maestra.
  • KEYCTL_GET_USER_KEYRING_ID: Obtener el ID del anillo de claves del usuario.
  • KEYCTL_GET_GROUP_KEYRING_ID: Obtener el ID del anillo de claves del grupo.
  • KEYCTL_GET_ROOT_KEYRING_ID: Obtener el ID del anillo de claves raíz.

Las operacioneskeyctl()se utilizan a menudo con la utilidad de línea de comandoskeyctl(1).

VALOR DE RETORNO

El valor de retorno depende de la operación. En caso de éxito, normalmente devuelve un valor no negativo (como un ID de clave o un número de bytes). En caso de error, devuelve -1 yerrnose establece en el valor adecuado.

ERRORES

Los errores posibles incluyenEACCES,EFAULT,EINTR,EINVAL,ENOMEM,ENOTDIR,ENOTSUP,EOPNOTSUPP,EPERM,ESRCH,ETIMEDOUTyEUNKNOWN.

ESTÁNDARES

La llamada al sistemakeyctl()es específica de Linux.

HISTORIA

La llamada al sistemakeyctl()se introdujo por primera vez en el kernel de Linux 2.6.10.

VER TAMBIÉN
