KEYCTL_GET_PERSISTENT(2const) KEYCTL_GET_PERSISTENT(2const)

NOMBRE

KEYCTL_GET_PERSISTENT - obtener el keyring persistente de un usuario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_GET_PERSISTENT, uid_t uid,
             key_serial_t keyring);

DESCRIPCIÓN

Obtiene el keyring persistente (persistent-keyring(7)) para un usuario especificado y lo enlaza a un keyring especificado.

El ID de usuario se especifica en uid. Si se especifica el valor -1, se utiliza el ID de usuario real del llamador. El ID del keyring de destino se especifica en keyring.

El llamador debe tener la capacidad CAP_SETUID en su espacio de nombres de usuario para poder obtener el keyring persistente de un ID de usuario que no coincida con el ID de usuario real o efectivo del llamador.

Si la llamada tiene éxito, se añade un enlace al keyring persistente al keyring cuyo ID se especificó en keyring.

El llamador debe tener permiso de escritura en el keyring.

El kernel creará el keyring persistente si aún no existe.

Cada vez que se realiza la operación KEYCTL_GET_PERSISTENT, el keyring persistente reiniciará su tiempo de espera de expiración al valor en:


/proc/sys/kernel/keys/persistent_keyring_expiry

Si se alcanza el tiempo de espera, el keyring persistente se eliminará y todo lo que ancla podrá ser recogido por el recolector de basura.

Los keyrings persistentes se añadieron en Linux 3.13.

VALOR DE RETORNO

En caso de éxito, el ID del keyring persistente.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EPERM
uid especificó una UID distinta de la UID real o efectiva del hilo llamador, y el llamador no tenía la capacidad CAP_SETUID.

VERSIONES

Se proporciona una envoltura en la biblioteca libkeyutils: keyctl_get_persistent(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 3.13.

VER TAMBIÉN

keyctl(2), keyctl_get_persistent(3)
