KEYCTL_SET_REQKEY_KEYRING(2const) KEYCTL_SET_REQKEY_KEYRING(2const)

NOMBRE

KEYCTL_SET_REQKEY_KEYRING - establecer el keyring de destino implícito

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de las constantes KEY* */
#include <sys/syscall.h>   /* Definición de las constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SET_REQKEY_KEYRING, int op);

DESCRIPCIÓN

Establece el keyring predeterminado al que se vincularán las claves solicitadas implícitamente para este hilo, y devuelve la configuración anterior. Las solicitudes de clave implícitas son aquellas realizadas por componentes internos del kernel, como puede ocurrir, por ejemplo, al abrir archivos en un sistema de archivos AFS o NFS. Establecer el keyring predeterminado también tiene un efecto al solicitar una clave desde el espacio de usuario; consulte request_key(2) para más detalles.

El argumento op debe contener uno de los siguientes valores, para especificar el nuevo keyring predeterminado:

KEY_REQKEY_DEFL_NO_CHANGE
No cambie el keyring predeterminado. Esto se puede usar para descubrir el keyring predeterminado actual (sin cambiarlo).
KEY_REQKEY_DEFL_DEFAULT
Selecciona el comportamiento predeterminado, que es utilizar el keyring específico del hilo si existe, de lo contrario, el keyring específico del proceso si existe, de lo contrario, el keyring de sesión si existe, de lo contrario, el keyring de sesión específico de UID, de lo contrario, el keyring específico del usuario.
KEY_REQKEY_DEFL_THREAD_KEYRING
Use el keyring específico del hilo (thread-keyring(7)) como el nuevo keyring predeterminado.
KEY_REQKEY_DEFL_PROCESS_KEYRING
Use el keyring específico del proceso (process-keyring(7)) como el nuevo keyring predeterminado.
KEY_REQKEY_DEFL_SESSION_KEYRING
Use el keyring específico de sesión (session-keyring(7)) como el nuevo keyring predeterminado.
KEY_REQKEY_DEFL_USER_KEYRING
Use el keyring específico de UID (user-keyring(7)) como el nuevo keyring predeterminado.
KEY_REQKEY_DEFL_USER_SESSION_KEYRING
Use el keyring de sesión específico de UID (user-session-keyring(7)) como el nuevo keyring predeterminado.
KEY_REQKEY_DEFL_REQUESTOR_KEYRING (desde Linux 2.6.29)
Use el keyring del solicitante.

Cualquier otro valor es inválido.

La configuración controlada por esta operación es heredada por el hijo de fork(2) y se conserva tras execve(2).

VALOR DE RETORNO

En caso de éxito, devuelve el ID del keyring predeterminado anterior al que se vincularon las claves solicitadas implícitamente (uno de KEY_REQKEY_DEFL_USER_*).

En caso de error, se devuelve -1 y se establece errno para indicar el error.

VERSIÓNES

Se proporciona una envoltura en la biblioteca libkeyutils: keyctl_set_reqkey_keyring(3)

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.13.

VER TAMBIÉN

keyctl(2), keyctl_set_reqkey_keyring(3)
