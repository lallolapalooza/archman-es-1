KEYCTL_RESTRICT_KEYRING(2const) KEYCTL_RESTRICT_KEYRING(2const)

NOMBRE

KEYCTL_RESTRICT_KEYRING - restringir las claves que se pueden vincular a un keyring

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_RESTRICT_KEYRING, key_serial_t keyring,
             const char *_Nullable type, const char *restriction);

DESCRIPCIÓN

Aplica una restricción de vinculación de claves al keyring con el ID proporcionado en keyring. El llamador debe tener permiso de *setattr* en la clave. Si type es NULL, se bloquea cualquier intento de añadir una clave al keyring; de lo contrario, contiene un puntero a una cadena con un nombre de tipo de clave y restriction contiene un puntero a una cadena que describe la restricción específica del tipo. A partir de Linux 4.12, solo el tipo "asymmetric" tiene restricciones definidas:

builtin_trusted
Solo permite claves firmadas por una clave vinculada al keyring incorporado (".builtin_trusted_keys").
builtin_and_secondary_trusted
Solo permite claves firmadas por una clave vinculada al keyring secundario (".secondary_trusted_keys") o, por extensión, una clave en un keyring incorporado, ya que este último está vinculado al anterior.
key_or_keyring:key
key_or_keyring:key:chain
Si key especifica el ID de una clave de tipo "asymmetric", entonces solo se permiten claves firmadas por esta clave.
Si key especifica el ID de un keyring, entonces solo se permiten claves firmadas por una clave vinculada a este keyring.
Si se especifica ":chain", también se permiten claves firmadas por claves vinculadas al keyring de destino (es decir, el keyring con el ID especificado en el argumento keyring).

Tenga en cuenta que una restricción solo puede configurarse una vez para el keyring especificado; una vez establecida una restricción, no se puede anular.

VALOR DE RETORNO

En caso de éxito, se devuelve 0.

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EDEADLK
La restricción de keyring solicitada resultaría en un ciclo.
EEXIST
keyring ya tiene una restricción establecida.
ENOENT
El tipo proporcionado en el argumento type no admite el establecimiento de restricciones de vinculación de claves.
EOPNOTSUPP
type era "asymmetric" y la clave especificada en la especificación de restricción proporcionada en restriction tiene un tipo distinto de "asymmetric" o "keyring".

VERSIONES

Se proporciona un envoltorio en la biblioteca libkeyutils: keyctl_restrict_keyring(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 4.12.

VER TAMBIÉN

keyctl(2), keyctl_restrict_keyring(3)
