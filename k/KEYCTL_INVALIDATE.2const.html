KEYCTL_INVALIDATE(2const) KEYCTL_INVALIDATE(2const)

NOMBRE

KEYCTL_INVALIDATE - invalidar una clave

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_INVALIDATE, key_serial_t key);

DESCRIPCIÓN

Marca una clave como inválida.

El ID de la clave a invalidar se especifica en key.

Para invalidar una clave, el llamador debe tener permiso de búsqueda sobre la clave.

Esta operación marca la clave como inválida y programa su recolección inmediata de basura. El recolector de basura elimina la clave invalidada de todos los anillos de claves y la borra cuando su contador de referencias llega a cero. Después de esta operación, la clave será ignorada por todas las búsquedas, incluso si aún no ha sido borrada.

Las claves marcadas como inválidas se vuelven invisibles para las operaciones normales de claves inmediatamente, aunque siguen siendo visibles en /proc/keys (marcadas con una bandera 'i') hasta que se eliminen realmente.

VALOR DE RETORNO

En caso de éxito, se devuelve 0.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

VERSIÓNES

Se proporciona una envoltura en la biblioteca libkeyutils: keyctl_invalidate(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 3.5.

VER TAMBIÉN

keyctl(2), keyctl_invalidate(3)
