KEYCTL_SET_TIMEOUT(2const) KEYCTL_SET_TIMEOUT(2const)

NOMBRE

KEYCTL_SET_TIMEOUT - establece el temporizador de expiración en una clave

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SET_TIMEOUT, key_serial_t key, time_t t);

DESCRIPCIÓN

Establece un tiempo de espera en una clave.

El ID de la clave se especifica en key. El valor del tiempo de espera, en segundos a partir del momento actual, se especifica en t. El tiempo de espera se mide contra el reloj de tiempo real.

Especificar el valor del tiempo de espera como 0 borra cualquier tiempo de espera existente en la clave.

El archivo /proc/keys muestra el tiempo restante hasta que cada clave expirará. (Este es el único método para descubrir el tiempo de espera en una clave).

El llamante debe tener el permiso setattr en la clave o poseer un token de autorización de instanciación para la clave (ver request_key(2)).

La clave y cualquier enlace a la clave se recolectarán automáticamente como basura después de que expire el tiempo de espera. Los intentos posteriores de acceder a la clave fallarán con el error EKEYEXPIRED.

Esta operación no se puede usar para establecer tiempos de espera en claves revocadas, expiradas o instanciadas negativamente.

VALOR DE RETORNO

En caso de éxito, se devuelve 0.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

VERSIONES

Se proporciona un envoltorio en la biblioteca libkeyutils: keyctl_set_timeout(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.16.

VER TAMBIÉN

keyctl(2), keyctl_set_timeout(3)
