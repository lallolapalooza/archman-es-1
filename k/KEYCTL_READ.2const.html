KEYCTL_READ(2const) KEYCTL_READ(2const)

NOMBRE

KEYCTL_READ - leer una clave

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(size_t size;
             SYS_keyctl, KEYCTL_READ, key_serial_t key,
             char buf[_Nullable size], size_t size);

DESCRIPCIÓN

Lee los datos de carga útil de una clave.

El ID de la clave cuya carga útil se va a leer se especifica en key. Este puede ser el ID de una clave existente o cualquiera de los ID de clave especiales listados para KEYCTL_GET_KEYRING_ID(2const).

La carga útil se coloca en el búfer apuntado por buf; el tamaño de ese búfer debe especificarse en size.

Los datos devueltos se procesarán para su presentación de acuerdo con el tipo de clave. Por ejemplo, un keyring devolverá una matriz de entradas key_serial_t que representan los ID de todas las claves vinculadas a él. El tipo de clave user devolverá sus datos tal cual.

Si buf no es NULL, se copiará en el búfer la mayor cantidad de datos de carga útil que quepan. En una devolución exitosa, el valor de retorno es siempre el tamaño total de los datos de carga útil. Para determinar si el búfer tenía un tamaño suficiente, compruebe que el valor de retorno sea menor o igual al valor proporcionado en size.

La clave debe otorgar al llamador permiso de lectura, o permiso de búsqueda al buscar desde los keyrings del proceso (es decir, la clave está en posesión).

VALOR DE RETORNO

En caso de éxito, la cantidad de datos disponibles en la clave, independientemente del tamaño del búfer proporcionado.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EOPNOTSUPP
El tipo de clave no admite la lectura (por ejemplo, el tipo es "login").

VERSIONES

Se proporciona un envoltorio en la biblioteca libkeyutils: keyctl_read(3).

ESTANDARES

Linux.

HISTORIA

Linux 2.6.10.

VER TAMBIÉN

keyctl(2), keyctl_read(3), keyctl_read_alloc(3)
