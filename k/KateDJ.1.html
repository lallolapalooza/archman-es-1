NOMBRE

KateDJ - edita y remezcla transmisiones Kate en Ogg

SINOPSIS

KateDJ [-hV]

DESCRIPCIÓN

KateDJ permite extraer pistas Kate incrustadas en una transmisión Ogg, editarlas y reconstruir la transmisión Ogg después de que las pistas Kate sean modificadas.

KateDJ es un programa GUI simple, por lo que su uso se basa en la interfaz de usuario, en lugar de la línea de comandos.

Este es un recorrido por el flujo habitual del programa:

Seleccione 'Load Ogg stream' para seleccionar el archivo Ogg que desea remezclar.

Seleccione 'Demux file' para extraer las transmisiones Kate de este archivo a un directorio temporal. Dependiendo del tamaño del archivo Ogg, ese paso puede llevar un tiempo. Luego, un mensaje le dirá dónde se han colocado los archivos temporales. Todas las transmisiones Kate se decodificarán a una descripción de texto y se colocarán en este directorio temporal, y una lista de ellas, junto con su número de serie, idioma y categoría, se mostrará en una lista.

Esos archivos pueden luego ser editados a voluntad, ya sea en el editor incrustado haciendo doble clic en la transmisión en la lista proporcionada, o con su editor de texto favorito. Se puede realizar cualquier modificación, incluyendo eliminar algunos de esos archivos por completo, o incluso agregar algunos. Sin embargo, para ser reconocidos, cualquier archivo nuevo debe nombrarse de acuerdo con la misma convención de nomenclatura que los existentes.

Una vez que se realizan las modificaciones deseadas, seleccione 'Remux file from parts' para intentar recrear la transmisión Ogg. Si ocurre algún error (por ejemplo, error de sintaxis en los archivos Kate), se le informará mediante un mensaje. Una vez que se corrigen los errores, seleccione 'Remux file from parts' nuevamente, hasta que la operación tenga éxito.

El editor incrustado puede probar una transmisión modificada, por lo que es más conveniente para modificaciones rápidas, mientras que su editor de elección puede ser más potente para modificaciones complejas.

OPCIONES

-h
Muestra la ayuda de la línea de comandos.
-V
Muestra información de la versión.
