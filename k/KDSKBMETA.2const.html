DESCRIPCIÓ

N

Las siguientes operaciones ioctl(2) específicas de Linux son admitidas para las terminales de consola y las consolas virtuales. Las operaciones ioctl(2) se soportan para terminales de consola y consolas

virtuales.

ED
Obtiene el estado de los LED. argp apunta a un char. Los tres bits inferiores de *argp se establecen al estado de los LED, de la siguiente manera: _CAP x04 de mayúsculas _NUM x02 bloqueo numérico _SCR x01 bloqueo de d

KDSETL
ED
Establece los LED. Los LED se establecen para corresponder a los tres bits inferiores del entero unsigned long en argp. Sin embargo, si se establece un bit de orden superior, los LED vuelven a la normalidad: muestran el
estado de las funciones de teclado de bloqueo de m
ayúsculas, bloqueo numérico y bloqueo de desplazamiento.

Antes de Linux 1.1.54, los LED simplemente reflejaban el estado de las banderas de teclado correspondientes, y KDGETLED/KDSETLED también cambiaban las banderas de teclado. Desde Linux 1.1.54, los LED pueden mostrar información arbitraria, pero de forma predeterminada muestran las banderas del teclado. Los siguientes dos ioctls se utilizan para acceder a las banderas del

teclado.
KDGKBL
ED
Obtiene las banderas de teclado CapsLock, NumLock, ScrollLock (no las luces). argp apunta a un char que se establece al estado de la bandera. Los tres bits de menor orden (máscara 0x7) obtienen el estado actual de la bandera, y los bits de menor orden del siguiente nibble (máscara 0x70) obtienen el estado predeterminado de la bandera. (Desde Linux 1.1.
54.)
KDSKBL
ED
Establece las banderas de teclado CapsLock, NumLock, ScrollLock (no las luces). argp es un entero unsigned long que tiene el estado de bandera deseado. Los tres bits de menor orden (máscara 0x7) tienen el estado de la bandera, y los bits de menor orden del siguiente nibble (máscara 0x70) tienen el estado predeterminado de la bandera. (Desde Linux 1.1.
54.)
KDGKBTY
PE
Obtiene el tipo de teclado. Esto devuelve el valor KB_101, definido como
0x02.

IO

KDMKTO
NE
Genera un tono de longitud especificada. Los 16 bits inferiores del entero unsigned long en argp especifican el periodo en ciclos de reloj, y los 16 bits superiores indican la duración en msec. Si la duración es cero, el sonido se apaga. El control regresa inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especificaría el pitido normalmente asociado con un ctrl-G. (Así, desde Linux 0.99pl1; roto en Linux 2.1.49-50.
)
KIOCSOU
ND
Inicia o detiene la generación de sonido. Los 16 bits inferiores de argp especifican el periodo en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En cualquier caso, el control regresa
inmediatamente.
GIO_CM
AP
Obtiene el mapa de colores predeterminado actual del núcleo. argp apunta a un array de 48 bytes. (Desde Linux 1.3.
3.)
PIO_CM
AP
Cambia el mapa de colores predeterminado del modo texto. argp apunta a un array de 48 bytes que contiene, en orden, los valores de Rojo, Verde y Azul para los 16 colores de pantalla disponibles: 0 es apagado, y 255 es intensidad completa. Los colores predeterminados son, en orden: negro, rojo oscuro, verde oscuro, marrón, azul oscuro, púrpura oscuro, cian oscuro, gris claro, gris oscuro, rojo brillante, verde brillante, amarillo, azul brillante, púrpura brillante, cian brillante y blanco. (Desde Linux 1.3.
3.)
GIO_FO
NT
Obtiene la fuente de pantalla de 256 caracteres en forma expandida. argp apunta a un array de 8192 bytes. Falla con el código de error EINVAL si la fuente cargada actualmente es una fuente de 512 caracteres, o si la consola no está en modo
texto.
GIO_FON
TX
Obtiene la fuente de pantalla y la información asociada. argp apunta a un struct consolefontdesc (ver PIO_FONTX). En la llamada, el campo charcount debe establecerse al número máximo de caracteres que cabrían en el buffer apuntado por chardata. Al regresar, el charcount y el charheight se rellenan con los datos respectivos para la fuente cargada actualmente, y el array chardata contiene los datos de la fuente si el valor inicial de charcount indicaba que había espacio suficiente disponible; de lo contrario, el buffer no se toca y errno se establece a ENOMEM. (Desde Linux 1.3.
1.)
PIO_FO
NT
Establece la fuente de pantalla de 256 caracteres. Carga la fuente en el generador de caracteres EGA/VGA. argp apunta a un mapa de 8192 bytes, con 32 bytes por carácter. Solo se usan los primeros N de ellos para una fuente de 8xN (0 < N <= 32). Esta llamada también invalida el mapeo
Unicode.
PIO_FON
TX
Establece la fuente de pantalla y la información de renderizado asociada. argp apunta
a un 

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en la fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de barrido por
                                  carácter (1-32) */
    char          *chardata;   /* datos de la fuente en
                                  forma expandida
*/ };
Si es necesario, la pantalla se redimensionará adecuadamente, y se enviará SIGWINCH a los procesos correspondientes. Esta llamada también invalida el mapeo Unicode. (Desde Linux 1.3.
1.

PIO_FONTRES
ET
Restablece la fuente de pantalla, el tamaño y el mapeo Unicode a los valores predeterminados de arranque. argp no se usa, pero debe establecerse a NULL para asegurar la compatibilidad con futuras versiones de Linux. (Desde Linux 1.3.
28.)
GIO_SCRNM
AP
Obtiene el mapa de pantalla del núcleo. argp apunta a un área de tamaño E_TABSZ, que se carga con las posiciones de fuente utilizadas para mostrar cada carácter. Es probable que esta llamada devuelva información inútil si la fuente cargada actualmente tiene más de 256
caracteres.
GIO_UNISCRNM
AP
Obtiene el mapa de pantalla Unicode completo del núcleo. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), que se carga con los Unicodes que representa cada carácter. Un conjunto especial de Unicodes, que comienza en U+F000, se usa para representar mapeos "directos a fuente". (Desde Linux 1.3.
1.)
PIO_SCRNM
AP
Carga la tabla "definible por el usuario" (cuarta) en el núcleo que mapea bytes a símbolos de pantalla de consola. argp apunta a un área de tamaño
E_TABSZ.

NAME

ioctl_console - console-specific ioctl requests

SYNOPSIS

#include <sys/ioctl.h>

long ioctl(int fd, unsigned long request, ...);

DESCRIPTION

The following ioctl requests operate on a file descriptor referring to a virtual console. These requests are defined in <linux/kd.h> and <linux/vt.h>.

PIO_UNISCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a Unicodes, los cuales son luego traducidos a símbolos de pantalla según el mapa de Unicode a fuente actualmente cargado. Los Unicodes especiales que comienzan en U+F000 pueden usarse para mapear directamente a los símbolos de la fuente. (Desde Linux 1.3.1.)
GIO_UNIMAP
Obtiene el mapeo de Unicode a fuente desde el kernel. argp apunta a un

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

donde entries apunta a un array de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Desde Linux 1.1.92.)
PIO_UNIMAP
Establece el mapeo de Unicode a fuente en el kernel. argp apunta a un struct unimapdesc. (Desde Linux 1.1.92)
PIO_UNIMAPCLR
Limpia la tabla, posiblemente sugiriendo un algoritmo hash. argp apunta a un

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si no hay opinión */
    unsigned short advised_hashstep;  /* 0 si no hay opinión */
    unsigned short advised_hashlevel; /* 0 si no hay opinión */
};

(Desde Linux 1.1.92.)
KDGKBMODE
Obtiene el modo actual del teclado. argp apunta a un long que se establece a uno de estos:
K_RAW 0x00 /* Modo Raw (scancode) */
K_XLATE 0x01 /* Traduce keycodes usando el keymap */
K_MEDIUMRAW 0x02 /* Modo Medium Raw (scancode) */
K_UNICODE 0x03 /* Modo Unicode */
K_OFF 0x04 /* Modo deshabilitado (desde Linux 2.6.39) */
KDSKBMODE
Establece el modo actual del teclado. argp es un long igual a uno de los valores mostrados para KDGKBMODE.
KDGKBMETA
Obtiene el modo de manejo de la tecla meta. argp apunta a un long que se establece a uno de estos:
K_METABIT 0x03 establece el bit de orden superior
K_ESCPREFIX 0x04 prefijo de escape
KDSKBMETA
Establece el modo de manejo de la tecla meta. argp es un long igual a uno de los valores mostrados anteriormente para KDGKBMETA.
KDGKBENT
Obtiene una entrada en la tabla de traducción de teclas (keycode a action code). argp apunta a un

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

con los dos primeros miembros completados: kb_table selecciona la tabla de teclas (0 <= kb_table < MAX_NR_KEYMAPS), y kb_index es el keycode (0 <= kb_index < NR_KEYS). kb_value se establece al action code correspondiente, o K_HOLE si no existe tal tecla, o K_NOSUCHMAP si kb_table es inválido.
KDSKBENT
Establece una entrada en la tabla de traducción. argp apunta a un struct kbentry.
KDGKBSENT
Obtiene una cadena de tecla de función. argp apunta a un

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string se establece a la cadena (terminada en nulo) correspondiente al action code de la kb_funcésima tecla de función.
KDSKBSENT
Establece una entrada de cadena de tecla de función. argp apunta a un struct kbsentry.
KDGKBDIACR
Lee la tabla de acentos del kernel. argp apunta a un

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

donde kb_cnt es el número de entradas en el array, cada una de las cuales es una

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lee una entrada de la tabla de keycodes del kernel (scancode a keycode). argp apunta a un

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode se establece para corresponder al scancode dado. (Solo 89 <= scancode <= 255. Para 1 <= scancode <= 88, keycode==scancode.) (Desde Linux 1.1.63.)
KDSETKEYCODE
Escribe una entrada de la tabla de keycodes del kernel. argp apunta a un struct kbkeycode. (Desde Linux 1.1.63.)
KDSIGACCEPT
El proceso que llama indica su disposición a aceptar la señal argp cuando se genera mediante la combinación de teclas apropiada. (1 <= argp <= NSIG). (Ver spawn_console() en linux/drivers/char/keyboard.c.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique lo contrario). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
argp es inválido.

ESTÁNDARES

Linux.
