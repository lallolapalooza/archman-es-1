KEYCTL_GET_SECURITY(2const) KEYCTL_GET_SECURITY(2const)

NOMBRE

KEYCTL_GET_SECURITY - manipular la instalación de gestión de claves del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(size_t n;
             SYS_keyctl, KEYCTL_GET_SECURITY, key_serial_t key,
             char buf[_Nullable n], size_t n);

DESCRIPCIÓN

KEYCTL_GET_SECURITY (desde Linux 2.6.26)
Obtener la etiqueta de seguridad LSM (Módulo de Seguridad de Linux) de la clave especificada.

La ID de la clave cuya etiqueta de seguridad se va a obtener se especifica en key. La etiqueta de seguridad (terminada por un byte nulo) se colocará en el búfer apuntado por el argumento buf; el tamaño del búfer debe proporcionarse en n.

Si buf se especifica como NULL o el tamaño del búfer especificado en n es demasiado pequeño, el tamaño completo de la cadena de la etiqueta de seguridad (incluido el byte nulo de terminación) se devolverá como resultado de la función, y nada se copiará al búfer.

El llamador debe tener permiso de *vista* sobre la clave especificada.

La cadena de etiqueta de seguridad devuelta se representará en un formato apropiado para el LSM en vigor. Por ejemplo, con SELinux, podría verse así:


unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023

Si actualmente no hay ningún LSM en vigor, se colocará una cadena vacía en el búfer.

VALOR DE RETORNO

En caso de éxito, el tamaño de la cadena de etiqueta de seguridad LSM (incluido el byte nulo de terminación), independientemente del tamaño del búfer proporcionado.

En caso de error, se devuelve -1 y se establece errno para indicar el error.

VERSIONES

Se proporciona una envoltura en la biblioteca libkeyutils: keyctl_get_security(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.26.

VER TAMBIÉN
