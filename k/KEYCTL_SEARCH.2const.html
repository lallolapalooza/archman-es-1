KEYCTL_SEARCH(2const) KEYCTL_SEARCH(2const)

NOMBRE

KEYCTL_SEARCH - buscar una clave en un keyring

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/keyctl.h>  /* Definición de constantes KEY* */
#include <sys/syscall.h>   /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_keyctl, KEYCTL_SEARCH, key_serial_t src,
             char *type, char *desc,
             unsigned long dst);

DESCRIPCIÓN

Busca una clave en un árbol de keyrings, devolviendo su ID y opcionalmente enlazándola a un keyring especificado.

El árbol a buscar se especifica pasando el ID del keyring principal en src. La búsqueda se realiza en anchura y recursivamente.

Los argumentos type y desc especifican la clave a buscar: type contiene el tipo de clave (una cadena de caracteres terminada en nulo de hasta 32 bytes de tamaño, incluyendo el byte nulo terminador), y desc contiene la descripción de la clave (una cadena de caracteres terminada en nulo de hasta 4096 bytes de tamaño, incluyendo el byte nulo terminador).

El keyring de origen debe otorgar permiso de búsqueda al llamador. Al realizar la búsqueda recursiva, solo se buscarán los keyrings que otorguen permiso de búsqueda al llamador. Solo se pueden encontrar claves para las que el llamador tenga permiso de búsqueda.

Si se encuentra la clave, su ID se devuelve como resultado de la función.

Si se encuentra la clave y dst no es cero, entonces, sujeto a las mismas restricciones y reglas que KEYCTL_LINK(2const), la clave se enlaza al keyring cuyo ID se especifica en dst. Si el keyring de destino especificado en dst ya contiene un enlace a una clave que tiene el mismo tipo y descripción, entonces ese enlace será reemplazado por un enlace a la clave encontrada por esta operación.

En lugar de IDs de keyrings válidos existentes, los keyrings de origen (src) y destino (dst) pueden ser uno de los IDs de keyrings especiales listados en KEYCTL_GET_KEYRING_ID(2const).

VALOR DE RETORNO

En caso de éxito, el ID de la clave encontrada.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El tamaño de la descripción en desc (incluyendo el byte nulo terminador) excedió los 4096 bytes.

VERSIÓNES

Se proporciona una envoltura en la biblioteca libkeyutils: keyctl_search(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.10.

VER TAMBIÉN

keyctl(2), keyctl_search(3)
