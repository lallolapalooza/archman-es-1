NOMBRE

borg-extract - Extraer contenido de archivo

SINOPSIS

borg [opciones comunes] extract [opciones] ARCHIVO [RUTA...]

DESCRIPCIÓN

Este comando extrae el contenido de un archivo.

Por defecto, se extrae todo el archivo, pero se puede seleccionar un subconjunto de archivos y directorios pasando una lista de argumentos RUTA. La interpretación por defecto para las rutas a extraer es pp: que es una coincidencia literal de prefijo de ruta. Si desea utilizar, por ejemplo, un comodín, debe seleccionar un estilo de patrón diferente como sh: o fm:. Consulte borg_patterns para obtener más información.

La selección de archivos puede restringirse aún más utilizando la opción --exclude. Para obtener más ayuda sobre los patrones de inclusión/exclusión, consulte la salida del comando borg_patterns.

Utilizando --dry-run, puede realizar todos los pasos de extracción excepto la escritura real de los datos de salida: leer metadatos y bloques de datos del repositorio, verificar el hash/HMAC, descifrar y descomprimir.

--progress puede ser más lento que la visualización sin progreso, ya que realiza un pase adicional sobre los metadatos del archivo.

NOTA:

Actualmente, extract siempre escribe en el directorio de trabajo actual ("."), así que asegúrese de cd al lugar correcto antes de llamar a borg extract.

Cuando los directorios padres no se extraen (debido a la selección de archivos/directorios o cualquier otra razón), Borg no puede restaurar los metadatos de los directorios padres, por ejemplo, propietario, grupo, permisos, etc.

OPCIONES

Consulte borg-common(1) para opciones comunes de los comandos Borg.

argumentos

ARCHIVO
archivo a extraer
RUTA
rutas a extraer; se admiten patrones

opciones

--list
mostrar lista detallada de elementos (archivos, directorios, ...)
-n, --dry-run
no modificar realmente ningún archivo
--numeric-owner
obsoleto, usar --numeric-ids en su lugar
--numeric-ids
solo obedecer identificadores numéricos de usuario y grupo
--nobsdflags
obsoleto, usar --noflags en su lugar
--noflags
no extraer/establecer banderas (ej. NODUMP, IMMUTABLE)
--noacls
no extraer/establecer ACLs
--noxattrs
no extraer/establecer xattrs
--stdout
escribir todos los datos extraídos a stdout
--sparse
crear agujeros en el archivo disperso de salida a partir de bloques todos ceros

Opciones de inclusión/exclusión

-e PATRÓN, --exclude PATRÓN
excluir rutas que coincidan con PATRÓN
--exclude-from ARCHIVO_EXCLUSIÓN
leer patrones de exclusión de ARCHIVO_EXCLUSIÓN, uno por línea
--pattern PATRÓN
incluir/excluir rutas que coincidan con PATRÓN
--patterns-from ARCHIVO_PATRONES
leer patrones de inclusión/exclusión de ARCHIVO_PATRONES, uno por línea
--strip-components NÚMERO
Eliminar el número especificado de elementos principales de la ruta. Las rutas con menos elementos se omitirán silenciosamente.

EJEMPLOS

# Extraer archivo completo
$ borg extract /ruta/al/repo::mis-archivos
# Extraer archivo completo y listar archivos mientras se procesa
$ borg extract --list /ruta/al/repo::mis-archivos
# Verificar si un archivo podría ser extraído con éxito, pero no escribir archivos en disco
$ borg extract --dry-run /ruta/al/repo::mis-archivos
# Extraer el directorio "src"
$ borg extract /ruta/al/repo::mis-archivos home/USUARIO/src
# Extraer el directorio "src" pero excluir archivos objeto
$ borg extract /ruta/al/repo::mis-archivos home/USUARIO/src --exclude '*.o'
# Extraer solo archivos C
$ borg extract /ruta/al/repo::mis-archivos 'sh:home/USUARIO/src/*.c'
# Restaurar un dispositivo en bruto (no debe estar activo/en uso/montado en ese momento)
$ borg extract --stdout /ruta/al/repo::mi-sdx | dd of=/dev/sdx bs=10M
