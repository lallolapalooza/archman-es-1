NOMBRE

buildah-source-pull - Descarga una imagen de origen de un registro a una ruta especificada

SINOPSIS

buildah source pull [opciones] registro ruta

DESCRIPCIÓN

Descarga una imagen de origen de un registro a una ruta especificada. La operación de descarga fallará si la imagen no cumple con un artefacto de imagen de origen OCI.

Tenga en cuenta que el comando buildah-source y todos sus subcomandos son experimentales y pueden estar sujetos a cambios futuros.

OPCIONES

--creds creds

El [nombre de usuario[:contraseña]] a utilizar para autenticarse con el registro si es necesario. Si no se proporcionan uno o ambos valores, aparecerá un aviso en la línea de comandos y se podrá ingresar el valor. La contraseña se ingresa sin mostrarse.

--quiet, -q

Suprime la salida de progreso al descargar una imagen de origen.

--tls-verify valor-booleano

Requiere HTTPS y verificación de certificados al comunicarse con los registros de contenedores (por defecto es verdadero). La verificación TLS no se puede utilizar al comunicarse con un registro inseguro.
