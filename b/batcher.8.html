BATCHER(8) Documentación de InterNetNews BATCHER(8)

NOMBRE

batcher - Creación de lotes de artículos para InterNetNews

SINOPSIS

batcher [-rv] [-a artículos] [-A artículos-totales] [-b tamaño] [-B tamaño-total] [-i cadena] [-N lotes] [-p proceso] [-s separador] host [entrada]

DESCRIPCIÓN

batcher lee una lista de archivos y prepara lotes de noticias para el host especificado. Generalmente se utiliza para preparar feeds UUCP, pero los lotes resultantes pueden ser utilizados por cualquier aplicación que utilice rnews(1) para insertar los artículos. Normalmente se invoca mediante un script ejecutado por cron que utiliza shlock para bloquear el host, seguido de ctlinnd para vaciar el archivo de lotes. Consulte send-uucp(8) para ver un frontend para batcher.

batcher lee el archivo entrada, o la entrada estándar si no se proporciona ningún archivo. Si entrada es un nombre de archivo relativo, se asume que está en pathoutgoing como se establece en inn.conf. Las líneas en blanco y las líneas que comienzan con un signo de número (#) se ignoran. Todas las demás líneas de la entrada deben consistir en uno o dos campos separados por un solo espacio. El primer campo es el token de la API de almacenamiento de un artículo. El segundo campo, si está presente, especifica el tamaño del artículo en bytes.

Por defecto, los lotes se escriben en la salida estándar (lo que no es muy útil si se genera más de un lote), pero consulte la opción -p.

OPCIONES

-a artículos
Esta bandera limita el número de artículos incluidos en cada lote. El valor por defecto es sin límite. Se iniciará un nuevo lote cuando el total de bytes o el número de artículos escritos supere los límites especificados.
-A artículos-totales
Limita el número total de artículos escritos para todos los lotes. Tan pronto como el número total de artículos escritos en lotes alcance o supere artículos-totales, todos los artículos adicionales en la entrada se pospondrán. El valor por defecto es sin límite.
-b tamaño
Esta bandera establece el límite de tamaño para cada lote; tan pronto como se haya escrito al menos esta cantidad de datos, se iniciará un nuevo lote. El tamaño por defecto es 60 KB. Usar "-b 0" permitirá tamaños de lote ilimitados.
-B tamaño-total
Limita el número total de bytes escritos para todos los lotes. Tan pronto como los bytes totales escritos en lotes alcancen o superen tamaño-total, todos los artículos adicionales en la entrada se pospondrán. El valor por defecto es sin límite.
-i cadena
Un lote comienza con una línea de identificación para especificar el método de desempaquetado que se utilizará en el extremo receptor. Cuando se utiliza esta bandera, cadena, seguida de un salto de línea, se escribirá al principio de cada lote. El valor por defecto es no tener una cadena inicial (bajo la suposición de que o bien el procesador especificado con la bandera -p o algún otro proceso posterior añadirá la línea apropiada).
-N lotes
Limita el número total de lotes escritos. Tan pronto como el número de lotes escritos alcance o supere lotes, todos los artículos adicionales en la entrada se pospondrán. El valor por defecto es sin límite.
-p proceso
Por defecto, los lotes se escriben en la salida estándar, lo cual no es útil cuando se crean más de un lote de salida. Si se proporciona esta opción, cada lote se enviará a través de una tubería al comando shell proceso. El argumento proceso debe ser una cadena de formato sprintf(3), que puede tener un solo parámetro %s que será reemplazado por el nombre del host.

Un valor común es:

( echo '#! gunbatch' ; exec gzip -c ) | uux - -r -z %s!rnews

que genera lotes comprimidos con gzip y los alimenta a uux.

-r
Por defecto, batcher informa los errores a pathlog/errlog. Para suprimir esta redirección e informar los errores a la salida estándar de error, use la bandera -r.
-s separador
Cada artículo en un lote comienza con una línea separadora que indica el tamaño del artículo. separador debe ser una cadena sprintf(3), que puede tener un solo %ld en la cadena que será reemplazado por el tamaño del artículo. Si el separador no está vacío, se le añadirá un salto de línea cuando se añada al principio de cada artículo.

El separador por defecto es:

#! rnews %ld

y rara vez debería cambiarse.

-v
Al salir, batcher informa estadísticas a través de syslog. Con esta bandera, las estadísticas también se imprimirán en la salida estándar.

ESTADO DE SALIDA

Si la entrada se agota y todos los lotes se crean correctamente, batcher saldrá con un estado cero.

Si se alcanzan alguno de los límites especificados con las banderas -A, -B o -N, o si hay un error al escribir un lote, batcher intentará encolar la entrada restante copiándola a un archivo de la siguiente manera:

  • Si no hubo nombre de archivo de entrada, la entrada restante se copiará a pathoutgoing/host.
  • Si se proporcionó un nombre de archivo de entrada, la entrada restante se copiará a un archivo temporal llamado añadiendo ".bch" al final de entrada (y cualificado añadiendo pathoutgoing si entrada no era una ruta completamente cualificada). Si esto ocurre con éxito, batcher intentará renombrar este archivo temporal a entrada (reemplazando así entrada con una copia de sí mismo con todas las líneas de los artículos que se crearon correctamente eliminadas).

Al recibir una señal de interrupción o terminación, batcher finalizará la creación del lote del artículo actual, cerrará el lote y luego reescribirá el archivo de lote como se describe anteriormente.
