    NAME

    bt_format_names — formatear un nombre en un formato especificado

    SYNOPSIS

    bt_format_names [-p] [--prefix=char] [--suffix=char] [--name-format=string] [--no-name-format] [--file=file] [file ...]

    DESCRIPTION

    El comando bt_format_names formatea los nombres extraídos de la entrada proporcionada (ya sea desde el terminal o desde un archivo) según las reglas de un formato de nombre especificado. Un formato de nombre es una cadena de caracteres que indica el orden de las partes del nombre y cómo se deben procesar.

    El formato de nombre por defecto está configurado para producir salidas razonablemente bien formadas para la mayoría de los usos. En particular, si se utiliza el formato de orden de partes "fvlj" (nombre, nombre de pila, inicial, apellido), el resultado será del tipo "John Q. Public". Si se utiliza "vljf" (apellido, nombre de pila, inicial, nombre), el resultado será del tipo "Public, John Q.".

    La entrada puede ser una lista de nombres, uno por línea. Si no se proporciona ningún archivo, se leerá desde la entrada estándar.

    Hay varias opciones para controlar cómo se crean y aplican los formatos de nombre:

    -p, --prefix=char
    Establece un prefijo que se añadirá al principio de cada nombre formateado. Si no se especifica, no se añade ningún prefijo.
    --suffix=char
    Establece un sufijo que se añadirá al final de cada nombre formateado. Si no se especifica, no se añade ningún sufijo.
    --name-format=string
    Define un formato de nombre personalizado. La cadena string debe consistir en una secuencia de caracteres que representan las partes del nombre. Los caracteres válidos son:
    f
    Nombre de pila
    v
    Segundo nombre o inicial
    l
    Apellido
    j
    Sufijo (p. ej., Jr., Sr.)
    i
    Iniciales (si el nombre de pila y el segundo nombre son múltiples palabras)
    Un sufijo de ejemplo podría ser "fvlj" o "vljf".
    --no-name-format
    Desactiva cualquier formato de nombre personalizado y utiliza el formato por defecto (que generalmente produce salidas del tipo "Nombre Apellido").
    --file=file
    Especifica un archivo que contiene nombres para formatear. Se pueden especificar múltiples archivos.

    Si no se proporcionan las opciones --name-format o --no-name-format, se utiliza un formato de nombre predeterminado que generalmente genera salidas del tipo "Nombre Apellido".

    FUNCTIONS

    Este comando utiliza las siguientes funciones de la biblioteca btparse:

    bt_create_name_format()
    bt_name_format * bt_create_name_format (char *order, 
                                                boolean abbrev)
    Crea una nueva estructura de formato de nombre. El argumento order es una cadena que especifica el orden de las partes del nombre (por ejemplo, "fvlj" para nombre, inicial, apellido). El argumento abbrev es un booleano que indica si las partes del nombre deben abreviarse (por ejemplo, el nombre de pila a su inicial). Por defecto, abbrev se establece en FALSE y el orden se establece en "fvlj".
    bt_split_name()
    bt_name * bt_split_name (char *name, bt_name_format *format)
    Divide una cadena de nombre en sus partes constituyentes según el formato dado. Devuelve un puntero a una estructura bt_name. Es responsabilidad del usuario liberar esta estructura con bt_free_name().
    bt_set_format_text()
    void bt_set_format_text (bt_name_format * format, 
                                 bt_namepart part,
                                 char * pre_part,
                                 char * post_part,
                                 char * pre_token,
                                 char * post_token)
    Permite personalizar el texto que rodea a una parte específica del nombre o a los tokens dentro de esa parte. Los argumentos pre_part y post_part controlan el texto antes y después de la parte completa del nombre. Los argumentos pre_token y post_token controlan el texto antes y después de cada token dentro de la parte. Pasar NULL a cualquiera de estos argumentos no cambiará la configuración existente para ese campo.

    Por ejemplo, para obtener "Smith, J." a partir de "John Smith" (asumiendo un formato de orden "fv"):

    format = bt_create_name_format("fv", TRUE);
bt_set_format_text(format, BTN_LAST, NULL, NULL, NULL, ", ");
bt_set_format_text(format, BTN_FIRST, NULL, NULL, NULL, ".");
    Esto produciría "Smith, J.". El texto después del token del apellido se establece en ", " y el texto después del token del nombre de pila se establece en ".".
    bt_set_format_options()
    void bt_set_format_options (bt_name_format * format, 
                                    bt_namepart part,
                                    boolean abbrev,
                                    bt_joinmethod join_tokens,
                                    bt_joinmethod join_part)
    Permite un mayor control sobre el formato del nombre. abbrev controla si la parte se abrevia. join_tokens especifica cómo se unen los tokens dentro de una parte (por ejemplo, BTJ_SPACE para un espacio, BTJ_NOTHING para ninguna separación). join_part especifica cómo se une esta parte con la siguiente parte (por ejemplo, BTJ_SPACE para un espacio, BTJ_COMMA para una coma y un espacio).

    Por ejemplo, para hacer que los sufijos como "Jr." no tengan un punto final y se unan a la parte anterior con solo un espacio:

    format = bt_create_name_format("flj", FALSE);
bt_set_format_options(format, BTN_LAST, FALSE, BTJ_SPACE, BTJ_SPACE);
bt_set_format_options(format, BTN_SUFFIX, FALSE, BTJ_NOTHING, BTJ_NOTHING);
bt_set_format_text(format, BTN_SUFFIX, NULL, NULL, NULL, ""); /* Quitar el punto del sufijo */
    Esto produciría "Smith J Jr".
    bt_format_name()
    char * bt_format_name (bt_name * name, bt_name_format * format)
    Formatea una estructura bt_name (obtenida de bt_split_name()) utilizando el formato especificado. Devuelve una cadena de caracteres recién asignada que contiene el nombre formateado. Es responsabilidad del usuario liberar esta cadena con free().
    bt_free_name()
    void bt_free_name (bt_name * name)
    Libera la memoria utilizada por una estructura bt_name.
    bt_free_name_format()
    void bt_free_name_format (bt_name_format * format)
    Libera la memoria utilizada por una estructura bt_name_format.

    El proceso general es:

    1. Crear un formato de nombre con bt_create_name_format().
    2. Opcionalmente, personalizar el formato con bt_set_format_text() y bt_set_format_options().
    3. Leer cada nombre de la entrada.
    4. Dividir el nombre en partes usando bt_split_name() con el formato creado.
    5. Formatear el nombre dividido usando bt_format_name().
    6. Imprimir el nombre formateado.
    7. Liberar la memoria utilizada por la estructura bt_name y la cadena formateada.
    8. Al final, liberar la memoria utilizada por la estructura bt_name_format.

    Un ejemplo detallado de cómo se maneja el formato de nombre: cuando se crea un formato con bt_create_name_format("flj", TRUE), generalmente se configura para producir "Smith, J. Jr.". Específicamente:

    • El texto después del token "Smith" (apellido) se establece en ",", y el método de unión entre partes para el apellido se establece en "BTJ_SPACE". Esto cambia "John Smith" a "John Smith," (donde el espacio sigue a "John" se debe a la configuración de BTJ_SPACE para el nombre de pila).
    • El texto después del token "J" (inicial) se establece en ".". Esto cambia "John Smith, J" a "John Smith, J.".
    • El texto después del token "Jr" (sufijo) se establece en ".". Esto cambia "John Smith, J. Jr" a "John Smith, J. Jr.", que es la forma deseada. (Si no quieres los puntos, tendrías que establecer el texto post-token manualmente con bt_set_format_text().)

    Luego, si `jr` (sufijo) está presente y es inmediatamente después de `l` (apellido) (lo cual es casi siempre el caso), el texto pre-parte para `jr` se establece en ", ", y el método de unión entre partes para `l` se establece en "BTJ_NOTHING". Esto cambia "John Smith Jr" (donde el espacio después de "Smith" proviene del formato del apellido con un método de unión entre partes "BTJ_SPACE") a "John Smith, Jr" (donde el ", " ahora está asociado con "Jr"---de esta manera, si no hay parte `jr`, el ", " no se imprimirá).

    Finalmente, si `f` (nombre de pila) está presente e inmediatamente sigue a `j` (sufijo) o `l` (apellido) (lo cual suele ser el caso en los formatos de "apellido, nombre"), se aplica la misma trampa: el texto pre-parte para `f` se establece en ", ", y el método de unión de partes para la parte precedente (ya sea `j` o `l`) se establece en "BTJ_NOTHING".

    Si bien todas estas reglas son bastante complicadas, significan que generalmente no tienes que hacer ninguna personalización del formato del nombre. Ciertamente este es el caso si solo necesitas los órdenes de partes "fvlj" y "vljf", solo quieres abreviar el nombre de pila, quieres puntos después de los tokens abreviados, espacios no separables en los lugares "correctos" y comas en los lugares convencionales.

    Si quieres algo fuera de lo común, por ejemplo, tokens abreviados juntos sin puntuación, o apellidos abreviados, necesitarás personalizar un poco el formato del nombre con bt_set_format_text() y bt_set_format_options().

    bt_free_name_format()
    void bt_free_name_format (bt_name_format * format)
    Libera un formato de nombre creado por bt_create_name_format().
    bt_set_format_text()
    void bt_set_format_text (bt_name_format * format, 
                             bt_namepart part,
                             char * pre_part,
                             char * post_part,
                             char * pre_token,
                             char * post_token)
    Permite personalizar todo o parte del texto circundante para una sola parte del nombre. Proporciona "NULL" para cualquier fragmento de texto que no quieras cambiar.

    Por ejemplo, digamos que quieres un formato de nombre que abreviará los nombres de pila, pero sin ninguna puntuación después de los tokens abreviados. Podrías crear y personalizar el formato de la siguiente manera:

    format = bt_create_name_format ("fvlj", TRUE);
bt_set_format_text (format, 
                    BTN_FIRST,       /* parte del nombre a personalizar */
                    NULL, NULL,      /* texto pre- y post- parte */
                    NULL, "");       /* cadena vacía para post-token */

    Sin la llamada a bt_set_format_text(), "format" resultaría en nombres formateados como "J. R. Smith". Después de establecer el texto post-token para los nombres de pila a "", este nombre se convertiría en "J R Smith".

    bt_set_format_options()
    void bt_set_format_options (bt_name_format * format, 
                                bt_namepart part,
                                boolean abbrev,
                                bt_joinmethod join_tokens,
                                bt_joinmethod join_part)
    Permite una mayor personalización de un formato de nombre: puedes establecer la bandera de abreviatura y los dos métodos de unión de tokens. Por desgracia, no hay un mecanismo para dejar un valor sin cambiar; debes establecer todo con bt_set_format_options().

    Por ejemplo, digamos que simplemente quitar los puntos de los tokens abreviados en el nombre de pila no es suficiente; *realmente* quieres ahorrar espacio juntando los tokens abreviados: "JR Smith" en lugar de "J R Smith". Asumiendo que las dos llamadas en el ejemplo anterior se han realizado, lo siguiente completará el trabajo:

    bt_set_format_options (format, BTN_FIRST,
                       TRUE,         /* mantener el mismo valor para la bandera de abbrev */
                       BTJ_NOTHING,  /* juntar los tokens */
                       BTJ_SPACE);   /* espacio después del último token de la parte */

    Nótese que desafortunadamente tuvimos que conocer y proporcionar los valores actuales para la bandera de abreviatura y el método de unión post-parte, aunque solo estábamos estableciendo el método de unión intra-parte.

    bt_format_name()
    char * bt_format_name (bt_name * name, bt_name_format * format)
    Una vez que un formato de nombre ha sido creado y personalizado a tu gusto, puedes usarlo para formatear cualquier número de nombres que hayan sido divididos con "bt_split_name" (ver bt_split_names). Simplemente pasa la estructura del nombre y la estructura del formato del nombre, y se te devolverá una cadena recién asignada que contiene el nombre formateado. Es tu responsabilidad free() esta cadena.
