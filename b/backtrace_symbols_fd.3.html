DESCRIPCIÓ

N

backtrace() devuelve una traza de retorno para el programa que la invoca, en el array apuntado por buffer. Una traza de retorno es la serie de llamadas a funciones actualmente activas para el programa. Cada elemento del array apuntado por buffer es de tipo void *, y es la dirección de retorno del marco de pila correspondiente. El argumento size especifica el número máximo de direcciones que pueden almacenarse en buffer. Si la traza de retorno es mayor que size, entonces se devuelven las direcciones correspondientes a las size llamadas a funciones más recientes; para obtener la traza de retorno completa, asegúrese de que buffer y size sean lo suficientemente

grandes.

Dado el conjunto de direcciones devueltas por backtrace() en buffer, backtrace_symbols() traduce las direcciones en un array de cadenas que describen las direcciones simbólicamente. El argumento size especifica el número de direcciones en buffer. La representación simbólica de cada dirección consiste en el nombre de la función (si esto puede determinarse), un desplazamiento hexadecimal dentro de la función y la dirección de retorno real (en hexadecimal). La dirección del array de punteros a cadenas se devuelve como el resultado de la función backtrace_symbols(). Este array es malloc(3)ed por backtrace_symbols(), y debe ser liberado por el llamador. (Las cadenas a las que apunta el array de punteros no necesitan y no deben ser liberadas.

)

backtrace_symbols_fd() toma los mismos argumentos buffer y size que backtrace_symbols(), pero en lugar de devolver un array de cadenas al llamador, escribe las cadenas, una por línea, en el descriptor de archivo fd. backtrace_symbols_fd() no llama a malloc(3), y por lo tanto puede emplearse en situaciones don

de la última función podrí
a fallar, pero consulte NOTAS.

VALOR

DEVUELTO

backtrace() devuelve el número de direcciones devueltas en buffer, que no es mayor que size. Si el valor de retorno es menor que size, entonces la traza de retorno completa fue almacenada; si es igual a size, entonces puede haber sido truncada, en cuyo caso, las direcciones de los marcos de pila más antiguos no son

devueltas.

En caso de éxito, backtrace_symbols() devuelve un puntero al array malloc(3)ed por la llamada; en c

aso de error, s
e devuelve NULL.

NOTA

S

Estas funciones hacen algunas suposiciones sobre cómo la dirección de retorno de una función se almacena en la pila. Tenga en cuenta lo

siguiente:
•
La omisión de los punteros de marco (como implica cualquiera de los niveles de optimización no nulos de gcc(1)) puede causar que estas suposiciones sean
violadas.
•
Las funciones en línea no tienen marcos de
pila.
•
La optimización de llamadas de cola causa que un marco de pila reemplace a
otro.
•
backtrace() y backtrace_symbols_fd() no llaman a malloc() explícitamente, pero son parte de libgcc, que se carga dinámicamente cuando se usa por primera vez. La carga dinámicamente generalmente desencadena una llamada a malloc(3). Si necesita que ciertas llamadas a estas dos funciones no asignen memoria (en manejadores de señales, por ejemplo), necesita asegurarse de que libgcc se carg
ue de an
temano.

Los nombres de los símbolos pueden no estar disponibles sin el uso de opciones especiales del enlazador. Para sistemas que usan el enlazador GNU, es necesario usar la opción del enlazador -rdynamic. Tenga en cuenta que los nombres de las funcion

es "static" no se exponen y no esta
rán disponibles en la traza de retorno.

#include <execinfo.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#define BT_BUF_SIZE 100
void
myfunc3(void)
{
    int nptrs;
    void *buffer[BT_BUF_SIZE];
    char **strings;
    nptrs = backtrace(buffer, BT_BUF_SIZE);
    printf("backtrace() devolvió %d direcciones\n", nptrs);
    /* La llamada backtrace_symbols_fd(buffer, nptrs, STDOUT_FILENO)
       produciría una salida similar a la siguiente: */
    strings = backtrace_symbols(buffer, nptrs);
    if (strings == NULL) {
        perror("backtrace_symbols");
        exit(EXIT_FAILURE);
    }
    for (size_t j = 0; j < nptrs; j++)
        printf("%s\n", strings[j]);
    free(strings);
}
static void   /* "static" significa no exportar el símbolo.  */
myfunc2(void)
{
    myfunc3();
}
void
myfunc(int ncalls)
{
    if (ncalls > 1)
        myfunc(ncalls - 1);
    else
        myfunc2();
}
int
main(int argc, char *argv[])
{
    if (argc != 2) {
        fprintf(stderr, "%s num-calls\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    myfunc(atoi(argv[1]));
    exit(EXIT_SUCCESS)
;
}
