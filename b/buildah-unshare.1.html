NOMBRE

buildah-unshare - Ejecuta un comando dentro de un espacio de nombres de usuario modificado.

SINOPSIS

buildah unshare [opciones] [--] [comando]

DESCRIPCIÓN

Lanza un proceso (por defecto, $SHELL) en un nuevo espacio de nombres de usuario. El espacio de nombres de usuario se configura de modo que el UID y el GID principal del usuario que invoca aparezcan como UID 0 y GID 0, respectivamente. Cualquier rango que coincida con ese usuario y grupo en /etc/subuid y /etc/subgid también se mapea como sí mismo con la ayuda de los ayudantes newuidmap(1) y newgidmap(1).

buildah unshare es útil para depurar operaciones no privilegiadas y para borrar manualmente datos de almacenamiento y otros datos relacionados con imágenes y contenedores.

También es útil si desea utilizar el comando buildah mount. Si un usuario no privilegiado desea montar y trabajar con un contenedor, entonces necesita ejecutar buildah unshare. La ejecución de buildah mount falla para los usuarios no privilegiados a menos que el usuario se esté ejecutando dentro de una sesión de buildah unshare.

OPCIONES

--mount, -m [VARIABLE=]nombre_o_id_contenedor

Monta el contenedor nombre_o_id_contenedor mientras ejecuta el comando, y establece la variable de entorno VARIABLE a la ruta del punto de montaje. Si VARIABLE no se especifica, por defecto será nombre_o_id_contenedor, que puede no ser un nombre válido para una variable de entorno.

EJEMPLO

buildah unshare id

buildah unshare pwd

buildah unshare cat /proc/self/uid_map /proc/self/gid_map

buildah unshare rm -fr $HOME/.local/share/containers/storage /run/user/`id -u`/run

buildah unshare --mount id_contenedor sh -c 'cat ${id_contenedor}/etc/os-release'

buildah unshare --mount root=id_contenedor sh -c 'cat ${root}/etc/os-release'

Si desea utilizar buildah con un comando de 'montaje', puede crear un script que se parezca a:

cat > buildah-script.sh << _EOF
#!/bin/bash
ctr=$(buildah from scratch)
mnt=$(buildah mount $ctr)
dnf -y install --installroot=$mnt --use-host-config --setopt "*.countme=false" PAQUETES
dnf -y clean all --installroot=$mnt
buildah config --entrypoint="/bin/PACKAGE" --env "FOO=BAR" $ctr
buildah commit $ctr nombre_imagen
buildah unmount $ctr
_EOF
chmod +x buildah-script.sh

Luego ejecútelo con:

buildah unshare ./buildah-script.sh
