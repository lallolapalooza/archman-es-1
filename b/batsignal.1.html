BATSIGNAL(1) Manual de Comandos Generales BATSIGNAL(1)

NOMBRE

batsignal - demonio monitor de batería

SINOPSIS

batsignal [OPCIONES]

DESCRIPCIÓN

batsignal es un demonio de batería ligero escrito en C que notifica al usuario sobre los estados de la batería. Está pensado para gestores de ventanas minimalistas, pero puede ser utilizado en cualquier entorno que soporte notificaciones de escritorio a través de libnotify.

OPCIONES

-h
Mostrar ayuda
-v
Mostrar información de la versión
-b
Ejecutar batsignal como demonio en segundo plano
-o
Comprobar la batería una vez y salir
-i
Ignorar errores de batería ausente
-e
Hacer que las notificaciones expiren
-N
Desactivar notificaciones de escritorio
-w NIVEL
NIVEL de advertencia de batería (predeterminado 15). 0 desactiva este nivel
-c NIVEL
NIVEL de batería crítica (predeterminado 5). 0 desactiva este nivel
-d NIVEL
NIVEL de batería peligrosa (predeterminado 2). 0 desactiva este nivel
-f NIVEL
NIVEL de batería llena (predeterminado 0). 0 desactiva este nivel
-p
Mostrar un mensaje cuando la batería comience a cargarse o descargarse
-W MENSAJE
Mostrar MENSAJE cuando la batería esté en nivel de advertencia
-C MENSAJE
Mostrar MENSAJE cuando la batería esté en nivel crítico
-D COMANDO
Ejecutar COMANDO cuando la batería esté en nivel peligroso
-F MENSAJE
Mostrar MENSAJE cuando la batería esté llena
-P MENSAJE
Mostrar MENSAJE cuando la batería se esté cargando, si la opción -p está activada
-U MENSAJE
Mostrar MENSAJE cuando la batería se esté descargando, si la opción -p está activada
-M COMANDO
Enviar cada mensaje usando COMANDO
-n NOMBRE
NOMBRE del dispositivo de batería; se pueden separar varias baterías por comas (predeterminado BAT0)
-m SEGUNDOS
Número mínimo de SEGUNDOS (predeterminado 60) a esperar entre comprobaciones de batería. Establecer SEGUNDOS a 0 deshabilita el sondeo y espera la señal USR1 antes de comprobar el nivel de batería. Prefijar SEGUNDOS con un + (ej: -m +10) forzará una comprobación a intervalos de SEGUNDOS, independientemente del nivel de batería.
-a NOMBRE_APP
Nombre de la aplicación utilizado en las notificaciones (predeterminado: batsignal)
-I ICONO
Mostrar el ICONO especificado en las notificaciones

CONFIGURACIÓN

Las opciones se pueden pasar a batsignal como argumentos de línea de comandos o colocarse en un archivo de configuración. Las opciones del archivo de configuración se aplicarán primero y luego podrán ser sobrescritas por los argumentos de la línea de comandos.

El archivo de configuración debe incluir los argumentos de las opciones como se documenta anteriormente, un argumento por línea. Las líneas que comienzan con # y las líneas vacías se ignoran. Por ejemplo, para especificar un nivel de advertencia de 30 y ejecutar como un demonio en segundo plano, se podría usar el siguiente archivo de configuración:

# Ejecutar en segundo plano
-b
# Usar nivel de advertencia de 30
-w
30

Las siguientes rutas se comprueban en secuencia para obtener un archivo de configuración:

•
Variable de entorno BATSIGNAL_CONFIG (si está presente)
•
$HOME/.config/batsignal (o la base de configuración especificada en XDG_CONFIG_HOME)
•
$HOME/.batsignal
•
/usr/local/etc/batsignal
•
/etc/batsignal

ENTORNO

BATSIGNAL_CONFIG
Establece la ruta del archivo de configuración de opciones.
XDG_CONFIG_HOME
La ruta base para el directorio de configuración XDG. Se utiliza en la búsqueda del archivo de opciones.

SEÑALES

batsignal responde a las siguientes señales:

SIGUSR1
Enviar la señal SIGUSR1 al proceso provocará una comprobación inmediata del nivel de batería.

NOTAS

En la mayoría de los casos, batsignal realizará menos comprobaciones del estado de la batería mientras la batería se está descargando y el nivel de carga no está cerca de un nivel de advertencia. Esta frecuencia se ve afectada por la opción multiplicador (-m) y nunca es inferior a <multiplicador> segundos. Si se establece el nivel "lleno" (-f) o se habilitan los mensajes de carga/descarga (-p), batsignal comprobará el estado de la batería cada <multiplicador> segundos independientemente del nivel de carga.

Si se establece el nivel "lleno" (-f), la notificación de batería llena se activará al nivel de carga dado o cuando el estado de la batería cambie a lleno, lo que ocurra primero.

El COMANDO de mensaje pasado con -M es una cadena de formato al estilo de printf de C. Puede utilizar dos marcadores de posición de cadena (%s) que serán reemplazados por el texto del mensaje y el nivel actual de la batería. Asegúrese de probar el comando: las cadenas de formato inválidas pueden provocar que batsignal se bloquee.
Ej: -M "wall 'Advertencia de batería: %s - Nivel %s'"
