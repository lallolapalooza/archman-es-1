B::Op_private(3perl) Guía de referencia del programador de Perl B::Op_private(3perl)

NOMBRE

B::Op_private - Definiciones de bandera op_private de OP

SINOPSIS

use B::Op_private;
# detalles de la bandera para el bit 7 de op_private de OP_AELEM:
my $nombre  = $B::Op_private::bits{aelem}{7}; # OPpLVAL_INTRO
my $valor = $B::Op_private::defines{$nombre}; # 128
my $etiqueta = $B::Op_private::labels{$nombre};  # LVINTRO
# el campo de bits en los bits 5..6 de op_private de OP_AELEM:
my $campo_bits  = $B::Op_private::bits{aelem}{6};
my $mascara = $campo_bits->{bitmask}; # etc

DESCRIPCIÓN

Este módulo proporciona cuatro hashes globales:

%B::Op_private::bits
%B::Op_private::defines
%B::Op_private::labels
%B::Op_private::ops_using

que contienen información sobre los significados por op de los bits en el campo op_private.

%bits

Se indexa por el nombre del op y luego por el número de bit (0..7). Para banderas de un solo bit, devuelve el nombre de la definición (si la hay) para ese bit:

$B::Op_private::bits{aelem}{7} eq 'OPpLVAL_INTRO';

Para campos de bits, devuelve una referencia a un hash que contiene detalles sobre el campo. Se devolverá la misma referencia para todas las posiciones de bits que componen el campo de bits; así, por ejemplo, ambas devoluciones devuelven la misma referencia a hash:

$campo_bits = $B::Op_private::bits{aelem}{5};
$campo_bits = $B::Op_private::bits{aelem}{6};

El formato general de esta referencia a hash es

{
    # El rango de bits y la máscara; estos siempre están presentes.
    bitmin        => 5,
    bitmax        => 6,
    bitmask       => 0x60,
    # (Las claves restantes son opcionales)
    # Los nombres de cualquier definición que se haya solicitado:
    mask_def      => 'OPpFOO_MASK',
    baseshift_def => 'OPpFOO_SHIFT',
    bitcount_def  => 'OPpFOO_BITS',
    # Si está presente, Concise etc mostrará el valor con un prefijo
    # 'FOO='. Si es igual a '-', entonces Concise tratará el campo de
    # bits como bits brutos y no intentará interpretarlo.
    label         => 'FOO',
    # Si está presente, especifica los nombres de algunas definiciones y
    # las etiquetas de visualización que se utilizan para asignar significado
    # a valores enteros particulares dentro del campo de bits; por ejemplo,
    # 3 se muestra como 'C'.
    enum          => [ qw(
                         1   OPpFOO_A  A
                         2   OPpFOO_B  B
                         3   OPpFOO_C  C
                     )],
};

%defines

Esto da el valor de cada definición "OPp", por ejemplo.

$B::Op_private::defines{OPpLVAL_INTRO} == 128;

%labels

Esto da la etiqueta de visualización corta para cada definición, tal como la usa "B::Concise" y "perl -Dx", por ejemplo.

$B::Op_private::labels{OPpLVAL_INTRO} eq 'LVINTRO';

Si la etiqueta es igual a '-', entonces Concise tratará el bit como un bit bruto y no intentará mostrarlo simbólicamente.

%ops_using

Para cada definición, esto da una referencia a un array de nombres de op que usan la bandera.

@ops_using_lvintro = @{ $B::Op_private::ops_using{OPp_LVAL_INTRO} };
