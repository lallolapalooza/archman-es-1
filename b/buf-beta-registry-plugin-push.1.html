NOMBRE

buf-beta-registry-plugin-push - Empuja un plugin a un registro

SINOPSIS

buf beta registry plugin push [flags]

DESCRIPCIÓN

El primer argumento es la fuente a empujar (directorio que contiene buf.plugin.yaml o el archivo zip de lanzamiento del plugin), que debe ser un directorio. Esto se establece por defecto en "." si no se especifica ningún argumento.

OPCIONES

--disable-symlinks[=false] No seguir enlaces simbólicos al leer fuentes o configuración del sistema de archivos local. Por defecto, se siguen los enlaces simbólicos en esta CLI, pero nunca se siguen en el Registro de Esquemas de Buf

--format="text" El formato de salida a utilizar. Debe ser uno de [text,json]

-h, --help[=false] Ayuda para push

--image="" Imagen existente a empujar

--override-remote="" Sobrescribir el registro predeterminado encontrado en el nombre y dependencias de buf.plugin.yaml

--visibility="" La configuración de visibilidad del plugin. Debe ser uno de [public,private]

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato de registro [text,color,json]

--timeout=0s La duración hasta que se agote el tiempo, establecerlo en 0 significa sin tiempo de espera
