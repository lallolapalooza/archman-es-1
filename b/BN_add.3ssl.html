BN_add(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_ADD(3ssl) OpenSSL BN_ADD(3ssl)

NOMBRE

BN_add, BN_sub, BN_mul, BN_sqr, BN_div, BN_mod, BN_nnmod, BN_mod_add, BN_mod_sub, BN_mod_mul, BN_mod_sqr, BN_mod_sqrt, BN_exp, BN_mod_exp, BN_gcd - operaciones aritméticas sobre BIGNUMs

SINOPSIS

#include <openssl/bn.h>
int BN_add(BIGNUM *r, const BIGNUM *a, const BIGNUM *b);
int BN_sub(BIGNUM *r, const BIGNUM *a, const BIGNUM *b);
int BN_mul(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, BN_CTX *ctx);
int BN_sqr(BIGNUM *r, const BIGNUM *a, BN_CTX *ctx);
int BN_div(BIGNUM *dv, BIGNUM *rem, const BIGNUM *a, const BIGNUM *d,
           BN_CTX *ctx);
int BN_mod(BIGNUM *rem, const BIGNUM *a, const BIGNUM *m, BN_CTX *ctx);
int BN_nnmod(BIGNUM *r, const BIGNUM *a, const BIGNUM *m, BN_CTX *ctx);
int BN_mod_add(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m,
               BN_CTX *ctx);
int BN_mod_sub(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m,
               BN_CTX *ctx);
int BN_mod_mul(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, const BIGNUM *m,
               BN_CTX *ctx);
int BN_mod_sqr(BIGNUM *r, const BIGNUM *a, const BIGNUM *m, BN_CTX *ctx);
BIGNUM *BN_mod_sqrt(BIGNUM *in, const BIGNUM *a, const BIGNUM *p, BN_CTX *ctx);
int BN_exp(BIGNUM *r, const BIGNUM *a, const BIGNUM *p, BN_CTX *ctx);
int BN_mod_exp(BIGNUM *r, const BIGNUM *a, const BIGNUM *p,
               const BIGNUM *m, BN_CTX *ctx);
int BN_gcd(BIGNUM *r, const BIGNUM *a, const BIGNUM *b, BN_CTX *ctx);

DESCRIPCIÓN

BN_add() suma a y b y coloca el resultado en r ("r=a+b"). r puede ser el mismo BIGNUM que a o b.

BN_sub() resta b de a y coloca el resultado en r ("r=a-b"). r puede ser el mismo BIGNUM que a o b.

BN_mul() multiplica a y b y coloca el resultado en r ("r=a*b"). r puede ser el mismo BIGNUM que a o b. Para multiplicar por potencias de 2, use BN_lshift(3).

BN_sqr() eleva al cuadrado a y coloca el resultado en r ("r=a^2"). r y a pueden ser el mismo BIGNUM. Esta función es más rápida que BN_mul(r,a,a).

BN_div() divide a entre d y coloca el resultado en dv y el resto en rem ("dv=a/d, rem=a%d"). Cualquiera de dv y rem puede ser NULL, en cuyo caso el valor correspondiente no se devuelve. El resultado se redondea hacia cero; por lo tanto, si a es negativo, el resto será cero o negativo. Para dividir por potencias de 2, use BN_rshift(3).

BN_mod() corresponde a BN_div() con dv establecido a NULL.

BN_nnmod() reduce a módulo m y coloca el resto no negativo en r.

BN_mod_add() suma a a b módulo m y coloca el resultado no negativo en r.

BN_mod_sub() resta b de a módulo m y coloca el resultado no negativo en r.

BN_mod_mul() multiplica a por b y encuentra el resto no negativo respecto al módulo m ("r=(a*b) mod m"). r puede ser el mismo BIGNUM que a o b. Para algoritmos más eficientes para cálculos repetidos usando el mismo módulo, vea BN_mod_mul_montgomery(3) y BN_mod_mul_reciprocal(3).

BN_mod_sqr() eleva al cuadrado a módulo m y coloca el resultado en r.

BN_mod_sqrt() devuelve la raíz cuadrada modular de a tal que "in^2 = a (mod p)". El módulo p debe ser primo, de lo contrario se devolverá un error o un "resultado" incorrecto. El resultado se almacena en in que puede ser NULL. En ese caso, el resultado se asignará recientemente.

BN_exp() eleva a a la potencia py coloca el resultado en r ("r=a^p"). Esta función es más rápida que la aplicación repetida de BN_mul().

BN_mod_exp() calcula a a la potencia pmódulo m ("r=a^p % m"). Esta función usa menos tiempo y espacio que BN_exp(). No llame a esta función cuando m sea par y cualquiera de los parámetros tenga el flag BN_FLG_CONSTTIME establecido.

BN_gcd() calcula el máximo común divisor de a y b y coloca el resultado en r. r puede ser el mismo BIGNUM que a o b.

Para todas las funciones, ctx es un BN_CTX previamente asignado utilizado para variables temporales; vea BN_CTX_new(3).

Salvo que se indique lo contrario, el BIGNUM de resultado debe ser diferente de los argumentos.

NOTAS

Para operaciones modulares como BN_nnmod() o BN_mod_exp() es un error usar el mismo objeto BIGNUM para el módulo y para la salida.

VALORES DE RETORNO

El BN_mod_sqrt() devuelve el resultado (posiblemente incorrecto si p no es primo), o NULL.

Para todas las demás funciones, se devuelve 1 en caso de éxito y 0 en caso de error. El valor de retorno siempre debe comprobarse (por ejemplo, "if (!BN_add(r,a,b)) goto err;"). Los códigos de error se pueden obtener mediante ERR_get_error(3).
