bayesiano
bogofilter.

Se utiliza para volcar y cargar las bases de datos Berkeley DB de bogofilter desde y hacia archivos de texto, realizar funciones de mantenimiento de la base de datos y mostrar los valores de

palabras específicas.

OPCIONE

S

L

a

opción

-d

archivo le indica a bogoutil que imprima el contenido del archivo de la base de datos en stdout. La opción

-H

archivo le indica a bogoutil que imprima un histograma del archivo de la base de datos en stdout. La salida es similar a bogofilter -vv. Finalmente, se cuentan los hapax (tokens que solo se vieron una vez) y los tokens puros (tokens que se encontraron solo en correo legítimo o solo en correo basura). L

a

opción -l archivo le indica a bogoutil que cargue los datos de stdin en el archivo de la base de datos. Si el archivo de la base de datos existe, los datos de stdin se fusionan en el archivo de la base de datos, sumando las cuentas. L

a

opción -m le indica a bogoutil que realice funciones de mantenimiento en la base de datos especificada, es decir, descartar tokens que sean más antiguos de lo deseado, tengan cuentas demasiado pequeñas o tamaños (longitudes) demasiado largos o demasiado cortos. L

a

opción -w archivo le indica a bogoutil que muestre la información del token del archivo de la base de datos. La opción toma un argumento, que es el nombre de la lista de palabras (normalmente wordlist.db) o el nombre del directorio que la contiene. Los tokens se pueden listar en la línea de comandos o enviar por tubería a bogoutil. Cuando hay argumentos adicionales en la línea de comandos, bogoutil los usará como los tokens a buscar. Si no hay argumentos adicionales, bogoutil leerá los tokens de stdin. L

a

opción -p archivo le indica a bogoutil que muestre la información de la base de datos para uno o más tokens. La visualización incluye una columna de probabilidad con la puntuación de correo basura del token (calculada usando los valores predeterminados de bogofilter). La opción -p toma los mismos argumentos que la opción -w. L

a

opción -r archivo le indica a bogoutil que recalcule el valor ROBX y lo imprima como una fracción de seis dígitos. L

a

opción -R archivo hace lo mismo que -r, pero guarda el resultado en la base de datos de entrenamiento sin imprimirlo. L

a

opción -I archivo le indica a bogoutil que lea su entrada de archivo en lugar de stdin. La opción

-O

archivo le indica a bogoutil que escriba su salida en archivo en lugar de stdout. La opción -v produce una salida detallada

en

stderr. Esta opción es principalmente útil para la depuración. La opción -C inhibe la lectura de los archivos de configuración y permite que bogoutil use los valores

predeterminados.

La opción --conf

ig-file

archivo le indica a bogoutil que lea archivo en lugar del archivo de configuración estándar. La opción -D redirige la salida de depuración a stdout (normalmente va

a

stderr). L

a

opción -x banderas establece las banderas de depuración. La opc

ión

-n significa "reemplazar caracteres no ascii". Reemplazará los caracteres con el bit alto (0x80) por signos de interrogación. Esto puede ser útil si una lista de palabras tiene muchos tokens ilegibles, por ejemplo, de correo basura en idiomas asiáticos. Los caracteres "malos" se convertirán en signos de interrogación y los tokens coincidentes se combinarán cuando se use con -m o -l, pero no con -d. La opc

ión

-a edad indica una edad de token aceptable, descartando los más antiguos. La edad puede ser una fecha (en la forma AAAAMMDD) o un recuento de días, es decir, descartar tokens más antiguos que edad días. La opc

ión

-c valor indica que los tokens con cuentas menores o iguales a valor deben ser descartados. La opc

ión

-s mín,máx se usa para descartar tokens basados en su tamaño, es decir, longitud. Todos los tokens más cortos que mín o más largos que máx serán

descartados.

La opción -y fecha especifica la fecha que se debe dar a los tokens que no tienen fechas. El formato es

AAAAMMDD.

ENTORNO

MANTENIMIENTO

La opción --db-checkpoint directorio hace que bogoutil vacíe las cachés de búfer y realice un punto de control del entorno de la base de

datos.

La opción --db-list-logfiles directorio hace que bogoutil liste los archivos de registro en el entorno. Se pueden añadir o combinar cero o más palabras clave (separadas por espacios en blanco) para modificar el comportamiento de este modo. El comportamiento predeterminado es listar solo los archivos de registro inactivos con rutas relativas. Puede añadir all para listar todos los archivos de registro (inactivos y activos). Puede añadir absolute para cambiar el listado a rutas

absolutas.

La opción --db-prune directorio hace que bogoutil realice un punto de control del entorno de la base de datos y elimine los archivos de registro

inactivos.

La opción --db-recover directorio ejecuta una recuperación normal de la base de datos en el directorio de la base de datos especificado. Si eso falla, reintentará con una recuperación catastrófica de la base de datos (generalmente más lenta). Si eso también falla, su base de datos no se puede reparar y debe reconstruirse desde cero. Esto solo es compatible cuando se compila con soporte de Berkeley DB con transacciones habilitadas. Intentar la recuperación con soporte de QDBM o SQLite3 resultará en un

error.

La opción --db-recover-harder directorio ejecuta una recuperación catastrófica de la base de datos en el directorio de la base de datos especificado. Si eso falla, su base de datos no se puede reparar y debe reconstruirse desde cero. Esto solo es compatible cuando se compila con soporte de Berkeley DB con transacciones habilitadas. Intentar la recuperación con soporte de QDBM o SQLite3 resultará en un

error.

La opción --db-remove-environment directorio no tiene una opción corta equivalente. Ejecuta la recuperación en el directorio dado y luego elimina el entorno de la base de datos. Use esto antes de actualizar a una nueva versión de Berkeley DB si la nueva versión que se va a instalar requiere una actualización del formato del archivo de

registro.

La opción --db-print-leafpage-count archivo imprime el número de páginas de hoja en el archivo de la base de datos archivo como un número decimal, o UNKNOWN si la base de datos no admite la consulta de esta

cifra.

La opción --db-print-pagesize archivo imprime el tamaño de una página de la base de datos en archivo como un número decimal, o UNKNOWN para bases de datos con tamaño de página variable o bases de datos que no permiten una consulta del tamaño de la página de la base de

datos.

La opción --db-verify archivo solicita que bogofilter verifique el archivo de la base de

datos. Imprime solo errores, a
menos que esté en modo detallado.

FORMATO DE

DATOS

Bogoutil lee y escribe archivos de texto donde cada línea no en blanco consta de una palabra, cu

alquier cantidad de espacios en blanco horizontales, un recuento numérico de palabras, más espa
cios en blanco y (opcionalmente) una fecha en la forma AAAAMMDD. Las líneas en blanco se omiten.

VALORES DE

RETORNO

0 para una operación exitosa. 1 para la mayoría de los errores. 3 pa

ra errores de E/S u otros errores. El error 3 generalmente signific
a que algo está seriamente mal con los archivos de la base de datos.
