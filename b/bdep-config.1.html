move asigna a la configuración de compilación especificada un nuevo directorio. Se normalmente se usa después de mover o renombrar el directorio de configuración. Tenga en cuenta que se requiere un comando bdep-sync(1) explícito para que este cambio surta efecto. Vea bdep-projects-configs(1) para conocer las diversas formas de especificar una configuración de compilación.
rename

El rename subcomando asigna un nuevo nombre a la configuración de compilación especificada. Vea bdep-projects-configs(1) para conocer las diversas formas de especificar una configuración de compilación.
remove

El remove subcomando elimina una o más configuraciones de compilación del conjunto de configuraciones de compilación del proyecto. Tenga en cuenta que solo se pueden eliminar las configuraciones que no tienen paquetes inicializados. Vea bdep-projects-configs(1) para conocer las diversas formas de especificar configuraciones de compilación.
set

El set subcomando modifica varias propiedades de una o más configuraciones de compilación asociadas al proyecto. Vea bdep-projects-configs(1) para conocer las diversas formas de especificar configuraciones de compilación.

Las propiedades que se pueden modificar incluyen los indicadores predeterminado (--[no-]default), de reenvío (--[no-]forward) y de sincronización automática (--[no-]auto-sync). Tenga en cuenta que cambiar cualquiera de estos indicadores requiere un comando bdep-sync(1) explícito para que surta efecto.

OPCIONES DE CONFIGURACIÓN

--type|--config-type tipo
El tipo de la configuración que se está creando. De forma predeterminada, se crea una configuración de tipo target . Vea bpkg-cfg-create(1) para obtener información sobre los tipos de configuración.
--default
Hace que la configuración añadida o creada sea la predeterminada.
--no-default
No hace que la primera configuración añadida o creada sea la predeterminada.
--forward
Hace que la configuración añadida o creada sea de reenvío.
--no-forward
No hace que la configuración añadida o creada sea de reenvío.
--auto-sync
Hace que la configuración añadida o creada se sincronice automáticamente.
--no-auto-sync
No hace que la configuración añadida o creada se sincronice automáticamente.
--existing|-e
Inicializa una bpkg configuración basada en una configuración existente del sistema de compilación.
--wipe
Borra el directorio de configuración antes de crear la nueva configuración.
--all|-a
Usa todas las configuraciones de compilación.
--config|-c dir
Especifica la configuración de compilación como un directorio.
--directory|-d dir
Asume que el proyecto/paquete está en el directorio especificado en lugar de en el directorio de trabajo actual.
--config-name|-n nombre
Especifica la configuración de compilación como un nombre.
--config-id num
Especifica la configuración de compilación como un id.

OPCIONES COMUNES

Las opciones comunes se resumen a continuación; una descripción más detallada está disponible en bdep-common-options(1).

-v
Imprime los comandos subyacentes esenciales que se están ejecutando.
-V
Imprime todos los comandos subyacentes que se están ejecutando.
--quiet|-q
Se ejecuta en silencio, imprimiendo solo mensajes de error.
--verbose nivel
Establece el nivel de verbosidad de los diagnósticos en nivel entre 0 y 6.
--stdout-format formato
Formato de representación que se usará para imprimir en stdout.
--jobs|-j num
Número de trabajos a realizar en paralelo.
--progress
Muestra indicadores de progreso para operaciones de larga duración, como transferencias de red, compilaciones, etc.
--no-progress
Suprime los indicadores de progreso para operaciones de larga duración, como transferencias de red, compilaciones, etc.
--diag-color
Usa color en los diagnósticos.
--no-diag-color
No usa color en los diagnósticos.
--bpkg ruta
El programa gestor de paquetes que se usará para la gestión de la configuración de compilación.
--bpkg-option opt
Opción adicional que se pasará al programa gestor de paquetes.
--build ruta
El programa de compilación que se usará para compilar paquetes.
--build-option opt
Opción adicional que se pasará al programa de compilación.
--curl ruta
El programa curl que se usará para las operaciones de red.
--curl-option opt
Opción adicional que se pasará al programa curl.
--pager ruta
El programa paginador que se usará para mostrar texto largo.
--pager-option opt
Opción adicional que se pasará al programa paginador.
--options-file archivo
Lee opciones adicionales desde archivo.
--default-options dir
El directorio desde el que cargar archivos de opciones predeterminadas adicionales.
--no-default-options
No carga archivos de opciones predeterminadas.

ARCHIVOS DE OPCIONES PREDETERMINADAS

Vea bdep-default-options-files(1) para obtener una descripción general de los archivos de opciones predeterminadas. Para el config comando, el directorio de inicio de búsqueda es el directorio del proyecto. Se buscan los siguientes archivos de opciones en cada directorio y, si se encuentran, se cargan en el orden indicado:

bdep.options
bdep-config.options
bdep-config-add.options          # si el subcomando es create
bdep-config-<subcomando>.options # (dependiente del subcomando)

Las siguientes opciones del config comando no se pueden especificar en los archivos de opciones predeterminadas:

--directory|-d
--wipe
