NOMBRE

Business::ISBN - trabajar con Números Estándar Internacionales de Libro

SINOPSIS

use Business::ISBN;
# ISBNs de 10 dígitos
$isbn10 = Business::ISBN->new('1565922573');
$isbn10 = Business::ISBN->new('1-56592-257-3');
# ISBNs de 13 dígitos
$isbn13 = Business::ISBN->new('978-0-596-52724-2');
# convertir
$isbn10 = $isbn13->as_isbn10;    # para los prefijos 978
$isbn13 = $isbn10->as_isbn13;
# quizás no te importa qué es, siempre y cuando todo funcione
$isbn = Business::ISBN->new( $ARGV[0] );
#imprimir el ISBN con guiones en las posiciones habituales
print $isbn->as_string;
#print el ISBN con guiones en posiciones específicas.
#esto no afecta a las posiciones predeterminadas
print $isbn->as_string([]);
#imprimir el código de grupo o el código de editor
print $isbn->group_code;
print $isbn->publisher_code;
#comprobar si el ISBN es válido
$isbn->is_valid;
#arreglar el dígito de control del ISBN.  CUIDADO:  el error podría no estar
#en el dígito de control!
$isbn->fix_checksum;
# crear un código de barras EAN13 en formato PNG
$isbn->png_barcode;

DESCRIPCIÓN

Este módulo maneja Números Estándar Internacionales de Libro, incluyendo ISBN-10 e ISBN-13.

Los datos provienen de Business::ISBN::Data, lo que significa que puedes actualizar los datos por separado del código. Además, puedes usar Business::ISBN::Data con cualquier RangeMessage.xml que desees si tienes datos actualizados. Consulta ese módulo para más detalles.

Interfaz de función

valid_isbn_checksum( ISBN10 | ISBN13 )
Esta función es exportable a petición, y funciona para ISBNs de 10 o 13 caracteres). 
use Business::ISBN qw( valid_isbn_checksum );

Devuelve 1 si el ISBN es un ISBN válido con el dígito de control correcto.

Devuelve 0 si el ISBN tiene prefijos y códigos de editor válidos, pero un dígito de control inválido.

Devuelve undef si el ISBN no valida por cualquier otra razón.

Interfaz de objeto

new($isbn)
El constructor acepta un escalar que representa el ISBN.

La cadena que representa el ISBN puede contener caracteres distintos de "[0-9xX]", aunque estos serán eliminados en la representación interna. La cadena resultante debe parecerse a un ISBN - los primeros nueve caracteres deben ser dígitos y el décimo carácter debe ser un dígito, 'x', o 'X'.

El constructor intenta determinar el código de grupo y el código de editor. Si estos datos no pueden determinarse, el constructor establece "$obj->error" a algo distinto de "GOOD_ISBN". Un objeto es devuelto igualmente y depende del programa comprobar el "error" método para uno de cinco valores o uno de los "error_*" métodos para comprobar un error en particular. Los valores reales de estas versiones simbólicas son los mismos que los de versiones anteriores de este módulo que usaban valores literales:

Business::ISBN::INVALID_PUBLISHER_CODE
Business::ISBN::INVALID_GROUP_CODE
Business::ISBN::BAD_CHECKSUM
Business::ISBN::GOOD_ISBN
Business::ISBN::BAD_ISBN

Si tienes uno de estos valores y quieres convertirlo en una cadena, puedes usar el %Business::ISBN::ERROR_TEXT hash, que es exportable pidiéndolo explícitamente en la lista de importación:

use Business::ISBN qw(%ERROR_TEXT);

A partir de la versión 2.010_01, puedes obtener este texto desde "error_text" así que no tienes que importar nada.

La cadena pasada como ISBN no necesita ser un ISBN válido mientras superficialmente se parezca a uno. Esto permite usar el fix_checksum() método. A pesar de la advertencia en la discusión de ese método, el autor lo ha encontrado extremadamente útil. Debería comprobar la validez del ISBN con is_valid() en lugar de confiar en el valor de retorno del constructor. Si todo lo que se quiere hacer es comprobar la validez de un ISBN, se puede saltar la interfaz orientada a objetos y usar la valid_isbn_checksum() función que es exportable a petición.

Si el constructor decide que no puede crear un objeto, devuelve "undef". Puede hacerlo si la cadena pasada como ISBN no puede ser convertida al formato interno lo que significa que ni siquiera se parece a un ISBN.

Métodos de instancia

input_isbn
Devuelve el ISBN inicial. Dado que puedes insertar guiones o arreglar dígitos de control, es posible que quieras ver los datos originales.
common_data
Devuelve el ISBN inicial después de la normalización, que elimina cualquier cosa que no sea un dígito o un carácter de dígito de control válido.
isbn
Devuelve el valor actual del ISBN, incluso si tiene un dígito de control inválido. Estos son los datos crudos, así que no tienen los guiones. Si quieres guiones, prueba "as_string".

El "isbn" método debería ser igual a as_string( [] ).

error
Devuelve el código de error por la razón por la que el ISBN no es válido. El valor de retorno es una clave en %ERROR_TEXT.
error_is_bad_group
error_is_bad_publisher
error_is_article_out_of_range
error_is_bad_checksum
Devuelve verdadero si el error del ISBN es de ese tipo.
error_text
Devuelve una versión de texto del texto de error
is_valid
Devuelve verdadero si el ISBN es válido, lo que significa que tiene un prefijo válido (para ISBN-13), código de grupo, y código de editor; y su dígito de control valida.
type
Devuelve ya sea "ISBN10" o "ISBN13".
prefix
Devuelve el prefijo para el ISBN. Actualmente es ya sea 978 o 979 para ISBN-13. Devuelve la cadena vacía (es decir, un valor definido) para ISBN-10.
group_code
Devuelve el código de grupo para el ISBN. Esta es la versión numérica, por ejemplo, '0' para el grupo en inglés. Los códigos de grupo válidos provienen de "Business::ISBN::Data".
group
Devuelve el nombre del grupo para el ISBN. Esta es la versión de cadena. Por ejemplo, 'English' para el grupo '0'. Los nombres provienen de "Business::ISBN::Data".
publisher_code
Devuelve el código de editor para el ISBN. Esta es la versión numérica, por ejemplo '596' para O'Reilly Media.
article_code
Devuelve el código de artículo para el ISBN. Esta es la versión numérica que identifica únicamente al artículo.
article_code_length
Devuelve la longitud del código de artículo para el ISBN.
article_code_min
Devuelve la longitud mínima del código de artículo para el código de editor.
article_code_max
Devuelve la longitud máxima del código de artículo para el código de editor.
checksum
Devuelve el código de dígito de control para el ISBN. Esta suma de comprobación puede no ser válida ya que puede crear un objeto y arreglar la suma de comprobación después con "fix_checksum".
is_valid_checksum
Devuelve "Business::ISBN::GOOD_ISBN" para sumas de comprobación válidas y "Business::ISBN::BAD_CHECKSUM" en caso contrario. Esto no garantiza que el resto del ISBN esté realmente asignado a un libro.
fix_checksum
Comprueba la suma de comprobación y modifica el ISBN para establecerla correctamente si es necesario.
as_string(), as_string([])
Devuelve el ISBN como una cadena de texto. Esta función toma como argumento opcional un array anónimo (o referencia a un array) que especifica la colocación de los guiones en la cadena. Un array anónimo vacío produce una cadena sin guiones. Una lista de argumentos vacía coloca automáticamente los guiones en el ISBN basándose en los códigos de grupo y de editorial descubiertos. Un ISBN que no es válido puede producir resultados extraños.

Las posiciones especificadas en el array anónimo pasado solo se usan para un solo método y no reemplazan los valores especificados por el constructor. El método asume que sabe lo que está haciendo y intentará usar las tres últimas posiciones especificadas. Si pasa un array anónimo con varias posiciones, la lista se ordenará y se usarán las tres posiciones más bajas. Las posiciones menores que 1 y mayores que 12 se ignoran silenciosamente.

Una 'x' final se cambia por 'X'.

as_isbn10
Devuelve un nuevo objeto ISBN. Si el objeto ya es ISBN-10, este método lo clona. Si es un ISBN-13 con el prefijo 978, devuelve el ISBN-10 equivalente. En todos los demás casos devuelve undef.
as_isbn13
Devuelve un nuevo objeto ISBN. Si el objeto ya es ISBN-13, este método lo clona. Si es un ISBN-10, devuelve el ISBN-13 equivalente con el prefijo 978.
increment
Devuelve el siguiente "Business::ISBN" incrementando el código de artículo del ISBN especificado (objeto o escalar).

Devuelve undef, si el parámetro es inválido o es igual al ISBN máximo posible para la editorial.

$isbn = Business::ISBN->new('1565922573');  # 1-56592-257-3
$next_isbn = $isbn->increment;              # 1-56592-258-1

Si el siguiente código de artículo excedería el código de artículo máximo posible (como al incrementar 999 a 1000), esto devuelve ARTICLE_CODE_OUT_OF_RANGE como el error.

decrement
Devuelve el anterior "Business::ISBN" decrementando el código de artículo del ISBN especificado (objeto o escalar).

Devuelve undef, si el parámetro es inválido o es igual al ISBN mínimo posible para la editorial.

$isbn = Business::ISBN->new('1565922573');  # 1-56592-257-3
$prev_isbn = $isbn->decrement;              # 1-56592-256-5

Si el siguiente código de artículo excedería el código de artículo máximo posible (como al incrementar 000 a -1), esto devuelve ARTICLE_CODE_OUT_OF_RANGE como el error.

png_barcode
Devuelve los datos de la imagen en formato PNG para el código de barras del ISBN. Esto funciona con ISBN-10 e ISBN-13. Los ISBN-10 se convierten automáticamente a ISBN-13.

Esto requiere "GD::Barcode::EAN13".
