NOMBRE

Business::ISSN - Extensión de Perl para Números Estándar Internacionales de Publicaciones Seriadas

SINOPSIS

use Business::ISSN;
$issn_object = Business::ISSN->new('1456-5935');
$issn_object = Business::ISSN->new('14565935');
# imprimir el ISSN (con guión)
print $issn_object->as_string;
# verificar si el ISSN es válido
$issn_object->is_valid;
# arreglar el checksum del ISSN. TENGA CUIDADO: ¡el error podría no
# estar en el checksum!
$issn_object->fix_checksum;
# FUNCIONES EXPORTABLES
use Business::ISSN qw( is_valid_checksum );
# verificar el checksum
if( is_valid_checksum('01234567') ) { ... }

DESCRIPCIÓN

new($issn)
El constructor acepta un escalar que representa el ISSN.

La cadena que representa el ISSN puede contener caracteres distintos de [0-9xX], aunque estos se eliminarán en la representación interna. La cadena resultante debe parecerse a un ISSN: los primeros siete caracteres deben ser dígitos y el octavo carácter debe ser un dígito, 'x' o 'X'.

La cadena pasada como ISSN no necesita ser un ISSN válido, siempre que se parezca superficialmente a uno. Esto permite usar el método "fix_checksum".

Se debe verificar la validez del ISSN con is_valid() en lugar de depender del valor de retorno del constructor.

Si lo único que se desea es verificar la validez de un ISSN, se puede omitir la interfaz orientada a objetos y usar la función c<is_valid_checksum()>, que es exportable bajo demanda.

Si el constructor decide que no puede crear un objeto, devuelve undef. Puede hacerlo si la cadena pasada como ISSN no se puede manipular al formato interno.

$obj->checksum
Devuelve el checksum del ISSN.
$obj->as_string
Devuelve el ISSN como una cadena.

Una 'x' final se cambia a 'X'.

$obj->is_valid
Devuelve 1 si el checksum es válido.

Devuelve 0 si el ISSN no pasa la prueba del checksum. El constructor acepta ISSN inválidos para que puedan ser corregidos con "fix_checksum".

$obj->fix_checksum
Reemplaza el octavo carácter con el checksum que corresponde a los siete dígitos anteriores. Esto no garantiza que el ISSN corresponda al producto que uno cree que es, o que el ISSN corresponda a algún producto en absoluto. Solo produce una cadena que pasa la rutina de checksum. Si el ISSN pasado al constructor era inválido, el error podría haber estado en cualquiera de las otras nueve posiciones.

FUNCIONES EXPORTABLES

Algunas funciones se pueden usar sin la interfaz de objeto. Estas no utilizan tecnología de objetos de forma interna.
