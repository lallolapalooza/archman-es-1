NOMBRE

bup-save - crea un nuevo conjunto de copias de seguridad de bup

SINOPSIS

bup save [-r host:path] <-t|-c|-n name> [-#] [-f indexfile] [-v] [-q] [--smaller=maxsize] <rutas...>;

DESCRIPCIÓN

bup save guarda el contenido de los archivos o rutas proporcionados en un nuevo conjunto de copias de seguridad y, opcionalmente, le asigna un nombre a ese conjunto.

Tenga en cuenta que para referirse a su conjunto de copias de seguridad más adelante (es decir, para la restauración), debe especificar --name (el caso normal), o registrar el id de árbol o de confirmación (commit) impreso por --tree o --commit.

Antes de intentar guardar archivos usando bup save, debe primero actualizar el índice usando bup index. Las razones para separar los dos pasos se describen en la página man de bup-index(1).

Por defecto, se guardarán metadatos para cada ruta, y los metadatos de los directorios padre no indexados de las rutas indexadas se tomarán directamente del sistema de archivos. Sin embargo, si se especifica --strip, --strip-patho --graft , no se guardarán metadatos para el directorio raíz (/). Vea bup-restore(1) para más información sobre el manejo de metadatos.

OPCIONES

-r, --remote=host:path
guarda el conjunto de copias de seguridad en el servidor remoto dado. Si se omite path , se usa la ruta predeterminada en el servidor remoto (aún debe incluir el `:'). La conexión con el servidor remoto se realiza con SSH. Si desea especificar qué puerto, usuario o clave privada usar para la conexión SSH, le recomendamos que use el archivo ~/.ssh/config .
-t, --tree
después de crear el conjunto de copias de seguridad, imprime el id de árbol git de la copia de seguridad resultante.
-c, --commit
después de crear el conjunto de copias de seguridad, imprime el id de confirmación (commit) git de la copia de seguridad resultante.
-n, --name=name
después de crear el conjunto de copias de seguridad, crea una rama git llamada name para que la copia de seguridad pueda ser accedida usando ese nombre. Si name ya existe, la nueva copia de seguridad se considerará un descendiente de la antigua name. (Así, puede crear continuamente nuevos conjuntos de copias de seguridad con el mismo nombre, y más adelante ver el historial de ese conjunto de copias de seguridad para ver cómo han cambiado los archivos con el tiempo.)
-d, --date=date
especifica la fecha de la copia de seguridad, en segundos desde la época, en lugar de la hora actual.
-f, --indexfile=indexfile
usa un nombre de archivo de índice diferente en lugar de $BUP_DIR/bupindex.
-v, --verbose
aumenta el nivel de verbosidad (puede usarse más de una vez). Con un -v, imprime cada nombre de directorio a medida que se respalda. Con dos -v, también imprime cada nombre de archivo.
-q, --quiet
desactiva los mensajes de progreso.
--smaller=maxsize
no respalda archivos >= maxsize bytes. Puede usar esto para ejecutar copias de seguridad incrementales frecuentes de sus archivos pequeños, que generalmente se pueden respaldar rápidamente, y omitir los grandes (como imágenes de máquinas virtuales) que tardan más. Luego puede respaldar los archivos grandes con menos frecuencia. Use un sufijo como k, M o G para especificar múltiplos de 1024, 1024*1024, 1024*1024*1024 respectivamente.
--bwlimit=bytes/seg
no transmite más de bytes/seg bytes por segundo al servidor. Esto es bueno para que sus copias de seguridad no consuman todo el ancho de banda de su red. Use un sufijo como k, M o G para especificar múltiplos de 1024, 1024*1024, 1024*1024*1024 respectivamente.
--strip
elimina la ruta proporcionada de todos los archivos y directorios.

Un directorio /root/chroot/etc guardado con "bup save -n chroot --strip /root/chroot" se guardaría como /etc. Tenga en cuenta que actualmente, no se guardarán metadatos para el directorio raíz (/) cuando se especifica esta opción.

--strip-path=prefijo-de-ruta
elimina el prefijo de ruta proporcionado prefijo-de-ruta de todos los archivos y directorios.

Un directorio /root/chroot/webserver/etc guardado con "bup save -n webserver --strip-path=/root/chroot /root/chroot/webserver/etc" se guardaría como /webserver/etc. Tenga en cuenta que actualmente, no se guardarán metadatos para el directorio raíz (/) cuando se especifica esta opción.

--graft=ruta-antigua=ruta-nueva
un punto de injerto ruta-antigua=ruta-nueva (puede usarse más de una vez).

Un directorio /root/chroot/a/etc guardado con "bup save -n chroot --graft /root/chroot/a=/chroot/a" se guardaría como /chroot/a/etc. Tenga en cuenta que actualmente, no se guardarán metadatos para el directorio raíz (/) cuando se especifica esta opción.

-#, --compress=#
establece el nivel de compresión a # (un valor de 0-9, donde 9 es el más alto y 0 es sin compresión). El valor predeterminado es 1 (compresión rápida y ligera)

EJEMPLOS

$ bup index -ux /etc
Indexing: 1981, done.
$ bup save -r myserver: -n my-pc-backup --bwlimit=50k /etc
Reading index: 1981, done.
Saving: 100.00% (998/998k, 1981/1981 files), done.
$ ls /home/joe/chroot/httpd
bin var
$ bup index -ux /home/joe/chroot/httpd
Indexing: 1337, done.
$ bup save --strip -n joes-httpd-chroot /home/joe/chroot/httpd
Reading index: 1337, done.
Saving: 100.00% (998/998k, 1337/1337 files), done.
$ bup ls joes-httpd-chroot/latest/
bin/
var/
$ bup save --strip-path=/home/joe/chroot -n joes-chroot \
     /home/joe/chroot/httpd
Reading index: 1337, done.
Saving: 100.00% (998/998k, 1337/1337 files), done.
$ bup ls joes-chroot/latest/
httpd/
$ bup save --graft /home/joe/chroot/httpd=/http-chroot \
     -n joe
     /home/joe/chroot/httpd
Reading index: 1337, done.
Saving: 100.00% (998/998k, 1337/1337 files), done.
$ bup ls joe/latest/
http-chroot/
