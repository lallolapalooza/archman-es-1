NOMBRE

btrfs-property - obtener/establecer/listar propiedades para un objeto del sistema de archivos dado

SINOPSIS

btrfs property <subcomando> <argumentos>

DESCRIPCIÓN

btrfs property se utiliza para obtener/establecer/listar propiedades para un objeto del sistema de archivos dado. El objeto puede ser un inodo (archivo o directorio), un subvolumen o el sistema de archivos completo.

btrfs property proporciona un método unificado y fácil de usar para ajustar diferentes propiedades de btrfs en lugar de utilizar el método tradicional como chattr(1) https://man7.org/linux/man-pages/man1/chattr.1.html o lsattr(1) https://man7.org/linux/man-pages/man1/lsattr.1.html.

Tipos de objeto

Una propiedad puede aplicarse a varios tipos de objetos, por lo que en algunos casos es necesario especificarlo explícitamente, sin embargo, no es necesario en el caso más común de archivos y directorios.

Los subcomandos toman el parámetro -t, usa la primera letra como atajo (f/s/d/i) del tipo:

  • sistema de archivos
  • subvolumen
  • dispositivo
  • inodo (archivo o directorio)

Propiedades de inodo

compresión
algoritmo de compresión establecido para un inodo (no es posible establecer el nivel de compresión de esta manera), valores posibles:
  • lzo
  • zlib
  • zstd
  • no o none - deshabilitar compresión (equivalente a chattr +m)
  • "" (cadena vacía) - establecer el valor predeterminado

Nota:

Esto ha cambiado en la versión 5.18 de btrfs-progs y requiere el kernel 5.14 o más reciente para funcionar.

Propiedades de subvolumen

ro
bandera de solo lectura del subvolumen: verdadero o falso. Por favor, consulte también la sección BANDERA DE SUBVOLUMEN en btrfs-subvolume(8) <> para posibles implicaciones relacionadas con el envío incremental.

Propiedades del sistema de archivos

etiqueta
etiqueta del sistema de archivos. Para un sistema de archivos sin montar, proporcione una ruta a un dispositivo de bloque como objeto. Para un sistema de archivos montado, especifique un punto de montaje.

SUBCOMANDO

obtener [-t <tipo>] <objeto> [<nombre>]
Lee el valor de una propiedad nombre del objeto btrfs del tipo dado, un nombre vacío leerá todas ellas
listar [-t <tipo>] <objeto>
Lista las propiedades disponibles con sus descripciones para el objeto dado.
establecer [-f] [-t <tipo>] <objeto> <nombre> <valor>
Establece el valor de la propiedad nombre en un objeto btrfs dado.

Opciones

-f
Forzar el cambio. Cambiar algunas propiedades puede implicar comprobaciones de seguridad o cambios adicionales que dependen de la semántica de las propiedades.

EJEMPLOS

Establecer compresión en un archivo:

$ touch archivo1
$ btrfs prop get archivo1
[ salida vacía ]
$ btrfs prop set archivo1 compression zstd
$ btrfs prop get archivo1
compression=zstd

Hacer un subvolumen escribible de solo lectura:

$ btrfs subvol create subvol1
[ llenar subvol1 con datos ]
$ btrfs prop get subvol1
ro=false
$ btrfs prop set subvol1 ro true
ro=true

ESTADO DE SALIDA

btrfs property devuelve un estado de salida cero si tiene éxito. Se devuelve un valor distinto de cero en caso de error.

DISPONIBILIDAD

btrfs es parte de btrfs-progs. Consulte la documentación en https://btrfs.readthedocs.io.
