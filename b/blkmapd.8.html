NOMBRE

blkmapd - demonio de mapeo de bloques de pNFS

SINOPSIS

blkmapd [-h] [-d] [-f]

DESCRIPCIÓN

El demonio blkmapd realiza el descubrimiento y mapeo de dispositivos para el cliente de mapeo de bloques pNFS (NFS paralelo) [RFC5663].

El protocolo de mapeo de bloques pNFS construye una jerarquía de almacenamiento compleja a partir de un conjunto de volúmenes simples. Estos volúmenes simples se direccionan por contenido, utilizando una firma en el volumen para nombrar de forma única cada uno de ellos. El demonio localiza un volumen examinando cada dispositivo de bloque en el sistema en busca de la firma dada.

La topología típicamente consiste en una jerarquía de volúmenes construida mediante striping, slicing y concatenación de los volúmenes simples. El demonio blkmapd utiliza el controlador device-mapper para construir dispositivos lógicos que reflejan la topología del servidor, y pasa estos dispositivos al kernel para su uso por el cliente de mapeo de bloques pNFS.

OPCIONES

-h
Muestra el mensaje de uso.
-d
Realiza solo el descubrimiento de dispositivos y luego sale.
-f
Ejecuta blkmapd en primer plano y envía la salida a stderr (en lugar de syslogd)

ARCHIVO DE CONFIGURACIÓN

El demonio blkmapd reconoce el siguiente valor de la sección [general] del archivo de configuración /etc/nfs.conf:

pipefs-directory
Indica a blkmapd dónde buscar el sistema de archivos rpc_pipefs. El valor por defecto es /var/lib/nfs/rpc_pipefs.

VER TAMBIÉN

nfs(5), dmsetup(8), nfs.conf(5)

RFC 5661 para la especificación de NFS versión 4.1.
RFC 5663 para la especificación de mapeo de bloques pNFS.
