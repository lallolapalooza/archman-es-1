NOMBRE

brightnessctl - leer y controlar el brillo del dispositivo

SINOPSIS

brightnessctl [opciones] [operación] [valor...]

OPCIONES

-h, --help

Imprimir esta ayuda.

-l, --list

Listar dispositivos con controles de brillo disponibles.

-q, --quiet

Suprimir la salida.

-p, --pretend

No realizar operaciones de escritura.

-m, --machine-readable

Producir salida legible por máquina.

-n, --min-value=VALOR

Establecer el valor mínimo de brillo al usar valores delta, por defecto es 1.

-e, --exponent=K

Cambia la curva de escalado de porcentaje a exponencial (lineal por defecto). El exponente por defecto es 4.

Ecuación del porcentaje: % = [VALOR]^[K] * [MAX] * 100^-[K].

La curva exponencial puede hacer que los ajustes sean perceptualmente iguales.

-s, --save

Guardar el estado en un archivo temporal.

-r, --restore

Restaurar el estado previamente guardado.

-d, --device=DISPOSITIVO

Especificar el nombre del dispositivo (puede ser un comodín).

-c, --class=CLASE

Especificar la clase del dispositivo.

-v, --version

Imprimir la versión y salir.

OPERACIONES

i, info

Obtener información del dispositivo.

g, get

Obtener el brillo actual del dispositivo.

m, max

Obtener el brillo máximo del dispositivo.

s, set VALOR

Establecer el brillo del dispositivo.

VALORES

Puede especificar VALOR para el comando set en forma absoluta o relativa, y como un valor o un delta del valor actual. Por ejemplo:

brightnessctl set 500

Establece el brillo a 500.

brightnessctl set 50%

Establece el brillo al 50% del máximo.

brightnessctl set 50-

Resta 50 del brillo actual.

brightnessctl set +10

Suma 10 al brillo actual.

brightnessctl set 50%-

Resta el 50% del máximo del brillo actual.

brightnessctl set +10%

Suma el 10% del máximo al brillo actual.
