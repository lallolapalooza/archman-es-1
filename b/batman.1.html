BATMAN(1) Manual de comandos generales BATMAN(1)

NOMBRE

batman - Lee las páginas del manual del sistema (man) usando bat como formateador de páginas del manual.

DESCRIPCIÓN

Atrás quedaron los días de perder el hilo al leer páginas del manual monótonas. Con bat y batman, puedes leer man ifconfig con un hermoso color de 24 bits y resaltado de sintaxis.

Si tienes fzf instalado, ¡incluso puedes usar batman para buscar en las páginas del manual!

USO


batman [SECCIÓN] [ENTRADA]

Como reemplazo de Man

Con bash:

bash
eval "$(batman --export-env)"

Con fish:

fish
batman --export-env | source

ENTORNO

Variable Descripción
MANPAGER Cambia el paginador utilizado para batman. Esto se trata como BAT_PAGER, pero solo afecta a este comando.

PERSONALIZACIÓN

Cambiar el tema

Puedes cambiar el tema de resaltado de sintaxis para batman estableciendo la variable de entorno BAT_THEME antes de llamar a batman. La siguiente función de envoltura cambiará el tema a Solarized (dark) sin afectar ningún otro comando bat.

bash
batman() {
BAT_THEME="Solarized (dark)" batman "$@"
return $?
}

ADVERTENCIAS

Las banderas no se resaltan:

- Esto ocurre cuando cambias el tema de bat a través del archivo de configuración de bat o la variable de entorno BAT_THEME. No todos los temas proporcionan colores para las banderas, y es un problema conocido.
- Puedes anular el tema para batman envolviéndolo en una función que establezca BAT_THEME.
- Los siguientes temas admiten el resaltado de páginas del manual:
- Monokai Extended / Monokai Extended Light
- Solarized (dark) / Solarized (light)
