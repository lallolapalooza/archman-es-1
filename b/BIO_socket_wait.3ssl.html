BIO_socket_wait(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_SOCKET_WAIT(3ssl) OpenSSL BIO_SOCKET_WAIT(3ssl)

NOMBRE

BIO_socket_wait, BIO_wait, BIO_do_connect_retry - Funciones de utilidad para la conexión BIO

SINOPSIS

#include <openssl/bio.h>
#ifndef OPENSSL_NO_SOCK
int BIO_socket_wait(int fd, int for_read, time_t max_time);
#endif
int BIO_wait(BIO *bio, time_t max_time, unsigned int nap_milliseconds);
int BIO_do_connect_retry(BIO *bio, int timeout, int nap_milliseconds);

DESCRIPCIÓN

BIO_socket_wait() espera en el socket fd para leer si for_read no es 0, de lo contrario para escribir, hasta un máximo de max_time. Tiene éxito inmediatamente si max_time == 0 (lo que significa que no se proporcionó tiempo de espera).

BIO_wait() espera como máximo hasta max_time en el bio dado (típicamente basado en socket), para leer si se supone que bio debe leer, de lo contrario para escribir. Es utilizada por BIO_do_connect_retry() y puede usarse junto con BIO_read(3). Tiene éxito inmediatamente si max_time == 0 (lo que significa que no se proporcionó tiempo de espera). Si los sockets no están disponibles, admite sondeos al tener éxito después de dormir como máximo el nap_milliseconds dado para evitar un bucle de sondeo intensivo. A través de nap_milliseconds, el llamador determina la granularidad del sondeo.

BIO_do_connect_retry() se conecta a través del bio dado. Reintenta BIO_do_connect() tantas veces como sea necesario para alcanzar un resultado definitivo, es decir, la conexión tuvo éxito, se alcanzó el tiempo de espera o ocurrió un error. Para BIOs no bloqueantes y potencialmente incluso no-socket, sondea cada nap_milliseconds y duerme entre tanto usando BIO_wait(). Si nap_milliseconds es < 0, se usa un valor predeterminado de 100 ms. Si el parámetro timeout es > 0, esto indica el número máximo de segundos a esperar hasta que se establezca la conexión o ocurra un error definitivo. Un valor de 0 permite esperar indefinidamente (es decir, sin tiempo de espera), mientras que un valor < 0 significa que BIO_do_connect() se intenta solo una vez. La función puede invocar, directa o indirectamente, ERR_clear_error().

VALORES DE RETORNO

BIO_socket_wait(), BIO_wait() y BIO_do_connect_retry() devuelven -1 en caso de error, 0 en caso de tiempo de espera y 1 en caso de éxito.

VER TAMBIÉN

BIO_do_connect(3), BIO_read(3)

HISTORIA

BIO_socket_wait(), BIO_wait() y BIO_do_connect_retry() se agregaron en OpenSSL 3.0.
