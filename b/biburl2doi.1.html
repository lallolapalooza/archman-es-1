NOMBRE

biburl2doi.pl - convierte URL que apuntan a doi.org a DOIs

SINOPSIS

biburl2doi [-D] [-o salida] archivo_bib

OPCIONES

-D
No eliminar las URL convertidas a DOI
-o salida
Archivo de salida. Si no se usa esta opción, el nombre para el archivo de salida se forma añadiendo "_cleaned" al archivo de entrada.

DESCRIPCIÓN

El script reconoce campos URL del tipo "http://dx.doi.org" y sus variantes y los convierte a campos DOI.
