SINOPSIS

Copias de seguridad cifradas y deduplicadas de Bupstash.

Ejecute uno de los siguientes subcomandos de bupstash.

bupstash init ...
bupstash new-key ...
bupstash new-sub-key ...
bupstash put ...
bupstash list ...
bupstash list-contents ...
bupstash diff ...
bupstash get ...
bupstash restore ...
bupstash rm ...
bupstash recover-removed ...
bupstash gc ...
bupstash sync ...
bupstash exec-with-locks ...
bupstash serve ...
bupstash help ...
bupstash version ...

DESCRIPCIÓN

bupstash es una herramienta para almacenar (y recuperar) archivos y datos en un bupstash-repostory(7) cifrado.

Algunas características notables de bupstash incluyen:

○
Deduplicación automática de los datos almacenados.
○
Cifrado de datos del lado del cliente.
○
Cargas incrementales de archivos.
○
Un lenguaje de consulta basado en etiquetas.
○
Separación opcional de claves de cifrado y descifrado basada en roles.
○
Repositorios remotos a través de ssh ssh.
○
Opcional, por clave ssh, controles de repositorio de acceso.
○
Un enfoque de múltiples capas para la seguridad.

La herramienta bupstash en sí está dividida en subcomandos que cada uno tiene su propia documentación.

SUBCOMANDOS

bupstash-init(1)
Inicializa un repositorio de bupstash.
bupstash-new-key(1)
Crea una nueva clave principal para crear/leer elementos del repositorio.
bupstash-new-sub-key(1)
Deriva una subclave para un subconjunto de operaciones.
bupstash-put(1)
Añade datos a un repositorio de bupstash.
bupstash-get(1)
Recupera datos del repositorio de bupstash que coinciden con una consulta.
bupstash-restore(1)
Restaura una instantánea en un directorio local.
bupstash-list(1)
Lista los elementos del repositorio que coinciden con una consulta dada.
bupstash-list-contents(1)
Lista el contenido de las instantáneas de directorios.
bupstash-diff(1)
Compara el contenido de las instantáneas.
bupstash-rm(1)
Elimina los elementos del repositorio que coinciden con una consulta dada.
bupstash-recover-removed(1)
Recupera elementos eliminados que están pendientes de recolección de basura.
bupstash-gc(1)
Recupera espacio en disco en un repositorio.
bupstash-sync(1)
Sincroniza elementos entre repositorios.
bupstash-exec-with-locks(1)
Ejecuta un comando con bloqueos exclusivos sobre el repositorio.
bupstash-serve(1)
Sirve un repositorio a través de stdin/stdout utilizando el protocolo bupstash-protocol(7).

EJEMPLOS

Inicializar un repositorio y crear claves

$ bupstash init -r ssh://$SERVIDOR/home/yo/backups $ bupstash new-key -o backups.key

Indicar a bupstash que use nuestro repositorio y clave por defecto

$ export BUPSTASH_REPOSITORY=ssh://$SERVIDOR/home/yo/backups $ export BUPSTASH_KEY=backups.key

Instantáneas de directorios

``` $ bupstash put ./some-data ebb66f3baa5d432e9f9a28934888a23d

$ bupstash list-contents id=ebb66f3baa5d432e9f9a28934888a23d drwxr-xr-x 0 2020/11/05 10:42:48 . -rw-r--r-- 177B 2020/07/12 17:13:42 data.txt ```

Listar elementos que coinciden con una consulta

$ bupstash list hostname=$(hostname) id="bcb8684e6bf5cb453e77486decf61685" name="some-file.txt" hostname="my-server" timestamp="2020-07-27 11:26:16" ...

Cargas incrementales

``` $ bupstash put --send-log /var/backup.sendlog ./some-data ebb66f3baa5d432e9f9a28934888a23d$ bupstash put --send-log /var/backup.sendlog ./some-data ebb66f3baa5d432e9f9a28934888a23d ```

Capturar y guardar la salida de un comando

# Comprueba si hay errores antes de guardar un nuevo elemento. $ bupstash put --exec name=database.sql pgdump mydatabase 14ebd2073b258b1f55c5bbc889c49db4

Obtener un elemento que coincida con una consulta

$ bupstash get id=bcb8684e6bf5cb453e77486decf61685 some data.

Restaurar un directorio a una instantánea anterior

$ bupstash restore --to ./dir name=dir.tar

Eliminar elementos que coincidan con una consulta.

$ bupstash rm name=some-data.txt

Limpiar un repositorio

$ bupstash rm --allow-many id=*

Recuperar espacio en disco

$ bupstash gc

Claves de descifrado fuera de línea

``` # Crea una clave, una clave solo de escritura y una clave de metadatos (solo listar/eliminar). $ bupstash new-key -o backups.key $ bupstash new-sub-key --put -k backups.key -o backups-put.key $ bupstash new-sub-key --list -k backups.key -o backups-metadata.key

... Copia backups.key a almacenamiento seguro fuera de línea ...$ shred backups.key

$ bupstash put -k backups-put.key ./data 14ebd2073b258b1f55c5bbc889c49db4

... Cuando necesites listar o eliminar copias de seguridad, puedes usar la clave de metadatos ...

$ bupstash list -k backups-metadata.key ... $ bupstash rm -k backups-metadata.key

... Después de la emergencia, obtén la clave de descifrado del almacenamiento fuera de línea ...$ bupstash get -k backups.key id=14ebd2073b258b1f55c5bbc889c49db4 | tar -C ./restore -xf - ```
