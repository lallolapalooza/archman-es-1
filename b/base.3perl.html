base(3perl) Guía de referencia para programadores de Perl base(3perl)

NOMBRE

base - Establece una relación ISA con clases base en tiempo de compilación

SINOPSIS

package Baz;
use base qw(Foo Bar);

DESCRIPCIÓN

A menos que estés utilizando el pragma "fields", considera este módulo desaconsejado en favor del más ligero "parent".

Permite cargar uno o varios módulos, a la vez que se configura la herencia de esos módulos. Tiene un efecto similar a

package Baz;
BEGIN {
    require Foo;
    require Bar;
    push @ISA, qw(Foo Bar);
}

Cuando "base" intenta "require" un módulo, no fallará si no puede encontrar el archivo del módulo, pero sí fallará ante cualquier otro error. Después de todo esto, si tu clase base estuviera vacía, sin contener ningún símbolo, "base" fallará. Esto es útil para heredar de clases en el mismo archivo que tú, pero donde el nombre del archivo no coincide con el nombre del módulo base, como se muestra aquí:

# en Bar.pm
package Foo;
sub exclaim { "¡Puedo tener algo así?!" }
package Bar;
use base "Foo";

No existe Foo.pm, pero como "Foo" define un símbolo (la subrutina "exclaim"), "base" no fallará cuando el "require" no pueda cargar Foo.pm.

"base" también inicializará los campos si una de las clases base los tiene. La herencia múltiple de campos NO se soporta; si dos o más clases base tienen campos heredables, el pragma 'base' fallará. Ver fields para una descripción de esta característica.

El método "import" de la clase base **no** se llama.

DIAGNÓSTICOS

La clase base "%s" está vacía.
base.pm no pudo requerir el paquete base, porque no se encontró en tu ruta.
La clase 'Foo' intentó heredar de sí misma
Intentar heredar de ti mismo genera una advertencia. 
package Foo;
use base 'Foo';

HISTORIA

Este módulo se introdujo con Perl 5.004_04.

ADVERTENCIAS

Debido a las limitaciones de la implementación, debes usar base antes de declarar tus propios campos.
