BUDGIE-DAEMON(1) Comandos de usuario BUDGIE-DAEMON(1)

NOMBRE

budgie-daemon - proceso de budgie para interactuar con varias interfaces dbus de budgie y GNOME

DESCRIPCIÓN

Uso:

budgie-daemon [OPCIÓN?] - Daemon de Budgie

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-gtk
Mostrar opciones de GTK+

Opciones de aplicación:

--replace
Reemplazar el daemon en ejecución actualmente
--display=DISPLAY
Pantalla X a utilizar
