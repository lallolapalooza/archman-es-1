bswap(3) Manual de funciones de la biblioteca bswap(3)

NOMBRE

bswap_16, bswap_32, bswap_64 - invertir el orden de los bytes

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <byteswap.h>
uint16_t bswap_16(uint16_t x);
uint32_t bswap_32(uint32_t x);
uint64_t bswap_64(uint64_t x);

DESCRIPCIÓN

Estas funciones devuelven un valor en el que se invierte el orden de los bytes de sus argumentos de 2, 4 u 8 bytes.

VALOR DE RETORNO

Estas funciones devuelven el valor de su argumento con los bytes invertidos.

ERRORES

Estas funciones siempre tienen éxito.

ESTÁNDARES

GNU.

EJEMPLOS

El programa a continuación invierte los bytes del entero de 8 bytes suministrado como argumento de línea de comandos. La siguiente sesión de shell demuestra el uso del programa:


$ ./a.out 0x0123456789abcdef;
0x123456789abcdef ==> 0xefcdab8967452301

Código fuente del programa

#include <byteswap.h>
#include <inttypes.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    uint64_t x;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s <num>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    x = strtoull(argv[1], NULL, 0);
    printf("%#" PRIx64 " ==> %#" PRIx64 "\n", x, bswap_64(x));
    exit(EXIT_SUCCESS);
}
