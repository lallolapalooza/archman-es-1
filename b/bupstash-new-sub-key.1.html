bupstash-new-sub-key(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Genera una clave secundaria de bupstash con capacidades de cifrado y descifrado menores.

bupstash new-sub-key -k CLAVE -o SUB_CLAVE

DESCRIPCIÓN

bupstash new-sub-key crea una nueva clave de bupstash capaz de un subconjunto de las operaciones de cifrado y descifrado de la clave principal.

Las capacidades son cualquiera de las opciones 'put', 'list' y 'list-contents'. Las claves 'put' pueden crear nuevas copias de seguridad pero no descifrar datos, las claves 'list' pueden descifrar etiquetas y otros metadatos, mientras que las claves 'list-contents' pueden descifrar el contenido de los elementos creados por 'bupstash put'.

Un uso típico de una clave solo de listado sería permitir que un trabajo cron rote copias de seguridad antiguas por sus etiquetas de búsqueda, sin exponer la clave de descifrado de datos.

La clave generada se marcará como legible solo para el usuario que la crea.

Si se pierde una subclave, la clave original aún podrá descifrar cualquier dato en el repositorio cifrado por esa subclave.

NOTA: el descifrado es diferente del acceso: un atacante todavía puede eliminar datos simplemente eliminando los elementos o archivos a los que tiene acceso. Utilice los controles de acceso de bupstash-serve(1) para restringir qué operaciones puede realizar un usuario y evitar la eliminación no autorizada de datos. Esto se puede hacer a través de un archivo authorized_keys de ssh, o a través de mecanismos como la configuración de sudo o doas.

OPCIONES

-k, --key RUTA
Clave de la cual derivar la nueva subclave.
-o, --output RUTA
Ruta donde se escribirá la subclave.
--put
La clave es capaz de cifrar datos para operaciones 'put'.
--list
La clave podrá descifrar metadatos y realizar consultas.
--list-contents
La clave podrá listar el contenido de los elementos con 'list-contents' (implica --list).

EJEMPLOS

Crear una nueva clave solo de escritura

$ bupstash new-sub-key --put -k backups.key -o ./put.key $ bupstash put -k ./backups-put.key ./data

Crear una nueva clave de listado

$ bupstash new-sub-key -k ./backups.key -o ./list.key --list $ bupstash list -k ./list.key

Crear una nueva clave de listado de contenido

$ bupstash new-sub-key -k ./backups.key -o ./list-contents.key --list-contents $ bupstash list-contents -k ./list-contents.key name=some-backup.tar
