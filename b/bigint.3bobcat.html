DESCRIPCIÓ

N

Esta clase está definida como una clase envolvente alrededor de la openSSL serie de funciones BN, ofreciendo miembros para realizar operaciones aritméticas en valores enteros de tamaños ilimitados. Se ofrecen miembros para generar números primos y para realizar todo tipo de operaciones aritméticas comunes sobre objetos BigInt . También se ofrecen conversiones a caracteres y tipos de valor numérico

estándar.

A continuación, la frase el objeto también puede referirse al valor del objeto. El contexto en el que esto ocurre dejará claro que se refiere al valor del objeto en lugar del objeto en

sí.

Varios constructores aceptan argumentos BIGNUM. El tipo BIGNUM es el tipo que contiene un entero de precisión ilimitada tal como está definido por OpenSSL. La definición de BIGNUM

es 
    typedef struct bignum_st BIGNUM;
    struct bignum_st
    {
        BN_ULONG *d;    // Puntero a un array de fragmentos de 'BN_BITS2' bits.
        int top;        // Índice del último d usado +1.
        // Lo siguiente es contabilidad interna para bn_expand.
        int dmax;       // Tamaño del array d.
        int neg;        // uno si el número es negativo
        int flags;
    }
;

Los signos de BigInt se manejan de una manera especial. Si un BigInt es negativo o positivo está determinado por su bandera de signo, y no por un bit de signo como es el caso con valores de tipo int. Dado que los valores BigInt tienen precisión ilimitada, desplazar valores a la izquierda no cambiará sus

signos.

Los operadores devuelven o bien una referencia al objeto actual (modificado) o devuelven un objeto BigInt que contiene el valor calculado. La regla seguida aquí fue implementar los operadores de manera análoga a la forma en que los operadores funcionan con valores y variables de tipo int. Por ejemplo, operator+() devuelve un valor BigInt mientras que operator+=() devuelve una referencia BigInt

&.

Todos los miembros que modifican sus objetos devuelven una referencia al objeto actual (modificado). Todos los miembros que no modifican el objeto actual devuelven un objeto BigInt. Si existen ambos miembros realizando la misma funcionalidad, el nombre del miembro que devuelve un objeto BigInt termina en una c (const) (por ejemplo, addMod y addMod

c).

Casi todos los operadores, miembros y constructores (excepto el constructor por defecto) lanzan excepciones Exceptio

n en caso
de fallo.

Este operador no está implementado ya que no puede ser implementado de modo que coincida con las acciones de este operador cuando se aplica a valores de tipo
int;
Cuando se usa en valores int este operador invierte todos los bits del int. Por ejemplo, ~5 representa -6, y ~-6 de nuevo es igual a cinco. El -6 es el resultado del bit de signo de los valores int. La implementación obvia de BigInt::operator~() es invertir todos los bits del valor e invertir su bit de signo. Para 5 esto resultaría en -250: 5, siendo 101 (binario), cabe en un byte, así que ~5 se convierte en 11111010 (binario), que es 250. Su signo debe invertirse también, así que se convierte en -250. Esto difiere claramente del valor representado por la constante int ~5: al construir BigInt(~5), se obtiene el valor
-6.
Es posible cambiar la implementación. Por ejemplo, después de 
        Bigint b(5);
        b =
~b; ~b podría ser implementado para que resulte en el valor -6. Pero esto también conduce a resultados inesperados. Mientras que 5 & ~5 == 0, esto ya no sería cierto para los objetos BigInt: Asumiendo que b contiene 5 entonces b & ~b se expandiría a (binario) 101 & (negativo)110 que es igual a (binario)
100;

MIEMBROS ESTÁTICOS

Todos los miembros que devuelven un BigInt calculado a partir de un conjunto de argumentos y que no requieren un objeto BigInt existente se definen como miembros estáticos. El primer miembro diophantus, que devuelve un valor long long, también es un miembro estático.

o
long long diophantus(long long *factor1, long long *factor2, long long value1, long long value2):
Se calcula la solución integral de factor1 * value1 + factor2 * value2 = gcd. La función devuelve el máximo común divisor (gcd) de value1 y value2, y devuelve sus factores de multiplicación en *factor1 y *factor2, respectivamente. La solución no es única: se obtiene otra solución sumando k * value2 a factor1 y restando k * value1 de factor2. Para valores que excedan std::numeric_limits<long, long>::max() se puede usar el siguiente miembro;
o
BigInt diophantus(BigInt *factor1, BigInt *factor2, BigInt const &value1, BigInt const &value2):
Se calcula la solución integral de factor1 * value1 + factor2 * value2 = gcd. La función devuelve el máximo común divisor (gcd) de value1 y value2, y devuelve sus factores de multiplicación en *factor1 y *factor2, respectivamente. La solución no es única: se obtiene otra solución sumando k * value2 a factor1 y restando k * value1 de factor2;
o
BigInt fromText(std::string text, int mode = 0):
Este miembro convierte una representación textual de un número a un valor BigInt. La conversión continúa hasta el final de text o hasta que se encuentra un carácter fuera del rango esperado;
El rango esperado puede preestablecerse especificando mode como ios::dec, ios::oct, o ios::hex o (por defecto) el rango esperado se determina por fromText inspeccionando los caracteres en text.
Por defecto, si text contiene caracteres hexadecimales, entonces fromText asume que el número está representado como un valor hexadecimal (por ejemplo, "abc" se convierte al valor (decimal) 2748); si text comienza con 0 y solo contiene caracteres en el rango de 0 hasta 7 (inclusive), entonces fromText asume que el número está representado como un valor octal (por ejemplo, "01234" se convierte al valor (decimal) 668). De lo contrario, se asume un valor decimal.
Si el texto no representa un valor numérico válido (del modo de extracción dado) entonces se lanza una excepción FBB::Exception (fromText: text does not represent a BigInt value);
o
BigInt rand(size_t size, Msb msb = MSB_IS_ONE, Lsb lsb = ODD):
Este miembro devuelve un número pseudoaleatorio criptográficamente seguro de size bits. El bit (o bits) más significativo(s) puede(n) ser controlado(s) por msb (por defecto MSB_IS_ONE), el bit menos significativo puede ser controlado por lsb (por defecto ODD). Antes de llamar a este miembro en la práctica, el generador de números aleatorios debe haber sido inicializado.
De la página man de RAND_add(3ssl):
OpenSSL se asegura de que el estado del PRNG sea único para cada hilo. En sistemas que proporcionan /dev/urandom, el dispositivo de aleatoriedad se utiliza para inicializar el PRNG de forma transparente. Sin embargo, en todos los demás sistemas, la aplicación es responsable de inicializar el PRNG llamando a RAND_add(3ssl), RAND_egd(3ssl), RAND_load_file(3ssl), o RAND_seed(3ssl);
o
BigInt randRange(BigInt const &max):
Este miembro devuelve un número pseudoaleatorio criptográficamente seguro en el rango 0 <= número < max. Antes de llamar a este miembro en la práctica, el generador de números aleatorios debe haber sido inicializado (ver también rand, descrito anteriormente);
o
BigInt setBigEndian(std::string const &bytes):
Los bytes.length() bytes de bytes se utilizan para calcular un objeto BigInt que es devuelto por esta función. Los caracteres en bytes se interpretan como una serie de bytes en orden big-endian. Ver también la función miembro bigEndian() anterior. El BigInt devuelto tiene un valor positivo;
o
BigInt prime(size_t nBits, BigInt const *mod = 0, BigInt const &rem = 0, PrimeType primeType = ANY):
Este miembro devuelve un número primo de nBits bits. Si tanto mod como rem no son cero, la condición prime % mod == rem. (Por ejemplo, use prime % mod == 1 para que se ajuste a un generador dado). El parámetro primeType puede ser ANY, (prime - 1) / 2 puede ser o no primo. Si es SAFE entonces (prime - 1) / 2 será un primo (llamado seguro);
o
BigInt pseudoRand(size_t size, Msb msb = MSB_IS_ONE, Lsb lsb = ODD):
Este miembro simplemente llama a BigInt::rand;
o
BigInt pseudoRandRange(BigInt const &max):
Este miembro simplemente llama a BigInt::randRange.
