NOMBRE

bpkg-pkg-update - actualizar paquete

SINOPSIS

bpkg pkg-update|update [opciones] [vars] pkg...
bpkg pkg-update|update [opciones] [vars] --all|-a
bpkg pkg-update|update [opciones] [vars] (--all-pattern <patrón>)...

DESCRIPCIÓN

El comando pkg-update actualiza los paquetes especificados (la primera forma), todos los paquetes retenidos (la segunda forma, véase bpkg-pkg-status(1)), o todos los paquetes retenidos que coincidan con cualquiera de los patrones comodín especificados (la tercera forma). Además, las dependencias inmediatas o totales de estos paquetes también pueden actualizarse especificando las opciones --immediate|-i o --recursive|-r respectivamente. En el fondo, este comando no hace mucho más que ejecutar b update (o una de sus variantes update-for-*; véase --for|-f). En la primera forma, los paquetes especificados deben haber sido configurados previamente con bpkg-pkg-build(1) o bpkg-pkg-configure(1). Se pueden pasar al sistema de compilación variables adicionales de la línea de comandos (

vars, normalmenteconfig.* ). Dichas variables se aplican a todos los paquetes especificados, pero también pueden especificarse para que se apliquen solo a paquetes concretos usando el mecanismo de agrupación de argumentos (véasebpkg-argument-grouping(1) para más detalles). OPCIONES DE PKG-UPDATE

OPCIONES DE PKG-UPDATE

--all|-a
Actualizar todos los paquetes retenidos.
--all-pattern patrón
Actualizar los paquetes retenidos que coincidan con el patrón comodín especificado. Repita esta opción para que coincidan varios patrones. Tenga en cuenta que puede necesitar entrecomillar el patrón para evitar que su shell lo expanda.
--immediate|-i
Actualizar también las dependencias inmediatas.
--recursive|-r
Actualizar también todas las dependencias, recursivamente.
--for|-f operación
En lugar de la operación de compilación update por defecto, realizar la variante update-for-operación donde operación es normalmente install o test.
--directory|-d dir
Asumir que la configuración está en dir en lugar de en el directorio de trabajo actual.

-v
Imprimir los comandos subyacentes esenciales que se están ejecutando.
-V
Imprimir todos los comandos subyacentes que se están ejecutando.
--quiet|-q
Ejecutar en silencio, imprimiendo solo mensajes de error.
--verbose nivel
Establecer el nivel de verbosidad del diagnóstico a nivel entre 0 y 6.
--stdout-format formato
Formato de representación a usar para imprimir en stdout.
--jobs|-j num
Número de trabajos a realizar en paralelo.
--no-result
No imprimir mensajes informativos sobre el resultado de realizar un comando o alguna de sus partes.
--structured-result fmt

--progress
Mostrar indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.

Suprimir los indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--diag-color
Usar color en los diagnósticos.
--no-diag-color
No usar color en los diagnósticos.
--build ruta
El programa de compilación a usar para construir paquetes.
--build-option opt
Opción adicional a pasar al programa de compilación.
--fetch ruta
El programa de descarga a usar para obtener recursos.
--fetch-option opt
Opción adicional a pasar al programa de descarga.
--fetch-timeout seg
El tiempo de espera del programa de descarga y de programas similares (por ejemplo, git).
--pkg-proxy url
Servidor proxy HTTP a usar al obtener manifiestos y archivos de paquetes de repositorios pkg remotos.
--git ruta
El programa git a usar para obtener repositorios git.
--git-option opt
Opción común adicional a pasar al programa git.
--sha256 ruta
El programa sha256 a usar para calcular sumas SHA256.
--sha256-option opt
Opción adicional a pasar al programa sha256.
--tar ruta

--openssl ruta

--openssl-option opt
Opción adicional a pasar al programa openssl.
--auth tipo

Confiar en el certificado del repositorio con una huella digital SHA256 huella_digital.
--trust-yes

--trust-no

OPCIONES POR DEFECTO ARCHIVOS

Ver bpkg-default-options-files(1) para una descripción general de los archivos de opciones por defecto. Para el pkg-update comando, el directorio de inicio de búsqueda es el directorio de configuración. Se buscan los siguientes archivos de opciones en cada directorio y, si se encuentran, se cargan en el orden listado:

bpkg.options
bpkg-pkg-update.options

Las siguientes pkg-update opciones del comando no pueden especificarse en los archivos de opciones por defecto:

--directory|-d
