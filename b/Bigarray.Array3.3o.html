Arreglos tridimensionales. La estructura Array3 proporciona operaciones similares a las de Bigarray.Genarray , pero especializadas para el caso de arreglos tridimensionales

.

type (!'a, !'b, !'c)

t

El tipo de Bigarrays tridimensionales cuyos elementos tienen tipo OCaml 'a , tipo de representación 'b , y diseño de memoria 'c . val create

('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> int -> ('a, 'b, 'c) t Array3.create kind layout dim1 dim2 dim3 devuelve un nuevo Bigarray de tres dimensiones, cuyo tamaño

es

dim1 en la primera dimensión, dim2 en la segunda dimensión, y dim3 en la tercera. kind y layout determinan el tipo de elementos del arreglo y el diseño del arreglo como se describe para Bigarray.Genarray.create . val ini

('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> int -> (int -> int -> int -> 'a) -> ('a, 'b, 'c) t Array3.init kind layout dim1 dim2 dim3 f devuelve un nuevo

Bigarray

Las dimensiones se invierten, de modo que get v [| a; b; c |] en diseño C se convierte en get v [| c+1; b+1; a+1 |] en diseño Fortran. Desde 4.
