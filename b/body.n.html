body(n)

Paquete: tcl

Licencias: TCL

body(n) [incr Tcl] body(n)

NOMBRE

itcl::body - cambia el cuerpo de un método/proc de clase

SINOPSIS

itcl::body nombreClase::función argumentos cuerpo

DESCRIPCIÓN

El comando body se utiliza fuera de una definición de clase de [incr Tcl] para definir o redefinir el cuerpo de un método o proc de clase. Esta facilidad permite que una definición de clase tenga partes de "interfaz" y "implementación" separadas. La parte de "interfaz" es un comando class con declaraciones para métodos, procs, variables de instancia y variables comunes. La parte de "implementación" es una serie de comandos body y configbody. Si la parte de "implementación" se mantiene en un archivo separado, se puede cargar una y otra vez a medida que se corrigen los errores, para soportar el desarrollo interactivo. Al usar el modo "tcl" en el editor emacs, las partes de "interfaz" y "implementación" se pueden mantener en el mismo archivo; a medida que se corrigen los errores, los cuerpos individuales se pueden resaltar y enviar a la aplicación de prueba.

El nombre "nombreClase::función" identifica el método/proc que se está cambiando.

Si se especificó una lista de argumentos cuando se definió la función en la definición de la clase, la lista de argumentos para el comando body debe coincidir en significado. Los nombres de las variables pueden cambiar, pero las listas de argumentos deben tener los mismos argumentos requeridos y los mismos valores predeterminados para los argumentos opcionales. El argumento especial args actúa como un comodín cuando se incluye en la lista de argumentos en la definición de la clase; coincidirá con cero o más argumentos de cualquier tipo cuando el cuerpo se redefina.

Si la cadena cuerpo comienza con "@", se trata como el nombre simbólico de un procedimiento C. La lista de argumentos tiene poca importancia para el procedimiento C, excepto para documentar el uso esperado. (No se garantiza que el procedimiento C use los argumentos de esta manera). Si cuerpo no comienza con "@", se trata como un script de comandos Tcl. Cuando se invoca la función, los argumentos de la línea de comandos se comparan con la lista de argumentos y se crean variables locales para representar cada argumento. Este es el comportamiento habitual para un proc estilo Tcl.

Los nombres simbólicos para procedimientos C se establecen registrando procedimientos a través de Itcl_RegisterC(). Esto generalmente se hace en el procedimiento Tcl_AppInit(), que se llama automáticamente cuando se inicia el intérprete. En el siguiente ejemplo, el procedimiento My_FooCmd() se registra con el nombre simbólico "foo". Este procedimiento se puede referenciar en el comando body como "@foo".

int
Tcl_AppInit(interp)
    Tcl_Interp *interp;     /* Intérprete para la aplicación. */
{
    if (Itcl_Init(interp) == TCL_ERROR) {
        return TCL_ERROR;
    }
    if (Itcl_RegisterC(interp, "foo", My_FooCmd) != TCL_OK) {
        return TCL_ERROR;
    }
}

EJEMPLO

En el siguiente ejemplo, se define una clase "File" para representar archivos abiertos. Los cuerpos de los métodos se incluyen debajo de la definición de la clase a través del comando body. Tenga en cuenta que los cuerpos del constructor/destructor deben incluirse en la definición de la clase, pero también se pueden redefinir a través del comando body.

itcl::class File {
    private variable fid ""
    constructor {name access} {
        set fid [open $name $access]
    }
    destructor {
        close $fid
    }
    method get {}
    method put {line}
    method eof {}
}
itcl::body File::get {} {
    return [gets $fid]
}
itcl::body File::put {line} {
    puts $fid $line
}
itcl::body File::eof {} {
    return [::eof $fid]
}
#
# Vea la clase File en acción:
#
File x /etc/passwd "r"
while {![x eof]} {
    puts "=> [x get]"
}
itcl::delete object x
