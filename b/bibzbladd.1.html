bibzbladd(1) BIBLIOTECA DE REFERENCIAS CRUZADAS DE LATEX bibzbladd(1)

NOMBRE

bibzbladd.pl - añadir números Zbl a artículos en un archivo bib dado

SINOPSIS

bibzbladd [-d] [-f] [-e] [-o salida] archivo_bib

OPCIONES

-d
Modo de depuración
-e
Si es 1 (por defecto), añadir un zblnumber vacío si no se puede encontrar un Zbl. Esto evita búsquedas repetidas para las mismas entradas si añades nuevas entradas al archivo. Llamar a "-e 0" suprime este comportamiento.
-f
Forzar la búsqueda de números Zbl incluso si la entrada ya tiene uno.
-o salida
Archivo de salida. Si no se usa esta opción, el nombre para el archivo de salida se forma añadiendo "_zbl" al archivo de entrada.

DESCRIPCIÓN

El script lee un archivo BibTeX. Comprueba si las entradas tienen Zbl. Si no es así, intenta encontrar los números en sitios de Internet. El resultado es un archivo BibTeX con campos "zblnumber=..." añadidos.

El nombre del archivo de salida se establece mediante la opción -o o se deriva añadiendo el sufijo "_zbl" al archivo de salida.

Consulta el script "bibdoiadd" para más detalles sobre el procesamiento.
