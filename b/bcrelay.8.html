BCRELAY(8) PÁGINA DEL MANUAL DE BCRELAY BCRELAY(8)

NOMBRE

bcrelay - un demonio de retransmisión de difusión

SINOPSIS

bcrelay [OPCIÓN]...

DESCRIPCIÓN

bcrelay simplemente actúa como un repetidor de difusión. Cuando bcrelay recibe paquetes de la interfaz entrante, los retransmitirá a la interfaz saliente.

OPCIONES

-d,--daemon
Ejecuta bcrelay como un demonio.
-p,--pidfile archivo-pid
especifica una ubicación alternativa para almacenar el archivo PID (por defecto /var/run/bcrelay.pid).
-h,--help
Muestra el mensaje de ayuda.
-i,--incoming interfaz-entrada
Define desde qué interfaz se leerán las difusiones.
-s,--outgoing interfaz-salida
Define a qué interfaz se retransmitirán las difusiones.
-n,--nolog
Desactiva cualquier registro y rastreo en /var/log/messages, excepto los mensajes de error fatales.
-s,--ipsec argumento
Define un túnel ipsec al que retransmitir. Dado que los túneles ipsec terminan en la misma interfaz, necesitamos definir la dirección de difusión del otro extremo del túnel. Esto se hace como ipsec0:x.x.x.255.
-v,--version
Muestra la versión de bcrelay.
Los mensajes de registro y la información de depuración van a syslog como demonio.
Las interfaces se pueden especificar como expresiones regulares, por ejemplo, ppp[0-9]+.
