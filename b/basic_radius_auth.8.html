NOMBRE

basic_radius_auth - Ayudante de autenticación RADIUS de Squid

SINOPSIS

basic_radius_auth -f archivo_config
basic_radius_auth -h " nombre_servidor " [-p puerto ] [-i identificador ] -w secreto [-t tiempo_espera ]

DESCRIPCIÓN

basic_radius_auth permite a Squid conectarse a un servidor RADIUS para validar el nombre de usuario y la contraseña de la autenticación HTTP Básica.

OPCIONES

-f archivo_config
Especifica la ruta a un archivo de configuración. Consulte la sección CONFIGURACIÓN para obtener detalles sobre el contenido del archivo.
-h servidor
Método alternativo para especificar el servidor al que conectarse
-p puerto
Especifica otro puerto del servidor donde el servidor RADIUS escucha las solicitudes si es diferente del puerto RADIUS predeterminado. Normalmente no se especifica.
-i identificador
Identificador único que identifica este proxy Squid al servidor RADIUS. Si no se especifica, se utiliza la dirección IP para identificar el proxy.
-w secreto
Método alternativo para especificar el secreto compartido. El uso de la opción -f con un archivo de configuración es generalmente más seguro y recomendado.
-t tiempo_espera
Tiempo de espera de la solicitud RADIUS. El valor predeterminado es 10 segundos.

CONFIGURACIÓN

La configuración especifica cómo el ayudante se conecta a RADIUS. El archivo contiene una lista de directivas (una por línea). Las líneas que comienzan con un # se ignoran.

servidor servidor_radius
especifica el nombre o la dirección del servidor RADIUS al que conectarse.
secreto cadena_secreto_alguna
especifica el secreto compartido de RADIUS.
identificador nombre_servidor
especifica qué nombre debe usar el proxy para identificarse ante el servidor RADIUS. Esta directiva es opcional.
puerto numero_puerto
Especifica el número de puerto o el nombre del servicio al que debe conectarse el ayudante.
tiempo_espera segundos
Especifica el tiempo de espera de la solicitud RADIUS.
