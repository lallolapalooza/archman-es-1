NOMBRE

borg-info - Muestra detalles del archivo como el espacio en disco utilizado

SINOPSIS

borg [opciones comunes] info [opciones] [REPOSITORIO_O_ARCHIVO]

DESCRIPCIÓN

Este comando muestra información detallada sobre el archivo o repositorio especificado.

Tenga en cuenta que los tamaños deduplicados de los archivos individuales no suman el tamaño deduplicado del repositorio ("todos los archivos"), ya que los dos significan cosas diferentes:

Este archivo / tamaño deduplicado = cantidad de datos almacenados SÓLO para este archivo = fragmentos únicos de este archivo. Todos los archivos / tamaño deduplicado = cantidad de datos almacenados en el repositorio = todos los fragmentos del repositorio.

Los archivos de Borg solo pueden contener una cantidad limitada de metadatos de archivos. El tamaño de un archivo en relación con este límite depende de varios factores, principalmente el número de archivos, la longitud de las rutas y otros metadatos almacenados para los archivos. Esto se muestra como utilización del tamaño máximo de archivo admitido.

OPCIONES

Ver borg-common(1) para las opciones comunes de los comandos Borg.

argumentos

REPOSITORIO_O_ARCHIVO
repositorio o archivo sobre el que mostrar información

opciones

--json
formatear la salida como JSON

Filtros de archivo

-P PREFIJO, --prefix PREFIJO
considerar solo los nombres de archivo que comiencen con este prefijo. (obsoleto)
-a GLOB, --glob-archives GLOB
considerar solo los nombres de archivo que coincidan con el glob. Se aplican las reglas de sh (sin usar realmente el prefijo sh:), consulte "borg help patterns".
--sort-by CLAVES
Lista separada por comas de claves de ordenación; las claves válidas son: timestamp, archive, name, id; el valor predeterminado es: timestamp
--first N
considerar los primeros N archivos después de aplicar otros filtros
--last N
considerar los últimos N archivos después de aplicar otros filtros
