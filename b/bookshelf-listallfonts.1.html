BOOKSHELF-LISTALLFONTS(1) Documentación de Perl contribuida por el usuario BOOKSHELF-LISTALLFONTS(1)

NOMBRE

bookshelf-listallfonts - lista todas las fuentes conocidas por LuaTeX con características "interesantes"

SINOPSIS

bookshelf-listallfonts [-d] [-f ARCHIVO_CARACTERISTICAS] [-x ARCHIVO_PATRONES_EXCLUIDOS]

bookshelf-listallfonts -h

bookshelf-listallfonts -v

bookshelf-listallfonts -m

DESCRIPCIÓN

Lista todas las fuentes conocidas por LuaTeX añadiendo características "interesantes" a la lista.

El script consulta las bases de datos de luaotfload y muestra la lista de fuentes y características como un flujo separado por tabulaciones con dos campos: nombre de fuente + nombre de característica, y comando de carga de LuaTeX. Esta forma es adecuada para el comando mkfontsel.pl(1) del paquete bookshelf.

Siempre incluimos características predeterminadas, "+clig;+liga;+tlig".

Se recomienda ejecutar

luaotfload-tool --update --force

antes de ejecutar el script.

OPCIONES

-d
Imprimir información de depuración en la salida estándar.
-f ARCHIVO_CARACTERISTICAS
Usar los patrones del archivo CARACTERISTICAS en lugar de los predeterminados.
-x ARCHIVO_PATRONES_EXCLUIDOS
Excluir patrones (rutas de fuentes y características o combinaciones) que se encuentran en ARCHIVO_PATRONES_EXCLUIDOS.
-v
Imprimir información de versión
-h
Imprimir información de uso
-m
Imprimir la página del manual
