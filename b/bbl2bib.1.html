NOMBRE

bbl2bib.pl - convierte el entorno bibliography a un archivo bib

SINOPSIS

bbl2bib.pl [-d] [-u] [-o salida] archivo

OPCIONES

[-d]
Envía salida de depuración a stdout
-o salida
Archivo de salida. Si no se utiliza esta opción, el nombre del archivo de salida se forma cambiando la extensión a ".bib"
-u
No limpiar campos URL.

Normalmente "bbl2bib" reconoce campos URL del tipo "http://dx.doi.org" y sus variantes y los convierte a campos DOI (ver también el script biburl2doi(1)). El modificador -u suprime esta limpieza.

DESCRIPCIÓN

El script intenta reconstruir un archivo "bib" a partir del entorno "thebibliography" correspondiente. Se puede argumentar que esta operación es similar a reconstruir una vaca a partir del bistec. La forma en que el script lo hace es buscando la entrada en la base de datos de MR y creando los campos BibTeX correspondientes.

El script lee un archivo TeX o Bbl y extrae de él el entorno "thebibliography". Para cada bibitem crea una entrada de bibliografía en texto plano y luego intenta hacer coincidirla en la base de datos.

ARCHIVO DE ENTRADA

Asumimos cierta estructura del archivo de entrada:

1.
La bibliografía está contenida entre las líneas 
\begin{thebibliography}...

y

\end{thebibliography}
2.
Cada elemento de la bibliografía comienza en la línea 
\bibitem[...]{....}

EJEMPLOS

bbl2bib  -o - file.tex > result.bib
bbl2bib  -o result.bib file.bbl
bbl2bib  file.tex
