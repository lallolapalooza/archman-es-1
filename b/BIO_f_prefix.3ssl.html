BIO_f_prefix(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_F_PREFIX(3ssl) OpenSSL BIO_F_PREFIX(3ssl)

NOMBRE

BIO_f_prefix, BIO_set_prefix, BIO_set_indent, BIO_get_indent - filtro BIO de prefijo

SINOPSIS

#include <openssl/bio.h>
const BIO_METHOD *BIO_f_prefix(void);
long BIO_set_prefix(BIO *b, const char *prefix);
long BIO_set_indent(BIO *b, long indent);
long BIO_get_indent(BIO *b);

DESCRIPCIÓN

BIO_f_cipher() devuelve el método BIO de prefijo. Este es un filtro para la salida de texto, donde cada línea se antepone y se indenta automáticamente según la entrada del usuario.

El prefijo y la indentación se combinan. Por cada línea de salida que pasa por este filtro, se muestra primero el prefijo, luego la cantidad de espacios adicionales indicada por la indentación y, a continuación, la línea en sí.

Por defecto, no hay prefijo y la indentación se establece en 0.

BIO_set_prefix() establece el prefijo que se utilizará para las futuras líneas de texto, utilizando prefix. prefix puede ser NULL, lo que significa que no debe haber prefijo. Si prefix no es NULL, esta función hace una copia de él.

BIO_set_indent() establece la indentación que se utilizará para las futuras líneas de texto, utilizando indent. No se permiten valores negativos.

BIO_get_indent() obtiene la indentación actual.

NOTAS

BIO_set_prefix(), BIO_set_indent() y BIO_get_indent() están implementadas como macros.

VALORES DEVUELTOS

BIO_f_prefix() devuelve el método BIO de prefijo.

BIO_set_prefix() devuelve 1 si el prefijo se estableció correctamente, o <=0 en caso de error.

BIO_set_indent() devuelve 1 si el prefijo se estableció correctamente, o <=0 en caso de error.

BIO_get_indent() devuelve la indentación actual, o un valor negativo en caso de error.

VER TAMBIÉN

bio(7)

HISTORIAL

BIO_get_indent(), BIO_set_indent(), BIO_set_prefix() se añadieron en OpenSSL 3.0.
