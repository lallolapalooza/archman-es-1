Nombre

btattach - Adjuntar dispositivos serie a la pila BlueZ

SINOPSIS

btattach [-B dispositivo] [-A dispositivo] [-P protocolo] [-R]

DESCRIPCIÓN

btattach(1) se utiliza para adjuntar una UART serie a la pila Bluetooth como una interfaz de transporte.

OPCIONES

-B dispositivo, --brder dispositivo
Adjuntar un controlador BR/EDR
-A dispositivo, --amp dispositivo
Adjuntar un controlador AMP
-P protocolo, --protocol protocolo
Especificar el tipo de protocolo para comunicarse con el dispositivo.

Los valores admitidos son:

protocolo
h4
bcsp
3wire
h4ds
ll
ath3k
intel
bcm
qca
-S velocidad_baudios, --speed velocidad_baudios
Especificar la velocidad de baudios a utilizar
-N, --noflowctl
Desactivar el control de flujo
-v, --version
Mostrar la versión
-h, --help
Mostrar las opciones de ayuda

RECURSOS
