NOMBRE

buildah-manifest-create - Crea una lista de manifiestos o un índice de imágenes.

SINOPSIS

buildah manifest create [opciones...] nombreListaOIndice [nombreImagen ...]

DESCRIPCIÓN

Crea una nueva lista de manifiestos y la almacena como una imagen en el almacenamiento local usando el nombre especificado.

Si se especifican imágenes adicionales, se agregan a la lista o índice recién creados.

VALOR DE RETORNO

El ID de imagen generado aleatoriamente de la lista o índice recién creado. La imagen se puede eliminar usando el comando buildah rmi.

OPCIONES

--all

Si alguna de las imágenes que deben agregarse a la nueva lista o índice son a su vez listas o índices, agregue todo su contenido. Por defecto, solo se agregará una imagen de dicha lista a la lista o índice recién creados.

--amend

Si ya existe una lista de manifiestos llamada nombreListaOIndice, modifica la lista preexistente en lugar de salir con un error. El contenido de nombreListaOIndice no se modifica si no se proporcionan *nombreImagen*s.

--annotation anotacion=valor

Establece una anotación en el índice de imágenes recién creado.

--tls-verify valor-booleano

Requiere HTTPS y verificación de certificados al comunicarse con los registros de contenedores (el valor predeterminado es true). La verificación TLS no se puede usar al comunicarse con un registro inseguro.

EJEMPLO

buildah manifest create mylist:v1.11
941c1259e4b85bebf23580a044e4838aa3c1e627528422c9bf9262ff1661fca9
buildah manifest create --amend mylist:v1.11
941c1259e4b85bebf23580a044e4838aa3c1e627528422c9bf9262ff1661fca9
buildah manifest create mylist:v1.11 docker://fedora
941c1259e4b85bebf23580a044e4838aa3c1e627528422c9bf9262ff1661fca9
buildah manifest create --all mylist:v1.11 docker://fedora
941c1259e4b85bebf23580a044e4838aa3c1e627528422c9bf9262ff1661fca9
