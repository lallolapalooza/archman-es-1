NOMBRE

basic_getpwnam_auth - Ayudante de autenticación de usuarios locales para Squid

SINOPSIS

basic_getpwnam_auth

DESCRIPCIÓN

basic_getpwnam_auth permite a Squid autenticar cualquier cuenta de usuario local para validar el nombre de usuario y la contraseña de la autenticación HTTP básica.

Utiliza las rutinas getpwnam() y getspnam() para la autenticación.

Esto tiene las siguientes ventajas sobre el módulo NCSA:

- Permite la autenticación de todos los usuarios locales conocidos
- Permite la autenticación a través de nsswitch.conf
- Puede manejar peticiones NIS(+)
- Puede manejar peticiones LDAP
- Puede manejar peticiones PAM

CONFIGURACIÓN

auth_param basic program /ruta/a/basic_getpwnam_auth
auth_param basic children concurrency=1

Cuando se utiliza para autenticar a bases de datos de contraseñas shadow locales de UNIX, el programa debe ejecutarse como root o no tendrá permisos suficientes para acceder a la base de datos de contraseñas de usuario. No se recomienda este uso del programa, pero si absolutamente lo necesita, haga que el programa sea setuid root

chown root basic_getpwnam_auth
chmod u+s basic_getpwnam_auth

Tenga en cuenta que en tales configuraciones también se recomienda encarecidamente mover el programa a un directorio donde los usuarios normales no puedan acceder a él, ya que este modo de operación permitirá a cualquier usuario local intentar descifrar contraseñas de otros usuarios. Tenga en cuenta también que el programa no ha sido auditado completamente y el autor no puede ser responsable de ningún problema de seguridad debido a tales instalaciones.
