NOMBRE

binaryring - Un sistema de partículas de trazado de caminos evoluciona continuamente desde una creación inicial.

SINOPSIS

binaryring [--fps] [--install] [--noinstall] [--mono] [--root] [--window-id número] [--visual visual] [--window] [--window-id window-id] [--color] [--no-color] [--growth-delay retraso_ms] [--particle-number partículas] [--ring-radius radio]

DESCRIPCIÓN

Un sistema de partículas de trazado de caminos evoluciona continuamente desde una creación circular inicial. Las edades de oscuridad juegan arbitrariamente con las edades de luz.

OPCIONES

binaryring acepta las siguientes opciones:

--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.
--install
Instala un mapa de colores privado para la ventana.
--mono
Si está en una pantalla en color, simula estar en una pantalla monocromática.
--noinstall
No instala un mapa de colores privado para la ventana.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--visual visual
Especifica qué visual utilizar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--window-id window-id
Especifica qué ID de ventana usar.
--color (Por defecto)
Las partículas tienen colores generados aleatoriamente que cambian gradualmente con el tiempo.
--no-color
Utiliza la visualización original en blanco y negro.
--growth-delay retraso_ms (Por defecto: 10000)
Retraso en ms entre ciclos de crecimiento. Más retraso, más lento (pero menos intensivo en CPU).
--particles-number partículas (Por defecto: 5000)
El número de partículas en el sistema. Con más partículas, los fotogramas por segundo también pueden verse afectados.
--ring-radius radio (Por defecto: 40)
El radio del anillo donde nacen las partículas, en píxeles.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
