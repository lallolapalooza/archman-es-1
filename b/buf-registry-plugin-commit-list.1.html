NOMBRE

buf-registry-plugin-commit-list - Listar commits de plugins

SINOPSIS

buf registry plugin commit list [flags]

DESCRIPCIÓN

Este comando lista los commits en un plugin basándose en la referencia especificada. Para una referencia de commit, lista el commit en sí. Para una referencia de etiqueta, lista los commits actuales y pasados asociados con esa etiqueta. Si no se especifica ninguna referencia, lista todos los commits en este plugin.

OPCIONES

--digest-changes-only[=false] Solo commits que han cambiado los digestos. Por defecto, se listan todos los commits

--format="text" El formato de salida a usar. Debe ser uno de [text,json]

-h, --help[=false] Ayuda para list

--page-size=10 El tamaño de página

--page-token="" El token de página. Si hay más resultados disponibles, una clave "next_page" está presente en la salida --format=json

--reverse[=false] Invertir los resultados. Por defecto, están ordenados con los más nuevos primero

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta agotar el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
