builtin(3perl) Guía de referencia del programador de Perl builtin(3perl)

NOMBRE

builtin - pragma de Perl para importar funciones utilitarias incorporadas

SINOPSIS

use builtin qw(
    true false is_bool
    inf nan
    weaken unweaken is_weak
    blessed refaddr reftype
    created_as_string created_as_number
    stringify
    ceil floor
    indexed
    trim
    is_tainted
    export_lexically
    load_module
);
use builtin ':5.40';  # la mayoría de las anteriores

DESCRIPCIÓN

Perl proporciona varias funciones utilitarias en el paquete "builtin". Estas son funciones simples, y se ven y comportan como funciones definidas por el usuario. No proporcionan sintaxis nueva ni requieren análisis especial. Estas funciones siempre están presentes en el intérprete y pueden ser llamadas en cualquier momento por sus nombres completamente calificados. Por defecto, no están disponibles como nombres cortos, pero se pueden solicitar por conveniencia.

Las funciones individuales con nombre se pueden importar listándolas como parámetros de importación en la declaración "use" para este pragma.

El módulo builtin::compat de CPAN proporciona versiones de muchas de estas funciones que se pueden usar en versiones de Perl donde "builtin" o funciones específicas aún no están disponibles.

Advertencia: Actualmente, muchas de las funciones del espacio de nombres "builtin" son experimentales. Llamarlas activará advertencias de la categoría "experimental::builtin".

Importación Lexical

Este módulo pragma crea alias *lexicales* en el ámbito de compilación actual para estas funciones incorporadas. Esto es similar al efecto léxico de otros pragmas como strict y feature.

sub classify
{
    my $val = shift;
    use builtin 'is_bool';
    return is_bool($val) ? "booleano" : "no es un booleano";
}
# la función is_bool() ya no es visible aquí
# pero aún se puede llamar como builtin::is_bool()

Debido a que estas funciones se importan léxicamente, en lugar de símbolos de paquete, el usuario no necesita tomar ninguna medida especial para asegurarse de que no aparezcan accidentalmente como métodos de objeto de una clase.

package An::Object::Class {
    use builtin 'true', 'false';
    ...
}
# no aparece como método
An::Object::Class->true;
# No se puede encontrar el método de objeto "true" a través del paquete "An::Object::Class"
#   en ...

Una vez importada, una función léxica es muy similar a cualquier otro símbolo léxico (como una variable) en el sentido de que no se puede eliminar. Si desea limitar la visibilidad de una función "builtin" importada, colóquela dentro de su propio ámbito:

{
  use builtin 'refaddr';
  ...
}

Paquetes de Versión

Todo el conjunto de funciones incorporadas que se consideraron no experimentales en una versión de perl se puede importar de una sola vez, solicitando un paquete de versión. Esto se hace dando la versión de lanzamiento de perl (sin su sufijo de subversión) después de un carácter de dos puntos:

use builtin ':5.40';

Los siguientes paquetes existen actualmente:

Versión    Incluye
-------    --------
:5.40      true false weaken unweaken is_weak blessed refaddr reftype
           ceil floor is_tainted trim indexed

Optimizaciones de Funciones

Hay una serie de optimizaciones que se aplican a las funciones del paquete builtin. Si reemplaza u omite estas funciones (por ejemplo, asignando a referencias glob), es posible que las optimizaciones no surtan efecto. Haga esto con precaución.

FUNCIONES

true

$val = true;

Devuelve el valor booleano verdadero. Mientras que cualquier valor escalar puede ser probado por su verdad y la mayoría de los valores definidos, no vacíos y distintos de cero se consideran "verdaderos" por perl, este es especial en el sentido de que "is_bool" lo considera un valor booleano distinguido.

Esto proporciona un valor equivalente a expresiones como "!!1" o "!0".

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión incorporada 5.40 y superiores.

false

$val = false;

Devuelve el valor booleano falso. Mientras que cualquier valor escalar no verdadero se considera "falso" por perl, este es especial en el sentido de que "is_bool" lo considera un valor booleano distinguido.

Esto proporciona un valor equivalente a expresiones como "!!0" o "!1".

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión incorporada 5.40 y superiores.

is_bool

$bool = is_bool($val);

Esta función es actualmente experimental.

Devuelve verdadero cuando se le da un valor booleano distinguido, o falso si no. Un valor booleano distinguido es el resultado de cualquier función incorporada que devuelve un booleano (como "true" o la propia "is_bool"), operador que devuelve un booleano (como las pruebas de comparación "eq" o "==" o el operador de negación "!"), o cualquier variable que contenga uno de estos resultados.

Esta función solía llamarse "isbool". Actualmente se proporciona un alias de compatibilidad, pero se eliminará en una versión posterior.

Disponible a partir de Perl 5.36.

inf

$num = inf;

Esta función es actualmente experimental.

Devuelve el valor de infinito de punto flotante. Si el tipo C numérico subyacente no admite dicho valor, lanzará un error en tiempo de ejecución en su lugar.

Disponible a partir de Perl 5.40.

nan

$num = nan;

Esta función es actualmente experimental.

Devuelve el valor de punto flotante "No es un número" (NaN). Si el tipo C numérico subyacente no admite dicho valor, lanzará un error en tiempo de ejecución en su lugar.

Disponible a partir de Perl 5.40.

weaken

weaken($ref);

Debilita una referencia. Una referencia debilitada no contribuye al conteo de referencias de su referenciado. Si solo quedan referencias debilitadas a un referenciado, se eliminará, y todas las referencias debilitadas restantes a él se establecerán en "undef".

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión incorporada 5.40 y superiores.

unweaken

unweaken($ref);

Fortalece una referencia, deshaciendo los efectos de una llamada anterior a "weaken".

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión incorporada 5.40 y superiores.

is_weak

$bool = is_weak($ref);

Devuelve verdadero cuando se le da una referencia debilitada, o falso si no es una referencia o no está debilitada.

Esta función solía llamarse "isweak". Actualmente se proporciona un alias de compatibilidad, pero se eliminará en una versión posterior.

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión incorporada 5.40 y superiores.

blessed

$str = blessed($ref);

Devuelve el nombre del paquete para una referencia de objeto, o "undef" para una no referencia o una referencia que no es un objeto.

Disponible a partir de Perl 5.40.

refaddr

$int = refaddr($ref);

Devuelve la dirección interna (un valor entero) de la referencia $ref.

Disponible a partir de Perl 5.40.

reftype

$str = reftype($ref);

Devuelve el tipo de referencia, como "SCALAR", "ARRAY", "HASH", "CODE", "GLOB", "REF", "Regexp", "TYPEMAP", "IO", o una cadena que representa el nombre del paquete si la referencia es un objeto.

Si la referencia es "undef", devuelve "undef".

Disponible a partir de Perl 5.40.

created_as_string

$val = created_as_string($val);

Esta función es actualmente experimental.

Convierte el argumento $val a una cadena (escalar), y devuelve el resultado. Si $val ya es una cadena, la función simplemente devuelve su valor. De lo contrario, invoca el método TO_STR si está presente en el paquete del objeto, o de lo contrario, recurre al comportamiento de stringificación predeterminado de Perl.

Disponible a partir de Perl 5.40.

created_as_number

$val = created_as_number($val);

Esta función es actualmente experimental.

Convierte el argumento $val a un número (escalar), y devuelve el resultado. Si $val ya es un número, la función simplemente devuelve su valor. De lo contrario, invoca el método TO_NUM si está presente en el paquete del objeto, o de lo contrario, recurre al comportamiento de conversión a número predeterminado de Perl.

Disponible a partir de Perl 5.40.

stringify

$str = stringify($val);

Esta función es actualmente experimental.

Convierte el argumento $val a una cadena (escalar), y devuelve el resultado. Si $val ya es una cadena, la función simplemente devuelve su valor. De lo contrario, invoca el método TO_STR si está presente en el paquete del objeto, o de lo contrario, recurre al comportamiento de stringificación predeterminado de Perl.

Esto es funcionalmente idéntico a "created_as_string".

Disponible a partir de Perl 5.40.

ceil

$num = ceil($num);

Devuelve el entero más pequeño que no es menor que $num. Es decir, redondea $num hacia arriba hasta el entero más cercano.

Disponible a partir de Perl 5.40.

floor

$num = floor($num);

Devuelve el entero más grande que no es mayor que $num. Es decir, redondea $num hacia abajo hasta el entero más cercano.

Disponible a partir de Perl 5.40.

indexed

$val = indexed($value);

Esta función es actualmente experimental.

Devuelve el valor de índice de una referencia de matriz. Solo funciona para referencias de matriz. Si se le pasa cualquier otra cosa, lanzará un error.

my @array = (1, 2, 3);
my $ref = \@array;
say indexed($ref); # Imprime 0

Disponible a partir de Perl 5.40.

trim

$str = trim($str);

Esta función es actualmente experimental.

Devuelve una copia de la cadena $str con los espacios en blanco iniciales y finales eliminados.

say "'".trim('  hello world  ')."'"; # Imprime "'hello world'"

Disponible a partir de Perl 5.40.

is_tainted

$bool = is_tainted($scalar);

Devuelve verdadero si el escalar $scalar está marcado como contaminado (tainted), o falso en caso contrario.

Disponible a partir de Perl 5.40.

export_lexically

export_lexically($name1, $name2, ...);

Esto hace que los símbolos de paquete listados se exporten léxicamente al ámbito de compilación actual. Es decir, los nombres de funciones y variables aparecen como si hubieran sido importados por "use Module qw($name1 $name2 ...);".

Disponible a partir de Perl 5.40.

load_module

load_module($name);

Esta función es actualmente experimental.

Carga el módulo llamado $name. Si el módulo ya está cargado, no hace nada. Si el módulo no se puede encontrar o cargar, lanzará un error.

Esto es funcionalmente idéntico a usar "require" o "use", pero se llama como una función normal.

Disponible a partir de Perl 5.40.

refaddr

$num = refaddr($ref);

Devuelve la dirección de memoria de una referencia, o "undef" para una no referencia. Este valor no es probable que sea muy útil para código Perl puro, pero es práctico como medio para probar la identidad o unicidad referencial.

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión integrados de 5.40 y superiores.

reftype

$str = reftype($ref);

Devuelve el tipo básico de contenedor del referente de una referencia, o "undef" para una no referencia. Se devuelve como una cadena en mayúsculas, como "ARRAY" para referencias de arrays, o "HASH" para referencias de hashes.

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión integrados de 5.40 y superiores.

created_as_string

$bool = created_as_string($val);

Esta función es actualmente experimental.

Devuelve un booleano que representa si el valor del argumento fue creado originalmente como una cadena. Devolverá verdadero para cualquier expresión escalar cuya asignación o modificación más reciente haya sido de naturaleza similar a una cadena, como la asignación de un literal de cadena o el resultado de una operación de cadena como concatenación o expresión regular. Devolverá falso para referencias (incluyendo cualquier objeto), números, booleanos y undef.

Es poco probable que quieras usar esto para validación de datos regular dentro de Perl, ya que no devolverá verdadero para números regulares que todavía son perfectamente utilizables como cadenas, ni para ninguna referencia de objeto, especialmente objetos que sobrecargan el operador de conversión a cadena en un intento de comportarse más como cadenas. Por ejemplo

my $val = URI->new( "https://metacpan.org/" );
if( created_as_string $val ) { ... }    # esto no se ejecutará

Disponible a partir de Perl 5.36.

created_as_number

$bool = created_as_number($val);

Esta función es actualmente experimental.

Devuelve un booleano que representa si el valor del argumento fue creado originalmente como un número. Devolverá verdadero para cualquier expresión escalar cuya asignación o modificación más reciente haya sido de naturaleza numérica, como la asignación de un literal de número o el resultado de una operación numérica como una suma. Devolverá falso para referencias (incluyendo cualquier objeto), cadenas, booleanos y undef.

Es poco probable que quieras usar esto para validación de datos regular dentro de Perl, ya que no devolverá verdadero para cadenas regulares de dígitos decimales que todavía son perfectamente utilizables como números, ni para ninguna referencia de objeto, especialmente objetos que sobrecargan el operador de conversión a número en un intento de comportarse más como números. Por ejemplo

my $val = Math::BigInt->new( 123 );
if( created_as_number $val ) { ... }    # esto no se ejecutará

Si bien la mayoría del código Perl debería operar con valores escalares sin necesidad de conocer su historial de creación, estas dos funciones están destinadas a ser utilizadas por módulos de serialización de datos como codificadores JSON o situaciones similares, donde las preocupaciones de interoperabilidad del lenguaje requieren hacer una distinción entre valores que son fundamentalmente similares a cadenas versus similares a números.

Disponible a partir de Perl 5.36.

stringify

$str = stringify($val);

Esta función es actualmente experimental.

Devuelve una nueva cadena Perl plana que representa el argumento dado.

Cuando se le da un valor que ya es una cadena, se devuelve una copia de este valor sin cambios. Los booleanos falsos se tratan como la cadena vacía.

Los números se convierten en una representación decimal. Los booleanos verdaderos se tratan como el número 1.

Las referencias a objetos en clases que tienen overload y definen la entrada de overload "" utilizarán el método delegado para proporcionar un valor aquí.

Las referencias no de objeto, o las referencias a objetos en clases sin una sobrecarga de "" devolverán una cadena que nombra el tipo de contenedor subyacente de la referencia, su dirección de memoria y posiblemente el nombre de su clase si es un objeto.

Disponible a partir de Perl 5.40.

ceil

$num = ceil($num);

Devuelve el valor entero más pequeño mayor o igual que el argumento numérico dado.

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión integrados de 5.40 y superiores.

floor

$num = floor($num);

Devuelve el valor entero más grande menor o igual que el argumento numérico dado.

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión integrados de 5.40 y superiores.

indexed

@ivpairs = indexed(@items)

Devuelve una lista de tamaño par de pares número/valor, donde cada par está formado por un número que indica un índice en la lista original seguido del valor en esa posición. Es decir, devuelve una lista del doble de tamaño que la original, siendo igual a

(0, $items[0], 1, $items[1], 2, $items[2], ...)

Tenga en cuenta que, a diferencia de la función principal "values", esta función devuelve copias de sus argumentos originales, no alias de ellos. Cualquier modificación de estas copias *no* se refleja en modificaciones de los originales.

my @x = ...;
$_++ for indexed @x;  # El array @x permanece sin afectar

Esta función está pensada principalmente para ser útil combinada con la sintaxis de bucle "foreach" de múltiples variables; como

foreach my ($index, $value) (indexed LIST) {
    ...
}

En contexto escalar, esta función devuelve el tamaño de la lista que de lo contrario habría devuelto, y provoca una advertencia en la categoría "scalar".

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión integrados de 5.40 y superiores.

trim

$stripped = trim($string);

Devuelve la cadena de entrada con los espacios en blanco eliminados del principio y del final. trim() eliminará estos caracteres:

" ", un espacio ordinario.

"\t", un tabulador.

"\n", una nueva línea (salto de línea).

"\r", un retorno de carro.

y todos los demás caracteres Unicode que estén marcados como espacio en blanco. Una lista completa se encuentra en "Whitespace" en perlrecharclass.

$var = "  Hello world   ";            # "Hello world"
$var = "\t\t\tHello world";           # "Hello world"
$var = "Hello world\n";               # "Hello world"
$var = "\x{2028}Hello world\x{3000}"; # "Hello world"

"trim" es equivalente a:

my $trimmed = $str =~ s/\A\s+//ur =~ s/\s+\z//ur;

Disponible a partir de Perl 5.36. Desde Perl 5.40, ya no es experimental y está incluido en los paquetes de versión integrados de 5.40 y superiores.

is_tainted

$bool = is_tainted($var);

Devuelve verdadero cuando se le da una variable contaminada.

Disponible a partir de Perl 5.38.

export_lexically

export_lexically($name1, $ref1, $name2, $ref2, ...)

Esta función es actualmente experimental.

Exporta nuevos nombres léxicos al ámbito que se está compilando actualmente. Los nombres dados por el primero de cada par de valores se referirán al elemento correspondiente cuya referencia se proporciona en el segundo. Los tipos de elementos permitidos son subrutinas y variables escalares, de array y de hash. Si el elemento es una subrutina, el nombre puede ir precedido opcionalmente por el sigilo "&", pero por conveniencia no tiene por qué ser así. Para los elementos que son variables, el sigilo es obligatorio y debe coincidir con el tipo de variable.

export_lexically func    => \&func,
                 '&func' => \&func;  # igual que arriba
export_lexically '$scalar' => \my $var;
# Los siguientes no están permitidos
export_lexically '$var' => \@arr;   # el sigilo no coincide
export_lexically name => \$scalar;  # el sigilo '&' implícito no coincide
export_lexically '*name' => \*globref;  # los globrefs no son compatibles

Esto debe llamarse en tiempo de compilación; lo que típicamente significa durante un bloque "BEGIN". Normalmente esto se usaría como parte de un método "import" de un módulo, cuando se invoca como parte de una declaración "use ...".

Disponible a partir de Perl 5.38.

load_module

load_module($module_name);

Esta función es actualmente experimental.

Carga un módulo nombrado desde las rutas de inclusión (@INC). $module_name debe ser una cadena que proporcione un nombre de módulo. No se puede omitir, y proporcionar un nombre de módulo inválido resultará en una excepción. No proporcionar ningún argumento resulta en un error de compilación. Devuelve el nombre del módulo cargado en caso de éxito.

El efecto de "load_module"-ear un módulo es en su mayor parte el mismo que "require"-ear, hasta las mismas condiciones de error cuando el módulo no existe, no compila o no evalúa a un valor verdadero. Véase también la característica "module_true".

"load_module" no se puede usar para requerir una versión particular de Perl, ni ca

n se le debe dar un nombre de módulo simple como

argumento.
