BPFTOOL-LINK(8) Manual del Administrador del Sistema BPFTOOL-LINK(8)

NOMBRE

bpftool-link - herramienta para inspección y manipulación simple de enlaces eBPF

SINOPSIS

bpftool [OPCIONES] link COMANDO

OPCIONES := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } | { -f | --bpffs } | { -n | --nomount } }

COMANDOS := { show | list | pin | help }

COMANDOS DE ENLACE

bpftool link { show | list } [ENLACE]
bpftool link pin ENLACE ARCHIVO
bpftool link detach ENLACE
bpftool link help
ENLACE := { id ID_ENLACE | pinned ARCHIVO }

DESCRIPCIÓN

bpftool link { show | list } [ENLACE]
Muestra información sobre enlaces activos. Si se especifica ENLACE, muestra información solo sobre el enlace dado; de lo contrario, lista todos los enlaces activos actualmente en el sistema.

La salida comenzará con el ID del enlace seguido del tipo de enlace y cero o más atributos con nombre, algunos de los cuales dependen del tipo de enlace.

Desde Linux 5.8, bpftool es capaz de descubrir información sobre los procesos que tienen descriptores de archivo (FD) abiertos contra enlaces BPF. En estos núcleos, bpftool emitirá automáticamente esta información también.

bpftool link pin ENLACE ARCHIVO
Fija el enlace ENLACE como ARCHIVO.

Nota: ARCHIVO debe estar ubicado en el montaje bpffs. No debe contener un punto ('.'), que está reservado para futuras extensiones de bpffs.

bpftool link detach ENLACE
Desacopla forzosamente el enlace ENLACE. El enlace BPF y su programa BPF subyacente permanecerán válidos, pero se desacoplarán del hook BPF respectivo y el enlace BPF pasará a un estado inactivo hasta que se cierre el último descriptor de archivo abierto para ese enlace.
bpftool link help
Imprime un mensaje de ayuda corto.

OPCIONES

-h, --help
Imprime un mensaje de ayuda corto (similar a bpftool help).
-V, --version
Imprime el número de versión de bpftool (similar a bpftool version), el número de la versión de libbpf en uso y las características opcionales que se incluyeron cuando se compiló bpftool. Las características opcionales incluyen el enlace con LLVM o libbfd para proporcionar el desensamblador para programas JIT-eados (bpftool prog dump jited) y el uso de esqueletos BPF (algunas características como bpftool prog profile o mostrar PIDs asociados con objetos BPF pueden depender de ello).
-j, --json
Genera salida JSON. Para comandos que no pueden producir JSON, esta opción no tiene efecto.
-p, --pretty
Genera salida JSON legible por humanos. Implica -j.
-d, --debug
Imprime todos los registros disponibles, incluso la información a nivel de depuración. Esto incluye registros de libbpf, así como del verificador, al intentar cargar programas.
-f, --bpffs
Al mostrar enlaces BPF, muestra los nombres de archivo de los enlaces fijados.
-n, --nomount
No intente montar automáticamente ningún sistema de archivos virtual (como tracefs o el sistema de archivos virtual BPF) cuando sea necesario.

EJEMPLOS

# bpftool link show

10: cgroup  prog 25
        cgroup_id 614  attach_type egress
        pids test_progs(223)

# bpftool --json --pretty link show

[{
        "type": "cgroup",
        "prog_id": 25,
        "cgroup_id": 614,
        "attach_type": "egress",
        "pids": [{
                "pid": 223,
                "comm": "test_progs"
            }
        ]
    }
]
# bpftool link pin id 10 /sys/fs/bpf/link
# ls -l /sys/fs/bpf/
-rw------- 1 root root 0 Apr 23 21:39 link
