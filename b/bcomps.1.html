BCOMPS(1) Manual de comandos generales BCOMPS(1)

NOMBRE

bcomps - filtro de componentes biconectados para grafos

SINOPSIS

bcomps [ -stvx? ] [ -oarchivo_salida ] [ archivos ]

DESCRIPCIÓN

bcomps descompone grafos en sus componentes biconectados, imprimiendo los componentes en la salida estándar.

OPCIONES

Las siguientes opciones son compatibles:

-s
No se imprime ningún grafo de salida. Implica la bandera -v.
-t
Imprime el árbol subyacente de bloques y vértices de corte.
-x
Cada componente biconectado se imprime como un grafo raíz separado.
-v
Imprime el número de bloques y vértices de corte.
-o archivo_salida
Si se especifica, cada grafo raíz se escribirá en un archivo diferente con nombres derivados de archivo_salida. En particular, si se utilizan las banderas -o y -x, entonces cada bloque se escribe en un archivo diferente. Si archivo_salida no tiene sufijo, el enésimo bloque del i-ésimo grafo se escribe en archivo_salida_n_i. Sin embargo, el bloque 0 del grafo 0 se escribe en archivo_salida.

Si archivo_salida tiene un sufijo, es decir, tiene la forma base.sfx, entonces los archivos tendrán el mismo nombre que el anterior, excepto que se les añadirá .sfx.

El árbol de bloques y vértices de corte del i-ésimo grafo se escribe en archivo_salida_n_T, con un sufijo añadido si se especifica.

Por defecto, cada grafo de entrada se imprime, y cada bloque se presenta como un subgrafo cuyo nombre es una concatenación del nombre del grafo de entrada, la cadena "_bcc_" y el número del bloque.

OPERANDOS

El siguiente operando es compatible:

archivos
Nombres de archivos que contienen 1 o más grafos en formato dot. Si no se especifica ningún operando de archivos, se utilizará la entrada estándar.

CÓDIGOS DE RETORNO

bcomps devuelve 0 si todos los grafos de entrada son biconectados; y un valor distinto de cero si algún grafo tiene múltiples bloques, o si ocurrió algún error.

ERRORES

Es posible, aunque poco probable, que los nombres utilizados para los componentes conectados y sus subgrafos entren en conflicto con nombres de subgrafos existentes.
