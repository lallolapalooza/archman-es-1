bdftruncate(1) Manual de comandos generales bdftruncate(1)

NOMBRE

bdftruncate - genera una fuente BDF truncada a partir de una fuente BDF codificada en ISO 10646-1

SINOPSIS

bdftruncate umbral < fuente_origen.bdf > fuente_destino.bdf

DESCRIPCIÓN

bdftruncate permite generar a partir de una fuente BDF codificada en ISO10646-1 otras fuentes BDF ISO10646-1 en las que todos los caracteres por encima de un valor de código umbral se almacenan sin codificar. Esto suele ser deseable porque la API de Xlib y las estructuras de datos del protocolo X11 utilizadas para representar información de métricas de fuentes son extremadamente ineficientes cuando se manejan fuentes escasamente pobladas.

EJEMPLO

El comando

bdftruncate 0x3200 < 6x13.bdf > 6x13t.bdf
generará el archivo 6x13t.bdf en el que todos los glifos con códigos >= 0x3200 solo se almacenarán sin codificar (es decir, se codifican con el punto de código -1).
