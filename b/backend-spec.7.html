NOMBRE

backend-spec - interfaz entre jw y sus backends

DESCRIPCIÓN

jw(1) llama a backends como backends/html para hacer el trabajo de conversión "real". El backend recibe todos los datos necesarios a través de variables de entorno, listos para usar.

Esta documentación describe esas variables de entorno.

El backend se ejecuta en el directorio donde se crearán los archivos de salida. Debería devolver 0 si no hubo ningún problema y devolver un valor positivo en caso contrario.

VARIABLES

SGML_FILE_NAME
El nombre base del archivo fuente
SGML_FILE
El nombre completo y la ruta del archivo fuente
SGML_JADE
El nombre del analizador (normalmente Jade u OpenJade)
SGML_ARGUMENTS
La cadena de argumentos completa para Jade u OpenJade
SGML_CATALOG_FILES
La lista de archivos de catálogo necesarios para Jade u OpenJade
SGML_STYLESHEET
La hoja de estilos a utilizar
SGML_BASE_DIR
El directorio base del sistema SGML (el valor predeterminado es /usr/share/sgml)
