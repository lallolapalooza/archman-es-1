NOMBRE

bspwm - Gestor de ventanas de partición binaria

SINOPSIS

bspwm [-h|-v|-c RUTA_CONFIGURACION]

bspc --print-socket-path

bspc DOMINIO [SELECTOR] COMANDOS

bspc COMANDO [OPCIONES] [ARGUMENTOS]

DESCRIPCIÓN

bspwm es un gestor de ventanas de tipo tiling (mosaico) que representa las ventanas como las hojas de un árbol binario completo.

Se controla y configura a través de bspc.

OPCIONES

-h

Muestra la sinopsis y sale.

-v

Muestra la versión y sale.

-c RUTA_CONFIGURACION

Usa el archivo de configuración dado.

--print-socket-path

Muestra la ruta del socket de bspwm y sale.

DEFINICIONES COMUNES

DIR         := norte | oeste | sur | este
CYCLE_DIR   := siguiente | anterior

SELECTORES

Los selectores se utilizan para seleccionar un nodo, escritorio o monitor de destino. Un selector puede describir el destino de forma relativa o nombrarlo globalmente.

Los selectores consisten en una referencia opcional, un descriptor y cualquier número de modificadores que no entren en conflicto, de la siguiente manera:

[REFERENCIA#]DESCRIPTOR(.MODIFICADOR)*

Los destinos relativos se calculan en relación con la referencia dada (el valor de referencia predeterminado es enfocado).

Se puede anteponer un signo de exclamación a cualquier modificador para invertir su significado.

Los siguientes caracteres no se pueden usar en nombres de monitores o escritorios: #, :, ..

El selector especial %<nombre> se puede usar para seleccionar un monitor o un escritorio con un nombre inválido.

Nodo

Selecciona un nodo.

NODE_SEL := [NODE_SEL#](DIR|CYCLE_DIR|PATH|any|first_ancestor|last|newest|
                        older|newer|focused|pointed|biggest|smallest|
                        <node_id>)[.[!]focused][.[!]active][.[!]automatic][.[!]local]
                                  [.[!]leaf][.[!]window][.[!]STATE][.[!]FLAG][.[!]LAYER][.[!]SPLIT_TYPE]
                                  [.[!]same_class][.[!]descendant_of][.[!]ancestor_of]
STATE := tiled|pseudo_tiled|floating|fullscreen
FLAG := hidden|sticky|private|locked|marked|urgent
LAYER := below|normal|above
SPLIT_TYPE := horizontal|vertical
PATH := @[DESKTOP_SEL:][[/]JUMP](/JUMP)*
JUMP := first|1|second|2|brother|parent|DIR

Descriptores

DIR

Selecciona la ventana en la dirección dada (espacial) relativa al nodo de referencia.

CYCLE_DIR

Selecciona el nodo en la dirección dada (cíclica) relativa al nodo de referencia dentro de un recorrido in-order en profundidad del árbol.

PATH

Selecciona el nodo en la ruta dada.

any

Selecciona el primer nodo que coincida con los selectores dados.

first_ancestor

Selecciona el primer ancestro del nodo de referencia que coincida con los selectores dados.

last

Selecciona el nodo enfocado previamente relativo al nodo de referencia.

newest

Selecciona el nodo más nuevo en el historial del nodo enfocado.

older

Selecciona el nodo más antiguo que el nodo de referencia en el historial.

newer

Selecciona el nodo más nuevo que el nodo de referencia en el historial.

focused

Selecciona el nodo actualmente enfocado.

pointed

Selecciona la hoja bajo el puntero.

biggest

Selecciona la hoja más grande.

smallest

Selecciona la hoja más pequeña.

<node_id>

Selecciona el nodo con el ID dado.

Saltos de Ruta

El nodo inicial es el nodo enfocado (o la raíz si la ruta comienza con /) del escritorio de referencia (o el escritorio seleccionado si la ruta tiene un prefijo DESKTOP_SEL).

1|first

Salta al primer hijo.

2|second

Salta al segundo hijo.

brother

Salta al nodo hermano.

parent

Salta al nodo padre.

DIR

Salta al nodo que tiene el borde en la dirección dada.

Modificadores

[!]focused

Solo considera el nodo enfocado.

[!]active

Solo considera los nodos que son el nodo enfocado de su escritorio.

[!]automatic

Solo considera nodos en modo de inserción automática. Ver también --presel-dir bajo Nodo en la sección DOMINIOS a continuación.

[!]local

Solo considera nodos en el escritorio de referencia.

[!]leaf

Solo considera nodos hoja.

[!]window

Solo considera nodos que contienen una ventana.

[!](tiled|pseudo_tiled|floating|fullscreen)

Solo considera ventanas en el estado dado.

[!]same_class

Solo considera ventanas que tienen la misma clase que la ventana de referencia.

[!]descendant_of

Solo considera nodos que son descendientes del nodo de referencia.

[!]ancestor_of

Solo considera nodos que son ancestros del nodo de referencia.

[!](hidden|sticky|private|locked|marked|urgent)

Solo considera ventanas que tienen el flag dado activado.

[!](below|normal|above)

Solo considera ventanas en la capa dada.

[!](horizontal|vertical)

Solo considera nodos con el tipo de división dado.

NAME

bspwm-settings - configuration options

DESCRIPTION

This document describes the available configuration options for bspwm.

General Settings

border_width

Window border width.

split_ratio

The default ratio for splitting nodes.

borderless_monocle

If true, monocle nodes will not have borders.

gapless_monocle

If true, monocle nodes will not have gaps.

single_monocle_border_width

If true and borderless_monocle is false, set the border width of monocle nodes to 1 pixel, regardless of the border_width setting.

normal_window_border_width

Window border width for non-monocle windows.

active_window_border_width

Window border width for the active window.

presel_feedback

If true, show a visual feedback for the preselection.

presel_feedback_gravity

The gravity of the preselection feedback. It can be center, north, east, south, or west.

presel_feedback_corner_width

The width of the corners of the preselection feedback rectangles.

presel_feedback_stroke_width

The width of the stroke of the preselection feedback rectangles.

split_mode

The default split mode. Can be automatic or manual.

focus_follows_pointer

Focus the window under the pointer.

pointer_follows_focus

When focusing a window, put the pointer at its center.

pointer_follows_monitor

When focusing a monitor, put the pointer at its center.

mapping_events_count

Handle the next mapping_events_count mapping notify events. A negative value implies that every event needs to be handled.

ignore_ewmh_focus

Ignore EWMH focus requests coming from applications.

ignore_ewmh_fullscreen

Block the fullscreen state transitions that originate from an EWMH request. The possible values are: none, all, or a comma separated list of the following values: enter, exit.

ignore_ewmh_struts

Ignore strut hinting from clients requesting to reserve space (i.e. task bars).

center_pseudo_tiled

Center pseudo tiled windows into their tiling rectangles. Defaults to true.

remove_disabled_monitors

Consider disabled monitors as disconnected.

remove_unplugged_monitors

Remove unplugged monitors.

merge_overlapping_monitors

Merge overlapping monitors (the bigger remains).

Monitor and Desktop Settings

top_padding, right_padding, bottom_padding, left_padding

Padding space added at the sides of the monitor or desktop.

Desktop Settings

window_gap

Size of the gap that separates windows.

Node Settings

border_width

Window border width.

honor_size_hints

If true, apply ICCCM window size hints to all windows. If floating, only apply them to floating and pseudo tiled windows. If tiled, only apply them to tiled windows. If false, don’t apply them. Defaults to false.

POINTER BINDINGS

click_to_focus

Focus the window (or the monitor) under the pointer if the value isn’t none.

pointer_modifier + button2

pointer_modifier + button3

The behavior of pointer_modifier + button<n> can be modified through the pointer_action<n> setting.

REPORT FORMAT

Each report event message is composed of items separated by colons.

Each item has the form <type><value> where <type> is the first character of the item.

M<monitor_name>

Focused monitor.

m<monitor_name>

Unfocused monitor.

O<desktop_name>

Occupied focused desktop.

o<desktop_name>

Occupied unfocused desktop.

F<desktop_name>

Free focused desktop.

f<desktop_name>

Free unfocused desktop.

U<desktop_name>

Urgent focused desktop.

u<desktop_name>

Urgent unfocused desktop.

L(T|M)

Layout of the focused desktop of a monitor.

T(T|P|F|=|@)

State of the focused node of a focused desktop.

G(S?P?L?M?)

Active flags of the focused node of a focused desktop.
