BPFTOOL-FEATURE(8) Manual del Administrador del Sistema BPFTOOL-FEATURE(8)

NOMBRE

bpftool-feature - herramienta para la inspección de parámetros relacionados con eBPF para el kernel de Linux o dispositivos de red

SINOPSIS

bpftool [OPCIONES] feature COMANDO

OPCIONES := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMANDOS := { probe | help }

COMANDOS DE CARACTERÍSTICAS

bpftool feature probe [COMPONENT] [full] [unprivileged] [macros [prefix PREFIX]]
bpftool feature list_builtins GROUP
bpftool feature help
COMPONENT := { kernel | dev NAME }
GROUP := { prog_types | map_types | attach_types | link_types | helpers }

DESCRIPCIÓN

bpftool feature probe [kernel] [full] [macros [prefix PREFIX]]
Explora el kernel en ejecución y vuelca una serie de parámetros relacionados con eBPF, como la disponibilidad de la llamada al sistema bpf(), el estado JIT, la disponibilidad de tipos de programas eBPF, la disponibilidad de funciones de ayuda de eBPF, y más.

Por defecto, bpftool no ejecuta sondeos para las funciones auxiliares bpf_probe_write_user() y bpf_trace_printk() que generan advertencias en los registros del kernel. Para habilitarlas y ejecutar todos los sondeos, se debe usar la palabra clave full.

Si se pasa la palabra clave macros (pero no la opción -j), se vuelca un subconjunto de la salida como una lista de macros #define que están listas para ser incluidas en un archivo de cabecera C, por ejemplo. Si, además, se usa prefix para definir un PREFIX, la cadena proporcionada se usará como prefijo para los nombres de las macros: esto puede usarse para evitar conflictos en los nombres de las macros al incluir la salida de este comando como un archivo de cabecera.

La palabra clave kernel puede omitirse. Si no se especifica ningún objetivo de sondeo, el sondeo del kernel es el comportamiento predeterminado.

Cuando se usa la palabra clave unprivileged, bpftool volcará solo las características disponibles para un usuario que no tenga establecida la capacidad CAP_SYS_ADMIN. Las características disponibles en ese caso suelen representar un pequeño subconjunto de los parámetros soportados por el sistema. Los usuarios no privilegiados DEBEN usar la palabra clave unprivileged: esto es para evitar detecciones erróneas si bpftool se ejecuta inadvertidamente como no root, por ejemplo. Esta palabra clave no está disponible si bpftool se compiló sin libcap.

bpftool feature probe dev NAME [full] [macros [prefix PREFIX]]
Explora el dispositivo de red en busca de características eBPF compatibles y vuelca los resultados en la consola.

Las palabras clave full, macros y prefix tienen el mismo papel que al explorar el kernel.

bpftool feature list_builtins GROUP
Lista los elementos conocidos por bpftool. Estos pueden ser tipos de programas BPF (prog_types), tipos de mapas BPF (map_types), tipos de adjuntos (attach_types), tipos de enlaces (link_types), o funciones auxiliares BPF (helpers). El comando no explora el sistema, sino que simplemente lista los elementos que bpftool conoce en tiempo de compilación, según lo proporcionado por libbpf (para todos los tipos de objetos) o desde la cabecera UAPI de BPF (lista de auxiliares). Esto se puede usar en scripts para iterar sobre tipos o auxiliares BPF.
bpftool feature help
Muestra un mensaje de ayuda corto.

OPCIONES

-h, --help
Muestra un mensaje de ayuda corto (similar a bpftool help).
-V, --version
Muestra el número de versión de bpftool (similar a bpftool version), el número de la versión de libbpf en uso y las características opcionales que se incluyeron cuando se compiló bpftool. Las características opcionales incluyen el enlace con LLVM o libbfd para proporcionar el desensamblador para programas JITeados (bpftool prog dump jited) y el uso de esqueletos BPF (algunas características como bpftool prog profile o la visualización de pids asociados a objetos BPF pueden depender de ello).
-j, --json
Genera salida JSON. Para comandos que no pueden producir JSON, esta opción no tiene efecto.
-p, --pretty
Genera salida JSON legible para humanos. Implica -j.
-d, --debug
Muestra todos los registros disponibles, incluso la información de nivel de depuración. Esto incluye registros de libbpf y del verificador, al intentar cargar programas.
