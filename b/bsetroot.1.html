NOMBRE

bsetroot - utilidad de blackbox para cambiar la apariencia de la ventana raíz

SINOPSIS

bsetroot -help
bsetroot [ -display display ] -solid color
bsetroot [ -display display ] -mod x y -fg color -bg color
bsetroot [ -display display ] -gradient textura -from color -to color

DESCRIPCIÓN

Bsetroot es una utilidad que puede controlar la apariencia de la ventana raíz de tres maneras: darle un color sólido, escribir un patrón modular de dos colores en ella, o renderizar una textura de gradiente, basada en dos colores diferentes.

Bsetroot se parece a xsetroot(1) en esta funcionalidad, pero soporta múltiples pantallas y texturas de gradiente de la misma manera que Blackbox. No maneja cursores, etc. Bsetroot es parte del paquete Blackbox.

OPCIONES

Bsetroot opera de tres maneras, debe elegir una de las 3 primeras opciones:

-solid color
Establece la ventana raíz al color especificado.
-mod x y
Crea un patrón modular. Debe especificar colores -bg y -fg.
-gradient cadena_textura
Renderiza la cadena de textura especificada en la ventana raíz. Para posibles cadenas de textura, consulte blackbox(1). También debe especificar un color -from y un color -to.
-display display
Indica a Bsetroot que se conecte a la pantalla especificada.
-bg, -background color
Color de fondo. Necesario para patrones -mod.
-fg, -foreground color
Color de primer plano. Necesario para patrones -mod.
-from color
Color de inicio para renderizar texturas. Necesario para el modo de operación -gradient.
-to color
Color final para renderizar texturas. Necesario para el modo de operación -gradient.
-help
Imprime información de versión y un breve texto de ayuda.

AUTOR

Bsetroot está escrito y mantenido por Brad Hughes (blackbox@alug.org) y Jeff Raven (jraven@psu.edu).
