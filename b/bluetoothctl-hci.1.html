Nombre

bluetoothctl-hci - Submenú de HCI

SINÓPSIS

bluetoothctl [--opciones] [comandos.hci]

Comandos

open

Abrir canal HCI.

Uso
> open <índice> <canal=raw,usuario>
Ejemplo de apertura de canal de usuario
Para abrir un canal de usuario, el controlador debe estar apagado
primero:
> power off
> hci.open 0 user
Canal de usuario del índice HCI 0 abierto

cmd

Enviar comando HCI.

Uso
> cmd <código_operación> [parámetros...]
Ejemplo de envío del comando HCI Reset
> hci.cmd 0x0c03
Comando HCI completado:
00

send

Enviar paquete de datos HCI.

Uso
> send <tipo=acl,sco,iso> <manejador> [datos...]
Ejemplo de envío de paquete de datos ACL al manejador de conexión 0x0000
> hci.send acl 0x0000

register

Registrar manejador de eventos HCI.

Uso
> register <evento>

unregister

Anular el registro del manejador de eventos HCI.

Uso
> unregister <evento>

close

Cerrar canal HCI.

Uso
> close <índice>
