NOMBRE

bup-init - inicializa un repositorio bup

SINOPSIS

[BUP_DIR=ruta_local] bup init [-r host:ruta]

DESCRIPCIÓN

bup init inicializa tu repositorio bup local. Por defecto, BUP_DIR es ~/.bup.

OPCIONES

-r, --remote=host:ruta
Inicializa no solo el repositorio local, sino también el repositorio remoto dado por el host y la ruta. Esto no es necesario si se pretende hacer una copia de seguridad en la ubicación predeterminada del servidor (es decir, una ruta en blanco). La conexión con el servidor remoto se realiza con SSH. Si desea especificar qué puerto, usuario o clave privada utilizar para la conexión SSH, le recomendamos que utilice el archivo ~/.ssh/config.

EJEMPLOS

bup init

VER TAMBIÉN

bup-fsck(1), ssh_config(5)
