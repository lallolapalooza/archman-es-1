bsearch(3) Manual de funciones de biblioteca bsearch(3)

NOMBRE

bsearch - búsqueda binaria de un array ordenado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
void *bsearch(const void *key, const void *base,
              size_t nmemb, size_t size,
              int (*compar)(const void *, const void *));

DESCRIPCIÓN

La función bsearch() busca en un array de nmemb elementos, cuyo miembro inicial está apuntado por base, un miembro que coincida con el objeto apuntado por key. El tamaño de cada miembro del array se especifica por size.

El contenido del array debe estar en orden ascendente según la función de comparación referenciada por compar. La rutina compar se espera que tenga dos argumentos que apunten al objeto key y a un miembro del array, en ese orden, y debe devolver un entero menor que, igual a, o mayor que cero si el objeto key se encuentra, respectivamente, menor que, igual a, o mayor que el miembro del array.

VALOR DE RETORNO

La función bsearch() devuelve un puntero a un miembro coincidente del array, o NULL si no se encuentra ninguna coincidencia. Si hay varios elementos que coinciden con la clave, el elemento devuelto no se especifica.

EJEMPLOS

El siguiente ejemplo primero ordena un array de estructuras usando qsort(3), luego recupera elementos deseados usando bsearch().

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
struct mi {
    int         nr;
    const char  *name;
};
static struct mi  months[] = {
    { 1, "jan" }, { 2, "feb" }, { 3, "mar" }, { 4, "apr" },
    { 5, "may" }, { 6, "jun" }, { 7, "jul" }, { 8, "aug" },
    { 9, "sep" }, {10, "oct" }, {11, "nov" }, {12, "dec" }
};
static int
compmi(const void *m1, const void *m2)
{
    const struct mi *mi1 = m1;
    const struct mi *mi2 = m2;
    return strcmp(mi1->name, mi2->name);
}
int
main(int argc, char *argv[])
{
    qsort(months, NITEMS(months), sizeof(months[0]), compmi);
    for (size_t i = 1; i < argc; i++) {
        struct mi key;
        struct mi *res;
        key.name = argv[i];
        res = bsearch(&key, months, NITEMS(months),
                      sizeof(months[0]), compmi);
        if (res == NULL)
            printf("'%s': unknown month\n", argv[i]);
        else
            printf("%s: month #%d\n", res->name, res->nr);
    }
    exit(EXIT_SUCCESS);
}
