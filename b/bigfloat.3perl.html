bigfloat(3perl) Guía de referencia del programador de Perl bigfloat(3perl)

NOMBRE

bigfloat - Soporte transparente de números de punto flotante grandes para Perl

SINOPSIS

use bigfloat;
$x = 2 + 4.5;                       # Math::BigFloat 6.5
print 2 ** 512 * 0.1;               # Math::BigFloat 134...09.6
print inf + 42;                     # Math::BigFloat inf
print NaN * 7;                      # Math::BigFloat NaN
print hex("0x1234567890123490");    # Perl v5.10.0 o posterior
{
    no bigfloat;
    print 2 ** 256;                 # ahora un escalar normal de Perl
}
# para versiones antiguas de Perl, importar en el paquete actual:
use bigfloat qw/hex oct/;
print hex("0x1234567890123490");
print oct("01234567890123490");

DESCRIPCIÓN

Todos los literales numéricos en el ámbito dado se convierten a objetos Math::BigFloat.

Todos los operadores (incluidas las operaciones matemáticas básicas) excepto el operador de rango ".." están sobrecargados.

Por lo tanto, lo siguiente:

use bigfloat;
$x = 1234;

crea un Math::BigFloat y almacena una referencia a él en $x. Esto ocurre de forma transparente y a tus espaldas, por así decirlo.

Puedes verlo con lo siguiente:

perl -Mbigfloat -le 'print ref(1234)'

Dado que los números son en realidad objetos, puedes llamar a todos los métodos habituales de Math::BigFloat sobre ellos. Esto funciona incluso hasta cierto punto en expresiones:

perl -Mbigfloat -le '$x = 1234; print $x->bdec()'
perl -Mbigfloat -le 'print 1234->copy()->binc();'
perl -Mbigfloat -le 'print 1234->copy()->binc->badd(6);'
perl -Mbigfloat -le 'print +(1234)->copy()->binc()'

(Nota que print no hace lo que esperas si la expresión empieza con '(' de ahí el "+")

Incluso puedes encadenar las operaciones como de costumbre:

perl -Mbigfloat -le 'print 1234->copy()->binc->badd(6);'
1241

Por favor, ten en cuenta que lo siguiente no funciona como se espera (no imprime nada), ya que la sobrecarga de '..' aún no es posible en Perl (a partir de v5.8.0):

perl -Mbigfloat -le 'for (1..2) { print ref($_); }'

Opciones

"bigfloat" reconoce algunas opciones que se pueden pasar al cargarlo a través de "use". Las siguientes opciones existen:

a o accuracy
Esto establece la precisión para todas las operaciones matemáticas. El argumento debe ser mayor o igual a cero. Consulta el método bround() de Math::BigInt para más detalles. 
perl -Mbigfloat=a,50 -le 'print sqrt(20)'

Ten en cuenta que establecer la precisión y la exactitud al mismo tiempo no es posible.

p o precision
Esto establece la precisión para todas las operaciones matemáticas. El argumento puede ser cualquier entero. Los valores negativos significan un número fijo de dígitos después del punto, mientras que un valor positivo redondea a este dígito a la izquierda del punto. 0 significa redondear a entero. Consulta el método bfround() de Math::BigInt para más detalles. 
perl -Mbigfloat=p,-50 -le 'print sqrt(20)'

Ten en cuenta que establecer la precisión y la exactitud al mismo tiempo no es posible.

t o trace
Esto habilita un modo de rastreo y es principalmente para depuración.
l, lib, try, o only
Carga una biblioteca matemática diferente, ver "Biblioteca Matemática". 
perl -Mbigfloat=l,GMP -e 'print 2 ** 512'
perl -Mbigfloat=lib,GMP -e 'print 2 ** 512'
perl -Mbigfloat=try,GMP -e 'print 2 ** 512'
perl -Mbigfloat=only,GMP -e 'print 2 ** 512'
hex
Sobrescribe el método incorporado hex() con una versión que pueda manejar números grandes. Esto lo sobrescribe exportándolo al paquete actual. En Perl v5.10.0 y superior, esto no es tan necesario, ya que hex() se sobrescribe léxicamente en el ámbito actual cada vez que el pragma "bigfloat" está activo.
oct
Sobrescribe el método incorporado oct() con una versión que pueda manejar números grandes. Esto lo sobrescribe exportándolo al paquete actual. En Perl v5.10.0 y superior, esto no es tan necesario, ya que oct() se sobrescribe léxicamente en el ámbito actual cada vez que el pragma "bigfloat" está activo.
v o version
esto imprime el nombre y la versión de los módulos y luego sale. 
perl -Mbigfloat=v

Biblioteca Matemática

Las operaciones matemáticas con los números se realizan (por defecto) mediante un módulo de biblioteca de backend llamado Math::BigInt::Calc. El valor predeterminado es equivalente a decir:

use bigfloat lib => 'Calc';

puedes cambiarlo usando:

use bigfloat lib => 'GMP';

Lo siguiente primero intentará encontrar Math::BigInt::Foo, luego Math::BigInt::Bar, y si esto también falla, volverá a Math::BigInt::Calc:

use bigfloat lib => 'Foo,Math::BigInt::Bar';

Usar c<lib> advierte si no se encuentran las bibliotecas especificadas y Math::BigInt recurre a una de las bibliotecas predeterminadas. Para suprimir esta advertencia, usa c<try> en su lugar:

use bigfloat try => 'GMP';

Si deseas que el código falle en lugar de recurrir a un valor predeterminado, usa "only" en su lugar:

use bigfloat only => 'GMP';

Consulta la documentación respectiva del módulo para obtener más detalles.

Llamadas a Métodos

Dado que todos los números son ahora objetos, puedes usar todos los métodos que forman parte de la API de Math::BigFloat.

Pero hay una advertencia. Al usar lo siguiente para hacer una copia de un número, solo se hará una copia superficial.

$x = 9; $y = $x;
$x = $y = 7;

Usar la copia o el original con matemáticas sobrecargadas está bien, por ejemplo, lo siguiente funciona:

$x = 9; $y = $x;
print $x + 1, " ", $y,"\n";     # imprime 10 9

pero llamar a cualquier método que modifique el número directamente dará como resultado la destrucción de tanto el original como la copia:

$x = 9; $y = $x;
print $x->badd(1), " ", $y,"\n";        # imprime 10 10
$x = 9; $y = $x;
print $x->binc(1), " ", $y,"\n";        # imprime 10 10
$x = 9; $y = $x;
print $x->bmul(2), " ", $y,"\n";        # imprime 18 18

Usar métodos que no modifican, sino que prueban el contenido, funciona:

$x = 9; $y = $x;
$z = 9 if $x->is_zero();                # funciona bien

Consulta la documentación sobre el constructor de copia y "=" en overload, así como la documentación de Math::BigFloat para más detalles.

Métodos

inf()
Un atajo para devolver Math::BigFloat->binf(). Útil porque Perl no siempre maneja correctamente el bareword "inf".
NaN()
Un atajo para devolver Math::BigFloat->bnan(). Útil porque Perl no siempre maneja correctamente el bareword "NaN".
e
# perl -Mbigfloat=e -wle 'print e'

Devuelve el número de Euler "e", también conocido como exp(1)

PI
# perl -Mbigfloat=PI -wle 'print PI'

Devuelve PI.

bexp()
bexp($power, $accuracy);

Devuelve el número de Euler "e" elevado a la potencia apropiada, con la precisión deseada.

Ejemplo:

# perl -Mbigfloat=bexp -wle 'print bexp(1,80)'
bpi()
bpi($accuracy);

Devuelve PI con la precisión deseada.

Ejemplo:

# perl -Mbigfloat=bpi -wle 'print bpi(80)'
accuracy()
Establece o obtiene la precisión.
precision()
Establecer u obtener la precisión.
round_mode()
Establecer u obtener el modo de redondeo.
div_scale()
Establecer u obtener la escala de división.
upgrade()
Establecer u obtener la clase a la que la clase de degradación se actualiza, si la hay. Establezca la clase de actualización a "undef" para desactivar la actualización.

La actualización está desactivada de forma predeterminada.

downgrade()
Establecer u obtener la clase a la que la clase de actualización se degrada, si la hay. Establezca la clase de degradación a "undef" para desactivar la actualización.

La degradación está desactivada de forma predeterminada.

in_effect()
use bigfloat;
print "in effect\n" if bigfloat::in_effect;       # true
{
    no bigfloat;
    print "in effect\n" if bigfloat::in_effect;   # false
}

Devuelve verdadero o falso si "bigfloat" está en vigor en el ámbito actual.

Este método solo funciona en Perl v5.9.4 o posterior.

ADVERTENCIAS

Literales de punto flotante en hexadecimal, octal y binario
Perl (y este módulo) aceptan literales de punto flotante en hexadecimal, octal y binario, pero úselos con precaución con versiones de Perl anteriores a la v5.32.0, porque algunas versiones de Perl dan silenciosamente un resultado incorrecto.
Sobrecarga de operadores frente a sobrecarga de literales
"bigrat" funciona sobrecargando el manejo de literales enteros y de punto flotante, convirtiéndolos en objetos Math::BigRat.

Esto significa que la aritmética que involucra solo valores de cadena o literales de cadena se realiza con los operadores incorporados de Perl.

Por ejemplo:

use bigrat;
my $x = "900000000000000009";
my $y = "900000000000000007";
print $x - $y;

produce 0 en compilaciones predeterminadas de 32 bits, ya que "bigfloat" nunca ve los literales de cadena. Para asegurarse de que la expresión se trate por completo como objetos "Math::BigFloat", use un número literal en la expresión: 

print +(0+$x) - $y;
Rangos
Perl no permite la sobrecarga de rangos, por lo que no puede usar de forma segura rangos con extremos de "bigfloat", ni la variable del iterador es un "Math::BigFloat". 
use 5.010;
for my $i (12..13) {
  for my $j (20..21) {
    say $i ** $j;  # produce un número de punto flotante,
                   # no un objeto
  }
}
in_effect()
Este método solo funciona en Perl v5.9.4 o posterior.
hex()/oct()
"bigfloat" sobrescribe estas rutinas con versiones que también pueden manejar valores de enteros grandes. Sin embargo, en Perl anteriores a la versión v5.9.4, esto no sucederá a menos que lo solicite específicamente con las dos etiquetas de importación "hex" y "oct" - y entonces será global y no se puede desactivar dentro de un ámbito con "no bigfloat": 
use bigfloat qw/hex oct/;
print hex("0x1234567890123456");
{
    no bigfloat;
    print hex("0x1234567890123456");
}

La segunda llamada a hex() advertirá sobre una constante no portable.

Compare esto con:

use bigfloat;
# advertirá solo en Perl anteriores a v5.9.4
print hex("0x1234567890123456");
