NOMBRE

bpkg-cfg-link - enlazar configuración

SINOPSIS

bpkg cfg-link [opciones] dir

DESCRIPCIÓN

El cfg-link comando enlaza la configuración especificada de bpkg con la configuración actual. Tenga en cuenta que también establece un enlace inverso implícito desde la configuración especificada hacia la actual. Vea bpkg-cfg-create(1) para obtener información de fondo sobre las configuraciones enlazadas. Para desenlazar configuraciones previamente enlazadas, use bpkg-cfg-unlink(1).

Las configuraciones enlazadas normalmente se referencian usando nombres cuando se especifican en la bpkg línea de comandos. A menos que se anule con la opción --name , el nombre original de la configuración se usa para nombrar el enlace. Si el enlace no tiene nombre, entonces se puede referenciar usando el id numérico que se asigna automáticamente al establecer el enlace o usando el UUID de la configuración.

Si la ruta de configuración especificada es relativa, entonces se reubica en relación con el directorio de configuración actual. De esta manera, cuando las configuraciones enlazadas se mueven juntas, las rutas relativas almacenadas siguen siendo válidas. Si la ruta de directorio especificada es absoluta, entonces se almacena como absoluta a menos que se especifique la opción --relative , en cuyo caso también se reubica en relación con el directorio de configuración actual.

OPCIONES DE CFG-LINK

--name nombre
Nombre alternativo del enlace. Si no se especifica esta opción, entonces el nombre de la configuración se usa como nombre del enlace (vea bpkg-cfg-create(1) para más detalles).
--relative
Reubica la ruta absoluta de la configuración enlazada en relación con el directorio de configuración actual.
--directory|-d dir
Asume que la configuración está en dir en lugar de en el directorio de trabajo actual.

ARCHIVOS DE OPCIONES PREDETERMINADAS

Vea bpkg-default-options-files(1) para una descripción general de los archivos de opciones predeterminadas. Para el comando cfg-link , el directorio de inicio de búsqueda es el directorio de configuración. Se buscan los siguientes archivos de opciones en cada directorio y, si se encuentran, se cargan en el orden listados:

bpkg.options
bpkg-cfg-link.options

Las siguientes cfg-link opciones de comando no pueden especificarse en los archivos de opciones predeterminados:

--directory|-d
