NOMBRE

buildah-manifest-inspect - Muestra una lista de manifiestos o índice de imágenes.

SINOPSIS

buildah manifest inspect nombreDeListaOIndice

DESCRIPCIÓN

Muestra la lista de manifiestos o el índice de imágenes almacenado con el nombre de imagen especificado.

VALOR DE RETORNO

Una representación JSON formateada de la lista de manifiestos o el índice de imágenes.

OPCIONES

--authfile ruta

Ruta del archivo de autenticación. El valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json, que se establece con buildah login. Si el estado de autorización no se encuentra allí, se comprueba $HOME/.docker/config.json, que se establece con docker login.

--tls-verify valor-booleano

Requiere HTTPS y verificación de certificados al comunicarse con los registros de contenedores (valor predeterminado: true). No se puede usar la verificación TLS al comunicarse con un registro no seguro.

EJEMPLO

buildah manifest inspect mylist:v1.11
