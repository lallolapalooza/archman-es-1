B::Hooks::EndOfScope(3) Documentación de Perl contribuida por el usuario B::Hooks::EndOfScope(3)

NOMBRE

B::Hooks::EndOfScope - Ejecutar código después de que un ámbito haya terminado de compilarse

VERSIÓN

versión 0.28

SINOPSIS

on_scope_end { ... };

DESCRIPCIÓN

Este módulo permite ejecutar código cuando perl termina de compilar el ámbito circundante.

FUNCIONES

on_scope_end

on_scope_end { ... };
on_scope_end $código;

Registra $código para ser ejecutado después de que el ámbito circundante haya sido compilado.

Esto se exporta por defecto. Consulta Sub::Exporter sobre cómo personalizarlo.

LIMITACIONES

Advertencia modo puro perl

Esta advertencia se aplica a **cualquier** versión de perl donde Variable::Magic no esté disponible o esté deshabilitado.

Si bien Variable::Magic tiene acceso a algo de hechicería muy oscura para permitir lanzar una excepción dentro de una devolución de llamada, la implementación pura de perl no tiene acceso a estos trucos. Por lo tanto, lo que habría sido una **excepción en tiempo de compilación** se **convierte en una advertencia**, y tu ejecución continuará como si la excepción nunca hubiera ocurrido.

Para solicitar explícitamente una implementación XS (o PP) tienes dos opciones. O importar de la implementación deseada explícitamente:

use B::Hooks::EndOfScope::XS
  o
use B::Hooks::EndOfScope::PP

o estableciendo $ENV{B_HOOKS_ENDOFSCOPE_IMPLEMENTATION} a "XS" o "PP".

Perl 5.8.0 ~ 5.8.3

Debido a un error en el intérprete principal
https://rt.perl.org/Public/Bug/Display.html?id=27040#txn-82797 presente en versiones antiguas de perl, la implementación de B::Hooks::EndOfScope fuga deliberadamente un único hash vacío por cada ámbito que se está limpiando. Esto se hace para evitar la corrupción de memoria asociada con el error mencionado anteriormente.

Para estabilizar esta solución alternativa, el uso de Variable::Magic está deshabilitado en perls anteriores a la versión 5.8.4. En dichos sistemas, cargar/solicitar B::Hooks::EndOfScope::XS explícitamente resultará en una excepción en tiempo de compilación.

Perl versiones 5.6.x

Las versiones de perl anteriores a 5.8.0 carecen de una característica que permita cambiar la visibilidad de "%^H" estableciendo el bit 17 dentro de $^H. Como tal, la única forma de lograr el efecto necesario para que este módulo funcione es usar el operador "local" explícitamente en estas plataformas. Esto podría llevar a interferencias inesperadas con otras bibliotecas basadas en ámbitos que dependen del mismo mecanismo. Por otro lado, no hay incompatibilidades conocidas de este tipo en el momento en que se escribió esta nota.

Para obtener más detalles sobre el comportamiento no disponible, consulte el archivo de prueba t/02-localise.t incluido con la distribución.
