NOMBRE

bf_copy - script de shell para copiar un directorio de trabajo de bogofilter

SINOPSIS

bf_copy [-c] dir_origen dir_destino

DESCRIPCIÓN

bf_copy copia un directorio de trabajo de bogofilter a otro directorio. Actualmente, copia los archivos de base de datos (*.db), archivos relacionados (log.*) y DB_CONFIG (si está presente).

OPCIONES

La opción -c hace que solo se copien los archivos de registro activos, no todos. La opción predeterminada es copiar todos los archivos de registro.

ESTADO DE SALIDA

El script sale con el código de estado 0 si todo salió bien, y un valor distinto de cero si encontró problemas.

ERRORES

Este script asume que todos los archivos *.db en el directorio de origen son relevantes y los copia. Esto puede no coincidir con su configuración real.

NOTAS

Este script está diseñado para usarse con versiones de bogofilter basadas en Berkeley DB y SQLite.

Este script espera un shell compatible con SUSv2. Los sistemas Solaris deben tener instalado el paquete SUNWxcu4 (cuando bogofilter está configurado) para que se pueda usar /usr/xpg4/bin/sh.
