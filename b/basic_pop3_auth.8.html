BASIC_POP3_AUTH(8) Documentación de Perl aportada por el usuario BASIC_POP3_AUTH(8)

NOMBRE

basic_pop3_auth - Autenticador POP3 para Squid

SINOPSIS

basic_pop3_auth servidor

DESCRIPCIÓN

basic_pop3_auth autentica las credenciales del usuario contra un servidor POP3.

OPCIONES

La única opción que este ayudante acepta es el nombre del servidor POP3 contra el cual validar.
