bupstash-sync(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Sincroniza elementos y datos de un repositorio bupstash a otro.

bupstash sync [OPCIONES] --to $REMOTO [CONSULTA...]

DESCRIPCIÓN

bupstash sync copia elementos y datos de un repositorio a otro, intentando minimizar el uso innecesario de ancho de banda.

Un uso típico de este comando es hacer copias de seguridad de archivos en un repositorio local (por ejemplo, un disco externo) y, al mismo tiempo, subirlos eficientemente a una ubicación externa para su almacenamiento seguro.

Tenga en cuenta que cuando no se especifica ninguna consulta, se sincronizan todos los elementos, incluso aquellos que no coinciden con la clave actual de bupstash.

LENGUAJE DE CONSULTA

Para obtener documentación completa sobre el lenguaje de consulta, consulte bupstash-query-language(7).

CACHÉ DE CONSULTA

El comando sync utiliza los mismos mecanismos de caché de consulta que bupstash-list(1). Consulte esa página para obtener más información sobre la caché de consulta.

OPCIONES

-r, --repository REPO
El repositorio desde el que sincronizar. Puede ser de la forma ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece en BUPSTASH_REPOSITORY.
--to REPO
El repositorio de destino al que sincronizar elementos. Puede ser de la forma ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece en BUPSTASH_TO_REPOSITORY.
-k, --key CLAVE
Clave utilizada para descifrar metadatos al ejecutar una consulta. Si no se establece, por defecto es BUPSTASH_KEY.
--query-cache RUTA
Ruta al archivo de caché de consulta, por defecto es uno de los siguientes, en orden, siempre que las variables de entorno apropiadas estén configuradas: $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache o $HOME/.cache/bupstash/bupstash.qcache.
--query-encrypted
La consulta no descifrará ningún metadato, lo que le permitirá listar elementos para los que no tiene una clave de descifrado. Esta opción inserta la etiqueta de consulta pseudo 'id-clave-descifrado'.
--ids-from-stdin
Sincroniza elementos con IDs leídos desde stdin, uno por línea, en lugar de ejecutar una consulta.
--utc-timestamps
Muestra y busca contra marcas de tiempo en hora UTC en lugar de hora local.
--no-progress
Suprime los indicadores de progreso (Los indicadores de progreso también se suprimen cuando stderr no es una terminal interactiva).
-q, --quiet
Silencioso, implica --no-progress.

AMBIENTE

BUPSTASH_REPOSITORY
El repositorio desde el que extraer elementos. Puede ser de la forma ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando para ejecutar y conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_TO_REPOSITORY
El repositorio al que sincronizar elementos. Puede ser de la forma ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_TO_REPOSITORY_COMMAND
Un comando para ejecutar y conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_KEY
Ruta a una clave principal que se utilizará para descifrar datos y metadatos.
BUPSTASH_KEY_COMMAND
Un comando para ejecutar que debe imprimir los datos de la clave, se puede utilizar en lugar de BUPSTASH_KEY para obtener la clave de ubicaciones arbitrarias como la red u otro almacenamiento secreto.
BUPSTASH_QUERY_CACHE
Ruta al archivo de caché de consulta a utilizar.

EJEMPLOS

Empujar todos los elementos de un repositorio local a un repositorio remoto

$ bupstash sync --repository ./repositorio-local --to ssh://$REMOTO

Realizar una copia de seguridad localmente y luego sincronizar una copia a un repositorio remoto

$ export BUPSTASH_REPOSITORY=./repositorio-local $ id="$(bupstash put ./algunos-archivos)" $ bupstash sync --to ssh://$REMOTE id="$id"
