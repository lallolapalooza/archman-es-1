BUMBLEBEED(1) Comandos de usuario BUMBLEBEED(1)

NOMBRE

bumblebeed - demonio de bumblebee

SINOPSIS

bumblebeed [OPCIÓN]...

DESCRIPCIÓN

Demonio para controlar la tarjeta de vídeo discreta nVidia en sistemas Optimus.

-D, --daemon
ejecutar como demonio (en segundo plano). Implica --use-syslog
-x, --xconf ARCHIVO
archivo xorg.conf a usar
--xconfdir DIRECTORIO
directorio xorg.conf.d a usar
-g, --group GRUPO
permitir que GRUPO se comunique con el demonio
--driver DRIVER
el controlador a usar para la tarjeta nvidia. Los valores válidos son nouveau y nvidia. Esta opción también afecta la sección del controlador que se usará del archivo de configuración
-m, --module-path RUTA
ModulePath a usar para Xorg (solo útil para nvidia)
-k, --driver-module NOMBRE
Nombre del módulo del kernel a cargar si es diferente al del controlador
--pm-method MÉTODO
método a usar para deshabilitar la tarjeta de vídeo discreta, los valores válidos son auto, bbswitch, switcheroo y none. auto selecciona un método sensato, bbswitch (módulo del kernel) está disponible para los controladores nvidia y nouveau, switcheroo (vga_switcheroo) es generalmente para los controladores nouveau y radeon y none deshabilita completamente la administración de energía (PM)
-q, --quiet, --silent
suprime todos los mensajes de registro
-v, --verbose
aumenta el nivel de verbosidad de los mensajes de registro. Se puede especificar hasta dos veces (o cinco si se usa --quiet)
--debug
muestra todos los mensajes de registro estableciendo el nivel de verbosidad al máximo
-C, --config ARCHIVO
recupera la configuración de Bumblebee del ARCHIVO
-d, --display VDISPLAY
inicia el servidor X de Bumblebee en VDISPLAY. No confundir esta opción con la variable de entorno DISPLAY
-l, --ldpath RUTA
las bibliotecas como nvidia_drv.so se buscan en RUTA (útil para el controlador nvidia)
-s, --socket NOMBRE_ARCHIVO
usa NOMBRE_ARCHIVO para la comunicación con el demonio
-h, --help
muestra esta ayuda y sale
--version
muestra información de la versión y sale
