NOMBRE

buf-registry-plugin-label-list - Lista etiquetas de plugins

SINOPSIS

buf registry plugin label list [flags]

DESCRIPCIÓN

Lista etiquetas de plugins

OPCIONES

--archive-status="unarchived" El estado de archivo de las etiquetas listadas. Debe ser uno de [archived,unarchived,all]

--format="text" El formato de salida a usar. Debe ser uno de [text,json]

-h, --help[=false] Ayuda para list

--page-size=10 El tamaño de página.

--page-token="" El token de página. Si hay más resultados disponibles, una clave "next_page" está presente en la salida --format=json

--reverse[=false] Invertir los resultados

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato de registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, configurarlo a 0 significa sin tiempo de espera
