NOMBRE

buf-dep-graph - Imprime el grafo de dependencias

SINOPSIS

buf dep graph [flags]

DESCRIPCIÓN

Como ejemplo, si un módulo en el directorio "src/proto" depende del módulo "buf.build/foo/bar" del BSR con el commit "12345", y "buf.build/foo/bar:12345" depende del módulo "buf.build/foo/baz" del BSR con el commit "67890", se imprimirá lo siguiente:

digraph {

"src/proto" -> "buf.build/foo/bar:12345"
"buf.build/foo/bar:12345" -> "buf.build/foo/baz:67890"

}

La salida real puede variar entre las versiones de la CLI y no tiene garantías de estabilidad, sin embargo, la salida siempre estará en formato DOT válido. ¡Si desea que produzcamos un formato alternativo y estable (como un mensaje de Protobuf que serializamos a JSON), háganoslo saber!

Consulte https://graphviz.org para explorar Graphviz y el lenguaje DOT. La instalación de graphviz variará según la plataforma, pero es fácil de instalar usando homebrew:

brew install graphviz

Puede visualizar fácilmente un grafo de dependencias usando la herramienta dot:

buf dep graph | dot -Tpng >| graph.png && open graph.png El primer argumento es la fuente o el módulo para imprimir el grafo de dependencias, que debe ser uno de los formatos [dir,git,mod,protofile,tar,zip]. Esto se establece por defecto en "." si no se especifica ningún argumento.

OPCIONES

--disable-symlinks[=false] No seguir enlaces simbólicos al leer fuentes o configuración del sistema de archivos local Por defecto, los enlaces simbólicos se siguen en esta CLI, pero nunca se siguen en el Buf Schema Registry

--error-format="text" El formato para los errores de compilación impresos en stderr. Debe ser uno de [text,json,msvs,junit,github-actions,gitlab-code-quality]

--format="dot" El formato en el que imprimir el grafo. Debe ser uno de [dot,json]

-h, --help[=false] Ayuda para graph

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa que no hay tiempo de espera

VER TAMBIÉN
