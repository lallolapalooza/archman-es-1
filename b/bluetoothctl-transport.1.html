Nombre

bluetoothctl-transport - Submenú de Transporte Multimedia

SINOPSIS

bluetoothctl [--opciones] [comandos.transport]

Comandos de Transporte Multimedia

listar

Lista los transportes disponibles.

Uso
> listar

mostrar

Muestra información del transporte.

Uso
> mostrar [transporte]

adquirir

Adquiere un transporte.

Uso
> adquirir <transporte> [transporte1...]

Nota:

Si se ejecuta la configuración con un servidor de audio que tenga soporte para LE Audio (como PipeWire), adquirirá automáticamente los transportes según los roles configurados.

seleccionar

Selecciona un transporte. Solo para transportes creados en un dispositivo Broadcast Sink. Esto mueve el transporte al estado de "transmisión", pendiente de adquisición.

Uso
> seleccionar <transporte> [transporte1...]

Nota:

Si el comando select recibe una lista de transportes, primero se vincularán usando la propiedad MediaTransport de "Links". Luego se seleccionarán uno por uno, llamando al método "Select" de MediaTransport. Después de que se adquiera el primer transporte, el Broadcast Sink creará ficheros (fd) para el stream asociado y todos sus enlaces. Cada enlace podrá adquirirse uno por uno, estableciendo el fichero (fd) para el transporte y comenzando a recibir audio.

El comando select no requiere que un punto final local se registre de antemano. Esto se debe a que si la configuración se ejecuta con un servidor de audio que tiene soporte para LE Audio (como PipeWire), es el servidor de audio el que registra los puntos finales y los transportes se crean como resultado. Una vez que se selecciona un transporte, el servidor de audio lo adquirirá automáticamente.

deseleccionar

Deselecciona un transporte. Solo para transportes creados en un dispositivo Broadcast Sink. Esto mueve el transporte al estado de "inactivo", pendiente de liberación por el servidor de audio. Si el transporte fue adquirido por bluetoothctl, puede liberarse de inmediato, sin necesidad de deseleccionarlo.

Uso
> deseleccionar <transporte> [transporte1...]

Nota: Si se ejecuta la configuración con un servidor de audio que tenga soporte para LE Audio (como PipeWire), se le indicará que libere automáticamente el transporte.

liberar

Libera un transporte.

Uso
> liberar <transporte> [transporte1...]

Nota:

Los transportes adquiridos por un servidor de audio solo pueden ser liberados por dicho servidor de audio.

enviar

Envía el contenido de un archivo.

Uso
> enviar <transporte> <nombre_archivo>

recibir

Obtiene/Establece el archivo a recibir.

Uso
> recibir <transporte> [nombre_archivo]

volumen

Obtiene/Establece el volumen del transporte.

Uso
> volumen <transporte> [valor]
