NOMBRE

bup-import-duplicity - importar copias de seguridad de duplicity

ADVERTENCIA

bup-import-duplicity es EXPERIMENTAL (proceda con precaución)

SINOPSIS

bup import-duplicity [-n] <url-fuente> <nombre-guardado>

DESCRIPCIÓN

bup import-duplicity importa todas las copias de seguridad de duplicity en url-fuente a bup a través de bup save -n nombre-guardado. Los guardados de bup tendrán las mismas marcas de tiempo (a través de bup save --date) que las copias de seguridad originales.

Dado que este comando opera restaurando cada copia de seguridad de duplicity a un directorio temporal, el grado en que se conservan los metadatos dependerá de las características del sistema de archivos subyacente, si ejecuta o no import-duplicity como root (o bajo fakeroot(1)), etc.

Tenga en cuenta que este comando utilizará mkdtemp para crear directorios temporales, lo que significa que debería respetar cualquier configuración de las variables de entorno TEMPDIR, TEMP o TMP. Asegúrese de que el sistema de archivos relevante tenga suficiente espacio para la copia de seguridad de duplicity más grande que se está importando.

Dado que todas las invocaciones de duplicity utilizan un --archive-dir temporal, import-duplicity no debería afectar a ~/.cache/duplicity.

OPCIONES

-n, --dry-run
no haga nada; solo imprima lo que se haría

EJEMPLOS

$ bup import-duplicity file:///duplicity/src/ legacy-duplicity
