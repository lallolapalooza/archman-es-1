BITCOIN-WALLET(1) Comandos de usuario BITCOIN-WALLET(1)

NOMBRE

bitcoin-wallet - página del manual para bitcoin-wallet v28.1.0

DESCRIPCIÓN

Bitcoin Core bitcoin-wallet versión v28.1.0

bitcoin-wallet es una herramienta sin conexión para crear e interactuar con archivos de billetera de Bitcoin Core. Por defecto, bitcoin-wallet actuará sobre las billeteras en el directorio de billetera principal por defecto en el datadir. Para cambiar la billetera objetivo, use los argumentos -datadir, -wallet y -regtest/-signet/-testnet/-testnet4.

Uso:

bitcoin-wallet [opciones] <comando>

OPCIONES

-?

Imprimir este mensaje de ayuda y salir

-datadir=<dir>

Especificar el directorio de datos

-descriptors

Crear una billetera de descriptores. Solo para 'create'

-dumpfile=<nombre de archivo>

Cuando se usa con 'dump', escribe los registros en este archivo. Cuando se usa con 'createfromdump', carga los registros en una nueva billetera.

-format=<formato>

El formato del archivo de billetera a crear. Puede ser "bdb" o "sqlite". Solo se usa con 'createfromdump'

-legacy

Crear billetera legacy. Solo para 'create'

-version

Imprimir versión y salir

-wallet=<nombre de billetera>

Especificar el nombre de la billetera

Opciones de depuración/pruebas:

-debug=<categoría>

Información de depuración de salida (por defecto: 0).

-printtoconsole

Enviar información de rastreo/depuración a la consola (por defecto: 1 cuando no está activado -debug, 0 en caso contrario).

-withinternalbdb

Usar el analizador interno de Berkeley DB al volcar un archivo de billetera de Berkeley DB (por defecto: false)

Opciones de selección de cadena:

-chain=<cadena>

Usar la cadena <cadena> (por defecto: main). Valores permitidos: main, test, testnet4, signet, regtest

-signet

Usar la cadena signet. Equivalente a -chain=signet. Tenga en cuenta que la red se define mediante el parámetro -signetchallenge

-signetchallenge

Los bloques deben satisfacer el script dado para ser considerados válidos (solo para redes signet; por defecto, el desafío global de red de prueba signet por defecto)

-signetseednode

Especificar un nodo semilla para la red signet, en formato hostname[:port], por ejemplo, sig.net:1234 (se puede usar varias veces para especificar varios nodos semilla; por defecto, los nodos semilla de red de prueba signet global por defecto)

-testnet

Usar la cadena testnet3. Equivalente a -chain=test. El soporte para testnet3 está obsoleto y se eliminará en una próxima versión. Considere migrar a testnet4 ahora usando -testnet4.

-testnet4

Usar la cadena testnet4. Equivalente a -chain=testnet4.

Comandos:

create
Crear un nuevo archivo de billetera
createfromdump
Crear un nuevo archivo de billetera a partir de registros volcados
dump
Volcar todos los registros clave-valor de la billetera
info
Obtener información de la billetera
salvage
Intentar recuperar claves privadas de una billetera corrupta. Advertencia: 'salvage' es experimental.
