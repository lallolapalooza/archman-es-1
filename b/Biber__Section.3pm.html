Biber::Section(3pm) Documentación de Perl aportada por el usuario Biber::Section(3pm)

NOMBRE

Biber::Section - objetos Biber::Section

new

Inicializa un objeto Biber::Section

citecount

set_citecount

Establece el recuento de citas de una clave. Esto proviene de biblatex a través de la opción citecounter y refleja el número real de citas que usan esta clave, teniendo en cuenta cosas como \citeauthor etc. que no son citas reales.

get_keycount

Obtiene el recuento de citas de una clave. Esto proviene de biblatex a través de la opción citecounter y refleja el número real de citas que usan esta clave, teniendo en cuenta cosas como \citeauthor etc. que no son citas reales. Un valor cero o undef necesita ser menor que 0, lo cual no falla en las comprobaciones if() - necesario para la delicada lógica de despacho de ordenación

seenkey

get_seenkey

Obtiene el recuento de una clave

incr_seenkey

Incrementa el recuento de apariciones de una clave

set_seenkey

Establece el recuento de apariciones de una clave

reset_caches

Restablece las cachés de la sección que lo necesitan

set_np_length

Comprueba y registra la longitud máxima de un componente del nombre. Necesario para construir claves de ordenación para nombres

get_np_length

Devuelve la longitud máxima de un componente del nombre. Necesario para construir claves de ordenación para nombres

set_set_pc

Registra una relación conjunto padre->hijo

set_set_cp

Registra una relación conjunto hijo->padre

get_set_pc

Devuelve un booleano que indica si existe una relación conjunto padre->hijo

get_set_cp

Devuelve un booleano que indica si existe una relación conjunto hijo->padre

get_set_children

Devuelve una lista de hijos para un conjunto padre

get_set_parents

Devuelve una lista de padres para un hijo de un conjunto

set_keytods

Guarda información sobre el mapeo clave de cita->nombre de fuente de datos. Se usa para la notificación de errores.

get_keytods

Obtiene información sobre el mapeo clave de cita->nombre de fuente de datos. Se usa para la notificación de errores.

has_badcasekey

Devuelve un valor que indica si hemos visto antes una clave que difiere solo en mayúsculas/minúsculas
<previouskey>  - hemos visto una variante de esta clave con mayúsculas/minúsculas diferentes, por lo que podemos advertir sobre esto
undef  - no hemos visto esta clave en absoluto en ninguna variante de mayúsculas/minúsculas antes

is_specificcitekey

Comprueba si una clave es citada específicamente por \cite{key} o \nocite{key}

add_related

Registra que una clave se usa como entrada relacionada

is_related

Comprueba si una clave se usa como clave de entrada relacionada

keytorelclone

Registra un mapeo clave<->clave de clon.

get_keytorelclone

Obtiene una clave de clon de entrada relacionada, dada una clave de cita

get_relclonetokey

Obtiene una clave de entrada relacionada, dada una clave de clon

has_keytorelclone

Devuelve un booleano que indica si una clave de cita tiene un clon de entrada relacionada en la sección actual

has_relclonetokey

Devuelve un booleano que indica si una clave de clon relacionado tiene una clave de cita en la sección actual

add_cite

Añade una clave a la lista de aquellas que provinieron de \cite

is_cite

Devuelve un booleano que indica si una clave provino de \cite

add_nocite

Añade una clave a la lista de aquellas que provinieron de \nocite

is_nocite

Devuelve un booleano que indica si una clave provino de \nocite

add_everykey

Añade una clave de fuente de datos a la lista de la sección de todas las claves de fuentes de datos

del_everykeys

Elimina la caché everykey. Para su uso en pruebas.

has_everykey

Devuelve un booleano que indica si hemos visto una clave en cualquier fuente de datos para esta sección.
Esto solía ser una referencia a una matriz que se comprobaba usando first() y era veinte veces más lenta.

set_allkeys_nocite

Establece un indicador que indica que la clave de cita '*' ocurrió a través de \nocite
También permitimos establecerlo a falso porque es útil en las pruebas

set_allkeys

Establece un indicador que indica que la clave de cita '*' ocurrió en las claves de cita
También permitimos establecerlo a falso porque es útil en las pruebas

is_allkeys_nocite

Comprueba el indicador que indica que la clave de cita '*' ocurrió a través de \nocite

is_allkeys

Comprueba el indicador que indica que la clave de cita '*' ocurrió en las claves de cita

bibentry

Devuelve un objeto Biber::Entry para la clave de cita dada
Entiende los alias de claves de cita

bibentries

Devuelve el objeto Biber::Entries para esta sección

del_bibentries

Elimina todos los objetos Biber::Entry del objeto Biber::Section

set_citekeys

Establece las claves de cita en un objeto Biber::Section

set_orig_order_citekeys

Establece el orden original de las claves de cita en un objeto Biber::Section

get_citekeys

Obtiene las claves de cita de un objeto Biber::Section
Devuelve una matriz normal

get_static_citekeys

Obtiene las claves de citación (citekeys) de un objeto Biber::Section
excluyendo las claves de entrada de conjuntos dinámicos
Devuelve un array normal

has_cited_citekey

Devuelve verdadero cuando $key fue una de las claves realmente citadas en la sección

add_undef_citekey

Añade una clave de citación al objeto Biber::Section como una clave
no definida. Esto nos permite emitir esta información en el archivo .bbl y
así biblatex puede ofrecer un mejor informe a utilidades externas como latexmk

get_undef_citekeys

Obtiene la lista de claves de citación no definidas de un objeto Biber::Section
Devuelve un array normal

get_orig_order_citekeys

Obtiene las claves de citación de un objeto Biber::Section en su orden original
Esto es solo para asegurarnos de tener un método que las devuelva, por si acaso
alteramos el orden en algún momento. Esto es necesario para la ordenación por citeorder.

has_citekey

Devuelve verdadero cuando $key está en el objeto Biber::Section
Entiende los alias de claves

del_citekey

Elimina una clave de citación de un objeto Biber::Section

del_citekeys

Elimina todas las claves de citación de un objeto Biber::Section

add_citekeys

Añade claves de citación al objeto Biber::Section

set_citekey_alias

Establece la información de alias de la clave de citación

get_citekey_alias

Obtiene la información de alias de la clave de citación

del_citekey_alias

Elimina el alias de la clave de citación

get_citekey_aliases

Obtiene una lista de todos los alias de claves de citación para la sección

set_labelcache_v

Establece la caché de desambiguación de etiquetas variables para un campo

get_labelcache_v

Obtiene la caché de desambiguación de etiquetas variables para un campo

set_labelcache_l

Establece la caché de desambiguación de etiquetas de lista para un campo

get_labelcache_l

Obtiene la caché de desambiguación de etiquetas de lista para un campo

is_dynamic_set

Comprueba si una clave es un conjunto dinámico

set_dynamic_set

Registra una asignación de clave dinámica a claves miembro

get_dynamic_set

Recupera las claves miembro para una clave de conjunto dinámico
Comprueba que la referencia no devuelva nada para evitar advertencias espurias
sobre desreferenciado vacío en el retorno.

dynamic_set_keys

Recupera todas las claves de conjuntos dinámicos

has_dynamic_sets

Devuelve verdadero o falso dependiendo de si la sección tiene alguna clave de conjunto dinámico

add_datasource

Añade una fuente de datos a una sección

set_datasources

Establece las fuentes de datos para una sección

get_datasources

Obtiene un array de fuentes de datos para esta sección

number

Obtiene el número de sección de un objeto Biber::Section
