NOMBRE

bdep-test - probar proyecto en configuraciones de compilación

SINOPSIS

bdep test [opciones] [pkg-spec] [cfg-spec] [cfg-var...]

cfg-spec = (@cfg-name | --config|-c cfg-dir)... | --all|-a
pkg-spec = (--directory|-d pkg-dir)... | prj-spec
prj-spec = --directory|-d prj-dir

DESCRIPCIÓN

El test comando prueba los paquetes del proyecto en una o más configuraciones de compilación. Además, las dependencias inmediatas o todas las dependencias del proyecto se pueden probar especificando las --immediate|-i o --recursive|-r opciones, respectivamente.

Internamente test ejecuta el bpkg-pkg-test(1) comando que en sí mismo no es mucho más que la operación de compilación del sistema de compilación test (ver b(1) para detalles). Como resultado, la utilidad principal de este comando es la capacidad de referirse a las configuraciones de compilación por nombre y a los paquetes del proyecto implícitamente a través del directorio de trabajo actual, así como probar dependencias.

Si no se especifica un directorio de proyecto o paquete, se asume el directorio de trabajo actual. Si no se especifica una configuración, se asumen las configuraciones predeterminadas. Ver bdep-projects-configs(1) para detalles sobre cómo especificar proyectos y configuraciones. Opcional cfg-var... son las variables de configuración adicionales para pasar al sistema de compilación.

OPCIONES DE PRUEBA

--immediate|-i
También probar dependencias inmediatas.
--recursive|-r
También probar todas las dependencias, recursivamente.
--all|-a
Usar todas las configuraciones de compilación.
--config|-c dir
Especificar la configuración de compilación como un directorio.
--directory|-d dir
Asumir que el proyecto/paquete está en el directorio especificado en lugar de en el directorio de trabajo actual.
--config-name|-n name
Especificar la configuración de compilación como un nombre.
--config-id num
Especificar la configuración de compilación como un id.

OPCIONES COMUNES

Las opciones comunes se resumen a continuación con una descripción más detallada disponible en bdep-common-options(1).

-v
Imprimir los comandos subyacentes esenciales que se están ejecutando.
-V
Imprimir todos los comandos subyacentes que se están ejecutando.
--quiet|-q
Ejecutar en silencio, solo imprimiendo mensajes de error.
--verbose level
Establecer la verbosidad del diagnóstico en level entre 0 y 6.
--stdout-format format
Formato de representación a usar para imprimir en stdout.
--jobs|-j num
Número de trabajos a realizar en paralelo.
--progress
Mostrar indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--no-progress
Suprimir indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--diag-color
Usar color en los diagnósticos.
--no-diag-color
No usar color en los diagnósticos.
--bpkg path
El programa gestor de paquetes a usar para la gestión de la configuración de compilación.
--bpkg-option opt
Opción adicional a pasar al programa gestor de paquetes.
--build path
El programa de compilación a usar para compilar paquetes.
--build-option opt
Opción adicional a pasar al programa de compilación.
--curl path
El programa curl a usar para operaciones de red.
--curl-option opt
Opción adicional a pasar al programa curl.
--pager path
El programa paginador a usar para mostrar texto largo.
--pager-option opt
Opción adicional a pasar al programa paginador.
--options-file file
Leer opciones adicionales desde file.
--default-options dir
El directorio desde el cual cargar archivos de opciones predeterminadas adicionales.
--no-default-options
No cargar archivos de opciones predeterminadas.

ARCHIVOS DE OPCIONES PREDETERMINADAS

Ver bdep-default-options-files(1) para una descripción general de los archivos de opciones predeterminadas. Para el test comando, el directorio de inicio de búsqueda es el directorio del proyecto. Los siguientes archivos de opciones se buscan en cada directorio y, si se encuentran, se cargan en el orden indicado:

bdep.options
bdep-test.options

Las siguientes test opciones del comando no se pueden especificar en los archivos de opciones predeterminadas:

--directory|-d
