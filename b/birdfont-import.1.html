BIRDFONT-IMPORT(1) Manual de Comandos Generales BIRDFONT-IMPORT(1)

NOMBRE

birdfont-import - Crear una fuente a partir de archivos SVG

SINOPSIS

birdfont-import archivo-birdfont archivo-svg ...

DESCRIPCIÓN

birdfont-import generará un archivo birdfont a partir de un conjunto de imágenes SVG. El comando asume que el nombre del archivo denota un solo carácter o un valor Unicode en el formato U+XX, donde XX es el número Unicode en formato hexadecimal.

Un dibujo guardado como "a.svg" se añadirá al glifo "a" cuando ejecutes: birdfont-import fuente.bf a.svg

Un dibujo guardado como "U+62.svg" se añadirá a "b" cuando ejecutes: birdfont-import fuente.bf U+62.svg

Consulta también birdfont-export para crear fuentes SVG, EOT y TTF a partir del archivo birdfont.
