BDF2GDFONT(1) Documentación de Perl contribuida por el usuario BDF2GDFONT(1)

NOMBRE

bdf2gdfont.pl - Convierte fuentes "BDF" de X11 a un formato de fuente cargable para GD.

SINOPSIS

% bdf2gdfont.pl courR12.bdf > courR12.fnt

DESCRIPCIÓN

Este script convierte archivos de fuentes X11 de estilo BDF a un formato que puede ser cargado por el módulo GD usando el método GD::Font->load(). Existen varias formas de obtener fuentes BDF.

1. La fuente ya está presente en tu sistema.
Algunas fuentes BDF se pueden encontrar en la distribución estándar X11R6. Este script descomprimirá automáticamente los archivos de fuentes comprimidos si su extensión termina en .gz (el programa gunzip debe estar en tu PATH).
2. Desde un servidor de fuentes.
La utilidad "fstobdf", una utilidad estándar de X11, leerá una fuente nombrada del servidor de fuentes de tu elección y la devolverá en formato BDF. Puedes canalizarla a bdf2gdfont.pl: 
fstobdf -s fontserverhost:7100 -fn 8x16 | bdf2gdfont.pl > newfont.fnt

Usa xlsfonts para averiguar qué fuentes están disponibles. La mayoría de las fuentes tendrán nombres largos como -B&H-LucidaTypewriter-Bold-R-Normal-Sans-18-180-75-75-M-110-ISO8859-10.

3. Usando la utilidad pcf2bdf.
Algunas fuentes solo están disponibles en formato PCF (compilado). Para obtenerlas, puedes activar un servidor de fuentes y seguir la receta (2), o usar la utilidad pcf2bdf de TAGA Nayuta. Esta utilidad está disponible en http://www.tsg.ne.jp/GANA/S/pcf2bdf/ (la página está en japonés, pero puedes encontrar el enlace de descarga).

Limitaciones

Este convertidor de fuentes solo funciona con fuentes de ancho fijo. Si se utiliza con una fuente TrueType o proporcional, fallará con un mensaje de error.
