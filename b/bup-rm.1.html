NOMBRE

bup-rm - eliminar referencias al contenido del archivo

SINOPSIS

bup rm [-#|--verbose] <rama|guardado...>

DESCRIPCIÓN

bup rm elimina las ramas (conjuntos de copias de seguridad) y los guardados indicados. Por sí solo, este comando no elimina ningún dato real (ni recupera ningún espacio de almacenamiento), pero puede hacer que sea muy difícil o imposible referirse a los elementos eliminados, a menos que existan otras referencias a ellos (por ejemplo, etiquetas).

Una recolección de basura posterior, ya sea mediante bup gc o mediante un git gc normal, puede eliminar permanentemente datos que ya no son alcanzables desde las ramas o etiquetas restantes, y reclamar el espacio de almacenamiento relacionado.

ADVERTENCIA: Este es uno de los pocos comandos de bup que modifica su archivo de forma intencionadamente destructiva.

OPCIONES

-v, --verbose
aumenta la verbosidad (se puede usar más de una vez).
-#, --compress=#
establece el nivel de compresión en # (un valor de 0 a 9, donde 9 es el más alto y 0 es sin compresión). El valor predeterminado es 6. Tenga en cuenta que bup rm puede que solo escriba commits nuevos.

EJEMPLOS

# Eliminar el conjunto de copias de seguridad (rama) foo y un guardado en bar.
$ bup rm /foo /bar/2014-10-21-214720
