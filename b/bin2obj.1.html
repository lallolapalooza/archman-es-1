bin2obj(1) Convertidor de binario a archivo de inclusión bin2obj(1)

NOMBRE

bin2obj - El convertidor de Free Pascal de binario a archivo de inclusión de Pascal.

SINOPSIS

bin2obj [-aeouUz] -c nombre_constante archivo_entrada

DESCRIPCIÓN

bin2obj lee un archivo binario y lo convierte en una declaración de constante de tipo Pascal. La constante es un array de bytes (base cero), en el que cada byte tiene el valor del byte en el desplazamiento índice en el archivo. (índice es el índice en el array).

USO

bin2obj acepta el nombre de un archivo binario y necesita el nombre de una constante (use la opción -c). La salida va a la salida estándar por defecto. Si no se proporciona un nombre de unidad, la salida tendrá el formato de código que se puede escribir en un archivo de inclusión.

OPCIONES

bin2obj tiene un pequeño número de opciones para controlar su comportamiento:

-a
Escribir datos ASCII en lugar de bytes. El array constante será un array de caracteres en lugar de un array de bytes. Los bytes se escribirán como constantes ASCII.
-e clave
Si se proporciona esta opción, los datos se cifrarán con clave, que es una cadena de 8 caracteres de longitud.
-h
Emitir un pequeño texto de ayuda.
-o nombre_archivo
Por defecto, la salida va a la salida estándar (la pantalla). Si se proporciona esta opción, bin2obj escribirá la salida en un archivo con el nombre nombre_archivo en su lugar. Esta opción es obligatoria si se especifica la opción -U.
-u [nombre_unidad]
Esta opción le dice a bin2obj que genere una unidad. Por defecto, la salida es solo la declaración de la constante. Si no se especifica el nombre de la unidad, bin2obj intenta determinarlo a partir del nombre del archivo de entrada.
-U [nombre_unidad]
Lo mismo que la opción -u, solo que bin2obj también llamará al compilador y compilará la unidad.
-z
Comprimir los datos antes de crear la unidad. Se utiliza la compresión zlib.
