NOMBRE

buf-beta-studio-agent - Ejecuta un servidor HTTP(S) como agente de Studio

SINOPSIS

buf beta studio-agent [flags]

DESCRIPCIÓN

Ejecuta un servidor HTTP(S) como agente de Studio

OPCIONES

--bind="127.0.0.1" La dirección que se expondrá para aceptar solicitudes HTTP

--ca-cert="" El certificado CA que se usará en la configuración TLS del cliente y del servidor

--client-cert="" El certificado que se usará en la configuración TLS del cliente

--client-key="" La clave que se usará en la configuración TLS del cliente

--disallowed-header=[] Los nombres de encabezado que no están permitidos por este agente. Cuando el agente reciba una solicitud envolvente con estos encabezados establecidos, devolverá un error en lugar de reenviar la solicitud al servidor de destino. Múltiples encabezados se añaden si se especifican varias veces

--forward-header=[] Los encabezados que se reenviarán a través del agente al servidor de destino. Debe ser un par clave-valor separado por un signo igual (como --forward-header=fromHeader1=toHeader1). Se añadirán múltiples pares de encabezados si se especifican varias veces

-h, --help[=false] Ayuda para studio-agent

--origin="https://buf.build" El origen permitido para las opciones CORS

--port="8080" El puerto que se expondrá para aceptar solicitudes HTTP

--private-network[=false] Usar el agente con CORS de red privada

--server-cert="" El certificado que se usará en la configuración TLS del servidor

--server-key="" La clave que se usará en la configuración TLS del servidor

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato de registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
