BF_COMPACT(1) Manual de Referencia de Bogofilter BF_COMPACT(1)

NOMBRE

bf_compact - script de shell para compactar un directorio de bogofilter

SINOPSIS

bf_compact directorio_bogofilter [nombre_lista_palabras...]

DESCRIPCIÓN

bf_compact crea un directorio de trabajo de bogofilter más compacto con un ciclo de volcado/carga y renombra el directorio_bogofilter anterior a directorio_bogofilter.old.

Nota: bf_compact no se puede usar para procesar el directorio de trabajo actual, ".", porque este no se puede renombrar.

Si no se proporcionan argumentos de archivo_lista_palabras, entonces bf_compact usará el conjunto configurado de listas de palabras, si el directorio_bogofilter proporcionado es el mismo que el configurado, o usará todos los archivos *.db si es un directorio diferente.

ESTADO DE SALIDA

El script sale con el código de estado 0 si todo salió bien, y no cero si encontró problemas.

NOTAS

¡Este script eliminará directorio_bogofilter.old y todo su contenido!

Este script espera un shell compatible con SUSv2. Los sistemas Solaris deberían tener instalado el paquete SUNWxcu4 (cuando bogofilter está configurado) para que se pueda usar /usr/xpg4/bin/sh.
