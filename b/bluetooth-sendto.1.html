NOMBRE

bluetooth-sendto - Aplicación GTK para transferir archivos por Bluetooth

SINOPSIS

bluetooth-sendto [--device=XX:XX:XX:XX:XX:XX [--name=NOMBRE]] [archivo...]

DESCRIPCIÓN

bluetooth-sendto mostrará un diálogo para transferir archivos por Bluetooth. bluetooth-sendto es parte de gnome-bluetooth, ver también https://wiki.gnome.org/Projects/GnomeBluetooth

OPCIONES

--device
Define la dirección del dispositivo al que se enviarán los archivos.
--name
Define el nombre del dispositivo al que se enviarán los archivos. Si se omite, se detectará automáticamente.
archivo
El archivo o archivos que se enviarán al dispositivo. Si se omite, se mostrará un selector.
