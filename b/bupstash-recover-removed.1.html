bupstash-recover-removed(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Recupera elementos del repositorio que fueron eliminados, pero que aún no han sido borrados mediante la recolección de basura.

bupstash recover-removed [OPCIONES]

DESCRIPCIÓN

bupstash recover-removed permite a un usuario deshacer todas las operaciones de ´rm´ que se hayan realizado desde la última invocación de bupstash-gc(1). En otras palabras, este comando proporciona una forma de corregir errores e invocaciones accidentales de bupstash-rm(1).

bupstash recover-removed requiere permisos de ´put´ y ´get´ para el repositorio sobre el que se está operando.

OPCIONES

-r, --repository REPO
El repositorio al que conectarse y operar. Puede tener el formato ssh://$SERVER/$PATH para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece a BUPSTASH_REPOSITORY.
--no-progress
Suprime los indicadores de progreso (Los indicadores de progreso también se suprimen cuando stderr no es una terminal interactiva).
-q, --quiet
Silencioso, implica --no-progress.

MEDIO AMBIENTE

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede tener el formato ssh://$SERVER/$PATH para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando para ejecutar y conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.

VER TAMBIÉN

bupstash(1), bupstash-rm(1), bupstash-gc(1)
