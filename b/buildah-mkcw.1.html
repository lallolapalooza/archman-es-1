NOMBRE

buildah-mkcw - Convierte una imagen de contenedor convencional en una imagen de carga de trabajo confidencial.

SINOPSIS

buildah mkcw [opciones] fuente destino

DESCRIPCIÓN

Convierte el contenido de una imagen de contenedor en una nueva imagen de contenedor que es adecuada para su uso en un entorno de ejecución confiable (TEE, por sus siglas en inglés), típicamente ejecutado usando krun (es decir, crun compilado con la característica libkrun habilitada e invocado como krun). En lugar de los contenidos convencionales, el sistema de archivos raíz de la imagen creada contendrá una imagen de disco cifrada e información de configuración para krun.

fuente

Una imagen de contenedor, almacenada localmente o en un registro

destino

Una imagen de contenedor, almacenada localmente o en un registro

OPCIONES

--add-file fuente[:destino]

Lee el contenido del archivo fuente y lo agrega a la imagen confirmada como un archivo en destino. Si no se especifica destino, se utilizará la ruta de fuente. El nuevo archivo será propiedad de UID 0, GID 0, tendrá permisos 0644 y se le dará una marca de tiempo actual. Esta opción se puede especificar varias veces.

--attestation-url, -u url La ubicación de un servidor de intermediación de claves / atestación. Si se especifica un valor, el ID de carga de trabajo de la nueva imagen, junto con la contraseña utilizada para cifrar la imagen del disco, se registrarán en el servidor, y la ubicación del servidor se almacenará en la imagen del contenedor. En tiempo de ejecución, se espera que krun contacte al servidor para recuperar la contraseña utilizando el ID de carga de trabajo, que también se almacena en la imagen del contenedor. Si no se especifica ningún valor, se debe especificar un valor de contraseña.

--base-image, -b imagen Una imagen alternativa para usar como base para la imagen de salida. Por defecto, se utiliza la imagen no-imagen scratch.

--cpus, -c número El número de CPU virtuales con los que se espera que la imagen se ejecute en tiempo de ejecución. Si no se especifica, se proporcionará un valor predeterminado.

--firmware-library, -f archivo La ubicación de la biblioteca compartida libkrunfw-sev. Si no se especifica, buildah verifica su presencia en una serie de ubicaciones codificadas.

--memory, -m número La cantidad de memoria con la que se espera que la imagen se ejecute en tiempo de ejecución, como un número de megabytes. Si no se especifica, se proporcionará un valor predeterminado.

--passphrase, -p texto La contraseña para usar para cifrar la imagen del disco que se incluirá en la imagen del contenedor. Si no se especifica ningún valor, pero se especifica un valor de --attestation-url, se utilizará una contraseña generada aleatoriamente. Los autores recomiendan configurar un --attestation-url pero no una --passphrase.

--slop, -s {porcentaje%|sizeKB|sizeMB|sizeGB} Espacio adicional a asignar para la imagen del disco en comparación con el tamaño de los contenidos de la imagen del contenedor, expresado como un porcentaje (..%) o un valor de tamaño (bytes, o unidades más grandes si están presentes sufijos como KB o MB), o una suma de dos o más de dichas especificaciones. Si no se especifica, buildah adivina que el 25% más de espacio que los contenidos será suficiente, pero esta opción se proporciona en caso de que su suposición sea incorrecta. Si el tamaño especificado o calculado es inferior a 10 megabytes, se aumentará a 10 megabytes.

--type, -t {SEV|SNP} El tipo de entorno de ejecución confiable (TEE) para el que se debe marcar la imagen. Los valores aceptados son "SEV" (AMD Secure Encrypted Virtualization - Encrypted State) y "SNP" (AMD Secure Encrypted Virtualization - Secure Nested Paging). Si no se especifica, el valor predeterminado es "SNP".

--workload-id, -w id Un identificador de carga de trabajo que se registrará en la imagen del contenedor, para ser utilizado en tiempo de ejecución para recuperar la contraseña que se utilizó para cifrar la imagen del disco. Si no se especifica, se derivará un valor semi-aleatorio del ID de imagen de la imagen base.
