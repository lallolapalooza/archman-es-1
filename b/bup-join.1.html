NOMBRE

bup-join - concatena archivos de un repositorio bup

SINOPSIS

bup join [-r host:ruta] [refs o hashes...]

DESCRIPCIÓN

bup join es aproximadamente la operación inversa a bup-split(1). Puedes usarla para recuperar el contenido de un archivo de un repositorio bup local o remoto.

La lista de refs o hashes proporcionada puede estar en cualquier formato aceptado por git(1), incluyendo nombres de ramas, IDs de commit, IDs de árbol o IDs de blob.

Si no se proporcionan refs o hashes en la línea de comandos, bup join los lee de la entrada estándar en su lugar.

OPCIONES

-r, --remote=host:ruta
Recupera objetos del repositorio remoto dado en lugar del local. ruta puede estar en blanco, en cuyo caso se usa el repositorio remoto predeterminado. La conexión con el servidor remoto se realiza con SSH. Si deseas especificar qué puerto, usuario o clave privada usar para la conexión SSH, te recomendamos que uses el archivo ~/.ssh/config. Aunque la fuente de datos sea remota, aún se requiere un repositorio bup local.

EJEMPLOS

# dividir y luego unir un archivo usando su ID de árbol
TREE=$(tar -cvf - /etc | bup split -t)
bup join $TREE | tar -tf -
# hacer dos copias de seguridad, luego obtener la penúltima más reciente.
# mybackup~1 es notación de git(1) para la penúltima commit
# más reciente en la rama llamada mybackup.
tar -cvf - /etc | bup split -n mybackup
tar -cvf - /etc | bup split -n mybackup
bup join mybackup~1 | tar -tf -
