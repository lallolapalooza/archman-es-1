init_cache

Invalida la caché del objeto T::B. Se utiliza solo en pruebas cuando, por ejemplo,
cambiamos la configuración de codificación y, por lo tanto, debemos forzar una
relectura de los datos.

TBSIG

Manejador de señales para capturar las SEGFAULTS fatales de Text::BibTex.
Tiene errores y queremos decir al menos algo si se vuelca en un core dump.

extract_entries

Rutina principal de extracción de datos.
Acepta un identificador de fuente de datos, preprocesa el archivo y luego
busca las claves pasadas, creando entradas cuando las encuentra y devolviendo
un array de claves que no encontró.

create_entry

Crea un objeto Biber::Entry a partir de un objeto Text::BibTeX.
Ten cuidado aquí, todos los métodos set de T::B son límites de UTF-8/NFC,
así que ten cuidado de codificar (NFC()) en las llamadas. Windows no manejará
UTF-8 en T::B btparse elegantemente y morirá.

cache_data

Almacena los datos del archivo en objetos T::B indexados por la clave original
de la fuente de datos, decodificados a UTF8.

preprocess_file

Convierte el archivo a UTF-8 y potencialmente decodifica las macros LaTeX a UTF-8.

parse_decode

Analiza parcialmente la fuente de datos .bib y decodifica los contenidos de datos de LaTeX.
Hacemos esto porque decodificar LaTeX todo el buffer es difícil ya que
dicha decodificación se basa en expresiones regulares y como se usan llaves para proteger
los datos en los archivos .bib, hace que sea difícil hacer algún análisis.

parsename

Dada una cadena de nombre, esta función devuelve un objeto Biber::Entry::Name
con todas las partes del nombre resueltas según las convenciones de BibTeX.
parsename('John Doe', 'author', 'key')
devuelve un objeto que internamente se ve algo así:
{ given          => {string => 'John', initial => ['J']},
  family         => {string => 'Doe', initial => ['D']},
  prefix         => {string => undef, initial => undef},
  suffix         => {string => undef, initial => undef},
  id             => 32RS0Wuj0P,
  strip          => {'given'  => 0,
                     'family' => 0,
                     'prefix' => 0,
                     'suffix' => 0}
  }

parsename_x

Dada una cadena de nombre en formato extendido, esta función devuelve un objeto Biber::Entry::Name
con todas las partes del nombre resueltas según las convenciones de BibTeX.
parsename_x('given=John, family=Doe')
devuelve un objeto que internamente se ve algo así:
{ given          => {string => 'John', initial => ['J']},
  family         => {string => 'Doe', initial => ['D']},
  prefix         => {string => undef, initial => undef},
  suffix         => {string => undef, initial => undef},
  id             => 32RS0Wuj0P,
  hashid         => 'someid',
  sortingnamekeytemplatename => 'template name',
}

NOMBRE

Biber::Input::file::bibtex - busca en un archivo BibTeX una entrada y la crea si la encuentra

DESCRIPCIÓN

Proporciona el método extract_entries() para obtener entradas de una fuente de datos BibTeX e instanciar objetos Biber::Entry para lo que encuentra.
