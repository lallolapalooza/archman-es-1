NOMBRE

bit_alloc, bit_clear, bit_decl, bit_ffs, bit_nclear, bit_nset, bit_set, bitstr_size, bit_test — macros de manipulación de cadenas de bits

BIBLIOTECA

biblioteca “libbsd”

void

void
bit_clear(bitstr_t *name, int bit);

void
bit_ffc(bitstr_t *name, int nbits, int *value);

void
bit_ffs(bitstr_t *name, int nbits, int *value);

void
bit_nclear(bitstr_t *name, int start, int stop);

void
bit_nset(bitstr_t *name, int start, int stop);

void
bit_set(bitstr_t *name, int bit);

int
bitstr_size(int nbits);

int
bit_test(bitstr_t *name, int bit);

DESCRIPCIÓN

Estas macros operan sobre cadenas de bits.

La macro bit_alloc() devuelve un puntero de tipo “bitstr_t *” al espacio suficiente para almacenar nbits bits, o NULL si no hay espacio disponible.

La macro bit_decl() asigna espacio suficiente para almacenar nbits bits en la pila.

La macro bitstr_size() devuelve el número de elementos de tipo bitstr_t necesarios para almacenar nbits bits. Esto es útil para copiar cadenas de bits.

Las macros bit_clear() y bit_set() borran o establecen el bit numerado desde cero bit, en la cadena de bits name.

Las macros bit_nset() y bit_nclear() establecen o borran los bits numerados desde cero desde start hasta stop en la cadena de bits name.

La macro bit_test() evalúa a un valor distinto de cero si el bit numerado desde cero bit de la cadena de bits name está establecido, y a cero en caso contrario.

La macro bit_ffs() almacena en la ubicación referenciada por value el número basado en cero del primer bit establecido en el arreglo de nbits bits referenciado por name. Si no hay bits establecidos, la ubicación referenciada por value se establece a -1.

La macro bit_ffc() almacena en la ubicación referenciada por value el número basado en cero del primer bit no establecido en el arreglo de nbits bits referenciado por name. Si todos los bits están establecidos, la ubicación referenciada por value se establece a -1.

Los argumentos de estas macros se evalúan solo una vez y pueden tener efectos secundarios de forma segura.

EJEMPLOS

#include <limits.h>
#include <bsd/bitstring.h>

...
#define	LPR_BUSY_BIT		0
#define	LPR_FORMAT_BIT		1
#define	LPR_DOWNLOAD_BIT	2
...
#define	LPR_AVAILABLE_BIT	9
#define	LPR_MAX_BITS		10

make_lpr_available()
{
	bitstr_t bit_decl(bitlist, LPR_MAX_BITS);
	...
	bit_nclear(bitlist, 0, LPR_MAX_BITS - 1);
	...
	if (!bit_test(bitlist, LPR_BUSY_BIT)) {
		bit_clear(bitlist, LPR_FORMAT_BIT);
		bit_clear(bitlist, LPR_DOWNLOAD_BIT);
		bit_set(bitlist, LPR_AVAILABLE_BIT);
	}
}
