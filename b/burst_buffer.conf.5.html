burst_buffer.conf - Archivo de

configuración de Slurm para la
gestión de búferes de ráfaga.

DESCRIPCIÓ

N

burst_buffer.conf es un archivo ASCII que describe la configuración de la gestión de recursos de búferes de ráfaga. Este archivo solo es necesario en los nodos de cabecera, donde se ejecuta el demonio slurmctld. El archivo siempre se encontrará en el mismo directorio que el slurm.c

onf.

Los nombres de los parámetros no distinguen entre mayúsculas y minúsculas. Cualquier texto que siga a un "#" en el archivo de configuración se trata como un comentario hasta el final de esa línea. Los cambios en el archivo de configuración entran en vigor al reiniciar los demonios de Slurm, al recibir el demonio la señal SIGHUP o al ejecutar el comando "scontrol

reconfigure".

Los parámetros de configuración disponibles

incluyen:
AllowUse
rs
Lista separada por comas de nombres de usuario y/o IDs permitidos para usar búferes de ráfaga. Las opciones AllowUsers y DenyUsers no pueden especificarse ambas a la vez. De forma predetermin
ada, todos los usuarios están perm
itidos para usar búferes de ráfaga.
DefaultPo
ol
Nombre del pool utilizado de forma predeterminada para las asignaciones de recursos. El valor predeterminado es el primer pool informado por la infraestructura de búferes de ráfaga. Esta opción solo la utiliza el plugin burst_buffer/datawar
p
.
DenyUse
rs
Lista delimitada por dos puntos de nombres de usuario y/o IDs a los que se les impide usar búferes de ráfaga. Las opciones AllowUsers y DenyUsers no pueden especificarse ambas a la vez. De forma predetermin
ada, todos los usuarios están perm
itidos para usar búferes de ráfaga.
Directi
ve
La cadena que debe usar un trabajo para solicitar un búfer de ráfaga. Esta cadena debe ir precedida
inmediatamente por un solo carácter '#'. Actualmente, esto solo lo utiliza el plugin lua. Para el pl
ugin lua, el valor predeterminado es "BB_LUA". Consulte burst_buffer.html para obtener más detalles.
Fla
gs
Cadena utilizada para controlar varias fun
ciones. Se pueden separar varias opciones p
or comas. Las opciones admitidas incluyen:
DisablePersist
ent
Impide que los usuarios normales puedan crear y destruir búferes de ráfaga persistente
s. Este es el comportamiento predeterminado; solo los usuarios privilegiados (operador
es y administradores de Slurm) pueden crear o destruir búferes de ráfaga persistentes.
EmulateCr
ay
Emulando un sistema Cray DataWarp utilizando el
script dw_wlm_cli en el plugin burst_buffer/dat
awarp. Esto solo lo utiliza el plugin datawarp.
EnablePersist
ent
Permite a los usuarios normales crear y destruir búferes de ráfaga persistentes. De forma p
redeterminada, solo los usuarios privilegiados (operadores y administradores de Slurm) puede
n crear o destruir búferes de ráfaga persistentes. Esto solo lo utiliza el plugin datawarp.
PrivateDa
ta
Si se establece, solo los operadores de S
lurm y el propietario del búfer de ráfaga
pueden ver los datos del búfer de ráfaga.
TeardownFail
ure
Si se establece, se desmonta un búfer de ráfag
a después de un error en la preparación de arc
hivos. De lo contrario, se conserva el búfer d
e ráfaga para su análisis y desmontaje manual.
GetSysSta
te
Ruta de nombre completamente calificada de un programa que devolverá el estado actual del búfer de ráfaga. Para el plugin DataWarp, esta debe ser la ruta del comando dw_wlm_cli y su valor predeterminado es /opt/cray/dw_
wlm/default/bin/dw_wlm_cli. Est
o no lo utiliza el plugin lua.
GetSysStat
us
Ruta de nombre completamente calificada de un programa que devolverá el estado actual del búfer de ráfaga. Para el plugin DataWarp, esta debe ser la ruta del comando dwstat y su valor predeterminado es /opt/cray/dw
s/default/bin/dwstat. Esto
no lo utiliza el plugin lua.
OtherTimeo
ut
Si una operación de búfer de ráfaga (distinta de la validación del trabajo, la preparación de entrada o la preparación de salida) se ejecuta durante más de este número de segundos, el trabajo se colocará en un estado retenido. Se requerirá que un administrador de Slurm libere el trabajo. De forma predeterminada, hay un tiempo de espera de 300 segundos (5 minutos) para estas operaciones. Consulte también las opciones StageInTimeout, StageOutTimeout y ValidateTimeout. Para el plugin lua, el valor máximo
de tiempo de espera es 2
073600 segundos (24 días).
PollInterv
al
Esta opción solo se aplica al plugin lua. Si los ganchos test_data_{in|o
ut} devuelven éxito y "BUSY", se llamarán de nuevo después de esperar el
número de segundos especificado. El valor predeterminado es 15 segundos.
PrivateDa
ta
Si se establece en "true", los usuarios solo podrán ver los búferes de ráfaga que pu
eden usar. Los administradores de Slurm seguirán pudiendo ver todos los búferes de r
áfaga. De forma predeterminada, los usuarios pueden ver todos los búferes de ráfaga.
StageInTimeo
ut
Si la preparación de entrada de archivos para un trabajo toma más de este número de segundos, el búfer de ráfaga se liberará y el trabajo se
colocará en un estado retenido. Se requerirá que un administrador de Slurm libere el trabajo. De forma predeterminada, hay un tiempo de esper
a de un día para el proceso de preparación de entrada. Para el plugin lua, el valor máximo de tiempo de espera es 2073600 segundos (24 días).
StageOutTime
out
Si la preparación de salida de archivos para un trabajo toma más de este número de segundos, el búfer de ráfaga
se liberará y el trabajo se purgará. De forma predeterminada, hay un tiempo de espera de un día para el proceso
de preparación de salida. Para el plugin lua, el valor máximo de tiempo de espera es 2073600 segundos (24 días).
ValidateTime
out
Si la validación de una solicitud de envío de trabajo toma más de este número de segundos, el envío será rechazado. El valor de ValidateTimeout debe ser menor que el valor de MessageTimeout configurado en el archivo slurm.conf o las solicitudes de envío de trabajos pueden fallar con un error de tiempo de espera de respuesta. De forma predetermina
da, hay un tiempo de espera de 5 segundos para las operaciones de validación. En el plu
gin lua, como la operación de validación no se puede matar, esta opción no se utiliza.
