NOMBRE

bcmxcp_usb - Controlador experimental para SAI que soportan el protocolo BCM/XCP sobre USB

SINOPSIS

bcmxcp_usb -h

bcmxcp_usb -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador bcmxcp_usb. Para obtener información sobre el controlador principal, consulta nutupsdrv(8).


Nota

Este controlador es una variante del controlador serie bcmxcp(8) y utiliza el mismo código principal.

HARDWARE SOPORTADO

Este controlador debería reconocer todos los SAI compatibles con BCM/XCP que estén conectados a través de USB. Ha sido desarrollado y probado en hardware Powerware PW3501. También ha sido probado en hardware PW5110.

ARGUMENTOS ADICIONALES

Este controlador admite las siguientes configuraciones opcionales en el archivo ups.conf(5).

shutdown_delay = retraso

El número de segundos que el SAI debe esperar entre la recepción del comando de apagado y el apagado real.

Nota

Este controlador no admite actualmente configuraciones de coincidencia USB comunes a otros controladores, como vendor, vendorid, product, productid, serial, device o bus.

VALORES POR DEFECTO PARA LOS ARGUMENTOS ADICIONALES

shutdown_delay =120

COMANDOS INSTANTÁNEOS

Este controlador admite los siguientes Comandos Instantáneos:

shutdown.return

Apaga la carga y regresa cuando la energía se restablezca.

shutdown.stayoff

Apaga la carga y permanece apagada.

test.battery.start

Inicia una prueba de batería.

LISTA DE PENDIENTES

Reportar estado de alarma del SAI

BCM/XCP admite la notificación de una amplia gama de condiciones de alarma del SAI.

Reportar información de estadísticas del SAI

BCM/XCP admite la notificación de datos de estadísticas del SAI.

CONTROLADOR EXPERIMENTAL

Este controlador ha sido etiquetado como experimental, incluso si se ha informado que es estable. Por lo tanto, no es adecuado para sistemas de producción y es posible que no se compile por defecto. Esto se debe principalmente a que es un controlador nuevo.

INSTALACIÓN

Este controlador puede que no se compile por defecto. Puedes requerir su compilación usando ./configure --with-usb=yes (ten en cuenta que también instalará otros controladores USB), o ./configure --with-drivers=bcmxcp_usb. En cualquier caso, necesitarías libusb-dev (paquete de bibliotecas y encabezados) o su equivalente para otras plataformas.

También necesitas instalar manualmente los archivos hotplug (libhidups y libhid.usermap), generalmente en etc/hotplug/usb/, para abordar el problema de configuración de permisos. Finalmente, ten en cuenta que el archivo libhidups debe tener el permiso de ejecución establecido (es decir, usando chmod +x ...).

IMPLEMENTACIÓN

bcmxcp_usb solo admite 1 SAI en este momento. Puedes poner el valor "auto" para el puerto en ups.conf, es decir:

[pw3105]
        driver = bcmxcp_usb
        port = auto

PROBLEMAS Y ERRORES CONOCIDOS

Obtuve EPERM: Operation not permitted al iniciar el controlador""

Has olvidado instalar los archivos hotplug, como se explica en la sección INSTALACIÓN. No olvides reiniciar hotplug para que aplique estos cambios.
