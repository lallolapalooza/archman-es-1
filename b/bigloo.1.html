BIGLOO(1) Manual de comandos generales BIGLOO(1)

NOMBRE

bigloo v2.3 - `un compilador práctico de Scheme'

SINOPSIS

bigloo [ opciones ] [ entrada ]

DESCRIPCIÓN

Bigloo es un compilador de Scheme. Scheme está definido en un estándar IEEE para el Lenguaje de Programación Scheme, pero Bigloo no lo cumple completamente. El compilador produce archivos C o archivos de clase de Java. Los archivos C son luego compilados por cualquier compilador C ISO para producir archivos .o o ejecutables. Bigloo es un compilador de módulos, lo que significa que se le permite compilar varios archivos y enlazarlos juntos para producir un único ejecutable.

OPCIONES

opciones
Hay muchas opciones disponibles. Escriba `bigloo -help' para imprimirlas.
-jvm
Produce archivos de clase Java en lugar de archivos C. Esta opción debe ser utilizada tanto al compilar como al enlazar.
-no-jvmjar
Deshabilita la producción de archivos jar al enlazar con -jvm.
entrada
Si se proporciona un archivo de entrada, Bigloo lo compila. De lo contrario, se entra en el intérprete. La entrada debe ser un nombre de archivo de fuente Scheme *reconocido* (es decir, un nombre de archivo con un sufijo reconocido (ver la opción -suffix)).

ARCHIVO DE CONFIGURACIÓN

Cada usuario de Bigloo puede usar un archivo de configuración especial. Este archivo debe llamarse `~/.bigloorc'. Este archivo permite modificar el comportamiento del compilador. Este archivo es un archivo Scheme regular que contiene expresiones enlazadas en un entorno donde los parámetros del compilador están enlazados. Ver la documentación para más detalles.

VARIABLES DE ENTORNO

BIGLOOHEAP
Establece el tamaño de la memoria (en megabytes). El valor por defecto es 4.
TMPDIR
Establece el directorio temporal. El valor por defecto es `/tmp'.
BIGLOOLIB
La ruta para encontrar la biblioteca de Bigloo.
BIGLOOJAVAOPT
Opciones de la Máquina Virtual Java al ejecutar una aplicación Bigloo.

ARCHIVOS

/.../lib/bigloo/2.3a/bigloo.heap -- imagen de memoria guardada para el compilador.
/.../lib/bigloo/2.3a/bigloo.jheap -- imagen de memoria guardada para el compilador para compilaciones -jvm.
/.../lib/bigloo/2.3a/bigloo.h -- definiciones que se incluyen (#include) en el código C.
/.../lib/bigloo/2.3a/libbigloo.a -- biblioteca.
/.../lib/bigloo/2.3a/libbigloo_u.a -- biblioteca.
~/.bigloorc -- archivo de configuración de `runtime-command' del usuario.
/.../.bigloorc -- ídem.
