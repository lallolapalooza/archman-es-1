BUDGIE-RUN-DIALOG(1) Comandos de usuario BUDGIE-RUN-DIALOG(1)

NOMBRE

budgie-run-dialog - aplicación invocada por el usuario para buscar y ejecutar aplicaciones rápidamente

DESCRIPCIÓN

Uso:

budgie-run-dialog [OPCIÓN?]

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-gapplication
Mostrar opciones de GApplication
--help-gtk
Mostrar opciones de GTK+

Opciones de aplicación:

--display=DISPLAY
Pantalla X a usar
