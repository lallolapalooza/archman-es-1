BOOKSHELF-MKFONTSEL(1) Documentación de Perl aportada por el usuario BOOKSHELF-MKFONTSEL(1)

NOMBRE

bookshelf-mkfontsel - un script para poblar el directorio "fontsel" y crear el archivo "pickfont.tex" para el paquete bookshelf

SINOPSIS

bookshelf-mkfontsel ARCHIVO_DE_FUENTES

DESCRIPCIÓN

Crea y puebla el directorio fontsel a partir del archivo producido por el script listallfonts.pl(1), y crea el archivo "pickfont.tex". Utilizado por el paquete bookshelf.
