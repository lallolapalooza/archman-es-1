NOMBRE

bpkg-cfg-info - imprimir información de configuración

SINOPSIS

bpkg cfg-info [opciones]

DESCRIPCIÓN

El cfg-info comando imprime la ruta absoluta, id, tipo y nombre de la configuración actual. Si se especifican las opciones --link y/o --backlink , entonces esta información también se imprime para cada configuración vinculada y/o con enlace inverso implícito, si la hay. Tenga en cuenta que los enlaces inversos implícitos colgantes se omiten silenciosamente, a menos que se especifique --dangling , en cuyo caso esta información también se imprime para ellos. Tenga en cuenta que la información se escribe en stdout, no en stderr.

Si se especifica la opción --recursive junto con --link y/o --backlink, entonces esta información se imprime para las configuraciones vinculadas y/o con enlace inverso implícito, recursivamente.

El formato de salida es regular, con cada valor impreso en una línea separada y precedido por el nombre del valor. Si se especifican las opciones --link, --backlinky/o --dangling , entonces los bloques de información correspondientes a las configuraciones vinculadas se separan con líneas en blanco. Por ejemplo:

path: /path/to/cfg/
uuid: 8d439f03-7342-4502-8b1c-74b173869478
type: target
name: foo
path: /path/to/host-cfg/
uuid: 7ee4dab3-07d9-4163-81c0-3779166a7213
type: host
name: tools
path: /path/to/build2-cfg/
uuid: d453aa2a-92c4-4066-87e4-c8672eed06e1
type: build2
name: modules

OPCIONES DE CFG-INFO

--link
Imprimir configuraciones vinculadas.
--backlink
Imprimir configuraciones con enlace inverso implícito.
--dangling
Imprimir enlaces inversos implícitos colgantes.
--recursive
Imprimir configuraciones vinculadas recursivamente.
--directory|-d dir
Asumir que la configuración está en dir en lugar del directorio de trabajo actual.

ARCHIVOS DE OPCIONES PREDETERMINADAS

Vea bpkg-default-options-files(1) para una descripción general de los archivos de opciones predeterminadas. Para el comando cfg-info , el directorio de inicio de búsqueda es el directorio de configuración.Los siguientes archivos de opciones se buscan en cada directorio y, si se encuentran, se cargan en el orden indicado:

bpkg.options
bpkg-cfg-info.options

Las siguientes opciones del comando cfg-info no se pueden especificar en los archivos de opciones predeterminados:

--directory|-d
