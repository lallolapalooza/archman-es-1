NOMBRE

bup-server - el lado del servidor de la relación cliente-servidor de bup

SINOPSIS

bup server

DESCRIPCIÓN

bup server es el lado del servidor de una sesión remota de bup. Si utiliza bup-split(1) o bup-save(1) con la opción -r, se conectarán por ssh al servidor remoto y ejecutarán bup server para recibir los objetos transmitidos.

Normalmente no hay ninguna razón para ejecutar bup server usted mismo.

MODOS

smart
En este modo, el servidor comprueba cada objeto entrante contra los archivos idx de su repositorio. Si algún objeto ya existe, informa al cliente sobre el archivo idx donde se encontró, permitiendo al cliente descargar ese idx y evitar enviar datos duplicados. Este es el modo por defecto de bup-server.
dumb
En este modo, el servidor no comprobará su índice local antes de escribir un objeto. Para evitar escribir objetos duplicados, el servidor indicará al cliente que descargue todos sus archivos .idx al inicio de la sesión. Este modo es útil en hardware de servidor de baja potencia (es decir, router/NAS lento).

ARCHIVOS

$BUP_DIR/bup-dumb-server
Activa el modo servidor "dumb", como se discute arriba. Este archivo no se crea por defecto en repositorios nuevos.

VER TAMBIÉN

bup-save(1), bup-split(1)

BUP

Parte del conjunto de herramientas bup(1).
