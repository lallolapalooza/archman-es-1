bigrat(3perl) Guía de referencia para programadores de Perl bigrat(3perl)

NOMBRE

bigrat - Soporte transparente para números racionales grandes en Perl

SINOPSIS

use bigrat;
print 2 + 4.5;                      # Math::BigRat 13/2
print 1/3 + 1/4;                    # Math::BigRat 7/12
print inf + 42;                     # Math::BigRat inf
print NaN * 7;                      # Math::BigRat NaN
print hex("0x1234567890123490");    # Perl v5.10.0 o posterior
{
    no bigrat;
    print 1/3;                      # 0.33333...
}
# para Perls más antiguos, importar en el paquete actual:
use bigrat qw/hex oct/;
print hex("0x1234567890123490");
print oct("01234567890123490");

DESCRIPCIÓN

Todos los literales numéricos en el ámbito dado se convierten en objetos Math::BigRat.

Todos los operadores (incluidas las operaciones matemáticas básicas) excepto el operador de rango ".." están sobrecargados.

Así, lo siguiente:

use bigrat;
$x = 1234;

crea un Math::BigRat y almacena una referencia a él en $x. Esto sucede de forma transparente y a tus espaldas, por así decirlo.

Puedes ver esto con lo siguiente:

perl -Mbigrat -le 'print ref(1234)'

Dado que los números son en realidad objetos, puedes llamar a todos los métodos habituales de Math::BigRat sobre ellos. Esto incluso funciona hasta cierto punto en expresiones:

perl -Mbigrat -le '$x = 1234; print $x->bdec()'
perl -Mbigrat -le 'print 1234->copy()->binc();'
perl -Mbigrat -le 'print 1234->copy()->binc->badd(6);'
perl -Mbigrat -le 'print +(1234)->copy()->binc()'

(Ten en cuenta que print no hace lo que esperas si la expresión comienza con '(' por lo tanto el "+")

Incluso puedes encadenar las operaciones juntas como de costumbre:

perl -Mbigrat -le 'print 1234->copy()->binc->badd(6);'
1241

Ten en cuenta que lo siguiente no funciona como se esperaba (no imprime nada), ya que la sobrecarga de '..' aún no es posible en Perl (a partir de v5.8.0):

perl -Mbigrat -le 'for (1..2) { print ref($_); }'

Opciones

"bigrat" reconoce algunas opciones que se pueden pasar al cargarlo mediante "use". Las siguientes opciones existen:

a o accuracy (precisión)
Esto establece la precisión para todas las operaciones matemáticas. El argumento debe ser mayor o igual a cero. Consulte el método bround() de Math::BigInt para obtener detalles. 
perl -Mbigrat=a,50 -le 'print sqrt(20)'

Tenga en cuenta que no es posible establecer la precisión y la exactitud al mismo tiempo.

p o precision (precisión)
Esto establece la precisión para todas las operaciones matemáticas. El argumento puede ser cualquier entero. Los valores negativos significan un número fijo de dígitos después del punto, mientras que un valor positivo redondea al dígito a la izquierda del punto. 0 significa redondear al entero. Consulte el método bfround() de Math::BigInt para obtener detalles. 
perl -Mbigrat=p,-50 -le 'print sqrt(20)'

Tenga en cuenta que no es posible establecer la precisión y la exactitud al mismo tiempo.

t o trace (rastrear)
Esto habilita un modo de rastreo y es principalmente para depuración.
l, lib, try, o only
Carga una biblioteca matemática diferente, vea "Biblioteca Matemática". 
perl -Mbigrat=l,GMP -e 'print 2 ** 512'
perl -Mbigrat=lib,GMP -e 'print 2 ** 512'
perl -Mbigrat=try,GMP -e 'print 2 ** 512'
perl -Mbigrat=only,GMP -e 'print 2 ** 512'
hex
Reemplaza el método incorporado hex() con una versión que puede manejar números grandes. Lo reemplaza exportándolo al paquete actual. En Perl v5.10.0 y superior, esto no es tan necesario, ya que hex() se reemplaza léxicamente en el ámbito actual cada vez que la pragmática "bigrat" está activa.
oct
Reemplaza el método incorporado oct() con una versión que puede manejar números grandes. Lo reemplaza exportándolo al paquete actual. En Perl v5.10.0 y superior, esto no es tan necesario, ya que oct() se reemplaza léxicamente en el ámbito actual cada vez que la pragmática "bigrat" está activa.
v o version (versión)
esto imprime el nombre y la versión de los módulos y luego sale. 
perl -Mbigrat=v

Biblioteca Matemática

Las operaciones matemáticas con los números las realiza (por defecto) un módulo de biblioteca de backend llamado Math::BigInt::Calc. El valor por defecto es equivalente a decir:

use bigrat lib => 'Calc';

Puedes cambiar esto usando:

use bigrat lib => 'GMP';

Lo siguiente primero intentaría encontrar Math::BigInt::Foo, luego Math::BigInt::Bar, y si esto también falla, volvería a Math::BigInt::Calc:

use bigrat lib => 'Foo,Math::BigInt::Bar';

Usar c<lib> advierte si no se pueden encontrar ninguna de las bibliotecas especificadas y Math::BigInt recurre a una de las bibliotecas por defecto. Para suprimir esta advertencia, use c<try> en su lugar:

use bigrat try => 'GMP';

Si desea que el código falle en lugar de recurrir, use "only" en su lugar:

use bigrat only => 'GMP';

Consulte la documentación respectiva del módulo para obtener más detalles.

Llamadas a métodos

Dado que todos los números son ahora objetos, puede usar todos los métodos que forman parte de la API de Math::BigRat.

Pero una advertencia es necesaria. Al usar lo siguiente para hacer una copia de un número, solo se hará una copia superficial.

$x = 9; $y = $x;
$x = $y = 7;

Usar la copia o el original con matemáticas sobrecargadas está bien, por ejemplo, lo siguiente funciona:

$x = 9; $y = $x;
print $x + 1, " ", $y,"\n";     # imprime 10 9

pero llamar a cualquier método que modifique el número directamente resultará en que tanto el original como la copia se destruyan:

$x = 9; $y = $x;
print $x->badd(1), " ", $y,"\n";        # imprime 10 10
$x = 9; $y = $x;
print $x->binc(1), " ", $y,"\n";        # imprime 10 10
$x = 9; $y = $x;
print $x->bmul(2), " ", $y,"\n";        # imprime 18 18

Usar métodos que no modifican, sino que prueban que el contenido funciona:

$x = 9; $y = $x;
$z = 9 if $x->is_zero();                # funciona bien

Consulte la documentación sobre el constructor de copias y "=" en overload, así como la documentación en Math::BigFloat para obtener más detalles.

Métodos

inf()
Un atajo para devolver Math::BigRat->binf(). Útil porque Perl no siempre maneja la palabra desnuda "inf" correctamente.
NaN()
Un atajo para devolver Math::BigRat->bnan(). Útil porque Perl no siempre maneja la palabra desnuda "NaN" correctamente.
e
# perl -Mbigrat=e -wle 'print e'

Devuelve el número de Euler "e", también conocido como exp(1).

PI
# perl -Mbigrat=PI -wle 'print PI'

Devuelve PI.

bexp()
bexp($power, $accuracy);

Devuelve el número de Euler "e" elevado a la potencia apropiada, con la precisión deseada.

Ejemplo:

# perl -Mbigrat=bexp -wle 'print bexp(1,80)'
bpi()
bpi($accuracy);

Devuelve PI con la precisión deseada.

Ejemplo:

# perl -Mbigrat=bpi -wle 'print bpi(80)'
accuracy()
Establece u obtiene la precisión.
precision()
Establece u obtiene la precisión.
round_mode()
Establecer u obtener el modo de redondeo.
div_scale()
Establecer u obtener la escala de división.
in_effect()
use bigrat;
print "in effect\n" if bigrat::in_effect;       # true
{
    no bigrat;
    print "in effect\n" if bigrat::in_effect;   # false
}

Devuelve true o false si "bigrat" está activo en el ámbito actual.

Este método solo funciona en Perl v5.9.4 o posterior.

ADVERTENCIAS

Literales de punto flotante hexadecimal, octal y binario
Perl (y este módulo) acepta literales de punto flotante hexadecimal, octal y binario, pero úselos con cuidado con versiones de Perl anteriores a la v5.32.0, porque algunas versiones de Perl dan silenciosamente un resultado incorrecto.
Sobrecarga de operadores vs literales
"bigrat" funciona sobrecargando el manejo de literales enteros y de punto flotante, convirtiéndolos en objetos Math::BigRat.

Esto significa que la aritmética que involucra solo valores de cadena o literales de cadena se realiza usando los operadores incorporados de Perl.

Por ejemplo:

use bigrat;
my $x = "900000000000000009";
my $y = "900000000000000007";
print $x - $y;

produce 0 en compilaciones de 32 bits predeterminadas, ya que "bigrat" nunca ve los literales de cadena. Para asegurarse de que la expresión se trate completamente como "Math::BigRat" objetos, use un literal numérico en la expresión:

print +(0+$x) - $y;
Rangos
Perl no permite la sobrecarga de rangos, por lo que no puede usar de forma segura rangos con "bigrat" como límites, ni la variable del iterador es un "Math::BigRat". 
use 5.010;
for my $i (12..13) {
  for my $j (20..21) {
    say $i ** $j;  # produces a floating-point number,
                   # not an object
  }
}
in_effect()
Este método solo funciona en Perl v5.9.4 o posterior.
hex()/oct()
"bigrat" sobrescribe estas rutinas con versiones que también pueden manejar valores enteros grandes. Sin embargo, en Perl anteriores a la versión v5.9.4, esto no sucederá a menos que lo solicite específicamente con las dos etiquetas de importación "hex" y "oct" - y entonces será global y no se puede desactivar dentro de un ámbito con "no bigrat": 
use bigrat qw/hex oct/;
print hex("0x1234567890123456");
{
    no bigrat;
    print hex("0x1234567890123456");
}

La segunda llamada a hex() advertirá sobre una constante no portable.

Compare esto con:

use bigrat;
# will warn only under Perl older than v5.9.4
print hex("0x1234567890123456");

EJEMPLOS

perl -Mbigrat -le 'print sqrt(33)'
perl -Mbigrat -le 'print 2**255'
perl -Mbigrat -le 'print 4.5+2**255'
perl -Mbigrat -le 'print 3/7 + 5/7 + 8/3'
perl -Mbigrat -le 'print 12->is_odd()';
perl -Mbigrat=l,GMP -le 'print 7 ** 7777'
