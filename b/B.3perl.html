DESCRIPCIÓ

N

El módulo "B" proporciona clases que permiten a un programa Perl indagar en sus propias entrañas. Es el módulo utilizado para implementar los "backends" del compilador de Perl. El uso del compilador no requiere conocimiento de este módulo: consulte el módulo O para la parte visible por el usuario. El módulo "B" es útil para aquellos que desean escribir nuevos backends del compilador. Esta documentación asume que el lector sabe una cantidad

considerable sobre el interior de perl, incluyendo cosas como SVs, OPs
y la tabla de símbolos interna y el árbol de sintaxis de un programa.

VISIÓN

GENERAL

El módulo "B" contiene un conjunto de funciones de utilidad para consultar el estado actual del intérprete de Perl; típicamente estas funciones devuelven objetos de

las clases B::SV y B::OP, o sus clases derivadas. Estas clases a su vez definen
métodos para consultar a los objetos resultantes sobre su propio estado interno.
