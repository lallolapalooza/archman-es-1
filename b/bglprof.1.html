NOMBRE

bglprof - muestra datos de perfil del grafo de llamadas para programas Bigloo

SINOPSIS

bglprof [ opciones ] [ archivo-objeto [ gmon.out ] ]

DESCRIPCIÓN

bglprof es un front-end para el programa gprof. Cualquier opción que se aplique a gprof es adecuada para bglprof. bglprof lee un archivo de monitorización adicional, el archivo bmon.out. Este archivo se genera al ejecutar un programa que ha sido enlazado por Bigloo utilizando la opción -p. Ver el manual de glprof para una documentación detallada.

OPCIONES

-v
modo verboso.

EJEMPLO

Aquí está la secuencia de comandos para obtener un perfil de Bigloo:

$ bigloo foo.scm -p -unsafe -O4 -c

$ bigloo foo.o -p -unsafe -O4 -c -o a.out

$ ./a.out

$ bglprof

VER TAMBIÉN

bigloo(1), prof(1), gprof(1)
