BIO_printf(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_PRINTF(3ssl) OpenSSL BIO_PRINTF(3ssl)

NOMBRE

BIO_printf, BIO_vprintf, BIO_snprintf, BIO_vsnprintf - salida formateada a un BIO

SINOPSIS

#include <openssl/bio.h>
int BIO_printf(BIO *bio, const char *format, ...);
int BIO_vprintf(BIO *bio, const char *format, va_list args);
int BIO_snprintf(char *buf, size_t n, const char *format, ...);
int BIO_vsnprintf(char *buf, size_t n, const char *format, va_list args);

DESCRIPCIÓN

BIO_printf() es similar a la función estándar de C printf(), excepto que la salida se envía al BIO especificado, bio, en lugar de a la salida estándar. Se admiten todos los especificadores de formato comunes.

BIO_vprintf() es similar a la función vprintf() que se encuentra en muchas plataformas, la salida se envía al BIO especificado, bio, en lugar de a la salida estándar. Se admiten todos los especificadores de formato comunes. La lista de argumentos args es una lista de argumentos stdarg.

BIO_snprintf() es para plataformas que no tienen la función común snprintf(). Es como sprintf() excepto que el parámetro de tamaño, n, especifica el tamaño del búfer de salida.

BIO_vsnprintf() es a BIO_snprintf() lo que BIO_vprintf() es a BIO_printf().

VALORES DE RETORNO

Todas las funciones devuelven el número de bytes escritos, o -1 en caso de error. Para BIO_snprintf() y BIO_vsnprintf() esto incluye cuando el búfer de salida es demasiado pequeño.

NOTAS

Excepto cuando n es 0, tanto BIO_snprintf() como BIO_vsnprintf() siempre terminan su salida con '\0'. Esto incluye casos en los que se devuelve -1, como cuando no hay espacio suficiente para generar toda la cadena.
