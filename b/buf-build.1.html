NOMBRE

buf-build - Compila archivos Protobuf en una imagen Buf

SINOPSIS

buf build [flags]

DESCRIPCIÓN

El primer argumento es la fuente o el módulo a compilar o la imagen a convertir, que debe ser uno de los formatos [binpb,dir,git,json,mod,protofile,tar,txtpb,yaml,zip]. Esto se establece por defecto en "." si no se especifica ningún argumento.

OPCIONES

--as-file-descriptor-set[=false] Generar como un google.protobuf.FileDescriptorSet en lugar de una imagen. Tenga en cuenta que las imágenes son compatibles en el cableado con FileDescriptorSets, pero esta bandera elimina los metadatos adicionales agregados para el uso de Buf.

--config="" El archivo buf.yaml o los datos a utilizar para la configuración.

--disable-symlinks[=false] No seguir enlaces simbólicos al leer fuentes o configuración del sistema de archivos local. Por defecto, se siguen los enlaces simbólicos en esta CLI, pero nunca se siguen en el Buf Schema Registry.

--error-format="text" El formato para los errores de compilación impresos en stderr. Debe ser uno de [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-imports[=false] Excluir importaciones.

--exclude-path=[] Excluir archivos o directorios específicos, por ejemplo, "proto/a/a.proto", "proto/a". Si se especifica varias veces, se toma la unión.

--exclude-source-info[=false] Excluir información de fuente.

--exclude-source-retention-options[=false] Excluir opciones cuya retención sea de fuente.

-h, --help[=false] Ayuda para la compilación.

-o, --output="/dev/null" La ubicación de salida para la imagen compilada. Debe ser uno de los formatos [binpb,json,txtpb,yaml]

--path=[] Limitar a archivos o directorios específicos, por ejemplo, "proto/a/a.proto", "proto/a". Si se especifica varias veces, se toma la unión.

--type=[] Los tipos (paquete, mensaje, enumeración, extensión, servicio, método) que deben incluirse en esta imagen. Cuando se especifican, la imagen resultante solo incluirá descriptores para describir los tipos solicitados.

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar registro de depuración.

--log-format="color" El formato de registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera.
