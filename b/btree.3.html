cachesize
Un
tamaño máximo sugerido (en bytes) de la caché de memoria. Este valor es solo orientativo, y el método de acceso asignará más memoria en lugar de fallar. Dado que cada búsqueda examina la página raíz del árbol, almacenar en caché las páginas usadas recientemente mejora sustancialmente el tiempo de acceso. Además, las escrituras físicas se retrasan el mayor tiempo posible, de modo que una caché moderada puede reducir significativamente el número de operaciones de E/S. Obviamente, usar una caché aumenta (pero solo aumenta) la probabilidad de corrupción o pérdida de datos si el sistema se bloquea mientras se modifica un árbol. Si cachesize es 0 (no se especifica tamaño), se usa una caché predeterminada.

La misma función de comparación debe usarse en un árbol determinado cada vez que se abre. prefix
Prefix es la función de comparación de prefijos. Si se especifica, esta rutina debe devolver el número de bytes del segundo argumento de clave que son necesarios para determinar que es mayor que el primer argumento de clave. Si las claves son iguales, se debe devolver la longitud de la clave. Tenga en cuenta que la utilidad de esta rutina depende mucho de los datos, pero, en algunos conjuntos de datos puede producir tamaños de árbol y tiempos de búsqueda significativamente reducidos. Si prefix es NULL (no se especifica función de prefijo), y no se especifica función de comparación, se usa una rutina de comparación léxica predeterminada.
