NOMBRE

brltty - controlador de pantalla braille actualizable para Linux/Unix

SINOPSIS

brltty [opción ...]

DESCRIPCIÓN

brltty es un proceso en segundo plano (demonio) que proporciona acceso a la pantalla de la consola (cuando está en modo texto) para una persona ciega que utiliza una pantalla braille actualizable. Controla la pantalla braille y proporciona una funcionalidad completa de revisión de pantalla. También se ha incorporado cierta capacidad de voz.

Opciones de línea de comandos

Las opciones se procesan secuencialmente de izquierda a derecha. Si se especifica una opción más de una vez, o en caso de conflicto, la especificación más a la derecha tiene prioridad.

Las siguientes opciones son compatibles:

-a tabla (--attributes-table=)
La ruta a la tabla de atributos. Las rutas relativas se anclan en /usr/share/brltty/Attributes. La extensión .atb es opcional. El valor predeterminado integrado es left_right.atb.
-b driver,...|auto (--braille-driver=)
El controlador para la pantalla braille (ver Especificación del controlador). El valor predeterminado integrado es auto.
-c tabla (--contraction-table=)
La ruta a la tabla de contracciones. Las rutas relativas se anclan en /usr/share/brltty/Contraction. La extensión .ctb es opcional.
-d dispositivo,... (--braille-device=)
El dispositivo al que está conectada la pantalla braille. El valor predeterminado integrado es usb:,bluetooth:.

La forma general de una especificación de dispositivo braille es calificador:datos. Para compatibilidad con versiones anteriores, si se omite el calificador, se asume serial:. Los siguientes tipos de dispositivos son compatibles:

Bluetooth
Para un dispositivo bluetooth, especifique bluetooth:dirección. La dirección debe ser seis números hexadecimales de dos dígitos separados por dos puntos, por ejemplo, 01:23:45:67:89:AB.
Serial
Para un dispositivo serie, especifique serial:dispositivo. El calificador serial: es opcional (para compatibilidad con versiones anteriores). Si se proporciona una ruta relativa, se ancla en /dev/ (la ubicación habitual donde se definen los dispositivos en un sistema similar a Unix). Las siguientes especificaciones de dispositivo se refieren al dispositivo serie principal en Linux: serial:ttyS0, serial:/dev/ttyS0, ttyS0, /dev/ttyS0.
USB
Para un dispositivo USB, especifique usb:. brltty buscará el primer dispositivo USB que coincida con el controlador de pantalla braille que se está utilizando. Si esto es inadecuado, por ejemplo, si tiene más de una pantalla braille USB que requiere el mismo controlador, puede refinar la especificación del dispositivo añadiéndole el número de serie de la pantalla, por ejemplo, usb:12345. N.B.: La función de "identificación por número de serie" no funciona para algunos modelos porque algunos fabricantes no establecen el descriptor de número de serie USB o lo establecen pero no de forma única.

Se puede especificar una lista de dispositivos braille separados por comas. Si se hace esto, se realiza la autodetección en cada dispositivo listado en secuencia. Esta función es particularmente útil si tiene una pantalla braille con más de una interfaz, por ejemplo, un puerto serie y un puerto USB.

Options

-c table (--contraction-table=)
The path to the contraction table. Relative paths are anchored at /usr/share/brltty/Contractor. The .ctb extension is optional. The built-in default is en-Short.ctb (the English short form contraction table).
-d [driver:][device] (--braille-device=)
The device to which the braille display is connected. A driver identification code may be specified in order to select the appropriate driver. If no driver is specified then the driver which is selected by default is used. The built-in default is auto.
-e (--enable-braille)
Enable braille output. This is the default.
-f file (--configuration-file=)
The path to the configuration file. Relative paths are anchored at /etc/brltty. The built-in default is /etc/brltty/brltty.conf.
-g (--enable-speech)
Enable speech output. This is the default.
-h (--help)
Print a command line usage summary and then exit.
-i (--interactive)
Run brltty in interactive mode. This is the default.
-m device (--midi-device=)
The device to use for the Musical Instrument Digital Interface. The built-in default is /dev/midi.
-n (--no-braille)
Disable braille output.
-o (--no-speech)
Disable speech output.
-p device (--pcm-device=)
The device to use for digital audio. The built-in default is /dev/dsp.
-q (--quiet)
Suppress the printing of start-up messages. This option is ignored if -v (--verify) or -V (--version) is also specified.
-r (--release-device)
Release the device to which the braille display is connected when the current screen or window can't be read.
-s driver,...|auto (--speech-driver=)
The driver for the speech synthesizer (see Driver Specification). The built-in default is auto.
-t table (--text-table=)
The path to the text table. Relative paths are anchored at /usr/share/brltty/Text. The .ttb extension is optional. The built-in default is en-nabcc.ttb (the North American Braille Computer Code).
-v (--verify)
Print the start-up messages and then exit. This always includes the versions of brltty itself, the server side of its application programming interface, and each of the selected braille and speech drivers. If the -q (--quiet) option isn't also specified then it also includes the values of the options after all sources have been considered. If more than one braille driver and/or more than one braille device has been specified then braille display autodetection is performed. If more than one speech driver has been specified then speech synthesizer autodetection is performed.
-x driver (--screen-driver=)
The screen driver. The built-in default is operating system appropriate.
-A name=value,... (--api-parameters=)
Parameters for the application programming interface. If the same parameter is specified more than once then the rightmost specification is used. Parameter names may be abbreviated.
-B [driver:]name=value,... (--braille-parameters=)
Parameters for the braille display driver. If the same parameter is specified more than once then the rightmost specification is used. Parameter names may be abbreviated. If a parameter assignment is qualified with a driver identification code then it's only processed if that braille display driver is being used.
-D directory (--drivers-directory=)
The path to the directory which contains the dynamically loadable driver objects. The built-in default is /usr/lib/brltty.
-E (--environment-variables)
Recognize environment variables.
-F file (--preferences-file=)
The path to the preferences file. Relative paths are anchored at /var/lib/brltty. The built-in default is brltty.prefs.
-H (--full-help)
Print a command line usage summary (all options), and then exit.
-I (--install-service)
(Windows only) Install brltty as the BrlAPI service so that it will be automatically started when the system is booted, and so that applications can know that a BrlAPI server is running.
-K arg (--keyboard-properties=)
Properties of the keyboard.
-L file (--log-file=)
The file to which log messages are written. Relative paths are anchored at the current working directory. The default is to send log messages to the system log.
-M csecs (--message-delay=)
The message hold time in hundredths of a second. The built-in default is 400 (4 seconds).
-N (--no-api)
Don't start the application programming interface.
-P file (--pid-file=)
The full path to the process identifier file. If this option is supplied, brltty writes its process identifier (pid) into the specified file at start-up. The file is removed when brltty terminates.
-R (--remove-service)
(Windows only) Remove the BrlAPI service so that brltty will not be automatically started when the system is booted, and so that applications can know that no BrlAPI server is running.
-S [driver:]name=value,... (--speech-parameters=)
Parameters for the speech synthesizer driver. If the same parameter is specified more than once then the rightmost specification is used. Parameter names may be abbreviated. If a parameter assignment is qualified with a driver identification code then it's only processed if that speech synthesizer driver is being used.
-T directory (--tables-directory=)
The path to the directory which contains the text, contraction, attributes, keyboard, and input tables. The built-in default is /usr/share/brltty.
-U directory (--updatable-directory=)
The path to a directory which contains files that can be updated. The built-in default is /var/lib/brltty.
-V (--version)
Print the versions of brltty itself, the server side of its application programming interface, and those drivers which were configured in at build-time, and then exit. If the -q (--quiet) option isn't also specified then also print copyright information.
-W directory (--writable-directory=)
The path to a directory which can be written to. The built-in default is /run/brltty.
-X name=value,... (--screen-parameters=)
Parameters for the screen driver. If the same parameter is specified more than once then the rightmost specification is used. Parameter names may be abbreviated.
-Y text (--start-message=)
The text to be shown when the braille driver starts and to be spoken when the speech driver starts. The built-in default is BRLTTY 6.8.
-Z text (--stop-message=)
The text to be shown when the braille driver stops. The built-in default is BRLTTY stopped.

El Archivo de Configuración

Las líneas en blanco se ignoran. Si el carácter # aparece en cualquier línea, entonces todos los caracteres desde él hasta el final de esa línea se tratan como un comentario.

Se admiten las siguientes directivas de configuración:

api-parameters name=value,...
Parámetros para la interfaz de programación de aplicaciones. Consulte la -A (--api-parameters=) opción para más detalles.
attributes-table table
La tabla de atributos. Consulte la -a (--attributes-table=) opción para más detalles.
braille-device device,...
El dispositivo al que está conectada la pantalla braille. Consulte la -d (--braille-device=) opción para más detalles.
braille-driver driver,...|auto
El driver para la pantalla braille. Consulte la -b (--braille-driver=) opción para más detalles.
braille-parameters [driver:]name=value,...
Parámetros para el driver de la pantalla braille. Consulte la -B (--braille-parameters=) opción para más detalles.
contraction-table table
La tabla de abreviaturas. Consulte la -c (--contraction-table=) opción para más detalles.
midi-device device
El dispositivo a usar para el Musical Instrument Digital Interface. Consulte la -m (--midi-device=) opción para más detalles.
pcm-device device
El dispositivo a usar para audio digital. Consulte la -p (--pcm-device=) opción para más detalles.
preferences-file file
El archivo de preferencias. Consulte la -F (--preferences-file=) opción para más detalles.
release-device on|off
Liberar el dispositivo al que está conectada la pantalla braille cuando la pantalla o ventana actual no se pueda leer. Consulte la -r (--release-device) opción para más detalles.
screen-driver driver
El driver de pantalla. Consulte la -x (--screen-driver=) opción para más detalles.
screen-parameters name=value,...
Parámetros para el driver de pantalla. Consulte la -X (--screen-parameters=) opción para más detalles.
speech-driver driver,...|auto
El driver para el sintetizador de voz. Consulte la -s (--speech-driver=) opción para más detalles.
speech-input 0me
El objeto del sistema de archivos que da a otras aplicaciones acceso al brltty's driver de voz para la conversión de texto a voz. Consulte la -i (--speech-input=) opción para más detalles.
speech-parameters [driver:]name=value,...
Parámetros para el driver del sintetizador de voz. Consulte la -S (--speech-parameters=) opción para más detalles.
text-table table
La tabla de texto. Consulte la -t (--text-table=) opción para más detalles.
