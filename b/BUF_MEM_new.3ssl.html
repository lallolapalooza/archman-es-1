BUF_MEM_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BUF_MEM_NEW(3ssl) OpenSSL BUF_MEM_NEW(3ssl)

NOMBRE

BUF_MEM_new, BUF_MEM_new_ex, BUF_MEM_free, BUF_MEM_grow, BUF_MEM_grow_clean, BUF_reverse - estructura simple de arreglo de caracteres

SINOPSIS

#include <openssl/buffer.h>
BUF_MEM *BUF_MEM_new(void);
BUF_MEM *BUF_MEM_new_ex(unsigned long flags);
void BUF_MEM_free(BUF_MEM *a);
int BUF_MEM_grow(BUF_MEM *str, int len);
size_t BUF_MEM_grow_clean(BUF_MEM *str, size_t len);
void BUF_reverse(unsigned char *out, const unsigned char *in, size_t size);

DESCRIPCIÓN

La biblioteca de búfer maneja arreglos de caracteres simples. Los búferes se utilizan para diversos propósitos en la biblioteca, en particular los BIOs de memoria.

BUF_MEM_new() asigna un nuevo búfer de tamaño cero.

BUF_MEM_new_ex() asigna un búfer con las banderas especificadas. La bandera BUF_MEM_FLAG_SECURE especifica que el puntero data debe asignarse en el heap seguro; consulte CRYPTO_secure_malloc(3).

BUF_MEM_free() libera un búfer ya existente. Los datos se ponen a cero antes de liberarse en caso de que el búfer contenga datos sensibles. Si el argumento es NULL, no se hace nada.

BUF_MEM_grow() cambia el tamaño de un búfer ya existente a len. Cualquier dato que ya esté en el búfer se conserva si aumenta de tamaño.

BUF_MEM_grow_clean() es similar a BUF_MEM_grow() pero establece a cero cualquier memoria liberada o asignada adicionalmente.

BUF_reverse() invierte size bytes en in a out. Si in es NULL, el arreglo se invierte en el lugar.

VALORES DE RETORNO

BUF_MEM_new() devuelve el búfer o NULL en caso de error.

BUF_MEM_free() no tiene valor de retorno.

BUF_MEM_grow() y BUF_MEM_grow_clean() devuelven cero en caso de error o el nuevo tamaño (es decir, len).

VER TAMBIÉN

bio(7), CRYPTO_secure_malloc(3).

HISTORIA

La función BUF_MEM_new_ex() se añadió en OpenSSL 1.1.0.
