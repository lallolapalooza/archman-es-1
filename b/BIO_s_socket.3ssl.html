BIO_s_socket(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_S_SOCKET(3ssl) OpenSSL BIO_S_SOCKET(3ssl)

NOMBRE

BIO_s_socket, BIO_new_socket - BIO de socket

SINOPSIS

#include <openssl/bio.h>
const BIO_METHOD *BIO_s_socket(void);
BIO *BIO_new_socket(int sock, int close_flag);

DESCRIPCIÓN

BIO_s_socket() devuelve el método BIO de socket. Esto es un envoltorio para las rutinas de socket de la plataforma.

BIO_read_ex() y BIO_write_ex() leen o escriben en el socket subyacente. BIO_puts() es compatible, pero BIO_gets() no lo es.

Si la bandera de cierre se establece, el socket se cierra y se desconecta cuando se libera el BIO.

BIO_new_socket() devuelve un BIO de socket utilizando sock y close_flag.

NOTAS

Los BIOs de socket también admiten cualquier funcionalidad relevante de los BIOs de descriptores de archivo.

El motivo de tener BIOs de descriptores de archivo y BIOs de socket separados es que en algunas plataformas los sockets no son descriptores de archivo y utilizan rutinas de E/S distintas, Windows es una de esas plataformas. Cualquier código que mezcle ambos no funcionará en todas las plataformas.

VALORES DE RETORNO

BIO_s_socket() devuelve el método BIO de socket.

BIO_new_socket() devuelve el BIO recién asignado o NULL si se produjo un error.
