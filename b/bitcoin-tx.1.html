BITCOIN-TX(1) Comandos de usuario BITCOIN-TX(1)

NOMBRE

bitcoin-tx - página del manual para bitcoin-tx v28.1.0

SINOPSIS

bitcoin-tx [opciones] <tx-hex> [comandos] Actualiza una transacción de bitcoin codificada en hexadecimal
bitcoin-tx [opciones] -create [comandos] Crea una transacción de bitcoin codificada en hexadecimal

DESCRIPCIÓN

Utilidad bitcoin-tx de Bitcoin Core versión v28.1.0

OPCIONES

-?

Imprime este mensaje de ayuda y sale

-create

Crea una TX nueva y vacía.

-json

Selecciona salida JSON

-txid

Imprime solo el ID de transacción codificado en hexadecimal de la transacción resultante.

-version

Imprime la versión y sale

Opciones de depuración/pruebas:

Opciones de selección de cadena:

-chain=<cadena>

Usa la cadena <cadena> (predeterminado: main). Valores permitidos: main, test, testnet4, signet, regtest

-signet

Usa la cadena signet. Equivalente a -chain=signet. Ten en cuenta que la red se define mediante el parámetro -signetchallenge.

-signetchallenge

Los bloques deben satisfacer el script dado para ser considerados válidos (solo para redes signet; predeterminado: el desafío global de la red de prueba signet)

-signetseednode

Especifica un nodo semilla para la red signet, en formato hostname[:port], por ejemplo, sig.net:1234 (se puede usar varias veces para especificar varios nodos semilla; predeterminado: el(los) nodo(s) semilla de la red de prueba signet global)

-testnet

Usa la cadena testnet3. Equivalente a -chain=test. El soporte para testnet3 está obsoleto y se eliminará en una próxima versión. Considera migrar a testnet4 ahora usando -testnet4.

-testnet4

Usa la cadena testnet4. Equivalente a -chain=testnet4.

Comandos:

delin=N
Elimina la entrada N de TX
delout=N
Elimina la salida N de TX
in=TXID:VOUT(:SECUENCIA_NUMERO)
Añade entrada a TX
locktime=N
Establece el locktime de TX a N
nversion=N
Establece la versión de TX a N
outaddr=VALOR:DIRECCION
Añade una salida basada en dirección a TX
outdata=[VALOR:]DATOS
Añade una salida basada en datos a TX
outmultisig=VALOR:REQUERIDO:CLAVES_PUB:CLAVE_PUB1:CLAVE_PUB2:....[:FLAGS]
Añade una salida Multi-sig n-de-m a TX. n = REQUERIDO, m = CLAVES_PUB. Opcionalmente añade el flag "W" para producir una salida pay-to-witness-script-hash. Opcionalmente añade el flag "S" para envolver la salida en una pay-to-script-hash.
outpubkey=VALOR:CLAVE_PUB[:FLAGS]
Añade una salida pay-to-pubkey a TX. Opcionalmente añade el flag "W" para producir una salida pay-to-witness-pubkey-hash. Opcionalmente añade el flag "S" para envolver la salida en una pay-to-script-hash.
outscript=VALOR:SCRIPT[:FLAGS]
Añade una salida de script raw a TX. Opcionalmente añade el flag "W" para producir una salida pay-to-witness-script-hash. Opcionalmente añade el flag "S" para envolver la salida en una pay-to-script-hash.
replaceable(=N)
Establece el número de secuencia de la entrada N para la opción de reemplazo por tarifa (RBF). Si N no se proporciona, el comando intenta habilitar todas las entradas disponibles para RBF. Si la transacción no tiene entradas, esta opción se ignora.
sign=BANDERA_SIGHASH
Añade cero o más firmas a la transacción. Este comando requiere registros JSON: prevtxs=objeto JSON, privatekeys=objeto JSON. Consulta la documentación de signrawtransactionwithkey para ver el formato de las banderas sighash y los objetos JSON.

Comandos de registro:

load=NOMBRE:NOMBRE_ARCHIVO
Carga el archivo JSON NOMBRE_ARCHIVO en el registro NOMBRE
set=NOMBRE:CADENA_JSON
Establece el registro NOMBRE a la CADENA_JSON dada
