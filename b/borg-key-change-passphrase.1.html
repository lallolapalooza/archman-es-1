BORG-KEY-CHANGE-PASSPHRASE(1) Herramienta de backup de borg BORG-KEY-CHANGE-PASSPHRASE(1)

NOMBRE

borg-key-change-passphrase - Cambiar la frase de contraseña de la clave del repositorio

SINOPSIS

borg [opciones comunes] key change-passphrase [opciones] [REPOSITORIO]

DESCRIPCIÓN

Los archivos de clave utilizados para el cifrado del repositorio están opcionalmente protegidos por frase de contraseña. Este comando se puede utilizar para cambiar esta frase de contraseña.

Tenga en cuenta que este comando solo cambia la frase de contraseña, pero no ningún secreto protegido por ella (por ejemplo, claves de cifrado/MAC o la semilla del chunker). Por lo tanto, cambiar la frase de contraseña después de que la frase de contraseña y la clave de Borg se vieran comprometidas no protege las copias de seguridad futuras (ni pasadas) del mismo repositorio.

OPCIONES

Vea borg-common(1) para las opciones comunes de los comandos de Borg.

argumentos

REPOSITORIO

EJEMPLOS

# Crear un repositorio protegido por archivo de clave
$ borg init --encryption=keyfile -v /ruta/al/repo
Inicializando repositorio en "/ruta/al/repo"
Introduce la nueva frase de contraseña:
Introduce la misma frase de contraseña de nuevo:
Recuerda tu frase de contraseña. No podrás acceder a tus datos sin ella.
Clave en "/root/.config/borg/keys/mnt_backup" creada.
Mantén esta clave segura. No podrás acceder a tus datos sin ella.
Sincronizando caché de fragmentos...
Archivos: 0, con Idx en caché: 0, con Idx obsoletos: 0, sin Idx en caché: 0.
Hecho.
# Cambiar la frase de contraseña del archivo de clave
$ borg key change-passphrase -v /ruta/al/repo
Introduce la frase de contraseña para la clave /root/.config/borg/keys/mnt_backup:
Introduce la nueva frase de contraseña:
Introduce la misma frase de contraseña de nuevo:
Recuerda tu frase de contraseña. No podrás acceder a tus datos sin ella.
Clave actualizada
# Importar una clave previamente exportada en el archivo de clave especificado
# (creando o sobrescribiendo la clave de salida)
# (solo repositorios de archivos de clave)
$ BORG_KEY_FILE=/ruta/al/archivo-salida-clave borg key import /ruta/al/repo /ruta/al/exportado

Completamente automatizado usando variables de entorno:

$ BORG_NEW_PASSPHRASE=vieja borg init -e=repokey repo
# ahora "vieja" es la frase de contraseña actual.
$ BORG_PASSPHRASE=vieja BORG_NEW_PASSPHRASE=nueva borg key change-passphrase repo
# ahora "nueva" es la frase de contraseña actual.
