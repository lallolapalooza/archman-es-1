BUNDLE-CONSOLE(1) Manual de Comandos Generales BUNDLE-CONSOLE(1)

NOMBRE

bundle-console - Abrir una sesión de IRB con el bundle pre-cargado

SINOPSIS

bundle console [GRUPO]

DESCRIPCIÓN

Inicia una sesión de consola interactiva de Ruby en el contexto del bundle actual.

Si no se especifica GRUPO, se cargan todas las gemas del grupo default en el Gemfile(5) https://bundler.io/man/gemfile.5.html.

Si se especifica GRUPO, se cargan todas las gemas del grupo dado en el Gemfile además de las gemas del grupo default. Incluso si el grupo dado no existe en el Gemfile, la consola IRB se inicia sin ninguna advertencia ni error.

La variable de entorno BUNDLE_CONSOLE o bundle config set console puede ser usada para cambiar el shell entre los siguientes:

  • irb (por defecto)
  • pry (https://github.com/pry/pry)
  • ripl (https://github.com/cldwalker/ripl)

bundle console usa irb por defecto. Se puede usar Pry o Ripl alternativamente con bundle console ajustando la configuración de Bundler console. Asegúrese también de que pry o ripl estén en su Gemfile.

EJEMPLO

$ bundle config set console pry
$ bundle console
Resolving dependencies...
[1] pry(main)>
