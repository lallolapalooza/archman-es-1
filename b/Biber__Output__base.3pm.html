Biber::Output::base(3pm) Documentación de Perl aportada por el usuario Biber::Output::base(3pm)

NOMBRE

Biber::Output::base - clase base para módulos de salida de Biber.

new

Inicializa un objeto Biber::Output::base

set_output_target_file

Establece el archivo de destino de salida de un objeto Biber::Output::base
Un atajo para set_output_target para que podamos seguir la pista del
nombre del archivo. Devuelve un objeto IO::File para el destino

get_output_target_file

Obtiene el nombre del archivo de destino de salida

set_output_target

Establece el destino de salida de un objeto Biber::Output::base

set_output_head

Establece el encabezado de salida de un objeto Biber::Output::base
$data puede ser cualquier cosa - se espera que el llamador lo sepa.

set_output_tail

Establece el pie de página de salida de un objeto Biber::Output::base
$data puede ser cualquier cosa - se espera que el llamador lo sepa.

get_output_head

Obtiene el encabezado de salida de un objeto Biber::Output
$data puede ser cualquier cosa - se espera que el llamador lo sepa.
Se utiliza principalmente en depuración

get_output_tail

Obtiene el pie de página de salida de un objeto Biber::Output
$data puede ser cualquier cosa - se espera que el llamador lo sepa.
Se utiliza principalmente en depuración

add_output_head

Añade datos al encabezado de salida de un objeto Biber::Output::base
El método de la clase base simplemente hace una concatenación de cadenas

add_output_tail

Añade datos al pie de página de salida de un objeto Biber::Output::base
El método de la clase base simplemente hace una concatenación de cadenas

set_output_section

Registra el objeto de sección en el objeto de salida
Necesitamos información de esto al escribir la salida

get_output_section

Recupera el objeto de sección de salida

get_output_entries

Obtiene los datos de salida ordenados para todas las entradas en una lista como referencia de array
Se utiliza principalmente en pruebas, ya que instancia la información dinámica de la lista para que podamos verla en las pruebas. Como resultado, tenemos que usar NFC() en el resultado para imitar la salida real, ya que la salida UTF-8 se asume en la mayoría de las pruebas.

get_output_macros

Obtiene las macros de salida para pruebas en modo herramienta

get_output_comments

Obtiene los comentarios de salida para pruebas en modo herramienta

clear_output_macros

Borra las macros de salida

clear_output_comments

Borra los comentarios de salida

get_output_entry

Obtiene los datos de salida para una entrada específica.
Se utiliza principalmente en pruebas, ya que instancia la información dinámica de la lista para que podamos verla en las pruebas. Como resultado, tenemos que usar NFC() en el resultado para imitar la salida real, ya que la salida UTF-8 se asume en la mayoría de las pruebas.

set_output_entry

Añade la salida de una entrada a un objeto Biber::Output::base
El método de la clase base simplemente vuelca los datos

create_output_misc

Crea la salida para fragmentos varios como preámbulo y llamada a macro de cierre, y la añade al objeto de salida.

create_output_section

Crea la salida a partir de los datos de las secciones y la introduce en el
objeto de salida.

set_output_keyalias

Establece la salida para una clave que es un alias de otra clave

set_output_undefkey

Establece la salida para una clave indefinida

output

Método de salida base genérico
