NOMBRE

Bundle::DBI - Un paquete para instalar DBI y módulos requeridos.

SINOPSIS

perl -MCPAN -e 'install Bundle::DBI'

CONTENIDOS

DBI - para conocerse a sí mismo

DBI::Shell 11.91 - el shell de línea de comandos de DBI

Storable 2.06 - para DBD::Proxy, DBI::ProxyServer, DBD::Forward

Net::Daemon 0.37 - para DBD::Proxy y DBI::ProxyServer

RPC::PlServer 0.2016 - para DBD::Proxy y DBI::ProxyServer

DBD::Multiplex 1.19 - trata múltiples manejadores de bases de datos como uno solo

DESCRIPCIÓN

Este paquete incluye todos los módulos utilizados por el módulo Perl Database Interface (DBI), creado por Tim Bunce.

Un Paquete es un módulo que simplemente define una colección de otros módulos. Es utilizado por el módulo CPAN para automatizar la obtención, construcción e instalación de módulos de los sitios de archivo ftp de CPAN.

Este paquete no se ocupa de los diversos controladores de bases de datos (por ejemplo, DBD::Informix, DBD::Oracle, etc.), muchos de los cuales requieren software de fuentes distintas de CPAN. Deberá obtener y construir esos controladores usted mismo.
