NOMBRE

batdiff - Compara un archivo con el índice git actual, o muestra la diferencia entre dos archivos.

DESCRIPCIÓN

Este script permite usar `delta` como un resaltador alternativo para las diferencias.

USO


batdiff [OPCIONES] ARCHIVO
batdiff [OPCIONES] ARCHIVO OTRO_ARCHIVO
batdiff --staged

ENTORNO

Variable Descripción
BATDIFF_USE_DELTA=true Si está instalado `delta`, úsalo por defecto.

OPCIONES

Corta Larga Descripción
-C --context=[LÍNEAS] El número de líneas a mostrar antes y después de las líneas diferentes.
--delta Muestra las diferencias usando `delta`.
--color Fuerza la salida en color.
--no-color Fuerza la desactivación de la salida en color.
--paging=["never"/"always"] Habilita/deshabilita la paginación.
--pager=[PAGER] Especifica el paginador a usar.
--terminal-width=[COLS] Genera salida para el ancho de terminal especificado.
--staged Muestra los cambios preparados (staged).

ADVERTENCIAS

Al usar `bat` como impresora:

- El resaltado de sintaxis en diferencias entre dos archivos no es compatible.
- El resaltado de sintaxis en una diferencia de un solo archivo requiere `bat` >= 0.15.

Al usar `delta` como impresora:

- La opción `--no-color` no elimina toda la salida en color.
