BUDGIE-SESSION-INH(1) Comandos de usuario BUDGIE-SESSION-INH(1)

NOMBRE

budgie-session-inhibit - inhibir la funcionalidad de budgie-session

SINOPSIS

budgie-session-inhibit [OPCIÓN...] [COMANDO]

DESCRIPCIÓN

budgie-session-inhibit puede inhibir ciertas funcionalidades de budgie-session mientras ejecuta el COMANDO dado. Para lograr esto, llama al método Inhibit() de la API D-Bus de budgie-session y crea un inhibidor. El inhibidor se elimina automáticamente cuando budgie-session-inhibit sale.

Un caso de uso típico es evitar que la sesión se quede inactiva (y por lo tanto bloquee la pantalla) mientras se está ejecutando un reproductor de películas.

OPCIONES

-h, --help

imprimir ayuda y salir

--version

imprimir información de versión y salir

--app-id ID

El ID de la aplicación a usar al llamar al método Inhibit() de budgie-session. Si esta opción no se especifica, se usa "unknown".

--reason RAZÓN

Una razón legible por humanos para pasar al llamar al método Inhibit() de budgie-session. Si esta opción no se especifica, se usa "not specified".

--inhibit ARG

ARG especifica las cosas a inhibir, como una lista separada por dos puntos. Los valores posibles son logout, switch-user, suspend, idle, automount. Si esta opción se usa más de una vez, los valores se combinan. Si esta opción no se especifica, se asume "idle".

--inhibit-only

No lanzar COMANDO y esperar para siempre en su lugar

-l, --list

listar las inhibiciones existentes y salir
