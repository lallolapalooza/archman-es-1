NOMBRE

bt_input - funciones de entrada/análisis en la biblioteca btparse

SINOPSIS

void  bt_set_stringopts (bt_metatype_t metatype, btshort options);
AST * bt_parse_entry_s (char *    entry_text,
                        char *    filename,
                        int       line,
                        btshort    options,
                        boolean * status);
AST * bt_parse_entry   (FILE *    infile,
                        char *    filename,
                        btshort    options,
                        boolean * status);
AST * bt_parse_file    (char *    filename, 
                        btshort    options, 
                        boolean * overall_status);

DESCRIPCIÓN

Las funciones descritas aquí se utilizan para leer y analizar datos BibTeX, convirtiéndolos de texto sin procesar a árboles de sintaxis abstracta (AST).

bt_set_stringopts ()
void bt_set_stringopts (bt_metatype_t metatype, btshort options);

Establece las opciones de procesamiento de cadenas para un metatipo de entrada particular. Esto afecta el postprocesamiento de la entrada realizado por bt_parse_entry_s(), bt_parse_entry()y bt_parse_file(). Si bt_set_stringopts() nunca se llama, los cuatro metatipos tienen por defecto los siguientes conjuntos de opciones de cadena:

BTE_REGULAR    BTO_CONVERT | BTO_EXPAND | BTO_PASTE | BTO_COLLAPSE
BTE_COMMENT    0
BTE_PREAMBLE   0
BTE_MACRODEF   BTO_CONVERT | BTO_EXPAND | BTO_PASTE

Por ejemplo,

bt_set_stringopts (BTE_COMMENT, BTO_COLLAPSE);

hará que la biblioteca colapse los espacios en blanco en el valor de todas las entradas de comentario; el AST devuelto por una de las funciones "bt_parse_*" reflejará este cambio.

bt_parse_entry ()
AST * bt_parse_entry (FILE *    infile,
                      char *    filename,
                      btshort    options,
                      boolean * status);

Escanea y analiza la siguiente entrada BibTeX en "infile". Debería proporcionar "filename" para ayudar a btparse a generar mensajes de error precisos; la biblioteca lleva un seguimiento interno del número de línea actual de "infile", por lo que no necesita pasarlo. "options" debe ser un mapa de bits de opciones que no son de procesamiento de cadenas (actualmente, "BTO_NOSTORE" para deshabilitar el almacenamiento de expansiones de macro es la única opción de este tipo). *status se establecerá en "TRUE" si la entrada se analizó correctamente o con solo advertencias menores, y en "FALSE" si hubo errores léxicos o sintácticos graves. Si "status" es "NULL", el estado del análisis no estará disponible. Tanto las advertencias menores como los errores graves se reportan en "stderr".

Devuelve un puntero al árbol de sintaxis abstracta (AST) que describe la entrada recién analizada, o "NULL" si no se encontraron más entradas en "infile" (esto dejará "infile" en fin de archivo). No intente anticiparse a bt_parse_entry() detectando el fin de archivo usted mismo; se le debe permitir determinarlo por sí mismo para poder limpiar algunos datos estáticos que se conservan entre llamadas en el mismo archivo.

bt_parse_entry() tiene dos restricciones importantes que debe conocer. Primero, debería dejar que btparse maneje toda la entrada en el archivo; esto es por razones tanto superficiales (para que la biblioteca sepa el número de línea actual para generar mensajes de error precisos) como fundamentales (se le debe permitir a la biblioteca detectar el fin de archivo para limpiar ciertas variables estáticas y permitirle analizar otro archivo). Segundo, no puede intercalar el análisis de dos archivos diferentes; intentar hacerlo resultará en un error fatal que hará que su programa se bloquee. Esto es un resultado directo del estado estático mantenido entre llamadas de bt_parse_entry().

Debido a los dos "fallos" distintos posibles para bt_parse_entry() (fin de archivo, que es esperado pero significa detener el procesamiento del archivo actual; y error en la entrada, que no es esperado pero le permite continuar procesando el mismo archivo), generalmente debería llamarlo así:

while (entry = bt_parse_entry (file, filename, options, &ok))
{
   if (ok)
   {
      /* ... procesar entrada ... */
   }
}

Al final de este bucle, "feof (file)" será verdadero.

bt_parse_entry_s ()
AST * bt_parse_entry_s (char *    entry_text,
                        char *    filename,
                        int       line,
                        btshort    options,
                        boolean * status)

Escanea y analiza una única entrada BibTeX completa contenida en una cadena, "entry_text". Si leyó esta cadena de un archivo, debería ayudar a btparse a generar mensajes de error precisos proporcionando el nombre del archivo como "filename" y el número de línea del comienzo de la entrada como "line"; de lo contrario, establezca "filename" en "NULL" y "line" en 1. "options" y "status" son los mismos que para bt_parse_entry().

Devuelve un puntero al árbol de sintaxis abstracta (AST) que describe la entrada recién analizada, y "NULL" si no se encontraron entradas en "entry_text" o si "entry_text" era "NULL".

Debería llamar a bt_parse_entry_s() una vez más que el número total de entradas que desea analizar; en la llamada final, establezca "entry_text" en "NULL" para que la función sepa que no hay más texto para analizar. Esta llamada final le permite limpiar algunas estructuras asignadas en la primera llamada. Así, bt_parse_entry_s() generalmente se usa así:

char *  entry_text;
btshort  options = 0;
boolean ok;
AST *   entry_ast;
while (entry_text = get_more_text ())
{
   entry_ast = bt_parse_entry_s (entry_text, NULL, 1, options, &ok);
   if (ok)
   {
      /* ... procesar entrada ... */
   }
}
bt_parse_entry_s (NULL, NULL, 1, options, NULL);    /* limpiar */

asumiendo que get_more_text() devuelve un puntero al texto de una entrada para analizar, o "NULL" si no hay más texto disponible.

bt_parse_file ()
AST * bt_parse_file (char *    filename, 
                     btshort    options, 
                     boolean * status)

Escanea y analiza un archivo BibTeX completo. Si "filename" es "NULL" o "-", entonces se leerá "stdin" ; de lo contrario, intenta abrir el archivo nombrado. Si este intento falla, imprime un mensaje de error en "stderr" y devuelve "NULL". "options" y "status" son los mismos que para bt_parse_entry()---note que *status será "FALSE" si hubo algún error en todo el archivo; para una granularidad más fina en la verificación de errores, debería usar bt_parse_entry().

Devuelve un puntero a una lista enlazada de AST que representan las entradas en el archivo, o &quot;NULL" si no se encontraron entradas en el archivo. Esta lista se puede recorrer con bt_next_entry(), y las entradas individuales se recorren luego como de costumbre (véase bt_traversal).

VÉASE TAMBIÉN

btparse, bt_postprocess, bt_traversal
