buf-config-ls-modules - Listar módulos configurados

SINOPSIS

buf config ls-modules [flags]

DESCRIPCIÓN

Listar módulos configurados

OPCIONES

--config="" El archivo buf.yaml o datos a usar para la configuración.

--format="path" El formato para imprimir las reglas. Debe ser uno de [path,name,json]

-h, --help[=false] Ayuda para ls-modules

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar registro de depuración

--log-format="color" El formato de registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
