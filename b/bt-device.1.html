NOMBRE

bt-device - un gestor de dispositivos Bluetooth

SINOPSIS

bt-device [OPCIÓN...]

Opciones de ayuda:
-h, --help

Opciones de aplicación:
-a, --adapter=<nombre|mac>
-l, --list
-c, --connect=<mac>
-d, --disconnect=<nombre|mac>
-r, --remove=<nombre|mac>
-i, --info=<nombre|mac>
-s, --services <nombre|mac> [<patrón>]
--set <nombre|mac> <propiedad> <valor>
-v, --verbose

DESCRIPCIÓN

Esta utilidad se utiliza para gestionar dispositivos Bluetooth. Puede listar dispositivos añadidos, conectarse a un nuevo dispositivo, desconectar un dispositivo, eliminar un dispositivo añadido, mostrar información sobre un dispositivo, descubrir servicios de dispositivos remotos o cambiar propiedades de dispositivos.

OPCIONES

-h, --help
Muestra la ayuda

-a, --adapter <nombre|mac>
Especifica el adaptador a usar por su nombre o dirección MAC
(si no se define esta opción, se usa el adaptador predeterminado)

-l, --list
Lista los dispositivos añadidos

-c, --connect <mac>
Se conecta al dispositivo remoto por su MAC, recupera todos los registros
SDP y luego inicia el emparejamiento

-d, --disconnect <nombre|mac>
Desconecta un dispositivo remoto específico terminando la
conexión ACL de bajo nivel.

-r, --remove
Elimina el dispositivo (y también la información de emparejamiento)

-i, --info
Muestra información sobre el dispositivo (devuelve todas las propiedades)

-s, --services <nombre|mac> [<patrón>]
Inicia la búsqueda de servicios para recuperar registros de servicios remotos,
el parámetro `patrón` se puede usar para especificar UUIDs específicos

--set <propiedad> <valor>
Cambia las propiedades del dispositivo (ver la sección PROPIEDADES DEL DISPOSITIVO para una lista
de propiedades disponibles)

-v, --verbose
Muestra detalladamente los registros de servicios remotos (afecta al modo
de descubrimiento de servicios)

PROPIEDADES DEL DISPOSITIVO

string Address [ro]
La dirección Bluetooth del dispositivo (MAC) del dispositivo remoto.

string Name [ro]
El nombre del dispositivo remoto Bluetooth.

string Icon [ro]
Nombre de icono propuesto según la especificación de nombres de iconos
de freedesktop.org.

uint32 Class [ro]
La clase de dispositivo Bluetooth del dispositivo remoto.

list UUIDs [ro]
Lista de UUIDs de 128 bits que representan los servicios
remotos disponibles.

boolean Paired [ro]
Indica si el dispositivo remoto está emparejado.

boolean Connected [ro]
Indica si el dispositivo remoto está actualmente conectado.

boolean Trusted [rw]
Indica si el dispositivo remoto se considera de confianza.

boolean Blocked [rw]
Si se establece en true, se rechazarán inmediatamente las conexiones entrantes
del dispositivo.

string Alias [rw]
El alias de nombre para el dispositivo remoto. El alias se puede
utilizar para tener un nombre amigable diferente para el
dispositivo remoto.

En caso de que no se establezca ningún alias, devolverá el nombre
del dispositivo remoto. Establecer una cadena vacía como alias
lo convertirá de nuevo al nombre del dispositivo remoto.

boolean LegacyPairing [ro]
Establecido en true si el dispositivo solo admite el mecanismo de
emparejamiento anterior a 2.1.
