BIO_find_type(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_FIND_TYPE(3ssl) OpenSSL BIO_FIND_TYPE(3ssl)

NOMBRE

BIO_find_type, BIO_next, BIO_method_type - Traversión de cadenas BIO

SINOPSIS

#include <openssl/bio.h>
BIO *BIO_find_type(BIO *b, int bio_type);
BIO *BIO_next(BIO *b);
int BIO_method_type(const BIO *b);

DESCRIPCIÓN

BIO_find_type() busca un BIO de un tipo dado en una cadena, comenzando en el BIO b. Si type es un tipo específico (como BIO_TYPE_MEM) entonces se realiza una búsqueda de un BIO de ese tipo. Si type es un tipo general (como BIO_TYPE_SOURCE_SINK) entonces se busca el siguiente BIO coincidente del tipo general dado. BIO_find_type() devuelve el siguiente BIO coincidente o NULL si no se encuentra ninguno. Si type es BIO_TYPE_NONE no encontrará una coincidencia.

Los siguientes tipos generales están definidos: BIO_TYPE_DESCRIPTOR, BIO_TYPE_FILTER, y BIO_TYPE_SOURCE_SINK.

Para obtener una lista de los tipos específicos, consulte el archivo de cabecera <openssl/bio.h>.

BIO_next() devuelve el siguiente BIO en una cadena. Se puede usar para recorrer todos los BIOs en una cadena o para usarse junto con BIO_find_type() para encontrar todos los BIOs de un tipo determinado.

BIO_method_type() devuelve el tipo de un BIO.

VALORES DE RETORNO

BIO_find_type() devuelve un BIO coincidente o NULL si no hay coincidencia.

BIO_next() devuelve el siguiente BIO en una cadena.

BIO_method_type() devuelve el tipo del BIO b.

EJEMPLOS

Recorrer una cadena buscando BIOs de resumen:

BIO *btmp;
btmp = in_bio; /* in_bio es la cadena a buscar */
do {
    btmp = BIO_find_type(btmp, BIO_TYPE_MD);
    if (btmp == NULL)
        break; /* No encontrado */
    /* btmp es un BIO de resumen, haz algo con él... */
    ...
    btmp = BIO_next(btmp);
} while (btmp);
