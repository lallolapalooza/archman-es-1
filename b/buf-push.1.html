NOMBRE

buf-push - Empujar a un registro

SINOPSIS

buf push [flags]

DESCRIPCIÓN

El primer argumento es la fuente a empujar, que debe ser uno de los formatos [dir,git,protofile,tar,zip]. Por defecto es "." si no se especifica ningún argumento.

OPCIONES

--create[=false] Crear el módulo si no existe. Por defecto crea un módulo privado si no se establece --create-visibility.

--create-default-label="" La configuración de la etiqueta predeterminada del módulo, si se crea. Si no se establece, el módulo se creará con la etiqueta predeterminada "main".

--create-visibility="private" La configuración de visibilidad del módulo, si se crea. Solo se puede establecer con --create. Debe ser uno de [public,private]

--disable-symlinks[=false] No seguir enlaces simbólicos al leer fuentes o configuración del sistema de archivos local. Por defecto, se siguen los enlaces simbólicos en esta CLI, pero nunca se siguen en el Buf Schema Registry.

--error-format="text" El formato de los errores de compilación impresos en stderr. Debe ser uno de [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-unnamed[=false] Solo empujar módulos con nombre al BSR. Los módulos con nombre no deben tener dependencias sin nombre.

--git-metadata[=false] Utiliza el estado del control de fuentes Git para establecer los valores de los indicadores. Si este indicador está establecido, utilizaremos los siguientes valores para sus indicadores:

--source-control-url a <URL del remoto de git>/<nombre del repositorio>/<ruta>/<sha del commit extraído> (por ejemplo, https://github.com/acme/weather/commit/ffac537e6cbbf934b08745a378932722df287a53).
--label para cada etiqueta y rama de Git que apunte al commit extraído actualmente. Puede establecer etiquetas adicionales usando --label con este indicador.
--create-default-label a la rama predeterminada de Git (por ejemplo, main) - esto solo estará en vigor si también se establece --create.

La URL del control de fuentes y la rama predeterminada se basan en el remoto de Git requerido "origin". Este indicador solo es compatible con extracciones de repositorios de fuentes de Git. Si establece usted mismo los indicadores --source-control-url y/o --create-default-label, se utilizarán los valores en su lugar y la información no se derivará del estado del control de fuentes de Git.

-h, --help[=false] ayuda para push

--label=[] Asociar la etiqueta con los módulos empujados. Se puede usar varias veces.

--source-control-url="" La URL para ver el código fuente de los módulos empujados (por ejemplo, el commit específico en el control de fuentes).

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo a 0 significa sin tiempo de espera
