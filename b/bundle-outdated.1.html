NOMBRE

bundle-outdated - Lista los gems instalados con versiones más recientes disponibles

SINOPSIS

bundle outdated [GEM] [--local] [--pre] [--source] [--filter-strict | --strict] [--update-strict] [--parseable | --porcelain] [--group=GRUPO] [--groups] [--patch|--minor|--major] [--filter-major] [--filter-minor] [--filter-patch] [--only-explicit]

DESCRIPCIÓN

Outdated lista los nombres y versiones de los gems para los que hay una versión más reciente disponible en la fuente dada. Llamar a outdated con [GEM [GEM]] solo buscará versiones más recientes de los gems dados. Los gems pre-release se ignoran por defecto. Si tus gems están actualizados, Bundler saldrá con un estado de 0. De lo contrario, saldrá con 1.

OPCIONES

--local
No intentes obtener gems remotamente y usa la caché de gems en su lugar.
--pre
Comprueba si hay gems pre-release más recientes.
--source=<lista>
Comprueba contra una fuente específica.
--filter-strict, --strict
Solo lista versiones más recientes permitidas por los requisitos de tu Gemfile, respetando también las banderas de actualización conservadora (--patch, --minor, --major).
--update-strict
Resolución conservadora estricta, no permite que ningún gem se actualice más allá del último --patch | --minor | --major.
--parseable, --porcelain
Usa formato mínimo para una salida más analizable.
--group=GRUPO
Lista gems de un grupo específico.
--groups
Lista gems organizados por grupos.
--minor
Prefiere actualizar solo a la siguiente versión menor.
--major
Prefiere actualizar a la siguiente versión mayor (por defecto).
--patch
Prefiere actualizar solo a la siguiente versión de parche.
--filter-major
Solo lista versiones mayores más recientes.
--filter-minor
Solo lista versiones menores más recientes.
--filter-patch
Solo lista versiones de parche más recientes.
--only-explicit
Solo lista los gems especificados en tu Gemfile, no sus dependencias.

OPCIONES DE NIVEL DE PARCHE

Ver bundle update(1) bundle-update.1.html para detalles.

FILTRADO DE SALIDA

Las 3 opciones de filtrado no afectan la resolución de versiones, solo qué versiones se muestran en la salida.

Si la salida regular muestra lo siguiente:

* Gem       Current  Latest  Requested  Groups
* faker     1.6.5    1.6.6   ~> 1.4     development, test
* hashie    1.2.0    3.4.6   = 1.2.0    default
* headless  2.2.3    2.3.1   = 2.2.3    test

--filter-major solo mostraría:

* Gem       Current  Latest  Requested  Groups
* hashie    1.2.0    3.4.6   = 1.2.0    default

--filter-minor solo mostraría:

* Gem       Current  Latest  Requested  Groups
* headless  2.2.3    2.3.1   = 2.2.3    test

--filter-patch solo mostraría:

* Gem       Current  Latest  Requested  Groups
* faker     1.6.5    1.6.6   ~> 1.4     development, test

Las opciones de filtro se pueden combinar. --filter-minor y --filter-patch mostrarían:

* Gem       Current  Latest  Requested  Groups
* faker     1.6.5    1.6.6   ~> 1.4     development, test

Combinar las tres opciones de filter sería lo mismo que no proporcionar ninguna de ellas.
