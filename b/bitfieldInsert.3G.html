NOMBRE

bitfieldInsert - inserta un rango de bits en un entero

DECLARACIÓN

genIType bitfieldInsert(genIType base, genIType insert, int offset, int bits);

genUType bitfieldInsert(genUType base, genUType insert, int offset, int bits);

PARÁMETROS

base

Especifica el entero en el que insertar insert.

insert

Especifica el valor de los bits a insertar.

offset

Especifica el índice del primer bit a insertar.

bits

Especifica el número de bits a insertar.

DESCRIPCIÓN

bitfieldInsert inserta los bits menos significativos de insert en base en el desplazamiento offset. El valor devuelto tendrá los bits [offset, offset + bits + 1] tomados de [0, bits - 1] de insert y todos los demás bits tomados directamente de los bits correspondientes de base. Si bits es cero, el resultado será simplemente el valor original de base. El resultado será indefinido si offset o bits son negativos, o si la suma de offset y bits es mayor que el número de bits utilizados para almacenar el operando.
