DESCRIPCIÓ

N

bat imprime el contenido resaltado por sintaxis de una colección de ARCHIVOs en la terminal. Si no se especifica ningún ARCHIVO, o cuando el ARCHIVO es '-', lee de la entrada

estándar.

bat admite un gran número de lenguajes de programación y de marcado. También se comunica con git(1) para mostrar modificaciones con respecto al índice de git. bat canaliza automáticamente su salida a través de un paginador (por defecto: less)

.

Siempre que la salida de bat va a una terminal no interactiva, es decir, cuando la salida se

canaliza a otro proceso o a un archivo, actuará como un reemplazo directo de cat(1) y volverá
a imprimir el contenido del archivo sin formato, a menos que se solicite un estilo explícito.

--pager <co

mando>
Determina qué paginador se usa. Esta opción anulará las variables de entorno PAGER y BAT_PAGER. El paginador por defecto es 'less'. Si proporcionas '--pager=builtin', usa el paginador integrado 'minus'. Para controlar cuándo se usa el paginador, consulta la opción '--paging'. Ejemplo: '--pager "less -RF"'.

Nota: Por defecto, si el paginador está configurado como 'less' (y no se especifican opciones de línea de comandos), 'bat' pasará las siguientes opciones de línea de comandos al paginador: '-R'/'--RAW-CONTROL-CHARS', '-F'/'--quit-if-one-screen' y '-X'/'--no-init'. La última opción ('

-X') solo se usa para versiones de 'less' anteriores a la 530. La opción '-R' es necesaria para interpretar correctamente los colores ANSI. La segunda opción ('-F') le indica a less que salga inmediatamente si el tamaño de la salida es menor que el tamaño vertical de la terminal. Est
o es conveniente para archivos pequeños porque no tienes que presionar 'q' para salir del paginador. La tercera opción ('-X') es necesaria para corregir un error con la función '--quit-if-one-screen' en versiones antiguas de 'less'. Desafortunadamente, también rompe el soporte de la r
ueda del ratón en 'less'. Si quieres habilitar el desplazamiento con la rueda del ratón en versiones antiguas de 'less', puedes pasar solo '-R' (como en el ejemplo anterior, esto desactivará la función quit-if-one-screen). Para less 530 o más reciente, debería funcionar directamente.

bat admite archivos de lenguaje de Sublime Text .sublime-syntax, y se puede personalizar para añadir lenguajes adicionales a tu instalación local. Para hacerlo, añade los archivos de lenguaje .sublime-syntax a `$(bat --config-dir)/syntaxes` y ejecuta `bat cache --

build`.

Ejemplo

cd "$(bat --config-dir)/syntaxes"

git clone https://github.com/tellnobody1/sublime-purescript-synta

Una vez construida la caché, el nuevo lenguaje será visible en `bat --list-languages`.
Si alguna vez quieres eliminar los lenguajes personalizados, puedes limpiar la caché con `bat cache
