BN_CTX_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_CTX_NEW(3ssl) OpenSSL BN_CTX_NEW(3ssl)

NOMBRE

BN_CTX_new_ex, BN_CTX_new, BN_CTX_secure_new_ex, BN_CTX_secure_new, BN_CTX_free - asignar y liberar estructuras BN_CTX

SINOPSIS

#include <openssl/bn.h>
BN_CTX *BN_CTX_new_ex(OSSL_LIB_CTX *ctx);
BN_CTX *BN_CTX_new(void);
BN_CTX *BN_CTX_secure_new_ex(OSSL_LIB_CTX *ctx);
BN_CTX *BN_CTX_secure_new(void);
void BN_CTX_free(BN_CTX *c);

DESCRIPCIÓN

Un BN_CTX es una estructura que contiene variables temporales BIGNUM utilizadas por las funciones de la biblioteca. Dado que la asignación de memoria dinámica para crear BIGNUM es bastante costosa cuando se usa junto con llamadas repetidas a subrutinas, se utiliza la estructura BN_CTX.

BN_CTX_new_ex() asigna e inicializa una estructura BN_CTX para el contexto de biblioteca dado ctx. El valor <ctx> puede ser NULL, en cuyo caso se utilizará el contexto de biblioteca predeterminado. BN_CTX_new() es lo mismo que BN_CTX_new_ex() excepto que siempre se utiliza el contexto de biblioteca predeterminado.

BN_CTX_secure_new_ex() asigna e inicializa una estructura BN_CTX, pero utiliza el montón seguro (ver CRYPTO_secure_malloc(3)) para almacenar los BIGNUM para el contexto de biblioteca dado ctx. El valor <ctx> puede ser NULL, en cuyo caso se utilizará el contexto de biblioteca predeterminado. BN_CTX_secure_new() es lo mismo que BN_CTX_secure_new_ex() excepto que siempre se utiliza el contexto de biblioteca predeterminado.

BN_CTX_free() libera los componentes del BN_CTX y la propia estructura. Dado que se requiere BN_CTX_start() para obtener BIGNUMs del BN_CTX, en la mayoría de los casos se debe llamar a BN_CTX_end() antes de que el BN_CTX pueda ser liberado por BN_CTX_free(). Si c es NULL, no se hace nada.

Un BN_CTX dado solo debe ser utilizado por un único hilo de ejecución. No se realiza ningún bloqueo y el asignador interno de pool no manejará correctamente múltiples hilos de ejecución.

VALORES DEVUELTOS

BN_CTX_new() y BN_CTX_secure_new() devuelven un puntero al BN_CTX. Si falla la asignación, devuelven NULL y establecen un código de error que puede obtenerse mediante ERR_get_error(3).

BN_CTX_free() no tiene valores de retorno.

FUNCIONALIDAD ELIMINADA

void BN_CTX_init(BN_CTX *c);

BN_CTX_init() ya no está disponible a partir de OpenSSL 1.1.0. Las aplicaciones deben reemplazar el uso de BN_CTX_init con BN_CTX_new en su lugar:

BN_CTX *ctx;
ctx = BN_CTX_new();
if (!ctx)
    /* error */
...
BN_CTX_free(ctx);

VER TAMBIÉN

ERR_get_error(3), BN_add(3), BN_CTX_start(3)

HISTORIAL

BN_CTX_init() fue eliminado en OpenSSL 1.1.0.
