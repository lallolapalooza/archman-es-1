BGLDEPEND(1) Manual de Comandos Generales BGLDEPEND(1)

NOMBRE

bgldepend - crea dependencias de Bigloo en makefiles

SINOPSIS

bgldepend [ opciones ] archivo_fuente ...

DESCRIPCIÓN

El programa bgldepend lee cada archivo_fuente en secuencia y lo analiza para encontrar las directivas de módulo include e import de módulo. bgldepend calcula el cierre transitivo de la relación de importación. Es decir, basta con proporcionar a bgldepend un único archivo Bigloo que importe todos los archivos del proyecto (por ejemplo, el archivo "main").

Cada archivo que un archivo_fuente incluye, directa o indirectamente, es lo que bgldepend llama una dependencia. Estas dependencias se escriben luego en un makefile de tal manera que make(1) sabrá qué archivos objeto deben ser recompilados cuando una dependencia haya cambiado.

Por defecto, bgldepend escribe su salida en el dispositivo de salida estándar. Si bgldepend recibe la opción -o makefile, actualizará el archivo makefile. Es decir, buscará en el makefile la línea:


# bgldepend start (no editar)

y


# bgldepend stop

Las dependencias se escribirán entre estas dos líneas.

OPCIONES

archivo
Es un archivo que implementa un módulo. bglafile lee ese archivo para descubrir el nombre del módulo implementado.
-ruta-busqueda <ruta>
Añade ruta a la lista de directorios leídos para buscar archivos fuente de Bigloo.
-excluir-ruta <ruta>
Excluye ruta de la lista de directorios leídos para buscar archivos fuente de Bigloo.
-sufijo <suf>
Añade suf a la lista de sufijos de archivos fuente de bmake. Los sufijos por defecto son "scm", "sch" y "bgl".
-v
Modo detallado
-o <makefile>
El nombre del archivo makefile a actualizar

EJEMPLO

Normalmente, bgldepend se utilizará en un objetivo de makefile para que al escribir ``make bgldepend'' se actualicen las dependencias del makefile. Por ejemplo,


MAIN=foo.scm


SRCS = $(MAIN) bar.scm gee.scm


bgldepend:


bgldepend -o Makefile $(MAIN)
