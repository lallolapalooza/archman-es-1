bsetbg - utilidad para manipular la apariencia de la ventana raíz del

escritorio de X11.

bsetbg está destinado a proporcionar un método estándar para

que el

gestor de ventanas Blackbox altere el fondo de la ventana raíz (aunque también funcionará con cualquier otro gestor de ventanas). bsetbg actúa como un envoltorio tanto para bsetroot como para una variedad flexible de aplicaciones de terceros que utiliza al manejar archivos de imágenes. OPCI

argumento-de-reserva ( -full,-tile, o -center como se describió anteriormente), bsetbg asumirá que el último argumento es un nombre de archivo. En el caso de que programa termine con un código distinto de cero o no esté disponible en el sistema de destino, bsetbg intentará manejar el archivo con el argumento de reserva. Consult

bsetbg también aceptará todos los argumentos

bsetbg leerá sus valores de configuración del

archivo

~/.bsetbgrc si existe. De lo contrario, escaneará la ruta del sistema en busca de una lista predefinida de aplicaciones de imágenes para usar (actualmente esta lista consta de qiv, xli, xv, wmsetbg, Esetroot, display y xsetbg). ~/.bsetbgrc debe contener las siguientes variables: CENTER

=
"cadena"Aplicación y argumentos a usar para centrar una imagen en la ventana raíz
cuando se especifica el argumento
-center. FULL
=
"cadena"Aplicación y argumentos a usar para estirar una imagen para llenar la ventana raíz
cuando se especifica el argumento
-full. TILE
=
"cadena"Aplicación y argumentos a usar para colocar en mosaico una imagen en la ventana raíz
cuando se especifica el argumento
-tile. DEFAULT
=
"cadena"Acción a realizar de forma predeterminada si no se ha especificado
ninguna de las anteriores.
Las siguientes variables son
opcionales:
NO_EXEC
=
"booleano"Si esta variable está establecida, bsetbg nunca modificará
la ventana raíz.
POST_COMMAND
=
"cadena"Esta variable especifica un
comando que
bsetbg ejecutará después de cada modificación exitosa de la ventana raíz. LOG_LAST_CMD
=
"booleano"Si esta variable está
establecida,
bsetbg mantendrá un archivo de registro de los últimos dos comandos exitosos. LOGFILE

"cadena"Esta variable puede especificar el archivo de registro a usar cuando $LOG_LAST_CMD está definido. El
valor predeterminado es ~/.bsetbg_last_cmd .
Como se mencionó
anteriormente,
bsetbg funcionará perfectamente para la mayoría de los usuarios sin tener un archivo de configuración. Los usuarios avanzados que deseen más control sobre el comportamiento de bsetbg deben ejecutar bsetbg -g y usar la salida para crear un ~/.bsetbgrc que luego puede ser ajustado
manualmente.
