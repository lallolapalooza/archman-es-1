BLITZ(1) Manual de Comandos Generales BLITZ(1)

NOMBRE

blitz — Transfiere archivos de forma segura entre dos estaciones de trabajo a través de NAT/Firewall.

SINOPSIS

blitz [-lT] [-s secreto] [-k archivo_clave] [-f lista] [-o RSOPT=] [archivos ...]

DESCRIPCIÓN

La utilidad blitz es un script envoltorio para gs-netcat y rsync. Permite enviar archivos desde una estación de trabajo a otra a través de la Red Global de Relevo de Sockets (GSRN).

Un caso de uso típico es cuando ambas estaciones de trabajo están separadas por un Firewall o NAT y no pueden establecer una conexión directa entre sí.

OPCIONES

-l
Modo servidor. El modo por defecto es cliente.
-s secreto
Una contraseña elegida por el usuario. Ambos usuarios deben usar la misma contraseña para conectarse.
-k ARCHIVO
Un archivo que contiene la contraseña.
-f ARCHIVO
Leer la lista de nombres de archivo de ARCHIVO. Si ARCHIVO es -, la lista se leerá de la entrada estándar.
-o RSOPT=
Opciones pasadas a rsync. Ver rsync(1) para opciones disponibles.
-T
Usar TOR. La herramienta blitz se conectará a través de TOR a la GSRN. Esto requiere que TOR esté instalado y en ejecución. La IP y el PUERTO del servidor TOR se pueden establecer mediante variables de entorno.

Ver gs-netcat(1) para más opciones.

EJEMPLOS

Escuchar a clientes con la contraseña 'MiSecreto':

$ mkdir /tmp/foo && cd /tmp/foo
$ blitz -s MiSecreto -l

Copiar 'archivo.dat' a /tmp/foo/archivo.dat en el servidor:

$ blitz -s MiSecreto archivo.dat

Copiar '/etc/ssh/ssh*config' a /tmp/foo/etc/ssh/ en el servidor:

$ blitz -s MiSecreto /etc/ssh/ssh*config

También es posible limitar la cantidad de información de ruta que se envía como directorios implícitos para cada ruta que especifiques. Puedes insertar un punto y una barra en la ruta de origen, así:

$ blitz -s MiSecreto /etc/./ssh/ssh*config
Los archivos recibidos se almacenarán en /tmp/foo/ssh/ en lugar de /tmp/foo/etc/ssh.

Copiar recursivamente y limitar el ancho de banda a 10kB/seg:

$ blitz -s MiSecreto -o 'RSOPT=--bwlimit=10' /usr/./share

Copiar todo el sistema de archivos raíz:

$ blitz -s MiSecreto -o 'RSOPT=-x' /

Copiar archivos específicos leídos de la entrada estándar:

$ find . -name '*.conf' | blitz -s MiSecreto -f -

Ejecutar un servidor permanente (demonio) a través de TOR:

$ blitz -s MiSecreto -l -D -T

ENTORNO
