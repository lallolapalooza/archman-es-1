NOMBRE

borg-key-import - Importar la clave del repositorio desde una copia de seguridad

SINOPSIS

borg [opciones comunes] key import [opciones] [REPOSITORIO] [RUTA]

DESCRIPCIÓN

Este comando restaura una clave previamente copiada con el comando export.

Si se proporciona la opción --paper, la importación será un proceso interactivo en el que cada línea se verificará para detectar posibles errores antes de pasar a la siguiente línea. Para este formato, no se debe proporcionar RUTA.

Para repositorios que utilizan cifrado de archivo de clave, el archivo de clave que borg key import escribe depende de varios factores. Si la variable de entorno BORG_KEY_FILE está configurada y no está vacía, borg key import crea o sobrescribe el archivo nombrado por $BORG_KEY_FILE. De lo contrario, borg key import busca en el directorio $BORG_KEYS_DIR un archivo de clave asociado con el repositorio. Si se encuentra un archivo de clave en $BORG_KEYS_DIR, borg key import lo sobrescribe; de lo contrario, borg key import crea un nuevo archivo de clave en $BORG_KEYS_DIR.

OPCIONES

Consulte borg-common(1) para ver las opciones comunes de los comandos de Borg.

argumentos

REPOSITORIO

RUTA
ruta a la copia de seguridad ('-' para leer desde stdin)

opciones

--paper
importar interactivamente desde una copia de seguridad realizada con --paper

borg-common(1), borg-key-export(1)
