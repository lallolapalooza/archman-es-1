NOMBRE

bpkg-argument-grouping - instalación de agrupación de argumentos

SINOPSIS

bpkg { opciones }+ argumento +{ opciones }

DESCRIPCIÓN

Para ciertos comandos, ciertas opciones y variables de línea de comandos se pueden agrupar para que solo se apliquen a argumentos específicos. Este tema de ayuda describe la instalación de agrupación de argumentos utilizada para este propósito.

Los grupos se pueden especificar antes (inicial) y/o después (final) del argumento al que se aplican. Un grupo inicial comienza con '{' y termina con '}+' mientras que un grupo final comienza con '+{' y termina con '}'. Por ejemplo:

{ --foo --bar }+ arg   # 'arg' con '--foo' '--bar'
arg +{ fox=1 baz=2 }   # 'arg' con 'fox=1' 'baz=2'

Se pueden especificar múltiples grupos iniciales y/o finales para el mismo argumento. Por ejemplo:

{ -f }+ { -b }+ arg +{ f=1 } +{ b=2 } # 'arg' con '-f' 'b' 'f=1' 'b=2'

El grupo se aplica a un solo argumento a menos que varios argumentos estén agrupados con '{' y '}'. Por ejemplo:

{ --foo }+ arg1  arg2 +{ --bar }      # 'arg1' con '--foo'
                                      # 'arg2' con '--bar'
{ --foo }+ { arg1  arg2 } +{ --bar }  # 'arg1' con '--foo' '--bar'
                                      # 'arg2' con '--foo' '--bar'

Los separadores de grupo ('{', '}+', etc.) deben ser argumentos de línea de comandos separados. En particular, no deben ser adyacentes ni a los argumentos dentro del grupo ni al argumento al que se aplican. Todos esos casos se tratarán como argumentos ordinarios. Por ejemplo:

{--foo}+ arg   # '{--foo}+' ...
arg+{ --foo }  # 'arg+{' ...

Si uno de los separadores de grupo necesita especificarse como un argumento literal, debe ser escapado con '\'. Por ejemplo:

}             # error: separador de grupo inesperado
}x            # '}x'
\}            # '}'
{ \}+ }+ arg  # 'arg' con '}+'
