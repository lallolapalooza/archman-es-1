BN_BLINDING_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_BLINDING_NEW(3ssl) OpenSSL BN_BLINDING_NEW(3ssl)

NOMBRE

BN_BLINDING_new, BN_BLINDING_free, BN_BLINDING_update, BN_BLINDING_convert, BN_BLINDING_invert, BN_BLINDING_convert_ex, BN_BLINDING_invert_ex, BN_BLINDING_is_current_thread, BN_BLINDING_set_current_thread, BN_BLINDING_lock, BN_BLINDING_unlock, BN_BLINDING_get_flags, BN_BLINDING_set_flags, BN_BLINDING_create_param - funciones BIGNUM relacionadas con el cegado

SINOPSIS

#include <openssl/bn.h>
BN_BLINDING *BN_BLINDING_new(const BIGNUM *A, const BIGNUM *Ai,
                             BIGNUM *mod);
void BN_BLINDING_free(BN_BLINDING *b);
int BN_BLINDING_update(BN_BLINDING *b, BN_CTX *ctx);
int BN_BLINDING_convert(BIGNUM *n, BN_BLINDING *b, BN_CTX *ctx);
int BN_BLINDING_invert(BIGNUM *n, BN_BLINDING *b, BN_CTX *ctx);
int BN_BLINDING_convert_ex(BIGNUM *n, BIGNUM *r, BN_BLINDING *b,
                           BN_CTX *ctx);
int BN_BLINDING_invert_ex(BIGNUM *n, const BIGNUM *r, BN_BLINDING *b,
                          BN_CTX *ctx);
int BN_BLINDING_is_current_thread(BN_BLINDING *b);
void BN_BLINDING_set_current_thread(BN_BLINDING *b);
int BN_BLINDING_lock(BN_BLINDING *b);
int BN_BLINDING_unlock(BN_BLINDING *b);
unsigned long BN_BLINDING_get_flags(const BN_BLINDING *b);
void BN_BLINDING_set_flags(BN_BLINDING *b, unsigned long flags);
BN_BLINDING *BN_BLINDING_create_param(BN_BLINDING *b,
                                      const BIGNUM *e, BIGNUM *m, BN_CTX *ctx,
                                      int (*bn_mod_exp)(BIGNUM *r,
                                                        const BIGNUM *a,
                                                        const BIGNUM *p,
                                                        const BIGNUM *m,
                                                        BN_CTX *ctx,
                                                        BN_MONT_CTX *m_ctx),
                                      BN_MONT_CTX *m_ctx);

DESCRIPCIÓN

BN_BLINDING_new() asigna una nueva estructura BN_BLINDING y copia los valores A y Ai en el objeto BN_BLINDING recién creado.

BN_BLINDING_free() libera la estructura BN_BLINDING. Si b es NULL, no se hace nada.

BN_BLINDING_update() actualiza los parámetros de BN_BLINDING elevando al cuadrado A y Ai o, después de un número específico de usos y si los parámetros necesarios están establecidos, recreando los parámetros de cegado.

BN_BLINDING_convert_ex() multiplica n por el factor de cegado A. Si r no es NULL, se devolverá una copia del factor de cegado inverso Ai en r (esto es útil si un objeto RSA se comparte entre varios hilos). BN_BLINDING_invert_ex() multiplica n por el factor de cegado inverso Ai. Si r no es NULL, se utilizará como el cegado inverso.

BN_BLINDING_convert() y BN_BLINDING_invert() son funciones envoltorio para BN_BLINDING_convert_ex() y BN_BLINDING_invert_ex() con r establecido a NULL.

BN_BLINDING_is_current_thread() devuelve si la estructura BN_BLINDING es propiedad del hilo actual. Esto es para ayudar a los usuarios a proporcionar el bloqueo adecuado si es necesario para el uso multihilo.

BN_BLINDING_set_current_thread() establece el hilo actual como propietario de la estructura BN_BLINDING.

BN_BLINDING_lock() bloquea la estructura BN_BLINDING.

BN_BLINDING_unlock() desbloquea la estructura BN_BLINDING.

BN_BLINDING_get_flags() devuelve las banderas de BN_BLINDING. Actualmente hay dos banderas admitidas: BN_BLINDING_NO_UPDATE y BN_BLINDING_NO_RECREATE. BN_BLINDING_NO_UPDATE inhibe la actualización automática de los parámetros de BN_BLINDING después de cada uso y BN_BLINDING_NO_RECREATE inhibe la recreación automática de los parámetros de BN_BLINDING después de un número fijo de usos (actualmente 32). En objetos BN_BLINDING recién asignados no se establece ninguna bandera. BN_BLINDING_set_flags() establece las banderas de los parámetros de BN_BLINDING.

BN_BLINDING_create_param() crea nuevos parámetros de BN_BLINDING utilizando el exponente e y el módulo m. bn_mod_exp y m_ctx se pueden usar para pasar funciones especiales para la exponenciación (normalmente BN_mod_exp_mont() y BN_MONT_CTX).

VALORES DE RETORNO

BN_BLINDING_new() devuelve la estructura BN_BLINDING recién asignada o NULL en caso de error.

BN_BLINDING_update(), BN_BLINDING_convert(), BN_BLINDING_invert(), BN_BLINDING_convert_ex() y BN_BLINDING_invert_ex() devuelven 1 en caso de éxito y 0 si ocurrió un error.

BN_BLINDING_is_current_thread() devuelve 1 si el hilo actual posee el objeto BN_BLINDING, 0 en caso contrario.

BN_BLINDING_set_current_thread() no devuelve nada.

BN_BLINDING_lock(), BN_BLINDING_unlock() devuelven 1 si la operación tuvo éxito o 0 en caso de error.

BN_BLINDING_get_flags() devuelve las banderas de BN_BLINDING actualmente establecidas (un valor unsigned long).

BN_BLINDING_create_param() devuelve los parámetros de BN_BLINDING recién creados o NULL en caso de error.

HISTORIA

BN_BLINDING_thread_id() se introdujo por primera vez en OpenSSL 1.0.0, y deprecia BN_BLINDING_set_thread_id() y BN_BLINDING_get_thread_id().
