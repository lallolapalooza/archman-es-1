B::Showlex(3perl) Guía de referencia para programadores de Perl B::Showlex(3perl)

NOMBRE

B::Showlex - Muestra las variables léxicas usadas en funciones o archivos

SINOPSIS

perl -MO=Showlex[,-OPCIONES][,SUBRUTINA] foo.pl

DESCRIPCIÓN

Cuando se da una lista de nombres de subrutinas separados por comas como opciones, Showlex imprime las variables léxicas utilizadas en esas subrutinas. De lo contrario, imprime las léxicas de ámbito de archivo en el archivo.

EJEMPLOS

Forma tradicional:

$ perl -MO=Showlex -e 'my ($i,$j,$k)=(1,"foo")'
Pad of lexical names for comppadlist has 4 entries
0: (0x8caea4) undef
1: (0x9db0fb0) $i
2: (0x9db0f38) $j
3: (0x9db0f50) $k
Pad of lexical values for comppadlist has 5 entries
0: SPECIAL #1 &PL_sv_undef
1: NULL (0x9da4234)
2: NULL (0x9db0f2c)
3: NULL (0x9db0f44)
4: NULL (0x9da4264)
-e syntax OK

Forma nueva:

$ perl -MO=Showlex,-newlex -e 'my ($i,$j,$k)=(1,"foo")'
main Pad has 4 entries
0: (0x8caea4) undef
1: (0xa0c4fb8) "$i" = NULL (0xa0b8234)
2: (0xa0c4f40) "$j" = NULL (0xa0c4f34)
3: (0xa0c4f58) "$k" = NULL (0xa0c4f4c)
-e syntax OK

Forma nueva, sin especiales, fuera del framework O:

$ perl -MB::Showlex -e \
   'my ($i,$j,$k)=(1,"foo"); B::Showlex::compile(-newlex,-nosp)->()'
main Pad has 4 entries
1: (0x998ffb0) "$i" = IV (0x9983234) 1
2: (0x998ff68) "$j" = PV (0x998ff5c) "foo"
3: (0x998ff80) "$k" = NULL (0x998ff74)

Nótese que este ejemplo muestra los valores de las léxicas, mientras que los otros ejemplos no lo hicieron (ya que son solo en tiempo de compilación).

OPCIONES

La opción "-newlex" produce un formato más legible de "nombre => valor", y se muestra en el segundo ejemplo anterior.

La opción "-nosp" elimina el reporte de ESPECIALES, como "0: SPECIAL #1 &PL_sv_undef" arriba. El reporte de ESPECIALES a veces puede abrumar tus léxicas declaradas.

VER TAMBIÉN

B::Showlex también puede ser usado fuera del framework O, como en el tercer ejemplo. Ver B::Concise para una explicación más completa de las razones.

TODO

Parte de la información reportada, como las direcciones hexadecimales, no es particularmente valiosa. Otra información sería más útil para el programador típico, como números de línea, reutilizaciones de ranuras de pad, etc. Dado esto, -newlex no es un nombre de bandera particularmente bueno.
