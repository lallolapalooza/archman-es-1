NOMBRE

buf-plugin-push - Empujar un plugin de verificación a un registro

SINOPSIS

buf plugin push [flags]

DESCRIPCIÓN

El primer argumento es el nombre completo del plugin en el formato .

OPCIONES

--binary="" La ruta al archivo binario Wasm a empujar.

--create[=false] Crear el plugin si no existe. Por defecto, crea un plugin privado en el BSR si no se establece --create-visibility. Debe usarse con --create-type.

--create-type="" La configuración de tipo del plugin, si se crea. Solo se puede establecer con --create. Debe ser uno de [check]

--create-visibility="private" La configuración de visibilidad del módulo, si se crea. Solo se puede establecer con --create. Debe ser uno de [public,private]

-h, --help[=false] Ayuda para push

--label=[] Asociar la etiqueta con los plugins empujados. Se puede usar varias veces.

--source-control-url="" La URL para ver el código fuente de los plugins empujados (por ejemplo, el commit específico en el control de origen).

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta que se agote el tiempo, establecerlo en 0 significa sin tiempo de espera
