DESCRIPCIÓ

N

El comando fetch obtiene la lista de paquetes disponibles en los repositorios de requisitos previos/complementarios del proyecto en una o más configuraciones de

compilación.

Si no se especifica un directorio de proyecto o paquete, se asume el directorio de trabajo actual. Si no se especifica una configuración, se asume la configuración predeterminada. Véase bdep-projects-configs(1) para obtener detalles sobre cómo especificar proyectos y configuraciones

.

Si se especifica la opción --full|-F, entonces en lugar de fetch se realiza una re-obtención completa de todos los repositorios añadidos a la configuración. Este modo es principalmente útil cuando una configuración (y algunos de los reposito

rios de requisitos previos/complementarios) se comparten entre varios proyectos. En esta sit
uación, una obtención incremental puede resultar en un estado de repositorio inconsistente.
