bupstash-init(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Inicializa un repositorio de bupstash.

bupstash init [OPCIONES]

DESCRIPCIÓN

bupstash init inicializa un repositorio. Si REPOSITORIO ya existe, el comando falla.

Actualmente, no se recomienda usar bupstash en un sistema de archivos de red.

Para obtener detalles sobre el contenido del almacén de paquetes después de la inicialización, consulte bupstash-repository(7).

OPCIONES

-r, --repository REPO
El repositorio al que conectarse. Puede ser de la forma ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece como BUPSTASH_REPOSITORY.
--storage ESPEC
Acepta ´dir´ o una especificación de almacenamiento json. El almacenamiento predeterminado es ´dir´ y almacena bloques de datos cifrados en un directorio de datos local del repositorio.
Consulte la sección de especificaciones de almacenamiento para ver las especificaciones json admitidas y ejemplos.

ENTORNO

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede ser de la forma ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando para ejecutar y conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.

EJEMPLOS

``` $ export BUPSTASH_REPOSITORY=./mi-repositorio $ bupstash init

$ export BUPSTASH_REPOSITORY=ssh://$SERVIDOR/home/copias/bupstash-copias $ bupstash init ```

ESPECIFICACIONES DE ALMACENAMIENTO JSON

Cada especificación de almacenamiento consta de un descriptor de tipo y un conjunto de parámetros específicos del tipo.

Almacenamiento Dir

El almacenamiento Dir es un alias para --storage dir y generalmente no es necesario.

Ejemplo:

$ bupstash init --storage ´{"Dir" : {}}´´

Almacenamiento externo

El motor de almacenamiento externo almacena datos a través de un socket externo; la documentación está pendiente de la estabilización de la interfaz.

Ejemplo:

$ bupstash init --storage ´{"External" : {"socket_path" : "/plugin/socket.sock", "path" : "ruta-especifica-del-plugin"}}´´
