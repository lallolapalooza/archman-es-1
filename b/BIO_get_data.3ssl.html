BIO_get_data(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_GET_DATA(3ssl) OpenSSL BIO_GET_DATA(3ssl)

NOMBRE

BIO_set_data, BIO_get_data, BIO_set_init, BIO_get_init, BIO_set_shutdown, BIO_get_shutdown - funciones para gestionar información de estado de BIO

SINOPSIS

#include <openssl/bio.h>
void BIO_set_data(BIO *a, void *ptr);
void *BIO_get_data(BIO *a);
void BIO_set_init(BIO *a, int init);
int BIO_get_init(BIO *a);
void BIO_set_shutdown(BIO *a, int shut);
int BIO_get_shutdown(BIO *a);

DESCRIPCIÓN

Estas funciones son principalmente útiles al implementar un BIO personalizado.

La función BIO_set_data() asocia los datos personalizados apuntados por ptr con el BIO. Estos datos pueden ser recuperados posteriormente mediante una llamada a BIO_get_data(). Esto puede ser utilizado por BIOs personalizados para almacenar información específica de la implementación.

La función BIO_set_init() establece el valor del flag de "init" del BIO para indicar si la inicialización se ha completado o no para este BIO. Un valor distinto de cero indica que la inicialización está completa, mientras que cero indica que no lo está. A menudo, la inicialización se completará durante la construcción inicial del BIO. Sin embargo, para algunos BIOs, la inicialización puede no completarse hasta después de que hayan ocurrido pasos adicionales (por ejemplo, a través de llamadas a ctrls personalizados). La función BIO_get_init() devuelve el valor del flag de "init".

Las funciones BIO_set_shutdown() y BIO_get_shutdown() establecen y obtienen el estado del flag de cierre (es decir, BIO_CLOSE) de este BIO. Si está establecido, el recurso subyacente también se cierra cuando se libera el BIO.

VALORES DE RETORNO

BIO_get_data() devuelve un puntero a los datos personalizados específicos de la implementación asociados con este BIO, o NULL si no se ha establecido ninguno.

BIO_get_init() devuelve el estado del flag de inicialización del BIO.

BIO_get_shutdown() devuelve el estado del flag de cierre (es decir, BIO_CLOSE) del BIO.

VER TAMBIÉN

bio(7), BIO_meth_new(3)
