BIO_F_MD(3ssl) OpenSSL BIO_F_MD(3ssl)

NOMBRE

BIO_f_md, BIO_set_md, BIO_get_md, BIO_get_md_ctx - filtro BIO de resumen de mensaje

SINOPSIS

#include <openssl/bio.h>
#include <openssl/evp.h>
const BIO_METHOD *BIO_f_md(void);
int BIO_set_md(BIO *b, EVP_MD *md);
int BIO_get_md(BIO *b, EVP_MD **mdp);
int BIO_get_md_ctx(BIO *b, EVP_MD_CTX **mdcp);

DESCRIPCIÓN

BIO_f_md() devuelve el método BIO de resumen de mensaje. Este es un filtro BIO que resume cualquier dato que pasa a través de él. Es un envoltorio BIO para las rutinas de resumen EVP_DigestInit(), EVP_DigestUpdate() y EVP_DigestFinal().

Cualquier dato escrito o leído a través de un BIO de resumen usando BIO_read_ex() y BIO_write_ex() es resumido.

BIO_gets(), si su parámetro size es lo suficientemente grande, finaliza el cálculo del resumen y devuelve el valor del resumen. BIO_puts() no es compatible.

BIO_reset() reinicializa un BIO de resumen.

BIO_set_md() establece el resumen de mensaje del BIO b a md: esto debe llamarse para inicializar un BIO de resumen antes de que se pasen datos a través de él. Es una macro de BIO_ctrl().

BIO_get_md() coloca un puntero al método de resumen del BIO de resumen en mdp. Es una macro de BIO_ctrl().

BIO_get_md_ctx() devuelve el contexto del BIO de resumen en mdcp.

NOTAS

El contexto devuelto por BIO_get_md_ctx() puede ser usado en llamadas a EVP_DigestFinal() y también a las rutinas de firma EVP_SignFinal() y EVP_VerifyFinal().

El contexto devuelto por BIO_get_md_ctx() es una estructura de contexto interna. Los cambios realizados en este contexto afectarán al propio BIO de resumen y el puntero de contexto se invalidará cuando el BIO de resumen se libere.

Después de que el resumen haya sido recuperado de un BIO de resumen, debe ser reinicializado llamando a BIO_reset(), o BIO_set_md() antes de que se pasen más datos a través de él.

Si una aplicación necesita llamar a BIO_gets() o BIO_puts() a través de una cadena que contiene BIOs de resumen, esto se puede hacer anteponiendo un BIO de almacenamiento en búfer.

Llamar a BIO_get_md_ctx() devolverá el contexto e inicializará el estado del BIO. Esto permite a las aplicaciones inicializar el contexto externamente si las llamadas estándar como BIO_set_md() no son lo suficientemente flexibles.

VALORES DE RETORNO

BIO_f_md() devuelve el método BIO de resumen.

BIO_set_md(), BIO_get_md() y BIO_md_ctx() devuelven 1 para éxito y <=0 para fallo.

EJEMPLOS

El siguiente ejemplo crea una cadena de BIOs que contiene un BIO de resumen SHA1 y MD5 y pasa la cadena "Hello World" a través de ella. La verificación de errores se ha omitido por claridad.

BIO *bio, *mdtmp;
char message[] = "Hello World";
bio = BIO_new(BIO_s_null());
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_sha1());
/*
 * Para BIO_push() queremos añadir el BIO receptor y mantener una nota
 * del inicio de la cadena.
 */
bio = BIO_push(mdtmp, bio);
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_md5());
bio = BIO_push(mdtmp, bio);
/* Nota: mdtmp ahora puede ser descartado */
BIO_write(bio, message, strlen(message));

El siguiente ejemplo resume datos leyendo a través de una cadena en su lugar:

BIO *bio, *mdtmp;
char buf[1024];
int rdlen;
bio = BIO_new_file(file, "rb");
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_sha1());
bio = BIO_push(mdtmp, bio);
mdtmp = BIO_new(BIO_f_md());
BIO_set_md(mdtmp, EVP_md5());
bio = BIO_push(mdtmp, bio);
do {
    rdlen = BIO_read(bio, buf, sizeof(buf));
    /* Podría querer hacer algo con los datos aquí */
} while (rdlen > 0);

Este siguiente ejemplo recupera los resúmenes de mensaje de una cadena de BIOs y los muestra. Esto podría usarse con los ejemplos anteriores.

BIO *mdtmp;
unsigned char mdbuf[EVP_MAX_MD_SIZE];
int mdlen;
int i;
mdtmp = bio;   /* Asumir que bio ha sido configurado previamente */
do {
    EVP_MD *md;
    mdtmp = BIO_find_type(mdtmp, BIO_TYPE_MD);
    if (!mdtmp)
        break;
    BIO_get_md(mdtmp, &md);
    printf("%s digest", OBJ_nid2sn(EVP_MD_get_type(md)));
    mdlen = BIO_gets(mdtmp, mdbuf, EVP_MAX_MD_SIZE);
    for (i = 0; i < mdlen; i++) printf(":%02X", mdbuf[i]);
    printf("\n");
    mdtmp = BIO_next(mdtmp);
} while (mdtmp);
BIO_free_all(bio);

ERRORES

La falta de soporte para BIO_puts() y el comportamiento no estándar de BIO_gets() podrían considerarse anómalos. Podría argumentarse que BIO_gets() y BIO_puts() deberían pasarse al siguiente BIO en la cadena y resumir los datos pasados a través, y que los resúmenes deberían recuperarse usando una llamada separada a BIO_ctrl().

HISTORIA

Antes de OpenSSL 1.0.0., la llamada a BIO_get_md_ctx() solo funcionaba si el BIO se inicializaba primero.
