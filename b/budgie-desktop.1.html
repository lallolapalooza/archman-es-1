BUDGIE-DESKTOP(1) Comandos de usuario BUDGIE-DESKTOP(1)

NOMBRE

budgie-desktop - punto de entrada central desde gnome-session para mostrar la interfaz gráfica

DESCRIPCIÓN

Uso:

gnome-session-binary [OPCIÓN?]
? el gestor de sesiones de GNOME

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda

Opciones de aplicación:

--systemd-service
Ejecutando como servicio systemd
--systemd
Usar gestión de sesiones systemd
--builtin
Usar gestión de sesiones incorporada (en lugar de la basada en systemd)
-a, --autostart=DIRECTORIO_INICIO_AUTOMÁTICO
Anular directorios de inicio automático estándar
--session=NOMBRE_SESIÓN
Sesión a utilizar
--debug
Habilitar código de depuración
-f, --failsafe
No cargar aplicaciones especificadas por el usuario
--version
Versión de esta aplicación
--whale
Mostrar el diálogo de "fail whale" para pruebas
--disable-acceleration-check
Deshabilitar la comprobación de aceleración de hardware
