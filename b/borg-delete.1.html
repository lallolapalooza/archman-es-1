BORG-DELETE(1) Herramienta de copia de seguridad de borg BORG-DELETE(1)

NOMBRE

borg-delete - Elimina un repositorio o archivos existentes

SINOPSIS

borg [opciones comunes] delete [opciones] [REPOSITORIO_O_ARCHIVO] [ARCHIVO...]

DESCRIPCIÓN

Este comando elimina un archivo del repositorio o el repositorio completo.

Importante: Al eliminar archivos, el espacio en disco del repositorio no se liberará hasta que ejecutes borg compact.

Al eliminar un repositorio completo, también se eliminan la información de seguridad y la caché local para él (si existen). Alternativamente, puedes eliminar solo la caché local con la opción --cache-only, o conservar la información de seguridad con la opción --keep-security-info.

En caso de duda, usa --dry-run --list para ver qué se eliminaría.

Al usar --stats, obtendrás algunas estadísticas sobre cuántos datos se eliminaron: el tamaño deduplicado "Datos eliminados" es el más interesante, ya que indica cuánto se reducirá tu repositorio. Ten en cuenta que las estadísticas "Todos los archivos" se refieren al estado después de la eliminación.

Puedes eliminar varios archivos especificando un patrón de shell para que coincida con varios archivos usando la opción --glob-archives GLOB (para más información sobre estos patrones, consulta borg_patterns(7)).

Para evitar eliminar archivos accidentalmente, especialmente al usar patrones globales, puede ser útil usar --dry-run para probar el comando sin realizar ningún cambio real en el repositorio.

OPCIONES

Consulta borg-common(1) para ver las opciones comunes de los comandos de Borg.

argumentos

REPOSITORIO_O_ARCHIVO
repositorio o archivo a eliminar
ARCHIVO
archivos a eliminar

opciones

-n, --dry-run
no cambiar el repositorio
--list
mostrar lista detallada de archivos
-s, --stats
mostrar estadísticas del archivo eliminado
--cache-only
eliminar solo la caché local para el repositorio dado
--force
forzar la eliminación de archivos corruptos, usa --force --force en caso de que --force no funcione.
--keep-security-info
conservar la información de seguridad local al eliminar un repositorio
--save-space
trabajar más lento, pero usando menos espacio
-c SEGUNDOS, --checkpoint-interval SEGUNDOS
escribir punto de control cada SEGUNDOS segundos (Predeterminado: 1800)

Filtros de archivo

-P PREFIJO, --prefix PREFIJO
considerar solo nombres de archivo que comiencen con este prefijo. (obsoleto)
-a GLOB, --glob-archives GLOB
considerar solo nombres de archivo que coincidan con el glob. Se aplican las reglas de sh (sin usar realmente el prefijo sh:), consulta "borg help patterns".
--sort-by CLAVES
Lista separada por comas de claves de ordenación; claves válidas son: timestamp, archive, name, id; predeterminado es: timestamp
--first N
considerar los primeros N archivos después de aplicar otros filtros
--last N
considerar los últimos N archivos después de aplicar otros filtros

EJEMPLOS

# eliminar un único archivo de copia de seguridad:
$ borg delete /ruta/al/repo::Lunes
# liberar espacio en disco realmente:
$ borg compact /ruta/al/repo
# eliminar todos los archivos cuyos nombres comiencen con el nombre del host de la máquina seguido de un guion
$ borg delete --glob-archives '{hostname}-*' /ruta/al/repo
# eliminar todos los archivos cuyos nombres contengan "-2012-"
$ borg delete --glob-archives '*-2012-*' /ruta/al/repo
# ver qué se eliminaría si delete se ejecutara sin --dry-run
$ borg delete --list --dry-run -a '*-May-*' /ruta/al/repo
# eliminar el repositorio completo y la caché local relacionada:
$ borg delete /ruta/al/repo
