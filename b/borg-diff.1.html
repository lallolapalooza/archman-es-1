Este comando encuentra diferencias (contenido de archivos, usuario/grupo/modo) entre

Debe especificarse una ubicación de repositorio y un nombre de archivo para REPO::ARCHIVE1. ARCHIVE2 es simplemente otro nombre de archivo en el mismo repositorio (no se permite la ubicación del repositorio)

Qué se

compara

Para cada elemento coincidente en ambos archivos, Borg

informa:
  • Cambios de contenido: bytes totales añadidos/eliminados dentro de los archivos. Si los parámetros del troceador son comparables, Borg compara rápidamente los IDs de los trozos; de lo contrario, compara el
    • contenido.
  • Cambios de metadatos: usuario, grupo, modo y otros metadatos mostrados en línea como "[modo_antiguo -> modo_nuevo]" para cambios de modo. Utilice --content-only para suprimir los cambios de
    • metadatos.
  • Elementos añadidos/e
    • liminados: se imprime

ÑO ruta" o "eli

La salida en formato JSON Lines (--json-lines) imprime un objeto JSON por cada ruta modificada, por

Solo se incluyen los cambios reales en la lis

Ordenació

n

Utilice --sort-by CAMPOS donde CAMPOS es una lista separada por comas de campos. Las ordenaciones se aplican de forma estable de la última a la primera en la lista dada. Anteponga ">" para descendente, "<" (o sin prefijo) para ascendente, por ejemplo --sort-by=">size_added,path". Los campos admitidos

incluyen:
  • path: la ruta del
    • elemento
  • size_added: bytes totales añadidos para el contenido del
    • elemento
  • size_removed: bytes totales eliminados para el contenido del
    • elemento
  • size_diff: size_added - size_removed (cambio neto de
    • contenido)
  • size: tamaño del elemento tal como se almacena en ARCHIVE2 (0 para elementos
    • eliminados)
  • user, group, uid, gid, ctime, mtime: tomados del estado del elemento en ARCHIVE2 cuando estén
    • presentes
  • ctime_diff, mtime_d
    • iff: diferencia de
marcas de tiempo (a
rchive2 - archive1)

La opción --sort está obsoleta y

solo orden

Consideraciones de

rendimiento

Para archivos creados con Borg 1.1 o posterior, diff detecta automáticamente si los archivos fueron creados con los mismos parámetros del troceador. Si es así, solo se comparan los IDs de los trozos, lo cual es muy

rápido.

Para archivos anteriores a Borg 1.1, el contenido de los trozos se compara por defecto. Si no creó los archivos con diferentes parámetros del troceador, pase --same-chunker-params. Tenga en cuenta que los parámetros del troceador cambiaron de Borg 0.xx a 1.

0.

Para obtener más ayuda sobre patrones de inclusión/exclusión, consulte la salida del co

mando b

NAME

borg-common - common options for borg commands

SYNOPSIS

borg [common options] command [command options]

DESCRIPTION

This page describes common options that can be used with any borg command.

See also borg-help(1) for a list of all commands and their respective options.

OPTIONS

The following options are available:

--help [command]
Show help message and exit. If command is specified, show help for that command.
--version
Show program's version number and exit.
--verbose, -v
Be more verbose. This option can be given multiple times to increase verbosity.
--quiet, -q
Be less verbose. This option can be given multiple times to decrease verbosity.
--log-json
Log messages in JSON format. Useful for machine-readable logging.
--config-dir PATH
Path to the borg configuration directory. Defaults to $XDG_CONFIG_HOME/borg or ~/.config/borg.
--cache-dir PATH
Path to the borg cache directory. Defaults to $XDG_CACHE_HOME/borg or ~/.cache/borg.
--no-local-cache
Disable the use of the local cache directory.
--optimize
Optimize repository structure after operations. This is a resource-intensive operation and may take a long time. Use with caution.
--json
Output results in JSON format. Some commands support this option.
--json-dump PATH
Dump JSON output to a file. Useful for debugging.
--json-file PATH
Read input from a file in JSON format. Some commands support this option.
--json-key KEY
Specify a JSON key for nested structures. Useful for advanced JSON processing.
--json-indent LEVEL
Set JSON indentation level. Defaults to 4.

EXAMPLES

Show help for the borg create command:

$ borg --help create

Run a command with increased verbosity:

$ borg -vv create ...
