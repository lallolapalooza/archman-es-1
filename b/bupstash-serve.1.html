bupstash-serve(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Sirve el protocolo bupstash a través de stdin/stdout.

bupstash serve [OPCIONES] REPOSITORIO

DESCRIPCIÓN

bupstash serve sirve el protocolo bupstash a través de stdin/stdout permitiendo la interacción con un repositorio. La mayoría de los comandos de bupstash operan a través de una instancia de bupstash serve.

El comando serve tiene banderas que se pueden establecer para restringir los permisos de acceso; por defecto, se permite todo el acceso hasta que se proporcione la primera opción --allow-*. Estas banderas pueden ser forzadas en un archivo de claves autorizadas de ssh, o a través de mecanismos como la configuración de sudo o doas.

Los clientes con permiso para leer datos aún pueden no poder descifrarlos si no tienen la clave de descifrado correcta del lado del cliente.

Tenga en cuenta que muchos errores se imprimen fuera de banda a través de stderr, por lo que los transportes alternativos deberían considerar cómo reenviar también los datos de stderr.

OPCIONES

--allow-init
Permite al cliente inicializar nuevos repositorios.
--allow-put
Permite al cliente poner más elementos en el repositorio.
--allow-list
Permite al cliente recuperar metadatos e índices de instantáneas para búsqueda y listado.
--allow-get
Permite al cliente recuperar datos del repositorio, implica --allow-list.
--allow-remove
Permite al cliente eliminar elementos del repositorio, implica --allow-list.
--allow-gc
Permite al cliente ejecutar el recolector de basura del repositorio.
--allow-sync
Permite al cliente sincronizar elementos en el repositorio, es decir, ser el destino de una sincronización de repositorio.

EJEMPLOS

Marcas personalizadas de ssh usando BUPSTASH_REPOSITORY_COMMAND

$ export BUPSTASH_REPOSITORY_COMMAND="ssh -p 2020 $SERVER bupstash serve /data/repository" $ bupstash list

Configurar controles de acceso SSH

Crea un usuario ´backups´ en tu servidor.

En tu archivo de configuración de sshd en tu servidor, añade la línea:

Match User backups ForceCommand "/bin/bupstash-put-force-command.sh"

Crea /bin/bupstash-put-force-command.sh en tu servidor:

$ echo ´exec bupstash serve --allow-put /home/backups/bupstash-backups´ > bupstash-put-force-command.sh $ sudo cp bupstash-put-force-command.sh /bin/bupstash-put-force-command.sh $ sudo chown root:root /bin/bupstash-put-force-command.sh $ sudo chmod +x /bin/bupstash-put-force-command.sh

Ahora, cualquier cliente con acceso ssh al usuario ´backups´ solo podrá añadir nuevas copias de seguridad a un repositorio:

$ export BUPSTASH_REPOSITORY="ssh://backups@$SERVER" $ bupstash put ./data d1659c3f56f744c7767fc57da003ee5d $ bupstash list el servidor ha deshabilitado la consulta y la búsqueda para este cliente

Al iniciar sesión en el servidor por otros medios, tendrás acceso completo al repositorio de copias de seguridad. Se pueden configurar diferentes permisos utilizando conceptos similares junto con diferentes configuraciones y claves ssh.
