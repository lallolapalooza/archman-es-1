NOMBRE

bup-validate-object-links - escanea el repositorio en busca de enlaces de objetos rotos

SINOPSIS

bup validate-object-links

DESCRIPCIÓN

bup validate-object-links escanea los objetos en el repositorio y reporta cualquier “enlace roto” que encuentre, es decir, cualquier enlace desde un árbol o commit en el repositorio a un objeto que no existe. Actualmente, no incluye “objetos sueltos” (aquellos que no están en archivos pack — que git puede crear, pero bup no), y no puede manejar objetos de etiqueta (que bup tampoco crea).

Cada vez que se encuentra un enlace roto (referencia faltante), se imprimirá una línea codificada en ASCII con el siguiente formato en la salida estándar:

no MISSING_HASH for PARENT_HASH

ESTADO DE SALIDA

El estado de salida será 1 si se encuentran enlaces rotos, 0 si no se encuentra ninguno y algún otro entero positivo para otros fallos.

VER TAMBIÉN

bup-fsck(1)
