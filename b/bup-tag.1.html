NOMBRE

bup-tag - Etiqueta un commit en el repositorio bup

SINOPSIS

bup tag

bup tag [-f] <nombre de etiqueta> <committish>

bup tag -d [-f] <nombre de etiqueta>

DESCRIPCIÓN

bup tag lista, crea o elimina una etiqueta en el repositorio bup.

Una etiqueta es una forma fácil de recuperar un commit específico. Puede usarse para marcar una copia de seguridad específica para una recuperación más fácil más adelante.

Cuando se llama sin argumentos, el comando lista todas las etiquetas que se pueden encontrar en el repositorio. Cuando se llama con un nombre de etiqueta y un ID de commit o nombre de ref, crea una nueva etiqueta con el nombre dado, si aún no existe, que apunta al commit dado en el segundo argumento. Cuando se llama con `-d' y un nombre de etiqueta, elimina la etiqueta dada, si existe.

bup expone el contenido de las copias de seguridad con las etiquetas actuales, a través de cualquier comando que liste o muestre copias de seguridad. Se pueden encontrar en el directorio /.tag. Por ejemplo, el comando `ftp' mostrará la etiqueta llamada `tag1' bajo /.tag/tag1.

OPCIONES

-d, --delete
eliminar una etiqueta
-f, --force
Sobrescribe la etiqueta nombrada incluso si ya existe. Con -f, no informes una etiqueta faltante como error.

EJEMPLOS

$ bup tag new-puppet-version hostx-backup
$ bup tag
new-puppet-version
$ bup ftp "ls /.tag/new-puppet-version"
files..
$ bup tag -d new-puppet-version
