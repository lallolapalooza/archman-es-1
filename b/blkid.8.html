DESCRIPCIÓ

N

El programa blkid es la interfaz de línea de comandos para trabajar con la biblioteca libblkid(3). Puede determinar el tipo de contenido (p. ej., sistema de archivos o swap) que contiene un dispositivo de bloque, y también los atributos (tokens, pares NOMBRE=valor) de los metadatos del contenido (p. ej., campos LABEL o UUID)

.

Se recomienda usar el comando lsblk(8) para obtener información sobre dispositivos de bloque, o lsblk --fs para obtener una visión general de los sistemas de archivos, o findmnt(8) para buscar en sistemas de archivos ya

montados.

lsblk(8) proporciona más información, mejor control sobre el formato de salida, es fácil de usar en scripts y no requiere permisos de root para obtener información real. blkid lee información directamente de los dispositivos y para usuarios no root devuelve información en caché sin verificar. blkid está diseñado principalmente para servicios del sistema y para probar la funcionalidad de libblkid(3).

Cuando se especifica un dispositivo, se muestran los tokens solo de este dispositivo. Es posible especificar múltiples argumentos de dispositivo en la línea de comandos. Si no se proporciona ninguno, se muestran todas las particiones o dispositivos sin particionar que aparezcan en /proc/partitions, si son

reconocidos.

blkid tiene dos formas principales de operación: buscar un dispositivo con un par NOMBRE=valor específico, o mostrar pares NOMBRE=valor para uno o más dispositivos

especificados.

Por razones de seguridad, blkid ignora silenciosamente todos los dispositivos donde el resultado de la sondeo es ambivalente (se detectan múltiples sistemas de archivos en conflicto). El modo de sondeo de bajo nivel (-p) proporciona más información y un estado de salida extra en este caso. Se recomienda usar wipefs(8) para obtener una visión general detallada y borr

ar cosas obsoletas (cade
nas mágicas) del dispositivo.

Si hay múltiples dispositivos que coinciden con el parámetro de búsqueda especificado, se devuelve el dispositivo con la mayor prioridad, y/o el primer dispositivo encontrado en una prioridad dada (pero vea la nota sobre udev a continuación). Si esta opción no se especifica, blkid imprimirá todos los dispositivos que coincidan con el parámetro de búsqueda.

Esta opción fuerza a blkid a usar udev cuando se usa para los tokens LABEL o UUID en --match-token. El objetivo es proporcionar una salida consistente con otras utilidades (como mount(8), etc.) en sistemas donde la misma

Este método de búsqueda es capaz de usar de forma fiable los enlaces simbólicos udev /dev/disk/by-label (depende de una configuración en /etc/blkid.conf). Evite usar los enlaces simbólicos directamente; no es fiable usar los enlaces sin verificación. La opción --label funciona en sistemas con y sin udev.

Desafortunadamente, el blkid(8) original de e2fsprogs usa la opción -L como sinónimo de -o list. Para una mejor portabilidad, use -l -o device -t LABEL=etiqueta y -o list en sus scripts en lugar de la opció
