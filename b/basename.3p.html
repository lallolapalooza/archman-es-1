PRÓLOGO

Esta página manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

basename — devuelve el último componente de una ruta de acceso

SINOPSIS

#include <libgen.h>
char *basename(char *path);

DESCRIPCIÓN

La función basename() tomará la ruta de acceso a la que apunta el puntero path y devolverá un puntero al componente final de la ruta de acceso, eliminando cualquier carácter '/' final.

Si la cadena a la que apunta path consiste enteramente del carácter '/' , basename() devolverá un puntero a la cadena "/". Si la cadena a la que apunta path es exactamente "//", queda a definición de la implementación si se devuelve '/' o "//" .

Si path es un puntero nulo o apunta a una cadena vacía, basename() devolverá un puntero a la cadena ".".

La función basename() puede modificar la cadena a la que apunta path, y puede devolver un puntero al almacenamiento interno. El puntero devuelto podría invalidarse o el almacenamiento podría ser sobrescrito por una llamada posterior a basename(). El puntero devuelto también podría invalidarse si el hilo que llama es terminado.

La función basename() no necesita ser segura para hilos.

VALOR DEVUELTO

La función basename() devolverá un puntero al componente final de path.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Uso de basename()

El siguiente fragmento de programa devuelve un puntero al valor lib, que es el nombre base de /usr/lib.

#include <libgen.h>
...
char name[] = "/usr/lib";
char *base;
base = basename(name);
...
