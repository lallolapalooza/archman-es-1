NOMBRE

buf-config-ls-lint-rules - Listar reglas de lint

SINOPSIS

buf config ls-lint-rules [flags]

DESCRIPCIÓN

Listar reglas de lint

OPCIONES

--config="" El archivo buf.yaml o datos a usar para la configuración. --configured-only debe estar establecido

--configured-only[=false] Listar reglas que están configuradas en lugar de listar todas las reglas disponibles

--format="text" El formato en el que se imprimirán las reglas. Debe ser uno de [text,json]

-h, --help[=false] Ayuda para ls-lint-rules

--include-deprecated[=false] Imprimir también las reglas obsoletas. No tiene efecto si --configured-only está establecido.

--module-path="" La ruta al módulo específico para listar las reglas configuradas, según lo especificado en buf.yaml. Si buf.yaml tiene más de un módulo definido, esto debe ser establecido. --configured-only debe estar establecido

--version="" Listar todas las reglas para la versión de configuración dada. Por defecto, se usa la versión en buf.yaml en el directorio actual, o la última versión en caso contrario (actualmente v2). No se puede establecer si --configured-only está establecido. Debe ser uno de [v1beta1 v1 v2]

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo a 0 significa sin tiempo de espera

VER TAMBIÉN
