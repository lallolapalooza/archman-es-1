Paquete: buf

NOMBRE

buf config ls-breaking-rules - Listar reglas que rompen

SINOPSIS

buf config ls-breaking-rules [flags]

DESCRIPCIÓN

Listar reglas que rompen

OPCIONES

--config="" El archivo o datos buf.yaml a usar para la configuración. Se debe establecer --configured-only

--configured-only[=false] Listar reglas que están configuradas en lugar de listar todas las reglas disponibles

--format="text" El formato en que se listarán las reglas. Debe ser uno de [text,json]

-h, --help[=false] Ayuda para ls-breaking-rules

--include-deprecated[=false] También mostrar reglas obsoletas. No tiene efecto si está configurado --configured-only.

--module-path="" La ruta al módulo específico para listar las reglas configuradas, tal como se especifica en buf.yaml. Si el buf.yaml tiene más de un módulo definido, esto debe estar configurado. Se debe configurar --configured-only

--version="" Listar todas las reglas para la versión de configuración dada. Por defecto, se usa la versión en el buf.yaml en el directorio actual, o la última versión en caso contrario (actualmente v2). No se puede establecer si está configurado --configured-only. Debe ser uno de [v1beta1 v1 v2]

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
