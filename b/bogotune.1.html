BOGOTUNE(1) Manual de Referencia de Bogofilter BOGOTUNE(1)

NOMBRE

bogotune - encuentra configuraciones óptimas de parámetros para bogofilter

SINOPSIS

bogotune [-v] [-c config] [-C] [-d dir] [-D] [-r valor] [-T valor] -n okfile [[-n] okfile [...]] -s spamfile [[-s] spamfile [...]] [-M archivo]

bogotune [-h]

DESCRIPCIÓN

Bogotune intenta encontrar configuraciones óptimas de parámetros para bogofilter. Necesita al menos un conjunto de mensajes de spam y no spam. La lista de palabras de producción se usa normalmente, pero se puede indicar que lea una lista de palabras diferente o que construya la suya propia a partir de la mitad de los mensajes suministrados.

Para producir resultados útiles, bogotune tiene requisitos mínimos de recuento de mensajes. La lista de palabras que utiliza debe tener al menos 2.000 de spam y 2.000 de no spam, y los archivos de mensajes deben contener al menos 500 de spam y 500 de no spam. Además, la proporción de spam a no spam debe estar en el rango de 0.2 a 5. Si se indica a bogotune que construya su propia lista de palabras, utilizará la mitad de la entrada o 2.000 mensajes (lo que sea mayor) para la lista de palabras.

Los archivos de mensajes pueden estar en formato mbox, maildir o carpetas MH, o cualquier combinación. También se pueden usar archivos de recuento de mensajes, pero no mezclados con otros formatos.

OPCIONES

La opción -h imprime el mensaje de ayuda y sale.

La opción -v aumenta el nivel de verbosidad. El nivel 1 muestra la salida del escaneo en detalle en lugar de usar un medidor de progreso.

La opción -c filename indica a bogofilter que lea el archivo de configuración especificado.

La opción -C evita que bogotune lea un archivo de configuración.

La opción -d dir especifica el directorio para la base de datos. Consulte la sección ENTORNO para ver otras opciones de configuración de directorio.

La opción -D indica a bogotune que construya una lista de palabras en memoria utilizando los mensajes de entrada. Los mensajes se leen y se dividen en dos grupos. El primer grupo se utiliza para construir una lista de palabras (en memoria) y el segundo se utiliza para la optimización. Para cumplir los requisitos mínimos de 2.000 mensajes en la lista de palabras y 500 mensajes para pruebas, cuando se utiliza -D, debe haber 2.500 de no spam y 2.500 de spam en los archivos de entrada. Si hay suficientes mensajes (más de 4.000), se dividirán equitativamente entre la lista de palabras y las pruebas. De lo contrario, se dividirán proporcionalmente.

La opción -n indica a bogotune que el siguiente argumento es un archivo (o carpeta) que contiene no spam. Desde la versión 1.0.3, se pueden dar múltiples argumentos a la opción -n. Todos los argumentos que no sean opciones hasta la siguiente opción -s se tratarán como si hubieran sido precedidos por -n.

La opción -s indica a bogotune que el siguiente argumento es un archivo (o carpeta) que contiene spam. Se puede repetir tantas veces como sea necesario. Desde la versión 1.0.3, se pueden dar múltiples argumentos a -s. Todos los argumentos que no sean opciones hasta la siguiente opción -n se tratarán como si hubieran sido precedidos por -s.

La opción -r valor indica a bogotune que use el siguiente parámetro como el valor robx.

La opción -T valor indica a bogotune que use el siguiente parámetro como el valor objetivo de falsos positivos.

La opción -M archivo indica a bogotune que convierta el archivo a formato de recuento de mensajes. Este formato proporciona una lista ordenada de los tokens únicos de cada mensaje, junto con sus recuentos de ham (no spam) y spam. El ordenamiento oculta el sentido de los mensajes de forma bastante eficaz, protegiendo así la privacidad. El formato de recuento de mensajes permite a bogotune y bogofilter puntuar mensajes rápidamente sin necesidad de la base de datos de tokens original.

ENTORNO

Bogofilter utiliza un directorio de base de datos, que se puede configurar en el archivo de configuración. Si no se establece allí, bogofilter utilizará el valor de BOGOFILTER_DIR. Ambos pueden ser anulados por la opción -ddir. Si nada de eso está disponible, bogofilter utilizará el directorio $HOME/.bogofilter.

ERRORES

Bogotune no es particularmente robusto cuando se le presentan entradas incorrectas.

AUTOR

El equipo de desarrollo de bogofilter.

Para actualizaciones, consulte la página del proyecto bogofilter[1].
