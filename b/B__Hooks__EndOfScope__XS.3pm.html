B::Hooks::EndOfScope::XS(3) Documentación de Perl aportada por el usuario B::Hooks::EndOfScope::XS(3)

NOMBRE

B::Hooks::EndOfScope::XS - Ejecutar código después de que un ámbito haya terminado de compilarse - implementación XS

VERSIÓN

versión 0.28

DESCRIPCIÓN

Esta es la implementación de B::Hooks::EndOfScope basada en Variable::Magic, que es un módulo XS dependiente de un compilador. Siempre se preferirá automáticamente si Variable::Magic está disponible.

FUNCIONES

on_scope_end

on_scope_end { ... };
on_scope_end $code;

Registra que $code se ejecutará después de que el ámbito circundante haya sido compilado.

Esto se exporta por defecto. Ver Sub::Exporter sobre cómo personalizarlo.
