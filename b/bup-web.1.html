NOMBRE

bup-web - Inicia un servidor web para explorar repositorios bup

SINOPSIS

bup web [[hostname]:puerto]

bup web unix://ruta

DESCRIPCIÓN

bup web inicia un servidor web que puede explorar repositorios bup. La jerarquía de archivos es la misma que la que se muestra con bup-fuse(1), bup-ls(1) y bup-ftp(1).

hostname y puerto tienen por defecto 127.0.0.1 y 8080, respectivamente, y por lo tanto bup web solo ofrecerá el servidor web a los clientes que se ejecuten localmente. Si desea exponer el servidor web a cualquier persona en su red (¡peligroso!) puede omitir la dirección de enlace para enlazar a todas las interfaces disponibles: :8080.

Cuando se especifica unix://ruta, el servidor escuchará en el socket del sistema de archivos en ruta en lugar de un socket de red.

Se puede enviar una señal SIGTERM al servidor para solicitar un apagado ordenado.

OPCIONES

--legible-humanos
muestra tamaños de archivo legibles por humanos (es decir, 3.9K, 4.7M)
--explorador
abre el sitio en el explorador predeterminado

EJEMPLOS

$ bup web
Sirviendo HTTP en 127.0.0.1:8080...
^C
Interrumpido.
$ bup web :8080
Sirviendo HTTP en 0.0.0.0:8080...
^C
Interrumpido.
$ bup web unix://socket &
Sirviendo HTTP en el socket del sistema de archivos 'socket'
$ curl --unix-socket ./socket http://localhost/
$ fg
bup web unix://socket
^C
Interrumpido.
$ bup web &
[1] 30980
Sirviendo HTTP en 127.0.0.1:8080...
$ kill -s TERM 30980
Se solicitó el apagado
$ wait 30980
$ echo $?
0
