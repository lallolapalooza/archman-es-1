NOMBRE

byobu-ulevel - script auxiliar para indicadores de nivel de notificación

DESCRIPCIÓN

byobu-ulevel es un script auxiliar que se puede utilizar para crear gráficos de historial con caracteres UTF8.

USO

byobu-ulevel [opciones] -c <num_actual>

byobu-ulevel [opciones] <num_actual>

byobu-ulevel <num_actual>

OPCIONES


-a : Modo de accesibilidad: solo salida ASCII. (También habilitado si la variable '$a11y_variable' está definida).
-b : Muestra el valor actual como un espacio si es cero, en lugar del 'valor' más bajo del tema.
-c <num> : Valor actual de tu indicador.
-d : Habilita la salida de depuración.
-e <int> : Número de lugares decimales a usar para el modo de accesibilidad (por defecto=$default_decimal_places).
-h : Muestra esta ayuda.
-i : Invierte el esquema de color (solo temas de calificación).
-l : Lista los temas disponibles. Si también se especifica '-t', muestra todos los valores para el tema especificado.
-m <num> : Valor mínimo (por defecto=$min_default).
-n : Suprime la salida del carácter de nueva línea.
-p : Modo permisivo: si el valor actual está fuera de los límites, establécelo en el límite más cercano (mínimo o máximo).
-q : Suprime mensajes (requiere '-t').
-r : Invierte la 'dirección' de la visualización (solo temas de calificación).
-t <tema> : Nombre del tema (por defecto=$theme_default).
-u <chars> : Especifica un tema de usuario (2 o más valores).
-w <int> : Ancho del tema de calificación (por defecto=$width_default).
-x <num> : Valor máximo (por defecto=$max_default).

EJEMPLOS

Muestra el carácter que representa el 27% usando el tema predeterminado.
byobu-ulevel 27

Lo mismo que arriba.
byobu-ulevel -c 27

Ejemplo que muestra valores de punto flotante y negativos.
byobu-ulevel -c 1.100001 -m -5.00234 -x 2.71828 -t dice_6

Usa el modo de accesibilidad para mostrar un valor porcentual (redondeado al porcentaje más cercano).
byobu-ulevel -m -22.613 -x 5.00212 -c 0.10203 -a -e 0

Muestra el valor usando un "tema de calificación" (mostrado de izquierda a derecha).
byobu-ulevel -c 83 -t stars_2

Muestra un "tema de calificación" invertido y de derecha a izquierda.
byobu-ulevel -c 60 -t diamonds_2 -ri

Muestra todos los glifos en el tema 'solid_numbers_a_10'.
byobu-ulevel -l -t solid_numbers_a_10

Muestra un tema de calificación especificado por el usuario con un ancho de 10 glifos.
byobu-ulevel -c 666.321 -m -273.15 -x 1370 -u "· ☢" -w 10

Un tema de usuario con múltiples elementos (esto imprime 'e').
byobu-ulevel -c 50 -u "a b c d e f g h i j"

NOTAS

Los argumentos de tipo "<int>" denotan un valor entero, mientras que los argumentos de tipo "<num>" denotan un número entero o de punto flotante.

El sufijo "_<número>" en el nombre de un tema denota el número de glifos que contiene.

Los "temas de calificación" son aquellos con solo 2 valores.

El argumento <chars> para '-u' debe contener caracteres separados por espacios.
