B43-FWCUTTER(1) Comandos de usuario B43-FWCUTTER(1)

NOMBRE

b43-fwcutter - Utilidad para extraer el firmware de Broadcom 43xx

SINOPSIS

b43-fwcutter [OPCIÓN] [CONTROLADOR]

DESCRIPCIÓN

b43-fwcutter puede extraer el firmware para tu hardware Broadcom 43xx de diferentes controladores de código cerrado. El controlador b43 depende de estos archivos de firmware y no puede funcionar sin ellos.

Actualmente b43-fwcutter soporta controladores de Apple MacOS X, Microsoft Windows y Linux, pero ten en cuenta que b43-fwcutter no soporta todas las versiones de controladores.

Ejemplo:

b43-fwcutter bcmwl5.sys

para extraer el firmware de bcmwl5.sys

OPCIONES

-l|--list
Listar versiones de controladores soportadas
-i|--identify
Solo identificar el archivo del controlador (no extraer)
-w|--target-dir DIR
Extraer y escribir el firmware en DIR
-a|--alt-iv
Extraer initvals alternativos (solo 3.10.x.x)
-v|--version
Imprimir la versión de b43-fwcutter
-h|--help
Imprimir información de ayuda

AUTORES
