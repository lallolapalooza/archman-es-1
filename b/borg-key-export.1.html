BORG-KEY-EXPORT(1) Herramienta de copia de seguridad borg BORG-KEY-EXPORT(1)

NOMBRE

borg-key-export - Exportar la clave del repositorio para copia de seguridad

SINOPSIS

borg [opciones comunes] key export [opciones] [REPOSITORIO] [RUTA]

DESCRIPCIÓN

Si se utiliza el cifrado del repositorio, el repositorio es inaccesible sin la clave. Este comando permite hacer una copia de seguridad de esta clave esencial. Tenga en cuenta que la copia de seguridad producida no incluye la contraseña en sí (es decir, la clave exportada permanece cifrada). Para recuperar el acceso a un repositorio, se necesita tanto la clave exportada como la contraseña original.

Hay tres formatos de copia de seguridad. El formato de copia de seguridad normal es adecuado para almacenamiento digital como archivo. El formato de copia de seguridad --paper está optimizado para imprimir y escribir manualmente durante la importación, con comprobaciones por línea para reducir problemas con la entrada manual. La opción --qr-html crea una plantilla HTML imprimible con un código QR y una copia de la clave en formato --paper.

Para repositorios que utilizan cifrado de clave de archivo, la clave se guarda localmente en el sistema que puede realizar copias de seguridad. Para protegerse contra la pérdida de esta clave, es necesario hacer una copia de seguridad de la clave independientemente de la copia de seguridad principal de los datos.

Para repositorios que utilizan cifrado de clave de repositorio, la clave se guarda en el repositorio en el archivo de configuración. Por lo tanto, una copia de seguridad no es estrictamente necesaria, pero protege contra que el repositorio se vuelva inaccesible si el archivo se daña por alguna razón.

Ejemplos:

borg key export /ruta/a/repo > copia-seguridad-clave-cifrada
borg key export --paper /ruta/a/repo > copia-seguridad-clave-cifrada.txt
borg key export --qr-html /ruta/a/repo > copia-seguridad-clave-cifrada.html
# O pasar el archivo de salida como argumento en lugar de redirigir stdout:
borg key export /ruta/a/repo copia-seguridad-clave-cifrada
borg key export --paper /ruta/a/repo copia-seguridad-clave-cifrada.txt
borg key export --qr-html /ruta/a/repo copia-seguridad-clave-cifrada.html

OPCIONES

Consulte borg-common(1) para ver las opciones comunes de los comandos de Borg.

argumentos

REPOSITORIO

RUTA
dónde almacenar la copia de seguridad

opciones

--paper
Crear una exportación adecuada para imprimir y luego introducir manualmente
--qr-html
Crear un archivo html adecuado para imprimir y luego introducir manualmente o escanear con qr
