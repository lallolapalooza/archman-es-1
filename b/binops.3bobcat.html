binops(3bobcat) Binary Operators binops(3bobcat)

NOMBRE

binops - Plantillas de funciones para operadores binarios de tipo clase

SINOPSIS

#include <utility>
#include <bobcat/typetrait>
#include <bobcat/binops>

DESCRIPCIÓN

Las clases pueden sobrecargar operadores binarios. Una clase llamada Class puede sobrecargar estos operadores binarios para adaptarlos a sus propias necesidades, permitiendo, por ejemplo, que dos objetos de tipo Class se sumen tras sobrecargar operator+. Los operadores para los operadores binarios *, /, %, +, -, <<, >>, &, |, y ^ (en esta página de manual se indican genéricamente como el operador `@') se pueden sobrecargar definiendo la función operator@.

Si una clase soporta la construcción por copia y si ofrece operadores de asignación binaria (es decir, ofrece miembros de la forma operator@=), entonces los operadores binarios correspondientes se pueden implementar todos de forma idéntica. El Class &operator@(Class &&lhs, Class const &rhs), consciente de movimiento, se implementa fácilmente en términos de operator@= (nota: la clase en sí no tiene que ser consciente de movimiento para definir esta función). El operador binario consciente de movimiento requiere una implementación de una sola línea, y como su implementación nunca cambia, podría definirse de forma segura inline:

Class operator@(Class &&lhs, Class const &rhs)
{
    return std::move(std::move(lhs) @= rhs);
}
El operador binario tradicional se puede implementar utilizando su forma estándar: 
Class operator@(Class const &lhs, Class const &rhs)
{
    Class tmp(lhs);
    tmp @= rhs;
    return tmp;
}
La implementación en bobcat/binops es ligeramente más compleja ya que permite promociones desde lhs o rhs.

Como los operadores binarios se pueden implementar todos de forma similar, sus definiciones son perfectamente adecuadas para plantillas: Una clase que ofrece un operator@= particular, entonces automáticamente también ofrece los operadores binarios correspondientes tras incluir bobcat/binops. Dado que las plantillas de funciones binarias no se instancian hasta que se utilizan, sus definiciones pueden ser procesadas por el compilador incluso si una clase implementa solo un subconjunto de los operadores de asignación binaria disponibles.

ESPACIO DE NOMBRES

Las plantillas de funciones de operadores binarios en bobcat/binops *no* están implementadas en un espacio de nombres particular. Esto permite que las fuentes incluyan bobcat/binops en múltiples espacios de nombres.

Si bobcat/binops se va a utilizar en múltiples espacios de nombres, la protección de inclusión (usando el identificador INCLUDED_BOBCAT_BINOPS_) debe suprimirse entre inclusiones de bobcat/binops en diferentes espacios de nombres.

Por ejemplo, para hacer que las plantillas de funciones de operadores binarios estén disponibles en un archivo fuente que utilice el namespace FBB y en un archivo fuente que utilice el espacio de nombres predeterminado, se puede utilizar el siguiente esquema:

#include <utility>              // asegura que std::move esté disponible
#include <bobcat/typetrait>     // requerido por binops
namespace MI_ESPACIO_DE_NOMBRES
{
    #include <bobcat/binops>    // operadores binarios disponibles en MI_ESPACIO_DE_NOMBRES
}
#undef INCLUDED_BOBCAT_BINOPS_  // suprime la protección de inclusión
#include <bobcat/binops>        // lee binops de nuevo para que los operadores binarios
                                // puedan usarse también en el espacio de nombres
                                // predeterminado

OPERADORES SOBRECARGADOS

Las plantillas de funciones en bobcat/binops implementan todos los operadores binarios aritméticos, tanto los conscientes de movimiento como los operadores binarios tradicionales, esperando referencias lvalue constantes. Se pueden utilizar si los operadores de asignación binaria correspondientes se implementaron en las clases para las que se deben instanciar las plantillas. Los siguientes operadores están disponibles:

Operadores conscientes de movimiento, utilizando objetos temporales para sus operandos del lado izquierdo:

o
Class operator*(Class &&lhs, Class const &rhs):
o
Class operator/(Class &&lhs, Class const &rhs):
o
Class operator%(Class &&lhs, Class const &rhs):
o
Class operator+(Class &&lhs, Class const &rhs):
o
Class operator-(Class &&lhs, Class const &rhs):
o
Class operator<<(Class &&lhs, Class const &rhs):
o
Class operator>>(Class &&lhs, Class const &rhs):
o
Class operator&(Class &&lhs, Class const &rhs):
o
Class operator|(Class &&lhs, Class const &rhs):
o
Class operator^(Class &&lhs, Class const &rhs):

Operadores "tradicionales", utilizando referencias lvalue a objetos constantes para sus operandos del lado izquierdo:

o
Class operator*(Class const &lhs, Class const &rhs):
o
Class operator/(Class const &lhs, Class const &rhs):
o
Class operator%(Class const &lhs, Class const &rhs):
o
Class operator+(Class const &lhs, Class const &rhs):
o
Class operator-(Class const &lhs, Class const &rhs):
o
Class operator<<(Class const &lhs, Class const &rhs):
o
Class operator>>(Class const &lhs, Class const &rhs):
o
Class operator&(Class const &lhs, Class const &rhs):
o
Class operator|(Class const &lhs, Class const &rhs):
o
Class operator^(Class const &lhs, Class const &rhs):
El último grupo de operadores también soporta promociones.

EJEMPLO

#include <iostream>
#include <utility>
#include "../../typetrait/typetrait"
#include "../binops"
class Demo
{
    friend std::ostream &operator<<(std::ostream &out, Demo const &demo);
    int d_value;
    public:
        Demo(int value = 0)
        :
            d_value(value)
        {}
        Demo(Demo const &other)
        :
            d_value(other.d_value)
        {
            std::cout << "Demo CC llamado\n";
        }
        Demo &operator+=(Demo const &rhs)
        {
            d_value += rhs.d_value;
            return *this;
        }
};
std::ostream &operator<<(std::ostream &out, Demo const &demo)
{
    return out << demo.d_value;
}
using namespace std;
int main()
{
    Demo four(4);
    Demo five(5);
    cout << four + five << ’\n’ <<
            four + 5 << ’\n’ <<
            4  + five << ’\n’;
}
