NOMBRE

budgie-session - Inicia el entorno de escritorio budgie

SINOPSIS

budgie-session [-a|--autostart=DIR] [--session=SESSION] [--failsafe|-f] [--debug] [--whale]

DESCRIPCIÓN

El programa budgie-session inicia el entorno de escritorio budgie. Este comando es típicamente ejecutado por tu gestor de inicio de sesión (ya sea gdm, xdm, o desde tus scripts de inicio de X). Cargará tu sesión guardada, o la instalación predeterminada de budgie en tu sistema. Ten en cuenta que budgie-session es un script de envoltura para budgie-session-binary.

$XDG_CONFIG_HOME/budgie-session/sessions, $XDG_CONFIG_DIRS/budgie-session/sessions y $XDG_DATA_DIRS/budgie-session/sessions.

Al guardar una sesión, budgie-session guarda las aplicaciones que se están ejecutando actualmente en el directorio $XDG_CONFIG_HOME/budgie-session/saved-session. Guardar sesiones solo se admite con el método de inicio heredado que no utiliza systemd.

budgie-session es un gestor de sesiones X11R6. Puede gestionar aplicaciones budgie así como cualquier aplicación compatible con X11R6 SM.

OPCIONES

Se admiten las siguientes opciones:

--autostart=DIR
El directorio DIR donde buscar archivos .desktop de inicio automático. Esta opción se puede usar varias veces. Cuando esta opción está presente, no se buscarán los directorios de inicio automático predeterminados.
--session=SESSION
Utiliza las aplicaciones definidas en SESSION.session. Si no se especifica, se usará budgie.session.
--builtin
Utiliza el método heredado que no utiliza systemd para gestionar la sesión del usuario.
--failsafe
Ejecuta en modo de recuperación. Las aplicaciones especificadas por el usuario no se iniciarán.
--debug
Habilita el código de depuración.
--whale
Muestra la ballena de fallo (fail whale) en un cuadro de diálogo para depurarla.

DEFINICIÓN DE SESIÓN

Las sesiones se definen en archivos .session, que utilizan un formato similar a .desktop, con las siguientes claves en el grupo budgie Session:

Name
Nombre de la sesión. Esto puede ser localizado.
RequiredComponents
Lista de identificadores de componentes (archivos .desktop) que son requeridos por la sesión. Los componentes requeridos se ejecutarán siempre en la sesión.

Aquí tienes un ejemplo de definición de sesión:


[budgie Session]
Name=budgie
RequiredComponents=budgie-desktop;gnome-settings-daemon;

Los archivos .session se buscan en $XDG_CONFIG_HOME/budgie-session/sessions, $XDG_CONFIG_DIRS/budgie-session/sessions y $XDG_DATA_DIRS/budgie-session/sessions.

Es mejor usar --builtin si se requieren personalizaciones de sesión. Esto se debe a la forma en que budgie define actualmente los componentes que se iniciarán en cada tipo de sesión.

ENTORNO

budgie-session establece varias variables de entorno para el uso de sus procesos hijos:

SESSION_MANAGER

Esta variable es utilizada por los clientes conscientes del gestor de sesión para contactar con budgie-session.

DISPLAY

Esta variable se establece en la pantalla X que está siendo utilizada por budgie-session. Ten en cuenta que si se utiliza la opción --display, esto podría ser diferente de la configuración de la variable de entorno cuando se invoca budgie-session.

El comportamiento de budgie-session en sí mismo puede ser modificado a través de la siguiente variable de entorno:

GNOME_SESSION_AUTOSTART_DIR

Esta variable especifica una lista de directorios donde buscar archivos de inicio automático. Esta variable anula todos los directorios especificados a través de la opción --autostart, así como todos los directorios de inicio automático predeterminados.

ARCHIVOS

$XDG_CONFIG_HOME/autostart $XDG_CONFIG_DIRS/autostart /usr/share/gnome/autostart

Las aplicaciones definidas a través de archivos .desktop en estos directorios se iniciarán al iniciar sesión.

$XDG_CONFIG_HOME/budgie-session/sessions $XDG_CONFIG_DIRS/budgie-session/sessions $XDG_DATA_DIRS/budgie-session/sessions

Estos directorios contienen los archivos .session que se pueden usar con la opción --session.

$XDG_CONFIG_HOME/budgie-session/saved-session

Este directorio contiene la lista de aplicaciones de la sesión guardada.

ERRORES

Si encuentras errores en el programa budgie-session, por favor repórtalos en https://github.com/buddiesofbudgie/budgie-session/issues.
