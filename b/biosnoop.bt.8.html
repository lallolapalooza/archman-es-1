biosnoop.bt(8) Manual del Administrador del Sistema biosnoop.bt(8)

NOMBRE

biosnoop.bt - Herramienta de rastreo de E/S de bloque, que muestra la latencia por E/S. Utiliza bpftrace/eBPF.

SINOPSIS

biosnoop.bt

DESCRIPCIÓN

Esta es una herramienta básica de rastreo de E/S de bloque (E/S de disco), que muestra cada evento de E/S junto con el ID del proceso que lo emitió y la latencia de la E/S. Esto se puede utilizar para investigar problemas de rendimiento de E/S de disco.

Esta herramienta funciona actualmente mediante el rastreo dinámico de las funciones kernel blk_account*(), que deberán actualizarse para coincidir con cualquier cambio en estas funciones en versiones futuras del kernel.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrea eventos de E/S de bloque, imprimiendo resúmenes por línea:
# biosnoop.bt

CAMPOS

TIEMPO
Tiempo de finalización de la E/S, en milisegundos desde el inicio del programa.
COMM
Nombre del proceso emisor. Esto a menudo identifica el proceso de la aplicación emisora, pero la E/S puede ser iniciada solo por hilos del kernel.
PID
ID del proceso emisor. Esto a menudo identifica el proceso de la aplicación emisora, pero la E/S puede ser iniciada solo por hilos del kernel.
ARGUMENTOS
Nombre y argumentos del proceso (máximo 16 palabras).

SOBRECARGA

Dado que la E/S de los dispositivos de bloque generalmente tiene una frecuencia relativamente baja (< 10.000/s), se espera que la sobrecarga de esta herramienta sea insignificante. Para sistemas de almacenamiento con alta IOPS, pruebe y cuantifique antes de usar.

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

Busque también en la distribución de bpftrace un archivo complementario _examples.txt que contenga ejemplos de uso, salida y comentarios para esta herramienta.

Esta es una versión de bpftrace de la herramienta bcc del mismo nombre. La herramienta bcc proporciona más campos.

https://github.com/iovisor/bcc
