BIO_parse_hostserv(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_PARSE_HOSTSERV(3ssl) OpenSSL BIO_PARSE_HOSTSERV(3ssl)

NOMBRE

BIO_hostserv_priorities, BIO_parse_hostserv - rutinas de utilidad para analizar una cadena estándar de host y servicio

SINOPSIS

#include <openssl/bio.h>
enum BIO_hostserv_priorities {
    BIO_PARSE_PRIO_HOST, BIO_PARSE_PRIO_SERV
};
int BIO_parse_hostserv(const char *hostserv, char **host, char **service,
                       enum BIO_hostserv_priorities hostserv_prio);

DESCRIPCIÓN

BIO_parse_hostserv() analizará la información proporcionada en hostserv, creará cadenas con el nombre de host y el nombre del servicio, y las devolverá a través de host y service. Estas deberán ser liberadas después de su uso. hostserv_prio ayuda a determinar si hostserv debe interpretarse principalmente como un nombre de host o un nombre de servicio en casos ambiguos.

La sintaxis que reconoce BIO_parse_hostserv() es:

host + ':' + servicio
host + ':' + '*'
host + ':'
       ':' + servicio
'*'  + ':' + servicio
host
servicio

La parte del host puede ser un nombre o una dirección IP. Si es una dirección IPv6, DEBE estar entre corchetes, como '[::1]'.

La parte del servicio puede ser un nombre de servicio o su número de puerto. Un nombre de servicio se mapeará a un número de puerto utilizando la función del sistema getservbyname().

Los valores devueltos dependerán de la cadena hostserv dada y de hostserv_prio, de la siguiente manera:

host + ':' + servicio  => *host = "host", *service = "service"
host + ':' + '*'      => *host = "host", *service = NULL
host + ':'            => *host = "host", *service = NULL
       ':' + servicio  => *host = NULL, *service = "service"
 '*' + ':' + servicio  => *host = NULL, *service = "service"
en caso de que no haya ':' en la cadena, el resultado depende de
hostserv_prio, de la siguiente manera:
cuando hostserv_prio == BIO_PARSE_PRIO_HOST
host                 => *host = "host", *service sin cambios
cuando hostserv_prio == BIO_PARSE_PRIO_SERV
servicio              => *host sin cambios, *service = "service"

VALORES DE RETORNO

BIO_parse_hostserv() devuelve 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN
