BN_copy(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_COPY(3ssl) OpenSSL BN_COPY(3ssl)

NOMBRE

BN_copy, BN_dup, BN_with_flags - copiar BIGNUMs

SINOPSIS

#include <openssl/bn.h>
BIGNUM *BN_copy(BIGNUM *to, const BIGNUM *from);
BIGNUM *BN_dup(const BIGNUM *from);
void BN_with_flags(BIGNUM *dest, const BIGNUM *b, int flags);

DESCRIPCIÓN

BN_copy() copia from en to. BN_dup() crea un nuevo BIGNUM que contiene el valor de from.

BN_with_flags crea una copia superficial temporal de b en dest. Impone restricciones significativas en los datos copiados. Las aplicaciones que no cumplan estas restricciones pueden encontrar efectos secundarios inesperados o fallos. Por esta razón, se desaconseja el uso de esta función. Cualquier bandera proporcionada en flags se establecerá en dest además de cualquier bandera que ya esté establecida en b. Por ejemplo, esto podría usarse comúnmente para crear una copia temporal de un BIGNUM con la bandera BN_FLG_CONSTTIME establecida para operaciones de tiempo constante. La copia temporal en dest compartirá algún estado interno con b. Por esta razón se aplican las siguientes restricciones al uso de dest:

  • dest debe ser un BIGNUM recién asignado obtenido mediante una llamada a BN_new(). No debe haberse utilizado para otros propósitos ni haberse inicializado de ninguna manera.
  • dest solo debe usarse en operaciones de "solo lectura", es decir, típicamente aquellas funciones donde el parámetro relevante se declara como "const".
  • dest debe usarse y liberarse antes de cualquier otro uso posterior de b.

VALORES DE RETORNO

BN_copy() devuelve to en caso de éxito, NULL en caso de error. BN_dup() devuelve el nuevo BIGNUM, y NULL en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).
