NOMBRE

batpipe - Un preprocesador de less (y bat) para ver más tipos de archivos en la terminal.

DESCRIPCIÓN

USO

Al igual que lesspipe, batpipe está diseñado para funcionar con programas que admiten el preprocesamiento con la variable de entorno LESSOPEN. La configuración de batpipe dependerá de tu shell:

Bash:


eval "$(batpipe)"

Fish:


eval (batpipe)

ENTORNO

Variable Descripción
BATPIPE_TERM_WIDTH Establece el ancho de terminal proporcionado a bat. Si esta variable comienza con un guion (-), el número proporcionado será relativo al tamaño de terminal detectado.

VISUALIZADORES EXTERNOS

Para formatos de archivo que no son compatibles por defecto, se puede añadir un visualizador de archivos externo a batpipe a través de la API de visualizadores externos.

Los visualizadores externos se añaden a batpipe creando scripts de bash dentro del directorio ~/.config/batpipe/viewers.d/.

Creación de visualizadores

Los visualizadores deben definir dos funciones y añadir el nombre del visualizador al array $BATPIPE_VIEWERS.


- viewer_${visualizador}_supports [nombre_archivo] [ruta_archivo] [ruta_archivo_interno]
- viewer_${visualizador}_process [ruta_archivo] [ruta_archivo_interno]

La función viewer_${visualizador}_supports se llama para determinar si el visualizador externo es capaz de visualizar el archivo proporcionado. Si esta función se completa con éxito, se llamará a la función process correspondiente.

API


$BATPIPE_VIEWERS -- Un array de visualizadores de archivos cargados.
$BATPIPE_ENABLE_COLOR -- Si el color es compatible. (true|false)
$BATPIPE_INSIDE_LESS -- Si batpipe está dentro de less. (true|false)


batpipe_header [patrón] [...] -- Imprime una línea de encabezado del visualizador.
batpipe_subheader [patrón] [...] -- Imprime una línea de subencabezado del visualizador.


strip_trailing_slashes [ruta] -- Elimina las barras diagonales finales de una ruta.

SALVEDADES

- Por defecto, batpipe no utilizará colores cuando se previsualice dentro de less.
Los colores deben habilitarse explícitamente con BATPIPE=color.
