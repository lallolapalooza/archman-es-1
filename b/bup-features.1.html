NOMBRE

bup-features - informa sobre el estado y las capacidades actuales de bup mismo

SINOPSIS

bup features

DESCRIPCIÓN

bup features informa sobre la instalación actual de bup, por ejemplo, qué versión del intérprete de Python se utiliza, si la edición de línea de comandos (en bup ftp) es soportada, o si las ACLs POSIX pueden ser guardadas y restauradas.

EJEMPLOS

$ bup features
bup 0.31~a7ff2d5b8c12b24b97858aad1251d28c18f8c1e1
source a7ff2d5b8c12b24b97858aad1251d28c18f8c1e1 2020-07-05 14:54:06 -0500
    Python: 3.7.3
    Command line editing (e.g. bup ftp): yes
    Saving and restoring POSIX ACLs: yes
....
