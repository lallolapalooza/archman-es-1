ImageByteOrder(3) FUNCIONES DE XLIB ImageByteOrder(3)

NOMBRE

ImageByteOrder, BitmapBitOrder, BitmapPad, BitmapUnit, DisplayHeight, DisplayHeightMM, DisplayWidth, DisplayWidthMM, XListPixmapFormats, XPixmapFormatValues - funciones y macros de formato de imagen

SINTAXIS

XPixmapFormatValues *XListPixmapFormats(Display *display, int *count_return);

int ImageByteOrder(Display *display);

int BitmapBitOrder(Display *display);

int BitmapPad(Display *display);

int BitmapUnit(Display *display);

int DisplayHeight(Display *display, int screen_number);

int DisplayHeightMM(Display *display, int screen_number);

int DisplayWidth(Display *display, int screen_number);

int DisplayWidthMM(Display *display, int screen_number);

ARGUMENTOS

display
Especifica la conexión al servidor X.
count_return
Devuelve el número de formatos de pixmap que son compatibles con la pantalla.
screen_number
Especifica el número de pantalla apropiado en el servidor anfitrión.

DESCRIPCIÓN

La función XListPixmapFormats devuelve una matriz de estructuras XPixmapFormatValues que describen los tipos de imágenes en formato Z compatibles con la pantalla especificada. Si no hay suficiente memoria disponible, XListPixmapFormats devuelve NULL. Para liberar el almacenamiento asignado para las estructuras XPixmapFormatValues, utilice XFree.

La macro ImageByteOrder especifica el orden de bytes requerido para las imágenes para cada unidad de escaneo en formato XY (mapa de bits) o para cada valor de píxel en formato Z.

La macro BitmapBitOrder devuelve LSBFirst o MSBFirst para indicar si el bit más a la izquierda en el mapa de bits tal como se muestra en la pantalla es el bit menos o más significativo de la unidad.

La macro BitmapPad devuelve el número de bits por los que debe rellenarse cada línea de escaneo.

La macro BitmapUnit devuelve el tamaño de la unidad de línea de escaneo de un mapa de bits en bits.

La macro DisplayHeight devuelve la altura de la pantalla especificada en píxeles.

La macro DisplayHeightMM devuelve la altura de la pantalla especificada en milímetros.

La macro DisplayWidth devuelve el ancho de la pantalla en píxeles.

La macro DisplayWidthMM devuelve el ancho de la pantalla especificada en milímetros.

ESTRUCTURAS

La estructura XPixmapFormatValues proporciona una interfaz a la información del formato de pixmap que se devuelve en el momento de la configuración de la conexión. Contiene:

typedef struct {
        int depth;
        int bits_per_pixel;
        int scanline_pad;
} XPixmapFormatValues;
