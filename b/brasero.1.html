BRASERO(1) Manual de Comandos Generales BRASERO(1)

NOMBRE

brasero - Aplicación simple y fácil de usar para grabar CD/DVD para el escritorio Gnome

SINOPSIS

brasero [opciones] [uri] [uri] ...

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando brasero.

Brasero es una aplicación para grabar discos. Está diseñado para ser simple y fácil de usar. Permite crear CD/DVD de datos, CD de audio, copiar CD/DVD y grabar imágenes. Tiene algunas características útiles, como un previsualizador de canciones, imágenes y vídeos. También puede buscar archivos (gracias a beagle) y mostrar una lista de reproducción y su contenido.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que empiezan con dos guiones (`-'). A continuación se incluye un resumen de las opciones. Para una descripción completa, consulte los archivos Info.

-p, --project=PROYECTO
Abre el proyecto especificado.
-a, --audio
Abre un proyecto de audio vacío.
-d, --data
Abre un proyecto de datos vacío.
-c, --copy=RUTA
Copia un disco.
-j, --cover=RUTA
Portada a utilizar.
-o, --video
Abre un proyecto de vídeo añadiendo las URIs dadas en la línea de comandos.
-i, --image=RUTA
URI de un archivo de imagen o archivo cue para grabar (autodetectado).
-e, --empty
Fuerza a brasero a mostrar la página de selección de proyecto.
-b, --blank
Abre el diálogo para vaciar disco.
-k, --check
Abre el diálogo para comprobar disco.
-n, --ncb
Abre un proyecto de datos con el contenido de la URI burn:///.
-r, --burn-and-remove-project=RUTA
Graba el proyecto especificado y lo ELIMINA.
--display=DISPLAY
Pantalla X a utilizar.
-?, --help
Muestra un resumen de las opciones.
