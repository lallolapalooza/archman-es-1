BITS(1) Comandos de usuario BITS(1)

NOMBRE

bits - convertir máscaras de bits de/a varios formatos

SINOPSIS

bits [-h] [-V] [-w <NÚM>] [<MODO>] [<MASCARA_O_LISTA>...]

DESCRIPCIÓN

La utilidad bits convierte máscaras de bits a varios formatos. Admite la combinación de múltiples máscaras mediante operaciones bit a bit.

ARGUMENTOS POSICIONALES

<MASCARA_O_LISTA>

Un conjunto de bits especificado como valor de máscara hexadecimal (por ejemplo, 0xeec2) o como una lista de IDs de bits separados por comas.

Si no se especifica ningún argumento, los conjuntos de bits se leerán de la entrada estándar; un grupo por línea.

Los IDs consecutivos se pueden comprimir como rangos (por ejemplo, 5,6,7,8,9,10 → 5-10).

Opcionalmente, si un argumento comienza con una coma, se analizará como una única máscara hexadecimal dividida en grupos de 32 bits (por ejemplo, ,00014000,00000000,00020000 → 17,78,80).

Por defecto, todos los grupos se combinarán mediante una operación OR. Si un grupo tiene uno de los siguientes prefijos, se combinará con la máscara resultante utilizando una operación binaria diferente:

&<MASCARA_O_LISTA>

El grupo se combinará con una operación AND binaria. Es decir, todos los bits que sean 1 en el grupo Y en los grupos combinados hasta el momento se conservarán como 1. Todos los demás bits se establecerán a 0.

^<MASCARA_O_LISTA>

El grupo se combinará con una operación XOR binaria. Es decir, todos los bits que sean 1 en el grupo Y 0 en los grupos combinados hasta el momento (o viceversa) se establecerán a 1. Los bits que sean ambos 1 o ambos 0 se establecerán a 0.

~<MASCARA_O_LISTA>

Todos los bits establecidos en 1 en el grupo se borrarán (establecerán a 0) en los grupos combinados hasta el momento.

OPCIONES

-w <NÚM>, --width <NÚM>

Número máximo de bits en las máscaras manejadas por bits (por defecto 8192). Cualquier bit mayor que este número será truncado.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar versión y salir.

MODO DE CONVERSIÓN

Se puede especificar uno de los siguientes modos de conversión. Si no se especifica, por defecto es -m, --mask.

-m, --mask

Imprimir los argumentos combinados como un valor de máscara hexadecimal (por defecto).

-g, --grouped-mask

Imprimir los argumentos combinados como un valor de máscara hexadecimal en grupos de 32 bits separados por comas.

-b, --binary

Imprimir los argumentos combinados como un valor de máscara binario.

-l, --list

Imprimir los argumentos combinados como una lista de IDs de bits. Los IDs consecutivos se comprimen como rangos.

EJEMPLOS

~$ bits --mask 4,5-8 16,30
0x400101f0
~$ bits --list 0xeec2
1,6,7,9-11,13-15
~$ bits --binary 4,5-8 16,30
0b100_0000_0000_0001_0000_0001_1111_0000
~$ bits --list ,00300000,03000000,30000003
0,1,28,29,56,57,84,85
~$ bits --list 1,2,3,4 ~3-10
1,2
~$ bits --list 1,2,3,4 ^3-10
1,2,5-10
~$ bits --grouped-mask 2,22,74,79
8400,00000000,00400004
~$ bits --width 64 --list 2,22,74,79
2,22
