BUNDLE-PLUGIN(1) Manual de comandos generales BUNDLE-PLUGIN(1)

NOMBRE

bundle-plugin - Gestionar plugins de Bundler

SINOPSIS

bundle plugin install PLUGINS [--source=SOURCE] [--version=VERSION] [--git=GIT] [--branch=BRANCH|--ref=REF] [--local-git=LOCAL_GIT] [--path=PATH]
bundle plugin uninstall PLUGINS [--all]
bundle plugin list
bundle plugin help [COMMAND]

DESCRIPCIÓN

Puedes instalar, desinstalar y listar plugin(s) con este comando para extender las funcionalidades de Bundler.

SUB-COMANDOS

install

Instala el/los plugin(s) dados.

Por ejemplo, bundle plugin install bundler-graph instalará el gem bundler-graph desde las fuentes configuradas globalmente (por defecto RubyGems.org). Ten en cuenta que la fuente global especificada en Gemfile se ignora.

OPCIONES

--source=SOURCE
Instala el gem del plugin desde una fuente específica, en lugar de las fuentes configuradas globalmente.
Ejemplo: bundle plugin install bundler-graph --source https://example.com
--version=VERSION
Especifica una versión del gem del plugin a instalar mediante --version.
Ejemplo: bundle plugin install bundler-graph --version 0.2.1
--git=GIT
Instala el gem del plugin desde un repositorio Git. Puedes usar URLs Git estándar como:
ssh://[user@]host.xz[:port]/path/to/repo.git
http[s]://host.xz[:port]/path/to/repo.git
/path/to/repo
file:///path/to/repo
Ejemplo: bundle plugin install bundler-graph --git https://github.com/rubygems/bundler-graph
--branch=BRANCH
Cuando especificas --git, puedes usar --branch para usar.
--ref=REF
Cuando especificas --git, puedes usar --ref para especificar cualquier etiqueta o hash de commit (revisión) a usar.
--path=PATH
Instala el gem del plugin desde una ruta local.
Ejemplo: bundle plugin install bundler-graph --path ../bundler-graph
--local-git=LOCAL_GIT
Instala el gem del plugin desde un repositorio Git local.
Ejemplo: bundle plugin install bundler-graph --local-git ../bundler-graph.
Esta opción está obsoleta en favor de --git.

uninstall

Desinstala el/los plugin(s) especificados en PLUGINS.

OPCIONES

--all
Desinstala todos los plugins instalados. Si no hay ningún plugin instalado, entonces no hace nada.

list

Lista los plugins instalados y los comandos disponibles.

Sin opciones.

help

Describe subcomandos o un subcomando específico.

Sin opciones.
