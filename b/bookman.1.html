NOMBRE

bookman - Genera un libro a partir de páginas man

SINOPSIS

bookman [-pPxn] [-o archivo_salida] [-a autor] [-d fecha] [-r release]
[-t titulo] [-v volumen] [-c archivo_portada] [archivo_man]

DESCRIPCIÓN

bookman compila un conjunto de archivos de páginas man especificados por los argumentos archivo_man, o si no se proporciona archivo_man, los nombres de archivo se leen de la entrada estándar.

OPCIONES

-p
Formato de salida PDF.
-P
Formato de salida Postscript.
-x
Vista previa X11, utilizando gxditview(1).
-n
Sin formato, la salida es formato intermedio directo de gtroff.
-o archivo_salida
Salida en el archivo archivo_salida. El valor predeterminado es la salida estándar.
-a autor
Establece el autor, en la página de portada.
-d fecha
Establece la fecha en la página de portada.
-r release
Establece el nombre del libro y la release en la página de portada.
-t titulo
Establece el título en la página de portada.
-v volumen
Especifica el nombre del volumen.
-c archivo_portada
Utiliza el archivo archivo_portada para generar la página de portada, es decir, todas las páginas que preceden al índice. archivo_portada debe estar en formato groff_ms(7).

AMBIENTE

SOURCE_DATE_EPOCH
Marca de tiempo Unix que se utiliza para la fecha en la cabecera en lugar de la fecha actual.

EJEMPLO

Para construir un manual de referencia de la sección 2 de man, haz:

    $ cd /usr/share/man/man2
    $ bookman -p -t 'Manual de Referencia de Unix' * >libro.pdf

VER TAMBIÉN

man(1), mandoc(7), groff_ms(7), groff(1), troff(1), grops(1), gxditview(1), ps2pdf(1).
