DESCRIPCIÓ

N
bpftool btf { show | list } [id BTF_I
D]
Muestra información sobre los objetos BTF cargados. Si se especifica un ID de BTF, muestra información solo sobre el objeto BTF dado; de lo contrario, lista todos los objetos BTF actualmente cargados en el sistema.

Desde Linux 5.8, bpftool es capaz de descubrir información sobre proces

os que mantienen descriptores de archivo (FDs) abiertos contra objetos BTF. En
esos kernels, bpftool emitirá automáticamente esta información también.
bpftool btf dump BTF_SRC [format FORMAT] [root_id ROOT_I
D]
Volca las entradas BTF de un BTF_SRC dado.

Cuando se especifica id, el objeto BTF con ese ID será cargado y todos sus tipos BTF

emitidos.

Cuando se proporciona map, se espera que el mapa tenga un objeto BTF asociado con tipos BTF que describan la clave y el valor. Es posible seleccionar si volcar solo el tipo(s) BTF asociado con la clave (key), el valor (value), tanto la clave como el valor (kv), o todos los tipos BTF presentes en el objeto BTF asociado (all). Si no se especifica, se asume

kv.

Cuando se proporciona prog, se espera que el programa tenga un objeto BTF asociado con tipos

BTF.

Al especificar FILE, se espera un archivo ELF, que contenga la sección .BTF con datos en formato binario BTF bien definido, típicamente producido por clang o

pahole.

La opción format se puede usar para anular el formato de salida predeterminado (raw). Se admiten los formatos de salida Raw (raw) o de sintaxis C (c). Con el formato de estilo C, la salida se ordena de forma predeterminada. Use la opción unsorted para evitar ordenar la

salida.

La opción root_id se puede usar para filtrar un volcado a un solo tipo y todos sus tipos dependientes. No se puede usar con ningún otro tipo

de filtrado (como los argumentos "key", "value" o "kv" al volcar BTF p
ara un mapa). Se puede pasar varias veces para volcar múltiples tipos.

OPCIONE

S
-h, --hel
p
Imprime un mensaje de ayuda corto (similar a bpftool help)
.
-V, --versi
on
Imprime el número de versión de bpftool (similar a bpftool version), el número de la versión de libbpf en uso y las características opcionales que se incluyeron cuando se compiló bpftool. Las características opcionales incluyen la vinculación con LLVM o libbfd para proporcionar el desensamblador para programas JIT (bpftool prog dump jited) y el uso de esqueletos BPF (algunas características como bpftool prog profile o mostrar los pids asociados a objetos BTF pueden depender de ello)
.
-j, --jso
n
Genera salida JSON. Para comandos que no pueden producir JSON, esta opción no tiene
efecto.
-p, --pret
ty
Genera salida JSON legible para humanos. Implica -j
.
-d, --debu
g
Imprime todos los registros disponibles, inclu
so información de nivel de depuración. Esto in
cluye registros de libbpf así como del ve
rificador, al intentar cargar programas.
-B, --base-btf FI
LE
Pasa un objeto BTF base. Los objetos BTF base se usan típicamente con objetos BTF para módulos del kernel. Para evitar duplicar todos los símbolos del kernel requeridos por los módulos, los objetos BTF para módulos están "divididos", se construyen incrementalmente sobre el objeto BTF del kernel (vmlinux). Por lo tanto, la referencia BTF base debería apuntar normalmente al BTF del kernel.

Cuando el objeto BTF principal a procesar (por ejemplo, el módulo BTF a volcar) se pasa como un FILE, bpftool intenta autodetectar la ruta para el ob

jeto base, y pasar esta opción
es opcional. Cuando el objeto B
TF principal se pasa a través d
e otros manejadores, esta opci
ón se vuelve necesaria.
