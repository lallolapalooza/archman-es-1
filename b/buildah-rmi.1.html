NOMBRE

buildah-rmi - Elimina una o más imágenes.

SINOPSIS

buildah rmi [imagen ...]

DESCRIPCIÓN

Elimina una o más imágenes almacenadas localmente. Pasar un argumento imagen la elimina, junto con cualquiera de sus imágenes padre pendientes (sin etiqueta).

LIMITACIONES

  • Si la imagen se subió a una ruta de directorio usando el transporte 'dir:', el comando rmi no puede eliminar la imagen. En su lugar, se deben usar los comandos del sistema de archivos estándar.
  • Si imageID es un nombre, pero no incluye un nombre de registro, buildah intentará encontrar y eliminar la imagen con el nombre usando el nombre de registro localhost. Si no se encuentra tal imagen, buscará la imagen deseada intentando expandir el nombre dado utilizando los nombres de los registros proporcionados en el archivo de configuración de registros del sistema, registries.conf.
  • Si el imageID se refiere a una lista de manifiestos o a un índice de imágenes, ¡este comando no hará lo que espera! Este comando eliminará las imágenes asociadas con la lista de manifiestos o el índice (no la lista de manifiestos/índice de imágenes en sí). Para eliminar eso, use en su lugar el subcomando buildah manifest rm.

OPCIONES

--all, -a

Se eliminarán todas las imágenes locales del sistema que no tengan contenedores que utilicen la imagen como imagen de referencia. No se puede proporcionar un nombre o ID de imagen cuando se utiliza esta opción. Las imágenes de solo lectura configuradas modificando "additionalimagestores" en el archivo /etc/containers/storage.conf, no se pueden eliminar.

--force, -f

Esta opción hará que Buildah elimine todos los contenedores que estén utilizando la imagen antes de eliminar la imagen del sistema.

--prune, -p

Se eliminarán todas las imágenes locales del sistema que no tengan etiqueta y no tengan una imagen hija que apunte a ellas. No se puede proporcionar un nombre o ID de imagen cuando se utiliza esta opción.

EJEMPLO

buildah rmi imageID

buildah rmi --all

buildah rmi --all --force

buildah rmi --prune

buildah rmi --force imageID

buildah rmi imageID1 imageID2 imageID3

Archivos

registries.conf (/etc/containers/registries.conf)

registries.conf es el archivo de configuración que especifica qué registros de contenedores se deben consultar al completar nombres de imágenes que no incluyen un registro o una porción de dominio.

storage.conf (/etc/containers/storage.conf)

storage.conf es el archivo de configuración de almacenamiento para todas las herramientas que utilizan containers/storage

El archivo de configuración de almacenamiento especifica todas las opciones de almacenamiento de contenedores disponibles para las herramientas que utilizan almacenamiento de contenedores compartido.
