NOMBRE

bup-on - ejecuta un servidor bup localmente y un cliente remotamente

SINOPSIS

bup on <nombre_host> index ...

bup on <nombre_host> save ...

bup on <nombre_host> split ...

bup on <nombre_host> get ...

DESCRIPCIÓN

bup on ejecuta el comando bup dado en el host especificado usando ssh. Ejecuta un servidor bup en la máquina local, de modo que comandos como bup save en la máquina remota puedan hacer copias de seguridad en la máquina local. (No necesita proporcionar una opción --remote a bup save para que esto funcione).

Consulte bup-index(1), bup-save(1), etc., para obtener detalles sobre cómo funciona cada subcomando.

Esta operación en 'modo inverso' es útil cuando la máquina que se está respaldando no debe poder iniciar sesión por ssh en el servidor de copias de seguridad. Por ejemplo, su servidor de copias de seguridad puede estar oculto detrás de un cortafuegos unidireccional en una dirección IP privada o dinámica; utilizando una clave ssh, puede ser autorizado para iniciar sesión por ssh en cada una de sus máquinas importantes. Después de conectarse a cada máquina de destino, inicia una copia de seguridad, recibiendo los datos resultantes y almacenándolos en su repositorio local.

Por ejemplo, si ejecuta varias máquinas virtuales Linux privadas en un proveedor de alojamiento remoto, podría respaldarlas en un ordenador local (mucho más económico) en su sótano.

EJEMPLOS

# Primero indexar los archivos en el servidor remoto
$ bup on myserver index -vux /etc
bup server: reading from stdin.
Indexing: 2465, done.
bup: merging indexes (186668/186668), done.
bup server: done
# Ahora guardar los archivos del servidor remoto en
# el directorio local $BUP_DIR
$ bup on myserver save -n myserver-backup /etc
bup server: reading from stdin.
bup server: command: 'list-indexes'
PackIdxList: using 7 indexes.
Saving: 100.00% (241/241k, 648/648 files), done.    
bup server: received 55 objects.
Indexing objects: 100% (55/55), done.
bup server: command: 'quit'
bup server: done
# Ahora podemos examinar el repositorio resultante en la
# máquina local
$ bup ftp 'cat /myserver-backup/latest/etc/passwd'
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/bin/sh
bin:x:2:2:bin:/bin:/bin/sh
sys:x:3:3:sys:/dev:/bin/sh
sync:x:4:65534:sync:/bin:/bin/sync
...
