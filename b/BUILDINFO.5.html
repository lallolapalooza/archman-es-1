BUILDINFO(5) Manual de Pacman BUILDINFO(5)

NOMBRE

BUILDINFO - Archivo de información de compilación de paquetes de Makepkg

SINOPSIS

Esta página del manual describe el formato de un archivo BUILDINFO que se encuentra en la raíz de un paquete creado por makepkg. El archivo contiene una descripción del entorno de compilación del paquete. La información está formateada en pares clave-valor separados por un =, un valor por línea. Los arreglos se representan con múltiples claves con el mismo valor.

DESCRIPCIÓN

Esta es una descripción del contenido de la versión 2 del formato de archivo BUILDINFO.

format

Denota la versión del formato del archivo, representada por un entero positivo simple.

pkgname

El nombre del paquete.

pkgbase

El nombre base de un paquete, generalmente el mismo que el pkgname excepto en el caso de paquetes divididos.

pkgver

La versión del paquete, incluyendo pkgrel y epoch.

pkgarch

La arquitectura del paquete.

pkgbuild_sha256sum

La suma sha256 en formato hexadecimal del PKGBUILD utilizado para compilar el paquete.

packager

Los detalles del empaquetador que compiló el paquete.

builddate

La fecha de compilación del paquete en formato epoch.

builddir

El directorio donde se compiló el paquete.

startdir

El directorio desde el cual se ejecutó makepkg.

buildtool

El nombre del ecosistema de herramientas utilizado para configurar el entorno de compilación. Se utiliza para definir una especificación para compilaciones reproducibles, por ejemplo, la fuente del makepkg.conf(5) utilizado.

buildtoolver

La versión completa de buildtool, por ejemplo: "$pkgver-$pkgrel-$pkgarch".

buildenv (array)

El entorno de compilación especificado en makepkg.conf.

options (array)

Las opciones configuradas especificadas al compilar el paquete.

installed (array)

Los paquetes instalados en el momento de la compilación, incluyendo la información de versión del paquete. Formateado como "$pkgname-$pkgver-$pkgrel-$pkgarch".

VER TAMBIÉN

makepkg(8), pacman(8), makepkg.conf(5)

Consulte el sitio web de pacman en https://archlinux.org/pacman/ para obtener información actualizada sobre pacman y sus herramientas relacionadas.
