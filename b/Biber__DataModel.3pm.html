Biber::DataModel(3pm) Documentación de Perl aportada por el usuario Biber::DataModel(3pm)

NOMBRE

Biber::DataModel - Objetos Biber::DataModel

new

Inicializa un objeto Biber::DataModel
Se pasa una matriz de modelos de datos ya que puede haber más de uno en el
modo herramienta - el de biber-tool.conf y las modificaciones en un .conf
de usuario
Primero fusionamos estos antes de extraer datos. En caso de conflictos, el
modelo de datos del .conf de usuario tiene prioridad.

get_outcase

Devuelve el modelo de datos original de campo/tipo de entrada para la salida

constants

Devuelve una referencia a matriz de nombres de constantes

get_constant_type

Devuelve un tipo de constante

get_constant_value

Devuelve un valor de constante

is_multiscript

Devuelve un booleano para indicar si un campo es un campo multiscript

fieldtypes

Devuelve una referencia a matriz de tipos de campo legales

datatypes

Devuelve una referencia a matriz de tipos de datos legales

is_field

Devuelve un booleano para indicar si un campo es un campo legal.
Permite campos con marcadores meta cuyo campo marcado debería estar en
el modelo de datos.

entrytypes

Devuelve una referencia a matriz de tipos de entrada legales

is_entrytype

Devuelve un booleano para indicar si un tipo de entrada es un tipo de entrada legal

is_field_for_entrytype

Devuelve un booleano para indicar si un campo es legal para un tipo de entrada

entrytype_is_skipout

Devuelve un booleano dependiendo de si un tipo de entrada debe omitirse en la salida

get_fields_of_fieldtype

Recupera campos de un cierto tipo de campo biblatex del modelo de datos
Devuelve en orden ordenado para que el orden bbl no cambie al cambiar
.bcf. De lo contrario, esto arruina las pruebas.

get_fields_of_fieldformat

Recupera campos de un cierto formato del modelo de datos
Devuelve en orden ordenado para que el orden bbl no cambie al cambiar
.bcf. De lo contrario, esto arruina las pruebas.

get_fields_of_datatype

Recupera campos de un cierto tipo de datos biblatex del modelo de datos
Devuelve en orden ordenado para que el orden bbl no cambie al cambiar
.bcf. De lo contrario, esto arruina las pruebas.

get_fields_of_type

Recupera campos de un cierto tipo biblatex del modelo de datos
Devuelve en orden ordenado para que el orden bbl no cambie al cambiar
.bcf. De lo contrario, esto arruina las pruebas.

is_fields_of_type

Devuelve un booleano para indicar si la combinación de tipo de campo/tipo de datos/formato dada es válida

get_fieldtype

Devuelve el tipo de campo de un campo

get_datatype

Devuelve el tipo de datos de un campo

get_fieldformat

Devuelve el formato de un campo

get_dm_for_field

Devuelve el tipo de campo, tipo de datos y formato de un campo

field_is_fieldtype

Devuelve un booleano dependiendo de si un campo es un cierto tipo de campo biblatex

field_is_datatype

Devuelve un booleano dependiendo de si un campo es un cierto tipo de datos biblatex

field_is_type

Devuelve un booleano dependiendo de si un campo es un cierto tipo de campo biblatex
y tipo de datos

field_is_nullok

Devuelve un booleano dependiendo de si un campo puede ser nulo

field_is_skipout

Devuelve un booleano dependiendo de si un campo debe omitirse en la salida

check_mandatory_constraints

Comprueba restricciones de tipo "mandatory" en la entrada y
devuelve una matriz de advertencias, si las hay

check_conditional_constraints

Comprueba restricciones de tipo "conditional" en la entrada y
devuelve una matriz de advertencias, si las hay

check_data_constraints

Comprueba restricciones de tipo "data" en la entrada y
devuelve una matriz de advertencias, si las hay

check_datatypes

Comprueba los tipos de datos de los campos contra los campos. Estas no son restricciones explícitas
en el modelo de datos, sino comprobaciones del tipo de datos de los campos en el modelo de datos.

dump

Vuelca el objeto Biber::DataModel

generate_bltxml_schema

Genera un esquema XML RelaxNG a partir del modelo de datos para fuentes de datos BibLaTeXML

generate_bblxml_schema

Genera un esquema XML RelaxNG a partir del modelo de datos para la salida bblXML
