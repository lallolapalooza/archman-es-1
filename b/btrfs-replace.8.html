NOMBRE

btrfs-replace - reemplaza dispositivos gestionados por btrfs con otros dispositivos

SINOPSIS

btrfs replace <subcomando> <argumentos>

DESCRIPCIÓN

btrfs replace se utiliza para reemplazar dispositivos gestionados por btrfs con otros dispositivos.

SUBCOMANDO

cancel <punto_de_montaje>
Cancela una operación de reemplazo de dispositivo en curso.
start [opciones] <dev_origen>|<id_disp> <dev_destino> <ruta>
Reemplaza un dispositivo de un sistema de archivos btrfs.

En un sistema de archivos en vivo, duplica los datos al dispositivo de destino que actualmente están en el dispositivo de origen. Si el dispositivo de origen ya no está disponible, o si se establece la opción -r, los datos se construyen solo utilizando los mecanismos de redundancia RAID. Después de completar la operación, el dispositivo de origen se elimina del sistema de archivos. Si el dev_origen es un valor numérico, se asume que es el ID del dispositivo del sistema de archivos que está montado en ruta, de lo contrario, es la ruta al dispositivo de origen. Si el dispositivo de origen está desconectado del sistema, deberá usar el formato de parámetro id_disp. El dev_destino debe ser del mismo tamaño o mayor que el dev_origen.

Nota:

El sistema de archivos debe redimensionarse para aprovechar completamente un dispositivo de destino más grande; esto se puede lograr con btrfs filesystem resize <id_disp>:max /ruta

Nota:

El reemplazo de dispositivo puede ser interrumpido por varios eventos después del kernel v6.19, incluyendo, entre otros, la suspensión/hibernación de la gestión de energía, la congelación del sistema de archivos, la congelación de cgroup (utilizada por systemd para la congelación de slices) y las señales pendientes.

El reemplazo de dispositivo en curso se cancelará después de dicha interrupción, y el usuario final deberá reiniciar el reemplazo de dispositivo desde el principio.

Por lo tanto, se recomienda inhibir la suspensión/hibernación antes de ejecutar la operación de reemplazo de dispositivo.

Opciones

-r
lee solo de dev_origen si no existe otro espejo libre de errores. (activa esto si tu disco tiene muchos errores de lectura, el acceso sería muy lento)
-f
fuerza el uso y la sobrescritura de dev_destino incluso si parece contener un sistema de archivos btrfs válido.

Se asume un sistema de archivos válido si se encuentra una superbloque de btrfs que contiene una suma de verificación correcta. Los dispositivos que están actualmente montados nunca se permiten usar como dev_destino.

-B
sin reemplazo en segundo plano.
--enqueue
espera si hay otra operación exclusiva en curso, de lo contrario continúa
-K|--nodiscard
No realiza la operación TRIM de disco completo en dispositivos que son capaces de ello. Esto no afecta a la operación de descarte/trim cuando el sistema de archivos está montado. Por favor, consulte la opción de montaje discard para eso en btrfs(5) <>.
status [-1] <punto_de_montaje>
Muestra el estado y la información de progreso de una operación de reemplazo de dispositivo en curso.

Opciones

-1
muestra una vez en lugar de mostrar continuamente hasta que la operación de reemplazo finalice (o se cancele)

EJEMPLOS

Reemplazando un disco en línea con uno más grande

Dado el siguiente sistema de archivos montado en /mnt/my-vault

Etiqueta: 'MyVault'  uuid: ae20903e-b72d-49ba-b944-901fc6d888a1
        Total de dispositivos 2 bytes del sistema de archivos usados 1TiB
        id_disp    1 tamaño 1TiB usado 500.00GiB ruta /dev/sda
        id_disp    2 tamaño 1TiB usado 500.00GiB ruta /dev/sdb

Para reemplazar /dev/sda (id_disp 1) con un disco más grande ubicado en /dev/sdc, ejecutaría lo siguiente:

btrfs replace start 1 /dev/sdc /mnt/my-vault/

Puede monitorear el progreso a través de:

btrfs replace status /mnt/my-vault/

Después de que el reemplazo se complete, según la documentación en btrfs-filesystem(8) <>, para usar todo el espacio de almacenamiento del nuevo disco, necesita ejecutar:

btrfs filesystem resize 1:max /mnt/my-vault/

ESTADO DE SALIDA

btrfs replace devuelve un estado de salida cero si tiene éxito. Se devuelve un valor distinto de cero en caso de error.

DISPONIBILIDAD

btrfs es parte de btrfs-progs. Consulte la documentación en https://btrfs.readthedocs.io.

VER TAMBIÉN
