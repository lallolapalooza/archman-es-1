NOMBRE

bup-gc - elimina datos no referenciados y no necesarios

SINOPSIS

bup gc [-#|--verbose] <rama|guardado...>

DESCRIPCIÓN

bup gc elimina (borra permanentemente) los datos inalcanzables del repositorio, datos que no están referenciados directa o indirectamente por el conjunto actual de ramas (conjuntos de copias de seguridad) y etiquetas. Pero ten en cuenta que, dada la deduplicación, eliminar un guardado y ejecutar el recolector de basura podría o no eliminar algo (o recuperar espacio).

Con la implementación actual, probabilística, es posible que se retenga una fracción de los datos inalcanzables. A cambio, la recolección de basura debería requerir menos RAM de la que podrían requerir otros enfoques más precisos.

Normalmente, el recolector de basura se invocaría después de una serie de invocaciones de bup rm.

ADVERTENCIA: Este es uno de los pocos comandos de bup que modifica tu archivo de forma intencionalmente destructiva. Sin embargo, si un intento de unir o restaurar los datos que aún te importan después de un gc tiene éxito, es una señal bastante alentadora de que los comandos funcionaron correctamente. (El comando dev/compare-trees en el árbol de fuentes puede usarse para ayudar a probar los resultados antes y después.)

OPCIONES

--umbral=N
solo reescribe un archivo de paquete si tiene más del N por ciento de basura y no contiene árboles o confirmaciones inalcanzables. El umbral predeterminado es 10%.
-v, --verbose
aumenta la verbosidad (se puede usar más de una vez). Con un -v, bup imprime cada nombre de directorio a medida que se respalda. Con dos -v, también imprime cada nombre de archivo.
-#, --compress=#
establece el nivel de compresión en # (un valor de 0 a 9, donde 9 es el más alto y 0 es sin compresión). El predeterminado es 1 (compresión rápida y laxa).
--ignorar-faltantes
informa sobre objetos faltantes, pero no detiene la recolección.

ESTADO DE SALIDA

El estado de salida será distinto de cero si hubo algún error. Encontrarse con cualquier objeto faltante se considera un error.

EJEMPLOS

# Elimina todos los guardados de "home" y la mayor parte de los datos no referenciados de otra manera.
$ bup rm home
$ bup gc
