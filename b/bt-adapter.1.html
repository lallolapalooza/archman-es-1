NOMBRE

bt-adapter - un gestor de adaptadores Bluetooth

SINOPSIS

bt-adapter [OPCIÓN...]

Opciones de ayuda:
-h, --help

Opciones de la aplicación:
-l, --list
-a, --adapter=<nombre|mac>
-i, --info
-d, --discover
--set <propiedad> <valor>

DESCRIPCIÓN

Esta utilidad se utiliza para gestionar adaptadores Bluetooth. Puede listar todos los adaptadores disponibles, mostrar información sobre un adaptador, cambiar las propiedades del adaptador o descubrir dispositivos remotos.

OPCIONES

-h, --help
Muestra la ayuda

-l, --list
Lista todos los adaptadores disponibles

-a, --adapter <nombre|mac>
Especifica el adaptador a utilizar por su Nombre o dirección MAC
(si esta opción no está definida, se utiliza el adaptador por defecto)

-i, --info
Muestra información sobre el adaptador (devuelve todas las propiedades)

-d, --discover
Descubre dispositivos remotos (con resolución de nombres de dispositivos remotos)

--set <propiedad> <valor>
Cambia las propiedades del adaptador (ver la sección PROPIEDADES DEL ADAPTADOR para la lista
de propiedades disponibles)

PROPIEDADES DEL ADAPTADOR

string Address [ro]
La dirección del adaptador Bluetooth (MAC).

string Alias [rw]
El nombre amigable del adaptador Bluetooth.

uint32 Class [ro]
La clase del dispositivo Bluetooth.

boolean Powered [rw]
Enciende o apaga un adaptador. Esto también establecerá el
estado conectable apropiado.

boolean Discoverable [rw]
Cambia un adaptador a descubrible o no descubrible
para hacerlo visible u ocultarlo.

Si el DiscoverableTimeout se establece en un valor distinto de cero,
entonces el sistema volverá a establecer este valor en
falso después de que expire el temporizador.
En caso de que el adaptador se apague, el establecimiento de este
valor fallará.

boolean Pairable [rw]
Cambia un adaptador a emparejable o no emparejable.

Tenga en cuenta que esta propiedad solo afecta a las solicitudes
de emparejamiento entrantes.

uint32 PaireableTimeout [rw]
El tiempo de espera de emparejamiento en segundos. Un valor de cero
significa que el tiempo de espera está deshabilitado y permanecerá en
modo emparejable para siempre.

uint32 DiscoverableTimeout [rw]
El tiempo de espera de descubrible en segundos. Un valor de cero
significa que el tiempo de espera está deshabilitado y permanecerá en
modo descubrible/limitado para siempre.

El valor predeterminado para el tiempo de espera de descubrible debería
ser 180 segundos (3 minutos).

boolean Discovering [ro]
Indica que un procedimiento de descubrimiento de dispositivos está activo.

list UUIDs [ro]
Lista de UUIDs de 128 bits que representan los servicios locales disponibles.
