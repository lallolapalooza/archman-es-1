int LIBMTP_Check_Capability (LIBMTP_mtpdevice_t * device, LIBMTP_devicecap_t cap)

Esta función comprueba si el dispositivo tiene ciertas capacidades, para evitar llamar a APIs que puedan perturbar el dispositivo.

Parámetros

device un puntero al dispositivo sobre el que comprobar la capacidad.
cap la capacidad a comprobar.

Devoluciones

0 si no se admite, cualquier otro valor significa que el dispositivo tiene la capacidad solicitada.

Referencias a LIBMTP_DEVICECAP_CopyObject, LIBMTP_DEVICECAP_EditObjects, LIBMTP_DEVICECAP_GetPartialObject, LIBMTP_DEVICECAP_MoveObject, LIBMTP_DEVICECAP_SendPartialObject y LIBMTP_mtpdevice_struct::params.

int LIBMTP_Check_Specific_Device (int busno, int devno)

Comprueba si un dispositivo específico con un determinado número de bus y dispositivo tiene un descriptor de dispositivo tipo MTP.

Parámetros

busno el número de bus del dispositivo a comprobar
devno el número de dispositivo a comprobar

Devoluciones

1 si el dispositivo es MTP, de lo contrario 0
