DESCRIPCIÓ

N

El comando rep-create regenera el archivo packages.manifest basándose en los archivos presentes en el directorio del repositorio. Si el archivo repositories.manifest contiene un certificado, entonces el archivo signature.manifest se regenera también. En este caso la opción --key debe usarse para especificar la clave privada del certificado. Si dir no se especifica, entonces se usa el directori

o de trabajo actual c
omo raíz del repositorio.

Aplicar soluciones de compatibilidad hacia atrás al archivo packages.manifest generado para que pueda ser consumido por versiones de bpkg mayores o iguales a la versión especificada.
