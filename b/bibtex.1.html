NOMBRE

bibtex - crear una bibliografía para (La)TeX

SINOPSIS

bibtex [-min-crossrefs=número] [-terse] nombreaux[.aux]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo de información o en el manual Web2C: Una implementación de TeX.

BibTeX lee el archivo auxiliar (.aux) de nivel superior nombreaux que se generó al ejecutar latex(1) o tex(1) y crea un archivo de bibliografía (.bbl) que se incorporará al documento en ejecuciones posteriores de LaTeX o TeX.

BibTeX busca, en los archivos de base de datos bibliográfica (.bib) especificados por el comando \bibliography, las entradas especificadas por los comandos \cite y \nocite en el archivo fuente de LaTeX o TeX. Formatea la información de esas entradas según las instrucciones de un archivo de estilo bibliográfico (.bst) (especificado por el comando \bibliographystyle, y vuelca los resultados al archivo .bbl.

El manual de LaTeX explica qué debe contener un archivo fuente de LaTeX para funcionar con BibTeX. El apéndice B del manual describe el formato de los archivos .bib. El documento `BibTeXing' describe las extensiones y detalles de este formato, y proporciona otros consejos útiles para usar BibTeX.

OPCIONES

La opción -min-crossrefs define el número mínimo de crossref requeridos para la inclusión automática de la entrada base de crossref en la lista de citas; el valor predeterminado es dos. Para evitar estas inclusiones automáticas por completo, proporcione a esta opción un número suficientemente grande y asegúrese de eliminar cualquier archivo .aux y .bbl anterior. De lo contrario, la opción puede parecer no tener efecto, ya que BibTeX habrá agregado la cita para la entrada base al archivo .aux, y nada la eliminará.

Con la opción -terse, BibTeX opera silenciosamente. Sin ella, se imprimen un banner y reportes de progreso en stdout.

ENTORNO

BibTeX busca en los directorios de la ruta definida por la variable de entorno BSTINPUTS los archivos .bst. Si BSTINPUTS no está configurada, utiliza la predeterminada del sistema. Para los archivos .bib, utiliza la variable de entorno BIBINPUTS si está configurada, de lo contrario, la predeterminada. Consulte tex(1) para obtener detalles sobre la búsqueda.

Si la variable de entorno TEXMFOUTPUT está configurada, BibTeX intenta colocar sus archivos de salida en ella, si no se pueden colocar en el directorio actual. Nuevamente, consulte tex(1). No se realiza ninguna búsqueda especial para el archivo .aux.

ARCHIVOS

*.bst
Archivos de estilo de bibliografía.
btxdoc.tex
``BibTeXing'' - Documentación para LaTeX para usuarios generales de BibTeX
btxhak.tex
``Diseño de estilos BibTeX'' - Documentación para LaTeX para diseñadores de estilos
btxdoc.bib
Archivo de base de datos para esos dos documentos
xampl.bib
Archivo de base de datos que proporciona ejemplos de todos los tipos de entrada estándar
btxbst.doc
Archivo de plantilla y documentación para los estilos estándar

Todos esos archivos deberían estar disponibles en algún lugar de su sistema.

El host math.utah.edu tiene una gran colección de archivos .bib disponibles para ftp anónimo, incluidas referencias para todos los libros estándar de TeX y una bibliografía completa de TUGboat.
