BIO_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_NEW(3ssl) OpenSSL BIO_NEW(3ssl)

NOMBRE

BIO_new_ex, BIO_new, BIO_up_ref, BIO_free, BIO_vfree, BIO_free_all - Funciones de asignación y liberación de BIO

SINOPSIS

#include <openssl/bio.h>
BIO *BIO_new_ex(OSSL_LIB_CTX *libctx, const BIO_METHOD *type);
BIO *BIO_new(const BIO_METHOD *type);
int BIO_up_ref(BIO *a);
int BIO_free(BIO *a);
void BIO_vfree(BIO *a);
void BIO_free_all(BIO *a);

DESCRIPCIÓN

La función BIO_new_ex() devuelve un nuevo BIO utilizando el método type asociado con el contexto de biblioteca libctx (ver OSSL_LIB_CTX(3)). El contexto de biblioteca puede ser NULL para indicar el contexto de biblioteca predeterminado. type NO DEBE ser NULL.

BIO_new() es lo mismo que BIO_new_ex() excepto que siempre se usa el contexto de biblioteca predeterminado.

BIO_up_ref() incrementa el contador de referencias asociado con el objeto BIO.

BIO_free() libera un único BIO, BIO_vfree() también libera un único BIO pero no devuelve un valor. Si a es NULL no se hace nada. Llamar a BIO_free() también puede tener algún efecto en la estructura de E/S subyacente, por ejemplo, puede cerrar el archivo al que se hace referencia en ciertas circunstancias. Para más detalles, consulte las descripciones individuales de BIO_METHOD.

BIO_free_all() libera una cadena completa de BIOs, no se detiene si ocurre un error al liberar un BIO individual en la cadena. Si a es NULL no se hace nada.

VALORES DE RETORNO

BIO_new_ex() y BIO_new() devuelven un BIO recién creado o NULL si la llamada falla.

BIO_up_ref() y BIO_free() devuelven 1 en caso de éxito y 0 en caso de fallo.

BIO_free_all() y BIO_vfree() no devuelven valores.

NOTAS

Si se llama a BIO_free() en una cadena de BIOs, solo liberará un BIO, lo que provocará una fuga de memoria.

Llamar a BIO_free_all() en un único BIO tiene el mismo efecto que llamar a BIO_free() en él, aparte del valor de retorno descartado.

HISTORIA

BIO_set() fue eliminado en OpenSSL 1.1.0 ya que el tipo BIO es ahora opaco.

BIO_new_ex() se añadió en OpenSSL 3.0.

EJEMPLOS

Crear un BIO de memoria:

BIO *mem = BIO_new(BIO_s_mem());
