Opciones Comunes para Conversión desde MODS

Tenga en cuenta que --output-encoding se refiere al archivo de entrada

-h --help muestra la ayuda
-v --version muestra la versión
-o --output-encoding interpreta el archivo de entrada como si usara el conjunto de caracteres solicitado (use sin argumento para la lista actual derivada de los conjuntos de caracteres en www.kostis.net[4]) unicode es ahora una opción de conjunto de caracteres
-s --single-refperfile pone una referencia por archivo llamado por el número de referencia
-nb --no-bom no escribe Byte Order Mark si escribe UTF8

xml2bib

xml2bib convierte la bibliografía MODS XML en un archivo de referencias con formato bibtex. El uso de xml2bib es como el de otras herramientas

xml2bib archivo.xml > archivo_salida.bib

Dado que el formato de referencia BibTeX es bastante flexible y parece tener el mayor número de preferencias personales, también ha acumulado una serie de opciones específicas que no están disponibles para otros formatos.

A partir de la versión 3.24, la salida de xml2bib utiliza etiquetas en minúsculas y tipos de referencia con mayúsculas y minúsculas para una mejor interacción con otro software. El comportamiento anterior con etiquetas/tipos de referencia en mayúsculas todavía se puede generar utilizando el modificador de línea de comandos -U/--uppercase.

Opciones específicas de xml2bib:

-fc --finalcomma añade una coma final en la salida bibtex para quienes la deseen
-sd --singledash usa un guión en lugar de dos (guión más largo en latex) entre números en la salida de páginas
-b --brackets usa corchetes en lugar de comillas alrededor de los datos del campo
-w --whitespace añade espacios en blanco embellecedores a la salida
-U --uppercase usa todas las mayúsculas para las etiquetas (nombres de campos) y tipos de referencia (comportamiento previo a la versión 3.24)
-sk --strictkey solo usa caracteres alfanuméricos para las claves de citación de bibtex

xml2ads

xml2ads convierte la bibliografía MODS XML al formato de referencia del Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System o formato de referencia ADS[6] (que es muy similar al estilo Endnote etiquetado). El uso de xml2ads es como el de otras herramientas

xml2ads archivo.xml > archivo_salida.ads

xml2ris

xml2ris convierte la bibliografía MODS XML a un archivo de bibliografía con formato RIS. El uso de xml2ris es como el de otras herramientas

xml2ris archivo.xml > archivo_salida.ris

xml2end

xml2end convierte la bibliografía MODS XML a un archivo de bibliografía con formato Endnote etiquetado (formato refer). El uso de xml2end es como el de otras herramientas

xml2end archivo.xml >  archivo_salida.end

xml2wordbib

xml2wordbib convierte la bibliografía MODS XML a un archivo de bibliografía XML con formato Word 2007. El uso de xml2wordbib es como el de otras herramientas

xml2wordbib archivo.xml >  archivo_salida.word.xml

xml2wordbib se llamaba xml2word en versiones de bibutils anteriores a la 3.40. Se renombró para evitar confusiones con otras herramientas. Esperemos que esto no rompa demasiados scripts ya en uso.
