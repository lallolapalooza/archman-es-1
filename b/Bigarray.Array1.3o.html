Módulo Bigarray.Array1

DOCUMENTACIÓN

Módulo Array1
: sig end

Arrays unidimensionales. La estructura Array1 proporciona operaciones similares a las de Bigarray.Genarray, pero especializadas para el caso de arrays unidimensionales. (Las estructuras Bigarray.Array2 y Bigarray.Array3 más abajo proporcionan operaciones especializadas para arrays bidimensionales y tridimensionales.) Conocer estáticamente el número de dimensiones del array permite operaciones más rápidas y una verificación de tipos estática más precisa.

type (!'a, !'b, !'c) t

El tipo de Bigarrays unidimensionales cuyos elementos tienen el tipo OCaml 'a, el tipo de representación 'b y la disposición de memoria 'c.

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> ('a, 'b, 'c) t

Array1.create kind layout dim devuelve un nuevo Bigarray unidimensional, cuyo tamaño es dim. kind y layout determinan el tipo de elemento del array y la disposición del array, como se describe para Bigarray.Genarray.create.

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> (int -> 'a) -> ('a, 'b, 'c) t

Array1.init kind layout dim f devuelve un nuevo Bigarray b unidimensional, cuyo tamaño es dim. kind y layout determinan el tipo de elemento del array y la disposición del array, como se describe para Bigarray.Genarray.create.

Cada elemento Array1.get b i del array se inicializa con el resultado de f i.

En otras palabras, Array1.init kind layout dimensions f tabula los resultados de f aplicados a los índices de un nuevo Bigarray cuya disposición se describe mediante kind, layout y dim.

Desde 4.12

val dim : ('a, 'b, 'c) t -> int

Devuelve el tamaño (dimensión) del Bigarray unidimensional dado.

val kind : ('a, 'b, 'c) t -> ('a, 'b) Bigarray.kind

Devuelve el tipo del Bigarray dado.

val layout : ('a, 'b, 'c) t -> 'c Bigarray.layout

Devuelve la disposición del Bigarray dado.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array1.change_layout a layout devuelve un Bigarray con la disposición especificada layout, compartiendo los datos con a (y por lo tanto teniendo la misma dimensión que a). No se realiza copia de elementos: el nuevo array y el array original comparten el mismo espacio de almacenamiento.

Desde 4.06

val size_in_bytes : ('a, 'b, 'c) t -> int

size_in_bytes a es el número de elementos en a multiplicado por el Bigarray.kind_size_in_bytes de a.

Desde 4.03

val get : ('a, 'b, 'c) t -> int -> 'a

Array1.get a x, o alternativamente a.{x}, devuelve el elemento de a en el índice x. x debe ser mayor o igual que 0 y estrictamente menor que Array1.dim a si a tiene disposición C. Si a tiene disposición Fortran, x debe ser mayor o igual que 1 y menor o igual que Array1.dim a. En caso contrario, se lanza Invalid_argument.

val set : ('a, 'b, 'c) t -> int -> 'a -> unit

Array1.set a x v, también escrito como a.{x} <- v, almacena el valor v en el índice x de a. x debe estar dentro de los límites de a, como se describe en Bigarray.Array1.get; de lo contrario, se lanza Invalid_argument.

val sub : ('a, 'b, 'c) t -> int -> int -> ('a, 'b, 'c) t

Extrae un sub-array del Bigarray unidimensional dado. Ver Bigarray.Genarray.sub_left para más detalles.

val slice : ('a, 'b, 'c) t -> int -> ('a, 'b, 'c) Bigarray.Array0.t

Extrae un escalar (rebanada de dimensión cero) del Bigarray unidimensional dado. El parámetro entero es el índice del escalar a extraer. Ver Bigarray.Genarray.slice_left y Bigarray.Genarray.slice_right para más detalles.

Desde 4.05

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t -> unit

Copia el primer Bigarray al segundo Bigarray. Ver Bigarray.Genarray.blit para más detalles.

val fill : ('a, 'b, 'c) t -> 'a -> unit

Rellena el Bigarray dado con el valor dado. Ver Bigarray.Genarray.fill para más detalles.

val of_array : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a array -> ('a, 'b, 'c) t

Construye un Bigarray unidimensional inicializado a partir del array dado.

val unsafe_get : ('a, 'b, 'c) t -> int -> 'a

Similar a Bigarray.Array1.get, pero la comprobación de límites no siempre se realiza. Usar con precaución y solo cuando la lógica del programa garantice que el acceso está dentro de los límites.

val unsafe_set : ('a, 'b, 'c) t -> int -> 'a -> unit

Similar a Bigarray.Array1.set, pero la comprobación de límites no siempre se realiza. Usar con precaución y solo cuando la lógica del programa garantice que el acceso está dentro de los límites.
