BUNDLE-ISSUE(1) Manual de comandos generales BUNDLE-ISSUE(1)

NOMBRE

bundle-issue - Obtener ayuda para reportar problemas de Bundler

SINOPSIS

bundle issue

DESCRIPCIÓN

Proporciona orientación sobre cómo reportar problemas de Bundler y muestra información detallada del sistema que debe incluirse al presentar un reporte de error. Este comando:

1.
Muestra enlaces a recursos de resolución de problemas
2.
Muestra instrucciones para reportar problemas
3.
Muestra información completa del entorno necesaria para la depuración

El comando ayuda a garantizar que los reportes de errores incluyan todos los detalles del sistema necesarios para una resolución de problemas efectiva.

SALIDA

El comando genera varias secciones:

  • Enlaces y recursos para la resolución de problemas
  • Enlace a la plantilla de incidencias de GitHub
  • Información del entorno que incluye: Versión y plataformas de Bundler, versión y configuración de Ruby, versión y rutas de RubyGems, versiones de herramientas de desarrollo (Git, RVM, rbenv, chruby)
  • Metadatos de compilación de Bundler
  • Configuración actual de Bundler
  • Salida de Bundle Doctor

EJEMPLOS

Obtener información para reportar problemas:

$ bundle issue
