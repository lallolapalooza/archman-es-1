Argumentos: COUNT es el número de veces que se ejecutará el bucle, y CODE es el código a ejecutar. CODE puede ser tanto una referencia a código como una cadena para evaluar; en cualquier caso, se ejecutará en el paquete del llamante.

Devuelve:

un objeto
Benchmark.
timethis ( COUNT, CODE, [ TITLE, [ STYLE ]
] )
Mide COUNT iteraciones de CODE. CODE puede ser una cadena para evaluar o una referencia a código; en cualquier caso, el CODE se ejecutará en el paquete del llamante. Los resultados se imprimirán en STDOUT como TITLE seguido de los tiempos. TITLE por defecto es "timethis COUNT" si no se proporciona ninguno. STYLE determina el formato de la salida, como se describe para timestr() más abajo.

COUNT puede ser cero o negativo: esto significa el número mínimo de segundos de CPU para ejecutar. Un cero significa el valor por defecto de 3 segundos. Por ejemplo, para ejecutar al menos durante

10 segundos: 
timethis(-10,
$code);

o para ejecutar dos piezas de código durante al menos 3

segundos: 
timethese(0, { test1 => '...', test2 => '...
'});

Los segundos de CPU son, en términos de UNIX, el tiempo de usuario más el tiempo de sistema del propio proceso, a diferencia del tiempo real (de reloj) y el tiempo empleado por los procesos hijos. Menos de 0.1 segundos no es aceptado (-0.01 como el conteo, por ejemplo, causará una excepción de tiempo de ejecución

fatal).

Ten en cuenta que los segundos de CPU son el tiempo mínimo: la planificación de CPU y otros factores del sistema operativo pueden complicar el intento de manera que se emplee un poco más de tiempo. La salida del benchmark, sin embargo, también indicará el número de ejecuciones de $code por segundo, que debería ser un número más interesante que los segundos realmente

empleados.

] )
Devuelve una cadena que formatea los tiempos en el objeto TIMEDIFF en el STYLE solicitado. Se espera que TIMEDIFF sea un objeto Benchmark similar a el devuelto por timediff().

STYLE puede ser cualquiera de 'all', 'none', 'noc', 'nop' o 'auto'. 'all' muestra cada uno de los 5 tiempos disponibles (tiempo de 'wallclock', tiempo de usuario, tiempo de sistema, tiempo de usuario de los hijos y tiempo de sistema de los hijos). 'noc' muestra todos excepto los dos tiempos de los hijos. 'nop' muestra solo el tiempo de wallclock y los dos tiempos de los hijos. 'auto' (el valor por defecto) actuará como 'all' a menos que los tiempos de los hijos sean ambos cero, en cuyo caso actuará como 'noc'. 'none' previene la
