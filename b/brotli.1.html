brotli(1) Manual de usuario brotli(1)

NOMBRE

brotli(1) -- brotli, unbrotli - comprimir o descomprimir archivos

SINOPSIS

brotli [OPCIÓN|ARCHIVO]...

unbrotli es equivalente a brotli --decompress

DESCRIPCIÓN

brotli es un algoritmo de compresión sin pérdidas de propósito general que comprime datos utilizando una combinación de una variante moderna del algoritmo LZ77, codificación Huffman y modelado de contexto de 2º orden, con una relación de compresión comparable a los mejores métodos de compresión de propósito general disponibles actualmente. Su velocidad es similar a deflate pero ofrece una compresión más densa.

La sintaxis de línea de comandos de brotli es similar a la de gzip (1) y zstd (1). A diferencia de gzip (1), los archivos fuente se conservan por defecto. Es posible eliminarlos después del procesamiento utilizando la opción --rm.

Los argumentos que parecen “--nombre” o “--nombre=valor” son opciones. Cada opción tiene una forma corta “-x” o “-x valor”. Se pueden agrupar múltiples opciones cortas:

•
“--decompress --stdout --suffix=.b” funciona igual que
•
“-d -s -S .b” y
•
“-dsS .b”

brotli tiene 3 modos de operación:

•
el modo por defecto es compresión;
•
la opción --decompress activa el modo de descompresión;
•
la opción --test cambia al modo de prueba de integridad; esta opción es equivalente a “--decompress --stdout” excepto que los datos descomprimidos se descartan en lugar de escribirse en la salida estándar.

Cada argumento que no sea una opción es una entrada de archivo. Si no se proporcionan archivos o el archivo es “-”, brotli lee de la entrada estándar. Todos los argumentos después de “--” son entradas de archivo.

A menos que se especifique --stdout o --output, los archivos se escriben en un nuevo archivo cuyo nombre se deriva del nombre del archivo fuente:

•
al comprimir, se añade un sufijo al nombre del archivo fuente para obtener el nombre del archivo de destino
•
al descomprimir, se elimina un sufijo del nombre del archivo fuente para obtener el nombre del archivo de destino

El sufijo por defecto es .br, pero se puede especificar con la opción --suffix.

No se permiten opciones conflictivas o duplicadas.

OPCIONES

•
-#: nivel de compresión (0-9); valores más altos causan una compresión más densa, pero más lenta
•
-c, --stdout: escribir en la salida estándar
•
-d, --decompress: modo de descompresión
•
-f, --force: forzar la sobrescritura del archivo de salida
•
-h, --help: mostrar esta ayuda y salir
•
-j, --rm: eliminar archivo(s) fuente; comportamiento similar a gzip (1)
•
-k, --keep: conservar archivo(s) fuente; comportamiento similar a zstd (1)
•
-n, --no-copy-stat: no copiar atributos del archivo(s) fuente
•
-o FILE, --output=FILE archivo de salida; válido solo si hay una única entrada de entrada
•
-q NUM, --quality=NUM: nivel de compresión (0-11); valores más altos causan una compresión más densa, pero más lenta
•
-t, --test: modo de prueba de integridad de archivo
•
-v, --verbose: aumentar la verbosidad de la salida
•
-w NUM, --lgwin=NUM: establecer el tamaño de la ventana LZ77 (0, 10-24) (por defecto: 24); el tamaño de la ventana es (pow(2, NUM) - 16); 0 permite al compresor decidir sobre el valor óptimo; un tamaño de ventana mayor mejora la densidad; el decodificador podría requerir hasta el tamaño de la ventana de memoria para operar
•
-D FILE, --dictionary=FILE: usar FILE como diccionario crudo (LZ77); se debe usar el mismo diccionario tanto para la compresión como para la descompresión
•
-S SUF, --suffix=SUF: sufijo del archivo de salida (por defecto: .br)
•
-V, --version: mostrar la versión y salir
•
-Z, --best: usar el nivel de compresión más alto (por defecto); igual a “-q 11”

VER TAMBIÉN

El formato de archivo brotli se define en RFC 7932 (https://www.ietf.org/rfc/rfc7932.txt).
