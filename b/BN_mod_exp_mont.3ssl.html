BN_mod_exp_mont(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_MOD_EXP_MONT(3ssl) OpenSSL BN_MOD_EXP_MONT(3ssl)

NOMBRE

BN_mod_exp_mont, BN_mod_exp_mont_consttime, BN_mod_exp_mont_consttime_x2 - Exponenciación de Montgomery

SINOPSIS

#include <openssl/bn.h>
int BN_mod_exp_mont(BIGNUM *rr, const BIGNUM *a, const BIGNUM *p,
                    const BIGNUM *m, BN_CTX *ctx, BN_MONT_CTX *in_mont);
int BN_mod_exp_mont_consttime(BIGNUM *rr, const BIGNUM *a, const BIGNUM *p,
                              const BIGNUM *m, BN_CTX *ctx,
                              BN_MONT_CTX *in_mont);
int BN_mod_exp_mont_consttime_x2(BIGNUM *rr1, const BIGNUM *a1,
                                 const BIGNUM *p1, const BIGNUM *m1,
                                 BN_MONT_CTX *in_mont1, BIGNUM *rr2,
                                 const BIGNUM *a2, const BIGNUM *p2,
                                 const BIGNUM *m2, BN_MONT_CTX *in_mont2,
                                 BN_CTX *ctx);

DESCRIPCIÓN

BN_mod_exp_mont() calcula a elevado a la potencia p módulo m ("rr=a^p % m") usando multiplicación de Montgomery. in_mont es un contexto de Montgomery y puede ser NULL. En el caso de que in_mont sea NULL, se inicializará dentro de la función, por lo que puede ahorrar tiempo en la inicialización si lo proporciona con antelación.

BN_mod_exp_mont_consttime() calcula a elevado a la potencia p módulo m ("rr=a^p % m") usando multiplicación de Montgomery. Es una variante de BN_mod_exp_mont(3) que utiliza ventanas fijas y la disposición especial de memoria precalculada para limitar la dependencia de los datos al mínimo y proteger los exponentes secretos. Se llama automáticamente cuando se invoca BN_mod_exp_mont(3) con los parámetros a, p, m, cualquiera de los cuales tiene la bandera BN_FLG_CONSTTIME.

BN_mod_exp_mont_consttime_x2() calcula dos exponenciaciones independientes: a1 elevado a la potencia p1 módulo m1 ("rr1=a1^p1 % m1") y a2 elevado a la potencia p2 módulo m2 ("rr2=a2^p2 % m2") usando multiplicación de Montgomery. Para algunos tamaños de módulo fijos e iguales m1 y m2, utiliza optimizaciones que permiten acelerar dos exponenciaciones. En todos los demás casos, la función se reduce a dos llamadas a BN_mod_exp_mont_consttime(3).

VALORES DE RETORNO

Para todas las funciones, se devuelve 1 en caso de éxito y 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), BN_mod_exp_mont(3)
