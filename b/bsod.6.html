NOMBRE

bsod - Emulador de Pantalla Azul de la Muerte

SINOPSIS

bsod [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--delay segundos] [--fps]

DESCRIPCIÓN

El programa bsod es lo mejor en emulación de ordenadores personales.

bsod recorre una serie de pantallas, cada una es una recreación de un modo de fallo diferente de un sistema operativo. Los sistemas representados incluyen Windows 3.1, Windows 95, Windows NT, MS-DOS, AmigaDOS 1.3, Linux, SCO UNIX, BSD UNIX, HPUX, Solaris, Tru64, VMS, HVX/GCOS6, IBM OS/390, OS/2, MacOS (MacsBug, Bomb, Sad Mac y OSX), Atari ST, Apple ][+, VMware y NCD X Terminals.

OPCIONES

bsod acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla a color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--delay retraso
La duración que se muestra cada modo de fallo antes de seleccionar otro.
--only cual
Indica que ejecute solo un modo, por ejemplo, --only HPUX.
--fps
Muestra la velocidad de fotogramas actual y la carga de CPU.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

RECURSOS X

Los recursos X notables admitidos incluyen los siguientes, que controlan qué "hacks" se muestran y cuáles no. doWindows, doNT, doWin2K, doWin10, doRansomware, doAmiga, doMac, doMac1, doMacsBug, doMacX, doSCO, doAtari, doBSD, doLinux, doSparcLinux, doHPPALinux, doBlitDamage, doSolaris, doHPUX, doApple2, doOS390, doTru64, doVMS, doMSDOS, doOS2, doHVX, doVMware y doATM. Cada uno de estos es un recurso booleano, todos tienen como valor predeterminado verdadero, excepto doAtari, doBSD, doSparcLinux y doHPPALinux, que están desactivados por defecto, ya que realmente no son muy interesantes de ver a menos que seas fanático de esos sistemas.

Hay opciones de línea de comandos para todos estos: por ejemplo, --bsd, --no-bsd. (También tenga en cuenta la opción --only).

ERRORES

A diferencia de los sistemas que simula, bsod no requiere un reinicio después de ejecutarse.
