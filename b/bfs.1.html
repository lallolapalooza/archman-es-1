ENTORNO

Ciertas variables de entorno afectan el comportamiento de bfs.

LANG
LC_*

Especifica la locale(7) en uso para varias cosas. bfs no está (todavía) traducido a ningún idioma que no sea el inglés, pero la configuración regional aún afectará al formato de los valores impresos. Las preguntas de sí/no (por ejemplo, desde -ok) también se interpretarán de acuerdo con la configuración regional actual.

LS_COLORS
BFS_COLORS

Controla los colores utilizados al mostrar rutas de archivos si -color está habilitado. bfs interpreta LS_COLORS de la misma manera que GNU ls(1) (ver dir_colors(5)). BFS_COLORS puede usarse para personalizar bfs sin afectar a otros comandos.
NO_COLOR
Hace que bfs use por defecto -nocolor si está definida (ver https://no-color.org/).
PAGER
Especifica el paginador utilizado para la salida de -help . Por defecto es less(1), si se encuentra en el PATHactual, de lo contrario more(1).
PATH
Se usa para resolver los ejecutables para -exec[dir] y -ok[dir].
POSIXLY_CORRECT
Hace que bfs se ajuste más estrictamente a la especificación POSIX.1-2017 para find(1). Actualmente esto tiene dos efectos:
  • Desactiva las advertencias por defecto, porque POSIX prohíbe escribir en la salida de error estándar (excepto para el aviso de -ok ), a menos que el comando también falle con un estado de salida distinto de cero.
  • Hace que -ls y -fls usen bloques de 512 bytes en lugar de bloques de 1024 bytes. (POSIX no especifica estas acciones, pero las implementaciones de find(1) de BSD usan bloques de 512 bytes, mientras que find(1) de GNU usa bloques de 1024 bytes por defecto.)

No desactiva bfs's various extensions to the base POSIX functionality. POSIXLY_CORRECT tiene los mismos efectos sobre GNU find(1).

EJEMPLOS

bfs
Sin argumentos, bfs imprime todos los archivos bajo el directorio actual en orden de amplitud (breadth-first).
bfs -name '*.txt'
Imprime todos los archivos .txt bajo el directorio actual. *.txt está entrecomillado para asegurar que el patrón sea procesado por bfs y no por el shell.
bfs -name access_log -L /var
Encuentra todos los archivos llamados access_log bajo /var, siguiendo enlaces simbólicos. bfs permite que las banderas y las rutas aparezcan en cualquier lugar de la línea de comandos.
bfs ~ -not -user $USER
Imprime todos los archivos en tu directorio de inicio que no te pertenecen.
bfs -xtype l
Encuentra enlaces simbólicos rotos.
bfs -name config -exclude -name .git
Encuentra todos los archivos llamados config, omitiendo cada .git directorio.
bfs -type f -executable -exec strip {} +
Ejecuta strip(1) en todos los archivos ejecutables que encuentra, pasándole múltiples archivos a la vez.
