BTFS(1) Manual de comandos generales BTFS(1)

NOMBRE

btfs - montar archivos torrent o enlaces magnéticos como un sistema de archivos

SINOPSIS

btfs [opciones] metadatos punto-de-montaje

DESCRIPCIÓN

btfs permite montar cualquier archivo torrent o enlace magnético como un sistema de archivos. El contenido de los archivos se descargará bajo demanda a medida que las aplicaciones los lean.

OPCIONES

-v --version
imprimir versión
-h --help
imprimir ayuda
-b --browse-only
descargar solo metadatos
-k --keep
conservar archivos después de desmontar
-s --silent
no crear registros
--utp-only
no usar TCP
--data-directory=DIRECTORIO
directorio en el que poner los datos de descarga de btfs. por defecto usará $XDG_DATA_HOME si está definido, de lo contrario usará $HOME/btfs, o /tmp/btfs si este último no está disponible
--min-port=PUERTO
inicio del rango de puertos de escucha
--max-port=PUERTO
fin del rango de puertos de escucha
--max-download-rate=TASA
tasa máxima de descarga (en kilobytes por segundo)
--max-upload-rate=TASA
tasa máxima de subida (en kilobytes por segundo)

EJEMPLOS

montar un archivo torrent:
btfs video.torrent ~/mnt

montar un enlace magnético:
btfs 'magnet:?xt=urn:btih:...' ~/mnt

desmontar:
fusermount -u ~/mnt

ERRORES

Por favor, informe de cualquier error en https://github.com/johang/btfs.
