bupstash-diff(1)

Paquete: bupstash

Licencias: MIT

() ()

SINÓPSIS

Compara dos instantáneas imprimiendo el resumen en la salida estándar.

bupstash diff [OPCIONES] CONSULTA1... :: CONSULTA2...

DESCRIPCIÓN

bupstash diff recupera dos listados de instantáneas del servidor remoto y los compara, imprimiendo la salida diff línea por línea en la salida estándar. Como caso especial, si alguna consulta comienza con ´./´ o ´/´, se crea un listado temporal para ese directorio local para comparación.

Se prefiere bupstash diff sobre la ejecución del comando tradicional diff contra la salida de bupstash list-contents porque tiene en cuenta la precisión completa de las marcas de tiempo y también el hash de archivo almacenado al realizar la operación diff.

Bupstash admite ignorar elementos en la comparación diff para facilitar el análisis. Ejemplos útiles son los valores --ignore times para ignorar las marcas de tiempo de modificación de archivos y content para ignorar los cambios de tamaño y hash de archivos.

FORMATO DE SALIDA

La salida es consistente con la de bupstash list-contents, excepto que cada línea se antepone con + o -, representando respectivamente elementos eliminados o agregados.

Especificar --format altera el formato de salida subyacente como se describe en bupstash-list-contents(1). Las líneas todavía se anteponen con + o - independientemente del formato de salida.

LENGUAJE DE CONSULTAS

Para obtener documentación completa sobre el lenguaje de consultas, consulte bupstash-query-language(7).

CACHÉ DE CONSULTAS

El comando diff utiliza los mismos mecanismos de caché de consultas que bupstash-list(1), consulte esa página para obtener más información sobre la caché de consultas.

OPCIONES

-r, --repository REPO
El repositorio al que conectarse, , puede tener el formato ssh://$SERVER/$PATH para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece como BUPSTASH_REPOSITORY.
-k, --key KEY
Clave utilizada para descifrar datos y metadatos. Si no se establece, por defecto es BUPSTASH_KEY.
--query-cache PATH
Ruta al archivo de caché de consultas, por defecto es uno de los siguientes, en orden, siempre que las variables de entorno apropiadas estén configuradas: $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache o $HOME/.cache/bupstash/bupstash.qcache.
-i, --ignore
Lista separada por comas de atributos de archivo a ignorar en las comparaciones. Los elementos válidos son ´content,dev,devnos,inode,type,perms,nlink,uid,gid,times,xattrs´
--relaxed
Atajo para --ignore ´dev,inode,nlink,uid,gid,times,xattrs´. Esta opción es útil para comparar contenido sin preocuparse tanto por los metadatos específicos de la máquina.
--{left,right}-pick PATH
Realiza la comparación diff en un subdirectorio de la consulta izquierda/derecha.
--indexer-threads N
Número de hilos de procesador a utilizar para el hash de archivos en paralelo y lecturas de metadatos. Por defecto, es el número de procesadores.
--xattrs
Recupera xattrs al indexar directorios locales.
--format FORMAT
Establece el formato de salida en uno de los siguientes: ´human´, ´jsonl´.
--utc-timestamps
Muestra y busca marcas de tiempo en hora UTC en lugar de hora local.
--no-progress
Suprime los indicadores de progreso (los indicadores de progreso también se suprimen cuando stderr no es una terminal interactiva).
-q, --quiet
Silencioso, implica --no-progress.

ENTORNO

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede tener el formato ssh://$SERVER/$PATH para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando a ejecutar para conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_KEY
Ruta a una clave principal que se utilizará para descifrar datos y metadatos.
BUPSTASH_KEY_COMMAND
Un comando a ejecutar que debe imprimir los datos de la clave, se puede utilizar en lugar de BUPSTASH_KEY para obtener la clave de ubicaciones arbitrarias como la red u otros almacenamientos secretos.
BUPSTASH_QUERY_CACHE
Ruta al archivo de caché de consultas a utilizar.

EJEMPLOS

Comparar dos instantáneas por consulta

$ bupstash diff id="14eb*" :: id="57de*" - -rw-r--r-- 1.1kB hello.txt + -rw-r--r-- 1.3kB goodbye.txt

Comparar una instantánea y un directorio local

$ bupstash diff --left-pick files --relaxed id="57de*" :: ./files
