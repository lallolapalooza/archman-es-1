BN_mod_mul_montgomery(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_MOD_MUL_MONTGOMERY(3ssl) OpenSSL BN_MOD_MUL_MONTGOMERY(3ssl)

NOMBRE

BN_mod_mul_montgomery, BN_MONT_CTX_new, BN_MONT_CTX_free, BN_MONT_CTX_set, BN_MONT_CTX_copy, BN_from_montgomery, BN_to_montgomery - Multiplicación de Montgomery

SINOPSIS

#include <openssl/bn.h>
BN_MONT_CTX *BN_MONT_CTX_new(void);
void BN_MONT_CTX_free(BN_MONT_CTX *mont);
int BN_MONT_CTX_set(BN_MONT_CTX *mont, const BIGNUM *m, BN_CTX *ctx);
BN_MONT_CTX *BN_MONT_CTX_copy(BN_MONT_CTX *to, BN_MONT_CTX *from);
int BN_mod_mul_montgomery(BIGNUM *r, BIGNUM *a, BIGNUM *b,
                          BN_MONT_CTX *mont, BN_CTX *ctx);
int BN_from_montgomery(BIGNUM *r, BIGNUM *a, BN_MONT_CTX *mont,
                       BN_CTX *ctx);
int BN_to_montgomery(BIGNUM *r, BIGNUM *a, BN_MONT_CTX *mont,
                     BN_CTX *ctx);

DESCRIPCIÓN

Estas funciones implementan la multiplicación de Montgomery. Se usan automáticamente cuando BN_mod_exp(3) se llama con entrada adecuada, pero pueden ser útiles cuando se van a realizar varias operaciones usando el mismo módulo.

BN_MONT_CTX_new() asigna e inicializa una estructura BN_MONT_CTX.

BN_MONT_CTX_set() configura la estructura mont a partir del módulo m precalculando su inverso y un valor R.

BN_MONT_CTX_copy() copia el BN_MONT_CTX de from a to.

BN_MONT_CTX_free() libera los componentes de BN_MONT_CTX y, si fue creada por BN_MONT_CTX_new(), también la propia estructura. Si mont es NULL, no se hace nada.

BN_mod_mul_montgomery() calcula Mont(a,b):=a*b*R^-1 y coloca el resultado en r.

BN_from_montgomery() realiza la reducción de Montgomery r = a*R^-1.

BN_to_montgomery() calcula Mont(a,R^2), es decir, a*R. Nótese que a debe ser no negativo y menor que el módulo.

Para todas las funciones, ctx es un BN_CTX asignado previamente utilizado para variables temporales.

VALORES DE RETORNO

BN_MONT_CTX_new() devuelve el BN_MONT_CTX recién asignado y NULL en caso de error.

BN_MONT_CTX_free() no tiene valor de retorno.

Para las otras funciones, se devuelve 1 para éxito, 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

ADVERTENCIAS

Las entradas deben estar reducidas módulo m, de lo contrario el resultado estará fuera del rango esperado.

VER TAMBIÉN

ERR_get_error(3), BN_add(3), BN_CTX_new(3)

HISTORIAL

BN_MONT_CTX_init() fue eliminado en OpenSSL 1.1.0
