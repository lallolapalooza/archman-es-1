bupstash-rm(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Elimina elementos de un repositorio bupstash.

bupstash rm [OPCIONES] CONSULTA...

DESCRIPCIÓN

bupstash rm elimina elementos de un repositorio bupstash.

Los elementos que se eliminan no se borran inmediatamente, sino que la eliminación y la recuperación de espacio se programan para la próxima vez que se ejecute el recolector de basura bupstash-gc(1).

Solo es necesario descifrar metadatos para eliminar elementos, por lo que una clave de metadatos es suficiente para la eliminación de elementos, incluso sin acceso a la clave de descifrado de datos.

LENGUAJE DE CONSULTAS

Para obtener la documentación completa sobre el lenguaje de consultas, consulte bupstash-query-language(7).

Ejemplos de consultas de eliminación

``` $ id=$(bupstash put ./some-data)

$ bupstash rm id=$id

$ bupstash rm name=backups.tar

$ bupstash rm --allow-many name=´*.tar´ and older-than 30d

$ bupstash rm --allow-many id="*" ```

CACHÉ DE CONSULTAS

El comando rm utiliza los mismos mecanismos de caché de consultas que bupstash-list(1); consulte esa página para obtener más información sobre la caché de consultas.

OPCIONES

-r, --repository REPO
El repositorio al que conectarse. Puede ser de la forma ssh://$SERVER/$PATH para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece en BUPSTASH_REPOSITORY.
-k, --key KEY
Clave utilizada para descifrar metadatos al ejecutar una consulta. Si no se establece, se utiliza por defecto BUPSTASH_KEY.
--query-cache PATH
Ruta al archivo de caché de consultas, por defecto es uno de los siguientes, en orden, siempre que las variables de entorno apropiadas estén configuradas: $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache o $HOME/.cache/bupstash/bupstash.qcache.
--query-encrypted
La consulta no descifrará ningún metadato, lo que le permitirá listar elementos para los que no tiene una clave de descifrado. Esta opción inserta la etiqueta de consulta pseudo ´decryption-key-id´.
--ids-from-stdin
Elimina elementos con IDs leídos desde stdin, uno por línea, en lugar de ejecutar una consulta.
--allow-many
Por defecto, bupstash se niega a eliminar varios elementos de una sola consulta; esta bandera deshabilita esa característica de seguridad.
--utc-timestamps
Mostrar y buscar contra marcas de tiempo en hora UTC en lugar de hora local.
--no-progress
Suprimir los indicadores de progreso (los indicadores de progreso también se suprimen cuando stderr no es una terminal interactiva).
-q, --quiet
Ser silencioso, implica --no-progress.

ENTORNO

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede ser de la forma ssh://$SERVER/$PATH para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando para ejecutar y conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_KEY
Ruta a una clave principal que se utilizará para descifrar datos y metadatos.
BUPSTASH_KEY_COMMAND
Un comando para ejecutar que debe imprimir los datos de la clave, se puede usar en lugar de BUPSTASH_KEY para obtener la clave de ubicaciones arbitrarias como la red u otro almacenamiento secreto.
BUPSTASH_QUERY_CACHE
Ruta al archivo de caché de consultas a utilizar.

EJEMPLOS

eliminar un elemento con un id específico del repositorio

$ bupstash rm id=14ebd2073b258b1f55c5bbc889c49db4

eliminar todos los elementos del repositorio

$ bupstash rm id="*"

eliminar elementos con el nombre backup.tar que tengan más de 30 días

$ bupstash rm name=backup.tar and older-than 30d

eliminar elementos con un script personalizado

$ bupstash list --format=jsonl1 \ | custom-json-filter \ | bupstash rm --ids-from-stdin
