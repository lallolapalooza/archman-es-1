bssh/bvnc/bshell(1) Manual de Comandos Generales bssh/bvnc/bshell(1)

NOMBRE

bssh/bvnc/bshell - Buscar servidores SSH/VNC en la red local

SINOPSIS

bssh

bvnc

bshell

DESCRIPCIÓN

bssh/bvnc/bshell busca servidores SSH/VNC en la red local, los muestra en una GUI para que el usuario seleccione uno y finalmente llama a ssh/vncviewer después de que se haya realizado una selección.

Si el binario se llama como bssh, solo se mostrarán servidores SSH. Si el binario se llama como bvnc, solo se mostrarán servidores VNC. Si el binario se llama como bshell, se mostrarán servidores VNC y SSH.

OPCIONES

-s | --ssh
Buscar servidores SSH (y solo servidores SSH) independientemente del nombre con el que se llame al binario.
-v | --vnc
Buscar servidores VNC (y solo servidores VNC) independientemente del nombre con el que se llame al binario.
-S | --shell
Buscar tanto servidores VNC como SSH independientemente del nombre con el que se llame al binario.
-d | --domain= DOMINIO
Buscar en el dominio especificado. Si se omite, bssh/bvnc/bshell buscará en el dominio de búsqueda predeterminado (normalmente .local)
-h | --help
Mostrar ayuda.
