buildah-pull - E

xtrae una imagen
de un registro.

SINOPSI

S

buildah pull [opciones] imag

e
n

DESCRIPCIÓ

N

Extrae una imagen basada en la entrada especificada. Soporta todos los transportes de containers-transports(5) (vea los ejemplos más abajo). Si no se especifica ningún transporte, la entrada está sujeta a la resolución de nombres cortos (vea containers-registries.conf(5)) y se utiliza el transporte docker (es decir, el registro de contenedores)

.

DEPENDENCIA

S

Buildah resuelve la ruta al registro del que extraer utilizando el archivo /etc/containers/registries.conf, containers-registries.conf(5). Si el comando buildah pull falla con un error "imagen no conocida",

primero verifique que el archiv
o registries.conf esté instalado
y configurado adecuadamente.

VALOR DE

RETORNO

El ID de la imagen que

fue extraída. En caso de
error se devuelve 1.

OPCIONE

S

--all-tags, -

a

Se extraerán todas las imágenes etiquetadas en el

repositorio.

--arch="ARCH

"

Establece la ARQUITECTURA de la imagen a extraer al valor proporcionado en lugar de usar la arquitectura del host. (Ejemplos: arm, arm64, 386, amd64, ppc64le,

s390x)

--authfile rut

a

Ruta del archivo de autenticación. Por defecto es ${XDG_RUNTIME_DIR}/containers/auth.json. Vea containers-auth.json(5) para más información. Este archivo se crea utilizando buildah l

ogin.

Si el estado de autorización no se encuentra allí, se comprueba $HOME/.docker/config.json, que se establece utilizando docker

login.

Nota: También puede sobrescribir la ruta por defecto del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. export REGISTRY_AUTH_FILE=rut

a

--cert-dir rut

a

Usar certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro. El directorio de certificados por defecto es /etc/containers/

certs.d.

--creds credencial

es

El [usuario[:contraseña]] a usar para autenticarse con el registro si es necesario. Si uno o ambos valores no se proporcionan, aparecerá un prompt de la línea de comandos y se puede introducir el valor. La contraseña se introduce sin

eco.

--decryption-key clave[:

frase-de-pase]

La [clave[:frase-de-pase]] a usar para la desencriptación de imágenes. La clave puede apuntar a claves y/o certificados. Se intentará la desencriptación con todas las claves. Si la clave está protegida por una frase de pase, es necesario pasarla en el argumento y omitirla en caso

contrario.

--os="SO

"

Establece el SO de la imagen a extraer en lugar de usar el sistema operativo actual del

host.

--platform="SO/ARQUITECTURA[/VARIANTE]

"

Establece el SO/ARQUITECTURA de la imagen a extraer al valor proporcionado en lugar de usar el sistema operativo y la arquitectura actuales del host (por ejemplo linux/a

rm).

Los pares SO/ARQUITECTURA son los utilizados por el Lenguaje de Programación Go. En varios casos, el valor de ARQUITECTURA para una plataforma difiere del producido por otras herramientas como el comando arch. Las combinaciones válidas de nombres de SO y arquitectura se listan como valores para $GOOS y $GOARCH en https://golang.org/doc/install/source#environment, y también se pueden encontrar ejecutando go tool dist

list.

NOTA: La opción --platform no puede usarse en combinación con las opciones --arch, --os o --variant

.

--policy=always|missing|never|newe

r

Política de extracción de imágenes. Por defecto es missing

.
  • always: Siempre extraer la imagen y lanzar un error si la extracción
    • falla.
  • missing: Extraer la imagen solo si no se pudo encontrar en el almacenamiento local de contenedores. Lanzar un error si no se pudo encontrar ninguna imagen y la extracción
    • falla.
  • never: Nunca extraer la imagen sino usar la del almacenamiento local de contenedores. Lanzar un error si no se pudo encontrar ninguna
    • imagen.
  • newer: Extraer si la imagen en el registro es más nueva que la del almacenamiento local de contenedores. Una imagen se con
    • sidera más nueva cuando los digests son diferentes. Compara
r las marcas de tiempo es propenso a errores. Los errores
de extracción se suprimen si se encontró una imagen local.

--quiet, -

q

Si es necesario extraer una imagen del registro, suprimir la salida de

progreso.

--remove-signature

s

No copiar firmas al extraer

imágenes.

--retry intento

s

Número de veces a reintentar en caso de fallo al realizar la extracción de imágenes del

registro.

Por defecto es 3

.

--retry-delay duració

n

Duración de la demora entre intentos de reintento en caso de fallo al realizar la extracción de imágenes del

registro.

Por defecto es 2s

.

--tls-verify valor-boolean

o

Requerir HTTPS y verificación de certificados al comunicarse con registros de contenedores (por defecto true). La verificación TLS no puede usarse al comunicarse con un registro

inseguro.

--variant="

"

Establecer la variant

e de arquitectura de
la imagen a extraer.

ENTORN

O

BUILD_REGISTRY_SOURCE

S

BUILD_REGISTRY_SOURCES, si está definida, se trata como un objeto JSON que contiene listas de nombres de registro bajo las claves insecureRegistries, blockedRegistries y allowedRegistries

.

Al extraer una imagen de un registro, si el nombre del registro coincide con cualquiera de los elementos de la lista blockedRegistries, se deniega el intento de extracción de la imagen. Si hay registros en la lista allowedRegistries y el nombre del registro no está en la lista, se deniega el intento de

extracción.

TMPDIR La variable de entorno TMPDIR permite al usuario especificar dónde se almacenan lo

s archivos temporales mientras se extraen y
se suben imágenes. Por defecto es '/var/tmp'.

ARCHIVO

S

registries.conf (/etc/containers/regis

tries.conf)

registries.conf es el archivo de configuración que especifica qué registros de contenedores deben consultarse al completar nombres de imagen que no incluyen una porción de registro o

dominio.

policy.json (/etc/containers/pol

icy.json)

Archivo de política de firmas. Define la política de confianza para i

mágenes de contenedores. Controla qué registros de contenedores se pu
eden usar para imágenes y si la herramienta debe confiar en las imágenes.
