NOMBRE

borg-compression - Detalles sobre la compresión

DESCRIPCIÓN

No hay problema en mezclar diferentes métodos de compresión en un mismo repositorio; la deduplicación se realiza sobre los fragmentos de datos de origen (no sobre los datos comprimidos o cifrados).

Si algún fragmento específico se comprimió y se almacenó en el repositorio, la creación de otra copia de seguridad que también utilice este fragmento no cambiará el fragmento almacenado. Por lo tanto, si utiliza especificaciones de compresión diferentes para las copias de seguridad, la que almacene un fragmento primero determinará su compresión. Consulte también borg recreate.

La compresión es lz4 por defecto. Si desea otra cosa, debe especificar lo que desea.

Los especificadores de compresión válidos son:

ninguno
No comprimir.
lz4
Usar compresión lz4. Velocidad muy alta, compresión muy baja. (por defecto)
zstd[,N]
Usar compresión zstd ("zstandard"), un algoritmo moderno de amplio rango. Si no especifica explícitamente el nivel de compresión N (que varía de 1 a 22), utilizará el nivel 3. Los archivos comprimidos con zstd no son compatibles con borg < 1.1.4.
zlib[,N]
Usar compresión zlib ("gz"). Velocidad media, compresión media. Si no especifica explícitamente el nivel de compresión N (que varía de 0 a 9), utilizará el nivel 6. Proporcionar el nivel 0 (significa "sin compresión", pero aún tiene la sobrecarga del protocolo zlib) suele ser inútil, es mejor usar la compresión "ninguno".
lzma[,N]
Usar compresión lzma ("xz"). Velocidad baja, compresión alta. Si no especifica explícitamente el nivel de compresión N (que varía de 0 a 9), utilizará el nivel 6. Proporcionar niveles superiores a 6 es inútil y contraproducente porque no comprime mejor debido al tamaño del búfer utilizado por borg; pero desperdicia muchos ciclos de CPU y RAM.
auto,C[,N]
Usar una heurística integrada para decidir por fragmento si comprimir o no. La heurística intenta con lz4 si los datos son compresibles. Para datos incompresibles, no utilizará compresión (usa "ninguno"). Para datos compresibles, utiliza la compresión C[,N] dada; C[,N] puede ser cualquier especificador de compresión válido. Esto puede ser útil para archivos multimedia que a menudo no se pueden comprimir mucho más.
obfuscate,ESPEC,C[,N]
Usar ofuscación de tamaño comprimido para dificultar los ataques de huella digital basados en el tamaño observable del fragmento almacenado. Nota:
  • Debe combinar esto con el cifrado, o no tendrá ningún sentido.
  • El tamaño de su repositorio será mayor, por supuesto.
  • Un fragmento está limitado por la constante MAX_DATA_SIZE (actualmente ~20MiB).

El valor ESPEC determina cómo funciona la ofuscación de tamaño:

Variación recíproca aleatoria relativa del tamaño (multiplicativa)

El tamaño aumentará en un factor, relativo al tamaño de los datos comprimidos. Se utilizan factores más pequeños con frecuencia, factores más grandes raramente.

Factores disponibles:

1:     0.01 ..        100
2:     0.1  ..      1,000
3:     1    ..     10,000
4:    10    ..    100,000
5:   100    ..  1,000,000
6: 1,000    .. 10,000,000

Probabilidades de ejemplo para ESPEC 1:

90   %  0.01 ..   0.1
 9   %  0.1  ..   1
 0.9 %  1    ..  10
 0.09% 10    .. 100

Relleno de tamaño aleatorio hasta el tamaño dado (aditivo)

110: 1kiB (2 ^ (ESPEC - 100))
...
120: 1MiB
...
123: 8MiB (máx.)

Relleno Padmé (determinista)

250: rellena a sumas de potencias de 2, máx. 12% de sobrecarga

Utiliza el algoritmo Padmé para rellenar determinísticamente el tamaño comprimido a una suma de potencias de 2, limitando la sobrecarga al 12%. Consulte https://lbarman.ch/blog/padme/ para más detalles.

Ejemplos:

borg create --compression lz4 REPO::ARCHIVE datos
borg create --compression zstd REPO::ARCHIVE datos
borg create --compression zstd,10 REPO::ARCHIVE datos
borg create --compression zlib REPO::ARCHIVE datos
borg create --compression zlib,1 REPO::ARCHIVE datos
borg create --compression auto,lzma,6 REPO::ARCHIVE datos
borg create --compression auto,lzma ...
borg create --compression obfuscate,110,none ...
borg create --compression obfuscate,3,auto,zstd,10 ...
borg create --compression obfuscate,2,zstd,6 ...
borg create --compression obfuscate,250,zstd,3 ...
