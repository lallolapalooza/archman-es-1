MKDEP(1) Manual de Comandos Generales MKDEP(1)

NOMBRE

mkdep — construye la lista de dependencias de un Makefile

SINOPSIS

mkdep [-aDdiopqv] [-f archivo] [-P prefijo] [-s sufijos] -- [flags] archivo ...

DESCRIPCIÓN

mkdep toma un conjunto de flags para el compilador C y una lista de archivos fuente C como argumentos y construye un conjunto de dependencias de archivos de inclusión que se escriben en el archivo ``.depend''. Un ejemplo de su uso en un Makefile podría ser:

CFLAGS= -O -I../include
SRCS= file1.c file2.c

depend:
	mkdep -- ${CFLAGS} ${SRCS}

donde el macro SRCS es la lista de archivos fuente C y el macro CFLAGS es la lista de flags para el compilador C.

Las opciones son las siguientes:

-a
Añadir al archivo de salida, de modo que múltiples mkdep's puedan ejecutarse desde un solo Makefile.
-D
Postprocesar (como -d) pero leer la lista de nombres de archivo desde stdin.
-d
Postprocesar y fusionar dependencias de archivos creadas previamente (por ejemplo, por “cc -MD x.c”) en un solo archivo.
-f
Escribir las dependencias del archivo de inclusión en archivo, en lugar del predeterminado ``.depend''.
-i
Cuando se usa -d o -D, en lugar de incrustar el contenido de los archivos en el archivo de dependencias resultante, usar sentencias de inclusión para incluir los archivos de dependencia fuente.
-o
Añadir una línea .OPTIONAL adicional para cada archivo dependiente.
-P
Anteponer la cadena dada en prefijo a cada nombre de archivo destino. Esto es útil para programas que tienen archivos fuente en múltiples subdirectorios y un solo Makefile que los referencia a todos explícitamente (sin usar la funcionalidad VPATH porque puede haber archivos con el mismo nombre en cada subdirectorio).
-p
Hacer que mkdep produzca dependencias del tipo: 
programa: programa.c

para que las compilaciones posteriores produzcan programa directamente desde su módulo C en lugar de usar un módulo .o intermedio. Esto es útil para programas cuya fuente está contenida en un solo módulo. -p es equivalente a especificar un sufijo nulo con -s.

-q
No imprimir una advertencia de archivos inaccesibles cuando se da -d.
-s
Expandir cada nombre de archivo destino a una lista, reemplazando el sufijo ‘.o’ con cada elemento de sufijos. La lista de sufijos puede estar separada por espacios o comas.
-v
imprimir salida de depuración.

ARCHIVOS

.depend
Archivo que contiene la lista de dependencias.

VER TAMBIÉN

cc(1), cpp(1), make(1)

HISTORIA

El comando mkdep apareció en 4.3BSD-Tahoe.

ERRORES

Algunos caracteres especiales para make(1), especialmente el carácter de comentario, no se escapan correctamente si aparecen en los nombres de archivo. Esto puede conducir a una salida que no se puede analizar o causar silenciosamente que se pierdan dependencias.
