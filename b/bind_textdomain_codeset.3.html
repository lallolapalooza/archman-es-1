NOMBRE

bind_textdomain_codeset - establece la codificación de las traducciones de mensajes

SINOPSIS

#include <libintl.h>

char * bind_textdomain_codeset (const char * domainname,
                                const char * codeset);

DESCRIPCIÓN

La función bind_textdomain_codeset establece la codificación de salida para los catálogos de mensajes del dominio domainname.

Un dominio de mensajes es un conjunto de mensajes msgid traducibles. Normalmente, cada paquete de software tiene su propio dominio de mensajes.

Por defecto, la familia de funciones gettext devuelve mensajes traducidos en la codificación de caracteres de la configuración regional, que se puede obtener con nl_langinfo (CODESET). La necesidad de llamar a bind_textdomain_codeset surge para programas que almacenan cadenas de texto de forma independiente de la configuración regional (por ejemplo, UTF-8) y desean evitar una conversión de conjunto de caracteres adicional en los mensajes traducidos devueltos.

domainname debe ser una cadena no vacía.

Si codeset no es NULL, debe ser un nombre de codificación válido que pueda usarse para la función iconv_open. La función bind_textdomain_codeset establece la codificación de salida para los catálogos de mensajes pertenecientes al dominio domainname a codeset. La función realiza copias de las cadenas de los argumentos según sea necesario.

Si codeset es NULL, la función devuelve la codificación previamente establecida para el dominio domainname. El valor predeterminado es NULL, lo que indica la codificación de caracteres de la configuración regional.

VALOR DE RETORNO

Si tiene éxito, la función bind_textdomain_codeset devuelve la codificación actual para el dominio domainname, después de haberla cambiado posiblemente. La cadena resultante es válida hasta la próxima llamada a bind_textdomain_codeset para el mismo domainname y no debe ser modificada ni liberada. Si ocurre un error de asignación de memoria, establece errno a ENOMEM y devuelve NULL. Si no se ha establecido ninguna codificación para el dominio domainname, devuelve NULL.

ERRORES

Entre otros, pueden ocurrir los siguientes errores:

ENOMEM
No hay suficiente memoria disponible.

ERRORES DE PROGRAMACIÓN

El tipo de retorno debería ser const char *, pero es char * para evitar advertencias en código C anterior a ANSI C.
