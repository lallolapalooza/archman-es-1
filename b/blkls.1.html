BLKLS(1) Manual de Comandos Generales BLKLS(1)

NOMBRE

blkls - Listar o mostrar unidades de datos del sistema de archivos.

SINOPSIS

blkls [-aAelsvV] [-f tipo_fs ] [-i tipo_img ] [-o offset_img ] [-b tamaño_sector_dev] imagen [imágenes] [inicio-fin]

DESCRIPCIÓN

blkls abre la(s) imagen(es) nombrada(s) y copia las unidades de datos del sistema de archivos (bloques). Por defecto, blkls copia el contenido de los bloques de datos no asignados. blkls se llamaba dls en versiones de TSK anteriores a la 3.0.0. blkls se llamaba unrm en TCT.

ARGUMENTOS

-e
Copia cada bloque, incluidos los bloques de metadatos del sistema de archivos. La salida es el sistema de archivos completo.
-a
Muestra todos los bloques asignados (igual que -e si también se proporciona -A).
-A
Muestra todos los bloques no asignados (igual que -e si también se proporciona -a). Este es el comportamiento predeterminado.
-f tipo_fs
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-o offset_img
El desplazamiento del sector donde comienza el sistema de archivos en la imagen.
-b tamaño_sector_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-l
Lista la información de datos en formato de máquina del tiempo.
-s
Copia solo el espacio residual de la imagen.
-v
Activa el modo detallado, salida a stderr.
-V
Muestra la versión.
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se indica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
inicio-fin ...
Examina el número de bloque o rango de números especificado.
