NOMBRE

borg-import-tar - Crear un archivo de copia de seguridad a partir de un tarball

SINOPSIS

borg [opciones comunes] import-tar [opciones] ARCHIVO TARFILE

DESCRIPCIÓN

Este comando crea un archivo de copia de seguridad a partir de un tarball.

Al indicar '-' como ruta, Borg leerá un flujo de tar de la entrada estándar.

Por defecto (--tar-filter=auto), Borg detectará si el archivo está comprimido basándose en su extensión y lo canalizará a través de un filtro apropiado:

  • .tar.gz o .tgz: gzip -d
  • .tar.bz2 o .tbz: bzip2 -d
  • .tar.xz o .txz: xz -d
  • .tar.zstd o .tar.zst: zstd -d
  • .tar.lz4: lz4 -d

Alternativamente, se puede especificar explícitamente un programa --tar-filter. Este programa debe leer datos comprimidos de stdin y emitir un flujo de tar sin comprimir en stdout.

La mayoría de la documentación de borg create se aplica. Tenga en cuenta que este comando no admite la exclusión de archivos.

import-tar es una conversión con pérdida: las banderas BSD, ACLs, atributos extendidos (xattrs), atime y ctime no se exportan. La resolución de las marcas de tiempo se limita a segundos enteros, no a la resolución de nanosegundos que de otro modo soportaría Borg.

Una opción --sparse (como se encuentra en borg create) no es compatible.

import-tar lee tar POSIX.1-1988 (ustar), POSIX.1-2001 (pax), GNU tar, UNIX V7 tar y SunOS tar con atributos extendidos.

Para importar múltiples tarballs en un solo archivo, simplemente se pueden concatenar (por ejemplo, usando "cat") en un solo archivo, e importar con una opción --ignore-zeros para saltar los marcadores de detención entre ellos.

OPCIONES

Vea borg-common(1) para las opciones comunes de los comandos de Borg.

argumentos

ARCHIVO
nombre del archivo a crear (debe ser también un nombre de directorio válido)
TARFILE
archivo tar de entrada. "-" para leer desde stdin en su lugar.

opciones

--tar-filter
programa de filtrado para canalizar los datos
-e, --estadisticas
imprimir estadísticas para el archivo creado
--list
mostrar lista detallada de elementos (archivos, directorios, ...)
--filter STATUSCHARS
mostrar solo elementos con los caracteres de estado dados
--json
mostrar estadísticas como JSON (implica --stats)
--ignore-zeros
ignorar bloques llenos de ceros en el tarball de entrada

Opciones de archivo

--comment COMENTARIO
añadir un texto de comentario al archivo
--timestamp MARCA_DE_TIEMPO
especificar manualmente la fecha/hora de creación del archivo (UTC, formato yyyy-mm-ddThh:mm:ss). alternativamente, dar un archivo/directorio de referencia.
-c SEGUNDOS, --checkpoint-interval SEGUNDOS
escribir un punto de control cada SEGUNDOS segundos (Por defecto: 1800)
--chunker-params PARAMS
especificar los parámetros del fragmentador (ALGORITMO, CHUNK_MIN_EXP, CHUNK_MAX_EXP, HASH_MASK_BITS, HASH_WINDOW_SIZE). por defecto: buzhash,19,23,21,4095
-C COMPRESION, --compression COMPRESION
seleccionar algoritmo de compresión, ver la salida del comando "borg help compression" para más detalles.
