NOMBRE

bup-ftp - cliente similar a ftp para navegar repositorios bup

SINOPSIS

bup ftp

DESCRIPCIÓN

bup ftp es una herramienta de línea de comandos para navegar repositorios bup. Tiene comandos similares al comando Unix ftp(1). La jerarquía de archivos es la misma que la mostrada por bup-fuse(1) y bup-ls(1).

Nota: si tu sistema tiene instalada la biblioteca python-readline, puedes usar la tecla <tab> para completar nombres de archivo mientras navegas por tus datos de respaldo. Esto te ahorrará mucha escritura.

COMANDOS

Los siguientes comandos están disponibles dentro de bup ftp:

ls [-s] [-a] [ruta]
muestra el contenido de un directorio. Si no se proporciona argumento de ruta, se muestra el contenido del directorio actual. Si se proporciona -a, incluye también archivos ocultos (archivos que comienzan con un carácter .). Si se proporciona -s, cada archivo se muestra con su hash del archivo bup a su izquierda.
cd nombre_directorio
cambia a un directorio de trabajo diferente
pwd
muestra la ruta del directorio de trabajo actual
cat nombres_archivos...
muestra el contenido de uno o más archivos en la salida estándar
get nombre_archivo nombre_local
descarga el contenido de nombre_archivo y lo guarda en disco como nombre_local. Si se omite nombre_local, usa nombre_archivo como nombre local.
mget nombres_archivos...
descarga el contenido de los nombres_archivos dados y los guarda en disco con los mismos nombres. Los nombres de archivo pueden contener comodines de nombres de archivo de Unix (*, ?, etc.)
help
muestra una lista de comandos disponibles
quit
sale del cliente bup ftp

EJEMPLOS

$ bup ftp
bup> ls
mirespaldo/    turespaldo/
bup> cd mirespaldo/
bup> ls
2010-02-05-185507@   2010-02-05-185508@    latest@
bup> cd latest/
bup> ls
  (...etc...)
bup> get miarchivo
Guardando 'miarchivo'
bup> quit
