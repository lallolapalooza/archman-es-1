bytes(3perl) Guía de referencia para programadores de Perl bytes(3perl)

NOMBRE

bytes - Pragma de Perl para exponer los bytes individuales de los caracteres

AVISO

Debido a que el pragma `bytes` rompe la encapsulación (es decir, expone los detalles internos de cómo el ejecutable de Perl almacena actualmente una cadena), los valores de bytes resultantes están en una codificación no especificada.

Se desaconseja firmemente el uso de este módulo para fines que no sean de depuración. Si cree que las funciones aquí podrían ser útiles para su aplicación, esto podría indicar una discrepancia entre su modelo mental de Unicode en Perl y la realidad actual. En ese caso, puede que desee leer la documentación de Unicode de Perl: perluniintro, perlunitut, perlunifaq y perlunicode.

SINOPSIS

use bytes;
... chr(...);       # o bytes::chr
... index(...);     # o bytes::index
... length(...);    # o bytes::length
... ord(...);       # o bytes::ord
... rindex(...);    # o bytes::rindex
... substr(...);    # o bytes::substr
no bytes;

DESCRIPCIÓN

Los caracteres de Perl se almacenan internamente como secuencias de uno o más bytes. Este pragma permite examinar los bytes individuales que componen un carácter.

Originalmente, el pragma se diseñó con el objetivo más ambicioso de ayudar a incorporar Unicode en Perl, pero el enfoque que lo utilizaba resultó defectuoso, y el único uso legítimo que queda es para depuración, cuando necesita examinar de forma no destructiva los bytes individuales de los caracteres. Simplemente inserte este pragma temporalmente y elimínelo una vez finalizada la depuración.

El uso original se puede lograr mediante la codificación explícita (en lugar de la implícita de este pragma) utilizando el módulo Encode:

use Encode qw/encode/;
my $cadena_bytes_utf8   = encode "UTF8",   $cadena;
my $cadena_bytes_latin1 = encode "Latin1", $cadena;

O, si se necesita rendimiento y solo está interesado en la representación UTF-8:

utf8::encode(my $cadena_bytes_utf8 = $cadena);

"no bytes" se puede usar para revertir el efecto de "use bytes" dentro del ámbito léxico actual.

Como ejemplo, cuando Perl ve "$x = chr(400)", codifica el carácter en UTF-8 y lo almacena en $x. Luego se marca como datos de caracteres, por lo que, por ejemplo, "length $x" devuelve 1. Sin embargo, en el ámbito del pragma "bytes", $x se trata como una serie de bytes -los bytes que componen la codificación UTF8- y "length $x" devuelve 2:

$x = chr(400);
print "La longitud es ", length $x, "\n";     # "La longitud es 1"
printf "El contenido es %vd\n", $x;         # "El contenido es 400"
{
    use bytes; # o "require bytes; bytes::length()"
    print "La longitud es ", length $x, "\n"; # "La longitud es 2"
    printf "El contenido es %vd\n", $x;     # "El contenido es 198.144 (en
                                         # plataformas ASCII)"
}

chr(), ord(), substr(), index() y rindex() se comportan de manera similar.

Para más información sobre las implicaciones, consulte perluniintro y perlunicode.

bytes::length() es admitiblemente útil si necesita conocer la longitud en bytes de un escalar de Perl. Pero una forma más moderna es:

use Encode 'encode';
length(encode('UTF-8', $escalar))

LIMITACIONES

bytes::substr() no funciona como un lvalue().

VER TAMBIÉN

perluniintro, perlunicode, utf8, Encode
