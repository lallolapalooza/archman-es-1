NOMBRE

birdfont-autotrace - Convertir imagen ráster a gráficos vectoriales

SINOPSIS

birdfont-import birdfont-file svg-files ...

DESCRIPCIÓN

birdfont-autotrace generará archivos SVG a partir de imágenes ráster. Para una imagen con el nombre example.png, se generará un archivo con el nombre example.svg.

OPCIONES

-c, --cutoff
umbral de brillo, de 0.001 a 2, el valor predeterminado es 1
-d, --details
detalles, de 0.001 a 9.999, el valor predeterminado es 1
-h, --help
imprimir mensaje de ayuda
-q, --quadratic
usar puntos de control cuadráticos en lugar de cúbicos.
-s, --simplification
simplificación de trazado, de 0.001 a 1, el valor predeterminado es 0.5
