NOMBRE

bt-adapter - un agente bluetooth

SINOPSIS

bt-agent [OPCIÓN...]

Opciones de ayuda:
-h, --help

Opciones de aplicación:
-c, --capability=<capacidad>
-p, --pin
-d, --daemon

DESCRIPCIÓN

Esta utilidad interactiva se utiliza para gestionar las solicitudes entrantes de Bluetooth (por ejemplo, solicitud de código PIN, solicitud de autorización de una conexión/solicitud de servicio, etc.).

OPCIONES

-h, --help
Mostrar ayuda

-c, --capability <capacidad>
Especificar las capacidades de entrada y salida del agente.
`capacidad` puede ser una de las siguientes:
DisplayOnly
DisplayYesNo (por defecto)
KeyboardOnly
NoInputNoOutput
(si esta opción no se define, se usará `DisplayYesNo')

-p, --pin <ruta de archivo<gt>
Utilizar un archivo que contenga una lista de códigos de autorización para cada dispositivo por nombre o dirección MAC.
El contenido del archivo debe tener este formato:
AA:BB:CC:DD:EE:FF 123456
NombreDispositivoRemoto * (acepta cualquier código PIN)
Si se incluye un archivo PIN, verificará la clave de acceso del dispositivo de emparejamiento contra la clave incluida en el archivo. Autorizará automáticamente el dispositivo si la clave coincide, de lo contrario, solicitará al usuario una autorización manual.

-d, --daemon
Ejecutar el agente como un proceso en segundo plano (como un demonio).
El agente dependerá de un archivo PIN y no solicitará autorización manual del usuario. Los dispositivos que intenten emparejarse sin una clave de acceso válida definida en el archivo PIN serán rechazados automáticamente.

AUTOR
