NOMBRE

Bglafile - Generador de Archivos de Acceso a Módulos

SINOPSIS

bglafile [ opciones ] archivo ...

DESCRIPCIÓN

Bglafile es un generador de Archivos de Acceso a Módulos. Produce un archivo que se adapta a la opción -afile de Bigloo. Un Archivo de Acceso a Módulos es una lista de scheme. Cada elemento de esa lista es una lista de al menos dos elementos: el nombre de un módulo, el archivo que implementa ese módulo. Para que BEE (el Entorno de Desarrollo Integrado de Bigloo) pueda recuperar archivos a partir de nombres de módulos, es obligatorio que los primeros paréntesis de la lista global queden solos en una línea.

OPCIONES

archivo
Es un archivo que implementa un módulo. Bglafile lee ese archivo para descubrir el nombre del módulo implementado.
-v
Modo detallado (verbose)
-o <archivo>
Imprime el Archivo de Acceso a Módulos en el archivo archivo. Por defecto, se imprime la lista en la salida estándar.
-sufijo <suf>
Añade suf a la lista de sufijos de archivos fuente de bglafile. Los sufijos por defecto son "scm", "sch" y "bgl".

EJEMPLO

Si los tres archivos existen y contienen una cláusula de módulo Bigloo legal, entonces:


$ bglafile foo.scm bar.scm gee.scm

podría imprimir una lista como:

;; foo

;; Mar 15 Ago 12:17:24 1998

(


(foo "foo.scm")


(bar "bar.scm")


(gee "gee.scm")

)
