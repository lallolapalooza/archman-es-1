BDFTOPCF(1) Manual de Comandos Generales BDFTOPCF(1)

NOMBRE

bdftopcf - convierte fuentes X de formato Bitmap Distribution Format a formato Portable Compiled Format

SINOPSIS

bdftopcf [ -pn ] [ -un ] [ -m ] [ -l ] [ -M ] [ -L ] [ -t ] [ -i ] [ -o archivo_salida ] archivo_fuente.bdf

DESCRIPCIÓN

Bdftopcf es un compilador de fuentes para el servidor X y el servidor de fuentes. Las fuentes en formato Portable Compiled Format pueden ser leídas por cualquier arquitectura, aunque el archivo está estructurado para permitir que una arquitectura en particular las lea directamente sin reformatear. Esto permite una lectura rápida en la máquina apropiada, pero los archivos siguen siendo portátiles (aunque se leen más lentamente) en otras máquinas.

OPCIONES

-pn
Establece el relleno de los glifos de la fuente. Cada glifo en la fuente tendrá cada línea de escaneo rellenada a un múltiplo de n bytes, donde n es 1, 2, 4 u 8.
-un
Establece la unidad de línea de escaneo de la fuente. Cuando el orden de bits de la fuente es diferente del orden de bytes de la fuente, la unidad de línea de escaneo n describe qué unidad de datos (en bytes) se deben intercambiar; la unidad i puede ser 1, 2 o 4 bytes.
-m
Establece el orden de bits de la fuente a MSB (bit más significativo) primero. Los bits para cada glifo se colocarán en este orden; es decir, el bit más a la izquierda en la pantalla estará en el bit de mayor valor en cada unidad.
-l
Establece el orden de bits de la fuente a LSB (bit menos significativo) primero. El bit más a la izquierda en la pantalla estará en el bit de menor valor en cada unidad.
-M
Establece el orden de bytes de la fuente a MSB primero. Todos los datos multibyte en el archivo (métricas, mapas de bits y todo lo demás) se escribirán con el byte más significativo primero.
-L
Establece el orden de bytes de la fuente a LSB primero. Todos los datos multibyte en el archivo (métricas, mapas de bits y todo lo demás) se escribirán con el byte menos significativo primero.
-t
Cuando se especifica esta opción, bdftopcf convertirá las fuentes en fuentes de "terminal" cuando sea posible. Una fuente de terminal tiene cada imagen de glifo rellena al mismo tamaño; el servidor X puede representar estos tipos de fuentes más rápidamente.
-i
Esta opción inhibe el cálculo normal de métricas de tinta. Cuando una fuente tiene imágenes de glifos que no llenan la imagen del mapa de bits (es decir, los píxeles "encendidos" no se extienden a los bordes de las métricas), bdftopcf calcula las métricas de tinta reales y las coloca en el archivo .pcf; la opción -t inhibe este comportamiento.
-o nombre-archivo-salida
Por defecto, bdftopcf escribe el archivo pcf en la salida estándar; esta opción proporciona el nombre de un archivo que se utilizará en su lugar.
-v
Imprime la información de la versión y sale.
