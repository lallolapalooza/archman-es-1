boltctl(1)

NOMBRE

boltctl — utilidad de línea de comandos para interactuar con el servicio Bolt

SINOPSIS

boltctl [Opción...] [Comando]

DESCRIPCIÓN

boltctl es una utilidad de línea de comandos para interactuar con el servicio Bolt. Bolt es un agente que gestiona dispositivos Thunderbolt. Permite a los usuarios autorizar y denegar dispositivos Thunderbolt, ver información sobre dispositivos y el sistema, y apagar el sistema de forma segura cuando se utilizan dispositivos Thunderbolt.

OPCIONES

El comando no tiene opciones específicas de línea de comandos. Las opciones que acepta son las opciones estándar de systemd para interactuar con servicios.

  • -h, --help: Muestra el mensaje de ayuda.
  • --version: Muestra la versión del programa.

COMANDOS

Los siguientes comandos están disponibles:

  • list: Lista todos los dispositivos Thunderbolt detectados y su estado (autorizado, denegado o pendiente).
  • info [dispositivo]: Muestra información detallada sobre un dispositivo específico. Si no se especifica ningún dispositivo, muestra información sobre todos los dispositivos.
  • authorize [dispositivo]: Autoriza un dispositivo Thunderbolt. Si no se especifica ningún dispositivo, se autorizarán todos los dispositivos pendientes.
  • deny [dispositivo]: Deniega un dispositivo Thunderbolt. Si no se especifica ningún dispositivo, se denegarán todos los dispositivos pendientes.
  • enroll [dispositivo]: Inscribe un dispositivo Thunderbolt. Esto suele ser necesario para dispositivos que requieren autorización permanente.
  • lock: Bloquea el puerto Thunderbolt, impidiendo que se conecten nuevos dispositivos.
  • unlock: Desbloquea el puerto Thunderbolt, permitiendo que se conecten nuevos dispositivos.
  • poweroff: Apaga el sistema de forma segura, liberando los recursos utilizados por los dispositivos Thunderbolt. Útil antes de desconectar dispositivos o apagar el sistema.
  • help: Muestra la ayuda sobre los comandos disponibles.

El argumento [dispositivo] puede ser el nombre del dispositivo (por ejemplo, THNDR0000:00) o el índice del dispositivo (por ejemplo, 0).
