SALIDA

JSON

Los comandos que admiten la salida JSON especifican sus formatos como una representación serializada de una estructura C++ struct o un array de ellas.

Por 
ejemplo:
struct package
{
  string name;
};
struct configuration
{
  uint64_t         id;
  string           path;
  optional<string> name;
  bool             default;
  vector<package>  packages;
}
;

Un ejemplo de la representación JSON serializada de struct configuración

: 
{
  "id": 1,
  "path": "/tmp/hello-gcc",
  "name": "gcc",
  "default": true,
  "packages": [
    {
      "name": "hello"
    }
  ]
}

Esta sección proporciona detalles sobre las propiedades generales de tales formatos y la semántica de la serialización de

struct.

El orden de los miembros en un objeto JSON está fijado como se especifica en el correspondiente struct. Aunque en el futuro pueden añadirse nuevos miembros (y deben ser ignorados por consumidores más antiguos), la semántica de los miembros existentes (incluyendo si la entrada de nivel superior es un objeto o un array) no puede

cambiar.

Un miembro de objeto es obligatorio a menos que su tipo sea optional<>, bool, o vector<> (array). Para bool, un miembro ausente significa false. Para vector<>, un miembro ausente significa vacío. Un array de nivel superior vacío siempre está

presente.

Por ejemplo, el siguiente texto JSON es una posible serialización de la struct configuración a

nterior: 
{
  "id": 1,
"path": "/tm
p/hello-gcc" }
