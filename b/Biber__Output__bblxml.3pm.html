Biber::Output::bblxml(3pm) Documentación de Perl contribuida por el usuario Biber::Output::bblxml(3pm)

NOMBRE

Biber::Output::bblxml - clase para la salida de Biber de .bbl en formato XML

new

Inicializa un objeto Biber::Output::bbxml

set_output_target_file

Establece el archivo de destino de la salida de un objeto Biber::Output::bblxml
Una conveniencia alrededor de set_output_target para que podamos mantener un registro
del nombre del archivo

set_output_entry

Establece la salida .bblxml para una entrada. Esta es la médula
de la salida .bbl

output

Método de salida BBL: se encarga de generar las entradas en el orden explícito
derivado del orden virtual de las claves de cita después de ordenar por clave de ordenación.

create_output_section

Crea la salida a partir de los datos de las secciones y la añade al
objeto de salida.
