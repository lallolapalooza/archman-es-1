NOMBRE

BEGIN - iniciar un bloque de transacción

SINOPSIS

BEGIN [ WORK | TRANSACTION ] [ modo_transaccion [, ...] ]
donde modo_transaccion es uno de:
    NIVEL DE AISLAMIENTO { SERIALIZABLE | REPEATABLE READ | READ COMMITTED | READ UNCOMMITTED }
    READ WRITE | READ ONLY
    [ NOT ] DEFERRABLE

DESCRIPCIÓN

BEGIN inicia un bloque de transacción, es decir, todas las sentencias después de un comando BEGIN se ejecutarán en una única transacción hasta que se emita un COMMIT o ROLLBACK explícito. Por defecto (sin BEGIN), PostgreSQL ejecuta las transacciones en modo "autocommit", es decir, cada sentencia se ejecuta en su propia transacción y se realiza una confirmación implícitamente al final de la sentencia (si la ejecución fue exitosa, de lo contrario se realiza una reversión).

Las sentencias se ejecutan más rápido en un bloque de transacción, ya que el inicio/confirmación de la transacción requiere una actividad significativa de CPU y disco. La ejecución de múltiples sentencias dentro de una transacción también es útil para garantizar la consistencia al realizar varios cambios relacionados: otras sesiones no podrán ver los estados intermedios en los que no se han realizado todas las actualizaciones relacionadas.

Si se especifica el nivel de aislamiento, el modo de lectura/escritura o el modo diferible, la nueva transacción tendrá esas características, como si se hubiera ejecutado SET TRANSACTION.

PARÁMETROS

WORK
TRANSACTION

Palabras clave opcionales. No tienen efecto.

Consulte SET TRANSACTION (SET_TRANSACTION(7)) para obtener información sobre el significado de los otros parámetros de esta sentencia.

NOTAS

START TRANSACTION tiene la misma funcionalidad que BEGIN.

Utilice COMMIT o ROLLBACK para finalizar un bloque de transacción.

Emitir BEGIN cuando ya se está dentro de un bloque de transacción provocará un mensaje de advertencia. El estado de la transacción no se ve afectado. Para anidar transacciones dentro de un bloque de transacción, use puntos de salvaguarda (consulte SAVEPOINT(7)).

Por razones de compatibilidad retroactiva, las comas entre modos_transaccion sucesivos pueden omitirse.

EJEMPLOS

Para iniciar un bloque de transacción:

BEGIN;

COMPATIBILIDAD

BEGIN es una extensión del lenguaje de PostgreSQL. Es equivalente al comando estándar SQL START TRANSACTION, cuya página de referencia contiene información adicional de compatibilidad.

El modo_transaccion DEFERRABLE es una extensión del lenguaje de PostgreSQL.

Por cierto, la palabra clave BEGIN se utiliza para un propósito diferente en SQL embebido. Se recomienda tener cuidado con las semánticas de transacción al portar aplicaciones de bases de datos.

VER TAMBIÉN

COMMIT(7), ROLLBACK(7), START TRANSACTION (START_TRANSACTION(7)), SAVEPOINT(7)
