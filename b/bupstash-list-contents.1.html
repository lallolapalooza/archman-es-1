bupstash-list-contents(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Lista el contenido de las instantáneas.

bupstash list-contents [OPCIONES] CONSULTA...

DESCRIPCIÓN

bupstash list-contents lista el contenido del elemento que coincide con la consulta dada.

Los elementos creados al usar bupstash put en un directorio tendrán un índice asociado, otros elementos no son listables.

FORMATOS DE SALIDA

Humano

Cuando --format se establece en human, bupstash list-contents produce filas alineadas que consisten en:

PERMISOS TAMAÑO AÑO/MES/DÍA HORA:MINUTO:SEGUNDO RUTA...

La fecha incluida es la hora del último cambio en un archivo dado, tal como la informa el sistema operativo en el momento de la instantánea.

Prefiera usar uno de los formatos legibles por máquina versionados al escribir scripts.

JSONl1

Cuando --format se establece en jsonl1, bupstash list-contents produce un objeto JSON por línea.

Cada línea tiene el siguiente esquema JSON:

{ "path": cadena | [ bytes... ], "mode": número, "size": número, "uid": número, "gid": número, "mtime": número, "mtime_nsec": número, "ctime": número, "ctime_nsec": número, "norm_dev": número, "ino": número, "nlink": número, "link_target": cadena | null, "dev_major": número | null, "dev_minor": número | null, "xattrs": {cadena : cadena | [bytes...] ...} | null, "sparse": booleano, "data_hash": "$KIND[:$HEXBYTE]" | null }

LENGUAJE DE CONSULTA

Para obtener documentación completa sobre el lenguaje de consulta, consulte bupstash-query-language(7).

CACHÉ DE CONSULTAS

El comando list-contents utiliza los mismos mecanismos de caché de consultas que bupstash-list(1), consulte esa página para obtener más información sobre la caché de consultas.

OPCIONES

-r, --repository REPOSITORIO
El repositorio al que conectarse, , puede tener el formato ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso SSH está configurado. Si no se especifica, se establece en BUPSTASH_REPOSITORY.
-k, --key CLAVE
Clave utilizada para descifrar datos y metadatos. Si no se establece, el valor predeterminado es BUPSTASH_KEY.
--format FORMATO
Establece el formato de salida en uno de los siguientes: ´human´, ´jsonl´.
--query-cache RUTA
Ruta al archivo de caché de consultas, el valor predeterminado es uno de los siguientes, en orden, siempre que las variables de entorno apropiadas estén configuradas: $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache o $HOME/.cache/bupstash/bupstash.qcache.
--pick RUTA
Lista un subdirectorio de la consulta.
--utc-timestamps
Muestra y busca contra marcas de tiempo en hora UTC en lugar de hora local.
-q, --quiet
Ser silencioso, implica --no-progress.

MEDIO AMBIENTE

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede tener el formato ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso SSH está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando a ejecutar para conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_KEY
Ruta a una clave primaria que se utilizará para descifrar datos y metadatos.
BUPSTASH_KEY_COMMAND
Un comando a ejecutar que debe imprimir los datos de la clave, se puede utilizar en lugar de BUPSTASH_KEY para obtener la clave de ubicaciones arbitrarias como la red u otros almacenamientos secretos.
BUPSTASH_QUERY_CACHE
Ruta al archivo de caché de consultas a utilizar.

EJEMPLOS

Obtener un elemento con un ID específico del repositorio

$ bupstash list-contents id="14eb*" drwxr-xr-x 0 2020/10/30 13:32:04 . -rw-r--r-- 1967 2020/10/30 13:32:04 data.txt
