NOMBRE

bibmradd.pl - añadir números MR a artículos en un archivo bib dado

SINOPSIS

bibmradd [-d] [-f] [-e 1|0] [-o salida] archivo_bib

OPCIONES

-d
Modo de depuración
-e
Si es 1 (predeterminado), añade un mrnumber vacío si no se puede encontrar un mr. Esto evita búsquedas repetidas para las mismas entradas si agregas nuevas entradas al archivo. Llamar a "-e 0" suprime este comportamiento.
-f
Forzar la búsqueda de números MR incluso si la entrada ya tiene uno.
-o salida
Archivo de salida. Si esta opción no se utiliza, el nombre del archivo de salida se forma añadiendo "_mr" al archivo de entrada.

DESCRIPCIÓN

El script lee un archivo BibTeX. Comprueba si las entradas tienen mrnumbers. Si no, intenta encontrar los números en sitios de Internet. El resultado es un archivo BibTeX con los campos "mrnumber=..." añadidos.

El nombre del archivo de salida se establece mediante la opción -o o se deriva añadiendo el sufijo "_mr" al archivo de salida.

Consulta el script "bibdoiadd" para obtener más detalles sobre el procesamiento.
