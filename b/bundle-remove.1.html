NOMBRE

bundle-remove - Elimina gems del Gemfile

SINOPSIS

bundle remove [GEM [GEM ...]] [--install]

DESCRIPCIÓN

Elimina las gems dadas del Gemfile asegurando al mismo tiempo que el Gemfile resultante siga siendo válido. Si una gem no puede ser eliminada, se imprime una advertencia. Si una gem ya está ausente del Gemfile, se genera un error.

OPCIONES

--install
Ejecuta bundle install después de que las gems dadas hayan sido eliminadas del Gemfile, lo que asegura que tanto el lockfile como las gems instaladas en disco también se actualicen para eliminar la(s) gem(s) dada(s).

Ejemplo:

bundle remove rails

bundle remove rails rack

bundle remove rails rack --install
