NOMBRE

borg-export-tar - Exportar el contenido del archivo como un tarball

SINOPSIS

borg [opciones comunes] export-tar [opciones] ARCHIVO FICHERO [RUTA...]

DESCRIPCIÓN

Este comando crea un tarball a partir de un archivo.

Al proporcionar '-' como FICHERO de salida, Borg escribirá un flujo tar en la salida estándar.

Por defecto (--tar-filter=auto), Borg detectará si el FICHERO debe comprimirse basándose en su extensión y canalizará el tarball a través de un filtro apropiado antes de escribirlo en FICHERO:

  • .tar.gz o .tgz: gzip
  • .tar.bz2 o .tbz: bzip2
  • .tar.xz o .txz: xz
  • .tar.zstd o .tar.zst: zstd
  • .tar.lz4: lz4

Alternativamente, se puede especificar explícitamente un programa --tar-filter. Este debe leer el flujo tar sin comprimir desde stdin y escribir un flujo tar comprimido/filtrado a stdout.

El tarball generado utiliza el formato GNU tar.

export-tar es una conversión con pérdida: las banderas BSD, ACLs, atributos extendidos (xattrs), atime y ctime no se exportan. La resolución de la marca de tiempo se limita a segundos enteros, no a la resolución de nanosegundos soportada por Borg.

Una opción --sparse (como se encuentra en borg extract) no es compatible.

Por defecto, se extrae todo el archivo, pero se puede seleccionar un subconjunto de archivos y directorios pasando una lista de RUTAS como argumentos. La selección de archivos puede restringirse aún más utilizando la opción --exclude.

Para obtener más ayuda sobre los patrones de inclusión/exclusión, consulte la salida del comando borg_patterns.

--progress puede ser más lento que no mostrar el progreso, ya que realiza un pase adicional sobre los metadatos del archivo.

OPCIONES

Consulte borg-common(1) para ver las opciones comunes de los comandos Borg.

argumentos

ARCHIVO
archivo a exportar
FICHERO
archivo tar de salida. "-" para escribir en stdout en su lugar.
RUTA
rutas a extraer; se admiten patrones

opciones

--tar-filter
programa de filtro para canalizar datos a través
--list
mostrar lista detallada de elementos (archivos, directorios, ...)

Opciones de inclusión/exclusión

-e PATRÓN, --exclude PATRÓN
excluir rutas que coincidan con PATRÓN
--exclude-from ARCHIVOEXCL
leer patrones de exclusión de ARCHIVOEXCL, uno por línea
--pattern PATRÓN
incluir/excluir rutas que coincidan con PATRÓN
--patterns-from ARCHIVOPATR
leer patrones de inclusión/exclusión de ARCHIVOPATR, uno por línea
--strip-components NÚMERO
Elimina el número especificado de elementos de ruta iniciales. Las rutas con menos elementos se omitirán silenciosamente.

EJEMPLOS

# Exportar como un tar no comprimido.
$ borg export-tar /ruta/a/repo::Lunes Lunes.tar
# Excluir algunos tipos; comprimir usando gzip.
$ borg export-tar /ruta/a/repo::Lunes Lunes.tar.gz --exclude '*.so'
# Usar un nivel de compresión más alto con gzip.
$ borg export-tar --tar-filter="gzip -9" testrepo::linux Lunes.tar.gz
# Exportar un tar, pero en lugar de guardarlo en disco,
# subirlo a un sitio remoto usando curl.
$ borg export-tar /ruta/a/repo::Lunes - | curl --data-binary @- https://algundonde/POST
# Extracción remota vía "tarpipe".
$ borg export-tar /ruta/a/repo::Lunes - | ssh algunlugar "cd extraido; tar x"
