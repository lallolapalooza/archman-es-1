BF_TAR(1) Manual de referencia de Bogofilter BF_TAR(1)

NOMBRE

bf_tar - script de shell para escribir un archivo tar de un directorio de bogofilter en la salida estándar

SINOPSIS

bf_tar [-r] [-R] directorio_bogofilter

DESCRIPCIÓN

bf_tar empaqueta un directorio de trabajo de bogofilter en formato tar y lo copia a la salida estándar (tu consola, o donde lo redirijas, ver EJEMPLOS más abajo).

OPCIONES

La opción -r hace que bf_tar elimine los archivos de registro inactivos después de que el archivo se haya escrito correctamente. Por defecto, se dejan los archivos de registro.

La opción -R hace que bf_tar elimine los archivos de registro inactivos antes de que se escriba el archivo. Esto puede reducir las posibilidades de que el archivo resultante sea recuperable si se daña. Sin embargo, el archivo puede ser más pequeño. Por defecto, se dejan los archivos de registro.

ESTADO DE SALIDA

El script sale con el código de estado 0 si todo salió bien, y un valor distinto de cero si encontró problemas.

EJEMPLOS

•bf_tar ~/.bogofilter > outfile.tar

Escribe un archivo .tar estándar que contiene los archivos esenciales de ~/.bogofilter en outfile.tar.

•bf_tar ~/.bogofilter | gzip -9 -c > outfile.tar.gz

Escribe un archivo .tar.gz comprimido con gzip que contiene los archivos esenciales de ~/.bogofilter en outfile.tar.gz.

•bf_tar `pwd`/mydirectory > outfile.tar

Anteponer $(pwd)/ o `pwd`/ si desea especificar una ruta absoluta en lugar de una ruta relativa.

NOTAS

Este script está diseñado para usarse con versiones de bogofilter basadas en Berkeley DB.

Este script requiere una utilidad pax compatible con SUSv2.

Este script espera un shell compatible con SUSv2. Los sistemas Solaris deberían tener instalado el paquete SUNWxcu4 (cuando bogofilter esté configurado) para que se pueda usar /usr/xpg4/bin/sh.
