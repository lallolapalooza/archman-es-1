Nombre

btmgmt - herramienta interactiva de gestión de bluetooth

SINOPSIS

btmgmt [--opciones] [comandos]

DESCRIPCIÓN

btmgmt(1) herramienta interactiva de gestión de bluetooth. La herramienta emite comandos al Kernel usando el socket de Gestión de Bluetooth, algunos comandos pueden requerir capacidad de administrador de red para funcionar ya que la interfaz de Gestión de Bluetooth se considera una interfaz de bajo nivel destinada a herramientas como bluetoothd(8), no se recomienda que las aplicaciones la utilicen directamente ya que puede dar lugar a un comportamiento inesperado.

OPCIONES

-i/--index
Especificar índice del adaptador
-m/-monitor
Habilitar salida de monitor
-t/--timeout
Tiempo de espera en segundos para el modo no interactivo
-v/--version
Mostrar versión
-i/--init-script
Archivo de script de inicialización
-h/--help
Mostrar ayuda

COMANDOS

main
Ver bluetoothctl-mgmt(1)
monitor
Ver bluetoothctl-monitor(1)

AUTOMATIZACIÓN

Dos formas comunes de automatizar la herramienta son pasar los comandos directamente como en el siguiente ejemplo:

btmgmt <<EOF
list
show
EOF

O crear un script y pasarlo como script de inicialización:

$ vi test-script.bt
list
show
quit
:wq
$ btmgmt --init-script=test-script
