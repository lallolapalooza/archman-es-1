EJEMPLO

S

La configuración de una interfaz batadv generalmente consiste en la creación de la interfaz principal, la adjunción de la interfaz física (inferior), el ajuste de la configuración y la activación de la

interfaz: 


# crear la interfaz batadv (malla) bat0 con el algoritmo de enrutamiento B.A.T.M.A.N. IV
$ batctl meshif bat0 interface create routing_algo BATMAN_IV
# añadir la interfaz mesh0 (ya activa y en funcionamiento) como interfaz física (inferior) a bat0
$ batctl meshif bat0 interface -M add mesh0
# cambiar algunas configuraciones para adaptarse mejor a los requisitos del usuario
$ batctl meshif bat0 orig_interval 5000
$ batctl meshif bat0 distributed_arp_table disable
...
# activar la interfaz batadv (malla) antes de que sea posible usarla
$ ip link set up dev
bat0

Esto solo se asegura de que la funcionalidad de la capa 2 de bat0 esté iniciada. Es responsabilidad del usuario asegurarse de que el dispositivo bat0 en sí mismo esté adjunto a un puente, configurado con una dirección IP (manualmente/cliente DHCP/...) o integrado en otras partes del sistema antes de que se

utilice.

También las interfaces físicas (inferiores) adjuntas a la interfaz batadv deben ser configuradas por el usuario para soportar el transporte de paquetes Ethernet de unidifusión y difusión entre sus pares vinculados. La razón más común para una malla batman-adv que no funciona son configuraciones incorrectas de las interfaces físicas, errores de hardware, firmware o controlador que impiden que algunos de los tipos de paquetes se intercambien

correctamente.

El estado actual de la interfaz se puede comprobar utilizando las tablas de depuración. A menudo es relevante comprobar desde qué vecinos directos se recibieron los paquetes de descubrimiento. El siguiente paso es comprobar las rutas (preferidas) hacia los originadores. Estas solo se establecerán cuando la métrica haya detectado conexiones bidireccionales entre vecinos y pueda haber reenviado paquetes de descubrimiento de nodos/originadores no directamente

alcanzables. 


# obtener la lista de vecinos de los que el nodo actual pudo recibir paquetes de descubrimiento
$ batctl meshif bat0 neighbors
# obtener las rutas (preferidas) que encontró el algoritmo de enrutamiento
$ batctl meshif bat0
originators

Si la interfaz bat0 ya no debe ser utilizada por el sistema, se puede destruir de

nuevo: 


# destruir la interfaz y permitir que el sistema elimine su estado
$ batctl meshi

Este archivo es similar al archivo /etc/hosts. Puedes escribir una dirección MAC y un nombre de host por línea. batc
tl buscará bat-hosts en /etc, tu directorio de inicio y el directorio actual. Los datos encontrados se utilizan par
a hacer coincidir la dirección MAC con el nombre de host proporcionado o para reemplazar las direcciones MAC en la
salida de depuración y los registros. Los nombres de host son mucho más fáciles de recordar que las direcciones MAC.
