NOMBRE

bpftool-perf - herramienta para la inspección de adjunciones de prog bpf relacionadas con perf

SINOPSIS

bpftool [OPCIONES] perf COMANDO

OPCIONES := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMANDOS := { show | list | help }

COMANDOS PERF

bpftool perf { show | list }
bpftool perf help

DESCRIPCIÓN

bpftool perf { show | list }
Lista todas las adjunciones de raw_tracepoint, tracepoint, kprobe en el sistema.

La salida comenzará con el id del proceso y el descriptor de archivo en ese proceso, seguido del id del programa bpf, información de la adjunción y el punto de adjunción. El punto de adjunción para raw_tracepoint/tracepoint es el nombre de la sonda de rastreo. El punto de adjunción para k[ret]probe es el nombre del símbolo y el desplazamiento, o una dirección virtual del kernel. El punto de adjunción para u[ret]probe es el nombre del archivo y el desplazamiento del archivo.

bpftool perf help
Imprime un mensaje de ayuda corto.

OPCIONES

-h, --help
Imprime un mensaje de ayuda corto (similar a bpftool help).
-V, --version
Imprime el número de versión de bpftool (similar a bpftool version), el número de la versión de libbpf en uso y las características opcionales que se incluyeron cuando se compiló bpftool. Las características opcionales incluyen enlazar contra LLVM o libbfd para proporcionar el desensamblador para programas JIT-teados (bpftool prog dump jited) y el uso de esqueletos BPF (algunas características como bpftool prog profile o la visualización de pids asociados a objetos BPF pueden depender de ello).
-j, --json
Genera salida JSON. Para los comandos que no pueden producir JSON, esta opción no tiene efecto.
-p, --pretty
Genera salida JSON legible por humanos. Implica -j.
-d, --debug
Imprime todos los registros disponibles, incluso la información a nivel de depuración. Esto incluye registros de libbpf y del verificador, al intentar cargar programas.
