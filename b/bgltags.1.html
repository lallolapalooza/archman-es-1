NOMBRE

bgltags - genera un archivo de etiquetas para Emacs

SINOPSIS

bgltags [ opciones ] [ archivo_objeto [ gmon.out ] ]

DESCRIPCIÓN

El programa bgltags se utiliza para crear un archivo de tabla de etiquetas, en un formato entendido por emacs(1). Este programa entiende la sintaxis de los archivos Bigloo. Lee los archivos especificados en la línea de comandos y escribe una tabla de etiquetas (por defecto: TAGS) en el directorio de trabajo actual. Los archivos especificados con nombres de archivo relativos se registrarán en la tabla de etiquetas con nombres de archivo relativos al directorio donde reside la tabla de etiquetas. Los archivos especificados con nombres de archivo absolutos se registrarán con nombres de archivo absolutos. El programa no reconoce el lenguaje utilizado en un archivo de entrada basándose en su nombre de archivo y contenido. El interruptor --language se puede usar para forzar el análisis de los nombres de archivo que siguen al interruptor según el lenguaje dado, anulando las suposiciones basadas en las extensiones de los nombres de archivo. Los archivos fuente que no son Scheme son procesados en realidad por el programa etags.

OPCIONES

-a, --append
Añade a un archivo de etiquetas existente.
-o archivo_etiqueta, --output=archivo_etiqueta
Nombre explícito del archivo para la tabla de etiquetas; anula el valor predeterminado `TAGS'.
-v
Imprime la versión actual del programa.
-module
Genera una entrada en la tabla para cada módulo. Normalmente, los identificadores de los módulos no se indexan en la tabla de etiquetas.

VÉASE TAMBIÉN

bigloo(1), bglafile(1), bgldepend(1), etags(1), emacs(1), bglmco(1), xemacs(1)
