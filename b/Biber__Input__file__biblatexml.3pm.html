extract_entries

Rutina principal de extracción de datos.
Acepta un identificador de fuente de datos (nombre de archivo en este caso),
preprocesa el archivo y luego busca las claves pasadas,
creando entradas cuando las encuentra y devuelve un
array de claves que no encontró.

create_entry

Crea un objeto Biber::Entry a partir de una entrada encontrada en una fuente de datos biblatexml

parsename

Dada una nodo de nombre, esta función devuelve un objeto Biber::Entry::Name
Devuelve un objeto que internamente se parece a esto:
{ given             => {string => 'John', initial => ['J']},
  family            => {string => 'Doe', initial => ['D']},
  middle            => {string => 'Fred', initial => ['F']},
  prefix            => {string => undef, initial => undef},
  suffix            => {string => undef, initial => undef},
  basenamestring    => 'Doe',
  namestring        => 'Doe, John Fred',
  nameinitstring    => 'Doe_JF',
  gender            => sm,
  useprefix         => 1,
  hashid            => 'someid',
  sortingnamekeytemplatename => 'templatename'
}

NOMBRE

Biber::Input::file::biblatexml - busca en un archivo BibLaTeXML una entrada y la crea si la encuentra

DESCRIPCIÓN

Proporciona el método extract_entries() para obtener entradas de una fuente de datos biblatexml e instanciar objetos Biber::Entry para lo que encuentre.
