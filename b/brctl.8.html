DESCRIPCIÓ

N

brctl se usa para configurar, mantener e inspeccionar la configuración del puente ethernet en el kernel de

Linux.

Un puente ethernet es un dispositivo comúnmente usado para conectar diferentes redes ethernet entre sí, de modo que estas ethernets aparezcan como una sola ethernet para los

participantes.

Cada una de las ethernets conectadas corresponde a una interfaz física en el p

uente. Estas ethernets individuales se agrupan en una ethernet más grande ('l
ógica'), esta ethernet más grande corresponde a la interfaz de red del puente.

INSTANCIA

S

El comando brctl addbr <nombre> crea una nueva instancia del puente ethernet. La interfaz de red correspondiente al puente se llamará <nombre>

.

El comando brctl delbr <nombre> elimina la instancia <nombre> del puente ethernet. ¡La interfaz de red correspondiente al puente debe estar caída antes de que pueda ser

eliminada!

El comando brctl show muestra todas las insta

ncias actuales del
puente ethernet.

PUERTO

S

Cada puente tiene un número de puertos conectados a él. El tráfico de red que entra por cualquiera de estos puertos será reenviado a los otros puertos de forma transparente, de modo que el puente sea invisible para el resto de la red (es decir, no aparecerá en traceroute(8) )

.

El comando brctl addif <brname> <ifname> hará que la interfaz <ifname> sea un puerto del puente <brname>. Esto significa que todos los tramas recibidos en <ifname> serán procesados como si estuvieran destinados al puente. Además, al enviar tramas en <brname>, <ifname> será considerada como una interfaz de salida

potencial.

El comando brctl delif <brname> <ifname> desacoplará la interfaz <ifname> del puente <brname>

.

El comando brctl show <brname> mostrará información

sobre el puente y sus
puertos conectados.

ENVEJECIMIEN

TO

El puente mantiene un registro de las direcciones ethernet vistas en cada puerto. Cuando necesita reenviar un trama, y resulta que sabe en qué puerto se encuentra la dirección ethernet de destino (especificada en el trama), puede 'hacer trampa' reenviando el trama solo a ese puerto, ahorrando así muchas copias y transmisiones

redundantes.

Sin embargo, los datos de ubicación de direcciones ethernet no son estáticos. Las máquinas pueden moverse a otros puertos, las tarjetas de red pueden ser reemplazadas (lo que cambia la dirección ethernet de la máquina),

etc.

brctl showmacs <brname> muestra una lista de direcciones MAC aprendidas para este

puente.

brctl setageing <brname> <time> establece el tiempo de envejecimiento de la dirección ethernet (MAC), en segundos. Después de <time> segundos sin haber visto un trama proveniente de una dirección determinada, el puente expirará (eliminará) esa dirección de la Base de Datos de Reenvío (fdb)

.

brctl setgcint <brname> <time> establece el intervalo de recolección de basura para el puente <brname> a <time> segundos.

Esto significa que el puente comprobará la base de datos de
reenvío en busca de entradas caducadas cada <time> segundos.

PROTOCOLO DE ÁRBOL DE

EXPANSIÓN

Múltiples puentes ethernet pueden trabajar juntos para crear redes de ethernets aún más grandes usando el protocolo de árbol de expansión IEEE 802.1d. Este protocolo se usa para encontrar el camino más corto entre dos ethernets y para eliminar bucles de la topología. Como este protocolo es un estándar, los puentes de Linux interoperarán correctamente con otros productos de puentes de terceros. Los puentes se comunican entre sí enviando y recibiendo BPDUs (Bridge Protocol Data Units). Estas BPDUs pueden ser reconocidas por una dirección de destino ethernet de 01:80:c2:00:00:

00.

El protocolo de árbol de expansión también puede ser desactivado (para esas situaciones donde simplemente no tiene sentido, por ejemplo cuando esta máquina Linux es el único puente en la LAN, o cuando sabes que no hay bucles en la topología.

)

brctl(8) puede usarse para configurar ciertos parámetros del protocolo de árbol de expansión. Para una explicación de estos parámetros, consulta la especificación IEEE 802.1d (o envíame un correo electrónico). Los valores por defecto deberían estar bien. Si no sabes qué significan estos parámetros, probablemente no sentirás el deseo de

ajustarlos.

brctl stp <bridge> <state> controla la participación de esta instancia de puente en el protocolo de árbol de expansión. Si <state> es "on" o "yes" el STP será activado, de lo contrario será desactivado. Cuando esté desactivado, el puente no enviará ni recibirá BPDUs, y por lo tanto no participará en el protocolo de árbol de expansión. Si tu puente no es el único puente en la LAN, o si hay bucles en la topología de la LAN, NO actives esta opción. Si activas esta opción, por favor, sé consciente de lo que estás

haciendo.

brctl setbridgeprio <bridge> <priority> establece la prioridad del puente a <priority>. El valor de prioridad es una cantidad sin signo de 16 bits (un número entre 0 y 65535), y no tiene dimensión. Los valores de prioridad más bajos son 'mejores'. El puente con la prioridad más baja será elegido 'puente

raíz'.

brctl setfd <bridge> <time> establece el 'retraso de reenvío del puente' a <time>

segundos.

brctl sethello <bridge> <time> establece el 'tiempo de saludo del puente' a <time>

segundos.

brctl setmaxage <bridge> <time> establece la 'edad máxima del mensaje' del puente a <time>

segundos.

brctl setpathcost <bridge> <port> <cost> establece el costo del puerto <port> a <cost>. Esta es una métrica sin

dimensión.

brctl setportprio <bridge> <port> <priority> establece la prioridad del puerto <port> a <priority>. El valor de prioridad es una cantidad sin sign

o de 8 bits (un número entre 0 y 255), y no tiene dimensión. Esta métrica
se usa en los algoritmos de selección de puerto designado y puerto raíz.

NOTA

S

brctl(8) está obsoleto. Algunas características como el guardián STP, el modo hairpin, la salida rápida y el bloqueo raíz no están implementadas intencionalmente en este comando. En su lugar, usa el comando bridge del paquete iproute2 para un conjunto

de característic
as más completo.

    NAME

    brctl — control bridge devices

    SYNOPSIS

    brctl [-a] [-d] [-s] [command]

    DESCRIPTION

    brctl is used to control the Linux Ethernet bridge, which allows you to connect multiple network segments into a single logical network segment.

    The brctl utility can be used to create and destroy bridges, bring interfaces up and down, add and remove ports from bridges, and show information about bridges and their ports.

    OPTIONS

    -a
    Show all bridges.
    -d
    Show only devices that are not bridges.
    -s
    Show statistics for bridges.

    COMMANDS

    addbr name
    Add a bridge named name.
    delbr name
    Delete bridge named name.
    addif name [interface]...
    Add interfaces to bridge named name.
    delif name [interface]...
    Remove interfaces from bridge named name.
    show
    Show the list of bridges and their ports.
    setageing name seconds
    Set the ageing time for bridge named name to seconds.
    setpriority name priority
    Set the priority for bridge named name to priority.
    setpathcost name interface cost
    Set the path cost for interface on bridge named name to cost.
    setportprio name interface priority
    Set the port priority for interface on bridge named name to priority.

    EXAMPLES

    Create a new bridge named br0:

    brctl addbr br0

    Add interface eth0 to bridge br0:

    brctl addif br0 eth0

    Show all bridges:

    brctl show

    ip(8), bridge(8)
