NOMBRE

bind8_named2dlf - convierte los logs de BIND8 named al formato dlf

SINOPSIS

bind8_named2dlf

DESCRIPCIÓN

Este script convierte cada línea de un log de BIND8 named a un registro dlf de dnszone. Se ha probado con logs de Bind 8.2. No somos conscientes de ningún cambio en el formato de registro en ninguna versión de Bind 8.*, esperamos que cualquier log de bind 8.* sea procesado correctamente por este script.

Se reconocen las siguientes líneas:

  • Solicitudes AXFR aprobadas/denegadas
  • Transferencias de zona completadas
  • Zonas maestras y esclavas cargadas
  • Actualizaciones dinámicas DNS denegadas

FORMATO DLF

El formato DLF del super-servicio dnszone es

servidor
Nombre del servidor DNS
tiempo
Marca de tiempo de la solicitud
host_axfr
Dirección IP del host que solicita la AXFR
zona_axfr
Nombre de la zona que se solicita
que_axfr
aprobada, denegada o axfr
zona_cargada
Nombre de la zona recién cargada
serial_cargado
Serial de la zona recién cargada
rol_cargado
maestro o esclavo
host_update_denegado
Dirección IP del host que solicita la actualización
zona_update_denegado
Nombre de la zona que se está actualizando

Debido a la naturaleza de los diferentes significados de las líneas en el archivo de log (no todas las líneas tienen una solicitud AXFR, una zona cargada y una solicitud de actualización recibida), uno o más campos pueden ser reemplazados por un 0 o un -. Estos campos se filtran automáticamente para los diferentes tipos de informes.

Ejemplos de líneas DLF son:

AXFR aprobada
tim 1026644876 10.10.10.1 algron.com aprobada - 0 - - -
update denegado
tim 1026645567 - - - - 0 - 10.in-addr.arpa 10.199.16.218
zona maestra cargada
tim 1026525210 - - - nigelbowen.com.au 2002071301 maestro - -

EJEMPLOS

Para procesar un log como el producido por bind8:

$ bind8_named2dlf < named-log

bind8_named2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report bind8_named < /var/log/named
