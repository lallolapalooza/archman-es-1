bupstash-get(1)

Paquete: bupstash

Licencias: MIT

() ()

SINOPSIS

Obtener datos de un repositorio bupstash.

bupstash get [OPCIONES] CONSULTA...

DESCRIPCIÓN

bupstash get recupera y descifra datos almacenados en un repositorio bupstash, enviándolos a la salida estándar. Si el elemento solicitado se guardó como un directorio, el comando lo convierte en un flujo tar.

El elemento que se recupera se elige basándose en una consulta simple contra las etiquetas especificadas al guardar datos con bupstash put.

LENGUAJE DE CONSULTA

Para obtener documentación completa sobre el lenguaje de consulta, consulte bupstash-query-language(7).

CACHÉ DE CONSULTAS

El comando get utiliza los mismos mecanismos de caché de consultas que bupstash-list(1), consulte esa página para obtener más información sobre la caché de consultas.

ARCHIVOS DISPERSOS

Al obtener un directorio como tarball, los archivos dispersos no se tratan de forma especial; para restaurar archivos dispersos conservando los huecos de los archivos, utilice bupstash restore en su lugar.

OPCIONES

-r, --repository REPO
El repositorio al que conectarse, , puede tener el formato ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece en BUPSTASH_REPOSITORY.
-k, --key KEY
Clave que se utilizará para descifrar datos y metadatos. Si no se establece, el valor predeterminado es BUPSTASH_KEY.
--pick RUTA
Recupera un archivo individual o un subdirectorio de una instantánea.
--query-cache RUTA
Ruta al archivo de caché de consultas, el valor predeterminado es uno de los siguientes, en orden, siempre que las variables de entorno apropiadas estén establecidas: $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache o $HOME/.cache/bupstash/bupstash.qcache.
--utc-timestamps
Muestra y busca marcas de tiempo en hora UTC en lugar de hora local.
--no-progress
Suprime los indicadores de progreso (Los indicadores de progreso también se suprimen cuando stderr no es una terminal interactiva).
-q, --quiet
Silencioso, implica --no-progress.

ENTORNO

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede tener el formato ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando para ejecutar para conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_KEY
Ruta a la clave que se utilizará para descifrar datos y metadatos.
BUPSTASH_KEY_COMMAND
Un comando para ejecutar que debe imprimir los datos de la clave, se puede utilizar en lugar de BUPSTASH_KEY para obtener la clave de ubicaciones arbitrarias como la red u otros almacenamientos secretos.
BUPSTASH_QUERY_CACHE
Ruta al archivo de caché de consultas a utilizar.

EJEMPLOS

Obtener un elemento con un ID específico

$ bupstash get id=14ebd2073b258b1f55c5bbc889c49db4 > ./data.file

Obtener un elemento por nombre y marca de tiempo

$ bupstash get name=backup.tar and timestamp=2020/19/* > ./restore.tar

Obtener un archivo o sub-tar de una instantánea de directorio

$ bupstash get --pick=ruta/al/archivo.txt id=$id $ bupstash get --pick=ruta/al/dir id=$id | tar ...

Obtener un tarball

La colocación de directorios integrada crea un tarball a partir de un directorio, por lo que para extraerlo usamos tar.

``` # Hacer una instantánea de un directorio. $ id=$(bupstash put ./data)$ mkdir restore $ bupstash get id=$id | tar -C ./restore -xvf - ```
