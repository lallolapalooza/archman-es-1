NOMBRE

borg-config - obtener, establecer y eliminar valores en un archivo de configuración de repositorio o caché

SINOPSIS

borg [opciones comunes] config [opciones] [REPOSITORIO] [NOMBRE] [VALOR]

DESCRIPCIÓN

Este comando obtiene y establece opciones en un archivo de configuración local de repositorio o caché. Por motivos de seguridad, este comando solo funciona en repositorios locales.

Para eliminar un valor de configuración por completo, use --delete. Para listar los valores del archivo de configuración o los valores predeterminados, use --list. Para obtener una clave existente, pase solo el nombre de la clave. Para establecer una clave, pase tanto el nombre de la clave como el nuevo valor. Las claves se pueden especificar en el formato "sección.nombre" o simplemente "nombre"; la sección será "repository" y "cache" para los archivos de configuración del repositorio y caché, respectivamente.

Por defecto, borg config manipula el archivo de configuración del repositorio. Usar --cache edita el archivo de configuración de la caché del repositorio en su lugar.

OPCIONES

Vea borg-common(1) para ver las opciones comunes de los comandos de Borg.

argumentos

REPOSITORIO
repositorio a configurar
NOMBRE
nombre de la clave de configuración
VALOR
nuevo valor para la clave

opciones

-c, --cache
obtener y establecer valores de la caché del repositorio
-d, --delete
eliminar la clave del archivo de configuración
-l, --list
listar la configuración del repositorio

EJEMPLOS

NOTA:

Los archivos de configuración del repositorio y la caché son algunas de las pocas partes de un repositorio que se pueden manipular directamente y que no están versionadas ni respaldadas, ¡así que ten cuidado al hacer cambios!
# encontrar el directorio de caché
$ cd ~/.cache/borg/$(borg config /ruta/al/repo id)
# reservar algo de espacio
$ borg config /ruta/al/repo additional_free_space 2G
# hacer un repositorio de solo adición
$ borg config /ruta/al/repo append_only 1
