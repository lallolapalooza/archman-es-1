BLUEFISH(1) Comandos de usuario BLUEFISH(1)

NOMBRE

bluefish - editor para diseñadores web y programadores experimentados

SINOPSIS

bluefish [[-c|--curwindow] | [-n|--newwindow]] [ARCHIVO(S)...]

bluefish {[-?|--help|--help-all|--help-*] | [-v|--Version]}

DESCRIPCIÓN

bluefish es un editor de código abierto para diseñadores web y programadores experimentados, que soporta muchos lenguajes de programación y marcado, pero se centra en la creación de sitios web dinámicos e interactivos.

OPCIONES

bluefish actualmente soporta las siguientes opciones:

-c, --curwindow
Abre un archivo en una ventana existente. Esto se puede usar para sobrescribir el predeterminado elegido.
-n, --newwindow
Abre un archivo en una nueva ventana. Esto se puede usar para sobrescribir el predeterminado elegido.
-?, --help, --help-*, --help-all
Imprime todas o solo un grupo de opciones de ayuda. Algunas de estas opciones pueden estar documentadas en gtk-options(7) y gnome-options(7).
-v, --Version
Imprime información de la versión.

VER TAMBIÉN

gnome-options(7), gtk-options(7)

También hay un manual en línea en http://bluefish.openoffice.nl/manual/.
