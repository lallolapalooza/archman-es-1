BIO_f_cipher(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_F_CIPHER(3ssl) OpenSSL BIO_F_CIPHER(3ssl)

NOMBRE

BIO_f_cipher, BIO_set_cipher, BIO_get_cipher_status, BIO_get_cipher_ctx - filtro BIO de cifrado

SINOPSIS

#include <openssl/bio.h>
#include <openssl/evp.h>
const BIO_METHOD *BIO_f_cipher(void);
int BIO_set_cipher(BIO *b, const EVP_CIPHER *cipher,
                   const unsigned char *key, const unsigned char *iv, int enc);
int BIO_get_cipher_status(BIO *b);
int BIO_get_cipher_ctx(BIO *b, EVP_CIPHER_CTX **pctx);

DESCRIPCIÓN

BIO_f_cipher() devuelve el método BIO de cifrado. Este es un BIO de filtro que cifra cualquier dato escrito a través de él y descifra cualquier dato leído de él. Es un envoltorio BIO para las rutinas de cifrado EVP_CipherInit(), EVP_CipherUpdate() y EVP_CipherFinal().

Los BIOs de cifrado no soportan BIO_gets() ni BIO_puts().

BIO_flush() en un BIO de cifrado por el que se está escribiendo se utiliza para señalar que no se van a cifrar más datos: esto se usa para vaciar y posiblemente rellenar el bloque final a través del BIO.

BIO_set_cipher() establece el cifrado del BIO b a cipher usando la clave key y el IV iv. enc debe establecerse a 1 para cifrado y cero para descifrado.

Al leer de un BIO de cifrado, el bloque final se descifra y se comprueba automáticamente cuando se detecta EOF. BIO_get_cipher_status() es una macro BIO_ctrl() que se puede llamar para determinar si la operación de descifrado fue exitosa.

BIO_get_cipher_ctx() es una macro BIO_ctrl() que recupera el contexto de cifrado BIO interno. El contexto recuperado se puede utilizar junto con las rutinas de cifrado estándar para configurarlo. Esto es útil cuando BIO_set_cipher() no es lo suficientemente flexible para las necesidades de las aplicaciones.

NOTAS

Al cifrar, BIO_flush() debe llamarse para vaciar el bloque final a través del BIO. Si no se hace, el bloque final fallará en un descifrado posterior.

Al descifrar, un error en el bloque final se señala mediante un valor de retorno cero de la operación de lectura. Un descifrado exitoso seguido de EOF también devolverá cero para la lectura final. BIO_get_cipher_status() debe llamarse para determinar si el descifrado fue exitoso.

Como siempre, si se necesita soporte para BIO_gets() o BIO_puts(), se puede lograr anteponiendo el BIO de cifrado con un BIO de almacenamiento en búfer.

VALORES DE RETORNO

BIO_f_cipher() devuelve el método BIO de cifrado.

BIO_set_cipher() devuelve 1 en caso de éxito y 0 en caso de fallo.

BIO_get_cipher_status() devuelve 1 para un descifrado exitoso y <=0 en caso de fallo.

BIO_get_cipher_ctx() devuelve 1 en caso de éxito y <=0 en caso de fallo.
