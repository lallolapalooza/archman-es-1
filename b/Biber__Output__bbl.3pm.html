Biber__Output__bbl(3pm)

Paquete: biber

Licencias: Artistic-2.0

Biber::Output::bbl(3pm) Documentación de Perl aportada por el usuario Biber::Output::bbl(3pm)

NOMBRE

Biber::Output::bbl - clase para la salida de Biber de .bbl

new

Inicializa un objeto Biber::Output::bbl

create_output_misc

Crea la salida para bits y piezas misceláneas como preámbulo y llamada a macro de cierre
y la añade al objeto de salida.

_printfield

Añade la salida .bbl para un campo de texto al acumulador de salida.

set_output_keyalias

Establece la salida para una clave que es un alias de otra clave

set_output_undefkey

Establece la salida .bbl para una clave indefinida

set_output_entry

Establece la salida .bbl para una entrada. Esta es la parte principal
de la salida .bbl

output

Método de salida BBL - esto se encarga de generar las entradas en el orden explícito
derivado del orden virtual de las claves de citación después de ordenar por clave de ordenación.
