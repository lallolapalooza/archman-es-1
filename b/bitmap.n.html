bitmap(n) Comandos incorporados de Tk bitmap(n)

NOMBRE

bitmap - Imágenes que muestran dos colores

SINOPSIS

image create bitmap ?nombre? ?opciones?
nombreImagen cget opción
nombreImagen configure ?opción? ?valor opción valor ...?

DESCRIPCIÓN

Un mapa de bits (bitmap) es una imagen cuyos píxeles pueden mostrar uno de dos colores o ser transparentes. Una imagen de mapa de bits se define por cuatro cosas: un color de fondo, un color de primer plano y dos mapas de bits, llamados la *fuente* (source) y la *máscara* (mask). Cada uno de los mapas de bits especifica valores 0/1 para una matriz rectangular de píxeles, y los dos mapas de bits deben tener las mismas dimensiones. Para los píxeles donde la máscara es cero, la imagen no muestra nada, produciendo un efecto transparente. Para otros píxeles, la imagen muestra el color de primer plano si los datos de origen son uno y el color de fondo si los datos de origen son cero.

CREACIÓN DE MAPAS DE BITS

Como todas las imágenes, los mapas de bits se crean utilizando el comando image create. Los mapas de bits admiten las siguientes *opciones*:

-background color
Especifica un color de fondo para la imagen de cualquiera de las formas estándar aceptadas por Tk. Si esta opción se establece en una cadena vacía, los píxeles de fondo serán transparentes. Este efecto se logra utilizando el mapa de bits de origen como mapa de bits de máscara, ignorando cualquier opción -maskdata o -maskfile.
-data cadena
Especifica el contenido del mapa de bits de origen como una cadena. La cadena debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap). Si se especifican las opciones -data y -file, la opción -data tiene prioridad.
-file nombre
nombre proporciona el nombre de un archivo cuyo contenido define el mapa de bits de origen. El archivo debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap).
-foreground color
Especifica un color de primer plano para la imagen de cualquiera de las formas estándar aceptadas por Tk.
-maskdata cadena
Especifica el contenido de la máscara como una cadena. La cadena debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap). Si se especifican las opciones -maskdata y -maskfile, la opción -maskdata tiene prioridad.
-maskfile nombre
nombre proporciona el nombre de un archivo cuyo contenido define la máscara. El archivo debe cumplir con el formato de mapa de bits de X11 (por ejemplo, como lo genera el programa bitmap).

COMANDO DE IMAGEN

Cuando se crea una imagen de mapa de bits, Tk también crea un nuevo comando cuyo nombre es el mismo que el de la imagen. Este comando se puede utilizar para invocar varias operaciones sobre la imagen. Tiene la siguiente forma general:

nombreImagen opción ?arg arg ...?
La *opción* y los *args* determinan el comportamiento exacto del comando. Los siguientes comandos son posibles para las imágenes de mapa de bits:
nombreImagen cget opción
Devuelve el valor actual de la opción de configuración dada por opción. Opción puede tener cualquiera de los valores aceptados por el comando image create bitmap.
nombreImagen configure ?opción? ?valor opción valor ...?
Consulta o modifica las opciones de configuración de la imagen. Si no se especifica ninguna *opción*, devuelve una lista que describe todas las opciones disponibles para nombreImagen (consulte Tk_ConfigureInfo para obtener información sobre el formato de esta lista). Si se especifica una *opción* sin *valor*, el comando devuelve una lista que describe la opción nombrada (esta lista será idéntica a la sublista correspondiente del valor devuelto si no se especifica ninguna *opción*). Si se especifican uno o más pares *opción-valor*, el comando modifica la(s) opción(es) dada(s) para que tengan el(los) valor(es) dado(s); en este caso, el comando devuelve una cadena vacía. Opción puede tener cualquiera de los valores aceptados por el comando image create bitmap.
