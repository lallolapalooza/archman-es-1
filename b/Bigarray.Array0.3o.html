Módulo Bigarray.Array0

DOCUMENTACIÓN

Módulo Array0
: sig end

Arrays de dimensión cero. La estructura Array0 proporciona operaciones similares a las de Bigarray.Genarray , pero especializadas para el caso de arrays de dimensión cero que solo contienen un único valor escalar. Conocer estáticamente el número de dimensiones del array permite operaciones más rápidas y una comprobación de tipos estática más precisa.

Desde 4.05

tipo (!'a, !'b, !'c) t

El tipo de Bigarrays de dimensión cero cuyos elementos tienen tipo OCaml 'a , tipo de representación 'b y diseño de memoria 'c .

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> ('a, 'b, 'c) t

Array0.create kind layout devuelve un nuevo Bigarray de dimensión cero. kind y layout determinan el tipo de elemento del array y el diseño del array, como se describe para Bigarray.Genarray.create .

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a -> ('a, 'b, 'c) t

Array0.init kind layout v se comporta como Array0.create kind layout excepto que el elemento se inicializa además con el valor v .

Desde 4.12

val kind : ('a, 'b, 'c) t -> ('a, 'b) Bigarray.kind

Devuelve el tipo del Bigarray dado.

val layout : ('a, 'b, 'c) t -> 'c Bigarray.layout

Devuelve el diseño del Bigarray dado.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array0.change_layout a layout devuelve un Bigarray con el layout especificado, compartiendo los datos con a . No se realiza ninguna copia de elementos: el nuevo array y el array original comparten el mismo espacio de almacenamiento.

Desde 4.06

val size_in_bytes : ('a, 'b, 'c) t -> int

size_in_bytes a es el Bigarray.kind_size_in_bytes de a .

val get : ('a, 'b, 'c) t -> 'a

Array0.get a devuelve el único elemento en a .

val set : ('a, 'b, 'c) t -> 'a -> unit

Array0.set a x v almacena el valor v en a .

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t -> unit

Copia el primer Bigarray al segundo Bigarray. Consulte Bigarray.Genarray.blit para más detalles.

val fill : ('a, 'b, 'c) t -> 'a -> unit

Rellena el Bigarray dado con el valor dado. Consulte Bigarray.Genarray.fill para más detalles.

val of_value : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a -> ('a, 'b, 'c) t

Construye un Bigarray de dimensión cero inicializado desde el valor dado.
