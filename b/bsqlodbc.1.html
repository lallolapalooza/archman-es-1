BSQLODBC(FreeTDS) FreeTDS (manual de referencia de freetds) BSQLODBC(FreeTDS)

NOMBRE

bsqlodbc — procesador de scripts SQL por lotes usando ODBC

SINOPSIS

bsqlodbc [-hqv] [-U nombre_usuario] [-P contraseña] [-S servidor] [-D base_de_datos] [-i archivo_entrada] [-o archivo_salida] [-e archivo_errores] [-t terminador_campo] [-V version_odbc]

DESCRIPCIÓN

bsqlodbc es un programa de utilidad distribuido con FreeTDS.

bsqlodbc es un equivalente no interactivo de los programas de utilidad 'isql' distribuidos por Sybase y Microsoft. Al igual que ellos, bsqlodbc utiliza el comando 'go' en una línea por sí solo como separador entre lotes. El último lote no necesita ir seguido de 'go'.

bsqlodbc utiliza la API ODBC proporcionada por FreeTDS. Esta API está, por supuesto, también disponible para los desarrolladores de aplicaciones.

OPCIONES

-U nombre_usuario
Nombre de inicio de sesión del servidor de base de datos.
-P contraseña
Contraseña del servidor de base de datos.
-S servidor
Servidor de base de datos al que conectarse.
-D base_de_datos
Base de datos a utilizar.
-i archivo_entrada
Nombre del archivo de script, que contiene SQL.
-o archivo_salida
Nombre del archivo de salida, que contiene los datos del resultado.
-e archivo_errores
Nombre del archivo para los errores.
-t terminador_campo
Especifica el terminador de campo. El valor predeterminado son dos espacios (' '). Las secuencias de escape reconocidas son tabulación ( '\t' ), retorno de carro ( '\r' ), nueva línea ( '\n' ) y barra invertida ( '\\' ).
-h
Imprime las cabeceras de las columnas con los datos en el mismo archivo.
-q
No imprime metadatos de la columna, el estado de retorno ni el número de filas. Anula -h.
-v
Modo verboso, para obtener más información sobre la interacción ODBC. Esto también informa de los metadatos del conjunto de resultados, incluyendo el código de retorno. Todos los datos de modo verboso se escriben en la salida de error estándar (o -e), para no interferir con el flujo de datos.
-V version_odbc
Especifica la versión de ODBC (2 o 3).

NOTAS

bsqlodbc es un filtro; lee de la entrada estándar, escribe en la salida estándar y escribe errores en la salida de error estándar. Las opciones -i, -o y -e anulan estos valores predeterminados.

ESTADO DE SALIDA

bsqlodbc sale con 0 en caso de éxito, y >0 si el servidor no puede procesar la consulta.

HISTORIA

bsqlodbc apareció por primera vez en FreeTDS 0.65.
