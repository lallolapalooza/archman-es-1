bsqldb(1)

Paquete: freetds

Licencias: GPL-2.0-only, LGPL-2.0-only

BSQLDB(1) Manual de comandos generales BSQLDB(1)

NOMBRE

bsqldb — procesador de scripts SQL por lotes usando DB-Library

SINOPSIS

bsqldb [-hqv] [-S nombre_servidor] [-D base_datos] [-U nombre_usuario] [-P contraseña] [-i archivo_entrada] [-o archivo_salida] [-e archivo_errores] [-H nombre_host] [-t terminador_campo] [-R descripcion_pivote]

DESCRIPCIÓN

bsqldb es una utilidad distribuida con FreeTDS. bsqldb es un equivalente no interactivo de las utilidades "isql" distribuidas por Sybase y Microsoft. Como ellas, bsqldb utiliza el comando "go" en una línea por sí solo como separador entre lotes. El último lote no necesita ser seguido por "go". bsqldb hace uso de la API DB-Library proporcionada por FreeTDS. Esta API está por supuesto también disponible para los desarrolladores de aplicaciones.

OPCIONES

-D base_datos
Base de datos a usar.
-H nombre_host
nombre_host Sobrescribe el nombre del cliente enviado al servidor.
-P contraseña
Contraseña del servidor de base de datos.
-S nombre_servidor
Servidor de base de datos al que conectarse.
-U nombre_usuario
Nombre de inicio de sesión del servidor de base de datos. Si no se proporciona un nombre de usuario, se intenta un inicio de sesión de dominio para conexiones TDS 7+.
-e archivo_errores
Nombre del archivo para errores.
-h
Imprime las cabeceras de las columnas con los datos en el mismo archivo.
-i archivo_entrada
Nombre del archivo de script, que contiene SQL.
-o archivo_salida
Nombre del archivo de salida, que contiene los datos del resultado.
-q
No imprime metadatos de columnas, estado o recuento de filas. Sobrescribe -h.
-t terminador_campo
Especifica el terminador de campo. Por defecto son dos espacios (' '). Las secuencias de escape reconocidas son tabulador ('\t'), retorno de carro ('\r'), nueva línea ('\n') y barra invertida ('\\').
-v
Modo detallado, para más información sobre la interacción de DB-Library. Esto también informa sobre los metadatos del conjunto de resultados, incluyendo el código de retorno. Todos los datos detallados se escriben en la salida estándar de error (o -e), para no interferir con el flujo de datos.
-R descripcion_pivote
Especifica la transformación de pivote. El formato es ⟨columnas_abajo⟩ ⟨columnas_transversales⟩ ⟨funcion⟩ ⟨valor⟩. Las columnas se especifican mediante números. El formato de las columnas de abajo y las columnas transversales es una lista separada por comas de columnas. La función es count, sum, min o max.

ENTORNO

DSQUERY valor por defecto nombre_servidor

NOTAS

bsqldb es un filtro; lee de la entrada estándar, escribe en la salida estándar y escribe errores en la salida estándar de error. Las opciones -i, -o y -e anulan estos valores por defecto.

El código fuente de bsqldb está destinado a servir como modelo para los usuarios de DB-Library. DB-Library tiene un rico conjunto de funciones, y a veces puede ser difícil entender cómo usarlas, especialmente la primera vez. Si encuentra algo poco claro en el código fuente, se le anima a enviar sus comentarios al autor.

ESTADO DE SALIDA

bsqldb sale con 0 en caso de éxito, y >0 si el servidor no puede procesar la consulta.

Para mensajes con severidad > 10, bsqldb llama a exit(3) con el nivel de severidad. Por ejemplo, si el nivel de severidad es 16, bsqldb devolverá un estado de salida de 16 a la shell.

HISTORIAL

bsqldb apareció por primera vez en FreeTDS 0.63.

AUTORES

La utilidad bsqldb fue escrita por James K. Lowden ⟨jklowden@freetds.org⟩.

ERRORES

Los servidores de Microsoft a partir de SQL Server 7.0 SP 3 no devuelven parámetros de salida a menos que se utilicen las funciones RPC. Esto significa que bsqldb no puede devolver parámetros de salida para procedimientos almacenados con estos servidores.
