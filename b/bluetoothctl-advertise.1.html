n

Establecer/Obtener la duración de la

publicidad.

El parámetro Duration configura la longitud de una

instancia.

El valor está en

segundos.

Un valor de 0 indica que se elige un valor predeterminado para la

Duración.

El valor predeterminado es 2

segundos.

Si solo se ha añadido una instancia de publicidad, el valor de Duration será

ignorado.

Si se han añadido múltiples instancias de publicidad, el valor de Duration se usará para determinar el tiempo que cada instancia es

publicitada.

El valor de Duration se usa para calcular el número de eventos de publicidad que se usarán para publicitar cada

instancia.

El número de eventos de publicidad se calcula dividiendo el valor de Duration por el intervalo de

publicidad.

El intervalo de publicidad está determinado por los parámetros de publicidad que se establecen para cada instancia. El intervalo de publicidadrval es el máximo de los intervalos de publicidad establecidos para cada

Instancia.
