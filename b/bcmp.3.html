bcmp(3) Manual de Funciones de Biblioteca bcmp(3)

NOMBRE

bcmp - comparar secuencias de bytes

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <strings.h>
[[deprecated]] int bcmp(size_t n;
                        const void s1[n], const void s2[n], size_t n);

DESCRIPCIÓN

bcmp() es idéntica a memcmp(3); utilice esta última en su lugar.

ESTáNDARES

Ninguno.

HISTORIA

4.3BSD. Marcada como LEGACY en POSIX.1-2001; eliminada en POSIX.1-2008.

VER TAMBIÉN

memcmp(3)
