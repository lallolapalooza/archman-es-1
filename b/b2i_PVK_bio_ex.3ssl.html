b2i_PVK_bio_ex(3ssl)

Paquete: openssl

Licencias: Apache-2.0

B2I_PVK_BIO(3ssl) OpenSSL B2I_PVK_BIO_EX(3ssl)

NOMBRE

b2i_PVK_bio, b2i_PVK_bio_ex, i2b_PVK_bio, i2b_PVK_bio_ex - Funciones de decodificación y codificación para leer y escribir claves privadas en formato MSBLOB

SINOPSIS

#include <openssl/pem.h>
EVP_PKEY *b2i_PVK_bio(BIO *in, pem_password_cb *cb, void *u);
EVP_PKEY *b2i_PVK_bio_ex(BIO *in, pem_password_cb *cb, void *u,
                         OSSL_LIB_CTX *libctx, const char *propq);
int i2b_PVK_bio(BIO *out, const EVP_PKEY *pk, int enclevel,
                pem_password_cb *cb, void *u);
int i2b_PVK_bio_ex(BIO *out, const EVP_PKEY *pk, int enclevel,
                   pem_password_cb *cb, void *u,
                   OSSL_LIB_CTX *libctx, const char *propq);

DESCRIPCIÓN

b2i_PVK_bio_ex() decodifica una clave privada de formato MSBLOB leída de un BIO. Intenta determinar automáticamente el tipo de clave. Si la clave está cifrada, se llama a cb con los datos del usuario u para obtener una contraseña para descifrar la clave. El contexto de biblioteca suministrado libctx y la cadena de consulta de propiedades propq se utilizan en cualquier operación de descifrado.

b2i_PVK_bio() hace lo mismo que b2i_PVK_bio_ex() excepto que se utiliza el contexto de biblioteca predeterminado y la cadena de consulta de propiedades.

i2b_PVK_bio_ex() codifica pk utilizando el formato MSBLOB. Si enclevel es 1, se utiliza una contraseña obtenida a través de pem_password_cb para cifrar la clave privada. Si enclevel es 0, no se aplica ningún cifrado. Los datos del usuario en u se pasan al callback de contraseña. El contexto de biblioteca suministrado libctx y la cadena de consulta de propiedades propq se utilizan en cualquier operación de descifrado.

i2b_PVK_bio() hace lo mismo que i2b_PVK_bio_ex() excepto que se utiliza el contexto de biblioteca predeterminado y la cadena de consulta de propiedades.

VALORES DE RETORNO

Las funciones b2i_PVK_bio() y b2i_PVK_bio_ex() devuelven una estructura EVP_PKEY válida o NULL si ocurre un error. El código de error se puede obtener llamando a ERR_get_error(3).

i2b_PVK_bio() y i2b_PVK_bio_ex() devuelven el número de bytes codificados con éxito o un valor negativo si ocurre un error. El código de error se puede obtener llamando a ERR_get_error(3).

VER TAMBIÉN

crypto(7), d2i_PKCS8PrivateKey_bio(3)

HISTORIAL

b2i_PVK_bio_ex() e i2b_PVK_bio_ex() se añadieron en OpenSSL 3.0.
