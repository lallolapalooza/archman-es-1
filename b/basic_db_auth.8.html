NOMBRE

basic_db_auth - Ayudante de autenticación de base de datos para Squid

SINOPSIS

basic_db_auth [opciones]

DESCRIPCIÓN

Este programa verifica el nombre de usuario y la contraseña en una base de datos.

OPCIONES

--debug
Escribe información de depuración en stderr.
--dsn
DSN de la base de datos. Por defecto "DBI:mysql:database=squid"
--user
Usuario de la base de datos
--password
Contraseña de la base de datos
--table
Tabla de la base de datos. Por defecto "passwd".
--usercol
Columna del nombre de usuario. Por defecto "user".
--passwdcol
Columna de la contraseña. Por defecto "password".
--cond
Condición, por defecto es enabled=1. Especifica 1 o "" para ninguna condición. Si usas la bandera --joomla, esta condición se cambiará a block=0
--plaintext
La base de datos contiene contraseñas en texto plano.
--md5
La base de datos contiene contraseñas MD5 sin salt.
--sha1
La base de datos contiene contraseñas SHA1 sin salt.
--salt
Selecciona la sal correcta para evaluar las contraseñas.
--persist
Mantiene una conexión persistente a la base de datos entre consultas.
--joomla
Indica al ayudante que la base de datos de usuarios es una base de datos de Joomla. Por lo tanto, se entiende su peculiar hashing de sal.
