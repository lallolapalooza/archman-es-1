DESCRIPCI

ÓN

bmon es una herramienta de monitoreo y depuración para capturar estadísticas relacionadas con la red y prepararlas visualmente de una manera amigable para el usuario. Cuenta con varios métodos de salida, incluyendo una interfaz de usuario interactiva basada en curses y una salida de texto programable

para
scripts.

NTRADA
Los módulos de entrada proporcionan datos estadísticos sobre elementos. Cada elemento consta de atributos que representan un contador, una
tasa o un porcentaje. Los elementos pueden llevar elementos hijos adicionales para representar una jerarquía. Cada elemento se asigna
a un grupo definido por el módulo de entrada. Los módulos de entrada se consultan en la frecuencia del intervalo de lectura configurado.

Los siguientes módulos de entrada están

disponibles:

netlin

k

Usa el protocolo Netlink para recopilar estadísticas de interfaz y control de tráfico del kernel. Este es el módulo de entrada

predeterminado.
pro
c
Lee estadísticas de interfaz del archivo /proc/net/dev. Esto se considera una interfaz heredada y se proporciona por razones de compatibilidad hacia atrás. Este es un módulo de respaldo si la interfaz Netlink no está
disponible.
dum
my
Módulo de entrada programable para fines de depuración y
pruebas.
nu
ll
No se recopilan
datos.
Para recibir información adicional sobre un módulo, ejecute el
módulo con la opción "help" establecida así:
bmon -i
netli
nk:help

MÓDULOS DE
SALIDA

Los módulos de salida muestran o exportan los datos estadísticos recopilados por los módulos de entrada. Se pueden ejecutar varios módulos de salida al mismo tiempo. bmon no evitará posibles conflictos, como múltiples módulos de salida escribiendo en

la
consola.

Existen los siguientes módulos de

salida:

curse

s

Interfaz de usuario de texto interactiva basada en curses que proporciona estimaciones de tasa en tiempo real y una representación gráfica de cada atributo. Presione '?' para mostrar la guía de referencia rápida. Este es el modo de salida

predeterminado.
asc
ii
Salida de texto simple y programable destinada al consumo humano. Capaz de imprimir listas de interfaces, contadores detallados y gráficos en la consola. Este es el modo de salida de respaldo predeterminado si curses no está
disponible.
form
at
Modo de salida totalmente programable destinado al consumo por otros programas. Consulte el texto de ayuda del módulo para información
adicional.
nul
l
Deshabilita la
salida.
Para recibir información adicional sobre un módulo, ejecute el
módulo con la opción "help" establecida así:
bmon -
o curse
s:help

La sintaxis para

SELECCIÓN DE

INTERFAZ
Se usa la siguiente sintaxis
para definir la política d
e selección de interfaz:

SELECTION ::= NAME[,NAME[,...]

]

NAME ::= [!]

interface
El nombre de la interfaz puede contener el carácter '*', que actuará como un comodín y representa cualquier número de cualquier tipo de carácter, por ejemplo eth*, h*0, ...
Ejemplos: lo,eth0,
eth1

eth*,!eth0

EJEMPLOS

Para ejecutar bmon en modo curses monitoreando las interfaces eth0 y

eth1:
bmon -p eth0,eth1 -o curses
Para ejecutar bmon en modo format, monitoreando cualquier interfaz eth*, con una cadena de
formato
especificada:

bmon -p 'eth*' -o format:fmt='$(element:name) $(attr:rxrate:

packets)\n'
