NOMBRE

bpkg-pkg-configure - configurar paquete

SINOPSIS

bpkg pkg-configure [opciones] [cfg-var...] pkg

DESCRIPCIÓN

El comando pkg-configure configura ya sea el paquete de código fuente previamente desempaquetado (bpkg-pkg-unpack(1), bpkg-pkg-checkout(1)) o un paquete que está presente en el sistema.

Un paquete de código fuente hereda los valores de configuración comunes de build2 que se especificaron al crear la configuración (bpkg-cfg-create(1)). Se pueden pasar variables de configuración adicionales específicas del paquete a pkg-configure (cfg-var).

Un paquete del sistema se especifica usando la sintaxis sys:pkg[/ver]. Si la versión del paquete (ver) no se especifica, se considera desconocida pero que satisface cualquier restricción de dependencia. Tal versión se muestra como *.

OPCIONES DE PKG-CONFIGURE

--directory|-d dir
Asume que la configuración está en dir en lugar del directorio de trabajo actual.

OPCIONES COMUNES

Las opciones comunes se resumen a continuación, con una descripción más detallada disponible en bpkg-common-options(1).

-v
Imprime los comandos subyacentes esenciales que se están ejecutando.
-V
Imprime todos los comandos subyacentes que se están ejecutando.
--quiet|-q
Ejecuta en silencio, imprimiendo solo mensajes de error.
--verbose level
Establece la verbosidad del diagnóstico en level entre 0 y 6.
--stdout-format format
Formato de representación a usar para imprimir en stdout.
--jobs|-j num
Número de trabajos a realizar en paralelo.
--no-result
No imprime mensajes informativos sobre el resultado de ejecutar un comando o alguna de sus partes.
--structured-result fmt
Escribe el resultado de ejecutar un comando en una forma estructurada.
--progress
Muestra indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--no-progress
Suprime los indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--diag-color
Usa color en los diagnósticos.
--no-diag-color
No usa color en los diagnósticos.
--build path
El programa de construcción a usar para compilar paquetes.
--build-option opt
Opción adicional a pasar al programa de construcción.
--fetch path
El programa de obtención a usar para descargar recursos.
--fetch-option opt
Opción adicional a pasar al programa de obtención.
--fetch-timeout sec
El tiempo de espera del programa de obtención y similares (por ejemplo, git).
--pkg-proxy url
Servidor proxy HTTP a usar al obtener manifiestos y archivos de paquetes de repositorios remotos pkg .
--git path
El programa git a usar para obtener repositorios git.
--git-option opt
Opción común adicional a pasar al programa git.
--sha256 path
El programa sha256 a usar para calcular sumas SHA256.
--sha256-option opt
Opción adicional a pasar al programa sha256.
--tar path
El programa tar a usar para extraer archivos de paquetes.
--tar-option opt
Opción adicional a pasar al programa tar.
--openssl path
El programa openssl a usar para operaciones criptográficas.
--openssl-option opt
Opción adicional a pasar al programa openssl.
--auth type
Tipos de repositorios a autenticar.
--trust fingerprint
Confiar en el certificado del repositorio con una huella digital SHA256 fingerprint.
--trust-yes
Asume que la respuesta a todas las solicitudes de autenticación es sí.
--trust-no
Asume que la respuesta a todas las solicitudes de autenticación es no.
--git-capabilities up=pc
Capacidades del protocolo (pc) para un prefijo de URL de repositorio git (up).
--pager path
El programa paginador a usar para mostrar texto largo.
--pager-option opt
Opción adicional a pasar al programa paginador.
--options-file file
Lee opciones adicionales de file.
--default-options dir
El directorio desde el cual cargar archivos de opciones predeterminadas adicionales.
--no-default-options
No carga archivos de opciones predeterminadas.
--keep-tmp
No elimina el directorio temporal de bpkgal final de la ejecución del comando e imprime su ruta con un nivel de verbosidad de 2 o superior.

ARCHIVOS DE OPCIONES PREDETERMINADAS

Consulte bpkg-default-options-files(1) para una descripción general de los archivos de opciones predeterminadas. Para el comando pkg-configure el directorio de inicio de búsqueda es el directorio de configuración. Los siguientes archivos de opciones se buscan en cada directorio y, si se encuentran, se cargan en el orden listado:

bpkg.options
bpkg-pkg-configure.options

Las siguientes opciones del comando pkg-configure no pueden especificarse en los archivos de opciones predeterminadas:

--directory|-d
