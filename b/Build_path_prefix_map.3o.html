val rewrite_first : map -> path -> path option

rewrite_first map path intenta encontrar una fuente en map que sea un prefijo de la path de entrada. Si tiene éxito, reemplaza este prefijo con el objetivo correspondiente. Si falla, simplemente devuelve None .

val rewrite_all : map -> path -> path list

rewrite_all map path encuentra todas las fuentes en map que son un prefijo de la path de entrada. Para cada fuente coincidente, en orden de prioridad, reemplaza este prefijo con el objetivo correspondiente y añade el resultado a la lista devuelta. Si no hay coincidencias, simplemente devuelve [] .

val rewrite : map -> path -> path

rewrite path utiliza rewrite_first para intentar encontrar un mapeo para la ruta. Si se encuentra, devuelve ese mapeo, de lo contrario, simplemente devuelve path .
