NOMBRE

bpkg-rep-info - imprimir información del repositorio

SINOPSIS

bpkg rep-info [opciones] ubicación_rep

DESCRIPCIÓN

El comando rep-info imprime diversa información sobre el repositorio especificado. Por defecto, imprime el nombre y la ubicación del repositorio como primera línea. Si el repositorio está firmado, la información del certificado (nombre/organización/email) se imprime como la siguiente línea, seguida de la huella digital del certificado. Luego viene la lista de repositorios complementarios y de prerrequisitos, seguida de la lista de paquetes disponibles.

Este formato predeterminado puede ser alterado de diversas formas utilizando las opciones enumeradas a continuación. Tenga en cuenta también que la información se escribe en stdout, no en stderr.

Si el directorio de trabajo actual contiene una configuración de bpkg, entonces rep-info usará su base de datos de certificados para la autenticación del repositorio. Es decir, confiará en el certificado del repositorio si ya es de confianza por la configuración. De lo contrario, agregará el certificado a la configuración si confirma que es de confianza. Puede especificar un directorio de configuración alternativo con la opción --directory|-d. Para deshabilitar el uso de la configuración en el directorio de trabajo actual, pase esta opción con una ruta vacía.

OPCIONES REP-INFO

--name|-n
Imprime el nombre y la ubicación del repositorio.
--cert-fingerprint
Imprime la huella digital del certificado del repositorio o una línea vacía si el repositorio no está firmado.
--cert-name
Imprime el nombre común (CN) del certificado del repositorio o una línea vacía si el repositorio no está firmado.
--cert-organization
Imprime el nombre de la organización (O) del certificado del repositorio o una línea vacía si el repositorio no está firmado.
--cert-email
Imprime el correo electrónico del certificado del repositorio o una línea vacía si el repositorio no está firmado.
--repositories|-r
Imprime la lista de repositorios complementarios y de prerrequisitos.
--packages|-p
Imprime la lista de paquetes disponibles.
--manifest
En lugar de imprimir la información en formato legible por humanos, la vuelca (a stdout) como manifiesto(s). Normalmente usaría esta opción en combinación con --packages|-p o --repositories|-r para volcar solo uno de los manifiestos. Si se especifica la opción --deep, entonces en el manifiesto de paquetes resultante los valores *-file se reemplazan con el contenido de los archivos referenciados y los valores *-build se añaden automáticamente (a menos que los archivos correspondientes estén ausentes). Ver también --ignore-unknown, --repositories-file y --packages-file.
--ignore-unknown
Ignora entradas de manifiesto desconocidas. Tenga en cuenta que esta opción también ignora las restricciones de versión en las dependencias especiales de tiempo de compilación del conjunto de herramientas. Esta opción se implica si --manifest no se especifica.
--deep
Verifica la presencia de los valores/archivos *-build requeridos y la validez de los archivos referenciados por los valores *-file del manifiesto.
--repositories-file ruta
Si se especifica --manifest, guarda el manifiesto de repositorios en el archivo especificado en lugar de volcarlo a stdout.
--packages-file ruta
Si se especifica --manifest, guarda el manifiesto de paquetes en el archivo especificado en lugar de volcarlo a stdout.
--type tipo
Especifica el tipo de repositorio con valores válidos siendo pkg, dir y git. Consulte bpkg-rep-add(1) para obtener detalles.
--directory|-d dir
Usa la configuración en dir para la base de datos de certificados confiables.

OPCIONES COMUNES

Las opciones comunes se resumen a continuación con una descripción más detallada disponible en bpkg-common-options(1).

-v
Imprime los comandos subyacentes esenciales que se están ejecutando.
-V
Imprime todos los comandos subyacentes que se están ejecutando.
--quiet|-q
Ejecuta en silencio, solo imprime mensajes de error.
--verbose nivel
Establece la verbosidad de los diagnósticos a nivel entre 0 y 6.
--stdout-format formato
Formato de representación a usar para imprimir en stdout.
--jobs|-j num
Número de trabajos a realizar en paralelo.
--no-result
No imprime mensajes informativos sobre el resultado de la ejecución de un comando o algunas de sus partes.
--structured-result fmt
Escribe el resultado de la ejecución de un comando en forma estructurada.
--progress
Muestra indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--no-progress
Suprime los indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--diag-color
Usa color en los diagnósticos.
--no-diag-color
No usa color en los diagnósticos.
--build ruta
El programa de compilación a utilizar para compilar paquetes.
--build-option opt
Opción adicional a pasar al programa de compilación.
--fetch ruta
El programa de descarga a utilizar para descargar recursos.
--fetch-option opt
Opción adicional a pasar al programa de descarga.
--fetch-timeout seg
El tiempo de espera del programa de descarga y similares (por ejemplo, git).
--pkg-proxy url
Servidor proxy HTTP a usar al obtener manifiestos de paquetes y archivos de repositorios remotos pkg.
--git ruta
El programa git a utilizar para obtener repositorios git.
--git-option opt
Opción común adicional a pasar al programa git.
--sha256 ruta
El programa sha256 a utilizar para calcular sumas SHA256.
--sha256-option opt
Opción adicional a pasar al programa sha256.
--tar ruta
El programa tar a utilizar para extraer archivos de paquetes.
--tar-option opt
Opción adicional a pasar al programa tar.
--openssl ruta
El programa openssl a utilizar para las operaciones de criptografía.
--openssl-option opt
Opción adicional a pasar al programa openssl.
--auth tipo
Tipos de repositorios para autenticar.
--trust huella_digital
Confiar en el certificado del repositorio con una huella digital SHA256.
--trust-yes
Asumir que la respuesta a todas las solicitudes de autenticación es sí.
--trust-no
Asumir que la respuesta a todas las solicitudes de autenticación es no.
--git-capabilities up=pc
Capacidades del protocolo (pc) para un prefijo de URL de un repositorio git (up).
--pager ruta
El programa paginador a utilizar para mostrar texto largo.
--pager-option opt
Opción adicional a pasar al programa paginador.
--options-file archivo
Leer opciones adicionales desde archivo.
--default-options dir
El directorio desde el cual cargar archivos de opciones predeterminadas adicionales.
--no-default-options
No cargar archivos de opciones predeterminadas.
--keep-tmp
No eliminar el directorio temporal de bpkgal final de la ejecución del comando e imprimir su ruta con un nivel de verbosidad de 2 o superior.

ARCHIVOS DE OPCIONES PREDETERMINADAS

Ver bpkg-default-options-files(1) para una descripción general de los archivos de opciones predeterminadas. Si el comando rep-info utiliza una configuración de bpkg existente, entonces el directorio inicial es el directorio de configuración. De lo contrario, solo se buscan los directorios predefinidos (home, system, etc). En cada directorio se buscan los siguientes archivos de opciones y, si se encuentran, se cargan en el orden indicado:

bpkg.options
bpkg-rep-info.options

Las siguientes opciones del comando rep-info no se pueden especificar en los archivos de opciones predeterminadas:

--directory|-d
