type (!'a, !'b, !'c)

t

El tipo Genarray.t es el tipo de Bigarrays con un número variable de dimensiones. Se admiten cualquier número de dimensiones entre 0 y

16.

Los tres parámetros de tipo de Genarray.t identifican el tipo de elemento del array y su disposición, como

sigue:

-el primer parámetro, 'a , es el tipo OCaml para acceder a los elementos del array ( float , int , int32 , int64 , nativeint )

;

-el segundo parámetro, 'b , es el tipo real de los elementos del array ( float32_elt , float64_elt , int8_signed_elt , int8_unsigned_elt , etc)

;

-el tercer parámetro, 'c , identifica la disposición del array ( c_layout o fortran_layout )

.

Por ejemplo, (float, float32_elt, fortran_layout) Genarray.t es el tipo de Bigarrays genéricos que contienen flotantes de 32 bits en disposición Fortran; las lecturas y escrituras en este array utilizan el tipo OCaml float

.

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int array -> ('a, 'b, 'c)

t

Genarray.create kind layout dimensions devuelve un nuevo Bigarray cuyo tipo de elemento está determinado por el parámetro kind (uno de float32 , float64 , int8_signed , etc) y cuya disposición está determinada por el parámetro layout (uno de c_layout o fortran_layout ). El parámetro dimensions es un array de enteros que indican el tamaño del Bigarray en cada dimensión. La longitud de dimensions determina el número de dimensiones del

Bigarray.

Por ejemplo, Genarray.create int32 c_layout [|4;6;8|] devuelve un Bigarray nuevo de enteros de 32 bits, en disposición C, con tres dimensiones, siendo las tres dimensiones 4, 6 y 8 respectivamente

.

Los Bigarrays devueltos por Genarray.create no están inicializados: los valores iniciales de los elementos del array no están

especificados.

Genarray.create lanza Invalid_argument si el número de dimensiones no está en el rango de 0 a 16 inclusive, o si alguna de las dimensiones es

negativa.

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int array -> (int array -> 'a) -> ('a, 'b, 'c)

t

Genarray.init kind layout dimensions f devuelve un nuevo Bigarray b cuyo tipo de elemento está determinado por el parámetro kind (uno de float32 , float64 , int8_signed , etc) y cuya disposición está determinada por el parámetro layout (uno de c_layout o fortran_layout ). El parámetro dimensions es un array de enteros que indican el tamaño del Bigarray en cada dimensión. La longitud de dimensions determina el número de dimensiones del

Bigarray.

Cada elemento Genarray.get b i se inicializa con el resultado de f i . En otras palabras, Genarray.init kind layout dimensions tabula los resultados de f aplicado a los índices de un nuevo Bigarray cuya disposición está descrita por kind , layout y dimensions . El array de índices i puede ser compartido y mutado entre llamadas a

f.

Por ejemplo, Genarray.init int c_layout [|2; 1; 3|]
(Array.fold_left (+) 0) devuelve un Bigarray nuevo de enteros, en disposición C, con tres dimensiones (2, 1, 3, respectivamente), con los valores de los elementos 0, 1, 2, 1, 2,

3.

Genarray.init lanza Invalid_argument si el número de dimensiones no está en el rango de 0 a 16 inclusive, o si alguna de las dimensiones es

negativa.

val nth_dim : ('a, 'b, 'c) t -> int ->

int

Genarray.nth_dim a n devuelve la dimensión número n del Bigarray a . La primera dimensión corresponde a n = 0 ; la segunda dimensión corresponde a n = 1 ; la última dimensión, a n = Genarray.num_dims a - 1

.

Lanza Invalid_argument si n es menor que 0 o mayor o igual que Genarray.num_dims a

.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd)

t

Genarray.change_layout a layout devuelve un Bigarray con la disposición especificada, compartiendo los datos con a (y por lo tanto teniendo las mismas dimensiones que a ). No se realiza ninguna copia de elementos: el nuevo array y el array original comparten el mismo espacio de almacenamiento. Las dimensiones se invierten, de modo que get v [| a; b |] en disposición C se convierte en get v [| b+1; a+1 |] en disposición

Fortran.

val get : ('a, 'b, 'c) t -> int array ->

'a

Lee un elemento de un Bigarray genérico. Genarray.get a [|i1; ...; iN|] devuelve el elemento de a cuyas coordenadas son i1 en la primera dimensión, i2 en la segunda dimensión, ..., iN en la N -ésima

dimensión.

Si a tiene disposición C, las coordenadas deben ser mayores o iguales que 0 y estrictamente menores que las dimensiones correspondientes de a . Si a tiene disposición Fortran, las coordenadas deben ser mayores o iguales que 1 y menores o iguales que las dimensiones correspondientes de a

.

Si N > 3 , se proporciona una sintaxis alternativa: puedes escribir a.{i1, i2, ..., iN} en lugar de Genarray.get a [|i1; ...; iN|] . (La sintaxis a.{...} con una, dos o tres coordenadas está reservada para acceder a arrays unidimensionales, bidimensionales y tridimensionales como se describe a continuación.

)

Lanza Invalid_argument si el array a no tiene exactamente N dimensiones, o si las coordenadas están fuera de los límites del

array.

val set : ('a, 'b, 'c) t -> int array -> 'a ->

unit

Asigna un elemento de un Bigarray genérico. Genarray.set a [|i1; ...; iN|] v almacena el valor v en el elemento de a cuyas coordenadas son i1 en la primera dimensión, i2 en la segunda dimensión, ..., iN en la N -ésima

dimensión.

El array a debe tener exactamente N dimensiones, y todas las coordenadas deben estar dentro de los límites del array, como se describe para Genarray.get ; de lo contrario, se lanza Invalid_argument

.

Si N > 3 , se proporciona una sintaxis alternativa: puedes escribir a.{i1, i2, ..., iN} <- v en lugar de Genarray.set a [|i1; ...; iN|] v . (La sintaxis a.{...} <- v con una, dos o tres coordenadas está reservada para actualizar arrays unidimensionales, bidimensionales y tridimensionales como se describe a continuación.

)

val sub_left : ('a, 'b, Bigarray.c_layout) t -> int -> int -> ('a, 'b, Bigarray.c_layout)

t

Extrae un sub-array del Bigarray dado restringiendo la primera (más a la izquierda) dimensión. Genarray.sub_left a ofs len devuelve un Bigarray con el mismo número de dimensiones que a , y las mismas dimensiones que a , excepto la primera dimensión, que corresponde al intervalo [ofs ... ofs + len - 1] de la primera dimensión de a . No se realiza ninguna copia de elementos: el sub-array y el array original comparten el mismo espacio de almacenamiento. En otras palabras, el elemento en las coordenadas [|i1; ...; iN|] del sub-array es idéntico al elemento en las coordenadas [|i1+ofs; ...; iN|] del array original a

.

Genarray.sub_left se aplica solo a Bigarrays en disposición

C.

Lanza Invalid_argument si ofs y len no designan un sub-array válido de a , es decir, si ofs < 0 , o len < 0 , o ofs + len > Genarray.nth_dim a 0

.

val sub_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> int -> ('a, 'b, Bigarray.fortran_layout)

t

Extrae un sub-arreglo del Bigarray dado restringiendo la última dimensión (la más a la derecha). Genarray.sub_right a ofs len devuelve un Bigarray con el mismo número de dimensiones que a , y las mismas dimensiones que a , excepto la última dimensión, que corresponde al intervalo [ofs ... ofs + len - 1] de la última dimensión de a . No se copian elementos: el sub-arreglo y el arreglo original comparten el mismo espacio de almacenamiento. En otras palabras, el elemento en las coordenadas [|i1; ...; iN|] del sub-arreglo es idéntico al elemento en las coordenadas [|i1; ...; iN+ofs|] del arreglo original a

.

Genarray.sub_right se aplica solo a Bigarrays en diseño

Fortran.

Lanza Invalid_argument si ofs y len no designan un sub-arreglo válido de a , es decir, si ofs < 1 , o len < 0 , o ofs + len > Genarray.nth_dim a (Genarray.num_dims a - 1)

.

val slice_left : ('a, 'b, Bigarray.c_layout) t -> int array -> ('a, 'b, Bigarray.c_layout)

t

Extrae un sub-arreglo de menor dimensión del Bigarray dado fijando una o varias de las primeras coordenadas (las más a la izquierda). Genarray.slice_left a [|i1; ... ; iM|] devuelve el 'slice' de a obtenido fijando las primeras M coordenadas a i1 , ..., iM . Si a tiene N dimensiones, el slice tiene dimensión N - M , y el elemento en las coordenadas [|j1; ...; j(N-M)|] en el slice es idéntico al elemento en las coordenadas [|i1; ...; iM; j1; ...; j(N-M)|] en el arreglo original a . No se copian elementos: el slice y el arreglo original comparten el mismo espacio de

almacenamiento.

Genarray.slice_left se aplica solo a Bigarrays en diseño

C.

Lanza Invalid_argument si M >= N , o si [|i1; ... ; iM|] está fuera de los límites de a

.

val slice_right : ('a, 'b, Bigarray.fortran_layout) t -> int array -> ('a, 'b, Bigarray.fortran_layout)

t

Extrae un sub-arreglo de menor dimensión del Bigarray dado fijando una o varias de las últimas coordenadas (las más a la derecha). Genarray.slice_right a [|i1; ... ; iM|] devuelve el 'slice' de a obtenido fijando las últimas M coordenadas a i1 , ..., iM . Si a tiene N dimensiones, el slice tiene dimensión N - M , y el elemento en las coordenadas [|j1; ...; j(N-M)|] en el slice es idéntico al elemento en las coordenadas [|j1; ...; j(N-M); i1; ...; iM|] en el arreglo original a . No se copian elementos: el slice y el arreglo original comparten el mismo espacio de

almacenamiento.

Genarray.slice_right se aplica solo a Bigarrays en diseño

Fortran.

Lanza Invalid_argument si M >= N , o si [|i1; ... ; iM|] está fuera de los límites de a

.

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t ->

unit

Copia todos los elementos de un Bigarray en otro Bigarray. Genarray.blit src dst copia todos los elementos de src en dst . Ambos arreglos src y dst deben tener el mismo número de dimensiones y dimensiones iguales. Copiar un sub-arreglo de src a un sub-arreglo de dst se puede lograr aplicando Genarray.blit a sub-arreglos o slices de src y dst

.
