NOMBRE

bup-meta - crear o extraer un archivo de metadatos

SINOPSIS

bup meta --create
[-R] [-v] [-q] [--no-symlinks] [--no-paths] [-f archivo] <rutas...>
bup meta --list
[-v] [-q] [-f archivo]
bup meta --extract
[-v] [-q] [--numeric-ids] [--no-symlinks] [-f archivo]
bup meta --start-extract
[-v] [-q] [--numeric-ids] [--no-symlinks] [-f archivo]
bup meta --finish-extract
[-v] [-q] [--numeric-ids] [-f archivo]
bup meta --edit
[--set-uid uid | --set-gid gid | --set-user usuario | --set-group grupo | ...] <rutas...>

DESCRIPCIÓN

bup meta crea, extrae o manipula de otra manera archivos de metadatos. Un archivo de metadatos contiene la información de metadatos (marcas de tiempo, propiedad, permisos de acceso, etc.) para un conjunto de rutas del sistema de archivos.

Consulte bup-restore(1) para obtener una descripción de la forma en que se restauran los metadatos de propiedad.

OPCIONES

-c, --create
Crea un archivo de metadatos para las rutas especificadas. Escribe el archivo en la salida estándar a menos que se especifique --file.
-t, --list
Muestra información sobre los metadatos de un archivo. Lee el archivo de la entrada estándar a menos que se especifique --file.
-x, --extract
Extrae un archivo de metadatos. Conceptualmente, realiza --start-extract seguido de --finish-extract. Lee el archivo de la entrada estándar a menos que se especifique --file.
--start-extract
Construye una estructura de sistema de archivos que coincide con las rutas almacenadas en un archivo de metadatos. Por sí solo, este comando no produce una restauración completa de los metadatos. Para una restauración completa, este comando debe ir seguido de una llamada a --finish-extract. Una vez que este comando ha terminado, todos los archivos normales descritos por los metadatos existirán y estarán vacíos. Restaurar los datos en esos archivos y luego llamar a --finish-extract debería restaurar la estructura original. El archivo se leerá de la entrada estándar a menos que se especifique --file.
--finish-extract
Finaliza la aplicación de los metadatos almacenados en un archivo al sistema de archivos. Normalmente, este comando debe seguir a una llamada a --start-extract. El archivo se leerá de la entrada estándar a menos que se especifique --file.
--edit
Edita archivos de metadatos. El resultado se escribirá en la salida estándar a menos que se especifique --file.
-f, --file=nombre-archivo
Lee el archivo de metadatos de nombre-archivo o escribe en él, según corresponda. Si nombre-archivo es “-”, lee de la entrada estándar o escribe en la salida estándar.
-R, --recurse
Desciende recursivamente en los subdirectorios durante --create.
--xdev, --one-file-system
no cruzar los límites del sistema de archivos – aunque, al igual que con tar y rsync, los propios puntos de montaje se manejarán.
--numeric-ids
Aplica IDs numéricos (usuario, grupo, etc.) en lugar de nombres durante --extract o --finish-extract.
--symlinks
Registra los objetivos de los enlaces simbólicos al crear un archivo, o restaura los enlaces simbólicos al extraer un archivo (durante --extract o --start-extract). Esta opción está habilitada por defecto. Especifique --no-symlinks para deshabilitarla.
--paths
Registra las rutas al crear un archivo. Esta opción está habilitada por defecto. Especifique --no-paths para deshabilitarla.
--set-uid=uid
Establece el uid de metadatos al entero uid durante --edit.
--set-gid=gid
Establece el gid de metadatos al entero gid durante --edit.
--set-user=usuario
Establece el usuario de metadatos a usuario durante --edit.
--unset-user
Elimina el usuario de metadatos durante --edit.
--set-group=grupo
Establece el usuario de metadatos a grupo durante --edit.
--unset-group
Elimina el grupo de metadatos durante --edit.
-v, --verbose
Sé más verboso (se puede usar más de una vez).
-q, --quiet
Sé silencioso.

EJEMPLOS

# Crea un archivo de metadatos para /etc.
$ bup meta -cRf etc.meta /etc
bup: eliminando el prefijo "/" de "/etc"
# Extrae el archivo etc.meta (los archivos estarán vacíos).
$ mkdir tmp && cd tmp
$ bup meta -xf ../etc.meta
$ ls
etc
# Restaura /etc completamente.
$ mkdir tmp && cd tmp
$ bup meta --start-extract -f ../etc.meta
...rellena todos los contenidos de archivos normales con alguna otra herramienta...
$ bup meta --finish-extract -f ../etc.meta
# Cambia el usuario/uid a root.
$ bup meta --edit --set-uid 0 --set-user root \
    src.meta > dest.meta

bup-meta - Muestra información sobre los metadatos de un repositorio Bup.

bup-meta es una herramienta de línea de comandos para interactuar con el sistema de control de versiones distribuido Bup. Esta página de manual describe la sintaxis y las opciones de bup-meta.

Sintaxis

bup meta [opciones]

Descripción

bup-meta se utiliza para obtener información detallada sobre los metadatos de un repositorio Bup. Los metadatos incluyen información sobre los objetos, las ramas, las etiquetas y otros datos internos del repositorio.

Opciones

  • -h, --help: Muestra un mensaje de ayuda y sale.
  • --version: Muestra la información de la versión y sale.
  • --json: Imprime la salida en formato JSON.
  • --human-readable: Imprime la salida en un formato legible para humanos.

Ejemplos

Para mostrar los metadatos de forma legible para humanos:

bup meta --human-readable
