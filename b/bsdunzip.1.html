BSDUNZIP(1) Manual de comandos generales BSDUNZIP(1)

NOMBRE

bsdunzip — extraer archivos de un archivo ZIP

SINOPSIS

bsdunzip [-aCcfjLlnopqtuvy] [{ -O | -I } codificación] [-d directorio] [-x patrón] [-P contraseña] archivo.zip [miembro ...]

DESCRIPCIÓN

Las siguientes opciones están disponibles:

-a
Al extraer un archivo de texto, convierte los finales de línea estilo DOS a estilo Unix.
-C
Compara nombres de archivo sin distinguir entre mayúsculas y minúsculas.
-c
Extrae a la salida estándar/pantalla. Al extraer archivos del archivo zip, se escriben en la salida estándar. Esto es similar a -p, pero no suprime la salida normal.
-d directorio
Extrae los archivos en el directorio especificado en lugar del directorio actual.
-f
Actualiza existentes. Extrae solo archivos del archivo zip si un archivo con el mismo nombre ya existe en el disco y es más antiguo que el primero. De lo contrario, el archivo se omite silenciosamente.
-I codificación
 
-O codificación
Convierte nombres de archivo de la codificación especificada.
-j
Ignora directorios almacenados en el archivo zip; en su lugar, extrae todos los archivos directamente en el directorio de extracción.
-L
Convierte los nombres de los archivos y directorios extraídos a minúsculas.
-l
Lista, en lugar de extraer, el contenido del archivo zip.
-n
No sobrescribir. Al extraer un archivo del archivo zip, si un archivo con el mismo nombre ya existe en el disco, el archivo se omite silenciosamente.
-o
Sobrescribir. Al extraer un archivo del archivo zip, si un archivo con el mismo nombre ya existe en el disco, el archivo existente se reemplaza con el archivo del archivo zip.
-p
Extrae a la salida estándar. Al extraer archivos del archivo zip, se escriben en la salida estándar. La salida normal se suprime como si se hubiera especificado -q.
-P contraseña
Extrae archivos cifrados usando una contraseña. Poner una contraseña en la línea de comandos usando esta opción puede ser inseguro.
-q
Silencioso: imprime menos información mientras extrae.
-t
Probar: no extrae nada, pero verifica la suma de verificación de cada archivo en el archivo.
-u
Actualizar. Al extraer un archivo del archivo zip, si un archivo con el mismo nombre ya existe en el disco, el archivo existente se reemplaza con el archivo del archivo zip si y solo si este último es más nuevo que el primero. De lo contrario, el archivo se omite silenciosamente.
-v
Lista detalladamente, en lugar de extraer, el contenido del archivo zip. Esto difiere de -l al usar la lista larga. Tenga en cuenta que la mayoría de los datos son actualmente falsos y no reflejan el contenido del archivo.
-x patrón
Excluye archivos que coincidan con el patrón patrón.
-y
Imprime años de cuatro dígitos en las listas en lugar de dos.
-Z modo
Emula el modo de zipinfo(1L). Habilitar el modo zipinfo(1L) cambia la forma en que se analizan los argumentos adicionales. Actualmente solo se admite el modo 1 de zipinfo(1L), que lista los nombres de archivo uno por línea.
[miembro ...]
Lista opcional de miembros a extraer del archivo zip. Puede incluir patrones, por ejemplo, 'directorio_miembro/*' extraerá todos los archivos y directorios debajo de directorio_miembro.

Tenga en cuenta que solo se puede especificar una de las opciones -n, -o o -u. Si el nombre de archivo especificado es "-", entonces los datos se leen de stdin.

AMBIENTE

Si la variable de entorno UNZIP_DEBUG está definida, la opción de línea de comandos -q no tendrá efecto y se imprimirá información de depuración adicional en stderr.

COMPATIBILIDAD

La utilidad bsdunzip tiene como objetivo ser suficientemente compatible con otras implementaciones para servir como un reemplazo directo en el contexto del sistema de ports(7). No se ha intentado replicar la funcionalidad que no es necesaria para ese propósito.

Por razones de compatibilidad, las opciones de línea de comandos se reconocerán si se enumeran no solo antes sino también después del nombre del archivo zip.

Normalmente, la opción -a solo debería afectar a los archivos que están marcados como archivos de texto en el directorio central del archivo zip. Dado que la biblioteca archive(3) no proporciona acceso a esa información, no está disponible para la utilidad bsdunzip. En cambio, la utilidad bsdunzip asumirá que un archivo es un archivo de texto si no hay caracteres no ASCII presentes dentro del primer bloque de datos descomprimidos para ese archivo. Si aparecen caracteres no ASCII en bloques de datos posteriores, se emitirá una advertencia.

La utilidad bsdunzip solo puede procesar archivos ZIP gestionados por libarchive(3). Dependiendo de la versión instalada de libarchive(3), esto puede incluir o no archivos ZIP autoejecutables o ZIPX.

VER TAMBIÉN

libarchive(3)

RECUERDOS Y ADVERTENCIAS

La utilidad bsdunzip realiza dos análisis de la línea de comandos para los argumentos antes y después del nombre del archivo, para mantener la compatibilidad con Info-ZIP unzip. Como resultado, la cadena POSIX ‘--’ utilizada para separar las opciones de los argumentos deberá repetirse. Por ejemplo, para extraer un

"-a.jpg" de "-b.zip" con sobrescritura, uno necesitaría invocar

bsdunzip -o -- -a.jpg -- -b.zip
