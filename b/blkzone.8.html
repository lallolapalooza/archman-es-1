BLKZONE(8) Administración del sistema BLKZONE(8)

NOMBRE

blkzone - ejecuta un comando de zona en un dispositivo

SINOPSIS

blkzone comando [opciones] dispositivo

DESCRIPCIÓN

blkzone se utiliza para ejecutar un comando de zona en un dispositivo que soporta los Comandos de Bloques Zonificados (ZBC) o los Comandos de Dispositivos Zonificados ATA (ZAC). Las zonas sobre las que operar pueden especificarse usando las opciones offset, count y length.

El dispositivo argumento es la ruta del dispositivo de bloque.

COMANDOS

report

El comando blkzone report se utiliza para informar de la información de las zonas del dispositivo.

Por defecto, el comando informará de todas las zonas desde el inicio del dispositivo de bloque. Se pueden usar opciones para modificar este comportamiento, cambiando la zona de inicio o el tamaño del informe, como se explica a continuación.

Salida del informe:

start Sector de inicio de la zona
len Longitud de la zona en número de sectores
cap Capacidad de la zona en número de sectores
wptr Posición del puntero de escritura de la zona
reset Se recomienda restablecer el puntero de escritura
non-seq Recursos de escritura no secuencial activos
cond Condición de la zona
type Tipo de zona

Condiciones de la zona:

cl Cerrada
nw Sin puntero de escritura
em Vacía
fu Llena
oe Abierta explícitamente
oi Abierta implícitamente
ol Fuera de línea
ro Solo lectura
x? Condiciones reservadas (no deberían informarse)

capacity

El comando blkzone capacity se utiliza para informar de la información de capacidad del dispositivo.

Por defecto, el comando informará de la suma, en número de sectores, de todas las capacidades de las zonas del dispositivo. Se pueden usar opciones para modificar este comportamiento, cambiando la zona de inicio o el tamaño del informe, como se explica a continuación.

reset

El comando blkzone reset se utiliza para restablecer una o más zonas. A diferencia de sg_reset_wp(8), este comando opera desde la capa de bloque y puede restablecer un rango de zonas.

open

El comando blkzone open se utiliza para abrir explícitamente una o más zonas. A diferencia de sg_zone(8), la acción open, este comando opera desde la capa de bloque y puede abrir un rango de zonas.

close

El comando blkzone close se utiliza para cerrar una o más zonas. A diferencia de sg_zone(9), la acción close, este comando opera desde la capa de bloque y puede cerrar un rango de zonas.

finish

El comando blkzone finish se utiliza para finalizar (transicionar a la condición de llena) una o más zonas. A diferencia de sg_zone(8), la acción finish, este comando opera desde la capa de bloque y puede finalizar un rango de zonas.

Por defecto, los comandos reset, open, close y finish operarán desde la zona en el sector 0 del dispositivo y operarán en todas las zonas. Se pueden usar opciones para modificar este comportamiento como se explica a continuación.

OPCIONES

Los argumentos de las opciones offset y length pueden ir seguidos de los sufijos multiplicativos KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, TiB, PiB, EiB, ZiB y YiB (el "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB") o los sufijos KB (=1000), MB (=1000*1000), y así sucesivamente para GB, TB, PB, EB, ZB y YB. Adicionalmente, el prefijo 0x puede usarse para especificar offset y length en hexadecimal.

-o, --offset sector

La zona de inicio especificada como un desplazamiento en sectores. El desplazamiento proporcionado en unidades de sectores (512 bytes) debe coincidir con el inicio de una zona. El valor por defecto es cero.

-l, --length sectors

El número máximo de sectores en los que el comando debe operar. El valor por defecto es el número de sectores restantes después de offset. Esta opción no puede usarse junto con la opción --count.

-c, --count count

El número máximo de zonas en las que el comando debe operar. El valor por defecto es el número de zonas a partir de offset. Esta opción no puede usarse junto con la opción --length.

-f, --force

Fuerza a los comandos a cambiar el estado de las zonas en los dispositivos de bloque utilizados por el sistema.

-v, --verbose

Muestra el número de zonas devueltas en el informe o el rango de sectores restablecidos.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.
