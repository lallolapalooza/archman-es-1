BORG-UMOUNT(1) Herramienta de copia de seguridad de borg BORG-UMOUNT(1)

NOMBRE

borg-umount - desmontar el sistema de archivos FUSE

SINOPSIS

borg [opciones comunes] umount [opciones] PUNTO_DE_MONTAJE

DESCRIPCIÓN

Este comando desmonta un sistema de archivos FUSE que fue montado con borg mount.

Este es un envoltorio de conveniencia que simplemente llama al comando shell específico de la plataforma, generalmente umount o fusermount -u.

OPCIONES

Ver borg-common(1) para las opciones comunes de los comandos Borg.

argumentos

PUNTO_DE_MONTAJE
punto de montaje del sistema de archivos a desmontar

EJEMPLOS

# Montar el repositorio muestra todos los archivos.
# Los archivos se cargan perezosamente, espera un retraso al navegar a un archivo
# por primera vez.
$ borg mount /ruta/al/repo /tmp/mi_punto_de_montaje
$ ls /tmp/mi_punto_de_montaje
root-2016-02-14 root-2016-02-15
$ borg umount /tmp/mi_punto_de_montaje
# Montar un archivo específico también es posible.
$ borg mount /ruta/al/repo::root-2016-02-15 /tmp/mi_punto_de_montaje
$ ls /tmp/mi_punto_de_montaje
bin  boot  etc      home  lib  lib64  lost+found  media  mnt  opt
root  sbin  srv  tmp  usr  var
$ borg umount /tmp/mi_punto_de_montaje
# La "vista de versiones" fusiona todos los archivos en el repositorio
# y proporciona una vista versionada de los archivos.
$ borg mount -o versions /ruta/al/repo /tmp/mi_punto_de_montaje
$ ls -l /tmp/mi_punto_de_montaje/home/usuario/doc.txt/
total 24
-rw-rw-r-- 1 usuario grupo 12357 Aug 26 21:19 doc.cda00bc9.txt
-rw-rw-r-- 1 usuario grupo 12204 Aug 26 21:04 doc.fa760f28.txt
$ borg umount /tmp/mi_punto_de_montaje
# Los filtros de archivos son compatibles.
# Estos son especialmente útiles para la "vista de versiones",
# que no admite el procesamiento perezoso de archivos.
$ borg mount -o versions --glob-archives '*-mi-casa' --last 10 /ruta/al/repo /tmp/mi_punto_de_montaje
# Las opciones de exclusión son compatibles.
# Estas pueden acelerar el montaje y reducir significativamente las necesidades de memoria.
$ borg mount /ruta/al/repo /tmp/mi_punto_de_montaje solo/esta/ruta
$ borg mount --exclude '...' /ruta/al/repo /tmp/mi_punto_de_montaje
# Cuando se utiliza la variable de entorno BORG_REPO, use :: como argumento posicional:
export BORG_REPO=/ruta/al/repo
# Montar todo el repo:
borg mount :: /tmp/mi_punto_de_montaje
# Montar un archivo específico:
borg mount ::root-2016-02-15 /tmp/mi_punto_de_montaje

borgfs

$ echo '/mnt/backup /tmp/mi_repo fuse.borgfs defaults,noauto 0 0' >> /etc/fstab
$ echo '/mnt/backup::root-2016-02-15 /tmp/mi_archivo fuse.borgfs defaults,noauto 0 0' >> /etc/fstab
$ mount /tmp/mi_repo
$ mount /tmp/mi_archivo
$ ls /tmp/mi_repo
root-2016-02-01 root-2016-02-15
$ ls /tmp/mi_archivo
bin  boot  etc      home  lib  lib64  lost+found  media  mnt  opt  root  sbin  srv  tmp  usr  var

NOTA:

borgfs se proporcionará automáticamente si utilizó un paquete de distribución o pip para instalar Borg. Los usuarios del binario independiente deberán crear manualmente un enlace simbólico (ver pyinstaller-binary).
