BGLMAKE(1) Manual de comandos generales BGLMAKE(1)

NOMBRE

bglmake - crear o actualizar makefiles de Bigloo

SINOPSIS

bglmake [ opciones ] [ archivo_fuente ]

DESCRIPCIÓN

bglmake lee archivo_fuente, calcula el cierre transitivo de la relación de importación y genera un archivo makefile que puede ser utilizado por el programa glmake(1) para compilar la aplicación o la biblioteca. Si no se proporciona ningún archivo_fuente, bglmake mostrará el archivo de plantilla para generar el Makefile.

OPCIONES

-v
Modo detallado
-q
Evita cargar el archivo de configuración del usuario ~/.bglmakerc.
-sufijo <suf>
Añade suf a la lista de sufijos de archivo fuente de bglmake. Los sufijos por defecto son "scm", "sch" y "bgl".
archivo
es el nombre del archivo "principal" para una aplicación o el nombre del archivo "heap" para una biblioteca.
-I<ruta>
Añade ruta a la lista de directorios leídos para buscar archivos fuente de Bigloo.
-X<ruta>
Excluye ruta de la lista de directorios leídos para buscar archivos fuente de Bigloo.
-o <makefile>
El nombre del archivo makefile a actualizar.
-p <nombre>
El nombre del proyecto. Este nombre se utiliza en las entradas de copia de seguridad y versionado.
-t <nombre>
El nombre del archivo binario objetivo o el nombre de la biblioteca.
-f<plantilla>
Establece un archivo de plantilla alternativo.
-objeto <obj>
Actualiza el makefile para añadir obj a la lista de objetos.
-fuente <src>
Actualiza el makefile para añadir src a la lista de archivos fuente.
-principal <archivo>
Establece el archivo principal inicial e indica a bglmake que el proyecto es una "aplicación" (en contraposición a las bibliotecas). Este archivo es el punto de partida del cierre transitivo de los módulos importados.
-heap <archivo>
Establece el archivo heap inicial e indica a bglmake que el proyecto es una "biblioteca" (en contraposición a las aplicaciones). Este archivo es el punto de partida del cierre transitivo de los módulos importados.

PLANTILLAS

Cuando bglmake genera un makefile, utiliza plantillas. Estas plantillas pueden especificarse con alguna opción o imprimirse. Para ello, basta con llamar a bglmake sin ningún parámetro. Los archivos de plantilla utilizan "macros" adicionales:

$[PROJECT]
esta macro se sustituye por el nombre del proyecto (opción -p). Si no se utiliza la opción -p, el nombre del proyecto por defecto es el nombre del directorio actual que contiene el archivo_fuente.
$[TARGET_NAME]
esta macro se sustituye por el nombre del objetivo (opción -t). Si no se utiliza la opción -t, el nombre del objetivo por defecto es el nombre del directorio actual que contiene el archivo_fuente.
$[MAKEFILE]
esta macro se sustituye por el nombre del makefile (opción -o).

EJEMPLO

Un Makefile se crea con ``bglmake foo.scm -o Makefile''. Luego se puede actualizar con ``make updatemakefile''.
