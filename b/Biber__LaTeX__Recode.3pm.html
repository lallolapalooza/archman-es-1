NOMBRE

Biber::LaTeX::Recode - Codifica/Decodifica caracteres a/desde UTF-8/lacros en LaTeX

SINOPSIS

use Biber::LaTeX:Recode
my $cadena = 'Muḥammad ibn Mūsā al-Khwārizmī';
my $cadena_latex = latex_encode($cadena);
    # => 'Mu\d{h}ammad ibn M\=us\=a al-Khw\=arizm\={\i}'
my $cadena = 'Mu\d{h}ammad ibn M\=us\=a al-Khw\=arizm\={\i}';
my $cadena_utf8   = latex_decode($cadena);
    # => 'Muḥammad ibn Mūsā al-Khwārizmī'

DESCRIPCIÓN

Permite la conversión entre caracteres Unicode y macros de LaTeX.

OPCIONES GLOBALES

Los valores posibles para el conjunto de codificación/decodificación a usar son 'null', 'base' y 'full'; el valor predeterminado es 'base'.

null => Sin conversión

base => Macros y diacríticos más comunes (suficiente para idiomas occidentales
y símbolos comunes)

full => También convierte puntuación, un rango mayor de diacríticos y macros
(por ejemplo, para IPA, Latin Extended Additional, etc.), símbolos, letras griegas,
dingbats, símbolos negados y caracteres y símbolos en superíndice...

init_sets(<conjunto_decodificar>, <conjunto_codificar>)

Inicializa los conjuntos de recodificación. No podemos hacer esto al cargar el módulo ya que aún no tenemos la información de configuración
para hacerlo

latex_decode($texto, @opciones)

Convierte macros de LaTeX en el $texto a caracteres Unicode.

La función acepta varias opciones:

* normalize => $booleano (predeterminado 1)
    si la cadena de salida debe normalizarse con Unicode::Normalize
* normalization => <forma de normalización> (predeterminado 'NFD')
    y si es así, la forma de normalización a usar (ver la documentación de Unicode::Normalize)

latex_encode($texto, @opciones)

Convierte UTF-8 a LaTeX
