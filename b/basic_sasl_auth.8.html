basic_sasl_auth(8) Manual del Administrador del Sistema basic_sasl_auth(8)

NOMBRE

basic_sasl_auth - Autenticación básica usando SASL (específicamente el método de autenticación cyrus-sasl)

Versión 1.0

SINOPSIS

basic_sasl_auth

DESCRIPCIÓN

basic_sasl_auth es un binario auxiliar instalado para Squid. SASL es configurable (algo parecido a PAM). Cada servicio que se autentica contra SASL se identifica con un nombre de aplicación. Cada aplicación puede ser configurada independientemente por el administrador de SASL.

CONFIGURACIÓN

Para configurar el método de autenticación utilizado, el archivo basic_sasl_auth.conf puede colocarse en la ubicación apropiada, generalmente /usr/lib/sasl.

La base de datos de autenticación se define por el parámetro pwcheck_method. Solo se utiliza el mecanismo de autenticación PLAIN.

Ejemplos: pwcheck_method:sasldb usa sasldb - el valor por defecto si no se instala ningún archivo de configuración. pwcheck_method:pam
- usa la base de datos de autenticación PAM pwcheck_method:passwd
- usa el tradicional /etc/passwd pwcheck_method:shadow
- usa el ligeramente menos tradicional /etc/shadow

Otros métodos pueden ser soportados por tu implementación de cyrus-sasl; consulta la documentación de cyrus-sasl para obtener información.

Típicamente, la base de datos de autenticación (/etc/sasldb, /etc/shadow, PAM) no puede ser accedida por un usuario normal. Deberías usar setuid/setgid y un usuario/grupo apropiado en el ejecutable para permitir que el autenticador acceda a la base de datos de contraseñas apropiada. Si el acceso a la base de datos no está permitido, el autenticador típicamente fallará con "-1, error genérico".

chown root.mail basic_sasl_auth
chmod ug+s basic_sasl_auth

Si el nombre de la aplicación basic_sasl_auth también se utilizará para el nombre del servicio PAM si se elige pwcheck_method:pam. También se incluye un archivo de configuración de ejemplo de PAM: basic_sasl_auth.pam.
