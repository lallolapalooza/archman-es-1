Paquete: biber

Biber(3pm) Documentación de Perl contribuida por usuarios Biber(3pm)

NOMBRE

Biber - módulo principal para biber, un reemplazo de bibtex para usuarios de biblatex

SINOPSIS

use Biber;
my $biber = Biber->new();
$biber->parse_ctrlfile("example.bcf");
$biber->prepare;

create_uniquename_info

Recopilar la información de uniquename mientras recorremos los nombres
Lo que está ocurriendo aquí es lo siguiente: estamos registrando el número de ocurrencias de cada nombre, nombre+inicial y nombre completo dentro de un contexto específico. Por ejemplo, el contexto es "global" con uniquename < mininit y "lista de nombres" para uniquename=mininit o minfull. Las claves que almacenamos para contar esto son la información más específica para el contexto, es decir, para uniquename < mininit, es el nombre completo y para uniquename=mininit o minfull, es la lista completa de nombres completos. Estas claves tienen valores en un hash que se ignoran. Sirven solo para acumular ocurrencias repetidas con el contexto y no nos importa esto, por lo que los valores son un sumidero útil para tal repetición. Por ejemplo, si encontramos en el contexto global un nombre base "Smith" en dos entradas diferentes bajo la misma forma "Alan Smith", la estructura de datos se vería así:
{Smith}->{global}->{Alan Smith} = 2
No nos importa el valor, ya que esto significa que hay 2 "Alan Smith" en el contexto global que necesitan desambiguar de la misma manera de todos modos. Así que, simplemente contamos las claves para el nombre base "Smith" en el contexto global para ver cuán ambiguo es el nombre base en sí. Esto sería "1" y por lo tanto "Alan Smith" obtendría uniquename=false porque es inambiguo como simplemente "Smith".
Lo mismo aplica para la desambigación de contexto de lista "minimal" para uniquename=mininit o minfull. Por ejemplo, si tuviéramos el nombre base "Smith" para desambiguar en dos entradas con labelname "John Smith and Alan Jones", la estructura de datos se vería así:
{Smith}->{Smith+Jones}->{John Smith+Alan Jones} = 2
De nuevo, contar las claves del contexto para el nombre base nos da "1", lo que significa que tenemos uniquename=false para "John Smith" en ambas entradas porque es la misma lista. Esto también funciona para nombres repetidos en la misma lista "John Smith and Bert Smith". Desambiguar "Smith" en esto:
{Smith}->{Smith+Smith}->{John Smith+Bert Smith} = 2
Así que tanto "John Smith" como "Bert Smith" en esta entrada obtienen uniquename=false (por supuesto, siempre que no haya otras entradas "X Smith and Y Smith" donde X != "John" o Y != "Bert").
Los valores de biblatex.sty:
false   = 0
init    = 1
true    = 2
full    = 2
allinit = 3
allfull = 4
mininit = 5
minfull = 6

Obtener datos de citekey y dependientes de las fuentes de datos de la sección

y una subrutina definida llamada:
Biber::Input::<type>::<datatype>::extract_entries

1: Objeto Biber
2: Nombre de la fuente de datos
3: Referencia a un array de claves de cita que buscar
y devuelve un array de las claves de cita que no encontró en la fuente de datos
