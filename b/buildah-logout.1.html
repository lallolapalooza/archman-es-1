NOMBRE

buildah-logout - Cerrar sesión en un registro de contenedores

SINOPSIS

buildah logout [opciones] registro

DESCRIPCIÓN

buildah logout cierra la sesión en un servidor de registro especificado eliminando las credenciales cacheadas almacenadas en el archivo auth.json. La ruta del archivo de autenticación puede ser anulada por el usuario estableciendo la opción authfile. La ruta predeterminada utilizada es ${XDG_RUNTIME_DIR}/containers/auth.json. Consulte containers-auth.json(5) para obtener más información. Todas las credenciales cacheadas se pueden eliminar estableciendo la opción all.

buildah [OPCIONES GENERALES]

buildah logout [OPCIONES GENERALES]

buildah logout [OPCIONES] REGISTRO [OPCIONES GENERALES]

OPCIONES

--all, -a

Elimina las credenciales cacheadas para todos los registros en el archivo de autenticación

--authfile

Ruta del archivo de autenticación. El valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json. Consulte containers-auth.json(5) para obtener más información.

Nota: También puede anular la ruta predeterminada del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. export REGISTRY_AUTH_FILE=ruta

--compat-auth-file=ruta

En lugar de actualizar el archivo de credenciales predeterminado, actualiza el que se encuentra en ruta y utiliza un formato compatible con Docker.

--help, -h

Imprime el enunciado de uso

EJEMPLOS

$ buildah logout quay.io
Credenciales de inicio de sesión eliminadas para quay.io
$ buildah logout --authfile authdir/myauths.json quay.io
Credenciales de inicio de sesión eliminadas para quay.io
$ buildah logout --all
Eliminar credenciales de inicio de sesión para todos los registros

VER TAMBIÉN

buildah(1), buildah-login(1), containers-auth.json(5)
