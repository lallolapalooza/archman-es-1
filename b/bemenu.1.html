DESCRIPCIÓ

N

bemenu es un menú dinámico para tty(4) (usando ncurses(3)), X11 y Wayland, inspirado en dmenu(

1).

Lee una lista de elementos separados por saltos de línea de la entrada estándar y luego los presenta como una lista, donde el usuario puede seleccionar uno o varios de ellos. Al presionar <retorno-de-carro>, los elementos seleccionados se imprimen en la salida estándar (uno por línea) y bemenu ter

mina.

Al introducir texto, se filtrarán los elementos para mostrar solo aquellos que coincidan con la entrada. Si el número de elementos supera el tamaño de la lista, los elementos se

paginarán.

bemenu-run es una invocación especial de bemenu, donde la entrada es la lista de ejecutables

bajo PATH y los elementos se
leccionados se ejecutan.
