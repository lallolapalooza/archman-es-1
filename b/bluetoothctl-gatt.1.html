Nombre

bluetoothctl-gatt - Submenú Genérico de Atributos

SINOPSIS

bluetoothctl [--opciones] [comandos gatt]

Comandos Genéricos de Atributos

list-attributes

Lista atributos.

Uso
> list-attributes <atributo/UUID>

select-attribute

Selecciona un atributo.

Uso
> select-attribute <atributo/UUID>

attribute-info

Selecciona un atributo.

Uso
> attribute-info [atributo/UUID]

read

Lee el valor del atributo.

Uso
> read [offset]

write

Escribe el valor del atributo.

Uso
> write <datos=xx xx ...> [offset] [tipo]

acquire-write

Adquiere un descriptor de archivo para escribir.

Uso
> acquire-write

release-write

Libera un descriptor de archivo para escribir.

Uso
> release-write

acquire-notify

Adquiere un descriptor de archivo para notificar.

Uso
> acquire-notify

release-notify

Libera un descriptor de archivo para notificar.

Uso
> release-notify

notify

Notifica el valor del atributo.

Uso
> notify <on/off>

clone

Clona un dispositivo o atributo.

Uso
> clone [dispositivo/atributo/UUID]

register-application

Registra una aplicación.

Uso
> register-application [UUID ...]

unregister-application

Anula el registro de una aplicación.

Uso
> unregister-application

register-service

Registra un servicio de la aplicación.

Uso
> register-service <UUID> [handle]

unregister-service

Anula el registro de un servicio de la aplicación.

Uso
> unregister-service <UUID/objeto>

register-includes

Registra como servicio incluido.

Uso
>r egister-includes <UUID> [handle]

unregister-includes

Anula el registro de un servicio incluido.

Uso
> unregister-includes <UUID-Servicio><UUID-Incluido>

register-characteristic

Registra una característica del servicio.

Uso
> register-characteristic <UUID> <Flags=lectura,escritura,notificación...> [handle]

unregister-characteristic

Anula el registro de una característica del servicio.

Uso
> unregister-characteristic <UUID/objeto>

register-descriptor

Registra un descriptor de característica.

Uso
> register-descriptor <UUID> <Flags=lectura,escritura...> [handle]

unregister-descriptor

Anula el registro de un descriptor de característica.

Uso
> unregister-descriptor <UUID/objeto>
