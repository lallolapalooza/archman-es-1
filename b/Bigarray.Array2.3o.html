Bigarray.Array2 - Arrays bidimensionales.

Módulo

Módulo Bigarray.Array2

Documentación

Módulo Array2
: sig end

Arrays bidimensionales. La estructura Array2 proporciona operaciones similares a las de Bigarray.Genarray , pero especializadas para el caso de arrays bidimensionales.

type (!'a, !'b, !'c) t

El tipo de Bigarrays bidimensionales cuyos elementos tienen tipo OCaml 'a , tipo de representación 'b y disposición de memoria 'c .

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> ('a, 'b, 'c) t

Array2.create kind layout dim1 dim2 devuelve un nuevo Bigarray de dos dimensiones, cuyo tamaño es dim1 en la primera dimensión y dim2 en la segunda dimensión. kind y layout determinan el tipo de elemento del array y la disposición del array, como se describe para Bigarray.Genarray.create .

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> (int -> int -> 'a) -> ('a, 'b, 'c) t

Array2.init kind layout dim1 dim2 f devuelve un nuevo Bigarray b de dos dimensiones, cuyo tamaño es dim1 en la primera dimensión y dim2 en la segunda dimensión. kind y layout determinan el tipo de elemento del array y la disposición del array, como se describe para Bigarray.Genarray.create .

Cada elemento Array2.get b i j del array se inicializa con el resultado de f i j .

En otras palabras, Array2.init kind layout dim1 dim2 f tabula los resultados de f aplicados a los índices de un nuevo Bigarray cuya disposición se describe mediante kind , layout , dim1 y dim2 .

Desde 4.12

val dim1 : ('a, 'b, 'c) t -> int

Devuelve la primera dimensión del Bigarray bidimensional dado.

val dim2 : ('a, 'b, 'c) t -> int

Devuelve la segunda dimensión del Bigarray bidimensional dado.

val kind : ('a, 'b, 'c) t -> ('a, 'b) Bigarray.kind

Devuelve el tipo del Bigarray dado.

val layout : ('a, 'b, 'c) t -> 'c Bigarray.layout

Devuelve la disposición del Bigarray dado.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array2.change_layout a layout devuelve un Bigarray con la disposición especificada layout , compartiendo los datos con a (y por lo tanto teniendo las mismas dimensiones que a ). No se realiza copia de elementos: el nuevo array y el array original comparten el mismo espacio de almacenamiento. Las dimensiones se invierten, de modo que get v [| a; b |] en disposición C se convierte en get v [| b+1; a+1 |] en disposición Fortran.

Desde 4.06

val size_in_bytes : ('a, 'b, 'c) t -> int

size_in_bytes a es el número de elementos en a multiplicado por el Bigarray.kind_size_in_bytes de a .

Desde 4.03

val get : ('a, 'b, 'c) t -> int -> int -> 'a

Array2.get a x y , también escrito como a.{x,y} , devuelve el elemento de a en las coordenadas ( x , y ). x e y deben estar dentro de los límites de a , como se describe para Bigarray.Genarray.get ; de lo contrario, se lanza Invalid_argument .

val set : ('a, 'b, 'c) t -> int -> int -> 'a -> unit

Array2.set a x y v , o alternativamente a.{x,y} <- v , almacena el valor v en las coordenadas ( x , y ) en a . x e y deben estar dentro de los límites de a , como se describe para Bigarray.Genarray.set ; de lo contrario, se lanza Invalid_argument .

val sub_left : ('a, 'b, Bigarray.c_layout) t -> int -> int -> ('a, 'b, Bigarray.c_layout) t

Extrae un sub-array bidimensional del Bigarray bidimensional dado restringiendo la primera dimensión. Ver Bigarray.Genarray.sub_left para más detalles. Array2.sub_left solo se aplica a arrays con disposición C.

val sub_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> int -> ('a, 'b, Bigarray.fortran_layout) t

Extrae un sub-array bidimensional del Bigarray bidimensional dado restringiendo la segunda dimensión. Ver Bigarray.Genarray.sub_right para más detalles. Array2.sub_right solo se aplica a arrays con disposición Fortran.

val slice_left : ('a, 'b, Bigarray.c_layout) t -> int -> ('a, 'b, Bigarray.c_layout) Bigarray.Array1.t

Extrae una fila (slice unidimensional) del Bigarray bidimensional dado. El parámetro entero es el índice de la fila a extraer. Ver Bigarray.Genarray.slice_left para más detalles. Array2.slice_left solo se aplica a arrays con disposición C.

val slice_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> ('a, 'b, Bigarray.fortran_layout) Bigarray.Array1.t

Extrae una columna (slice unidimensional) del Bigarray bidimensional dado. El parámetro entero es el índice de la columna a extraer. Ver Bigarray.Genarray.slice_right para más detalles. Array2.slice_right solo se aplica a arrays con disposición Fortran.

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t -> unit

Copia el primer Bigarray al segundo Bigarray. Ver Bigarray.Genarray.blit para más detalles.

val fill : ('a, 'b, 'c) t -> 'a -> unit

Rellena el Bigarray dado con el valor dado. Ver Bigarray.Genarray.fill para más detalles.

val of_array : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a array array -> ('a, 'b, 'c) t

Construye un Bigarray bidimensional inicializado a partir del array de arrays dado.

val unsafe_get : ('a, 'b, 'c) t -> int -> int -> 'a

Al igual que Bigarray.Array2.get , pero la comprobación de límites no siempre se realiza.

val unsafe_set : ('a, 'b, 'c) t -> int -> int -> 'a -> unit

Al igual que Bigarray.Array2.set , pero la comprobación de límites no siempre se realiza.
