NOMBRE

bt-network - un gestor de red bluetooth

SINOPSIS

bt-network [OPCIÓN...]

Opciones de ayuda:
-h, --help

Opciones de aplicación:
-a, --adapter=<nombre|mac>
-c, --connect <nombre|mac> <uuid>
-s, --server <gn|panu|nap> <bridge>

DESCRIPCIÓN

Esta utilidad se utiliza para gestionar servicios de red (cliente/servidor). Todos los servidores se desregistrarán automáticamente cuando la aplicación termine.

OPCIONES

-h, --help
Muestra la ayuda

-a, --adapter <nombre|mac>
Especifica el adaptador a utilizar por su nombre o dirección MAC
(si esta opción no se define - se utiliza el adaptador por defecto)

-c, --connect <nombre|mac> <uuid>
Conéctate al dispositivo de red y devuelve el nombre de la interfaz de red.
el uuid puede ser "gn", "panu" o "nap".

-s, --server <gn|panu|nap> <bridge>
Registra el servidor para el UUID proporcionado, cada nueva conexión a
este servidor añadirá la interfaz bridge.
