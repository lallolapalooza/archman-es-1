BGLJFILE(1) Manual de Comandos Generales BGLJFILE(1)

NOMBRE

Bgljfile - un generador de archivos de acceso Jvm

SINOPSIS

bgljfile [ opciones ] archivo ...

DESCRIPCIÓN

Bgljfile es un generador de archivos de acceso Jvm. Produce un archivo que se adapta a la opción -bgljfile de Bigloo. Un archivo de acceso Jvm es una lista scheme. Cada elemento de esa lista es una lista de al menos dos elementos: un nombre de módulo y el archivo de clase Java que implementa ese módulo.

OPCIONES

archivo
Es un archivo que implementa un módulo. Bgljfile lee ese archivo para descubrir el nombre del módulo implementado.
-base
Establece el paquete base de Jvm.
-o <archivo>
Imprime el archivo de acceso de módulos en archivo. Por defecto, la lista se imprime en la salida estándar.
-suffix <suf>
Añade suf a la lista de sufijos de archivos fuente de bgljfile. Los sufijos por defecto son "scm", "sch" y "bgl".

EJEMPLO

Si los tres archivos existen y contienen una cláusula de módulo Bigloo válida, entonces:


$ bgljfile foo.scm bar.scm gee.scm

podría imprimir una lista como:

(


(foo "./foo")


(bar "./bar")


(gee "./gee")

)

bigloo(1), bgldepend(1), bglmake(1), bglpp(1), bglprof(1), bgltags(1)
