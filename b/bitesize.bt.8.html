bitesize.bt(8) Manual del Administrador del Sistema bitesize.bt(8)

NOMBRE

bitesize.bt - Muestra el tamaño de I/O del disco como un histograma. Utiliza bpftrace/eBPF.

SINOPSIS

bitesize.bt

DESCRIPCIÓN

Esto se puede usar para caracterizar la distribución de los tamaños de I/O de dispositivos de bloque (discos). Para estudiar los I/O de dispositivos de bloque con más detalle, consulta biosnoop.bt(8).

Esto utiliza el punto de rastreo tracepoint:block:block_rq_issue y es un ejemplo simple de bpftrace.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrear I/O de bloque y resumir como un histograma por proceso:
# bitesize.bt

CAMPOS

0
Se imprime un nombre de proceso (mostrado en "@[...]") antes de cada histograma de I/O.
1, 2
Este es un rango de tamaños de I/O, en Kbytes (mostrado en notación de conjunto "[...]").
3
Una columna que muestra la cuenta de I/O en este rango.
4
Este es un histograma ASCII que representa la columna de cuenta.

SOBRECARGA

Dado que el I/O de los dispositivos de bloque suele tener una frecuencia relativamente baja (< 10.000/s), se espera que la sobrecarga de esta herramienta sea baja o insignificante. Para sistemas de almacenamiento con alto IOPS, prueba y cuantifica antes de usar.

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

Busca también en la distribución de bpftrace un archivo _examples.txt complementario que contenga ejemplos de uso, salida y comentarios para esta herramienta.

Esta es una versión de bpftrace de la herramienta bcc con el mismo nombre.

https://github.com/iovisor/bcc
