NOMBRE

btrfs - una caja de herramientas para gestionar sistemas de archivos btrfs

SINOPSIS

btrfs [opciones globales] <grupo> [<grupo>...] <comando> [opciones] [<argumentos>]

DESCRIPCIÓN

La utilidad btrfs es una caja de herramientas para gestionar sistemas de archivos btrfs. Existen grupos de comandos para trabajar con subvolúmenes, dispositivos, para el sistema de archivos completo u otras acciones específicas. Ver la sección COMANDOS.

También existen herramientas independientes para algunas tareas como btrfs-convert(8) <> o btrfstune(8) <> que fueron separadas históricamente y/o no se han fusionado a la utilidad principal. Ver la sección HERRAMIENTAS INDEPENDIENTES para más detalles.

Para otros temas (opciones de montaje, etc.) por favor consulte la página de manual separada btrfs(5) <>.

SINTAXIS DEL COMANDO

Cualquier nombre de comando puede acortarse siempre que la forma acortada no sea ambigua, sin embargo, se recomienda usar nombres de comando completos en scripts. Todos los grupos de comandos tienen su página de manual llamada btrfs-<grupo>.

Por ejemplo: es posible ejecutar btrfs sub snaps en lugar de btrfs subvolume snapshot. Pero btrfs file s no está permitido, porque file s puede interpretarse tanto como filesystem show como filesystem sync.

Los *tamaños*, tanto de entrada como de salida, pueden expresarse en unidades SI o IEC-I (ver numfmt(1) https://man7.org/linux/man-pages/man1/numfmt.1.html) con el sufijo *B* añadido. Todos los números se formatearán según las reglas del locale *C* (ignorando el locale del shell, ver locale(7) https://man7.org/linux/man-pages/man7/locale.7.html).

Para una descripción general de un comando dado, use btrfs command --help o btrfs [command...] help --full para mostrar todas las opciones disponibles para todos los comandos.

Existen opciones globales que se pasan entre *btrfs* y el nombre del *grupo* y afectan al comportamiento no específico del comando, por ejemplo, la verbosidad o el tipo de salida:

btrfs -q subvolume create ...
btrfs --dry-run subvolume create ...
--format <formato>
si es compatible con el comando, imprime la salida del subcomando en ese formato (texto, json)
-v|--verbose
aumenta la verbosidad del subcomando
-q|--quiet
imprime solo errores
--log <nivel>
establece el nivel de registro (default, info, verbose, debug, quiet)

Las opciones restantes solo son relevantes para la herramienta principal:

--help
imprime ayuda condensada para todos los subcomandos
--version
imprime la cadena de versión

COMANDOS

balance
Equilibra los bloques del sistema de archivos btrfs entre uno o varios dispositivos. Ver btrfs-balance(8) <> para más detalles.
check
Realiza una comprobación fuera de línea en un sistema de archivos btrfs. Ver btrfs-check(8) <> para más detalles.
device
Gestiona los dispositivos gestionados por btrfs, incluyendo añadir/eliminar/escanear y así sucesivamente. Ver btrfs-device(8) <> para más detalles.
filesystem
Gestiona un sistema de archivos btrfs, incluyendo el establecimiento/sincronización de etiquetas y así sucesivamente. Ver btrfs-filesystem(8) <> para más detalles.
inspect-internal
Herramientas de depuración para desarrolladores/hackers. Ver btrfs-inspect-internal(8) <> para más detalles.
property
Obtiene/establece una propiedad de/a un objeto btrfs. Ver btrfs-property(8) <> para más detalles.
qgroup
Gestiona grupos de cuotas (qgroup) para sistemas de archivos btrfs. Ver btrfs-qgroup(8) <> para más detalles.
quota
Gestiona las cuotas en sistemas de archivos btrfs, como habilitar/re-escanear etc. Ver btrfs-quota(8) <> y btrfs-qgroup(8) <> para más detalles.
receive
Recibe datos de subvolúmenes desde stdin/archivo para restauración, etc. Ver btrfs-receive(8) <> para más detalles.
replace
Reemplaza dispositivos btrfs. Ver btrfs-replace(8) <> para más detalles.
rescue
Intenta rescatar un sistema de archivos btrfs dañado. Ver btrfs-rescue(8) <> para más detalles.
restore
Intenta restaurar archivos desde un sistema de archivos btrfs dañado. Ver btrfs-restore(8) <> para más detalles.
scrub
Frota un sistema de archivos btrfs. Ver btrfs-scrub(8) <> para más detalles.
send
Envía datos de subvolúmenes a stdout/archivo para copias de seguridad, etc. Ver btrfs-send(8) <> para más detalles.
subvolume
Crea/elimina/lista/gestiona subvolúmenes de btrfs. Ver btrfs-subvolume(8) <> para más detalles.

HERRAMIENTAS INDEPENDIENTES

La nueva funcionalidad podría proporcionarse utilizando una herramienta independiente. Si la funcionalidad resulta ser útil, entonces la herramienta independiente se declara obsoleta y su funcionalidad se copia a la herramienta principal. Las herramientas obsoletas se eliminan después de un largo período (años) de advertencia.

Herramientas que todavía están en uso activo sin un equivalente en btrfs:

btrfs-convert
conversión in-situ de sistemas de archivos ext2/3/4 a btrfs
btrfstune
ajusta algunas propiedades del sistema de archivos en un sistema de archivos desmontado
btrfs-select-super
herramienta de rescate para sobrescribir la superbloque primaria desde una copia de seguridad
btrfs-find-root
ayudante de rescate para encontrar raíces de árbol en un sistema de archivos

Para entornos con espacio limitado, es posible compilar una única binario con la funcionalidad de varias herramientas independientes. Esto sigue el concepto de busybox donde el nombre del archivo selecciona la funcionalidad. Esto funciona para enlaces simbólicos o duros. La lista completa se puede obtener con btrfs help --box.

ESTADO DE SALIDA

btrfs devuelve un estado de salida cero si tiene éxito. Se devuelve un valor distinto de cero en caso de fallo.

DISPONIBILIDAD

btrfs es parte de btrfs-progs. Por favor, consulte la documentación en https://btrfs.readthedocs.io.
