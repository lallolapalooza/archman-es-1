BLKCAT(1) Manual de Comandos Generales BLKCAT(1)

NOMBRE

blkcat - Muestra el contenido de una unidad de datos del sistema de archivos en una imagen de disco.

SINOPSIS

blkcat [-ahswvV] [-f fstype] [-u unit_size] [-i imgtype] [-o imgoffset] [-b dev_sector_size] imagen [imágenes] unit_addr [num]

DESCRIPCIÓN

blkcat muestra num unidades de datos (por defecto es una) a partir de la dirección de unidad unit_addr de imagen a la salida estándar en diferentes formatos (el predeterminado es raw). blkcat se llamaba dcat en versiones de TSK anteriores a la 3.0.0.

ARGUMENTOS

-a
Muestra el contenido en ASCII
-f fstype
Especifica la imagen como un tipo de archivo específico. Si se indica 'swap', la imagen se mostrará en páginas de 4096 bytes. Si se indica 'raw', se usará 512 bytes como tamaño predeterminado. La opción '-u' puede cambiar el tamaño predeterminado. Usa '-f list' para listar los tipos de sistema de archivos compatibles. Si no se especifica, se utilizan métodos de autodetección.
-h
Muestra el contenido en formato hexdump
-s
Muestra estadísticas sobre la imagen (tamaño de unidad, tamaño de bloque de archivo y número de fragmentos).
-u unit_size
Especifica el tamaño de la unidad de datos predeterminada para imágenes raw, blkls y swap.
-i imgtype
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos compatibles. Si no se especifica, se utilizan métodos de autodetección.
-o imgoffset
El desplazamiento de sector donde comienza el sistema de archivos en la imagen.
-b dev_sector_size
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se especifica, se utiliza el valor del formato de imagen (si existe) o se asume 512 bytes.
-v
Salida detallada a stderr.
-V
Muestra la versión.
-w
Muestra el contenido en formato de tabla HTML.
imagen [imágenes]
La imagen del disco o partición a leer, cuyo formato se indica con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
unit_addr
Dirección de la unidad de disco a mostrar. El tamaño de una unidad en este sistema de archivos se puede determinar usando la opción -s.
num
Número de unidades de datos a mostrar.

La funcionalidad básica de blkcat también se puede lograr usando dd. Para determinar qué inodo ha asignado una unidad determinada, se puede utilizar el comando ifind(1).

EJEMPLOS

# blkcat -hw imagen 264 4

o

# blkcat -hw imagen 264

VER TAMBIÉN
