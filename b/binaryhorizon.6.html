NOMBRE

binaryhorizon - Un sistema de partículas de trazado de caminos evoluciona continuamente.

SINOPSIS

binaryhorizon [--fps] [--install] [--noinstall] [--mono] [--root] [--window-id número] [--visual visual] [--window] [--window-id id-ventana] [--color] [--no-color] [--growth-delay retraso_ms] [--particle-number partículas] [--duration segundos] [--bicolor] [--monocolor]

DESCRIPCIÓN

Un sistema de partículas de trazado de caminos evoluciona continuamente desde un horizonte inicial, alternando entre colores.

OPCIONES

binaryhorizon acepta las siguientes opciones:

--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.
--install
Instala un mapa de colores privado para la ventana.
--mono
Si está en una pantalla en color, finge que estamos en una pantalla monocromática.
--noinstall
No instales un mapa de colores privado para la ventana.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--window-id id-ventana
Especifica qué ID de ventana usar.
--color (Por defecto)
Las partículas tienen colores generados aleatoriamente que cambian gradualmente con el tiempo.
--no-color
Usa la visualización original en blanco y negro.
--bicolor (Por defecto)
Las partículas tienen 2 colores aleatorios, comenzando como blanco y negro.
--monocolor
Las partículas tienen 2 colores, uno comenzando como blanco y cambiando gradualmente, y otro que permanece negro.
--fade (Por defecto)
Las partículas se desvanecen gradualmente entre colores con el tiempo.
--no-fade
Cada partícula es de un color aleatorio.
--growth-delay retraso_ms (Por defecto: 10000)
Retraso en ms entre ciclos de crecimiento. Mayor retraso, más lento (pero menos carga de CPU).
--particles-number partículas (Por defecto: 5000)
El número de partículas en el sistema. Con más partículas, los fps también pueden verse afectados.
--duration segundos (Por defecto: 30)
Cuánto tiempo entre reinicios completos.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
