DESCRIPCIÓ

N

B::Deparse es un módulo backend para el compilador de Perl que genera código fuente perl, basado en la estructura compilada interna que el propio perl crea después de analizar un programa. La salida de B::Deparse no será exactamente igual al código fuente original, ya que perl no conserva un registro de los comentarios o el espacio en blanco, y no existe una correspondencia uno a uno entre las construcciones sintácticas de perl y su forma compilada, pero a menudo será cercana. Cuando utilizas la opción -p, la salida también incluye paréntesis incluso cuando no son requeridos por la precedencia, lo que puede facilitar ver si perl está analizando tus expresiones de la manera que

pretendías.

Aunque B::Deparse hace algunos esfuerzos para intentar averiguar qué estaba haciendo tu programa original, algunas partes del lenguaje aún pueden

confundirlo; incluso falla en algunas partes de la propia suite de pruebas de Perl. Si encuentras un fallo diferente a los más comunes descritos
en la sección ERRORES a continuación, puedes contribuir al desarrollo continuo de B::Deparse enviando un informe de error con un pequeño ejemplo.

d
Imprime los valores de datos (cuando aparecen como constantes) usando Data::Dumper. Sin esta opción, B::Deparse usará algunas rutinas simples propias para el mismo propósito. Actualmente, Data::Dumper es mejor para algunos tipos de datos (como estructuras complejas con compartición y autorreferencia) mientras que las rutinas integradas son mejores para otros (como valores de punto flotante extraños)

Normalmente, B::Deparse analiza el código principal de un programa, y todos los subs definidos en el mismo archivo. Para incluir subs definidos en otros archivos, pasa la opción -f con el nombre del archivo. Puedes pasar la opción -f varias veces, para incluir más de un archivo secundario. (La mayor parte del tiempo no querrás usarla en absoluto.) También puedes usar esta opción para incluir subs que están definidos en el ámbito de una directiva #line con dos
parámetros.
