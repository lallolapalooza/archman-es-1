BN_rand(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_RAND(3ssl) OpenSSL BN_RAND(3ssl)

NOMBRE

BN_rand_ex, BN_rand, BN_priv_rand_ex, BN_priv_rand, BN_pseudo_rand, BN_rand_range_ex, BN_rand_range, BN_priv_rand_range_ex, BN_priv_rand_range - generar número pseudoaleatorio

SINOPSIS

#include <openssl/bn.h>
int BN_rand_ex(BIGNUM *rnd, int bits, int top, int bottom,
               unsigned int strength, BN_CTX *ctx);
int BN_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_priv_rand_ex(BIGNUM *rnd, int bits, int top, int bottom,
                    unsigned int strength, BN_CTX *ctx);
int BN_priv_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_rand_range_ex(BIGNUM *rnd, const BIGNUM *range, unsigned int strength,
                     BN_CTX *ctx);
int BN_rand_range(BIGNUM *rnd, const BIGNUM *range);
int BN_priv_rand_range_ex(BIGNUM *rnd, const BIGNUM *range, unsigned int strength,
                          BN_CTX *ctx);
int BN_priv_rand_range(BIGNUM *rnd, const BIGNUM *range);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

int BN_pseudo_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_pseudo_rand_range(BIGNUM *rnd, const BIGNUM *range);

DESCRIPCIÓN

BN_rand_ex() genera un número pseudoaleatorio criptográficamente seguro de bits de longitud y una fortaleza de seguridad de al menos strength bits utilizando el generador de números aleatorios para el contexto de la biblioteca asociado con ctx. La función almacena los datos generados en rnd. El parámetro ctx puede ser NULL, en cuyo caso se utiliza el contexto de la biblioteca por defecto. Si bits es menor que cero, o demasiado pequeño para acomodar los requisitos especificados por los parámetros top y bottom, se devuelve un error. El parámetro top especifica los requisitos sobre el bit más significativo del número generado. Si es BN_RAND_TOP_ANY, no hay restricción. Si es BN_RAND_TOP_ONE, el bit superior debe ser uno. Si es BN_RAND_TOP_TWO, los dos bits más significativos del número se establecerán a 1, de modo que el producto de dos números aleatorios de este tipo siempre tendrá una longitud de 2*bits. Si bottom es BN_RAND_BOTTOM_ODD, el número será impar; si es BN_RAND_BOTTOM_ANY, puede ser impar o par. Si bits es 1, entonces top no puede ser también BN_RAND_TOP_TWO.

BN_rand() es lo mismo que BN_rand_ex() excepto que siempre se utiliza el contexto de la biblioteca por defecto.

BN_rand_range_ex() genera un número pseudoaleatorio criptográficamente seguro rnd, de una fortaleza de seguridad de al menos strength bits, en el rango 0 <= rnd < range utilizando el generador de números aleatorios para el contexto de la biblioteca asociado con ctx. El parámetro ctx puede ser NULL, en cuyo caso se utiliza el contexto de la biblioteca por defecto.

BN_rand_range() es lo mismo que BN_rand_range_ex() excepto que siempre se utiliza el contexto de la biblioteca por defecto.

BN_priv_rand_ex(), BN_priv_rand(), BN_priv_rand_rand_ex() y BN_priv_rand_range() tienen la misma semántica que BN_rand_ex(), BN_rand(), BN_rand_range_ex() y BN_rand_range() respectivamente. Están destinados a ser utilizados para generar valores que deben permanecer privados, y reflejan la misma diferencia entre RAND_bytes(3) y RAND_priv_bytes(3).

NOTAS

Siempre comprueba el valor de retorno de error de estas funciones y no des por sentada la aleatoriedad: se produce un error si el CSPRNG no ha sido sembrado con suficiente aleatoriedad para garantizar una secuencia de bytes impredecible.

VALORES DE RETORNO

Las funciones devuelven 1 en caso de éxito, 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), RAND_add(3), RAND_bytes(3), RAND_priv_bytes(3), RAND(7), EVP_RAND(7)

HISTORIA

  • A partir de la versión 1.1.0 de OpenSSL, BN_pseudo_rand() ha sido idéntica a BN_rand() y BN_pseudo_rand_range() ha sido idéntica a BN_rand_range(). Las funciones BN_pseudo_rand() y BN_pseudo_rand_range() fueron marcadas como obsoletas en OpenSSL 3.0.
  • Las funciones BN_priv_rand() y BN_priv_rand_range() fueron añadidas en OpenSSL 1.1.1.
  • Las funciones BN_rand_ex(), BN_priv_rand_ex(), BN_rand_range_ex() y BN_priv_rand_range_ex() fueron añadidas en OpenSSL 3.0.
