NOMBRE

basic_ncsa_auth - Ayudante de autenticación de archivo de contraseña estilo NCSA httpd para Squid

SINOPSIS

basic_ncsa_auth archivo_contraseñas

DESCRIPCIÓN

basic_ncsa_auth permite a Squid leer y autenticar información de usuario y contraseña de un archivo de contraseña estilo NCSA/Apache httpd al usar autenticación HTTP básica.

Este archivo de contraseña puede ser manipulado usando htpasswd.

Este autenticador acepta:
* Blowfish - para contraseñas de 72 caracteres o menos.
* SHA256 - con salting y cadenas mágicas.
* SHA512 - con salting y cadenas mágicas.
* MD5 - con salting y cadenas mágicas opcionales.
* DES - para contraseñas de 8 caracteres o menos. NOTA: Los algoritmos Blowfish y SHA requieren soporte específico del sistema.

OPCIONES

El único parámetro es el archivo de contraseñas. Debe tener permisos para ser leído por el usuario con el que se está ejecutando Squid.

CONFIGURACIÓN

basic_ncsa_auth /etc/squid/squid.pass

basic_ncsa_auth debe tener acceso al archivo de contraseñas para ser ejecutado.

PROBLEMAS CONOCIDOS

La funcionalidad DES (usada por htpasswd por defecto) trunca silenciosamente las contraseñas a 8 caracteres. Permitiendo el inicio de sesión con valores de contraseña más cortos que el deseado. Este autenticador rechazará el inicio de sesión con contraseñas largas cuando se usa DES.
