Business::ISBN::Data(3) Documentación de Perl contribuida por el usuario Business::ISBN::Data(3)

NOMBRE

Business::ISBN::Data - paquete de datos para Business::ISBN

SINOPSIS

ver Business::ISBN

DESCRIPCIÓN

No necesita cargar este módulo usted mismo en la mayoría de los casos. Business::ISBN lo cargará cuando se cargue. Debe usar Business::ISBN 3.005 o posterior porque la estructura de datos cambió ligeramente para corregir un error con los prefijos ISBN13.

Estos datos se generan a partir del archivo RangeMessage.xml proporcionado por la Agencia ISBN. La versión distribuida coincide con la fecha en la versión de este módulo. Puede recuperarla usted mismo en https://www.isbn-international.org/range_file_generation. Este archivo se incluye como parte de la distribución y debe instalarse en ~lib/Business/ISBN/Data/RangeMessage.xml.

Si desea utilizar un archivo RangeMessage.xml diferente, puede establecer la variable de entorno "ISBN_RANGE_MESSAGE" a la ubicación alternativa antes de cargar "Business::ISBN". De esta manera, puede utilizar los datos más recientes (o incluso anteriores) sin tener que instalar algo nuevo o esperar una actualización de este módulo.

Si el archivo RangeMessage.xml predeterminado o el suyo alternativo no está disponible, el módulo recurre a los datos incluidos en Data.pm. Sin embargo, es probable que esos datos estén desactualizados. Si no encuentra ese archivo, busca RangeMessage.xml en el directorio actual.

Los datos están en %Business::ISBN::country_data (aunque la parte de "country" es histórica). Si desea ver de dónde provienen los datos, consulte $Business::ISBN::country_data{_source}.

Empaquetado de este módulo

El archivo RangeMessage.xml incluido está en lib/ al mismo nivel que Data.pm. Los mismos datos existen como datos predeterminados en el código, por lo que no necesita pasar el archivo distribuido RangeMessage.xml. Sin embargo, puede incluir un archivo RangeMessage.xml más reciente.

Con PAR, puede agregar archivos adicionales al archivo con "-a". Coloque el nuevo archivo en algún lugar donde el módulo lo encuentre (o use "ISBN_RANGE_MESSAGE" para que lo dirija allí):

pp ... -a '..../RangeMessage.xml;RangeMessage.xml'

Si coloca RangeMessage.xml en el directorio de trabajo actual de la aplicación, el módulo debería encontrarlo.

Actualización de los datos predeterminados

En el repositorio, encuentre el programa examples/make_default_data.pl. Ejecútelo contra el último RangeMessage.xml:

% perl -Ilib examples/make_default_data.pl RangeMessage.xml

Eso produce el código que necesita reemplazar en el módulo. Verifique que esos datos no sean extraños: a veces los nombres de grupo tienen errores o rarezas. El programa maneja el escape de comillas simples y el recorte de espacios en blanco.
