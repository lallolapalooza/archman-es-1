NOMBRE

bt-obex - cliente/servidor OBEX de bluetooth

SINOPSIS

bt-obex [OPCIÓN...]

Opciones de ayuda:
-h, --help

Opciones de aplicación:
-a, --adapter=<nombre|mac>
-s, --server [<ruta>]
-p, --opp <nombre|mac> <archivo>
-f, --ftp=<nombre|mac>

DESCRIPCIÓN

Esta utilidad implementa el soporte para el Perfil de Envío de Objetos (OPP) y el Perfil de Transferencia de Archivos (FTP). Puede enviar y recibir archivos hacia/desde un dispositivo remoto usando esta herramienta.

OPCIONES

-h, --help
Mostrar ayuda

-a, --adapter <nombre|mac>
Especificar el adaptador a usar por su nombre o dirección MAC
(si esta opción no se define, se usa el adaptador predeterminado)

-s, --server [<ruta>]
Registrar un agente en el servidor OBEX y establecer el directorio entrante/raíz a
`ruta` o se usará la carpeta actual; el agente se usa para
aceptar/rechazar solicitudes entrantes de envío de objetos por bluetooth

-p, --opp <nombre|mac> <archivo>
Enviar un archivo local al dispositivo remoto especificado usando el perfil de envío de objetos

-f, --ftp <nombre|mac>
Iniciar una sesión FTP con el dispositivo remoto; si la sesión se abre
correctamente, se abrirá un shell FTP

Comandos FTP:
    help                    Mostrar mensaje de ayuda
    exit                    Cerrar sesión FTP
    cd <carpeta>            Cambiar la carpeta actual del dispositivo remoto
    mkdir <carpeta>         Crear una nueva carpeta en el dispositivo remoto
    ls                      Listar contenido de la carpeta
    get <fuente> <destino>  Copiar el archivo fuente (desde el dispositivo remoto) al archivo destino (en el sistema de archivos local)
    put <fuente> <destino>  Copiar el archivo fuente (desde el sistema de archivos local) al archivo destino (en el dispositivo remoto)
    cp <fuente> <destino>  Copiar un archivo dentro del dispositivo remoto desde el archivo fuente a el archivo destino
    mv <fuente> <destino>  Mover un archivo dentro del dispositivo remoto desde el archivo fuente a el archivo destino
    rm <objetivo>           Elimina el archivo/carpeta especificado
