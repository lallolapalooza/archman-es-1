NOMBRE

buf-registry-sdk-info - Obtiene información del SDK para el módulo, plugin y, opcionalmente, versión dados.

SINOPSIS

buf registry sdk info --module= --plugin= [flags]

DESCRIPCIÓN

Este comando devuelve la información de la versión de un SDK Generado basado en la información especificada. Para resolver la información del SDK, se deben especificar un módulo y un plugin.

Ejemplos:

Para obtener la información del SDK para el último commit de un módulo y la última versión de un plugin, solo necesitas especificar el módulo y el plugin. Lo siguiente resolverá la información del SDK para el último commit del módulo connectrpc/eliza y la última versión del plugin bufbuild/es:

$ buf registry sdk info --module=buf.build/connectrpc/eliza --plugin=buf.build/connectrpc/es
Module
Owner:  connectrpc
Name:   eliza
Commit: <último commit en la etiqueta predeterminada>
Plugin
Owner:    bufbuild
Name:     es
Version:  <última versión del plugin>
Revision: <última revisión de la versión del plugin>
Version: <versión del SDK para el commit del módulo y la versión del plugin resueltos>

Para obtener la información del SDK para un commit específico de un módulo y/o una versión específica de un plugin, puedes especificar el commit con el módulo y/o la versión con el plugin. Lo siguiente resolverá la información del SDK para el commit especificado del módulo connectrpc/eliza y la versión especificada del plugin bufbuild/es:

$ buf registry sdk info --module=buf.build/connectrpc/eliza:d8fbf2620c604277a0ece1ff3a26f2ff --plugin=buf.build/bufbuild/es:v1.2.1
Module
Owner:  connectrpc
Name:   eliza
Commit: d8fbf2620c604277a0ece1ff3a26f2ff
Plugin
Owner:    bufbuild
Name:     es
Version:  v1.2.1
Revision: 1
Version: 1.2.1-20230727062025-d8fbf2620c60.1

Si tienes una versión de SDK y quieres conocer la información correspondiente del commit del módulo y la versión del plugin para ese SDK, puedes especificar el módulo y el plugin con la cadena de versión. Lo siguiente resolverá la información del SDK para la versión de SDK especificada del módulo connectrpc/eliza y el plugin bufbuild/es.

$ buf registry sdk --module=buf.build/connectrpc/eliza --plugin=buf.build/bufbuild/es --version=1.2.1-20230727062025-d8fbf2620c60.1
Module
Owner:  connectrpc
Name:   eliza
Commit: d8fbf2620c604277a0ece1ff3a26f2ff
Plugin
Owner:    bufbuild
Name:     es
Version:  v1.2.1
Revision: 1
Version: 1.2.1-20230727062025-d8fbf2620c60.1

La información del commit del módulo y la versión del plugin se resuelven basándose en la cadena de versión del SDK especificada.

Si se especifican una referencia de módulo y/o una versión de plugin junto con la versión del SDK, la versión del SDK se validará contra la referencia de módulo especificada y/o la versión de plugin. Si hay una discrepancia, este comando generará un error.

$ buf registry sdk info  \
    --module=buf.build/connectrpc/eliza:8b8b971d6fde4dc8ba5d96f9fda7d53c   \
    --plugin=buf.build/bufbuild/es  \
    --version=1.2.1-20230727062025-d8fbf2620c60.1
Failure: invalid_argument: invalid SDK version v1.2.1-20230727062025-d8fbf2620c60.1 with module short commit d8fbf2620c60 for resolved module reference connectrpc/eliza:8b8b971d6fde4dc8ba5d96f9fda7d53c

En este caso, la versión del SDK proporcionada se resuelve a un commit diferente al commit proporcionado para el módulo.

OPCIONES

--format="text" El formato de salida a usar. Debe ser uno de [text,json]

-h, --help[=false] Ayuda para info

--module="" La referencia del módulo para el SDK.

--plugin="" La referencia del plugin para el SDK.

--version="" La versión del SDK.

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato de registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
