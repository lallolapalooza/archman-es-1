BOGOUPGRADE(1) Manual de referencia de Bogofilter BOGOUPGRADE(1)

NOMBRE

bogoupgrade - actualiza la base de datos de bogofilter a la versión actual

SINOPSIS

bogoupgrade [-h] -d directorio [-i archivo_entrada] [-o archivo_salida] [-b ruta_a_bogoutil]

DESCRIPCIÓN

bogoupgrade es un comando para actualizar las bases de datos de bogofilter de un formato antiguo al formato actual. Dado que el formato de la base de datos cambia de vez en cuando, la utilidad está diseñada para hacer la actualización fácil.

OPCIONES

La opción -h imprime el mensaje de ayuda y sale.

La opción -d especifica el directorio con las listas de palabras para convertir. Esta opción se utiliza al convertir desde múltiples listas de palabras separadas (spamlist.db y goodlist.db - que contienen tokens de spam y ham, respectivamente) a una lista de palabras combinada (wordlist.db) que contiene tokens de spam y ham.

La opción -i especifica el archivo de entrada a convertir. Debería ser un archivo de texto que contenga recuentos de mensajes y, posiblemente, datos. Si no hay datos en el archivo de texto, debería haber un archivo Berkeley DB en el mismo directorio que el archivo de texto que contenga los datos.

La opción -o especifica el archivo Berkeley DB de salida.

La opción -b proporciona la ruta al comando bogoutil. Por defecto es 'bogoutil', esperando que tu shell lo encuentre.

ACTUALIZANDO

Sigue estas instrucciones para actualizar las bases de datos de bogofilter a la última versión.

1.Detén todas las instancias de bogofilter. Mientras las herramientas de actualización bloquean los archivos de la base de datos, la actualización puede llevar mucho tiempo si tienes un sitio con mucho tráfico. No olvides detener los trabajos cron o los demonios que obtienen y procesan el correo y que podrían iniciar bogofilter.
2.Haz una copia de seguridad de tus datos. Supongamos que ejecutaste: 
$ mv ~/.bogofilter ~/.bogofilter.safe
$ mkdir ~/.bogofilter
3.Si tu versión de bogofilter es anterior a la 0.7, ejecuta: 
$ bogoupgrade -i ~/.bogofilter.safe/goodlist -o ~/.bogofilter/goodlist.db
$ bogoupgrade -i ~/.bogofilter.safe/badlist -o ~/.bogofilter/spamlist.db

Si tu versión de bogofilter es 0.7 o superior, ejecuta:

$ bogoupgrade -i ~/.bogofilter.safe/hamlist.count -o ~/.bogofilter/goodlist.db
$ bogoupgrade -i ~/.bogofilter.safe/spamlist.count -o ~/.bogofilter/spamlist.db
4.Las versiones actuales de bogofilter utilizan una lista de palabras combinada que contiene tokens de spam y no spam. Se llama wordlist.db. Si estás actualizando desde una versión anterior a la 0.14.0 que tiene listas de palabras separadas (llamadas goodlist.db y spamlist.db), usa: 
$ bogoupgrade -d ~/.bogofilter.safe
5.Listo. Reinicia cualquier demonio, tarea cron, etc., detenidos.
