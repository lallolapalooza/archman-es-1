NOMBRE

buf-format - Formatea archivos Protobuf

SINOPSIS

buf format [flags]

DESCRIPCIÓN

Por defecto, la fuente es el directorio actual y el contenido formateado se escribe en stdout.

Ejemplos:

Escribe el contenido formateado del directorio actual en stdout:

$ buf format

La mayoría de la gente querrá reescribir los archivos definidos en el directorio actual in situ con -w:

$ buf format -w

Muestra un diff entre el contenido original y el formateado con -d. Escribe un diff en lugar del archivo formateado:

$ buf format simple/simple.proto -d
$ diff -u simple/simple.proto.orig simple/simple.proto
--- simple/simple.proto.orig	2022-03-24 09:44:10.000000000 -0700
+++ simple/simple.proto	2022-03-24 09:44:10.000000000 -0700
@@ -2,8 +2,7 @@
package simple;
-
message Object {
-    string key = 1;
-   bytes value = 2;
+  string key = 1;
+  bytes value = 2;
}

Usa la bandera --exit-code para salir con un código de salida no cero si hay un diff:

$ buf format --exit-code
$ buf format -w --exit-code
$ buf format -d --exit-code

Formatea un archivo, directorio o referencia de módulo especificando una fuente, por ejemplo, escribe el archivo formateado en stdout:

$ buf format simple/simple.proto
syntax = "proto3";
package simple;
message Object {
  string key = 1;
  bytes value = 2;
}

Escribe el directorio formateado en stdout:

$ buf format simple
...

Escribe la referencia de módulo formateada en stdout:

$ buf format buf.build/acme/petapis
...

Escribe el resultado en un archivo o directorio de salida especificado con -o, por ejemplo:

Escribe el archivo formateado en otro archivo:

$ buf format simple/simple.proto -o simple/simple.formatted.proto

Escribe el directorio formateado en otro directorio, creándolo si no existe:

$ buf format proto -o formatted

Esto también funciona con referencias de módulo:

$ buf format buf.build/acme/weather -o formatted

Reescribe los archivos in situ con -w, por ejemplo:

Reescribe un solo archivo in situ:

$ buf format simple.proto -w

Reescribe un directorio completo in situ:

$ buf format proto -w

Escribe un diff y reescribe los archivos in situ:

$ buf format simple -d -w
$ diff -u simple/simple.proto.orig simple/simple.proto
...

Las banderas -w y -o no se pueden usar juntas en una sola invocación.

OPCIONES

--config="" El archivo buf.yaml o datos a usar para la configuración

-d, --diff[=false] Muestra diffs en lugar de reescribir archivos

--disable-symlinks[=false] No seguir enlaces simbólicos al leer fuentes o configuración del sistema de archivos local. Por defecto, los enlaces simbólicos se siguen en esta CLI, pero nunca se siguen en el Buf Schema Registry

--error-format="text" El formato para los errores de compilación impresos en stderr. Debe ser uno de [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-path=[] Excluye archivos o directorios específicos, por ejemplo "proto/a/a.proto", "proto/a". Si se especifica múltiples veces, se toma la unión.

--exit-code[=false] Sale con un código de salida no cero si los archivos no estaban ya formateados

-h, --help[=false] Ayuda para format

-o, --output="-" La ubicación de salida para los archivos formateados. Debe ser uno de los formatos [dir,protofile]. Si se omite, el resultado se escribe en stdout

--path=[] Limita a archivos o directorios específicos, por ejemplo "proto/a/a.proto", "proto/a". Si se especifica múltiples veces, se toma la unión.

-w, --write[=false] Reescribe los archivos in situ

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activa el registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
