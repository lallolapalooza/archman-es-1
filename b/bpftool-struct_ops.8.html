BPFTOOL-STRUCT_OPS(8) Manual del Administrador del Sistema BPFTOOL-STRUCT_OPS(8)

NOMBRE

bpftool-struct_ops - herramienta para registrar/desregistrar/introspeccionar BPF struct_ops

SINOPSIS

bpftool [OPCIONES] struct_ops COMANDO

OPCIONES := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMANDOS := { show | list | dump | register | unregister | help }

COMANDOS STRUCT_OPS

bpftool struct_ops { show | list } [MAPA_STRUCT_OPS]
bpftool struct_ops dump [MAPA_STRUCT_OPS]
bpftool struct_ops register OBJ [DIR_LINK]
bpftool struct_ops unregister MAPA_STRUCT_OPS
bpftool struct_ops help
MAPA_STRUCT_OPS := { id ID_MAPA_STRUCT_OPS | name NOMBRE_MAPA_STRUCT_OPS }
OBJ := /un/archivo/de/bpf_struct_ops.o

DESCRIPCIÓN

bpftool struct_ops { show | list } [MAPA_STRUCT_OPS]
Muestra información breve sobre las struct_ops en el sistema. Si se especifica MAPA_STRUCT_OPS, solo muestra información para la struct_ops dada. De lo contrario, lista todas las struct_ops existentes actualmente en el sistema.

La salida comenzará con el ID del mapa struct_ops, seguido de su nombre de mapa y el tipo de kernel de su struct_ops.

bpftool struct_ops dump [MAPA_STRUCT_OPS]
Descarga información detallada sobre las struct_ops en el sistema. Si se especifica MAPA_STRUCT_OPS, solo descarga información para la struct_ops dada. De lo contrario, descarga todas las struct_ops existentes actualmente en el sistema.
bpftool struct_ops register OBJ [DIR_LINK]
Registra struct_ops bpf desde OBJ. Todas las struct_ops bajo la sección ELF ".struct_ops" y ".struct_ops.link" se registrarán en su subsistema de kernel. Para cada struct_ops en la sección ".struct_ops.link", se creará un enlace. Puede proporcionar DIR_LINK para especificar una ruta de directorio donde estos enlaces se fijarán con el mismo nombre que su nombre de mapa correspondiente.
bpftool struct_ops unregister MAPA_STRUCT_OPS
Anula el registro de MAPA_STRUCT_OPS del subsistema del kernel.
bpftool struct_ops help
Imprime un mensaje de ayuda corto.

OPCIONES

-h, --help
Imprime un mensaje de ayuda corto (similar a bpftool help).
-V, --version
Imprime el número de versión de bpftool (similar a bpftool version), el número de la versión de libbpf en uso y las características opcionales que se incluyeron cuando se compiló bpftool. Las características opcionales incluyen el enlace a LLVM o libbfd para proporcionar el desensamblador para programas JIT-ted (bpftool prog dump jited) y el uso de esqueletos BPF (algunas características como bpftool prog profile o mostrar pids asociados a objetos BPF pueden depender de ello).
-j, --json
Genera salida JSON. Para los comandos que no pueden producir JSON, esta opción no tiene efecto.
-p, --pretty
Genera salida JSON legible por humanos. Implica -j.
-d, --debug
Imprime todos los registros disponibles, incluso información a nivel de depuración. Esto incluye registros de libbpf y del verificador, al intentar cargar programas.

EJEMPLOS

# bpftool struct_ops show

100: dctcp           tcp_congestion_ops
105: cubic           tcp_congestion_ops

# bpftool struct_ops unregister id 105

Unregistered tcp_congestion_ops cubic id 105

# bpftool struct_ops register bpf_cubic.o

Registered tcp_congestion_ops cubic id 110
