BIO_s_core(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_S_CORE(3ssl) OpenSSL BIO_S_CORE(3ssl)

NOMBRE

BIO_s_core, BIO_new_from_core_bio - Funciones OSSL_CORE_BIO

SINOPSIS

#include <openssl/bio.h>
const BIO_METHOD *BIO_s_core(void);
BIO *BIO_new_from_core_bio(OSSL_LIB_CTX *libctx, OSSL_CORE_BIO *corebio);

DESCRIPCIÓN

BIO_s_core() devuelve la función del método BIO principal.

Un BIO principal se trata como un BIO de origen/destino que se comunica con algún BIO externo. Esto es principalmente útil para los autores de proveedores. Varias llamadas de libcrypto a un proveedor proporcionan un parámetro OSSL_CORE_BIO. Esto representa un BIO dentro de libcrypto, pero no puede ser utilizado directamente por un proveedor. En su lugar, debe envolverse utilizando un BIO_s_core().

Una vez que se construye un BIO basado en BIO_s_core(), el objeto OSSL_CORE_BIO asociado debe establecerse en él utilizando BIO_set_data(3). Tenga en cuenta que el BIO solo funcionará correctamente si está asociado con un contexto de biblioteca construido utilizando OSSL_LIB_CTX_new_from_dispatch(3). Para asociar el BIO con un contexto de biblioteca, constrúyalo usando BIO_new_ex(3).

BIO_new_from_core_bio() es una función de conveniencia que construye un nuevo BIO basado en BIO_s_core() y que está asociado con el contexto de biblioteca dado. Luego, también establece el objeto OSSL_CORE_BIO en el BIO utilizando BIO_set_data(3).

VALORES DE RETORNO

BIO_s_core() devuelve una estructura de método BIO principal BIO_METHOD.

BIO_new_from_core_bio() devuelve una estructura BIO en caso de éxito o NULL en caso de error. Un error será comúnmente debido a que el contexto de la biblioteca no se construyó utilizando OSSL_LIB_CTX_new_from_dispatch(3).

HISTORIA

BIO_s_core() y BIO_new_from_core_bio() se agregaron en OpenSSL 3.0.

EJEMPLOS

Crear un BIO principal y escribir algunos datos en él:

int some_function(OSSL_LIB_CTX *libctx, OSSL_CORE_BIO *corebio) {
    BIO *cbio = BIO_new_from_core_bio(libctx, corebio);
    if (cbio == NULL)
        return 0;
    BIO_puts(cbio, "Hola Mundo\n");
    BIO_free(cbio);
    return 1;
}
