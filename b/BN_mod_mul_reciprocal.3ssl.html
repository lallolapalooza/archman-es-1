BN_mod_mul_reciprocal(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_mod_mul_reciprocal(3ssl) OpenSSL BN_mod_mul_reciprocal(3ssl)

NOMBRE

BN_mod_mul_reciprocal, BN_div_recp, BN_RECP_CTX_new, BN_RECP_CTX_free, BN_RECP_CTX_set - multiplicación modular usando recíproco

SINOPSIS

#include <openssl/bn.h>
BN_RECP_CTX *BN_RECP_CTX_new(void);
void BN_RECP_CTX_free(BN_RECP_CTX *recp);
int BN_RECP_CTX_set(BN_RECP_CTX *recp, const BIGNUM *m, BN_CTX *ctx);
int BN_div_recp(BIGNUM *dv, BIGNUM *rem, const BIGNUM *a, BN_RECP_CTX *recp,
                BN_CTX *ctx);
int BN_mod_mul_reciprocal(BIGNUM *r, const BIGNUM *a, const BIGNUM *b,
                          BN_RECP_CTX *recp, BN_CTX *ctx);

DESCRIPCIÓN

BN_mod_mul_reciprocal() se puede usar para realizar una operación BN_mod_mul(3) eficiente cuando la operación se realizará repetidamente con el mismo módulo. Calcula r=(a*b)%m usando recp=1/m, que se establece como se describe a continuación. ctx es un BN_CTX previamente asignado utilizado para variables temporales.

BN_RECP_CTX_new() asigna e inicializa una estructura BN_RECP.

BN_RECP_CTX_free() libera los componentes de BN_RECP y, si fue creado por BN_RECP_CTX_new(), también la estructura misma. Si recp es NULL, no se hace nada.

BN_RECP_CTX_set() almacena m en recp y lo configura para calcular 1/m y desplazarlo a la izquierda en BN_num_bits(m)+1 para convertirlo en un entero. El resultado y el número de bits que se desplazó a la izquierda se almacenarán posteriormente en recp.

BN_div_recp() divide a entre m usando recp. Coloca el cociente en dv y el resto en rem.

La estructura BN_RECP_CTX no se puede compartir entre hilos.

VALORES DE RETORNO

BN_RECP_CTX_new() devuelve el BN_RECP_CTX recién asignado, y NULL en caso de error.

BN_RECP_CTX_free() no tiene valor de retorno.

Para las demás funciones, se devuelve 1 para éxito, 0 en caso de error. Los códigos de error se pueden obtener mediante ERR_get_error(3).

VER TAMBIÉN

ERR_get_error(3), BN_add(3), BN_CTX_new(3)

HISTORIA

BN_RECP_CTX_init() fue eliminado en OpenSSL 1.1.0
