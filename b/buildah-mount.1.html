NOMBRE

buildah-mount - Montar el sistema de archivos raíz de un contenedor en construcción.

SINOPSIS

buildah mount [contenedor ...]

DESCRIPCIÓN

Monta el sistema de archivos raíz del contenedor especificado en una ubicación accesible desde el host y devuelve su ubicación.

Si el comando mount se invoca sin argumentos, la herramienta listará todos los contenedores montados actualmente.

Al ejecutarse en modo sin privilegios (rootless), mount se ejecuta en un espacio de nombres diferente, de modo que el volumen montado podría no ser accesible desde el host si se utiliza un controlador diferente a vfs. Para poder acceder al sistema de archivos montado, es posible que necesites crear el espacio de nombres de montaje por separado como parte de buildah unshare. En el entorno creado con buildah unshare, puedes usar entonces buildah mount y tener acceso al sistema de archivos montado.

VALOR DE RETORNO

La ubicación del sistema de archivos montado. En caso de error, se devuelve una cadena vacía y el código de error (errno).

OPCIONES

--json

Salida en formato JSON.

EJEMPLO

buildah mount contenedor-en-construccion
/var/lib/containers/storage/overlay2/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged
buildah mount
contenedor-en-construccion /var/lib/containers/storage/overlay2/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged
contenedor-en-construccion-fedora /var/lib/containers/storage/overlay2/0ff7d7ca68bed1ace424f9df154d2dd7b5a125c19d887f17653cbcd5b6e30ba1/merged
buildah mount contenedor-en-construccion contenedor-en-construccion-fedora contenedor-en-construccion-ubi8
contenedor-en-construccion /var/lib/containers/storage/overlay/f8cac5cce73e5102ab321cc5b57c0824035b5cb82b6822e3c86ebaff69fefa9c/merged
contenedor-en-construccion-fedora /var/lib/containers/storage/overlay/c3ec418be5bda5b72dca74c4d397e05829fe62ecd577dd7518b5f7fc1ca5f491/merged
contenedor-en-construccion-ubi8 /var/lib/containers/storage/overlay/03a071f206f70f4fcae5379bd5126be86b5352dc2a0c3449cd6fca01b77ea868/merged

Si se ejecuta en modo sin privilegios (rootless), necesitas hacer un `buildah unshare` primero para usar el punto de montaje.

$ buildah unshare
# buildah mount contenedor-en-construccion
/var/lib/containers/storage/overlay/f8cac5cce73e5102ab321cc5b57c0824035b5cb82b6822e3c86ebaff69fefa9c/merged
# cp foobar  /var/lib/containers/storage/overlay/f8cac5cce73e5102ab321cc5b57c0824035b5cb82b6822e3c86ebaff69fefa9c/merged
# buildah unmount contenedor-en-construccion
# exit
$ buildah commit  contenedor-en-construccion nueva-imagen
