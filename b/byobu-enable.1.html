NOMBRE

byobu-enable, byobu-disable - script de envoltura para habilitar/deshabilitar el inicio automático de byobu después de iniciar sesión en la consola de texto

SINOPSIS

byobu-enable

byobu-disable

DESCRIPCIÓN

byobu-enable ejecutará byobu-launcher-install(1) para configurar byobu(1) para que se inicie automáticamente al iniciar sesión.

byobu-disable simplemente ejecutará byobu-launcher-uninstall(1).
