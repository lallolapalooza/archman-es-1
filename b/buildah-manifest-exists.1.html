NOMBRE

buildah-manifest-exists - Comprueba si la lista de manifiestos dada existe en el almacenamiento local

SINOPSIS

buildah manifest exists manifiesto

DESCRIPCIÓN

buildah manifest exists comprueba si una lista de manifiestos existe en el almacenamiento local. Buildah devolverá un código de salida de 0 cuando se encuentre la lista de manifiestos. Se devolverá un 1 en caso contrario. Un código de salida de 125 indica que hubo otro problema.

OPCIONES

--help, -h

Imprime la declaración de uso.

EJEMPLO

Comprueba si existe una lista de manifiestos llamada list1 (la lista de manifiestos realmente existe).

$ buildah manifest exists list1
$ echo $?
0
$

Comprueba si existe un manifiesto llamado mylist (la lista de manifiestos no existe realmente).

$ buildah manifest exists mylist
$ echo $?
1
$
