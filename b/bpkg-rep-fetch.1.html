DESCRIPCIÓ

N

El comando rep-fetch obtiene la lista de paquetes disponibles para los repositorios especificados, así como todos sus repositorios complementarios y de requisitos previos, de forma recursiva. Si no se especificaron repositorios, se obtienen todos los repositorios previamente añadidos (bpkg-rep-add(1)) a la

configuración.

El repositorio a obtener se puede especificar ya sea como un nombre de repositorio o como una ubicación de repositorio (URL o una ruta de directorio; ver bpkg-rep-add(1) para más detalles). En el último caso, la ubicación del repositorio se añade/reemplaza como si se ejecutara primero el comando

rep-add.

Tenga en cuenta que obtener solo un repositorio específico que resulte se

r un requisito previo o complemento de otro repositorio que no se está
obteniendo puede resultar en un estado de repositorio inconsistente.
