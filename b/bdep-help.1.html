NOMBRE

bdep-help - mostrar ayuda para un comando o tema de ayuda

SINOPSIS

bdep help [comando | tema]

DESCRIPCIÓN

Muestra la ayuda detallada para comando o tema de ayuda, o un resumen de los comandos y temas disponibles si no se especificó ninguno.

OPCIONES COMUNES

Las opciones comunes se resumen a continuación, con una descripción más detallada disponible en bdep-common-options(1).

-v
Imprime los comandos subyacentes esenciales que se están ejecutando.
-V
Imprime todos los comandos subyacentes que se están ejecutando.
--quiet|-q
Ejecuta en silencio, solo imprimiendo mensajes de error.
--verbose nivel
Establece la verbosidad de los diagnósticos en nivel entre 0 y 6.
--stdout-format formato
Formato de representación a usar para imprimir en stdout.
--jobs|-j num
Número de trabajos a realizar en paralelo.
--progress
Muestra indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--no-progress
Suprime los indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.
--diag-color
Usa color en los diagnósticos.
--no-diag-color
No uses color en los diagnósticos.
--bpkg ruta
El programa gestor de paquetes a utilizar para la gestión de la configuración de compilación.
--bpkg-option opt
Opción adicional a pasar al programa gestor de paquetes.
--build ruta
El programa de compilación a utilizar para compilar paquetes.
--build-option opt
Opción adicional a pasar al programa de compilación.
--curl ruta
El programa curl a utilizar para operaciones de red.
--curl-option opt
Opción adicional a pasar al programa curl.
--pager ruta
El programa paginador a utilizar para mostrar texto largo.
--pager-option opt
Opción adicional a pasar al programa paginador.
--options-file archivo
Lee opciones adicionales del archivo.
--default-options dir
El directorio desde donde cargar archivos de opciones predeterminados adicionales.
--no-default-options
No cargues archivos de opciones predeterminados.

ARCHIVOS DE OPCIONES PREDETERMINADOS

Consulta bdep-default-options-files(1) para obtener una descripción general de los archivos de opciones predeterminados. Para el comando help, solo se buscan los siguientes archivos de opciones en los directorios predefinidos (inicio, sistema, etc.) y, si se encuentran, se cargan en el orden que se indica:

bdep.options
bdep-help.options

ERRORES

Envía informes de errores a la lista de correo users@build2.org.
