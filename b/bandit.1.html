bandit(1)

NAME

bandit - find common security issues in Python code

SYNOPSIS

bandit [OPTIONS] [FILE ...]

DESCRIPTION

Bandit is a tool designed to find common security issues in Python code. It works by inspecting the abstract syntax tree of your Python code, and identifying common patterns that are often associated with security vulnerabilities.

Bandit works by using a plugin system. Each plugin checks for a specific type of vulnerability. The checks are defined in YAML files, and can be customized or extended.

OPTIONS

The following options are available:

-h, --help
Show a help message and exit.
-r, --recursive
Recursively search for files to check.
-x, --exclude EXCLUDE_PATHS
Comma-separated list of paths to exclude.
-i, --include INCLUDE_PATHS
Comma-separated list of paths to include.
-v, --verbose
Increase verbosity of output.
-iii, --debug
Print debug messages.
-f, --format FORMAT
Specify the output format. Supported formats: plain, json, csv, sarif. Default is plain.
-c, --config-file CONFIG_FILE
Path to configuration file. Default is .bandit in the current directory or a parent directory.
-n, --number NUMBER
Limit the number of issues reported.
--version
Show program's version number and exit.
--tests TEST_NAMES
Run only specified tests. Comma-separated list of test names.
--skip-list SKIP_FILE
Specify a file containing a list of issues to skip.
-ll, --level LEVEL
Only report issues of severity LEVEL or higher. Possible values: INFO, LOW, MEDIUM, HIGH. Default is INFO.

FILES

.bandit
Bandit configuration file. If not found in the current directory, Bandit will look for it in parent directories.

EXAMPLES

Run bandit on a single file: 

        bandit my_app.py

Run bandit recursively on a directory: 

        bandit -r src/

Run bandit and exclude a specific directory: 

        bandit -r src/ -x tests/

Run bandit and output in JSON format: 

        bandit -r src/ -f json
