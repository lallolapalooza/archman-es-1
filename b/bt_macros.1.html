DESCRIPCIÓ

N

btparse mantiene una única tabla con todas las macros (abreviaturas) encontradas al analizar entradas BibTeX. Actualiza esta tabla siempre que encuentra una "definición de macro" (@string), y la consulta cuando una macro se usa en una entrada y necesita ser expandida. (Las macros no se expanden necesariamente en la entrada, aunque es el comportamiento por defecto. Vea bt_postprocess.) Las definiciones de macro solo se borran cuando se llama a la función de limpieza global de btparse, bt_cleanup(). Por lo tanto, a menos que llame explícitamente a bt_delete_macro() o bt_delete_all_macros(), las definiciones de macro persisten mientras

use la biblioteca---normalmente, d
urante la vida útil de su proceso.

S

Puede usar las siguientes funciones para añadir macros, borrarlas y consultar sus valores---interfiriendo así con el funcionamiento normal de btparse sobre la

marcha.
bt_add_macro_text
() 
void bt_add_macro_text (char * macro,
                        char * text,
                        char * filename,
                        int
line);

Define una nueva macro o redefine una existente. "macro" es el nombre de la macro y "text" es el texto al que debe expandirse. "filename" y "line" se usan solo para generar cualquier advertencia sobre la definición de la macro; si no aplican, especifique "NULL" para "filename" y 0 para "line". La única advertencia de este tipo se produce cuando redefine una macro antigua: su valor se sobrescribe, y bt_add_macro_text() emite una advertencia

indicándolo.

Por ejemplo, al analizar esta entrada de definición

de macro: 
@string{fubar = "Fouled Up Beyond All
Recognition"}

la biblioteca (en particular, el código de postproceso que se llama después de analizar correctamente una entrada) terminará haciendo

esto: 
bt_add_macro_text ("fubar", "Fouled Up Beyond All Recognition",
                   filename,
line);

Esto, a su vez, hará que la macro "fubar" se expanda adecuadamente siempre que el

código de postproceso la vea
en cualquier entrada futura.
bt_add_macro_value
() 
void bt_add_macro_value (AST *  assignment,
                         btshort
options);

Esta función es principalmente para uso interno de la biblioteca, pero está disponible para usted si alguna vez se encuentra con un pequeño AST que representa una definición de macro y quiere definir la macro usted mismo (en lugar de dejar que el código de postproceso de la biblioteca se encargue de ello). "assignment" debe ser un nodo AST tal como lo devuelve bt_next_field(). A diferencia de la mayoría de las otras funciones de btparse que toman un argumento "options", "options" aquí indica cómo se postprocesó el valor en "assignment". Esto es necesario porque los valores de las macros deben procesarse de una manera especial para ser válidos en futuras expansiones; si este no se procesó así, bt_add_macro_value() lo hará por usted. Si no sabe cómo se postprocesó el valor, simplemente proporcione 0 para "options"---esto está garantizado para describir algo diferente de "la manera correcta" para las macros, de modo que el postproceso se realizará

correctamente.

El procesamiento que se hace a los valores de las macros es principalmente para asegurar que podemos almacenar simplemente una cadena de texto en la tabla de macros: las macros invocadas por la macro se expanden a su vez, y todas las subcadenas se concatenan. Por ejemplo, si btparse analiza estas

entradas: 
@string{and = " and "}
@string{jim_n_bob = "James Smith" # and # "Bob
Jones"}

entonces el valor almacenado para "jim_n_bob" debe ser obviamente la cadena "James Smith and Bob Jones". Para asegurar esto, btparse debe procesar el valor de "and" de manera diferente a la mayoría de las cadenas BibTeX: en particular, los espacios en blanco no se colapsan antes de que la cadena se almacene. De esa manera, el valor correcto, " and ", se interpola en el valor de "jim_n_bob". Así, todos los valores de las macros tienen sus submacros expandidas y las cadenas concatenadas antes de almacenarse, pero los espacios en blanco no se colapsan hasta que la macro se usa en una entrada

normal.

Esta función llama a bt_add_macro_text(), por lo que la misma advertencia sobre redefinir macros a

ntiguas se aplica---se emitirá una adverten
cia y se perderá el valor antiguo.
