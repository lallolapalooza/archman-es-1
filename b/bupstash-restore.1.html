bupstash-restore(1)

Paquete: bupstash

Licencias: MIT

() ()

RESUMEN

Restaura eficientemente el contenido de una instantánea en un directorio local.

bupstash restore [OPCIONES] --into $RUTA CONSULTA...

DESCRIPCIÓN

bupstash restore realiza un conjunto eficiente de cambios incrementales en un directorio para que sea idéntico a la instantánea solicitada. La naturaleza incremental de bupstash restore lo hace adecuado para alternar entre múltiples instantáneas similares. Tenga en cuenta que esta operación es peligrosa ya que elimina archivos adicionales ya presentes en el directorio de destino.

Para facilitar la navegación de archivos como usuarios no privilegiados, bupstash restore no intenta restaurar usuarios, grupos y xattrs por defecto. Para configurarlos, debe especificar las banderas --ownership y --xattrs respectivamente.

El elemento que se extrae se elige basándose en una consulta simple contra las etiquetas especificadas al guardar datos con bupstash put.

LENGUAJE DE CONSULTA

Para obtener documentación completa sobre el lenguaje de consulta, consulte bupstash-query-language(7).

CACHÉ DE CONSULTAS

El comando restore utiliza los mismos mecanismos de caché de consultas que bupstash-list(1), revise esa página para obtener más información sobre la caché de consultas.

ARCHIVOS DISPERSOS

Si un archivo fue detectado como disperso durante 'put', el comando restore lo restaurará como disperso, pero cabe señalar que el comando restore no eliminará un archivo existente con la suma de verificación correcta para recrearlo como disperso.

OPCIONES

--into RUTA
Directorio donde restaurar los archivos, por defecto es BUPSTASH_RESTORE_DIR.
-r, --repository REPOSITORIO
El repositorio al que conectarse, , puede tener el formato ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado. Si no se especifica, se establece a BUPSTASH_REPOSITORY.
-k, --key CLAVE
Clave que se utilizará para descifrar datos y metadatos. Si no se establece, por defecto es BUPSTASH_KEY.
--pick RUTA
Selecciona un subdirectorio de la instantánea para restaurar.
--ownership
Establece uid's y gid's.
--xattrs
Establece xattrs.
--indexer-threads N
Número de hilos de procesador a utilizar para el hashing de archivos en paralelo y la lectura de metadatos. Por defecto, el número de procesadores.
--query-cache RUTA
Ruta al archivo de caché de consultas, por defecto es uno de los siguientes, en orden, siempre que las variables de entorno apropiadas estén configuradas, $BUPSTASH_QUERY_CACHE, $XDG_CACHE_HOME/.cache/bupstash/bupstash.qcache o $HOME/.cache/bupstash/bupstash.qcache.
--utc-timestamps
Muestra y busca por marcas de tiempo en hora UTC en lugar de hora local.
--no-progress
Suprime los indicadores de progreso (Los indicadores de progreso también se suprimen cuando stderr no es una terminal interactiva).
-q, --quiet
Silencioso, implica --no-progress.

ENTORNO

BUPSTASH_REPOSITORY
El repositorio al que conectarse. Puede tener el formato ssh://$SERVIDOR/$RUTA para repositorios remotos si el acceso ssh está configurado.
BUPSTASH_REPOSITORY_COMMAND
Un comando para ejecutar y conectarse a una instancia de bupstash-serve(1). Esto permite conexiones más complejas al repositorio para casos de uso menos comunes.
BUPSTASH_KEY
Ruta a la clave que se utilizará para descifrar datos y metadatos.
BUPSTASH_KEY_COMMAND
Un comando para ejecutar que debe imprimir los datos de la clave, se puede usar en lugar de BUPSTASH_KEY para obtener la clave de ubicaciones arbitrarias, como la red u otros almacenamientos de secretos.
BUPSTASH_QUERY_CACHE
Ruta a la caché de consultas a utilizar.
BUPSTASH_RESTORE_DIR
Ruta donde restaurar, se puede usar en lugar del argumento --into.

EJEMPLOS

Restaurar una instantánea en un directorio local

$ bupstash restore --into ./dir id=ad8*

Restaurar incluyendo usuarios y grupos

$ bupstash restore --ownership --into ./dir id=ad8*

Restaurar un subdirectorio de la instantánea

$ bupstash restore --into ./dir --pick sub/dir id=ad8*
