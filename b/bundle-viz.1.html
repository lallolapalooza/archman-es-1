NOMBRE

bundle-viz - Genera un gráfico visual de dependencias para tu Gemfile

SINOPSIS

bundle viz [--file=ARCHIVO] [--format=FORMATO] [--requirements] [--version] [--without=GRUPO GRUPO]

DESCRIPCIÓN

viz genera un archivo PNG del Gemfile(5) actual como un gráfico de dependencias. viz requiere el gem ruby-graphviz (y sus dependencias).

Los gems asociados también deben instalarse a través de bundle install(1) bundle-install.1.html.

El comando viz fue obsoleto en Bundler 2.2. Utilice el plugin bundler-graph https://github.com/rubygems/bundler-graph en su lugar.

OPCIONES

--file=ARCHIVO, -f=ARCHIVO
El nombre a usar para el archivo generado. Consulte la opción --format
--format=FORMATO, -F=FORMATO
Esta es la opción de formato de salida. Los formatos compatibles son png, jpg, svg, dot ...
--requirements, -R
Establecer para mostrar la versión de cada dependencia requerida.
--version, -v
Establecer para mostrar la versión de cada gem.
--without=<lista>, -W=<lista>
Excluir gems que forman parte del grupo nombrado especificado.
