DESCRIPCIÓ

N

Estas macros operan sobre cadenas de

bits.

La macro bit_alloc() devuelve un puntero de tipo “bitstr_t *” al espacio suficiente para almacenar nbits bits, o NULL si no hay espacio

disponible.

La macro bit_decl() asigna espacio suficiente para almacenar nbits bits en la

pila.

La macro bitstr_size() devuelve el número de elementos de tipo bitstr_t necesarios para almacenar nbits bits. Esto es útil para copiar cadenas de

bits.

Las macros bit_clear() y bit_set() limpian o establecen el bit numerado desde cero bit, en la cadena de bits name

.

Las macros bit_nset() y bit_nclear() establecen o limpian los bits numerados desde cero desde start hasta stop en la cadena de bits name

.

La macro bit_test() evalúa a distinto de cero si el bit numerado desde cero bit de la cadena de bits name está establecido, y a cero en caso

contrario.

La macro bit_ffs() almacena en la ubicación referenciada por value el número desde cero del primer bit establecido en el arreglo de nbits bits referenciado por name. Si no hay bits establecidos, la ubicación referenciada por value se establece a

-1.

La macro bit_ffc() almacena en la ubicación referenciada por value el número desde cero del primer bit no establecido en el arreglo de nbits bits referenciado por name. Si todos los bits están establecidos, la ubicación referenciada por value se establece a

-1.

Los argumentos de estas macros se eva

lúan solo una vez y pueden tener
efectos secundarios de forma segura.
