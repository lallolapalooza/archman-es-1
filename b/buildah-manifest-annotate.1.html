NOMBRE

buildah-manifest-annotate - Añadir y actualizar información sobre una imagen o artefacto a una lista de manifiestos o índice de imágenes.

SINOPSIS

buildah manifest annotate [opciones...] NombreDeListaOÍndice DigestDeImagenOManifiestoOImagenOArtefacto

DESCRIPCIÓN

Añade o actualiza información sobre una imagen o artefacto incluido en una lista de manifiestos o índice de imágenes.

VALOR DE RETORNO

El ID de la imagen de la lista y el digest del manifiesto de la imagen.

OPCIONES

--annotation anotación=valor

Establece una anotación en la entrada para la imagen o artefacto especificado. Si también se especifica --index, establece la anotación en todo el índice de imágenes.

--arch

Sobrescribe la arquitectura que la lista o el índice registran como requisito para la imagen. Esto se recupera automáticamente de la información de configuración de la imagen, por lo que rara vez es necesario usar esta opción.

--features

Especifica la lista de características que la lista o el índice registran como requisitos para la imagen. Esta opción se usa raramente.

--index

Trata los argumentos de la opción --annotation como valores de anotación que se establecerán en el propio índice de imágenes en lugar de en una entrada del índice de imágenes. Implícito para --subject.

--os

Sobrescribe el sistema operativo (OS) que la lista o el índice registran como requisito para la imagen. Esto se recupera automáticamente de la información de configuración de la imagen, por lo que rara vez es necesario usar esta opción.

--os-features

Especifica la lista de características del sistema operativo (OS) que la lista o el índice registran como requisitos para la imagen. Esta opción se usa raramente.

--os-version

Especifica la versión del sistema operativo (OS) que la lista o el índice registran como requisito para la imagen. Esta opción se usa raramente.

--subject nombreDeImagen

Establece el campo subject en el índice de imágenes para marcar el índice de imágenes como asociado con la imagen especificada de alguna manera. Un índice de imágenes solo puede asociarse con, como máximo, un sujeto.

--variant

Especifica la variante que la lista o el índice registran para la imagen. Esta opción se usa típicamente para distinguir entre múltiples entradas que comparten el mismo valor de arquitectura, pero que esperan diferentes versiones de su conjunto de instrucciones.

EJEMPLO

buildah manifest annotate --arch arm64 --variant v8 mylist:v1.11 sha256:c829b1810d2dbb456e74a695fd3847530c8319e5a95dca623e9f1b1b89020d8b
506d8f4bb54931ea03a7e70173a0ed6302e3fb92dfadb3955ba5c17812e95c51: sha256:c829b1810d2dbb456e74a695fd3847530c8319e5a95dca623e9f1b1b89020d8b
