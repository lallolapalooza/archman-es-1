DESCRIPCIÓ

N

BIO_s_file() devuelve el método BIO de archivo. Como su nombre implica, es un envoltorio alrededor de la estructura FILE de stdio y es un BIO fuente/sumidero

.

Las llamadas a BIO_read_ex() y BIO_write_ex() leen y escriben datos en el flujo subyacente. BIO_gets() y BIO_puts() están soportados en BIOs de

archivo.

BIO_flush() en un BIO de archivo llama a la función fflush() en el flujo

envuelto.

BIO_reset() intenta cambiar el puntero de archivo al inicio del archivo usando fseek(stream, 0, 0)

.

BIO_seek() establece el puntero de archivo en la posición ofs desde el inicio del archivo usando fseek(stream, ofs, 0)

.

BIO_eof() llama a feof(

).

Establecer la bandera BIO_CLOSE llama a fclose() en el flujo cuando el BIO es

liberado.

BIO_new_file() crea un nuevo BIO de archivo con el modo mode; el significado de mode es el mismo que el de la función stdio fopen(). La bandera BIO_CLOSE está establecida en el BIO

devuelto.

BIO_new_fp() crea un BIO de archivo que envuelve stream. Las banderas pueden ser: BIO_CLOSE, BIO_NOCLOSE (la bandera de cierre), BIO_FP_TEXT (establece el flujo subyacente en modo texto, el modo predeterminado es binario: esto solo tiene algún efecto bajo Win32)

.

BIO_set_fp() establece el fp de un BIO de archivo a fp. flags tiene el mismo significado que en BIO_new_fp(), es una

macro.

BIO_get_fp() recupera el fp de un BIO de archivo, es una

macro.

BIO_seek() es una macro que establece el puntero de posición a offset bytes desde el inicio del

archivo.

BIO_tell() devuelve el valor del puntero de

posición.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename() y BIO_rw_filename() establecen el BIO de archivo b para usar el archivo name para lectura, escritura, añadido o lectura-escritura

respectivamente
.

NOTA

S

Al envolver stdout, stdin o stderr, el flujo subyacente normalmente no debe ser cerrado, por lo que se debe establecer la bandera

BIO_NOCLOSE.

Debido a que el BIO de archivo llama a las funciones stdio subyacentes, cualquier peculiaridad en el comportamiento de stdio será reflejada por el BIO correspondiente

.

En Windows, BIO_new_file() espera que el argumento filename esté co

dificado en UTF-8. En otras palabras, si tiene que hacerlo funcionar en
un entorno multilingüe, codifique los nombres de archivo en UTF-8.

VALORES

DEVUELTOS

BIO_s_file() devuelve el método BIO de

archivo.

BIO_new_file() y BIO_new_fp() devuelven un BIO de archivo o NULL si ocurrió un

error.

BIO_set_fp() y BIO_get_fp() devuelven 1 para éxito o <=0 para fallo (aunque la implementación actual nunca devuelve 0)

.

BIO_seek() devuelve 0 para éxito o valores negativos para

fallo.

BIO_tell() devuelve la posición actual del archivo o valores negativos para

fallo.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename() y BIO_rw_filename() devuelven 1 para éxito o <=0 para fall

o. También se devuelve un erro
r si el archivo no existe.

ERRORE

S

BIO_reset() y BIO_seek() están implementados usando fseek() en el flujo subyacente. El valor devuelto para fseek() es 0 para éxito o -1 si ocurrió un error; esto difiere de otros tipos de B

IO que típicamente devuelven 1 para éxito y
un valor no positivo si ocurrió un error.
