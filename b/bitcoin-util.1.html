BITCOIN-UTIL(1) Comandos de usuario BITCOIN-UTIL(1)

NOMBRE

bitcoin-util - página del manual para bitcoin-util v28.1.0

SINOPSIS

bitcoin-util [opciones] [comandos] hacer cosas

DESCRIPCIÓN

Utilidad bitcoin-util de Bitcoin Core versión v28.1.0

OPCIONES

-?

Imprimir este mensaje de ayuda y salir

-version

Imprimir versión y salir

Opciones de depuración/pruebas:

Opciones de selección de cadena:

-chain=<cadena>

Usar la cadena <cadena> (predeterminada: main). Valores permitidos: main, test, testnet4, signet, regtest

-signet

Usar la cadena signet. Equivalente a -chain=signet. Nota que la red se define mediante el parámetro -signetchallenge

-signetchallenge

Los bloques deben satisfacer el script dado para ser considerados válidos (solo para redes signet; utiliza por defecto el desafío global de la red de prueba signet por defecto)

-signetseednode

Especificar un nodo semilla para la red signet, en formato hostname[:port], por ejemplo sig.net:1234 (se puede usar varias veces para especificar varios nodos semilla; utiliza por defecto los nodos semilla de la red de prueba signet global por defecto)

-testnet

Usar la cadena testnet3. Equivalente a -chain=test. El soporte para testnet3 está obsoleto y se eliminará en una próxima versión. Considere pasar ahora a testnet4 usando -testnet4.

-testnet4

Usar la cadena testnet4. Equivalente a -chain=testnet4.

Comandos:

grind
Realizar prueba de trabajo en una cadena de encabezado hexadecimal
