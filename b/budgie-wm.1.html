BUDGIE-WM(1) Comandos de usuario BUDGIE-WM(1)

NOMBRE

budgie-wm - envoltorio alrededor de libmutter que forma la gestión de ventanas para budgie

DESCRIPCIÓN

Uso:

budgie-wm [OPCIÓN?]

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda

Opciones de aplicación:

--sm-disable
Desactivar la conexión al gestor de sesiones
-r, --replace
Reemplazar el gestor de ventanas en ejecución
--sm-client-id=ID
Especificar el ID de gestión de sesiones
-d, --display=PANTALLA
Pantalla X a utilizar
--sm-save-file=ARCHIVO
Inicializar la sesión desde el archivo de guardado
--sync
Hacer que las llamadas X sean síncronas
--wayland
Ejecutar como un compositor de Wayland
--nested
Ejecutar como un compositor anidado
--no-x11
Ejecutar el compositor de Wayland sin iniciar Xwayland
--wayland-display
Especificar el nombre de pantalla de Wayland a utilizar
--display-server
Ejecutar como un servidor de pantalla completo, en lugar de anidado
--headless
Ejecutar como un servidor de pantalla sin cabeza
--virtual-monitor
Añadir monitor virtual persistente (AxA o AxA@R)
--x11
Ejecutar con backend X11
