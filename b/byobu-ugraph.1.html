NOMBRE

byobu-ugraph - script auxiliar para gráficos del historial de notificaciones

DESCRIPCIÓN

byobu-ugraph es un script auxiliar que se puede usar para crear gráficos del historial

USO

byobu-ugraph [opciones] [comando [argumentos...]]

OPCIONES


-f <archivo> : Archivo del cual leer los puntos de datos. (solo se requiere si no se especifica un comando).
-h : Mostrar esta ayuda.
-m <num> : Valor mínimo (predeterminado=$min_default).
-n : Suprimir la salida del carácter de nueva línea.
-p <puntos> : Especificar el número de puntos de datos en el gráfico (predeterminado=$points_default).
-r : No rotar el archivo <archivo> (el valor predeterminado es rotar). La opción implica que el archivo <archivo> no se escribirá, por lo que un comando no puede seguir a las opciones del script en este caso.
-t <tema> : Tema 'byobu-ulevel' a utilizar (predeterminado=$theme_default).
-x <num> : Valor máximo (predeterminado=$max_default).

EJEMPLOS

Uso de byobu-ugraph para ejecutar un comando, rotar el registro y mostrar el gráfico.

Aquí especificamos un comando para mostrar la memoria disponible. El 'echo' final añade una nueva línea requerida. Nótese que no se especifica nombre de archivo.


byobu-ugraph "(/usr/lib/byobu/mem_used | sed -e 's/% //g';echo)"

Uso de byobu-ugraph solo para rotar el registro y mostrar el gráfico


file=/tmp/load.dat
awk '{ print $1}' /proc/loadavg >> $file
# Nota: necesitamos especificar lo que consideramos una carga máxima "razonable"
byobu-ugraph -m 3.0 -f $file

NOTAS

Si especifica 'comando', se debe tener cuidado con las comillas del shell para evitar la expansión antes de que este script ejecute el comando.

Si no se especifica '-r', el archivo <archivo> se rotará de manera que se retengan como máximo <puntos> líneas en cada invocación de este script.
