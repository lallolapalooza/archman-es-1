NOMBRE

btrfs-restore - intenta restaurar archivos de una imagen de sistema de archivos dañada

SINOPSIS

btrfs restore [opciones] <dispositivo> <ruta> | -l <dispositivo>

DESCRIPCIÓN

btrfs restore se utiliza para intentar salvar archivos de un sistema de archivos dañado y restaurarlos en ruta o simplemente listar los árboles de subvolúmenes. La imagen del sistema de archivos no se modifica.

Si el sistema de archivos está dañado y no puede ser reparado por otras herramientas (btrfs-check(8) <> o btrfs-rescue(8) <>), btrfs restore podría usarse para recuperar datos de archivos, hasta donde la metadatos sean legibles. Las comprobaciones realizadas por restore son menos estrictas y el proceso suele ser capaz de llegar lo suficientemente lejos como para recuperar datos de todo el sistema de archivos. Esto tiene el costo de que algunos datos podrían estar incompletos o ser de versiones anteriores si están disponibles.

Existen varias opciones para intentar la restauración de varios tipos de metadatos de archivos. Puedes intentar una simulación primero para ver qué tan bien va el proceso y usar opciones adicionales para extender el conjunto de metadatos restaurados.

Para imágenes con estructuras de árbol dañadas, hay varias opciones para señalar al proceso alguna copia de repuesto.

OPCIONES

-s|--snapshots
obtener también instantáneas que se omiten por defecto
-x|--xattr
obtener atributos extendidos
-m|--metadata
restaurar propietario, permisos y tiempos para archivos y directorios
-S|--symlinks
restaurar enlaces simbólicos además de archivos normales
-i|--ignore-errors
ignorar errores durante la restauración y continuar
-o|--overwrite
sobrescribir directorios/archivos en ruta, por ejemplo para ejecuciones repetidas
-t <bytenr>
usar bytenr para leer el árbol raíz
-f <bytenr>
restaurar solo archivos que están bajo la raíz de subvolumen especificada apuntada por bytenr
-u|--super <mirror>
usar el espejo de superbloque dado identificado por <mirror>, puede ser 0, 1 o 2
-r|--root <rootid>
restaurar solo archivos que están bajo un subvolumen especificado cuyo objectid es rootid
-d
encontrar directorio
-l|--list-roots
listar raíces de subvolúmenes, puede usarse como argumento para -r
-D|--dry-run
simulación (solo listar archivos que se recuperarían)
--path-regex <regex>
restaurar solo nombres de archivo que coincidan con una expresión regular (regex(7) https://man7.org/linux/man-pages/man7/regex.7.html) con un formato obligatorio

^/(|home(|/username(|/Desktop(|/.*))))$

El formato no es muy cómodo y restaura todos los archivos en los directorios en la ruta completa, por lo que no es útil para restaurar un solo archivo en una jerarquía profunda.

-c
ignorar mayúsculas/minúsculas (solo --path-regex)
-v|--verbose
(obsoleto) alias para la opción global -v

Opciones globales

-v|--verbose
ser verboso e imprimir lo que se está restaurando

ESTADO DE SALIDA

btrfs restore devuelve un estado de salida cero si tiene éxito. Se devuelve un valor distinto de cero en caso de fallo.

DISPONIBILIDAD

btrfs es parte de btrfs-progs. Consulte la documentación en https://btrfs.readthedocs.io.

VER TAMBIÉN

btrfs-check(8) <>, btrfs-rescue(8) <>, mkfs.btrfs(8) <>
