BN_num_bytes(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_NUM_BYTES(3ssl) OpenSSL BN_NUM_BYTES(3ssl)

NOMBRE

BN_num_bits, BN_num_bytes, BN_num_bits_word - obtener el tamaño de BIGNUM

SINOPSIS

#include <openssl/bn.h>
int BN_num_bytes(const BIGNUM *a);
int BN_num_bits(const BIGNUM *a);
int BN_num_bits_word(BN_ULONG w);

DESCRIPCIÓN

BN_num_bytes() devuelve el tamaño de un BIGNUM en bytes.

BN_num_bits_word() devuelve el número de bits significativos en una palabra. Si tomamos 0x00000432 como ejemplo, devuelve 11, no 16, ni 32. Básicamente, excepto para un cero, devuelve floor(log2(w))+1.

BN_num_bits() devuelve el número de bits significativos en un BIGNUM, siguiendo el mismo principio que BN_num_bits_word().

BN_num_bytes() es una macro.

VALORES DE RETORNO

El tamaño.

NOTAS

Algunos han intentado usar BN_num_bits() en números individuales de claves RSA, claves DH y claves DSA, y descubrieron que no siempre arrojan el número de bits esperado (algo como 512, 1024, 2048, ...). Esto se debe a que generar un número con un número específico de bits no siempre establece los bits más altos, lo que hace que el número de bits *significativos* sea un poco menor. Si desea conocer el "tamaño de la clave" de dicha clave, use funciones como RSA_size(), DH_size() y DSA_size(), o use BN_num_bytes() y multiplique por 8 (aunque no hay garantía real de que coincida con el "tamaño de la clave", solo una probabilidad mucho mayor).

VER TAMBIÉN

DH_size(3), DSA_size(3), RSA_size(3)
