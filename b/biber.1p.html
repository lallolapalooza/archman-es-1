NOMBRE

"biber" — Un reemplazo de bibtex para usuarios de biblatex

SINOPSIS

biber [opciones] archivo[.bcf]
biber [opciones] --tool <fuente_datos>
Crea "archivo.bbl" usando el archivo de control "archivo.bcf" (la extensión
".bcf" es opcional). Normalmente, el uso con biblatex no requiere opciones, ya
que todas están establecidas en biblatex y se pasan a través del archivo
".bcf".
En modo "herramienta" (ver opción B<--tool>), toma una fuente de datos
(por defecto la fuente de datos "bibtex") y genera una copia de la fuente
de datos con las opciones aplicadas de la línea de comandos o del archivo de
configuración.
Por favor, ejecuta "biber --help" para ver los detalles de las opciones.

DESCRIPCIÓN

"biber" proporciona un reemplazo para el procesador bibtex para usuarios de biblatex.

OPCIONES

--annotation-marker=[marcador]
Establece el sufijo que se puede añadir al nombre de un campo de fuente de datos BibTeX para indicar que el valor del campo es una anotación de datos. El valor por defecto es "+an".
--cache
Si se ejecuta como un binario PAR::Packer, muestra la ubicación de la caché y sale.
--clrmacros
Borra cualquier macro BibTeX (@STRING) entre refsections de BibLaTeX. Esto evita advertencias de BibTeX sobre redefiniciones de macros si estás utilizando la misma fuente de datos varias veces para diferentes refsections.
--collate-options|-c [opciones]
Opciones para pasar al objeto "Unicode::Collate" utilizado para la ordenación (el valor por defecto es "--collate-options level=4 --collate-options variable='non-ignorable'"). Consulta "perldoc Unicode::Collate" para más detalles.
--configfile|-g [archivo]
Utiliza archivo como archivo de configuración para "biber" en lugar de buscar en las ubicaciones por defecto que son, en orden:

* "biber.conf" o ".biber.conf" en el directorio actual

* "$HOME/.biber.conf"

* "$XDG_CONFIG_HOME/biber/biber.conf"

* "$HOME/.config/biber/biber.conf"

* "$HOME/Library/biber/biber.conf" (solo en Mac OS X)

* "$APPDATA/biber.conf" (solo en Windows)

* El resultado de "kpsewhich biber.conf" (si está disponible en el sistema).

En modo herramienta (--tool), se utiliza siempre biber-tool.conf instalado con Biber para establecer las opciones por defecto si no se especifica un archivo de configuración definido por el usuario. Utiliza la opción --tool-config para ver la ubicación del archivo de configuración por defecto del modo herramienta, lo cual puede ser útil como fuente para escribir el tuyo propio.

--convert-control
Convierte el archivo de control .bcf a html utilizando una transformación XSLT. Puede ser útil para depuración. El archivo se nombra añadiendo ".html" al archivo .bcf.
--decodecharsset=[nombre del juego de recodificación]
El conjunto de caracteres incluidos en la rutina de conversión al decodificar macros LaTeX a UTF-8 (lo que ocurre cuando --bblencoding|-E está configurado como UTF-8). Establecer a "full" para intentar con un conjunto mucho mayor o "base" para usar un conjunto básico más pequeño. El valor por defecto es "base". Puede que desees probar "full" si tienes caracteres UTF-8 menos comunes en tu fuente de datos. Los conjuntos de recodificación se definen en el archivo de datos de re-codificación, que puede ser personalizado. Consulta la opción --recodedata y el manual en PDF. El nombre de conjunto virtual "null" puede ser especificado, lo que efectivamente desactiva la decodificación de macros.
--debug|-D
Activa la depuración para "biber".
--dieondatamodel
Sale inmediatamente con un error si se utiliza "--validate-datamodel" y se encuentra un error de validación del modelo de datos. El valor por defecto es advertir y continuar.
--dot-include=seccion,campo,xdata,crossref,xref,relacionado
Especifica el elemento a incluir en el formato de salida DOT de GraphViz si el formato de salida es 'dot'. También puedes elegir mostrar conexiones de referencia cruzada, xref, xdata y/o entradas relacionadas. El valor por defecto si no se especifica es "--dot-include=seccion,xdata,crossref,xref".
--fixinits
Intenta arreglar iniciales múltiples rotas cuando no hay espacio entre ellas en las fuentes de datos BibTeX. Es decir, "A.B. Clarke" se convierte en "A. B. Clarke" antes de analizar el nombre. Esto puede estropear ligeramente cosas como "{U.K. Government}" y otros casos esotéricos.
--help|-h
Muestra este mensaje de ayuda.
--input-directory [directorio]
Los archivos .bcf y de datos se buscarán primero en el directorio. Consulta la documentación PDF de biber para otras posibilidades y cómo interactúa esto con la opción "--output-directory".
--input-encoding|-e [codificación]
Especifica la codificación del(los) archivo(s) fuente de datos. El valor por defecto es "UTF-8". Normalmente no es necesario establecer esto, ya que se pasa a través del archivo .bcf desde la opción "bibencoding" de biblatex. Consulta "perldoc Encode::Supported" para una lista de codificaciones soportadas. La opción heredada --bibencoding se soporta como un alias.
--input-format=bibtex|biblatexml
Formato de entrada de Biber. Esta opción solo tiene sentido en modo herramienta (ver opción tool), ya que normalmente el formato de entrada de una fuente de datos se especifica en el archivo .bcf y, por lo tanto, desde la macro \addbibresouce en BibLaTeX. El valor por defecto cuando está en modo herramienta es 'bibtex'.
--isbn10
Fuerza todas las ISBN a versiones de 10 dígitos en la salida. Esto convertirá la ISBN internamente a un objeto ISBN que no tendrá guiones en la salida. Si utilizas esta opción y quieres una ISBN con guiones en el lugar correcto en la salida, utiliza la opción --isbn-normalise.
--isbn13
Fuerza todas las ISBN a versiones de 13 dígitos en la salida. Esto convertirá la ISBN internamente a un objeto ISBN que no tendrá guiones en la salida. Si utilizas esta opción y quieres una ISBN con guiones en el lugar correcto en la salida, utiliza la opción --isbn-normalise.
--isbn-normalise
Normaliza las ISBN con guiones en los lugares correctos en la salida.
--logfile [archivo]
Utiliza archivo.blg como nombre del archivo de log.
--listsep=[sep]
Utiliza sep como separador para los campos de lista de fuentes de datos BibTeX. El valor por defecto es el habitual 'and' de BibTeX.
--mincrossrefs|-m [número]
Establece el umbral para las referencias cruzadas.
--named-annotation-marker=[marcador]
Establece el separador entre el "--annotation-marker" y el nombre de una anotación con nombre. El valor por defecto es ":".
--namesep=[sep]
Utiliza sep como separador para los campos de nombres de fuentes de datos BibTeX. El valor por defecto es el habitual 'and' de BibTeX.
--no-bblxml-schema
Al escribir la salida bblxml, no genera un esquema XML RNG a partir del modelo de datos.
