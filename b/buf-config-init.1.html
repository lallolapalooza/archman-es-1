NOMBRE

buf-config-init - Inicializa archivos de configuración de buf para tu desarrollo local

SINOPSIS

buf config init [buf.build/owner/foobar] [flags]

DESCRIPCIÓN

Este comando escribirá un archivo buf.yaml nuevo para iniciar tu desarrollo local.

Si ya existe un buf.yaml, este comando no lo sobrescribirá y generará un error.

Los efectos de este comando pueden cambiar con el tiempo; este comando podría inicializar, por ejemplo, archivos buf.gen.yaml en el futuro.

OPCIONES

-h, --help[=false] Ayuda para init

-o, --output="." El directorio donde escribir los archivos de configuración

OPCIONES HEREDADAS DE COMANDOS PADRE

--debug[=false] Activar el registro de depuración

--log-format="color" El formato del registro [text,color,json]

--timeout=0s La duración hasta el tiempo de espera, establecerlo en 0 significa sin tiempo de espera
