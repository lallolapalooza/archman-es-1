BUNDLE-ADD(1) Manual de comandos generales BUNDLE-ADD(1)

NOMBRE

bundle-add - Añadir gem a Gemfile y ejecutar bundle install

SINOPSIS

bundle add NOMBRE_GEM [--group=GRUPO] [--version=VERSIÓN] [--source=FUENTE] [--path=RUTA] [--git=GIT|--github=GITHUB] [--branch=RAMA] [--ref=REF] [--quiet] [--skip-install] [--strict|--optimistic]

DESCRIPCIÓN

Añade la gema nombrada al [Gemfile(5)][Gemfile(5)] y ejecuta bundle install. Se puede evitar bundle install utilizando la opción --skip-install.

OPCIONES

--version=VERSIÓN, -v=VERSIÓN
Especifica los requisitos de versión para la gema añadida.
--group=GRUPO, -g=GRUPO
Especifica el grupo (o grupos) para la gema añadida. Los grupos múltiples deben estar separados por comas.
--source=FUENTE, -s=FUENTE
Especifica la fuente para la gema añadida.
--require=REQUERIR, -r=REQUERIR
Añade la ruta de requerimiento a la gema. Proporciona `false` o una ruta como cadena.
--path=RUTA
Especifica la ruta en el sistema de archivos para la gema añadida.
--git=GIT
Especifica la fuente git para la gema añadida.
--github=GITHUB
Especifica la fuente de GitHub para la gema añadida.
--branch=RAMA
Especifica la rama git para la gema añadida.
--ref=REF
Especifica la referencia git (ref) para la gema añadida.
--glob=GLOB
Especifica la ubicación del archivo .gemspec de una dependencia, expandido dentro de Ruby (se recomiendan comillas simples).
--quiet
No imprimir información de progreso a la salida estándar.
--skip-install
Añade la gema a Gemfile pero no la instala.
--optimistic
Añade una declaración optimista de la versión.
--strict
Añade una declaración estricta de la versión.

EJEMPLOS

1.
Puedes añadir la gema rails a Gemfile sin ninguna restricción de versión. La fuente de la gema será la fuente global.
bundle add rails
2.
Puedes añadir la gema rails con la versión mayor que 1.1 (sin incluir 1.1) y menor que 3.0.
bundle add rails --version "> 1.1, < 3.0"
3.
Puedes usar la fuente personalizada https://gems.example.com y asignar la gema a un grupo.
bundle add rails --version "~> 5.0.0" --source "https://gems.example.com" --group "development"
4.
Lo siguiente añade la entrada de gema a Gemfile sin instalar la gema. Puedes instalar las gemas más tarde mediante bundle install.
bundle add rails --skip-install
5.
Puedes asignar la gema a más de un grupo.
bundle add rails --group "development, test"
