type current_phase =
| Parser
|

Invariant_check

register_attr debe llamarse en las ubicaciones de todos los atributos que deben ser rastreados con el propósito de las advertencias de atributos mal ubicados. En particular, debe llamarse en todos los atributos que están presentes en el programa fuente, excepto aquellos que están contenidos en la carga útil de otro atributo (porque estos pueden ser dejados atrás por un ppx e ignorados intencionalmente por el compilador)

.

El argumento current_phase indica cuándo se está llamando a esta

función

-ya sea cuando un atributo se crea en el analizador o cuando vemos un atributo mientras ejecutamos la comprobación en el módulo Ast_invariants. Esto se usa para asegurar que solo rastreamos atributos de la versión final del árbol de análisis: omitimos agregar atributos vistos en tiempo de análisis si podemos ver que un ppx se ejecutará más tarde, porque la comprobación de Ast_invariants siempre se ejecuta en el resultado de un

ppx.

Tenga en cuenta que la comprobación de Ast_invariants también se ejecuta en árboles de análisis creados desde archivos ast marshalled si no se está usando ningún ppx, asegurando que no perdamos atributos en ese

caso.

Ayudas de la advertencia 53 para atributos de

entorno

Algunos atributos, como los marcadores de obsolescencia, no afectan la compilación de la definición en la que aparecen, sino que resultan en advertencias en usos futuros de esa definición. Esto se implementa moviendo los atributos crudos al entorno, donde serán notados en accesos

futuros.

Para hacer que las advertencias de atributos mal ubicados funcionen apropiadamente para estos atributos, los marcamos como "usados" cuando se mueven al entorno. Esto se hace con las funciones auxiliares en esta

sección.

val mark_alert_used : Parsetree.attribute ->

unit

Marca el atributo como usado con el propósito de las advertencias de atributos mal ubicados si es una alerta. Llame a esto cuando mueva cosas que pueden tener atributos de alerta al

entorno.

unit

unit

Marca los atributos "warn_on_literal_pattern" como usados con el propósito de las advertencias de atributos mal ubicados. Llame a esto cuando mueva constructores al

entorno.

val mark_deprecated_mutable_used : Parsetree.attributes ->

unit

Marca los atributos "deprecated_mutable" como usados con el

propósito de las advertencias de atributos mal ubicados. Llame
a esto cuando mueva etiquetas de campos mutables al entorno.

val warning_attribute : ?ppwarning:bool -> Parsetree.attribute ->

unit

Aplica la configuración de advertencias del atributo especificado. "ocaml.warning"/"ocaml.warnerror" (y las variantes sin el prefijo) se procesan y se marcan como usados para la advertencia 53. Otros atributos se

ignoran.

También implementa ocaml.ppwarning (a menos que se pase ~ppwarning:false)

.

val warning_scope : ?ppwarning:bool -> Parsetree.attributes -> (unit -> 'a) ->

'a

Ejecuta una función en un nuevo ámbito para la configuración de advertencias. Esto significa que el efecto de cualquier llamada a warning_attribute durante la ejecución de esta función se descartará después de la

ejecución.

La función también toma una lista de atributos que se procesan con warning_attribute en el ámbito nuevo a

ntes de que la func
ión se ejecute.

val has_attribute : string -> Parsetree.attributes ->

bool

has_attribute name attrs es verdadero si un atributo con el nombre name o "ocaml." ^ name está presente en attrs . Marca ese atributo como usado con el propósito de las advertencias de atributos mal

ubicados.

type attr_action =
| Mark_used_only
|

Return

select_attributes actions attrs encuentra los elementos de attrs que aparecen en actions y ya sea los devuelve o solo los marca como usados, de acuerdo con el attr_action corresp

ondiente.

Cada elemento (nm, action) de la lista actions es un atributo junto con un attr_action que especifica qué hacer con ese atributo. La acción se usa para acomodar diferentes configuraciones del compilador. Si un atributo se usa solo en algunas configuraciones del compilador, es importante que aún lo busquemos y lo marquemos como usado cuando compilamos con otras configuraciones. De lo contrario, emitiríamos advertencias espurias de atributos mal

ubicados.

val select_attributes : (string * attr_action) list -> Parsetree.attributes -> Parsetree.

attributes

val attr_equals_builtin : Parsetree.attribute -> string ->

bool

attr_equals_builtin attr s es verdadero si el nombre del atributo es s o "ocaml." ^ s . Esto es útil para inspeccionar manualmente los nombres de los atributos, pero tenga en cuenta que hacerlo no resultará en marcar el atributo como usado con el propósito de la advertencia 53, por lo que generalmente es preferpreferible usar has_attribute o select_attributes
