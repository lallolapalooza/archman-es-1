BIO_get_rpoll_descriptor(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BIO_GET_RPOLL_DESCRIPTOR(3ssl) OpenSSL BIO_GET_RPOLL_DESCRIPTOR(3ssl)

NOMBRE

BIO_get_rpoll_descriptor, BIO_get_wpoll_descriptor - obtener una estructura que puede usarse para determinar cuándo un objeto BIO puede ser leído o escrito a continuación

SINOPISIS

#include <openssl/bio.h>
typedef struct bio_poll_descriptor_st {
    uint32_t type;
    union {
        int        fd;
        void       *custom;
        uintptr_t  custom_ui;
    } value;
} BIO_POLL_DESCRIPTOR;
int BIO_get_rpoll_descriptor(BIO *b, BIO_POLL_DESCRIPTOR *desc);
int BIO_get_wpoll_descriptor(BIO *b, BIO_POLL_DESCRIPTOR *desc);

DESCRIPCIÓN

BIO_get_rpoll_descriptor() y BIO_get_wpoll_descriptor(), en caso de éxito, rellenan *desc con un descriptor de sondeo. Un descriptor de sondeo es una estructura de unión etiquetada que representa algún tipo de recurso del sistema operativo o no del sistema operativo que puede usarse para sincronizar eventos de disponibilidad de E/S.

BIO_get_rpoll_descriptor() genera un descriptor que puede usarse para determinar cuándo el BIO puede (potencialmente) leerse a continuación, y BIO_get_wpoll_descriptor() genera un descriptor que puede usarse para determinar cuándo el BIO puede (potencialmente) escribirse a continuación.

Está permitido que BIO_get_rpoll_descriptor() y BIO_get_wpoll_descriptor() generen el mismo descriptor.

Los descriptores de sondeo pueden representar diferentes tipos de información. Un tipo típico de recurso que podría ser representado por un descriptor de sondeo es un descriptor de archivo del sistema operativo que puede usarse con APIs como select().

Los tipos de descriptor de sondeo definidos por OpenSSL son:

BIO_POLL_DESCRIPTOR_TYPE_NONE
Representa la ausencia de un descriptor de sondeo válido. Puede ser usado por BIO_get_rpoll_descriptor() o BIO_get_wpoll_descriptor() para indicar que el BIO no es sondeable para lectura o escritura respectivamente.

Para este tipo, ningún campo dentro del campo value de BIO_POLL_DESCRIPTOR es válido.

BIO_POLL_DESCRIPTOR_TYPE_SOCK_FD
El descriptor de sondeo representa un recurso de socket del sistema operativo. El campo value.fd en BIO_POLL_DESCRIPTOR es válido si no está establecido a -1.

El recurso es el tipo de manejador que usa un sistema operativo dado para representar sockets, lo cual puede variar según el sistema operativo. Por ejemplo, en Windows, el valor es un SOCKET para usar con la API de Winsock. En plataformas similares a POSIX, es un descriptor de archivo.

Donde un descriptor de sondeo de este tipo es generado por BIO_get_rpoll_descriptor(), debe ser sondeado para lectura para determinar cuándo el BIO podría completar exitosamente una operación BIO_read(); de manera similar, donde un descriptor de sondeo de este tipo es generado por BIO_get_wpoll_descriptor(), debe ser sondeado para escritura para determinar cuándo el BIO podría completar exitosamente una operación BIO_write().

BIO_POLL_DESCRIPTOR_CUSTOM_START
Los valores de tipo que comienzan con este valor (inclusive) están reservados para la asignación de aplicaciones para tipos de descriptores de sondeo personalizados. Cualquiera de las definiciones en el campo de unión value puede ser usada por la aplicación arbitrariamente como valores opacos.

Dado que los descriptores de sondeo son una estructura de unión etiquetada, pueden representar diferentes tipos de información. Pueden definirse nuevos tipos de descriptores de sondeo, incluso por aplicaciones, según sus necesidades.

VALORES DE RETORNO

Las funciones BIO_get_rpoll_descriptor() y BIO_get_wpoll_descriptor() devuelven 1 en caso de éxito y 0 en caso de error.

Se permite que estas funciones tengan éxito e inicialicen *desc con un descriptor de sondeo de tipo BIO_POLL_DESCRIPTOR_TYPE_NONE para indicar que el BIO no es sondeable para lectura o escritura respectivamente.

HISTORIA
