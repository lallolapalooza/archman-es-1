brk(2) Manual de llamadas al sistema brk(2)

NOMBRE

brk, sbrk - cambiar el tamaño del segmento de datos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int brk(void *addr);
void *sbrk(intptr_t increment);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

brk(), sbrk():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
            || ((_XOPEN_SOURCE >= 500) &&
                ! (_POSIX_C_SOURCE >= 200112L))
    De glibc 2.12 a glibc 2.19:
        _BSD_SOURCE || _SVID_SOURCE
            || ((_XOPEN_SOURCE >= 500) &&
                ! (_POSIX_C_SOURCE >= 200112L))
    Antes de glibc 2.12:
        _BSD_SOURCE || _SVID_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

brk() y sbrk() cambian la ubicación del punto de interrupción del programa, que define el final del segmento de datos del proceso (es decir, el punto de interrupción del programa es la primera ubicación después del final del segmento de datos no inicializados). Aumentar el punto de interrupción del programa tiene el efecto de asignar memoria al proceso; disminuir el punto de interrupción libera memoria.

brk() establece el final del segmento de datos al valor especificado por addr, cuando dicho valor es razonable, el sistema tiene suficiente memoria y el proceso no excede su tamaño máximo de datos (ver setrlimit(2)).

sbrk() incrementa el espacio de datos del programa en incremento bytes. Llamar a sbrk() con un incremento de 0 puede usarse para encontrar la ubicación actual del punto de interrupción del programa.

VALOR DE RETORNO

En caso de éxito, brk() devuelve cero. En caso de error, devuelve -1 y se establece errno a ENOMEM.

En caso de éxito, sbrk() devuelve el punto de interrupción anterior del programa. (Si el punto de interrupción aumentó, este valor es un puntero al inicio de la memoria recién asignada). En caso de error, devuelve (void *) -1 y se establece errno a ENOMEM.

ESTÁNDARES

Ninguno.

HISTORIA

4.3BSD; SUSv1, marcado como LEGACY en SUSv2, eliminado en POSIX.1-2001.

NOTAS

Evite usar brk() y sbrk(): el paquete de asignación de memoria malloc(3) es la forma portátil y cómoda de asignar memoria.

Varios sistemas utilizan diferentes tipos para el argumento de sbrk(). Comunes son int, ssize_t, ptrdiff_t, intptr_t.

diferencias biblioteca C/kernel

El valor de retorno descrito anteriormente para brk() es el comportamiento proporcionado por la función de envoltura glibc para la llamada al sistema brk() de Linux. (En la mayoría de las otras implementaciones, el valor de retorno de brk() es el mismo; este valor de retorno también se especificó en SUSv2). Sin embargo, la llamada al sistema Linux real devuelve el nuevo punto de interrupción del programa en caso de éxito. En caso de error, la llamada al sistema devuelve el punto de interrupción actual. La función de envoltura glibc realiza algo de trabajo (es decir, comprueba si el nuevo punto de interrupción es menor que addr) para proporcionar los valores de retorno 0 y -1 descritos anteriormente.

En Linux, sbrk() se implementa como una función de biblioteca que utiliza la llamada al sistema brk(), y realiza algo de contabilidad interna para poder devolver el valor del punto de interrupción anterior.

VER TAMBIÉN

execve(2), getrlimit(2), end(3), malloc(3)
