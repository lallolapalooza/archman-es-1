NOMBRE

bup random - genera un flujo de salida aleatoria

SINOPSIS

bup random [-S semilla] [-fv] <numbytes>

DESCRIPCIÓN

bup random produce un flujo de bytes de salida pseudoraleatoria a stdout. Nota: los bytes *no* se generan utilizando un algoritmo criptográfico y nunca deben usarse para seguridad.

Tenga en cuenta que el flujo de bytes aleatorios será idéntico cada vez que se ejecute bup random, a menos que proporcione un valor de semilla diferente. Esto es intencional: el propósito de este programa es poder ejecutar pruebas repetibles en grandes cantidades de datos, por lo que queremos datos idénticos cada vez.

bup random genera aproximadamente 240 megabytes por segundo en un sistema de prueba moderno (Intel Core2), lo que es más rápido de lo que podría lograr leyendo datos de la mayoría de los discos. Por lo tanto, puede ser útil al ejecutar microbenchmarks.

OPCIONES

<numbytes>
el número de bytes de datos a generar. Se puede usar con los sufijos k, M o G para indicar kilobytes, megabytes o gigabytes, respectivamente.
-S, --seed=semilla
usa el valor dado para sembrar el generador de números pseudorandom. El flujo de salida generado será idéntico para cada flujo sembrado con el mismo valor. La semilla predeterminada es 1. Un valor de semilla de 0 es equivalente a 1.
-f, --force
genera salida incluso si stdout es una tty. (Generar datos aleatorios a una tty generalmente se considera desaconsejable, pero puedes hacerlo si realmente quieres).
-v, --verbose
muestra un mensaje de progreso que indica el número de bytes que se han enviado hasta el momento.

EJEMPLOS

$ bup random 1k | sha1sum
2108c55d0a2687c8dacf9192677c58437a55db71  -
$ bup random -S1 1k | sha1sum
2108c55d0a2687c8dacf9192677c58437a55db71  -
$ bup random -S2 1k | sha1sum
f71acb90e135d98dad7efc136e8d2cc30573e71a  -
$ time bup random 1G >/dev/null
Random: 1024 Mbytes, done.
real   0m4.261s
user   0m4.048s
sys    0m0.172s
$ bup random 1G | bup split -t --bench
Random: 1024 Mbytes, done.
bup: 1048576.00kbytes in 18.59 secs = 56417.78 kbytes/sec
1092599b9c7b2909652ef1e6edac0796bfbfc573
