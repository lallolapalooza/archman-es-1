bibdoiadd(1) UTILIDADES DE REFERENCIAS CRUZADAS DE LATEX bibdoiadd(1)

NOMBRE

bibdoiadd.pl - añade números DOI a artículos en un archivo bib dado

SINOPSIS

bibdoiadd [-c archivo_config] [-C 1|0] [-e 1|0] [-f] [-o salida] archivo_bib

OPCIONES

-c archivo_config
Archivo de configuración. Si este archivo no está presente, se usan algunos valores predeterminados. Ver más abajo para su formato.
-C 1|0
Si canonizar los nombres en la salida (1) o no (0). Por defecto, 1.
-e
Si es 1 (por defecto), añadir doi vacío si no se puede encontrar un doi. Esto evita búsquedas repetidas para las mismas entradas si añades nuevas entradas al archivo. Llamar "-e 0" suprime este comportamiento.
-f
Forzar la comprobación del número DOI incluso si ya hay uno presente.
-o salida
Archivo de salida. Si no se usa esta opción, el nombre del archivo de salida se forma añadiendo "_doi" al archivo de entrada.

DESCRIPCIÓN

El script lee un archivo BibTeX. Comprueba si las entradas tienen DOIs. Si no, intenta contactar http://www.crossref.org para obtener el DOI correspondiente. El resultado es un archivo BibTeX con los campos "doi=..." añadidos.

El nombre del archivo de salida se establece mediante la opción -o o se deriva añadiendo el sufijo "_doi" al archivo de salida.

Cada registro BibTeX en la entrada se analiza, utilizando BibTeX::Parser, pero solo se procesan aquellos que no tienen el campo "doi" (o "mrnumber" o "zblnumber" para los scripts hermanos). Estas entradas sin el campo solicitado se vuelven a escribir, como se describe en BibTeX::Parser::Entry.

Los registros bib que no se procesan (porque ya tienen el campo solicitado) se vuelven a escribir tal cual, sin ninguna reformateo.

Había (¿hay?) dos opciones para realizar consultas con Crossref: cuenta gratuita y membresía de pago. En el primer caso, aún debes registrarte en Crossref y estás limitado a un pequeño número de consultas, consulta el acuerdo en "http://www.crossref.org/01company/free_services_agreement.html". En el segundo caso, tienes un nombre de usuario y una contraseña, y puedes usarlos para consultas automáticas. No estoy seguro de si el uso de este script está permitido para los titulares de cuentas gratuitas. En cualquier caso, si deseas añadir DOIs a un gran número de entradas, deberías registrarte como miembro de pago.

ARCHIVO DE CONFIGURACION

El archivo de configuración se refiere a las consultas de Crossref y es mayormente autoexplicativo: tiene comentarios (que comienzan con "#") y asignaciones en la forma

$campo = valor ;

Los parámetros importantes son $modo ('free' o 'paid'), $email (para usuarios gratuitos) y $username & $password para miembros de pago.

EJEMPLOS

bibdoiadd -c bibdoiadd.cfg -o - citations.bib > result.bib
bibdoiadd -c bibdoiadd.cfg -o result.bib citations.bib
