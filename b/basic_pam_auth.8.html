NOMBRE

basic_pam_auth - Ayudante de autenticación básica PAM para Squid

SINOPSIS

basic_pam_auth [-n nombre del servicio TTL ] [-o] [-1]

DESCRIPCIÓN

basic_pam_auth permite a Squid conectarse a casi cualquier base de datos PAM disponible para validar el nombre de usuario y la contraseña de la autenticación HTTP básica.

OPCIONES

-s nombre-del-servicio
Especifica el nombre del servicio PAM que usa Squid, por defecto es squid
-t TTL
Habilita conexiones PAM persistentes donde la conexión a la base de datos PAM se mantiene abierta y se reutiliza para nuevos inicios de sesión. El TTL especifica cuánto tiempo se mantendrá abierta la conexión (en segundos). Por defecto, no se mantienen abiertas las conexiones PAM. Tenga en cuenta que el uso de conexiones PAM persistentes está ligeramente fuera de la especificación PAM y puede no funcionar con todas las configuraciones PAM.
-o
No realizar el grupo de gestión de cuentas PAM (expiración de cuentas, etc.)

CONFIGURACIÓN

El programa necesita un servicio PAM configurado en /etc/pam.conf o /etc/pam.d/squid

El nombre de servicio predeterminado es squid, y el programa utiliza los grupos de gestión auth y account para verificar la contraseña y la validez de las cuentas.

Para obtener detalles sobre cómo configurar servicios PAM, consulte la documentación de PAM para su sistema. Este manual no cubre los detalles de configuración de PAM.

NOTAS

Cuando se usa para autenticarse en bases de datos de contraseñas shadow de UNIX locales, el programa debe ejecutarse como root o no tendrá permisos suficientes para acceder a la base de datos de contraseñas de usuario. Tal uso de este programa no se recomienda, pero si absolutamente lo necesita, haga que el programa sea setuid root

chown root basic_pam_auth
chmod u+s basic_pam_auth

Tenga en cuenta que en tales configuraciones, también se recomienda encarecidamente que el programa se mueva a un directorio donde los usuarios normales no puedan acceder a él, ya que este modo de operación permitirá a cualquier usuario local forzar la contraseña de otros usuarios. Tenga en cuenta también que el programa no ha sido auditado completamente y el autor no puede ser considerado responsable de ningún problema de seguridad debido a dichas instalaciones.
