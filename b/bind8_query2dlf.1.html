NOMBRE

bind8_query2dlf - convertir logs de consultas BIND8 a dlf

SINOPSIS

bind8_query2dlf

DESCRIPCIÓN

Este script convierte cada línea de un log de consultas bind8 a un registro dlf de dns.

BIND genera estos logs cuando algo como

logging {
    channel query_logging {
        file "/var/log/named_querylog"
        versions 3 size 100M;
        print-time yes;                 // marca temporal de las entradas de log              
     };
     category queries {
         query_logging;
     };
};

está en el named.conf de bind. Esto guardará hasta tres archivos de log de un máximo de 100 megabytes en el directorio /var/log.

Estos archivos de log se ven así:

10-Apr-2000 00:01:20.307 XX /10.2.3.4/1.2.3.in-addr.arpa/SOA/IN
10-Apr-2000 00:01:20.308 XX+/10.4.3.2/host.foo.com/A/IN

EJEMPLOS

Para procesar un log como el producido por bind8:

$ bind8_query2dlf < dns-query

bind8_query2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report bind8_query < /var/log/dns-query
