NOMBRE

bup - Programa de copia de seguridad que utiliza sumas de verificación rodantes y formatos de archivo de git

SINOPSIS

bup [opciones_globales...] <comando> [opciones...]

DESCRIPCIÓN

bup es un programa para realizar copias de seguridad de sus archivos utilizando el formato de archivo de git.

A diferencia de git(1) en sí, bup está optimizado para manejar conjuntos de datos enormes, incluidos archivos individuales muy grandes (como imágenes de máquinas virtuales). Sin embargo, una vez creado un conjunto de copias de seguridad, aún se puede acceder a él utilizando herramientas de git.

Los subcomandos se describen en páginas de manual separadas. Por ejemplo, bup-init(1) cubre bup init.

OPCIONES GENERALES

--version
muestra el número de versión de bup. Equivalente a bup version.
-d, --bup-dir=DIRECTORIO_BUP
utiliza el parámetro DIRECTORIO_BUP dado como ubicación del repositorio de bup, en lugar de leerlo de la variable de entorno $BUP_DIR o usar la ubicación predeterminada ~/.bup.

SUBCOMANDOS DE USO COMÚN

bup-fsck(1)
Comprueba si los conjuntos de copias de seguridad están dañados y agrega información de redundancia.
bup-ftp(1)
Navega por los conjuntos de copias de seguridad utilizando un cliente tipo ftp.
bup-fuse(1)
Monta tus conjuntos de copias de seguridad como un sistema de archivos.
bup-help(1)
Muestra ayuda detallada para el comando dado.
bup-index(1)
Crea o muestra el índice de archivos a respaldar.
bup-on(1)
Realiza una copia de seguridad de una máquina remota en la local.
bup-restore(1)
Extrae archivos de un conjunto de copias de seguridad.
bup-save(1)
Guarda archivos en un conjunto de copias de seguridad (nota: ejecuta “bup index” primero).
bup-web(1)
Inicia un servidor web para examinar los conjuntos de copias de seguridad.

SUBCOMANDOS DE USO POCO COMÚN

bup-damage(1)
Destruye datos deliberadamente.
bup-drecurse(1)
Lista recursivamente los archivos en tu sistema de archivos.
bup-init(1)
Inicializa un repositorio de bup.
bup-join(1)
Recupera un archivo respaldado usando bup-split(1).
bup-ls(1)
Examina los archivos en tus conjuntos de copias de seguridad.
bup-margin(1)
Determina qué tan cerca está tu repositorio de bup del apocalipsis.
bup-memtest(1)
Prueba las estadísticas de uso de memoria de bup.
bup-midx(1)
Indexa objetos para acelerar futuras copias de seguridad.
bup-newliner(1)
Asegura que los mensajes de progreso no se superpongan con la salida.
bup-random(1)
Genera un flujo de salida aleatoria.
bup-server(1)
El lado del servidor de la relación cliente-servidor de bup.
bup-split(1)
Divide un solo archivo en su propio conjunto de copias de seguridad.
bup-tick(1)
Espera hasta un segundo.
bup-version(1)
Informa el número de versión de tu copia de bup.

MEDIO AMBIENTE

BUP_ASSUME_GIT_VERSION_IS_FINE
Si se establece en true, yes o 1, asume que la versión de git en la ruta es aceptable.

VER TAMBIÉN

git(1) y el archivo README de la distribución de bup.

El hogar de bup está en http://github.com/bup/bup/.
