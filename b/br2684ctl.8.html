br2684ctl(8) Manual del Administrador del Sistema br2684ctl(8)

NOMBRE

br2684ctl - Demonio de puente RFC1483/2684

SINOPSIS

br2684ctl [ -b ] [[ -c n ] [ -e 0|1 ] [ -p 0|1 ] [ -s sndbuf ] [ -a [itf].vpi.vci ]] ...

PARÁMETROS

-a [itf].vpi.vci
Número de PVC ATM, VPI y VCI. (Requerido)
-b
Pone el proceso en segundo plano.
-c n
Número de interfaz br2684 como 0, 1, ... (Requerido)
-e 0|1
Método de encapsulación: 0=LLC, 1=VC mux (el valor predeterminado es 0 o LLC)
-p 0|1
Método de carga útil: 0=Enrutado, 1=Puenteado (el valor predeterminado es 1 o Puenteado)
-s sndbuf
Tamaño del búfer de envío. El valor predeterminado es 8192.

DESCRIPCIÓN

br2684ctl maneja PDUs puenteados RFC1483/2684. Esto se utiliza con más frecuencia en escenarios ADSL donde *normalmente* el tráfico ethernet de los suscriptores se encapsula en ATM AAL5 (mediante el puenteo de módems ADSL) de acuerdo con RFC2684. El módem ADSL del lado del suscriptor puede ser externo con un conector ethernet o una tarjeta ADSL interna en un PC. RFC1483 ha sido obsoleto por RFC2684.

Por ejemplo, es posible configurar tu sistema Linux para manejar varios PVC ATM con encapsulación de puente-1483 (a veces referida como SNAP). La pila de red de Linux puede proporcionar servicios DHCP, enmascaramiento IP, cortafuegos IP o puentear los fotogramas Ethernet como si tuviera varias interfaces ethernet. De hecho, puede tener varias interfaces ethernet (lógicas), donde ATM se utiliza simplemente como portador.

USO

br2684ctl crea una nueva interfaz de red llamada nas[n] que está vinculada a un PVC ATM específico. Requiere dos argumentos obligatorios: -c, el número de interfaz, y -a, el PVC ATM. Cabe señalar que el orden de los argumentos del comando importa; a -c le debe seguir -a. Puedes crear tantas interfaces como sea necesario de una vez, simplemente haz una línea de comandos larga ;)

Por ejemplo, el siguiente comando creará una interfaz nas0 que utiliza el PVC ATM con VPI=0 y VCI=401. Necesitas configurar la conexión PVC 0.401 manualmente en el conmutador ATM.

% br2684ctl -c 0 -a 0.401

El comando solo creará una nueva interfaz nas0. El siguiente paso es asignar una dirección IP y una máscara de red a la interfaz nas0 usando el comando ifconfig. Usando ifconfig, también puedes asignar una dirección MAC Ethernet a la interfaz nas0, si es necesario.

% ifconfig nas0 192.168.2.1 netmask 255.255.255.0

Los mensajes se registran en la instalación syslog LOCAL2.

ARCHIVOS

/var/run/br2684ctl-<iface>.pid
