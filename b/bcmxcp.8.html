NOMBRE

bcmxcp - Controlador para SAI que soportan el protocolo serie BCM/XCP

SINOPSIS

bcmxcp -h

bcmxcp -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador bcmxcp. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este controlador debería reconocer todos los SAI compatibles con BCM/XCP en serie. Se ha desarrollado y probado en hardware Powerware PW5115 y PW9120.

Si su SAI tiene una conexión USB, también puede consultar la documentación del controlador bcmxcp_usb(8).

ARGUMENTOS ADICIONALES

Este controlador soporta las siguientes configuraciones opcionales en el archivo ups.conf(5).

shutdown_delay=retraso

El número de segundos que el SAI debe esperar entre la recepción del comando de apagado (upsdrvctl shutdown) y el apagado real.

baud_rate=velocidad

Velocidad de comunicación para el SAI. Si se establece en 9600, intenta conectarse al SAI a 9600 bps. Si falla la comunicación, entra en modo de búsqueda de velocidad (baud hunting). Comienza en 1200 y llega hasta 19200. Si tiene éxito, le informará de la velocidad con la que se conectó. Si no se incluye en la configuración, el valor predeterminado es la búsqueda de velocidad.

VALORES PREDETERMINADOS PARA LOS ARGUMENTOS ADICIONALES

•shutdown_delay = 120
•baud_rate = ninguno

COMANDOS INSTANTÁNEOS

Este controlador soporta los siguientes Comandos Instantáneos:

shutdown.return

Apaga la carga y regresa cuando la energía se restablece.

shutdown.stayoff

Apaga la carga y permanece apagado.

test.battery.start

Inicia una prueba de batería.

outlet.n.shutdown.return

Apaga la carga en la toma de corriente n y regresa cuando la energía se restablece. (n es el número de toma de corriente informado por el comando upsc)

LISTA DE TAREAS PENDIENTES

Reportar información de estadísticas del SAI

BCM/XCP soporta el reporte de datos de estadísticas del SAI.

Cambiar configuraciones

Acceder al registro de configuración para cambiar las configuraciones.

ERRORES CONOCIDOS

Ninguno conocido.
