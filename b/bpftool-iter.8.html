NOMBRE

bpftool-iter - herramienta para crear iteradores BPF

SINOPSIS

bpftool [OPCIONES] iter COMANDO

OPCIONES := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

COMANDOS := { pin | help }

COMANDOS ITER

bpftool iter pin OBJ RUTA [map MAPA]
bpftool iter help
OBJ := /un/archivo/de/bpf_iter_target.o
MAPA := { id ID_MAPA | pinned ARCHIVO }

DESCRIPCIÓN

bpftool iter pin OBJ RUTA [map MAPA]
Un iterador bpf combina una iteración del kernel sobre datos específicos del kernel (por ejemplo, tareas, bpf_maps, etc.) y un programa bpf llamado para cada objeto de datos del kernel (por ejemplo, una tarea, un bpf_map, etc.). El espacio de usuario puede *leer* la salida del iterador del kernel a través de la llamada al sistema read().

El comando pin crea un iterador bpf a partir de OBJ, y lo fija en RUTA. La RUTA debe estar ubicada en el montaje bpffs. No debe contener un punto ('.'), que está reservado para futuras extensiones de bpffs.

El iterador de elementos de mapa requiere un parámetro adicional MAPA para que el programa bpf pueda iterar sobre los elementos del mapa de ese mapa. El usuario puede tener un programa bpf en el kernel para ejecutarse con cada elemento del mapa, realizar verificaciones, filtrado, agregación, etc. sin copiar datos al espacio de usuario.

Luego, el usuario puede ejecutar cat RUTA para ver la salida del iterador bpf.

bpftool iter help
Imprime un mensaje de ayuda corto.

OPCIONES

-h, --help
Imprime un mensaje de ayuda corto (similar a bpftool help).
-V, --version
Imprime el número de versión de bpftool (similar a bpftool version), el número de la versión de libbpf en uso y las características opcionales que se incluyeron cuando se compiló bpftool. Las características opcionales incluyen el enlace con LLVM o libbfd para proporcionar el desensamblador para programas JIT-ted (bpftool prog dump jited) y el uso de esqueletos BPF (algunas características como bpftool prog profile o mostrar pids asociados a objetos BPF pueden depender de ello).
-j, --json
Genera salida JSON. Para comandos que no pueden producir JSON, esta opción no tiene efecto.
-p, --pretty
Genera salida JSON legible para humanos. Implica -j.
-d, --debug
Imprime todos los registros disponibles, incluso la información a nivel de depuración. Esto incluye registros de libbpf así como del verificador, al intentar cargar programas.

EJEMPLOS

# bpftool iter pin bpf_iter_netlink.o /sys/fs/bpf/my_netlink

Crea un iterador bpf basado en archivos a partir de bpf_iter_netlink.o y lo fija
en /sys/fs/bpf/my_netlink

# bpftool iter pin bpf_iter_hashmap.o /sys/fs/bpf/my_hashmap map id 20

Crea un iterador bpf basado en archivos a partir de bpf_iter_hashmap.o y el mapa con
id 20, y lo fija en /sys/fs/bpf/my_hashmap
