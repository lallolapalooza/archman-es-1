NOMBRE

borg-version - Muestra la versión del cliente borg / servidor borg

SINOPSIS

borg [opciones comunes] version [opciones] [REPOSITORIO]

DESCRIPCIÓN

Este comando muestra la versión del cliente Borg / versión del servidor Borg.

Si se proporciona un repositorio local, el código del cliente accede directamente al repositorio, por lo que mostramos la versión del cliente también como la versión del servidor.

Si se proporciona un repositorio remoto (por ejemplo, ssh:), se consulta el Borg remoto y su versión se muestra como la versión del servidor.

Ejemplos:

# repo local (el cliente usa la versión alfa 1.4.0)
$ borg version /mnt/backup
1.4.0a / 1.4.0a
# repo remoto (el cliente usa la alfa 1.4.0, el servidor usa la versión estable 1.2.7)
$ borg version ssh://borg@borgbackup:repo
1.4.0a / 1.2.7

Debido al formato de tupla de versión utilizado en la negociación cliente/servidor de Borg, solo se muestra una versión simplificada (según lo proporcionado por borg.version.format_version).

También existe borg --version para mostrar una versión del cliente potencialmente más precisa.

OPCIONES

Consulte borg-common(1) para ver las opciones comunes de los comandos de Borg.

argumentos

REPOSITORIO
repositorio (utilizado para determinar la situación cliente/servidor)
