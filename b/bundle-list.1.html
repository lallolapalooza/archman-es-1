BUNDLE-LIST(1) Manual de Comandos Generales BUNDLE-LIST(1)

NOMBRE

bundle-list - Lista todas las gemas del bundle

SINOPSIS

bundle list [--name-only] [--paths] [--without-group=GROUP[ GROUP...]] [--only-group=GROUP[ GROUP...]]

DESCRIPCIÓN

Imprime una lista de todas las gemas del bundle, incluyendo su versión.

Ejemplo:

bundle list --name-only

bundle list --paths

bundle list --without-group test

bundle list --only-group dev

bundle list --only-group dev test --paths

OPCIONES

--name-only
Imprime solo el nombre de cada gema.
--paths
Imprime la ruta de cada gema en el bundle.
--without-group=<lista>
Una lista separada por espacios de grupos de gemas a omitir durante la impresión.
--only-group=<lista>
Una lista separada por espacios de grupos de gemas a imprimir.
