binopsbase(3bobcat) Binary Operators binopsbase(3bobcat)

NOMBRE

BinopsBase - Plantilla de clase que ofrece operadores binarios de tipo clase

SINOPSIS

#include <bobcat/binopsbase>

DESCRIPCIÓN

Las clases pueden sobrecargar operadores binarios. Una clase llamada Derived puede sobrecargar operadores binarios para adaptarlos a sus propias necesidades. Podría, por ejemplo, permitir que dos objetos de clase Derived se sumen, o podría definir una operación de desplazamiento dado un argumento de mano derecha (rhs) de tipo size_t.

Los operadores binarios disponibles son *, /, %, +, -, <<, >>, &, |, y ^ (en esta página de manual se indican genéricamente como el operador `@’). Además, frecuentemente se definen los operator<< y operator>> sobrecargados para inserción y extracción de flujos.

Si una clase Derived soporta construcción por copia y/o movimiento y si ofrece una función miembro swap (void Derived::swap(Derived &rhs)), y deriva públicamente de FBB::BinopsBase<Derived> entonces, una vez que Derived define un miembro

    void Class::operator@=(Rhs const &rhs) &&
que define el operador compuesto @ para objetos Derived temporales y anónimos y un tipo Rhs para su operando de mano derecha, los siguientes operadores también estarán disponibles: 
    Derived &operator@=(Rhs const &rhs) &
    Derived operator@(Derived &&lhs, Rhs const &rhs);
    Derived operator@(Derived const &lhs, Rhs const &rhs);

Un procedimiento similar se aplica a los operadores de inserción y extracción. Los operadores de inserción y extracción estarán disponibles una vez que BinopsBase<Derived> se declare como clase amiga de Derived. Para que el operador de inserción esté disponible, se debe definir además un miembro privado

    void Derived::insert(std::ostream &out) const
que inserte el objeto llamante en out. Análogamente, para que el operador de extracción esté disponible, se debe definir un miembro privado 
    void Derived::extract(std::istream &in)
que extraiga el objeto llamante de in.

HEREDA DE

--

OPERADORES SOBRECARGADOS

Para cada Derived &&operator@=(Rhs const &rhs) && definido en la clase Derived, los siguientes operadores también están disponibles automáticamente:

    Derived operator@(Derived &&lhs, Rhs const &rhs);
    Derived operator@(Derived const &lhs, Rhs const &rhs);

y

    Derived &operator@=(Rhs const &rhs) &;

El operador de inserción estará disponible una vez que se haya definido

    void Derived::insert(std::ostream &out) const
(insertando el objeto llamante en out). Análogamente, el operador de extracción estará disponible después de definir un miembro privado 
    void Derived::extract(std::istream &in)
(extrayendo el objeto llamante de in).

DECLARACIÓN DE AMIGA

Para que los operadores de inserción y/o extracción estén disponibles, la clase Derived también debe declarar

    friend FBB::BinopsBase<Derived>;

EJEMPLO

#include <iostream>
#include <bobcat/binopsbase>
class Demo1: public FBB::BinopsBase<Demo1>
{
    friend FBB::BinopsBase<Demo1>;            // para insert/extract
    public:
        void swap(Demo1 &other)
        {}
        Demo1 &&operator+=(Demo1 const &rhs) &&
        {
            std::cout << "adding two Demo1 objects\n";
            return std::move(*this);
        }
//  Explicit definitions take precedence over functions templates
//  instantiated from definitions in bobcat/binopsbase.
//        Demo1 &operator+=(Demo1 const &rhs) &
//        {
//            std::cout << "adding (self-defined) two Demo1 objects\n";
//            return *this;
//        }
        Demo1 &&operator-=(Demo1 const &rhs) &&
        {
            std::cout << "subtracting two Demo1 objects\n";
            return std::move(*this);
        }
        Demo1 &&operator<<=(Demo1 const &rhs) &&
        {
            std::cout << "shiftleft on two Demo1 objects\n";
            return std::move(*this);
        }
        Demo1 &&operator<<=(size_t rhs) &&
        {
            std::cout << "shiftleft Demo1 object size_t bits\n";
            return std::move(*this);
        }
        void insert(std::ostream &out) const        // requires friend
        {
            out << "inerting a Demo1 object\n";
        }
        void extract(std::istream &in)              // requires friend
        {
            std::cout << "extracting a Demo1 object\n";
        }
};
class Demo2: public FBB::BinopsBase<Demo2>
{
    public:
        void swap(Demo2 &other)
        {}
        Demo2 &&operator+=(Demo2 const &rhs) &&
        {
            std::cout << "adding two Demo2 objects\n";
            return std::move(*this);
        }
        Demo2 &operator+=(Demo2 const &rhs) &
        {
            std::cout << "adding (self-defined) two Demo2 objects";
            return *this;
        }
        Demo2 &&operator^=(Demo2 const &rhs) &&
        {
            std::cout << "xor-ing two Demo2 objects\n";
            return std::move(*this);
        }
        Demo2 &&operator|=(Demo2 const &rhs) &&
        {
            std::cout << "or-ing two Demo2 objects\n";
            return std::move(*this);
        }
};
int main()
{
    Demo1 d1a, d1b;
    Demo1 d1c = d1a + d1b;
    d1a += d1b;
    d1c = Demo1{} + d1b;
    std::cout << "Here we are " << d1c << ’\n’;
    std::cin >> d1c;
    d1a <<= d1a;
    d1a <<= 5;
    Demo2 d2a, d2b;
    Demo2 d2c = d2a + d2b;
    d2a ^= d2b;
    d2c = Demo2{} ^ d2b;
    d2c = d2c | d2b;
}
