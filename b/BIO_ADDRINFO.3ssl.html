NOMBRE

BIO_lookup_type, BIO_ADDRINFO, BIO_ADDRINFO_next, BIO_ADDRINFO_free, BIO_ADDRINFO_family, BIO_ADDRINFO_socktype, BIO_ADDRINFO_protocol, BIO_lookup_ex, BIO_lookup - Tipo BIO_ADDRINFO y rutinas

SINOPSIS

#include <sys/types.h>
#include <openssl/bio.h>
typedef union bio_addrinfo_st BIO_ADDRINFO;
enum BIO_lookup_type {
    BIO_LOOKUP_CLIENT, BIO_LOOKUP_SERVER
};
int BIO_lookup_ex(const char *host, const char *service, int lookup_type,
                  int family, int socktype, int protocol, BIO_ADDRINFO **res);
int BIO_lookup(const char *host, const char *service,
               enum BIO_lookup_type lookup_type,
               int family, int socktype, BIO_ADDRINFO **res);
const BIO_ADDRINFO *BIO_ADDRINFO_next(const BIO_ADDRINFO *bai);
int BIO_ADDRINFO_family(const BIO_ADDRINFO *bai);
int BIO_ADDRINFO_socktype(const BIO_ADDRINFO *bai);
int BIO_ADDRINFO_protocol(const BIO_ADDRINFO *bai);
const BIO_ADDR *BIO_ADDRINFO_address(const BIO_ADDRINFO *bai);
void BIO_ADDRINFO_free(BIO_ADDRINFO *bai);

DESCRIPCIÓN

El tipo BIO_ADDRINFO es un envoltorio para los tipos de información de dirección proporcionados en su plataforma.

BIO_ADDRINFO normalmente forma una cadena de varios que se pueden seleccionar uno a uno.

BIO_lookup_ex() busca un host y service especificados, y utiliza lookup_type para determinar cuál debe ser la dirección predeterminada si host es NULL. family, socktype y protocol se utilizan para determinar qué familia de protocolo, tipo de socket y protocolo se deben utilizar para la búsqueda. family puede ser cualquiera de AF_INET, AF_INET6, AF_UNIX y AF_UNSPEC. socktype puede ser SOCK_STREAM, SOCK_DGRAM o 0. Especificar 0 indica que se puede usar cualquier tipo. protocol especifica un protocolo como IPPROTO_TCP, IPPROTO_UDP o IPPORTO_SCTP. Si se establece en 0, se puede usar cualquier protocolo. res apunta a un puntero para contener el inicio de una cadena BIO_ADDRINFO.

Para la familia AF_UNIX, BIO_lookup_ex() ignorará el parámetro service y espera que el parámetro host contenga la ruta al archivo de socket.

BIO_lookup() hace lo mismo que BIO_lookup_ex() pero no proporciona la capacidad de seleccionar según el protocolo (se puede devolver cualquier protocolo).

BIO_ADDRINFO_family() devuelve la familia del BIO_ADDRINFO dado. El resultado será una de las constantes AF_INET, AF_INET6 y AF_UNIX.

BIO_ADDRINFO_socktype() devuelve el tipo de socket del BIO_ADDRINFO dado. El resultado será una de las constantes SOCK_STREAM y SOCK_DGRAM.

BIO_ADDRINFO_protocol() devuelve el id. de protocolo del BIO_ADDRINFO dado. El resultado será una de las constantes IPPROTO_TCP y IPPROTO_UDP.

BIO_ADDRINFO_address() devuelve el BIO_ADDR subyacente del BIO_ADDRINFO dado.

BIO_ADDRINFO_next() devuelve el siguiente BIO_ADDRINFO en la cadena a partir del dado.

BIO_ADDRINFO_free() libera la cadena de BIO_ADDRINFO comenzando con la dada. Si el argumento es NULL, no se hace nada.

VALORES DE RETORNO

BIO_lookup_ex() y BIO_lookup() devuelven 1 en caso de éxito y 0 cuando ocurrió un error, y dejarán una indicación de error en la pila de errores de OpenSSL en ese caso.

Todas las demás funciones descritas aquí devuelven 0 o NULL cuando la información que deberían devolver no está disponible.

NOTAS

La implementación de BIO_lookup_ex() utiliza la función getaddrinfo() proporcionada por la plataforma. En Linux se sabe que especificar 0 para el protocolo no devolverá ninguna dirección basada en SCTP al llamar a getaddrinfo(). Por lo tanto, si se requiere una dirección SCTP, el parámetro protocol para BIO_lookup_ex() debe establecerse explícitamente en IPPROTO_SCTP. Lo mismo puede ser cierto en otras plataformas.

HISTORIA

La función BIO_lookup_ex() se añadió en OpenSSL 1.1.1.
