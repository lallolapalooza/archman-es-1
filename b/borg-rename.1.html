BORG-RENAME(1) Herramienta de backup borg BORG-RENAME(1)

NOMBRE

borg-rename - Renombrar un archivo existente

SINOPSIS

borg [opciones comunes] rename [opciones] ARCHIVO NUEVO_NOMBRE

DESCRIPCIÓN

Este comando renombra un archivo en el repositorio.

Esto resulta en un ID de archivo diferente.

OPCIONES

Ver borg-common(1) para opciones comunes de los comandos de Borg.

argumentos

ARCHIVO
archivo a renombrar
NUEVO_NOMBRE
el nuevo nombre de archivo a utilizar

EJEMPLOS

$ borg create /ruta/al/repo::nombre_archivo ~
$ borg list /ruta/al/repo
nombre_archivo                   Lun, 2016-02-15 19:50:19
$ borg rename /ruta/al/repo::nombre_archivo nuevo_nombre
$ borg list /ruta/al/repo
nuevo_nombre                     Lun, 2016-02-15 19:50:19
