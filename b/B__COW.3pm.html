NOMBRE

B::COW - Ayudantes adicionales de B::COW para comprobar el estado de COW

VERSIÓN

versión 0.007

SINOPSIS

#!perl

use strict;
use warnings;

use Test::More;    # sólo se usa a efectos de ilustración

use B::COW qw{:all};

if ( can_cow() ) {    # $] >= 5.020
    ok !is_cow(undef);

    my $str = "abcdef";
    ok is_cow($str);
    is cowrefcnt($str), 1;

    my @a;
    push @a, $str for 1 .. 100;

    ok is_cow($str);
    ok is_cow( $a[0] );
    ok is_cow( $a[99] );
    is cowrefcnt($str), 101;
    is cowrefcnt( $a[-1] ), 101;

    delete $a[99];
    is cowrefcnt($str), 100;
    is cowrefcnt( $a[-1] ), 100;

    {
        my %h = ( 'a' .. 'd' );
        foreach my $k ( sort keys %h ) {
            ok is_cow($k);
            is cowrefcnt($k), 0;
        }
    }

}
else {
    my $str = "abcdef";
    is is_cow($str),    undef;
    is cowrefcnt($str), undef;
    is cowrefcnt_max(), undef;
}

done_testing;

DESCRIPCIÓN

B::COW proporciona algunos ayudantes adicionales ingenuos de B para comprobar el estado de COW de un SvPV.

Introducción a COW o Copy On Write

Un SvPV COWed está compartiendo su cadena (el PV) con otros SvPVs. Es (una especie de) cadena C de solo lectura, que se copiaría al escribir (COW).

Más de un SV puede compartir el mismo PV, pero cuando un PV necesita modificarlo, realizaría una copia de él, disminuyendo el contador COWREFCNT.

Un SV puede entonces eliminar la bandera COW cuando es el único que mantiene un puntero al PV.

El COWREFCNT se almacena al final del PV, después del "\0".

Ese valor está limitado a 255; cuando alcanzamos 255, se crearía un nuevo PV.

FUNCIONES

can_cow()

Devuelve un valor booleano. Verdadero si tu versión de Perl soporta Copy On Write para SvPVs.

is_cow( PV )

Devuelve un valor booleano. Verdadero si el SV es un SvPV con COW. (Comprueba las BANDERAS del SV).

cowrefcnt( PV )

Devuelve un entero que representa el valor del recuento de referencias de COW. Si la cadena no es COW, devolverá undef.

cowrefcnt_max()

Devolverá el SV_COW_REFCNT_MAX de tu Perl. (si COW es compatible, debería ser 255 a menos que se personalice).
