NOMBRE

byobu-prompt, byobu-enable-prompt, byobu-disable-prompt - añade y elimina un prompt de color agradable con un temporizador de comando previo a tu configuración de shell

SINOPSIS

byobu-prompt

byobu-enable-prompt
byobu-disable-prompt

DESCRIPCIÓN

Byobu proporciona un comando especial de prompt PS0 y PS1, compatible con shells Bash. Mostrará el tiempo total de ejecución y el código de salida del comando anterior, si no es cero. Utilizará 3 colores separados para el nombre de usuario local, el nombre del host y el directorio de trabajo actual.

byobu-enable-prompt añadirá una línea a tu ~/.bashrc.

Puedes eliminar de forma segura la línea de tu ~/.bashrc que termina en #byobu-prompt.

byobu-disable-prompt eliminará su configuración de color de ~/.bashrc.

byobu-prompt es un envoltorio interactivo de las dos herramientas anteriores.

ERRORES

Actualmente, esto solo es compatible con bash(1).
