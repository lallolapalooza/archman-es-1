BN_CTX_start(3ssl)

Paquete: openssl

Licencias: Apache-2.0

BN_CTX_START(3ssl) OpenSSL BN_CTX_START(3ssl)

NOMBRE

BN_CTX_start, BN_CTX_get, BN_CTX_end - usar variables BIGNUM temporales

SINOPSIS

#include <openssl/bn.h>
void BN_CTX_start(BN_CTX *ctx);
BIGNUM *BN_CTX_get(BN_CTX *ctx);
void BN_CTX_end(BN_CTX *ctx);

DESCRIPCIÓN

Estas funciones se utilizan para obtener variables BIGNUM temporales de un BN_CTX (que puede haberse creado usando BN_CTX_new(3)) con el fin de ahorrar la sobrecarga de crear y liberar repetidamente BIGNUMs en funciones que se llaman desde dentro de un bucle.

Una función debe llamar primero a BN_CTX_start(). Luego, se puede llamar a BN_CTX_get() repetidamente para obtener BIGNUMs temporales. Todas las llamadas a BN_CTX_get() deben realizarse antes de llamar a cualquier otra función que utilice ctx como argumento.

Finalmente, se debe llamar a BN_CTX_end() antes de devolver la ejecución de la función. Si ctx es NULL, no se hace nada. Cuando se llama a BN_CTX_end(), los punteros BIGNUM obtenidos de BN_CTX_get() dejan de ser válidos.

VALORES DE RETORNO

BN_CTX_start() y BN_CTX_end() no devuelven valores.

BN_CTX_get() devuelve un puntero al BIGNUM, o NULL en caso de error. Una vez que BN_CTX_get() ha fallado, las llamadas subsiguientes también devolverán NULL, por lo que es suficiente comprobar el valor de retorno de la última llamada a BN_CTX_get(). En caso de error, se establece un código de error, que puede obtenerse mediante ERR_get_error(3).

VER TAMBIÉN
