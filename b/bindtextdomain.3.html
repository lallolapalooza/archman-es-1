BINDTEXTDOMAIN(3) Manual de funciones de biblioteca BINDTEXTDOMAIN(3)

NOMBRE

bindtextdomain - establece el directorio que contiene los catálogos de mensajes

SINOPSIS

#include <libintl.h>

char * bindtextdomain (const char * domainname, const char * dirname);

DESCRIPCIÓN

La función bindtextdomain establece el directorio base de la jerarquía que contiene los catálogos de mensajes para un dominio de mensajes dado.

Un dominio de mensajes es un conjunto de mensajes msgid traducibles. Normalmente, cada paquete de software tiene su propio dominio de mensajes. La necesidad de llamar a bindtextdomain surge porque los paquetes no siempre se instalan con el mismo prefijo que la cabecera <libintl.h> y las bibliotecas libc/libintl.

Se esperará que los catálogos de mensajes se encuentren en las rutas dirname/locale/category/domainname.mo, donde locale es un nombre de localización y category es una faceta de localización como LC_MESSAGES.

domainname debe ser una cadena no vacía.

Si dirname no es NULL, el directorio base para los catálogos de mensajes pertenecientes al dominio domainname se establece en dirname. La función realiza copias de las cadenas de argumento según sea necesario. Si el programa desea llamar a la función chdir, es importante que dirname sea una ruta absoluta; de lo contrario, no se puede garantizar que se encuentren los catálogos de mensajes.

Si dirname es NULL, la función devuelve el directorio base previamente establecido para el dominio domainname.

VALOR DE RETORNO

Si tiene éxito, la función bindtextdomain devuelve el directorio base actual para el dominio domainname, después de haberlo cambiado posiblemente. La cadena resultante es válida hasta la próxima llamada a bindtextdomain para el mismo domainname y no debe modificarse ni liberarse. Si se produce un error de asignación de memoria, establece errno a ENOMEM y devuelve NULL.

ERRORES

Pueden ocurrir los siguientes errores, entre otros:

ENOMEM
No hay suficiente memoria disponible.

ERRORES

El tipo de retorno debería ser const char *, pero es char * para evitar advertencias en código C anterior a ANSI C.
