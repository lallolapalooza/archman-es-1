configuración de

es un directorio que contiene paquetes compilados con configuraciones similares. Por ejemplo, una configuración puede ser para un destino específico ( i68

, x86_64 ), compilador ( clang , gcc ) opciones de compilación ( -O3 , -g ), y así sucesivamente. Las configuraciones son relativamente baratas y pueden crearse y descartarse según sea necesario. Las configuraciones pueden moverse y copiarse simplemente moviendo y copiando los directorios. Sin embargo, tenga en cuenta que un movimiento o copia puede hacer que algunos paquetes queden desactualizados. En los términos del sistema de compilación build2

una

bpkg configuración de compilación es una amalgama que contiene paquetes como subproyectos (consulte bpkg-cfg-create(1)para más detalles). Las configuraciones de compilación pueden enlazarse entre sí de modo que mientras un paquete se compila en una configuración, algunas de sus dependencias pueden compilarse en configuraciones enlazadas (consultebpkg-cfg-create(1) para más detalles).Un paquete bpkg es un archivo o directorio (potencialmente en un sistema de control de versiones) que contiene un proyecto build2 más el archivo manifiesto del paquete. bpkg puede usar archivos/directorios de paquetes directamente desde el sistema de archivos o puede obtenerlos de

repositorios.

Un repositorio bpkg es una colección de paquetes así como información sobre repositorios de requisitos previos y

complementarios.

Se admiten repositorios basados en archivo , directorio y control de versiones . Un repositorio se identifica por su ubicación, que puede ser una ruta local del sistema de archivos o una URL.

Consulte

bpkg-repository-types(1) para más detalles sobre las estructuras de repositorio y los formatos de URL. Si la misma versión de un paquete está disponible en múltiples repositorios, se asume que contienen contenido de paquete idéntico. En tales casos bpkg prefiere los repositorios locales sobre los remotos y entre los repositorios locales prefiere los que tienen paquetes externos (consulte bpkg-pkg-unpack(1

)

OPCIONES COMUNES


Las opciones comunes se resumen a continuación; una descripción más detallada está disponible en bpkg-common-options(1).



  
-v

  
Imprimir los comandos subyacentes esenciales que se están ejecutando.

  
-V

  
Imprimir todos los comandos subyacentes que se están ejecutando.

  
--quiet|-q

  
Ejecutar en silencio, imprimiendo solo mensajes de error.

  
--verbose
    level

  
Establecer el nivel de verbosidad del diagnóstico en level entre 0 y 6.

  
--stdout-format
    format

  
Formato de representación a utilizar para imprimir en stdout.

  
--jobs|-j
    num

  
Número de trabajos a realizar en paralelo.

  
--no-result

  
No imprimir mensajes informativos sobre el resultado de la ejecución de un comando o de algunas de sus partes.

  
--structured-result
    fmt

  
Escribir el resultado de la ejecución de un comando en una forma estructurada.

  
--progress

  
Mostrar indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.

  
--no-progress

  
Suprimir los indicadores de progreso para operaciones de larga duración, como transferencias de red, compilación, etc.

  
--diag-color

  
Usar color en los diagnósticos.

  
--no-diag-color

  
No usar color en los diagnósticos.

  
--build
    path

  
El programa de compilación a utilizar para compilar paquetes.

  
--build-option
    opt

  
Opción adicional a pasar al programa de compilación.

  
--fetch
    path

  
El programa de obtención a utilizar para descargar recursos.

  
--fetch-option
    opt

  
Opción adicional a pasar al programa de obtención.

  
--fetch-timeout
    sec

  
Tiempo de espera del programa de obtención y de programas similares (por ejemplo, git).

  
--pkg-proxy
    url

  
Servidor proxy HTTP a utilizar al obtener manifiestos y archivos de paquetes de
      repositorios pkg remotos.

  
--git
    path

  
El programa git a utilizar para obtener repositorios git.

  
--git-option
    opt

  
Opción común adicional a pasar al programa git.

  
--sha256
    path

  
El programa sha256 a utilizar para calcular sumas SHA256.

  
--sha256-option
    opt

  
Opción adicional a pasar al programa sha256.

  
--tar
    path

  
El programa tar a utilizar para extraer archivos de paquetes.

  
--tar-option
    opt

  
Opción adicional a pasar al programa tar.

  
--openssl
    path

  
El programa openssl a utilizar para operaciones criptográficas.

  
--openssl-option
    opt

  
Opción adicional a pasar al programa openssl.

  
--auth
    type

  
Tipos de repositorios a autenticar.

  
--trust
    fingerprint

  
Confiar en el certificado del repositorio con una huella digital SHA256 fingerprint.

  
--trust-yes

  
Asumir que la respuesta a todas las solicitudes de autenticación es yes.

  
--trust-no

  
Asumir que la respuesta a todas las solicitudes de autenticación es no.

  
--git-capabilities
    up=pc

  
Capacidades del protocolo (pc) para un prefijo de URL de repositorio git (up).

  
--pager
    path

  
El programa paginador a utilizar para mostrar texto largo.

  
--pager-option
    opt

  
Opción adicional a pasar al programa paginador.

  
--options-file
    file

  
Leer opciones adicionales de file.

  
--default-options
    dir

  
El directorio desde el cual cargar archivos de opciones predeterminadas adicionales.

  
--no-default-options

  
No cargar archivos de opciones predeterminadas.

  
--keep-tmp

  
No eliminar el directorio temporal de bpkgal final de la ejecución del comando e imprimir su ruta con un nivel de verbosidad de 2 o
    superior.








ENTORNO


Los comandos ejecutados por bpkg mientras las bases de datos de configuración de compilación actual y vinculada están abiertas tendrán la
    variable de entorno
    BPKG_OPEN_CONFIGS establecida a la lista de rutas de directorios de configuración absolutas y normalizadas, separadas por espacios y
    entrecomilladas con
    ". Esto puede ser utilizado por los ganchos del sistema de compilación y/o por los programas que estos ejecuten.






ESTADO DE SALIDA



  
0

  

    

    Éxito.

  
1

  

    

    Error fatal.

  
2

  

    

    Error recuperable que probablemente desaparecerá si el comando se vuelve a ejecutar.








ENTORNO


La variable de entorno BPKG_DEF_OPT se utiliza para suprimir la
    carga de archivos de opciones predeterminadas en invocaciones anidadas de bpkg . Sus valores son false u 0 para suprimir y true u 1
    para cargar.
