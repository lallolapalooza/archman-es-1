BINDRESVPORT(3) Manual de Funciones de Biblioteca BINDRESVPORT(3)

NOMBRE

bindresvport, bindresvport_sa — enlazar un socket a un puerto IP privilegiado

SINOPSIS

#include <sys/types.h>
#include <rpc/rpc.h>

int
bindresvport(int sd, struct sockaddr_in *sin);

int
bindresvport_sa(int sd, struct sockaddr *sa);

DESCRIPCIÓN

Las funciones bindresvport() y bindresvport_sa() se utilizan para enlazar un descriptor de socket a un puerto IP privilegiado, es decir, un número de puerto en el rango 0-1023.

Si sin es un puntero a una struct sockaddr_in, los campos apropiados de la estructura deben estar definidos. Tenga en cuenta que sin->sin_family debe inicializarse a la familia de direcciones del socket, pasado por sd. Si sin->sin_port es ‘0’, se elegirá un puerto anónimo (en el rango 600-1023), y si bind(2) tiene éxito, sin->sin_port se actualizará para contener el puerto asignado.

Si sin es el puntero NULL, se asignará un puerto anónimo (como se describió anteriormente). Sin embargo, no hay forma de que bindresvport() devuelva el puerto asignado en este caso.

Solo root puede enlazar a un puerto privilegiado; esta llamada fallará para cualquier otro usuario.

El prototipo de la función bindresvport() está sesgado hacia sockets AF_INET. La función bindresvport_sa() actúa exactamente igual, con un prototipo de función más neutral. Tenga en cuenta que ambas funciones se comportan exactamente igual y ambas admiten sockets AF_INET6, así como sockets AF_INET.

VALORES DE RETORNO

La función bindresvport() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

[EPFNOSUPPORT]
Si se proporcionó el segundo argumento y la familia de direcciones no coincidió entre los argumentos.

La función bindresvport() también puede fallar y establecer errno por cualquiera de los errores especificados para las llamadas bind(2), getsockopt(2), o setsockopt(2).

DISPONIBILIDAD

La función bindresvport() es parte de libtirpc.

VER TAMBIÉN

bind(2), getsockopt(2), setsockopt(2)
