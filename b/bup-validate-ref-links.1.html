NOMBRE

bup-validate-ref-links - comprueba las referencias del repositorio en busca de enlaces a objetos que faltan

SINOPSIS

bup validate-ref-links [ref...]

DESCRIPCIÓN

bup validate-ref-links comprueba las referencias del repositorio (por ejemplo, saves) en busca de commits o subárboles que hagan referencia a objetos que faltan y reporta las rutas a los encontrados. Si no se proporcionan refs, comprueba todas las refs, de lo contrario, solo comprueba las especificadas.

Este comando también se puede utilizar para validar un save más rápidamente que intentando una restore o un join del save a /dev/null, y mucho más rápidamente para múltiples saves relacionados, aunque solo comprueba la existencia de los datos de las hojas (blobs), no intenta leer esos datos.

Por el momento, la información de ruta rota solo se registra en la salida de error estándar, y no está bien especificada (es decir, es adecuada para inspección, pero no para análisis).

Tenga en cuenta también que la implementación actual puede no reportar todas las rutas a un objeto faltante dado porque solo examina cada objeto de árbol o commit único una vez, sin importar cuántas veces aparezca dentro de las refs que se están examinando. Esto significa que, para encontrar cada save roto, necesitaría ejecutar el comando por separado para cada ref, lo que probablemente será mucho más costoso que una ejecución combinada porque no puede omitir subárboles que ha encontrado antes.

ESTADO DE SALIDA

El estado de salida será 1 si se encuentran enlaces rotos, 0 si no se encuentra ninguno, y algún otro entero positivo para otros fallos.

VER TAMBIÉN

bup-fsck(1), bup-join(1), bup-restore(1)
