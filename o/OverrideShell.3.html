OverrideShell OverrideShell

NOMBRE

OverrideShell - Clase de widgets OverrideShell

SINOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPCIÓN

OverrideShell se usa para ventanas de shell que omiten completamente el gestor de ventanas, por ejemplo, ventanas de PopupMenu.

Clases

OverrideShell hereda comportamiento y recursos de Core, Composite y Shell.

El puntero de clase es overrideShellWidgetClass.

El nombre de la clase es OverrideShell.

Nuevos Recursos

OverrideShell define ningún nuevo recurso, pero sobrescribe los recursos XmNoverrideRedirect y XmNsaveUnder de la clase Shell.

Recursos Heredados

OverrideShell hereda comportamiento y recursos de las siguientes superclases. Para una descripción completa de cada recurso, consulte la página de referencia para cada clase.

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos de este widget. Para referirse a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use los caracteres restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use los caracteres restantes (en minúsculas o mayúsculas, pero incluya los guiones entre palabras). Los códigos en la columna de acceso indican si el recurso puede ser establecido en tiempo de creación (C), mediante XtSetValues (S), mediante XtGetValues (G), o no es aplicable (N/A).

Nombre

NOMBRE

OverrideShell - OverrideShell widget (e.g., dialog shells)

SINOPSIS

   #include <Xm/OverrideSB.h>

La interfaz de programación de aplicaciones para OverrideShell no expone ninguna interfaz pública además de las definidas por las interfaces de Core(3) y Shell(3).

DESCRIPCIÓN

OverrideShell es un widget de shell que permite a los desarrolladores ignorar las características del shell padre. Se utiliza principalmente para implementar shells de diálogo, que requieren un control específico sobre sus características para un comportamiento correcto del diálogo.

No hay recursos específicos para OverrideShell que no estén heredados de sus clases padre.

RECURSOS

OverrideShell hereda los recursos de las siguientes clases:

Core
Permite la configuración de las características básicas del widget, como el nombre de clase, el nombre de instancia, el ancho, la altura, el borde y el fondo.
Shell
Proporciona recursos relacionados con la configuración de la ventana del shell, como el título, el administrador de geometría y el mapa de colores.

Los siguientes códigos de acceso se aplican a los recursos:

C
Se puede establecer durante la creación del widget.
G
Se puede obtener consultando el valor del recurso.
S
Se puede establecer consultando el valor del recurso después de la creación del widget.
R
Se puede establecer solo durante la creación del widget; no se puede modificar posteriormente.
D
Se puede establecer durante la creación del widget y también modificarse posteriormente.
