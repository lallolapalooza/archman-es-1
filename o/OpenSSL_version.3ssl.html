OpenSSL_version(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL_VERSION(3ssl) OpenSSL OPENSSL_VERSION(3ssl)

NOMBRE

OPENSSL_VERSION_MAJOR, OPENSSL_VERSION_MINOR, OPENSSL_VERSION_PATCH, OPENSSL_VERSION_PRE_RELEASE, OPENSSL_VERSION_BUILD_METADATA, OPENSSL_VERSION_TEXT, OPENSSL_VERSION_PREREQ, OPENSSL_version_major, OPENSSL_version_minor, OPENSSL_version_patch, OPENSSL_version_pre_release, OPENSSL_version_build_metadata, OpenSSL_version, OPENSSL_VERSION_NUMBER, OpenSSL_version_num, OPENSSL_info - obtener el número de versión de OpenSSL y otra información

SINOPSIS

#include <openssl/opensslv.h>
#define OPENSSL_VERSION_MAJOR  x
#define OPENSSL_VERSION_MINOR  y
#define OPENSSL_VERSION_PATCH  z
/* Las definiciones aquí son valores típicos de lanzamiento */
#define OPENSSL_VERSION_PRE_RELEASE ""
#define OPENSSL_VERSION_BUILD_METADATA ""
#define OPENSSL_VERSION_TEXT "OpenSSL x.y.z xx XXX xxxx"
#define OPENSSL_VERSION_PREREQ(maj,min)
#include <openssl/crypto.h>
unsigned int OPENSSL_version_major(void);
unsigned int OPENSSL_version_minor(void);
unsigned int OPENSSL_version_patch(void);
const char *OPENSSL_version_pre_release(void);
const char *OPENSSL_version_build_metadata(void);
const char *OpenSSL_version(int t);
const char *OPENSSL_info(int t);
/* desde openssl/opensslv.h */
#define OPENSSL_VERSION_NUMBER 0xnnnnnnnnL
/* desde openssl/crypto.h */
unsigned long OpenSSL_version_num();

DESCRIPCIÓN

Macros

Las tres macros OPENSSL_VERSION_MAJOR, OPENSSL_VERSION_MINOR y OPENSSL_VERSION_PATCH representan las tres partes de un identificador de versión, MAYOR.MENOR.PARCHE.

La macro OPENSSL_VERSION_PRE_RELEASE es un texto adicional que indica que se trata de una versión preliminar, como "-dev" para una instantánea de desarrollo en curso o "-alpha3" para un lanzamiento alfa. El valor debe ser una cadena.

La macro OPENSSL_VERSION_BUILD_METADATA es información adicional, reservada para terceros, como "+fips" o "+vendor.1". El proyecto OpenSSL no tocará esta macro (la dejará como una cadena vacía). El valor debe ser una cadena.

OPENSSL_VERSION_STR es una macro de conveniencia para obtener la cadena identificadora de versión corta, "MAYOR.MENOR.PARCHE".

OPENSSL_FULL_VERSION_STR es una macro de conveniencia para obtener la cadena identificadora de versión más larga, que combina OPENSSL_VERSION_STR, OPENSSL_VERSION_PRE_RELEASE y OPENSSL_VERSION_BUILD_METADATA.

OPENSSL_VERSION_TEXT es una macro de conveniencia para obtener un texto descriptivo completo de la versión, que incluye OPENSSL_FULL_VERSION_STR y la fecha de lanzamiento.

OPENSSL_VERSION_PREREQ es una macro útil para verificar si la versión de OpenSSL para las cabeceras en uso es al menos igual al número de versión mayor (maj) y menor (min) predefinido o no. Se evaluará como verdadero si el número de versión de las cabeceras (OPENSSL_VERSION_MAJOR.OPENSSL_VERSION_MINOR) es mayor o igual a maj.min.

OPENSSL_VERSION_NUMBER es una combinación de la versión mayor, menor y parche en un solo entero 0xMNN00PP0L, donde:

M
es el número de OPENSSL_VERSION_MAJOR, en notación hexadecimal
NN
es el número de OPENSSL_VERSION_MINOR, en notación hexadecimal
PP
es el número de OPENSSL_VERSION_PATCH, en notación hexadecimal

Funciones

OPENSSL_version_major(), OPENSSL_version_minor(), OPENSSL_version_patch(), OPENSSL_version_pre_release() y OPENSSL_version_build_metadata() devuelven los valores de las macros anteriores para la compilación de la biblioteca, respectivamente.

OpenSSL_version() devuelve diferentes cadenas dependiendo de t:

OPENSSL_VERSION
El valor de OPENSSL_VERSION_TEXT
OPENSSL_VERSION_STRING
El valor de OPENSSL_VERSION_STR
OPENSSL_FULL_VERSION_STRING
El valor de OPENSSL_FULL_VERSION_STR
OPENSSL_CFLAGS
Las banderas del compilador establecidas para el proceso de compilación en formato "compiler: ..." si están disponibles, o "compiler: information not available" en caso contrario.
OPENSSL_BUILT_ON
La fecha del proceso de compilación en formato "built on: ..." si está disponible o "built on: date not available" en caso contrario. La fecha no estaría disponible en una compilación reproducible, por ejemplo.
OPENSSL_PLATFORM
El objetivo "Configure" de la compilación de la biblioteca en formato "platform: ..." si está disponible, o "platform: information not available" en caso contrario.
OPENSSL_DIR
La configuración de OPENSSLDIR de la compilación de la biblioteca en formato "OPENSSLDIR: "..."" si está disponible, o "OPENSSLDIR: N/A" en caso contrario.
OPENSSL_ENGINES_DIR
La configuración de ENGINESDIR de la compilación de la biblioteca en formato "ENGINESDIR: "..."" si está disponible, o "ENGINESDIR: N/A" en caso contrario. Esta opción está obsoleta en OpenSSL 3.0.
OPENSSL_MODULES_DIR
La configuración de MODULESDIR de la compilación de la biblioteca en formato "MODULESDIR: "..."" si está disponible, o "MODULESDIR: N/A" en caso contrario.
OPENSSL_CPU_INFO
La configuración actual de CPU de OpenSSL. Esta es la configuración actual de las banderas de capacidad de CPU. Generalmente se configura automáticamente, pero puede establecerse a través de una variable de entorno. El valor tiene la misma sintaxis que la variable de entorno. Para x86, la cadena se ve como "CPUINFO: OPENSSL_ia32cap=0x123:0x456" o "CPUINFO: N/A" si no está disponible.
OPENSSL_WINCTX
El contexto de instalación de Windows. El contexto de instalación de Windows se utiliza para calcular el nombre de la clave de registro de OpenSSL en Windows. La clave de registro completa es "SOFTWARE\WOW6432Node\OpenSSL-{major}.{minor}-{context}", donde "{major}", "{minor}" y "{context}" son el número de versión mayor de OpenSSL, el número de versión menor y el contexto de instalación de Windows, respectivamente.

Para un t desconocido, se devuelve el texto "not available".

OPENSSL_info() también devuelve diferentes cadenas dependiendo de t:

OPENSSL_INFO_CONFIG_DIR
El "OPENSSLDIR" configurado, que es la ubicación predeterminada para los archivos de configuración de OpenSSL.
OPENSSL_INFO_ENGINES_DIR
El "ENGINESDIR" configurado, que es la ubicación predeterminada para los motores de OpenSSL.
OPENSSL_INFO_MODULES_DIR
El "MODULESDIR" configurado, que es la ubicación predeterminada para los módulos cargables dinámicamente de Open

HISTORIA

Los macros y funciones descritas aquí fueron añadidas en OpenSSL 3.0, excepto por OPENSSL_VERSION_NUMBER y OPENSSL_version_num().

BUGS

Hubo una discrepancia entre este man y el comentario + código en <openssl/opensslv.h>, donde el último sugería que los cuatro bits menos significativos de OPENSSL_VERSION_NUMBER podían ser 0x0f en versiones de OpenSSL liberadas.
