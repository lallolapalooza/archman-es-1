OPENSSL_instrument_bus(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL_INSTRUMENT_BUS(3ssl) OpenSSL OPENSSL_INSTRUMENT_BUS(3ssl)

NOMBRE

OPENSSL_instrument_bus, OPENSSL_instrument_bus2 - instrumentar referencias al bus de memoria

SINOPSIS

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.6 y serán eliminadas en una futura versión. Ya no deben ser utilizadas.

#ifdef OPENSSL_CPUID_OBJ
size_t OPENSSL_instrument_bus(unsigned int *vector, size_t num);
size_t OPENSSL_instrument_bus2(unsigned int *vector, size_t num, size_t max);
#endif

DESCRIPCIÓN

Se encontró empíricamente que los tiempos de las referencias a la memoria primaria están sujetos a variaciones irregulares, aparentemente no deterministas. Las subrutinas en cuestión instrumentan estas referencias con el fin de recopilar aleatoriedad para el generador de números aleatorios. Para hacerlo dependiente del bus, se utiliza una instrucción de 'línea de caché de limpieza' entre las sondas. Además, se añaden sondas a los elementos de vector de manera atómica o entrelazada, lo que debería aportar ruido adicional en sistemas multiprocesador. Esto también significa que vector[num] debe ser puesto a cero al invocar la función (si desea recuperar los valores reales de las sondas).

OPENSSL_instrument_bus() realiza num sondas y registra el número de ciclos del oscilador que tomó cada sonda.

OPENSSL_instrument_bus2(), por otro lado, acumula sondas consecutivas con el mismo valor, es decir, de alguna manera registra la duración de los períodos en los que los valores de las sondas parecían deterministas. La subrutina realiza como máximo max sondas en un intento de llenar vector[num], con un valor max de 0 que significa "tantas como sea necesario".

VALORES DE RETORNO

Un valor de retorno de 0 indica que la CPU no es capaz de realizar la evaluación comparativa, ya sea porque el contador del oscilador o la 'línea de caché de limpieza' no están disponibles en la plataforma actual. Como referencia, en x86 la 'línea de caché de limpieza' se introdujo con las extensiones SSE2.

De lo contrario, se devuelve el número de valores registrados.
