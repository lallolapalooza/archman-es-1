Descripción Detallada

API de C++ de OpenDBX.

La API de C++ de OpenDBX es una capa de abstracción de base de datos orientada a objetos basada en la API procedural C de la biblioteca OpenDBX. La API de C++ proporciona objetos que encapsulan conexiones, sentencias, conjuntos de resultados y objetos grandes.

El uso de la API comienza estableciendo una conexión al servidor de la base de datos creando una instancia de la clase Conn con los parámetros backend, host y port. Conn::getCapability() prueba las capacidades implementadas de la biblioteca de base de datos subyacente mientras que Conn::getOption() y Conn::setOption() se utilizan para probar y cambiar una serie de opciones. Las opciones deben cambiarse antes de autenticar la conexión con el método Conn::bind() para que tengan algún efecto. También es posible volver a vincular una conexión usando credenciales diferentes después de que se haya llamado a Conn::unbind(). Adicionalmente, la clase Conn es capaz de escapar secuencias de caracteres potencialmente peligrosas con Conn::escape() si, por ejemplo, la entrada del usuario debe formar parte de una sentencia como valor.

El método Conn::create() crea e inicializa una nueva instancia de sentencia a partir de una cadena SQL. Actualmente, solo se implementan objetos de sentencia simples, que deben ser sentencias completas que se puedan enviar a la base de datos con Stmt::execute(). Este método devuelve un objeto Result que encapsula uno o más conjuntos de resultados devueltos por la base de datos dependiendo de la sentencia enviada.

Cada conjunto de resultados debe recuperarse usando Result::getResult(), mientras que Result::getRows() obtiene una fila del conjunto de resultados actual si la sentencia era un tipo SELECT. De lo contrario, Result::rowsAffected() se puede usar para obtener el número de filas afectadas por la sentencia. Si la sentencia puede devolver filas, los métodos Result::columnName() y Result::columnType() son capaces de proporcionar información sobre las columnas indexadas de 0 a n. También es posible mapear el nombre de la columna con el método Result::columnPos() al índice de la columna que requieren los otros métodos de columna. Para obtener el valor real y la longitud del contenido en la fila actual en la posición dada, se deben llamar a Result::fieldValue() y Result::fieldLength().

En caso de que la biblioteca de base de datos subyacente requiera un manejo especial de objetos grandes (LOB binarios o de texto), el valor de Result::fieldValue() debe ser alimentado al método Result::getLob(). Devuelve un objeto Lob que permite a la aplicación leer y escribir en un objeto grande usando Lob::read() o Lob::write() respectivamente. Esto solo es necesario si el método Conn::getCapability() devuelve verdadero al preguntar por ODBX_CAP_LO.

Si ocurre un error en cualquiera de los métodos de los objetos, los objetos lanzarán una instancia de la clase Exception que extiende la excepción runtime_error de STL. La instancia contiene un mensaje de error, el código de error de OpenDBX y un tipo de error que indica la severidad del error. Esta información se puede recuperar mediante los métodos Exception::what(), Exception::getCode() y Exception::getType().
