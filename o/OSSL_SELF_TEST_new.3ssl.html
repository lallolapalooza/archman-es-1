OSSL_SELF_TEST_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_SELF_TEST_NEW(3ssl) OpenSSL OSSL_SELF_TEST_NEW(3ssl)

NOMBRE

OSSL_SELF_TEST_new, OSSL_SELF_TEST_free, OSSL_SELF_TEST_onbegin, OSSL_SELF_TEST_oncorrupt_byte, OSSL_SELF_TEST_onend - funcionalidad para disparar una llamada de retorno durante una auto-prueba

SINOPSIS

#include <openssl/self_test.h>
OSSL_SELF_TEST *OSSL_SELF_TEST_new(OSSL_CALLBACK *cb, void *cbarg);
void OSSL_SELF_TEST_free(OSSL_SELF_TEST *st);
void OSSL_SELF_TEST_onbegin(OSSL_SELF_TEST *st, const char *type,
                            const char *desc);
int OSSL_SELF_TEST_oncorrupt_byte(OSSL_SELF_TEST *st, unsigned char *bytes);
void OSSL_SELF_TEST_onend(OSSL_SELF_TEST *st, int ret);

DESCRIPCIÓN

Estos métodos están destinados a ser utilizados por implementadores de proveedores, para mostrar información de diagnóstico durante las auto-pruebas.

OSSL_SELF_TEST_new() asigna un objeto opaco OSSL_SELF_TEST que tiene una llamada de retorno y un argumento de llamada de retorno asociados a él.

La llamada de retorno cb puede ser disparada múltiples veces por una auto-prueba para indicar diferentes fases.

OSSL_SELF_TEST_free() libera el espacio asignado por OSSL_SELF_TEST_new(). Si el argumento es NULL, no se hace nada.

OSSL_SELF_TEST_onbegin() puede insertarse al inicio de un bloque de código de auto-prueba. Puede usarse con fines de diagnóstico. Si se llama a este método, la llamada de retorno cb recibirá el siguiente objeto OSSL_PARAM(3).

"st-phase" (OSSL_PROV_PARAM_SELF_TEST_PHASE) <cadena UTF8>
El valor es la cadena "Start"

OSSL_SELF_TEST_oncorrupt_byte() puede insertarse justo después de calcular la respuesta conocida, pero antes de que la auto-prueba compare el resultado. El primer byte del array de bytes proporcionado será corrompido si la llamada de retorno devuelve 0, de lo contrario, deja el array sin modificar. Puede usarse para pruebas de fallos. Los parámetros type y desc pueden usarse para identificar una auto-prueba individual a la que apuntar para pruebas de fallo. Si se llama a este método, la llamada de retorno cb recibirá el siguiente objeto OSSL_PARAM(3).

"st-phase" (OSSL_PROV_PARAM_SELF_TEST_PHASE) <cadena UTF8>
El valor es la cadena "Corrupt"

OSSL_SELF_TEST_onend() puede insertarse al final de un bloque de código de auto-prueba justo antes de la limpieza para indicar si la prueba pasó o falló. Puede usarse con fines de diagnóstico. Si se llama a este método, la llamada de retorno cb recibirá el siguiente objeto OSSL_PARAM(3).

"st-phase" (OSSL_PROV_PARAM_SELF_TEST_PHASE) <cadena UTF8>
El valor de la cadena es "Pass" si ret no es cero, de lo contrario, tiene el valor "Fail".

Después de que la llamada de retorno cb haya sido llamada, los valores que se establecieron con OSSL_SELF_TEST_onbegin() para type y desc se establecen al valor "None".

Si se llama a OSSL_SELF_TEST_onbegin(), OSSL_SELF_TEST_oncorrupt_byte() o OSSL_SELF_TEST_onend(), se pasan los siguientes OSSL_PARAM(3) adicionales a la llamada de retorno.

"st-type" (OSSL_PROV_PARAM_SELF_TEST_TYPE) <cadena UTF8>
El valor es configurado por el type pasado a OSSL_SELF_TEST_onbegin(). Esto permite a la llamada de retorno identificar el tipo de prueba que se está ejecutando.
"st-desc" (OSSL_PROV_PARAM_SELF_TEST_DESC) <cadena UTF8>
El valor es configurado por el type pasado a OSSL_SELF_TEST_onbegin(). Esto permite a la llamada de retorno identificar la subcategoría de la prueba que se está ejecutando.

VALORES DE RETORNO

OSSL_SELF_TEST_new() devuelve el objeto OSSL_SELF_TEST asignado, o NULL si falla.

OSSL_SELF_TEST_oncorrupt_byte() devuelve 1 si ocurre una corrupción, de lo contrario, devuelve 0.

EJEMPLOS

Una única auto-prueba podría configurarse de la siguiente manera:

  OSSL_SELF_TEST *st = NULL;
  OSSL_CALLBACK *cb;
  void *cbarg;
  int ok = 0;
  unsigned char out[EVP_MAX_MD_SIZE];
  unsigned int out_len = 0;
  EVP_MD_CTX *ctx = EVP_MD_CTX_new();
  EVP_MD *md = EVP_MD_fetch(libctx, t->algorithm, NULL);
  /*
   * Recupera la llamada de retorno - será NULL si no está configurada por la aplicación
   * a través de OSSL_SELF_TEST_set_callback().
   */
  OSSL_SELF_TEST_get_callback(libctx, &cb, &cbarg);
  st = OSSL_SELF_TEST_new(cb, cb_arg);
  /* Dispara la llamada de retorno opcional */
  OSSL_SELF_TEST_onbegin(st, OSSL_SELF_TEST_TYPE_KAT_DIGEST,
                         OSSL_SELF_TEST_DESC_MD_SHA2);
  if (!EVP_DigestInit_ex(ctx, md, NULL)
      || !EVP_DigestUpdate(ctx, pt, pt_len)
      || !EVP_DigestFinal(ctx, out, &out_len))
      goto err;
  /* Corrupción opcional - Si la llamada de retorno de la aplicación devuelve 0 */
  OSSL_SELF_TEST_oncorrupt_byte(st, out);
  if (out_len != t->expected_len
      || memcmp(out, t->expected, out_len) != 0)
      goto err;
  ok = 1;
err:
  OSSL_SELF_TEST_onend(st, ok);
  EVP_MD_free(md);
  EVP_MD_CTX_free(ctx);

Se pueden configurar múltiples auto-pruebas de manera similar repitiendo el patrón de OSSL_SELF_TEST_onbegin(), OSSL_SELF_TEST_oncorrupt_byte(), OSSL_SELF_TEST_onend() para cada prueba.
