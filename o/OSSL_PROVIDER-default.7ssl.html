NOMBRE

OSSL_PROVIDER-default - Proveedor predeterminado de OpenSSL

DESCRIPCIÓN

El proveedor predeterminado de OpenSSL suministra la mayoría de las diversas implementaciones de algoritmos de OpenSSL. Si una aplicación no especifica nada más explícitamente (por ejemplo, en la aplicación o a través de la configuración), este es el proveedor que se utilizará como respaldo: se carga automáticamente la primera vez que se obtiene un algoritmo de un proveedor o se llama a una función que actúa sobre proveedores y aún no se ha cargado ningún otro proveedor.

Si ya se ha intentado cargar un proveedor (ya sea con éxito o no), el proveedor predeterminado no se cargará automáticamente. Por lo tanto, si el proveedor predeterminado se va a utilizar junto con otros proveedores, debe cargarse explícitamente. La carga automática del proveedor predeterminado solo ocurre como máximo una vez; si el proveedor predeterminado se descarga explícitamente, no se volverá a cargar automáticamente.

Propiedades

Las implementaciones en este proveedor tienen específicamente definida esta propiedad:

"provider=default"

Puede usarse en una cadena de consulta de propiedades con funciones de obtención como EVP_MD_fetch(3) o EVP_CIPHER_fetch(3), así como con otras funciones que toman una cadena de consulta de propiedades, como EVP_PKEY_CTX_new_from_name(3).

No es obligatorio consultar esta propiedad, excepto para asegurarse de obtener implementaciones de este proveedor y ninguna otra.

Algunas implementaciones pueden definir propiedades adicionales. La información exacta se detalla a continuación

HISTORY

The RIPEMD160 digest was added to the default provider in OpenSSL 3.0.7.

The HKDF-SHA256, HKDF-SHA384 and HKDF-SHA512 algorithms were added in OpenSSL 3.6.

All other functionality was added in OpenSSL 3.0.
