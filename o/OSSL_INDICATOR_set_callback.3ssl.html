OSSL_INDICATOR_set_callback(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_INDICATOR_SET_CALLBACK(3ssl) OpenSSL OSSL_INDICATOR_SET_CALLBACK(3ssl)

NOMBRE

OSSL_INDICATOR_set_callback, OSSL_INDICATOR_get_callback - especificar una función de devolución de llamada para indicadores FIPS

SINOPSIS

#include <openssl/indicator.h>

typedef int (OSSL_INDICATOR_CALLBACK)(const char *type, const char *desc,
const OSSL_PARAM params[]);

void OSSL_INDICATOR_set_callback(OSSL_LIB_CTX *libctx,
                                 OSSL_INDICATOR_CALLBACK *cb);
void OSSL_INDICATOR_get_callback(OSSL_LIB_CTX *libctx,
                                 OSSL_INDICATOR_CALLBACK **cb);

DESCRIPCIÓN

OSSL_INDICATOR_set_callback() establece una función de devolución de llamada de usuario cb asociada con un libctx que se llamará cuando se detecte una operación FIPS no aprobada.

La función de devolución de llamada del usuario puede ser invocada múltiples veces durante la operación de un algoritmo para indicar que diferentes verificaciones de modo aprobado han fallado.

Las operaciones no aprobadas solo pueden ocurrir si el usuario ha elegido deliberadamente hacerlo (ya sea estableciendo una opción de configuración global de FIPS o a través de una opción en el contexto de operación de un algoritmo).

Los parámetros type y desc de la función de devolución de llamada del usuario contienen el tipo y la operación del algoritmo que no está aprobado. params no se utiliza actualmente.

Si la función de devolución de llamada del usuario devuelve 0, ocurrirá un error en el llamador. Esto se puede usar para fines de prueba.

VALORES DE RETORNO

OSSL_INDICATOR_get_callback() devuelve la función de devolución de llamada que se ha establecido mediante OSSL_INDICATOR_set_callback() para el contexto de biblioteca dado libctx, o NULL si actualmente no hay ninguna función de devolución de llamada establecida.

EJEMPLOS

Una función de devolución de llamada de indicador simple para registrar operaciones FIPS no aprobadas

 static int indicator_cb(const char *type, const char *desc,
                         const OSSL_PARAM params[])
 {
     if (type != NULL && desc != NULL)
         fprintf(stdout, "%s %s no está aprobado\n", type, desc);
end:
     /* Para fines de prueba, podrías devolver 0 aquí para causar un error */
     return 1;
 }
 OSSL_INDICATOR_set_callback(libctx, indicator_cb);
