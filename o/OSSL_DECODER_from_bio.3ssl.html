OSSL_DECODER_from_bio(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_DECODER_FROM_BIO(3ssl) OpenSSL OSSL_DECODER_FROM_BIO(3ssl)

NOMBRE

OSSL_DECODER_from_data, OSSL_DECODER_from_bio, OSSL_DECODER_from_fp - Rutinas para realizar una decodificación

SINOPSIS

#include <openssl/decoder.h>
int OSSL_DECODER_from_bio(OSSL_DECODER_CTX *ctx, BIO *in);
int OSSL_DECODER_from_fp(OSSL_DECODER_CTX *ctx, FILE *fp);
int OSSL_DECODER_from_data(OSSL_DECODER_CTX *ctx, const unsigned char **pdata,
                           size_t *pdata_len);

Macros de disponibilidad de características:

OSSL_DECODER_from_fp() solo está disponible cuando OPENSSL_NO_STDIO está indefinido.

DESCRIPCIÓN

OSSL_DECODER_from_data() ejecuta el proceso de decodificación para el contexto ctx, con la entrada proveniente de *pdata, con una longitud de *pdata_len bytes. Tanto *pdata como *pdata_len deben ser no nulos. Cuando OSSL_DECODER_from_data() retorna, *pdata se actualiza para apuntar a la ubicación después de lo que ha sido decodificado, y *pdata_len para tener el número de bytes restantes.

OSSL_DECODER_from_bio() ejecuta el proceso de decodificación para el contexto ctx, con la entrada proveniente del BIO in. Si llegara a marcar la diferencia, se recomienda tener el BIO configurado en modo binario en lugar de modo texto.

OSSL_DECODER_from_fp() hace lo mismo que OSSL_DECODER_from_bio(), excepto que la entrada proviene del FILE fp.

VALORES DE RETORNO

OSSL_DECODER_from_bio(), OSSL_DECODER_from_data() y OSSL_DECODER_from_fp() retornan 1 en caso de éxito, o 0 en caso de fallo.

EJEMPLOS

Para decodificar una clave RSA codificada con PEM desde un bio:

OSSL_DECODER_CTX *dctx;
EVP_PKEY *pkey = NULL;
const char *format = "PEM";   /* NULL para cualquier formato */
const char *structure = NULL; /* cualquier estructura */
const char *keytype = "RSA";  /* NULL para cualquier clave */
const unsigned char *pass = "mi contraseña";
dctx = OSSL_DECODER_CTX_new_for_pkey(&pkey, format, structure,
                                     keytype,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR,
                                     NULL, NULL);
if (dctx == NULL) {
    /* error: no se encontraron decodificadores potenciales adecuados */
}
if (pass != NULL)
    OSSL_DECODER_CTX_set_passphrase(dctx, pass, strlen(pass));
if (OSSL_DECODER_from_bio(dctx, bio)) {
    /* pkey se crea con los datos decodificados del bio */
} else {
    /* fallo de decodificación */
}
OSSL_DECODER_CTX_free(dctx);

Para decodificar una clave EC codificada con DER desde un buffer:

OSSL_DECODER_CTX *dctx;
EVP_PKEY *pkey = NULL;
const char *format = "DER";   /* NULL para cualquier formato */
const char *structure = NULL; /* cualquier estructura */
const char *keytype = "EC";   /* NULL para cualquier clave */
const unsigned char *pass = NULL
const unsigned char *data = buffer;
size_t datalen = sizeof(buffer);
dctx = OSSL_DECODER_CTX_new_for_pkey(&pkey, format, structure,
                                     keytype,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR
                                     | OSSL_KEYMGMT_SELECT_DOMAIN_PARAMETERS,
                                     NULL, NULL);
if (dctx == NULL) {
    /* error: no se encontraron decodificadores potenciales adecuados */
}
if (pass != NULL)
    OSSL_DECODER_CTX_set_passphrase(dctx, pass, strlen(pass));
if (OSSL_DECODER_from_data(dctx, &data, &datalen)) {
    /* pkey se crea con los datos decodificados del buffer */
} else {
    /* fallo de decodificación */
}
OSSL_DECODER_CTX_free(dctx);
