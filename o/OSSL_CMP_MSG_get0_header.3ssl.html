NOMBRE

OSSL_CMP_MSG_get0_header, OSSL_CMP_MSG_get_bodytype, OSSL_CMP_MSG_get0_certreq_publickey, OSSL_CMP_MSG_update_transactionID, OSSL_CMP_MSG_update_recipNonce, OSSL_CMP_CTX_setup_CRM, OSSL_CMP_MSG_read, OSSL_CMP_MSG_write, d2i_OSSL_CMP_MSG_bio, i2d_OSSL_CMP_MSG_bio - funciones que manipulan mensajes CMP

SINOPSIS

#include <openssl/cmp.h>
OSSL_CMP_PKIHEADER *OSSL_CMP_MSG_get0_header(const OSSL_CMP_MSG *msg);
int OSSL_CMP_MSG_get_bodytype(const OSSL_CMP_MSG *msg);
X509_PUBKEY *OSSL_CMP_MSG_get0_certreq_publickey(const OSSL_CMP_MSG *msg);
int OSSL_CMP_MSG_update_transactionID(OSSL_CMP_CTX *ctx, OSSL_CMP_MSG *msg);
int OSSL_CMP_MSG_update_recipNonce(OSSL_CMP_CTX *ctx, OSSL_CMP_MSG *msg);
OSSL_CRMF_MSG *OSSL_CMP_CTX_setup_CRM(OSSL_CMP_CTX *ctx, int for_KUR, int rid);
OSSL_CMP_MSG *OSSL_CMP_MSG_read(const char *file, OSSL_LIB_CTX *libctx, const char *propq);
int OSSL_CMP_MSG_write(const char *file, const OSSL_CMP_MSG *msg);
OSSL_CMP_MSG *d2i_OSSL_CMP_MSG_bio(BIO *bio, OSSL_CMP_MSG **msg);
int i2d_OSSL_CMP_MSG_bio(BIO *bio, const OSSL_CMP_MSG *msg);

DESCRIPCIÓN

OSSL_CMP_MSG_get0_header() devuelve la cabecera del mensaje CMP dado.

OSSL_CMP_MSG_get_bodytype() devuelve el tipo de cuerpo del mensaje CMP dado.

OSSL_CMP_MSG_get0_certreq_publickey() espera que msg sea un mensaje de solicitud de certificado y devuelve la clave pública en su plantilla de certificado si está presente.

OSSL_CMP_MSG_update_transactionID() actualiza el campo transactionID en la cabecera del mensaje dado según el CMP_CTX. Si ctx no contiene un ID de transacción, se crea uno nuevo antes. El mensaje se reprotege (si se requiere proteger las solicitudes).

OSSL_CMP_MSG_update_recipNonce() actualiza el campo recipNonce en la cabecera del mensaje dado según el CMP_CTX. El mensaje se reprotege (si se requiere proteger las solicitudes).

OSSL_CMP_CTX_setup_CRM() crea un mensaje de solicitud de certificado CRMF a partir de diversa información proporcionada en el argumento de contexto CMP ctx para incluirlo en un mensaje de solicitud CMP basado en detalles contenidos en ctx. El argumento rid define el identificador de solicitud a usar, que típicamente es 0.

El DN del sujeto incluido en la plantilla de certificado es el primer valor disponible de estos:

cualquier nombre de sujeto en ctx establecido a través de OSSL_CMP_CTX_set1_subjectName(3) - si es el DN NULL (es decir, cualquier secuencia vacía de RDNs), no se incluye ningún sujeto,
el campo de sujeto de cualquier CSR PKCS#10 establecido en ctx a través de OSSL_CMP_CTX_set1_p10CSR(3),
el campo de sujeto de cualquier certificado de referencia proporcionado en ctx (ver OSSL_CMP_CTX_set1_oldCert(3)), pero solo si for_KUR es distinto de cero o si ctx no incluye un Nombre Alternativo del Sujeto.

La clave pública incluida es el primer valor disponible de estos:

la clave pública derivada de cualquier clave establecida a través de OSSL_CMP_CTX_set0_newPkey(3),
la clave pública de cualquier CSR PKCS#10 proporcionado en ctx,
la clave pública de cualquier certificado de referencia proporcionado en ctx (ver OSSL_CMP_CTX_set1_oldCert(3)),
la clave pública derivada de cualquier clave privada del cliente establecida a través de OSSL_CMP_CTX_set1_pkey(3).

El conjunto de extensiones X.509 a incluir se calcula de la siguiente manera. Si hay un CSR PKCS#10 presente en ctx, las extensiones predeterminadas se toman de allí; de lo contrario, se toma el conjunto vacío como valor inicial. Si hay un certificado de referencia en ctx y contiene Nombres Alternativos del Sujeto (SANs) y OSSL_CMP_OPT_SUBJECTALTNAME_NODEFAULT no está establecido, estos anulan cualquier SAN del CSR PKCS#10. Las extensiones se aumentan o anulan aún más por cualquier extensión con los mismos OIDs incluida en el ctx a través de OSSL_CMP_CTX_set0_reqExtensions(3). Los SANs se anulan aún más por cualquier SAN incluido en ctx a través de OSSL_CMP_CTX_push1_subjectAltName(3). Finalmente, las políticas se anulan por cualquier política incluida en ctx a través de OSSL_CMP_CTX_push0_policy(3).

OSSL_CMP_CTX_setup_CRM() también establece el control regToken oldCertID para mensajes KUR utilizando el nombre del emisor y el número de serie del certificado de referencia, si está presente.

OSSL_CMP_MSG_read() carga un OSSL_CMP_MSG codificado en DER desde file.

OSSL_CMP_MSG_write() almacena el OSSL_CMP_MSG dado en file en codificación DER.

d2i_OSSL_CMP_MSG_bio() analiza un OSSL_CMP_MSG codificado en ASN.1 desde el BIO bio. Asigna un puntero a la nueva estructura a *msg si msg no es NULL.

i2d_OSSL_CMP_MSG_bio() escribe el OSSL_CMP_MSG msg en codificación ASN.1 al BIO bio.

NOTAS

CMP está definido en RFC 4210.

VALORES DEVUELTOS

OSSL_CMP_MSG_get0_header() devuelve el valor del puntero previsto como se describe arriba o NULL si la entrada correspondiente no existe y en caso de error.

OSSL_CMP_MSG_get_bodytype() devuelve el tipo de cuerpo o -1 en caso de error.

OSSL_CMP_MSG_get0_certreq_publickey() devuelve una clave pública o NULL en caso de error.

OSSL_CMP_CTX_setup_CRM() devuelve un puntero a un OSSL_CRMF_MSG en caso de éxito, NULL en caso de error.

d2i_OSSL_CMP_MSG_bio() devuelve el mensaje analizado o NULL en caso de error.

OSSL_CMP_MSG_read() y d2i_OSSL_CMP_MSG_bio() devuelven el mensaje CMP analizado o NULL en caso de error.

OSSL_CMP_MSG_write() devuelve el número de bytes codificados con éxito o un valor negativo si ocurre un error.

i2d_OSSL_CMP_MSG_bio(), OSSL_CMP_MSG_update_transactionID() y OSSL_CMP_MSG_update_recipNonce() devuelven 1 en caso de éxito, 0 en caso de error.

OSSL_CMP_MSG_get0_header

OSSL_CMP_MSG_get0_header - Obtiene el encabezado de un mensaje CMP.

NAME

OSSL_CMP_MSG_get0_header - Obtiene el encabezado de un mensaje CMP.

SYNOPSIS

#include <openssl/cmp.h>

const OSSL_CMP_MSG *OSSL_CMP_MSG_get0_header(const OSSL_CMP_MSG *msg);

DESCRIPTION

OSSL_CMP_MSG_get0_header() extrae y devuelve un puntero al encabezado de un mensaje CMP contenido en msg.

NOTES

El valor devuelto no debe ser liberado. Es un puntero a un campo interno de msg.

RETURN VALUES

Devuelve un puntero al encabezado del mensaje CMP, o NULL si msg es NULL o si el mensaje no contiene un encabezado.

SEE ALSO

OSSL_CMP_MSG_new(3ssl), OSSL_CMP_MSG_print(3ssl)

HISTORY

La función OSSL_CMP_MSG_get0_header() fue añadida en OpenSSL 3.0.
