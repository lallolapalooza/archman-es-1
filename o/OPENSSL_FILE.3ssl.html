OPENSSL_FILE(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL_FILE(3ssl) OpenSSL OPENSSL_FILE(3ssl)

NOMBRE

OPENSSL_FILE, OPENSSL_LINE, OPENSSL_FUNC, OPENSSL_MSTR, OPENSSL_MSTR_HELPER - macros de utilidad genéricos para programación en C

SINOPSIS

#include <openssl/macros.h>
#define OPENSSL_FILE /* típicamente: __FILE__ */
#define OPENSSL_LINE /* típicamente: __LINE__ */
#define OPENSSL_FUNC /* típicamente: __func__ */
#define OPENSSL_MSTR_HELPER(x) #x
#define OPENSSL_MSTR(x) OPENSSL_MSTR_HELPER(x)

DESCRIPCIÓN

Las macros OPENSSL_FILE y OPENSSL_LINE típicamente proporcionan el nombre del archivo y el número de línea actuales durante la compilación de C. Cuando OPENSSL_NO_FILENAMES está definido, proporcionan "" y 0, respectivamente.

La macro OPENSSL_FUNC intenta proporcionar el nombre de la función de C que se está compilando actualmente, en la medida en que lo permitan las versiones del lenguaje y del compilador. De lo contrario, proporciona "(función desconocida)".

La macro OPENSSL_MSTR proporciona la expansión de la macro dada como argumento, lo cual es útil para la concatenación con constantes de cadena. La macro OPENSSL_MSTR_HELPER es una macro auxiliar para este propósito.
