DESCRIPCIÓN

ITAV es abreviatura de InfoTypeAndValue.

OSSL_CMP_ITAV_new_caCerts() crea una estructura OSSL_CMP_ITAV de tipo caCerts y la llena con una copia de la lista de certificados proporcionada. El argumento caCerts puede ser NULL o contener cualquier número de certificados.

OSSL_CMP_ITAV_get0_caCerts() requiere que itav sea de tipo caCerts. Si no hay certificados en itav, asigna NULL a *out. De lo contrario, asigna el puntero interno de la estructura STACK_OF(X509) con los certificados presentes.

OSSL_CMP_ITAV_new_rootCaCert() crea una nueva estructura OSSL_CMP_ITAV de tipo rootCaCert que incluye el certificado opcionalmente dado.

OSSL_CMP_ITAV_get0_rootCaCert() requiere que itav sea de tipo rootCaCert. Si no hay certificado en itav, asigna NULL a *out. De lo contrario, asigna el puntero interno al certificado contenido en el campo infoValue.

OSSL_CMP_ITAV_new_rootCaKeyUpdate() crea una nueva estructura OSSL_CMP_ITAV de tipo rootCaKeyUpdate que incluye una estructura opcional RootCaKeyUpdateContent con los certificados newWithNew, newWithOld y oldWithNew. Se incluye una estructura RootCaKeyUpdateContent solo si newWithNew no es NULL.

OSSL_CMP_ITAV_get0_rootCaKeyUpdate() requiere que itav tenga el campo infoType rootCaKeyUpdate. Si hay una actualización de un certificado raíz, asigna a *newWithNew el puntero interno al certificado contenido en el subcampo newWithNew de itav. Si newWithOld no es NULL, asigna a *newWithOld el puntero interno al certificado contenido en el subcampo newWithOld de itav. Si oldWithNew no es NULL, asigna a *oldWithNew el puntero interno al certificado contenido en el subcampo oldWithNew de itav. Cada uno de estos punteros se establecerá a NULL si no hay ninguna actualización de certificado raíz o el subcampo respectivo no está incluido.

OSSL_CMP_CRLSTATUS_new1() asigna una nueva estructura de tipo CRLSTATUS que contiene una copia del nombre del punto de distribución dpn o del emisor issuer, pero ambos son un error. Si se proporciona, también incluye una copia del tiempo de emisión del CRL thisUpdate.

OSSL_CMP_CRLSTATUS_create() es una variante de alto nivel de OSSL_CMP_CRLSTATUS_new1(). Llena el campo thisUpdate con una copia del campo thisUpdate de crl si está presente. Llena el campo CRLSource con una copia del primer elemento encontrado usando los parámetros crl y/o cert, siguiendo la siguiente regla: cualquier nombre de punto de distribución es preferido sobre los nombres de emisor. Los datos de cert, si están presentes, son preferidos sobre los datos de crl. Si no hay nombres de punto de distribución, se utilizan nombres de emisor según los siguientes orígenes, según estén presentes:

la lista de puntos de distribución en la extensión cert
el campo issuer de la clave de firma de autoridad en cert
la DN del emisor de cert
el campo issuer de la clave de firma de autoridad en crl
la DN del emisor de crl

Si only_DN está establecido, solo se aceptan nombres de emisor de tipo GENERAL_NAMES si contienen exactamente un nombre de tipo directoryName.

OSSL_CMP_CRLSTATUS_get0() lee los campos de crlstatus y asigna los valores a *dpn, *issuer y *thisUpdate. *thisUpdate se asigna solo si el argumento thisUpdate no es NULL. Según esté presente, se elegirá entre *dpn o *issuer, pero solo uno de ellos será NULL. *thisUpdate también puede ser NULL si el campo no está presente.

OSSL_CMP_ITAV_new0_crlStatusList() crea una nueva estructura OSSL_CMP_ITAV de tipo crlStatusList que incluye la lista opcional de datos de estado de CRL, cada uno de tipo OSSL_CMP_CRLSTATUS.

OSSL_CMP_ITAV_get0_crlStatusList() en caso de éxito asigna a *out un puntero interno a la lista de datos de estado de CRL en el campo infoValue de itav. El puntero puede ser NULL si no se incluyen datos de estado de CRL. Es un error si el tipo de información de itav no es crlStatusList.

OSSL_CMP_ITAV_new_crls() crea una nueva estructura OSSL_CMP_ITAV de tipo crls que incluye una lista vacía de CRL si el argumento crl es NULL o incluye una lista singleton con una copia del CRL proporcionado opcionalmente.

OSSL_CMP_ITAV_get0_crls() en caso de éxito asigna a *out un puntero interno a la lista de CRLs contenidas en el campo infoValue de itav. El puntero puede ser NULL si no se incluye ningún CRL. Es un error si el tipo de información de itav no es crls.

OSSL_CMP_ITAV_new0_certReqTemplate() crea una estructura OSSL_CMP_ITAV de tipo certReqTemplate. Si certTemplate es NULL, keySpec también debe ser NULL, y el resultado se puede usar en un mensaje genm para solicitar las exigencias de la PKI sobre la plantilla de certificado utilizada para solicitar certificados, o en un mensaje genp que indique que no hay tales exigencias. De lo contrario, el resultado incluye una estructura CertReqTemplateValue con certTemplate de tipo OSSL_CRMF_CERTTEMPLATE y una lista opcional de especificaciones de clave keySpec, cada una de tipo OSSL_CMP_ATAV, y el resultado se puede usar en un mensaje genp para proporcionar las exigencias.
