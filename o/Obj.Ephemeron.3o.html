Efímero con aridad arbitraria y sin tipo

type obj_t = Obj.t

type t

un efímero cf Obj.Ephemeron

val create : int -> t

create n devuelve un efímero con n claves. Todas las claves y los datos están inicialmente vacíos. El argumento n debe estar entre cero y Obj.Ephemeron.max_ephe_length (límites incluidos).

devuelve el número de claves
