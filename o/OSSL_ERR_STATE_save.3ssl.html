OSSL_ERR_STATE_save(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_ERR_STATE_SAVE(3ssl) OpenSSL OSSL_ERR_STATE_SAVE(3ssl)

NOMBRE

OSSL_ERR_STATE_new, OSSL_ERR_STATE_save, OSSL_ERR_STATE_save_to_mark, OSSL_ERR_STATE_restore, OSSL_ERR_STATE_free - guardar y restaurar el estado de error

SINOPSIS

#include <openssl/err.h>
ERR_STATE *OSSL_ERR_STATE_new(void);
void OSSL_ERR_STATE_save(ERR_STATE *es);
void OSSL_ERR_STATE_save_to_mark(ERR_STATE *es);
void OSSL_ERR_STATE_restore(const ERR_STATE *es);
void OSSL_ERR_STATE_free(ERR_STATE *es);

DESCRIPCIÓN

Estas funciones guardan y restauran el estado de error del estado de error local del hilo a una estructura de estado de error preasignada.

OSSL_ERR_STATE_new() asigna una estructura de estado de error vacía para ser utilizada al guardar y restaurar el estado de error del hilo.

OSSL_ERR_STATE_save() guarda el estado de error del hilo en es. Posteriormente, borra el estado de error del hilo. Cualquier estado previamente guardado en es se borra antes de guardar el nuevo estado.

OSSL_ERR_STATE_save_to_mark() es similar a OSSL_ERR_STATE_save() pero solo guarda las entradas de ERR hasta la marca más reciente en la pila de ERR. Estas entradas se mueven a es y se eliminan del estado de error del hilo. Sin embargo, la ERR marcada más reciente y cualquier estado de ERR anterior permanecen como parte del estado de error del hilo y no se mueven a ERR_STATE. La marca no se borra y debe borrarse explícitamente después de una llamada a esta función usando ERR_pop_to_mark(3) o ERR_clear_last_mark(3). (Dado que una llamada a OSSL_ERR_STATE_save_to_mark() deja la ERR marcada como el error superior, cualquiera de estas funciones tendrá el mismo efecto.) Si no hay ninguna ERR marcada en el estado de error local del hilo, todas las entradas de ERR se copian y el efecto es el mismo que para una llamada a OSSL_ERR_STATE_save().

OSSL_ERR_STATE_restore() agrega todas las entradas de error del estado guardado es al estado de error del hilo. Las entradas existentes en el estado de error del hilo no se ven afectadas si hay suficiente espacio para todas las entradas agregadas. Cualquier dato asignado en las entradas de error guardadas se duplica al agregarse al estado del hilo.

OSSL_ERR_STATE_free() libera el estado de error guardado es. Si el argumento es NULL, no se hace nada.

VALORES DE RETORNO

OSSL_ERR_STATE_new() devuelve un puntero a la estructura ERR_STATE asignada o NULL si hay un error.

OSSL_ERR_STATE_save(), OSSL_ERR_STATE_save_to_mark(), OSSL_ERR_STATE_restore(), OSSL_ERR_STATE_free() no devuelven ningún valor.

NOTAS

OSSL_ERR_STATE_save() y OSSL_ERR_STATE_save_to_mark() no pueden fallar, ya que se apropian de cualquier dato asignado del estado de error del hilo.

OSSL_ERR_STATE_restore() es una función de "mejor esfuerzo". El único fallo que puede ocurrir durante su operación es cuando la asignación de memoria falla. Debido a que manipula el estado de error del hilo, evita generar errores de memoria en caso de fallo. En el peor de los casos, faltarán los datos de error auxiliares en las entradas de error restauradas.

VER TAMBIÉN

ERR_raise(3), ERR_get_error(3), ERR_clear_error(3)

HISTORIA

Todas estas funciones se agregaron en OpenSSL 3.2.
