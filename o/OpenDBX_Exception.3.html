Descripción detallada

Excepciones lanzadas por las clases de OpenDBX.

La mayoría de las llamadas a métodos de objetos OpenDBX lanzan una excepción en caso de que ocurra un error en la biblioteca de base de datos subyacente. Además de otras excepciones que heredan de la clase de excepción STL, no solo contendrá un mensaje de error traducido dependiendo de la configuración del usuario, sino también un código de error legible por máquina y un indicador de la severidad del error.

OpenDBX::Exception::Exception (const string & msg, int err, int type)

Inicializa el objeto de excepción. El primer parámetro, el mensaje de error, debe ser la descripción legible por humanos de lo que ha ido mal. También debe estar ya traducido al idioma del usuario, lo que depende de la configuración de su entorno cuando, por ejemplo, se utiliza GNU gettext. Los errores lanzados por la biblioteca C++ OpenDBX ya están traducidos.

El código de error de OpenDBX es el código legible por máquina para el error que ha ocurrido.

El último parámetro debe ser un valor que indique la severidad del error lanzado. Si el valor es menor que cero, el error es fatal y la conexión a la base de datos no se puede recuperar y debe cerrarse y volver a abrirse antes de que la aplicación pueda intentar continuar. En caso de que sea mayor que cero, la operación falló pero la conexión a la base de datos aún es utilizable. Cero representa una operación exitosa y no debe usarse, ya que una excepción solo debe lanzarse en condiciones de error.

Parámetros

msg Mensaje de error legible por humanos
err Código de error de OpenDBX
type Severidad del error (negativo: fatal, cero: éxito, positivo: advertencia)

int OpenDBX::Exception::getCode () const

Devuelve el código de error de OpenDBX relacionado con el error. El código legible por máquina que describe el error ocurrido puede ser utilizado por la aplicación para actuar de manera diferente según el error específico. Los códigos definidos actualmente son:

  • ODBX_ERR_SUCCESS
    La operación se completó con éxito.
  • ODBX_ERR_BACKEND
    Ocurrió un error en la biblioteca de base de datos nativa o en el servidor de base de datos.
  • ODBX_ERR_NOCAP
    La capacidad no está disponible en el backend actualmente seleccionado.
  • ODBX_ERR_PARAM
    Uno de los parámetros dados no es válido y no coincide con las expectativas.
  • ODBX_ERR_NOMEM
    Ocurrió una condición de falta de memoria.
  • ODBX_ERR_SIZE
    La memoria asignada internamente no es capaz de almacenar el valor.
  • ODBX_ERR_NOTEXIST
    La biblioteca de backend no se encontró o la carga de la biblioteca falló.
  • ODBX_ERR_NOOP
    La función requerida no está disponible o la operación no es posible en este backend.
  • ODBX_ERR_OPTION
    La opción dada es desconocida y, por lo tanto, no válida.
  • ODBX_ERR_OPTRO
    La opción solicitada es de solo lectura y su valor no se puede cambiar.
  • ODBX_ERR_OPTWR
    Establecer la opción dada a su nuevo valor falló.
  • ODBX_ERR_RESULT
    Esperar el conjunto de resultados después de enviar una declaración al servidor de base de datos falló.
  • ODBX_ERR_NOTSUP
    La funcionalidad solicitada no está soportada por el backend.
  • ODBX_ERR_HANDLE
    La estructura de datos interna que debería almacenar los detalles para acceder a la base de datos no es válida.

Devuelve

Código de error

int OpenDBX::Exception::getType () const

Devuelve el indicador de severidad. El valor devuelto clasifica el error lanzado. En caso de que sea negativo, el error es fatal (por ejemplo, se pierde la conexión con la base de datos) y la aplicación no puede continuar sin cerrar y reabrir la conexión.

Si el valor es positivo, la base de datos no pudo realizar la acción solicitada pero la conexión sigue estando bien y se puede utilizar para enviar más solicitudes a la base de datos. En cero, todo fue exitoso y no ocurrió ningún error. Esto no debería suceder al capturar una de estas excepciones.

Devuelve

Severidad del error (negativo: fatal, cero: éxito, positivo: advertencia)
