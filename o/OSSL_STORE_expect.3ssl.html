OSSL_STORE_expect(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_STORE_EXPECT(3ssl) OpenSSL OSSL_STORE_EXPECT(3ssl)

NOMBRE

OSSL_STORE_expect, OSSL_STORE_supports_search, OSSL_STORE_find - Especificar qué tipo de objeto se espera

SINOPSIS

#include <openssl/store.h>
int OSSL_STORE_expect(OSSL_STORE_CTX *ctx, int expected_type);
int OSSL_STORE_supports_search(OSSL_STORE_CTX *ctx, int criterion_type);
int OSSL_STORE_find(OSSL_STORE_CTX *ctx, OSSL_STORE_SEARCH *search);

DESCRIPCIÓN

OSSL_STORE_expect() ayuda a las aplicaciones a filtrar lo que OSSL_STORE_load() devuelve especificando un tipo de OSSL_STORE_INFO. Por defecto, no se hacen expectativas sobre los tipos de objetos a cargar. expected_type puede ser 0 para indicar explícitamente que no hay expectativa, o puede ser cualquiera de los tipos de objetos conocidos (ver "OBJETOS SOPORTADOS" en OSSL_STORE_INFO(3)) excepto OSSL_STORE_INFO_NAME. Por ejemplo, si "file:/foo/bar/store.pem" contiene varios objetos de diferente tipo y solo los certificados son de interés, la aplicación puede simplemente decir que espera el tipo OSSL_STORE_INFO_CERT.

OSSL_STORE_find() ayuda a las aplicaciones a especificar un criterio para una búsqueda más detallada de objetos.

OSSL_STORE_supports_search() comprueba si el cargador del contexto OSSL_STORE dado soporta el tipo de búsqueda dado. Ver "TIPOS DE CRITERIOS SOPORTADOS" en OSSL_STORE_SEARCH(3) para información sobre los tipos de criterios de búsqueda soportados.

OSSL_STORE_expect() y OSSL_STORE_find deben ser llamados antes de la primera OSSL_STORE_load() de una sesión dada, o fallarán.

NOTAS

Si se requiere un filtro más elaborado por la aplicación, una mejor opción sería usar una función de post-procesamiento. Ver OSSL_STORE_open(3) para más información.

Sin embargo, algunos cargadores pueden aprovechar el conocimiento de un tipo esperado para hacer la recuperación de objetos más eficiente, por lo que si se espera un solo tipo, este método es generalmente preferible.

VALORES DE RETORNO

OSSL_STORE_expect() devuelve 1 en caso de éxito, o 0 en caso de fallo.

OSSL_STORE_supports_search() devuelve 1 si el criterio es soportado, o 0 en caso contrario.

OSSL_STORE_find() devuelve 1 en caso de éxito, o 0 en caso de fallo.

VER TAMBIÉN

ossl_store(7), OSSL_STORE_INFO(3), OSSL_STORE_SEARCH(3), OSSL_STORE_load(3)

HISTORIA

OSSL_STORE_expect(), OSSL_STORE_supports_search() y OSSL_STORE_find() se añadieron en OpenSSL 1.1.1.
