Object::Event(3pm) Documentación Perl contribuida por el usuario Object::Event(3pm)

NOMBRE

Object::Event - Una clase que proporciona una interfaz de devolución de llamada de eventos

VERSIÓN

Versión 1.23

SINOPSIS

package foo;
use Object::Event;
our @ISA = qw/Object::Event/;
package main;
my $o = foo->new;
my $regguard = $o->reg_cb (foo => sub {
   print "Recibí un evento, con estos argumentos: $_[1], $_[2], $_[3]\n";
});
$o->event (foo => 1, 2, 3);
$o->unreg_cb ($regguard);
# o simplemente:
$regguard = undef;

DESCRIPCIÓN

Este módulo fue escrito principalmente para AnyEvent::XMPP, AnyEvent::IRC, AnyEvent::HTTPD y BK para proporcionar una API consistente para registrar y emitir eventos. Aunque originalmente lo escribí para esos módulos, lo publiqué por separado en caso de que alguien encuentre útil este módulo.

Para un manejo de eventos más completo, consulta también Glib y POE.

Esta clase proporciona una forma sencilla de extender una clase, heredando de esta clase, con una interfaz de devolución de llamada de eventos.

Podrás registrar devoluciones de llamada para eventos, identificados por sus nombres (una cadena) y llamarlos más tarde invocando el método "event" con el nombre del evento y algunos argumentos.

Incluso hay una azúcar sintáctica que permite llamar a métodos en las instancias de clases derivadas de Object::Event para invocar eventos. Para esta característica, consulta la sección "MÉTODOS DE EVENTOS" de este documento.

RENDIMIENTO

En la primera versión presentada aquí, no se han aplicado optimizaciones especiales de rendimiento. Así que ten cuidado de que sea lo suficientemente rápido para tus propósitos. Al menos para módulos como AnyEvent::XMPP, la sobrecarga probablemente no sea perceptible, ya que otras tecnologías como XML ya desperdician muchos más ciclos de CPU. Además, la E/S suele introducir sobrecargas _mucho_ mayores/más largas que esta simple interfaz de eventos.

FUNCIONES

Object::Event::register_priority_alias ($alias, $priority)
Esta función de paquete añadirá un alias de prioridad global. Si $priority es indefinido, el alias se eliminará.

Hay 4 alias predefinidos:

before     =>  1000
ext_before =>   500
ext_after  =>  -500
after      => -1000

Ver también el método "reg_cb" para más información sobre los alias.

MÉTODOS

Object::Event->new (%args)
Tu::Subclase::De::Object::Event->new (%args)
Este es el constructor para Object::Event, creará una referencia de hash bendecida inicializada con %args.
$obj->init_object_events ()
Este método solo debe llamarse si no puedes llamar al constructor "new" de esta clase. Entonces necesitas llamar a este método para inicializar el sistema de eventos.
$obj->set_exception_cb ($cb->($excepcion, $nombre_evento))
Este método instala una devolución de llamada que se llamará cuando otra devolución de llamada de evento lance una excepción. El primer argumento para $cb será la excepción y el segundo el nombre del evento.
$guard = $obj->reg_cb ($nombre_evento => $cb->($obj, @args), ...)
$guard = $obj->reg_cb ($nombre_evento => $prio, $cb->($obj, @args), ...)
Este método registra una devolución de llamada $cb1 para el evento con el nombre $nombre_evento1. También puedes pasar múltiples pares de nombre_evento => devolución_de_llamada.

El valor de retorno $guard será un guard que representa el conjunto de devoluciones de llamada que has instalado. Puedes simplemente "olvidar" el contenido de $guard para anular el registro de las devoluciones de llamada o llamar a "unreg_cb" con esa ID para eliminar esas devoluciones de llamada de nuevo. Si "reg_cb" se llama en un contexto vacío, no se devuelve ningún guard y no tienes forma de anular el registro de las devoluciones de llamada registradas.

El primer argumento para las devoluciones de llamada registradas con la función "reg_cb" será siempre el objeto maestro $obj.

Los valores de retorno de las devoluciones de llamada se ignoran. Si necesitas pasar alguna información desde un manejador al llamador del evento, tienes que establecer tu propio "protocolo" para hacerlo. Recomiendo pasar una referencia de array a los manejadores:

$obj->reg_cb (event_foobar => sub {
   my ($self, $resultados) = @_;
   push @$resultados, time / 30;
});
my @resultados;
$obj->event (event_foobar => \@resultados);
for (@resultados) {
   # ...
}

El orden de las devoluciones de llamada en la cadena de llamadas del evento depende de su prioridad. Si no especificaste ninguna prioridad (ver abajo), obtienen la prioridad predeterminada de 0 y se añaden a las otras devoluciones de llamada de prioridad 0. Cuanto mayor sea el número de prioridad, antes se llamarán las devoluciones de llamada en la cadena.

Si $nombre_evento1 comienza con 'before_', la devolución de llamada recibe una prioridad de 1000, y si comienza con 'ext_before_', recibe la prioridad 500. 'after_' se mapea a la prioridad -1000 y 'ext_after_' a -500.

Si deseas un control más detallado, puedes pasar una referencia de array en lugar del nombre del evento:

($nombre_evento1, $prio) = ('test_abc', 100);
$obj->reg_cb ([$nombre_evento1, $prio] => sub {
   ...
});
$obj->unreg_cb ($cb)
Elimina la devolución de llamada $cb del conjunto de devoluciones de llamada registradas.
mi $manejado = $obj->event ($nombre_evento, @args)
Emite el evento $nombre_evento y pasa los argumentos @args a las devoluciones de llamada. El valor de retorno $manejado es un valor verdadero en caso de que algún manejador fuera encontrado y ejecutado. Devuelve falso si no se encontró ningún manejador (ver también el método "handles" a continuación). Básicamente: Devuelve el mismo valor que el método "handles".

Ten en cuenta que un evento puede ser detenido y reinvocado mientras está siendo manejado.

Ver también la especificación de los eventos before y after en "reg_cb" arriba.

NOTA: Cada vez que se emite un evento, se utilizará el conjunto actual de devoluciones de llamada registradas para ese evento. Por lo tanto, si registras otra devolución de llamada de evento para el mismo evento que se está ejecutando en este momento, se llamará la **próxima** vez que se emita el evento. Ejemplo:

$obj->reg_cb (event_test => sub {
   my ($obj) = @_;
   print "Test1\n";
   $obj->unreg_me;
   $obj->reg_cb (event_test => sub {
      my ($obj) = @_;
      print "Test2\n";
      $obj->unreg_me;
   });
});
$obj->event ('event_test'); # imprime "Test1"
$obj->event ('event_test'); # imprime "Test2"
mi $booleano = $obj->handles ($nombre_evento)
Este método devuelve verdadero si se ha configurado algún manejador de eventos para el evento $nombre_evento.

Devuelve falso si no es así.

$obj->nombre_evento
Devuelve el nombre del evento que se está ejecutando actualmente.
$obj->unreg_me
Anula el registro de la devolución de llamada que se está ejecutando actualmente.
$continuar_cb = $obj->stop_event
Este método detiene la ejecución de las devoluciones de llamada del evento actual y devuelve (en contexto no vacío) una devolución de llamada que permitirá continuar la ejecución.
$obj->add_forward ($obj, $cb)
¡OBSOLETO: No lo uses! Solo para compatibilidad hacia atrás con AnyEvent::XMPP versión 0.4.
$obj->remove_forward ($obj)
¡OBSOLETO: No lo uses! Solo para compatibilidad hacia atrás con AnyEvent::XMPP versión 0.4.
$obj->remove_all_callbacks ()
Este método elimina

Object::Event(3pm)

NAME

Object::Event - A simple event handling mechanism for Perl objects

VERSION

1.23

SYNOPSIS

  package MyObject;
  use base qw/Object::Event/;

  sub _init {
    my $self = shift;
    $self->event_register('click', \&on_click);
    $self->event_register('move', $self->can('on_move'));
    $self->event_register('resize', sub { print "resizing!\n" });
  }

  sub on_click {
    my $self = shift;
    print "object clicked!\n";
  }

  package main;
  my $obj = MyObject->new;
  $obj->event('click');   # prints 'object clicked!'
  $obj->event('move');    # prints 'object clicked!'
  $obj->event('resize');  # prints 'resizing!'

  # Using static event handlers
  package MyObject2;
  use base qw/Object::Event/;
  sub test : event_cb { print "test event handler!\n" }
  package main;
  my $o = MyObject2->new;
  $o->test ();        # prints 'test event handler!'
  $o->event ('test'); # also prints 'test event handler!'

DESCRIPTION

Object::Event is a simple base class that provides an object-oriented event handling mechanism. It allows you to register callbacks for specific events and then trigger those events.

The main idea is to separate the code that causes an event (e.g. a button click) from the code that reacts to it (e.g. updating the GUI).

Events are identified by names, which are typically strings. Callbacks can be subroutines (references to subroutines), method names (as returned by can()), or coderefs.

Object::Event offers two ways to define event handlers:

  • Registering handlers dynamically using event_register() and event_unregister(). This is useful when you want to add or remove handlers at runtime.
  • Defining handlers statically using Perl's attributes. This is useful for defining event handlers that are part of the class definition itself. See EVENT METHODS.

The method event() is used to trigger an event. All registered callbacks for that event will be executed in the order they were registered.

The base class also supports multiple inheritance. If you inherit from Object::Event, the constructor (_init) will be called automatically after the object has been created.

PERFORMANCE

The overhead of this module is minimal. The performance critical part is the invocation of the event handlers, which is basically a subroutine call.

If you are registering a very large number of event handlers, you might want to consider alternatives. However, for most common use cases, this module should be perfectly adequate.

FUNCTIONS

$obj->event_register($event_name, $callback)
Registers a callback for a given event name. The callback can be a subroutine reference, a method name (as returned by can()), or a code reference. The callbacks are executed in the order they are registered.
$obj->event_unregister($event_name, $callback)
Unregisters a specific callback for a given event name. If multiple callbacks are registered for the same event, only the specified callback is removed.
$obj->event_unregister_all($event_name)
Unregisters all callbacks for a given event name.
$obj->event_registered($event_name)
Returns true if the event name has any registered callbacks, false otherwise.
$obj->event_callbacks($event_name)
Returns a list of all registered callbacks for the given event name.

METHODS

$obj = Class->new(...)
Creates a new object. If the class has an _init method, it will be called automatically after the object is created.
$obj->event($event_name, @args)
Triggers the specified event. All registered callbacks for that event will be executed in the order they were registered, with the object itself passed as the first argument, followed by any additional arguments @args.
$obj->event_as_string_dump()
This method returns a string dump of all registered event callbacks. This method is only for debugging purposes.

EVENT METHODS

You can define static methods in a package that act as event handler. This is done by using Perl's attributes functionality. To make a method act as event handler you need to add the "event_cb" attribute to it.

NOTE: Please note that for this to work the methods need to be defined at compile time. This means that you are not able to add event handles using "AUTOLOAD"!

NOTE: Perl's attributes have a very basic syntax, you have to take care to not insert any whitespace, the attribute must be a single string that contains no whitespace. That means: "event_cb (1)" is not the same as event_cb(1)!

Here is an example:

package foo;
use base qw/Object::Event/;
sub test : event_cb { print "test event handler!\n" }
package main;
my $o = foo->new;
$o->test ();        # prints 'test event handler!'
$o->event ('test'); # also prints 'test event handler!'!

In case you want to set a priority use this syntax:

sub test : event_cb(-1000) { ... }

Or:

sub test : event_cb(after) { ... }

You may want to have a look at the tests of the Object::Event distribution for more examples.

ALIASES

If you want to define multiple event handlers as package method you can use the "event_cb" attribute with an additional argument:

package foo;
use base qw/Object::Event/;
sub test : event_cb { # default prio is always 0
   print "middle\n";
}
sub test_last : event_cb(-1,test) {
   print "after\n";
}
sub test_first : event_cb(1,test) {
   print "before\n";
}
package main;
my $o = foo->new;
$o->test ();        # prints "after\n" "middle\n" "before\n"
$o->event ('test'); # prints the same
$o->test_first ();  # also prints the same

NOTE: Please note that if you don't provide any order the methods are sorted alphabetically:

package foo;
use base qw/Object::Event/;
sub test : event_cb { # default prio is always 0
   print "middle\n";
}
sub x : event_cb(, test) { # please note the empty element before the ','!
   print "after\n";
}
sub a : event_cb(, test) {
   print "before\n";
}
package main;
my $o = foo->new;
$o->test ();        # prints "after\n" "middle\n" "before\n"
$o->event ('test'); # prints the same
$o->x ();           # also prints the same

ALIAS ORDERING

The ordering of how the methods event handlers are called if they are all defined for the same event is strictly defined:

1.
Ordering of the methods for the same event in the inheritance hierarchy is always dominated by the priority of the event callback.
2.
Then if there are multiple methods with the same priority the place in the inheritance hierarchy defines in which order the methods are executed. The higher up in the hierarchy the class is, the earlier it will be called.
3.
Inside a class the name of the method for the event decides which event is executed first. (All if the priorities are the same)

DEBUGGING

There exists a package global variable called $DEBUG that control debugging capabilities.

Set it to 1 to produce a slightly extended "events_as_string_dump" output.

Set it to 2 and all events will be dumped in a tree of event invocations.

You can set the variable either in your main program:

$Object::Event::DEBUG = 2;

Or use the environment variable "PERL_OBJECT_EVENT_DEBUG":

export PERL_OBJECT_EVENT_DEBUG=2
