OSSL_CRMF_pbmp_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_CRMF_PBMP_NEW(3ssl) OpenSSL OSSL_CRMF_PBMP_NEW(3ssl)

NOMBRE

OSSL_CRMF_pbm_new, OSSL_CRMF_pbmp_new - funciones para producir MAC basado en contraseña (PBM)

SINOPSIS

#include <openssl/crmf.h>
int OSSL_CRMF_pbm_new(OSSL_LIB_CTX *libctx, const char *propq,
                      const OSSL_CRMF_PBMPARAMETER *pbmp,
                      const unsigned char *msg, size_t msglen,
                      const unsigned char *sec, size_t seclen,
                      unsigned char **mac, size_t *maclen);
OSSL_CRMF_PBMPARAMETER *OSSL_CRMF_pbmp_new(OSSL_LIB_CTX *libctx, size_t saltlen,
                                           int owfnid, size_t itercnt,
                                           int macnid);

DESCRIPCIÓN

OSSL_CRMF_pbm_new() genera un PBM (MAC basado en contraseña) basado en los parámetros PBM dados pbmp, mensaje msg y secreto sec, junto con las longitudes respectivas msglen y seclen. Los parámetros opcionales de contexto de biblioteca libctx y propq pueden usarse para influir en la selección del algoritmo MAC al que se hace referencia en pbmp; consulte "EXTRACCIÓN DE ALGORITMOS" en crypto(7) para más información. En caso de éxito, escribe la dirección del MAC recién asignado a través del parámetro de referencia mac y escribe la longitud a través del parámetro de referencia maclen, a menos que sea NULL.

OSSL_CRMF_pbmp_new() inicializa y devuelve una nueva estructura PBMParameter con una nueva sal aleatoria de longitud dada saltlen, NID de OWF (función de un solo sentido) owfnid, recuento de iteraciones de OWF itercnt y NID de MAC macnid. El parámetro de contexto de biblioteca libctx puede usarse para seleccionar el proveedor para la generación de números aleatorios (DRBG) y puede ser NULL para el valor predeterminado.

NOTAS

Los algoritmos para la OWF (función de un solo sentido) y para el MAC (código de autenticación de mensajes) pueden ser cualquiera con un NID definido en <openssl/objects.h>. Según lo especificado por RFC 4210, estos deben incluir NID_hmac_sha1.

RFC 4210 recomienda que la sal DEBERÍA tener al menos 8 bytes (64 bits) de longitud, siendo 16 bytes común.

El recuento de iteraciones debe ser al menos 100, según lo estipulado por RFC 4211, y se limita a un máximo de 100000 para evitar DoS a través de entradas manipuladas o mal formadas.

VALORES DE RETORNO

OSSL_CRMF_pbm_new() devuelve 1 en caso de éxito, 0 en caso de error.

OSSL_CRMF_pbmp_new() devuelve una estructura OSSL_CRMF_PBMPARAMETER nueva e inicializada, o NULL en caso de error.

EJEMPLOS

OSSL_CRMF_PBMPARAMETER *pbm = NULL;
unsigned char *msg = "Hola";
unsigned char *sec = "SeCrEt";
unsigned char *mac = NULL;
size_t maclen;
if ((pbm = OSSL_CRMF_pbmp_new(16, NID_sha256, 500, NID_hmac_sha1) == NULL))
    goto err;
if (!OSSL_CRMF_pbm_new(pbm, msg, 5, sec, 6, &mac, &maclen))
    goto err;
