OCSP_REQUEST_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OCSP_REQUEST_NEW(3ssl) OpenSSL OCSP_REQUEST_NEW(3ssl)

NOMBRE

OCSP_REQUEST_new, OCSP_REQUEST_free, OCSP_request_add0_id, OCSP_request_sign, OCSP_request_add1_cert, OCSP_request_onereq_count, OCSP_request_onereq_get0 - funciones de solicitud OCSP

SINOPSIS

#include <openssl/ocsp.h>
OCSP_REQUEST *OCSP_REQUEST_new(void);
void OCSP_REQUEST_FREE(OCSP_REQUEST *req);
OCSP_ONEREQ *OCSP_request_add0_id(OCSP_REQUEST *req, OCSP_CERTID *cid);
int OCSP_request_sign(OCSP_REQUEST *req,
                      X509 *signer, EVP_PKEY *key, const EVP_MD *dgst,
                      STACK_OF(X509) *certs, unsigned long flags);
int OCSP_request_add1_cert(OCSP_REQUEST *req, X509 *cert);
int OCSP_request_onereq_count(OCSP_REQUEST *req);
OCSP_ONEREQ *OCSP_request_onereq_get0(OCSP_REQUEST *req, int i);

DESCRIPCIÓN

OCSP_REQUEST_new() asigna y devuelve una estructura OCSP_REQUEST vacía.

OCSP_REQUEST_free() libera la estructura de solicitud req. Si el argumento es NULL, no se hace nada.

OCSP_request_add0_id() añade el identificador de certificado cid a req. Devuelve la estructura OCSP_ONEREQ añadida para que una aplicación pueda añadir extensiones adicionales a la solicitud. El parámetro id NO DEBE liberarse después de la operación.

OCSP_request_sign() firma la solicitud OCSP req utilizando el certificado signer, la clave privada key, el digest dgst y los certificados adicionales certs. Si la opción flags OCSP_NOCERTS está establecida, no se incluirán certificados en la solicitud.

OCSP_request_add1_cert() añade el certificado cert a la solicitud req. La aplicación es responsable de liberar cert después de su uso.

OCSP_request_onereq_count() devuelve el número total de estructuras OCSP_ONEREQ en req.

OCSP_request_onereq_get0() devuelve un puntero interno a la OCSP_ONEREQ contenida en req con índice i. El valor del índice i va de 0 a OCSP_request_onereq_count(req) - 1.

VALORES DE RETORNO

OCSP_REQUEST_new() devuelve una estructura OCSP_REQUEST vacía o NULL si ocurrió un error.

OCSP_request_add0_id() devuelve la estructura OCSP_ONEREQ que contiene cid o NULL si ocurrió un error.

OCSP_request_sign() y OCSP_request_add1_cert() devuelven 1 para éxito y 0 para fallo.

OCSP_request_onereq_count() devuelve el número total de estructuras OCSP_ONEREQ en req y -1 en caso de error.

OCSP_request_onereq_get0() devuelve un puntero a una estructura OCSP_ONEREQ o NULL si el valor del índice está fuera de rango.

NOTAS

Una estructura de solicitud OCSP contiene una o más estructuras OCSP_ONEREQ correspondientes a cada certificado.

OCSP_request_onereq_count() y OCSP_request_onereq_get0() son utilizados principalmente por los respondedores OCSP.

EJEMPLOS

Crear una estructura OCSP_REQUEST para el certificado cert con emisor issuer:

OCSP_REQUEST *req;
OCSP_ID *cid;
req = OCSP_REQUEST_new();
if (req == NULL)
   /* error */
cid = OCSP_cert_to_id(EVP_sha1(), cert, issuer);
if (cid == NULL)
   /* error */
if (OCSP_REQUEST_add0_id(req, cid) == NULL)
   /* error */
/* Hacer algo con req, p. ej., consultar al respondedor */
OCSP_REQUEST_free(req);
