Destruye una instancia Result si no hay otras referencias. Cada objeto de resultado usa un contador de referencias para recordar si las variables internas están compartidas con otros objetos. odbxtype OpenDBX::Result::fieldtype (unsigned long pos)

Returns the data type of the column at the given position pos in the current row which was retrieved by the latest call to getRow().

Possible values for the returned data type are:

Numeric values:

  • ODBX_TYPE_REAL: Valores numéricos aproximados (con signo) con 32 bits de precisión
  • ODBX_TYPE_DOUBLE: Valores numéricos aproximados (con signo) con 64 bits de precisión
  • ODBX_TYPE_FLOAT: Valores numéricos aproximados (con signo) con precisión definida por el usuario

Valores de cadena:

  • ODBX_TYPE_CHAR: Número fijo de caracteres
  • ODBX_TYPE_NCHAR: Número fijo de caracteres utilizando un conjunto de caracteres nacional
  • ODBX_TYPE_VARCHAR: Número variable de caracteres
  • ODBX_TYPE_NVARCHAR: Número variable de caracteres utilizando un conjunto de caracteres nacional

Objetos grandes:

  • ODBX_TYPE_CLOB: Objeto de texto grande
  • ODBX_TYPE_NCLOB: Objeto de texto grande utilizando un conjunto de caracteres nacional
  • ODBX_TYPE_XML: Árbol XML en formato de texto
  • ODBX_TYPE_BLOB: Objeto binario grande

Valores de fecha y hora:

  • ODBX_TYPE_TIME: Hora incluyendo horas, minutos y segundos
  • ODBX_TYPE_TIME_TZ: Hora con información de zona horaria
  • ODBX_TYPE_TIMESTAMP: Fecha y hora
  • ODBX_TYPE_TIMESTAMP_TZ: Fecha y hora con información de zona horaria
  • ODBX_TYPE_DATE: Fecha incluyendo año, mes y día
  • ODBX_TYPE_INTERVAL: Intervalo de fecha

Arrays y conjuntos:

  • ODBX_TYPE_ARRAY: Array de valores
  • ODBX_TYPE_MULTISET: Arrays asociativos

Enlaces externos:

•
ODBX_TYPE_DATALINK: Localizadores URI como enlaces URL

Los tipos de datos proporcionados por las implementaciones de base de datos que no están cubiertos por el estándar SQL2003 se agrupan como ODBX_TYPE_UNKNOWN.

const char * OpenDBX::Result::fieldValue (unsigned long pos)

Devuelve un puntero al contenido en la fila actual en la posición especificada. Esta función devuelve un puntero a los datos del campo especificado por el índice de columna pos. El campo es parte de la fila actual que fue recuperada por la última llamada a getRow(). Todos los valores excepto los objetos binarios se devuelven como cadenas terminadas por el carácter nulo. Esto también se aplica a valores numéricos, fechas, etc. Deben convertirse a su representación binaria dependiente de la máquina antes de que se puedan realizar operaciones aritméticas. Si un valor no está definido, es decir, 'NULL' está asociado al campo en la base de datos, se devuelve un puntero NULL equivalente.

void OpenDBX::Result::finish ()

Recupera las filas no recuperadas y limpia los conjuntos de resultados disponibles. Después de ejecutar una sentencia, al menos un conjunto de resultados es devuelto por el servidor de la base de datos. En caso de sentencias de manipulación de datos, no se devuelven filas, pero aún así se debe limpiar el conjunto de resultados. Esto generalmente se hace llamando a getResult() en un bucle hasta que devuelve 'done'. Para simplificar el desarrollo de aplicaciones, el método finish() hace esto por usted.

Excepciones

OpenDBX::Exception Si la biblioteca subyacente de la base de datos devuelve un error

Lob OpenDBX::Result::getLob (const char * value)

Crea una instancia de objeto grande si es compatible con la base de datos. Devuelve una instancia de la clase Lob que representa un objeto grande almacenado en la base de datos. Hace referencia al objeto grande y proporciona métodos para acceder y modificar su contenido.

El parámetro requerido por este método debe ser el valor devuelto por el método fieldValue() de una columna de objeto grande.

Este método solo debe usarse si el controlador subyacente indica que admite objetos grandes a través de Conn::getCapabilities(). De lo contrario, el contenido se puede recuperar directamente mediante el método fieldValue().

odbxres OpenDBX::Result::getResult (struct timeval * timeout = NULL, unsigned long chunk = 0)

Recupera un conjunto de resultados de la base de datos. Recupera el resultado de una sentencia de consulta del servidor de la base de datos. Si la sentencia fue INSERT, UPDATE, DELETE o una sentencia similar, el número de filas afectadas está disponible a través de rowsAffected().

El parámetro timeout restringe el tiempo que la función espera un resultado del servidor. Puede ser NULL para esperar hasta que llegue un resultado. De lo contrario, puede contener cualquier número de segundos y microsegundos en una estructura timeval para esperar. La estructura timeval debe configurarse cada vez antes de llamar a getResult() porque su contenido puede ser modificado por la función. Si el servidor no responde dentro del tiempo de espera, ¡la consulta no se cancela! En cambio, la próxima llamada a esta función esperará el mismo conjunto de resultados. La espera del tiempo especificado puede ser implementada en los backends si es posible, pero no hay garantía. Si no es así, getResult() no se devolverá hasta que llegue una respuesta.

Dependiendo de la biblioteca de base de datos nativa, puede ser posible recuperar todas las filas a la vez (si chunk es cero), una por una o más de una fila a la vez. Se permiten todos los valores positivos, incluido el cero, como valores para chunk. Si la paginación (más de una fila a la vez) no es compatible con el backend, utilizará 'una por una' o 'todas a la vez' si esta es la única opción proporcionada.

getResult() devuelve ODBX_RES_ROWS si hay un conjunto de resultados disponible y ODBX_RES_DONE si no se devolverán más resultados de la última consulta exitosa. ODBX_RES_NOROWS se devuelve si la sentencia se ejecutó correctamente pero no devolverá un conjunto de resultados (como para sentencias INSERT, UPDATE y DELETE) y ODBX_RES_TIMEOUT indica un tiempo de espera agotado.

Parámetros

timeout Puntero a una estructura timeval que especifica cuánto tiempo esperar un conjunto de resultados del servidor de la base de datos
chunk Número de filas a recuperar a la vez del servidor de la base de datos (cero significa todas las filas a la vez)

Retorna

Código de estado o error

odbxrow OpenDBX::Result::getRow ()

Hace que los datos de la siguiente fila estén disponibles. Recupera los valores de una fila del conjunto de resultados actual devuelto por getResult(). Hasta que se invoca esta función, no hay datos de fila ni de campo disponibles a través de fieldLength() o fieldValue() y estas funciones lanzarán una excepción.

getRow() devolverá ODBX_ROW_NEXT mientras haya filas disponibles en el conjunto de resultados. Después de que se haya puesto a disposición la última fila, las llamadas posteriores a esta función devolverán ODBX_ROW_DONE indicando que el conjunto de resultados no contiene más filas.

Retorna

uint64_t OpenDBX::Result::rowsAffected ()

Devuelve el número de filas afectadas por sentencias DELETE, INSERT o UPDATE. Devuelve el número de filas que han sido modificadas por la sentencia actual cuyo conjunto de resultados fue recuperado por getResult() y cero si el servidor de la base de datos no alteró ninguna fila. Las filas afectadas solo se devuelven para sentencias DELETE, INSERT o UPDATE y su número concreto depende de la implementación de la base de datos. Algunos servidores de bases de datos como MySQL pueden devolver un número menor de lo esperado porque no modifican registros cuyos valores no cambiarían.
