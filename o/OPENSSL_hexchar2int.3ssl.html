OPENSSL_hexchar2int(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL_hexchar2int(3ssl) OpenSSL OPENSSL_hexchar2int(3ssl)

NOMBRE

OPENSSL_hexchar2int, OPENSSL_hexstr2buf_ex, OPENSSL_hexstr2buf, OPENSSL_buf2hexstr_ex, OPENSSL_buf2hexstr - Funciones de codificación y decodificación hexadecimales

SINOPSIS

#include <openssl/crypto.h>
int OPENSSL_hexchar2int(unsigned char c);
int OPENSSL_hexstr2buf_ex(unsigned char *buf, size_t buf_n, long *buflen,
                          const char *str, const char sep);
unsigned char *OPENSSL_hexstr2buf(const char *str, long *len);
int OPENSSL_buf2hexstr_ex(char *str, size_t str_n, size_t *strlength,
                          const unsigned char *buf, long buflen,
                          const char sep);
char *OPENSSL_buf2hexstr(const unsigned char *buf, long buflen);

DESCRIPCIÓN

OPENSSL_hexchar2int() convierte un carácter hexadecimal a su equivalente numérico.

OPENSSL_hexstr2buf_ex() decodifica la cadena hexadecimal str y coloca la cadena de bytes resultante en el buf dado. El carácter sep es el separador entre los bytes; establecerlo a '\0' significa que no hay separador. buf_n proporciona el tamaño del buffer. Si buflen no es NULL, se rellena con la longitud del resultado. Para averiguar qué tan grande será el resultado, llame a esta función con NULL para buf. Se aceptan y se ignoran los dos puntos entre "bytes" hexadecimales de dos caracteres. Un número impar de dígitos hexadecimales es un error.

OPENSSL_hexstr2buf() hace lo mismo que OPENSSL_hexstr2buf_ex(), pero asigna espacio para el resultado y devuelve el resultado. Utiliza un separador predeterminado de ':'. La memoria se asigna llamando a OPENSSL_malloc() y debe liberarse llamando a OPENSSL_free().

OPENSSL_buf2hexstr_ex() codifica el contenido del buf dado con longitud buflen y coloca la cadena de caracteres hexadecimales resultante en el str dado. El carácter sep es el separador entre los bytes; establecerlo a '\0' significa que no hay separador. str_n proporciona el tamaño del buffer de cadena. Si strlength no es NULL, se rellena con la longitud del resultado. Para averiguar qué tan grande será el resultado, llame a esta función con NULL para str.

OPENSSL_buf2hexstr() hace lo mismo que OPENSSL_buf2hexstr_ex(), pero asigna espacio para el resultado y devuelve el resultado. Utiliza un separador predeterminado de ':'. La memoria se asigna llamando a OPENSSL_malloc() y debe liberarse llamando a OPENSSL_free().

VALORES DE RETORNO

OPENSSL_hexchar2int devuelve el valor de un carácter hexadecimal decodificado, o -1 en caso de error.

OPENSSL_buf2hexstr() y OPENSSL_hexstr2buf() devuelven un puntero a memoria asignada, o NULL en caso de error.

OPENSSL_buf2hexstr_ex() y OPENSSL_hexstr2buf_ex() devuelven 1 en caso de éxito, o 0 en caso de error.
