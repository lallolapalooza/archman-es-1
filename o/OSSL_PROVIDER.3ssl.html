DESCRIPCIÓN

OSSL_PROVIDER es un tipo que almacena información interna sobre los implementadores de proveedores (ver provider(7) para información sobre lo que es un proveedor). Un proveedor puede ser construido dentro de la aplicación o en las bibliotecas OpenSSL, o puede ser un módulo cargable. Las funciones descritas aquí manejan ambos tipos.

Algunas de estas funciones operan dentro de un contexto de biblioteca, por favor vea OSSL_LIB_CTX(3) para más detalles.

Funciones

OSSL_PROVIDER_set_default_search_path() especifica la ruta de búsqueda predeterminada que se utilizará para encontrar proveedores en el contexto especificado libctx. Si no se especifica, se utilizará un valor de entorno y un valor predeterminado de respaldo.

OSSL_PROVIDER_get0_default_search_path() obtiene la ruta de búsqueda predeterminada que se utilizará para encontrar proveedores en el contexto especificado libctx. Si tiene éxito, devuelve la ruta o una cadena vacía; la ruta es válida hasta que el contexto se libere o se llame a OSSL_PROVIDER_set_default_search_path().

OSSL_PROVIDER_add_builtin() se utiliza para agregar un proveedor precompilado a la base de datos de proveedores en el contexto dado, asociando un nombre de proveedor con una función de inicialización del proveedor. Este nombre puede ser utilizado posteriormente con OSSL_PROVIDER_load().

OSSL_PROVIDER_load() carga e inicializa un proveedor. Esto puede simplemente inicializar un proveedor que fue agregado previamente con OSSL_PROVIDER_add_builtin() y ejecutar su función de inicialización, o cargar un módulo de proveedor con el nombre dado y ejecutar su punto de entrada del proveedor, "OSSL_provider_init". El nombre del proveedor puede ser una ruta a un módulo de proveedor, en cuyo caso el nombre del proveedor devuelto por OSSL_PROVIDER_get0_name() será la ruta. Las rutas relativas se consideran dependientes del sistema y son relativas al directorio configurado "MODULESDIR" o a la ruta establecida en la variable de entorno OPENSSL_MODULES si está establecida.

OSSL_PROVIDER_try_load() funciona de manera similar a OSSL_PROVIDER_load(), excepto que no deshabilita los proveedores de respaldo si el proveedor no puede ser cargado e inicializado o si retain_fallbacks es mayor que cero. Si el proveedor se carga correctamente y retain_fallbacks es cero, los proveedores de respaldo se deshabilitan.

OSSL_PROVIDER_load_ex() y OSSL_PROVIDER_try_load_ex() son variantes de las funciones anteriores que aceptan una matriz de "OSSL_PARAM" de parámetros que se utilizan como configuración del proveedor cargado. Los parámetros de cualquier tipo excepto "OSSL_PARAM_UTF8_STRING" son ignorados silenciosamente. Si se proporcionan parámetros, reemplazan **todos** los parámetros especificados en el archivo de configuración.

OSSL_PROVIDER_unload() descarga el proveedor dado. Para un proveedor agregado con OSSL_PROVIDER_add_builtin(), esto simplemente ejecuta su función de descarga.

OSSL_PROVIDER_available() verifica si un proveedor con el nombre especificado está disponible para su uso.

OSSL_PROVIDER_do_all() itera sobre todos los proveedores cargados, llamando a cb para cada uno, con el proveedor actual en provider y el cbdata que se obtiene del llamador. Si no hay otro proveedor cargado previamente antes de llamar a esta función, el proveedor predeterminado aún está disponible como respaldo. Ver OSSL_PROVIDER-default(7) para más información sobre este comportamiento de respaldo.

OSSL_PROVIDER_gettable_params() se utiliza para obtener un descriptor de parámetros del proveedor que se especifica como una matriz constante OSSL_PARAM(3).

OSSL_PROVIDER_get_params() se utiliza para obtener los valores de los parámetros del proveedor. El llamador debe preparar la matriz OSSL_PARAM(3) antes de llamar a esta función, y los valores actúan como buffers para esta matriz de parámetros que deben llenarse con datos cuando se devuelve con éxito.

OSSL_PROVIDER_add_conf_parameter() establece el parámetro de configuración del proveedor name a value. Los parámetros de configuración del proveedor son gestionados por el núcleo de OpenSSL y normalmente se establecen en el archivo de configuración, pero también pueden ser establecidos temprano en el programa principal antes de que un proveedor sea utilizado por múltiples hilos. Los parámetros que solo afectan la inicialización del proveedor deben, por ahora, estar establecidos en el archivo de configuración, y solo tienen efecto cuando se establecen a través de esta interfaz, los parámetros que también se consultan después tienen algún efecto. Solo se pueden pasar parámetros de texto, y es responsabilidad del proveedor interpretarlos.

OSSL_PROVIDER_get_conf_parameters() recopila los parámetros de configuración globales asociados con prov. Estos parámetros de configuración son almacenados por el núcleo de OpenSSL para cada proveedor, no por el proveedor en sí mismo; los parámetros gestionados por el proveedor se consultan mediante OSSL_PROVIDER_get_params() descrito anteriormente. Los parámetros se devuelven por referencia, no como copias, por lo que los elementos de la matriz param deben tener OSSL_PARAM_UTF8_PTR como su data_type.

OSSL_PROVIDER_conf_get_bool() analiza el parámetro de configuración global name asociado con el proveedor prov como un valor booleano, devolviendo un valor predeterminado defval si no se puede obtener o analizar el parámetro. Los valores de parámetro que sean iguales (en sentido literal) a 1, "on", "yes" o "true" producen un resultado verdadero (distinto de cero). Los valores de parámetro iguales a "true" se consideran verdaderos.

DESCRIPCIÓN

OSSL_PROVIDER es un módulo que proporciona funciones para gestionar y cargar proveedores para la biblioteca OpenSSL. Las funciones descritas aquí se utilizan para cargar proveedores, realizar auto-pruebas, obtener información sobre los proveedores y gestionar parámetros de configuración.

Las funciones OSSL_PROVIDER_load_ex y OSSL_PROVIDER_try_load_ex se utilizan para cargar proveedores con argumentos opcionales. La función OSSL_PROVIDER_self_test ejecuta auto-pruebas en un proveedor. La función OSSL_PROVIDER_get0_provider_ctx devuelve el contexto del proveedor para un proveedor dado. La función OSSL_PROVIDER_get0_name devuelve el nombre de un proveedor. La función OSSL_PROVIDER_get0_dispatch devuelve la tabla de envío de un proveedor. La función OSSL_PROVIDER_get0_default_search_path devuelve la ruta de búsqueda predeterminada para un proveedor. Las funciones OSSL_PROVIDER_load y OSSL_PROVIDER_try_load cargan proveedores. La función OSSL_PROVIDER_do_all ejecuta callbacks para todos los proveedores. La función OSSL_PROVIDER_available comprueba si un proveedor está disponible. La función OSSL_PROVIDER_gettable_params devuelve parámetros para un proveedor. La función OSSL_PROVIDER_get_params recupera parámetros para un proveedor. La función OSSL_PROVIDER_query_operation consulta operaciones para un proveedor. La función OSSL_PROVIDER_unquery_operation anula la consulta de operaciones para un proveedor.

VALORES DE RETORNO

Las funciones descritas aquí devuelven 1 en caso de éxito o 0 en caso de error.

La función OSSL_PROVIDER_get0_default_search_path devuelve un puntero a una ruta en caso de éxito, o NULL en caso de error o si la ruta no se ha establecido previamente.

Las funciones OSSL_PROVIDER_load y OSSL_PROVIDER_try_load devuelven un puntero a un objeto proveedor en caso de éxito, o NULL en caso de error.

La función OSSL_PROVIDER_do_all devuelve 1 si el callback devuelve 1 para cada proveedor, o 0 si algún callback de proveedor devuelve 0. El procesamiento de callbacks se detiene en el primer proveedor que devuelve 0.

La función OSSL_PROVIDER_available devuelve 1 si el proveedor nombrado está disponible, de lo contrario 0.

La función OSSL_PROVIDER_gettable_params devuelve un puntero a una matriz de OSSL_PARAM(3) constantes, o NULL si no se proporciona ninguna.

La función OSSL_PROVIDER_get_params devuelve 1 en caso de éxito, o 0 en caso de error.

La función OSSL_PROVIDER_query_operation devuelve una matriz de OSSL_ALGORITHM o NULL en caso de error.

La función OSSL_PROVIDER_self_test devuelve 1 si las auto-pruebas pasan, o 0 en caso de error.

EJEMPLOS

Esto demuestra cómo cargar el módulo proveedor "foo" y solicitar su información de compilación.

#include <openssl/params.h>
#include <openssl/provider.h>
#include <openssl/err.h>
OSSL_PROVIDER *prov = NULL;
const char *build = NULL;
OSSL_PARAM request[] = {
    { "buildinfo", OSSL_PARAM_UTF8_PTR, &build, 0, 0 },
    { NULL, 0, NULL, 0, 0 }
};
if ((prov = OSSL_PROVIDER_load(NULL, "foo")) != NULL
    && OSSL_PROVIDER_get_params(prov, request))
    printf("Provider 'foo' buildinfo: %s\n", build);
else
    ERR_print_errors_fp(stderr);
