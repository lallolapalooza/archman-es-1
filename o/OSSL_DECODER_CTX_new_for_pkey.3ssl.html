OSSL_DECODER_CTX_new_for_pkey(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_DECODER_CTX_NEW_FOR_PKEY(3ssl) OpenSSL OSSL_DECODER_CTX_NEW_FOR_PKEY(3ssl)

NOMBRE

OSSL_DECODER_CTX_new_for_pkey, OSSL_DECODER_CTX_set_passphrase, OSSL_DECODER_CTX_set_pem_password_cb, OSSL_DECODER_CTX_set_passphrase_ui, OSSL_DECODER_CTX_set_passphrase_cb - Rutinas de decodificador para decodificar EVP_PKEYs

SINOPSIS

#include <openssl/decoder.h>
OSSL_DECODER_CTX *
OSSL_DECODER_CTX_new_for_pkey(EVP_PKEY **pkey,
                              const char *input_type,
                              const char *input_struct,
                              const char *keytype, int selection,
                              OSSL_LIB_CTX *libctx, const char *propquery);
int OSSL_DECODER_CTX_set_passphrase(OSSL_DECODER_CTX *ctx,
                                    const unsigned char *kstr,
                                    size_t klen);
int OSSL_DECODER_CTX_set_pem_password_cb(OSSL_DECODER_CTX *ctx,
                                         pem_password_cb *cb,
                                         void *cbarg);
int OSSL_DECODER_CTX_set_passphrase_ui(OSSL_DECODER_CTX *ctx,
                                       const UI_METHOD *ui_method,
                                       void *ui_data);
int OSSL_DECODER_CTX_set_passphrase_cb(OSSL_DECODER_CTX *ctx,
                                       OSSL_PASSPHRASE_CALLBACK *cb,
                                       void *cbarg);

DESCRIPCIÓN

OSSL_DECODER_CTX_new_for_pkey() es una función de utilidad que crea un OSSL_DECODER_CTX, encuentra todas las implementaciones de decodificador aplicables y las configura, de modo que lo único que el llamador tiene que hacer a continuación es llamar a funciones como OSSL_DECODER_from_bio(3). El llamador puede utilizar input_type, input_struct, keytype y selection opcionales para especificar qué se espera que contenga la entrada. pkey debe hacer referencia a una variable EVP_PKEY * que se establecerá en el EVP_PKEY recién creado en caso de decodificación exitosa. La variable referenciada debe inicializarse a NULL antes de llamar a la función.

Internamente OSSL_DECODER_CTX_new_for_pkey() busca todas las implementaciones disponibles de EVP_KEYMGMT(3) y luego construye una lista de todas las implementaciones de decodificador potenciales que puedan procesar la entrada codificada en datos adecuados para EVP_PKEYs. Todas estas implementaciones se obtienen implícitamente utilizando libctx y propquery.

La búsqueda de implementaciones de decodificador puede limitarse con input_type y input_struct, que especifican un tipo de entrada y una estructura de entrada iniciales. NULL es válido para ambos y significa que las implementaciones de decodificador determinarán el tipo de entrada por sí mismas. Se establecen con OSSL_DECODER_CTX_set_input_type(3) y OSSL_DECODER_CTX_set_input_structure(3). Consulte "Tipos de Entrada" y "Estructuras de Entrada" a continuación para obtener más información.

La búsqueda de implementaciones de decodificador también puede limitarse con keytype y selection, que especifican el tipo de clave y los contenidos esperados del resultado. NULL y cero son válidos y significan que las implementaciones de decodificador determinarán el tipo de clave y los contenidos de la clave por sí mismas a partir de la entrada que reciben.

Si no se encuentra ninguna implementación de decodificador adecuada, OSSL_DECODER_CTX_new_for_pkey() aún crea un OSSL_DECODER_CTX, pero sin un decodificador asociado (OSSL_DECODER_CTX_get_num_decoders(3) devuelve cero). Esto ayuda al llamador a distinguir entre un error al crear el OSSL_ENCODER_CTX y la falta de una implementación de codificador, y le permite actuar en consecuencia.

OSSL_DECODER_CTX_set_passphrase() proporciona a la implementación una frase de contraseña para usar al descifrar la clave privada codificada. Alternativamente, se puede especificar una función de devolución de llamada para la frase de contraseña con las siguientes funciones.

OSSL_DECODER_CTX_set_pem_password_cb(), OSSL_DECODER_CTX_set_passphrase_ui() y OSSL_DECODER_CTX_set_passphrase_cb() configuran un método de devolución de llamada que la implementación puede utilizar para solicitar una frase de contraseña, dando al llamador la opción de la forma preferida de devolución de llamada para la frase de contraseña. Estas se llaman indirectamente, a través de una función interna OSSL_PASSPHRASE_CALLBACK(3).

La función interna OSSL_PASSPHRASE_CALLBACK(3) almacena en caché la frase de contraseña, para que se reutilice en todas las decodificaciones que se realicen en la misma ejecución de decodificación (por ejemplo, dentro de una sola llamada a OSSL_DECODER_from_bio(3)).

Tipos de Entrada

Los tipos de entrada disponibles dependen de las implementaciones que ofrecen los proveedores disponibles, y la documentación del proveedor debe tener los detalles.

Entre los tipos de entrada conocidos que ofrecen las implementaciones de decodificador de OpenSSL para EVP_PKEYs se encuentran "DER", "PEM", "MSBLOB" y "PVK". Consulte openssl-glossary(7) para obtener más información sobre lo que significan estos tipos de entrada.

Estructuras de Entrada

Las estructuras de entrada disponibles dependen de las implementaciones que ofrecen los proveedores disponibles, y la documentación del proveedor debe tener los detalles.

Entre las estructuras de entrada conocidas que ofrecen las implementaciones de decodificador de OpenSSL para EVP_PKEYs se encuentran "pkcs8" y "SubjectPublicKeyInfo".

Las implementaciones de decodificador de OpenSSL también admiten la estructura de entrada "type-specific". Esta es la estructura utilizada para claves codificadas de acuerdo con especificaciones específicas del tipo de clave. Por ejemplo, claves RSA codificadas según PKCS#1.

Selecciones

selection puede ser cualquiera de los valores descritos en "Selecciones" en EVP_PKEY_fromdata(3). Adicionalmente selection también puede establecerse en 0 para indicar que el código detectará automáticamente la selección.

VALORES DE RETORNO

OSSL_DECODER_CTX_new_for_pkey() devuelve un puntero a un OSSL_DECODER_CTX, o NULL si no pudo ser creado.

OSSL_DECODER_CTX_set_passphrase(), OSSL_DECODER_CTX_set_pem_password_cb(), OSSL_DECODER_CTX_set_passphrase_ui() y OSSL_DECODER_CTX_set_passphrase_cb() devuelven 1 en caso de éxito, o 0 en caso de error.
