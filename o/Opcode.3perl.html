Opcode(3perl) Guía de Referencia de Programadores de Perl Opcode(3perl)

NOMBRE

Opcode - Deshabilitar opcodes nombrados cuando se compila código Perl

SINOPSIS

use Opcode;

DESCRIPCIÓN

El código Perl siempre se compila en un formato interno antes de su ejecución.

Evaluar código Perl (por ejemplo, mediante "eval" o "do 'file'") hace que el código se convierta en un formato interno y, tras un error en la compilación, se ejecute. El formato interno se basa en muchos distintos opcodes.

Por defecto, ningún opmask está en vigor y cualquier código puede compilarse.

El módulo Opcode permite definir un máscara de operador para que esté en vigor cuando Perl siguiente compile cualquier código. Intentar compilar código que contenga un opcode marcado con la máscara causará la falla en la compilación con un error. El código no se ejecutará.

NOTA

El módulo Opcode no se usa normalmente directamente. Consulte los pragma ops y el módulo Safe para usos más típicos.

ADVERTENCIA

El módulo Opcode no implementa un sandbox efectivo para evaluar código no confiable con el intérprete de Perl.

Los errores en el intérprete de Perl que podrían ser aprovechados para romper las restricciones de Opcode no se tratan como vulnerabilidades. Consulte perlsecpolicy para más información.

Los autores no garantizan la idoneidad de este software para seguridad o uso seguro.

Los autores no serán responsables de daños especiales, incidentales, consecuentes, indirectos o similares que puedan surgir del uso de este software.

Su rendimiento será variable. Si tiene dudas, no lo use.

Nombres de Operadores y Listas de Operadores

La lista canónica de nombres de operadores es el contenido del array PL_op_name definido y inicializado en el archivo opcode.h de la distribución de fuente de Perl (y instalado en la librería Perl).

Cada operador tiene tanto un nombre corto (su opname) como un nombre más detallado o reconocible. La función opdesc puede usarse para devolver una lista de descripciones de operadores dados.

Muchas de las funciones y métodos mencionados aquí aceptan una lista de operadores como parámetros. La mayoría de las listas de operadores pueden consistir en varios tipos de elementos. Cada elemento puede ser uno de:

un nombre de operador (opname)
Los nombres de operadores son generalmente términos cortos en minúsculas como enterloop, leaveloop, last, next, redo, etc. A veces son bastante crípticos como gv2cv, i_ncmp y ftsvtx.
un nombre de etiqueta de operador (optag)
Los nombres de etiquetas de operadores pueden usarse para referirse a grupos (o conjuntos) de operadores. Los nombres de etiquetas siempre empiezan con un signo de dos puntos. El módulo Opcode define varios optags y el usuario puede definir otros usando la función define_optag.
un nombre negado de operador o etiqueta de operador
Un operador o etiqueta puede prefijarse con un signo de exclamación, por ejemplo, !mkdir. Negar un nombre de operador o etiqueta significa eliminar los operadores correspondientes de la colección acumulada en ese momento.
un conjunto de operadores (opset)
Un opset es una cadena binaria de aproximadamente 44 bytes que contiene un conjunto de cero o más operadores.

Las funciones opset y opset_to_ops pueden usarse para convertir una lista de operadores en un opset y viceversa.

Donde se pueda proporcionar una lista de operadores, se puede usar uno o más opsets. Véase también la manipulación de opsets a continuación.

Funciones de Opcode

El paquete Opcode contiene funciones para manipular los nombres de operadores, etiquetas y conjuntos de operadores. Todas son disponibles para exportar por el paquete.

opcodes
En un contexto escalar, devuelve el número de opcodes en esta versión de Perl (alrededor de 350 para perl-5.7.0). En un contexto de lista, devuelve una lista de todos los nombres de operadores. (No implementado aún, use @names = opset_to_ops(full_opset)).
opset (OP, ...)
Devuelve un opset que contiene los operadores indicados.
opset_to_ops (OPSET)
Devuelve una lista de nombres de operadores correspondientes a los operadores en el conjunto.
opset_to_hex (OPSET)
Devuelve una representación en cadena de un opset. Puede ser útil para depuración.
full_opset
Devuelve un opset que incluye todos los operadores.
empty_opset
Devuelve un opset que no contiene ningún operador.
invert_opset (OPSET)
Devuelve un opset que es el conjunto inverso del proporcionado.
verify_opset (OPSET, ...)
Devuelve verdadero si el conjunto de operadores proporcionado parece un conjunto válido (es decir, tiene la longitud correcta, etc.). De lo contrario, devuelve falso. Si el segundo parámetro es verdadero, verify_opset lanzará un error si el conjunto de operadores es inválido. Las funciones restantes de Opcode llaman automáticamente a verify_opset y lanzarán un error si se le pasa un conjunto de operadores inválido.
define_optag (OPTAG, OPSET)
Define OPTAG como un nombre simbólico para OPSET. Los nombres de optags siempre comienzan con un signo de dos puntos ":".

El nombre de optag usado no debe estar ya definido (define_optag lanzará un error si ya está definido). Los nombres de optags son globales para el proceso Perl y no pueden ser modificados o eliminados una vez definidos.

Se recomienda que las aplicaciones que usen Opcode usen un nombre de etiqueta con mayúsculas al principio, ya que los nombres de minúsculas están reservados para el módulo Opcode. Si está usando Opcode dentro de un módulo, se recomienda preceder los nombres de etiquetas con el nombre del módulo para garantizar la unicidad y evitar colisiones con otros módulos.

Manipulación de Opsets

Los opsets se pueden manipular utilizando los operadores de bit a bit & (and), | (or), ^ (xor) y ~ (negar/invertir).

Sin embargo, nunca debe depender de la posición numérica de cualquier opcode dentro del opset. En otras palabras, ambos lados de un operador de bit a bit deben ser opsets devueltos por funciones de Opcode.

También, ya que el número de opcodes en la versión actual de Perl puede no ser un múltiplo exacto de ocho, podría haber bits no utilizados en el último byte de un opset. Esto no causará problemas (las funciones de Opcode ignoran esos bits extras), pero significa que el operador ~ típicamente no producirá el mismo 'string' de opset 'físico' que la función invert_opset.

POR HACER (posiblemente)

$bool = opset_eq($opset1, $opset2)  verdadero si los opsets son lógicamente equivalentes
$yes = opset_can($opset, @ops)      verdadero si

Opcode(3pm)

NOMBRE

Opcode - información sobre el conjunto de códigos de operación de Perl

SINOPSIS

    use Opcode qw(opcode opname func argspec);
    use Opcode qw(:base_core);
    use Opcode qw(:base_core :base_mem);

    $opset = Opcode->new;
    $opset->insert('foo', 'bar');
    $opset->delete('bar');
    @ops = $opset->ops;
    @names = $opset->opnames;
    $opset->push(OP_CONST);
    $opset->set(OP_PUSH);
    $opset->add(':base_core');

    $opset1 = Opcode->new(':base_core');
    $opset2 = Opcode->new(':base_io');
    $opset has all @ops set
    @diff = opset_diff($opset1, $opset2) => ('foo', '!bar', ...)

DESCRIPCIÓN

El módulo Opcode proporciona una interfaz para la tabla de códigos de operación interna de Perl. Permite examinar, construir y manipular conjuntos de códigos de operación, que luego pueden usarse para controlar qué códigos de operación están permitidos en un bloque de código (por ejemplo, dentro de un eval o un use Safe::Root).

Los códigos de operación se representan mediante enteros (constantes definidas en el módulo Opcode, como OP_PUSH, OP_CONST, etc.).

Un Opcode objeto representa un conjunto de códigos de operación. Puede crearse de varias formas:

  • Opcode->new: Crea un conjunto vacío.
  • Opcode->new(OP_PUSH, OP_CONST, ...)`: Crea un conjunto que contiene los códigos de operación especificados.
  • Opcode->new(':tagname'): Crea un conjunto que contiene todos los códigos de operación asociados con la etiqueta especificada (ver más abajo).
  • Opcode->new($opset_ref)`: Crea una copia de un conjunto existente.

Puede usar las siguientes funciones de utilidad:

opcode(name)
Devuelve el entero de código de operación para el nombre dado. Por ejemplo, opcode('push') devuelve OP_PUSH. Si el nombre no se reconocece, devuelve undef.
opname(opcode)
Devuelve el nombre de cadena para el código de operación entero dado. Por ejemplo, opname(OP_PUSH) devuelve 'push'. Si el código de operación no se reconocece, devuelve undef.
func(name)
Devuelve el número de argumentos esperados para la operación dada su nombre. Por ejemplo, func('push') devuelve 1. Si la operación no se reconocece, devuelve undef.
argspec(name)
Devuelve una cadena que describe los argumentos esperados para la operación dado su nombre.
opset_diff(opset1, opset2)
Devuelve una lista de códigos de operación que están en opset1 pero no en opset2.

NOTA

El conjunto de códigos de operación por defecto proporcionado por :default puede cambiar entre versiones de Perl. No confíe en su contenido si la seguridad es importante.

ADVERTENCIA

La manipulación del conjunto de códigos de operación puede permitir la ejecución de código arbitrario si se hace de forma imprudente. Tenga cuidado al utilizar este módulo, especialmente en entornos donde la seguridad es crítica.

Nombres de Operadores y Listas de Operadores

Los códigos de operación se identifican por un entero. Estos enteros se definen mediante preprocesador en los archivos de encabezado de Perl, pero el módulo Opcode expone estos números como constantes con nombres como OP_PUSH, OP_CONST, etc.

Puede obtener la lista de todos los códigos de operación conocidos como una lista de enteros usando $opset->ops o como una lista de nombres de cadenas usando $opset->opnames.

Puede añadir o eliminar códigos de operación individuales de un conjunto:

$opset->insert(OP_CONST, OP_PUSH)
Añade los códigos de operación especificados al conjunto.
$opset->delete(OP_CONST)
Elimina el código de operación especificado del conjunto.
$opset->insert('foo', 'bar')
Puede insertar códigos de operación usando sus nombres de cadena, que se resolverán internamente.
$opset->delete('bar')
Puede eliminar códigos de operación usando sus nombres de cadena.
$opset->push(OP_CONST)
Añade un único código de operación al conjunto.
$opset->set(OP_PUSH)
Establece el conjunto para que contenga solo el código de operación especificado.

Funciones de Código de Operación

Las siguientes funciones están disponibles para interactuar con códigos de operación individuales:

opcode(name)
Devuelve el valor entero de un código de operación a partir de su nombre.
opname(value)
Devuelve el nombre de cadena de un código de operación a partir de su valor entero.
func(name)
Devuelve el número de argumentos de una operación dado su nombre.
argspec(name)
Devuelve la cadena de especificación de argumentos para una operación dado su nombre.

Manipulando Conjuntos de Operación

Un objeto Opcode representa un conjunto de códigos de operación. Puede manipular estos conjuntos de la siguiente manera:

$opset->insert(op, ...)`
Inserta uno o más códigos de operación (enteros o nombres) en el conjunto.
$opset->delete(op, ...)`
Elimina uno o más códigos de operación (enteros o nombres) del conjunto.
$opset->add(tag)`
Añade todos los códigos de operación asociados con la etiqueta especificada al conjunto.
$opset->remove(tag)`
Elimina todos los códigos de operación asociados con la etiqueta especificada del conjunto.
$opset->has(op)`
Devuelve verdadero si el código de operación op (entero o nombre) está en el conjunto.
$opset->contains(opset)`
Devuelve verdadero si este conjunto contiene todos los códigos de operación del opset dado.
$opset->ops`
Devuelve una lista de todos los códigos de operación enteros en el conjunto.
$opset->opnames`
Devuelve una lista de todos los nombres de códigos de operación de cadena en el conjunto.
opset_diff(opset1, opset2)`
Devuelve una lista de códigos de operación que están en opset1 pero no en opset2.

El ejemplo de la sinopsis muestra cómo crear un conjunto que contiene todos los códigos de operación del conjunto :base_core, luego elimina 'bar', y finalmente añade el código de operación OP_PUSH.

La función opset_diff se puede usar para encontrar las diferencias entre dos conjuntos de códigos de operación.

$opset has all @ops set
@diff = opset_diff($opset1, $opset2) => ('foo', '!bar', ...)

:base_mem
Estas ops relacionadas con la memoria no se incluyen en :base_core porque pueden usarse fácilmente para implementar un ataque de recursos (por ejemplo, consumir toda la memoria disponible). 
concat multiconcat repeat join range
anonlist anonhash

Tenga en cuenta que a pesar de la existencia de esta etiqueta de operación, un ataque de recursos de memoria aún puede ser posible utilizando solo operaciones :base_core.

Deshabilitar estas ops es una forma *muy* drástica de intentar prevenir un ataque de recursos de memoria. Es probable que en un futuro cercano se añada un mecanismo específico de límite de memoria a Perl.
