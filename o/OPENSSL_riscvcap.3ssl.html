NOMBRE

OPENSSL_riscvcap - vector de capacidades del procesador RISC-V

SINOPSIS

env OPENSSL_riscvcap=... <aplicación>

DESCRIPCIÓN

libcrypto soporta extensiones del conjunto de instrucciones RISC-V. Estas extensiones se indican mediante nombres individuales de extensión en el vector de capacidades. Para la plataforma Linux, cuando libcrypto se inicializa, los resultados devueltos por la llamada al sistema de sondeo de hardware RISC-V (hwprobe) se almacenan en el vector. De lo contrario, todas las capacidades están deshabilitadas.

Para anular el conjunto de instrucciones disponibles para una aplicación, puede establecer la variable de entorno OPENSSL_riscvcap antes de iniciar la aplicación.

La variable de entorno es similar a la cadena ISA de RISC-V definida en el Manual del Conjunto de Instrucciones de RISC-V. No distingue entre mayúsculas y minúsculas. Aunque debido al límite del analizador de variables de entorno dentro de libcrypto, una extensión debe ir precedida de un guion bajo para hacerla reconocible. Esto también se aplica a la extensión Vector.

OPENSSL_riscvcap="rv64gc_v_zba_zbb_zbs..."

Tenga en cuenta que la implicación de extensiones no está implementada actualmente. Por ejemplo, cuando se proporciona "rv64gc_b" como variable de entorno, zba/zbb/zbs no se implicarían en el vector de capacidades.

Actualmente, solo se reconocen estas extensiones:

ZBA

Podría detectarse mediante hwprobe para el kernel de Linux >= 6.8

VALORES DE RETORNO

No disponible.

EJEMPLOS

Comprobar las capacidades detectadas actualmente

$ openssl info -cpusettings
OPENSSL_riscvcap=ZBA_ZBB_ZBC_ZBS_V

Deshabilita todas las extensiones del conjunto de instrucciones:

OPENSSL_riscvcap="rv64gc"

Habilita solo la extensión vectorial:

OPENSSL_riscvcap="rv64gc_v"
