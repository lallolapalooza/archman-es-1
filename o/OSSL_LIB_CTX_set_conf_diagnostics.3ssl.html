OSSL_LIB_CTX_set_conf_diagnostics(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_LIB_CTX_SET_CONF_DIAGNOSTICS(3ssl) OpenSSL OSSL_LIB_CTX_SET_CONF_DIAGNOSTICS(3ssl)

NOMBRE

OSSL_LIB_CTX_set_conf_diagnostics, OSSL_LIB_CTX_get_conf_diagnostics - Establecer y obtener diagnósticos de configuración

SINOPSIS

#include <openssl/crypto.h>
void OSSL_LIB_CTX_set_conf_diagnostics(OSSL_LIB_CTX *ctx, int value);
int OSSL_LIB_CTX_get_conf_diagnostics(OSSL_LIB_CTX *ctx);

DESCRIPCIÓN

OSSL_LIB_CTX_set_conf_diagnostics() establece el valor del indicador de diagnósticos de configuración. Si value no es cero, el análisis y la aplicación posteriores de los datos de configuración pueden informar errores que de otro modo se ignorarían. En particular, cualquier error en el módulo de configuración ssl provocará un fallo en las llamadas a SSL_CTX_new(3) y SSL_CTX_new_ex(3). El indicador de diagnósticos de configuración también se puede establecer cuando un archivo de configuración se está cargando en OSSL_LIB_CTX con OSSL_LIB_CTX_load_config(3). Si la configuración establece un valor de config_diagnostics como se describe en config(5), anulará el valor establecido por OSSL_LIB_CTX_set_conf_diagnostics() antes de cargar el archivo de configuración.

OSSL_LIB_CTX_get_conf_diagnostics() devuelve el valor actual del indicador de diagnósticos de configuración.

VALORES DE RETORNO

OSSL_LIB_CTX_get_conf_diagnostics() devuelve 0 si los diagnósticos de configuración no deben realizarse, y un valor distinto de cero en caso contrario.

VER TAMBIÉN

SSL_CTX_new(3), OSSL_LIB_CTX_load_config(3), config(5)
