OSSL_QUIC_client_method(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_QUIC_CLIENT_METHOD(3ssl) OpenSSL OSSL_QUIC_CLIENT_METHOD(3ssl)

NOMBRE

OSSL_QUIC_client_method, OSSL_QUIC_client_thread_method, OSSL_QUIC_server_method - Proporcionar objetos SSL_METHOD para funciones habilitadas para QUIC

SINOPSIS

#include <openssl/quic.h>
const SSL_METHOD *OSSL_QUIC_client_method(void);
const SSL_METHOD *OSSL_QUIC_client_thread_method(void);
const SSL_METHOD *OSSL_QUIC_server_method(void);

DESCRIPCIÓN

Las funciones OSSL_QUIC_client_method(), OSSL_QUIC_client_thread_method() y OSSL_QUIC_server_method() proporcionan métodos para la función SSL_CTX_new_ex(3) para ofrecer soporte para el protocolo QUIC.

OSSL_QUIC_client_thread_method() utiliza hilos para permitir un modo de operación bloqueante y evitar la necesidad de devolver el control a la biblioteca OpenSSL para el procesamiento de eventos basados en el tiempo. OSSL_QUIC_client_method() no utiliza hilos y depende del modo de operación no bloqueante y de que la aplicación llame periódicamente a las funciones SSL.

OSSL_QUIC_server_method() proporciona soporte para el protocolo QUIC del lado del servidor y debe usarse con la API SSL_new_listener(3). Intentar usar OSSL_QUIC_server_method() con SSL_new(3) resultará en un error.

VALORES DE RETORNO

Estas funciones devuelven punteros a los objetos de método constantes.

VER TAMBIÉN

SSL_CTX_new_ex(3), SSL_new_listener(3)

HISTORIAL

OSSL_QUIC_client_method() y OSSL_QUIC_client_thread_method() se agregaron en OpenSSL 3.2.

OSSL_QUIC_server_method() se agregó en OpenSSL 3.5.
