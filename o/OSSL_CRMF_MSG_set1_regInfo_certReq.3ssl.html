OSSL_CRMF_MSG_set1_regInfo_certReq(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_CRMF_MSG_SET1_REGINFO_CERTREQ(3ssl) OpenSSL OSSL_CRMF_MSG_SET1_REGINFO_CERTREQ(3ssl)

NOMBRE

OSSL_CRMF_MSG_get0_regInfo_utf8Pairs, OSSL_CRMF_MSG_set1_regInfo_utf8Pairs, OSSL_CRMF_MSG_get0_regInfo_certReq, OSSL_CRMF_MSG_set1_regInfo_certReq - funciones para obtener o establecer la Información de Registro de CRMF

SINOPSIS

#include <openssl/crmf.h>
ASN1_UTF8STRING
    *OSSL_CRMF_MSG_get0_regInfo_utf8Pairs(const OSSL_CRMF_MSG *msg);
int OSSL_CRMF_MSG_set1_regInfo_utf8Pairs(OSSL_CRMF_MSG *msg,
                                         const ASN1_UTF8STRING *utf8pairs);
OSSL_CRMF_CERTREQUEST
    *OSSL_CRMF_MSG_get0_regInfo_certReq(const OSSL_CRMF_MSG *msg);
int OSSL_CRMF_MSG_set1_regInfo_certReq(OSSL_CRMF_MSG *msg,
                                       const OSSL_CRMF_CERTREQUEST *cr);

DESCRIPCIÓN

OSSL_CRMF_MSG_get0_regInfo_utf8Pairs() devuelve el primer regInfo de utf8Pairs en el msg dado, si está presente.

OSSL_CRMF_MSG_set1_regInfo_utf8Pairs() añade una copia del valor utf8pairs dado como regInfo de utf8Pairs al msg dado. Ver RFC 4211 sección 7.1.

OSSL_CRMF_MSG_get0_regInfo_certReq() devuelve el primer regInfo de certReq en el msg dado, si está presente.

OSSL_CRMF_MSG_set1_regInfo_certReq() añade una copia del valor cr dado como regInfo de certReq al msg dado. Ver RFC 4211 sección 7.2.

VALORES DE RETORNO

Todas las funciones get0_*() devuelven el valor del puntero respectivo, NULL si no está presente.

Todas las funciones set1_*() devuelven 1 en caso de éxito, 0 en caso de error.

NOTAS

Llamar a las funciones set1_*() varias veces añade múltiples instancias del control respectivo a la estructura regInfo del msg dado. Mientras que RFC 4211 espera múltiples utf8Pairs en una estructura regInfo, no permite múltiples certReq.

VER TAMBIÉN

RFC 4211

HISTORIAL

El soporte de CRMF de OpenSSL se añadió en OpenSSL 3.0.
