OPENSSL_LH_STATS(3ssl) OpenSSL OPENSSL_LH_STATS(3ssl)

NOMBRE

OPENSSL_LH_stats, OPENSSL_LH_node_stats, OPENSSL_LH_node_usage_stats, OPENSSL_LH_stats_bio, OPENSSL_LH_node_stats_bio, OPENSSL_LH_node_usage_stats_bio - estadísticas de LHASH

SINOPSIS

#include <openssl/lhash.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.1, y pueden ser ocultadas por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

void OPENSSL_LH_node_stats(LHASH *table, FILE *out);
void OPENSSL_LH_node_usage_stats(LHASH *table, FILE *out);
void OPENSSL_LH_node_stats_bio(LHASH *table, BIO *out);
void OPENSSL_LH_node_usage_stats_bio(LHASH *table, BIO *out);
void OPENSSL_LH_stats(LHASH *table, FILE *out);
void OPENSSL_LH_stats_bio(LHASH *table, BIO *out);

DESCRIPCIÓN

La estructura LHASH registra estadísticas sobre la mayoría de los aspectos del acceso a la tabla hash.

OPENSSL_LH_stats() imprime estadísticas sobre el tamaño de la tabla hash y cuántas entradas contiene. Por razones históricas, esta función también muestra una serie de estadísticas adicionales, pero el seguimiento de estas estadísticas ya no está soportado y estas estadísticas siempre se informan como cero.

OPENSSL_LH_node_stats() imprime el número de entradas por cada 'cubo' en la tabla hash.

OPENSSL_LH_node_usage_stats() imprime un resumen breve del estado de la tabla hash. Imprime la 'carga' y la 'carga real'. La carga es el número promedio de elementos de datos por 'cubo' en la tabla hash. La 'carga real' es el número promedio de elementos por 'cubo', pero solo para los cubos que contienen entradas. Por lo tanto, la 'carga real' es el número promedio de búsquedas que necesitarán encontrar un elemento en la tabla hash, mientras que la 'carga' es el número promedio que se realizará para registrar un fallo.

OPENSSL_LH_stats_bio(), OPENSSL_LH_node_stats_bio() y OPENSSL_LH_node_usage_stats_bio() son iguales a las anteriores, excepto que la salida se dirige a un BIO.

Estas funciones están obsoletas y ya no deben usarse.

VALORES DE RETORNO

Estas funciones no devuelven valores.

NOTA

Estas llamadas deben realizarse bajo un bloqueo de lectura. Consulte "NOTA" en OPENSSL_LH_COMPFUNC(3) para más detalles sobre los bloqueos necesarios al usar la estructura de datos LHASH.

VER TAMBIÉN

bio(7), OPENSSL_LH_COMPFUNC(3)

HISTORIAL

Estas funciones fueron marcadas como obsoletas en la versión 3.1.
