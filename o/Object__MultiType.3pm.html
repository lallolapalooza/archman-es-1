Paquete: perl-object-multitype

MultiType(3) Documentación de Perl aportada por el usuario MultiType(3)

NOMBRE

Object::MultiType - Objetos Perl como Hash, Array, Escalar, Código y Glob al mismo tiempo.

SINOPSIS

use Object::MultiType ;
my $scalar = 'abc' ;
my @array  = qw(x y z);
my %hash   = (A => 1 , B => 2) ;
my $obj = Object::MultiType->new(
scalar => \$scalar ,
array  => \@array ,
hash   => \%hash ,
code   => sub{ return("¡Soy una referencia sub!") ; }
glob   => \*STDOUT ,
) ;

print "Yo como escalar: $obj\n" ;

my $array_1 = $obj->[1] ;
print "$array_1\n" ;

my $hash_B = $obj->{B} ;
print "$hash_B\n" ;

my $hash = $$obj->hash ;
foreach my $Key (sort keys %$hash ) {
  print "$Key = $$hash{$Key}\n" ;
}

&$obj(args) ;

DESCRIPCIÓN

Este módulo devuelve un objeto que funciona como un objeto Hash, Array, Escalar, Código y Glob al mismo tiempo.

La forma habitual es llamarlo desde tu módulo en new():

package FOO ;

use Object::MultiType ;
use vars qw(@ISA) ;
@ISA = qw(Object::MultiType) ; ## ¡Es bueno que 'Object::MultiType' sea el último en @ISA!

sub new {
  my $class = shift ;
  my $this = Object::MultiType->new() ;
  bless($this,$class) ;
}

MÉTODOS

** Ver también los métodos de Saver.

new

Argumentos:

bool
La referencia *booleana*. Por defecto: undef
boolcode|boolsub
Establece la subrutina/función (referencia CÓDIGO) que devolverá/generará el valor *booleano*.
scalar
La referencia ESCALAR. Si no se envía, se creará un ESCALAR nulo.
scalarcode|scalarsub
Establece la subrutina/función (referencia CÓDIGO) que devolverá/generará los datos escalares del objeto.
array
La referencia ARRAY. Si no se envía, se creará un ARRAY nulo.
hash
La referencia HASH. Si no se envía, se creará un HASH nulo.
code
La referencia CÓDIGO. Si no se envía, se creará una subrutina nula {}.

Con esto tu objeto puede ser usado como una referencia a subrutina:

my $multi = Object::MultiType->new( code => sub { print "Args: @_\n" ;} ) ;
&$multi();

Nota que el primer argumento enviado a la SUB es el objeto ($multi).

glob
La referencia GLOB (HANDLE). Si no se envía, se creará un GLOB nulo.

** ¡Nota que no puedes usar el GLOB por defecto (nulo) creado cuando no envías este argumento! Ya que todos los objetos lo compartirán, ¡y estaba ahí solo para evitar errores!

tiearray
Nombre del paquete para crear un TIEARRAY. El argumento $$this se envía a tie().

tie() se llama como:

tie(@array,$args{tiearray},$$this) ;

Nota que es difícil implementar los métodos tie para PUSH, POP, SHIFT, UNSHIFT, SPLICE... A menos que hagas solo un alias a otro array a través de los métodos tie.

** Ver también tiehash.

tiehash
Nombre del paquete para crear un TIEHASH. El argumento $$this se envía a tie().

tie() se llama como:

tie(%hash,$args{tiehash},$$this) ;

** Se envía $$this (el Saver), y no $this, para evitar la interrupción de DESTROY (auto referencia).

** $$this es una referencia al objeto Saver que guarda el ESCALAR, ARRAY, HASH, CÓDIGO y GLOB.

sub TIEHASH {
  my $class = shift ;
  my $multi = shift ; ## $$this
  my $scalarref = $multi->scalar ; ## \${*$multi}
  my $arrayref  = $multi->array  ; ## \@{*$multi}
  my $hashref   = $multi->hash   ; ## \%{*$multi}

  my $this = { s => $scalarref , a => $arrayref , h => $hashref } ;
  bless($this,$class) ;
}
tiehandle
Hace que el objeto funcione como un glob enlazado (TIEHANDLE).

Si se usa con glob, lo enlazará (tie()). Si glob no se envía, se usa un GLOB nulo:

my $multi = Object::MultiType->new(
glob      => \*MYOUT ,               ## 'glob' es Opcional.
tiehandle => 'TieHandlePack' ,
) ;
tieonuse
La referencia solo se enlaza cuando se usa. Por lo tanto, el HASH, ARRAY o GLOB (handle) solo se enlazan si/cuando se accede a ellos.
nodefault
Si se establece en verdadero, indica que no se creen las referencias por defecto dentro del Saver, y solo contendrá las referencias enviadas (scalar, array, hash, code, glob).

** Esto es bueno para ahorrar memoria.

is_saver

Devuelve 0. Bueno para ver si lo que tienes es el Saver o el objeto MultiType.

SAVER

El objeto MultiType tiene un objeto Saver (Object::MultiType::Saver), que guarda todos los diferentes tipos de datos (referencias). Se puede acceder a este saver desde el objeto principal:

my $multi = Object::MultiType->new() ;

my $saver = $$multi ;
print $saver->scalar ;

Si quieres guardar atributos en tu Objeto y usas tiehash, ¡no puedes establecer atributos directamente en el objeto MultiType!:

sub new {
  my $class = shift ;
  my $this = Object::MultiType->new(tiehash => 'TieHashPack') ;
  ## ¡No hagas esto! Esto llamará a STORE() en TIEHASH, y no lo guardará en el objeto:
  $this->{flagx} = 1 ;

  bless($this,$class) ;
}

Por lo tanto, si usas tiehash y quieres guardar atributos (fuera de tie), usa esto:

## Esto guarda el atributo dentro del Saver:
$$this->{flagx} = 1 ;

¡Nota que esto establece un atributo en el saver, y este tiene sus propios atributos!

## $saver = $$this ;
$saver->{s} ## la ref. escalar.
$saver->{a} ## la ref. array.
$saver->{h} ## la ref. hash.
$saver->{c} ## la ref. código.
$saver->{g} ## la ref. glob.

** Ver "Acceso directo a los tipos de datos".

DESTROY

Cuando el objeto se DESTRUYE, el Saver dentro de él se limpia, por lo que los objetos enlazados también pueden ser DESTRUIDOS automáticamente.

Acceso directo a los tipos de datos

Para acceder directamente a la referencia de los diferentes tipos de datos (ESCALAR, ARRAY, HASH, CÓDIGO y GLOB), usa:

my $multi = Object::MultiType->new() ;
my $saver = $$multi ;
my $scalarref = $saver->scalar ; ## $saver->{s}
my $arrayref  = $saver->array  ; ## $saver->{a}
my $hashref   = $saver->hash   ; ## $saver->{h}
my $coderef   = $saver->code   ; ## $saver->{c}
my $globeref  = $saver->glob   ; ## $saver->{g}

## Puedes acceder al Saver directamente desde el objeto principal:
$$multi->hash  ;

Estableciendo los datos:

$saver->set_bool( 1 ) ;
$saver->set_scalar( 'xyz' ) ;
$saver->set_array( [qw(x y z)] ) ;
$saver->set_hash( {X => 1} ) ;
$saver->set_code( sub{ print "XYZ\n" ; } ) ;
$saver->set_glob( \*STDOUT ) ;

Como ESCALAR

Puedes usarlo como ESCALAR cuando lo pones entre comillas o haces una copia de él:

my $multi = Object::MultiType->new( scalar => 'Foo' ) ;
## Comillas:
print "Yo como escalar: $multi\n" ;

## Copia:
my $str = $multi ;
$str .= '_x' ; ## ¡Copia hecha cuando lo cambias! Hasta entonces $str funciona como $multi.
print "$str\n" ;

Usando el argumento scalarsub puedes usar una función que generará los datos escalares, en lugar de una referencia a un ESCALAR:

my $multi = Object::MultiType->new(scalarsub => sub{ return 'datos generados' ;} ) ;

print "Mi escalar tiene $multi!\n" ;

Como ARRAY

Como ARRAY

Puedes usarlo como ARRAY directamente desde el objeto:

my $multi = Object::MultiType->new( array => [qw(FOO BAR)] ) ;
my $array_0 = $multi->[0] ;
$multi->[1] = 'foo' ;

Como HASH

Puedes usarlo como HASH directamente desde el objeto:

my $multi = Object::MultiType->new( hash => {key => 'foo'} ) ;
my $k = $multi->{key} ;
$multi->{foo} = 'bar' ;

Con TIE

Para usar tu ARRAY y HASH "tieados" (vinculados), puedes pasar la referencia ya "tieada" del HASH o ARRAY, o usar los argumentos tiehash y tiearray en new():

## Usando la referencia:
my %hash ;
tie(%hash,'TieHash') ;
my $multi = Object::MultiType->new(hash => \%hash) ;

## O usando directamente el argumento:
my $multi = Object::MultiType->new(tiehash => 'TieHashPack') ;

Nota que usar tiehash o tiearray es mejor, ya que tu HASH o ARRAY "tieado" puede ver el objeto Saver y el otro tipo de dato del mismo. Ver el método new() y sus argumentos.

Aquí tienes un ejemplo de un paquete TieHash que se llama desde Object::MultiType->new():

## La llamada dentro de Object::MultiType->new():
tie(%hash,$args{tiehash},$$this) ;

## El paquete:
package TieHash ;

sub TIEHASH {
    my $class = shift ;
    my $Saver = shift ; ## Object::MultiType pasa como $$this (solo el Saver) para evitar romper DESTROY!
                        ## $this = Object::MultiType >> $$this = Object::MultiType::Saver

    my $scalarref = $Saver->scalar ;
    my $arrayref  = $Saver->array  ;
    ## Nota que $Saver->hash devolverá el hash tieado, y no es necesario aquí!
    ## my $hashref   = $Saver->hash ;

    ## Guardando las referencias dentro del objeto TIE:
    my $this = { scalar => $scalarref , array => $arrayref , hash => {} } ;

    bless($this,$class) ;
}

sub FETCH    { my $this = shift ; return( 'key' ) ;}

sub NEXTKEY  { my $this = shift ; return( 'key' ) ;}

sub STORE    { my $this = shift ; $this->{hash}{$_[0]} = $_[1] }

sub DELETE   { my $this = shift ; delete $this->{hash}{$_[0]} }

sub CLEAR    { my $this = shift ; $this->{hash} = {} ;}

sub EXISTS   { my $this = shift ; defined $this->{hash}{$_[0]} ;}

sub FIRSTKEY { my $this = shift ; (sort keys %{$this->{hash}} )[0] }

sub DESTROY  {}

Usando tiehash, necesitas guardar los atributos en el Saver, o llamas a tie().

$$this->{flagx} = 1 ;

Object::MultiType::Saver

Este es un pequeño paquete donde se crean los objetos Saver. Guardará los tipos de datos (SCALAR, ARRAY, HASH, CODE y GLOB) de los objetos principales (Object::MultiType).
