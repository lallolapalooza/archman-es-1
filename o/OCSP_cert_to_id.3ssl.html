OCSP_cert_to_id(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OCSP_CERT_TO_ID(3ssl) OpenSSL OCSP_CERT_TO_ID(3ssl)

NOMBRE

OCSP_cert_to_id, OCSP_cert_id_new, OCSP_CERTID_free, OCSP_id_issuer_cmp, OCSP_id_cmp, OCSP_id_get0_info - Funciones de utilidad para el identificador de certificado OCSP

SINOPSIS

#include <openssl/ocsp.h>
OCSP_CERTID *OCSP_cert_to_id(const EVP_MD *dgst,
                             X509 *subject, X509 *issuer);
OCSP_CERTID *OCSP_cert_id_new(const EVP_MD *dgst,
                              X509_NAME *issuerName,
                              ASN1_BIT_STRING *issuerKey,
                              ASN1_INTEGER *serialNumber);
void OCSP_CERTID_free(OCSP_CERTID *id);
int OCSP_id_issuer_cmp(const OCSP_CERTID *a, const OCSP_CERTID *b);
int OCSP_id_cmp(const OCSP_CERTID *a, const OCSP_CERTID *b);
int OCSP_id_get0_info(ASN1_OCTET_STRING **piNameHash, ASN1_OBJECT **pmd,
                      ASN1_OCTET_STRING **pikeyHash,
                      ASN1_INTEGER **pserial, OCSP_CERTID *cid);

DESCRIPCIÓN

OCSP_cert_to_id() crea y devuelve una nueva estructura OCSP_CERTID utilizando el resumen de mensajes dgst para el certificado subject con el emisor issuer. Si dgst es NULL, se usa SHA1.

OCSP_cert_id_new() crea y devuelve un nuevo OCSP_CERTID utilizando dgst y el nombre del emisor issuerName, el hash de la clave del emisor issuerKey y el número de serie serialNumber.

OCSP_CERTID_free() libera id. Si el argumento es NULL, no se hace nada.

OCSP_id_cmp() compara los OCSP_CERTID a y b.

OCSP_id_issuer_cmp() compara solo el nombre del emisor de los OCSP_CERTID a y b.

OCSP_id_get0_info() devuelve el hash del nombre del emisor, el OID del hash, el hash de la clave del emisor y el número de serie contenidos en cid. Si alguno de los valores no es necesario, el parámetro correspondiente se puede establecer a NULL.

VALORES DE RETORNO

OCSP_cert_to_id() y OCSP_cert_id_new() devuelven un puntero a una estructura OCSP_CERTID válida o NULL si ocurrió un error.

OCSP_id_cmp() y OCSP_id_issuer_cmp() devuelven cero para una coincidencia y un valor distinto de cero en caso contrario.

OCSP_CERTID_free() no devuelve un valor.

OCSP_id_get0_info() devuelve 1 para éxito y 0 para fallo.

NOTAS

Los clientes OCSP normalmente solo usarán OCSP_cert_to_id() u OCSP_cert_id_new(): las otras funciones son utilizadas por las aplicaciones del respondedor.

Los valores devueltos por OCSP_id_get0_info() son punteros internos y la aplicación **NO DEBE** liberarlos: se liberarán cuando la estructura OCSP_CERTID correspondiente sea liberada.
