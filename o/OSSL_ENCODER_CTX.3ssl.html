DESCRIPCIÓN

Codificar un objeto de entrada a un tipo de codificación deseado puede realizarse con una cadena de implementaciones de codificadores, lo que significa que el resultado de un codificador puede ser utilizado como entrada para el siguiente en la cadena. El OSSL_ENCODER_CTX almacena todos los datos sobre estos codificadores. Esto permite tener codificadores genéricos como DER a PEM, así como codificadores más especializados como RSA a DER.

El tipo de salida final debe especificarse, y una cadena de codificadores debe terminar con una implementación que produzca ese tipo de salida.

Al comenzar el proceso de codificación, un constructor proporcionado por el usuario se llama para asegurar que haya un objeto adecuado en el lado del proveedor para iniciar. El constructor se establece con OSSL_ENCODER_CTX_set_construct().

OSSL_ENCODER_INSTANCE es una estructura opaca que contiene datos sobre el codificador que se va a usar, y puede ser útil para el constructor. Hay algunas funciones para extraer datos de este tipo, descritas en "Constructor" a continuación.

Funciones

OSSL_ENCODER_CTX_new() crea un OSSL_ENCODER_CTX.

OSSL_ENCODER_settable_ctx_params() devuelve un array de OSSL_PARAM(3) descriptores de parámetros.

OSSL_ENCODER_CTX_set_params() intenta establecer los parámetros especificados con un array de OSSL_PARAM(3) params. Los parámetros que la implementación no reconoce deben ignorarse.

OSSL_ENCODER_CTX_free() libera el contexto ctx. Si el argumento es NULL, nada se hace.

OSSL_ENCODER_CTX_add_encoder() popula el OSSL_ENCODER_CTX ctx con un codificador, para ser utilizado para codificar un objeto de entrada.

OSSL_ENCODER_CTX_add_extra() encuentra codificadores que más codifican la salida de codificadores ya añadidos, y los añade también. Esto se utiliza para construir cadenas de codificadores.

OSSL_ENCODER_CTX_set_output_type() establece el tipo de salida final. Esto debe especificarse, y determina si una cadena completa de codificadores está disponible.

OSSL_ENCODER_CTX_set_output_structure() establece el tipo de estructura deseado. Esto puede utilizarse para determinar qué implementaciones de codificadores pueden ser usadas. Dependiendo del tipo de objeto a codificar, el tipo de estructura puede no ser relevante.

OSSL_ENCODER_CTX_get_num_encoders() obtiene el número de codificadores actualmente añadidos al contexto ctx.

OSSL_ENCODER_CTX_set_construct() establece el constructor construct.

OSSL_ENCODER_CTX_set_construct_data() establece el dato del constructor que se pasa a cada llamada al constructor.

OSSL_ENCODER_CTX_set_cleanup() establece el dato de limpieza del constructor cleanup. Este se llama por OSSL_ENCODER_CTX_free(3).

Constructor

Un OSSL_ENCODER_CONSTRUCT recibe los siguientes argumentos:

encoder_inst
El OSSL_ENCODER_INSTANCE para el codificador desde el cual el constructor obtiene sus datos.
construct_data
El puntero que fue establecido con OSSL_ENCODE_CTX_set_construct_data().

El constructor espera devolver un puntero válido (no NULL) a un objeto nativo del proveedor que pueda usarse como entrada de una cadena de codificación, o NULL si ha ocurrido un error.

Estas funciones de utilidad pueden ser utilizadas por un constructor:

OSSL_ENCODER_INSTANCE_get_encoder() puede usarse para obtener la implementación del codificador del instanciador encoder_inst.

OSSL_ENCODER_INSTANCE_get_encoder_ctx() puede usarse para obtener el contexto del proveedor de la implementación del codificador del instanciador encoder_inst.

OSSL_ENCODER_INSTANCE_get_output_type() puede usarse para obtener el tipo de salida para la implementación del codificador del instanciador encoder_inst. Este siempre será no NULL.

OSSL_ENCODER_INSTANCE_get_output_structure() puede usarse para obtener el tipo de estructura de salida para la implementación del codificador del instanciador encoder_inst. Esto puede ser NULL.

VALORES DE RETORNO

OSSL_ENCODER_CTX_new() devuelve un puntero a un OSSL_ENCODER_CTX, o NULL si no se pudo alojar el contexto.

OSSL_ENCODER_settable_ctx_params() devuelve un array de OSSL_PARAM(3), o NULL si no hay uno disponible.

OSSL_ENCODER_CTX_set_params() devuelve 1 si todos los parámetros reconocidos eran válidos, o 0 si uno de ellos fue inválido o causó un error en la implementación.

OSSL_ENCODER_CTX_add_encoder(), OSSL_ENCODER_CTX_add_extra(), OSSL_ENCODER_CTX_set_construct(), OSSL_ENCODER_CTX_set_construct_data() y OSSL_ENCODER_CTX_set_cleanup() devuelven 1 en caso de éxito, o 0 en caso de falla.

OSSL_ENCODER_CTX_get_num_encoders() devuelve el número actual de codificadores. Devuelve 0 si ctx es NULL.

OSSL_ENCODER_INSTANCE_get_encoder() devuelve un OSSL_ENCODER en caso de éxito, o NULL en caso de falla.

OSSL_ENCODER_INSTANCE_get_encoder_ctx() devuelve un puntero a un contexto de proveedor en caso de éxito, o NULL en caso de falla.

OSSL_ENCODER_INSTANCE_get_output_type() devuelve una cadena con el nombre del tipo de entrada, si es relevante. NULL es un valor válido devuelto.

OSSL_ENCODER_INSTANCE_get_output_type() devuelve una cadena con el nombre del tipo de salida.

OSSL_ENCODER_INSTANCE_get_output_structure() devuelve una cadena con el nombre del tipo de estructura de salida.
