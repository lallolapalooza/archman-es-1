DESCRIPCIÓN

Una colección de funciones de utilidad que simplifican y añaden seguridad de tipo a los arreglos OSSL_PARAM(3). Los siguientes nombres de **TYPE** se soportan:

  • double
  • int
  • int32 (int32_t)
  • int64 (int64_t)
  • long int (long)
  • time_t
  • size_t
  • uint32 (uint32_t)
  • uint64 (uint64_t)
  • unsigned int (uint)
  • unsigned long int (ulong)

OSSL_PARAM_TYPE() son una serie de macros diseñadas para ayudar a inicializar un arreglo de estructuras OSSL_PARAM(3). Cada una de estas macros define un parámetro del TYPE especificado con la clave y la dirección de la variable del parámetro proporcionadas.

OSSL_PARAM_utf8_string(), OSSL_PARAM_octet_string(), OSSL_PARAM_utf8_ptr(), OSSL_PARAM_octet_ptr(), OSSL_PARAM_BN() son macros que proporcionan soporte para definir cadenas UTF8, cadenas OCTET y números grandes. Se define un parámetro con el nombre key. El almacenamiento para este parámetro está en address y tiene un tamaño de size bytes.

OSSL_PARAM_END proporciona un marcador de fin de lista de parámetros. Esto debería terminar todos los arreglos de OSSL_PARAM(3).

La macro OSSL_PARAM_DEFN() proporciona la capacidad de construir un solo OSSL_PARAM(3) (típicamente utilizado en la construcción de arreglos OSSL_PARAM). Los argumentos key, type, addr y sz corresponden a los campos key, data_type, data y data_size de la estructura OSSL_PARAM(3) como se describe en la página OSSL_PARAM(3).

OSSL_PARAM_construct_TYPE() son una serie de funciones que crean registros OSSL_PARAM(3) dinámicamente. Se crea un parámetro con el nombre key. El parámetro utilizará el almacenamiento apuntado por buf y devolverá el tamaño en ret.

OSSL_PARAM_construct_BN() es una función que construye una estructura de parámetro OSSL_PARAM(3) de número grande. Se crea un parámetro con el nombre key, almacenamiento buf, tamaño bsize y tamaño de retorno rsize.

OSSL_PARAM_construct_utf8_string() es una función que construye una estructura de parámetro de cadena UTF8 OSSL_PARAM(3). Se crea un parámetro con el nombre key, almacenamiento buf y tamaño bsize. Si bsize es cero, la longitud de la cadena se determina usando strlen(3). Generalmente, pase cero para bsize en lugar de llamar a strlen(3) usted mismo.

OSSL_PARAM_construct_octet_string() es una función que construye una estructura de parámetro de cadena OCTET OSSL_PARAM(3). Se crea un parámetro con el nombre key, almacenamiento buf y tamaño bsize.

OSSL_PARAM_construct_utf8_ptr() es una función que construye una estructura de puntero a cadena UTF8 OSSL_PARAM(3). Se crea un parámetro con el nombre key, puntero de almacenamiento *buf y tamaño bsize.

OSSL_PARAM_construct_octet_ptr() es una función que construye una estructura de puntero a cadena OCTET OSSL_PARAM(3). Se crea un parámetro con el nombre key, puntero de almacenamiento *buf y tamaño bsize.

OSSL_PARAM_construct_end() es una función que construye la estructura OSSL_PARAM(3) de terminación.

OSSL_PARAM_locate() es una función que busca en un array de parámetros el que coincida con el nombre key.

OSSL_PARAM_locate_const() se comporta exactamente como OSSL_PARAM_locate() excepto por la presencia de const para el argumento array y su valor de retorno.

VALORES DE RETORNO

OSSL_PARAM_construct_TYPE(), OSSL_PARAM_construct_BN(), OSSL_PARAM_construct_utf8_string(), OSSL_PARAM_construct_octet_string(), OSSL_PARAM_construct_utf8_ptr() y OSSL_PARAM_construct_octet_ptr() devuelven una estructura OSSL_PARAM(3) poblada.

OSSL_PARAM_locate() y OSSL_PARAM_locate_const() devuelven un puntero a un objeto OSSL_PARAM(3) que coincide. Si ocurre un error o no existe ningún objeto que coincida con key en el array, devuelven NULL.

OSSL_PARAM_modified() devuelve 1 si el parámetro param ha sido establecido y 0 en caso contrario.

Todas las otras funciones devuelven 1 en caso de éxito y 0 en caso de fallo.

NOTAS

Los tipos nativos se convertirán solo si el valor es representable exactamente por el tipo objetivo o el parámetro. A menos que se requiera explícitamente, las funciones deben usarse de forma adecuada para el tipo esperado del parámetro.

OSSL_PARAM_get_BN() y OSSL_PARAM_set_BN() solo soportan BIGNUM no negativos cuando el tipo deseado sea OSSL_PARAM_UNSIGNED_INTEGER. OSSL_PARAM_construct_BN() actualmente construye un OSSL_PARAM(3) con el tipo OSSL_PARAM_UNSIGNED_INTEGER.

Para OSSL_PARAM_construct_utf8_ptr() y OSSL_PARAM_construct_octet_ptr(), bsize no es relevante si el propósito es enviar el OSSL_PARAM(3) a un responder, es decir, para obtener datos de parámetros. En ese caso, bsize puede ser establecido a cero de forma segura. Consulte la sección "DESCRIPCIÓN" en OSSL_PARAM(3) para más información sobre los posibles usos.

EJEMPLOS

Reutilizando los ejemplos de OSSL_PARAM(3) para mostrar cómo se pueden manejar los arrays OSSL_PARAM(3) a través de los macros y funciones aquí definidos.

Ejemplo 1

Este ejemplo se usa para establecer parámetros en algún objeto:

#include <openssl/core.h>
const char *foo = "some string";
size_t foo_l = strlen(foo);
const char bar[] = "some other string";
const OSSL_PARAM set[] = {
    OSSL_PARAM_utf8_ptr("foo", &foo, foo_l),
    OSSL_PARAM_utf8_string("bar", bar, sizeof(bar) - 1),
    OSSL_PARAM_END
};

Ejemplo 2

Este ejemplo se usa para solicitar parámetros de algún objeto y muestra que el solicitante no está obligado a solicitar todos los parámetros disponibles:

const char *foo = NULL;
char bar[1024];
OSSL_PARAM request[] = {
    OSSL_PARAM_utf8_ptr("foo", &foo, 0),
    OSSL_PARAM_utf8_string("bar", bar, sizeof(bar)),
    OSSL_PARAM_END
};

Un responder que recibe este array (como "params" en este ejemplo) podría poblar los parámetros así:

/* OSSL_PARAM *params */
OSSL_PARAM *p;
if ((p = OSSL_PARAM_locate(params, "foo")) != NULL)
    OSSL_PARAM_set_utf8_ptr(p, "foo value");
if ((p = OSSL_PARAM_locate(params, "bar")) != NULL)
    OSSL_PARAM_set_utf8_string(p, "bar value");
if ((p = OSSL_PARAM_locate(params, "cookie")) != NULL)
    OSSL_PARAM_set_utf8_ptr(p, "cookie value");

Ejemplo 3

Este ejemplo muestra un caso especial donde -Wincompatible-pointer-types-discards-qualifiers puede estar habilitado durante la compilación. El valor para buf no puede ser un string const char *. Una alternativa en este caso sería usar el macro OSSL_PARAM para llamadas más cortas que los llamadores específicos, lo que permite definir el argumento SHA1 como un array de caracteres estándar (char[]).

Por ejemplo, este código:

OSSL_PARAM params[2];
params[0] = OSSL_PARAM_construct_utf8_string("digest", "SHA1", 0);
params[1] = OSSL_PARAM_construct_end();

puede hacerse compatible con la siguiente versión:

char sha1[] = "SHA1"; /* sha1 se define como char[] en este caso */
OSSL_PARAM params[2];
params[0] = OSSL_PARAM_construct_utf8_string("digest", sha1, 0);
params[1] = OSSL_PARAM_construct_end();
