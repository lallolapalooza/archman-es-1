OSSL_CALLBACK(3ssl) OpenSSL OSSL_CALLBACK(3ssl)

NOMBRE

OSSL_CALLBACK, OSSL_PASSPHRASE_CALLBACK - Tipo principal de OpenSSL para definir callbacks

SINOPSIS

#include <openssl/core.h>
typedef int (OSSL_CALLBACK)(const OSSL_PARAM params[], void *arg);
typedef int (OSSL_PASSPHRASE_CALLBACK)(char *pass, size_t pass_size,
                                       size_t *pass_len,
                                       const OSSL_PARAM params[],
                                       void *arg);

DESCRIPCIÓN

Para ciertos eventos o actividades, la funcionalidad del proveedor puede necesitar ayuda de la aplicación o de las propias bibliotecas de OpenSSL que llaman. Por ejemplo, la entrada del usuario o la salida directa (posiblemente opcional) del usuario podrían implementarse de esta manera.

Las funciones de callback en sí mismas son siempre proporcionadas por o a través de las bibliotecas de OpenSSL que llaman, junto con un puntero genérico a los datos arg. En lo que respecta a la función que recibe el puntero al puntero de función y arg, los datos a los que apunta arg son opacos, y el puntero simplemente debe pasarse de vuelta a la función de callback cuando se llama.

OSSL_CALLBACK
Esta es una función de callback genérica. Al llamar a esta función de callback, se espera que el llamador construya una matriz OSSL_PARAM(3) de datos que desea o se espera que devuelva, y la pase como params, así como el puntero de datos opaco que recibió, como arg.
OSSL_PASSPHRASE_CALLBACK
Esta es una función de callback especializada, utilizada específicamente para solicitar al usuario una contraseña. Al llamar a esta función de callback, se necesita proporcionar un búfer para almacenar la contraseña con pass, y su tamaño con pass_size. La longitud de la contraseña solicitada se devolverá en *pass_len.

Se pueden pasar parámetros adicionales con la matriz OSSL_PARAM(3) params,

VALORES DE RETORNO

Las funciones de tipo OSSL_CALLBACK y OSSL_PASSPHRASE_CALLBACK deben devolver 1 en caso de éxito y 0 en caso de fallo.
