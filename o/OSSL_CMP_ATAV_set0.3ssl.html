OSSL_CMP_ATAV_set0(3ssl)

OSSL_CMP_ATAV_SET0(3ssl) OpenSSL OSSL_CMP_ATAV_SET0(3ssl)

NOMBRE

OSSL_CMP_ATAV, OSSL_CMP_ATAV_create, OSSL_CMP_ATAV_set0, OSSL_CMP_ATAV_get0_type, OSSL_CMP_ATAV_get0_value, OSSL_CMP_ATAV_new_algId, OSSL_CMP_ATAV_get0_algId, OSSL_CMP_ATAV_new_rsaKeyLen, OSSL_CMP_ATAV_get_rsaKeyLen, OSSL_CMP_ATAVS, OSSL_CMP_ATAV_push1, OSSL_CMP_ATAV_free - funciones de utilidad OSSL_CMP_ATAV

SINOPSIS

#include <openssl/cmp.h>
typedef OSSL_CRMF_ATTRIBUTETYPEANDVALUE OSSL_CMP_ATAV;
OSSL_CMP_ATAV *OSSL_CMP_ATAV_create(ASN1_OBJECT *type, ASN1_TYPE *value);
void OSSL_CMP_ATAV_set0(OSSL_CMP_ATAV *atav, ASN1_OBJECT *type,
                        ASN1_TYPE *value);
ASN1_OBJECT *OSSL_CMP_ATAV_get0_type(const OSSL_CMP_ATAV *atav);
ASN1_TYPE *OSSL_CMP_ATAV_get0_value(const OSSL_CMP_ATAV *atav);
OSSL_CMP_ATAV *OSSL_CMP_ATAV_new_algId(const X509_ALGOR *alg);
X509_ALGOR *OSSL_CMP_ATAV_get0_algId(const OSSL_CMP_ATAV *atav);
OSSL_CMP_ATAV *OSSL_CMP_ATAV_new_rsaKeyLen(int len);
int OSSL_CMP_ATAV_get_rsaKeyLen(const OSSL_CMP_ATAV *atav);
typedef STACK_OF(OSSL_CRMF_ATTRIBUTETYPEANDVALUE) OSSL_CMP_ATAVS;
int OSSL_CMP_ATAV_push1(OSSL_CMP_ATAVS **sk_p, const OSSL_CMP_ATAV *atav);
void OSSL_CMP_ATAV_free(OSSL_CMP_ATAV *atav);

DESCRIPCIÓN

OSSL_CMP_ATAV es una abreviatura de OSSL_CRMF_ATTRIBUTETYPEANDVALUE, definida en la RFC 4211 Apéndice B. Se utiliza típicamente en estructuras CertRequest, pero también en estructuras CertReqTemplateContent para especificaciones de claves.

OSSL_CMP_ATAV_create() crea una nueva estructura OSSL_CMP_ATAV y la rellena. Combina OSSL_CMP_ATAV_new() y OSSL_CMP_ATAV_set0().

OSSL_CMP_ATAV_set0() establece el atav con un tipo de información (infoType) type y un valor de información (infoValue) value. Los punteros type y value pueden ser NULL, de lo contrario, no deben liberarse después de la llamada, ya que su propiedad se transfiere a atav. El puntero itav no debe ser NULL.

OSSL_CMP_ATAV_get0_type() devuelve un puntero directo al infoType en el atav, a menos que sea NULL.

OSSL_CMP_ATAV_get0_value() devuelve un puntero directo al infoValue en el atav como un puntero genérico ASN1_TYPE, a menos que atav sea NULL.

OSSL_CMP_ATAV_new_algId() crea una nueva estructura OSSL_CMP_ATAV de tipo algId y la rellena con una copia del alg dado.

OSSL_CMP_ATAV_get0_algId() devuelve un puntero directo al infoValue algId en el atav de tipo X509_ALGOR o NULL si atav es NULL o no contiene un algId.

OSSL_CMP_ATAV_new_rsaKeyLen() crea una nueva estructura OSSL_CMP_ATAV de tipo rsaKeyLen y la rellena con la len dada, que debe ser positiva.

OSSL_CMP_ATAV_get_rsaKeyLen() devuelve la longitud de la clave RSA en el infoValue rsaKeyLen en el atav, -1 si atav es NULL o no contiene un rsaKeyLen o no se puede analizar, o -2 si el valor es menor que 1 o es mayor que INT_MAX.

OSSL_CMP_ATAV_push1() inserta una copia de atav en la pila de OSSL_CMP_ATAV apuntada por *sk_p. Crea una nueva pila si *sk_p apunta a NULL.

OSSL_CMP_ATAV_free() libera atav. Está definida como una macro.

NOTAS

CMP está definido en la RFC 4210. CRMF está definido en la RFC 4211.

VALORES DEVUELTOS

OSSL_CMP_ATAV_create(), OSSL_CMP_ATAV_new_algId(), y OSSL_CMP_ATAV_new_rsaKeyLen() devuelven un puntero a la estructura ATAV en caso de éxito, o NULL en caso de error.

OSSL_CMP_ATAV_set0() y OSSL_CMP_ATAV_free() no devuelven valor.

OSSL_CMP_ATAV_get0_type(), OSSL_CMP_ATAV_get0_value(), y OSSL_CMP_ATAV_get0_algId() devuelven el puntero respectivo o NULL si su entrada es NULL.

OSSL_CMP_ATAV_get_rsaKeyLen() devuelve una longitud de clave en bits o < 0 en caso de error.

OSSL_CMP_ATAV_push1() devuelve 1 en caso de éxito, 0 en caso de error.

VER TAMBIÉN

OSSL_CMP_ITAV_new0_certReqTemplate(3), ASN1_TYPE_set(3)

HISTORIA

El tipo OSSL_CMP_ATAV y las funciones relacionadas se añadieron en OpenSSL 3.4.
