OSSL_ENCODER(3ssl)

OSSL_ENCODER(3ssl) OpenSSL OSSL_ENCODER(3ssl)

NOMBRE

OSSL_ENCODER, OSSL_ENCODER_fetch, OSSL_ENCODER_up_ref, OSSL_ENCODER_free, OSSL_ENCODER_get0_provider, OSSL_ENCODER_get0_properties, OSSL_ENCODER_is_a, OSSL_ENCODER_get0_name, OSSL_ENCODER_get0_description, OSSL_ENCODER_do_all_provided, OSSL_ENCODER_names_do_all, OSSL_ENCODER_gettable_params, OSSL_ENCODER_get_params - Rutinas de métodos codificadores

SINOPSIS

#include <openssl/encoder.h>
typedef struct ossl_encoder_st OSSL_ENCODER;
OSSL_ENCODER *OSSL_ENCODER_fetch(OSSL_LIB_CTX *ctx, const char *name,
                                 const char *properties);
int OSSL_ENCODER_up_ref(OSSL_ENCODER *encoder);
void OSSL_ENCODER_free(OSSL_ENCODER *encoder);
const OSSL_PROVIDER *OSSL_ENCODER_get0_provider(const OSSL_ENCODER *encoder);
const char *OSSL_ENCODER_get0_properties(const OSSL_ENCODER *encoder);
int OSSL_ENCODER_is_a(const OSSL_ENCODER *encoder, const char *name);
const char *OSSL_ENCODER_get0_name(const OSSL_ENCODER *encoder);
const char *OSSL_ENCODER_get0_description(const OSSL_ENCODER *encoder);
void OSSL_ENCODER_do_all_provided(OSSL_LIB_CTX *libctx,
                                  void (*fn)(OSSL_ENCODER *encoder, void *arg),
                                  void *arg);
int OSSL_ENCODER_names_do_all(const OSSL_ENCODER *encoder,
                              void (*fn)(const char *name, void *data),
                              void *data);
const OSSL_PARAM *OSSL_ENCODER_gettable_params(OSSL_ENCODER *encoder);
int OSSL_ENCODER_get_params(OSSL_ENCODER_CTX *ctx, const OSSL_PARAM params[]);

DESCRIPCIÓN

OSSL_ENCODER es un método para codificadores, que saben cómo codificar un objeto de algún tipo a un formato codificado, como PEM, DER o incluso texto legible por humanos.

OSSL_ENCODER_fetch() busca un algoritmo dentro del proveedor que se ha cargado en el OSSL_LIB_CTX dado por ctx, con el nombre dado por name y las propiedades dadas por properties. El name determina qué tipo de objeto se espera que el método codificador recuperado pueda codificar, y las propiedades se utilizan para determinar el tipo de salida esperado. Para propiedades conocidas y los valores que pueden tener, por favor, consulte "Nombres y propiedades" en provider-encoder(7).

OSSL_ENCODER_up_ref() incrementa el contador de referencias para el encoder dado.

OSSL_ENCODER_free() decrementa el contador de referencias para el encoder dado, y cuando el contador llega a cero, lo libera. Si el argumento es NULL, no se hace nada.

OSSL_ENCODER_get0_provider() devuelve el proveedor del encoder dado.

OSSL_ENCODER_get0_properties() devuelve la definición de propiedades asociada con el encoder dado.

OSSL_ENCODER_is_a() comprueba si encoder es una implementación de un algoritmo que se puede identificar con name.

OSSL_ENCODER_get0_name() devuelve el nombre utilizado para recuperar el encoder dado.

OSSL_ENCODER_get0_description() devuelve una descripción del loader, destinada a la visualización y consumo humano. La descripción queda a discreción de la implementación del loader.

OSSL_ENCODER_names_do_all() recorre todos los nombres del encoder dado, y llama a fn con cada nombre y data como argumentos.

OSSL_ENCODER_do_all_provided() recorre todas las implementaciones de codificador de todos los proveedores activados en el contexto de la biblioteca libctx, y para cada una de las implementaciones, llama a fn con el método de implementación y arg como argumentos.

OSSL_ENCODER_gettable_params() devuelve una matriz OSSL_PARAM(3) de descriptores de parámetros.

OSSL_ENCODER_get_params() intenta obtener los parámetros especificados con una matriz OSSL_PARAM(3) params. Los parámetros que la implementación no reconoce deben ignorarse.

VALORES DE RETORNO

OSSL_ENCODER_fetch() devuelve un puntero a la implementación de gestión de claves representada por un objeto OSSL_ENCODER, o NULL si hay un error.

OSSL_ENCODER_up_ref() devuelve 1 en caso de éxito, o 0 en caso de error.

OSSL_ENCODER_free() no devuelve ningún valor.

OSSL_ENCODER_get0_provider() devuelve un puntero a un objeto proveedor, o NULL en caso de error.

OSSL_ENCODER_get0_properties() devuelve un puntero a una cadena de definición de propiedades, o NULL en caso de error.

OSSL_ENCODER_is_a() devuelve 1 si encoder era identificable, de lo contrario 0.

OSSL_ENCODER_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para el encoder dado. Tenga en cuenta que el encoder puede tener varios sinónimos asociados. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad de la cadena devuelta la conserva el objeto encoder y el llamador no debe liberarla.

OSSL_ENCODER_get0_description() devuelve un puntero a una descripción, o NULL si no hay ninguna.

OSSL_ENCODER_names_do_all() devuelve 1 si la función de retorno de llamada se llamó para todos los nombres. Un valor de retorno de 0 significa que la función de retorno de llamada no se llamó para ningún nombre.
