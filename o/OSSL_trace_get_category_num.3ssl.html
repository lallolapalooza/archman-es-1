OSSL_trace_get_category_num(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_TRACE_GET_CATEGORY_NUM(3ssl) OpenSSL OSSL_TRACE_GET_CATEGORY_NUM(3ssl)

NOMBRE

OSSL_trace_get_category_num, OSSL_trace_get_category_name - Funciones de información de trazado de OpenSSL

SINOPSIS

#include <openssl/trace.h>
int OSSL_trace_get_category_num(const char *name);
const char *OSSL_trace_get_category_name(int num);

DESCRIPCIÓN

OSSL_trace_get_category_num() devuelve el número de categoría correspondiente al "name" dado.

OSSL_trace_get_category_name() devuelve el nombre de la categoría correspondiente al "num" dado.

VALORES DEVUELTOS

OSSL_trace_get_category_num() devuelve el número de categoría si el "name" dado es un nombre de categoría reconocido, de lo contrario devuelve -1.

OSSL_trace_get_category_name() devuelve el nombre de la categoría si el "num" dado es un número de categoría reconocido, de lo contrario devuelve NULL.

HISTORIAL

La API de Trazado de OpenSSL se añadió en OpenSSL 3.0.
