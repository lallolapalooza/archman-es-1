OSSL_CMP_STATUSINFO_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_CMP_STATUSINFO_NEW(3ssl) OpenSSL OSSL_CMP_STATUSINFO_NEW(3ssl)

NOMBRE

OSSL_CMP_STATUSINFO_new, OSSL_CMP_snprint_PKIStatusInfo, OSSL_CMP_CTX_snprint_PKIStatus - función(es) para gestionar el PKIStatus CMP

SINOPSIS

#include <openssl/cmp.h>
OSSL_CMP_PKISI *OSSL_CMP_STATUSINFO_new(int status, int fail_info,
                                        const char *text);
char *OSSL_CMP_snprint_PKIStatusInfo(const OSSL_CMP_PKISI *statusInfo,
                                     char *buf, size_t bufsize);
char *OSSL_CMP_CTX_snprint_PKIStatus(const OSSL_CMP_CTX *ctx, char *buf,
                                     size_t bufsize);

DESCRIPCIÓN

Esta es la API PKIStatus para usar CMP (Certificate Management Protocol) con OpenSSL.

OSSL_CMP_STATUSINFO_new() crea una nueva estructura PKIStatusInfo y la rellena con los valores dados. Establece el campo status a status, copia text (a menos que sea NULL) a statusString, e interpreta fail_info como un patrón de bits para el campo failInfo.

OSSL_CMP_snprint_PKIStatusInfo() coloca una cadena legible por humanos que representa el statusInfo dado en el búfer provisto, con la longitud máxima especificada.

OSSL_CMP_CTX_snprint_PKIStatus() coloca una cadena legible por humanos que representa los componentes PKIStatusInfo del contexto CMP ctx en el búfer provisto, con la longitud máxima especificada.

NOTAS

CMP está definido en RFC 4210 (y CRMF en RFC 4211).

VALORES DE RETORNO

OSSL_CMP_STATUSINFO_new() devuelve un puntero a la estructura en caso de éxito, o NULL en caso de error.

OSSL_CMP_snprint_PKIStatusInfo() y OSSL_CMP_CTX_snprint_PKIStatus() devuelven una copia del puntero al búfer que contiene la cadena o NULL en caso de error.

HISTORIA

El soporte de CMP de OpenSSL se añadió en OpenSSL 3.0.
