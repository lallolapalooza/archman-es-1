NOMBRE

i2t_ASN1_OBJECT, OBJ_length, OBJ_get0_data, OBJ_nid2obj, OBJ_nid2ln, OBJ_nid2sn, OBJ_obj2nid, OBJ_txt2nid, OBJ_ln2nid, OBJ_sn2nid, OBJ_cmp, OBJ_dup, OBJ_txt2obj, OBJ_obj2txt, OBJ_create, OBJ_cleanup, OBJ_add_sigid - Funciones de utilidad para estructuras ASN1_object

SINOPSIS

#include <openssl/objects.h>
ASN1_OBJECT *OBJ_nid2obj(int n);
const char *OBJ_nid2ln(int n);
const char *OBJ_nid2sn(int n);
int OBJ_obj2nid(const ASN1_OBJECT *o);
int OBJ_ln2nid(const char *ln);
int OBJ_sn2nid(const char *sn);
int OBJ_txt2nid(const char *s);
ASN1_OBJECT *OBJ_txt2obj(const char *s, int no_name);
int OBJ_obj2txt(char *buf, int buf_len, const ASN1_OBJECT *a, int no_name);
int i2t_ASN1_OBJECT(char *buf, int buf_len, const ASN1_OBJECT *a);
int OBJ_cmp(const ASN1_OBJECT *a, const ASN1_OBJECT *b);
ASN1_OBJECT *OBJ_dup(const ASN1_OBJECT *o);
int OBJ_create(const char *oid, const char *sn, const char *ln);
size_t OBJ_length(const ASN1_OBJECT *obj);
const unsigned char *OBJ_get0_data(const ASN1_OBJECT *obj);
int OBJ_add_sigid(int signid, int dig_id, int pkey_id);

Las siguientes funciones han sido obsoletas desde OpenSSL 1.1.0 y pueden ser ocultadas completamente definido OPENSSL_API_COMPAT con un valor adecuado, ver openssl_user_macros(7):

void OBJ_cleanup(void);

DESCRIPCIÓN

Las funciones de utilidad para estructuras ASN1_OBJECT procesan estructuras ASN1_OBJECT que representan el tipo ASN1_OBJECT IDENTIFICADOR (OID). Para conveniencia, los OID se representan generalmente como identificadores numéricos o NID. OpenSSL tiene una tabla interna de OID generados al momento de la construcción del biblioteca, y sus correspondientes NIDs están disponibles como constantes definidas. Para las funciones siguientes, el código de aplicación debe tratar todos los valores devueltos —OID, NID o nombres— como constantes.

OBJ_nid2obj(), OBJ_nid2ln() y OBJ_nid2sn() convierten el NID n en una estructura ASN1_OBJECT, su nombre largo y su nombre corto, o NULL si ha ocurrido un error.

OBJ_obj2nid(), OBJ_ln2nid(), OBJ_sn2nid() y OBJ_txt2nid() devuelven el correspondiente NID para el objeto o, el nombre largo ln o el nombre corto sn, o NID_undef si ha ocurrido un error.

OBJ_txt2nid() devuelve el NID correspondiente a la cadena de texto s. s puede ser un nombre largo, un nombre corto o la representación numérica de un objeto.

OBJ_txt2obj() convierte la cadena de texto s en una estructura ASN1_OBJECT. Si no_name es 0, se interpretan los nombres largos y cortos así como las formas numéricas. Si no_name es 1, solo se acepta la forma numérica.

OBJ_obj2txt() convierte la estructura ASN1_OBJECT a en una representación textual. No se usa el nombre buf si es NULL, la representación se escribe como una cadena NUL-terminada a buf, donde se escriben hasta buf_len bytes, truncando el resultado si es necesario. En todo caso, devuelve la longitud total de la cadena, sin el carácter NUL, requerida para representación no truncada, o -1 en error. Si no_name es 0, si el objeto tiene un nombre largo o corto, se usará ese nombre, de lo contrario se usará la forma numérica. Si no_name es 1, siempre se usará la forma numérica.

i2t_ASN1_OBJECT() es la misma que OBJ_obj2txt() con no_name establecido a cero.

OBJ_cmp() compara a con b. Si son iguales devuelve 0.

OBJ_dup() devuelve una copia de o.

OBJ_create() agrega un nuevo objeto a la tabla interna. oid es la forma numérica del objeto, sn el nombre corto y ln el nombre largo. En caso de éxito, se devuelve un nuevo NID para el objeto creado, y NID_undef en caso de error. Cualquier de oid, sn o ln puede ser NULL, pero no todos a la vez.

OBJ_length() devuelve el tamaño en octetos de los contenidos de obj.

OBJ_get0_data() devuelve un puntero al contenido octetos de obj. El puntero devuelto es un puntero interno que debe no ser liberado.

OBJ_add_sigid() crea un nuevo composite "Signature Algorithm" que asocia un NID con otros dos NIDs - uno representando el algoritmo de firma bajo y otro representando un algoritmo de digesto a usarse junto con él. signid representa el NID para el composite "Signature Algorithm", dig_id es el NID para el algoritmo de digesto y pkey_id es el NID para el algoritmo de firma bajo. Como hay algoritmos de firma que no requieren un digesto, NID_undef es válido como dig_id.

OBJ_cleanup() libera los recursos asignados al crear nuevos objetos.

NOTAS

Los objetos de OpenSSL pueden tener un nombre corto, un nombre largo y un identificador numérico (NID) asociado. Un conjunto estándar de objetos se representa en una tabla interna. Los valores adecuados son definidos en el archivo de cabecera objects.h.

Por ejemplo, la OID para commonName tiene las siguientes definiciones:

#define SN_commonName                   "CN"
#define LN_commonName                   "commonName"
#define NID_commonName                  13

Los objetos nuevos pueden ser añadidos llamando a OBJ_create().

Los objetos de tabla tienen ciertas ventajas sobre otros objetos: por ejemplo, sus NIDs pueden usarse en una instrucción de C switch. También son estructuras estáticas constantes compartidas: es decir, hay solo una estructura constante para cada objeto de tabla.

Los objetos que no estén en la tabla tienen el valor NID_undef.

Los objetos no necesitan estar en las tablas internas para ser procesados, las funciones OBJ_txt2obj() y OBJ_obj2txt() pueden procesar la forma numérica de un OID.

Algunos objetos se utilizan para representar algoritmos que no tienen una codificación correspondiente de ASN.1 OBJECT IDENTIFIER (por ejemplo, no existe actualmente un OID para un algoritmo particular). Como resultado, no pueden ser codificados o descodificadas como parte de estructuras ASN.1. Las aplicaciones pueden determinar si existe una correspondencia de OBJECT IDENTIFIER llamando a OBJ_length() y verificando que no sea cero.

Estas funciones no pueden devolver const porque un ASN1_OBJECT puede representar tanto un OID interno constante como uno dinámicamente creado. El último no puede ser constante porque necesita ser liberado después de su uso.

Estas funciones no eran seguras en OpenSSL 3.0 y antes.

VALORES DE RETORNO

OBJ_nid2obj() devuelve una estructura ASN1_OBJECT o NULL si ha ocurrido un error.

OBJ_nid2ln() y OBJ_nid2sn() devuelven un string válido o NULL en caso de error.

OBJ_obj2nid(), OBJ_ln2nid(), OBJ_sn2nid() y OBJ_txt2nid() devuelven un NID o NID_undef en caso de error.

OBJ_add_sigid() devuelve 1 en caso de éxito o 0 en caso de error.

i2t_ASN1_OBJECT() devuelve -1 en caso de error, y devuelve la longitud de la cadena escrita a buf si buf no es NULL y buf_len es suficientemente grande, de lo contrario devuelve la longitud total de la cadena. Nota: esta no cuenta el carácter NUL al final.

EJEMPLOS

Crear un objeto para commonName:

ASN1_OBJECT *o = OBJ_nid2obj(NID_commonName);

Verificar si un objeto es commonName

if (OBJ_obj2nid(obj) == NID_commonName)
    /* Hacer algo */

Crear un nuevo NID y inicializar un objeto a partir de él:

int new_nid = OBJ_create("1.2.3.4", "NewOID", "New Object Identifier");
ASN1_OBJECT *obj = OBJ_nid2obj(new_nid);

Crear un objeto directamente:

obj = OBJ_txt2obj("1.2.3.4", 1);

openssl - OBJ_nid2obj(3ssl)

NAME

OBJ_nid2obj, OBJ_obj2nid, OBJ_nid2ln, OBJ_nid2sn, OBJ_obj2txt, OBJ_txt2nid, OBJ_txt2obj, OBJ_bsearch_by_nid, OBJ_add_obj, OBJ_create_tree, OBJ_free_tree, OBJ_cleanup - Object Identifiers utility functions

SYNOPSIS

#include <openssl/objects.h>

ASN1_OBJECT *OBJ_nid2obj(int n);
int OBJ_obj2nid(const ASN1_OBJECT *o);
const char *OBJ_nid2ln(int n);
const char *OBJ_nid2sn(int n);
int OBJ_obj2txt(char *buf, int buf_len, const ASN1_OBJECT *a, int no_name);
int OBJ_txt2nid(const char *s);
const ASN1_OBJECT *OBJ_txt2obj(const char *s, int no_advance);
int OBJ_bsearch_by_nid(int *conf, const int *cn, int n);
int OBJ_add_obj(const ASN1_OBJECT *obj, int priority);
int OBJ_create_tree(const ASN1_OBJECT *obj, int priority);
void OBJ_free_tree(void);
void OBJ_cleanup(void);

DESCRIPTION

These functions provide a means to access and manipulate OpenSSL's internal Object Identifier (OID) database.

The OID database maps numerical OID values to symbolic names, long names, and short names. It also supports conversion between numerical and textual OID representations.

  • OBJ_nid2obj() takes an OID number (NID) and returns a pointer to the corresponding ASN1_OBJECT structure. The returned pointer is owned by the caller and should not be freed.

  • OBJ_obj2nid() takes an ASN1_OBJECT and returns its associated NID. If the object is not found in the database, it returns NID_undef.

  • OBJ_nid2ln() returns the long name associated with the given NID. If no long name is found, it returns NULL.

  • OBJ_nid2sn() returns the short name associated with the given NID. If no short name is found, it returns NULL.

  • OBJ_obj2txt() converts an ASN1_OBJECT into a text string. If buf is not NULL, the string is written into buf with a maximum length of buf_len. If buf is NULL, the required length is returned. If no_name is non-zero, only the numerical OID is written, otherwise both the numerical OID and any associated name are written.

  • OBJ_txt2nid() converts a text string representing an OID (either numerical or a known name) into its corresponding NID. If the string is not found, it returns NID_undef.

  • OBJ_txt2obj() converts a text string representing an OID into an ASN1_OBJECT. If no_advance is non-zero, the string pointer is not advanced. The returned ASN1_OBJECT is owned by the caller and must be freed using ASN1_OBJECT_free().

  • OBJ_bsearch_by_nid() is an internal function used for searching the OID database by NID.

  • OBJ_add_obj() adds a new ASN1_OBJECT to the database with the specified priority. Higher priority values mean the object is preferred.

  • OBJ_create_tree() creates a tree structure for OIDs. This is an internal function and generally not needed by application developers.

  • OBJ_free_tree() frees the OID tree structure. This is an internal function.

  • OBJ_cleanup() frees all resources associated with the OID database. This should be called when the OpenSSL library is no longer needed.

NOTES

The OID database is initialized when OpenSSL is first used. It can be dynamically extended using OBJ_add_obj().

The returned strings from OBJ_nid2ln() and OBJ_nid2sn() are static and should not be freed.

OBJ_txt2obj() may allocate memory, and the returned ASN1_OBJECT should be freed using ASN1_OBJECT_free().

RETURN VALUES

Functions typically return values indicating success or failure, or the result of the conversion. Specific return values are detailed in the descriptions above.

EXAMPLES

/* Convert a NID to an ASN1_OBJECT */
int nid = NID_sha256;
ASN1_OBJECT *obj = OBJ_nid2obj(nid);
if (obj == NULL) {
    /* handle error */
}
/* ... use obj ... */
/* The returned object should not be freed */

/* Convert an ASN1_OBJECT to a NID */
int nid_from_obj = OBJ_obj2nid(obj);

/* Convert a NID to its long name */
const char *long_name = OBJ_nid2ln(nid);

/* Convert a text OID string to a NID */
int nid_from_txt = OBJ_txt2nid("1.2.840.113549.1.1.11"); /* sha256WithRSAEncryption */

/* Convert a text OID string to an ASN1_OBJECT */
const ASN1_OBJECT *obj_from_txt = OBJ_txt2obj("2.16.840.1.101.3.4.2.1", 0); /* sha256 */
if (obj_from_txt == NULL) {
    /* handle error */
}
/* ... use obj_from_txt ... */
ASN1_OBJECT_free((ASN1_OBJECT *)obj_from_txt); /* Free the allocated object */
