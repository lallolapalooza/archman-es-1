OSSL_PARAM_allocate_from_text(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_PARAM_allocate_from_text(3ssl) OpenSSL OSSL_PARAM_allocate_from_text(3ssl)

NOMBRE

OSSL_PARAM_allocate_from_text - Utilidades para la construcción de OSSL_PARAM

SINTAXIS

#include <openssl/params.h>
int OSSL_PARAM_allocate_from_text(OSSL_PARAM *to,
                                  const OSSL_PARAM *paramdefs,
                                  const char *key, const char *value,
                                  size_t value_n,
                                  int *found);

DESCRIPCIÓN

Antes de OpenSSL versión 3.0, los parámetros se pasaban a o se recuperaban de las implementaciones de algoritmo mediante funciones de control. Algunas de estas funciones de control existían en variaciones que aceptaban parámetros de cadena, por ejemplo EVP_PKEY_CTX_ctrl_str(3).

OpenSSL 3.0 introduce un nuevo mecanismo para hacer lo mismo con un conjunto de parámetros que contienen nombre, valor, tipo de valor y tamaño del valor (ver OSSL_PARAM(3) para más información).

OSSL_PARAM_allocate_from_text() usa key para buscar un elemento en paramdefs. Si se encuentra un elemento, convierte value en algo adecuado para el tipo de valor del elemento encontrado, y almacena el resultado en to->data junto con su tamaño en to->data_size. to->key y to->data_type se asignan los valores correspondientes del elemento encontrado, y to->return_size se establece en cero.

to->data siempre se asigna con OPENSSL_zalloc(3) y debe ser liberado por el llamador cuando ya no se use, usando OPENSSL_free(3).

Si found no es nulo, *found se establece en 1 si key puede encontrarse en paramdefs, y en 0 de lo contrario.

Uso del key y value en detalle

OSSL_PARAM_allocate_from_text() tiene en cuenta si key comienza con "hex" y solo usa el resto de key para buscar un elemento en paramdefs en ese caso. Como ejemplo, si key es "hexid", se busca "id" en paramdefs.

Cuando un elemento en paramdefs ha sido encontrado, value se convierte según el tipo de valor del elemento encontrado, de la siguiente manera:

OSSL_PARAM_INTEGER y OSSL_PARAM_UNSIGNED_INTEGER
Si key no comenzó con "hex", se asume que value contiene value_n caracteres decimales, que se decodifican, y los bytes resultantes se convierten en el número almacenado en el almacenamiento de to->data.

Si value comienza con "0x", se asume que contiene value_n caracteres hexadecimales.

Si key comenzó con "hex", se asume que value contiene value_n caracteres hexadecimales sin el prefijo "0x".

Si value contiene caracteres que no se pueden decodificar como hexadecimales o decimales, OSSL_PARAM_allocate_from_text() considera eso un error.

OSSL_PARAM_UTF8_STRING
Si key comenzó con "hex", OSSL_PARAM_allocate_from_text() considera eso un error.

De lo contrario, se considera value una cadena C y se copia al almacenamiento de to->data. En sistemas donde el código de caracteres nativo es EBCDIC, los bytes en to->data se convierten a ASCII.

OSSL_PARAM_OCTET_STRING
Si key comenzó con "hex", se asume que value contiene value_n caracteres hexadecimales, que se decodifican, y los bytes resultantes se almacenan en el almacenamiento de to->data. Si value contiene caracteres que no se pueden decodificar como hexadecimales o decimales, OSSL_PARAM_allocate_from_text() considera eso un error.

Si key no comenzó con "hex", se copian value_n bytes de value al almacenamiento de to->data.

VALOR DE RETORNO

OSSL_PARAM_allocate_from_text() devuelve 1 si key se encuentra en paramdefs y no hay otros errores, de lo contrario 0.

NOTAS

El array de descripción de parámetros proviene de funciones dedicadas a devolverlos. Los siguientes atributos de OSSL_PARAM(3) se utilizan:

key
data_type
data_size

Todos los otros atributos se ignoran.

El atributo data_size puede ser cero, lo que significa que se espera que el parámetro que describe datos de cualquier longitud.

EJEMPLOS

Código que parecía así:

int mac_ctrl_string(EVP_PKEY_CTX *ctx, const char *value)
{
    int rv;
    char *stmp, *vtmp = NULL;
    stmp = OPENSSL_strdup(value);
    if (stmp == NULL)
        return -1;
    vtmp = strchr(stmp, ':');
    if (vtmp != NULL)
        *vtmp++ = '\0';
    rv = EVP_MAC_ctrl_str(ctx, stmp, vtmp);
    OPENSSL_free(stmp);
    return rv;
}
...
for (i = 0; i < sk_OPENSSL_STRING_num(macopts); i++) {
    char *macopt = sk_OPENSSL_STRING_value(macopts, i);
    if (pkey_ctrl_string(mac_ctx, macopt) <= 0) {
        BIO_printf(bio_err,
                   "MAC parameter error \"%s\"\n", macopt);
        ERR_print_errors(bio_err);
        goto mac_end;
    }
}

Puede ser escrito así en su lugar:

 OSSL_PARAM *params =
     OPENSSL_zalloc(sizeof(*params)
                    * (sk_OPENSSL_STRING_num(opts) + 1));
 const OSSL_PARAM *paramdefs = EVP_MAC_settable_ctx_params(mac);
 size_t params_n;
 char *opt = "<unknown>";
 for (params_n = 0; params_n < (size_t)sk_OPENSSL_STRING_num(opts);
      params_n++) {
     char *stmp, *vtmp = NULL;
     opt = sk_OPENSSL_STRING_value(opts, (int)params_n);
     if ((stmp = OPENSSL_strdup(opt)) == NULL
             || (vtmp = strchr(stmp, ':')) == NULL)
         goto err;
     *vtmp++ = '\0';
     if (!OSSL_PARAM_allocate_from_text(&params[params_n],
                                        paramdefs, stmp,
                                        vtmp, strlen(vtmp), NULL))
         goto err;
 }
 params[params_n] = OSSL_PARAM_construct_end();
 if (!EVP_MAC_CTX_set_params(ctx, params))
     goto err;
 while (params_n-- > 0)
     OPENSSL_free(params[params_n].data);
 OPENSSL_free(params);
 /* ... */
 return;
err:
 BIO_printf(bio_err, "MAC parameter error '%s'\n", opt);
 ERR_print_errors(bio_err);
