OMPI_Affinity_str(3)

Paquete: openmpi

OMPI_AFFINITY_STR(3) Open MPI OMPI_AFFINITY_STR(3)

OMPI_Affinity_str - Obtener cadenas de texto legible de la información de afinidad de procesador para este proceso

SINTAXIS

Sintaxis C

#include <mpi.h>
#include <mpi-ext.h>
int OMPI_Affinity_str(ompi_affinity_fmt_type_t fmt_type,
                      char ompi_bound[OMPI_AFFINITY_STRING_MAX],
                      char current_binding[OMPI_AFFINITY_STRING_MAX],
                      char exists[OMPI_AFFINITY_STRING_MAX])

Sintaxis Fortran

Sintaxis Fortran 2008

No hay enlace Fortran 2008 para esta función.

Sintaxis C++

PARÁMETROS DE ENTRADA

  • fmt_type: Una enumeración que indica cómo formatear las cadenas ompi_bound y current_binding devueltas. OMPI_AFFINITY_RSRC_STRING_FMT devuelve la cadena como nombres de recursos legibles, como "socket 0, core 0".
  • OMPI_AFFINITY_LAYOUT_FMT devuelve arte ASCII que representa dónde este proceso MPI: está enlazado en relación con el diseño de recursos de la máquina. Por ejemplo, "[. B][. .]" muestra que el proceso que llamó a la rutina está enlazado al socket 0, core 1 en un sistema con 2 sockets, cada uno con 2 cores.
  • Ver más ejemplos de salida a continuación.:

PARÁMETROS DE SALIDA

  • ompi_bound: Una cadena de texto legible que describe a qué procesador(es) enlazó Open MPI a este proceso, o una cadena que indica que Open MPI no enlazó este proceso.
  • current_binding: Una cadena de texto legible que describe a qué procesador(es) está actualmente enlazado este proceso, o una cadena que indica que el proceso está enlazado a todos los procesadores disponibles (y, por lo tanto, se considera "no enlazado").
  • exists: Una cadena de texto legible que describe los sockets y cores disponibles en este host.

DESCRIPCIÓN

Open MPI puede enlazar un proceso a sockets y/o cores específicos al lanzar el proceso. Esta llamada de función no estándar de Open MPI devuelve información legible sobre tres cosas:

Dónde enlazó Open MPI a este proceso.
La cadena devuelta en ompi_bound indicará si Open MPI no enlazó este proceso a nada, o contendrá una descripción legible de los procesadores a los que Open MPI enlazó este proceso.
Dónde está actualmente enlazado este proceso.
Independientemente de si Open MPI enlazó este proceso o no, otra entidad podría haberlo hecho. La cadena devuelta en current_binding indicará cuál es el enlace *actual* de este proceso, independientemente de lo que Open MPI haya hecho anteriormente. La cadena devuelta indicará si el proceso no está enlazado (lo que significa que está enlazado a todos los procesadores disponibles) o contendrá una descripción legible de los sockets y cores a los que el proceso está actualmente enlazado.
Qué procesadores existen.
Como conveniencia para el usuario, la cadena exists contendrá una descripción legible de los sockets y cores que este proceso puede ver (que *normalmente* son todos los procesadores del sistema).

EJEMPLOS

Ejemplo 1: Imprimir los enlaces de procesos usando el formato de cadena de recursos.

int rank;
char ompi_bound[OMPI_AFFINITY_STRING_MAX];
char current_binding[OMPI_AFFINITY_STRING_MAX];
char exists[OMPI_AFFINITY_STRING_MAX];
MPI_Init(&argc, &argv);
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
OMPI_Affinity_str(OMPI_AFFINITY_RSRC_STRING_FMT,
                  ompi_bound, current_binding, exists);
printf("rango %d: \n"
       "       ompi_bound: %s\n"
       "  current_binding: %s\n"
       "           exists: %s\n",
       rank, ompi_bound, current_binding, exists);
...

Salida de mpirun -n 2 -bind-to-core a.out:

rango 0:
       ompi_bound: socket 0[core 0]
  current_binding: socket 0[core 0]
           exists: socket 0 tiene 4 cores
rango 1:
       ompi_bound: socket 0[core 1]
  current_binding: socket 0[core 1]
           exists: socket 0 tiene 4 cores

Salida de mpirun -n 2 -bind-to-socket a.out:

rango 0:
       ompi_bound: socket 0[core 0-3]
  current_binding: No enlazado (o enlazado a todos los procesadores disponibles)
           exists: socket 0 tiene 4 cores
rango 1:
       ompi_bound: socket 0[core 0-3]
  current_binding: No enlazado (o enlazado a todos los procesadores disponibles)
           exists: socket 0 tiene 4 cores
Ejemplo 2: Imprimir los enlaces de procesos usando el formato de cadena
de diseño.
int rank;
char ompi_bound[OMPI_AFFINITY_STRING_MAX];
char current_binding[OMPI_AFFINITY_STRING_MAX];
char exists[OMPI_AFFINITY_STRING_MAX];
MPI_Init(&argc, &argv);
MPI_Comm_rank(MPI_COMM_WORLD, &rank);
OMPI_Affinity_str(OMPI_AFFINITY_LAYOUT_FMT,
                  ompi_bound, current_binding, exists);
printf("rango %d: \n"
       "       ompi_bound: %s\n"
       "  current_binding: %s\n"
       "           exists: %s\n",
       rank, ompi_bound, current_binding, exists);
...
