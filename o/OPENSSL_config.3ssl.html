Paquete: openssl

OPENSSL_CONFIG(3ssl) OpenSSL OPENSSL_CONFIG(3ssl)

NOMBRE

OPENSSL_config, OPENSSL_no_config - funciones de configuración sencillas de OpenSSL

SINOPSIS

#include <openssl/conf.h>

Las siguientes funciones han sido deprecadas desde OpenSSL 1.1.0, y pueden ocultarse completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

void OPENSSL_config(const char *appname);
void OPENSSL_no_config(void);

DESCRIPCIÓN

OPENSSL_config() configura OpenSSL utilizando el archivo estándar openssl.cnf y lee de la sección de la aplicación appname. Si appname es NULL, se utilizará la sección por defecto, openssl_conf. Los errores se ignoran silenciosamente. Las llamadas múltiples no tienen efecto.

OPENSSL_no_config() deshabilita la configuración. Si se llama antes que OPENSSL_config(), no se produce ninguna configuración.

Si la aplicación se compila con OPENSSL_LOAD_CONF definido, una llamada a OpenSSL_add_all_algorithms() llamará implícitamente a OPENSSL_config() primero.

NOTAS

La función OPENSSL_config() está diseñada para ser una función muy simple de "llámala y olvídate". Sin embargo, es mucho mejor que nada. Las aplicaciones que necesitan un control más fino sobre su funcionalidad de configuración deben usar directamente las funciones de configuración como CONF_modules_load(). Esta función está deprecada y se debe evitar su uso. Las aplicaciones deben llamar a CONF_modules_load() durante la inicialización (es decir, antes de iniciar cualquier hilo).

Hay varias razones por las que llamar a las rutinas de configuración de OpenSSL es aconsejable. Por ejemplo, para cargar ENGINEs dinámicos desde bibliotecas compartidas (DSO). Sin embargo, muy pocas aplicaciones admiten actualmente la interfaz de control y, por lo tanto, muy pocas pueden cargar y utilizar ENGINEs dinámicos. Igualmente, en el futuro, los ENGINEs más sofisticados requerirán ciertas operaciones de control para personalizarlos. Si una aplicación llama a OPENSSL_config(), no necesita conocer ni preocuparse por las operaciones de control de ENGINEs, ya que estas pueden realizarse editando un archivo de configuración.

MEDIO AMBIENTE

OPENSSL_CONF
La ruta al archivo de configuración. Se ignora en programas con permisos de usuario o grupo establecidos.

VALORES DE RETORNO

Ni OPENSSL_config() ni OPENSSL_no_config() devuelven un valor.

VER TAMBIÉN

config(5), CONF_modules_load_file(3)

HISTORIA

Las funciones OPENSSL_no_config() y OPENSSL_config() fueron deprecadas en OpenSSL 1.1.0 por OPENSSL_init_crypto().
