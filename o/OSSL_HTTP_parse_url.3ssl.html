OSSL_HTTP_parse_url(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_HTTP_PARSE_URL(3ssl) OpenSSL OSSL_HTTP_PARSE_URL(3ssl)

NOMBRE

OSSL_HTTP_adapt_proxy, OSSL_parse_url, OSSL_HTTP_parse_url, OCSP_parse_url - funciones de utilidad http

SINOPSIS

#include <openssl/http.h>
const char *OSSL_HTTP_adapt_proxy(const char *proxy, const char *no_proxy,
                                  const char *server, int use_ssl);
int OSSL_parse_url(const char *url, char **pscheme, char **puser, char **phost,
                   char **pport, int *pport_num,
                   char **ppath, char **pquery, char **pfrag);
int OSSL_HTTP_parse_url(const char *url,
                        int *pssl, char **puser, char **phost,
                        char **pport, int *pport_num,
                        char **ppath, char **pquery, char **pfrag);

Las siguientes funciones han sido obsoletas desde OpenSSL 3.0 y pueden ocultarse por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, véase openssl_user_macros(7):

int OCSP_parse_url(const char *url, char **phost, char **pport, char **ppath,
                   int *pssl);

DESCRIPCIÓN

OSSL_HTTP_adapt_proxy() toma un nombre de host de proxy opcional proxy y lo devuelve transformado según el parámetro opcional no_proxy, server, use_ssl y la variable de entorno aplicable, de la siguiente manera. Si proxy es NULL, toma cualquier valor predeterminado de la variable de entorno "http_proxy", o de "https_proxy" si use_ssl no es cero. Si esto aún no produce un nombre de host de proxy, toma cualquier valor predeterminado adicional de la variable de entorno "HTTP_PROXY", o de "HTTPS_PROXY" si use_ssl no es cero. Si no_proxy es NULL, toma cualquier valor de exclusión predeterminado de la variable de entorno "no_proxy", o de lo contrario de "NO_PROXY". Devuelve el host de proxy determinado a menos que el valor de exclusión, que es una lista de hosts de proxy separados por "," y/o espacios en blanco, contenga server. De lo contrario, devuelve NULL. Cuando server es una cadena delimitada por "[" y "]", que se utilizan para direcciones IPv6, se eliminan los corchetes "[" y "]" circundantes antes de la comparación.

OSSL_parse_url() analiza su cadena de entrada url como una URL de la forma "[esquema://][info_usuario@]host[:puerto][/ruta][?consulta][#fragmento]" y la divide en componentes de esquema, información de usuario, host, puerto, ruta, consulta y fragmento. El componente host (o servidor) puede ser un nombre DNS o una dirección IP, donde las direcciones IPv6 deben estar entre corchetes "[" y "]". El componente de puerto es opcional y por defecto es 0. Si se proporciona, debe estar en formato decimal. Si el argumento pport_num no es NULL, el valor entero del número de puerto se asigna a *pport_num en caso de éxito. El componente de ruta también es opcional y por defecto es "/". Cada argumento de puntero de resultado no NULL pscheme, puser, phost, pport, ppath, pquery y pfrag, recibe el componente de URL respectivo. Cualquier dirección IPv6 en *phost está rodeada por "[" y "]". En caso de éxito, se garantiza que contendrán punteros a cadenas no NULL, de lo contrario NULL. Es responsabilidad del llamante liberarlos usando OPENSSL_free(3). Si pquery es NULL, cualquier componente de consulta dado se maneja como parte de la ruta. Se garantiza que una cadena devuelta a través de *ppath comienza con un carácter "/". Para esquemas, información de usuario, puertos, consultas y fragmentos ausentes se proporciona una cadena vacía.

OSSL_HTTP_parse_url() es una forma especial de OSSL_parse_url() donde el esquema, si se proporciona, debe ser "http" o "https". Si pssl no es NULL, *pssl se asigna 1 si el análisis fue exitoso y el esquema es "https", de lo contrario 0. El componente de puerto es opcional y por defecto es 443 si el esquema es "https", de lo contrario 80. Tenga en cuenta que las rutas relativas deben proporcionarse con una "/" inicial, de lo contrario, el primer elemento de la ruta se interpreta como el host.

Llamar a la función obsoleta OCSP_parse_url(url, host, port, path, ssl) es equivalente a OSSL_HTTP_parse_url(url, ssl, NULL, host, port, NULL, path, NULL, NULL).

VALORES DE RETORNO

OSSL_HTTP_adapt_proxy() devuelve NULL si no se debe usar ningún proxy, de lo contrario, una cadena constante del nombre de host del proxy, que es el nombre del proxy proporcionado o un valor de variable de entorno.

OSSL_parse_url(), OSSL_HTTP_parse_url() y OCSP_parse_url() devuelven 1 en caso de éxito, 0 en caso de error.

VER TAMBIÉN

OSSL_HTTP_transfer(3)

HISTORIA

OSSL_HTTP_adapt_proxy(), OSSL_parse_url() y OSSL_HTTP_parse_url() se añadieron en OpenSSL 3.0. OCSP_parse_url() quedó obsoleto en OpenSSL 3.0.
