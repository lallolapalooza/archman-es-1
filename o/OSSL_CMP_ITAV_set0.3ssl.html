NOMBRE

OSSL_CMP_ITAV_create, OSSL_CMP_ITAV_set0, OSSL_CMP_ITAV_get0_type, OSSL_CMP_ITAV_get0_value, OSSL_CMP_ITAV_push0_stack_item, OSSL_CMP_ITAV_new0_certProfile, OSSL_CMP_ITAV_get0_certProfile - Funciones de utilidad OSSL_CMP_ITAV

SINOPSIS

#include <openssl/cmp.h>
OSSL_CMP_ITAV *OSSL_CMP_ITAV_create(ASN1_OBJECT *type, ASN1_TYPE *value);
void OSSL_CMP_ITAV_set0(OSSL_CMP_ITAV *itav, ASN1_OBJECT *type,
                        ASN1_TYPE *value);
ASN1_OBJECT *OSSL_CMP_ITAV_get0_type(const OSSL_CMP_ITAV *itav);
ASN1_TYPE *OSSL_CMP_ITAV_get0_value(const OSSL_CMP_ITAV *itav);
int OSSL_CMP_ITAV_push0_stack_item(STACK_OF(OSSL_CMP_ITAV) **itav_sk_p,
                                   OSSL_CMP_ITAV *itav);
OSSL_CMP_ITAV
*OSSL_CMP_ITAV_new0_certProfile(STACK_OF(ASN1_UTF8STRING) *certProfile);
int OSSL_CMP_ITAV_get0_certProfile(const OSSL_CMP_ITAV *itav,
                                   STACK_OF(ASN1_UTF8STRING) **out);

DESCRIPCIÓN

ITAV es la abreviatura de InfoTypeAndValue. Este tipo se define en la RFC 4210 sección 5.3.19 y el Apéndice F. Se utiliza en varios lugares de los mensajes CMP, por ejemplo, en el campo PKIHeader generalInfo, para almacenar un par clave-valor.

OSSL_CMP_ITAV_create() crea una nueva estructura OSSL_CMP_ITAV y la rellena. Combina OSSL_CMP_ITAV_new() y OSSL_CMP_ITAV_set0().

OSSL_CMP_ITAV_set0() establece el itav con un infoType de type y un infoValue de value. Esta función utiliza los punteros type y value internamente, por lo que no se deben liberar después de la llamada.

OSSL_CMP_ITAV_get0_type() devuelve un puntero directo al infoType en el itav.

OSSL_CMP_ITAV_get0_value() devuelve un puntero directo al infoValue en el itav como un puntero genérico ASN1_TYPE.

OSSL_CMP_ITAV_push0_stack_item() inserta itav en la pila apuntada por *itav_sk_p. Crea una nueva pila si *itav_sk_p apunta a NULL.

OSSL_CMP_ITAV_new0_certProfile() crea una nueva estructura OSSL_CMP_ITAV de tipo certProfile que incluye la lista opcionalmente dada de nombres de perfil. En caso de éxito, la propiedad de la lista corresponde a la nueva estructura OSSL_CMP_ITAV.

OSSL_CMP_ITAV_get0_certProfile() en caso de éxito asigna a *out un puntero interno a la lista de nombres de perfil de certificado contenida en el campo infoValue de itav. El puntero puede ser NULL si no se incluye ningún nombre de perfil. Es un error si el infoType de itav no es certProfile.

NOTAS

CMP se define en la RFC 4210 y la RFC 9480 (y CRMF en la RFC 4211).

Los OID a utilizar como tipos en OSSL_CMP_ITAV se pueden encontrar en https://datatracker.ietf.org/doc/html/rfc9480#section-4.2.2. Los NIDs de OpenSSL correspondientes, como NID_id_it_certProfile, se definen en el archivo de cabecera <openssl/obj_mac.h>.

VALORES DE RETORNO

OSSL_CMP_ITAV_create() y OSSL_CMP_ITAV_new0_certProfile() devuelven un puntero a una estructura ITAV en caso de éxito, o NULL en caso de error.

OSSL_CMP_ITAV_set0() no devuelve un valor.

OSSL_CMP_ITAV_get0_type() y OSSL_CMP_ITAV_get0_value() devuelven el puntero respectivo o NULL si su entrada es NULL.

OSSL_CMP_ITAV_push0_stack_item() y OSSL_CMP_ITAV_get0_certProfile() devuelven 1 en caso de éxito, 0 en caso de error.

EJEMPLOS

El siguiente código crea y establece una estructura que representa una secuencia genérica InfoTypeAndValue, utilizando un OID creado a partir de texto como tipo y un entero como valor. Posteriormente, se inserta en el OSSL_CMP_CTX para ser incluido más tarde en el campo genInfo del PKIHeader de las solicitudes.

ASN1_OBJECT *type = OBJ_txt2obj("1.2.3.4.5", 1);
if (type == NULL) ...
ASN1_INTEGER *asn1int = ASN1_INTEGER_new();
if (asn1int == NULL || !ASN1_INTEGER_set(asn1int, 12345)) ...
ASN1_TYPE *val = ASN1_TYPE_new();
if (val == NULL) ...
ASN1_TYPE_set(val, V_ASN1_INTEGER, asn1int);
OSSL_CMP_ITAV *itav = OSSL_CMP_ITAV_create(type, val);
if (itav == NULL) ...
if (!OSSL_CMP_CTX_push0_geninfo_ITAV(ctx, itav)) {
    OSSL_CMP_ITAV_free(itav); /* también libera type y val */
    ...
}
...
OSSL_CMP_CTX_free(ctx); /* también libera itav */

OSSL_CMP_ITAV_new0_certProfile() y OSSL_CMP_ITAV_get0_certProfile() se añadieron en OpenSSL 3.3.
