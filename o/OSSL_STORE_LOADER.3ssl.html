DESCRIPCIÓN

OSSL_STORE_LOADER es un método para los loaders de OSSL_STORE, que implementan OSSL_STORE_open(), OSSL_STORE_open_ex(), OSSL_STORE_load(), OSSL_STORE_eof(), OSSL_STORE_error() y OSSL_STORE_close() para esquemas de almacenamiento específicos.

OSSL_STORE_LOADER_fetch() busca una implementación para un esquema scheme dentro de los proveedores cargados en el OSSL_LIB_CTX dado por libctx, y con las propiedades dadas por properties.

OSSL_STORE_LOADER_up_ref() incrementa el contador de referencias para el loader.

OSSL_STORE_LOADER_free() decrementa el contador de referencias para el loader, y cuando el contador alcanza cero, lo libera. Si el argumento es NULL, nada se hace.

OSSL_STORE_LOADER_get0_provider() devuelve el proveedor del loader.

OSSL_STORE_LOADER_get0_properties() devuelve la definición de propiedades asociada al loader.

OSSL_STORE_LOADER_is_a() verifica si loader es una implementación de un algoritmo identificable con scheme.

OSSL_STORE_LOADER_get0_description() devuelve una descripción del loader, destinada a mostrar y consumo humano. La descripción está a discreción del loader de implementación.

OSSL_STORE_LOADER_do_all_provided() recorre todas las implementaciones de almacenamiento en todos los proveedores activos en el contexto de librería libctx, y para cada una de las implementaciones, llama a user_fn con el método de la implementación y user_arg como argumentos.

OSSL_STORE_LOADER_names_do_all() recorre todos los nombres para el loader, y llama a fn con cada nombre y data.

OSSL_STORE_LOADER_settable_ctx_params() devuelve un array constante de OSSL_PARAM(3) que describe los nombres y tipos de parámetros clave que pueden pasarse a OSSL_STORE_open_ex(3).

Tipos y funciones obsoletas (deprecated)

Estas funciones ayudan a aplicaciones y motor de proveedores a crear loaders para esquemas que ellos soportan. Estas son todas obsoletas y desaconsejadas en favor de implementaciones de proveedores, véase provider-storemgmt(7).

OSSL_STORE_LOADER_CTX es un tipo de plantilla, a definir por cada loader usando "struct ossl_store_loader_ctx_st { ... }".

OSSL_STORE_open_fn, OSSL_STORE_open_ex_fn, OSSL_STORE_attach_fn, OSSL_STORE_ctrl_fn, OSSL_STORE_expect_fn, OSSL_STORE_find_fn, OSSL_STORE_load_fn, OSSL_STORE_eof_fn y OSSL_STORE_close_fn son los tipos de puntero de función usados dentro de un loader de almacenamiento. Las funciones apuntadas definen la funcionalidad del loader dado.

FUNCIONES

FUNCIONES

Esta función toma un BIO y realiza el mismo trabajo que OSSL_STORE_open_ex_fn, pero utiliza libctx y propq como NULL.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y un número de comando cmd y un va_list args y se usa para manipular parámetros específicos del cargador.

Los números de comando específicos del cargador deben comenzar en OSSL_STORE_C_CUSTOM_START. Cualquier número menor es reservado para números de comando globales conocidos futuros.

Esta función espera que devuelva 1 en caso de éxito, 0 en caso de error.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y un OSSL_STORE_INFO expected y se usa para decir al cargador qué tipo de objeto se espera. expected puede ser cero para indicar que no se espera un tipo específico de objeto.

Esta función espera que devuelva 1 en caso de éxito, 0 en caso de error.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y un criterio de búsqueda OSSL_STORE_SEARCH y se usa para decir al cargador qué buscar. Cuando se llama con el contexto de carga NULL, esta función espera devolver 1 si el cargador soporta el criterio, de lo contrario 0.

Cuando se llama con el contexto de carga no siendo NULL, esta función espera devolver 1 en caso de éxito, 0 en caso de error.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y un UI_METHOD con datos asociados. Se espera cargar el siguiente dato disponible, moldarlo en un estructura que pueda ser envuelta en un OSSL_STORE_INFO usando una de las funciones OSSL_STORE_INFO(3). Si no hay más datos o ocurre un error, esta función espera devolver NULL. Las funciones OSSL_STORE_eof_fn y OSSL_STORE_error_fn deben indicar si fue realmente el fin de datos o si ocurrió un error.

Nota: Esta función solo recupera un dato individual.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y espera devolver 1 para indicar que se ha alcanzado el fin de datos disponibles. De lo contrario, espera devolver 0.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y espera devolver 1 para indicar que ocurrió un error en una llamada previa a la función OSSL_STORE_load_fn. De lo contrario, espera devolver 0.

FUNCIONES

Esta función toma un OSSL_STORE_LOADER_CTX y espera cerrar o finalizar lo que necesita cerrar, y finalmente liberar el contenido del OSSL_STORE_LOADER_CTX. Devuelve 1 en caso de éxito, 0 en caso de error.

FUNCIONES

La función OSSL_STORE_LOADER_new() crea un nuevo OSSL_STORE_LOADER. Toma un ENGINE e y una cadena scheme. scheme debe ser siempre establecido. Ambos e y scheme se usan como es y deben estar vivos durante el tiempo que el cargador sea.

La función OSSL_STORE_LOADER_get0_engine() devuelve el motor del store_loader. La función OSSL_STORE_LOADER_get0_scheme() devuelve el esquema del store_loader.

La función OSSL_STORE_LOADER_set_open() establece la función de abrider para el store_loader.

La función OSSL_STORE_LOADER_set_open_ex() establece la función de abrider con contexto de biblioteca para el store_loader.

La función OSSL_STORE_LOADER_set_attach() establece la función de atachar para el store_loader.

La función OSSL_STORE_LOADER_set_ctrl() establece la función de control para el store_loader.

La función OSSL_STORE_LOADER_set_expect() establece la función de esperar para el store_loader.

La función OSSL_STORE_LOADER_set_load() establece la función de carga para el store_loader.

La función OSSL_STORE_LOADER_set_eof() establece la función de fin de archivo para el store_loader.

La función OSSL_STORE_LOADER_set_close() establece la función de cierre para el store_loader.

La función OSSL_STORE_LOADER_free() libera el contenido del store_loader. Si el argumento es NULL, nada se hace.

La función OSSL_STORE_register_loader() registra el store_loader y lo hace disponible para uso con OSSL_STORE_open(), OSSL_STORE_open_ex(), OSSL_STORE_load(), OSSL_STORE_eof() y OSSL_STORE_close().

La función OSSL_STORE_unregister_loader() desregistra el store_loader para el esquema dado.

VALOR DE RETORNO

La función OSSL_STORE_LOADER_fetch() devuelve un puntero a un objeto OSSL_STORE_LOADER, o NULL en error.

La función OSSL_STORE_LOADER_up_ref() devuelve 1 en caso de éxito, 0 en caso de error.

La función OSSL_STORE_LOADER_names_do_all() devuelve 1 si la callback fue llamada para todos los nombres. Un valor de retorno de 0 significa que la callback no fue llamada para ningún nombre.

La función OSSL_STORE_LOADER_free() no devuelve ningún valor.

La función OSSL_STORE_LOADER_get0_provider() devuelve un puntero a un objeto de proveedor, o NULL en error.

La función OSSL_STORE_LOADER_get0_properties() devuelve un puntero a una definición de propiedades, o NULL en error.

La función OSSL_STORE_LOADER_is_a() devuelve 1 si el loader fue identificable, de lo contrario 0.

La función OSSL_STORE_LOADER_get0_description() devuelve un puntero a una descripción, o NULL si no hay una.

Las funciones con tipos OSSL_STORE_open_fn, OSSL_STORE_open_ex_fn, OSSL_STORE_ctrl_fn, OSSL_STORE_expect_fn, OSSL_STORE_load_fn, OSSL_STORE_eof_fn y OSSL_STORE_close_fn tienen los mismos valores de retorno que OSSL_STORE_open(), OSSL_STORE_open_ex(), OSSL_STORE_ctrl(), OSSL_STORE_expect(), OSSL_STORE_load(), OSSL_STORE_eof() y OSSL_STORE_close(), respectivamente.

La función OSSL_STORE_LOADER_new() devuelve un puntero a un OSSL_STORE_LOADER en caso de éxito, o NULL en caso de error.

Las funciones OSSL_STORE_LOADER_set_open(), OSSL_STORE_LOADER_set_open_ex(), OSSL_STORE_LOADER_set_ctrl(), OSSL_STORE_LOADER_set_load(), OSSL_STORE_LOADER_set_eof() y OSSL_STORE_LOADER_set_close() devuelven 1 en caso de éxito, 0 en caso de error.

La función OSSL_STORE_register_loader() devuelve 1 en caso de éxito, 0 en caso de error.

La función OSSL_STORE_unregister_loader() devuelve el cargador desregistrado en caso de éxito, o NULL en caso de error.

HISTORIA

La función OSSL_STORE_LOADER_fetch(), OSSL_STORE_LOADER_up_ref(), OSSL_STORE_LOADER_get0_provider(), OSSL_STORE_LOADER_get0_properties(), OSSL_STORE_LOADER_get0_description(), OSSL_STORE_LOADER_is_a(), OSSL_STORE_LOADER_do_all_provided() y OSSL_STORE_LOADER_names_do_all() fueron añadidas en OpenSSL 3.0.

El OSSL_STORE_LOADER y OSSL_STORE_LOADER_free() fueron añadidos en OpenSSL 1.1.1.

La función OSSL_STORE_LOADER_set_open_ex() y OSSL_STORE_open_ex_fn() fueron añadidas en OpenSSL 3.0 y se han vuelto obsoletas.

El OSSL_STORE_LOADER_CTX, OSSL_STORE_LOADER_new(), OSSL_STORE_LOADER_set0_scheme(), OSSL_STORE_LOADER_get0_scheme(), OSSL_STORE_LOADER_get0_engine(), OSSL_STORE_LOADER_set_expect(), OSSL_STORE_LOADER_set_find(), OSSL_STORE_LOADER_set_attach(), OSSL_STORE_LOADER_set_open_ex(), OSSL_STORE_LOADER_set_open(), OSSL_STORE_LOADER_set_ctrl(), OSSL_STORE_LOADER_set_load(), OSSL_STORE_LOADER_set_eof(), OSSL_STORE_LOADER_set_close(), OSSL_STORE_register_loader(), OSSL_STORE_LOADER_set_error(), OSSL_STORE_unregister_loader(), OSSL_STORE_open_fn(), OSSL_STORE_ctrl_fn(), OSSL_STORE_load_fn(), OSSL_STORE_eof_fn() y OSSL_STORE_close_fn() fueron añadidos en OpenSSL 1.1.1 y se volvieron obsoletos en OpenSSL 3.0.

La función OSSL_STORE_LOADER_settable_ctx_params() fue añadida en OpenSSL 3.6.
