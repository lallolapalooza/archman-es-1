DESCRIPCIÓN

El OSSL_DECODER_CTX contiene datos sobre múltiples decodificadores, necesarios para determinar qué tipo de entrada se necesita y para intentar decodificarlo en uno de varios resultados posibles. Esto también incluye la cadena de decodificadores, por lo que el resultado de uno puede ser la entrada para otro. Esto permite tener decodificadores genéricos como PEM a DER, así como decodificadores más especializados como DER a RSA.

Las cadenas pueden ser limitadas especificando un tipo de entrada, que se considera un punto de partida. Esto se considera por OSSL_DECODER_CTX_add_extra(), que detiene el añadir más decodificadores implementaciones cuando ya se añadieron aquellas que utilizan el tipo de entrada especificado, y funciones como OSSL_DECODER_from_bio(3), que comienza el proceso de decodificación solo con las implementaciones de decodificador que usen ese tipo de entrada. Por ejemplo, si el tipo de entrada se establece en "DER", una decodificadora PEM a DER será ignorada.

El tipo de entrada también puede ser NULL, lo que significa que el llamante no sabe qué tipo de entrada tiene. En este caso, OSSL_DECODER_from_bio() simplemente intenta con una implementación de decodificador después de otra, y así descubrirá qué tipo de entrada dio el llamante.

Para cada decodificación realizada, incluso una intermedia, se llama al constructor proporcionado por el llamante para intentar construir un tipo / estructura que el llamante conoce cómo manejar a partir del resultado actual de decodificación. El constructor se establece con OSSL_DECODER_CTX_set_construct().

OSSL_DECODER_INSTANCE es un estructura opaca que contiene datos sobre el decodificador que fue utilizado recientemente, y que puede ser útil para el constructor. Hay algunas funciones para extraer datos de este tipo, descritas más abajo.

Funciones

OSSL_DECODER_CTX_new() crea un nuevo contexto OSSL_DECODER_CTX vacío.

OSSL_DECODER_settable_ctx_params() devuelve un array de descripciones de parámetros OSSL_PARAM(3).

OSSL_DECODER_CTX_set_params() intenta establecer los parámetros especificados con un array OSSL_PARAM(3) params. Estos parámetros se pasan a todos los decodificadores que se han añadido al ctx hasta ahora. Los parámetros que un implementación no reconoce deben ser ignorados por ella.

OSSL_DECODER_CTX_free() libera el contexto ctx dado. Si el argumento es NULL, nada se hace.

OSSL_DECODER_CTX_add_decoder() popula el OSSL_DECODER_CTX ctx con un decodificador, para usarlo para intentar decodificar algún tipo de entrada.

OSSL_DECODER_CTX_add_extra() encuentra decodificadores que generan entrada para decodificadores ya añadidos y los añade también. Esto se usa para construir cadenas de decodificadores.

OSSL_DECODER_CTX_set_input_type() establece el tipo de entrada inicial. Esto limita las cadenas de decodificadores a considerarse, como se explica en la descripción general.

OSSL_DECODER_CTX_set_input_structure() establece el nombre de la estructura que se espera que tenga la entrada. Esto puede usarse para determinar qué implementaciones de decodificador pueden usarse. NULL es un valor válido de estructura de entrada, cuando no es relevante, o cuando las implementaciones de decodificador esperan que figure lo así.

OSSL_DECODER_CTX_get_num_decoders() obtiene el número de decodificadores actualmente añadidos al contexto ctx.

OSSL_DECODER_CTX_set_construct() establece el constructor construct.

OSSL_DECODER_CTX_set_construct_data() establece el dato del constructor que se pasa a cada llamada al constructor.

OSSL_DECODER_CTX_set_cleanup() establece el función de cleanup cleanup. Esta función se llama por OSSL_DECODER_CTX_free(3).

OSSL_DECODER_CTX_get_construct(), OSSL_DECODER_CTX_get_construct_data() y OSSL_DECODER_CTX_get_cleanup() devuelven los valores que se han establecido por OSSL_DECODER_CTX_set_construct(), OSSL_DECODER_CTX_set_construct_data() y OSSL_DECODER_CTX_set_cleanup() respectivamente.

OSSL_DECODER_export() es una función de fallback para constructores que no pueden usar directamente los datos que reciben para múltiples razones. Pasa el mismo decodificador de instancia decoder_inst que el constructor obtuvo y un objeto reference, descompone el objeto que se refiere, y exporta el mismo mediante la creación de un array OSSL_PARAM(3) que luego pasa a export_cb, junto con export_arg.

Constructor

Un OSSL_DECODER_CONSTRUCT recibe los siguientes argumentos:

decoder_inst
El OSSL_DECODER_INSTANCE para el decodificador desde el cual el constructor obtiene sus datos.
object
Una abstracción nativa de objeto producida por el decodificador. Más información sobre la abstracción de objetos nativos del proveedor puede encontrarse en provider-object(7).
construct_data
El puntero que se estableció con OSSL_DECODE_CTX_set_construct_data().

El constructor espera devolver 1 cuando el dato que recibe puede construirse, de lo contrario

DESCRIPTION

The OpenSSL decoder API provides a mechanism to convert data from one format to another. This includes converting data from different serialization formats (like PEM, DER, PKCS#12) into OpenSSL internal objects (like EVP_PKEY(3), X509(3), etc).

The main component of this API is the OSSL_DECODER_CTX structure which holds the state and configuration for a decoding operation.

OSSL_DECODER_CTX_new() creates and initialises a new decoder context.

OSSL_DECODER_CTX_free() frees the decoder context ctx.

The following functions are used to set and get constructor callbacks:

OSSL_DECODER_CTX_set_construct() sets the constructor function construct to be used when an object needs to be created from the decoded data. The function signature is defined in <openssl/core.h> as:

typedef void *(*OSSL_FUNC_construct_fn)(OSSL_PROVIDER *provider, void *data);

OSSL_DECODER_CTX_get_construct() returns the currently set constructor function.

OSSL_DECODER_CTX_set_construct_data() sets the opaque pointer data to be passed to the constructor function when it is called. This is useful for passing context specific information to the constructor.

OSSL_DECODER_CTX_get_construct_data() returns the currently set constructor data pointer.

OSSL_DECODER_CTX_set_cleanup() sets the cleanup function cleanup to be used to free the constructed object. The function signature is defined in <openssl/core.h> as:

typedef void (*OSSL_FUNC_cleanup_fn)(void *ptr);

OSSL_DECODER_CTX_get_cleanup() returns the currently set cleanup function.

OSSL_DECODER_CTX_add_decoder() adds an existing decoder implementation decoder to the context ctx. The caller must ensure that the decoder implementation remains valid for the lifetime of the context.

OSSL_DECODER_CTX_add_extra() is used to add a decoder implementation from a provider. It looks for a decoder in the given provider that supports the specified algorithm name. If found, it is added to the context ctx.

OSSL_DECODER_CTX_decode() performs the decoding operation. It takes the input data via the context ctx (for example, using OSSL_DECODER_from_bio(3)), and if successful, it calls the constructor function to create the output object. The pointer to the created object is stored in out. params can be used to pass parameters to the decoding process.

OSSL_DECODER_CTX_decode_cleanup() cleans up the decoded object decoded using the registered cleanup function.

OSSL_DECODER_CTX_get_num_decoders() returns the number of decoders currently configured in the context ctx.

OSSL_DECODER_CTX_get_num_delegates() returns the number of decoder delegates currently configured in the context ctx. A delegate is a decoder that is explicitly requested by another decoder.

OSSL_DECODER_settable_ctx_params() returns an array of OSSL_PARAM(3) describing the parameters that can be set on the decoder context itself.

OSSL_DECODER_CTX_set_params() sets parameters on the decoder context ctx using the provided array of OSSL_PARAM(3).

OSSL_DECODER_CTX_get_params() retrieves parameters from the decoder context ctx. The params array indicates which parameters are requested and is updated with the retrieved values.

OSSL_DECODER_export() is a special function intended for use within the provider framework. It facilitates the export of a decoder instance. It can be used by a provider to present a decoder implementation to the core OpenSSL library. cin and cout are the core I/O functions. inst will be populated with the exported decoder instance if successful.

The following utility functions may be used by a constructor:

OSSL_DECODER_INSTANCE_decoder() can be used to get the decoder implementation from a decoder instance decoder_inst.

OSSL_DECODER_INSTANCE_decoder_ctx() can be used to get the decoder implementation's provider context from a decoder instance decoder_inst.

OSSL_DECODER_INSTANCE_get_input_type() can be used to get the decoder implementation's input type from a decoder instance decoder_inst. The actual type name is allocated and returned in type_name, which must be freed by the caller.

OSSL_DECODER_INSTANCE_get_input_structure() can be used to get the input structure for the decoder implementation from a decoder instance decoder_inst. The actual structure name is allocated and returned in structure_name, which must be freed by the caller. This may be NULL.

RETURN VALUES

OSSL_DECODER_CTX_new() returns a pointer to a OSSL_DECODER_CTX, or NULL if the context structure couldn't be allocated.

OSSL_DECODER_settable_ctx_params() returns an OSSL_PARAM(3) array, or NULL if none is available.

OSSL_DECODER_CTX_set_params() returns 1 if all recognised parameters were valid, or 0 if one of them was invalid or caused some other failure in the implementation.

OSSL_DECODER_CTX_add_decoder(), OSSL_DECODER_CTX_add_extra(), OSSL_DECODER_CTX_set_construct(), OSSL_DECODER_CTX_set_construct_data() and OSSL_DECODER_CTX_set_cleanup() return 1 on success, or 0 on failure.

OSSL_DECODER_CTX_get_construct(), OSSL_DECODER_CTX_get_construct_data() and OSSL_DECODER_CTX_get_cleanup() return the current pointers to the constructor, the constructor data and the cleanup functions, respectively.

OSSL_DECODER_CTX_get_num_decoders() and OSSL_DECODER_CTX_get_num_delegates() return the current number of decoders/delegates. They return 0 if ctx is NULL.

OSSL_DECODER_export() returns 1 on success, or 0 on failure.

OSSL_DECODER_INSTANCE_decoder() returns an OSSL_DECODER pointer on success, or NULL on failure.

OSSL_DECODER_INSTANCE_decoder_ctx() returns a provider context pointer on success, or NULL on failure.

OSSL_DECODER_INSTANCE_get_input_type() returns 1 on success or 0 on failure. If successful, type_name contains the allocated type name.

OSSL_DECODER_INSTANCE_get_input_structure() returns 1 on success or 0 on failure. If successful, structure_name contains the allocated structure name.
