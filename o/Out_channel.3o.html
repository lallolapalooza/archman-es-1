Canales de salida.

Este módulo proporciona funciones para trabajar con canales de salida.

Ver Out_channel.examples abajo.

Desde 4.14

Canales

type t = out_channel

El tipo de canal de salida.

type open_flag = open_flag =
| Open_rdonly (* abierto para lectura.
*)
| Open_wronly (* abierto para escritura.
*)
| Open_append (* abierto para añadir: siempre escribir al final del archivo.
*)
| Open_creat (* crear el archivo si no existe.
*)
| Open_trunc (* vaciar el archivo si ya existe.
*)
| Open_excl (* fallar si Open_creat y el archivo ya existe.
*)
| Open_binary (* abierto en modo binario (sin conversión).
*)
| Open_text (* abierto en modo texto (puede realizar conversiones).
*)
| Open_nonblock (* abierto en modo no bloqueante.
*)

Modos de apertura para Out_channel.open_gen.

val stdout : t

La salida estándar del proceso.

val stderr : t

La salida de error estándar del proceso.

val open_bin : string -> t

Abre el archivo con el nombre dado para escritura y devuelve un nuevo canal de salida en ese archivo, posicionado al principio del archivo. El archivo se trunca a longitud cero si ya existe. Se crea si no existe previamente.

val open_text : string -> t

Igual que Out_channel.open_bin, pero el archivo se abre en modo texto, de modo que las traducciones de nueva línea ocurren durante las escrituras. En sistemas operativos que no distinguen entre modo texto y modo binario, esta función se comporta como Out_channel.open_bin.

val open_gen : open_flag list -> int -> string -> t

open_gen modo perm nombre_archivo abre el archivo con el nombre dado para escritura, como se describe arriba. El argumento adicional modo especifica el modo de apertura. El argumento adicional perm especifica los permisos del archivo, en caso de que el archivo deba ser creado. Out_channel.open_text y Out_channel.open_bin son casos especiales de esta función.

val with_open_bin : string -> (t -> 'a) -> 'a

with_open_bin fn f abre un canal oc en el archivo fn y devuelve f
oc. Después de que f retorna, ya sea con un valor o lanzando una excepción, se garantiza que oc se cerrará.

val with_open_text : string -> (t -> 'a) -> 'a

Similar a Out_channel.with_open_bin, pero el canal se abre en modo texto (ver Out_channel.open_text).

val with_open_gen : open_flag list -> int -> string -> (t -> 'a) -> 'a

Similar a Out_channel.with_open_bin, pero puede especificar el modo de apertura y los permisos del archivo, en caso de que el archivo deba ser creado (ver Out_channel.open_gen).

val close : t -> unit

Cierra el canal dado, vaciando todas las operaciones de escritura en búfer. Las funciones de salida lanzan una excepción Sys_error cuando se aplican a un canal de salida cerrado, excepto Out_channel.close y Out_channel.flush, que no hacen nada cuando se aplican a un canal ya cerrado. Tenga en cuenta que Out_channel.close puede lanzar Sys_error si el sistema operativo señala un error al vaciar o cerrar.

val close_noerr : t -> unit

Igual que Out_channel.close, pero ignora todos los errores.

Salida

val output_char : t -> char -> unit

Escribe el carácter en el canal de salida dado.

val output_byte : t -> int -> unit

Escribe un entero de 8 bits (como el único carácter con ese código) en el canal de salida dado. El entero dado se toma módulo 256.

val output_string : t -> string -> unit

Escribe la cadena en el canal de salida dado.

val output_bytes : t -> bytes -> unit

Escribe la secuencia de bytes en el canal de salida dado.

Salida avanzada

val output : t -> bytes -> int -> int -> unit

output oc buf pos len escribe len caracteres de la secuencia de bytes buf, comenzando en el desplazamiento pos, en el canal de salida dado oc.

Lanza Invalid_argument si pos y len no designan un rango válido de buf.

val output_substring : t -> string -> int -> int -> unit

Igual que Out_channel.output pero toma una cadena como argumento en lugar de una secuencia de bytes.

val output_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> unit

Igual que Out_channel.output pero toma los datos de un bigarray.

Desde 5.2

Vaciado

val flush : t -> unit

Vacía el búfer asociado al canal de salida dado, realizando todas las escrituras pendientes en ese canal. Los programas interactivos deben tener cuidado al vaciar la salida estándar y el error estándar en el momento adecuado.

val flush_all : unit -> unit

Vacía todos los canales de salida abiertos; ignora los errores.

Búsqueda

val seek : t -> int64 -> unit

seek chan pos establece la posición de escritura actual a pos para el canal chan. Esto solo funciona para archivos regulares. En archivos de otros tipos (como terminales, tuberías y sockets), el comportamiento no está especificado.

val pos : t -> int64

Devuelve la posición de escritura actual para el canal dado. No funciona en canales abiertos con la bandera Open_append (devuelve resultados no especificados).

Para archivos abiertos en modo texto en Windows, la posición devuelta es aproximada (debido a la conversión de fin de línea); en particular, guardar la posición actual con Out_channel.pos y luego volver a esta posición usando Out_channel.seek no funcionará. Para que este idioma de programación funcione de manera fiable y portable, el archivo debe abrirse en modo binario.

Atributos

val length : t -> int64

Devuelve el tamaño (número de caracteres) del archivo regular en el que está abierto el canal dado. Si el canal está abierto en un archivo que no es un archivo regular, el resultado no tiene sentido.

val set_binary_mode : t -> bool -> unit

set_binary_mode oc true establece el canal oc en modo binario: no se realizan traducciones durante la salida.

set_binary_mode oc false establece el canal oc en modo texto: dependiendo del sistema operativo, pueden realizarse algunas traducciones durante la salida. Por ejemplo, en Windows, los finales de línea se traducirán de \n a \r\n.

Esta función no tiene efecto en sistemas operativos que no distinguen entre modo texto y modo binario.

val is_binary_mode : t -> bool

is_binary_mode oc devuelve si el canal oc está en modo binario (ver Out_channel.set_binary_mode).

NAME

Out_channel - Output channels.

Module

Module Out_channel

Documentation

An output channel is a destination for output operations. Channels can be either buffered or unbuffered. In buffered mode, data written to the channel is collected in a buffer and written to the underlying system device only when the buffer is full or explicitly flushed. In unbuffered mode, data is sent to the output device immediately.

All channels are open in buffered mode by default.

val set_buffered : t -> bool -> unit

Set the buffering mode for the output channel oc. If the second argument is true, the channel is set to buffered mode. If it is false, the channel is set to unbuffered mode. In this mode, data output on oc will be sent to the output device immediately.

All channels are open in buffered mode by default.

val is_buffered : t -> bool

is_buffered oc returns whether the channel oc is buffered (see Out_channel.set_buffered ).

val isatty : t -> bool

isatty oc is true if oc refers to a terminal or console window, false otherwise.

Since 5.1

Examples

Writing the contents of a file:

      let write_file file s =
        Out_channel.with_open_bin file
          (fun oc -> Out_channel.output_string oc s))
