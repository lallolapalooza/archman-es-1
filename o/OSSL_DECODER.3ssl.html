DESCRIPCIÓN

OSSL_DECODER es un método para decodificadores, que saben cómo decodificar datos codificados en un objeto de algún tipo que el resto de OpenSSL sabe cómo manejar.

OSSL_DECODER_fetch() busca un algoritmo dentro del proveedor que ha sido cargado en el OSSL_LIB_CTX dado por ctx, con el nombre dado por name y las propiedades dadas por properties. El name determina qué tipo de objeto se espera que el método decodificador recuperado sea capaz de decodificar, y las propiedades se utilizan para determinar el tipo de salida esperado. Para propiedades conocidas y los valores que pueden tener, por favor, consulte "Nombres y propiedades" en provider-encoder(7).

OSSL_DECODER_up_ref() incrementa el contador de referencias para el decoder dado.

OSSL_DECODER_free() decrementa el contador de referencias para el decoder dado, y cuando el contador llega a cero, lo libera. Si el argumento es NULL, no se hace nada.

OSSL_DECODER_get0_provider() devuelve el proveedor del decoder dado.

OSSL_DECODER_get0_properties() devuelve la definición de propiedades asociada con el decoder dado.

OSSL_DECODER_is_a() comprueba si decoder es una implementación de un algoritmo que es identificable con name.

OSSL_DECODER_get0_name() devuelve el nombre utilizado para recuperar el decoder dado.

OSSL_DECODER_get0_description() devuelve una descripción del decoder, destinada a visualización y consumo humano. La descripción queda a discreción de la implementación del decoder.

OSSL_DECODER_names_do_all() recorre todos los nombres para el decoder dado, y llama a fn con cada nombre y data como argumentos.

OSSL_DECODER_do_all_provided() recorre todas las implementaciones de decodificadores de todos los proveedores activados en el contexto de biblioteca libctx, y para cada una de las implementaciones, llama a fn con el método de implementación y arg como argumentos.

OSSL_DECODER_gettable_params() devuelve una matriz OSSL_PARAM(3) de descriptores de parámetros.

OSSL_DECODER_get_params() intenta obtener los parámetros especificados con una matriz OSSL_PARAM(3) params. Los parámetros que la implementación no reconoce deben ser ignorados.

VALORES DE RETORNO

OSSL_DECODER_fetch() devuelve un puntero a un objeto OSSL_DECODER, o NULL en caso de error.

OSSL_DECODER_up_ref() devuelve 1 en caso de éxito, o 0 en caso de error.

OSSL_DECODER_free() no devuelve ningún valor.

OSSL_DECODER_get0_provider() devuelve un puntero a un objeto proveedor, o NULL en caso de error.

OSSL_DECODER_get0_properties() devuelve un puntero a una cadena de definición de propiedades, o NULL en caso de error.

OSSL_DECODER_is_a() devuelve 1 si decoder era identificable, de lo contrario 0.

OSSL_DECODER_get0_name() devuelve el nombre del algoritmo de la implementación proporcionada para el decoder dado. Tenga en cuenta que el decoder puede tener varios sinónimos asociados. En este caso, se devuelve el primer nombre de la definición del algoritmo. La propiedad de la cadena devuelta la retiene el objeto decoder y no debe ser liberada por el llamador.

OSSL_DECODER_get0_description() devuelve un puntero a una descripción, o NULL si no existe ninguna.

OSSL_DECODER_names_do_all() devuelve 1 si la función de llamada fue invocada para todos los nombres. Un valor de retorno de 0 significa que la función de llamada no fue invocada para ningún nombre.

NOTAS

OSSL_DECODER_fetch() puede ser llamado implícitamente por otras funciones de recuperación, utilizando el mismo contexto de biblioteca y propiedades. Cualquier otra API que utilice claves hará esto típicamente.

EJEMPLOS

Para listar todos los decodificadores en un proveedor a un bio_out:

static void collect_decoders(OSSL_DECODER *decoder, void *stack)
{
    STACK_OF(OSSL_DECODER) *decoder_stack = stack;
    sk_OSSL_DECODER_push(decoder_stack, decoder);
    OSSL_DECODER_up_ref(decoder);
}
void print_name(const char *name, void *vdata)
{
    BIO *bio = vdata;
    BIO_printf(bio, "%s ", name);
}
STACK_OF(OSSL_DECODER) *decoders;
int i;
decoders = sk_OSSL_DECODER_new_null();
BIO_printf(bio_out, "Decodificadores proporcionados por %s:\n", provider);
OSSL_DECODER_do_all_provided(NULL, collect_decoders,
                             decoders);
for (i = 0; i < sk_OSSL_DECODER_num(decoders); i++) {
    OSSL_DECODER *decoder = sk_OSSL_DECODER_value(decoders, i);
    if (strcmp(OSSL_PROVIDER_get0_name(OSSL_DECODER_get0_provider(decoder)),
               provider) != 0)
        continue;
    if (OSSL_DECODER_names_do_all(decoder, print_name, bio_out))
           BIO_printf(bio_out, "\n");
}
sk_OSSL_DECODER_pop_free(decoders, OSSL_DECODER_free);
