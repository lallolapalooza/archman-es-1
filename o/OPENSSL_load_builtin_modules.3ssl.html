OPENSSL_load_builtin_modules(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL_LOAD_BUILTIN_MODULES(3ssl) OpenSSL OPENSSL_LOAD_BUILTIN_MODULES(3ssl)

NOMBRE

OPENSSL_load_builtin_modules, ASN1_add_oid_module, ENGINE_add_conf_module - añadir módulos de configuración estándar

SINOPSIS

#include <openssl/conf.h>
void OPENSSL_load_builtin_modules(void);
void ASN1_add_oid_module(void);
void ENGINE_add_conf_module(void);

DESCRIPCIÓN

La función OPENSSL_load_builtin_modules() añade todos los módulos de configuración estándar de OpenSSL a la lista interna. Pueden ser utilizados por el código de configuración de OpenSSL.

ASN1_add_oid_module() añade solo el módulo ASN1 OBJECT.

ENGINE_add_conf_module() añade solo el módulo de configuración ENGINE.

NOTAS

Si se llama a la función de configuración simple OPENSSL_config(), entonces OPENSSL_load_builtin_modules() se llama automáticamente.

Las aplicaciones que usan las funciones de configuración directamente necesitarán llamar a OPENSSL_load_builtin_modules() ellas mismas *antes* de cualquier otro código de configuración.

Las aplicaciones deberían llamar a OPENSSL_load_builtin_modules() para cargar todos los módulos de configuración en lugar de añadir módulos de forma selectiva: de lo contrario, la funcionalidad podría faltar en la aplicación si se añaden nuevos módulos en el futuro.

VALORES DE RETORNO

Ninguna de las funciones devuelve un valor.

VER TAMBIÉN

config(5), OPENSSL_config(3)

HISTORIA

ENGINE_add_conf_module() fue obsoleto en OpenSSL 3.0.
