OSSL_PARAM_BLD(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_PARAM_BLD(3ssl) OpenSSL OSSL_PARAM_BLD(3ssl)

NOMBRE

OSSL_PARAM_BLD, OSSL_PARAM_BLD_new, OSSL_PARAM_BLD_to_param, OSSL_PARAM_BLD_free, OSSL_PARAM_BLD_push_int, OSSL_PARAM_BLD_push_uint, OSSL_PARAM_BLD_push_long, OSSL_PARAM_BLD_push_ulong, OSSL_PARAM_BLD_push_int32, OSSL_PARAM_BLD_push_uint32, OSSL_PARAM_BLD_push_int64, OSSL_PARAM_BLD_push_uint64, OSSL_PARAM_BLD_push_size_t, OSSL_PARAM_BLD_push_time_t, OSSL_PARAM_BLD_push_double, OSSL_PARAM_BLD_push_BN, OSSL_PARAM_BLD_push_BN_pad, OSSL_PARAM_BLD_push_utf8_string, OSSL_PARAM_BLD_push_utf8_ptr, OSSL_PARAM_BLD_push_octet_string, OSSL_PARAM_BLD_push_octet_ptr - funciones para ayudar en la creación de arrays OSSL_PARAM

SINOPSIS

#include <openssl/param_build.h>
typedef struct OSSL_PARAM_BLD;
OSSL_PARAM_BLD *OSSL_PARAM_BLD_new(void);
OSSL_PARAM *OSSL_PARAM_BLD_to_param(OSSL_PARAM_BLD *bld);
void OSSL_PARAM_BLD_free(OSSL_PARAM_BLD *bld);
int OSSL_PARAM_BLD_push_TYPE(OSSL_PARAM_BLD *bld, const char *key, TYPE val);
int OSSL_PARAM_BLD_push_BN(OSSL_PARAM_BLD *bld, const char *key,
                           const BIGNUM *bn);
int OSSL_PARAM_BLD_push_BN_pad(OSSL_PARAM_BLD *bld, const char *key,
                               const BIGNUM *bn, size_t sz);
int OSSL_PARAM_BLD_push_utf8_string(OSSL_PARAM_BLD *bld, const char *key,
                                    const char *buf, size_t bsize);
int OSSL_PARAM_BLD_push_utf8_ptr(OSSL_PARAM_BLD *bld, const char *key,
                                 char *buf, size_t bsize);
int OSSL_PARAM_BLD_push_octet_string(OSSL_PARAM_BLD *bld, const char *key,
                                     const void *buf, size_t bsize);
int OSSL_PARAM_BLD_push_octet_ptr(OSSL_PARAM_BLD *bld, const char *key,
                                  void *buf, size_t bsize);

DESCRIPCIÓN

Una colección de funciones de utilidad que simplifican la creación de arrays OSSL_PARAM. Los nombres de TYPE se corresponden con los de OSSL_PARAM_int(3).

OSSL_PARAM_BLD_new() asigna e inicializa una nueva estructura OSSL_PARAM_BLD para que se puedan añadir valores. Se limpian los valores existentes.

OSSL_PARAM_BLD_free() desasigna la memoria asignada por OSSL_PARAM_BLD_new(). Si el argumento es NULL, no se hace nada.

OSSL_PARAM_BLD_to_param() convierte una estructura OSSL_PARAM_BLD construida bld en un array OSSL_PARAM asignado. El array OSSL_PARAM y todo el almacenamiento asociado deben liberarse llamando a OSSL_PARAM_free() con el valor de retorno de la función. OSSL_PARAM_BLD_free() se puede llamar de forma segura en cualquier momento después de esta función.

OSSL_PARAM_BLD_push_TYPE() es una serie de funciones que crearán objetos OSSL_PARAM del tamaño especificado y del tipo correcto para el argumento val. val se almacena por valor y se puede usar una expresión o una variable automática.

Cuando TYPE denota un tipo entero, los tipos enteros con signo normalmente recibirán los parámetros de tipo OSSL_PARAM OSSL_PARAM_INTEGER. Cuando TYPE denota un tipo entero sin signo, recibirá el tipo OSSL_PARAM OSSL_PARAM_UNSIGNED_INTEGER.

OSSL_PARAM_BLD_push_BN() es una función que creará un objeto OSSL_PARAM que contiene el BIGNUM bn especificado. Cuando el bn es cero o positivo, su tipo OSSL_PARAM se convierte en OSSL_PARAM_UNSIGNED_INTEGER. Cuando el bn es negativo, su tipo OSSL_PARAM se convierte en OSSL_PARAM_INTEGER. Si bn está marcado como asignado de forma segura, su representación OSSL_PARAM también estará asignada de forma segura. El argumento bn se almacena por referencia y el objeto BIGNUM subyacente debe existir hasta después de que se haya llamado a OSSL_PARAM_BLD_to_param().

OSSL_PARAM_BLD_push_BN_pad() es una función que creará un objeto OSSL_PARAM que contiene el BIGNUM bn especificado. El objeto se rellenará para ocupar exactamente sz bytes; si se especifica espacio insuficiente, se producirá un error. Cuando el bn es cero o positivo, su tipo OSSL_PARAM se convierte en OSSL_PARAM_UNSIGNED_INTEGER. Cuando el bn es negativo, su tipo OSSL_PARAM se convierte en OSSL_PARAM_INTEGER. Si bn está marcado como asignado de forma segura, su representación OSSL_PARAM también estará asignada de forma segura. El argumento bn se almacena por referencia y el objeto BIGNUM subyacente debe existir hasta después de que se haya llamado a OSSL_PARAM_BLD_to_param().

OSSL_PARAM_BLD_push_utf8_string() es una función que creará un objeto OSSL_PARAM que referencia la cadena UTF8 especificada por buf. La longitud de la cadena bsize no debe incluir el byte NUL de terminación. Si es cero, se calculará. La cadena a la que apunta buf se almacena por referencia y debe permanecer en el ámbito hasta después de que se haya llamado a OSSL_PARAM_BLD_to_param().

OSSL_PARAM_BLD_push_octet_string() es una función que creará un objeto OSSL_PARAM que referencia la cadena de octetos especificada por buf y <bsize>. La memoria a la que apunta buf se almacena por referencia y debe permanecer en el ámbito hasta después de que se haya llamado a OSSL_PARAM_BLD_to_param().

OSSL_PARAM_BLD_push_utf8_ptr() es una función que creará un objeto OSSL_PARAM que referencia la cadena UTF8 especificada por buf. La longitud de la cadena bsize no debe incluir el byte NUL de terminación. Si es cero, se calculará. La cadena a la que apunta buf se almacena por referencia y debe permanecer en el ámbito hasta que se libere el array OSSL_PARAM.

OSSL_PARAM_BLD_push_octet_ptr() es una función que creará un objeto OSSL_PARAM que referencia la cadena de octetos especificada por buf. La memoria a la que apunta buf se almacena por referencia y debe permanecer en el ámbito hasta que se libere el array OSSL_PARAM.

VALORES DE RETORNO

OSSL_PARAM_BLD_new() devuelve la estructura OSSL_PARAM_BLD asignada, o NULL en caso de error.

OSSL_PARAM_BLD_to_param() devuelve el array OSSL_PARAM asignado, o NULL en caso de error.

Todas las funciones OSSL_PARAM_BLD_push_TYPE devuelven 1 en caso de éxito y 0 en caso de error.

NOTAS

OSSL_PARAM_BLD_push_BN() y OSSL_PARAM_BLD_push_BN_pad() solo admiten BIGNUMs no negativos. Devuelven un error en BIGNUMs negativos. Para pasar BIGNUMs con signo, use OSSL_PARAM_BLD_push_signed_BN().

EJEMPLOS

Ambos ejemplos crean un array OSSL_PARAM que contiene una clave RSA. Para ambos, las variables de clave predefinidas son:

BIGNUM *n;           /* módulo */
unsigned int e;      /* exponente público */
BIGNUM *d;           /* exponente privado */
BIGNUM *p, *q;       /* primeros dos factores primos */
BIGNUM *dmp1, *dmq1; /* primeros dos exponentes CRT */
BIGNUM *iqmp;        /* primer coeficiente CRT */

Ejemplo 1

Este ejemplo muestra cómo crear un array OSSL_PARAM que contiene una clave privada RSA.

OSSL_PARAM_BLD *bld = OSSL_PARAM_BLD_new();
OSSL_PARAM *params = NULL;
if (bld == NULL
    || !OSSL_PARAM_BLD_push_BN(bld, "n", n)
    || !OSSL_PARAM_BLD_push_uint(bld, "e", e)
    || !OSSL_PARAM_BLD_push_BN(bld, "d", d)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-factor1", p)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-factor2", q)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-exponent1", dmp1)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-exponent2", dmq1)
    || !OSSL_PARAM_BLD_push_BN(bld, "rsa-coefficient1", iqmp)
    || (params = OSSL_PARAM_BLD_to_param(bld)) == NULL)
    goto err;
OSSL_PARAM_BLD_free(bld);
/* Usar params */
...
OSSL_PARAM_free(params);

Ejemplo 2

Este ejemplo muestra cómo crear un array OSSL_PARAM que contiene una clave pública RSA.

OSSL_PARAM_BLD *bld = OSSL_PARAM_BLD_new();
OSSL_PARAM *params = NULL;
if (nld == NULL
    || !OSSL_PARAM_BLD_push_BN(bld, "n", n)
    || !OSSL_PARAM_BLD_push_uint(bld, "e", e)
    || (params = OSSL_PARAM_BLD_to_param(bld)) == NULL)
    goto err;
OSSL_PARAM_BLD_free(bld);
/* Usar params */
...
OSSL_PARAM_free(params);
