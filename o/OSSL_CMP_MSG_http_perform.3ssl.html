OSSL_CMP_MSG_http_perform(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_CMP_MSG_HTTP_PERFORM(3ssl) OpenSSL OSSL_CMP_MSG_HTTP_PERFORM(3ssl)

NOMBRE

OSSL_CMP_MSG_http_perform - transferencia HTTP(S) del lado del cliente de un par de solicitud-respuesta CMP

SINOPSIS

#include <openssl/cmp.h>
OSSL_CMP_MSG *OSSL_CMP_MSG_http_perform(OSSL_CMP_CTX *ctx,
                                        const OSSL_CMP_MSG *req);

DESCRIPCIÓN

OSSL_CMP_MSG_http_perform() envía el mensaje PKIMessage dado req al servidor CMP especificado en ctx y devuelve el resultado obtenido del mismo.

Si se ha utilizado OSSL_CMP_CTX_set_transfer_cb_arg(3) para establecer el argumento de la función de devolución de llamada de transferencia, entonces el puntero proporcionado bios se toma como una matriz de dos BIO para usar en el intercambio con el servidor como se describe para los parámetros bio y rbio de OSSL_HTTP_open(3). Por ejemplo, los dos punteros BIO pueden ser iguales y referirse a una conexión TLS, como en BRSKI-AE, donde se reutiliza un canal TLS preestablecido para CMP.

De lo contrario, se contacta con el servidor especificado a través de OSSL_CMP_CTX_set1_server(3) y opcionalmente OSSL_CMP_CTX_set_serverPort(3), donde el puerto predeterminado es 80 para HTTP y 443 para HTTPS. La ruta HTTP (también conocida como "alias CMP" en este contexto) a utilizar es por defecto "/", de lo contrario la cadena especificada a través de OSSL_CMP_CTX_set1_serverPath(3). En caso de éxito, la función devuelve el mensaje PKIMessage de respuesta del servidor.

La función utiliza cualquier función de devolución de llamada HTTP establecida a través de OSSL_CMP_CTX_set_http_cb(3). Respeta cualquier valor de tiempo de espera establecido a través de OSSL_CMP_CTX_set_option(3) con un argumento OSSL_CMP_OPT_MSG_TIMEOUT. También respeta cualquier opción de proxy HTTP(S) establecida a través de OSSL_CMP_CTX_set1_proxy(3) y OSSL_CMP_CTX_set1_no_proxy(3) y las variables de entorno correspondientes. El proxy HTTP plano es compatible directamente, mientras que el uso de un proxy para conexiones HTTPS requiere una función de devolución de llamada adecuada, como OSSL_HTTP_proxy_connect(3).

NOTAS

CMP se define en RFC 4210. La transferencia HTTP para CMP se define en RFC 6712.

VALORES DE RETORNO

OSSL_CMP_MSG_http_perform() devuelve el mensaje de respuesta CMP recibido en caso de éxito, de lo contrario NULL.

VER TAMBIÉN

OSSL_CMP_CTX_new(3), OSSL_HTTP_open(3), y OSSL_HTTP_proxy_connect(3).

HISTORIA

El soporte CMP de OpenSSL se añadió en OpenSSL 3.0.

El uso de transfer_cb_arg en OSSL_CMP_MSG_http_perform() se añadió en OpenSSL 3.5.
