Documentación de Enumeración de Miembros

enum OpenDBX::Stmt::Type

Objetos de sentencia que se pueden crear. Actualmente, solo se admite el procesamiento simple de sentencias, lo que significa que la sentencia enviada al servidor de base de datos consta de la sentencia y los parámetros en formato de texto. Más adelante, también estarán disponibles las sentencias preparadas, que separan el análisis y la ejecución con diferentes parámetros.

Constructor por defecto. El constructor por defecto no forma parte de la interfaz pública, ya que el objeto no debe crearse manualmente. En su lugar, el método Conn::create() es una fábrica de instancias de la clase Stmt.

OpenDBX::Stmt::Stmt (Stmt_Iface * impl) [protected]

Crea una instancia de sentencia. El constructor no forma parte de la interfaz pública, ya que el objeto no debe crearse manualmente. En su lugar, el método Conn::create() es una fábrica de instancias de la clase Stmt.

Parámetros

impl Puntero a la implementación privada

Excepciones

std::exception Si ocurre un error

Devuelve

Instancia de sentencia

OpenDBX::Stmt::~Stmt ()

Destruye la instancia de sentencia si no existen otras referencias. Cada objeto de sentencia utiliza un contador de referencias para recordar si las variables internas se comparten con otros objetos. Si este no es el caso o si este objeto es el último que hace referencia a las variables, el objeto se limpia y la memoria asignada se libera.

OpenDBX::Stmt::Stmt (const Stmt & ref)

Constructor de copia. Permite la transferencia del estado interno de un objeto ref del mismo tipo a este objeto. Ambos objetos comparten las mismas variables y el contador de referencias después. El contador de referencias se incrementa cada vez que se copia un objeto y se decrementará si se destruye.

Parámetros

ref Instancia del objeto de sentencia original

Documentación de Funciones Miembro

Result OpenDBX::Stmt::execute ()

Ejecuta una sentencia y devuelve una instancia de Result. Envía los datos necesarios al servidor de base de datos, que ejecutará la sentencia y devolverá uno o más conjuntos de resultados posteriormente. Los conjuntos de resultados se pueden obtener a través del objeto Result devuelto.

Devuelve

Instancia de Result

Excepciones

OpenDBX::Exception Si la biblioteca de base de datos subyacente devuelve un error
