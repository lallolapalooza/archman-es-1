OpenDBX::Lob::~Lob ()

Destruye la instancia del objeto grande si no existen otras referencias. Cada objeto grande utiliza un contador de referencias para recordar si las variables internas se comparten con otros objetos. Si este no es el caso o si este objeto es el último que hace referencia a las variables, el objeto se limpia y se libera la memoria asignada.

OpenDBX::Lob::Lob (const Lob & ref)

Constructor de copia. Permite la transferencia del estado interno de un objeto ref del mismo tipo a este objeto. Ambos objetos comparten las mismas variables y el contador de referencias después. El contador de referencias se incrementa cada vez que se copia un objeto y se decrementará si se destruye.

Parámetros

ref Instancia original del objeto grande

Documentación de funciones miembro

void OpenDBX::Lob::close ()

Cierra el objeto grande y confirma los cambios. Después de leer o escribir contenido nuevo en el objeto grande, debe cerrarse para confirmar los cambios en el disco y liberar los recursos. Si no se hace, el destructor del objeto intenta cerrar el objeto grande automáticamente, pero no hay garantía de que haya tenido éxito, ya que el destructor no lanza una excepción en caso de error. Por lo tanto, se recomienda encarecidamente llamar a este método una vez que ya no necesite el objeto.

Excepciones

OpenDBX::Exception Si la biblioteca subyacente de la base de datos devuelve un error

ssize_t OpenDBX::Lob::read (void * buffer, size_t buflen)

Lee el contenido del objeto grande en el búfer. Para obtener el contenido de un objeto grande, este método recupera los datos en una o más partes del servidor y las almacena en el búfer proporcionado por el usuario. La primera llamada a read() devolverá los bytes desde el principio. La segunda y todas las demás llamadas almacenarán partes subsiguientes del contenido del objeto grande en el búfer hasta que se alcance el final de los datos. Para volver a leer el contenido por segunda vez, debe cerrar el manejador del objeto grande y volver a abrirlo, ya que algunas bases de datos no proporcionan una forma de reposicionar el indicador de posición del archivo interno para el flujo. El contenido del objeto grande recuperado del servidor se almacena en el buffer proporcionado por el usuario hasta buflen bytes.

El método devuelve el número de bytes colocados en buffer, que puede ser hasta buflen bytes. Si se alcanza el final del contenido y no hay más datos disponibles, el valor de retorno será 0 (cero).

Parámetros

buffer Puntero a una matriz de bytes donde se escribirán los datos
buflen Longitud del búfer dado en bytes

Devuelve

Número de bytes escritos en el búfer

Excepciones

OpenDBX::Exception Si la biblioteca subyacente de la base de datos devuelve un error

ssize_t OpenDBX::Lob::write (void * buffer, size_t buflen)

Escribe datos del búfer en el objeto grande. Envía los datos suministrados en el búfer al servidor para almacenarlos dentro del objeto grande. La función se puede llamar más de una vez para agregar partes subsiguientes del contenido al objeto. Si no es un objeto nuevo o vacío, los datos existentes se sobrescribirán y se truncarán al nuevo tamaño. No es posible actualizar solo partes del contenido, ya que algunas bases de datos no admiten la posición del indicador de posición del archivo interno. Los datos que deben enviarse al servidor se leen de buffer hasta buflen bytes.

El método devuelve el número de bytes leídos de buffer y enviados al servidor de la base de datos, que puede ser hasta buflen bytes. No se garantiza que el fragmento completo se envíe al servidor, por lo que el tamaño devuelto puede ser menor que el valor en buflen.

Parámetros

buffer Puntero a una matriz de bytes donde se almacena el contenido
buflen Longitud de los datos en el búfer en bytes

Devuelve

Número de bytes escritos en el objeto grande

Excepciones

OpenDBX::Exception Si la biblioteca subyacente de la base de datos retu
