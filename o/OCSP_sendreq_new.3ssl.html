OCSP_sendreq_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OCSP_SENDREQ_NEW(3ssl) OpenSSL OCSP_SENDREQ_NEW(3ssl)

NOMBRE

OCSP_REQ_CTX, OCSP_sendreq_new, OCSP_sendreq_nbio, OCSP_sendreq_bio, OCSP_REQ_CTX_i2d, OCSP_REQ_CTX_add1_header, OCSP_REQ_CTX_free, OCSP_set_max_response_length, OCSP_REQ_CTX_set1_req - Funciones de consulta del respondedor OCSP

SINOPSIS

#include <openssl/ocsp.h>
OSSL_HTTP_REQ_CTX *OCSP_sendreq_new(BIO *io, const char *path,
                                    const OCSP_REQUEST *req, int buf_size);
OCSP_RESPONSE *OCSP_sendreq_bio(BIO *io, const char *path, OCSP_REQUEST *req);

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

typedef OSSL_HTTP_REQ_CTX OCSP_REQ_CTX;
int OCSP_sendreq_nbio(OCSP_RESPONSE **presp, OSSL_HTTP_REQ_CTX *rctx);
int OCSP_REQ_CTX_i2d(OCSP_REQ_CT *rctx, const ASN1_ITEM *it, ASN1_VALUE *req);
int OCSP_REQ_CTX_add1_header(OCSP_REQ_CT *rctx,
                             const char *name, const char *value);
void OCSP_REQ_CTX_free(OCSP_REQ_CTX *rctx);
void OCSP_set_max_response_length(OCSP_REQ_CT *rctx, unsigned long len);
int OCSP_REQ_CTX_set1_req(OCSP_REQ_CTX *rctx, const OCSP_REQUEST *req);

DESCRIPCIÓN

Estas funciones realizan una transferencia de solicitud/respuesta POST OCSP sobre HTTP, utilizando las funciones de solicitud HTTP descritas en OSSL_HTTP_REQ_CTX(3).

La función OCSP_sendreq_new() construye una estructura completa OSSL_HTTP_REQ_CTX con el BIO io a ser utilizado para solicitudes y respuestas, la ruta de la URL path, opcionalmente la solicitud OCSP req, y una longitud máxima de línea de cabecera de respuesta de buf_size. Si buf_size es cero, se usa un valor predeterminado de 4KiB. El argumento req puede ser establecido a NULL y proporcionado más tarde usando OCSP_REQ_CTX_set1_req() o OSSL_HTTP_REQ_CTX_set1_req(3). Los argumentos io y path para OCSP_sendreq_new() corresponden a los componentes de la URL. Por ejemplo, si la URL del respondedor es "http://example.com/ocspreq", el BIO io debería haber sido conectado al host "example.com" en el puerto 80 y path debería ser establecido a "/ocspreq".

OCSP_sendreq_nbio() intenta enviar la solicitud preparada en rctx y recopilar la respuesta a través de HTTP, utilizando el BIO io y path que se proporcionaron al llamar a OCSP_sendreq_new(). Si la operación se completa, asigna la respuesta, un puntero a una estructura OCSP_RESPONSE, en *presp. La función puede necesitar ser llamada de nuevo si su resultado es -1, lo que indica BIO_should_retry(3). En tal caso, es aconsejable dormir un poco entre llamadas, usando BIO_wait(3) en el BIO de lectura para prevenir un bucle de sondeo.

OCSP_sendreq_bio() combina OCSP_sendreq_new() con tantas llamadas a OCSP_sendreq_nbio() como sean necesarias y luego OCSP_REQ_CTX_free(), con una longitud máxima de línea de cabecera de respuesta de 4k. Espera indefinidamente una respuesta. No admite la configuración de un tiempo de espera ni la adición de cabeceras y se mantiene por compatibilidad; use OSSL_HTTP_transfer(3) en su lugar.

OCSP_REQ_CTX_i2d(rctx, it, req) es equivalente a lo siguiente:

OSSL_HTTP_REQ_CTX_set1_req(rctx, "application/ocsp-request", it, req)

OCSP_REQ_CTX_set1_req(rctx, req) es equivalente a lo siguiente:

OSSL_HTTP_REQ_CTX_set1_req(rctx, "application/ocsp-request",
                           ASN1_ITEM_rptr(OCSP_REQUEST),
                           (const ASN1_VALUE *)req)

El tipo obsoleto y las funciones obsoletas restantes han sido reemplazados por los siguientes equivalentes: OCSP_REQ_CTX por OSSL_HTTP_REQ_CTX(3), OCSP_REQ_CTX_add1_header() por OSSL_HTTP_REQ_CTX_add1_header(3), OCSP_REQ_CTX_free() por OSSL_HTTP_REQ_CTX_free(3), y OCSP_set_max_response_length() por OSSL_HTTP_REQ_CTX_set_max_response_length(3).

VALORES DE RETORNO

OCSP_sendreq_new() devuelve una estructura OSSL_HTTP_REQ_CTX válida o NULL si ocurrió un error.

OCSP_sendreq_nbio() devuelve 1 para éxito, 0 en caso de error, -1 si se necesita reintento.

OCSP_sendreq_bio() devuelve la estructura OCSP_RESPONSE enviada por el respondedor o NULL si ocurrió un error.

VER TAMBIÉN

OSSL_HTTP_REQ_CTX(3), OSSL_HTTP_transfer(3), OCSP_cert_to_id(3), OCSP_request_add1_nonce(3), OCSP_REQUEST_new(3), OCSP_resp_find_status(3), OCSP_response_status(3)

HISTORIA

OCSP_REQ_CTX, OCSP_REQ_CTX_i2d(), OCSP_REQ_CTX_add1_header(), OCSP_REQ_CTX_free(), OCSP_set_max_response_length(), y OCSP_REQ_CTX_set1_req() fueron marcadas como obsoletas en OpenSSL 3.0.
