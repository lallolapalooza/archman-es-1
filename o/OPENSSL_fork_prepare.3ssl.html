OPENSSL_fork_prepare(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OPENSSL_FORK_PREPARE(3ssl) OpenSSL OPENSSL_FORK_PREPARE(3ssl)

NOMBRE

OPENSSL_fork_prepare, OPENSSL_fork_parent, OPENSSL_fork_child - manejadores de fork de OpenSSL

SINOPSIS

#include <openssl/crypto.h>

Las siguientes funciones han sido marcadas como obsoletas desde OpenSSL 3.0, y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

void OPENSSL_fork_prepare(void);
void OPENSSL_fork_parent(void);
void OPENSSL_fork_child(void);

DESCRIPCION

Estos métodos actualmente no se utilizan y, como tales, no se requieren ni se planifican métodos de reemplazo.

OpenSSL tiene un estado que debe restablecerse cuando un proceso se bifurca. Por ejemplo, el grupo de entropía utilizado para generar números aleatorios (y, por lo tanto, claves de cifrado) no debe compartirse entre varios programas. Las funciones OPENSSL_fork_prepare(), OPENSSL_fork_parent() y OPENSSL_fork_child() se utilizan para restablecer este estado interno.

Las plataformas sin fork(2) probablemente no necesitarán usar estas funciones. Las plataformas con fork(2) pero sin pthread_atfork(3) probablemente necesitarán llamarlas manualmente, como se describe en el siguiente párrafo. Las plataformas como Linux que tienen ambas funciones normalmente no necesitarán llamar a estas funciones, ya que la biblioteca OpenSSL lo hará automáticamente.

OPENSSL_init_crypto(3) registrará estas funciones con el manejador apropiado, cuando se utilice la bandera OPENSSL_INIT_ATFORK. Para otras aplicaciones, estas funciones pueden ser llamadas directamente. Deben utilizarse de acuerdo con la secuencia de llamadas descrita en la documentación de pthread_atfork(3), que se resume aquí. OPENSSL_fork_prepare() debe llamarse antes de que se realice una llamada a fork(). Después de que fork() retorne, el proceso padre debe llamar a OPENSSL_fork_parent() y el proceso hijo debe llamar a OPENSSL_fork_child().

VALORES DE RETORNO

OPENSSL_fork_prepare(), OPENSSL_fork_parent() y OPENSSL_fork_child() no devuelven valores.

VER TAMBIÉN

OPENSSL_init_crypto(3)

HISTORIAL

Estas funciones se añadieron en OpenSSL 1.1.1.
