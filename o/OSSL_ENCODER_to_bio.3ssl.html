OSSL_ENCODER_to_bio(3ssl)

Paquete: openssl

Licencias: Apache-2.0

OSSL_ENCODER_TO_BIO(3ssl) OpenSSL OSSL_ENCODER_TO_BIO(3ssl)

NOMBRE

OSSL_ENCODER_to_data, OSSL_ENCODER_to_bio, OSSL_ENCODER_to_fp - Rutinas para realizar una codificación

SINOPSIS

#include <openssl/encoder.h>
int OSSL_ENCODER_to_data(OSSL_ENCODER_CTX *ctx, unsigned char **pdata,
                         size_t *pdata_len);
int OSSL_ENCODER_to_bio(OSSL_ENCODER_CTX *ctx, BIO *out);
int OSSL_ENCODER_to_fp(OSSL_ENCODER_CTX *ctx, FILE *fp);

Macros de disponibilidad de funcionalidades:

OSSL_ENCODER_to_fp() solo está disponible cuando OPENSSL_NO_STDIO está indefinido.

DESCRIPCIÓN

OSSL_ENCODER_to_data() ejecuta el proceso de codificación para el contexto ctx, con la salida dirigida a *pdata y *pdata_len. Si *pdata es NULL cuando se llama a OSSL_ENCODER_to_data(), se asignará un búfer usando OPENSSL_zalloc(3), y *pdata se establecerá para apuntar al inicio de ese búfer, y *pdata_len se le asignará su longitud cuando OSSL_ENCODER_to_data() retorne. Si *pdata no es NULL cuando se llama a OSSL_ENCODER_to_data(), se asume que *pdata_len tiene su tamaño. En este caso, *pdata se establecerá para apuntar después de los bytes codificados, y *pdata_len se le asignará el número de bytes restantes.

OSSL_ENCODER_to_bio() ejecuta el proceso de codificación para el contexto ctx, con la salida dirigida al BIO out.

OSSL_ENCODER_to_fp() hace lo mismo que OSSL_ENCODER_to_bio(), excepto que la salida se dirige al FILE fp.

Para OSSL_ENCODER_to_bio() y OSSL_ENCODER_to_fp(), la aplicación debe configurar el BIO o FILE correctamente, por ejemplo, para que esté en modo texto o binario según sea apropiado para el tipo de salida del codificador.

VALORES DE RETORNO

OSSL_ENCODER_to_bio(), OSSL_ENCODER_to_fp() y OSSL_ENCODER_to_data() retornan 1 en caso de éxito, o 0 en caso de fallo.

EJEMPLOS

Para codificar una pkey como PKCS#8 con formato PEM en un bio:

OSSL_ENCODER_CTX *ectx;
const char *format = "PEM";
const char *structure = "PrivateKeyInfo"; /* Estructura PKCS#8 */
const unsigned char *pass = "mi contraseña";
ectx = OSSL_ENCODER_CTX_new_for_pkey(pkey,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR
                                     | OSSL_KEYMGMT_SELECT_DOMAIN_PARAMETERS,
                                     format, structure,
                                     NULL);
if (ectx == NULL) {
    /* error: no se encontraron codificadores potenciales adecuados */
}
if (pass != NULL)
    OSSL_ENCODER_CTX_set_passphrase(ectx, pass, strlen(pass));
if (OSSL_ENCODER_to_bio(ectx, bio)) {
    /* pkey fue codificada exitosamente en el bio */
} else {
    /* fallo de codificación */
}
OSSL_ENCODER_CTX_free(ectx);

Para codificar una pkey como PKCS#8 con formato DER cifrado con AES-256-CBC en un búfer:

OSSL_ENCODER_CTX *ectx;
const char *format = "DER";
const char *structure = "PrivateKeyInfo"; /* Estructura PKCS#8 */
const unsigned char *pass = "mi contraseña";
unsigned char *data = NULL;
size_t datalen;
ectx = OSSL_ENCODER_CTX_new_for_pkey(pkey,
                                     OSSL_KEYMGMT_SELECT_KEYPAIR
                                     | OSSL_KEYMGMT_SELECT_DOMAIN_PARAMETERS,
                                     format, structure,
                                     NULL);
if (ectx == NULL) {
    /* error: no se encontraron codificadores potenciales adecuados */
}
if (pass != NULL) {
    OSSL_ENCODER_CTX_set_passphrase(ectx, pass, strlen(pass));
    OSSL_ENCODER_CTX_set_cipher(ctx, "AES-256-CBC", NULL);
}
if (OSSL_ENCODER_to_data(ectx, &data, &datalen)) {
    /*
     * pkey fue codificada exitosamente en un búfer de datos
     * recién asignado
     */
} else {
    /* fallo de codificación */
}
OSSL_ENCODER_CTX_free(ectx);
