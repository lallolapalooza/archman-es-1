OSSL_IETF_ATTR_SYNTAX(3ssl)

NOMBRE

OSSL_IETF_ATTR_SYNTAX, OSSL_IETF_ATTR_SYNTAX_get0_policyAuthority, OSSL_IETF_ATTR_SYNTAX_set0_policyAuthority, OSSL_IETF_ATTR_SYNTAX_get_value_num, OSSL_IETF_ATTR_SYNTAX_get0_value, OSSL_IETF_ATTR_SYNTAX_add1_value - Accesores y establecedores para OSSL_IETF_ATTR_SYNTAX

SINOPSIS

#include <openssl/x509_acert.h>
typedef struct OSSL_IETF_ATTR_SYNTAX_st OSSL_IETF_ATTR_SYNTAX;
const GENERAL_NAMES *
OSSL_IETF_ATTR_SYNTAX_get0_policyAuthority(const OSSL_IETF_ATTR_SYNTAX *a);
void OSSL_IETF_ATTR_SYNTAX_set0_policyAuthority(OSSL_IETF_ATTR_SYNTAX *a,
                                                GENERAL_NAMES *names);
int OSSL_IETF_ATTR_SYNTAX_get_value_num(const OSSL_IETF_ATTR_SYNTAX *a);
void *OSSL_IETF_ATTR_SYNTAX_get0_value(const OSSL_IETF_ATTR_SYNTAX *a,
                                       int ind, int *type);
int OSSL_IETF_ATTR_SYNTAX_add1_value(OSSL_IETF_ATTR_SYNTAX *a, int type,
                                     void *data);

DESCRIPCIÓN

OSSL_IETF_ATTR_SYNTAX es una estructura opaca que representa el tipo IetfAttrSyntax definido en RFC 5755 (Sección 4.4) para su uso como AttributeValue.

OSSL_IETF_ATTR_SYNTAX_get0_policyAuthority() y OSSL_IETF_ATTR_SYNTAX_set0_policyAuthority() obtienen y establecen el campo policyAuthority de la estructura. Ambas rutinas actúan sobre punteros internos de la estructura y no deben ser liberadas por la aplicación.

Un objeto OSSL_IETF_ATTR_SYNTAX también contiene una secuencia de valores. OSSL_IETF_ATTR_SYNTAX_get_value_num() devuelve el número de valores en la secuencia. OSSL_IETF_ATTR_SYNTAX_add1_value(), añade una copia de data de un type especificado a la secuencia. El llamador debe liberar data después de su uso.

OSSL_IETF_ATTR_SYNTAX_get0_value() devolverá el valor y un índice específico ind en la secuencia o NULL en caso de error. Si type no es NULL, el tipo del valor se escribirá en esta ubicación.

El type de los valores almacenados en la secuencia de valores OSSL_IETF_ATTR_SYNTAX es uno de los siguientes:

OSSL_IETFAS_OCTETS
Un puntero a un ASN1_OCTET_STRING
OSSL_IETFAS_OID
Un puntero a un ASN1_OBJECT
OSSL_IETFAS_STRING
Un puntero a un ASN1_UTF8STRING

VALORES DEVUELTOS

OSSL_IETF_ATTR_SYNTAX_get0_policyAuthority() devuelve un puntero a una estructura GENERAL_NAMES o NULL si la autoridad de política no ha sido establecida.

OSSL_IETF_ATTR_SYNTAX_get_value_num() devuelve el número de entradas en la secuencia de valores o -1 en caso de error.

OSSL_IETF_ATTR_SYNTAX_get0_value() devuelve un puntero al valor en el índice dado o NULL si el índice está fuera de rango.

OSSL_IETF_ATTR_SYNTAX_add1_value() devuelve 1 en caso de éxito y 0 en caso de fallo.

HISTORIA

OSSL_IETF_ATTR_SYNTAX_get0_policyAuthority(), OSSL_IETF_ATTR_SYNTAX_set0_policyAuthority(), OSSL_IETF_ATTR_SYNTAX_get_value_num(), OSSL_IETF_ATTR_SYNTAX_get0_value(), y OSSL_IETF_ATTR_SYNTAX_add1_value() se añadieron en OpenSSL 3.4.
