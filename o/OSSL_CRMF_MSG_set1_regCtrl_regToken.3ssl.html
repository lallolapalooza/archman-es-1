DESCRIPCIÓN

Cada una de las funciones OSSL_CRMF_MSG_get0_regCtrl_X() devuelve el control X respectivo en el msg dado, si está presente.

OSSL_CRMF_MSG_set1_regCtrl_regToken() establece el control regToken en el msg dado, copiando el tok dado como valor. Ver RFC 4211, sección 6.1.

OSSL_CRMF_MSG_set1_regCtrl_authenticator() establece el control authenticator en el msg dado, copiando el auth dado como valor. Ver RFC 4211, sección 6.2.

OSSL_CRMF_MSG_PKIPublicationInfo_push0_SinglePubInfo() agrega el spi dado a si. Consume el puntero spi.

OSSL_CRMF_MSG_set0_SinglePubInfo() establece en el SinglePubInfo spi dado el method y la ubicación de publicación, en forma de un GeneralName, nm. La ubicación de publicación es opcional, y por lo tanto nm puede ser NULL. La función consume el puntero nm si está presente. Los métodos disponibles son:
# define OSSL_CRMF_PUB_METHOD_DONTCARE 0
# define OSSL_CRMF_PUB_METHOD_X500 1
# define OSSL_CRMF_PUB_METHOD_WEB 2
# define OSSL_CRMF_PUB_METHOD_LDAP 3

OSSL_CRMF_MSG_set_PKIPublicationInfo_action() establece la acción en el pi dado usando la action dada como valor. Ver RFC 4211, sección 6.3. Las acciones disponibles son:
# define OSSL_CRMF_PUB_ACTION_DONTPUBLISH 0
# define OSSL_CRMF_PUB_ACTION_PLEASEPUBLISH 1

OSSL_CRMF_MSG_set1_regCtrl_pkiPublicationInfo() establece el control pkiPublicationInfo en el msg dado, copiando el tok dado como valor. Ver RFC 4211, sección 6.3.

OSSL_CRMF_MSG_set1_regCtrl_protocolEncrKey() establece el control protocolEncrKey en el msg dado, copiando el pubkey dado como valor. Ver RFC 4211, sección 6.6.

OSSL_CRMF_MSG_set1_regCtrl_oldCertID() establece el control de regToken oldCertID en el msg dado, copiando el cid dado como valor. Ver RFC 4211, sección 6.5.

OSSL_CRMF_CERTID_gen produce una estructura OSSL_CRMF_CERTID_gen copiando el nombre issuer y el número de serie serial dados.

VALORES DE RETORNO

Todas las funciones OSSL_CRMF_MSG_get0_*() devuelven el puntero respectivo o NULL si no está presente y en caso de error.

Todas las funciones OSSL_CRMF_MSG_set1_*() devuelven 1 en caso de éxito, 0 en caso de error.

OSSL_CRMF_CERTID_gen() devuelve un puntero a la estructura resultante o NULL en caso de error.

NOTAS

Una función OSSL_CRMF_MSG_set1_regCtrl_pkiArchiveOptions() para establecer un Control de Opciones de Archivado aún no está implementada debido a la falta de características para crear el contenido OSSL_CRMF_PKIARCHIVEOPTINS necesario.

VER TAMBIÉN
