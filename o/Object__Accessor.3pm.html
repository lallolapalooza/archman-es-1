Object::Accessor(3) Documentación de Perl aportada por el usuario Object::Accessor(3)

NOMBRE

Object::Accessor - interfaz para crear accesores por objeto

SINOPSIS

### usando el objeto
$obj = Object::Accessor->new;        # crear objeto
$obj = Object::Accessor->new(@list); # crear objeto con accesores
$obj = Object::Accessor->new(\%h);   # crear objeto con accesores
                                     # y sus manejadores de permiso
$bool   = $obj->mk_accessors('foo'); # crear accesores
$bool   = $obj->mk_accessors(        # crear accesores con validación
           {foo => MANEJADOR_PERMITIDO} ); # de entrada
$bool   = $obj->mk_aliases(          # crear un alias a un nombre
            nombre_alias => 'metodo'); # de método existente
$clone  = $obj->mk_clone;            # crear una copia del objeto
                                     # original sin datos
$bool   = $obj->mk_flush;            # limpiar todos los datos
@list   = $obj->ls_accessors;        # recupera una lista de todos
                                     # los accesores para este objeto
$bar    = $obj->foo('bar');          # asignar 'foo' a 'bar'
$bar    = $obj->foo();               # recuperar 'bar' de nuevo
$sub    = $obj->can('foo');          # recuperar coderef para
                                     # el accesorio 'foo'
$bar    = $sub->('bar');             # asignar 'foo' vía coderef
$bar    = $sub->();                  # recuperar 'bar' por coderef
### usando el objeto como clase base
package Mi::Clase;
use base 'Object::Accessor';
$obj    = Mi::Clase->new;               # crear objeto base
$bool   = $obj->mk_accessors('foo');    # crear accesores, etc...
### hacer que todos los intentos de acceso a accesores inexistentes sean fatales
### (por defecto es falso)
$Object::Accessor::FATAL = 1;
### habilitar depuración
$Object::Accessor::DEBUG = 1;
### uso avanzado -- callbacks
{   my $obj = Object::Accessor->new('foo');
    $obj->register_callback( sub { ... } );
    $obj->foo( 1 ); # estas llamadas invocan el callback que registraste
    $obj->foo()     # lo cual te permite cambiar el comportamiento
                    # de obtener/establecer y lo que se devuelve al llamador.
}
### uso avanzado -- atributos lvalue
{   my $obj = Object::Accessor::Lvalue->new('foo');
    print $obj->foo = 1;            # imprimirá 1
}
### uso avanzado -- valores de atributos con ámbito
{   my $obj = Object::Accessor->new('foo');
    $obj->foo( 1 );
    print $obj->foo;                # imprimirá 1
    ### enlazar el ámbito del valor del atributo 'foo'
    ### al ámbito de '$x' -- cuando $x salga del
    ### ámbito, se restaurará el valor anterior de 'foo'
    {   $obj->foo( 2 => \my $x );
        print $obj->foo, ' ', $x;   # imprimirá '2 2'
    }
    print $obj->foo;                # imprimirá 1
}

DESCRIPCIÓN

"Object::Accessor" proporciona una interfaz para crear accesores por objeto (en contraposición a accesores por "Clase", como, por ejemplo, "Class::Accessor" proporciona).

Puedes elegir entre crear una subclase de este módulo, y así usar sus accesores en tu propio módulo, o almacenar un objeto "Object::Accessor" dentro de tu propio objeto y acceder a los accesores desde allí. Consulta la "SINOPSIS" para ver ejemplos.

MÉTODOS

$objeto = Object::Accessor->new( [ARGUMENTOS] );

Crea un nuevo objeto (y vacío) de "Object::Accessor". Este método es heredable.

Cualquier argumento dado a "new" se pasa directamente a "mk_accessors".

Si deseas poder asignar a tus accesores como si fueran "lvalue"s, deberías crear tu objeto en el espacio de nombres "Object::Accessor::Lvalue" en su lugar. Consulta la sección sobre "ACCESORES LVALUE" más abajo.

$bool = $objeto->mk_accessors( @ACCESORES | \%MAPA_DE_ACCESORES );

Crea una lista de accesores para este objeto (y "NO" para otros en la misma clase!). No sobrescribirá datos existentes, por lo que si un accesorio ya existe, solicitar crearlo de nuevo es efectivamente una operación nula ("no-op").

Al proporcionar un "hashref" como argumento, en lugar de una lista normal, puedes especificar una lista de pares clave/valor de accesorios y sus respectivos validadores de entrada. Los validadores pueden ser cualquier cosa que la función "allow" de "Params::Check" acepte. Por favor, consulta su página del manual para obtener detalles.

Por ejemplo:

$object->mk_accessors( {
    foo     => qr/^\d+$/,       # solo dígitos
    bar     => [0,1],           # booleanos
    zot     => \&mi_sub         # una subrutina de verificación personalizada
} );

Devuelve verdadero en caso de éxito, falso en caso de fallo.

Los accesores que se llaman en un objeto, que no existen, devuelven "undef" por defecto, pero puedes hacer que esto sea un error fatal estableciendo la variable global $FATAL a verdadero. Consulta la sección sobre "VARIABLES GLOBALES" para más detalles.

Ten en cuenta que puedes enlazar los valores de los atributos a un ámbito. Esto te permite cambiar "temporalmente" un valor de un atributo, y que su valor original se restaure al final del ámbito de su variable enlazada;

Por ejemplo, en este fragmento de código, el atributo "foo" se establecerá temporalmente a 2, hasta el final del ámbito de $x, momento en el cual se restaurará el valor original de 1.

my $obj = Object::Accessor->new;
$obj->mk_accessors('foo');
$obj->foo( 1 );
print $obj->foo;                # imprimirá 1
### enlazar el ámbito del valor del atributo 'foo'
### al ámbito de '$x' -- cuando $x salga del
### ámbito, se restaurará el valor anterior de 'foo'
{   $obj->foo( 2 => \my $x );
    print $obj->foo, ' ', $x;   # imprimirá '2 2'
}
print $obj->foo;                # imprimirá 1

Ten en cuenta que todos los accesores son de lectura/escritura para todos. Consulta la sección "TODO" para más detalles.

@list = $self->ls_accessors;

Devuelve una lista de accesorios que son compatibles con el objeto actual. Los coderefs correspondientes se pueden recuperar pasando esta lista uno por uno al método "can".

$ref = $self->ls_allow(CLAVE)

Devuelve el manejador de permiso para la clave dada, que se puede utilizar con el manejador allow() de "Params::Check". Si no se especificó ningún manejador de permiso, se devolverá un manejador de permiso que siempre devuelve verdadero.

$bool = $self->mk_aliases( alias => metodo, [alias2 => metodo2, ...] );

Crea un alias para un nombre de método dado. Para todos los efectos intencionados, estos dos accesores son ahora idénticos para este objeto. Esto es similar a hacer lo siguiente a nivel de tabla de símbolos:

*alias = *metodo

Esto te permite hacer lo siguiente:

$self->mk_accessors('foo');
$self->mk_aliases( bar => 'foo' );
$self->bar( 42 );
print $self->foo;     # imprimirá 42

$copia = $self->mk_clone;

Crea una copia del objeto actual, que tendrá exactamente los mismos accesores que el objeto actual, pero sin los datos almacenados en ellos.

$bool = $self->mk_flush;

Limpia todos los datos del objeto actual; todos los accesores se restablecerán a su estado predeterminado de "undef".

Devuelve verdadero en caso de éxito y falso en caso de fallo.

$bool = $self->mk_verify;

Verifica si todos los valores en el objeto actual están en acuerdo

Object::Accessor::Lvalue - Perl object, accessor, and method generator

NAME

Object::Accessor::Lvalue - Perl object, accessor, and method generator

SYNOPSIS

    use Object::Accessor;
    my $obj = Object::Accessor->new( 'foo', 'bar' );
    $obj->foo( 'baz' );
    print $obj->foo; # prints baz
    $obj->bar( [qw( a b c )] );
    print join ',', $obj->bar; # prints a,b,c
    print $obj->foo() # prints baz
    print $obj->bar() # prints ARRAY ref

And for lvalue accessors:

    use Object::Accessor::Lvalue;
    my $obj = Object::Accessor::Lvalue->new( 'foo' );
    $obj->foo += 1; # works!
    print $obj->foo; # prints 1

DESCRIPTION

This module provides a convenient way to generate simple Perl objects with methods (accessors) to get and set their attributes.

It automates the creation of simple getter/setter methods, and also provides hooks for more advanced functionality like callbacks and validation.

METHODS

$obj = CLASS->new( ATTRIBUTE_NAME, ... )

The constructor. Creates a new object, and for each attribute name passed, it creates a corresponding accessor method.

    my $obj = Object::Accessor->new( 'foo', 'bar', 'baz' );

You can also pass a hashref to the constructor:

    my $obj = Object::Accessor->new({
        foo => 'bar',
        baz => 'qux',
    });

This will create the object and set the initial values for the attributes.

$obj = CLASS->new( ATTRIBUTE_NAME => ALLOW_HANDLER )

You can pass a coderef as the value for an attribute. This coderef will be used as an "allow handler". See the section on "ALLOW HANDLERS" below for details.

    my $obj = Object::Accessor->new(
        'name' => sub { my $val = shift; return lc($val) },
        'age'  => qr/^\d+$/s, # Use a regex as allow handler
    );

$value = $self->accessor_name( [ $value ] )

This is the standard accessor method. If called with an argument, it sets the attribute's value and returns the value. If called without an argument, it returns the attribute's current value.

$bool = $self->allow( ATTRIBUTE_NAME => ALLOW_HANDLER )

This method allows you to dynamically set or override an attribute's allow handler. The handler is a coderef that is called every time the attribute is set. It receives the value to be set as its only argument, and is expected to return the value that should actually be stored. This allows for data validation and transformation.

    # Set an allow handler for the 'email' attribute
    $obj->allow( email => sub {
        my $email = shift;
        return undef unless $email =~ qr/@/;
        return $email;
    });

    # Set the value, the allow handler will be called
    $obj->email('test@example.com');

    # Check if the object has an allow handler for an attribute
    if ( $obj->allow('email') ) {
        print "Email handler exists\n";
    }

This method is particularly useful for checking if an empty, initialized object has been filled with values that satisfy their respective allow criteria.

$bool = $self->register_callback( sub { ... } );

This method allows you to register a callback, which is invoked every time an accessor is called. This allows you to munge input data, access external data stores, etc.

You are free to return whatever you wish. On a "set" call, the data is even stored in the object.

Below is an example of the use of a callback.

$object->some_method( "some_value" );
my $callback = sub {
    my $self    = shift; # the object
    my $meth    = shift; # "some_method"
    my $val     = shift; # ["some_value"]
                         # could be undef -- check 'exists';
                         # if scalar @$val is empty, it was a 'get'
    # your code here
    return $new_val;     # the value you want to be set/returned
}

To access the values stored in the object, circumventing the callback structure, you should use the "___get" and "___set" methods documented further down.

$bool = $self->can( METHOD_NAME )

This method overrides "UNIVERAL::can" in order to provide coderefs to accessors which are loaded on demand. It will behave just like "UNIVERSAL::can" where it can -- returning a class method if it exists, or a closure pointing to a valid accessor of this particular object.

You can use it as follows:

$sub = $object->can('some_accessor');   # retrieve the coderef
$sub->('foo');                          # 'some_accessor' now set
                                        # to 'foo' for $object
$foo = $sub->();                        # retrieve the contents
                                        # of 'some_accessor'

See the "SYNOPSIS" for more examples.

$val = $self->___get( METHOD_NAME );

Method to directly access the value of the given accessor in the object. It circumvents all calls to allow checks, callbacks, etc.

Use only if you "Know What You Are Doing"! General usage for this functionality would be in your own custom callbacks.

$bool = $self->___set( METHOD_NAME => VALUE );

Method to directly set the value of the given accessor in the object. It circumvents all calls to allow checks, callbacks, etc.

Use only if you "Know What You Are Doing"! General usage for this functionality would be in your own custom callbacks.

$bool = $self->___alias( ALIAS => METHOD );

Method to directly alias one accessor to another for this object. It circumvents all sanity checks, etc.

Use only if you "Know What You Are Doing"!

LVALUE ACCESSORS

"Object::Accessor" supports "lvalue" attributes as well. To enable these, you should create your objects in the designated namespace, "Object::Accessor::Lvalue". For example:

my $obj = Object::Accessor::Lvalue->new('foo');
$obj->foo += 1;
print $obj->foo;

will actually print 1 and work as expected. Since this is an optional feature, that's not desirable in all cases, we require you to explicitly use the "Object::Accessor::Lvalue" class.

Doing the same on the standard "Object">Accessor> class would generate the following code & errors:

my $obj = Object::Accessor->new('foo');
$obj->foo += 1;
Can't modify non-lvalue subroutine call

Note that "lvalue" support on "AUTOLOAD" routines is a "perl 5.8.x" feature. See perldoc perl58delta for details.

CAVEATS

  • Allow handlers

    Due to the nature of "lvalue subs", we never get access to the value you are assigning, so we can not check it against your allow handler. Allow handlers are therefor unsupported under "lvalue" conditions.

    See "perldoc perlsub" for details.

  • Callbacks

    Due to the nature of "lvalue subs", we never get access to the value you are assigning, so we can not check provide this value to your callback. Furthermore, we can not distinguish between a "get" and a "set" call. Callbacks are therefor unsupported under "lvalue" conditions.

    See "perldoc perlsub" for details.

GLOBAL VARIABLES

$Object::Accessor::FATAL

Set this variable to true to make all attempted access to non-existent accessors be fatal. This defaults to "false".

$Object::Accessor::DEBUG

Set this variable to enable debugging output. This defaults to "false".

CAVEATS

If you use codereferences for your allow handlers, you will not be able to freeze the data structures using "Storable".

Due to a bug in storable (until at least version 2.15), "qr//" compiled regexes also don't de-serialize properly. Although this bug has been reported, you should be aware of this issue when serializing your objects.

You can track the bug here:
