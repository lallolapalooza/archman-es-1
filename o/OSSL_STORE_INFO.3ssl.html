DESCRIPCIÓN

Estas funciones son principalmente útiles para que las aplicaciones recuperen objetos soportados de los objetos OSSL_STORE_INFO y para que los cargadores específicos del esquema creen contenedores OSSL_STORE_INFO.

Tipos

OSSL_STORE_INFO es un tipo opaco que es solo un intermediario para los objetos que han sido recuperados por OSSL_STORE_load() y funciones similares. Los objetos de tipo OpenSSL soportados se pueden extraer utilizando una de las funciones STORE_INFO_get0_<TIPO>() donde <TIPO> puede ser NAME, PARAMS, PKEY, CERT o CRL. La vida útil de este objeto extraído es tan larga como la vida útil del OSSL_STORE_INFO del que se extrajo, por lo que se debe tener cuidado de no liberar este último demasiado pronto. Como alternativa, STORE_INFO_get1_<TIPO>() extrae una copia (o el mismo objeto con su contador de referencias incrementado), que se puede usar después de que el OSSL_STORE_INFO contenedor haya sido liberado. El objeto devuelto por STORE_INFO_get1_<TIPO>() debe ser liberado por separado por el llamador. Ver "OBJETOS SOPORTADOS" para más información sobre los tipos soportados.

Funciones

OSSL_STORE_INFO_get_type() toma un OSSL_STORE_INFO y devuelve el número de tipo STORE para el objeto que contiene.

STORE_INFO_type_string() toma un número de tipo STORE y devuelve una cadena corta que lo describe.

OSSL_STORE_INFO_get0_NAME(), OSSL_STORE_INFO_get0_NAME_description(), OSSL_STORE_INFO_get0_PARAMS(), OSSL_STORE_INFO_get0_PUBKEY(), OSSL_STORE_INFO_get0_PKEY(), OSSL_STORE_INFO_get0_CERT(), OSSL_STORE_INFO_get0_CRL() toman un OSSL_STORE_INFO y devuelven el objeto que contiene si el tipo de OSSL_STORE_INFO (tal como lo devuelve OSSL_STORE_INFO_get_type()) coincide con la función, de lo contrario NULL.

OSSL_STORE_INFO_get1_NAME(), OSSL_STORE_INFO_get1_NAME_description(), OSSL_STORE_INFO_get1_PARAMS(), OSSL_STORE_INFO_get1_PUBKEY(), OSSL_STORE_INFO_get1_PKEY(), OSSL_STORE_INFO_get1_CERT() y OSSL_STORE_INFO_get1_CRL() toman un OSSL_STORE_INFO y devuelven una copia del objeto que contiene si el tipo de OSSL_STORE_INFO (tal como lo devuelve OSSL_STORE_INFO_get_type()) coincide con la función, de lo contrario NULL.

OSSL_STORE_INFO_free() libera un OSSL_STORE_INFO y su tipo contenido. Si el argumento es NULL, no se hace nada.

OSSL_STORE_INFO_new_NAME(), OSSL_STORE_INFO_new_PARAMS(), OSSL_STORE_INFO_new_PUBKEY(), OSSL_STORE_INFO_new_PKEY(), OSSL_STORE_INFO_new_CERT() y OSSL_STORE_INFO_new_CRL() crean un objeto OSSL_STORE_INFO para contener el objeto de entrada dado. En caso de éxito, el objeto de entrada se consume.

Adicionalmente, para los objetos OSSL_STORE_INFO_NAME, OSSL_STORE_INFO_set0_NAME_description() se puede usar para agregar una descripción adicional. Esta descripción está destinada a ser legible por humanos y debe usarse para la impresión de información.

OSSL_STORE_INFO_new() crea un OSSL_STORE_INFO con un número de tipo arbitrario y una estructura de datos. Es responsabilidad del llamador definir números de tipo distintos de los definidos por <openssl/store.h> y manejar la liberación de la estructura de datos asociada por su cuenta. El uso de números de tipo que están definidos por <openssl/store.h> puede causar comportamientos indefinidos, incluyendo caídas.

OSSL_STORE_INFO_get0_data() devuelve el puntero de datos que se pasó a OSSL_STORE_INFO_new() si el tipo coincide con el número de tipo en info.

OSSL_STORE_INFO_new() y OSSL_STORE_INFO_get0_data() pueden ser útiles para aplicaciones que definen sus propios datos de STORE, pero deben usarse con cuidado.

OBJETOS SOPORTADOS

Actualmente los tipos de objetos soportados son:

OSSL_STORE_INFO_NAME
Un nombre es exactamente eso, un nombre. Es como un nombre en un directorio, pero formateado como una URI completa. Por ejemplo, la ruta en la URI "file:/foo/bar/" podría incluir un archivo llamado "cookie.pem", y en ese caso, el objeto OSSL_STORE_INFO_NAME devuelto tendría la URI "file:/foo/bar/cookie.pem", que puede ser utilizada por la aplicación para obtener los objetos en ese archivo. Esto se puede aplicar a todos los esquemas que de alguna manera puedan soportar un listado de URIs de objetos.

Para las URIs de "file:" que se usan sin el esquema explícito, el nombre devuelto será la ruta de cada objeto, por lo que si se dio "/foo/bar" y esa ruta tiene el archivo "cookie.pem", se devolverá el nombre "/foo/bar/cookie.pem".

La URI devuelta se considera canónica y debe ser única y permanente para el almacenamiento donde reside el objeto (o colección de objetos). Cada cargador es responsable de asegurar que solo devuelve URIs canónicas. Sin embargo, es posible que ciertos esquemas permitan que un objeto (o colección de ellos) sea alcanzado con URIs alternativas; el hecho de que una URI sea canónica no significa que otras variantes no puedan usarse.

A discreción del cargador que se utilizó para obtener estos nombres, también se puede adjuntar una descripción adicional.

DESCRIPTION

The OSSL_STORE API is a generic interface for loading objects like certificates, CRLs, private keys, and others from various sources. This documentation describes the OSSL_STORE_INFO object, which is the return type from many of the OSSL_STORE functions. It's a container for various types of objects.

The OSSL_STORE_INFO object is opaque. Its contents are accessed through the functions described below.

The different types of objects that can be contained within an OSSL_STORE_INFO are identified by integer type numbers. The following symbolic names are defined:

OSSL_STORE_INFO_NAME

An OSSL_STORE_NAMED_VALUE object. This is a generic name-value pair. The name is a string and the value is a generic pointer, which must be cast to the correct type by the caller.

See OSSL_STORE_NAMED_VALUE(3ssl).

OSSL_STORE_INFO_PARAMS

An ASN1_TYPE object. This is a generic ASN.1 type.

OSSL_STORE_INFO_PKEY

An EVP_PKEY object, representing a private key.

OSSL_STORE_INFO_CERT

An X.509 certificate.

OSSL_STORE_INFO_CRL

A X.509 certificate revocation list.

RETURN VALUES

OSSL_STORE_INFO_get_type() returns the STORE type number of the given OSSL_STORE_INFO. There is no error value.

OSSL_STORE_INFO_get0_NAME(), OSSL_STORE_INFO_get0_NAME_description(), OSSL_STORE_INFO_get0_PARAMS(), OSSL_STORE_INFO_get0_PKEY(), OSSL_STORE_INFO_get0_CERT() and OSSL_STORE_INFO_get0_CRL() all return a pointer to the OpenSSL object on success, NULL otherwise.

OSSL_STORE_INFO_get1_NAME(), OSSL_STORE_INFO_get1_NAME_description(), OSSL_STORE_INFO_get1_PARAMS(), OSSL_STORE_INFO_get1_PKEY(), OSSL_STORE_INFO_get1_CERT() and OSSL_STORE_INFO_get1_CRL() all return a pointer to a duplicate of the OpenSSL object on success, NULL otherwise.

OSSL_STORE_INFO_type_string() returns a string on success, or NULL on failure.

OSSL_STORE_INFO_new_NAME(), OSSL_STORE_INFO_new_PARAMS(), OSSL_STORE_INFO_new_PKEY(), OSSL_STORE_INFO_new_CERT() and OSSL_STORE_INFO_new_CRL() return a OSSL_STORE_INFO pointer on success, or NULL on failure.

OSSL_STORE_INFO_set0_NAME_description() returns 1 on success, or 0 on failure.
