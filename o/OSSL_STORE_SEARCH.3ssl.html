OSSL_STORE_SEARCH(3ssl) OpenSSL OSSL_STORE_SEARCH(3ssl)

NOMBRE

OSSL_STORE_SEARCH, OSSL_STORE_SEARCH_by_name, OSSL_STORE_SEARCH_by_issuer_serial, OSSL_STORE_SEARCH_by_key_fingerprint, OSSL_STORE_SEARCH_by_alias, OSSL_STORE_SEARCH_free, OSSL_STORE_SEARCH_get_type, OSSL_STORE_SEARCH_get0_name, OSSL_STORE_SEARCH_get0_serial, OSSL_STORE_SEARCH_get0_bytes, OSSL_STORE_SEARCH_get0_string, OSSL_STORE_SEARCH_get0_digest - Tipo y funciones para crear criterios de búsqueda OSSL_STORE

SINOPSIS

#include <openssl/store.h>
typedef struct ossl_store_search_st OSSL_STORE_SEARCH;
OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_by_name(X509_NAME *name);
OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_by_issuer_serial(X509_NAME *name,
                                                      const ASN1_INTEGER
                                                      *serial);
OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_by_key_fingerprint(const EVP_MD *digest,
                                                        const unsigned char
                                                        *bytes, int len);
OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_by_alias(const char *alias);
void OSSL_STORE_SEARCH_free(OSSL_STORE_SEARCH *search);
int OSSL_STORE_SEARCH_get_type(const OSSL_STORE_SEARCH *criterion);
X509_NAME *OSSL_STORE_SEARCH_get0_name(OSSL_STORE_SEARCH *criterion);
const ASN1_INTEGER *OSSL_STORE_SEARCH_get0_serial(const OSSL_STORE_SEARCH
                                                  *criterion);
const unsigned char *OSSL_STORE_SEARCH_get0_bytes(const OSSL_STORE_SEARCH
                                                  *criterion, size_t *length);
const char *OSSL_STORE_SEARCH_get0_string(const OSSL_STORE_SEARCH *criterion);
const EVP_MD *OSSL_STORE_SEARCH_get0_digest(const OSSL_STORE_SEARCH
                                            *criterion);

DESCRIPCIÓN

Estas funciones se utilizan para especificar criterios de búsqueda que ayuden a buscar objetos específicos a través de nombres distintos del URI que se proporciona a OSSL_STORE_open(). Por ejemplo, esto puede ser útil para una aplicación que ha recibido un URI y luego quiere añadir criterios de búsqueda de manera uniforme y compatible.

Tipos

OSSL_STORE_SEARCH es un tipo opaco que contiene el criterio de búsqueda construido, y que puede ser dado a un contexto OSSL_STORE con OSSL_STORE_find().

La aplicación que llama es propietaria de la asignación de un OSSL_STORE_SEARCH en todo momento, y por lo tanto debe tener cuidado de no desasignarlo antes de que se haya llamado a OSSL_STORE_close() para el contexto OSSL_STORE al que se le dio.

Funciones de aplicación

OSSL_STORE_SEARCH_by_name(), OSSL_STORE_SEARCH_by_issuer_serial(), OSSL_STORE_SEARCH_by_key_fingerprint(), y OSSL_STORE_SEARCH_by_alias() se utilizan para crear un OSSL_STORE_SEARCH a partir de un nombre de sujeto, un par de nombre de emisor y número de serie, una huella digital de clave y un alias (por ejemplo, un nombre descriptivo). Los parámetros que se proporcionan no se copian, solo se refieren en un criterio, por lo que deben tener al menos la misma vida útil que el OSSL_STORE_SEARCH creado.

OSSL_STORE_SEARCH_free() se utiliza para liberar el OSSL_STORE_SEARCH. Si el argumento es NULL, no se hace nada.

Funciones de carga

OSSL_STORE_SEARCH_get_type() devuelve el tipo de criterio para el OSSL_STORE_SEARCH dado.

OSSL_STORE_SEARCH_get0_name(), OSSL_STORE_SEARCH_get0_serial(), OSSL_STORE_SEARCH_get0_bytes(), OSSL_STORE_SEARCH_get0_string(), y OSSL_STORE_SEARCH_get0_digest() se utilizan para recuperar diferentes datos de un OSSL_STORE_SEARCH, según estén disponibles para cada tipo. Para más información, ver "TIPOS DE CRITERIOS SOPORTADOS" a continuación.

TIPOS DE CRITERIOS SOPORTADOS

Actualmente, los tipos de criterios soportados son:

OSSL_STORE_SEARCH_BY_NAME
Este criterio admite una búsqueda por coincidencia exacta del nombre del sujeto. El nombre del sujeto en sí es un puntero X509_NAME. Un criterio de este tipo se crea con OSSL_STORE_SEARCH_by_name(), y el nombre del sujeto real se recupera con OSSL_STORE_SEARCH_get0_name().
OSSL_STORE_SEARCH_BY_ISSUER_SERIAL
Este criterio admite una búsqueda por coincidencia exacta tanto del nombre del emisor como del número de serie. El nombre del emisor en sí es un puntero X509_NAME, y el número de serie es un puntero ASN1_INTEGER. Un criterio de este tipo se crea con OSSL_STORE_SEARCH_by_issuer_serial() y el nombre del emisor y el número de serie reales se recuperan con OSSL_STORE_SEARCH_get0_name() y OSSL_STORE_SEARCH_get0_serial().
OSSL_STORE_SEARCH_BY_KEY_FINGERPRINT
Este criterio admite una búsqueda por coincidencia exacta de la huella digital de la clave. La huella digital de la clave en sí es una cadena de bytes y su longitud, así como el algoritmo que se utilizó para calcular la huella digital. El digest puede dejarse sin especificar (NULL), y en ese caso, el cargador tiene que decidir sobre un digest predeterminado y comparar las huellas digitales en consecuencia. Un criterio de este tipo se crea con OSSL_STORE_SEARCH_by_key_fingerprint() y la huella digital real y su longitud se pueden recuperar con OSSL_STORE_SEARCH_get0_bytes(). El digest se puede recuperar con OSSL_STORE_SEARCH_get0_digest().
OSSL_STORE_SEARCH_BY_ALIAS
Este criterio admite una búsqueda por coincidencia de un alias de algún tipo. El alias en sí es una cadena C simple. Un criterio de este tipo se crea con OSSL_STORE_SEARCH_by_alias() y el alias real se recupera con OSSL_STORE_SEARCH_get0_string().

VALORES DE RETORNO

OSSL_STORE_SEARCH_by_name(), OSSL_STORE_SEARCH_by_issuer_serial(), OSSL_STORE_SEARCH_by_key_fingerprint(), y OSSL_STORE_SEARCH_by_alias() devuelven un puntero OSSL_STORE_SEARCH en caso de éxito, o NULL en caso de error.

OSSL_STORE_SEARCH_get_type() devuelve el tipo de criterio del OSSL_STORE_SEARCH dado. No hay valor de error.

OSSL_STORE_SEARCH_get0_name() devuelve un puntero X509_NAME en caso de éxito, o NULL cuando el OSSL_STORE_SEARCH dado era de un tipo diferente.

OSSL_STORE_SEARCH_get0_serial() devuelve un puntero ASN1_INTEGER en caso de éxito, o NULL cuando el OSSL_STORE_SEARCH dado era de un tipo diferente.

OSSL_STORE_SEARCH_get0_bytes() devuelve un puntero const unsigned char y establece *length a la longitud de la cadena en caso de éxito, o NULL cuando el OSSL_STORE_SEARCH dado era de un tipo diferente.

OSSL_STORE_SEARCH_get0_string() devuelve un puntero const char en caso de éxito, o NULL cuando el OSSL_STORE_SEARCH dado era de un tipo diferente.

OSSL_STORE_SEARCH_get0_digest() devuelve un puntero const EVP_MD. NULL es un valor válido y significa que el predeterminado del cargador de la tienda se utilizará cuando sea aplicable.

VER TAMBIÉN

ossl_store(7), OSSL_STORE_supports_search(3), OSSL_STORE_find(3)

HISTORIA

OSSL_STORE_SEARCH(3ssl) - OpenSSL Manual

NAME

OSSL_STORE_SEARCH - API for searching and retrieving objects from a store.

SYNOPSIS

#include <openssl/store.h>

OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_new(int type, OSSL_STORE_SEARCH_METHOD *sm);
int OSSL_STORE_SEARCH_set_str(OSSL_STORE_SEARCH *search, const char *value);
int OSSL_STORE_SEARCH_set_int(OSSL_STORE_SEARCH *search, int value);
int OSSL_STORE_SEARCH_set_keyid(OSSL_STORE_SEARCH *search, const OSSL_STORE_SEARCH *keyid);
int OSSL_STORE_SEARCH_set_pem_url(OSSL_STORE_SEARCH *search, const char *value);
int OSSL_STORE_SEARCH_set_x509(OSSL_STORE_SEARCH *search, const X509 *value);
int OSSL_STORE_SEARCH_set_x509_by_alias(OSSL_STORE_SEARCH *search, const char *value);
int OSSL_STORE_SEARCH_set_dh(OSSL_STORE_SEARCH *search, const DH *value);
int OSSL_STORE_SEARCH_set_group(OSSL_STORE_SEARCH *search, const EC_GROUP *value);
void OSSL_STORE_SEARCH_free(OSSL_STORE_SEARCH *search);
int OSSL_STORE_SEARCH_get_type(const OSSL_STORE_SEARCH *search);
void *OSSL_STORE_SEARCH_get_data(const OSSL_STORE_SEARCH *search);
OSSL_STORE_SEARCH_METHOD *OSSL_STORE_SEARCH_get_method(const OSSL_STORE_SEARCH *search);
OSSL_STORE_SEARCH *OSSL_STORE_SEARCH_dup(const OSSL_STORE_SEARCH *search);

DESCRIPTION

The OpenSSL store component provides an API for retrieving objects from various storage backends, such as files, PKCS#11 tokens, or Key Archiving Service (KAS) servers. The objects can be certificates, private keys, DH parameters, EC parameters, etc. The retrieval process is driven by searches.

The general idea is that you create a search object, populate it with the criteria you want to use for searching, and then pass that search object to an OSSL_STORE_LOADER object. The OSSL_STORE_LOADER object then iterates through all suitable storage backends, and for each backend, it checks if it can satisfy the search request.

A search is represented by the OSSL_STORE_SEARCH structure. This structure contains the type of search criterion and associated data.

The type of search criterion is an integer that must be one of the types defined in the "SUPPORTED CRITERION TYPES" section below.

The search method is an OSSL_STORE_SEARCH_METHOD pointer. This is a pointer to a structure that contains function pointers for all the operations that a specific storage backend can perform. The search method can be NULL if the storage backend doesn't support any search operations.

OSSL_STORE_SEARCH_new() creates a new search object of the specified type. If a method is provided, it is copied and associated with the search object. If the method is NULL, it means the search is generic and independent of any specific backend method.

OSSL_STORE_SEARCH_set_str(), OSSL_STORE_SEARCH_set_int(), OSSL_STORE_SEARCH_set_keyid(), OSSL_STORE_SEARCH_set_pem_url(), OSSL_STORE_SEARCH_set_x509(), OSSL_STORE_SEARCH_set_x509_by_alias(), OSSL_STORE_SEARCH_set_dh(), and OSSL_STORE_SEARCH_set_group() are functions to set the value of the search criterion. The type of value depends on the type of search.

OSSL_STORE_SEARCH_free() frees the search object.

OSSL_STORE_SEARCH_get_type(), OSSL_STORE_SEARCH_get_data(), and OSSL_STORE_SEARCH_get_method() are accessors to retrieve the type, data, and method from a search object.

OSSL_STORE_SEARCH_dup() duplicates a search object.

SUPPORTED CRITERION TYPES

OSSL_STORE_SEARCH_BY_NAME
Search by object name. The value is a string.
OSSL_STORE_SEARCH_BY_TYPE
Search by object type. The value is an integer (e.g. OSSL_STORE_CERTIFICATE, OSSL_STORE_PRIVATEKEY).
OSSL_STORE_SEARCH_BY_KEY_ID
Search by key identifier. The value is an OSSL_STORE_SEARCH object representing the key identifier. This key identifier can be a raw byte string, or a string representation of a key identifier.
OSSL_STORE_SEARCH_BY_ALIAS
Search by alias. The value is a string.
OSSL_STORE_SEARCH_BY_PEM_URL
Search by PEM URL. The value is a string.
OSSL_STORE_SEARCH_BY_X509
Search by X509 certificate. The value is a pointer to a X509 object.
OSSL_STORE_SEARCH_BY_X509_BY_ALIAS
Search by X509 certificate using an alias. The value is a string.
OSSL_STORE_SEARCH_BY_DH
Search by DH parameters. The value is a pointer to a DH object.
OSSL_STORE_SEARCH_BY_GROUP
Search by EC group. The value is a pointer to an EC_GROUP object.

RETURN VALUES

OSSL_STORE_SEARCH_new(), OSSL_STORE_SEARCH_dup() return a pointer to a newly allocated OSSL_STORE_SEARCH structure, or NULL on error.

OSSL_STORE_SEARCH_set_str(), OSSL_STORE_SEARCH_set_int(), OSSL_STORE_SEARCH_set_keyid(), OSSL_STORE_SEARCH_set_pem_url(), OSSL_STORE_SEARCH_set_x509(), OSSL_STORE_SEARCH_set_x509_by_alias(), OSSL_STORE_SEARCH_set_dh(), and OSSL_STORE_SEARCH_set_group() return 1 on success, or 0 on error.

OSSL_STORE_SEARCH_get_type() returns the type of the search criterion.

OSSL_STORE_SEARCH_get_data() returns a pointer to the data associated with the search criterion.

OSSL_STORE_SEARCH_get_method() returns a pointer to the search method associated with the search object.
