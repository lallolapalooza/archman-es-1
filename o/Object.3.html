NOMBRE

Object — La clase del widget Object

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

Object nunca se instancia. Su único propósito es como superclase de soporte para otras clases de widgets.

Clases

El puntero de clase es objectClass.

El nombre de la clase es Object.

Recursos Nuevos

La siguiente tabla define un conjunto de recursos de widgets utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), se puede establecer usando XtSetValues (S), se puede recuperar usando XtGetValues (G) o no es aplicable (N/A).
