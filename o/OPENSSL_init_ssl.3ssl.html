NOMBRE

OPENSSL_init_ssl - Inicialización de OpenSSL (libssl y libcrypto)

SINOPSIS

#include <openssl/ssl.h>
int OPENSSL_init_ssl(uint64_t opts, const OPENSSL_INIT_SETTINGS *settings);

DESCRIPCIÓN

Durante el funcionamiento normal, OpenSSL (libssl y libcrypto) asignará varios recursos al inicio que, posteriormente, deberán liberarse al cerrar la biblioteca. Además, algunos recursos se asignan por hilo (si la aplicación es multihilo) y estos recursos deben liberarse antes de que el hilo se cierre.

A partir de la versión 1.1.0, OpenSSL asignará automáticamente todos los recursos que necesite, por lo que no se requiere una inicialización explícita. De manera similar, también se desinicializará automáticamente según sea necesario.

Sin embargo, puede haber situaciones en las que la inicialización explícita sea deseable o necesaria, por ejemplo, cuando se requiere alguna inicialización no predeterminada. La función OPENSSL_init_ssl() se puede utilizar para este propósito. Llamar a esta función inicializará explícitamente AMBAS libcrypto y libssl. Para inicializar explícitamente SOLO libcrypto, consulte la función OPENSSL_init_crypto(3).

Numerosas funciones internas de OpenSSL llaman a OPENSSL_init_ssl(). Por lo tanto, para realizar una inicialización no predeterminada, el código de la aplicación DEBE llamar a OPENSSL_init_ssl() antes de cualquier otra llamada a funciones de OpenSSL.

El parámetro opts especifica qué aspectos de libssl y libcrypto deben inicializarse. Las opciones válidas para libcrypto se describen en la página OPENSSL_init_crypto(3). Además de cualquier opción específica de libcrypto, también se pueden utilizar las siguientes opciones de libssl:

OPENSSL_INIT_NO_LOAD_SSL_STRINGS
Suprime la carga automática de las cadenas de error de libssl. Esta opción no es una opción predeterminada. Una vez seleccionada, las llamadas posteriores a OPENSSL_init_ssl() con la opción OPENSSL_INIT_LOAD_SSL_STRINGS serán ignoradas.
OPENSSL_INIT_LOAD_SSL_STRINGS
Carga automática de las cadenas de error de libssl. Esta opción es una opción predeterminada. Una vez seleccionada, las llamadas posteriores a OPENSSL_init_ssl() con la opción OPENSSL_INIT_LOAD_SSL_STRINGS serán ignoradas.

OPENSSL_init_ssl() toma un parámetro settings que se puede utilizar para establecer valores de parámetros. Consulte OPENSSL_init_crypto(3) para obtener detalles.

VALORES DE RETORNO

La función OPENSSL_init_ssl() devuelve 1 en caso de éxito o 0 en caso de error.

VER TAMBIÉN

OPENSSL_init_crypto(3)

HISTORIA

La función OPENSSL_init_ssl() se añadió en OpenSSL 1.1.0.
