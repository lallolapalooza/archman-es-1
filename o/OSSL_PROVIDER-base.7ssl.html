NOMBRE

OSSL_PROVIDER-base - Proveedor base de OpenSSL

DESCRIPCIÓN

El proveedor base de OpenSSL suministra la codificación para la criptografía asimétrica de OpenSSL.

Propiedades

Las implementaciones en este proveedor tienen específicamente esta propiedad definida:

"provider=base"

Puede ser utilizada en una cadena de consulta de propiedades con funciones de obtención.

No es obligatorio consultar esta propiedad, excepto para asegurarse de obtener implementaciones de este proveedor y ninguna otra.

"type=parameters"
"type=private"
"type=public"

Estas pueden ser utilizadas en una cadena de consulta de propiedades con funciones de obtención para seleccionar qué datos deben ser codificados. Se puede seleccionar el material de la clave privada, el material de la clave pública o los parámetros del dominio.

"format=der"
"format=pem"
"format=text"

Estas pueden ser utilizadas en una cadena de consulta de propiedades con funciones de obtención para seleccionar el formato de salida de la codificación. Actualmente se permiten los formatos DER, PEM y texto plano.

OPERACIONES Y ALGORITMOS

El proveedor base de OpenSSL soporta estas operaciones y algoritmos:

Generación de Números Aleatorios

SEED-SRC, véase EVP_RAND-SEED-SRC(7)
JITTER, véase EVP_RAND-JITTER(7)

Además de este proveedor, los algoritmos "SEED-SRC" y "JITTER" también están disponibles en el proveedor por defecto.
