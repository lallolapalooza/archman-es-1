NOMBRE

fd2pascal - Conversor de archivos de diseño de XForms a programa Pascal

SINOPSIS

fd2pascal [-compensate] [-altformat] [-main] [-callback] nombre_archivo

DESCRIPCIÓN

fd2pascal lee un archivo de diseño de XForms ( .fd ) y crea código Pascal para generar el formulario descrito en el archivo. El código Pascal se escribe en un archivo con el mismo nombre que el archivo de entrada, pero con la extensión .pp Si ya existe un archivo con ese nombre, se renombrará a un archivo al que se le añadirá la extensión .bak.

OPCIONES

fd2pascal tiene un número reducido de opciones para controlar su comportamiento:

-altformat
Por defecto, se emite un tipo de registro para la definición del formulario, con un campo para cada widget (objeto) en el formulario. El formato alternativo declara una variable global para el formulario y para cada widget en él.
-compensate
Si se proporciona esta opción, se emitirá una llamada a fl_adjust_form_size después de que se cree el formulario.
-callback
Si se proporciona esta opción, se generará un procedimiento de devolución de llamada (callback) para cada widget del formulario.
-main
Por defecto, se crea una unidad que puede incluirse en la cláusula `uses` de un programa. Si se especifica esta opción, se emitirá en su lugar un archivo de programa.
