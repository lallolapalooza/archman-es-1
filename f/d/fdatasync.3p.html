PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fdatasync — sincroniza los datos de un archivo (REALTIME)

SINOPSIS

#include <unistd.h>
int fdatasync(int fildes);

DESCRIPCIÓN

La función fdatasync() forzará todas las operaciones de I/O en cola actualmente asociadas con el archivo indicado por el descriptor de archivo fildes al estado de finalización de I/O sincronizada.

La funcionalidad será equivalente a fsync() con el símbolo _POSIX_SYNCHRONIZED_IO definido, con la excepción de que todas las operaciones de I/O se completarán según lo definido para la finalización de la integridad de los datos de I/O sincronizada.

VALOR DEVUELTO

Si tiene éxito, la función fdatasync() devolverá el valor 0; de lo contrario, la función devolverá el valor -1 y establecerá errno para indicar el error. Si la función fdatasync() falla, no se garantiza que las operaciones de I/O pendientes se hayan completado.

ERRORES

La función fdatasync() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo válido.
EINVAL
Esta implementación no soporta I/O sincronizada para este archivo.

En caso de que alguna de las operaciones de I/O en cola falle, fdatasync() devolverá las condiciones de error definidas para read() y write().

USO DE LA APLICACIÓN

Tenga en cuenta que incluso si el descriptor de archivo no está abierto para escritura, si hay solicitudes de escritura pendientes en el archivo subyacente, esa I/O se completará antes de que fdatasync() devuelva.
