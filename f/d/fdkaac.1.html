NOMBRE

fdkaac - interfaz de línea de comandos para el codificador libfdk-aac

SINOPSIS

fdkaac [OPCIONES] [ARCHIVO]

DESCRIPCIÓN

fdkaac lee audio PCM lineal en formato WAV, PCM sin procesar o CAF, y lo codifica en un archivo M4A / AAC.

Si el archivo de entrada es "-", se leen datos de stdin. Del mismo modo, si el archivo de salida es "-", se escriben datos en stdout si se ha seleccionado uno de los formatos de transporte AAC transmisibles mediante -f.

Cuando se usa una entrada CAF y una salida M4A, las etiquetas del archivo CAF se copian en el M4A resultante.

OPCIONES

-h, --help
Muestra la ayuda del comando
-o <ARCHIVO>
Nombre del archivo de salida.
-p, --profile <n>
Perfil de destino (tipo de objeto de audio MPEG4, AOT)

5

-b, --bitrate <n>

-m, --bitrate-mode <n>
Modo de configuración de la tasa de bits. El valor de calidad VBR disponible depende de otros parámetros como el perfil, la frecuencia de muestreo o el número de canales.
0
CBR (por defecto)
1-5
VBR (valor más alto -> tasa de bits más alta)
-w, --bandwidth <n>
Ancho de banda de frecuencia (frecuencia de corte del paso bajo) en Hz. Disponible solo en AAC LC.
-a, --afterburner <n>
Configura el modo afterburner. Cuando está activado, la calidad se incrementa a expensas de una carga computacional adicional.
0
Desactivado
1
Activado (por defecto)
-L, --lowdelay-sbr <n>
Configura la actividad SBR en AAC ELD.
-1
Usar la configuración automática de ELD SBR
0
Desactivar SBR en ELD (por defecto)
1
Activar SBR en ELD
-s, --sbr-ratio <n>
Controla la activación del SBR muestreado a la mitad.
0
Usar el valor por defecto de la librería (por defecto)
1
Usar SBR muestreado a la mitad (por defecto para ELD+SBR)
2
Usar SBR de doble frecuencia (por defecto para HE-AAC)

El SBR de doble frecuencia es el que normalmente se usa para HE-AAC, donde AAC se codifica a la mitad de la frecuencia de muestreo de SBR, de ahí el nombre "doble frecuencia". Por otro lado, el SBR muestreado a la mitad usa la misma frecuencia de muestreo tanto para AAC como para SBR (frecuencia única), por lo tanto el SBR muestreado a la mitad típicamente consume más tasa de bits.

El SBR muestreado a la mitad es una función recién introducida en la biblioteca del codificador FDK versión 3.4.12. Cuando libfdk-aac en el sistema no lo soporta, se usará el SBR de doble frecuencia. Cuando está disponible, el SBR de doble frecuencia es el valor por defecto para HE-AAC y el SBR muestreado a la mitad es el valor por defecto para ELD+SBR.

Tenga en cuenta que el HE-AAC muestreado a la mitad no es tan común como el de doble frecuencia. Cuando se selecciona HE-AAC muestreado a la mitad, fdkaac se ve forzado a elegir señalización SBR jerárquica explícita, que (al menos) iTunes no acepta.

-G, --gapless-mode <n>
Método para declarar la cantidad de retardo del codificador (y relleno) en el contenedor M4A. Estos valores son obligatorios para una reproducción sin pausas correcta en el lado del reproductor.
0

--include-sbr-delay
Cuando se especifica, cuenta el retardo del decodificador SBR en el retardo del codificador.

Esto no es compatible con iTunes y llevará a un problema de reproducción sin pausas en decodificadores solo LC, pero este es el comportamiento por defecto de la biblioteca FDK.

Contar o no el retardo del decodificador SBR en el retardo del codificador resulta en una incompatibilidad en la reproducción sin pausas. Debe elegir cuál funcionará para su reproductor favorito.

Sin embargo, es mejor no elegir SBR en absoluto si se quiere reproducción sin pausas. LC no tiene tales problemas.

NAME

fdkaac

A command line tool to encode audio stream into MPEG4 AAC format using Fraunhofer FDK AAC codec.

SYNOPSIS

fdkaac [-o output] [--}$$ input

fdkaac [-o output] [--] [input]

DESCRIPTION

The fdkaac is a command line tool to encode audio stream into MPEG4 AAC format using Fraunhofer FDK AAC codec library. It supports various input formats (like WAV, CAF, FLAC, MP3, etc.) and output formats (M4A, ADTS).

The input file is taken from standard input if it is omitted or specified as `-`.

The output file is written to standard output if it is omitted or specified as `-`.

OPTIONS

-o output
Set output file name. Default is standard output.
-h, --help
Show help message and exit.
-v, --version
Show version information and exit.
-m mode
Set encoding mode. Supported modes are:
0
A basic AAC-LC mode. The default mode.
1
A better AAC-LC mode (might be slower).
2
HE-AAC mode (Low Complexity). Good for low bitrate.
3
HE-AAC v2 mode (further compression).
4
AAC-ELD mode (Enhanced Low Delay). Suitable for real-time applications.
5
AAC-XHE mode (Extended High Efficiency). Supports very low bitrates down to 6 kbps.
-q num
Set quality level for VBR. Higher number means higher quality. Default is 0.
-b bitrate
Set target bitrate in kbps. Default is 128kbps.
-r avg_bitrate
Set average bitrate in kbps for advanced rate control.
-p profile
Set AAC profile. Supported profiles are:
0
AAC-LC (Low Complexity). This is the default.
1
AAC-HEv1 (High Efficiency v1).
2
AAC-HEv2 (High Efficiency v2).
3
AAC-ELD (Enhanced Low Delay).
4
AAC-XHE (Extended High Efficiency).
-c mode
Set channel mode:
0
Mono
1
Stereo
2
Joint Stereo. This is the default.
3
Dual channel
-s rate
Set sampling rate in Hz. Default is auto-detected from input.
--title <string>
Set title tag.
--artist <string>
Set artist tag.
--album <string>
Set album tag.
--genre <string>
Set genre tag.
--date <string>
Set date tag.
--composer <string>
Set composer tag.
--grouping <string>
Set grouping tag.
--comment <string>
Set comment tag.
--album-artist <string>
Set album artist tag.
--track <number[/total]>
Set track tag, with or without number of total tracks.
--disk <number[/total]>
Set disk tag, with or without number of total discs.
--tempo <n>
Set tempo (BPM) tag.
--tag <fcc>:<value>
Set iTunes predefined tag with explicit fourcc key and value. See https://code.google.com/p/mp4v2/wiki/iTunesMetadata for known predefined keys. You can omit first char of fcc when it is the copyright sign.
--tag-from-file <fcc>:<filename>
Same as --tag, but set content of file as tag value.
--long-tag <name>:<value>
Set arbitrary tag as iTunes custom metadata. Stored in com.apple.iTunes field.
--tag-from-json <filename[?dot_notation]>
Read tags from JSON. By default, tags are assumed to be direct children of the root object in JSON. Optionally you can specify arbitrary dot notation to locate the object containing tags.

EXAMPLES

Encode WAV file into a M4A file. MPEG4 AAC LC, VBR quality 3:

fdkaac -m3 foo.wav

Encode WAV file into a M4A file. MPEG4 HE-AAC, bitrate 64kbps:

fdkaac -p5 -b64 foo.wav

Piping from ffmpeg (you need version supporting CAF output):

ffmpeg -i foo.flac -f caf - | fdkaac -b128 - -o foo.m4a

Import tags via json:

ffprobe -v 0 -of json -show_format foo.flac >foo.json
flac -dc foo.flac | \
fdkaac - -ox.m4a -m2 --import-tag-from-json=foo.json?format.tags

NOTES

Upto 32bit integer or 64bit floating point format is supported as input. However, FDK library is implemented based on fixed point math and only supports 16bit integer PCM. Therefore, be wary of clipping. You might want to dither/noise shape beforehand when your input has higher resolution.

Following channel layouts are supported by the encoder.

1ch
C
2ch
L R
3ch
C L R
4ch
C L R Cs
5ch
C L R Ls Rs
5.1ch
C L R Ls Rs LFE
7.1ch (front)
C Lc Rc L R Ls Rs LFE
7.1ch (rear)
C L R Ls Rs Rls Rrs LFE
