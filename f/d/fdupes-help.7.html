NOMBRE

fdupes-help - Referencia del modo interactivo de fdupes

INTRODUCCIÓN

Cuando se ejecuta de forma interactiva (como fdupes --delete), fdupes mostrará una lista de duplicados y solicitará al usuario una acción posterior.

El usuario puede indicar a fdupes qué archivos conservar o eliminar marcándolos en consecuencia. Una vez marcados, el usuario puede instruir a fdupes para que elimine cualquier archivo que haya sido marcado para su eliminación. Esto puede hacerse de forma incremental, si se desea, marcando y eliminando sucesivamente un número limitado de archivos a la vez hasta que no queden más duplicados por procesar.

Hay varias formas de marcar archivos en fdupes: individualmente usando el cursor, proporcionando una lista de archivos a conservar, o seleccionando archivos que coincidan con criterios de búsqueda particulares y marcándolos como se desee. Cada uno de estos enfoques se discute en detalle en las secciones siguientes.

DESPLAZAMIENTO DE LA LISTA

La lista de duplicados puede desplazarse de la siguiente manera:

PÁG ABAJO
Desplazar hacia abajo a la siguiente página.
PÁG ARRIBA
Desplazar hacia arriba a la página anterior.
MAYÚS + ABAJO
Desplazar hacia abajo una línea. No soportado en algunas terminales.
MAYÚS + ARRIBA
Desplazar hacia arriba una línea. No soportado en algunas terminales.

MOVER EL CURSOR

El cursor indica a fdupes sobre qué archivo y/o conjunto de duplicados actuar, como se describe en la siguiente sección. La posición del cursor puede cambiarse de la siguiente manera:

ABAJO
Avanzar el cursor al siguiente archivo de la lista.
ARRIBA
Mover el cursor al archivo anterior.
TABULADOR
Avanzar el cursor al siguiente conjunto de duplicados.
RETROCESO
Mover el cursor al conjunto anterior.
F3
Avanzar el cursor al siguiente conjunto seleccionado , si existe.
F2
Mover el cursor al conjunto seleccionado anterior, si existe.

También es posible saltar directamente a un conjunto particular:

'goto <índice>'
Mover el cursor al inicio del conjunto indicado por índice.

MARCAR ARCHIVOS USANDO EL CURSOR

Los archivos individuales pueden marcarse usando las teclas siguientes. Estas teclas actúan todas sobre el archivo actual, identificado por el cursor.

MAYÚS + DERECHA
Marcar el archivo actual para conservar.
MAYÚS + IZQUIERDA
Marcar el archivo actual para eliminación.
'?'
Quitar la marca del archivo actual.

Se pueden marcar conjuntos completos de archivos proporcionando una lista de índices en una lista separada por comas. Los archivos del conjunto actual cuyos índices aparezcan en la lista serán marcados para conservar, mientras que cualquier otro archivo en ese conjunto será marcado para eliminación. Como con los archivos individuales, el conjunto actual es identificado por el cursor.

Como ejemplo, dada la siguiente lista de duplicados:

Conjunto 1 de 5:


1 [ ] ruta/archivo_a
2 [ ] ruta/archivo_b
3 [ ] ruta/archivo_c

Escribiendo '1, 3' en el prompt y pulsando ENTER le dirá a fdupes que marque archivo_a y archivo_c para conservar, y archivo_b para eliminación. El comando especial 'all' marcará todos los archivos para conservar.

Hay un comando más para tratar con archivos en el conjunto actual:

'rg'
Quitar las marcas de todos los archivos del conjunto actual.

COMANDOS DE SELECCIÓN DE ARCHIVOS

Otra forma de marcar archivos es primero seleccionarlos de acuerdo con criterios de búsqueda particulares y luego decirle a fdupes qué hacer con ellos. Los siguientes comandos pueden usarse para seleccionar archivos para marcar:

'sel <texto>'
Seleccionar cualquier archivo cuya ruta contenga el texto dado.
'selb <texto>'
Seleccionar cualquier archivo cuya ruta comience con el texto dado.
'sele <texto>'
Seleccionar cualquier archivo cuya ruta termine con el texto dado.
'selm <texto>'
Seleccionar cualquier archivo cuya ruta coincida exactamente con el texto dado.
'selr <expresión>'
Seleccionar cualquier archivo cuya ruta coincida con la expresión regular dada (ver abajo).
'dsel <texto>'
Deseleccionar cualquier archivo cuya ruta contenga el texto dado.
'dselb <texto>'
Deseleccionar cualquier archivo cuya ruta comience con el texto dado.
'dsele <texto>'
Deseleccionar cualquier archivo cuya ruta termine con el texto dado.
'dselm <texto>'
Deseleccionar cualquier archivo cuya ruta coincida exactamente con el texto dado.
'dselr <expresión>'
Deseleccionar cualquier archivo cuya ruta coincida con la expresión regular dada (ver abajo).
'csel'
Limpiar todas las selecciones.
'isel'
Invertir las selecciones dentro de los conjuntos seleccionados. Por ejemplo, si los archivos 1 y 4 en un conjunto de 5 están seleccionados, isel deseleccionará los archivos 1 y 4, y seleccionará los archivos 2, 3 y 5. Repetir inmediatamente el mismo comando deseleccionará los archivos 2, 3 y 5, y seleccionará los archivos 1 y 4, restaurando las selecciones a su estado anterior.

MARCAR ARCHIVOS SELECCIONADOS

Una vez que algunos archivos hayan sido seleccionados usando los comandos descritos arriba, los siguientes comandos pueden usarse para marcar los archivos seleccionados como se desee:

'ks'
Marcar los archivos seleccionados para conservar.
'ds'
Marcar los archivos seleccionados para eliminación.
'rs'
Quitar todas las marcas de los archivos seleccionados.

ELIMINAR DUPLICADOS

Una vez marcados para eliminación, los archivos pueden eliminarse pulsando SUPRIMIR o usando el comando 'prune' . Fdupes eliminará cualquier archivo que esté marcado para eliminación y quitará de la lista cualquier conjunto cuyos archivos restantes hayan sido marcados para conservar. Por seguridad, fdupes se negará a actuar sobre conjuntos para los cuales todos los archivos hayan sido marcados para eliminación. Para manejar estos casos, marque al menos un archivo para conservar y ejecute el comando de eliminación nuevamente.

OTROS COMANDOS

'exit', 'quit'
Salir del programa.
'help'
Mostrar este texto de ayuda.

EXPRESIONES REGULARES

Una expresión regular es una secuencia de caracteres que define un patrón de búsqueda contra el cual otras secuencias de caracteres pueden ser comparadas. Las cadenas de caracteres que siguen el patrón definido por una expresión se dice que coinciden con la expresión, mientras que las cadenas que rompen el patrón no coinciden.

La sintaxis para las expresiones regulares usadas por fdupes es conocida como la sintaxis de Expresiones Regulares Compatibles con Perl . Una descripción detallada de la sintaxis de expresiones regulares está fuera del alcance de este documento. Para información detallada se recomienda al usuario consultar la documentación PCRE2 :

https://www.pcre.org/current/doc/html/pcre2syntax.html

Brevemente, aquí hay algunos ejemplos de expresiones regulares:

abc123
Coincidirá con cualquier cadena que contenga la secuencia abc123, como abc123, abc123x, xabc123, y xabc123x.
^abc123
Coincidirá con cualquier cadena que comience con abc123, como abc123 y abc123x, pero no xabc123 o x

EXPRESIONES REGULARES

Los siguientes modificadores se pueden usar para afinar las búsquedas:

abc123
Buscarán cadenas que contengan la secuencia de caracteres abc123.
^abc123
Buscará cadenas que comiencen con abc123, como por ejemplo abc123x. El carácter '^' tiene un significado especial, indicando al programa que solo debe buscar cadenas que comiencen con el patrón que le sigue.
abc123$
Buscará cadenas que terminen con abc123, como por ejemplo abc123 y xabc123, pero no abc123x ni xabc123x. El carácter '$' tiene un significado especial, indicando al programa que solo debe buscar cadenas que terminen con el patrón precedente.
^abc123$
Buscará la cadena abc123 y ninguna otra.
ab.123
Buscará cualquier cadena que contenga abc123 como en el primer ejemplo, pero también encontrará cadenas que contengan abz123, ab0123, ab_123, etc. El carácter '.' tiene un significado especial, actuando como un marcador de posición que encontrará cualquier carácter en esa posición.
^a.*3$
Buscará cualquier cadena que comience con la letra a y termine con el número 3, como por ejemplo abc123, a3, y a0b1c2d3. Aquí, el carácter '*' indica al programa que acepte cualquier número de apariciones (incluyendo ninguna) del elemento precedente (aquí, cualquier carácter que coincida con el carácter marcador '.'). Los caracteres '^' y '$' tienen el mismo significado que en los ejemplos anteriores.
abc\d+
Buscará cualquier cadena que contenga los caracteres abc seguidos inmediatamente por uno o más dígitos decimales, como por ejemplo abc123 y abc3210, pero no abcd123 ni abc 123 (nota el espacio). Aquí, \d es un marcador de posición para cualquier dígito decimal, mientras que el carácter '+' indica al programa que busque una o más apariciones del carácter o marcador de posición precedente (aquí, \d).
\w+\d+
Buscará cualquier cadena que contenga uno o más caracteres de "palabra" seguidos inmediatamente por uno o más dígitos decimales, como por ejemplo abc123 y abcd3210, pero no abc 123 (nota el espacio). Aquí, \w es un marcador de posición para un carácter de "palabra", y \d y '+' tienen el mismo significado que en el ejemplo anterior.

Esto es solo una introducción a lo que se puede hacer con las expresiones regulares. Consulte la documentación de PCRE2 para una referencia completa.
