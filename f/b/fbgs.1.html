FBGS(1) Visor de PostScript/pdf para la consola framebuffer de Linux FBGS(1)

NOMBRE

fbgs - Visor de PostScript/pdf improvisado para la consola framebuffer de Linux.

SINOPSIS

fbgs [-l|-xl|-xxl|-r n] [-c] [-b] [-p contraseña] [--fp número] [--lp número] [opciones de fbi] archivo

DESCRIPCIÓN

Fbgs es un script envoltorio simple que toma un archivo PostScript (PS) o Portable Document Format (PDF) como entrada, renderiza las páginas usando gs(1) - GhostScript - en un directorio temporal y finalmente llama a fbi(1) para mostrarlas.

OPCIONES

Fbgs entiende todas las opciones de fbi(1) (se pasan a través), excepto: store, list, text, (no)comments, e, (no)edit, (no)backup, (no)preserve, (no)readahead, cachemem, blend.

Adicionalmente puede especificar:

-h, --help
Imprime información de uso (sobrescribe la opción de fbi).
-b, --bell
Emite un pitido cuando el documento está listo.
-c, --color
Para renderizar las páginas en color (el predeterminado es B&N).
-l
Para que las páginas se rendericen con 100 dpi (el predeterminado es 75).
-xl
Para que las páginas se rendericen con 120 dpi.
-xxl
Para que las páginas se rendericen con 150 dpi.
-r n, --resolution n
Para que las páginas se rendericen con n dpi (sobrescribe la opción de fbi).
-fp número, --firstpage número
Comienza a interpretar en la página designada del documento.
-lp número, --lastpage número
Detiene la interpretación después de la página designada del documento.
-p contraseña, --password contraseña
Puede usar esta opción si su archivo PDF requiere una contraseña.

VER TAMBIÉN

fbi(1), gs(1)
