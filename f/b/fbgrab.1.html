NOMBRE

fbgrab - toma capturas de pantalla usando el dispositivo de framebuffer

SINOPSIS

fbgrab [opciones] nombre_archivo

DESCRIPCIÓN

fbgrab lee el dispositivo de framebuffer (/dev/fb*) o una copia del mismo y guarda un archivo de imagen PNG. Puedes usarlo para hacer capturas de pantalla de prácticamente cualquier aplicación, desde aplicaciones de prueba tradicionales hasta tu escritorio X-windows, así como aplicaciones de framebuffer.

OPCIONES

-?
muestra información de uso.
-a
ignora el canal alfa con controladores que lo configuran incorrectamente pero no lo soportan.
-b profundidad_bits
el número de bits por píxel utilizado, opcional al leer desde el dispositivo.
-c consola
especifica qué consola (o terminal virtual - como lo llama otra gente) capturar. A veces este cambio es más rápido que la actualización del framebuffer (especialmente al capturar aplicaciones de framebuffer). Si es así, deberías usar -C consola ... Esto espera un tiempo antes de capturar. No puedes usar -s en este caso.
-d dispositivo
especifica qué dispositivo de framebuffer deseas leer. Si no usas esta opción, toma el valor de la variable de entorno FRAMEBUFFER. Si no se proporciona ninguna variable de entorno FRAMEBUFFER o si su valor es NULL, se toma DEFAULT_FB. (ver código fuente), que normalmente es /dev/fb0.
-f nombre_archivo
Lee desde un archivo en lugar de un dispositivo, requiere que se especifiquen -w (ancho), -h (alto) y -b (profundidad_bits).
-h alto
el alto del framebuffer en píxeles, opcional al leer desde el dispositivo.
-i entrelazado
desactiva el entrelazado. Si no quieres el entrelazado ADAM7, deberías usar la opción -i.
-l longitud_linea, también llamada stride.
la longitud en píxeles entre el inicio de cada fila en el framebuffer, que podría ser mayor o igual al ancho. Opcional al leer desde el dispositivo.
-s segundos
especifica cuántos segundos esperar antes de capturar. fbshot no bloquea el cambio de consola, por lo que puedes cambiarla mientras esperas, si no puedes usar -c requiere normalmente que fbgrab se ejecute como root.
-v verboso
ser verboso
-w ancho
el ancho del framebuffer en píxeles, opcional al leer desde el dispositivo.
-z nivel_compresión
establece el nivel de compresión png de 0 (rápido) a 9 (mejor).

PENDIENTE

* Profundidades de bits bajas, por ejemplo, 1, 2, 4 y 8 bits.

* Programa compañero fbput que mostraría una imagen en el framebuffer.
* Mejor utilización de la librería PNG, todos los formatos se convierten primero a 32 bits de profundidad y luego se almacenan como PNG - difícilmente el enfoque correcto.

EJEMPLOS

fbgrab fb.png

tomará una instantánea del framebuffer, o si no tienes fbgrab en tu máquina, puedes hacer

cp /dev/fb0 framebuffer.dump

y luego

fbgrab -w 1024 -h 768 -l 2048 -b 16 -f framebuffer.dump fb.png

para convertirlo en una imagen.
