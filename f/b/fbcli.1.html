Nombre

fbcli - Emitir eventos a feedbackd

SINOPSIS

fbcli [OPCIONES...]

DESCRIPCIÓN

fbcli puede usarse para enviar eventos a feedbackd para activar retroalimentación de audio, visual o háptica.

OPCIONES

-h, --help
imprimir ayuda y salir
-E=EVENTO, --event=EVENTO
Enviar el evento dado a feedbackd. Los eventos válidos se listan en la especificación de nombres de eventos en https://gitlab.freedesktop.org/agx/feedbackd/-/blob/main/doc/Event-naming-spec-0.0.0.md
-I, --important
Si se debe establecer la pista importante
-t=TIEMPO_DE_ESPERA, --timeout=TIEMPO_DE_ESPERA
El tiempo de espera en segundos después del cual la retroalimentación para el evento dado debe detenerse.
-P=PERFIL, --profile=PERFIL
El perfil de retroalimentación (full, quiet, silent) a utilizar para el evento dado. Si no se especifica ningún evento, se cambia el perfil de retroalimentación global.
-w=TIEMPO_DE_ESPERA, --watch=TIEMPO_DE_ESPERA
Tiempo de espera máximo para esperar a que finalice la retroalimentación del evento dado y que fbcli salga.
-A=ID_APLICACION, --app-id=ID_APLICACION
Anular el ID de aplicación utilizado
-S=ARCHIVO_SONIDO, --sound-file=ARCHIVO_SONIDO
Anular el efecto de sonido utilizado con el archivo dado. Esto solo tiene efecto cuando un evento de sonido sería activado por este evento en el nivel actual.
