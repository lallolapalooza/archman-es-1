NOMBRE

fbdev - controlador de video para el dispositivo framebuffer

SINOPSIS

Sección "Device"
  Identificador "nombre_dispositivo"
  Driver "fbdev"
  BusID  "pci:bus:dev:func"
  ...
FinSección

DESCRIPCIÓN

fbdev es un controlador de Xorg para dispositivos framebuffer. Este es un controlador no acelerado, los siguientes profundidades de framebuffer son compatibles: 8, 15, 16, 24. Todos los tipos visuales son compatibles para profundidad 8, y el tipo visual TrueColor es compatible para las otras profundidades. Las configuraciones multi-monitor son compatibles.

HARDWARE SOPORTADO

El controlador fbdev soporta todo el hardware para el cual está disponible un controlador de framebuffer. fbdev utiliza el submódulo específico del sistema operativo fbdevhw(4) para comunicarse con el controlador de dispositivo del kernel. Actualmente, un módulo fbdevhw está disponible para linux.

DETALLES DE CONFIGURACIÓN

Por favor, consulte xorg.conf(5) para detalles generales de configuración. Esta sección solo cubre los detalles de configuración específicos de este controlador.

Para este controlador no es necesario especificar modos en la sección de pantalla del archivo de configuración. El controlador fbdev puede obtener el modo de video actualmente utilizado del controlador de framebuffer y lo usará si no hay modos de video configurados.

Para placas PCI, es posible que deba agregar una línea BusID a la sección Device. Consulte arriba para ver una línea de ejemplo.

Las siguientes Opciones del controlador son compatibles:

Opción "fbdev" "cadena"
El dispositivo framebuffer a utilizar. Por defecto: /dev/fb0.
Opción "ShadowFB" "booleano"
Habilitar o deshabilitar el uso de la capa de framebuffer en sombra. Obligatorio para framebuffers de 24bpp en servidores más nuevos. Por defecto: activado.
Opción "Rotate" "cadena"
Habilita la rotación de la pantalla. Los valores compatibles son "CW" (sentido horario, 90 grados), "UD" (boca abajo, 180 grados) y "CCW" (sentido antihorario, 270 grados). Implica el uso de la capa de framebuffer en sombra. Deshabilitado para framebuffers de 24bpp. Por defecto: desactivado.
