fblocked(n) Comandos integrados de Tcl fblocked(n)

NOMBRE

fblocked - Comprueba si la última operación de entrada agotó toda la entrada disponible

SINOPSIS

fblocked idCanal

DESCRIPCIÓN

El comando fblocked devuelve 1 si la operación de entrada más reciente en idCanal devolvió menos información de la solicitada porque toda la entrada disponible se agotó. Por ejemplo, si se invoca gets cuando solo hay tres caracteres disponibles para entrada y ninguna secuencia de fin de línea, gets devuelve una cadena vacía y una llamada posterior a fblocked devolverá 1.

idCanal debe ser un identificador para un canal abierto, como un canal estándar de Tcl (stdin, stdout o stderr), el valor de retorno de una invocación de open o socket, o el resultado de un comando de creación de canal proporcionado por una extensión de Tcl.

EJEMPLO

El comando fblocked es particularmente útil al escribir servidores de red, ya que le permite escribir su código en un estilo línea por línea sin impedir el servicio de otras conexiones. Esto se puede ver en este simple servicio de eco:

# Esto se llama cada vez que un nuevo cliente se conecta al servidor proc connect {chan host port} {
set clientName [format <%s:%d> $host $port]
puts "conexión desde $clientName"
fconfigure $chan -blocking 0 -buffering line
fileevent $chan readable [list echoLine $chan $clientName] }

# Esto se llama siempre que haya al menos un byte de datos de entrada disponibles, o el canal sea cerrado por el cliente. proc echoLine {chan clientName} {
gets $chan line
if {[eof $chan]} {
puts "finalizando conexión desde $clientName"
close $chan
} elseif {![fblocked $chan]} {
# No se bloqueó esperando el fin de línea
puts "$clientName - $line"
puts $chan $line
} }

# Crea el socket del servidor y entra en el bucle de eventos para esperar # conexiones entrantes... socket -server connect 12345 vwait forever

PALABRAS CLAVE

bloqueo, no bloqueo
