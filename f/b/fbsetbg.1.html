FBSETBG(1) Manual de Fluxbox FBSETBG(1)

NOMBRE

fbsetbg - Establecer un fondo de pantalla o patrón

SINOPSIS

fbsetbg [-uU establecedor_fondo] [-fFcCtTaA] fondo_pantalla

fbsetbg [-uU establecedor_fondo] -rR ruta

fbsetbg -bB opciones_fbsetroot...

fbsetbg [-l|h|i|p]

DESCRIPCIÓN

fbsetbg(1) es un script que intenta encontrar una aplicación adecuada para establecer el fondo de pantalla y luego intenta establecer el fondo de pantalla usando esa aplicación. No es necesario configurar fbsetbg. Simplemente utiliza la primera aplicación que encuentra.

Además, admite recordar el último fondo de pantalla establecido para que no tenga que editar el archivo de estilo o inicialización para cambiar el fondo de pantalla.

Su objetivo es proporcionar mensajes de error claros en una ventana que faciliten la depuración de problemas.

OPCIONES

-f archivo

Establece el fondo de pantalla a pantalla completa.

-c archivo

Establece el fondo de pantalla centrado.

-t archivo

Establece el fondo de pantalla en mosaico.

-a archivo

Establece el fondo de pantalla maximizado, conservando la relación de aspecto (si su establecedor de fondo no admite esta opción, fbsetbg recurrirá a -f).

-u establecedor_fondo

Utiliza el establecedor de fondo especificado, no uses argumento para olvidarlo.

-b opciones_fbsetroot

Pasa las opciones a fbsetroot(1). Estas se pueden utilizar para establecer una textura de fondo sólida, de patrón o degradada.

-r directorio

Establece un fondo de pantalla aleatorio de un directorio.

-F, -C, -T, -A, -U, -B, -R

Igual que la opción en minúsculas pero sin recordar.

-l

Restablece el fondo de pantalla anterior. O, si la función aleatoria se usó por última vez, establece otro fondo de pantalla aleatorio del mismo directorio.

-i

Muestra información útil sobre el mejor establecedor de fondo encontrado.

-p

Muestra algunos consejos útiles.

-h

Muestra un mensaje de ayuda.

ARCHIVOS

~/.fluxbox/lastwallpaper

En este archivo se guardará el fondo de pantalla que establezcas, para la opción -l.

ENTORNO

wpsetters

Establecedores de fondos de pantalla a utilizar. Esta puede ser una lista delimitada por espacios de las aplicaciones a probar, o solo un nombre.

DISPLAY

La pantalla en la que deseas establecer el fondo de pantalla.

EJEMPLOS

Para usar feh(1) como establecedor de fondo de pantalla y establecer wallpaper.jpg del directorio actual como fondo de pantalla.

$ wpsetters=feh fbsetbg wallpaper.jpg

Recupera el último fondo de pantalla establecido en la pantalla :0.0 con las opciones guardadas.

$ DISPLAY=:0.0 fbsetbg -l

ERRORES

fbsetbg(1) no es infalible.
