FBSETROOT(1) Manual de Fluxbox FBSETROOT(1)

NOMBRE

fbsetroot - una utilidad simple para el fondo utilizada por el gestor de ventanas fluxbox(1), escrita originalmente para y por el gestor de ventanas original blackbox(1).

SINOPSIS

fbsetroot [-display display] -solid color

fbsetroot [-display display] -mod x y -fg color -bg color

fbsetroot [-display display] -gradient textura -from color -to color

fbsetroot -help

DESCRIPCIÓN

fbsetroot(1) es una utilidad que puede controlar la apariencia de la ventana raíz de tres maneras: dándole un color sólido, escribiendo un patrón modular de dos colores en ella, o renderizando una textura degradada, basada en dos colores diferentes.

fbsetroot se parece a xsetroot(1) en esta funcionalidad, pero soporta pantallas múltiples y texturas degradadas de la misma manera que lo hacen blackbox o fluxbox. No maneja cursores, etc. fbsetroot fue originalmente parte del paquete Blackbox y se transfirió con el código que se convirtió en Fluxbox. En aquel entonces se llamaba bsetroot.

Si se encuentran errores, fbsetroot utilizará gxmessage(1) o xmessage(1) para informar al usuario de los errores.

OPCIONES

fbsetroot opera de tres maneras, debes elegir una de las 3 primeras opciones:

-solid color

Establece la ventana raíz al color especificado.

-mod x y

Crea un patrón modular. Debes especificar colores -bg y -fg.

-gradient cadena_textura

Renderiza la cadena de textura especificada en la ventana raíz.

cadena_textura puede ser una de:

Horizontal / Vertical / Diagonal / Diagonal cruzada / Crucetar / Elíptica / Rectangular / Pirámide

Selecciona uno de estos tipos de textura, solo se aplican cuando se especifica -gradient. También debes especificar un color -from y un color -to.

-display display

Indica a fbsetroot que se conecte a la pantalla especificada.

-bg, -background color

Color de fondo. Necesario para los patrones -mod.

-fg, -foreground color

Color de primer plano. Necesario para los patrones -mod.

-from color

Color de inicio para renderizar texturas. Necesario para los patrones -gradient.

-to color

Color final para renderizar texturas. Necesario para los patrones -gradient.

-help

Imprime información de la versión y un texto de ayuda corto.
