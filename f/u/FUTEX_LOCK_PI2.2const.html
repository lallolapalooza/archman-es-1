FUTEX_LOCK_PI2(2const) FUTEX_LOCK_PI2(2const)

NOMBRE

FUTEX_LOCK_PI2 - bloquear un futex de herencia de prioridad

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/futex.h>  /* Definición de constantes FUTEX_* */
#include <sys/syscall.h>  /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_LOCK_PI2, 0,
             const struct timespec *timeout);

DESCRIPCIÓN

Esta operación es la misma que FUTEX_LOCK_PI(2const), excepto que el reloj contra el cual se mide el tiempo de espera timeout es seleccionable.

Por defecto, el tiempo de espera (absoluto) especificado en timeout se mide contra el reloj CLOCK_MONOTONIC.

VALOR DE RETORNO

Ver FUTEX_LOCK_PI(2const).

ERRORES

Ver FUTEX_LOCK_PI(2const).

ESTÁNDARES

Linux.

HISTORIA

Linux 5.14.

VER TAMBIÉN
