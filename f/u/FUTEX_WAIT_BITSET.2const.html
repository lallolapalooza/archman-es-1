DESCRIPCIÓ

N
FUTEX_WAIT_BIT
SET
Esta operación es como FUTEX_WAIT(2const) excepto que val3 se utiliza para proporcionar al kernel una máscara de bits de 32 bits. Esta máscara de bits, en la que al menos un bit debe estar establecido, se almacena en el estado interno del kernel del que espera. Consulte la descripción de FUTEX_WAKE_BITSET
para más
detalles.
Si timeout no es NULL, la estructura a la que apunta especifica un tiempo de espera absoluto para la operación de espera. Si timeout es NULL, la operación puede bloquearse
indefinidamente
.
FUTEX_WAKE_BIT
SET
Esta operación es la misma que FUTEX_WAKE(2const) excepto que el argumento val3 se utiliza para proporcionar al kernel una máscara de bits de 32 bits. Esta máscara de bits, en la que al menos un bit debe estar establecido, se utiliza para seleccionar qué procesos en espera deben despertarse. La selección se realiza mediante un AND bit a bit entre la máscara de bits de "despertar" (es decir, el valor en val3) y la máscara de bits almacenada en el estado interno del kernel del que espera (la máscara de bits de "espera" que se establece mediante FUTEX_WAIT_BITSET). Todos los que esperan para los que el resultado del AND es
distinto de cero se despiertan; los q
ue esperan restantes permanecen durmiendo.
El efecto de FUTEX_WAIT_BITSET y FUTEX_WAKE_BITSET es permitir despertares selectivos entre múltiples procesos en espera que están bloqueados en el mismo futex. Sin embargo, tenga en cuenta que, dependiendo del caso de uso, emplear esta característica de multiplexación de máscaras de bits en un futex puede ser menos eficiente que simplemente usar múltiples futexes, porque emplear la multiplexación de máscaras de bits requiere que el kernel verifique todos los procesos en espera en un futex, incluidos aquellos que no están interesados en ser despertados (es decir, no tienen el bit relevante establecido en su máscara de bits de "espera")
.
La constante FUTEX_BITSET_MATCH_ANY, que corresponde a los 32 bits establecidos en la máscara de bits, se puede usar como el argumento val3 para FUTEX_WAIT_BITSET y FUTEX_WAKE_BITSET. Aparte de las diferencias en el manejo del argumento timeout, la operación FUTEX_WAIT(2const) es equivalente a FUTEX_WAIT_BITSET con val3 especificado como FUTEX_BITSET_MATCH_ANY; es decir, permitir un despertar por cualquier despertador. La operación FUTEX_WAKE(2const) es equivalente a FUTEX_WAKE_BITSET con val3 especificado como FUTEX_BITSET_MATCH_ANY; es deci
r, despertar a
cualquier proces
o(s) en espera.
