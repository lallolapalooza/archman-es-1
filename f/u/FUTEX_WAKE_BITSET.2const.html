FUTEX_WAIT_BITSET(2const) FUTEX_WAIT_BITSET(2const)

NOMBRE

FUTEX_WAIT_BITSET, FUTEX_WAKE_BITSET - espera y activación selectiva de futex

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/futex.h>  /* Definición de constantes FUTEX_* */
#include <sys/syscall.h>  /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_WAIT_BITSET, uint32_t val,
             const struct timespec *timeout, NULL,
             uint32_t val3);
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_WAKE_BITSET, uint32_t val,
             NULL, NULL,
             uint32_t val3);

DESCRIPCIÓN

FUTEX_WAIT_BITSET
Esta operación es como FUTEX_WAIT(2const) excepto que val3 se utiliza para proporcionar una máscara de bits de 32 bits al kernel. Esta máscara de bits, en la que al menos un bit debe estar establecido, se almacena en el estado interno del kernel del que espera. Vea la descripción de FUTEX_WAKE_BITSET para más detalles.
Si timeout no es NULL, la estructura a la que apunta especifica un tiempo de espera absoluto para la operación de espera. Si timeout es NULL, la operación puede bloquearse indefinidamente.
FUTEX_WAKE_BITSET
Esta operación es la misma que FUTEX_WAKE(2const) excepto que el argumento val3 se utiliza para proporcionar una máscara de bits de 32 bits al kernel. Esta máscara de bits, en la que al menos un bit debe estar establecido, se utiliza para seleccionar qué esperadores deben ser despertados. La selección se realiza mediante un AND bit a bit de la máscara de bits de "wake" (es decir, el valor en val3) y la máscara de bits que se almacena en el estado interno del kernel del que espera (la máscara de bits de "wait" que se establece usando FUTEX_WAIT_BITSET). Todos los que esperan para los cuales el resultado del AND es distinto de cero se despiertan; los que quedan dormidos siguen durmiendo.
El efecto de FUTEX_WAIT_BITSET y FUTEX_WAKE_BITSET es permitir despertares selectivos entre múltiples esperadores que están bloqueados en el mismo futex. Sin embargo, tenga en cuenta que, dependiendo del caso de uso, emplear esta característica de multiplexación de máscara de bits en un futex puede ser menos eficiente que simplemente usar múltiples futexes, porque emplear la multiplexación de máscara de bits requiere que el kernel compruebe a todos los que esperan en un futex, incluidos aquellos que no están interesados en ser despertados (es decir, no tienen el bit relevante establecido en su máscara de bits de "wait").
La constante FUTEX_BITSET_MATCH_ANY, que corresponde a todos los 32 bits establecidos en la máscara de bits, se puede usar como argumento val3 para FUTEX_WAIT_BITSET y FUTEX_WAKE_BITSET. Aparte de las diferencias en el manejo del argumento timeout, la operación FUTEX_WAIT(2const) es equivalente a FUTEX_WAIT_BITSET con val3 especificado como FUTEX_BITSET_MATCH_ANY; es decir, permite un despertar de cualquier despertador. La operación FUTEX_WAKE(2const) es equivalente a FUTEX_WAKE_BITSET con val3 especificado como FUTEX_BITSET_MATCH_ANY; es decir, despierta a cualquier(os) esperador(es).

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

El valor de retorno en caso de éxito depende de la operación, como se describe en la siguiente lista:

FUTEX_WAIT_BITSET
Devuelve 0 si el llamador fue despertado. Vea FUTEX_WAIT(2const) sobre cómo interpretar esto correctamente en la práctica.
FUTEX_WAKE_BITSET
Devuelve el número de esperadores que fueron despertados.

ERRORES

Vea futex(2).

EAGAIN
(FUTEX_WAIT_BITSET) El valor apuntado por uaddr no fue igual al valor esperado val en el momento de la llamada.
Nota: en Linux, los nombres simbólicos EAGAIN y EWOULDBLOCK (ambos aparecen en diferentes partes del código futex del kernel) tienen el mismo valor.
EFAULT
timeout no apuntaba a una dirección válida en el espacio de usuario.
EINTR
Una operación FUTEX_WAIT_BITSET fue interrumpida por una señal (vea signal(7)). Antes de Linux 2.6.22, este error también podía devolverse por un despertar espurio; desde Linux 2.6.22, esto ya no ocurre.
EINVAL
El argumento timeout proporcionado no era válido (tv_sec era menor que cero, o tv_nsec no era menor que 1,000,000,000).
EINVAL
uaddr2 no apunta a un objeto válido, es decir, la dirección no está alineada a cuatro bytes.
EINVAL
La máscara de bits proporcionada en val3 es cero.
EINVAL
(FUTEX_WAKE_BITSET) El kernel detectó una inconsistencia entre el estado del espacio de usuario en uaddr y el estado del kernel, es decir, detectó un esperador que espera en FUTEX_LOCK_PI(2const) o FUTEX_LOCK_PI2(2const) en uaddr.
ETIMEDOUT
El tiempo de espera expiró antes de que se completara la operación.
