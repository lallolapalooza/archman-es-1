DESCRIPCIÓ

N

Esta operación se añadió para soportar algunos casos de uso en el espacio de usuario donde se debe manejar más de un futex al mismo tiempo. El ejemplo más notable es la implementación de pthread_cond_signal(3), que requiere operaciones en dos futexes, el que se usa para implementar el mutex y el que se usa en la implementación de la cola de espera asociada a la variable de condición. FUTEX_WAKE_OP permite implementar tales casos sin llevar a altas tasas de contención y cambio de

contexto.

La operación FUTEX_WAKE_OP es equivalente a ejecutar el siguiente código de forma atómica y totalmente ordenada con respecto a otras operaciones futex en cualquiera de las dos palabras futex

proporcionadas: 


uint32_t oldval = *(uint32_t *) uaddr2;
*(uint32_t *) uaddr2 = oldval op oparg;
futex(uaddr, FUTEX_WAKE, val, 0, 0, 0);
if (oldval cmp cmparg)
    futex(uaddr2, FUTEX_WAKE, val2, 0, 0, 0)
;

En otras palabras, FUTEX_WAKE_OP hace lo

siguiente:
•
guarda el valor original de la palabra futex en uaddr2 y realiza una operación para modificar el valor del futex en uaddr2; este es un acceso de memoria atómico de lectura-modificación-escritura (es decir, usando instrucciones atómicas de la arquitectura
respectiva)
•
despierta un máximo de val esperadores en el futex para la palabra futex en uaddr
; y
•
dependiendo de los resultados de una prueba del valor original de la palabra futex en uaddr2, despierta un máximo de val2 esperadores en el futex para la palabra
futex en
uaddr2.

La operación y la comparación que se deben realizar están codificadas en los bits del argumento val3. Pictóricamente, la codificación

es: 


+---+---+-----------+-----------+
|op |cmp|   oparg   |  cmparg   |
+---+---+-----------+-----------+
  4   4       12          12    <== # de
bits

Expresado en código, la codificación

es: 


#define FUTEX_OP(op, oparg, cmp, cmparg) \
                (((op & 0xf) << 28) | \
                ((cmp & 0xf) << 24) | \
                ((oparg & 0xfff) << 12) | \
                (cmparg & 0xfff)
)

En lo anterior, op y cmp son cada uno de los códigos listados a continuación. Los componentes oparg y cmparg son valores numéricos literales, excepto como se indica a

continuación.

El componente op tiene uno de los siguientes

valores:

Además, hacer OR bit a bit del siguiente valor en op hace que (1 << oparg) se use como el

operando: 


FUTEX_OP_ARG_SHIFT  8  /* Usar (1 << oparg) como operando
*/

El campo cmp es uno de los

siguientes: 


FUTEX_OP_CMP_EQ     0  /* si (oldval == cmparg) despertar */
FUTEX_OP_CMP_NE     1  /* si (oldval != cmparg) despertar */
FUTEX_OP_CMP_LT     2  /* si (oldval < cmparg) despertar */
FUTEX_OP_CMP_LE     3  /* si (oldval <= cmparg) despertar */
FUTEX_OP_CMP_GT     4  /* si (oldval > cmparg) despertar */
FUTEX_OP_CMP_GE     5  /* si (oldval >= cmparg) despertar
*/

El valor de retorno de FUTEX_WAKE_OP es la suma del número de esperadores despertados en el futex uaddr más el número de esperadores despertados en el futex uadd
