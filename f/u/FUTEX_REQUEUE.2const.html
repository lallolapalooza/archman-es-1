FUTEX_REQUEUE(2const) FUTEX_REQUEUE(2const)

NOMBRE

FUTEX_REQUEUE - despertar a algunos esperadores y reenviar a otros

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/futex.h>  /* Definición de las constantes FUTEX_* */
#include <sys/syscall.h>  /* Definición de las constantes SYS_* */
#include <unistd.h>
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_REQUEUE,
             uint32_t val, uint32_t val2, uint32_t *uaddr2);

DESCRIPCIÓN

Esta operación realiza la misma tarea que FUTEX_CMP_REQUEUE(2const), excepto que la palabra futex no se compara.

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

En caso de éxito, FUTEX_REQUEUE devuelve el número de esperadores que fueron despertados.

ERRORES

Véase futex(2).

EFAULT
uaddr2 no apuntaba a una dirección válida del espacio de usuario.
EINVAL
uaddr2 no apunta a un objeto válido; es decir, la dirección no está alineada a cuatro bytes.
EINVAL
El kernel detectó una inconsistencia entre el estado del espacio de usuario en uaddr y el estado del kernel; es decir, detectó un esperador que espera en FUTEX_LOCK_PI(2const) o FUTEX_LOCK_PI2(2const) en uaddr.

ESTNDARES

Linux.

HISTORIA

Linux 2.6.0.
