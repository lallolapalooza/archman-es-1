FUTEX_UNLOCK_PI(2const) FUTEX_UNLOCK_PI(2const)

NOMBRE

FUTEX_UNLOCK_PI - desbloquear un futex de herencia de prioridad

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/futex.h>  /* Definición de constantes FUTEX_* */
#include <sys/syscall.h>  /* Definición de constantes SYS_* */
#include <unistd.h>
long syscall(SYS_futex, uint32_t *uaddr, FUTEX_UNLOCK_PI);

DESCRIPCIÓN

Esta operación despierta al esperador de mayor prioridad que está esperando en FUTEX_LOCK_PI(2const) o FUTEX_LOCK_PI2(2const) en la dirección futex proporcionada por el argumento uaddr.

Esto se llama cuando el valor en espacio de usuario en uaddr no puede cambiarse atómicamente de un TID (del propietario) a 0.

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

En caso de éxito, FUTEX_UNLOCK_PI devuelve 0 si el futex se desbloqueó correctamente.

ERRORES

Ver futex(2).

EINVAL
El kernel detectó una inconsistencia entre el estado del espacio de usuario en uaddr y el estado del kernel. Esto indica corrupción del estado o que el kernel encontró un esperador en uaddr que está esperando a través de FUTEX_WAIT(2const) o FUTEX_WAIT_BITSET(2const).
ENOSYS
Una comprobación en tiempo de ejecución determinó que la operación no está disponible. Las operaciones PI-futex no están implementadas en todas las arquitecturas y no son compatibles con algunas variantes de CPU.
EPERM
El llamador no posee el bloqueo representado por la palabra futex.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.18.
