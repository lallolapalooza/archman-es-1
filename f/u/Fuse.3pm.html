DESCRIPCIÓ

N

Esto le permite implementar sistemas de archivos en perl, a través de la interfaz del kernel/biblioteca de FUSE (Filesystem in USErspace)

.

FUSE espera que implemente funciones de retorno para las distintas

funciones.

En las siguientes definiciones, "errno" puede ser 0 (para un éxito), -EINVAL, -ENOENT, -EONFIRE, cualquier entero menor que 1 en

realidad.

Puede importar constantes de error estándar diciendo algo como "use POSIX qw(EDOTDOT ENOANO);

".

Cada constante que necesite (tipos de archivo, flags de open(), valores de error, etc) puede importarse tanto desde POSIX como desde Fcntl, a menudo desde ambos. Consulte sus respectivas documentaciones para más

información.

Fuse::

main

Toma argumentos en forma de pares clave=>valor de hash. Hay muchas claves válidas. La mayoría de ellas corresponden con nombres de funciones de retorno, como se describe en la sección 'FUNCIONES QUE SU SISTEMA DE ARCHIVOS PUEDE IMPLEMENTAR'. También existen algunas claves

especiales:
debug =>
booleano
Esto activa y desactiva el rastreo de llamadas de FUSE. El valor predeterminado es 0 (lo que significa desactivado)
.
mountpoint =>
cadena
El punto en el que montar este sistema de archivos. No hay valor predeterminado, debe especificarlo. Un ejemplo sería
'/mnt'.
mountopts =>
cadena
Esta es una lista separada por comas de opciones de montaje para pasar al módulo del kernel de FUSE.

Actualmente, permite la especificación del argumento allow_other al montar el nuevo sistema de archivos FUSE. Para usar esto, también necesitará 'user_allow_other' en /etc/fuse.conf según la documentación

de FUSE 
mountopts => "allow_other" o
mountopts
=>
""
threaded =>
booleano
Esto activa y desactiva el multihilo de FUSE. El valor predeterminado es 0, lo que significa que su script de FUSE se ejecutará en modo de un solo hilo. Tenga en cuenta que el modo de un solo hilo también significa que no tendrá que preocuparse por la reentrancia, aunque tendrá que preocuparse por las búsquedas recursivas. En modo de un solo hilo, FUSE mantiene un bloqueo global en su sistema de archivos, y esperará a que una función de retorno regrese antes de llamar a otra. Esto puede llevar a bloqueos mutuos, si su script hace algún intento de acceder a archivos o directorios en el sistema de archivos que está proporcionando. (Esto incluye llamar a stat() en el punto de montaje, llamadas a statfs() del comando 'df', y así sucesivamente.) Vale la pena prestar un poco de atención y tener cuidado con esto.

Habilitar el multihilo hará que FUSE haga múltiples llamadas simultáneas a las distintas funciones de retorno de su script de perl. Si habilita el modo con hilos, puede disfrutar de todos los beneficios de ejecución paralela y respuesta interactiva de los hilos, y también puede disfrutar de todos los beneficios de las condiciones de carrera y errores de bloqueo. Asegúrese también de que cualquier otro módulo de perl que esté usando también sea seguro para

hilos.

(Si está habilitada, esta opción causará una advertencia si su intérprete de perl no fue compilado con USE_ITHREADS, o si ha fallado en usar threads o threads::

shared.
)
nullpath_ok =>
booleano
Esta bandera le indica a Fuse que no pase rutas para funciones que operan en identificadores de archivo o directorio. Esto producirá parámetros de ruta vacíos para funciones que incluyen read, write, flush, release, fsync, readdir, releasedir, fsyncdir, truncate, fgetattr y lock. Si usa esto, debe devolver identificadores de archivo/directorio desde open, opendir y create. El valor predeterminado es 0 (desactivado). Solo es efectivo en Fuse 2.8 y superior; con versiones anteriores, esto no hace
nada.
utimens_as_array =>
booleano
Esta bandera hace que las marcas de tiempo pasadas a través de la llamada a utimens() se pasen como matrices que contienen el tiempo en segundos, y un segundo valor que contiene el número de nanosegundos, en lugar de un valor de punto flotante. Esto permite tiempos más precisos, ya que el tipo de punto flotante normal usado por Perl (double) pierde precisión a partir de aproximadamente décimas de un
microsegundo.
nopath =>
booleano
Bandera que indica que la ruta no necesita ser calculada para las siguientes operaciones:

read, write, flush, release, fsync, readdir, releasedir, fsyncdir, ftruncate, fgetattr, lock, ioctl

y poll

Estrechamente relacionada con nullpath_ok, pero si esta bandera está establecida entonces la ruta no se calculará incluso si el archivo no fue desvinculado. Sin embargo, la ruta todavía puede definirse si necesita ser calculada por alguna otra

razón.

Solo es efect

ivo en Fuse 2.
9 y superior.
utime_omit_ok =>
booleano
Bandera que indica que el sistema de archivos acepta los valores especiales UTIME_NOW y UTIME_OMIT en su operación "utimens".

Si desea usar estas constantes, asegúrese de incluir la bandera ':utime' al incluir el módulo Fuse, o la bandera ':

all'.

Solo es ef

ectivo en
Fuse 2.9 y
superior.

Fuse::

fuse_version

Indica la versión de Fuse en uso; con más precisión, indica la versión de la API de Fuse en uso en el momento de la compilación. Si se llama en contexto escalar, la versión se devolverá como un valor decimal; es decir, para la API de Fuse v2.6, devolverá "2.6". Si se llama en contexto de matriz, se devolverá una matriz, que contiene los números de versión mayor, menor y micro de la API de Fuse contra la que fue

compilada.

Fuse::

fuse_buf_size

Calcula el tamaño total de un vector de búfer. Aplicable para las operaciones "read_buf" y "write_buf"

.

Fuse::

fuse_buf_copy

Copia datos de un vector de búfer a otro. Principalmente útil si un vector de búfer contiene múltiples fragmentos o si contiene un búfer de FD en lugar de un búfer de memoria. Aplicable para "write_buf"

.

Fuse::

notify_poll

Solo disponible si el módulo Fuse está compilado contra libfuse 2.8 o posterior. Use fuse_version() para determinar si ese es el caso. Llamar a esta función con un argumento pollhandle (como se proporciona a la implementación de la operación "poll") enviará una notificación al llamador que está haciendo poll() de la disponibilidad de operaciones de E/S. Si se proporciona más de un pollhandle para el mismo identificador de archivo, use solo el más reciente; usted *puede* enviar notificaciones a todos, pero es innecesario y disminuye el

rendimiento.

Proporcione ÚNICAMENTE manejadores de poll que le hayan sido entregados a través de "poll" a esta función. Debido a los requisitos de seguridad de hilos, actualmente no podemos empaquetar el puntero en un objeto de la manera que nos gustaría para evitar esta situación, pero su programa servidor de sistema de archivos puede fallar con segmentación, o peor, si le da cosas a esta función que no debería recibir. Si lo hace de todos modos, no nos hacemos responsables de lo que sea que pueda

suceder.

Fuse::pollhandle_destro

y

Solo disponible si el módulo Fuse está compilado contra libfuse 2.8 o posterior. Use fuse_version() para determinar si ese es el caso. Esta función destruye un manejador de poll (entregado a su programa a través de "poll"). Cuando haya terminado con un manejador de poll, ya sea porque ha sido reemplazado, o porque una notifification has been sent to it, pass it to this function to dispose of it

safely.

ONLY supply poll handles fed to you through "poll" to this function. Due to thread safety requirements, we can't currently package the pointer up in an object the way we'd like to to prevent this situation, but your filesystem server

program may segfault, or worse, if you feed things to this function which it is not supposed
to receive. If you do anyway, we take no responsibility for whatever Bad Things(tm) may happen.

Un sistema de archivos de dispositivo de loopback. Al igual que fusexmp de la
    distribución principal de FUSE, simplemente recurre las operaciones de
    archivos al sistema de archivos real. A diferencia de fusexmp, solo
    vuelve a compartir los archivos bajo el directorio
/tmp/test.

rmount.

pl 
Un equivalente a NFS que se conecta a través de SSH. Requiere una cuenta
    en algún servidor ssh (obviamente), con autenticación por clave pública
    habilitada. (Si tiene que escribir una contraseña, no la tiene. man ssh_keygen.).
    Copie rmount_remote.pl a su directorio de inicio en la máquina remota
    y hágalo ejecutable. Luego cree un subdirectorio de punto de montaje en
    algún lugar local y ejecute el script de ejemplo: ./rmount.pl host /remote/dir
/local/dir
