FS_IOC_SETFSLABEL(2const) FS_IOC_SETFSLABEL(2const)

NOMBRE

FS_IOC_GETFSLABEL, FS_IOC_SETFSLABEL - obtener o establecer la etiqueta de un sistema de archivos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/fs.h>  /* Definición de las constantes *FSLABEL* */
#include <sys/ioctl.h>
int ioctl(int fd, FS_IOC_GETFSLABEL, char label[FSLABEL_MAX]);
int ioctl(int fd, FS_IOC_SETFSLABEL, char label[FSLABEL_MAX]);

DESCRIPCIÓN

Si un sistema de archivos soporta la manipulación de etiquetas en línea, estas operaciones ioctl(2) se pueden usar para obtener o establecer la etiqueta del sistema de archivos en el que reside fd. La operación FS_IOC_SETFSLABEL requiere privilegios (CAP_SYS_ADMIN).

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Los posibles errores incluyen (pero no se limitan a) los siguientes:

EFAULT
label hace referencia a una zona de memoria inaccesible.
EINVAL
La etiqueta especificada excede la longitud máxima de etiqueta para el sistema de archivos.
ENOTTY
Esto puede aparecer si el sistema de archivos no soporta la manipulación de etiquetas en línea.
EPERM
El proceso llamante no tiene suficientes permisos para establecer la etiqueta.

ESTÁNDARES

Linux.

HISTORIA

Linux 4.18.

Anteriormente se conocían como BTRFS_IOC_GET_FSLABEL y BTRFS_IOC_SET_FSLABEL y eran privadas de Btrfs.

NOTAS

La longitud máxima de cadena para esta interfaz es FSLABEL_MAX, incluido el byte nulo de terminación ('\0'). Los sistemas de archivos tienen diferentes longitudes máximas de etiqueta, que pueden o no incluir el nulo de terminación. La cadena proporcionada a FS_IOC_SETFSLABEL siempre debe terminar en nulo, y la cadena devuelta por FS_IOC_GETFSLABEL siempre terminará en nulo.

VER TAMBIÉN

ioctl(2), blkid(8)
