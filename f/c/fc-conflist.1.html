NOMBRE

fc-conflist - lista los archivos de configuración procesados por Fontconfig

SINOPSIS

fc-conflist [ -Vh ]
[ --version ] [ --help ]

DESCRIPCIÓN

fc-conflist imprime una lista anotada de todos los archivos de configuración procesados por Fontconfig.

La salida es un `-' o `+' dependiendo de si el archivo es ignorado o procesado, un espacio, la ruta del archivo, dos puntos y un espacio, y la descripción del archivo o `Sin descripción' si no hay ninguna presente.

El orden de los archivos se parece a cómo fontconfig los procesa realmente, excepto que uno contiene un elemento <include>. En ese caso, se mostrará después de procesar todos los subdirectorios a los que se dirige <include>.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-V --version
Muestra la versión del programa y sale.
-h --help
Muestra un resumen de las opciones.

CÓDIGOS DE RETORNO

fc-conflist devuelve el código de error 0 si el análisis fue exitoso, o 1 si ocurrió algún error o si al menos una cara de fuente no pudo ser abierta.
