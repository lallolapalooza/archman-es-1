#include <fontconfig/fontconfig.

h>

FcChar8 * FcPatternFormat (FcPattern *pat, const FcChar8 *format);

DESCRIPCIÓ

N

Convierte el patrón dado pat en texto descrito por el especificador de formato format. El valor de retorno se refiere a memoria recién asignada que debe ser liberada por el llamante usando free(), o NULL si format no es

válido.

El formato está libremente modelado después de la cadena de formato estilo printf. La cadena de formato está compuesta por cero o más directivas: caracteres ordinarios (no "%"), que se copian sin cambios al flujo de salida; y etiquetas que se interpretan para construir texto a partir del patrón de diversas maneras (explicado más abajo). Los caracteres especiales se pueden escapar usando la barra invertida. También se admiten caracteres especiales de estilo cadena C como \n y \r (esto es útil cuando la cadena de formato no es un literal de cadena C). Es aconsejable escapar siempre las llaves que se pretenden copiar a la salida como caracteres

ordinarios.

Cada etiqueta es introducida por el carácter "%", seguido de un ancho de campo mínimo opcional, seguido del contenido de la etiqueta entre llaves ({}). Si se proporciona el valor del ancho de campo mínimo, la etiqueta se expandirá y el resultado se rellenará para alcanzar el ancho mínimo. Si el ancho de campo mínimo es positivo, el relleno alineará el texto a la derecha. Un ancho de campo negativo lo alineará a la izquierda. El resto de esta sección describe varios contenidos de etiquetas soportados y su

expansión.

Una etiqueta simple es aquella cuyo contenido es un identificador. Cuando se expanden las etiquetas simples, el identificador nombrado se buscará en patrón y se devolverá la lista resultante de valores, unidos con comas. Por ejemplo, para imprimir el nombre de la familia y el estilo del patrón, use el formato "%{family} %{style}\n". Para extender la columna de la familia a cuarenta caracteres use "%-40{family}%{style}

\n".

Las etiquetas simples se expanden a la lista de todos los valores de un elemento. Para elegir solo uno de los valores, se puede indexar usando la sintaxis "%{elt[idx]}". Por ejemplo, para obtener solo el primer nombre de familia, use "%{family[0]}

".

Si una etiqueta simple termina con "=" y el elemento se encuentra en el patrón, el nombre del elemento seguido de "=" se emitirá antes de la lista de valores. Por ejemplo, "%{weight=}" puede expandirse a la cadena "weight=80". O a la cadena vacía si patrón no tiene el peso

establecido.

Si una etiqueta simple comienza con ":" y el elemento se encuentra en el patrón, ":" se imprimirá primero. Por ejemplo, combinando esto con el =, el formato "%{:weight=}" puede expandirse a ":weight=80" o a la cadena vacía si patrón no tiene el peso

establecido.

Si una etiqueta simple contiene la cadena ":-", el resto del contenido de la etiqueta se usará como cadena predeterminada. La cadena predeterminada se emite si el elemento no se encuentra en el patrón. Por ejemplo, el formato "%{:weight=:-123}" puede expandirse a ":weight=80" o a la cadena ":weight=123" si patrón no tiene el peso

establecido.

Una etiqueta de conteo es aquella que comienza con el carácter "#" seguido de un nombre de elemento, y se expande al número de valores del elemento en el patrón. Por ejemplo, "%{#family}" se expande al número de nombres de familia que patrón tiene establecidos, que puede ser

cero.

Una etiqueta de subexpresión es aquella que expande una subexpresión. El contenido de la etiqueta es la subexpresión a expander colocada dentro de otro juego de llaves. Las etiquetas de subexpresión son útiles para alinear una subexpresión completa, o para aplicar convertidores (explicados más tarde) a toda la salida de la subexpresión. Por ejemplo, el formato "%40{{%{family} %{style}}}" expande la subexpresión para construir el nombre de la familia seguido del estilo, luego toma la cadena completa y la rellena a la izquierda para que tenga al menos cuarenta

caracteres.

Una etiqueta de filtro-out es aquella que comienza con el carácter "-" seguido de una lista de nombres de elementos separados por comas, seguida de una subexpresión encerrada en llaves. La subexpresión se expandirá pero con un patrón que tenga los elementos listados eliminados de él. Por ejemplo, el formato "%{-size,pixelsize{sub-expr}}" expandirá "sub-expr" con patrón sin los elementos size y

pixelsize.

Una etiqueta de filtro-in es aquella que comienza con el carácter "+" seguido de una lista de nombres de elementos separados por comas, seguida de una subexpresión encerrada en llaves. La subexpresión se expandirá pero con un patrón que solo tiene los elementos listados del patrón circundante. Por ejemplo, el formato "%{+family,familylang{sub-expr}}" expandirá "sub-expr" con un subpatrón que consiste solo en los elementos family y familylang de patrón

.

Una etiqueta condicional es aquella que comienza con el carácter "?" seguido de una lista de condiciones de elementos separadas por comas, seguida de dos subexpresiones encerradas en llaves. Una condición de elemento puede ser un nombre de elemento, en cuyo caso prueba si el elemento está definido en el patrón, o el carácter "!" seguido de un nombre de elemento, en cuyo caso la prueba se niega. La condicional pasa si todas las condiciones de elementos pasan. La etiqueta expande la primera subexpresión si la condicional pasa, y expande la segunda subexpresión de lo contrario. Por ejemplo, el formato "%{?size,dpi,!pixelsize{pass}{fail}}" se expandirá a "pass" si patrón tiene los elementos size y dpi pero no el elemento pixelsize, y a "fail" de lo

contrario.

Una etiqueta de enumeración es aquella que comienza con la cadena "[]" seguida de una lista de nombres de elementos separados por comas, seguida de una subexpresión encerrada en llaves. La lista de valores de los elementos nombrados se recorre en paralelo y la subexpresión se expande cada vez con un patrón que tiene solo un valor para esos elementos, comenzando desde el primer valor y continuando mientras cualquiera de esos elementos tenga un valor. Por ejemplo, el formato "%{[]family,familylang{%{family} (%{familylang})\n}}" expandirá el patrón "%{family} (%{familylang})\n" con un patrón que tiene solo el primer valor de los elementos family y familylang, luego lo expandirá con los segundos valores, luego con los terceros,

etc.

Como caso especial, si una etiqueta de enumeración tiene solo un elemento, y ese elemento tiene solo un valor en el patrón, y ese valor es de tipo FcLangSet, se enumeran los idiomas individuales en el conjunto de

idiomas.
