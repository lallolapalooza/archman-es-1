FCGI::Client::RecordHeader(3pm) Documentación de Perl aportada por el usuario FCGI::Client::RecordHeader(3pm)

NOMBRE

FCGI::Client::RecordHeader - objeto de encabezado de registro para FCGI

SINOPSIS

my $header = FCGI::Client::RecordHeader->new(raw => $raw);
say $header->type;

DESCRIPCIÓN

Este módulo es la clase de encabezado de registro para FCGI::Client.

ATRIBUTOS

raw
la cadena cruda del encabezado del registro. El tamaño del encabezado del registro se define en FCGI::Client::Constant::FCGI_HEADER_LEN.

MÉTODO DE INSTANCIA

$self->request_id()
$self->type()
$self->content_length()
$self->padding_length()
Estos métodos devuelven cada campo del encabezado del registro.
