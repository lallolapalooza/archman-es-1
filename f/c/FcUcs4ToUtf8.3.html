NOMBRE

FcUcs4ToUtf8 - convertir UCS4 a UTF-8

SINOPSIS

#include <fontconfig/fontconfig.h>

int FcUcs4ToUtf8 (FcChar32 src, FcChar8 dst[FC_UTF8_MAX_LEN]);

DESCRIPCIÓN

Convierte el carácter Unicode de src a dst y devuelve el número de bytes necesarios para codificar el carácter.
