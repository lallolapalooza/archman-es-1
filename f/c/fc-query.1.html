NOMBRE

fc-query - consultar archivos de fuentes

SINOPSIS

fc-query [ -Vh ]
[ -b | --ignore-blanks ] [ -i índice | --index índice ] [ -f formato | --format formato ] [ --version ] [ --help ] archivo-fuente ...

DESCRIPCIÓN

fc-query consulta los archivo-fuente(s) utilizando las reglas normales de fontconfig e imprime el patrón de fuente para cada cara encontrada. Si se proporciona --index, solo se consulta una cara de cada archivo, de lo contrario, se consultan todas las caras.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-b --ignore-blanks
Ignorar espacios en blanco para calcular idiomas
-i --index índice
Solo consultar la cara con el índice índice de cada archivo.
-f --format formato
Formatear la salida según el especificador de formato formato.
-V --version
Mostrar la versión del programa y salir.
-h --help
Mostrar resumen de opciones.
archivo-fuente
Consultar archivo-fuente para caras de fuentes.

CÓDIGOS DE RETORNO

fc-query devuelve el código de error 0 para un análisis exitoso, o 1 si ocurrió algún error o si al menos una cara de fuente no se pudo abrir.
