NOMBRE

fcitx - Free Chinese Input Toy of X - un IME chino para XIM

SINOPSIS

fcitx [OPCIÓN]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando fcitx.

fcitx es un IME chino para XIM diseñado intencionalmente para no depender de ningún Entorno de Escritorio. Incluye Pinyin y Tabla por defecto, pero también puede soportar otros Métodos de Entrada.

OPCIONES

-r
reemplazar fcitx existente
-d
ejecutar como demonio (por defecto)
-D
no ejecutar como demonio
-s[tiempo de espera]
ignorar el tiempo de inicio retardado en el archivo de configuración, 0 para inicio inmediato
-u, --ui[nombre de ui]
forzar el uso de la interfaz de usuario especificada
--enable[complemento A,complemento B]
especificar una lista separada por comas de complementos que anularán la opción de habilitar
--disable[complemento A,complemento B]
especificar una lista separada por comas de complementos que serán explícitamente deshabilitados, la prioridad es mayor que --enable
-v
mostrar la información de la versión y salir
-h
mostrar ayuda y salir

ENTORNO

XMODIFIERS
Si $XMODIFIERS está establecido, fcitx se ejecutará con el nombre especificado en $XMODIFIERS, de lo contrario se ejecutará con el nombre de im fcitx.

VER TAMBIÉN

Por favor, consulte la página principal en https://fcitx-im.org/
