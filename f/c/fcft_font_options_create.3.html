fcft_font_options_create(3) fcft fcft_font_options_create(3)

NOMBRE

fcft_font_options_create - instanciar una nueva fuente

SINOPSIS

#include <fcft/fcft.h>

struct fcft_font_options *fcft_font_options_create(void);

DESCRIPCIÓN

fcft_font_options_create() asigna un objeto struct fcft_font_options para ser usado con fcft_from_name2(3).

El objeto devuelto se inicializará con valores predeterminados. Modifique manualmente los miembros de la estructura para anularlos.

Nota: debe usar fcft_font_options_create() para asignar el objeto options; no lo asigne usted mismo, ni desde el montón ni en la pila. Esto es para asegurar la compatibilidad futura.

struct fcft_font_options {
    enum fcft_scaling_filter scaling_filter;
    enum fcft_emoji_presentation emoji_presentation;
    struct {
        bool srgb_decode;
        pixman_format_code_t format;
    } color_glyphs;
};

FILTRO DE ESCALADO

Configura el filtro a utilizar al reducir el tamaño de las fuentes bitmap (típicamente fuentes emoji).

Los valores posibles son:

  • FCFT_SCALING_FILTER_NONE
  • FCFT_SCALING_FILTER_NEAREST
  • FCFT_SCALING_FILTER_BILINEAR
  • FCFT_SCALING_FILTER_IMPULSE
  • FCFT_SCALING_FILTER_BOX
  • FCFT_SCALING_FILTER_LINEAR
  • FCFT_SCALING_FILTER_CUBIC
  • FCFT_SCALING_FILTER_GAUSSIAN
  • FCFT_SCALING_FILTER_LANCZOS2
  • FCFT_SCALING_FILTER_LANCZOS3
  • FCFT_SCALING_FILTER_LANCZOS3_STRETCHED

FCFT_SCALING_FILTER_NONE deshabilita el filtrado.

FCFT_SCALING_FILTER_NEAREST y FCFT_SCALING_FILTER_BILINEAR son filtros tradicionales, siendo nearest el más rápido.

El resto son filtros de convolución separable.

El valor predeterminado es FCFT_SCALING_FILTER_CUBIC.

PRESENTACIÓN DE EMOJIS

emoji_presentation configura el estilo de presentación predeterminado a utilizar con emojis que tienen tanto una presentación de texto como un estilo de presentación emoji.

Estos emojis pueden ir seguidos de un selector de variación (invisible). Cuando no van seguidos de un selector, la implementación debe elegir un estilo.

Un ejemplo de dicho emoji es U+263A - CARA SONRIENTE BLANCA:

  • no cualificado: ☺
  • texto: ☺
  • emoji: ☺️

El estándar Unicode define los estilos de presentación predeterminados, y esto es a lo que fcft se ajusta por defecto.

Sin embargo, en algunos casos, la aplicación puede querer usar siempre el estilo de texto o el estilo emoji.

Para esto sirve emoji_presentation. Los valores posibles son:

  • FCFT_EMOJI_PRESENTATION_DEFAULT
  • FCFT_EMOJI_PRESENTATION_TEXT
  • FCFT_EMOJI_PRESENTATION_EMOJI

Para reiterar; esta configuración afecta a los emojis sin un selector de variación explícito. En otras palabras, anula el estilo de presentación predeterminado.

FCFT_EMOJI_PRESENTATION_DEFAULT es el valor predeterminado y hace que fcft utilice la presentación predeterminada según lo definido por Unicode.

FCFT_EMOJI_PRESENTATION_TEXT fuerza a que todos los emojis con estilo de presentación múltiple se representen en su estilo de presentación de texto.

FCFT_EMOJI_PRESENTATION_EMOJI fuerza a que todos los emojis con estilo de presentación múltiple se representen en su estilo de presentación emoji.

GLIFOS DE COLOR

srgb_decode: cuando es verdadero, los datos de píxeles se decodificarán de sRGB a espacio lineal. Cuando es falso (el valor predeterminado), los datos de píxeles se utilizan tal cual.

format define el formato de superficie pixman a utilizar para los glifos de color. El valor predeterminado es PIXMAN_a8r8g8b8. Un uso es habilitar una mayor precisión de color cuando srgb_decode está habilitado, para evitar la pérdida de precisión al decodificar de sRGB.
