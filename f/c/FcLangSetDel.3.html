NOMBRE

FcLangSetDel - eliminar un idioma de un conjunto de idiomas

SINOPSIS

#include <fontconfig/fontconfig.h>

FcBool FcLangSetDel (FcLangSet *ls, const FcChar8 *lang);

DESCRIPCIÓN

Se elimina lang de ls. lang debe tener el formato Ll-Tt, donde Ll es un idioma de dos o tres letras de ISO 639 y Tt es un territorio de ISO 3166.
