NOMBRE

FcConfigGetFilename - Encontrar un archivo de configuración

SINOPSIS

#include <fontconfig/fontconfig.h>

FcChar8 * FcConfigGetFilename (FcConfig *config, const FcChar8 *name);

DESCRIPCIÓN

Dado el nombre de la entidad externa especificada, devuelve el nombre de archivo asociado. Esto proporciona a las aplicaciones una forma de convertir varias referencias de archivos de configuración a formato de nombre de archivo.

Un name nulo o vacío indica que se debe usar el archivo de configuración predeterminado; a qué archivo se refiere esto puede anularse con la variable de entorno FONTCONFIG_FILE. A continuación, si el nombre comienza con ~, se refiere a un archivo en el directorio principal del usuario actual. De lo contrario, si el nombre no comienza con '/', se refiere a un archivo en el directorio de configuración predeterminado; el directorio predeterminado incorporado puede anularse con la variable de entorno FONTCONFIG_PATH.

El resultado de esta función se ve afectado por la variable de entorno FONTCONFIG_SYSROOT o una funcionalidad equivalente.
