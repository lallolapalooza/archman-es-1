NOMBRE

FcFontationsQueryAll - calcula todos los patrones desde el archivo de fuente (e índice)

SINOPSIS

#include <fontconfig.h> #include <fcfontations.h>

unsigned int FcFontationsQueryAll (const FcChar8 *file, int id, FcBlanks *blanks, int *count, FcFontSet *set);

DESCRIPCIÓN

Característica INESTABLE. Construye los patrones encontrados en 'file'. Actualmente, el patrón está incompleto en comparación con FcFreeTypeQueryAll() y puede desviarse de lo que produce la indexación de FreeType. Aún no es compatible, pero seguirá: Si id es -1, entonces todos los patrones encontrados en 'file' se añaden a 'set'. De lo contrario, esta función funciona exactamente como FcFreeTypeQueryAll()/FcFreeTypeQuery(). El número de caras en 'file' se devuelve en 'count'. Se devuelve el número de patrones añadidos a 'set'. FcBlanks está obsoleto, blanks se ignora y se acepta solo por compatibilidad con código antiguo.
