NOMBRE

FcDirSave - OBSOLETO: anteriormente se usaba para guardar una caché de directorio

SINOPSIS

#include <fontconfig/fontconfig.h>

FcBool FcDirSave (FcFontSet *set, FcStrSet *dirs, const FcChar8 *dir);

DESCRIPCIÓN

Esta función ahora no hace nada más que devolver FcFalse. Solía crear el archivo de caché por directorio para dir y lo poblaba con las fuentes en set y subdirectorios en dirs. Toda esta funcionalidad ahora es gestionada automáticamente por FcDirCacheLoad y FcDirCacheRead.
