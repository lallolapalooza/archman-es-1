NOMBRE

fc-match - compara fuentes disponibles

SINOPSIS

fc-match [ -asvVh ] [ --all ] [ --sort ] [ --verbose ] [ -f formato | --format formato ] [ --version ] [ --help ]
[ patrón [ elemento ... ] ]

DESCRIPCIÓN

fc-match compara el patrón (patrón vacío por defecto) utilizando las reglas normales de coincidencia de fontconfig para encontrar la mejor fuente disponible. Si se proporciona --sort, se muestra la lista ordenada de las mejores fuentes coincidentes. La opción --all funciona como --sort excepto que no se realiza ninguna poda en la lista de fuentes.

Si se especifican elementos, solo se imprimen esos. De lo contrario, se imprimen el nombre corto del archivo, la familia y el estilo, a menos que se solicite una salida detallada.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-a --all
Muestra la lista ordenada de las mejores fuentes coincidentes, pero no realiza ninguna poda en la lista.
-s --sort
Muestra la lista ordenada de las mejores fuentes coincidentes.
-v --verbose
Imprime una salida detallada de todo el patrón de fuente para cada coincidencia, o los elementos si se proporciona alguno.
-f --format formato
Formatea la salida según el especificador de formato formato.
-V --version
Muestra la versión del programa y sale.
-h --help
Muestra un resumen de las opciones.
patrón
Muestra las fuentes que coinciden con patrón (usa patrón vacío por defecto).
elemento
Si se establece, la propiedad elemento se muestra para las fuentes coincidentes.

EJEMPLOS

fc-match sans
Muestra la mejor fuente coincidente categorizada en la familia genérica sans-serif, filtrada por el locale actual.
fc-match sans:lang=en
Muestra la mejor fuente coincidente categorizada en la familia genérica sans-serif, filtrada por el idioma inglés.
fc-match sans:lang=en:weight=bold
Muestra la mejor fuente coincidente categorizada en la familia genérica sans-serif, filtrada por el idioma inglés y peso negrita.
