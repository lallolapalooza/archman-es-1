FCGI::Client::Record(3pm) Documentación contribuida por el usuario de Perl FCGI::Client::Record(3pm)

NOMBRE

FCGI::Client::Record - objeto de registro para FCGI

SINOPSIS

my $record = FCGI::Client::Record->new(header => $header, content => $content);
say $record->type;

DESCRIPCIÓN

Este módulo es la clase de registro para FCGI::Client.

ATRIBUTOS

encabezado
El atributo 'encabezado' es una instancia de FCGI::Client::RecordHeader.
contenido
El atributo 'contenido' es una cadena de contenido del registro.

MÉTODO

$self->request_id()
$self->content_length()
$self->type()
atajo de $self->header->cualquier_método()
