FCITX(1) Manual de comandos generales FCITX(1)

NOMBRE

fcitx-remote - Herramienta para controlar el estado de fcitx a través de la consola

SINOPSIS

fcitx-remote [OPCIÓN]

OPCIONES

-c
desactivar método de entrada
-o
activar método de entrada
-r
recargar configuración de fcitx
-t
cambiar entre activo/inactivo
-s nombre_im
cambiar al método de entrada identificado de forma única por nombre_im
[sin opción]
mostrar estado de fcitx, 0 para cerrado, 1 para inactivo, 2 para activo
-h
mostrar ayuda y salir

ARCHIVOS

fcitx creará un socket en /tmp/fcitx-socket-<nombre_pantalla>, por lo que el usuario debe tener permisos para acceder a la carpeta /tmp.

VER TAMBIÉN

Por favor, consulte la página principal en https://fcitx-im.org/
