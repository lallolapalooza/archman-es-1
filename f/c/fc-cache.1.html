NOMBRE

fc-cache - crea archivos de caché de información de fuentes

SINOPSIS

fc-cache [ -EfrsvVh ] [ --error-on-no-fonts ] [ --force ] [ --really-force ] [ -y dir | --sysroot dir ] [ --system-only ] [ --verbose ] [ --version ] [ --help ] [ dir ... ]

DESCRIPCIÓN

fc-cache escanea los directorios de fuentes en el sistema y crea archivos de caché de información de fuentes para aplicaciones que utilizan fontconfig para el manejo de fuentes.

Si no se proporcionan argumentos de directorio, fc-cache utiliza cada directorio en la configuración de fuentes actual. Cada directorio se escanea en busca de archivos de fuentes legibles por FreeType. Se crea una caché que contiene las propiedades de cada fuente y el nombre de archivo asociado. Esta caché se utiliza para acelerar el inicio de aplicaciones cuando se usa la biblioteca fontconfig.

Tenga en cuenta que fc-cache debe ejecutarse una vez por arquitectura para generar información de fuentes personalizada para esa arquitectura.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-E --error-on-no-fonts
Genera un error si no hay fuentes en dir o en los directorios de la configuración si no se especifican.
-f --force
Fuerza la regeneración de archivos de caché aparentemente actualizados, ignorando la verificación de marcas de tiempo.
-r --really-force
Borra todos los archivos de caché existentes y vuelve a escanear.
-s --system-only
Solo escanea directorios del sistema, omitiendo los ubicados en el directorio principal del usuario.
-v --verbose
Muestra información de estado mientras está ocupado.
-y -sysroot dir
Añade dir al principio de todas las rutas para el escaneo.
-h --help
Muestra un resumen de las opciones.
-V --version
Muestra la versión del programa y sale.
dir
Directorio para escanear fuentes.

CÓDIGOS DE RETORNO

fc-cache devuelve cero si las cachés se generaron correctamente; de lo contrario, devuelve un valor distinto de cero.

ARCHIVOS

%cachedir%/*-%arch%.cache-%version%
Estos archivos son generados por fc-cache y contienen mapas de nombres de archivo a propiedades de fuentes. La biblioteca fontconfig los lee al inicio de la aplicación para localizar las fuentes apropiadas.
