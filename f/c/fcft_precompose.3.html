NOMBRE

fcft_precompose - pre-compone dos caracteres anchos en uno

SINOPSIS

#include <fcft/fcft.h>

bool fcft_precompose(

const struct fcft_font *font, uint32_t base, uint32_t comb, bool *base_is_from_primary, bool *comb_is_from_primary, bool *composed_is_from_primary);

DESCRIPCIÓN

fcft_precompose() compone los caracteres anchos base y comb en un único carácter ancho. Por ejemplo, L'a' + L'́' (acento agudo) se puede combinar en L'á'.

Si *_is_from_primary no son NULL, serán true si el carácter ancho correspondiente existe en la fuente primaria. Si es false, no existe en la fuente primaria y fcft_codepoint_rasterize() seleccionará el glifo de una de las fuentes de respaldo.

VALOR DE RETORNO

En caso de éxito, fcft_precompose() devuelve un carácter ancho compuesto. En caso de error, se devuelve (uint32_t)-1.

VER TAMBIÉN

fcft_codepoint_rasterize(), fcft_kerning()
