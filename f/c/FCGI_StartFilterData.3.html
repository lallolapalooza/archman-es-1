FCGI_StartFilterData(3)

Paquete: fcgi

Licencias: custom

() ()
NOMBRE
FCGI_StartFilterData - biblioteca de compatibilidad fcgi_stdio

SINOPSIS
#include "fcgi_stdio.h"


int
FCGI_StartFilterData(void);

DESCRIPCIÓN
Habilita a una aplicación FastCGI de filtro a comenzar a leer sus datos de
entrada de filtro desde stdin.


Para poder llamar a FCGI_StartFilterData, la aplicación FastCGI
debería haber sido invocada en el rol de Filtro
(getenv("FCGI_ROLE") == "FILTER"), y debería haber leído
stdin hasta EOF, consumiendo todo el flujo de datos de FCGI_STDIN.
La llamada a FCGI_StartFilterData posiciona stdin al
principio de FCGI_DATA.


Si las precondiciones no se cumplen (por ejemplo, la aplicación no
ha leído stdin hasta EOF), FCGI_StartFilterData devuelve
un resultado negativo, y la aplicación obtendrá EOF en los intentos
de leer desde stdin.


La aplicación puede determinar el número de bytes disponibles
en FCGI_DATA realizando atoi(getenv("FCGI_DATA_LENGTH")).
Si se entregan menos bytes que esta cantidad en stdin después
de llamar a FCGI_StartFilterData, la aplicación debería realizar
una respuesta de error específica de la aplicación. Si la aplicación
normalmente realiza una actualización, lo más probable es que debería
abortar la actualización.


La aplicación puede determinar la hora de la última modificación de los
datos de entrada del filtro realizando getenv("FCGI_DATA_LAST_MOD").
Esto permite a las aplicaciones realizar almacenamiento en caché basado en la hora
de la última modificación.

VALORES DE RETORNO
0 para una llamada exitosa, < 0 para error.
