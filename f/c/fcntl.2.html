DESCRIPCIÓ

N

fcntl() realiza una de las operaciones descritas a continuación en el descriptor de archivo abierto fd. La operación está determinada por op

.

Algunas de las operaciones siguientes solo están disponibles desde una versión particular del núcleo Linux. El método preferido para comprobar si el núcleo anfitrión admite una operación particular es invocar fcntl() con el valor de op deseado y luego comprobar si la llamada falló con EINVAL, lo que indica que el núcleo no reconoce este

valor.
