NOMBRE

fc-pattern - analizar y mostrar patrón

SINOPSIS

fc-pattern [ -cdVh ] [ --config ] [ --default ] [ -f formato | --format formato ] [ --version ] [ --help ]
[ patrón [ elemento ... ] ]

DESCRIPCIÓN

fc-pattern analiza patrón (patrón vacío por defecto) y muestra el resultado analizado. Si se proporciona --config, se realiza una sustitución de configuración en el patrón antes de mostrarlo. Si se proporciona --default, se realiza una sustitución por defecto en el patrón antes de mostrarlo.

Si se especifican elementos, solo se imprimirán esos.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-c --config
Realiza la sustitución de configuración en el patrón.
-d --default
Realiza la sustitución por defecto en el patrón.
-f --format formato
Formatea la salida según el especificador de formato formato.
-V --version
Muestra la versión del programa y sale.
-h --help
Muestra un resumen de las opciones.
patrón
Analiza y muestra patrón (usa patrón vacío por defecto).
elemento
Si se establece, se muestra la propiedad elemento para el patrón analizado.
