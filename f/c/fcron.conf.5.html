NOMBRE

fcron.conf - archivo de configuración para fcron y fcrontab

DESCRIPCIÓN

RESUMEN

Esta página describe la sintaxis utilizada para el archivo de configuración de fcrontab(1), fcrondyn(1) y fcron(8).

Las líneas en blanco, las líneas que comienzan con un signo de almohadilla (#) (que se consideran comentarios), los espacios en blanco iniciales y las tabulaciones se ignoran. Cada línea en un archivo fcron.conf tiene el formato

nombre = valor

donde los espacios alrededor del signo igual (=) se ignoran y son opcionales. Los espacios finales también se ignoran.

Los siguientes nombres son reconocidos (valor por defecto entre paréntesis): "VARIABLES VÁLIDAS EN UN ARCHIVO FCRON.CONF"

fcrontabs=directorio (/usr/local/var/spool/fcron)
Directorio de spool de Fcron.
pidfile=ruta-archivo (/usr/local/var/run/fcron.pid)
Ubicación del archivo PID de fcron (necesario para que fcrontab funcione correctamente).
suspendfile=ruta-archivo (/usr/local/var/run/fcron.suspend)
Ubicación del archivo de suspensión de fcron. En sistemas que no son Linux, esto debe usarse para que fcron sepa cuánto tiempo estuvo suspendido el sistema (en memoria o en disco), para que los horarios de las tareas puedan actualizarse en consecuencia.
fifofile=ruta-archivo (/usr/local/var/run/fcron.fifo)
Ubicación del archivo FIFO de fcron (necesario para que fcrondyn se comunique con fcron).
fcronallow=ruta-archivo (/usr/local/etc/fcron.allow)
Ubicación del archivo fcron.allow.
fcrondeny=ruta-archivo (/usr/local/etc/fcron.deny)
Ubicación del archivo fcron.deny.
shell=ruta-archivo (/usr/bin/sh)
Ubicación del shell predeterminado llamado por fcron al ejecutar un trabajo. Cuando fcron ejecuta un trabajo, fcron usa el valor de SHELL del fcrontab si existe, de lo contrario utiliza el valor de fcron.conf si existe, o en última instancia el valor de /etc/passwd.
sendmail=ruta-archivo (/usr/sbin/sendmail)
Ubicación del programa de correo llamado por fcron para enviar la salida del trabajo.
editor=ruta-archivo (/usr/bin/vi)
Ubicación del editor predeterminado utilizado al invocar "fcrontab -e".
maildisplayname=cadena (Fcron Daemon)
Nombre de visualización para la cabecera "From: " de los correos enviados por nosotros. Tenga en cuenta que en el pasado, fcron seguía el formato de cabecera de correo electrónico predeterminado de Vixie cron, que no cumple completamente con RFC 5322 (ver Issue #15 <URL:https://github.com/yo8192/fcron/issues/15>). fcron volverá a este comportamiento antiguo cuando esta opción se establezca en una cadena vacía. Las rutas de archivos y los directorios son completos y absolutos (es decir, comienzan con "/").

Para ejecutar varias instancias de fcron simultáneamente en el mismo sistema, debe usar un archivo de configuración diferente para cada instancia. Cada instancia debe tener un fcrontabs, pidfile y fifofile diferentes. Luego, use la opción de línea de comandos -c de fcron(8) para seleccionar a qué archivo de configuración (y por lo tanto a qué instancia) se refiere.

ARCHIVOS

/usr/local/etc/fcron.conf
Archivo de configuración para fcron, fcrontab y fcrondyn: contiene rutas (directorio de spool, archivo PID) y programas predeterminados a usar (editor, shell, etc.). Ver fcron.conf(5) para más detalles.
/usr/local/etc/fcron.allow
Usuarios permitidos para usar fcrontab y fcrondyn (un nombre por línea, el nombre especial "all" actúa para todos)
/usr/local/etc/fcron.deny
Usuarios a los que no se les permite usar fcrontab y fcrondyn (mismo formato que el archivo allow)
/usr/local/etc/pam.d/fcron (o /usr/local/etc/pam.conf)
Archivo de configuración PAM para fcron. Eche un vistazo a pam(8) para más detalles.
