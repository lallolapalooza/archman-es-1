NOMBRE

FcAtomicCreate - crear un objeto FcAtomic

SINOPSIS

#include <fontconfig/fontconfig.h>

FcAtomic * FcAtomicCreate (const FcChar8 *archivo);

DESCRIPCIÓN

Crea una estructura de datos que contiene los datos necesarios para controlar el acceso a archivo. La escritura se realiza en un archivo separado. Una vez que ese archivo está completo, el archivo de configuración original se reemplaza atómicamente para que los procesos de lectura siempre vean un archivo consistente y completo sin necesidad de bloquear para leer.
