CANALES ESTÁNDAR

Los canales estándar de Tcl (stdin, stdout y stderr) se pueden configurar a través de este comando como cualquier otro canal abierto por la biblioteca Tcl. Más allá de las opciones estándar descritas anteriormente, también admitirán cualquier opción especial según su tipo actual. Si, por ejemplo, una aplicación Tcl se inicia mediante el super-servidor inet común en los sistemas Unix, sus canales estándar de Tcl serán sockets y, por lo tanto, admitirán las opciones de socket.

EJEMPLOS

Instruir a Tcl para que envíe siempre la salida a stdout inmediatamente, ya sea a un terminal o no:

fconfigure stdout -buffering none

Abrir un socket y leer líneas de él sin bloquear nunca el procesamiento de otros eventos:

set s [socket some.where.com 12345]
fconfigure $s -blocking 0
fileevent $s readable "readMe $s"
proc readMe chan {
    if {[gets $chan line] < 0} {
        if {[eof $chan]} {
            close $chan
            return
        }
        # No se pudo leer una línea completa esta vez; el
        # búfer interno de Tcl mantendrá la línea parcial
        # hasta que haya más datos disponibles en el socket.
    } else {
        puts stdout $line
    }
}

Leer una imagen en formato PPM de un archivo:

# Abrir el archivo y ponerlo en modo ASCII Unix
set f [open teapot.ppm]
fconfigure $f -encoding ascii -translation lf
# Obtener la cabecera
if {[gets $f] ne "P6"} {
    error "not a raw-bits PPM"
}
# Leer líneas hasta que hayamos obtenido líneas que no sean comentarios
# que nos proporcionen tres valores decimales.
set words {}
while {[llength $words] < 3} {
    gets $f line
    if {[string match "#*" $line]} continue
    lappend words {*}[join [scan $line %d%d%d]]
}
# Esas palabras proporcionan el tamaño de la imagen y su
# profundidad general por canal. Asignar a variables.
lassign $words xSize ySize depth
# Ahora cambiar a modo binario para obtener los datos,
# un byte por canal (rojo, verde, azul) por píxel.
fconfigure $f -translation binary
set numDataBytes [expr {3 * $xSize * $ySize}]
set data [read $f $numDataBytes]
close $f
