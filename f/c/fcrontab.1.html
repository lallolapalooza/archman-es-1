NOMBRE

fcrontab - manipular archivos fcrontab por usuario que se adhieren al formato definido en fcrontab(5)

SINOPSIS

fcrontab [ -c archivo ] [ -n ] archivo [ usuario | -u usuario ]

fcrontab [ -c archivo ] [ -n ] { -l | -r | -e | -z } [ usuario | -u usuario ]

fcrontab [ -h ]

DESCRIPCIÓN

Fcrontab es el programa destinado a instalar, editar, listar y eliminar las tablas utilizadas por el demonio fcron(8). Como fcron utiliza internamente un formato no legible por humanos (esto es necesario porque fcron guarda más información de la que proporciona el usuario, por ejemplo, la hora y fecha de la próxima ejecución), el usuario no puede editar su fcrontab directamente (la que utiliza fcron).

Cuando un usuario instala un fcrontab, el archivo de origen se guarda en el directorio de spool (/usr/local/var/spool/fcron) para permitir su edición, y se genera un archivo formateado para el demonio fcron. Este archivo formateado (no legible por humanos) con todos los cambios recientes incluidos se envía al demonio. El demonio no es informado de los cambios inmediatamente, sino después de un tiempo para evitar que usuarios malintencionados bloqueen el demonio instalando fcrontab repetidamente (es decir, un ataque de denegación de servicio). Por defecto, el archivo se envía una vez por minuto (unos diez segundos antes del minuto completo) al demonio; el parámetro de compilación --with-max-fcrontab-reload-delay-seconds puede usarse para especificar un tiempo máximo diferente para enviar estos datos. Llamaremos "fcrontab" al archivo de origen del fcrontab en lo sucesivo.

Los archivos fcrontab que un usuario modifica deben seguir el formato definido en fcrontab(5).

Los usuarios pueden instalar un fcrontab si están listados en /usr/local/etc/fcron.allow y no están listados en /usr/local/etc/fcron.deny (ver sección "archivos" más abajo). La palabra clave 'all' es una abreviatura para todos los usuarios. Si no existen ni fcron.allow ni fcron.deny, todos los usuarios están permitidos. Ninguno de estos archivos tiene que existir, pero si existen, el archivo deny tiene precedencia.

La primera forma del comando se utiliza para instalar un nuevo fcrontab, desde cualquier archivo nombrado o desde la entrada estándar (si se da el pseudonombre de archivo "-"), reemplazando el anterior (si lo hubiera). Cada usuario puede tener solo un fcrontab.

Por ejemplo, root puede crear un archivo fcrontab a nivel de sistema, digamos /etc/fcrontab, y ejecutar "fcrontab /etc/fcrontab" para instalar la nueva versión después de cada cambio del archivo. O root puede crear un nuevo fcrontab ejecutando un simple "fcrontab", y luego mantenerlo usando "fcrontab -e". Las mismas consideraciones se aplican a un usuario no privilegiado.

OPCIONES

-u usuario
Especifica el usuario cuyo fcrontab será gestionado, o "systab" para el fcrontab del sistema. Solo debe ser utilizado por root. Si no se proporciona, se gestionará el archivo fcrontab del usuario que invoca fcrontab. Puede ser útil ya que el comando su(8) puede confundir a fcrontab.
Nota: el 'usuario' en la sinopsis es equivalente a un '-u usuario'.
-l
Lista el fcrontab actual del usuario en la salida estándar.
-e
Edita el fcrontab actual del usuario utilizando el editor especificado por la variable de entorno VISUAL, o EDITOR si VISUAL no está establecido. Si ninguno de ellos está establecido, se usará /usr/bin/vi.
-r
Elimina el fcrontab del usuario.
-z
Reinstala el fcrontab del usuario desde su código fuente. Toda la información que fcron pueda haber guardado en el fcrontab binario (como la última hora y fecha de ejecución) será olvidada (es decir, perdida).
-n
Ignora la versión anterior. Si esta opción no se proporciona, fcron intentará mantener tanta información como sea posible entre la versión vieja y la nueva del fcrontab (hora y fecha de la próxima ejecución, si el trabajo está en la cola serial, etc.) si la línea no ha sido modificada (mismos campos, mismo comando de shell).
-c archivo
Hace que fcrontab use el archivo de configuración archivo en lugar del archivo de configuración por defecto /usr/local/etc/fcron.conf. Para interactuar con un proceso fcron en ejecución, fcrontab debe usar el mismo archivo de configuración que el proceso. De esta manera, varios procesos fcron pueden ejecutarse simultáneamente en un solo sistema.
-d
Ejecutar en modo de depuración. En este modo, se mostrarán muchos mensajes informativos para comprobar si algo salió mal.
-h
Muestra una breve descripción de las opciones.
-V
Muestra un mensaje informativo sobre fcrontab, incluyendo su versión y la licencia bajo la cual se distribuye.

VALORES DE RETORNO

Fcrontab retorna 0 en salida normal y 1 en error.

CONFORME A

Debería ser compatible con POSIX.

ARCHIVOS

/usr/local/etc/fcron.conf
Archivo de configuración para fcron, fcrontab y fcrondyn: contiene rutas (directorio de spool, archivo pid) y programas por defecto a usar (editor, shell, etc.). Ver fcron.conf(5) para más detalles.
/usr/local/etc/fcron.allow
Usuarios permitidos para usar fcrontab y fcrondyn (un nombre por línea, el nombre especial "all" actúa para todos)
/usr/local/etc/fcron.deny
Usuarios que no tienen permitido usar fcrontab y fcrondyn (mismo formato que el archivo allow)
/usr/local/etc/pam.d/fcron (o /usr/local/etc/pam.conf)
Archivo de configuración PAM para fcron. Echa un vistazo a pam(8) para más detalles.
