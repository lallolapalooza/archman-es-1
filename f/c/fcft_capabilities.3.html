NOMBRE

fcft_capabilities - capacidades opcionales de la biblioteca disponibles

SINOPSIS

#include <fcft/fcft.h>

enum fcft_capabilities fcft_capabilities(void);

DESCRIPCIÓN

fcft_capabilities() devuelve una máscara de bits de las capacidades opcionales de la biblioteca habilitadas:

enum fcft_capabilities {
    FCFT_CAPABILITY_GRAPHEME_SHAPING = 0x1,  /* Desde 2.3.0 */
    FCFT_CAPABILITY_TEXT_RUN_SHAPING = 0x2,  /* Desde 2.4.0 */
    FCFT_CAPABILITY_SVG = 0x4,               /* Desde 3.1.0 */
};

FCFT_CAPABILITY_GRAPHEME_SHAPING

fcft puede realizar la conformación de grafemas (usando HarfBuzz), y se puede esperar que fcft_grapheme_rasterize() devuelva no NULL.

FCFT_CAPABILITY_TEXT_RUN_SHAPING

fcft puede realizar la conformación de secuencias de texto (usando HarfBuzz), y se puede esperar que fcft_text_run_rasterize() devuelva no NULL.

FCFT_CAPABILITY_SVG

fcft puede rasterizar glifos de fuentes OT-SVG.

VER TAMBIÉN

fcft_grapheme_glyph_rasterize(), fcft_text_run_rasterize()
