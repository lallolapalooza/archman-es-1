NOMBRE

FcCharSetFirstPage - Iniciar la enumeración del contenido del conjunto de caracteres

SINOPSIS

#include <fontconfig/fontconfig.h>

FcChar32 FcCharSetFirstPage (const FcCharSet *a, FcChar32[FC_CHARSET_MAP_SIZE] map, FcChar32 *next);

DESCRIPCIÓN

Construye un array de bits en map que marca la primera página de cobertura Unicode de a. *next se establece para contener el punto de código base para la siguiente página en a. Devuelve el punto de código base para la página, o FC_CHARSET_DONE si a no contiene páginas. Como ejemplo, si FcCharSetFirstPage devuelve 0x300 y rellena map con

0xffffffff 0xffffffff 0x01000008 0x44300002 0xffffd7f0 0xfffffffb 0xffff7fff 0xffff0003
Entonces la página contiene los puntos de código 0x300 a 0x33f (los primeros 64 puntos de código en la página) porque map[0] y map[1] tienen todos sus bits establecidos. También contiene los puntos de código 0x343 (0x300 + 32*2 + (4-1)) y 0x35e (0x300 + 32*2 + (31-1)) porque map[2] tiene el 4º y 31º bits establecidos. Los puntos de código representados por map[3] y posteriores se dejan como ejercicio para el lector ;)
