FCGI_SetExitStatus(3)

Paquete: fcgi

Licencias: custom

() ()
NOMBRE
FCGI_SetExitStatus - biblioteca de compatibilidad fcgi_stdio

SINOPSIS
#include "fcgi_stdio.h"


void
FCGI_SetExitStatus(int status);

DESCRIPCIÓN
Establece el estado de salida para la solicitud FastCGI actual.
El estado de salida es el código de estado con el que la solicitud habría
salido, si la solicitud se hubiera ejecutado como un programa CGI.


Puede llamar a FCGI_SetExitStatus varias veces durante una solicitud;
la última llamada antes de que finalice la solicitud determina el valor.
