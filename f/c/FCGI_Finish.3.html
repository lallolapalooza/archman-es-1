FCGI_Finish(3)

Paquete: fcgi

Licencias: custom

() ()
NOMBRE
FCGI_Finish
- biblioteca de compatibilidad fcgi_stdio

SINOPSIS
#include "fcgi_stdio.h"


void
FCGI_Finish(void);

DESCRIPCIÓN
La función FCGI_Finish finaliza la solicitud actual del servidor
HTTP. La solicitud actual se inició con la llamada más reciente
a FCGI_Accept(3).


FCGI_Finish permite a una aplicación intercalar otras actividades
con el procesamiento de solicitudes. En un caso extremo, una
aplicación llamaría a FCGI_Finish para completar la solicitud
actual antes de salir, por ejemplo, para recuperar memoria filtrada.


Al completar la solicitud actual, FCGI_Finish puede detectar
errores, por ejemplo, una tubería rota a un cliente que se ha
desconectado temprano. FCGI_Finish ignora dichos errores. Una
aplicación que desee manejar dichos errores debe llamar
explícitamente a fclose(stderr), luego fclose(stdout); un retorno
de EOF de cualquiera de ellos indica un error.


FCGI_Finish libera cualquier almacenamiento asignado por la llamada
más reciente a FCGI_Accept. Consulte FCGI_Accept(3) para ver
advertencias contra la retención de punteros a este almacenamiento.
