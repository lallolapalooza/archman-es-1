FCHMOD(3P) Manual del programador POSIX FCHMOD(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fchmod — cambiar el modo de un archivo

SINOPSIS

#include <sys/stat.h>
int fchmod(int fildes, mode_t mode);

DESCRIPCIÓN

La función fchmod() será equivalente a chmod() excepto que el archivo cuyas permisos se cambian se especifica mediante el descriptor de archivo fildes.

Si fildes hace referencia a un objeto de memoria compartida, la función fchmod() solo necesita afectar los bits de permiso de archivo S_IRUSR, S_IWUSR, S_IRGRP, S_IWGRP, S_IROTH y S_IWOTH.

Si fildes hace referencia a un objeto de memoria tipificada, el comportamiento de fchmod() no está especificado.

Si fildes hace referencia a un socket, el comportamiento de fchmod() no está especificado.

Si fildes hace referencia a un STREAM (que está fattach()-ed en el espacio de nombres del sistema de archivos) la llamada retorna exitosamente, sin hacer nada.

VALOR DE RETORNO

Al completarse exitosamente, fchmod() retornará 0. En caso contrario, retornará -1 y establecerá errno para indicar el error.

ERRORES

La función fchmod() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo abierto.
EPERM
El ID de usuario efectivo no coincide con el propietario del archivo y el proceso no tiene privilegios apropiados.
EROFS
El archivo al que se refiere fildes reside en un sistema de archivos de solo lectura.

La función fchmod() puede fallar si:

EINTR
La función fchmod() fue interrumpida por una señal.
EINVAL
El valor del argumento mode es inválido.
EINVAL
El argumento fildes hace referencia a una tubería (pipe) y la implementación prohíbe la ejecución de fchmod() en una tubería.

EJEMPLOS

Cambiar los permisos actuales para un archivo

El siguiente ejemplo muestra cómo cambiar los permisos de un archivo llamado /home/cnd/mod1 para que el propietario y el grupo tengan permisos de lectura/escritura/ejecución, pero el resto del mundo solo tenga permisos de lectura/escritura.

#include <sys/stat.h>
#include <fcntl.h>
mode_t mode;
int    fildes;
...
fildes = open("/home/cnd/mod1", O_RDWR);
fchmod(fildes, S_IRWXU | S_IRWXG | S_IROTH | S_IWOTH);
