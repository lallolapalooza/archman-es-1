NOMBRE

FcFreeTypeCharSetAndSpacing - calcular el conjunto de caracteres y el espaciado

SINOPSIS

#include <fontconfig.h> #include <fcfreetype.h>

FcCharSet * FcFreeTypeCharSetAndSpacing (FT_Face face, FcBlanks *blanks, int *spacing);

DESCRIPCIÓN

Escanea una cara FreeType y devuelve el conjunto de caracteres Unicode codificados. FcBlanks está obsoleto, blanks se ignora y se acepta solo por compatibilidad con código antiguo. spacing recibe el tipo de espaciado calculado de la fuente, uno de FC_MONO para una fuente donde todos los glifos tienen el mismo ancho, FC_DUAL, donde la fuente tiene glifos en precisamente dos anchos, uno el doble de ancho que el otro, o FC_PROPORTIONAL donde la fuente tiene glifos de muchos anchos.
