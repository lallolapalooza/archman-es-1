NOMBRE

fc-validate - valida archivos de fuentes

SINOPSIS

fc-validate [ -Vhv ]
[ -i índice | --index índice ] [ -l lang | --lang lang ] [ --verbose ] [ --version ] [ --help ] archivo-de-fuente ...

DESCRIPCIÓN

fc-validate valida archivo-de-fuente(s) si cada fuente satisface la cobertura de idioma según los archivos de ortografía en fontconfig. Si se proporciona --index, solo se valida una cara de cada archivo, de lo contrario, se validan todas las caras.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-i --index índice
Solo consulta la cara con índice índice de cada archivo.
-l --lang lang
Establece lang como idioma en lugar de la configuración regional actual. esto se usa para -m.
-v --verbose
Muestra información más detallada.
-V --version
Muestra la versión del programa y sale.
-h --help
Muestra un resumen de las opciones.
archivo-de-fuente
Consulta archivo-de-fuente para obtener caras de fuentes.

CÓDIGOS DE RETORNO

fc-validate devuelve el código de error 0 si el análisis se realizó correctamente, o 1 si ocurrieron errores o si no se pudo abrir al menos una cara de fuente.
