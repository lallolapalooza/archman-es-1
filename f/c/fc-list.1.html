NOMBRE

fc-list - lista las fuentes disponibles

SINOPSIS

fc-list [ -vVh ] [ --verbose ] [ -f formato | --format formato ] [ -q | --quiet ] [ --version ] [ --help ]
[ patrón [ elemento ... ] ]

DESCRIPCIÓN

fc-list lista las fuentes y estilos disponibles en el sistema para las aplicaciones que utilizan fontconfig. Si se especifican elementos, solo se imprimen esos. De lo contrario, se imprimen la familia y el estilo, a menos que se solicite una salida detallada.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-v --verbose
Imprime una salida detallada del patrón de fuente completo para cada coincidencia, o los elementos si se proporciona alguno.
-f --format formato
Formatea la salida según el especificador de formato formato.
-q --quiet
Suprime toda la salida normal. Devuelve 1 como código de error si no coinciden fuentes.
-V --version
Muestra la versión del programa y sale.
-h --help
Muestra un resumen de las opciones.
patrón
Si se establece este argumento, solo se muestran las fuentes que coinciden con patrón.
elemento
Si se establece, se muestra la propiedad elemento para las fuentes coincidentes.

EJEMPLOS

fc-list
Lista todas las caras de fuente.
fc-list :lang=hi
Lista las caras de fuente que cubren el hindi.
fc-list : familia estilo archivo espaciado
Lista el nombre del archivo y el valor de espaciado para cada cara de fuente. ``:'' es un patrón vacío que coincide con todas las fuentes.
