FCHOWN(3P) Manual del programador POSIX FCHOWN(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fchown — cambiar propietario y grupo de un archivo

SINOPSIS

#include <unistd.h>
int fchown(int fildes, uid_t owner, gid_t group);

DESCRIPCIÓN

La función fchown() será equivalente a chown() excepto que el archivo cuyo propietario y grupo se cambian se especifica mediante el descriptor de archivo fildes.

VALOR DE RETORNO

Al completarse con éxito, fchown() devolverá 0. De lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función fchown() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo abierto.
EPERM
El ID de usuario efectivo no coincide con el propietario del archivo o el proceso no tiene privilegios apropiados y _POSIX_CHOWN_RESTRICTED indica que se requiere dicho privilegio.
EROFS
El archivo al que se refiere fildes reside en un sistema de archivos de solo lectura.

La función fchown() puede fallar si:

EINVAL
El ID del propietario o del grupo no es un valor compatible con la implementación. El argumento fildes se refiere a una tubería o socket o a una STREAM asociada con fattach() y la implementación no permite la ejecución de fchown() en una tubería.
EIO
Ha ocurrido un error físico de E/S.
EINTR
La función fchown() fue interrumpida por una señal que fue capturada.

EJEMPLOS

Cambiar el propietario actual de un archivo

El siguiente ejemplo muestra cómo cambiar el propietario de un archivo llamado /home/cnd/mod1 a ``jones'' y el grupo a ``cnd''.

El valor numérico del ID de usuario se obtiene extrayendo el ID de usuario de la entrada de la base de datos de usuarios asociada con ``jones''. De manera similar, el valor numérico del ID de grupo se obtiene extrayendo el ID de grupo de la entrada de la base de datos de grupos asociada con ``cnd''. Este ejemplo asume que el programa que llama tiene los privilegios adecuados.

#include <sys/types.h>
#include <unistd.h>
#include <fcntl.h>
#include <pwd.h>
#include <grp.h>
struct passwd *pwd;
struct group  *grp;
int            fildes;
...
fildes = open("/home/cnd/mod1", O_RDWR);
pwd = getpwnam("jones");
grp = getgrnam("cnd");
fchown(fildes, pwd->pw_uid, grp->gr_gid);
