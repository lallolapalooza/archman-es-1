chdir(2) Manual de llamadas al sistema chdir(2)

NOMBRE

chdir, fchdir - cambiar directorio de trabajo

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <unistd.h>
int chdir(const char *path);
int fchdir(int fd);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

fchdir():

    _XOPEN_SOURCE >= 500
        || /* Desde glibc 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc hasta 2.19 inclusive: */ _BSD_SOURCE

DESCRIPCIÓN

chdir() cambia el directorio de trabajo actual del proceso llamante al directorio especificado en path.

fchdir() es idéntico a chdir(); la única diferencia es que el directorio se proporciona como un descriptor de archivo abierto.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Dependiendo del sistema de archivos, se pueden devolver otros errores. Los errores más generales para chdir() se enumeran a continuación:

EACCES
Se niega el permiso de búsqueda en uno de los componentes de path. (Ver también path_resolution(7)).
EFAULT
path apunta fuera de su espacio de direcciones accesible.
EIO
Ocurrió un error de E/S.
ELOOP
Se encontraron demasiados enlaces simbólicos al resolver path.
ENAMETOOLONG
path es demasiado largo.
ENOENT
El directorio especificado en path no existe.
ENOMEM
No había suficiente memoria del kernel disponible.
ENOTDIR
Un componente de path no es un directorio.

Los errores generales para fchdir() se enumeran a continuación:

EACCES
Se negó el permiso de búsqueda en el directorio abierto en fd.
EBADF
fd no es un descriptor de archivo válido.
ENOTDIR
fd no se refiere a un directorio.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001, SVr4, 4.4BSD.

NOTAS

El directorio de trabajo actual es el punto de partida para interpretar las rutas relativas (aquellas que no comienzan con '/').

Un proceso hijo creado a través de fork(2) hereda el directorio de trabajo actual de su padre. El directorio de trabajo actual no se modifica con execve(2).

VER TAMBIÉN

chroot(2), getcwd(3), path_resolution(7)
