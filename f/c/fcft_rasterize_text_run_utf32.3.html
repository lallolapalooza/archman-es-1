fcft_rasterize_text_run_utf32(3) fcft fcft_rasterize_text_run_utf32(3)

NOMBRE

fcft_rasterize_text_run_utf32 - rasteriza una serie de glifos para una cadena de texto

SINOPSIS

#include <fcft/fcft.h>

struct fcft_text_run *fcft_rasterize_text_run_utf32(

struct fcft_font *font, size_t len, const uint32_t text[static len], enum fcft_subpixel subpixel);

DESCRIPCIÓN

fcft_rasterize_text_run_utf32() da forma y rasteriza la cadena Unicode codificada en UTF-32 text en una serie de glifos utilizando la fuente principal y, posiblemente, una o más fuentes de reserva en font.

subpixel le permite especificar qué modo subpíxel usar. Ver fcft_rasterize_char_utf32() para más detalles.

La cadena se segmenta primero en clústeres de grafemas usando utf8proc. A cada grafema se le asigna una fuente usando las reglas normales de búsqueda de fuentes (ver fcft_rasterize_char_utf32()).

A continuación, HarfBuzz se utiliza para adivinar el script (~idioma) de cada grafema. Los grafemas consecutivos que comparten la misma fuente asignada y pertenecen al mismo script se fusionan en una ejecución de texto "parcial".

Finalmente, cada ejecución de texto parcial se da forma con HarfBuzz.

VALOR DE RETORNO

En caso de error, se devuelve NULL.

En caso de éxito, se devuelve un puntero a una ejecución de texto asignada dinámicamente:

struct fcft_text_run {
    const struct fcft_glyph **glyphs;
    int *cluster;
    size_t count;
};

Tanto glyphs como cluster son arreglos con count elementos. cluster contiene los desplazamientos de caracteres (en la cadena original) de cada glifo correspondiente.

Tenga en cuenta que el miembro cols de los glifos no es válido.

La ejecución de texto no se almacena en caché en fcft. La aplicación que llama puede almacenarla en caché durante el tiempo que desee, incluso después de que la fuente haya sido destruida.

La ejecución de texto debe ser liberada con fcft_text_run_destroy().

VER TAMBIÉN

fcft_text_run_destroy(), fcft_rasterize_char_utf32(), fcft_rasterize_grapheme_utf32()
