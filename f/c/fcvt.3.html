ecvt(3) Manual de funciones de biblioteca ecvt(3)

NOMBRE

ecvt, fcvt - convertir un número de punto flotante a una cadena

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <stdlib.h>
[[deprecated]] char *ecvt(double number, int ndigits,
                          int *restrict decpt, int *restrict sign);
[[deprecated]] char *fcvt(double number, int ndigits,
                          int *restrict decpt, int *restrict sign);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

ecvt(), fcvt():

    Desde glibc 2.17
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200809L))
            || /* glibc >= 2.20 */ _DEFAULT_SOURCE
            || /* glibc <= 2.19 */ _SVID_SOURCE
    glibc 2.12 a glibc 2.16:
        (_XOPEN_SOURCE >= 500 && ! (_POSIX_C_SOURCE >= 200112L))
            || _SVID_SOURCE
    Antes de glibc 2.12:
        _SVID_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

La función ecvt() convierte number a una cadena terminada en nulo de ndigits dígitos (donde ndigits se reduce a un límite específico del sistema determinado por la precisión de un double), y devuelve un puntero a la cadena. El dígito de orden superior es distinto de cero, a menos que number sea cero. El dígito de orden inferior se redondea. La cadena en sí no contiene un punto decimal; sin embargo, la posición del punto decimal con respecto al inicio de la cadena se almacena en *decpt. Un valor negativo para *decpt significa que el punto decimal está a la izquierda del inicio de la cadena. Si el signo de number es negativo, *sign se establece en un valor distinto de cero, de lo contrario se establece en 0. Si number es cero, no se especifica si *decpt es 0 o 1.

La función fcvt() es idéntica a ecvt(), excepto que ndigits especifica el número de dígitos después del punto decimal.

VALOR DE RETORNO

Tanto las funciones ecvt() como fcvt() devuelven un puntero a una cadena estática que contiene la representación ASCII de number. La cadena estática se sobrescribe en cada llamada a ecvt() o fcvt().

ESTÁNDARES

Ninguno.

HISTORIAL

SVr2; marcado como LEGACY en POSIX.1-2001. POSIX.1-2008 elimina las especificaciones de ecvt() y fcvt(), recomendando el uso de sprintf(3) en su lugar (aunque snprintf(3) puede ser preferible).

NOTAS

No todas las configuraciones regionales utilizan un punto como carácter separador decimal ("punto decimal").
