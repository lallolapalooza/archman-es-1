NOMBRE

fcrondyn - dialogar dinámicamente con un demonio fcron en ejecución

SINOPSIS

fcrondyn [ -c archivo ] [ -i ]

fcrondyn [ -c archivo ] -x comando

fcrondyn [ -h ]

DESCRIPCIÓN

Fcrondyn es una herramienta de usuario destinada a interactuar con un demonio fcron en ejecución. Puede, por ejemplo, listar los trabajos del usuario cargados por fcron, ejecutar uno de ellos, cambiar la prioridad de un trabajo en ejecución, enviar una señal a un trabajo en ejecución, etc.

OPCIONES

-i
Ejecuta fcrondyn en modo interactivo. fcrondyn también se ejecuta en modo interactivo cuando no se proporciona ninguna opción.
-x comando
Ejecuta comando y retorna inmediatamente. Ver más abajo para la sintaxis y una lista de comandos.
-c archivo
Hace que fcrondyn use el archivo de configuración archivo en lugar del archivo de configuración predeterminado /usr/local/etc/fcron.conf. Para interactuar con un proceso fcron en ejecución, fcrondyn debe usar el mismo archivo de configuración que el proceso. De esta manera, varios procesos fcron pueden ejecutarse simultáneamente en un solo sistema.
-d
Ejecuta en modo de depuración. En este modo, se generarán muchos mensajes informativos para comprobar si algo salió mal.
-h
Muestra una breve descripción de las opciones.
-V
Muestra un mensaje informativo sobre fcrondyn, incluida su versión y la licencia bajo la cual se distribuye.

DESCRIPCIÓN DE COMANDOS

La sintaxis del comando de Fcrondyn es la siguiente:

comando arg1 arg2 [...]

Un argumento de un comando de fcrondyn es de uno de los siguientes tipos: "TIPOS DE ARGUMENTOS DE LOS COMANDOS DE FCRONDYN"

usuario
Un nombre de usuario válido.
id_trabajo
Un ID de trabajo proporcionado por uno de los comandos ls* de fcrondyn (es decir, un entero).
señal
Un número de señal o su nombre (no distingue entre mayúsculas y minúsculas). Por ejemplo, "term" o "15".
valor_nice
Un valor de prioridad del trabajo. Un valor_nice es un entero de -20 (prioridad más alta) a 19 (más baja) (solo se permite a root usar un valor negativo con esta opción).

Finalmente, se reconocen los siguientes comandos (los argumentos opcionales están entre []): "COMANDOS VÁLIDOS DE FCRONDYN"

ayuda
h
Imprime un mensaje de ayuda sobre los comandos de fcrondyn.
salir
q
En modo interactivo, sale de fcrondyn.
ls [usuario]
Lista todos los trabajos del usuario. Cuando ls es ejecutado por root, se listan todos los usuarios a menos que se proporcione un nombre de usuario como argumento. Ver más abajo para algunas explicaciones sobre los campos utilizados por los comandos ls*.
ls_lavgq [usuario]
Igual que ls, pero lista solo los trabajos que están en la cola de carga promedio (es decir, que esperan una carga promedio menor para ser ejecutados).
ls_serialq [usuario]
Igual que ls, pero lista solo los trabajos que están en la cola serial (es decir, que esperan a que otros trabajos terminen).
ls_exeq [usuario]
Igual que ls, pero lista solo los trabajos que se están ejecutando.
detalle id_trabajo
Imprime detalles sobre un trabajo. id_trabajo es el proporcionado por ls.
ejecutar_ahora id_trabajo
En lugar de esperar el próximo tiempo de ejecución programado, ejecuta el trabajo ahora. El próximo tiempo de ejecución se cambia como si el trabajo se hubiera ejecutado a tiempo.
ejecutar id_trabajo
Ejecuta el trabajo ahora. Su próximo tiempo de ejecución no se cambia.
matar señal id_trabajo
Envía una señal a un trabajo en ejecución.
renice valor_nice id_trabajo
Cambia la prioridad de un trabajo en ejecución. "CAMPOS UTILIZADOS POR LOS COMANDOS DETALLE Y LS*"
ID
Número de identificación único del trabajo.
USUARIO
Usuario propietario de este trabajo.
PID
El PID del trabajo en ejecución.
ÍNDICE
Índice del trabajo en la cola serial (es decir, se ejecutará cuando todos los trabajos de un índice inferior se hayan ejecutado)
R&Q
El trabajo tiene este número de instancias de la tarea dada que se están ejecutando o en cola en la cola serial o lavg.
OPCIONES
Lista de opciones principales configuradas para la tarea. L para los trabajos que se ejecutan solo bajo una carga promedio del sistema dada (opción lavg, lavg1, lavg5 y lavg15), LO (Load average Once) si solo como máximo una instancia de la tarea puede estar en la cola de carga promedio a la vez (opción lavgonce), S para trabajos serializados (opción serial), SO para los trabajos que solo se serializarán para la próxima ejecución (Serial Once), y ES si varias instancias del mismo trabajo pueden ejecutarse simultáneamente (opción exesev).
LAVG
3 valores, correspondientes a los valores de carga promedio del sistema de 1, 5 y 15 minutos (en este orden) por debajo de los cuales se ejecutará el trabajo, de lo contrario, se pondrá en cola hasta que la carga promedio del sistema sea apropiada (ver opción lavg).
HASTA
Campo correspondiente a la opción until.
ESTRICTO
Campo correspondiente a la opción strict. Y para sí, N para no.
PROGRAMADO
La próxima ejecución está programada para esta hora y fecha. Tenga en cuenta que fcrondyn imprime la hora y fecha de la próxima ejecución en la zona horaria del sistema donde se está ejecutando fcron, y no en la zona horaria que se puede definir para usar la opción timezone.
CMD
El comando que se ejecutará.

VALORES DE RETORNO

Fcrondyn retorna 0 en salida normal y 1 en caso de error.

CONFORME A

Debería ser compatible con POSIX.

ARCHIVOS

/usr/local/etc/fcron.conf
Archivo de configuración para fcron, fcrontab y fcrondyn: contiene rutas (directorio spool, archivo pid) y programas predeterminados a usar (editor, shell, etc.). Ver fcron.conf(5) para más detalles.
/usr/local/etc/fcron.allow
Usuarios permitidos para usar fcrontab y fcrondyn (un nombre por línea, el nombre especial "all" actúa para todos)
/usr/local/etc/fcron.deny
Usuarios a los que no se les permite usar fcrontab y fcrondyn (mismo formato que el archivo allow)
/usr/local/etc/pam.d/fcron (o /usr/local/etc/pam.conf)
Archivo de configuración PAM para fcron. Echa un vistazo a pam(8) para más detalles.
