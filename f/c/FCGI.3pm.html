Paquete: perl-fcgi

FCGI(3) Documentación de Perl aportada por el usuario FCGI(3)

NOMBRE

FCGI - Módulo Fast CGI

SINOPSIS

use FCGI;
my $count = 0;
my $request = FCGI::Request();
while($request->Accept() >= 0) {
    print("Content-type: text/html\r\n\r\n", ++$count);
}

DESCRIPCIÓN

Funciones:

FCGI::Request
Crea un manejador de solicitud. Tiene los siguientes parámetros opcionales:
manejador de archivo de entrada de Perl (por defecto: \*STDIN)
manejador de archivo de salida de Perl (por defecto: \*STDOUT)
manejador de archivo de error de Perl (por defecto: \*STDERR)
Estos manejadores de archivo se configurarán para actuar como entrada/salida/error en caso de éxito en la aceptación.
referencia a un hash de entorno (por defecto: \%ENV)
El hash se poblará con el entorno.
socket (por defecto: 0)
Socket para comunicarse con el servidor. Puede ser el resultado de la función OpenSocket. Por el momento, es el descriptor de archivo del socket que debe pasarse. Esto puede cambiar en el futuro.

Solo debes usar tu propio socket si tu programa no es iniciado por un gestor de procesos como mod_fastcgi (excepto en el caso de FastCgiExternalServer) o cgi-fcgi. Si utilizas la opción, debes informar a tu servidor FastCGI en qué puerto (y posiblemente servidor) está escuchando tu programa. Consulta remote.pl para ver un ejemplo.

flags (por defecto: FCGI::FAIL_ACCEPT_ON_INTR)
Valores posibles:
FCGI::FAIL_ACCEPT_ON_INTR
Si está establecido, Accept fallará si es interrumpido. Si no está establecido, simplemente seguirá esperando.

Ejemplo de uso:
my $req = FCGI::Request;

o:
my %env;
my $in = new IO::Handle;
my $out = new IO::Handle;
my $err = new IO::Handle;
my $req = FCGI::Request($in, $out, $err, \%env);

FCGI::OpenSocket(ruta, cola)
Crea un socket adecuado para usar como argumento para Request.
ruta
Nombre del archivo del socket o dos puntos seguidos del puerto TCP local. Ten en cuenta que algunos sistemas tienen en cuenta los permisos de archivo en los sockets de dominio Unix, por lo que tendrás que asegurarte de que el servidor pueda escribir en el archivo creado, cambiando la umask antes de la llamada y/o cambiando los permisos y/o el grupo del archivo después.
cola
Longitud máxima de la cola de conexiones pendientes. Si llega una solicitud de conexión con la cola llena, el cliente puede recibir un error con una indicación de ECONNREFUSED.
FCGI::CloseSocket(socket)
Cierra un socket abierto con OpenSocket.
$req->Accept()
Acepta una conexión en $req, adjuntando los manejadores de archivo y poblando el hash de entorno. Devuelve 0 en caso de éxito. Si se ha aceptado una conexión previamente, la anterior se finalizará primero.

Ten en cuenta que, a diferencia de la interfaz anterior, no se instalan manejadores de die y warn por defecto. Esto significa que si no estás ejecutando un Perl con sfio activado, cualquier mensaje de warn o die no terminará en el registro del servidor por defecto. Se recomienda que configures tú mismo los manejadores de die y warn. FCGI.pm contiene un ejemplo de manejadores de die y warn.

$req->Finish()
Finaliza la conexión aceptada. También desvincula los manejadores de archivo.
$req->Flush()
Vacía la conexión aceptada.
$req->Detach()
Desvincula temporalmente los manejadores de archivo de una conexión aceptada.
$req->Attach()
Revincula los manejadores de archivo de una conexión aceptada.
$req->LastCall()
Indica a la biblioteca que no acepte más solicitudes en este manejador. Debe ser seguro llamar a este método desde manejadores de señales.

Ten en cuenta que este método sigue siendo experimental y todo lo relacionado con él, incluido su nombre, está sujeto a cambios.

$env = $req->GetEnvironment()
Devuelve el parámetro de entorno pasado a FCGI::Request.
($in, $out, $err) = $req->GetHandles()
Devuelve los parámetros de los manejadores de archivo pasados a FCGI::Request.
$isfcgi = $req->IsFastCGI()
Devuelve si el programa se ejecutó o no como FastCGI.

LIMITACIONES

FCGI.pm no es compatible con Unicode; solo se admiten caracteres en el rango 0x00-0xFF. Los intentos de imprimir cadenas que contengan caracteres superiores a 0xFF generan una excepción: (F) "Wide character in %s".

Los usuarios que deseen el comportamiento incorrecto anterior (FCGI.pm <= 0.68) pueden deshabilitar la excepción usando la pragmática "bytes".

{
    use bytes;
    print "\x{263A}";
}
