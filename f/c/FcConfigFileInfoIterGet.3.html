NOMBRE

FcConfigFileInfoIterGet - Obtener la información del archivo de configuración

SINOPSIS

#include <fontconfig/fontconfig.h>

FcBool FcConfigFileInfoIterGet (FcConfig *config, FcConfigFileInfoIter *iter, FcChar8 **name, FcChar8 **description, FcBool *enabled);

DESCRIPCIÓN

Obtiene el nombre del archivo, la descripción y el indicador de si está habilitado o no para 'iter', donde apunta a la información actual del archivo de configuración. Si el iterador no es válido, se devuelve FcFalse.

Esta función no es segura para hilos (MT-safe). Se debe llamar a FcConfigReference antes de usar FcConfigFileInfoIterInit y luego a FcConfigDestroy cuando los valores relevantes ya no se referencien.
