FCGI::Client::RecordFactory(3pm) Documentación de Perl aportada por el usuario FCGI::Client::RecordFactory(3pm)

NOMBRE

FCGI::Client::RecordFactory - Fábrica de registros FCGI

MÉTODOS DE API DE ALTO NIVEL

FCGI::Client::RecordFactory->create_request($reqid, $env, $content);
Este método crea un conjunto de registros de solicitud. $env son variables de entorno, igual que CGI. $content es el cuerpo de la solicitud. Este método devuelve una cadena de registros de solicitud. Puedes enviarla a un socket.

MÉTODOS DE API DE BAJO NIVEL

FCGI::Client::RecordFactory->build_begin_request($reqid, FCGI_RESPONDER, $flags);
Construye el registro FCGI_BEGIN_REQUEST.
FCGI::Client::RecordFactory->build_params($reqid, %$env)
Construye el registro FCGI_PARAMS.
FCGI::Client::RecordFactory->build_stdin($reqid, $content);
Construye el registro FCGI_STDIN.
