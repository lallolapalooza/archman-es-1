DESCRIPCIÓ

N

fcft_from_name2() instancia un nuevo objeto de fuente fcft a partir de los nombres de fuente con formato de FontConfig. El primer elemento en names es la fuente principal, y los elementos restantes (si los hay) son fuentes de

respaldo.

Debes proporcionar al menos un nombre de

fuente.

Todos los aspectos de la fuente (tamaño, DPI, variante, etc.) se configuran a través del nombre de la fuente, usando pares atributo=valor separados por dos puntos (por ejemplo, "Serif:size=26:slant

=italic").

attributes es una forma conveniente de aplicar un conjunto de atributos a todas las fuentes en names. attributes puede ser NULL, en cuyo caso no se añaden atributos extra a las cadenas en names

.

El tamaño de la fuente se establece como parte del nombre de la fuente: por ejemplo, Helvetica:size=12, o Helvetica:pixel

size=12.

Para implementar el escalado de escritorio, simplemente multiplica el tamaño de la fuente por el factor de escalado del

escritorio.

La fuente principal se instanciará inmediatamente, y cualquier fallo al hacerlo resultará en un error. Las fuentes de respaldo se instancian bajo demanda, y cualquier fallo al hacerlo resultará en que esa fuente de respaldo sea ignorada, y se intente la siguiente de la

lista.

Los detalles de renderizado se pueden controlar a través del parámetro options. No debes asignar options tú mismo; usa fcft_font_options_create(3). También puedes pasar NULL; es lo mismo que usar el valor devuelto por fcft_font_options_create(3) directamente, sin modificarl

o (es decir, obtienes la
s opciones predeterminadas).

    int height;
    int descent;
    int ascent;
    struct {
        int x;
        int y;
    } max_advance;
    struct {
        int x;
        int y;
    } space_advance;
    struct {
        int position;
        int thickness;
    } underline;
    struct {
        int position;
        int thickness;
    } strikeout;
}
;

height es la altura de línea, en

píxeles.

descent es la distancia entre la línea base y el glifo descendente más bajo de la fuente, en píxeles. En el caso de fcft, generalmente es positiva (un valor negativo significa que el descent se extiende hacia arriba desde la línea base)

.

ascent es la distancia entre la línea base y el glifo ascendente más alto de la fuente, en píxeles. Generalmente un número positivo (un valor negativo significa que el ascent se extiende hacia abajo debajo de la línea base)

.

ascent + descent es a menudo igual que height, pero no necesariamente. height puede ser mayor, lo que significa que la fuente añade intencionalmente espacio (vertical) extra entre líneas. O puede ser menor, en cuyo caso las líneas se

superponen.

max_advance es la cantidad, en píxeles, que el glifo más ancho de la fuente avanza la posición del lápiz; x para una disposición horizontal, y y para una disposición

vertical.

space_advance es la cantidad, en píxeles, que el glifo para espacio (0x20) avanza la posición del lápiz; x para una disposición horizontal, y y para una disposición

vertical.

underline describe cómo renderizar subrayados. position es la distancia, en píxeles, desde la línea base. Un valor positivo significa sobre la línea base, y un valor negativo significa debajo de la línea base. thickness es el grosor de la línea, en

píxeles.

strikeout describe cómo renderizar tachados. Ver underline para una descr

ipción de s
us miembros.

EJEMPL

O

En este ejemplo, instanciamos Times New Roman a un tamaño de punto de 8 como fuente

principal.

También le decimos que use Serif Bold (tamaño de punto 10) como fuente de respaldo (ten en cuenta que generalmente es mejor dejar que FontConfig maneje el respaldo a fuentes genéricas como esta)

.

Además, ambas fuentes serán Italic, y usarán

DPI=140.

Luego procedemos a renderizar la cadena hello world. Se asume que sabes cómo crear y usar una imagen pixman. Este ejemplo solo muestra cómo se puede usar fcft para instanciar una fuente, rasterizar glifos y luego mezclarlos en una imagen pixman de
