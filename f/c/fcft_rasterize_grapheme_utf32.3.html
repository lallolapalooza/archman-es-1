fcft_rasterize_grapheme_utf32(3) fcft fcft_rasterize_grapheme_utf32(3)

NOMBRE

fcft_rasterize_grapheme_utf32 - rasteriza glifo(s) para un grafema

SINOPSIS

#include <fcft/fcft.h>

const struct fcft_grapheme *fcft_rasterize_grapheme_utf32(

struct fcft_font *fuente, size_t longitud, const uint32_t cluster_grafemico[len], enum fcft_subpixel subpixel);

DESCRIPCIÓN

fcft_rasterize_grapheme_utf32() rasteriza el grafema cluster utilizando la fuente principal, o una de las fuentes de reserva, en fuente.

Cada elemento del cluster es un punto de código Unicode codificado en UTF-32.

Las fuentes se buscan para *todos* los puntos de código del grafema, comenzando por la fuente principal y luego las fuentes de reserva personalizadas, y finalmente las fuentes de reserva proporcionadas por FontConfig.

subpixel te permite especificar qué modo de subpíxel usar. Consulta fcft_rasterize_char_utf32() para obtener más detalles.

VALOR DEVUELTO

En caso de error, se devuelve NULL.

En caso de éxito, se devuelve un puntero a un grafema rasterizado. El grafema se almacena en caché en fcft, lo que hace que las llamadas posteriores con los mismos argumentos sean muy rápidas (es decir, no es necesario que los programas almacenen glifos en caché por sí mismos).

El objeto grafema es administrado por fuente. No es necesario liberarlo explícitamente; se libera cuando se destruye fuente (con fcft_destroy()).

struct fcft_grapheme {
    int cols;
    size_t count;
    const struct fcft_glyph **glyphs;
};

cols es el número de "columnas" que ocupa el glifo (efectivamente, wcswidth(cluster)).

glyphs es una matriz de count glifos rasterizados. Consulta fcft_rasterize_char_utf32() para obtener una descripción de struct fcft_glyph.

VER TAMBIÉN

fcft_destroy(), fcft_rasterize_char_utf32(), fcft_rasterize_text_run_utf32()
