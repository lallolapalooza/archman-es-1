Paquete: fcft

Licencias: MIT

fcft_text_run_destroy(3) fcft fcft_text_run_destroy(3)

NOMBRE

fcft_text_run_destroy - liberar objetos fcft_text_run

SINOPSIS

#include <fcft/fcft.h>

void fcft_text_run_destroy(struct fcft_text_run *run);

DESCRIPCIÓN

fcft_text_run_destroy() libera el objeto fcft_text_run run, que debe haber sido creado con fcft_text_run_rasterize().

Tenga en cuenta que está bien llamar a fcft_destroy() en el objeto de fuente utilizado para rasterizar la ejecución de texto, antes de liberar la ejecución de texto en sí. Es decir, las aplicaciones pueden almacenar en caché ejecuciones de texto más allá del tiempo de vida del objeto de fuente.

run puede ser NULL, en cuyo caso fcft_text_run_destroy() no hace nada.

VER TAMBIÉN

fcft_text_run_rasterize()
