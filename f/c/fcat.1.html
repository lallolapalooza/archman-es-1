FCAT(1) Manual de Comandos Generales FCAT(1)

NOMBRE

fcat - Muestra el contenido de un archivo según su nombre.

SINOPSIS

fcat [-hRsvV] [-f tipo_sistema_archivos ] [-i tipo_imagen ] [-o desplazamiento_imagen ] [-b tamaño_sectores_dispositivo] ruta_del_archivo imagen [imágenes]

DESCRIPCIÓN

fcat abre la(s) imagen(es) nombrada(s) y copia el archivo en la ruta ruta_del_archivo a la salida estándar.

ARGUMENTOS

-f tipo_sistema_archivos
Especifica el tipo de sistema de archivos. Use '-f list' para listar los tipos de sistemas de archivos admitidos. Si no se proporciona, se utilizan métodos de autodetección.
-h
Omite los huecos en archivos dispersos, de modo que la información de dirección absoluta se pierda. Esta opción ahorra espacio al copiar archivos dispersos.
-R
Suprime errores si se está recuperando un archivo eliminado.
-s
Incluye el espacio de holgura en la salida.
-i tipo_imagen
Identifica el tipo de archivo de imagen, como "raw". Use '-i list' para listar los tipos admitidos. Si no se proporciona, se utilizan métodos de autodetección.
-o desplazamiento_imagen
El desplazamiento del sector donde comienza el sistema de archivos en la imagen.
-b tamaño_sectores_dispositivo
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-v
Habilita el modo detallado, la salida a stderr.
-V
Muestra la versión
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
ruta_del_archivo
Ruta del archivo del cual extraer el contenido. Rodee la ruta entre comillas si hay un espacio en el nombre de un archivo o directorio. Use barras diagonales hacia adelante.
