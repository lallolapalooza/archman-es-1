NOMBRE

fcft_set_scaling_filter - configura el filtro a usar al reducir el tamaño de las fuentes de mapas de bits

SINOPSIS

#include <fcft/fcft.h>

bool fcft_set_scaling_filter(enum fcft_scaling_filter filtro);

DESCRIPCIÓN

fcft_set_scaling_filter() configura el filtro a usar al reducir el tamaño de las fuentes de mapas de bits (típicamente fuentes emoji). La configuración afecta a **todas** las instancias de fuente.

Esta función **no** borra las cachés de glifos y, por lo tanto, debe llamarse antes de cualquier llamada a fcft_codepoint_rasterize().

Los valores posibles para filtro son:

  • FCFT_SCALING_FILTER_NONE
  • FCFT_SCALING_FILTER_NEAREST
  • FCFT_SCALING_FILTER_BILINEAR
  • FCFT_SCALING_FILTER_IMPULSE
  • FCFT_SCALING_FILTER_BOX
  • FCFT_SCALING_FILTER_LINEAR
  • FCFT_SCALING_FILTER_CUBIC
  • FCFT_SCALING_FILTER_GAUSSIAN
  • FCFT_SCALING_FILTER_LANCZOS2
  • FCFT_SCALING_FILTER_LANCZOS3
  • FCFT_SCALING_FILTER_LANCZOS3_STRETCHED

FCFT_SCALING_FILTER_NONE deshabilita el filtrado.

FCFT_SCALING_FILTER_NEAREST y FCFT_SCALING_FILTER_BILINEAR son filtros tradicionales, siendo nearest el más rápido.

El resto son filtros de convolución separable.

Si esta función no se llama, fcft utiliza FCFT_SCALING_FILTER_CUBIC por defecto.

VALOR DE RETORNO

En caso de éxito, fcft_set_scaling_filter() devuelve verdadero. En caso de error, devuelve falso.
