fcft_from_name(3)

Paquete: fcft

Licencias: MIT

fcft_from_name(3) fcft fcft_from_name(3)

NOMBRE

fcft_from_name - instanciar una nueva fuente

SINOPSIS

#include <fcft/fcft.h>

struct fcft_font *fcft_from_name(

size_t count, const char *names[static count], const char *attributes);

DESCRIPCIÓN

fcft_from_name() instancia un nuevo objeto de fuente fcft a partir de los nombres de fuente con formato de FontConfig. El primer elemento en names es la fuente principal, y los elementos restantes (si los hay) son fuentes de respaldo.

Debes debes proporcionar al menos un nombre de fuente.

Todos los aspectos de la fuente (tamaño, DPI, variante, etc.) se configuran a través del nombre de la fuente, usando pares atributo=valor separados por dos puntos (por ejemplo, "Serif:size=26:slant=italic").

attributes es una forma conveniente de aplicar un conjunto de atributos a todas las fuentes en names. attributes puede ser NULL, en cuyo caso no se añaden atributos extra a las cadenas en names.

El tamaño de la fuente se establece como parte del nombre de la fuente: por ejemplo, Helvetica:size=12, o Helvetica:pixelsize=12.

Para implementar el escalado del escritorio, simplemente multiplica el tamaño de la fuente por el factor de escalado del escritorio.

La fuente principal se instanciará inmediatamente, y cualquier fallo al hacerlo resultará en un error. Las fuentes de respaldo se instancian bajo demanda, y cualquier fallo al hacerlo resultará en que esa fuente de respaldo sea ignorada, y se intente con la siguiente de la lista.

VALOR DE RETORNO

En caso de éxito, fcft_from_name() devuelve un puntero a un objeto de tipo fcft_font asignado. En caso de error, se devuelve NULL.

struct fcft_font {
    int height;
    int descent;
    int ascent;
    struct {
        int x;
        int y;
    } max_advance;
    struct {
        int x;
        int y;
    } space_advance;
    struct {
        int position;
        int thickness;
    } underline;
    struct {
        int position;
        int thickness;
    } strikeout;
};

height es la altura de línea, en píxeles.

descent es la distancia entre la línea base y el glifo descendente más bajo de la fuente, en píxeles. En el caso de fcft, generalmente es positivo (un valor negativo significa que el descenso se extiende hacia arriba desde la línea base).

ascent es la distancia entre la línea base y el glifo ascendente más alto de la fuente, en píxeles. Generalmente un número positivo (un valor negativo significa que el ascenso se extiende hacia abajo por debajo de la línea base).

ascent + descent es a menudo lo mismo que height, pero no necesariamente. height puede ser mayor, lo que significa que la fuente añade intencionalmente espacio (vertical) extra entre líneas. O puede ser menor, en cuyo caso las líneas se superponen.

max_advance es la cantidad, en píxeles, que el glifo más ancho de la fuente avanza la posición del lápiz; x para una disposición horizontal, y y para una disposición vertical.

space_advance es la cantidad, en píxeles, que el glifo para espacio (0x20) avanza la posición del lápiz; x para una disposición horizontal, y y para una disposición vertical.

underline describe cómo renderizar subrayados. position es la distancia, en píxeles, desde la línea base. Un valor positivo significa por encima de la línea base, y un valor negativo significa por debajo de la línea base. thickness es el grosor de la línea, en píxeles.

strikeout describe cómo renderizar tachados. Ver underline para una descripción de sus miembros.

EJEMPLO

En este ejemplo, instanciamos Times New Roman a un tamaño de punto de 8 como la fuente principal.

También le decimos que use Serif Bold (tamaño de punto 10) como una fuente de respaldo (nota que generalmente es mejor dejar que FontConfig maneje el respaldo a fuentes genéricas como esta).

Además, ambas fuentes serán Italic, y usarán DPI=140.

Luego procedemos a renderizar la cadena hello world. Se asume que sabes cómo crear y usar una imagen pixman. Este ejemplo solo muestra cómo uno puede usar fcft para instanciar una fuente, rasterizar glifos y luego mezclarlos en una imagen pixman de destino.

#include <stdlib.h>
#include <uchar.h>
#include <fcft/fcft.h>
int
main(void)
{
    setlocale(LC_CTYPE, "en_US.UTF-8");
    if (!fcft_set_scaling_filter(FCFT_SCALING_FILTER_LANCZOS3))
       return EXIT_FAILURE;
    struct fcft_font *font = fcft_from_name(
        2,
        (const char *[]){
            "Times New Roman:size=8",
            "Serif:size=10:weight=bold",
        },
        "slant=italic:dpi=140");
    if (font == NULL)
        return EXIT_FAILURE;
    /* Aquí necesitas instanciar una imagen pixman 'objetivo', para mezclar
       con ella */
    pixman_image_t *canvas = ...;
    /* Cadena a imprimir */
    static const char32_t const hello[] = U"hello world";
    /*
     * Posición del lápiz en el lienzo. Los números elegidos aquí son más o menos
     * aleatorios. Sin embargo, ten en cuenta que las llamadas de composición a continuación asumen que 'y'
     * es la línea base de la fuente (y por lo tanto los glifos se renderizarán
     * por encima de 'y')
     */
    struct {
        int x;
        int y;
    } pen = {.x = 25, .y = 50};
    /* Los glifos se renderizarán en blanco */
    pixman_image_t *color = pixman_image_create_solid_fill(
        &(struct pixman_color_t){
            .red = 0xffff,
            .green = 0xffff,
            .blue = 0xffff,
            .alpha = 0xffff,
        });
    for (size_t i = 0; i < sizeof(hello) / sizeof(hello[0]) - 1; i++) {
        const struct fcft_glyph *glyph = fcft_codepoint_rasterize(
            font, hello[i], FCFT_SUBPIXEL_DEFAULT);
        if (glyph == NULL)
            continue;
        /* Kerning */
        long x_kern = 0;
        if (i > 0) {
            fcft_kerning(font, hello[i - 1], hello[i], &x_kern, NULL);
        pen.x += x_kern;
        if (glyph->is_color_glyph) {
            /* El glifo es una imagen pre-renderizada; típicamente un emoji de color */
            pixman_image_composite32(
                PIXMAP_OP_OVER, glyph->pix, NULL, canvas, 0, 0, 0, 0,
                pen.x + glyph->x, pen.y + font->ascent - glyph->y,
                glyph->width, glyph->height);
        }
        else {
            /* El glifo es una máscara alfa */
            pixman_image_composite32(
                PIXMAN_OP_OVER, color, glyph->pix, canvas, 0, 0, 0, 0,
                pen.x + glyph->x, pen.y + font->ascent - glyph->y,
                glyph->width, glyph->height);
        }
        /* Avanzar la posición del lápiz */
        pen.x += glyph->advance.x;
    }
    pixman_image_unref(src);
    fcft_destroy(font);
    return EXIT_SUCCESS;
}
