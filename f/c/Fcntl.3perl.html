Fcntl(3perl) Guía del programador de Perl Fcntl(3perl)

NOMBRE

Fcntl - constantes de varias banderas y funciones de ayuda de fcntl.h de C

SINOPSIS

use Fcntl;
use Fcntl qw(:DEFAULT :flock);
use Fcntl qw(F_GETFD F_SETFD FD_CLOEXEC);

DESCRIPCIÓN

Este módulo proporciona banderas y funciones de ayuda para usar con "chmod" en perlfunc (S_*), "fcntl" en perlfunc (F_*), "flock" en perlfunc (LOCK_*), "seek" en perlfunc (SEEK_*), "stat" en perlfunc (S_*), "sysopen" en perlfunc (O_*), y "sysseek" en perlfunc (SEEK_*). Corresponden a las macros C definidas en fcntl.h.

No todos los símbolos están disponibles en todos los sistemas. Excepto donde se indique lo contrario, las constantes y funciones proporcionadas por este módulo lanzarán una excepción en tiempo de ejecución si la macro C correspondiente no está disponible. Consulte la documentación de su sistema para ver la descripción completa de cada símbolo y si está disponible en su plataforma: chmod(2), fcntl(2), flock(2), lseek(2), open(2), stat(2).

(En particular, algunos de los símbolos F_* no son portátiles ya que solo existen en una única plataforma o requieren que se pasen estructuras de datos C específicas del sistema como tercer argumento a "fcntl", lo que no se puede construir de forma portable en Perl puro.)

Symbols for use with "flock"

"LOCK_EX"
Exclusive lock. (This is mutually exclusive with "LOCK_SH".)
"LOCK_NB"
Non-blocking lock. If the lock cannot be acquired immediately, the call returns with an error. This flag is combined with either "LOCK_EX" or "LOCK_SH" using the bitwise OR operator. (e.g., "LOCK_EX | LOCK_NB") (See also "LOCK_MAND".)
"LOCK_SH"
Shared lock. (This is mutually exclusive with "LOCK_EX".)
"LOCK_UN"
Unlock the file.
"LOCK_MAND"
(Mandatory locking.) This flag is combined with "LOCK_EX", "LOCK_SH", or "LOCK_NB" using the bitwise OR operator. If the flag is present, locks are managed by the kernel as specified by POSIX. If the flag is absent, locks are managed by the "flock" program itself (like NFS locking).
"LOCK_READ"
With "LOCK_MAND": Allow concurrent reads.
"LOCK_RW"
With "LOCK_MAND": Allow concurrent reads and writes.
"LOCK_WRITE"
With "LOCK_MAND": Allow concurrent writes.

DESCRIPTION

The Fcntl module provides access to the Perl constants used by the fcntl(), open(), and ioctl() system calls.

It also provides a number of convenience functions that are useful for checking the file type of a file descriptor.

S_IFMT

This function extracts the file type from a mode. It is equivalent to "(mode & S_IFMT)".

S_IFSOCK

Socket file type.

S_IFLNK

Symbolic link file type.

S_IFREG

Regular file type.

S_IFBLK

Block special file type.

S_IFDIR

Directory file type.

S_IFCHR

Character special file type.

S_IFFIFO

FIFO (named pipe) file type.

S_IFWHT

Whiteout file type.

S_ISUID

Permissions: Set effective user ID from file (when running executables).

S_ISGID

Permissions: Set effective group ID from file (when running executables); mandatory locking (on non-group-executable files); new files inherit their group from the directory (on directories).

S_ISVTX

Permissions: Files in this directory can only be deleted/renamed by their owner (or the directory's owner), even if other users have write permissions to the directory ("sticky bit").

S_IREAD

Permissions: Read by owner. Equivalent to "S_IRUSR".

S_IWRITE

Permissions: Write by owner. Equivalent to "S_IWUSR".

S_IEXEC

Permissions: Execute by owner. Equivalent to "S_IXUSR".

S_IRWXU

Permissions: Read, write, and execute by owner.

S_IRUSR

Permissions: Read by owner.
