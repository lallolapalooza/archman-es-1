NOMBRE

FcPatternBuild, FcPatternVaBuild, FcPatternVapBuild - Crear patrones a partir de argumentos

SINOPSIS

#include <fontconfig/fontconfig.h>

FcPattern * FcPatternBuild (FcPattern *patrón, ...);

FcPattern * FcPatternVaBuild (FcPattern *patrón, va_list va);

void FcPatternVapBuild (FcPattern *resultado, FcPattern *patrón, va_list va);

DESCRIPCIÓN

Construye un patrón utilizando una lista de objetos, tipos y valores. Cada valor que se va a introducir en el patrón se especifica con tres argumentos:

1.
Nombre del objeto, una cadena que describe la propiedad a añadir.
2.
Tipo del objeto, uno de los valores enumerados de FcType
3.
Valor, no un FcValue, sino el tipo crudo tal como se pasa a cualquiera de las funciones FcPatternAdd<tipo>. Debe coincidir con el tipo del segundo argumento.

La lista de argumentos se termina con un nombre de objeto nulo; no es necesario pasar ni un tipo de objeto ni un valor para esto. Los valores se añaden a `patrón', si `patrón' es nulo, se crea un nuevo patrón. En cualquier caso, se devuelve el patrón. Ejemplo:

patrón = FcPatternBuild (0, FC_FAMILY, FcTypeString, "Times", (char *) 0);

FcPatternVaBuild se utiliza cuando los argumentos ya están en forma de valor varargs. FcPatternVapBuild es una versión macro de FcPatternVaBuild que devuelve su resultado directamente en la variable resultado.
