FCGI::Client(3pm) Documentación de Perl aportada por el usuario FCGI::Client(3pm)

NOMBRE

FCGI::Client - biblioteca cliente para el protocolo fastcgi

SINOPSIS

use FCGI::Client;
my $sock = IO::Socket::INET->new(
    PeerAddr => '127.0.0.1',
    PeerPort => $port,
) or die $!;
my $client = FCGI::Client::Connection->new( sock => $sock );
my ( $stdout, $stderr ) = $client->request(
    +{
        REQUEST_METHOD => 'GET',
        QUERY_STRING   => 'foo=bar',
    },
    ''
);

DESCRIPCIÓN

FCGI::Client es una biblioteca cliente para el protocolo fastcgi.
