FCEUX-NET-SERVER(6) Manual de Juegos FCEUX-NET-SERVER(6)

NOMBRE

fceux-net-server - Servidor de juegos FCE Ultra

SINOPSIS

fceux-net-server [opciones]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando fceux-net-server.

fceux-net-server es el servidor de juegos para el uso multijugador de la familia de emuladores NES FCE Ultra. Este servidor buscará primero en /etc/fceux-server.conf las opciones. Si ese archivo no existe, utilizará los valores predeterminados indicados aquí. Cualquier argumento proporcionado directamente anulará cualquier valor predeterminado.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --help
Muestra un mensaje de ayuda.
-v, --version
Muestra el número de versión y sale.
-p, --port
Inicia el servidor en el puerto dado (predeterminado = 4046).
-w, --password
Especifica una contraseña para la entrada.
-m, --maxclients
Especifica el número máximo de clientes permitidos para acceder al servidor (predeterminado = 100).
-t, --timeout
Especifica el número de segundos antes de que el servidor expire (predeterminado = 5).
-f, --framedivisor
Especifica el divisor de fotogramas, que controla el número de actualizaciones enviadas al cliente; calculado como: 60 / divisor_de_fotogramas = actualizaciones por segundo (predeterminado = 1).
-c, --configfile
Carga el archivo de configuración dado (predeterminado = /etc/fceux-server.conf).
