NOMBRE

FcFontList - Lista de fuentes

SINOPSIS

#include <fontconfig/fontconfig.h>

FcFontSet * FcFontList (FcConfig *config, FcPattern *p, FcObjectSet *os);

DESCRIPCIÓN

Selecciona fuentes que coincidan con p, crea patrones a partir de esas fuentes que contengan solo los objetos en os y devuelve el conjunto de patrones únicos de este tipo. Si config es NULL, se comprueba que la configuración predeterminada esté actualizada y se utiliza.
