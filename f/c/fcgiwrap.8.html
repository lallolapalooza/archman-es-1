FCGIWRAP(8) Manual del Administrador del Sistema FCGIWRAP(8)

NOMBRE

fcgiwrap - servir aplicaciones CGI sobre FastCGI

SINOPSIS

fcgiwrap [OPCIONES]

DESCRIPCIÓN

fcgiwrap es un servidor simple para ejecutar aplicaciones CGI sobre FastCGI. Espera proporcionar soporte CGI limpio a Nginx (y a otros servidores web que puedan necesitarlo).

OPCIONES

-c número
Número de procesos fcgiwrap para pre-lanzar (prefork).
-f
Redirigir la salida STDERR de la CGI ejecutada a través de FastCGI para que aparezca en el log de errores del servidor web. De lo contrario, se devolvería en el STDERR de fcgiwrap, que podría ser redirigido. Si se ejecuta a través de spawn-fcgi, el STDERR de fcgiwrap se envía a /dev/null, por lo que esta opción proporciona una forma de recuperar esa salida.
-s url_socket
Una URL para el socket de escucha al que enlazarse. Por defecto, fcgiwrap espera que se le pase un socket de escucha en el descriptor de archivo 0, coincidiendo con la convención de FastCGI. La forma recomendada de desplegar fcgiwrap es ejecutarlo bajo un gestor de procesos que se encargue de abrir el socket. Sin embargo, para configuraciones simples y pruebas puntuales se puede utilizar esta opción. Las url_socket válidas incluyen unix:/ruta/al/socket/unix, tcp:punto.dots.cuad.ru.po:puerto y tcp6:[dir_ipv6]:puerto.
-h
Mostrar un mensaje de ayuda y salir.

ENTORNO

Al ejecutarse, fcgiwrap evalúa estas variables de entorno establecidas por el servidor web que llama a un script fcgi. Las variables DOCUMENT_ROOT y SCRIPT_NAME se concatenarán y el ejecutable resultante se ejecutará como un script CGI encapsulado como FastCGI, con el resto después del nombre del script disponible como PATH_INFO. Para deshabilitar el procesamiento de PATH_INFO, configure su servidor web para pasar SCRIPT_FILENAME, que debería contener la ruta completa al script. Entonces PATH_INFO no será modificado.

DOCUMENT_ROOT

directorio en el que reside el script
SCRIPT_NAME
ejecutable real
SCRIPT_FILENAME
ruta completa al script CGI. Cuando se establece, anula DOCUMENT_ROOT y SCRIPT_NAME

EJEMPLO

La forma más rápida de ver fcgiwrap haciendo algo es lanzarlo en la línea de comandos así:
fcgiwrap -s unix:/var/run/fcgiwrap.sock
Aparte de posibles problemas de permisos, etc., debería estar listo para aceptar peticiones FastCGI y ejecutar scripts CGI.

Lo más probable es que desee lanzar fcgiwrap con spawn-fcgi utilizando una configuración como esta:

FCGI_SOCKET=/var/run/fcgiwrap.sock
FCGI_PROGRAM=/usr/sbin/fcgiwrap
FCGI_USER=nginx
FCGI_GROUP=www
FCGI_EXTRA_OPTIONS="-M 0700"
ALLOWED_ENV="PATH"

Nginx puede configurarse para que el CGI arbitrario cgit se ejecute como FastCGI de la siguiente manera:

location / {
fastcgi_param DOCUMENT_ROOT /var/www/localhost/htdocs/cgit/;
fastcgi_param SCRIPT_NAME cgit;
fastcgi_pass unix:/var/run/fastcgi.sock;
}
