NOMBRE

fc-cat - leer archivos de caché de información de fuentes

SINOPSIS

fc-cat [ -rvVh ] [ --recurse ] [ --verbose ] [ --version ] [ --help ]
[ archivos-de-caché-%version%-archivos | directorios ... ]

DESCRIPCIÓN

fc-cat lee la información de las fuentes de los archivos de caché o relacionada con directorios de fuentes y la emite en formato ASCII.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-r --recurse
Recursivamente en subdirectorios.
-v --verbose
Detallado.
-h --help
Mostrar resumen de opciones.
-V --version
Mostrar la versión del programa y salir.
