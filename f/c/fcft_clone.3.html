NOMBRE

fcft_clone - copiar una fuente ya instanciada

SINOPSIS

#include <fcft/fcft.h>

struct fcft_font *fcft_clone(const struct fcft_font *font);

DESCRIPCIÓN

fcft_clone() crea una nueva instancia copiando font. fcft utiliza internamente el recuento de referencias, lo que hace que esta operación sea muy rápida (mucho más rápida que instanciar explícitamente una nueva fuente usando fcft_from_name()).

Para liberar todos los recursos asociados tanto a la fuente original como a la fuente clonada, se debe llamar a fcft_destroy() tanto para la fuente original como para el clon.

VALOR DE RETORNO

En caso de éxito, fcft_clone() devuelve un puntero a un nuevo objeto fcft_font. En caso de error, devuelve NULL.

VER TAMBIÉN

fcft_from_name(), fcft_from_name2(), fcft_destroy()
