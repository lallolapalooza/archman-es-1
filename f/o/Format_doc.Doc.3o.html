Tipo de documento inmutable

type ('a, 'b) fmt = ('a, t, t, 'b) format4

type printer0 = t -> t

type 'a printer = 'a -> printer0

val empty : t

Documento vacío

val format : Format.formatter -> t -> unit

format ppf doc envía la instrucción de formato de doc al formateador doc de Format.

val fold : ('acc -> element -> 'acc) -> 'acc -> t -> 'acc

Itera sobre un documento como una secuencia de instrucciones

val msg : ('a, t) fmt -> 'a

Format_doc.Doc.msg y Format_doc.Doc.kmsg producen un documento a partir de una cadena de formato y su argumento

val kmsg : (t -> 'b) -> ('a, 'b) fmt -> 'a

val printf : ('a, printer0) fmt -> 'a

Format_doc.Doc.printf y Format_doc.Doc.kprintf producen un `printer` a partir de una cadena de formato y su argumento

val kprintf : (t -> 'b) -> ('a, t -> 'b) fmt -> 'a

val open_box : box_type -> int -> printer0

Funciones de alineación

val align_prefix : (t * int) list -> t list

Alinea el lado derecho de una caja de etiqueta "@{<ralign>...@}" insertando espacios al principio de las cajas. Estas funciones no hacen nada si la caja de etiqueta aparece después de una sugerencia de salto.
