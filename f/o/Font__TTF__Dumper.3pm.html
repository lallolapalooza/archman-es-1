Font__TTF__Dumper(3pm)

Paquete: perl-font-ttf

Licencias: Artistic2.0

Font::TTF::Dumper(3) Documentación de Perl contribuida por el usuario Font::TTF::Dumper(3)

NOMBRE

Font::TTF::Dumper - Volcado de depuración de una estructura de datos de fuente, evitando la recursión en ' PARENT'

SINOPSIS

use Font::TTF::Dumper;

# Imprime una tabla de la estructura de la fuente:
print ttfdump($font->{$tag});

# Imprime una tabla de fuente con nombre
print ttfdump($font->{'head'}, 'head');

# Imprime una tabla de fuente con nombre y otras opciones
print ttfdump($font->{'head'}, 'head', %opts);
# Imprime los datos de un glifo:
print ttfdump($font->{'loca'}->read->{'glyphs'}[$gid], "glyph_$gid");

DESCRIPCIÓN

Las estructuras de datos de Font::TTF son árboles creados a partir de hashes y arrays. Al intentar averiguar cómo funcionan las estructuras, a veces es útil usar Data::Dumper en ellas. Sin embargo, muchas de las estructuras de objetos tienen enlaces ' PARENT' que se refieren al padre del objeto, lo que significa que Data::Dumper termina volcando toda la fuente sin importar qué.

El propósito principal de este módulo es invocar Data::Dumper con un filtro que omite el elemento ' PARENT' de cualquier hash.

Para reducir aún más la salida, este módulo también omite los elementos ' CACHE' y cualquier elemento hash cuyo valor sea un objeto Font::TTF::Glyph o Font::TTF::Font. (Realmente debería hacer esto configurable).

Si $opts{'d'}, entonces establece el modo Deepcopy para minimizar el uso de referencias cruzadas.
