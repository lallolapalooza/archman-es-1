Módulo Format_doc

Documento componible para el motor de formato Format.

Este módulo introduce un tipo de documento puro e inmutable que representa una secuencia de instrucciones de formato para ser impresas por un motor de formato en un momento posterior. Al mismo tiempo, también proporciona un intérprete de cadenas de formato que produce este tipo de documento a partir de cadenas de formato y sus impresoras asociadas.

El módulo está diseñado para ser compatible a nivel de código fuente con el código que define las impresoras de formato: reemplazar `Format` por `Format_doc` en tu código convertirá las impresoras de `Format` a impresoras de `Format_doc`.

API de compatibilidad

Las funciones y tipos a continuación proporcionan compatibilidad a nivel de código fuente con impresoras de formato y funciones de conversión de impresoras de Format_doc a Format. La dirección inversa se implementa utilizando una escotilla de escape en la instrucción de formato y solo debe usarse para preservar la compatibilidad con versiones anteriores.

pp_two_columns

pp_two_columns ?pp_sep ?max_lines ppf l prints a list of pairs in two columns.

  • pp_sep is the separator string between the two columns (default is " | ").
  • max_lines can be used to indicate a maximum number of lines to print -- an ellipsis gets inserted at the middle if the input has too many lines.

Example:

pp_two_columns ~max_lines:3 Format.std_formatter [ "abc", "hello"; "def", "zzz"; "a", "bllbl"; "bb", "dddddd"; ]

prints

abc | hello ... bb | dddddd
