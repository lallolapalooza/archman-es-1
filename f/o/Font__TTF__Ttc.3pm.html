NOMBRE

Font::TTF::Ttc - Clase para colecciones Truetype

DESCRIPCIÓN

Una colección TrueType es una colección de fuentes TrueType en un archivo en el que las tablas pueden ser compartidas entre diferentes directorios. Para soportar esto, la TTC introduce el concepto de una tabla compartida por diferentes fuentes TrueType. Esto plantea la pregunta de qué debe suceder con la propiedad ' PADRE' de una tabla en particular. Se hace que apunte al primer objeto de directorio que la referencia. Por lo tanto, la aplicación debe resolver cualquier confusión. La confusión solo ocurre si las tablas compartidas requieren acceso a tablas no compartidas. Esto no debería suceder ya que las tablas compartidas se ocupan solo de la información de glifos y las tablas privadas se ocupan de la codificación y la identificación de glifos. Por lo tanto, la dirección general es de la identificación al glifo y no a la inversa (al menos no sin conocer el contexto particular).

VARIABLES DE INSTANCIA

Las siguientes variables de instancia van precedidas de un espacio

fname (P)
Nombre del archivo para esta Colección TrueType
INFILE (P)
El manejador de archivo de esta colección

La siguiente variable de instancia no comienza con un espacio

directs
Un array de directorios (objetos Font::TTF::Font) para cada sub-fuente en el directorio

MÉTODOS

Font::TTF::Ttc->open($fname)

Abre y lee el nombre de archivo dado como una Colección TrueType. Leer una colección implica leer cada uno de los directorios que componen la colección.

$c->read

Lee una Colección leyendo todos los directorios de la colección

$c->find($direct, $name, $check, $off, $len)

Busca para ver si una tabla con las características dadas de nombre, checksum, offset y longitud ha sido asociada con un directorio anteriormente en la lista. En realidad, solo verifica el offset ya que ninguna tabla puede compartir el mismo offset en una fuente TrueType, colecciones o de otro tipo.

$c->DESTROY

Cierra cualquier archivo abierto por nosotros
