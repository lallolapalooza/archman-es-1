NOMBRE

Font::TTF::Hdmx - Métricas de dispositivo horizontal

DESCRIPCIÓN

La tabla consta de un hash de tablas de métricas de dispositivo indexado por el ppem para esa subtabla. Cada subtabla consta de una matriz de anchos de avance en píxeles para cada glifo en ese ppem (horizontalmente).

VARIABLES DE INSTANCIA

Las métricas individuales se acceden utilizando la siguiente referencia:

$f->{'hdmx'}{$ppem}[$glyph_num]

Además, hay una variable de instancia:

Num
Número de tablas de dispositivo.

MÉTODOS

$t->read

Lee la tabla en estructuras de datos

$t->out($fh)

Emite las métricas de dispositivo para esta fuente

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla. Si es menor que este, entonces la tabla debe estar corrupta y debe eliminarse o lo que sea.

$t->tables_do(&func)

Para cada subtabla llama a &sub($ref, $ppem)

$t->XML_element($context, $depth, $key, $value)

Emite métricas de dispositivo de una manera un poco más ordenada

ERRORES
