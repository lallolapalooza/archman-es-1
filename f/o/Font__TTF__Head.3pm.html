Font::TTF::Head(3) Documentación de Perl aportada por el usuario Font::TTF::Head(3)

NOMBRE

Font::TTF::Head - La tabla head de una fuente TTF

DESCRIPCIÓN

Esta es una tabla muy básica con solo variables de instancia como se describe en la documentación de TTF, utilizando los mismos nombres. Una de las más comúnmente utilizadas es "unitsPerEm".

VARIABLES DE INSTANCIA

La tabla "head" no tiene variables de instancia internas más allá de las comunes a todas las tablas y las especificadas en el estándar:

version
fontRevision
checkSumAdjustment
magicNumber
flags
unitsPerEm
created
modified
xMin
yMin
xMax
yMax
macStyle
lowestRecPPEM
fontDirectionHint
indexToLocFormat
glyphDataFormat

Las dos fechas se conservan como un array de dos unsigned longs (32 bits)

MÉTODOS

$t->read

Lee la tabla en memoria gracias a algunas funciones de utilidad

$t->out($fh)

Escribe la tabla en un archivo, ya sea desde memoria o copiándola. Si está en memoria (que suele ser el caso) el campo checkSumAdjustment se establece en 0, según el valor predeterminado si no se considera la suma de verificación del archivo.

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla. Si es menor que esto, entonces la tabla debe estar corrupta y debería eliminarse o algo parecido.

$t->XML_element($context, $depth, $key, $value)

Maneja el proceso de fechas para el exportador XML

$t->update

Actualiza la tabla head basándose en los datos de los glifos y la tabla hmtx

$t->getdate($is_create)

Convierte la hora de modificación de la fuente (o la hora de creación si se establece $is_create) a un entero de 32 bits como el devuelto por time(). Devuelve undef si el valor está fuera de rango, ya sea antes de la época o después de la hora máxima almacenable.

$t->setdate($time, $is_create)

Establece la información de hora para la modificación (o la hora de creación si se establece $is_create) según la información de hora de 32 bits.
