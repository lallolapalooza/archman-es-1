- La tabla princ

DESCRIPCIÓ

N

La tabla Silf contiene el núcleo de las reglas de Graphite para una fuente. Una tabla Silf tiene potencialmente múltiples subtab

las silf, aunque normalmente solo hay una. Dentro de una subtabla silf, hay un número de pasadas que contienen las máquinas de
estado finito reales para hacer coincidir reglas y el código de restricción y acción que se ejecutará cuando una regla coincida.

@opcodes

Cada array contiene el nombre del código de operación, el número de bytes del operando y una cadena que describe los operandos. Los caracteres en la cadena tienen el siguiente significado:

c - byte menos significativo del id de clase
C - byte más significativo del id de clase
f - índice de característica
g - byte menos significativo del id de atributo de glifo
G - byte más significativo del id de atributo de glifo
l - byte menos significativo de una extensión de 32 bits a un número de 16 bits
L - byte más significativo de un número de 32 bits
m - id de métrica de glifo
n - byte menos significativo de un número
N - byte más significativo de un número de 16 bits
o - desplazamiento (salto)
s - referencia de slot
S - id de atributo de slot
v - número variable de argumentos siguientes
