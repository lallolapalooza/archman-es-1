NOMBRE

Font::TTF::Segarr - Array segmentado

DESCRIPCIÓN

Almacena datos ya sea directamente o indirectamente como una serie de arrays. Esta clase se encarga del conjunto de arrays y enmascara los sub-arrays individuales, ahorrando así una clase, esperamos.

VARIABLES DE INSTANCIA

Todas las variables de instancia no comienzan con un espacio.

El array segmentado es simplemente un array de segmentos

Cada segmento es un asunto más complejo:

INICIO
En términos del array, la dirección para el elemento 0 en este segmento.
LONGITUD
Número de elementos en este segmento
VALOR
El array que contiene los elementos

MÉTODOS

Font::TTF::Segarr->new($size)

Crea un nuevo array segmentado con un tamaño de datos dado

$s->fastadd_segment($start, $is_sparse, @dat)

Crea un nuevo segmento y lo añade al array asumiendo que no hay solapamiento entre el nuevo segmento y ningún otro en el array. $is_sparse indica si el array pasado contiene "undef"s o no. Si es falso no se realiza ninguna comprobación (lo que es más rápido, pero más arriesgado). Si es igual a 2, entonces 0 también se considera undef.

Devuelve el número de segmentos insertados.

$s->add_segment($start, $overwrite, @dat)

Crea un nuevo segmento y lo añade al array permitiendo posibles solapamientos entre el nuevo segmento y los existentes. En caso de solapamientos, se eliminan los elementos del nuevo segmento a menos que $overwrite esté establecido, en cuyo caso se sobrescriben los elementos ya existentes.

Este método también comprueba los datos entrantes para ver si son esparsos (es decir, contienen valores indefinidos). Los huecos provocan la creación de nuevos segmentos o que no se sobrescriban los valores existentes.

$s->tidy

Fusiona cualquier segmento inmediatamente adyacente

$s->at($addr, [$len])

Busca los datos almacenados en la dirección dada localizando el segmento apropiado, etc. Si $len > 1, devuelve un array de valores, rellenando los espacios con undef.

$s->remove($addr, [$len])

Elimina el elemento o elementos de la dirección devolviéndolos como un array o el primer valor en un contexto escalar. Esto es muy parecido a "at", incluyendo el relleno con undef, pero elimina cosas a medida que avanza.

$s->copy

Copia profundamente este array

$s->copy_seg($seg)

Crea una copia profunda de un segmento
