Font::TTF::GrFeat(3) Documentación de Perl contribuida por el usuario Font::TTF::GrFeat(3)

NOMBRE

Font::TTF::GrFeat - Características de fuentes Graphite

DESCRIPCIÓN

VARIABLES DE INSTANCIA

version
features
Un array de hashes de la siguiente forma
feature
número de ID de característica
name
índice de nombre en la tabla de nombres
exclusive
bandera exclusiva
default
el número de configuración predeterminado
settings
hash del número de configuración contra el índice de cadena de nombre

MÉTODOS

$t->read

Lee las características del archivo TTF en memoria

$t->out($fh)

Escribe las características en un archivo TTF

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla. Si es menor que esto, entonces la tabla está mal y debe ser eliminada o lo que sea.

$t->print($fh)

Imprime una representación legible por humanos de la tabla

$t->tag_to_num ($feat_str)

Convierte una etiqueta de ID de característica alfanumérica (cadena) a un número (32 bits). Las etiquetas suelen tener 4 caracteres. Graphite ignora el relleno de espacios si está presente, así que hacemos lo mismo aquí.

$t->num_to_tag ($feat_num)

Convierte un número de ID de característica (32 bits) de nuevo a una etiqueta (cadena). Se elimina el relleno de espacios o nulos al final. Los números de ID de característica que no representan etiquetas alfanuméricas se devuelven sin cambios.

ERRORES

La tabla Feat versión 1 termina con una característica (ID 1) llamada NoName con cero configuraciones pero con un desplazamiento a la última entrada del array de configuraciones. Esta última configuración tiene ID 0 y un ID de nombre no válido. Esta última característica se modifica para tener una configuración.
