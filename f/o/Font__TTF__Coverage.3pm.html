NOMBRE

Font::TTF::Coverage - Objetos de definición de clase y cobertura Opentype

DESCRIPCIÓN

Las tablas de cobertura y los objetos de definición de clase son conceptos prácticamente idénticos en OpenType. Su diferencia radica puramente en su almacenamiento. Por lo tanto, podemos decir que una tabla de cobertura es una definición de clase en la que la definición de clase para cada glifo es el índice correspondiente en la tabla de cobertura. La estructura de datos resultante es que una tabla de Cobertura tiene los siguientes campos:

cover
Un booleano para indicar si esta tabla es una tabla de cobertura (VERDADERO) o una definición de clase (FALSO)
val
Un hash de ids de glifos contra valores (índice de cobertura o valor de clase)
fmt
El formato de almacenamiento utilizado se indica aquí, pero se recalcula cuando se escribe la tabla.
count
Un contador de los elementos en una tabla de cobertura para usar con `add`. Cada adición subsiguiente se añade con el contador actual y se incrementa el contador.
max
Valor máximo de clase en una tabla de clases.

MÉTODOS

new($isCover [, vals])

Crea una nueva tabla de cobertura o tabla de definición de clase, dependiendo del valor de $isCover. Si $isCover es verdadero, `vals` puede ser una lista de glifos a incluir en orden. Si $isCover es falso, entonces `vals` es un hash de glifos contra valores de clase.

read($fh)

Lee la tabla de cobertura/clase del manejador de archivo proporcionado.

out($fh, $state)

Escribe la tabla de cobertura/clase en el manejador de archivo proporcionado. Si $state es 1, entonces la cadena de salida se devuelve en lugar de ser enviada a un manejador de archivo.

$c->add($glyphid[, $class])

Añade un id de glifo a la tabla de cobertura o clase. Devuelve el índice o el número de clase del glifo añadido.

$c->signature

Devuelve un vector de todos los ids de glifos cubiertos por esta tabla de cobertura o clase.

@map=$c->sort

Ordena la tabla de cobertura de modo que los índices estén en orden ascendente de id de glifo. Devuelve un mapa tal que $map[$nuevo_índice]=$índice_antiguo.

$c->out_xml($context)

Imprime esta cobertura/clase en formato XML.
