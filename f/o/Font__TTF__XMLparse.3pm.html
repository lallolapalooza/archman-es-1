Font::TTF::XMLparse(3) Documentación de Perl contribuida por usuarios Font::TTF::XMLparse(3)

NOMBRE

Font::TTF::XMLparse - proporciona soporte para el análisis XML. Requiere el módulo Expat XML::Parser::Expat

SINOPSIS

use Font::TTF::Font;
use Font::TTF::XMLparse;
$f = Font::TTF::Font->new;
read_xml($f, $ARGV[0]);
$f->out($ARGV[1]);

DESCRIPCIÓN

Este módulo contiene las rutinas de soporte para el análisis de XML y la generación de las estructuras de fuentes Truetype como resultado. El módulo se ha separado del resto del paquete para reducir la dependencia que esto traería, de todo el paquete en XML::Parser. De esta manera, las personas sin XML::Parser aún pueden usar el resto del paquete.

El paquete interactúa con otro paquete a través del uso de un contexto que contiene un elemento 'receptor' que es un objeto que posiblemente puede recibir uno de los siguientes mensajes:

XML_start
Este mensaje se llama cuando ocurre una etiqueta de apertura. Se llama con el contexto, el nombre de la etiqueta y los atributos. El valor de retorno no tiene significado.
XML_end
Este mensaje se llama cuando ocurre una etiqueta de cierre. Se llama con el contexto, el nombre de la etiqueta y los atributos (retenidos desde cuando se abrió la etiqueta). Hay 3 valores de retorno posibles para dicho mensaje:
undef
Este es el valor de retorno predeterminado que indica que se debe realizar un procesamiento predeterminado, en el que el elemento actual en el árbol, o el texto de este elemento, se almacenará en el objeto padre.
$context
Este valor mágico marca que el elemento debe ser eliminado del padre. No se almacena nada en el padre. (Esto en lugar de '' se utiliza para permitir devoluciones de 0.)
cualquier cosa
Cualquier otra cosa se toma como el contenido del elemento que se almacenará en el padre.

Además, el hash de contexto pasado a estos mensajes contiene las siguientes claves:

xml
Este es el objeto xml de expat. El contexto también está disponible como $context->{'xml'}{' mycontext'}. ¡Pero esa es una forma larga y tediosa de no decir mucho!
font
Este es el objeto base que se pasó para el análisis de XML.
receptor
Esto contiene el receptor actual de eventos de análisis. Puede ser configurado en la aplicación asociada para ajustar qué objetos deben recibir mensajes cuándo. También se almacena en la pila de análisis para asegurar que donde un objeto lo cambia durante XML_start, ese mismo objeto que recibió XML_start recibirá el XML_end correspondiente.
pila
Esta es la pila de análisis, utilizada internamente para mantener el receptor y los atributos actuales para cada elemento abierto, como una jerarquía completa hasta el elemento raíz.
arbol
Este elemento contiene el árbol de almacenamiento correspondiente al padre de cada elemento en la pila. La acción predeterminada es empujar undef en esta pila durante XML_start y luego resolverlo, ya sea en la aplicación asociada (cambiando $context->{'tree'}[-1]) o durante XML_end de un elemento hijo, momento en el cual sabemos si estamos tratando con una matriz o un hash o qué.
texto
El procesamiento de caracteres consiste en insertar todos los caracteres en el elemento de texto del contexto para su uso posterior.
