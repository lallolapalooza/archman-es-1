NOMBRE

Font::TTF::OTTags - Utilidades para etiquetas TrueType/OpenType

SINOPSIS

use Font::TTF::OTTags qw( %tttags %ttnames %iso639 readtagsfile );

# Ver elementos integrados:
$script_tag = $tttags{'SCRIPT'}{'Cypriot Syllabary'};  # devuelve 'cprt'
$lang_name = $ttnames{'LANGUAGE'}{'ALT '};             # devuelve 'Altai'

# Mapear etiqueta iso639-2 a/desde etiqueta de idioma OT
@isotags = $iso639{'ALT '};    # devuelve [ 'atv', 'alt' ]
$lang_tag = $iso639{'atv'};    # devuelve 'ALT '

# Leer el último archivo de etiquetas para añadir a las definiciones integradas
readtagsfile ("C:\\Program Files\\Microsoft VOLT\\TAGS.txt");

Las claves de primer nivel para %tttags y %ttnames son:

SCRIPT
recuperar etiqueta o nombre de script
LANGUAGE
recuperar etiqueta o nombre de idioma
FEATURE
recuperar etiqueta o nombre de característica

Los datos integrados se han derivado del borrador del 11 de julio de 2014 de la 3ª edición de ISO/IEC 14496-22 (Tecnología de la información - Codificación de objetos audiovisuales - Parte 22: Formato Open Font), que, cuando se finalice y apruebe, reemplazará a la segunda edición (ISO/IEC 14496-22:2009).

MÉTODOS

readtagsfile ( nombre_archivo )

Lee un archivo en la sintaxis de Tags.txt (incluido con Microsoft VOLT) para obtener definiciones de etiquetas adicionales/reemplazadas.

Devuelve 0 si no puede abrir el archivo; de lo contrario, 1.
