NOMBRE

Font::TTF::Post - Contiene los nombres Postscript de cada glifo

DESCRIPCIÓN

Contiene los nombres postscript para los glifos. Ten en cuenta que no se almacenan como un array, sino como índices en dos listas. La primera lista es la lista estándar de nombres Postscript definida por el estándar TrueType. La segunda proviene de la propia fuente.

Buscar un glifo a partir de un nombre Postscript o un nombre a partir de un número de glifo se logra a través de métodos en lugar de la búsqueda de variables.

Esta clase maneja los tipos de tabla PostScript 1, 2, 2.5 y 3, pero no el tipo 4. El soporte para la versión 2.5 es según la especificación de Apple y no de MS.

La forma de buscar nombres Postscript o glifos es:

$pname = $f->{'post'}{'VAL'}[$gnum];
$gnum = $f->{'post'}{'STRINGS'}{$pname};

VARIABLES DE INSTANCIA

Debido a que los diferentes sistemas tienen diferentes limitaciones, hay varias variables de clase disponibles para controlar qué tipos de tabla post se pueden escribir.

$Font::TTF::Post::no25
Si está configurado, le indica a Font::TTF::Post::out que use el tipo de tabla 2 en lugar del 2.5 en caso de que las aplicaciones no puedan manejar la versión 2.5.
VAL
Contiene un array indexado por número de glifo de nombres Postscript. Esto se utiliza al escribir una fuente.
STRINGS
Un array asociativo de nombres Postscript que mapean al glifo más alto con ese nombre. Estos pueden no estar sincronizados con VAL.

Además, están las variables introductorias estándar definidas en el estándar:

FormatType
italicAngle
underlinePosition
underlineThickness
isFixedPitch
minMemType42
maxMemType42
minMemType1
maxMemType1

MÉTODOS

$t->read

Lee la tabla Postscript en memoria desde el disco.

$t->out($fh)

Escribe una nueva tabla de nombres Postscript desde la memoria o la copia desde el disco.

$t->XML_element($context, $depth, $key, $val)

Genera los nombres como un bloque de XML.

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla. Si es menor que este, entonces la tabla debe estar corrupta y debe ser eliminada o algo similar.

ERRORES

•
No hay soporte para tablas de tipo 4.
