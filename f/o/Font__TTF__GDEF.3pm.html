NOMBRE

Font::TTF::GDEF - Soporte para la tabla GDEF de OpenType

DESCRIPCIÓN

La tabla GDEF contiene varias listas globales de información que se utilizan en otros lugares de un renderizador OpenType. Pero dónde exactamente es especulativo...

VARIABLES DE INSTANCIA

Hay hasta 5 tablas en la tabla GDEF, cada una con su propia estructura:

GLYPH
Esta es una tabla de definición de clase Font::TTF::Coverage que contiene información sobre el tipo de cada glifo.
ATTACH
La tabla de adjuntos consiste en una tabla de cobertura y luego puntos de adjunto para cada glifo en la tabla de cobertura:
COVERAGE
Esta es una tabla de cobertura.
POINTS
Este es un array de elementos de punto. Cada elemento es un array de puntos de curva correspondientes a los puntos de adjunto en ese glifo. El orden de los puntos de curva en el array corresponde al número de punto de adjunto especificado en la tabla de cobertura MARKS (ver más abajo).
LIG
Esto contiene la información de posicionamiento del trazo de ligadura para glifos de ligadura.
COVERAGE
Una tabla de cobertura para indicar qué glifos son ligaduras.
LIGS
Un array de elementos para cada ligadura. Cada elemento es un array de información para cada posición de trazo en la ligadura (generalmente hay número de componentes - 1 de estas).
FMT
Este es el formato de la información y es importante para proporcionar la semántica del valor. Este valor debe establecerse correctamente antes de la salida.
VAL
El valor que tiene significado según FMT.
DEVICE
Para FMT = 3, también se hace referencia a una tabla de dispositivos que se almacena aquí.
MARKS
Esta tabla de definición de clase define las clases de glifos de marca que se pueden seleccionar para su procesamiento utilizando el campo MarkAttachmentType de las palabras de FLAG de búsqueda.
MARKSETS
Contiene un array de tablas de cobertura indexadas por el valor FILTER de una búsqueda.

MÉTODOS

$t->read

Lee la tabla en la estructura de datos.

$t->out($fh)

Escribe esta tabla.

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla. Si es menor que esto, entonces la tabla está defectuosa y debe eliminarse o lo que sea.

$t->update

Ordena las tablas COVERAGE.
