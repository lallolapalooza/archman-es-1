Font::TTF::Woff(3) Documentación de Perl contribuida por el usuario Font::TTF::Woff(3)

NOMBRE

Font::TTF::WOFF - contiene datos del archivo de fuente Web Open Font File (WOFF) para la fuente

DESCRIPCIÓN

Esto contiene los datos de empaquetado WOFF.

VARIABLES DE INSTANCIA

Este objeto admite las siguientes variables de instancia (que, debido a que reflejan la estructura de la tabla, no comienzan con un espacio):

majorVersion
minorVersion
Los dos enteros de versión provienen directamente de la cabecera de la fuente WOFF.
metaData
Contiene una referencia a una estructura Font::TTF::Woff::Meta, si la fuente tiene metadatos WOFF.
privateData
Contiene una referencia a una estructura Font::TTF::Woff::Private, si la fuente tiene un bloque de datos privados WOFF.
