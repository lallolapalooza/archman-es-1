NOMBRE

Font::TTF::Delta - Tablas de Dispositivos Opentype

DESCRIPCIÓN

Cada tabla de dispositivo corresponde a un conjunto de deltas para un punto particular en un rango de valores ppem.

first
El primer valor ppem en el rango
last
El último valor ppem en el rango
val
Este es un array de deltas correspondientes a cada ppem en el rango entre first y last inclusive.
fmt
Este es el fmt usado (log2 del número de bits por valor) cuando se leyó la tabla de dispositivo. Se recalcula en la salida.

MÉTODOS

new

Crea una nueva tabla de dispositivo

read

Lee una tabla de dispositivo del objeto IO dado en la ubicación actual

out($fh, $style)

Saca una tabla de dispositivo al objeto IO dado en la ubicación actual, o simplemente devuelve los datos que se van a sacar si $style != 0

$d->signature()

Devuelve una cadena identificadora basada en contenido para este delta con fines de compresión

$d->out_xml($context)

Saca un delta en formato XML
