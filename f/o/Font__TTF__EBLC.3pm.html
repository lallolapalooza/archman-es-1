Font::TTF::EBLC(3) Documentación de Perl contribuida por el usuario Font::TTF::EBLC(3)

NOMBRE

Font::TTF::EBLC - Tabla de Ubicación de Bitmap Embebido

DESCRIPCIÓN

Contiene los tamaños y rangos de glifos de los bitmaps, y los desplazamientos de los datos del bitmap del glifo en indexSubTables para EBDT.

Posiblemente contiene información de métricas de glifos.

VARIABLES DE INSTANCIA

La información especificada como '(S)ólo Lectura' es de sólo lectura, estas se calculan a partir de EBDT, cuando se 'actualiza'.

bitmapSizeTable
Un array de tablas con la siguiente información
indexSubTableArrayOffset (S)
indexTablesSize (S)
numberOfIndexSubTables (S)
colorRef
hori
vert
startGlyphIndex (S)
endGlyphIndex (S)
ppemX
ppemY
bitDepth
flags
indexSubTableArray (S)
Un array que contiene información de rango.
indexSubTable (S)
Un array que contiene los desplazamientos de la tabla EBDT.

MÉTODOS

$t->read

Lee la información de ubicación del bitmap incrustado desde el archivo TTF a la memoria.

$t->out($fh)

Emite la información de ubicación del bitmap incrustado para esta fuente.

ERRORES

Sólo se implementa indexFormat ==1. La salida XML no es compatible (todavía).
