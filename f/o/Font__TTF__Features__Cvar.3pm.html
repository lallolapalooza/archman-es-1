Font::TTF::Features::Cvar(3) Documentación aportada por el usuario de Perl Font::TTF::Features::Cvar(3)

NOMBRE

Font::TTF::Features::Size - Clase para Parámetros de Características de Variantes de Caracteres

DESCRIPCIÓN

Maneja los valores de Parámetros de Características para las características de Variantes de Caracteres.

VARIABLES DE INSTANCIA

INFILE
El manejador de archivo de lectura.
OFFSET
Ubicación del archivo en el archivo de entrada.
Format
Formato de tabla - establecido a 0.
UINameID
El ID de nombre de la tabla 'name' que especifica una cadena (o cadenas, para varios idiomas) para una etiqueta de interfaz de usuario para esta característica.
TooltipNameID
El ID de nombre de la tabla 'name' para el texto de la información sobre herramientas para la característica.
SampleTextNameID
El ID de nombre de la tabla 'name' para el texto de muestra para ilustrar la característica.
NumNamedParms
El número de parámetros nombrados.
FirstNamedParmID
El ID de nombre de la tabla 'name' para el primer parámetro nombrado.
Characters
Un array que contiene los valores unicode de los caracteres para los que la característica proporciona variantes de glifos.

MÉTODOS

$t->read

Lee los Parámetros de Características.

$t->out($fh)

Escribe la tabla FeatureParams en la salida.

Font::TTF::Features::Sset->new()

Crea un nuevo objeto FeatureParams. Los valores para INFILE y OFFSET se pueden pasar como parámetros.
