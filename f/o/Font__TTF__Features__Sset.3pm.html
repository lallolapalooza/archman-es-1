NOMBRE

Font::TTF::Features::Sset - Clase para Parámetros de Característica de Conjuntos Estilísticos

DESCRIPCIÓN

Maneja los valores de Parámetros de Característica para Conjuntos Estilísticos

VARIABLES DE INSTANCIA

INFILE
El manejador de archivo leído
OFFSET
Ubicación del archivo en el archivo de entrada
Version
El número de versión menor, actualmente siempre 0
UINameID
El ID de nombre de la tabla 'name' que especifica una cadena (o cadenas, para múltiples idiomas) para una etiqueta de interfaz de usuario para esta característica

MÉTODOS

$t->leer

Lee los Parámetros de Característica

$t->escribir($fh)

Escribe la tabla FeatureParams en la salida

Font::TTF::Features::Sset->new()

Crea un nuevo objeto FeatureParams. Los valores para INFILE y OFFSET pueden pasarse como parámetros
