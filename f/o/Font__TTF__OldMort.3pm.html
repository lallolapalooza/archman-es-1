NOMBRE

Font::TTF::OldMort - Tabla de metamorfosis de glifos en una fuente

DESCRIPCIÓN

VARIABLES DE INSTANCIA

version
número de versión de la tabla (Fixed: actualmente 1.0)
chains
lista de cadenas de metamorfosis, cada una con sus propios campos:
defaultFlags
flags de subcaracterística predeterminados de la cadena (UInt32)
featureEntries
lista de entradas de características, cada una con los campos:
type
setting
enable
disable
subtables
lista de subtables de metamorfosis, cada una con los campos:
type
tipo de subtabla (0: reorganización; 1: sustitución contextual; 2: ligadura; 4: sustitución no contextual; 5: inserción)
direction
dirección de procesamiento ('LR' o 'RL')
orientation
se aplica al texto en el que la orientación ('VH', 'V' o 'H')
subFeatureFlags
los flags de subcaracterística que controlan si se utiliza la tabla (UInt32)

Los campos adicionales dependen del tipo de subtabla:

Tabla de reorganización:
classes
matriz de listas de glifos
states
matriz de matrices de hashes{'nextState', 'flags'}

Tabla de sustitución contextual:

classes
matriz de listas de glifos
states
matriz de matriz de hashes{'nextState', 'flags', 'actions'}, donde "actions" es una matriz de dos elementos que son desplazamientos que se añadirán a [marcado, actual] glifo para obtener el índice en "mappings" (o "undef" si no se aplica ninguna asignación)
mappings
lista de códigos de glifos mapeados a través de las asignaciones de la tabla de estados
