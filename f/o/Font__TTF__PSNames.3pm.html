Font::TTF::PSNames(3) Documentación de Perl contribuida por el usuario Font::TTF::PSNames(3)

NOMBRE

Font::TTF::PSNames - Utilidades para el procesamiento de nombres de glifos Postscript

SINOPSIS

use Font::TTF::PSNames qw(parse lookup);
$nombre = lookup($uni);
$uni = parse($nombre);

MÉTODOS

lookup ( $usv [, $noAlt [, $noUni] ])

Devuelve el nombre de glifo recomendado por Adobe para un punto de código Unicode específico (entero). Por defecto, devuelve nombres "uniXXXX" en lugar de nombres "afiiNNNNN" o "SFnnnnnn".

Si $noAlt es verdadero, se devuelven nombres "afii" y "SF" en lugar de "uniXXXX".

Si $noUni es verdadero, devuelve undef si tuviera que recurrir a nombres de estilo "uniXXXX" o "uXXXXXX". Esencialmente, esto representa una búsqueda directa en la lista recomendada por Adobe.

parse ( $nombre_de_glifo )

Analiza un nombre de glifo conforme a Adobe, generando una secuencia de puntos de código Unicode equivalente al glifo (o componentes de glifo, si el nombre representa una ligadura). En contexto escalar, devuelve una referencia a un array de Unicodes (decimales). El array está vacío si el nombre del glifo no es conforme. En contexto de lista, el primer elemento devuelto es la misma referencia de array que la anterior. El segundo elemento es una referencia a un array que contiene las extensiones (si las hay) presentes en el nombre del glifo. El '.' que precede a cada extensión no se incluye.
