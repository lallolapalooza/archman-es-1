Font::TTF::GSUB(3) Documentación de Perl contribuida por el usuario Font::TTF::GSUB(3)

NOMBRE

Font::TTF::GSUB - Soporte de módulo para la tabla GSUB en conjunción con TTOpen

DESCRIPCIÓN

Maneja las subtables GSUB en relación con las tablas Ttopen. Debido a la variedad de diferentes tipos de búsqueda, las estructuras de datos no son tan sencillas como cabría esperar, ¡aunque he intentado facilitarme la vida al usar esto!

VARIABLES DE INSTANCIA

La estructura de una tabla GSUB es la misma que la dada en Font::TTF::Ttopen. Aquí damos algunas de las semánticas específicas de las búsquedas GSUB.

TIPO_DE_ACCIÓN
Esta es una cadena que toma uno de 4 valores que indican la naturaleza de la información en el array ACTION de la regla:
g
La acción contiene una cadena de glifos para reemplazar la cadena de coincidencia por
l
El array de acción contiene una lista de desplazamientos y búsquedas a ejecutar, en orden, en la cadena coincidente
a
El array de acción es un conjunto desordenado de reemplazos opcionales para el glifo coincidente. La aplicación debe realizar la selección de alguna manera.
o
El array de acción está vacío (de hecho, no hay array de reglas para este tipo de regla) y el valor ADJUST debe añadirse al id del glifo para encontrar el valor del id del glifo de reemplazo
r
El array de acción es una lista de glifos de reemplazo en orden de cobertura. Este TIPO_DE_ACCIÓN se utiliza solo para búsquedas de encadenamiento inverso de Tipo 8 que, por diseño, son sustituciones de glifo único.
TIPO_DE_COINCIDENCIA
Esto indica qué tipo de información tienen los varios arrays MATCH (MATCH, PRE, POST) en la regla:
g
El array contiene una cadena de ids de glifos que deben coincidir exactamente
c
El array contiene una secuencia de definiciones de clase a las que cada glifo debe corresponder correspondientemente
o
El array contiene desplazamientos a tablas de cobertura

CORRESPONDENCIA CON LOS TIPOS DE DISEÑO

La siguiente tabla proporciona los valores para ACTION_TYPE y MATCH_TYPE para cada uno de los 12 tipos de búsqueda diferentes que se encuentran en la definición de la tabla GSUB:

              1.1 1.2  2  3  4  5.1 5.2 5.3  6.1 6.2 6.3  8
TIPO_DE_ACCIÓN o   g   g  a  g   l   l   l    l   l   l   r
TIPO_DE_COINCIDENCIA                   g   g   c   o    g   c   o   o

Esperemos que el resto de los usos de las variables tengan sentido a partir de esta tabla.

MÉTODOS

$t->read_sub($fh, $lookup, $index)

Solicitado por la superclase para leer del archivo dado el subtable indexésimo de la búsqueda número lookup. El archivo está posicionado listo para la lectura.

$t->extension

Devuelve el número de tipo de tabla para la tabla de extensión.

$t->out_sub($fh, $lookup, $index)

Pasado el manejador de archivo para la salida, debidamente posicionado, la búsqueda y el índice de la subtabla, esta función emite la subtabla a $fh en ese punto.
