NOMBRE

Font::TTF::Kern - Tablas de kerning

DESCRIPCIÓN

Las tablas de kerning se mantienen como una colección ordenada de subtablas, cada una proporcionando información incremental sobre el kerning de varios pares de glifos.

La estructura básica de la estructura de datos de kerning es:

$kern = $f->{'kern'}{'tables'}[$tnum]{'kerns'}{$leftnum}{$rightnum};

Debido a la posible complejidad de algunas tablas de kerning, la información anterior es insuficiente. También se debe hacer referencia al tipo de tabla y al campo de cobertura.

VARIABLES DE INSTANCIA

Las variables de instancia para una tabla de kerning son relativamente sencillas.

Version
Número de versión de la tabla de kerning
Num
Número de subtables en la tabla de kerning
tables
Matriz de subtables en la tabla de kerning

Cada subtabla tiene un número de variables de instancia.

kern
Una matriz hash de dos niveles que contiene valores de kerning. La indexación es por clase izquierda y clase derecha. Puede parecer extraño usar hashes, pero la mayoría de las tablas no son de tipo 2 y este método ahorra valores de matriz vacíos.
type
Almacena el tipo de tabla. Hasta ahora, solo los tipos de tabla 0 y 2 están especificados para TrueType.
coverage
Un campo de bits con información de cobertura sobre el valor de kerning. Consulte la especificación TrueType para obtener más detalles.
Version
Contiene el número de versión de la tabla.
Num
Número de pares de kerning en esta tabla de tipo 0.
left
Una matriz indexada por glifo - left_first que devuelve un número de clase para el glifo en tablas de tipo 2.
right
Una matriz indexada por glifo - right_first que devuelve un número de clase para el glifo en tablas de tipo 2.
left_first
el número de glifo del primer elemento de la matriz izquierda para tablas de tipo 2.
right_first
el número de glifo del primer elemento de la matriz derecha para tablas de tipo 2.
num_left
Número de clases izquierdas
num_right
Número de clases derechas

MÉTODOS

$t->read

Lee la tabla de kerning completa en estructuras

$t->out($fh)

Exporta las tablas de kerning al archivo dado

$t->XML_element($context, $depth, $key, $value)

Maneja la exportación de la matriz hash de kerning a XML de una manera un poco más ordenada

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla. Si es menor que esto, entonces la tabla debe estar mal y debe ser eliminada o lo que sea.

ERRORES

  • Solo admite los tipos de tabla de kerning 0 y 2.
  • Aún no hay funciones de soporte reales para *hacer* algo con las tablas de kerning.
