NOMBRE

Font::TTF::OldCmap - Tabla de mapa de caracteres

Este módulo está obsoleto

DESCRIPCIÓN

Se encarga del mapa de caracteres. La estructura principal utilizada para manejar un cmap es Font::TTF::Segarr, que se encarga de las matrices segmentadas de tablas de formato 4, y de forma más simple para tablas de formato 0.

Debido a la complejidad de trabajar con matrices segmentadas, la mayor parte del manejo de dichas matrices se realiza a través de métodos en lugar de variables de instancia.

Una característica importante de una tabla de formato 4 es que siempre contiene un segmento con una dirección final de 0xFFFF. Si está creando una tabla desde cero, esto es importante (aunque Font::TTF::Segarr puede funcionar perfectamente sin él).

VARIABLES DE INSTANCIA

Las variables de instancia que se enumeran aquí no van precedidas por un espacio debido a que emulan información estructural en la fuente.

Num
Número de subtables en esta tabla
Tables
Un array de subtables ([0..Num-1])

Cada subtabla también tiene sus propias variables de instancia que, de nuevo, no van precedidas por un espacio.

Platform
El número de plataforma para esta subtabla
Encoding
El número de codificación para esta subtabla
Format
Indica el formato almacenado de esta subtabla
Ver
Proporciona información de versión (o idioma) para esta subtabla
val
Esto apunta a un Font::TTF::Segarr que contiene el contenido de la subtabla particular.

MÉTODOS

$t->read

Lee el cmap en memoria. Las subtables de formato 4 leen toda la subtabla y rellenan la matriz segmentada correspondientemente.

Las subtables de formato 2 no se leen en absoluto.

$t->ms_lookup($uni)

Dado un valor Unicode en la tabla MS (Plataforma 3, Codificación 1) localiza esa tabla y busca el número de glifo apropiado en ella.

$t->find_ms

Busca la tabla Unicode de Microsoft y establece la variable de instancia "mstable" a ella si se encuentra. Devuelve la tabla que encuentra.

$t->out($fh)

Escribe una tabla cmap en un manejador de archivos. Si no se ha leído, simplemente copia del archivo de entrada a la salida.

@map = $t->reverse([$num])

Devuelve un mapa inverso de la tabla del número dado o del cmap de Microsoft. Es decir, dado un glifo, devuelve el valor Unicode para él.

ERRORES

•
No hay soporte para tablas de formato 2 (MBCS)
