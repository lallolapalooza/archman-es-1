NOMBRE

Font::TTF::Cmap - Tabla de mapa de caracteres

DESCRIPCIÓN

Se encarga del mapa de caracteres. Para facilitar su uso, el cmap real se almacena en una tabla hash contra el punto de código. Por lo tanto, para una tabla dada:

$gid = $font->{'cmap'}{'Tables'}[0]{'val'}{$code};

Tenga en cuenta que $code debe ser un valor verdadero (0x1234) en lugar de una representación de cadena.

VARIABLES DE INSTANCIA

Las variables de instancia enumeradas aquí no van precedidas de un espacio debido a que emulan información estructural en la fuente.

Num
Número de subtables en esta tabla
Tables
Un array de subtables ([0..Num-1])

Cada subtabla tiene también sus propias variables de instancia que, de nuevo, no van precedidas de un espacio.

Platform
El número de plataforma para esta subtabla
Encoding
El número de codificación para esta subtabla
Format
Indica el formato almacenado de esta subtabla
Ver
Proporciona información de versión (o idioma) para esta subtabla
val
Una tabla hash indexada por el valor del punto de código (no una cadena) que almacena el id del glifo.

Las siguientes opciones de cmap están controladas por variables de instancia que comienzan con un espacio:

allowholes
Por defecto, al generar subtables cmap de formato 4, los códigos de caracteres que apuntan al glifo cero (normalmente llamado .notdef) no se incluyen en la subtabla. En algunos casos, incluir algunos de estos códigos de caracteres puede resultar en una subtabla de formato 4 más pequeña. Para habilitar este comportamiento, establezca allowholes a un valor distinto de cero.

MÉTODOS

$t->read

Lee el cmap en memoria. Las subtables de formato 4 leen la subtabla completa y rellenan la matriz segmentada en consecuencia.

$t->ms_lookup($uni)

Busca una tabla Unicode, dando preferencia a la de MS, y busca el punto de código Unicode dado en ella para encontrar el id del glifo.

$t->find_ms

Busca una tabla Unicode, dando preferencia a la de Microsoft, y establece la variable de instancia "mstable" a ella si se encuentra. Devuelve la tabla que encuentra.

$t->ms_enc

Devuelve la codificación de la tabla de Microsoft (0 => símbolo, etc.). Devuelve undef si no hay un cmap de Microsoft.

$t->out($fh)

Escribe una tabla cmap en un manejador de archivos. Si no se ha leído, simplemente copia del archivo de entrada al de salida.

$t->XML_element($context, $depth, $name, $val)

Genera los elementos del cmap en XML. Solo necesitamos procesar `val` aquí.

$t->minsize()

Devuelve el tamaño mínimo que puede tener esta tabla en bytes. Si es menor que esto, la tabla debe ser incorrecta y debe eliminarse o lo que sea.

$t->update

Limpia la tabla cmap.

Elimina el cmap MS Fmt12 si ya no es necesario.

Elimina de todos los cmaps cualquier punto de código que se mapee a GID=0. Tenga en cuenta que tales entradas se reintroducirán según sea necesario dependiendo del formato del cmap.

@map = $t->reverse(%opt)

Devuelve un mapa inverso del cmap Unicode. Es decir, dado un glifo, devuelve el valor Unicode para él. Las opciones son:

tnum
Número de tabla a usar en lugar de la tabla Unicode por defecto
array
Devuelve cada elemento del mapa inverso como un array, ya que un glifo puede ser mapeado por más de un valor Unicode. Los arrays no están ordenados. De lo contrario, almacena cualquier valor unicode para un glifo.

is_unicode($index)

Devuelve si la tabla de un índice dado se conoce como una tabla unicode (como se especifica en las especificaciones).

ERRORES

•
Los cmaps de formato 14 (Secuencias de Variación Unicode) no son compatibles.
