Font::TTF::Utils(3) Documentación de Perl aportada por el usuario Font::TTF::Utils(3)

NOMBRE

Font::TTF::Utils - Funciones de utilidad para ahorrar dedos

DESCRIPCIÓN

Muchas funciones útiles para ahorrar mis dedos, especialmente para tablas triviales

FUNCIONES

Las siguientes funciones son exportadas

($val, $pos) = TTF_Init_Fields ($str, $pos)

Dada una descripción de campo de la sección "DATA", crea una entrada absoluta en el array asociativo de campos para la clase

TTF_Read_Fields($obj, $dat, $fields)

Dado un bloque de datos lo suficientemente grande como para cubrir todos los campos de una tabla, procesa el bloque de datos para convertirlo en los valores de las variables de instancia del objeto por nombre, basándose en la lista de la sección "DATA" que ha sido procesada por "TTF_Init_Fields"

TTF_Unpack($fmt, $dat)

Un equivalente de TrueType de la función "unpack" de Perl. Por lo tanto, $fmt consiste en un tipo seguido de un número opcional de elementos a leer, incluyendo *. El tipo puede ser uno de:

c       BYTE
C       CHAR
f       FIXED
F       F2DOT14
l       LONG
L       ULONG
s       SHORT
S       USHORT
v       Número de versión (FIXED)

Tenga en cuenta que "FUNIT", "FWORD" y "UFWORD" no son tipos de datos sino unidades.

Devuelve una matriz de escalares (primer elemento) dependiendo del contexto

$dat = TTF_Out_Fields($obj, $fields, $len)

Dada la tabla de campos de "TTF_Init_Fields", escribe las variables de instancia del objeto al manejador de archivos en formato binario TTF.

$dat = TTF_Pack($fmt, @data)

El equivalente de TrueType a la función "pack" de Perl. Vea los detalles de "TTF_Unpack" para saber cómo trabajar con la cadena $fmt.

($num, $range, $select, $shift) = TTF_bininfo($num)

Calcula información de búsqueda binaria a partir de un número de elementos

TTF_word_utf8($str)

Devuelve la forma UTF8 de la cadena de 16 bits, asumida en orden big-endian, incluyendo el manejo de sustitutos

TTF_utf8_word($str)

Devuelve la forma de 16 bits en orden big-endian de la cadena UTF 8, incluyendo el manejo de sustitutos a Unicode.

XML_hexdump($context, $dat)

Muestra los datos proporcionados como una secuencia de bloques <data> de 16 bytes de ancho cada uno

XML_outhints

Convierte una cadena binaria de código de indicación en una representación textual

make_circle($f, $cmap, [$dia, $sb, $opts])

Añade un círculo punteado a una fuente. Esta función es muy configurable. Los parámetros que se pasan son:

$f
Fuente con la que trabajar. Esto es obligatorio.
$cmap
Una tabla cmap (no el sub-elemento 'val' de un cmap) a la que añadir el glifo. Opcional.
$dia
Diámetro opcional para el círculo principal. Por defecto es el 80% del em.
$sb
Rodapié lateral. Los rodapiés laterales izquierdo y derecho son siempre iguales. Este valor por defecto es el 10% del em.

Hay varias opciones para controlar todo tipo de aspectos interesantes del círculo

numDots
Número de puntos en el círculo
numPoints
Número de puntos de curva a utilizar para crear cada punto
uid
Referencia Unicode para almacenar este glifo en el cmap. Por defecto es 0x25CC
pname
Nombre PostScript a dar al glifo. Por defecto es uni25CC.
-dRadius
Radio de cada punto.
