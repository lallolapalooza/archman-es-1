NOMBRE

flatpak-remote-modify - Modificar un repositorio remoto

SINOPSIS

flatpak remote-modify [OPCIÓN...] NOMBRE

DESCRIPCIÓN

Modifica las opciones de un repositorio remoto existente en la configuración de repositorios de flatpak. NOMBRE es el nombre del repositorio remoto.

A menos que se anule con las opciones --system, --user o --installation, este comando utiliza la instalación predeterminada a nivel de sistema o la del usuario, según cuál tenga el REMOTO especificado.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Mostrar opciones de ayuda y salir.

-u, --user

Modificar la configuración por usuario.

--system

Modificar la configuración predeterminada a nivel de sistema.

--installation=NOMBRE

Modificar una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--no-gpg-verify

Desactivar la verificación GPG para el repositorio añadido.

--gpg-verify

Activar la verificación GPG para el repositorio añadido.

--prio=PRIO

Establecer la prioridad para el repositorio. El valor predeterminado es 1, un valor mayor indica mayor prioridad. Esto se usa principalmente para herramientas de instalación gráficas.

--subset=SUBSET

Limitar las referencias disponibles desde el repositorio a aquellas que forman parte del subconjunto con el nombre dado.

--no-enumerate

Marcar el repositorio como no enumerado. Esto significa que el repositorio no se usará para listar aplicaciones, por ejemplo, en herramientas de instalación gráficas. Tampoco se usará para la resolución de dependencias de tiempo de ejecución (como con --no-use-for-deps).

--no-use-for-deps

Marcar el repositorio para que no se use para la resolución automática de dependencias de tiempo de ejecución.

--disable

Desactivar el repositorio. Los repositorios desactivados no se actualizarán automáticamente.

--enable

Activar el repositorio.

--enumerate

Marcar el repositorio como enumerado. Esto significa que el repositorio se usará para listar aplicaciones, por ejemplo, en herramientas de instalación gráficas.

--use-for-deps

Marcar el repositorio para que se use en la resolución automática de dependencias de tiempo de ejecución.

--title=TITULO

Un título para el repositorio, por ejemplo, para mostrarlo en una interfaz de usuario.

--comment=COMENTARIO

Un comentario de una sola línea para el repositorio, por ejemplo, para mostrarlo en una interfaz de usuario.

--description=DESCRIPCIÓN

Una descripción en un párrafo completo para el repositorio, por ejemplo, para mostrarla en una interfaz de usuario.

--homepage=URL

URL de un sitio web para el repositorio, por ejemplo, para mostrarlo en una interfaz de usuario.

--icon=URL

URL de un icono para el repositorio, por ejemplo, para mostrarlo en una interfaz de usuario.

--default-branch=RAMA

Una rama predeterminada para el repositorio, utilizada principalmente en una interfaz de usuario.

--collection-id=COLLECTION-ID

El identificador único global del repositorio remoto, para permitir que los espejos se agrupen. Esto solo debe establecerse con el ID de colección proporcionado por el repositorio remoto y no debe establecerse si el repositorio remoto no proporciona un ID de colección.

--url=URL

Establecer una nueva URL.

--update-metadata

Actualizar los metadatos adicionales del repositorio desde el archivo de resumen del repositorio OSTree. Actualmente, solo xa.title y xa.default-branch son compatibles.

--no-filter, --filter=ARCHIVO

Modificar la ruta (o eliminarla) para el filtro local utilizado para este repositorio. Consulte flatpak-remote-add(1) para obtener detalles sobre el formato del archivo de filtro.

--gpg-import=ARCHIVO

Importar claves gpg desde el archivo de keyring especificado como confiables para el nuevo repositorio. Si el archivo es -, el keyring se lee de la entrada estándar.

--authenticator-name=NOMBRE

Especificar el autenticador a utilizar para el repositorio.

--authenticator-option=CLAVE=VALOR

Especificar una opción del autenticador para el repositorio.

--authenticator-install

Activar la instalación automática del autenticador.

--no-authenticator-install

Desactivar la instalación automática del autenticador.

--follow-redirect

Seguir xa.redirect-url definido en el archivo de resumen.

--no-follow-redirect

No seguir xa.redirect-url definido en el archivo de resumen.

-v, --verbose

Imprimir información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprimir información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak --user remote-modify --no-gpg-verify test-repo
