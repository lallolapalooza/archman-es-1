NOMBRE

flatpak-document-export - Exportar un archivo a una aplicación con sandbox

SINOPSIS

flatpak document-export [OPCIÓN...] ARCHIVO

DESCRIPCIÓN

Crea un ID de documento para un archivo local que puede exponerse a aplicaciones con sandbox, permitiéndoles acceso a archivos que de otro modo no verían. Los archivos exportados se exponen en un sistema de archivos FUSE en /run/user/$UID/doc/.

Este comando también te permite modificar los permisos por aplicación de los documentos, otorgando o revocando el acceso al archivo en base a la aplicación.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Mostrar opciones de ayuda y salir.

-u, --unique

No reutilizar un ID de documento existente para el archivo. Esto hace que sea seguro eliminar el documento más tarde cuando hayas terminado con él.

-t, --transient

El documento solo existirá durante la sesión. Esto es útil para concesiones temporales.

-n, --noexist

No requerir que el archivo exista previamente.

-a, --app=APPID

Otorgar acceso de lectura a la aplicación especificada. Las opciones --allow y --forbid se pueden usar para otorgar o eliminar privilegios adicionales. Esta opción se puede usar varias veces.

-r, --allow-read

Otorgar acceso de lectura a las aplicaciones especificadas con --app. Esto es verdadero por defecto.

--forbid-read

Revocar el acceso de lectura para las aplicaciones especificadas con --app.

-w, --allow-write

Otorgar acceso de escritura a las aplicaciones especificadas con --app.

--forbid-write

Revocar el acceso de escritura para las aplicaciones especificadas con --app.

-d, --allow-delete

Otorgar a las aplicaciones especificadas con --app la capacidad de eliminar el documento del portal de documentos.

--forbid-delete

Revocar a las aplicaciones especificadas con --app la capacidad de eliminar el documento del portal de documentos.

-g, --allow-grant-permission

Otorgar a las aplicaciones especificadas con --app la capacidad de otorgar permisos adicionales.

--forbid-grant-permission

Revocar la capacidad de otorgar permisos adicionales para las aplicaciones especificadas con --app.

-v, --verbose

Imprimir información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprimir información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak document-export --app=org.gnome.gedit ~/test.txt

/run/user/1000/doc/e52f9c6a/test.txt
