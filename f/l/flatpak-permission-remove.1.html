FLATPAK PERMISSION-(1) flatpak permission-remove FLATPAK PERMISSION-(1)

NOMBRE

flatpak-permission-remove - Eliminar permisos

SINOPSIS

flatpak permission-remove [OPCIÓN...] TABLA ID [ID_APLICACIÓN]

DESCRIPCIÓN

Elimina una entrada para el objeto con el id ID del almacén de permisos TABLA. El ID debe estar en un formato adecuado para la tabla. Si se especifica ID_APLICACIÓN, solo se elimina la entrada para esa aplicación.

El almacén de permisos es utilizado por los portales. Cada portal generalmente tiene su propia tabla en el almacén de permisos, y el formato de las entradas de la tabla es específico para cada portal.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Mostrar opciones de ayuda y salir.

-v, --verbose

Imprimir información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprimir información de depuración de OSTree durante el procesamiento del comando.
