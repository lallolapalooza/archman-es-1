NOMBRE

flatpak-build-bundle - Crear un paquete de archivo único a partir de un repositorio local

SINOPSIS

flatpak build-bundle [OPCIÓN...] UBICACIÓN ARCHIVO NOMBRE [RAMA]

DESCRIPCIÓN

Crea un archivo único llamado ARCHIVO para la aplicación (o entorno de ejecución) llamada NOMBRE en el repositorio en UBICACIÓN. Si se especifica una RAMA, se utilizará esa rama de la aplicación.

El ID de colección establecido en el repositorio en UBICACIÓN (si está establecido) se usará para el paquete.

A menos que se use --oci, el formato del archivo del paquete es el de un delta estático de ostree (contra una base vacía) con algunos metadatos específicos de flatpak para los iconos de la aplicación y los datos de la aplicación.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Mostrar opciones de ayuda y salir.

--runtime

Exportar un entorno de ejecución en lugar de una aplicación.

--arch=ARQUITECTURA

La arquitectura para la que crear un paquete. Ver flatpak --supported-arches para las arquitecturas compatibles con el host.

--repo-url=URL

La URL del repositorio desde el cual se puede actualizar la aplicación. La instalación del paquete configurará automáticamente un remoto para esta URL.

--runtime-repo=URL

La URL de un archivo .flatpakrepo que contiene la información sobre el repositorio que proporciona los entornos de ejecución necesarios para la aplicación.

--gpg-keys=ARCHIVO

Añadir la clave GPG de ARCHIVO (usar - para stdin).

--gpg-homedir=RUTA

Directorio de inicio de GPG a usar al buscar llaveros.

--from-commit=COMMIT

El commit OSTree del cual crear un paquete delta.

--oci

Exportar a una imagen OCI en lugar de un paquete Flatpak.

-v, --verbose

Imprimir información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprimir información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak build-bundle /var/lib/flatpak/repo gnome-calculator.flatpak org.gnome.Calculator stable

$ flatpak build-bundle ~/.local/share/flatpak/repo gnome-calculator.flatpak org.gnome.Calculator stable
