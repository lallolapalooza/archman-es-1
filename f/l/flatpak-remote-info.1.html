NOMBRE

flatpak-remote-info - Muestra información sobre una aplicación o runtime en un repositorio remoto

SINOPSIS

flatpak remote-info [OPCIÓN...] REMOTO REF

DESCRIPCIÓN

Muestra información sobre el runtime o la aplicación REF del repositorio remoto con el nombre REMOTO. Puedes encontrar todos los repositorios remotos configurados con flatpak remotes.

Por defecto, la salida se formatea de manera amigable. Si especificas una de las opciones --show-..., la salida se formatea en su lugar de manera legible para máquinas.

A menos que se anule con las opciones --system, --user o --installation, este comando utiliza la instalación predeterminada a nivel de sistema o la del usuario, dependiendo de cuál tenga el REMOTO especificado.

OPCIONES

Se reconocen las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Utiliza la configuración por usuario.

--system

Utiliza la configuración predeterminada a nivel de sistema.

--installation=NOMBRE

Utiliza una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--cached

Prefiere usar información en caché local si es posible, aunque pueda estar desactualizada. Esto es más rápido, pero corre el riesgo de devolver información obsoleta. Además, parte de la información no se guarda en caché, por lo que no estará disponible.

--runtime

Asume que REF es un runtime si no se especifica explícitamente.

--app

Asume que REF es una aplicación si no se especifica explícitamente.

--arch=ARQUITECTURA

La arquitectura predeterminada a buscar, si no se especifica explícitamente en REF. Consulta flatpak --supported-arches para ver las arquitecturas compatibles con el host.

--commit=COMMIT

Muestra información sobre el commit específico, en lugar de la última versión.

--log

Muestra un registro de versiones anteriores.

-r, --show-ref

Muestra la referencia coincidente.

-c, --show-commit

Muestra el ID del commit.

-p, --show-parent

Muestra el ID del commit padre.

-m, --show-metadata

Muestra los metadatos.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.
