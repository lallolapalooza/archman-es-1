NOMBRE

flatpak-build-update-repo - Crear un repositorio a partir de un directorio de compilación

SINOPSIS

flatpak build-update-repo [OPCIÓN...] UBICACIÓN

DESCRIPCIÓN

Actualiza la metadata del repositorio para el repositorio en UBICACIÓN. Este comando genera un archivo de resumen de OSTree que lista el contenido del repositorio. El resumen es utilizado por flatpak remote-ls y otros comandos para mostrar el contenido de los repositorios remotos.

Después de este comando, UBICACIÓN puede ser utilizada como la ubicación del repositorio para flatpak remote-add, ya sea exportándola a través de http, o directamente con una URL de tipo file:.

OPCIONES

Las siguientes opciones son entendidas:

-h, --help

Muestra las opciones de ayuda y sale.

--redirect-url=URL

Redirige este repositorio a una nueva URL.

--title=TÍTULO

Un título para el repositorio, por ejemplo, para mostrarlo en una interfaz de usuario. El título se almacena en el resumen del repositorio.

--comment=COMENTARIO

Un comentario de una sola línea para el remoto, por ejemplo, para mostrarlo en una interfaz de usuario. El comentario se almacena en el resumen del repositorio.

--description=DESCRIPCIÓN

Una descripción completa en forma de párrafo para el remoto, por ejemplo, para mostrarlo en una interfaz de usuario. La descripción se almacena en el resumen del repositorio.

--homepage=URL

URL de un sitio web para el remoto, por ejemplo, para mostrarlo en una interfaz de usuario. La URL se almacena en el resumen del repositorio.

--icon=URL

URL de un icono para el remoto, por ejemplo, para mostrarlo en una interfaz de usuario. La URL se almacena en el resumen del repositorio.

--default-branch=RAMA

Una rama predeterminada para el repositorio, principalmente para uso en una interfaz de usuario.

--gpg-import=ARCHIVO

Importa una nueva clave pública GPG predeterminada desde el archivo dado.

--collection-id=COLLECTION-ID

El identificador único global del repositorio remoto, para permitir la agrupación de espejos. Debe establecerse en una cadena DNS inversa globalmente única si el repositorio se va a hacer disponible públicamente. Si un ID de colección ya está establecido en un repositorio existente, esto lo actualizará. Si no se especifica, el ID de colección existente no se modificará.

--deploy-collection-id

Implementa el ID de colección (establecido usando --collection-id) en la configuración remota estática para todos los clientes. Esto es irrevocable una vez publicado en un repositorio. Úsalo para decidir cuándo implementar un ID de colección a los usuarios de un repositorio existente. Si estás construyendo un nuevo repositorio que tiene un ID de colección, generalmente deberías pasar siempre esta opción.

--deploy-sideload-collection-id

Esto es similar a --deploy-collection-id, pero solo aplica la implementación a clientes más nuevos que flatpak 1.7 que soporten la nueva forma de sideloads.

--gpg-sign=KEYID

Firma el commit con esta clave GPG. Esta opción se puede usar varias veces.

--gpg-homedir=RUTA

Directorio GPG Homedir a utilizar al buscar llaveros.

--generate-static-deltas

Genera deltas estáticos para todas las referencias. Esto genera archivos estáticos "desde vacío" y delta que permiten descargas más rápidas.

--static-delta-jobs=NUM-JOBS

Limita el número de trabajos paralelos que crean deltas estáticos. El valor predeterminado es el número de CPUs.

--static-delta-ignore-ref=PATRÓN

No genera deltas para el ID de runtime o aplicación que coincida con este patrón. Por ejemplo, --static-delta-ignore-ref=*.Sources significa que no habrá deltas para las referencias de origen.

--prune

Elimina objetos no referenciados en el repositorio.

--prune-depth

Solo conserva como máximo este número de versiones antiguas para cualquier referencia particular. El valor predeterminado es -1, lo que significa infinito.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.
