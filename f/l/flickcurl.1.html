DESCRIPCIÓ

N

flickcurl es un programa utilitario para llamar a las APIs de Flickr a través de la biblioteca flickcurl. Ejecute flickcurl -h para obtener una lista de los comandos soportados y sus

argumentos.

El programa requiere ser configurado antes de su uso para trabajar con las APIs de Flickr. Ejecute flickcurl sin ninguna opción para obtener las instrucciones para registrar la aplicación y crear el archivo de configuración inicial ~/.flickcurl.conf a partir d

e la informació
n de registro.
