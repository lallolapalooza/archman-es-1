NOMBRE

flatpak-make-current - Hace que una versión específica de una aplicación sea la actual

SINOPSIS

flatpak make-current [OPCIÓN...] APP BRANCH

DESCRIPCIÓN

Hace que una rama particular de una aplicación sea la actual. Solo la rama actual de una aplicación tiene sus archivos exportados (como archivos de escritorio e iconos) visibles para el host.

Cuando se instala una nueva rama, se convertirá automáticamente en la actual, por lo que este comando a menudo no es necesario.

A menos que se anule con las opciones --user o --installation, este comando cambia la instalación predeterminada a nivel de sistema.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Actualiza una instalación por usuario.

--system

Actualiza la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Actualiza una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--arch=ARCH

La arquitectura que se hará actual. Consulte flatpak --supported-arches para ver las arquitecturas compatibles con el host.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak --user make-current org.gnome.gedit 3.14
