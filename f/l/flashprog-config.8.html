NOMBRE

flashprog-config - leer y escribir registros de estado y configuración de chips de memoria flash

SINOPSIS

flashprog config [get] <opciones> <configuración>
flashprog config  set  <opciones> [--temporal] <configuración> <valor>

Donde las <opciones> genéricas son:

-p <nombre_programador>[:<parámetros>] [-c <nombre_chip>]
[-V[V[V]]] [-o <archivo_log>] [-h]

DESCRIPCIÓN

flashprog-config es una utilidad para leer y escribir bits de registros de estado y configuración de chips de memoria flash. Actualmente, solo soporta chips NOR SPI.

OPERACIONES

Puede especificar una de las operaciones get o set, o ninguna operación, lo que por defecto será leer una configuración.

get <configuración>

Lee e imprime el valor de la configuración dada. Ver CONFIGURACIONES más abajo.

set [--temporal] <configuración> <valor>

Escribe el valor dado a la configuración. Ver CONFIGURACIONES y VALORES más abajo.

Cuando se proporciona la opción --temporal, flashprog intentará escribir un valor temporal que no se almacena en la memoria flash. Esto requiere soporte especial por parte del chip de memoria flash para un comando de registro de estado de escritura volátil. El nuevo valor se perderá al reiniciar el chip de memoria flash. Por lo tanto, es inútil usar esto con programadores externos que conmutan la alimentación del chip de memoria flash (por ejemplo, Dediprog).

CONFIGURACIONES

qe, quad-enable

Los chips de memoria flash NOR SPI a menudo soportan la multiplexación de algunos de sus pines (generalmente /WP y /HOLD) con líneas de E/S adicionales. Esto les permite transferir cuatro bits a la vez cuando el bit quad-enable está activado.

VALORES

false, true

Los valores false y true se convertirán a 0 y 1 respectivamente.

números naturales: 0, 1, ...

Cuando se proporcionan números naturales, los bits menos significativos de su representación binaria se escribirán en una configuración.

OPCIONES

Todas las operaciones requieren el uso de la opción -p/--programmer (por favor, consulte para más información sobre el soporte de programadores y parámetros).

-p, --programmer <nombre>[:<parámetro>[,<parámetro>]...]

Especifica el dispositivo programador. Esto es obligatorio para todas las operaciones. Por favor, consulte el manual para una lista de programadores soportados actualmente y sus parámetros.

-c, --chip <nombre_chip>

Sondea solo para el chip de memoria ROM flash especificado. Esta opción toma el nombre del chip impreso por flashprog -L sin el nombre del proveedor como parámetro. Tenga en cuenta que el nombre del chip distingue entre mayúsculas y minúsculas.

-V, --verbose

Salida más detallada. Esta opción se puede proporcionar múltiples veces (máximo 3 veces, es decir, -VVV) para obtener aún más salida de depuración.

-o, --output <archivo_log>

Guarda el log de depuración completo en <archivo_log>. Si el archivo ya existe, será sobrescrito. Esta es la forma recomendada de recopilar logs de flashprog ya que serán detallados incluso si los mensajes en pantalla no lo son y no requieren redirección de salida.

-h, --help

Muestra un texto de ayuda y sale.

--temporal

Intenta usar un comando de registro de estado de escritura volátil. Ver set bajo OPERACIONES arriba.

EJEMPLOS

Para leer la configuración quad-enable de la memoria flash BIOS interna:

flashprog config -p internal quad-enable
o
flashprog config get -p internal quad-enable
Para configurar temporalmente el bit quad-enable de un chip conectado a un FT4222H:
flashprog config set -p ft4222_spi --temporary quad-enable 1

ESTADO DE SALIDA

flashprog sale con 0 en caso de éxito, 1 en la mayoría de los fallos, pero con 3 si una llamada a mmap() falla.

REQUISITOS

flashprog necesita diferentes permisos de acceso para diferentes programadores. Ver esta sección en el manual para detalles.

ERRORES

Puede reportar errores, hacernos preguntas o enviar informes de éxito a través de nuestros canales de comunicación listados aquí: https://www.flashprog.org/Contact.
