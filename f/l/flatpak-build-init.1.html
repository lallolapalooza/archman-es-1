NOMBRE

flatpak-build-init - Inicializa un directorio de compilación

SINOPSIS

flatpak build-init [OPCIÓN...] DIRECTORIO NOMBRE_APP SDK RUNTIME [RAMA]

DESCRIPCIÓN

Inicializa un directorio de compilación separado. DIRECTORIO es el nombre del directorio. NOMBRE_APP es el ID de la aplicación que se compilará. SDK y RUNTIME especifican el sdk y el runtime contra los cuales se debe compilar y en los que se ejecutará la aplicación. RAMA especifica la versión del sdk y el runtime.

Inicializa un directorio como directorio de compilación que puede ser utilizado como directorio de destino de flatpak build. Crea un archivo de metadatos dentro del directorio dado. Además, se crean archivos vacíos y subdirectorios var.

Es un error ejecutar build-init en un directorio que ya ha sido inicializado como directorio de compilación.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--arch=ARCH

La arquitectura a utilizar. Consulte flatpak --supported-arches para conocer las arquitecturas compatibles con el host.

-v, --var=RUNTIME

Inicializa var desde el runtime especificado.

-w, --writable-sdk

Inicializa /usr con una copia del sdk, que es modificable durante la compilación de flatpak. Esto se puede utilizar si necesita instalar herramientas de compilación en /usr durante la compilación. Esto se almacena en el subdirectorio usr del directorio de la aplicación, pero no formará parte de la aplicación final.

--tag=TAG

Añade una etiqueta al archivo de metadatos. Esta opción puede utilizarse varias veces.

--sdk-extension=EXTENSION

Al usar --writable-sdk, además del sdk, también instala la extensión especificada. Esta opción puede utilizarse varias veces.

--extension=NAME=VARIABLE[=VALOR]

Añade información del punto de extensión.

--sdk-dir

Especifica un subdirectorio personalizado para usar en lugar de usr para --writable-sdk.

--update

Re-inicializa el sdk y var, no falla si ya están inicializados.

--base=APP

Inicializa la aplicación con archivos de otra aplicación especificada.

--base-version=VERSION

Especifica la versión a utilizar para --base. Si no se especifica, se usará por defecto "master".

--base-extension=EXTENSION

Al usar --base, también instala la extensión especificada de la aplicación. Esta opción puede utilizarse varias veces.

--type=TYPE

Esto se puede usar para compilar diferentes tipos de elementos. El valor predeterminado es "app", que es una aplicación normal, pero "runtime" crea un runtime basado en un runtime existente, y "extension" crea una extensión para una aplicación o runtime.

--extension-tag=EXTENSION_TAG

Si se compila una extensión, la etiqueta a utilizar al buscar el punto de montaje de la extensión.

--verbose

Muestra información de depuración durante el procesamiento del comando.

--ostree-verbose

Muestra información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak build-init /build/my-app org.example.myapp org.gnome.Sdk org.gnome.Platform 3.36
