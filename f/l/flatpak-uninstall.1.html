NOMBRE

flatpak-uninstall - Desinstala una aplicación o runtime

SINOPSIS

flatpak uninstall [OPCIÓN...] [REF...]

DESCRIPCIÓN

Desinstala una aplicación o runtime. REF es una referencia a la aplicación o runtime que se va a desinstalar.

Cada argumento REF es un identificador completo o parcial en el formato de referencia de flatpak, que se ve como "(app|runtime)/ID/ARCH/BRANCH". Todos los elementos excepto ID son opcionales y pueden omitirse, incluyendo las barras, por lo que la mayoría de las veces solo necesita especificar ID. Cualquier parte omitida se comparará con lo que está instalado, y si hay múltiples coincidencias se le pedirá que elija entre ellas. También se le pedirá si REF no coincide exactamente con ninguna referencia instalada pero es similar (por ejemplo, "gedit" es similar a "org.gnome.gedit"), pero este comportamiento de coincidencia aproximada se desactiva si REF contiene barras o puntos.

Por defecto, esto busca tanto aplicaciones como runtimes instalados con la REF dada, pero puede limitar esto utilizando la opción --app o --runtime, o proporcionando el elemento inicial en la REF.

Normalmente, este comando elimina la referencia de esta aplicación/runtime del repositorio local de OSTree y purga cualquier objeto que ya no sea necesario para liberar espacio en disco. Si la misma aplicación se reinstala más tarde, los objetos se obtendrán nuevamente del repositorio remoto. La opción --keep-ref se puede utilizar para evitar esto.

Cuando se especifica --delete-data al eliminar una aplicación, se elimina su directorio de datos en ~/.var/app y cualquier permiso que pueda tener. Cuando --delete-data se utiliza sin una REF, se eliminan todos los datos de aplicaciones 'sin propietario'.

A menos que se anule con las opciones --system, --user o --installation, este comando busca tanto en la instalación sistémica como en la del usuario la REF y falla si existe en más de una.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--keep-ref

Conserva la referencia de la aplicación y los objetos que le pertenecen en el repositorio local.

-u, --user

Desinstala de una instalación por usuario.

--system

Desinstala de la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Desinstala de una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--arch=ARCH

La arquitectura a desinstalar, en lugar de la arquitectura del sistema anfitrión. Ver flatpak --supported-arches para las arquitecturas compatibles con el anfitrión.

--all

Elimina todas las referencias en el sistema.

--unused

Elimina las referencias no utilizadas en el sistema.

-y, --assumeyes

Responde automáticamente sí a todas las preguntas. Esto es útil para la automatización.

--noninteractive

Produce una salida mínima y evita la mayoría de las preguntas. Esto es adecuado para su uso en situaciones no interactivas, por ejemplo, en un script de compilación.

--app

Busca solo una aplicación con el nombre dado.

--runtime

Busca solo un runtime con el nombre dado.

--no-related

No desinstalar extensiones relacionadas, como los datos de idioma.

--force-remove

Elimina archivos incluso si están siendo utilizados por una aplicación en ejecución.

--delete-data

Elimina los datos de la aplicación en ~/.var/app y en el almacén de permisos.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak --user uninstall org.gnome.gedit
