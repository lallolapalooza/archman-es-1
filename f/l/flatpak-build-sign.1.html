flatpak-build-sign(1)

FLATPAK BUILD-SIGN(1) flatpak build-sign FLATPAK BUILD-SIGN(1)

NOMBRE

flatpak build-sign - Firma una aplicación o runtime

SINOPSIS

flatpak build-sign [OPCIÓN...] UBICACIÓN ID [RAMA]

DESCRIPCIÓN

Firma el commit de una aplicación o runtime especificado en un repositorio local. UBICACIÓN es la ubicación del repositorio. ID es el nombre de la aplicación o runtime si se especifica --runtime. Si no se especifica RAMA, se asume que es "master".

Las aplicaciones también se pueden firmar durante build-export, pero a veces es útil añadir firmas adicionales más tarde.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--gpg-sign=KEYID

Firma el commit con esta clave GPG. Esta opción se puede usar varias veces.

--gpg-homedir=PATH

Directorio de inicio GPG a usar al buscar llaveros.

--runtime

Firma un runtime en lugar de una aplicación.

--arch=ARCH

La arquitectura a usar. Consulte flatpak --supported-arches para las arquitecturas compatibles con el host.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak build-sign --gpg-sign=D8BA6573DDD2418027736F1BC33B315E53C1E9D6 /algun/repo org.my.App
