NOMBRE

flatpak-remote-ls - Mostrar entornos de ejecución y aplicaciones disponibles

SINOPSIS

flatpak remote-ls [OPCIÓN...] [REMOTO]

DESCRIPCIÓN

Muestra los entornos de ejecución y aplicaciones que están disponibles en el repositorio remoto con el nombre REMOTO, o en todos los remotos si no se especifica ninguno. Puede encontrar todos los repositorios remotos configurados con flatpak remotes.

REMOTO puede ser una URI file:// que apunte a un repositorio local en lugar de a un nombre remoto.

A menos que se anule con las opciones --system, --user o --installation, este comando utiliza la instalación predeterminada a nivel de sistema o la del usuario, dependiendo de cuál tenga el REMOTO especificado.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Mostrar opciones de ayuda y salir.

-u, --user

Usar la configuración por usuario.

--system

Usar la configuración predeterminada a nivel de sistema.

--installation=NOMBRE

Usar una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--cached

Preferir usar información local en caché si es posible, aunque pueda estar desactualizada. Esto es más rápido, pero corre el riesgo de devolver información obsoleta.

-d, --show-details

Mostrar arquitecturas, ramas e IDs de commit, además de los nombres. Equivalente a --columns=all.

--runtime

Mostrar solo entornos de ejecución, omitir aplicaciones.

--app

Mostrar solo aplicaciones, omitir entornos de ejecución.

--all, -a

Mostrar todo. Por defecto, las extensiones de idioma y depuración, así como las arquitecturas secundarias cuando la arquitectura principal está disponible, se ocultan.

--updates

Mostrar solo aquellos que tienen actualizaciones disponibles.

--arch=ARCH

Mostrar solo los que coinciden con la arquitectura especificada. Por defecto, solo se muestran las arquitecturas soportadas. Usar --arch=* para mostrar todas las arquitecturas. Consulte flatpak --supported-arches para ver las arquitecturas soportadas por el host.

-v, --verbose

Imprimir información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprimir información de depuración de OSTree durante el procesamiento del comando.

--app-runtime=RUNTIME

Listar aplicaciones que utilizan el runtime dado

--columns=CAMPO,...

Especificar qué información mostrar sobre cada ref. Puede listar varios campos, o usar esta opción varias veces.

Añada :s[tart], :m[iddle], :e[nd] o :f[ull] a los nombres de columna para cambiar la elipsis.

CAMPOS

Las siguientes campos son entendidos por la opción --columns:

name

Mostrar el nombre

description

Mostrar la descripción de la aplicación

application

Mostrar el ID de la aplicación o entorno de ejecución

arch

Mostrar la arquitectura

branch

Mostrar la rama

version

Mostrar la versión

ref

Mostrar la ref

origin

Mostrar el remoto de origen

commit

Mostrar el commit activo

runtime

Mostrar el entorno de ejecución utilizado

installed-size

Mostrar el tamaño instalado

download-size

Mostrar el tamaño de descarga

options

Mostrar opciones

all

Mostrar todas las columnas

help

Mostrar la lista de columnas disponibles

Tenga en cuenta que los nombres de campo se pueden abreviar hasta un prefijo único.

EJEMPLOS

$ flatpak --user remote-ls --app testrepo

Ref
org.gnome.Builder
org.freedesktop.glxgears

$ flatpak remote-ls file:///run/media/mwleeds/d4d37026-cde2-4e5e-8bcc-d23ebbf231f9/.ostree/repo

Ref
org.kde.Khangman
