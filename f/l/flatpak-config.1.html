FLATPAK CONFIG(1) flatpak config FLATPAK CONFIG(1)

NOMBRE

flatpak-config - Gestionar configuración

SINOPSIS

flatpak config [OPCIÓN...]

flatpak config [OPCIÓN...] --set CLAVE VALOR

flatpak config [OPCIÓN...] --unset|--get CLAVE

DESCRIPCIÓN

El comando flatpak config muestra o modifica la configuración de una instalación de flatpak. Las siguientes claves son compatibles:

languages

Los idiomas que se incluyen al instalar extensiones de idioma (Locale). El valor es una lista separada por punto y coma de códigos de idioma de dos letras, o uno de los valores especiales * o *all*. Si esta clave no está establecida, flatpak por defecto incluye la clave extra-languages y la configuración regional actual.

extra-languages

Esta clave se utiliza cuando no se establece languages y define extensiones de idioma adicionales además de los idiomas configurados en el sistema. El valor es una lista separada por punto y coma de identificadores de idioma (idioma, idioma opcional, codeset opcional, modificador opcional) como se documenta en setlocale(3) (por ejemplo, en;en_DK;zh_HK.big5hkscs;uz_UZ.utf8@cyrillic).

Para la configuración de remotos individuales, consulte flatpak-remote-modify(1). Para la configuración de aplicaciones individuales, consulte flatpak-override(1).

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--list

Imprime todas las claves y sus valores.

--set

Establece la clave CLAVE a VALOR.

--unset

Elimina la clave CLAVE.

--get

Imprime el valor de CLAVE.

-u, --user

Configura la instalación por usuario.

--system

Configura la instalación a nivel de sistema.

--installation=NOMBRE

Configura la instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. El uso de --installation=default es equivalente al uso de --system.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak config --set languages "sv;en;fi"
