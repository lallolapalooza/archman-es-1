NOMBRE

flopen, flopenat — Abrir y bloquear un archivo de forma fiable

BIBLIOTECA

biblioteca «libbsd»

#include <sys/fcntl.h>
#include <libutil.h> (Véase libbsd(7) para el uso de includes.)
int
flopen(const char *path, int flags);

int
flopen(const char *path, int flags, mode_t mode);

int
flopenat(int fd, const char *path, int flags);

int
flopenat(int fd, const char *path, int flags, mode_t mode);

DESCRIPCIÓN

La función flopen() abre o crea un archivo y adquiere un bloqueo exclusivo sobre él. Es esencialmente equivalente a llamar a open() con los mismos parámetros seguido de flock() con un argumento operation de LOCK_EX, excepto que flopen() intentará detectar y manejar las carreras que puedan ocurrir entre la apertura/creación del archivo y su bloqueo. Por lo tanto, es adecuada para abrir archivos de bloqueo, archivos PID, archivos de cola de trabajos (spool), buzones y otros tipos de archivos que se utilizan para la sincronización entre procesos.

Si flags incluye O_NONBLOCK y el archivo ya está bloqueado, flopen() fallará y establecerá errno a EWOULDBLOCK.

Al igual que con open(), el argumento adicional mode es requerido si flags incluye O_CREAT.

La función flopenat() es equivalente a la función flopen() excepto en el caso en que path especifique una ruta relativa. En este caso, el archivo a abrir se determina en relación con el directorio asociado con el descriptor de archivo fd en lugar del directorio de trabajo actual. Si flopenat() recibe el valor especial AT_FDCWD en el parámetro fd, se utiliza el directorio de trabajo actual y el comportamiento es idéntico a una llamada a flopen().

VALORES DE RETORNO

Si tiene éxito, flopen() devuelve un descriptor de archivo válido. De lo contrario, devuelve -1 y establece errno como se describe en flock(2) y open(2).
