NOMBRE

flatpak-ps - Enumerar instancias en ejecución

SINOPSIS

flatpak ps [OPCIÓN...]

DESCRIPCIÓN

Enumera información útil sobre las instancias de Flatpak en ejecución.

Para ver detalles completos de una instancia en ejecución, puede abrir el archivo /run/user/$UID/.flatpak/$INSTANCIA/, donde $INSTANCIA es el ID de la instancia reportado por flatpak ps.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

--columns=CAMPO,...

Especifica qué información mostrar sobre cada instancia. Puede listar varios campos o usar esta opción varias veces.

Añada :s[tart], :m[iddle], :e[nd] o :f[ull] a los nombres de columna para cambiar el elipsis.

CAMPOS

Los siguientes campos son entendidos por la opción --columns:

instance

Muestra el ID de la instancia

application

Muestra el ID de la aplicación

arch

Muestra la arquitectura

branch

Muestra la rama de la aplicación

commit

Muestra el commit de la aplicación

runtime

Muestra el ID del runtime

runtime-branch

Muestra la rama del runtime

runtime-commit

Muestra el commit del runtime

pid

Muestra el PID del proceso contenedor

child-pid

Muestra el PID del proceso del sandbox

active

Muestra si la aplicación está activa (es decir, tiene una ventana activa)

background

Muestra si la aplicación está en segundo plano (sin ventanas abiertas)

all

Muestra todas las columnas

help

Muestra la lista de columnas disponibles

Tenga en cuenta que los nombres de los campos pueden abreviarse a un prefijo único.

EJEMPLOS

$ flatpak ps --columns=application,pid,runtime,runtime-branch
