NOMBRE

flatpak build-commit-from - Crear nuevos commits basados en uno existente (posiblemente de otro repositorio)

SINOPSIS

flatpak build-commit-from [OPCIÓN...] DST-REPO DST-REF...

DESCRIPCIÓN

Crea nuevos commits en la rama DST-REF del DST-REPO, con el contenido (y la mayor parte de los metadatos) tomados de otra rama, ya sea de otro repositorio o de otra rama en el mismo repositorio.

El ID de colección establecido en DST-REPO (si está establecido) se utilizará para los commits recién creados.

Este comando es muy útil cuando se desea mantener una rama con un historial limpio que no tenga commits sin firmar o rotos. Por ejemplo, puede importar la cabeza de otro repositorio de un constructor automático después de haber verificado que funcionó. El nuevo commit no tendrá padres ni firmas del autobuilder, y podrá ser firmado correctamente con la clave oficial.

Cualquier delta que afecte al commit original y que coincida con los commits padre en el repositorio de destino se copia y se reescribe para el nuevo ID de commit.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--src-repo=SRC-REPO

El repositorio (local) del que extraer la rama fuente. Por defecto, es el repositorio de destino.

--src-ref=SRC-REF

La rama que se utilizará como fuente para el nuevo commit. Por defecto, es la misma que la ref de destino, lo cual es útil solo si se ha especificado un repositorio fuente diferente.

--extra-collection-id=COLLECTION-ID

Agrega un enlace adicional de colección-ref para esta colección, además de lo que normalmente se agregaría debido al ID de colección del repositorio de destino. Esta opción se puede usar varias veces.

--subset=SUBSET

Marca el commit para que sea incluido en el subconjunto nombrado. Esto hará que el commit se incluya en el resumen del subconjunto nombrado (además del principal), permitiendo a los usuarios ver solo este subconjunto en lugar de todo el repositorio.

--untrusted

El repositorio fuente no es de confianza, todos los objetos se copian (no se enlazan físicamente) y todas las sumas de verificación se verifican.

-s, --subject=SUBJECT

Asunto de una línea para el mensaje del commit. Si no se especifica, se tomará del commit fuente.

-b, --body=BODY

Descripción completa del mensaje del commit. Si no se especifica, se tomará del commit fuente.

--update-appstream

Actualiza la rama appstream después de la compilación.

--no-update-summary

No actualiza el archivo summary después de que se agregue el nuevo commit. Esto significa que el repositorio no será útil para servir a través de http hasta que se ejecute build-update-repo. Esto es útil si desea realizar múltiples operaciones en el repositorio antes de actualizar finalmente el summary.

--force

Crea un nuevo commit incluso si el contenido no ha cambiado con respecto a la cabeza de la rama existente.

--disable-fsync

No realiza fsync al escribir en el repositorio. Esto puede resultar en pérdida de datos en situaciones excepcionales, pero puede mejorar el rendimiento cuando se trabaja con repositorios temporales o de prueba.

--gpg-sign=KEYID

Firma el commit con esta clave GPG. Esta opción se puede usar varias veces.

--gpg-homedir=PATH

Directorio de inicio GPG a usar al buscar anillos de claves.

--end-of-life=REASON

Marca la compilación como fin de vida útil.

--end-of-life-rebase=OLDID=NEWID

Marca las nuevas refs como fin de vida útil. A diferencia de --end-of-life, este toma un ID que reemplaza al actual. Por solicitud del usuario, los datos de la aplicación pueden conservarse para la nueva aplicación. Tenga en cuenta que esto es en realidad una coincidencia de prefijo, por lo que si dice org.the.app=org.new.app, algo como org.the.app.Locale se reorganizará a org.new.app.Locale.

--timestamp=TIMESTAMP

Anula la marca de tiempo del commit. Utilice una fecha con formato ISO 8601 o NOW para la hora actual.

--disable-fsync

No realiza fsync al escribir en el repositorio. Esto puede resultar en pérdida de datos en situaciones excepcionales, pero puede mejorar el rendimiento cuando se trabaja con repositorios temporales o de prueba.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

Para revertir un commit al commit anterior:

$ flatpak build-commit-from --timestamp=NOW --src-ref=app/org.gnome.gedit/x86_64/master^ repo app/org.gnome.gedit/x86_64/master
