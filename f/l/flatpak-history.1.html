FLATPAK HISTORY(1) historial de flatpak FLATPAK HISTORY(1)

NOMBRE

flatpak-history - Mostrar historial

SINOPSIS

flatpak history [OPCIÓN...]

DESCRIPCIÓN

Muestra los cambios en las instalaciones de flatpak en el sistema. Esto incluye la instalación, actualización y eliminación de aplicaciones y entornos de ejecución.

Por defecto, se muestran tanto las instalaciones por usuario como las del sistema. Utilice las opciones --user, --installation o --system para cambiar esto.

La información para el comando de historial se toma del journal de systemd, y también se puede acceder usando, por ejemplo, journalctl MESSAGE_ID=c7b39b1e006b464599465e105b361485

OPCIONES

Se reconocen las siguientes opciones:

-h, --help

Mostrar opciones de ayuda y salir.

-u, --user

Mostrar cambios en la instalación del usuario.

--system

Mostrar cambios en la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Mostrar cambios en la instalación especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--since=TIEMPO

Mostrar solo cambios más recientes que el tiempo especificado por TIEMPO.

TIEMPO puede ser una hora absoluta en un formato como AAAA-MM-DD HH:MM:SS, o un tiempo relativo como "2h", "7days", "4days 2hours".

--until=TIEMPO

Mostrar solo cambios más antiguos que el tiempo especificado por TIEMPO.

--reverse

Mostrar primero las entradas más recientes.

-v, --verbose

Mostrar información de depuración durante el procesamiento del comando.

--ostree-verbose

Mostrar información de depuración de OSTree durante el procesamiento del comando.

--columns=CAMPO,...

Especificar qué información mostrar sobre cada ref. Puede listar varios campos, o usar esta opción varias veces.

Añada :s[tart], :m[iddle], :e[nd] o :f[ull] a los nombres de columna para cambiar la elipsis.

CAMPOS

Los siguientes campos son reconocidos por la opción --columns:

time

Mostrar cuándo ocurrió el cambio

change

Mostrar el tipo de cambio

ref

Mostrar la ref

application

Mostrar el ID de la aplicación/entorno de ejecución

arch

Mostrar la arquitectura

branch

Mostrar la rama

installation

Mostrar la instalación afectada.

Este será el ID de una instalación de Flatpak o la ruta a un repositorio OSTree temporal.

remote

Mostrar el remoto que se utiliza.

Este será el nombre de un remoto configurado o la ruta a un repositorio OSTree temporal.

old-commit

Mostrar el commit anterior. Para las extracciones (pull), este es el HEAD anterior de la rama. Para los despliegues, es el commit activo anteriormente

commit

Mostrar el commit actual. Para las extracciones (pull), este es el HEAD de la rama. Para los despliegues, es el commit activo

url

Mostrar la URL del remoto

user

Mostrar el usuario que realiza el cambio.

Si es el ayudante del sistema operando como root, también mostrar qué usuario activó el cambio.

tool

Mostrar la herramienta que se utilizó.

Si es el ayudante del sistema, también mostrar qué herramienta se utilizó para activar el cambio.

all

Mostrar todas las columnas

help

Mostrar la lista de columnas disponibles

Tenga en cuenta que los nombres de los campos se pueden abreviar a un prefijo único.
