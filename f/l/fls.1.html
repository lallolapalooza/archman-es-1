FLS(1) Manual de Comandos Generales FLS(1)

NOMBRE

fls - Listar nombres de archivos y directorios en una imagen de disco.

SINOPSIS

fls [-adDFlpruvV] [-m mnt ] [-z zona ] [-f tiposistema ] [-s segundos ] [-i tiposimg ] [-o offsetimg ] [-b tam_sector_disp] imagen [imágenes] [ inodo ]

DESCRIPCIÓN

fls lista los archivos y nombres de directorios en la imagen y puede mostrar los nombres de archivos de archivos borrados recientemente para el directorio usando el inodo dado. Si no se proporciona el argumento inodo, se utiliza el valor del inodo para el directorio raíz. Por ejemplo, en un sistema de archivos NTFS sería 5 y en un sistema de archivos Ext3 sería 2.

Los argumentos son los siguientes:

-a
Mostrar las entradas de directorio "." y ".." (por defecto no lo hace)
-d
Mostrar solo entradas borradas
-D
Mostrar solo entradas de directorio
-f tiposistema
El tipo de sistema de archivos. Use '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-F
Mostrar solo archivos (todos los que no son directorios).
-l
Mostrar detalles del archivo en formato largo. Se muestran los siguientes contenidos:

tipo_archivo inodo nombre_archivo hora_mod hora_acc hora_camb hora_cre tamaño uid gid

-m mnt
Mostrar archivos en formato de máquina del tiempo para que se pueda crear una línea de tiempo con mactime(1). La cadena dada como mnt se antepondrá a los nombres de archivo como punto de montaje (por ejemplo, /usr).
-p
Mostrar la ruta completa para cada entrada. Por defecto, indica la profundidad del directorio en ejecuciones recursivas con un signo '+'.
-r
Mostrar directorios recursivamente. Esto no seguirá directorios borrados, porque no puede.
-s segundos
El desfase horario del sistema original en segundos. Por ejemplo, si el sistema original estaba atrasado 100 segundos, este valor sería -100. Esto solo se usa si se proporcionan -l o -m.
-i tiposimg
Identificar el tipo de archivo de imagen, como raw. Use '-i list' para listar los tipos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-o offsetimg
El desplazamiento de sector donde comienza el sistema de archivos en la imagen.
-b tam_sector_disp
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asumen 512 bytes.
-u
Mostrar solo entradas no borradas
-v
Salida detallada a stderr.
-V
Mostrar versión.
-z zona
La cadena ASCII de la zona horaria del sistema original. Por ejemplo, EST o GMT. Estas cadenas deben ser definidas por su sistema operativo y pueden variar.
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.

Una vez determinado el inodo, el archivo puede recuperarse usando icat(1) de The Coroners Toolkit. La cantidad de información recuperada de las entradas de archivos borradas varía según el sistema. Por ejemplo, en Linux, un archivo borrado recientemente se puede recuperar fácilmente, mientras que en Solaris ni siquiera se puede determinar el inodo. Si solo desea averiguar a qué inodo pertenece un nombre de archivo, es más fácil usar ffind(1).

EJEMPLOS

Para obtener una lista de todos los archivos y directorios en una imagen, use:

# fls -r imagen 2

o simplemente (si no se especifica ningún inodo, se usa el inodo del directorio raíz):

# fls -r imagen

Para obtener la ruta completa de los archivos borrados en un directorio dado:

# fls -d -p imagen 29

Para obtener la salida de mactime, haga:

# fls -m /usr/local imagen 2

Si tiene una imagen de disco y el sistema de archivos comienza en el sector 63, use:

# fls -o 63 disco-img.dd

Si tiene una imagen de disco dividida, use:

# fls -i "split" -o 63 disco-1.dd disco-2.dd disco-3.dd

VER TAMBIÉN
