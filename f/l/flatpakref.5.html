NOMBRE

flatpakref - Referencia a un repositorio para una aplicación o tiempo de ejecución

DESCRIPCIÓN

Flatpak utiliza archivos flatpakref para compartir información sobre un repositorio para una sola aplicación. El archivo flatpakref contiene suficiente información para añadir el repositorio e instalar la aplicación. Utilice el comando flatpak install --from para hacerlo.

Los archivos flatpakref también pueden contener información adicional que es útil al mostrar la aplicación al usuario, por ejemplo, en una tienda de aplicaciones.

La extensión de archivo comúnmente utilizada para los archivos flatpakref es .flatpakref.

Un archivo flatpakref también puede referirse a un repositorio para un tiempo de ejecución.

FORMATO DEL ARCHIVO

El archivo flatpakref utiliza el mismo formato de archivo .ini que se usa para los archivos de unidad de systemd o los archivos .desktop de aplicación.

[Flatpak Ref]

Toda la información está contenida en el grupo [Flatpak Ref].

Las siguientes claves pueden estar presentes en este grupo:

Version (uint64)

La versión del formato del archivo, debe ser 1 si está presente.

Name (string)

El nombre completo del tiempo de ejecución o aplicación. Esta clave es obligatoria.

Url (string)

La URL del repositorio. Esta clave es obligatoria.

Branch (string)

El nombre de la rama desde la cual instalar la aplicación o el tiempo de ejecución. Si esta clave no se especifica, se usa la rama "master".

Title (string)

El título de la aplicación o tiempo de ejecución. Este debería ser un nombre amigable para el usuario que se pueda mostrar, por ejemplo, en una tienda de aplicaciones.

Comment (string)

Un resumen corto de la aplicación o tiempo de ejecución, para mostrar, por ejemplo, en una tienda de aplicaciones.

Description (string)

Una descripción más larga de la aplicación o tiempo de ejecución, para mostrar, por ejemplo, en una tienda de aplicaciones.

Icon (string)

La URL de un icono que se puede usar para representar la aplicación o el tiempo de ejecución.

Homepage (string)

La URL de una página web que describe la aplicación o tiempo de ejecución.

DeploySideloadCollectionID (string)

El ID de colección del repositorio, si tiene uno. Esto identifica de forma única la colección de aplicaciones en el repositorio, para permitir la redistribución peer-to-peer (ver flatpak(1)). Se recomienda usar esta clave en lugar de DeployCollectionID o CollectionID porque solo los clientes más nuevos (Flatpak 1.12.8 o posterior) le prestan atención (y los clientes más antiguos no manejan los IDs de colección correctamente).

DeployCollectionID (string)

Esto está obsoleto pero todavía se admite por motivos de compatibilidad con versiones anteriores. Use DeploySideloadCollectionID en su lugar.

CollectionID (string)

Esto está obsoleto pero todavía se admite por motivos de compatibilidad con versiones anteriores. Use DeploySideloadCollectionID en su lugar.

IsRuntime (boolean)

Si este archivo se refiere a un tiempo de ejecución. Si esta clave no se especifica, se asume que el archivo se refiere a una aplicación.

GPGKey (string)

La clave gpg codificada en base64 para el repositorio.

RuntimeRepo (string)

La URL de un archivo .flatpakrepo para el repositorio donde se puede encontrar el tiempo de ejecución. Tenga en cuenta que si el tiempo de ejecución está disponible en el repositorio que proporciona la aplicación, se puede usar ese repositorio, pero el especificado por esta opción aún se añadirá.

SuggestRemoteName (string)

Un nombre sugerido para el repositorio.
