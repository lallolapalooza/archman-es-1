NOMBRE

flatpak-repo - Muestra información sobre un repositorio local

SINOPSIS

flatpak repo [OPCIÓN...] UBICACIÓN

DESCRIPCIÓN

Muestra información sobre un repositorio local.

Si necesita modificar un repositorio local, consulte el comando flatpak build-update-repo, o use la herramienta ostree.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--info

Imprime información general sobre un repositorio local.

--branches

Enumera las ramas en un repositorio local.

--metadata=BRANCH

Imprime metadatos para una rama en el repositorio.

--commits=BRANCH

Muestra los commits y deltas para una rama en el repositorio.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak repo --info ~/my-repo

VER TAMBIÉN

flatpak(1), flatpak-info(1) flatpak-build-update-repo(1) ostree(1)
