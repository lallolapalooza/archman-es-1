NOMBRE

flatpak-search - Buscar aplicaciones y entornos de ejecución

SINOPSIS

flatpak search TEXT

DESCRIPCIÓN

Busca aplicaciones y entornos de ejecución que coincidan con TEXT. Ten en cuenta que esto utiliza datos de appstream que se pueden actualizar con el comando flatpak update. Los datos de appstream se actualizan automáticamente solo si tienen al menos un día de antigüedad.

OPCIONES

Se entienden las siguientes opciones:

-u, --user

Solo buscar en repositorios remotos en la instalación por usuario.

--system

Solo buscar en repositorios remotos en la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Mostrar una instalación a nivel de sistema por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

-h, --help

Mostrar las opciones de ayuda y salir.

-v, --verbose

Imprimir información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprimir información de depuración de OSTree durante el procesamiento del comando.

--columns=CAMPO,...

Especificar qué información mostrar sobre cada resultado. Puedes listar varios campos, o usar esta opción varias veces.

Añade :s[tart], :m[iddle], :e[nd] o :f[ull] a los nombres de columna para cambiar el truncamiento.

CAMPOS

Los siguientes campos son entendidos por la opción --columns:

name

Mostrar el nombre

description

Mostrar la descripción

application

Mostrar el ID de la aplicación

version

Mostrar la versión

branch

Mostrar la rama

remotes

Mostrar los repositorios remotos

all

Mostrar todas las columnas

help

Mostrar la lista de columnas disponibles

Ten en cuenta que los nombres de campo se pueden abreviar a un prefijo único.
