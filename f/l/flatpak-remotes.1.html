FLATPAK REMOTES(1) flatpak remotes FLATPAK REMOTES(1)

NOMBRE

flatpak-remotes - Listar repositorios remotos

SINOPSIS

flatpak remotes [OPCIÓN...]

DESCRIPCIÓN

Lista los repositorios remotos conocidos, en orden de prioridad.

Por defecto, se muestran tanto las instalaciones por usuario como las del sistema. Utilice las opciones --user, --system o --installation para cambiar esto.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Mostrar las opciones de ayuda y salir.

-u, --user

Mostrar la configuración por usuario.

--system

Mostrar la configuración predeterminada del sistema.

--installation=NOMBRE

Mostrar una instalación del sistema por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

-d, --show-details

Mostrar más información para cada repositorio además del nombre. Equivalente a --columns=all.

--show-disabled

Mostrar repositorios deshabilitados.

-v, --verbose

Mostrar información de depuración durante el procesamiento del comando.

--ostree-verbose

Mostrar información de depuración de OSTree durante el procesamiento del comando.

--columns=CAMPO,...

Especificar qué información mostrar sobre cada ref. Puede listar varios campos o usar esta opción varias veces.

Añada :s[tart], :m[iddle], :e[nd] o :f[ull] a los nombres de columna para cambiar la elisión.

CAMPOS

Los siguientes campos son entendidos por la opción --columns:

name

Mostrar el nombre del repositorio remoto

title

Mostrar el título del repositorio remoto

url

Mostrar la URL del repositorio remoto

filter

Mostrar la ruta al filtro del lado del cliente del repositorio remoto.

collection

Mostrar el ID de colección del repositorio remoto

priority

Mostrar la prioridad del repositorio remoto

options

Mostrar opciones

comment

Mostrar comentario

description

Mostrar descripción

homepage

Mostrar página de inicio

icon

Mostrar icono

all

Mostrar todas las columnas

help

Mostrar la lista de columnas disponibles

Tenga en cuenta que los nombres de los campos se pueden abreviar a un prefijo único.

EJEMPLOS

$ flatpak remotes --user --show-details

testrepo	Test Repository	 http://209.132.179.91/repo/ no-gpg-verify
