NOMBRE

flatpak-update - Actualiza una aplicación o runtime

SINOPSIS

flatpak update [OPCIÓN...] [REF...]

flatpak update [OPCIÓN...] --appstream [REMOTO]

DESCRIPCIÓN

Actualiza aplicaciones y runtimes. REF es una referencia a la aplicación o runtime a actualizar. Si no se proporciona REF, se actualiza todo, así como la información de appstream para todos los remotos.

Cada argumento REF es un identificador completo o parcial en el formato de ref de flatpak, que se ve como "(app|runtime)/ID/ARCH/BRANCH". Todos los elementos excepto ID son opcionales y se pueden omitir, incluyendo las barras, por lo que la mayoría de las veces solo necesitas especificar el ID. Cualquier parte omitida se comparará con lo que está instalado, y si hay múltiples coincidencias, un mensaje de error enumerará las alternativas.

Por defecto, esto busca aplicaciones y runtimes con el REF dado, pero puedes limitarlo usando la opción --app o --runtime, o proporcionando el elemento inicial en el REF.

Normalmente, este comando actualiza la aplicación a la última versión de su rama. Pero es posible seleccionar otro commit, con la opción --commit.

Si el remoto configurado para un ref que se está actualizando tiene un ID de colección configurado, Flatpak buscará en los directorios sideload-repos configurados ya sea con la opción --sideload-repo, o a nivel de instalación individual o general (ver flatpak(1)).

Ten en cuenta que actualizar un runtime es diferente a instalar una rama diferente, y se espera que las actualizaciones de runtime mantengan una compatibilidad estricta. Si una actualización de aplicación causa un problema, es posible volver a la versión anterior, con la opción --commit.

Además de las actualizaciones, este comando ofrecerá desinstalar cualquier runtime obsoleto no utilizado. Los runtimes que fueron instalados explícitamente (no como dependencia) o fijados explícitamente (ver flatpak-pin(1)) se dejan instalados incluso si no se usan y están obsoletos.

A menos que se anule con las opciones --user, --system o --installation, este comando actualiza cualquier ref coincidente en la instalación global predeterminada y la del usuario.

OPCIONES

Se reconocen las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Actualiza una instalación por usuario.

--system

Actualiza la instalación global predeterminada.

--installation=NOMBRE

Actualiza una instalación global especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--arch=ARCH

La arquitectura a actualizar. Ver flatpak --supported-arches para las arquitecturas soportadas por el host.

--subpath=RUTA

Instala solo una subruta del ref. Esto se usa principalmente para instalar un subconjunto de locales. Esto se puede añadir varias veces para instalar múltiples subrutas. Si no se especifica, se reutilizan las subrutas especificadas en el momento de la instalación.

--commit=COMMIT

Actualiza a este commit, en lugar de la última versión de la rama. Puedes encontrar commits usando flatpak remote-info --log REMOTO REF.

--no-deploy

Descarga la última versión, pero no la despliega.

--no-pull

No descargues la última versión, despliega lo que esté disponible localmente.

--no-related

No descargues extensiones relacionadas, como los datos de idioma.

--no-deps

No actualices ni instales dependencias de runtime al instalar.

--app

Busca solo una aplicación con el nombre dado.

--appstream

Actualiza appstream para REMOTO, o todos los remotos si no se especifica ninguno.

--runtime

Busca solo un runtime con el nombre dado.

--sideload-repo=RUTA

Añade un repositorio local ostree adicional como fuente para la instalación. Esto es equivalente a usar los directorios sideload-repos (ver flatpak(1)), pero se puede hacer a nivel de comando. Cualquier ruta añadida aquí se usa además de las de esos directorios.

-y, --assumeyes

Responde automáticamente sí a todas las preguntas (o elige la respuesta más prioritaria). Esto es útil para la automatización.

--noninteractive

Produce una salida mínima y evita la mayoría de las preguntas. Esto es adecuado para su uso en situaciones no interactivas, por ejemplo, en un script de compilación.

--force-remove

Elimina archivos antiguos incluso si están en uso por una aplicación en ejecución.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak --user update org.gnome.gedit
