NOMBRE

fltk-options - aplicación para obtener y modificar opciones de tiempo de ejecución de FLTK.

SINOPSIS

fltk-options [ -Sopción[=valor] ] [ -Uopción[=valor] ] [ -L ] [ -LS ] [ -LU ] [ -f ] [ -v ] [ --verbose ] [ -h[opción] ] [ --help [opción] ]

DESCRIPCIÓN

fltk-options es una herramienta que permite acceder y modificar configuraciones relacionadas con la interfaz de usuario en aplicaciones creadas con FLTK. Estas configuraciones se aplicarán cuando se inicie el programa. Se pueden configurar a nivel del sistema o por el usuario individual. Las configuraciones del usuario tienen prioridad sobre las del sistema.

Los siguientes argumentos de línea de comandos son compatibles:

-Sopción[=valor]

Cambia o imprime una opción a nivel de sistema.
-Uopción[=valor]

Cambia o imprime una opción de usuario. Los valores pueden ser "0" o "OFF" para borrar, o "1" o "ON" para establecer la opción. El valor "-1" o "DEFAULT" establece la opción a su valor predeterminado. Si no se proporciona ningún valor, se devuelve la configuración actual como "-1", "0" o "1".
-L

Lista el valor de todas las opciones.
-LS

Lista el valor de todas las opciones del sistema.
-LU

Lista el valor de todas las opciones del usuario.
-f

Suprime mensajes de error relacionados con los permisos de acceso a archivos.
-v, --verbose

Imprime información adicional en modo de línea de comandos.
-h[opción], --help [opción]

Imprime una página de ayuda. Si se proporciona una opción, imprime información detallada para esa opción.

Las siguientes opciones de FLTK son compatibles:

OPTION_VISIBLE_FOCUS

Dibuja un rectángulo punteado en el widget con foco de teclado.
OPTION_ARROW_FOCUS

Las teclas de flecha moverán el foco más allá del campo de entrada de texto.
OPTION_SHOW_TOOLTIPS

Muestra u oculta las descripciones emergentes (tooltips).
OPTION_DND_TEXT

El usuario puede arrastrar texto de FLTK a otras aplicaciones.
OPTION_FNFC_USES_GTK

Utiliza el selector de archivos GTK en lugar del de FLTK si está disponible.
OPTION_PRINTER_USES_GTK

Utiliza el diálogo de impresión GTK en lugar del de FLTK si está disponible.
OPTION_SHOW_SCALING

Muestra el factor de zoom en una ventana emergente transitoria.

Llamar a fltk-options sin opciones iniciará el modo interactivo de fltk-options.
