FLATPAK INSTALLATION(5) Instalación de flatpak FLATPAK INSTALLATION(5)

NOMBRE

flatpak-installation - Configuración para una ubicación de instalación

DESCRIPCIÓN

Flatpak puede operar en modo global para todo el sistema o por usuario. Los datos del sistema se encuentran en $prefix/var/lib/flatpak/, y los datos por usuario en $HOME/.local/share/flatpak/.

Además de las ubicaciones de instalación predeterminadas, se pueden definir más instalaciones globales mediante archivos de configuración en /etc/flatpak/installations.d/, que deben tener la extensión .conf y seguir el formato descrito a continuación.

FORMATO DEL ARCHIVO

El formato del archivo de configuración de instalación utiliza el mismo formato de archivo .ini que se usa para los archivos de unidad de systemd o los archivos .desktop de aplicaciones.

[Instalación ...]

Toda la configuración para la ubicación de instalación con el nombre NOMBRE se contiene en el grupo [Instalación "NOMBRE"].

Se reconocen las siguientes claves:

Path (cadena)

La ruta para esta instalación. Esta clave es obligatoria.

DisplayName (cadena)

El nombre a usar al mostrar esta instalación en la interfaz de usuario.

Priority (entero)

Una prioridad para esta instalación.

StorageType (cadena)

El tipo de almacenamiento utilizado para esta instalación. Los valores posibles incluyen: network, mmc, sdcard, harddisk.

EJEMPLOS

[Instalación "extra"]
Path=/location/of/sdcard
DisplayName=Instalación Extra
StorageType=sdcard
