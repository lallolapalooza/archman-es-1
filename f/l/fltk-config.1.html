NOMBRE

fltk-config - script para obtener información sobre la versión instalada de fltk.

SINOPSIS

fltk-config [ --prefix [=DIR] ] [ --exec-prefix [=DIR] ] [ --version ] [ --api-version ] [ --use-gl ] [ --use-images ] [ --use-glut ] [ --cc ] [ --cxx ] [ --cflags ] [ --cxxflags ] [ --ldflags ] [ --ldstaticflags ] [ --libs ] [ -Dnombre[=valor] ] [ -g ] [ --compile programa.cxx ]

DESCRIPCIÓN

fltk-config es un script utilitario que puede ser utilizado para obtener información sobre la versión actual de FLTK instalada en el sistema, qué opciones de compilador y enlazador usar al compilar aplicaciones basadas en FLTK, y para compilar aplicaciones FLTK simples.

Las siguientes opciones son soportadas:

--api-version

Muestra el número de versión de la API de FLTK actual, p. ej. "1.1".
--cc
--cxx

Muestra el compilador C/C++ que se utilizó para compilar FLTK.
--cflags
--cxxflags

Muestra las opciones del compilador C/C++ a usar al compilar archivos fuente que usan FLTK.
--compile programa.cxx

Compila el archivo fuente programa.cxx en programa. Esta opción implica "--post programa".
-g

Habilita información de depuración al compilar con la opción --compile.
--ldflags

Muestra las opciones del enlazador a usar al enlazar una aplicación FLTK.
--ldstaticflags

Muestra las opciones del enlazador a usar al enlazar una aplicación FLTK a las bibliotecas estáticas de FLTK.
--libs

Muestra la ruta completa a los archivos de la biblioteca FLTK, para ser utilizada en la verificación de dependencias.
--use-gl

Habilita el soporte de OpenGL.
--use-glut

Habilita el soporte de GLUT.
--use-images

Habilita el soporte de archivos de imagen.
--version

Muestra el número de versión actual de FLTK, p. ej. "1.1.0".
