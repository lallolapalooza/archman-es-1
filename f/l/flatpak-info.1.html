NOMBRE

flatpak-info - Mostrar información sobre una aplicación o entorno de ejecución instalado

SINOPSIS

flatpak info [OPCIÓN...] NOMBRE [RAMA]

DESCRIPCIÓN

Muestra información sobre una aplicación o entorno de ejecución instalado.

Por defecto, la salida se formatea de manera amigable. Si se especifica alguna de las opciones --show-... o --file-access, la salida se formatea de manera legible por máquina.

Por defecto, se consultan tanto las instalaciones por usuario como las del sistema. Utilice las opciones --user, --system o --installation para cambiar esto.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Consulta las instalaciones por usuario.

--system

Consulta la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Consulta una instalación a nivel de sistema por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--arch=ARQUITECTURA

Consulta para esta arquitectura. Consulte flatpak --supported-arches para las arquitecturas soportadas por el host.

-r, --show-ref

Muestra la referencia instalada.

-o, --show-origin

Muestra el repositorio remoto del que está instalada la referencia.

-c, --show-commit

Muestra el ID del commit instalado.

-s, --show-size

Muestra el tamaño instalado.

-m, --show-metadata

Muestra los metadatos.

--show-runtime

Muestra el entorno de ejecución.

--show-sdk

Muestra el SDK.

-M, --show-permissions

Muestra los permisos.

--file-access=RUTA

Muestra el nivel de acceso a la ruta dada.

-e, --show-extensions

Muestra las extensiones coincidentes.

-l, --show-location

Muestra la ubicación en el disco de la aplicación o entorno de ejecución. Consulte los ejemplos a continuación.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak info org.gnome.Builder//master

$ tree `flatpak info -l org.gnome.Builder//master`/files
