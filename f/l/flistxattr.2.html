DESCRIPCIÓ

N

Los atributos extendidos son pares de nombre:valor asociados con inodos (archivos, directorios, enlaces simbólicos, etc.). Son extensiones de los atributos normales que se asocian con todos los inodos del sistema (es decir, los datos de stat(2)). Se puede encontrar una visión general completa de los conceptos de los atributos extendidos en xattr(

7).

listxattr() recupera la lista de nombres de los atributos extendidos asociados con la ruta dada en el sistema de archivos. La lista recuperada se coloca en list, un búfer asignado por el llamante cuyo tamaño (en bytes) se especifica en el argumento size. La lista es el conjunto de nombres (terminados en nulo), uno tras otro. Los nombres de los atributos extendidos a los que el proceso llamante no tiene acceso pueden omitirse de la lista. Se devuelve la longitud de la lista de nombres de los atributos .

llistxattr() es idéntica a listxattr(), excepto en el caso de un enlace simbólico, donde se recupera la lista de nombres de los atributos extendidos asociados con el propio enlace, no con el archivo al que hace

referencia.

flistxattr() es idéntica a listxattr(), solo que se interroga el archivo abierto al que hace referencia fd (tal como lo devuelve open(2)) en lugar de path

.

Un nombre de un solo atributo extendido es una cadena terminada en nulo. El nombre incluye un prefijo de espacio de nombres; puede haber varios espacios de nombres disjuntos asociados con un inodo

individual.

Si size se especifica como cero, estas llamadas devuelven el tamaño actual de la lista de nombres de los atributos extendidos (y dejan list sin cambios). Esto se puede utilizar para determinar el tamaño del búfer que se debe suministrar en una llamada posterior. (Pero, ten en cuenta que existe la posibilidad de que el conjunto de atributos extendidos cambie entre las dos llamadas, por lo que aún es necesario comprobar el estado de retorno de la segunda llamada.

)

Como se indica en xattr(7), el VFS impone un límite de 64 kB en el tamaño de la lista de nombres de los atributos extendidos devuelta por listxattr(). Si el tamaño total de los nombres de los atributos adjuntos a un archivo

EJEMPLO

S

El siguiente programa demuestra el uso de listxattr() y getxattr(2). Para el archivo cuya ruta de acceso se proporciona como argumento de la línea de comandos, lista todos los atributos extendidos del archivo y sus

valores.

Para mantener el código simple, el programa asume que las claves y los valores de los atributos son constantes durante la ejecución del programa. Un programa de producción debería esperar y gestionar los cambios durante la ejecución del programa. Por ejemplo, el número de bytes necesarios para las claves de los atributos podría aumentar entre las dos llamadas a listxattr(). Una aplicación podría gestionar esta posibilidad usando un bucle que reintenta la llamada (quizás hasta un número máximo predeterminado de intentos) con un búfer más grande cada vez que falla con el error ERANGE. Las llamadas a getxattr(2) podrían gestionarse de manera

similar.

ejemplo.

Código fuente del programa (listxattr.

c) 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/xattr.h>
int
main(int argc, char *argv[])
{
    char     *buf, *key, *val;
    ssize_t  buflen, keylen, vallen;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s path\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /*
     * Determine the length of the buffer needed.
     */
    buflen = listxattr(argv[1], NULL, 0);
    if (buflen == -1) {
        perror("listxattr");
        exit(EXIT_FAILURE);
    }
    if (buflen == 0) {
        printf("%s has no attributes.\n", argv[1]);
        exit(EXIT_SUCCESS);
    }
    /*
     * Allocate the buffer.
     */
    buf = malloc(buflen);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    /*
     * Copy the list of attribute keys to the buffer.
     */
    buflen = listxattr(argv[1], buf, buflen);
    if (buflen == -1) {
        perror("listxattr");
        exit(EXIT_FAILURE);
    }
    /*
     * Loop over the list of zero terminated strings with the
     * attribute keys.  Use the remaining buffer length to determine
     * the end of the list.
     */
    key = buf;
    while (buflen > 0) {
        /*
         * Output attribute key.
         */
        printf("%s: ", key);
        /*
         * Determine length of the value.
         */
        vallen = getxattr(argv[1], key, NULL, 0);
        if (vallen == -1)
            perror("getxattr");
        if (vallen > 0) {
            /*
             * Allocate value buffer.
             * One extra byte is needed to append 0x00.
             */
            val = malloc(vallen + 1);
            if (val == NULL) {
                perror("malloc");
                exit(EXIT_FAILURE);
            }
            /*
             * Copy value to buffer.
             */
            vallen = getxattr(argv[1], key, val, vallen);
            if (vallen == -1) {
                perror("getxattr");
            } else {
                /*
                 * Output attribute value.
                 */
                val[vallen] = 0;
                printf("%s", val);
            }
            free(val);
        } else if (vallen == 0) {
            printf("<no value>");
        }
        printf("\n");
        /*
         * Forward to next attribute key.
         */
        keylen = strlen(key) + 1;
        buflen -= keylen;
        key += keylen;
    }
    free(buf);
    exit(EXIT_SUCCESS)
;
}
