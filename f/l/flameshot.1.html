DESCRIPCIÓ

N

Esta página de manual documenta brevemente el comando flameshot tal como es proporcionado por el paquete fla

meshot.

flameshot es una herramienta de captura de pantalla que pretende ser potente pero fácil de usar. Sus características notables incluyen apariencia personalizable, edición de capturas de pantalla dentro de la aplicación, interfaz D-Bus, soporte de icono en la bandeja, soporte experimental de GNOME/KDE Wayland, integración con Imgur y soporte tanto para la interfaz gráfica como para la de línea de

comandos.

Además de la información de uso sobre flameshot en esta página de manual, puede encontrar información similar usando flameshot --help. El mismo --help se puede usar para cada subcomando también para obtener los argumentos válidos para ellos. El uso detallado de flameshot está documentado en el archivo README.md en la página del repositorio Git del proyecto: https://github.com/flameshot-org/flamesh

SUBCOMANDO

S

Por defecto, sin subcomandos, flameshot ejecuta Flameshot en segundo plano y añade un icono en la bandeja para la configuración. Tenga en cuenta que no tomará una captura de pantalla a menos que defina uno de los modos a través de los subcomandos. Hay varios subcomandos que se pueden usar para usar flameshot en diferentes

modos:

pantalla.

RETORNO

Devuelve 0 en una salida normal, 2 si la captura de

pantalla se aborta, 3 si se pierde la conexión con
dbus, 130 al recibir SIGINT, 143 al recibir SIGTERM.
