NOMBRE

flawz - Una UI de Terminal para navegar por las CVEs

SINOPSIS

flawz [--url] [-f|--feeds] [-d|--db] [-u|--force-update] [-o|--offline] [-q|--query] [-t|--theme] [-h|--help] [-V|--version]

DESCRIPCIÓN

Una UI de Terminal para navegar por las CVEs

OPCIONES

--url=URL [por defecto: https://nvd.nist.gov/feeds/json/cve/1.1/]
Una URL donde se pueden encontrar los feeds CVE 1.1 de NIST
También puede especificarse con la variable de entorno URL.
-f, --feeds=FEEDS [por defecto: 2002:2024,recent,modified]
Lista de feeds que se sincronizarán
También puede especificarse con la variable de entorno FEEDS.
-d, --db=DB
Ruta a la base de datos SQLite utilizada para almacenar los datos CVE sincronizados
También puede especificarse con la variable de entorno DB.
-u, --force-update
Obtener siempre los feeds
-o, --offline
No obtener los feeds
-q, --query=QUERY
Iniciar con una consulta de búsqueda
También puede especificarse con la variable de entorno QUERY.
-t, --theme=THEME [por defecto: dracula]
Establecer el tema

Valores posibles:

  • dracula: Dracula
  • nord: Nord
  • one-dark: One Dark
  • solarized-dark: Solarized Dark
  • gruvbox-light: Gruvbox Light
-h, --help
Imprimir ayuda (ver un resumen con '-h')
-V, --version
Imprimir versión

VERSIÓN

v0.3.0
