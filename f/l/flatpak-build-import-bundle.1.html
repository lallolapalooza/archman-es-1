NOMBRE

flatpak-build-import-bundle - Importar un paquete de archivos en un repositorio local

SINOPSIS

flatpak build-import-bundle [OPCIÓN...] UBICACIÓN ARCHIVO

DESCRIPCIÓN

Importa un paquete de un archivo llamado ARCHIVO en el repositorio en UBICACIÓN.

El formato del archivo de paquete es el generado por build-bundle.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

--ref=REF

Anula la referencia especificada en el paquete.

--oci

Importa una imagen OCI en lugar de un paquete Flatpak.

--update-appstream

Actualiza la rama appstream después de la construcción.

--no-update-summary

No actualiza el archivo de resumen después de que se agrega el nuevo commit. Esto significa que el repositorio no será útil para servir a través de http hasta que se ejecute build-update-repo. Esto es útil si desea realizar varias operaciones de repositorio antes de finalmente actualizar el resumen.

--gpg-sign=KEYID

Firma el commit con esta clave GPG. Esta opción se puede usar varias veces.

--gpg-homedir=PATH

Directorio de inicio GPG a usar al buscar anillos de claves.

VER TAMBIÉN
