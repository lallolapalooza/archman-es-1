NOMBRE

flatpak-remote-add - Añadir un repositorio remoto

SINOPSIS

flatpak remote-add [OPCIÓN...] NOMBRE UBICACIÓN

DESCRIPCIÓN

Añade un repositorio remoto a la configuración de repositorios de flatpak. NOMBRE es el nombre del nuevo repositorio remoto, y UBICACIÓN es una URL o una ruta de sistema de archivos. La UBICACIÓN es un repositorio flatpak, o un archivo .flatpakrepo que describe un repositorio. En el primer caso, es posible que también tenga que especificar opciones adicionales, como la clave GPG del repositorio.

A menos que se anule con las opciones --user o --installation, este comando cambia la instalación predeterminada a nivel de sistema.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--from

Asume que la URI es un archivo .flatpakrepo en lugar del repositorio en sí. Esto está habilitado por defecto si la extensión es .flatpakrepo, por lo que generalmente no necesita esta opción.

-u, --user

Modifica la configuración por usuario.

--system

Modifica la configuración predeterminada a nivel de sistema.

--installation=NOMBRE

Modifica una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--no-gpg-verify

Deshabilita la verificación GPG para el repositorio añadido.

--prio=PRIO

Establece la prioridad del repositorio. Por defecto es 1, un valor mayor indica mayor prioridad. Esto se usa principalmente para herramientas de instalación gráficas. También se utiliza al buscar un repositorio para proporcionar el runtime de una aplicación. El origen de la aplicación se verifica antes que otros repositorios con la misma prioridad.

--subset=SUBSET

Limita las referencias disponibles del repositorio a aquellas que forman parte del subconjunto nombrado.

--no-enumerate

Marca el repositorio como no enumerado. Esto significa que el repositorio no se usará para listar aplicaciones, por ejemplo, en herramientas de instalación gráficas.

--no-use-for-deps

Marca el repositorio como no utilizable para la resolución automática de dependencias de runtime.

--if-not-exists

No haga nada si el repositorio proporcionado ya existe.

--disable

Deshabilita el repositorio añadido.

--title=TÍTULO

Un título para el repositorio remoto, por ejemplo, para mostrar en una interfaz de usuario.

--comment=COMENTARIO

Un comentario de una sola línea para el repositorio remoto, por ejemplo, para mostrar en una interfaz de usuario.

--description=DESCRIPCIÓN

Una descripción de párrafo completo para el repositorio remoto, por ejemplo, para mostrar en una interfaz de usuario.

--homepage=URL

URL de un sitio web para el repositorio remoto, por ejemplo, para mostrar en una interfaz de usuario.

--icon=URL

URL de un icono para el repositorio remoto, por ejemplo, para mostrar en una interfaz de usuario.

--default-branch=BRANCH

Una rama predeterminada para el repositorio remoto, principalmente para uso en una interfaz de usuario.

--filter=RUTA

Añade un filtro local al repositorio remoto. Un archivo de filtro es una lista de líneas, cada una comenzando con "allow" o "deny", y luego un glob para la referencia a permitir o denegar. Los globs especifican una referencia parcial (es decir, puede omitir partes finales que luego coincidirán con todo), pero por lo demás, solo "*" es especial, coincidiendo con cualquier cosa en esa parte de la referencia.

Por defecto, todas las referencias están permitidas, pero si una referencia coincide con una regla de denegación, se deniega a menos que coincida específicamente con una regla de permiso. Esto significa que puede usar esto para implementar tanto listas de permisos como de denegación.

Aquí hay un ejemplo de archivo de filtro:

# Este es un filtro estilo lista de permisos ya que deniega todo primero
deny *
allow runtime/org.freedesktop.*
allow org.some.app/arm
allow org.signal.Signal/*/stable
allow org.signal.Signal.*/*/stable

--gpg-import=ARCHIVO

Importa claves gpg del archivo de keyring especificado como confiables para el nuevo repositorio remoto. Si el archivo es -, el keyring se lee de la entrada estándar.

--authenticator-name=NOMBRE

Especifica el autenticador a utilizar para el repositorio remoto.

--authenticator-option=CLAVE=VALOR

Especifica una opción de autenticador para el repositorio remoto.

--authenticator-install

Habilita la instalación automática del autenticador.

--no-authenticator-install

Deshabilita la instalación automática del autenticador.

--no-follow-redirect

No seguir xa.redirect-url definido en el archivo de resumen.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak remote-add gnome https://sdk.gnome.org/gnome.flatpakrepo

$ flatpak --user remote-add --no-gpg-verify test-repo https://people.gnome.org/~alexl/gnome-sdk/repo/
