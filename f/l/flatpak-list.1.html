NOMBRE

flatpak-list - Lista aplicaciones y/o runtimes instalados

SINOPSIS

flatpak list [OPCIÓN...]

DESCRIPCIÓN

Lista los nombres de las aplicaciones y runtimes instalados.

Por defecto, se muestran tanto las aplicaciones como los runtimes, pero puedes cambiar esto usando las opciones --app o --runtime.

Por defecto, se muestran tanto las instalaciones por usuario como las del sistema. Utiliza las opciones --user, --installation o --system para cambiar esto.

El comando list también se puede usar para encontrar aplicaciones instaladas que usan un runtime específico, con la opción --app-runtime.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Lista las instalaciones por usuario.

--system

Lista las instalaciones por defecto a nivel de sistema.

--installation=NOMBRE

Lista una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Utilizar --installation=default es equivalente a usar --system.

--arch=ARQUITECTURA

Lista aplicaciones/runtimes para esta arquitectura. Consulta flatpak --supported-arches para las arquitecturas soportadas por el host.

-d, --show-details

Muestra el origen, tamaños y otra información adicional. Equivalente a --columns=all.

--app

Lista aplicaciones.

--runtime

Lista runtimes.

--all, -a

Lista todos los runtimes instalados, incluyendo extensiones de localización y depuración. Estos están ocultos por defecto.

--app-runtime=RUNTIME

Lista aplicaciones que utilizan el runtime dado.

-v, --verbose

Muestra información de depuración durante el procesamiento del comando.

--ostree-verbose

Muestra información de depuración de OSTree durante el procesamiento del comando.

--columns=CAMPO,...

Especifica qué información mostrar sobre cada ref. Puedes listar varios campos o usar esta opción varias veces.

Añade :s[tart], :m[iddle], :e[nd] o :f[ull] a los nombres de columna para cambiar el elipsisado.

CAMPOS

Los siguientes campos son entendidos por la opción --columns:

name

Muestra el nombre

description

Muestra la descripción

application

Muestra el ID de la aplicación o runtime

arch

Muestra la arquitectura

branch

Muestra la rama

runtime

Muestra el runtime utilizado

version

Muestra la versión

ref

Muestra la ref

origin

Muestra el remoto de origen

installation

Muestra la instalación

active

Muestra el commit activo

latest

Muestra el último commit

size

Muestra el tamaño instalado

options

Muestra las opciones

all

Muestra todas las columnas

help

Muestra la lista de columnas disponibles

Ten en cuenta que los nombres de campo pueden abreviarse a un prefijo único.

EJEMPLOS

$ flatpak --user --columns=app list
