NOMBRE

flatpak-permission-set - Establecer permisos

SINOPSIS

flatpak permission-set [OPCIÓN...] TABLA ID ID_APLICACION [PERMISO...]

DESCRIPCIÓN

Establece los permisos para una aplicación en una entrada del almacén de permisos. La entrada se identifica mediante TABLA e ID, y la aplicación se identifica mediante ID_APLICACION. Las cadenas de PERMISO deben estar en un formato adecuado para la tabla.

El almacén de permisos es utilizado por los portales. Cada portal generalmente tiene su propia tabla en el almacén de permisos, y el formato de las entradas de la tabla es específico para cada portal.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--data=DATOS

Asocia DATOS con la entrada. Los datos deben ser un GVariant serializado.

-v, --verbose

Muestra información de depuración durante el procesamiento del comando.

--ostree-verbose

Muestra información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak permission-set --data "{'always-ask':<true>}" desktop-used-apps text/plain org.mozilla.Firefox org.gnome.gedit 0 3
