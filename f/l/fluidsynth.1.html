FluidSynth(1) Manual general de comandos FluidSynth(1)

NOMBRE

FluidSynth - un sintetizador SoundFont

SINOPSIS

fluidsynth [opciones] [ SoundFonts ] [ ficheros midi ]

DESCRIPCIÓN

FluidSynth es un sintetizador MIDI en tiempo real basado en las especificaciones de SoundFont(R) 2. Puede ser utilizado para renderizar entrada MIDI o ficheros MIDI a audio. Los eventos MIDI se leen desde un dispositivo MIDI. El sonido se renderiza en tiempo real al dispositivo de salida de audio.

La forma más fácil de iniciar el sintetizador es darle un SoundFont en la línea de comandos: 'fluidsynth soundfont.sf2'. fluidsynth cargará el SoundFont y leerá eventos MIDI desde el dispositivo MIDI predeterminado usando el controlador MIDI predeterminado. Una vez que FluidSynth está en ejecución, lee comandos desde la entrada estándar. Hay comandos para enviar eventos MIDI manualmente, para cargar o descargar SoundFonts, y así sucesivamente. Todos los comandos disponibles se discuten a continuación.

FluidSynth también puede ser utilizado para reproducir una lista de ficheros MIDI. Simplemente ejecute FluidSynth con el SoundFont y la lista de ficheros MIDI a reproducir. En este caso, puede que no quiera abrir el dispositivo MIDI para leer eventos externos. Use la opción -n para desactivar la entrada MIDI. Si también quiere desactivar el uso del shell, inicie FluidSynth con la opción -i: 'fluidsynth -ni soundfont.sf2 midifile1.mid midifile2.mid'.

Ejecute fluidsynth con la opción --help para comprobar cambios en la lista de opciones.

OPCIONES

fluidsynth acepta las siguientes opciones:

-a, --audio-driver=[etiqueta]
El controlador de audio a usar. "-a help" para listar opciones válidas
-b, --bank-offset=[num]
Un indicador posicional que especifica el offset del banco para cualquier Soundfont que siga a dicho indicador. Puede especificarse múltiples veces.
-c, --audio-bufcount=[cantidad]
Número de búferes de audio
-C, --chorus
Activa o desactiva el coro [0|1|sí|no, predeterminado = activado]
-d, --dump
Vuelca los eventos MIDI entrantes y salientes a stdout
-E, --audio-file-endian
Endian del fichero de audio para renderizado rápido o controlador aufile ("-E help" para la lista)
-f, --load-config
Carga un fichero de configuración de comandos (comandos shell)
-F, --fast-render=[fichero]
Renderiza el fichero MIDI a datos de audio crudos y los guarda en [fichero]
-g, --gain
Establece la ganancia maestra [0 < ganancia < 10, predeterminado = 0.2]
-G, --audio-groups
Define el número de nodos de audio LADSPA
-h, --help
Imprime este resumen de ayuda
-i, --no-shell
No lee comandos desde el shell [predeterminado = sí]
-j, --connect-jack-outputs
Intenta conectar las salidas de Jack a los puertos físicos
-K, --midi-channels=[num]
El número de canales MIDI [predeterminado = 16]
-L, --audio-channels=[num]
El número de canales de audio estéreo [predeterminado = 1]
-m, --midi-driver=[etiqueta]
El nombre del controlador MIDI a usar. "-m help" para listar opciones válidas.
-n, --no-midi-in
No crea un controlador MIDI para leer eventos de entrada MIDI [predeterminado = sí]
-o
Define una configuración, -o nombre=valor ("-o help" para volcar los valores actuales)
-O, --audio-file-format
Formato del fichero de audio para renderizado rápido o controlador aufile ("-O help" para la lista)
-p, --portname=[etiqueta]
Establece el nombre del puerto MIDI (controladores alsa_seq, coremidi)
-q, --quiet
No imprime el mensaje de bienvenida ni otra salida informativa
-r, --sample-rate
Establece la frecuencia de muestreo
-R, --reverb
Activa o desactiva la reverberación [0|1|sí|no, predeterminado = activado]
-s, --server
Inicia FluidSynth como un proceso servidor
-T, --audio-file-type
Tipo de fichero de audio para renderizado rápido o controlador aufile ("-T help" para la lista)
-v, --verbose
Imprime mensajes detallados sobre eventos MIDI (synth.verbose=1) así como otros mensajes de depuración
-V, --version
Muestra la versión del programa
-z, --audio-bufsize=[tamaño]
Tamaño de cada búfer de audio

CONFIGURACIONES

Las configuraciones a especificar con -o están documentadas en fluidsettings.xml, que se espera que se distribuya con esta distribución o en línea en https://www.fluidsynth.org/api/fluidsettings.xml . Recomendamos ver este fichero en un navegador web, preferiblemente Firefox.

COMANDOS DE SHELL

GENERAL
help
Imprime la lista de temas de ayuda (escribe "help <tema>" para ver detalles sobre los comandos disponibles)
quit
Sale del sintetizador
SOUNDFONTS
load nombre_fichero [reset] [bankofs]
Carga un SoundFont en la pila de SoundFonts. Si reset es 1 (que es el predeterminado implícito), todos los presets de SoundFont actualmente en uso se reevaluarán teniendo en cuenta el SoundFont recién cargado. Opcionalmente, puede especificar un offset de banco no nulo para el nuevo SoundFont. Por ejemplo, el comando load soundfont.sf2 0 10 cargará soundfont.sf2 con un offset de banco de 10 sin reevaluar los presets.
unload número
Descarga un SoundFont. El número es el índice del SoundFont en la pila.
fonts
Lista los SoundFonts actuales en la pila
inst número
Imprime los instrumentos disponibles para el SoundFont.
MENSAJES MIDI
noteon canal nota velocidad
Envía un evento note-on
noteoff canal nota
Envía un evento note-off
cc canal ctrl valor
Envía un evento de cambio de control
prog chan num
Envía un mensaje de cambio de programa
select chan sfont banco prog
Combinación de cambio de banco y cambio de programa
channels
Imprime los presets de todos los canales.
