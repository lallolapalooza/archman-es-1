NOMBRE

flatpak-remote-delete - Eliminar un repositorio remoto

SINOPSIS

flatpak remote-delete [OPCIÓN...] NOMBRE

DESCRIPCIÓN

Elimina un repositorio remoto de la configuración de repositorios de flatpak. NOMBRE es el nombre de un repositorio remoto existente.

A menos que se anule con las opciones --system, --user, o --installation, este comando utiliza la instalación predeterminada a nivel de sistema o la del usuario, dependiendo de cuál contenga el REPOSITORIO especificado.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Modifica la configuración por usuario.

--system

Modifica la configuración predeterminada a nivel de sistema.

--installation=NOMBRE

Modifica una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--force

Elimina el repositorio remoto incluso si está en uso por aplicaciones o tiempos de ejecución instalados.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak --user remote-delete dried-raisins
