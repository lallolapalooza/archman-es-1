FLOOR(3P) Manual del programador POSIX FLOOR(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

floor, floorf, floorl — función piso

SINOPSIS

#include <math.h>
double floor(double x);
float floorf(float x);
long double floorl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

Estas funciones calcularán el valor entero más grande no mayor que x.

VALOR DE RETORNO

El resultado tendrá el mismo signo que x.

Al completarse con éxito, estas funciones devolverán el valor entero más grande no mayor que x, expresado como un double, float o long double, según corresponda al tipo de retorno de la función.

Si x es NaN, se devolverá un NaN.

Si x es ±0 o ±Inf, se devolverá x.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

El valor entero devuelto por estas funciones podría no ser expresable como un intmax_t. El valor de retorno debe ser comprobado antes de asignarlo a un tipo entero para evitar los resultados indefinidos de un desbordamiento entero.

Estas funciones pueden generar la excepción de punto flotante inexacta si el resultado difiere en valor del argumento.
