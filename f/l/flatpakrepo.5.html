NOMBRE

flatpakrepo - Referencia a un repositorio remoto

DESCRIPCIÓN

Flatpak utiliza archivos flatpakrepo para compartir información sobre repositorios remotos. El archivo flatpakrepo contiene suficiente información para añadir el repositorio. Utilice el comando flatpak remote-add --from para hacerlo.

Los archivos flatpakrepo también pueden contener información adicional que es útil al mostrar un repositorio al usuario, por ejemplo, en una tienda de aplicaciones.

La extensión de archivo comúnmente utilizada para los archivos flatpakrepo es .flatpakrepo.

Los archivos flatpakrepo también pueden colocarse en /usr/share/flatpak/remotes.d/ y /etc/flatpak/remotes.d/ para preconfigurar estáticamente repositorios a nivel de sistema. Dichos archivos deben usar la extensión .flatpakrepo. Si existe un archivo con el mismo nombre en ambos directorios, el archivo en /etc prevalecerá.

FORMATO DEL ARCHIVO

El archivo flatpakrepo utiliza el mismo formato de archivo .ini que se usa para los archivos de unidad de systemd o los archivos .desktop de aplicaciones.

[Flatpak Repo]

Toda la información está contenida en el grupo [Flatpak Repo].

Las siguientes claves pueden estar presentes en este grupo:

Version (uint64)

La versión del formato del archivo, debe ser 1 si está presente.

Url (string)

La url para el repositorio remoto. Esta clave es obligatoria.

GPGKey (string)

La clave gpg codificada en base64 para el repositorio remoto.

DefaultBranch (string)

La rama por defecto a utilizar para este repositorio remoto.

Subset (string)

Limita el repositorio a la subconjunto de referencias nombradas.

Title (string)

El título del repositorio remoto. Este debe ser un nombre fácil de usar que se pueda mostrar, por ejemplo, en una tienda de aplicaciones.

Comment (string)

Un resumen corto del repositorio remoto, para mostrarlo, por ejemplo, en una tienda de aplicaciones.

Description (string)

Una descripción más larga del repositorio remoto, para mostrarla, por ejemplo, en una tienda de aplicaciones.

Icon (string)

La url de un icono que se puede utilizar para representar el repositorio remoto.

Homepage (string)

La url de una página web que describe el repositorio remoto.

Filter (string)

La ruta de un archivo local para filtrar las referencias del repositorio remoto. Consulte flatpak-remote-add(1) para más detalles sobre el formato del archivo.

Nota: Este campo es tratado de forma especial por flatpak remote-add. Si instala un repositorio con --if-not-exists y el repositorio ya está configurado, el campo filter de la configuración del repositorio se actualizará de todos modos. Y, si el campo filter no se especifica, se limpiarán todos los filtros existentes. El objetivo aquí es permitir que un repositorio filtrado preconfigurado sea reemplazado por el normal si se añade el archivo flatpakrepo upstream (sin filtrar) normal.

DeploySideloadCollectionID (string)

El ID de colección del repositorio remoto, si lo tiene. Esto identifica de forma única la colección de aplicaciones en el repositorio, para permitir la redistribución peer-to-peer (ver flatpak(1)). Se recomienda usar esta clave en lugar de DeployCollectionID o CollectionID porque solo los clientes más nuevos (Flatpak 1.12.8 o posterior) le prestan atención (y los clientes más antiguos no manejan los IDs de colección correctamente).

DeployCollectionID (string)

Esto está obsoleto pero todavía se admite por compatibilidad con versiones anteriores. Utilice DeploySideloadCollectionID en su lugar.

CollectionID (string)

Esto está obsoleto pero todavía se admite por compatibilidad con versiones anteriores. Utilice DeploySideloadCollectionID en su lugar.
