NOMBRE

flatpak-remote - Configuración de un repositorio remoto

DESCRIPCIÓN

Flatpak almacena información sobre los repositorios remotos configurados para una ubicación de instalación en $installation/repo/config. Por ejemplo, los repositorios remotos para la instalación global predeterminada se encuentran en $prefix/var/lib/flatpak/repo/config, y los repositorios remotos para la instalación por usuario se encuentran en $HOME/.local/share/flatpak/repo/config.

Normalmente, no es necesario editar directamente los archivos de configuración de los repositorios remotos; se debe usar el comando flatpak remote-modify para cambiar las propiedades de los repositorios remotos.

Los repositorios remotos globales pueden preconfigurarse estáticamente colocando archivos de flatpakrepo(5) en /usr/share/flatpak/remotes.d/ y /etc/flatpak/remotes.d/. Si existe un archivo con el mismo nombre en ambas ubicaciones, el archivo en /etc tendrá precedencia.

FORMATO DEL ARCHIVO

El formato del archivo de configuración del repositorio remoto utiliza el mismo formato de archivo .ini que se usa para los archivos de unidad de systemd o los archivos .desktop de aplicaciones.

[remote ...]

Toda la configuración para el repositorio remoto con el nombre NOMBRE se contiene en el grupo [remote "NOMBRE"].

OSTree reconoce, entre otras, las siguientes claves:

url (cadena)

La URL para el repositorio remoto. Una URL del tipo oci+https:// o oci+http:// es una extensión de Flatpak que indica que el repositorio remoto no es un repositorio ostree, sino una URL a un índice de imágenes OCI que se almacenan dentro de un registro de imágenes de contenedor.

Para repositorios OCI, los certificados del cliente y de la CA se leen de /etc/containers/certs.d y de ~/.config/containers/certs.d, como se documenta en containers-certs.d(5).

gpg-verify (booleano)

Indica si se debe usar la verificación GPG para el contenido de este repositorio remoto.

gpg-verify-summary (booleano)

Indica si se debe usar la verificación GPG para el resumen de este repositorio remoto.

Esto se ignora si se establece collection-id, ya que las referencias se verifican en los metadatos del commit en ese caso. Habilitar gpg-verify-summary rompería la distribución peer-to-peer de referencias.

collection-id (cadena)

El identificador único global para el repositorio de colección de origen, para permitir agrupar espejos.

Todas las claves específicas de Flatpak tienen un prefijo xa.:

xa.disable (booleano)

Indica si el repositorio remoto está deshabilitado. El valor predeterminado es falso.

xa.prio (entero)

La prioridad para el repositorio remoto. Se utiliza al listar los repositorios remotos y al buscarlos para obtener el tiempo de ejecución necesario para una aplicación. El repositorio que proporciona la aplicación se busca para obtener su tiempo de ejecución antes que otros con la misma prioridad. El valor predeterminado es 1.

xa.noenumerate (booleano)

Indica si este repositorio remoto debe ignorarse al presentar las aplicaciones/tiempos de ejecución disponibles o al buscar una dependencia de tiempo de ejecución. El valor predeterminado es falso.

xa.nodeps (booleano)

Indica si este repositorio remoto debe excluirse al buscar dependencias. El valor predeterminado es falso.

xa.title (cadena)

Un título opcional para usar al presentar este repositorio remoto en una interfaz de usuario.

xa.title-is-set (booleano)

Esta clave se establece en verdadero si xa.title se ha establecido explícitamente.

xa.comment (cadena)

Un comentario opcional de una sola línea para usar al presentar este repositorio remoto en una interfaz de usuario.

xa.comment-is-set (booleano)

Esta clave se establece en verdadero si xa.comment se ha establecido explícitamente.

xa.description (cadena)

Un párrafo opcional de texto para usar al presentar este repositorio remoto en una interfaz de usuario.

xa.description-is-set (booleano)

Esta clave se establece en verdadero si xa.description se ha establecido explícitamente.

xa.homepage (cadena)

Una URL opcional que apunta a un sitio web para este repositorio que se utilizará al presentar este repositorio remoto en una interfaz de usuario.

xa.homepage-is-set (booleano)

Esta clave se establece en verdadero si xa.homepage se ha establecido explícitamente.

xa.icon (cadena)

Una URL opcional que apunta a un icono para este repositorio que se utilizará al presentar este repositorio remoto en una interfaz de usuario.

xa.icon-is-set (booleano)

Esta clave se establece en verdadero si xa.icon se ha establecido explícitamente.

xa.default-branch (cadena)

La rama predeterminada a usar al instalar desde este repositorio remoto.

xa.default-branch-is-set (booleano)

Esta clave se establece en verdadero si xa.default-branch se ha establecido explícitamente.

xa.main-ref (cadena)

La referencia principal servida por este repositorio remoto. Se utiliza para los repositorios de origen de las aplicaciones instaladas a través de un archivo flatpakref.

EJEMPLOS

[remote "gnome-nightly-apps"]
gpg-verify=true
gpg-verify-summary=true
url=https://sdk.gnome.org/nightly/repo-apps/
xa.title=Aplicaciones GNOME
[remote "flathub"]
gpg-verify=true
gpg-verify-summary=false
collection-id=org.flathub.Stable
url=https://dl.flathub.org/repo/
xa.title=Flathub
