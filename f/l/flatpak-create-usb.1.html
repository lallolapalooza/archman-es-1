NOMBRE

flatpak-create-usb - Copiar aplicaciones y/o tiempos de ejecución en medios extraíbles.

SINOPSIS

flatpak create-usb [OPCIÓN...] RUTA-MONTAJE REF...

DESCRIPCIÓN

Copia las REFERENCIAS de aplicaciones y/o tiempos de ejecución especificadas en los medios extraíbles montados en RUTA-MONTAJE, junto con todas las dependencias y metadatos necesarios para instalarlos. Esta es una forma de transferir flatpaks entre ordenadores que no requiere conexión a Internet. Después de usar este comando, la unidad USB puede conectarse a otro ordenador que ya tenga configurado el o los remotos relevantes, y Flatpak instalará o actualizará desde la unidad sin conexión (ver abajo). Si está en línea, la unidad se utilizará como caché, lo que significa que algunos objetos se extraerán de ella y otros de Internet. Para que este proceso funcione, se debe configurar un ID de colección en los remotos relevantes en ambos ordenadores (origen y destino), y en el servidor remoto.

En el ordenador de destino se puede instalar desde la USB (o cualquier sistema de archivos montado) utilizando la opción --sideload-repo con flatpak install. También es posible configurar rutas de carga lateral mediante enlaces simbólicos; consulte flatpak(1). Flatpak también incluye unidades systemd para cargar automáticamente desde unidades USB conectadas en caliente, pero estas pueden estar habilitadas o no dependiendo de su distribución Linux.

Cada argumento REF es un identificador completo o parcial en el formato de referencia flatpak, que se ve así: "(app|runtime)/ID/ARCH/BRANCH". Todos los elementos excepto ID son opcionales y pueden omitirse, incluidas las barras inclinadas, por lo que la mayoría de las veces solo necesita especificar el ID. Cualquier parte omitida se comparará con lo que está instalado, y si hay varias coincidencias, un mensaje de error listará las alternativas.

Por defecto, busca tanto aplicaciones instaladas como tiempos de ejecución con la REF dada, pero puede limitarlo usando la opción --app o --runtime.

Todas las REFERENCIAS deben estar en la misma instalación (usuario, sistema u otra). De lo contrario, es ambiguo de qué metadatos del repositorio extraer en la unidad USB.

Por defecto, flatpak create-usb utiliza .ostree/repo como directorio de destino bajo MOUNT-PATH, pero si especifica otra ubicación usando --destination-repo, se creará un enlace simbólico para usted en .ostree/repos.d. Esto asegura que de cualquier manera el repositorio será encontrado por flatpak (y otros consumidores de libostree) para operaciones de instalación/actualización.

A menos que se anule con las opciones --system, --user o --installation, este comando busca tanto en la instalación a nivel de sistema como en la del usuario para REF y genera un error si existe en más de una.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

-u, --user

Copia referencias de la instalación por usuario.

--system

Copia referencias de la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Copia referencias de una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

--app

Asume que todas las REFERENCIAS son aplicaciones si no se especifican explícitamente.

--runtime

Asume que todas las REFERENCIAS son tiempos de ejecución si no se especifican explícitamente.

--destination-repo=DEST

Crea el repositorio en DEST bajo MOUNT-PATH, en lugar de la ubicación predeterminada.

--allow-partial

No imprime una advertencia al exportar commits parcialmente instalados, por ejemplo, extensiones de idioma sin todos los idiomas. Estos pueden causar problemas al instalarlos, por ejemplo, si la configuración de idioma es diferente en el lado de la instalación.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

--ostree-verbose

Imprime información de depuración de OSTree durante el procesamiento del comando.

EJEMPLOS

$ flatpak create-usb /run/media/mwleeds/1a9b4cb2-a7ef-4d9b-91a5-6eaf8fdd2bf6/ com.endlessm.wiki_art.en
