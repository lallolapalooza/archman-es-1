NOMBRE

flatpak-mask - Enmascara actualizaciones e instalación automática

SINOPSIS

flatpak mask [OPCIÓN...] PATRÓN...

DESCRIPCIÓN

Flatpak mantiene una lista de patrones que definen qué refs están enmascarados. Un ref enmascarado nunca se actualizará ni se instalará automáticamente (por ejemplo, una extensión enmascarada marcada como descarga automática no se descargará). Aún puedes instalar manualmente dichos refs, pero una vez instalados, la versión se fijará.

Los patrones son solo una parte del ref, con el carácter * coincidiendo con cualquier cosa dentro de esa parte del ref. Aquí hay algunos patrones de ejemplo:

org.some.App
org.some.App//unstable
app/org.domain.*
org.some.App/arm

Para listar el conjunto actual de máscaras, ejecuta este comando sin ningún patrón.

OPCIONES

Se reconocen las siguientes opciones:

-h, --help

Muestra las opciones de ayuda y sale.

--remove

En lugar de añadir los patrones, elimina los patrones coincidentes.

-u, --user

Enmascara refs en una instalación por usuario.

--system

Enmascara refs en la instalación predeterminada a nivel de sistema.

--installation=NOMBRE

Enmascara refs en una instalación a nivel de sistema especificada por NOMBRE entre las definidas en /etc/flatpak/installations.d/. Usar --installation=default es equivalente a usar --system.

-v, --verbose

Imprime información de depuración durante el procesamiento del comando.

EJEMPLOS

$ flatpak mask

$ flatpak mask org.broken.App

$ flatpak mask --remove org.broken.App
