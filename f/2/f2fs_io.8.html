f2fs_io(8) Utilidades de Administración del Sistema f2fs_io(8)

NOMBRE

f2fs_io - utilidad ioctl de f2fs

DESCRIPCIÓN

f2fs_io se utiliza para enviar varios comandos al sistema de archivos f2fs para fines administrativos.

COMANDOS DISPONIBLES

set_verity [archivo]
Establece las banderas de veracidad asociadas con el archivo especificado.
getflags [archivo]
Obtiene las banderas asociadas con el archivo especificado.
setflags [bandera] [archivo]
Establece un archivo f2fs en el archivo especificado. La bandera puede ser casefold, compression y nocompression.
shutdown apagado sistema_archivos
Congela y detiene todas las operaciones de E/S para el sistema de archivos montado en dir. El parámetro de nivel puede ser:
0
apagándose con sincronización completa
1
apagándose solo con punto de control
2
apagándose sin sincronización
3
apagándose con volcado de metadatos
4
apagándose con marca fsck
pinfile [get|set] [archivo]
Obtiene o establece el estado de fijación en un archivo.
fallocate [tamano_mantener] [desplazamiento] [longitud] [archivo]
Solicita que se asigne espacio en un archivo. El parámetro tamano_mantener puede ser 1 o 0.
write [tamano_bloque en 4kb] [desplazamiento en tamano_bloque] [cantidad] [patron] [E/S] [ruta_archivo]
Escribe un patrón dado en ruta_archivo. El parámetro patron puede ser:
zero
ceros
inc_num
números incrementales
rand
números aleatorios
El parámetro E/S puede ser:
buffered
E/S en búfer
dio
E/S directa
dsync
E/S directa con O_DSYNC
read [tamano_bloque en 4kb] [desplazamiento en tamano_bloque] [cantidad] [E/S] [imprimir_nbytes] [ruta_archivo]
Lee datos en ruta_archivo e imprime imprimir_nbytes. Las opciones de E/S pueden ser:
buffered
E/S en búfer
dio
E/S directa
fiemap [desplazamiento en 4kb] [cantidad] [ruta_archivo]
Obtiene la dirección del bloque en el archivo.
gc_urgent dev [start|end|run] [tiempo en seg]
Inicia, finaliza o ejecuta gc_urgent durante un período de tiempo dado.
defrag_file [inicio] [longitud] [ruta_archivo]
Desfragmenta un archivo.
copy [-d] [-m] [-s] [ruta_origen] [ruta_destino]
Copia el archivo de ruta_origen a ruta_destino. El parámetro patron puede ser:
-d
usa E/S directa
-m
usa mmap para el archivo de origen
-s
usa sendfile para transferir datos
get_cblocks [archivo]
Obtiene el número de bloques comprimidos.
release_cblocks [archivo]
Libera bloques comprimidos para obtener espacio libre.
reserve_cblocks [archivo]
Reserva bloques libres para preparar la descompresión de bloques en el archivo.
gc [modo_sincronizacion] [archivo]
Desencadena la GC del sistema de archivos.
