Paquete: f2fs-tools

Licencias: GPL

F2FSCRYPT(8) Manual del Administrador del Sistema F2FSCRYPT(8)

NOMBRE

f2fscrypt - Utilidad de cifrado del sistema de archivos f2fs

SINOPSIS

f2fscrypt add_key -S [ -k keyring ] [-v] [-q] [ ruta ... ]
f2fscrypt new_session
f2fscrypt get_policy ruta ...
f2fscrypt set_policy política ruta ...

DESCRIPCIÓN

f2fscrypt realiza la gestión del cifrado para los sistemas de archivos f2fs.

COMANDOS

f2fscrypt add_key -S [ -k keyring ] [-v] [-q] [ ruta ... ]
Solicita al usuario una frase de contraseña y la inserta en el keyring especificado. Si no se especifica ningún keyring, f2fscrypt usará el keyring de sesión si existe o el keyring de sesión del usuario si no existe.
Si se especifican uno o más directorios, f2fscrypt intentará establecer la política de esos directorios para usar la clave introducida por el usuario.
f2fscrypt get_policy ruta ...
Imprime la política de los directorios especificados en la línea de comandos.
f2fscrypt new_session
Proporciona al proceso invocador (típicamente un shell) un nuevo keyring de sesión, descartando su keyring de sesión anterior.
f2fscrypt set_policy política ruta ...
Establece la política para los directorios especificados en la línea de comandos. Todos los directorios deben estar vacíos para establecer la política; si el directorio ya tiene una política establecida, f2fscrypt validará que la política coincide con lo especificado. Una política es un identificador de clave de cifrado que consta de 16 caracteres hexadecimales.

NOTAS

El directorio de destino debe estar vacío.

EJEMPLO

Formatea un sistema de archivos f2fs que soporta cifrado.
# mkfs.f2fs -O encrypt /dev/sdxx
# mount /dev/sdxx /encrypted/
# mkdir /encrypted/dir
Primero crea la clave en el keyring usando una sal simple
(o genera una sal aleatoria).
Luego úsala para establecer la política del directorio a cifrar.
# f2fscrypt add_key -S 0x1234
  Introduce frase de contraseña (eco deshabilitado):
  Clave añadida con descriptor [28e21cc0c4393da1]
# f2fscrypt set_policy 28e21cc0c4393da1 /encrypted/dir
  Clave con descriptor [28e21cc0c4393da1] aplicada a /encrypted/dir.
# touch /encrypted/dir/test.txt
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 test.txt
Después de cada reinicio, el mismo comando se puede usar para establecer
la clave de descifrado del directorio y sus descendientes.
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 zbx7tsUEMLzh+AUVMkQcnB
# f2fscrypt get_policy /encrypted/dir/
  /encrypted/dir/: 28e21cc0c4393da1
# f2fscrypt add_key -S 0x1234
  Introduce frase de contraseña (eco deshabilitado):
  Clave añadida con descriptor [28e21cc0c4393da1]
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 test.txt
Muestra los keyrings de los procesos.
# keyctl show
  Session Keyring
    84022412 --alswrv      0     0  keyring: _ses
   204615789 --alswrv      0 65534   \_ keyring: _uid.0
   529474961 --alsw-v      0     0   \_ logon: f2fs:28e21cc0c4393da1
