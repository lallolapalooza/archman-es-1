F_GET_RW_HINT(2const) F_GET_RW_HINT(2const)

NOMBRE

F_GET_RW_HINT, F_SET_RW_HINT, F_GET_FILE_RW_HINT, F_SET_FILE_RW_HINT - obtener/establecer pistas de lectura/escritura de archivo

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <fcntl.h>
int fcntl(int fd, F_GET_RW_HINT, uint64_t *arg);
int fcntl(int fd, F_SET_RW_HINT, uint64_t *arg);
int fcntl(int fd, F_GET_FILE_RW_HINT, uint64_t *arg);
int fcntl(int fd, F_GET_FILE_RW_HINT, uint64_t *arg);

DESCRIPCIÓN

Las pistas de vida útil de escritura se pueden utilizar para informar al kernel sobre la vida útil relativa esperada de las escrituras en un inodo determinado o a través de una descripción de archivo abierta particular. (Véase open(2) para una explicación de las descripciones de archivo abiertas.) En este contexto, el término "vida útil de escritura" significa el tiempo esperado que los datos vivirán en los medios, antes de ser sobrescritos o borrados.

Una aplicación puede utilizar los diferentes valores de pista especificados a continuación para separar las escrituras en diferentes clases de escritura, de modo que múltiples usuarios o aplicaciones que se ejecutan en un único backend de almacenamiento puedan agregar sus patrones de I/O de manera consistente. Sin embargo, no hay semántica funcional implícita por estas banderas, y diferentes clases de I/O pueden usar las pistas de vida útil de escritura de manera arbitraria, siempre que las pistas se utilicen de manera consistente.

Las siguientes operaciones se pueden aplicar al descriptor de archivo, fd:

F_GET_RW_HINT
Devuelve el valor de la pista de lectura/escritura asociada con el inodo subyacente al que se refiere fd.
F_SET_RW_HINT
Establece el valor de la pista de lectura/escritura asociado con el inodo subyacente al que se refiere fd. Esta pista persiste hasta que se modifica explícitamente o hasta que se desmonta el sistema de archivos subyacente.
F_GET_FILE_RW_HINT
Devuelve el valor de la pista de lectura/escritura asociada con la descripción de archivo abierta a la que se refiere fd.
F_SET_FILE_RW_HINT
Establece el valor de la pista de lectura/escritura asociado con la descripción de archivo abierta a la que se refiere fd.

Si a una descripción de archivo abierta no se le ha asignado una pista de lectura/escritura, utilizará el valor asignado al inodo, si lo hay.

Las siguientes pistas de lectura/escritura son compatibles:

RWH_WRITE_LIFE_NOT_SET
No se ha establecido ninguna pista específica. Este es el valor predeterminado.
RWH_WRITE_LIFE_NONE
No hay una vida útil de escritura específica asociada con este archivo o inodo.
RWH_WRITE_LIFE_SHORT
Se espera que los datos escritos en este inodo o a través de esta descripción de archivo abierta tengan una vida útil corta.
RWH_WRITE_LIFE_MEDIUM
Se espera que los datos escritos en este inodo o a través de esta descripción de archivo abierta tengan una vida útil más larga que los datos escritos con RWH_WRITE_LIFE_SHORT.
RWH_WRITE_LIFE_LONG
Se espera que los datos escritos en este inodo o a través de esta descripción de archivo abierta tengan una vida útil más larga que los datos escritos con RWH_WRITE_LIFE_MEDIUM.
RWH_WRITE_LIFE_EXTREME
Se espera que los datos escritos en este inodo o a través de esta descripción de archivo abierta tengan una vida útil más larga que los datos escritos con RWH_WRITE_LIFE_LONG.

Todas las pistas específicas de escritura son relativas entre sí, y no se debe atribuir ningún significado absoluto individual a ellas.

VALOR DE RETORNO

Cero.

En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

Ver fcntl(2).
