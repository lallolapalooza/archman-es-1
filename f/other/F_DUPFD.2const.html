F_DUPFD(2const) F_DUPFD(2const)

NOMBRE

F_DUPFD, F_DUPFD_CLOEXEC - duplicar un descriptor de archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <fcntl.h>
int fcntl(int fd, F_DUPFD, int arg);
int fcntl(int fd, F_DUPFD_CLOEXEC, int arg);

DESCRIPCIÓN

F_DUPFD
Duplica el descriptor de archivo fd usando el descriptor de archivo disponible de menor número mayor o igual que arg. Esto es diferente de dup2(2), que utiliza exactamente el descriptor de archivo especificado.
En caso de éxito, se devuelve el nuevo descriptor de archivo.
Ver dup(2) para más detalles.
F_DUPFD_CLOEXEC
Como para F_DUPFD, pero además establece el indicador de cierre al ejecutar para el descriptor de archivo duplicado. Especificar este indicador permite a un programa evitar una operación adicional de F_SETFD(2const) para establecer el indicador FD_CLOEXEC. Para una explicación de por qué este indicador es útil, ver la descripción de O_CLOEXEC en open(2).

VALOR DE RETORNO

El nuevo descriptor de archivo.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Ver fcntl(2).

EINVAL
arg es negativo o es mayor que el valor máximo permitido (ver la discusión de RLIMIT_NOFILE en getrlimit(2)).
EMFILE
Se ha alcanzado el límite por proceso en el número de descriptores de archivo abiertos.

VERSIÓNES

POSIX.1-2024 especifica F_DUPFD_CLOFORK, pero Linux no lo soporta.

ESTÁNDARES

POSIX.1-2024.

HISTORIAL

F_DUPFD
SVr4, 4.3BSD, POSIX.1-2001.
F_DUPFD_CLOEXEC
Linux 2.6.24. POSIX.1-2008. (Para obtener esta definición, define _POSIX_C_SOURCE con el valor 200809L o superior, o _XOPEN_SOURCE con el valor 700 o superior.)

ADVERTENCIAS

Los errores devueltos por dup2(2) son diferentes de los devueltos por F_DUPFD.

VER TAMBIÉN

dup2(2), fcntl(2)
