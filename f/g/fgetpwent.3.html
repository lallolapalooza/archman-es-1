fgetpwent(3) Manual de funciones de la biblioteca fgetpwent(3)

NOMBRE

fgetpwent - obtener entrada del archivo de contraseñas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <sys/types.h>
#include <pwd.h>
struct passwd *fgetpwent(FILE *stream);
Requisitos de las macros de prueba de características para glibc (ver feature_test_macros(7)):

fgetpwent():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

La función fgetpwent() devuelve un puntero a una estructura que contiene los campos desglosados de una línea en el archivo stream. La primera vez que se llama, devuelve la primera entrada; después, devuelve entradas sucesivas. El archivo al que se refiere stream debe tener el mismo formato que /etc/passwd (ver passwd(5)).

La estructura passwd se define en <pwd.h> de la siguiente manera:


struct passwd {
    char   *pw_name;       /* nombre de usuario */
    char   *pw_passwd;     /* contraseña del usuario */
    uid_t   pw_uid;        /* ID de usuario */
    gid_t   pw_gid;        /* ID de grupo */
    char   *pw_gecos;      /* nombre real */
    char   *pw_dir;        /* directorio de inicio */
    char   *pw_shell;      /* programa shell */
};

VALOR DE RETORNO

La función fgetpwent() devuelve un puntero a una estructura passwd, o NULL si no hay más entradas o ocurre un error. En caso de error, errno se establece para indicar el error.

ERRORES

ENOMEM
Memoria insuficiente para asignar la estructura passwd.

ARCHIVOS

/etc/passwd
archivo de la base de datos de contraseñas
