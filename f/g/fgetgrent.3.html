fgetgrent(3) Manual de Funciones de Biblioteca fgetgrent(3)

NOMBRE

fgetgrent - obtener entrada del archivo de grupo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <sys/types.h>
#include <grp.h>
struct group *fgetgrent(FILE *stream);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

fgetgrent():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

La función fgetgrent() devuelve un puntero a una estructura que contiene la información del grupo del archivo al que se refiere stream. La primera vez que se llama, devuelve la primera entrada; posteriormente, devuelve entradas sucesivas. El archivo al que se refiere stream debe tener el mismo formato que /etc/group (ver group(5)).

La estructura group se define en <grp.h> como sigue:


struct group {
    char   *gr_name;        /* nombre del grupo */
    char   *gr_passwd;      /* contraseña del grupo */
    gid_t   gr_gid;         /* ID del grupo */
    char  **gr_mem;         /* arreglo terminado en NULL de punteros
                               a nombres de miembros del grupo */
};

VALOR DE RETORNO

La función fgetgrent() devuelve un puntero a una estructura group, o NULL si no hay más entradas o ocurre un error. En caso de error, errno se establece para indicar el error.

ERRORES

ENOMEM
Memoria insuficiente para asignar la estructura group.
