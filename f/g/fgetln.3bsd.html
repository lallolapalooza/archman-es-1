fgetln(3bsd)

Paquete: libbsd

Licencias: custom

fgetln(3bsd) 3bsd fgetln(3bsd)

NOMBRE

fgetln — obtener una línea de un flujo

BIBLIOTECA

biblioteca «libbsd»

SINOPSIS

#include <stdio.h> (Ver libbsd(7) para el uso de la inclusión.)
char *
fgetln(FILE *stream, size_t *len);

DESCRIPCIÓN

La función fgetln() devuelve un puntero a la siguiente línea del flujo referenciado por stream. Esta línea no es una cadena C, ya que no termina con un carácter NUL terminador. La longitud de la línea, incluida la nueva línea final, se almacena en la ubicación de memoria a la que apunta len y se garantiza que sea mayor que 0 al completarse con éxito. (Sin embargo, tenga en cuenta que si la línea es la última en un archivo que no termina con una nueva línea, el texto devuelto no contendrá una nueva línea).

VALORES DE RETORNO

Al completarse con éxito, se devuelve un puntero; este puntero se vuelve inválido después de la siguiente operación de E/S en stream (sea exitosa o no) o tan pronto como se cierre el flujo. De lo contrario, se devuelve NULL. La función fgetln() no distingue entre el fin de archivo y el error; las rutinas feof(3) y ferror(3) deben usarse para determinar cuál ocurrió. Si ocurre un error, la variable global errno se establece para indicar el error. La condición de fin de archivo se recuerda, incluso en una terminal, y todos los intentos posteriores de lectura devolverán NULL hasta que la condición se borre con clearerr(3).

El texto al que apunta el puntero devuelto puede modificarse, siempre que no se realicen cambios más allá del tamaño devuelto. Estos cambios se pierden tan pronto como el puntero se vuelve inválido.

ERRORES

[EBADF]
El argumento stream no es un flujo abierto para lectura.

La función fgetln() también puede fallar y establecer errno por cualquiera de los errores especificados para las rutinas fflush(3), malloc(3), read(2), stat(2) o realloc(3).

VER TAMBIÉN

ferror(3), fgets(3), fgetwln(3bsd), fopen(3), putc(3)

HISTORIAL

La función fgetln() apareció por primera vez en 4.4BSD.
