getgrent_r(3) Manual de Funciones de Biblioteca getgrent_r(3)

NOMBRE

getgrent_r, fgetgrent_r - obtiene una entrada del archivo de grupos de forma reentrante

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <grp.h>
int getgrent_r(size_t size;
               struct group *restrict gbuf,
               char buf[restrict size], size_t size,
               struct group **restrict gbufp);
int fgetgrent_r(size_t size;
               FILE *restrict stream, struct group *restrict gbuf,
               char buf[restrict size], size_t size,
               struct group **restrict gbufp);
Requisitos de la macro de prueba de características para glibc (ver feature_test_macros(7)):

getgrent_r():

    _GNU_SOURCE

fgetgrent_r():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

Las funciones getgrent_r() y fgetgrent_r() son las versiones reentrantes de getgrent(3) y fgetgrent(3). La primera lee la siguiente entrada de grupo del flujo inicializado por setgrent(3). La segunda lee la siguiente entrada de grupo de stream.

La estructura group está definida en <grp.h> de la siguiente manera:


struct group {
    char   *gr_name;        /* group name */
    char   *gr_passwd;      /* group password */
    gid_t   gr_gid;         /* group ID */
    char  **gr_mem;         /* NULL-terminated array of pointers
                               to names of group members */
};

Para más información sobre los campos de esta estructura, ver group(5).

Las funciones no reentrantes devuelven un puntero al almacenamiento estático, donde este almacenamiento estático contiene más punteros al nombre del grupo, la contraseña y los miembros. Las funciones reentrantes descritas aquí devuelven todo eso en buffers proporcionados por el llamante. En primer lugar está el buffer gbuf que puede contener un struct group. Y a continuación el buffer buf de tamaño size que puede contener cadenas adicionales. El resultado de estas funciones, el struct group leído del flujo, se almacena en el buffer proporcionado *gbuf, y un puntero a este struct group se devuelve en *gbufp.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0 y *gbufp es un puntero al struct group. En caso de error, estas funciones devuelven un valor de error y *gbufp es NULL.

ERRORES

ENOENT
No hay más entradas.
ERANGE
Espacio de buffer proporcionado insuficiente. Inténtelo de nuevo con un buffer más grande.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
getgrent_r () Seguridad de hilos MT-Unsafe race:grent locale
fgetgrent_r () Seguridad de hilos MT-Safe

En la tabla anterior, grent en race:grent significa que si alguna de las funciones setgrent(3), getgrent(3), endgrent(3), o getgrent_r() se usan en paralelo en diferentes hilos de un programa, podrían ocurrir condiciones de carrera en los datos.

VERSIONES

Otros sistemas usan el prototipo


struct group *getgrent_r(struct group *grp, char buf[.size],
                         int size);

o, mejor,


int getgrent_r(struct group *grp, char buf[.size], int size,
               FILE **gr_fp);

ESTÁNDARES

GNU.

HISTORIA

Estas funciones están hechas en un estilo que se asemeja a la versión POSIX de funciones como getpwnam_r(3).

NOTAS

La función getgrent_r() no es realmente reentrante ya que comparte la posición de lectura en el flujo con todos los demás hilos.

EJEMPLOS

#define _GNU_SOURCE
#include <grp.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define BUFLEN 4096
int
main(void)
{
    struct group grp;
    struct group *grpp;
    char buf[BUFLEN];
    int i;
    setgrent();
    while (1) {
        i = getgrent_r(&grp, buf, sizeof(buf), &grpp);
        if (i)
            break;
        printf("%s (%jd):", grpp->gr_name, (intmax_t) grpp->gr_gid);
        for (size_t j = 0; ; j++) {
            if (grpp->gr_mem[j] == NULL)
                break;
            printf(" %s", grpp->gr_mem[j]);
        }
        printf("\n");
    }
    endgrent();
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN

fgetgrent(3), getgrent(3), getgrgid(3), getgrnam(3), putgrent(3), group(5)
