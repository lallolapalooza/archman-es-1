FGETWS(3P) Manual del programador POSIX FGETWS(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fgetws — obtener una cadena de caracteres anchos de un flujo

SINOPSIS

#include <stdio.h>
#include <wchar.h>
wchar_t *fgetws(wchar_t *restrict ws, int n,
    FILE *restrict stream);

DESCRIPCION

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función fgetws() leerá caracteres del stream, los convertirá a los códigos de caracteres anchos correspondientes, los colocará en el array wchar_t apuntado por ws, hasta que se lean n-1 caracteres, o se lea un <nueva línea>, se convierta y se transfiera a ws, o se encuentre una condición de fin de archivo. La cadena de caracteres anchos, ws, se terminará entonces con un código de carácter ancho nulo.

Si ocurre un error, el valor resultante del indicador de posición del archivo para el flujo no está especificado.

La función fgetws() puede marcar la marca de tiempo del último acceso a los datos del archivo asociado con stream para su actualización. La marca de tiempo del último acceso a los datos se marcará para actualización mediante la primera ejecución exitosa de fgetwc(), fgetws(), fwscanf(), getwc(), getwchar(), vfwscanf(), vwscanf(), o wscanf() usando stream que devuelva datos no suministrados por una llamada previa a ungetwc().

VALOR DE RETORNO

Al completarse con éxito, fgetws() devolverá ws. Si el indicador de fin de archivo para el flujo está establecido, o si el flujo está en fin de archivo, el indicador de fin de archivo para el flujo se establecerá y fgetws() devolverá un puntero nulo. Si ocurre un error de lectura, el indicador de error para el flujo se establecerá, fgetws() devolverá un puntero nulo y establecerá errno para indicar el error.

ERRORES

Consulte fgetwc().
