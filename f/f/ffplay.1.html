NOMBRE

ffplay - Reproductor multimedia FFplay

SINOPSIS

ffplay [opciones] [input_url]

DESCRIPCIÓN

FFplay es un reproductor multimedia muy simple y portable que utiliza las bibliotecas FFmpeg y la biblioteca SDL. Se utiliza principalmente como banco de pruebas para las distintas API de FFmpeg.

OPCIONES

Todas las opciones numéricas, a menos que se especifique lo contrario, aceptan como entrada una cadena que representa un número, la cual puede ir seguida de uno de los prefijos de unidad SI, por ejemplo: 'K', 'M' o 'G'.

Si se añade 'i' al prefijo de unidad SI, el prefijo completo se interpretará como un prefijo de unidad para múltiplos binarios, los cuales se basan en potencias de 1024 en lugar de potencias de 1000. Añadir 'B' al prefijo de unidad SI multiplica el valor por 8. Esto permite usar, por ejemplo: 'KB', 'MiB', 'G' y 'B' como sufijos numéricos.

Las opciones que no toman argumentos son opciones booleanas y establecen el valor correspondiente a verdadero. Se pueden establecer a falso anteponiendo "no" al nombre de la opción. Por ejemplo, usar "-nofoo" establecerá la opción booleana llamada "foo" a falso.

Las opciones que toman argumentos admiten una sintaxis especial donde el argumento dado en la línea de comandos se interpreta como una ruta al archivo desde el cual se carga el valor real del argumento. Para usar esta función, añada una barra inclinada '/' inmediatamente antes del nombre de la opción (después del guion inicial). Por ejemplo:

ffmpeg -i INPUT -/filter:v filter.script OUTPUT

cargará una descripción de grafo de filtros desde el archivo llamado filter.script.

Especificadores de flujo

Algunas opciones se aplican por flujo, por ejemplo la tasa de bits o el códec. Los especificadores de flujo se utilizan para especificar con precisión a qué flujo o flujos pertenece una opción determinada.

Un especificador de flujo es una cadena que generalmente se añade al final del nombre de la opción y se separa de él mediante dos puntos. Por ejemplo: "-codec:a:1 ac3" contiene el especificador de flujo "a:1" , que coincide con el segundo flujo de audio. Por lo tanto, seleccionaría el códec ac3 para el segundo flujo de audio.

Un especificador de flujo puede coincidir con varios flujos, de modo que la opción se aplique a todos ellos. Por ejemplo, el especificador de flujo en "-b:a 128k" coincide con todos los flujos de audio.

Un especificador de flujo vacío coincide con todos los flujos. Por ejemplo, "-codec copy" o "-codec: copy" copiarían todos los flujos sin recodificar.

Las formas posibles de los especificadores de flujo son:

stream_index
Coincide con el flujo con este índice. Por ejemplo, "-threads:1 4" establecería el número de hilos del segundo flujo a 4. Si stream_index se usa como un especificador de flujo adicional (ver abajo), entonces selecciona el flujo número stream_index de los flujos que coinciden. La numeración de flujos se basa en el orden de los flujos tal como los detecta libavformat, excepto cuando también se especifica un especificador de grupo de flujos o un ID de programa. En este caso, se basa en el ordenamiento de los flujos en el grupo o programa.
stream_type[:additional_stream_specifier]
stream_type es uno de los siguientes: 'v' o 'V' para vídeo, 'a' para audio, 's' para subtítulos, 'd' para datos y 't' para adjuntos. 'v' coincide con todos los flujos de vídeo, 'V' solo coincide con flujos de vídeo que no sean imágenes adjuntas, miniaturas de vídeo o carátulas. Si additional_stream_specifier se usa, entonces coincide con flujos que tienen tanto este tipo como el que coincide con additional_stream_specifier. De lo contrario, coincide con todos los flujos del tipo especificado.
g:group_specifier[:additional_stream_specifier]
Coincide con los flujos que están en el grupo con el especificador group_specifier. Si additional_stream_specifier se usa, entonces coincide con los flujos que son parte del grupo y coinciden con additional_stream_specifier. group_specifier puede ser uno de los siguientes:
group_index
Coincide con el flujo con este índice de grupo.
#group_id o i:group_id
Coincide con el flujo con este id de grupo.
p:program_id[:additional_stream_specifier]
Coincide con los flujos que están en el programa con el id program_id. Si additional_stream_specifier se usa, entonces coincide con los flujos que son parte del programa y coinciden con additional_stream_specifier.
#stream_id o i:stream_id
Coincide con el flujo por su id de flujo (por ejemplo, PID en el contenedor MPEG-TS).
m:key[:value]
Coincide con los flujos con la etiqueta de metadatos key que tienen el valor especificado. Si value no se da, coincide con los flujos que contienen la etiqueta dada con cualquier valor. El carácter de dos puntos ':' en key o value necesita ser escapado con una barra invertida.
disp:dispositions[:additional_stream_specifier]
Coincide con los flujos con la(s) disposición(es) dada(s). dispositions es una lista de una o más disposiciones (tal como las imprime la opción -dispositions ) unidas con '+'.
u
Coincide con los flujos con una configuración utilizable, el códec debe estar definido y la información esencial como la dimensión del vídeo o la frecuencia de muestreo de audio debe estar presente.

Tenga en cuenta que en ffmpeg, la coincidencia por metadatos solo funcionará correctamente para archivos de entrada.
