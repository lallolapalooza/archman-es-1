NOMBRE

FFI — Interfaz de funciones externas

BIBLIOTECA

libffi, -lffi

SINOPSIS

#include <ffi.h>

ffi_status
ffi_prep_cif(ffi_cif *cif, ffi_abi abi, unsigned int nargs, ffi_type *rtype, ffi_type **atypes);

void
ffi_prep_cif_var(ffi_cif *cif, ffi_abi abi, unsigned int nfixedargs, unsigned int ntotalargs, ffi_type *rtype, ffi_type **atypes);

void
ffi_call(ffi_cif *cif, void (*fn)(void), void *rvalue, void **avalue);

DESCRIPCIÓN

La interfaz de funciones externas proporciona un mecanismo mediante el cual una función puede generar una llamada a otra función en tiempo de ejecución sin necesidad de conocer la interfaz de la función llamada en tiempo de compilación.

VER TAMBIÉN

ffi_prep_cif(3), ffi_prep_cif_var(3), ffi_call(3)
