NOMBRE

ffi_prep_cif_var — Prepara una estructura ffi_cif para su uso con ffi_call para funciones variádicas.

SINOPSIS

#include <ffi.h>

ffi_status
ffi_prep_cif_var(ffi_cif *cif, ffi_abi abi, unsigned int nfixedargs, unsigned int ntotalargs, ffi_type *rtype, ffi_type **atypes);

DESCRIPCIÓN

La función ffi_prep_cif_var prepara una estructura ffi_cif para su uso con ffi_call para funciones variádicas. abi especifica un conjunto de convenciones de llamada a utilizar. atypes es una matriz de ntotalargs punteros a estructuras ffi_type que describen el tipo de dato, tamaño y alineación de cada argumento. rtype apunta a un ffi_type que describe el tipo de dato, tamaño y alineación del valor de retorno. nfixedargs debe contener el número de argumentos fijos (no variádicos). Tenga en cuenta que para llamar a una función no variádica se debe usar ffi_prep_cif.

VALORES DE RETORNO

Al completarse con éxito, ffi_prep_cif_var devuelve FFI_OK. Devolverá FFI_BAD_TYPEDEF si cif es NULL o si atypes o rtype están mal formados. Si abi no se refiere a una ABI válida, se devolverá FFI_BAD_ABI. Las ABI disponibles se definen en <ffitarget.h>

VER TAMBIÉN

ffi(3), ffi_call(3), ffi_prep_cif(3)
