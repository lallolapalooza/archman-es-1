FFADO-BRIDGECO-DOWNLOADER(1) Manual de comandos generales FFADO-BRIDGECO-DOWNLOADER(1)

NOMBRE

ffado-bridgeco-downloader - aplicación de descarga de firmware para dispositivos BridgeCo

SINOPSIS

ffado-bridgeco-downloader [OPCIÓN...] OPERACIÓN

DESCRIPCIÓN

ffado-bridgeco-downloader permite realizar actualizaciones de firmware a dispositivos BridgeCo (también conocidos como BeBoB) bajo Linux. OPERACIÓN describe la acción a realizar. Una OPERACIÓN se introduce con el GUID del dispositivo sobre el que operar. Le sigue una de las siguientes palabras clave y cualquier argumento requerido por dicha palabra clave.

mostrar
Muestra información sobre la interfaz
establecerguid NUEVO_GUID
Establece el GUID del dispositivo a NUEVO_GUID
firmware ARCHIVO
Descarga el archivo de firmware ARCHIVO al dispositivo.
cne ARCHIVO
Descarga el archivo CnE ARCHIVO al dispositivo.
bcd ARCHIVO
Analiza el archivo BCD de BeBoB ARCHIVO y muestra información sobre su contenido.

OPCIONES

-?, --ayuda, --uso
Muestra información breve de uso y sale
-V, --version
Muestra la versión del programa y sale
-p, --puerto=NUM
Especifica el uso del puerto IEEE1394 NUM
-v, --detallado=NIVEL
Produce salida detallada. Cuanto mayor sea el NIVEL, más detallados serán los mensajes. Algunos mensajes detallados solo pueden estar disponibles si FFADO se compiló con depuración habilitada.
-b, --sin-arranque
No inicies el gestor de arranque. Usa esto si el gestor de arranque ya está en ejecución.
-f, --forzar
Forzar la descarga del firmware en caso de que el programa no crea que sea una buena idea. Úsese con precaución.
-m, --magia=MAGIA
Un número mágico que debes obtener antes de que este programa funcione. Especificarlo en la línea de comandos significa que aceptas los riesgos que vienen con esta herramienta. El número mágico se puede obtener en el código fuente.

NOTAS

La manipulación del firmware puede hacer que tu dispositivo deje de funcionar. El proyecto FFADO no acepta ninguna responsabilidad si esto ocurre como resultado del uso de esta herramienta.
