Solo para soxr, la precisión en bits a la que se calculará la señal remuestreada. El valor por defecto de 20 (que, con un dithering adecuado, es apropiado para una profundidad de bits de destino de 16) da el 'Alta Calidad' de SoX; un valor de 28 da el 'Muy Alta Calidad' de

Solo para soxr, selecciona el decaimiento de banda pasante ninguno (Chebyshev) y una aproximación de mayor precisión para relaciones 'irracionales'. El valor por defecto

asy
nc
Solo para swr, sincronización simple de audio con 1 parámetro a las marcas de tiempo usando estiramiento, compresión, relleno y recorte. Establecer esto en 1 habilitará el relleno y el recorte, valores más grandes representan la cantidad máxima en muestras que los datos pueden estirarse o comprimirse por cada segundo. El valor por defecto es 0, por lo que no se aplica ninguna compensación para hacer que las muestras coincidan con las marcas de tiempo del
audio.
first_p
ts
Solo para swr, asume que el primer pts debe ser este valor. La unidad de tiempo es 1 / frecuencia de muestreo. Esto permite el relleno/recorte al inicio del flujo. Por defecto, no se hace ninguna suposición sobre el pts esperado del primer fotograma, por lo que no se hace ningún relleno ni recorte. Por ejemplo, esto podría establecerse en 0 para rellenar el inicio con silencio si un flujo de audio comrts después del flujo de vídeo o para recortar cualquier muestra con un pts negativo debido al retraso del codificador.
min_comp
Solo para swr, establece la diferencia mínima entre marcas de tiempo y datos de audio (en segundos) para activar el estiramiento/relleno/relleno o el recorte de los datos para que coincidan con las marcas de tiempo. Por defecto, el estiramiento/relleno/relleno y el recorte están deshabilitados (min_comp = "FLT_MAX").
min_hard_comp
Solo para swr, establece la diferencia mínima entre marcas de tiempo y datos de audio (en segundos) para activar la adición/eliminación de muestras para que coincidan con las marcas de tiempo. Esta opción es efectivamente un umbral para seleccionar entre la compensación dura (recorte/relleno) y suave (compresión/estiramiento). Tenga en cuenta que toda la compensación está deshabilitada por defecto a través de min_comp. El valor predeterminado es 0.1.
comp_duration
Solo para swr, establece la duración (en segundos) durante la cual los datos son estirados/comprimidos para que coincidan con las marcas de tiempo. Debe ser un valor double float no negativo, el valor predeterminado es 1.0.
max_soft_comp
Solo para swr, establece el factor máximo por el cual los datos son estirados/comprimidos para que coincidan con las marcas de tiempo. Debe ser un valor double float no negativo, el valor predeterminado es 0.
matrix_encoding
Selecciona la codificación de estéreo matricial.

Acepta los siguientes valores:

none
selecciona ninguno
dolby
selecciona Dolby
dplii
selecciona Dolby Pro Logic II

El valor predeterminado es "none".

filter_type
Solo para swr, selecciona el tipo de filtro de remuestreo. Esto solo afecta a las operaciones de remuestreo.

Acepta los siguientes valores:

cubic
selecciona cúbico
blackman_nuttall
selecciona sinc con ventana de Blackman Nuttall
kaiser
selecciona sinc con ventana de Kaiser
kaiser_beta
Solo para swr, establece el valor beta de la ventana de Kaiser. Debe ser un valor double float en el intervalo [2,16], el valor predeterminado es 9.
output_sample_bits
Solo para swr, establece el número de bits de muestra de salida utilizados para el dithering. Debe ser un entero en el intervalo [0,64], el valor predeterminado es 0, lo que significa que no se utiliza.
