Paquete: libffi

ffi_call(3) Manual de funciones de biblioteca ffi_call(3)

NOMBRE

ffi_call — Invoca una función externa.

SINOPSIS

#include <ffi.h>

void
ffi_call(ffi_cif *cif, void (*fn)(void), void *rvalue, void **avalue);

DESCRIPCIÓN

La función ffi_call proporciona un mecanismo simple para invocar una función sin requerir conocimiento de la interfaz de la función en tiempo de compilación. fn se llama con los valores recuperados de los punteros en el array avalue. El valor de retorno de fn se coloca en el almacenamiento apuntado por rvalue. cif contiene información que describe los tipos de datos, tamaños y alineaciones de los argumentos y el valor de retorno de fn, y debe inicializarse con ffi_prep_cif antes de ser utilizada con ffi_call.

rvalue debe apuntar a un almacenamiento que sea de tamaño sizeof(ffi_arg) o mayor para tipos que no sean de punto flotante. Para tipos de valor de retorno de menor tamaño, se debe usar el tipo integral ffi_arg o ffi_sarg para contener el valor de retorno.

EJEMPLOS

#include <ffi.h>
#include <stdio.h>

unsigned char
foo(unsigned int, float);

int
main(int argc, const char **argv)
{
    ffi_cif cif;
    ffi_type *arg_types[2];
    void *arg_values[2];
    ffi_status status;

    // Como el valor de retorno de foo() es menor que sizeof(long),
    // debe pasarse como ffi_arg o ffi_sarg.
    ffi_arg result;

    // Especificar el tipo de dato de cada argumento. Los tipos disponibles se definen
    // en <ffi/ffi.h>.
    arg_types[0] = &ffi_type_uint;
    arg_types[1] = &ffi_type_float;

    // Preparar la estructura ffi_cif.
    if ((status = ffi_prep_cif(&cif, FFI_DEFAULT_ABI,
        2, &ffi_type_uint8, arg_types)) != FFI_OK)
    {
        // Manejar el error ffi_status.
    }

    // Especificar los valores de cada argumento.
    unsigned int arg1 = 42;
    float arg2 = 5.1;

    arg_values[0] = &arg1;
    arg_values[1] = &arg2;

    // Invocar la función.
    ffi_call(&cif, FFI_FN(foo), &result, arg_values);

    // El ffi_arg 'result' ahora contiene el unsigned char devuelto por foo(),
    // que se puede acceder mediante un typecast.
    printf("el resultado es %hhu", (unsigned char)result);

    return 0;
}

// La función objetivo.
unsigned char
foo(unsigned int x, float y)
{
    unsigned char result = x - y;
    return result;
}
