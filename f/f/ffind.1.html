FFIND(1) Manual de Comandos Generales FFIND(1)

NOMBRE

ffind - Encuentra el nombre del archivo o directorio usando un inodo dado

SINOPSIS

ffind [-aduvV] [-f fstype] [-i imgtype] [-o imgoffset] [-b dev_sector_size] imagen [imágenes] inodo

DESCRIPCIÓN

ffind encuentra los nombres de los archivos o directorios que están asignados al inodo en la imagen de disco imagen. Por defecto, solo devolverá el primer nombre que encuentre. Con algunos sistemas de archivos, esto encontrará nombres de archivos eliminados.

ARGUMENTOS

-a
Encuentra todas las ocurrencias del inodo.
-d
Encuentra solo entradas eliminadas.
-f fstype
Identifica el tipo de sistema de archivos de la imagen. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se utilizan métodos de autodetcción.
-u
Encuentra solo entradas no eliminadas.
-i imgtype
Identifica el tipo de archivo de imagen, como "raw". Usa '-i list' para listar los tipos compatibles. Si no se proporciona, se utilizan métodos de autodetcción.
-o imgoffset
El desplazamiento de sector donde comienza el sistema de archivos en la imagen.
-b dev_sector_size
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se usa el valor en el formato de imagen (si existe) o se asume 512 bytes.
-v
Salida detallada a stderr.
-V
Muestra la versión.
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se indica con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
inodo
Entero del inodo a encontrar.

Este programa busca en todas las entradas de directorio en busca del inodo dado. Esto es útil cuando un inodo ha sido identificado a partir de la dirección de la unidad de disco usando ifind(1).

EJEMPLO

# ffind -a imagen 212
