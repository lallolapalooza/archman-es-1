NOMBRE

ffi_prep_cif — Prepara una estructura ffi_cif para su uso con ffi_call

SINOPSIS

#include <ffi.h>

ffi_status
ffi_prep_cif(ffi_cif *cif, ffi_abi abi, unsigned int nargs, ffi_type *rtype, ffi_type **atypes);

DESCRIPCIÓN

La función ffi_prep_cif prepara una estructura ffi_cif para su uso con ffi_call. abi especifica un conjunto de convenciones de llamada a utilizar. atypes es un array de nargs punteros a estructuras ffi_type que describen el tipo de dato, tamaño y alineación de cada argumento. rtype apunta a una ffi_type que describe el tipo de dato, tamaño y alineación del valor de retorno. Tenga en cuenta que para llamar a una función variádica, se debe usar en su lugar ffi_prep_cif_var.

VALORES DE RETORNO

Al completarse con éxito, ffi_prep_cif devuelve FFI_OK. Devolverá FFI_BAD_TYPEDEF si cif es NULL o si atypes o rtype están mal formados. Si abi no se refiere a un ABI válido, se devolverá FFI_BAD_ABI. Los ABI disponibles se definen en <ffitarget.h>.

VER TAMBIÉN

ffi(3), ffi_call(3), ffi_prep_cif_var(3)
