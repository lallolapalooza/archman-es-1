File::Compare(3perl) Guía de referencia para programadores de Perl File::Compare(3perl)

NOMBRE

File::Compare - Compara archivos o manejadores de archivos

SINOPSIS

use File::Compare;
if (compare("archivo1", "archivo2") == 0) {
    print "Son iguales\n";
}

DESCRIPCIÓN

La función "File::Compare::compare" compara el contenido de dos fuentes, cada una de las cuales puede ser un archivo o un manejador de archivos. Se exporta desde "File::Compare" por defecto.

"File::Compare::cmp" es un sinónimo de "File::Compare::compare". Se exporta desde "File::Compare" solo bajo petición.

"File::Compare::compare_text" realiza una comparación línea por línea de los dos archivos. Se detiene tan pronto como se detecta una diferencia. compare_text() acepta un tercer argumento opcional: Debe ser una referencia CODE a una función de comparación de líneas, que devuelve 0 cuando ambas líneas se consideran iguales. Por ejemplo:

compare_text($archivo1, $archivo2)

es básicamente equivalente a

compare_text($archivo1, $archivo2, sub {$_[0] ne $_[1]} )

RETORNO

"File::Compare::compare" y sus funciones hermanas devuelven 0 si los archivos son iguales, 1 si los archivos son diferentes, o -1 si se encontró un error.
