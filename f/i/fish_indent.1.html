NOMBRE

fish_indent - indentador y formateador

SINOPSIS

fish_indent [OPCIONES] [ARCHIVO ...]

DESCRIPCIÓN

fish_indent se utiliza para indentar código fish. fish_indent lee comandos de la entrada estándar o de los archivos especificados y los emite a la salida estándar o a un archivo especificado (si se usa -w).

Las siguientes opciones están disponibles:

-w o --write
Indenta un archivo especificado y escribe inmediatamente en ese archivo.
-i o --no-indent
No indenta comandos; solo reformatea a un trabajo por línea.
--only-indent
No reformatea, solo indenta cada línea.
--only-unindent
No reformatea, solo desindenta cada línea.
-c o --check
No indenta, solo devuelve 0 si el código ya está indentado como lo haría fish_indent, de lo contrario, el número de archivos fallidos. También imprime los nombres de los archivos fallidos si no se lee de la entrada estándar.
-v o --version
Muestra la versión actual de fish y luego sale.
--ansi
Colorea la salida usando secuencias de escape ANSI con los colores definidos en el entorno (como fish_color_command <#envvar-fish_color_command>).
--html
Genera salida HTML, que admite resaltado de sintaxis si se define el CSS apropiado. Los nombres de las clases CSS son los mismos que los nombres de las variables, como fish_color_command.
--dump-parse-tree
Muestra información sobre las sentencias analizadas en la salida de error estándar. Esto probablemente solo interese a las personas que trabajan en el código fuente de fish.
-h o --help
Muestra ayuda sobre el uso de este comando.
