Este documento usa formato para mostrar cómo se vería un prompt. Si estás viendo esto en la página man, probablemente quieras cambiar a la versión HTML. Ejecuta help custom-prompt para
verlo en un n
avegador web.

Fish incluye varios prompts que puedes ver con el comando fish_config <>, y muchos usuarios han compartido sus prompts en

línea.

Sin embargo, también puedes escribir el tuyo propio, o ajustar un prompt existente. Esta es una buena manera de acostumbrarte al lenguaje de scripting de fish <>

.

A diferencia de otros shells, el prompt de fish se construye ejecutando una función - fish_prompt <>. O, más específicamente, tres

funciones:
  • fish_prompt <>, que es la función principal del
    • prompt
  • fish_right_prompt <>, que se muestra en el lado derecho de la
    • terminal.
  • fish_mode_prompt
    • <>, que se muestr
a si se usa el mo
do vi <#vi-mode>.

Estas funciones se ejecutan, y lo que impriman se muestra como el prompt (menos un salto de línea final)

.

Aquí, solo escribiremos un fish_prompt

simple.

NUESTRO PRIMER

PROMPT

Veamos un ejemplo muy

simple: 
function f
ish_prompt
echo $P
WD '>' end

Esto imprime el directorio de trabajo actual (PWD <#envvar-PWD>) y un símbolo > para mostrar dónde termina el prompt. El > está entre comillas <#quotes> porque de lo contrario significaría una redirección <#redirects>

.

Como hemos usado echo <>, añade espacios entre los dos así que termina viéndose como (asumiendo que _ es tu cursor)

: 
/ho
me/t
uto
rial
>_

FORMAT

O

echo añade espacios entre sus argumentos. Si no quieres esos, puedes usar string join <>

así: 
function fish_
prompt str
ing join '' -
- $PWD '>' end

El -- indica a string que no pueden venir opciones después de él, en caso de que extendamos esto con algo que pueda empezar con un -

.

Hay otras formas de eliminar el espacio, incluyendo echo -s y printf

<>
.

AÑADIENDO

COLOR

Este prompt es funcional, pero un poco aburrido. Podríamos añadir algo de

color.

Afortunadamente, fish ofrece el comando set_color <>, así que puedes

hacer: 
echo (
set_co
lor r
ed)foo

set_color también puede manejar colores RGB como set_color 23b455, y otras opciones de formato incluyendo negrita y

cursiva.

Así que, tomando nuestro prompt anterior y añadiendo algo de

color: 
function fish_prompt
string join '' -- (se
t_color green) $PWD (se
t_color normal) '>' end

Un color "normal" le dice a la terminal que vuelva a sus opciones de formato

normales.

set_color funciona produciendo una secuencia de escape, que es un texto especial que las terminales interpretan como instrucciones - por ejemplo, para cambiar de color. Así que set_color red produce el mismo efecto

que: 
ech
o \
e\[
31m

Aunque puedes escribir tus propias secuencias de escape a mano, es mucho más fácil usar set_c

olo
r.

ACORTANDO EL DIRECTORIO DE

TRABAJO

Esto está bien, pero nuestro PWD <#envvar-PWD> puede ser un poco largo, y normalmente solo nos interesan los últimos directorios. Podemos acortarlo con el ayudante prompt_pwd <> que nos dará un directorio de trabajo

acortado: 
function fish_prompt
string join '' -- (set_co
lor green) (prompt_pwd) (
set_color normal) '>' end

prompt_pwd acepta opciones para controlar cuánto acortar. Por ejemplo, si queremos mostrar los últimos dos directorios, usaríamos prompt_pwd --full-len

gth-dirs 2: 
function fish_prompt
    strin
g join '' -- (set_color green)
(prompt_pwd --full-length-dirs
2) (set_color normal) '>' end

imprimiría

ine/O
neknow
ing>_

ESTAD

O

Un bit de información importante que cada comando devuelve es el estado <#variables-status>. Este es un número entero de 0 a 255, y normalmente se usa como código de error - 0 si el comando se completó exitosamente, o un número de 1 a 255 si

no.

Es útil mostrar esto en tu prompt, pero mostrarlo cuando es 0 parece un poco

desperdiciador.

Primero, ya que cada comando (excepto set <>) cambia el estado, necesitas almacenarlo para uso posterior como lo primero en tu prompt. Usa una variable local <#variables-scope> para que quede confinada a tu función de

prompt: 
set -l
last_s
tatus $
status

Y después de eso, puedes establecer una cadena si no es

cero: 
# Estado del prompt solo si no es 0
set -l stat if test $last_status -
ne 0 set stat (set_color red)"[$
last_status]"(set_color normal) end

Y para imprimirlo, lo añadimos a nuestro string j

oin: 
string join '' -- (
set_color green) (p
rompt_pwd) (set_colo
r normal) $stat '>'

Si $last_status era 0, $stat está vacío, y así simplemente

desaparecerá.

Así que nuestro prompt completo ahora

es: 
function fish_prompt
    set -l last_status $status
    # Estado del prompt
solo si no es 0 set -l stat if test $last_status -ne 0 set
stat (set_color red)"[$last_status]"(set_color normal) end string
join '' -- (set_color green) (prompt_pwd) (set_color normal) $stat '>' end

Y se ve

así: 
~/M/L/Onekn
owing>false
~/M/L/Onek
nowing[1]>_

después de ejecutar false (que devuelve

1)
.

PROMPT

TRANSITORIO

Para habilitar la funcionalidad de prompt transitorio, establece la variable fish_transient_prompt <#envvar-fish_transient_prompt> a

1: 
set -g f
ish_tra
nsient_
prompt 1

Con esto establecido, fish re-ejecuta las funciones de prompt con un argumento --final-rendering antes de ejecutar una línea de comando. Así que puedes usarlo para despejar tus prompts antiguos. Por ejemplo, si quieres ver solo el nombre del directorio actual al desplazarte hacia

arriba: 
function fish_prompt
    set -l last_status $status
    set -l stat
    set -l pwd
    # Verificar si es un prompt transitori
o o final if contains -- --final-rendering $argv set pwd (path basename $PWD) else set pwd (prompt_pw
d) # Estado del prompt solo si no es 0 if test $last_status -ne 0 set stat (set_color red)"[$last
_status]"(set_color normal) end end string join '' -- (set_color green) $pwd (set_color normal) $stat '>' end

Ahora ejecutar dos comandos en el mismo directorio podría resultar en esta

pantalla: 
Oneknowi
ng>fals
e ~/M/L/
Oneknow
ing[1]>_

GUARDAR EL

PROMPT

Una vez que estés satisfecho con tu prompt, puedes guardarlo con funcsave fish_prompt (ver funcsave - guardar la definición de una función en el directorio de autocarga del usuario <>) o escríbelo en ~/.config/fish/functions/fish_prompt.fish tú

mismo.

Si quieres editarlo de nuevo, abre ese archivo o usa funced fish_prompt (ver funced - editar una función interactivamente <>

)
.
