NOMBRE

FileCache - mantener más archivos abiertos de los que el sistema permite

SINOPSIS

no strict 'refs';
use FileCache;
# o
use FileCache maxopen => 16;
cacheout $modo, $ruta;
# o
cacheout $ruta;
print $ruta @datos;
$fh = cacheout $modo, $ruta;
# o
$fh = cacheout $ruta;
print $fh @datos;

DESCRIPCIÓN

La función "cacheout" se asegurará de que haya un descriptor de archivo abierto para lectura o escritura disponible para la ruta de archivo que le proporcione. Cierra y reabre archivos automáticamente si excede el número máximo de descriptores de archivo de su sistema, o el máximo sugerido maxopen.

cacheout EXPRESIÓN
La forma de cacheout con un argumento abrirá un archivo para escritura ('>') en su primer uso, y para añadir ('>>') posteriormente.

Devuelve EXPRESIÓN en caso de éxito para conveniencia. Puede ignorar el valor de retorno y manipular EXPRESIÓN como el descriptor de archivo directamente si lo prefiere.

cacheout MODO, EXPRESIÓN
La forma de cacheout con dos argumentos utilizará el modo proporcionado para las aperturas iniciales y subsiguientes. La mayoría de los modos válidos para "open" con 3 argumentos son compatibles, a saber: '>', '+>', '<', '<+', '>>', '|-' y '-|'

Para pasar argumentos suplementarios a un programa abierto con '|-' o '-|' , agréguelos a la cadena de comandos como lo haría con la EXPRESIÓN del sistema.

Devuelve EXPRESIÓN en caso de éxito para conveniencia. Puede ignorar el valor de retorno y manipular EXPRESIÓN como el descriptor de archivo directamente si lo prefiere.

ADVERTENCIAS

Si bien es permisible "cerrar" un archivo gestionado por FileCache, no lo haga si está llamando "FileCache::cacheout" desde un paquete distinto al que se importó, o con otro módulo que anule "close". Si debe hacerlo, utilice "FileCache::cacheout_close".

Aunque FileCache se puede usar con aperturas de tubería ('-|' o '|-') se desaconseja encarecidamente hacerlo. Si FileCache considera necesario cerrar y volver a abrir una tubería, el comando al otro extremo de la tubería se reiniciará; es poco probable que los resultados de realizar E/S en tuberías gestionadas por FileCache sean los esperados. La capacidad de usar FileCache en tuberías puede ser eliminada en una versión futura.

FileCache no almacena la posición actual del archivo si considera necesario cerrar un archivo. Cuando el archivo se reabra, la posición será la especificada por el modo de archivo "open" original. Esto podría considerarse un error.

La funcionalidad del módulo se basa en referencias simbólicas, por lo que las cosas se romperán con 'use strict' a menos que también se especifique 'no strict "refs"'.

ERRORES

sys/param.h miente con su definición "NOFILE" en algunos sistemas, por lo que es posible que deba establecer maxopen usted mismo.
