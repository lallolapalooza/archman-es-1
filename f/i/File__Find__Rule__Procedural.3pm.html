NOMBRE

File::Find::Rule::Procedural - Interfaz procedural de File::Find::Rule

SINOPSIS

use File::Find::Rule;
# encontrar todos los archivos .pm, de forma procedural
my @files = find(name => '*.pm', in => \@INC);

DESCRIPCIÓN

Además de la interfaz orientada a objetos regular, File::Find::Rule proporciona dos subrutinas para que las utilices.

find( @clausulas )
rule( @clausulas )
"find" y "rule" se pueden usar para invocar cualquier método disponible para la versión OO. "rule" es un sinónimo de "find"

Pasar más de un valor a una cláusula se hace con un array anónimo:

my $finder = find( name => [ '*.mp3', '*.ogg' ] );

"find" y "rule" ambos devuelven una instancia de File::Find::Rule, a menos que uno de los argumentos sea "in", en cuyo caso devuelve una lista de elementos que coinciden con la regla.

my @files = find( name => [ '*.mp3', '*.ogg' ], in => $ENV{HOME} );

Ten en cuenta que "in" será la última cláusula evaluada, por lo que este código buscará mp3s independientemente de su tamaño.

my @files = find( name => '*.mp3', in => $ENV{HOME}, size => '<2k' );

                                                   |
              El procesamiento de cláusulas se detuvo aquí ------/

También es posible invertir una regla individual prefijándola con "!" de la siguiente manera:

# archivos grandes que no son videos
my @files = find( file    =>
                  '!name' => [ '*.avi', '*.mov' ],
                  size    => '>20M',
                  in      => $ENV{HOME} );
