NOMBRE

fi_errno - errores de fabric

fi_strerror - Convierte un error de fabric en una cadena imprimible

SINOPSIS

#include <rdma/fi_errno.h>
const char *fi_strerror(int errno);

ERRORES

FI_ENOENT
No existe el archivo o el directorio.
FI_EIO
Error de E/S
FI_E2BIG
Lista de argumentos demasiado larga.
FI_EBADF
Número de archivo incorrecto.
FI_EAGAIN
Reintentar.
FI_ENOMEM
Memoria insuficiente.
FI_EACCES
Permiso denegado.
FI_EBUSY
Dispositivo o recurso ocupado
FI_ENODEV
No existe tal dispositivo
FI_EINVAL
Argumento no válido
FI_EMFILE
Demasiados archivos abiertos
FI_ENOSPC
No queda espacio en el dispositivo
FI_ENOSYS
Función no implementada
FI_EWOULDBLOCK
La operación bloquearía
FI_ENOMSG
No hay mensaje del tipo deseado
FI_ENODATA
No hay datos disponibles
FI_EOVERFLOW
Valor demasiado grande para el tipo de datos definido
FI_EMSGSIZE
Mensaje demasiado largo
FI_ENOPROTOOPT
Protocolo no disponible
FI_EOPNOTSUPP
Operación no admitida en el punto de extremo de transporte
FI_EADDRINUSE
Dirección ya en uso
FI_EADDRNOTAVAIL
No se puede asignar la dirección solicitada
FI_ENETDOWN
La red está caída
FI_ENETUNREACH
La red es inaccesible
FI_ECONNABORTED
El software provocó la interrupción de la conexión
FI_ECONNRESET
Conexión restablecida por el par
FI_ENOBUFS
No hay espacio de búfer disponible
FI_EISCONN
El punto de extremo de transporte ya está conectado
FI_ENOTCONN
El punto de extremo de transporte no está conectado
FI_ESHUTDOWN
No se puede enviar después del cierre del punto de extremo de transporte
FI_ETIMEDOUT
Tiempo de espera de la operación agotado
FI_ECONNREFUSED
Conexión rechazada
FI_EHOSTDOWN
El host está caído
FI_EHOSTUNREACH
No hay ruta hacia el host
FI_EALREADY
Operación ya en curso
FI_EINPROGRESS
Operación en curso ahora
FI_EREMOTEIO
Error de E/S remota
FI_ECANCELED
Operación cancelada
FI_ENOKEY
La clave requerida no está disponible
FI_EKEYREJECTED
La clave fue rechazada por el servicio
FI_EOTHER
Error no especificado
FI_ETOOSMALL
El búfer proporcionado es demasiado pequeño
FI_EOPBADSTATE
Operación no permitida en el estado actual
FI_EAVAIL
Error disponible
FI_EBADFLAGS
Banderas no admitidas
FI_ENOEQ

FI_EDOMAIN

FI_ENOCQ
Cola de finalización faltante o no disponible
FI_ECRC

FI_ETRUNC
Error de truncamiento
FI_ENOKEY

FI_ENOAV
Vector de direcciones faltante o no disponible
FI_EOVERRUN

FI_ENORX

FI_ENOMR
