DESCRIPCIÓ

N

La fido_dev_open() función abre el dispositivo apuntado por path, donde dev es un fido_dev_t recién asignado o de lo contrario cerrado. Si dev afirma ser FIDO2, libfido2 intentará hablar FIDO2 con dev. Si eso falla, libfido2 volverá a U2F a menos que la bandera FIDO_DISABLE_U2F_FALLBACK se haya establecido en fido_init

(3).

La fido_dev_open_with_info() función abre dev previamente asignado usando fido_dev_new_with

_info().

La fido_dev_close() función cierra el dispositivo representado por dev. Si dev ya está cerrado, fido_dev_close() es un

NOP.

La fido_dev_cancel() función cancela cualquier solicitud pendiente en dev

.

La fido_dev_new() función devuelve un puntero a un fido_dev_t recién asignado y vacío. Si no se puede asignar memoria, se devuelve

NULL.

La fido_dev_new_with_info() función devuelve un puntero a un fido_dev_t recién asignado con parámetros fido_dev_info_t, para usar con fido_dev_info_manifest(3) y fido_dev_open_with_info(). Si no se puede asignar memoria, se devuelve

NULL.

La fido_dev_free() función libera la memoria que respalda *dev_p, donde *dev_p debe haber sido asignado previamente por fido_dev_new(). Al regresar, *dev_p se establece en NULL. Tanto dev_p como *dev_p pueden ser NULL, en cuyo caso fido_dev_free() es un

NOP.

La fido_dev_force_fido2() función se puede usar para forzar la comunicación CTAP2 con dev, donde dev es un dispositivo

abierto.

La fido_dev_force_u2f() función se puede usar para forzar la comunicación CTAP1 (U2F) con dev, donde dev es un dispositivo

abierto.

La fido_dev_is_fido2() función devuelve true si dev es un dispositivo

FIDO2.

La fido_dev_is_winhello() función devuelve true si dev es un dispositivo Windows

Hello.

La fido_dev_supports_credman() función devuelve Dv">true si dev soporta Credential Management de CTAP 2.

1.

La fido_dev_supports_cred_prot() función devuelve true si dev soporta Credential Protection de CTAP 2.

1.

La fido_dev_supports_permissions() función devuelve true si dev soporta permisos de token UV de CTAP 2.

1.

La fido_dev_supports_pin() función devuelve true si dev soporta Client PINs de CTAP 2.

0.

La fido_dev_supports_uv() función devuelve true si dev soporta un método integrado de verificación de

usuario.

La fido_dev_has_pin() función devuelve true si dev tiene un Client PIN de CTAP 2.0

configurado.

La fido_dev_has_uv() función devuelve true si dev soporta verificación de usuario integrada y su característica de verificación de usuario está

configurada.

La fido_dev_protocol() función devuelve el identificador de versión del protocolo CTAPHID de dev

.

La fido_dev_build() función devuelve el número de versión de compilación CTAPHID de dev

.

La fido_dev_flags() función devuelve las banderas de capacidades CTAPHID de dev

.

La fido_dev_major() función devuelve el número de versión principal CTAPHID de dev

.

La fido_dev_minor() función devuelve el número de versión secundario CTAPHID de dev

.

Para el formato y significado de los parámetros CTAPHID dev

ueltos por las funciones anteriores, consulte la espec
ificación FIDO Client to Authenticator Protocol (CTAP).
