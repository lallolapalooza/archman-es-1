NOMBRE

finance-quote-wrapper - interfaz interna entre gnucash y Finance::Quote

SINOPSIS

finance-quote-wrapper

DESCRIPCIÓN

Entrada: un hash codificado en JSON de espacios de nombres y materias para las que consultar precios. Todas las divisas van bajo el espacio de nombres "currency", otras materias se agrupan según la fuente de cotizaciones desde la que se deben consultar. También debe haber una clave "defaultcurrency" con la divisa que se usará como divisa base para las cotizaciones de divisas.

{
"defaultcurrency": "EUR",
"currency": {
"XAG": "",
"HKD": "",
"USD": ""
},
"yahoo_json": {
"CSCO": ""
} }

Salida (en salida estándar):

Las cotizaciones recuperadas en formato JSON para su posterior procesamiento. Estos son los valores brutos devueltos por Finance::Quote. El llamador es responsable de analizar e interpretar los resultados.

Si hay fallos en el programa, se imprimirá un mensaje de error en la salida de error estándar.

Estado de salida

0 - éxito no cero - fallo
