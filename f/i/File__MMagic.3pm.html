RESUME

N

Esta biblioteca de perl usa objetos de perl5 pa

ra adivinar el tipo de archivo a partir del
nombre de archivo y/o el manejador de archivo.

DESCRIPCIÓ

N

checktype_filename(), checktype_filehandle() y checktype_contents devuelven una caden

a que contiene el tipo de archivo
con el formato de mediatype MIME.

addSpecials
Si no se puede determinar el tipo de archivo mediante números mágicos, se realizan comprobaciones adicionales basadas en expresiones regulares adicionales que se pueden definir aquí. El primer argumento debe ser el tipo de archivo, y los argumentos restantes deben ser una o más expresiones regulares.

Por defecto, se realizan comprobaci

ones para message/news, message/rfc8
22, text/html, text/x-roff.
$mm->
removeSpecials
Elimina expresiones regulares especiales. Especifica uno o más tipos de archivo. Si no se especifican tipos de archivo, se eliminan todas las expresiones regulares especiales.

Devuelve un hash q

ue contiene las en
tradas eliminadas.
$mm->
addFileExts
Si no se puede determinar el tipo de archivo mediante números mágicos, se pueden realizar comprobaciones adicionales basadas en la extensión del archivo (en realidad, una expresión regular). Se deben proporcionar dos argumentos: el patrón del nombre de archivo y el tipo de archivo correspondiente.

Por defecto, se realizan comprobaciones para a

pplication/x-compress, application/x-bz
ip2, application/x-gzip, text/html, text/plain
$mm->
removeFileExts
Elimina las comprobaciones de patrones de nombres de archivo. Especifica uno o más patrones. Si no se especifica ningún patrón, se eliminan todos.

Devuelve un hash q

ue contiene las en
tradas eliminadas.
