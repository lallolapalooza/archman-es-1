IÓN

fi_pingpong es una prueba de pingpong para la funcionalidad principal de la biblioteca libfabric: la transmisión de datos entre dos procesos. fi_pingpong también muestra estadísticas agregadas después de cada ejecución de la prueba, y puede

además verificar la integridad de los datos al recibirlos.

De forma predeterminada, se utiliza el endpoint d

e datagramas (FI_EP_DGRAM) para la prueba, a m
enos que se especifique lo contrario mediante -e.

OPCIONE

S

El servidor y el cliente deben poder comunicarse correctamente para que la utilidad fi_pingpong funcione. Si se usa alguna de las opciones -e, -I, -S o -p, entonces deben especificarse en la invocación tanto para el proceso servidor como para el cliente. Si se especifica la opción -d en el servidor, entonces el cliente seleccionará el dominio apropiado si no se proporciona ninguna pista en el lado del cliente. Si se especifica la opción -d en el cliente, entonces también debe especificarse en el servidor. Si tanto el servidor como el cliente especifican la opción -d y los dominios dados no pueden comunicarse,

entonces la aplicación fallará.
