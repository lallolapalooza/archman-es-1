FILTER-DKIMSIGN(8) Manual del Administrador del Sistema FILTER-DKIMSIGN(8)

NOMBRE

filter-dkimsign - añadir firma dkim a los mensajes

SINOPSIS

filter-dkimsign [-tz] [-a algoritmo] [-c canonicalizacion] [-h cabeceras] [-x segundos] -d dominio -D archivo -k archivo -s selector

DESCRIPCIÓN

filter-dkimsign añade una firma dkim al mensaje. Las siguientes opciones son soportadas:

-a algoritmo
El algoritmo a usar. Los algoritmos de firma soportados son rsa y ed25519 (cuando está habilitado en tiempo de compilación). Solo sha256 debe ser usado para hashing, ya que otros algoritmos es muy probable que no sean soportados por los verificadores. Por defecto es rsa-sha256.
-c canonicalizacion
El algoritmo de canonicalización usado para firmar el mensaje. Por defecto es simple/simple.
-D archivo
archivo debe apuntar a un archivo que contiene una lista de dominios. Solo un dominio por línea debe ser especificado. Ver -d para más información.
-d dominio
El dominio donde la clave pública puede ser encontrada. Esta opción puede ser especificada múltiples veces para seleccionar el mejor dominio durante la firma. Si se especifica múltiples veces, mira el componente dominio del primer buzón en la cabecera from y trata de encontrar una coincidencia. Si no se encuentra una coincidencia exacta, busca el dominio padre más cercano. Si no se encuentran coincidencias, se usará el primer dominio especificado.
-h cabeceras
Las cabeceras de correo electrónico que se incluyen en la firma del correo. Según RFC, esta opción requiere que al menos la cabecera from sea incluida. Las cabeceras se especifican separándolas con dos puntos. El valor por defecto es from:reply-to:subject:date:to:cc:resent-date:resent-from:resent-to:resent-cc:in-reply-to:references:list-id:list-help:list-unsubscribe:list-subscribe:list-post:list-owner:list-archive.
-k archivo
archivo debe apuntar a un archivo que contiene la clave privada RSA para firmar los mensajes.
-s selector
El selector dentro del subdominio _domainkey de dominio donde la clave pública puede ser encontrada.
-t
Añade la hora de la firma a la cabecera dkim.
-x segundos
Añade la cantidad de segundos que la firma es válida a la cabecera dkim.
-z
Añade las cabeceras de correo usadas en la firma dkim a la cabecera dkim. Si se especifica un segundo -z, todas las cabeceras se incluirán en la cabecera dkim. Útil para fines de depuración.
