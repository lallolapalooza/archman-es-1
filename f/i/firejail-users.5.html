NOMBRE

firejail.users - Base de datos de usuarios de Firejail

DESCRIPCIÓN

/etc/firejail/firejail.users lista los usuarios permitidos para ejecutar el ejecutable SUID de firejail. El usuario root está permitido por defecto, el usuario nobody nunca está permitido.

Si al usuario no se le permite iniciar el sandbox, Firejail intentará ejecutar el programa sin sandboxing.

Si el archivo no está presente en el sistema, todos los usuarios tienen permiso para usar el sandbox.

Ejemplo:

$ cat /etc/firejail/firejail.users
dustin
lucas
mike
eleven

Use un editor de texto para agregar o eliminar usuarios de la lista. También puede usar el comando firecfg --add-users. Ejemplo:

$ sudo firecfg --add-users dustin lucas mike eleven

Por defecto, ejecutar firecfg crea el archivo y agrega el usuario actual a la lista. Ejemplo:

$ sudo firecfg

Consulte man 1 firecfg para más detalles.

SOLUCIÓN ALTERNATIVA

Una forma alternativa de restringir el acceso de los usuarios al ejecutable de firejail es crear un grupo de usuarios especial de firejail y permitir solo a los usuarios de este grupo ejecutar el sandbox:

# addgroup --system firejail
# chown root:firejail /usr/bin/firejail
# chmod 4750 /usr/bin/firejail
