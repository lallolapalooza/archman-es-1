file(n) Comandos incorporados de Tcl file(n)

NOMBRE

file - Manipular nombres y atributos de archivos

SINOPSIS

file opción nombre ?arg arg ...?

DESCRIPCIÓN

Este comando proporciona varias operaciones sobre el nombre o atributos de un archivo. Nombre es el nombre de un archivo; si comienza con una tilde, se realiza la sustitución de tilde antes de ejecutar el comando (ver la página del manual de filename para más detalles). Opción indica qué hacer con el nombre del archivo. Se acepta cualquier abreviatura única de opción. Las opciones válidas son:

file atime nombre ?tiempo?
Devuelve una cadena decimal que indica la hora en que el archivo nombre fue accedido por última vez. Si se especifica tiempo, es un tiempo de acceso para establecer para el archivo. El tiempo se mide de la manera estándar POSIX como segundos desde una hora de inicio fija (a menudo el 1 de enero de 1970). Si el archivo no existe o su tiempo de acceso no se puede consultar o establecer, se genera un error. En Windows, los sistemas de archivos FAT no admiten el tiempo de acceso.
file attributes nombre
file attributes nombre ?opción?
file attributes nombre ?opción valor opción valor...?
Este subcomando devuelve o establece valores específicos de plataforma asociados con un archivo. La primera forma devuelve una lista de las opciones específicas de plataforma y sus valores. La segunda forma devuelve el valor de la opción dada. La tercera forma establece uno o más de los valores. Los valores son los siguientes:

En Unix, -group obtiene o establece el nombre del grupo para el archivo. Se puede pasar un ID de grupo al comando, pero devuelve un nombre de grupo. -owner obtiene o establece el nombre de usuario del propietario del archivo. El comando devuelve el nombre del propietario, pero el ID numérico se puede pasar al establecer el propietario. -permissions recupera o establece los permisos de acceso de un archivo, utilizando la notación octal por defecto. Esta opción también proporciona soporte limitado para establecer permisos utilizando la notación simbólica aceptada por el comando chmod, siguiendo el formato [ugo]?[[+-=][rwxst],[...]]. Se pueden dar múltiples especificaciones de permisos, separadas por comas. Por ejemplo, u+s,go-rw establecería el bit setuid para el propietario de un archivo, así como eliminaría los permisos de lectura y escritura para el grupo y otros usuarios del archivo. También se acepta una cadena de estilo ls con el formato rwxrwxrwx, pero siempre debe tener 9 caracteres de longitud. Por ejemplo, rwxr-xr-t es equivalente a 01755. En versiones de Unix que admiten indicadores de archivo, -readonly devuelve el valor de, o establece o borra el atributo de solo lectura de un archivo, es decir, el indicador inmutable de usuario (uchg) del comando chflags.

En Windows, -archive da el valor o establece o borra el atributo de archivo del archivo. -hidden da el valor o establece o borra el atributo oculto del archivo. -longname expandirá cada elemento de la ruta a su versión larga. Este atributo no se puede establecer. -readonly da el valor o establece o borra el atributo de solo lectura del archivo. -shortname da una cadena donde cada elemento de la ruta se reemplaza con su versión corta (8.3) del nombre, si es posible. Para los elementos de ruta que no se pueden mapear a nombres cortos, se conserva el nombre largo. Este atributo no se puede establecer. -system da o establece o borra el valor del atributo del sistema del archivo.

En macOS y Darwin, -creator da o establece el tipo de creador de Finder del archivo. -hidden da o establece o borra el atributo oculto del archivo. -readonly da o establece o borra el atributo de solo lectura del archivo. -rsrclength da la longitud de la bifurcación de recursos del archivo, este atributo solo se puede establecer al valor 0, lo que resulta en la eliminación de la bifurcación de recursos del archivo.

file channels ?patrón?
Si no se especifica patrón, devuelve una lista de nombres de todos los canales abiertos registrados en este intérprete. Si se especifica patrón, solo se devuelven aquellos nombres que coinciden con patrón. La coincidencia se determina utilizando las mismas reglas que para string match.
file copy ?-force? ?--? fuente destino
file copy ?-force? ?--? fuente ?fuente ...? directorioDestino
La primera forma hace una copia del archivo o directorio fuente bajo la ruta destino. Si destino es un directorio existente, entonces se usa la segunda forma. La segunda forma hace una copia dentro de directorioDestino de cada archivo fuente listado. Si se especifica un directorio como fuente, entonces el contenido del directorio se copiará recursivamente en directorioDestino. Los archivos existentes no se sobrescribirán a menos que se especifique la opción -force (cuando Tcl también intentará ajustar los permisos en el archivo o directorio de destino si es necesario para permitir que la copia proceda). Al copiar dentro de un solo sistema de archivos, file copy copiará enlaces simbólicos (es decir, se copian los enlaces mismos, no las cosas a las que apuntan). Intentar sobrescribir un directorio no vacío, sobrescribir un directorio con un archivo, o sobrescribir un archivo con un directorio resultará en errores incluso si se especificó -force. Los argumentos se procesan en el orden especificado, deteniéndose en el primer error, si lo hay. Un -- marca el final de las opciones; el argumento que sigue a -- se tratará como una fuente incluso si comienza con un -.
file delete ?-force? ?--? ?ruta ... ?
Elimina el archivo o directorio especificado por cada argumento de ruta. Los directorios no vacíos se eliminarán solo si se especifica la opción -force. Al operar en enlaces simbólicos, se eliminarán los enlaces mismos, no los objetos a los que apuntan. Intentar eliminar un archivo inexistente no se considera un error. Intentar eliminar un archivo de solo lectura provocará la eliminación del archivo, incluso si la opción -force no está especificada. Si la opción -force se especifica en un directorio, Tcl intentará tanto cambiar los permisos como mover el directorio actual “pwd” fuera de la ruta dada si es necesario para permitir que la eliminación proceda. Los argumentos se procesan en el orden especificado, deteniéndose en el primer error, si lo hay. Un -- marca el final de las opciones; el argumento que sigue a -- se tratará como una ruta incluso si comienza con un -.
file dirname nombre
Devuelve un nombre compuesto por todos los componentes de la ruta en nombre excluyendo el último elemento. Si nombre es un nombre de archivo relativo y solo contiene un componente de ruta, devuelve “.”. Si nombre se refiere a un directorio raíz, entonces se devuelve el directorio raíz. Por ejemplo,
file dirname c:/

devuelve c:/.

Tenga en cuenta que la sustitución de tilde solo se realizará si es necesario para completar el comando. Por ejemplo,

file dirname ~/src/foo.c

devuelve ~/src, mientras que

file dirname ~

devuelve /home (o algo similar).

file executable nombre
Devuelve 1 si el archivo nombre es ejecutable por el usuario actual, 0 en caso contrario. En Windows, que no tiene un atributo de ejecutable, el comando trata todos los directorios y cualquier archivo con extensiones exe, com, cmd o bat como ejecutables.
file exists nombre
Devuelve 1 si el archivo nombre existe y el usuario actual tiene privilegios de búsqueda para los directorios que conducen a él, 0 en caso contrario.
file extension nombre
Devuelve todos los caracteres en nombre después y incluido el último punto en el último elemento de nombre. Si no hay un punto en el último elemento de nombre, devuelve la cadena vacía.
