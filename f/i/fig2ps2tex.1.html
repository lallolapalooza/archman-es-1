FIG2PS2TEX(1) Manual de Comandos Generales FIG2PS2TEX(1)

NOMBRE

fig2ps2tex - genera un archivo TeX para incluir un archivo PostScript

SINOPSIS

fig2ps2tex archivo

DESCRIPCIÓN

Fig2ps2tex genera un archivo TeX para incluir un archivo PostScript en un documento TeX. Esto implica calcular el cuadro delimitador del documento Postscript. El archivo de inclusión TeX se escribe en la salida estándar.

También existe Fig2ps2tex.csh para aquellos sistemas con csh y dc.

Tenga en cuenta que el paquete de macros psfig proporciona un enfoque más sofisticado para incluir archivos Postscript en documentos LaTeX. Sin embargo, Fig2ps2tex funciona con TeX plano.

USO

Supongamos que el archivo Postscript se llama foo.ps. El comando

% fig2ps2tex foo.ps >foo.tex

creará el archivo de inclusión con la información del cuadro delimitador. Luego incluya este archivo en su documento TeX con el comando

\input{foo}

VER TAMBIÉN

psfig(1), latex(1), fig2dev(1), transfig(1).
