DESCRIPCIÓ

N

File::ShareDir::Install le permite instalar archivos de datos de solo lectura desde una distribución. Es un módulo complementario de File::ShareDir, que le permite localizar estos archivos después de la

instalación.

Es un port de Module::Install::Share a ExtUtils::MakeMaker con la mejora de instalar solo los archivos que usted desee; ".svn", ".git" y otros archivos de control de versiones serán

ignorados.

Tenga en cuenta que este módulo instala

archivos de datos de solo lectura; los
directorios vacíos serán ignorados.

EXPORTACI

ÓN

install_shar

e 
install_share $dir;
install_share dist => $dir;
install_share module => $module,
$dir;

Hace que todos los archivos en $dir y sus subdirectorios se instalen en un directorio de compartición por distribución o por módulo. Debe ser llamado antes de "WriteMakefile"

.

Las primeras 2 formas son equivalentes; los archivos se instalan en un directorio por distribución. Por ejemplo "/usr/lib/perl5/site_perl/auto/share/dist/My-Dist". El nombre de ese directorio se puede recuperar con "dist_dir" en File::

ShareDir.

La última forma instala archivos en un directorio por módulo. Por ejemplo "/usr/lib/perl5/site_perl/auto/share/module/My-Dist-Package". El nombre de ese directorio se puede recuperar con "module_dir" en File::

ShareDir.

El parámetro $dir puede ser un array de

directorios.

Los archivos se instalarán cuando ejecute "make install". Sin embargo, la lista de archivos a instalar se genera cuando se ejecuta Makefile.

PL.

Tenga en cuenta que si hace múltiples llamadas a "install_share" en directorios diferentes que contienen los mismos nombres de archivo, la última de estas llamadas tiene prioridad. En otras palabras, si

hace: 
install_share 'share1';
install_share
'share2';

Y ambos "share1" y "share2" contienen un archivo llamado "info.txt", el archivo "share2/info.txt" se instalará en su dist_d

ir
().

delete_shar

e 
delete_share $list;
delete_share dist => $list;
delete_share module => $module,
$list;

Elimina archivos o directorios instalados

previamente.

A diferencia de "install_share", el último parámetro es una lista de archivos o directorios que fueron instalados previamente. Estos archivos y directorios serán eliminados cuando ejecute "make ins

tall".

El parámetro $list puede ser un array de archivos o

directorios.

La eliminación ocurre en orden junto con la instalación. Esto significa que puede eliminar todos los archivos instalados previamente colocando lo siguiente en la parte superior de su Makefile.

PL. 
delete_share '.
';

También puede eliminar selectivamente algunos archivos de la

instalación. 
install_share 'some-dir';
if( ... ) {
    delete_share 'not-this-file.rc';
}

CONFIGURACIÓ

N

Dos variables controlan el manejo de archivos y directorios con punto (dot-files y dot-directories)

.

Un archivo con punto (dot-file) tiene un nombre de archivo que comienza con un punto (.). Por ejemplo ".htaccess". Un directorio con punto (dot-directory) es un directorio que comienza con un punto (.). Por ejemplo ".config/". No todos los sistemas de archivos soportan el uso de archivos con

punto.

$INCLUDE_DOTFILE

S

Si se establece a un valor verdadero,

los archivos con punto serán copiado
s. El valor por defecto es falso.

$INCLUDE_DOTDIR

S

Si se establece a un valor verdadero, los archivos dentro de los direct

orios con punto serán copiados. Los directorios de control de vers
iones conocidos aún serán ignorados. El valor por defecto es falso.

Not

a

Estas variables solo influyen en las llamadas subsecuentes a install_share(). Esto le permite controlar el comportamiento para cada

directorio.

Por

ejemplo: 
$INCLUDE_DOTDIRS = 1;
install_share 'share1';
$INCLUDE_DOTFILES = 1;
$INCLUDE_DOTDIRS = 0;
install_share
'share2';

El directorio "share1" tendrá archivos en sus directorios con punto instalados, pero no archivos con punto. El directorio "share2" tendrá archivos en sus archivos con p

unto instalados, p
ero los directorios con
punto serán ignorados.
