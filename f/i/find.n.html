find(n)

Paquete: tcl

Licencias: TCL

find(n) [incr Tcl] find(n)

NOMBRE

itcl::find - buscar clases y objetos

SINOPSIS

itcl::find opción ?argumento argumento ...?

DESCRIPCIÓN

El comando find se utiliza para encontrar clases y objetos que están disponibles en el intérprete actual. Las clases y objetos se informan primero en el espacio de nombres activo, luego en todos los demás espacios de nombres del intérprete.

El argumento opción determina qué acción se lleva a cabo por el comando. Las opciones legales (que pueden abreviarse) son:

find clases ?patrón?
Devuelve una lista de clases de [incr Tcl]. Las clases en el espacio de nombres actual se listan primero, seguidas de las clases en todos los demás espacios de nombres del intérprete. Si se especifica el patrón opcional, entonces los nombres informados se comparan utilizando las reglas del comando "string match", y solo se informan los nombres que coinciden.

Si una clase reside en el contexto del espacio de nombres actual, este comando informa su nombre simple, sin calificadores. Sin embargo, si el patrón contiene calificadores ::, o si la clase reside en otro contexto, este comando informa su nombre completamente calificado. Por lo tanto, puede usar el siguiente comando para obtener una lista donde todos los nombres estén completamente calificados:

itcl::find clases ::*
find objetos ?patrón? ?-clase nombreClase? ?-isa nombreClase?
Devuelve una lista de objetos de [incr Tcl]. Los objetos en el espacio de nombres actual se listan primero, seguidos de los objetos en todos los demás espacios de nombres del intérprete. Si se especifica el patrón opcional, entonces los nombres informados se comparan utilizando las reglas del comando "string match", y solo se informan los nombres que coinciden. Si se especifica el parámetro opcional "-clase", esta lista se restringe a objetos cuya clase más específica es nombreClase. Si se especifica el parámetro opcional "-isa", esta lista se restringe aún más a objetos que tienen el nombreClase dado en algún lugar de su herencia.

Si un objeto reside en el contexto del espacio de nombres actual, este comando informa su nombre simple, sin calificadores. Sin embargo, si el patrón contiene calificadores ::, o si el objeto reside en otro contexto, este comando informa su nombre completamente calificado. Por lo tanto, puede usar el siguiente comando para obtener una lista donde todos los nombres estén completamente calificados:

itcl::find objetos ::*
