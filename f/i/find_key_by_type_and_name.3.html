FIND_KEY_BY_TYPE_AND_NAME(3) Llamadas de utilidad de clave de Linux FIND_KEY_BY_TYPE_AND_NAME(3)

NOMBRE

find_key_by_type_and_name - buscar una clave por tipo y nombre

SINOPSIS

#include <keyutils.h>

key_serial_t find_key_by_type_and_name(const char *type,
    const char *description, key_serial_t destringid);

DESCRIPCIÓN

find_key_by_type_and_name() busca una clave con el type y la description exacta dadas, primero en los keyrings de hilo, proceso y sesión a los que un proceso está suscrito y luego en /proc/keys.

Si se encuentra una clave y destringid no es 0 y especifica un keyring, entonces la clave encontrada se vinculará a él.

VALOR DE RETORNO

La función devuelve el ID de la clave si se encontró una clave o -1 en caso contrario.

ERRORES

ENOKEY
No se encontró ninguna clave o el keyring especificado es inválido.
EKEYEXPIRED
La clave o el keyring han expirado.
EKEYREVOKED
La clave o el keyring han sido revocados.
EACCES
La clave no es accesible o el keyring existe, pero no es escribible por el proceso que llama.

ENLAZADO

Al enlazar, se debe especificar -lkeyutils al enlazador.

VER TAMBIÉN

request_key(2), keyctl(3), keyrings(7)
