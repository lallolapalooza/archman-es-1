filezilla(1) Manual de FileZilla filezilla(1)

NOMBRE

FileZilla - Cliente FTP

SINOPSIS

filezilla
filezilla [-l <tipodeacceso>] <URL FTP>
filezilla -h|-s|-v
filezilla -c <sitio>
filezilla -a <ruta>

DESCRIPCIÓN

FileZilla es un potente cliente para FTP simple, FTP sobre SSL/TLS (FTPS) y el Protocolo de Transferencia de Archivos SSH (SFTP).

OPCIONES

-c <sitio>, --sitio <sitio>
Conéctese al sitio dado desde el Administrador de Sitios. El sitio debe darse como una ruta completa, con una barra como carácter separador. Cualquier barra o barra invertida que forme parte de un segmento debe escaparse con una barra invertida. La ruta debe ir precedida por 0 para entradas definidas por el usuario o 1 para entradas predeterminadas. La ruta del sitio no puede contener comillas dobles.
Ejemplo: filezilla -c 0/foo/bar/sl\/ash se conecta al sitio de usuario sl/ash en el directorio de sitios foo/bar
No se puede usar junto con -s ni con el parámetro de URL.
-a <ruta>, --local <ruta>
Establece el sitio local en la ruta dada.
Ejemplo: filezilla -a "/foo bar/"
-h, --ayuda
Muestra un diálogo de ayuda que enumera estas opciones de línea de comandos.
-l <tipodeacceso>, --tipodeacceso <tipodeacceso>
Establece un tipo de acceso especial, solo se puede usar en combinación con una URL FTP como argumento.

El tipo de acceso debe ser pedir o interactivo. Si no se proporciona -l, se utiliza el tipo de acceso normal.

-s, --administradordesitios
Iniciar con el Administrador de Sitios abierto. No se puede usar junto con -c ni con el parámetro de URL.
-v, --version
Muestra el número de versión de FileZilla.

MEDIO AMBIENTE

La variable de entorno FZ_DATADIR se puede usar para especificar el directorio que contiene los archivos de datos de FileZilla.

SOPORTE

Visite https://filezilla-project.org/ para más información. Informe de errores solo si está utilizando la última versión disponible en el sitio web de FileZilla.
