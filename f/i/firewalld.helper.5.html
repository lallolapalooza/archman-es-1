FIREWALLD.HELPER(5) firewalld.helper FIREWALLD.HELPER(5)

NOMBRE

firewalld.helper - archivos de configuración de helpers de firewalld

SINOPSIS

/etc/firewalld/helpers/helper.xml
/usr/lib/firewalld/helpers/helper.xml

DESCRIPCIÓN

Un archivo de configuración de helper de firewalld proporciona la información de una entrada de helper para firewalld. Las opciones de configuración más importantes son puertos, familia y módulo.

Este archivo de configuración de ejemplo muestra la estructura de un archivo de configuración de helper:

<?xml version="1.0" encoding="utf-8"?>
<helper module="nf_conntrack_module" [family="ipv4|ipv6"]>
  <short>nombre corto</short>
  <description>descripción</description>
  <port id_puerto[-id_puerto]" protocol="tcp|udp|sctp|dccp"/>
</helper>

OPCIONES

La configuración puede contener estas etiquetas y atributos. Algunos de ellos son obligatorios, otros opcionales.

helper

La etiqueta de inicio y fin obligatoria del helper define el helper. Esta etiqueta solo puede usarse una vez en un archivo de configuración de helper. Hay un atributo obligatorio y también opcionales para el helper:

module="cadena"

El módulo obligatorio del helper. Este es uno de los módulos de helper de netfilter conntrack. El nombre comienza con nf_conntrack_.

family="ipv4|ipv6"

La familia opcional del helper. Puede ser uno de estos tipos de ipv: ipv4 o ipv6. Si la familia no se especifica, el helper es utilizable para IPv4 y IPv6.

version="cadena"

Para dar una versión al helper.

short

Es una etiqueta de inicio y fin opcional y se utiliza para dar un nombre más legible a un helper.

description

Es una etiqueta de inicio y fin opcional para tener una descripción de un helper.

port

Es una etiqueta obligatoria de elemento vacío y se puede usar varias veces para tener más de una entrada de puerto. Todos los atributos de una entrada de puerto son obligatorios:

port="cadena"

La cadena del puerto puede ser un solo número de puerto o un rango de puertos id_puerto-id_puerto o también puede estar vacío para coincidir solo con un protocolo.

protocol="cadena"

El valor del protocolo puede ser tcp, udp, sctp o dccp.
