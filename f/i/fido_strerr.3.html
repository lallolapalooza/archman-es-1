FIDO_STRERR(3) Manual de Funciones de Biblioteca FIDO_STRERR(3)

NOMBRE

fido_strerr — Códigos de error FIDO2

SINOPSIS

#include <fido.h>

const char *
fido_strerr(int n);

DESCRIPCIÓN

La función fido_strerr() traduce el código de error n a una cadena legible, donde n es un código de error definido en <fido/err.h>. fido_strerr() nunca devuelve NULL. Los punteros devueltos apuntan a cadenas estáticas.
