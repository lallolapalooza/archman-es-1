DESCRIPCIÓ

N

Este módulo se puede usar para encontrar directorios y archivos según lo especificado por la Especificación de Directorio Base de Freedesktop.org. Esta especificación proporciona un mecanismo para localizar directorios de configuración, datos de la aplicación y datos de caché. Se sugiere que las aplicaciones de escritorio, por ejemplo, para las plataformas GNOME, KDE o Xfce, sigan esta distribución. Sin embargo, la misma distribución se puede usar igualmente bien para aplicaciones sin

GUI.

Este módulo se bifurcó de File::

MimeInfo.

Este módulo sigue la ver

sión 0.6 de la especifica
ción de Directorio Base.

Ninguna de estas se exporta por defecto, pero todas las funciones se pueden exportar a petición. También se definen los grupos ":lookup" y ":vars". El grupo ":vars" contiene todas las rutinas con un prefijo "xdg_". El grupo ":lookup" contiene las rutinas para localizar archivos y

directorios.

e 
my $path = data_home(@path);

Toma una lista de elementos de ruta de archivo y devuelve una nueva ruta añadiéndolos al directorio de datos principal. La nueva ruta no necesita existir. Usa esto cuando escribas datos de la aplicación específicos del

PLATAFORMAS NO

UNIX

El uso de File::Spec asegura que todas las rutas se devuelvan en sus formatos nativos independientemente de la plataforma. En Windows, este módulo usará las variables de entorno nativas, en lugar del valor por defecto en UNIX (que es tradicionalmente $HOME

).

Ten en cuenta que la especificación está dirigida solo a plataformas Unix y solo tend

rá una relevancia limitada en otras plataformas. Cualquier comportamiento dependiente
de la plataforma en este módulo debe considerarse una extensión de la especificación.
