NOMBRE

fi_udp - El Proveedor de Fabric UDP

DESCRIPCIÓN

El proveedor UDP es un proveedor básico que puede ser utilizado en cualquier sistema que soporte sockets UDP. El proveedor no está diseñado para proporcionar mejoras de rendimiento sobre los sockets TCP normales, sino más bien para permitir a los desarrolladores de aplicaciones y proveedores escribir, probar y depurar su código. El proveedor UDP forma la base de un proveedor de utilidad que permite la implementación de características de libfabric sobre cualquier hardware.

CARACTERÍSTICAS SOPORTADAS

El proveedor UDP soporta un conjunto mínimo de características útiles para enviar y recibir mensajes de datagramas a través de un endpoint no fiable.

Tipos de endpoint
El proveedor solo soporta el tipo de endpoint FI_EP_DGRAM.
Capacidades del endpoint
Se soporta la siguiente interfaz de transferencia de datos: fi_msg. El proveedor soporta transferencias de datagramas unicast estándar, así como operaciones multicast.
Modos
El proveedor no requiere el uso de ningún bit de modo.
Progreso
El proveedor UDP soporta tanto FI_PROGRESS_AUTO como FI_PROGRESS_MANUAL, con un valor predeterminado de auto. Sin embargo, los búferes de datos del lado de recepción no se modifican fuera de las rutinas de procesamiento de finalización.

LIMITACIONES

El proveedor UDP tiene máximos codificados para tamaños de cola y transferencias de datos soportados. Estos valores se reflejan en las estructuras de atributos de fabric relacionadas

Los EPs deben estar enlazados a CQs tanto de RX como de TX.

No hay soporte para completaciones selectivas o multi-recv.

No hay soporte para contadores.

PARÁMETROS EN TIEMPO DE EJECUCIÓN

Actualmente no hay parámetros definidos en tiempo de ejecución.

VER TAMBIÉN
