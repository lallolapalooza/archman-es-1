NOMBRE

fi_fabric - Operaciones de red de fabric

fi_fabric / fi_close
Abrir / cerrar una red de fabric
fi_tostr / fi_tostr_r
Convertir atributos, indicadores y capacidades de fabric en una cadena imprimible

SINOPSIS

#include <rdma/fabric.h>
int fi_fabric(struct fi_fabric_attr *attr,
    struct fid_fabric **fabric, void *context);
int fi_close(struct fid *fabric);
char * fi_tostr(const void *data, enum fi_type datatype);
char * fi_tostr_r(char *buf, size_t len, const void *data,
    enum fi_type datatype);

ARGUMENTOS

attr
Atributos del fabric a abrir.
fabric
Red de fabric
context
Contexto especificado por el usuario asociado con el objeto abierto. Este contexto se devuelve como parte de cualquier evento asíncrono asociado.
buf
Búfer de salida donde escribir la cadena.
len
Tamaño en bytes de la memoria referenciada por buf.
data
Datos de entrada a convertir en una cadena. El formato de data está determinado por el parámetro datatype.
datatype
Indica los datos a convertir en una cadena imprimible.

DESCRIPCIÓN

Un identificador de fabric se utiliza para referenciar los recursos de fabric abiertos y los objetos relacionados con la biblioteca.

La red de fabric representa una colección de recursos de hardware y software que acceden a una única red física o virtual. Todos los puertos de red en un sistema que pueden comunicarse entre sí a través de sus redes conectadas pertenecen al mismo fabric. Una red de fabric comparte direcciones de red y puede abarcar múltiples proveedores. Una aplicación debe abrir una red de fabric antes de asignar otros recursos de red, como puntos de comunicación.

fi_fabric

Abre un proveedor de red de fabric. Los atributos del proveedor de fabric se especifican a través de la llamada de apertura, y pueden obtenerse llamando a fi_getinfo.

fi_close

La llamada fi_close se utiliza para liberar todos los recursos asociados con un objeto de fabric. Todos los elementos asociados con el fabric abierto deben liberarse antes de llamar a fi_close.

fi_tostr / fi_tostr_r

Convierte los atributos de la interfaz de fabric, capacidades, indicadores y valores de enum en una cadena imprimible. El parámetro data acepta un puntero al atributo o valor(es) a mostrar, con el parámetro datatype indicando el tipo de datos referenciados por el parámetro data. Los valores válidos para datatype se enumeran a continuación, junto con el tipo de dato o valor de campo correspondiente.

FI_TYPE_INFO

FI_TYPE_EP_CAP

fi_tostr() devolverá un puntero a un búfer interno de libfabric que no debe ser modificado, y será sobrescrito la próxima vez que se invoque fi_tostr(). fi_tostr() no es seguro para hilos.

La función fi_tostr_r() es una versión reentrante y segura para hilos de fi_tostr(). Escribe la cadena en un búfer proporcionado por el llamador. fi_tostr_r() devuelve el inicio del búfer del llamador.

NOTAS

Los siguientes recursos están asociados con los dominios de fabric: dominios de acceso, puntos de pasiva y colas de eventos de CM.

ATRIBUTOS DE FABRIC

La estructura fi_fabric_attr define el conjunto de atributos asociados con un fabric y un proveedor de fabric.

struct fi_fabric_attr {
    struct fid_fabric *fabric;
    char              *name;
    char              *prov_name;
    uint32_t          prov_version;
    uint32_t          api_version;
};

fabric

En la entrada de fi_getinfo, un usuario puede establecer esto en una instancia de fabric abierta para restringir la salida al fabric dado. En la salida de fi_getinfo, si no se especificó ningún fabric, pero el usuario tiene una instancia abierta del fabric nombrado, esto referenciará la primera instancia abierta. Si no se ha abierto ninguna instancia, este campo será NULL.

NAME

fi_fabric — fabric attribute information

SYNOPSIS

#include <rdma/fabric.h>

int fi_fabric(
    fi_info *info,
    uint32_t flags
);

DESCRIPTION

The fi_fabric function is used to retrieve information about the underlying fabric hardware and software. The fabric information is returned in the info structure. The fi_fabric function should be called prior to calling fi_domain or other fabric resource allocation functions.

The info structure is defined as follows:

struct fi_info {
    char *name;
    char *prov_name;
    char *prov_version;
    char *fabric_name;
    char *domain_name;
    char *endpoint_name;
    char *service_name;
    char *transport;
    void *addr;
    size_t addrlen;
    uint64_t flags;
    uint64_t caps;
    uint64_t eav;
    int     count;
    struct fid_domain *domain;
    struct fid_fabric *fabric;
    struct fid_ep *ep;
    struct fi_eq *eq;
    void *user_data;
    void *conn_data;
    struct fi_ep_attr *ep_attr;
    struct fi_domain_attr *domain_attr;
};

The flags parameter is used to specify desired fabric attributes. The following flags are currently supported:

FI_FABRIC_NAME
Return the name of the fabric.
FI_PROV_NAME
Return the name of the fabric provider.
FI_PROV_VERSION
Return the version of the fabric provider.
FI_ADDR
Return the address of the fabric.
FI_COUNT
Return the number of available endpoints.
FI_CAPS
Return the capabilities of the fabric.
FI_EAV
Return the extended attribute vector of the fabric.
FI_ALL
Return all available fabric information.

ARGUMENTS

info
A pointer to a fi_info structure that will be filled with fabric information. The caller is responsible for allocating and freeing the memory for this structure.
flags
A bitmask of flags specifying the desired fabric attributes to retrieve.

NOTES

The fi_fabric function may be called multiple times to retrieve different fabric information. The information returned by fi_fabric is only valid until the application closes any fabric instances. Specifically, the results returned by fi_fabric should only be considered valid if the application does not close any fabric instances from another thread while fi_fabric is being processed.

name

A fabric identifier.

prov_name - Provider Name

The name of the underlying fabric provider.

To request an utility provider layered over a specific core provider, both the provider names have to be specified using “;” as delimiter.

e.g. “ofi_rxm;verbs” or “verbs;ofi_rxm”

For debugging and administrative purposes, environment variables can be used to control which fabric providers will be registered with libfabric. Specifying “FI_PROVIDER=foo,bar” will allow any providers with the names “foo” or “bar” to be registered. Similarly, specifying “FI_PROVIDER=^foo,bar” will prevent any providers with the names “foo” or “bar” from being registered. Providers which are not registered will not appear in fi_getinfo results. Applications which need a specific set of providers should implement their own filtering of fi_getinfo’s results rather than relying on these environment variables in a production setting.

prov_version - Provider Version

Version information for the fabric provider, in a major.minor format. The use of the FI_MAJOR() and FI_MINOR() version macros may be used to extract the major and minor version data. See fi_version(3).

In case of an utility provider layered over a core provider, the version would always refer to that of the utility provider.

api_version

The interface version requested by the application. This value corresponds to the version parameter passed into fi_getinfo(3).

RETURN VALUE

Returns FI_SUCCESS on success. On error, a negative value corresponding to fabric errno is returned. Fabric errno values are defined in rdma/fi_errno.h.
