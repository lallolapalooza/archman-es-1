NOMBRE

fido_dev_get_assert — obtiene una aserción de un dispositivo FIDO2

SINOPSIS

#include <fido.h>

int
fido_dev_get_assert(fido_dev_t *dev, fido_assert_t *assert, const char *pin);

DESCRIPCIÓN

La función fido_dev_get_assert() solicita al dispositivo FIDO2 representado por dev una aserción de acuerdo con los siguientes parámetros definidos en assert:

  • ID del proveedor de confianza;
  • hash de datos del cliente;
  • lista de IDs de credenciales permitidas;
  • atributos de presencia y verificación del usuario.

Consulte fido_assert_set_authdata(3) para obtener información sobre cómo se establecen estos valores.

Si no se necesita un PIN para autenticar la solicitud contra dev, entonces pin puede ser NULL. De lo contrario, pin debe apuntar a una cadena UTF-8 terminada en NULO.

Después de una llamada exitosa a fido_dev_get_assert(), las funciones fido_assert_count(3), fido_assert_user_display_name(3), fido_assert_user_icon(3), fido_assert_user_name(3), fido_assert_authdata_ptr(3), fido_assert_user_id_ptr(3), fido_assert_sig_ptr(3), y fido_assert_sigcount(3) pueden invocarse sobre assert para recuperar los diversos atributos de la aserción generada.

Tenga en cuenta que fido_dev_get_assert() es síncrona y se bloqueará si es necesario.

VALORES DE RETORNO

Los códigos de error devueltos por fido_dev_get_assert() se definen en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

VER TAMBIÉN

fido_assert_new(3), fido_assert_set_authdata(3)
