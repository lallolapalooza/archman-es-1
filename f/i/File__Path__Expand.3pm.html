NOMBRE

File::Path::Expand - expandir nombres de archivo

SINOPSIS

use File::Path::Expand;
print expand_filename("~richardc/foo"); # imprime "/home/richardc/foo"

DESCRIPCIÓN

File::Path::Expand expande directorios de usuario en nombres de archivo. Para el caso simple, no es más complejo que s{^~/}{$HOME/}, pero para otros casos consulta "getpwent" y hace lo correcto.
