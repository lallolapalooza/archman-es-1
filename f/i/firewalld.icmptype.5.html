firewalld.icmptype(5)

Paquete: firewalld

Licencias: GPL-2.0-or-later

FIREWALLD.ICMPTYPE(5) firewalld.icmptype FIREWALLD.ICMPTYPE(5)

NOMBRE

firewalld.icmptype - archivos de configuración icmptype de firewalld

SINOPSIS

/etc/firewalld/icmptypes/icmptype.xml
/usr/lib/firewalld/icmptypes/icmptype.xml

DESCRIPCIÓN

Un archivo de configuración icmptype de firewalld proporciona la información para un tipo de protocolo de mensajes de control de Internet (ICMP) para firewalld.

Este archivo de configuración de ejemplo muestra la estructura de un archivo de configuración icmptype:

<?xml version="1.0" encoding="utf-8"?>
<icmptype>
  <short>Mi Icmptype</short>
  <description>descripción</description>
  <destination ipv4="sí" ipv6="sí"/>
</icmptype>

OPCIONES

La configuración puede contener estas etiquetas y atributos. Algunos de ellos son obligatorios, otros opcionales.

icmptype

La etiqueta de inicio y fin obligatoria icmptype define el icmptype. Esta etiqueta solo se puede usar una vez en un archivo de configuración icmptype. Esta etiqueta tiene atributos opcionales:

version="cadena"

Para dar al icmptype una versión.

short

Es una etiqueta de inicio y fin opcional y se utiliza para dar un nombre más legible a un icmptype.

description

Es una etiqueta de inicio y fin opcional para tener una descripción de un icmptype.

destination

Es una etiqueta opcional de elemento vacío y se puede usar solo una vez. La etiqueta destination especifica si una entrada icmptype está disponible para IPv4 y/o IPv6. El valor predeterminado es IPv4 e IPv6, momento en el cual esta etiqueta puede estar ausente.

ipv4="booleano"

Describe si el icmptype está disponible para IPv4.

ipv6="booleano"

Describe si el icmptype está disponible para IPv6.
