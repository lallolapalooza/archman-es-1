File::Listing(3) Documentación de Perl aportada por el usuario File::Listing(3)

NOMBRE

File::Listing - Analiza listados de directorios

VERSIÓN

versión 6.16

SINOPSIS

use File::Listing qw(parse_dir);
$ENV{LANG} = "C";  # Fechas en locales no ingleses no soportadas
foreach my $file (parse_dir(`ls -l`)) {
    my ($name, $type, $size, $mtime, $mode) = @$file;
    next if $type ne 'f'; # archivo plano
    #...
}

# El listado del directorio también se puede leer de un archivo
open my $listing, "zcat ls-lR.gz|";
$dir = parse_dir($listing, '+0000');

DESCRIPCIÓN

Este módulo exporta una única función llamada "parse_dir", que se puede utilizar para analizar listados de directorios.

FUNCIONES

parse_dir

my $dir = parse_dir( $listing );
my $dir = parse_dir( $listing, $time_zone );
my $dir = parse_dir( $listing, $time_zone, $type );
my $dir = parse_dir( $listing, $time_zone, $type, $error );
my @files = parse_dir( $listing );
my @files = parse_dir( $listing, $time_zone );
my @files = parse_dir( $listing, $time_zone, $type );
my @files = parse_dir( $listing, $time_zone, $type, $error );

El primer parámetro ($listing) es el listado del directorio a analizar. Puede ser un escalar, una referencia a un array de líneas de directorio o un comodín que representa un manejador de archivos para leer el listado del directorio.

El segundo parámetro ($time_zone) es la zona horaria a utilizar al analizar las marcas de tiempo en el listado. Si este valor no está definido, se asume la zona horaria local.

El tercer parámetro ($type) es el tipo de listado a asumir. Los formatos actualmente soportados son 'unix', 'apache' y 'dosftp'. El valor predeterminado es 'unix'. Idealmente, el tipo de listado debería determinarse automáticamente.

El cuarto parámetro ($error) especifica cómo se deben tratar las líneas no analizables. Los valores pueden ser 'ignore', 'warn' o una referencia a código. Warn significa que se llamará a la función perl warn(). Si se pasa una referencia a código, se llamará a esta rutina y el valor de retorno de la misma se incorporará al listado. El valor predeterminado es 'ignore'.

Solo el primer parámetro es obligatorio.

# contexto de lista
foreach my $file (parse_dir($listing)) {
    my($name, $type, $size, $mtime, $mode) = @$file;
}

# contexto escalar
my $dir = parse_dir($listing);
foreach my $file (@$dir) {
    my($name, $type, $size, $mtime, $mode) = @$file;
}

El valor de retorno de parse_dir() es una lista de entradas de directorio. En un contexto escalar, el valor de retorno es una referencia a la lista. Las entradas de directorio se representan mediante un array que consiste en:

nombre
El nombre del archivo.
tipo
Uno de: "f" archivo, "d" directorio, "l" enlace simbólico, "?" desconocido.
tamaño
El tamaño del archivo.
tiempo
El número de segundos desde el 1 de enero de 1970.
modo
Máscara de bits similar al modo devuelto por "stat".

VER TAMBIÉN

File::Listing::Ftpcopy
Proporciona la misma interfaz pero utiliza XS y la implementación del analizador de "ftpcopy".
