SINOPSI

use File::Find::Rule;
# encontrar todos los subdirectorios de un directorio dado
my @subdirs = File::Find::Rule->directory->in( $directory );
# encontrar todos los archivos .pm en @INC
my @files = File::Find::Rule->file()
                            ->name( '*.pm' )
                            ->in( @INC );
# lo mismo, pero sin encadenamiento de métodos
my $rule =  File::Find::Rule->new;
$rule->file;
$rule->name( '*.pm' );
my @files = $rule->in( @INC
)
;

DESCRIPCIÓ

N

File::Find::Rule es una interfaz más amigable para

File::Find. Le permite construir reglas que
especifican los archivos y directorios deseados.

Abre un archivo y lo prueba línea por línea.

INTERACCIÓN CON EL MODO DE CONTAMINACIÓN

(TAINT)

A partir de la versión 0.32, File::Find::Rule no captura el directorio de trabajo actual de una manera insegura para el modo taint. File::Find en sí mismo todavía realiza operaciones que el sistema de taint marcará como inseguras, pero puede usar la característica "extras" para pedirle a File::Find que internamente "descontamine" (untaint) las rutas de archivo con una expresión regular como la

siguiente: 
my $rule = File::Find::Rule->extras({ untaint => 1 })
;

Por favor consulte la documentación de File::Find para "untaint", "untaint_pattern", y "untaint_skip" par

a más inf
ormación.
