NOMBRE

File::Spec::OS2 - métodos para especificaciones de archivos de OS/2

SINOPSIS

require File::Spec::OS2; # Hecho internamente por File::Spec si es necesario

DESCRIPCIÓN

Ver File::Spec y File::Spec::Unix. Este paquete anula la implementación de estos métodos, no la semántica.

Entre los cambios realizados para OS/2 se encuentran...

tmpdir
Modifica la lista de lugares donde se busca información del directorio temporal. 
$ENV{TMPDIR}
$ENV{TEMP}
$ENV{TMP}
/tmp
/
splitpath
Los volúmenes pueden ser letras de unidad o nombres de recurso compartido UNC (\\servidor\recursocompartido).
