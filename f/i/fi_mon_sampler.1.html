NOMBRE

fi_mon_sampler - Muestreador simple para el proveedor ofi_hook_monitor.

SINOPSIS

 fi_mon_sampler [OPCIONES] <objetivo>      muestrear desde archivo(s) en <objetivo>

DESCRIPCIÓN

Extrae datos del proveedor ofi_hook_monitor a través de archivos de comunicación. <objetivo> puede ser un archivo de comunicación o una carpeta de archivos. Los datos se exportan basándose en -f <formato> y se imprimen en la salida estándar (solo para archivos individuales), o se almacenan por archivo de comunicación en -o <ruta_salida>. El muestreador puede observar los archivos de comunicación en busca de cambios a través de la opción -w <msec> para muestreos repetidos.

El formato del nombre de los archivos de salida se basa en el proveedor ofi_hook_monitor y es el siguiente: <ppid>_<pid>_<id_secuencial>_<id_trabajo>_<nombre_proveedor>. ppid y pid se toman desde la perspectiva de la aplicación monitoreada. En un entorno por lotes que ejecuta SLURM, el id de trabajo se establece en el ID del trabajo SLURM, de lo contrario, se establece en 0.

CÓMO EJECUTARLO

Inicie una aplicación libfabric con FI_HOOK=monitor para habilitar el proveedor ofi_hook_monitor. Ajuste la configuración del proveedor monitor de acuerdo con fi_hook(7).

Luego, inicie el muestreador a través de fi_mon_sampler -o <salida> <objetivo>. Por defecto, el proveedor ofi_hook_monitor almacena los datos en /dev/shm/ofi/<uid>/<hostname>.

El muestreador generará archivos de salida en el directorio especificado en <salida>, uno para cada proveedor monitoreado.

OPCIONES

-w <msec>
Observa los archivos en busca de cambios, verifica cada <msec> milisegundos.
-f <formato>
Formato de salida. Actualmente solo soporta CSV.
-o <ruta_salida>
Ruta del archivo de salida. Usa stdout si no está definido.

EJEMPLOS DE USO

Inicie una aplicación libfabric y habilite el proveedor ofi_hook_monitor:

FI_HOOK=monitor fi_pingpong [OPCIONES]

Inicie otro fi_pingpong con la configuración respectiva.

Finalmente, inicie el muestreador:

fi_mon_sampler -o $HOME -w 1000 -f csv /dev/shm/ofi/$UID/$HOSTNAME

SALIDA

Los archivos de salida se generarán en la carpeta especificada en -o <salida>.

En el modo -f csv, esto contendrá un archivo CSV con datos para todas las funciones de libfabric monitoreadas. Para cada función, se exportan tanto los contadores de recuento como de suma, indicados por el sufijo del nombre de la columna _c y _s respectivamente. Además, cada función se monitorea para cada grupo de tamaño de datos. Consulte fi_hook(7) para obtener más detalles.

Ejemplo de salida CSV, primeras cuatro columnas, primeras tres filas:

mon_recv_0_64_c,mon_recv_0_64_s,mon_recv_64_512_c,mon_recv_64_512_s
0,0,0,0
22529,0,0,0
113664,0,0,0
