NOMBRE

fidentify - Determina el tipo de archivo usando la base de datos de PhotoRec

SINOPSIS

fidentify [--check] [directorio|archivo]

fidentify --version

DESCRIPCIÓN


fidentify identifica el tipo de archivo, la "extensión", utilizando la misma base de datos que PhotoRec.
Cuando se especifica un archivo o directorio, fidentify mostrará el tipo de archivo, o los archivos dentro del directorio especificado.
Si no se proporcionan argumentos, fidentify mostrará el tipo de archivos en el directorio actual.
fidentify es similar a file(1).

OPCIONES

--check
comprueba el formato del archivo como lo hace PhotoRec por defecto

VER TAMBIÉN

photorec(8), testdisk(8), file(1)
