fido_cred_exclude(3)

Paquete: libfido2

Licencias: BSD-2-Clause

FIDO_CRED_EXCLUDE(3) Manual de funciones de biblioteca FIDO_CRED_EXCLUDE(3)

NOMBRE

fido_cred_exclude, fido_cred_empty_exclude_list — gestionar listas de exclusión en una credencial FIDO2

SINOPSIS

#include <fido.h>

int
fido_cred_exclude(fido_cred_t *cred, const unsigned char *ptr, size_t len);

int
fido_cred_empty_exclude_list(fido_cred_t *cred);

DESCRIPCIÓN

La función fido_cred_exclude() añade ptr a la lista de credenciales excluidas por cred, donde ptr apunta a un ID de credencial de len bytes. Se realiza una copia de ptr y no se conservan referencias al puntero pasado. Si fido_cred_exclude() falla, la lista existente de credenciales excluidas se conserva.

Si fido_cred_exclude devuelve éxito y cred se pasa posteriormente a fido_dev_make_cred(3) en un dispositivo que contiene la credencial denotada por ptr, entonces fido_dev_make_cred(3) fallará.

Para conocer el formato de un ID de credencial FIDO2, consulte el estándar Web Authentication (webauthn).

La función fido_cred_empty_exclude_list() vacía la lista de credenciales excluidas por cred.

VALORES DE RETORNO

Los códigos de error devueltos por fido_cred_exclude() y fido_cred_empty_exclude_list() están definidos en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

VER TAMBIÉN

fido_cred_new(3), fido_cred_set_authdata(3), fido_dev_make_cred(3)
