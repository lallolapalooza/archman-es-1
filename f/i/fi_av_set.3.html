NOMBRE

fi_av_set - Operaciones de conjunto de vector de direcciones

fi_av_set / fi_close
Abrir o cerrar un conjunto de vector de direcciones
fi_av_set_union
Realizar una operación de unión de conjuntos en dos conjuntos AV
fi_av_set_intersect
Realizar una operación de intersección de conjuntos en dos conjuntos AV
fi_av_set_diff
Realizar una operación de diferencia de conjuntos en dos conjuntos AV
fi_av_set_insert
Añadir una dirección a un conjunto AV
fi_av_set_remove
Eliminar una dirección de un conjunto AV
fi_av_set_addr
Obtener una dirección colectiva para las direcciones actuales en un conjunto AV

SINOPSIS

#include <rdma/fi_collective.h>
int fi_av_set(struct fid_av *av, struct fi_av_set_attr *attr,
      struct fid_av_set **set, void * context);
int fi_av_set_union(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_intersect(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_diff(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_insert(struct fid_av_set *set, fi_addr_t addr);
int fi_av_set_remove(struct fid_av_set *set, fi_addr_t addr);
int fi_av_set_addr(struct fid_av_set *set, fi_addr_t *coll_addr);
int fi_close(struct fid *av_set);

ARGUMENTOS

av
Vector de direcciones
set
Conjunto de vector de direcciones
dst
Conjunto de vector de direcciones actualizado por la operación de conjunto
src
Conjunto de vector de direcciones que proporciona entrada a una operación de conjunto
attr
Atributos del conjunto de vector de direcciones
context
Contexto especificado por el usuario asociado al conjunto de vector de direcciones
flags
Banderas adicionales a aplicar a la operación.
addr
Dirección de destino para insertar o eliminar del conjunto AV.
coll_addr
Dirección que identifica el grupo colectivo.

DESCRIPCIÓN

Un conjunto de vector de direcciones (conjunto AV) representa un subconjunto ordenado de direcciones de un vector de direcciones. Los conjuntos AV se utilizan para identificar a los participantes en una operación colectiva. Los puntos finales utilizan la operación fi_join_collective() para asociarse con un conjunto AV. La operación de unir colectivamente proporciona un fi_addr que se utiliza al comunicarse con un grupo colectivo.

La creación y manipulación de un conjunto AV es una operación local. No se intercambia tráfico de red entre pares. Como resultado, cada par es responsable de crear conjuntos AV coincidentes como parte de su definición de membresía colectiva. Consulte fi_collective(3) para una discusión de los modelos de membresía.

fi_av_set

La llamada fi_av_set crea un nuevo conjunto AV. Las propiedades iniciales del conjunto AV se especifican a través del parámetro struct fi_av_set_attr. Esta estructura se define a continuación y permite incluir un subconjunto de direcciones en el conjunto AV como parte de la creación del conjunto AV. Las direcciones se pueden añadir o eliminar de un conjunto AV utilizando las interfaces del conjunto AV definidas a continuación.

fi_av_set_attr

struct fi_av_set_attr {
    size_t count;
    fi_addr_t start_addr;
    fi_addr_t end_addr;
    uint64_t stride;
    size_t comm_key_size;
    uint8_t *comm_key;
    uint64_t flags;
};
count
Indica el número esperado de miembros que formarán parte del conjunto AV. El proveedor utiliza esto para optimizar las asignaciones de recursos. Si count es 0, el proveedor seleccionará un tamaño basado en los datos de configuración del sistema disponibles o las limitaciones subyacentes.
start_addr / end_addr
Las direcciones de inicio y fin, inclusive, a incluir como parte del conjunto AV. El uso de la dirección de inicio y fin requiere que el AV asociado se haya creado como tipo FI_AV_TABLE. Las direcciones válidas en el AV que se encuentren dentro del rango especificado y que cumplan otros requisitos (como el paso) se añadirán como miembros iniciales al conjunto AV. start_addr y end_addr deben establecerse en FI_ADDR_NOTAVAIL si se crea un conjunto AV vacío, se proporciona una clave de comunicación, o el AV es de tipo FI_AV_MAP.

El número de direcciones entre start_addr y end_addr debe ser menor o igual al valor de count especificado.

stride
El número de entradas entre direcciones sucesivas incluidas en el conjunto AV. El conjunto AV incluirá todas las direcciones desde start_addr + stride x i, para valores enteros crecientes y no negativos de i, hasta end_addr. Un paso de 1 indica que todas las direcciones entre start_addr y end_addr deben añadirse al conjunto AV. Stride debe establecerse en 0, a menos que los campos start_addr y end_addr sean válidos.
comm_key_size
La longitud de la clave de comunicación en bytes. Este campo debe ser 0 si no hay una clave de comunicación disponible.
comm_key
Si es compatible con la red, esto representa una clave asociada con el conjunto AV. La clave de comunicación es utilizada por las aplicaciones que gestionan directamente la membresía colectiva a través de un agente de gestión de red o un gestor de recursos. La clave se utiliza para transmitir los resultados de la configuración de membresía al proveedor subyacente. El uso y formato de una clave de comunicación es específico del proveedor de red.
flags
Las banderas pueden utilizarse para configurar el conjunto AV, incluyendo la restricción de qué operaciones colectivas necesita soportar el conjunto AV. Consulte la sección de banderas para ver una lista de las banderas que pueden especificarse al crear el conjunto AV.

fi_av_set_union

La llamada de unión de conjuntos AV añade todas las direcciones del conjunto AV de origen que no están en el conjunto AV de destino al conjunto AV de destino. Donde el orden importa, las direcciones recién insertadas se colocan al final del conjunto AV.

fi_av_set_intersect

La llamada de intersección de conjuntos AV elimina todas las direcciones del conjunto AV de destino que no sean también miembros del conjunto AV de origen. El orden de las direcciones en el conjunto AV de destino no cambia.

fi_av_set_diff

La llamada de diferencia de conjuntos AV elimina todas las direcciones del conjunto AV de destino que también sean miembros del conjunto AV de origen. El orden de las direcciones en el conjunto AV de destino no cambia.

fi_av_set_insert

La llamada de inserción de conjuntos AV añade la dirección especificada al final del conjunto AV.

fi_av_set_remove

La llamada de eliminación de conjuntos AV elimina la dirección especificada del conjunto AV dado. El orden de las direcciones restantes en el conjunto AV no cambia.

fi_av_set_addr

Devuelve una dirección que puede utilizarse para comunicarse con todos los miembros actuales de un conjunto AV. Esta es una operación puramente local que no implica comunicación de red. La dirección devuelta puede utilizarse como entrada para fi_join_collective. fi_av_set.3 — Libfabric Programmer’s Manual

NAME

fi_av_set — AV set resource management

SYNOPSIS

#include <rdma/fabric.h>
int fi_create_av_set(struct fid_av *av,
                     struct fi_av_attr *attr,
                     struct fid_av_set **av_set);
int fi_destroy_av_set(struct fid_av_set *av_set);
int fi_av_set_add(struct fid_av_set *av_set,
                  const void *address,
                  void *context);
int fi_av_set_remove(struct fid_av_set *av_set,
                     const void *address,
                     void *context);
int fi_av_set_insert(struct fid_av_set *av_set,
                     const void *address,
                     size_t count,
                     void *context);
int fi_av_set_remove_by_index(struct fid_av_set *av_set,
                              size_t index,
                              size_t count,
                              void *context);
int fi_close(fid_t fd);

ARGUMENTS

av
An active Fabric Interface (FI) Address Vector (AV) resource. An AV set is created and associated with this AV.
attr
AV set attributes. See fi_av_set(3) for details on AV set attributes. Note that if the FI_UNIVERSE flag is specified in the attr structure, then the AV set will be created containing all addresses currently stored in the associated AV.
av_set
Return parameter for the newly created AV set. The AV set is a handle to the set of addresses.
address
The address to be added or removed from the AV set. The format of the address is dependent on the underlying fabric provider.
context
User-specified data that will be returned with the completion of the operation. See fi_cntr(3) for more information on context.
count
The number of addresses to be added or removed from the AV set. This parameter is used by fi_av_set_insert and fi_av_set_remove_by_index.
index
The starting index of addresses to be removed from the AV set. This parameter is used by fi_av_set_remove_by_index.

DESCRIPTION

An AV set is a collection of addresses that can be used to scope collective operations. AV sets are associated with an AV resource and inherit the communication fabric and addressing properties of that AV.

AV sets are primarily intended to simplify the use of collective operations within the Fabric Interface (FI) programming model. Rather than specifying a list of destination addresses for each collective operation, developers can create an AV set containing the desired group of addresses and then associate that AV set with the collective operation.

The following functions are provided for managing AV sets:

fi_create_av_set
Creates a new AV set associated with the specified AV. The flags and other parameters in the attr structure control the properties and initial contents of the AV set.
fi_destroy_av_set
Destroys the specified AV set and releases all associated resources. Any operations that were active and using this AV set will be aborted, with the result being undefined.
fi_av_set_add
Adds a single address to the specified AV set. If the address is already present in the AV set, the operation has no effect.
fi_av_set_remove
Removes a single address from the specified AV set. If the address is not present in the AV set, the operation has no effect.
fi_av_set_insert
Adds multiple addresses to the specified AV set. The addresses are provided as an array of address pointers. The count parameter specifies the number of addresses in the array.
fi_av_set_remove_by_index
Removes multiple addresses from the specified AV set, starting at the specified index. The count parameter specifies the number of addresses to remove.
fi_close
Closes an AV set and releases all resources associated with it. Any operations active at the time an AV set is closed will be aborted, with the result of the collective undefined.

Modifying the addresses stored in an AV set while operations are active that use that AV set results in undefined behavior.

FLAGS

The following flags may be specified as part of AV set creation.

FI_UNIVERSE
When set, then the AV set will be created containing all addresses stored in the corresponding AV.
FI_BARRIER_SET
If set, the AV set will be configured to support barrier operations.
FI_BROADCAST_SET
If set, the AV set will be configured to support broadcast operations.
FI_ALLTOALL_SET
If set, the AV set will be configured to support all to all operations.
FI_ALLREDUCE_SET
If set, the AV set will be configured to support all reduce operations.
FI_ALLGATHER_SET
If set, the AV set will be configured to support all gather operations.
FI_REDUCE_SCATTER_SET
If set, the AV set will be configured to support reduce scatter operations.
FI_REDUCE_SET
If set, the AV set will be configured to support reduce operations.
FI_SCATTER_SET
If set, the AV set will be configured to support scatter operations.
FI_GATHER_SET
If set, the AV set will be configured to support gather operations.

NOTES

Developers who are familiar with MPI will find that AV sets are similar to MPI groups, and may act as a direct mapping in some, but not all, situations.

By default an AV set will be created to support all collective operations supported by the underlying provider (see fi_query_collective). Users may reduce resource requirements by specifying only those collection operations needed by the AV set through the use of creation flags: FI_BARRIER_SET, FI_BROADCAST_SET, etc. If no such flags are specified, the AV set will be configured to support any that are supported. It is an error for a user to request an unsupported collective.

RETURN VALUES

Returns 0 on success. On error, a negative value corresponding to fabric errno is returned. Fabric errno values are defined in rdma/fi_errno.h.
