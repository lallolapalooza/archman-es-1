FIDO_BIO_INFO_NEW(3) Manual de funciones de biblioteca FIDO_BIO_INFO_NEW(3)

NOMBRE

fido_bio_info_new, fido_bio_info_free, fido_bio_info_type, fido_bio_info_max_samples — API de información del sensor biométrico FIDO2

SINOPSIS

#include <fido.h>
#include <fido/bio.h>

fido_bio_info_t *
fido_bio_info_new(void);

void
fido_bio_info_free(fido_bio_info_t **info_p);

uint8_t
fido_bio_info_type(const fido_bio_info_t *info);

uint8_t
fido_bio_info_max_samples(const fido_bio_info_t *info);

DESCRIPCIÓN

Los metadatos del sensor biométrico son abstraídos en libfido2 por el tipo fido_bio_info_t.

Las funciones descritas en esta página permiten que un tipo fido_bio_info_t sea asignado, liberado e inspeccionado. Para operaciones de dispositivo en fido_bio_info_t, por favor consulte fido_bio_dev_get_info(3).

La función fido_bio_info_new() devuelve un puntero a un tipo fido_bio_info_t recién asignado y vacío. Si no se puede asignar memoria, se devuelve NULL.

La función fido_bio_info_free() libera la memoria que soporta *info_p, donde *info_p debe haber sido previamente asignado por fido_bio_info_new(). Al regresar, *info_p se establece a NULL. Tanto info_p como *info_p pueden ser NULL, en cuyo caso fido_bio_info_free() no hace nada.

La función fido_bio_info_type() devuelve el tipo de sensor de huellas dactilares, que es 1 para sensores táctiles y 2 para sensores de deslizamiento.

La función fido_bio_info_max_samples() devuelve el número máximo de muestras exitosas requeridas para la inscripción.
