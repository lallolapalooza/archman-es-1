NOMBRE

findrule - envoltorio de línea de comandos para File::Find::Rule

USO

findrule [ruta...] [expresión]

DESCRIPCIÓN

"findrule" toma prestada en gran medida la interfaz de GNU find(1) para proporcionar una interfaz de línea de comandos a la jerarquía de módulos de File::Find::Rule.

La sintaxis de las expresiones es el nombre de la regla, precedido por un guión, seguido de un argumento opcional. Si el argumento es un paréntesis de apertura, se toma como una lista de argumentos, terminada por un paréntesis de cierre.

Algunos ejemplos:

find -file -name ( foo bar )

archivos llamados "foo" o "bar", por debajo del directorio actual.

find -file -name foo -bar

archivos llamados "foo", que tienen pubs (porque esto es lo que especifica nuestra ficticia cláusula "bar"), por debajo del directorio actual.

find -file -name ( -bar )

archivos llamados "-bar", por debajo del directorio actual. En este caso, si hubiéramos omitido el paréntesis, se habría analizado como una llamada a name sin argumentos, seguida de una llamada a -bar.

Cambios admitidos

Soy muy vago. Por favor, consulta la página del manual de File::Find::Rule por ahora, y antepón - a los comandos que quieras.

Cambios extra bonificados

findrule carga automáticamente todos tus módulos de extensión File::Find::Rule::* instalados, así que consulta la documentación para ver cuáles son.
