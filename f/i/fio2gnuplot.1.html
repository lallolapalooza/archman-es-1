NOMBRE

fio2gnuplot - Renderizar archivos de salida de fio con gnuplot

SINOPSIS

fio2gnuplot [-ghbiodvk] [-t título] [-o archivo_salida]
               [-d directorio_salida] [-p patrón]
               [-G tipo] [-m tiempo_min] [-M tiempo_max]

DESCRIPCIÓN

fio2gnuplot analiza un conjunto de archivos de registro de fio para convertirlos en un conjunto de trazas gráficas utilizando la herramienta gnuplot. Se producen varios tipos de trazados:

Gráfico 2D Individual
Cada archivo se traza en un archivo de imagen separado con varias opciones:
  • raw : Traza el rendimiento exacto reportado. Este trazado puede ser difícil de leer.
  • smooth : una versión más suave de la impresión raw. Usando la opción csplines de gnuplot, la representación se filtra para obtener un gráfico más fácil de leer.
  • trend : una versión aún más suave de la impresión raw para obtener tendencias. Las curvas de Bezier crean gráficos mucho más filtrados. El gráfico resultante ayuda a comprender las tendencias.
Gráfico 2D Agrupado
Todos los archivos se trazan en una sola imagen para facilitar la comparación. Se utilizan las mismas opciones de representación que en el gráfico 2D individual:
  • raw
  • smooth
  • trend
Gráfico 3D Agrupado
Todos los archivos se trazan en un único gráfico 3D. El trazado 3D genera una 'superficie' para estimar cuán cercanos fueron los rendimientos. Una superficie plana significa una buena coherencia entre las trazas. Una superficie rugosa significa una falta de coherencia entre las trazas.
Trazado Matemático
Gráfico Promedio
Un gráfico de barras para mostrar el rendimiento promedio de cada archivo. Se agrega una línea verde para mostrar el rendimiento promedio global. Esta línea verde ayuda a comprender cuán lejos del promedio está cada archivo individual.
Gráfico Mínimo
Se agrega una línea verde para mostrar el promedio global del rendimiento mínimo. Esta línea verde ayuda a comprender cuán lejos del promedio está cada archivo individual.
Gráfico Máximo
Un gráfico de barras para mostrar el rendimiento máximo de cada archivo. Se agrega una línea verde para mostrar el promedio global del rendimiento máximo. Esta línea verde ayuda a comprender cuán lejos del promedio está cada archivo individual.
Desviación Estándar
Un gráfico de barras para mostrar la desviación estándar de cada archivo. Se agrega una línea verde para mostrar el promedio global de la desviación estándar. Esta línea verde ayuda a comprender cuán lejos del promedio está cada archivo individual.

OPCIONES

-h o --help
La opción -h muestra la ayuda.
-p 'patrón' o --patrón 'patrón'
Un patrón en expresión regular para seleccionar archivos de entrada de fio. No olvides las comillas simples para evitar interacciones del shell.
-b o --bandwidth
Un patrón predefinido para seleccionar archivos *_bw.log.
-i o --iops
Un patrón predefinido para seleccionar archivos *_iops.log.
-g o --gnuplot
Renderiza las trazas de gnuplot antes de salir.
-o archivo o --archivo_salida archivo
El nombre base para las trazas de gnuplot (establecido con el patrón si está definido).
-d directorio o --directorio_salida directorio
El directorio donde gnuplot renderizará los archivos.
-t título o --título título
El título de las trazas de gnuplot. El título se establece con el tamaño de bloque detectado en la traza de fio.
-G tipo o --Global tipo
Busca el 'tipo' en los archivos .global que coincidan con un patrón. Los tipos disponibles son: min, max, avg, stddev. La extensión .global se agrega automáticamente al patrón.
-m tiempo o --tiempo_min tiempo
Solo considera datos a partir de 'tiempo' segundos. El valor predeterminado es 0.
-M tiempo o --tiempo_max tiempo
Solo considera datos hasta antes de 'tiempo' segundos. El valor predeterminado es -1, que significa sin límite.
-v o --verbose
Aumenta la verbosidad.
-k o --keep
Conserva todos los archivos temporales del directorio de salida de gnuplot.

EJEMPLO

Para trazar todas las trazas con nombre como 'host*_read_4k_iops.log'
$ fio2gnuplot -p 'host*_read_4k_iops.log' -g
Para trazar todos los archivos de registro orientados a IO del directorio actual
$ fio2gnuplot -g -i
Para trazar todos los archivos de registro orientados a Ancho de Banda del directorio actual
$ fio2gnuplot -g -b
Para trazar todos los archivos de registro orientados a Ancho de Banda en un directorio llamado 'outdir'
$ fio2gnuplot -g -b -d outdir
