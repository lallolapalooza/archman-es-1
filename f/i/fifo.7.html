fifo(7) Información Miscelánea Manual fifo(7)

NOMBRE

fifo - archivo especial de primera entrada, primera salida (first-in first-out), tubería con nombre

DESCRIPCIÓN

Un archivo especial FIFO (tubería con nombre) es similar a una tubería, excepto que se accede a él como parte del sistema de archivos. Puede ser abierto por múltiples procesos para lectura o escritura. Cuando los procesos intercambian datos a través de la FIFO, el kernel pasa todos los datos internamente sin escribirlos en el sistema de archivos. Por lo tanto, el archivo especial FIFO no tiene contenido en el sistema de archivos; la entrada del sistema de archivos simplemente sirve como un punto de referencia para que los procesos accedan a la tubería utilizando un nombre en el sistema de archivos.

El kernel mantiene exactamente un objeto de tubería por cada archivo especial FIFO que sea abierto por al menos un proceso. La FIFO debe ser abierta en ambos extremos (lectura y escritura) antes de que los datos puedan ser pasados. Normalmente, abrir la FIFO se bloquea hasta que el otro extremo también se abre.

Un proceso puede abrir una FIFO en modo no bloqueante. En este caso, abrir para solo lectura se completa con éxito incluso si nadie ha abierto en el lado de escritura todavía, y abrir para solo escritura falla con ENXIO (no existe tal dispositivo o dirección) a menos que el otro extremo ya haya sido abierto.

Bajo Linux, abrir una FIFO para lectura y escritura se completa con éxito tanto en modo bloqueante como no bloqueante. POSIX deja este comportamiento sin definir. Esto puede usarse para abrir una FIFO para escritura mientras no hay lectores disponibles. Un proceso que usa ambos extremos de la conexión para comunicarse consigo mismo debe tener mucho cuidado para evitar interbloqueos.

NOTAS

Para detalles sobre la semántica de E/S en FIFOs, ver pipe(7).

Cuando un proceso intenta escribir en una FIFO que no está abierta para lectura en el otro lado, se le envía una señal SIGPIPE.

Los archivos especiales FIFO pueden ser creados por mkfifo(3), y son indicados por ls -l con el tipo de archivo 'p'.

VER TAMBIÉN
