NOMBRE

fi_control - Realizar una operación en un recurso de fabric.

SINOPSIS

#include <rdma/fabric.h>
int fi_control(struct fid *fid, int command, void *arg);
int fi_alias(struct fid *fid, struct fid **alias_fid, uint64_t flags);
int fi_get_val(struct fid *fid, int name, void *val);
int fi_set_val(struct fid *fid, int name, void *val);

ARGUMENTOS

fid
Recurso de fabric.
command
Operación a realizar.
arg
Argumento opcional para el comando.

DESCRIPCIÓN

La operación fi_control se utiliza para realizar una o más operaciones en un recurso de fabric. Conceptualmente, fi_control es similar a la rutina fcntl de POSIX. El comportamiento exacto del uso de fi_control depende del recurso de fabric que se esté operando, el comando especificado y cualquier argumento proporcionado para el comando. Para detalles específicos, consulte las páginas de ayuda específicas del recurso de fabric que se mencionan a continuación.

fi_alias, fi_get_val y fi_set_val son envolturas para fi_control con los comandos FI_ALIAS, FI_GET_VAL y FI_SET_VAL, respectivamente. fi_alias crea un alias del recurso de fabric especificado. fi_get_val lee el valor del parámetro con nombre asociado al recurso de fabric, mientras que fi_set_val actualiza ese valor. Los nombres de parámetro disponibles dependen del tipo del recurso de fabric y del proveedor en uso. Los proveedores pueden definir nombres específicos del proveedor en los archivos de cabecera de la extensión del proveedor (’rdma/fi_ext_*.h’). Por favor, consulte las páginas del manual del proveedor para obtener detalles.
