filmleader(6) Manual de XScreenSaver filmleader(6)

NOMBRE

filmleader - salvapantallas.

SINOPSIS

filmleader [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id numero] [--tv-color numero] [--tv-tint numero] [--noise numero] [--tv-brightness numero] [--tv-contrast numero] [--fps]

DESCRIPCIÓN

Muestra una cuenta regresiva en bucle basada en el líder de película universal SMPTE en una simulación de un viejo televisor analógico.

OPCIONES

--visual visual
Especifica qué visual utilizar. Los valores válidos son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--tv-color numero
Control de Color. 0 - 1000. Por defecto: 70.
--tv-tint numero
Control de Tinte. 0 - 100. Por defecto: 5.
--noise numero
Ruido. 0.0 - 0.2. Por defecto: 0.04.
--tv-brightness numero
Control de Brillo. 0 - 200. Por defecto: 150.
--tv-contrast numero
Control de Contraste. 0 - 1500. Por defecto: 1000.
--fps | --no-fps
Si mostrar o no una pantalla de fotogramas por segundo en la parte inferior de la pantalla.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
