NOMBRE

File::HomeDir::Darwin::Cocoa - Encuentra tu directorio de inicio y otros directorios en Darwin (OS X)

DESCRIPCIÓN

Este módulo proporciona implementaciones específicas de Darwin para determinar directorios comunes de usuario utilizando la API de Cocoa a través de Mac::SystemDirectory. En uso normal, este módulo siempre se utilizará a través de File::HomeDir.

Teóricamente, esto debería devolver las mismas rutas que los otros dos controladores de Darwin.

Debido a que este módulo requiere Mac::SystemDirectory, si el módulo no está instalado, File::HomeDir recurrirá a File::HomeDir::Darwin.

SINOPSIS

use File::HomeDir;

# Encuentra directorios para el usuario actual
$home    = File::HomeDir->my_home;      # /Users/micuenta
$desktop = File::HomeDir->my_desktop;   # /Users/micuenta/Desktop
$docs    = File::HomeDir->my_documents; # /Users/micuenta/Documents
$music   = File::HomeDir->my_music;     # /Users/micuenta/Music
$pics    = File::HomeDir->my_pictures;  # /Users/micuenta/Pictures
$videos  = File::HomeDir->my_videos;    # /Users/micuenta/Movies
$data    = File::HomeDir->my_data;      # /Users/micuenta/Library/Application Support
