File::HomeDir::Test(3) Documentación de Perl aportada por el usuario File::HomeDir::Test(3)

NOMBRE

File::HomeDir::Test - Evita la creación accidental de archivos propiedad del usuario durante las pruebas

SINOPSIS

use Test::More test => 1;
use File::HomeDir::Test;
use File::HomeDir;

DESCRIPCIÓN

File::HomeDir::Test es un controlador de File::HomeDir destinado al uso en scripts de prueba de módulos o aplicaciones que escriben archivos en directorios propiedad del usuario.

Está diseñado para evitar la contaminación de directorios de usuario con archivos que no forman parte de la instalación de la aplicación en sí, sino que se crearon durante las pruebas. Estos archivos pueden filtrar información de estado de las pruebas al uso en tiempo de ejecución de una aplicación, y en sistemas Unix también evitan que las pruebas (que pueden ejecutarse como root a través de sudo) escriban archivos que no puedan ser modificados o eliminados posteriormente por el usuario regular.
