Este módulo lanza una excepción cuando no puede encontrar ningún archivo de datos, cuando no puede abrir un archivo de datos que encontró para lectura o cuando una subrutina no recibe suficientes argumentos. En el primer caso, o bien no tiene instalada la base de datos de información mime de freedesktop, o sus variables de entorno apuntan a los lugares equivocados; en el segundo caso, tiene la base de datos instalada, pero está dañada (la base de datos de información mime

debería ser legible por todos lógicamente).

LIMITACIONE

S

Las versiones de Perl anteriores a la 5.8.0 no tienen la capa de E/S ':utf8', por lo que para el método predeterminado y para leer los archivos xml no se admite utf8 en estas

versiones.

Dado que no es posible distinguir entre tipos de codificación (utf8, latin1, latin2, etc.) de una manera directa, solo se admite utf8 (porque la especificación lo recomienda)

.

Este módulo aún no comprueba los atributos extendidos para un mimetype. Los parches para esto son muy

bienvenidos.

Este módulo usa la base de datos de información mime compartida de FreeDesktop.org. En su escritorio linux esto suele estar preinstalado, por lo que no es un problema. En su servidor puede instalar el paquete shared-mime-info a través de apt o dnf o apk o lo que

sea.

Para instalar en macOS, puede instalarlo

así: 
brew install
shared-mime-inf
