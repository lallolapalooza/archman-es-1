FIND-DEBUGINFO(1) Comandos de usuario FIND-DEBUGINFO(1)

NOMBRE

find-debuginfo - encuentra información de depuración y la procesa

SINOPSIS

find-debuginfo [OPCIÓN]... [directorio_compilacion]

DESCRIPCIÓN

Genera automáticamente información de depuración y listas de archivos.

OPCIONES

[--strict-build-id] [-g] [-r] [-m] [-i] [-n] [-q] [-v] [--keep-section SECCIÓN] [--remove-section SECCIÓN] [--g-libs] [--no-ar-files] [-j N] [--jobs N] [-o debugfiles.list] [-S debugsourcefiles.list] [--run-dwz] [--dwz-low-mem-die-limit N] [--dwz-max-die-limit N] [--dwz-single-file-mode] [--build-id-seed SEMILLA] [--unique-debug-suffix SUFIJO] [--unique-debug-src-base BASE] [[-l listaarchivos]... [-p 'patrón'] -o debuginfo.list] [directorio_compilacion]

La bandera -g indica usar strip -g en lugar de strip completo en DSOs o EXEs. La bandera --g-libs indica usar strip -g en lugar de strip completo SÓLO en DSOs. Las opciones -g y --g-libs son mutuamente excluyentes.

La bandera -r indica usar eu-strip --reloc-debug-sections.

Use --keep-section SECCIÓN o --remove-section SECCIÓN para mantener explícitamente una sección (no asignada) en el ejecutable principal o eliminarla explícitamente en el archivo .debug. SECCIÓN es un patrón de comodín extendido. Ambas opciones se pueden dar más de una vez.

La bandera --strict-build-id indica salir con un estado de fallo si algún binario ELF procesado no contiene una nota build-id.

La bandera -m indica incluir una sección .gnu_debugdata (MiniDebugInfo) en el binario principal.

La bandera -i indica incluir una sección .gdb_index en el archivo .debug.

La bandera -n indica no recalcular el build-id.

La opción -j, --jobs N generará N procesos para realizar la extracción de información de depuración en paralelo.

Un único interruptor -o antes de cualquier interruptor -l o -p simplemente renombra el archivo de salida principal de debugfiles.list a otra cosa. Un interruptor -o que sigue a un interruptor -p o algunos interruptores -l produce un archivo de salida adicional con la información de depuración de los archivos en la lista de archivos -l, o cuyos nombres coinciden con el patrón -p. El argumento -p es una expresión regular de estilo grep -E que coincide con el nombre de un archivo y no debe usar anclajes (^ o $).

La bandera --run-dwz instruye a find-debuginfo a ejecutar la utilidad dwz si está disponible, y --dwz-low-mem-die-limit y --dwz-max-die-limit proporcionan límites detallados. Ver dwz(1) opciones -l y -L para más detalles. Use --dwz-single-file-mode para deshabilitar el modo de archivo múltiple, ver dwz(1) -m para más detalles.

Si se da --build-id-seed SEMILLA, entonces se llama a debugedit para actualizar los build-ids que encuentra, añadiendo la SEMILLA como semilla para recalcular el hash del build-id. Esto asegura que los build-ids en los archivos ELF sean únicos entre versiones y lanzamientos del mismo paquete. (Use --build-id-seed "%{VERSION}-%{RELEASE}".)

Si se da --unique-debug-suffix SUFIJO, entonces los archivos de depuración creados para <ARCHIVO> se llamarán <ARCHIVO>-<SUFIJO>.debug. Esto asegura que los archivos .debug sean únicos entre la versión del paquete, el lanzamiento y la arquitectura. (Use --unique-debug-suffix "-%{VERSION}-%{RELEASE}.%{_arch}".)

Si se da --unique-debug-src-base BASE, entonces el directorio de origen se llamará /usr/debug/src/<BASE>. Esto asegura que los directorios de origen de depuración sean únicos entre la versión del paquete, el lanzamiento y la arquitectura (Use --unique-debug-src-base "%{name}-%{VERSION}-%{RELEASE}.%{_arch}")

Si se da --no-ar-files, entonces se ignorarán las bibliotecas estáticas. De lo contrario, solo se les proporciona reescritura y recopilación de rutas de origen. No se les aplica strip, ya que no tienen build-ids persistentes para acomodar una eventual reunificación.

La bandera -q o --quiet silencia toda la salida que no sea de error del script. La bandera -v o --verbose añade más salida para todos los archivos procesados. Cuando no se da ni -q ni -v, solo se muestra la salida de cada pasada.

Todos los nombres de archivo en los interruptores son relativos a directorio_compilacion ('.' si no se proporciona).
