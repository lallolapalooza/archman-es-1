FIREWALLD.POLICY-(5) Conjunto de políticas de Firewalld: Gateway FIREWALLD.POLICY-(5)

NOMBRE

firewalld.policy-set-gateway - Conjunto de políticas de Firewalld: Gateway

DESCRIPCIÓN

Conjunto de políticas: Gateway

El conjunto de políticas Gateway es un punto de partida útil para un enrutador doméstico. Habilita el enmascaramiento, los ayudantes de conntrack y el reenvío entre zonas.

Las zonas utilizadas por este conjunto están agrupadas lógicamente. Estos nombres de grupo se utilizan en las políticas predefinidas.

            +-----------+                  +-----------+
            |    LAN    |                  |   MUNDO   |
            |-----------|                  |-----------|
            | zonas:    |                  | zonas:    |
            |  internal |                  |  external |
            |  home     |                  |  public   |
            |  trusted  |                  |           |
            +-----------+                  +-----------+
                  |                              |
                  |                              |
                  |         +-----------+        |
                  +---------|    HOST   |--------+
                            |-----------|
                            | zonas:    |
                  +---------|   HOST    |--------+
                  |         +-----------+        |
                  |                              |
                  |                              |
            +-----------+                  +-----------+
            |    WORK   |                  |    DMZ    |
            |-----------|                  |-----------|
            | zones:    |                  | zones:    |
            |  work     |                  |  dmz      |
            +-----------+                  +-----------+

Políticas en el conjunto Gateway

gateway-dmz-to-HOST

Habilita los servicios comúnmente necesarios para una pasarela, por ejemplo, dns, dhcp.

Ubicación del archivo: /usr/lib/firewalld/policies/gateway-dmz-to-HOST.xml

gateway-lan-to-work

Permite todo el tráfico de LAN a work. Habilita el enmascaramiento y los ayudantes comunes de seguimiento de conexiones.

Ubicación del archivo: /usr/lib/firewalld/policies/gateway-lan-to-work.xml

gateway-lan-to-world

Permite todo el tráfico de LAN al mundo. Si se agrega una interfaz a la zona "external", el tráfico se enmascarará. También habilita ayudantes de seguimiento de conexiones para servicios comunes, por ejemplo, ftp.

Ubicación del archivo: /usr/lib/firewalld/policies/gateway-lan-to-world.xml

gateway-lan-to-HOST

Habilita los servicios comúnmente necesarios para una pasarela, por ejemplo, dns, dhcp.

Ubicación del archivo: /usr/lib/firewalld/policies/gateway-lan-to-HOST.xml

gateway-world-to-HOST

Puede usarse para exponer servicios internos/dmz al mundo agregando un puerto de reenvío a esta política.

Aquí hay un ejemplo para agregar un puerto de reenvío. Reenvía el puerto 8080 a 10.1.1.42:80.

# firewall-cmd --permanent --policy gateway-world-to-HOST \
               --add-forward-port=port=8080:proto=tcp:toport=80:toaddr=10.1.1.42
# firewall-cmd --reload

Ubicación del archivo: /usr/lib/firewalld/policies/gateway-world-to-HOST.xml
