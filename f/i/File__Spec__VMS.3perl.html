File::Spec::VMS(3perl) Guía de referencia del programador de Perl File::Spec::VMS(3perl)

NOMBRE

File::Spec::VMS - métodos para especificaciones de archivos VMS

SINOPSIS

require File::Spec::VMS; # Hecho internamente por File::Spec si es necesario

DESCRIPCIÓN

Ver File::Spec::Unix para obtener una documentación de los métodos proporcionados allí. Este paquete reemplaza la implementación de estos métodos, no las semánticas.

El comportamiento predeterminado es permitir la sintaxis VMS o Unix en la entrada y devolver la sintaxis VMS en la salida, a menos que la sintaxis Unix se haya solicitado explícitamente a través de la función CRTL "DECC$FILENAME_UNIX_REPORT".

canonpath (reemplazar)
Elimina partes redundantes de las especificaciones de archivos y devuelve los resultados en sintaxis nativa, a menos que se haya habilitado la información de nombres de archivo Unix.
catdir (reemplazar)
Concatena una lista de especificaciones de archivos y devuelve el resultado como una especificación de directorio nativa, a menos que se haya habilitado la función de información de nombres de archivo Unix. No se realiza ninguna comprobación de casos "imposibles" (por ejemplo, elementos que no sean el primero que sean especificaciones de archivo absolutas).
catfile (reemplazar)
Concatena una lista de especificaciones de directorio con una especificación de nombre de archivo para construir una ruta.
curdir (reemplazar)
Devuelve una representación de cadena del directorio actual: '[]' o '.'
devnull (reemplazar)
Devuelve una representación de cadena del dispositivo nulo: '_NLA0:' o '/dev/null'
rootdir (reemplazar)
Devuelve una representación de cadena del directorio raíz: 'SYS$DISK:[000000]' o '/'
tmpdir (reemplazar)
Devuelve una representación de cadena del primer directorio escribible de la siguiente lista o '' si ninguno es escribible: 
/tmp si C<DECC$FILENAME_UNIX_REPORT> está habilitado.
sys$scratch:
$ENV{TMPDIR}

Si se ejecuta en modo contaminado, y si $ENV{TMPDIR} está contaminado, no se usa.

updir (reemplazar)
Devuelve una representación de cadena del directorio padre: '[-]' o '..'
case_tolerant (reemplazar)
La sintaxis de especificación de archivos VMS es tolerante a mayúsculas y minúsculas.
path (reemplazar)
Traduce el nombre lógico DCL$PATH como una lista de búsqueda, en lugar de intentar "dividir" el valor de cadena de $ENV{'PATH'}.
file_name_is_absolute (reemplazar)
Comprueba la especificación de directorio VMS y los separadores Unix.
splitpath (reemplazar)
($volume,$directories,$file) = File::Spec->splitpath( $path );
($volume,$directories,$file) = File::Spec->splitpath( $path,
                                                      $no_file );

Pasar un valor verdadero para $no_file indica que la ruta que se está dividiendo solo contiene componentes de directorio, incluso en sistemas donde normalmente (cuando no se admite una sintaxis extranjera) se puede distinguir de un vistazo entre directorios y archivos.

splitdir (reemplazar)
Divide una especificación de directorio en sus componentes.
catpath (reemplazar)
Construye una especificación de archivo completa.
abs2rel (reemplazar)
Intenta convertir una especificación de archivo absoluta a una relativa.
rel2abs (reemplazar)
Devuelve una especificación de archivo absoluta a partir de una relativa.
