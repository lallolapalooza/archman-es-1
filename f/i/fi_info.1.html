NOMBRE

fi_info - Utilidad simple para consultar interfaces de fabric

SINOPSIS

 fi_info [OPCIONES]

DESCRIPCIÓN

La utilidad fi_info se puede usar para consultar las interfaces de fabric disponibles. La utilidad admite el filtrado basado en varias opciones, como el tipo de punto final, el nombre del proveedor o los modos admitidos. Además, fi_info también se puede usar para descubrir las variables de entorno que se pueden usar para ajustar parámetros específicos del proveedor. Si no se especifican filtros, se devolverán todas las interfaces de fabric disponibles para todos los proveedores y tipos de punto final.

OPCIONES

Filtrado

-n, –node=<NOMBRE>
Nombre de nodo o dirección utilizada para filtrar interfaces. Solo responderán las interfaces que puedan alcanzar el nodo o la dirección indicados.
-P, –port=<PUERTO>
Número de puerto utilizado para filtrar interfaces.
-c, –caps=<CAP1|CAP2>..
Lista de capacidades separadas por pipe utilizadas para filtrar interfaces. Solo responderán las interfaces que admitan todas las capacidades indicadas. Para obtener más información sobre las capacidades, consulte fi_getinfo(3).
-m, –mode=<MOD1|MOD2>..
Lista de modos separados por pipe utilizados para filtrar interfaces. Solo responderán las interfaces que admitan todos los modos indicados. Para obtener más información sobre los modos, consulte fi_getinfo(3).
-t, –ep_type=<TIPO_EP>
Especifica el tipo de comunicación de interfaz de fabric deseado. Por ejemplo, especificar FI_EP_DGRAM devolvería solo las interfaces que admitan datagramas no confiables. Para obtener más información sobre los tipos de punto final, consulte fi_endpoint(3).
-a, –addr_format=<FMT>
Filtra las interfaces de fabric por su formato de dirección. Por ejemplo, especificar FI_SOCKADDR_IN devolvería solo las interfaces que usan estructuras sockaddr_in para el direccionamiento. Para obtener más información sobre los formatos de dirección, consulte fi_getinfo(3).
-p, –provider=<PROV>
Filtra las interfaces de fabric por la implementación del proveedor. Para obtener una lista de proveedores, consulte la opción --list.
-d, –domain=<DOMINIO>
Filtra las interfaces para que solo se muestren aquellas con el nombre de dominio indicado.
-f, –fabric=<FABRIC>
Filtra las interfaces para que solo se muestren aquellas con el nombre de fabric indicado.

Descubrimiento

-e, –env
Lista las variables de entorno relacionadas con libfabric que se pueden usar para habilitar configuración o ajustes adicionales.
-g [filtro]
Igual que la opción -e, pero con la salida limitada a las variables de entorno que contienen el filtro como subcadena.
-l, –list
Lista los proveedores de libfabric disponibles.
-v, –verbose
De forma predeterminada, fi_info mostrará un resumen de cada una de las interfaces descubiertas. Si se habilita la opción verbose, se mostrarán todos los contenidos de la estructura fi_info. Para obtener más información sobre los datos contenidos en la estructura fi_info, consulte fi_getinfo(3).
–version
Muestra la información de la versión.

EJEMPLOS DE USO

$ fi_info -p verbs -t FI_EP_DGRAM

Esto responderá con todas las interfaces de fabric que usan el tipo de punto final FI_EP_DGRAM con el proveedor verbs.

fi_info -c 'FI_MSG|FI_READ|FI_RMA'

Esto responderá con todas las interfaces de fabric que pueden admitir las capacidades FI_MSG|FI_READ|FI_RMA.
