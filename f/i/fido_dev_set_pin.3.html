fido_dev_set_pin(3)

Paquete: libfido2

Licencias: BSD-2-Clause

FIDO_DEV_SET_PIN(3) Manual de funciones de biblioteca FIDO_DEV_SET_PIN(3)

NOMBRE

fido_dev_set_pin, fido_dev_get_retry_count, fido_dev_get_uv_retry_count, fido_dev_reset — Funciones de gestión de dispositivos FIDO2

SINOPSIS

#include <fido.h>

int
fido_dev_set_pin(fido_dev_t *dev, const char *pin, const char *oldpin);

int
fido_dev_get_retry_count(fido_dev_t *dev, int *retries);

int
fido_dev_get_uv_retry_count(fido_dev_t *dev, int *retries);

int
fido_dev_reset(fido_dev_t *dev);

DESCRIPCIÓN

La función fido_dev_set_pin() establece el PIN del dispositivo dev en pin, donde pin es una cadena terminada en NUL y codificada en UTF-8. Si oldpin no es NULL, el PIN del dispositivo se cambia de oldpin a pin, donde pin y oldpin son cadenas terminadas en NUL y codificadas en UTF-8.

La función fido_dev_get_retry_count() rellena retries con el número de reintentos de PIN restantes en dev antes del bloqueo, donde retries es un puntero direccionable.

La función fido_dev_get_uv_retry_count() rellena retries con el número de reintentos UV integrados restantes en dev antes de que se deshabilite la autenticación UV integrada, donde retries es un puntero direccionable.

La función fido_dev_reset() realiza un reinicio en dev, restableciendo el PIN del dispositivo y borrando las credenciales almacenadas en el dispositivo.

Tenga en cuenta que fido_dev_set_pin(), fido_dev_get_retry_count(), fido_dev_get_uv_retry_count() y fido_dev_reset() son síncronas y bloquearán si es necesario.

VALORES DE RETORNO

Los códigos de error devueltos por fido_dev_set_pin(), fido_dev_get_retry_count(), fido_dev_get_uv_retry_count() y fido_dev_reset() están definidos en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

VER TAMBIÉN

fido_cbor_info_uv_attempts(3)

ADVERTENCIAS

En cuanto a fido_dev_reset(), el flujo de usuario real para realizar un reinicio está fuera del alcance de la especificación FIDO2 y, por lo tanto, puede variar según el autenticador. Los autenticadores Yubico devolverán FIDO_ERR_NOT_ALLOWED si se emite un reinicio más de 5 segundos después de encender el dispositivo, y FIDO_ERR_ACTION_TIMEOUT si el usuario no confirma el reinicio tocando la llave dentro de los 30 segundos.
