NOMBRE

firewalld.ipset - archivos de configuración de ipset de firewalld

SINOPSIS

/etc/firewalld/ipsets/ipset.xml
/usr/lib/firewalld/ipsets/ipset.xml

DESCRIPCIÓN

Un archivo de configuración de ipset de firewalld proporciona la información de un conjunto de ips para firewalld. Las opciones de configuración más importantes son type, option y entry.

Este archivo de configuración de ejemplo muestra la estructura de un archivo de configuración de ipset:

<?xml version="1.0" encoding="utf-8"?>
<ipset type="hash:ip">
  <short>Mi Ipset</short>
  <description>descripción</description>
  <entry>1.2.3.4</entry>
  <entry>1.2.3.5</entry>
  <entry>1.2.3.6</entry>
</ipset>

OPCIONES

La configuración puede contener estas etiquetas y atributos. Algunos de ellos son obligatorios, otros opcionales.

ipset

La etiqueta de inicio y fin obligatoria de ipset define el ipset. Esta etiqueta solo se puede usar una vez en un archivo de configuración de ipset. Hay un atributo obligatorio y también opcional para los ipsets:

type="string"

El tipo obligatorio del ipset. Para obtener la lista de tipos compatibles, usa firewall-cmd --get-ipset-types.

version="string"

Para darle una versión al ipset.

short

Es una etiqueta de inicio y fin opcional y se usa para dar un nombre más legible a un ipset.

description

Es una etiqueta de inicio y fin opcional para tener una descripción de un ipset.

option

Es una etiqueta de elemento vacío opcional y se puede usar varias veces para tener más de una opción. La mayoría de los atributos de una entrada de opción son obligatorios:

name="string"

El nombre de opción obligatorio string.

value="string"

El valor opcional de la opción.

Las opciones compatibles son: family: "inet"|"inet6", timeout: integer, hashsize: integer, maxelem: integer. Para más información sobre estas opciones, por favor, consulta la documentación de ipset.

entry

Es una etiqueta de inicio y fin opcional y se puede usar varias veces para tener más de una entrada. Una entrada no tiene atributos.
