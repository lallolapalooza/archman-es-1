NOMBRE

fido_dev_make_cred — genera una nueva credencial en un dispositivo FIDO2

SINOPSIS

#include <fido.h>

int
fido_dev_make_cred(fido_dev_t *dev, fido_cred_t *cred, const char *pin);

DESCRIPCIÓN

La función fido_dev_make_cred() solicita al dispositivo FIDO2 representado por dev que genere una nueva credencial de acuerdo con los siguientes parámetros definidos en cred:

  • type;
  • hash de datos del cliente;
  • parte de confianza;
  • atributos de usuario;
  • lista de IDs de credencial excluidas;
  • clave residente/descubrible y atributos de verificación de usuario.

Ver fido_cred_set_authdata(3) para obtener información sobre cómo se establecen estos valores.

Si no se necesita un PIN para autenticar la solicitud contra dev, entonces pin puede ser NULL. De lo contrario, pin debe apuntar a una cadena UTF-8 terminada en NUL.

Después de una llamada exitosa a fido_dev_make_cred(), las funciones fido_cred_authdata_ptr(3), fido_cred_pubkey_ptr(3), fido_cred_x5c_ptr(3), y fido_cred_sig_ptr(3) pueden ser invocadas sobre cred para recuperar las diversas partes de la credencial generada.

Tenga en cuenta que fido_dev_make_cred() es síncrona y se bloqueará si es necesario.

VALORES DE RETORNO

Los códigos de error devueltos por fido_dev_make_cred() se definen en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

VER TAMBIÉN

fido_cred_new(3), fido_cred_set_authdata(3)
