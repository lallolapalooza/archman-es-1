NOMBRE

fio_generate_plots - Genera gráficos para el Probador de E/S Flexible

SINOPSIS

fio_generate_plots título

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando fio_generate_plots. Esta página del manual fue escrita para la distribución Debian porque el programa original no tiene una página del manual.

fio_generate_plots es un script de shell que utiliza gnuplot para generar gráficos a partir de ejecuciones de fio con --latency-log (-l) y/o --bandwidth-log (-w). Espera los archivos de registro que fio generó en el directorio actual.

OPCIONES

El script toma el título del gráfico como único argumento. No ofrece ninguna opción adicional.
