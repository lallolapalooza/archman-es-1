NAME

File::GlobMapper - Perl module for filename mapping

SYNOPSIS

use File::GlobMapper qw(globmap) ;
my $pairs = globmap($from_glob, $to_glob);
for my $pair (@$pairs) {
    my ($from, $to) = @$pair;
    # do something with $from and $to
}

DESCRIPTION

The globmap function takes two glob patterns, expands them and returns a reference to an array of pairs of filenames. It is primarily intended for use in renaming files.

The arguments to globmap are:

from_glob
A glob pattern specifying the source files.
to_glob
A glob pattern specifying the destination files. This pattern may contain capture groups of the form \#n, where n is the number of the capture group.

The function returns undef on error, setting the $File::GlobMapper::Error global variable.

On success, it returns a reference to an array of pairs of filenames. Each pair is an array reference containing two strings: the source filename and the destination filename.

The expansion is performed using the standard Perl globbing mechanisms. If the number of files matching $from_glob is not equal to the number of files matching $to_glob then an error is returned.

The globmap function is designed to be used with File::Copy.

use File::GlobMapper qw(globmap) ;
use File::Copy;
die "rename: Usage rename 'from' 'to'\n"
    unless @ARGV == 2 ;
my $fromGlob = shift @ARGV;
my $toGlob   = shift @ARGV;
my $pairs = globmap($fromGlob, $toGlob)
    or die $File::GlobMapper::Error;
for my $pair (@$pairs)
{
    my ($from, $to) = @$pair;
    move $from => $to ;
}

EXAMPLES

Here is an example that renames all c files to cpp.

$ rename '*.c' '#1.cpp'

A few example globmaps

Below are a few examples of globmaps

To copy all your .c file to a backup directory

'</my/home/*.c>'    '</my/backup/#1.c>'

If you want to compress all

'</my/home/*.[ch]>'    '<*.gz>'

To uncompress

'</my/home/*.[ch].gz>'    '</my/home/#1.#2>'
