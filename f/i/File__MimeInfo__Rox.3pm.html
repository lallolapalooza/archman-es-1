NOMBRE

File::MimeInfo::Rox - Abrir archivos por tipo MIME al estilo "Rox"

SINOPSIS

use File::MimeInfo::Magic;
use File::MimeInfo::Rox qw/:magic/;
# abrir un archivo con el programa apropiado
mime_system($somefile);
# versión más detallada
my $mt = mimetype($somefile)
  || die "No se pudo encontrar el tipo MIME para $somefile\n";
mime_system($somefile, $mt)
  || die "No hay ningún programa disponible para abrir $somefile\n";

DESCRIPCIÓN

Este módulo intenta imitar el comportamiento del navegador de archivos rox http://rox.sf.net al "abrir" archivos de datos. Determina el tipo MIME y busca en los directorios "Choices" de rox un programa para manejar ese tipo MIME.

Consulte la documentación de rox para una discusión exhaustiva de este mecanismo.

EXPORTAR

Los métodos "mime_exec" y "mime_system" se exportan. Si usa la etiqueta de exportación ":magic", obtendrá los mismos métodos, pero se usará File::MimeInfo::Magic para la búsqueda del tipo MIME.

ENTORNO

La variable de entorno "CHOICESPATH" se utiliza al buscar los directorios de configuración de rox. Por defecto es "$ENV{HOME}/Choices:/usr/local/share/Choices:/usr/share/Choices"

MÉTODOS

mime_system($file)
"mime_system($file, $mimetype, @_)"
Intenta abrir $file con el programa apropiado para archivos de su tipo MIME. Puede usar $mimetype para forzar el tipo MIME. Además, si ya conoce el tipo MIME, ahorrará mucho tiempo si simplemente lo indica.

Si no se pudo determinar el tipo MIME o no se encontró ningún programa apropiado, se devuelve "undef". Si el sistema falla realmente, se genera una excepción.

Los argumentos restantes se pasan al manejador.

mime_exec($file)
"mime_exec($file, $mimetype, @_)"
Al igual que mime_system(), pero usa exec en lugar de system, por lo que **nunca regresa** si tiene éxito.
suggest_script_name($mimetype)
Devuelve la lista "($dir, $file)" para el lugar sugerido para escribir nuevos scripts (o enlaces simbólicos) para el tipo MIME $mimetype. El directorio sugerido no necesita existir.
