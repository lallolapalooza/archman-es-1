NOMBRE

fish_key_reader - explorar qué caracteres envían las teclas del teclado

SINOPSIS

fish_key_reader [OPCIONES]

DESCRIPCIÓN

fish_key_reader se utiliza para explicar cómo enlazarías una determinada secuencia de teclas. Por defecto, imprime el comando bind <> para una secuencia de teclas leída interactivamente a través de la entrada estándar.

Las siguientes opciones están disponibles:

-c o --continuous
Inicia una sesión donde se pueden inspeccionar múltiples secuencias de teclas. Por defecto, el programa sale después de capturar una sola secuencia de teclas.
-h o --help
Muestra ayuda sobre el uso de este comando.
-V o --verbose
Explica qué secuencia se recibió además de la tecla decodificada.
-v o --version
Muestra la versión actual de fish y luego sale.

NOTAS DE USO

fish_key_reader deshabilita intencionalmente el manejo de muchas señales. Para terminar fish_key_reader en modo --continuous haz lo siguiente:

  • presiona ctrl-c dos veces, o
  • presiona ctrl-d dos veces, o
  • escribe exit, o
  • escribe quit

EJEMPLO

> fish_key_reader
Press a key:
# presiona flecha arriba
bind up 'do something'
