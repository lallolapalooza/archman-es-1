¿Qué es una

zona?

Una zona de red define el nivel de confianza para las conexiones de red. Esta es una relación de uno a muchos, lo que significa que una conexión solo puede ser parte de una zona, pero una zona puede usarse para muchas conexiones de

red.

La zona define las características del cortafuegos que están habilitadas en esta

zona:

Reenvío intra-zona

Permite que los paquetes recibidos por una zona se reenvíen a otras interfaces o fuentes dentro de la misma zona, incluso si el destino de la zona no es ACCE

P
T.

Servicios predefinidos

Un servicio es una combinación de entradas de puerto y/o prot

ocolo. Opcionalmente se pueden añadir módulos auxiliares
de netfilter y también una dirección de destino IPv4 e IPv6.

Puertos y protocolos

Definición de tcp, udp, sctp o dccp puertos, donde los puertos pueden

ser un solo puerto o
un rango de puertos.

Bloqueos ICMP

Bloquea mensajes seleccionados del Protocolo de Mensajes de Control de Int

ernet (ICMP). Estos mensajes son solicitudes de información o se crean
como respuesta a solicitudes de información o en condiciones de error.

Inversión de bloqueo ICMP

Cambia cómo se manejan los mensajes ICMP. Cuando está habilitado, todos los tipos de mensajes ICMP están bloqueados, excepto los de la lis

ta de bloqu
eo ICMP.

Enmascaramiento

Las direcciones de una red privada se mapean y s

e ocultan detrás de una dirección IP pública.
Esta es una forma de traducción de direcciones.

Reenvío de puertos

Un puerto reenviado se mapea ya sea al mismo

puerto en otro host o a otro puerto en
el mismo host o a otro puerto en otro host.

Reglas de lenguaje enriquecido

El lenguaje enriquecido extiende los elementos (servicio, puerto, icmp-block, masquerade, forward-port y source-port) con direcciones de origen y destino adicionales, registro, acciones y límites para registros y acciones. También se puede usar para listas blancas y negras de hosts o redes (para más información, por favor, eche un vistazo a firewalld.rich

langua
ge(5)).

Para más información sobre el formato de archivo de zona, por favor, eche un vistazo a firewalld

.zone
(5).

¿Qué zonas están

disponibles?

Aquí están las zonas proporcionadas por firewalld ordenadas según el nivel de confianza predeterminado de las zonas, de no confiable a

confiable:

dro

p
Cualquier paquete de red entrante se descarta, no hay respuesta. Solo son posibles las conexiones de red
salientes.

bloc

k
Cualquier conexión de red entrante se rechaza con un mensaje icmp-host-prohibited para IPv4 y icmp6-adm-prohibited para IPv6. Solo son posibles las conexiones de red iniciadas dentro de este
sistema.

publi

c
Para usar en áreas públicas. No confías en las otras computadoras en las redes para que no dañen tu computadora. Solo se aceptan conexiones entrantes
seleccionadas.

externa

l
Para usar en redes externas con enmascaramiento habilitado, especialmente para enrutadores. No confías en las otras computadoras en las redes para que no dañen tu computadora. Solo se aceptan conexiones entrantes
seleccionadas.

dm

z
Para computadoras en tu zona desmilitarizada que son accesibles públicamente con acceso limitado a tu red interna. Solo se aceptan conexiones entrantes
seleccionadas.

wor

k
Para usar en áreas de trabajo. Confías mayormente en las otras computadoras en las redes para que no dañen tu computadora. Solo se aceptan conexiones entrantes
seleccionadas.

hom

e
Para usar en áreas domésticas. Confías mayormente en las otras computadoras en las redes para que no dañen tu computadora. Solo se aceptan conexiones entrantes
seleccionadas.

interna

l
Para usar en redes internas. Confías mayormente en las otras computadoras en las redes para que no dañen tu computadora. Solo se aceptan conexiones entrantes
seleccionadas.

truste

d
Se aceptan todas las conexiones
de red. Los paquetes no dirig
idos a este host se reenviarán.

¿Qué zona debería

usarse?

Una conexión de red WIFI pública, por ejemplo, debería ser principalmente n

o confiable, una conexión de red cableada doméstica debería ser bastante confi
able. Seleccione la zona que mejor coincida con la red que está utilizando.

¿Cómo configurar o añadir

zonas?

Para configurar o añadir zonas, puede usar una de las interfaces de firewalld para gestionar y cambiar la configuración: Estas son la herramienta gráfica de configuración firewall-config, la herramienta de línea de comandos firewall-cmd o la interfaz D-Bus. O puede crear o copiar un archivo de zona en uno de los directorios de configuración. /usr/lib/firewalld/zones se usa para configuraciones predeterminadas y de respaldo y /etc/firewalld/zones se usa para archivos de configu

ración creados por el usu
ario y personalizados.

¿Cómo establecer o cambiar una zona para una

conexión?

La zona se guarda en el ifcfg de la conexión con la opción ZONE=. Si la opción falta o está vacía, se usa la zona predeterminada establecida en

firewalld.

Si la conexión está controlada por NetworkManager, también puede usar nm-connection-editor para cambiar la

zona.

Para la adición o cambio de interfaces que no están bajo control de NetworkManager: firewalld intenta cambiar la configuración ZONE en el archivo ifcfg, si existe un archivo ifcfg que usa la

interfaz.

Solo para la eliminación de interfaces que no están bajo control de NetworkManager: firewalld

no intenta cambiar la configuración ZONE en el archivo ifcfg. Esto es necesario para asegura
r que un ifdown de la interfaz no resulte en un restablecimiento de la configuración de la zo
na a la zona predeterminada. Solo se elimina entonces la vinculación de la zona en firewalld.
