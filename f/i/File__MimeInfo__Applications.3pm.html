NOMBRE

File::MimeInfo::Applications - Encuentra programas para abrir un archivo por tipo MIME

SINOPSIS

use File::MimeInfo::Magic;
use File::MimeInfo::Applications;
my $archivo = '/foo/bar';
my $mimetype = mimetype($archivo)
  || die "No se pudo encontrar el tipo MIME para $archivo\n";
my ($predeterminado, @otros) = mime_applications($mimetype);
if (defined $predeterminado) {
  $predeterminado->system($archivo)
}
else {
  # preguntar al usuario con la opción de @otros
  # ...
}

DESCRIPCIÓN

Este módulo intenta encontrar aplicaciones que puedan abrir archivos con un tipo MIME determinado. Esto se hace de la manera sugerida por la especificación de entradas de escritorio de freedesktop. Este módulo está diseñado para ser compatible con administradores de archivos y otras aplicaciones que implementan esta especificación.

Este módulo depende de que File::DesktopEntry esté instalado.

Para usar este módulo de manera efectiva, debe tener el paquete desktop-file-utils de freedesktop y ejecutar update-desktop-database después de instalar nuevos archivos .desktop. Consulte http://www.freedesktop.org/wiki/Software/desktop-file-utils.

En el momento de escribir esto, este módulo es compatible con la forma en que Nautilus (Gnome) y Thunar (XFCE) manejan las aplicaciones para tipos MIME. Entiendo que KDE todavía está trabajando en la implementación de las especificaciones MIME de freedesktop, pero seguirá.

EXPORTAR

Todos los métodos se exportan por defecto.

MÉTODOS

mime_applications(TIPO_MIME)
Devuelve una matriz de objetos File::DesktopEntry. El primero es la aplicación predeterminada para este tipo MIME, los demás son aplicaciones que dicen que pueden manejar este tipo MIME.

Si el primer resultado no está definido, no hay una aplicación predeterminada y es una buena práctica preguntar al usuario qué aplicación desea utilizar.

mime_applications_all(TIPO_MIME)
Similar a mime_applications(), pero también tiene en cuenta las aplicaciones que pueden abrir tipos MIME de los cuales TIPO_MIME hereda. Los tipos MIME padres dicen algo sobre el formato de los datos, por ejemplo, todo el código hereda de text/plain.
"mime_applications_set_default(TIPO_MIME, APLICACIÓN)"
Guarda una aplicación predeterminada para este tipo MIME. Esta acción afectará a otras aplicaciones que utilicen el mismo mecanismo para encontrar una aplicación predeterminada.

APLICACIÓN puede ser un objeto File::DesktopEntry o el nombre base de un archivo .desktop.

"mime_applications_set_custom(TIPO_MIME, COMANDO)"
Guarda un comando de shell personalizado como aplicación predeterminada. Genera un archivo DesktopEntry sobre la marcha y llama a "mime_applications_set_custom". Devuelve el objeto DesktopEntry.

No se realizan comprobaciones en COMANDO. Sin embargo, debería contener al menos una palabra.

NOTAS

Este módulo busca archivos de asociaciones en el orden especificado en la versión 1.0 de la especificación de aplicaciones MIME. También intentará un último recurso al archivo heredado $XDG_DATA_HOME/applications/defaults.list. En todos los casos, solo escribirá en el archivo de valores predeterminados por usuario recomendado ubicado en $XDG_CONFIG_HOME/mimeapps.list.
