File::Slurp(3) Documentación de Perl aportada por el usuario File::Slurp(3)

NOMBRE

File::Slurp - Lectura/Escritura/Modificación simples y eficientes de archivos completos

SINOPSIS

use File::Slurp;
# leer un archivo completo en un escalar
my $text = read_file('/path/file');
# leer un archivo completo en un arreglo de líneas
my @lines = read_file('/path/file');
# escribir un archivo completo desde un escalar
write_file('/path/file', $text);
# escribir un archivo completo desde un arreglo de líneas
write_file('/path/file', @lines);
# Aquí hay una forma simple y rápida de cargar y guardar un archivo de configuración simple
# compuesto por líneas clave=valor.
my %conf = read_file('/path/file') =~ /^(\w+)=(.*)$/mg;
write_file('/path/file', {atomic => 1}, map "$_=$conf{$_}\n", keys %conf);
# insertar texto al comienzo de un archivo
prepend_file('/path/file', $text);
# edición en el lugar para reemplazar todas las 'foo' con 'bar' en el archivo
edit_file { s/foo/bar/g } '/path/file';
# edición en el lugar para eliminar todas las líneas con 'foo' del archivo
edit_file_lines sub { $_ = '' if /foo/ }, '/path/file';
# leer todos los nombres de archivo de un directorio completo (omitir . y ..)
my @files = read_dir('/path/to/dir');

DESCRIPCIÓN

Este módulo proporciona subrutinas que le permiten leer o escribir archivos completos con una sola llamada sencilla. Están diseñadas para ser fáciles de usar, tener formas flexibles de pasar u obtener el contenido del archivo y ser muy eficientes. También hay una subrutina para leer todos los archivos de un directorio.

ADVERTENCIA - RUINA PENDIENTE

Aunque técnicamente puede, NO use este módulo para trabajar con manejadores de archivos, tuberías, sockets, E/S estándar, o el "DATA" manejador. Estas son características implementadas hace mucho tiempo que realmente no deberían ser abusadas aquí.

Advertencia: esta actividad conducirá a una codificación/descodificación inexacta de los datos.

Todas las menciones posteriores de acciones sobre lo anterior han sido eliminadas de esta documentación y ese conjunto de características probablemente se descontinuará en el futuro.

En otras palabras, si no tiene un nombre de archivo para pasar, considere usar el estándar "do { local $/; <$fh> }", o Data::Section/Data::Section::Simple para trabajar con "__DATA__".

FUNCIONES

File::Slurp implementa las siguientes funciones.

append_file

use File::Slurp qw(append_file write_file);
my $res = append_file('/path/file', "Some text");
# igual que
my $res = write_file('/path/file', {append => 1}, "Some text");

La "append_file" función es simplemente un sinónimo para la función "write_file" in File::Slurp, pero asegura que la "append" opción esté establecida.

edit_file

use File::Slurp qw(edit_file);
# perl -0777 -pi -e 's/foo/bar/g' /path/file
edit_file { s/foo/bar/g } '/path/file';
edit_file sub { s/foo/bar/g }, '/path/file';
sub replace_foo { s/foo/bar/g }
edit_file \&replace_foo, '/path/file';

La "edit_file" función lee un archivo en $_, ejecuta un bloque de código que debería modificar $_, y luego escribe $_ de vuelta al archivo. La "edit_file" función lee el archivo completo y llama al bloque de código una sola vez. Es equivalente a las opciones de línea de comandos "-pi" de Perl, pero puede llamarla desde dentro de su programa y no tiene que crear un proceso hijo.

El primer argumento de "edit_file" es un bloque de código o una referencia a código. El bloque de código no va seguido de una coma (como con "grep" y "map"), pero una referencia a código va seguida de una coma.

El siguiente argumento es el nombre del archivo.

El(los) siguiente(s) argumento(s) es una referencia a hash o un hash aplanado, pares "clave => valor" . Las opciones se pasan a la función "write_file" in File::Slurp. Todas las opciones se describen allí. Solo se admiten las opciones "binmode" y "err_mode" . La llamada a "write_file" in File::Slurp tiene la opción "atomic" establecida, por lo que siempre tendrá un archivo consistente.

edit_file_lines

use File::Slurp qw(edit_file_lines);
# perl -pi -e '$_ = "" if /foo/' /path/file
edit_file_lines { $_ = '' if /foo/ } '/path/file';
edit_file_lines sub { $_ = '' if /foo/ }, '/path/file';
sub delete_foo { $_ = '' if /foo/ }
edit_file \&delete_foo, '/path/file';

La "edit_file_lines" función lee cada línea de un archivo en $_, y ejecuta un bloque de código que debería modificar $_. Luego escribirá $_ de vuelta al archivo. Es equivalente a las opciones de línea de comandos "-pi" de Perl, pero puede llamarla desde dentro de su programa y no tiene que crear un proceso hijo.

El primer argumento de "edit_file_lines" es un bloque de código o una referencia a código. El bloque de código no va seguido de una coma (como con "grep" y "map"), pero una referencia a código va seguida de una coma.

El siguiente argumento es el nombre del archivo.

El(los) siguiente(s) argumento(s) es una referencia a hash o un hash aplanado, pares "clave => valor" . Las opciones se pasan a la función "write_file" in File::Slurp. Todas las opciones se describen allí. Solo se admiten las opciones "binmode" y "err_mode" . La llamada a "write_file" in File::Slurp tiene la opción "atomic" establecida, por lo que siempre tendrá un archivo consistente.

ef

use File::Slurp qw(ef);
# perl -0777 -pi -e 's/foo/bar/g' /path/file
ef { s/foo/bar/g } '/path/file';
ef sub { s/foo/bar/g }, '/path/file';
sub replace_foo { s/foo/bar/g }
ef \&replace_foo, '/path/file';

La "ef" función es simplemente un sinónimo para la función "edit_file" in File::Slurp.

efl

use File::Slurp qw(efl);
# perl -pi -e '$_ = "" if /foo/' /path/file
efl { $_ = '' if /foo/ } '/path/file';
efl sub { $_ = '' if /foo/ }, '/path/file';
sub delete_foo { $_ = '' if /foo/ }
efl \&delete_foo, '/path/file';

La "efl" función es simplemente un sinónimo para la función "edit_file_lines" in File::Slurp.

overwrite_file

use File::Slurp qw(overwrite_file);
my $res = overwrite_file('/path/file', "Some text");

La "overwrite_file" función es simplemente un sinónimo para la función "write_file" in File::Slurp.

prepend_file

use File::Slurp qw(prepend_file);
prepend_file('/path/file', $header);
prepend_file('/path/file', \@lines);
prepend_file('/path/file', { binmode => ':raw'}, $bin_data);
# equivalente a:
use File::Slurp qw(read_file write_file);
my $content = read_file('/path/file');
my $new_content = "hahahaha";
write_file('/path/file', $new_content . $content);

La "prepend_file" función es lo opuesto de "append_file" in File::Slurp, ya que escribe nuevos contenidos al comienzo del archivo en lugar del final. Es una combinación de "read_file" in File::Slurp y "write_file" in File::Slurp. Funciona usando primero "read_file" para leer el archivo completo y luego llamando a "write_file" con los nuevos datos y los datos existentes del archivo.

El primer argumento de "prepend_file" es el nombre del archivo.

El(los) siguiente(s) argumento(s) es una referencia a hash o un hash aplanado, pares "clave => valor". Las opciones se pasan a la función "write_file" de File::Slurp. Todas las opciones se describen allí.

Solo se admiten las opciones "binmode" y "err_mode". La llamada a "write_file" tiene la opción "atomic" establecida para que siempre tenga un archivo coherente.

read_dir

use File::Slurp qw(read_dir);
my @files = read_dir('/ruta/a/dir');
# todos los archivos, incluso los puntos
my @files = read_dir('/ruta/a/dir', keep_dot_dot => 1);
# mantener la ruta completa del archivo
my @paths = read_dir('/ruta/a/dir', prefix => 1);
# contexto escalar
my $files_ref = read_dir('/ruta/a/dir');

Esta función devuelve una lista de los nombres de archivo en el directorio proporcionado. En contexto de lista, se devuelve un array; en contexto escalar, se devuelve una referencia a un array.

El primer argumento es la ruta al directorio que se va a leer.

El siguiente argumento(s) es una referencia a un hash o un hash aplanado, pares "clave => valor". Las siguientes opciones están disponibles:

  • err_mode

    La opción "err_mode" tiene tres valores posibles: "quiet", "carp" o el valor predeterminado, "croak". En el modo "quiet", todos los errores serán silenciosos. En el modo "carp", todos los errores se emitirán como advertencias. Y, en el modo "croak", todos los errores se emitirán como excepciones. Eche un vistazo a Try::Tiny o Syntax::Keyword::Try para ver cómo capturar excepciones.

  • keep_dot_dot

    La opción "keep_dot_dot" es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción en verdadero (1) también devolverá los archivos "." y ".." que se eliminan de la lista de archivos por defecto.

  • prefix

    La opción "prefix" es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción en verdadero (1) agregará el directorio como prefijo al archivo. El directorio y el nombre del archivo se unen usando "File::Spec->catfile()" para garantizar que se utilice el separador de directorios adecuado para su sistema operativo. Ver File::Spec.

read_file

use File::Slurp qw(read_file);
my $text = read_file('/ruta/archivo');
my $bin = read_file('/ruta/archivo', { binmode => ':raw' });
my @lines = read_file('/ruta/archivo');
my $lines_ref = read_file('/ruta/archivo', array_ref => 1);
my $lines_ref = [ read_file('/ruta/archivo') ];
# o podemos leer en un buffer:
my $buffer;
read_file('/ruta/archivo', buf_ref => \$buffer);
# o podemos establecer el tamaño del bloque para la lectura
my $text_ref = read_file('/ruta/archivo', blk_size => 10_000_000, array_ref => 1);
# o podemos obtener una referencia escalar
my $text_ref = read_file('/ruta/archivo', scalar_ref => 1);

Esta función lee un archivo completo y devuelve su contenido al llamador. En contexto escalar, devuelve el archivo completo como un solo escalar. En contexto de lista, devolverá una lista de líneas (usando el valor actual de $/ como separador, incluyendo soporte para el modo párrafo cuando se establece en '').

El primer argumento es la ruta al archivo que se va a leer.

El siguiente argumento(s) es una referencia a un hash o un hash aplanado, pares "clave => valor". Las siguientes opciones están disponibles:

  • array_ref

    La opción "array_ref" es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción en verdadero (1) solo tendrá relevancia si la función "read_file" se llama en contexto escalar. Cuando es verdadero, la función "read_file" devolverá una referencia a un array con las líneas del archivo.

  • binmode

    La opción "binmode" es una opción de cadena, cuyo valor predeterminado es vacío (''). Si establece la opción "binmode", su valor se pasará a una llamada a "binmode" en el manejador abierto. Puede usar esto para establecer el archivo que se leerá en modo binario, utf8, etc. Consulte "perldoc -f binmode" para más información.

  • blk_size

    Puede usar esta opción para establecer el tamaño del bloque utilizado al leer desde un manejador ya abierto (como "\*STDIN"). El valor predeterminado es 1 MB.

  • buf_ref

    La opción "buf_ref" se puede usar junto con cualquiera de las otras opciones. Puede usar esta opción para pasar una referencia escalar y el contenido del archivo leído se almacenará en el escalar. Esto ahorra una copia adicional del archivo leído y puede reducir el uso de RAM en comparación con la devolución del archivo. Suele ser la forma más rápida de leer un archivo en un escalar.

  • chomp

    La opción "chomp" es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción en verdadero (1) hará que a cada línea se le elimine el final de línea de su contenido. Esta opción funciona en contexto de lista o en contexto escalar con la opción "array_ref".

  • err_mode

    La opción "err_mode" tiene tres valores posibles: "quiet", "carp" o el valor predeterminado, "croak". En el modo "quiet", todos los errores serán silenciosos. En el modo "carp", todos los errores se emitirán como advertencias. Y, en el modo "croak", todos los errores se emitirán como excepciones. Eche un vistazo a Try::Tiny o Syntax::Keyword::Try para ver cómo capturar excepciones.

  • scalar_ref

    La opción "scalar_ref" es una opción booleana, cuyo valor predeterminado es falso (0). Solo tiene significado en contexto escalar. El valor devuelto será una referencia escalar a una cadena que contiene el contenido del archivo leído. Esto suele ser más rápido que devolver el escalar plano. También ahorrará memoria, ya que no hará una copia del archivo para devolverlo.

rf

use File::Slurp qw(rf);
my $text = rf('/ruta/archivo');

La función "rf" es simplemente un sinónimo de la función "read_file" de File::Slurp.

slurp

use File::Slurp qw(slurp);
my $text = slurp('/ruta/archivo');

La función "slurp" es simplemente un sinónimo de la función "read_file" de File::Slurp.

wf

use File::Slurp qw(wf);
my $res = wf('/ruta/archivo', "Algún texto");

La función "wf" es simplemente un sinónimo de la función "write_file" de File::Slurp.

write_file

use File::Slurp qw(write_file);
write_file('/ruta/archivo', @data);
write_file('/ruta/archivo', {append => 1}, @data);
write_file('/ruta/archivo', {binmode => ':raw'}, $buffer);
write_file('/ruta/archivo', \$buffer);
write_file('/ruta/archivo', $buffer);
write_file('/ruta/archivo', \@lines);
write_file('/ruta/archivo', @lines);
# binmode
write_file('/ruta/archivo', {binmode => ':raw'}, @data);
write_file('/ruta/archivo', {binmode => ':utf8'}, $utf_text);
# bufferizado
write_file('/ruta/archivo', {buf_ref => \$buffer});
write_file('/ruta/archivo', \$buffer);
write_file('/ruta/archivo', $buffer);
# anexar
write_file('/ruta/archivo', {append => 1}, @data);
# sin sobrescritura
write_file('/ruta/archivo', {no_clobber => 1}, @data);

Esta función escribe un archivo completo en una sola llamada. Por defecto, "write_file" devuelve 1 si escribe el archivo con éxito o "undef" si encontró un error. Puede cambiar cómo se manejan los errores con la opción "err_mode".

El primer argumento para "write_file" es el nombre del archivo.

El siguiente argumento(s) es una referencia a un hash o un hash aplanado, pares "clave => valor". Las siguientes opciones están disponibles:

  • append

    La opción "append" es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción en verdadero (1) hará que los datos se escriban al final del archivo actual. Internamente, esto establece el indicador de modo "sysopen" "O_APPEND".

    La función "append_file" de File::Slurp establece esta opción por defecto.

  • atomic

    La opción "atomic" es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción en verdadero (1) hará que el archivo se escriba de forma atómica. Se crea un nombre de archivo temporal usando "tempfile" de File::Temp. Después de cerrar el archivo, se renombra al nombre de archivo original (y "rename" es una operación atómica en la mayoría de los sistemas operativos). Si el programa que usa esto se bloqueara en medio de esta operación, el archivo temporal podría quedar atrás.

  • binmode

    La opción "binmode" es una opción de cadena, cuyo valor predeterminado es vacío (''). Si establece la opción "binmode", su valor se pasará a una llamada a "binmode" en el manejador abierto. Puede usar esto para establecer el archivo que se leerá en modo binario, utf8, etc. Consulte "perldoc -f binmode" para más información.

  • buf_ref

    La "buf_ref" opción se usa para pasar una referencia escalar que contiene los datos a escribir. Si se establece, cualquier argumento de datos (incluido el atajo de referencia escalar) en @_ será ignorado.

  • err_mode

    La "err_mode" opción tiene tres valores posibles: "quiet", "carp", o el valor predeterminado, "croak". En el modo "quiet" , todos los errores serán silenciosos. En el modo "carp" , todos los errores se emitirán como advertencias. Y, en el modo "croak" , todos los errores se emitirán como excepciones. Echa un vistazo a Try::Tiny o Syntax::Keyword::Try para ver cómo capturar excepciones.

  • no_clobber

    La "no_clobber" opción es una opción booleana, cuyo valor predeterminado es falso (0). Establecer esta opción como verdadera (1) asegurará que un archivo existente no sea sobrescrito.

  • perms

    La "perms" opción establece los permisos de los archivos recién creados. Este valor es modificado por el "umask" de tu proceso y tiene como valor predeterminado 0666 (igual que "sysopen" ).NOTA: esta opción es nueva a partir de la versión 9999.14 de File::Slurp.

    EXPORTACIÓN

Estas se exportan por defecto o con

use File::Slurp qw(:std); # read_file write_file overwrite_file append_file read_dir

Estas se exportan con

use File::Slurp qw(:edit); # edit_file edit_file_lines

Puedes obtener todas las subrutinas del módulo exportadas con

use File::Slurp qw(:all);

VER   TAMBIÉN

File::Slurper - Proporciona un conjunto sencillo de funciones para las tareas más comunes de leer/escribir archivos de texto y binarios.

  • Path::Tiny - Manejo de archivos ligero y completo, incluyendo métodos simples para leer, escribir y editar archivos de texto y binarios.
  • Mojo::File - Similar a Path::Tiny para el conjunto de herramientas Mojo, siempre trabaja en bytes.
