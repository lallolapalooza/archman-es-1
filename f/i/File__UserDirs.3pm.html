File::UserDirs(3) Documentación de Perl contribuida por el usuario File::UserDirs(3)

NOMBRE

File::UserDirs - Encuentra directorios adicionales de medios y documentos

VERSIÓN

versión 0.09

SINOPSIS

use File::UserDirs qw(:all);
print xdg_desktop_dir; # por ejemplo, /home/usuario/Escritorio

DESCRIPCIÓN

Este módulo se puede utilizar para encontrar directorios según lo especificado informalmente por el software xdg-user-dirs de Freedesktop.org. Esto proporciona un mecanismo para localizar directorios adicionales para archivos multimedia y de documentos.

FUNCIONES

Se pueden exportar bajo petición. También se define el grupo ":all" que exporta todos los métodos.

xdg_desktop_dir

my $dir = xdg_desktop_dir;

Devuelve el directorio del escritorio. A menos que el usuario lo cambie, este es el directorio Escritorio en el directorio de inicio.

xdg_documents_dir

my $dir = xdg_documents_dir;

Devuelve el directorio de documentos. A menos que el usuario lo cambie, este es el directorio de inicio.

xdg_download_dir

my $dir = xdg_download_dir;

Devuelve el directorio de descargas. A menos que el usuario lo cambie, este es el directorio de inicio.

xdg_music_dir

my $dir = xdg_music_dir;

Devuelve el directorio de música. A menos que el usuario lo cambie, este es el directorio de inicio.

xdg_pictures_dir

my $dir = xdg_pictures_dir;

Devuelve el directorio de imágenes. A menos que el usuario lo cambie, este es el directorio de inicio.

xdg_publicshare_dir

my $dir = xdg_publicshare_dir;

Devuelve el directorio de uso compartido público. A menos que el usuario lo cambie, este es el directorio de inicio.

xdg_templates_dir

my $dir = xdg_templates_dir;

Devuelve el directorio de plantillas. A menos que el usuario lo cambie, este es el directorio de inicio.

xdg_videos_dir

my $dir = xdg_videos_dir;

Devuelve el directorio de vídeos. A menos que el usuario lo cambie, este es el directorio de inicio.

DIAGNÓSTICOS

""xdg-user-dir" falló al iniciarse: %s"
El ejecutable "xdg-user-dir" no se pudo ejecutar, muy probablemente porque no estaba instalado. Consulte "DEPENDENCIAS".

CONFIGURACIÓN Y ENTORNO

La ubicación de los directorios puede ser especificada por el usuario en el archivo $XDG_CONFIG_HOME/user-dirs.dirs. Es un archivo de shell que establece una serie de variables de entorno. Para encontrar la ruta exacta desde Perl, ejecute:

use File::BaseDir qw(config_home);
print config_home('user-dirs.dirs');

Ejemplo de user-dirs.dirs personalizado

XDG_DESKTOP_DIR="$HOME/Workspace"
XDG_DOCUMENTS_DIR="$HOME/Files"
XDG_DOWNLOAD_DIR="$HOME/Files/Downloads"
XDG_MUSIC_DIR="$HOME/Files/Audio"
XDG_PICTURES_DIR="$HOME/Files/Images"
XDG_PUBLICSHARE_DIR="$HOME/public_html"
XDG_TEMPLATES_DIR="$HOME/Files/Document templates"
XDG_VIDEOS_DIR="$HOME/Files/Video"

DEPENDENCIAS

Este módulo requiere el ejecutable xdg-user-dir del paquete "xdg-user-dirs". El código fuente está disponible en http://cgit.freedesktop.org/xdg/xdg-user-dirs/.
