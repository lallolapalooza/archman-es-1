File::MimeInfo::Magic(3) Documentación de Perl contribuida por el usuario File::MimeInfo::Magic(3)

NOMBRE

File::MimeInfo::Magic - Determinar el tipo de archivo con magia

SINOPSIS

use File::MimeInfo::Magic;
my $mime_type = mimetype($file);

DESCRIPCIÓN

Este módulo hereda de File::MimeInfo, es transparente para sus funciones pero añade soporte para el archivo mágico de freedesktop.

Los datos mágicos se hashean la primera vez que se necesitan. Si desea forzar el hasheo antes, utilice la función rehash().

EXPORTAR

El método "mimetype" se exporta por defecto. Los métodos "magic", "inodetype", "globs" y "describe" se pueden exportar bajo demanda.

MÉTODOS

Consulte también File::MimeInfo para los métodos que se heredan.

mimetype($file)
Devuelve una cadena de tipo MIME para $file, devuelve undef en caso de error.

Este método agrupa inodetype(), globs() y magic().

Las reglas mágicas con una prioridad de 80 o superior se comprueban antes de llamar a globs(), todas las demás reglas mágicas después.

Si esto no funciona, se lee el archivo y el tipo MIME por defecto es 'text/plain' o 'application/octet-stream' cuando los diez primeros caracteres del archivo coinciden con caracteres de control ASCII (excluyendo espacios en blanco). Si el archivo no existe o no es legible, se devuelve "undef".

Si $file es una referencia a un objeto, solo se utilizan "magic" y el método predeterminado. Consulte más abajo para obtener detalles.

magic($file)
Devuelve una cadena de tipo MIME para $file basándose en las reglas mágicas, devuelve undef en caso de error.

$file puede ser una referencia a un objeto, en cuyo caso se supone que tiene métodos seek() y read(). Esto le permite, por ejemplo, determinar el tipo MIME de los datos en memoria utilizando IO::Scalar.

Tenga en cuenta que al utilizar un manejador de archivos o un objeto "IO::", debe establecer usted mismo el modo binario ":utf8" si es apropiado.

rehash()
Vuelve a hashear los archivos de datos. La información de glob y magia se pre-procesa cuando se llama a este método.

Si desea omitir el sistema XDG basedir, puede especificar sus directorios de bases de datos estableciendo @File::MimeInfo::DIRS. Pero normalmente es mejor cambiar las variables de entorno XDG basedir.

"default"
"describe"
"extensions"
"globs"
"inodetype"
Estas rutinas se importan de File::MimeInfo.

VER TAMBIÉN

File::MimeInfo

LIMITACIONES

Solo se admiten tamaños de palabra de 1, 2 o 4. Cualquier otro tamaño de palabra se ignora y provocará una advertencia.
