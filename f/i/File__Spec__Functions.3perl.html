File::Spec::Functions(3perl) Guía del programador de Perl File::Spec::Functions(3perl)

NOMBRE

File::Spec::Functions - realizar operaciones portátiles en nombres de archivos

SINOPSIS

use File::Spec::Functions;
my $x = catfile('a', 'b');

DESCRIPCIÓN

Este módulo exporta funciones de conveniencia para todos los métodos de clase proporcionados por File::Spec.

Para una referencia de las funciones disponibles, por favor consulte File::Spec::Unix, que contiene el conjunto completo, y que es heredado por los módulos para otras plataformas. Para más información, por favor vea File::Spec::Mac, File::Spec::OS2, File::Spec::Win32, o File::Spec::VMS.

Exportaciones

Las siguientes funciones se exportan por defecto.

canonpath
catdir
catfile
curdir
rootdir
updir
no_upwards
file_name_is_absolute
path

Las siguientes funciones se exportan solo bajo petición.

devnull
tmpdir
splitpath
splitdir
catpath
abs2rel
rel2abs
case_tolerant

Todas las funciones pueden ser importadas usando la etiqueta ":ALL".
