NOMBRE

firemon - Programa de monitorización para procesos iniciados en un sandbox de Firejail.

SINOPSIS

firemon [OPCIONES] [PID]

DESCRIPCIÓN

Firemon monitoriza los programas iniciados en un sandbox de Firejail. Sin un PID especificado, se monitorizan todos los procesos iniciados por Firejail. Los descendientes de estos procesos también son monitorizados. En sistemas Grsecurity, solo el usuario root puede ejecutar este programa.

OPCIONES

--apparmor
Imprime el estado de confinamiento de AppArmor para cada sandbox.
--arp
Imprime la tabla ARP para cada sandbox.
--caps
Imprime la configuración de capacidades para cada sandbox.
--cpu
Imprime la afinidad de CPU para cada sandbox.
--debug
Imprime mensajes de depuración.
-?, --help
Imprime las opciones y sale.
--list
Lista todos los sandboxes.
--name=nombre
Imprime información solo sobre el sandbox con el nombre especificado.
--netstats
Monitoriza estadísticas de red para sandboxes que crean un nuevo espacio de nombres de red.
--route
Imprime la tabla de rutas para cada sandbox.
--seccomp
Imprime la configuración seccomp para cada sandbox.
--top
Monitoriza los sandboxes que consumen más CPU. Este comando es similar al comando top de UNIX, pero se aplica solo a los sandboxes.
--tree
Imprime un árbol de todos los procesos en sandbox.
--version
Imprime la versión del programa y sale.
--wrap
Habilita el ajuste de línea en terminales. Por defecto, las líneas se recortan.
--x11
Imprime el número de pantalla X11.

El formato para cada entrada de sandbox listada es el siguiente:

PID:USUARIO:Nombre del Sandbox:Comando

A continuación se enumeran los campos (columnas) disponibles en varios comandos de firemon en orden alfabético:

Comando
Comando utilizado para iniciar el sandbox.
CPU%
Uso de CPU, la parte del sandbox del tiempo de CPU transcurrido desde la última actualización de pantalla.
PID
ID de proceso único para la tarea que controla el sandbox.
Prcs
Número de procesos en ejecución en el sandbox, incluido el proceso controlador.
RES
Tamaño de Memoria Residente (KiB), memoria física no paginada del sandbox. Es una suma de los valores RES de todos los procesos en ejecución en el sandbox.
Nombre del Sandbox
El nombre del sandbox, si lo hay.
SHR
Tamaño de Memoria Compartida (KiB), refleja la memoria compartida con otros procesos. Es una suma de los valores SHR de todos los procesos en ejecución en el sandbox, incluido el proceso controlador.
Tiempo activo
Tiempo de ejecución del sandbox en formato horas:minutos:segundos.
USUARIO
El propietario del sandbox.
