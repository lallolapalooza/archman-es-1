NOMBRE

fi_nic - Atributos de la tarjeta de red (NIC)

ATRIBUTOS DE LA TARJETA DE RED (NIC)

La estructura fid_nic define atributos para un struct fi_info que está directamente asociado con el hardware de red subyacente y puede ser devuelto directamente al llamar a fi_getinfo(3). El formato de fid_nic y las subestructuras relacionadas se definen a continuación.

Tenga en cuenta que no todos los campos de todas las estructuras pueden estar disponibles. Los campos no disponibles o que no son aplicables al dispositivo indicado se establecerán en NULL o 0.

struct fid_nic {
    struct fid             fid;
    struct fi_device_attr *device_attr;
    struct fi_bus_attr    *bus_attr;
    struct fi_link_attr   *link_attr;
    void                  *prov_attr;
};
struct fi_device_attr {
    char *name;
    char *device_id;
    char *device_version;
    char *vendor_id;
    char *driver;
    char *firmware;
};
struct fi_pci_attr {
    uint16_t domain_id;
    uint8_t  bus_id;
    uint8_t  device_id;
    uint8_t  function_id;
};
struct fi_bus_attr {
    enum fi_bus_type       bus_type;
    union {
        struct fi_pci_attr pci;
    } attr;
};
struct fi_link_attr {
    char               *address;
    size_t             mtu;
    size_t             speed;
    enum fi_link_state state;
    char               *network_type;
};

Atributos del Dispositivo

Los atributos del dispositivo se utilizan para identificar la NIC virtual o de hardware específica asociada con una estructura fi_info.

name
El nombre del sistema operativo asociado con el dispositivo. Puede ser un nombre de interfaz de red lógico (por ejemplo, eth0 o eno1) o un nombre de archivo absoluto.
device_id
Este es un identificador específico del proveedor para el dispositivo o producto.
device_version
Indica la versión del dispositivo.
vendor_id
Indica el nombre del proveedor que distribuye la NIC.
driver
El nombre del controlador asociado con el dispositivo.
firmware
La versión del firmware del dispositivo.

Atributos del Bus

Los atributos del bus se utilizan para identificar la ubicación física de la NIC en el sistema.

bus_type
Indica el tipo de bus del sistema donde se encuentra la NIC. Los valores válidos son FI_BUS_PCI o FI_BUS_UNKNOWN.
attr.pci.domain_id
El dominio donde se encuentra el bus PCI. Válido solo si bus_type es FI_BUS_PCI.
attr.pci.bus_id
El identificador del bus PCI donde se encuentra el dispositivo. Válido solo si bus_type es FI_BUS_PCI.
attr.pci.device_id
El identificador en el bus PCI donde se encuentra el dispositivo. Válido solo si bus_type es FI_BUS_PCI.
attr.pci.function_id
La función en el dispositivo al que se hace referencia. Válido solo si bus_type es FI_BUS_PCI.

Atributos del Enlace

Los atributos del enlace describen detalles de bajo nivel sobre la conexión de red a la red (fabric).

address
La dirección principal a nivel de enlace asociada con la NIC, como una dirección MAC. Si hay varias direcciones disponibles, solo se informará una.
mtu
La unidad de transmisión máxima de los marcos o paquetes a nivel de enlace, en bytes.
speed
La velocidad de datos activa del enlace, en bits por segundo.
state
El estado actual del puerto físico. Los valores posibles son FI_LINK_UNKNOWN, FI_LINK_DOWN y FI_LINK_UP, para indicar si el estado del puerto es desconocido o no aplicable (desconocido), inactivo (caído) o activo (arriba).
network_type
Especifica el tipo de interfaz de red actualmente activa, como Ethernet o InfiniBand.

Atributos del Proveedor

Los atributos del proveedor hacen referencia a detalles específicos del proveedor del dispositivo. Estos atributos son específicos tanto del proveedor como del dispositivo. Los atributos pueden ser interpretados por fi_tostr(3). Las aplicaciones también pueden usar otros campos de atributos, como el campo prov_name de fi_fabric_attr relacionado, para determinar una estructura apropiada para convertir los atributos. El formato y la definición de este campo están fuera del alcance del marco principal de libfabric, pero pueden estar disponibles como parte de un archivo de encabezado específico del proveedor incluido con el paquete libfabric.

NOTAS

La estructura fid_nic se devuelve como parte de una llamada a fi_getinfo(3). Se libera automáticamente como parte de la llamada a fi_freeinfo(3)
