NOMBRE

fi_strerror - mostrar cadenas de error de libfabric

SINOPSIS

fi_strerror CODIGO_ERROR_FI

DESCRIPCIÓN

Muestra la cadena de error para el CODIGO_ERROR_FI numérico dado. CODIGO_ERROR_FI puede ser una constante hexadecimal, octal o decimal. Aunque la función de biblioteca fi_strerror(3) solo acepta valores de error positivos, para mayor comodidad, esta utilidad acepta valores de error tanto positivos como negativos.

Esta es principalmente una herramienta de conveniencia para desarrolladores.

VER TAMBIÉN

fabric(7) fi_errno(3)

AUTORES

OpenFabrics.
