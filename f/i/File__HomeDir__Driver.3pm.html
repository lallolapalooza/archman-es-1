NOMBRE

File::HomeDir::Driver - Clase base para todos los controladores de File::HomeDir

DESCRIPCIÓN

Este módulo es la clase base para todos los controladores de File::HomeDir, y debe ser heredado para identificar una clase como un controlador.

Se proporciona principalmente como una conveniencia para este propósito específico de identificación, ya que File::HomeDir soporta la especificación de controladores personalizados y se utiliza una comprobación "->isa" durante la carga del controlador.
