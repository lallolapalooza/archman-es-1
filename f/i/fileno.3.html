fileno(3) Manual de funciones de biblioteca fileno(3)

NOMBRE

fileno - obtener el descriptor de archivo de un stream stdio

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int fileno(FILE *stream);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

fileno():

    _POSIX_C_SOURCE

DESCRIPCIÓN

La función fileno() examina el argumento stream y devuelve el descriptor de archivo entero utilizado para implementar este stream. El descriptor de archivo todavía pertenece a stream y se cerrará cuando se llame a fclose(3). Duplique el descriptor de archivo con dup(2) antes de pasarlo a código que pueda cerrarlo.

Para el homólogo no bloqueante, consulte unlocked_stdio(3).

VALOR DE RETORNO

En caso de éxito, fileno() devuelve el descriptor de archivo asociado con stream. En caso de fallo, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
stream no está asociado con un archivo.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).
