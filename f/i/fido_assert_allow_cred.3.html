FIDO_ASSERT_ALLOW_CRED(3) Manual de funciones de la biblioteca FIDO_ASSERT_ALLOW_CRED(3)

NOMBRE

fido_assert_allow_cred, fido_assert_empty_allow_list — gestionar listas de permisos en una aserción FIDO2

SINOPSIS

#include <fido.h>

int
fido_assert_allow_cred(fido_assert_t *assert, const unsigned char *ptr, size_t len);

int
fido_assert_empty_allow_list(fido_assert_t *assert);

DESCRIPCIÓN

La función fido_assert_allow_cred() añade ptr a la lista de credenciales permitidas en assert, donde ptr apunta a un ID de credencial de len bytes. Se realiza una copia de ptr, y no se conservan referencias al puntero pasado. Si fido_assert_allow_cred() falla, la lista existente de credenciales permitidas se preserva.

Para el formato de un ID de credencial FIDO2, consulte el estándar Web Authentication (webauthn).

La función fido_assert_empty_allow_list() vacía la lista de credenciales permitidas en assert.

VALORES DE RETORNO

Los códigos de error devueltos por fido_assert_allow_cred() y fido_assert_empty_allow_list() se definen en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

VER TAMBIÉN

fido_assert_new(3), fido_assert_set_authdata(3), fido_dev_get_assert(3)
