NOMBRE

login.users - Sintaxis del archivo de inicio de sesión para Firejail

DESCRIPCIÓN

El archivo /etc/firejail/login.users describe argumentos adicionales pasados al ejecutable firejail al iniciar sesión un usuario en un shell restringido por Firejail. Cada entrada de usuario en el archivo consiste en un nombre de usuario seguido de los argumentos pasados a firejail. El formato es el siguiente:

nombre_usuario: argumentos

Ejemplo:

netblue: --net=none --protocol=unix

Se aceptan patrones comodín en el campo del nombre de usuario:

user*: --private

SHELL RESTRINGIDO

Para configurar un shell restringido, reemplace /bin/bash por /usr/bin/firejail en el archivo /etc/passwd para cada usuario que necesite ser restringido. Alternativamente, puede especificar /usr/bin/firejail usando los comandos `adduser` o `usermod`:

adduser --shell /usr/bin/firejail nombre_usuario
usermod --shell /usr/bin/firejail nombre_usuario
