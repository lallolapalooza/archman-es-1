NOMBRE

fi_av_set - Operaciones de conjunto de vectores de direcciones

fi_av_set / fi_close
Abrir o cerrar un conjunto de vectores de direcciones (AV)
fi_av_set_union
Realizar una operación de unión de conjuntos en dos AV sets
fi_av_set_intersect
Realizar una operación de intersección de conjuntos en dos AV sets
fi_av_set_diff
Realizar una operación de diferencia de conjuntos en dos AV sets
fi_av_set_insert
Añadir una dirección a un AV set
fi_av_set_remove
Eliminar una dirección de un AV set
fi_av_set_addr
Obtener una dirección colectiva para las direcciones actuales en un AV set

SINOPSIS

#include <rdma/fi_collective.h>
int fi_av_set(struct fid_av *av, struct fi_av_set_attr *attr,
      struct fid_av_set **set, void * context);
int fi_av_set_union(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_intersect(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_diff(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_insert(struct fid_av_set *set, fi_addr_t addr);
int fi_av_set_remove(struct fid_av_set *set, fi_addr_t addr);
int fi_av_set_addr(struct fid_av_set *set, fi_addr_t *coll_addr);
int fi_close(struct fid *av_set);

ARGUMENTOS

av
Vector de direcciones
set
Conjunto de vectores de direcciones
dst
Conjunto de vectores de direcciones actualizado por la operación de conjunto
src
Conjunto de vectores de direcciones que proporciona entrada a una operación de conjunto
attr
Atributos del conjunto de vectores de direcciones
context
Contexto especificado por el usuario asociado al conjunto de vectores de direcciones
flags
Banderas adicionales a aplicar a la operación.
addr
Dirección de destino para insertar o eliminar del AV set.
coll_addr
Dirección que identifica el grupo colectivo.

DESCRIPCIÓN

Un conjunto de vectores de direcciones (AV set) representa un subconjunto ordenado de direcciones de un vector de direcciones. Los AV sets se utilizan para identificar a los participantes en una operación colectiva. Los puntos finales utilizan la operación fi_join_collective() para asociarse con un AV set. La operación de unión colectiva proporciona un fi_addr que se utiliza al comunicarse con un grupo colectivo.

La creación y manipulación de un AV set es una operación local. No se intercambia tráfico de red entre pares. Como resultado, cada par es responsable de crear AV sets coincidentes como parte de su definición de membresía colectiva. Consulte fi_collective(3) para una discusión sobre los modelos de membresía.

fi_av_set

La llamada a fi_av_set crea un nuevo AV set. Las propiedades iniciales del AV set se especifican a través del parámetro struct fi_av_set_attr. Esta estructura se define a continuación y permite incluir un subconjunto de direcciones en el AV set como parte de la creación del AV set. Las direcciones se pueden añadir o eliminar de un AV set utilizando las interfaces de AV set definidas a continuación.

fi_av_set_attr

struct fi_av_set_attr {
    size_t count;
    fi_addr_t start_addr;
    fi_addr_t end_addr;
    uint64_t stride;
    size_t comm_key_size;
    uint8_t *comm_key;
    uint64_t flags;
};
count
Indica el número esperado de miembros que formarán parte del AV set. El proveedor lo utiliza para optimizar las asignaciones de recursos. Si count es 0, el proveedor seleccionará un tamaño basado en los datos de configuración del sistema disponibles o en las limitaciones subyacentes.
start_addr / end_addr
Las direcciones de inicio y fin, inclusivas, a incluir como parte del AV set. El uso de las direcciones de inicio y fin requiere que el AV asociado se haya creado como tipo FI_AV_TABLE. Las direcciones válidas en el AV que se encuentren dentro del rango especificado y que cumplan otros requisitos (como el stride) se añadirán como miembros iniciales al AV set. Las start_addr y end_addr deben establecerse en FI_ADDR_NOTAVAIL si se crea un AV set vacío, se proporciona una clave de comunicación o el AV es de tipo FI_AV_MAP.

El número de direcciones entre start_addr y end_addr debe ser menor o igual al valor de count especificado.

stride
El número de entradas entre direcciones sucesivas incluidas en el AV set. El AV set incluirá todas las direcciones de start_addr + stride x i, para valores enteros positivos crecientes de i, hasta end_addr. Un stride de 1 indica que todas las direcciones entre start_addr y end_addr deben añadirse al AV set. Stride debe establecerse en 0 a menos que los campos start_addr y end_addr sean válidos.
comm_key_size
La longitud de la clave de comunicación en bytes. Este campo debe ser 0 si no hay una clave de comunicación disponible.
comm_key
Si es compatible con la red, esta representa una clave asociada al AV set. La clave de comunicación es utilizada por las aplicaciones que gestionan directamente la membresía colectiva a través de un agente de gestión de red o un administrador de recursos. La clave se utiliza para transmitir los resultados de la configuración de membresía al proveedor subyacente. El uso y formato de una clave de comunicación es específico del proveedor de red.
flags
Las banderas pueden usarse para configurar el AV set, incluyendo la restricción de qué operaciones colectivas debe soportar el AV set. Consulte la sección de banderas para obtener una lista de las banderas que se pueden especificar al crear el AV set.

fi_av_set_union

La llamada a AV set union añade todas las direcciones del AV set de origen que no están en el AV set de destino al AV set de destino. Donde el orden sea importante, las direcciones recién insertadas se colocan al final del AV set.

fi_av_set_intersect

La llamada a AV set intersect elimina todas las direcciones del AV set de destino que no son miembros del AV set de origen. El orden de las direcciones en el AV set de destino no cambia.

fi_av_set_diff

La llamada a diferencia de AV set elimina todas las direcciones del AV set de destino que también son miembros del AV set de origen. El orden de las direcciones en el AV set de destino no cambia.

fi_av_set_insert

La llamada a AV set insert añade la dirección especificada al final del AV set.

fi_av_set_remove

La llamada a AV set remove elimina la dirección especificada del AV set dado. El orden de las direcciones restantes en el AV set no cambia.

fi_av_set_addr

Devuelve una dirección que puede utilizarse para comunicarse con todos los miembros actuales de un AV set. Esta es solo una operación local que no implica comunicación de red. La dirección devuelta puede utilizarse como entrada en fi_join_collective. fi_close

Cierra un conjunto AV y libera todos los recursos asociados a él. Cualquier operación activa en el momento en que se cierra un conjunto AV será abortada, con el resultado de la colectividad indefinido.

BANDERAS

Las siguientes banderas pueden especificarse como parte de la creación de un conjunto AV.

FI_UNIVERSE
Cuando se establece, el conjunto AV se creará conteniendo todas las direcciones almacenadas en el AV correspondiente.
FI_BARRIER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de barrera.
FI_BROADCAST_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de difusión (broadcast).
FI_ALLTOALL_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de todos a todos.
FI_ALLREDUCE_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de reducción global.
FI_ALLGATHER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de recolección global.
FI_REDUCE_SCATTER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de reducción y dispersión.
FI_REDUCE_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de reducción.
FI_SCATTER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de dispersión.
FI_GATHER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de recolección.

NOTAS

Los desarrolladores familiarizados con MPI encontrarán que los conjuntos AV son similares a los grupos de MPI, y pueden actuar como un mapeo directo en algunas, pero no en todas, situaciones.

Por defecto, se creará un conjunto AV para soportar todas las operaciones colectivas soportadas por el proveedor subyacente (ver fi_query_collective). Los usuarios pueden reducir los requisitos de recursos especificando solo aquellas operaciones colectivas necesarias para el conjunto AV mediante el uso de banderas de creación: FI_BARRIER_SET, FI_BROADCAST_SET, etc. Si no se especifican tales banderas, el conjunto AV se configurará para soportar cualquiera que sea soportado. Es un error que un usuario solicite una operación colectiva no soportada.

VALORES DE RETORNO

Devuelve 0 en caso de éxito. En caso de error, se devuelve un valor negativo correspondiente a el errno de fabric. Los valores de errno de fabric están definidos en rdma/fi_errno.h.
