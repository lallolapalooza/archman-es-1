DESCRIPCIÓ

N

File::pushd realiza un "chdir" temporal que se revierte fácil y automáticamente, similar a "pushd" en algunos shells de comandos de Unix. Funciona creando un objeto que almacena en caché el directorio de trabajo original. Cuando el objeto es destruido, el destructor llama a "chdir" para volver al directorio de trabajo original. Al almacenar el objeto en una variable léxica con un ámbito limitado, esto ocurre automáticamente al final del

ámbito.

Esto es muy útil al trabajar con directorios temporales para tareas como pruebas; se proporciona una función para facilitar la obtención de un directorio temporal de File::

Temp.

Por conveniencia, el objeto se convierte en la forma canónica de la ruta absoluta del directorio al que se ha

entrado.

Advertencia: si creas múltiples objetos "pushd" en el mismo ámbito léxico, no se garantiza el orden de s

u destrucción y podrías no terminar
en el directorio que esperas.

Usar File::pushd importa automáticamente las funciones "pushd" y "tempd"

push

d 
{
    my $dir = pushd( $target_directory );
}

Almacena en caché el directorio de trabajo actual, llama a "chdir" para cambiar al directorio de destino, y devuelve un objeto File::pushd. Cuando el objeto es destruido, el directorio de trabajo vuelve al directorio

original.

El directorio de destino proporcionado puede ser una ruta relativa o absoluta. Si se llama sin argumentos, usa el directorio actual como destino y vuelve al directorio actual cuando el objeto es

destruido.

Si el directorio de destino no existe o si el cambio de directorio falla por alguna razón, "pushd" morirá con un mensaje de

error.

Se puede pasar un hashref como segundo argumento opcional. La única opción soportada es "untaint_pattern", que se usa para descontaminar las rutas de archivo involucradas. Por defecto es {qr{^("" in -+@\w.+)$}}, que es bastante restrictivo (p. ej. no permite espacios en la ruta). Cámbi

alo para adaptarlo a tus circunstancias y necesidades de seguridad si se ejecuta en modo taint. *Not
a*: debes incluir los paréntesis en el patrón para capturar la porción descontaminada de la ruta.

temp

d 
{
    my $dir = tempd();
}

Esta función es como "pushd" pero crea y llama automáticamente a "chdir" a un directorio temporal creado por File::Temp. A diferencia de la limpieza normal de File::Temp que ocurre al final del programa, este directorio temporal se elimina cuando el objeto es destruido. (Pero ver también "preserve".) Se emitirá una advertencia si el directorio no se puede

eliminar.

Al igual que con "pushd", "tempd" morirá si "chdir" f

alla.

Se le puede dar un único hash de opciones que se pasará internamente a "pus

hd
".

preserv

e 
{
    my $dir = tempd();
    $dir->preserve;      # marcar para preservar al final del ámbito
    $dir->preserve(0);   # marcar para eliminar al final del ámbito
}

Controla si un directorio temporal se limpiará cuando el objeto sea destruido. Sin argumentos, "preserve" establece el directorio para ser preservado. Con un argumento, el directorio se preservará si el argumento es verdadero, o se marcará para limpieza si el argumento es falso. Solo los objetos "tempd" pueden marcarse para limpieza. (Los directorios de destino de "pushd" siempre se preservan.) "preserve" devuelve verdadero si el

directorio se p
reservará, y falso
en caso contrario.
