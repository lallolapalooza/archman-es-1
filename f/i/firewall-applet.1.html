NOMBRE

firewall-applet - applet de firewalld

SINOPSIS

firewall-applet [OPCIONES...]

DESCRIPCIÓN

firewall-applet es un applet de bandeja para firewalld.

OPCIONES

firewall-applet no admite opciones especiales.

Se admiten las siguientes opciones:

-h, --help

Imprime un breve texto de ayuda y sale.

QSETTINGS

firewall-applet tiene configuraciones adicionales para adaptar la apariencia. Se utiliza QSettings y se guardan en ~/.config/firewall/applet.conf. El archivo se recarga automáticamente si se ha modificado y la nueva configuración será efectiva inmediatamente.

También existe el archivo de configuración global /etc/firewall/applet.conf, que contiene los valores predeterminados. La configuración en este archivo será sobrescrita por la configuración en el archivo de configuración del usuario.

Aquí hay un ejemplo de archivo applet.conf:

[General]
notifications=true
show-inactive=true

Se admiten los siguientes ajustes:

notifications

El applet muestra notificaciones si están habilitadas. Esta configuración también se puede habilitar en el applet con la casilla de verificación "Habilitar Notificaciones" en el menú del botón derecho.

Esta configuración está desactivada de forma predeterminada (false).

Si se muestran notificaciones para estas acciones si están habilitadas:

•Conexión establecida con firewalld
•Conexión perdida con firewalld
•Firewall recargado
•Zona predeterminada cambiada
•Modo pánico activado o desactivado
•Activación, desactivación o cambio de zonas vinculadas a interfaces
•Activación, desactivación o cambio de zonas vinculadas a direcciones de origen

show-inactive

Mostrar el applet incluso si firewalld no se está ejecutando. Si firewalld se ha detenido o no se está ejecutando, el applet se ocultará y no será visible en la bandeja del applet. Habilite esta configuración para ver el applet todo el tiempo, por ejemplo, para asegurarse de que el firewall esté activo.

Esta configuración está desactivada de forma predeterminada (false).

shields-up

El nombre de la zona "shields-up" que se utilizará si "shields-up" está habilitado.

Esta configuración tiene como valor predeterminado 'block'.

shields-down

El nombre de la zona "shields-down" que se utilizará si "shields-up" se ha desactivado de nuevo.

Esta configuración tiene como valor predeterminado 'public'.

blink

Si está habilitado, el icono del applet parpadea en los siguientes casos:
•Conexión perdida con firewalld
•Modo pánico activado o desactivado

Esta configuración está desactivada de forma predeterminada (false).

blink-count

El número de parpadeos si blink está habilitado.

Esta configuración tiene como valor predeterminado 5.
