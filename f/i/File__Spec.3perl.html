File::Spec(3perl) Guía de Programadores de Perl File::Spec(3perl)

NOMBRE

File::Spec - realizar operaciones portables sobre nombres de archivo

SINOPSIS

use File::Spec;
my $x = File::Spec->catfile('a', 'b', 'c');

que devuelve 'a/b/c' en Unix. O:

use File::Spec::Functions;
my $x = catfile('a', 'b', 'c');

DESCRIPCIÓN

Este módulo está diseñado para soportar operaciones comúnmente realizadas sobre especificaciones de archivos (generalmente llamadas "nombres de archivo", pero no deben confundirse con el contenido de un archivo, o los manejadores de archivo de Perl), como concatenar varios directorios y nombres de archivo en una ruta única, o determinar si una ruta está enraizada. Se basa en código tomado directamente de MakeMaker 5.17, código escrito por Andreas König, Andy Dougherty, Charles Bailey, Ilya Zakharevich, Paul Schinder y otros.

Dado que estas funciones son diferentes para la mayoría de los sistemas operativos, cada conjunto de rutinas específicas del SO está disponible en un módulo separado, que incluye:

File::Spec::Unix
File::Spec::Mac
File::Spec::OS2
File::Spec::Win32
File::Spec::VMS

El módulo apropiado para el SO actual es cargado automáticamente por File::Spec. Dado que algunos módulos (como VMS) hacen uso de instalaciones disponibles solo bajo ese SO, puede que no sea posible cargar todos los módulos bajo todos los sistemas operativos.

Dado que File::Spec está orientado a objetos, las subrutinas no deben llamarse directamente, como en:

File::Spec::catfile('a','b');

sino como métodos de clase:

File::Spec->catfile('a','b');

Para usos simples, File::Spec::Functions proporciona formas funcionales convenientes de estos métodos.

MÉTODOS

canonpath
No realiza una comprobación física en el sistema de archivos, sino una limpieza lógica de una ruta. 
$cpath = File::Spec->canonpath( $path ) ;

Tenga en cuenta que esto *no* colapsa las secciones x/../y en y. Esto es intencional. Si /foo en su sistema es un enlace simbólico a /bar/baz, entonces /foo/../quux es en realidad /bar/quux, no /quux como daría una eliminación ingenua de ../. Si desea realizar este tipo de procesamiento, probablemente desee la función realpath() de "Cwd" para recorrer realmente el sistema de archivos limpiando rutas como esta.

catdir
Concatena dos o más nombres de directorio para formar una ruta completa que termina con un directorio. Pero elimina la barra diagonal final de la cadena resultante, porque no queda bien, no es necesaria y confunde a OS/2. Por supuesto, si este es el directorio raíz, ¡no corte la barra diagonal final! :-) 
$path = File::Spec->catdir( @directories );
catfile
Concatena uno o más nombres de directorio y un nombre de archivo para formar una ruta completa que termina con un nombre de archivo 
$path = File::Spec->catfile( @directories, $filename );
curdir
Devuelve una representación en cadena del directorio actual. 
$curdir = File::Spec->curdir();
devnull
Devuelve una representación en cadena del dispositivo nulo. 
$devnull = File::Spec->devnull();
rootdir
Devuelve una representación en cadena del directorio raíz. 
$rootdir = File::Spec->rootdir();
tmpdir
Devuelve una representación en cadena del primer directorio escribible de una lista de posibles directorios temporales. Devuelve el directorio actual si no se encuentran directorios temporales escribibles. La lista de directorios comprobados depende de la plataforma; por ejemplo, File::Spec::Unix comprueba $ENV{TMPDIR} (a menos que el nivel de seguridad esté activado) y /tmp. 
$tmpdir = File::Spec->tmpdir();
updir
Devuelve una representación en cadena del directorio padre. 
$updir = File::Spec->updir();
no_upwards
Dada una lista de archivos en un directorio (como de readdir()), elimina '.' y '..'.

NOTA DE SEGURIDAD: Esto NO filtra rutas que contengan '..', como '../../../../etc/passwd', solo coincidencias literales con '.' y '..'.

@paths = File::Spec->no_upwards( readdir $dirhandle );
case_tolerant
Devuelve un valor verdadero o falso que indica, respectivamente, que la mayúscula o minúscula alfabética no es o sí es significativa al comparar especificaciones de archivo. Cygwin y Win32 aceptan un argumento de unidad opcional. 
$is_case_tolerant = File::Spec->case_tolerant();
file_name_is_absolute
Toma como argumento una ruta y devuelve verdadero si es una ruta absoluta. 
$is_absolute = File::Spec->file_name_is_absolute( $path );

Esto no consulta el sistema de archivos local en Unix, Win32, OS/2 o Mac OS (Classic). Consulta el entorno de trabajo para VMS (ver "file_name_is_absolute" en File::Spec::VMS).

path
No toma argumentos. Devuelve la variable de entorno "PATH" (o el equivalente de la plataforma local) como una lista. 
@PATH = File::Spec->path();
join
join es lo mismo que catfile.
splitpath
Divide una ruta en porciones de volumen, directorio y nombre de archivo. En sistemas sin concepto de volumen, devuelve '' para el volumen. 
($volume,$directories,$file) =
                   File::Spec->splitpath( $path );
($volume,$directories,$file) =
                   File::Spec->splitpath( $path, $no_file );

Para sistemas sin sintaxis que diferencie nombres de archivo de directorios, asume que el último archivo es una ruta a menos que $no_file sea verdadero o esté presente un separador final o /. o /... En Unix, esto significa que $no_file verdadero hace que esto devuelva ( '', $path, '' ).

La porción de directorio puede o no ser devuelta con una barra diagonal final.

Los resultados se pueden pasar a "catpath()" para obtener una ruta equivalente a (generalmente idéntica a) la ruta original.

splitdir
Lo opuesto a "catdir". 
@dirs = File::Spec->splitdir( $directories );

$directories debe ser solo la porción de directorio de la ruta en sistemas que tienen el concepto de volumen o que tienen sintaxis de ruta que diferencia archivos de directorios.

A diferencia de simplemente dividir los directorios por el separador, se pueden devolver nombres de directorio vacíos (''), porque estos son significativos en algunos sistemas operativos.

catpath()
Toma las porciones de volumen, directorio y archivo y devuelve una ruta completa. En Unix, $volume se ignora, y el directorio y el archivo se concatenan. Se inserta una '/' si es necesario. En otros SO, $volume es significativo. 
$full_path = File::Spec->catpath( $volume, $directory, $file );
abs2rel
Toma una ruta de destino y una ruta base opcional y devuelve una ruta relativa desde la ruta base a la ruta de destino: 
$rel_path = File::Spec->abs2rel( $path ) ;
$rel_path = File::Spec->abs2rel( $path, $base ) ;

Si $base no está presente o es '', se utiliza Cwd::cwd(). Si $base es relativa, se convierte a forma absoluta usando "rel2abs()". Esto significa que se toma como relativa a Cwd::cwd().

rel2abs()
Convierte una ruta relativa a una ruta absoluta. 
$abs_path = File::Spec->rel2abs( $path ) ;
$abs_path = File::Spec->rel2abs( $path, $base ) ;

Si $base no está presente o es '', entonces se usa Cwd::cwd() . Si $base es relativo, entonces se convierte a forma absoluta usando "rel2abs()". Esto significa que se considera relativo a Cwd::cwd().

En los sistemas con el concepto de volumen, si $path y $base parecen estar en dos volúmenes diferentes, no intentaremos resolver las dos rutas, y en su lugar simplemente devolveremos $path. Tenga en cuenta que las versiones anteriores de este módulo ignoraban el volumen de $base, lo que resultaba en resultados incorrectos parte del tiempo.

En los sistemas que tienen una gramática que indica nombres de archivo, esto ignora el $base nombre de archivo también. En caso contrario, se asume que todos los componentes de la ruta son directorios.

Si $path es absoluta, se limpia y se devuelve usando "canonpath".

No se realizan comprobaciones contra el sistema de archivos. En VMS, hay interacción con el entorno de trabajo, ya que se expanden lógicos y macros.
