DESCRIPCIÓ

N

Este módulo copia y mueve directorios recursivamente (o archivos

individuales, bueno... individualmente) hasta una profundidad opc
ional e intenta preservar el modo de cada archivo o directorio.

fcopy(

)

Esta función usa la función copy() de File::Copy para copiar un archivo pero no un directorio. Se crean recursivamente todos los directorios si es necesario. Una diferencia con File::Copy::copy() es que fcopy intenta preservar el modo (véase Preservar el modo más abajo). El $buf opcional en la sinopsis es igual que el tercer argumento de File::Copy::copy(). Esta función devuelve lo mismo que File::Copy::copy() en contexto escalar y 1,0,0 en contexto de lista para acomodar el contexto de lista de rcopy() en archivos norm

ales. (Véase más aba
jo para más información)

Intenta preservar el modo (véase Preservar el modo más abajo) y por defecto copia todo el camino hacia abajo en el directorio (véase Gestionar la profundidad, más abajo). Si no se especifica un directorio, queja igual que fcopy queja si no se especifica un

archivo.
