fields(3perl) Guía del programador de Perl fields(3perl)

NOMBRE

fields - campos de clase en tiempo de compilación

SINOPSIS

{
    package Foo;
    use fields qw(foo bar _Foo_private);
    sub new {
        my Foo $self = shift;
        unless (ref $self) {
            $self = fields::new($self);
            $self->{_Foo_private} = "esto es secreto de Foo";
        }
        $self->{foo} = 10;
        $self->{bar} = 20;
        return $self;
    }
}
my $var = Foo->new;
$var->{foo} = 42;
# esto generará un error en tiempo de ejecución
$var->{zap} = 42;
# esto generará un error en tiempo de compilación
my Foo $foo = Foo->new;
$foo->{zap} = 24;
# subclasificación
{
    package Bar;
    use base 'Foo';
    use fields qw(baz _Bar_private);        # no compartido con Foo
    sub new {
        my $class = shift;
        my $self = fields::new($class);
        $self->SUPER::new();                # inicializa campos base
        $self->{baz} = 10;                  # inicializa campos propios
        $self->{_Bar_private} = "esto es secreto de Bar";
        return $self;
    }
}

DESCRIPCIÓN

El pragma "fields" habilita campos de clase verificados en tiempo de compilación y en tiempo de ejecución.

NOTA: La implementación actual mantiene los campos declarados en el hash %FIELDS del paquete que llama, pero esto puede cambiar en versiones futuras. **No** actualice el hash %FIELDS directamente, ya que debe crearse en tiempo de compilación para que sea completamente útil, como lo hace este pragma.

Si se utiliza una variable léxica tipada (my Class $var) que contiene una referencia para acceder a un elemento de hash y un paquete con el mismo nombre que el tipo ha declarado campos de clase usando este pragma, la clave del hash se verifica en tiempo de compilación. Si las variables no están tipadas, el acceso solo se verifica en tiempo de ejecución.

El pragma relacionado "base" combinará los campos de las clases base y cualquier campo declarado usando el pragma "fields". Esto permite que la herencia de campos funcione correctamente. Los campos heredados se pueden sobrescribir pero generarán una advertencia si las advertencias están habilitadas.

**Solo válido para Perl 5.8.x y anteriores:** Los nombres de campo que comienzan con un carácter de guion bajo se vuelven privados para la clase y no son visibles para las subclases.

Además, **en Perl 5.8.x y anteriores**, este pragma utiliza pseudo-hashes, con el efecto de que puedes tener objetos con campos con nombre que son tan compactos y rápidos de acceder como los arrays, siempre y cuando los objetos se accedan a través de variables debidamente tipadas.

Las siguientes funciones son compatibles:

new
fields::new() crea y bendice un hash de los campos declarados usando el pragma "fields" en la clase especificada. Es la forma recomendada de construir un objeto basado en campos.

Esto hace posible escribir un constructor como este:

package Critter::Sounds;
use fields qw(cat dog bird);
sub new {
    my $self = shift;
    $self = fields::new($self) unless ref $self;
    $self->{cat} = 'miau';                      # elemento escalar
    @$self{'dog','bird'} = ('ladrar','piar');    # slice
    return $self;
}
phash
Esta función solo funciona en Perl 5.8.x y anteriores. Los pseudo-hashes fueron eliminados de Perl a partir de la versión 5.10. Considere usar hashes restringidos o fields::new() en su lugar (que a su vez utiliza hashes restringidos en 5.10+). Ver Hash::Util. Usar fields::phash() en la versión 5.10 o superior causará un error.

fields::phash() se puede usar para crear e inicializar un pseudo-hash simple (sin bendecir). Esta función siempre debe usarse en lugar de crear pseudo-hashes directamente.

Si el primer argumento es una referencia a un array, el pseudo-hash se creará con claves de ese array. Si se proporciona un segundo argumento, también debe ser una referencia a un array cuyos elementos se usarán como valores. Si el segundo array contiene menos elementos que el primero, los elementos finales del pseudo-hash no se inicializarán. Esto lo hace particularmente útil para crear un pseudo-hash a partir de argumentos de subrutina:

sub dogtag {
   my $tag = fields::phash([qw(nombre rango ser_num)], [@_]);
}

fields::phash() también acepta una lista de pares clave-valor que se utilizarán para construir el pseudo hash. Ejemplos:

my $tag = fields::phash(nombre => "Joe",
                        rango => "capitán",
                        ser_num => 42);
my $pseudohash = fields::phash(%args);
