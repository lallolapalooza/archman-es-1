FIREWALLD.POLICY-SETS(5) Conjuntos de políticas de Firewalld FIREWALLD.POLICY-SETS(5)

NOMBRE

firewalld.policy-sets - Conjuntos de políticas

DESCRIPCIÓN

¿Qué son los conjuntos de políticas?

Los conjuntos de políticas son colecciones de políticas que sirven como configuración inicial para casos de uso específicos, por ejemplo, un router doméstico. Proporcionan una forma fácil de empezar. Los usuarios pueden luego ajustar la configuración para su entorno. Cada conjunto de políticas tiene una página de manual dedicada para explicar su caso de uso.

Todos los conjuntos de políticas distribuidos por firewalld están deshabilitados administrativamente por defecto. Usarlos es cuestión de añadir sus interfaces a las zonas y eliminar la desactivación.

Habilitar un conjunto de políticas

A continuación se muestra un ejemplo completo para usar el conjunto de políticas de gateway. En este ejemplo: eth0 es la interfaz LAN y eth1 es el enlace ascendente a internet.

	      # firewall-cmd --permanent --zone internal eth0
	      # firewall-cmd --permanent --zone external eth1
	      # firewall-cmd --permanent --policy-set gateway --remove-disable
	      # firewall-cmd --reload

Habilitar múltiples conjuntos de políticas

Se garantiza que los conjuntos de políticas interoperarán. Se pueden habilitar múltiples conjuntos de políticas simultáneamente.

Conjuntos de políticas existentes

gateway

Proporciona funcionalidad básica para un gateway, por ejemplo, un router doméstico. Ver firewalld.policy-set-gateway(5).
