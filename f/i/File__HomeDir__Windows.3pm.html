NOMBRE

File::HomeDir::Windows - Encuentra tu directorio de inicio y otros directorios en Windows

SINOPSIS

use File::HomeDir;

# Encuentra directorios para el usuario actual (ej. usando Windows XP Professional)
$home    = File::HomeDir->my_home;        # C:\Documents and Settings\miusuario
$desktop = File::HomeDir->my_desktop;     # C:\Documents and Settings\miusuario\Desktop
$docs    = File::HomeDir->my_documents;   # C:\Documents and Settings\miusuario\My Documents
$music   = File::HomeDir->my_music;       # C:\Documents and Settings\miusuario\My Documents\My Music
$pics    = File::HomeDir->my_pictures;    # C:\Documents and Settings\miusuario\My Documents\My Pictures
$videos  = File::HomeDir->my_videos;      # C:\Documents and Settings\miusuario\My Documents\My Video
$data    = File::HomeDir->my_data;        # C:\Documents and Settings\miusuario\Local Settings\Application Data

DESCRIPCIÓN

Este módulo proporciona implementaciones específicas de Windows para determinar directorios comunes de usuario. En uso normal, este módulo siempre se usará a través de File::HomeDir.

Internamente, este módulo usará Win32::GetFolderPath para obtener la ubicación de tus directorios. Como resultado de esto, en ciertas situaciones inusuales (generalmente encontradas en organizaciones grandes), los métodos pueden devolver rutas UNC como "\\cifs.local\home$".

Si tu aplicación se ejecuta en Windows y quieres que funcione completamente en todas partes, puede que necesites implementar tu propio manejo para estas rutas, ya que pueden causar comportamientos extraños.

Por ejemplo, las llamadas a stat a rutas UNC pueden funcionar pero bloquearse durante varios segundos, pero opendir() puede no ser capaz de leer ningún archivo (creando la apariencia de un directorio existente pero vacío).

Para evitar complicar más el problema, en la rara situación en que se devuelva una ruta UNC por "GetFolderPath" las comprobaciones de validación -d habituales **no** se realizarán.
