NAME

fips_config, fips_config - OpenSSL FIPS provider configuration

DESCRIPTION

This man page describes the configuration directives for the OpenSSL FIPS provider. The directives are used in the configuration file (see config(5)) to control the behaviour of the FIPS provider.

The directives are grouped into sections. The primary section is [fips_sect].

The following directives are supported in the [fips_sect] section:

activate
A boolean value. If set to 1, the FIPS provider is activated. If set to 0, the FIPS provider is not activated. The default value is 0.
install-version
A boolean value. If set to 1, the FIPS provider will perform a self-test of the installed FIPS module during initialization. This is the default value.
conditional-errors
A boolean value. If set to 1, the FIPS provider will return specific error codes for FIPS violations. This is the default value.
security-checks
A boolean value. If set to 1, the FIPS provider will perform additional security checks, such as validating cryptographic module MACs. This is the default value.
module-mac
Specifies the MAC (Message Authentication Code) of the FIPS module. This is used to verify the integrity of the FIPS module. The value should be a colon-separated hexadecimal string.
install-mac
Specifies the MAC of the FIPS module installation. This is used to verify that the FIPS module has been installed correctly. The value should be a colon-separated hexadecimal string.
install-status
Specifies the installation status of the FIPS module. Possible values include:
INSTALL_NONE
No installation has been performed.
INSTALL_SELF_TEST_FAILED
The self-test of the FIPS module failed.
INSTALL_SELF_TEST_KATS_RUN
The self-test (Known Answer Tests) of the FIPS module has been run.
INSTALL_MODULE_BAD
The FIPS module is corrupted or invalid.
INSTALL_BAD_MAC
The MAC of the FIPS module is incorrect.
INSTALL_SELF_TEST_RUN
The self-test of the FIPS module has been run.
INSTALL_VERIFIED
The FIPS module has been successfully installed and verified.
kmac-key-check
See "OPTIONS" in openssl-fipsinstall(1) -kmac_key_check

For example:

[fips_sect]
activate = 1
install-version = 1
conditional-errors = 1
security-checks = 1
module-mac = 41:D0:FA:C2:5D:41:75:CD:7D:C3:90:55:6F:A4:DC
install-mac = FE:10:13:5A:D3:B4:C7:82:1B:1E:17:4C:AC:84:0C
install-status = INSTALL_SELF_TEST_KATS_RUN

NOTES

When using the FIPS provider, it is recommended that the config_diagnostics option is enabled to prevent accidental use of non-FIPS validated algorithms via broken or mistaken configuration. See config(5).
