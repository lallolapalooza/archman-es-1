fips_config -

Configuración F
IPS de OpenSSL

DESCRIPCIÓ

N

Se utiliza un archivo de configuración separado, que emplea la sintaxis de config(5) de OpenSSL, para almacenar información sobre el módulo FIPS. Esto incluye un resumen del archivo de biblioteca compartida y el estado de las autopruebas. Estos datos son utilizados automáticamente por el propio módulo con dos

propósitos:
- Ejecutar la autoprueba FIPS de inicio, pruebas de conocimiento previo
(KATS).
Esto se realiza normalmente una vez, en el momento de la instalación, pero también se puede configurar para que se ejecute cada vez que se use el
módulo.
- Verificar la suma de comprobación del
módulo.
Esto se hace c
ada vez que se
usa el módulo.

Este archivo es generado por el programa openssl-fipsinstall(1) y es utilizado internamente por el módulo FIPS durante su

inicialización.

Se admiten las siguientes opciones. Todas deben aparecer en una sección cuyo nombre es identificado por la opción fips en la sección providers, como se describe en "Provider Configuration Module" en config(

5).
activa
te
Si está presente, el módulo se activa. El valor asignado a este nombre no es
significativo.
conditional-err
ors
El módulo FIPS normalmente entra en un modo de error interno si alguna autoprueba falla. Una vez que este modo de error está activo, no se puede acceder a ningún servicio o algoritmo criptográfico a partir de este punto. Las pruebas continuas son un subconjunto de las autopruebas (p. ej., una prueba de par de claves durante la generación de claves, o la prueba de salida del CRNG). Establecer este valor en 0 permite que el modo de error no se active si alguna prueba continua falla. El valor predeterminado de 1 activará el modo de error. Independientemente del valor, la operación (p. ej., generación de claves) que llamó a la prueba continua devolverá un código de error si su prueba continua falla. La operación puede reintentarse si el modo de error no se ha
activado.

Opciones indicadoras de

FIPS

Las siguientes opciones de configuración de FIPS indican si se utilizan verificaciones en tiempo de ejecución relacionadas con la aplicación de parámetros de seguridad FIPS, como la fuerza de seguridad mínima de las claves y los nombres de curvas aprobadas. Un valor de '1' realizará las verificaciones; de lo contrario, si el valor es '0', las verificaciones no se realizan y el cumplimiento de FIPS debe hacerse mediante los procedimientos documentados en la Política de Seguridad correspondiente

.
