¿CUÁL ES EL EQUIVALENTE A ESTA COSA DE BASH (O DE OTROS SHELLS)?

Ver Fish para usuarios de bash <>

¿CÓMO ¿ESTABLEZCO O BORRO UNA VARIABLE DE ENTORNO?

Usa el comando set <>:

set -x clave valor # típicamente set -gx clave valor
set -e clave

Desde fish 3.1 puedes establecer una variable de entorno para un solo comando usando la sintaxis clave=valor algún comando, como en otros shells. Las dos líneas siguientes se comportan de manera idéntica - a diferencia de otros shells, fish mostrará valor en ambos casos:

clave=valor echo $clave
begin; set -lx clave valor; echo $clave; end

Ten en cuenta que "exportado" no es un ámbito <#variables-scope>, sino un bit adicional de estado. Una variable puede ser global y exportada, o local y exportada, o incluso universal y exportada. Típicamente, tiene sentido hacer global una variable exportada.

¿CÓMO ¿VERIFICO SI UNA VARIABLE ESTÁ DEFINIDA?

Usa set -q var. Por ejemplo, if set -q var; echo variable definida; end. Para verificar múltiples variables puedes combinarlas con and y or así:

if set -q var1; or set -q var2
    echo al menos una variable está definida
end

Ten en cuenta que una variable definida también podría estar vacía, ya sea por no tener elementos (si se estableció como set var) o solo elementos vacíos (si se estableció como set var ""). Lee más abajo cómo manejar eso.

¿CÓMO ¿VERIFICO SI UNA VARIABLE NO ESTÁ VACÍA?

Usa string length -q -- $var. Por ejemplo, if string length -q -- $var; echo no está vacía; end. Ten en cuenta que string length interpretará una lista de múltiples variables como una disyunción (es decir, cualquiera/o):

if string length -q -- $var1 $var2 $var3
    echo al menos una de estas variables no está vacía
end

Alternativamente, usa test -n "$var", pero recuerda que la variable debe estar entre comillas dobles. Por ejemplo, if test -n "$var"; echo no está vacía; end. El comando test proporciona sus propios y (-a) o (-o):

if test -n "$var1" -o -n "$var2" -o -n "$var3"
    echo al menos una de estas variables no está vacía
end

Si quieres saber si una variable no tiene elementos, usa set -q var[1].

¿POR ¿QUÉ SET -UX (VARIABLES UNIVERSALES EXPORTADAS) NO PARECE FUNCIONAR?

Ya existe una variable global con el mismo nombre.

Las variables de entorno como EDITOR o TZ se pueden establecer universalmente usando set -Ux. Sin embargo, si hay una variable de entorno ya establecida antes de que fish comience (como por scripts de inicio de sesión o administradores del sistema), se importa en fish como una variable global. Los ámbitos de variables <#variables-scope> se buscan desde el "interior hacia afuera", lo que significa que primero se comprueban las variables locales, seguidas de las variables globales y, finalmente, las universales.

Esto significa que el valor global tiene precedencia sobre el valor universal.

Para evitar este problema, considera cambiar la configuración que fish hereda. Si esto no es posible, añade una declaración a tu archivo de configuración <#configuration> (normalmente ~/.config/fish/config.fish):

set -gx EDITOR vim

¿CÓMO ¿EJECUTO UN COMANDO EN CADA INICIO DE SESIÓN? ¿CUÁL ES EL EQUIVALENTE DE FISH A .BASHRC O .PROFILE?

Edita el archivo ~/.config/fish/config.fish [1], creándolo si no existe (Nota el punto inicial).

A diferencia de .bashrc y .profile, este archivo se lee siempre, incluso en shells no interactivos o de inicio de sesión.

Para hacer algo solo en shells interactivos, comprueba status is-interactive así:

if status is-interactive
    # usa el tema coolbeans
    fish_config theme choose coolbeans
end
[1]
La parte "~/.config" de esto se puede establecer a través de $XDG_CONFIG_HOME, ese es solo el valor predeterminado.

¿CÓMO ¿ESTABLEZCO MI PROMPT?

El prompt es la salida de la función fish_prompt. Colócala en ~/.config/fish/functions/fish_prompt.fish. Por ejemplo, un prompt simple es:

function fish_prompt
    set_color $fish_color_cwd
    echo -n (prompt_pwd)
    set_color normal
    echo -n ' > '
end

También puedes usar la herramienta de configuración web, fish_config <>, para previsualizar y elegir entre una galería de prompts de ejemplo.

O puedes usar fish_config desde la línea de comandos:

> fish_config prompt show
# muestra todos los prompts que fish trae de serie
> fish_config prompt choose disco
# carga el prompt disco en el shell actual
> fish_config prompt save
# hace que el cambio sea permanente

Si quieres modificar tu prompt actual, puedes usar funced <> y funcsave <> así:

>_ funced fish_prompt
# Esto abre tu editor (establecido en $EDITOR).
# Modifica la función,
# guarda el archivo y repite a tu gusto.
# Una vez que estés satisfecho:
>_ funcsave fish_prompt

Esto también se aplica a fish_right_prompt <> y fish_mode_prompt <>.

¿POR ¿POR QUÉ MI PROMPT MUESTRA UN [I]?

Ese es el fish_mode_prompt <>. Se muestra por defecto cuando has activado el modo vi usando fish_vi_key_bindings.

Si no has activado el modo vi a propósito, es posible que hayas instalado un tema o plugin de terceros que lo haga.

Si quieres cambiar o deshabilitar esta visualización, modifica la función fish_mode_prompt, por ejemplo, a través de funced <>.

¿CÓMO ¿PERSONALIZO LOS COLORES DE MI RESALTADO DE SINTAXIS?

Usa la herramienta de configuración web, fish_config <>, o modifica la familia de variables de entorno fish_color <#variables-color>.

También puedes usar fish_config en la línea de comandos, así:

> fish_config theme show
# para mostrar todos los esquemas de color
> fish_config theme choose coolbeans
# para cargar el tema "coolbeans"
> fish_config theme save
# para hacer que el cambio sea permanente

¿CÓMO ¿CAMBIO EL MENSAJE DE BIENVENIDA?

Cambia el valor de la variable fish_greeting o crea una función fish_greeting <>. Por ejemplo, para eliminar el saludo usa:

set -U fish_greeting

O si prefieres no usar una variable universal, usa:

set -g fish_greeting

en config.fish <#configuration>.

A diferencia de otros shells, fish divide las sustituciones de comandos solo en saltos de línea, no en espacios, tabuladores o los caracteres en

$IFS.

Eso significa que si

En la abrumadora mayoría de los casos, dividir por espacios es indeseable, así que esto es una mejora. Es por eso que escuchas sobre problemas con nombres de archivos con espacios, después de

Sin embargo, a veces, especialmente con pkg-config y herramientas relacionadas, dividir por espacios es

necesario.

En estos casos usa string split -n " "
