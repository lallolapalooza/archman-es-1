DESCRIPCIÓ

N

findmnt listará todos los sistemas de archivos montados o buscará un sistema de archivos. El comando findmnt es capaz de buscar en /etc/fstab, /etc/mtab o /proc/self/mountinfo. Si no se proporciona el dispositivo o el punto de montaje, se muestran todos los sistemas de

archivos.

El dispositivo puede especificarse por nombre de dispositivo, números mayor:menor, etiqueta del sistema de archivos o UUID, o etiqueta de partición o UUID. Tenga en cuenta que findmnt sigue el comportamiento de mount(8) donde un nombre de dispositivo puede interpretarse como un punto de montaje (y viceversa) si no se especifican las opciones --target, --mountpoint o --source

.

La opción de línea de comandos --target acepta cualquier archivo o directorio y luego findmnt muestra el sistema de archivos para la ruta

dada.

El comando imprime todos los sistemas de archivos montados en formato de árbol de forma predeterminada. La salida predeterminada está sujeta a cambios. Por lo tanto, siempre que sea posible, debe evitar usar la salida predeterminada en sus scripts. Defina siempre explícitamente las columnas esperadas usando --output lista-de-columnas en entornos donde se requiere una salida

estable.

La relación entre los dispositivos de bloque y los sistemas de archivos no es siempre uno a uno. El sistema de archivos puede usar más de un dispositivo de bloque. Es por esto que findmnt proporciona las columnas SOURCE y SOURCES (pl.). La columna SOURCES muestra todos los dispositivos donde es posible encontrar el mismo UUID del sistema de archivos (u otra etiqueta especificada en fstab cuando se ejecuta con --fstab y --eval

uat
e).

NOMBRE

findmnt - buscar sistemas de archivos

SINOPSIS

findmnt [options] [
findmnt [options] spec[...]

DESCRIPCIÓN

La utilidad findmnt se utiliza para encontrar y enumerar sistemas de archivos montados. La utilidad puede utilizarse de varias maneras: para buscar un sistema de archivos específico montado en un dispositivo o punto de montaje, o para listar todos los sistemas de archivos montados con opciones de filtrado.

OPCIONES

-a, --all
Lista todos los sistemas de archivos, incluidos los sistemas de archivos virtuales (por ejemplo, proc, sysfs). Por defecto, findmnt no lista los sistemas de archivos que no se pueden leer o aquellos que no están asociados con un dispositivo (por ejemplo, sistemas de archivos tmpfs sin una opción -t).
-c, --canonical
Escribe los nombres de dispositivo en forma canónica (por ejemplo, /dev/sda1 en lugar de sda1).
-t, --types fstype
Lista solo los sistemas de archivos del tipo especificado. Se puede especificar múltiples tipos separados por comas. El valor por defecto es listar todos los tipos de sistemas de archivos.
-s, --source device
Lista solo los sistemas de archivos montados en el dispositivo especificado.
-m, --mount-point path
Lista solo los sistemas de archivos montados en el punto de montaje especificado.
-o, --output list
Especifica las columnas que se van a mostrar. Utilice -o help para obtener una lista de todas las columnas disponibles. El valor por defecto es FIELD,SOURCE,TARGET,FSTYPE,OPTIONS.
-r, --raw
Listar en modo raw (sin formato). Esto es útil para el procesamiento de scripts.
-n, --noheadings
No imprimir las cabeceras de la tabla.
-L, --evaluate
Sigue los enlaces simbólicos en el punto de montaje.
-i, --inverse
Invierte la lógica de la selección. Selecciona las entradas que no coinciden.
-h, --help
Muestra un mensaje de ayuda y sale.
-V, --version
Muestra la información de la versión y sale.

ESTADO DE SALIDA

El código de salida es 0 si se encontró al menos un sistema de archivos que coincide con los criterios especificados, y 1 en caso contrario.

ENTORNO

findmnt respeta las siguientes variables de entorno:

LIBC_FATAL_STDERR_
Si esta variable está configurada, findmnt imprimirá todos los mensajes en stderr en lugar de stdout.

EJEMPLOS

Para listar todos los sistemas de archivos montados:

findmnt

Para listar todos los sistemas de archivos montados, incluidos los virtuales:

findmnt -a

Para listar solo los sistemas de archivos ext4:

findmnt -t ext4

Para listar solo los sistemas de archivos montados en /dev/sda1:

findmnt -s /dev/sda1

Para listar solo los sistemas de archivos montados en el punto de montaje /home:

findmnt -m /home

Para listar todos los sistemas de archivos montados en formato raw:

findmnt -r

Para listar solo el dispositivo y el punto de montaje de todos los sistemas de archivos:

findmnt -o SOURCE,TARGET
