Paquete: perl-file-readbackwards

ReadBackwards(3) Documentación de Perl aportada por el usuario ReadBackwards(3)

NOMBRE

File::ReadBackwards.pm -- Lee un archivo hacia atrás por líneas.

SINOPSIS

use File::ReadBackwards ;
# Interfaz de objeto
$bw = File::ReadBackwards->new( 'log_file' ) or
                    die "no se puede leer 'log_file' $!" ;
while( defined( $log_line = $bw->readline ) ) {
        print $log_line ;
}
# ... o la forma alternativa de leer
until ( $bw->eof ) {
        print $bw->readline ;
}
# Interfaz de manejador enlazado (Tied Handle)
tie *BW, 'File::ReadBackwards', 'log_file' or
                    die "no se puede leer 'log_file' $!" ;
while( <BW> ) {
        print ;
}

DESCRIPCIÓN

Este módulo lee un archivo hacia atrás línea por línea. Es sencillo de usar, eficiente en memoria y rápido. Admite tanto una interfaz de objeto como una interfaz de manejador enlazado (tied handle).

Está pensado para procesar archivos de registro (log) y otros archivos de texto similares que normalmente tienen sus entradas más recientes añadidas al final. Por defecto, se asume que los archivos son texto plano y tienen una terminación de línea adecuada para el sistema operativo. Pero puedes establecer el separador de registros de entrada por archivo.

INTERFAZ DE OBJETO

Estos son los métodos de la interfaz de objeto de "File::ReadBackwards":

new( $archivo, [$sep_reg] )

"new" toma como argumentos un nombre de archivo, un separador de registros opcional y un indicador opcional que marca el separador de registros como una expresión regular. Devuelve el objeto en caso de una apertura exitosa o undef en caso de fallo. $! se establece al código de error si lo hay.

readline

"readline" no toma argumentos y devuelve la línea anterior en el archivo o undef cuando no hay más líneas en el archivo. Si el archivo no es buscable (por ejemplo, una tubería), se devuelve undef.

getline

"getline" es un alias del método readline. Está aquí por compatibilidad con las clases IO::*, que tienen un método getline.

eof

"eof" no toma argumentos y devuelve true cuando readline() ha iterado a través de todo el archivo.

close

"close" no toma argumentos y cierra el manejador.

tell

"tell" no toma argumentos y devuelve la posición actual del manejador de archivo. Este valor puede usarse para seek() de vuelta a esta posición usando un manejador de archivo normal.

get_handle

"get_handle" no toma argumentos y devuelve el manejador de archivo interno de Perl utilizado por el objeto File::ReadBackwards. Este manejador puede usarse para leer el archivo hacia adelante. Su posición de búsqueda se establecerá en la posición devuelta por el método tell(). Tenga en cuenta que intercalar lecturas hacia adelante y hacia atrás puede producir resultados impredecibles. El único uso admitido en la actualidad es leer un archivo hacia atrás hasta cierto punto, luego usar 'handle' para extraer el manejador y leer hacia adelante desde ese punto.

INTERFAZ DE MANEJADOR ENLAZADO (TIED HANDLE)

tie( *MANEJADOR, 'File::ReadBackwards', $archivo, [$sep_reg] )

Los métodos TIEHANDLE, READLINE, EOF, CLOSE y TELL se aliñan a los métodos new, readline, eof, close y tell respectivamente, así que consulte ellos para sus argumentos y API. Una vez que haya enlazado un manejador a File::ReadBackwards, la única operación de E/S permitida es <>, que leerá la línea anterior. También puede llamar a eof() y close() en el manejador enlazado. Todas las demás operaciones de manejador enlazado generarán un error de método desconocido. No haga seek, write ni realice ninguna otra operación no admitida en el manejador enlazado.

TERMINADORES DE LINEA Y REGISTRO

Dado que este módulo necesita usar E/S de bajo nivel por eficiencia, no puede hacer seek portablemente y realizar E/S de bloque sin gestionar las conversiones de terminadores de línea. Este módulo admite los separadores de registros predeterminados de las cadenas de terminación de línea normales utilizadas por el SO. También puede establecer el separador por archivo.

El separador de registros es una expresión regular por defecto, lo que difiere del comportamiento de $/.

Solo si el separador de registros no se especifica y por defecto es CR/LF (por ejemplo, VMS, redmondware) se convertirá a una sola nueva línea. Los sistemas de archivos Unix y MacOS utilizan un solo carácter para los terminadores de línea y las líneas se dejan sin cambios. Esto significa que para los archivos de texto nativos, debería poder procesar sus líneas hacia atrás sin problemas con los terminadores de línea. Si especifica un separador de registros, no se realizarán conversiones y obtendrá los registros como si los hubiera leído en modo binario.

DISEÑO

Funciona leyendo un bloque grande (8kb) de datos desde el final del archivo. Luego los divide en el separador de registros y almacena una lista de registros en el objeto. Cada llamada a readline devuelve el registro superior de la lista y si la lista está vacía, la rellena leyendo el bloque anterior del archivo y dividiéndolo. Cuando se alcanza el principio del archivo y no hay más líneas, se devuelve undef. Todas las condiciones de borde se manejan correctamente, es decir, si hay una línea parcial final (sin nueva línea), será la primera línea devuelta y las líneas más grandes que el tamaño del búfer de lectura se manejan correctamente.

NOTAS

No hay soporte para contexto de lista ni en la interfaz de objeto ni en la interfaz enlazada. Si desea cargar todas las líneas en un array en orden inverso (y no le importa el uso de memoria), simplemente haga:

@lineas_inversas = reverse <FH>.

Este módulo solo está diseñado para leer una línea a la vez desde el final de un archivo hasta el principio.
