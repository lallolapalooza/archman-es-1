NOMBRE

Filesys::Df - Extensión de Perl para información de espacio en disco del sistema de archivos.

SINOPSIS

use Filesys::Df;
#### Obtener información pasando un valor escalar de directorio/nombre de archivo
my $ref = df("/tmp");  # La salida predeterminada son bloques de 1K
if(defined($ref)) {
   print "Total de bloques de 1k: $ref->{blocks}\n";
   print "Total de bloques de 1k libres: $ref->{bfree}\n";
   print "Total de bloques de 1k disponibles para mí: $ref->{bavail}\n";
   print "Total de bloques de 1k utilizados: $ref->{used}\n";
   print "Porcentaje ocupado: $ref->{per}\n";
   if(exists($ref->{files})) {
      print "Total de inodos: $ref->{files}\n"; 
      print "Total de inodos libres: $ref->{ffree}\n"; 
      print "Porcentaje de inodos ocupados: $ref->{fper}\n";
   }
}
#### Obtener información pasando un manejador de archivo
open(FILE, "some_file");  # Obtener información del sistema de archivos en "some_file"
my $ref = df(\*FILE);  
#### o
my $ref = df(*FILE);  
#### o
my $fhref = \*FILE;
my $ref = df($fhref);  
#### Obtener información en bloques distintos de 1k
my $ref = df("/tmp", 8192);  # la salida son bloques de 8K
my $ref = df("/tmp", 1);     # la salida son bytes

DESCRIPCIÓN

Este módulo proporciona una forma de obtener información sobre el espacio en disco del sistema de archivos. Esta es una distribución solo para Unix. Si desea recopilar esta información para Unix y Windows, utilice "Filesys::DfPortable". El único beneficio importante de usar "Filesys::Df" sobre "Filesys::DfPortable" es que "Filesys::Df" admite el uso de manejadores de archivos abiertos como argumentos.

El módulo debería funcionar con todos los sabores de Unix que implementen las llamadas statvfs() y fstatvfs(), o las llamadas statfs() y fstatfs(). Esto incluiría Linux, *BSD, HP-UX, AIX, Solaris, Mac OS X, Irix, Cygwin, etc.

df() requiere un argumento que represente el sistema de archivos que desea consultar. El argumento puede ser un nombre escalar de directorio/archivo o un manejador de archivo abierto. También hay un argumento opcional de tamaño de bloque para que pueda adaptar el tamaño de los valores devueltos. El tamaño de bloque predeterminado es 1024. Esto hará que la función devuelva los valores en bloques de 1k. Si desea bytes, establezca el tamaño de bloque en 1.

df() devuelve una referencia a un hash. Las claves disponibles en el hash son las siguientes:

"{blocks}" = Bloques totales en el sistema de archivos.

"{bfree}" = Bloques totales libres en el sistema de archivos.

"{bavail}" = Bloques totales disponibles para el usuario que ejecuta la aplicación Perl. Esto puede ser diferente de "{bfree}" si tiene cuotas por usuario en el sistema de archivos, o si el superusuario tiene una cantidad reservada. "{bavail}" también puede ser un valor negativo debido a esto. Por ejemplo, si se está utilizando más espacio del que tiene disponible.

"{used}" = Bloques totales utilizados en el sistema de archivos.

"{per}" = Porcentaje de espacio en disco utilizado. Esto se basa en el espacio en disco disponible para el usuario que ejecuta la aplicación. En otras palabras, si el sistema de archivos tiene un 10% de su espacio reservado para el superusuario, entonces el porcentaje utilizado puede llegar hasta el 110%.

También puede obtener información de inodos a través del módulo, pero primero debe llamar a exists() en la clave "{files}" para asegurarse de que la información esté disponible. Algunos sistemas de archivos pueden no devolver información de inodos, por ejemplo, algunos sistemas de archivos NFS.

Aquí están las claves de inodos disponibles:

"{files}" = Inodos totales en el sistema de archivos.

"{ffree}" = Inodos totales libres en el sistema de archivos.

"{favail}" = Inodos totales disponibles para el usuario que ejecuta la aplicación. Consulte las reglas para la clave "{bavail}".

"{fused}" = Inodos totales utilizados en el sistema de archivos.

"{fper}" = Porcentaje de inodos utilizados en el sistema de archivos. Consulte las reglas para la clave "{per}".

Hay algunas claves no documentadas que se definen para mantener la compatibilidad con versiones anteriores: "{su_blocks}", "{user_blocks}", etc.

Si la llamada a df() falla por algún motivo, devolverá `undef`. Esto probablemente sucederá si hace algo descabellado como intentar obtener información para `/proc`, o si pasa un nombre de sistema de archivos no válido, o si hay un error interno. df() hará croak() si le pasa un valor indefinido.

Requisitos: Su sistema debe contener statvfs() y fstatvfs(), o statfs() y fstatfs(). Debe estar ejecutando Perl 5.6 o superior.
