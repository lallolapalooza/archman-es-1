File__ShareDir(3pm)

File::ShareDir(3) Documentación de Perl contribuida por el usuario File::ShareDir(3)

NOMBRE

File::ShareDir - Localizar archivos compartidos por dist y por módulo

SINOPSIS

use File::ShareDir ':ALL';

# Dónde se guardan los archivos de datos compartidos a nivel de distribución
$dir = dist_dir('File-ShareDir');

# Dónde se guardan los archivos de datos compartidos a nivel de módulo
$dir = module_dir('File::ShareDir');

# Buscar un archivo específico en nuestro dir compartido de dist/módulo
$file = dist_file(  'File-ShareDir',  'file/name.txt');
$file = module_file('File::ShareDir', 'file/name.txt');

# Como module_file, pero busca hacia arriba en el árbol de herencia
$file = class_file( 'Foo::Bar', 'file/name.txt' );

DESCRIPCIÓN

La intención de File::ShareDir es proporcionar un complemento a Class::Inspector y File::HomeDir, módulos que toman un proceso que es bien conocido por los desarrolladores Perl avanzados pero que se vuelve un poco complicado, y lo hacen más disponible para la comunidad Perl en general.

Muy a menudo desea o necesita que su módulo Perl (CPAN o de otro tipo) tenga acceso a una gran cantidad de datos de solo lectura que se almacenan en el sistema de archivos en tiempo de ejecución.

En un sistema similar a Linux, esto estaría en un lugar como /usr/share, sin embargo Perl se ejecuta en una amplia variedad de sistemas diferentes, y por lo tanto el uso de cualquier ubicación única no es fiable.

Perl proporciona un método poco conocido para hacer esto, pero casi nadie es consciente de que existe. Como resultado, los autores de módulos a menudo pasan por algunos métodos muy extraños para poner los datos disponibles para su código.

El más común de estos es volcar los datos a una estructura de datos Perl enorme y guardarla en el módulo mismo. El resultado son archivos .pm enormes de varios megabytes que consumen mucha memoria innecesariamente.

Otro método es poner el "archivo" de datos después de la etiqueta del compilador __DATA__ y limitarse a acceder como un filehandle.

El problema a resolver es realmente bastante simple.

1. Escribir los archivos de datos en el sistema en el momento de la instalación.

2. Saber dónde los puso en tiempo de ejecución.

El sistema de instalación de Perl crea un directorio "auto" para tanto para cada distribución como para cada archivo de módulo.

Estos son utilizados por un par de diferentes sistemas de auto-carga para almacenar fragmentos de código generados en el momento de la instalación, y varios otros módulos escritos por los "maestros antiguos" de Perl.

Pero el mismo mecanismo está disponible para cualquier dist o módulo para almacenar cualquier tipo de datos.

Usando Datos en su Módulo

"File::ShareDir" forma una mitad de una solución de dos partes.

Una vez que los archivos se hayan instalado en el directorio correcto, puede usar "File::ShareDir" para encontrar sus archivos de nuevo después de la instalación.

Para la mitad de la instalación de la solución, vea File::ShareDir::Install y su "install_share" directiva.

Usar File::ShareDir::Install junto con File::ShareDir permite depender de los archivos en el dist_dir() o module_dir() apropiado en la fase de desarrollo, también.

FUNCIONES

"File::ShareDir" proporciona cuatro funciones para localizar archivos y directorios.

Para una mayor mantenibilidad, ninguna de estas se exporta por defecto y se espera que nombre las que desee en el momento del use, o proporcione la etiqueta ':ALL' . Las siguientes son todas equivalentes.

# Cargar pero no importar, y luego llamar directamente
use File::ShareDir;
$dir = File::ShareDir::dist_dir('My-Dist');

# Importar una sola función
use File::ShareDir 'dist_dir';
dist_dir('My-Dist');

# Importar todas las funciones
use File::ShareDir ':ALL';
dist_dir('My-Dist');

Todas las funciones comprobarán por usted que el dir/archivo realmente existe, y que tiene permisos de lectura, o lanzarán una excepción.

dist_dir

# Obtener el directorio de archivos compartidos de una distribución
my $dir = dist_dir('My-Distribution');

La función "dist_dir" toma un único parámetro con el nombre de una distribución instalada (CPAN o de otro tipo), y localiza el directorio de datos compartidos creado en el momento de la instalación para ella.

Devuelve la ruta del directorio como una cadena, o muere si no puede ser localizado o no es legible.

module_dir

# Obtener el directorio de archivos compartidos de un módulo
my $dir = module_dir('My::Module');

La función "module_dir" toma un único parámetro con el nombre de un módulo instalado (CPAN o de otro tipo), y localiza el directorio de datos compartidos creado en el momento de la instalación para él.

Para encontrar el directorio, el módulo debe estar cargado al llamar a esta función.

Devuelve la ruta del directorio como una cadena, o muere si no puede ser localizado o no es legible.

dist_file

# Encontrar un archivo en nuestro dir compartido de distribución
my $dir = dist_file('My-Distribution', 'file/name.txt');

La función "dist_file" toma dos parámetros: el nombre de la distribución y el nombre del archivo, localiza el dir de la distribución, y luego encuentra el archivo dentro de él, verificando que el archivo realmente existe, y que es legible.

El nombre del archivo debe ser una ruta relativa en el formato de su sistema de archivos local. Simplemente se añadirá al directorio usando el método "catfile" de File::Spec.

Devuelve la ruta del archivo como una cadena, o muere si el archivo o el dir de la dist no puede ser localizado, o el archivo no es legible.

module_file

# Encontrar un archivo en nuestro dir compartido de módulo
my $dir = module_file('My::Module', 'file/name.txt');

La función "module_file" toma dos parámetros: el nombre del módulo y el nombre del archivo. Localiza el dir del módulo, y luego encuentra el archivo dentro de él, verificando que el archivo realmente existe, y que es legible.

Para encontrar el directorio, el módulo debe estar cargado al llamar a esta función.

El nombre del archivo debe ser una ruta relativa en el formato de su sistema de archivos local. Simplemente se añadirá al directorio usando el método "catfile" de File::Spec.

Devuelve la ruta del archivo como una cadena, o muere si el archivo o el dir de la dist no puede ser localizado, o el archivo no es legible.

class_file

# Encontrar un archivo en nuestro dir compartido de módulo, o en nuestra clase padre
my $dir = class_file('My::Module', 'file/name.txt');

La función "module_file" toma dos parámetros: el nombre del módulo y el nombre del archivo. Localiza el dir del módulo, y luego encuentra el archivo dentro de él, verificando que el archivo realmente existe, y que es legible.

Para encontrar el directorio, el módulo debe estar cargado al llamar a esta función.

El nombre del archivo debe ser una ruta relativa en el formato de su sistema de archivos local. Simplemente se añadirá al directorio usando el método "catfile" de File::Spec.

Si el archivo NO se encuentra para ese módulo, "class_file" escaneará hacia arriba el árbol @ISA del módulo, buscando el archivo en todas las clases padre.

Esto le permite, en efecto, "subclasear" los archivos compartidos.

Devuelve la ruta del archivo como una cadena, o muere si el archivo o el dir de la dist no puede ser localizado, o el archivo no es legible.

EXTENSIÓN

Sobrescribiendo la Resolución de Directorios

"File::ShareDir" tiene dos hashes de conveniencia para personas que tienen requisitos de uso avanzados de "File::ShareDir" como usar dirs "share" no instalados durante el desarrollo.

#
# Dist-Name => /ruta/absoluta/para/DistName/share/dir
#
%File::ShareDir::DIST_SHARE
#
# Module::Name => /ruta/absoluta/para/Module/Name/share/dir
