EXTENDIN

G

Surcharge de la Résolution de

Répertoire

"File::ShareDir" dispose de deux tableaux de convenience pour les personnes ayant des besoins d'utilisation avancés de "File::ShareDir" tels que l'utilisation de répertoires "share" non installés pendant le

développement. 
#
# Dist-Name => /chemin/absolut/pour/DistName/share/dir
#
%File::ShareDir::DIST_SHARE
#
# Module::Name => /chemin/absolut/pour/Module/Name/share/dir



File::ShareDir::MODULE_SHARE


Establecer estos valores en cualquier momento antes de las llamadas correspondientes


dist_dir('Dist-Name')
dist_file('Dist-Name','some/file');
module_dir('Module::Name');
module_file('Module::Name','some/file');


Anulará el directorio base para resolver esas llamadas.


Un ejemplo de dónde sería útil esto es en una prueba para un módulo
que depende de archivos instalados en un directorio compartido, para permitir que
las pruebas utilicen la copia de desarrollo sin necesidad de instalarlos primero.


use File::ShareDir;
use Cwd qw( getcwd );
use File::Spec::Functions qw( rel2abs catdir );
$File::ShareDir::MODULE_SHARE{'Foo::Module'} = rel2abs(catfile(getcwd,'share'));
use Foo::Module;
# las llamadas internas en Foo::Module a module_file('Foo::Module','bar') ahora se resuelven a
# el directorio share/ del árbol de origen en lugar de algo en @INC
