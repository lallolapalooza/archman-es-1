NOMBRE

fido_dev_get_touch_begin, fido_dev_get_touch_status — esperar asíncronamente por el toque en un autenticador FIDO2

SINOPSIS

#include <fido.h>

int
fido_dev_get_touch_begin(fido_dev_t *dev);

int
fido_dev_get_touch_status(fido_dev_t *dev, int *touched, int ms);

DESCRIPCIÓN

Las funciones descritas en esta página permiten a una aplicación esperar asíncronamente por el toque en un autenticador FIDO2. Esto es útil cuando hay varios autenticadores presentes y la aplicación necesita saber cuál usar.

La función fido_dev_get_touch_begin() inicia una solicitud de toque en dev.

La función fido_dev_get_touch_status() continúa una solicitud de toque en curso en dev, bloqueando hasta ms milisegundos. En caso de éxito, touched se actualizará para reflejar el estado de la solicitud de toque. Si touched es 1, el dispositivo fue tocado y la solicitud de toque se termina. Si touched es 0, la aplicación puede llamar a fido_dev_get_touch_status() para continuar la solicitud de toque, o a fido_dev_cancel() para terminarla.

VALORES DE RETORNO

Los códigos de error devueltos por fido_dev_get_touch_begin() y fido_dev_get_touch_status() están definidos en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

EJEMPLOS

Por favor, consulte examples/select.c en el árbol de fuentes de libfido2.

VER TAMBIÉN

fido_dev_cancel(3)

ADVERTENCIAS

La función fido_dev_get_touch_status() provocará la transmisión de un comando a los autenticadores U2F. Estas transmisiones no deben exceder una frecuencia de 5Hz.
