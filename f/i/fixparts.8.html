FIXPARTS(8) Manual de FixParts FIXPARTS(8)

NOMBRE

fixparts - Utilidad de reparación de tablas de particiones MBR

SINOPSIS

fixparts dispositivo

DESCRIPCIÓN

FixParts (también conocido como fixparts) es un programa de menú en modo texto para reparar ciertos tipos de problemas con las tablas de particiones del Registro de Arranque Maestro (MBR). El programa tiene tres objetivos de diseño, aunque también se admiten algunas características adicionales:

*
Puede eliminar datos residuales de la Tabla de Particiones GUID (GPT), que pueden quedar en un disco que alguna vez se usó como disco GPT pero que luego se convirtió de forma incompleta a la forma MBR (más común a partir de 2011).
*
Puede reparar particiones extendidas de tamaño incorrecto, ya sea particiones que se extienden más allá del final físico del disco o que se superponen con particiones primarias cercanas. FixParts está diseñado de manera que este tipo de reparación ocurre automáticamente, por lo que si ese es el único problema de su disco, puede iniciar el programa y luego guardar la tabla de particiones inmediatamente, sin realizar cambios manuales, y el programa resolverá el problema.
*
Puede cambiar particiones primarias a particiones lógicas o viceversa, dentro de las limitaciones impuestas por las estructuras de datos del MBR.

Las características adicionales incluyen la capacidad de cambiar los códigos de tipo de partición o los indicadores de arranque/activo, eliminar particiones y recalcular los valores CHS. Con la posible excepción de recalcular los valores CHS, estas características secundarias se realizan mejor con fdisk, porque el diseño de fixpartssignifica que es probable que altere la numeración de las particiones incluso cuando no se solicitan tales cambios.

El programa fixparts emplea una interfaz de usuario similar a la de fdiskde Linux, pero fixparts es mucho más especializado. Lo más importante es que no puede crear nuevas particiones con fixparts, aunque puede cambiar la asignación primaria/lógica.

En el esquema MBR, las particiones vienen en tres variedades:

primarias
Estas particiones están definidas en el primer sector del disco duro y están limitadas en número a cuatro. Algunos sistemas operativos, como Windows y FreeBSD, deben arrancar desde una partición primaria.
extendidas
Las particiones extendidas son particiones primarias especializadas. Sirven como áreas de contención para las particiones lógicas.
lógicas
Un disco puede contener un número arbitrario de particiones lógicas(fixparts, sin embargo, impone un límite de 124 particiones lógicas). Todas las particiones lógicas residen dentro de una única partición extendida y se definen utilizando una estructura de datos de lista enlazada. Este hecho significa que cada partición lógica debe ir precedida de al menos un sector de espacio no asignado para contener su estructura de datos definitoria (un Registro de Arranque Extendido, o EBR).

Estas distinciones significan que las particiones primarias y lógicas no pueden estar intercaladas arbitrariamente. Un disco puede contener de una a tres particiones primarias, un bloque de una o más particiones lógicas, y de una a tres particiones primarias más (para un total de tres particiones primarias, sin contar la partición extendida). Las particiones primarias no pueden estar intercaladas entre particiones lógicas, ya que esto significaría colocar una partición primaria dentro de una partición extendida (que es solo un tipo específico de partición primaria).

A diferencia de la mayoría de las utilidades de disco, la interfaz de usuario de fixpartsignora las particiones extendidas. Internamente, el programa descarta la información de la partición extendida original y, cuando le indica que guarde sus cambios, genera una nueva partición extendida para contener las particiones lógicas definidas en ese momento. Esto se hace porque la mayoría de las reparaciones y manipulaciones que realiza la herramienta requieren generar una partición extendida nueva, por lo que mantener la original en la interfaz de usuario solo sería una complicación.

Otra característica inusual de la interfaz de usuario de fixpartses que los números de partición no necesariamente se correlacionan con el estado primario/lógico. En la mayoría de las utilidades, las particiones 1-4 corresponden a particiones primarias, mientras que las particiones 5 en adelante son particiones lógicas. En fixparts, cualquier número de partición puede tener estado primario o lógico, siempre que se obedezcan las reglas de disposición descritas anteriormente. Cuando se guarda la tabla de particiones, las particiones se asignarán adecuadamente y luego herramientas como el kernel de Linux y fdisk les darán números convencionales.

Cuando se inicia por primera vez, fixparts realiza un análisis de datos GPT. Si el disco parece ser un disco GPT convencional, fixparts se niega a ejecutarse. Si el disco parece ser un disco MBR convencional pero hay firmas GPT presentes en las áreas de encabezado primario o secundario GPT, fixparts ofrece eliminar estos datos superfluos. Si le indica que lo haga, el programa borra inmediatamente el encabezado o encabezados GPT. (Si solo se encontró un encabezado, solo se borrará ese encabezado, para minimizar el riesgo de dañar un cargador de arranque u otros datos que puedan haber sobrescrito solo uno de los encabezados GPT).

Con la excepción de borrar opcionalmente los datos GPT residuales cuando se inicia por primera vez, fixparts mantiene todos los cambios en memoria hasta que el usuario escribe los cambios con el comando w . Así, puede ajustar sus particiones en la interfaz de usuario y abortar esos cambios escribiendo q para salir sin guardar los cambios.

OPCIONES

La utilidad fixparts no admite opciones de línea de comandos, excepto la especificación del dispositivo de destino.

La mayoría de las interacciones con fixparts ocurren con su menú interactivo en modo texto. Las funciones específicas son:

a
Alternar el indicador de activo/arranque. Este indicador es requerido por algunos cargadores de arranque y sistemas operativos.
c
Recalcular los valores de cilindro/cabeza/sector (CHS) para todas las particiones. El modo de direccionamiento CHS está en gran medida obsoleto, pero algunos sistemas operativos y utilidades se quejan si no les gustan los valores CHS. Tenga en cuenta que los valores CHS de fixpartsprobablemente sean incorrectos en discos de menos de unos 8 GiB, excepto en Linux.
l
Cambiar el estado de una partición a lógico. Esta opción solo funcionará si la disposición actual de particiones permite dicho cambio. Tenga en cuenta que si cambiar el estado de una partición de esta manera no es posible en este momento, realizar algún otro cambio puede hacerlo posible. Por ejemplo, omitir una partición que precede a la partición de destino puede permitir convertir una partición a forma lógica si no había sectores libres entre las dos particiones.
o
Omitir una partición. Una vez omitida, la partición seguirá apareciendo en la lista de particiones de fixparts , pero se marcará como omitida. Posteriormente puede convertirla a forma primaria o lógica con los comandos r o l , respectivamente. Sin embargo, cuando guarde sus cambios con w, la partición se perderá.
p
Mostrar datos básicos de resumen de la partición. Esto incluye el número de la partición, el estado del indicador de activo/arranque, los números de sector de inicio y fin, el estado primaria/lógica/omitida, si la partición puede convertirse a forma lógica o no, y el código de tipo MBR de la partición.
q
Salir del programa sin guardar sus cambios. Use esta opción si solo quería ver información o si comete un error y quiere deshacer todos sus cambios.
r
Cambiar el estado de una partición a primario. Esta opción solo funcionará si la disposición actual de particiones permite dicho cambio. Tenga en cuenta que teóricamente cualquier partición puede convertirse en una partición primaria, aunque en algunas configuraciones, realizar este cambio requerirá omitir algunas particiones. Si fixparts se niega a permitir cambiar una partición a primaria, puede necesitar convertir otras particiones a forma lógica u omitirlas por completo.
s
Ordenar las entradas de partición. Esta opción ordena las particiones en la visualización para que coincidan con sus posiciones en el disco, lo que puede facilitar la comprensión de la disposición del disco en algunos casos. Esta opción no tiene efecto en el orden final de las particiones lógicas, que se ordenan antes de ser guardadas. El orden de las particiones primarias en la tabla de particiones guardada final puede verse afectado por esta opción. En ambos casos, elComo ya se ha señalado, los números de partición mostrados por fixparts pueden no ser los mismos que los utilizados por el kernel o mostrados por otras herramientas de particionado.
t
Cambia el código de tipo de una partición. Introduzca el código de tipo usando un número hexadecimal de un byte.
w
Escribe los datos. Use este comando para guardar sus cambios y salir del programa.
?
Imprime el menú. Escriba este comando (o cualquier otro comando no reconocido) para ver un resumen de las opciones disponibles.

ERRORES

Los errores y limitaciones conocidos incluyen:

*
El programa solo se compila correctamente en Linux, FreeBSD, Mac OS X y Windows. Se han probado versiones de Linux para x86-64 (64 bits), x86 (32 bits) y PowerPC (32 bits), habiendo sido la versión x86-64 la que más pruebas ha recibido. En FreeBSD, se han probado las versiones de 32 bits (x86) y 64 bits (x86-64). Solo se han probado las versiones de 32 bits para Mac OS X y Windows.
*
La versión del programa para FreeBSD no puede escribir cambios en la tabla de particiones en un disco cuando las particiones existentes en ese disco están montadas. (El mismo problema existe con muchas otras utilidades de FreeBSD, como gpt, fdisky dd.) Esta limitación se puede superar escribiendo sysctl kern.geom.debugflags=16 en un símbolo del sistema.
*
El programa solo puede cargar hasta 128 particiones (4 particiones primarias y 124 particiones lógicas). Este límite se puede aumentar cambiando la línea #define MAX_MBR_PARTS en el archivo de código fuente basicmbr.h y recompilando.
*
El programa solo puede leer particiones si el disco tiene descriptores de partición LBA correctos. Estos descriptores deberían estar presentes en cualquier disco de más de 8 GiB de tamaño o en discos más pequeños particionados con cualquier software que no sea muy antiguo.
*
El programa no hace ningún esfuerzo por preservar los números de partición. Esto puede tener consecuencias para los cargadores de arranque y para el montaje de sistemas de archivos a través de /etc/fstab. Puede ser necesario editar los archivos de configuración o incluso reinstalar su cargador de arranque.
*

El programa puede cambiar el orden de las particiones en la tabla de particiones.
