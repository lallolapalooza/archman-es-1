DESCRIPCIÓ

N

firewalld proporciona un firewall gestionado dinámicamente con soporte para zonas de red/firewall para definir el nivel de confianza de las conexiones o

interfaces de red. Tiene soporte para configuraciones de firewall IPv4, IPv6 y para puentes ethernet, y tiene una separación de las opciones de confi
guración en tiempo de ejecución y permanentes. También soporta una interfaz para que servicios o aplicaciones añadan reglas de firewall directamente.

firewalld:

sale.

g

--debug[=nivel

]
Establece el nivel de depuración para firewalld a nivel. El rango del nivel de depuración es 1 (nivel más bajo) a 10 (nivel más alto). La salida de depuración se escribirá en el archivo de registro de firewalld especificado por
--log-file.

--debug-g

c
Imprime información sobre fugas del recolector de basura. El recolector se ejecuta cada 10 segundos y si hay fugas, imprime información sobre las

Define el destino de salida al que se escriben los mensajes de registro. En modo mixto, Firewalld escribe mensajes de registro de nivel info en syslog. Los mensajes de depuración se escriben en un archivo (vea el parámetro --log-file). Los mensajes de info también van a stdout y stderr. Los modos syslog, archivo o consola escriben todos los mensajes solo al destino

CONCEPTO

S

firewalld tiene una interfaz D-Bus para la configuración del firewall de servicios y aplicaciones. También tiene un cliente de línea de comandos para el usuario. Los servicios o aplicaciones que ya usan D-Bus pueden solicitar cambios al firewall directamente con la interfaz D-Bus. Para más información sobre la interfaz D-Bus de firewalld, por favor eche un vistazo a firewalld.db

us(5).

firewalld proporciona soporte para zonas, servicios predefinidos y tipos ICMP, y tiene una separación de las opciones de configuración en tiempo de ejecución y permanentes. La configuración permanente se carga desde archivos XML en /usr/lib/firewalld (--default-config) o /etc/firewalld (--system-config) (vea la sección llamada “DIRECTORIOS”)

.

Si NetworkManager no está en uso y firewalld se inicia después de que la red ya esté activa, las conexiones y las interfaces creadas manualmente no se vinculan a la zona especificada en el archivo ifcfg. Las interfaces serán gestionadas automáticamente por la zona por defecto. firewalld tampoco recibirá notificaciones sobre cambios de nombre de dispositivos de red. Todo esto también se aplica a interfaces que no están controladas por NetworkManager si NM_CONTROLLED=no está

establecido.

Puede añadir estas interfaces a una zona con firewall-cmd [--permanent] --zone=zona --add-interface=interface. Si existe un archivo /etc/sysconfig/network-scripts/ifcfg-interface, firewalld intentará cambiar la configuración ZONE=zona en este

archivo.

Si firewalld se recarga, restaurará las vinculaciones de interfaz que estaban en vigor antes de la recarga para mantener las vinculaciones de interfaz estables en el caso de interfaces no controladas por NetworkManager. Este mecanismo no es posible en el caso de un reinicio del servicio

firewalld.

Es esencial mantener la configuración ZONE= en el archivo ifcfg consistente con la vinculación en firewalld en el caso de interfaces no controladas por

NetworkManager.

Zona

s

Una zona de red o firewall define el nivel de confianza de la interfaz usada para una conexión. Hay varias zonas predefinidas proporcionadas por firewalld. Las opciones de configuración de zona y la información genérica sobre zonas se describen en firewa

lld.z
one(5)

Servicio

s

Un servicio puede ser una lista de puertos locales, protocolos y destinos y además también una lista de módulos auxiliares de firewall que se cargan automáticamente si un servicio está habilitado. Las opciones de configuración de servicio y la información genérica sobre servicios se describen en firewalld.service(5). El uso de servicios predefinidos facilit

a al usuario habilitar y desh
abilitar el acceso a un servicio.

Tipos

ICMP

El Protocolo de Mensajes de Control de Internet (ICMP) se usa para intercambiar información y también mensajes de error en el Protocolo de Internet (IP). Los tipos ICMP pueden usarse en firewalld para limitar el intercambio de estos mensajes. Para más información, por favor eche un vistazo a firewalld.i

cmpty
pe(5).

Configuración en tiempo de

ejecución

La configuración en tiempo de ejecución es la configuración activa real y no es permanent

e. Después de una recarga/reinicio del servicio o un reinicio del sistema, los ajustes e
n tiempo de ejecución desaparecerán si no estaban también en la configuración permanente.

Configuración

permanente

La configuración permanente se almacena en archivos de configuración y se

cargará y se convertirá en la nueva configuración en tiempo de ejecu
ción con cada arranque de la máquina o recarga/reinicio del servicio.

directa

La interfaz directa es usada principalmente por servicios

o aplicaciones para añadir reglas específicas de firewa
ll. Requiere conocimientos básicos de conceptos de ip(6)tab
les (tablas, cadenas, comandos, parámetros, destinos).

DIRECTORIO

S

firewalld soporta dos directorios de

configuración:

Configuración por defecto/alternativa en /usr/lib/firewalld (--default-config

)

Este directorio contiene la configuración por defecto y alternativa proporcionada por firewalld para icmptypes, servicios y zonas. Los archivos proporcionados con el paquete firewalld no deberían modificarse y los cambios desaparecen con una actualización del paquete firewalld. Se pueden proporcionar icmptypes, servicios y zonas adicionales con paque

tes o creando
archivos.

Ajustes de configuración del sistema en /etc/firewalld (--system-config

)

La configuración del sistema o del usuario almacenada aquí es creada por el administrador del sistema o por personalización con la interfaz de configuración de firewalld o a mano. Los archivos sobrescribirán los archivos de configuración por

defecto.

Para cambiar manualmente ajustes de icmptypes, zonas o servicios predefinidos, copie el archivo del directorio de configuración por defecto al directorio correspondiente en el directorio de configuración del sistema y modifíquelo en

consecuencia.
