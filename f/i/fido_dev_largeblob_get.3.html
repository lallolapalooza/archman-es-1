fido_dev_largeblob_get(3)

NOMBRE

fido_dev_largeblob_get, fido_dev_largeblob_set, fido_dev_largeblob_remove, fido_dev_largeblob_get_array, fido_dev_largeblob_set_array — API de large blob de FIDO2

SINOPSIS

#include <fido.h>

int
fido_dev_largeblob_get(fido_dev_t *dev, const unsigned char *key_ptr, size_t key_len, unsigned char **blob_ptr, size_t *blob_len);

int
fido_dev_largeblob_set(fido_dev_t *dev, const unsigned char *key_ptr, size_t key_len, const unsigned char *blob_ptr, size_t blob_len, const char *pin);

int
fido_dev_largeblob_remove(fido_dev_t *dev, const unsigned char *key_ptr, size_t key_len, const char *pin);

int
fido_dev_largeblob_get_array(fido_dev_t *dev, unsigned char **cbor_ptr, size_t *cbor_len);

int
fido_dev_largeblob_set_array(fido_dev_t *dev, const unsigned char *cbor_ptr, size_t cbor_len, const char *pin);

DESCRIPCIÓN

La API “largeBlobs” de libfido2 permite leer, escribir e inspeccionar blobs binarios que residen en un autenticador CTAP 2.1. “largeBlobs” es una extensión de CTAP 2.1.

Los “largeBlobs” se almacenan como elementos de un array CBOR. La confidencialidad se garantiza cifrando cada elemento con una clave AES-GCM de 256 bits distinta y vinculada a la credencial. El array se comparte entre diferentes credenciales y partes confiables de FIDO2.

La obtención de la clave de cifrado de una credencial es posible durante el registro con fido_cred_set_extensions(3) y fido_cred_largeblob_key_ptr(3), durante la afirmación con fido_assert_set_extensions(3) y fido_assert_largeblob_key_ptr(3), o, en el caso de una credencial residente, a través de la API de gestión de credenciales de libfido2. API de gestión de credenciales de libfido2.

El array CBOR de “largeBlobs” es opaco para el autenticador. La gestión del array queda a discreción de los clientes FIDO2. Para más detalles sobre la extensión “largeBlobs” de CTAP 2.1, consulte la especificación CTAP 2.1.

La fido_dev_largeblob_get() recupera el array CBOR de “largeBlobs” del autenticador y, en caso de éxito, devuelve el primer blob (iterando desde el índice cero del array) que puede ser descifrado por key_ptr, donde key_ptr apunta a key_len bytes. En caso de éxito, fido_dev_largeblob_get() establece blob_ptr al cuerpo del blob descifrado, y blob_len a la longitud del blob descifrado en bytes. Es responsabilidad del llamador liberar blob_ptr.

La fido_dev_largeblob_set() usa key_ptr para cifrar blob_ptr e inserta el resultado en el array CBOR de “largeBlobs” del autenticador. La inserción ocurre al final del array si ningún elemento existente puede ser descifrado por key_ptr, o en la posición del primer elemento (iterando desde el índice cero del array) que puede ser descifrado por key_ptr. key_len contiene la longitud de key_ptr en bytes, y blob_len la longitud de blob_ptr en bytes. Se requiere un pin o un gesto de verificación de usuario equivalente.

La fido_dev_largeblob_remove() recupera el array CBOR de “largeBlobs” del autenticador y, en caso de éxito, elimina el primer blob (iterando desde el índice cero del array) que puede ser descifrado por key_ptr, donde key_ptr apunta a key_len bytes. Se requiere un pin o un gesto de verificación de usuario equivalente.

La fido_dev_largeblob_get_array() recupera el array CBOR de “largeBlobs” del autenticador y, en caso de éxito, establece cbor_ptr al cuerpo del array CBOR y cbor_len a su longitud correspondiente en bytes. Es responsabilidad del llamador liberar cbor_ptr.

Finalmente, la fido_dev_largeblob_set_array() establece el array CBOR de “largeBlobs” del autenticador a los datos a los que apunta cbor_ptr, donde cbor_ptr apunta a cbor_len bytes. Se requiere un pin o un gesto de verificación de usuario equivalente.

VALORES DE RETORNO

Las funciones fido_dev_largeblob_set(), fido_dev_largeblob_get(), fido_dev_largeblob_remove(), fido_dev_largeblob_get_array(), y fido_dev_largeblob_set_array() devuelven FIDO_OK en caso de éxito. En caso de error, se devuelve un código de error definido en <fido/err.h> .

VÉASE TAMBIÉN

fido_assert_largeblob_key_len(3), fido_assert_largeblob_key_ptr(3), fido_assert_set_extensions(3), fido_cred_largeblob_key_len(3), fido_cred_largeblob_key_ptr(3), fido_cred_set_extensions(3), fido_credman_get_dev_rk(3), fido_credman_get_dev_rp(3), fido_dev_get_assert(3), fido_dev_make_cred(3)

ADVERTENCIAS

La extensión “largeBlobs” no está destinada a usarse para almacenar datos sensibles. Cuando se recupera, la clave de cifrado “largeBlobs” de una credencial se transmite en claro, y el array CBOR de “largeBlobs” de un autenticador puede ser leído sin interacción del usuario.acción o verificación.
