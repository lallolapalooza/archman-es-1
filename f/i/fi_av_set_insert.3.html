NOMBRE

fi_av_set - Operaciones de conjunto de vectores de dirección

fi_av_set / fi_close
Abrir o cerrar un conjunto de vectores de dirección
fi_av_set_union
Realizar una operación de unión de conjuntos en dos conjuntos AV
fi_av_set_intersect
Realizar una operación de intersección de conjuntos en dos conjuntos AV
fi_av_set_diff
Realizar una operación de diferencia de conjuntos en dos conjuntos AV
fi_av_set_insert
Añadir una dirección a un conjunto AV
fi_av_set_remove
Eliminar una dirección de un conjunto AV
fi_av_set_addr
Obtener una dirección colectiva para las direcciones actuales en un conjunto AV

SINOPSIS

#include <rdma/fi_collective.h>
int fi_av_set(struct fid_av *av, struct fi_av_set_attr *attr,
      struct fid_av_set **set, void * context);
int fi_av_set_union(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_intersect(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_diff(struct fid_av_set *dst, const struct fid_av_set *src);
int fi_av_set_insert(struct fid_av_set *set, fi_addr_t addr);
int fi_av_set_remove(struct fid_av_set *set, fi_addr_t addr);
int fi_av_set_addr(struct fid_av_set *set, fi_addr_t *coll_addr);
int fi_close(struct fid *av_set);

ARGUMENTOS

av
Vector de direcciones
set
Conjunto de vectores de dirección
dst
Conjunto de vectores de dirección actualizado por la operación de conjunto
src
Conjunto de vectores de dirección que proporciona la entrada a una operación de conjunto
attr
Atributos del conjunto de vectores de dirección
context
Contexto especificado por el usuario asociado con el conjunto de vectores de dirección
flags
Banderas adicionales para aplicar a la operación.
addr
Dirección de destino para insertar o eliminar del conjunto AV.
coll_addr
Dirección que identifica al grupo colectivo.

DESCRIPCIÓN

Un conjunto de vectores de dirección (AV set) representa un subconjunto ordenado de direcciones de un vector de dirección. Los conjuntos AV se utilizan para identificar a los participantes en una operación colectiva. Los puntos finales utilizan la operación fi_join_collective() para asociarse con un conjunto AV. La operación de unión colectiva proporciona una fi_addr que se utiliza al comunicarse con un grupo colectivo.

La creación y manipulación de un conjunto AV es una operación local. No se intercambia tráfico de red entre pares. Como resultado, cada par es responsable de crear conjuntos AV coincidentes como parte de su definición de membresía colectiva. Consulte fi_collective(3) para una discusión de los modelos de membresía.

fi_av_set

La llamada fi_av_set crea un nuevo conjunto AV. Las propiedades iniciales del conjunto AV se especifican a través del parámetro struct fi_av_set_attr. Esta estructura se define a continuación, y permite incluir un subconjunto de direcciones en el conjunto AV como parte de la creación del conjunto AV. Las direcciones pueden añadirse o eliminarse de un conjunto AV utilizando las interfaces del conjunto AV definidas a continuación.

fi_av_set_attr

struct fi_av_set_attr {
    size_t count;
    fi_addr_t start_addr;
    fi_addr_t end_addr;
    uint64_t stride;
    size_t comm_key_size;
    uint8_t *comm_key;
    uint64_t flags;
};
count
Indica el número esperado de miembros que formarán parte del conjunto AV. El proveedor utiliza esto para optimizar las asignaciones de recursos. Si count es 0, el proveedor seleccionará un tamaño basado en los datos de configuración del sistema disponibles o en limitaciones subyacentes.
start_addr / end_addr
Las direcciones de inicio y fin, inclusivas, a incluir como parte del conjunto AV. El uso de las direcciones de inicio y fin requiere que el AV asociado haya sido creado como tipo FI_AV_TABLE. Las direcciones válidas en el AV que caigan dentro del rango especificado y que cumplan otros requisitos (como el stride) se añadirán como miembros iniciales al conjunto AV. El start_addr y end_addr deben establecerse en FI_ADDR_NOTAVAIL si se está creando un conjunto AV vacío, si se está proporcionando una clave de comunicación, o si el AV es de tipo FI_AV_MAP.

El número de direcciones entre start_addr y end_addr debe ser menor o igual al valor de count especificado.

stride
El número de entradas entre direcciones sucesivas incluidas en el conjunto AV. El conjunto AV incluirá todas las direcciones desde start_addr + stride x i, para valores enteros crecientes y no negativos de i, hasta end_addr. Un stride de 1 indica que todas las direcciones entre start_addr y end_addr deben añadirse al conjunto AV. El stride debe establecerse en 0 a menos que los campos start_addr y end_addr sean válidos.
comm_key_size
La longitud de la clave de comunicación en bytes. Este campo debe ser 0 si una clave de comunicación no está disponible.
comm_key
Si la red lo soporta, esto representa una clave asociada con el conjunto AV. La clave de comunicación la utilizan las aplicaciones que gestionan directamente la membresía colectiva a través de un agente de gestión de red o un gestor de recursos. La clave se utiliza para transmitir los resultados de la configuración de la membresía al proveedor subyacente. El uso y el formato de una clave de comunicación son específicos del proveedor de red.
flags
Las banderas pueden utilizarse para configurar el conjunto AV, incluyendo restringir qué operaciones colectivas el conjunto AV necesita soportar. Consulte la sección de banderas para una lista de banderas que pueden especificarse al crear el conjunto AV.

fi_av_set_union

La llamada de unión de conjunto AV añade todas las direcciones del conjunto AV de origen que no están en el conjunto AV de destino al conjunto AV de destino. Donde el orden importa, las direcciones recién insertadas se colocan al final del conjunto AV.

fi_av_set_intersect

La llamada de intersección de conjunto AV elimina todas las direcciones del conjunto AV de destino que no son también miembros del conjunto AV de origen. El orden de las direcciones en el conjunto AV de destino no cambia.

fi_av_set_diff

La llamada de diferencia de conjunto AV elimina todas las direcciones del conjunto AV de destino que también son miembros del conjunto AV de origen. El orden de las direcciones en el conjunto AV de destino no cambia.

fi_av_set_insert

La llamada de inserción de conjunto AV añade la dirección especificada al final de el conjunto AV.

fi_av_set_remove

La llamada de eliminación de conjunto AV elimina la dirección especificada del conjunto AV dado. El orden de las direcciones restantes en el conjunto AV es inalterado.

fi_av_set_addr

Devuelve una dirección que puede utilizarse para comunicarse con todos los miembros actuales de un conjunto AV. Esta es solo una operación local que no implica comunicación de red. La dirección devuelta puede utilizarse como entrada en fi_join_collective. Tenga en cuenta que intentar utilizar la dirección devuelta por fi_av_set_addr (p. ej., pasándola a fi_join_collective) mientras modificar simultáneamente las direcciones almacenadas en un conjunto AV da como resultado un comportamiento indefinido.

fi_close

Cierra un conjunto AV y libera todos los recursos asociados a él. Cualquier operación activa en el momento en que se cierra un conjunto AV será abortada, con el resultado del colectivo indefinido.

BANDERAS

Las siguientes banderas pueden especificarse como parte de la creación de un conjunto AV.

FI_UNIVERSE
Cuando se establece, el conjunto AV se creará conteniendo todas las direcciones almacenadas en el AV correspondiente.
FI_BARRIER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de barrera.
FI_BROADCAST_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de difusión (broadcast).
FI_ALLTOALL_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de todos a todos.
FI_ALLREDUCE_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de reducción global (all reduce).
FI_ALLGATHER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de recolección global (all gather).
FI_REDUCE_SCATTER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de reducción y dispersión (reduce scatter).
FI_REDUCE_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de reducción.
FI_SCATTER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de dispersión.
FI_GATHER_SET
Si se establece, el conjunto AV se configurará para soportar operaciones de recolección.

NOTAS

Los desarrolladores familiarizados con MPI encontrarán que los conjuntos AV son similares a los grupos de MPI, y pueden actuar como un mapeo directo en algunas, pero no en todas, situaciones.

Por defecto, se creará un conjunto AV para soportar todas las operaciones colectivas soportadas por el proveedor subyacente (ver fi_query_collective). Los usuarios pueden reducir los requisitos de recursos especificando solo aquellas operaciones colectivas necesarias para el conjunto AV mediante el uso de banderas de creación: FI_BARRIER_SET, FI_BROADCAST_SET, etc. Si no se especifican tales banderas, el conjunto AV se configurará para soportar cualquiera de las que sean soportadas. Es un error que un usuario solicite una operación colectiva no soportada.

VALORES DE RETORNO

Devuelve 0 en caso de éxito. En caso de error, se devuelve un valor negativo correspondiente al errno de fabric. Los valores de errno de fabric están definidos en rdma/fi_errno.h.
