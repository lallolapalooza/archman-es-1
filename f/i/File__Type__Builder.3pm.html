File::Type::Builder(3) Documentación de Perl contribuida por el usuario File::Type::Builder(3)

NOMBRE

File::Type::Builder - analizar mime-magic y generar código

SINOPSIS

my $build = File::Type::Builder->new();

while (<magic>) {
  chomp;
  my $parsed = $build->parse_magic($_);

  my $code   = $build->string_start($parsed);
  (o string_offset o beshort)

DESCRIPCIÓN

Lee el formato de archivo mime-magic y lo traduce a código. (Esta documentación sería más larga si realmente esperara que alguien que no fuera yo ejecutara el código).

MÉTODOS

new

Crea un nuevo objeto File::Type::Builder.

parse_magic

Desglosa una línea de un archivo mime-magic utilizando una cadena de expresiones regulares.

Se puede encontrar un archivo mime-magic de ejemplo en el CVS de cleancode en http://cleancode.org/cgi-bin/viewcvs.cgi/email/mime-magic.mime?rev=1.1.1.1

string

Construye código para que coincida con la magia de tipo cadena.

Tiene que hacer algunas sutilezas para que la expresión regular funcione correctamente.

be

Construye código para que coincida con la magia 'beshort' y 'belong' (por ejemplo, audio/mpeg, image/jpeg).

MÉTODOS PRIVADOS

_substr_matching

A veces, los datos son más pequeños que el desplazamiento que buscamos en el archivo. Si este es el caso, entonces el archivo obviamente no es de ese tipo y, además, debemos evitar emitir un par de advertencias que Perl emitiría de lo contrario.

Esta subrutina genera este código.

_get_escapes

Devuelve una referencia a un hash que define los caracteres que no deben escaparse.

PENDIENTE

* Añadir manejadores para otros tipos de magia (bedate, byte, etc)

* Hacer que la verbosidad/registro sea más agradable.

* Encontrar más casos extremos.

* Eliminar la comprobación redundante 'if (length $data > 0)'.

A más largo plazo:

* ¿Solución para múltiples formatos de magia?

ERRORES

Incompleto. Algunos problemas conocidos con entradas extrañas en mime-magic. Omite algunas líneas de mime-magic.
