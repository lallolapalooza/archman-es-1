NOMBRE

firewall-config - herramienta de configuración gráfica de firewalld

SINÓPSIS

firewall-config [OPCIONES...]

DESCRIPCIÓN

firewall-config es una herramienta de configuración gráfica para firewalld.

OPCIONES

firewall-config no soporta opciones especiales. Las únicas opciones que se pueden usar son las opciones generales que Gtk utiliza para la inicialización de aplicaciones Gtk. Para más información sobre estas opciones, por favor, consulte la documentación en tiempo de ejecución de Gtk.

Se soportan las siguientes opciones:

-h, --help

Muestra un breve texto de ayuda y sale.
