NOMBRE

fido_dev_enable_entattest, fido_dev_toggle_always_uv, fido_dev_force_pin_change, fido_dev_set_pin_minlen, fido_dev_set_pin_minlen_rpid — API de configuración del autenticador CTAP 2.1

SINOPSIS

#include <fido.h>
#include <fido/config.h>

int
fido_dev_enable_entattest(fido_dev_t *dev, const char *pin);

int
fido_dev_toggle_always_uv(fido_dev_t *dev, const char *pin);

int
fido_dev_force_pin_change(fido_dev_t *dev, const char *pin);

int
fido_dev_set_pin_minlen(fido_dev_t *dev, size_t len, const char *pin);

int
fido_dev_set_pin_minlen_rpid(fido_dev_t *dev, const char * const *rpid, size_t n, const char *pin);

DESCRIPCIÓN

Las funciones descritas en esta página permiten la configuración de un autenticador CTAP 2.1.

La función fido_dev_enable_entattest() habilita la característica de Atestación Empresarial en dev. La Atestación Empresarial instruye al autenticador a incluir información de identificación única en declaraciones de atestación posteriores. El parámetro pin puede ser NULL si dev no tiene un PIN configurado.

La función fido_dev_toggle_always_uv() cambia el estado de la característica "verificación de usuario siempre" en dev. Cuando está activada, esta opción fuerza la verificación del usuario a nivel del autenticador para todas las credenciales conocidas. Si dev soporta U2F (CTAP1) y los métodos de verificación de usuario soportados por el autenticador no permiten la protección de las credenciales U2F, el subsistema U2F será deshabilitado por el autenticador. El parámetro pin puede ser NULL si dev no tiene un PIN configurado.

La función fido_dev_force_pin_change() instruye a dev a requerir un cambio de PIN. Los intentos posteriores de autenticación de PIN contra dev fallarán hasta que su PIN sea cambiado.

La función fido_dev_set_pin_minlen() establece la longitud mínima del PIN de dev a len. Las longitudes mínimas del PIN solo pueden ser aumentadas.

La función fido_dev_set_pin_minlen_rpid() establece la lista de identificadores de partes confiables (RP IDs) que tienen permiso para obtener la longitud mínima del PIN de dev a través de la extensión CTAP 2.1 FIDO_EXT_MINPINLEN. La lista de identificadores de RP está denotada por rpid, un vector de n cadenas UTF-8 terminadas en NUL. Se hace una copia de rpid, y no se conserva ninguna referencia a él o a su contenido. El valor máximo de n soportado por el autenticador se puede obtener usando fido_cbor_info_maxrpid_minpinlen(3).

La configuración se refleja en la carga útil devuelta por el autenticador en respuesta a una llamada a fido_dev_get_cbor_info(3).

VALORES DE RETORNO

Los códigos de error devueltos por fido_dev_enable_entattest(), fido_dev_toggle_always_uv(), fido_dev_force_pin_change(), fido_dev_set_pin_minlen(), y fido_dev_set_pin_minlen_rpid() están definidos en <fido/err.h>. En caso de éxito, se devuelve FIDO_OK.

VER TAMBIÉN

fido_cbor_info_maxrpid_minpinlen(3), fido_cred_pin_minlen(3), fido_dev_get_cbor_info(3), fido_dev_reset(3)
