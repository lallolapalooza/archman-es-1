NOMBRE

File::Type - determinar el tipo de archivo usando magia

SINOPSIS

my $ft = File::Type->new();

# leer datos del archivo en $data, luego
my $type_from_data = $ft->checktype_contents($data);

# alternativamente, verificar archivo desde disco
my $type_from_file = $ft->checktype_filename($file);
# método conveniente para verificar un archivo o datos
my $type_1 = $ft->mime_type($file);
my $type_2 = $ft->mime_type($data);

DESCRIPCIÓN

File::Type utiliza números mágicos (típicamente al principio de un archivo) para determinar el tipo MIME de ese archivo.

File::Type puede usar un nombre de archivo o el contenido del archivo para determinar el tipo de un archivo.

MÉTODOS

new

Devuelve un nuevo objeto File::Type.

mime_type($argument)

Toma datos o un nombre de archivo, determina qué es y pasa el argumento al método relevante a continuación. Si el argumento es un directorio, devuelve undef.

checktype_filename($filename)

Abre $filename (si es posible; si no, devuelve undef) y devuelve el tipo MIME del archivo.

checktype_contents($data)

Compara $data con los criterios de la base de datos mágica y devuelve el tipo MIME del archivo.

PENDIENTE

* Agregar criterios adicionales de coincidencia mágica

ERRORES

Ninguno conocido.

NOTAS

Algunas definiciones mágicas en el archivo mime-magic utilizadas en la creación de este módulo varían de las de otras aplicaciones (por ejemplo, image/x-png en lugar de image/png).

VER TAMBIÉN

File::MMagic y File::MimeInfo realizan el mismo trabajo, pero tienen una serie de problemas que llevaron a la creación de este módulo.

File::MMagic incrusta una copia de la base de datos mágica y utiliza un manejador de archivo DATA, lo que causa problemas al ejecutarse bajo mod_perl.

File::MimeInfo utiliza un archivo mágico externo y se basa en extensiones de archivo en lugar de magia para determinar el tipo MIME.

Como resultado, File::Type utiliza un módulo y un script separados para crear el código central de este módulo, lo que significa que no es necesario incluir una base de datos mágica y que es seguro ejecutarlo bajo mod_perl.

File::Type::Builder, que genera el código en el corazón de este módulo.

AGRADECIMIENTOS

File::Type se basa en un archivo mime-magic de cleancode.org. El original se puede encontrar en http://cleancode.org/cgi-bin/viewcvs.cgi/email/mime-magic.mime?rev=1.1.1.1.
