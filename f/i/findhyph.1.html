NOMBRE

findhyph – encontrar palabras con guiones de TeX en un documento

INSTALACIÓN

Copie findhyph o findhyph.bat (dependiendo del sistema operativo utilizado) a un directorio incluido en la variable PATH del sistema. Se requiere que el intérprete de Perl esté en "/usr/bin/" para sistemas tipo Unix o en PATH cuando se usa findhyph.bat.

SINOPSIS

findhyph [opciones] foo.log

DESCRIPCIÓN

Para usar este programa:

1)
establezca "\tracingparagraphs=1" en un documento TeX foo.tex y ejecute:
2)
tex foo.tex
3)
findhyph [opciones] foo.log

Si está estableciendo "\looseness=<N>" para optimizar párrafos, necesita pasar esa información al archivo foo.log en forma "@looseness=<N>" (en una línea separada). Puede usar una macro como "\def\setlooseness#1{\looseness=#1 \immediate\write-1{@looseness=#1}}" para este propósito. Si el párrafo contiene material en modo de matemática de visualización, necesita usar la macro en todas las partes divididas del párrafo.

OPCIONES

-c
mostrar palabras con guiones en contexto
-f
mostrar selectores de fuente y otras cadenas que comienzan con un carácter de barra invertida
-v
mostrar la versión del programa
-p
generar un archivo que contenga información sobre preposiciones y conjunciones de una sola letra que quedan al final de la línea
-l=STRING
usar las preposiciones/conjunciones listadas en STRING en lugar de la lista predeterminada de preposiciones y conjunciones "kKsSvVzZoOuUiIA" utilizadas para los idiomas eslovaco y checo

ARCHIVOS DE SALIDA

foo.hyph
Lista de palabras con guiones. Todos los caracteres de puntuación, paréntesis y otros caracteres que preceden o siguen inmediatamente a las palabras mostradas se incluyen en esta lista. Las construcciones de TeX que son demasiado difíciles de mostrar ("\hbox{}", "\mark{}", etc.) se muestran como "[]". El modo matemático se indica con el signo "$".

Los números de página entre corchetes se refieren al archivo LOG y pueden diferir ocasionalmente del documento compuesto. La razón es que TeX puede necesitar dividir más párrafos de los que cabrían eventualmente en la página para encontrar un salto de página.

Las palabras con guiones en las notas a pie de página se enumeran antes que las palabras con guiones en el párrafo en el que se hace referencia a la nota a pie de página.

foo.prep
Lista de preposiciones si se usa la opción -p.

HISTORIAL

1.0 (2001-04-08)

•
lanzamiento público

2.0 (2009-08-10)

  • correcciones en el algoritmo de detección de saltos de línea; soporte para el tercer paso del algoritmo de salto de línea en TeX (variable "\emergencystretch" positiva); soporte para saltos discrecionales en el primer paso
  • detección de número de página mejorada (reconoció números de página negativos, números de página compuestos cuando los registros "\count1" a "\count9" no son cero y se usan los formatos "[nn{mapfile}]", "[nn<picture>]" y "[nn<newline>" de pdfTeX; la detección falsa de números de página debería ser mucho menos frecuente)
  • lista configurable de preposiciones y conjunciones
  • las palabras con guiones se pueden mostrar en contexto
  • sugerencias y pruebas de Pavel Stříž
