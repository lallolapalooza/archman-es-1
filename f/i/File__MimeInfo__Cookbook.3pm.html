File::MimeInfo::Cookbook(3) Documentación de Perl aportada por el usuario File::MimeInfo::Cookbook(3)

NOMBRE

File::MimeInfo::Cookbook - varios fragmentos de código

DESCRIPCIÓN

Algunos fragmentos de código para usos no básicos del módulo File::MimeInfo:

Coincidir una extensión
Un archivo no tiene que existir realmente para obtener su mimetype. Esto significa que lo siguiente funcionará: 
mi $extension = '*.txt';
mi $mimetype = mimetype( $extension );
Mimetizar un escalar
Si quieres encontrar el mimetype de un valor escalar, necesitas mimetizado mágico; después de todo, un escalar no tiene nombre de archivo ni inode. Lo que necesitas hacer es usar IO::Scalar: 
usa File::MimeInfo::Magic;
usa IO::Scalar;
mi $io_scalar = new IO::Scalar \$data;
mi $mimetype = mimetype( $io_scalar );

De hecho, la mayoría de los otros objetos "IO::" funcionarán siempre que soporten los métodos seek() y read(). Por supuesto, si quieres que ocurran cosas realmente extrañas, siempre puedes escribir tu propio objeto IO y alimentarlo allí.

Ten en cuenta que al usar un manejador de archivos de esta manera, necesitas establecer el modo binario ":utf8" tú mismo si es apropiado.

Mimetizar un manejador de archivos
Lamentablemente, para manejadores de archivos no buscables como STDIN, simplemente usar un objeto "IO::" no funcionará. Necesitarás almacenar en búfer suficientes datos para un mimetizado correcto. Por ejemplo, podrías mimetizar datos de STDIN de esta manera: 
usa File::MimeInfo::Magic;
usa IO::Scalar;
mi $data;
read(STDIN, $data, $File::MimeInfo::Magic::max_buffer);
mi $io_scalar = new IO::Scalar \$data;
mi $mimetype = mimetype( $io_scalar );

Ten en cuenta que al usar un manejador de archivos de esta manera, necesitas establecer el modo binario ":utf8" tú mismo si es apropiado.

Crear un nuevo nombre de archivo
Supongamos que tienes un archivo temporal que quieres guardar con un nombre de archivo más apropiado. 
usa File::MimeInfo::Magic qw#mimetype extensions#;
usa File::Copy;
mi $tmpfile = '/tmp/foo';
mi $mimetype = mimetype($tmpfile);
mi $extension = extensions($mimetype);
mi $newfile = 'untitled1';
$newfile .= '.'.$extension if length $extension;
move($tmpfile, $newfile);
Forzar el uso de un directorio de base de datos específico
Normalmente, solo necesitas añadir el directorio donde reside tu base de datos de mimes a las variables de entorno XDG_DATA_HOME o XDG_DATA_DIRS para que se encuentre. Pero en algunos casos raros, podrías querer evitar este sistema por completo. Prueba una de las siguientes opciones: 
@File::MimeInfo::DIRS = ('/home/yo/share/mime');
eval 'usa File::MimeInfo';
die if $@;

o:

usa File::MimeInfo;
@File::MimeInfo::DIRS = ('/home/yo/share/mime');
File::MimeInfo->rehash();

Esto también se puede usar para cambiar entre bases de datos en tiempo de ejecución mientras se deja intacta otra configuración XDG.
