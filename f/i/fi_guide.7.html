NOMBRE

fi_guide - guía del programador de libfabric

DESCRIPCIÓN GENERAL

libfabric es un framework de biblioteca de comunicación diseñado para satisfacer los requisitos de rendimiento y escalabilidad de las aplicaciones de computación de alto rendimiento (HPC). libfabric define interfaces de comunicación que permiten un mapeo semántico estrecho entre aplicaciones y servicios de red subyacentes. Específicamente, las interfaces de software de libfabric han sido co-diseñadas con proveedores de hardware de red y desarrolladores de aplicaciones, con un enfoque en las necesidades de los usuarios de HPC.

Esta guía describe la arquitectura e interfaces de libfabric. Debido a la longitud de la guía, se ha dividido en varias páginas. Estas secciones son:

Introducción fi_intro(7)
Esta sección proporciona información sobre la motivación del diseño de libfabric y las características de red subyacentes que se exponen a través de la API.
Arquitectura fi_arch(7)
Esto describe la arquitectura expuesta de libfabric, incluido el modelo de objetos y sus operaciones relacionadas.
Configuración fi_setup(7)
Esto proporciona la configuración y el arranque básicos para usar la API de libfabric.

AUTORES
