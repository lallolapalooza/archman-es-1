[--zone=zone] --list-interfaces

Lista las interfaces que están vinculadas a la zona zone como una lista separada por espacios. Si se omite la zona, se utilizará la zona predeterminada.

[--zone=zone] --add-interface=interface

Vincula la interfaz interface a la zona zone. Si se omite la zona, se utilizará la zona predeterminada.

[--zone=zone] --change-interface=interface

Cambia la zona a la que está vinculada la interfaz interface a la zona zone. Si se omite la zona, se utilizará la zona predeterminada. Si la zona antigua y la nueva son la misma, la llamada se ignorará sin generar un error. Si la interfaz no ha estado vinculada a una zona antes, se comportará como --add-interface.

Opciones para manejar las vinculaciones de fuentes

Vincular una fuente a una zona significa que la configuración de esta zona se utilizará para restringir el tráfico de esta fuente.

Una dirección de origen o un rango de direcciones es una dirección IP o una dirección IP de red con una máscara para IPv4 o IPv6, o una dirección MAC, o un ipset con el prefijo ipset:. Para IPv4, la máscara puede ser una máscara de red o un número simple. Para IPv6, la máscara es un número simple. No se admite el uso de nombres de host.

Las opciones de esta sección afectan solo a una zona en particular. Si se utilizan con la opción --zone=zone , afectan a la zona zone. Si se omite la opción, afectan a la zona predeterminada (véase --get-default-zone).

Para obtener una lista de zonas predefinidas, utilice firewall-cmd --get-zones.

[--zone=zone] --list-sources

Lista las fuentes que están vinculadas a la zona zone como una lista separada por espacios. Si se omite la zona, se utilizará la zona predeterminada.

[--zone=zone] --add-source=source[/mask]|MAC|ipset:ipset

Vincula la fuente a la zona zone. Si se omite la zona, se utilizará la zona predeterminada.

[--zone=zone] --change-source=source[/mask]|MAC|ipset:ipset

Cambia la zona a la que está vinculada la fuente a la zona zone. Si se omite la zona, se utilizará la zona predeterminada. Si la zona antigua y la nueva son la misma, la llamada se ignorará sin generar un error. Si la fuente no ha estado vinculada a una zona antes, se comportará como --add-source.

[--zone=zone] --query-source=source[/mask]|MAC|ipset:ipset

Consulta si la fuente está vinculada a la zona zone. Devuelve 0 si es cierto, 1 en caso contrario.

[--zone=zone] --remove-source=source[/mask]|MAC|ipset:ipset

Elimina la vinculación de la fuente de la zona zone. Si se omite la zona, se utilizará la zona predeterminada.

Opciones Directas

OBSOLETO

La interfaz directa ha quedado obsoleta. Será eliminada en una versión futura. Ha sido reemplazada por políticas, ver firewalld.policies(5).

Las opciones directas proporcionan un acceso más directo al cortafuegos. Estas opciones requieren que el usuario conozca conceptos básicos de iptables, es decir, table (filter/mangle/nat/...), chain (INPUT/OUTPUT/FORWARD/...), commands (-A/-D/-I/...), parameters (-p/-s/-d/-j/...) y targets (ACCEPT/DROP/REJECT/...).

Las opciones directas deberían usarse solo como último recurso cuando no sea posible usar, por ejemplo, --add-service=service o --add-rich-rule='rule'.

Advertencia: El comportamiento de las reglas directas es diferente dependiendo del valor de FirewallBackend. Ver CAVEATS en firewalld.direct(5).

El primer argumento de cada opción debe ser ipv4 o ipv6 o eb. Con ipv4 será para IPv4 (iptables(8)), con ipv6 para IPv6 (ip6tables(8)) y con eb para puentes ethernet (ebtables(8)).

--direct --get-all-chains

Obtener todas las cadenas agregadas a todas las tablas.

Esta opción concierne solo a cadenas previamente agregadas con --direct --add-chain.

--direct --get-chains { ipv4 | ipv6 | eb } table

Obtener todas las cadenas agregadas a la tabla table como una lista separada por espacios.

Esta opción concierne solo a cadenas previamente agregadas con --direct --add-chain.

--direct --add-chain { ipv4 | ipv6 | eb } table chain

Agregar una nueva cadena con el nombre chain a la tabla table.

Ya existen cadenas básicas para usar con las opciones directas, por ejemplo la cadena INPUT_direct (ver la salida de iptables-save | grep direct para todas ellas). Estas cadenas se saltan antes que las cadenas de zonas, es decir, cada regla puesta en INPUT_direct será comprobada antes que las reglas en las zonas.

--direct --remove-chain { ipv4 | ipv6 | eb } table chain

Eliminar la cadena con el nombre chain de la tabla table.

--direct --query-chain { ipv4 | ipv6 | eb } table chain

Devolver si existe una cadena con el nombre chain en la tabla table. Devuelve 0 si es verdadero, 1 en caso contrario.

Esta opción concierne solo a cadenas previamente agregadas con --direct --add-chain.

--direct --get-all-rules

Obtener todas las reglas agregadas a todas las cadenas en todas las tablas como una lista separada por saltos de línea de la prioridad y los argumentos.

--direct --get-rules { ipv4 | ipv6 | eb } table chain

Obtener todas las reglas agregadas a la cadena chain en la tabla table como una lista separada por saltos de línea de la prioridad y los argumentos.

--direct --add-rule { ipv4 | ipv6 | eb } table chain priority args

Agregar una regla con los argumentos args a la cadena chain en la tabla table con la prioridad priority.

La priority se usa para ordenar las reglas. La prioridad 0 significa agregar la regla en la parte superior de la cadena, con una prioridad mayor la regla se agregará más abajo. Las reglas con la misma prioridad están en el mismo nivel y el orden de estas reglas no es fijo y puede cambiar. Si quieres asegurarte de que una reglal be added after another one, use a low priority for the first and a higher for the following.

--direct --remove-rule { ipv4 | ipv6 | eb } table chain priority args

Elimina una regla con prioridad y los argumentos args de la cadena chain en la tabla table.

--direct --remove-rules { ipv4 | ipv6 | eb } table chain

Elimina todas las reglas en la cadena con el nombre chain que existe en la tabla table.

Esta opción se refiere solo a las reglas añadidas previamente con --direct --add-rule en esta cadena.

--direct --query-rule { ipv4 | ipv6 | eb } table chain priority args

Devuelve si existe una regla con prioridad y los argumentos args en la cadena chain en la tabla table. Devuelve 0 si es cierto, 1 en caso contrario.

--direct --get-all-passthroughs

Obtiene todos los passthrough permanentes como una lista separada por saltos de línea del valor ipv y los argumentos.

--direct --get-passthroughs { ipv4 | ipv6 | eb }

Obtiene todas las reglas de passthrough permanentes para el valor ipv como una lista separada por saltos de línea de la prioridad y los argumentos.

--direct --add-passthrough { ipv4 | ipv6 | eb } args

Añade una regla de passthrough permanente con los argumentos args para el valor ipv.

--direct --remove-passthrough { ipv4 | ipv6 | eb } args

Elimina una regla de passthrough permanente con los argumentos args para el valor ipv.

--direct --query-passthrough { ipv4 | ipv6 | eb } args

Devuelve si existe una regla de passthrough permanente con los argumentos args para el valor ipv. Devuelve 0 si es cierto, 1 en caso contrario.
