NOMBRE

File::HomeDir::Darwin - Encuentra tu directorio personal y otros directorios en Darwin (OS X)

DESCRIPCIÓN

Este módulo proporciona implementaciones específicas de Darwin para determinar directorios comunes de usuario. En uso normal, este módulo siempre se utilizará a través de File::HomeDir.

Nota: dado que este módulo requiere Mac::Carbon y Mac::Carbon no funciona con Perl de 64 bits, en tales sistemas, File::HomeDir intentará usar File::HomeDir::Darwin::Cocoa y luego recurrirá a File::HomeDir::Darwin (escrito puramente en Perl).

SINOPSIS

use File::HomeDir;
# Encuentra directorios para el usuario actual
$home    = File::HomeDir->my_home;      # /Users/mi_login
$desktop = File::HomeDir->my_desktop;   # /Users/mi_login/Desktop
$docs    = File::HomeDir->my_documents; # /Users/mi_login/Documents
$music   = File::HomeDir->my_music;     # /Users/mi_login/Music
$pics    = File::HomeDir->my_pictures;  # /Users/mi_login/Pictures
$videos  = File::HomeDir->my_videos;    # /Users/mi_login/Movies
$data    = File::HomeDir->my_data;      # /Users/mi_login/Library/Application Support
