NOMBRE

fixcvsdiff - corrige archivos diff problemáticos

SINOPSIS

fixcvsdiff [-p] [-b] [archivo...]

DESCRIPCIÓN

fixcvsdiff modifica archivos diff creados desde el comando cvs diff, donde se han añadido o eliminado archivos. CVS tiende a crear archivos diff que patch(1) malinterpreta. El archivo diff debe conservar las líneas que comienzan con “Index:” para que la corrección funcione.

OPCIONES

-b

Conserva un archivo de copia de seguridad .bak.

-p

Imprime los comandos cvs add y cvs remove que deben ejecutarse después de aplicar el diff, pero antes de ejecutar cvs commit.

VER TAMBIÉN

diff(1), patch(1), cvs(1)
