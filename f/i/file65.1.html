FILE65(1) Manual de comandos generales FILE65(1)

NOMBRE

file65 - imprime información para archivos objeto o65

SINOPSIS

file65 [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

file65 imprime información de archivo para archivos en el formato objeto o65.

OPCIONES

-v
Imprime etiquetas indefinidas y globales.
-vv
Imprime etiquetas indefinidas y globales, y tablas de reubicación.
-P
Imprime las direcciones de fin de segmento (adecuado para el parámetro de línea de comandos -b del comando xa(1)).
-a offset
Imprime el parámetro "ROMmable" de xa(1) para otro archivo detrás de este en la misma ROM, ubicado en el offset especificado.
-A offset
Hace lo mismo que -a pero solo imprime la dirección de inicio del siguiente archivo en la ROM.
--help
Muestra un resumen de las opciones.
--version
Muestra la versión del programa.

VER TAMBIÉN
