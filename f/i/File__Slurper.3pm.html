NOMBRE

File::Slurper - Un módulo simple, sensato y eficiente para "tragar" un archivo

VERSIÓN

versión 0.014

SINOPSIS

use File::Slurper 'read_text';
my $content = read_text($filename);

DESCRIPCIÓN

Este módulo proporciona funciones para "tragar" y "escupir" archivos de forma rápida y correcta. Todas las funciones se exportan opcionalmente. Todas las funciones lanzan excepciones en caso de error, las funciones de escritura no devuelven ningún valor significativo.

FUNCIONES

read_text($filename, $encoding, $crlf)

Lee el archivo $filename en un escalar y lo decodifica desde $encoding (que por defecto es UTF-8). Si $crlf es verdadero, se realiza la traducción de crlf. El valor por defecto para este argumento está desactivado. El valor especial 'auto' lo establecerá en un valor por defecto específico de la plataforma.

read_binary($filename)

Lee el archivo $filename en un escalar sin ninguna decodificación o transformación.

read_lines($filename, $encoding, $crlf, $skip_chomp)

Lee el archivo $filename en una lista/array línea por línea, después de decodificarlo desde $encoding, traducción opcional de crlf y "chomp". Siempre usará una nueva línea como separador.

write_text($filename, $content, $encoding, $crlf)

Escribe $content al archivo $filename, codificándolo a $encoding (que por defecto es UTF-8). También puede tomar un argumento "crlf" que funciona exactamente igual que en read_text.

write_binary($filename, $content)

Escribe $content al archivo $filename como datos binarios.

read_dir($dirname)

Abre el directorio "dirname" y devuelve todas las entradas excepto "." y "..".

RACIÓNALE

Este módulo intenta hacer lo más fácil posible leer y escribir archivos de forma correcta y rápida. La forma más correcta de hacer esto no siempre es obvia (por ejemplo, #83126 https://rt.cpan.org/Public/Bug/Display.html?id=83126), y tan a menudo la forma correcta más obvia no es la forma correcta más rápida. Este módulo oculta todas estas complicaciones detrás de una interfaz intuitiva y fácil.

DEPENDENCIA

Este módulo tiene una dependencia opcional de PerlIO::utf8_strict. Instalar esto hará que la E/S codificada en UTF-8 sea significativamente más rápida, pero no debería afectar de otra manera la operación de este módulo. Esto puede convertirse en una dependencia de Unicode::UTF8 relacionado en el futuro.

VER TAMBIÉN

  • Path::Tiny

    Una abstracción minimalista que maneja no solo E/S sino también rutas.

  • IO::All

    Un intento de exponer tantas características relacionadas con E/S como sea posible a través de una única API.

  • File::Slurp

    Este es un módulo de "tragar" archivos de generación anterior. Tiene una serie de problemas, como se describe aquí http://blogs.perl.org/users/leon_timmermans/2015/08/fileslurp-is-broken-and-wrong.html.

  • File::Slurp::Tiny

    Este fue mi intento anterior de un mejor módulo para "tragar" archivos. Es mayormente (pero no enteramente) un reemplazo directo para File::Slurp, lo cual es tanto una característica (conversión fácil) como un error (problemas de interfaz).
