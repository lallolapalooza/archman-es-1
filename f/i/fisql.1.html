usa la API DB-Library proporcionada por FreeTDS. Fue implementado primero usando la propia biblioteca de Sybase y continúa funcionando con ella. Antes (y después) de modificarlo, sería bueno probarlo con la biblioteca de Sybase para asegurar la

compatibilidad entre ella y FreeTDS. ESTADO DE SALIDA

fisql sale con 0 en éxito, y >0 si el servidor no puede procesar la consulta. fisql reportará cualquier error devuelto por el servidor, pero continuará procesando. En un entorno de producción, este comportamiento puede ser insuficientemente estricto. Para hacerlo extremadamente intolerante de errores, cambie los manejadores de mensajes y errores para que llamen a

exit(3).
