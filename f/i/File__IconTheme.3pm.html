File::IconTheme(3) Documentación de Perl aportada por el usuario File::IconTheme(3)

NOMBRE

File::IconTheme - Buscar directorios de iconos

VERSIÓN

versión 0.09

SINOPSIS

use File::IconTheme qw(xdg_icon_theme_search_dirs);
print join "\n", xdg_icon_theme_search_dirs;

DESCRIPCIÓN

Este módulo se puede utilizar para encontrar directorios según lo especificado por la Especificación de Temas de Iconos de Freedesktop.org. Actualmente, solo se implementa una parte pequeña (pero muy útil) de la especificación.

En caso de que desee almacenar un tema de iconos, utilice el directorio devuelto por:

use File::BaseDir qw(data_dirs);
print scalar data_dirs('icons');

FUNCIONES

Se puede exportar bajo petición.

xdg_icon_theme_search_dirs

my @dirs = xdg_icon_theme_search_dir;

Devuelve una lista de los directorios base de los temas de iconos.

CONFIGURACIÓN Y ENTORNO

$XDG_DATA_HOME, $XDG_DATA_DIRS

VER TAMBIÉN

http://standards.freedesktop.org/icon-theme-spec/
