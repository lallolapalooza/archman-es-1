FILECAP:(8) Utilidades de Administración del Sistema FILECAP:(8)

NOMBRE

filecap - un programa para ver capacidades

SINOPSIS

filecap [ -a | -d | /dir | /dir/file [cap1 cap2 ...] ]

DESCRIPCIÓN

filecap es un programa que imprime un informe de programas con capacidades basadas en archivos. Si un archivo no está en el informe o no hay ningún informe, no se encontraron capacidades. Por conveniencia, el predeterminado es verificar solo los directorios en la variable de entorno PATH. Si se proporciona la opción de línea de comandos -a, se verificarán todos los directorios. Si se pasa un directorio, se verificará recursivamente ese directorio. Si se proporciona una ruta a un archivo, solo se verificará ese archivo. Si se proporciona un archivo seguido de capacidades, estas se escribirán en el archivo.

OPCIONES

-a
Esto le indica al programa que muestre todas las capacidades comenzando desde el directorio /. Normalmente, la variable de entorno PATH se utiliza para mostrarle las capacidades en archivos que probablemente ejecute.
-d
Esto vuelca todas las capacidades como referencia.

EJEMPLOS

Para verificar las capacidades de archivos en $PATH:
filecap
Para verificar las capacidades de archivos de todo el sistema:
filecap -a
Para verificar las capacidades de archivos recursivamente en un directorio:
filecap /usr
Para verificar las capacidades de archivos de un programa específico:
filecap /bin/passwd
Para listar todas las capacidades posibles:
filecap -d
Para establecer una capacidad de archivo en un programa específico:
filecap /bin/ping net_raw net_admin
Para eliminar las capacidades de archivo en un programa específico:
filecap /bin/ping none

VER TAMBIÉN

pscap(8), netcap(8), capabilities(7).
