NOMBRE

fi_mrail - El Proveedor de Utilidad Multi-Rail

DESCRIPCIÓN GENERAL

El proveedor mrail (ofi_mrail) es un proveedor de utilidad que se superpone a un proveedor subyacente para permitir el uso de múltiples puertos de red (rails). Esto aumenta el ancho de banda total disponible de un proveedor subyacente. El estado actual del proveedor mrail es experimental: no todas las características de libfabric son compatibles y el rendimiento no está garantizado.

REQUISITOS

Requisitos para el proveedor subyacente

El proveedor mrail requiere que el proveedor subyacente sea compatible con las siguientes capacidades / modos:

•
Recepción en búfer (FI_BUFFERED_RECV)
•
FI_SOURCE
•
FI_AV_TABLE

Requisitos para las aplicaciones

Las aplicaciones necesitan: * Ser compatibles con el bit de modo FI_MR_RAW MR para hacer uso de la capacidad FI_RMA. * Establecer la variable de entorno FI_OFI_MRAIL_ADDR (ver sección PARÁMETROS EN TIEMPO DE EJECUCIÓN a continuación).

CARACTERÍSTICAS COMPATIBLES

Tipos de endpoint
El proveedor solo admite FI_EP_RDM.
Capacidades de endpoint
Se admite la siguiente interfaz de transferencia de datos: FI_MSG, FI_TAGGED, FI_RMA.
# LIMITACIONES
Las limitaciones del proveedor subyacente pueden manifestarse como las del proveedor mrail. El proveedor mrail no permite la transferencia directa de ningún bit de modo al proveedor subyacente.

Características no compatibles

Las siguientes son las principales características de libfabric que no son compatibles. Cualquier otra característica no enumerada en "Características compatibles" puede considerarse no compatible.

•
FI_ATOMIC
•
Endpoints escalables
•
Contextos compartidos
•
FABRIC_DIRECT
•
Multicast
•
Operaciones activadas

DESCRIPCIÓN GENERAL DE LA FUNCIONALIDAD

Para mensajes (FI_MSG, FI_TAGGED), el proveedor utiliza diferentes políticas para enviar mensajes a través de uno o varios rails basándose en el tamaño del mensaje (ver FI_OFI_MRIAL_CONFIG en la sección PARÁMETROS EN TIEMPO DE EJECUCIÓN). El orden se garantiza mediante el uso de números de secuencia.

Para RMA, los datos se distribuyen por igual entre todos los rails.

PARÁMETROS EN TIEMPO DE EJECUCIÓN

El proveedor ofi_mrail comprueba las siguientes variables de entorno.

FI_OFI_MRAIL_ADDR
Lista de direcciones de rails individuales separadas por comas. Cada dirección puede ser una dirección en formato FI_ADDR_STR, un nombre de host, una dirección IP o un nombre de interfaz de red.
FI_OFI_MRAIL_ADDR_STRC
Obsoleto. Reemplazado por FI_OFI_MRAIL_ADDR.
FI_OFI_MRAIL_CONFIG
Lista separada por comas de pares <tamaño_máx>:<política>, ordenados en orden ascendente de <tamaño_máx>. Cada par indica la política de distribución de rails que se utilizará para mensajes de hasta el tamaño <tamaño_máx> y que no están cubiertos por todos los pares anteriores. El valor de <política> puede ser fixed (se usa un rail fijo), round-robin (un rail por mensaje, seleccionado en modo round-robin) o striping (distribución en todos los rails). La configuración predeterminada es 16384:fixed,ULONG_MAX:striping. El valor ULONG_MAX se puede introducir como -1.
