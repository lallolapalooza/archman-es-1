ros módulos File::Spec, como File::Spec::Mac, heredan

canonpath
()
Sin comprobación física en el sistema de archivos, pero una limpieza lógica de una ruta. En UNIX elimina barras diagonales sucesivas y "/." sucesivos. 
$cpath = File::Spec->canonpath( $path
) ;

Ten en cuenta que esto *no* colapsa secciones x/../y en y. Esto es por diseño. Si /foo en tu sistema es un enlace simbólico a /bar/baz, entonces /foo/../quux es en realidad /bar/quux, no /quux como una eliminación ingenua de ../ te daría. Si quieres hacer este tipo de procesamiento, probablemente quieras la función "Cwd"'s realpath() para recorrer realmente el sist

ema de archivos limpi
ando rutas como esta.

splitpa
th 
($volume,$directories,$file) = File::Spec->splitpath( $path );
($volume,$directories,$file) = File::Spec->splitpath( $path,
                                                      $no_file
);

Divide una ruta en porciones de volumen, directorio y nombre de archivo. En sistemas sin concepto de volumen, devuelve '' para el

volumen.

Para sistemas sin sintaxis que diferencie nombres de archivo de directorios, asume que el último archivo es una ruta a menos que $no_file sea verdadero o haya un separador final o /. o /.. presente. En Unix esto significa que $no_file verdadero hace que esto devuelva ( '', $path,

'' ).

La porción del directorio puede o no devolverse con una barra diagonal '/'

final.

Los resultados pueden pasarse a "catpath()" para obtener de vuelta una ruta equiva

lente a (usualmente idént
ica a) la ruta original.
splitd
ir
Lo opuesto de "catdir()". 
@dirs = File::Spec->splitdir( $directories

$directories debe ser solo la porción del directorio de la ruta en sistemas que tienen el concepto de un volumen o que tienen sintaxis de ruta que diferencia archivos de

A diferencia de simplemente dividir los directorios por el separador, se pueden devolver nombres de directorio vacíos (''), porque estos son significativos en algunos sistemas

catpath
()
Toma las porciones de volumen, directorio y archivo y devuelve una ruta completa. Bajo Unix, $volume se ignora, y directorio y archivo se concatenan. Se inserta una '/' si es necesaria (aunque si la porción del directorio no comienza con '/' no se añade). En otros sistemas operativos, $volume es
significativo.
abs2r
el
Toma una ruta de destino y una ruta base opcional y devuelve una ruta relativa desde la ruta base hasta la ruta de destino: 
$rel_path = File::Spec->abs2rel( $path ) ;
$rel_path = File::Spec->abs2rel( $path, $base
) ;

Si $base no está presente o es '', entonces se usa cwd(). Si $base es relativa, entonces se convierte a forma absoluta usando "rel2abs()". Esto significa que se considera relativa a cwd(

).

En sistemas que tienen una gramática que indica nombres de archivo, esto ignora el nombre de archivo $base. De lo contrario, se asume que todos los componentes de la ruta son

directorios.

Si $path es relativa, se convierte a forma absoluta usando "rel2abs()". Esto significa que se considera relativa a cwd(

).

No se realizan comprobaciones contra el sistema de archivos, por lo que el resultado puede no ser correcto si $base contiene enlaces simbólicos. (Aplica Cwd::abs_path() previamente si eso es una preocupación.) En VMS, hay interacción con el entorno de trabajo, ya que los lógicos y macros se

expanden.

Basado en códig

o escrito por Sh
igio Yamaguchi.

Si $base no está presente o es '', entonces se usa cwd(). Si $base es relativa, entonces se convierte a forma absoluta usando "rel2abs()". Esto significa que se considera relativa a cwd(
