FindBin(3perl) Guía de referencia del programador de Perl FindBin(3perl)

NOMBRE

FindBin - Localiza el directorio del script Perl original

SINOPSIS

use FindBin;
use lib "$FindBin::Bin/../lib";
use FindBin qw($Bin);
use lib "$Bin/../lib";

DESCRIPCIÓN

Localiza la ruta completa al directorio de binarios del script para permitir el uso de rutas relativas al directorio de binarios.

Esto permite a un usuario configurar un árbol de directorios para algún software con los directorios "<raíz>/bin" y "<raíz>/lib", y entonces el ejemplo anterior permitirá el uso de módulos en el directorio lib sin saber dónde está instalado el árbol de software.

Si "perl" se invoca usando la opción "-e" o el script Perl se lee de "STDIN", entonces "FindBin" establece tanto $Bin como $RealBin al directorio actual.

VARIABLES EXPORTABLES

$Bin o $Dir
Ruta al directorio de binarios desde donde se invocó el script
$Script
Nombre base del script desde el cual se invocó "perl"
$RealBin o $RealDir
$Bin con todos los enlaces resueltos
$RealScript
$Script con todos los enlaces resueltos

También puede usar la etiqueta "ALL" para exportar todas las variables anteriores juntas:

use FindBin ':ALL';

PROBLEMAS CONOCIDOS

Si hay dos módulos que usan "FindBin" desde directorios diferentes bajo el mismo intérprete, esto no funcionará. Dado que "FindBin" usa un bloque "BEGIN", se ejecutará solo una vez, y solo el primer invocador lo hará correctamente. Este es un problema bajo "mod_perl" y otros entornos Perl persistentes, donde no debería usar este módulo. Lo que también significa que debería evitar usar "FindBin" en módulos que planea poner en CPAN. Llame a la función "again" para asegurarse de que "FindBin" funcionará:

use FindBin;
FindBin::again(); # o FindBin->again;

En versiones anteriores de "FindBin" no existía la función "again". La solución alternativa era forzar la ejecución del bloque "BEGIN" de nuevo:

delete $INC{'FindBin.pm'};
require FindBin;
