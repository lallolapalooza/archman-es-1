NOMBRE

fi_fabric - Operaciones de red de fabric

fi_fabric / fi_close
Abrir / cerrar una red de fabric
fi_tostr / fi_tostr_r
Convertir atributos, flags y capacidades de fabric en una cadena imprimible

SINOPSIS

#include <rdma/fabric.h>
int fi_fabric(struct fi_fabric_attr *attr,
    struct fid_fabric **fabric, void *context);
int fi_close(struct fid *fabric);
char * fi_tostr(const void *data, enum fi_type datatype);
char * fi_tostr_r(char *buf, size_t len, const void *data,
    enum fi_type datatype);

DESCRIPCIÓN

Se utiliza un identificador de fabric para referenciar recursos de fabric abiertos y objetos relacionados con la biblioteca.

La red de fabric representa una colección de recursos de hardware y software que acceden a una única red física o virtual. Todos los puertos de red en un sistema que pueden comunicarse entre sí a través de sus redes conectadas pertenecen al mismo fabric. Una red de fabric comparte direcciones de red y puede abarcar múltiples proveedores. Una aplicación debe abrir una red de fabric antes de asignar otros recursos de red, como puntos de comunicación.

fi_fabric

Abre un proveedor de red de fabric. Los atributos del proveedor de fabric se especifican a través de la llamada de apertura, y pueden obtenerse llamando a fi_getinfo.

fi_close

La llamada fi_close se utiliza para liberar todos los recursos asociados con un objeto fabric. Todos los elementos asociados con el fabric abierto deben liberarse antes de llamar a fi_close.

fi_tostr / fi_tostr_r

Convierte los atributos de interfaz de fabric, capacidades, flags y valores enum en una cadena imprimible. El parámetro data acepta un puntero al atributo o valor(es) a mostrar, con el parámetro datatype indicando el tipo de datos referenciado por el parámetro data. fi_tostr() devolverá un puntero a un buffer interno de libfabric que no debe ser modificado, y será sobrescrito la próxima vez que se invoque fi_tostr(). fi_tostr() no es seguro en entornos multihilo.

La función fi_tostr_r() es una versión reentrante y segura en entornos multihilo de fi_tostr(). Escribe la cadena en un buffer proporcionado por el llamador. fi_tostr_r() devuelve el inicio del buffer del llamador.

NOTAS

Los siguientes recursos están asociados con los dominios de fabric: dominios de acceso, puntos de acceso pasivos y colas de eventos de CM.

ATRIBUTOS DE FABRIC

La estructura fi_fabric_attr define el conjunto de atributos asociados con un fabric y un proveedor de fabric.

struct fi_fabric_attr {
    struct fid_fabric *fabric;
    char              *name;
    char              *prov_name;
    uint32_t          prov_version;
    uint32_t          api_version;
};
