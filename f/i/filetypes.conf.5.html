NOMBRE

filetypes.conf - la configuración de tipos de archivo de highlight

DESCRIPCIÓN

Este archivo de configuración contiene extensiones de nombre de archivo y patrones shebang que se mapean a las definiciones de sintaxis de highlight.

Si solo hay una extensión, simplemente nombre el archivo de idioma correspondientemente y funcionará (no se necesita ninguna entrada en este archivo).

Las entradas de tipo de archivo en gui_files/ext/fileopenfilter.conf también deben actualizarse.

Las extensiones se pueden configurar para varios idiomas (ver "asm", que se asigna a assembler y fasm).

La línea de comandos (CLI) y las compilaciones de GUI Qt manejan las asignaciones ambiguas de la siguiente manera:

- CLI: se utilizará la primera asociación que se enumera aquí

- GUI: se mostrará un aviso de selección de sintaxis

Si un nombre de archivo no tiene extensión por convención (por ejemplo, makefile), puede agregarse aquí de todos modos o configurarse como "Shebang".

Ubicación: El primer filetypes.conf encontrado en un directorio de búsqueda de highlight gana.

Es fácilmente posible mejorar la base de datos de lenguajes de programación y temas de color de highlight. Consulte el archivo README para obtener detalles.

EJEMPLO DE MAPEADO DE EXTENSIÓN

{ Lang='purebasic', Extensions={'pb', 'pbi'} }

EJEMPLO DE MAPEADO DE SHEBANG

{ Lang='xml', Shebang=[[^\s*<\?xml\s+version='1.0'\s+[^(\?>)]*?>\s*$]] }
