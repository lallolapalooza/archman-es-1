NOMBRE

File::HomeDir::MacOS9 - Encuentra tu directorio personal y otros directorios en sistemas Macintosh heredados

SINOPSIS

use File::HomeDir;

# Encuentra directorios para el usuario actual
$home    = File::HomeDir->my_home;
$desktop = File::HomeDir->my_desktop;

DESCRIPCIÓN

Este módulo proporciona implementaciones para determinar directorios comunes de usuario en hosts Mac heredados. En el uso normal, este módulo siempre se utilizará a través de File::HomeDir.

Este módulo ya no se mantiene activamente y solo se incluye para una compatibilidad retroactiva extrema.

Solo se admiten los métodos "my_home" y "my_desktop".
