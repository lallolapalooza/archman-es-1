File::Find::Rule::Perl(3) Documentación de Perl aportada por el usuario File::Find::Rule::Perl(3)

NOMBRE

File::Find::Rule::Perl - Reglas comunes para buscar cosas de Perl

SINOPSIS

use File::Find::Rule       ();
use File::Find::Rule::Perl ();

# Busca todos los archivos Perl de menos de 10k
my @files = File::Find::Rule->perl_file
                            ->size('<10Ki')
                            ->in('dir');

# Localiza todos los módulos que PAUSE indexará
my @mod = File::Find::Rule->no_index
                          ->perl_module
                          ->in('My-Distribution');

DESCRIPCIÓN

Escribo muchas cosas que manipulan archivos Perl. Y siempre me molestó que encontrar "archivos Perl" requiera un patrón de File::Find::Rule moderadamente complejo.

File::Find::Rule::Perl proporciona métodos para encontrar varios tipos de archivos relacionados con Perl, o para replicar consultas de búsqueda ejecutadas en una distribución en varias partes del ecosistema CPAN.

MÉTODOS

perl_module

La regla "perl_module" localiza módulos Perl. Es decir, archivos que se nombran "*.pm".

Esta regla es equivalente a "->"file->name( '*.pm' )> y se incluye principalmente por completitud.

perl_test

La regla "perl_test" localiza scripts de prueba Perl. Es decir, archivos que se nombran "*.t".

Esta regla es equivalente a "->"file->name( '*.t' )> y se incluye principalmente por completitud.

perl_installer

La regla "perl_installer" localiza instaladores de distribución Perl. Es decir, localiza archivos "Makefile.PL" y "Build.PL".

perl_script

La regla "perl_script" localiza scripts Perl.

Esto es cualquier archivo que termine en .pl, o cualquier archivo sin extensiones que tenga una línea "hash-bang" de Perl.

perl_file

La regla "perl_file" localiza todos los archivos que contienen código Perl.

Esto incluye todos los archivos que coinciden con las reglas "perl_module", "perl_test", "perl_installer" y "perl_script" anteriores.

no_index

# Proporciona las reglas directamente
$rule->no_index(
    directory => [ 'inc', 't', 'examples' ],
    file      => [ 'Foo.pm', 'lib/Foo.pm' ],
);

# Proporciona un META.yml para usar
$rule->no_index( 'META.yml' );

# Proporciona un directorio raíz de distribución para buscar un META.yml
$rule->no_index( 'My-Distribution' );

# Recoge automáticamente un META.yml del directorio objetivo
$rule->no_index->in( 'My-Distribution' );

El método "no_index" aplica un conjunto de reglas según la sección no_index de un archivo "META.yml".
