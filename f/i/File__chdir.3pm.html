DESCRIPCIÓ

N

El chdir() de Perl tiene el desafortunado problema de ser muy, muy, muy global. Si cualquier parte de tu programa llama a chdir() o si cualquier biblioteca que uses llama a chdir(), cambia el directorio de trabajo actual para *todo* el

programa.

Esto es

terrible.

File::chdir te da una alternativa, $CWD y @CWD. Estas dos variables combinan todo el poder de chdir(), File

::Spec
y Cwd.

$CW

D

Usa la variable $CWD en lugar de chdir() y

Cwd. 
use File::chdir;
$CWD = $dir;  # ¡igual que chdir($dir)!
print $CWD;   # imprime el directorio de trabajo
actual

Se puede localizar, y hace lo

correcto. 
$CWD = "/foo";      # es /foo aquí fuera.
{
    local $CWD = "/bar";  # /bar aquí dentro
}
# ¡sigue siendo /foo aquí
fuera!

$CWD siempre devuelve la ruta absoluta en la forma nativa para el sistema

operativo.

$CWD y el chdir() normal f

uncionan bi
en juntos.

@CW

D

@CWD representa el directorio de trabajo actual como un array, cada directorio en la ruta es un elemento del array. Esto a menudo hace que el directorio sea más fácil de manipular, y no tienes que manejarte con "File::Spec->splitpath" y "File::Spec->catdir" para hacer código

portable. 
# Similar a chdir("/usr/local/src/perl")
@CWD = qw(usr local src perl)
;

pop, push, shift, unshift y splice funcionan todos. pop y push son probablemente los más

útiles. 
pop @CWD;                 # igual que chdir(File::Spec->updir)
push @CWD, 'some_dir'     # igual que chdir('some_dir'
)

@CWD y $CWD funcionan bien

juntos.

*NOTA* Debido a un error de perl no puedes localizar @CWD. Ver "CAVEATS" para

una solución
alternativa.

Es más útil para escribir subrutinas educadas que no dejan el programa en algún directorio

extraño: 
sub foo {
    local $CWD = 'some/other/dir';
    ...haz tu trabajo...
}

lo cual es mucho más simple que el

equivalente: 
sub foo {
    use Cwd;
    my $orig_dir = Cwd::getcwd;
    chdir('some/other/dir');
    ...haz tu trabajo...
    chdir($orig_dir);
}

@CWD es útil cuando quieres empezar a moverte arriba y abajo por la jerarquía de directorios de una manera multiplataforma sin tener que usar File::

Spec. 
pop @CWD;                   # chdir(File::Spec->updir);
push @CWD, 'some', 'dir'    # chdir(File::Spec->catdir(qw(some dir)))
;

Puedes cambiar fácilmente tu directorio

padre: 
# chdir de /some/dir/b

ADVERTENCI

AS

"local @CWD" no

funciona.

"local @CWD" no localizará @CWD. Este es un error en Perl, no puedes localizar arrays vinculados (tied). Como solución alternativa, localizar $CWD localizará efectivamente @CWD

. 
{
    local $CWD;
    pop @CWD;
    ...
}

Asignar a @CWD llama a chdir() para cada

elemento 
@CWD = qw/a b c
d/;

Internamente, Perl limpia @CWD y asigna cada elemento a su vez. Por lo tanto, el código anterior hará

esto: 
chdir 'a';
chdir 'a/b';
chdir 'a/b/c';
chdir
'a/b/c/d';

Generalmente, evita asignar a @CWD y simpleme

nte usa p
ush y pop.

manejados

orma de cambiar el vo
lumen actual a través
de File::chdir.

NOTA

S

$CWD devuelve el directorio actual usando separadores de ruta nativos, es decir, "\" en Win32. Esto asegura que $CWD se comparará correctamente con directorios creados usando File::Spec. Por

ejemplo: 
my $working_dir = File::Spec->catdir( $CWD, "foo" );
$CWD = $working_dir;
doing_stuff_might_chdir();
is( $CWD, $working_dir, "¿de vuelta al working_dir original?" )
;

Borrar el último elemento de @CWD actuará como un pop. Borrar del medio lanzará una

excepción. 
delete @CWD[-1]; # OK
delete @CWD[-2]; #
Muere

volúmenes?
