NOMBRE

File::HomeDir::Darwin - Encuentra tu directorio de inicio y otros directorios en Darwin (OS X)

DESCRIPCIÓN

Este módulo proporciona rutas de archivo específicas de Mac OS X para determinar directorios comunes de usuario en perl puro, simplemente usando $ENV{HOME} sin llamadas a API Carbon ni Cocoa. En uso normal, este módulo siempre se usará a través de File::HomeDir.

SINOPSIS

use File::HomeDir;

# Encuentra directorios para el usuario actual
$home    = File::HomeDir->my_home;      # /Users/mylogin
$desktop = File::HomeDir->my_desktop;   # /Users/mylogin/Desktop
$docs    = File::HomeDir->my_documents; # /Users/mylogin/Documents
$music   = File::HomeDir->my_music;     # /Users/mylogin/Music
$pics    = File::HomeDir->my_pictures;  # /Users/mylogin/Pictures
$videos  = File::HomeDir->my_videos;    # /Users/mylogin/Movies
$data    = File::HomeDir->my_data;      # /Users/mylogin/Library/Application Support
