NOMBRE

fido2-token — encontrar y gestionar un autenticador FIDO2

SINOPSIS

fido2-token -C [-d] device

fido2-token -D [-d] -i cred_id device

fido2-token -D -b [-d] -k key_path device

fido2-token -D -b [-d] -n rp_id [-i cred_id] device

fido2-token -D -e [-d] -i template_id device

fido2-token -D -u [-d] device

fido2-token -G -b [-d] -k key_path blob_path device

fido2-token -G -b [-d] -n rp_id [-i cred_id] blob_path device

fido2-token -I [-cd] [-k rp_id -i cred_id] device

fido2-token -L [-bder] [-k rp_id] [device]

fido2-token -R [-d] device

fido2-token -S [-adefu] device

fido2-token -S [-d] -i template_id -n template_name device

fido2-token -S [-d] -l pin_length device

fido2-token -S -b [-d] -k key_path blob_path device

fido2-token -S -b [-d] -n rp_id [-i cred_id] blob_path device

fido2-token -S -c [-d] -i cred_id -k user_id -n name -p display_name device

fido2-token -S -m rp_id device

fido2-token -V

DESCRIPCIÓN

fido2-token gestiona un autenticador FIDO2.

Las opciones son las siguientes:

-C device
Cambia el PIN de device. Se le pedirá al usuario el PIN actual y el nuevo.
-D -i id device
Elimina la credencial residente especificada por id de device, donde id es el id de la credencial codificado en base64. Se le pedirá al usuario el PIN.
-D -b -k key_path device
Elimina un “largeBlob” cifrado con key_path de device, donde key_path contiene la clave de cifrado AES-256 GCM de 32 bytes del blob codificada en base64. Se requiere un PIN o un gesto de verificación de usuario equivalente.
-D -b -n rp_id [-i cred_id] device
Elimina un “largeBlob” correspondiente a rp_id de device. Si rp_id tiene múltiples credenciales inscritas en device, el ID de la credencial debe especificarse usando -i cred_id, donde cred_id es un blob codificado en base64. Se requiere un PIN o un gesto de verificación de usuario equivalente.
-D -e -i id device
Elimina el registro biométrico especificado por id de device, donde id es el id de la plantilla del registro codificado en base64. Se le pedirá al usuario el PIN.
-D -u device
Desactiva la función “user verification always” de CTAP 2.1 en device.
-G -b -k key_path blob_path device
Obtiene un “largeBlob” de CTAP 2.1 cifrado con key_path de device, donde key_path contiene la clave de cifrado AES-256 GCM de 32 bytes del blob codificada en base64. El blob se escribe en blob_path. Se requiere un PIN o un gesto de verificación de usuario equivalente.
