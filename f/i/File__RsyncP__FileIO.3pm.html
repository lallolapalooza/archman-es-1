File::RsyncP::FileIO(3) Documentación de Perl aportada por el usuario File::RsyncP::FileIO(3)

NOMBRE

File::RsyncP::FileIO - E/S del sistema de archivos para el cliente Rsync de Perl

SINOPSIS

use File::RsyncP::FileIO;
my $rs = File::RsyncP->new({
            logLevel   => 1,
            rsyncCmd => ["/bin/rsh", $host,  "-l", $user, "/bin/rsync"],
            rsyncArgs  => [qw(
                    --numeric-ids
                    --perms
                    --owner
                    --group
                    --devices
                    --links
                    --ignore-times
                    --block-size=700
                    --relative
                    --recursive
                    -v
                )],
            logHandler => sub {
                    my($str) = @_;    
                    print MyHandler "log: $str\n";
                };
            fio        => File::RsyncP::FileIO->new({
                            logLevel   => 1,
                        });
        });

DESCRIPCIÓN

File::RsyncP::FileIO contiene todas las funciones de acceso al sistema de archivos necesarias por File::RsyncP. Esta funcionalidad está relegada a este módulo para que pueda ser subclaseado o reemplazado por código diferente en aplicaciones donde se proporciona una interfaz rsync para datos que no son del sistema de archivos (por ejemplo: bases de datos).

File::RsyncP::FileIO proporciona las siguientes funciones.

Funciones de configuración y utilidad

new({ opciones... })
Crea un nuevo objeto File::RsyncP::FileIO. El único argumento es una referencia a un hash de opciones:
blockSize
Por defecto es 700. Puede establecerse más tarde usando la función blockSize.
logLevel
Por defecto es 0. Controla el nivel de detalle de las operaciones de FileIO.
digest
Por defecto es File::RsyncP::Digest->new. No hay necesidad de sobreescribirlo.
checksumSeed
La semilla de suma de verificación utilizada en los cálculos de digest. Por defecto es 0. El Rsync del lado del servidor genera una semilla de suma de verificación y la envía al cliente. Este valor normalmente se establece más tarde, después de recibir la semilla de suma de verificación del rsync remoto, a través de la función checksumSeed.
logHandler
Una referencia a un subrutina para una función que maneja todos los mensajes de registro. El valor por defecto es una subrutina que imprime los mensajes en STDERR.
blockSize($valor)
Establece el tamaño de bloque al nuevo valor, en caso de que no se haya establecido a través de la opción blockSize en new().
checksumSeed($semilla)
Establece la semilla de suma de verificación utilizada en los cálculos de digest al nuevo valor. Normalmente este valor no se conoce cuando se llama a new() , por lo que es necesario establecerlo más tarde a través de esta función.
logHandlerSet
Establece la función de retorno de llamada del manejador de registro. Normalmente este valor se especifica a través de new(), pero puede cambiarse más tarde a través de esta función.
dirs($directorioLocal, $directorioRemoto)
Especifica los directorios local y remoto.
log(@msg)
Guarda uno (o más) mensajes con fines de registro.
statsGet
Devuelve una referencia a un hash opcional de estadísticas compiladas por el objeto FileIO. Estos valores se pasan opacamente hacia arriba a File::RsyncP.
finish($esHijo)
Realiza cualquier procesamiento de finalización necesario. El argumento $esHijo es verdadero si este es el proceso hijo (recuerde que el lado receptor tiene dos procesos: el hijo recibe los deltas del archivo mientras que el padre genera los digests de los bloques).

Funciones de cálculo de sumas de verificación

csumStart($f, $necesitaMD4)
Se prepara para generar sumas de verificación de bloques para el archivo dado. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get. Típicamente esto abre el archivo subyacente y crea un objeto File::RsyncP::Digest. Si $necesitaMD4 es distinto de cero, entonces csumEnd() devolverá el digest MD4 del archivo.
csumGet($num, $longitudCsum, $tamañoBloque)
Devuelve $num bloques de trabajo de sumas de verificación con la longitud de suma de verificación MD4 de $longitudCsum (típicamente 2 o 16), con un tamaño de bloque de $tamañoBloque. Típicamente esto lee el archivo y llama a File::RsyncP::Digest->blockDigest.
csumEnd()
Finaliza el cálculo de la suma de verificación. Típicamente cierra el archivo subyacente. Tenga en cuenta que csumStart, csumGet, csumEnd se llaman en orden estricto por lo que no necesitan ser reentrantes (es decir, solo se hace una suma de verificación a la vez). Si csumStart() se llamó con $necesitaMD4 entonces csumEnd() devolverá el digest MD4 del archivo.

Funciones de lectura de archivos

Se usan para enviar archivos (actualmente el envío de archivos no implementa deltas; se comporta como si se hubiera especificado --whole-file):

readStart($f)
Se prepara para leer el archivo dado. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get. Típicamente esto abre el archivo subyacente.
read($num)
Lee $num bytes del archivo.
readEnd()
Finaliza la operación de lectura. Típicamente cierra el archivo subyacente. Tenga en cuenta que readStart, readGet, readEnd se llaman en orden estricto por lo que no necesitan ser reentrantes (es decir, solo se hace una lectura a la vez).

Operaciones de archivos

attribGet($f)
Devuelve los atributos del archivo dado como una referencia a un hash. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get.
attribSet($f, $marcadorDePosicion)
Establece los atributos para el archivo dado. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get. Si $marcadorDePosicion es verdadero, no hace nada. Devuelve undef en caso de éxito.
makePath($f)
Crea el directorio especificado por $f. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get. Devuelve undef en caso de éxito.
makeSpecial($f)
Crea el archivo especial especificado por $f. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get. Devuelve undef en caso de éxito.
unlink($rutaRemota)
Desvincula el archivo o directorio correspondiente a la ruta remota dada.
ignoreAttrOnFile($f)
Normalmente debería devolver undef, lo que significa usar la configuración por defecto de ignore-times. De lo contrario, si esta función devuelve cero o distinto de cero, el valor devuelto anula la configuración de ignore-times para este archivo. El argumento es una referencia a un hash típicamente devuelta por File::RsyncP::FileList->get. Vea la opción doPartial en File::RsyncP->new().

Funciones de recepción de deltas de archivos

Estas funciones solo se llaman cuando estamos recibiendo archivos.ey son llamados por el proceso hijo.

fileDeltaRxStart($f, $cnt, $size, $remainder)
Inicia la recepción de deltas de archivo para el archivo $f, un hashref generalmente devuelto por File::RsyncP::FileList->get. Los argumentos restantes son el número de bloques, el tamaño de los bloques y el tamaño del último bloque (parcial) tal como lo genera el proceso padre en el lado receptor (no son los valores del nuevo archivo en el lado emisor). Devuelve undef en caso de éxito.
fileDeltaRxNext($blk, $newData)
Esta función se llama repetidamente mientras se construye el archivo. Exactamente uno de $blk y $newData está definido. Si $blk está definido, es un entero que especifica qué bloque del archivo original debe escribirse en este punto. Si $newData está definido, son datos literales (que no coincidieron con ningún bloque) que deben escribirse en este punto.
fileDeltaRxDone($md4)
Finaliza el procesamiento de los deltas de archivo para este archivo. $md4 es el digesto MD4 del archivo enviado. Debe compararse contra el digesto MD4 del archivo reconstruido. Devuelve undef en caso de éxito, 1 si el MD4 del archivo no coincide (lo que significa que debe repetirse para la fase 2), y negativo en caso de error.

Función de envío de lista de archivos

fileListSend($fileList, $outputFunc)
Genera la lista de archivos (llamando a $fileList->encode para cada archivo a enviar) y llama a la función de salida $outputFunc con los datos de salida llamando a 
&$outputFunc($fileList->encodeData);
