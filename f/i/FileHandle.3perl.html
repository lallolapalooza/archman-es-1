FileHandle(3perl) Guía de Referencia del Programador de Perl FileHandle(3perl)

NOMBRE

FileHandle - Suministra métodos de objeto para manejadores de archivo

SINOPSIS

use FileHandle;
my $fh = FileHandle->new;
if ($fh->open("< file")) {
    print <$fh>;
    $fh->close;
}
my $fh = FileHandle->new("> FOO");
if (defined $fh) {
    print $fh "bar\n";
    $fh->close;
}
my $fh = FileHandle->new("file", "r");
if (defined $fh) {
    print <$fh>;
    undef $fh;       # cierra automáticamente el archivo
}
my $fh = FileHandle->new("file", O_WRONLY|O_APPEND);
if (defined $fh) {
    print $fh "corge\n";
    undef $fh;       # cierra automáticamente el archivo
}
my $pos = $fh->getpos;
$fh->setpos($pos);
$fh->setvbuf(my $buffer_var, _IOLBF, 1024);
my ($readfh, $writefh) = FileHandle::pipe;
autoflush STDOUT 1;

DESCRIPCIÓN

NOTA: Esta clase es ahora un front-end para las clases IO::*.

"FileHandle::new" crea un "FileHandle", que es una referencia a un símbolo recién creado (ver el paquete Symbol). Si recibe algún parámetro, se pasa a "FileHandle::open"; si la apertura falla, el objeto "FileHandle" se destruye. De lo contrario, se devuelve al llamador.

"FileHandle::new_from_fd" crea un "FileHandle" como lo hace "new". Requiere dos parámetros, que se pasan a "FileHandle::fdopen"; si el fdopen falla, el objeto "FileHandle" se destruye. De lo contrario, se devuelve al llamador.

"FileHandle::open" acepta un parámetro o dos. Con un parámetro, es solo un front-end para la función incorporada "open". Con dos parámetros, el primer parámetro es un nombre de archivo que puede incluir espacios en blanco u otros caracteres especiales, y el segundo parámetro es el modo de apertura, seguido opcionalmente por un valor de permisos de archivo.

Si "FileHandle::open" recibe una cadena de modo de Perl (">", "+<", etc.) o una cadena de modo fopen() de POSIX ("w", "r+", etc.), utiliza el operador incorporado de Perl "open".

Si "FileHandle::open" recibe un modo numérico, pasa ese modo y el valor de permisos opcional al operador "sysopen" de Perl. Para mayor comodidad, "FileHandle::import" intenta importar las constantes O_XXX del módulo Fcntl. Si la carga dinámica no está disponible, esto puede fallar, pero el resto de FileHandle seguirá funcionando.

"FileHandle::fdopen" es como "open" excepto que su primer parámetro no es un nombre de archivo sino el nombre de un manejador de archivo, un objeto FileHandle o un número de descriptor de archivo.

Si las funciones C fgetpos() y fsetpos() están disponibles, entonces "FileHandle::getpos" devuelve un valor opaco que representa la posición actual del FileHandle, y "FileHandle::setpos" utiliza ese valor para volver a una posición visitada previamente.

Si la función C setvbuf() está disponible, entonces "FileHandle::setvbuf" establece la política de búfer para el FileHandle. La secuencia de llamada para la función Perl es la misma que su contraparte C, incluidas las macros "_IOFBF", "_IOLBF" y "_IONBF", excepto que el parámetro de búfer especifica una variable escalar para usar como búfer. ¡ADVERTENCIA: Una variable utilizada como búfer por "FileHandle::setvbuf" no debe modificarse de ninguna manera hasta que el FileHandle se cierre o hasta que se llame nuevamente a "FileHandle::setvbuf", o podría producirse una corrupción de memoria!

Además, para realizar E/S normal, puede necesitar estos:

$fh->print
Ver "print" en perlfunc.
$fh->printf
Ver "printf" en perlfunc.
$fh->getline
Esto funciona como <$fh> descrito en "Operadores de E/S" en perlop, excepto que es más legible y se puede llamar de forma segura en un contexto de lista pero aún así devuelve solo una línea.
$fh->getlines
Esto funciona como <$fh> cuando se llama en un contexto de lista para leer todas las líneas restantes en un archivo, excepto que es más legible. También hará croak() si se llama accidentalmente en un contexto escalar.

Hay muchas otras funciones disponibles ya que FileHandle desciende de IO::File, IO::Seekable e IO::Handle. Consulte esas páginas respectivas para obtener documentación sobre más funciones.
