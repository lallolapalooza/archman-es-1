NOMBRE

fixkrf - Corrige archivos keyrec de DNSSEC-Tools cuyos archivos de clave de cifrado se han movido

SINOPSIS

fixkrf [opciones] <archivo-keyrec> <dir 1> ... <dir N>

DESCRIPCIÓN

fixkrf comprueba un archivo keyrec especificado para asegurarse de que los archivos de clave de cifrado referenciados existen donde se listan. Si una clave no está donde el keyrec especifica que debería estar, entonces fixkrf buscará en los directorios dados por esas claves y ajustará el keyrec para que coincida con la realidad. Si una clave con un nombre de archivo particular se encuentra en múltiples lugares, se imprimirá una advertencia y el archivo keyrec no se modificará para esa clave.

OPCIONES

-list
Muestra información sobre las claves faltantes, pero no corrige el archivo keyrec.
-verbose
Muestra información sobre las claves encontradas, así como sobre las claves faltantes.
-Version
Muestra información de versión para fixkrf y DNSSEC-Tools.
-help
Muestra un mensaje de uso.
