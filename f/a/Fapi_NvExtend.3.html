Realiza una operación de extensión en un índice NV con el tipo extend.

    NAME

    Fapi_NvExtend - Functions for Non-Volatile NVRAM extension management

    SYNOPSIS

    #include <fapi.h>

    int Fapi_NvExtend(uint32_t nBytes, uint8_t *pNvData);

    DESCRIPTION

    The Fapi_NvExtend function extends the size of the Non-Volatile Random-Access Memory (NVRAM) by nBytes bytes. The new bytes will be initialized with the contents of pNvData. If pNvData is NULL, the new bytes will be initialized to zero.

    This function can only be called if the NVRAM has not been previously extended. If the NVRAM has already been extended, Fapi_NvExtend will return an error.

    FUNCTION DOCUMENTATION

    int Fapi_NvExtend(uint32_t nBytes, uint8_t *pNvData);

    Extends the NVRAM by nBytes bytes.

    Parameters:

    nBytes
    The number of bytes to extend the NVRAM by.
    pNvData
    A pointer to the data to initialize the new NVRAM bytes with. If NULL, the new bytes are initialized to zero.

    Return Value:

    Returns 0 on success, or a negative error code on failure.
