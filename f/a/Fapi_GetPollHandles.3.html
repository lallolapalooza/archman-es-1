Función FAPI para recuperar los identificadores de sondeo utilizados actualmente por el correspondiente FAPI_CONTEXT.

DOCUMENTACIÓN DE LA FUNCIÓN

TSS2_RC Fapi_GetPollHandles (FAPI_CONTEXT * context, FAPI_POLL_HANDLE ** handles, size_t * num_handles)

Recuperar identificadores para sondeo

Devuelve una matriz de identificadores que se pueden sondear para ser notificado cuando los datos del TPM o de una operación de disco estén disponibles.

El código correspondiente debería parecerse a lo siguiente: do { r = Fapi_GetPollHandles(fc, &ph, &nph); if (r == TSS2_RC_SUCCESS) { poll(ph, nph, -1); Fapi_Free(ph); } r = Fapi_*_Finish(fc, ...); } while (r == TSS2_FAPI_RC_TRY_AGAIN);

Parámetros

context El FAPI_CONTEXT
handles Una matriz de entradas de identificador de sondeo
num_handles El tamaño de la matriz en identificadores

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si el contexto o los datos son NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto no tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_NO_HANDLE si no hay identificadores para sondear
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
