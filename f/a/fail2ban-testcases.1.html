NOMBRE

fail2ban-testcases - ejecuta pruebas unitarias de Fail2Ban

SINOPSIS

fail2ban-testcases [OPCIONES] [expresionesregulares]

DESCRIPCIÓN

Script para ejecutar la batería de pruebas de Fail2Ban

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
-l NIVEL_LOG, --log-level=NIVEL_LOG
Nivel de registro para que el registrador lo use durante la ejecución de las pruebas
-v
Aumenta la verbosidad
--verbosity=VERBOSIDAD
Establece el nivel numérico de verbosidad (0..4)
--log-direct
Evita el registro diferido dentro de las pruebas
-n, --no-network
No ejecuta pruebas que requieran red
-m, --memory-db
Ejecuta pruebas de base de datos usando memoria en lugar de archivo
-f, --fast
Intenta aumentar la velocidad de las pruebas, disminuyendo los intervalos de espera, base de datos en memoria
-i, --ignore
niega el filtro [expresionesregulares] para ignorar pruebas que coincidan con expresiones regulares especificadas
-t, --log-traceback
Enriquece los mensajes de registro con rastreos de pila comprimidos
--full-traceback
Para hacer que los rastreos de pila sean completos, no comprimidos (como por defecto)

VER TAMBIÉN

fail2ban-client(1) fail2ban-server(1) fail2ban-regex(1)
