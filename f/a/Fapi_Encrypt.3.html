TSS2_RC Fapi_Encrypt (FAPI_CONTEXT * context, char const * keyPath, uint8_t const * plainText, size_t plainTextSize, uint8_t ** cipherText, size_t *

cipherTextSize)

Función de una sola llamada para

Fapi_Encrypt

Cifra los datos proporcionados para la clave de destino utilizando los esquemas de cifrado del TPM según se especifica en el perfil criptográfico. Esta función no utiliza el TPM; es decir, funciona en modo sin

TPM.

Parámetro

s
context El FAPI_CONTEXT
keyPath La ruta a la clave de cifrado
plainText Los datos en texto plano a cifrar
plainTextSize El tamaño del texto plano en bytes
cipherText El texto cifrado codificado.
cipherTextSize El tamaño del texto cifrado
codificado.

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context, keyPath, plainText o cipherText es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si keyPath no corresponde a una clave FAPI.
TSS2_FAPI_RC_BAD_KEY si la clave en keyPath no es adecuada para el cifrado.
TSS2_FAPI_RC_BAD_VALUE si plainTextSize es 0.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_IO_ERROR si ocurrió un error al acceder al almacén de objetos.
TSS2_FAPI_RC_NOT_IMPLEMENTED si el algoritmo de cifrado no está disponible.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no está establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto resumen de política no fue exitosa.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI no fue aprovisionada.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un cont
exto inapropiado o cont
