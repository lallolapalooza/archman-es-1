NOMBRE

faad — Procesa un stream de Advanced Audio Codec

SINOPSIS

faad [opciones] [-w | -o <nombre_archivo_salida> | -a <nombre_archivo_salida>] <nombre_archivo_entrada>

DESCRIPCIÓN

Esta utilidad proporciona una interfaz de línea de comandos a libfaad2. Este programa lee archivos MPEG‐4 AAC, los procesa y los produce en formato Microsoft WAV, MPEG‐4 AAC ADTS o PCM estándar.

OPCIONES

-a <nombre_archivo>, --adtsout <nombre_archivo>
Establece el procesamiento para generar salida al archivo especificado en formato MPEG‐4 AAC ADTS.
-b <número>, --bits <número>
Establece el formato de muestra de salida (individual). El número toma uno de los siguientes valores:
1: Datos PCM de 16 bits (por defecto).
2: Datos PCM de 24 bits.
3: Datos PCM de 32 bits.
4: Datos de punto flotante de 32 bits.
5: Datos de punto flotante de 64 bits.
-d , --downmix
Establece el procesamiento para remuestrear de 5.1 (sonido envolvente y graves) canales a 2 canales (estéreo).
-f <número>, --format <número>
Establece el formato del archivo de salida. El número toma uno de los siguientes valores:
1: Formato WAV de Microsoft (por defecto).
2: Datos PCM sin formato.
-g
Establece el procesamiento para no realizar decodificación sin pausas.
-h , --help
Muestra un resumen de uso.
-i , --info
Muestra información sobre el archivo de entrada.
-l <número>, --objecttype <número>
Establece el MPEGpe para que lo use el procesamiento. El número toma uno de los siguientes valores:
1: Tipo de objeto principal.
2: Tipo de objeto de baja complejidad (LC) (por defecto).
4: Tipo de objeto de predicción a largo plazo (LTP).
23: Tipo de objeto de baja latencia (LD).
-o <nombre_archivo>, --outfile <número>
Establece el nombre del archivo para la salida del procesamiento.
-q , --quiet
Silencioso: Suprime los mensajes de estado durante el procesamiento.
-t , --oldformat
Establece el procesamiento para usar el formato antiguo MPEG‐4 AAC ADTS al generar salida en dicho formato.
-w , --stdio
Establece que la salida del procesamiento se envíe a la salida estándar.
