TSS2_RC Fapi_GetPlatformCertificates (FAPI_CONTEXT * context, uint8_t ** certificates, size_t * certificatesSize)

Función de una sola llamada para Fapi_GetPlatformCertificates

Los certificados de plataforma para TPM 2.0 pueden consistir no solo en un certificado único sino en una serie de los llamados certificados delta. Esta función devuelve el conjunto de certificados de plataforma concatenados en un búfer continuo.

Parámetros

context El FAPI_CONTEXT
certificates Los certificados de plataforma
certificatesSize El tamaño del búfer con los certificados. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o certificates es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no pueden ser guardados.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI fue inicializada en modo sin-TPM a través de su archivo de configuración.
TSS2_FAPI_RC_NO_CERT si ocurrió un error durante la descarga del certificado.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si un callback de autorización requerido no está establecido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para cierto resumen de política no fue exitosa.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI no fue aprovisionada.
TSS2_FAPI_RC_KEY_NOT_FOUND si una clave no fue encontrada.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_PATH_NOT_FOUND si una ruta de objeto FAPI no fue encontrada durante la autorización.

TSS2_RC Fapi_GetPlatformCertificates_Async (FAPI_CONTEXT * context)

Función asíncrona para Fapi_GetPlatformCertificates

Los certificados de plataforma para TPM 2.0 pueden consistir no solo en un certificado único sino en una serie de los llamados certificados delta. Esta función devuelve el conjunto de certificados de plataforma concatenados en un búfer continuo.

Llame a Fapi_GetPlatformCertificates_Finish para finalizar la ejecución de este comando.
