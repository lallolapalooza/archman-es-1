TSS2_RC Fapi_GetDescription (FAPI_CONTEXT * context, char const * path, char ** description)

Función de llamada única para Fapi_GetDescription

Devuelve la descripción de un objeto previamente almacenado.

Parámetros

context El FAPI_CONTEXT
path La ruta del objeto para el que se carga la descripción
description La descripción del objeto

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, path o description son NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si la ruta no se mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si el FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha finalizado y esta función debe ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.
