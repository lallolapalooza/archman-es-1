TSS2_RC Fapi_List (FAPI_CONTEXT * context, char const * searchPath, char ** pathList)

Función de llamada única para Fapi_List

Enumera todos los objetos en el almacén de metadatos en la ruta proporcionada y los devuelve en una lista de rutas completas desde la raíz con los valores separados por dos puntos.

Parámetros

context El FAPI_CONTEXT
searchPath La ruta que identifica la raíz de la búsqueda
pathList Una lista separada por dos puntos de todos los objetos en la ruta raíz

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, searchPath, pathList es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si searchPath no se mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no se aprovisionó.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.

TSS2_RC Fapi_List_Async (FAPI_CONTEXT * context, char const * searchPath)

Función asíncrona para Fapi_List

Enumera todos los objetos en el almacén de metadatos en la ruta proporcionada y los devuelve en una lista de rutas completas desde la raíz con los valores separados por dos puntos.

Llame a Fapi_List_Finish para finalizar la ejecución de este comando.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.

Parámetros

context El FAPI_CONTEXT
searchPath La ruta que identifica la raíz de la búsqueda

Valores de retorno

TSS2_FAPI_RC_BAD_REFERENCE si context o searchPath es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si searchPath no se mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.

TSS2_RC Fapi_List_Finish (FAPI_CONTEXT * context, char ** pathList)

Función de finalización asíncrona para Fapi_List

Esta función debe llamarse después de una Fapi_List_Async previa.

Parámetros

context El FAPI_CONTEXT
pathList Una lista separada por dos puntos de todos los objetos en la ruta raíz

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o pathList es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_TRY_AGAIN si la operación asíncrona aún no se ha completado. Llame a esta función de nuevo más tarde.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no se aprovisionó.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
