NOMBRE

falcodump - Volcar datos de registro a un archivo utilizando un plugin de fuente de Falco.

SINOPSIS

Opciones comunes
falcodump [ --help ] [ --version ] [ --plugin-api-version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interfaz> ] [ --extcap-config ] [ --extcap-capture-filter=<filtro de captura> ] [ --capture ] [ --fifo=<ruta a archivo o tubería> ] [ --plugin-source=<ruta o URL de fuente> ] [ --log-level=<nivel de registro> ] [ --log-file=<ruta a archivo> ]

Opciones de llamadas al sistema
[ --include-capture-processes=<VERDADERO o FALSO> ] [ --include-switch-calls=<VERDADERO o FALSO> ]

Opciones del plugin CloudTrail
[ --cloudtrail-s3downloadconcurrency=<número de descargas concurrentes> ] [ --cloudtrail-s3interval=<intervalo de tiempo> ] [ --cloudtrail-s3accountlist=<IDs de cuenta separados por comas> ] [ --cloudtrail-sqsdelete=<verdadero o falso> ] [ --cloudtrail-useasync=<verdadero o falso> ] [ --cloudtrail-uses3sns=<verdadero o falso> ] [ --cloudtrail-aws-region=<región de AWS> ] [ --cloudtrail-aws-profile=<perfil de AWS> ] [ --cloudtrail-aws-config=<ruta> ] [ --cloudtrail-aws-credentials=<ruta a archivo> ]

DESCRIPCIÓN

falcodump es una herramienta extcap que permite capturar mensajes de registro de proveedores en la nube.

Cada plugin se lista como una interfaz separada. Por ejemplo, el plugin AWS CloudTrail se lista como "cloudtrail".

OPCIONES

--help

Imprime los argumentos del programa. Esto también listará los argumentos de configuración para cada plugin.

--version

Imprime la versión del programa.

--plugin-api-version

Imprime la versión de la API de plugins de Falco.

--extcap-interfaces

Lista las interfaces disponibles.

--extcap-interface=<interfaz>

Utiliza la interfaz especificada.

--extcap-dlts

Lista los DLT de la interfaz especificada.

--extcap-config

Lista las opciones de configuración de la interfaz especificada.

--extcap-capture-filter=<filtro de captura>

El filtro de captura. Debe ser un filtro válido de Sysdig / Falco.

--capture

Comienza a capturar desde la fuente especificada por --plugin-source a través de la interfaz especificada y escribe los datos crudos del paquete en la ubicación especificada por --fifo.

--fifo=<ruta a archivo o tubería>

Guarda el paquete capturado en un archivo o lo envía a través de una tubería.

--plugin-source=<ruta o URL de fuente>

Captura desde la ubicación especificada.

--log-level

Establece el nivel de registro

--log-file

Establece un archivo de registro para registrar mensajes además de la consola

OPCIONES DE LLAMADAS AL SISTEMA

--include-capture-processes

Incluye llamadas al sistema para procesos de captura (falcodump, dumpcap y Stratoshark) si es VERDADERO. Por defecto es FALSO.

--include-switch-calls

Incluye llamadas "switch" si es VERDADERO. Por defecto es FALSO.

PLUGINS

cloudtrail (AWS CloudTrail)

--cloudtrail-s3downloadconcurrency

Controla el número de gorutinas en segundo plano utilizadas para descargar archivos S3 (Predeterminado: 32)

--cloudtrail-s3interval

Descarga archivos de registro durante el intervalo especificado (Predeterminado: sin intervalo)

--cloudtrail-s3accountlist

Si la fuente es un bucket S3 de CloudTrail de organización, descarga archivos de registro para todos los IDs de cuenta especificados (Predeterminado: sin IDs de cuenta)

--cloudtrail-sqsdelete

Si es verdadero, el plugin eliminará los mensajes SQS de la cola inmediatamente después de recibirlos (Predeterminado: verdadero)

--cloudtrail-useasync

Si es verdadero, la optimización de extracción asíncrona está habilitada (Predeterminado: verdadero)

--cloudtrail-uses3sns

Si es verdadero, el plugin esperará que los mensajes SNS se originen desde S3 en lugar de directamente desde Cloudtrail (Predeterminado: falso)

--cloudtrail-aws-profile

Si no está vacío, anula el perfil de configuración compartida de AWS (por ejemplo, 'default') y las variables de entorno como AWS_PROFILE (Predeterminado: vacío)

--cloudtrail-aws-region

Si no está vacío, anula la región de AWS especificada en el perfil (por ejemplo, 'us-east-1') y las variables de entorno como AWS_REGION (Predeterminado: vacío)

--cloudtrail-aws-config

Si no está vacío, anula la ruta del archivo de configuración compartida de AWS (por ejemplo, ~/.aws/config) y las variables de entorno como AWS_CONFIG_FILE (Predeterminado: vacío)

--cloudtrail-aws-credentials

Si no está vacío, anula la ruta del archivo de credenciales compartidas de AWS (por ejemplo, ~/.aws/credentials) y las variables de entorno como AWS_SHARED_CREDENTIALS_FILE (Predeterminado: vacío)

Las fuentes de CloudTrail pueden ser buckets S3 o URLs de colas SQS. Las URLs de buckets S3 tienen el formato

's3://nombre_del_bucket/prefijo/AWSLogs/id_de_cuenta/CloudTrail/región/año/mes/día'

Para CloudTrail de organización, la URL del bucket S3 puede ser

's3://nombre_del_bucket/prefijo/AWSLogs/id_de_org/id_de_cuenta/CloudTrail/región/año/mes/día'

Los componentes región, año, mes y día se pueden omitir para obtener más o menos datos. Por ejemplo, la fuente 's3://mybucket/AWSLogs/012345678/CloudTrail/us-west-2/2023' obtendrá todos los registros de CloudWatch para el año 2023.

Si la URL termina con 'id_de_cuenta/' o 'id_de_cuenta/CloudTrail/' (por ejemplo 's3://mybucket/AWSLOGS/012345678912/') la opción '--cloudtrail-s3interval' puede usarse para definir el intervalo de tiempo. Un s3interval de '1d', por ejemplo, obtendría todos los eventos de las últimas 24 horas de todas las regiones disponibles. Un s3interval de '2w-1w' obtendría todos los eventos de todas las regiones desde hace dos semanas hasta hace una semana. El s3interval también se puede definir como una marca de tiempo estilo RFC 3339 como '2024-02-29T18:07:17Z' o '2024-02-29T00:00:00Z-2024-03-01T23:59:59Z'.

Si la URL termina con 'AWSLogs/id_de_org', la opción '--cloudtrail-s3accountlist' puede usarse para especificar IDs de cuenta. Esto se puede combinar con '--cloudtrail-s3interval'. Una fuente como 's3://my-org-bucket/AWSLogs/o-123abc/' con '--cloudstrail-s3accountlist' establecido en '123456789012,987654321098' y '--cloudtrail-s3interval' establecido en '30m' obtendría todos los eventos de los últimos 30 minutos de todas las regiones para las cuentas 123456789012 y 987654321098.

Si la URL de origen es el bucket CloudTrail de la organización (como 's3://my-org-bucket/AWSLogs/o-123abc') y '--s3accountlist' no está establecido, el plugin itera sobre todas las cuentas (limitado por '--s3interval' si está establecido). Atención: Dependiendo del tamaño de la organización y el intervalo de tiempo, esto puede llevar mucho tiempo.

El plugin cloudtrail utiliza el SDK de AWS para Go, que puede obtener la configuración del perfil, la región y las credenciales de un conjunto de variables de entorno y archivos de configuración estándar https://aws.github.io/aws-sdk-go-v2/docs/configuring-sdk/. Falcodump mostrará una lista de perfiles configurados localmente y las regiones actuales, y también le permitirá proporcionar un valor personalizado.

Hay más información disponible en el README https://github.com/falcosecurity/plugins/blob/master/plugins/cloudtrail/.
