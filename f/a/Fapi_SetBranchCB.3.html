Documentación de Funciones

TSS2_RC Fapi_SetBranchCB (FAPI_CONTEXT * context, Fapi_CB_Branch callback, void * userData)

Esta función registra una llamada de retorno que se invocará cada vez que el FAPI tenga que decidir qué rama de una política Policy-OR utilizar para autorizar una operación FAPI particular.

Parámetros

context El FAPI_CONTEXT
callback La función de llamada de retorno para la selección de rama
userData Un puntero que se proporciona a todas las invocaciones de llamada de retorno

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si el contexto es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_MEMORY si el FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_BAD_SEQUENCE si las funciones síncrona o Asíncrona se llaman mientras el contexto tiene otra operación asíncrona pendiente, o la función Finish se llama mientras el contexto no tiene una operación asíncrona apropiada pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
