TSS2_RC Fapi_ExportPolicy (FAPI_CONTEXT * context, char const * path, char ** jsonPolicy)

Función de llamada única para Fapi_ExportPolicy

Exporta una política a un buffer de bytes codificado en JSON.

Parámetros

context El FAPI_CONTEXT
path La ruta de la política que se va a exportar
jsonPolicy La política codificada en JSON. jsonPolicy DEBE ser NULL.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, path o jsonPolicy son NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si la ruta no se mapea a una política FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función debe llamarse de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no se ha aprovisionado.

TSS2_RC Fapi_ExportPolicy_Async (FAPI_CONTEXT * context, char const * path)

Función asíncrona para Fapi_ExportPolicy

Exporta una política a un buffer de bytes codificado en JSON.

TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si la ruta no se mapea a una política FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.

TSS2_RC Fapi_ExportPolicy_Finish (FAPI_CONTEXT * context, char ** jsonPolicy)

Función de finalización asíncrona para Fapi_ExportPolicy

Esta función debe llamarse después de un Fapi_ExportPolicy_Async anterior.

Parámetros

context El FAPI_CONTEXT
jsonPolicy La política codificada en JSON. jsonPolicy DEBE ser NULL.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o jsonPolicy son NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_TRY_AGAIN si la operación asíncrona aún no ha completado. Llame a esta función de nuevo más tarde.
TSS2_FAPI_RC_BAD_PATH si se utiliza una ruta en un contexto inapropiado o contiene caracteres ilegales.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
