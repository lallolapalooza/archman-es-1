FAIL2BAN-SERVER(1) Comandos de usuario FAIL2BAN-SERVER(1)

NOMBRE

fail2ban-server - iniciar el servidor

SINOPSIS

fail2ban-server [OPCIONES]

DESCRIPCIÓN

Fail2Ban v1.1.0 lee el archivo de registro que contiene informes de fallos de contraseña y bloquea las direcciones IP correspondientes utilizando reglas de firewall.

OPCIONES

-c, --conf <DIR>
directorio de configuración
-s, --socket <ARCHIVO>
ruta del socket
-p, --pidfile <ARCHIVO>
ruta del archivo PID
--pname <NOMBRE>
nombre del proceso (hilo principal) para identificar la instancia (por defecto fail2ban-server)
--loglevel <NIVEL>
nivel de registro
--logtarget <DESTINO>
destino del registro, usar nombre de archivo o stdout, stderr, syslog o sysout.

--syslogsocket auto|<ARCHIVO>

-d
volcar configuración. Para depuración
--dp, --dump-pretty
volcar la configuración usando una representación más legible para humanos
-t, --test
probar configuración (también se puede especificar con parámetros de inicio)
-i
modo interactivo
-v
aumentar verbosidad
-q
disminuir verbosidad
-x
forzar ejecución del servidor (eliminar archivo de socket)
-b
iniciar servidor en segundo plano (por defecto)
-f
iniciar servidor en primer plano
--async
iniciar servidor en modo asíncrono (solo para uso interno, no leer configuración)
--timeout
tiempo de espera para el servidor (solo para uso interno, no leer configuración)
--str2sec <CADENA>
convertir formato de abreviatura de tiempo a segundos
-h, --help
mostrar este mensaje de ayuda
-V, --version
imprimir la versión (-V devuelve formato corto legible por máquina)

REPORTE DE ERRORES

Reportar errores a https://github.com/fail2ban/fail2ban/issues
