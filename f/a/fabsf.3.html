fabs(3) Manual de Funciones de Biblioteca fabs(3)

NOMBRE

fabs, fabsf, fabsl - valor absoluto de un número de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double fabs(double x);
float fabsf(float x);
long double fabsl(long double x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

fabsf(), fabsl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven el valor absoluto del número de punto flotante x.

VALOR DE RETORNO

Estas funciones devuelven el valor absoluto de x.

Si x es un NaN, se devuelve un NaN.

Si x es -0, se devuelve +0.

Si x es infinito negativo o infinito positivo, se devuelve infinito positivo.

ERRORES

No se producen errores.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
fabs (), fabsf (), fabsl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

VER TAMBIÉN

abs(3), cabs(3), ceil(3), floor(3), labs(3), rint(3)
