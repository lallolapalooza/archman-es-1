TSS2_RC Fapi_SetCertificate (FAPI_CONTEXT * context, char const * path, char const * x509certData)

Función de una sola llamada para Fapi_SetCertificate

Establece un certificado x509 en la ruta de una clave.

Parámetros

context El FAPI_CONTEXT
path La ruta de la entidad a la que se asociará el certificado
x509certData El certificado que se asocia con la entidad. Si es NULL, se eliminará un certificado existente de la entidad

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o path es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta una corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si path no corresponde a una entidad FAPI.
TSS2_FAPI_RC_BAD_KEY si x509certData es inválido.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI no fue aprovisionada.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
