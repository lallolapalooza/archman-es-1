FATSORT(1) Comandos de usuario FATSORT(1)

NOMBRE

fatsort - Herramienta de ordenación FAT

SINOPSIS

fatsort [OPCIONES] DISPOSITIVO

DESCRIPCIÓN

FATSort ordena las estructuras de directorios de sistemas de archivos FAT (FAT12, FAT16, FAT32 y exFAT). Muchos reproductores de hardware MP3 no ordenan los archivos automáticamente, sino que los reproducen en el orden en que fueron transferidos al dispositivo. FATSort puede ayudar en esto.

Opciones de ordenación:

-a
Usar orden alfabético ASCII para la ordenación
-c
Ignorar mayúsculas/minúsculas en los nombres de archivo (por defecto para la mayoría de las locales)
-I PREFIJO
Ignorar el PREFIJO del nombre de archivo
-n
Ordenación natural

-o INDICADOR Orden de ordenación de archivos donde INDICADOR es uno de

d : directorios primero (por defecto)
f : archivos primero
a : archivos y directorios no se diferencian
-r
Ordenar en orden inverso
-R
Ordenar en orden aleatorio
Estas opciones hacen que todas las demás opciones de ordenación sean obsoletas.
-t
Ordenar por fecha y hora de última modificación

Las siguientes opciones se pueden especificar varias veces para seleccionar qué directorios se ordenarán:

-d DIR
Ordenar solo el directorio DIR
-D DIR
Ordenar el directorio DIR y todos sus subdirectorios
-x DIR
No ordenar el directorio DIR
-X DIR
No ordenar el directorio DIR y sus subdirectorios

Las siguientes opciones se pueden especificar varias veces para seleccionar qué directorios se ordenarán utilizando expresiones regulares extendidas de POSIX.2:

-e RE
Ordenar solo directorios que coincidan con la expresión regular RE
-E RE
No ordenar directorios que coincidan con la expresión regular RE

Sin embargo, las opciones -e y -E no pueden usarse simultáneamente con las opciones -d, -D, -x y -X.

-L LOC
Usar la locale LOC en lugar de la locale de las variables de entorno

Más opciones:

-l
Mostrar solo el orden actual de los archivos
-i
Mostrar solo información del sistema de archivos
-f
Forzar la ordenación incluso si el sistema de archivos está montado

-h, --help

Mostrar ayuda

-v, --version

Mostrar información de la versión
-q
Ser silencioso

DISPOSITIVO debe ser un sistema de archivos FAT12, FAT16, FAT32 o exFAT.

ADVERTENCIA: EL SISTEMA DE ARCHIVOS DEBE ESTAR CONSISTENTE (SIN ERRORES DEL SISTEMA DE ARCHIVOS). POR FAVOR, HAGA UNA COPIA DE SEGURIDAD DE SUS DATOS ANTES DE USAR FATSORT. ¡RIESGO DE CORRUPCIÓN DEL SISTEMA DE ARCHIVOS! EL USUARIO DE FATSORT ASUME TODO EL RIESGO. ¡FATSORT NO SERÁ RESPONSABLE POR PÉRDIDA DE DATOS!

EJEMPLOS

fatsort /dev/sda
Ordenar /dev/sda.
fatsort -n /dev/sdb1
Ordenar /dev/sdb1 con orden natural.
