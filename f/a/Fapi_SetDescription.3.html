TSS2_RC Fapi_SetDescription (FAPI_CONTEXT * context, char const * path, char const * description)

Función de llamada única para Fapi_SetDescription

Asocia una descripción legible por humanos con un objeto en el almacén de metadatos.

Parámetros

context El FAPI_CONTEXT
path La ruta del objeto en el almacén de metadatos
description La descripción que se asocia con el objeto. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o path son NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si path no se mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función debe ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.

TSS2_RC Fapi_SetDescription_Async (FAPI_CONTEXT * context, char const * path, char const * description)

Función asíncrona para Fapi_SetDescription

Asocia una descripción legible por humanos con un objeto en el almacén de metadatos.

Llame a Fapi_SetDescription_Finish para finalizar la ejecución de este comando.

Parámetros

context El FAPI_CONTEXT
path La ruta del objeto en el almacén de metadatos
description La descripción que se asocia con el objeto. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o path son NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si path no se mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.

TSS2_RC Fapi_SetDescription_Finish (FAPI_CONTEXT * context)

Función asíncrona de finalización para Fapi_SetDescription

Esta función debe ser llamada después de una llamada previa a Fapi_SetDescription_Async.

Parámetros

context El FAPI_CONTEXT

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND Si no se encuentra ningún archivo después de la expansión de la ruta.
TSS2_FAPI_RC_TRY_AGAIN si la operación asíncrona aún no está completa. Llame a esta función de nuevo más tarde.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
