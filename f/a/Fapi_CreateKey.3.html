TSS2_RC Fapi_CreateKey (FAPI_CONTEXT * context, char const * path, char const * type, char const * policyPath, char const * authValue)

Función de llamada única para Fapi_CreateKey

Crea una clave dentro del TPM basándose en el tipo de clave, utilizando la política y el valor de autorización proporcionados. La clave se almacenará entonces en el almacén de metadatos de FAPI o en el TPM.

Parámetros

context El FAPI_CONTEXT
path La ruta donde se almacena la nueva clave
type El tipo de la nueva clave. Puede ser NULL
policyPath La ruta a la política que se asocia con la nueva clave. Puede ser NULL
authValue El valor de autorización para la nueva clave. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o path es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del context.
TSS2_FAPI_RC_BAD_PATH si policyPath no es NULL y no se mapea a una política FAPI.
TSS2_FAPI_RC_KEY_NOT_FOUND si la clave padre no se mapea a una clave FAPI.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si ya existe un archivo en la ruta.
TSS2_FAPI_RC_BAD_VALUE si el keyType no es NULL y es inválido.
TSS2_FAPI_RC_BAD_SEQUENCE si el context tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S no ha finalizado aún y esta función debe ser llamada de nuevo.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no se ha configurado un callback de autorización requerido.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si falla el intento de autorización.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto digest de política no tuvo éxito.
