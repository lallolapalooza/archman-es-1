NOMBRE

fake_router26

SINOPSIS

fake_router26 [-E tipo] [-A red/prefijo] [-R red/prefijo] [-D servidor-dns] [-s ip-origen] [-S mac-origen] [-ardl segundos] [-Tt ms] [-n no] [-i intervalo] interfaz [objetivo]

OPCIONES

 -A red/prefijo  añadir red de autoconfiguración (hasta 16 veces)
 -a segundos     vida útil del prefijo -A (por defecto 99999)
 -R red/prefijo  añadir una entrada de ruta (hasta 16 veces)
 -r segundos     vida útil de la entrada de ruta -R (por defecto 4096)
 -D servidor-dns añadir un servidor DNS (hasta 16 veces)
 -L lista-busqueda especificar la lista de búsqueda de dominio DNS, separar entradas con ,
 -d segundos     vida útil de la entrada DNS -D (por defecto 4096
 -M mtu          la MTU a enviar, por defecto la configuración de la interfaz
 -s ip-origen    la IP de origen del router, por defecto tu enlace local
 -S mac-origen   la MAC de origen del router, por defecto tu interfaz
 -f mac-ethernet la dirección MAC de ethernet a usar para enviar los frames
 -l segundos     vida útil del router (por defecto 2048)
 -T ms           temporizador de alcance (por defecto 0)
 -t ms           temporizador de retransmisión (por defecto 0)
 -p prioridad    prioridad "baja", "media", "alta" (por defecto), "reservada"
 -F flags        Establecer una o más de las siguientes banderas: managed, other,
                 homeagent, proxy, reserved; separar por comas
 -E tipo         Opción de evasión de Advertisement Guard de Router. Tipos: 
     F              evasión completa (Windows y FreeBSD)
     H              cabecera simple hop-by-hop
     1              cabecera de fragmentación simple de un solo disparo (se pueden añadir varias)
     D              insertar una cabecera de destino grande para que fragmente
     O              fragmentos superpuestos para objetivos de mantener primero (Win, BSD, Mac)
     o              fragmentos superpuestos para objetivos de mantener último (Linux, Solaris)
                 Ejemplos: -E H111, -E D
 -m direccion-mac si solo una máquina debe recibir las RA (no con -E DoO)
 -i intervalo    tiempo entre paquetes RA (por defecto: 5)
 -n numero       número de RAs a enviar (por defecto: ilimitado)
 -X              limpiar de-anunciando el router falso (por defecto: deshabilitado)
Anunciarse como router e intentar convertirse en el router por defecto.
Si se suministra una dirección enlace local o MAC inexistente, esto resulta en un ataque de denegación de servicio (DOS).
