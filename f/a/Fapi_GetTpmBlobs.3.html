Función de una sola llamada para Fapi_GetTpmBlobs

Obtiene los blobs público y privado de un objeto TPM. Pueden ser cargados con una API de nivel inferior como la SAPI o la ESAPI.

Parámetros

context El FAPI_CONTEXT
path La ruta a la clave para la cual se devolverán los blobs
tpm2bPublic El área pública devuelta del objeto. Puede ser NULL
tpm2bPublicSize El tamaño de tpm2bPublic en bytes. Puede ser NULL
tpm2bPrivate El área privada devuelta del objeto. Puede ser NULL
tpm2bPrivateSize El tamaño de tpm2bPrivate en bytes. Puede ser NULL
policy La política asociada con el objeto codificada en JSON. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o path es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si path no corresponde a una entidad FAPI.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no pueden ser guardados.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI no fue aprovisionada.
