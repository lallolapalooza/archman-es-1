TSS2_RC Fapi_Provision (FAPI_CONTEXT * context, char const * authValueEh, char const * authValueSh, char const * authValueLockout)

Función de llamada única para la provisión inicial de FAPI.

Proporciona un TSS con su TPM. Esto incluye el establecimiento de contraseñas importantes y configuraciones de políticas, así como la lectura del EK y su certificado y la inicialización del almacén de claves de todo el sistema.

Parámetros

context El FAPI_CONTEXT.
authValueEh El valor de autorización para la jerarquía de respaldo. Puede ser NULL
authValueSh El valor de autorización para la jerarquía de almacenamiento. Debe ser NULL
authValueLockout El valor de autorización para el bloqueo.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_NO_CERT si no se encontró ningún certificado para el EK calculado.
TSS2_FAPI_RC_BAD_KEY si la clave pública del EK no coincide con el certificado configurado o la huella digital configurada no coincide con el EK calculado.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función debe llamarse de nuevo.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no se establece un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto digest de política no tuvo éxito.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si el objeto ya existe en el almacén de objetos.

TSS2_RC Fapi_Provision_Async (FAPI_CONTEXT * context, char const * authValueEh, char const * authValueSh, char const * authValueLockout)

Función asíncrona para la provisión inicial de FAPI.

Proporciona un TSS con su TPM. Esto incluye el establecimiento de contraseñas importantes y configuraciones de políticas, así como la lectura del EK y su certificado y la inicialización del almacén de claves de todo el sistema.

Llame a Fapi_Provision_Finish para finalizar la ejecución de este comando.

Parámetros

context El FAPI_CONTEXT.
authValueEh El valor de autorización para la jerarquía de respaldo. Puede ser NULL
authValueSh El valor de autorización para la jerarquía de almacenamiento. Debe ser NULL
authValueLockout El valor de autorización para el bloqueo.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
