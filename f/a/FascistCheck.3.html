NOMBRE

FascistCheck - una biblioteca de verificación proactiva de contraseñas

SINOPSIS

#include <crack.h>

static char const CRACKLIB_DICTPATH[] =  ...;

extern char const *
FascistCheck(char const passwd[], char const dictpath[]);

DESCRIPCIÓN

cracklib es una biblioteca que contiene la función C FascistCheck que puede ser utilizada en un programa tipo "passwd". La idea es simple: intentar prevenir que los usuarios elijan contraseñas que puedan ser adivinadas por "crack" filtrándolas en origen. cracklib es una derivación de la versión 5 del software "crack" y contiene un número considerable de ideas tomadas del nuevo software.

El primer argumento formal password es la contraseña potencial. El segundo argumento formal dictpath es el nombre de ruta completo + prefijo de archivo de la base de datos del diccionario de cracklib. FascistCheck devuelve el puntero NULL para una contraseña buena, o un puntero a una cadena de diagnóstico si es una contraseña débil.

La base de datos tiene un formato binario generado por las utilidades crack_mkdict(8) y crack_packer(8). En un sistema Debian, la base de datos se encuentra en el directorio definido por la constante estática CRACKLIB_DICTPATH y está configurada a /var/cache/cracklib/cracklib_dict. Ninguna de las subrutinas en las bibliotecas de cracklib tiene esta ubicación codificada en sus implementaciones. Se genera diariamente con el programa /etc/cron.daily/cracklib.

ARCHIVOS

/var/cache/cracklib/cracklib_dict.[hwm|pwd|pwi]
Archivos de la base de datos del diccionario de cracklib utilizados por las utilidades.
/etc/cron.daily/cracklib
Programa cron diario de cracklib para reconstruir la base de datos del diccionario de cracklib.
/etc/cracklib/cracklib.conf
Archivo de configuración de cracklib utilizado por el programa cron diario de cracklib para reconstruir la base de datos del diccionario de cracklib.
/usr/sbin/crack_mkdict
Script de shell de cracklib para crear una lista inicial de palabras para la base de datos del diccionario.
/usr/share/doc/cracklib2-dev/examples
Archivos de origen de ejemplo de cc(1) que muestran cómo se utiliza FascistCheck.
