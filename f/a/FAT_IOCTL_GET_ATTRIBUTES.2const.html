FAT_IOCTL_SET_ATTRIBUTES(2const) FAT_IOCTL_SET_ATTRIBUTES(2const)

NOMBRE

FAT_IOCTL_GET_ATTRIBUTES, FAT_IOCTL_SET_ATTRIBUTES - obtener y establecer atributos de archivo en un sistema de archivos FAT

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <linux/msdos_fs.h>  /* Definición de las constantes FAT_* y
                                ATTR_* */
#include <sys/ioctl.h>
int ioctl(int fd, FAT_IOCTL_GET_ATTRIBUTES, uint32_t *attr);
int ioctl(int fd, FAT_IOCTL_SET_ATTRIBUTES, uint32_t *attr);

DESCRIPCIÓN

Los archivos y directorios en el sistema de archivos FAT poseen una máscara de bits de atributos que se puede leer con FAT_IOCTL_GET_ATTRIBUTES y escribir con FAT_IOCTL_SET_ATTRIBUTES.

El argumento fd contiene un descriptor de archivo para un archivo o directorio. Es suficiente crear el descriptor de archivo llamando a open(2) con la bandera O_RDONLY.

El argumento attr contiene un puntero a una máscara de bits. Los bits de la máscara de bits son:

ATTR_RO
Este bit especifica que el archivo o directorio es de solo lectura.
ATTR_HIDDEN
Este bit especifica que el archivo o directorio está oculto.
ATTR_SYS
Este bit especifica que el archivo es un archivo del sistema.
ATTR_VOLUME
Este bit especifica que el archivo es una etiqueta de volumen. Este atributo es de solo lectura.
ATTR_DIR
Este bit especifica que este es un directorio. Este atributo es de solo lectura.
ATTR_ARCH
Este bit indica que este archivo o directorio debe ser archivado. Se establece cuando se crea o modifica un archivo. Un sistema de archivado lo restablece.

El valor cero ATTR_NONE se puede usar para indicar que no se establece ningún bit de atributo.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece la variable errno para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.12.

EJEMPLOS

El siguiente programa demuestra el uso de ioctl(2) para manipular atributos de archivo. El programa lee y muestra el atributo de archivo de un archivo. Después de invertir el valor del atributo, el programa lee y muestra el atributo de nuevo.

Lo siguiente se registró al aplicar el programa al archivo /mnt/user/foo:


# ./toggle_fat_archive_flag /mnt/user/foo
Archive flag is set
Toggling archive flag
Archive flag is not set

Código fuente del programa (toggle_fat_archive_flag.c)

#include <fcntl.h>
#include <linux/msdos_fs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
/*
 * Lee los atributos de archivo de un archivo en un sistema de archivos FAT.
 * Muestra el estado de la bandera de archivo.
 */
static uint32_t
readattr(int fd)
{
    int       ret;
    uint32_t  attr;
    ret = ioctl(fd, FAT_IOCTL_GET_ATTRIBUTES, &attr);
    if (ret == -1) {
        perror("ioctl");
        exit(EXIT_FAILURE);
    }
    if (attr & ATTR_ARCH)
        printf("Archive flag is set\n");
    else
        printf("Archive flag is not set\n");
    return attr;
}
int
main(int argc, char *argv[])
{
    int       fd;
    int       ret;
    uint32_t  attr;
    if (argc != 2) {
        printf("Usage: %s FILENAME\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /*
     * Lee y muestra los atributos de archivo FAT.
     */
    attr = readattr(fd);
    /*
     * Invierte el atributo de archivo.
     */
    printf("Toggling archive flag\n");
    attr ^= ATTR_ARCH;
    /*
     * Escribe los atributos de archivo FAT modificados.
     */
    ret = ioctl(fd, FAT_IOCTL_SET_ATTRIBUTES, &attr);
    if (ret == -1) {
        perror("ioctl");
        exit(EXIT_FAILURE);
    }
    /*
     * Lee y muestra los atributos de archivo FAT.
     */
    readattr(fd);
    close(fd);
    exit(EXIT_SUCCESS);
}
