Función de una sola llamada para Fapi_VerifySignatur

Verifica una firma usando una clave pública encontrada en un

keyPath.

Parámetro

s
context El FAPI_CONTEXT
keyPath La ruta a la clave pública de verificación
digest El que fue firmado. Debe estar ya hasheado
digestSize el tamaño del digest en bytes
signature La firma a verificar
signatureSize El tamaño de la firma en
bytes

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, keyPath, signature o digest es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta una corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si keyPath no corresponde a un objeto FAPI.
TSS2_FAPI_RC_BAD_KEY si el objeto en publicKeyPath no es una clave, o es una clave que no es adecuada para la operación solicitada.
TSS2_FAPI_RC_BAD_VALUE si la firma es inválida (tiene el formato incorrecto) o si digestSize es cero.
TSS2_FAPI_RC_SIGNATURE_VERIFICATION_FAILED si la firma no se verifica correctamente.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
