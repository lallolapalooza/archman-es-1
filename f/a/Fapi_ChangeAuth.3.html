TSS2_RC Fapi_ChangeAuth (FAPI_CONTEXT * context, char const * entityPath, char const *

authValue)

Función de una sola llamada para

Fapi_ChangeAuth

Cambia los datos de autorización de una entidad encontrada en keyPath. El parámetro authValue es una contraseña codificada en UTF-8 terminada en 0. Si es más larga que el tamaño de resumen del nameAlg de la entidad, se le aplicará un hash de acuerdo con la especificación TPM parte 1, rev 138, sección 19.6.4.

3.

Parámetro

s

entityPath La ruta hacia la entidad a modificar
authValue La nueva contraseña terminada en 0 a establecer para la entidad. Puede ser
NULL
