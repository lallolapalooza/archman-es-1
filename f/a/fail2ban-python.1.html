FAIL2BAN-PYTHON(1) Comandos de usuario FAIL2BAN-PYTHON(1)

NOMBRE

fail2ban-python - una utilidad para Fail2Ban para asegurar que se utiliza el mismo Python

DESCRIPCIÓN

uso: fail2ban-python [opción] ... [-c cmd | -m mod | archivo | -] [arg] ... Opciones (y variables de entorno correspondientes): -b : emite advertencias sobre str(instancia_bytes), str(instancia_bytearray)

y comparaciones de bytes/bytearray con str. (-bb: emite errores)

-B : no escribir archivos .pyc al importar; también PYTHONDONTWRITEBYTECODE=x -c cmd : programa pasado como cadena (termina la lista de opciones) -d : activar la salida de depuración del analizador (sólo para expertos, sólo funciona en

compilaciones de depuración); también PYTHONDEBUG=x

-E : ignorar variables de entorno PYTHON* (como PYTHONPATH) -h : imprimir este mensaje de ayuda y salir (también -? o --help) -i : inspeccionar interactivamente después de ejecutar el script; fuerza un prompt incluso

si la entrada estándar no parece ser una terminal; también PYTHONINSPECT=x

-I : aislar Python del entorno del usuario (implica -E y -s) -m mod : ejecutar el módulo de biblioteca como un script (termina la lista de opciones) -O : eliminar las sentencias assert y dependientes de __debug__; añadir .opt-1 antes de

la extensión .pyc; también PYTHONOPTIMIZE=x

-OO : hacer los cambios de -O y también descartar docstrings; añadir .opt-2 antes de

la extensión .pyc

-P : no anteponer una ruta potencialmente insegura a sys.path -q : no imprimir mensajes de versión y copyright al inicio interactivo -s : no añadir el directorio de sitio del usuario a sys.path; también PYTHONNOUSERSITE -S : no implicar 'import site' al inicializar -u : forzar que los flujos de salida estándar (stdout) y error estándar (stderr) no tengan búfer;

esta opción no tiene efecto en la entrada estándar; también PYTHONUNBUFFERED=x

-v : detallado (rastrear sentencias de importación); también PYTHONVERBOSE=x

se puede suministrar varias veces para aumentar el detalle

-V : imprimir el número de versión de Python y salir (también --version)

cuando se da dos veces, imprime más información sobre la compilación

-W arg : control de advertencias; arg es acción:mensaje:categoría:módulo:lineno

también PYTHONWARNINGS=arg

-x : omitir la primera línea de código fuente, permitiendo el uso de formas no Unix de #!cmd -X opt : establecer opción específica de la implementación --check-hash-based-pycs always|default|never:

controla cómo Python invalida los archivos .pyc basados en hash

--help-env : imprimir ayuda sobre variables de entorno de Python y salir --help-xoptions : imprimir ayuda sobre opciones específicas de la implementación -X y salir --help-all : imprimir información de ayuda completa y salir Argumentos: archivo : programa leído del archivo script - : programa leído de la entrada estándar (por defecto; modo interactivo si es una tty) arg ...: argumentos pasados al programa en sys.argv[1:]
