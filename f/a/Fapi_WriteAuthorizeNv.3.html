TSS2_RC Fapi_WriteAuthorizeNv (FAPI_CONTEXT * context, char const * nvPath, char const * policyPath)

Función de llamada única para Fapi_WriteAuthorizeNv

Escribe el policyDigest de una política en un índice NV para que pueda ser utilizado en políticas que contengan elementos PolicyAuthorizeNV.

Parámetros

context El FAPI_CONTEXT
nvPath La ruta del índice NV
policyPath La ruta de la nueva política

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o path es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si nvPath o policyPath no se mapean a una FAPI política o índice NV.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no pueden ser guardados.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha finalizado y esta función debe ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionada.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si la devolución de llamada de autorización requerida no está establecida.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un digest de política determinado no fue exitosa.

TSS2_RC Fapi_WriteAuthorizeNv_Async (FAPI_CONTEXT * context, char const * nvPath, char const * policyPath)

Función asíncrona para Fapi_WriteAuthorizeNv

Escribe el policyDigest de una política en un índice NV para que pueda ser utilizado en políticas que contengan elementos PolicyAuthorizeNV.

Llame a Fapi_WriteAuthorizeNv_Finish para finalizar la ejecución de este comando.

Parámetros

context El FAPI_CONTEXT

Valores de retorno

TSS2_FAPI_RC_BAD_REFERENCE si context o path es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si nvPath o policyPath no se mapean a una FAPI política o índice NV.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no pueden ser guardados.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionada.
