FAIL2BAN-CLIENT(1) Comandos de usuario FAIL2BAN-CLIENT(1)

NOMBRE

fail2ban-client - configurar y controlar el servidor

SINOPSIS

fail2ban-client [OPCIONES] <COMANDO>

DESCRIPCIÓN

Fail2Ban v1.1.0 lee un archivo de registro que contiene informes de fallos de contraseña y bloquea las direcciones IP correspondientes usando reglas de firewall.

OPCIONES

-c, --conf <DIR>
directorio de configuración
-s, --socket <FILE>
ruta del socket
-p, --pidfile <FILE>
ruta del archivo pid
--pname <NAME>
nombre del proceso (hilo principal) para identificar la instancia (por defecto fail2ban-server)
--loglevel <LEVEL>
nivel de registro
--logtarget <TARGET>
destino de registro, use nombre de archivo o stdout, stderr, syslog o sysout.

--syslogsocket auto|<FILE>

-d
volcar la configuración. Para depuración
--dp, --dump-pretty
volcar la configuración usando una representación más legible para humanos
-t, --test
probar la configuración (también se puede especificar con los parámetros de inicio)
-i
modo interactivo
-v
aumentar el nivel de detalle
-q
disminuir el nivel de detalle
-x
forzar la ejecución del servidor (eliminar el archivo socket)
-b
iniciar el servidor en segundo plano (por defecto)
-f
iniciar el servidor en primer plano
--async
iniciar el servidor en modo asíncrono (solo para uso interno, no leer la configuración)
--timeout
tiempo de espera por el servidor (solo para uso interno, no leer la configuración)
--str2sec <STRING>
convertir el formato de abreviatura de tiempo a segundos
-h, --help
mostrar este mensaje de ayuda
-V, --version
imprimir la versión (-V devuelve un formato corto legible por máquina)

COMANDO

BÁSICO
start
inicia el servidor y las cárceles
restart
reinicia el servidor
restart [--unban] [--if-exists] <JAIL>
reinicia la cárcel <JAIL> (alias de 'reload --restart ... <JAIL>')
reload [--restart] [--unban] [--all]
recarga la configuración sin reiniciar el servidor, la opción '--restart' activa el reinicio completo de las cárceles afectadas, por lo que puede desbloquear direcciones IP (si se especifica la opción '--unban')
reload [--restart] [--unban] [--if-exists] <JAIL>
recarga la cárcel <JAIL>, o la reinicia (si se especifica la opción '--restart')
stop
detiene todas las cárceles y termina el servidor
unban --all
desbloquea todas las direcciones IP (en todas las cárceles y en la base de datos)
unban <IP> ... <IP>
desbloquea <IP> (en todas las cárceles y en la base de datos)
banned
devuelve las cárceles con IPs bloqueadas como diccionario
banned <IP> ... <IP>]
devuelve la(s) lista(s) de cárceles donde la(s) IP(s) dada(s) están bloqueadas
status
obtiene el estado actual del servidor
status --all [FLAVOR]
obtiene el estado actual de todas las cárceles, con información opcional o extendida
stat[istic]s
obtiene las estadísticas actuales de todas las cárceles como tabla
ping
comprueba si el servidor está activo
echo
para uso interno, devuelve e imprime una cadena dada
help
devuelve esta salida
version
devuelve la versión del servidor
REGISTRO
set loglevel <LEVEL>
establece el nivel de registro a <LEVEL>. Niveles: CRITICAL, ERROR, WARNING, NOTICE, INFO, DEBUG, TRACEDEBUG, HEAVYDEBUG o el valor numérico correspondiente (50-5)
get loglevel
obtiene el nivel de registro
set logtarget <TARGET>
establece el destino de registro a <TARGET>. Puede ser STDOUT, STDERR, SYSLOG, SYSTEMD-JOURNAL o un archivo
get logtarget
obtiene el destino de registro
set syslogsocket auto|<SOCKET>
establece la ruta del socket de syslog a auto o <SOCKET>. Solo se usa si logtarget es SYSLOG
get syslogsocket
obtiene la ruta del socket de syslog
flushlogs
vacía el destino de registro si es un archivo y lo reabre. Para rotación de registros.
BASE DE DATOS
set dbfile <FILE>
establece la ubicación del almacén de datos persistente de fail2ban. Establezca a "None" para desactivarlo
get dbfile
obtiene la ubicación del almacén de datos persistente de fail2ban
set dbmaxmatches <INT>
establece el número máximo de coincidencias almacenadas en la base de datos por ticket
get dbmaxmatches
obtiene el número máximo de coincidencias almacenadas en la base de datos por ticket
set dbpurgeage <SECONDS>
establece la edad máxima en <SECONDS> que se conservará el historial de bloqueos
get dbpurgeage
obtiene la edad máxima en segundos que se conservará el historial de bloqueos
CONTROL DE CÁRCELES
add <JAIL> <BACKEND>
crea <JAIL> usando <BACKEND>
start <JAIL>
inicia la cárcel <JAIL>
stop <JAIL>
detiene la cárcel <JAIL>. La cárcel es eliminada
status <JAIL> [FLAVOR]
obtiene el estado actual de <JAIL>, con información opcional o extendida
CONFIGURACIÓN DE CÁRCELES
set <JAIL> idle on|off
establece el estado de inactividad de <JAIL>d>
set <JAIL> ignoreself true|false
permite ignorar las propias direcciones IP
set <JAIL> addignoreip <IP>
añade <IP> a la lista de ignorados de <JAIL>
set <JAIL> delignoreip <IP>
elimina <IP> de la lista de ignorados de <JAIL>
set <JAIL> ignorecommand <VALUE>
establece ignorecommand de <JAIL>
set <JAIL> ignorecache <VALUE>
establece ignorecache de <JAIL>
set <JAIL> addlogpath <FILE> ['tail']
añade <FILE> a la lista de monitoreo de <JAIL>, opcionalmente comenzando desde el 'tail' del archivo (por defecto 'head').
set <JAIL> dellogpath <FILE>
elimina <FILE> de la lista de monitoreo de <JAIL>
set <JAIL> logencoding <ENCODING>
establece la <ENCODING> de los archivos de registro para <JAIL>
set <JAIL> addjournalmatch <MATCH>
añade <MATCH> al filtro de journal de <JAIL>
set <JAIL> deljournalmatch <MATCH>
elimina <MATCH> del filtro de journal de <JAIL>
set <JAIL> addfailregex <REGEX>
añade la expresión regular <REGEX> que debe coincidir con fallos para <JAIL>
set <JAIL> delfailregex <INDEX>
elimina la expresión regular en <INDEX> para failregex
set <JAIL> addignoreregex <REGEX>
añade la expresión regular <REGEX> que debe coincidir con patrones a excluir para <JAIL>
set <JAIL> delignoreregex <INDEX>
elimina la expresión regular en <INDEX> para ignoreregex
set <JAIL> findtime <TIME>
establece el número de segundos <TIME> hacia atrás que el filtro buscará para <JAIL>
set <JAIL> bantime <TIME>
establece el número de segundos <TIME> que un host será baneado para <JAIL>
set <JAIL> datepattern <PATTERN>
establece el <PATTERN> usado para coincidir con fechas/horas para <JAIL>
set <JAIL> usedns <VALUE>
establece el modo usedns para <JAIL>
set <JAIL> attempt <IP> [<failure1> ... <failureN>]
notifica manualmente sobre un fallo de <IP>
set <JAIL> banip <IP> ... <IP>
Banea manualmente <IP> para <JAIL>
set <JAIL> unbanip [--report-absent] <IP> ... <IP>
Desbanea manualmente <IP> en <JAIL>
set <JAIL> maxretry <RETRY>
establece el número de fallos <RETRY> antes de banear al host para <JAIL>
set <JAIL> maxmatches <INT>
establece el número máximo de coincidencias almacenadas en memoria por ticket en <JAIL>
set <JAIL> maxlines <LINES>
establece el número de <LINES> a almacenar en búfer para la búsqueda de expresiones regulares para <JAIL>
set <JAIL> addaction <ACT>[ <PYTHONFILE> <JSONKWARGS>]
añade una nueva acción llamada <ACT> para <JAIL>. Opcionalmente para una acción basada en Python, se puede especificar un <PYTHONFILE> y <JSONKWARGS>, de lo contrario será una Acción de Comando
set <JAIL> delaction <ACT>
elimina la acción <ACT> de <JAIL>
CONFIGURACIÓN DE ACCIÓN DE COMANDO
set <JAIL> action <ACT> actionstart <CMD>
establece el comando de inicio <CMD> de la acción <ACT> para <JAIL>
set <JAIL> action <ACT> actionstop <CMD> establece el comando de parada <CMD> de la
acción <ACT> para <JAIL>
set <JAIL> action <ACT> actioncheck <CMD>
establece el comando de verificación <CMD> de la acción <ACT> para <JAIL>
set <JAIL> action <ACT> actionban <CMD>
establece el comando de baneo <CMD> de la acción <ACT> para <JAIL>
set <JAIL> action <ACT> actionunban <CMD>
establece el comando de desbaneo <CMD> de la acción <ACT> para <JAIL>
set <JAIL> action <ACT> timeout <TIMEOUT>
establece <TIMEOUT> como el tiempo de espera del comando en segundos para la acción <ACT> para <JAIL>
CONFIGURACIÓN GENERAL DE ACCIÓN
set <JAIL> action <ACT> <PROPERTY> <VALUE>
establece el <VALUE> de <PROPERTY> para la acción <ACT> para <JAIL>
set <JAIL> action <ACT> <METHOD>[ <JSONKWARGS>]
llama al <METHOD> con <JSONKWARGS> para la acción <ACT> para <JAIL>
INFORMACIÓN DE JAIL
get <JAIL> banned
devuelve las IPs baneadas de <JAIL>
get <JAIL> banned <IP> ... <IP>]
devuelve 1 si la IP está baneada en <JAIL>, de lo contrario 0, o una lista de 1/0 para múltiples IPs
get <JAIL> logpath
obtiene la lista de los archivos monitoreados para <JAIL>
get <JAIL> logencoding
obtiene la codificación de los archivos de registro para <JAIL>
get <JAIL> journalmatch
obtiene la coincidencia del filtro de journal para <JAIL>
get <JAIL> ignoreself
obtiene el valor actual de ignorar las propias direcciones IP
get <JAIL> ignoreip
obtiene la lista de direcciones IP ignoradas para <JAIL>
get <JAIL> ignorecommand
obtiene ignorecommand de <JAIL>
get <JAIL> failregex
obtiene la lista de expresiones regulares que coinciden con los fallos para <JAIL>
get <JAIL> ignoreregex
obtiene la lista de expresiones regulares que coinciden con patrones a ignorar para <JAIL>
get <JAIL> findtime
obtiene el tiempo hacia atrás que el filtro buscará fallos para <JAIL>
get <JAIL> bantime
obtiene el tiempo que un host está baneado para <JAIL>
get <JAIL> datepattern
obtiene el patrón usado para coincidir con fechas/horas para <JAIL>
get <JAIL> usedns
obtiene la configuración de usedns para <JAIL>
get <JAIL> banip [<SEP>|--with-time]
obtiene la lista de direcciones IP baneadas para <JAIL>. Opcionalmente se puede especificar el carácter separador ('<SEP>', por defecto es espacio) o la opción ' --with-time' (imprimiendo los tiempos de baneo). Las IPs están ordenadas por fin de baneo.
get <JAIL> maxretry
obtiene el número de fallos permitidos para <JAIL>
get <JAIL> maxmatches
obtiene el número máximo de coincidencias almacenadas en memoria por ticket en <JAIL>
get <JAIL> maxlines
obtiene el número de líneas a almacenar en búfer para <JAIL>
get <JAIL> actions
obtiene una lista de acciones para <JAIL>
INFORMACIÓN DE ACCIÓN DE COMANDO
get <JAIL> action <ACT> actionstart
obtiene el comando de inicio para la acción <ACT> para <JAIL>
get <JAIL> action <ACT> actionstop
obtiene el comando de parada para la acción <ACT> para <JAIL>
get <JAIL> action <ACT> actioncheck
obtiene el comando de verificación para la acción <ACT> para <JAIL>
get <JAIL> action <ACT> actionban
obtiene el comando de baneo para la acción <ACT> para <JAIL>
get <JAIL> action <ACT> actionunban
obtiene el comando de desbaneo para la acción <ACT> para <JAIL>
get <JAIL> action <ACT> timeout
obtiene el tiempo de espera del comando en segundos para la acción <ACT> para <JAIL>
INFORMACIÓN GENERAL DE ACCIONES
get <JAIL> actionproperties <ACT>
obtiene una lista de propiedades para la acción <ACT> para <JAIL>
get <JAIL> actionmethods <ACT>
obtiene una lista de métodos para la acción <ACT> para <JAIL>
get <JAIL> action <ACT> <PROPERTY>
obtiene el valor de <PROPERTY> para la acción <ACT> para <JAIL>
