FAILLOG(8) Comandos de Administración del Sistema FAILLOG(8)

NOMBRE

faillog - muestra registros de faillog o establece límites de fallos de inicio de sesión

SINOPSIS

faillog [opciones]

DESCRIPCIÓN

faillog muestra el contenido de la base de datos de registros de fallos (/var/log/faillog). También puede establecer los contadores y límites de fallos. Cuando faillog se ejecuta sin argumentos, solo muestra los registros de faillog de los usuarios que tuvieron un fallo de inicio de sesión.

OPCIONES

Las opciones que se aplican al comando faillog son:

-a, --all

Muestra (o actúa sobre) los registros de faillog para todos los usuarios que tienen una entrada en la base de datos de faillog.

El rango de usuarios puede ser restringido con la opción -u.

En modo de visualización, esto todavía se restringe a los usuarios existentes, pero fuerza la visualización de las entradas de faillog, incluso si están vacías.

Con las opciones -l, -m, -r, -t, se modifican los registros de los usuarios, incluso si el usuario no existe en el sistema. Esto es útil para restablecer los registros de usuarios que han sido eliminados o para establecer una política por adelantado para un rango de usuarios.

-h, --help

Muestra el mensaje de ayuda y sale.

-l, --lock-secs SEC

Bloquea la cuenta durante SEC segundos después de un inicio de sesión fallido.

Se requiere acceso de escritura a /var/log/faillog para esta opción.

-m, --maximum MAX

Establece el número máximo de fallos de inicio de sesión después de los cuales la cuenta se deshabilita a MAX.

Seleccionar un valor MAX de 0 tiene el efecto de no colocar un límite en el número de inicios de sesión fallidos.

El recuento máximo de fallos siempre debe ser 0 para root para evitar un ataque de denegación de servicio contra el sistema.

Se requiere acceso de escritura a /var/log/faillog para esta opción.

-r, --reset

Restablece los contadores de fallos de inicio de sesión.

Se requiere acceso de escritura a /var/log/faillog para esta opción.

-R, --root CHROOT_DIR

Aplica cambios en el directorio CHROOT_DIR y utiliza los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

-t, --time DAYS

Muestra registros de faillog más recientes que DAYS.

-u, --user LOGIN|RANGE

Muestra el registro de faillog o mantiene los contadores y límites de fallos (si se usa con las opciones -l, -m o -r) solo para el/los usuario(s) especificado(s).

Los usuarios pueden especificarse por nombre de inicio de sesión, ID de usuario numérico o un RANGO de usuarios. Este RANGO de usuarios se puede especificar con valores mínimo y máximo (UID_MIN-UID_MAX), un valor máximo (-UID_MAX) o un valor mínimo (UID_MIN-).

Cuando no se utilizan las opciones -l, -m o -r, faillog muestra el registro de faillog del/los usuario(s) especificado(s).

ADVERTENCIAS

faillog solo muestra los usuarios sin un inicio de sesión exitoso desde el último fallo. Para mostrar un usuario que ha tenido un inicio de sesión exitoso desde su último fallo, debe solicitar explícitamente al usuario con la opción -u, o mostrar a todos los usuarios con la opción -a.

ARCHIVOS

/var/log/faillog

Archivo de registro de fallos.

VER TAMBIÉN

login(1), faillog(5).
