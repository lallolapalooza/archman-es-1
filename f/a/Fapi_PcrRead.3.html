TSS2_RC Fapi_PcrRead (FAPI_CONTEXT * context, uint32_t pcrIndex, uint8_t ** pcrValue, size_t * pcrValueSize, char ** pcrLog)

Función de llamada única para Fapi_PcrRead

Lee de un PCR dado y devuelve el valor y el registro de eventos.

Parámetros

context El FAPI_CONTEXT
pcrIndex El índice del PCR a leer
pcrValue El valor del PCR. Puede ser NULL
pcrValueSize El tamaño del valor en bytes. Puede ser NULL
pcrLog El registro del PCR. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context, pcrValue o pcrValueSize es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_VALUE si pcrIndex no es válido.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha finalizado y esta función debe llamarse de nuevo.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no se establece una devolución de llamada de autorización requerida.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un determinado resumen de política no tuvo éxito.
TSS2_FAPI_RC_NO_CERT si ocurrió un error durante la descarga del certificado.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
