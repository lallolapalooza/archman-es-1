TSS2_RC Fapi_Import (FAPI_CONTEXT * context, char const * path, char const *

importData)

Función de una sola llamada para

Fapi_Import

Importa una política, plantilla de política o clave codificada en JSON y la almacena en la ruta

dada.

Parámetro

s
context El FAPI_CONTEXT
path la ruta a la que se importa el objeto
importData Los datos que se
importan

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, path o importData es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta una corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH Si path no corresponde a una política o clave de FAPI.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si ya existe una política o clave en path.
TSS2_FAPI_RC_BAD_VALUE si importData contiene datos no válidos.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no está establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto resumen de política no fue exitosa.
TSS2_ESYS_RC_* códigos de error posibles de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED
FAPI no fue
aprovisionado.
