FAIL2BAN-REGEX(1) Comandos de usuario FAIL2BAN-REGEX(1)

NOMBRE

fail2ban-regex - probar la opción "failregex" de Fail2ban

SINOPSIS

fail2ban-regex [OPCIONES] <LOG> <REGEX> [IGNOREREGEX]

DESCRIPCIÓN

Fail2Ban lee un archivo de registro que contiene informes de fallos de contraseña y banea las direcciones IP correspondientes usando reglas de firewall.

Esta herramienta puede probar expresiones regulares para "fail2ban".

LOG:

cadena
una cadena que representa una línea de registro
nombre de archivo
ruta a un archivo de registro (/var/log/auth.log)
systemd-journal
busca en el diario de systemd (se requiere systemd-python), opcionalmente con parámetros de backend, ver `man jail.conf` para uso y ejemplos (systemd-journal[journalflags=1]).

REGEX:

cadena
una cadena que representa un 'failregex'
filtro
nombre del filtro, opcionalmente con opciones (sshd[mode=aggressive])
nombre de archivo
ruta a un archivo de filtro (filter.d/sshd.conf)

IGNOREREGEX:

cadena
una cadena que representa un 'ignoreregex'
nombre de archivo
ruta a un archivo de filtro (filter.d/sshd.conf)

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
-c CONFIG, --config=CONFIG
establece un directorio de configuración alternativo
-d DATEPATTERN, --datepattern=DATEPATTERN
establece un patrón personalizado usado para hacer coincidir fechas/horas
--timezone=TIMEZONE, --TZ=TIMEZONE
establece la zona horaria usada por el convertidor de formato de hora
-e ENCODING, --encoding=ENCODING
Codificación del archivo. Por defecto: configuración regional del sistema
-r, --raw
Hosts en bruto, no resolver dns
--usedns=USEDNS
Reemplazo de DNS especificado de las etiquetas <HOST> en la expresión regular ('yes' - coincide con todas las formas de hosts, 'no' - solo direcciones IP)
-L MAXLINES, --maxlines=MAXLINES
número máximo de líneas para regex multilínea.
-m JOURNALMATCH, --journalmatch=JOURNALMATCH
coincidencias al estilo de journalctl que anulan el archivo de filtro. Solo "systemd-journal"
-l LOG_LEVEL, --log-level=LOG_LEVEL
Nivel de registro para el logger de Fail2Ban
-V
obtener la versión en formato corto legible por máquina
-v, --verbose
Aumentar la verbosidad
--verbosity=VERBOSE
Establecer el nivel numérico de verbosidad (0..4)
--verbose-date, --VD
Patrones/regex de fecha detallados en la salida
-D, --debuggex
Producir urls de debuggex.com para depurar allí
--no-check-all
Desactivar la comprobación de todas las regex
-o OUT, --out=OUT
Establecer el token para imprimir solo información de fallo (fila, id, ip, msg, host, ip4, ip6, dns, coincidencias, ...)
--print-no-missed
No imprimir ninguna línea perdida
--print-no-ignored
No imprimir ninguna línea ignorada
--print-all-matched
Imprimir todas las líneas coincidentes
--print-all-missed
Imprimir todas las líneas perdidas, sin importar cuántas
--print-all-ignored
Imprimir todas las líneas ignoradas, sin importar cuántas
-t, --log-traceback
Enriquecer los mensajes de registro con trazas comprimidas
--full-traceback
Hacer que las trazas sean completas, no comprimidas (como por defecto)
