NOMBRE

faillock - Herramienta para mostrar y modificar los archivos de registro de fallos de autenticación

SINOPSIS

faillock [--dir /ruta/al/directorio-de-recuento] [--user nombre-de-usuario] [--reset]

DESCRIPCIÓN

El módulo pam_faillock.so mantiene una lista de intentos de autenticación fallidos por usuario durante un intervalo especificado y bloquea la cuenta en caso de que haya habido más de deny autenticaciones fallidas consecutivas. Almacena los registros de fallos en archivos por usuario en el directorio de recuento.

El comando faillock es una aplicación que se puede utilizar para examinar y modificar el contenido de los archivos de recuento. Puede mostrar los intentos recientes de autenticación fallidos del nombre-de-usuario o borrar los archivos de recuento de todos o de usuarios individuales.

OPCIONES

--conf /ruta/al/archivo-de-configuracion

El archivo donde se encuentra la configuración. El valor predeterminado es /etc/security/faillock.conf.

--dir /ruta/al/directorio-de-recuento

El directorio donde se guardan los archivos de usuario con los registros de fallos.

La prioridad para establecer esta opción es usar el valor proporcionado desde la línea de comandos. Si no se proporciona, se utiliza el valor del archivo de configuración. Finalmente, si no se proporciona ninguno de los dos, se utiliza /var/run/faillock.

--user nombre-de-usuario

El usuario cuyos registros de fallos deben mostrarse o borrarse.

--reset

En lugar de mostrar los registros de fallos del usuario, borrarlos.

ARCHIVOS

/var/run/faillock/*

los archivos que registran los fallos de autenticación de los usuarios
