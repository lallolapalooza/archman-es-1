TSS2_RC Fapi_VerifyQuote (FAPI_CONTEXT * context, char const * publicKeyPath, uint8_t const * qualifyingData, size_t qualifyingDataSize, char const * quoteInfo, uint8_t const * signature, size_t signatureSize, char const * pcrLog)

Función de llamada única para Fapi_VerifyQuote

Verifica que los datos devueltos por una cita (quote) sean válidos.

Parámetros

context El FAPI_CONTEXT
publicKeyPath La ruta a la clave de firma
qualifyingData El nonce de datos de calificación. Puede ser NULL
qualifyingDataSize El tamaño de qualifyingData en bytes. Debe ser 0 si qualifyingData es NULL
quoteInfo La información de la cita
signature La firma de la cita
signatureSize El tamaño de signature en bytes
pcrLog El registro de los PCR. Puede ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, publicKeyPath, quoteInfo, o signature es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si la ruta no mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_KEY si la entidad en la ruta no es una clave, o es una clave inadecuada para la operación solicitada.
TSS2_FAPI_RC_BAD_VALUE si quoteInfo, pcrEventLog, qualifyingData, o signature es inválido.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha finalizado y esta función debe ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_SIGNATURE_VERIFICATION_FAILED si la firma no pudo ser verificada.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue provisionado.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.
