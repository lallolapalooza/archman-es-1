TSS2_RC Fapi_NvIncrement (FAPI_CONTEXT * context, char const * nvPath)

Función de una sola llamada para Fapi_NvIncrement

Incrementa en 1 un índice NV que es un contador.

Parámetros

context El FAPI_CONTEXT
nvPath La ruta al índice NV que se incrementa.

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context o nvPath es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta una corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si no se encuentra nvPath.
TSS2_FAPI_RC_NV_WRONG_TYPE si el tipo de índice NV no es TPM2_NT_COUNTER.
TSS2_FAPI_RC_NV_NOT_WRITEABLE si el índice NV no es escribible.
TSS2_FAPI_RC_POLICY_UNKNOWN si la política es desconocida.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no está establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI no fue aprovisionada.
