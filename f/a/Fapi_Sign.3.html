TSS2_RC Fapi_Sign (FAPI_CONTEXT * context, char const * keyPath, char const * padding, uint8_t const * digest, size_t digestSize, uint8_t ** signature, size_t * signatureSize, char ** publicKey, char **

certificate)

Función de una sola llamada para

Fapi_Sign

Utiliza una clave, identificada por su ruta, para firmar un resumen y coloca el resultado en un flujo de bytes

TPM2B.

Parámetro

s
context El FAPI_CONTEXT
keyPath La ruta de la clave de firma
padding Un algoritmo de relleno. Debe ser 'RSA_SSA' o 'RSA_PSS' o NULL
digest El resumen a firmar. Debe estar ya hasheado
digestSize El tamaño del resumen en bytes
signature La firma
signatureSize El tamaño de la firma en bytes. Puede ser NULL
publicKey La clave pública que se puede usar para verificar la firma en formato PEM. Puede ser NULL
certificate El certificado asociado con la clave de firma en formato PEM. Puede ser
NULL

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, keyPath, digest o signature es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si keyPath no corresponde a una clave FAPI.
TSS2_FAPI_RC_BAD_KEY si el objeto en keyPath no es una clave, o es una clave que no es adecuada para la operación solicitada.
TSS2_FAPI_RC_BAD_VALUE si digestSize es cero.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no está establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para cierto resumen de política no fue exitosa.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un cont
exto inapropiado o cont
iene caracteres ilegales.
