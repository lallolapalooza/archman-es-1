fapi-config(5) Manual de Formatos de Archivo fapi-config(5)

VER TAMBIÉN

fapi-profile(5)

DESCRIPCIÓN

Archivo de configuración de FAPI

Los parámetros de FAPI que se pueden ajustar a través del archivo de configuración son:

•
profile_name: Nombre del perfil criptográfico predeterminado elegido del directorio profile_dir.
•
profile_dir: Directorio que contiene todos los perfiles criptográficos conocidos por FAPI.
•
user_dir: El directorio donde se almacenan los objetos de usuario.
•
system_dir: El directorio donde se almacenan los objetos del sistema, las políticas y los objetos importados.
•
tcti: La interfaz TCTI que se utilizará.
•
system_pcrs: Los registros PCR que utiliza el sistema.
•
log_dir: El directorio para el registro de eventos.
•
ek_cert_less: Un interruptor para deshabilitar la verificación del certificado (opcional).
•
ek_fingerprint: La huella digital de la clave de aprobación (opcional).

Si no se especifica lo contrario durante la instalación de TSS, la ubicación predeterminada para los perfiles de ejemplo es /etc/tpm2-tss/profiles/ y /etc/tpm2-tss/ para el archivo de configuración de FAPI. La variable de entorno TSS_FAPICONF se puede usar para establecer una ruta alternativa para el archivo de configuración de FAPI. Si los archivos de medición del sistema (IMA y bios) no existen, se utilizará /dev/null para firmware_log_file e ima_log_file.

EJEMPLOS

El archivo de configuración de FAPI está codificado en JSON:

{
     "profile_name": "P_ECCP256SHA256",
     "profile_dir": "/etc/tpm2-tss/fapi-profiles/",
     "user_dir": "~/.local/share/tpm2-tss/user/keystore/",
     "system_dir": "/home/myhome/keystore/system/keystore",
     "tcti": "",
     "system_pcrs" : [0, 1, 2, 3, 4, 5, 6, 7],
     "log_dir" : "/home/myhome/eventlog/",
     "firmware_log_file" : "/sys/kernel/security/tpm0/binary_bios_measurements",
      "ima_log_file" : "/sys/kernel/security/ima/binary_runtime_measurements"
}

Para este ejemplo se utilizará el TCTI predeterminado del sistema. Se verificarán los certificados de las claves de aprobación almacenadas. Si no se necesita la verificación de certificados, la opción:

"ek_cert_less": "yes" se puede agregar al archivo de configuración. Alternativamente a la verificación estándar de certificados, se puede definir una huella digital (hash de la clave pública) para la clave de aprobación almacenada en el archivo de configuración:

"ek_fingerprint":  {     "hashAlg" : "sha256",     "digest" : "9e56...214d"     }
