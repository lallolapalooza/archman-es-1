TSS2_RC Fapi_GetCertificate (FAPI_CONTEXT * context, char const * path, char ** x509certData)

Función de llamada única para Fapi_GetCertificate

Obtiene un certificado x.509 para la clave en una ruta dada.

Parámetros

context El FAPI_CONTEXT
path La ruta a la clave cuyo certificado se crea
x509certData El certificado codificado en PEM

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, path o x509CertData es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_PATH_NOT_FOUND si la ruta no se mapea a una entidad FAPI.
TSS2_FAPI_RC_BAD_KEY si la clave no es adecuada para la operación solicitada.
TSS2_FAPI_RC_NO_CERTIFICATE si no hay un certificado x.509 asociado con la ruta de la clave.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S no ha terminado todavía y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un contexto inapropiado o contiene caracteres ilegales.

TSS2_RC Fapi_GetCertificate_Finish (FAPI_CONTEXT * context, char ** x509certData)

Función asíncrona de finalización para Fapi_GetCertificate
