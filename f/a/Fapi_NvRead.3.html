TSS2_RC Fapi_NvRead (FAPI_CONTEXT * context, char const * nvPath, uint8_t ** data, size_t * size, char **

logData)

Función de una sola llamada para

Fapi_NvRead

Lee datos de un índice NV dentro del TPM. La FAPI realizará automáticamente las lecturas múltiples si el índice NV es más grande que el TPM2_MAX_NV_BUFFER_SIZE del

TPM.

Parámetro

s
context El FAPI_CONTEXT
nvPath La ruta del índice NV a leer
data Los datos que fueron leídos del índice NV
size El tamaño de los datos en bytes. Puede ser NULL
logData Los datos de registro del índice NV si el índice es de tipo 'extend'. Puede ser
NULL

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context, nvPath o data es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si nvPath no se encuentra.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si la autorización falla.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no se sabe cómo autenticar.
TSS2_FAPI_RC_NV_NOT_READABLE si el NV no es un índice legible.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no pueden ser guardados.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI fue inicializada en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_PATH_NOT_FOUND si una ruta de objeto FAPI no fue encontrada durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si una clave no fue encontrada.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S no ha terminado aún y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto resumen de política no fue exitosa.
