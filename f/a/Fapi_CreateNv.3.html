Función de una sola llamada para

Fapi_CreateNv

Este comando crea un índice NV en el TPM utilizando una ruta y un tipo

dados.

Parámetro

s
context El FAPI_CONTEXT
path La ruta al nuevo índice NV
type El tipo previsto para el nuevo índice NV. Puede ser NULL
size El tamaño del nuevo índice NV en bytes. Puede ser 0 si el tamaño se infiere del tipo
policyPath La ruta a la política que está asociada con el nuevo índice NV. Puede ser NULL
authValue El valor de autorización que está asociado con el nuevo índice NV. Puede ser
NULL

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context o path es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta una corrupción del contexto.
TSS2_FAPI_RC_PATH_ALREADY_EXISTS si ya existe un índice NV en path.
TSS2_FAPI_RC_BAD_VALUE si type no es NULL pero es inválido o no coincide con el tamaño.
TSS2_FAPI_RC_BAD_PATH si policyPath no es NULL y no se corresponde con una política FAPI o si path no se refiere a una ruta de índice NV válida.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para las operaciones internas o los parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y es necesario llamar a esta función de nuevo.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_NV_TOO_SMALL si se han definido demasiados manejadores NV.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no está establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto resumen de política no fue exitosa.
