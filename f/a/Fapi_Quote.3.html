Función de una sola llamada para

Fapi_Quote

Dado un conjunto de PCRs y una clave de firma restringida, firmará esos PCRs y devolverá la

cita.

Parámetro

s
context El FAPI_CONTEXT
pcrList La lista de PCRs que se van a citar
pcrListSize El tamaño de pcrList en bytes
keyPath La ruta a la clave de firma
quoteType El tipo de cita. Puede ser NULL
qualifyingData Un nonce proporcionado por el llamador. Puede ser NULL
qualifyingDataSize El tamaño de qualifyingData en bytes. Debe ser 0 si qualifyingData es NULL
quoteInfo Una estructura codificada en JSON que contiene las entradas para la operación de cita
signature La firma de los PCRs
signatureSize El tamaño de la firma en bytes. Puede ser NULL
pcrLog El registro del PCR. Puede ser NULL
certificate El certificado asociado con la clave de firma. Puede ser
NULL

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context, pcrList, keyPath, quoteInfo o signature es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si la ruta no corresponde a una entidad FAPI.
TSS2_FAPI_RC_BAD_KEY si la entidad en la ruta no es una clave, o es una clave que no es adecuada para la operación solicitada.
TSS2_FAPI_RC_BAD_VALUE si qualifyingData no es válido o si qualifyingDataSize es cero.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para las operaciones internas o los parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.

TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no se ha establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
