FABS(3P) Manual del Programador POSIX FABS(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

fabs, fabsf, fabsl — función de valor absoluto

SINOPSIS

#include <math.h>
double fabs(double x);
float fabsf(float x);
long double fabsl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán el valor absoluto de su argumento x,|x|.

VALOR DE RETORNO

Tras una finalización exitosa, estas funciones devolverán el valor absoluto de x.

Si x es NaN, se devolverá un NaN.

Si x es ±0, se devolverá +0.

Si x es ±Inf, se devolverá +Inf.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Cálculo de la 1-norma de un vector de punto flotante

Este ejemplo muestra el uso de fabs() para calcular la 1-norma de un vector definida de la siguiente manera:

norm1(v) = |v[0]| + |v[1]| + ... + |v[n-1]|

donde |x| denota el valor absoluto de x, n denota la dimensión del vector v[i] denota el componente i de v (0≤i<n).

#include <math.h>
double
norm1(const double v[], const int n)
{
    int     i;
    double  n1_v;  /* 1-norma de v */
    n1_v = 0;
    for (i=0; i<n; i++) {
        n1_v += fabs (v[i]);
    }
    return n1_v;
}
