TSS2_RC Fapi_Decrypt (FAPI_CONTEXT * context, char const * keyPath, uint8_t const * cipherText, size_t cipherTextSize, uint8_t ** plainText, size_t *

plainTextSize)

Función de una sola llamada para

Fapi_Decrypt

Descifra datos que fueron previamente cifrados con

Fapi_Encrypt.

Parámetro

s
context El FAPI_CONTEXT
keyPath La clave de descifrado.
cipherText El texto cifrado a descifrar.
cipherTextSize El tamaño del texto cifrado a descifrar.
plainText el texto cifrado descifrado. Puede ser NULL (asignado por el llamado)
plainTextSize El tamaño del texto cifrado en bytes. Puede ser
NULL

Valores de

retorno
TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si context o cipherText es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se puede encontrar la clave necesaria para descifrar el archivo.
TSS2_FAPI_RC_BAD_KEY si la clave de descifrado no es adecuada para la operación solicitada.
TSS2_FAPI_RC_BAD_VALUE si el descifrado falla
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si la FAPI fue inicializada en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha terminado y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró una ruta de objeto FAPI durante la autorización.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no está establecido un callback de autorización requerido.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si el intento de autorización falla.
TSS2_FAPI_RC_POLICY_UNKNOWN si la búsqueda de política para un cierto resumen de política no fue exitosa.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED La FAPI no fue aprovisionada.
TSS2_FAPI_RC_BAD_PATH si la ruta se usa en un cont
