TSS2_RC Fapi_Initialize (FAPI_CONTEXT ** contexto, char const * uri)

Función de llamada única para Fapi_Initialize

Inicializa un FAPI_CONTEXT que contiene toda la información de estado y metadatos durante una interacción con el TPM.

Parámetros

contexto El FAPI_CONTEXT
uri No se utiliza en esta versión de FAPI. Debe ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si contexto es NULL.
TSS2_FAPI_RC_BAD_VALUE si uri no es NULL.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_TRY_AGAIN si una operación de I/O no ha terminado todavía y esta función necesita ser llamada de nuevo.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_BAD_PATH si se usa una ruta en un contexto inapropiado o contiene caracteres ilegales.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.

TSS2_RC Fapi_Initialize_Async (FAPI_CONTEXT ** contexto, char const * uri)

Función asíncrona para Fapi_Initialize

Inicializa un FAPI_CONTEXT que contiene toda la información de estado y metadatos durante una interacción con el TPM.

Llame a Fapi_Initialize para finalizar la ejecución de este comando.

Parámetros

contexto El FAPI_CONTEXT
uri No se utiliza en esta versión de FAPI. Debe ser NULL

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si contexto es NULL.
TSS2_FAPI_RC_BAD_VALUE si uri no es NULL.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.

TSS2_RC Fapi_Initialize_Finish (FAPI_CONTEXT ** contexto)

Función asíncrona de finalización para Fapi_Initialize

Esta función debe ser llamada después de una llamada previa a Fapi_Initialize_Async.

Parámetros

contexto El FAPI_CONTEXT

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si contexto es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_TRY_AGAIN si la operación asíncrona aún no está completa. Llame a esta función de nuevo más tarde.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_BAD_PATH si se usa una ruta en un contexto inapropiado o contiene caracteres ilegales.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
