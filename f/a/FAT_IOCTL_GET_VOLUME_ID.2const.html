FAT_IOCTL_GET_VOLUME_ID(2const) FAT_IOCTL_GET_VOLUME_ID(2const)

NOMBRE

FAT_IOCTL_GET_VOLUME_ID - leer el ID del volumen en un sistema de archivos FAT

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/msdos_fs.h>  /* Definición de constantes FAT_* */
#include <sys/ioctl.h>
int ioctl(int fd, FAT_IOCTL_GET_VOLUME_ID, uint32_t *id);

DESCRIPCIÓN

Los sistemas de archivos FAT se identifican mediante un ID de volumen. El ID de volumen se puede leer con FAT_IOCTL_GET_VOLUME_ID.

El argumento fd puede ser un descriptor de archivo para cualquier archivo o directorio del sistema de archivos. Es suficiente crear el descriptor de archivo llamando a open(2) con la bandera O_RDONLY.

El argumento id es un puntero al campo que se llenará con el ID del volumen. Típicamente, el ID del volumen se muestra al usuario como un grupo de dos campos de 16 bits:


printf("Volume ID %04x-%04x\n", id >> 16, id & 0xFFFF);

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 3.11.

EJEMPLOS

El siguiente programa demuestra el uso de ioctl(2) para mostrar el ID del volumen de un sistema de archivos FAT.

La siguiente salida se registró al aplicar el programa al directorio /mnt/user:


$ ./display_fat_volume_id /mnt/user
Volume ID 6443-6241

Código fuente del programa (display_fat_volume_id.c)

#include <fcntl.h>
#include <linux/msdos_fs.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int       fd;
    int       ret;
    uint32_t  id;
    if (argc != 2) {
        printf("Usage: %s FILENAME\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDONLY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /*
     * Leer el ID del volumen.
     */
    ret = ioctl(fd, FAT_IOCTL_GET_VOLUME_ID, &id);
    if (ret == -1) {
        perror("ioctl");
        exit(EXIT_FAILURE);
    }
    /*
     * Formatear la salida como dos grupos de 16 bits cada uno.
     */
    printf("Volume ID %04x-%04x\n", id >> 16, id & 0xFFFF);
    close(fd);
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN

ioctl(2), ioctl_fat(2)
