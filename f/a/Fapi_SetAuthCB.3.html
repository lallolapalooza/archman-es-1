TSS2_RC Fapi_SetAuthCB (FAPI_CONTEXT * context, Fapi_CB_Auth callback, void * userData)

Esta función registra una función definida por la aplicación como callback para permitir que el TSS obtenga los valores de autorización de la aplicación.

Parámetros

context El FAPI_CONTEXT
callback La función callback para la recuperación del valor de autorización
userData Un puntero que se proporciona a todas las invocaciones de callback

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue exitosa.
TSS2_FAPI_RC_BAD_REFERENCE si el contexto es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_BAD_SEQUENCE si las funciones síncrona o Asíncrona se llaman mientras el contexto tiene otra operación asíncrona pendiente, o si la función Finish se llama mientras el contexto no tiene una operación asíncrona apropiada pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
