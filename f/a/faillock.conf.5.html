NOMBRE

faillock.conf - archivo de configuración de pam_faillock

DESCRIPCIÓN

faillock.conf proporciona una forma de configurar los ajustes predeterminados para bloquear al usuario después de múltiples intentos fallidos de autenticación. Este archivo es leído por el módulo pam_faillock y es el método preferido sobre la configuración directa de pam_faillock.

El archivo tiene un formato muy simple de nombre = valor con posibles comentarios que comienzan con el carácter #. Se ignora el espacio en blanco al principio de la línea, al final de la línea y alrededor del signo =.

OPCIONES

dir=/ruta/al/directorio/de/recuento

El directorio donde se guardan los archivos de usuario con los registros de fallos. El valor predeterminado es /var/run/faillock.

Nota: Estos archivos desaparecerán después del reinicio en sistemas configurados con el directorio /var/run/faillock montado en memoria virtual.

audit

Registrará el nombre de usuario en el registro del sistema si no se encuentra al usuario.

silent

No mostrar mensajes informativos al usuario. Tenga en cuenta que cuando esta opción no se utiliza, habrá una diferencia en el comportamiento de autenticación para los usuarios que existen en el sistema y los usuarios que no existen.

no_log_info

No registrar mensajes informativos a través de syslog(3).

local_users_only

Solo rastrear los intentos fallidos de autenticación de usuarios locales en /etc/passwd e ignorar los usuarios centralizados (AD, IdM, LDAP, etc.). El comando faillock(8) tampoco rastreará los intentos fallidos de autenticación de usuarios. Habilitar esta opción evitará un escenario de doble bloqueo donde un usuario está bloqueado localmente y en el mecanismo centralizado.

nodelay

No aplicar un retraso después de los fallos de autenticación.

deny=n

Denegar el acceso si el número de fallos de autenticación consecutivos para este usuario durante el intervalo reciente excede n. El valor predeterminado es 3.

fail_interval=n

La duración del intervalo durante el cual deben ocurrir los fallos de autenticación consecutivos para que la cuenta del usuario se bloquee es n segundos. El valor predeterminado es 900 (15 minutos).

unlock_time=n

El acceso se reanudará después de n segundos después del bloqueo. El valor 0 tiene el mismo significado que el valor nunca: el acceso no se reanudará sin restablecer las entradas de faillock mediante el comando faillock(8). El valor predeterminado es 600 (10 minutos).

Tenga en cuenta que el directorio predeterminado que usa pam_faillock generalmente se borra al arrancar el sistema, por lo que el acceso también se reanudará después del reinicio del sistema. Si eso no es deseable, se debe establecer un directorio de recuento diferente con la opción dir.

También tenga en cuenta que generalmente no es deseable bloquear permanentemente a los usuarios, ya que pueden convertirse fácilmente en objetivo de un ataque de denegación de servicio a menos que los nombres de usuario sean aleatorios y se mantengan en secreto para los posibles atacantes.

even_deny_root

La cuenta root puede bloquearse al igual que las cuentas regulares.

root_unlock_time=n

Esta opción implica la opción even_deny_root. Permitir el acceso después de n segundos a la cuenta root después de que la cuenta esté bloqueada. En caso de que la opción no se especifique, el valor es el mismo que el de la opción unlock_time.

admin_group=nombre

Si se especifica un nombre de grupo con esta opción, los miembros del grupo serán manejados por este módulo de la misma manera que la cuenta root (las opciones even_deny_root y root_unlock_time se aplicarán a ellos. Por defecto, la opción no está establecida.

EJEMPLOS

Ejemplo de archivo /etc/security/faillock.conf:

deny=4
unlock_time=1200
silent

ARCHIVOS

/etc/security/faillock.conf

el archivo de configuración para opciones personalizadas
