TSS2_RC Fapi_NvWrite (FAPI_CONTEXT * context, char const * nvPath, uint8_t const * data, size_t size)

Función de llamada única para Fapi_NvWrite

Escribe datos en un índice NV 'regular' (no pin, extend o contador).

Parámetros

context El FAPI_CONTEXT
nvPath La ruta del índice NV a escribir
data Los datos a escribir en el índice NV
size El tamaño de los datos en bytes

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si context, nvPath, o data es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_BAD_PATH si nvPath no se encuentra.
TSS2_FAPI_RC_NV_EXCEEDED si el NV no es lo suficientemente grande para los datos a escribir.
TSS2_FAPI_RC_NV_WRONG_TYPE si el índice NV no es uno 'regular'.
TSS2_FAPI_RC_NV_NOT_WRITEABLE si el NV no es un índice escribible.
TSS2_FAPI_RC_POLICY_UNKNOWN si la política es desconocida.
TSS2_FAPI_RC_BAD_SEQUENCE si el contexto ya tiene una operación asíncrona pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.
TSS2_FAPI_RC_MEMORY si FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_NO_TPM si FAPI se inicializó en modo sin TPM a través de su archivo de configuración.
TSS2_FAPI_RC_TRY_AGAIN si una operación de E/S aún no ha finalizado y esta función debe ser llamada nuevamente.
TSS2_FAPI_RC_BAD_VALUE si se pasó un valor inválido a la función.
TSS2_FAPI_RC_PATH_NOT_FOUND si no se encontró un objeto de ruta FAPI durante la autorización.
TSS2_FAPI_RC_KEY_NOT_FOUND si no se encontró una clave.
TSS2_FAPI_RC_GENERAL_FAILURE si ocurrió un error interno.
TSS2_FAPI_RC_AUTHORIZATION_UNKNOWN si no se establece una devolución de llamada de autorización requerida.
TSS2_FAPI_RC_AUTHORIZATION_FAILED si falla el intento de autorización.
TSS2_ESYS_RC_* posibles códigos de error de ESAPI.
TSS2_FAPI_RC_NOT_PROVISIONED FAPI no fue aprovisionado.
