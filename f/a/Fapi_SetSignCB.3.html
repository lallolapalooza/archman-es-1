TSS2_RC Fapi_SetPolicyActionCB (FAPI_CONTEXT * context, Fapi_CB_PolicyAction callback, void * userData)

Fapi_SetActionCB() registra una función definida por la aplicación como una devolución de llamada que se invocará al encontrar un elemento de acción de política.

Parámetros

context El FAPI_CONTEXT
callback La función de devolución de llamada para la selección de rama
userData Un puntero que se proporciona a todas las invocaciones de devolución de llamada

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si el contexto es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
TSS2_FAPI_RC_BAD_SEQUENCE si las funciones síncronas o Async se llaman mientras el contexto tiene otra operación asíncrona pendiente, o si la función Finish se llama mientras el contexto no tiene una operación asíncrona apropiada pendiente.
TSS2_FAPI_RC_IO_ERROR si los datos no se pueden guardar.

TSS2_RC Fapi_SetSignCB (FAPI_CONTEXT * context, Fapi_CB_Sign callback, void * userData)

Fapi_SetSignCB() registra una función definida por la aplicación como una devolución de llamada para permitir que la FAPI obtenga firmas que autoricen el uso de objetos TPM.

Parámetros

context El FAPI_CONTEXT
callback La función de devolución de llamada para la selección de firma
userData Un puntero que se proporciona a todas las invocaciones de devolución de llamada

Valores de retorno

TSS2_RC_SUCCESS si la llamada a la función fue un éxito.
TSS2_FAPI_RC_BAD_REFERENCE si el contexto es NULL.
TSS2_FAPI_RC_BAD_CONTEXT si se detecta corrupción del contexto.
TSS2_FAPI_RC_MEMORY si la FAPI no puede asignar suficiente memoria para operaciones internas o parámetros de retorno.
