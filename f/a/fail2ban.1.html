FAIL2BAN(1) Manual de Comandos Generales FAIL2BAN(1)

NOMBRE

fail2ban - un conjunto de programas de servidor y cliente para limitar los intentos de autenticación por fuerza bruta.

DESCRIPCIÓN

Fail2Ban consiste en un cliente, un servidor y archivos de configuración para limitar los intentos de autenticación por fuerza bruta.

El programa servidor fail2ban-server es responsable de monitorizar los archivos de registro y emitir comandos de bloqueo/desbloqueo. Se configura a través de un protocolo simple por fail2ban-client, que también puede leer archivos de configuración y emitir comandos de configuración correspondientes al servidor.

Para obtener detalles sobre la configuración de fail2ban, consulte la página del manual jail.conf(5). Una "jail" (según se especifica en jail.conf) combina filtros y definiciones de acciones para cualquier lista dada de archivos a monitorizar.

Para obtener detalles sobre las opciones de línea de comandos de fail2ban-server, consulte la página del manual fail2ban-server(1).

Para obtener detalles sobre las opciones de línea de comandos y los comandos para configurar el servidor a través de fail2ban-client, consulte la página del manual fail2ban-client(1).

Para probar expresiones regulares especificadas en un filtro, puede ser útil el programa fail2ban-regex y su página del manual es fail2ban-regex(1).

LIMITACIÓN

Fail2Ban es capaz de reducir la tasa de intentos de autenticación incorrectos, sin embargo, no puede eliminar el riesgo que presenta la autenticación débil. Configure los servicios para usar solo mecanismos de autenticación de dos factores o de clave pública/privada si realmente desea proteger los servicios.

Un usuario local puede inyectar mensajes en syslog y, utilizando una "jail" de Fail2Ban que lee desde syslog, puede activar efectivamente un ataque de Denegación de Servicio (DoS) contra cualquier IP. Conozca este riesgo y configure Fail2Ban/conceda acceso a la shell en consecuencia.
