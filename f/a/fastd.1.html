FASTD(1) Comandos de usuario FASTD(1)

NOMBRE

fastd - Demonio de túneles rápido y seguro

SINOPSIS

fastd OPCIÓN...

DESCRIPCIÓN

fastd es un demonio VPN muy pequeño que tuneliza paquetes IP y tramas Ethernet sobre UDP. Soporta varios esquemas modernos de cifrado y autenticación, y puede ser utilizado en diversas topologías de red (1:1, 1:n, en malla).

OPCIONES

--help, -h
Muestra un texto de ayuda.
--version, -v
Muestra la versión de fastd.
--daemon, -d
Ejecuta fastd en segundo plano.
--pid-file <nombre_archivo>
Escribe el PID de fastd en el archivo especificado.
--status-socket <socket>
Configura un socket para obtener el estado de fastd.
--config, -c <nombre_archivo>
Carga un archivo de configuración. Se puede especificar - para leer un archivo de configuración desde la entrada estándar. Se pueden cargar varios archivos de configuración.
--config-peer <nombre_archivo>
Carga un archivo de configuración para un único par. El nombre del archivo se utilizará como nombre del par.
--config-peer-dir <directorio>
Carga todos los archivos de un directorio como configuraciones de par. Con SIGHUP, fastd recargará los directorios de pares.
--user <usuario>
Establece el usuario con el que se ejecutará fastd.
--group <grupo>
Establece el grupo con el que se ejecutará fastd.
--log-level error|warn|info|verbose|debug|debug2
Establece el nivel de registro para stderr; el valor por defecto es info si no se ha configurado ninguna otra salida de registro.
--syslog-level error|warn|info|verbose|debug|debug2
Establece el nivel de registro para la salida de syslog; el valor por defecto es no usar syslog.
--syslog-ident <ident>
Establece la identificación de syslog; el valor por defecto es fastd.
--hide-ip-addresses
Oculta las direcciones IP en la salida de registro.
--hide-mac-addresses
Oculta las direcciones MAC en la salida de registro.
--mode, -m tap|multitap|tun
Establece el modo de la interfaz; el valor por defecto es el modo TAP.
--interface, -i <nombre>
Establece el nombre de la interfaz TUN/TAP a utilizar. Si no se especifica, se utilizarán los nombres por defecto especificados por el sistema.
--mtu, -M <mtu>
Establece la MTU; debe ser al menos 576.
--bind, -b <direccion>[:<puerto>]
Establece la dirección de enlace. La dirección puede ser una dirección IPv4 o IPv6, o la palabra clave any. Las direcciones IPv6 deben estar entre corchetes.

Por defecto, fastd se enlazará a un puerto aleatorio tanto para IPv4 como para IPv6. Actualmente no es posible especificar una dirección local de enlace IPv6 en la línea de comandos.

--protocol, -p <protocolo>
Establece el protocolo de handshake. Actualmente, el único protocolo disponible es ec25519-fhmqvc, que proporciona una autenticación segura de los pares basada en claves públicas/secretas.
--method <metodo>
Establece el método de cifrado.
--forward
Habilita el reenvío de paquetes entre pares; ¡lee la documentación completa antes de usar!
--on-pre-up <comando>
Establece un comando de shell a ejecutar antes de la creación de la interfaz.
--on-up <comando>
Establece un comando de shell a ejecutar después de la creación de la interfaz.
--on-down <comando>
Establece un comando de shell a ejecutar antes de la destrucción de la interfaz.
--on-post-down <comando>
Establece un comando de shell a ejecutar después de la destrucción de la interfaz.
--on-connect <comando>
Establece un comando de shell a ejecutar cuando se envía un handshake para establecer una nueva conexión.
--on-establish <comando>
Establece un comando de shell a ejecutar cuando se establece una nueva conexión.
--on-disestablish <comando>
Establece un comando de shell a ejecutar cuando se pierde una conexión.
--on-verify <comando>
Establece un comando de shell a ejecutar para verificar un intento de conexión de un par desconocido.
--verify-config
Verifica la configuración y sale.
--generate-key
Genera un nuevo par de claves.
--show-key
Muestra la clave pública correspondiente a la secreta configurada.
--machine-readable
Suprime la salida de texto explicativo en los comandos --show-key y --generate-key.
