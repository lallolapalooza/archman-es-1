FANCONTROL(8) Manual del Administrador del Sistema FANCONTROL(8)

NOMBRE

fancontrol - regulación automática de la velocidad del ventilador basada en software

SINOPSIS

fancontrol [archivo_de_configuración]

DESCRIPCIÓN

fancontrol es un script de shell para usar con lm_sensors. Este lee su configuración de un archivo, luego calcula las velocidades de los ventiladores a partir de las temperaturas y establece las salidas PWM correspondientes en los valores calculados.

ADVERTENCIA

Por favor, tenga cuidado al usar las funciones de control de ventilador de su placa base; además del riesgo de quemar su CPU, a temperaturas más altas habrá un mayor desgaste de sus otros componentes de hardware. Así que si planea usar estos componentes en 50 años, quizás no debería usar fancontrol en absoluto. Además, tenga en cuenta que la mayoría de los ventiladores no están diseñados para ser alimentados por un voltaje PWM.

En la práctica, no parece ser un problema importante; los ventiladores se calentarán ligeramente, solo asegúrese de tener una alarma de temperatura y/o una llamada de apagado, en caso de que algún ventilador falle, porque probablemente ya no lo escuchará ;)

CONFIGURACIÓN

Para una configuración fácil, hay un script llamado pwmconfig(8) que le permite escribir interactivamente su archivo de configuración para fancontrol. Alternativamente, puede escribir este archivo usted mismo usando la información de esta página del manual.

Dado que la mayoría de ustedes van a usar el script pwmconfig(8) , la sintaxis del archivo de configuración se discutirá al final. Primero describiré las diversas variables disponibles para cambiar el comportamiento de fancontrol:

INTERVAL
Esta variable define el intervalo en segundos en el que el bucle principal de fancontrol será ejecutado
DEVPATH
Asigna los dispositivos de clase hwmon a dispositivos físicos. Esto permite a fancontrol verificar que el archivo de configuración siga estando actualizado.
DEVNAME
Registra los nombres de los dispositivos de clase hwmon. Esto permite a fancontrol verificar que el archivo de configuración siga estando actualizado.
FCTEMPS
Asigna las salidas PWM a los sensores de temperatura para que fancontrol sepa qué sensores de temperatura deben usarse para el cálculo de nuevos valores para las salidas PWM correspondientes. Se puede usar un prefijo de ! para ejecutar un comando como sensor de temperatura.
FCFANS
Registra la asociación entre una salida PWM y una entrada de ventilador. Luego, fancontrol puede verificar la velocidad del ventilador y reiniciarlo si se detiene inesperadamente.
MINTEMP
La temperatura por debajo de la cual el ventilador se cambia a la velocidad mínima.
MAXTEMP
La temperatura por encima de la cual el ventilador se cambia a la velocidad máxima.
MINSTART
Establece la velocidad mínima a la que el ventilador comienza a girar. Debería usar un valor seguro para asegurarse de que funcione, incluso cuando el ventilador envejezca.
MINSTOP
La velocidad mínima a la que el ventilador todavía gira. Use un valor seguro aquí, también.
MINPWM
El valor PWM a usar cuando la temperatura está por debajo de MINTEMP. Típicamente, esto será 0 si es aceptable que el ventilador se detenga por completo, o el mismo valor que MINSTOP si no quiere que el ventilador se detenga nunca. Si este valor no está definido, el valor predeterminado es 0 (ventilador detenido).
MAXPWM
El valor PWM a usar cuando la temperatura está por encima de MAXTEMP. Si este valor no está definido, el valor predeterminado es 255 (velocidad máxima).
AVERAGE
Cuántas lecturas de temperatura recientes se usan para promediar la temperatura. Se puede usar para suavizar picos cortos de temperatura. Si este valor no está definido, el valor predeterminado es 1 (sin promediado).

El formato del archivo de configuración es un poco extraño:

VARIABLE=chip/pwmdev=valor chip/pwmdev2=valor2
VARIABLE2=...

Cada variable tiene su propia línea. El nombre de la variable es seguido por un signo igual y los pares dispositivo=valor. Estos consisten en la ruta a la salida pwm para la cual el valor es válido, un signo igual seguido del valor y están separados por un espacio en blanco. La ruta puede ser absoluta o relativa (desde /sys/bus/i2c/devices o /sys/class/hwmon dependiendo de la versión del kernel). Ejemplo:

MINTEMP=hwmon0/device/pwm1=40 hwmon0/device/pwm2=54

Tendrá que jugar un poco con los valores de temperatura para estar satisfecho. Para la configuración inicial, recomiendo usar el script pwmconfig . Se pueden hacer cambios pequeños editando el archivo de configuración directamente siguiendo las reglas anteriores.

Al iniciar, fancontrol se asegurará de que todos los dispositivos referenciados existan y coincidan con lo que eran en el momento de la configuración, y de que todos los archivos de sysfs referenciados existan. Si no, se cerrará inmediatamente, bajo la suposición de que el archivo de configuración puede estar desincronizado con los controladores del kernel cargados.

EL ALGORITMO

fancontrol primero lee su configuración, la escribe en arreglos y ejecuta en bucle su función principal. Esta función obtiene las temperaturas y las velocidades de los ventiladores de los archivos de controladores del kernel y calcula nuevas velocidades dependiendo de los cambios de temperatura, pero solo si la temperatura está entre MINTEMP y MAXTEMP. Después de eso, los nuevos valores se escriben en las salidas PWM. Actualmente, la velocidad aumenta linealmente con la temperatura creciente. De esta manera, no escuchará sus ventiladores la mayor parte del tiempo, en el mejor de los casos.
