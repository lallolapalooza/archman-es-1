FASTFETCH(1) Manual de Comandos Generales FASTFETCH(1)

NOMBRE

fastfetch - una herramienta rápida y personalizable de información del sistema similar a neofetch

SINOPSIS

fastfetch [opciones...]

DESCRIPCIÓN

Fastfetch es una herramienta para mostrar información del sistema de una manera visualmente atractiva. Escrito principalmente en C, se centra en el rendimiento y la personalización, al tiempo que proporciona funcionalidades similares a neofetch. Soporta Linux, Android, *BSD, macOS, Haiku y Windows 7 o superior.

ESTADO DE SALIDA

Fastfetch devuelve cero en caso de ejecución exitosa. Cualquier error resulta en un código de salida distinto de cero.

OPCIONES

Opciones Informativas

-h, --help [comando]
Muestra información de ayuda para todas las opciones disponibles o para un comando específico
-v, --version
Muestra la versión de fastfetch
--version-raw
Muestra la cadena de versión sin formato (mayor.menor.parche)
--list-config-paths
Lista las rutas de búsqueda de archivos de configuración
--list-data-paths
Lista las rutas de búsqueda de preajustes y logos
--list-logos
Lista los logos disponibles que se pueden cargar con --logo
--list-modules
Lista todos los módulos disponibles
--list-presets
Lista los preajustes disponibles que se pueden cargar con --config
--list-features
Lista las características con las que se compiló fastfetch (principalmente para desarrollo)
--print-logos
Muestra todos los logos disponibles
--print-structure
Muestra la estructura predeterminada
--format <tipo>
Establece el formato de salida. Las opciones disponibles son:
  • default: Formato legible por humanos por defecto
  • json: Formato JSON para procesamiento por máquina

Opciones de Configuración

-c, --config <config>
Utiliza el archivo de configuración o preajuste especificado. Especifica none para deshabilitar la carga posterior de configuraciones. Consulta la sección CONFIGURACIÓN para obtener detalles sobre los archivos de configuración.
--gen-config [ruta]
Genera un archivo de configuración con las opciones especificadas en la línea de comandos. Si no se especifica ruta, se utiliza por defecto ~/.config/fastfetch/config.jsonc. Si ruta es "-", la configuración se escribirá en stdout.
--gen-config-force [ruta]
Igual que --gen-config, pero sobrescribe cualquier archivo existente en la ruta de destino.

Opciones de Logo

-l, --logo <logo>
Establece el logo a mostrar. Puede ser el nombre de un logo incorporado o una ruta a un archivo de imagen. Usa none para deshabilitar el logo.
--logo-type <tipo>
Establece el tipo del logo especificado con --logo. Los tipos disponibles incluyen auto, builtin, file, sixel, kitty y otros. Consulta --help logo-type para obtener detalles.
--logo-width <ancho>
Establece el ancho del logo en caracteres (para logos de imagen)
--logo-height <alto>
Establece el alto del logo en caracteres (para logos de imagen)
--logo-color-[1-9] <color>
Sobrescribe colores específicos en el logo

Opciones de Pantalla

-s, --structure <estructura>
Establece la estructura de la obtención (una lista separada por dos puntos de nombres de módulos)
--color <color>
Establece el color de las claves y el título. Consulta --help color para ver los colores disponibles.
--color-keys <color>
Establece el color solo de las claves
--color-title <color>
Establece el color solo del título
--separator <cadena>
Establece el separador entre clave y valor (por defecto: ": ")
--key-width <num>
Alinea el ancho de las claves a <num> caracteres
--show-errors
Muestra los errores cuando ocurren (por defecto: falso)
--pipe
Deshabilita los colores (detectado automáticamente según si stdout es una terminal)

Para listar todas las opciones disponibles, incluidas las específicas de módulo, usa --help.

CONFIGURACIÓN

Estructura de Obtención

La estructura define qué módulos mostrar y en qué orden. Consiste en nombres de módulos separados por dos puntos (:). Por ejemplo: title:separator:os:kernel:uptime

Para listar todos los módulos disponibles, usa --list-modules

Archivos de Configuración

Fastfetch utiliza JSONC para los archivos de configuración. JSONC es JSON con soporte para comentarios (// y /* */). Los archivos de configuración deben tener la extensión .jsonc.

Puedes generar un archivo de configuración predeterminado usando --gen-config. Por defecto, el archivo de configuración se guarda en ~/.config/fastfetch/config.jsonc.

Los archivos de configuración/preajuste se buscan en las siguientes ubicaciones (en orden):

1.
Relativo al directorio de trabajo actual
2.
Relativo a ~/.local/share/fastfetch/presets/
3.
Relativo a /usr/share/fastfetch/presets/

Para obtener información detallada sobre las opciones de logo, configuración de módulos y formato, visita:

https://github.com/fastfetch-cli/fastfetch/wiki/Configuration

Fastfetch proporciona varios preajustes incorporados. Lístalos con --list-presets.

Esquema JSON

Hay disponible un esquema JSON para la inteligencia del editor al editar el archivo de configuración. Agrega la siguiente línea al principio de tu archivo de configuración:

"$schema": "https://github.com/fastfetch-cli/fastfetch/raw/dev/doc/json_schema.json"

EJEMPLOS

Uso básico:
fastfetch
Usar un logo específico:
fastfetch --logo Arch
Usar un archivo de imagen como logo:
fastfetch --logo /ruta/a/mi/logo.png
Cambiar el orden de los módulos:
fastfetch --structure os:kernel:uptime
Establecer un color personalizado:
fastfetch --color blue
Cargar un preajuste de configuración:
fastfetch --config ~/.config/fastfetch/my_custom_config.jsonc
Generar un archivo de configuración:
fastfetch --gen-config
Generar un archivo de configuración y escribirlo en stdout:
fastfetch --gen-config -
