FreezeThaw(3pm)

Paquete: perl-freezethaw

Licencias: GPL, PerlArtistic

FreezeThaw(3pm) Documentación Perl contribuida por el usuario FreezeThaw(3pm)

NOMBRE

FreezeThaw - convertir estructuras Perl a cadenas y viceversa.

SINOPSIS

use FreezeThaw qw(freeze thaw cmpStr safeFreeze cmpStrHard);
$cadena = freeze $dato1, $dato2, $dato3;
...
($viejoDato1, $viejoDato2, $viejoDato3) = thaw $cadena;
if (cmpStr($viejoDato2,$dato2) == 0) {print "OK!"}

DESCRIPCIÓN

Convierte datos a/desde forma de cadena, apropiado para guardar/leer desde almacenamiento permanente.

Maneja objetos, listas circulares, apariciones repetidas de la misma referencia. Todavía no maneja el operador de *stringify* sobrecargado.

EXPORTAR

Por defecto
Ninguno.
Exportables
"freeze thaw cmpStr cmpStrHard safeFreeze".

API de Usuario

"cmpStr"
análogo de "cmp" para datos. Toma dos argumentos y los compara como entidades separadas.
"cmpStrHard"
análogo de "cmp" para datos. Toma dos argumentos y los compara considerándolos como un grupo.
"freeze"
devuelve una cadena que encapsula sus argumentos (considerados como un grupo). "thaw"ing esta cadena conduce a un error fatal si los argumentos de "freeze" contuvieron referencias a "GLOB"s y "CODE"s.
"safeFreeze"
devuelve una cadena que encapsula sus argumentos (considerados como un grupo). El resultado es "thaw"able en el mismo proceso. "thaw"ing el resultado en un proceso diferente debería resultar en un error fatal si los argumentos de "safeFreeze" contuvieron referencias a "GLOB"s y "CODE"s.
"thaw"
toma un argumento de cadena y devuelve un array. Los elementos del array son "equivalentes" a los argumentos del comando "freeze" que creó la cadena. Puede resultar en un error fatal (ver arriba).

API de Desarrollador

"FreezeThaw" "freeze"a y "thaw"a datos bendecidos en algún paquete llamando a los métodos "Freeze" y "Thaw" en el paquete. Los métodos de respaldo son proporcionados por el propio "FreezeThaw". El "Freeze" de respaldo congela el "contenido" del objeto bendecido (desde el punto de vista de Perl). El "Thaw" de respaldo vuelve a bendecir los datos *thaw*eados al paquete.

Por lo tanto, el paquete necesita definir sus propios métodos solo si los métodos de respaldo fallan (por ejemplo, para muchos datos el "contenido" de un objeto es la dirección de algunos datos de C). Los métodos se llaman así:

$nuevaGalleta = $obj->Freeze($galleta);
$obj = Package->Thaw($contenido,$galleta);

Para guardar y restaurar los datos, los siguientes métodos son aplicables:

$galleta->FreezeScalar($dato,$ignorarPaquete,$sinDuplicados);

durante la *congelación* (Freeze()), y

$dato = $galleta->ThawScalar;

Dos argumentos opcionales $ignorarPaquete y $sinDuplicados regulan si la congelación no debe llamar a los métodos incluso si $dato es una referencia a un objeto bendecido, y si los datos no deben ser marcados como ya vistos incluso si se vieron antes. Los métodos por defecto

sub UNIVERSAL::Freeze {
  my ($obj, $galleta) = (shift, shift);
  $galleta->FreezeScalar($obj,1,1);
}
sub UNIVERSAL::Thaw {
  my ($paquete, $galleta) = (shift, shift);
  my $obj = $galleta->ThawScalar;
  bless $obj, $paquete;
}

llaman al método "FreezeScalar" de $galleta ya que el motor de congelación verá los datos por segunda vez durante esta llamada. De hecho, es el motor de congelación quien llama a UNIVERSAL::Freeze(), y lo llama porque necesita congelar $obj. La llamada anterior a $galleta->FreezeScalar() devuelve los mismos datos al motor, pero debido a que las banderas son diferentes, el código no se cicla.

Congelar y descongelar $galleta también permite los siguientes métodos adicionales:

$galleta->isSafe;

para averiguar si la congelación actual fue iniciada por el comando "freeze" o "safeFreeze". Un método análogo para descongelar $galleta devuelve si la operación de descongelación actual se considera segura (es decir, o bien no contiene datos cacheados en otro lugar, o proviene de la misma aplicación). Puedes usar

$galleta->makeSafe;

para prohibir datos cacheados durante el resto de la congelación o descongelación del objeto actual.

Dos métodos

$valor = $galleta->repeatedOK;
$galleta->noRepeated;           # Ahora se prohíben las repeticiones

permiten averiguar/cambiar la configuración actual para permitir referencias repetidas.

Si deseas vaciar la caché de objetos guardados, puedes usar

FreezeThaw->flushCache;

esto puede invalidar alguna cadena congelada, de modo que su descongelación resulte en un error fatal.

Instanciación

A veces, cuando un objeto de un paquete se recrea en presencia de referencias repetidas, no es seguro recrear la estructura interna de un objeto en un solo paso. En tal situación, la recreación de un objeto se lleva a cabo en dos pasos: en el primero el objeto se "asigna", en el segundo se "instancia".

La restricción es que durante el paso de *asignación* no se puede utilizar ninguna referencia a ningún objeto Perl que pueda ser referenciado desde cualquier otro lugar. Esta restricción se aplica ya que ese objeto puede no existir todavía.

Correspondientemente, durante el paso de *instanciación*, el objeto previamente *asignado* debe ser "llenado", es decir, puede ser modificado de cualquier manera de modo que las referencias a este objeto permanezcan válidas.

Los métodos se llaman así:

$pre_objeto_ref = Package->Allocate($pre_pre_objeto_ref);
      # Devuelve una referencia
Package->Instantiate($pre_objeto_ref,$galleta);
      # Convierte en referencia a objeto bendecido

Las operaciones inversas son

$ref_objeto->FreezeEmpty($galleta);
$ref_objeto->FreezeInstance($galleta);

durante estas llamadas el objeto puede "freezeScalar" alguna información (de la manera habitual) que se utilizará durante las llamadas "Allocate" y "Instantiate" (a través de "thawScalar"). Tenga en cuenta que el valor de retorno de "FreezeEmpty" se almacena en caché durante la fase de creación de objetos no inicializados. Esto *debe* utilizarse de esta manera: el valor de retorno es la referencia al objeto creado, por lo que no se destruye hasta que se crean otros objetos, por lo tanto, los valores congelados de los diferentes objetos no compartirán las mismas referencias. Ejemplo de mal resultado:

$o1->FreezeEmpty($galleta)

congela "{}", y "$o2->FreezeEmpty($galleta)" hace lo mismo. Ahora nadie garantiza que estas dos copias de "{}" sean diferentes, a menos que una referencia a la primera se preserve durante la llamada a "$o2->FreezeEmpty($galleta)". Si "$o1->FreezeEmpty($galleta)" devuelve el valor de "{}" que utiliza, será preservado por el motor.

La función auxiliar "FreezeThaw::copyContents" se proporciona para simplificar la instanciación. La sintaxis es

FreezeThaw::copyContents $a, $de;
