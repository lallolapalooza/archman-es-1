FEUPDATEENV(3P) Manual del programador POSIX FEUPDATEENV(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

feupdateenv — actualiza el entorno de punto flotante

SINOPSIS

#include <fenv.h>
int feupdateenv(const fenv_t *envp);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función feupdateenv() intentará guardar las excepciones de punto flotante activadas actualmente en su almacenamiento automático, intentará instalar el entorno de punto flotante representado por el objeto al que apunta envp, y luego intentará activar las excepciones de punto flotante guardadas. El argumento envp deberá apuntar a un objeto establecido por una llamada a feholdexcept() o fegetenv(), o ser igual a una macro de entorno de punto flotante.

VALOR DE RETORNO

La función feupdateenv() devolverá un valor cero si y solo si todas las acciones requeridas se llevaron a cabo con éxito.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

El siguiente ejemplo muestra código de muestra para ocultar excepciones espurias de punto flotante de subdesbordamiento:

#include <fenv.h>
double f(double x)
{
    #pragma STDC FENV_ACCESS ON
    double result;
    fenv_t save_env;
    feholdexcept(&save_env);
    // calcular resultado
    if (/* probar subdesbordamiento espurio */)
    feclearexcept(FE_UNDERFLOW);
    feupdateenv(&save_env);
    return result;
}
