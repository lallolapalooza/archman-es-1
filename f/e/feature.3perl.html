feature(3perl) Guía de referencia para programadores de Perl feature(3perl)

NOMBRE

feature - pragma de Perl para habilitar nuevas características

SINOPSIS

use feature qw(fc say);
# Sin el "use feature" anterior, este código no podría encontrar
# las funciones incorporadas "say" ni "fc":
say "La versión con mayúsculas/minúsculas de $x es: " . fc $x;
# establece las características para que coincidan con el paquete :5.36, lo que puede
# desactivar o activar múltiples características (ver "PAQUETES DE CARACTERÍSTICAS" más abajo)
use feature ':5.36';
# carga implícitamente el paquete de características :5.36
use v5.36;

DESCRIPCIÓN

Generalmente es imposible añadir nueva sintaxis a Perl sin romper algunos programas existentes. Este pragma proporciona una forma de minimizar ese riesgo. Nuevas construcciones sintácticas, o nuevos significados semánticos para construcciones más antiguas, pueden ser habilitadas mediante "use feature 'foo'", y serán analizadas solo cuando el pragma de característica correspondiente esté en el ámbito de visibilidad. (Sin embargo, el "CORE::" prefijo proporciona acceso a todas las palabras clave de Perl, independientemente de este pragma.)

Efecto léxico

Como otros pragmas ("use strict", por ejemplo), las características tienen un efecto léxico. "use feature qw(foo)" solo hará que la característica "foo" esté disponible desde ese punto hasta el final del bloque que la contiene.

{
    use feature 'say';
    say "'say' está disponible aquí";
}
print "Pero no aquí.\n";

"no feature"

Las características también pueden ser desactivadas usando "no feature "foo"". Esto también tiene efecto léxico.

use feature 'say';
say "'say' está disponible aquí";
{
    no feature 'say';
    print "Pero no aquí.\n";
}
say "Sin embargo, aquí sí está.";

"no feature" sin especificar características reiniciará al grupo por defecto. Para desactivar todas las características (¡una solicitud inusual!) use "no feature ':all'".

CARACTERÍSTICAS DISPONIBLES

Lea "PAQUETES DE CARACTERÍSTICAS" para el resumen de referencia de características.

La característica 'say'

"use feature 'say'" le dice al compilador que habilite la función "say" inspirada en Raku.

Ver "say" en perlfunc para más detalles.

Esta característica está disponible a partir de Perl 5.10.

La característica 'state'

"use feature 'state'" le dice al compilador que habilite las variables "state" .

Ver "Persistent Private Variables" en perlsub para más detalles.

Esta característica está disponible a partir de Perl 5.10.

La característica 'smartmatch'

"use feature 'smartmatch'" le dice al compilador que habilite el operador de coincidencia inteligente "~~". Está habilitada por defecto, pero puede ser desactivada para no permitir el operador "~~" .

Esta característica está deshabilitada por defecto a partir del paquete de características 5.42:

$x ~~ $y; # bien
use v5.42;
$x ~~ $y; # error

Esto no tiene efecto sobre las coincidencias inteligentes implícitas realizadas por "when".

Ver "Smartmatch Operator" en perlop para más detalles.

La característica 'switch'

"use feature 'switch'" le dice al compilador que habilite la construcción given/when de Raku.

Ver "Switch Statements" en perlsyn para más detalles.

Esta característica está disponible a partir de Perl 5.10. Está habilitada por los paquetes de características 5.10 a 5.34, y deshabilitada a partir del paquete de características 5.36.

La característica 'unicode_strings'

"use feature 'unicode_strings'" le dice al compilador que use reglas Unicode en todas las operaciones de cadena ejecutadas dentro de su ámbito de visibilidad (a menos que también estén dentro del ámbito de "use locale" o "use bytes"). Lo mismo se aplica a todas las expresiones regulares compiladas dentro del ámbito, incluso si se ejecutan fuera de él. No cambia la representación interna de las cadenas, sino solo cómo se interpretan.

"no feature 'unicode_strings'" le dice al compilador que use las reglas tradicionales de Perl, en las que se usan las reglas del juego de caracteres nativo a menos que sea claro para Perl que se desea Unicode. Esto puede llevar a algunas sorpresas cuando el comportamiento cambia repentinamente. (Ver "The "Unicode Bug"" en perlunicode para más detalles.) Por esta razón, si está usando potencialmente Unicode en su programa, se "use feature 'unicode_strings'" subpragma es fuertemente recomendado.

Esta característica está disponible a partir de Perl 5.12; fue casi completamente implementada en Perl 5.14; y extendida en Perl 5.16 para cubrir "quotemeta"; fue extendida aún más en Perl 5.26 para cubrir el operador de rango; y fue extendida de nuevo en Perl 5.28 para cubrir la división de cadenas por espacios en blanco con casos especiales.

Las características 'unicode_eval' y 'evalbytes'

Juntas, estas dos características están destinadas a reemplazar la función "eval" de cadena heredada, que se comporta problemáticamente en algunos casos. Están disponibles a partir de Perl 5.16, y están habilitadas por defecto con una declaración "use 5.16" o superior.

"unicode_eval" cambia el comportamiento del "eval" de cadena simple para funcionar de manera más consistente, especialmente en el mundo de Unicode. Ciertos (mal)comportamientos no podían cambiarse sin romper algunas cosas que habían llegado a depender de ellos, por lo que la característica puede ser habilitada y deshabilitada. Los detalles están en "Under the "unicode_eval" feature" en perlfunc.

"evalbytes" es como el "eval"de cadena, pero trata su argumento como una cadena de bytes. Los detalles están en "evalbytes EXPR" en perlfunc. Sin una "use feature 'evalbytes'" ni una "use v5.16" (o superior) declaración en el ámbito actual, aún puede acceder a él escribiendo "CORE::evalbytes".

La característica 'current_sub'

Esto proporciona el token "__SUB__" que devuelve una referencia a la subrutina actual o "undef" fuera de una subrutina.

Esta característica está disponible a partir de Perl 5.16.

La característica 'array_base'

Esta característica soportaba la variable heredada $[ . Ver "$[" en perlvar. Estaba activada por defecto pero deshabilitada bajo "use v5.16" (ver "CARGA IMPLÍCITA", más abajo) y no disponible desde perl 5.30.

Esta característica está disponible bajo este nombre a partir de Perl 5.16. En versiones anteriores, simplemente estaba activada todo el tiempo, y este pragma no sabía nada sobre ella.

La característica 'fc'

"use feature 'fc'" le dice al compilador que habilite la función "fc" , que implementa el casefolding de Unicode.

Ver "fc" en perlfunc para más detalles.

Esta característica está disponible desde Perl 5.16 en adelante.

La característica 'lexical_subs'

En versiones de Perl anteriores a 5.26, esta característica habilitaba la declaración de subrutinas mediante la sintaxis "my sub foo", "state sub foo" y "our sub foo" . Ver "Lexical Subroutines" en perlsub para más detalles.

Esta característica está disponible desde Perl 5.18 en adelante. Desde Perl 5.18 hasta 5.24, fue clasificada como experimental, y Perl emitía una advertencia por su uso, excepto cuando se deshabilitaba explícitamente:

no warnings "experimental::lexical_subs";quot;;

A partir de Perl 5.26, el uso de esta funcionalidad ya no genera una advertencia, aunque la "experimental::lexical_subs" categoría de advertencia todavía existe (por compatibilidad con código que la deshabilita). Además, esta sintaxis ya no es experimental, sino que está habilitada para todo el código Perl, independientemente de las declaraciones de funcionalidad que estén en el ámbito.

Las funcionalidades 'postderef' y 'postderef_qq'

La funcionalidad 'postderef_qq' extiende la aplicabilidad de la sintaxis de desreferencia postfija de modo que el desreferenciado de arrays postfijo, el desreferenciado de escalares postfijo y el acceso al índice más alto de un array postfijo estén disponibles en interpolaciones de doble comilla. Por ejemplo, hace que las siguientes dos sentencias sean equivalentes:

my $s = "[@{ $h->{a} }]";
my $s = "[$h->{a}->@*]";

Esta funcionalidad está disponible desde Perl 5.20 en adelante. En Perl 5.20 y 5.22, se clasificaba como experimental y Perl emitía una advertencia por su uso, excepto cuando se deshabilitaba explícitamente:

no warnings "experimental::postderef";

A partir de Perl 5.24, el uso de esta funcionalidad ya no genera una advertencia, aunque la "experimental::postderef" categoría de advertencia todavía existe (por compatibilidad con código que la deshabilita).

La funcionalidad 'postderef' se utilizó en Perl 5.20 y Perl 5.22 para habilitar la sintaxis de desreferencia postfija fuera de las interpolaciones de doble comilla. En esas versiones, su uso generaba la "experimental::postderef" advertencia de la misma manera que la funcionalidad 'postderef_qq'. A partir de Perl 5.24, esta sintaxis ya no es experimental, sino que está habilitada para todo el código Perl, independientemente de las declaraciones de funcionalidad que estén en el ámbito.

La funcionalidad 'signatures'

Esto habilita la sintaxis para declarar argumentos de subrutinas como variables léxicas. Por ejemplo, para esta subrutina:

sub foo ($left, $right) {
    return $left + $right;
}

Llamar a "foo(3, 7)" asignará 3 a $left y 7 a $right.

Consulte "Signatures" en perlsub para más detalles.

Esta funcionalidad está disponible desde Perl 5.20 en adelante. Desde Perl 5.20 hasta 5.34, se clasificaba como experimental y Perl emitía una advertencia por su uso, excepto cuando se deshabilitaba explícitamente:

no warnings "experimental::signatures";

A partir de Perl 5.36, el uso de esta funcionalidad ya no genera una advertencia, aunque la "experimental::signatures" categoría de advertencia todavía existe (por compatibilidad con código que la deshabilita). Esta funcionalidad ahora se considera estable y se habilita automáticamente con "use v5.36" (o superior).

La funcionalidad 'refaliasing'

ADVERTENCIA: Esta funcionalidad sigue siendo experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando use la funcionalidad, a menos que haya deshabilitado explícitamente la advertencia:

no warnings "experimental::refaliasing";

Esto habilita el aliasing mediante la asignación a referencias:

\$a = \$b; # $a y $b ahora apuntan al mismo escalar
\@a = \@b; #                     al mismo array
\%a = \%b;
\&a = \&
foreach \%hash (@array_of_hash_refs) {
    ...
}

Consulte "Assigning to References" en perlref para más detalles.

Esta funcionalidad está disponible desde Perl 5.22 en adelante.

La funcionalidad 'bitwise'

Esto hace que los cuatro operadores bitwise estándar ("& | ^ ~") traten sus operandos consistentemente como números, e introduce cuatro nuevos operadores con punto ("&. |. ^. ~.") que tratan sus operandos consistentemente como cadenas. Lo mismo se aplica a las variantes de asignación ("&= |= ^= &.= |.= ^.=").

Consulte "Bitwise String Operators" en perlop para más detalles.

Esta funcionalidad está disponible desde Perl 5.22 en adelante. A partir de Perl 5.28, "use v5.28" habilitará la funcionalidad. Antes de 5.28, seguía siendo experimental y emitía una advertencia en la categoría "experimental::bitwise".

La funcionalidad 'declared_refs'

ADVERTENCIA: Esta funcionalidad sigue siendo experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando use la funcionalidad, a menos que haya deshabilitado explícitamente la advertencia:

no warnings "experimental::declared_refs";

Esto permite que una referencia a una variable se declare con "my", "state"o "our", o se localice con "local". Está destinada principalmente para usarse en conjunto con la funcionalidad "refaliasing". Consulte "Declaring a Reference to a Variable" en perlref para ver ejemplos.

Esta funcionalidad está disponible desde Perl 5.26 en adelante.

La funcionalidad 'isa'

Esto permite el uso del operador infijo "isa" , que comprueba si el escalar dado por el operando izquierdo es un objeto de la clase dada por el operando derecho. Consulte "Class Instance Operator" en perlop para más detalles.

Esta funcionalidad está disponible desde Perl 5.32 en adelante. Desde Perl 5.32 hasta 5.34, se clasificaba como experimental y Perl emitía una advertencia por su uso, excepto cuando se deshabilitaba explícitamente:

no warnings "experimental::isa";

A partir de Perl 5.36, el uso de esta funcionalidad ya no genera una advertencia (aunque la "experimental::isa" categoría de advertencia todavía existe por compatibilidad con código que la deshabilita). Esta funcionalidad ahora se considera estable y se habilita automáticamente con "use v5.36" (o superior).

La funcionalidad 'indirect'

Esta funcionalidad permite el uso de la sintaxis de objeto indirecto para llamadas a métodos, por ejemplo "new Foo 1, 2;". Está habilitada de forma predeterminada, pero puede desactivarse para no permitir la sintaxis de objeto indirecto.

Esta funcionalidad está disponible bajo este nombre desde Perl 5.32 en adelante. En versiones anteriores, simplemente estaba activada todo el tiempo. Para no permitir (o advertir sobre) la sintaxis de objeto indirecto en versiones anteriores de Perl, consulte el módulo CPAN indirect. Se deshabilita a partir del paquete de funcionalidades 5.36.

La funcionalidad 'multidimensional'

Esta funcionalidad habilita la emulación de arrays multidimensionales, una funcionalidad de perl 4 (o anterior) que se usaba para emular arrays multidimensionales con hashes. Esto funciona convirtiendo código como $foo{$x, $y} en $foo{join($;, $x, $y)}. Está habilitada de forma predeterminada, pero puede desactivarse para deshabilitar la emulación de arrays multidimensionales.

Cuando esta funcionalidad está deshabilitada, la sintaxis que normalmente se reemplaza generará un error de compilación.

Esta funcionalidad está disponible bajo este nombre desde Perl 5.34 en adelante. En versiones anteriores, simplemente estaba activada todo el tiempo. Se deshabilita a partir del paquete de funcionalidades 5.36.

Puede usar el módulo multidimensional en CPAN para deshabilitar la emulación de arrays multidimensionales en versiones anteriores de Perl.

La funcionalidad 'bareword_filehandles'

Esta funcionalidad habilita identificadores de manejadores de archivos sin comillas para operaciones de funciones incorporadas, una práctica generalmente desaconsejada. Está habilitada de forma predeterminada, pero puede desactivarse para deshabilitar los identificadores de manejadores de archivos sin comillas, excepto para las excepciones listadas a continuación.

Los manejadores de archivos incorporados de perl "STDIN", "STDOUT", "STDERR", "DATA", "ARGV", "ARGVOUT" y el especial "_" siempre están habilitados.

Esta funcionalidad está disponible bajo este nombre desde Perl 5.34 en adelante. En versiones anteriores, simplemente estaba activada todo el tiempo. Se deshabilita a partir del paquete de funcionalidades 5.38.

Puede usar el módulo bareword::filehandles en CPAN para deshabilitar los identificadores de manejadores de archivos sin comillas en versiones anteriores de perl.

La funcionalidad 'try'

ADVERTENCIA: Esta funcionalidad sigue siendo parcialmente experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl.

Esta funcionalidad habilita la sintaxis "try" y "catch" , que permite el manejo de excepciones, donde las excepciones lanzadas desde el cuerpo del bloque introducido con "try" se capturan ejecutando el cuerpo del bloque "catch" .

Esta funcionalidad está disponible a partir de Perl 5.34. Antes de Perl 5.40 se clasificaba como experimental y Perl emitía una advertencia por su uso, excepto cuando se deshabilitaba explícitamente:

no warnings "experimental::try";

A partir de Perl 5.40, el uso de esta funcionalidad sin un bloque "finally" ya no genera una advertencia. El bloque opcional "finally" todavía se considera experimental y emite una advertencia, excepto cuando se deshabilita explícitamente como se indicó anteriormente.

Para más información, consulte "Try Catch Exception Handling" en perlsyn.

La funcionalidad 'defer'

ADVERTENCIA: Esta funcionalidad sigue siendo experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando use la funcionalidad, a menos que haya deshabilitado explícitamente la advertencia:

no warnings "experimental::defer";

Esta funcionalidad habilita la sintaxis de bloque "defer" , que permite que un bloque de código se difiera hasta que el flujo de control salga del bloque que lo contenía. Para más detalles, consulte "defer" en perlsyn.

Esta funcionalidad está disponible a partir de Perl 5.36.

La funcionalidad 'extra_paired_delimiters'

ADVERTENCIA: Esta funcionalidad sigue siendo experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando use la funcionalidad, a menos que haya deshabilitado explícitamente la advertencia:

no warnings "experimental::extra_paired_delimiters";

Esta funcionalidad habilita el uso de más delimitadores de cadenas emparejados que los cuatro tradicionales, "< >"pan>, "( )", "{ }", y "[ ]]". Cuando esta característica está activada, por ejemplo, puedes decir "qr«pat»".

Como con cualquier uso de delimitadores no ASCII en un archivo fuente codificado en UTF-8, querrás asegurarte de que el analizador decodifique el código fuente desde bytes UTF-8 con una declaración como "use utf8".

Esta característica está disponible a partir de Perl 5.36.

Para obtener una lista completa de los caracteres disponibles, consulta "List of Extra Paired Delimiters" en perlop.

La característica 'module_true'

Esta característica elimina la necesidad de devolver un valor verdadero al final de un módulo cargado con "require" o "use". Cualquier error durante la compilación causará fallos, pero llegar al final del módulo cuando esta característica está en efecto evitará que "perl" lance una excepción de que el módulo "did not return a true value" (no devolvió un valor verdadero).

La característica 'class'

ADVERTENCIA: Esta característica aún es experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando uses la característica, a menos que hayas deshabilitado explícitamente la advertencia:

no warnings "experimental::class";

Esta característica habilita la sintaxis de bloque "class" y otras palabras clave asociadas que implementan el sistema de objetos "new", previamente con el nombre en clave "Corinna".

La característica 'apostrophe_as_package_separator'

Esta característica permite usar "'" (apóstrofo) como alternativa a usar "::" como separador en nombres de paquetes y otros nombres globales.

Esto está habilitado de forma predeterminada, pero deshabilitado desde el paquete de características 5.42 en adelante. En versiones anteriores estaba habilitado todo el tiempo.

Esto solo deshabilita "'" en símbolos en tu código fuente; la conversión interna de "'" a "::", incluyendo referencias simbólicas, siempre está habilitada.

La característica 'keyword_any'

ADVERTENCIA: Esta característica aún es experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando uses la característica, a menos que hayas deshabilitado explícitamente la advertencia:

no warnings "experimental::keyword_any";

Esta característica habilita la palabra clave de operador "any" . Esto permite probar si alguno de los valores en una lista satisface una condición dada, con comportamiento de cortocircuito en cuanto encuentra uno.

La característica 'keyword_all'

ADVERTENCIA: Esta característica aún es experimental y la implementación puede cambiar o eliminarse en futuras versiones de Perl. Por esta razón, Perl emitirá una advertencia cuando uses la característica, a menos que hayas deshabilitado explícitamente la advertencia:

no warnings "experimental::keyword_all";

Esta característica habilita la palabra clave de operador "all" . Esto permite probar si todos los valores en una lista satisfacen una condición dada, con comportamiento de cortocircuito en cuanto encuentra uno que no la satisface.

El ":default" paquete representa el conjunto de características que está habilitado antes de cualquier declaración "use feature" o "no feature" .

Especificar subversiones como 0 en 5.14.0 en paquetes de características no tiene efecto. Se garantiza que los paquetes de características sean los mismos para todas las subversiones.

use feature ":5.14.0";    # igual que ":5.14"
use feature ":5.14.1";    # igual que ":5.14"

También puedes hacer:

use feature ":all";

o

no feature ":all";

pero lo primero puede habilitar características en una versión posterior de Perl que cambien el significado de tu código, y lo segundo puede deshabilitar mecanismos que son parte del comportamiento actual de Perl que se han convertido en características, tal como "indirect" y "bareword_filehandles" lo fueron.

CARGA IMPLÍCITA

En lugar de cargar paquetes de características por nombre, es más fácil dejar que Perl haga la carga implícita de un paquete de características por ti.

Hay dos formas de cargar el pragmático "feature" implícitamente:

  • Usando el interruptor "-E" en la línea de comandos de Perl en lugar de "-e". Eso habilitará el paquete de características para esa versión de Perl en la unidad de compilación principal (es decir, la instrucción de una línea que sigue a "-E").
  • Requiriendo explícitamente un número de versión mínimo de Perl para tu programa, con la construcción "use VERSION" . Es decir, 
    use v5.36.0;

    hará una carga implícita de

    no feature ':all';
use feature ':5.36';

    y así sucesivamente. Observa cómo la subversión final se elimina automáticamente de la versión.

    Pero para evitar advertencias de portabilidad (consulta "use" en perlfunc), quizás prefieras:

    use 5.036;

    con el mismo efecto.

    Si la versión requerida es anterior a Perl 5.10, se carga automáticamente el paquete de características ":default" en su lugar.

    A diferencia de "use feature ":5.12"", decir "use v5.12" (o cualquier versión superior) también hace el equivalente de "use strict"; consulta "use" en perlfunc para más detalles.

VERIFICACIÓN DE CARACTERÍSTICAS

"feature" proporciona algunas APIs simples para verificar qué características están habilitadas.

Estas funciones no se pueden importar y deben llamarse por sus nombres completamente calificados. Si de otro modo no necesitas establecer una característica, necesitarás asegurarte de que "feature" esté cargado con:

use feature ();
