NOTES

glibc notes

Si es posible, la biblioteca C de GNU define una macro FE_NOMASK_ENV que representa un entorno en el que cada excepción generada provoca una trampa. Puedes probar esta macro usando #ifdef. Solo se define si se define _GNU_SOURCE. El estándar C99 no define una forma de establecer bits individuales en la máscara de punto flotante, por ejemplo, para detectar señales en indicadores específicos. Desde glibc 2.2, glibc admite las funciones feenableexcept() y fedisableexcept() para establecer trampas de punto flotante individuales, y fegetexcept() para consultar el estado.

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <fenv.h>
int feenableexcept(int excepts);
int fedisableexcept(int excepts);
int fegetexcept(void);

Las funciones feenableexcept() y fedisableexcept() habilitan (inhabilitan) trampas para cada una de las excepciones representadas por excepts y devuelven el conjunto anterior de excepciones habilitadas cuando tienen éxito, y -1 en caso contrario. La función fegetexcept() devuelve el conjunto de todas las excepciones actualmente habilitadas.

BUGS

C99 especifica que el valor de FLT_ROUNDS debe reflejar los cambios en el modo de redondeo actual, tal como se establece con fesetround(). Actualmente, esto no ocurre: FLT_ROUNDS siempre tiene el valor 1.
