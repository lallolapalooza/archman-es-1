glibc

Si es posible, la Biblioteca C de GNU define una macro FE_NOMASK_ENV que representa un entorno donde cada excepción generada provoca la ocurrencia de una trampa. Puede comprobar esta macro usando #ifdef. Solo se define si _GNU_SOURCE está definido. El estándar C99 no define una forma de establecer bits individuales en la máscara de coma flotante, por ejemplo, para generar una trampa en indicadores específicos. Desde glibc 2.2, glibc soporta las funciones feenableexcept() y fedisableexcept() para establecer trampas individuales de coma flotante, y fegetexcept() para consultar el

estado.
