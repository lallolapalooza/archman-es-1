FERAISEEXCEPT(3P) Manual POSIX para programadores FERAISEEXCEPT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual POSIX para Programadores. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

feraiseexcept — generar excepción de punto flotante

SINOPSIS

#include <fenv.h>
int feraiseexcept(int excepts);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencionado. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función feraiseexcept() intentará generar las excepciones de punto flotante admitidas representadas por el argumento excepts. El orden en que se generen estas excepciones de punto flotante no está especificado, excepto que si el argumento excepts representa excepciones de punto flotante coincidentes válidas de IEC 60559 para operaciones atómicas (a saber, desbordamiento e inexactitud, o subdesbordamiento e inexactitud), entonces se generará desbordamiento o subdesbordamiento antes que inexactitud. Si la función feraiseexcept() genera además la excepción de punto flotante inexacto cada vez que genera la excepción de punto flotante de desbordamiento o subdesbordamiento es una determinación de la implementación.

VALOR DE RETORNO

Si el argumento es cero o si todas las excepciones especificadas se generaron correctamente, feraiseexcept() devolverá cero. De lo contrario, devolverá un valor distinto de cero.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

El efecto está pensado para ser similar al de las excepciones de punto flotante generadas por operaciones aritméticas. Por lo tanto, se activan las trampas habilitadas para las excepciones de punto flotante generadas por esta función.

FUNDAMENTACIÓN

Se permite que la generación de desbordamiento o subdesbordamiento también genere inexactitud porque en algunas arquitecturas la única forma práctica de generar una excepción es ejecutar una instrucción que tenga la excepción como efecto secundario. La función no se limita a aceptar solo expresiones coincidentes válidas para operaciones atómicas, por lo que la función se puede utilizar para generar excepciones acumuladas durante varias operaciones.

DIRECCIONES FUTURAS

Ninguna.
