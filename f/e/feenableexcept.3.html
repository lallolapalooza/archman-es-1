NOTA

S

notas de glibc

Si es posible, la Biblioteca C de GNU define una macro FE_NOMASK_ENV que representa un entorno donde cada excepción generada provoca la ocurrencia de una trampa. Puedes comprobar esta macro usando #ifdef. Solo se define si _GNU_SOURCE está definido. El estándar C99 no define una forma de establecer bits individuales en la máscara de coma flotante, por ejemplo, para generar una trampa en indicadores específicos. Desde glibc 2.2, glibc soporta las funciones feenableexcept() y fedisableexcept() para establecer trampas individuales de coma flotante, y fegetexcept() para consultar el estado.

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <fenv.h>
int feenableexcept(int excepts);
int fedisableexcept(int excepts);
int fegetexcept(void);

Las feenableexcept() y fedisableexcept() funciones habilitan (deshabilitan) trampas para cada una de las excepciones representadas por excepts y devuelven el conjunto anterior de excepciones habilitadas cuando tienen éxito, y -1 en caso contrario. La fegetexcept() función devuelve el conjunto de todas las excepciones actualmente habilitadas.

ERRORES

C99 especifica que el valor de FLT_ROUNDS debe reflejar cambios en el modo de redondeo actual, tal como lo establece fesetround(). Actualmente, esto no ocurre: FLT_ROUNDS siempre tiene el valor 1.
