fenv(3) Manual de funciones de biblioteca fenv(3)

NOMBRE

feclearexcept, fegetexceptflag, feraiseexcept, fesetexceptflag, fetestexcept, fegetenv, fegetround, feholdexcept, fesetround, fesetenv, feupdateenv, feenableexcept, fedisableexcept, fegetexcept - manejo de redondeo y excepciones de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <fenv.h>
int feclearexcept(int excepts);
int fegetexceptflag(fexcept_t *flagp, int excepts);
int feraiseexcept(int excepts);
int fesetexceptflag(const fexcept_t *flagp, int excepts);
int fetestexcept(int excepts);
int fegetround(void);
int fesetround(int rounding_mode);
int fegetenv(fenv_t *envp);
int feholdexcept(fenv_t *envp);
int fesetenv(const fenv_t *envp);
int feupdateenv(const fenv_t *envp);

DESCRIPCIÓN

Estas once funciones fueron definidas en C99 y describen el manejo de excepciones (desbordamiento, división por cero, etc.) y redondeo de punto flotante.

Excepciones

La excepción de *división por cero* ocurre cuando una operación sobre números finitos produce infinito como respuesta exacta.

La excepción de *desbordamiento* ocurre cuando un resultado tiene que ser representado como un número de punto flotante, pero tiene un valor absoluto (mucho) mayor que el número (finito) de punto flotante más grande que es representable.

La excepción de *subdesbordamiento* ocurre cuando un resultado tiene que ser representado como un número de punto flotante, pero tiene un valor absoluto menor que el número normalizado positivo más pequeño de punto flotante (y perdería mucha precisión al ser representado como un número denormalizado).

La excepción de *inexactitud* ocurre cuando el resultado redondeado de una operación no es igual al resultado de precisión infinita. Puede ocurrir siempre que ocurra un *desbordamiento* o *subdesbordamiento*.

La excepción de *inválido* ocurre cuando no hay un resultado bien definido para una operación, como en el caso de 0/0 o infinito - infinito o la raíz cuadrada de -1.

Manejo de excepciones

Las excepciones se representan de dos maneras: como un solo bit (excepción presente/ausente), y estos bits corresponden de alguna manera definida por la implementación con posiciones de bits en un entero, y también como una estructura opaca que puede contener más información sobre la excepción (quizás la dirección de código donde ocurrió).

Cada una de las macros FE_DIVBYZERO, FE_INEXACT, FE_INVALID, FE_OVERFLOW, FE_UNDERFLOW se define cuando la implementación soporta el manejo de la excepción correspondiente, y si es así, define el bit (o bits) correspondiente, de modo que se puedan llamar a funciones de manejo de excepciones, por ejemplo, usando el argumento entero FE_OVERFLOW|FE_UNDERFLOW. Pueden soportarse otras excepciones. La macro FE_ALL_EXCEPT es el OR a nivel de bits de todos los bits correspondientes a las excepciones soportadas.

La función feclearexcept() borra las excepciones soportadas representadas por los bits en su argumento.

La función fegetexceptflag() almacena una representación del estado de las banderas de excepción representadas por el argumento excepts en el objeto opaco *flagp.

La función feraiseexcept() genera las excepciones soportadas representadas por los bits en excepts.

La función fesetexceptflag() establece el estado completo para las excepciones representadas por excepts al valor *flagp. Este valor debe haber sido obtenido por una llamada anterior a fegetexceptflag() con un último argumento que contenía todos los bits en excepts.

La función fetestexcept() devuelve una palabra en la que se han establecido los bits que estaban establecidos en el argumento excepts y para los cuales la excepción correspondiente está actualmente establecida.

Modo de redondeo

El modo de redondeo determina cómo se trata el resultado de las operaciones de punto flotante cuando el resultado no se puede representar exactamente en la mantisa. Se pueden proporcionar varios modos de redondeo: redondear al más cercano (el predeterminado), redondear hacia arriba (hacia infinito positivo), redondear hacia abajo (hacia infinito negativo) y redondear hacia cero.

Cada una de las macros FE_TONEAREST, FE_UPWARD, FE_DOWNWARD y FE_TOWARDZERO se define cuando la implementación soporta la obtención y el establecimiento de la dirección de redondeo correspondiente.

La función fegetround() devuelve la macro que corresponde al modo de redondeo actual.

La función fesetround() establece el modo de redondeo como lo especifica su argumento y devuelve cero cuando tuvo éxito.

C99 y POSIX.1-2008 especifican un identificador, FLT_ROUNDS, definido en <float.h>, que indica el comportamiento de redondeo definido por la implementación para la suma de punto flotante. Este identificador tiene uno de los siguientes valores:

-1
El modo de redondeo no se puede determinar.
0
El redondeo es hacia 0.
1
El redondeo es hacia el número más cercano.
2
El redondeo es hacia el infinito positivo.
3
El redondeo es hacia el infinito negativo.

Otros valores representan modos de redondeo dependientes de la máquina, no estándar.

El valor de FLT_ROUNDS debe reflejar el modo de redondeo actual establecido por fesetround() (pero véase ERRORES).

Entorno de punto flotante

Todo el entorno de punto flotante, incluidos los modos de control y las banderas de estado, puede manejarse como un único objeto opaco, de tipo fenv_t. El entorno predeterminado se denota por FE_DFL_ENV (de tipo const fenv_t *). Este es el entorno configurado al inicio del programa y está definido por ISO C para tener redondeo al más cercano, todas las excepciones borradas y un modo continuo (continuar ante excepciones).

La función fegetenv() guarda el entorno de punto flotante actual en el objeto *envp.

La función feholdexcept() hace lo mismo, luego borra todas las banderas de excepción y establece un modo continuo (continuar ante excepciones), si está disponible. Devuelve cero si tuvo éxito.

La función fesetenv() restaura el entorno de punto flotante desde el objeto *envp. Este objeto debe ser válido conocido, por ejemplo, el resultado de una llamada a fegetenv() o feholdexcept() o igual a FE_DFL_ENV. Esta llamada no genera excepciones.

La función feupdateenv() instala el entorno de punto flotante representado por el objeto *envp, excepto que las excepciones actualmente generadas no se borran. Después de llamar a esta función, las excepciones generadas serán un OR a nivel de bits de las previamente establecidas con las de *envp. Como antes, el objeto *envp debe ser conocido como válido.

VALOR DE RETORNO

Estas funciones devuelven cero en caso de éxito y un valor distinto de cero si ocurrió un error.

NOTAS

Notas de glibc

Las funciones feenableexcept(), fedisableexcept() y fegetexcept() no son parte del estándar C99 ni de POSIX.1-2008, pero se encuentran en glibc.

En glibc, el valor de FLT_ROUNDS siempre es 1 (redondeo al más cercano), incluso si el hardware soporta otras formas de redondeo y el modo de redondeo se ha cambiado con fesetround().

Las llamadas a estas funciones pueden no ser seguras para hilos (thread-safe) si las excepciones de punto flotante se manejan con interrupciones del sistema operativo. En particular, la configuración de un manejador de señales para las excepciones de punto flotante podría no ser segura para hilos, y el uso de sigaction(2) para modificar el comportamiento de las excepciones de punto flotante no está soportado por glibc.

class='permalink' href='#glibc_notes'>notas de glibc

Si es posible, la Biblioteca C de GNU define una macro FE_NOMASK_ENV que representa un entorno donde cada excepción generada provoca la ocurrencia de una trampa. Puede comprobar esta macro usando #ifdef. Solo se define si _GNU_SOURCE está definido. El estándar C99 no define una forma de establecer bits individuales en la máscara de coma flotante, por ejemplo, para generar una trampa en indicadores específicos. Desde glibc 2.2, glibc soporta las funciones feenableexcept() y fedisableexcept() para establecer trampas individuales de coma flotante, y fegetexcept() para consultar el estado.

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <fenv.h>
int feenableexcept(int excepts);
int fedisableexcept(int excepts);
int fegetexcept(void);

Las feenableexcept() y fedisableexcept() funciones habilitan (deshabilitan) trampas para cada una de las excepciones representadas por excepts y devuelven el conjunto anterior de excepciones habilitadas cuando se tiene éxito, y -1 en caso contrario. La fegetexcept() función devuelve el conjunto de todas las excepciones actualmente habilitadas.

ERRORES

C99 especifica que el valor de FLT_ROUNDS debe reflejar cambios en el modo de redondeo actual, establecido por fesetround(). Actualmente, esto no ocurre: FLT_ROUNDS siempre tiene el valor 1.
