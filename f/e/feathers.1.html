FEATHERS(1) Manual de comandos generales FEATHERS(1)

NOMBRE

feathers — un depurador simple a nivel de código fuente para CHICKEN Scheme

SINOPSIS

feathers [OPCIÓN ...] [PROGRAMA ARGUMENTOS ...]

DESCRIPCIÓN

feathers ejecuta un programa compilado con CHICKEN Scheme y permite la depuración básica a nivel de código fuente, como establecer puntos de interrupción, ejecutar paso a paso y la inspección de argumentos de procedimientos y variables globales.

El código Scheme debe compilarse con el nivel de depuración 3 para que la depuración sea posible. La comunicación con el depurador se realiza intercambiando mensajes a través de un socket TCP, cuya dirección y puerto se especifican mediante la variable de entorno CHICKEN_DEBUGGER, que contiene una dirección de conexión del tipo ⟨DIRECCIÓN⟩:⟨PUERTO⟩.

PROGRAMA debe ser la ruta al ejecutable que se va a ejecutar; PATH no se buscará.

El programa acepta los siguientes argumentos:

-help
Muestra una lista de las opciones de línea de comandos admitidas.
-n
No cargue el archivo de inicio predeterminado .feathers.
-d
TODO: Documentar esto
-dir DIRECTORIO
Agregue DIRECTORIO a la lista de rutas buscadas para localizar archivos de código fuente.
-port PUERTO
Seleccione un puerto TCP diferente al predeterminado (9999).

AMBIENTE

Las siguientes variables de entorno cambian el comportamiento de feathers:

CHICKEN_DEBUGGER
Debería contener una dirección y puerto de servidor TCP donde el depurador está escuchando. Esta variable la establece el depurador cuando se ejecuta un programa desde él, y por defecto es localhost:9999.

ESTADO DE SALIDA

La utilidad feathers sale con 0 si tiene éxito y >0 si ocurre un error.

VER TAMBIÉN

Se puede encontrar más información en el Manual del Usuario de CHICKEN.
