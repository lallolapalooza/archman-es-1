std::vector<uint8_t> Vector::BLF::Most150AllocTab::tableData {}

Datos de la Tabla de Asignación.

La disposición de los datos de tableData depende del bit 0 de eventModeFlags.

Si el bit 0 de eventModeFlags está borrado, tableData contiene registros de length/4 con los siguientes campos. (Otras disposiciones de datos no están especificadas todavía).

  • Bits 0..12 (LabelIdent): Etiqueta de Conexión Síncrona.
  • Bits 12..15 (LabelStatus):
•
0: etiqueta sin cambios
•
4: etiqueta añadida (asignada)
•
8: etiqueta eliminada (desasignada) ¡Listar las etiquetas eliminadas al final de la tabla! Listar las etiquetas eliminadas es opcional.
•
Bits 16..31 (LabelWidth): Ancho de la etiqueta en bytes.

Disposición de datos: if((eventModeFlags & 0x0001) == 0) layout A: SLLLWWWWSLLLWWWWSLLLWWWW... if((eventModeFlags & 0x0001) == 0x0001) layout B: SLLLWWWW< canales >SLLLWWWW< canales >SLLLWWWW< canales >...

•
S: banderas de estado.
•
0x4: 1: etiqueta nueva (asignación)
•
0x8: 1: esta etiqueta ha sido eliminada (desasignación)
  • LLL: número de etiqueta.
  • WWWW: ancho de etiqueta.
  • < canales >: lista de números de canal de 16 bits (tamaño = ancho de etiqueta).
