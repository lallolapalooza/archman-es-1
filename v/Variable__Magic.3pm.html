Variable::Magic(3) Documentación de Perl aportada por el usuario Variable::Magic(3)

NOMBRE

Variable::Magic - Asociar magia definida por el usuario a variables desde Perl.

VERSIÓN

Versión 0.64

SINOPSIS

use Variable::Magic qw<wizard cast VMG_OP_INFO_NAME>;
{ # Un rastreador de variables
 my $wiz = wizard(
  set  => sub { print "¡ahora establecido a ${$_[0]}!\n" },
  free => sub { print "¡destruido!\n" },
 );
 my $a = 1;
 cast $a, $wiz;
 $a = 2;        # "¡ahora establecido a 2!"
}               # "¡destruido!"
{ # Un hash con un valor predeterminado
 my $wiz = wizard(
  data     => sub { $_[1] },
  fetch    => sub { $_[2] = $_[1] unless exists $_[0]->{$_[2]}; () },
  store    => sub { print "clave $_[2] almacenada en $_[-1]\n" },
  copy_key => 1,
  op_info  => VMG_OP_INFO_NAME,
 );
 my %h = (_default => 0, apple => 2);
 cast %h, $wiz, '_default';
 print $h{banana}, "\n"; # "0" (no hay clave 'banana' en %h)
 $h{pear} = 1;           # "clave pear almacenada en helem"
}

DESCRIPCIÓN

La magia es la forma de Perl de mejorar las variables. Este mecanismo permite al usuario añadir datos adicionales a cualquier variable y enganchar operaciones sintácticas (como acceso, asignación o destrucción) que se puedan aplicar a ella. Con este módulo, puedes añadir tu propia magia a cualquier variable sin tener que escribir una sola línea de XS.

Te darás cuenta de que estas variables mágicas se parecen mucho a las variables enlazadas (tied). No es sorprendente, ya que las variables enlazadas se implementan como un tipo especial de magia, al igual que cualquier variable Perl 'irregular': escalares como $!, $( o $^W, los hashes %ENV y %SIG, el array %ISA, lvalues de vec() y substr(), variables threads::shared... Todos comparten la misma API C subyacente, y este módulo te da acceso directo a ella.

Aún así, la magia disponible a través de este módulo difiere de enlazar y sobrecargar de varias maneras:

  • La magia no se copia en la asignación.

    Se adjunta a las variables, no a los valores (como para las referencias bendecidas).

  • La magia no reemplaza la semántica original.

    Las devoluciones de llamada de magia generalmente se activan antes de que ocurra la acción original, y no pueden evitar que suceda. Esto también facilita la captura de eventos individuales que con "tie", donde tienes que proporcionar métodos de respaldo para todas las acciones, generalmente heredando de la clase correcta de "Tie::Std*" y sobrescribiendo métodos individuales en tu propia clase.

  • La magia es multivalor.

    Puedes aplicar de forma segura diferentes tipos de magia a la misma variable, y cada una de ellas se invocará sucesivamente.

  • La magia es agnóstica al tipo.

    La misma magia se puede aplicar a escalares, arrays, hashes, subs o globs. Pero el mismo hook (ver abajo para una lista) puede dispararse de manera diferente dependiendo del tipo de la variable.

  • La magia es invisible a nivel de Perl.

    Las variables mágicas y no mágicas no se pueden distinguir con "ref", "tied" u otro truco.

  • La magia es notablemente más rápida.

    Principalmente porque la forma en que Perl maneja la magia es más ligera por naturaleza, y porque no hay necesidad de resolución de métodos. Además, como no tienes que reimplementar toda la semántica de la variable, solo pagas por lo que realmente usas.

Las operaciones que se pueden sobrecargar son:

  • get

    Esta magia se invoca cuando se evalúa la variable. Nunca se llama para arrays y hashes.

  • set

    Esta magia se llama cada vez que cambia el valor de la variable. Se llama para subíndices y rebanadas de arrays, pero nunca para hashes.

  • len

    Esta magia se aplica solo a arrays (aunque solía aplicarse también a escalares), y se activa cuando Perl necesita conocer el 'tamaño' o la 'longitud' de la variable. Esta es típicamente la magia involucrada cuando un array se evalúa en contexto escalar, pero también en asignación de arrays y bucles ("for", "map" o "grep"). La longitud se devuelve de la devolución de llamada como un entero.

    A partir de perl 5.12, esta magia ya no es llamada por la palabra clave "length", y a partir de perl 5.17.4 tampoco se llama para escalares en ninguna situación, lo que hace que esta magia solo sea significativa en arrays. Puedes usar las constantes "VMG_COMPAT_SCALAR_LENGTH_NOLEN" y "VMG_COMPAT_SCALAR_NOLEN" para ver si esta magia está disponible para escalares o no.

  • clear

    Esta magia se invoca cuando la variable se reinicia, como cuando se vacía un array. Tenga en cuenta que esto es diferente de desdefinir la variable, aunque la magia se llama cuando el vaciado es el resultado de la desdefinición (por ejemplo, para un array, pero en realidad un error impide que funcione antes de perl 5.9.5 - vea el historial).

  • free

    Esta magia se llama cuando una variable es destruida como resultado de salir de su ámbito (pero no cuando se desdefine). Se comporta aproximadamente como los destructores de objetos de Perl (es decir, los métodos "DESTROY"), excepto que las excepciones lanzadas desde dentro de una devolución de llamada free siempre se propagarán al código circundante.

  • copy

    Cuando se aplica a arrays y hashes enlazados, esta magia se activa cuando intentas acceder o cambiar sus elementos.

    A partir de perl 5.17.0, también se puede aplicar a prototipos de cierre, en cuyo caso la magia se llamará cuando el prototipo se clona. La constante "VMG_COMPAT_CODE_COPY_CLONE" es verdadera cuando tu perl soporta esta característica.

  • dup

    Esta magia se invoca cuando la variable se clona entre hilos. Actualmente no está disponible.

  • local

    Cuando esta magia se establece en una variable, todas las localizaciones posteriores de la variable activarán la devolución de llamada. Está disponible en tu perl si y solo si "MGf_LOCAL" es verdadero.

Las siguientes acciones solo se aplican a hashes y están disponibles si y solo si "VMG_UVAR" es verdadero. Se denominan magias uvar.

  • fetch

    Esta magia se invoca cada vez que se recupera un elemento del hash.

  • store

    Esta se llama cuando se almacena un elemento en el hash.

  • exists

    Esta magia se activa cuando se prueba la existencia de una clave en el hash.

  • delete

    Esta magia se activa cuando se elimina una clave en el hash, independientemente de si la clave existe realmente en él.

Puedes consultar las pruebas para tener más información sobre dónde se invocan las diferentes magias.

FUNCIONES

"wizard"

wizard(
 data     => sub { ... },
 get      => sub { my ($ref, $data [, $op]) = @_; ... },
 set      => sub { my ($ref, $data [, $op]) = @_; ... },
 len      => sub {
  my ($ref, $data, $len [, $op]) = @_; ... ; return $newlen
 },
 clear    => sub { my ($ref, $data [, $op]) = @_; ... },
 free     => sub { my ($ref, $data [, $op]) = @_, ... },
 copy     => sub { my ($ref, $data, $key, $elt [, $op]) = @_; ... },
 local    => sub { my ($ref, $data [, $op]) = @_; ... },
 fetch    => sub { my ($ref, $data, $key [, $op]) = @_; ... },
 store    => sub { my ($ref, $data, $key [, $op]) = @_; ... },
 exists   => sub { my ($ref, $data, $key [, $op]) = @_; ... },
 delete   => sub { my ($ref, $data, $key [, $op]) = @_; ... },
 copy_key => $bool,
 op_info  => [ 0 | VMG_OP_INFO_NAME | VMG_OP_INFO_OBJECT ],
)

Esta función crea un 'wizard', un objeto opaco que contiene la información de magia. Toma una lista de claves / valores como argumento, cuyas claves pueden ser:

  • "data"

    Una referencia a código (o cadena) para un constructor de datos privado. Se llama una vez por cada variable a la que se le aplica la magia, y se espera que devuelva los datos privados para esta variable. Si no se proporciona, la magia no tendrá datos privados.

  • "get", "set", "len", "clear", "free", "copy", "local"

    Una referencia a código (o cadena) que se llama cuando ocurre la operación correspondiente. Los argumentos pasados a estas devoluciones de llamada son:

    my ($ref, $data [, $op])
    Para las operaciones get, set, clear, free, local.
    my ($ref, $data, $len [, $op])
    Para la operación len (solo en arrays).
    my ($ref, $data, $key, $elt [, $op])
    Para la operación copy (solo en hashes y arrays enlazados).

    donde $ref es la variable mágica (o un puntero a ella), $data es los datos privados (si los hay) asociados a esta magia, y $op es el valor de la operación para esta variable (ver abajo).

    Si las devoluciones de llamada devuelven un valor, se utilizará en lugar del valor original. Si no devuelven nada (o implícitamente), se mantenrá el comportamiento original de Perl.

    La operación "get" es un caso especial. Si no devuelve nada, el valor original de la variable se mantendrá. Si devuelve un valor, este se utilizará en su lugar. Si la variable es un escalar y está vacía, entonces la devolución de llamada get para la magia será invocada con undef.

    La operación "len" debe devolver la nueva longitud de la variable como un entero.

    Las operaciones "copy" y "local" están disponibles para todos los tipos de variables en las versiones de Perl correspondientes.

  • "fetch", "store", "exists", "delete"

    Estos métodos solo se aplican a hashes (o a la parte de hash de los globs) y tienen una sintaxis ligeramente diferente.

    my ($ref, $data, $key [, $op])

    donde $key es la clave que se accede/almacena/prueba/elimina.

    Los métodos fetch y store también tienen que devolver un valor, que se utilizará como valor de la operación.

    Si devuelve undef, se producirá un error de uso de lista/escalar.

  • "copy_key"

    Booleano (0 o 1). Si es verdadero, la magia será copiada en cada clave del hash/array al que se aplica. Esto es útil para el ejemplo de hash con valor predeterminado.

  • "op_info"

    Define la información de operación para el hook. Los valores posibles son 0 (predeterminado, ninguna información de operación), VMG_OP_INFO_NAME (el nombre de la operación está disponible como último argumento de las devoluciones de llamada) o VMG_OP_INFO_OBJECT (el objeto de la operación está disponible como último argumento).

"cast"

cast VAR, WIZARD [, KEY] [, extra_data]

Aplica la magia representada por WIZARD a la variable VAR. Si VAR es un array o un hash, la magia se aplica a la variable en sí, no a sus elementos. Sin embargo, si se proporciona una KEY opcional (solo aplicable a arrays y hashes), la magia se aplicará a esa clave específica. En el caso de hashes, si copy_key se establece en verdadero en el wizard, la magia se copiará en todas las claves existentes y futuras.

Se puede pasar cualquier argumento adicional después de la clave (si se proporciona) o después del wizard (si no se proporciona la clave). Estos argumentos se pasarán como el último argumento a todas las devoluciones de llamada de magia, como $op.

El wizard se puede eliminar de una variable con:

no_magic VAR

"wizard_info"

wizard_info VAR [, KEY]

Devuelve el wizard (o un array de wizards si hay varios) asociado a VAR (o KEY de VAR). La información devuelta es una lista de pares clave-valor tal como se pasaron a la función wizard.

"is_magic"

is_magic VAR [, KEY]

Devuelve verdadero si VAR (o KEY de VAR) tiene alguna magia asociada.

"no_magic"

no_magic VAR [, KEY]

Elimina toda la magia de VAR (o KEY de VAR).

"magic_log"

magic_log( ON | OFF )

Activa o desactiva el registro de todas las operaciones de magia. Esto es útil para depurar.

"magic_args"

magic_args()

Devuelve los argumentos adicionales que se pasaron a la función cast.

EJEMPLOS

Ve el ejemplo de SINOPSIS para una introducción rápida.

UN RASTREADOR DE VARIABLES SIMPLE

Este ejemplo muestra cómo rastrear cuándo se establece o destruye una variable.

use Variable::Magic qw(wizard cast);
{
    my $trace_wiz = wizard(
        set => sub { printf "Variable changed to: %s\n", $_[0] },
        free => sub { printf "Variable destroyed.\n" }
    );
    my $var = "initial";
    cast $var, $trace_wiz;
    print "Setting variable...\n";
    $var = "new value";
    print "Variable is now: $var\n";
} # Variable destroyed. se imprime aquí
print "Scope ended.\n";

HASH CON VALOR PREDETERMINADO

Este ejemplo muestra cómo crear un hash que proporciona un valor predeterminado para las claves inexistentes.

use Variable::Magic qw(wizard cast VMG_OP_INFO_NAME);
{
    my $default_wiz = wizard(
        # 'data' define el valor que se devolverá si la clave no existe
        data => sub { return shift if defined $_[0]; $_[1] },
        # 'fetch' se llama cuando se accede a una clave
        fetch => sub {
            my ($hash, $data, $key) = @_;
            # Si la clave no existe y no es la clave de datos especial, usa el valor predeterminado
            unless (exists $hash->{$key} || $key eq '_default') {
                return $data; # Devuelve el valor predeterminado
            }
            return # Devuelve undef, Perl usará el valor existente o creará uno nuevo
        },
        # 'store' se llama cuando se asigna un valor a una clave
        store => sub {
            my ($hash, $data, $key) = @_;
            print "Storing key '$key' with value '$hash->{$key}'\n";
        },
        # 'copy_key' asegura que la magia se copie en las nuevas claves
        copy_key => 1,
        # 'op_info' nos permite obtener el nombre de la operación
        op_info => VMG_OP_INFO_NAME,
    );
    my %my_hash = (_default => 0); # Valor predeterminado
    cast %my_hash, $default_wiz, '_default'; # Asocia la magia
    print "Value of 'apple': ", $my_hash{'apple'}, "\n"; # Devuelve 0
    $my_hash{'banana'} = 5; # Almacenando clave 'banana' con valor '5'
    print "Value of 'banana': ", $my_hash{'banana'}, "\n"; # Devuelve 5
    print "Value of 'orange': ", $my_hash{'orange'}, "\n"; # Devuelve 0
}

MEJORANDO ARRAYS

Este ejemplo muestra cómo crear un array que solo acepta números.

use Variable::Magic qw(wizard cast);
{
    my $numeric_wiz = wizard(
        set => sub {
            my ($arr_ref, $data, $index) = @_;
            # Solo permite números
            die "Array element must be numeric\n" unless $_[0] =~ /^\d+$/;
        },
        # La magia 'copy' se activa cuando se copian elementos de un array a otro
        copy => sub {
            my ($arr_ref, $data, $index, $value) = @_;
            die "Array element must be numeric\n" unless $value =~ /^\d+$/;
            return $value; # Devuelve el valor copiado
        }
    );
    my @numbers;
    cast @numbers, $numeric_wiz;
    print "Pushing 10...\n";
    push @numbers, 10;
    print "Pushing abc...\n";
    eval { push @numbers, "abc" };
    if ($@) { print "Caught expected error: $@"; }
    my @more_numbers;
    cast @more_numbers, $numeric_wiz;
    print "Copying numbers...\n";
    eval { @more_numbers = @numbers };
    if ($@) { print "Caught expected error: $@"; }
    print "Copying numbers with an invalid one...\n";
    eval { @more_numbers = (1, 2, "bad", 4) };
    if ($@) { print "Caught expected error: $@"; }
}

API de MAGIA de PERL

Esta interfaz es una abstracción de la API de magia de Perl. Permite instalar, desinstalar y obtener información sobre la magia asociada con una variable.

"wizard"

my $wiz = wizard( TYPEDEF => $code, ... )

Crea y devuelve un nuevo objeto de magia. El objeto de magia se utiliza para asociar (o desasociar) la magia a una variable y para obtener datos asociados. Los argumentos son pares clave-valor que definen los callbacks de la magia. Aquí están los callbacks disponibles:

  • "getdata"

    Un callback para obtener datos de la variable. Ver "getdata".

  • "cast"

    Un callback que se llama cada vez que la magia se aplica a una variable. Se llama en contexto escalar, con $_[0] siendo una referencia a esta variable y @_[1 .. @_-1] siendo todos los argumentos adicionales que se pasaron a "cast". El escalar devuelto desde esta llamada se adjunta a la variable y se puede recuperar más tarde con "getdata".

  • "get", "set", "len", "clear", "free", "copy", "local", "fetch", "store", "exists" y "delete"

    Referencias de código (o cadenas) a los respectivos callbacks de magia. No es necesario especificarlos todos: la magia que corresponde a las entradas no definidas simplemente no se enganchará.

    Cuando se ejecutan estos callbacks, $_[0] es una referencia a la variable mágica y $_[1] son los datos privados asociados (o "undef" cuando no se proporciona un constructor de datos privados con el asistente). Otros argumentos dependen de qué tipo de magia esté involucrada:

  • len

    $_[2] contiene la longitud natural, no mágica, de la variable (que solo puede ser un escalar o una matriz, ya que la magia len solo es relevante para estos tipos). Se espera que el callback devuelva la nueva longitud de escalar o matriz a usar, o "undef" para usar la longitud normal por defecto.

  • copy

    Cuando la variable para la que se invoca la magia es una matriz o un hash, $_[2] es un alias o una copia de la clave actual, y $_[3] es un alias para el elemento actual (es decir, el valor). Dado que $_[2] puede ser una copia, es inútil intentar cambiarlo o aplicarle magia.

    A partir de perl 5.17.0, esta magia también puede ser llamada para referencias de código. En este caso, $_[2] es siempre "undef" y $_[3] es una referencia a la subrutina anónima clonada.

  • fetch, store, exists y delete

    $_[2] es un alias para la clave actual. Tenga en cuenta que $_[2] puede ser de solo lectura legítimamente si la clave proviene de una palabra desnuda, y como tal, no es seguro asignarle un valor. Puede solicitar una copia en su lugar pasando "copy_key => 1" a "wizard", lo que, a costa de un pequeño impacto en el rendimiento, le permite asignar de forma segura a $_[2] para, por ejemplo, redirigir la acción a otra clave.

Finalmente, si "op_info => $num" también se pasa a "wizard", se agrega un elemento adicional a @_. Su naturaleza depende del valor de $num:

  • "VMG_OP_INFO_NAME"

    $_[-1] es el nombre de la operación actual.

  • "VMG_OP_INFO_OBJECT"

    $_[-1] es el objeto "B::OP" para la operación actual.

Ambos resultan en un pequeño impacto en el rendimiento, pero solo obtener el nombre es más ligero que obtener el objeto de operación.

Estos callbacks siempre se ejecutan en contexto escalar. El valor devuelto se convierte a un entero con signo, que luego se pasa directamente a la API de magia de perl. Sin embargo, tenga en cuenta que perl actualmente solo se preocupa por el valor de retorno del callback de magia len e ignora todos los demás. A partir de Variable::Magic 0.58, una referencia devuelta desde un callback de magia que no sea len no se destruirá inmediatamente, sino que se permitirá que sobreviva hasta el final de la declaración que activó la magia. Esto le permite usar este valor de retorno como un token para activar un destructor después de que ocurra la acción mágica original. Puede ver un ejemplo de esta técnica en el libro de cocina.

Cada callback puede especificarse como:

  • una referencia de código, que se llamará como una subrutina.
  • una referencia a una cadena, donde la cadena denota qué subrutina se debe llamar cuando se activa la magia. Si el nombre de la subrutina no está completamente calificado, entonces el paquete actual en el momento en que se invoca la magia se usará en su lugar.
  • una referencia a "undef", en cuyo caso se instala un callback de magia sin operación en lugar del predeterminado. Esto puede ser especialmente útil para la magia local, donde un callback vacío evita que la magia se copie durante la localización.

Tenga en cuenta que la magia free nunca se llama durante la destrucción global, ya que no hay forma de garantizar que el objeto asistente y el callback no se destruyeran antes que la variable.

Aquí hay un ejemplo de uso simple:

# Un simple rastreador de escalares
my $wiz = wizard(
 get  => sub { print STDERR "obtenido ${$_[0]}\n" },
 set  => sub { print STDERR "establecido a ${$_[0]}\n" },
 free => sub { print STDERR "${$_[0]} fue eliminado\n" },
);

"cast"

cast [$@%&*]var, $wiz, @args

Esta función asocia la magia $wiz a la variable proporcionada, sin sobrescribir ningún otro tipo de magia. Devuelve verdadero si tiene éxito o cuando la magia $wiz ya está adjunta, y falla (croaks) en caso de error. Cuando $wiz proporciona un constructor de datos, se llama justo antes de que la magia se aplique a la variable, y recibe una referencia a la variable objetivo en $_[0] y el contenido de @args en @_[1 .. @args]. De lo contrario, @args se ignora.

# Aplica $wiz a $x, pasando (\$x, '1') al constructor de datos.
my $x;
cast $x, $wiz, 1;

El argumento "var" puede ser un valor de matriz o hash. La magia para estos escalares se comporta como para cualquier otro, excepto que se disipa cuando la entrada se elimina del contenedor. Por ejemplo, si desea llamar a "POSIX::tzset" cada vez que la variable de entorno 'TZ' cambia en %ENV, puede usar:

use POSIX;
cast $ENV{TZ}, wizard set => sub { POSIX::tzset(); () };

Si desea manejar la posible eliminación de la entrada 'TZ', también debe especificar la magia store.

"getdata"

getdata [$@%&*]var, $wiz

Este accesor recupera los datos privados asociados con la magia $wiz en la variable. Falla (croaks) cuando $wiz no representa un objeto de magia válido y devuelve una lista vacía si no hay tal magia adjunta a la variable o cuando el asistente no tiene un constructor de datos.

# Obtiene los datos adjuntos a $wiz en $x, o undef si $wiz
# no adjuntó ninguno.
my $data = getdata $x, $wiz;

"dispell"

dispell [$@%&*]variable, $wiz

Lo opuesto exacto a "cast": disocia la magia $wiz de la variable. Esta función devuelve verdadero si tiene éxito, 0 cuando no se pudo encontrar magia representada por $wiz en la variable, y falla (croaks) si el asistente proporcionado es inválido.

# Disipa ahora.
die 'no such magic in $x' unless dispell $x, $wiz;

CONSTANTES

"MGf_COPY"

Se evalúa como verdadero si y solo si la magia copy está disponible. Este es el caso para perl 5.7.3 y superior, lo que está garantizado por los requisitos de este módulo.

"MGf_DUP"

Se evalúa como verdadero si y solo si la magia dup está disponible. Este es el caso para perl 5.7.3 y superior, lo que está garantizado por los requisitos de este módulo.

"MGf_LOCAL"

Se evalúa como verdadero si y solo si la magia local está disponible. Este es el caso para perl 5.9.3 y superior.

"VMG_UVAR"

Cuando esta constante es verdadera, puede usar las magias fetch, store, exists y delete en hashes. La capacidad inicial "VMG_UVAR" se introdujo en perl 5.9.5, con una implementación completamente funcional enviada con perl 5.10.0.

"VMG_COMPAT_SCALAR_LENGTH_NOLEN"

Verdadero para perls que no llaman a la magia len al tomar la "longitud" de un escalar mágico.

"VMG_COMPAT_SCALAR_NOLEN"

Verdadero para perls que no llaman a la magia len en escalares. Implica "VMG_COMPAT_SCALAR_LENGTH_NOLEN".

"VMG_COMPAT_ARRAY_PUSH_NOLEN"

Verdadero para perls que no llaman a la magia len cuando se inserta un elemento en una matriz mágica. A partir de perl 5.11.0, esto solo se refiere a inserciones en contexto no vacío y, por lo tanto, es falso.

'"VMG_COMPAT_ARRAY_PUSH_NOLEN_VOID"

Verdadero para perls que no llaman a la magia len cuando insertas en contexto void un elemento en un array mágico.

"VMG_COMPAT_ARRAY_UNSHIFT_NOLEN_VOID"

Verdadero para perls que no llaman a la magia len cuando quitas al principio en contexto void un elemento de un array mágico.

"VMG_COMPAT_ARRAY_UNDEF_CLEAR"

Verdadero para perls que llaman a la magia clear al desdefinir arrays mágicos.

"VMG_COMPAT_HASH_DELETE_NOUVAR_VOID"

Verdadero para perls que no llaman a la magia delete cuando borras un elemento de un hash en contexto void.

"VMG_COMPAT_CODE_COPY_CLONE"

Verdadero para perls que llaman a la magia copy cuando un prototipo de cierre mágico es clonado.

"VMG_COMPAT_GLOB_GET"

Verdadero para perls que llaman a la magia get para operaciones en globs.

"VMG_PERL_PATCHLEVEL"

El nivel de parche de perl con el que se construyó este módulo, o 0 para perls no depurables.

"VMG_THREADSAFE"

Verdadero si y solo si este módulo podría haberse construido con funciones de seguridad de hilos habilitadas.

"VMG_FORKSAFE"

Verdadero si y solo si este módulo podría haberse construido con funciones de seguridad de fork habilitadas. Esto siempre es verdadero, excepto en Windows, donde es falso para perl 5.10.0 y anteriores.

"VMG_OP_INFO_NAME"

Valor a pasar con "op_info" para obtener el nombre del op actual en las callbacks mágicas.

"VMG_OP_INFO_OBJECT"

Valor a pasar con "op_info" para obtener un objeto "B::OP" que representa el op actual en las callbacks mágicas.

MANUAL DE RECETAS

Asociar un objeto a cualquier variable de perl

Esta técnica puede ser útil para pasar datos de usuario a través de APIs limitadas. Es similar a usar objetos inside-out, pero sin el inconveniente de tener que implementar un destructor complejo.

{
 package Magical::UserData;
 use Variable::Magic qw<wizard cast getdata>;
 my $wiz = wizard data => sub { \$_[1] };
 sub ud (\[$@%*&]) : lvalue {
  my ($var) = @_;
  my $data = &getdata($var, $wiz);
  unless (defined $data) {
   $data = \(my $slot);
   &cast($var, $wiz, $slot)
             or die "Couldn't cast UserData magic onto the variable";
  }
  $$data;
 }
}
{
 BEGIN { *ud = \&Magical::UserData::ud }
 my $cb;
 $cb = sub { print 'Hola, ', ud(&$cb), "!\n" };
 ud(&$cb) = 'mundo';
 $cb->(); # Hola, mundo!
}

Lanzar magia recursivamente en estructuras de datos

"cast" puede ser llamado desde cualquier callback mágico y, en particular, desde "data". Esto te permite lanzar magia recursivamente en estructuras de datos:

my $wiz;
$wiz = wizard data => sub {
 my ($var, $depth) = @_;
 $depth ||= 0;
 my $r = ref $var;
 if ($r eq 'ARRAY') {
  &cast((ref() ? $_ : \$_), $wiz, $depth + 1) for @$var;
 } elsif ($r eq 'HASH') {
  &cast((ref() ? $_ : \$_), $wiz, $depth + 1) for values %$var;
 }
 return $depth;
},
free => sub {
 my ($var, $depth) = @_;
 my $r = ref $var;
 print "liberar $r en profundidad $depth\n";
 ();
};
{
 my %h = (
  a => [ 1, 2 ],
  b => { c => 3 }
 );
 cast %h, $wiz;
}

Cuando %h sale del alcance, esto imprime algo como:

liberar HASH en profundidad 0
liberar HASH en profundidad 1
liberar SCALAR en profundidad 2
liberar ARRAY en profundidad 1
liberar SCALAR en profundidad 3
liberar SCALAR en profundidad 3

Por supuesto, este ejemplo no hace nada con los valores que se añaden después de "cast".

Acciones mágicas retardadas

A partir de Variable::Magic 0.58, el valor de retorno de las callbacks mágicas se puede usar para retrasar la acción hasta después de que ocurra la acción original:

my $delayed;
my $delayed_aux = wizard(
 data => sub { $_[1] },
 free => sub {
  my ($target) = $_[1];
  my $target_data = &getdata($target, $delayed);
  local $target_data->{guard} = 1;
  if (ref $target eq 'SCALAR') {
   my $orig = $$target;
   $$target = $target_data->{mangler}->($orig);
  }
  return;
 },
);
$delayed = wizard(
 data => sub {
  return +{ guard => 0, mangler => $_[1] };
 },
 set  => sub {
  return if $_[1]->{guard};
  my $token;
  cast $token, $delayed_aux, $_[0];
  return \$token;
 },
);
my $x = 1;
cast $x, $delayed => sub { $_[0] * 2 };
$x = 2;
# $x ahora es 4
# Pero ten en cuenta que la acción retrasada solo tiene lugar al final de
# la declaración actual:
my @y = ($x = 5, $x);
# $x ahora es 10, pero @y es (5, 5)

HISTORIAL DE MAGIA DE PERL

Los lugares donde se invoca la magia han cambiado un poco a lo largo de la historia de perl. Aquí hay una pequeña lista de los más recientes.

  • 5.6.x

    p14416 : Magia copy y dup.

  • 5.8.9

    p28160 : Integración de p25854 (ver abajo).

    p32542 : Integración de p31473 (ver abajo).

  • 5.9.3

    p25854 : La magia len ya no se llama al insertar un elemento en un array mágico.

    p26569 : Magia local.

  • 5.9.5

    p31064 : Magia uvar con significado.

    p31473 : La magia clear no se invocaba al desdefinir un array. El error se corrige a partir de esta versión.

  • 5.10.0

    Dado que "PERL_MAGIC_uvar" está en mayúsculas, hv_magic_check() activa la magia copy en las asignaciones de hash para hashes (no atados) que también tienen magia uvar.

  • 5.11.x

    p32969 : La magia len ya no se invoca al llamar a "length" con un escalar mágico.

    p34908 : La magia len ya no se llama al insertar / quitar al principio un elemento en un array mágico en contexto void. La parte de "push" ya estaba cubierta por p25854.

    g9cdcb38b : La magia len se vuelve a llamar al insertar en un array mágico en contexto no void.

EXPORTACIÓN

Las funciones "wizard", "cast", "getdata" y "dispell" solo se exportan bajo petición. Todas ellas se exportan con las etiquetas ':funcs' y ':all'.

Todas las constantes también se exportan solo bajo petición, ya sea individualmente o con las etiquetas ':consts' y ':all'.

ADVERTENCIAS

Para enganchar operaciones de hash con magia, necesitas al menos perl 5.10.0 (ver "VMG_UVAR").

Si quieres almacenar un objeto mágico en la ranura de datos privada, no podrás recuperar la magia con "getdata", ya que la magia no se copia por asignación. Puedes sortear este escollo almacenando en su lugar una referencia al objeto mágico.

Si defines un mago con magia free y lo lanzas sobre sí mismo, resulta en un ciclo de memoria, por lo que este destructor no se llamará cuando el mago sea liberado.
