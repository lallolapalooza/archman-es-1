Vector_BLF_TestStructure(3)

NAME

Vector_BLF_TestStructure - Data structure for BLF test results.

DESCRIPTION

This structure is used to store the results of BLF (Binary Logging Format) tests.

STRUCT DEFINITION


typedef struct {
    int test_id;
    bool passed;
    char result_message[256];
    // Other relevant test data can be added here
} Vector_BLF_TestStructure;

MEMBER FUNCTION DOCUMENTATION

No member functions are directly associated with this structure in this context. Functions that operate on this structure would typically be defined elsewhere.

MEMBER DATA DOCUMENTATION

  • test_id: An integer representing the unique identifier for the test.
  • passed: A boolean value indicating whether the test passed (true) or failed (false).
  • result_message: A character array to store a descriptive message about the test result (e.g., success details or error description). Maximum length is 255 characters plus null terminator.
