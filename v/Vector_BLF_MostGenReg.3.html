DESCRIPCIÓN DETALLADA

MOST_GENREG.

Este evento informa del cambio de un registro importante del transceptor, como la posición del nodo o la dirección del nodo. Puede ocurrir de forma espontánea o como resultado de una operación de lectura/escritura. Inmediatamente después del inicio de la medición, se informan los valores actuales de los registros especiales, incluso si no han cambiado.

uint16_t Vector::BLF::MostGenReg::regId {}

ID de registro IDs para identificar registros.

  • Vacío = 0x0
  • NPR = 0x87: registro de posición de nodo de 8 bits
  • GA = 0x89: dirección de grupo de 8 bits (Dirección de grupo = 0x0300 + Grupo)
  • NA = 0x8A: dirección de nodo de 16 bits
  • NDR = 0x8F: retardo de nodo de 8 bits (solo MOST25)
  • MPR = 0x90: número de nodos con bypass abierto de 8 bits
  • MDR = 0x91: retardo máximo de 8 bits (solo MOST25)
  • SBC = 0x96: control de ancho de banda síncrono de 8 bits (SBC)
•
Ancho de banda síncrono = 4 x SBC
•
Valores máximos para SBC:
•
MOST25: 15 (= 60 Bytes)
•
MOST50: 29 (= 116 Bytes)
•
MOST150: 93 (= 372 Bytes)
  • APA = 0xE8: dirección de paquete alternativo de 16 bits (solo MOST25)
  • XTIM = 0xBE: tiempo de reintento de transmisión de 8 bits
  • XRTY = 0xBF: número de intentos de envío de 8 bits
  • MacAdr = 0xFE: dirección MAC de 48 bits (EUI-48, conforme al estándar IEEE; solo MOST150)

uint8_t Vector::BLF::MostGenReg::subType {}

solicitud/resultado de lectura/escritura Tipo de operación de un evento de registro.

  • No especificado = 0: no especificado (o HW no admite subtipos)
  • Notificación = 1: notificación de cambio de registro (espontánea)
  • SolicitudLectura = 2: solicitud de operación de lectura de registro
  • SolicitudEscritura = 3: solicitud de operación de escritura de registro
  • ResultadoLectura = 4: resultado de operación de lectura de registro
  • ResultadoEscritura = 5: resultado de operación de escritura de registro
  • LecturaFallida = 6: operación de lectura de registro fallida
  • EscrituraFallida = 7: operación de escritura de registro fallida
