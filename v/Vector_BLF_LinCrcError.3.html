    NAME

    Vector_BLF_LinCrcError - Vector BLF library LIN CRC error handling.

    SYNOPSIS

    This man page describes the error handling functions for LIN CRC errors in the Vector BLF library.

    DESCRIPTION

    The Vector BLF library provides functions to work with BLF log files. This page specifically addresses how LIN CRC errors are handled and reported within the library.

    DETAILED DESCRIPTION

    When processing LIN frames, the BLF library calculates the CRC based on the LIN specification. If the calculated CRC does not match the CRC present in the frame, a CRC error is indicated. The library provides mechanisms to detect, report, and potentially retrieve information about these CRC errors.
