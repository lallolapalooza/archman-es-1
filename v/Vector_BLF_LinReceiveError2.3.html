Descripción detallada

LIN_RCV_ERROR2.

Este evento puede tener una amplia variedad de causas. Un Maestro externo puede causar un evento de error de recepción:

  • transmitiendo un sync break demasiado corto,
  • no devolviendo el valor correcto 0x55 en el campo de sincronización,
  • asignando una paridad incorrecta al identificador de trama. Otras razones:
  • Esclavo transmitiendo un carácter ilegal durante una fase de Bus Idle (por ejemplo, porque no terminó la transmisión lo suficientemente rápido y la suma de verificación de la respuesta se envió durante la fase de Bus Idle),
  • Bit de parada defectuoso (dominante) (es decir, error de trama),
  • El hardware LIN recibe un carácter que es diferente del carácter transmitido durante la transmisión
  • El hardware LIN solo recibe parte de una trama, al inicio de una medición (en un sistema que funciona correctamente).

uint8_t Vector::BLF::LinReceiveError2::stateReason {}

The lower 4 bits indicate the LIN hard-ware state at the time the error has occurred, while the upper 4 bits indicate the reason of the error

Value for the state:

  • 0: Bus idle
  • 1: Waiting for SynchBreak
  • 2: Waiting for SynchField
  • 3: Waiting for frame ID
  • 4-12: Waiting for data byte or checksum byte depending on the frame length. E.g. value 4 for FrameLength=0, value 12 for FrameLength=8
  • 14: Consecutive event (i.e. event resulting from further data interpretation, after already notified error for first offending byte)
  • 15: Not expected event (i.e. not WakeupRequest) during sleep mode. Occurs for LIN hardware in Master mode only

Values for the reason:

  • 0: Timeout
  • 1: Received an unexpected byte violating protocol. In this case, mOffendingByte member contains its value
  • 2: Received a byte with framing error (with dominant stop bit). In this case, mOffendingByte member contains its value
  • 3: Unexpected Break field
  • 4: Unidentified error

uint8_t Vector::BLF::LinReceiveError2::timeoutDuringDlcDetection {}

Flag indicating if the error is a result of an attempt to resolve frame length. Following values are possible:

  • 0: False
  • 1: True
