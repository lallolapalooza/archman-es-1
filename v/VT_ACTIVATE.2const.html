ioctl_vt(2) Manual de llamadas al sistema ioctl_vt(2)

NOMBRE

ioctl_vt - ioctls para terminal de consola y consolas virtuales

SINOPSIS

#include <linux/vt.h>  /* Definición de las constantes VT_* */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones de ioctl(2) específicas de Linux son soportadas para terminales de consola y consolas virtuales.

VT_OPENQRY
Devuelve la primera consola disponible (no abierta). argp apunta a un int que se establece al número de la vt (1 <= *argp <= MAX_NR_CONSOLES).
VT_GETMODE
Obtiene el modo de la vt activa. argp apunta a una

struct vt_mode {
    char  mode;    /* modo de la vt */
    char  waitv;   /* si está establecido, esperar en escrituras si no está activo */
    short relsig;  /* señal a levantar en operación de liberación */
    short acqsig;  /* señal a levantar en adquisición */
    short frsig;   /* no utilizado (establecido a 0) */
};

que se establece al modo de la vt activa. mode se establece a uno de estos valores:
VT_AUTO cambio automático de vt
VT_PROCESS el proceso controla el cambio
VT_ACKACQ acusa recibo del cambio
VT_SETMODE
Establece el modo de la vt activa. argp apunta a un struct vt_mode.
VT_GETSTATE
Obtiene información del estado global de la vt. argp apunta a una

struct vt_stat {
    unsigned short v_active;  /* vt activa */
    unsigned short v_signal;  /* señal a enviar */
    unsigned short v_state;   /* máscara de bits de la vt */
};

Para cada vt en uso, el bit correspondiente en el miembro v_state está establecido. (Linux 1.0 a Linux 1.1.92.)
VT_RELDISP
Libera una pantalla.
VT_ACTIVATE
Cambia a la vt argp (1 <= argp <= MAX_NR_CONSOLES).
VT_WAITACTIVE
Espera hasta que la vt argp haya sido activada.
VT_DISALLOCATE
Desasigna la memoria asociada con la vt argp. (Desde Linux 1.1.54.)
VT_RESIZE
Establece la idea del kernel sobre el tamaño de la pantalla. argp apunta a una

struct vt_sizes {
    unsigned short v_rows;       /* # filas */
    unsigned short v_cols;       /* # columnas */
    unsigned short v_scrollsize; /* ya no se usa */
};

Tenga en cuenta que esto no cambia el modo de video. Ver resizecons(8). (Desde Linux 1.1.54.)
VT_RESIZEX
Establece la idea del kernel sobre varios parámetros de pantalla. argp apunta a una

struct vt_consize {
    unsigned short v_rows;  /* número de filas */
    unsigned short v_cols;  /* número de columnas */
    unsigned short v_vlin;  /* número de filas de píxeles
                               en la pantalla */
    unsigned short v_clin;  /* número de filas de píxeles
                               por carácter */
    unsigned short v_vcol;  /* número de columnas de píxeles
                               en la pantalla */
    unsigned short v_ccol;  /* número de columnas de píxeles
                               por carácter */
};

Cualquier parámetro puede establecerse a cero, indicando "sin cambios", pero si se establecen múltiples parámetros, deben ser coherentes entre sí. Tenga en cuenta que esto no cambia el modo de video. Ver resizecons(8). (Desde Linux 1.3.3.)
VT_GETCONSIZECSRPOS
Obtiene el tamaño de la consola y la posición del cursor. argp apunta a una

struct vt_consizecsrpos {
    __u16 con_rows;  /* número de filas de la consola */
    __u16 con_cols;  /* número de columnas de la consola */
    __u16 csr_row;   /* fila actual del cursor */
    __u16 csr_col;   /* columna actual del cursor */
};

(Desde Linux 6.16.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique lo contrario). En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
argp no es válido.

ESTANDARES

Linux.

VER TAMBIÉN

ioctl(2), ioctl_console(2)
