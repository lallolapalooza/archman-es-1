Documentación de datos miembro

uint32_t Vector::BLF::CanFdErrorFrame64::btrCfgArb {}

Tasa de bits utilizada en la fase de arbitraje. Configuración de temporización de bits CAN-FD para la fase de arbitraje, puede ser 0 si no es soportado por el hardware/driver.

  • Bits 0-7: Frecuencia de cuarzo
  • Bits 8-15: Prescaler
  • Bits 16-23: Ciclos BTL
  • Bits 24-31: Punto de muestreo

uint32_t Vector::BLF::CanFdErrorFrame64::btrCfgData {}

Tasa de bits utilizada en la fase de datos. Configuración de temporización de bits CAN-FD para la fase de arbitraje, puede ser 0 si no es soportado por el hardware/driver. Ver btrCfgArb.

uint8_t Vector::BLF::CanFdErrorFrame64::channel {}

Canal de la aplicación. Canal por el que se envió o recibió el marco.

uint32_t Vector::BLF::CanFdErrorFrame64::crc {}

Suma de verificación CRC del mensaje corrupto.

std::vector<uint8_t> Vector::BLF::CanFdErrorFrame64::data {}

Datos CAN FD. Bytes de datos CAN FD (la longitud real puede ser menor que 64 bytes, según el valor de dlc, por ejemplo, cuando DLC es 12, los datos tienen una longitud de 24).

uint8_t Vector::BLF::CanFdErrorFrame64::dlc {}

DLC de CAN. Código de longitud de datos del mensaje corrupto.

uint8_t Vector::BLF::CanFdErrorFrame64::ecc {}

Contenido del registro de captura de código de error Philips SJA1000, o del registro de error Vector CAN-Core. Ver el campo ecc de CanErrorFrameExt.

uint16_t Vector::BLF::CanFdErrorFrame64::errorCodeExt {}

Banderas de error extendidas. Ver el campo flagsExt de CanErrorFrameExt.

uint16_t Vector::BLF::CanFdErrorFrame64::errorPosition {}

Posición del error como desplazamiento de bits. Posición del bit del marco de error en el mensaje corrupto.

uint8_t Vector::BLF::CanFdErrorFrame64::extDataOffset {}

desplazamiento si se usa extDataOffset

uint16_t Vector::BLF::CanFdErrorFrame64::extFlags {}

Flags específicos de FD. Flags específicos de CAN-FD.

•
Significado del bit 0-3:
•
no utilizado
•
Significado del bit 0-4:
•
0: Error en la fase de arbitraje
•
1: Error en la fase de datos
•
Significado del bit 5:
•
0: ESI es 0
•
1: ESI es 1
•
Significado del bit 6
•
0: BRS es 0
•
1: BRS es 1
•
Significado del bit 7
•
0: EDL es 0
•
1: EDL es 1

uint16_t Vector::BLF::CanFdErrorFrame64::flags {}

Define qué información adicional es válida. Ver campo flags de CanErrorFrameExt.
