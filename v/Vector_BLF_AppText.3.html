uint32_t Vector::BLF::AppText::source {}

fuente del texto Define la fuente/semántica del texto. Actualmente se definen dos valores diferentes:

0: Comentario de medición

  • reservado no se utiliza
  • text contiene un comentario de medición

1: Información del canal de la base de datos

  • reservado contiene información del canal. La siguiente
  • tabla muestra cómo se utilizan los 4 bytes:
•
Bits 0-7: Versión de los datos
•
Bits 8-15: Número de canal
•
Bits 15-23: Tipo de bus del canal. Uno de los siguientes valores:
•
1: BL_BUSTYPE_CAN
•
5: BL_BUSTYPE_LIN
•
6: BL_BUSTYPE_MOST
•
7: BL_BUSTYPE_FLEXRAY
•
9: BL_BUSTYPE_J1708
•
10: BL_BUSTYPE_ETHERNET
•
13: BL_BUSTYPE_WLAN
•
14: BL_BUSTYPE_AFDX
•
Bit 24: Bandera que determina si el canal es un canal CAN- FD
•
Bits 25-31: Sin usar por el momento
•
text contiene información de la base de datos para el canal específico. Cada base de datos se define por la ruta de la base de datos y el nombre del clúster (si está disponible). Las bases de datos individuales y el nombre del clúster están separados por un punto y coma. Ejemplo: <Path1>;<ClusterName1>;<Path2>;<ClusterName2>;... Si para una base de datos no hay nombre de clúster disponible, se escribe una cadena vacía como nombre de clúster.
