uint8_t Vector::BLF::Most50Message::ackNack {}

código de acuse de recibo AckNack contiene el estado de transmisión de un mensaje de control (ver Registro de Estado de Transmisión de OS8104 para MOST25).

•
Bit 0: Significado:
•
1: sin respuesta (NoResp) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 1: Significado:
•
1: recepción válida (Valid) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 2: Significado:
•
1: Error CRC (CRCError) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 3: Significado:
•
1: búfer de recepción lleno (RxBufFull) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 4: Significado:
•
1: reconocido (Ack) Restricción:
•
solo para Dir = Tx o mensajes espía (siempre establecido en 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: reconocimiento negativo (NAck) Restricción:
•
solo para Dir = Tx o mensajes espía

uint8_t Vector::BLF::Most50Message::state {}

estado de transmisión Estados de transmisión de mensajes y paquetes MOST50/150.

•
Bit 0: Significado:
•
0: bus inactivo
•
1: bus activo Restricción:
•
solo para Dir = Rx o mTransferType = Spy
•
Bit 4: Significado:
•
1: reconocido (Ack) Restricción
•
solo para mTransferType = Node y Dir = Tx (siempre establecido en 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: no reconocido (NAck) Restricción:
•
solo para Dir = Tx
•
Bit 6: Significado: Resultado del envío:
•
0: Error de transmisión (TxF)
•
1: OK Restricción:
•
solo para Dir = Tx
•
solo para mTransferType = Node

uint8_t Vector::BLF::Most50Message::transferType {}

Tipo de transferencia. Los eventos similares a mensajes se pueden registrar a través del chip transceptor MOST o a través de un espía de red separado.

  • 1: Nodo El transceptor MOST informó el mensaje (ya sea debido a una recepción exitosa o como reconocimiento de una solicitud de transmisión).
  • 2: Espía El mensaje fue informado por el espía de red. El espía ve todos los mensajes independientemente de la dirección de destino.
