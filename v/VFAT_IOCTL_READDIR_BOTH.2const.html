VFAT_IOCTL_READDIR_BOTH(2const) VFAT_IOCTL_READDIR_BOTH(2const)

NOMBRE

VFAT_IOCTL_READDIR_BOTH, VFAT_IOCTL_READDIR_SHORT - leer nombres de archivo de un directorio en un sistema de archivos FAT

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/msdos_fs.h>  /* Definición de las constantes VFAT_* */
#include <sys/ioctl.h>
int ioctl(int fd, VFAT_IOCTL_READDIR_BOTH,
          struct __fat_dirent entrada[2]);
int ioctl(int fd, VFAT_IOCTL_READDIR_SHORT,
          struct __fat_dirent entrada[2]);

DESCRIPCIÓN

Un archivo o directorio en un sistema de archivos FAT siempre tiene un nombre de archivo corto que consta de hasta 8 letras mayúsculas, opcionalmente seguido de un punto y hasta 3 letras mayúsculas para la extensión del archivo. Si el nombre de archivo real no se ajusta a este esquema, se almacena como un nombre de archivo largo de hasta 255 caracteres UTF-16.

Los nombres de archivo cortos en un directorio se pueden leer con VFAT_IOCTL_READDIR_SHORT. VFAT_IOCTL_READDIR_BOTH lee tanto los nombres de archivo cortos como los largos.

El argumento fd debe ser un descriptor de archivo para un directorio. Es suficiente crear el descriptor de archivo llamando a open(2) con la bandera O_RDONLY. El descriptor de archivo solo se puede usar una vez para iterar sobre las entradas del directorio llamando a ioctl(2) repetidamente.

El argumento entrada es un array de dos elementos de las siguientes estructuras:


struct __fat_dirent {
    long            d_ino;
    __kernel_off_t  d_off;
    uint32_t short  d_reclen;
    char            d_name[256];
};

La primera entrada en el array es para el nombre de archivo corto. La segunda entrada es para el nombre de archivo largo.

Los campos d_ino y d_off se rellenan solo para nombres de archivo largos. El campo d_ino contiene el número de inodo del directorio. El campo d_off contiene el desplazamiento de la entrada del archivo en el directorio. Como estos valores no están disponibles para nombres de archivo cortos, el código del usuario simplemente debe ignorarlos.

El campo d_reclen contiene la longitud del nombre de archivo en el campo d_name. Para mantener la compatibilidad con versiones anteriores, una longitud de 0 para el nombre de archivo corto indica que se ha alcanzado el final del directorio. Sin embargo, el método preferido para detectar el final del directorio es probar el valor de retorno de ioctl(2). Si no existe un nombre de archivo largo, el campo d_reclen se establece en 0 y d_name es una cadena de caracteres de longitud 0 para el nombre de archivo largo.

VALOR DE RETORNO

Un valor de retorno de 1 indica que se ha leído una nueva entrada de directorio y un valor de retorno de 0 indica que se ha alcanzado el final del directorio.

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

ENOENT
fd se refiere a un directorio eliminado, pero aún abierto.
ENOTDIR
fd no se refiere a un directorio.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.0.

EJEMPLOS

El siguiente programa demuestra el uso de ioctl(2) para listar un directorio.

Lo siguiente se grabó al aplicar el programa al directorio /mnt/user:


$ ./fat_dir /mnt/user;
. -> ''
.. -> ''
ALONGF~1.TXT -> 'a long filename.txt'
UPPER.TXT -> ''
LOWER.TXT -> 'lower.txt'

Código fuente del programa

#include <fcntl.h>
#include <linux/msdos_fs.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int                  fd;
    int                  ret;
    struct __fat_dirent  entry[2];
    if (argc != 2) {
        printf("Uso: %s DIRECTORIO\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /*
     * Abrir descriptor de archivo para el directorio.
     */
    fd = open(argv[1], O_RDONLY | O_DIRECTORY);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    for (;;) {
        /*
         * Leer la siguiente entrada del directorio.
         */
        ret = ioctl(fd, VFAT_IOCTL_READDIR_BOTH, entry);
        /*
         * Si ocurre un error, el valor de retorno es -1.
         * Si se ha alcanzado el final de la lista del directorio,
         * el valor de retorno es 0.
         * Para compatibilidad con versiones anteriores, el final de la
         * lista del directorio también se señala por d_reclen == 0.
         */
        if (ret < 1)
            break;
        /*
         * Escribir tanto el nombre corto como el nombre largo.
         */
        printf("%s -> '%s'\n", entry[0].d_name, entry[1].d_name);
    }
    if (ret == -1) {
        perror("VFAT_IOCTL_READDIR_BOTH");
        exit(EXIT_FAILURE);
    }
    /*
     * Cerrar el descriptor de archivo.
     */
    close(fd);
    exit(EXIT_SUCCESS);
}
