Detailed Description

Ethernet Status Information is used to convey information about the state of the Ethernet connection of a ECU.

The information contains:

  • Channel: The CAN channel number of the event.
  • Hardware Channel: The Hardware Channel number of the event.
  • Connector: The connector type of the event.
  • Clock Mode: clock mode of the Ethernet Connection.
  • MDI: MDI setup of the Ethernet Connection.
  • Pairs: The number of pairs used for the Ethernet connection.
  • Link Status: The link status of the Ethernet connection.
