NAME

Vector_BLF_DistributedObjectMember - Represents a member of a distributed object.

SYNOPSIS

#include <vector/blf/distributed_object_member.h>

namespace Vector::BLF {

class DistributedObjectMember : public ObjectHeaderBase {

public:

// Constructors and destructors
DistributedObjectMember ();
DistributedObjectMember (const DistributedObjectMember & _rhs);
virtual ~DistributedObjectMember ();

// Member functions
virtual void read (AbstractFile & is);
virtual void write (AbstractFile & os);

}; // class DistributedObjectMember

} // namespace Vector::BLF

Detailed Description

This class represents a member of a distributed object. It provides functionality to read and write the member data to and from an abstract file stream.
