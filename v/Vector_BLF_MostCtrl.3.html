uint8_t Vector::BLF::MostCtrl::ackNack {}

bits de reconocimiento AckNack contiene el estado de transmisión de un mensaje de control (ver el Registro de Estado de Transmisión de OS8104 para MOST25).

•
Bit 0: Significado:
•
1: sin respuesta (NoResp) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 1: Significado:
•
1: recepción válida (Valid) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 2: Significado:
•
1: Error de CRC (CRCError) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 3: Significado:
•
1: búfer de recepción lleno (RxBufFull) Restricción:
•
solo para Dir = Tx o mensajes espía
•
Bit 4: Significado:
•
1: reconocido (Ack) Restricción:
•
solo para Dir = Tx o mensajes espía (siempre establecido en 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: acuse de recibo negativo (NAck) Restricción:
•
solo para Dir = Tx o mensajes espía

Detailed Description

Control messages MOST25.

  • 0x00: Device (dirección lógica del nodo)
  • 0x10: Posición del nodo
  • 0x20: Difusión
  • 0x30: Difusión grupal
  • 0xFF: Desconocido

Estado de transmisión MOST25. Estado de transmisión de un mensaje de Control MOST25.

•
Bit 0: Significado:
•
0: bus inactivo
•
1: bus activo Restricción:
•
solo para Dir = Rx (MOSTCtrl) o MOSTSpy
•
Bit 1: Significado:
•
1: evento de desbloqueo durante la transmisión (Unl) Restricción:
•
solo para Dir = Rx (MOSTCtrl) o MOSTSpy
•
Bit 4: Significado:
•
1: confirmado (Ack) Restricción:
•
solo para Dir = Tx (siempre establecido en 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: no confirmado (NAck) Restricción:
•
solo para Dir = Tx
•
Bit 6: Significado:
•
Resultado del envío:
•
0: Error de transmisión (TxF)
•
1: OK Restricción:
•
solo para Dir = Tx (MOSTCtrl)
