DOCUMENTACIÓN DE DATOS MIEMBRO

std::array<uint64_t, 9> Vector::BLF::LinDatabyteTimestampEvent::databyteTimestamps {}

Marcas de tiempo de bytes de datos, donde d[0] = FinDeCabecera, d[1]=FinDeByteDeDatos1, ..., d[8]=FinDeByteDeDatos8. Marcas de tiempo de bytes de datos [en nanosegundos].

El índice 0 corresponde al último byte de la cabecera.

Los índices 1-9 corresponden a los bytes de datos de respuesta D1-D8.
