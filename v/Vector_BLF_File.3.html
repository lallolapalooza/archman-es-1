Vector BLF File(3)

Name

Name

Vector BLF File - Read Vector BLF files

Description

Description

The BLF (Binary Logging Format) is a proprietary binary file format used by Vector Informatik GmbH to store CAN logging data. The blf_read library provides functions to read data from BLF files.

This library allows you to access various types of data recorded in BLF files, including CAN messages (standard and extended), CAN FD messages, FlexRay messages, LIN messages, Ethernet frames, and application-specific data.

Options

Options

The library supports various options that can be passed to the reading functions to control the data retrieval process. These options include:

  • Filtering by message ID.
  • Specifying a time range for data retrieval.
  • Selecting specific channels or buses.
  • Extracting specific data fields.

Refer to the library's documentation for a complete list of supported options and their usage.

Return value

Return value

The functions in the blf_read library typically return data structures containing the requested log data. The specific return type depends on the function called and the type of data being retrieved. Error codes are returned in case of issues during file access or data parsing.

Examples

Examples

#include <blf_read.h>
#include <stdio.h>

int main() {
    blf_file_handle_t* handle;
    blf_message_t message;
    int ret;

    // Open a BLF file
    ret = blf_open("log.blf", &handle);
    if (ret != BLF_SUCCESS) {
        fprintf(stderr, "Error opening BLF file: %d\n", ret);
        return 1;
    }

    // Read messages one by one
    while ((ret = blf_read_next_message(handle, &message)) == BLF_SUCCESS) {
        if (message.type == BLF_MSG_TYPE_CAN) {
            printf("Timestamp: %llu, ID: 0x%X, DLC: %d, Data: ...\n",
                   message.timestamp, message.data.can.id, message.data.can.dlc);
            // Process message data
        }
    }

    if (ret != BLF_END_OF_FILE) {
        fprintf(stderr, "Error reading message: %d\n", ret);
    }

    // Close the file
    blf_close(handle);

    return 0;
}
