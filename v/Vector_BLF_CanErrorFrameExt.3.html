uint32_t Vector::BLF::CanErrorFrameExt::flags {}

flags extendidos del frame de error CAN Define qué información adicional es válida. Los siguientes valores son posibles:

  • 1: ECC SJA 1000 es válido (miembro ecc)
  • 2: Código de Error de Vector CAN Core es válido.
  • 4: Posición de Error de Vector CAN Core
  • 8: Duración del Frame en ns de Vector CAN Core

uint16_t Vector::BLF::CanErrorFrameExt::flagsExt {}

flags de error extendidos Flags de error extendidos.
