NOMBRE

VendorShell — La clase de widget VendorShell

SINOPSIS

#include <Xm/Xm.h>
#include <X11/Shell.h>

DESCRIPCIÓN

VendorShell es una clase de widget de Motif utilizada como superclase de soporte para todas las clases de shell que son visibles para el gestor de ventanas y que no están redirigidas. Contiene recursos que describen el aspecto y la sensación específicos de MWM. También gestiona la comunicación específica de MWM necesaria para todas las subclases de VendorShell. Consulte la página de referencia de mwm para obtener más información.

También es responsable de gestionar las descripciones emergentes (toolTips). Todas las subclases de XmPrimitive y XmGadget tienen un recurso XmNtoolTipString. Si XmNtoolTipEnable es True, y el puntero entra en un Primitive o Gadget que tiene la navegación habilitada, y el XmNtoolTipString no es NULL, el XmNtoolTipString se mostrará de acuerdo con los recursos de VendorShell para controlar las descripciones emergentes. VendorShell muestra el XmNtoolTipString en un XmLabel que es hijo de un transientShell. El nombre del transientShell es TipShell, y el nombre del XmLabel es TipLabel. La apariencia de la descripción emergente se puede controlar especificando recursos en estos widgets.

Si una aplicación utiliza los recursos XmNmwmDecorations, XmNmwmFunctions o XmNmwmInputMode, debe incluir el archivo Xm/MwmUtil.h.

Establecer XmNheight, XmNwidth o XmNborderWidth para un VendorShell o su hijo gestionado suele establecer ese recurso en el mismo valor en el padre y en el hijo. Cuando existe un método de entrada fuera del punto, la altura y el ancho del shell pueden ser mayores que los del hijo gestionado para acomodar el método de entrada. En este caso, establecer XmNheight o XmNwidth para el shell no establece necesariamente ese recurso en el mismo valor en el hijo gestionado, y establecer XmNheight o XmNwidth para el hijo no establece necesariamente ese recurso en el mismo valor en el shell.

Para el hijo gestionado de un VendorShell, independientemente del valor de XmNallowShellResize del shell, establecer XmNx o XmNy establece el recurso correspondiente del padre pero no cambia la posición del hijo en relación con el padre. XtGetValues para el XmNx o XmNy del hijo devuelve el valor del recurso correspondiente en el padre. Las coordenadas x e y de la esquina exterior superior izquierda del hijo en relación con la esquina interior superior izquierda del padre son ambas 0 (cero) menos el valor de XmNborderWidth.

Tenga en cuenta que el Manual de convenciones de comunicación entre clientes (ICCCM) permite que un gestor de ventanas cambie o controle el ancho del borde de una ventana de nivel superior reparentada.

VendorShell contiene el trait XmQTspecifyRenderTable.

Clases

VendorShell hereda el comportamiento, los recursos y los traits de las clases Core, Composite, Shell y WMShell.

El puntero de clase es vendorShellWidgetClass.

El nombre de la clase es VendorShell.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un subrecurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un subrecurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el subrecurso dado se puede establecer en el momento de la creación (C), establecer mediante XtSetValues (S), recuperar mediante XtGetValues (G), o no es aplicable (N/A).

XmNaudibleWarning
Determina si una acción activa su señal acústica asociada. Los valores posibles son XmBELL y XmNONE.
XmNbuttonFontList
Especifica la lista de fuentes utilizada para los descendientes de los botones. Ver el recurso XmNbuttonRenderTable.
XmNbuttonRenderTable
Especifica la tabla de renderizado utilizada para los descendientes de los botones de VendorShell. Si este valor es NULL al inicializar y si el valor de XmNdefaultFontList no es NULL, XmNbuttonRenderTable se inicializa con el valor de XmNdefaultFontList. Si el valor de XmNdefaultFontList es NULL, la jerarquía padre del widget se recorre en busca de un ancestro que contenga el rasgo XmQTspecifyRenderTable. Si se encuentra dicho ancestro, XmNbuttonRenderTable se inicializa con el valor XmNBUTTON_RENDER_TABLE del widget ancestro. Si no se encuentra ningún ancestro, el valor predeterminado depende de la implementación. Consulte XmRenderTable(3) para obtener más información sobre la creación y estructura de una tabla de renderizado.
XmNdefaultFontList
Especifica una lista de fuentes predeterminada para los descendientes de VendorShell. Este recurso está obsoleto y existe por compatibilidad con versiones anteriores. Ha sido reemplazado por XmNbuttonFontList, XmNlabelFontList y XmNtextFontList.
XmNdeleteResponse
Determina qué acción toma el shell en respuesta a un mensaje WM_DELETE_WINDOW. La configuración puede ser uno de los tres valores: XmDESTROY, XmUNMAP y XmDO_NOTHING. El recurso se examina y se toma la acción apropiada después de que la lista de callbacks de WM_DELETE_WINDOW (si existe) registrada con el gestor de Protocolo haya sido llamada.
XmNinputMethod
Especifica la cadena que establece el modificador de localización para el método de entrada. Cuando se llama a XtGetValues en este recurso, el valor devuelto es un puntero al valor real del recurso y no debe liberarse.
XmNinputPolicy
Especifica la política a seguir para crear un Contexto de Entrada (IC) para este shell. Este recurso puede tener los siguientes valores:
XmPER_SHELL
Especifica que solo se crea un XIC por shell.
XmPER_WIDGET
Especifica que se crea un XIC para cada widget.
XmNkeyboardFocusPolicy
Determina la asignación del foco del teclado dentro de la jerarquía de widgets arraigada en este shell. El foco del teclado X debe dirigirse a algún lugar de la jerarquía para que esta gestión de foco del lado del cliente tenga efecto. Los valores posibles son XmEXPLICIT, que especifica una política de clic para escribir, y XmPOINTER, que especifica una política controlada por el puntero.
XmNlabelFontList
Especifica la lista de fuentes utilizada para los descendientes de etiquetas. Consulte el recurso XmNlabelRenderTable.
XmNlabelRenderTable
Especifica la lista de fuentes utilizada para los descendientes de etiquetas de VendorShell (Etiquetas y LabelGadgets). Si este valor es NULL al inicializarse y si el valor de XmNdefaultFontList no es NULL, XmNlabelFontList se inicializa con el valor de XmNdefaultFontList. Si el valor de XmNdefaultFontList es NULL, se busca en la jerarquía padre del widget un ancestro que tenga el rasgo XmQTspecifyRenderTable. Si se encuentra dicho ancestro, XmNlabelRenderTable se inicializa con la XmLABEL_RENDER_TABLE del widget ancestro. Si no se encuentra ningún ancestro de este tipo, el valor predeterminado depende de la implementación. Consulte XmRenderTable(3) para obtener más información sobre la creación y estructura de una tabla de renderizado.
XmNlayoutDirection
Especifica la dirección en la que se deben colocar los subwidgets, los hijos de un widget, u otros componentes visuales. Esta política se aplicará como la política de diseño predeterminada para todos los descendientes de este VendorShell.
XmNmwmDecorations
Especifica las banderas de decoración (decoraciones específicas para agregar o eliminar del marco del gestor de ventanas) para la propiedad _MOTIF_WM_HINTS. Si se especifican banderas de decoración por la propiedad _MOTIF_WM_HINTS, solo se muestran las decoraciones indicadas tanto por esa propiedad como por los recursos clientDecoration y transientDecoration de MWM. Si no se especifican banderas de decoración por la propiedad _MOTIF_WM_HINTS, se muestran las decoraciones indicadas por los recursos clientDecoration y transientDecoration de MWM. El valor predeterminado para el recurso XmNmwmDecorations es no especificar ninguna bandera de decoración para la propiedad _MOTIF_WM_HINTS.
El valor de este recurso es el OR inclusivo a nivel de bits de una o más banderas. Las posibles constantes de bandera, definidas en el archivo de inclusión Xm/MwmUtil.h, son
MWM_DECOR_ALL
Todas las decoraciones, *excepto* aquellas especificadas por otras banderas que estén activadas.
MWM_DECOR_BORDER
Borde de la ventana del cliente.
MWM_DECOR_RESIZEH
Manijas del marco de redimensionamiento.
MWM_DECOR_TITLE
Barra de título.
MWM_DECOR_MENU
Botón del menú de la ventana.
MWM_DECOR_MINIMIZE
Botón para minimizar la ventana.
MWM_DECOR_MAXIMIZE
Botón para maximizar la ventana.
XmNmwmFunctions
Especifica las banderas de función (funciones específicas del gestor de ventanas para aplicar o no aplicar a la ventana del cliente) para la propiedad _MOTIF_WM_HINTS. Si se especifican banderas de función por la propiedad _MOTIF_WM_HINTS, solo se aplican las funciones indicadas tanto por esa propiedad como por los recursos clientFunctions y transientFunctions de MWM. Si no se especifican banderas de función por la propiedad _MOTIF_WM_HINTS, se aplican las funciones indicadas por los recursos clientFunctions y transientFunctions de MWM. El valor predeterminado para el recurso XmNmwmFunctions es no especificar ninguna bandera de función para la propiedad _MOTIF_WM_HINTS.
El valor de este recurso es el OR inclusivo a nivel de bits de una o más banderas. Las posibles constantes de bandera, definidas en el archivo de inclusión Xm/MwmUtil.h, son
MWM_FUNC_ALL
Todas las funciones, *excepto* aquellas especificadas por otras banderas que estén activadas.
MWM_FUNC_RESIZE

f.move
MWM_FUNC_MINIMIZE
f.minimize
MWM_FUNC_MAXIMIZE
f.maximize
MWM_FUNC_CLOSE
f.kill
XmNmwmInputMode
Especifica la bandera del modo de entrada (restricciones de entrada modales de la aplicación o del sistema) para la propiedad _MOTIF_WM_HINTS. Si no se especifica ninguna bandera de modo de entrada por la propiedad _MOTIF_WM_HINTS, no se aplican restricciones de entrada y la entrada va a cualquier ventana. El valor predeterminado para el recurso XmNmwmInputMode es no especificar ninguna bandera de modo de entrada para la propiedad _MOTIF_WM_HINTS.
Una aplicación que establece restricciones de entrada en un diálogo suele utilizar el recurso XmNdialogStyle del BulletinBoard en lugar del recurso XmNmwmInputMode del DialogShell padre.
Los valores posibles para este recurso, definidos en el archivo de inclusión Xm/MwmUtil.h, son
MWM_INPUT_MODELESS
La entrada va a cualquier ventana.
MWM_INPUT_PRIMARY_APPLICATION_MODAL
La entrada no va a los ancestros de esta ventana.
MWM_INPUT_SYSTEM_MODAL
La entrada solo va a esta ventana.
MWM_INPUT_FULL_APPLICATION_MODAL
La entrada no va a otras ventanas de esta aplicación.
XmNmwmMenu
Especifica los elementos del menú que el gestor de ventanas de Motif debe agregar al final del menú de la ventana. La cadena contiene una lista de elementos separados por 0fP con el siguiente formato:
etiqueta [mnemotécnico] [acelerador] función
Si se especifica más de un elemento, los elementos deben estar separados por un carácter de nueva línea.
Cuando se llama a XtGetValues en este recurso, el valor devuelto es un puntero al valor real del recurso y no debe liberarse.
XmNpreeditType
Especifica el estilo o los estilos del método de entrada disponibles para el gestor de entrada. El recurso puede ser una lista separada por comas de los siguientes valores:
Valores de Preedición
Valor de Preedición Estilo XIM

OverTheSpot XIMPreeditPosition
OnTheSpot XIMPreeditCallbacks

XmNshellUnitType
Este recurso está obsoleto y solo se incluye por compatibilidad con versiones anteriores de Motif. Utilice el recurso XmNunitType en su lugar.
XmNtextFontList
Especifica la lista de fuentes utilizada para los descendientes de texto. Consulte el recurso XmNtextRenderTable.
XmNtextRenderTable
Especifica la tabla de renderizado utilizada para los descendientes de Texto y Lista de VendorShell. Si este valor es NULL al inicializarse y si el valor de XmNdefaultFontList no es NULL, XmNtextRenderTable se inicializa con el valor de XmNdefaultFontList. Si el valor de XmNdefaultFontList es NULL, se busca en la jerarquía padre del widget un ancestro que tenga el rasgo XmQTspecifyRenderTable.
. Si se encuentra dicho ancestro, XmNtextRenderTable se inicializa al valor XmTEXT_RENDER_TABLE del widget ancestro. Si no se encuentra ningún ancestro, el valor predeterminado depende de la implementación. Consulte XmRenderTable(3) para obtener más información sobre la creación y la estructura de una tabla de renderizado.
XmNtoolTipEnable
Especifica si las tooltips están habilitadas o no para este shell.
XmNtoolTipPostDelay
Especifica el tiempo, en milisegundos, que se debe esperar después de que el puntero entre en un widget antes de mostrar la tooltip asociada con este widget.
XmNtoolTipPostDuration
Especifica el tiempo, en milisegundos, que se muestra la tooltip. Un valor de 0 mostrará la dica indefinidamente.
XmNunitType
Proporciona el soporte básico para la independencia de resolución. Define el tipo de unidades que utiliza un widget con los recursos de dimensionamiento y posicionamiento. El recurso tiene un tipo de unidad predeterminado de XmPIXELS.
El tipo de unidad también se puede especificar en los archivos de recursos, con el siguiente formato:
<valor flotante><unidad>
donde:
unidad
es <" ", píxeles, pulgadas, centímetros, milímetros, puntos, unidades de fuente>
píxeles
es <pix, pixel, píxeles>
pulgadas
es <in, inch, pulgadas>
centímetro
es <cm, centímetro, centímetros>
milímetros
es <mm, milímetro, milímetros>
puntos
es <pt, point, puntos>
unidades de fuente
es <fu, font_unit, font_units>
flotante
es {"+"|"-"}{{<"0"-"9">*}.}<"0"-"9">*
Tenga en cuenta que el tipo Dimension siempre debe ser positivo.
Por ejemplo,
xmfonts*XmMainWindow.height: 10.4cm
*PostIn.width: 3inches
XmNunitType puede tener los siguientes valores:
XmPIXELS
Todos los valores proporcionados al widget se tratan como valores normales de píxeles.
XmMILLIMETERS
Todos los valores proporcionados al widget se tratan como valores normales de milímetros.
Xm100TH_MILLIMETERS
Todos los valores proporcionados al widget se tratan como 1/100 de un milímetro.
XmCENTIMETERS
Todos los valores proporcionados al widget se tratan como valores normales de centímetros.
XmINCHES
Todos los valores proporcionados al widget se tratan como valores normales de pulgadas.
Xm1000TH_INCHES
Todos los valores proporcionados al widget se tratan como 1/1000 de pulgada.
XmPOINTS
Todos los valores proporcionados al widget se tratan como valores normales de puntos. Un punto es una unidad utilizada en aplicaciones de procesamiento de texto y se define como 1/72 de pulgada.
Xm100TH_POINTS
Todos los valores proporcionados al widget se tratan como 1/100 de punto. Un punto es una unidad utilizada en aplicaciones de procesamiento de texto y se define como 1/72 de pulgada.
XmFONT_UNITS
Todos los valores proporcionados al widget se tratan como unidades de fuente normales. Una unidad de fuente tiene componentes horizontal y vertical. Estos son los valores de los recursos de pantalla de Xm XmNhorizontalFontUnit y XmNverticalFontUnit.
Xm100TH_FONT_UNITS
Todos los valores proporcionados al widget se tratan como 1/100 de unidad de fuente. Una unidad de fuente tiene componentes horizontal y vertical. Estos son los valores de los recursos de pantalla de XmScreen XmNhorizontalFontUnit y XmNverticalFontUnit.
Para obtener más información sobre las unidades, consulte la página de referencia de XmConvertUnits.
XmNuseAsyncGeometry
Especifica si el gestor de geometría debe esperar la confirmación de una solicitud de geometría al gestor de ventanas. Cuando el valor de este recurso es True, el gestor de geometría fuerza XmNwaitForWm a False y XmNwmTimeout a 0, y se basa en notificaciones asíncronas. Cuando el valor de este recurso es False, XmNwaitForWm y XmNwmTimeout no se ven afectados. El valor predeterminado es False.

NAME

VendorShell - Vendorshell widget class

SYNOPSIS

#include <X11/Shell.h>

VendorShell widget creation functions, callbacks, resources, and subclassing information.

DESCRIPTION

The VendorShell widget is the superclass for all vendor-specific shell widgets. It is a subclass of Core and Shell.

A vendor-specific shell widget defines a subclass of the Shell widget that is intended for use by a specific widget vendor. It is expected that the vendor-specific shell widget will contain resources that are specific to that vendor. Currently, there is only one vendor-specific shell widget, XmVendorShell, which is used by the Motif widget set.

The VendorShell widget defines no new callbacks or actions. Its primary purpose is to provide a common superclass for vendor-specific shell widgets.

The resources defined by the VendorShell widget are:
XmNsensitive XmCSensitive Boolean True CSG
XmNtranslations XmCTranslations XtTranslations dynamic CSG
XmNwidth XmCWidth Dimension dynamic CSG
XmNx XmCPosition Position 0 CSG
XmNy XmCPosition Position 0 CSG
