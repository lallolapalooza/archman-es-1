ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen_number
Especifica el número de pantalla apropiado en el servidor anfitrión.
count_return
Devuelve el número de profundidades.

DESCRIPCIÓN

El macro AllPlanes devuelve un valor con todos los bits establecidos a 1 adecuado para su uso en un argumento de plano para un procedimiento.

El macro BlackPixel devuelve el valor del píxel negro para la pantalla especificada.

El macro WhitePixel devuelve el valor del píxel blanco para la pantalla especificada.

El macro ConnectionNumber devuelve un número de conexión para la pantalla especificada.

El macro DefaultColormap devuelve el ID del mapa de color predeterminado para la asignación en la pantalla especificada.

El macro DefaultDepth devuelve la profundidad (número de planos) de la ventana raíz predeterminada para la pantalla especificada.

La función XListDepths devuelve la matriz de profundidades que están disponibles en la pantalla especificada. Si screen_number es válido y se puede asignar suficiente memoria para la matriz, XListDepths establece count_return al número de profundidades disponibles. De lo contrario, no establece count_return y devuelve NULL. Para liberar la memoria asignada para la matriz de profundidades, use XFree.

El macro DefaultGC devuelve el GC predeterminado para la ventana raíz de la pantalla especificada.

El macro DefaultRootWindow devuelve la ventana raíz de la pantalla predeterminada.

El macro DefaultScreenOfDisplay devuelve la pantalla predeterminada de la pantalla especificada.

El macro DefaultScreen devuelve el número de pantalla predeterminado referenciado en la rutina XOpenDisplay.

El macro DefaultVisual devuelve el tipo visual predeterminado para la pantalla especificada.

El macro DisplayCells devuelve el número de entradas en el mapa de color predeterminado.

El macro DisplayPlanes devuelve la profundidad de la ventana raíz de la pantalla especificada.

El macro DisplayString devuelve la cadena que se pasó a XOpenDisplay cuando se abrió la pantalla actual.

La función XMaxRequestSize devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) admitido por el servidor sin utilizar una codificación de protocolo de longitud extendida. Las solicitudes de protocolo individuales al servidor no pueden ser mayores que este tamaño a menos que el servidor admita una codificación de protocolo de longitud extendida. El protocolo garantiza que el tamaño no sea inferior a 4096 unidades (16384 bytes). Xlib divide automáticamente los datos en varias solicitudes de protocolo según sea necesario para las siguientes funciones: XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles y XPutImage.

La función XExtendedMaxRequestSize devuelve cero si la pantalla especificada no admite una codificación de protocolo de longitud extendida; de lo contrario, devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) admitido por el servidor utilizando la codificación de longitud extendida. Las funciones Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles y XSetRegion utilizarán la codificación de longitud extendida según sea necesario, si es compatible con el servidor. El uso de la codificación de longitud extendida en otras funciones Xlib (por ejemplo, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) está permitido pero no es obligatorio; una implementación de Xlib puede optar por dividir los datos en múltiples solicitudes más pequeñas.

El macro LastKnownRequestProcessed extrae el número de serie completo de la última solicitud que Xlib sabe que ha sido procesada por el servidor X.

El macro NextRequest extrae el número de serie completo que se utilizará para la siguiente solicitud.

El macro ProtocolVersion devuelve el número de versión principal (11) del protocolo X asociado con la pantalla conectada.

El macro ProtocolRevision devuelve el número de revisión del protocolo secundario del servidor X.

El macro QLength devuelve la longitud de la cola de eventos para la pantalla conectada.

El macro RootWindow devuelve la ventana raíz.

El macro ScreenCount devuelve el número de pantallas disponibles.

El macro ScreenOfDisplay devuelve un puntero a la pantalla de la pantalla especificada.

El macro ServerVendor devuelve un puntero a una cadena terminada en nulo que proporciona alguna identificación del propietario de la implementación del servidor X.

El macro VendorRelease devuelve un número relacionado con una versión del proveedor del servidor X.
