NAME

Vector_BLF_EthernetRxError - Structure representing a BLF Ethernet Rx Error message

SYNOPSIS

struct Vector_BLF_EthernetRxError { ... };

Detailed Description

This structure is used to represent an Ethernet Rx Error message within the Vector BLF file format. It contains fields that describe the nature of the Ethernet reception error.

Member Enumeration Documentation

No enumerations are documented for this structure.
