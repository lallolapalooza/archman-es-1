ioctl_vt(2) Manual de llamadas al sistema ioctl_vt(2)

NOMBRE

ioctl_vt - ioctls para terminales de consola y consolas virtuales

SINOPSIS

#include <linux/vt.h>  /* Definición de las constantes VT_* */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones ioctl(2) específicas de Linux son compatibles con terminales de consola y consolas virtuales.

VT_OPENQRY
Devuelve la primera consola disponible (no abierta). argp apunta a un int que se establece al número de la vt (1 <= *argp <= MAX_NR_CONSOLES).
VT_GETMODE
Obtiene el modo de la vt activa. argp apunta a una

struct vt_mode {
    char  mode;    /* modo vt */
    char  waitv;   /* si está establecido, esperar en las escrituras si no está activo */
    short relsig;  /* señal a elevar en la operación de liberación */
    short acqsig;  /* señal a elevar en la adquisición */
    short frsig;   /* no utilizado (establecer a 0) */
};

que se establece al modo de la vt activa. mode se establece a uno de estos valores:
VT_AUTO conmutación automática de vt
VT_PROCESS el proceso controla la conmutación
VT_ACKACQ confirmar conmutación
VT_SETMODE
Establece el modo de la vt activa. argp apunta a una struct vt_mode.
VT_GETSTATE
Obtiene información global del estado de la vt. argp apunta a una

struct vt_stat {
    unsigned short v_active;  /* vt activa */
    unsigned short v_signal;  /* señal a enviar */
    unsigned short v_state;   /* máscara de bits de vt */
};

Para cada vt en uso, se establece el bit correspondiente en el miembro v_state. (Linux 1.0 hasta Linux 1.1.92.)
VT_RELDISP
Liberar una pantalla.
VT_ACTIVATE
Cambiar a la vt argp (1 <= argp <= MAX_NR_CONSOLES).
VT_WAITACTIVE
Esperar hasta que la vt argp se haya activado.
VT_DISALLOCATE
Desasigna la memoria asociada con la vt argp. (Desde Linux 1.1.54.)
VT_RESIZE
Establece la idea del kernel sobre el tamaño de la pantalla. argp apunta a una

struct vt_sizes {
    unsigned short v_rows;       /* # filas */
    unsigned short v_cols;       /* # columnas */
    unsigned short v_scrollsize; /* ya no se usa */
};

Tenga en cuenta que esto no cambia el modo de video. Consulte resizecons(8). (Desde Linux 1.1.54.)
VT_RESIZEX
Establece la idea del kernel sobre varios parámetros de pantalla. argp apunta a una

struct vt_consize {
    unsigned short v_rows;  /* número de filas */
    unsigned short v_cols;  /* número de columnas */
    unsigned short v_vlin;  /* número de filas de píxeles
                               en pantalla */
    unsigned short v_clin;  /* número de filas de píxeles
                               por carácter */
    unsigned short v_vcol;  /* número de columnas de píxeles
                               en pantalla */
    unsigned short v_ccol;  /* número de columnas de píxeles
                               por carácter */
};

Cualquier parámetro puede establecerse a cero, indicando "sin cambios", pero si se establecen varios parámetros, deben ser coherentes entre sí. Tenga en cuenta que esto no cambia el modo de video. Consulte resizecons(8). (Desde Linux 1.3.3.)
VT_GETCONSIZECSRPOS
Obtiene el tamaño de la consola y la posición del cursor. argp apunta a una

struct vt_consizecsrpos {
    __u16 con_rows;  /* número de filas de la consola */
    __u16 con_cols;  /* número de columnas de la consola */
    __u16 csr_row;   /* fila actual del cursor */
    __u16 csr_col;   /* columna actual del cursor */
};

(Desde Linux 6.16.)

VALOR DEVUELTO

En caso de éxito, se devuelve 0 (excepto donde se indique). En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
argp es inválido.

ESTÁNDARES

Linux.

VER TAMBIÉN

ioctl(2), ioctl_console(2)
