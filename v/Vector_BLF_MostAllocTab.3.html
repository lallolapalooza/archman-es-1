Tabla de Asignación

La etiqueta de una conexión síncrona se puede distribuir en varios bytes en la Tabla de Asignación.

Cada byte en mTableData contiene un valor que especifica el número de identificación de la etiqueta a la que pertenece. Si el dispositivo es un maestro de temporización, el bit más significativo del valor del byte se utiliza para indicar si la etiqueta está en uso o no; de lo contrario, el bit más significativo debe ignorarse. El número de etiqueta, por lo tanto, se puede determinar por el valor del byte & 0x7F. Si el número de etiqueta resultante es 0x70, el byte no se utiliza para ninguna etiqueta.
