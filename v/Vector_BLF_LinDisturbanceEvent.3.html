Descripción Detallada

Esta clase se utiliza para almacenar y gestionar información relacionada con eventos de perturbación lineal dentro de un archivo BLF (Bus Logging Format). Permite representar las características de dichas perturbaciones, como su tiempo de inicio, duración, amplitud y frecuencia.
