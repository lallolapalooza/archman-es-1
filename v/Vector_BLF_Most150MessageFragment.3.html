DESCRIPCION DETALLADA

MOST_150_MESSAGE_FRAGMENT.

Fragmento de mensaje del canal de control MOST50 o MOST150 transmitido parcialmente. Los fragmentos se reportan desde un espía de red si la transmision del mensaje esta corrompida o terminada.

uint32_t Vector::BLF::Most150MessageFragment::dataLenAnnounced {}

longitud de datos de usuario anunciada al inicio de la transmisión Longitud de datos de usuario anunciada al inicio de la transmisión. En algunos casos (por ejemplo, envío a una dirección de destino no válida, búfer de recepción lleno del dispositivo de destino) la transmisión se interrumpe antes de que se envíen todos los bytes de datos. Entonces el número contado de bytes en el bus es menor que la longitud de datos anunciada (dataLen < dataLenAnnonced). Debido a errores de bit raros y muy específicos (degradación del byte de terminación final) dataLen también puede ser mayor que dataLenAnnonced.

uint32_t Vector::BLF::Most150MessageFragment::validMask {}

máscara de bits que indica qué miembros tienen datos válidos Si un bit en la máscara está establecido, el campo de datos correspondiente se ha visto en el bus.

  • Bit 0: 0x00000001: dataLenAnnounced
  • Bit 1: 0x00000002: sourceAdr
  • Bit 2: 0x00000004: destAdr
  • Bit 3: 0x00000008: ackNack
  • Bit 4: 0x00000010: pAck
  • Bit 5: 0x00000020: pIndex
  • Bit 6: 0x00000040: piority
  • Bit 7: 0x00000080: crc
  • Bit 8: 0x00000100: cAck
  • Bit 9: 0x00000200: sourceMacAdr
  • Bit 10: 0x00000400: destMacAdr
  • Bit 31: 0x80000000: 0: fragmento MOST150; 1: fragmento MOST50
