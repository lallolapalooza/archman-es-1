Descripción detallada

LIN_RCV_ERROR.

Obsoleto

Este evento puede tener una gran variedad de causas.

Un Maestro externo puede causar un evento de error de recepción:

  • transmitiendo un break demasiado corto,
  • no devolviendo el valor correcto 0x55 en el campo de sincronización,
  • asignando una paridad incorrecta al identificador del frame. Otras razones:
  • Un esclavo transmitiendo un carácter ilegal durante una fase de Bus Idle (ej. porque no terminó la transmisión lo suficientemente rápido y el byte de checksum de la respuesta se envió durante la fase de Bus Idle),
  • Bit de parada defectuoso (dominante) (es decir, error de framing),
  • El hardware LIN recibe un carácter que es diferente del carácter enviado durante la transmisión
  • El hardware LIN solo recibe parte de un frame, al inicio de una medición (en un sistema que funciona correctamente).

uint8_t Vector::BLF::LinReceiveError::stateReason {}

Los 4 bits inferiores indican el estado del hardware LIN en el momento en que ocurrió el error, mientras que los 4 bits superiores indican la razón del error

Valor para el estado:

  • 0: Bus inactivo
  • 1: Esperando SynchBreak
  • 2: Esperando SynchField
  • 3: Esperando ID del frame
  • 4-12: Esperando byte de datos o byte de checksum dependiendo de la longitud del frame. Ej. valor 4 para FrameLength=0, valor 12 para FrameLength=8
  • 15: Evento inesperado (es decir, no WakeupRequest) durante el modo de sueño. Ocurre solo para hardware LIN en modo Maestro

Valores para la razón:

  • 0: Tiempo de espera agotado
  • 1: Se recibió un byte inesperado que viola el protocolo. En este caso, el miembro offendingByte contiene su valor
  • 2: Se recibió un byte con error de framing (con bit de parada dominante). En este caso, el miembro offendingByte contiene su valor
  • 3: Campo Break inesperado
