Documentación de Datos de Miembro

uint16_t Vector::BLF::AfdxFrame::afdxFlags {}

Indicadores de estado y error como:

  • Bit 0: Marco de la línea B
  • Bit 1: Paquete es redundante
  • Bit 2: Marco es solo un fragmento
  • Bit 3: Marco ya está reensamblado
  • Bit 4: Paquete no es un marco AFDX válido
  • Bit 5: AFDX-SequenceNo es inválido
  • Bit 6: Se violó el tiempo de espera de redundancia
  • Bit 7: Se encontró error de redundancia
  • Bit 8: Desajuste de interfaz A / B
  • Bit 11: Error de fragmentación
