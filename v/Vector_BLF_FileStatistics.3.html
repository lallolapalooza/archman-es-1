Documentación de datos miembro

uint32_t Vector::BLF::FileStatistics::apiNumber { 4080200 }

número de API de BL

Esto consta de mayor, menor, compilación, parche. Está codificado como: mayor \* 1000000 + menor \* 1000 + compilación \* 100 + parche. Ejemplo: 4010608 decodifica a 4.1.6.8.

uint32_t Vector::BLF::FileStatistics::applicationBuild {}

Por hacer

Nota

zlib define un nivel de compresión máximo de 9. Todos los archivos que muestran 10 aquí, en realidad tienen LogContainers con nivel de compresión 6, que es el predeterminado para Vector BLF.

Nota

Las siguientes variables se basan en observaciones, ya que no hay documentación pública disponible. Esta variable designa la posición en el archivo del (primer) LogContainer que contiene los objetos RestorePointContainer.

Si no se utilizan RestorePoints, esto se establece en 0.
