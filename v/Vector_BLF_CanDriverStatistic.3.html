Vector_BLF_CanDriverStatistic(3)

NOMBRE

Vector_BLF_CanDriverStatistic - Obteniene estadísticas del controlador BLF CAN.

SINOPSIS

Vector_BLF_CanDriverStatistic(
    IN Vector_BLF_CanCardHandle handle,
    OUT Vector_BLF_CanDriverStatisticStruct *statistic
)

DESCRIPCIÓN

La función Vector_BLF_CanDriverStatistic recupera las estadísticas detalladas del controlador CAN del dispositivo BLF especificado por el descriptor de archivo handle. Estas estadísticas pueden incluir información sobre errores, mensajes transmitidos/recibidos, latencia, etc.

PARÁMETROS

handle
Un descriptor de archivo válido que hace referencia a un dispositivo BLF CAN abierto.
statistic
Un puntero a una estructura Vector_BLF_CanDriverStatisticStruct donde se almacenarán las estadísticas recuperadas. La estructura debe estar inicializada por el llamador.

VALOR DE RETORNO

Devuelve Vector_BLF_CAN_ERR_SUCCESS si la operación se completa con éxito. En caso de error, devuelve un código de error específico de la biblioteca BLF CAN. Consulte la documentación de la biblioteca BLF CAN para obtener una lista completa de los posibles códigos de error.
