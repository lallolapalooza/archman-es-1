Vector BLF :: Most150PktFragment (3)

NAME

Vector::BLF::Most150PktFragment

Packet fragment struct for MOST150 data

SYNOPSIS

#include <vector/blf/most150_pkt_fragment.h>

Structure Vector::BLF::Most150PktFragment

    struct Most150PktFragment {
        // fields
    };

Detailed Description

This structure is used to represent a fragment of a MOST150 packet. It contains information about the source and destination addresses, packet index, priority, and the data payload.

uint32_t Vector::BLF::Most150PktFragment::dataLen {}

announced data length Data length

The data length is announced at the start of the transmission. In some cases (e.g., sending to an invalid target address, receive buffer full of the target device) the transmission is terminated before all data bytes have been sent. Then the counted number of bytes on the bus is less than the announced data length (dataLen < dataLenAnnounced). Due to rare and very specific bit errors (degradation of the end termination byte), dataLen can also be greater than dataLenAnnounced.

uint32_t Vector::BLF::Most150PktFragment::validMask {}

bitfield indicating which members have valid data If a bit in the mask is set, the corresponding data field has been seen on the bus.

  • Bit 0: 0x00000001: dataLenAnnounced
  • Bit 1: 0x00000002: sourceAdr
  • Bit 2: 0x00000004: destAdr
  • Bit 3: 0x00000008: ackNack
  • Bit 4: 0x00000010: pAck
  • Bit 5: 0x00000020: pIndex
  • Bit 6: 0x00000040: piority
  • Bit 7: 0x00000080: crc
  • Bit 8: 0x00000100: cAck
  • Bit 9: 0x00000200: sourceMacAdr
  • Bit 10: 0x00000400: destMacAdr
  • Bit 31: 0x80000000: 0: MOST150 fragment; 1: MOST50 fragment
