    Descripción

    Esta clase representa un mensaje LIN. Proporciona métodos para acceder y modificar los atributos de un mensaje LIN, como el ID, los datos, la suma de comprobación y la información de protección.

    Documentación de Datos Miembro

    m_uiID

    El identificador único (ID) del mensaje LIN. Típicamente un valor de 6 bits.

    m_pucData

    Un puntero al búfer de datos que contiene la carga útil del mensaje LIN. La longitud de estos datos está especificada por m_uiDataLen.

    m_uiDataLen

    Especifica la cantidad de bytes de datos útiles en el mensaje LIN. Para un mensaje LIN, este valor puede variar de 0 a 8 bytes.

    m_ucChecksum

    Almacena el byte de suma de comprobación calculado para el mensaje LIN. Se utiliza para la verificación de errores.

    m_ucChecksumType

    Indica el algoritmo utilizado para calcular la suma de comprobación. Los valores comunes incluyen el tipo Clásico (0) y el tipo Mejorado (1).

    m_bProtected

    Un indicador booleano que, si es true, significa que el mensaje LIN utiliza suma de comprobación mejorada (Enhanced Checksum), que incluye protección contra la suplantación de identidad del ID.

    m_bBreakSent

    Un indicador booleano que, si es true, significa que el campo de ruptura (Break field) se transmitió explícitamente como parte de la trama del encabezado del mensaje LIN.

    m_bSyncSent

    Un indicador booleano que, si es true, significa que el campo de sincronización (Sync field) se transmitió explícitamente como parte de la trama del encabezado del mensaje LIN.
