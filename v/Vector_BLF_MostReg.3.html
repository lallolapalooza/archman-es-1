Descripción Detallada

MOST_REG.

Este evento transporta el resultado de una lectura o escritura de registro (por ejemplo, leer el motor de enrutamiento del OS8104). A diferencia del evento de registro especial (MostGenReg), este evento no ocurre espontáneamente.

    NAME

    Vector::BLF::MostReg - Perl interface to the Vector::BLF library

    SYNOPSIS

    use Vector::BLF::MostReg;

my $log = Vector::BLF::MostReg->new( filename => "log.blf" );

my $message_count = $log->message_count;
my $start_time = $log->start_time;
my $end_time = $log->end_time;

my $messages = $log->messages( start_time => $start_time, end_time => $end_time );

# Iterate over messages
for my $message (@$messages) {
    print $message->{timestamp}, ": ", $message->{data}, "\n";
}

$log->close;

    DESCRIPTION

    The Vector::BLF::MostReg module provides a Perl interface to the Vector::BLF library, allowing you to read and process BLF (Binary Logging Format) log files. BLF is a proprietary log file format used by Vector Informatik GmbH for logging data from automotive bus systems.

    This module provides methods to open BLF files, retrieve metadata such as message count, start time, and end time, and extract specific log messages within a given time range.

    METHODS

    • new( filename => "path/to/your/log.blf" ): Constructor for the Vector::BLF::MostReg object. Takes the path to the BLF file as an argument.

    • message_count(): Returns the total number of messages in the log file.

    • start_time(): Returns the timestamp of the first message in the log file.

    • end_time(): Returns the timestamp of the last message in the log file.

    • messages( start_time => $start, end_time => $end ): Retrieves log messages within the specified time range (inclusive). Returns an array reference of message hashes. Each hash contains the following keys:

      • timestamp: The timestamp of the message.
      • data: The message data (can be a string or a hash reference depending on the message type).
      • type: The type of the message (e.g., CAN, LIN, FlexRay).

    • close(): Closes the BLF log file and releases associated resources.

    PROPERTIES

    The Vector::BLF::MostReg object exposes the following properties (accessible via the corresponding methods):

    • message_count
    • start_time
    • end_time
