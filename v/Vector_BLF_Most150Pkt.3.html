uint8_t Vector::BLF::Most150Pkt::ackNack {}

código de acuse de recibo AckNack contiene el estado de transmisión de un mensaje de control (ver Registro de Estado de Transmisión de OS8104 para MOST25).

•
Bit 0: Significado:
•
1: sin respuesta (NoResp) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 1: Significado:
•
1: recepción válida (Valid) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 2: Significado:
•
1: Error CRC (CRCError) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 3: Significado:
•
1: búfer de recepción lleno (RxBufFull) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 4: Significado:
•
1: reconocido (Ack) Restricción:
•
solo para mensajes Dir = Tx o spy (siempre establecido a 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: reconocimiento negativo (NAck) Restricción:
•
solo para mensajes Dir = Tx o spy

uint8_t Vector::BLF::Most150Pkt::state {}

transmission status Transmission states of MOST50/150 messages and packets.

•
Bit 0: Meaning:
•
0: bus inactive
•
1: bus active Restriction:
•
only for Dir = Rx or mTransferType = Spy
•
Bit 4: Meaning:
•
1: acknowledged (Ack) Restriction
•
only for mTransferType = Node and Dir = Tx (always set to 1 for Rx messages in node mode)
•
Bit 5: Meaning:
•
1: not acknowledged (NAck) Restriction:
•
only for Dir = Tx
•
Bit 6: Meaning: Send result:
•
0: Transmission error (TxF)
•
1: OK Restriction:
•
only for Dir = Tx
•
only for mTransferType = Node

uint8_t Vector::BLF::Most150Pkt::transferType {}

Tranfer Type. Message-like events can either be recorded through the MOST transceiver chip or through a separate network spy.

  • 1: Node MOST transceiver reported the message (either due to a successful reception or as acknowledgment for a transmit request).
  • 2: Spy Message was reported by the network spy. The Spy sees all messages independently of the desti-nation address.
