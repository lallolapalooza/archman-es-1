uint8_t Vector::BLF::MostSpy::ackNack {}

AckNack contiene el estado de transmisión de un mensaje de control (ver Registro de Estado de Transmisión de OS8104 para MOST25).

•
Bit 0: Significado:
•
1: sin respuesta (NoResp) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 1: Significado:
•
1: recepción válida (Valid) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 2: Significado:
•
1: Error CRC (CRCError) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 3: Significado:
•
1: búfer de recepción lleno (RxBufFull) Restricción:
•
solo para mensajes Dir = Tx o spy
•
Bit 4: Significado:
•
1: reconocido (Ack) Restricción:
•
solo para mensajes Dir = Tx o spy (siempre establecido en 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: reconocimiento negativo (NAck) Restricción:
•
solo para mensajes Dir = Tx o spy

uint16_t Vector::BLF::MostSpy::rTyp {}

Subtipo de mensaje de control. Subtipo de un mensaje de Control MOST 25 (ver también la hoja de datos de OS8104).

  • 0: Normal
  • 1: RemoteRead
  • 2: RemoteWrite
  • 3: Alloc
  • 4: Dealloc
  • 5: GetSource
  • >5: no usado hasta ahora

uint8_t Vector::BLF::MostSpy::rTypAdr {}

Modo de direccionamiento. Modo de direccionamiento de los mensajes de Control MOST25.

  • 0x00: Dispositivo (dirección lógica del nodo)
  • 0x10: Posición del nodo
  • 0x20: Difusión
  • 0x30: Multicast grupal
  • 0xFF: Desconocido

uint8_t Vector::BLF::MostSpy::state {}

Estado de transmisión MOST25. Estado de transmisión de un mensaje de Control MOST25.

•
Bit 0: Significado:
•
0: bus inactivo
•
1: bus activo Restricción:
•
solo para Dir = Rx (MOSTCtrl) o MOSTSpy
•
Bit 1: Significado:
•
1: evento de desbloqueo durante la transmisión (Unl) Restricción:
•
solo para Dir = Rx (MOSTCtrl) o MOSTSpy
•
Bit 4: Significado:
•
1: reconocido (Ack) Restricción:
•
solo para Dir = Tx (siempre establecido en 1 para mensajes Rx en modo nodo)
•
Bit 5: Significado:
•
1: no reconocido (NAck) Restricción:
•
solo para Dir = Tx
•
Bit 6: Significado:
•
Resultado del envío:
•
0: Error de transmisión (TxF)
•
1: OK Restricción:
•
solo para Dir = Tx (MOSTCtrl)
