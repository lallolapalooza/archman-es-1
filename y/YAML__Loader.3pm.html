YAML::Loader(3) Documentación de Perl aportada por el usuario YAML::Loader(3)

NOMBRE

YAML::Loader - Clase YAML para cargar objetos Perl a YAML

SINOPSIS

use YAML::Loader;
my $loader = YAML::Loader->new;
my $hash = $loader->load(<<'...');
foo: bar
...

DESCRIPCIÓN

YAML::Loader es el módulo que YAML.pm utilizaba para deserializar YAML a objetos Perl. Es totalmente orientado a objetos y se puede usar por sí solo.
