YAML__Any(3pm)

Paquete: perl-yaml

Licencias: GPL, PerlArtistic

YAML::Any(3) Documentación de Perl aportada por el usuario YAML::Any(3)

NOMBRE

YAML::Any - Selecciona una implementación de YAML y úsala.

ESTADO

ADVERTENCIA: Este módulo pronto quedará obsoleto. El plan es que YAML.pm en sí mismo actúe como un módulo de tipo Any.

SINOPSIS

use YAML::Any;
$YAML::Indent = 3;
my $yaml = Dump(@objects);

DESCRIPCIÓN

Existen varias implementaciones de YAML que soportan la API Dump/Load. Este módulo selecciona la mejor disponible y la utiliza.

ORDEN

Actualmente, YAML::Any elegirá la primera de estas implementaciones de YAML que esté instalada en tu sistema:

  • YAML::XS
  • YAML::Syck
  • YAML::Old
  • YAML
  • YAML::Tiny

OPCIONES

Si especificas una opción como:

$YAML::Indent = 4;

Y YAML::Any está usando YAML::XS, usará la variable apropiada: $YAML::XS::Indent.

SUBRUTINAS

Al igual que todos los módulos YAML que YAML::Any utiliza, las siguientes subrutinas se exportan por defecto:

  • Dump
  • Load

y las siguientes subrutinas son exportables bajo petición:

  • DumpFile
  • LoadFile

MÉTODOS

YAML::Any proporciona los siguientes métodos de clase.

"YAML::Any->order"
Este método devuelve una lista de las implementaciones posibles actuales que YAML::Any buscará.
"YAML::Any->implementation"
Este método devuelve la implementación que usará YAML::Any. Este resultado se obtiene encontrando el primer miembro de YAML::Any->order que ya esté cargado en %INC o que pueda ser cargado usando "require". Si no se encuentra ninguna implementación, se lanzará un error.

EJEMPLOS

DumpFile y LoadFile

Aquí tienes un ejemplo para "DumpFile":

#!/usr/bin/perl
use strict;
use warnings;
use YAML::Any qw(DumpFile);
my $ds =
{
    array => [5,6,100],
    string => "Hello",
};
DumpFile("hello.yml", $ds);

Al ejecutarse, esto crea un archivo llamado "hello.yml" en el directorio de trabajo actual, con el siguiente contenido.

---
array:
- 5
- 6
- 100
string: Hello

A su vez, el siguiente ejemplo de "LoadFile", carga el contenido desde ahí y accede a él:

#!/usr/bin/perl
use strict;
use warnings;
use YAML::Any qw(LoadFile);
my ($ds) = LoadFile("hello.yml");
print "String == '", $ds->{string}, "'\n";

Asumiendo que "hello.yml" existe, y es como lo creó el ejemplo de "DumpFile", imprime:

$ perl load.pl
String == 'Hello'
$
