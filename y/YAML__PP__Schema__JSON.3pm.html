NOMBRE

YAML::PP::Schema::JSON - Esquema JSON de YAML 1.2

SINOPSIS

my $yp = YAML::PP->new( schema => ['JSON'] );
my $yp = YAML::PP->new( schema => [qw/ JSON empty=str /] );
my $yp = YAML::PP->new( schema => [qw/ JSON empty=null /] );

DESCRIPCIÓN

Con este esquema, la resolución de valores planos funcionará como en JSON. Todo lo que coincida con un valor especial se cargará como tal, los demás escalares planos se cargarán como cadenas.

Tenga en cuenta que esto es diferente del Esquema JSON JSON 1.2 oficial, donde todas las cadenas deben ir entre comillas.

Aquí puede ver todos los Esquemas y ejemplos implementados por YAML::PP: https://perlpunk.github.io/YAML-PP-p5/schemas.html

Esquema oficial: https://yaml.org/spec/1.2/spec.html#id2803231

CONFIGURACIÓN

El Esquema JSON 1.2 oficial de YAML quiere que todas las cadenas estén entre comillas. YAML::PP actualmente no exige eso (podría hacerlo opcionalmente en el futuro).

Eso significa que no se permiten nodos vacíos en el esquema oficial. Ejemplo:

---
key:

El comportamiento predeterminado de YAML::PP::Schema::JSON es devolver una cadena vacía, por lo que sería equivalente a:

---
key: ''

Puede configurarlo para que resuelva esto como "undef":

my $yp = YAML::PP->new( schema => [qw/ JSON empty=null /] );

De esta manera, es equivalente a:

---
key: null

El valor predeterminado es:

my $yp = YAML::PP->new( schema => [qw/ JSON empty=str /] );
