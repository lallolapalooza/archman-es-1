NOMBRE

YAML::PP::Schema::Include - Incluir archivos YAML

SINOPSIS

# /ruta/al/archivo.yaml
# ---
# incluido: !include include/archivo2.yaml
# /ruta/al/archivo2.yaml
# ---
# a: b
my $include = YAML::PP::Schema::Include->new;
my $yp = YAML::PP->new( schema => ['+', $include] );
# necesitamos el objeto YAML::PP original para obtener el nombre del archivo actual
# y para cargar otro archivo
$include->yp($yp);
my ($data) = $yp->load_file("/ruta/al/archivo.yaml");
# El resultado será:
$data = {
    incluido => { a => 'b' }
};

Permitir nombres de archivo absolutos y el uso de '..' para subir:

my $include = YAML::PP::Schema::Include->new(
    allow_absolute => 1, # por defecto: 0
);

Especificar rutas donde buscar para incluir:

my @rutas_inclusion = ("/ruta/a/incluir/yaml/1", "/ruta/a/incluir/yaml/2");
my $include = YAML::PP::Schema::Include->new(
    paths => \@rutas_inclusion,
);
my $yp = YAML::PP->new( schema => ['+', $include] );
$include->yp($yp);
# /ruta/a/incluir/yaml/1/archivo1.yaml
# ---
# a: b
my $yaml = <<'EOM';
- incluido: !include archivo1.yaml
EOM
my ($data) = $yp->load_string($yaml);

DESCRIPCIÓN

Este plugin te permite dividir un archivo YAML grande en archivos más pequeños. Luego puedes incluir estos archivos con la etiqueta "!include".

Buscará el nombre de archivo especificado relativo al nombre de archivo que se está procesando actualmente.

También puedes especificar las rutas donde buscar archivos para incluir. Itera a través de las rutas y devuelve el primer nombre de archivo que exista.

Por defecto, solo se permiten rutas relativas. Cualquier "../" en la ruta se eliminará. Puedes cambiar ese comportamiento estableciendo la opción "allow_absolute" a verdadero.

Si el archivo incluido contiene más de un documento, solo se incluirá el primero.

Probablemente añadiré una posibilidad de devolver todos los documentos como un arrayref.

El archivo YAML incluido se cargará creando un nuevo objeto YAML::PP con el esquema del objeto existente. De esta manera puedes incluir archivos recursivamente.

Incluso puedes reutilizar la misma inclusión mediante un alias:

---
factura:
    dirección de envío: &direccion !include direccion.yaml
    dirección de facturación: *direccion

Se detectarán las inclusiones circulares y serán fatales.

Es posible especificar qué hacer con el archivo incluido:

my $include = YAML::PP::Schema::Include->new(
    loader => sub {
        my ($yp, $filename);
        if ($filename =~ m/\.txt$/) {
            # abre el archivo y devuelve solo el texto
        }
        else {
            # comportamiento por defecto
            return $yp->load_file($filename);
        }
    },
);

Por ejemplo, RAML define una etiqueta "!include" que depende del contenido del archivo. Si contiene una directiva especial de RAML, se cargará como YAML, de lo contrario, se incluirá el contenido del archivo como una cadena.

Así, con este plugin puedes leer especificaciones RAML.
