YAML::PP::Schema::Binary - Esquema para cargar y datos binarios

SINOPSIS

use YAML::PP;
my $yp = YAML::PP->new( schema => [qw/ + Binary /] );

DESCRIPCIÓN

Ver https://yaml.org/type/binary.html

Al anteponer una cadena binaria codificada en base64 con la etiqueta "!!binary", se puede decodificar automáticamente al cargar.

Ten en cuenta que la lógica para volcar es probablemente defectuosa, ver https://github.com/perlpunk/YAML-PP-p5/issues/28.

Se aceptan sugerencias.
