YAML::PP::Writer::File(3) Documentación de Contribución de Perl de Usuario YAML::PP::Writer::File(3)

NOMBRE

YAML::PP::Writer::File - Escribe salida YAML a un archivo o manejador de archivo

SINOPSIS

my $writer = YAML::PP::Writer::File->new(output => $file);

DESCRIPCIÓN

El emisor YAML::PP envía su salida al escritor.

Puedes usar tu propio escritor si deseas enviar la salida YAML a otro lugar. Consulta t/44.writer.t para un ejemplo.

MÉTODOS

new
my $writer = YAML::PP::Writer::File->new(output => $file);
my $writer = YAML::PP::Writer::File->new(output => $filehandle);

Constructor.

escribir
$writer->write('- ');
init
$writer->init;

Inicializa

finish
$writer->finish;

Se llama cuando finaliza la salida. Si el argumento fue un nombre de archivo, el manejador de archivo se cerrará. Si el argumento fue un manejador de archivo, el llamador deberá cerrarlo.
