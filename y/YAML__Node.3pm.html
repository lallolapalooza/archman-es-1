YAML::Node(3) Documentación de Perl aportada por el usuario YAML::Node(3)

NOMBRE

YAML::Node - Un nodo de datos genérico que encapsula información YAML

SINOPSIS

use YAML;
use YAML::Node;
my $ynode = YAML::Node->new({}, 'ingerson.com/fruit');
%$ynode = qw(orange orange apple red grape green);
print Dump $ynode;

produce:

--- !ingerson.com/fruit
orange: orange
apple: red
grape: green

DESCRIPCIÓN

Un nodo YAML genérico es similar a un hash, array o nodo escalar simple en Perl, excepto que debe mantener un registro de su tipo. El tipo es una URI llamada etiqueta de tipo YAML.

YAML::Node es una clase para generar y manipular estos contenedores. Un nodo YAML (o ynode) es un hash, array o escalar "tied". En la mayoría de los aspectos, se comporta como la versión simple. Pero puedes asignar y recuperar una URI de etiqueta de tipo YAML. Para el tipo hash, también puedes asignar el orden en que se recuperarán las claves. Por defecto, un ynode ofrecerá sus claves en el mismo orden en que fueron asignadas.

YAML::Node tiene un método de clase llamado new() que devolverá un ynode. Le pasas un nodo regular y una etiqueta de tipo opcional. Después de eso, puedes usarlo como un nodo Perl normal, pero cuando lo uses con YAML::Dump, se respetarán las propiedades mágicas.

Así es como puedes controlar el orden de clasificación de las claves de hash durante una serialización YAML. Por defecto, YAML ordena las claves alfabéticamente. Pero observa en el ejemplo anterior que las claves se volcaron en el mismo orden en que se asignaron.

YAML::Node exporta una función llamada ynode(). Esta función devuelve el objeto "tied" para que puedas llamar a métodos especiales en él, como ->keys().

keys() funciona así:

use YAML;
use YAML::Node;
%$node = qw(orange orange apple red grape green);
$ynode = YAML::Node->new($node);
ynode($ynode)->keys(['grape', 'apple']);
print Dump $ynode;

produce:

---
grape: green
apple: red

Le dice al ynode qué claves y en qué orden usar.

Los ynodes desempeñarán un papel muy importante en cómo los programas utilizan YAML. Son la base de cómo una clase Perl puede organizar la carga y volcado de sus objetos.

Las próximas versiones de YAML.pm tendrán mucha más información sobre esto.
