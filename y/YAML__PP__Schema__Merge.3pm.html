NOMBRE

YAML::PP::Schema::Merge - Habilita las claves de fusión de YAML para mapeos

SINOPSIS

use YAML::PP;
my $yp = YAML::PP->new( schema => [qw/ + Merge /] );
my $yaml = <<'EOM';
---
- &CENTER { x: 1, y: 2 }
- &LEFT { x: 0, y: 2 }
- &BIG { r: 10 }
- &SMALL { r: 1 }
# Todos los siguientes mapeos son iguales:
- # Claves explícitas
  x: 1
  y: 2
  r: 10
  label: center/big
- # Fusionar un mapeo
  << : *CENTER
  r: 10
  label: center/big
- # Fusionar múltiples mapeos
  << : [ *CENTER, *BIG ]
  label: center/big
- # Sobrescribir
  << : [ *BIG, *LEFT, *SMALL ]
  x: 1
  label: center/big
EOM
my $data = $yp->load_string($yaml);
# $data->[4] == $data->[5] == $data->[6] == $data->[7]

DESCRIPCIÓN

Ver https://yaml.org/type/merge.html para la especificación.

Cita:

"Especifica uno o más mapeos que se fusionarán con el actual.

La clave de fusión "<<" se utiliza para indicar que todas las claves de uno o más mapeos especificados se insertarán en el mapeo actual, a menos que la clave ya exista en él. Si el valor asociado con la clave es un nodo de mapeo único, cada uno de sus pares clave/valor se inserta en el mapeo actual, a menos que la clave ya exista en él. Si el valor asociado con la clave de fusión es una secuencia, entonces se espera que esta secuencia contenga nodos de mapeo y cada uno de estos nodos se fusiona en secuencia según su orden. Las claves en los nodos de mapeo anteriores en la secuencia anulan las claves especificadas en los nodos de mapeo posteriores."

La implementación de esto de forma genérica no es trivial, porque también tenemos que manejar claves duplicadas, y YAML::PP te permite escribir tu propio manejador para procesar mapeos.

Por lo tanto, la API interna de esto no es estable en este momento.

Tenga en cuenta que si habilita este esquema, un escalar simple `<<` se verá como especial en cualquier lugar de su documento, por lo que si desea un literal `<<`, debe ponerlo entre comillas.

Tenga en cuenta que la fusión realizada no es una "fusión profunda". Solo se fusionan las claves de nivel superior.
