NOMBRE

YAML::PP::Schema::Perl - Esquema para serializar objetos de Perl y tipos especiales

SINOPSIS

use YAML::PP;
# ¡Esto puede ser peligroso al cargar YAML no confiable!
my $yp = YAML::PP->new( schema => [qw/ + Perl /] );
# o
my $yp = YAML::PP->new( schema => [qw/ Core Perl /] );
my $yaml = $yp->dump_string(sub { return 23 });
# cargar referencias de código
# ¡¡Esto es muy peligroso al cargar YAML no confiable!!
my $yp = YAML::PP->new( schema => [qw/ + Perl +loadcode /] );
my $code = $yp->load_string(<<'EOM');
--- !perl/code |
    {
        use 5.010;
        my ($name) = @_;
        say "Hello $name!";
    }
EOM
$code->("Ingy");

DESCRIPCIÓN

Este esquema te permite cargar y volcar objetos de Perl y tipos especiales.

Ten en cuenta que cargar objetos de clases arbitrarias puede ser peligroso en Perl. Debes cargar los módulos tú mismo, pero si se carga un módulo explotable y se crea un objeto, su método "DESTROY" será llamado cuando el objeto salga de ámbito. File::Temp es un ejemplo que puede ser explotable y podría eliminar archivos arbitrarios.

Volcar referencias de código está activado por defecto, pero no cargarlas (porque es fácilmente explotable ya que usa "eval" de cadena).

Estilos de Etiquetas

Puedes definir el estilo de las etiquetas que quieres soportar:

my $yp_perl_two_one = YAML::PP->new(
    schema => [qw/ + Perl tags=!!perl+!perl /],
);
"!perl" (por defecto)
Solo se soportan etiquetas "!perl/type".
"!!perl"
Solo se soportan etiquetas "!!perl/type".
"!perl+!!perl"
Se soportan tanto "!perl/type" como "!!perl/tag" al cargar. Al volcar, se usa "!perl/type".
"!!perl+!perl"
Se soportan tanto "!perl/type" como "!!perl/tag" al cargar. Al volcar, se usa "!!perl/type".

YAML.pm, YAML::Syck y YAML::XS usan "!!perl/type" al volcar.

YAML.pm y YAML::Syck soportan tanto "!perl/type" como "!!perl/type" al cargar. YAML::XS actualmente solo soporta lo último.

Permitir solo ciertas clases

Desde v0.017

Bendecir objetos arbitrarios puede ser peligroso. Quizás quieras permitir bendecir solo clases específicas e ignorar otras. Para esto, debes instanciar un objeto Perl Schema primero y usar la opción "classes".

Actualmente, solo permite una lista de cadenas:

my $perl = YAML::PP::Schema::Perl->new(
    classes => ['Foo', 'Bar'],
);
my $yp = YAML::PP::Perl->new(
    schema => [qw/ + /, $perl],
);

Las clases permitidas se cargarán y volcarán como de costumbre. Las otras serán ignoradas.

Si quieres permitir ningún objeto, pasa un array ref vacío.

EJEMPLOS

Esta es una lista de los tipos soportados actualmente y cómo se volcan a YAML:

arreglo
# Código
[
    qw/ uno dos tres cuatro /
]
# YAML
---
- uno
- dos
- tres
- cuatro
arreglo_bendecido
# Código
bless [
    qw/ uno dos tres cuatro /
], "Solo::Un::Arrayref"
# YAML
--- !perl/array:Solo::Un::Arrayref
- uno
- dos
- tres
- cuatro
círculo
# Código
my $circle = bless [ 1, 2 ], 'Circle';
push @$circle, $circle;
$circle;
# YAML
--- &1 !perl/array:Circle
- 1
- 2
- *1
ref_código
# Código
sub {
    my (%args) = @_;
    return $args{x} + $args{y};
}
# YAML
--- !perl/code |-
  {
      use warnings;
      use strict;
      (my(%args) = @_);
      (return ($args{'x'} + $args{'y'}));
  }
ref_código_bendecido
# Código
bless sub {
    my (%args) = @_;
    return $args{x} - $args{y};
}, "Soy::Código"
# YAML
--- !perl/code:Soy::Código |-
  {
      use warnings;
      use strict;
      (my(%args) = @_);
      (return ($args{'x'} - $args{'y'}));
  }
hash
# Código
{
    U => 2,
    B => 52,
}
# YAML
---
B: 52
U: 2
hash_bendecido
# Código
bless {
    U => 2,
    B => 52,
}, 'Una::Clase::Muy::Exclusiva'
# YAML
--- !perl/hash:Una::Clase::Muy::Exclusiva
B: 52
U: 2
referencia_de_referencia
# Código
my $ref = { a => 'hash' };
my $refref = \$ref;
$refref;
# YAML
--- !perl/ref
=:
  a: hash
referencia_de_referencia_bendecida
# Código
my $ref = { a => 'hash' };
my $refref = bless \$ref, 'Foo';
$refref;
# YAML
--- !perl/ref:Foo
=:
  a: hash
expresión_regular
# Código
my $string = 'sin bendecir';
qr{$string}
# YAML
--- !perl/regexp sin bendecir
expresión_regular_bendecida
# Código
my $string = 'bendecido';
bless qr{$string}, "Foo"
# YAML
--- !perl/regexp:Foo bendecido
referencia_escalar
# Código
my $scalar = "alguna cadena";
my $scalarref = \$scalar;
$scalarref;
# YAML
--- !perl/scalar
=: alguna cadena
referencia_escalar_bendecida
# Código
my $scalar = "otra cadena";
my $scalarref = bless \$scalar, 'Foo';
$scalarref;
# YAML
--- !perl/scalar:Foo
=: otra cadena

MÉTODOS

new
my $perl = YAML::PP::Schema::Perl->new(
    tags => "!perl",
    classes => ['MyClass'],
    loadcode => 1,
    dumpcode => 1,
);

El constructor reconoce las siguientes opciones:

tags
Por defecto: '"!perl"'

Ver "Estilos de Etiquetas"

classes
Por defecto: "undef"

Desde: v0.017

Acepta un array ref de nombres de clase

loadcode
Por defecto: 0
dumpcode
Por defecto: 1 
my $yp = YAML::PP->new( schema => [qw/ + Perl -dumpcode /] );
register
Un método de clase llamado por YAML::PP::Schema
construct_ref, represent_ref
Las variables de Perl del tipo "REF" se representan en YAML de esta manera: 
--- !perl/ref
=:
  a: 1

"construct_ref" devuelve los datos de Perl:

my $data = YAML::PP::Schema::Perl->construct_ref([ '=', { some => 'data' } ]);
my $data = \{ a => 1 };

"represent_ref" convierte una variable "REF" en un mapeo YAML:

my $data = YAML::PP::Schema::Perl->represent_ref(\{ a => 1 });
my $data = { '=' => { a => 1 } };

NAME

YAML::PP::Schema::Perl - Schema for Perl specific types

SYNOPSIS

use YAML::PP::Schema::Perl;

my $schema = YAML::PP::Schema::Perl->new;

# Construct data
my $data_scalar = $schema->construct_scalar([ '=', 'string' ]);
my $data_regex = $schema->construct_regex('foo.*');
my $data_code = $schema->evaluate_code('{ return 23 }');
my $data_glob = $schema->construct_glob($hash);
my $data_object = $schema->object($data, $class);

# Represent data
my $yaml_scalar = $schema->represent_scalar($string_ref);
my $yaml_regex = $schema->represent_regex($qr);
my $yaml_code = $schema->represent_code($code_ref);
my $yaml_glob = $schema->represent_glob($glob);

DESCRIPTION

This module implements a YAML schema for Perl-specific types, like "SCALAR", regexes, code references, and globs.

construct_scalar, represent_scalar
Perl variables of the type "SCALAR" are represented in yaml like this: 
--- !perl/scalar
=: string

"construct_scalar" returns the perl data:

my $data = YAML::PP::Schema::Perl->construct_ref([ '=', 'string' );
my $data = \'string';

"represent_scalar" turns a "SCALAR" variable into a YAML mapping:

my $data = YAML::PP::Schema::Perl->represent_scalar(\'string');
my $data = { '=' => 'string' };
construct_regex, represent_regex
"construct_regex" returns a "qr{}" object from the YAML string: 
my $qr = YAML::PP::Schema::Perl->construct_regex('foo.*');

"represent_regex" returns a string representing the regex object:

my $string = YAML::PP::Schema::Perl->represent_regex(qr{...});
evaluate_code, represent_code
"evaluate_code" returns a code reference from a string. The string must start with a "{" and end with a "}". 
my $code = YAML::PP::Schema::Perl->evaluate_code('{ return 23 }');

"represent_code" returns a string representation of the code reference with the help of B::Deparse:

my $string = YAML::PP::Schema::Perl->represent_code(sub { return 23 });
construct_glob, represent_glob
"construct_glob" returns a glob from a hash. 
my $glob = YAML::PP::Schema::Perl->construct_glob($hash);

"represent_glob" returns a hash representation of the glob.

my $hash = YAML::PP::Schema::Perl->represent_glob($glob);
object
Does the same as "bless": 
my $object = YAML::PP::Schema::Perl->object($data, $class);
