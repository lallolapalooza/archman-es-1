NOMBRE

YAML::PP::Common - Constantes y funciones comunes

SINOPSIS

use YAML::PP::Common ':STYLES';
# o
use YAML::PP::Common qw/
    YAML_ANY_SCALAR_STYLE YAML_PLAIN_SCALAR_STYLE
    YAML_SINGLE_QUOTED_SCALAR_STYLE YAML_DOUBLE_QUOTED_SCALAR_STYLE
    YAML_LITERAL_SCALAR_STYLE YAML_FOLDED_SCALAR_STYLE
    YAML_QUOTED_SCALAR_STYLE
    YAML_ANY_SEQUENCE_STYLE
    YAML_BLOCK_SEQUENCE_STYLE YAML_FLOW_SEQUENCE_STYLE
    YAML_ANY_MAPPING_STYLE
    YAML_BLOCK_MAPPING_STYLE YAML_FLOW_MAPPING_STYLE
/;
use YAML::PP::Common ':PRESERVE';
# o
use YAML::PP::Common qw/
    PRESERVE_ALL PRESERVE_ORDER PRESERVE_SCALAR_STYLE PRESERVE_FLOW_STYLE
    PRESERVE_ALIAS
/:

DESCRIPCIÓN

Este módulo proporciona constantes y funciones comunes para módulos que trabajan con eventos de YAML::PP.

FUNCIONES

event_to_test_suite
my $string = YAML::PP::Common::event_to_test_suite($event_prom_parser);

Para ver ejemplos del formato devuelto, mire el directorio de esta distribución "yaml-test-suite" que es una copia de https://github.com/yaml/yaml-test-suite.

test_suite_to_event
my $event = YAML::PP::Common::test_suite_to_event($str);

Convierte una cadena de eventos en formato de suite de pruebas a un hashref de eventos. Todavía no está completo.
