YAML::PP::Perl(3) Documentación de Perl aportada por el usuario YAML::PP::Perl(3)

NOMBRE

YAML::PP::Perl - Módulo de conveniencia para cargar y volcar objetos Perl

SINOPSIS

use YAML::PP::Perl;
my @docs = YAML::PP::Perl->new->load_string($yaml);
my @docs = YAML::PP::Perl::Load($yaml);
# lo mismo que
use YAML::PP;
my $yp = YAML::PP->new( schema => [qw/ Core Perl /] );
my @docs = $yp->load_string($yaml);

DESCRIPCIÓN

Esto es solo por conveniencia. Creará un objeto YAML::PP usando el esquema predeterminado ("Core") y el esquema YAML::PP::Schema::Perl.

Consulta YAML::PP::Schema::Perl para obtener documentación.

MÉTODOS

Load, Dump, LoadFile, DumpFile
Estos funcionan como las funciones en YAML::PP, simplemente añadiendo el esquema "Perl".
new
Constructor, funciona como en YAML::PP, solo añade el esquema "Perl" a la lista de argumentos.
