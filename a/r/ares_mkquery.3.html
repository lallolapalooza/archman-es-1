ARES_MKQUERY(3) Manual de funciones de biblioteca ARES_MKQUERY(3)

NOMBRE

ares_mkquery - Componer un búfer de consulta DNS de pregunta única

SINOPSIS

#include <ares.h>
int ares_mkquery(const char *name, int dnsclass, int type,
                 unsigned short id, int rd, unsigned char **buf,
                 int *buflen)

DESCRIPCIÓN

Esta función está obsoleta desde c-ares 1.10, por favor use ares_dns_record_create(3) en su lugar.

La función ares_mkquery compone una consulta DNS con una única pregunta. El parámetro name proporciona el nombre de la consulta como una cadena de caracteres C terminada en NULO de etiquetas separadas por puntos, opcionalmente terminada con un punto; los puntos y las barras invertidas dentro de una etiqueta deben escaparse con una barra invertida. Los parámetros dnsclass y type proporcionan la clase y el tipo de la consulta utilizando los valores definidos en <arpa/nameser.h>. El parámetro id proporciona un identificador de 16 bits para la consulta. El parámetro rd debe ser distinto de cero si se desea recursión, cero si no. La consulta se colocará en un búfer asignado, un puntero al cual se almacenará en la variable apuntada por buf, y la longitud del cual se almacenará en la variable apuntada por buflen. Es responsabilidad del llamador liberar este búfer usando ares_free_string(3) cuando ya no sea necesario.

El uso de ares_mkquery(3) está obsoleto, mientras que la función es equivalente a ares_create_query(3) con max_udp_size establecido en 0.

VALORES DE RETORNO

ares_mkquery puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La construcción de la consulta DNS tuvo éxito.
ARES_ENOTFOUND
El nombre de consulta name se refiere a un nombre de dominio .onion. Ver RFC 7686.
ARES_EBADNAME
El nombre de consulta name no pudo ser codificado como un nombre de dominio, ya sea porque contenía una etiqueta de longitud cero o porque contenía una etiqueta de más de 63 caracteres.
ARES_ENOMEM
Se agotó la memoria.

VER TAMBIÉN

ares_expand_name(3), ares_dns_record(3), ares_free_string(3)
