ares_set_sortlist(3)

Paquete: c-ares

Licencias: MIT

ARES_SET_SORTLIST(3) Manual de funciones de biblioteca ARES_SET_SORTLIST(3)

NOMBRE

ares_set_sortlist - Inicializa la configuración de una lista de ordenación (sortlist) de un canal ares_channel_t

SINOPSIS

#include <ares.h>
int ares_set_sortlist(ares_channel_t *channel, const char *sortstr)

DESCRIPCIÓN

La función ares_set_sortlist(3) inicializa una configuración de lista de ordenación de direcciones para los datos del canal identificados por channel, de modo que las direcciones devueltas por ares_gethostbyname(3) se ordenen según la lista de ordenación. La cadena sortstr proporcionada contiene una lista separada por espacios de pares de direcciones IP-máscara de red. La máscara de red es opcional pero sigue a la dirección después de una barra inclinada si está presente. Por ejemplo, "130.155.160.0/255.255.240.0 130.155.0.0".

Esta función reemplaza cualquier lista de ordenación de direcciones previamente configurada con las dadas en la cadena de configuración.

VALORES DEVUELTOS

ares_set_sortlist(3) puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La configuración de la lista de ordenación se inicializó correctamente.
ARES_ENOMEM
Se agotó la memoria disponible del proceso.
ARES_ENODATA
Los datos del canal identificados por channel no eran válidos.
ARES_ENOTINITIALIZED
Aún no se ha realizado la inicialización de la biblioteca c-ares.

VER TAMBIÉN

ares_init_options(3), ares_dup(3)

DISPONIBILIDAD
