Los nombres de ruta pueden proporcionarse de una de tres maneras

diferentes:
char
*
Cadenas multibyte en la configuración regional
actual.
wchar_t
*
Cadenas de caracteres anchos en la configuración regional actual. Las funciones de acceso se denominan XXX_w
().
UTF
-8
Cadenas Unicode codificadas como UTF-8. Estas son funci
ones de conveniencia para actualizar tanto las cadenas m
ultibyte como las de caracteres anchos al mismo tiempo.

sourcepath es un concepto puramente del sistema de archivos y nunca se almacena directamente en un

archivo.

Por esa razón, solo está disponible como cadena multibyte. La ruta link es una función de conveniencia para establecer condicionalmente el destino de un enlace duro o simbólico. No tiene una función de acceso correspondiente para

obtener.
