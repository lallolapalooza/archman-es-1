NOMBRE

argomail2dlf - convierte los archivos de registro de ArGoSoft Mail Server al formato DLF de correo electrónico

SINOPSIS

argomail2dlf

DESCRIPCIÓN

argomail2dlf convierte un archivo de registro de ArGoSoft Mail Server al formato DLF de correo electrónico. La información sobre ArGoSoft Mail Server se puede encontrar en http://www.argosoft.com/applications/mailserver/. El formato genérico DLF de correo electrónico se describe en email.xml.

Este convertidor DLF fue desarrollado y probado con ArGoSoft Mail Server Pro. Podría funcionar con las versiones Free y Plus, pero no fue probado.

CONFIGURACIÓN DE REGISTRO

Para operar correctamente con Lire, debes asegurarte de que las siguientes funciones de registro estén habilitadas:

- Registrar comandos SMTP.
- Registrar conversaciones SMTP.
- Registrar en archivo.

Las otras dos opciones (Registrar comandos POP y Registrar comandos Web) no son necesarias y pueden dejarse desmarcadas.

LIMITACIONES

Debido a las limitaciones en el sistema de registro de ArGoSoft Mail Server, la siguiente información no está disponible:

- tamaño de los mensajes
- ID del mensaje

Además, dado que ArGoSoft no registra el "identificador de cola" (que es un identificador que se puede usar para rastrear la entrega de un mensaje a través de los diferentes componentes), tenemos que confiar en heurísticas e invariantes asumidas para rastrear los mensajes. Usamos las direcciones del remitente y del destinatario para rastrear los mensajes.

Entrega en orden
Asumimos que ArGoSoft Mail Server entregará sus mensajes en el orden en que los recibió.
Entrega a un destinatario
Asumimos que ArGoSoft Mail Server solo entregará a un destinatario a la vez. Es decir, si un mensaje estaba dirigido a dos destinatarios en el mismo dominio remoto, utilizará dos conexiones para entregar este mensaje.
La entrega local es inmediata
Asumimos que la entrega local (y reenvío) ocurrirá justo después de que se registre el código de estado 354 o 250. Tenemos que confiar en esto, ya que los mensajes de registro relacionados con el reenvío no mencionan al remitente.
Mensajes desconocidos fueron entregados a través de la web
Se presume que los mensajes que se entregan pero que no se enviaron a través de SMTP provienen del retransmisor webmail (enviados a través de la interfaz web). También podrían haberse enviado antes del inicio del archivo de registro.

EJEMPLOS

Para procesar un registro como el producido por argomail

$ argomail2dlf < mail.log

argomail2dlf raramente se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report argomail < /var/log/mail.log
