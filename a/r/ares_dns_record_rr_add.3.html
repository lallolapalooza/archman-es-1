ares_dns_record_rr_cnt(

3)

Le renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect. La fonction ares_dns_record_rr_add(3)

ajoute

une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide, ou « . ». Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl. Les fonctions ares_dns_record_rr_get(3) e

t

ares_dns_record_rr_get_const(3) sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à [[109]] ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de ressources. La

fonction

ares_dns_record_rr_del(3) est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son utilisation principale est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il faut réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à [[116]] ares_dns_record_rr_cnt(3) .
