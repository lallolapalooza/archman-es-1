NOMBRE

ares_set_local_ip6 - Establecer la dirección IP local para las solicitudes IPv6 salientes.

SINOPSIS

#include <ares.h>
void ares_set_local_ip6(ares_channel_t *channel, const unsigned char* local_ip6)

DESCRIPCIÓN

La función ares_set_local_ip6 establece la dirección IPv6 para las solicitudes IPv6 salientes. El parámetro local_ip6 se especifica en orden de bytes de red. Esto permite a los usuarios especificar interfaces de salida cuando se utiliza en sistemas multi-homed. El argumento local_ip6 debe tener una longitud de 16 bytes.

VER TAMBIÉN

NOTAS
