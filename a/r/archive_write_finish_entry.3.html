ARCHIVE_WRITE_FINISH_ENTRY(3) Manual de funciones de biblioteca ARCHIVE_WRITE_FINISH_ENTRY(3)

NOMBRE

archive_write_finish_entry — funciones para crear archivos

BIBLIOTECA

Biblioteca de Archivos de Streaming (libarchive, -larchive)

SINOPSIS

#include <archive.h>

int
archive_write_finish_entry(struct archive *);

DESCRIPCIÓN

Finaliza la entrada que se acaba de escribir. En particular, esto escribe el relleno final requerido por algunos formatos. Normalmente, los clientes nunca necesitan llamar a esto, ya que se llama automáticamente por archive_write_header() y archive_write_close() según sea necesario. Para los manejadores de archive_write_disk, esto vacía los cambios pendientes de atributos de archivo, como la hora de modificación.

VALORES DE RETORNO

Esta función devuelve ARCHIVE_OK en caso de éxito, o uno de varios códigos de error distintos de cero en caso de errores. Los códigos de error específicos incluyen: ARCHIVE_RETRY para operaciones que podrían tener éxito si se vuelven a intentar, ARCHIVE_WARN para condiciones inusuales que no impiden operaciones posteriores y ARCHIVE_FATAL para errores graves que hacen imposibles las operaciones restantes.

ERRORES

Los códigos de error detallados y las descripciones textuales están disponibles en las funciones archive_errno() y archive_error_string().

VER TAMBIÉN
