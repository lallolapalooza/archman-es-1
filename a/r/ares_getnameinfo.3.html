NOMBRE

ares_getnameinfo - Traducción de dirección a nombre de host de manera independiente del protocolo

SINOPSIS

#include <ares.h>
typedef void (*ares_nameinfo_callback)(void *arg, int status,
                                       int timeouts, char *node,
                                       char *service)
void ares_getnameinfo(ares_channel_t *channel, const struct sockaddr *sa,
                      ares_socklen_t salen, int flags,
                      ares_nameinfo_callback callback, void *arg)

DESCRIPCIÓN

La función ares_getnameinfo está definida para la traducción de direcciones independiente del protocolo. La función es una combinación de ares_gethostbyaddr(3) y getservbyport(3). La función traducirá la dirección ejecutando una consulta de host en el canal de servicio de nombres identificado por channel o intentará resolverla localmente si es posible. Los parámetros sa y len proporcionan la dirección como una estructura sockaddr, y flags proporciona las opciones que utilizará la función. Las banderas válidas se enumeran a continuación:

ARES_NI_NOFQDN
Solo se devuelve la porción del nombre de host del FQDN para hosts locales.
ARES_NI_NUMERICHOST
Se devuelve la forma numérica del nombre de host en lugar del nombre.
ARES_NI_NAMEREQD
Se devuelve un error si el nombre de host no se puede encontrar en el DNS.
ARES_NI_NUMERICSERV
Se devuelve la forma numérica del servicio en lugar del nombre.
ARES_NI_TCP
El nombre del servicio se buscará para el protocolo TCP.
ARES_NI_UDP
El nombre del servicio se buscará para el protocolo UDP.
ARES_NI_SCTP
El nombre del servicio se buscará para el protocolo SCTP.
ARES_NI_DCCP
El nombre del servicio se buscará para el protocolo DCCP.
ARES_NI_NUMERICSCOPE
Se devuelve la forma numérica del ID de ámbito en lugar del nombre.
ARES_NI_LOOKUPHOST
Se está solicitando una búsqueda de nombre de host.
ARES_NI_LOOKUPSERVICE
Se está solicitando una búsqueda de nombre de servicio.

Cuando la consulta se completa o falla, la biblioteca ares invocará a callback. La finalización o el fallo de la consulta pueden ocurrir inmediatamente, o pueden ocurrir durante una llamada posterior a ares_process(3), ares_destroy(3) o ares_cancel(3).

Cuando se llama a la función de devolución de llamada asociada, se llama con un bloqueo de canal, por lo que se debe tener cuidado de garantizar que cualquier procesamiento sea mínimo para evitar bloqueos del canal DNS.

La función de devolución de llamada puede activarse desde un hilo diferente al que llamó a ares_getnameinfo(3).

Para los integradores que ejecutan sus propios bucles de eventos y no usan ARES_OPT_EVENT_THREAD, se debe tener cuidado para asegurar que las listas de descriptores de archivos se actualicen inmediatamente dentro del bucle de eventos cuando se notifiquen.

El argumento de la función de devolución de llamada arg se copia del argumento arg de ares_getnameinfo. El argumento de la función de devolución de llamada status indica si la consulta tuvo éxito y, si no, cómo falló. Puede tener cualquiera de los siguientes valores:

ARES_SUCCESS
La búsqueda de host se completó con éxito.
ARES_ENOTIMP
La biblioteca ares no sabe cómo buscar direcciones del tipo family.
ARES_ENOTFOUND
La dirección addr no se encontró.
ARES_ENOMEM
Se agotó la memoria.
ARES_ECANCELLED
La consulta fue cancelada.
ARES_EDESTRUCTION
El canal de servicio de nombres channel se está destruyendo; la consulta no se completará.
ARES_EBADFLAGS
El parámetro flags contiene un valor ilegal.

El argumento de la función de devolución de llamada timeouts informa cuántas veces una consulta caducó durante la ejecución de la solicitud dada.

En caso de una finalización exitosa de la consulta, el argumento de la función de devolución de llamada node contiene una cadena que representa el nombre de host (suponiendo que se especificó ARES_NI_LOOKUPHOST). Además, service contiene una cadena que representa el nombre del servicio (suponiendo que se especificó ARES_NI_LOOKUPSERVICE). Si la consulta no se completó con éxito, o uno de los valores no se solicitó, node o service serán NULL.
