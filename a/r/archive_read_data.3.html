archive_read_data(3)

Paquete: libarchive

Licencias: BSD-2-Clause

ARCHIVE_READ_DATA(3) Manual de funciones de la biblioteca ARCHIVE_READ_DATA(3)

NOMBRE

archive_read_data, archive_read_data_block, archive_read_data_skip, archive_read_data_into_fd — funciones para leer archivos de transmisión

BIBLIOTECA

Biblioteca de archivos de transmisión (libarchive, -larchive)

SINOPSIS

#include <archive.h>

la_ssize_t
archive_read_data(struct archive *, void *buff, size_t len);

int
archive_read_data_block(struct archive *, const void **buff, size_t *len, off_t *offset);

int
archive_read_data_skip(struct archive *);

int
archive_read_data_into_fd(struct archive *, int fd);

DESCRIPCIÓN

archive_read_data()
Lee datos asociados con la cabecera recién leída. Internamente, esta es una función de conveniencia que llama a archive_read_data_block() y rellena cualquier hueco con nulos para que los llamadores vean un único flujo continuo de datos.
archive_read_data_block()
Devuelve el siguiente bloque de datos disponible para esta entrada. A diferencia de archive_read_data(), la función archive_read_data_block() evita copiar datos y le permite manejar correctamente archivos dispersos (sparse files), tal como lo soportan algunos formatos de archivo. La biblioteca garantiza que los desplazamientos aumentarán y que los bloques no se solaparán. Tenga en cuenta que los bloques devueltos por esta función pueden ser mucho más grandes que el tamaño del bloque leído del disco, debido a la compresión y a las optimizaciones de búfer internas.
archive_read_data_skip()
Una función de conveniencia que llama repetidamente a archive_read_data_block() para omitir todos los datos de esta entrada de archivo. Tenga en cuenta que esta función se invoca automáticamente por archive_read_next_header2() si la entrada anterior no se consumió por completo.
archive_read_data_into_fd()
Una función de conveniencia que llama repetidamente a archive_read_data_block() para copiar toda la entrada al descriptor de archivo proporcionado.

VALORES DE RETORNO

La mayoría de las funciones devuelven cero si tienen éxito, un valor distinto de cero en caso de error. Los posibles códigos de retorno incluyen: ARCHIVE_OK (la operación tuvo éxito), ARCHIVE_WARN (la operación tuvo éxito pero se encontró un error no crítico), ARCHIVE_EOF (se encontró el fin del archivo), ARCHIVE_RETRY (la operación falló pero se puede reintentar) y ARCHIVE_FATAL (hubo un error fatal; el archivo debe cerrarse inmediatamente).

archive_read_data() devuelve el número de bytes leídos realmente o cero al final de la entrada. En caso de error, se devuelve un valor de ARCHIVE_FATAL, ARCHIVE_WARN o ARCHIVE_RETRY.

ERRORES

Los códigos de error detallados y las descripciones textuales están disponibles en las funciones archive_errno() y archive_error_string().
