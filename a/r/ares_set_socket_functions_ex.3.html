No se puede usar cuando se pasa ARES_OPT_EVENT_THREAD a ares_init_options(3). Esta función reemplaza la llamada ares_set_socket_functions(3) ahora obsoleta. Estas funciones de devolución de llamada se invocarán para crear/destruir objetos socket y realizar E/S,

en

lugar de las llamadas al sistema normales. Una aplicación cliente puede anular completamente la operación de red normal a través de esta funcionalidad, y proporcionar su propia capa de transporte. Algunas devoluciones de llamada pueden ser opcionales y se documentan

como

tales a continuación, pero no implementar tales devoluciones de llamada deshabilitará ciertas características dentro de c-ares. Se recomienda encarecidamente implementar todas las devoluciones de llamada.

Se

espera que todas las funciones de devolución de llamada operen como sus equivalentes del sistema, y que establezcan errno(2) o WSASetLastError(2) a un código de error apropiado en caso de fallo. Se recomienda encarecidamente que las devoluciones de llamada de E/S se implementen para ser asíncronas y se indique como tal en el miembro flags.
