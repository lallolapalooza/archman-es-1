ARP-SCAN(1) Manual de Comandos Generales ARP-SCAN(1)

NOMBRE

arp-scan - Envía peticiones ARP a hosts de destino y muestra las respuestas

SINOPSIS

arp-scan [opciones] [hosts...]

Los hosts de destino deben especificarse en la línea de comandos a menos que se utilice la opción --file o --localnet.

Los objetivos pueden ser direcciones IPv4 o nombres de host. También puede usar notación CIDR (10.0.0.0/24) (incluye red y broadcast), rangos (10.0.0.1-10.0.0.10) y red:máscara (10.0.0.0:255.255.255.0).

DESCRIPCIÓN

arp-scan envía paquetes de petición ARP a los hosts especificados y muestra cualquier respuesta recibida. La interfaz de red se puede especificar con la opción --interface. Si no se especifica ninguna interfaz, arp-scan elegirá la interfaz activa con el número más bajo (excluyendo el loopback).

arp-scan utiliza sockets crudos (raw sockets), lo que requiere privilegios en algunos sistemas:

Linux con soporte de capacidades POSIX.1e usando libcap:
arp-scan tiene en cuenta las capacidades. Requiere CAP_NET_RAW en el conjunto permitido y solo habilita esa capacidad para las funciones requeridas. use setcap cap_net_raw+p /ruta/a/arp-scan para añadir CAP_NET_RAW al conjunto permitido del ejecutable arp-scan. El soporte de capacidades también hace que SUID root sea mucho más seguro, ya que arp-scan soltará todas las capacidades excepto CAP_NET_RAW y no se ejecutará con privilegios de root completos.
BSD y macOS:
Necesita acceso de lectura/escritura a /dev/bpf*
Cualquier sistema operativo:
Ejecutar como root o SUID root funcionará en cualquier sistema operativo, pero otros métodos son preferibles siempre que sea posible.

ARP solo opera en la red local y no puede ser enrutado. Aunque el protocolo ARP utiliza direcciones IPv4, no es un protocolo IP y arp-scan puede usarse en interfaces sin una dirección IPv4.

Se envía una petición ARP por cada objetivo. Si un host no responde, la petición se reintentará una vez más. El número de reintentos se puede cambiar con la opción --retry. Reducir el número de reintentos reducirá el tiempo de escaneo a riesgo de perder algunos resultados debido a la pérdida de paquetes.

Puede especificar el ancho de banda que usará arp-scan con la opción --bandwidth. El valor predeterminado es 256000 bits por segundo. Aumentar el ancho de banda reducirá el tiempo de escaneo, pero establecer un ancho de banda demasiado alto puede causar una alta tasa de paquetes de broadcast. Otra forma de especificar la tasa de paquetes es con la opción --interval.

El tiempo para un escaneo de una sola pasada (es decir, con --retry=1) es:

tiempo=n×i+t+o

Donde n es el número de hosts, i es el intervalo (dado con --interval o calculado a partir de --bandwidth), t es el tiempo de espera (especificado con --timeout) y o es el tiempo de sobrecarga necesario para cargar la lista de objetivos y leer los archivos de mapeo MAC/Vendor. La sobrecarga es normalmenre despreciable (típicamente alrededor de 100ms) pero puede reducirse aún más con la opción --quiet. Para listas pequeñas de hosts, el valor de tiempo de espera dominará, pero para listas grandes el intervalo de paquetes es el valor más importante.

Cualquier parte de la petición ARP puede ser modificada mediante el uso de las opciones --arpXXX como se muestra en la tabla a continuación:

Opciones de Paquete de Petición ARP
Campo Bits Opción Por defecto
ar$hrd 16 --arphrd 1 (ARPHRD_ETHER)
ar$pro 16 --arppro 0x0800
ar$hln 8 --arphln 6 (ETH_ALEN)
ar$pln 8 --arppln 4 (IPv4)
ar$op 16 --arpop 1 (ARPOP_REQUEST)
ar$sha 48 --arpsha dirección h/w de la interfaz
ar$spa 32 --arpspa dirección IPv4 de la interfaz
ar$tha 48 --arptha 00:00:00:00:00:00
ar$tpa 32 Ninguna dirección IPv4 del host de destino

La opción más común es --arpspa, que establece la dirección IPv4 de origen en la petición ARP, permitiendo que la petición ARP use una dirección de origen diferente a la dirección de la interfaz. Esto permite el uso de arp-scan en interfaces sin dirección IPv4. Nota: Establecer ar$spa a la dirección IP del objetivo hace que algunos sistemas operativos informen de un conflicto de direcciones cuando reciben una petición ARP para su propia dirección.

También puede cambiar los valores en la cabecera del trama Ethernet como se muestra a continuación:

Opciones de Cabecera Ethernet
Campo Bits Opción Por defecto
Dirección Destino 48 --destaddr ff:ff:ff:ff:ff:ff
Dirección Origen 48 --srcaddr dirección de la interfaz
Tipo de Protocolo 16 --prototype 0x0806 (ARP)

La opción --destaddr, que establece la dirección Ethernet de destino, es la única que se usa comúnmente.

Por defecto, las respuestas ARP se muestran en el siguiente formato:

<Dirección IPv4> <Dirección MAC> <Detalles del Vendedor>

Donde Dirección IPv4 es la dirección IP del objetivo que responde, Dirección MAC es su dirección de capa de enlace y Detalles del Vendedor son los detalles del vendedor decodificados de la dirección de hardware. Los campos de salida están separados por un solo carácter de tabulación. Puede cambiar el formato de salida con la opción --format.

Las respuestas se muestran en el orden en que se reciben, lo que puede ser diferente del orden en que se enviaron las peticiones, ya que algunos hosts pueden responder más rápido que otros.

La decodificación del vendedor utiliza los archivos ieee-oui.txt y mac-vendor.txt. ieee-oui.txt se genera a partir de los registros IEEE MA-L (OUI), MA-M, MA-S (OUI36) y IAB. mac-vendor.txt contiene mapeos adicionales de MAC a Vendedor, y puede usarse para agregar mapeos personalizados. get-oui se puede usar para actualizar ieee-oui.txt con los últimos datos de los registros IEEE.

Todos los hosts IPv4 deberían responder a los paquetes de petición ARP, incluidos los hosts con filtrado de paquetes como los firewalls. Esto hace de arp-scan una herramienta útil para descubrir todos los hosts IPv4 activos en la red local.

OPCIONES

A continuación se enumeran las opciones disponibles. Las opciones cortas y largas que hacen lo mismo están agrupadas.

-h, --help
Muestra un mensaje de ayuda y sale.
-v, --version
Muestra la información de la versión y sale.
-i interfaz, --interface=interfaz
Especifica la interfaz de red a utilizar para enviar y recibir paquetes. Si no se especifica, se elige automáticamente la interfaz activa con el número más bajo (excluyendo el loopback).
-l, --localnet
Escanea toda la subred local. No se necesitan hosts de destino en la línea de comandos. La subred se deduce de la dirección IP y máscara de la interfaz seleccionada.
-f archivo, --file=archivo
Lee los hosts de destino desde el archivo especificado. No se necesitan hosts de destino en la línea de comandos. El archivo debe contener una dirección IP o nombre de host por línea.
-r num, --retry=num
Establece el número de reintentos para cada host a num. El valor predeterminado es 1. El valor 0 significa que no se reintentará la petición en caso de que no haya respuesta.
-t msec, --timeout=msec
Establece el tiempo de espera para las respuestas ARP a msec milisegundos. El valor predeterminado es 500.
-b bps, --bandwidth=bps
Establece el ancho de banda a utilizar en bits por segundo. El valor predeterminado es 256000 (256 kbps). El ancho de banda se utiliza para calcular el intervalo entre paquetes. Si se especifica --interval, este valor se ignora.
-i usec, --interval=usec
Establece el intervalo entre paquetes de petición ARP en microsegundos. Si se especifica, este valor se utiliza en lugar del calculado a partir de --bandwidth.
-O, --random
Envía las peticiones ARP en orden aleatorio. Esto puede ser útil para evitar la detección por sistemas que monitorizan el tráfico ARP.
-Q, --quiet
Suprime la salida de los mensajes de progreso y los mensajes de error que no son críticos. Útil para scripts.
-V, --verbose
Activa la salida detallada. Imprime más información sobre lo que está haciendo el programa.
-F, --full
Intenta obtener una respuesta ARP completa para cada host. Esto significa enviar una petición ARP con una dirección MAC de destino inválida (00:00:00:00:00:00) y la dirección IP del objetivo. Esto hará que el host objetivo responda con su dirección MAC. Esto solo funciona si el host objetivo está activo y configurado para responder a este tipo de peticiones.
-H, --hwaddr
Carga la lista de hosts y sus direcciones MAC desde el archivo especificado con la opción -f. La información de la dirección MAC debe estar en el mismo formato que se usa en la salida de arp-scan (por ejemplo, 00:11:22:33:44:55). Si la dirección MAC no se proporciona, se usará una dirección MAC ficticia.
-W segundos, --vendor=segundos
Establece el tiempo de espera para la carga de la base de datos de proveedores a segundos. El valor predeterminado es 2.
-M modelo, --mac=modelo
Establece el modelo de dispositivo asociado con la dirección MAC de origen. Esto se utiliza para la decodificación del proveedor cuando se utiliza la opción --hwaddr.
-O, --only-sender
Solo muestra las respuestas del remitente (es decir, hosts que responden a la petición ARP). En lugar de mostrar las respuestas de todos los hosts, solo se mostrarán aquellos que respondieron activamente.
-A, --active
Mostrar solo hosts que respondieron a la petición ARP.
-E, --exclude
Excluye hosts especificados de la lista de objetivos. Los hosts a excluir se especifican en la línea de comandos después de esta opción, separados por comas.
-x, --xterm
Muestra la salida en un formato más detallado, adecuado para su visualización en una terminal xterm. Cada campo se muestra en una línea separada.
-c, --csv
Muestra la salida en formato CSV.
-j, --json
Muestra la salida en formato JSON.
-p, --noprint
No imprimir ninguna salida. Esta opción se utiliza normalmente junto con la opción -w para escribir la salida en un archivo.
-w archivo, --write=archivo
Escribe la salida en el archivo especificado en lugar de a la salida estándar. Si se utiliza con la opción -p, no se imprimirá nada en la salida estándar.
-D, --debug
Activa la depuración. Imprime información detallada sobre el paquete enviado y recibido.
-Z, --log
Registra los paquetes de red enviados y recibidos en un archivo pcap. El nombre del archivo se genera automáticamente (por ejemplo, arp-scan_YYYYMMDD_HHMMSS.pcap).
--arpXXX
Las opciones --arphrd, --arppro, --arphln, --arppln, --arpop, --arpsha, --arpspa, y --arptha se utilizan para modificar los campos del paquete de petición ARP. Vea la sección DESCRIPCIÓN para más detalles.
--destaddr
Establece la dirección Ethernet de destino. Vea la sección DESCRIPCIÓN para más detalles.
--srcaddr
Establece la dirección MAC de origen en la cabecera Ethernet.
--prototype
Establece el tipo de protocolo en la cabecera Ethernet.
--format=formato
Especifica el formato de salida. El formato predeterminado es <ipv4><tab><mac><tab><vendor>. Las cadenas de formato válidas son: ipv4, mac, vendor, vendor-or-mac, interface, ip-and-mac, ip-and-vendor, ip-mac-and-vendor, all. Puede usarse para especificar el formato de la salida, por ejemplo, --format='ipv4:mac:vendor'.

EJEMPLOS

Para escanear todos los hosts de la subred local:

arp-scan --localnet

Para escanear una lista de hosts desde un archivo:

arp-scan --file hosts.txt

Para escanear un rango de direcciones IP:

arp-scan 192.168.1.100-192.168.1.200

Para escanear una red CIDR:

arp-scan 10.0.0.0/24

Para escanear hosts específicos:

arp-scan 192.168.1.1 192.168.1.50

Para escanear la subred local y solo mostrar los hosts activos:

arp-scan --localnet --active

Para escanear la subred local y mostrar la salida en formato CSV:

arp-scan --localnet --csv

Para escanear la subred local y especificar la interfaz:

arp-scan --interface eth1 --localnet

Para escanear la subred local con un ancho de banda menor:

arp-scan --localnet --bandwidth 64000

Para escanear la subred local con un intervalo de 100 microsegundos entre paquetes:

arp-scan --localnet --interval 100

Para escanear la subred local y reintentar solo una vez:

arp-scan --localnet --retry 1

Para escanear la subred local y no reintentar en caso de no respuesta:

arp-scan --localnet --retry 0

Para escanear la subred local y usar una dirección IP de origen diferente:

arp-scan --localnet --arpspa 192.168.1.10

Para escanear la subred local y enviar paquetes con la dirección Ethernet de destino 00:11:22:33:44:55:

arp-scan --localnet --destaddr 00:11:22:33:44:55

Para escanear la subred local y obtener una respuesta ARP completa (si es posible):

arp-scan --localnet --full

Para escanear la subred local y excluir las direcciones 192.168.1.1 y 192.168.1.254:

arp-scan --localnet --exclude 192.168.1.1,192.168.1.254

Para escanear la subred local y guardar la salida en un archivo:

arp-scan --localnet --write output.txt

Para escanear la subred local y registrar los paquetes de red en un archivo pcap:

arp-scan --localnet --log

OPCIONES

Donde una opción toma un valor, ese valor se especifica como una letra entre corchetes angulares. La letra indica el tipo de datos que se espera:

<s>
Cadena de caracteres.
<i>
Entero decimal, o hexadecimal si va precedido por 0x, por ejemplo, 2048 o 0x800.
<f>
Número decimal de punto flotante.
<m>
Dirección MAC, por ejemplo, 01:23:45:67:89:ab o 01-23-45-67-89-ab (sin distinguir entre mayúsculas y minúsculas)
<a>
Dirección IPv4, por ejemplo, 10.0.0.1
<h>
Datos binarios codificados en hexadecimal. Sin prefijo 0x. (sin distinguir entre mayúsculas y minúsculas).
<x>
Algo más - consulte la descripción de la opción.

Opciones Generales

--help o -h
Muestra este mensaje de uso y sale.
--verbose o -v
Muestra mensajes de progreso detallados. Se puede usar varias veces para aumentar la verbosidad. Máximo=3.
--version o -V
Muestra la versión del programa y sale. Muestra la versión, los detalles de la licencia, la versión de libpcap y si se incluye compatibilidad con capacidades POSIX.1e.
--interface=<s> o -I <s>
Utiliza la interfaz de red <s>. Si esta opción no se especifica, arp-scan buscará en la lista de interfaces del sistema la interfaz configurada como activa con el número más bajo (excluyendo el loopback).

Selección de Hosts

--file=<s> o -f <s>
Lee nombres de host o direcciones del archivo especificado. Un nombre o patrón de dirección por línea. Usa "-" para stdin.
--localnet o -l
Genera direcciones a partir de la configuración de la interfaz. Genera la lista a partir de la dirección e máscara de red de la interfaz (incluyendo la red y la difusión). No puedes usar la opción --file ni proporcionar objetivos en la línea de comandos. Usa --interface para especificar la interfaz.

Archivos de Mapeo de MAC/Vendedor

--ouifile=<s> o -O <s>
Utiliza el archivo de mapeo de vendedores del registro IEEE <s>. El valor predeterminado es ieee-oui.txt en el directorio actual. Si no se encuentra o no se puede abrir, se utiliza /usr/share/arp-scan/ieee-oui.txt.
--macfile=<s> o -m <s>
Utiliza el archivo de mapeo de vendedores personalizado <s>. El valor predeterminado es mac-vendor.txt en el directorio actual. Si no se encuentra o no se puede abrir, se utiliza /etc/arp-scan/mac-vendor.txt.

Control del Formato de Salida

--quiet o -q
Muestra una salida mínima para cada host que responde. Solo se muestran la dirección IP y la dirección MAC. Reduce el uso de memoria en aproximadamente 5 MB porque no se utilizan los archivos de mapeo de vendedores. Solo los campos ${ip} y ${mac} están disponibles para la opción --format si se especifica --quiet.
--plain o -x
Suprime el texto de encabezado y pie de página. Solo muestra los detalles del host que responde. Útil si la salida será analizada por un script.
--ignoredups o -g
No muestres paquetes duplicados. Por defecto, los paquetes duplicados se marcan con (DUP: n) donde n es el número de veces que este host ha respondido.
--rtt o -D
Calcula y muestra el tiempo de ida y vuelta del paquete. El tiempo se muestra en milisegundos y microsegundos fraccionarios. Hace que el campo ${rtt} esté disponible para --format.
--format=<s> o -F <s>
Especifica la cadena de formato de salida. El formato es una cadena que se mostrará para cada host que responda. Los detalles del host se pueden incluir insertando referencias a campos usando la sintaxis "${campo[;ancho]}". Los campos se muestran alineados a la derecha a menos que el ancho sea negativo, en cuyo caso se utilizará alineación a la izquierda. Se reconocen los siguientes nombres de campo (sin distinguir entre mayúsculas y minúsculas):
IP Dirección IPv4 del host en formato cuádruple con puntos
Name Nombre del host si se proporciona la opción --resolve
MAC Dirección MAC del host xx:xx:xx:xx:xx:xx
HdrMAC Dirección de origen Ethernet si es diferente
Vendor Cadena de detalles del vendedor
Padding Relleno después del paquete ARP en hexadecimal si es distinto de cero
Framing Tipo de encapsulación si no es Ethernet_II
VLAN ID de VLAN 802.1Q si está presente
Proto Protocolo ARP si no es 0x0800
DUP Número de paquete para paquetes duplicados (>1)
RTT Tiempo de ida y vuelta si se proporciona la opción --rtt

Solo los campos ${ip} y ${mac} están disponibles si se especifica la opción --quiet.

Cualquier carácter que no sean campos se muestra verbatim. "\" introduce escapes:

\n nueva línea
\r retorno de carro
\t tabulador
\ suprime el significado especial del carácter siguiente

Deberías encerrar el argumento de --format entre 'comillas simples' para proteger los caracteres especiales del shell.

Ejemplo: --format='${ip}\t${mac}\t${vendor}'

Aleatorización de la Lista de Hosts

--random o -R
Aleatoriza la lista de hosts objetivo.
--randomseed=<i>
Siembra el generador de números pseudoaleatorios. Útil si deseas un orden reproducible de --random.

Temporización de Salida y Reintentos

--retry=<i> o -r <i>
Establece el número total de intentos por host a <i>, predeterminado=2.
--backoff=<f> o -b <f>
Establece el factor de retroceso a <f>, predeterminado=1.50. Multiplica el tiempo de espera por <f> por cada pase.
--timeout=<i> o -t <i>
Establece el tiempo de espera inicial por host a <i> ms, predeterminado=500. Este tiempo de espera es para el primer paquete enviado a cada host. Los tiempos de espera posteriores se multiplican por el factor de retroceso que se establece con --backoff.
--interval=<x> o -i <x>
Establece el intervalo mínimo de paquetes a <x>. Esto controla el uso de ancho de banda saliente limitando la tasa de paquetes. Si desea utilizar hasta un ancho de banda determinado, es más fácil usar la opción --bandwidth en su lugar. El intervalo está en milisegundos, o microsegundos si se añade "u".
--bandwidth=<x> o -B <x>
Establece el ancho de banda de salida a <x>, predeterminado=256000. El valor está en bits por segundo. Añade K para kilobits o M para megabits (múltiplos decimales). No puedes especificar tanto --interval como --bandwidth.

Resolución DNS

--numeric o -N
Los objetivos deben ser direcciones IP, no nombres de host. Puede reducir el tiempo de inicio para listas de objetivos grandes.
--resolve o -d
Resuelve las direcciones que responden a nombres de host. El formato de salida predeterminado mostrará el nombre de host en lugar de la dirección IPv4. Esta opción hace que el campo ${name} esté disponible para la opción --format.

Salida del Paquete ARP

--arpsha=<m> o -u <m>
Establece la dirección Ethernet de origen ARP. Establece el campo de 48 bits ar$sha pero no cambia la dirección de hardware en el encabezado del marco, ver --srcaddr para cómo cambiar esa dirección. El valor predeterminado es la dirección Ethernet de la interfaz de salida.
--arptha=<m> o -w <m>
Establece la dirección Ethernet de destino ARP. Establece el campo de 48 bits ar$tha. El valor predeterminado es cero, ya que este campo no se utiliza para paquetes de solicitud ARP.
--arphrd=<i> o -H <i>
Establece el tipo de hardware ARP, predeterminado=1. Establece el campo de 16 bits ar$hrd. El valor predeterminado es 1 (ARPHRD_ETHER). Muchos sistemas operativos también responden a 6 (ARPHRD_IEEE802).
--a

.
--arppln=<i> o -P <i
>
Establece la longitud de la dirección de protocolo, por defecto=4. Establece el campo de 8 bits ar$pln. Las longitudes de los campos ar$spa y ar$tpa no se modifican con esta opción; solo cambia el campo ar$pln

Opciones

Varias
--limit=<i> o -M <i
>
Sale después de que el número especificado de hosts haya respondido. arp-scan saldrá con el estado 1 si el número de hosts que responden es menor que el límite. Puede usarse en scripts para comprobar si responden menos hosts sin tener que analizar la
salida.
--pcapsavefile=<s> o -W <s
>
Escribe los paquetes recibidos en el archivo de guardado pcap <s>. Las respuestas ARP se escribirán en el archivo especificado además de ser decodificadas y
mostradas.
