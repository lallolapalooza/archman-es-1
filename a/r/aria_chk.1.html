ARIA_CHK(1) User Commands ARIA_CHK(1)

NOMBRE

aria_chk - Utilidad de mantenimiento de tablas de Aria

SINOPSIS

aria_chk [OPCIONES] tablas[.MAI]

DESCRIPCIÓN

Describe, comprueba y repara tablas de Aria. Al usarse sin opciones, se comprobarán todas las tablas especificadas en la línea de comandos.

Opciones globales

-#, --debug=...
Salida del registro de depuración. A menudo es de la forma 'd:t:o,nombre_archivo'.
-H, --HELP
Imprime todas las opciones de argumentos ordenadas alfabéticamente.
-?, --help
Imprime todas las opciones por grupos
--datadir=ruta
Ruta para el archivo de control (y registros si no se usa --logdir)
--logdir=ruta
Ruta para los archivos de registro
--ignore-control-file
No abrir el archivo de control. ¡Solo use esta opción si está seguro de que las tablas no están en uso por otro programa!
--require-control-file
Abortar si no se puede encontrar/leer el archivo maria_log_control
-s, --silent
Solo imprime errores. Se puede usar dos veces -s para hacer que maria_chk sea muy silencioso.
-t, --tmpdir=ruta
Ruta para archivos temporales. Se pueden especificar varias rutas, separadas por dos puntos (:), se usarán de forma rotatoria.
-v, --verbose
Imprime más información. Esto se puede usar con --description y --check. Use varios -v para más verbosidad.
-V, --version
Imprime la versión y sale.
-w, --wait
Espera si la tabla está bloqueada.

Opciones de comprobación (comprobar es la acción predeterminada de aria_chk)

-c, --check
Comprueba la tabla en busca de errores.
-e, --extend-check
Comprueba la tabla MUY a fondo. Solo usa esta opción en casos extremos, ya que aria_chk normalmente debería poder determinar si la tabla está bien sin este modificador.
-F, --fast
Comprueba solo las tablas que no se han cerrado correctamente.
-C, --check-only-changed
Comprueba solo las tablas que han cambiado desde la última comprobación.
-f, --force
Reinicia con '-r' si hay algún error en la tabla. Los estados se actualizarán como con '--update-state'.
-i, --information
Imprime información estadística sobre la tabla que se está comprobando.
-m, --medium-check
Más rápido que extend-check, pero solo encuentra el 99.99% de todos los errores. Debería ser suficiente para la mayoría de los casos.
-T, --read-only
No marcar la tabla como comprobada.
-U, --update-state
Marca las tablas como caídas si se encuentran errores y limpias si la comprobación no encontró errores pero la tabla estaba marcada como 'no limpia' anteriormente. Esto permite deshacerse de advertencias como 'tabla no cerrada correctamente'. Si la tabla se actualizó, actualiza también la marca de tiempo de cuándo se realizó la comprobación. ¡Esta opción está activada por defecto! Usa --skip-update-state para deshabilitarla.

--warning-for-wrong-transaction-id

Emite una advertencia si encontramos un ID de transacción en la tabla que es mayor que el que existe en el archivo de control. Usa --skip-... para deshabilitar la advertencia.

Opciones de recuperación (reparación) (al usar '--recover' o '--safe-recover')

-B, --backup
Crea una copia de seguridad del archivo .MAD como 'nombre_archivo-tiempo.BAK'.
--correct-checksum
Corrige la información de suma de verificación para la tabla.
-D, --data-file-length=#
Longitud máxima del archivo de datos (al recrear el archivo de datos cuando está lleno).
-e, --extend-check
Intenta recuperar cada fila posible del archivo de datos. Normalmente, esto también encontrará muchas filas basura; no uses esta opción si no estás totalmente desesperado.
-f, --force
Sobrescribe archivos temporales antiguos.
-k, --keys-used=#
Indica a Aria que actualice solo algunas claves específicas. # es una máscara de bits de las claves a usar. Esto se puede usar para acelerar las inserciones.
--max-record-length=#
Omite filas más grandes que esto si aria_chk no puede asignar memoria para contenerlas.
-r, --recover
Puede arreglar casi todo excepto las claves únicas que no son únicas.
-n, --sort-recover
Fuerza la recuperación con ordenación, incluso si el archivo temporal fuera muy grande.
-p, --parallel-recover
Utiliza la misma técnica que '-r' y '-n', pero crea todas las claves en paralelo, en diferentes hilos.
-o, --safe-recover
Utiliza el método de recuperación antiguo; es más lento que '-r', pero puede manejar un par de casos en los que '-r' informa que no puede reparar el archivo de datos.
--transaction-log
Registra el comando de reparación en el registro de transacciones. Esto es necesario si se quiere usar aria_read_log para repetir la reparación.
--character-sets-dir=...
Directorio donde se encuentran los conjuntos de caracteres.
--set-collation=nombre
Cambia la colación utilizada por el índice.
-q, --quick
Reparación más rápida al no modificar el archivo de datos. Se puede dar una segunda '-q' para forzar a aria_chk a modificar el archivo de datos original en caso de claves duplicadas. NOTA: Las tablas cuyo archivo de datos esté corrupto no se pueden reparar con esta opción.
-u, --unpack
Descomprime un archivo empaquetado con ariapack.

Otras acciones

-a, --analyze
Analiza la distribución de las claves. Hará que algunas uniones en MariaDB sean más rápidas. Puedes comprobar la distribución calculada usando '--description --verbose nombre_tabla'.
--stats_method=nombre
Especifica cómo el código de recopilación de estadísticas de índices debe tratar los NULL. Los valores posibles de nombre son "nulls_unequal" (predeterminado para 4.1/5.0), "nulls_equal" (emula 4.0) y "nulls_ignored".
-d, --description
Imprime información sobre la tabla.
-A, --set-auto-increment[=valor]
Fuerza a auto_increment a empezar en este valor o superior. Si no se proporciona valor, establece el siguiente valor de auto_increment al valor más alto usado para la clave automática + 1.
-S, --sort-index
Ordena los bloques de índices. Esto acelera la 'lectura siguiente' en las aplicaciones.
-R, --sort-records=#
>
Ordena los registros según un índice. Esto localiza mucho más tus datos y puede acelerar las cosas (¡Puede ser MUY lento hacer una ordenación la primera vez!).
-b, --block-search=#
Encuentra un registro al que pertenece un bloque en un desplazamiento dado.
-z, --zerofill
Rellena el espacio vacío en los archivos de datos e índices con ceros. Esto hace que el archivo de datos sea movible entre diferentes servidores.
--zerofill-keep-lsn
Como --zerofill pero no pone a cero el LSN de las páginas de datos/índices.

Variables

--page_buffer_size=#
Tamaño del búfer de página. Usado por --safe-repair
--read_buffer_size=#
Tamaño del búfer de lectura para lecturas secuenciales durante el escaneo
--sort_buffer_size=#
Tamaño del búfer de ordenación. Usado por --recover
--sort_key_blocks=#
Búfer interno para ordenar claves; No lo toques.
--write_buffer_size=#
Tamaño del búfer de escritura para escrituras secuenciales durante la reparación

Las opciones predeterminadas se leen de los siguientes archivos en el orden dado: /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf

Se leen los siguientes grupos: aria_chk

Las siguientes opciones pueden darse como primer argumento:

--print-defaults
Imprime la lista de argumentos del programa y sale.
--no-defaults
No lea las opciones predeterminadas de ningún archivo de opciones.
--defaults-file=#
Lee las opciones predeterminadas solo del archivo # dado.
--defaults-extra-file=#
Lee este archivo después de que se hayan leído los archivos globales.
