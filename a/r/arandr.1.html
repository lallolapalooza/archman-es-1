Nombre

arandr - interfaz gráfica para XRandR 1.2

SINOPSIS

arandr [archivo_guardado]

DESCRIPCIÓN

ARandR es una interfaz gráfica para XRandR 1.2 (opciones por pantalla), que proporciona control total sobre el posicionamiento, guardado y carga a/desde scripts de shell y fácil integración con otras aplicaciones.

--version
muestra la versión del programa y sale
-h, --help
muestra este mensaje de ayuda y sale
--randr-display=D
Utiliza D como pantalla para xrandr (pero aún así muestra la GUI en la pantalla del entorno; por ejemplo, localhost:10.0)
--force-version
Ejecutar incluso con versiones de XRandR no probadas

VER TAMBIÉN

man 1 xrandr
