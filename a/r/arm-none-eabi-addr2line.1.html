ADDR2LINE(1) Herramientas de desarrollo GNU ADDR2LINE(1)

NOMBRE

addr2line - convierte direcciones o símbolo+desplazamiento en nombres de archivo y números de línea

SINOPSIS

addr2line [-a|--addresses]
[-b nombrebfd|--target=nombrebfd]
[-C|--demangle[=estilo]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e archivo|--exe=archivo]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nombre]
[-H|--help] [-V|--version]
[dir dir ...]

DESCRIPCIÓN

addr2line traduce direcciones o símbolo+desplazamiento a nombres de archivo y números de línea. Dada una dirección o símbolo+desplazamiento en un ejecutable o un desplazamiento en una sección de un objeto relocable, utiliza la información de depuración para determinar qué nombre de archivo y número de línea están asociados con él.

El ejecutable u objeto relocable a usar se especifica con la opción -e. El valor predeterminado es el archivo a.out. La sección en el objeto relocable a usar se especifica con la opción -j.

addr2line tiene dos modos de operación.

En el primero, se especifican direcciones hexadecimales o símbolo+desplazamiento en la línea de comandos, y addr2line muestra el nombre del archivo y el número de línea para cada dirección.

En el segundo, addr2line lee direcciones hexadecimales o símbolo+desplazamiento de la entrada estándar, e imprime el nombre del archivo y el número de línea para cada dirección en la salida estándar. En este modo, addr2line puede usarse en una tubería para convertir direcciones seleccionadas dinámicamente.

El formato de la salida es NOMBREARCHIVO:NUMEROLINEA. Por predeterminado, cada dirección de entrada genera una línea de salida.

Dos opciones pueden generar líneas adicionales antes de cada línea de NOMBREARCHIVO:NUMEROLINEA (en ese orden).

Si se utiliza la opción -a, se muestra una línea con la dirección de entrada.

Si se utiliza la opción -f, se muestra una línea con el NOMBREFUNCION. Este es el nombre de la función que contiene la dirección.

Una opción puede generar líneas adicionales después de la línea NOMBREARCHIVO:NUMEROLINEA.

Si se utiliza la opción -i y el código en la dirección dada está presente allí debido a la interpolación (inlining) por parte del compilador, entonces se mostrarán líneas adicionales después. Se muestran una o dos líneas adicionales (si se usa la opción -f) para cada función interpolada.

Alternativamente, si se utiliza la opción -p, cada dirección de entrada genera una única línea de salida larga que contiene la dirección, el nombre de la función, el nombre del archivo y el número de línea. Si también se ha utilizado la opción -i, cualquier función interpolada se mostrará de la misma manera, pero en líneas separadas y precedidas por el texto (interpolado por).

Si el nombre del archivo o el nombre de la función no se pueden determinar, addr2line imprimirá dos signos de interrogación en su lugar. Si el número de línea no se puede determinar, addr2line imprimirá 0.

Cuando se usa símbolo+desplazamiento, +desplazamiento es opcional, excepto cuando el símbolo es ambiguo con un número hexadecimal. Los símbolos resueltos pueden estar o no mangled (codificados), excepto que los símbolos no mangled con + no están permitidos.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-a
--addresses
Muestra la dirección antes de la información del nombre de la función, archivo y número de línea. La dirección se imprime con un prefijo 0x para identificarla fácilmente.
-b nombrebfd
--target=nombrebfd
Especifica que el formato del código objeto para los archivos objeto es nombrebfd.
-C
--demangle[=estilo]
Decodifica (demangle) los nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar el guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones de C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El estilo de decodificación opcional puede usarse para elegir un estilo de decodificación apropiado para su compilador.
-e archivo
--exe=archivo
Especifica el nombre del ejecutable para el cual se traducirán las direcciones. El archivo predeterminado es a.out.
-f
--functions
Muestra los nombres de las funciones, así como la información del archivo y el número de línea.
-s
--basenames
Muestra solo la parte base (nombre del archivo sin la ruta) de cada nombre de archivo.
-i
--inlines
Si la dirección pertenece a una función que fue interpolada (inlined), también se imprimirá la información fuente de todos los ámbitos envolventes hasta la primera función no interpolada. Por ejemplo, si "main" interpola "callee1" que interpola "callee2", y la dirección es de "callee2", también se imprimirá la información fuente de "callee1" y "main".
-j
--section
Lee los desplazamientos relativos a la sección especificada en lugar de las direcciones absolutas.
-p
--pretty-print
Hace que la salida sea más amigable para el humano: cada ubicación se imprime en una línea. Si se especifica la opción -i, las líneas de todos los ámbitos envolventes se prefijan con (interpolado por).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio en la pila disponible en la máquina host, provocando una falla de memoria. El límite intenta evitar que esto suceda al restringir la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible un agotamiento de la pila y cualquier informe de error sobre tal evento será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

Tenga en cuenta que esta opción solo es efectiva si se ha habilitado la opción -C o --demangle.

@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción @archivo original. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en archivo están separadas por espacios en blanco. Se puede incluir un carácter de espacio en blanco en una opción rodeando toda la opción con comillas simples o dobles. Se puede incluir cualquier carácter (incluido una barra invertida) anteponiendo el carácter a incluir con una barra invertida. El archivo puede contener opciones @archivo adicionales; tales opciones se procesarán

ed

recursivamente.
