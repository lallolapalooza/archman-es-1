DESCRIPCIÓ

N

La función ares_dns_record_rr_cnt(3) devuelve el número de registros de recursos en el registro DNS proporcionado por el parámetro dnsrec para la sección proporcionada en el parámetro

sect.

La función ares_dns_record_rr_add(3) añade una nueva entrada de registro de recursos al registro DNS proporcionado por el parámetro dnsrec. El registro de recursos resultante se almacena en la variable a la que apunta rr_out. La sección DNS a la que pertenece el registro de recursos se especifica mediante el parámetro sect. El nombre de dominio asociado con el registro de recursos se especifica mediante el parámetro name, que no puede ser NULL pero puede ser una cadena vacía o ".". El tipo de registro de recursos se especifica en el parámetro type, junto con la clase del registro DNS en el parámetro rclass, y el Tiempo de Vida (TTL) en el parámetro

ttl.

La función ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) se utilizan para recuperar el puntero del registro de recursos del registro DNS proporcionado en el parámetro dnsrec, para la sección del registro de recursos proporcionada en el parámetro sect, para el índice especificado en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3). La primera devuelve un puntero escribible al registro de recursos, mientras que la segunda devuelve un puntero de solo lectura al registro de

recursos.

La función ares_dns_record_rr_del(3) se utiliza para eliminar un registro de recursos del registro DNS especificado en el parámetro dnsrec. Su uso principal es eliminar un registro ARES_REC_TYPE_OPT cuando se necesita reintentar una consulta sin soporte EDNS. La sección RR de DNS se especifica mediante el parámetro sect, y el índice a eliminar se especifica en el parámetro idx. El índice debe ser menor que ares_dns_record_r

r_cnt(3).

La función ares_dns_rr_get_name(3) se utiliza para recuperar el nombre de dominio del registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_type(3) se utiliza para recuperar el tipo de registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_class(3) se utiliza para recuperar la clase del registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_ttl(3) se utiliza para recuperar el Tiempo de Vida (TTL) de la clase del registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_set_addr(3) se utiliza para establecer una dirección IPv4 para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_INADDR. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

addr.

La función ares_dns_rr_set_addr6(3) se utiliza para establecer una dirección IPv6 para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_INADDR6. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

addr.

La función ares_dns_rr_set_str(3) se utiliza para establecer una cadena para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. La mayoría de las cadenas están limitadas a 255 bytes, sin embargo algunos registros, como un registro TXT, pueden permitir más ya que se emiten como múltiples cadenas. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u8(3) se utiliza para establecer un valor sin signo de 8 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U8. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u16(3) se utiliza para establecer un valor sin signo de 16 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U16. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u32(3) se utiliza para establecer un valor sin signo de 32 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U32. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_bin(3) se utiliza para establecer un valor binario para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro

len.

La función ares_dns_rr_add_abin(3) se utiliza para añadir un valor binario al array para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro

len.

La función ares_dns_rr_del_abin(3) se utiliza para eliminar un valor binario del array para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_ABINP.
