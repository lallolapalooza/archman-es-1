ARDOUR(1) Comandos de usuario ARDOUR(1)

NOMBRE

Ardour - estación de trabajo de audio digital

SINOPSIS

ardour [ OPCIONES ] [ NOMBRE-SESION ]

DESCRIPCIÓN

Ardour es una grabadora de disco duro multicanal (HDR) y estación de trabajo de audio digital (DAW).

OPCIONES

-a, --no-announcements
No contactar al sitio web para anuncios
-A, --actions
Imprimir todos los nombres de acciones de menú posibles
-b, --bindings
Mostrar todas las asignaciones de teclas actuales
-B, --bypass-plugins
Omitir todos los plugins en una sesión existente
-c, --name <nombre>
Usar un nombre de cliente de backend específico, el predeterminado es ardour
-d, --disable-plugins
Desactivar todos los plugins (modo seguro)
-D, --debug <opciones>
Establecer indicadores de depuración. Use "-D list" para ver las opciones disponibles
-h, --help
Imprimir este mensaje
-k, --keybindings <archivo>
Ruta al archivo de asignaciones de teclas a cargar
-m, --menus archivo
Usar "archivo" para definir menús
-n, --no-splash
No mostrar la pantalla de presentación
-N, --new nombre-sesión
Crear una nueva sesión desde la línea de comandos
-O, --no-hw-optimizations
Desactivar optimizaciones específicas de hardware
-P, --no-connect-ports
No conectar ningún puerto al inicio
-S, --sync
Dibujar la GUI de forma síncrona
-T, --template <nombre>
Usar la plantilla dada para la nueva sesión
-v, --version
Imprimir la versión y salir

REPORTAR ERRORES

Reporte errores a https://tracker.ardour.org
Sitio web https://ardour.org
