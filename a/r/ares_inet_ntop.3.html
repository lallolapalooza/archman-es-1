NOMBRE

ares_inet_ntop - convertir una dirección en formato de red a formato de presentación

SINOPSIS

#include <ares.h>
const char *ares_inet_ntop(int af, const void *src, char *dst,
                           ares_socklen_t size);

DESCRIPCIÓN

Esta es una versión portátil con la funcionalidad idéntica de la comúnmente disponible inet_ntop.

La función ares_inet_ntop() convierte una dirección numérica en una cadena de texto adecuada para presentación. El argumento af especificará la familia de la dirección. Puede ser AF_INET o AF_INET6. El argumento src apunta a un búfer que contiene una dirección IPv4 si el argumento af es AF_INET, o una dirección IPv6 si el argumento af es AF_INET6; la dirección debe estar en orden de bytes de red. El argumento dst apunta a un búfer donde la función almacena la cadena de texto resultante; no debe ser NULL. El argumento size especifica el tamaño de este búfer, que debe ser lo suficientemente grande para contener la cadena de texto (INET_ADDRSTRLEN (16) caracteres para IPv4, INET6_ADDRSTRLEN (46) caracteres para IPv6).

VER TAMBIÉN

ares_init(3), ares_inet_pton(3)
