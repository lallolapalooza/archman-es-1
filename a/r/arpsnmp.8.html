ARPSNMP(8) Manual del Administrador del Sistema ARPSNMP(8)

NOMBRE

arpsnmp — mantener un registro de las asociaciones de direcciones ethernet/ip

SINOPSIS

arpsnmp [-dqs] [-D arpdir] [-f datafile] [-w watcher@email] [-W watchee@email] archivo ...

DESCRIPCIÓN

arpsnmp mantiene un registro de las asociaciones de direcciones ethernet/ip. Registra la actividad en el sistema y reporta ciertos cambios por correo electrónico. arpsnmp lee información de un archivo (generalmente generado por snmpwalk(3)).

El formato del archivo de entrada es el mismo que arp.dat; la dirección MAC, la dirección IP, la marca de tiempo opcional y el nombre de host simple opcional. Si falta la marca de tiempo, se utiliza la fecha actual.

arpsnmp también se puede utilizar para fusionar archivos. Si la misma asociación de dirección ethernet/ip ocurre en más de un archivo, se guarda la marca de tiempo de la última vez que se vio.

La bandera -C utiliza direcciones ethernet acolchadas compactas en arp.dat, por ejemplo, 0:8:e1:1:2:d6.

La bandera -d se utiliza para habilitar la depuración. Esto también inhibe el envío de informes por correo electrónico. En su lugar, se envían a stderr.

La bandera -D se utiliza para especificar el directorio de trabajo. Por defecto es /usr/local/arpwatch.

La bandera -f se utiliza para establecer el nombre del archivo de la base de datos de direcciones ethernet/ip. El valor predeterminado es arp.dat.

Tenga en cuenta que se debe crear un archivo vacío antes de ejecutar por primera vez

La bandera -q suprime la generación de informes en el registro o la impresión en stderr.

La bandera -s suprime los informes enviados por correo electrónico.

La bandera -w se utiliza para especificar la dirección de destino para los informes de correo electrónico. El valor predeterminado es root.

La bandera -W se utiliza para especificar la dirección de origen para los informes de correo electrónico. El valor predeterminado es root.

La bandera -Z utiliza direcciones ethernet con ceros iniciales en arp.dat, por ejemplo, 00:08:e1:01:02:d6.

MENSAJES DE INFORME

Consulte la página del manual de arpwatch(1) para obtener detalles sobre los mensajes de informe generados por arpsnmp(1).
