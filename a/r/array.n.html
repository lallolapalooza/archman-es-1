DESCRIPCIÓ

N

Este comando realiza una de varias operaciones sobre la variable dada por nombreDeArray. A menos que se especifique lo contrario para comandos individuales a continuación, nombreDeArray debe ser el nombre de una variable de tipo array existente. El argumento opción determina qué acción realiza el comando. Las opciones legales (que pueden abreviarse)

son:
array anymore nombreDeArray
searchId
Devuelve 1 si quedan más elementos por procesar en una búsqueda de array, 0 si todos los elementos ya han sido devueltos. SearchId indica qué búsqueda sobre nombreDeArray comprobar, y debe haber sido el valor de retorno de una invocación anterior de array startsearch. Esta opción es particularmente útil si un array tiene un elemento con un nombre vacío, ya que el valor de retorno de array nextelement no indicará si la búsqueda ha sido
completada.
array donesearch nombreDeArray
searchId
Este comando termina una búsqueda de array y destruye todo el estado asociado con esa búsqueda. SearchId indica qué búsqueda sobre nombreDeArray destruir, y debe haber sido el valor de retorno de una invocación anterior de array startsearch. Devuelve una cadena
vacía.
array exists nombreDeAr
ray
Devuelve 1 si nombreDeArray es una variable de tipo array, 0 si no existe una variable con ese nombre o si es una variable
escalar.
array get nombreDeArray ?patró
n?
Devuelve una lista que contiene pares de elementos. El primer elemento de cada par es el nombre de un elemento en nombreDeArray y el segundo elemento de cada par es el valor del elemento del array. El orden de los pares es indefinido. Si patrón no se especifica, entonces todos los elementos del array se incluyen en el resultado. Si patrón se especifica, entonces solo se incluyen aquellos elementos cuyos nombres coinciden con patrón (usando las reglas de coincidencia de string match). Si nombreDeArray no es el nombre de una variable de tipo array, o si el array no contiene elementos, entonces se devuelve una lista vacía. Si las trazas en el array modifican la lista de elementos, los elementos devueltos son aquellos que existen tanto antes como después de la llamada a array g
et.
array names nombreDeArray ?modo? ?patró
n?
Devuelve una lista que contiene los nombres de todos los elementos del array que coinciden con patrón. Modo puede ser uno de -exact, -glob, o -regexp. Si se especifica, modo designa qué reglas de coincidencia usar para hacer coincidir patrón con los nombres de los elementos en el array. Si no se especifica, modo por defecto es -glob. Consulte la documentación de string match para información sobre coincidencia de estilo glob, y la documentación de regexp para información sobre coincidencia regexp. Si patrón se omite, entonces el comando devuelve todos los nombres de elementos en el array. Si no hay elementos (coincidentes) en el array, o si nombreDeArray es el nombre de una variable de tipo array, entonces se devuelve una cadena
vacía.
array nextelement nombreDeArray
searchId
Devuelve el nombre del siguiente elemento en nombreDeArray, o una cadena vacía si todos los elementos de nombreDeArray ya han sido devueltos en esta búsqueda. El argumento searchId identifica la búsqueda, y debe haber sido el valor de retorno de un comando array startsearch. Advertencia: si se añaden elementos al array o se eliminan de él, entonces todas las búsquedas se terminan automáticamente como si se hubiera invocado array donesearch; esto hará que las operaciones de array nextelement fallen para esas
búsquedas.
array set nombreDeArray
lista
Establece los valores de uno o más elementos en nombreDeArray. lista debe tener una forma como la devuelta por array get, consistente en un número par de elementos. Cada elemento de número impar en lista se trata como un nombre de elemento dentro de nombreDeArray, y el elemento siguiente en lista se usa como un nuevo valor para ese elemento del array. Si la variable nombreDeArray no existe ya y lista está vacía, nombreDeArray se crea con un valor de array
vacío.
array size nombreDeAr
ray
Devuelve una cadena decimal que indica el número de elementos en el array. Si nombreDeArray no es el nombre de un array, entonces se devuelve
0.
array startsearch nombreDeAr
ray
Este comando inicializa una búsqueda elemento por elemento a través del array dado por nombreDeArray, de modo que las invocaciones del comando array nextelement devolverán los nombres de los elementos individuales en el array. Cuando la búsqueda haya sido completada, se debe invocar el comando array donesearch. El valor de retorno es un identificador de búsqueda que debe usarse en array nextelement y array donesearch; permite que múltiples búsquedas estén en curso simultáneamente para el mismo array. Actualmente es más eficiente y más fácil usar ya sea array get o array names, junto con foreach, para iterar sobre todos los arrays excepto los muy grandes. Vea los ejemplos a continuación para saber cómo hacer
esto.
array statistics nombreDeAr
ray
Devuelve estadísticas sobre la distribución de datos dentro de la tabla hash que representa el array. Esta información incluye el número de entradas en la tabla, el número de cubetas, y la utilización de las
cubetas.
array unset nombreDeArray ?patró
n?
Elimina todos los elementos del array que coinciden con patrón (usando las reglas de coincidencia de string match). Si nombreDeArray no es el nombre de una variable de tipo array o no hay elementos coincidentes en el array, no se generará ningún error. Si patrón se omite y nombreDeArray es una variable de tipo array, entonces
el comando elimina el array c
ompleto. El comando siem
pre devuelve una cadena vacía.
