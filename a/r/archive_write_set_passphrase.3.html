NOMBRE

archive_write_set_passphrase, archive_write_set_passphrase_callback — funciones para escribir archivos cifrados

BIBLIOTECA

Biblioteca de Archivos en Streaming (libarchive, -larchive)

SINOPSIS

#include <archive.h>

int
archive_write_set_passphrase(struct archive *, const char *passphrase);

int
archive_write_set_passphrase_callback(struct archive *, void *client_data, archive_passphrase_callback *);

DESCRIPCIÓN

archive_write_set_passphrase()
Establece una contraseña para escribir un archivo cifrado. Si passphrase es NULL o está vacío, esta función no hará nada y se devolverá ARCHIVE_FAILED. De lo contrario, se devolverá ARCHIVE_OK.
archive_write_set_passphrase_callback()
Registra una función de devolución de llamada que se invocará para obtener una contraseña para el cifrado si la contraseña no fue establecida por la función archive_write_set_passphrase().

VER TAMBIÉN

tar(1), archive_write(3), archive_write_set_options(3), libarchive(3)
