ares_getaddrinfo(3)

Paquete: c-ares

Licencias: MIT

ARES_GETADDRINFO(3) Manual de Funciones de Biblioteca ARES_GETADDRINFO(3)

NOMBRE

ares_getaddrinfo - Inicia una consulta de host por nombre y servicio

SINOPSIS

#include <ares.h>
typedef void (*ares_addrinfo_callback)(void *arg, int status,
                                       int timeouts,
                                       struct ares_addrinfo *result)
void ares_getaddrinfo(ares_channel_t *channel, const char *name,
                      const char* service,
                      const struct ares_addrinfo_hints *hints,
                      ares_addrinfo_callback callback, void *arg)

DESCRIPCIÓN

La función ares_getaddrinfo(3) inicia una consulta de host por nombre en el canal de servicio de nombres identificado por channel. Los parámetros name y service proporcionan el nombre de host y el servicio como cadenas C terminadas en NULL. El parámetro hints es una estructura ares_addrinfo_hints :

struct ares_addrinfo_hints {
  int ai_flags;
  int ai_family;
  int ai_socktype;
  int ai_protocol;
};
ai_family
Especifica la familia de direcciones deseada. AF_UNSPEC significa devolver tanto AF_INET como AF_INET6.
ai_socktype
Especifica el tipo de socket deseado, por ejemplo SOCK_STREAM o SOCK_DGRAM. Establecer esto en 0 significa cualquier tipo.
ai_protocol
Establecer esto en 0 significa cualquier protocolo.
ai_flags
Especifica opciones adicionales, véase abajo.
ARES_AI_NUMERICSERV
Si esta opción está establecida, el campo service
se tratará como un valor numérico.
ARES_AI_CANONNAME
La estructura ares_addrinfo devolverá una lista de nombres canónicos.
ARES_AI_NOSORT
Las direcciones resultantes no se ordenarán y no se intentará ninguna conexión a las direcciones resueltas.
ARES_AI_ENVHOSTS Leer la ruta del archivo hosts desde la variable de entorno

CARES_HOSTS . Cuando la consulta se completa o falla, la biblioteca ares invocarácallback . La finalización o el fallo de la consulta puede ocurrir inmediatamente, o puede ocurrir durante una llamada posterior aares_process(3) , ares_destroy(3) oares_cancel(3)

.

Cuando se llama al callback asociado, se llama con el bloqueo del canal, por lo que se debe tener cuidado para asegurar que cualquier procesamiento sea mínimo para prevenir bloqueos del canal DNS. El callback puede ser activado desde un hilo diferente a aquel que llamó aares_getaddrinfo(3)

. Para los integradores que ejecutan sus propios bucles de eventos y no usanARES_OPT_EVENT_THREAD

, se debe tener cuidado para asegurar que las listas de descriptores de archivo se actualicen inmediatamente dentro del bucle de eventos cuando se notifique. El argumento del callback arg se copia desde el argumento ares_getaddrinfo(3) arg. El argumento del callback status indica si la consulta tuvo éxito y, si no, cómo falló. Puede tener cualquiera de los siguientes valores:

ARES_SUCCESS
La búsqueda del host se completó con éxito.
ARES_ENOTIMP
La biblioteca ares no sabe cómo encontrar direcciones de tipo family.
ARES_ENOTFOUND
El nombre no fue encontrado.
ARES_ENOMEM
Se agotó la memoria.
ARES_ESERVICE
El nombre de servicio textual proporcionado no pudo ser resuelto a un puerto.
ARES_ECANCELLED
La consulta fue cancelada.
ARES_EDESTRUCTION
El canal de servicio de nombres channel está siendo destruido; la consulta no será completada.

En la finalización exitosa de la consulta, el argumento del callback result apunta a un struct ares_addrinfo que contiene dos listas enlazadas, una con las direcciones resueltas y otra con los nombres canónicos. También incluye el nombre oficial del host (análogo a gethostbyname() h_name).

struct ares_addrinfo {
  struct ares_addrinfo_cname *cnames;
  struct ares_addrinfo_node  *nodes;
  char *name;
};

La estructura ares_addrinfo_node es similar a addrinfo de RFC3493, pero sin canonname y con un campo ttl extra.

struct ares_addrinfo_node {
  int                        ai_ttl;
  int                        ai_flags;
  int                        ai_family;
  int                        ai_socktype;
  int                        ai_protocol;
  ares_socklen_t             ai_addrlen;
  struct sockaddr           *ai_addr;
  struct ares_addrinfo_node *ai_next;
};

La estructura ares_addrinfo_cname es una lista enlazada de registros CNAME donde ttl es un tiempo de vida, alias es una etiqueta del registro de recursos y name es un valor (nombre canónico) del registro de recursos. Véase RFC2181 10.1.1. Terminología CNAME.

struct ares_addrinfo_cname {
  int                         ttl;
  char                       *alias;
  char                       *name;
  struct ares_addrinfo_cname *next;
};

La memoria reservada tiene que ser eliminada por ares_freeaddrinfo(3).

El resultado se ordena de acuerdo con RFC6724 excepto:
- Regla 3 (Evitar direcciones obsoletas)
- Regla 4 (Preferir direcciones de origen)
- Regla 7 (Preferir transporte nativo)

Tenga en cuenta que la función intentará una conexión en cada una de las direcciones resueltas según RFC6724.

DISPONIBILIDAD
