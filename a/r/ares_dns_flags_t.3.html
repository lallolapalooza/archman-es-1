NOMBRE

ares_dns_class_t, ares_dns_flags_t, ares_dns_opcode_t, ares_dns_parse, ares_dns_rcode_t, ares_dns_record_create, ares_dns_record_destroy, ares_dns_record_get_flags, ares_dns_record_get_id, ares_dns_record_get_opcode, ares_dns_record_get_rcode, ares_dns_record_query_add, ares_dns_record_query_cnt, ares_dns_record_query_get, ares_dns_rec_type_t, ares_dns_write - Funciones de análisis, escritura, creación y destrucción de registros DNS.

SINOPSIS

#include <ares.h>
void ares_dns_record_destroy(ares_dns_record_t *dnsrec);
ares_status_t ares_dns_parse(const unsigned char *buf,
                             size_t buf_len, unsigned int flags,
                             ares_dns_record_t **dnsrec);
ares_status_t ares_dns_write(const ares_dns_record_t *dnsrec,
                             unsigned char **buf, size_t *buf_len);
ares_status_t ares_dns_record_create(ares_dns_record_t **dnsrec,
                                     unsigned short      id,
                                     unsigned short      flags,
                                     ares_dns_opcode_t   opcode,
                                     ares_dns_rcode_t    rcode);
ares_dns_record_t *ares_dns_record_duplicate(const ares_dns_record_t *dnsrec);
unsigned short ares_dns_record_get_id(const ares_dns_record_t *dnsrec);
ares_bool_t ares_dns_record_set_id(ares_dns_record_t *dnsrec,
                                   unsigned short id);
unsigned short ares_dns_record_get_flags(const ares_dns_record_t *dnsrec);
ares_dns_opcode_t ares_dns_record_get_opcode(const ares_dns_record_t *dnsrec);
ares_dns_rcode_t ares_dns_record_get_rcode(const ares_dns_record_t *dnsrec);

                                             size_t              idx,

                                             size_t              idx,
                                             ares_dns_rec_type_t qtype);
size_t ares_dns_record_query_cnt(const ares_dns_record_t *dnsrec);
ares_status_t ares_dns_record_query_get(const ares_dns_record_t *dnsrec,
                                        size_t idx, const char **name,

                                        ares_dns_class_t *qclass);

ENUMERACIONES

ares_dns_rec_type_t - Tipos de registros DNS manejados por c-ares. Algunos tipos de registro pueden ser válidos solo en peticiones, y otros pueden serlo solo en respuestas:

ARES_REC_TYPE_A - Dirección del host
ARES_REC_TYPE_NS - Servidor autoritativo
ARES_REC_TYPE_CNAME - Nombre canónico
ARES_REC_TYPE_SOA - Inicio de la zona de autoridad
ARES_REC_TYPE_PTR - Puntero a nombre de dominio
ARES_REC_TYPE_HINFO - Información del host
ARES_REC_TYPE_MX - Información de enrutamiento de correo
ARES_REC_TYPE_TXT - Cadenas de texto
ARES_REC_TYPE_SIG - RFC 2535. RFC 2931. Registro SIG
ARES_REC_TYPE_AAAA - RFC 3596. Dirección Ip6
ARES_REC_TYPE_SRV - RFC 2782. Selección de Servidor
ARES_REC_TYPE_NAPTR - RFC 3403. Puntero a Autoridad de Nomenclatura
ARES_REC_TYPE_OPT - RFC 6891. Opción EDNS0 (meta-RR). Registro Pseudo.
ARES_REC_TYPE_TLSA - RFC 6698. Autenticación Basada en DNS de Entidades Nombradas (DANE) Protocolo de Seguridad de Capa de Transporte (TLS): TLSA
ARES_REC_TYPE_SVCB - RFC 9460. Enlace de Servósito de Propósito General
ARES_REC_TYPE_HTTPS - - RFC 9460. Tipo de Enlace de Servicio para usar con HTTPS
ARES_REC_TYPE_ANY - Coincidencia comodín. No es una respuesta RR
ARES_REC_TYPE_URI - RFC 7553. Identificador de Recurso Uniforme
ARES_REC_TYPE_CAA - RFC 6844. Autorización de la Autoridad de Certificación
ARES_REC_TYPE_RAW_RR - Se usa como indicador de que el registro RR no se analiza, sino que se proporciona en formato de línea

ares_dns_class_t - Clases DNS para peticiones y respuestas:

ARES_CLASS_IN - Internet
ARES_CLASS_CHAOS - CHAOS
ARES_CLASS_HESOID - Hesoid [Dyer 87]
ARES_CLASS_NONE - RFC 2136
ARES_CLASS_ANY - Cualquier clase (solo peticiones)

ares_dns_opcode_t - Códigos de Operación de la Cabecera DNS:

ARES_OPCODE_QUERY - Consulta estándar
ARES_OPCODE_IQUERY - Consulta inversa. Obsoleta
ARES_OPCODE_STATUS - Consulta de estado del servidor de nombres
ARES_OPCODE_NOTIFY - Notificación de cambio de zona (RFC 1996)
ARES_OPCODE_UPDATE - Mensaje de actualización de zona (RFC 2136)

ares_dns_flags_t - Banderas de la Cabecera DNS:

ARES_FLAG_QR - QR. Si está establecida, es una respuesta
ARES_FLAG_AA - Respuesta Autoritativa. Si está establecida, es autoritativa
ARES_FLAG_TC - Truncamiento. Si está establecida, es una respuesta truncada
ARES_FLAG_RD - Recursión Deseada. Si está establecida, se desea recursión
ARES_FLAG_RA - Recursión Disponible. Si está establecida, el servidor soporta recursión
ARES_FLAG_AD - RFC 2065. El bit de Datos Auténticos indica en una respuesta que los datos incluidos han sido verificados por el servidor que los proporciona
ARES_FLAG_CD - RFC 2065. El bit de Comprobación Deshabilitada indica en una consulta que los datos no verificados son aceptables para el resolvedor que envía la consulta

ares_dns_rcode_t - Códigos de respuesta DNS del servidor:

ARES_RCODE_NOERROR - Éxito
ARES_RCODE_FORMERR - Error de formato. El servidor de nombres no pudo interpretar la consulta
ARES_RCODE_SERVFAIL - Fallo del Servidor. El servidor de nombres no pudo procesar esta consulta debido a un problema con el servidor de nombres
ARES_RCODE_NXDOMAIN - Error de Nombre. Significativo solo para respuestas de un servidor de nombres autoritativo, este código indica que el nombre de dominio referenciado en la consulta no existe.
ARES_RCODE_NOTIMP - No implementado. El servidor de nombres no soporta el tipo de consulta solicitado
ARES_RCODE_REFUSED - Rechazado. El servidor de nombres se niega a realizar la operación especificada por razones de política.
ARES_RCODE_YXDOMAIN - RFC 2136. Algún nombre que no debería existir, sí existe
ARES_RCODE_YXRRSET - RFC 2136. Algún RRset que no debería existir, sí existe
ARES_RCODE_NXRRSET - RFC 2136. Algún RRset que debería existir, no existe
ARES_RCODE_NOTAUTH - RFC 2136. El servidor no es autoritativo para la zona nombrada en la sección Zona.
ARES_RCODE_NOTZONE - RFC 2136. Un nombre usado en la sección de Prerrequisitos o de Actualización no está dentro de la zona denotada por la sección Zona.
ARES_RCODE_DSOTYPEI - RFC 8409. DSO-TYPE No implementado
ARES_RCODE_BADSIG - RFC 8945. Fallo en la Firma TSIG
ARES_RCODE_BADKEY - RFC 8945. Clave no reconocida
ARES_RCODE_BADTIME - RFC 8945. Firma fuera de la ventana de tiempo
ARES_RCODE_BADMODE - RFC 2930. Modo TKEY incorrecto
ARES_RCODE_BADNAME - RFC 2930. Nombre de Clave Duplicado
ARES_RCODE_BADALG - RFC 2930. Algoritmo no soportado
ARES_RCODE_BADTRUNC - RFC 8945. Truncamiento Incorrecto
ARES_RCODE_BADCOOKIE - RFC 7973. Cookie de Servidor incorrecta/faltante

ares_dns_parse_flags_t - Banderas para alterar el ares_dns_parse(3) comportamiento:

ARES_DNS_PARSE_AN_BASE_RAW - Analizar la Sección de Respuesta de RFC 1035 que permite la compresión de nombres como tipo RR RAW
ARES_DNS_PARSE_NS_BASE_RAW - Analizar la Sección de Autoridad de RFC 1035 que permite la compresión de nombres como tipo RR RAW
ARES_DNS_PARSE_AR_BASE_RAW - Analizar la Sección Adicional de RFC 1035 que permite la compresión de nombres como tipo RR RAW
ARES_DNS_PARSE_AN_EXT_RAW - Analizar la Sección de Respuesta de RFCs posteriores (sin compresión de nombres) como tipo RR RAW
ARES_DNS_PARSE_NS_EXT_RAW - Analizar la Sección de Autoridad de RFCs posteriores (sin compresión de nombres) como tipo RR RAW
ARES_DNS_PARSE_AR_EXT_RAW - Analizar la Sección Adicional de RFCs posteriores (sin compresión de nombres) como tipo RR RAW

DESCRIPCIÓN

La ares_dns_record_destroy(3) función destruye la memoria asociada con el registro DNS creado por ares_dns_record_create(3) o ares_dns_parse(3) pasado a través de dnsrec.

La ares_dns_parse(3) función analiza el búfer proporcionado en buf con la longitud proporcionada en buf_len. El flags parámetro puede ser uno o más ares_dns_parse_flags_t, o cero si no se necesitan banderas. La estructura de datos de registro DNS resultante se almacena en la variable apuntada por dnsrec y debe ser destruida usando ares_dns_record_destroy(3).

La función ares_dns_write(3) toma una estructura de registro DNS poblada en dnsrec y escribe un mensaje DNS en formato de cable en la variable apuntada por buf y escribe la longitud del búfer en la variable apuntada por buf_len. El búfer debe ser destruido usando ares_free_string(3).

La función ares_dns_record_create(3) crea una estructura de registro DNS vacía en la variable apuntada por dnsrec. El parámetro id es el id del mensaje DNS, sin embargo, si se pasa a ares_send(3) este identificador será sobrescrito, por lo que normalmente debe ser 0. El parámetro flags es uno o más ares_dns_flags_t. El opcode se pasa en el parámetro opcode y normalmente debería ser ARES_OPCODE_QUERY. El código de respuesta está destinado principalmente a las respuestas y se pasa en el parámetro rcode y normalmente es ARES_RCODE_NOERROR.

La función ares_dns_record_duplicate(3) duplica una estructura de registro DNS existente. Esto puede ser útil si se necesita guardar un resultado tal como se recuperó de ares_send_dnsrec(3) o ares_search_dnsrec(3). La estructura a duplicar se pasa en el parámetro dnsrec, y se devuelve la copia duplicada, o NULL en caso de error, como falta de memoria.

La función ares_dns_record_get_id(3) se utiliza para recuperar el id del mensaje DNS del registro DNS proporcionado en el parámetro dnsrec.

La función ares_dns_record_set_id(3) se utiliza para establecer el id del mensaje DNS en el parámetro id del registro DNS proporcionado en el parámetro dnsrec. Este id será sobrescrito al pasar el registro a c-ares, por lo que existe principalmente para fines externos.

La función ares_dns_record_get_flags(3) se utiliza para recuperar las banderas del mensaje DNS del registro DNS proporcionado en el parámetro dnsrec.

La función ares_dns_record_get_opcode(3) se utiliza para recuperar el opcode del mensaje DNS del registro DNS proporcionado en el parámetro dnsrec.

La función ares_dns_record_get_rcode(3) se utiliza para recuperar el código de respuesta del mensaje DNS del registro DNS proporcionado en el parámetro dnsrec.

La función ares_dns_record_query_add(3) se utiliza para añadir una pregunta al registro DNS proporcionado en el parámetro dnsrec. El nombre de dominio especificado para la pregunta se proporciona en el parámetro name, junto con el tipo de pregunta en el parámetro qtype y la clase de pregunta (normalmente ARES_CLASS_IN) en el parámetro qclass.

La función ares_dns_record_query_set_name(3) se utiliza para modificar el nombre de la pregunta en el registro DNS proporcionado en el parámetro dnsrec. El índice de la consulta, que debe ser menor que ares_dns_record_query_cnt(3), se proporciona en el parámetro idx. El nuevo nombre de dominio se proporciona en el parámetro name. Se debe tener cuidado, ya que esto invalidará cualquier puntero name recuperado de ares_dns_Record_query_get(3). Esta función es útil si se envían múltiples consultas similares sin recrear toda la consulta DNS.

La función ares_dns_record_query_set_type(3) se utiliza para modificar el tipo de pregunta en el registro DNS proporcionado en el parámetro dnsrec. El índice de la consulta, que debe ser menor que ares_dns_record_query_cnt(3), se proporciona en el parámetro idx. El nuevo tipo de consulta se proporciona en el parámetro qtype.

La función ares_dns_record_query_cnt(3) se utiliza para recuperar el número de preguntas DNS en el registro DNS proporcionado en el parámetro dnsrec.

La función ares_dns_record_query_get(3) se utiliza para recuperar los detalles de una única pregunta DNS en el parámetro dnsrec proporcionado. El índice proporcionado en el parámetro idx debe ser menor que el valor devuelto por ares_dns_record_query_cnt(3). El nombre de la pregunta DNS se devolverá en la variable apuntada por el parámetro name, que puede proporcionarse como NULL si el nombre no es necesario. Este puntero se invalidará con cualquier llamada a ares_dns_record_query_set_name(3). El tipo de pregunta DNS se devolverá en la variable apuntada por el parámetro qtype, que puede proporcionarse como NULL si el tipo no es necesario. La clase de pregunta DNS se devolverá en la variable apuntada por el parámetro qclass, que puede proporcionarse como NULL si la clase no es necesaria.

VALORES DE RETORNO

ares_dns_parse(3), ares_dns_write(3), ares_dns_record_create(3), ares_dns_record_query_add(3), y ares_dns_record_query_get(3) devuelven un código de error ares_status_t. Se devuelve ARES_SUCCESS en caso de éxito, ARES_ENOMEM en caso de falta de memoria, ARES_EFORMERR en caso de mal uso.

ares_dns_record_get_id(3), ares_dns_record_set_id(3), ares_dns_record_get_flags(3), ares_dns_record_get_opcode(3), ares_dns_record_get_rcode(3), y ares_dns_record_query_cnt(3) devuelven sus valores de tipo de dato prescritos y, en general, no pueden fallar excepto en casos de mal uso, en los que puede devolverse 0, sin embargo, 0 también puede ser un valor de retorno válido para la mayoría de estas funciones.

DISPONIBILIDAD
