NOMBRE

archive_read_set_filter_option, archive_read_set_format_option, archive_read_set_option, archive_read_set_options — funciones que controlan las opciones para leer archivos

BIBLIOTECA

Biblioteca de Archivos en Streaming (libarchive, -larchive)

SINOPSIS

int
archive_read_set_filter_option(struct archive *, const char *módulo, const char *opción, const char *valor);

int
archive_read_set_format_option(struct archive *, const char *módulo, const char *opción, const char *valor);

int
archive_read_set_option(struct archive *, const char *módulo, const char *opción, const char *valor);

int
archive_read_set_options(struct archive *, const char *opciones);

DESCRIPCIÓN

Estas funciones proporcionan una forma para que los clientes de libarchive configuren módulos de lectura específicos.

archive_read_set_filter_option(), archive_read_set_format_option()
Especifica una opción que se pasará a los filtros (incluidos los filtros de descompresión) o lectores de formato registrados actualmente.

Si opción y valor son ambos NULL, estas funciones no harán nada y se devolverá ARCHIVE_OK. Si opción es NULL pero valor no lo es, estas funciones no harán nada y se devolverá ARCHIVE_FAILED.

Si módulo no es NULL, opción y valor se proporcionarán al filtro o lector llamado módulo. El valor de retorno será el del módulo. Si no existe tal módulo, se devolverá ARCHIVE_FAILED.

Si módulo es NULL, opción y valor se proporcionarán a cada módulo registrado. Si algún módulo devuelve ARCHIVE_FATAL, este valor se devolverá inmediatamente. De lo contrario, se devolverá ARCHIVE_OK si algún módulo acepta la opción, y ARCHIVE_FAILED en todos los demás casos.

archive_read_set_option()
Llama a archive_read_set_format_option(), luego a archive_read_set_filter_option(). Si alguna función devuelve ARCHIVE_FATAL, se devolverá ARCHIVE_FATAL inmediatamente. De lo contrario, se devolverá el mayor de los dos valores.
archive_read_set_options()
opciones es una lista de opciones separadas por comas. Si opciones es NULL o está vacío, se devolverá ARCHIVE_OK inmediatamente.

Llama a archive_read_set_option() con cada opción por turno. Si alguna llamada a archive_read_set_option() devuelve ARCHIVE_FATAL, se devolverá ARCHIVE_FATAL inmediatamente.

Las opciones individuales tienen una de las siguientes formas:

opción=valor
El par opción/valor se proporcionará a cada módulo. Los módulos que no acepten una opción con este nombre la ignorarán.
opción
La opción se proporcionará a cada módulo con el valor “1”.
!opción
La opción se proporcionará a cada módulo con un valor NULL.
módulo:opción=valor, módulo:opción, módulo:!opción
Como lo anterior, pero la opción y el valor correspondientes se proporcionarán solo a los módulos cuyo nombre coincida con módulo.

OPCIONES

Formato cab
hdrcharset
El valor se utiliza como un nombre de conjunto de caracteres que se utilizará al traducir nombres de archivo.
Formato cpio
compat-2x
Libarchive 2.x codificó incorrectamente los nombres de archivo Unicode en algunas plataformas. Esta opción imita el manejo de nombres de archivo de libarchive 2.x para que tales archivos se puedan leer correctamente.
hdrcharset
El valor se utiliza como un nombre de conjunto de caracteres que se utilizará al traducir nombres de archivo.
pwb
Al leer un archivo CPIO binario, asume que está en el formato original de PWB cpio y maneja los bits de modo de archivo en consecuencia. El valor predeterminado es asumir el formato v7.
Formato iso9660
joliet
Admite extensiones Joliet. Habilitado por defecto, usa !joliet para deshabilitar.
rockridge
Admite extensiones RockRidge. Habilitado por defecto, usa !rockridge para deshabilitar.
Formato lha
hdrcharset
El valor se utiliza como un nombre de conjunto de caracteres que se utilizará al traducir nombres de archivo.
Formato mtree
checkfs
Permite leer información faltante del mtree desde el sistema de archivos. Deshabilitado por defecto.
Formato rar
hdrcharset
El valor se utiliza como un nombre de conjunto de caracteres que se utilizará al traducir nombres de archivo.
Formato tar
compat-2x
Libarchive 2.x codificó incorrectamente los nombres de archivo Unicode en algunas plataformas. Esta opción imita el manejo de nombres de archivo de libarchive 2.x para que tales archivos se puedan leer correctamente.
hdrcharset
El valor se utiliza como un nombre de conjunto de caracteres que se utilizará al traducir nombres de archivo.
mac-ext
Admite la extensión de metadatos de Mac OS que registra datos en archivos especiales que comienzan con un punto y un guion bajo. Habilitado por defecto.

read_concatenated_archives
Ignora los bloques con ceros en el archivo, lo cual ocurre cuando se han concatenado varios archivos tar. Sin esta opción, solo se leería el contenido del primer archivo concatenado.
