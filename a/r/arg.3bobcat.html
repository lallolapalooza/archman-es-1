FBB::Arg(3bobcat) Argumentos de Línea de Comandos FBB::Arg(3bobcat)

NOMBRE

FBB::Arg - Una clase singleton que interactúa con los argumentos de la línea de comandos

SINOPSIS

#include <bobcat/arg>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Clase singleton (ver Gamma et al., 1995) construida alrededor de getopt_long()(3). La clase maneja opciones de línea de comandos cortas y largas.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

-

ENUMERACIÓN

La enumeración FBB::Arg::Type está definida por la clase FBB::Arg. Se utiliza para especificar si las opciones largas requieren argumentos. Define los siguientes valores: None, Required, Optional.

o
None: la opción larga no utiliza un argumento;
o
Required: la opción larga requiere un valor de argumento;
o
Optional: la opción larga puede proporcionarse opcionalmente con un valor de argumento;

Estos valores se utilizan al definir opciones largas (como --version), que se definen como objetos de la clase (anidada) FBB::Arg::LongOption.

LA CLASE ANIDADA FBB::Arg::LongOption

Las opciones largas se definen utilizando objetos de la clase anidada FBB::Arg::LongOption. Esta clase proporciona los siguientes constructores:

o
FBB::Arg::LongOption(char const *name, FBB::Arg::Type type = FBB::Arg::None):
Este constructor se utiliza para definir una opción larga para la cual no se define una opción corta correspondiente. El parámetro name es el nombre de la opción larga (sin especificar los caracteres -- que solo son necesarios al especificar una opción larga al llamar a un programa).
o
FBB::Arg::LongOption(char const *name, int optionChar):
Este constructor se utiliza para definir una opción larga para la cual se define una opción corta correspondiente. El parámetro name es el nombre de la opción larga (sin especificar los caracteres -- que solo son necesarios al especificar una opción larga al llamar a un programa).

Para definir opciones largas utilice el siguiente procedimiento:

o
Primero, construya un array 
    FBB::Arg::LongOption longOptions[] = { c1, c2, ..., cn };
Donde c1, c2, ..., cn son n invocaciones de constructor de los constructores FBB::Arg::LongOption()
o
A continuación, pase longOptions, LongOptions + n como argumentos a un miembro Arg::initialize que admita opciones largas.

Los objetos de la clase LongOptions normalmente los utiliza internamente el objeto Arg, pero también pueden usarse fuera del objeto Arg. Para esa situación, los siguientes miembros están disponibles:

o
std::string const &longName() const:
devuelve el nombre de la opción larga de LongOption;
o
int optionChar() const:
devuelve el carácter de opción de LongOption (o uno de los valores de la enumeración Arg::Type si no hay un carácter de opción asociado con LongOption).

CONSTRUCTORES

Dado que la clase Arg es un singleton, no hay constructores públicos. En su lugar, hay miembros estáticos disponibles para inicializar y acceder al objeto único FBB::Arg.

MIEMBROS ESTÁTICOS

Todos los miembros initialize inicializan el singleton FBB::Arg, y solo pueden llamarse una vez. Se lanza una excepción cuando se llaman varias veces. Todos los miembros initialize devuelven una referencia al objeto singleton Arg inicializado.

Todos los miembros initialize definen los parámetros argc y argv que se interpretan como los parámetros argc y argv de main. Cuando un elemento de argv apunta a dos guiones consecutivos (--), ese elemento se ignora, y todos los elementos subsiguientes de argv se consideran argumentos en lugar de opciones.

o
FBB::Arg &Arg::initialize(char const *optstring, int argc, char **argv):
El parámetro optstring es una cadena de bytes terminada en nulo (NTBS) que opcionalmente comienza con un carácter +, pero que por lo demás contiene caracteres de opción. Uno o dos puntos pueden ir seguidos de los caracteres de opción:
o
un solo punto (:) indica que la opción requiere un valor de opción.
o
un doble punto (::) indica que la opción tiene un argumento opcional. Con opciones cortas, el valor de la opción se considera ausente a menos que esté adjunto a la opción corta (por ejemplo, -tvalor). Las opciones largas que aceptan argumentos opcionalmente siempre deben ir seguidas inmediatamente por un carácter de asignación (=), seguido inmediatamente por el valor de la opción (que debe comenzar con un carácter que no sea un espacio en blanco). Por ejemplo, --valor= indica un valor de opción ausente, --valor=texto indica que el valor de la opción es texto. Si el valor de una opción contiene espacios, debe estar rodeado de comillas simples o dobles (por ejemplo, -t’este valor’, o --texto=’este valor’). Las comillas circundantes no forman parte del valor de la opción.
Cuando el primer carácter de optstring es + entonces todas las opciones no especificadas se consideran argumentos, apareciendo en la lista final de argumentos en sus posiciones de argumento actuales. Por ejemplo, cuando optstring es +ab y no se definen opciones largas, entonces la llamada 
    prog -a -z -b -yvalor --largo arg1 arg2
resulta en que el miembro argv devuelva un vector que contiene los elementos -z, -yvalor, --largo, arg1, y arg2. Si el primer carácter de optstring no es + y se encuentra una opción indefinida, se lanza una excepción.
o
FBB::Arg &Arg::initialize(int accept, char const *optstring, int argc, char **argv):
Actúa como el miembro anterior, pero además define el parámetro accept que especifica un carácter de opción a partir del cual todos los argumentos y opciones subsiguientes se consideran argumentos. Para ignorar accept se puede especificar el valor 0 (no el carácter '0') o se pueden usar miembros initialize que no definan un parámetro accept.
Cuando los argumentos contienen tanto una opción accept como dos guiones consecutivos, se interpreta el primero, lo que resulta en que todos los elementos argv restantes se interpreten como simples argumentos. Por ejemplo, al especificar initialize(’t’, ...) y llamar 
    prog uno -tdos -c -- tres
entonces el miembro argv devuelve un vector que contiene los elementos uno, -tdos, -c, -- y tres (ver también el miembro beyondDashes a continuación).
o
FBB::Arg &Arg::initialize(char const *optstring, Arg::LongOption const *const begin, Arg::LongOption const *const end, int argc, char **argv):
Actúa como el primer miembro Arg::initialize, pero además define dos parámetros que especifican el rango de elementos de un array de objetos Arg::LongOption que especifican opciones largas. El parámetro begin apunta
apunta al primer elemento del rango, el parámetro end apunta justo más allá del último elemento del rango. Por ejemplo, después de definir 
    FBB::Arg::LongOption longOptions[] = { c1, c2, ..., cn };
los argumentos pasados a begin y end podrían especificarse como 
    initialize(..., longOptions, longOptions + size(longOptions), ...);
o
FBB::Arg &Arg::initialize(char accept, char const *optstring, LongOption const *const begin, LongOption const *const end, int argc, char **argv):
Se comporta como el miembro Arg::initialize anterior, pero además define un parámetro accept como se define en el segundo miembro Arg::initialize .
o
FBB::Arg &Arg::instance():
Una vez que se ha llamado a un miembro Arg::initialize , este miembro puede llamarse desde cualquier parte del programa (y puede llamarse múltiples veces), devolviendo una referencia al objeto Arg inicializado.
Si se llama antes de que se haya llamado a un miembro Arg::initialize , se lanza una excepción.

OPERADOR SOBRECARGADO

o
char const *operator[](size_t idx) const:
Devuelve argument[idx], después de que se hayan eliminado todas las opciones. Devuelve 0 si no hay ningún arg[x] disponible. El nombre del programa (argv[0]) NO se cuenta aquí: el índice 0 se refiere al primer ARGUMENTO, por ejemplo, el argv[1]del programa.

FUNCIONES MIEMBRO NO ESTÁTICAS

o
string const &argv0() const:
Devuelve el nombre del programa tal como se especifica en argv[0] (véase también el miembro basename);
o
char const **argPointers() const:
Devuelve un conjunto de punteros tipo argva todos los argumentos restantes. El elemento nArgs() + 1 es un puntero nulo. Los primeros nArgs() elementos apuntan a los valores respectivos de los argumentos NTBS que se pasaron al programa, después de haber eliminado las opciones.
El llamador es responsable de devolver el array de punteros devuelto por este miembro al pool común, pero el llamador no debe borrar los NTBS a los que apuntan los punteros, como se ilustra con las siguientes dos sentencias: 
    char const **ptr = Arg::instance().argPointers();
    delete[] ptr;   // ¡no borre los elementos ptr[idx]!
o
std::vector<std::string> const &args() const:
Devuelve un vector de cadenas que contiene todos los argumentos después de haber eliminado todas las opciones. El nombre del programa (argv[0]) NO se incluye aquí: su primer elemento se refiere al primer ARGUMENTO, por ejemplo, el argv[1]del programa;
o
std::string const &basename() const:
Devuelve el nombre base del programa (es decir, el valor de argv0() más allá del último separador de directorio);
o
std::vector<std::string>::const_iterator begin() const:
Devuelve el iterador al primer argumento del programa (es decir, args().begin()). Este miembro, en combinación con el miembro end, permite el procesamiento de todos los argumentos mediante algoritmos genéricos;
o
size_t beyondDashes() const:
Devuelve el índice del primer argumento más allá del argumento -- o devuelve el índice del argumento accept (lo que ocurra primero) o devuelve nArgs() si no se encontró ningún argumento -- o accept . Véase también el miembro nArgs más abajo;
o
std::vector<std::string>::const_iterator end() const:
Devuelve el iterador que apunta más allá del último argumento del programa (es decir, args().end()). Este miembro, en combinación con el miembro begin, permite el procesamiento de todos los argumentos mediante algoritmos genéricos;
o
void help() const:
Si se llamó al miembro versionHelp (véase más abajo), entonces este miembro llama a la función usage que se pasó a versionHelp. Si versionHelp no ha sido llamado (es decir, si no se ha especificado ninguna función usage ), se lanza una excepción;
o
size_t nArgs() const:
Devuelve el número de argumentos después de haber eliminado las opciones (es decir, devuelve args().size()). Tenga en cuenta que el nombre del programa no se cuenta aquí;
o
size_t nLongOptions() const:
Devuelve el número de opciones largas que no tienen sinónimos de opción corta. Las opciones largas especificadas varias veces se cuentan cada una;
o
size_t nOptions() const:
Devuelve el número de opciones de un solo carácter especificadas. Si las opciones cortas tienen sinónimos de opción larga, entonces estos sinónimos de opción larga se cuentan como si se hubieran especificado como opciones de un solo carácter. Si las opciones de un solo carácter (o sus sinónimos de opción larga) se especifican varias veces, entonces cada especificación se cuenta por separado;
o
size_t option(int option) const:
Devuelve el número de veces que se especificó `option' (o su sinónimo de opción larga, si está definido);
o
size_t option(std::string const &options) const:
Devuelve el número de veces que se especificó cada una de las opciones del argumento `option' (o sus sinónimos de opción larga). Tenga en cuenta que cada carácter en options debe especificar una opción de un solo carácter;
o
size_t option(string *value, int option) const:
Devuelve el número de veces que la opción proporcionada (o su sinónimo de opción larga) estuvo presente. Si el valor de retorno no es cero, entonces el valor de la primera aparición de esta opción se almacena en *value, que se deja intacto si `option' no estuvo presente. El parámetro value puede inicializarse a 0 si la opción no tiene un valor o si el valor de la opción no debe almacenarse;
o
size_t option(size_t idx, string *value, int option) const:
Devuelve el número de veces que la opción proporcionada (o su sinónimo de opción larga) estuvo presente. Si el valor de retorno no es cero, entonces el valor de la idx-ésima aparición (desplazamiento basado en 0) de esta opción se almacena en *value, que se deja intacto si `option' no estuvo presente o si idx es o excede el número de especificaciones de la opción proporcionada. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe almacenarse;
o
size_t option(size_t *idx, string *value, int option) const:
Devuelve el número de veces que la opción proporcionada (o su sinónimo de opción larga) estuvo presente. Si el valor de retorno no es cero, entonces el desplazamiento (dentro de la serie de especificaciones de option ) de la primera opción que tiene un valor de opción no vacío se devuelve en *idx, mientras que su valor de opción se almacena en *value. Tanto *value como *idx se dejan intactos si `option' no estuvo presente. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe almacenarse;
o
size_t option(string *value, char const *longOption) const:
Devuelve el número de veces que la opción larga especificada (que no tiene un sinónimo de un solo carácter) estuvo presente. Su valor se almacena entonces en *value, que se deja intacto si la opción larga no estuvo presente. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe almacenarse;
o
size_t option(size_t idx, string *value, char const * longOption) const:
Devuelve el número de veces que la opción larga proporcionada (que no tiene un sinónimo de un solo carácter) estuvo presente. Si el valor de retorno no es cero entonces el valor de la idx-ésima aparición (desplazamiento basado en 0) de esta opción larga se almacena en *value, que se deja intacto si la opción larga no estuvo presente o si idx es o excede el número de especificaciones de la opción larga proporcionada. Se puede especificar 0 para value si la opción larga no tiene un valor o si el valor no debe almacenarse;
o
size_t option(size_t *idx, string *value, int longOption) const:
Devuelve el número de veces que la opción larga proporcionada (que no tiene un sinónimo de un solo carácter) estuvo presente. Si el valor de retorno no es cero entonces el desplazamiento (dentro de la serie de especificaciones de esta opción larga) de la primera opción larga que tiene un valor de opción no vacío se devuelve en *idx, mientras que su valor de opción se almacena en *value. Tanto *value como *idx se dejan intactos si la opción larga no estuvo presente. Se puede especificar 0 para value si la opción larga no tiene un valor o si el valor no debe almacenarse;
o
void versionHelp(void (*usage)(std::string const &progname), char const *version, size_t minArgs, int helpFlag = ’h’, int versionFlag = ’v’) const:
Si se especificó helpFlag se llama a usage() con el argumento basename() , después de lo cual el programa lanza int 0.
Si versionFlag fue especificado, el nombre del programa (usando basename()) y la versión se muestran en std::cout , después de lo cual el programa lanza int 0.

NAME

arg - command-line argument parser

SYNOPSIS

#include <bobcat/arg>

namespace FBB
{
    class Arg
    {
        public:
            // ...
            // Class LongOption
            class LongOption
            {
                public:
                    // ...
                    LongOption(char const *name, char shortOpt = 0,
                               char const *arg = 0);
                    // ...
            };
            // ...
            // Class Arg
            static Arg &initialize(char const *options,
                                     LongOption *begin, LongOption *end,
                                     int argc, char **argv);
            static Arg &initialize(char const *options,
                                     LongOption *begin, LongOption *end,
                                     int argc, char **argv,
                                     char const *usage);
            static Arg &initialize(char const *options,
                                     LongOption *begin, LongOption *end,
                                     int argc, char **argv,
                                     char const *usage,
                                     char const *version);
            static Arg &initialize(char const *options,
                                     LongOption *begin, LongOption *end,
                                     int argc, char **argv,
                                     char const *usage,
                                     char const *version,
                                     size_t minArgs);
            // ...
            size_t nArgs() const;
            size_t beyondDashes() const;
            void versionHelp(char const *usage, char const *version,
                             size_t minArgs = 0) const;
            // ...
    };
}

DESCRIPTION

The Arg class is a parser for command-line arguments. It supports both POSIX-style options (e.g. -f, -h) and GNU-style long options (e.g. --help, --version).

In addition to the POSIX-style options, long options may be specified. These are defined by the LongOption class. The constructor of LongOption may be passed the long option name, optionally a short option character, and optionally the name of an argument required by the long option.

The Arg::initialize function initializes the parser. Its first argument is a string specifying the POSIX-style options. For each option character in this string, the following rules apply:

  • If the character is followed by no letter, then the option does not take an argument.
  • If the character is followed by a letter, then the option takes an argument, and the letter indicates the argument's name.

The next two arguments are iterators defining the range of long options. The last three arguments are the standard argc and argv values, and optionally, the program's usage message, and program version. If a usage message and/or version string are provided, then the -h / --help and -v / --version options are automatically handled by the parser.

The initialize function returns a reference to the Arg object and initializes it with the parsed command-line arguments.

The nArgs() member function returns the number of non-option arguments found on the command line. The beyondDashes() member function returns the number of non-option arguments that appear after the -- argument.

The versionHelp() member function is used to display the program's version and/or usage information.

THE NESTED CLASS FBB::Arg::LongOption

This class represents a long-form option. It is used to define long options that are recognized by the Arg class. The constructor takes the long option name, an optional short option character, and an optional argument name.

CONSTRUCTORS

o
LongOption(char const *name, char shortOpt = 0, char const *arg = 0);

Constructs a LongOption object. name is the name of the long option. shortOpt is the short option character, or 0 if none. arg is the name of the option's argument, or 0 if none.

STATIC MEMBERS

o
static Arg &initialize(char const *options, LongOption *begin, LongOption *end, int argc, char **argv);

Initializes the Arg parser with POSIX-style options, a range of long options, and the command-line arguments.

o
static Arg &initialize(char const *options, LongOption *begin, LongOption *end, int argc, char **argv, char const *usage);

Similar to the above, but also accepts a usage message.

o
static Arg &initialize(char const *options, LongOption *begin, LongOption *end, int argc, char **argv, char const *usage, char const *version);

Similar to the above, but also accepts a version string.

o
static Arg &initialize(char const *options, LongOption *begin, LongOption *end, int argc, char **argv, char const *usage, char const *version, size_t minArgs);

Similar to the above, but also accepts a minimum number of non-option arguments.

OVERLOADED OPERATOR

NON-STATIC MEMBER FUNCTIONS

nArgs()
size_t nArgs() const;

Returns the number of non-option arguments.

beyondDashes()
size_t beyondDashes() const;

Returns the number of non-option arguments that appear after the -- argument.

versionHelp()
void versionHelp(char const *usage, char const *version, size_t minArgs = 0) const;

Displays usage and version information. If usage and version are provided, the corresponding options (-h, --help, -v, --version) will automatically print this information and exit. The minArgs parameter specifies the minimum number of non-option arguments expected. If the number of non-option arguments is less than minArgs, usage information is printed and the program exits. The value for minArgs can be calculated using nArgs() and beyondDashes(). For example, if you have 2 mandatory arguments (e.g. input and output file names), then add nArgs() - beyondDashes() to the minArg argument. E.g., 

    arg.versionHelp(usage, version, 2 + arg.nArgs()
                                      - arg.beyondDashes());
The address of the usage() function, the current version and the minimum number of arguments must be specified. Default argument values are provided for the option flags.

EXAMPLE

The following example illustrates defining long options and shows an initialization. It is not a full-fledched example in the sense of a small runnable program.

#include <bobcat/arg>
using namespace FBB;
using namespace std;
namespace   // the anonymous namespace can be used here
{
    Arg::LongOption longOptions[] =
    {
        Arg::LongOption{"debug"},
        Arg::LongOption{"filenames", ’f’},
        Arg::LongOption{"help", ’h’},
        Arg::LongOption{"version", ’v’},
    };
    auto longEnd = longOptions + size(longOptions);
}
int main(int argc, char **argv)
try
{
    Arg &arg = Arg::initialize("df:hv",
                    longOptions, longEnd,
                    argc, argv);
    // code using arg, etc.
}
catch (exception const &err)     // handle exceptions
{
    cerr << err.what() << ’\n’;
    return 1;
}
