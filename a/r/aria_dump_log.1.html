ARIA_DUMP_LOG(1) Comandos de usuario ARIA_DUMP_LOG(1)

NOMBRE

aria_dump_log - Volcar contenido de las páginas de registro de Aria.

SINOPSIS

aria_dump_log -f archivo OPCIONES

DESCRIPCIÓN

Volca el contenido de las páginas de registro de Aria.

-#, --debug[=nombre]
Salida del registro de depuración. A menudo el argumento es 'd:t:o,nombrearchivo'.
-f, --file=nombre
Ruta al archivo que se leerá
-?, --help
Mostrar esta ayuda y salir.
-o, --offset=#
Comenzar a leer el registro desde este desplazamiento
-n, --pages=#
Número de páginas a leer
-U, --unit-test
Usar la tabla de registros de prueba unitaria (para registros creados por pruebas unitarias)
-V, --version
Imprimir versión y salir.

Las opciones predeterminadas se leen de los siguientes archivos en el orden dado: /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf

Se leen los siguientes grupos: aria_dump_log

Las siguientes opciones se pueden proporcionar como primer argumento:

--print-defaults
Imprimir la lista de argumentos del programa y salir.
--no-defaults
No leer opciones predeterminadas de ningún archivo de opciones.
--defaults-file=#
Leer opciones predeterminadas solo del archivo # dado.
--defaults-extra-file=#
Leer este archivo después de que se lean los archivos globales.

VER TAMBIÉN

Para obtener más información, consulte la Base de conocimiento de MariaDB, disponible en línea en https://mariadb.com/kb/

AUTOR
