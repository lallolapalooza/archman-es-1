DESCRIPCIÓ

N

Ark es un programa para gestionar diversos formatos de archivos comprimidos dentro de KDE. Los archivos comprimidos

pueden ser vistos, extraídos, creados y modificados con Ark. El programa puede manejar varios formatos como tar, g
zip, bzip2, zip, rar (cuando las bibliotecas o programas de línea de comandos correspondientes están instalados).

MODOS DE

OPERACIÓN

Ark puede usarse tanto como un programa gráfico independiente como un programa de línea de comandos para realizar algunas tareas

específicas.

Si se invoca sin las opciones -b (--batch) o -c (--add), Ark se inicia como un programa gráfico

normal.

Cuando se usa la opción -b (--batch), Ark puede usarse para extraer el contenido de uno o más archivos directamente desde la línea de comandos, sin iniciar su interfaz

gráfica.

Cuando se usa la opción -c (--add), Ark sol

icita los archivos que deben añadirse a
un archivo nuevo o a un archivo existente.
