NOMBRE

archive_read_add_passphrase, archive_read_set_passphrase_callback — funciones para leer archivos cifrados

BIBLIOTECA

Biblioteca de Archivos en Streaming (libarchive, -larchive)

SINTAXIS

#include <archive.h>

int
archive_read_add_passphrase(struct archive *, const char *passphrase);

int
archive_read_set_passphrase_callback(struct archive *, void *client_data, archive_passphrase_callback *);

DESCRIPCIÓN

archive_read_add_passphrase()
Registra contraseñas para leer un archivo cifrado. Si passphrase es NULL o está vacío, esta función no hará nada y se devolverá ARCHIVE_FAILED. De lo contrario, se devolverá ARCHIVE_OK.
archive_read_set_passphrase_callback()
Registra una función de callback que se invocará para obtener una contraseña de descifrado después de que hayan fallado todas las contraseñas registradas por la función archive_read_add_passphrase().

VER TAMBIÉN

tar(1), archive_read(3), archive_read_set_options(3), libarchive(3)
