NOMBRE

ares_threadsafety - Consultar si c-ares se compiló con seguridad para hilos

SINOPSIS

#include <ares.h>
ares_bool_t ares_threadsafety(void);

DESCRIPCIÓN

La función ares_threadsafety(3) devuelve si la biblioteca se compiló con la seguridad para hilos habilitada o no.

A partir de c-ares 1.23.0, esto significa simplemente que cada función pública que hace referencia a un objeto ares_channel_t bloqueará el canal al entrar y liberará el bloqueo al salir de la función. Esto impedirá el acceso concurrente de hilos al canal, garantizando así que no pueda ocurrir ninguna corrupción.

A partir de c-ares 1.26.0, esto también indica si ARES_OPT_EVENT_THREAD puede pasarse a ares_init_options(3).

VALORES DE RETORNO

ares_threadsafety(3) puede devolver cualquiera de los siguientes valores:

ARES_TRUE
Compilado con seguridad para hilos.
ARES_FALSE
Compilado sin seguridad para hilos.

DISPONIBILIDAD

Esta función se introdujo por primera vez en la versión 1.23.0 de c-ares.

VER TAMBIÉN
