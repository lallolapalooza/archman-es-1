DESCRIPCIÓ

N

Argtable es una biblioteca ANSI C para analizar argumentos de línea de comandos al estilo GNU con el mínimo de complicaciones. Permite al programador definir la sintaxis de los argumentos de su programa directamente en el código fuente como una matriz de estructuras. La línea de comandos se analiza entonces de acuerdo con esa especificación y los valores resultantes se almacenan directamente en variables de programa definidas por el usuario donde son accesibles para el programa

principal.

Esta página del manual es solo para referencia. La documentación introductoria y el código fuente de ejemplo se instalan típicamente bajo /usr/share/doc/argtable2/ y también están disponibles desde la página principal de argtable en http://argtable.sourc

eforge.net.

Construyendo una estructura de datos

arg_<xxx>

Cada struct arg_<xxx> tiene su propio conjunto único de funciones constructoras (definidas arriba) que típicamente tienen la

forma: 
struct arg_int* arg_int0("f", "foo", "<int>", "el factor foo")
struct arg_int* arg_int1("f", "foo", "<int>", "el factor foo")
struct arg_int* arg_intn("f", "foo", "<int>", 2, 4, "el factor
foo")

donde arg_int0() y arg_int1() son simplemente formas abreviadas de arg_intn(). Se proporcionan por conveniencia al definir opciones de línea de comandos que tienen cero o una ocurrencia (mincount=0,maxcount=1) o exactamente una ocurrencia (mincount=1,maxcount=1) respectivamente

.

El parámetro shortopts="f" define la etiqueta de forma corta de la opción (por ejemplo -f). Se pueden definir múltiples etiquetas alternativas concatenándolas (por ejemplo shortopts="abc" define las opciones -a, -b y -c como equivalentes). Especifique shortopts=NULL cuando no se requiera una opción

corta.

El parámetro longopts="foo" define la etiqueta de forma larga de la opción (por ejemplo --foo). Se pueden separar múltiples etiquetas alternativas de forma larga con comas (por ejemplo longopts="size,limit" define --size y --limit). No incluya ningún espacio en blanco en la cadena longopts. Especifique longopts=NULL cuando no se requiera una opción

larga.

Si tanto shortopts como longopts son NULL, entonces la opción es un argumento sin

etiqueta.

El parámetro datatype="<int>" es una cadena descriptiva que denota el tipo de datos del argumento en los mensajes de error, como en --foo=<int>. Especificar datatype=NULL indica que se debe usar el tipo de datos predeterminado. Especificar datatype="" desactiva efectivamente la visualización del tipo de

datos.

Los parámetros mincount=2 y maxcount=3 especifican el número mínimo y máximo de ocurrencias de la opción en la línea de comandos. Si la opción de línea de comandos no aparece el número de veces requerido, el analizador informa un error de

sintaxis.

El parámetro glossary="el factor foo" es otra cadena descriptiva. Aparece solo en la tabla de glosario que genera automáticamente la función arg_print_glossary (descrita más adelante)

.
-f, --foo=<int> el factor foo

Especificar una cadena glossar

y NULL hace que esa opción se
omita de la tabla de glosario.

ENTERAS

-x2, -z 32MB, --size=734kb, --hex 0x7, --binary 0b10011010, --octal

0o123

Argtable acepta enteros de línea de comandos en formatos decimal (por ejemplo 123), hexadecimal (por ejemplo 0xFF12), octal (por ejemplo 0o123) y binario (por ejemplo 0b0101110). También acepta enteros con sufijo "KB" (x1024), "MB" (x1048576) o "GB" (x1073741824). Todos los caracteres no distinguen entre mayúsculas y

minúsculas

cadenas de argumentos analizadas */ }; Similar a arg_str excepto que los valores de argumentos de cadena solo se aceptan si coinciden con una expresión regular predefinida. Las expresiones regulares son útiles para hacer coincidir palabras clave de la línea de comandos, particularmente si se requieren cadenas que no distingan entre mayúsculas y minúsculas o coincidencia de patrones. La expresión regular se define mediante el parámetro pattern pasado al constructor arg_rex y se evalúa usando regex. Su comportamiento se puede controlar mediante los indicadores de bits estándar de regex. Estos se pasan a argtable a través del parámetro flags en el constructor arg_rex. Sin embargo, solo dos de los indicadores de regex estándar son relevantes para argtable, a saber, REG_EXTENDED (usar expresiones regulares extendidas en lugar de las básicas) y REG_ICASE (ignorar mayúsculas/minúsculas). Estos indicadores pueden combinarse

con

un OR lógico si se desea. Consulte regex(3) para obtener más detalles sobre la coincidencia de expresiones regulares. Restricciones: Argtable no admite la funcionalidad de arg_rex en plataform

void arg_print_syntaxv (FILE *fp, void **argtable, const char *suffix)

Prints the verbose form of the command line syntax for the given argument table, as in: [-a] [-b] [-c] [--scalar=<n>] [-o myfile] [-v|--verbose] <file> [<file>]
The suffix string is provided as a convenience for appending newlines and so forth to the end of the display and can be given as NULL if not required.

void arg_print_glossary (FILE *fp, void **argtable, const char *format)

Prints a glossary table describing each option in the given argument table. The format string is passed to printf to control the formatting of each entry in the the glossary. It must have exactly two "%s" format parameters as in "%(%-25s %s\n", the first is for the option's syntax and the second for its glossary string. If an option's glossary string is NULL then that option in omitted from the glossary display.

void arg_print_glossary_gnu (FILE *fp, void **argtable)

An alternate form of arg_print_glossary() that prints the glossary using strict GNU formatting conventions wherein long options are vertically aligned in a second column, and lines are wrapped at 80 characters.

void arg_print_errors (FILE *fp, struct arg_end *end, const char *progname)

Prints the details of all errors stored in the end data structure. The progname string is prepended to each error message.

void arg_freetable (void ** argtable, size_t n)

Deallocates the memory used by each arg_xxx struct referenced by argtable[]. It does this by calling free for each of the n pointers in the argtable array and then nulling them for safety.
