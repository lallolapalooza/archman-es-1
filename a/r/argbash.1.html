argbash(1) Manual de Comandos Generales argbash(1)

Nombre

argbash - Argbash es un generador de analizadores de argumentos para Bash.

SINOPSIS

argbash [--output SALIDA] [--in-place] [--type tipo] [--library] [--strip contenido] [--check-typos] [--commented] [--search BUSCAR]... [--debug DEBUG] [--help] [--version] <entrada>

DESCRIPCION

Argbash es un generador de código que típicamente genera una biblioteca de análisis de argumentos de bash hecha a medida para tu script. Te permite describir los argumentos que tu script debe aceptar y luego puedes generar el código de análisis de bash. Por defecto, permanece en tu script, pero puedes generarlo a un archivo separado y dejar que bash lo incluya en tu script por ti. Argbash es muy simple de usar y el código generado es relativamente agradable de leer. Además, las definiciones de argumentos permanecen incrustadas en el script, por lo que cuando necesites actualizar la lógica de análisis, simplemente vuelve a ejecutar el script argbash en el script ya generado.

ARGUMENTOS

-o SALIDA, --output SALIDA
Nombre del archivo de salida (usa '-' para la salida estándar). [Por defecto: -]
-i, --in-place
Actualizar un script de bash en el lugar. [Por defecto: desactivado]
-t bash-script|posix-script|manpage|manpage-defs|completion|docopt|excised, --type bash-script|posix-script|manpage|manpage-defs|completion|docopt|excised Tipo de salida a generar.
[Por defecto: bash-script]

Consulta la documentación para conocer todas las capacidades de argbash que se admiten.

--library
Indica si el archivo de entrada es la biblioteca de análisis pura. [Por defecto: desactivado]

Esta opción está obsoleta y es lo mismo que --strip user-content.

--strip none|user-content|all Determina qué incluir en la salida.
[Por defecto: none]

Puedes elegir entre none, que es útil para scripts. Si eliges user-content, conservas la cabecera de Argbash. Si eliges all, solo tendrás el contenido generado en el resultado.

--check-typos
Indica si se deben verificar posibles errores tipográficos en las macros de argbash. [Por defecto: activado]
-c, --commented
Modo comentado: incluye comentarios explicativos con el código de análisis. [Por defecto: desactivado]
-I BUSCAR, --search BUSCAR
Directorios donde buscar los scripts envueltos (el directorio de la plantilla se añadirá al final de la lista). [Por defecto: "."]
--debug DEBUG
(opción de desarrollador) Indica a autom4te que trace una macro.
-h, --help
Imprime la ayuda.
-v, --version
Imprime la versión.
