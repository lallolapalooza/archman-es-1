NOMBRE

ares_gethostbyname_file - Busca un nombre en el archivo hosts del sistema

SINOPSIS

#include <ares.h>
int ares_gethostbyname_file(ares_channel_t *channel, const char *name,
                            int family, struct hostent **host)

DESCRIPCIÓN

La función ares_gethostbyname_file realiza una búsqueda de host por nombre contra el archivo hosts del sistema (o una base de datos de nombres de host locales equivalente). El parámetro channel es requerido, pero no se realizan consultas asíncronas. En su lugar, la búsqueda se realiza a través del mismo mecanismo utilizado para realizar búsquedas 'f' (ver el campo de opciones lookups en ares_init_options(3)). El parámetro name proporciona el nombre del host como una cadena de C terminada en NUL, y family proporciona el tipo de dirección deseado para la entrada de host resultante.

El valor de retorno indica si la consulta tuvo éxito y, si no, cómo falló. Puede tener cualquiera de los siguientes valores:

ARES_SUCCESS
La búsqueda del host se completó con éxito y host ahora apunta al resultado (y debe liberarse con ares_free_hostent(3)).
ARES_ENOTFOUND
No se encontró el nombre de host name.
ARES_EFILE
Hubo un error de E/S de archivo al realizar la búsqueda.
ARES_ENOMEM
Se agotó la memoria.

Al completar con éxito la consulta, el puntero al que apunta host apunta a una struct hostent que contiene la dirección del host devuelta por la búsqueda. El usuario debe liberar la memoria apuntada por host cuando termine con ella llamando a ares_free_hostent(3). Si la búsqueda no se completó con éxito, host será NULL.
