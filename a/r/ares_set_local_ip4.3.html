NOMBRE

ares_set_local_ip4 - Establecer la dirección IP local para las solicitudes salientes.

SINOPSIS

#include <ares.h>
void ares_set_local_ip4(ares_channel_t *channel, unsigned int local_ip)

DESCRIPCIÓN

La función ares_set_local_ip4 establece la dirección IP para las solicitudes salientes. El parámetro local_ip se especifica en orden de bytes del host. Esto permite a los usuarios especificar interfaces salientes cuando se utilizan en sistemas multi-homed.
