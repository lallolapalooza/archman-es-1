DESCRIPCIÓN

Estas funciones proporcionan una interfaz para crear, leer y modificar Registros de Recursos (RR) dentro de una estructura ares_dns_record_t. Una estructura ares_dns_record_t contiene varias secciones (Respuesta, Autoridad, Información adicional), y cada sección contiene una lista de RR.

Funciones de gestión de secciones RR

size_t ares_dns_record_rr_cnt(const ares_dns_record_t *dnsrec, ares_dns_section_t sect);
Devuelve el número de RR en la sección especificada del registro DNS.
ares_status_t ares_dns_record_rr_add(ares_dns_rr_t **rr_out, ares_dns_record_t *dnsrec, ares_dns_section_t sect, const char *name, ares_dns_rec_type_t type, ares_dns_class_t rclass, unsigned int ttl);
Añade un nuevo RR a la sección especificada del registro DNS. El nuevo RR se crea y se inicializa con el nombre, tipo, clase y TTL proporcionados. Si tiene éxito, el puntero al nuevo RR se almacena en rr_out.
ares_dns_rr_t *ares_dns_record_rr_get(ares_dns_record_t *dnsrec, ares_dns_section_t sect, size_t idx);
Devuelve un puntero al RR en el índice especificado dentro de la sección dada del registro DNS. Tenga en cuenta que este RR puede ser modificado.
const ares_dns_rr_t *ares_dns_record_rr_get_const(const ares_dns_record_t *dnsrec, ares_dns_section_t sect, size_t idx);
Devuelve un puntero constante al RR en el índice especificado dentro de la sección dada del registro DNS. Este RR no debe ser modificado.
ares_status_t ares_dns_record_rr_del(ares_dns_record_t *dnsrec, ares_dns_section_t sect, size_t idx);
Elimina el RR en el índice especificado dentro de la sección dada del registro DNS.

Funciones de lectura de RR básicos

const char *ares_dns_rr_get_name(const ares_dns_rr_t *rr);
Devuelve el nombre de dominio del RR.
ares_dns_rec_type_t ares_dns_rr_get_type(const ares_dns_rr_t *rr);
Devuelve el tipo del RR (por ejemplo, A, MX, TXT).
ares_dns_class_t ares_dns_rr_get_class(const ares_dns_rr_t *rr);
Devuelve la clase del RR (normalmente IN para Internet).
unsigned int ares_dns_rr_get_ttl(const ares_dns_rr_t *rr);
Devuelve el valor TTL (Time To Live) del RR.

DESCRIPTION

The ares_dns_record_rr_cnt() function returns the number of resource records in the DNS record provided by the dnsrec parameter for the section provided in the sect parameter.

The ares_dns_record_rr_add() function adds a new resource record entry to the DNS record provided by the dnsrec parameter. The resulting resource record is stored into the variable pointed to by rr_out. The DNS section the resource record belongs to is specified by the sect parameter. The domain name associated with the resource record is specified by the name parameter, which can not be NULL but may be an empty string, or ".". The resource record type is specified in the type parameter, along with the DNS record class in the rclass parameter, and the Time To Live (TTL) in the ttl parameter.

The ares_dns_record_rr_get() and ares_dns_record_rr_get_const() functions are used to retrieve the resource record pointer from the DNS record provided in the dnsrec parameter, for the resource record section provided in the sect parameter, for the specified index in the idx parameter. The index must be less than ares_dns_record_rr_cnt(). The former returns a writable pointer to the resource record, while the latter returns a read-only pointer to the resource record.

The ares_dns_record_rr_del() is used to delete a resource record from the DNS record specified in the dnsrec parameter. Its primary use is to remove a ARES_REC_TYPE_OPT record when needing to retry a query without EDNS support. The DNS RR section is specified via the sect parameter, and the index to remove is specified in the idx parameter. The index must be less than ares_dns_record_rr_cnt().

The ares_dns_rr_get_name() function is used to retrieve the resource record domain name from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_get_type() function is used to retrieve the resource record type from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_get_class() function is used to retrieve the resource record class from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_get_ttl() function is used to retrieve the resource record class Time to Live (TTL) from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_set_addr() function is used to set an IPv4 address for the associated resource record key/parameter when the datatype is ARES_DATATYPE_INADDR. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the addr parameter.

The ares_dns_rr_set_addr6() function is used to set an IPv6 address for the associated resource record key/parameter when the datatype is ARES_DATATYPE_INADDR6. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the addr parameter.

The ares_dns_rr_set_str() function is used to set a string for the associated resource record key/parameter when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. Most strings are limited to 255 bytes, however some records, such as a TXT record may allow longer as they are output as multiple strings. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_u8() function is used to set an 8bit unsigned value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_U8. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_u16() function is used to set an 16bit unsigned value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_U16. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_u32() function is used to set an 32bit unsigned value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_U32. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_bin() function is used to set a binary value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter. And the associated value length is provided in the len parameter.

The ares_dns_rr_add_abin() function is used to append a binary value in the array for the associated resource record key/parameter when the datatype is ARES_DATATYPE_ABINP. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter. And the associated value length is provided in the len parameter.

The ares_dns_rr_del_abin() function is used to delete a binary value in the array for the associated resource record key/parameter when the datatype is ARES_DATATYPE_ABINP. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter. And the associated value length is provided in the len parameter.

La función ares_dns_rr_set_opt(3) se usa para establecer las claves y valores de opción/parámetro para el registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt, y se deja al usuario determinar el valor apropiado a utilizar. Algunos valores conocidos pueden ser proporcionados por las enumeraciones ares_svcb_param_t y ares_opt_param_t. El valor de la opción siempre se proporciona en forma binaria en val con la longitud proporcionada en val_len

.

La función ares_dns_rr_del_opt_byid(3) se usa para eliminar las claves y valores de opción/parámetro para el registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt. encontrado.

key.

key.

key.

La función ares_dns_rr_get_u8(3) se usa para recuperar un entero de 8 bits del registro de recursos cuando el tipo de dato es ARES_DATATYPE_U8. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

key.

key.
