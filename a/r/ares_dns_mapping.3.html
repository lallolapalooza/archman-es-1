ares_dns_datatype_t - Tipos de datos asociados con ares_dns_rr_key_t

:
ARES_DATATYPE_INADDR - Dirección IPv4 como struct in_addr *. Utilice ares_dns_rr_set_addr(3) para establecer y ares_dns_rr_get_addr(3) para obtener.
ARES_DATATYPE_INADDR6 - Dirección IPv6 como struct ares_in6_addr *. Utilice ares_dns_rr_set_addr6(3) para establecer y ares_dns_rr_get_addr6(3) para obtener.
ARES_DATATYPE_U8 - Entero sin signo de 8 bits. Utilice ares_dns_rr_set_u8(3) para establecer y ares_dns_rr_get_u8(3) para obtener.
ARES_DATATYPE_U16 - Entero sin signo de 16 bits. Utilice ares_dns_rr_set_u16(3) para establecer y ares_dns_rr_get_u16(3) para obtener.
ARES_DATATYPE_U32 - Entero sin signo de 32 bits. Utilice ares_dns_rr_set_u32(3) para establecer y ares_dns_rr_get_u32(3) para obtener.
ARES_DATATYPE_NAME - Cadena terminada en nulo de un nombre de dominio (serie de etiquetas). Utilice ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_STR - Cadena terminada en nulo. Utilice ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_BIN - Datos binarios. Utilice ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_BINP - Oficialmente definido como datos binarios, pero probablemente imprimible. Garantizado para tener un terminador NULL por conveniencia (no incluido en la longitud). Utilice ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_OPT - Matriz de opciones. Identificador de 16 bits, datos binarios. Utilice ares_dns_rr_set_opt(3) para establecer y ares_dns_rr_get_opt(3) para obtener.
ARES_DATATYPE_ABINP - Matriz de datos binarios, pero probablemente imprimible. Garantizado para tener un terminador NULL por conveniencia (no incluido en la longitud). Utilice ares_dns_rr_add_abin(3) para establecer y ares_dns_rr_get_abin(3) para obtener. También puede usar ares_dns_rr_set_bin(3) y ares_dns_rr_get_bin(3) si solo se desean cadenas concatenadas.

ares_dns_opt_datatype_t - Tipos de datos asociados con parámetros ARES_DATATYPE_OPT si se conocen, tal como los devuelve ares_dns_opt_get_da

tatype(3):
ARES_OPT_DATATYPE_NONE - No se permite ningún valor para este parámetro
ARES_OPT_DATATYPE_STR_LIST - Lista de cadenas, cada una con un prefijo de un solo octeto que representa la longitud según lo definido por RFC 1035. Puede usar ares_expand_string(3) hasta que se consuma el búfer.
ARES_OPT_DATATYPE_U8_LIST - Lista de enteros sin signo de 8 bits, concatenados
ARES_OPT_DATATYPE_U16 - Entero sin signo de 16 bits en orden de bytes de red
ARES_OPT_DATATYPE_U16_LIST - lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_U32 - Entero sin signo de 32 bits en orden de bytes de red
ARES_OPT_DATATYPE_U32_LIST - lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_INADDR4_LIST - Lista de direcciones ipv4 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_INADDR6_LIST - Lista de direcciones ipv6 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_BIN - Datos binarios
ARES_OPT_DATATYPE_NAME - Formato binario de nombre de dominio DNS según lo definido en RFC1035, puede usar ares_expand_name(3)

ares_svcb_param_t - Parámetros conocidos de RR SVCB (y HTTPS) tal como los devuelve ares_dns_opt_get_datatype(3) con ARES_RR_SVCB_PARAMS o ARES_RR_HTTPS_PARAMS

:
ARES_SVCB_PARAM_MANDATORY - Claves obligatorias en este RR (RFC 9460 Sección 8). Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_SVCB_PARAM_ALPN - Protocolos adicionales admitidos (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_STR_LIST
ARES_SVCB_PARAM_NO_DEFAULT_ALPN - Sin soporte para el protocolo predeterminado (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_NONE
ARES_SVCB_PARAM_PORT - Puerto para el punto final alternativo (RFC 9460 Sección 7.2). Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_SVCB_PARAM_IPV4HINT - Sugerencias de dirección IPv4 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR4_LIST
ARES_SVCB_PARAM_ECH - RESERVADO (mantenido para Encrypted ClientHello)
ARES_SVCB_PARAM_IPV6HINT - Sugerencias de dirección IPv6 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR6_LIS
T

ares_opt_param_t - Parámetros conocidos de RR OPT tal como los devuelve ares_dns_opt_get_datatype(3) con ARES_RR_OPT_OPTIONS

:
ARES_OPT_PARAM_LLQ - RFC 8764. Protocolo de consultas de larga duración de Apple para DNS. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_UL - http://files.dns-sd.org/draft-sekar-dns-ul.txt: Arrendamiento de actualización. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_NSID - RFC 5001. Identificación del servidor de nombres. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_DAU - RFC 6975. Algoritmo DNSSEC comprendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_DHU - RFC 6975. Hash DS comprendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_N3U - RFC 6975. Hash NSEC3 comprendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_EDNS_CLIENT_SUBNET - RFC 7871. Subred del cliente. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_EXPIRE - RFC 7314. Temporizador de expiración. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_COOKIE - RFC 7873. Cookies de cliente y servidor. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_TCP_KEEPALIVE - RFC 7828. Tiempo de espera de keepalive TCP. Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_OPT_PARAM_PADDING - RFC 7830. Relleno. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_CHAIN - RFC 7901. Solicitudes de consulta en cadena. Tipo de dato: ARES_OPT_DATATYPE_NAME
ARES_OPT_PARAM_EDNS_KEY_TAG - RFC 8145. Señalización del conocimiento del ancla de confianza en DNSSEC. Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_OPT_PARAM_EXTENDED_DNS_ERROR - RFC 8914. Código y mensaje de ERROR extendido. Tipo de dato: ARES_OPT_DATATYPE_BIN

DESCRIPCIÓ

N

La función ares_dns_rec_type_tostr(3) La función outputs a human readable DNS record type from its numeric form passed in type

.

The ares_dns_class_tostr(3) function outputs a human readable DNS class from its numeric form passed in qclass

.

The ares_dns_opcode_tostr(3) function outputs a human readable DNS opcode from its numeric form in opcode

.

The ares_dns_rr_key_tostr(3) function outputs a human readable DNS Resource Record parameter name from its numeric form in key

.

The ares_dns_section_tostr(3) function outputs a human readable DNS message section from its numeric form in section

.

The ares_dns_rcode_tostr(3) function outputs a human readable DNS response code from its numeric form in rcode

.

The ares_dns_class_fromstr(3) function outputs the DNS class in numeric from from its string representation in str. The result is stored into the variable pointed to by qclass

.

The ares_dns_rec_type_fromstr(3) function outputs the DNS record type in numeric from from its string representation in str. The result is stored into the variable pointed to by qtype

.

The ares_dns_rr_get_keys(3) function retrieves a list of parameters that may be set or retrieved for the provided type. The count of returned keys is stored into the variable pointed to by cnt

.

The ares_dns_rr_key_datatype(3) function retrieves the associated datatype for an RR parameter specified by key

.

The ares_dns_rr_key_to_rec_type(3) function dereferences the provided RR parameter specified by key to the DNS Record Type it

belongs.

The ares_dns_opt_get_datatype(3) function is used in association with ares_dns_rr_set_opt(3) and ares_dns_rr_get_opt(3) to retrieve the datatype of an option record contained within an RR as specified in key if it is known. The raw option record identifier is provided by opt

.

The ares_dns_opt_get_name(3) function is used in association with ares_dns_rr_set_opt(3) and ares_dns_rr_get_opt(3) to retrieve human readable parameter name of an option record contained within an RR as specified in key if it is known. The raw option record identifier is provided by op

t
.

VALORES DE

RETORNO

ares_dns_rec_type_tostr(3), ares_dns_class_tostr(3), ares_dns_opcode_tostr(3), ares_dns_rr_key_tostr(3), ares_dns_section_tostr(3), ares_dns_rcode_tostr(3), and ares_dns_opt_get_name(3) all return a human printable ASCII string, or NULL on

error.

ares_dns_class_fromstr(3) and ares_dns_rec_type_fromstr(3) return ARES_TRUE on successful conversion, otherwise ARES_FALSE

.

ares_dns_rr_get_keys(3) returns an array of keys or NULL on

failure.

ares_dns_rr_key_datatype(3), ares_dns_rr_key_to_rec_type(3), and ares_dns_opt_get_datatype(3) return their re

spective integer values
, or 0 on failure.
