ARCHIVE_WRITE_NEW(3) Manual de funciones de biblioteca ARCHIVE_WRITE_NEW(3)

NOMBRE

archive_write_new — funciones para crear archivos

BIBLIOTECA

Biblioteca de archivos en streaming (libarchive, -larchive)

SINOPSIS

#include <archive.h>

struct archive *
archive_write_new(void);

DESCRIPCIÓN

Asigna e inicializa un objeto struct archive adecuado para escribir un archivo tar. Se devuelve NULL en caso de error.

Una descripción completa del objeto struct archive se puede encontrar en la página del manual de descripción general de libarchive(3).

VER TAMBIÉN
