ARES_SET_LOCAL_DEV(3) Manual de funciones de biblioteca ARES_SET_LOCAL_DEV(3)

NOMBRE

ares_set_local_dev - Vincula a un dispositivo de red específico al crear sockets.

SINOPSIS

#include <ares.h>
void ares_set_local_dev(ares_channel_t *channel, const char* local_dev_name)

DESCRIPCIÓN

La función ares_set_local_dev hace que todos los sockets futuros se vinculen a este dispositivo con SO_BINDTODEVICE. Esto fuerza a que las comunicaciones pasen a través de una interfaz determinada, lo que puede ser útil en máquinas multi-homed. Esta opción solo se admite en Linux, la interfaz no debe estar ya vinculada al socket o el usuario efectivo actual debe tener la capacidad CAP_NET_RAW en el espacio de nombres de red actual para que la opción funcione. Si SO_BINDTODEVICE no es compatible o la llamada a setsockopt falla (probablemente debido a permisos), el error se ignora silenciosamente.

VER TAMBIÉN
