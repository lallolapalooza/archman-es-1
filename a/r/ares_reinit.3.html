ares_reinit(3)

Paquete: c-ares

Licencias: MIT

ARES_REINIT(3) Manual de funciones de biblioteca ARES_REINIT(3)

NOMBRE

ares_reinit - Reinicializa un canal de resolución a partir de la configuración del sistema.

SINOPSIS

#include <ares.h>
int ares_reinit(ares_channel_t *channel)

DESCRIPCIÓN

La función ares_reinit(3) relee la configuración del sistema y la aplica de forma segura al canal existente. La configuración del sistema nunca anulará las configuraciones proporcionadas por el usuario, como las proporcionadas a través de ares_init_options(3) o ares_set_servers(3).

Cualquier consulta existente se volverá a encolar automáticamente si el servidor al que están actualmente asignadas se elimina de la configuración del sistema.

Esta función puede provocar la creación de descriptores de archivo adicionales y la destrucción de los existentes si la configuración del servidor ha cambiado.

Es seguro para subprocesos, ya que iniciará un hilo en segundo plano para leer la configuración y aplicarla. Es crucial que los desarrolladores utilicen ARES_OPT_SOCK_STATE_CB o ARES_OPT_EVENT_THREAD para que se notifiquen los cambios. Si se utiliza ares_getsock(3) o ares_fds(3), no es posible ninguna notificación, lo que podría causar un bloqueo.

VALORES DE RETORNO

ares_reinit(3) puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La inicialización se realizó correctamente.
ARES_EFILE
No se pudo leer un archivo de configuración.
ARES_ENOMEM
Se agotó la memoria disponible del proceso.

DISPONIBILIDAD

Esta función se introdujo por primera vez en la versión 1.22.0 de c-ares.

VER TAMBIÉN
