DESCRIPCIÓ

N

Estas funciones son específicas de

glibc.

Un vector argz es un puntero a un búfer de caracteres junto con una longitud. La interpretación prevista del búfer de caracteres es un array de cadenas, donde las cadenas están separadas por bytes nulos ('\0'). Si la longitud no es cero, el último byte del búfer debe ser un byte

nulo.

Estas funciones son para manejar vectores argz. La pareja (NULL,0) es un vector argz y, a la inversa, los vectores argz de longitud 0 deben tener un puntero nulo. La asignación de vectores argz no vacíos se realiza utilizando malloc(3), de modo que free(3) pueda usarse para liberarlos

nuevamente.

argz_add() añade la cadena str al final del array *argz, y actualiza *argz y *argz_len

.

argz_add_sep() es similar, pero divide la cadena str en subcadenas separadas por el delimitador delim. Por ejemplo, uno podría usar esto en una ruta de búsqueda UNIX con el delimitador ':

'.

argz_append() añade el vector argz (buf,buf_len) después de (*argz,*argz_len) y actualiza *argz y *argz_len. (Así, *argz_len se incrementará en buf_le

n.)

argz_count() cuenta el número de cadenas, es decir, el número de bytes nulos ('\0'), en (argz,argz_le

n).

argz_create() convierte un vector de argumentos al estilo UNIX argv, terminado por (char *) 0, en un vector argz (*argz,*argz_l

en).

argz_create_sep() convierte la cadena terminada por nulo str en un vector argz (*argz,*argz_len) dividiéndola en cada aparición del separador sep

.

argz_delete() elimina la subcadena a la que apunta entry del vector argz (*argz,*argz_len) y actualiza *argz y *argz_len

.

argz_extract() es lo opuesto de argz_create(). Toma el vector argz (argz,argz_len) y rellena el array que comienza en argv con punteros a las subcadenas, y un NULL final, creando un vector argv al estilo UNIX. El array argv debe tener espacio para argz_count(argz, argz_len) + 1

punteros.

argz_insert() es lo opuesto de argz_delete(). Inserta el argumento entry en la posición before en el vector argz (*argz,*argz_len) y actualiza *argz y *argz_len. Si before es NULL, entonces entry se insertará al

final.

argz_next() es una función para recorrer el vector argz. Si entry es NULL, se devuelve la primera entrada. De lo contrario, se devuelve la entrada siguiente. Devuelve NULL si no hay una entrada

siguiente.

argz_replace() reemplaza cada aparición de str con with, realocando argz según sea necesario. Si replace_count no es NULL, *replace_count se incrementará en el número de

reemplazos.

argz_stringify() es lo opuesto de argz_create_sep(). Transforma el vector argz en una cadena normal reemplazando todos los bytes nulos ('\0') excepto el último por se

p
.

    NAME

    argz_extract - extract arguments from an argz string

    SYNOPSIS

    #include <argz.h>

error_t argz_extract(const char *restrict argz, size_t argz_len,
                     char ***restrict argv, size_t *restrict argv_count);

    DESCRIPTION

    The argz_extract function extracts the arguments from an argz string pointed to by argz with a total length of argz_len bytes. The arguments are returned in an array of strings pointed to by argv, and the number of arguments is returned in argv_count. The allocated memory for the argv array and the strings it contains should be freed using free.

    An argz string is a contiguous block of memory containing a sequence of null- terminated strings, with the last string also terminated by a null byte.

    RETURN VALUE

    On success, argz_extract returns 0. On failure, it returns an error number.

    errno can be set to the following values:

    ENOMEM
    Insufficient memory to allocate the argument array or strings.

    ATTRIBUTES

    For an explanation of the terms used in this section, see attributes(7).

    Interface Attribute
    argz_extract NOCANCEL, ThreadSafe

    STANDARDS

    This is a GNU extension.

    BUGS

    The documentation states that the returned strings are copies and that the entire array including the strings can be freed with a single call to free. This is not true. The array itself and each string within the array must be freed individually.
