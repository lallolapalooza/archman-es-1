ares_dns_opt_get_datatype(3)

Paquete: c-ares

Licencias: MIT

ARES_DNS_MAPPINGS(3) Manual de funciones de biblioteca ARES_DNS_MAPPINGS(3)

NOMBRE

ares_dns_class_fromstr, ares_dns_class_tostr, ares_dns_datatype_t, ares_dns_opcode_tostr, ares_dns_opt_datatype_t, ares_dns_opt_get_datatype, ares_dns_opt_get_name, ares_dns_rcode_tostr, ares_dns_rec_type_fromstr, ares_dns_rr_get_keys, ares_dns_rr_key_datatype, ares_dns_rr_key_to_rec_type, ares_dns_rr_key_tostr, ares_dns_section_tostr, ares_opt_param_t, ares_svcb_param_t - Funciones auxiliares para convertir identificadores de registros DNS a y desde sus tipos respectivos, así como para identificar tipos de datos para varios registros.

SINOPSIS

#include <ares.h>
const char *ares_dns_rec_type_tostr(ares_dns_rec_type_t type);
const char *ares_dns_class_tostr(ares_dns_class_t qclass);
const char *ares_dns_opcode_tostr(ares_dns_opcode_t opcode);
const char *ares_dns_rr_key_tostr(ares_dns_rr_key_t key);
const char *ares_dns_section_tostr(ares_dns_section_t section);
const char *ares_dns_rcode_tostr(ares_dns_rcode_t rcode);
ares_bool_t ares_dns_class_fromstr(ares_dns_class_t *qclass, const char *str);
ares_bool_t ares_dns_rec_type_fromstr(ares_dns_rec_type_t *qtype,
                                      const char *str);
const ares_dns_rr_key_t *ares_dns_rr_get_keys(ares_dns_rec_type_t type,
                                              size_t *cnt);
ares_dns_datatype_t ares_dns_rr_key_datatype(ares_dns_rr_key_t key);
ares_dns_rec_type_t ares_dns_rr_key_to_rec_type(ares_dns_rr_key_t key);
ares_dns_opt_datatype_t ares_dns_opt_get_datatype(ares_dns_rr_key_t key,
                                                  unsigned short opt);
const char *ares_dns_opt_get_name(ares_dns_rr_key_t key, unsigned short opt);

ENUMERACIONES

ares_dns_datatype_t - Tipos de datos asociados con ares_dns_rr_key_t:

ARES_DATATYPE_INADDR - Dirección IPv4 como struct in_addr *. Use ares_dns_rr_set_addr(3) para establecer y ares_dns_rr_get_addr(3) para obtener.
ARES_DATATYPE_INADDR6 - Dirección IPv6 como struct ares_in6_addr *. Use ares_dns_rr_set_addr6(3) para establecer y ares_dns_rr_get_addr6(3) para obtener.
ARES_DATATYPE_U8 - Entero sin signo de 8 bits. Use ares_dns_rr_set_u8(3) para establecer y ares_dns_rr_get_u8(3) para obtener.
ARES_DATATYPE_U16 - Entero sin signo de 16 bits. Use ares_dns_rr_set_u16(3) para establecer y ares_dns_rr_get_u16(3) para obtener.
ARES_DATATYPE_U32 - Entero sin signo de 32 bits. Use ares_dns_rr_set_u32(3) para establecer y ares_dns_rr_get_u32(3) para obtener.
ARES_DATATYPE_NAME - Cadena terminada en nulo de un nombre de dominio (serie de etiquetas). Use ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_STR - Cadena terminada en nulo. Use ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_BIN - Datos binarios. Use ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_BINP - Oficialmente definido como datos binarios, pero probablemente imprimibles. Garantizado que tiene un terminador NULL para conveniencia (no incluido en la longitud). Use ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_OPT - Matriz de opciones. Identificador de 16 bits, Datos binarios. Use ares_dns_rr_set_opt(3) para establecer y ares_dns_rr_get_opt(3) para obtener.
ARES_DATATYPE_ABINP - Matriz de datos binarios, pero probablemente imprimibles. Garantizado que tiene un terminador NULL para conveniencia (no incluido en la longitud). Use ares_dns_rr_add_abin(3) para establecer y ares_dns_rr_get_abin(3) para obtener. También puede usar ares_dns_rr_set_bin(3) y ares_dns_rr_get_bin(3) si solo se desean cadenas concatenadas.

ares_dns_opt_datatype_t - Tipos de datos asociados con los parámetros de ARES_DATATYPE_OPT si se conocen y son devueltos por ares_dns_opt_get_datatype(3):

ARES_OPT_DATATYPE_NONE - No se permite valor para este parámetro
ARES_OPT_DATATYPE_STR_LIST - Lista de cadenas, cada una prefijada con un octeto que representa la longitud según lo definido por RFC 1035. Puede usar ares_expand_string(3) hasta que el búfer se consuma.
ARES_OPT_DATATYPE_U8_LIST - Lista de enteros sin signo de 8 bits, concatenados
ARES_OPT_DATATYPE_U16 - Entero sin signo de 16 bits en orden de bytes de red
ARES_OPT_DATATYPE_U16_LIST - Lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_U32 - Entero sin signo de 32 bits en orden de bytes de red
ARES_OPT_DATATYPE_U32_LIST - Lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_INADDR4_LIST - Lista de direcciones IPv4 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_INADDR6_LIST - Lista de direcciones IPv6 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_BIN - Datos binarios
ARES_OPT_DATATYPE_NAME - Formato binario de nombre de dominio DNS según lo definido en RFC1035, puede usar ares_expand_name(3)

ares_svcb_param_t - Parámetros conocidos de SVCB (y HTTPS) RR devueltos por ares_dns_opt_get_datatype(3) con ARES_RR_SVCB_PARAMS o ARES_RR_HTTPS_PARAMS:

ARES_SVCB_PARAM_MANDATORY - Claves obligatorias en este RR (RFC 9460 Sección 8). Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_SVCB_PARAM_ALPN - Protocolos adicionales admitidos (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_STR_LIST
ARES_SVCB_PARAM_NO_DEFAULT_ALPN - Sin soporte para protocolo predeterminado (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_NONE
ARES_SVCB_PARAM_PORT - Puerto para punto final alternativo (RFC 9460 Sección 7.2). Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_SVCB_PARAM_IPV4HINT - Sugerencias de direcciones IPv4 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR4_LIST
ARES_SVCB_PARAM_ECH - RESERVADO (reservado para Encrypted ClientHello)
ARES_SVCB_PARAM_IPV6HINT - Sugerencias de direcciones IPv6 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR6_LIST

ares_opt_param_t - Parámetros conocidos de OPT RR devueltos por ares_dns_opt_get_datatype(3) con ARES_RR_OPT_OPTIONS:

ARES_OPT_PARAM_LLQ - RFC 8764. Protocolo de Consultas de Larga Duración (LLQ) de DNS de Apple. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_UL - http://files.dns-sd.org/draft-sekar-dns-ul.txt: Arrendamiento de Actualización (Update Lease). Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_NSID - RFC 5001. Identificación del Servidor de Nombres. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_DAU - RFC 6975. Algoritmos DNSSEC Comprendidos. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_DHU - RFC 6975. Hashes DS Comprendidos. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_N3U - RFC 6975. Hashes NSEC3 Comprendidos. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_EDNS_CLIENT_SUBNET - RFC 7871. Subred del Cliente. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_EXPIRE - RFC 7314. Temporizador de Expiración. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_COOKIE - RFC 7873. Cookies del Cliente y Servidor. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_TCP_KEEPALIVE - RFC 7828. Tiempo de espera de mantenimiento de conexión TCP. Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_OPT_PARAM_PADDING - RFC 7830. Relleno. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_CHAIN - RFC 7901. Solicitudes de consulta de cadena. Tipo de dato: ARES_OPT_DATATYPE_NAME
ARES_OPT_PARAM_EDNS_KEY_TAG - RFC 8145. Señalización del conocimiento del ancla de confianza en DNSSEC. Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_OPT_PARAM_EXTENDED_DNS_ERROR - RFC 8914. Código y mensaje de ERROR extendido. Tipo de dato: ARES_OPT_DATATYPE_BIN

DESCRIPCIÓN

Las funciones ares_dns_rec_type_tostr y similares son la contraparte de ares_dns_class_fromstr y ares_dns_rec_type_fromstr. Cada uno toma un valor de enumeración y devuelve la cadena ASCII correspondiente, o NULL si el valor no es reconocido. De manera similar, las funciones con prefijo `fromstr` intentan convertir una cadena ASCII en el valor de enumeración correspondiente, devolviendo ARES_TRUE y estableciendo el valor de salida si tiene éxito, o ARES_FALSE y dejando el valor de salida sin cambiar si la cadena no es reconocida. Se espera que las cadenas de nombre de dominio para los tipos RR y las etiquetas de opciones sean canonizadas en minúsculas.

Ares está diseñado para la resolución de nombres y la gestión de registros DNS. Las funciones documentadas aquí son utilidades para que los desarrolladores accedan y manipulen la información de los registros de manera más sencilla, especialmente al trabajar con tipos de registros y opciones complejos o menos comunes, o cuando se necesita representar los datos en un formato legible por humanos.

NOTA: A partir de la versión 1.28.1, la familia de funciones `ares_dns_rr_key_*` es utilizada por el soporte de ares para la conversión entre el formato nativo de la biblioteca de los datos del registro y el formato serializado en la red. Su uso directo probablemente no sea necesario para la mayoría de los desarrolladores.

Las funciones `ares_dns_opt_get_datatype` y `ares_dns_opt_get_name` son métodos para consultar el tipo de dato esperado de un parámetro conocido dentro de un registro OPT o un registro SVCB/HTTPS, así como el nombre canónico de dicho parámetro si existe.

La enumeración `ares_dns_datatype_t` es un mapeo de los tipos de datos nativos de C que son utilizados por las diversas estructuras de registro que ares puede crear o consumir. Esto permite que las funciones de acceso a los registros seleccionen el tipo de getter/setter correcto para el campo en cuestión.

La enumeración `ares_dns_opt_datatype_t` es una descripción de cómo se espera que los datos de un parámetro de registro OPT se codifiquen según los RFC pertinentes. Si se le solicita, la función `ares_dns_opt_get_datatype` devolverá uno de estos valores para indicar el tipo de datos esperado.

La enumeración `ares_svcb_param_t` es un mapeo de los parámetros comunes definidos en RFC 9460 para los registros SVCB y HTTPS. La función `ares_dns_opt_get_datatype` puede devolver estos valores cuando se le proporciona una clave de registro de tipo SVCB o HTTPS, y también proporciona el tipo de dato esperado para el parámetro.

La enumeración `ares_opt_param_t` es un mapeo de los parámetros comunes definidos en varios RFC para los registros OPT. La función `ares_dns_opt_get_datatype` puede devolver estos valores cuando se le proporciona una clave de registro de tipo OPT, y también proporciona el tipo de dato esperado para el parámetro.

VALORES DE RETORNO

Las funciones que devuelven cadenas devuelven un puntero a una cadena constante. El llamador no debe liberar este puntero. Las funciones `*_fromstr` devuelven `ares_bool_t`.

.

La función ares_dns_class_tostr(3) devuelve una clase DNS legible por humanos a partir de su forma numérica pasada en qclass

.

La función ares_dns_opcode_tostr(3) devuelve un código de operación DNS legible por humanos a partir de su forma numérica en opcode

.

La función ares_dns_rr_key_tostr(3) devuelve un nombre de parámetro de Registro de Recurso DNS legible por humanos a partir de su forma numérica en key

.

La función ares_dns_section_tostr(3) devuelve una sección de mensaje DNS legible por humanos a partir de su forma numérica en section

.

La función ares_dns_rcode_tostr(3) devuelve un código de respuesta DNS legible por humanos a partir de su forma numérica en rcode

.

La función ares_dns_class_fromstr(3) devuelve la clase DNS en forma numérica a partir de su representación de cadena en str. El resultado se almacena en la variable a la que apunta qclass

.

La función ares_dns_rec_type_fromstr(3) devuelve el tipo de registro DNS en forma numérica a partir de su representación de cadena en str. El resultado se almacena en la variable a la que apunta qtype

.

La función ares_dns_rr_get_keys(3) recupera una lista de parámetros que pueden establecerse o recuperarse para el type proporcionado. El número de claves devueltas se almacena en la variable a la que apunta cnt

.

La función ares_dns_rr_key_datatype(3) recupera el tipo de dato asociado para un parámetro RR especificado por key

.

La función ares_dns_rr_key_to_rec_type(3) resuelve la referencia del parámetro RR proporcionado especificado por key al Tipo de Registro DNS al que

pertenece.

La función ares_dns_opt_get_datatype(3) se utiliza en asociación con ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt(3) para recuperar el tipo de dato de un registro de opción contenido dentro de un RR, tal como se especifica en key, si se conoce. El identificador crudo del registro de opción lo proporciona opt

.

La función ares_dns_opt_get_name(3) se utiliza en asociación con ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt(3) para recuperar el nombre de parámetro legible por humanos de un registro de opción contenido dentro de un RR, tal como se especifica en key, si se conoce. El identificador crudo del registro de opción lo proporciona op

t.
