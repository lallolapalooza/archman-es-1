ares_getsock(3)

Paquete: c-ares

Licencias: MIT

ARES_GETSOCK(3) Manual de Funciones de Biblioteca ARES_GETSOCK(3)

NOMBRE

ares_getsock - obtener descriptores de socket en los que esperar (obsoleto)

SINOPSIS

#include <ares.h>
int ares_getsock(const ares_channel_t *channel, ares_socket_t *socks,
                 int numsocks);

DESCRIPCIÓN

La función ares_getsock recupera el conjunto de descriptores de socket en los que la aplicación que llama debería esperar para leer y/o escribir para el procesamiento de consultas de nombres de servicio pendientes en el canal de nombres de servicio identificado por channel. Los descriptores de socket se establecerán en el array de descriptores de socket apuntado por socks. numsocks es el tamaño del array dado en número de enteros.

Esta función solo puede devolver información de hasta 16 sockets. Si se utilizan más, simplemente no se informan.

VALORES DE RETORNO

ares_getsock devuelve una máscara de bits para qué acciones esperar en los diferentes sockets. El archivo de cabecera ares.h proporciona estas macros de conveniencia para extraer la información apropiadamente:

#define ARES_GETSOCK_MAXNUM 16 /* ares_getsock() puede devolver información
                                  sobre este número de sockets */
#define ARES_GETSOCK_READABLE(bits,num) (bits & (1<< (num)))
#define ARES_GETSOCK_WRITABLE(bits,num) (bits & (1 << ((num) +                                          ARES_GETSOCK_MAXNUM)))

NOTAS

Esta función se añadió en c-ares 1.3.1 y se marcó como obsoleta en c-ares 1.20.0 debido a la implementación de ARES_OPT_MAX_UDP_QUERIES, que hace probable exceder los 16 descriptores de archivo abiertos.

Se recomienda usar ARES_OPT_EVENT_THREAD pasado a ares_init_options(3) o usar callbacks de estado de socket (ARES_OPT_SOCK_STATE_CB) registrados a través de ares_init_options(3).

VER TAMBIÉN

ares_init_options(3), ares_timeout(3), ares_fds(3), ares_process(3)
