archive_write_blocksize(3)

Paquete: libarchive

Licencias: BSD-2-Clause

ARCHIVE_WRITE_BLOCKSIZE(3) Manual de funciones de la biblioteca ARCHIVE_WRITE_BLOCKSIZE(3)

NOMBRE

archive_write_get_bytes_per_block, archive_write_set_bytes_per_block, archive_write_get_bytes_in_last_block, archive_write_set_bytes_in_last_block — funciones para la creación de archivos

BIBLIOTECA

Biblioteca de archivos en streaming (libarchive, -larchive)

SINOPSIS

#include <archive.h>

int
archive_write_get_bytes_per_block(struct archive *);

int
archive_write_set_bytes_per_block(struct archive *, int bytes_per_block);

int
archive_write_get_bytes_in_last_block(struct archive *);

int
archive_write_set_bytes_in_last_block(struct archive *, int);

DESCRIPCIÓN

archive_write_set_bytes_per_block()
Establece el tamaño del bloque utilizado para escribir los datos del archivo. Cada llamada a la función de devolución de llamada de escritura, excepto posiblemente la última, utilizará este valor como longitud. El valor por defecto es utilizar un tamaño de bloque de 10240 bytes. Tenga en cuenta que un tamaño de bloque de cero suprimirá el bloqueo interno y hará que las escrituras se envíen directamente a la función de devolución de llamada de escritura a medida que ocurran.
archive_write_get_bytes_per_block()
Recupera el tamaño del bloque que se utilizará para escribir. Un valor de -1 aquí indica que la biblioteca debe utilizar los valores predeterminados. Un valor de cero indica que se suprime el bloqueo interno.
archive_write_set_bytes_in_last_block()
Establece el tamaño del bloque utilizado para escribir el último bloque. Si este valor es cero, el último bloque se rellenará hasta el mismo tamaño que los otros bloques. De lo contrario, el bloque final se rellenará hasta un múltiplo de este tamaño. En particular, establecerlo en 1 hará que el bloque final no se rellene. Para la salida comprimida, cualquier relleno generado por esta opción se aplica solo después de la compresión. Los datos sin comprimir siempre se devuelven sin relleno. El valor predeterminado es rellenar el último bloque hasta el tamaño completo del bloque (tenga en cuenta que archive_write_open_filename() lo establecerá según el tipo de archivo). A diferencia de las otras funciones de "establecer", esta función se puede llamar después de que el archivo se haya abierto.
archive_write_get_bytes_in_last_block()
Recupera el valor actualmente configurado para el tamaño del último bloque. Un valor de -1 aquí indica que la biblioteca debe utilizar los valores predeterminados.

VALORES DE RETORNO

archive_write_set_bytes_per_block() y archive_write_set_bytes_in_last_block() devuelven ARCHIVE_OK en caso de éxito, o ARCHIVE_FATAL.

archive_write_get_bytes_per_block() y archive_write_get_bytes_in_last_block() devuelven el tamaño de bloque configurado actualmente (-1 indica el tamaño de bloque predeterminado), o ARCHIVE_FATAL.

ERRORES

Los códigos de error detallados y las descripciones textuales están disponibles en las funciones archive_errno() y archive_error_string().
