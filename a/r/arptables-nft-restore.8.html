NOMBRE

arptables-restore — Restaura las Tablas ARP (basado en nft)

SINOPSIS

arptables-restore

DESCRIPCIÓN

arptables-restore se utiliza para restaurar las Tablas ARP a partir de datos especificados en STDIN o a través de un archivo como primer argumento. Utilice la redirección de I/O proporcionada por su shell para leer desde un archivo.

arptables-restore
descarga (elimina) todo el contenido previo de la Tabla ARP respectiva.

AUTOR
