DESCRIPCIÓ

N

El propósito de un depurador como GDB es permitirte ver qué está ocurriendo "dentro" de otro programa mientras se ejecuta -- o qué estaba haciendo otro programa en el momento en que se

bloqueó.

GDB puede hacer cuatro tipos principales de cosas (más otras cosas en apoyo de estas) para ayudarte a atrapar errores en el

acto:
  • Iniciar tu programa, especificando cualquier cosa que pueda afectar su
    • comportamiento.
  • Hacer que tu programa se detenga en condiciones
    • especificadas.
  • Examinar lo que ha sucedido cuando tu programa se ha
    • detenido.
  • Cambiar cosas en tu programa, para que puedas
    • experimentar con corregir los efectos
de un error y seguir aprendiendo sobre otro.

Puedes usar GDB para depurar programas escritos en C, C++, Fortran y

Modula-2.

GDB se invoca con el comando de shell "gdb". Una vez iniciado, lee comandos desde la terminal hasta que le digas que salga con el comando de GDB "quit" o "exit". Puedes obtener ayuda en línea de GDB mismo usando el comando "help"

.

Puedes ejecutar "gdb" sin argumentos u opciones; pero la forma más usual de iniciar GDB es con un argumento o dos, especificando un programa ejecutable como

argumento: 
gdb
program

También puedes iniciar con un programa ejecutable y un archivo de volcado de memoria (core)

especificados: 
gdb program
core

Puedes, en su lugar, especificar un ID de proceso como segundo argumento o usar la opción "-p", si quieres depurar un proceso en

ejecución: 
gdb program 1234
gdb -p
1234

adjuntaría GDB al proceso 1234. Con la opción -p puedes omitir el nombre de archivo del

programa.

Cualquier argumento que no sea una opción especifica un archivo ejecutable y un archivo de volcado de memoria (o ID de proceso); es decir, el primer argumento encontrado sin una opción de bandera asociada es equivalente a una opción --se, y el segundo, si existe, es equivalente a una opción -c si es el nombre de un archivo. Muchas opciones tienen tanto formas largas como abreviadas; ambas se muestran aquí. Las formas largas también se reconocen si las trunca, siempre que haya suficiente de la opción presente para ser

inequívoca.

Las formas abreviadas se muestran aquí con - y las formas largas se muestran con -- para reflejar cómo se muestran en --help. Sin embargo, GDB reconoce todas las siguientes convenciones para la mayoría de las
