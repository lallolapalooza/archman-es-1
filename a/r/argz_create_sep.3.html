DESCRIPCIÓN

Estas funciones son específicas de glibc.

Un vector argz es un puntero a un búfer de caracteres junto con una longitud. La interpretación prevista del búfer de caracteres es una matriz de cadenas, donde las cadenas están separadas por bytes nulos ('\0'). Si la longitud no es cero, el último byte del búfer debe ser un byte nulo.

Estas funciones son para manejar vectores argz. El par (NULL,0) es un vector argz y, a la inversa, los vectores argz de longitud 0 deben tener un puntero nulo. La asignación de vectores argz no vacíos se realiza utilizando malloc(3), de modo que free(3) pueda usarse para liberarlos nuevamente.

argz_add() añade la cadena str al final del array *argzy actualiza *argz y *argz_len.

argz_add_sep() es similar, pero divide la cadena str en subcadenas separadas por el delimitador delim. Por ejemplo, uno podría usar esto en una ruta de búsqueda UNIX con el delimitador ':'.

argz_append() añade el vector argz (buf,buf_len) después de (*argz,*argz_len) y actualiza *argz y *argz_len. (Así, *argz_len se incrementará en buf_len.)

argz_count() cuenta el número de cadenas, es decir, el número de bytes nulos ('\0'), en (argz,argz_len).

argz_create() convierte un vector de argumentos al estilo UNIX argv, terminado por (char *) 0, en un vector argz (*argz,*argz_len).

argz_create_sep() convierte la cadena terminada en nulo str en un vector argz (*argz,*argz_len) dividiéndola en cada ocurrencia del separador sep.

argz_delete() elimina la subcadena a la que apunta entry del vector argz (*argz,*argz_len) y actualiza *argz y *argz_len.

argz_extract() es lo opuesto de argz_create(). Toma el vector argz (argz,argz_len) y rellena la matriz que comienza en argv con punteros a las subcadenas, y un NULL final, creando un vector argv al estilo UNIX. La matriz argv debe tener espacio para argz_count(argz, argz_len) + 1 punteros.

argz_insert() es lo opuesto de argz_delete(). Inserta el argumento entry en la posición before en el vector argz (*argz,*argz_len) y actualiza *argz y *argz_len. Si before es NULL, entonces entry se insertará al final.

argz_next() es una función para recorrer el vector argz. Si entry es NULL, se devuelve la primera entrada. De lo contrario, se devuelve la entrada siguiente. Devuelve NULL si no hay una entrada siguiente.

argz_replace() reemplaza cada ocurrencia de str con with, realocando argz según sea necesario. Si replace_count no es NULL, *replace_count se incrementará en el número de reemplazos.

argz_stringify() es lo opuesto de argz_create_sep(). Transforma el vector argz en una cadena normal reemplazando todos los bytes nulos ('\0') excepto el último por sep.

VALOR DE RETORNO

Todas las funciones argz que realizan asignación de memoria tienen un tipo de retorno de error_t (un tipo entero), y devuelven 0 para éxito, y ENOMEM si ocurre un error de asignación.

    NAME

    argz_create_sep - Create an argz string from a separated string

    SYNOPSIS

    #include <argz.h>

    error_t argz_create_sep(const char *string, char sep, char **argz, size_t *len);

    DESCRIPTION

    The argz_create_sep function creates a new argz string from the input string. The input string is split into arguments using the separator character sep. The arguments are stored in a contiguous block of memory pointed to by *argz, and the total length of the argz string (including the null terminators) is stored in *len. The argz string is terminated by two null characters.

    If the input string is empty, an argz string consisting of a single null character is created.

    The memory for the argz string is allocated using malloc and should be freed using free.

    ARGUMENTS

    • string: The input string to be converted.
    • sep: The separator character.
    • argz: A pointer to a pointer to store the newly created argz string.
    • len: A pointer to store the length of the argz string.

    RETURN VALUE

    On success, argz_create_sep returns 0. On failure, it returns an error number.

    ATTRIBUTES

    For information about the attributes of the functions of this library, see attributes(7).

    STANDARDS

    GNU libargz.

    BUGS

    No known bugs.
