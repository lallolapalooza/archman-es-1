ares_set_servers(3)

Paquete: c-ares

Licencias: MIT

ARES_SET_SERVERS(3) Manual de funciones de biblioteca ARES_SET_SERVERS(3)

NOMBRE

ares_set_servers, ares_set_servers_ports - Inicializa la configuración del servidor de nombres para un canal de ares. (obsoleto)

SINOPSIS

#include <ares.h>
int ares_set_servers(ares_channel_t *channel,
                     const struct ares_addr_node *servers)
int ares_set_servers_ports(ares_channel_t *channel,
                           const struct ares_addr_port_node *servers)

DESCRIPCIÓN

La función ares_set_servers(3) inicializa la configuración del servidor de nombres para los datos del canal identificados por channel, a partir de un puntero servers a una lista enlazada de estructuras ares_addr_node que contienen datos de dirección del servidor de nombres.

El argumento puntero a la lista enlazada del servidor de nombres puede ser el resultado de una llamada anterior a ares_get_servers(3) o una lista enlazada de estructuras ares_addr_node configuradas por otros medios.

La función ares_set_servers_ports(3) también permite la especificación de puertos UDP y TCP que se utilizarán para la comunicación en una base por servidor. El argumento de lista enlazada proporcionado puede ser el resultado de una llamada anterior a ares_get_servers_ports(3) o una lista enlazada de estructuras ares_addr_port_node configuradas por otros medios.

Esta función reemplaza cualquier servidor de nombres previamente configurado con los proporcionados en la lista enlazada. Por lo tanto, para configurar un canal con más de un servidor de nombres, todos los deseados deben especificarse en una sola lista. Aunque no se recomienda, pasar NULL borrará todos los servidores configurados y dejará un canal inoperable; esto puede ser ventajoso para simulaciones de prueba, pero es poco probable que sea útil en producción.

La función no toma posesión del argumento de la lista enlazada. El llamador es responsable de liberar la lista enlazada cuando ya no se necesite.

Esta función es capaz de manejar direcciones de servidores de nombres IPv4 e IPv6 simultáneamente, lo que hace que ares_init_options(3) con optmask ARES_OPT_SERVERS sea funcionalmente obsoleto, excepto para el uso de servidores de nombres solo IPv4.

A partir de la versión 1.22.0, esta función se puede llamar en un canal activo con consultas en curso; anteriormente, devolvería ARES_ENOTIMP.

VALORES DE RETORNO

ares_set_servers(3) puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La configuración del servidor de nombres se inicializó correctamente.
ARES_ENOMEM
Se agotó la memoria disponible del proceso.
ARES_ENODATA
Los datos del canal identificados por channel no eran válidos.
ARES_ENOTINITIALIZED
La inicialización de la biblioteca c-ares aún no se ha realizado.

VER TAMBIÉN

ares_set_servers_csv(3), ares_get_servers(3), ares_init_options(3), ares_dup(3)

NOTAS

Funciones obsoletas a partir de c-ares 1.24.0 debido a la incapacidad de establecer todas las opciones de servidor disponibles. Use ares_set_servers_csv(3).

DISPONIBILIDAD

ares_set_servers(3) se agregó en c-ares 1.7.1; ares_set_servers_ports(3) se agregó en c-ares 1.11.0.
