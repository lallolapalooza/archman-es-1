ares_dns_record_rr_cnt(

3)

Le renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect. La fonction ares_dns_record_rr_add(

3)

ajoute une nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide ou ".". Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl. Les fonctions ares_dns_record_rr_get(3) et ares_dns_record_rr_get_const(

3)

Le sont utilisées pour récupérer le pointeur de l'enregistrement de ressources à partir de l'enregistrement DNS fourni dans le paramètre dnsrec, pour la section d'enregistrement de ressources fournie dans le paramètre sect, pour l'index spécifié dans le paramètre idx. L'index doit être inférieur à [[109] ] ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de ressources. La fonction ares_dns_record_rr_del(3

)

Le est utilisée pour supprimer un enregistrement de ressources de l'enregistrement DNS spécifié dans le paramètre dnsrec. Son usage principal est de supprimer un enregistrement ARES_REC_TYPE_OPT lorsqu'il est nécessaire de réessayer une requête sans support EDNS. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à [[116]] ares_dns_record_rr_cnt(3) . ENUMERATIONS

These functions use the datatype enum ares_datatype_t, defined in ares_dns_mapping(3). It is an enumeration of valid datatypes that can be stored in a resource record.

These functions use the ares_status_t return code which is defined in ares_init(3).

Some functions take an integer key. This is expected to be a type from the ares_dns_type_t enumeration defined in ares_mapping(3).

DESCRIPTION

The following functions are provided to allow manipulation of resource records that are not tied to a specific DNS type.

The ares_dns_record_rr_add function adds a new resource record to the DNS recordset. The resource record is provided in the dns_rr parameter.

The ares_dns_record_rr_del function removes a resource record from the DNS recordset. The resource record to be removed is provided in the dns_rr parameter.

The ares_dns_record_rr_cnt function returns the number of resource records in the DNS recordset.

The ares_dns_record_rr_get function returns the resource record at index idx in the DNS recordset.

The ares_dns_record_rr_get_const function returns the const resource record at index idx in the DNS recordset.

The ares_dns_rr_set_addr function is used to set an IPv4 address for the resource record when the datatype is ARES_DATATYPE_INADDR. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The address is provided in the addr parameter.

The ares_dns_rr_set_addr6 function is used to set an IPv6 address for the resource record when the datatype is ARES_DATATYPE_INADDR6. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The address is provided in the addr6 parameter.

The ares_dns_rr_set_str function is used to set a string value for the resource record when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The string value is provided in the str parameter.

The ares_dns_rr_set_u8 function is used to set an 8bit unsigned integer value for the resource record when the datatype is ARES_DATATYPE_U8. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The value is provided in the val parameter.

The ares_dns_rr_set_u16 function is used to set a 16bit unsigned integer value for the resource record when the datatype is ARES_DATATYPE_U16. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The value is provided in the val parameter.

The ares_dns_rr_set_u32 function is used to set a 32bit unsigned integer value for the resource record when the datatype is ARES_DATATYPE_U32. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The value is provided in the val parameter.

The ares_dns_rr_set_bin function is used to set binary data for the resource record when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The binary value is provided in val with length provided in val_len.

The ares_dns_rr_add_abin function is used to add binary data to the resource record array when the datatype is ARES_DATATYPE_ABINP. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter. The binary value is provided in val with length provided in val_len.

The ares_dns_rr_del_abin function is used to delete binary data from the resource record array when the datatype is ARES_DATATYPE_ABINP. The resource record to be modified is provided in the dns_rr parameter and the key/parameter is provided in the key parameter, and the index to remove is provided in the idx parameter.

The ares_dns_rr_set_opt function is used to set option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter, and this is left to the user to determine the appropriate value to use. Some known values may be provided by ares_svcb_param_t and ares_opt_param_t enumerations. The value for the option is always provided in binary form in val with length provided in val_len.

The ares_dns_rr_del_opt_byid function is used to delete option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter. This function returns ARES_SUCCESS if the record is successfully removed, or ARES_ENOTFOUND if the record could not be found.

The ares_dns_rr_get_addr function is used to retrieve the IPv4 address from the resource record when the datatype is ARES_DATATYPE_INADDR. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_addr6 function is used to retrieve the IPv6 address from the resource record when the datatype is ARES_DATATYPE_INADDR6. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_str function is used to retrieve a string from the resource record when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u8 function is used to retrieve an 8bit integer from the resource record when the datatype is ARES_DATATYPE_U8. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u16 function is used to retrieve a 16bit integer from the resource record when the datatype is ARES_DATATYPE_U16. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u32 function is used to retrieve a 32bit integer from the resource record when the datatype is ARES_DATATYPE_U32. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_bin function is used to retrieve binary data from the resource record when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_abin_cnt function is used to retrieve the count of the array of stored binary values from the resource record when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_abin function is used to retrieve binary data from the resource record array when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and the index to retrieve from the array is provided by the idx parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_opt_cnt function is used to retrieve the count of options/parameters associated with the resource record when the datatype is ARES_DATATYPE_OPT. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key.

The ares_dns_rr_get_opt function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified index. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the index to retrieve the option data from is provided in the idx parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

The ares_dns_rr_get_opt_byid function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified option identifier, if it exists. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the identifier to retrieve the option data from is provided in the opt parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

RETURN VALUES

ares_dns_record_rr_cnt and ares_dns_rr_get_opt_cnt return the respective counts.

ares_dns_record_rr_add, ares_dns_record_rr_del, ares_dns_rr_set_addr, ares_dns_rr_set_addr6, ares_dns_rr_set_str, ares_dns_rr_set_u8, ares_dns_rr_set_u16, ares_dns_rr_set_u32, ares_dns_rr_set_bin, ares_dns_rr_add_abin, ares_dns_rr_del_abin, and ares_dns_rr_set_opt all return an ares_status_t error code. ARES_SUCCESS is returned on success, ARES_ENOMEM is returned on out of memory, ARES_EFORMERR is returned on misuse.

ares_dns_rr_get_name, ares_dns_rr_get_type, ares_dns_rr_get_class, ares_dns_rr_get_ttl, ares_dns_rr_get_addr, ares_dns_rr_get_addr6, ares_dns_rr_get_str, ares_dns_rr_get_u8, ares_dns_rr_get_u16, ares_dns_rr_get_u32, ares_dns_rr_get_bin, ares_dns_rr_get_abin_cnt, ares_dns_rr_get_abin, ares_dns_rr_get_opt all return their prescribed datatype values and in general can't fail except for misuse cases, in which a 0 (or NULL) may be returned, however 0 can also be a valid return value for most of these functions.

ares_dns_record_rr_get and ares_dns_record_rr_get_const will return the requested resource record pointer or NULL on failure (misuse).

ares_dns_rr_get_opt_byid will return ARES_TRUE if the option was found, otherwise ARES_FALSE if not found (or misuse).

AVAILABILITY

These functions were first introduced in c-ares version 1.22.0.
