NOMBRE

ares_expand_name - Expande un nombre de dominio codificado en DNS

SINOPSIS

#include <ares.h>
int ares_expand_name(const unsigned char *encoded,
                     const unsigned char *abuf, int alen,
                     char **s, long *enclen)

DESCRIPCIÓN

La función ares_expand_name convierte un nombre de dominio codificado en DNS a una cadena C separada por puntos. El argumento encoded proporciona el inicio del nombre de dominio codificado, y los argumentos abuf y alen proporcionan el búfer de mensaje contenedor (necesario para el procesamiento de punteros de indirección dentro del nombre de dominio codificado). El resultado se coloca en un búfer asignado terminado en NUL, un puntero al cual se almacena en la variable apuntada por s. La longitud del nombre codificado se almacena en la variable apuntada por enclen para que el llamador pueda avanzar más allá del nombre de dominio codificado para leer datos adicionales en el mensaje.

Utilice ares_free_string(3) para liberar el nombre de host asignado.

VALORES DE RETORNO

ares_expand_name puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La expansión del nombre codificado se realizó con éxito.
ARES_EBADNAME
El nombre de dominio codificado estaba mal formado y no pudo ser expandido.
ARES_ENOMEM
Se agotó la memoria.

VER TAMBIÉN

ares_mkquery(3), ares_free_string(3)
