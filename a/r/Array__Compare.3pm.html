Array::Compare(3) Documentación de Perl aportada por el usuario Array::Compare(3)

NOMBRE

Array::Compare - Extensión de Perl para comparar arreglos.

SINOPSIS

use Array::Compare;
my $comp1 = Array::Compare->new;
$comp->Sep('|');
$comp->Skip({3 => 1, 4 => 1});
$comp->WhiteSpace(0);
$comp->Case(1);
my $comp2 = Array::Compare->new(Sep => '|',
                                WhiteSpace => 0,
                                Case => 1,
                                Skip => {3 => 1, 4 => 1});
my @arr1 = 0 .. 10;
my @arr2 = 0 .. 10;
$comp1->compare(\@arr1, \@arr2);
$comp2->compare(\@arr1, \@arr2);

DESCRIPCIÓN

Si tienes dos arreglos y quieres saber si son iguales o diferentes, entonces Array::Compare te será útil.

Todas las comparaciones se realizan a través de un objeto comparador. En el uso más simple, puedes crear y usar un objeto comparador así:

my @arr1 = 0 .. 10;
my @arr2 = 0 .. 10;
my $comp = Array::Compare->new;
if ($comp->compare(\@arr1, \@arr2)) {
  print "Los arreglos son iguales\n";
} else {
  print "Los arreglos son diferentes\n";
}

Nota que pasas referencias a los dos arreglos al método de comparación.

Internamente, el comparador compara los dos arreglos utilizando "join" para convertir ambos arreglos en cadenas y comparando las cadenas usando "eq". En las cadenas unidas, los elementos de los arreglos originales están separados con el carácter "^G" . Esto puede causar problemas si los datos de tu arreglo contienen "^G" caracteres, ya que es posible que dos arreglos diferentes puedan convertirse en la misma cadena.

Para evitar esto, es posible anular el carácter separador predeterminado, ya sea pasando una alternativa a la "new" función

my $comp = Array::Compare->new(Sep => '|');

o cambiando el separador para un objeto comparador existente

$comp->Sep('|');

En general, deberías elegir un carácter separador que no aparezca en tus datos.

También puedes controlar si el espacio en blanco dentro de los elementos de los arreglos debe considerarse significativo al hacer la comparación. El valor predeterminado es que todo el espacio en blanco es significativo. La alternativa es que todos los caracteres de espacio en blanco consecutivos se conviertan en un solo espacio para los fines de la comparación. Nuevamente, esto se puede activar al crear un objeto comparador:

my $comp = Array::Compare->new(WhiteSpace => 0);

o alterando un objeto existente:

$comp->WhiteSpace(0);

También puedes controlar si las mayúsculas y minúsculas de los datos son significativas en la comparación. El valor predeterminado es que las mayúsculas y minúsculas de los datos se tomen en cuenta. Esto se puede cambiar de las maneras estándar al crear un nuevo objeto comparador:

my $comp = Array::Compare->new(Case => 0);

o alterando un objeto existente:

$comp->Case(0);

Además de la comparación simple descrita anteriormente (que devuelve verdadero si los arreglos son iguales y falso si son diferentes) también hay una comparación completa que devuelve una lista que contiene los índices de los elementos que difieren entre los dos arreglos. Si los arreglos son iguales devuelve una lista vacía. En contexto escalar, la comparación completa devuelve la longitud de esta lista (es decir, el número de elementos que difieren). Puedes acceder a la comparación completa de dos maneras. Primero, hay un "DefFull" atributo. Si este es "verdadero" entonces se lleva a cabo una comparación completa cada vez que se llama al "compare" método.

my $comp = Array::Compare->new(DefFull => 1);
$comp->compare(\@arr1, \@arr2); # Comparación completa
$comp->DefFull(0);
$comp->compare(\@arr1, \@arr2); # Comparación simple
$comp->DefFull(1);
$comp->compare(\@arr1, \@arr2); # Comparación completa de nuevo

Segundo, puedes acceder al método de comparación completa directamente

$comp->full_compare(\@arr1, \@arr2);

Por simetría, también hay un método directo para usar para llamar a la comparación simple.

$comp->simple_compare(\@arr1, \@arr2);

La última complicación es la capacidad de omitir elementos en la comparación. Si sabes que dos arreglos siempre diferirán en un elemento particular pero quieres comparar los arreglos ignorando este elemento, puedes hacerlo con Array::Compare sin tomar porciones de arreglos. Para hacer esto, un objeto comparador tiene un atributo opcional llamado "Skip" que es una referencia a un hash. Las claves en este hash son los índices de los elementos del arreglo y los valores deben ser cualquier valor verdadero para los elementos que deben omitirse.

Por ejemplo, si quieres comparar dos arreglos, ignorando los valores en los elementos dos y cuatro, puedes hacer algo así:

my %skip = (2 => 1, 4 => 1);
my @a = (0, 1, 2, 3, 4, 5);
my @b = (0, 1, X, 3, X, 5);
my $comp = Array::Compare->new(Skip => \%skip);
$comp->compare(\@a, \@b);

Esto debería devolver verdadero, ya que estamos ignorando explícitamente las columnas que difieren.

Por supuesto, habiendo creado un objeto comparador sin hash de omisión, es posible agregar uno más tarde:

$comp->Skip({1 => 1, 2 => 1});

o:

my %skip = (1 => 1, 2 => 2);
$comp->Skip(\%skip);

Para restablecer el comparador para que ya no omita elementos, llama a NoSkip().

$comp->NoSkip();

También puedes verificar si un arreglo es una permutación de otro, es decir, contienen los mismos elementos pero en un orden diferente.

if ($comp->perm(\@a, \@b) {
  print "Los arreglos son permutaciones\n";
} else {
  print "No. Los arreglos son completamente diferentes\n";
}

En este caso, los valores de "WhiteSpace" y "Case" todavía se usan, pero "Skip" se ignora por, esperemos que, razones obvias.

MÉTODOS

new [ %OPCIONES ]

Construye un nuevo objeto de comparación.

Toma un hash opcional que contiene varias opciones que controlan cómo se realizan las comparaciones. Cualquier opción omitida toma valores predeterminados útiles.

Sep
Este es el valor que se usa para separar campos cuando el arreglo se une en una cadena. Debería ser un valor que no aparezca en tus datos. El valor predeterminado es '^G'.
WhiteSpace
Bandera que indica si el espacio en blanco es significativo en la comparación. Si este valor es falso, entonces todos los caracteres de espacio en blanco múltiples se cambian a un solo espacio antes de que tenga lugar la comparación. El valor predeterminado es 1 (el espacio en blanco es significativo).
Case
Bandera que indica si las mayúsculas y minúsculas de los datos deben ser significativas en la comparación. El valor predeterminado es 1 (las mayúsculas y minúsculas son significativas).
Skip
una referencia a un hash que contiene los números de las columnas que deben omitirse en la comparación. El valor predeterminado es un hash vacío (todas las columnas son significativas).
NoSkip
Restablece los detalles de las columnas omitidas. Asigna {} al atributo "Skip".
DefFull
Bandera que indica si la comparación predeterminada es simple (solo devuelve verdadero si los arreglos son iguales o falso si no lo son) o completa (devuelve un arreglo que contiene los índices de las columnas que difieren). El valor predeterminado es 0 (comparación simple).

compare_len \@ARR1, \@ARR2

Comparación muy simple. Solo verifica que las longitudes de los arreglos sean iguales.

different_len \@ARR1, \@ARR2

Recibe dos arreglos y devuelve verdadero si tienen longitudes diferentes.

Esto es solo lo inverso de "compare_len" (que está mal nombrado).

compare \@ARR1, \@ARR2

Compara los valores en dos arreglos yeturna un dato que indica si las matrices son iguales. Los valores de retorno exactos difieren dependiendo del método de comparación utilizado. Consulte las descripciones de simple_compare y full_compare para más detalles.

Utiliza el valor de DefFull para determinar qué rutina de comparación usar.

simple_compare \@ARR1, \@ARR2

Compara los valores en dos matrices y devuelve un indicador que señala si las matrices son iguales o no.

Devuelve verdadero si las matrices son iguales o falso si difieren.

Utiliza los valores de 'Sep', 'WhiteSpace' y 'Skip' para influir en la comparación.

full_compare \@ARR1, \@ARR2

Realiza una comparación completa entre dos matrices.

Comprueba cada columna individual. En contexto escalar devuelve el número de columnas que difieren (cero si las matrices son iguales). En contexto de lista devuelve una lista que contiene los índices de las columnas que difieren (una lista vacía si las matrices son iguales).

Utiliza los valores de 'Sep' y 'WhiteSpace' para influir en la comparación.

Nota: Si las dos matrices tienen longitudes diferentes, este método simplemente devuelve los índices de los elementos que aparecen en una matriz pero no en la otra (es decir, los índices de la matriz más larga que están más allá del final de la matriz más corta). Esto puede ser un poco contraintuitivo.

perm \@ARR1, \@ARR2

Comprueba si una matriz es una permutación de la otra (es decir, contiene el mismo conjunto de elementos, pero en un orden diferente).

Hacemos esto ordenando las matrices y pasando referencias a las versiones ordenadas a simple_compare. También hay algunos cambios pequeños en simple_compare, ya que debería ignorar el hash Skip si somos llamados desde perm.

VER TAMBIÉN

Array::Diff - mientras que Array::Compare se centra en si dos matrices son diferentes, "Array::Diff" te dice cómo son diferentes.

Test::Deep - funciones para comparar estructuras de datos arbitrarias, como parte de un conjunto de pruebas.

List::Compare - funcionalidad similar, pero de nuevo con más opciones.

Algorithm::Diff - la implementación subyacente del algoritmo de diff. Si tienes instalado Algorithm::Diff::XS, se usará ese.

YAML::Diff - encuentra la diferencia entre dos documentos YAML.

HTML::Differences - encuentra la diferencia entre dos documentos HTML. Este usa un enfoque más sensato que HTML::Diff.

XML::Diff - encuentra la diferencia entre dos documentos XML.

Hash::Diff - encuentra las diferencias entre dos hashes de Perl.

Data::Diff - encuentra la diferencia entre dos estructuras de datos arbitrarias.

Text::Diff - puede encontrar la diferencia entre dos entradas, que pueden ser estructuras de datos o nombres de archivos.
