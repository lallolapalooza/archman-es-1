Paquete: c-ares

ARES_GETHOSTBYNAME(3) Manual de funciones de biblioteca ARES_GETHOSTBYNAME(3)

NOMBRE

ares_gethostbyname - Inicia una consulta de host por nombre

SINOPSIS

#include <ares.h>
typedef void (*ares_host_callback)(void *arg, int status,
                                   int timeouts,
                                   struct hostent *hostent)
void ares_gethostbyname(ares_channel_t *channel, const char *name,
                        int family, ares_host_callback callback,
                        void *arg)

DESCRIPCIÓN

La función ares_gethostbyname inicia una consulta de host por nombre en el canal de servicio de nombres identificado por channel. El parámetro name proporciona el nombre de host como una cadena de C terminada en NUL y family proporciona el tipo de dirección deseado para la entrada de host resultante. Cuando la consulta se complete o haya fallado, la biblioteca ares invocará a callback. La finalización o el fallo de la consulta pueden ocurrir inmediatamente o durante una llamada posterior a ares_process(3), ares_destroy(3) o ares_cancel(3).

El argumento de callback arg se copia del argumento arg de ares_gethostbyname. El argumento de callback status indica si la consulta tuvo éxito y, si no, cómo falló. Puede tener cualquiera de los siguientes valores:

ARES_SUCCESS
La búsqueda de host se completó con éxito.
ARES_ENOTIMP
La biblioteca ares no sabe cómo encontrar direcciones del tipo family.
ARES_EBADNAME
El nombre de host name está compuesto enteramente de números y puntos, pero no es una representación válida de una dirección de Internet.
ARES_ENODATA
No se devolvieron datos para extraer un resultado.
ARES_ENOTFOUND
No se encontró el nombre name.
ARES_ENOMEM
Se agotó la memoria.
ARES_ECANCELLED
La consulta fue cancelada.
ARES_EDESTRUCTION
El canal de servicio de nombres channel está siendo destruido; la consulta no se completará.

El argumento de callback timeouts informa cuántas veces una consulta caducó durante la ejecución de la solicitud dada.

En caso de éxito de la consulta, el argumento de callback hostent apunta a un struct hostent que contiene el nombre del host devuelto por la consulta. El callback no necesita ni debe intentar liberar la memoria apuntada por hostent; la biblioteca ares la liberará cuando el callback retorne. Si la consulta no se completó con éxito, hostent será NULL.

Cuando se llama al callback asociado, se llama con un bloqueo de canal, por lo que se debe tener cuidado de asegurar que cualquier procesamiento sea mínimo para evitar bloqueos en el canal DNS.

El callback puede activarse desde un hilo diferente al que llamó a ares_gethostbyname(3).

Para los integradores que ejecutan sus propios bucles de eventos y no utilizan ARES_OPT_EVENT_THREAD, se debe tener cuidado para asegurar que las listas de descriptores de archivos se actualicen inmediatamente dentro del bucle de eventos cuando se notifiquen.
