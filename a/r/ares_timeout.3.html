ares_timeout(3)

Paquete: c-ares

Licencias: MIT

ARES_TIMEOUT(3) Manual de funciones de biblioteca ARES_TIMEOUT(3)

NOMBRE

ares_timeout - devuelve el tiempo máximo de espera

SINOPSIS

#include <ares.h>
struct timeval *ares_timeout(const ares_channel_t *channel,
                             struct timeval *maxtv,
                             struct timeval *tv)

DESCRIPCIÓN

La función ares_timeout(3) determina el tiempo máximo durante el cual el llamador debe esperar antes de invocar ares_process(3) para procesar los tiempos de espera. El parámetro maxtv especifica un tiempo de espera máximo existente, o NULL si el llamador no desea aplicar un tiempo de espera máximo. El parámetro tv debe apuntar a un buffer escribible de tipo struct timeval. Es válido que maxtv y tv tengan el mismo valor.

Si ninguna consulta tiene tiempos de espera pendientes antes del tiempo de espera máximo dado, ares_timeout(3) devuelve el valor de maxtv; de lo contrario, ares_timeout(3) almacena el valor de tiempo de espera apropiado en el buffer apuntado por tv y devuelve el valor de tv.

VER TAMBIÉN

ares_fds(3), ares_process(3), ares_process_fd(3)
