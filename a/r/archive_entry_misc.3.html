ARCHIVE_ENTRY_MISC(3) Manual de Funciones de Librería ARCHIVE_ENTRY_MISC(3)

NOMBRE

archive_entry_symlink_type, archive_entry_set_symlink_type — funciones misceláneas para manipular propiedades de archive_entry

BIBLIOTECA

Librería de Archivo en Streaming (libarchive, -larchive)

SINOPSIS

#include <archive_entry.h>

int
archive_entry_symlink_type(struct archive_entry *a);

void
archive_entry_set_symlink_type(struct archive_entry *a, int);

DESCRIPCIÓN

La función archive_entry_symlink_type() devuelve y la función archive_entry_set_symlink_type() establece el tipo del enlace simbólico almacenado en una entrada de archivo. Estas funciones tienen un significado especial en sistemas operativos que soportan múltiples tipos de enlaces simbólicos (por ejemplo, Microsoft Windows).

Los valores soportados son:

AE_SYMLINK_TYPE_UNDEFINED
El tipo del objetivo del enlace simbólico no está definido (por defecto en sistemas unix)
AE_SYMLINK_TYPE_FILE
El enlace simbólico apunta a un archivo
AE_SYMLINK_TYPE_DIRECTORY
El enlace simbólico apunta a un directorio

VER TAMBIÉN

archive_entry(3), archive_entry_paths(3), archive_entry_stat(3), libarchive(3)
