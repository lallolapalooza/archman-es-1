argz_add(3) Manual de Funciones de Biblioteca argz_add(3)

NOMBRE

argz_add, argz_add_sep, argz_append, argz_count, argz_create, argz_create_sep, argz_delete, argz_extract, argz_insert, argz_next, argz_replace, argz_stringify - funciones para manejar una lista argz

BIBLIOTECA

Biblioteca C estándar (libc,-lc)

SINOPSIS

#include <argz.h>
error_t argz_add(char **restrict argz, size_t *restrict argz_len,
                const char *restrict str);
error_t argz_add_sep(char **restrict argz, size_t *restrict argz_len,
                const char *restrict str, int delim);
error_t argz_append(char **restrict argz, size_t *restrict argz_len,
                const char *restrict buf, size_t buf_len);
size_t argz_count(const char *argz, size_t argz_len);
error_t argz_create(char *const argv[], char **restrict argz,
                size_t *restrict argz_len);
error_t argz_create_sep(const char *restrict str, int sep,
                char **restrict argz, size_t *restrict argz_len);
void argz_delete(char **restrict argz, size_t *restrict argz_len,
                char *restrict entry);
void argz_extract(const char *restrict argz, size_t argz_len,
                char **restrict argv);
error_t argz_insert(char **restrict argz, size_t *restrict argz_len,
                char *restrict before, const char *restrict entry);
char *argz_next(const char *restrict argz, size_t argz_len,
                const char *restrict entry);
error_t argz_replace(char **restrict argz, size_t *restrict argz_len,
                const char *restrict str, const char *restrict with,
                unsigned int *restrict replace_count);
void argz_stringify(char *argz, size_t len, int sep);

DESCRIPCIÓN

Estas funciones son específicas de glibc.

Un vector argz es un puntero a un búfer de caracteres junto con una longitud. La interpretación prevista del búfer de caracteres es un array de cadenas, donde las cadenas están separadas por bytes nulos ('\0'). Si la longitud no es cero, el último byte del búfer debe ser un byte nulo.

Estas funciones son para manejar vectores argz. El par (NULL,0) es un vector argz y, a la inversa, los vectores argz de longitud 0 deben tener un puntero nulo. La asignación de vectores argz no vacíos se realiza usando malloc(3), de modo que free(3) puede usarse para liberarlos nuevamente.

argz_add() añade la cadena str al final del array *argzy actualiza *argz y *argz_len.

argz_add_sep() es similar, pero divide la cadena str en subcadenas separadas por el delimitador delim. Por ejemplo, uno podría usar esto en una ruta de búsqueda de UNIX con el delimitador ':'.

argz_append() añade el vector argz (buf,buf_len) después de (*argz,*argz_len) y actualiza *argz y *argz_len. (Así, *argz_len se incrementará en buf_len.)

argz_count() cuenta el número de cadenas, es decir, el número de bytes nulos ('\0'), en (argz,argz_len).

argz_create() convierte un vector de argumentos al estilo UNIX argv, terminado por (char *) 0, en un vector argz (*argz,*argz_len).

argz_create_sep() convierte la cadena terminada en nulo str en un vector argz (*argz,*argz_len) dividiéndola en cada aparición del separador sep.

argz_delete() elimina la subcadena a la que apunta entry del vector argz (*argz,*argz_len) y actualiza *argz y *argz_len.

argz_extract() es lo opuesto de argz_create(). Toma el vector argz (argz,argz_len) y rellena el array que comienza en argv con punteros a las subcadenas, y un NULL final, creando un vector argv al estilo UNIX. El array argv debe tener espacio para argz_count(argz, argz_len) + 1 punteros.

argz_insert() es lo opuesto de argz_delete(). Inserta el argumento entry en la posición before del vector argz (*argz,*argz_len) y actualiza *argz y *argz_len. Si before es NULL, entonces entry se insertará al final.

argz_next() es una función para recorrer el vector argz. Si entry es NULL, se devuelve la primera entrada. De lo contrario, se devuelve la entrada siguiente. Devuelve NULL si no hay una entrada siguiente.

argz_replace() reemplaza cada aparición de str con with, realocando argz según sea necesario. Si replace_count no es NULL, *replace_count se incrementará en el número de reemplazos.

argz_stringify() es lo opuesto de argz_create_sep(). Transforma el vector argz en una cadena normal reemplazando todos los bytes nulos ('\0') excepto el último por sep.

VALOR DE RETORNO

Todas las funciones argz que realizan asignación de memoria tienen un tipo de retorno de error_t (un tipo entero) y devuelven 0 en caso de éxito, y ENOMEM si ocurre un error de asignación.

ERRORES
