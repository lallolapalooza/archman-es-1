ares_dns_rr_key_datatype(3)

Paquete: c-ares

Licencias: MIT

ARES_DNS_MAPPINGS(3) Manual de Funciones de Biblioteca ARES_DNS_MAPPINGS(3)

NOMBRE

ares_dns_class_fromstr, ares_dns_class_tostr, ares_dns_datatype_t, ares_dns_opcode_tostr, ares_dns_opt_datatype_t, ares_dns_opt_get_datatype, ares_dns_opt_get_name, ares_dns_rcode_tostr, ares_dns_rec_type_fromstr, ares_dns_rr_get_keys, ares_dns_rr_key_datatype, ares_dns_rr_key_to_rec_type, ares_dns_rr_key_tostr, ares_dns_section_tostr, ares_opt_param_t, ares_svcb_param_t - Funciones auxiliares para convertir identificadores de registros DNS a y desde sus respectivos tipos, así como para identificar los tipos de datos de varios registros.

SINOPSIS

#include <ares.h>
const char *ares_dns_rec_type_tostr(ares_dns_rec_type_t type);
const char *ares_dns_class_tostr(ares_dns_class_t qclass);
const char *ares_dns_opcode_tostr(ares_dns_opcode_t opcode);
const char *ares_dns_rr_key_tostr(ares_dns_rr_key_t key);
const char *ares_dns_section_tostr(ares_dns_section_t section);
const char *ares_dns_rcode_tostr(ares_dns_rcode_t rcode);
ares_bool_t ares_dns_class_fromstr(ares_dns_class_t *qclass, const char *str);
ares_bool_t ares_dns_rec_type_fromstr(ares_dns_rec_type_t *qtype,
                                      const char *str);
const ares_dns_rr_key_t *ares_dns_rr_get_keys(ares_dns_rec_type_t type,
                                              size_t *cnt);
ares_dns_datatype_t ares_dns_rr_key_datatype(ares_dns_rr_key_t key);
ares_dns_rec_type_t ares_dns_rr_key_to_rec_type(ares_dns_rr_key_t key);
ares_dns_opt_datatype_t ares_dns_opt_get_datatype(ares_dns_rr_key_t key,
                                                  unsigned short opt);
const char *ares_dns_opt_get_name(ares_dns_rr_key_t key, unsigned short opt);

ENUMERACIONES

ares_dns_datatype_t - Tipos de datos asociados con ares_dns_rr_key_t:

ARES_DATATYPE_INADDR - Dirección IPv4 como struct in_addr *. Utilice ares_dns_rr_set_addr(3) para establecer y ares_dns_rr_get_addr(3) para obtener.
ARES_DATATYPE_INADDR6 - Dirección IPv6 como struct ares_in6_addr *. Utilice ares_dns_rr_set_addr6(3) para establecer y ares_dns_rr_get_addr6(3) para obtener.
ARES_DATATYPE_U8 - Entero sin signo de 8 bits. Utilice ares_dns_rr_set_u8(3) para establecer y ares_dns_rr_get_u8(3) para obtener.
ARES_DATATYPE_U16 - Entero sin signo de 16 bits. Utilice ares_dns_rr_set_u16(3) para establecer y ares_dns_rr_get_u16(3) para obtener.
ARES_DATATYPE_U32 - Entero sin signo de 32 bits. Utilice ares_dns_rr_set_u32(3) para establecer y ares_dns_rr_get_u32(3) para obtener.
ARES_DATATYPE_NAME - Cadena terminada en nulo de un nombre de dominio (serie de etiquetas). Utilice ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_STR - Cadena terminada en nulo. Utilice ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_BIN - Datos binarios. Utilice ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_BINP - Oficialmente definido como datos binarios, pero probablemente imprimible. Garantiza tener un terminador NULL por conveniencia (no incluido en la longitud). Utilice ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_OPT - Matriz de opciones. Identificador de 16 bits, datos binarios. Utilice ares_dns_rr_set_opt(3) para establecer y ares_dns_rr_get_opt(3) para obtener.
ARES_DATATYPE_ABINP - Matriz de datos binarios, pero probablemente imprimible. Garantiza tener un terminador NULL por conveniencia (no incluido en la longitud). Utilice ares_dns_rr_add_abin(3) para establecer y ares_dns_rr_get_abin(3) para obtener. También puede usar ares_dns_rr_set_bin(3) y ares_dns_rr_get_bin(3) si solo se desean cadenas concatenadas.

ares_dns_opt_datatype_t - Tipos de datos asociados con ARES_DATATYPE_OPT parámetros si se conocen, tal como los devuelve ares_dns_opt_get_datatype(3):

ARES_OPT_DATATYPE_NONE - No se permite ningún valor para este parámetro
ARES_OPT_DATATYPE_STR_LIST - Lista de cadenas, cada una precedida por un solo octeto que representa la longitud según lo definido por RFC 1035. Puede usar ares_expand_string(3) hasta que se consuma el búfer.
ARES_OPT_DATATYPE_U8_LIST - Lista de enteros sin signo de 8 bits, concatenados
ARES_OPT_DATATYPE_U16 - Entero sin signo de 16 bits en orden de bytes de red
ARES_OPT_DATATYPE_U16_LIST - lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_U32 - Entero sin signo de 32 bits en orden de bytes de red
ARES_OPT_DATATYPE_U32_LIST - lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_INADDR4_LIST - Lista de direcciones IPv4 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_INADDR6_LIST - Lista de direcciones IPv6 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_BIN - Datos binarios
ARES_OPT_DATATYPE_NAME - Formato binario del nombre de dominio DNS según lo definido en RFC1035, puede usar ares_expand_name(3)

ares_svcb_param_t - Parámetros conocidos de los RR SVCB (y HTTPS) tal como los devuelve ares_dns_opt_get_datatype(3) con ARES_RR_SVCB_PARAMS o ARES_RR_HTTPS_PARAMS:

ARES_SVCB_PARAM_MANDATORY - Claves obligatorias en este RR (RFC 9460 Sección 8). Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_SVCB_PARAM_ALPN - Protocolos admitidos adicionales (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_STR_LIST
ARES_SVCB_PARAM_NO_DEFAULT_ALPN - Sin soporte para el protocolo predeterminado (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_NONE
ARES_SVCB_PARAM_PORT - Puerto para el punto final alternativo (RFC 9460 Sección 7.2). Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_SVCB_PARAM_IPV4HINT - Sugerencias de dirección IPv4 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR4_LIST
ARES_SVCB_PARAM_ECH - RESERVADO (reservado para Encrypted ClientHello)
ARES_SVCB_PARAM_IPV6HINT - Sugerencias de dirección IPv6 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR6_LIST

ares_opt_param_t - Parámetros conocidos del RR OPT tal como los devuelve ares_dns_opt_get_datatype(3) con ARES_RR_OPT_OPTIONS:

ARES_OPT_PARAM_LLQ - RFC 8764. Protocolo de Consultas de Vida Larga de Apple. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_UL - http://files.dns-sd.org/draft-sekar-dns-ul.txt: Arrendamiento de Actualización. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_NSID - RFC 5001. Identificación del Servidor de Nombres. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_DAU - RFC 6975. Algoritmo DNSSEC Comprendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_DHU - RFC 6975. Hash DS Comprendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_N3U - RFC 6975. Hash NSEC3 Comprendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_EDNS_CLIENT_SUBNET - RFC 7871. Subred del Cliente. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_EXPIRE - RFC 7314. Temporizador de Expiración. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_COOKIE - RFC 7873. Cookies del Cliente y del Servidor. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_TCP_KEEPALIVE - RFC 7828. Tiempo de espera de Keepalive TCP. Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_OPT_PARAM_PADDING - RFC 7830. Relleno. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_CHAIN - RFC 7901. Solicitudes de consulta en cadena. Tipo de dato: ARES_OPT_DATATYPE_NAME
ARES_OPT_PARAM_EDNS_KEY_TAG - RFC 8145. Señalización del Conocimiento del Ancla de Confianza en DNSSEC. Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_OPT_PARAM_EXTENDED_DNS_ERROR - RFC 8914. Código y mensaje de ERROR extendido. Tipo de dato: ARES_OPT_DATATYPE_BIN

DESCRIPCIÓN

La función ares_dns_rec_type_tostr(3) la función devuelve un tipo de registro DNS legible por humanos a partir de su forma numérica pasada en type.

La ares_dns_class_tostr(3) función devuelve una clase DNS legible por humanos a partir de su forma numérica pasada en qclass.

La ares_dns_opcode_tostr(3) función devuelve un código de operación DNS legible por humanos a partir de su forma numérica en opcode.

La ares_dns_rr_key_tostr(3) función devuelve un nombre de parámetro de registro de recursos DNS legible por humanos a partir de su forma numérica en key.

La ares_dns_section_tostr(3) función devuelve una sección de mensaje DNS legible por humanos a partir de su forma numérica en section.

La ares_dns_rcode_tostr(3) función devuelve un código de respuesta DNS legible por humanos a partir de su forma numérica en rcode.

La ares_dns_class_fromstr(3) función devuelve la clase DNS en forma numérica a partir de su representación de cadena en str. El resultado se almacena en la variable a la que apunta qclass.

La ares_dns_rec_type_fromstr(3) función devuelve el tipo de registro DNS en forma numérica a partir de su representación de cadena en str. El resultado se almacena en la variable a la que apunta qtype.

La ares_dns_rr_get_keys(3) función recupera una lista de parámetros que pueden establecerse o recuperarse para el typeproporcionado. El número de claves devueltas se almacena en la variable a la que apunta cnt.

La ares_dns_rr_key_datatype(3) función recupera el tipo de datos asociado para un parámetro RR especificado por key.

La ares_dns_rr_key_to_rec_type(3) función resuelve la referencia del parámetro RR proporcionado especificado por key al tipo de registro DNS al que pertenece.

La ares_dns_opt_get_datatype(3) función se utiliza en asociación con ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt(3) para recuperar el tipo de datos de un registro de opción contenido dentro de un RR como se especifica en key si se conoce. El identificador de registro de opción sin procesar lo proporciona opt.

La ares_dns_opt_get_name(3) función se utiliza en asociación con ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt(3) para recuperar el nombre de parámetro legible por humanos de un registro de opción contenido dentro de un RR como se especifica en key si se conoce. El identificador de registro de opción sin procesar lo proporciona opt.

VALORES DE RETORNO

ares_dns_rec_type_tostr(3), ares_dns_class_tostr(3), ares_dns_opcode_tostr(3), ares_dns_rr_key_tostr(3), ares_dns_section_tostr(3), ares_dns_rcode_tostr(3)y ares_dns_opt_get_name(3) devuelven todos una cadena ASCII imprimible legible por humanos, o NULL en caso de error.

ares_dns_class_fromstr(3) y ares_dns_rec_type_fromstr(3) devuelven ARES_TRUE en una conversión exitosa, de lo contrario ARES_FALSE.

ares_dns_rr_get_keys(3) devuelve un array de claves o NULL en caso de fallo.

ares_dns_rr_key_datatype(3), ares_dns_rr_key_to_rec_type(3)y ares_dns_opt_get_datatype(3) devuelven sus respectivos valores enteros, o 0 en caso de fallo.

DISPONIBILIDAD

Estas funciones se introdujeron por primera vez en la versión 1.22.0 de c-ares.
