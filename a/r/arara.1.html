ARARA(1) Manual de Comandos Generales ARARA(1)

NOMBRE

arara - una herramienta de automatización TeX basada en reglas y directivas.

SINOPSIS

arara [opciones] documentos...

DESCRIPCIÓN

arara es una herramienta de automatización TeX basada en reglas y directivas. Te proporciona una forma de mejorar tu experiencia TeX. La herramienta es un esfuerzo para proporcionar una forma concisa de automatizar el flujo de trabajo diario de TeX para usuarios y también para los escritores de paquetes. Los usuarios pueden escribir sus propias reglas cuando las proporcionadas no son suficientes.

arara toma una lista de documentos como entrada. Serán procesados de acuerdo con sus directivas. Las opciones se aplican a la ejecución de todos los documentos.

OPCIONES

--log
Genera una salida de registro.
--verbose
Imprime o suprime la salida del comando.
--dry-run
Realiza todas las acciones de ejecución de un comando pero sin llamadas reales.
--safe-run
Ejecuta en modo seguro y deshabilita características potencialmente dañinas.
--whole-file
Extrae directivas en todo el archivo, no solo en la cabecera.
--preamble
Establece el preámbulo del archivo con el nombre basado en el archivo de configuración.
--timeout
Establece un tiempo de espera de ejecución para los procesos generados.
--language
Establece la localización al idioma especificado por el código.
--max-loops
Establece el número > 0 de bucles para directivas de bucle.
--working-directory
Establece el directorio de trabajo para toda la ejecución.
--call-property
Pasa una propiedad como parámetro clave=valor a la aplicación para ser utilizada dentro de la sesión.
--generate-completion
Genera un script de finalización para arara.
--version
Muestra la versión y sale.
--help
Muestra un mensaje de ayuda y sale.
