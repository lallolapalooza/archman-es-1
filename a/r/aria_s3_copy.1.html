ARIA_S3_COPY(1) Comandos de usuario ARIA_S3_COPY(1)

NOMBRE

aria_s3_copy - Copiar una tabla Aria hacia y desde s3

DESCRIPCIÓN

Uso: aria_s3_copy --aws-access-key=# --aws-secret-access-key=# --aws-region=# --op=(from_s3 | to_s3 | delete_from_s3) [OPCIONES] tablas[.MAI]

-?, -h, --help
Mostrar ayuda y salir.
-k, --s3-access-key=nombre
ID de clave de acceso de AWS
-r, -s3-region=nombre
Región de AWS
-K, -s3-secret-key=nombre
ID de clave secreta de acceso de AWS
-b, -s3-bucket=nombre
Prefijo de AWS para las tablas
-h, -s3-host-name=nombre
Nombre del host del proveedor de S3
-c, -compress
Usar compresión
-o, -op=nombre
Operación a ejecutar. Una de 'from_s3', 'to_s3' o 'delete_from_s3'
-d, -database=nombre
Base de datos para la tabla copiada (segundo prefijo). Si no se proporciona, se utiliza el directorio del archivo de la tabla.
-B, -s3-block-size=#
Tamaño de bloque para bloques de datos/índices en s3
-L, -s3-protocol-version=nombre
Protocolo utilizado para la comunicación con S3. Uno de "Auto", "Amazon" u "Original".
-f, -force
Forzar copia incluso si el destino existe
-V, -version
Imprimir versión y salir.
--s3-debug
Mostrar registro de depuración de marias3 en stdout
-v, --verbose
Ser detallado.

Para más información, por favor consulte la página de la Base de Conocimiento de MariaDB https://mariadb.com/kb/en/aria_s3_copy/
