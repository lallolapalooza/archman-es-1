Archive::Tar::File(3perl) Guía de referencia para programadores de Perl Archive::Tar::File(3perl)

NOMBRE

Archive::Tar::File - una subclase para archivos extraídos en memoria de Archive::Tar

SINOPSIS

my @items = $tar->get_files;
print $_->name, ' ', $_->size, "\n" for @items;
print $object->get_content;
$object->replace_content('new content');
$object->rename( 'new/full/path/to/file.c' );

DESCRIPCIÓN

Archive::Tar::File proporciona una pequeña y elegante capa de objetos para archivos extraídos en memoria. Se usa principalmente internamente en Archive::Tar para ordenar el código, pero no hay razón por la que los usuarios no puedan usar esta API también.

Accessors

Muchos de los métodos en este paquete son accessors para los distintos campos en la cabecera del tar:

name
El nombre del archivo
mode
El modo del archivo
uid
El id de usuario propietario del archivo
gid
El id de grupo propietario del archivo
size
Tamaño del archivo en bytes
mtime
Tiempo de modificación. Ajustado a mac-time en MacOS si es necesario
chksum
Campo de suma de verificación para la cabecera del tar
type
Tipo de archivo -- numérico, pero comparable a constantes exportadas -- ver la documentación de Archive::Tar
linkname
Si el archivo es un symlink, el archivo al que apunta
magic
Cadena mágica del tar -- no útil para la mayoría de los usuarios
version
Cadena de versión del tar -- no útil para la mayoría de los usuarios
uname
El nombre de usuario propietario del archivo
gname
El nombre de grupo propietario del archivo
devmajor
Número mayor del dispositivo en caso de un archivo especial
devminor
Número menor del dispositivo en caso de un archivo especial
prefix
Cualquier directorio a prefijar a la ruta de extracción, si lo hay
raw
Cabecera cruda del tar -- no útil para la mayoría de los usuarios

Métodos

Archive::Tar::File->new( file => $path )

Devuelve un nuevo objeto Archive::Tar::File a partir de un archivo existente.

Devuelve undef en caso de fallo.

Archive::Tar::File->new( data => $path, $data, $opt )

Devuelve un nuevo objeto Archive::Tar::File a partir de datos.

$path define el nombre del archivo (que no necesita existir), $data los contenidos del archivo, y $opt es una referencia a un hash de atributos que pueden usarse para sobreescribir los atributos por defecto (campos en la cabecera del tar), que se describen arriba en la sección de Accessors.

Devuelve undef en caso de fallo.

Archive::Tar::File->new( chunk => $chunk )

Devuelve un nuevo objeto Archive::Tar::File a partir de un trozo crudo de 512 bytes de un archivo tar.

Devuelve undef en caso de fallo.

$bool = $file->extract( [ $alternative_name ] )

Extrae este objeto, opcionalmente a un nombre alternativo.

Ver "Archive::Tar->extract_file" para detalles.

Devuelve true en caso de éxito y false en caso de fallo.

$path = $file->full_path

Devuelve la ruta completa desde la cabecera del tar; esto es básicamente una concatenación de los campos "prefix" y "name" .

$bool = $file->validate

Hecho por Archive::Tar internamente al leer el archivo tar: valida la cabecera contra la suma de verificación para asegurar un archivo tar entero.

Devuelve true en caso de éxito, false en caso de fallo

$bool = $file->has_content

Devuelve un booleano para indicar si el objeto actual tiene contenido. Algunos archivos especiales como directorios y demás nunca tendrán contenido. Este método es principalmente para asegurarse de que no obtienes advertencias por usar valores no inicializados al mirar el contenido de un objeto.

$content = $file->get_content

Devuelve el contenido actual del archivo en memoria

$cref = $file->get_content_by_ref

Devuelve el contenido actual del archivo en memoria como una referencia escalar. Los usuarios normales no necesitarán esto, pero ahorrará memoria si estás tratando con archivos de datos muy grandes en tu archivo tar, ya que pasará los contenidos por referencia, en lugar de hacer una copia primero.

$bool = $file->replace_content( $content )

Reemplaza el contenido actual del archivo con el nuevo contenido. Esto solo afecta al archivo en memoria, no a la versión en disco hasta que lo escribas.

Devuelve true en caso de éxito, false en caso de fallo.

$bool = $file->rename( $new_name )

Renombra el archivo actual a $new_name.

Ten en cuenta que debes especificar una ruta Unix para $new_name, ya que según el estándar tar, todos los archivos en el archivo deben ser rutas Unix.

Devuelve true en caso de éxito y false en caso de fallo.

$bool = $file->chmod( $mode )

Cambia el modo de $file a $mode. El modo puede ser una cadena o un número que se interpreta como octal independientemente de si se da un 0 inicial o no.

Devuelve true en caso de éxito y false en caso de fallo.

$bool = $file->chown( $user [, $group])

Cambia el propietario de $file a $user. Si se da un $group también se cambia eso. Puedes también pasar un único parámetro con un colon separando el usuario y el grupo como en 'root:wheel'.

Devuelve true en caso de éxito y false en caso de fallo.

Métodos de conveniencia

Para comprobar rápidamente el tipo de un objeto "Archive::Tar::File" , puedes usar los siguientes métodos:

$file->is_file
Devuelve true si el archivo es de tipo "file"
$file->is_dir
Devuelve true si el archivo es de tipo "dir"
$file->is_hardlink
Devuelve true si el archivo es de tipo "hardlink"
$file->is_symlink
Devuelve true si el archivo es de tipo "symlink"
$file->is_chardev
Devuelve true si el archivo es de tipo "chardev"
$file->is_blockdev
Devuelve true si el archivo es de tipo "blockdev"
$file->is_fifo
Devuelve true si el archivo es de tipo "fifo"
$file->is_socket
Devuelve true si el archivo es de tipo "socket"
$file->is_longlink
Devuelve true si el archivo es de tipo "LongLink". No debería ocurrir después de un "read" exitoso.
$file->is_label
Devuelve true si el archivo es de tipo "Label". No debería ocurrirdespués de una lectura exitosa "read".
$file->is_unknown
Devuelve verdadero si el tipo de archivo es "unknown"
