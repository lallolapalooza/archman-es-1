ares_library_init_android(3)

Paquete: c-ares

Licencias: MIT

ARES_LIBRARY_INIT_ANDROID(3) Manual de funciones de biblioteca ARES_LIBRARY_INIT_ANDROID(3)

NOMBRE

ares_library_init_android - inicialización de la biblioteca c-ares para Android

SINOPSIS

#include <ares.h>
int ares_library_init_android(jobject connectivity_manager)
int ares_library_android_initialized();
void ares_library_init_jvm(JavaVM *jvm)

DESCRIPCIÓN

La función ares_library_init_android(3) realiza las inicializaciones internas requeridas por la biblioteca c-ares cuando se utiliza en Android. Esto puede ocurrir en cualquier momento después de ares_library_init(3). Debe ocurrir después de ares_library_init_jvm. ares_library_init_android debe llamarse antes de que la resolución DNS funcione en Android 8 (Oreo) o versiones posteriores cuando targetSdkVersion se establece en 26 o superior.

A partir de Android 8 (nivel de API 26), el acceso a la información del servidor DNS se ha vuelto más restrictivo y solo se puede acceder utilizando el Administrador de Conectividad. Es necesario pasar el administrador de conectividad a c-ares a través de JNI. Además, el permiso ACCESS_NETWORK_STATE debe estar presente en la aplicación de Android.

Las versiones de Android anteriores a la 8 no necesitan inicializarse ya que son menos restrictivas. Sin embargo, esta es una limitación en tiempo de ejecución, no en tiempo de compilación. La inicialización adecuada de Android debe realizarse independientemente de la versión de Android de destino.

La desinicialización se realizará a través de ares_library_cleanup(3).

La función ares_library_init_jvm permite al llamador registrar la JVM con c-ares. Está destinada a ser llamada durante JNI_OnLoad porque se garantiza que tendrá la JVM en esa función. La JVM es necesaria para utilizar el Administrador de Conectividad registrado con ares_library_init_android(3). Esto debe llamarse antes de ares_library_init_android(3).

La función ares_library_android_initialized se puede usar para verificar si c-ares se ha inicializado para su uso con Android.

VALORES DE RETORNO

Se devolverá ARES_SUCCESS en caso de éxito, de lo contrario se devolverá un código de error.

SEGURIDAD DE HILOS

¡Estas funciones de inicialización no son seguras para hilos! Debe llamarlas una vez que el programa haya comenzado, pero esta llamada debe realizarse antes de que el programa inicie cualquier otro hilo. Esto es necesario para evitar posibles condiciones de carrera en la inicialización de la biblioteca, y también debido al hecho de que podrían llamar a funciones de otras bibliotecas que no son seguras para hilos y podrían entrar en conflicto con cualquier otro hilo que ya esté utilizando estas otras bibliotecas.

JNI

Acceso al Administrador de Conectividad a través de Java:

Registre la inicialización nativa de ares.

  static JNINativeMethod funcs[] = {
  { "initialize_native",     "(Landroid/net/ConnectivityManager;)I",
    (void *)&ares_library_init_android}
  };
  JNIEXPORT jint JNICALL JNI_OnLoad(JavaVM *vm, void *reserved)
  {
    JNIEnv *env = NULL;
    jclass  cls = NULL;
    jint    res;
    if ((*vm)->GetEnv(vm, (void **)&env, JNI_VERSION_1_6) != JNI_OK)
      return -1;
    cls = (*env)->FindClass(env, JNIT_CLASS);
    if (cls == NULL)
      return -1;
    res = (*env)->RegisterNatives(env, cls, funcs, sizeof(funcs)/sizeof(funcs[0]));
    if (res != 0)
      return -1;
    ares_library_init_jvm(vm);
    return JNI_VERSION_1_6;
  }
Llamando a la función registrada desde Java: 
  public class MyObject {
    static {
      System.loadLibrary("cares");
    }
    private static native boolean initialize_native(ConnectivityManager
      connectivity_manager);
    public static boolean initialize(Context context) {
      initialize_native((ConnectivityManager)context.getSystemService(Context.CONNECTIVITY_SERVICE));
    }
  }

Inicializando el Administrador de Conectividad en JNI directamente utilizando un Contexto de Android. Se asume que la JVM ya ha sido registrada a través de JNI_OnLoad.

  void initialize(jobject android_context)
  {
    jclass obj_cls = jni_get_class(env, "android/content/Context");
    jmethodID obj_mid = jni_get_method_id(env, obj_cls, "getSystemService", "(Ljava/lang/String;)Ljava/lang/Object;");
    jfieldID fid = (*env)->GetStaticFieldID(env, obj_cls, "CONNECTIVITY_SERVICE", "Ljava/lang/String;");
    jstring str = (*env)->GetStaticObjectField(env, obj_cls, fid);
    connectivity_manager = (*env)->CallObjectMethod(env, android_context, obj_mid, str);
    if (connectivity_manager == NULL)
      return;
    ares_library_init_android(connectivity_manager);
  }

DISPONIBILIDAD

Esta función se introdujo por primera vez en la versión 1.15.0 de c-ares.
