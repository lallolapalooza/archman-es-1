Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

arpa/inet.h — definiciones para operaciones de internet

SINOPSIS

#include <arpa/inet.h>

DESCRIPCIÓN

El encabezado <arpa/inet.h> definirá los tipos in_port_t e in_addr_t como se describe en <netinet/in.h>.

El encabezado <arpa/inet.h> definirá la estructura in_addr como se describe en <netinet/in.h>.

El encabezado <arpa/inet.h> definirá las macros INET_ADDRSTRLEN e INET6_ADDRSTRLEN como se describe en <netinet/in.h>.

Los siguientes se declararán como funciones, o se definirán como macros, o ambas cosas. Si se declaran funciones, se proporcionarán prototipos de función.

uint32_t htonl(uint32_t);
uint16_t htons(uint16_t);
uint32_t ntohl(uint32_t);
uint16_t ntohs(uint16_t);

El encabezado <arpa/inet.h> definirá los tipos uint32_t y uint16_t como se describe en <inttypes.h>.

Los siguientes se declararán como funciones y también pueden definirse como macros. Se proporcionarán prototipos de función.

in_addr_t    inet_addr(const char *);
char        *inet_ntoa(struct in_addr);
const char  *inet_ntop(int, const void *restrict, char *restrict,
                 socklen_t);
int          inet_pton(int, const char *restrict, void *restrict);

La inclusión del encabezado <arpa/inet.h> puede hacer visibles todos los símbolos de <netinet/in.h> y <inttypes.h>.
