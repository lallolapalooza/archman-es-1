NOMBRE

ares_parse_uri_reply - Analiza una respuesta a una consulta DNS de tipo URI

SINOPSIS

#include <ares.h>
int ares_parse_uri_reply(const unsigned char* abuf, int alen,
                         struct ares_uri_reply** uri_out);

DESCRIPCIÓN

La función ares_parse_uri_reply(3) analiza la respuesta a una consulta de tipo URI en una lista enlazada de struct ares_uri_reply. Los parámetros abuf y alen proporcionan el contenido de la respuesta. El resultado se almacena en memoria asignada y un puntero a él se almacena en la variable apuntada por uri_out. Es responsabilidad del llamador liberar la estructura uri_out resultante cuando ya no sea necesaria, utilizando la función ares_free_data(3).

La estructura ares_uri_reply contiene los siguientes campos:

struct ares_uri_reply {
    struct ares_uri_reply       *next;
    unsigned short              weight;
    unsigned short              priority;
    char                        *uri;
    int                         ttl;
};

VALORES DE RETORNO

ares_parse_uri_reply puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La respuesta se analizó correctamente.
ARES_EBADRESP
La respuesta estaba mal formateada.
ARES_ENODATA
La respuesta no contenía una respuesta a la consulta.
ARES_ENOMEM
Se agotó la memoria.
