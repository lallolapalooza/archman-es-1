DESCRIPCIÓN

Estas funciones proporcionan una API para leer información sobre objetos en el disco. En particular, proporcionan una interfaz para poblar objetos struct archive_entry.

archive_read_disk_new()
Asigna e inicializa un objeto struct archive adecuado para leer información de objetos desde el disco.
archive_read_disk_open()
Abre el archivo o directorio desde la ruta dada y prepara el struct archive para leerlo desde el disco.
archive_read_disk_open_w()
Abre el archivo o directorio desde la ruta dada como una cadena de caracteres anchos y prepara el struct archive para leerlo desde el disco.
archive_read_disk_set_behavior()
Configura varias opciones de comportamiento al leer entradas desde el disco. El campo flags consiste en un OR bit a bit de uno o más de los siguientes valores:
ARCHIVE_READDISK_HONOR_NODUMP
Omite archivos y directorios con el atributo de archivo (flag) nodump establecido. De forma predeterminada, el atributo de archivo nodump se ignora.
ARCHIVE_READDISK_MAC_COPYFILE
Específico de Mac OS X. Lee metadatos (ACLs y atributos extendidos) con copyfile(3). De forma predeterminada, los metadatos se leen usando copyfile(3).
ARCHIVE_READDISK_NO_ACL
No lee las Listas de Control de Acceso (ACL). De forma predeterminada, las ACL se leen desde el disco.
ARCHIVE_READDISK_NO_FFLAGS
No lee los atributos de archivo (flags de archivo). De forma predeterminada, los atributos de archivo se leen desde el disco. Consulte chattr(1) (Linux) o chflags(1) (FreeBSD, Mac OS X) para más información sobre los atributos de archivo.
ARCHIVE_READDISK_NO_TRAVERSE_MOUNTS
No recorre los puntos de montaje. De forma predeterminada, los puntos de montaje se recorren.
