ENUMERACIONES

ares_dns_rec_type_t - Tipos de registros DNS manejados por c-ares. Algunos tipos de registro solo pueden ser válidos en solicitudes, y algunos solo pueden ser válidos en respuestas:

ARES_REC_TYPE_A - Dirección del host
ARES_REC_TYPE_NS - Servidor autoritativo
ARES_REC_TYPE_CNAME - Nombre canónico
ARES_REC_TYPE_SOA - Zona de inicio de autoridad
ARES_REC_TYPE_PTR - Puntero a nombre de dominio
ARES_REC_TYPE_HINFO - Información del host
ARES_REC_TYPE_MX - Información de enrutamiento de correo
ARES_REC_TYPE_TXT - Cadenas de texto
ARES_REC_TYPE_SIG - RFC 2535. RFC 2931. Registro SIG
ARES_REC_TYPE_AAAA - RFC 3596. Dirección Ip6
ARES_REC_TYPE_SRV - RFC 2782. Selección de servidor
ARES_REC_TYPE_NAPTR - RFC 3403. Puntero de autoridad de nombres
ARES_REC_TYPE_OPT - RFC 6891. Opción EDNS0 (meta-RR). Registro Pseudo.
ARES_REC_TYPE_TLSA - RFC 6698. Autenticación de Entidades Nombradas basada en DNS (DANE) Protocolo de Seguridad de Capa de Transporte (TLS): TLSA
ARES_REC_TYPE_SVCB - RFC 9460. Vinculación de Servicios de Propósito General
ARES_REC_TYPE_HTTPS - - RFC 9464. Tipo de vinculación de servicio para usar con HTTPS
ARES_REC_TYPE_ANY - Coincidencia comodín. RR de respuesta no
ARES_REC_TYPE_URI - RFC 7553. Identificador Uniforme de Recursos
ARES_REC_TYPE_CAA - RFC 6844. Autorización de Autoridad de Certificación
ARES_REC_TYPE_RAW_RR - Se usa como indicador de que el registro RR no se analiza, sino que se proporciona en formato de alambre

ares_dns_class_t - Clases DNS para solicitudes y respuestas:

ARES_CLASS_IN - Internet
ARES_CLASS_CHAOS - CHAOS
ARES_CLASS_HESOID - Hesoid [Dyer 87]
ARES_CLASS_NONE - RFC 2136
ARES_CLASS_ANY - Cualquier clase (solo solicitudes)

ares_dns_opcode_t - Opcodes de encabezado DNS:

ARES_OPCODE_QUERY - Consulta estándar
ARES_OPCODE_IQUERY - Consulta inversa. Obsoleto
ARES_OPCODE_STATUS - Consulta de estado del servidor de nombres
ARES_OPCODE_NOTIFY - Notificación de cambio de zona (RFC 1996)
ARES_OPCODE_UPDATE - Mensaje de actualización de zona (RFC 2136)

ares_dns_flags_t - Indicadores de encabezado DNS:

ARES_FLAG_QR - QR. Si está configurado, es una respuesta
ARES_FLAG_AA - Respuesta Autoritativa. Si está configurado, es autoritativo
ARES_FLAG_TC - Truncamiento. Si está configurado, es una respuesta truncada
ARES_FLAG_RD - Recursión Deseada. Si está configurado, se desea recursión
ARES_FLAG_RA - Recursión Disponible. Si está configurado, el servidor admite recursión
ARES_FLAG_AD - RFC 2065. El bit de Datos Auténticos indica en una respuesta que los datos incluidos han sido verificados por el servidor que los proporciona
ARES_FLAG_CD - RFC 2065. El bit de Verificación Deshabilitada indica en una consulta que los datos no verificados son aceptables para el resolvedor que envía la consulta

ares_dns_rcode_t - Códigos de respuesta DNS del servidor:

ARES_RCODE_NOERROR - Éxito
ARES_RCODE_FORMERR - Error de formato. El servidor de nombres no pudo interpretar la consulta
ARES_RCODE_SERVFAIL - Fallo del servidor. El servidor de nombres no pudo procesar esta consulta debido a un problema con el servidor de nombres
ARES_RCODE_NXDOMAIN - Error de nombre. Significativo solo para respuestas de un servidor de nombres autoritativo, este código significa que el nombre de dominio al que se hace referencia en la consulta no existe.
ARES_RCODE_NOTIMP - No implementado. El servidor de nombres no admite el tipo de consulta solicitado
ARES_RCODE_REFUSED - Rechazado. El servidor de nombres se niega a realizar la operación especificada por razones de política.
ARES_RCODE_YXDOMAIN - RFC 2136. Existe un nombre que no debería existir.
ARES_RCODE_YXRRSET - RFC 2136. Existe un conjunto de RR (Resource Record) que no debería existir.
ARES_RCODE_NXRRSET - RFC 2136. No existe un conjunto de RR que debería existir.
ARES_RCODE_NOTAUTH - RFC 2136. El servidor no es autoritativo para la zona nombrada en la sección Zone.
ARES_RCODE_NOTZONE - RFC 2136. Un nombre utilizado en la Sección de Prerrequisito o Actualización no se encuentra dentro de la zona designada por la Sección de Zona.
ARES_RCODE_DSOTYPEI - RFC 8409. DSO-TYPE No implementado
ARES_RCODE_BADSIG - RFC 8945. Fallo de firma TSIG
ARES_RCODE_BADKEY - RFC 8945. Clave no reconocida
ARES_RCODE_BADTIME - RFC 8945. Firma fuera de la ventana de tiempo
ARES_RCODE_BADMODE - RFC 2930. Modo TKEY incorrecto
ARES_RCODE_BADNAME - RFC 2930. Nombre de clave duplicado
ARES_RCODE_BADALG - RFC 2930. Algoritmo no soportado
ARES_RCODE_BADTRUNC - RFC 8945. Truncamiento incorrecto
ARES_RCODE_BADCOOKIE - RFC 7973. Cookie de servidor incorrecta/faltante

ares_dns_parse_flags_t - Indicadores para alterar el comportamiento de ares_dns_parse(3):

ARES_DNS_PARSE_AN_BASE_RAW - Analizar la Sección de Respuesta de RFC 1035 que permite la compresión de nombres como tipo RR RAW
ARES_DNS_PARSE_NS_BASE_RAW - Analizar la Sección de Autoridad de RFC 1035 que permite la compresión de nombres como tipo RR RAW
ARES_DNS_PARSE_AR_BASE_RAW - Analizar la Sección Adicional de RFC 1035 que permite la compresión de nombres como tipo RR RAW
ARES_DNS_PARSE_AN_EXT_RAW - Analizar la Sección de Respuesta de RFC posteriores (sin compresión de nombres) como tipo RR RAW
ARES_DNS_PARSE_NS_EXT_RAW - Analizar la Sección de Autoridad de RFC posteriores (sin compresión de nombres) como tipo RR RAW
ARES_DNS_PARSE_AR_EXT_RAW - Analizar la Sección Adicional de RFC posteriores (sin compresión de nombres) como tipo RR RAW

La función ares_dns_record_destroy(3) destruye la memoria asociada con el registro DNS creado por ares_dns_record_create(3) o ares_dns_parse(3) pasado a través de dnsrec.
