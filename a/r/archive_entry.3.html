ARCHIVE_ENTRY(3) Manual de funciones de biblioteca ARCHIVE_ENTRY(3)

NOMBRE

archive_entry_clear, archive_entry_clone, archive_entry_free, archive_entry_new — funciones para gestionar descripciones de entradas de archivo

BIBLIOTECA

Biblioteca de Archivo de Flujo (libarchive, -larchive)

SINOPSIS

#include <archive_entry.h>

struct archive_entry *
archive_entry_clear(struct archive_entry *);

struct archive_entry *
archive_entry_clone(struct archive_entry *);

void
archive_entry_free(struct archive_entry *);

struct archive_entry *
archive_entry_new(void);

DESCRIPCIÓN

Estas funciones crean y manipulan objetos de datos que representan entradas dentro de un archivo. Puede considerar un struct archive_entry como una versión de gran alcance de un struct stat: incluye todo de un struct stat más la ruta de acceso asociada, nombres de grupo y usuario textuales, etc. Estos objetos son utilizados por libarchive(3) para representar los metadatos asociados con una entrada particular en un archivo.

Crear y destruir

Existen funciones para asignar, destruir, limpiar y copiar objetos archive_entry:

archive_entry_clear()
Borra el objeto, restableciendo todos los campos internos al mismo estado que un objeto recién creado. Esto se proporciona para permitirle reciclar objetos rápidamente sin agotar la memoria.
archive_entry_clone()
Una operación de copia profunda; todos los campos de texto se duplican.
archive_entry_free()
Libera el objeto struct archive_entry.
archive_entry_new()
Asigna y devuelve un objeto struct archive_entry en blanco.

Grupos de funciones

Debido al gran número de funciones, las funciones de acceso se pueden encontrar en páginas de manual agrupadas por su propósito.

archive_entry_acl(3)
Manipulación de Listas de Control de Acceso
archive_entry_paths(3)
Manipulación de nombres de ruta
archive_entry_perms(3)
Manipulación de usuario, grupo y modo
archive_entry_stat(3)
Funciones no incluidas en los otros grupos y copia hacia/desde struct stat.
archive_entry_time(3)
Manipulación de campos de tiempo

La mayoría de las funciones establecen o leen entradas en un objeto. Dichas funciones tienen una de las siguientes formas:

archive_entry_set_XXXX()
Almacena los datos proporcionados en el objeto. En particular, para las cadenas de texto, se almacena el puntero, no la cadena referenciada.
archive_entry_copy_XXXX()
Como arriba, excepto que los datos referenciados se copian en el objeto.
archive_entry_XXXX()
Devuelve los datos especificados. En el caso de las cadenas de texto, se devuelve un puntero de solo lectura a la cadena.
Los datos de cadena de texto se pueden establecer o acceder como cadenas de caracteres anchos o cadenas de char normales. Las funciones que utilizan cadenas de caracteres anchos tienen el sufijo _w. Tenga en cuenta que estas son representaciones diferentes de los mismos datos: Por ejemplo, si almacena una cadena de texto estrecha y lee la cadena ancha correspondiente, el objeto se convertirá de forma transparente utilizando la configuración regional actual. Del mismo modo, si almacena una cadena ancha y luego almacena una cadena estrecha para los mismos datos, la cadena ancha previamente establecida se descartará en favor de los nuevos datos.
