NOMBRE

ares_inet_pton - convertir una dirección IPv4 o IPv6 de texto a forma binaria

SINOPSIS

#include <ares.h>
int ares_inet_pton(int af, const char *src, void *dst);

DESCRIPCIÓN

Esta es una versión portable con la funcionalidad idéntica de inet_pton comúnmente disponible.

La función ares_inet_pton() convierte la dirección en su forma de presentación textual estándar a su forma numérica binaria. El argumento af especificará la familia de la dirección. Se deben soportar las familias de direcciones AF_INET y AF_INET6. El argumento src apunta a la cadena que se está pasando. El argumento dst apunta a un buffer en el cual la función almacena la dirección numérica; este debe ser lo suficientemente grande para contener la dirección numérica (32 bits para AF_INET, 128 bits para AF_INET6).

Devuelve 1 si la dirección era válida para la familia de direcciones especificada, o 0 si la dirección no era interpretable en la familia de direcciones especificada, o -1 si ocurrió algún error del sistema (en cuyo caso errno habrá sido establecido).

VER TAMBIÉN

ares_init(3), ares_inet_ntop(3)

DISPONIBILIDAD

hecho debidamente público en c-ares para uso real en la versión 1.10.0
