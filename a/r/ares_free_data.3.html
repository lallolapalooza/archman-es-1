ares_free_data(3)

Paquete: c-ares

Licencias: MIT

ARES_FREE_DATA(3) Manual de funciones de la biblioteca ARES_FREE_DATA(3)

NOMBRE

ares_free_data - Liberar datos asignados por varias funciones de c-ares

SINOPSIS

#include <ares.h>
void ares_free_data(void *dataptr)

DESCRIPCIÓN

La función ares_free_data(3) libera una o más estructuras de datos asignadas y devueltas por varias funciones de c-ares. Específicamente, los datos devueltos por la siguiente lista de funciones deben ser desasignados usando esta función.

ares_get_servers(3)
Cuando se usa para liberar los datos devueltos por ares_get_servers(3), esto liberará toda la lista enlazada de estructuras ares_addr_node devueltas por ares_get_servers(3).
ares_parse_srv_reply(3)
Cuando se usa para liberar los datos devueltos por ares_parse_srv_reply(3), esto liberará toda la lista enlazada de estructuras ares_srv_reply devueltas por ares_parse_srv_reply(3), junto con cualquier almacenamiento adicional asociado con esas estructuras.
ares_parse_mx_reply(3)
Cuando se usa para liberar los datos devueltos por ares_parse_mx_reply(3), esto liberará toda la lista enlazada de estructuras ares_mx_reply devueltas por ares_parse_mx_reply(3), junto con cualquier almacenamiento adicional asociado con esas estructuras.
ares_parse_txt_reply(3)
Cuando se usa para liberar los datos devueltos por ares_parse_txt_reply(3), esto liberará toda la lista enlazada de estructuras ares_txt_reply devueltas por ares_parse_txt_reply(3), junto con cualquier almacenamiento adicional asociado con esas estructuras.
ares_parse_soa_reply(3)
Cuando se usa para liberar los datos devueltos por ares_parse_soa_reply(3), esto liberará la estructura ares_soa_reply, junto con cualquier almacenamiento adicional asociado con esa estructura. ares_parse_uri_reply(3) Cuando se usa para liberar los datos devueltos por ares_parse_uri_reply(3), esto liberará la lista de estructuras ares_uri_reply, junto con cualquier almacenamiento adicional asociado con esa estructura.

VALOR DE RETORNO

La función ares_free_data(3) no devuelve ningún valor.

DISPONIBILIDAD

Esta función se introdujo por primera vez en la versión 1.7.0 de c-ares.

VER TAMBIÉN

ares_get_servers(3), ares_parse_srv_reply(3), ares_parse_mx_reply(3), ares_parse_txt_reply(3), ares_parse_soa_reply(3)
