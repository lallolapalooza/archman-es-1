DESCRIPCIÓN

Estas funciones proporcionan una interfaz para manipular los registros de recursos (RR) de DNS de forma independiente del protocolo de red.

La función ares_dns_record_rr_add() crea un nuevo registro de recursos de tipo type y clase rclass para el dominio name con un TTL de ttl en la sección sect del registro DNS dnsrec. El nuevo RR se devuelve en rr_out.

La función ares_dns_record_rr_cnt() devuelve el número de registros RR en la sección sect del registro DNS dnsrec.

Las funciones ares_dns_record_rr_get() y ares_dns_record_rr_get_const() devuelven un puntero al registro RR en el índice idx de la sección sect del registro DNS dnsrec. ares_dns_record_rr_get_const() solo se puede usar en registros DNS de solo lectura.

La función ares_dns_record_rr_del() elimina el registro RR en el índice idx de la sección sect del registro DNS dnsrec.

Las funciones ares_dns_rr_get_*() devuelven el valor del campo especificado por key del registro RR rr o dns_rr. Si el campo no está presente o no es del tipo correcto, se devuelve un valor predeterminado o NULL.

Las funciones ares_dns_rr_set_*() establecen el valor del campo especificado por key del registro RR dns_rr.

Las funciones ares_dns_rr_add_abin() y ares_dns_rr_del_abin() manejan las matrices de bytes (arrays) de los registros RR. ares_dns_rr_add_abin() añade un nuevo elemento a la matriz.

Las funciones ares_dns_rr_set_opt(), ares_dns_rr_get_opt_cnt(), ares_dns_rr_get_opt() y ares_dns_rr_get_opt_byid() manejan las opciones (OPT pseudo-RR) de los registros RR.

VALORES DE RETORNO

Las funciones que establecen valores devuelven ares_status_t. Un valor de ARES_SUCCESS indica éxito. Cualquier otro valor indica un error.

Las funciones que devuelven punteros devuelven NULL en caso de error.

Las funciones que devuelven conteos devuelven 0 en caso de error.

EJEMPLO

Para crear un registro A para example.com con la dirección 192.0.2.1:

struct ares_dns_record_t *dnsrec;
ares_dns_rr_t *rr;
struct in_addr addr;
ares_inet_pton(AF_INET, "192.0.2.1", &addr);
if (ares_dns_record_rr_add(&rr, dnsrec, ARES_SECTION_ANSWER, "example.com",
                           ARES_REC_TYPE_A, ARES_CLASS_IN, 3600) == ARES_SUCCESS) {
    ares_dns_rr_set_addr(rr, ARES_RR_A_ADDR, &addr);
}

DESCRIPCIÓ

N

La función ares_dns_record_rr_cnt(3) devuelve el número de registros de recursos en el registro DNS proporcionado por el parámetro dnsrec para la sección proporcionada en el parámetro

sect.

La función ares_dns_record_rr_add(3) añade una nueva entrada de registro de recursos al registro DNS proporcionado por el parámetro dnsrec. El registro de recursos resultante se almacena en la variable a la que apunta rr_out. La sección DNS a la que pertenece el registro de recursos se especifica mediante el parámetro sect. El nombre de dominio asociado con el registro de recursos se especifica mediante el parámetro name, que no puede ser NULL pero puede ser una cadena vacía o ".". El tipo de registro de recursos se especifica en el parámetro type, junto con la clase de registro DNS en el parámetro rclass, y el Tiempo de Vida (TTL) en el parámetro

ttl.

La función ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) se utilizan para recuperar el puntero del registro de recursos del registro DNS proporcionado en el parámetro dnsrec para la sección de registro de recursos proporcionada en el parámetro sect para el índice especificado en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3). La primera devuelve un puntero escribible al registro de recursos, mientras que la segunda devuelve un puntero de solo lectura al registro de

recursos.

La función ares_dns_record_rr_del(3) se utiliza para eliminar un registro de recursos del registro DNS especificado en el parámetro dnsrec. Su uso principal es eliminar un registro ARES_REC_TYPE_OPT cuando se necesita reintentar una consulta sin soporte EDNS. La sección RR de DNS se especifica mediante el parámetro sect, y el índice a eliminar se especifica en el parámetro idx. El índice debe ser menor que ares_dns_record_r

r_cnt(3).

La función ares_dns_rr_get_name(3) se utiliza para recuperar el nombre de dominio del registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_type(3) se utiliza para recuperar el tipo de registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_class(3) se utiliza para recuperar la clase del registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_ttl(3) se utiliza para recuperar el Tiempo de Vida (TTL) de la clase del registro de recursos a partir del puntero de Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_set_addr(3) se utiliza para establecer una dirección IPv4 para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_INADDR. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

addr.

La función ares_dns_rr_set_addr6(3) se utiliza para establecer una dirección IPv6 para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_INADDR6. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

addr.

La función ares_dns_rr_set_str(3) se utiliza para establecer una cadena para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. La mayoría de las cadenas están limitadas a 255 bytes, sin embargo algunos registros, como un registro TXT, pueden permitir más ya que se emiten como múltiples cadenas. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u8(3) se utiliza para establecer un valor sin signo de 8 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_U8. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u16(3) se utiliza para establecer un valor sin signo de 16 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_U16. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u32(3) se utiliza para establecer un valor sin signo de 32 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_U32. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_bin(3) se utiliza para establecer un valor binario para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro

len.

La función ares_dns_rr_add_abin(3) se utiliza para añadir un valor binario al array para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro

len.

La función ares_dns_rr_del_abin(3) se utiliza para eliminar un valor binario del array para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro clave, y el índice a eliminar se proporciona en el parámetro

idx.

La función ares_dns_rr_set_opt(3) se utiliza para establecer claves/parámetros y valores de opción para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt, y se deja al usuario determinar el valor apropiado a utilizar. Algunos valores conocidos pueden ser proporcionados por las enumeraciones ares_svcb_param_t y ares_opt_param_t. El valor de la opción siempre se proporciona en forma binaria en val con la longitud proporcionada en val_len

.

La función ares_dns_rr_del_opt_byid(3) se utiliza para eliminar claves/parámetros y valores de opción para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt. Esta función devuelve ARES_SUCCESS si el registro se elimina correctamente, o ARES_ENOTFOUND si el registro no se pudo

encontrar.

La función ares_dns_rr_get_addr(3) se utiliza para recuperar la dirección IPv4 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_addr6(3) se utiliza para recuperar la dirección IPv6 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR6. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_str(3) se utiliza para recuperar una cadena del registro de recursos cuando el tipo de datos es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_u8(3) se utiliza para recuperar un entero de 8 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U8. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_u16(3) se utiliza para recuperar un entero de 16 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U16. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_u32(3) se utiliza para recuperar un entero de 32 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U32. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_bin(3) se utiliza para recuperar datos binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y la longitud se almacena en la variable apuntada por len

.

La función ares_dns_rr_get_abin_cnt(3) se utiliza para recuperar el recuento del arreglo de valores binarios almacenados del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_abin(3) se utiliza para recuperar datos binarios del arreglo del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y el índice a recuperar del arreglo se proporciona mediante el parámetro idx, y la longitud se almacena en la variable apuntada por len

.

La función ares_dns_rr_get_opt_cnt(3) se utiliza para recuperar el recuento de opciones/parámetros asociados con el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el key

.

La función ares_dns_rr_get_opt(3) se utiliza para recuperar datos de opción binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el índice especificado. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar es proporcionado en el parámetro key, el índice del que recuperar los datos de la opción se proporciona en el parámetro idx. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len

.

La función ares_dns_rr_get_opt_byid(3) se utiliza para recuperar datos de opción binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el identificador de opción especificado, si existe. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, el identificador del que recuperar los datos de la opción se proporciona en el parámetro opt . El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_le

n
