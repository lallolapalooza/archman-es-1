NOMBRE

arch-nspawn - Ejecuta un comando o sistema operativo en un contenedor ligero de namespace

SINOPSIS

arch-nspawn [opciones] directorio-trabajo [argumentos de systemd-nspawn]

DESCRIPCIÓN

arch-nspawn es un envoltorio para systemd-nspawn para ejecutar un comando o sistema operativo en un contenedor de namespace, como un directorio que incluye las utilidades base de un sistema operativo. Se utiliza para compilar paquetes en un entorno limpio y definido.

OPCIONES

-C <archivo>

Ubicación de un archivo de configuración de pacman

-M <archivo>

Ubicación de un archivo de configuración de makepkg. Adiciones específicas (por ejemplo, flags de compilación para idiomas adicionales) pueden colocarse en <archivo>.d/*.conf.

-c <dir>

Establece la caché de pacman. Si no se especifica ningún directorio, se utiliza el `cachedir` del pacman.conf proporcionado con una alternativa a /etc/pacman.conf.

-f <src>[:<dst>]

Copia un archivo del host al chroot. Si no se proporciona dst, por defecto es src dentro del chroot.

-s

No ejecutar setarch

-h

Muestra este mensaje de uso
