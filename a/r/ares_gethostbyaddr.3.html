NOMBRE

ares_gethostbyaddr - Iniciar una consulta de host por dirección

SINOPSIS

#include <ares.h>
typedef void (*ares_host_callback)(void *arg, int status,
                                   int timeouts,
                                   struct hostent *hostent)
void ares_gethostbyaddr(ares_channel_t *channel, const void *addr,
                        int addrlen, int family,
                        ares_host_callback callback, void *arg)

DESCRIPCIÓN

La función ares_gethostbyaddr inicia una consulta de host por dirección en el canal del servicio de nombres identificado por channel. Los parámetros addr y addrlen proporcionan la dirección como una serie de bytes, y family indica el tipo de dirección. Cuando la consulta se complete o falle, la biblioteca ares invocará a callback. La finalización o el fallo de la consulta puede ocurrir inmediatamente, o puede ocurrir durante una llamada posterior a ares_process(3), ares_destroy(3) o ares_cancel(3).

El argumento de devolución de llamada arg se copia del argumento arg de ares_gethostbyaddr. El argumento de devolución de llamada status indica si la consulta tuvo éxito y, si no, cómo falló. Puede tener cualquiera de los siguientes valores:

ARES_SUCCESS
La búsqueda de host se completó con éxito.
ARES_ENOTIMP
La biblioteca ares no sabe cómo buscar direcciones del tipo family.
ARES_ENOTFOUND
La dirección addr no se encontró.
ARES_ENOMEM
Se agotó la memoria.
ARES_ECANCELLED
La consulta fue cancelada.
ARES_EDESTRUCTION
Se está destruyendo el canal del servicio de nombres channel; la consulta no se completará.

El argumento de devolución de llamada timeouts informa cuántas veces una consulta expiró durante la ejecución de la solicitud dada.

En caso de finalización exitosa de la consulta, el argumento de devolución de llamada hostent apunta a un struct hostent que contiene el nombre del host devuelto por la consulta. La devolución de llamada no necesita y no debe intentar liberar la memoria apuntada por hostent; la biblioteca ares la liberará cuando la devolución de llamada regrese. Si la consulta no se completó con éxito, hostent será NULL.

Cuando se llama a la devolución de llamada asociada, se llama con un bloqueo de canal, por lo que se debe tener cuidado para asegurarse de que cualquier procesamiento sea mínimo para evitar bloqueos del canal DNS.

La devolución de llamada puede activarse desde un hilo diferente al que llamó a ares_gethostbyaddr(3).

Para los integradores que ejecutan sus propios bucles de eventos y no utilizan ARES_OPT_EVENT_THREAD, se debe tener cuidado para asegurarse de que las listas de descriptores de archivos se actualicen inmediatamente dentro del bucle de eventos cuando se notifique.
