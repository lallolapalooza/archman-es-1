DESCRIPCIÓ

N

Argtable es una biblioteca ANSI C para analizar argumentos de línea de comandos estilo GNU con el mínimo de complicaciones. Permite al programador definir la sintaxis de los argumentos de su programa directamente en el código fuente como un array de estructuras. La línea de comandos se analiza entonces según esa especificación y los valores resultantes se almacenan directamente en variables de programa definidas por el usuario donde son accesibles para el programa

principal.

Esta página man es solo para referencia. La documentación introductoria y el código fuente de ejemplo se instalan típicamente bajo /usr/share/doc/argtable2/ y también están disponibles desde la página principal de argtable en http://argtable.sourc

eforge.net.

Construyendo una estructura de datos

arg_<xxx>

Cada struct arg_<xxx> tiene su propio conjunto único de funciones constructoras (definidas arriba) que típicamente tienen la

forma: 
struct arg_int* arg_int0("f", "foo", "<int>", "the foo factor")
struct arg_int* arg_int1("f", "foo", "<int>", "the foo factor")
struct arg_int* arg_intn("f", "foo", "<int>", 2, 4, "the foo
factor")

donde arg_int0() y arg_int1() son meras formas abreviadas de arg_intn(). Se proporcionan por conveniencia al definir opciones de línea de comandos que tienen cero-o-una ocurrencias (mincount=0,maxcount=1) o exactamente una ocurrencia (mincount=1,maxcount=1) respectivamente

.

El parámetro shortopts="f" define la etiqueta de la forma corta de la opción (ej -f). Se pueden definir múltiples etiquetas alternativas concatenándolas (ej shortopts="abc" define las opciones -a, -b y -c como equivalentes). Especifique shortopts=NULL cuando no se requiera una opción

corta.

El parámetro longopts="foo" define la etiqueta de la forma larga de la opción (ej --foo). Se pueden separar múltiples etiquetas alternativas de forma larga con comas (ej longopts="size,limit" define --size y --limit). No incluya ningún espacio en blanco en la cadena longopts. Especifique longopts=NULL cuando no se requiera una opción

larga.

Si tanto shortopts como longopts son NULL entonces la opción es un argumento sin

etiqueta.

El parámetro datatype="<int>" es una cadena descriptiva que denota el tipo de datos del argumento en los mensajes de error, como en --foo=<int>. Especificar datatype=NULL indica que se debe usar el tipo de datos por defecto. Especificar datatype="" desactiva efectivamente la visualización del tipo de

datos.

Los parámetros mincount=2 y maxcount=3 especifican el número mínimo y máximo de ocurrencias de la opción en la línea de comandos. Si la opción de línea de comandos no aparece el número de veces requerido entonces el analizador reporta un error de

sintaxis.

El parámetro glossary="the foo factor" es otra cadena descriptiva. Aparece solo en la tabla de glosario que es generada automáticamente por la función arg_print_glossary (descrita más adelante)

.
-f, --foo=<int> the foo factor

Especificar una cadena glossary N

ULL causa que esa opción sea omi
tida de la tabla de glosario.

OPCIONES DE LÍNEA DE COMANDOS

ENTERAS

-x2, -z 32MB, --size=734kb, --hex 0x7, --binary 0b10011010, --octal

0o123

Argtable acepta enteros de línea de comandos en decimal (ej 123), hexadecimal (ej 0xFF12), octal (ej 0o123) y binario (ej 0b0101110) formatos. También acepta enteros que tienen el sufijo "KB" (x1024), "MB" (x1048576) o "GB" (x1073741824). Todos los caracteres no distinguen entre mayúsculas y

minúsculas 
struct arg_int
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de valores devueltos en ival[] */
   int *ival;           /* array de valores enteros analizados */
   }
;

Tras un análisis exitoso, count se garantiza que está dentro de los límites mincount y maxcount establecidos para la opción en la construcción con los valores apropiados almacenados en el array ival. El analizador no aceptará ningún valor más allá de

TIPOS DE ARGUMENTOS

El usuario es responsable de definir la estructura de argumentos que desea analizar. Esto se logra mediante la inicialización de una matriz de punteros a estructuras arg_hdr. Cada estructura define un tipo de argumento, sus etiquetas cortas y largas, los valores predeterminados esperados y una cadena de ayuda que se puede mostrar al usuario. 

    void *argtable[] =
        {
        arg_litn,  /* flag type, no value expected */
        arg_intn,  /* integer type, one value expected */
        arg_dbln,  /* double type, one value expected */
        arg_strn,  /* string type, one value expected */
        arg_filep, /* filename type, one value expected */
        arg_datep, /* date/time type, one value expected */
        arg_rem,   /* remark type, no value expected */
        arg_end,   /* end of table */
        NULL       /* end of array */
        };

La matriz argtable[] debe terminar con un puntero NULL.

OPCIONES DE LÍNEA DE COMANDOS LITERALES

-h, --help, -q, --quiet, -v, --verbose

struct arg_lit
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de veces que se ha visto esta opción */
   };

Los argumentos literales no toman ningún valor de la línea de comandos; su propósito es simplemente estar presente o ausente. La cuenta de la estructura arg_lit indica cuántas veces se ha visto la opción en la línea de comandos (esto puede ser mayor que uno si se combinan opciones cortas, p. ej., -abc).

OPCIONES DE LÍNEA DE COMANDOS ENTEROS

-n 100, -l 20, --limit=250, --count 10

struct arg_int
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de valores enteros devueltos en ival[] */
   int *ival;           /* array de valores enteros analizados */
   };

Los argumentos enteros pueden aparecer una o más veces en la línea de comandos. El número de valores que se espera que se analicen para un argumento dado se especifica mediante el parámetro maxcount en el constructor de la estructura arg_int. El número de valores que se han visto realmente en la línea de comandos se devuelve en el campo count de la estructura. Los valores enteros analizados se devuelven en la matriz ival[].

Pista: Es legal establecer valores predeterminados en la matriz ival antes de llamar a la función arg_parse. Argtable no alterará las entradas de ival para las cuales no se recibe ningún argumento de línea de comandos.

Pista: No se recomiendan los argumentos numéricos sin etiqueta porque GNU getopt confunde los valores negativos (p. ej. -123) con opciones etiquetadas (p. ej. -1 -2 -3). Los argumentos etiquetados (p. ej. -x -123, --tag=-123) no sufren este problema.

OPCIONES DE LÍNEA DE COMANDOS REAL/DOUBLE

-x2.234, -y 7e-03, -z-3.3E+6, --pi=3.1415, --tolerance 1.0E-6

struct arg_dbl
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de valores devueltos en dval[] */
   double *dval;        /* array de valores double analizados */
   };

Igual que arg_int, excepto que los valores analizados se almacenan en dval como doubles.

OPCIONES DE LÍNEA DE COMANDOS DE CADENA

-Dmacro, -t mytitle, -m "my message string", --title="hello world"

struct arg_str
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de cadenas devueltas en sval[] */
   const char **sval;   /* array de punteros a cadenas de argumentos analizadas */
   };

Igual que arg_int, excepto que se devuelven punteros a las cadenas analizadas en sval en lugar de una copia separada de la cadena. De hecho, estos punteros hacen referencia a los buffers de cadena originales almacenados en argv[], por lo que su contenido no debe alterarse. Sin embargo, es legal inicializar los punteros de cadena en la matriz sval para que apunten a cadenas predeterminadas proporcionadas por el usuario antes de llamar a arg_parse. Argtable solo alterará el contenido de sval cuando se detecten argumentos coincidentes en la línea de comandos.

OPCIONES DE LÍNEA DE COMANDOS DE EXPRESIÓN REGULAR

commit, update, --command=commit, --command=update

struct arg_rex
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de cadenas devueltas en sval[] */
   const char **sval;   /* array de punteros a cadenas de argumentos analizadas */
   };

Similar a arg_str, excepto que los valores de los argumentos de cadena solo se aceptan si coinciden con una expresión regular predefinida. Las expresiones regulares son útiles para hacer coincidir palabras clave de la línea de comandos, particularmente si se requieren cadenas que no distingan entre mayúsculas y minúsculas o coincidencia de patrones. La expresión regular se define mediante el parámetro pattern pasado al constructor de arg_rex y se evalúa usando regex. Su comportamiento se puede controlar a través de indicadores estándar de regex. Estos se pasan a argtable a través del parámetro flags en el constructor de arg_rex. Sin embargo, solo dos de los indicadores estándar de regex son relevantes para argtable, a saber, REG_EXTENDED (use expresiones regulares extendidas en lugar de básicas) y REG_ICASE (ignorar mayúsculas y minúsculas). Estos indicadores pueden combinarse lógicamente si se desea. Consulte regex(3) para obtener más detalles sobre la coincidencia de expresiones regulares.

Restricciones: Argtable no admite la funcionalidad de arg_rex en plataformas Microsoft Windows porque los compiladores de Microsoft no incluyen el soporte regex necesario como estándar.

OPCIONES DE LÍNEA DE COMANDOS DE NOMBRE DE ARCHIVO

-o myfile, -Ihome/foo/bar, --input=~/doc/letter.txt, --name a.out

struct arg_file
   {
   struct arg_hdr hdr;      /* cabecera interna de argtable */
   int count;               /* número de cadenas de nombres de archivo devueltas */
   const char **filename;   /* puntero a la cadena completa del nombre de archivo */
   const char **basename;   /* puntero al nombre de archivo excluyendo la ruta inicial */
   const char **extension;  /* puntero a la extensión del nombre de archivo */
   };

Similar a arg_str, pero se asume que las cadenas de argumentos se refieren a nombres de archivo, por lo que se realiza un análisis adicional para separar el nombre base y la extensión del nombre de archivo (si existen). Las tres matrices filename[], basename[], extension[] almacenan hasta maxcount entradas cada una, y la i-ésima entrada de cada una de estas matrices se refiere a diferentes componentes del mismo buffer de cadena.

Por ejemplo, -o /home/heitmann/mydir/foo.txt se analizaría como: 

filename[i]  = "/home/heitmann/mydir/foo.txt"
basename[i]  =                      "foo.txt"
extension[i] =                         ".txt"

Si el nombre del archivo no tiene una ruta inicial, el nombre base es el mismo que el nombre del archivo. Si no se pudo identificar ninguna extensión, se proporciona como NULL. Las extensiones se consideran todo el texto a partir del último punto en el nombre del archivo.

Pista: Argtable solo trata los nombres de archivo como cadenas y nunca intenta abrirlos como archivos ni realizar ninguna búsqueda de directorios en ellos.

OPCIONES DE LÍNEA DE COMANDOS DE FECHA/HORA

12/31/04, -d 1982-11-28, --time 23:59

struct arg_date
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   const char *format;  /* cadena de formato de fecha proporcionada por el usuario que se pasó al constructor */
   int count;           /* número de marcas de tiempo devueltas en tmval[] */
   struct tm *tmval;    /* array de marcas de tiempo */
   };

Acepta una cadena de marca de tiempo de la línea de comandos y la convierte al formato struct tm utilizando la función del sistema strptime. El formato de hora se define mediante la cadena format pasada al constructor de arg_date y se pasa directamente a strptime. Consulte strptime(3) para obtener más detalles sobre la cadena de formato.

Restricciones: Argtable no admite la funcionalidad de arg_date en Microsoft Windows porque los compiladores de Microsoft no incluyen el soporte strptime necesario como estándar.

OPCIONES DE OBSERVACIÓN

struct arg_rem
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   };

La estructura arg_rem es una estructura ficticia en el sentido de que no representa una opción de línea de comandos que deba analizarse. En su lugar, proporciona un medio para incluir cadenas de datatype y glossary adicionales en la salida de las funciones arg_print_syntax, arg_print_syntaxv y arg_print_glossary. Como tales, las estructuras arg_rem se pueden usar en la tabla de argumentos para insertar líneas de texto adicionales en las descripciones del glosario o para insertar campos de texto adicionales en la descripción de la sintaxis.

OPCIÓN DE FIN DE TABLA

struct arg_end
   {
   struct arg_hdr hdr;  /* cabecera interna de argtable */
   int count;           /* número de errores devueltos */
   int *error;          /* array de códigos de error */
   void **parent;       /* punteros a las opciones de línea de comandos erróneas */
   const char **argval; /* punteros a los valores de argumento de línea de comandos erróneos */
   };

Cada tabla de argumentos debe tener una estructura arg_end como su
última entrada. Marca el final de una tabla de argumentos y almacena los
códigos de error generados por el analizador mientras procesaba la tabla de
argumentos. El parámetro maxerrors pasado al constructor de
arg_end especifica el número máximo de errores que la estructura puede
almacenar. Cualquier error adicional se descarta y se reemplaza con el único
código de error ARG_ELIMIT, que luego se informa al usuario con el mensaje
"too many errors". Un límite de maxerrors de 20 es bastante razonable.
La función arg_print_errors imprimirá los errores almacenados en la
estructura arg_end en el mismo orden en que ocurrieron, por lo que no es
necesario comprender los detalles internos de la estructura arg_end.

REFERENCIA DE FUNCIONES


int arg_nullcheck (void **argtable)

Devuelve un valor distinto de cero si la matriz argtable[] contiene alguna entrada NULL hasta la entrada terminadora arg_end*. Devuelve cero en caso contrario.

int arg_parse (int argc, char **argv, void **argtable)

Analiza los argumentos de la línea de comandos en argv[] utilizando la sintaxis de línea de comandos especificada en argtable[], devolviendo el número de errores encontrados. Los detalles del error se registran en la estructura arg_end de la tabla de argumentos, desde donde se pueden mostrar más tarde con la función arg_print_errors. Tras un análisis correcto, las estructuras arg_xxx a las que se hace referencia en argtable[] contendrán los valores de los argumentos extraídos de la línea de comandos.

void arg_print_option (FILE *fp, const char *shortopts, const char *longopts, const char *datatype, const char *suffix)

Esta función imprime la sintaxis de una opción, como -K|--scalar=<int>, donde las opciones cortas, las opciones largas y el tipo de datos se proporcionan como parámetros de esta función. Se utiliza principalmente dentro de las funciones errorfn de las estructuras arg_xxx como una forma de mostrar la sintaxis de una opción dentro de los mensajes de error. Sin embargo, también se puede utilizar en código de usuario si se desea. La cadena suffix se proporciona como una conveniencia para agregar saltos de línea y similares al final de la pantalla y se puede dar como NULL si no se requiere.

void arg_print_syntax (FILE *fp, void **argtable, const char *suffix)

Imprime la sintaxis de la línea de comandos estilo GNU para la tabla de argumentos dada, como en: [-abcv] [--scalar=<n>] [-o myfile] <file> [<file>]
La cadena suffix se proporciona como una conveniencia para agregar saltos de línea y similares al final de la pantalla y se puede dar como NULL si no se requiere.

void arg_print_syntaxv (FILE *fp, void **argtable, const char *suffix)

Similar a arg_print_syntax(), pero la sintaxis se imprime como una secuencia de argumentos separados por espacios en lugar de una sola línea. Esto puede ser útil para incluir la sintaxis de la línea de comandos en texto que no está necesariamente destinado a ser una única línea de texto.

void arg_print_glossary (FILE *fp, void **argtable, const char *suffix)

Imprime un glosario de las opciones de línea de comandos que se encuentran en la tabla de argumentos dada. Los comentarios de ayuda que se proporcionan para cada opción se imprimen justo debajo del nombre de la opción y se alinean automáticamente para que coincidan con los comentarios de las opciones subsiguientes. La cadena suffix se proporciona como una conveniencia para agregar saltos de línea y similares al final de la pantalla y se puede dar como NULL si no se requiere.

void arg_print_errors (FILE *fp, void **argtable, const char *suffix)

Imprime cualquier error que se haya encontrado durante el análisis de la línea de comandos. Los detalles del error se obtienen de la estructura arg_end al final de la tabla de argumentos. La cadena suffix se proporciona como una conveniencia para agregar saltos de línea y similares al final de la pantalla y se puede dar como NULL si no se requiere.

void arg_print_help (FILE *fp, void **argtable, const char *suffix)

Esta función es simplemente un alias para arg_print_narrative().

void arg_print_narrative (FILE *fp, void **argtable, const char *suffix)

Imprime tanto la sintaxis como el glosario de la línea de comandos. Esto es útil para generar automáticamente la cadena de ayuda para un programa.

void arg_freetable (void **argtable)

Libera cualquier memoria asignada dinámicamente por argtable durante la inicialización de la tabla de argumentos. Esta función debe llamarse una vez que la tabla de argumentos ya no sea necesaria.

int arg_count (...)

Devuelve el número de veces que se ha visto una opción determinada en la línea de comandos. Se deben pasar al menos dos argumentos a esta función: el primero es un puntero a la estructura de argumentos que se va a contar, y el segundo es un puntero a la tabla de argumentos que contiene la estructura. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.

Por ejemplo:

    int verbose_count = arg_count(arg_verbose, argtable, NULL);
    int quiet_count = arg_count(arg_quiet, argtable, NULL);
    int debug_count = arg_count(arg_debug, argtable, NULL);

Si se necesitan hacer coincidir múltiples opciones, se pueden pasar los punteros a las estructuras de las opciones como argumentos adicionales.

    int verbose_or_debug = arg_count(arg_verbose, argtable, arg_debug, NULL);

int arg_imax (...)

Devuelve el valor entero más grande que se ha visto para una opción determinada. Se deben pasar al menos dos argumentos a esta función: el primero es un puntero a la estructura de argumentos arg_int que se va a examinar, y el segundo es un puntero a la tabla de argumentos que contiene la estructura. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.

Por ejemplo:

    int max_limit = arg_imax(arg_limit, argtable, NULL);

Si se necesitan hacer coincidir múltiples opciones, se pueden pasar los punteros a las estructuras de las opciones como argumentos adicionales.

    int max_limit_or_count = arg_imax(arg_limit, argtable, arg_count, NULL);

int arg_umin (...)

Devuelve el valor entero más pequeño que se ha visto para una opción determinada. Se deben pasar al menos dos argumentos a esta función: el primero es un puntero a la estructura de argumentos arg_int que se va a examinar, y el segundo es un puntero a la tabla de argumentos que contiene la estructura. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.

Por ejemplo:

    int min_limit = arg_umin(arg_limit, argtable, NULL);

Si se necesitan hacer coincidir múltiples opciones, se pueden pasar los punteros a las estructuras de las opciones como argumentos adicionales.

    int min_limit_or_count = arg_umin(arg_limit, argtable, arg_count, NULL);

double arg_dmax (...)

Devuelve el valor double más grande que se ha visto para una opción determinada. Se deben pasar al menos dos argumentos a esta función: el primero es un puntero a la estructura de argumentos arg_dbl que se va a examinar, y el segundo es un puntero a la tabla de argumentos que contiene la estructura. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.0.

Por ejemplo:

    double max_tolerance = arg_dmax(arg_tolerance, argtable, NULL);

Si se necesitan hacer coincidir múltiples opciones, se pueden pasar los punteros a las estructuras de las opciones como argumentos adicionales.

Devuelve el valor double más pequeño que se ha visto para una opción determinada. Se deben pasar al menos dos argumentos a esta función: el primero es un puntero a la estructura de argumentos arg_dbl que se va a examinar, y el segundo es un puntero a la tabla de argumentos que contiene la estructura. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.0.

Por ejemplo:

    double min_tolerance = arg_dmin(arg_tolerance, argtable, NULL);

    double min_tolerance_or_pi = arg_dmin(arg_tolerance, argtable, arg_pi, NULL);

int arg_strcomp (...)

Devuelve el número de veces que se ha visto una cadena determinada para una opción dada. Se deben pasar al menos tres argumentos a esta función: el primero es un puntero a la estructura de argumentos arg_str que se va a examinar, el segundo es un puntero a la tabla de argumentos que contiene la estructura, y el tercero es la cadena que se va a buscar. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.

Por ejemplo:

    int commit_count = arg_strcomp(arg_command, argtable, "commit", NULL);
    int update_count = arg_strcomp(arg_command, argtable, "update", NULL);

int arg_match (...)

Devuelve el número de veces que se ha visto una opción determinada que coincide con un patrón dado. Se deben pasar al menos tres argumentos a esta función: el primero es un puntero a la estructura de argumentos arg_rex que se va a examinar, el segundo es un puntero a la tabla de argumentos que contiene la estructura, y el tercero es el patrón que se va a buscar. Se pueden pasar argumentos adicionales para hacer coincidir múltiples estructuras de argumentos. Si no se encuentran coincidencias, se devuelve 0.

Por ejemplo:

    int file_match = arg_match(arg_filename, argtable, "*.c", NULL);

int arg_exist (...)

Devuelve un valor distinto de cero si una opción determinada existe en la línea de comandos, y cero en caso contrario. Se deben pasar al menos dos argumentos a esta función: el primero es un puntero a la estructura de argumentos que se va a comprobar, y el segundo es un puntero a la tabla de argumentos que contiene la estructura. Se pueden pasar argumentos adicionales para comprobar varias opciones. Si alguna de las opciones verificadas existe, la función devuelve 1; de lo contrario, devuelve 0.

Por ejemplo:

    if (arg_exist(arg_verbose, argtable, NULL)) {
        printf("Verbose mode enabled\n");
    }
