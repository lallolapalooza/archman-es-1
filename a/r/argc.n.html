Esta variable es mantenida por Tcl como una matriz cuyos elementos son las variables de entorno del proceso. Leer un elemento devolverá el valor de la variable de entorno correspondiente. Establecer un elemento de la matriz modificará la variable de entorno correspondiente o creará una nueva si aún no existe. Eliminar un elemento de env eliminará la variable de entorno correspondiente. Los cambios en la matriz env afectarán el entorno pasado a los hijos por comandos como exec. Si toda la matriz env se elimina, entonces Tcl dejará de monitorear los accesos a env y no actualizará las
variables de
entorno.

En Windows, las variables de entorno PATH y COMSPEC, en cualquier capitalización, se convierten automáticamente a mayúsculas. Por ejemplo, la variable PATH podría ser exportada por el sistema operativo como “path”, “Path”, “PaTh”, etc., haciendo que código Tcl de lo contrario simple tenga que soportar muchos casos especiales. Todas las demás variables de entorno heredadas por Tcl se dejan sin modificar. Establecer una variable de la matriz env en blanco es lo mismo que eliminarla, ya que este es el comportamiento del sistema operativo Windows subyacente. Debe notarse que confiar en una variable de entorno existente y vacía no funcionará en Windows y se desaconseja para uso multiplataforma
