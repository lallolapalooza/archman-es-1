DESCRIPCIÓN

La función ares_dns_record_rr_cnt(3) devuelve el número de registros de recursos en el registro DNS proporcionado por el parámetro dnsrec para la sección proporcionada en el parámetro sect.

La función ares_dns_record_rr_add(3) agrega una nueva entrada de registro de recursos al registro DNS proporcionado por el parámetro dnsrec. El registro de recursos resultante se almacena en la variable apuntada por rr_out. La sección DNS a la que pertenece el registro de recursos se especifica mediante el parámetro sect. El nombre de dominio asociado con el registro de recursos se especifica mediante el parámetro name, que no puede ser NULL pero puede ser una cadena vacía o ".". El tipo de registro de recursos se especifica en el parámetro type, junto con la clase de registro DNS en el parámetro rclass, y el Tiempo de Vida (TTL) en el parámetro ttl.

Las funciones ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) se utilizan para recuperar el puntero del registro de recursos del registro DNS proporcionado en el parámetro dnsrec, para la sección de registro de recursos proporcionada en el parámetro sect, para el índice especificado en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3). La primera devuelve un puntero modificable al registro de recursos, mientras que la segunda devuelve un puntero de solo lectura al registro de recursos.

La función ares_dns_record_rr_del(3) se utiliza para eliminar un registro de recursos del registro DNS especificado en el parámetro dnsrec. Su uso principal es eliminar un registro ARES_REC_TYPE_OPT cuando se necesite reintentar una consulta sin soporte EDNS. La sección RR DNS se especifica a través del parámetro sect, y el índice a eliminar se especifica en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3).

La función ares_dns_rr_get_name(3) se utiliza para recuperar el nombre de dominio del registro de recursos del puntero del Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_get_type(3) se utiliza para recuperar el tipo de registro de recursos del puntero del Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_get_class(3) se utiliza para recuperar la clase del registro de recursos del puntero del Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_get_ttl(3) se utiliza para recuperar el Tiempo de Vida (TTL) del registro de recursos del puntero del Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_set_addr(3) se utiliza para establecer una dirección IPv4 para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_INADDR. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro addr.

La función ares_dns_rr_set_addr6(3) se utiliza para establecer una dirección IPv6 para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_INADDR6. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro addr.

La función ares_dns_rr_set_str(3) se utiliza para establecer una cadena para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. La mayoría de las cadenas están limitadas a 255 bytes, sin embargo, algunos registros, como un registro TXT, pueden permitir longitudes mayores ya que se generan como cadenas múltiples. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro val.

La función ares_dns_rr_set_u8(3) se utiliza para establecer un valor sin signo de 8 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_U8. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro val.

La función ares_dns_rr_set_u16(3) se utiliza para establecer un valor sin signo de 16 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_U16. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro val.

La función ares_dns_rr_set_u32(3) se utiliza para establecer un valor sin signo de 32 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_U32. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro val.

La función ares_dns_rr_set_bin(3) se utiliza para establecer un valor binario para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro len.

La función ares_dns_rr_add_abin(3) se utiliza para agregar un valor binario en el array para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro len.

La función ares_dns_rr_del_abin(3) se utiliza para eliminar un valor binario del array para la clave/parámetro del registro de recursos asociado cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el

proporcionado en el parámetro key, y el índice a eliminar se proporciona en el parámetro

idx.

La función ares_dns_rr_set_opt(3) se utiliza para establecer claves/parámetros de opción y valores para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt, y se deja al usuario determinar el valor apropiado a utilizar. Algunos valores conocidos pueden ser proporcionados por ares_svcb_param_t y ares_opt_param_t enumeraciones. El valor de la opción siempre se proporciona en forma binaria en val con la longitud proporcionada en val_len

.

La función ares_dns_rr_del_opt_byid(3) se utiliza para eliminar claves/parámetros de opción y valores para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt. Esta función devuelve ARES_SUCCESS si el registro se elimina correctamente, o ARES_ENOTFOUND si el registro no pudo ser

encontrado.

La función ares_dns_rr_get_addr(3) se utiliza para recuperar la dirección IPv4 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_addr6(3) se utiliza para recuperar la dirección IPv6 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR6. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

key.

La función ares_dns_rr_get_u32(3) se utiliza para recuperar un entero de 32 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U32. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_bin(3) se utiliza para recuperar datos binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y la longitud se almacena en la variable apuntada por len

.

La función ares_dns_rr_get_abin_cnt(3) se utiliza para recuperar el recuento del arreglo de valores binarios almacenados del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_abin(3) se utiliza para recuperar datos binarios del arreglo del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y el índice a recuperar del arreglo se proporciona por el parámetro idx, y la longitud se almacena en la variable apuntada por len

.

La función ares_dns_rr_get_opt_cnt(3) se utiliza para recuperar el recuento de opciones/parámetros asociados con el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el key

.

La función ares_dns_rr_get_opt(3) se utiliza para recuperar datos binarios de opción del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el índice especificado. El registro de recursos es proporcionado en el parámetro dns_rr y la clave/parámetro a recuperar es proporcionado en el parámetro key, el índice del cual recuperar los datos de opción se proporciona en el parámetro idx. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len

.

La función ares_dns_rr_get_opt_byid(3) se utiliza para recuperar datos binarios de opción del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el identificador de opción especificado, si existe. El registro de recursos se proporciona en el parámetro dns_rr y el clave/parámetro a recuperar se proporciona en el parámetro key, el identificador del cual recuperar los datos de opción se proporciona en el parámetro opt . El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_le

n
