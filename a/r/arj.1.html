El comando "ac" es una abreviatura de "u -u2 -jb"
El comando "cc" es una abreviatura de "y -jb"
El comando "dc" es una abreviatura de "d -jb"


En Win32, arj usa la página de códigos OEM por defecto. La
    opción "-hy" configura arj para usar la página de códigos
    ANSI, que es el valor predeterminado del entorno gráfico de Windows. Los
    archivos autoextraíbles de arj/Win32 deben crearse usando la opción
    "-hy".


Para garantizar la compatibilidad con versiones anteriores de
    arj, el parámetro "-2d" debe especificarse al
    archivar en UNIX.

EJEMPLOS



  
Añadir archivos sin estructura de
    directorio:

  
arj a -e archivo *

  
Añadir dos archivos al
    archivo:

  
arj a archivo nombre1 nombre2

  
Añadir archivos al archivo con
    verificación:

  
arj a -jt archivo *

  
Añadir archivos con máxima
    compresión:

  
arj a -jm archivo *

  
Añadir varios directorios de
    archivos:

  
arj a archivo ... dir1 dir2 dir3

  
Añadir miles de archivos a un
    archivo:

  
arj a -hm1 -r archivo *

  
Añadir un capítulo a un
    archivo:

  
arj ac archivo /foo/dir/* -r

  
Comentar solo la cabecera del
    archivo:

  
arj c archivo -zcmt.fil

  
Convertir archivo estándar a
    capítulo:

  
arj cc archivo

  
Convertir archivo de
    capítulo a estándar:

  
arj y archivo -jb0

  
Eliminar el último capítulo de
    un archivo:

  
arj dc archivo *

  
Eliminar solo el comentario del
    archivo:

  
arj c archivo -z/dev/null

  
Extraer archivos de un
    archivo:

  
arj e archivo

  
Extraer manteniendo la
    estructura de directorios:

  
arj x archivo

  
Extraer archivos nuevos y
    más recientes sin preguntar:

  
arj e archivo -u -y

  
Extraer un subdirectorio
    de un archivo:

  
arj e archivo subdir/* -p1

  
Extraer archivos a un
    directorio:

  
arj x archivo destdir/ *

  
Extraer archivos a un
    directorio:

  
arj x archivo * -htdestdir

  
Extraer archivos a un
    directorio con espacio:

  
arj x archivo "Algún Dir/ "

  
Extraer archivos a un
    directorio con espacio:

  
arj x archivo "-htAlgún Dir"

  
Extraer un archivo de
    Win95 a DOS plano:

  
arj x archivo -hf2

  
Listar archivos en un
    archivo:

  
arj l archivo

  
Mover archivos a un
    archivo:

  
arj m archivo *.tex

  
Mover archivos de un
    archivo:

  
arj e -d archivo *.tex

  
Recuperar archivos de un
    archivo dañado:

  
arj x archivo -jr

  
Probar la integridad de los
    archivos en un archivo:

  
arj t archivo

  
Probar múltiples archivos
    arj:

  
arj t *.arj -hr

  
Añadir archivos a un archivo de
    múltiples volúmenes:

  
arj a -va /floppy/archivo *

  
Crear hasta 999 volúmenes de
    archivo:

  
arj a -va /floppy/archivo.001

  
Extraer de un archivo de
    múltiples volúmenes:

  
arj x -v /floppy/archivo

  
Crear un autoextractor de
    múltiples volúmenes:

Convertir archivo a
    autoextractor:

  
arj y -je1 archivo

  
Hacer copia de seguridad del

arj a /floppy/backup/foo -a1 -b2 -r -vvas
      -w/foo -js -jt -hk

  
Restaurar copia de seguridad en el directorio
    /floppy al directorio /foo:

  
arj x /floppy/backup /foo -vv -y








ARCHIVOS AUTOEXTRACCIÓN


Si los dos primeros caracteres de un arj comentario son
    "))" en un autoextractor, entonces el autoextractor
    aceptará la línea añadida como su línea de comandos.


")) -o" forzará al autoextractor a
    sobrescribir los archivos existentes.
