archive_write_free(3)

Paquete: libarchive

Licencias: BSD-2-Clause

ARCHIVE_WRITE_FREE(3) Manual de Funciones de Librería ARCHIVE_WRITE_FREE(3)

NOMBRE

archive_write_fail, archive_write_close, archive_write_finish, archive_write_free — funciones para crear archivos

LIBRERÍA

Librería de Archivos en Streaming (libarchive, -larchive)

SINOPSIS

#include <archive.h>

int
archive_write_fail(struct archive *);

int
archive_write_close(struct archive *);

int
archive_write_finish(struct archive *);

int
archive_write_free(struct archive *);

DESCRIPCIÓN

archive_write_fail()
Siempre devuelve ARCHIVE_FATAL. Esto marca el objeto archivo como inutilizable; después de llamar a esta función, la única llamada que puede tener éxito es archive_write_free() para liberar los recursos. Esto se puede usar para acelerar la recuperación cuando la creación del archivo debe ser abortada. Tenga en cuenta que el archivo creado es probable que esté mal formado en este caso;
archive_write_close()
Completa el archivo e invoca la llamada de cierre.
archive_write_finish()
Este es un sinónimo obsoleto para archive_write_free().
archive_write_free()
Invoca archive_write_close() si es necesario, luego libera todos los recursos. Si necesita información detallada sobre los fallos de archive_write_close(), debe tener cuidado de llamarla por separado, ya que no podrá obtener información de error después de que archive_write_free() retorne.

VALORES DE RETORNO

Estas funciones devuelven ARCHIVE_OK en éxito, o ARCHIVE_FATAL.

ERRORES

Los códigos de error detallados y las descripciones textuales están disponibles en las funciones archive_errno() y archive_error_string().

VER TAMBIÉN

tar(1), archive_write_set_options(3), libarchive(3), cpio(5), mtree(5), tar(5)
