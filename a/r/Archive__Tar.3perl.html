DESCRIPCIÓ

N

Archive::Tar proporciona un mecanismo orientado a objetos para manejar archivos tar. Proporciona métodos de clase para un manejo rápido y fácil de archivos, al tiempo que permite la creación de objetos de archivo tar para una manipulación personalizada. Si tiene instalado el módulo IO::Zlib, Archive::Tar también admitirá archivos tar comprimidos o con

gzip.

Un objeto de la clase Archive::T

ar representa un archivo .tar(.gz
) lleno de archivos y cosas.

$tar->write ( [$file, $compressed, $prefix]

Escribe el archivo en memoria en el disco. El primer argumento puede ser el nombre de un archivo o una referencia a un manejador de archivo ya abierto (una referencia GLOB)

El segundo argumento se usa para indicar la compresión. Puede comprimir usando "gzip", "bzip2" o "xz". Si pasa un dígito, se asume que es el nivel de compresión de "gzip" (entre 1 y 9), pero se prefiere el uso de
