ares_set_server_state_callback(3)

Paquete: c-ares

NOMBRE

ares_set_server_state_callback - Función para establecer una devolución de llamada de estado del servidor

SINOPSIS

#include <ares.h>
typedef void (*ares_server_state_callback)(const char *server_string,
                                           ares_bool_t success,
                                           int flags,
                                           void *data);
void ares_set_server_state_callback(ares_channel_t *channel,
                                    ares_server_state_callback callback,
                                    void *user_data);

DESCRIPCIÓN

La función ares_set_server_state_callback(3) establece una función de devolución de llamada callback en el manejador de canal ares dado channel que se invoca cada vez que se completa una consulta en el canal. Esto incluye consultas exitosas y no exitosas (incluidos errores graves y tiempos de espera). La función de devolución de llamada se invoca con una serie de parámetros que describen la consulta, como sigue:

El parámetro server_string indica el servidor DNS que se utilizó para la consulta, dado como una cadena con el mismo formato devuelto por ares_get_servers_csv(3).

El parámetro success indica si la consulta tuvo éxito o no. Se establece en ARES_TRUE en caso de éxito y ARES_FALSE en caso de fallo.

El parámetro flags es una máscara de bits de indicadores que describen varios aspectos de la consulta (por ejemplo, si la consulta utilizó UDP o TCP). Estos se describen a continuación.

El parámetro data es una referencia a los datos de usuario personalizados user_data que se pasaron a ares_set_server_state_callback(3) al establecer la devolución de llamada de estado del servidor.

La devolución de llamada de estado del servidor puede ser utilizada por las aplicaciones para monitorizar el estado de los servidores DNS utilizados por un canal ares. Por ejemplo, se puede utilizar para rastrear métricas sobre el número y tipo de consultas enviadas a cada servidor o para detectar cuándo un servidor no es accesible o no es saludable.

INDICADORES

ARES_SERV_STATE_UDP
Indica que la consulta se intentó a través de UDP.
ARES_SERV_STATE_TCP
Indica que la consulta se intentó a través de TCP.

DISPONIBILIDAD

Esta función se introdujo por primera vez en la versión 1.29.0 de c-ares.
