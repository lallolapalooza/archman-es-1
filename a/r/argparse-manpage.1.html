ARGPARSE-MANPAGE(1) Manual generado de Python ARGPARSE-MANPAGE(1)

NOMBRE

argparse-manpage

SINOPSIS

argparse-manpage [-h] (--module MÓDULO | --pyfile ARCHIVO_PY) (--function FUNCIÓN | --object OBJETO) [--project-name NOMBRE_PROYECTO] [--prog PROG] [--version VERSIÓN] [--description TEXTO] [--author [AUTOR]] [--url URL] [--format {pretty,single-commands-section}] [--output ARCHIVO_SALIDA] [--manual-section SECCIÓN_MANUAL] [--manual-title TÍTULO_MANUAL] [--include ARCHIVO] [--manfile ARCHIVO]

DESCRIPCIÓN

Genera una página de manual a partir del objeto ArgumentParser de Python.

OPCIONES

--module MÓDULO
busca el OBJETO/FUNCIÓN en MÓDULO
--pyfile ARCHIVO_PY
busca el OBJETO/FUNCIÓN en el ARCHIVO
--function FUNCIÓN
llama a FUNCIÓN desde MÓDULO/ARCHIVO para obtener el objeto ArgumentParser
--object OBJETO
obtiene el OBJETO ArgumentParser de FUNCIÓN (para obtener el objeto argparse) desde MÓDULO o ARCHIVO
--project-name NOMBRE_PROYECTO
Nombre del proyecto del que forma parte el programa documentado.
--prog PROG
Sustituye %prog en el uso de ArgumentParser.
--version VERSIÓN
Versión del programa, será visible en el pie de página del manual.
--description TEXTO
descripción del programa, utilizada en la sección NOMBRE, después de la parte inicial 'nombre - ', ver man (7) man-pages para más información
--author [AUTOR]
Autor del programa. Se puede especificar varias veces.
--url URL
Enlace a la página principal del proyecto
--format {pretty,single-commands-section}
Formato de la página de manual generada. Por defecto es 'pretty'.
--output ARCHIVO_SALIDA
Archivo de salida. Por defecto es la salida estándar.
--manual-section SECCIÓN_MANUAL
Sección del manual, por defecto es 1. Ver man (7) man-pages para más información sobre las secciones existentes.
--manual-title TÍTULO_MANUAL
El título del manual, por defecto es "Manual generado de Python". Ver man (7) man-pages para más instrucciones.
--include ARCHIVO
Archivo que contiene material adicional para la página del manual.
--manfile ARCHIVO
Archivo que contiene una página de manual completa.
