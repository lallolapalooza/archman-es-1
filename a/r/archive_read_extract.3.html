archive_read_extract(3)

Paquete: libarchive

Licencias: BSD-2-Clause

ARCHIVE_READ_EXTRACT(3) Manual de funciones de biblioteca ARCHIVE_READ_EXTRACT(3)

NOMBRE

archive_read_extract, archive_read_extract2, archive_read_extract_set_progress_callback — funciones para leer archivos de streaming

BIBLIOTECA

Biblioteca de Archivos de Streaming (libarchive, -larchive)

SINOPSIS

#include <archive.h>

int
archive_read_extract(struct archive *, struct archive_entry *, int flags);

int
archive_read_extract2(struct archive *src, struct archive_entry *, struct archive *dest);

void
archive_read_extract_set_progress_callback(struct archive *, void (*func)(void *), void *user_data);

DESCRIPCIÓN

archive_read_extract(), archive_read_extract_set_skip_file()
Una función de conveniencia que envuelve las interfaces correspondientes de archive_write_disk(3). La primera llamada a archive_read_extract() crea un objeto de restauración usando archive_write_disk_new(3) y archive_write_disk_set_standard_lookup(3), luego invoca transparentemente archive_write_disk_set_options(3), archive_write_header(3), archive_write_data(3), y archive_write_finish_entry(3) para crear la entrada en el disco y copiar los datos en ella. El argumento flags se pasa sin modificar a archive_write_disk_set_options(3).
archive_read_extract2()
Esta es otra versión de archive_read_extract() que te permite proporcionar tu propio objeto de restauración. En particular, esto te permite anular las funciones de búsqueda estándar usando archive_write_disk_set_group_lookup(3), y archive_write_disk_set_user_lookup(3). Ten en cuenta que archive_read_extract2() no acepta un argumento flags; deberías usar archive_write_disk_set_options() para establecer las opciones de restauración tú mismo.
archive_read_extract_set_progress_callback()
Establece un puntero a una función de callback definida por el usuario que puede ser utilizada para actualizar pantallas de progreso durante la extracción. La función de progreso se invocará durante la extracción de archivos regulares grandes. La función de progreso se invocará con el puntero proporcionado a esta llamada. Generalmente, los datos a los que apunta deben incluir una referencia al objeto de archivo y al objeto archive_entry para que se puedan recuperar diversas estadísticas para la pantalla de progreso.

VALORES DE RETORNO

La mayoría de las funciones devuelven cero en caso de éxito, un valor distinto de cero en caso de error. Los posibles códigos de retorno incluyen: ARCHIVE_OK (la operación se realizó con éxito), ARCHIVE_WARN (la operación se realizó con éxito pero se encontró un error no crítico), ARCHIVE_EOF (se encontró el final del archivo), ARCHIVE_RETRY (la operación falló pero se puede reintentar), y ARCHIVE_FATAL (hubo un error fatal; el archivo debe cerrarse inmediatamente).

ERRORES

Los códigos de error detallados y las descripciones textuales están disponibles en las funciones archive_errno() y archive_error_string().
