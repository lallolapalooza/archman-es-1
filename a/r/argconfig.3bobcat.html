FBB::ArgConfig(3bobcat) Argumentos del Programa FBB::ArgConfig(3bobcat)

NOMBRE

FBB::ArgConfig - Una clase singleton para procesar argumentos de programa

SINOPSIS

#include <bobcat/argconfig>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Clase singleton (ver Gamma et al., 1995) construida alrededor de getopt_long()(3). La clase maneja opciones cortas y largas de línea de comandos, así como archivos de configuración.

Además de las opciones estándar de línea de comandos, los diversos miembros option también reconocen opciones largas como claves, opcionalmente seguidas por dos puntos y un valor de opción. Por ejemplo, una opción --input filename puede especificarse en el archivo de configuración como:

    input: filename
o 
    input filename
Las opciones sin argumentos probablemente no deberían usar los dos puntos, aunque ConfigArg los acepta. Por ejemplo, para la opción --verbose se aceptan ambas formas: 
verbose
verbose:

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::Arg,
FBB::ConfigFile

ENUMERACIÓN

La enumeración FBB::ArgConfig::Type se hereda de la clase FBB::Arg. Se utiliza para especificar si las opciones largas requieren o no argumentos. Define los siguientes valores: None, Required, Optional.

o
None: la opción larga no usa argumento;
o
Required: la opción larga requiere un valor de argumento;
o
Optional: la opción larga puede proporcionarse opcionalmente con un valor de argumento;

Estos valores se utilizan al definir opciones largas (como --version), que se definen como objetos de la clase (anidada y heredada) FBB::Arg::LongOption (en el contexto de ArgConfig, esto es idéntico a FBB::ArgConfig::LongOption.

LA CLASE ANIDADA HEREDADA FBB::Arg::LongOption

Las opciones largas se definen utilizando objetos de la clase anidada FBB::Arg::LongOption. Esta clase proporciona los siguientes constructores:

o
FBB::Arg::LongOption(char const *name, FBB::Arg::Type type = FBB::Arg::None):
Este constructor se utiliza para definir una opción larga para la cual no se define una opción corta correspondiente. El parámetro name es el nombre de la opción larga (sin especificar los caracteres -- que solo son necesarios al especificar una opción larga al llamar a un programa).
o
FBB::Arg::LongOption(char const *name, int optionChar):
Este constructor se utiliza para definir una opción larga para la cual se define una opción corta correspondiente. El parámetro name es el nombre de la opción larga (sin especificar los caracteres -- que solo son necesarios al especificar una opción larga al llamar a un programa).

Para definir opciones largas, utilice el siguiente procedimiento:

o
Primero, construya un array 
    FBB::Arg::LongOption longOptions[] = { c1, c2, ..., cn };
Donde c1, c2, ..., cn son n invocaciones de constructores de FBB::Arg::LongOption()
o
A continuación, pase longOptions, LongOptions + n como argumentos a un miembro Arg::initialize que admita opciones largas.

Los objetos de la clase LongOptions se utilizan normalmente internamente por el objeto ArgConfig, pero también pueden utilizarse fuera del objeto ArgConfig. Para esa situación, están disponibles los siguientes miembros:

o
std::string const &longName() const:
devuelve el nombre de la opción larga de LongOption;
o
int optionChar() const:
devuelve el carácter de opción de LongOption (o uno de los valores de la enumeración Arg::Type si no hay ningún carácter de opción asociado con LongOption).

CONSTRUCTORES

Dado que la clase es un Singleton, no hay constructores públicos disponibles. En su lugar, se ofrecen miembros estáticos para inicializar y acceder al único objeto ArgConfig.

MIEMBROS ESTÁTICOS

Todos los miembros initialize inicializan el singleton FBB::ArgConfig y solo pueden llamarse una vez. Se lanza una excepción cuando se llaman varias veces. Todos los miembros initialize devuelven una referencia al objeto singleton ArgConfig inicializado.

Todos los miembros initialize definen los parámetros argc y argv que se interpretan como los parámetros argc y argv de main. Cuando un elemento de argv apunta a dos guiones consecutivos (--), ese elemento se ignora y todos los elementos subsiguientes de argv se consideran argumentos en lugar de opciones.

o
FBB::ArgConfig &ArgConfig::initialize(char const *optstring, int argc, char **argv, [std::string const &fname,] Comment cType = KeepComment, SearchCasing sType = SearchCaseSensitive, Indices iType = IgnoreIndices):
El parámetro optstring es una cadena de bytes terminada en nulo (NTBS) que opcionalmente comienza con un carácter +, pero de lo contrario contiene caracteres de opción. Uno o dos puntos pueden ir después de los caracteres de opción:
o
un solo punto (:) indica que la opción requiere un valor de opción.
o
un doble punto (::) indica que la opción tiene un argumento opcional. Con opciones cortas, el valor de la opción se considera ausente a menos que esté unido a la opción corta (p. ej., -tvalue). Las opciones largas que aceptan argumentos opcionalmente siempre deben ir seguidas inmediatamente por un carácter de asignación (=), seguido inmediatamente por el valor de la opción (que debe comenzar con un carácter no en blanco). Por ejemplo, --value= indica un valor de opción ausente, --value=text indica que el valor de la opción es text. Si el valor de la opción en sí contiene espacios, debe ir rodeado de comillas simples o dobles (p. ej., -t’este valor’, o --text=’este valor’). Las comillas que rodean no forman parte del valor de la opción.
Cuando el primer carácter de optstring es +, todas las opciones no especificadas se consideran argumentos, que aparecen en la lista final de argumentos en sus posiciones de argumento actuales. Por ejemplo, cuando optstring es +ab y no se definen opciones largas, llamar 
    prog -a -z -b -yvalue --long arg1 arg2
da como resultado que el miembro argv devuelva un vector que contiene los elementos -z, -yvalue, --long, arg1 y arg2. Si el primer carácter de optstring no es + y se encuentra una opción indefinida, se lanza una excepción.
El argumento fname es opcional. Si se proporciona, se abre un archivo de configuración con el nombre especificado (y debe existir); si se omite, el ArgConfig se crea sin usar un archivo de configuración. En este último caso, un archivo de configuración puede especificarse más tarde utilizando el miembro open heredado de ConfigFile.
Los tres últimos parámetros son parámetros de ConfigFile, que reciben los valores predeterminados que se muestran. Este constructor devuelve una referencia al objeto singleton, lo que permite al código que inicializa ArgConfig utilizar el objeto inicializado inmediatamente.
o
FBB::ArgConfig &ArgConfig::initialize(int accept, char const *optstring, int argc, char **argv, [std::string const &fname,] Comentario cType = KeepComment, SearchCasing sType = SearchCaseSensitive, Indices iType = IgnoreIndices):
Se comporta como el miembro anterior, pero además define el parámetro accept especificando un carácter de opción a partir del cual todos los argumentos y opciones subsiguientes se consideran argumentos. Para ignorar accept se puede especificar el valor 0 (no el carácter ’0’) o se pueden usar los miembros initialize que no definen un parámetro a
ccept.
Cuando los argumentos contienen tanto una opción accept como dos guiones consecutivos, se interpreta el primero, lo que resulta en que todos los elementos restantes de argv se interpreten como simples argumentos. Por ejemplo, al especificar initialize(’t’, ...) y llamar a 
    prog one -ttwo -c -- three
entonces el miembro argv devuelve un vector que contiene los elementos one, -ttwo, -c, --, y three (véase también el miembro beyondDashes más abajo)
.
o
FBB::ArgConfig &ArgConfig::initialize(char const *optstring, ArgConfig::LongOption const *const begin, ArgConfig::LongOption const *const end, int argc, char **argv, [std::string const &fname,] Comentario cType = KeepComment, SearchCasing sType = SearchCaseSensitive, Indices iType = IgnoreIndices):
Se comporta como el primer miembro ArgConfig::initialize, pero además define dos parámetros que especifican el rango de elementos de un array de objetos ArgConfig::LongOption que especifican opciones largas. El parámetro begin apunta al primer elemento del rango, el parámetro end apunta justo más allá del último elemento del rango. Por ejemplo, después de definir 
    FBB::ArgConfig::LongOption longOptions[] = { c1, c2, ..., cn };
los argumentos pasados a begin y end podrían especificarse como 
    initialize(..., longOptions, longOptions + size(longOptions)
, ...
);
o
FBB::ArgConfig &ArgConfig::initialize(char accept, char const *optstring, LongOption const *const begin, LongOption const *const end, int argc, char **argv, [std::string const &fname,] Comentario cType = KeepComment, SearchCasing sType = SearchCaseSensitive, Indices iType = IgnoreInd
ices):
Se comporta como el miembro ArgConfig::initialize anterior, pero en adición define un parámetro accept tal como lo define el segundo miembro ArgConfig::i
nitialize.
o
FBB::ArgConfig &ArgConfig::instance():
Una vez que se ha llamado a un miembro ArgConfig::initialize, se puede llamar a este miembro desde cualquier parte del programa (y se puede llamar varias veces), devolviendo una referencia al objeto ArgConfig
inicializado.
Si se llama antes de que se haya llamado a un miembro ArgConfig::initialize, se lanza una
excepción.
o

Devuelve la instancia del objeto ArgConfig, disponible después de llamar a uno de los miembros ArgConfig::initialize. Si se llama antes de la inicialización, se lanza una excepción FBB::Ex

FUNCIONES MIEMBRO NO

ESTÁTICAS

Todos los miembros públicos de las clases Arg y ConfigFile también son soportados por la clase ArgConfig. Como varios miembros Arg::option fueron reimplementados por ArgConfig, todos los miembros option se discuten a continuación. Todos los demás miembros se heredan directamente de las clases Arg y ConfigFile. Consulte sus páginas de manual para más

detalles.
o
size_t option(int option) const:
Devuelve el número de veces que `option’ (o su sinónimo de opción larga, si está definido) fue especificado como opción de línea de comandos o como opción de archivo de
configuración.
o
size_t option(std::string const &options) const:
Devuelve el número total de veces que cualquiera de los caracteres especificados en la cadena `options’ (o sus sinónimos de opción larga) fue especificado como opción de línea de comandos o como opción de archivo de
configuración.
o
size_t option(string *value, int option) const:
Devuelve el número de veces que la opción proporcionada (o su sinónimo de opción larga) estuvo presente como opción de línea de comandos o como opción de archivo de configuración. Si el valor de retorno no es cero, entonces el valor de la primera ocurrencia de esta opción (primero verificando las opciones de la línea de comandos; luego verificando el archivo de configuración) se almacena en *value, que se deja intacto si `option’ no estaba presente. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe ser
almacenado.
o
size_t option(size_t idx, string *value, int option) const:
Este miembro se comporta de manera idéntica al miembro Arg::option con el prototipo idéntico. No considera el archivo de configuración, sino que simplemente considera los argumentos de la línea de comandos, devolviendo el número de veces que la opción proporcionada (o su sinónimo de opción larga) estuvo presente. Si el valor de retorno no es cero, entonces el valor de la idxésima ocurrencia (desplazamiento basado en 0) de esta opción se almacena en *value, que se deja intacto si `option’ no estaba presente o si idx es o excede el número de especificaciones de la opción proporcionada. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe ser
almacenado.
o
size_t option(size_t *idx, string *value, int option) const:
Este miembro se comporta de manera idéntica al miembro Arg::option con el prototipo idéntico. No considera el archivo de configuración, sino que simplemente considera los argumentos de la línea de comandos, devolviendo el número de veces que la opción proporcionada (o su sinónimo de opción larga) estuvo presente. Si el valor de retorno no es cero, entonces el desplazamiento (dentro de la serie de especificaciones de opciones) de la primera opción que tiene un valor de opción no vacío se devuelve en *idx, mientras que su valor de opción se almacena en *value. Tanto *value como *idx se dejan intactos si `option’ no estaba presente. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe ser
almacenado.
o
size_t option(string *value, char const *longOption) const:
Devuelve el número de veces que la opción larga especificada (que no tiene un sinónimo de un solo carácter) estuvo presente como opción de línea de comandos o en el archivo de configuración. Si se encuentra, el valor encontrado en la primera ocurrencia de la opción (primero considerando las opciones de la línea de comandos, luego el archivo de configuración) se almacena en *value. La cadena a la que apunta value se deja intacta si la opción larga no estaba presente. Se puede especificar 0 para value si la opción no tiene un valor o si el valor no debe ser

EJEMPL

O 
#include <iostream>
#include <string>
#include <bobcat/argconfig>
#include <bobcat/exception>
using namespace std;
using namespace FBB;
ArgConfig::LongOption lo[] =
{
    ArgConfig::LongOption{"option", ’o’},
    ArgConfig::LongOption{"value-option", ’v’}
};
class X
{
    ArgConfig &
    public:
        X();
        void function();
};
X::X()
:
    d_arg(ArgConfig::instance())
{}
void X::function()
{
    if (d_arg.nArgs() == 0)
        throw Exception() << "Proporcione el nombre de un archivo de configuración como 1er argumento";
    cout << "Contando " << d_arg.option(’o’) << " instancias de -o o "
                                                            "--option\n";
    d_arg.open(d_arg[0]);       // Ahora abre el archivo de configuración explícitamente
                            // (alternativamente: use un constructor que espere
                            // un nombre de archivo)
    cout << "Contando " << d_arg.option(’o’) << " instancias de -o o "
                                                            "--option\n";
    string optval;
    size_t count = d_arg.option(&optval, ’v’);
    cout << "Contando " << count <&lt;
                        " instancias de -v o --value-option\n";
    if (count)
        cout << "Valor de la opción = " << optval << endl;
}
int main(int argc, char **argv)
try
{
    ArgConfig::initialize("ov:", lo, lo + 2, argc, argv);
    X x;
    x.function();
}
catch (Exception const &err)
{
    cout << "Terminando " << err.what() << endl;
    return 1;
}
