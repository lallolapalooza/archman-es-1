DESCRIPCIÓN

Las "Listas de Control de Acceso (ACLs)" extienden el modelo de permisos estándar de Unix. La interfaz ACL de libarchive soporta tanto ACLs de estilo POSIX.1e como NFSv4. El uso de ACLs está restringido por varios niveles de soporte de ACL en sistemas operativos, sistemas de archivos y formatos de archivo.

Listas de Control de Acceso POSIX.1e

Una ACL POSIX.1e consiste en un número de entradas independientes. Cada entrada especifica el conjunto de permisos como una máscara de bits de permisos básicos. Los permisos válidos en permset son:

ARCHIVE_ENTRY_ACL_READ (r)
 
ARCHIVE_ENTRY_ACL_WRITE (w)
 
ARCHIVE_ENTRY_ACL_EXECUTE (x)
 
Los permisos corresponden a los permisos normales de Unix.

El tag especifica el principal al que se aplica el permiso. Los valores válidos son:

ARCHIVE_ENTRY_ACL_USER
El usuario especificado por el campo nombre.
ARCHIVE_ENTRY_ACL_USER_OBJ
El propietario del archivo.
ARCHIVE_ENTRY_ACL_GROUP
El grupo especificado por el campo nombre.
ARCHIVE_ENTRY_ACL_GROUP_OBJ
El grupo que posee el archivo.
ARCHIVE_ENTRY_ACL_MASK
Los permisos máximos que se obtendrán a través de permisos de grupo.
ARCHIVE_ENTRY_ACL_OTHER
Cualquier principal que no sea el propietario del archivo o un miembro del grupo propietario.

Los principales ARCHIVE_ENTRY_ACL_USER_OBJ, ARCHIVE_ENTRY_ACL_GROUP_OBJ y ARCHIVE_ENTRY_ACL_OTHER son equivalentes a usuario, grupo y otros en el modelo de permisos clásico de Unix y especifican entradas ACL no extendidas.

Todos los archivos tienen una ACL de acceso (ARCHIVE_ENTRY_ACL_TYPE_ACCESS). Esto especifica los permisos requeridos para el acceso al archivo mismo. Los directorios tienen una ACL adicional (ARCHIVE_ENTRY_ACL_TYPE_DEFAULT), que controla la ACL de acceso inicial para las entradas de directorio recién creadas.

Listas de Control de Acceso NFSv4

Una ACL NFSv4 consiste en múltiples entradas individuales llamadas Entradas de Control de Acceso (ACEs).

Hay cuatro tipos posibles de ACE NFSv4:

ARCHIVE_ENTRY_ACL_TYPE_ALLOW
Permitir al principal realizar acciones que requieran los permisos dados.
ARCHIVE_ENTRY_ACL_TYPE_DENY
Evitar que el principal realice acciones que requieran los permisos dados.
ARCHIVE_ENTRY_ACL_TYPE_AUDIT
Registrar intentos de acceso del principal que requieran los permisos dados.
ARCHIVE_ENTRY_ACL_TYPE_ALARM
Disparar una alarma del sistema ante intentos de acceso del principal que requieran los permisos dados.

El tag especifica el principal al que se aplica el permiso. Los valores válidos son:

ARCHIVE_ENTRY_ACL_USER
El usuario especificado por el campo nombre.
ARCHIVE_ENTRY_ACL_USER_OBJ
El propietario del archivo.
ARCHIVE_ENTRY_ACL_GROUP
El grupo especificado por el campo nombre.
ARCHIVE_ENTRY_ACL_GROUP_OBJ
El grupo que posee el archivo.
ARCHIVE_ENTRY_ACL_OWNER
El propietario del archivo.

El campo qualifier se usa para identificar a los usuarios o grupos especificados por los campos ARCHIVE_ENTRY_ACL_USER y ARCHIVE_ENTRY_ACL_GROUP.

Los campos permset especifican los permisos que se aplican a la entrada de control de acceso. Los bits de permisos válidos son:

ARCHIVE_ENTRY_ACL_READ
 
ARCHIVE_ENTRY_ACL_WRITE
 
ARCHIVE_ENTRY_ACL_EXECUTE
 
ARCHIVE_ENTRY_ACL_SYNCHRONIZE
Permite o deniega la capacidad de sincronizar datos con el archivo.

El campo name es una cadena de caracteres que especifica el nombre de usuario o grupo.

Las ACLs se gestionan mediante las siguientes funciones:

archive_entry_acl_add_entry()
Añade una entrada ACL especificada por los argumentos type, permset, tag, qualifier y name a la ACL del archivo de entrada a.
archive_entry_acl_add_entry_w()
Similar a archive_entry_acl_add_entry, pero toma un nombre wchar_t.
archive_entry_acl_clear()
Borra todas las entradas ACL del archivo de entrada a.
archive_entry_acl_count()
Devuelve el número de entradas ACL del tipo especificado por type en el archivo de entrada a.
archive_entry_acl_from_text()
Carga las entradas ACL desde la cadena de texto especificada por text en el archivo de entrada a. El argumento type especifica el tipo de ACL que se está cargando (por ejemplo, ARCHIVE_ENTRY_ACL_TYPE_ACCESS o ARCHIVE_ENTRY_ACL_TYPE_DEFAULT).
archive_entry_acl_from_text_w()
Similar a archive_entry_acl_from_text, pero toma un nombre wchar_t.
archive_entry_acl_next()
Itera a través de las entradas ACL del archivo de entrada a. La primera vez que se llama, type debe ser el tipo de ACL que se desea iterar. Las llamadas subsiguientes con el mismo valor de type devolverán la siguiente entrada ACL. Los valores de la entrada ACL se almacenan en los punteros proporcionados por ret_type, ret_permset, ret_tag, ret_qual y ret_name. Cuando no quedan más entradas ACL, devuelve NULL.
archive_entry_acl_reset()
Elimina todas las entradas ACL del tipo especificado por type del archivo de entrada a.
archive_entry_acl_to_text()
Devuelve una representación de cadena de la ACL del archivo de entrada a. La cadena devuelta es asignada y debe liberarse con free(3). El puntero len_p se establece en la longitud de la cadena devuelta. El argumento flags se puede usar para modificar el formato de la salida.
archive_entry_acl_to_text_w()
Similar a archive_entry_acl_to_text, pero devuelve una cadena wchar_t.
archive_entry_acl_types()
Devuelve una máscara de bits que indica los tipos de ACL presentes en el archivo de entrada a. Los bits posibles son ARCHIVE_ENTRY_ACL_TYPE_ACCESS y ARCHIVE_ENTRY_ACL_TYPE_DEFAULT.

VALORES DE RETORNO

Las funciones archive_entry_acl_count, archive_entry_acl_next y archive_entry_acl_types devuelven el número de entradas ACL o una máscara de bits de los tipos de ACL presentes. Las funciones archive_entry_acl_from_text y archive_entry_acl_from_text_w devuelven cero si la operación tiene éxito, y un valor distinto de cero si falla.

La función archive_entry_acl_to_text devuelve un puntero a la cadena de texto de la ACL o NULL si ocurre un error. La función archive_entry_acl_to_text_w devuelve un puntero a la cadena de texto de la ACL o NULL si ocurre un error.
