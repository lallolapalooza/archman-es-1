Archive::Zip::MemberRead(3) Documentación de Perl contribuida por el usuario Archive::Zip::MemberRead(3)

NOMBRE

Archive::Zip::MemberRead - Un envoltorio que te permite leer miembros de archivos Zip como si fueran archivos.

SINOPSIS

use Archive::Zip;
use Archive::Zip::MemberRead;
$zip = Archive::Zip->new("archivo.zip");
$fh  = Archive::Zip::MemberRead->new($zip, "subdir/abc.txt");
while (defined($linea = $fh->getline()))
{
    print $fh->input_line_number . "#: $linea\n";
}
$leido = $fh->read($buffer, 32*1024);
print "Leído $leido bytes como :$buffer:\n";

DESCRIPCIÓN

El módulo Archive::Zip::MemberRead te permite leer datos de miembros de archivos Zip como si leyeras datos de archivos.

MÉTODOS

Archive::Zip::Member::readFileHandle()
Puedes obtener un "Archive::Zip::MemberRead" de un miembro de archivo llamando a readFileHandle(): 
mi $miembro = $zip->memberNamed('abc/def.c');
mi $fh = $miembro->readFileHandle();
while (defined($linea = $fh->getline()))
{
    # ...
}
$fh->close();
Archive::Zip::MemberRead->new($zip, $nombre_archivo)
Archive::Zip::MemberRead->new($zip, $miembro)
Archive::Zip::MemberRead->new($miembro)
Construye un nuevo Archive::Zip::MemberRead en el miembro especificado. 
mi $fh = Archive::Zip::MemberRead->new($zip, 'fred.c')
setLineEnd(expresión)
Establece el carácter de fin de línea a usar. Se establece en \n por defecto, excepto en sistemas Windows donde se establece en \r\n. Solo necesitarás establecer esto en sistemas que no sean Windows o Unix y que requieran un fin de línea diferente de \n. Este es un método de clase, así que llámalo como "Archive::Zip::MemberRead"->setLineEnd($nl)
rewind()
Rebobina un "Archive::Zip::MemberRead" para que puedas leer desde él nuevamente comenzando desde el principio.
input_record_separator(expresión)
Si se proporciona el argumento, el input_record_separator para esta instancia se establece en él. Siempre se devuelve la configuración actual (que puede ser el $ global).
input_line_number()
Devuelve el número de línea actual, pero solo si estás usando getline(). El uso de read() no actualizará el número de línea.
close()
Cierra el manejador de archivo dado.
buffer_size([ $tamaño ])
Obtiene o establece el tamaño del búfer utilizado para las lecturas. El valor predeterminado es el tamaño del fragmento utilizado por Archive::Zip.
getline()
Devuelve la siguiente línea del miembro actualmente abierto. Solo tiene sentido para archivos de texto. Un error de lectura se considera lo suficientemente grave como para morir. Devuelve undef en eof. Todas las llamadas posteriores devolverían undef, a menos que se llame a rewind(). Nota: La línea devuelta tiene el input_record_separator (predeterminado: nueva línea) eliminado.
getline( { preserve_line_ending => 1 } )
Devuelve la siguiente línea, incluyendo el final de línea.
read($buffer, $num_bytes_a_leer)
Simula una llamada al sistema read() normal. Devuelve el número de bytes leídos. "undef" en caso de error, 0 en eof, p. ej.: 
$fh = Archive::Zip::MemberRead->new($zip, "sreeji/secrets.bin");
while (1)
{
  $leido = $fh->read($buffer, 1024);
  die "¡ERROR FATAL leyendo mis secretos! \n" if (!defined($leido));
  last if (!$leido);
  # Realizar procesamiento.
  ....
 }
