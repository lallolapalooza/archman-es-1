ARCH-REPRO-STATUS(1) Comandos de usuario ARCH-REPRO-STATUS(1)

NOMBRE

arch-repro-status - comprueba el estado de reproducibilidad de los paquetes de Arch Linux

SINOPSIS

arch-repro-status [OPCIONES]

DESCRIPCIÓN

Comprueba el estado de reproducibilidad de los paquetes de Arch Linux utilizando datos de una instancia de rebuilderd como reproducible.archlinux.org. Puede mostrar el estado de reproducibilidad de:

•
paquetes que pertenecen a un mantenedor de paquetes individual (utiliza los datos de archlinux.org)
•
paquetes actualmente instalados en el sistema (utiliza los datos de la base de datos local de pacman)

Puedes inspeccionar los registros de compilación y diffoscope de los paquetes habilitando el modo interactivo con -i.

OPCIONES:

-q, --quiet
Deshabilita el registro
-v, --verbose
Aumenta la verbosidad del registro
-a, --all
Comprueba todos los paquetes del sistema
-m, --maintainer <MAINTAINER>
Establece el nombre de usuario del mantenedor [env: MAINTAINER=]
-r, --rebuilderd <URL>
Establece la dirección de la instancia de rebuilderd [env: REBUILDERD=] [predeterminado: https://reproducible.archlinux.org]
-b, --dbpath <RUTA>
Establece la ruta a la base de datos de pacman [env: DBPATH=] [predeterminado: /var/lib/pacman]
--repos <REPO>
Establece los repositorios a consultar [predeterminado: core,extra,multilib]
-n, --pkgnames <NOMBREPAQ>
Establece la lista separada por comas de los paquetes a consultar [env: PKGNAME=]
-f, --filter <ESTADO>
Establece el filtro para el estado del paquete [env: FILTER=] [valores posibles: GOOD, BAD, UNKWN]
-i, --inspect
Muestra el registro de compilación o diffoscope del paquete seleccionado interactivamente
-p, --pager <PAGER>
Establece el paginador para ver archivos [env: PAGER=] [predeterminado: less]
-c, --cache-dir <DIR>
Establece el directorio de caché para los archivos de registro [env: CACHE_DIR=]
-h, --help
Imprime la información de ayuda
-V, --version
Imprime la información de la versión

BUGS

Reporta errores en https://gitlab.archlinux.org/archlinux/arch-repro-status/-/issues
