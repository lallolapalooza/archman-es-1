NOMBRE

Archive::Cpio - módulo para manipulaciones de archivos cpio

SINOPSIS

use Archive::Cpio;
# ejemplo simple eliminando la entrada "foo"
my $cpio = Archive::Cpio->new;
$cpio->read($file);
$cpio->remove('foo');
$cio->write($file);
 # ejemplo más complejo, filtrando sobre la marcha
my $cpio = Archive::Cpio->new;
$cpio->read_with_handler(\*STDIN,
            sub {
                my ($e) = @_;
                if ($e->name ne 'foo') {
                    $cpio->write_one(\*STDOUT, $e);
                }
            });
$cpio->write_trailer(\*STDOUT);

DESCRIPCIÓN

Archive::Cpio proporciona algunas funciones para leer y escribir archivos cpio.

Archive::Cpio->new()

Crea un objeto

$cpio->read($nombre_archivo)

$cpio->read($manejador_archivo)

Lee el archivo cpio

$cpio->write($nombre_archivo)

$cpio->write($manejador_archivo)

Escribe las entradas y el tráiler

$cpio->remove(@nombres_archivos)

Elimina cualquier entrada cuyos nombres coincidan con cualquiera de los nombres de archivo dados del archivo en memoria

$cpio->get_files([ @nombres_archivos ])

Devuelve una lista de "Archive::Cpio::File" (después de una lectura de "$cpio-")

$cpio->get_file($nombre_archivo)

Devuelve el objeto "Archive::Cpio::File" que coincide con "$nombre_archivo" (después de una lectura de "$cpio-"read")

$cpio->add_data($nombre_archivo, $datos, $referencia_hash_opciones)

Toma un nombre de archivo, un escalar lleno de datos y opcionalmente una referencia a un hash con opciones específicas.

Añadirá un archivo al archivo en memoria, con el nombre $nombre_archivo y el contenido $datos. Las propiedades específicas se pueden establecer usando $referencia_hash_opciones.

$cpio->read_with_handler($manejador_archivo, $coderef)

Llama a la función manejadora en cada cabecera. Se pasa un objeto "Archive::Cpio::File" como parámetro

$cpio->write_one($manejador_archivo, $entrada)

Escribe un objeto "Archive::Cpio::File" (¡cuidado!, un archivo cpio válido necesita un tráiler usando "write_trailer")

$cpio->write_trailer($manejador_archivo)

Escribe el tráiler para finalizar el archivo cpio
