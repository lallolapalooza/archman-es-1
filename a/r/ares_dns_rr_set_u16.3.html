DESCRIPTIO

N

renvoie le nombre d'enregistrements de ressources dans l'enregistrement DNS fourni par le paramètre dnsrec pour la section fournie dans le paramètre sect. La fonction ares_dns_record_rr_add(3) ajoute

une

nouvelle entrée d'enregistrement de ressources à l'enregistrement DNS fourni par le paramètre dnsrec. L'enregistrement de ressources résultant est stocké dans la variable pointée par rr_out. La section DNS à laquelle appartient l'enregistrement de ressources est spécifiée par le paramètre sect. Le nom de domaine associé à l'enregistrement de ressources est spécifié par le paramètre name, qui ne peut pas être NULL mais peut être une chaîne vide ou « . ». Le type d'enregistrement de ressources est spécifié dans le paramètre type, ainsi que la classe d'enregistrement DNS dans le paramètre rclass, et le Time To Live (TTL) dans le paramètre ttl. L'index doit être inférieur à [[109]] ares_dns_record_rr_cnt(3). La première fonction renvoie un pointeur modifiable vers l'enregistrement de ressources, tandis que la seconde renvoie un pointeur en lecture seule vers l'enregistrement de ressources. La section RR DNS est spécifiée via le paramètre sect, et l'index à supprimer est spécifié dans le paramètre idx. L'index doit être inférieur à [[116]] ares_dns_record_rr_cnt(3). La función ares_dns_rr_set_opt(3) se utiliza para establecer claves y valores de opción/parámetro para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt, y se deja al usuario determinar el valor apropiado a utilizar. Algunos valores conocidos pueden ser proporcionados por las enumeraciones ares_svcb_param_t y ares_opt_param_t. El valor de la opción siempre se proporciona en forma binaria en val con la longitud proporcionada en val_len

.

La función ares_dns_rr_del_opt_byid(3) se utiliza para eliminar claves y valores de opción/parámetro para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt. Esta función devuelve ARES_SUCCESS si el registro se elimina correctamente, o ARES_ENOTFOUND si el registro no pudo ser

encontrado.

La función ares_dns_rr_get_addr(3) se utiliza para recuperar la dirección IPv4 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_addr6(3) se utiliza para recuperar la dirección IPv6 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR6. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_str(3) se utiliza para recuperar una cadena del registro de recursos cuando el tipo de datos es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_u8(3) se utiliza para recuperar un entero de 8 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U8. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_u16(3) se utiliza para recuperar un entero de 16 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U16. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_u32(3) se utiliza para recuperar un entero de 32 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U32. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_bin(3) se utiliza para recuperar datos binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y la longitud se almacena en la variable apuntada por len

.

La función ares_dns_rr_get_abin_cnt(3) se utiliza para recuperar el recuento del arreglo de valores binarios almacenados del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro

key.

La función ares_dns_rr_get_abin(3) se utiliza para recuperar datos binarios del arreglo del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y el índice a recuperar del arreglo se proporciona por el parámetro idx, y la longitud se almacena en la variable apuntada por len

.

La función ares_dns_rr_get_opt_cnt(3) se utiliza para recuperar el recuento de opciones/parámetros asociados con el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el key

.

La función ares_dns_rr_get_opt(3) se utiliza para recuperar datos de opción binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el índice especificado. El registro de recursos es proporcionado en el parámetro dns_rr y la clave/parámetro a recuperar es proporcionado en el parámetro key, el índice del cual recuperar los datos de opción se proporciona en el parámetro idx. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len

.

La función ares_dns_rr_get_opt_byid(3) se utiliza para recuperar datos de opción binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el identificador de opción especificado, si existe. El registro de recursos se proporciona en el parámetro dns_rr y el clave/parámetro a recuperar se proporciona en el parámetro key, el identificador del cual recuperar los datos de opción se proporciona en el parámetro opt . El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_le

n
.
