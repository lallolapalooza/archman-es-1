NOMBRE

ares_parse_aaaa_reply - Analizar una respuesta a una consulta DNS de tipo AAAA

SINOPSIS

#include <ares.h>
int ares_parse_aaaa_reply(const unsigned char *abuf, int alen,
                          struct hostent **host,         
                          struct ares_addr6ttl *addrttls, int *naddrttls);

DESCRIPCIÓN

La función ares_parse_aaaa_reply analiza la respuesta a una consulta de tipo AAAA en una struct hostent y/o un array de struct ares_addr6ttl. Los parámetros abuf y alen proporcionan el contenido de la respuesta. El resultado se almacena en memoria asignada y un puntero a ella se guarda en la variable apuntada por host, si host no es nulo. Es responsabilidad del llamador liberar la estructura host resultante usando ares_free_hostent(3) cuando ya no se necesite.

Si addrttls y naddrttls son ambos no nulos, entonces se almacenan hasta *naddrttls registros struct ares_addr6ttl en el array apuntado por addrttls, y luego *naddrttls se establece en el número de registros almacenados. Tenga en cuenta que la memoria para estos registros es proporcionada por el llamador.

VALORES DE RETORNO

ares_parse_aaaa_reply puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La respuesta se analizó correctamente.
ARES_EBADRESP
La respuesta tenía un formato incorrecto.
ARES_ENODATA
La respuesta no contenía una respuesta a la consulta.
ARES_ENOMEM
Se agotó la memoria.

VER TAMBIÉN

ares_gethostbyname(3), ares_free_hostent(3)
