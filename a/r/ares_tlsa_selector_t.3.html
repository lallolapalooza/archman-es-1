DESCRIPCIÓN La función ares_dns_record_rr_cnt(3) devuelve el número de registros de recursos en el registro DNS proporcionado por el parámetro
dnsrec para la sección proporcionada en el
parámetro sect . La función ares_dns_record_rr_add(3) añade una nueva entrada de registro de recursos al registro DNS proporcionado por el parámetro dnsrec
. El registro de recursos resultante se almacena en la variable a la que apunta rr_out . La sección DNS a la que pertenece el registro de recursos se especifica mediante el parámetro sect . El nombre de dominio asociado con el registro de recursos se especifica mediante el
parámetro name
, el cual no puede ser NULL pero puede ser una cadena vacía o ".". El tipo de registro de recursos se especifica en el parámetro type
, junto con la clase del registro DNS en el parámetro rclass , y el Tiempo de Vida (TTL) en el parámetro
ttl . Las funciones ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3)
se utilizan para recuperar el puntero del registro de recursos del registro DNS proporcionado en el parámetro dnsrec
, para la sección del registro de recursos proporcionada en el parámetro sect , para el índice especificado en el parámetro idx . El índice debe ser menor que ares_dns_record_rr_cnt(3) . La primera devuelve un puntero de escritura al registro de recursos, mientras que la segunda devuelve un puntero de solo lectura al registro de recursos. La función ares_dns_record_rr_del(3)

La función ares_dns_rr_set_opt(3) se utiliza para establecer claves y valores de opción/parámetro para el registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt, y queda a cargo del usuario determinar el valor apropiado a utilizar. Algunos valores conocidos pueden ser proporcionados por las enumeraciones ares_svcb_param_t y ares_opt_param_t. El valor para la opción siempre se proporciona en formato binario en val con la longitud proporcionada en val_len.

La función ares_dns_rr_del_opt_byid(3) se utiliza para eliminar claves y valores de opción/parámetro para el registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt. Esta función devuelve ARES_SUCCESS si el registro se elimina correctamente, o ARES_ENOTFOUND si no se pudo encontrar el registro.

La función ares_dns_rr_get_addr(3) se utiliza para recuperar la dirección IPv4 del registro de recursos cuando el tipo de dato es ARES_DATATYPE_INADDR. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_addr6(3) se utiliza para recuperar la dirección IPv6 del registro de recursos cuando el tipo de dato es ARES_DATATYPE_INADDR6. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_str(3) se utiliza para recuperar una cadena del registro de recursos cuando el tipo de dato es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u8(3) se utiliza para recuperar un entero de 8 bits del registro de recursos cuando el tipo de dato es ARES_DATATYPE_U8. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u16(3) se utiliza para recuperar un entero de 16 bits del registro de recursos cuando el tipo de dato es ARES_DATATYPE_U16. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u32(3) se utiliza para recuperar un entero de 32 bits del registro de recursos cuando el tipo de dato es ARES_DATATYPE_U32. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_bin(3) se utiliza para recuperar datos binarios del registro de recursos cuando el tipo de dato es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y la longitud se almacena en la variable apuntada por len.

La función ares_dns_rr_get_abin_cnt(3) se utiliza para recuperar el recuento del array de valores binarios almacenados del registro de recursos cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_abin(3) se utiliza para recuperar datos binarios del array de registros de recursos cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y el índice a recuperar del array se proporciona por el parámetro idx, y la longitud se almacena en la variable apuntada por len.

La función ares_dns_rr_get_opt_cnt(3) se utiliza para recuperar el recuento de opciones/parámetros asociados con el registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en la key.

La función ares_dns_rr_get_opt(3) se utiliza para recuperar datos binarios de opción del registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT para el índice especificado. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, el índice para recuperar los datos de opción se proporciona en el parámetro idx. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len.

La función ares_dns_rr_get_opt_byid(3) se utiliza para recuperar datos binarios de opción del registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT para el identificador de opción especificado, si existe. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, el identificador para recuperar los datos de opción se proporciona en el parámetro opt. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len.

VALORES DE RETORNO

ares_dns_record_rr_cnt(3) y ares_dns_rr_get_opt_cnt(3) devuelven los recuentos respectivos.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), y ares_dns_rr_set_opt(3) devuelven todos un código de error ares_status_t. Se devuelve ARES_SUCCESS en caso de éxito, ARES_ENOMEM en caso de falta de memoria, ARES_EFORMERR en caso de uso incorrecto.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) devuelven sus valores de tipo de dato prescritos y, en general, no pueden fallar, excepto en casos de uso incorrecto, en los que se puede devolver 0 (o NULL), sin embargo, 0 también puede ser un valor de retorno válido para la mayoría de estas funciones.

ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) devolverán el puntero del registro de recursos solicitado o NULL en caso de fallo (uso incorrecto).

ares_dns_rr_get_opt_byid(3) devolverá ARES_TRUE si se encontró la opción, de lo contrario ARES_FALSE si no se encontró (o uso incorrecto).
