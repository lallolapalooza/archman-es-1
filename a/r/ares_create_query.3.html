NOMBRE

ares_create_query - Componer un búfer de consulta DNS de pregunta única

SINOPSIS

#include <ares.h>
int ares_create_query(const char *name,
                      int dnsclass,
                      int type,
                      unsigned short id,
                      int rd,
                      unsigned char **buf,
                      int *buflen,
                      int max_udp_size);

DESCRIPCIÓN

Esta función está obsoleta a partir de c-ares 1.22, por favor use ares_dns_record_create(3) en su lugar.

La función ares_create_query(3) compone una consulta DNS con una única pregunta. El parámetro name proporciona el nombre de la consulta como una cadena de C terminada en NUL de etiquetas separadas por puntos, opcionalmente terminando con un punto; los puntos y las barras invertidas dentro de una etiqueta deben ser escapados con una barra invertida.

Los parámetros dnsclass y type proporcionan la clase y el tipo de la consulta utilizando los valores definidos en <arpa/nameser.h>.

El parámetro id proporciona un identificador de 16 bits para la consulta.

El parámetro rd debe ser distinto de cero si se desea recursión, cero si no.

La consulta se colocará en un búfer asignado, un puntero al cual se almacenará en la variable apuntada por buf, y la longitud del cual se almacenará en la variable apuntada por buflen.

Es responsabilidad del llamante liberar este búfer usando ares_free_string(3) cuando ya no sea necesario. El parámetro max_udp_size debe ser distinto de cero para activar EDNS. El uso de ares_create_query(3) con max_udp_size establecido en cero es equivalente a usar ares_mkquery(3).

VALORES DE RETORNO

ares_create_query puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La construcción de la consulta DNS tuvo éxito.
ARES_ENOTFOUND
El nombre de consulta name se refiere a un nombre de dominio .onion. Ver RFC 7686.
ARES_EBADNAME
El nombre de consulta name no pudo ser codificado como un nombre de dominio, ya sea porque contenía una etiqueta de longitud cero o porque contenía una etiqueta de más de 63 caracteres.
ARES_ENOMEM
Se agotó la memoria.

DISPONIBILIDAD

Añadido en c-ares 1.10.0

VER TAMBIÉN
