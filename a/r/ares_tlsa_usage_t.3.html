DESCRIPTION

The ares_dns_record_rr_cnt(3) function returns the number of resource records in the DNS record provided by the dnsrec parameter for the section provided in the sect parameter.

The ares_dns_record_rr_add(3) function adds a new resource record entry the the DNS record provided by the dnsrec parameter. The resulting resource record is stored into the variable pointed to by rr_out. The DNS section the resource record belongs to is specified by the sect parameter. The domain name associated with the resource record is specified by the name parameter, which can not be NULL but may be an empty string, or ".". The resource record type is specified in the type parameter, along with the DNS record class in the rclass parameter, and the Time To Live (TTL) in the ttl parameter.

The ares_dns_record_rr_get(3) and ares_dns_record_rr_get_const(3) functions are used to retrieve the resource record pointer from the DNS record provided in the dnsrec parameter, for the resource record section provided in the sect parameter, for the specified index in the idx parameter. The index must be less than ares_dns_record_rr_cnt(3). The former returns a writable pointer to the resource record, while the latter returns a read-only pointer to the resource record.

The ares_dns_record_rr_del(3) is used to delete a resource record from the DNS record specified in the dnsrec parameter. Its primary use is to remove a ARES_REC_TYPE_OPT record when needing to retry a query without EDNS support. The DNS RR section is specified via the sect parameter, and the index to remove is specified in the idx parameter. The index must be less than ares_dns_record_rr_cnt(3).

The ares_dns_rr_get_name(3) function is used to retrieve the resource record domain name from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_get_type(3) function is used to retrieve the resource record type from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_get_class(3) function is used to retrieve the resource record class from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_get_ttl(3) function is used to retrieve the resource record class Time to Live (TTL) from the Resource Record pointer provided in the rr parameter.

The ares_dns_rr_set_addr(3) function is used to set an IPv4 address for the associated resource record key/parameter when the datatype is ARES_DATATYPE_INADDR. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the addr parameter.

The ares_dns_rr_set_addr6(3) function is used to set an IPv6 address for the associated resource record key/parameter when the datatype is ARES_DATATYPE_INADDR6. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the addr parameter.

The ares_dns_rr_set_str(3) function is used to set a string for the associated resource record key/parameter when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. Most strings are limited to 255 bytes, however some records, such as a TXT record may allow longer as they are output as multiple strings. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_u8(3) function is used to set an 8bit unsigned value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_U8. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_u16(3) function is used to set an 16bit unsigned value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_U16. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_u32(3) function is used to set an 32bit unsigned value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_U32. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter.

The ares_dns_rr_set_bin(3) function is used to set a binary value for the associated resource record key/parameter when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter. And the associated value length is provided in the len parameter.

The ares_dns_rr_add_abin(3) function is used to append a binary value in the array for the associated resource record key/parameter when the datatype is ARES_DATATYPE_ABINP. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter, and the value is provided in the val parameter. And the associated value length is provided in the len parameter.

The ares_dns_rr_del_abin(3) function is used to delete a binary value in the array for the associated resource record key/parameter when the datatype is ARES_DATATYPE_ABINP. The resource record to be modified is provided in the dns_rr parameter, the key/parameter is provided in the key parameter.

La función ares_dns_rr_set_opt(3) se utiliza para establecer claves/parámetros de opción y sus valores para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt, y se deja al usuario determinar el valor apropiado a utilizar. Algunos valores conocidos pueden ser proporcionados por las enumeraciones ares_svcb_param_t y ares_opt_param_t . El valor de la opción siempre se proporciona en forma binaria en val con la longitud proporcionada en val_len.

La función ares_dns_rr_del_opt_byid(3) se utiliza para eliminar claves/parámetros de opción y sus valores para el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave/parámetro se proporciona en el parámetro key. El valor de opción/parámetro específico del registro de recursos se proporciona en el parámetro opt. Esta función devuelve ARES_SUCCESS si el registro se elimina correctamente, o ARES_ENOTFOUND si el registro no pudo ser encontrado.

La función ares_dns_rr_get_addr(3) se utiliza para recuperar la dirección IPv4 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_addr6(3) se utiliza para recuperar la dirección IPv6 del registro de recursos cuando el tipo de datos es ARES_DATATYPE_INADDR6. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_str(3) se utiliza para recuperar una cadena de texto del registro de recursos cuando el tipo de datos es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u8(3) se utiliza para recuperar un entero de 8 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U8. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u16(3) se utiliza para recuperar un entero de 16 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U16. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u32(3) se utiliza para recuperar un entero de 32 bits del registro de recursos cuando el tipo de datos es ARES_DATATYPE_U32. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_bin(3) se utiliza para recuperar datos binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y la longitud se almacena en la variable apuntada por len.

La función ares_dns_rr_get_abin_cnt(3) se utiliza para recuperar el conteo del arreglo de valores binarios almacenados del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_abin(3) se utiliza para recuperar datos binarios del arreglo del registro de recursos cuando el tipo de datos es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y el índice a recuperar del arreglo se proporciona por el parámetro idx, y la longitud se almacena en la variable apuntada por len.

La función ares_dns_rr_get_opt_cnt(3) se utiliza para recuperar el conteo de opciones/parámetros asociados con el registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el key.

La función ares_dns_rr_get_opt(3) se utiliza para recuperar datos de opción binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el índice especificado. El registro de recursos es proporcionado en el parámetro dns_rr y la clave/parámetro a recuperar es proporcionado en el parámetro key, el índice del cual recuperar los datos de opción se proporciona en el parámetro idx. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len.

La función ares_dns_rr_get_opt_byid(3) se utiliza para recuperar datos de opción binarios del registro de recursos cuando el tipo de datos es ARES_DATATYPE_OPT para el identificador de opción especificado, si existe. El registro de recursos se proporciona en el parámetro dns_rr y el clave/parámetro a recuperar se proporciona en el parámetro key, el identificador del cual recuperar los datos de opción se proporciona en el parámetro opt. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len.

VALORES DE RETORNO

ares_dns_record_rr_cnt(3) y ares_dns_rr_get_opt_cnt(3) devuelven los respectivos conteos.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), y ares_dns_rr_set_opt(3) devuelven todos un código de error ares_status_t . ARES_SUCCESS se devuelve en caso de éxito, ARES_ENOMEM se devuelve en caso de falta de memoria, ARES_EFORMERR se devuelve en caso de uso incorrecto.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) devuelven todos sus valores de tipo de datos prescritos y en general no pueden fallar excepto en casos de uso incorrecto, en los cuales se puede devolver un 0 (o NULL), sin embargo 0 también puede ser un valor de retorno válido para la mayoría de estas funciones.

ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) devolverán el puntero al registro de recursos solicitado o NULL en caso de fallo (uso incorrecto).

ares_dns_rr_get_opt_byid(3) devolverá ARES_TRUE si la opción fue encontrada, de lo contrario ARES_FALSE si no fue encontrada (o uso incorrecto).
