NOMBRE

archive_entry_linkresolver, archive_entry_linkresolver_new, archive_entry_linkresolver_set_strategy, archive_entry_linkresolver_free, archive_entry_linkify — funciones del resolutor de enlaces duros

BIBLIOTECA

Biblioteca de archivos de transmisión (libarchive, -larchive)

SINOPSIS

#include <archive_entry.h>

struct archive_entry_linkresolver *
archive_entry_linkresolver_new(void);

void
archive_entry_linkresolver_set_strategy(struct archive_entry_linkresolver *resolver, int format);

void
archive_entry_linkresolver_free(struct archive_entry_linkresolver *resolver);

void
archive_entry_linkify(struct archive_entry_linkresolver *resolver, struct archive_entry **entry, struct archive_entry **sparse);

DESCRIPCIÓN

Los programas que desean crear archivos tienen que lidiar con los enlaces duros. Los enlaces duros se manejan de diferentes maneras según los formatos de archivo. Las estrategias básicas son:

  1. Ignorar los enlaces duros y almacenar el cuerpo para cada referencia (cpio antiguo, zip).
  2. Almacenar el cuerpo la primera vez que se ve un inodo (ustar, pax).
  3. Almacenar el cuerpo la última vez que se ve un inodo (cpio nuevo).

Las funciones archive_entry_linkresolver ayudan proporcionando una interfaz unificada y manejando la complejidad detrás de escena.

Las funciones archive_entry_linkresolver asumen que las instancias de archive_entry tienen valores válidos de nlinks, inodo y dispositivo. El valor del inodo y dispositivo se utiliza para hacer coincidir las entradas. El valor de nlinks se utiliza para determinar si se han encontrado todas las referencias y si las referencias internas pueden ser recicladas.

La función archive_entry_linkresolver_new() asigna un nuevo resolutor de enlaces. La instancia se puede liberar usando archive_entry_linkresolver_free(). Todas las entradas diferidas se vacían y se libera el almacenamiento interno.

La función archive_entry_linkresolver_set_strategy() selecciona la estrategia óptima de enlaces duros para el formato dado. El código de formato se puede obtener de archive_format(3). La función se puede llamar más de una vez, pero se recomienda vaciar todas las entradas diferidas primero.

La función archive_entry_linkify() es el núcleo de archive_entry_linkresolver. El argumento entry() apunta a la archive_entry que debe ser escrita. Dependiendo de la estrategia se realiza una de las siguientes acciones:

  1. Para los formatos de archivo simples, *entry se deja sin modificar y *sparse se establece en NULL.
  2. Para los formatos de archivo tipo tar, *sparse se establece en NULL. Si *entry es NULL, no se realiza ninguna acción. Si el recuento de enlaces duros de *entry es mayor que 1 y el tipo de archivo es un archivo regular o un enlace simbólico, la lista interna se busca para encontrar un inodo coincidente. Si se encuentra dicho inodo, el recuento de enlaces se decrementa y el tamaño del archivo de *entry se establece en 0 para notificar que no se debe escribir ningún cuerpo. Si no se encuentra dicho inodo, se añade una copia de la entrada a la caché interna con un recuento de enlaces reducido en uno.
  3. Para los formatos de archivo tipo cpio nuevo, se utiliza un valor para *entry de NULL para vaciar las entradas diferidas. En ese caso, *entry se establece en una entrada diferida arbitraria y la entrada en sí se elimina de la lista interna. Si la lista interna está vacía, *entry se establece en NULL. En cualquier caso, *sparse se establece en NULL y la función retorna. Si el recuento de enlaces duros de *entry es uno o el tipo de archivo es un directorio o dispositivo, *sparse se establece en NULL y no se realiza ninguna acción adicional. De lo contrario, se busca en la lista interna un inodo coincidente. Si no se encuentra dicho inodo, la entrada se añade a la lista interna, tanto *entry como *sparse se establecen en NULL y la función retorna. Si se encuentra dicho inodo, el recuento de enlaces se decrementa. Si sigue siendo mayor que uno, la entrada existente en la lista interna se intercambia con *entry después de retener el recuento de enlaces. La entrada existente se devuelve en *entry. Si el recuento de enlaces llega a uno, la nueva entrada también se elimina de la lista interna y se devuelve en *sparse. De lo contrario, *sparse se establece en NULL.

Por lo tanto, el uso general es:

  1. Por cada nueva entrada de archivo, llama a archive_entry_linkify().
  2. Ten en cuenta que las entradas devueltas pueden tener ahora un tamaño de 0.
  3. Si *entry no es NULL, archívalo.
  4. Si *sparse no es NULL, archívalo.
  5. Después de que todas las entradas se hayan escrito en disco, llama a archive_entry_linkify() con *entry establecido en NULL y archiva la entrada devuelta mientras no sea NULL.

VALORES DE RETORNO

archive_entry_linkresolver_new() retorna NULL en caso de fallos de malloc(3).
