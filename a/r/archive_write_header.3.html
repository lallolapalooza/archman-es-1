ARCHIVE_WRITE_HEADER(3) Manual de funciones de biblioteca ARCHIVE_WRITE_HEADER(3)

NOMBRE

archive_write_header — funciones para crear archivos

BIBLIOTECA

Biblioteca de archivos de transmisión (libarchive, -larchive)

SINOPSIS

#include <archive.h>

int
archive_write_header(struct archive *, struct archive_entry *);

DESCRIPCIÓN

Construye y escribe una cabecera utilizando los datos de la estructura struct archive_entry proporcionada. Consulte archive_entry(3) para obtener información sobre cómo crear y poblar objetos struct archive_entry.

VALORES DE RETORNO

Esta función devuelve ARCHIVE_OK en caso de éxito, o uno de los siguientes en caso de error: ARCHIVE_RETRY para operaciones que podrían tener éxito si se reintentan, ARCHIVE_WARN para condiciones inusuales que no impiden operaciones posteriores, y ARCHIVE_FATAL para errores graves que hacen imposibles las operaciones restantes.

ERRORES

Los códigos de error detallados y las descripciones textuales están disponibles en las funciones archive_errno() y archive_error_string().

VER TAMBIÉN

tar(1), archive_write_set_options(3), libarchive(3), cpio(5), mtree(5), tar(5)
