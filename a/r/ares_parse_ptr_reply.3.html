NOMBRE

ares_parse_ptr_reply - Analiza una respuesta a una consulta DNS de tipo PTR en un hostent

SINOPSIS

#include <ares.h>
int ares_parse_ptr_reply(const unsigned char *abuf, int alen,
                         const void *addr, int addrlen,
                         int family, struct hostent **host);

DESCRIPCIÓN

La función ares_parse_ptr_reply analiza la respuesta a una consulta de tipo PTR en un struct hostent. Los parámetros abuf y alen proporcionan el contenido de la respuesta. Los parámetros addr, addrlen y family especifican qué dirección fue consultada; no se utilizan para verificar la respuesta, sino para rellenar la dirección del struct hostent. El struct hostent resultante se almacena en memoria asignada y se almacena un puntero a él en la variable apuntada por host. Es responsabilidad del llamador liberar la estructura host resultante usando ares_free_hostent(3) cuando ya no sea necesaria.

VALORES DE RETORNO

ares_parse_ptr_reply puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La respuesta se analizó correctamente.
ARES_EBADRESP
La respuesta estaba mal formateada.
ARES_ENODATA
La respuesta no contenía una respuesta a la consulta.
ARES_ENOMEM
Se agotó la memoria.

VER TAMBIÉN

ares_gethostbyaddr(3), ares_free_hostent(3)
