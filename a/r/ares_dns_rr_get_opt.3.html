DESCRIPCIÓ

N

La función ares_dns_record_rr_cnt(3) devuelve el número de registros de recursos en el registro DNS proporcionado por el parámetro dnsrec para la sección proporcionada en el parámetro

sect.

La función ares_dns_record_rr_add(3) añade una nueva entrada de registro de recursos al registro DNS proporcionado por el parámetro dnsrec. El registro de recursos resultante se almacena en la variable a la que apunta rr_out. La sección DNS a la que pertenece el registro de recursos se especifica mediante el parámetro sect. El nombre de dominio asociado con el registro de recursos se especifica mediante el parámetro name, que no puede ser NULL pero puede ser una cadena vacía o ".". El tipo de registro de recursos se especifica en el parámetro type, junto con la clase del registro DNS en el parámetro rclass, y el Tiempo de Vida (TTL) en el parámetro

ttl.

La función ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) se utilizan para recuperar el puntero al registro de recursos del registro DNS proporcionado en el parámetro dnsrec, para la sección de registro de recursos proporcionada en el parámetro sect, para el índice especificado en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3). La primera devuelve un puntero de escritura al registro de recursos, mientras que la segunda devuelve un puntero de solo lectura al registro de

recursos.

La función ares_dns_record_rr_del(3) se utiliza para eliminar un registro de recursos del registro DNS especificado en el parámetro dnsrec. Su uso principal es eliminar un registro ARES_REC_TYPE_OPT cuando se necesita reintentar una consulta sin soporte EDNS. La sección RR de DNS se especifica mediante el parámetro sect, y el índice a eliminar se especifica en el parámetro idx. El índice debe ser menor que ares_dns_record_r

r_cnt(3).

La función ares_dns_rr_get_name(3) se utiliza para recuperar el nombre de dominio del registro de recursos del puntero al Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_type(3) se utiliza para recuperar el tipo de registro de recursos del puntero al Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_class(3) se utiliza para recuperar la clase del registro de recursos del puntero al Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_get_ttl(3) se utiliza para recuperar el Tiempo de Vida (TTL) de la clase del registro de recursos del puntero al Registro de Recursos proporcionado en el parámetro

rr.

La función ares_dns_rr_set_addr(3) se utiliza para establecer una dirección IPv4 para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_INADDR. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

addr.

La función ares_dns_rr_set_addr6(3) se utiliza para establecer una dirección IPv6 para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_INADDR6. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

addr.

La función ares_dns_rr_set_str(3) se utiliza para establecer una cadena para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. La mayoría de las cadenas están limitadas a 255 bytes, sin embargo algunos registros, como un registro TXT, pueden permitir más ya que se emiten como múltiples cadenas. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u8(3) se utiliza para establecer un valor sin signo de 8 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U8. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u16(3) se utiliza para establecer un valor sin signo de 16 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U16. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_u32(3) se utiliza para establecer un valor sin signo de 32 bits para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U32. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro

val.

La función ares_dns_rr_set_bin(3) se utiliza para establecer un valor binario para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro

len.

La función ares_dns_rr_add_abin(3) se utiliza para añadir un valor binario al array para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val. Y la longitud del valor asociado se proporciona en el parámetro

len.

La función ares_dns_rr_del_abin(3) se utiliza para eliminar un valor binario del array para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro es c-ares DNS record manipulation functions

ENUMERATIONS

Several types of data can be stored and retrieved from resource records. These include:

ARES_DATATYPE_INADDR
IPv4 address.
ARES_DATATYPE_INADDR6
IPv6 address.
ARES_DATATYPE_STR
Null-terminated string.
ARES_DATATYPE_NAME
Domain name string.
ARES_DATATYPE_U8
8-bit unsigned integer.
ARES_DATATYPE_U16
16-bit unsigned integer.
ARES_DATATYPE_U32
32-bit unsigned integer.
ARES_DATATYPE_BIN
Arbitrary binary data.
ARES_DATATYPE_BINP
Pointer to binary data.
ARES_DATATYPE_ABINP
Array of pointers to binary data.
ARES_DATATYPE_OPT
Option/parameter data, typically used for EDNS.

The key names are defined in the scope of the resource record.

DESCRIPTION

These functions provide the means to inspect and manipulate individual resource records (RRs) within a DNS record. The resource record to be modified or inspected is provided in the dns_rr parameter.

The ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), and ares_dns_rr_get_ttl(3) functions are used to retrieve the name, type, class, and TTL of the resource record, respectively.

The set functions allow modifying the value of a key within a resource record based on the datatype. For example, ares_dns_rr_set_addr(3) and ares_dns_rr_set_addr6(3) are used to set IPv4 and IPv6 addresses, respectively. ares_dns_rr_set_str(3) sets a string value, while ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), and ares_dns_rr_set_u32(3) set 8-bit, 16-bit, and 32-bit unsigned integers, respectively. ares_dns_rr_set_bin(3) is used to set arbitrary binary data. The key for the data is provided in the key parameter.

The ares_dns_rr_add_abin(3) function is used to add an entry to an array of binary data. The resource record is provided in the dns_rr parameter, the key is provided in the key parameter, and the binary value and its length are provided in val and val_len, respectively.

The ares_dns_rr_del_abin(3) function is used to delete an entry from an array of binary data. The resource record is provided in the dns_rr parameter, the key is provided in the key parameter, and the index of the entry to remove is provided in the idx parameter.

The ares_dns_rr_set_opt(3) function is used to set option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter, and this is left to the user to determine the appropriate value to use. Some known values may be provided by ares_svcb_param_t and ares_opt_param_t enumerations. The value for the option is always provided in binary form in val with length provided in val_len.

The ares_dns_rr_del_opt_byid(3) function is used to delete option/parameter keys and values for the resource record when the datatype is ARES_DATATYPE_OPT. The resource record to be modified is provided in the dns_rr parameter. They key/parameter is provided in the key parameter. The option/parameter value specific to the resource record is provided in the opt parameter. This function returns ARES_SUCCESS if the record is successfully removed, or ARES_ENOTFOUND if the record could not be found.

The ares_dns_rr_get_addr(3) function is used to retrieve the IPv4 address from the resource record when the datatype is ARES_DATATYPE_INADDR. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_addr6(3) function is used to retrieve the IPv6 address from the resource record when the datatype is ARES_DATATYPE_INADDR6. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_str(3) function is used to retrieve a string from the resource record when the datatype is ARES_DATATYPE_STR or ARES_DATATYPE_NAME. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u8(3) function is used to retrieve an 8bit integer from the resource record when the datatype is ARES_DATATYPE_U8. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u16(3) function is used to retrieve a 16bit integer from the resource record when the datatype is ARES_DATATYPE_U16. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_u32(3) function is used to retrieve a 32bit integer from the resource record when the datatype is ARES_DATATYPE_U32. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_bin(3) function is used to retrieve binary data from the resource record when the datatype is ARES_DATATYPE_BIN or ARES_DATATYPE_BINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_abin_cnt(3) function is used to retrieve the count of the array of stored binary values from the resource record when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter.

The ares_dns_rr_get_abin(3) function is used to retrieve binary data from the resource record array when the datatype is ARES_DATATYPE_ABINP. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, and the index to retrieve from the array is provided by the idx parameter, and length is stored into the variable pointed to by len.

The ares_dns_rr_get_opt_cnt(3) function is used to retrieve the count of options/parameters associated with the resource record when the datatype is ARES_DATATYPE_OPT. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key.

The ares_dns_rr_get_opt(3) function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified index. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the index to retrieve the option data from is provided in the idx parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

The ares_dns_rr_get_opt_byid(3) function is used to retrieve binary option data from the resource record when the datatype is ARES_DATATYPE_OPT for the specified option identifier, if it exists. The resource record is provided in the dns_rr parameter and the key/parameter to retrieve is provided in the key parameter, the identifier to retrieve the option data from is provided in the opt parameter. The value is stored into the variable pointed to by val and length is stored into the variable pointed to by val_len.

RETURN VALUES

ares_dns_record_rr_cnt(3) and ares_dns_rr_get_opt_cnt(3) return the respective counts.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), and ares_dns_rr_set_opt(3) all return an ares_status_t error code. ARES_SUCCESS is returned on success, ARES_ENOMEM is returned on out of memory, ARES_EFORMERR is returned on misuse.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) all return their prescribed datatype values and in general can't fail except for misuse cases, in which a 0 (or NULL) may be returned, however 0 can also be a valid return value for most of these functions.

ares_dns_record_rr_get(3) and ares_dns_record_rr_get_const(3) will return the requested resource record pointer or NULL on failure (misuse).

ares_dns_rr_get_opt_byid(3) will return ARES_TRUE if the option was found, otherwise ARES_FALSE if not found (or misuse).

AVAILABILITY

These functions were first introduced in c-ares version 1.22.0.
