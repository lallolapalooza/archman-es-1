S

ares_dns_datatype_t - Tipos de datos asociados con ares_dns_rr_key_t

:
ARES_DATATYPE_INADDR - Dirección IPv4 como struct in_addr *. Use ares_dns_rr_set_addr(3) para establecer y ares_dns_rr_get_addr(3) para obtener.
ARES_DATATYPE_INADDR6 - Dirección IPv6 como struct ares_in6_addr *. Use ares_dns_rr_set_addr6(3) para establecer y ares_dns_rr_get_addr6(3) para obtener.
ARES_DATATYPE_U8 - Entero sin signo de 8 bits. Use ares_dns_rr_set_u8(3) para establecer y ares_dns_rr_get_u8(3) para obtener.
ARES_DATATYPE_U16 - Entero sin signo de 16 bits. Use ares_dns_rr_set_u16(3) para establecer y ares_dns_rr_get_u16(3) para obtener.
ARES_DATATYPE_U32 - Entero sin signo de 32 bits. Use ares_dns_rr_set_u32(3) para establecer y ares_dns_rr_get_u32(3) para obtener.
ARES_DATATYPE_NAME - Cadena terminada en nulo de un nombre de dominio (serie de etiquetas). Use ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_STR - Cadena terminada en nulo. Use ares_dns_rr_set_str(3) para establecer y ares_dns_rr_get_str(3) para obtener.
ARES_DATATYPE_BIN - Datos binarios. Use ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_BINP - Oficialmente definido como datos binarios, pero probablemente imprimible. Garantizado tener un terminador NULL por conveniencia (no incluido en la longitud). Use ares_dns_rr_set_bin(3) para establecer y ares_dns_rr_get_bin(3) para obtener.
ARES_DATATYPE_OPT - Arreglo de opciones. Identificador de 16 bits, datos binarios. Use ares_dns_rr_set_opt(3) para establecer y ares_dns_rr_get_opt(3) para obtener.
ARES_DATATYPE_ABINP - Arreglo de datos binarios, pero probablemente imprimible. Garantizado tener un terminador NULL por conveniencia (no incluido en la longitud). Use ares_dns_rr_add_abin(3) para establecer y ares_dns_rr_get_abin(3) para obtener. También puede usar ares_dns_rr_set_bin(3) y ares_dns_rr_get_bin(3) si solo se desean cadenas concatenadas.

ares_dns_opt_datatype_t - Tipos de datos asociados con parámetros ARES_DATATYPE_OPT si se conocen, como lo devuelve ares_dns_opt_get_da

tatype(3):
ARES_OPT_DATATYPE_NONE - No se permite valor para este parámetro
ARES_OPT_DATATYPE_STR_LIST - Lista de cadenas, cada una prefijada con un solo octeto que representa la longitud según lo definido por RFC 1035. Puede usar ares_expand_string(3) hasta que se consuma el búfer.
ARES_OPT_DATATYPE_U8_LIST - Lista de enteros sin signo de 8 bits, concatenados
ARES_OPT_DATATYPE_U16 - Entero sin signo de 16 bits en orden de bytes de red
ARES_OPT_DATATYPE_U16_LIST - lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_U32 - Entero sin signo de 32 bits en orden de bytes de red
ARES_OPT_DATATYPE_U32_LIST - lista de enteros sin signo de 16 bits en orden de bytes de red, concatenados.
ARES_OPT_DATATYPE_INADDR4_LIST - Lista de direcciones ipv4 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_INADDR6_LIST - Lista de direcciones ipv6 en orden de bytes de red, concatenadas
ARES_OPT_DATATYPE_BIN - Datos binarios
ARES_OPT_DATATYPE_NAME - Formato binario de nombre de dominio DNS como se define en RFC1035, puede usar ares_expand_name(3)

ares_svcb_param_t - Parámetros conocidos de SVCB (y HTTPS) RR como lo devuelve ares_dns_opt_get_datatype(3) con ARES_RR_SVCB_PARAMS o ARES_RR_HTTPS_PARAMS

:
ARES_SVCB_PARAM_MANDATORY - Claves obligatorias en este RR (RFC 9460 Sección 8). Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_SVCB_PARAM_ALPN - Protocolos soportados adicionales (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_STR_LIST
ARES_SVCB_PARAM_NO_DEFAULT_ALPN - Sin soporte para el protocolo predeterminado (RFC 9460 Sección 7.1). Tipo de dato: ARES_OPT_DATATYPE_NONE
ARES_SVCB_PARAM_PORT - Puerto para el punto final alternativo (RFC 9460 Sección 7.2). Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_SVCB_PARAM_IPV4HINT - Sugerencias de dirección IPv4 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR4_LIST
ARES_SVCB_PARAM_ECH - RESERVADO (mantenido para Encrypted ClientHello)
ARES_SVCB_PARAM_IPV6HINT - Sugerencias de dirección IPv6 (RFC 9460 Sección 7.3). Tipo de dato: ARES_OPT_DATATYPE_INADDR6_LIS
T

ares_opt_param_t - Parámetros conocidos de OPT RR como lo devuelve ares_dns_opt_get_datatype(3) con ARES_RR_OPT_OPTIONS

:
ARES_OPT_PARAM_LLQ - RFC 8764. Protocolo de Consultas de Larga Duración (Long-Lived Queries) de Apple. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_UL - http://files.dns-sd.org/draft-sekar-dns-ul.txt: Update Lease. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_NSID - RFC 5001. Identificación del Servidor de Nombres. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_DAU - RFC 6975. Algoritmo DNSSEC Entendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_DHU - RFC 6975. Hash DS Entendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_N3U - RFC 6975. Hash NSEC3 Entendido. Tipo de dato: ARES_OPT_DATATYPE_U8_LIST
ARES_OPT_PARAM_EDNS_CLIENT_SUBNET - RFC 7871. Subred del Cliente. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_EXPIRE - RFC 7314. Temporizador de Expiración. Tipo de dato: ARES_OPT_DATATYPE_U32
ARES_OPT_PARAM_COOKIE - RFC 7873. Cookies del Cliente y del Servidor. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_EDNS_TCP_KEEPALIVE - RFC 7828. Tiempo de espera de Keepalive TCP. Tipo de dato: ARES_OPT_DATATYPE_U16
ARES_OPT_PARAM_PADDING - RFC 7830. Relleno. Tipo de dato: ARES_OPT_DATATYPE_BIN
ARES_OPT_PARAM_CHAIN - RFC 7901. Solicitudes de consulta en cadena. Tipo de dato: ARES_OPT_DATATYPE_NAME
ARES_OPT_PARAM_EDNS_KEY_TAG - RFC 8145. Señalización del conocimiento del ancla de confianza en DNSSEC. Tipo de dato: ARES_OPT_DATATYPE_U16_LIST
ARES_OPT_PARAM_EXTENDED_DNS_ERROR - RFC 8914. Código y mensaje de ERROR extendido. Tipo de dato: ARES_OPT_DATATYPE_BIN

DESCRIPCIÓ

N

La función ares_dns_rec_type_tostrr(3) función devuelve un tipo de registro DNS legible para humanos a partir de su forma numérica pasada en type

.

The ares_dns_class_tostr(3) función devuelve una clase DNS legible para humanos a partir de su forma numérica pasada en qclass

.

The ares_dns_opcode_tostr(3) función devuelve un código de operación DNS legible para humanos a partir de su forma numérica en opcode

.

The ares_dns_rr_key_tostr(3) función devuelve un nombre de parámetro de Registro de Recurso DNS legible para humanos a partir de su forma numérica en key

.

The ares_dns_section_tostr(3) función devuelve una sección de mensaje DNS legible para humanos a partir de su forma numérica en section

.

The ares_dns_rcode_tostr(3) función devuelve un código de respuesta DNS legible para humanos a partir de su forma numérica en rcode

.

The ares_dns_class_fromstr(3) función devuelve la clase DNS en forma numérica a partir de su representación de cadena en str. The result is stored into the variable pointed to by qclass

.

The ares_dns_rec_type_fromstr(3) función devuelve el tipo de registro DNS en forma numérica a partir de su representación de cadena en str. The result is stored into the variable pointed to by qtype

.

The ares_dns_rr_get_keys(3) función recupera una lista de parámetros que pueden establecerse o recuperarse para el type. The count of returned keys is stored into the variable pointed to by cnt

.

The ares_dns_rr_key_datatype(3) función recupera el tipo de datos asociado para un parámetro RR especificado por key

.

The ares_dns_rr_key_to_rec_type(3) función desreferencia el parámetro RR proporcionado especificado por key al Tipo de Registro DNS al que

pertenece.

The ares_dns_opt_get_datatype(3) función se utiliza en asociación con ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt(3) para recuperar el tipo de datos de un registro de opción contenido dentro de un RR como se especifica en key si se conoce. El identificador crudo del registro de opción es proporcionado por opt

.

The ares_dns_opt_get_name(3) función se utiliza en asociación con ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt(3) para recuperar el nombre de parámetro legible para humanos de un registro de opción contenido dentro de un RR como se especifica en key si se conoce. El identificador crudo del registro de opción es proporcionado por op

t
.

VALORES DE

RETORNO

ares_dns_rec_type_tostr(3), ares_dns_class_tostr(3), ares_dns_opcode_tostr(3), ares_dns_rr_key_tostr(3), ares_dns_section_tostr(3), ares_dns_rcode_tostr(3), y ares_dns_opt_get_name(3) todas devuelven una cadena ASCII imprimible legible para humanos, o NULL en caso de

error.

ares_dns_class_fromstr(3) y ares_dns_rec_type_fromstr(3) devuelven ARES_TRUE en una conversión exitosa, de lo contrario ARES_FALSE

.

ares_dns_rr_get_keys(3) devuelve un array de claves o NULL en caso de

fallo.

ares_dns_rr_key_datatype(3), ares_dns_rr_key_to_rec_type(3), y ares_dns_opt_get_datatype(3) devuelven sus respe

ctivos valores enteros,
o 0 en caso de fallo.
