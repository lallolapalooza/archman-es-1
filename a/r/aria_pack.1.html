ARIA_PACK(1) Comandos de usuario ARIA_PACK(1)

NOMBRE

aria_pack - generar tablas comprimidas y de solo lectura de Aria

SINOPSIS

aria_pack [OPCIONES] nombre_archivo...

DESCRIPCIÓN

Empaqueta una tabla de Aria para que ocupe mucho menos espacio. Las claves no se actualizan; debes ejecutar aria_chk -rq en el archivo de índice (.MAI) después para actualizar las claves. Debes proporcionar el archivo .MAI como argumento del nombre de archivo. Para desempaquetar una tabla empaquetada, ejecuta aria_chk -u en la tabla.

-b, --backup
Haz una copia de seguridad de la tabla como nombre_tabla.OLD.
--character-sets-dir=nombre
Directorio donde se encuentran los conjuntos de caracteres.
-#, --debug[=nombre]
Registra el registro de depuración. A menudo es 'd:t:o,nombre_archivo'.
-f, --force
Fuerza el empaquetado de la tabla incluso si aumenta de tamaño o si existe un archivo temporal.
-j, --join=nombre
Une todas las tablas dadas en 'nuevo_nombre_tabla'. Todas las tablas DEBEN tener diseños idénticos.
-?, --help
Muestra esta ayuda y sale.
-s, --silent
Sé más silencioso.
-T, --tmpdir=nombre
Usa el directorio temporal para almacenar la tabla temporal.
-t, --test
No empaquetes la tabla, solo prueba a empaquetarla.
-v, --verbose
Escribe información sobre el progreso y el resultado del empaquetado. ¡Usa muchas -v para más verbosidad!
-V, --version
Muestra información de la versión y sale.
-w, --wait
Espera y reintenta si la tabla está en uso.

Las opciones predeterminadas se leen de los siguientes archivos en el orden dado: /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf

Se leen los siguientes grupos: ariapack

Las siguientes opciones pueden darse como primer argumento:

--print-defaults
Imprime la lista de argumentos del programa y sale.
--no-defaults
No leas opciones predeterminadas de ningún archivo de opciones.
--defaults-file=#
Solo lee opciones predeterminadas del archivo # dado.
--defaults-extra-file=#
Lee este archivo después de que se lean los archivos globales.

VER TAMBIÉN

myisampack(1)
