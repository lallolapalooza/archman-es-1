ares_set_socket_configure_callback(3)

Paquete: c-ares

Licencias: MIT

ARES_SET_SOCKET_CONFIGURE_CALLBACK(3) Manual de funciones de biblioteca ARES_SET_SOCKET_CONFIGURE_CALLBACK(3)

NOMBRE

ares_set_socket_configure_callback - Establece una función de devolución de llamada para la configuración de sockets

SINOPSIS

#include <ares.h>
typedef int (*ares_sock_config_callback)(ares_socket_t socket_fd,
                                         int type,
                                         void *userdata)
void ares_set_socket_configure_callback(ares_channel_t *channel,
                                        ares_sock_config_callback callback,
                                        void *userdata)

DESCRIPCIÓN

Esta función establece una función de devolución de llamada en el manejador del canal de ares dado. No se puede utilizar cuando se pasa ARES_OPT_EVENT_THREAD a ares_init_options(3).

Esta función de devolución de llamada se invocará después de que se haya creado el socket, pero antes de que se haya conectado al servidor remoto, lo cual es un momento ideal para configurar varias opciones del socket. La función de devolución de llamada debe devolver ARES_SUCCESS si todo está bien, o devolver -1 para indicar un error. Un error devuelto abortará la operación de ares.

VER TAMBIÉN

ares_init_options(3), ares_set_socket_callback(3)
