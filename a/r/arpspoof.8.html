ARPSPOOF(8) Manual del Administrador del Sistema ARPSPOOF(8)

NOMBRE

arpspoof - interceptar paquetes en una LAN conmutada

SINOPSIS

arpspoof [-i interfaz] [-c propia|host|ambos] [-t objetivo] [-r] host

DESCRIPCIÓN


arpspoof redirige los paquetes de un host objetivo (o de todos los hosts) en la LAN destinados a otro host en la LAN mediante la falsificación de respuestas ARP. Esta es una forma extremadamente eficaz de capturar tráfico en un switch.

El reenvío IP del kernel (o un programa en espacio de usuario que logre lo mismo, p. ej., fragrouter(8)) debe estar activado de antemano.

OPCIONES

-i interfaz
Especifica la interfaz a utilizar.
-c propia|host|ambos
Especifica qué dirección de hardware utilizar al restaurar la configuración arp; mientras se limpia, los paquetes pueden enviarse con la propia dirección así como con la dirección del host. El envío de paquetes con una dirección de hardware falsa puede interrumpir la conectividad con ciertas configuraciones de switch/ap/bridge, sin embargo, funciona de manera más fiable que usar la propia dirección, que es la forma predeterminada en que arpspoof limpia después.
-t objetivo
Especifica un host en particular para envenenar con ARP (si no se especifica, todos los hosts en la LAN). Repetir para especificar múltiples hosts.
-r
Envenena ambos hosts (host y objetivo) para capturar tráfico en ambas direcciones. (solo válido en conjunción con -t)
host
Especifica el host para el que deseas interceptar paquetes (generalmente la puerta de enlace local).

VER TAMBIÉN

dsniff(8), fragrouter(8)
