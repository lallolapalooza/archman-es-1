ares_search_dnsrec(3)

Paquete: c-ares

Licencias: MIT

ARES_SEARCH(3) Manual de funciones de la biblioteca ARES_SEARCH(3)

NOMBRE

ares_search - Inicia una consulta DNS con búsqueda de dominio

SINOPSIS

#include <ares.h>
typedef void (*ares_callback_dnsrec)(void *arg,
                                     ares_status_t status,
                                     size_t timeouts,
                                     const ares_dns_record_t *dnsrec);
void ares_search_dnsrec(ares_channel_t *channel,
                        const ares_dns_record_t *dnsrec,
                        ares_callback_dnsrec callback, void *arg);
typedef void (*ares_callback)(void *arg, int status,
                              int timeouts, unsigned char *abuf,
                              int alen);
void ares_search(ares_channel_t *channel, const char *name,
                 int dnsclass, int type,
                 ares_callback callback, void *arg);

DESCRIPCIÓN

La función ares_search inicia una serie de consultas DNS de pregunta única en el canal de servicio de nombres identificado por channel, utilizando los dominios de búsqueda del canal, así como un archivo de alias de host dado por la variable de entorno HOSTALIAS. El parámetro name proporciona el nombre del alias o la base del nombre de consulta como una cadena C terminada en NUL de etiquetas separadas por puntos; si termina con un punto, los dominios de búsqueda del canal no se utilizarán. Los puntos y las barras invertidas dentro de una etiqueta deben escaparse con una barra invertida. Los parámetros dnsclass y type proporcionan la clase y el tipo de la consulta utilizando los valores definidos en <arpa/nameser.h>. Cuando la secuencia de consulta se completa o ha fallado, la biblioteca ares invocará a callback. La finalización o el fallo de la secuencia de consulta pueden ocurrir inmediatamente o durante una llamada posterior a ares_process(3) o ares_destroy(3).

Si esto se llama desde un hilo que no es el que ejecuta el bucle principal de eventos del programa, se debe tener cuidado para garantizar que las listas de descriptores de archivos se actualicen inmediatamente dentro del bucle de eventos. Cuando se llama a la función de retorno de llamada asociada, se hace con un bloqueo de canal, por lo que se debe tener cuidado para garantizar que cualquier procesamiento sea mínimo para evitar bloqueos en el canal DNS.

El argumento de retorno de llamada arg se copia del argumento arg de ares_search. El argumento de retorno de llamada status indica si la secuencia de consulta terminó con una consulta exitosa y, si no, cómo falló la secuencia de consulta. Puede tener cualquiera de los siguientes valores:

ARES_SUCCESS
Una consulta se completó con éxito.
ARES_ENODATA
Ninguna consulta se completó con éxito; cuando se intentó la consulta sin un dominio de búsqueda añadido, se recibió una respuesta sin respuestas.
ARES_EFORMERR
Una consulta se completó pero el servidor afirmó que la consulta estaba mal formada.
ARES_ESERVFAIL
Ninguna consulta se completó con éxito; cuando se intentó la consulta sin un dominio de búsqueda añadido, el servidor afirmó haber experimentado un fallo. (Este código solo puede ocurrir si el flag ARES_FLAG_NOCHECKRESP se especificó en el momento de la inicialización del canal; de lo contrario, tales respuestas se ignoran a nivel de ares_send(3).)
ARES_ENOTFOUND
Ninguna consulta se completó con éxito; cuando se intentó la consulta sin un dominio de búsqueda añadido, el servidor informó que el nombre de dominio consultado no se encontró.
ARES_ENOTIMP
Una consulta se completó pero el servidor no implementa la operación solicitada por la consulta. (Este código solo puede ocurrir si el flag ARES_FLAG_NOCHECKRESP se especificó en el momento de la inicialización del canal; de lo contrario, tales respuestas se ignoran a nivel de ares_send(3).)
ARES_EREFUSED
Una consulta se completó pero el servidor rechazó la consulta. (Este código solo puede ocurrir si el flag ARES_FLAG_NOCHECKRESP se especificó en el momento de la inicialización del canal; de lo contrario, tales respuestas se ignoran a nivel de ares_send(3).)
ARES_TIMEOUT
Ningún servidor de nombres respondió a una consulta dentro del período de tiempo de espera.
ARES_ECONNREFUSED
No se pudo contactar a ningún servidor de nombres.
ARES_ENOMEM
Se agotó la memoria.
ARES_ECANCELLED
La consulta fue cancelada.
ARES_EDESTRUCTION
El canal de servicio de nombres channel se está destruyendo; la consulta no se completará.
ARES_ENOSERVER
Ninguna consulta se completó con éxito; no se configuraron servidores DNS en el canal.

El argumento de retorno de llamada timeouts informa cuántas veces una consulta excedió el tiempo de espera durante la ejecución de la solicitud dada.

Si una consulta se completó con éxito, el argumento de retorno de llamada abuf apunta a un búfer de resultados de longitud alen. Si la consulta no se completó con éxito, abuf generalmente será NULL y alen generalmente será 0, pero en algunos casos un resultado de consulta no exitoso puede colocarse en abuf.

La función ares_search_dnsrec(3) se comporta idénticamente a ares_search(3), pero toma un objeto de registro DNS inicializado y relleno para usar en las consultas como segundo argumento dnsrec en lugar de un nombre, clase y tipo. Este objeto se utiliza como base para las consultas y debe representar en sí mismo una consulta válida para un solo nombre. Tenga en cuenta que los dominios de búsqueda solo se añadirán al nombre en la sección de preguntas; los RR en el objeto de registro DNS no se verán afectados. Además, el argumento callback es de tipo ares_callback_dnsrec. Esta función de retorno de llamada se comporta de manera idéntica a ares_callback, pero se invoca con un objeto de registro DNS analizado dnsrec en lugar de un búfer sin procesar con longitud. Tenga en cuenta que este objeto es de solo lectura.

La función ares_search_dnsrec(3) devuelve un código de respuesta ares_status_t. Esto puede ser útil para saber que la consulta se encoló correctamente. El código de respuesta no refleja el resultado de la consulta, solo el resultado de la puesta en cola de la consulta.

DISPONIBILIDAD

ares_search_dnsrec(3) se introdujo en c-ares 1.28.0.

VER TAMBIÉN
