arc4random(3) Manual de funciones de biblioteca arc4random(3)

NOMBRE

arc4random, arc4random_uniform, arc4random_buf - generador de números pseudorandom criptográficamente seguro

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
uint32_t arc4random(void);
uint32_t arc4random_uniform(uint32_t upper_bound);
void arc4random_buf(size_t n;
                    void buf[n], size_t n);

DESCRIPCIÓN

Estas funciones proporcionan números pseudorandom criptográficamente seguros.

arc4random() devuelve un valor distribuido uniformemente.

arc4random_uniform() devuelve un valor distribuido uniformemente menor que upper_bound (ver BUGS).

arc4random_buf() rellena la memoria apuntada por buf, con n bytes de datos pseudorandom.

Las familias de funciones rand(3) y drand48(3) solo deben usarse donde la calidad de los números pseudorandom no sea una preocupación y exista la necesidad de reproducibilidad de los resultados. A menos que cumpla ambas condiciones, use las funciones arc4random().

VALOR DE RETORNO

arc4random() devuelve un número pseudorandom.

arc4random_uniform() devuelve un número pseudorandom menor que upper_bound para una entrada válida, o 0 cuando upper_bound es inválido.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, vea attributes(7).

Interfaz Atributo Valor
arc4random (), arc4random_uniform (), arc4random_buf () Seguridad de hilos MT-Safe

ESTÁNDARES

BSD.

HISTORIA

OpenBSD 2.1, FreeBSD 3.0, NetBSD 1.6, DragonFly 1.0, libbsd, glibc 2.36.

BUGS

Un upper_bound de 0 no tiene sentido en una llamada a arc4random_uniform(). Dicha llamada fallará y devolverá 0. Tenga cuidado, ya que ese valor no es menor que upper_bound. En algunos casos, como al acceder a un array, usar ese valor podría resultar en comportamiento indefinido.

VER TAMBIÉN

getrandom(3), rand(3), drand48(3), random(7)
