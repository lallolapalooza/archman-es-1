ARP(8) Manual de Administrador del Sistema de Linux ARP(8)

NOMBRE

arp - manipular la caché ARP del sistema

SINOPSIS

arp [-vn] [-H tipo] [-i if] [-ae] [nombre_host]

arp [-v] [-i if] -d nombre_host [pub]

arp [-v] [-H tipo] [-i if] -s nombre_host dir_hw [temp]

arp [-v] [-H tipo] [-i if] -s nombre_host dir_hw [netmask nm] pub

arp [-v] [-H tipo] [-i if] -Ds nombre_host ifname [netmask nm] pub

arp [-vnD] [-H tipo] [-i if] -f [nombre_archivo]

DESCRIPCIÓN

Arp manipula o muestra la caché de vecinos IPv4 del kernel. Puede añadir entradas a la tabla, eliminar una o mostrar el contenido actual.

ARP significa Protocolo de Resolución de Direcciones, que se utiliza para encontrar la dirección de control de acceso al medio de un vecino de red para una dirección IPv4 dada.

MODOS

arp sin especificador de modo imprimirá el contenido actual de la tabla. Es posible limitar el número de entradas impresas, especificando un tipo de dirección de hardware, nombre de interfaz o dirección de host.

arp -d dirección eliminará una entrada de la tabla ARP. Se requiere privilegio de root o de netadmin para hacerlo. La entrada se busca por dirección IP. Si se proporciona un nombre de host, se resolverá antes de buscar la entrada en la tabla ARP.

arp -s dirección dir_hw se utiliza para configurar una nueva entrada en la tabla. El formato del parámetro dir_hw depende de la clase de hardware, pero para la mayoría de las clases se puede asumir que se puede utilizar la presentación habitual. Para la clase Ethernet, son 6 bytes en hexadecimal, separados por dos puntos. Al añadir entradas ARP proxy (es decir, aquellas con el indicador publish activado) se puede especificar una netmask para hacer proxy ARP para subredes enteras. Esto no es una buena práctica, pero es compatible con kernels más antiguos porque puede ser útil. Si no se proporciona el indicador temp, las entradas se almacenarán permanentemente en la caché ARP. Para simplificar la configuración de entradas para una de sus propias interfaces de red, puede utilizar la forma arp -Ds dirección ifname. En ese caso, la dirección de hardware se toma de la interfaz con el nombre especificado.

OPCIONES

-v, --verbose
Indica al usuario lo que está sucediendo siendo verboso.
-n, --numeric
muestra direcciones numéricas en lugar de intentar determinar nombres simbólicos de host, puerto o usuario.
-H tipo, --hw-type tipo, -t tipo
Al configurar o leer la caché ARP, este parámetro opcional indica a arp qué clase de entradas debe comprobar. El valor predeterminado de este parámetro es ether (es decir, código de hardware 0x01 para Ethernet IEEE 802.3 de 10 Mbps). Otros valores podrían incluir tecnologías de red como ARCnet (arcnet), PROnet (pronet), AX.25 (ax25) y NET/ROM (netrom).
-a
Utiliza el formato de salida alternativo estilo BSD (sin columnas fijas).
-e
Utiliza el formato de salida predeterminado estilo Linux (con columnas fijas).
-D, --use-device
En lugar de una dir_hw, el argumento proporcionado es el nombre de una interfaz. arp usará la dirección MAC de esa interfaz para la entrada de la tabla. Esta suele ser la mejor opción para configurar una entrada ARP proxy para uno mismo.
-i If, --device If
Selecciona una interfaz. Al volcar la caché ARP solo se imprimirán las entradas que coincidan con la interfaz especificada. Al configurar una entrada ARP permanente o temp, esta interfaz se asociará con la entrada; si no se utiliza esta opción, el kernel adivinará basándose en la tabla de enrutamiento. Para las entradas pub, la interfaz especificada es la interfaz en la que se responderán las solicitudes ARP.
NOTA: Esto tiene que ser diferente de la interfaz a la que se enrutarán los datagramas IP. NOTA: A partir del kernel 2.2.0 ya no es posible configurar una entrada ARP para toda una subred. Linux en su lugar realiza ARP proxy automático cuando existe una ruta y está reenviando. Ver arp(7) para más detalles. Tampoco se puede usar la opción dontpub, que está disponible para operaciones de eliminación y configuración, con kernels 2.4 y posteriores.
-f nombre_archivo, --file nombre_archivo
Similar a la opción -s, solo que esta vez la información de la dirección se toma del archivo nombre_archivo. Esto se puede usar si se deben configurar entradas ARP para muchos hosts. El nombre del archivo de datos es muy a menudo /etc/ethers, pero esto no es oficial. Si no se especifica un nombre de archivo, se utiliza /etc/ethers como predeterminado.

El formato del archivo es simple; solo contiene líneas de texto ASCII con un nombre de host y una dirección de hardware separadas por espacios en blanco. Adicionalmente, se pueden usar los indicadores pub, temp y netmask.

En todos los lugares donde se espera un nombre_host, también se puede introducir una dirección IP en notación decimal con puntos.

Como caso especial de compatibilidad, el orden del nombre de host y la dirección de hardware pueden intercambiarse.

Cada entrada completa en la caché ARP estará marcada con el indicador C. Las entradas permanentes están marcadas con M y las entradas publicadas tienen el indicador P.

EJEMPLOS

/usr/sbin/arp -i eth0 -Ds 10.0.0.2 eth1 pub

Esto responderá a las solicitudes ARP para 10.0.0.2 en eth0 con la dirección MAC de eth1.

/usr/sbin/arp -i eth1 -d 10.0.0.1

Elimina la entrada de la tabla ARP para 10.0.0.1 en la interfaz eth1. Esto coincidirá con las entradas ARP proxy publicadas y las entradas permanentes.
