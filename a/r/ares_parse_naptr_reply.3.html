NOMBRE

ares_parse_naptr_reply - Analizar una respuesta a una consulta DNS de tipo NAPTR

SINOPSIS

#include <ares.h>
int ares_parse_naptr_reply(const unsigned char* abuf, int alen,
                           struct ares_naptr_reply** naptr_out);

DESCRIPCIÓN

La función ares_parse_naptr_reply analiza la respuesta a una consulta de tipo NAPTR en una lista enlazada de struct ares_naptr_reply Los parámetros abuf y alen proporcionan el contenido de la respuesta. El resultado se almacena en memoria asignada y un puntero a ella se almacena en la variable apuntada por naptr_out. Es responsabilidad del llamador liberar la estructura naptr_out resultante cuando ya no sea necesaria utilizando la función ares_free_data(3).

La estructura ares_naptr_reply contiene los siguientes campos:


struct ares_naptr_reply {
    struct ares_naptr_reply *next;
    unsigned char *flags;
    unsigned char *service;
    unsigned char *regexp;
    char *replacement;
    unsigned short order;
    unsigned short preference;
};

VALORES DE RETORNO

ares_parse_naptr_reply puede devolver cualquiera de los siguientes valores:

ARES_SUCCESS
La respuesta se analizó correctamente.
ARES_EBADRESP
La respuesta tenía un formato incorrecto.
ARES_ENODATA
La respuesta no contenía una respuesta a la consulta.
ARES_ENOMEM
Se agotó la memoria.

DISPONIBILIDAD

Esta función se introdujo por primera vez en la versión 1.7.6 de c-ares.
