DESCRIPCIÓ

N

Archive::Extract es un mecanismo genérico de extracción de

archivos.

Permite extraer cualquier archivo comprimido de tipo .tar, .tar.gz, .gz, .Z, tar.bz2, .tbz, .bz2, .zip, .xz,, .txz, .tar.xz o .lzma sin tener que preocuparse de cómo lo hace, o usar interfaces diferentes para cada tipo mediante el uso de módulos de perl, o herramientas de línea de comandos en tu

sistema.

Consulta la sección "CÓMO FUNCIONA" má

s abajo para ob
tener detalles.

$ae->extract( [to => '/ruta/de/salida']

)

Extrae el archivo comprimido representado por el objeto "Archive::Extract" en la ruta de tu elección, como se especifica con el argumento "to". Por defecto es cwd(

).

Dado que los archivos ".gz" nunca contienen un directorio, sino un solo archivo; si el argumento "to" es un directorio existente, el archivo se extrae allí, con su sufijo ".gz" eliminado. Si el argumento "to" no es un directorio existente, el argumento "to" se entiende como un nombre de archivo, si el tipo de archivo comprimido es "gz". En el caso de que no hayas especificado un argumento "to", el archivo de salida será el nombre del archivo comprimido, sin su sufijo ".gz", en el directorio de trabajo

actual.

"extract" intentará primero una solución en perl puro, y luego recurrirá a herramientas de línea de comandos si están disponibles. Consulta la sección "VARIABLES GLOBALES" más abajo para saber cómo alterar este

comportamiento.

Devolverá verdadero en caso de éxito y falso en caso de

fallo.

En caso de éxito, también establecerá los siguientes atributos en el

objeto:

FONCTION

UTILITAIRE

type_for($archive

)

Étant donné un nom de fichier d'archive, elle détermine le type en analysant l'extension du nom de fichier. Utilisée par new() lorsque le paramètre "type" n'est pas passé. Également utile lorsque le fichier d'archive n'inclut pas de suffixe mais que le nom de fichier est autrement connu, par exemple lorsqu'un fichier est téléversé sur un serveur web et stocké avec un nom temporaire différent du nom original, et que vous voulez utiliser le même motif de détection que Archive::Extract. Exemple

: 
my $ae = Archive::Extract->new(
    archive => '/tmp/02af6s',
    type    => Archive::Extract::type_for('archive.zip'),
)
;

COMMENT ÇA

MARCHE

"Archive::Extract" essaie d'abord de déterminer quel type d'archive vous lui transmettez, en inspectant son suffixe. Elle ne le fait pas en utilisant Mime magic, ou quelque chose de lié. Voir "AVERTISSEMENTS" ci

-dessous.

Une fois qu'elle a déterminé le type de fichier, elle sait quelles méthodes d'extraction elle peut utiliser sur l'archive. Elle essaiera d'abord une solution en perl, puis retombera sur un outil en ligne de commandes si cela échoue. Si cela échoue également, elle renverra faux, indiquant qu'elle n'a pas pu extraire l'archive. Voir la section sur "VARIABLES GLOBALES" pour voir

comment mod
ifier cet ordre.

AVERTISSEMEN

TS

Extensions de

fichiers

"Archive::Extract" se fie à l'extension de l'archive pour déterminer de quel type il s'agit, et quelles méthodes d'extraction peuvent donc être utilisées. Si vos archives n'ont aucune des extensions décrites dans la méthode new(), vous devrez spécifier le type explicitement, ou "Archive::Extract" ne pourra pas

extraire l'ar
chive pour vous.

Prise en charge de fichiers très

volumineux

"Archive::Extract" peut utiliser soit des modules perl purs, soit des programmes en ligne de commandes en interne. Certains des modules perl purs (comme "Archive::Tar" et Compress::unLZMA) chargent l'intégralité du contenu de l'archive en mémoire, ce qui peut ne pas être faisable sur votre système. Envisagez de définir la variable globale $Archive::Extract::PREFER_BIN à 1, ce qui privilégiera l'utilisation des programmes en ligne de commandes et ne consommera pas autant de

mémoire.

Voir la section "VARIABLES GLOBALES"

ci-dessous pour
plus de détails.

Prise en charge par Bunzip2 d'extensions

arbitraires.

Les anciennes versions de "/bin/bunzip2" ne prennent pas en charge les extensions de fichiers arbitraires et insistent sur un suffixe ".bz2". Bien que nous fassions de notre mieux pour nous prémunir contre cela, si vous rencontrez une erreur bunzip2, elle peut être liée à ceci. Pour plus de détails, veuillez voir la méthode "have_old_bunzip2". méthode "have_old_bunzip
