DESCRIPCIÓN

La función ares_dns_record_rr_cnt(3) devuelve el número de registros de recursos en el registro DNS proporcionado por el parámetro dnsrec para la sección proporcionada en el parámetro sect.

La función ares_dns_record_rr_add(3) agrega una nueva entrada de registro de recursos al registro DNS proporcionado por el parámetro dnsrec. El registro de recursos resultante se almacena en la variable apuntada por rr_out. La sección DNS a la que pertenece el registro de recursos se especifica mediante el parámetro sect. El nombre de dominio asociado con el registro de recursos se especifica mediante el parámetro name, que no puede ser NULL pero puede ser una cadena vacía o ".". El tipo de registro de recursos se especifica en el parámetro type, junto con la clase de registro DNS en el parámetro rclass, y el Tiempo de Vida (TTL) en el parámetro ttl.

Las funciones ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) se utilizan para recuperar el puntero del registro de recursos del registro DNS proporcionado en el parámetro dnsrec, para la sección de registros de recursos proporcionada en el parámetro sect, para el índice especificado en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3). La primera devuelve un puntero modificable al registro de recursos, mientras que la segunda devuelve un puntero de solo lectura al registro de recursos.

La función ares_dns_record_rr_del(3) se utiliza para eliminar un registro de recursos del registro DNS especificado en el parámetro dnsrec. Su uso principal es eliminar un registro ARES_REC_TYPE_OPT cuando se necesita reintentar una consulta sin soporte EDNS. La sección RR del DNS se especifica a través del parámetro sect, y el índice a eliminar se especifica en el parámetro idx. El índice debe ser menor que ares_dns_record_rr_cnt(3).

La función ares_dns_rr_get_name(3) se utiliza para recuperar el nombre de dominio del registro de recursos del puntero de Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_get_type(3) se utiliza para recuperar el tipo de registro de recursos del puntero de Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_get_class(3) se utiliza para recuperar la clase del registro de recursos del puntero de Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_get_ttl(3) se utiliza para recuperar el Tiempo de Vida (TTL) de la clase del registro de recursos del puntero de Registro de Recursos proporcionado en el parámetro rr.

La función ares_dns_rr_set_addr(3) se utiliza para establecer una dirección IPv4 para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_INADDR. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro addr.

La función ares_dns_rr_set_addr6(3) se utiliza para establecer una dirección IPv6 para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_INADDR6. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro addr.

La función ares_dns_rr_set_str(3) se utiliza para establecer una cadena para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. La mayoría de las cadenas están limitadas a 255 bytes, sin embargo, algunos registros, como un registro TXT, pueden permitir un tamaño mayor ya que se presentan como múltiples cadenas. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val.

La función ares_dns_rr_set_u8(3) se utiliza para establecer un valor de 8 bits sin signo para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U8. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val.

La función ares_dns_rr_set_u16(3) se utiliza para establecer un valor de 16 bits sin signo para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U16. La función ares_dns_rr_set_u32(3) se utiliza para establecer un valor de 32 bits sin signo para la clave/parámetro del registro de recursos asociado cuando el tipo de dato es ARES_DATATYPE_U32. El registro de recursos a modificar se proporciona en el parámetro dns_rr, la clave/parámetro se proporciona en el parámetro key, y el valor se proporciona en el parámetro val.

ENUMERACIONES

Las funciones ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_opt(3) y ares_dns_rr_get_opt_byid(3) utilizan claves (keys) para acceder a los datos del registro DNS. Las claves utilizadas para los tipos de datos ARES_DATATYPE_INADDR y ARES_DATATYPE_INADDR6 deben ser "inet" y "inet6" respectivamente.

Las claves utilizadas para los tipos de datos ARES_DATATYPE_STR y ARES_DATATYPE_NAME deben ser "dns".

Las claves utilizadas para los tipos de datos ARES_DATATYPE_U8, ARES_DATATYPE_U16 y ARES_DATATYPE_U32 deben ser "uint8", "uint16" y "uint32" respectivamente.

Las claves utilizadas para los tipos de datos ARES_DATATYPE_BIN y ARES_DATATYPE_BINP deben ser "bin".

Las claves utilizadas para los tipos de datos ARES_DATATYPE_ABINP y ARES_DATATYPE_OPT deben ser "abin" y "opt" respectivamente.

Algunas claves pueden ser específicas del tipo de registro, como por ejemplo, para los registros SVCB y HTTPS.

DESCRIPCIÓN

Estas funciones proporcionan una interfaz para crear, modificar y consultar registros DNS y sus recursos individuales.

La función ares_dns_record_add(3) se utiliza para crear un nuevo registro DNS con los campos especificados y devolver un puntero a la nueva estructura del registro.

Las funciones ares_dns_record_rr_add(3) y ares_dns_record_rr_del(3) se utilizan para añadir o eliminar registros de recursos (RR) de un registro DNS existente. Los campos del registro de recursos que se van a añadir o eliminar se proporcionan en los parámetros correspondientes.

Las funciones ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) se utilizan para recuperar un registro de recursos específico de un registro DNS existente, basándose en sus campos.

Las funciones ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3) y ares_dns_rr_get_ttl(3) se utilizan para recuperar respectivamente el nombre, tipo, clase y tiempo de vida (TTL) de un registro de recursos dado.

Las funciones ares_dns_rr_set_addr(3) y ares_dns_rr_set_addr6(3) se utilizan para establecer direcciones IPv4 e IPv6 respectivamente en un registro de recursos. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para la dirección se proporciona en el parámetro key (debe ser "inet" para IPv4 y "inet6" para IPv6). El valor de la dirección se proporciona en val y su longitud en val_len.

La función ares_dns_rr_set_str(3) se utiliza para establecer una cadena de texto en un registro de recursos. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para la cadena se proporciona en el parámetro key (debe ser "dns"). El valor de la cadena se proporciona en val.

Las funciones ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3) y ares_dns_rr_set_u32(3) se utilizan para establecer enteros sin signo de 8, 16 y 32 bits respectivamente en un registro de recursos. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para el entero se proporciona en el parámetro key (debe ser "uint8", "uint16" o "uint32"). El valor del entero se proporciona en val.

La función ares_dns_rr_set_bin(3) se utiliza para establecer datos binarios en un registro de recursos. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para los datos binarios se proporciona en el parámetro key (debe ser "bin"). El valor de los datos binarios se proporciona en val y su longitud en val_len.

Las funciones ares_dns_rr_add_abin(3) y ares_dns_rr_del_abin(3) se utilizan para añadir y eliminar datos binarios de un registro de recursos que almacena una lista de valores binarios (por ejemplo, registros TXT con múltiples cadenas). El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para los datos binarios se proporciona en el parámetro key (debe ser "abin"). Para ares_dns_rr_add_abin, el valor y su longitud se proporcionan en val y val_len. Para ares_dns_rr_del_abin, el índice del valor a eliminar se proporciona en el parámetro idx.

La función ares_dns_rr_set_opt(3) se utiliza para establecer opciones/parámetros para un registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para la opción se proporciona en el parámetro key (debe ser "opt"). La opción específica se proporciona en el parámetro opt. El valor de la opción se proporciona en binario en val con la longitud proporcionada en val_len.

La función ares_dns_rr_del_opt(3) se utiliza para eliminar opciones/parámetros de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para la opción se proporciona en el parámetro key (debe ser "opt"). La opción específica se proporciona en el parámetro opt. El índice de la opción a eliminar se proporciona en el parámetro idx.

La función ares_dns_rr_del_opt_byid(3) se utiliza para eliminar opciones/parámetros de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT basándose en el identificador de la opción. El registro de recursos a modificar se proporciona en el parámetro dns_rr. La clave para la opción se proporciona en el parámetro key (debe ser "opt"). El identificador de la opción se proporciona en el parámetro opt. La función devuelve ARES_SUCCESS si el registro se elimina correctamente, o ARES_ENOTFOUND si el registro no se encuentra.

La función ares_dns_rr_get_addr(3) se utiliza para recuperar la dirección IPv4 de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_INADDR. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_addr6(3) se utiliza para recuperar la dirección IPv6 de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_INADDR6. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_str(3) se utiliza para recuperar una cadena de texto de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_STR o ARES_DATATYPE_NAME. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u8(3) se utiliza para recuperar un entero de 8 bits de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_U8. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u16(3) se utiliza para recuperar un entero de 16 bits de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_U16. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_u32(3) se utiliza para recuperar un entero de 32 bits de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_U32. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_bin(3) se utiliza para recuperar datos binarios de un registro de recursos cuando el tipo de dato es ARES_DATATYPE_BIN o ARES_DATATYPE_BINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y la longitud se almacena en la variable apuntada por len.

La función ares_dns_rr_get_abin_cnt(3) se utiliza para recuperar el recuento de la lista de valores binarios almacenados en el registro de recursos cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key.

La función ares_dns_rr_get_abin(3) se utiliza para recuperar datos binarios de la lista de registros de recursos cuando el tipo de dato es ARES_DATATYPE_ABINP. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, y el índice a recuperar de la lista se proporciona mediante el parámetro idx, y la longitud se almacena en la variable apuntada por len.

La función ares_dns_rr_get_opt_cnt(3) se utiliza para recuperar el recuento de opciones/parámetros asociados con el registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en la key.

La función ares_dns_rr_get_opt(3) se utiliza para recuperar datos binarios de opciones del registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT para el índice especificado. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, el índice para recuperar los datos de la opción se proporciona en el parámetro idx. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len.

La función ares_dns_rr_get_opt_byid(3) se utiliza para recuperar datos binarios de opciones del registro de recursos cuando el tipo de dato es ARES_DATATYPE_OPT para el identificador de opción especificado, si existe. El registro de recursos se proporciona en el parámetro dns_rr y la clave/parámetro a recuperar se proporciona en el parámetro key, el identificador para recuperar los datos de la opción se proporciona en el parámetro opt. El valor se almacena en la variable apuntada por val y la longitud se almacena en la variable apuntada por val_len.

VALORES DE RETORNO

ares_dns_record_rr_cnt(3) y ares_dns_rr_get_opt_cnt(3) devuelven los recuentos respectivos.

ares_dns_record_rr_add(3), ares_dns_record_rr_del(3), ares_dns_rr_set_addr(3), ares_dns_rr_set_addr6(3), ares_dns_rr_set_str(3), ares_dns_rr_set_u8(3), ares_dns_rr_set_u16(3), ares_dns_rr_set_u32(3), ares_dns_rr_set_bin(3), ares_dns_rr_add_abin(3), ares_dns_rr_del_abin(3), y ares_dns_rr_set_opt(3) devuelven un código de error ares_status_t. Se devuelve ARES_SUCCESS en caso de éxito, ARES_ENOMEM en caso de falta de memoria, ARES_EFORMERR en caso de mal uso.

ares_dns_rr_get_name(3), ares_dns_rr_get_type(3), ares_dns_rr_get_class(3), ares_dns_rr_get_ttl(3), ares_dns_rr_get_addr(3), ares_dns_rr_get_addr6(3), ares_dns_rr_get_str(3), ares_dns_rr_get_u8(3), ares_dns_rr_get_u16(3), ares_dns_rr_get_u32(3), ares_dns_rr_get_bin(3), ares_dns_rr_get_abin_cnt(3), ares_dns_rr_get_abin(3), ares_dns_rr_get_opt(3) devuelven sus respectivos valores de tipo de dato y, en general, no pueden fallar excepto en casos de mal uso, en los que se puede devolver un 0 (o NULL), sin embargo, 0 también puede ser un valor de retorno válido para la mayoría de estas funciones.

ares_dns_record_rr_get(3) y ares_dns_record_rr_get_const(3) devolverán el puntero al registro de recursos solicitado o NULL en caso de fallo (mal uso).

ares_dns_rr_get_opt_byid(3) devolverá ARES_TRUE si la opción se encontró, de lo contrario ARES_FALSE si no se encontró (o por mal uso).
