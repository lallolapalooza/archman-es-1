DESCRIPCIÓN

Estas funciones establecen el formato que se utilizará para el archivo.

La biblioteca puede escribir una variedad de formatos de archivo comunes.

archive_write_set_format()
Establece el formato basándose en el código de formato (ver archive.h para la lista completa de códigos de formato). En particular, esto se puede usar junto con archive_format() para crear un nuevo archivo con el mismo formato que un archivo existente.
archive_write_set_format_by_name()
Establece el formato correspondiente basándose en el nombre común.
archive_write_set_format_filter_by_ext() archive_write_set_format_filter_by_ext_def()
Establece tanto los filtros como el formato basándose en el nombre del archivo de salida. Extensiones admitidas: .7z, .zip, .jar, .cpio, .iso, .a, .ar, .tar, .tgz, .tar.gz, .tar.bz2, .tar.xz
