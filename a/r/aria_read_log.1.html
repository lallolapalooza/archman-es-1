NOMBRE

aria_read_log - muestra el contenido del archivo de registro de Aria

SINOPSIS

aria_read_log OPCIONES

DESCRIPCIÓN

Muestra y aplica registros de transacciones de Aria desde un archivo de registro ubicado en el directorio actual (por ahora).

Nota: Aria está compilado sin -DIDENTICAL_PAGES_AFTER_RECOVERY, lo que significa que los archivos de tabla no son byte a byte idénticos a los archivos creados durante la ejecución normal. Esto debería estar bien, excepto para los scripts de prueba que intentan comparar archivos antes y después de la recuperación.

Necesitas usar una de las opciones -d o -a.

-a, --apply
Aplica el registro a las tablas: ¡modifica las tablas! ¡deberías hacer una copia de seguridad primero! Muestra mucha información si no se ejecuta con --silent.
--character-sets-dir=nombre
Directorio donde se encuentran los conjuntos de caracteres.
-c, --check
si --display-only, verifica si el registro es completamente legible (para depuración).
-#, --debug[=nombre]
Muestra el registro de depuración. A menudo el argumento es 'd:t:o,nombre_archivo'.
--force-crash=#
Fuerza un fallo después de # eventos de recuperación.
-?, --help
Muestra esta ayuda y sale.
-d, --display-only
Muestra información breve leída de las cabeceras de los registros.
-e, --end-lsn=#
Deja de aplicar en este lsn. Si se usa end-lsn, los UNDO no se aplicarán.
-h, --aria-log-dir-path=nombre
Ruta al directorio donde se almacenará el registro transaccional.
-P, --page-buffer-size=#
El tamaño del búfer utilizado para los bloques de índice de las tablas Aria.
-o, --start-from-lsn=#
Comienza a leer el registro desde este lsn.
-C, --start-from-checkpoint
Comienza a aplicar desde el último punto de control.
-s, --silent
Imprime menos información durante la fase de aplicación/deshacer.
-T, --tables-to-redo=nombre
Lista de tablas separadas por comas sobre las que se debe aplicar REDO. Úsala si solo deseas recuperar algunas tablas.
-t, --tmpdir=nombre
Ruta para los archivos temporales. Se pueden especificar varias rutas, separadas por dos puntos (:).
--translog-buffer-size=#
El tamaño del búfer utilizado para el registro de transacciones de las tablas Aria.
-u, --undo
Aplica registros UNDO a las tablas. (desactivado con --disable-undo) (Activado por defecto; usa --skip-undo para desactivar).
-v, --verbose
Imprime más información durante la fase de aplicación/deshacer.
-V, --version
Imprime la versión y sale.

Las opciones por defecto se leen de los siguientes archivos en el orden dado: /etc/my.cnf /etc/mysql/my.cnf ~/.my.cnf.

Se lee el siguiente grupo: aria_read_log.

Las siguientes opciones se pueden dar como el primer argumento:

--print-defaults
Imprime la lista de argumentos del programa y sale.
--no-defaults
No lee opciones por defecto de ningún archivo de opciones.
--defaults-file=#
Solo lee opciones por defecto del archivo dado #.
--defaults-extra-file=#
Lee este archivo después de que se lean los archivos globales.
