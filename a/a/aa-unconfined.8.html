AA-UNCONFINED(8) AppArmor AA-UNCONFINED(8)

NOMBRE

aa-unconfined - muestra una lista de procesos con puertos tcp o udp que no tienen perfiles AppArmor cargados

SINOPSIS

aa-unconfined [opciones] [--with-ss | --with-netstat]

OPCIONES

--paranoid
Muestra todos los procesos visibles desde el sistema de archivos /proc, y si están o no confinados por un perfil o "no confinados". Equivalente a --show=all.
--show=(all|network|server|client)
Determina el conjunto de procesos a mostrar.

--show=all muestra todos los procesos, equivalente a --paranoid

--show=network muestra solo procesos con algún socket abierto.

--show=server muestra solo procesos con sockets de escucha abiertos. Este es el valor predeterminado si no se especifican --show= o --paranoid.

--show=client muestra solo procesos con sockets que no son de escucha abiertos.

--with-ss
Utiliza el comando ss(8) para encontrar procesos que escuchan en sockets de red (predeterminado).
--with-netstat
Utiliza el comando netstat(8) para encontrar procesos que escuchan en sockets de red. Este es también el recurso al que recurrirá aa-unconfined cuando ss(8) no esté disponible.

DESCRIPCIÓN

aa-unconfined utilizará netstat(8) para determinar qué procesos tienen sockets de red abiertos y no tienen perfiles AppArmor cargados en el kernel.

ERRORES

aa-unconfined debe ejecutarse como root para recuperar el ejecutable del proceso del sistema de archivos /proc. Este programa es susceptible a condiciones de carrera de varios tipos: un ejecutable sin enlazar se manejará incorrectamente; un ejecutable iniciado antes de que se cargue un perfil AppArmor no aparecerá en la salida, a pesar de ejecutarse sin confinamiento; un proceso que muere entre la ejecución de netstat(8) y las comprobaciones posteriores se manejará incorrectamente. Este programa solo lista procesos que usan TCP y UDP. En resumen, este programa no es adecuado para uso forense y se proporciona solo como ayuda para perfilar todos los procesos accesibles por red en el laboratorio.

Si encuentra algún error, repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN

ss(8), netstat(8), apparmor(7), apparmor.d(5), aa_change_hat(2), y https://wiki.apparmor.net.
