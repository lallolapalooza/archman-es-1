DESCRIPCIÓ

N

aa-exec se utiliza para lanzar un programa confinado por el perfil y/o espacio de nombres especificado. Si se especifican tanto un perfil como un espacio de nombres, el comando será confinado por el perfil en el nuevo espacio de nombres de políticas. Si solo se especifica un espacio de nombres, se utilizará el nombre del perfil del confinamiento actual. Si no se especifica ni un perfil ni un espacio de nombres, el comando se ejecutará utilizando la adjuntación de perfil estándar (es decir, como si se ejecutara sin el comando aa-exec)

.

Si los argumentos deben pasarse al <comando> invocado por aa-exec, se debe utilizar -- para separar los argumentos de aa-exec del comando.
aa-exec -

p profile1
-- ls -l

argumentos:
-p PERFIL,
--profile=PERFIL
confina <comando> con PERFIL. Si no se especifica el PERFIL, se utiliza el nombre del perfil actual (probablemente unconfined)
.

perfiles.
-i,
--immediate
transiciona a PERFIL antes de ejecutar <comando>. Esto somete la ejecución de <comando> a las reglas de transición de ejecución del perfil

RESTRICCIONE

S

aa-exec usa aa_change_profile(3) para cambiar el confinamiento de la aplicación. El uso de aa_change_profile(3) puede estar restringido por las políticas de formas que causarán fallos o resultados diferentes a los

esperados.

Incluso cuando se usa aa-exec desde unconfined, las restricciones en las políticas pueden causar fallos o que el confinamiento al que se accede sea diferente al

solicitado

Consulte la documentación de la restricción de unconfined no privilegiado para más detalles. https://gitlab.com/apparmor/apparmor/-/wikis/unprivileged_unconfined_restricti

APILAD

O

aa-exec se puede utilizar para configurar una pila de perfiles como confinamiento. Cuando una aplicación está confinada por una pila, todos los perfiles de la pila se comprueban como si fueran el perfil que confina la aplicación. La mediación resultante es la intersección de lo que permite cada perfil de la

pila.

Los perfiles en una pila se tratan de forma independiente. Cada perfil puede tener sus propias banderas y transiciones de perfil. Durante una ejecución, cada perfil especifica su transición y los resultados se combinan para formar una nueva pila

canonizada.

El separador de perfiles que indica una pila es la secuencia de caracteres //&. Así, una pila puede expresarse

usando 
$ aa-exec -p "unconfined//&firefox" -- bash
$ ps -Z
LABEL                               PID TTY
TIME CMD unconfined 30714 pts/12 00:00:00 bash firefox//&unconfined (u
nconfined) 31160 pts/12 00:00:00 bash firefox//&unconfined (unconfined) 31171 pts/12 00:00:00 ps

ESPACIOS DE

NOMBRES

aa-exec se puede utilizar para entrar en un confinamiento en otro espacio de nombres de políticas si el espacio de nombres de políticas existe, es visible y el perfil existe en el espacio de nombres. Tenga en cuenta que las aplicaciones lanzadas dentro del espacio de nombres no podrán salir del espacio de nombres y pueden estar restringidas por un confinamiento adicional alrededor del espacio de nombres. Los archivos y recursos visibles para el padre que lanza la aplicación pueden no ser visibles en el espacio de nombres de políticas, lo que resulta en denegaciones de

acceso.

Para entrar en un espacio de nombres de políticas, el perfil se antepone con el nombre del espacio de nombres, usando un : como prefijo y

sufijo.

Por

ejemplo. 
$ aa-exec -p :ex1:unconfined -- bash
$ ps -Z
LABEL                               PID TTY          TIME CMD
-                                 30714 pts/12   00:00:00 bash
unconfined                        34372 pts/12   00:00:00 bash
unconfined                        34379 pts/12   00:00:00
ps

El confinamiento de los procesos fuera del espacio de nombres puede no ser visible, en cuyo caso el confinamiento se representará con un -. Si las políticas están apiladas, solo puede ser visible parte del confinamiento. Sin embargo, el confinamiento suele ser completamente visible desde el espacio de nombres de políticas

principal.

Por ejemplo, el confinamiento del hijo se puede consultar en el padre para

ver 
$ ps -Z 34372
LABEL                               PID TTY      STAT   TIME COMMAND
:ex1:unconfined                   34372 pts/12   S+     0:00
bash

Y en el caso de apilado con espacios de

nombres 
$ aa-exec -p "unconfined//&:ex1:unconfined" -- bash
$ ps -Z
LABEL                               PID TTY          TIME CMD
-                                 30714 pts/12   00:00:00 bash
unconfined                        36298 pts/12   00:00:00 bash
unconfined                        36305 pts/12   00:00:00
ps

mientras que desde el espacio de nombres principal se puede ver el confinamiento

completo 
$ ps -Z 36298
LABEL
PID TTY STAT TIME COMMAND unconfined//&:ex
1:unconfined 36298 pts/12 S+ 0:00 bash
