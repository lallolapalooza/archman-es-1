NOMBRE

aa_render - convierte un búfer de imagen a arte ASCII.

SINOPSIS

#include <aalib.h>

void aa_render
(
aa_context *c,
const aa_renderparams *p,
int x1,
int y1,
int x2,
int y2
);

PARÁMETROS

aa_context *c
Especifica el contexto de AA-lib sobre el que operar.
const aa_renderparams *p
Parámetros de renderizado utilizados para especificar el brillo, la corrección gamma y otras cosas útiles. Utilice aa_defrenderparams para los valores predeterminados.
int x1
Columna de la esquina superior izquierda del área renderizada (¡en caracteres!).
int y1
Fila de la esquina superior izquierda del área renderizada.
int x2
Columna de la esquina inferior derecha del área renderizada.
int y2
Fila de la esquina inferior derecha del área renderizada.

DESCRIPCIÓN

Esta función realiza la tarea de convertir el framebuffer emulado en arte ASCII de alta calidad. Si desea ser muy rápido, puede usar aa_fastrender. Si desea emular una paleta, use aa_renderpalette.

Tenga en cuenta que para ver el efecto, también debe llamar a aa_flush.

La primera llamada a esta función puede tardar un tiempo, ya que se producen las tablas de renderizado.
