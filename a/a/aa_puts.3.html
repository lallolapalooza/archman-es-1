aa_puts(3) Manual de Funciones de Biblioteca aa_puts(3)

NOMBRE

aa_puts - imprime una cadena en los búferes de salida de AA-lib.

SINOPSIS

#include <aalib.h>

void aa_puts
(
aa_context *c,
int x,
int y,
enum aa_attribute attr,
const char *s
);

PARÁMETROS

aa_context *c
Especifica el contexto de AA-lib sobre el que operar.
int x
Coordenada X del primer carácter.
int y
Coordenada Y del primer carácter.
enum aa_attribute attr
Atributo a usar.

Los valores posibles para un enum aa_attribute son los siguientes:

AA_NORMAL
Caracteres normales.
AA_DIM
Caracteres oscuros.
AA_BOLD
Caracteres brillantes.
AA_BOLDFONT
Caracteres renderizados en fuente negrita.
AA_REVERSE
Caracteres invertidos (blanco sobre negro).
AA_SPECIAL
Renderiza los caracteres de una manera fácilmente visible en la pantalla. La renderización exacta depende del controlador, pero este modo debe usarse para imprimir textos que quieras que sean fácilmente visibles en la imagen.
const char *s
Cadena a imprimir.

DESCRIPCIÓN

Imprime la cadena dada en los búferes de salida de AA-lib. Para ver el efecto, también necesitas llamar a aa_flush.
