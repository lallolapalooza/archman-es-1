NOMBRE

aa-autodep - adivina los requisitos básicos del perfil de AppArmor

SINOPSIS

aa-autodep <ejecutable> [<ejecutable> ...] [-d /ruta/a/perfiles] [-f]

OPCIONES

-d --dir /ruta/a/perfiles

Especifica dónde buscar el conjunto de perfiles de seguridad de AppArmor.
Por defecto es /etc/apparmor.d.

-f --force

Sobrescribe cualquier perfil de AppArmor existente para el ejecutable con el perfil mínimo de AppArmor generado.

DESCRIPCIÓN

aa-autodep se utiliza para generar un perfil mínimo de AppArmor para un conjunto de ejecutables. Este programa generará un perfil para un ejecutable binario así como para scripts interpretados. Como mínimo, aa-autodep proporcionará un perfil base que contiene una directiva de inclusión base que incluye entradas de perfil básicas necesarias por la mayoría de los programas.

La opción --force sobrescribirá cualquier perfil existente para el ejecutable con el perfil mínimo de AppArmor recién generado.

ERRORES

Este programa no realiza un análisis estático completo de los ejecutables, por lo que los perfiles generados son necesariamente incompletos. Si encuentra algún error, por favor repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN

apparmor(7), apparmor.d(5), aa-complain(1), aa-enforce(1), aa-disable(1), aa_change_hat(2), y https://wiki.apparmor.net.
