AA-DISABLE(8) AppArmor AA-DISABLE(8)

NOMBRE

aa-disable - desactiva un perfil de seguridad de AppArmor

SINOPSIS

aa-disable <ejecutable> [<ejecutable> ...] [-d /ruta/a/perfiles] [--no-reload] [-r]

OPCIONES

-d --dir /ruta/a/perfiles

Especifica dónde buscar el conjunto de perfiles de seguridad de AppArmor.
Por defecto es /etc/apparmor.d.

--no-reload
No recargar el perfil después de modificarlo.

DESCRIPCIÓN

aa-disable se utiliza para *desactivar* uno o más perfiles. Este comando descargará el perfil del kernel y evitará que el perfil se cargue al inicio de AppArmor. Las utilidades aa-enforce y aa-complain pueden ser utilizadas para cambiar este comportamiento.

ERRORES

Si encuentra algún error, por favor repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN

apparmor(7), apparmor.d(5), aa-enforce(1), aa-complain(1), aa_change_hat(2), y https://wiki.apparmor.net.
