DESCRIPCIÓ

N

GNU nm lista los símbolos de los archivos de objetos objfile.... Si no se listan archivos de objetos como argumentos, nm asume el archivo a.ou

t.

Para cada símbolo, nm mues

tra:
  • El valor del símbolo, en la base numérica seleccionada por las opciones (ver abajo), o hexadecimal por
    • defecto.
  • El tipo de símbolo. Se utilizan al menos los siguientes tipos; otros también se usan, dependiendo del formato del archivo de objeto. Si es minúscula, el símbolo es generalmente local; si es mayúscula, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúscula que se muestran para símbolos globales especiales ("u", "v" y "w
    • ")

posterior.

"b

El símbolo está en la sección de datos BSS. Esta sección típicamente contiene datos inicializados a cero o sin inicializar, aunque el comportamiento exacto depende del

"c

El símbolo es común. Los símbolos comunes son datos sin inicializar. Al enlazar, pueden aparecer múltiples símbolos comunes con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias sin definir. El carácter c en minúscula se usa cuando el símbolo está en una sección especial para comunes
pequeños.

El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivo de objetos permiten un acceso más eficiente a objetos de datos pequeños, como una variable int global en lugar de un gran arreglo
global.
"i
"
Para archivos en formato PE esto indica que el símbolo está en una sección específica de la implementación de DLLs.

Para archivos en formato ELF esto indica que el símbolo es una función indirecta. Esta es una extensión GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que, si es referenciado por una reubicación, no se evalúa a su dirección, sino que debe ser invocado en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá entonces el valor a usar en la

reubicación.

Nota: la visualización real de los símbolos para los símbolos indirectos de GNU es controlada por la opción de línea de comandos --ifunc-chars. Si esta opción ha sido proporcionada, el primer carácter de la cadena será usado para los símbolos de fu

nción indirecta global. Si la cadena contiene un segundo ca

"V

"v

El símbolo es un objeto débil. Cuando un símbolo débil definido se enlaza con un símbolo definido normal, se usa el símbolo definido normal sin error. Cuando un símbolo débil sin definir se enlaza y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin error. En algunos sistemas, mayúscula indica que se ha especificado un valor por

"w

El símbolo es un símbolo débil que no ha sido etiquetado específicamente como un símbolo de objeto débil. Cuando un símbolo débil definido se enlaza con un símbolo definido normal, se usa el símbolo definido normal sin error. Cuando un símbolo débil sin definir se enlaza y el símbolo no está definido, el valor del símbolo se determina de una manera específica del sistema sin error. En algunos sistemas, mayúscula indica que se ha especificado un valor por
defecto.

depuración.

Decodificar (demangle) los nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial añadido por el sistema, esto hace legibles los nombres de funciones de C++. Diferentes compiladores tienen diferentes estilos de mangling. --no-recursion-li
mit
Habilita o deshabilita un límite en la cantidad de recursión realizada al desmangling de cadenas. Dado que los formatos de mangled de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agotará la cantidad de espacio de pila disponible en la máquina anfitriona, provocando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para desm

angling de nombres verdaderamente complicados. Sin embargo, ten en cuenta que si el límite de recursión está
deshabilitado, es posible que se agote la pila y cualquier informe de error sobre tal evento será rechazado.

Carga el plugin llamado name para agregar soporte para tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se ha compilado con soporte de plugins habilitado.

Si --plugin no se proporciona, pero el soporte de plugins ha sido habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se usa el primer plugin que reclama el objeto en

Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang se llama LLVMgold.so. --size-so
rt
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen del ELF, para otros tipos de objetos, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor más alto. Si se usa el formato de salida "bsd" se imprime el tamaño del símbolo, en lugar del valor, y -S debe usarse para que tanto el tamaño como el valor se impriman.

Nota: esta opción no funciona si --undefined-only ha sido habilitado, ya

que los símbolos indef

Por ejemplo, para destinos ARM, esta opción omitiría los símbolos de mapeo usados para marcar transiciones entre código ARM, código THUMB y

--unicode=[default|invalid|locale|escape|hex|highlig

Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no soportarlas. Las opciones --unicode=hex y --unicode=invalid las muestran como secuencias de bytes hex encerradas entre corchetes angulares o llaves.

La opción --unicode=escape las muestra como secuencias de escape (\uxxxx) y la --unicode=highlight las muestra como secuencias de escape resaltadas en rojo (si es soportado por el dispositivo de sal

ida). El coloreado está destinado a atraer la atención sobre la
