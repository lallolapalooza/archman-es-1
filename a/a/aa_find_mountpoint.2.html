aa_find_mountpoint(2)

Paquete: apparmor

AA_FIND_MOUNTPOINT(2) AppArmor AA_FIND_MOUNTPOINT(2)

NOMBRE

aa_is_enabled - determinar si apparmor está habilitado

aa_find_mountpoint - encontrar dónde está montado el sistema de archivos de la interfaz de apparmor

SINOPSIS

#include <sys/apparmor.h>

int aa_is_enabled(void);

int aa_find_mountpoint(char **mnt);

Enlazar con -lapparmor al compilar.

DESCRIPCIÓN

La función aa_is_enabled devuelve verdadero (1) si apparmor está habilitado. Si no lo está, establece la variable errno(3) para reflejar la razón por la cual no está habilitado y devuelve 0.

La función aa_find_mountpoint encuentra dónde está montado el sistema de archivos de apparmor en el sistema y devuelve una cadena que contiene la ruta de montaje. Es responsabilidad del llamante liberar la ruta devuelta con free(3).

VALOR DE RETORNO

aa_is_enabled En caso de éxito, se devuelve 1. En caso de error, se devuelve 0 y se establece errno(3) apropiadamente.

aa_find_mountpoint En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno(3) apropiadamente.

ERRORES

aa_is_enabled

ENOSYS
Las extensiones de AppArmor para el sistema no están disponibles.
ECANCELED
AppArmor está disponible en el sistema pero ha sido deshabilitado al arrancar.
EBUSY
AppArmor está disponible pero solo a través de interfaces privadas.
ENOENT
AppArmor está disponible (e incluso puede estar aplicando políticas) pero la interfaz no está disponible.
ENOMEM
No había suficiente memoria disponible.
EPERM
No se tenían permisos suficientes para determinar si AppArmor está habilitado.
EACCES
No se tenían permisos suficientes para determinar si AppArmor está habilitado.
EBUSY
AppArmor está habilitado pero no tiene acceso a interfaces compartidas, y solo están disponibles interfaces privadas.

aa_find_mountpoint

ENOMEM
No había suficiente memoria disponible.
EACCES
Se denegó el acceso a las rutas requeridas.
ENOENT
No se pudo encontrar el montaje del sistema de archivos de apparmor.

ERRORES CONOCIDOS

Ninguno conocido. Si encuentra alguno, por favor repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

apparmor(7), apparmor.d(5), apparmor_parser(8), y https://wiki.apparmor.net.
