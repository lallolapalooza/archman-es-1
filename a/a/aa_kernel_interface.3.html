aa_kernel_interface(3)

Paquete: apparmor

Licencias: GPL-2.0-only, LGPL-2.0-only, LGPL-2.1-only

aa_kernel_interface(3) AppArmor aa_kernel_interface(3)

NOMBRE

aa_kernel_interface - un objeto opaco que representa la interfaz del kernel de AppArmor para la carga, reemplazo y eliminación de políticas

aa_kernel_interface_new - crea un nuevo objeto aa_kernel_interface a partir de una ruta opcional

aa_kernel_interface_ref - incrementa el contador de referencias de un objeto aa_kernel_interface

aa_kernel_interface_unref - decrementa el contador de referencias y libera el objeto aa_kernel_interface cuando llega a 0

aa_kernel_interface_load_policy - carga una política desde un buffer al kernel

aa_kernel_interface_load_policy_from_file - carga una política desde un archivo al kernel

aa_kernel_interface_load_policy_from_fd - carga una política desde un descriptor de archivo al kernel

aa_kernel_interface_replace_policy - reemplaza una política en el kernel con una política desde un buffer

aa_kernel_interface_replace_policy_from_file - reemplaza una política en el kernel con una política desde un archivo

aa_kernel_interface_replace_policy_from_fd - reemplaza una política en el kernel con una política desde un descriptor de archivo

aa_kernel_interface_remove_policy - elimina una política del kernel

aa_kernel_interface_write_policy - escribe una política en un descriptor de archivo

SINOPSIS

#include <sys/apparmor.h>

typedef struct aa_kernel_interface aa_kernel_interface;

int aa_kernel_interface_new(aa_kernel_interface **kernel_interface, aa_features *kernel_features, const char *apparmorfs);

aa_kernel_interface *aa_kernel_interface_ref(aa_kernel_interface *kernel_interface);

void aa_kernel_interface_unref(aa_kernel_interface *kernel_interface);

int aa_kernel_interface_load_policy(aa_kernel_interface *kernel_interface, const char *buffer, size_t size);

int aa_kernel_interface_load_policy_from_file(aa_kernel_interface *kernel_interface, int dirfd, const char *path);

int aa_kernel_interface_load_policy_from_fd(aa_kernel_interface *kernel_interface, int fd);

int aa_kernel_interface_replace_policy(aa_kernel_interface *kernel_interface, const char *buffer, size_t size);

int aa_kernel_interface_replace_policy_from_file(aa_kernel_interface *kernel_interface, int dirfd, const char *path);

int aa_kernel_interface_replace_policy_from_fd(aa_kernel_interface *kernel_interface, int fd);

int aa_kernel_interface_remove_policy(aa_kernel_interface *kernel_interface, const char *fqname);

int aa_kernel_interface_write_policy(int fd, const char *buffer, size_t size);

Enlace con -lapparmor al compilar.

DESCRIPCIÓN

El objeto aa_kernel_interface contiene información sobre la interfaz del kernel de AppArmor para la carga, reemplazo y eliminación de políticas.

La función aa_kernel_interface_new() crea un objeto aa_kernel_interface basándose en un objeto aa_features opcional y una ruta opcional al directorio de apparmor de securityfs, que normalmente se encuentra en "/sys/kernel/security/apparmor/". Si kernel_features es NULL, se utilizan las características del kernel actual. Al especificar un objeto kernel_features válido, debe ser compatible con las características del kernel en ejecución actual. Si apparmorfs es NULL, se utiliza la ubicación predeterminada. El objeto kernel_interface asignado debe liberarse usando aa_kernel_interface_unref().

aa_kernel_interface_ref() incrementa el contador de referencias del objeto kernel_interface.

aa_kernel_interface_unref() decrementa el contador de referencias del objeto kernel_interface y libera todos los recursos correspondientes cuando el contador de referencias llega a cero.

Las funciones de la familia aa_kernel_interface_load() cargan una política en el kernel. La operación fallará si ya hay cargada una política con el mismo nombre. Utilice las funciones de la familia aa_kernel_interface_replace() si desea reemplazar una política cargada previamente con una nueva política del mismo nombre. Las funciones aa_kernel_interface_replace() también se pueden usar para cargar una política que no corresponde a una política cargada previamente.

Al cargar o reemplazar desde un buffer, el buffer contendrá datos binarios. El argumento size debe especificar el tamaño del argumento buffer.

Al cargar o reemplazar desde un archivo, la combinación dirfd y path se utiliza para especificar la ubicación del archivo. Consulte la página del manual de openat(2) para ver ejemplos de dirfd y path.

También es posible cargar o reemplazar desde un descriptor de archivo especificado por el argumento fd. El archivo debe estar abierto para lectura y la posición del archivo debe configurarse adecuadamente.

La función aa_kernel_interface_remove_policy() se puede utilizar para descargar una política cargada previamente. El nombre completo de la política debe especificarse con el argumento fqname. La operación fallará si no se encuentra una política que coincida con fqname.

La función aa_kernel_interface_write_policy() permite escribir una política, que se almacena en buffer y consta de size bytes, en un descriptor de archivo. El fd debe estar abierto para escritura y la posición del archivo debe configurarse adecuadamente.

VALOR DE RETORNO

La función aa_kernel_interface_new() devuelve 0 en caso de éxito y *kernel_interface apuntará a un objeto aa_kernel_interface que debe ser liberado por aa_kernel_interface_unref(). Se devuelve -1 en caso de error, con errno establecido apropiadamente, y *kernel_interface se establecerá a NULL.

aa_kernel_interface_ref() devuelve el valor de kernel_interface.

Las funciones de la familia aa_kernel_interface_load(), las funciones de la familia aa_kernel_interface_replace(), aa_kernel_interface_remove() y aa_kernel_interface_write_policy() devuelven 0 en caso de éxito. Se devuelve -1 en caso de error, con errno establecido apropiadamente.

ERRORES

El valor de errno se establecerá según el error subyacente en la familia de funciones aa_kernel_interface que devuelven -1 en caso de error.

NOTAS

Todas las funciones aa_kernel_interface descritas anteriormente están presentes en libapparmor versión 2.10 y posteriores.

aa_kernel_interface_unref() guarda el valor de errno al ser llamada y restaura errno antes de salir en libapparmor versión 2.12 y posteriores.

ERRORES CONOCIDOS

Ninguno conocido. Si encuentra alguno, por favor repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN

aa_features(3), openat(2) y https://wiki.apparmor.net.
