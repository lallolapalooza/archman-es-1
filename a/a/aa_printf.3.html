aa_printf(3)

Paquete: aalib

Licencias: LGPL-2.0-or-later

aa_printf(3) Manual de Funciones de Biblioteca aa_printf(3)

NOMBRE

aa_printf - imprime texto en los búferes de salida de AA-lib.

SINOPSIS

#include <aalib.h>

int aa_printf
(
aa_context *c,
int x,
int y,
enum aa_attribute attr,
const char *fmt,
...
);

PARÁMETROS

aa_context *c
Especifica el contexto de AA-lib sobre el que operar.
int x
Coordenada X del primer carácter.
int y
Coordenada Y del primer carácter.
enum aa_attribute attr
Atributo a utilizar.

Los valores posibles para un enum aa_attribute son los siguientes:

AA_NORMAL
Caracteres normales.
AA_DIM
Caracteres oscuros.
AA_BOLD
Caracteres brillantes.
AA_BOLDFONT
Caracteres renderizados en fuente negrita.
AA_REVERSE
Caracteres invertidos (blanco sobre negro).
AA_SPECIAL
Renderiza los caracteres de una manera fácilmente visible en la pantalla. La renderización exacta depende del controlador, pero este modo debe utilizarse para la salida de textos que se quieran hacer fácilmente visibles en la imagen.
const char *fmt
Texto a imprimir en formato printf estándar.
...
No documentado.

DESCRIPCIÓN

Imprime el texto dado en los búferes de salida de AA-lib. Para ver el efecto, también es necesario llamar a aa_flush.
