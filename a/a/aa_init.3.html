aa_init(3) Manual de funciones de biblioteca aa_init(3)

NOMBRE

aa_init - abre la pantalla de salida para AA-lib.

SINOPSIS

#include <aalib.h>

aa_context *aa_init

(

const struct aa_driver *driver,

const struct aa_hardware_params *defparams,

const void *driverdata

);

PARÁMETROS

const struct aa_driver *driver
Controlador que desea utilizar. Los controladores disponibles se enumeran en la matriz `aa_drivers` terminada en NULL.
const struct aa_hardware_params *defparams
Parámetros de hardware que desea. Utilice `aa_defparams` para los valores predeterminados.
const void *driverdata
Este puntero se pasa directamente al controlador utilizado para especificar parámetros adicionales dependientes del controlador.

DESCRIPCIÓN

Esta es la función de inicialización más primitiva de AA-lib. Permite un mejor control sobre el proceso que la función más fácil de usar `aa_autoinit`.

Cada programa de AA-lib debería tener una llamada a `aa_parseoptions` antes de la primera llamada a `aa_init`.

RETORNA

Puntero a un nuevo contexto de AA-lib o NULL si falla.
