NOMBRE

aa-enabled - comprueba si AppArmor está habilitado

SINOPSIS

aa-enabled [opciones]

DESCRIPCIÓN

aa-enabled se utiliza para determinar si AppArmor está habilitado.

OPCIONES

aa-enabled acepta los siguientes argumentos:

-h, --help
Muestra una breve guía de uso.
-q, --quiet
No muestres nada en la salida estándar. Esta opción está pensada para ser utilizada por scripts que simplemente quieren usar el código de salida para determinar si AppArmor está habilitado.
-x, --exclusive
Requiere que AppArmor tenga acceso exclusivo a las interfaces LSM compartidas para ser considerado habilitado.

ESTADO DE SALIDA

Al salir, aa-enabled establecerá su estado de salida en los siguientes valores:

0
si AppArmor está habilitado.
1
si AppArmor no está habilitado/cargado.
2
intencionadamente no utilizado como estado de salida de aa-enabled.
3
si los archivos de control de AppArmor no están disponibles en /sys/kernel/security/.
4
si aa-enabled no tiene suficientes privilegios para leer los archivos de control de apparmor.
10
AppArmor está habilitado pero no tiene acceso a interfaces LSM compartidas.
64
si se encuentra algún error o condición inesperada.

ERRORES

Si encuentras algún error, por favor repórtalo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN

apparmor(7), apparmor.d(5), aa_is_enabled(2), y https://wiki.apparmor.net.
