aa_query_label(2)

Paquete: apparmor

Licencias: GPL-2.0-only, LGPL-2.0-only, LGPL-2.1-only

AA_QUERY_LABEL(2) AppArmor AA_QUERY_LABEL(2)

NOMBRE

aa_query_label - consulta el permiso de acceso asociado a una etiqueta

aa_query_file_path, aa_query_file_path_len - consulta los permisos de acceso de una ruta de archivo

aa_query_link_path, aa_query_link_path_len - consulta los permisos de acceso de una ruta de enlace

SINOPSIS

#include <sys/apparmor.h>

int aa_query_label(uint32_t mask, char *query, size_t size, int *allowed, int *audited);

int aa_query_file_path(uint32_t mask, const char *label, size_t label_len, const char *path, int *allowed, int *audited);

int aa_query_file_path_len(uint32_t mask, const char *label, size_t label_len, const char *path, size_t path_len, int *allowed, int *audited);

int aa_query_link_path(const char *label, const char *target, const char *link, int *allowed, int *audited);

int aa_query_link_path_len(const char *label, size_t label_len, const char *target, size_t target_len, const char *link, size_t link_len, int *allowed, int *audited);

Enlace con -lapparmor al compilar.

DESCRIPCIÓN

La función aa_query_label obtiene los permisos actuales otorgados por la etiqueta especificada en la cadena query.

La consulta es una consulta de formato binario crudo, que contiene la etiqueta y la consulta de permiso a realizar. Los valores allowed y audited devueltos son valores booleanos interpretados, simplemente indicando si la consulta está permitida y si está auditada.

La máscara de la cadena de consulta es una máscara de bits de permisos a consultar y depende del tipo de clase (ver las entradas AA_CLASS_xxx en sys/apparmor.h).

El formato de la cadena de consulta también depende de la AA_CLASS y, por lo tanto, generalmente se deben usar las funciones auxiliares aa_query_xxx en lugar de usar directamente aa_query_label. Si se usa la interfaz directamente, la cadena query debe tener una cabecera de AA_QUERY_CMD_LABEL_SIZE que será utilizada por aa_query_label.

Las funciones aa_query_file_path y aa_query_file_path_len son funciones auxiliares que ensamblan una consulta de ruta de archivo con formato adecuado para la función aa_query_label. La label es una etiqueta de apparmor válida tal como la devuelve aa_splitcon con label_len siendo la longitud de la label. La path es cualquier ruta de sistema de archivos válida para consultar permisos. Para la variante aa_query_file_path_len, el parámetro path_len especifica el número de bytes en la path a utilizar como parte de la consulta.

Las funciones aa_query_link_path y aa_query_link_path_len son funciones auxiliares que ensamblan una consulta de ruta de enlace con formato adecuado para la función aa_query_label. Los parámetros link_len y target_len especifican el número de bytes en el link y target a utilizar como parte de la consulta.

VALOR DE RETORNO

En caso de éxito se devuelve 0, y los parámetros allowed y audited contienen un valor booleano de 0 no permitido/auditado o 1 permitido/auditado. En caso de error, se devuelve -1 y errno(3) se establece apropiadamente.

ERRORES

EINVAL
La mask solicitada está vacía.

El size de la consulta es menor que el tamaño de la consulta AA_QUERY_CMD_LABEL_SIZE

El módulo del kernel de apparmor no está cargado o la interfaz de acceso a la interfaz del kernel no está disponible

ENOMEM
No había suficiente memoria disponible.
EACCES
Se denegó el acceso a la etiqueta especificada o a la interfaz de consulta.
ENOENT
La etiqueta especificada no existe o no es visible.
ERANGE
Los datos de confinamiento son demasiado grandes para caber en el búfer proporcionado.

NOTAS

Los permisos de etiqueta devueltos solo son válidos en el momento de la consulta y pueden cambiar en cualquier momento en el futuro.

ERRORES CONOCIDOS

Ninguno conocido. Si encuentra alguno, repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN
