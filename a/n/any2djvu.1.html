NOMBRE

any2djvu - Convierte .ps/.ps.gz/.pdf a .djvu

SINOPSIS

any2djvu url {nombre_archivo(s)}

DESCRIPCIÓN

Convierte archivos de .ps/.ps.gz/.pdf a .djvu ejecutándolos a través de un servidor web dispuesto a realizar esta tarea.

Invoque con el interruptor -h para obtener información de uso.

ENTORNO

Un valor no vacío de DJVU_ONLINE_ACK reconoce la transmisión de los documentos al servidor (para que no se muestre ningún diálogo de advertencia).

EJEMPLOS

any2djvu http://barak.pearlmutter.net/papers mesh-preprint.ps.gz

any2djvu archivo_local.pdf

AUTORES

David Kreil, Barak A. Pearlmutter, Yaroslav O. Halchenko

ERRORES

El uso de un servidor de codificación basado en web es una medida provisional hasta que los mejores codificadores disfruten de una amplia distribución gratuita.

Existe un problema de seguridad al operar con documentos que no están destinados a una distribución generalizada, que podría mitigarse parcial, aunque no completamente, mediante el uso de una conexión web segura.

VER TAMBIÉN

Toda la suite djvu, por ejemplo djvu(1), djview(1) y djvuserver(1).
