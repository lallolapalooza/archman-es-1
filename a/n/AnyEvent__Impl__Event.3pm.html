NOMBRE

AnyEvent::Impl::Event - Adaptador de AnyEvent para Event

SINOPSIS

use AnyEvent;
use Event;

# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent. No tienes que hacer nada para que Event funcione con AnyEvent, excepto cargar Event antes de crear el primer observador de AnyEvent.

El módulo Event es razonablemente eficiente y generalmente funciona correctamente incluso con muchos observadores, excepto que su manejo de señales es intrínsecamente susceptible a condiciones de carrera y requiere la solución alternativa de "despertar frecuentemente".

VER TAMBIÉN

AnyEvent, Event.
