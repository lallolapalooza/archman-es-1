Nombre

ansible-galaxy - Realiza varias operaciones relacionadas con Roles y Colecciones.

SINOPSIS

uso: ansible-galaxy [-h] [--version] [-v] TIPO ...

DESCRIPCIÓN

Comando para gestionar roles y colecciones de Ansible.

Ninguna de las herramientas de la línea de comandos está diseñada para ejecutarse concurrentemente consigo misma. Utilice un programador externo y/o bloqueo para asegurarse de que no haya operaciones en conflicto.

OPCIONES COMUNES

--version

muestra el número de versión del programa, la ubicación del archivo de configuración, la ruta de búsqueda de módulos configurada, la ubicación del módulo, la ubicación del ejecutable y sale

-h, --help

muestra este mensaje de ayuda y sale

-v, --verbose

Hace que Ansible imprima más mensajes de depuración. Añadir múltiples -v aumentará el nivel de detalle, los plugins integrados actualmente evalúan hasta -vvvvvv. Un nivel razonable para empezar es -vvv, la depuración de la conexión podría requerir -vvvv. Este argumento puede especificarse múltiples veces.

ARCHIVOS

/etc/ansible/ansible.cfg -- Archivo de configuración, se utiliza si está presente

~/.ansible.cfg -- Archivo de configuración del usuario, anula la configuración predeterminada si está presente

./ansible.cfg -- Archivo de configuración local (en el directorio de trabajo actual) se asume que es 'específico del proyecto' y anula el resto si está presente.

Como se mencionó anteriormente, la variable de entorno ANSIBLE_CONFIG anulará todas las demás.
