NOMBRE

AnyEvent::XMPP::Ext::OOB - Datos fuera de banda XEP-0066

SINOPSIS

my $con = AnyEvent::XMPP::Connection->new (...);
$con->add_extension (my $disco = AnyEvent::XMPP::Ext::Disco->new);
$con->add_extension (my $oob = AnyEvent::XMPP::Ext::OOB->new);
$disco->enable_feature ($oob->disco_feature);
$oob->reg_cb (oob_recv => sub {
   my ($oob, $con, $node, $url) = @_;
   if (got ($url)) {
      $oob->reply_success ($con, $node);
   } else {
      $oob->reply_failure ($con, $node, 'not-found');
   }
});
$oob->send_url (
   $con, 'someonewho@wants.an.url.com', "http://nakedgirls.com/marie_021.jpg",
   "Yaww!!! Hot like SUN!",
   sub {
      my ($error) = @_;
      if ($error) { # entonces hay error
      } else { # todo bien
      }
   }
)

DESCRIPCIÓN

Este módulo proporciona una abstracción auxiliar para manejar datos fuera de banda según se especifica en XEP-0066.

El objeto que se genera maneja las solicitudes de datos fuera de banda hacia y desde otros.

También hay algunas funciones de utilidad definidas para obtener, por ejemplo, la información oob de un elemento XML:

FUNCIONES

url_from_node ($node)
Esta función extrae la URL y opcionalmente un campo de descripción del elemento XML en $node (que debe ser un AnyEvent::XMPP::Node).

$node debe ser el nodo XML que contiene el elemento <url> y opcionalmente <desc> (que es, por ejemplo, un elemento <x xmlns='jabber:x:oob'>).

(Este método busca en ambos namespaces, jabber:x:oob y jabber:iq:oob, los elementos <url> y <desc>).

Devuelve una referencia a un hash que debe tener la siguiente estructura:

{
   url  => "http://someurl.org/mycoolparty.jpg",
   desc => "That was a party!",
}

Si no se encuentra nada, este método no devuelve nada (undef).

MÉTODOS

new ()
Este es el constructor, no toma argumentos adicionales.
reply_success ($con, $node)
Este método responde al remitente de la oob que la URL se recuperó correctamente.

$con y $node son los argumentos $con y $node del evento "oob_recv" al que desea responder.

reply_failure ($con, $node, $type)
Este método responde al remitente que la transferencia fue rechazada o no se encontró.

Si la transferencia fue rechazada, debe establecer $type a 'reject', de lo contrario, $type debe ser 'not-found'.

$con y $node son los argumentos $con y $node del evento "oob_recv" al que desea responder.

send_url ($con, $jid, $url, $desc, $cb)
Este método envía una solicitud de transferencia de archivos fuera de banda a $jid. $url es la URL que el otro debe descargar. $desc es una cadena de descripción opcional (legible por humanos) para el archivo al que apunta la url y puede ser undef si no desea transmitir ninguna descripción.

$cb es una función de devolución de llamada que se llamará una vez que la transferencia sea exitosa.

El primer argumento de la función de devolución de llamada será undef en caso de éxito o 'reject' cuando el otro lado rechazó el archivo o 'not-found' si el otro lado no pudo descargar el archivo.

EVENTOS

Estos eventos pueden registrarse con "reg_cb":

oob_recv => $con, $node, $url
Este evento se genera cada vez que alguien quiere enviarle un archivo de datos fuera de banda. $url es una referencia a un hash como la que devuelve "url_from_node".

$con es la conexión AnyEvent::XMPP (o AnyEvent::XMPP::IM::Connection) desde la que se recibieron los datos.

$node es el nodo AnyEvent::XMPP de la solicitud IQ; puede obtener el JID del remitente del atributo 'from' del mismo.

Si ha recuperado el archivo con éxito, debe llamar a "reply_success". Si desea rechazar el archivo o no pudo obtenerlo, llame a "reply_failure".
