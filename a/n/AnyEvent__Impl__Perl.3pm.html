NOMBRE

AnyEvent::Impl::Perl - Adaptador de AnyEvent para AnyEvent's pure perl AnyEvent::Loop

SINOPSIS

use AnyEvent;
use AnyEvent::Loop;
# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent en caso de que no se pudiera encontrar o cargar ningún otro bucle de eventos.

Si deseas utilizar este módulo en lugar de cargar automáticamente otro bucle de eventos, simplemente puedes cargar AnyEvent::Loop antes de crear el primer observador.

Naturalmente, soporta todas las características de AnyEvent.

Ver AnyEvent::Loop para más detalles sobre las características de rendimiento.

VER TAMBIÉN
