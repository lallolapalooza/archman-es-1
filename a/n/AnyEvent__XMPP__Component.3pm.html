AnyEvent::XMPP::Component(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Component(3)

NOMBRE

AnyEvent::XMPP::Component - Flujo "XML" que implementa el XEP-0114

SINOPSIS

use AnyEvent::XMPP::Component;
my $con = AnyEvent::XMPP::Component->new (
             domain => 'chat.jabber.org'
             host   => 'jabber.org',
             port   => 5347,
             secret => 'contraseñainseguraparaloshackers'
          );
$con->reg_cb (session_ready => sub { ... });
$con->connect;

DESCRIPCIÓN

Este módulo representa una conexión XMPP a un servidor que se autentica como componente.

Este módulo es una subclase de "AnyEvent::XMPP::Connection" y hereda todos los métodos. Por ejemplo "reg_cb" y las rutinas de envío de stanzas.

Para eventos adicionales que se pueden registrar, véase la sección EVENTOS más abajo.

Por favor, tenga en cuenta que para componentes, varias funcionalidades en AnyEvent::XMPP::Connection podrían no tener efecto o no tener el efecto deseado. Básicamente, debería usar AnyEvent::XMPP::Component como componente y solo manejar los eventos que manejan los datos entrantes. Y solo usar las funciones que envían stanzas.

El evento "stream_pre_authentication" y el método "authenticate" de AnyEvent::XMPP::Connection no tienen efecto, porque estos manejan la autenticación SASL o iq-auth habitual. Los componentes "Jabber" tienen un mecanismo de autenticación completamente diferente.

Tenga en cuenta también que el soporte para algunos XEPs en AnyEvent::XMPP::Ext está pensado solo para uso del lado del cliente; si echa en falta alguna funcionalidad, ¡no dude en preguntar al autor o enviarle un parche! (Vea AnyEvent::XMPP para información de contacto).

MÉTODOS

new (%args)
Este es el constructor. Toma los mismos argumentos que el constructor de AnyEvent::XMPP::Connection junto con algunos otros:

NOTA: Tenga en cuenta que algunos argumentos que AnyEvent::XMPP::Connection suele tomar no tienen efecto al usar esta clase. (Por ejemplo, los argumentos 'username', 'password', 'resource' y 'jid').

secret => $secret
$secret es el secreto que se usará para la autenticación con el servidor.
