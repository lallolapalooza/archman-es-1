AnyEvent__XMPP__Ext__Ping(3pm)

Paquete: perl-anyevent-xmpp

Licencias: GPL, PerlArtistic

AnyEvent::XMPP::Ext::Ping(3) Documentación Perl de contribución de usuarios AnyEvent::XMPP::Ext::Ping(3)

NOMBRE

AnyEvent::XMPP::Ext::Ping - Implementación de XMPP Ping XEP-0199

SINOPSIS

use AnyEvent::XMPP::Ext::Ping;
my $con = AnyEvent::XMPP::IM::Connection->new (...);
$con->add_extension (my $ping = AnyEvent::XMPP::Ext::Ping->new);
# esto habilita el tiempo de espera automático de una conexión si no respondió
# dentro de los 120 segundos a un ping con una respuesta
$ping->enable_timeout ($con, 120);
my $cl = AnyEvent::XMPP::Client->new (...);
$cl->add_extension (my $ping = AnyEvent::XMPP::Ext::Ping->new);
# esto habilita el tiempo de espera automático de las nuevas conexiones
$ping->auto_timeout (120);
$ping->ping ($con, 'ping_dest@server.tld', sub {
   my ($time, $error) = @_;
   if ($error) {
      # obtuvimos un error
   }
   # $time es un flotante (segundos) del RTT si tienes Time::HiRes
});

DESCRIPCIÓN

Esta extensión implementa XEP-0199: XMPP Ping. Permite definir un temporizador de ping automático que desconectará las conexiones muertas (que no respondieron a un ping después de N segundos). Ver también la documentación del método "enable_timeout" abajo.

También permite enviar pings a cualquier entidad XMPP que desee y medirá el tiempo que tardó si tiene Time::HiRes.

MÉTODOS

new (%args)
Crea un nuevo manejador de ping.
auto_timeout ($timeout)
Este método habilita el tiempo de espera automático de las nuevas conexiones. Llama a "enable_timeout" (ver abajo) para cada nueva conexión que se haya conectado y emitido un evento "stream_ready".

Esto es útil si desea que las conexiones que tienen esta extensión tengan un tiempo de espera automático. En particular, esto es útil con módulos como AnyEvent::XMPP::Client (ver también la SINOPSIS arriba).

enable_timeout ($con, $timeout)
Esto habilita un ping periódico en la conexión $con. $timeout debe ser los segundos que duran los intervalos de ping.

Si el servidor al que se conecta a través de $con no responde dentro de los $timeout segundos, la conexión $con se desconectará.

Tenga en cuenta que ya existe un mecanismo básico de tiempo de espera para conexiones TCP muertas en AnyEvent::XMPP::Connection, ver también la variable de configuración "whitespace_ping_interval" para una conexión allí. Entonces dependerá de los tiempos de espera de TCP para desconectar la conexión.

Use "enable_timeout" y "auto_timeout" solo si realmente siente que necesita un tiempo de espera explícito para sus conexiones.

ping ($con, $dest, $cb, $timeout)
Este método envía una solicitud de ping a $dest a través de la Conexión AnyEvent::XMPP en $con. Si $dest no está definido, el ping se enviará al servidor conectado. $cb se llamará cuando el ping exceda el tiempo de espera, ocurra un error o se reciba el resultado del ping. $timeout es un tiempo de espera opcional para la solicitud de ping, si $timeout no se proporciona, el tiempo de espera IQ predeterminado para la conexión es el tiempo de espera relevante.

El primer argumento para $cb serán los segundos del tiempo de ida y vuelta para esa solicitud (si tienes Time::HiRes). Si no tienes Time::HiRes instalado, el primer argumento será undef.

El segundo argumento para $cb será undef si no ocurrió ningún error o un objeto de error AnyEvent::XMPP::Error::IQ.

ignore_pings ($bool)
Este método es principalmente para pruebas, le dice a esta extensión que ignore todas las solicitudes de ping y evitará que se envíe cualquier respuesta.
