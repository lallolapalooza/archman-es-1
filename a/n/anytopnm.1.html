NOMBRE

anytopnm - convertir un tipo de archivo de imagen arbitrario a PBM, PGM o PPM

SINOPSIS

anytopnm [archivo]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

anytopnm convierte la imagen de entrada, que puede estar en cualquiera de aproximadamente 100 formatos gráficos, a formato PBM, PGM o PPM, dependiendo de la naturaleza de la imagen de entrada, y la envía a la salida estándar.

Para determinar el formato de la entrada, anytopnm utiliza el programa file (posiblemente asistido por el fragmento de archivo de números mágicos incluido con Netpbm). Si eso falla (muy pocos formatos de imagen tienen números mágicos), anytopnm examina la extensión del nombre del archivo. Si eso falla, anytopnm renuncia.

El tipo del archivo de salida depende de la imagen de entrada.

anytopnm utiliza los conversores para formatos gráficos específicos que se encuentran en el paquete Netpbm, por lo que no puede convertir ningún formato que no pudiera convertir con algún otro programa Netpbm. Lo que anytopnm añade es la capacidad de reconocer el formato y elegir el programa Netpbm apropiado para convertirlo. Por ejemplo, si invoca anytopnm en un archivo GIF, anytopnm reconocerá que es un archivo GIF y, por lo tanto, giftopnm sabe cómo convertirlo a PNM, así que anytopnm invoca a giftopnm.

anytopnm no puede reconocer todos los formatos de entrada posibles, por lo que es posible que aún pueda convertir una imagen con un programa Netpbm específico cuando anytopnm no pueda convertirla.

Si file indica que el archivo de entrada está comprimido (ya sea mediante compress, gzip o bzip de Unix), anytopnm lo descomprime y procede como se describe anteriormente con el resultado descomprimido.

Si file indica que el archivo de entrada está codificado mediante uuencode o btoa, anytopnm lo decodifica y procede como se describe anteriormente con el resultado decodificado.

Si archivo es - o no se proporciona, anytopnm toma su entrada de la entrada estándar.
