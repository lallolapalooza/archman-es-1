NOMBRE

AnyEvent::Impl::UV - Adaptador de AnyEvent para UV

SINOPSIS

use AnyEvent;
use UV;

# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent. No tienes que hacer nada para que UV funcione con AnyEvent, solo cargar UV antes de crear el primer observador de AnyEvent.

VER TAMBIÉN

AnyEvent, UV.
