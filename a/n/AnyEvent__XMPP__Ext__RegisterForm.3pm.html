AnyEvent::XMPP::Ext::RegisterForm(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Ext::RegisterForm(3)

NOMBRE

AnyEvent::XMPP::Ext::RegisterForm - Manejador para registro en banda

SINOPSIS

my $con = AnyEvent::XMPP::Connection->new (...);
...
$con->do_in_band_register (sub {
   my ($form, $error) = @_;
   if ($error) { print "ERROR: ".$error->string."\n" }
   else {
      if ($form->type eq 'simple') {
         if ($form->has_field ('username') && $form->has_field ('password')) {
            $form->set_field (
               username => 'test',
               password => 'qwerty',
            );
            $form->submit (sub {
               my ($form, $error) = @_;
               if ($error) { print "ERROR DE ENVÍO: ".$error->string."\n" }
               else {
                  print "Registrado con éxito como ".$form->field ('username')."\n"
               }
            });
         } else {
            print "No se pudo completar el formulario: " . $form->field ('instructions') ."\n";
         }
      } elsif ($form->type eq 'data_form' {
         my $dform = $form->data_form;
         ... completar el formulario $dform (de tipo AnyEvent::XMPP::DataForm) ...
         $form->submit_data_form ($dform, sub {
            my ($form, $error) = @_;
            if ($error) { print "ERROR DE ENVÍO DEL FORMULARIO DE DATOS: ".$error->string."\n" }
            else {
               print "Registrado con éxito como ".$form->field ('username')."\n"
            }
         })
      }
   }
});

DESCRIPCIÓN

Este módulo representa un formulario de registro en banda que puede ser completado y enviado.

Solo puede obtener una instancia de esta clase solicitándola a una AnyEvent::XMPP::Connection llamando al método "request_inband_register_form".

new (%args)
Normalmente el constructor no toma argumentos, excepto cuando se quiere construir un formulario de respuesta, en cuyo caso se llama al constructor así:

Si tiene campos de formulario heredados como una referencia hash en $filled_legacy_form:

AnyEvent::XMPP::Ext::RegisterForm (
   legacy_form => $filled_legacy_form,
   answered => 1
);

Si tiene un formulario de datos en $answer_data_form:

AnyEvent::XMPP::Ext::RegisterForm (
   legacy_form => $answer_data_form,
   answered => 1
);
try_fillout_registration ($username, $password)
Este método intenta completar un formulario recibido del otro extremo. Introduce el nombre de usuario y la contraseña, y devuelve un nuevo objeto AnyEvent::XMPP::Ext::RegisterForm que es el formulario de respuesta.

NOTA: Esta función es solo una heurística para completar un formulario de registro automático, pero podría fallar si los formularios son más complejos y tienen campos requeridos que no conocemos.

El registro sin interacción del usuario teóricamente no es posible porque los formularios pueden ser diferentes de un servidor a otro y requerir información distinta. Por favor, consulte también XEP-0077.

Tenga en cuenta que si el formulario es más complicado, este método no funcionará y no se garantiza que el registro sea exitoso.

Llamar a este método en un formulario de respuesta (donde "is_answer_form" devuelve verdadero) tendrá un resultado indefinido.

is_answer_form
Este método devolverá un valor verdadero si este formulario fue devuelto por, por ejemplo, "try_fillout_registration" o generalmente representa un formulario de respuesta.
is_already_registered
Este método devuelve verdadero si el formulario recibido fueran solo los datos de registro actuales. Básicamente, este método devuelve verdadero cuando ya está registrado en el servidor.
get_legacy_form_fields
Este método devuelve un hash con las claves siendo los campos del formulario heredado, tal como se describe en el esquema XML de XEP-0077.

Si el formulario contenía solo nodos, las claves tendrán el valor undef.

Si el formulario contenía también información de registro, en caso de que "is_already_registered" devuelva un valor verdadero, los valores contendrán las cadenas para los campos.

get_data_form
Este método devuelve el AnyEvent::XMPP::Ext::DataForm que vino con la respuesta de registro. Si el servidor no proporcionó ningún formulario de datos, este método devuelve undef.
get_oob
Este método devuelve un hash similar al devuelto por la función "url_from_node" en AnyEvent::XMPP::Ext::OOB. Contiene los datos fuera de banda para este formulario de registro.
answer_form_to_simxml
Este método devuelve una lista de nodos "simxml".
