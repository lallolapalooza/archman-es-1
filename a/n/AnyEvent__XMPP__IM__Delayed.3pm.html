AnyEvent::XMPP::IM::Delayed(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::IM::Delayed(3)

NOMBRE

AnyEvent::XMPP::IM::Delayed - un stanza "XML" retardado

SINOPSIS

DESCRIPCIÓN

Este módulo maneja los campos retardados de los stanzas y es una superclase de AnyEvent::XMPP::IM::Message y AnyEvent::XMPP::IM::Presence.

MÉTODOS

new
El constructor no toma argumentos y solo crea un nuevo objeto de esta clase.
xml_node ()
Devuelve el objeto AnyEvent::XMPP::Node para este error de transmisión.
fetch_delay_from_node ($node)
$node debe ser un AnyEvent::XMPP::Node. Este método intentará obtener la información de retardo del $node. Buscará en las listas de nodos hijos los elementos de retardo y establecerá sus valores a partir de ahí.
delay_from
Este método devuelve la fuente original de un stanza posiblemente retardado. Es el JID de la entidad original que envió el stanza.

Este método devuelve undef si este stanza no fue retardado.

Y este método devuelve undef si este stanza no tenía detalles sobre quién envió el mensaje en primer lugar.

Para saber si este stanza fue retardado, utiliza el método "delay_stamp".

delay_stamp
Este método devuelve la marca de tiempo en formato XMPP que puede ser alimentada a la función "from_xmpp_datetime" documentada en AnyEvent::XMPP::Util.

(Tenga en cuenta que esta podría ser una marca de tiempo de estilo nuevo XEP-0087 o una marca de tiempo heredada de estilo antiguo)

Si el stanza no fue retardado, este método devuelve undef.

delay_reason
Este método podría devolver una cadena legible por humanos que contenga la razón por la cual el stanza fue retardado.

Será undef si el stanza no contenía retardo.

is_delayed
Si este método devuelve un valor verdadero, entonces este stanza fue retardado. De lo contrario, devuelve undef.
