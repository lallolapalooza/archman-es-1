AnyEvent::XMPP::Extendable(3) Documentación de Perl contribuida por el usuario AnyEvent::XMPP::Extendable(3)

NOMBRE

AnyEvent::XMPP::Extendable - Clase base extensible

DESCRIPCIÓN

Esta clase proporciona un mecanismo para agregar extensiones. Tenga en cuenta que la clase que hereda de esta también debe heredar de AnyEvent::XMPP::Event!

Por favor, consulte AnyEvent::XMPP::Ext para obtener más información sobre este mecanismo.

add_extension ($ext)
Este método extiende el objeto actual con un objeto AnyEvent::XMPP::Ext. $ext debe ser una instancia de AnyEvent::XMPP::Ext.

Básicamente, "add_extension" convierte la extensión en un receptor de eventos para todos los eventos que recibe el objeto extendido.

remove_extension ($ext)
Este método elimina la extensión $ext.
