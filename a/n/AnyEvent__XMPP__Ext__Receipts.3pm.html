Paquete: perl-anyevent-xmpp

AnyEvent::XMPP::Ext::Receipts(3) Documentación Perl aportada por el usuario AnyEvent::XMPP::Ext::Receipts(3)

NOMBRE

AnyEvent::XMPP::Ext::Receipts - recibos de mensajes XEP-0184

SINOPSIS

use AnyEvent::XMPP::Ext::Disco;
use AnyEvent::XMPP::Ext::Receipts;
my $disco = AnyEvent::XMPP::Ext::Disco->new();
$xmpp->add_extension($disco);
my $receipts = AnyEvent::XMPP::Ext::Receipts->new(disco => $disco);
$xmpp->add_extension($receipts);
$disco->enable_feature($receipts->disco_feature);

DESCRIPCIÓN

Este módulo añade soporte para recibos de mensajes XEP-0184.

Los recibos de mensajes proporcionan una forma de verificar que los mensajes fueron recibidos por el destinatario, siempre que el cliente del destinatario lo soporte.

Tenga en cuenta que debe enviar mensajes con recibos de mensaje a identificadores Jabber completos (por ejemplo, jabber@example.com/android3948128), no a identificadores Jabber desnudos (por ejemplo, jabber@example.com).

MÉTODOS

new (%args)
Crea un nuevo manejador de recibos.

Se pueden especificar las siguientes claves:

disco
Un objeto "AnyEvent::XMPP::Ext::Disco" para que se pueda determinar si el destinatario soporta recibos de mensaje (mediante descubrimiento de servicios).

Esto es obligatorio.

debug
Si pasa un valor que se evalúa como verdadero, se imprimirán mensajes de depuración en STDOUT.
auto_resend
Cantidad de tiempo en segundos después de la cual se reenviarán los mensajes cuando no se reciba un recibo. Por supuesto, los mensajes solo se reenviarán si se sabe que el destinatario soporta recibos de mensaje.

Por defecto es 30 (segundos).

Establecer a 0 para deshabilitar el reenvío automático.

Aquí hay un ejemplo con todas las claves establecidas:

my $receipts = AnyEvent::XMPP::Ext::Receipts->new(
    disco => $disco,
    auto_resend => 30,
    debug => 1,
);
