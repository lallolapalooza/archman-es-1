DESCRIPCIÓ

N

Este módulo intenta implementar una API directa y fácil de usar para comunicarse con entidades XMPP. AnyEvent::XMPP::Client se encarga de las conexiones, los tiempos de espera y todo ese tipo de cosas por

usted.

Para mayor flexibilidad, por favor, eche un vistazo a AnyEv

ent::XMPP::Connection y AnyEvent::XMPP::IM::Connection, le per
miten controlar qué y cómo se envía algo con más precisión.

send_message ($msg, $dest_jid, $src,

$type)

Envía un mensaje al destino $dest_jid. $msg puede ser una cadena de texto o un objeto AnyEvent::XMPP::IM::Message. Si $msg es tal objeto, $dest_jid es opcional, pero, cuando se pase, anulará el destino del

$src es opcional. Especifica qué cuenta usar para enviar el mensaje. Si no se pasa, AnyEvent::XMPP::Client intentará encontrar una cuenta por sí mismo. Primero buscará en todos los rosters para encontrar $dest_jid y si no encuentra ninguna, elegirá cualquiera de las cuentas que estén

conectadas.
