NOMBRE

AnyEvent::XMPP::Error::Stream - Errores de Stream XML

Subclase de AnyEvent::XMPP::Error

MÉTODOS

xml_node ()
Devuelve el objeto AnyEvent::XMPP::Node para este error de stream.
name ()
Devuelve el nombre del error. Puede ser undef, una de las siguientes cadenas o alguna otra cadena descubierta por heurística (porque algunos servidores envían errores que no están en el RFC). 
bad-format
bad-namespace-prefix
conflict
connection-timeout
host-gone
host-unknown
improper-addressing
internal-server-error
invalid-from
invalid-id
invalid-namespace
invalid-xml
not-authorized
policy-violation
remote-connection-failed
resource-constraint
restricted-xml
see-other-host
system-shutdown
undefined-condition
unsupported-stanza-type
unsupported-version
xml-not-well-formed
text ()
La porción del error legible por humanos. Puede ser undef si no se recibió ninguna.
