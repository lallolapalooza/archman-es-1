AnyEvent::Impl::EventLib(3) Documentación de Contribución de Perl AnyEvent::Impl::EventLib(3)

NOMBRE

AnyEvent::Impl::EventLib - Adaptador AnyEvent para Event::Lib

SINOPSIS

use AnyEvent;
use Event::Lib;

# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent. No tienes que hacer nada para que Event funcione con AnyEvent, excepto cargar Event::Lib antes de crear el primer observador de AnyEvent.

Nota: El autor de AnyEvent no ha encontrado que las versiones recientes de Event::Lib funcionen remotamente (ni siquiera los ejemplos del manual o la suite de pruebas funcionan), por lo que se debe evitar este backend de eventos (o alguien debería dar un paso al frente y mantenerlo, pista, pista).

El módulo Event::Lib sufre las mismas limitaciones y errores que libevent, en particular, elimina los observadores ya instalados en un descriptor de archivo y no puede admitir bifurcaciones (fork). Estos no son problemas fatales y son solucionados por este módulo, pero el módulo Perl Event::Lib en sí mismo tiene muchos errores adicionales, como tomar referencias a manejadores de archivos y callbacks en lugar de hacer una copia o liberar escalares ya asignados, lo que provoca corrupción de memoria y bloqueos aleatorios. Solo Tk lo rivaliza en su mal funcionamiento.

Este módulo adaptador emplea la misma solución alternativa para los problemas de observadores que Tk y, por lo tanto, debe evitarse. (Esto se hizo por simplicidad, en teoría se podrían solucionar los problemas con menor sobrecarga gestionando nuestros propios observadores).

Event::Lib también filtra descriptores de archivo y memoria y tiende a salir ante problemas.

Tampoco soluciona el error de Windows de no señalar fallos en las conexiones TCP.

Tampoco funciona con muchos dispositivos especiales en Linux (/dev/random funciona, /dev/urandom falla, /dev/tty funciona, /dev/null falla y así sucesivamente).

Event::Lib no admite observadores inactivos (idle watchers). Podrían emularse usando temporizadores de baja prioridad, pero como el rango de prioridad (y disponibilidad) no es consultable ni garantizado, y la prioridad por defecto es probablemente la más baja, este módulo no puede utilizarlos.

Evita Event::Lib si puedes.

VER TAMBIÉN

AnyEvent, Event::Lib.
