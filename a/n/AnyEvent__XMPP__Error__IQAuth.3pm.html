AnyEvent::XMPP::Error::IQAuth(3) Documentación de Perl aportada por usuarios AnyEvent::XMPP::Error::IQAuth(3)

NOMBRE

AnyEvent::XMPP::Error::IQAuth - Error de autenticación IQ

Subclase de AnyEvent::XMPP::Error

MÉTODOS

contexto
Este método devuelve:

"iq_error" que significa que se detectó un error IQ, al cual se puede acceder mediante el método "iq_error".

O: "no_fields" que significa que no se encontraron campos de formulario en el resultado de autenticación IQ.
