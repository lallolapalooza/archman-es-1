NOMBRE

AnyEvent::XMPP::TestClient - Cliente de prueba XMPP para pruebas

SINOPSIS

DESCRIPCIÓN

Este módulo es una ayuda para facilitar la tarea de pruebas. Si desea ejecutar el conjunto de pruebas del desarrollador, debe establecer la variable de entorno "NET_XMPP2_TEST" con algo como esto:

NET_XMPP2_TEST="test_me@your_xmpp_server.tld:secret_password"

La mayoría de las pruebas intentarán conectar dos cuentas, así que por favor utilice un servidor que permita dos conexiones desde la misma IP.

Si también desea ejecutar las pruebas MUC (ver AnyEvent::XMPP::Ext::MUC), también necesita configurar la variable de entorno "NET_XMPP2_TEST_MUC" para que contenga el dominio de un servicio MUC:

NET_XMPP2_TEST_MUC="conference.your_xmpp_server.tld"

Si ve que algunas pruebas fallan y quiere saber más sobre el flujo del protocolo, puede habilitar la salida de depuración del protocolo estableciendo "NET_XMPP2_TEST_DEBUG" a '1':

NET_XMPP2_TEST_DEBUG=1

(NOTA: Solo verá la salida de esto ejecutando una única prueba)

Si alguna de las pruebas tarda más de los 20 segundos preconfigurados de tiempo de espera en su configuración, puede establecer "NET_XMPP2_TEST_TIMEOUT":

NET_XMPP2_TEST_TIMEOUT=60  # para un tiempo de espera de 1 minuto

LIMPIEZA

Si las pruebas fallaron en algún punto o interrumpió las pruebas, quizás quiera eliminar manualmente las cuentas del servidor, luego ejecute:

perl t/z_*_unregister.t

PRUEBAS MANUALES

Si solo desea ejecutar una prueba individualmente, simplemente ejecute la prueba de registro antes de hacerlo:

perl t/z_00_register.t

Y luego podría, por ejemplo, ejecutar:

perl t/z_03_iq_auth.t
