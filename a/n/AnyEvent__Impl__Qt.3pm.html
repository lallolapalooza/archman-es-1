AnyEvent::Impl::Qt(3) Documentación de Perl contribuida por el usuario AnyEvent::Impl::Qt(3)

NOMBRE

AnyEvent::Impl::Qt - Adaptador AnyEvent para Qt

SINOPSIS

use AnyEvent;
use Qt;

my $app = Qt::Application \@ARGV; # ¡OBLIGATORIO!

# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent. No tienes que hacer nada para que Qt funcione con AnyEvent, excepto cargar Qt antes de crear el primer observador de AnyEvent e instanciar el objeto Qt::Application. La falta de hacerlo resultará en segfaults, por eso este modelo no funciona por defecto y no será autodetectado (pero será detectado automáticamente cuando el programa principal use Qt).

Qt sufre las mismas limitaciones que Event::Lib y Tk, la solución es también la misma (duplicación de descriptores de archivo).

Qt no soporta eventos inactivos (idle events), por lo que se emulan.

Evita Qt si puedes.

VER TAMBIÉN

AnyEvent, Qt.
