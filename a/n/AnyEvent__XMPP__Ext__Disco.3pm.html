NOMBRE

AnyEvent::XMPP::Ext::Disco - Clase gestora de descubrimiento de servicios para XEP-0030

SINOPSIS

use AnyEvent::XMPP::Ext::Disco;
my $con = AnyEvent::XMPP::IM::Connection->new (...);
$con->add_extension (my $disco = AnyEvent::XMPP::Ext::Disco->new);
$disco->request_items ($con, 'romeo@montague.net', undef,
   sub {
      my ($disco, $items, $error) = @_;
      if ($error) { print "ERROR:" . $error->string . "\n" }
      else {
         ... haz algo con los $items ...
      }
   }
);

DESCRIPCIÓN

Este módulo representa una clase gestora de descubrimiento de servicios. Creas instancias de esta clase y obtienes un manejador para enviar solicitudes de descubrimiento como se describe en XEP-0030.

También te permite configurar un árbol de información/elementos de disco que otros pueden recorrer y te permite publicar información de disco.

Esta clase deriva de AnyEvent::XMPP::Ext y puede añadirse como extensión a objetos que implementan la interfaz AnyEvent::XMPP::Extendable o derivan de ella.

MÉTODOS

new (%args)
Crea un nuevo manejador de disco.
set_identity ($category, $type, $name)
Esto establece la identidad del nodo de información superior.

$name es opcional y puede ser undef. ¡Ten en cuenta que $name sobrescribirá todos los nombres establecidos previamente! Si $name no está definido, entonces ningún nombre anterior se sobrescribe.

Para una lista de identidades válidas, consulta:

http://www.xmpp.org/registrar/disco-categories.html

Los $types de identidad válidos para "$category = "client"" pueden ser:

bot
console
handheld
pc
phone
web
unset_identity ($category, $type)
Esta función elimina la identidad $category y $type.
enable_feature ($uri)
Este método habilita la característica $uri, donde $uri debe ser uno de los valores de la columna Name en: http://www.xmpp.org/registrar/disco-features.html

Estas características están habilitadas por defecto:

http://jabber.org/protocol/disco#info
http://jabber.org/protocol/disco#items

¡También puedes pasar una lista de características que deseas habilitar a "enable_feature"!

disable_feature ($uri)
Este método habilita la característica $uri, donde $uri debe ser uno de los valores de la columna Name en: http://www.xmpp.org/registrar/disco-features.html

¡También puedes pasar una lista de características que deseas deshabilitar a "disable_feature"!

request_items ($con, $dest, $node, $cb)
Este método envía una solicitud de elementos al JID de destino $from. $node es el nodo opcional al que enviar la solicitud, que puede ser undef.

$con debe ser una instancia de AnyEvent::XMPP::Connection o una subclase de ella. La función de devolución de llamada $cb se llamará cuando la solicitud regrese con 3 argumentos: el manejador de disco, un objeto AnyEvent::XMPP::Ext::Disco::Items (o undef) y un objeto AnyEvent::XMPP::Error::IQ cuando ocurrió un error y no se recibieron elementos.

El tiempo de espera de la solicitud es el tiempo de espera IQ de la conexión $con.

$disco->request_items ($con, 'a@b.com', undef, sub {
   my ($disco, $items, $error) = @_;
   die $error->string if $error;
   # haz algo con los items aquí ;_)
});
request_info ($con, $dest, $node, $cb)
Este método envía una solicitud de información al JID de destino $from. $node es el nodo opcional al que enviar la solicitud, que puede ser undef.

$con debe ser una instancia de AnyEvent::XMPP::Connection o una subclase de ella. La función de devolución de llamada $cb se llamará cuando la solicitud regrese con 3 argumentos: el manejador de disco, un objeto AnyEvent::XMPP::Ext::Disco::Info (o undef) y un objeto AnyEvent::XMPP::Error::IQ cuando ocurrió un error y no se recibieron elementos.

El tiempo de espera de la solicitud es el tiempo de espera IQ de la conexión $con.

$disco->request_info ($con, 'a@b.com', undef, sub {
   my ($disco, $info, $error) = @_;
   die $error->string if $error;
   # haz algo con la info aquí ;_)
});
