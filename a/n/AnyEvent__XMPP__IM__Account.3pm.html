AnyEvent::XMPP::IM::Account(3) Documentación de Perl contribuida por el usuario AnyEvent::XMPP::IM::Account(3)

NOMBRE

AnyEvent::XMPP::IM::Account - Cuenta de mensajería instantánea

SINOPSIS

my $cl = AnyEvent::XMPP::IM::Client->new;
...
my $acc = $cl->get_account ($jid);

DESCRIPCIÓN

Este módulo representa una clase para cuentas de mensajería instantánea. Es utilizado por AnyEvent::XMPP::Client.

Solo puede obtener una instancia de esta clase llamando al método "get_account" en un objeto AnyEvent::XMPP::Client.

MÉTODOS

connection ()
Devuelve el objeto AnyEvent::XMPP::IM::Connection si esta cuenta ya tiene uno (undef en caso contrario).
is_connected ()
Devuelve verdadero si esta cuenta está conectada.
jid ()
Devuelve el JID completo si la cuenta está conectada o devuelve el JID desnudo si no.
bare_jid ()
Devuelve siempre el JID desnudo de esta cuenta después de aplicar stringprep, por lo que puede comparar los JIDs devueltos por esta función.
nickname ()
Tu apodo para esta cuenta.
nickname_for_jid ($jid)
Este método transforma el $jid en un apodo. Busca el $jid en la lista de contactos y busca un apodo. Si no se encuentra ningún apodo en la lista de contactos, devuelve la parte del nodo del $jid.
send_tracked_message ($msg)
Este método envía el objeto AnyEvent::XMPP::IM::Message en $msg. El atributo "to" del mensaje se ajusta mediante el mecanismo de seguimiento de conversaciones.

EVENTOS

Para estos eventos se pueden registrar callbacks (con la interfaz Object::Event):

tracked_message_destination => $bare_jid, $full_jid
Este evento se emite cada vez que el mecanismo de seguimiento de mensajes cambia (o establece) su recurso de destino para el $bare_jid a $full_jid.
removed
Cada vez que la cuenta se elimina del AnyEvent::XMPP::Client (por ejemplo, al desconectarse) se emite este evento antes de que sea destruido.
