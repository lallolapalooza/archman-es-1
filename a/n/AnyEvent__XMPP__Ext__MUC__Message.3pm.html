NOMBRE

AnyEvent::XMPP::Ext::MUC::Message - Un mensaje de sala

SINOPSIS

DESCRIPCIÓN

Este mensaje representa un mensaje de una sala MUC. Se deriva de AnyEvent::XMPP::IM::Message. (Puedes usar los métodos de esa clase para acceder a él, por ejemplo).

Además, los métodos como, por ejemplo, "make_reply" devuelven un AnyEvent::XMPP::Ext::MUC::Message.

MÉTODOS

new (%args)
Este constructor toma los mismos argumentos que el constructor para AnyEvent::XMPP::IM::Message.
room
Devuelve la sala de chat en cuyo contexto se envió este mensaje.
send ([$room])
Este método envía este mensaje. Si $room está definido, establecerá la conexión de este objeto de mensaje antes de enviarlo.
make_reply ([$msg])
Este método devuelve una nueva instancia de AnyEvent::XMPP::Ext::MUC::Message. La dirección de destino, la conexión y el tipo del objeto de mensaje devuelto se configurarán.

Si $msg está definido y es una instancia de AnyEvent::XMPP::Ext::MUC::Message, la dirección de destino, la conexión y el tipo de $msg se modificarán y este método no devolverá una nueva instancia de AnyEvent::XMPP::Ext::MUC::Message.

Si $self es un mensaje de tipo 'groupchat', el atributo "to" se establecerá al JID desnudo de la sala para la respuesta.

from_nick
Este método devuelve el apodo de la fuente de este mensaje.
is_private
Este método devuelve verdadero si el mensaje no se dirigió a la sala, sino privadamente a ti.
