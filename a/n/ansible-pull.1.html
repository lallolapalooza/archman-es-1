ARGUMENTOS

playbook.yml

El nombre de uno de los archivos en formato YAML para ejecutar como un playbook de Ansible. Esta puede ser una ruta relativa dentro del repositorio. Por defecto, Ansible buscará un playbook basado en el nombre de dominio completamente calificado del host, en el nombre de host y finalmente un playbook llamado local.yml.

INVENTARIO

Ansible almacena los hosts en los que puede operar potencialmente en un inventario. Este puede ser un archivo YAML, un archivo tipo ini, un script, un directorio, una lista, etc. Para opciones adicionales, consulte la documentación en https://docs.ansible.com/.

ENTORNO

Se pueden especificar las siguientes variables de entorno.

ANSIBLE_INVENTORY -- Sobrescribe las fuentes de inventario de ansible predeterminadas

ANSIBLE_LIBRARY -- Sobrescribe la ruta de la biblioteca de módulos de ansible predeterminada

ANSIBLE_CONFIG -- Especifica la ubicación de sobrescritura para el archivo de configuración de ansible

Hay muchas más disponibles para la mayoría de las opciones en ansible.cfg

Para una lista completa, consulte https://docs.ansible.com/. o use el ansible-config comando.

ARCHIVOS

/etc/ansible/hosts -- Archivo de inventario predeterminado

/etc/ansible/ansible.cfg -- Archivo de configuración, se usa si está presente

~/.ansible.cfg -- Archivo de configuración del usuario, sobrescribe la configuración predeterminada si está presente

./ansible.cfg -- Archivo de configuración local (en el directorio de trabajo actual) se asume que es 'específico del proyecto' y sobrescribe al resto si está presente.

Como se mencionó anteriormente, la variable de entorno ANSIBLE_CONFIG sobrescribirá a todas las demás.
