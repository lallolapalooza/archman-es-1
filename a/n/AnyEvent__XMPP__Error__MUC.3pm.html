AnyEvent::XMPP::Error::MUC(3) Documentación aportada por el usuario de Perl AnyEvent::XMPP::Error::MUC(3)

NOMBRE

AnyEvent::XMPP::Error::MUC - Error de MUC

Subclase de AnyEvent::XMPP::Error

MÉTODOS

tipo
Este método devuelve:
timeout_entrada
Si la entrada a la sala tardó demasiado.
formulario_config_no_encontrado
Si la sala de la que solicitamos la configuración no proporcionó un formulario de datos.
cambio_tema_prohibido
Si no está permitido cambiar el tema de una sala.
error_mensaje
Si se trata de un error de mensaje no identificado.

Si se produce un error de presencia, el método "error_presencia" devuelve un objeto AnyEvent::XMPP::Error::Presence con más detalles. Sin embargo, esta clase intenta proporcionar un mapeo para usted (el desarrollador) para aliviar la carga de averiguar qué error significa qué. Para hacer más clara la identificación de los errores con XEP-0045, incluí los códigos de error y los nombres de las condiciones.

Aquí están los tipos más descriptivos:

contraseña_requerida
Entrando a una sala. Informa al usuario que se requiere una contraseña.

(Condición: not-authorized, Código: 401)

baneado
Entrando a una sala. Informa al usuario que ha sido expulsado de la sala.

(Condición: forbidden, Código: 403)

sala_bloqueada
Entrando a una sala. Informa al usuario que la sala no existe y que alguien la está creando actualmente.

(Condición: item-not-found, Código: 404)

sala_no_creable
Entrando a una sala. Informa al usuario que la creación de salas está restringida.

(Condición: not-allowed, Código: 405)

usar_nick_reservado
Entrando a una sala. Informa al usuario que se debe usar el nick reservado de la sala.

(Condición: not-acceptable, Código: 406)

no_esta_en_lista_miembros
Entrando a una sala. Informa al usuario que no está en la lista de miembros.

(Condición: registration-required, Código: 407)

nick_en_uso
Entrando a una sala. Informa al usuario que su nick deseado en la sala está en uso o registrado por otro usuario.

(Condición: conflict, Código: 409)

sala_llena
Entrando a una sala. Informa al usuario que se ha alcanzado el número máximo de usuarios.

(Condición: service-unavailable, Código: 503)

La condición y el código también están disponibles a través del objeto AnyEvent::XMPP::Error::Presence devuelto por "error_presencia", ver más abajo.

texto
Este método devuelve un texto legible por humanos si está disponible.
error_presencia
Devuelve un objeto AnyEvent::XMPP::Error::Presence si este error se origina de un error de este tipo y no de un error interno.
error_mensaje
Devuelve un objeto AnyEvent::XMPP::Error::Message si este error se origina de un error de este tipo y no de un error interno.
