AnyEvent::XMPP::Parser(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Parser(3)

NOMBRE

AnyEvent::XMPP::Parser - Analizador de flujos XML (ayudante para AnyEvent::XMPP)

SINOPSIS

use AnyEvent::XMPP::Parser;
...

DESCRIPCIÓN

Esta es una clase auxiliar de análisis de XMPP XML, que me ayuda a manejar el XMPP XML.

Ver también AnyEvent::XMPP::Writer para una discusión de los problemas con XML en XMPP.

MÉTODOS

new
Esto crea un nuevo AnyEvent::XMPP::Parser y llama a "init".
set_stanza_cb ($cb)
Establece el callback de 'stanza XML'.

$cb debe ser una referencia a código. El primer argumento para el callback será esta instancia de AnyEvent::XMPP::Parser y el segundo será la raíz de las stanza, AnyEvent::XMPP::Node, como primer argumento.

Si el segundo argumento es indefinido, se ha encontrado el final del flujo.

set_error_cb ($cb)
Esto establece el callback de error que se llamará cuando el analizador encuentre un error de sintaxis. El primer argumento es la excepción y el segundo son los datos que causaron el error.
set_stream_cb ($cb)
Este método establece el callback de etiqueta de flujo. Se llama cuando se ha encontrado la etiqueta <stream> del servidor. El primer argumento para el callback es el nodo AnyEvent::XMPP::Node de la etiqueta de flujo de apertura.
init
Este método (re)inicializa el analizador.
cleanup
Este método elimina todos los manejadores. Úsalo para evitar referencias circulares.
nseq ($namespace, $tagname, $cmptag)
Este método comprueba si $cmptag coincide con $tagname en el $namespace.

$cmptag necesita provenir de XML::Parser::Expat, ya que tiene alguna magia adjunta que almacena el espacio de nombres.

feed ($data)
Este método alimenta un trozo de datos sin analizar al analizador.
