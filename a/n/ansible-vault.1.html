NAME

ansible-vault

encrypt and decrypt Ansible files

SYNOPSIS

ansible-vault encrypt FILE [...],

ansible-vault decrypt FILE [...],

ansible-vault rekey FILE [...],

ansible-vault view FILE [...],

ansible-vault edit FILE [...],

ansible-vault lint FILE [...],

ansible-vault encrypt_string STRING [...],

ansible-vault create FILE [...],

ansible-vault remove FILE [...],

ansible-vault list FILE [...],

ansible-vault rotate FILE [...]

DESCRIPTION

The ansible-vault command provides commands to create, encrypt, decrypt, and rekey Ansible variable files, and to edit and view these files.

Ansible Vault is a utility that allows you to keep sensitive data such as passwords, API keys, or certificates in plain text within your Ansible projects without exposing them. It uses symmetric encryption to protect secrets, allowing you to manage encrypted files directly in your version control system.

When encrypting or decrypting files, you will be prompted to enter a vault password. This password is used to encrypt and decrypt the content. It is recommended to use a strong password and manage it securely.

Ansible Vault supports multiple vault IDs, allowing you to use different passwords for different sets of encrypted files. This is useful for managing access to sensitive data within a team or for different environments.

COMMON OPTIONS

--ask-vault-pass
Ask for the vault password interactively.
--vault-password-file FILE
Vault password file.
--vault-id METHOD1[,METHOD2,...]
The vault identifier. Vault identifiers are used to specify different vault passwords for different encrypted files. The identifier can be a label or a file path. For more information, see the Ansible documentation on vault identifiers.
-h, --help
Show a help message and exit.
-v, --verbose
Increase verbosity of output.
-q, --quiet
Suppress output.

ACTIONS

The following actions can be performed with ansible-vault:

encrypt FILE [...], e FILE [...]
Encrypts the specified file(s) in place. The original file is replaced with an encrypted version.
decrypt FILE [...], d FILE [...]
Decrypts the specified file(s) in place. The encrypted file is replaced with a decrypted version.
rekey FILE [...]
Rekey the specified encrypted file(s). This changes the vault password used to encrypt the file(s). You will be prompted for the old password and then for the new password.
view FILE [...]
Decrypts the specified file(s) to standard output without modifying the original file.
edit FILE [...]
Opens the specified file(s) in the default editor (or the editor specified by the ANSIBLE_EDITOR environment variable). After saving and closing the editor, the file is re-encrypted.
lint FILE [...]
Lints the specified encrypted file(s) for potential issues and provides recommendations.
encrypt_string STRING [--name NAME]
Encrypts a string and outputs the result in YAML format. The --name option can be used to specify a name for the encrypted string.
create FILE [...]
Creates a new encrypted file. You will be prompted to enter content and then save it.
remove FILE [...]
Removes the specified file(s) without prompting. Use with caution.
list FILE [...]
Lists the contents of an encrypted file without decrypting it. This is useful for quickly inspecting encrypted variables.
rotate FILE [...]
Rotates the vault password for the specified encrypted file(s). This is similar to `rekey` but may have additional options or behaviors depending on the Ansible version.
