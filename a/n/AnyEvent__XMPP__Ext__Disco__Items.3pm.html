AnyEvent::XMPP::Ext::Disco::Items(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Ext::Disco::Items(3)

NOMBRE

AnyEvent::XMPP::Ext::Disco::Items - Elementos de descubrimiento de servicios

SINOPSIS

DESCRIPCIÓN

Esta clase representa el resultado de una solicitud de elementos de descubrimiento enviada por un manejador de "AnyEvent::XMPP::Ext::Disco".

MÉTODOS

xml_node ()
Devuelve el objeto AnyEvent::XMPP::Node de la consulta IQ.
jid ()
Devuelve el JID al que pertenecen estos elementos.
node ()
Devuelve el nodo al que pertenecen estos elementos (puede ser indefinido).
items ()
Devuelve una lista de referencias a hash que contienen las siguientes claves: 
jid, name, node y xml_node

"jid" contiene el JID del elemento. "name" contiene el nombre del elemento y puede ser indefinido. "node" contiene el ID del nodo del elemento y puede ser indefinido. "xml_node" contiene el objeto AnyEvent::XMPP::Node del elemento para análisis posteriores.

debug_dump ()
Imprime estos elementos en la salida estándar para depuración.
