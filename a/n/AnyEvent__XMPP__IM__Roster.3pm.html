NOMBRE

AnyEvent::XMPP::IM::Roster - Lista de contactos de mensajería instantánea para XMPP

SINOPSIS

my $con = AnyEvent::XMPP::IM::Connection->new (...);
...
my $ro  = $con->roster;
if (my $c = $ro->get_contact ('test@example.com')) {
   $c->make_message ()->add_body ("¡Hola!")->send;
}

DESCRIPCIÓN

Este módulo representa una clase para objetos de lista de contactos que contienen información de contacto.

Gestiona la lista de contactos de un JID conectado por un AnyEvent::XMPP::IM::Connection. También gestiona la información de presencia que se recibe.

Se obtiene la lista de contactos llamando al método "roster" en un objeto AnyEvent::XMPP::IM::Connection. No hay otra manera.

MÉTODOS

is_retrieved
Devuelve verdadero si esta lista de contactos fue obtenida del servidor o falso si esta lista aún no ha sido recuperada.
new_contact ($jid, $name, $groups, $cb)
Este método envía una solicitud de creación de elemento de lista de contactos al servidor. $jid es el JID del contacto. $name es el apodo del contacto, que puede ser undef. $groups debe ser una referencia a un array que contenga los grupos en los que debería estar este contacto.

La función de devolución de llamada en $cb se llamará cuando la creación haya finalizado. El primer argumento será el objeto "AnyEvent::XMPP::IM::Contact" si no ocurrió ningún error. El segundo argumento será un objeto AnyEvent::XMPP::Error::IQ si la solicitud resultó en un error.

Tenga en cuenta que el contacto que se le proporciona en esa función de devolución de llamada puede que aún no esté en la lista de contactos (la llamada a "is_on_roster" aún devuelve un valor falso), si el servidor envió la actualización de la lista de contactos después del resultado iq del conjunto de lista de contactos, así que no confíe en el hecho de que el contacto esté en la lista de contactos.

delete_contact ($jid, $cb)
Este método enviará una solicitud al servidor para eliminar este contacto de la lista de contactos. Resultará en la cancelación de todas las suscripciones.

$cb se llamará cuando la solicitud haya finalizado. El primer argumento para la función de devolución de llamada puede ser un objeto AnyEvent::XMPP::Error::IQ si la solicitud resultó en un error.

get_contact ($jid)
Devuelve el contacto en la lista de contactos con el JID $jid. (Si $jid no está desnudo la parte del recurso será eliminada antes de buscar)

NOTA: Este método también devolverá contactos de los que solo tenemos presencia. Para estar seguro de que el contacto está en la lista de contactos del usuario, necesita llamar al método "is_on_roster" en el contacto.

El valor de retorno es una instancia de AnyEvent::XMPP::IM::Contact.

get_contacts
Devuelve los contactos que están en esta lista de contactos como objetos AnyEvent::XMPP::IM::Contact.

NOTA: Este método solo devuelve los contactos que tienen un elemento en la lista de contactos. Si aún no ha recuperado la lista de contactos, la información de presencia todavía se almacena, pero tiene que obtener los contactos sin un elemento en la lista de contactos con el método "get_contacts_off_roster". Ver abajo.

get_contacts_off_roster
Devuelve los contactos que no están en la lista de contactos pero para los cuales hemos recibido presencia. El valor de retorno es una lista de objetos AnyEvent::XMPP::IM::Contact.

Ver también la documentación del método "get_contacts" de AnyEvent::XMPP::IM::Roster arriba.

get_own_contact
Este método devuelve un objeto AnyEvent::XMPP::IM::Contact que nos representa a nosotros mismos. Se utilizará para realizar un seguimiento de nuestras propias presencias.
debug_dump
Esto imprime la lista de contactos y todos sus contactos y sus presencias.
