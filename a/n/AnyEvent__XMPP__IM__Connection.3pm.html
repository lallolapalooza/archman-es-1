DESCRIPCIÓ

N

Este módulo representa una conexión de mensajería instantánea XMPP y implementa el RFC

3921.

Este módulo es una subclase de "AnyEvent::XMPP::Connection" y hereda todos los métodos. Por ejemplo "reg_cb" y las rutinas de envío de

estrofas.

Para eventos adicionales que se

pueden registrar, consulte más
abajo en la sección EVENTOS.

Este evento se emite cuando se ha recibido una actualización de la lista de contactos. $contacts es una referencia a un array de objetos AnyEvent::XMPP::IM::Contact que han cambiado. Si un contacto fue eliminado, devolverá 'remove' cuando llame al método "subscription" en él.

Este evento se emite cuando la presencia de un contacto ha cambiado. $contact es el objeto AnyEvent::XMPP::IM::Contact cuyo estado de presencia ha cambiado. $old_presence es un objeto AnyEvent::XMPP::IM::Presence que representa la presencia anterior al cambio. $new_presence es un objeto AnyEvent::XMPP::IM::Presence que representa la presencia después del cambio. La nueva presencia podría ser undef si la nueva presencia es
