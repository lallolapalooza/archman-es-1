AnyEvent::Impl::FLTK(3) Documentación de Perl aportada por el usuario AnyEvent::Impl::FLTK(3)

NOMBRE

AnyEvent::Impl::FLTK - Adaptador AnyEvent para FLTK (Fast Light Toolkit versión dos)

SINOPSIS

use AnyEvent;
use FLTK;

# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent. No tienes que hacer nada para que FLTK funcione con AnyEvent, excepto cargar FLTK antes de crear el primer observador de AnyEvent.

Esta implementación no debe confundirse con AnyEvent::Impl::FLTK de Sanko Robinson. Esa implementación está completamente rota y el autor aparentemente no es accesible.

En cualquier caso, FLTK sufre de enfermedades típicas de los kits de herramientas GUI, como O(n) o peor para cada operación (añadir un temporizador, destruir un temporizador, etc.), las enfermedades típicas de la interfaz Perl No Bien Probada, como corrupción de memoria no aleatoria y los problemas típicos del Bucle de Eventos como Postizos, como observadores múltiples en el mismo fd que se sobrescriben silenciosamente entre sí.

No tiene observadores nativos de inactividad, señales o hijos, por lo que todos estos se emulan.

VER TAMBIÉN

AnyEvent, FLTK.
