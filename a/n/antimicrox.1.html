ANTIMICROX(1) Comandos de usuario ANTIMICROX(1)

NOMBRE

AntiMicroX - mapear teclas del teclado y controles del ratón a un gamepad

SINOPSIS

antimicrox [OPCIÓN] [PERFIL]

DESCRIPCIÓN

AntiMicroX es un programa gráfico utilizado para mapear botones del gamepad a teclado, ratón, scripts y macros. Sin embargo, puedes usar este programa para controlar cualquier aplicación de escritorio con un gamepad.

--tray
iniciar el programa solo en la bandeja del sistema
--no-tray
iniciar el programa con el menú de la bandeja deshabilitado
-h, --help
mostrar esta ayuda y salir
-v, --version
mostrar información de la versión y salir
--profile <ubicación>
usar el perfil especificado como predeterminado para los controladores seleccionados. Por defecto se aplica a todos los controladores.
--profile-controller <valor>
aplicar el archivo de configuración a un controlador específico. <valor> puede ser un índice, nombre o GUID del controlador.
--hidden
iniciar el programa sin la ventana principal
--unload [<valor>]
descargar el perfil(es) habilitado(s) actualmente. El valor puede ser un índice, nombre o GUID del controlador.
--startSet <número> [<valor>]
iniciar joysticks en un conjunto específico. El valor puede ser un índice, nombre o GUID del controlador.
--next
avanzar las opciones de carga del perfil.
--log-level {debug,info,warn}
habilitar registro. Predeterminado: warn
-l, --list
imprimir información sobre los joysticks detectados por SDL.
--map <valor>
abrir la ventana de mapeo del controlador de juego del controlador seleccionado. El valor puede ser un índice o GUID del controlador.
--eventgen {xtest,uinput}
elegir entre usar el soporte XTest y el soporte uinput para la generación de eventos. Predeterminado: xtest.
