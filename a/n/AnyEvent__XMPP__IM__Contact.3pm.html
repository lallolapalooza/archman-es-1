AnyEvent::XMPP::IM::Contact(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::IM::Contact(3)

NOMBRE

AnyEvent::XMPP::IM::Contact - Contacto de la lista de contactos de mensajería instantánea

SINOPSIS

my $con = AnyEvent::XMPP::IM::Connection->new (...);
...
my $ro  = $con->roster;
if (my $c = $ro->get_contact ('test@example.com')) {
   $c->make_message ()->add_body ("¡Hola!")->send;
}

DESCRIPCIÓN

Este módulo representa una clase para objetos de contacto que pueblan una lista de contactos (AnyEvent::XMPP::IM::Roster).

Hay dos tipos de 'contactos' que son gestionados por esta clase. El primero son contactos que están en la lista de contactos del usuario, y el segundo son contactos que no están en la lista de contactos del usuario.

Para averiguar si este es un contacto que está realmente disponible como elemento de la lista de contactos en la lista de contactos del usuario, debería consultar el método "is_on_roster" (véase más abajo).

Otro tipo especial de contacto es el contacto que representa a nosotros mismos y que se usa principalmente para hacer un seguimiento de nuestras propias presencias y recursos. Pero tenga en cuenta que incluso si el método "is_me" devuelve true, el método "is_on_roster" también podría devolver un valor verdadero, en caso de que tengamos un elemento de la lista de contactos de nosotros mismos en la lista de contactos (lo cual podría ocurrir en casos raros :).

Puede obtener una instancia de esta clase solo llamando a la función "get_contact" en un objeto de lista de contactos.

MÉTODOS

send_update ($cb, %upd)
Este método actualiza un contacto. Si la solicitud finaliza, llamará a $cb. Si resultó en un error, el primer argumento de esa devolución de llamada será un objeto AnyEvent::XMPP::Error::IQ.

El hash %upd debería tener una de las siguientes claves y define qué partes del contacto actualizar:

name => $name
Actualiza el nombre del contacto. $name = '' borra el contacto.
add_group => $groups
Añade el contacto a los grupos en la referencia de array $groups.
remove_group => $groups
Elimina el contacto de los grupos en la referencia de array $groups.
groups => $groups
Esto establece los grupos del contacto. $groups debería ser una referencia de array de los grupos.
send_subscribe ()
Este método envía a este contacto una solicitud de suscripción.
send_subscribed ()
Este método acepta una solicitud de suscripción de un contacto.
send_unsubscribe ()
Este método envía a este contacto una solicitud de cancelación de suscripción.
send_unsubscribed ()
Este método envía a este contacto una solicitud de cancelación de suscripción que cancela la suscripción de nuestra propia presencia a él (él no recibirá ninguna presencia más de nosotros).
update ($item)
Este método espera un AnyEvent::XMPP::Node en $item que debería ser un elemento de la lista de contactos recibido del servidor. El método actualizará el contacto en consecuencia y se devolverá a sí mismo.
update_presence ($presence)
Este método actualiza la presencia de los contactos en la lista de contactos. $presence debe ser un objeto AnyEvent::XMPP::Node y debería ser un paquete de presencia.
get_presence ($jid)
Este método devuelve una presencia de este contacto si está disponible. El valor de retorno es una instancia de AnyEvent::XMPP::IM::Presence o undef si no existe tal presencia.
get_presences
Devuelve todas las presencias de este contacto en forma de objetos AnyEvent::XMPP::IM::Presence.
get_priority_presence
Devuelve la presencia con la prioridad más alta.
groups
Devuelve la lista de grupos (cadenas) en los que está este contacto.
jid
Devuelve el JID básico de este contacto.
name
Devuelve el (apodo)nombre de este contacto.
is_on_roster ()
Devuelve 1 si este es un contacto que está oficialmente en la lista de contactos y no solo un contacto del que hemos recibido información de presencia.
is_me
Devuelve un valor verdadero cuando este contacto representa a nosotros mismos y solo se usa para recibir presencias de nuestros propios recursos.
subscription
Devuelve el estado de suscripción de este contacto, que puede ser uno de: 
'none', 'to', 'from', 'both'

Si el contacto ya no está en la lista de contactos, este método devuelve:

'remove'
ask
Devuelve 'subscribe' si pedimos a este contacto una suscripción.
subscription_pending
Devuelve true si este contacto tiene una suscripción pendiente. Eso significa: el contacto tiene que confirmar la suscripción.
nickname
Devuelve el apodo de este contacto (o, si no hay ninguno establecido en la lista de contactos, devuelve la parte de nodo del JID)
make_message (%args)
Este método devuelve un objeto AnyEvent::XMPP::IM::Message con el campo to establecido al JID de este contacto.

%args son argumentos adicionales para el constructor de mensajes.
