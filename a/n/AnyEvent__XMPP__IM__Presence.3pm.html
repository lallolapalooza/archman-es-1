NOMBRE

AnyEvent::XMPP::IM::Presence - Presencia XMPP

SINOPSIS

DESCRIPCIÓN

Este módulo representa una presencia XMPP. Almacena el JID completo del contacto, el valor de show, el valor de status y la prioridad.

AnyEvent::XMPP::IM::Presence se deriva de AnyEvent::XMPP::IM::Delayed, utiliza la interfaz descrita allí para averiguar si esta presencia se retrasó.

MÉTODOS

jid
Devuelve el JID completo de esta presencia.
priority
Devuelve la prioridad de esta presencia.
status_all_lang
Devuelve todas las etiquetas de idioma de las descripciones de estado disponibles. Ver también status.
show
Devuelve el valor de show de esta presencia, que es uno de: 
'away', 'chat', 'dnd', 'xa'

o la cadena vacía si la presencia es 'available'.

status ([$lang])
Devuelve la descripción de la presencia. $lang es opcional y debe ser una de las etiquetas devueltas por "status_all_lang".
make_message (%args)
Devuelve un objeto AnyEvent::XMPP::IM::Message con el campo to establecido en el JID completo de esta presencia.

%args son argumentos adicionales para el constructor del mensaje.
