NOMBRE

AnyDBM_File - proporciona un marco para múltiples DBMs

NDBM_File, DB_File, GDBM_File, SDBM_File, ODBM_File - varias implementaciones de DBM

SINOPSIS

use AnyDBM_File;

DESCRIPCIÓN

Este módulo es una "clase base puramente virtual"-- no tiene nada propio. Está ahí solo para heredar de uno de los varios paquetes DBM. Prefiere ndbm por razones de compatibilidad con Perl 4, luego Berkeley DB (Ver DB_File), GDBM, SDBM (que siempre está ahí-- viene con Perl), y finalmente ODBM. De esta manera, los programas antiguos que solían usar NDBM a través de dbmopen() aún pueden hacerlo, pero los nuevos pueden reordenar @ISA:

BEGIN { @AnyDBM_File::ISA = qw(DB_File GDBM_File NDBM_File) }
use AnyDBM_File;

Tener múltiples implementaciones de DBM hace trivial copiar formatos de base de datos:

use Fcntl; use NDBM_File; use DB_File;
tie %newhash,  'DB_File', $new_filename, O_CREAT|O_RDWR;
tie %oldhash,  'NDBM_File', $old_filename, 1, 0;
%newhash = %oldhash;
