AnyEvent::Impl::Glib(3) Documentación de Perl aportada por el usuario AnyEvent::Impl::Glib(3)

NOMBRE

AnyEvent::Impl::Glib - Adaptador de AnyEvent para Glib

SINOPSIS

use AnyEvent;
use Glib;

# este módulo se carga automáticamente según sea necesario

DESCRIPCIÓN

Este módulo proporciona soporte transparente para AnyEvent. No tienes que hacer nada para que Glib funcione con AnyEvent, solo cargar Glib antes de crear el primer observador de AnyEvent.

Glib es probablemente el bucle de eventos más ineficiente que jamás haya visto la luz del mundo: Glib no solo escanea todos sus observadores (realmente, TODOS, ya sean relacionados con E/S, temporizadores o cualquier otra cosa) durante cada iteración del bucle, sino que también lo hace múltiples veces y reconstruye la lista de sondeos para el kernel cada vez, incluso dinámicamente. Afortunadamente, las versiones más recientes de libglib no llaman a malloc/free en cada invocación de observador.

Glib también impone ciertos comportamientos no documentados; por ejemplo, no siempre se pueden eliminar los observadores hijos activos, y las condiciones bajo las cuales es válido hacerlo no están documentadas. Por supuesto, si te equivocas, obtendrás mensajes de "GLib-CRITICAL". Esto hace que sea extremadamente difícil escribir programas de glib "correctos", ya que tienes que estudiar el código fuente para hacerlo bien y esperar que las versiones futuras no cambien ningún aspecto interno.

AnyEvent implementa las soluciones alternativas necesarias, a un pequeño coste de rendimiento.

En el lado positivo, y lo más importante, cuando funciona, Glib generalmente funciona correctamente, no hay quejas al respecto.

Si creas muchos observadores (es decir, más de dos), podrías considerar uno de los módulos Glib::EV, EV::Glib o Glib::Event que mapean Glib a otros bucles de eventos más eficientes.

Este módulo utiliza el contexto de eventos predeterminado de Glib para todos sus observadores.

VER TAMBIÉN
