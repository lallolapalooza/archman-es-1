AnyEvent::XMPP::Node(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Node(3)

NOMBRE

AnyEvent::XMPP::Node - Ayudante de árbol de nodos XML para el analizador.

SINOPSIS

use AnyEvent::XMPP::Node;
...

DESCRIPCIÓN

Esta clase representa un nodo XML. AnyEvent::XMPP normalmente no debería requerir manipular el árbol de análisis, pero a veces es necesario.

Si experimenta alguna necesidad de manipular estos y siente que AnyEvent::XMPP debería encargarse de ello, envíeme un correo electrónico, una solicitud de características o, preferiblemente, ¡un parche!

Cada AnyEvent::XMPP::Node tiene un espacio de nombres, atributos, texto y nodos hijos.

Puede acceder a estos con los siguientes métodos:

MÉTODOS

new ($ns, $el, $attrs, $parser)
Crea un nuevo objeto AnyEvent::XMPP::Node con el nombre de etiqueta del nodo $el en el URI del espacio de nombres $ns y los atributos $attrs. El $parser debe ser la instancia de "AnyEvent::XMPP::Parser" que generó este nodo.
name
El nombre de la etiqueta de este nodo.
namespace
Devuelve el URI del espacio de nombres de este nodo.
eq ($namespace_or_alias, $name) or eq ($node)
Devuelve verdadero si el elemento actual coincide con el nombre de etiqueta $name en los espacios de nombres apuntados por $namespace_or_alias.

Puede pasar un alias definido en AnyEvent::XMPP::Namespaces o pasar un URI de espacio de nombres en $namespace_or_alias. Si no se encuentra ningún alias con el nombre $namespace_or_alias en AnyEvent::XMPP::Namespaces, se interpretará como un URI de espacio de nombres.

El primer argumento para eq también puede ser otra instancia de AnyEvent::XMPP::Node.

eq_ns ($namespace_or_alias) or eq_ns ($node)
Este método devuelve verdadero si el espacio de nombres de esta instancia de AnyEvent::XMPP::Node coincide con el espacio de nombres descrito por $namespace_or_alias o el espacio de nombres del $node, que debe ser otra instancia de AnyEvent::XMPP::Node.

Ver "eq" para el significado de $namespace_or_alias.

attr ($name)
Devuelve el contenido del atributo $name.
add_node ($node)
Añade un sub-nodo al nodo actual.
nodes
Devuelve una lista de sub-nodos.
add_text ($string)
Añade datos de caracteres al nodo actual.
text
Devuelve el texto de este nodo.
find_all (@path)
Este método realiza un descenso recursivo a través de los sub-nodos y recupera todos los nodos que coinciden con el último elemento de @path.

Los elementos de @path consisten en una referencia a un array con dos elementos: la clave del espacio de nombres conocida por el $parser y el nombre de etiqueta que buscamos.

write_on ($writer)
Esto escribe el nodo actual en el objeto AnyEvent::XMPP::Writer en $writer.
as_string ()
Este método devuelve la representación de caracteres original de este elemento XML (y sus nodos hijos). Tenga en cuenta que la cadena es una cadena unicode, lo que significa que para obtener octetos use: 
my $octets = encode ('UTF-8', $node->as_string);

Ahora puede hacer cosas como:

my $libxml = XML::LibXML->new;
my $doc    = $libxml->parse_string (encode ('UTF-8', $node->as_string ()));

(Puede usar su analizador XML favorito :)

append_raw ($string)
Este método es llamado por el analizador para almacenar cadenas originales de este elemento.
to_sax_events ($handler)
Este método toma cualquier cosa que pueda recibir eventos SAX. Ver también XML::GDOME::SAX::Builder o XML::Handler::BuildDOM o XML::LibXML::SAX::Builder.

Con esto, puede convertir este nodo a cualquier estructura DOM de nivel 2 que desee:

my $builder = XML::LibXML::SAX::Builder->new;
$node->to_sax_events ($builder);
my $dom = $builder->result;
print "Canonizado: " . $dom->toStringC14N . "\n";
