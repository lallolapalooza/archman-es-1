AnyEvent::XMPP::Ext::MUC::User(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Ext::MUC::User(3)

NOMBRE

AnyEvent::XMPP::Ext::MUC::User - Clase de usuario

SINOPSIS

DESCRIPCIÓN

Este módulo representa un identificador de usuario (ocupante) para una MUC (Salas de Chat Multi-Usuario). Esta clase deriva de AnyEvent::XMPP::Presence ya que un usuario también tiene una presencia dentro de una sala.

MÉTODOS

new (%args)
nick
El apodo del usuario de la MUC.
affiliation
La afiliación del usuario.
role
El rol del usuario.
room
La sala AnyEvent::XMPP::Ext::MUD::Room en la que se encuentra este usuario.
in_room_jid
El JID local de la sala del usuario.
real_jid
El JID real del usuario; puede ser undef si es una sala anónima.
make_message (%args)
Devuelve un objeto AnyEvent::XMPP::Ext::MUC::Message con el campo 'to' establecido al JID completo de esta presencia.

%args son argumentos adicionales para el constructor del mensaje.

did_create_room
Este método devuelve true si el usuario creó una sala.
