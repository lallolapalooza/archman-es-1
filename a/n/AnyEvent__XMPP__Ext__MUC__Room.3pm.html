NOMBRE

AnyEvent::XMPP::Ext::MUC::Room - Clase de sala

SINOPSIS

DESCRIPCIÓN

Este módulo representa un manejador de sala para un MUC.

MÉTODOS

new (%args)
get_user ($nick)
Este método devuelve el usuario con el apodo $nick en la sala.
get_me
Este método devuelve el objeto AnyEvent::XMPP::Ext::MUC::User de ti mismo en la sala. Devolverá undef si ya no estamos en la sala.
get_user_jid ($jid)
Este método comprueba si existe un usuario con el JID $jid en la sala. Eso significa si la parte de nodo y dominio del JID coinciden con las partes de nodo y dominio de la sala, y la parte de recurso del JID coincide con un apodo unido.
get_users
Este método devuelve la lista de ocupantes como objetos AnyEvent::XMPP::Ext::MUC::User.
make_instant ($cb)
Si acabas de crear una sala puedes crear una sala instantánea con este método en lugar de pasar por la configuración de la sala para una sala reservada.

Si quieres crear una sala reservada en su lugar, no olvides desactivar el argumento "create_instant" del método "join_room" de AnyEvent::XMPP::Ext::MUC!

Ver también el "request_configuration" método más abajo para la configuración de la sala reservada.

$cb es la función de retorno que será llamada cuando la creación de la sala instantánea termine. Si es exitosa, el primer argumento será este objeto de sala ($self), si no es exitosa, el primer argumento será undef y el segundo será un objeto AnyEvent::XMPP::Error::IQ.

request_configuration ($cb)
Este método solicita la configuración de la sala. Cuando llegue el formulario de configuración o un error $cb será llamado. El primer argumento para la función de retorno será un AnyEvent::XMPP::Ext::DataForm con el formulario de configuración de la sala o undef en caso de error. El segundo argumento será un objeto de error AnyEvent::XMPP::Error::MUC si ocurrió un error o undef si no ocurrió ningún error.

Si hiciste un formulario de respuesta puedes enviarlo a través del "send_configuration" método más abajo.

Aquí hay un ejemplo:

$room->request_configuration (sub {
   my ($form, $err) = @_;
   $form or return;
   my $af = AnyEvent::XMPP::Ext::DataForm->new;
   $af->make_answer_form ($form);
   $af->set_field_value ('muc#roomconfig_maxusers', 20);
   $af->clear_empty_fields;
   $roomhdl->send_configuration ($af, sub {
      # ...
   });
});
"send_configuration ($answer_form, $cb)"
Este método envía el formulario de respuesta a una solicitud de configuración a la sala. $answer_form debería ser un objeto AnyEvent::XMPP::Ext::DataForm que contenga el formulario de respuesta con la configuración cambiada.

El primer argumento de $cb será un valor verdadero si el cambio de configuración fue exitoso. El segundo argumento de $cb será un "AnyEvent::XMPP::Error::IQ" objeto si el cambio de configuración no fue exitoso.

make_message (%args)
Este método construye un AnyEvent::XMPP::Ext::MUC::Message con una conexión a esta sala.

%args son argumentos adicionales para el constructor de AnyEvent::XMPP::Ext::MUC::Message. El argumento por defecto "to" para el mensaje es la sala y el "type" será 'groupchat'.

send_part ($msg, $cb, $timeout)
Esto te permite salir de la sala, $msg es un mensaje de salida opcional y puede ser undef si no se debe generar un mensaje personalizado.

$cb se llama cuando salimos de la sala exitosamente o después de $timeout segundos. El valor por defecto para $timeout es 60.

El primer argumento para la llamada de $cb será undef si salimos exitosamente, o un valor verdadero cuando se alcanzó el tiempo de espera. Incluso si se alcanza el tiempo de espera, nos consideramos fuera de la sala (y se genera un evento 'leave').

users
Devuelve una lista de objetos AnyEvent::XMPP::Ext::MUC::User que están en esta sala.
jid
Devuelve el JID simple de esta sala.
nick_jid
Devuelve el JID completo de ti mismo en la sala.
is_connected
Devuelve true si esta sala sigue conectada (pero quizás no unida (aún)).
connection
Si la sala sigue unida, este método devolverá la conexión en la que está conectada la sala.
is_joined
Devuelve true si esta sala sigue unida (y conectada).
change_nick ($newnick)
Este método te permite cambiar tu apodo en esta sala.
change_subject ($newsubject)
Este método cambia el asunto de la sala.
