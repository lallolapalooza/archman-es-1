Extensiones

admitidas

Esta es la lista de extensiones XMPP

admitidas:
XEP-0004 - Formularios de datos (Versión
2.8)
Esta extensión maneja formularios de datos como se describe en XEP-0004. AnyEvent::XMPP::Ext::DataForm le permite construir, recibir y responder formularios de datos. Esto es necesario para todo tipo de cosas en XMPP. Por ejemplo, XEP-0055 (Búsqueda Jabber) o también el registro
in-band.
XEP-0030 - Descubrimiento de servicios (Versión
2.3)
Esta extensión le permite enviar solicitudes de descubrimiento de servicios y definir un conjunto de información descubrible. Véase también AnyEvent::XMPP::Ext::
Disco.
XEP-0054 - vcard-temp (Versión
1.1)
Esta extensión permite la recuperación y el almacenamiento de vcards XMPP como se definen en XEP-0054. Está implementada por AnyEvent::XMPP::Ext::
VCard.
XEP-0066 - Datos fuera de banda (Versión
1.5)
Esta extensión permite recibir y enviar URL de datos fuera de banda y proporciona funciones auxiliares para manejar datos jabber:x:oob. Véase también AnyEvent::XMPP::Ext::
OOB.
XEP-0077 - Registro in-band (Versión
2.2)
Esta extensión le permite registrar nuevas cuentas "in-band". Para más detalles, por favor, eche un vistazo a AnyEvent::XMPP::Ext::
Registration.
XEP-0078 - Autenticación no-SASL (Versión
2.3)
Después de mucho sudor y maldiciones, finalmente implementé la autenticación iq. Desafortunadamente, el XEP-0078 especifica cosas que no están implementadas; de hecho, el único servidor que funcionó fue openfire y psyced.org.

Así que des-analicé la autenticación iq y ahora simplemente escupe el conjunto IQ en el flujo con el nombre de usuario y la

contraseña.

Si insiste en el comportamiento del XEP-0078, habilite la opción "anal_iq_auth" al crear el

flujo.

También puede deshabilitar completamente la au

tenticación iq, bueno, simplemente vea la
documentación de AnyEvent::XMPP::Connection
XEP-0082 - Perfiles de fecha y hora de XMPP (Versión
1.0)
Implementadas algunas funciones para tratar con marcas de tiempo de XMPP, véase AnyEvent::XMPP::Util "to_xmpp_time", "to_xmpp_datetime", "from_xmpp_datetime".

Están destinadas a ser formateadores simpl

es para usted, aún necesitará manej
ar las zonas horarias y demás usted mismo.
XEP-0086 - Mapeos de condiciones de error (Versión
1.0) 
"Un mapeo para permitir que las entidades heredadas manejen correctamente los errores de las entidades que conocen
XMPP."

Esta extensión habilitará el envío de los códigos de error antiguos al generar un error de estrofa con, por ejemplo, el método "write_error_tag" de AnyEvent::XMPP::

Writer.

Además, si solo se proporcionan los códigos numéricos antiguos, la

clase AnyEvent::XMPP::Error::Stanza intenta mapear los código
s numéricos a las nuevas condiciones de error si es posible.
XEP-0091 - Entrega retrasada (Versión
1.3)
Véase también XEP-0203 más
abajo.
XEP-0092 - Versión del software (Versión
1.1)
La capacidad de responder a solicitudes de versión del software, nombre y sistema operativo, y de poder enviar tales solicitudes, está implementada en AnyEvent::XMPP::Ext::
Version.
XEP-0114 - Protocolo de componentes Jabber (Versión
1.5)
Esta extensión le permite conectarse a un servidor como un componente y hace posible implementar servicios como pubsub, muc, o lo que se le ocurra (incluso pasarelas). Véase la documentación de AnyEvent::XMPP::Component y el ejemplo "samples/simple_componen
t".
XEP-0153 - Avatares basados en vCard (Versión
1.0)
Esta extensión permite almacenar y recuperar avatares de vcards. Además de eso, también señalará a otros que usted admite avatares y que estos podrían haber cambiado. Véase AnyEvent::XMPP::Ext::
VCard.
XEP-0199 - Ping de XMPP (Versión
1.0)
Puede enviar solicitudes de ping a otras entidades y también puede responder a ellas. Además, la extensión AnyEvent::XMPP::Ext::Ping implementa un mecanismo de tiempo de espera de conexión basado en
esto.
XEP-0203 - Entrega retrasada (Versión
1.0)
Ambos XEP de entrega retrasada están admitidos y están implementados por AnyEvent::XMPP::IM::Delayed, que es una superclase de AnyEvent::XMPP::IM::Message y AnyEvent::XMPP::IM::Presence.

Si necesita obtener el retraso de estrofas que capturó en un evento, puede usar un objeto AnyEvent::XMPP::IM::Delayed para analizar/obtener el retraso del AnyEvent::XMPP::

Node.

Use las funciones descrita

s anteriormente en el ele
mento XEP-0082 para
decodificar las marcas
de tiempo de los retrasos.
