NOMBRE

AnyEvent::Impl::Cocoa - Adaptador de AnyEvent para Cocoa::EventLoop

SINOPSIS

use AnyEvent;
use Cocoa::EventLoop;

# haz algo

DESCRIPCIÓN

Este módulo proporciona soporte NSRunLoop a AnyEvent.

NSRunLoop es un bucle de eventos para aplicaciones Cocoa, envuelto por Cocoa::EventLoop. Usando este módulo, puedes usar API basadas en Cocoa en tu aplicación AnyEvent, o AnyEvent dentro de aplicaciones Cocoa.

No soporta esperas bloqueantes.

ERRORES

Por ahora, Cocoa::EventLoop (y este módulo) están en una fase temprana de desarrollo y tienen algunas deficiencias y probables errores.

Por ejemplo, parece no haber forma de manejar un solo evento con Cocoa (¿no hay nada que puedan implementar correctamente?), así que este módulo actualmente se activa al menos diez veces por segundo cuando espera eventos. Además, los eventos causados por temporizadores podrían retrasarse hasta 0.1 segundos.
