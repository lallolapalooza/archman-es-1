AnyEvent::I3(3) Documentación de Perl aportada por el usuario AnyEvent::I3(3)

NOMBRE

AnyEvent::I3 - comunicarse con el gestor de ventanas i3

VERSIÓN

Versión 0.19

SINOPSIS

Este módulo se conecta al gestor de ventanas i3 usando la interfaz IPC basada en socket UNIX que proporciona (si está habilitada en el archivo de configuración). Luego puede suscribirse a eventos o enviar mensajes y recibir sus respuestas.

use AnyEvent::I3 qw(:all);
my $i3 = i3();
$i3->connect->recv or die "Error connecting";
say "Connected to i3";
my $workspaces = $i3->message(TYPE_GET_WORKSPACES)->recv;
say "Currently, you use " . @{$workspaces} . " workspaces";

...o, usando los métodos azucarados:

use AnyEvent::I3;
my $workspaces = i3->get_workspaces->recv;
say "Currently, you use " . @{$workspaces} . " workspaces";

Un ejemplo algo más elaborado que vuelca el árbol de diseño de i3 siempre que hay un evento de espacio de trabajo:

use Data::Dumper;
use AnyEvent;
use AnyEvent::I3;
my $i3 = i3();
$i3->connect->recv or die "Error connecting to i3";
$i3->subscribe({
    workspace => sub {
        $i3->get_tree->cb(sub {
            my ($tree) = @_;
            say "tree: " . Dumper($tree);
        });
    }
})->recv->{success} or die "Error subscribing to events";

EXPORTAR

$i3 = i3([ $path ]);

Crea un nuevo "AnyEvent::I3" objeto y lo devuelve.

"path" es una ruta opcional del socket UNIX al que conectarse. Se recomienda encarecidamente NO especificarla a menos que esté absolutamente seguro de que la necesita. "AnyEvent::I3" la determinará automáticamente consultando la instancia de i3 en ejecución en el DISPLAY actual, lo cual es casi siempre lo que desea.

SUBRUTINAS/MÉTODOS

$i3 = AnyEvent::I3->new([ $path ])

Crea un nuevo "AnyEvent::I3" objeto y lo devuelve.

"path" es una ruta opcional del socket UNIX al que conectarse. Se recomienda encarecidamente NO especificarla a menos que esté absolutamente seguro de que la necesita. "AnyEvent::I3" la determinará automáticamente consultando la instancia de i3 en ejecución en el DISPLAY actual, lo cual es casi siempre lo que desea.

$i3->connect

Establece la conexión con i3. Devuelve un "AnyEvent::CondVar" que se activará con un booleano (verdadero si la conexión se estableció) tan pronto como se haya establecido la conexión.

if ($i3->connect->recv) {
    say "Connected to i3";
}

$i3->subscribe(\%callbacks)

Se suscribe a los tipos de eventos dados. Esta función espera una referencia a hash cuya clave sea el nombre del evento y el valor una llamada de retorno.

my %callbacks = (
    workspace => sub { say "Workspaces changed" }
);
if ($i3->subscribe(\%callbacks)->recv->{success}) {
    say "Successfully subscribed";
}

La llamada de retorno especial con el nombre "_error" se invoca cuando la conexión con i3 se interrumpe (probablemente debido a un fallo, salida o reinicio de i3). Puede usarla para imprimir un mensaje apropiado y salir limpiamente o para intentar reconectarse.

my %callbacks = (
    _error => sub {
        my ($msg) = @_;
        say "I am sorry. I am so sorry: $msg";
        exit 1;
    }
);
$i3->subscribe(\%callbacks)->recv;

$i3->message($type, $content)

Envía un mensaje del "type" especificado a i3, posiblemente conteniendo la estructura de datos "content" (o "content", codificado como utf8, si "content" es un escalar), si se especifica.

my $reply = $i3->message(TYPE_RUN_COMMAND, "reload")->recv;
if ($reply->{success}) {
    say "Configuration successfully reloaded";
}

MÉTODOS AZUCARADOS

Estos métodos pretenden hacer que sus scripts sean lo más elegantes posible. Todos ellos establecen automáticamente una conexión bloqueante con i3 (si aún no existe).

get_workspaces

Obtiene los espacios de trabajo actuales de i3.

my $ws = i3->get_workspaces->recv;
say Dumper($ws);

get_outputs

Obtiene las salidas actuales de i3.

my $outs = i3->get_outputs->recv;
say Dumper($outs);

get_tree

Obtiene el árbol de diseño de i3 (>= v4.0).

my $tree = i3->get_tree->recv;
say Dumper($tree);

get_marks

Obtiene todas las marcas de identificación de ventanas de i3 (>= v4.1).

my $marks = i3->get_marks->recv;
say Dumper($marks);

get_bar_config

Obtiene la configuración de la barra para el id de barra específico de i3 (>= v4.1).

my $config = i3->get_bar_config($id)->recv;
say Dumper($config);

get_version

Obtiene la versión de i3 vía IPC, con una alternativa que analiza la salida de i3 --version (para i3 < v4.3).

my $version = i3->get_version()->recv;
say "major: " . $version->{major} . ", minor = " . $version->{minor};

get_config

Obtiene la última configuración leída en bruto de i3. Requiere i3 >= 4.14

send_tick

Envía un evento de tick. Requiere i3 >= 4.15

sync

Envía un evento de sincronización de i3. Requiere i3 >= 4.16

command($content)

Hace que i3 ejecute el comando dado

my $reply = i3->command("reload")->recv;
die "command failed" unless $reply->{success};
