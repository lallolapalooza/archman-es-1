--capture DESCRIPCIÓN Androiddump es una herramienta extcap que proporciona interfaces para capturar desde un dispositivo Android.

Solo hay dos
requisitos:

1.Debe tener el Android SDK y añadirlo a su variable de entorno PATH. PATH debe contener el directorio con herramientas como "adb" y "android". El Android SDK para varias plataformas

está disponible en:

https://developer.android.com/sdk/index.

html#Other
2.Debe tener permiso para capturar desde el dispositivo Android. Algunos dispositivos Android requieren autenticación en pantalla. Interfaces
compatibles:
1.Logcat Main (binario [<=Jelly Bean] o
texto)

2.Logcat System (binario [<=Jelly Bean] o

texto)
3.Logcat Events (binario [<=Jelly Bean] o
texto)
4.Logcat Radio (binario [<=Jelly Bean] o
texto)
5.Logcat Crash (texto; desde
Lollipop)
6.Bluetooth Hcidump [<=Jelly
Bean]
7.Bluetooth Bluedroid External Parser
[Kitkat]
8.Bluetooth BtsnoopNet [>
=Lollipop]
9.WiFi/Ethernet tcpdump [necesita tcpdump en el
teléfono]
Tenga en cuenta que Androiddump también funcionará para FirefoxOS u otros sistemas operativos basados en
Android.
