AnyEvent::XMPP::Ext::Version(3) Documentación de Perl aportada por el usuario AnyEvent::XMPP::Ext::Version(3)

NOMBRE

AnyEvent::XMPP::Ext::Version - Versión del software

SINOPSIS

use AnyEvent::XMPP::Ext::Version;
my $version = AnyEvent::XMPP::Ext::Version->new;
$version->set_name    ("Mi cliente");
$version->set_version ("0.3");
$version->set_os      (`uname -a`);
$disco->enable_feature ($version->disco_feature);

DESCRIPCIÓN

Este módulo define una extensión para proporcionar las capacidades de responder a solicitudes de versión de software y de solicitar la versión de software de otras entidades.

Ver también XEP-0092

Esta clase se deriva de AnyEvent::XMPP::Ext y puede añadirse como extensión a objetos que implementan la interfaz AnyEvent::XMPP::Extendable o que derivan de ella.

MÉTODOS

new (%args)
Crea un nuevo manejador de versión de software.
set_name ($nombre)
Este método establece la cadena de $nombre del software, el valor por defecto es "AnyEvent::XMPP".
set_version ($version)
Este método establece la cadena de $version del software a la que se responde.

El valor por defecto es $AnyEvent::XMPP::VERSION.

set_os ($os)
Este método establece la cadena del sistema operativo $os. Si se pasa undef, se eliminará la cadena.

El valor por defecto es no tener ninguna cadena de sistema operativo.

Puede que quieras pasar algo como esto:

$version->set_os (`uname -s -r -m -o`);
request_version ($con, $dest, $cb)
Este método envía una solicitud de versión a $dest en la conexión $con.

$cb es la función de devolución de llamada que se invocará si ocurre un error o si se recibe el resultado. La función de devolución de llamada también se invocará después del tiempo de espera predeterminado de IQ para la conexión $con. El segundo argumento para la función de devolución de llamada será undef si no se produjo ningún error o un error de AnyEvent::XMPP::Error::IQ. El primer argumento será una referencia a un hash con los siguientes campos:

jid
El JID de la entidad a la que pertenece esta respuesta de versión.
version
La cadena de versión de software de la entidad.
name
El nombre del software de la entidad.
os
El sistema operativo de la entidad, que puede ser indefinido si no se proporcionó ninguno.

Aquí un ejemplo de la estructura de la referencia a hash:

{
   jid     => 'juliet@capulet.com/balcony',
   name    => 'Exodus',
   version => '0.7.0.4',
   os      => 'Windows-XP 5.01.2600',
}
