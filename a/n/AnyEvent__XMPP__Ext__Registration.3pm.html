NOMBRE

AnyEvent::XMPP::Ext::Registration - Maneja todas las tareas de registro en banda

SINOPSIS

my $con = AnyEvent::XMPP::Connection->new (...);
$con->reg_cb (stream_pre_authentication => sub {
   my ($con) = @_;
   my $reg = AnyEvent::XMPP::Ext::Registration->new (connection => $con);
   $reg->send_registration_request (sub {
      my ($reg, $form, $error) = @_;
      if ($error) {
         # manejo de errores
      } else {
         my $af = $form->try_fillout_registration ("tester", "secret");
         $reg->submit_form ($af, sub {
            my ($reg, $ok, $error, $form) = @_;
            if ($ok) { # ¡registro exitoso!
               $con->authenticate
            } else {   # error
               if ($form) { # ¡tenemos un formulario alternativo!
                  # complétalo y envíalo de nuevo con C<submit_form>
               }
            }
         });
      }
   });
   0
});

DESCRIPCIÓN

Este módulo maneja todas las tareas de registro en banda que son posibles y especificadas por XEP-0077. Es principalmente una clase auxiliar que facilita algunas tareas como el envío y la recuperación de un formulario.

MÉTODOS

new (%args)
Este es el constructor para un objeto de registro.
connection
Debe ser un objeto de AnyEvent::XMPP::Connection (o alguna otra subclase de este).

Este argumento es obligatorio.

send_registration_request ($cb)
Este método envía una solicitud de formulario de registro. $cb será llamado cuando llegue el formulario o ocurra un error.

El primer argumento de $cb es siempre $self. Si llegó el formulario, el segundo argumento de $cb será un objeto de AnyEvent::XMPP::Ext::RegisterForm. Si ocurrió un error, el segundo argumento será indefinido y el tercer argumento será un objeto de AnyEvent::XMPP::Error::Register.

Para obtener pistas sobre cómo completar AnyEvent::XMPP::Ext::RegisterForm, consulta XEP-0077. Ya sea que tengas campos de formulario heredados, datos fuera de banda o un formulario de datos.

Ver también try_fillout_registration en AnyEvent::XMPP::Ext::RegisterForm.

send_unregistration_request ($cb)
Este método envía una solicitud de anulación de registro.

Para la descripción de la semántica del callback en $cb, consulta la descripción del método "submit_form" a continuación.

send_password_change_request ($username, $password, $cb)
Este método envía una solicitud de cambio de contraseña para el usuario $username con la nueva contraseña $password.

Para la descripción de la semántica del callback en $cb, consulta la descripción del método "submit_form" a continuación.

submit_form ($form, $cb)
Este método envía el $form, que debe ser de tipo AnyEvent::XMPP::Ext::RegisterForm y debe ser un formulario de respuesta.

$con es la conexión en la que se enviará este formulario.

$cb es el callback que se llamará una vez que el formulario haya sido enviado y se haya recibido éxito o error. El primer argumento para el callback será el objeto AnyEvent::XMPP::Ext::Registration, el segundo será un valor booleano que es verdadero cuando el formulario se transmitió con éxito y todo está bien. Si el segundo argumento es falso, el tercer argumento es un objeto AnyEvent::XMPP::Error::Register. Si el error contenía un formulario de datos que es necesario para realizar la solicitud con éxito, entonces el cuarto argumento será un objeto AnyEvent::XMPP::Ext::RegisterForm que debes completar y enviar de nuevo con "submit_form".

Para la semántica de dicho formulario de error, consulta también XEP-0077.
