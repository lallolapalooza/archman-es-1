DESCRIPCIÓ

N

Antiword es una aplicación que muestra el texto y las imágenes de documentos de Microsoft Word.
Un archivo llamado - representa un documento de Word leído de la entrada estándar.
Solo se admiten documentos

creados con MS Word versión
2 y versión 6 o posterior.

ARCHIVO

S
Archivos de mapeo como 8859-1.
txt

Antiword busca sus archivos de mapeo en tres directorios, en el orden indicado:
(1) El directorio especificado por $ANTIWORDHOME
(2) El directorio especificado por $HOME/.antiword
(3) El directorio /usr/share/antiw
ord
El archivo
fontnames

Antiword buscará su archivo de nombres de fuentes en los mismos directorios que se usan para los archivos de mapeo.
El archivo fontnames contiene la tabla de traducción de los nombres de fuentes usados por MS Word a los nombres de fuentes usados por
PostScript.
NOT
A:

Antiword no puede distinguir
entre un archivo que no exis
te y un archivo que no
se puede abrir para lectura.

ENTORN

O

Antiword usa la variable de entorno ``ANTIWORDHOME'' como primer directorio para buscar sus archivos. Antiword usa la variable de entorno ``HOME'' para encontrar el directorio personal del usuario. Cuando está en modo texto, usa la variable ``COLUMNS'' para establecer el ancho de la salida (a menos que se anule con la opción -w)

.

Antiword usa las variables de entorno ``LC_ALL'', ``LC_CTYPE'' y ``LANG'

' (en ese orden) para obtener la configuración regional (locale) actual y u
sa esta información para seleccionar el archivo de mapeo predeterminado.

s aún no se muestran. Algunas de las imágenes que se muestran, se muestran en el lug
ar equivocado. La salida PostScript solo está disponible en ISO 8859-1 y ISO 8859-2.
