afInitAESChannelData(3)

AFINITAESCHANNELDATA(3)   AFINITAESCHANNELDATA(3)

NOMBRE

afInitAESChannelDataTo, afInitAESChannelData - inicializa datos no audio AES en una configuración de archivo de audio

SINOPSIS

#include <audiofile.h>
void afInitAESChannelDataTo(AFfilesetup setup, int track, int willHaveData);
void afInitAESChannelData(AFfilesetup setup, int track);

PARÁMETROS

setup es una configuración de archivo válida devuelta por afNewFileSetup(3).

track especifica una pista dentro de la configuración del archivo de audio. track es siempre AF_DEFAULT_TRACK para todos los formatos de archivo actualmente soportados.

willHaveData es un entero de valor booleano que indica si habrá datos no audio AES presentes.

DESCRIPCIÓN

Dada una estructura AFfilesetup creada con afNewFileSetup(3) y una pista identificada por track (AF_DEFAULT_TRACK para todos los formatos de archivo actualmente soportados), afInitAESChannelDataTo inicializa la pista para contener o no contener datos no audio AES. afInitAESChannelData se comporta de manera similar pero siempre inicializa la pista para contener datos no audio AES.

Actualmente, solo los formatos de archivo AIFF y AIFF-C pueden almacenar datos no audio AES; estos datos se ignoran en todos los demás formatos de archivo.

ERRORES

afInitAESChannelDataTo y afInitAESChannelData pueden producir los siguientes errores:

AF_BAD_FILESETUP

setup representa una configuración de archivo inválida.

AF_BAD_TRACKID

track representa un identificador de pista inválido.

VER TAMBIÉN

afNewFileSetup(3)
