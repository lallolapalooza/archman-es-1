NOMBRE

afWriteFrames - escribe fotogramas de muestra en una pista de un archivo de audio

SINOPSIS

#include <audiofile.h>
AFframecount afWriteFrames(AFfilehandle file, int track, const void *data,
    AFframecount count);

DESCRIPCIÓN

afWriteFrames intenta escribir hasta count fotogramas de datos de audio desde el búfer data al manejador de archivos de audio file.

PARÁMETROS

file es un manejador de archivo válido devuelto por afOpenFile(3).

track es siempre AF_DEFAULT_TRACK para todos los formatos de archivo actualmente soportados.

data es un búfer de fotogramas de muestra que se escribirán en el archivo.

count es el número de fotogramas de muestra que se escribirán.

VALOR DE RETORNO

afWriteFrames devuelve el número de fotogramas de muestra escritos con éxito en file.

ERRORES

afWriteFrames puede producir los siguientes errores:

AF_BAD_FILEHANDLE

el manejador de archivo no era válido

AF_BAD_TRACKID

la pista no es AF_DEFAULT_TRACK

AF_BAD_WRITE

falló la escritura de datos de audio en el archivo

AF_BAD_LSEEK

falló la búsqueda dentro del archivo

VER TAMBIÉN

afReadFrames(3)
