NOMBRE

afpcmd - Transfiere archivos a través de la red utilizando el Apple Filing Protocol (AFP)

SINOPSIS

afpcmd [-r [url afp]

DESCRIPCION

afpcmd es una herramienta de línea de comandos para ayudar a transferir archivos hacia y desde un servidor usando AFP. Típicamente, esto es Netatalk o Mac OS o Mac OS X.

Esto se puede hacer como un usuario no root. Ofrece una línea de comandos interactiva (como un cliente FTP tradicional) o para recuperaciones por lotes.

No confundir con las herramientas de montaje FUSE (mount_afp, afpfsd, afp_client), que ofrecen la capacidad de montar un sistema de archivos completo.

OPCIONES

-r establece el indicador recursivo.

url afp utiliza el formato de URL AFP estándar.

SOPORTE DE VERSIÓN AFP

Consulte la documentación de afpfs-ng para obtener más información sobre la compatibilidad con versiones específicas de AFP.

MODO POR LOTES

Las transferencias de archivos por lotes se pueden realizar de una de estas dos maneras:

afpcmd -r [url afp al directorio]

Esto realiza una transferencia recursiva de todos los subdirectorios y archivos localmente.

afpcmd [url afp al archivo]

Esto transfiere solo el archivo localmente.

Después de que cualquiera de estas opciones termine, el comando sale.

MODO INTERACTIVO

Si se proporciona una URL en la línea de comandos, afpcmd se conecta y entra en el volumen y directorio especificados.

Se habilitan las pulsaciones de teclas estándar de readline. Se proporciona autocompletado de línea de comandos (usando tab) e historial (usando las flechas arriba y abajo). Se habilita el autocompletado de nombres de archivo locales.

Comandos más comunes

connect <URL afp>: Conéctate al servidor, cambia al volumen y directorio

cd: Cambia de directorio en el servidor

get <nombre de archivo>: recupera el archivo

get -r <directorio>: Recupera recursivamente el directorio

put <nombre de archivo>: Sube el archivo

quit: Sale

Comandos de conexión/desconexión

disconnect: Desconéctate del servidor actual

passwd: Solicita una nueva contraseña sin mostrarla en pantalla

user <usuario>: Establece el usuario

passwd: cambia la contraseña en el servidor. No funciona.

Comandos de directorio remoto

pwd: Muestra el directorio actual en el servidor

mkdir <directorio>: crea un nuevo directorio

rmdir <directorio: elimina un directorio

ls o dir: muestra los archivos en el directorio actual

Comandos de archivos remotos

mv o rename archivo_antiguo archivo_nuevo: Renombra <archivo antiguo> a <archivo nuevo>

touch <nombre de archivo>: Crea un archivo en blanco

view <nombre de archivo>: Muestra el archivo

chmod: <archivo> <modo>: Cambia el modo de un archivo en el servidor

delete o rm: <archivo>: Elimina el archivo del servidor

Comandos de estado

status: Muestra el estado de la conexión y detalles. Para depuración.

df: Muestra el tamaño del disco y los bloques disponibles.

Comandos locales

lpwd: Muestra el directorio local actual

lcd: Cambia el directorio local

Otros comandos

help o ?: muestra ayuda

testafp: varias pruebas para desarrolladores

URL AFP

Un uso típico de afpcmd es:

afpcmd afp://usuario:contraseña@nombre_servidor/volumen

La sintaxis completa de una URL es:

afp://usuario;AUTH=tipo_autenticación:contraseña@servidor:puerto/volumen/ruta

Si se proporciona una contraseña de "-", se le pedirá al usuario una contraseña.

REPORTE DE ERRORES

Reporte errores a la lista de correo afpfs-ng-devel@sf.net.
