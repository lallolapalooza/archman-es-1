NOMBRE

afl-plot

SINOPSIS

afl-plot [ -g | --graphical ] directorio_estado_afl directorio_salida_grafico

OPCIONES

Este programa genera imágenes de gnuplot a partir de datos de salida de afl-fuzz.
Uso:
    directorio_estado_afl    debe apuntar a un directorio de estado existente para
                             cualquier instancia activa o detenida de afl-fuzz
    directorio_salida_grafico    debe apuntar a un directorio vacío donde esta
                             herramienta pueda escribir los gráficos resultantes
    -g, --graphical     (opcional) muestra los gráficos en una ventana gráfica
                        (deberías haber construido afl-plot-ui para usar esta opción)
El programa colocará index.html y tres imágenes PNG en el directorio de salida;
deberías poder verlo con cualquier navegador web de tu elección.
