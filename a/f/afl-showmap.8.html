afl-showmap(8) Manual del Administrador del Sistema afl-showmap(8)

NOMBRE

afl-showmap

SINOPSIS

afl-showmap [ opciones ] -- /ruta/a/la_aplicacion_objetivo [ ... ]

OPCIONES

Parámetros requeridos:
  -o archivo    - archivo al que escribir los datos de rastreo
Configuración de control de ejecución:
  -t mseg       - tiempo de espera para cada ejecución (predeterminado: 1000ms)
  -m megs       - límite de memoria para el proceso hijo (predeterminado: ninguno)
  -O            - usar instrumentación solo binaria (modo FRIDA)
  -Q            - usar instrumentación solo binaria (modo QEMU)
  -U            - usar instrumentación basada en Unicorn (modo Unicorn)
  -W            - usar instrumentación basada en qemu con Wine (modo Wine)
                (No es necesario, aquí por consistencia con otras herramientas afl-*)
  -X            - usar modo Nyx
Otras configuraciones:
  -i dir        - procesar todos los archivos debajo de este directorio, debe combinarse con -o.
                Con -C, -o es un archivo, sin -C debe ser un directorio
                y cada mapa de bits se escribirá allí individualmente.
  -I filelist   - alternativamente a -i, -I es una lista de archivos
  -C            - recopilar cobertura, escribe todos los bordes a -o y da un resumen
                Debe combinarse con -i.
  -q            - descartar la salida del programa y no mostrar mensajes
  -e            - mostrar solo la cobertura de bordes, ignorar los recuentos de aciertos
  -r            - mostrar valores de tupla reales en lugar de valores de filtro AFL
  -s            - no clasificar el mapa
  -c            - permitir volcados de núcleo
Esta herramienta muestra datos de tupla crudos capturados por la instrumentación AFL.
Para obtener ayuda adicional, consulta docs/README.md.
Si usas el modo -i/-I, entonces la funcionalidad de mutación personalizada post_process
send send es compatible.
Variables de entorno utilizadas:
LD_BIND_LAZY: no establecer la variable de entorno LD_BIND_NOW para el objetivo
AFL_CMIN_CRASHES_ONLY: (modo cmin) escribir tuplas solo para entradas que causan fallos
AFL_CMIN_ALLOW_ANY: (modo cmin) escribir tuplas para entradas que causan fallos también
AFL_CRASH_EXITCODE: código de salida opcional del hijo a interpretar como fallo
AFL_DEBUG: habilitar salida adicional para desarrolladores
AFL_FORKSRV_INIT_TMOUT: tiempo de espera para el forkserver durante el inicio (en milisegundos)
AFL_KILL_SIGNAL: ID de señal entregada a los procesos hijos en caso de tiempo de espera, etc.
                 (predeterminado: SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: Señal de terminación para el servidor de bifurcación al terminar
                             (predeterminado: SIGTERM). Si no está establecido y AFL_KILL_SIGNAL
                             está establecido, se usará ese valor.
AFL_MAP_SIZE: el tamaño de memoria compartida para ese objetivo. debe ser >= el tamaño para
              el que se compiló el objetivo
AFL_PRELOAD: configuración de LD_PRELOAD / DYLD_INSERT_LIBRARIES para el objetivo
AFL_PRINT_FILENAMES: Imprimir la entrada de cola que se está procesando actualmente en stdout
AFL_QUIET: no imprimir salida informativa adicional
AFL_NO_FORKSRV: ejecutar el objetivo a través de execve en lugar de usar el forkserver
