AFQUERY(3)   AFQUERY(3)

NOMBRE

afQuery, afQueryLong, afQueryDouble, afQueryPointer - consultar las capacidades de la Biblioteca de Archivos de Audio

SINOPSIS

#include <audiofile.h>
AUpvlist afQuery (int querytype, int arg1, int arg2, int arg3, int arg4);
long afQueryLong (int querytype, int arg1, int arg2, int arg3, int arg4);
double afQueryDouble (int querytype, int arg1, int arg2, int arg3,
    int arg4);
void *afQueryPointer (int querytype, int arg1, int arg2, int arg3,
    int arg4);

PARÁMETROS

querytype puede ser uno de los siguientes:

• AF_QUERYTYPE_FILEFMT
• AF_QUERYTYPE_INST
• AF_QUERYTYPE_INSTPARAM
• AF_QUERYTYPE_COMPRESSION
• AF_QUERYTYPE_COMPRESSIONPARAM
• AF_QUERYTYPE_MISC
• AF_QUERYTYPE_MARK
• AF_QUERYTYPE_LOOP

arg1, arg2, arg3 y arg4 son selectores enteros cuyo significado depende de querytype.

VALOR DE RETORNO

En caso de éxito, afQuery devolverá un valor AUpvlist no nulo. En caso de fallo, afQuery devolverá nulo, mientras que afQueryLong y afQueryDouble devolverán -1 y afQueryPointer devolverá nulo.

Los punteros que representan cadenas de caracteres son propiedad de la Biblioteca de Archivos de Audio y no deben ser liberados; todos los demás valores de puntero deben ser liberados por el llamador.

DESCRIPCIÓN

Para AF_QUERYTYPE_FILEFMT, los siguientes selectores son valores válidos para arg1:

AF_QUERY_LABEL

Solicita una cadena de etiqueta corta para el formato (por ejemplo, "aiff").

AF_QUERY_NAME

Solicita un nombre corto para el formato (por ejemplo, "MS RIFF WAVE").

AF_QUERY_DESC

Solicita un nombre descriptivo para el formato (por ejemplo, "Audio Interchange File Format").

AF_QUERY_IMPLEMENTED

Solicita un valor booleano que indica si el formato está implementado para lectura y escritura en la Biblioteca de Archivos de Audio.

AF_QUERY_ID_COUNT

Solicita el número total de formatos implementados.

AF_QUERY_IDS

Solicita una matriz de enteros con los valores de token de identificación de todos los formatos de archivo implementados.

AF_QUERY_COMPRESSION_TYPES

Utilizado con el selector AF_QUERY_VALUE_COUNT en arg2, devolverá un entero largo que contiene el número de esquemas de compresión disponibles para su uso dentro del formato especificado en arg3. Utilizado con el selector AF_QUERY_VALUES, devuelve un puntero a una matriz de enteros que contiene los valores de identificación de compresión de los esquemas de compresión compatibles con el formato especificado en arg3.

AF_QUERY_SAMPLE_FORMATS

Utilizado con el selector AF_QUERY_DEFAULT en arg2, devolverá el formato de muestra predeterminado para el formato de archivo especificado en arg3.

AF_QUERY_SAMPLE_SIZES

Utilizado con el selector AF_QUERY_DEFAULT en arg2, devolverá el ancho de muestra predeterminado para el formato de archivo especificado en arg3.

Para AF_QUERYTYPE_INST, los siguientes selectores son válidos para arg1:

AF_QUERY_SUPPORTED

Solicita un valor booleano que indica si el formato de archivo en arg2 admite instrumentos.

AF_QUERY_MAX_NUMBER

Solicita un valor entero que indica el número máximo de instrumentos compatibles con el formato de archivo en arg2.

Para AF_QUERYTYPE_INSTPARAM, los siguientes selectores son válidos para arg1:

AF_QUERY_SUPPORTED

Solicita un valor booleano que indica si el formato de archivo en arg2 admite parámetros de instrumento.

AF_QUERY_ID_COUNT

Solicita un valor entero que indica el número de parámetros de instrumento compatibles con el formato de archivo en arg2.

AF_QUERY_IDS

Solicita una matriz de enteros que contiene los valores de parámetro de instrumento para el formato de archivo en arg2.

AF_QUERY_TYPE

Para el formato de archivo en arg2, solicita el tipo del parámetro de instrumento en arg3.

AF_QUERY_NAME

Para el formato de archivo en arg2, solicita el nombre del parámetro de instrumento en arg3.

AF_QUERY_DEFAULT

Para el formato de archivo en arg2, solicita el valor predeterminado del parámetro de instrumento en arg3.

ERRORES

afQuery puede producir los siguientes errores:

AF_BAD_QUERYTYPE

El tipo de consulta no es compatible.

AF_BAD_QUERY

Los argumentos de la consulta son incorrectos.
