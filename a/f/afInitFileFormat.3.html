AFINITFILEFORMAT(3)   AFINITFILEFORMAT(3)

NOMBRE

afInitFileFormat - inicializa el formato de archivo de una configuración de archivo de audio

SINOPSIS

#include <audiofile.h>
void afInitFileFormat(AFfilesetup setup, int fileFormat);

PARÁMETROS

setup es una configuración de archivo válida creada por afNewFileSetup(3).

fileFormat es una constante entera que especifica un formato de archivo.

DESCRIPCIÓN

Dada una estructura AFfilesetup creada con afNewFileSetup(3), afInitFileFormat inicializa el formato de archivo al especificado por fileFormat.

Actualmente se soportan los siguientes formatos de archivo:

AF_FILE_RAWDATA

datos de audio sin procesar

AF_FILE_AIFF

Formato de archivo de audio Interchange File Format

AF_FILE_AIFFC

Formato de archivo de audio Interchange File Format AIFF-C

AF_FILE_NEXTSND

NeXT .snd/Sun .au

AF_FILE_WAVE

Microsoft RIFF WAVE

AF_FILE_BICSF

Berkeley/IRCAM/CARL Sound File

AF_FILE_AVR

Audio Visual Research

AF_FILE_IFF_8SVX

Amiga IFF/8SVX

AF_FILE_SAMPLEVISION

Sample Vision

AF_FILE_VOC

Creative Voice File

AF_FILE_NIST_SPHERE

NIST SPHERE

AF_FILE_CAF

Core Audio Format

ERRORES

afInitFileFormat puede producir los siguientes errores:

AF_BAD_FILESETUP

setup representa una configuración de archivo no válida.

AF_BAD_FILEFMT

fileFormat representa un formato de archivo desconocido.

AF_BAD_NOT_IMPLEMENTED

fileFormat representa un formato de archivo que no está implementado actualmente.

VER TAMBIÉN

afNewFileSetup(3)
