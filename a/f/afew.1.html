NOMBRE

afew - Documentación de afew

afew es un script de etiquetado inicial para notmuch mail:

  • http://notmuchmail.org/
  • http://notmuchmail.org/initial_tagging/

Su tarea básica es proporcionar etiquetado automático cada vez que se registra nuevo correo con notmuch. En una configuración clásica, podría llamarlo después de notmuch new en un hook de post-sincronización de offlineimap o en el hook post-new de notmuch.

Puede hacer cosas básicas como añadir etiquetas basadas en encabezados de correo o carpetas maildir, manejando hilos eliminados y spam.

Para su información: afew funciona bien con alot, una GUI para notmuch mail ;)

•
https://github.com/pazz/alot

INICIO RÁPIDO

Los pasos para ponerlo en marcha son:

  • instalar el paquete afew
  • crear los archivos de configuración
  • añadir un hook post-new de notmuch que llame a afew

Instalar

Los siguientes comandos le pondrán en marcha en sistemas Debian/Ubuntu:

$ sudo aptitude install notmuch python-notmuch dbacl
$ git clone git://github.com/teythoon/afew.git
$ cd afew
$ python setup.py install --prefix=~/.local

Asegúrese de que ~/.local/bin está en su PATH. Una forma es añadir lo siguiente a su ~/.bashrc:

if [ -d ~/.local/bin ]; then
    PATH=$PATH:~/.local/bin
fi

Consulte INSTALACIÓN para una guía más detallada.

Configuración Inicial

Asegúrese de que ~/.notmuch-config dice:

[new]
tags=new

Ponga una lista de filtros en ~/.config/afew/config:

# Esta es la cadena de filtros predeterminada
[SpamFilter]
[KillThreadsFilter]
[ListMailsFilter]
[ArchiveSentMailsFilter]
[InboxFilter]

Y cree un hook post-new para que notmuch llame a afew:

$ notmuchdir=ruta/a/maildir/.notmuch
$ mkdir -p "$notmuchdir/hooks"
$ printf > "$notmuchdir/hooks/post-new" '#!/usr/bin/env sh\n$HOME/.local/bin/afew --tag --new\n'
$ chmod u+x "$notmuchdir/hooks/post-new"

Siguientes Pasos

Puede:

  • añadir Filtros adicionales para un filtrado más personalizado
  • hacer uso del Modo de Movimiento para mover su correo entre carpetas
  • ejecutar afew contra todo su correo antiguo ejecutando afew --tag --all
  • empezar a Extender afew

INSTALACIÓN

Requisitos

afew funciona con python 3.6+ y requiere notmuch y sus bindings de python. En sistemas Debian/Ubuntu puede instalarlos haciendo:

$ sudo aptitude install notmuch python-notmuch python-dev python-setuptools

Nota: si está instalando notmuch usando Homebrew en macOS, asegúrese de ejecutar $ brew install --with-python3 notmuch, porque la fórmula de brew no instala bindings de python3 de notmuch por defecto.

Instalación sin privilegios

Se recomienda instalar afew en sí mismo dentro de un virtualenv como un usuario sin privilegios, ya sea revisando el código fuente e instalando vía setup.py, o vía pip.

# crear y activar virtualenv
$ python -m venv --system-site-packages .venv
$ source .venv/bin/activate
# instalar vía pip desde PyPI:
$ pip install afew
# o instalar desde la fuente:
$ python setup.py install --prefix=~/.local

Es posible que desee crear un enlace simbólico de .venv/bin/afew en algún lugar dentro de su PATH (en `~bin/` en este caso):

$ ln -snr .venv/bin/afew ~/.bin/afew

Construir la documentación

La documentación se puede construir en varios formatos usando Sphinx:

# construir documentación en build/sphinx/{html,man}
$ python setup.py build_sphinx -b html,man

USO DE LA LÍNEA DE COMANDOS

En última instancia, afew es una herramienta de línea de comandos. Debe especificar una acción y si actuar sobre todos los mensajes o solo sobre los mensajes nuevos. Las acciones entre las que puede elegir son:

tag
ejecutar los filtros de etiquetas. Consulte Etiquetado inicial.
watch
monitorizar continuamente el buzón de correo en busca de archivos nuevos
move-mails
mover archivos de correo entre carpetas maildir

Etiquetado inicial

Las tareas básicas de etiquetado no requieren configuración, simplemente ejecute

$ afew --tag --new
# o para etiquetar *todos* los mensajes
$ afew --tag --all

Para hacer esto automáticamente, puede añadir el siguiente hook en su ~/.offlineimaprc:

postsynchook = ionice -c 3 chrt --idle 0 /bin/sh -c "notmuch new && afew --tag --new"

Hay mucho más que decir sobre la Configuración general de filtros y los diferentes Filtros proporcionados por afew.

Simulación

Añadir --dry-run a cualquier acción --tag o --sync-tags evita la modificación de la base de datos de notmuch. Añada algo de -vv para ver algo de acción.

Modo de Movimiento

Para invocar afew en modo de movimiento, proporcione la opción --move-mails en la línea de comandos. El modo de movimiento respetará --dry-run, así que incluya --verbose y observe qué efectos tendría una ejecución real.

En modo de movimiento, afew revisará todos los correos (o solo los recientes) en las carpetas maildir configuradas, decidiendo si deben ser movidos a otra carpeta.

La decisión se basa en reglas definidas en su archivo de configuración. Una regla está vinculada a una carpeta de origen y especifica una carpeta de destino a la que se moverá un correo que coincida con una consulta asociada.

De esta manera podrá transferir sus principios de clasificación aproximadamente a la estructura clásica de carpetas maildir entendida por su servidor de correo tradicional. Etiquete sus correos con notmuch, llame a afew --move-mails en un hook pre-sincronización de offlineimap y disfrute de una bandeja de entrada limpia en su interfaz web/cliente GUI en el trabajo.

Tenga en cuenta que en modo de movimiento, afew llama a notmuch new después de mover correos. Puede usar afew -m --notmuch-args=--no-hooks en un hook pre-new de notmuch para evitar bucles.

Para obtener información sobre cómo configurar reglas para el modo de movimiento, qué puede hacer con él y qué no, consulte Modo de Movimiento.

NAME

afew - Una aplicación para organizar correos electrónicos con filtros.

INICIO RÁPIDO

Para empezar, solo necesitas ejecutar el comando afew. Si es la primera vez que lo ejecutas, creará un archivo de configuración en ~/.config/afew/config. Si ya tienes un archivo de configuración, afew intentará aplicar todos los filtros definidos en tu archivo ~/.config/afew/config a tus correos electrónicos no leídos.

Después de ejecutar afew, es posible que necesites ejecutar un cliente de correo electrónico para ver los cambios.

INSTALACIÓN

afew se puede instalar desde los repositorios oficiales de Arch Linux.

sudo pacman -S afew

USO DE LA LÍNEA DE COMANDOS

La forma más sencilla de usar afew es simplemente ejecutar el comando afew en tu terminal. Esto aplicará los filtros definidos en tu archivo de configuración a tus correos electrónicos no leídos.

También puedes pasar argumentos a afew para modificar su comportamiento:

  • --dry-run: Simula la ejecución de los filtros sin realizar ningún cambio real en tus correos electrónicos.
  • --force: Fuerza la aplicación de los filtros, incluso si ya se han aplicado previamente.
  • --help: Muestra la ayuda y las opciones disponibles.
  • --version: Muestra la versión de afew.

CONFIGURACIÓN

El archivo de configuración principal de afew se encuentra en ~/.config/afew/config. Este archivo está escrito en Python y te permite definir tus propios filtros y acciones.

Aquí tienes un ejemplo básico de un archivo de configuración:

# ~/.config/afew/config

# Define los filtros aquí. Cada filtro es una tupla que contiene:
# 1. El nombre del filtro (un string opcional).
# 2. Una expresión de búsqueda de Maildir (un string).
# 3. Una lista de acciones a realizar.

filters = [
    ('Leer correos de Arch Linux', 'from:archlinux.org AND subject:news', ['set_flags(Seen)']),
    ('Mover correos de spam', 'subject:spam OR from:spammer.com', ['move("Junk")']),
    ('Archivar correos antiguos', 'before:2023/01/01', ['move("Archive/2023")']),
]

# Acciones disponibles:
# - set_flags(*flags): Establece las banderas de correo electrónico (ej. Seen, Flagged).
# - unset_flags(*flags): Elimina las banderas de correo electrónico.
# - move(folder): Mueve el correo electrónico a la carpeta especificada.
# - delete(): Elimina el correo electrónico.
# - mark_as_read(): Marca el correo electrónico como leído.
# - mark_as_unread(): Marca el correo electrónico como no leído.
# - custom_action(function): Ejecuta una función de Python personalizada.

Puedes encontrar más detalles sobre la configuración y las acciones disponibles en la documentación oficial de afew.

FILTROS

Los filtros son la parte central de afew. Te permiten definir criterios para seleccionar correos electrónicos y luego realizar acciones sobre ellos. Los criterios se basan en las expresiones de búsqueda de Maildir, que son similares a las usadas en otros clientes de correo electrónico como Mutt.

Algunos ejemplos de criterios de búsqueda:

  • from:nombre@dominio.com: Busca correos enviados desde una dirección específica.
  • subject:asunto: Busca correos con un asunto específico.
  • seen: Busca correos marcados como leídos.
  • before:YYYY/MM/DD: Busca correos anteriores a una fecha determinada.
  • older_than:Xd: Busca correos más antiguos que X días.

Puedes combinar múltiples criterios usando AND y OR.

MODO DE MOVIMIENTO

El modo de movimiento de afew te permite mover correos electrónicos de una carpeta a otra basándose en tus filtros. Esto es útil para organizar automáticamente tu bandeja de entrada.

Por ejemplo, puedes configurar un filtro para mover todos los correos de un remitente específico a una carpeta dedicada.

EXTENSIÓN DE AFEW

afew es extensible a través de funciones de Python personalizadas. Puedes definir tus propias funciones en tu archivo de configuración y usarlas como acciones de filtro.

Esto te da una gran flexibilidad para implementar lógica de organización de correos electrónicos compleja.

IMPLEMENTACIÓN

afew está escrito en Python y utiliza la biblioteca email para procesar los correos electrónicos. Se integra bien con los sistemas de correo electrónico que utilizan el formato Maildir.
