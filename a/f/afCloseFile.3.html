NOMBRE

afCloseFile - cierra un archivo de audio abierto

SINOPSIS

#include <audiofile.h>
int afCloseFile(AFfilehandle file);

PARÁMETROS

file es un manejador de archivo válido creado por afOpenFile(3).

DESCRIPCIÓN

afCloseFile cierra el archivo de audio file, actualizando el archivo si se abrió para escritura.

VALOR DE RETORNO

afCloseFile devuelve 0 si el archivo se cerró correctamente y -1 si ocurrió un error al cerrar el archivo.

ERRORES

afCloseFile puede generar los siguientes errores posibles:

• AF_BAD_FILEHANDLE
• AF_BAD_LSEEK
• AF_BAD_WRITE

VER TAMBIÉN
