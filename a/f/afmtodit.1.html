La sortie est écrite au format groff_font(5) dans fichier-description-police, un fichier nommé d'après le nom de police groff prévu (mais voir l'option -o). fichier-map doit contenir une séquence de lignes de la forme glyphe-ps caractère-groff où glyphe-ps est le nom de

Le même glyphe-ps peut apparaître plusieurs fois dans le fichier ; chaque caractère-groff ne doit apparaître qu'une seule fois au maximum. Les lignes commençant par « # » et les lignes vides sont ignorées. Si le fichier n'est pas trouvé dans le répertoire courant, il est recherché dans le sous-répertoire devps/generate de le répertoire de polices par défaut. Si un glyphe PostScript n'est pas mentionné dans fichier-map,

et qu'un nom de caractère groff ne peut pas être déduit à l'aide de l'Adobe Glyph List (AGL, intégré dans afmtodit), alors afmtodit place le glyphe PostScript dans le fichier de description de police groff en tant que glyphe non nommé qui ne peut être accédé que par la séquence d'échappement « \N » dans un document roff. En particulier, c'est le cas pour les variantes de glyphes nommées sous la forme « foo. bar » ; tous les noms de glyphescontenant un ou plusieurs points sont mappés à des entités non nommées. Sauf si -e est spécifié, l'encodage défini dans le fichier AFM (c'est-à-dire les entrées avec des codes non négatifs) est utilisé. Voir la section « Utilisation des symboles » dans Groff : l'implémentation GNU de troff, le manuel Texinfo de groff, ou groff_char(7) , qui décrivent comment les identifiants de caractères groff sont construits. Les glyphes non encodés dans le

fichier

AFM (c'est-à-dire les entrées indexées comme « -1 ») restent disponibles dans groff ; ils reçoivent des valeurs d'index de glyphe supérieures à 255 (ou supérieures au plus grand code utilisé dans le fichier AFM dans le cas peu probable où il est supérieur à 255) dans le fichier de description de police groff. Les indices de glyphes non encodés n'ont pas d'ordre spécifique ; il est préférable de ne les accéder que via des identifiants de caractères

spéciaux.
