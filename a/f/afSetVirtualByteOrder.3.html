afSetVirtualByteOrder(3)

Paquete: audiofile

Licencias: Apache-2.0, GPL-2.0-or-later, LGPL-2.1-or-later

AFSETVIRTUALSAMPLEFO(3)   AFSETVIRTUALSAMPLEFO(3)

NOMBRE

afSetVirtualByteOrder, afSetVirtualChannels, afSetVirtualPCMMapping, afSetVirtualSampleFormat - establecer el formato de datos virtual para una pista en un archivo de audio

SINOPSIS

#include <audiofile.h>
int afSetVirtualByteOrder (AFfilehandle file, int track, int byteOrder);
int afSetVirtualChannels (AFfilehandle file, int track, int channels);
int afSetVirtualSampleFormat (AFfilehandle file, int track,
    int sampleFormat, int sampleWidth);
int afSetVirtualPCMMapping (AFfilehandle file, int track,
    double slope, double intercept, double minclip, double maxclip);

PARÁMETROS

• file es un AFfilehandle que se refiere a un archivo de audio abierto y que normalmente se crea con afOpenFile.
• track es un entero que identifica una pista concreta en un archivo de audio abierto. La única pista válida es AF_DEFAULT_TRACK para todos los formatos de archivo actualmente soportados.
• sampleFormat es un entero que denota un formato de muestra virtual. Los valores válidos son AF_SAMPFMT_TWOSCOMP, AF_SAMPFMT_UNSIGNED, AF_SAMPFMT_FLOAT y AF_SAMPFMT_DOUBLE.
• sampleWidth es un entero positivo que especifica el número de bits en una muestra.
• channels es un entero positivo que especifica el número de canales de audio entrelazados en la pista de audio dada.
• byteOrder es un entero que especifica el orden de bytes virtual de las muestras en la pista de audio dada. byteOrder puede ser AF_BYTEORDER_BIGENDIAN o AF_BYTEORDER_LITTLEENDIAN.
• slope e intercept son valores de punto flotante de doble precisión que indican la pendiente de la muestra de datos de audio y el valor de cruce por cero, respectivamente, para el formato de muestra dado.
• minclip y maxclip son valores de punto flotante de doble precisión que indican los valores mínimos o máximos de muestra a devolver. Cualquier valor inferior a minclip se establecerá en minclip, y cualquier valor superior a maxclip se establecerá en maxclip.

VALOR DE RETORNO

Estas funciones devuelven 0 en caso de éxito y -1 en caso de fallo.
