NOMBRE

afpfsd - Demonio para gestionar sesiones AFP para el cliente FUSE afpfs-ng.

SINOPSIS

afpfsd [-l|metodo_log=metodo [f|--primerplano [d|--depuracion

DESCRIPCIÓN

afpfsd es un demonio que gestiona sesiones AFP. Las funciones (como montar, obtener estado, etc.) se pueden realizar utilizando la herramienta afp_client(1). Este cliente se comunica con el demonio a través de una tubería con nombre (named pipe).

afpfsd no se iniciará si otra instancia ya está en ejecución. Debe haber una copia de afpfsd ejecutándose por usuario.

OPCIONES

-l|--metodo_log establece el método utilizado para registrar; los valores son stdout o syslog

-f|--primerplano no crea un proceso hijo (fork) para el demonio

-f|--depuracion pone el demonio en primer plano y vuelca los registros a stdout

VER TAMBIÉN

afp_client(1), mount_afp(1)
