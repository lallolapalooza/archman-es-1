NOMBRE

afl-cmin

SINOPSIS

afl-cmin [ opciones ] -- /ruta/a/la_app_objetivo [ ... ]

OPCIONES

Parámetros requeridos:
  -i dir        - directorio de entrada con corpus inicial
  -o dir        - directorio de salida para archivos minimizados
Configuración de control de ejecución:
  -T tasks      - cuántas tareas paralelas ejecutar (por defecto: 1, todas=nproc)
  -f file       - ubicación leída por el programa fuzzificado (por defecto: stdin)
  -m megs       - límite de memoria para el proceso hijo (MB)
  -t msec       - límite de tiempo de ejecución para el proceso hijo (por defecto: 5000)
  -O            - usar instrumentación solo binaria (modo FRIDA)
  -Q            - usar instrumentación solo binaria (modo QEMU)
  -U            - usar instrumentación basada en unicorn (modo unicorn)
  -X            - usar modo Nyx
Configuración de minimización:
  -A            - permitir bloqueos y tiempos de espera (no recomendado)
  -C            - mantener las entradas que causan bloqueos, rechazar todo lo demás
  -e            - resolver solo para cobertura de bordes, ignorar recuentos de aciertos
Para obtener consejos adicionales, consulta README.md
Variables de entorno utilizadas:
AFL_CRASH_EXITCODE: código de salida opcional del hijo a interpretar como bloqueo
AFL_FORKSRV_INIT_TMOUT: tiempo que el fuzzer espera a que el servidor fork arranque
AFL_KEEP_TRACES: deja el directorio temporal <out_dir>/.traces
AFL_KILL_SIGNAL: señal entregada a los procesos hijos en caso de tiempo de espera agotado (por defecto: SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: señal entregada a los procesos del servidor fork al
   terminar (por defecto: SIGTERM). Si esto no está establecido y AFL_KILL_SIGNAL
   está establecido, esto se establecerá al mismo valor que AFL_KILL_SIGNAL.
AFL_NO_FORKSRV: ejecuta el objetivo a través de execve en lugar de usar el servidor fork
AFL_CMIN_ALLOW_ANY: escribe tuplas para entradas que causan bloqueos también
AFL_PATH: ruta para el binario afl-showmap si no se encuentra en ninguna parte de PATH
AFL_PRINT_FILENAMES: Si está establecido, el nombre de archivo que se está procesando se imprimirá en stdout
AFL_SKIP_BIN_CHECK: omite las comprobaciones de instrumentación de afl para el binario objetivo
