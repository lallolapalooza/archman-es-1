AFNEWFILESETUP(3)   AFNEWFILESETUP(3)

NOMBRE

afNewFileSetup - crea e inicializa una estructura AFfilesetup nueva

SINOPSIS

#include <audiofile.h>
AFfilesetup afNewFileSetup(void);

VALOR DE RETORNO

afNewFileSetup devuelve, si tiene éxito, una estructura AFfilesetup válida.

En caso de fallo, afNewFileSetup devuelve una AFfilesetup nula. Este caso solo debería ocurrir cuando no hay memoria disponible.

DESCRIPCIÓN

La estructura opaca AFfilesetup devuelta por afNewFileSetup se puede utilizar para especificar parámetros para un archivo que se abrirá para escritura por afOpenFile(3).
