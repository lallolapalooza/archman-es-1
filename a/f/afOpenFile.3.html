afOpenFile(3)

AFOPENFILE(3)   AFOPENFILE(3)

NOMBRE

afOpenFile - abre un archivo de audio y crea una estructura de manejador de archivo utilizada para llamadas subsiguientes a la Biblioteca de Archivos de Audio

SINOPSIS

#include <audiofile.h>
AFfilehandle afOpenFile(const char *path, const char *mode,
    AFfilesetup setup);

PARÁMETROS

path es la ruta al archivo que se va a abrir.

mode especifica un modo para abrir el archivo: "r" para leer o "w" para escribir.

setup es un AFfilesetup creado por afNewFileSetup(3). Este valor se ignora para los archivos abiertos para lectura excepto cuando el formato del archivo es AF_FILE_RAWDATA.

VALOR DE RETORNO

Al tener éxito, afOpenFile devuelve un AFfilehandle válido que puede ser utilizado en llamadas subsiguientes a la Biblioteca de Archivos de Audio. Al fallar, afOpenFile devuelve NULL y genera un error.

afCloseFile(3) se utiliza para cerrar el archivo cuando ya no es necesario.

ERRORES

afOpenFile puede producir los siguientes errores:

AF_BAD_OPEN

La llamada a open falló.

AF_BAD_READ

La llamada a read falló

AF_BAD_WRITE

La llamada a write falló.

AF_BAD_LSEEK

La llamada a lseek falló.

AF_BAD_MALLOC

La asignación de memoria falló.

AF_BAD_FILEFMT

setup especifica un formato de archivo que no es compatible para el modo.

AF_BAD_SAMPFMT

El formato de muestra del archivo no es compatible.

AF_BAD_WIDTH

El ancho de muestra del archivo no es compatible.

AF_BAD_RATE

La frecuencia de muestreo del archivo no es compatible.

AF_BAD_CHANNELS

El número de canales en el archivo no es compatible.

AF_BAD_FILESETUP

setup especifica una configuración inválida o no compatible.

VER TAMBIÉN

afCloseFile(3), afNewFileSetup(3), afInitFileFormat(3), afInitSampleFormat(3), afReadFrames(3), afWriteFrames(3)
