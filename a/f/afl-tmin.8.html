afl-tmin(8) Manual del Administrador del Sistema afl-tmin(8)

NOMBRE

afl-tmin

SINOPSIS

afl-tmin [ opciones ] -- /ruta/a/la_aplicacion_objetivo [ ... ]

OPCIONES

Parámetros requeridos:
  -i archivo    - caso de prueba de entrada para ser reducido por la herramienta
  -o archivo    - ubicación final de la salida para los datos minimizados
Ajustes de control de ejecución:
  -f archivo    - archivo de entrada leído por el programa probado (stdin)
  -t mseg       - tiempo de espera para cada ejecución (1000 ms)
  -m megs       - límite de memoria para el proceso hijo (0 MB)
  -O            - usar instrumentación solo binaria (modo FRIDA)
  -Q            - usar instrumentación solo binaria (modo QEMU)
  -U            - usar instrumentación basada en unicorn (modo Unicorn)
  -W            - usar instrumentación basada en qemu con Wine (modo Wine)
                  (No es necesario, aquí por consistencia con otras herramientas afl-*)
  -X            - usar modo Nyx
Ajustes de minimización:
  -e            - resolver solo para la cobertura de bordes, ignorar los recuentos de aciertos
  -l bytes      - establecer la longitud mínima de eliminación de bloques para acelerar la minimización
  -x            - tratar los códigos de salida distintos de cero como fallos
  -H            - minimizar un cuelgue (modo cuelgue)
Para obtener consejos adicionales, consulte docs/README.md.
Variables de entorno utilizadas:
AFL_CRASH_EXITCODE: código de salida hijo opcional que se interpretará como fallo
AFL_FORKSRV_INIT_TMOUT: tiempo dedicado a esperar al servidor fork durante el inicio (en ms)
AFL_KILL_SIGNAL: Señal ID entregada a los procesos hijos en caso de tiempo de espera, etc.
                 (por defecto: SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: Señal de eliminación para el servidor fork al terminar
                             (por defecto: SIGTERM). Si no está establecida y AFL_KILL_SIGNAL está
                             establecida, se utilizará ese valor.
AFL_MAP_SIZE: el tamaño de la memoria compartida para ese objetivo. debe ser >= el tamaño
              para el que se compiló el objetivo
AFL_PRELOAD:  configuración de LD_PRELOAD / DYLD_INSERT_LIBRARIES para el objetivo
AFL_TMIN_EXACT: exigir que las rutas de ejecución coincidan para las entradas de fallo
AFL_NO_FORKSRV: ejecutar el objetivo a través de execve en lugar de usar el servidor fork
ASAN_OPTIONS: ajustes personalizados para ASAN
              (debe contener abort_on_error=1 y symbolize=0)
MSAN_OPTIONS: ajustes personalizados para MSAN
              (debe contener exitcode=86 y symbolize=0)
TMPDIR: directorio a utilizar para archivos de entrada temporales
