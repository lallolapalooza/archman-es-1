NOMBRE

afl-cmin.bash

SINOPSIS

Uso: ./afl-cmin.bash [ opciones ] -- /ruta/a/la_app_objetivo [ ... ]

OPCIONES

Parámetros requeridos:
  -i dir        - directorio de entrada con el corpus inicial
  -o dir        - directorio de salida para archivos minimizados
Configuración del control de ejecución:
  -T tareas     - cuántos procesos paralelos crear (por defecto=1, "all"=nproc)
  -f archivo    - ubicación leída por el programa fuzzed (por defecto: stdin)
  -m megs       - límite de memoria para el proceso hijo (por defecto: ningún MB)
  -t msec       - límite de tiempo de ejecución para el proceso hijo (por defecto: 5000ms)
  -O            - usar instrumentación solo de binario (modo FRIDA)
  -Q            - usar instrumentación solo de binario (modo QEMU)
  -U            - usar instrumentación basada en unicorn (modo Unicorn)
  -X            - usar modo Nyx
Configuración de minimización:
  -A            - permitir entradas que causan fallos y tiempos de espera agotados
  -C            - mantener las entradas que causan fallos, rechazar todo lo demás
  -e            - resolver solo para cobertura de bordes, ignorar recuentos de aciertos
Para obtener consejos adicionales, consulte README.md.
Este script no puede leer nombres de archivo que terminen con un espacio ' '.
Variables de entorno utilizadas:
AFL_KEEP_TRACES: deja el directorio temporal <out_dir>.traces
AFL_NO_FORKSRV: ejecuta el objetivo vía execve en lugar de usar el forkserver
AFL_PATH: ubicación de último recurso para encontrar el binario afl-showmap
AFL_SKIP_BIN_CHECK: omite la verificación del binario objetivo
AFL_CUSTOM_MUTATOR_LIBRARY: biblioteca mutadora personalizada (post_process y send)
AFL_PYTHON_MODULE: biblioteca mutadora personalizada (post_process y send)
