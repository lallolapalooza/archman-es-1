NOMBRE

afReadFrames - leer tramas de muestra de una pista en un archivo de audio

SINOPSIS

#include <audiofile.h>
AFframecount afReadFrames(AFfilehandle file, int track, void *data,
    int count);

DESCRIPCIÓN

afReadFrames intenta leer hasta count tramas de datos de audio del manejador de archivo de audio file al búfer en data.

PARÁMETROS

file es un manejador de archivo válido devuelto por afOpenFile(3).

track es siempre AF_DEFAULT_TRACK para todos los formatos de archivo soportados actualmente.

data es un búfer para almacenar count tramas de datos de muestra de audio.

count es el número de tramas de muestra a leer.

VALOR DE RETORNO

afReadFrames devuelve el número de tramas leídas con éxito de file.

ERRORES

afReadFrames puede producir los siguientes errores:

AF_BAD_FILEHANDLE

el manejador de archivo era inválido

AF_BAD_TRACKID

el parámetro track no es AF_DEFAULT_TRACK

AF_BAD_READ

la lectura de datos de audio del archivo falló

AF_BAD_LSEEK

la búsqueda dentro del archivo falló

VER TAMBIÉN
