afl-analyze(8) Manual del Administrador del Sistema afl-analyze(8)

NOMBRE

afl-analyze

SINOPSIS

afl-analyze [ opciones ] -- /ruta/a/la/aplicacion_objetivo [ ... ]

OPCIONES

Parámetros requeridos:
  -i archivo    - caso de prueba de entrada a ser analizado por la herramienta
Configuración de control de ejecución:
  -f archivo    - archivo de entrada leído por el programa probado (stdin)
  -t mseg       - tiempo de espera para cada ejecución (1000 ms)
  -m megs       - límite de memoria para el proceso hijo (0 MB)
  -O            - usar instrumentación solo binaria (modo FRIDA)
  -Q            - usar instrumentación solo binaria (modo QEMU)
  -U            - usar instrumentación basada en unicorn (modo Unicorn)
  -W            - usar instrumentación basada en qemu con Wine (modo Wine)
  -X            - usar modo Nyx
Configuración de análisis:
  -e            - buscar solo cobertura de aristas, ignorar recuentos de aciertos
Para consejos adicionales, por favor consulte docs/README.md.
Variables de entorno utilizadas:
TMPDIR: directorio a usar para archivos de entrada temporales
ASAN_OPTIONS: configuraciones personalizadas para ASAN
              (debe contener abort_on_error=1 y symbolize=0)
MSAN_OPTIONS: configuraciones personalizadas para MSAN
              (debe contener exitcode=86 y symbolize=0)
AFL_ANALYZE_HEX: imprimir desplazamientos de archivo en hexadecimal en lugar de decimal
AFL_KILL_SIGNAL: ID de señal entregada a los procesos hijos en tiempo de espera, etc.
                 (por defecto: SIGKILL)
AFL_FORK_SERVER_KILL_SIGNAL: Señal de terminación para el servidor de bifurcación al finalizar
                             (por defecto: SIGTERM). Si no está configurada y AFL_KILL_SIGNAL
                             está configurada, se usará ese valor.
AFL_MAP_SIZE: el tamaño de memoria compartida para ese objetivo. debe ser >= al tamaño
              para el que fue compilado el objetivo
AFL_PRELOAD: configuración LD_PRELOAD / DYLD_INSERT_LIBRARIES para el objetivo
AFL_SKIP_BIN_CHECK: omitir la comprobación de la ubicación y del objetivo
