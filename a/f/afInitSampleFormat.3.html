afInitSampleFormat(3)

Paquete: audiofile

Licencias: Apache-2.0, GPL-2.0-or-later, LGPL-2.1-or-later

AFINITSAMPLEFORMAT(3)   AFINITSAMPLEFORMAT(3)

NOMBRE

afInitSampleFormat, afInitByteOrder, afInitChannels, afInitRate - inicializar el formato de datos de audio para una pista en una configuración de archivo de audio

SINOPSIS

#include <audiofile.h>
void afInitSampleFormat(AFfilesetup setup, int track, int sampleFormat,
    int sampleWidth);
void afInitByteOrder(AFfilesetup setup, int track, int byteOrder);
void afInitChannels(AFfilesetup setup, int track, int channels);
void afInitRate(AFfilesetup setup, int track, double rate);

PARÁMETROS

setup es una configuración de archivo válida devuelta por afNewFileSetup(3).

track especifica una pista dentro de la configuración del archivo. track es siempre AF_DEFAULT_TRACK para todos los formatos de archivo actualmente soportados.

sampleFormat es una constante simbólica que especifica el formato de muestra para los datos de audio en la pista. sampleFormat debe ser uno de AF_SAMPFMT_TWOSCOMP, AF_SAMPFMT_UNSIGNED, AF_SAMPFMT_FLOAT, o AF_SAMPFMT_DOUBLE.

sampleWidth es un entero positivo que especifica el número de bits por muestra en la pista.

byteOrder es una constante simbólica que especifica el orden de bytes de la pista. byteOrder debe ser uno de AF_BYTEORDER_BIGENDIAN o AF_BYTEORDER_LITTLEENDIAN.

channels es un entero positivo que especifica el número de canales en la pista.

rate es un número de punto flotante de doble precisión positivo que especifica la frecuencia de muestreo de la pista.

DESCRIPCIÓN

afInitSampleFormat inicializa la pista al formato de muestra y ancho de muestra especificados.

afInitByteOrder inicializa la pista al orden de bytes especificado.

afInitChannels inicializa la pista al número de canales especificado.

afInitRate inicializa la pista a la frecuencia de muestreo especificada.

ERRORES

afInitSampleFormat, afInitByteOrder, afInitChannels y afInitRate pueden producir los siguientes errores:

AF_BAD_FILESETUP setup representa una configuración de archivo inválida.
AF_BAD_TRACK track representa un identificador de pista inválido.

afInitSampleFormat también puede producir los siguientes errores:

AF_BAD_SAMPFMT sampleFormat no representa un formato de muestra válido.
AF_BAD_WIDTH sampleWidth no es un ancho de muestra válido.

afInitByteOrder también puede producir el siguiente error:

AF_BAD_BYTEORDER byteOrder no representa un orden de bytes válido.

afInitChannels también puede producir el siguiente error:

AF_BAD_CHANNELS channels especifica un número de canales inválido.

afInitRate también puede producir el siguiente error:

AF_BAD_RATE rate especifica una frecuencia de muestreo inválida.

VER TAMBIÉN

afNewFileSetup(3), afInitFileFormat(3), afInitCompression(3), afOpenFile(3)
