AFREADMISC(3)   AFREADMISC(3)

NOMBRE

afReadMisc, afWriteMisc, afSeekMisc - acceder a metadatos varios en un archivo de audio

SINOPSIS

#include <audiofile.h>
int afReadMisc (AFfilehandle file, int miscid, void *buffer, int nbytes);
int afWriteMisc (AFfilehandle file, int miscid, const void *buffer, int nbytes);
int afSeekMisc (AFfilehandle file, int miscid, int offbytes);

DESCRIPCIÓN

afReadMisc lee hasta nbytes del bloque de datos varios identificado por miscid en file.

afWriteMisc escribe hasta nbytes en el bloque de datos varios identificado por miscid en file.

afSeekMisc cambia la posición actual dentro del bloque de datos varios identificado por miscid a la posición offbytes.

VALOR DE RETORNO

afReadMisc devuelve el número de bytes leídos del bloque varios especificado al búfer al que hace referencia buffer.

afWriteMisc devuelve el número de bytes escritos en el bloque varios especificado desde el búfer al que hace referencia buffer.

afSeekMisc devuelve la nueva posición del puntero de datos lógico medido como un desplazamiento en bytes desde el principio del área de datos del bloque varios.

ERRORES

afReadMisc, afWriteMisc y afSeekMisc pueden producir los siguientes códigos de error:

• AF_BAD_READ
• AF_BAD_WRITE
• AF_BAD_MISCSEEK
• AF_BAD_MISCID
• AF_BAD_TRACKID
• AF_BAD_FILEHANDLE
