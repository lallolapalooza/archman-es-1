NOMBRE

ao_string_tokenize - tokenizar una cadena de entrada

SINOPSIS

#include <tu-opts.h>
cc [...] -o archivo_salida archivo_entrada.c -lopts [...]

token_list_t * ao_string_tokenize(char const * cadena);

DESCRIPCIÓN

Esta función convertirá una cadena de entrada en una lista de cadenas. La lista de cadenas se deriva separando la entrada basándose en el espacio en blanco. Sin embargo, si la entrada contiene comillas simples o dobles, el texto después de ese carácter hasta una comilla coincidente se convertirá en la cadena de la lista.

El puntero devuelto debe ser liberado con free(3C) cuando hayas terminado de usar los datos. Los datos se colocan en un único bloque de memoria asignada. No liberes tokens/cadenas individuales.

La estructura a la que apunta contendrá al menos estos dos campos:

tkn_ct El número de tokens encontrados en la cadena de entrada.

tok_list Una matriz de tkn_ct + 1 punteros a subcadenas tokenizadas, con el último puntero establecido a NULL.

Hay dos tipos de cadenas entre comillas: comillas simples (') y comillas dobles ("). Las cadenas entre comillas simples son bastante crudas, ya que los caracteres de escape (\) son simplemente otro carácter, excepto cuando preceden a los siguientes caracteres:

    \  dobles barras invertidas se reducen a una
    '   incorpora la comilla simple a la cadena
    0fP  suprime tanto la barra invertida como el carácter de nueva línea

Las cadenas entre comillas dobles se forman de acuerdo con las reglas de las constantes de cadena en los programas ANSI-C.

cadena
cadena a tokenizar

VALOR DE RETORNO

puntero a una estructura que lista cada token

ERRORES

Se devuelve NULL y se establecerá errno para indicar el problema:

EINVAL - Hubo una cadena entre comillas sin terminar.

ENOENT - La cadena de entrada estaba vacía.

ENOMEM - No hay suficiente memoria. @end itemize

EJEMPLOS

    #include <stdlib.h>
    int ix;
    token_list_t * ptl = ao_string_tokenize(cadena_alguna)
    for (ix = 0; ix < ptl->tkn_ct; ix++)
    hacer_algo_con_tkn(ptl->tok_list[ix]);
    free(ptl);

Ten en cuenta que todo se libera con la única llamada a free(3C).
