AOSS(1) Manual de Comandos Generales AOSS(1)

NOMBRE

aoss - Script envoltorio para facilitar el uso de la biblioteca de compatibilidad ALSA OSS.

SINOPSIS

aoss comando_oss [argumentos]

DESCRIPCIÓN

aoss es un script envoltorio simple que facilita el uso de la biblioteca de compatibilidad ALSA OSS. Simplemente establece la ruta apropiada de LD_PRELOAD y luego ejecuta el comando.

Esto es útil en casos donde la configuración de enrutamiento (que se puede hacer en tu archivo .asoundrc) necesita ser aplicada a comandos que usan la API OSS.

Ejemplos de configuración de asoundrc:

pcm.dsp0 { type plug slave.pcm "hw:0,0" }

o

pcm.dsp0 { type plug slave.pcm "dmix" }

En los ejemplos de configuración anteriores, la definición pcm.dsp0 se utiliza para envolver las llamadas a /dev/dsp0. También puedes envolver el uso de /dev/dsp1, /dev/dsp2, etc., definiendo pcm.dsp1, pcm.dsp2, etc.

El nombre del PCM a abrir se puede proporcionar explícitamente a través de la variable de entorno ALSA_OSS_PCM_DEVICE. Esto anula el valor por defecto dsp0, etc.

Nota sobre mmap: El soporte de mmap de aoss puede ser defectuoso. Tus resultados pueden variar al intentar usar una aplicación que utiliza mmap para acceder a los archivos del dispositivo OSS.

Argumentos

comando_oss
Un comando que utiliza la API OSS
argumentos
Los argumentos y opciones apropiados para el comando OSS.

AUTORES

La biblioteca de compatibilidad OSS es de Abramo Bagnara <abramo@alsa-project.org>. El script aoss y este documento son de James Tappin <james@xena.uklinux.net>.
