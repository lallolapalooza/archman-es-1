NOMBRE

a2jmidid - demonio JACK MIDI para ALSA MIDI

SINOPSIS

a2jmidid [-j servidor-jack] [e | --exportar-hw]

DESCRIPCIÓN

a2jmidid es un demonio que implementa un puente automático. Por cada puerto del secuenciador ALSA se obtiene un puerto MIDI de JACK. Si un puerto del secuenciador ALSA es tanto de entrada como de salida, se obtienen dos puertos MIDI de JACK, uno de entrada y otro de salida.

OPCIONES

-e | --exportar-hw
fuerza a a2jmidid a puentear puertos de hardware así como puertos de software
-u
fuerza a a2jmidid a generar nombres de puerto no únicos (ver NOTAS)
-j
especifica qué servidor jack usar

NOTAS

ALSA no garantiza que los nombres de cliente sean únicos. Es decir, es posible tener dos aplicaciones que creen dos clientes con el mismo nombre de cliente ALSA. Sin embargo, JACK requiere que los nombres de puerto sean únicos. Para garantizar esta unicidad, a2jmidid añadirá el ID numérico único del cliente ALSA al nombre del puerto JACK. Sin embargo, se sabe que este comportamiento es problemático al restaurar conexiones usando herramientas simplistas como aj-snapshot y jack_connect. Para que funcionen, se puede usar la opción -u. Esta opción hará que a2jmidid omita el ID numérico del cliente ALSA de los nombres de puerto JACK. En este modo, la unicidad del nombre del cliente ALSA debe garantizarse externamente.
