a2x.3bobcat

Paquete: libbobcat

FBB::A2x(3bobcat) Convertidor de texto a X FBB::A2x(3bobcat)

NOMBRE

FBB::A2x - Objetos que realizan conversiones de ascii a x (cualquier cosa)

SINOPSIS

#include <bobcat/a2x>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::A2x ofrecen el equivalente en **C++** de las funciones estándar de conversión de cadenas de **C++** como *stol, stoul, stod*, etc. Estas funciones estándar de **C++** son extremadamente útiles y probablemente deberían preferirse sobre el uso de los miembros de los objetos *A2x*, pero *A2x* ofrece beneficios adicionales al generalizar estas funciones a *cualquier* tipo que pueda extraerse de los objetos **istream**.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros y operadores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::istringstream

CONSTRUCTORES

o
A2x():
Este constructor construye un objeto A2x vacío. No se puede extraer información de un objeto A2x construido de esta manera.
o
A2x(char const *text):
Este constructor almacena text. Si text representa un valor textual de algún tipo, el objeto A2x puede usarse para inicializar o asignar este valor a una variable de ese tipo particular. La extracción, sin embargo, también es posible.
o
A2x(std::string const &str):
Este constructor almacena el texto contenido en str. Si este texto representa un valor textual de algún tipo, el objeto A2x puede usarse para inicializar o asignar este valor a una variable de ese tipo particular. La extracción también es posible.

Los constructores de copia y movimiento están disponibles.

FUNCIÓN MIEMBRO ESTÁTICA

o
bool lastFail():
Este miembro devuelve true si la última conversión falló (es decir, el miembro fail() del objeto devolvió true y devuelve false en caso contrario). Este miembro permite comprobar el éxito de la extracción/conversión utilizando objetos A2x anónimos. El miembro también devuelve true cuando aún no se ha realizado ninguna conversión.
Tenga en cuenta que este miembro devuelve el valor de un miembro estático thread_local: los diferentes hilos no pueden inspeccionar el estado lastFail de otros hilos.

FUNCIÓN MIEMBRO

Todos los miembros de la clase istringstream están disponibles.

o
Type to():
Este miembro devuelve cualquier tipo Type que admita extracciones de i[string]streams. Si la extracción falla, el miembro good() del objeto A2x devuelve false y se devuelve el valor predeterminado de Type. Este operador se implementó como una función miembro de plantilla. También hay un operador de conversión de tipo disponible (ver más abajo), pero la variante de función miembro puede ser preferible al operador de conversión en situaciones donde se requiere una desambiguación explícita (por ejemplo, en casos donde una conversión no tiene una solución de tipo obvia, como inserciones directas). Se proporciona un ejemplo en la sección EJEMPLO más abajo.

OPERADORES SOBRECARGADOS

o
operator Type():
Conversión a cualquier tipo Type que admita extracciones de istreams. Si la extracción falla, el miembro good() del objeto A2x devolverá false y se devolverá el valor predeterminado de Type. Este operador se implementó como una plantilla miembro.
o
istream &operator>>(istream &, Type &):
Extracción a cualquier tipo Type que admita extracciones de istreams. Si la extracción falla, el miembro good() del objeto A2x devuelve false y se devuelve el valor predeterminado de Type (esta funcionalidad se infiere del hecho de que esta clase hereda de istringstream, pero probablemente sea útil destacar que la operación de extracción todavía está disponible).
o
A2x &operator=(char const *):
Almacena texto nuevo en el objeto A2x, restablece los indicadores de estado a ios::good. Si se pasa un puntero nulo, se almacena una cadena vacía.
o
A2x &operator=(std::string const &):
Almacena el texto almacenado en el argumento std::string en el objeto A2x, restablece los indicadores de estado a ios::good.

El operador de asignación sobrecargado está disponible.

EJEMPLO

    int x = A2x("12");
    A2x a2x("12.50");
    double d;
    d = a2x;
    a2x = "err";
    d = a2x;        // d ahora es 0
    a2x = " a";
    char c = a2x;   // c ahora es 'a'
                    // conversión explícita a `double'
    cout << A2x("12.4").to<double>() << endl;
