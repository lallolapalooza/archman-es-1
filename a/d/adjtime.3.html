adjtime(3) Manual de funciones de biblioteca adjtime(3)

NOMBRE

adjtime - corrige la hora para sincronizar el reloj del sistema

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/time.h>
int adjtime(const struct timeval *delta, struct timeval *olddelta);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

adjtime():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

La función adjtime() ajusta gradualmente el reloj del sistema (tal como lo devuelve gettimeofday(2)). La cantidad de tiempo por la que se debe ajustar el reloj se especifica en la estructura a la que apunta delta. Esta estructura tiene el siguiente formato:


struct timeval {
    time_t      tv_sec;     /* segundos */
    suseconds_t tv_usec;    /* microsegundos */
};

Si el ajuste en delta es positivo, entonces el reloj del sistema se acelera en un pequeño porcentaje (es decir, añadiendo una pequeña cantidad de tiempo al valor del reloj en cada segundo) hasta que se completa el ajuste. Si el ajuste en delta es negativo, entonces el reloj se ralentiza de manera similar.

Si un ajuste de reloj de una llamada anterior a adjtime() ya está en curso en el momento de una llamada posterior a adjtime(), y delta no es NULL para la llamada posterior, entonces el ajuste anterior se detiene, pero cualquier parte ya completada de ese ajuste no se deshace.

Si olddelta no es NULL, entonces el búfer al que apunta se utiliza para devolver la cantidad de tiempo restante de cualquier ajuste previo que aún no se haya completado.

VALOR DE RETORNO

En caso de éxito, adjtime() devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El ajuste en delta está fuera del rango permitido.
EPERM
El llamante no tiene suficiente privilegio para ajustar la hora. En Linux, se requiere la capacidad CAP_SYS_TIME.

ESTÁNDARES

Ninguno.

HISTORIAL

4.3BSD, System V.

NOTAS

El ajuste que adjtime() realiza en el reloj se lleva a cabo de tal manera que el reloj siempre aumenta monótonamente. Usar adjtime() para ajustar la hora evita los problemas que podrían ser causados para ciertas aplicaciones (por ejemplo, make(1)) por saltos abruptos positivos o negativos en la hora del sistema.

adjtime() está diseñado para ser utilizado para hacer pequeños ajustes en la hora del sistema. La mayoría de los sistemas imponen un límite en el ajuste que se puede especificar en delta. En la implementación de glibc, delta debe ser menor o igual a (INT_MAX / 1000000 - 2) y mayor o igual a (INT_MIN / 1000000 + 2) (respectivamente 2145 y -2145 segundos en i386).

ERRORES

Un error de larga data significaba que si delta se especificaba como NULL, no se devolvía información válida sobre el ajuste de reloj pendiente en olddelta. (En esta circunstancia, adjtime() debería devolver el ajuste de reloj pendiente, sin cambiarlo.) Este error se ha corregido en sistemas con glibc 2.8 o posterior y kernel de Linux 2.6.26 o posterior.

VER TAMBIÉN
