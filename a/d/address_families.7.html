address_families(7) Manual de Información Miscelánea address_families(7)

NOMBRE

address_families - familias (dominios) de direcciones de sockets

SINOPSIS

#include <sys/types.h>          /* Ver NOTAS */
#include <sys/socket.h>
int socket(int domain, int type, int protocol);

DESCRIPCIÓN

El argumento domain de la llamada al sistema socket(2) especifica un dominio de comunicación; esto selecciona la familia de protocolos que se utilizará para la comunicación. Estas familias se definen en <sys/socket.h>. Los formatos actualmente reconocidos por el kernel de Linux incluyen:

AF_UNIX
AF_LOCAL
Comunicación local. Para más información, véase unix(7).
AF_INET
Protocolos de Internet IPv4. Para más información, véase ip(7).
AF_AX25
Protocolo AX.25 de radioaficionados. Para más información, véase ax25(4).
AF_IPX
Protocolos IPX - Novell.
AF_APPLETALK
AppleTalk. Para más información, véase ddp(7).
AF_NETROM
Protocolo de capa de paquetes AX.25. Para más información, véase netrom(4), The Packet Radio Protocols and Linux y los capítulos de programación de red de AX.25, NET/ROM y ROSE del Linux Amateur Radio AX.25 HOWTO.
AF_BRIDGE
No se puede utilizar para crear sockets; se usa principalmente para enlaces de puente en comandos del protocolo rtnetlink(7).
AF_ATMPVC
Acceso a Circuitos Virtuales Permanentes (PVC) de ATM. Para más información, véase la ATM on Linux HOWTO.
AF_X25
Protocolo ITU-T X.25 / ISO/IEC 8208. Para más información, véase x25(7).
AF_INET6
Protocolos de Internet IPv6. Para más información, véase ipv6(7).
AF_ROSE
RATS (Radio Amateur Telecommunications Society). Protocolo de capa de paquetes AX.25 del entorno de sistemas abiertos (ROSE). Para más información, véase los recursos listados para AF_NETROM.
AF_DECnet
Sockets de protocolo DECnet. Véase Documentation/networking/decnet.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_NETBEUI
Reservado para el proyecto "802.2LLC"; nunca se usó.
AF_SECURITY
Esta fue una familia de protocolos de corta duración (entre Linux 2.1.30 y 2.1.99pre2) para las llamadas de upcall del firewall.
AF_KEY
Protocolo de gestión de claves, desarrollado originalmente para su uso con IPsec (desde Linux 2.1.38). No tiene relación con keyctl(2) ni con la instalación de almacenamiento de claves en el kernel. Véase RFC 2367 PF_KEY Key Management API, Version 2 para más detalles.
AF_NETLINK
Interfaz de usuario del kernel. Para más información, véase netlink(7).
AF_PACKET
Interfaz de paquetes de bajo nivel. Para más información, véase packet(7).
AF_ECONET
Protocolo del bus Acorn Econet (eliminado en Linux 3.5). Véase la documentación de Econet para más detalles.
AF_ATMSVC
Acceso a Circuitos Virtuales Conmutados (SVC) de ATM. Véase la ATM on Linux HOWTO para más detalles.
AF_RDS
Protocolo Reliable Datagram Sockets (RDS) (desde Linux 2.6.30). RDS sobre RDMA no tiene relación con AF_SMC o AF_XDP. Para más información, véase rds(7), rds-rdma(7), y Documentation/networking/rds.txt en el árbol de fuentes del kernel de Linux.
AF_IRDA
Interfaz de sockets sobre IrDA (movido a staging en Linux 4.14, eliminado en Linux 4.17). Para más información, véase irda(7).
AF_PPPOX
Capa de transporte PPP genérica, para configurar túneles L2 (L2TP y PPPoE). Véase Documentation/networking/l2tp.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_WANPIPE
Protocolo obsoleto para conectividad de red de área amplia (WAN) que era utilizado por las tarjetas WAN de Sangoma (llamadas "WANPIPE"); eliminado en Linux 2.6.21.
AF_LLC
Protocolo Logical Link Control (IEEE 802.2 LLC), parte superior de la capa de enlace de datos de la pila de protocolos de red ISO/OSI (desde Linux 2.4); no tiene relación con AF_PACKET. Véase el capítulo 13.5.3. Logical Link Control en Understanding Linux Kernel Internals (O'Reilly Media, 2006) y IEEE Standards for Local Area Networks: Logical Link Control (The Institute of Electronics and Electronics Engineers, Inc., New York, New York, 1985) para más detalles. Véase también notas históricas relativas a su desarrollo.
AF_IB
Direccionamiento nativo de InfiniBand (desde Linux 3.11).
AF_MPLS
Multiprotocol Label Switching (desde Linux 4.1); se usa principalmente para configurar el enrutamiento MPLS a través de netlink(7), ya que no expone la capacidad de crear sockets al espacio de usuario.
AF_CAN
Protocolo del bus automotriz Controller Area Network (desde Linux 2.6.25). Véase Documentation/networking/can.rst en el árbol de fuentes del kernel de Linux para más detalles.
AF_TIPC
TIPC, protocolo de "sockets de dominio de clúster" (desde Linux 2.6.16). Véase TIPC Programmer's Guide y la descripción del protocolo para más detalles.
AF_BLUETOOTH
Protocolo de socket de bajo nivel de Bluetooth (desde Linux 3.11). Véase Bluetooth Management API overview y An Introduction to Bluetooth Programming de Albert Huang para más detalles.
AF_IUCV
Protocolo IUCV (inter-user communication vehicle) de z/VM para interacción hipervisor-invitado (desde Linux 2.6.21); no tiene relación con AF_VSOCK y/o AF_SMC. Véase IUCV protocol overview para más detalles.
AF_RXRPC
Rx, procedimiento de llamada remota del Andrew File System

Protocolos de familia de direcciones AF (lo lejos)

AF_PACKET
Interfaz para enlazar sockets con interfaces de red (desde Linux 2.6.22). Ver Documentation/networking/packet.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_ISDN
Nuevo protocolo de interfaz de controlador de "ISDN modular" (desde Linux 2.6.27). Ver el wiki de mISDN para más detalles.
AF_PHONET
Interfaz IPC/RPC de módem celular Nokia (desde Linux 2.6.31). Ver Documentation/networking/phonet.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_IEEE802154
Protocolo de paquete crudo IEEE 802.15.4 WPAN (red de área personal inalámbrica) (desde Linux 2.6.31). Ver Documentation/networking/ieee802154.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_CAIF
Protocolo de interfaz de comunicación CPU a CPU de aplicación de Ericsson (CAIF) (desde Linux 2.6.36). Ver Documentation/networking/caif/Linux-CAIF.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_ALG
Interfaz para la API criptográfica del kernel (desde Linux 2.6.38). Ver Documentation/crypto/userspace-if.rst en el árbol de fuentes del kernel de Linux para más detalles.
AF_VSOCK
Protocolo VSockets de VMWare para interacción hipervisor-invitado (desde Linux 3.9); no tiene relación con AF_IUCV y AF_SMC. Para más información, ver vsock(7).
AF_KCM
Interfaz KCM (multiplexor de conexiones del kernel) (desde Linux 4.6). Ver Documentation/networking/kcm.txt en el árbol de fuentes del kernel de Linux para más detalles.
AF_QIPCRTR
Protocolo de interfaz de enrutador IPC de Qualcomm (desde Linux 4.7).
AF_SMC
Protocolo SMC-R (comunicaciones de memoria compartida sobre RDMA) (desde Linux 4.11), y protocolo SMC-D (comunicaciones de memoria compartida, acceso directo a memoria) para interacción de invitados z/VM intra-nodo (desde Linux 4.19); no tiene relación con AF_RDS, AF_IUCV o AF_VSOCK. Ver RFC 7609 IBM's Shared Memory Communications over RDMA (SMC-R) Protocol para detalles sobre SMC-R. Ver SMC-D Reference Information para detalles sobre SMC-D.
AF_XDP
Interfaz XDP (ruta de datos expres) (desde Linux 4.18). Ver Documentation/networking/af_xdp.rst en el árbol de fuentes del kernel de Linux para más detalles.
AF_MCTP
Interfaz MCTP (Protocolo de Transporte de Componentes de Gestión) (desde Linux 5.15), según se define en la especificación DMTF DSP0236. Para más información, ver mctp(7).
