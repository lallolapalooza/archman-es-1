addseverity(3) Manual de Funciones de Biblioteca addseverity(3)

NOMBRE

addseverity - introduce nuevas clases de severidad

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <fmtmsg.h>
int addseverity(int severity, const char *s);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

addseverity():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

Esta función permite la introducción de nuevas clases de severidad que pueden ser referenciadas por el argumento severity de la función fmtmsg(3). Por defecto, esa función solo sabe cómo imprimir mensajes para las severidades 0-4 (con las cadenas (none), HALT, ERROR, WARNING, INFO). Esta llamada asocia la cadena dada s con el valor dado severity. Si s es NULL, la clase de severidad con el valor numérico severity se elimina. No es posible sobrescribir o eliminar una de las clases de severidad por defecto. El valor de severidad debe ser no negativo.

VALOR DE RETORNO

En caso de éxito, se devuelve el valor MM_OK. En caso de error, el valor de retorno es MM_NOTOK. Los posibles errores incluyen: falta de memoria, intento de eliminar una clase de severidad inexistente o por defecto.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
addseverity () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIA

glibc 2.1. System V.

NOTAS

Se pueden añadir nuevas clases de severidad también estableciendo la variable de entorno SEV_LEVEL.

VER TAMBIÉN
