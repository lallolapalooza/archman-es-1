ADELSYSTEM_CBI(8) Manual de NUT ADELSYSTEM_CBI(8)

NOMBRE

adelsystem_cbi - Driver para el DC-UPS ADELSYSTEM CB/CBI

SINOPSIS

adelsystem_cbi -h

adelsystem_cbi -a NOMBRE_DISPOSITIVO [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del driver adelsystem_cbi. Para obtener información sobre el driver principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este es el driver para los dispositivos DC-UPS cb/cbi de adelsystem.

El driver ha sido probado con CBI2801224A, DC-UPS todo en uno de 12/24Vdc.

Puede encontrar más información sobre este UPS aquí:

https://www.adelsystem.com/en/products/dc-ups-/

ARGUMENTOS ADICIONALES

Este driver soporta las siguientes configuraciones opcionales en el archivo ups.conf(5):

Serie:

ser_baud_rate=valor

Un entero que especifica la velocidad en baudios del puerto serie (por defecto 9600).

ser_data_bit=valor

Un entero que especifica los bits de datos del puerto serie (por defecto 8).

ser_parity=valor

Un carácter que especifica la paridad del puerto serie (por defecto N).

ser_stop_bit=valor

Un entero que especifica los bits de parada del puerto serie (por defecto 1).

Modbus:

dev_slave_id=valor

Un entero que especifica el ID de esclavo Modbus del dispositivo (por defecto 1).

CONFIGURACIÓN

Aquí tiene un ejemplo de configuración del driver adelsystem_cbi en el archivo ups.conf:

[adelsystem_cbi]
  driver = adelsystem_cbi
  port = /dev/ttyUSB0
  desc = "Driver ups adelsystem cb/cbi"
  # ajustes de serie
  ser_baud_rate = 9600
  ser_parity = N
  ser_data_bit = 8
  ser_stop_bit = 1
  # id de esclavo modbus
  dev_slave_id = 5

COMANDOS INSTANTÁNEOS

Este driver soporta los siguientes comandos instantáneos:

load.off

ejecuta "apagado instantáneo"

INSTALACIÓN

Es posible que este driver no se compile por defecto. Puede compilarlo instalando libmodbus y ejecutando configure --with-modbus=yes.

También necesita dar los permisos adecuados en el archivo del dispositivo serie local (por ejemplo, /dev/ttyUSB0) para permitir que la cuenta de usuario del driver NUT en tiempo de ejecución acceda a él.
