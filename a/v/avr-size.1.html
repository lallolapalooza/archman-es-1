DESCRIPCIÓ

N

La utilidad GNU size lista los tamaños de las secciones y el tamaño total de cada uno de los archivos binarios archivoobj de su lista de argumentos. Por defecto, se genera una línea de salida para cada archivo o para cada módulo si el archivo es un

archivo.

archivoobj... son los archivos a examinar. Si no se especifica ninguno, se utilizará el archivo "a.out"

en su
lugar.

OPCIONE

S

Las opciones de la línea de comandos tienen los siguientes

significados:
-
A
-
B
-
G
--format=compatibili
dad
Usando una de estas opciones, puede elegir si la salida de GNU size se asemeja a la salida de System V size (usando -A, o --format=sysv), o de Berkeley size (usando -B, o --format=berkeley). El valor por defecto es el formato de una línea similar al de Berkeley. Alternativamente, puede elegir la salida en formato GNU (usando -G, o --format=gnu), que es similar al formato de salida de Berkeley, pero los tamaños se calculan de manera diferente.

Aquí hay un ejemplo del formato de salida Berkeley (por defecto) de si

ze: 
$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50
size

La salida al estilo de Berkeley cuenta los datos de solo lectura en la columna "text", no en la columna "data", las columnas "dec" y "hex" muestran ambas la suma de las columnas "text", "data" y "bss" en decimal y hexadecimal

respectivamente.

El formato GNU cuenta los datos de solo lectura en la columna "data", no en la columna "text", y solo muestra la suma de las columnas "text", "data" y "bss" una sola vez, en la columna "total". La opción --radix se puede usar para cambiar la base numérica de todas las columnas. Aquí están los mismos datos mostrados con las convenciones

de GNU: 
$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688
size

Estos son los mismos datos, pero mostrados más cerca de las convenciones de

System V: 
$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data
81920 303104 .bss 11592 385024 Total 388392 size : section size addr
.text 294880 8192 .data 81920 303104 .bss 11888 385024 Total 388688

En --radix=número, solo se admiten los tres valores (8, 10, 16). El tamaño total siempre se da en dos radices; decimal y hexadecimal para la salida -d o -x, o octal y hexadecimal si está usando -o
