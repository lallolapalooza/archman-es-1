DESCRIPCIÓN

readelf muestra información sobre uno o más archivos objeto con formato ELF. Las opciones controlan qué información particular se debe mostrar.

archivoelf... son los archivos objeto a examinar. Se admiten archivos ELF de 32 y 64 bits, así como archivos que contienen archivos ELF.

Este programa realiza una función similar a objdump pero entra en más detalle y existe independientemente de la biblioteca BFD, por lo que si hay un error en BFD, readelf no se verá afectado.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes. Se debe proporcionar al menos una opción además de -v o -H.

-a
--all
Equivalente a especificar --file-header, --program-headers, --sections, --symbols, --relocs, --dynamic, --notes, --version-info, --arch-specific, --unwind, --section-groups y --histogram.

Nota: esta opción no habilita --use-dynamic en sí misma, por lo que si esa opción no está presente en la línea de comandos, los símbolos dinámicos y las relocalizaciones dinámicas no se mostrarán.

-g

-t
--section-details
Muestra la información detallada de las secciones. Implica -S.
-s
--symbols
--syms
Muestra las entradas en la tabla de símbolos del archivo, si tiene una. Si un símbolo tiene información de versión asociada, esta se muestra también. La cadena de versión se muestra como un sufijo del nombre del símbolo, precedido por un carácter @. Por ejemplo, foo@VER_1. Si la versión es la versión predeterminada que se usará al resolver referencias no versionadas al símbolo, se muestra como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2.
--dyn-syms
Muestra las entradas en la tabla de símbolos dinámicos del archivo, si tiene una. El formato de salida es el mismo que el formato utilizado por la opción --syms.
--lto-syms
Muestra el contenido de las tablas de símbolos LTO en el archivo.
--sym-base=[0|8|10|16]
Fuerza que el campo de tamaño de la tabla de símbolos utilice la base dada. Cualquier opción no reconocida se tratará como 0. --sym-base=0 representa el comportamiento predeterminado y heredado. Esto mostrará los tamaños como decimales para números menores que 100000. Para tamaños de 100000 y mayores se usará notación hexadecimal con un prefijo 0x. --sym-base=8 dará los tamaños de los símbolos en octal. --sym-base=10 siempre dará los tamaños de los símbolos en decimal. --sym-base=16 siempre dará los tamaños de los símbolos en hexadecimal con un prefijo 0x.
-C
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional del estilo de demangling se puede usar para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Esta es la opción predeterminada.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al demangler cadenas. Dado que los formatos de mangling de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina host, desencadenando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para demangler nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, el agotamiento de la pila es

posible y cualquier informe d

e errores sobre tal evento será rechazado. -U [d|i|l|e|x|h]

--dwarf-depth=n
Limita el volcado de la ".debug_info" sección a n hijos. Esto solo es útil con --debug-dump=info. El valor predeterminado es imprimir todos los DIEs; el valor especial 0 para n también tendrá este efecto.

Con un valor distinto de cero para n, los DIEs en o más profundos que n niveles no se imprimirán. El rango para n es basado en cero.

--dwarf-start=n
Imprime solo los DIEs que comienzan con el DIE numerado n. Esto solo es útil con --debug-dump=info.

Si se especifica, esta opción suprimirá la impresión de cualquier información de encabezado y todos los DIEs antes del DIE numerado n. Solo se imprimirán los hermanos e hijos del DIE especificado.

Esto se puede usar en conjunto con --dwarf-depth.

-P
--process-links
Muestra el contenido de secciones no de depuración encontradas en archivos de debuginfo separados que están enlazados al archivo principal. Esta opción implica automáticamente la -wK opción, y solo se mostrarán las secciones solicitadas por otras opciones de línea de comando.
--ctf[=section]
Muestra el contenido de la sección CTF especificada. Las secciones CTF en sí mismas contienen muchas subsecciones, todas las cuales se muestran en orden.

De forma predeterminada, muestra el nombre de la sección llamada .ctf, que es el nombre emitido por ld.

--ctf-parent=member
Si la sección CTF contiene tipos definidos ambiguamente, consistirá en un archivo de muchos diccionarios CTF, todos heredando de un diccionario que contiene tipos no ambiguos. Este miembro se llama de forma predeterminada .ctf, como la sección que lo contiene, pero es posible cambiar este nombre usando la función "ctf_link_set_memb_name_changer" en tiempo de enlace. Al examinar archivos CTF que han sido creados por un enlazador que usa el cambiador de nombre para renombrar el miembro del archivo padre, --ctf-parent se puede usar para especificar el nombre usado para el padre.
--ctf-parent-section=section
Esta opción le permite elegir una sección completamente diferente para el diccionario padre CTF que contiene tipos no ambiguos que para los diccionarios hijos que contienen el resto ambiguo. El enlazador no emite objetos ELF estructurados de esta manera, pero algunos enlazadores de terceros pueden. También es conveniente para inspeccionar CTF escrito como múltiples archivos crudos para componerlos con objcopy, que puede ponerlos en diferentes secciones ELF pero no en diferentes miembros de un solo diccionario CTF.
--ctf-symbols=section
--ctf-strings=section
Especifica el nombre de otra sección de la que el archivo CTF puede heredar cadenas y símbolos. De forma predeterminada, se usa ".symtab" y su tabla de cadenas vinculada.

Si se especifica cualquiera de --ctf-symbols o --ctf-strings , el otro también debe especificarse.

-I
--histogram
Muestra un histograma de las longitudes de las listas de cubetas al mostrar el contenido de las tablas de símbolos.
-v
--version
Muestra el número de versión de readelf.
-W
--wide
No divide las líneas de salida para ajustarse a 80 columnas. De forma predeterminada readelf divide las líneas de listado de encabezados de sección y segmentos para archivos ELF de 64 bits, de modo que se ajusten a 80 columnas. Esta opción hace que readelf imprima cada encabezado de sección respectivamente cada segmento en una sola línea, lo cual es mucho más legible en terminales más anchos que 80 columnas.
-T
--silent-truncation
Normalmente cuando readelf muestra un nombre de símbolo, y tiene que truncar el nombre para ajustarlo a una visualización de 80 columnas, añadirá un sufijo de "[...]" al nombre. Esta opción de línea de comando deshabilita este comportamiento, permitiendo mostrar 5 caracteres más del nombre y restaurando el comportamiento antiguo de readelf (antes de la versión 2.35).
-H
--help
Muestra las opciones de línea de comando reconocidas por readelf.
@file
Lee opciones de línea de comando desde file. Las opciones leídas se insertan en lugar de la opción original @file . Si file no existe, o no se puede leer, entonces la opción se tratará literalmente, y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Un carácter en blanco puede incluirse en una opción rodeando toda la opción entre comillas simples o dobles. Cualquier carácter (incluyendo una barra invertida) puede incluirse anteponiendo al carácter a incluir una barra invertida. El file puede contener opciones adicionales @file ; cualquier opción de este tipo se procesará recursivamente.
