DESCRIPCIÓ

N

El propósito de un depurador como GDB es permitirle ver qué está sucediendo "dentro" de otro programa mientras se ejecuta, o qué estaba haciendo otro programa en el momento en que se

bloqueó.

GDB puede hacer cuatro tipos principales de cosas (más otras cosas en apoyo de estas) para ayudarle a atrapar errores en el

acto:
  • Iniciar su programa, especificando cualquier cosa que pueda afectar su
    • comportamiento.
  • Hacer que su programa se detenga en condiciones
    • especificadas.
  • Examinar lo que ha sucedido cuando su programa se ha
    • detenido.
  • Cambiar cosas en su programa, para que pueda exp
    • erimentar con la corrección de los efectos
de un error y continuar aprendiendo sobre otro.

Puede usar GDB para depurar programas escritos en C, C++, Fortran y

Modula-2.

GDB se invoca con el comando de shell "gdb". Una vez iniciado, lee comandos desde la terminal hasta que le indique salir con el comando de GDB "quit" o "exit". Puede obtener ayuda en línea de GDB mismo usando el comando "help"

.

Puede ejecutar "gdb" sin argumentos u opciones; pero la forma más usual de iniciar GDB es con un argumento o dos, especificando un programa ejecutable como

argumento: 
gdb
program

También puede iniciar con un programa ejecutable y un archivo de volcado de memoria (core)

especificados: 
gdb program
core

Puede, en cambio, especificar un ID de proceso como segundo argumento o usar la opción "-p", si quiere depurar un proceso en

ejecución: 
gdb program 1234
gdb -p
1234

adjuntaría GDB al proceso 1234. Con la opción -p puede omitir el nombre de archivo del

programa.

Cualquier argumento que no sea una opción especifica un archivo ejecutable y un archivo de volcado de memoria (o ID de proceso); es decir, el primer argumento encontrado sin una opción de bandera asociada es equivalente a una opción --se, y el segundo, si existe, es equivalente a una opción -c si es el nombre de un archivo. Muchas opciones tienen tanto formas largas como abreviadas; ambas se muestran aquí. Las formas largas también se reconocen si las trunca, siempre que la opción presente sea suficiente para ser

inequívoca.
