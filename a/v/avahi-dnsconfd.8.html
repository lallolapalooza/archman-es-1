avahi-dnsconfd(8) Manual del Administrador del Sistema avahi-dnsconfd(8)

NOMBRE

avahi-dnsconfd - Demonio de configuración de DNS unicast de mDNS/DNS-SD

SINOPSIS

avahi-dnsconfd [opciones]

avahi-dnsconfd --kill

avahi-dnsconfd --refresh

avahi-dnsconfd --check

DESCRIPCIÓN

avahi-dnsconfd se conecta a un avahi-daemon en ejecución y ejecuta el script /etc/avahi/avahi-dnsconfd.action para cada servidor DNS unicast que se anuncia en la LAN local. Esto es útil para configurar servidores DNS unicast de forma similar a DHCP con mDNS.

OPCIONES

-D | --daemonize
Se ejecuta como demonio después del inicio y redirige los mensajes de registro a syslog.
-s | --syslog
Registra en syslog en lugar de STDERR. Implícito por --daemonize.
-k | --kill
Detiene un avahi-dnsconfd en ejecución. (equivalente a enviar una SIGTERM)
-r | --refresh
Indica a un avahi-dnsconfd en ejecución que actualice los datos del servidor DNS. (equivalente a enviar una SIGHUP)
-c | --check
Devuelve 0 como código de retorno si avahi-dnsconfd ya está en ejecución.
-h | --help
Muestra la ayuda
-v | --version
Muestra información de la versión

ARCHIVOS

/etc/avahi/avahi-dnsconfd.action: el script que se ejecutará cuando se encuentre o elimine un servidor DNS.

SEÑALES

SIGINT, SIGTERM: avahi-dnsconfd se apagará. Esto se emite al pasar --kill a avahi-daemon.

SIGHUP: avahi-dnsconfd actualizará los datos del servidor DNS.

AUTORES

VER TAMBIÉN
