NOMBRE

avahi-autoipd.action - script de acción de avahi-autoipd

SINOPSIS

/etc/avahi/avahi-autoipd.action

DESCRIPCIÓN

avahi-autoipd.action es el script de acción que se llama cada vez que avahi-autoipd ha adquirido una dirección IP o cuando ha detectado un conflicto de direcciones IP. El script debe añadir o eliminar la dirección especificada de la interfaz de red especificada.

PARÁMETROS

argv[1] Una cadena de evento: uno de BIND, CONFLICT, UNBIND o STOP. Si se pasa BIND, se ha adquirido correctamente una dirección IP y el script debe añadirla a la interfaz de red. Si se pasa CONFLICT, avahi-autopid ha detectado una dirección IP en la red local, el script de acción debe eliminar la dirección IP configurada. Si se pasa UNBIND, la dirección IP también debe eliminarse de la interfaz, ya que algún otro programa ha configurado una dirección enrutable a la interfaz. Si se pasa STOP, avahi-autoipd se está deteniendo y el script de acción debe eliminar la dirección IP. En resumen: en BIND la dirección debe añadirse a la interfaz, en CONFLICT, UNBIND o STOP debe eliminarse.
argv[2] El nombre de la interfaz de red.
argv[3] Una dirección IP del rango IPv4LL.

AUTORES
