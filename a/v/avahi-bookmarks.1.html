avahi-bookmarks(1) Manual de comandos generales avahi-bookmarks(1)

NOMBRE

avahi-bookmarks - Servicio web que muestra servicios HTTP anunciados por mDNS/DNS-SD utilizando el demonio Avahi

SINOPSIS

avahi-bookmarks

DESCRIPCIÓN

Un servicio web para listar servicios HTTP que se anuncian a través de mDNS/DNS-SD utilizando el demonio Avahi. avahi-bookmarks abre un socket TCP en el puerto 8080 y espera conexiones HTTP entrantes, devolviendo un sitio web dinámico que contiene enlaces a todos los servicios del tipo _http._tcp en la LAN. Apunta tu navegador a http://localhost:8080/ para utilizar avahi-bookmarks.

OPCIONES

-p | --puerto= PUERTO
Especifica un número de puerto TCP para escuchar. Si se omite, por defecto es 8080.
-a | --direccion= direccion
Especifica una dirección IP en la que escuchar. Si se omite, por defecto es 127.0.0.1. Especifica 0.0.0.0 si deseas permitir acceso remoto.
-H | --nombres-host
Crea enlaces que apuntan a nombres de host mDNS en lugar de direcciones IP resueltas. Esto solo es compatible con tu navegador si ejecutas algún tipo de módulo NSS local para resolver nombres de host mDNS (por ejemplo, nss-mdns). Si se omiten -A y -H, avahi-bookmarks detecta si el soporte NSS está disponible localmente. Esta opción entra en conflicto con -A.
-A | --direcciones
Crea enlaces que apuntan a direcciones IP numéricas en lugar de nombres de host mDNS. Esto romperá el acceso a hosts que ejecutan servidores virtuales. Si se omiten -A y -H, avahi-bookmarks detecta si el soporte NSS está disponible localmente. Esta opción entra en conflicto con -H.
-d | --dominio=DOMINIO
El dominio en el que buscar servicios.
-h | --ayuda
Mostrar ayuda
