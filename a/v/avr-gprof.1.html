NOMBRE

gprof - muestra datos de perfil de grafo de llamadas

SINOPSIS

gprof [ -[abcDhilLrsTvwxyz] ] [ -[ABCeEfFJnNOpPqQRStZ][nombre] ]
[ -I dirs ] [ -d[num] ] [ -k desde/hasta ]
[ -m conteo-min ] [ -R archivo-mapa ] [ -t longitud-tabla ]
[ --[no-]fuente-anotada[=nombre] ]
[ --[no-]conteo-ejecuciones[=nombre] ]
[ --[no-]perfil-plano[=nombre] ] [ --[no-]grafo[=nombre] ]
[ --[no-]tiempo=nombre] [ --todas-las-lineas ] [ --breve ]
[ --depuracion[=nivel] ] [ --ordenacion-funciones ]
[ --ordenacion-archivos archivo-mapa ] [ --ruta-directorio=dirs ]
[ --mostrar-funciones-no-usadas ] [ --formato-archivo=nombre ]
[ --info-archivo ] [ --ayuda ] [ --linea ] [ --nombres-archivo-enlazado ]
[ --conteo-minimo=n ] [ --no-estatico ] [ --imprimir-ruta ]
[ --archivos-separados ] [ --grafo-llamadas-estatico ] [ --suma ]
[ --longitud-tabla=longitud ] [ --tradicional ] [ --version ]
[ --ancho=n ] [ --ignorar-no-funciones ]
[ --desenmascarar[=ESTILO] ] [ --no-desenmascarar ]
[--tabla-simbolos-externa=nombre]
[ archivo-imagen ] [ archivo-perfil ... ]

DESCRIPCIÓN

"gprof" produce un perfil de ejecución de programas en C, Pascal o Fortran77. El efecto de las rutinas llamadas se incorpora en el perfil de cada llamador. Los datos del perfil se toman del archivo de perfil del grafo de llamadas (gmon.out por defecto) que se crea con programas compilados con la opción -pg de "cc", "pc" y "f77". La opción -pg también enlaza versiones de las rutinas de biblioteca que están compiladas para perfilado. "Gprof" lee el archivo objeto dado (por defecto es "a.out") y establece la relación entre su tabla de símbolos y el perfil del grafo de llamadas de gmon.out. Si se especifican varios archivos de perfil, la salida de "gprof" muestra la suma de la información de perfil en los archivos de perfil dados.

"Gprof" calcula la cantidad de tiempo dedicado a cada rutina. Luego, estos tiempos se propagan a lo largo de los bordes del grafo de llamadas. Se descubren ciclos y las llamadas a un ciclo se hacen para compartir el tiempo del ciclo.

Varios formatos de salida están disponibles a partir del análisis.

El perfil plano muestra cuánto tiempo dedicó su programa a cada función y cuántas veces se llamó a esa función. Si simplemente desea saber qué funciones consumen la mayor parte del tiempo, aquí se indica concisamente.

El grafo de llamadas muestra, para cada función, qué funciones la llamaron, qué otras funciones llamó y cuántas veces. También hay una estimación de cuánto tiempo se dedicó a las subrutinas de cada función. Esto puede sugerir lugares donde podría intentar eliminar llamadas a funciones que consumen mucho tiempo.

La lista de código fuente anotado es una copia del código fuente del programa, etiquetada con el número de veces que se ejecutó cada línea del programa.

OPCIONES

Estas opciones especifican cuál de los varios formatos de salida debe producir "gprof".

Muchas de estas opciones toman un symspec opcional para especificar funciones a incluir o excluir. Estas opciones se pueden especificar múltiples veces, con diferentes symspecs, para incluir o excluir conjuntos de símbolos.

Especificar cualquiera de estas opciones anula los valores predeterminados (-p -q), que imprimen un perfil plano y un análisis del grafo de llamadas para todas las funciones.

"-A[symspec]"
"--fuente-anotada[=symspec]"
La opción -A hace que "gprof" imprima código fuente anotado. Si se especifica symspec, imprima la salida solo para los símbolos coincidentes.
"-b"
"--breve"
Si se proporciona la opción -b, "gprof" no imprime los textos explicativos verborreicos que intentan explicar el significado de todos los campos en las tablas. Esto es útil si tiene la intención de imprimir la salida o está cansado de ver los textos explicativos.
"-B"
La opción -B hace que "gprof" imprima el análisis del grafo de llamadas.
"-C[symspec]"
"--conteo-ejecuciones[=symspec]"
La opción -C hace que "gprof" imprima un recuento de funciones y el número de veces que se llamó a cada una. Si se especifica symspec, imprima el recuento solo para los símbolos coincidentes.

Si el archivo de datos de perfil contiene registros de recuento de bloques básicos, especificar la opción -l, junto con -C, hará que los recuentos de ejecución de bloques básicos se totalicen y se muestren.

"-i"
"--info-archivo"
La opción -i hace que "gprof" muestre información resumida sobre los archivos de datos de perfil y luego salga. Se muestra el número de registros de histograma, grafo de llamadas y recuento de bloques básicos.
"-I dirs"
"--ruta-directorio=dirs"
La opción -I especifica una lista de directorios de búsqueda en los que encontrar archivos fuente. La variable de entorno GPROF_PATH también se puede usar para transmitir esta información. Se utiliza principalmente para la salida de código fuente anotado.
"-J[symspec]"
"--no-fuente-anotada[=symspec]"
La opción -J hace que "gprof" no imprima código fuente anotado. Si se especifica symspec, "gprof" imprime código fuente anotado, pero excluye los símbolos coincidentes.
"-L"
"--imprimir-ruta"
Normalmente, los nombres de archivo de origen se imprimen suprimiendo el componente de ruta. La opción -L hace que "gprof" imprima la ruta completa de los nombres de archivo de origen, que se determina a partir de la información de depuración simbólica en el archivo imagen y es relativa al directorio en el que se invocó el compilador.
"-p[symspec]"
"--perfil-plano[=symspec]"
La opción -p hace que "gprof" imprima un perfil plano. Si se especifica symspec, imprima el perfil plano solo para los símbolos coincidentes.
"-P[symspec]"
"--no-perfil-plano[=symspec]"
La opción -P hace que "gprof" suprima la impresión de un perfil plano. Si se especifica symspec, "gprof" imprime un perfil plano, pero excluye los símbolos coincidentes.
"-q[symspec]"
"--grafo[=symspec]"
La opción -q hace que "gprof" imprima el análisis del grafo de llamadas. Si se especifica symspec, imprima el grafo de llamadas solo para los símbolos coincidentes y sus hijos.
"-Q[symspec]"
"--no-grafo[=symspec]"
La opción -Q hace que "gprof" suprima la impresión del grafo de llamadas. Si se especifica symspec, "gprof" imprime un grafo de llamadas, pero excluye los símbolos coincidentes.
"-t"
"--longitud-tabla=num"
La opción -t hace que se listen las num líneas de código fuente más activas en cada archivo fuente cuando la anotación de código fuente está habilitada. El valor predeterminado es 10.
"-y"
"--archivos-separados"
Esta opción solo afecta la salida de código fuente anotado. Normalmente, "gprof" imprime archivos de código fuente anotado en la salida estándar. Si se especifica esta opción, el código fuente anotado para un archivo llamado ruta/nombrearchivo se genera en el archivo nombrearchivo-ann. Si el sistema de archivos subyacente truncara nombrearchivo-ann de manera que sobrescribiera el nombrearchivo original, "gprof" generará código fuente anotado en el archivo nombrearchivo.ann en su lugar (si el nombre de archivo original tiene una extensión, esa extensión se reemplaza por .ann).
"-Z[symspec]"
"--no-conteo-ejecuciones[=symspec]"
La opción -Z hace que "gprof" no imprima el recuento de ejecuciones.

VER TAMBIÉN

gcc(1)

HISTORIA

El programa "gprof" apareció por primera vez en la versión 4.7 BSD de UNIX.

Li">"gprof" no imprimir un recuento de funciones y el número de veces que cada una fue llamada. Si symspec está especificado, imprimir el recuento, pero excluir los símbolos que coincidan.
"-r"
"--function-ordering"
La opción --function-ordering hace que "gprof" imprima un ordenamiento sugerido de funciones para el programa basado en los datos de perfilado. Esta opción sugiere un ordenamiento que puede mejorar el comportamiento de paginación, tlb y caché para el programa en sistemas que soportan un ordenamiento arbitrario de funciones en un ejecutable.

Los detalles exactos de cómo forzar al enlazador a colocar las funciones en un orden particular dependen del sistema y están fuera del alcance de este manual.

"-R map_file"
"--file-ordering map_file"
La opción --file-ordering hace que "gprof" imprima un ordenamiento sugerido de la línea de enlace de archivos .o para el programa basado en los datos de perfilado. Esta opción sugiere un ordenamiento que puede mejorar el comportamiento de paginación, tlb y caché para el programa en sistemas que no soportan un ordenamiento arbitrario de funciones en un ejecutable.

El uso del argumento -a es altamente recomendado con esta opción.

El argumento map_file es una ruta de acceso a un archivo que proporciona mapeos de nombres de funciones a archivos de objetos. El formato del archivo es similar a la salida del programa "nm".

c-parse.o:00000000 T yyparse
c-parse.o:00000004 C yyerrflag
c-lang.o:00000000 T maybe_objc_method_name
c-lang.o:00000000 T print_lang_statistics
c-lang.o:00000000 T recognize_objc_keyword
c-decl.o:00000000 T print_lang_identifier
c-decl.o:00000000 T print_lang_type
...

Para crear un map_file con GNU "nm", escriba un comando como "nm --extern-only --defined-only -v --print-file-name program-name".

"-T"
"--traditional"
La opción -T hace que "gprof" imprima su salida en estilo BSD "tradicional".
"-w width"
"--width=width"
Establece el ancho de las líneas de salida a width. Actualmente solo se usa al imprimir el índice de funciones en la parte inferior del grafo de llamadas.
"-x"
"--all-lines"
Esta opción afecta solo a la salida de código fuente anotado. De forma predeterminada, solo las líneas al comienzo de un bloque básico son anotadas. Si se especifica esta opción, cada línea en un bloque básico es anotada repitiendo la anotación de la primera línea. Este comportamiento es similar a "tcov"'s -a.
"--demangle[=style]"
"--no-demangle"
Estas opciones controlan si los nombres de símbolos C++ deben ser desenmascarados al imprimir la salida. El valor predeterminado es desenmascarar los símbolos. La opción --no-demangle puede usarse para desactivar el desenmascaramiento. Diferentes compiladores tienen diferentes estilos de enmascaramiento. El argumento opcional de estilo de desenmascaramiento puede usarse para elegir un estilo de desenmascaramiento apropiado para su compilador.

Opciones de Análisis

"-a"
"--no-static"
La opción -a hace que "gprof" suprima la impresión de funciones declaradas estáticamente (privadas). (Estas son funciones cuyos nombres no están listados como globales y que no son visibles fuera del archivo/función/bloque donde fueron definidas.) El tiempo pasado en estas funciones, las llamadas desde/hacia ellas, etc., serán atribuidos a la función que fue cargada directamente antes en el archivo ejecutable. Esta opción afecta tanto al perfil plano como al grafo de llamadas.
"-c"
"--static-call-graph"
La opción -c hace que el grafo de llamadas del programa sea aumentado por una heurística que examina el espacio de texto del archivo de objetos e identifica llamadas a funciones en el código máquina binario. Dado que los registros normales del grafo de llamadas solo se generan cuando se entra en funciones, esta opción identifica hijos que podrían haber sido llamados, pero nunca lo fueron. Las llamadas a funciones que no fueron compiladas con el perfilado habilitado también son identificadas, pero solo si existen entradas de tabla de símbolos para ellas. Las llamadas a rutinas de bibliotecas dinámicas típicamente no son encontradas por esta opción. Los padres o hijos identificados vía esta heurística se indican en el grafo de llamadas con recuentos de llamada de 0.
"-D"
"--ignore-non-functions"
La opción -D hace que "gprof" ignore los símbolos que no se sabe que son funciones. Esta opción dará datos de perfil más precisos en sistemas donde es soportada (Solaris y HPUX, por ejemplo).
"-k from/to"
La opción -k le permite eliminar del grafo de llamadas cualquier arco desde símbolos que coincidan con symspec from hacia aquellos que coincidan con symspec to.
"-l"
"--line"
La opción -l habilita el perfilado línea por línea, lo que hace que los aciertos del histograma se cobren a líneas individuales del código fuente, en lugar de a funciones. Esta característica solo funciona con programas compilados por versiones anteriores del compilador "gcc" . Las versiones más recientes de "gcc" están diseñadas para funcionar con la herramienta "gcov" en su lugar.

Si el programa fue compilado con el conteo de bloques básicos habilitado, esta opción también identificará cuántas veces se ejecutó cada línea de código. Aunque el perfilado línea por línea puede ayudar a aislar dónde en una función grande el programa está pasando su tiempo, también aumenta significativamente el tiempo de ejecución de "gprof", y amplifica las imprecisiones estadísticas.

"--inline-file-names"
Esta opción hace que "gprof" imprima el archivo fuente después de cada símbolo tanto en el perfil plano como en el grafo de llamadas. Se imprime la ruta completa al archivo si se usa con la opción -L .
"-m num"
"--min-count=num"
Esta opción afecta solo a la salida de conteo de ejecución. Los símbolos que se ejecutan menos de num veces son suprimidos.
"-nsymspec"
"--time=symspec"
La opción -n hace que "gprof", en su análisis de grafo de llamadas, solo propague tiempos para símbolos que coincidan con symspec.
"-Nsymspec"
"--no-time=symspec"
La opción -n hace que "gprof", en su análisis de grafo de llamadas, no propague tiempos para símbolos que coincidan con symspec.
"-Sfilename"
"--external-symbol-table=filename"
La opción -S hace que "gprof" lea un archivo de tabla de símbolos externo, como /proc/kallsyms, en lugar de leer la tabla de símbolos del archivo de objetos dado (el valor predeterminado es "a.out"). Esto es útil para perfilar módulos del kernel.
"-z"
"--display-unused-functions"
Si usted da la opción -z , "gprof" mencionará todas las funciones en el perfil plano, incluso aquellas que nunca fueron llamadas y en las que no se pasó tiempo. Esto es útil en conjunto con la opción -c para descubrir qué rutinas nunca fueron llamadas.

Opciones Varias

"-d[num]"
"--debug[=num]"
La opción -d num especifica opciones de depuración. Si num no está especificado, habilita toda la depuración.
"-h"
"--help"
La opción -h imprime el uso de la línea de comandos.
"-Oname"
"--file-format=name"
Selecciona el formato de los archivos de datos de perfil. Los formatos reconocidos son auto (el predeterminado), bsd, 4.4bsd, magic, y prof (aún no soportado).
"-s"
"--sum"
La opción -s hace que "gprof" resuma la información en los archivos de datos de perfil que leyó, y escriba un archivo de datos de perfil llamado gmon.sum, que contiene toda la información de los archivos de datos de perfil que "gprof" leyó. El archivo gmon.sum puede ser uno de los archivos de entrada especificados; el efecto de esto es fusionar los datos de los otros archivos de entrada en gmon.sum.

Eventualmente puede ejecutar "gprof" de nuevo sin -s para analizar los datos acumulados en el archivo gmon.sum.

"-v"
"--version"
La opción -v hace que "gprof" imprima el número de versión actual y luego salga.

Opciones Obsoletas

Estas opciones han sido reemplazadas por versiones más nuevas que usan symspecs.

"-e function_name"
La opción -e function le dice a "gprof" que no imprima información sobre la función function_name (y sus hijos...) en el grafo de llamadas. La función aún será listada como un hijo de cualquier función que la llame, pero su número de índice se mostrará como [not printed]. Se puede dar más de una opción -e ; solo se puede indicar un function_name con cada opción -e .
"-E function_name"
La opción "-E function" funciona como la opción "-e" , pero el tiempo pasado en la función (y en hijos que no fueron llamados desde ningún otro lugar), no se usará para calcular los porcentajes-de-tiempo para el grafo de llamadas. Se puede dar más de una opción -E ; solo se puede indicar un function_name con cada opción -E .
"-f function_name"
La opción -f function hace que &quot;gprof" para limitar el grafo de llamadas a la función function_name y sus hijos (y sus hijos...). Se puede indicar más de una -f opción; solo se puede indicar un function_name con cada -f opción.
"-F function_name"
La -F función opción funciona igual que la "-f" opción, pero solo el tiempo empleado en la función y sus hijos (y sus hijos...) se utilizará para determinar el tiempo total y los porcentajes de tiempo para el grafo de llamadas. Se puede indicar más de una -F opción; solo se puede indicar un function_name con cada -F opción. La -F opción anula la -E opción.

ARCHIVOS

"a.out"
el nombre y el espacio de texto.

ERRORES

La granularidad del muestreo se muestra, pero sigue siendo estadística en el mejor de los casos. Asumimos que el tiempo de cada ejecución de una función puede expresarse como el tiempo total de la función dividido por el número de veces que se llama a la función. Por lo tanto, el tiempo propagado a lo largo de los arcos del grafo de llamadas hacia los padres de la función es directamente proporcional al número de veces que se recorre ese arco.

Los padres que no son perfilados por sí mismos tendrán el tiempo de sus hijos perfilados propagado hacia ellos, pero aparecerán como invocados espontáneamente en el listado del grafo de llamadas, y su tiempo no se propagará más. De manera similar, los capturadores de señales, aunque estén perfilados, aparecerán como espontáneos (aunque por razones más oscuras). Cualquier hijo perfilado de los capturadores de señales debería tener sus tiempos propagados correctamente, a menos que el capturador de señales fuera invocado durante la ejecución de la rutina de perfilado, en cuyo caso se pierde todo.

El programa perfilado debe llamar a "exit"(2) o retornar normalmente para que la información de perfilado se guarde en el archivo gmon.out .
