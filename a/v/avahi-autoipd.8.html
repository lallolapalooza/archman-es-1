avahi-autoipd(8) Manual del Administrador del Sistema avahi-autoipd(8)

NOMBRE

avahi-autoipd - Demonio de configuración de direcciones de red IPv4LL

SINOPSIS

avahi-autoipd [opciones] interfaz

avahi-autoipd --kill interfaz

avahi-autoipd --refresh interfaz

avahi-autoipd --check interfaz

DESCRIPCIÓN

avahi-autoipd implementa IPv4LL, "Configuración Dinámica de Direcciones de Enlace Local IPv4" (IETF RFC3927), un protocolo para la configuración automática de direcciones IP del rango 169.254.0.0/16 de enlace local sin necesidad de un servidor central. Está destinado principalmente para ser utilizado en redes ad-hoc que carecen de un servidor DHCP.

IPv4LL es parte de la pila Zeroconf.

avahi-autoipd puede ser utilizado como un asignador de direcciones independiente o como un plugin para un cliente DHCP como dhclient de ISC, donde puede ser utilizado como solución de respaldo si no se encuentra un servidor DHCP.

Para permitir la comunicación entre hosts que solo tienen una dirección IPv4LL asignada y hosts que solo tienen una dirección IP enrutable asignada, puedes añadir las siguientes rutas a ambas configuraciones de red:

route add -net 169.254.0.0 netmask 255.255.0.0 dev eth0 metric 99

route add default dev eth0 metric 99

Consulta http://developer.apple.com/qa/qa2004/qa1357.html para más información.

OPCIONES

-D | --daemonize
Se convierte en un demonio después de iniciarse. Implica --syslog.
-k | --kill
Termina un avahi-autoipd en ejecución en la interfaz de red especificada. (Equivalente a enviar una señal SIGTERM)
-r | --refresh
Indica a un avahi-autoipd en ejecución que reanuncie la dirección IP adquirida en la interfaz de red especificada. (Equivalente a enviar una señal SIGHUP)
-c | --check
Devuelve 0 como código de retorno si avahi-autoipd ya se está ejecutando para la interfaz de red especificada.
-s | --syslog
Registra en syslog en lugar de STDERR. Implícito por --daemonize.
--debug
Habilita el modo detallado.
--no-drop-root
No descarta los privilegios de root después de iniciarse. Recomendamos no utilizar esta opción.
--no-chroot
No realiza un chroot(2) al demonio. Esta opción solo está disponible cuando se compila con soporte para chroot().
-S | --start=
Intenta adquirir la dirección IP especificada, que debe ser del rango IPv4LL 169.254.0.0/16.
-w | --wait
Espera hasta que se haya adquirido una dirección IP con éxito antes de desconectarse. Solo válido en combinación con --daemonize.
--force-bind
Adquiere una dirección IPv4LL, incluso si se ha configurado una dirección enrutable en la interfaz.
--no-proc-title
No cambia el nombre del proceso mientras se ejecuta. A menos que se especifique esta opción, avahi-autoipd reflejará su estado actual y la dirección IP en el título del proceso.
-h | --help
Muestra la ayuda.
-v | --version
Muestra información de la versión.

ARCHIVOS

/etc/avahi/avahi-autoipd.action: el script a ejecutar cuando se adquiere o se pierde una dirección IP.

SEñALES

SIGINT, SIGTERM: avahi-autoipd se apagará. (Igual que --kill)

SIGHUP: avahi-autoipd reanunciará la dirección IP adquirida. (Igual que --refresh)
