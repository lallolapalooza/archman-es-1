DESCRIPCIÓ

N

GNU nm lista los símbolos de los archivos de objetos objfile.... Si no se listan archivos de objetos como argumentos, nm asume el archivo a.ou

t.

Para cada símbolo, nm mues

tra:
  • El valor del símbolo, en la base seleccionada por las opciones (véase más abajo), o hexadecimal por
    • defecto.
  • El tipo de símbolo. Al menos los siguientes tipos se utilizan; otros también, dependiendo del formato del archivo de objeto. Si es minúscula, el símbolo es generalmente local; si es mayúscula, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúscula que se muestran para símbolos globales especiales ("u", "v" y "w
    • ")

Para archivos de formato ELF esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que si es referenciado por una reubicación no se evalúa a su dirección, sino que debe ser invocado en tiempo de ejecución. Cuando un símbolo débil no definido se vincula y el símbolo no está definido, el valor del símbolo se determina de una manera específica del sistema sin error. En algunos sistemas, la mayúscula indica que se ha especificado un valor por

ame
Anteponer a cada símbolo el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada una sola vez, antes de todos sus
símbolos.

--debug-sy
ms
Mostrar todos los símbolos, incluso los símbolos solo para depurador; normalmente estos no se

-
B
Igual que --format=bsd (para compatibilidad con el nm de
MIPS).
-
C
--demangle[=style
]
Decodificar (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial añadido por el sistema, esto hace legibles los nombres de funciones de C++. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling puede usarse para elegir un estilo de demangling apropiado para su
compilador.
--no-demang
le
No hacer demangle de nombres de símbolos de bajo nivel. Este es el valor por
defecto.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al desensamblar cadenas. Dado que los formatos de "mangled names" permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote el espacio de pila disponible en la máquina host, desencadenando un error de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidación.

El valor predeterminado es que este límite esté habilitado, pero puede ser necesario deshabilitarlo para desensamblar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

-D
--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
-f formato
--format=formato
Usa el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". El valor predeterminado es "bsd". Solo el primer carácter de formato es significativo; puede ser mayúscula o minúscula.
-g
--extern-only
Muestra solo símbolos externos.
-h
--help
Muestra un resumen de las opciones de nm y sale.
--ifunc-chars=CHARS
Al mostrar símbolos de funciones indirectas de GNU, nm usará por defecto el carácter "i" tanto para funciones indirectas locales como para funciones indirectas globales. La opción --ifunc-chars permite al usuario especificar una cadena que contenga uno o dos caracteres. El primer carácter se usará para símbolos de funciones indirectas globales y el segundo carácter, si está presente, se usará para símbolos de funciones indirectas locales.
j
Lo mismo que --format=just-symbols.
-l
--line-numbers
Para cada símbolo, utiliza información de depuración para intentar encontrar un nombre de archivo y un número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que se refiera al símbolo. Si se puede encontrar información del número de línea, imprímela después de la otra información del símbolo.
--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue insertada en línea, esta opción hace que se imprima también la información de origen de todos los ámbitos contenedores hasta la primera función no insertada en línea. Por ejemplo, si "main" inserta en línea a "callee1" que inserta en línea a "callee2", y la dirección proviene de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
-p
--no-sort
No molestarse en ordenar los símbolos en ningún orden; imprímelos en el orden en que se encuentran.
-P
--portability
Utiliza el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
-r
--reverse-sort
Invierte el orden de la clasificación (ya sea numérica o alfabética); que el último venga primero.
-S
--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que también se use --size-sort, en cuyo caso se muestra un tamaño calculado.

Note that this option has no effect for object formats that do not record symbol sizes, unless --size-sort is also used in which case a calculated size is displayed.

-s
--print-armap
Al listar símbolos de miembros de archivo, incluye el índice: un mapeo (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
-t base
--radix=base
Usa base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
-u
--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por predeterminado, se muestran tanto los símbolos definidos como los indefinidos.
-U
--defined-only
Muestra solo símbolos definidos para cada archivo objeto. Por predeterminado, se muestran tanto los símbolos definidos como los indefinidos.
-V
--version
Muestra el número de versión de nm y sale.
-X
Esta opción se ignora por compatibilidad con la versión de AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de nm de AIX corresponde a -X 32, que no es compatible con el nm de GNU.
--plugin nombre
Carga el plugin llamado nombre para agregar soporte a tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se compiló con el soporte de plugins habilitado.

Si no se proporciona --plugin, pero el soporte de plugins ha sido habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se utiliza el primer plugin que reclama el objeto en cuestión.

Tenga en cuenta que este directorio de búsqueda de plugins es no el que utiliza la opción -plugin de ld. Para hacer que nm use el plugin del enlazador, debe copiarse al directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin de GCC siempre es compatible con versiones anteriores, por lo que es suficiente copiar el más reciente.

--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen de ELF; para otros tipos de objeto, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor más alto. Si se utiliza el formato de salida "bsd", se imprime el tamaño del símbolo en lugar del valor, y se debe usar -S para que se impriman tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

--special-syms
Muestra símbolos que tienen un significado especial específico del objetivo. Estos símbolos son usualmente usados por el objetivo para algún procesamiento especial y normalmente no son útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para objetivos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar transiciones entre código ARM, código THUMB y datos.
--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para diversos propósitos. No se muestran por defecto ya que no forman parte del código fuente original del binario.
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en las cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirlos. Las opciones --unicode=hex y --unicode=invalid las muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape las muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight las muestra como secuencias de escape resaltadas en rojo (si el dispositivo de salida lo admite). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde podrían no esperarse.

-W
--no-weak
No muestra símbolos débiles.
--with-symbol-versions
--without-symbol-versions
Habilita o deshabilita la visualización de información de versiones de símbolos. La cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo, foo@VER_1. Si la versión es la versión predeterminada que se debe usar al resolver referencias sin versión al símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo foo@@VER_2. Por defecto, se muestra la información de versión del
símbolo.
--target=bfdna
me

sistema.
