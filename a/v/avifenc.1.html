AVIFENC(1) Manual de Comandos Generales AVIFENC(1)

NOMBRE

avifenc - comprime un archivo de imagen a un archivo AVIF

SINOPSIS

avifenc [opciones] entrada.[jpg|jpeg|png|y4m] salida.avif

DESCRIPCIÓN

avifenc comprime un archivo de imagen a un archivo AVIF. El formato de entrada puede ser JPEG, PNG o YUV4MPEG2 (Y4M).

OPCIONES

-h, --help
Muestra la ayuda de sintaxis.
-V, --version
Muestra el número de versión.

OPCIONES BÁSICAS

-q, --qcolor Q
Calidad para el color en 0..100, donde 100 es sin pérdida.
--qalpha Q
Calidad para el canal alfa en 0..100, donde 100 es sin pérdida.
-s, --speed S
Velocidad del codificador en 0..10, donde 0 es la más lenta y 10 la más rápida. O `default' o `d' para los valores predeterminados internos del códec. (Predeterminado: 6).

OPCIONES AVANZADAS

-j, --jobs J
Número de trabajos (hilos de trabajo), o `all' para usar potencialmente tantos núcleos como sea posible. (Predeterminado: all).
--no-overwrite
Nunca sobrescribir el archivo de salida existente.
-o, --output NOMBREDEARCHIVO
En lugar de usar el último nombre de archivo dado como salida, usar este nombre de archivo.
-l, --lossless
Establece todos los valores predeterminados para codificar sin pérdida, y emite advertencias cuando la configuración o la entrada no lo permiten.
-d, --depth D
Profundidad de salida, uno de 8, 10 o 12. (Solo JPEG/PNG; para y4m o stdin, la profundidad se conserva).
-y, --yuv FORMATO
Formato de salida, uno de `auto' (predeterminado), 444, 422, 420 o 400. Ignorado para y4m o stdin (el formato y4m se conserva).

Para JPEG, auto respeta el formato interno del JPEG, si es posible. Para PNG en escala de grises, auto usa 400 por defecto.

Para todos los demás casos, auto usa 444 por defecto.

-p, --premultiply
Premultiplica el color por el canal alfa y señala esto en el AVIF.
--sharpyuv
Usa la conversión RGB a YUV420 nítida (si es compatible). Ignorado para y4m o si la salida no es 420.
--stdin
Lee fotogramas y4m desde stdin en lugar de archivos; no se permiten nombres de archivo de entrada, debe establecerse antes de proporcionar el nombre de archivo de salida.
--cicp, --nclx P/T/M
Establece los valores CICP (caja de color nclx) (3 números crudos, usa -r para establecer el indicador de rango).
•
P = primarios de color
•
T = características de transferencia
•
M = coeficientes de matriz

Usa 2 para cualquiera que desees dejar sin especificar.

-r, --range RANGO
Rango YUV, uno de `limited' o `l', `full' o `f'. (Solo JPEG/PNG, predeterminado: full; para y4m o stdin, el rango se conserva).
--target-size S
Establece el tamaño de archivo objetivo en bytes (hasta 7 veces más lento)
--progressive
EXPERIMENTAL: Establece automáticamente los parámetros para codificar una imagen por capas simple que admite renderizado progresivo a partir de un solo fotograma de entrada.
--layered
EXPERIMENTAL: Codifica un AVIF por capas. Cada entrada se codifica como una capa y se pueden codificar como máximo 4 capas.
-g, --grid MxN
Codifica un AVIF de cuadrícula de una sola imagen con M columnas y N filas. Proporciona MxN imágenes idénticas en W/H/D, o una sola imagen que se pueda dividir uniformemente en la cuadrícula MxN y sigue las restricciones de imagen de cuadrícula AVIF. La cuadrícula adoptará el perfil de color de la primera imagen proporcionada.
-c, --codec C
Códec a usar.

Los valores posibles dependen de los códecs habilitados en tiempo de compilación (ver --help o --version para los códecs disponibles). El predeterminado se selecciona automáticamente de los códecs disponibles.

Los valores posibles son:
•
aom
•
rav1e
•
svt
--exif NOMBREDEARCHIVO
Proporciona una carga útil de metadatos Exif para asociar con el elemento principal (implica --ignore-exif).
--xmp NOMBREDEARCHIVO
Proporciona una carga útil de metadatos XMP para asociar con el elemento principal (implica --ignore-xmp).
--icc NOMBREDEARCHIVO
Proporciona una carga útil de perfil ICC para asociar con el elemento principal (implica --ignore-icc).
--timescale, --fps V
Escala de tiempo para secuencias de imágenes. Si todos los fotogramas tienen una duración de 1 unidad de escala de tiempo, esto equivale a fotogramas por segundo. (Predeterminado: 30) Si no se establece ni la duración ni la escala de tiempo, avifenc intentará usar la frecuencia de actualización almacenada en un encabezado y4m, si está presente.
-k, --keyframe INTERVALO
Intervalo máximo de fotograma clave para secuencias de imágenes (cualquier conjunto de INTERVALO fotogramas consecutivos tendrá al menos un fotograma clave). Establecer a 0 para desactivar (predeterminado).
--ignore-exif
Si el archivo de entrada contiene metadatos Exif incrustados, ignorarlos (no-op si están ausentes).
--ignore-xmp
Si el archivo de entrada contiene metadatos XMP incrustados, ignorarlos (no-op si están ausentes).
--ignore-profile, --ignore-icc
Si el archivo de entrada contiene un perfil de color incrustado, ignorarlo (no-op si está ausente).
--ignore-gain-map
Si el archivo de entrada contiene un mapa de ganancia incrustado, ignorarlo (no-op si está ausente).
--qgain-map Q
Calidad para el mapa de ganancia en 0..100, donde 100 es sin pérdida.
--pasp H,V
Añade la propiedad pasp (relación de aspecto). H=espaciado horizontal, V=espaciado vertical.
--crop CROPX,CROPY,CROPW,CROPH
Añade la propiedad clap (apertura limpia), pero calculada a partir de un rectángulo de recorte.
--clap WN,WD,HN,HD,HON,HOD,VON,VOD
Añade la propiedad clap (apertura limpia). Ancho, Alto, HOffset, VOffset (en pares numerador/denominador).
--irot ÁNGULO
Añade la propiedad irot (rotación) en 0..3. Hace una rotación de (90 * ÁNGULO) grados en sentido antihorario.
--imir EJE
Añade la propiedad imir (reflejo). 0=de arriba a abajo, 1=de izquierda a derecha.
--clli MaxCLL,MaxPALL
Añade la propiedad clli (información de nivel de luz del contenido).
--repetition-count N
Nombre de fois qu'une séquence d'images animée sera répétée, ou `infinite' pour des répétitions infinies. (Par défaut : infinite)
