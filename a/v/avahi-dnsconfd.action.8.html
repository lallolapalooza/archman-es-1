NOMBRE

avahi-dnsconfd.action - script de acción de avahi-dnsconfd

SINOPSIS

/etc/avahi/avahi-dnsconfd.action

DESCRIPCIÓN

avahi-dnsconfd.action es el script de acción que se llama cada vez que avahi-dnsconfd encuentra o elimina un nuevo servidor DNS unicast. El script predeterminado que se envía con avahi modifica /etc/resolv.conf para reflejar la configuración cambiada del servidor DNS unicast.

PARÁMETROS

argv[1] Contiene el carácter "+" si el servidor DNS es nuevo, "-" cuando debe eliminarse de la lista de servidores DNS.
argv[2] La dirección IP del servidor DNS.
argv[3] Número de interfaz de red numérica en la que se encontró este servidor DNS.
argv[4] Número de protocolo numérico en el que se encontró este servidor DNS. (generalmente 2 para IPv4 y 10 para IPv6)

ENTORNO

AVAHI_INTERFACE Contiene el nombre de la interfaz textual que corresponde a argv[3]. (por ejemplo, "eth0")
AVAHI_INTERFACE_DNS_SERVERS Contiene una lista de todos los servidores DNS que avahi-dnsconfd encontró en la interfaz $AVAHI_INTERFACE, separados por espacios.
AVAHI_DNS_SERVERS Contiene una lista de todos los servidores DNS que avahi-dnsconfd encontró en todas las interfaces, separados por espacios.

AUTORES
