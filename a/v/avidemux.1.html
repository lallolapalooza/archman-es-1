AVIDEMUX(1) Documentación de Avidemux AVIDEMUX(1)

NOMBRE

Avidemux — un editor de vídeo gratuito

SINOPSIS

avidemux [opciones]

avidemux_gtk [opciones]

avidemux_cli [opciones] [archivos ...]

DESCRIPCIÓN

Avidemux es un editor de vídeo gratuito diseñado para tareas sencillas de corte, filtrado y codificación. Soporta muchos tipos de archivos, incluyendo AVI, MPG (VCD, SVCD), MPEG compatible con DVD, MP4 y ASF, utilizando una variedad de códecs. Las tareas pueden automatizarse utilizando proyectos, cola de trabajos y potentes capacidades de scripting.

Página principal: http://avidemux.sourceforge.net/

SCRIPTS PERSONALIZADOS

La configuración de codificación personalizada se puede crear con el motor de scripting. Realiza los siguientes pasos:
1. Inicia avidemux y abre cualquier archivo de vídeo.
2. Configura tus propios ajustes de codificación.
3. Guarda los ajustes como un proyecto (Archivo -> Guardar proyecto como...) con el sufijo ".js".
4. Cierra avidemux.
5. Abre el archivo de proyecto en un editor simple y elimina las líneas inútiles.
* Necesitas la primera línea "//AD" y la línea "app = new Avidemux()"
* y los ajustes de codificación que comienzan con "app.video.codec(...)".
6. Guarda este archivo de script con el sufijo ".js" en el directorio de usuario "~/.avidemux/custom".
7. Este script personalizado ahora está disponible en avidemux bajo el elemento de menú "Custom".
