NOMBRE

gdb-add-index - Añade archivos de índice para acelerar GDB

SINOPSIS

gdb-add-index [-dwarf-5] nombre_archivo

DESCRIPCIÓN

Cuando GDB encuentra un archivo de símbolos, escanea los símbolos en el archivo para construir una tabla de símbolos interna. Esto permite que la mayoría de las operaciones de GDB funcionen rápidamente, a costa de un retraso inicial. Para programas grandes, este retraso puede ser bastante largo, por lo que GDB ofrece una forma de crear un índice, que acelera el inicio.

Para determinar si un archivo contiene dicho índice, usa el comando "readelf -S nombre_archivo": el índice se almacena en una sección llamada ".gdb_index" (pre-DWARF 5) o ".debug_names" y ".debug_str" (DWARF 5). Los índices solo pueden producirse en sistemas que usan binarios ELF e información de depuración DWARF (es decir, secciones llamadas ".debug_*").

Por defecto, gdb-add-index añadirá una sección pre-DWARF 5 ".gdb_index" a nombre_archivo. Con -dwarf-5, se añadirán secciones DWARF 5 en su lugar.

nombre_archivo debe ser escribible.

gdb-add-index usa GDB, objcopy y readelf encontrados en la variable de entorno PATH. Si quieres usar versiones diferentes de estos programas, puedes especificarlas a través de las variables de entorno apropiadas (ver abajo).

gdb-add-index sale con estado 0 si tiene éxito en crear el índice para nombre_archivo o mayor que 0 si ocurre un error.

Ver más en el manual de GDB en el nodo "Index Files" -- comando de shell "info -f gdb -n "Index Files"".

OPCIONES

-dwarf-5
Añade secciones DWARF 5 en lugar de la sección ".debug_index" anterior.

ENTORNO

GDB
Nombre de archivo completo del programa "gdb" a usar para la generación del índice. Si no está configurado, se buscará un programa "gdb" en el PATH.
OBJCOPY
Nombre de archivo completo del programa "objcopy" a usar para copiar información de sección al archivo dado. Si no está configurado, se buscará un programa "objcopy" en el PATH.
READELF
Nombre de archivo completo del programa "readelf" a usar para inspeccionar propiedades del archivo dado. Si no está configurado, se buscará un programa "readelf" en el PATH.

VER TAMBIÉN

La documentación completa para GDB se mantiene como un manual Texinfo. Si los programas "info" y "gdb" y la documentación Texinfo de GDB están correctamente instalados en tu sitio, el comando

info gdb

debería darte acceso al manual completo.
