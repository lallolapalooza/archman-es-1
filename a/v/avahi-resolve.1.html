avahi-resolve(1) Manual de Comandos Generales avahi-resolve(1)

NOMBRE

avahi-resolve - Resuelve uno o más nombres de host mDNS/DNS a direcciones IP (y viceversa) usando el demonio Avahi

SINOPSIS

avahi-resolve --name nombre-host ...

avahi-resolve-host-name nombre-host ...

avahi-resolve --address direccion ...

avahi-resolve-address direccion ...

DESCRIPCIÓN

Resuelve uno o más nombres de host mDNS/DNS a direcciones IP (y viceversa) usando el demonio Avahi.

OPCIONES

Al pasar -n, especifica uno o más nombres de host mDNS/DNS completamente calificados (por ejemplo, "foo.local") para resolver en direcciones IP en la línea de comandos.

Al pasar -a, especifica una o más direcciones IP para resolver en nombres de host. Cuando enable-wide-area está configurado en yes en avahi-daemon.conf(5), las búsquedas inversas pasarán primero por DNS unicast y luego recurrirán a mDNS.

avahi-resolve-host-name es equivalente a avahi-resolve --name.

avahi-resolve-address es equivalente a avahi-resolve --address.

-n | --name
Traduce uno o más nombres de host completamente calificados a direcciones.
-a | --address
Traduce una o más direcciones a nombres de host completamente calificados.
-v | --verbose
Habilita el modo detallado.
-6
Al resolver un nombre de host, busca exclusivamente direcciones IPv6.
-4
Al resolver un nombre de host, busca exclusivamente direcciones IPv4.
-h | --help
Muestra la ayuda.
-V | --version
Muestra información de la versión.

AUTORES

Los desarrolladores de Avahi <avahi (at) lists (dot) freedesktop (dot) org>; Avahi está disponible en http://avahi.org/
