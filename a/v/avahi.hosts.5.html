avahi.hosts(5) Manual de formatos de archivo avahi.hosts(5)

NOMBRE

avahi.hosts - archivo de nombres de host estáticos de avahi-daemon

SINOPSIS

/etc/avahi/hosts

DESCRIPCIÓN

/etc/avahi/hosts es un archivo que se puede utilizar para definir mapeos estáticos de nombre de host a dirección IP para Multicast DNS. Esto es especialmente útil al publicar servicios DNS-SD en nombre de otros hosts. Consulte avahi.service(5) para obtener más información.

El formato del archivo es similar al de /etc/hosts: en cada línea una dirección IP y el nombre de host correspondiente. Los nombres de host deben estar en formato FQDN, es decir, con el sufijo .local añadido.

AUTORES

Los desarrolladores de Avahi <avahi (at) lists (dot) freedesktop (dot) org>; Avahi está disponible en http://avahi.org/

VER TAMBIÉN
