GSTACK(1) Herramientas de desarrollo de GNU GSTACK(1)

NOMBRE

gstack - Imprime un rastreo de pila de un programa en ejecución

SINOPSIS

gstack [-h | --help] [-v | --version] pid

DESCRIPCIÓN

Imprime un rastreo de pila de un programa en ejecución con el ID de proceso pid. Si el proceso es multihilo, gstack genera rastreos de pila para cada hilo que existe en el proceso.

El script invoca GDB, se adjunta al ID de proceso dado, imprime el rastreo de pila y se desvincula del proceso.

gstack sale con un estado distinto de cero si "gdb" no pudo adjuntarse al ID de proceso dado por cualquier motivo, como un ID de proceso inexistente o privilegios insuficientes para adjuntarse al proceso.

OPCIONES

--help
-h
Lista todas las opciones con explicaciones breves.
--version
-v
Imprime la información de la versión y luego sale.

AMBIENTE

AWK
Nombre completo del archivo para un intérprete Awk a utilizar. Si no está establecido, se buscará en el PATH un programa "awk".
GDB
Nombre completo del archivo para un ejecutable GDB a utilizar para generar rastreos de pila. Si no está establecido, se buscará en el PATH un programa "gdb".
GDBARGS
Argumentos opcionales que se pasarán al programa "gdb".

VER TAMBIÉN

La documentación completa de GDB se mantiene como un manual de Texinfo. Si los programas "info" y "gdb" y la documentación Texinfo de GDB están instalados correctamente en su sitio, el comando

info gdb

debería darle acceso al manual completo.

Using GDB: A Guide to the GNU Source-Level Debugger, Richard M. Stallman y Roland H. Pesch, Julio de 1991.
