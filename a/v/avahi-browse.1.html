NOMBRE

avahi-browse - Buscar servicios mDNS/DNS-SD usando el demonio Avahi

SINOPSIS

avahi-browse [opciones] tipo-de-servicio

avahi-browse [opciones] --all

avahi-browse [opciones] --browse-domains

avahi-browse [opciones] --dump-db

avahi-browse-domains [opciones]

DESCRIPCIÓN

Buscar servicios de red mDNS/DNS-SD y dominios de búsqueda usando el demonio Avahi.

OPCIONES

Especifique un tipo de servicio DNS-SD (p. ej., _http._tcp) para buscar en la línea de comandos, o -a para buscar todos los tipos de servicio disponibles. Los elementos que aparecen en la red se prefijan con "+", los elementos que desaparecen se prefijan con "-". Si se pasa --resolve, los elementos que se resuelven se prefijan con "=".

-a | --all
Buscar todos los tipos de servicio registrados en la LAN, no solo el especificado en la línea de comandos.
-D | --browse-domains
Buscar dominios de búsqueda en lugar de servicios. avahi-browse-domains es equivalente a avahi-browse --browse-domains.
-d | --domain= DOMINIO
Buscar en el dominio especificado. Si se omite, avahi-browse buscará en el dominio de búsqueda predeterminado (normalmente: local).
-v | --verbose
Habilitar el modo detallado.
-t | --terminate
Terminar después de volcar una lista más o menos completa.
-c | --cache
Terminar después de volcar todas las entradas disponibles en la caché.
-l | --ignore-local
Ignorar servicios locales, mostrar solo servicios remotos.
-r | --resolve
Resolver automáticamente los servicios encontrados.
-f | --no-fail
No fallar si el demonio no se encuentra en ejecución. En su lugar, esperar hasta que aparezca. Si se desconecta, intentar reconectar.
-p | --parsable
Hacer que la salida sea fácilmente analizable para su uso en scripts. Si está habilitado, los campos se separan por punto y coma (;), los nombres de servicio se escapan. Se recomienda combinar esto con --no-db-lookup.
-k | --no-db-lookup
No buscar tipos de servicio en la base de datos de tipos de servicio.
-b | --dump-db
Volcar la base de datos de tipos de servicio (se puede combinar con -k)
-h | --help
Mostrar ayuda.
-V | --version
Mostrar información de la versión.

AUTORES
