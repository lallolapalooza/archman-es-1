avr-windres(1)

WINDRES(1) Herramientas de desarrollo GNU WINDRES(1)

NOMBRE

windres - manipula recursos de Windows

SINOPSIS

windres [opciones] [archivo-de-entrada] [archivo-de-salida]

DESCRIPCIÓN

windres lee recursos de un archivo de entrada y los copia en un archivo de salida. Cualquiera de los archivos puede estar en uno de tres formatos:

"rc"
Un formato de texto leído por el Compilador de Recursos.
"res"
Un formato binario generado por el Compilador de Recursos.
"coff"
Un objeto o ejecutable COFF.

La descripción exacta de estos diferentes formatos está disponible en la documentación de Microsoft.

Cuando windres convierte del "rc" formato al "res" formato, actúa como el Compilador de Recursos de Windows. Cuando windres convierte del "res" formato al "coff" formato, actúa como el programa de Windows "CVTRES" .

Cuando windres genera un "rc" archivo, la salida es similar pero no idéntica al formato esperado para la entrada. Cuando un "rc" archivo de entrada hace referencia a un nombre de archivo externo, un "rc" archivo de salida incluirá en su lugar el contenido del archivo.

Si el formato de entrada o salida no se especifica, windres lo deducirá basándose en el nombre del archivo o, en el caso del archivo de entrada, en el contenido del archivo. Un archivo con una extensión de .rc se tratará como un "rc" archivo, un archivo con una extensión de .res se tratará como un "res" archivo, y un archivo con una extensión de .o o .exe se tratará como un "coff" archivo.

Si no se especifica un archivo de salida, windres imprimirá los recursos en "rc" formato a la salida estándar.

El uso normal es que usted escriba un "rc" archivo, use windres para convertirlo en un archivo objeto COFF, y luego enlace el archivo COFF en su aplicación. Esto hará que los recursos descritos en el "rc" archivo estén disponibles para Windows.

OPCIONES

-i nombre-de-archivo
--input nombre-de-archivo
El nombre del archivo de entrada. Si esta opción no se usa, entonces windres usará el primer argumento que no sea una opción como el nombre del archivo de entrada. Si no hay argumentos que no sean opciones, entonces windres leerá de la entrada estándar. windres no puede leer un archivo COFF de la entrada estándar.
-o nombre-de-archivo
--output nombre-de-archivo
El nombre del archivo de salida. Si esta opción no se usa, entonces windres usará el primer argumento que no sea una opción, después de cualquier uso para el nombre del archivo de entrada, como el nombre del archivo de salida. Si no hay argumentos que no sean opciones, entonces windres escribirá a la salida estándar. windres no puede escribir un archivo COFF a la salida estándar. Nótese que, por compatibilidad con rc la opción -fo también es aceptada, pero su uso no es recomendado.
-J formato
--input-format formato
El formato de entrada a leer. formato puede ser res, rc, o coff. Si no se especifica un formato de entrada, windres lo deducirá, como se describe arriba.
-O formato
--output-format formato
El formato de salida a generar. formato puede ser res, rc, o coff. Si no se especifica un formato de salida, windres lo deducirá, como se describe arriba.
-F destino
--target destino
Especifica el formato BFD a usar para un archivo COFF como entrada o salida. Este es un nombre de destino BFD; puede usar la --help opción para ver una lista de destinos soportados. Normalmente windres usará el formato por defecto, que es el primero listado por la --help opción.
--preprocessor programa
Cuando windres lee un "rc" archivo, lo ejecuta primero a través del preprocesador de C. Esta opción puede usarse para especificar el preprocesador a usar. El preprocesador por defecto es "gcc".
--preprocessor-arg opción
Cuando windres lee un "rc" archivo, lo ejecuta primero a través del preprocesador de C. Esta opción puede usarse para especificar texto adicional a pasar al preprocesador en su línea de comandos. Esta opción puede usarse múltiples veces para añadir múltiples opciones a la línea de comandos del preprocesador. Si la --preprocessor opción no ha sido especificada, entonces se usará un conjunto por defecto de argumentos del preprocesador, con cualquier --preprocessor-arg opciones colocadas después de ellos en la línea de comandos. Estos argumentos por defecto son "-E", "-xc-header" y "-DRC_INVOKED".
-I directorio
--include-dir directorio
Especifica un directorio de inclusión a usar cuando se lee un "rc" archivo. windres pasará esto al preprocesador como una -I opción. windres también buscará en este directorio cuando busque archivos nombrados en el "rc" archivo. Si el argumento pasado a este comando coincide con cualquiera de los formatos soportados (como se describe en la opción -J ), emitirá una advertencia de obsolescencia y se comportará igual que la -J opción. Los programas nuevos no deberían usar este comportamiento. Si un directorio coincide con un formato, simplemente prepóngale ./ para desactivar la compatibilidad hacia atrás.
-D destino
--define sim[=val]
Especifica una -D opción a pasar al preprocesador cuando se lee un "rc" archivo.
-U destino
--undefine sim
Especifica una -U opción a pasar al preprocesador cuando se lee un "rc" archivo.
-r
Ignorado por compatibilidad con rc.
-v
Habilita el modo verboso. Esto le dice cuál es el preprocesador si no especificó uno.
-c val
--codepage val
Especifica la página de código por defecto a usar cuando se lee un "rc" archivo. val debería ser un código de página de código hexadecimal prefijado por 0x o decimal. El rango válido es de cero hasta 0xffff, pero la validez de la página de código depende del host y la configuración.
-l val
--language val
Especifica el idioma por defecto a usar cuando se lee un "rc" archivo. val debería ser un código de idioma hexadecimal. Los ocho bits bajos son el idioma, y los ocho bits altos son el subidioma.
--use-temp-file
Usa un archivo temporal en lugar de usar popen para leer la salida del preprocesador. Use esta opción si la implementación de popen tiene errores en el host (por ejemplo, se sabe que ciertas versiones de Windows 95 y Windows 98 en idiomas no ingleses tienen
