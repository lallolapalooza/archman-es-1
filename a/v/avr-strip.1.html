NOMBRE

strip - descarta símbolos y otros datos de archivos objeto

SINOPSIS

strip [-F bfdname |--target=bfdname]
[-I bfdname |--input-target=bfdname]
[-O bfdname |--output-target=bfdname]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombre-símbolo|--keep-symbol=nombre-símbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombre-símbolo |--strip-symbol=nombre-símbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombre-sección |--remove-section=nombre-sección]
[--keep-section=patrón-sección]
[--remove-relocations=patrón-sección]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivo-objeto...

DESCRIPCIÓN

GNU strip descarta todos los símbolos de los archivos objeto archivo-objeto. La lista de archivos objeto puede incluir archivos complementarios. Debe proporcionarse al menos un archivo objeto.

strip modifica los archivos nombrados en sus argumentos, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F bfdname
--target=bfdname
Trata el archivo-objeto original como un archivo con el formato de código objeto bfdname, y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista con todas las arquitecturas y formatos de objeto disponibles.
-I bfdname
--input-target=bfdname
Trata el archivo-objeto original como un archivo con el formato de código objeto bfdname.
-O bfdname
--output-target=bfdname
Reemplaza archivo-objeto con un archivo en el formato de salida bfdname.
-R nombre-sección
--remove-section=nombre-sección
Elimina cualquier sección llamada nombre-sección del archivo de salida, además de las secciones que de otro modo serían eliminadas. Esta opción se puede dar varias veces. Tenga en cuenta que el uso inadecuado de esta opción puede hacer que el archivo de salida no sea utilizable. El carácter comodín * se puede dar al final de nombre-sección. Si es así, se eliminará cualquier sección que comience con nombre-sección.

Si el primer carácter de patrón-sección es el signo de exclamación (!) entonces las secciones coincidentes no se eliminarán, incluso si un uso anterior de --remove-section en la misma línea de comandos las eliminara de otro modo. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patrón-sección
Al eliminar secciones del archivo de salida, conserva las secciones que coincidan con patrón-sección.
--remove-relocations=patrón-sección
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patrón-sección. Esta opción se puede dar varias veces. Tenga en cuenta que el uso inadecuado de esta opción puede hacer que el archivo de salida no sea utilizable. Se aceptan caracteres comodín en patrón-sección. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patrón-sección es el signo de exclamación (!) entonces a las secciones coincidentes no se les eliminarán sus reubicaciones, incluso si un uso anterior de --remove-relocations en la misma línea de comandos provocara que se eliminaran. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones de secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones de la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica para archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando intactas las secciones de depuración restantes y todos los símbolos. Consulte la descripción de esta opción en la sección objcopy para obtener más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicaciones, además de los símbolos y secciones de depuración que elimina --strip-debug.
-K nombre-símbolo
--keep-symbol=nombre-símbolo
Al eliminar símbolos, conserva el símbolo nombre-símbolo aunque normalmente se eliminaría. Esta opción se puede dar varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intenta (o no intenta) reducir el tamaño de las secciones de tipo SHT_NOTE eliminando notas duplicadas. El valor predeterminado es intentar esta reducción a menos que se esté eliminando información de depuración o DWO.
-N nombre-símbolo
--strip-symbol=nombre-símbolo
Elimina el símbolo nombre-símbolo del archivo fuente. Esta opción se puede dar varias veces y se puede combinar con otras opciones de strip distintas de -K.
-o archivo
Coloca la salida eliminada en archivo, en lugar de reemplazar el archivo existente. Cuando se utiliza este argumento, solo se puede especificar un argumento archivo-objeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice de archivo, utiliza cero para UIDs, GIDs, marcas de tiempo y utiliza modos de archivo consistentes para todos los archivos.

Si binutils se configuró con --enable-deterministic-archives, entonces este modo está activado por defecto. Se puede deshabilitar con la opción -U, a continuación.

Depura un archivo, vaciando el contenido de cualquier sección que no sería depurada por --strip-debug y dejando intactas las secciones de depuración. En los archivos ELF, esto también conserva todas las secciones de nota en la salida.

Nota: los encabezados de las secciones depuradas se conservan, incluyendo sus tamaños, pero el contenido de la sección se descarta. Los encabezados de las secciones se conservan para que otras herramientas puedan hacer coincidir el archivo debuginfo con el ejecutable real, incluso si ese ejecutable se ha reubicado en un espacio de direcciones

diferente.

distribución, y el segundo, un archivo de información de depuración que
solo es necesario si se requieren capacidades de depuración. El procedimiento sugerido para crear estos archivos es el siguiente:
