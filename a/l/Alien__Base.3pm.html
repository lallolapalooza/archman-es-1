DESCRIPCIÓ

N

NOTA: Alien::Base::ModuleBuild ya no se incluye con Alien::Base y se ha separado en una distribución independiente. Alien::Base::ModuleBuild será un prerrequisito para Alien::Base hasta el 1 de octubre de 2017. Si está usando Alien::Base::ModuleBuild, debe asegurarse de que esté declarado como "configure_requires" en su "Build.PL". También podría considerar usar Alien::Base y alienfile como una alternativa más

moderna.

Alien::Base comprende clases base para ayudar en la construcción de módulos "Alien::". Los módulos en el espacio de nombres Alien se utilizan para localizar e instalar (si es necesario) bibliotecas externas necesarias para otros módulos de

Perl.

Esta es la documentación del propio módulo Alien::Base. Si está comenzando, probablemente quiera hacerlo desde uno de estos

documentos:
Alien::Build::Manual::
AlienUser
Para usuarios de un "Alien::libfoo" que está implementado usando Alien::Base. (El desarrollador de "Alien::libfoo" debería proporcionar la documentación necesaria, pero si no lo hace, este es el lugar para comenzar)
.
Alien::Build::Manual::
AlienAuthor
Si está escribiendo su propio Alien basado en Alien::Build y Alien::
Base.
Alien::Build::Manual::
FAQ
Si tiene una pregunta común que ya ha sido respondida, como "¿Cómo uso alienfile con algún sistema de construcción?
".
Alien::Build::Manual::
PluginAuthor
Esto es para las almas valientes que qu
ieren escribir complementos que funciona
rán con Alien::Build + alienfile.

Antes de usar directamente un Alien basado en Alien::Base, considere el siguiente

consejo:

Si desea usar un Alien basado en Alien::Base con un módulo XS usando ExtUtils::MakeMaker o Module::Build, se recomienda encarecidamente que use Alien::Base::Wrapper, en lugar de usar el Alien directamente, porque maneja una serie de problemas difíciles y evita trampas comunes al intentar usar un Alien directamente con ExtUtils::

MakeMaker.

En la misma línea, si desea usar un Alien basado en Alien::Base con un módulo XS usando Dist::Zilla, se recomienda encarecidamente que use Dist::Zilla::Plugin::AlienBase::Wrapper por las mismas

razones.

A partir de la versión 0.28, FFI::CheckLib tiene una buena interfaz para trabajar con Aliens basados en Alien::Base en modo de respaldo, lo cual es

recomendable.

Normalmente solo debería estar usando directamente un Alien basado en Alien::Base si necesita integrarlo con algún otro sistema, o si es un Alien basado en herramientas que no necesita

vincular.

La sinopsis anterior y los documentos manuales enlazad

os lo llevarán por el camino correcto, pero vale la
pena saberlo antes de leer más en este documento.

alien_helpe

r 
my $helpers = Alien::MyLibrary->
alien_helper;

Devuelve una referencia a hash de los ayudantes proporcionados por el módulo Alien. Las claves son nombres de ayudantes y los valores son referencias a código. Las referencias a código se ejecutarán en el momento del comando y el valor de retorno se interpolará en el comando antes de su ejecución. La implementación predeterminada devuelve una referencia a hash vacía, y se espera que anule el método para crear sus propios

ayudantes.

Para su uso con comandos especificados en un alienfile o en su "Build.Pl" cuando se usa con Alien::Base::

ModuleBuild.

Los ayudantes permiten a los usuarios de su módulo Alien usar lógica determinada por la plataforma o el entorno para calcular nombres de comandos o argumentos en su lógica de instalación. Los ayudantes le permiten hacer esto sin convertir su módulo Alien en un requisito cuando no es necesaria una compilación a partir del código

fuente.

Como ejemplo concreto, considere Alien::gmake, que proporciona el ayudante "gmake"

: 
package Alien::gmake;

...

sub alien_helper {
  my($class) = @_;
  return {
    gmake => sub {
      # return the executable name for GNU make,
      # usually either make or gmake depending on
      # the platform and environment
      $class->exe;
    }
  },
}

Ahora considere Alien::nasm. "nasm" requiere GNU Make para compilarse a partir del código fuente, pero si el paquete "nasm" del sistema está instalado, no lo necesitamos. Del alienfile de "Alien::n

asm": 
use alienfile;

plugin 'Probe::CommandLine' => (

  ...

  plugin 'Build::MSYS';

  build [
    'sh configure --prefix=%{alien.install.prefix}',
    '%{gmake}',
    '%{gmake} install',
  ];
};
