NOMBRE

al_draw_filled_polygon_with_holes - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
void al_draw_filled_polygon_with_holes(const float *vertices,
   const int *vertex_counts, ALLEGRO_COLOR color)

DESCRIPCIÓN

Dibuja un polígono simple relleno con cero o más polígonos simples restados de él: los agujeros. Los agujeros no pueden tocar ni intersectar el contorno del polígono relleno.

•
vertices - Matriz intercalada de coordenadas de vértices (x, y) para cada uno de los polígonos, incluidos los agujeros.
•
vertex_counts - Número de vértices para cada polígono. El número de vértices en el polígono relleno se da por vertex_counts[0] y debe ser como mínimo tres. Los elementos subsiguientes indican el número de vértices en cada agujero. La matriz debe terminar con un elemento con valor cero.
•
color - Color del polígono relleno

Cuando el eje y apunta hacia abajo (lo habitual), las coordenadas del polígono relleno deben ordenarse en sentido antihorario. Todos los vértices de los agujeros deben usar el orden opuesto (horario con y hacia abajo). Todos los vértices de los agujeros deben estar dentro del polígono principal y ningún agujero puede solaparse con el polígono principal.

Por ejemplo:

float vertices[] = {
      0,   0, // polígono relleno, esquina superior izquierda
      0, 100, // polígono relleno, esquina inferior izquierda
    100, 100, // polígono relleno, esquina inferior derecha
    100,   0, // polígono relleno, esquina superior derecha
     10,  10, // agujero, superior izquierdo
     90,  10, // agujero, superior derecho
     90,  90  // agujero, inferior derecho
};
int vertex_counts[] = {
   4, // número de vértices para el polígono relleno
   3, // número de vértices para el agujero
   0  // terminador
};

Hay 7 vértices: cuatro para un cuadrado exterior desde (0, 0) hasta (100, 100) en orden antihorario, y tres más para un triángulo interior en orden horario. El polígono principal exterior usa los vértices 0 a 3 (inclusive) y el agujero usa los vértices 4 a 6 (inclusive).
