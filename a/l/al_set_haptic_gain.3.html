NOMBRE

al_set_haptic_gain - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
bool al_set_haptic_gain(ALLEGRO_HAPTIC *hap, double gain)

DESCRIPCIÓN

Establece la ganancia del dispositivo háptico si es compatible. La ganancia es muy similar al volumen del sonido, es como si la intensidad de cada efecto se multiplicara por ella. La ganancia es un valor entre 0.0 y 1.0. Devuelve true si se estableció correctamente, false si no. Solo funciona si al_get_haptic_capabilities(3) devuelve un valor que tiene ALLEGRO_HAPTIC_GAIN(3)ALLEGRO_HAPTIC_CONSTANTS(3) configurado. Si no es así, esta función devuelve false y todos los efectos se reproducirán sin ninguna influencia de ganancia.

DESDE
