ALTER_ROUTINE(7)

Paquete: postgresql

Licencias: PostgreSQL

ALTER ROUTINE(7) Documentación de PostgreSQL 18.1 ALTER ROUTINE(7)

NOMBRE

ALTER_ROUTINE - cambiar la definición de una rutina

SINOPSIS

ALTER ROUTINE nombre [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ]
    acción [ ... ] [ RESTRICT ]
ALTER ROUTINE nombre [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ]
    RENAME TO nuevo_nombre
ALTER ROUTINE nombre [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ]
    OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER ROUTINE nombre [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ]
    SET SCHEMA nuevo_esquema
ALTER ROUTINE nombre [ ( [ [ modo_arg ] [ nombre_arg ] tipo_arg [, ...] ] ) ]
    [ NO ] DEPENDS ON EXTENSION nombre_extension
donde acción es una de las siguientes:
    IMMUTABLE | STABLE | VOLATILE
    [ NOT ] LEAKPROOF
    [ EXTERNAL ] SECURITY INVOKER | [ EXTERNAL ] SECURITY DEFINER
    PARALLEL { UNSAFE | RESTRICTED | SAFE }
    COST costo_ejecucion
    ROWS filas_resultado
    SET parametro_configuracion { TO | = } { valor | DEFAULT }
    SET parametro_configuracion FROM CURRENT
    RESET parametro_configuracion
    RESET ALL

DESCRIPCIÓN

ALTER ROUTINE cambia la definición de una rutina, que puede ser una función agregada, una función normal o un procedimiento. Véase en ALTER AGGREGATE (ALTER_AGGREGATE(7)), ALTER FUNCTION (ALTER_FUNCTION(7)) y ALTER PROCEDURE (ALTER_PROCEDURE(7)) la descripción de los parámetros, más ejemplos y detalles adicionales.

EJEMPLOS

Para renombrar la rutina foo para el tipo integer a foobar:

ALTER ROUTINE foo(integer) RENAME TO foobar;

Este comando funcionará independientemente de si foo es un agregado, una función o un procedimiento.

COMPATIBILIDAD

Esta sentencia es parcialmente compatible con la sentencia ALTER ROUTINE en el estándar SQL. Véase en ALTER FUNCTION (ALTER_FUNCTION(7)) y ALTER PROCEDURE (ALTER_PROCEDURE(7)) para más detalles. Permitir que los nombres de rutina se refieran a funciones agregadas es una extensión de PostgreSQL.

VER TAMBIÉN

ALTER AGGREGATE (ALTER_AGGREGATE(7)), ALTER FUNCTION (ALTER_FUNCTION(7)), ALTER PROCEDURE (ALTER_PROCEDURE(7)), DROP ROUTINE (DROP_ROUTINE(7))

Tenga en cuenta que no existe un comando CREATE ROUTINE.
