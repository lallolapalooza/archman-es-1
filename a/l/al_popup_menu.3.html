al_popup_menu(3) Manual de funciones de biblioteca al_popup_menu(3)

NOMBRE

al_popup_menu - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_native_dialog.h>
bool al_popup_menu(ALLEGRO_MENU *popup, ALLEGRO_DISPLAY *display)

DESCRIPCIÓN

Muestra un menú contextual junto al cursor del ratón. El menú debe haber sido creado con al_create_popup_menu(3). Genera eventos al igual que un menú de pantalla normal. Es posible que el menú se cancele sin que se realice ninguna selección.

El parámetro display indica con qué ventana está asociado el menú (cuando procesas el evento de clic del menú), pero en realidad no afecta la ubicación del menú en la pantalla.

Devuelve true si se mostró el menú contextual.

Nota: En Linux, esta función fallará si alguna de las teclas del ratón está presionada. Es decir, solo funcionará de manera confiable si lo manejas en eventos ALLEGRO_MOUSE_BUTTON_UP y, aun así, solo si ese evento corresponde al último botón del ratón que se presionó.

DESDE

5.1.0

VER TAMBIÉN
