ALTER EVENT TRIGGER(7) Documentación de PostgreSQL 18.1 ALTER EVENT TRIGGER(7)

NOMBRE

ALTER_EVENT_TRIGGER - cambiar la definición de un disparador de eventos

SINOPSIS

ALTER EVENT TRIGGER nombre DISABLE
ALTER EVENT TRIGGER nombre ENABLE [ REPLICA | ALWAYS ]
ALTER EVENT TRIGGER nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER EVENT TRIGGER nombre RENAME TO nuevo_nombre

DESCRIPCIÓN

ALTER EVENT TRIGGER cambia las propiedades de un disparador de eventos existente.

Debes ser superusuario para alterar un disparador de eventos.

PARÁMETROS

nombre

El nombre de un disparador existente para alterar.

nuevo_propietario

El nombre de usuario del nuevo propietario del disparador de eventos.

nuevo_nombre

El nuevo nombre del disparador de eventos.

DISABLE/ENABLE [ REPLICA | ALWAYS ]

Estas formas configuran la activación de los disparadores de eventos. Un disparador deshabilitado todavía es conocido por el sistema, pero no se ejecuta cuando ocurre su evento desencadenante. Ver también session_replication_role.

COMPATIBILIDAD

No existe la sentencia ALTER EVENT TRIGGER en el estándar SQL.

VER TAMBIÉN

CREATE EVENT TRIGGER (CREATE_EVENT_TRIGGER(7)), DROP EVENT TRIGGER (DROP_EVENT_TRIGGER(7))
