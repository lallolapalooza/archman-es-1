Alien::Build::Plugin::Decode(3) Documentación de Perl aportada por el usuario Alien::Build::Plugin::Decode(3)

NOMBRE

Alien::Build::Plugin::Decode - Decodifica plugins de Alien::Build

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Decode::HTML';
plugin 'Decode::DirListing';

DESCRIPCIÓN

Los plugins de Decode decodifican listados de archivos HTML y FTP. Normalmente querrás usar el plugin Alien::Build::Plugin::Download::Negotiate, que cargará automáticamente los plugins de Decode apropiados.

Alien::Build::Plugin::Decode::DirListing
Decodificador predeterminado para listados de archivos FTP, que utiliza el módulo puramente en Perl File::Listing.
Alien::Build::Plugin::Decode::DirListingFtpcopy
Otro decodificador para listados de archivos FTP, que utiliza el módulo XS File::Listing::Ftpcopy.
Alien::Build::Plugin::Decode::HTML
Decodificador más antiguo para listados de archivos HTML, que utiliza el módulo XS HTML::LinkExtor. Este solía ser el decodificador predeterminado hasta la versión 1.75 de Alien::Build. En algunos casos, se usará como decodificador HTML si se configura con Alien::Build antes de la versión 1.75 y se actualiza a una versión más reciente para la etapa de compilación de su Alien.
Alien::Build::Plugin::Decode::Mojo
Decodificador más nuevo para listados de archivos HTML, que utiliza el módulo puramente en Perl Mojo::DOM o Mojo::DOM58. Este se convirtió en el decodificador predeterminado a partir de la versión 1.75 de Alien::Build.
