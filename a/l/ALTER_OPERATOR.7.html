ALTER_OPERATOR(7)

Paquete: postgresql

Licencias: PostgreSQL

ALTER OPERATOR(7) Documentación de PostgreSQL 18.1 ALTER OPERATOR(7)

NOMBRE

ALTER OPERATOR - cambiar la definición de un operador

SINOPSIS

ALTER OPERATOR nombre ( { tipo_izquierdo | NONE } , tipo_derecho )
    OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER OPERATOR nombre ( { tipo_izquierdo | NONE } , tipo_derecho )
    SET SCHEMA nuevo_esquema
ALTER OPERATOR nombre ( { tipo_izquierdo | NONE } , tipo_derecho )
    SET ( {  RESTRICT = { proc_res | NONE }
           | JOIN = { proc_join | NONE }
           | COMMUTATOR = op_com
           | NEGATOR = op_neg
           | HASHES
           | MERGES
          } [, ... ] )

DESCRIPCIÓN

ALTER OPERATOR cambia la definición de un operador.

Debes ser el propietario del operador para usar ALTER OPERATOR. Para cambiar el propietario, debes poder hacer SET ROLE al nuevo rol propietario, y ese rol debe tener el privilegio CREATE en el esquema del operador. (Estas restricciones aseguran que alterar el propietario no hace nada que no pudieras hacer eliminando y recreando el operador. Sin embargo, un superusuario puede alterar la propiedad de cualquier operador de todos modos.)

PARÁMETROS

nombre

El nombre (opcionalmente calificado por esquema) de un operador existente.

tipo_izquierdo

El tipo de dato del operando izquierdo del operador; escribe NONE si el operador no tiene operando izquierdo.

tipo_derecho

El tipo de dato del operando derecho del operador.

nuevo_propietario

El nuevo propietario del operador.

nuevo_esquema

El nuevo esquema para el operador.

proc_res

La función de estimación de selectividad de restricción para este operador; escribe NONE para eliminar el estimador de selectividad existente.

proc_join

La función de estimación de selectividad de unión para este operador; escribe NONE para eliminar el estimador de selectividad existente.

op_com

El conmutador de este operador. Solo se puede cambiar si el operador no tiene un conmutador existente.

op_neg

El negador de este operador. Solo se puede cambiar si el operador no tiene un negador existente.

HASHES

Indica que este operador puede soportar una unión hash. Solo se puede habilitar y no deshabilitar.

MERGES

Indica que este operador puede soportar una unión merge. Solo se puede habilitar y no deshabilitar.

NOTAS

Consulte la Sección 36.14 y la Sección 36.15 para obtener más información.

Dado que los conmutadores vienen en pares que son conmutadores entre sí, ALTER OPERATOR SET COMMUTATOR también establecerá el conmutador de op_com para que sea el operador de destino. De manera similar, ALTER OPERATOR SET NEGATOR también establecerá el negador de op_neg para que sea el operador de destino. Por lo tanto, debes ser propietario del operador conmutador o negador, así como del operador de destino.

EJEMPLOS

Cambiar el propietario de un operador personalizado a @@ b para el tipo text:

ALTER OPERATOR @@ (text, text) OWNER TO joe;

Cambiar las funciones de estimación de selectividad de restricción y unión de un operador personalizado a && b para el tipo int[]:

ALTER OPERATOR && (int[], int[]) SET (RESTRICT = _int_contsel, JOIN = _int_contjoinsel);

Marcar el operador && como su propio conmutador:

ALTER OPERATOR && (int[], int[]) SET (COMMUTATOR = &&);

COMPATIBILIDAD

No existe una instrucción ALTER OPERATOR en el estándar SQL.

VER TAMBIÉN

CREATE OPERATOR (CREATE_OPERATOR(7)), DROP OPERATOR (DROP_OPERATOR(7))
