NOMBRE

al_remove_menu_item - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_native_dialog.h>
bool al_remove_menu_item(ALLEGRO_MENU *menu, int pos)

DESCRIPCIÓN

Elimina el elemento especificado del menú y lo destruye. Si el elemento contiene un submenú, también se destruye. Cualquier referencia a él se invalida. Si desea conservar ese submenú, primero debe hacer una copia con al_clone_menu(3).

Es seguro llamar a esto en un menú que se está mostrando actualmente.

Devuelve true si se eliminó un elemento.

DESDE

5.1.0

VER TAMBIÉN

al_append_menu_item(3), al_insert_menu_item(3), al_destroy_menu(3)
