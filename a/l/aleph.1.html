DESCRIPCIÓ

N

Ejecuta el compositor Aleph sobre archivo, generalmente creando archivo.dvi. Si el argumento de archivo no tiene extensión, se le añadirá ".tex". En lugar de un nombre de archivo, se puede dar un conjunto de comandos de Aleph, el primero de los cuales debe empezar con una barra invertida. Con un &argumento de formato, Aleph usa un conjunto diferente de comandos precompilados, contenidos en formato.fmt; generalmente es mejor usar la -fmt opción de formato en su

lugar.

Aleph es una versión del programa TeX modificada para la composición multilingüe. Usa Unicode y tiene primitivas adicionales para (entre otras cosas) la composición

bidireccional.

Las opciones de línea de comandos de Aleph son similares a las de

TeX.

do activamente; consulte LuaTe

ENTORN

O

Consulte la documentación de la biblioteca Kpathsearch (el nodo `Especificaciones de ruta') para detalles precisos de cómo se usan las variables de entorno. La utilidad kpsewhich se puede usar para consultar los valores de las

variables.

Una advertencia: En la mayoría de los formatos de Aleph, no puede usar ~ en un nombre de archivo que dé directamente a Aleph, porque ~ es un carácter activo y por lo tanto se expande, no se toma como parte del nombre de archivo. Otros programas, como Metafont, no tienen este

problema.
TEXMFOUTP
UT
Normalmente, Aleph pone sus archivos de salida en el directorio actual. Si algún archivo de salida no se puede abrir ahí, intenta abrirlo en el directorio especificado en la variable de entorno TEXMFOUTPUT. No hay un valor por defecto para esa variable. Por ejemplo, si usted dice tex paper y el directorio actual no es escribible, si TEXMFOUTPUT tiene el valor /tmp, Aleph intenta crear /tmp/paper.log (y /tmp/paper.dvi, si se produce alguna salida.) TEXMFOUTPUT también se comprueba para los archivos de entrada, ya que TeX a menudo genera archivos que necesitan ser leídos posteriormente; para la entrada, no se añaden sufijos (como ``.tex'') por defecto, el nombre de entrada se comprueba tal como se
da.
TEXINPU
TS
Ruta de búsqueda para archivos \input y \openin. Esta debería empezar con ``.'', para que los archivos de usuario se encuentren antes que los del sistema. Un componente de ruta vacío será reemplazado con las rutas definidas en el archivo texmf.cnf. Por ejemplo, establezca TEXINPUTS a ".:/home/user/tex:" para anteponer el directorio actual y ``/home/user/tex'' a la ruta de búsqueda
estándar.
TEXED
IT
Plantilla de comando para cambiar al editor. El valor por defecto, generalmente vi, se establ
ece cuand
o se compi
la Aleph.

ERRORE

S

Esta versión de Aleph implementa una serie de extensiones opcionales. De hecho, muchas de estas extensiones entran en conflicto en mayor o menor medida con la definición de Aleph. Cuando estas extensiones están habilitadas, el banner que se imprime al iniciar Aleph cambia para imprimir Alephk en lugar de Aleph

.

Esta versión de Aleph no atrapa el desbordamiento aritmético cuando se suman o restan dimensiones. Los casos en los que esto ocurre son raros, pero cuando ocurre, el archivo DVI genera

do será
inválido.
