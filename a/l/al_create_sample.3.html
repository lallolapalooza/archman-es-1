al_create_sample(3) Manual de funciones de biblioteca al_create_sample(3)

NOMBRE

al_create_sample - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_SAMPLE *al_create_sample(void *buf, unsigned int samples,
   unsigned int freq, ALLEGRO_AUDIO_DEPTH depth,
   ALLEGRO_CHANNEL_CONF chan_conf, bool free_buf)

DESCRIPCIÓN

Crea una estructura de datos de muestra a partir del búfer suministrado. Si free_buf es verdadero, el búfer se liberará con al_free(3) cuando se destruya la estructura de datos de muestra. Para mayor portabilidad (especialmente en Windows), el búfer debería haberse asignado con al_malloc(3). De lo contrario, debes liberar tú mismo los datos de la muestra.

Una muestra a la que se hace referencia en el parámetro samples se refiere a una secuencia de intensidades de canal. Por ejemplo, si estás creando una muestra estéreo con samples establecido en 4, la disposición de los datos en buf será:

LRLRLRLR

Donde L y R son las intensidades de los canales izquierdo y derecho respectivamente. Una sola muestra, entonces, se refiere al par LR en este ejemplo.

Para asignar un búfer del tamaño correcto, puedes usar algo como esto:

int sample_size = al_get_channel_count(chan_conf)
                  * al_get_audio_depth_size(depth);
int bytes = samples * sample_size;
void *buffer = al_malloc(bytes);

VER TAMBIÉN
