import = ["<string>",

]
Importa archivos de configuración adicionales.

Las importaciones se cargan en orden, omitiendo todos los archivos que falten, siendo el archivo que importa cargado en último lugar. Si un campo ya está presente en una importación anterior, será

reemplazado.

Todas las importaciones deben ser rutas absolutas que comiencen con /, rutas relativas al directorio de inicio del usuario que comiencen con ~/, o rutas relativas desde el archivo de configuración

actual.

Ejemplo

:
import = [
"~/.config/alacritty/base16-dark.toml",
"~/.config/alacritty/keybindings.toml",
"alacritty-theme/themes/gruvbox_dark.toml",
]
