Algorithm::DiffOld(3) Documentación de Perl aportada por el usuario Algorithm::DiffOld(3)

NOMBRE

Algorithm::DiffOld - Calcula diferencias 'inteligentes' entre dos archivos/listas pero usa la interfaz antigua (<=0.59).

NOTA

Esto ha sido proporcionado como parte del paquete Algorithm::Diff por Ned Konz. Este módulo en particular es **SOLO** para personas que **DEBEN** tener la interfaz antigua, que utiliza una función de comparación en lugar de una función generadora de claves.

Debido a que cada una de las líneas en un array tiene que compararse con cada una de las líneas en el otro array, esto realiza M*N comparaciones. Esto puede ser muy lento. Lo cronometré en 18 veces más tiempo que la versión estándar de Algorithm::Diff para un archivo de 4000 líneas. Empeorará cuadráticamente a medida que aumente el tamaño de los arrays.

SINOPSIS

use Algorithm::DiffOld qw(diff LCS traverse_sequences);
@lcs    = LCS( \@seq1, \@seq2, $funcion_comparacion );
$lcsref = LCS( \@seq1, \@seq2, $funcion_comparacion );
@diffs = diff( \@seq1, \@seq2, $funcion_comparacion );

traverse_sequences( \@seq1, \@seq2,
                   { MATCH => $callback,
                     DISCARD_A => $callback,
                     DISCARD_B => $callback,
                   },
                   $funcion_comparacion );

FUNCIONES DE COMPARACIÓN

Cada una de las rutinas principales debe recibir una función de comparación. Si no estás pasando una, **usa Algorithm::Diff en su lugar**.

Estas funciones deben devolver un valor verdadero cuando dos elementos deban compararse como iguales.

Por ejemplo,

@lcs    = LCS( \@seq1, \@seq2, sub { my ($a, $b) = @_; $a eq $b } );

pero si eso es todo lo que estás haciendo con tu función de comparación, simplemente usa Algorithm::Diff y deja que haga esto (este es su comportamiento predeterminado).

O:

sub algunaFuncionDeComparacionRara
{
      my ($a, $b) = @_;
      $a =~ m{$b};
}
@diffs = diff( \@lineas, \@patrones, \&algunaFuncionDeComparacionRara );

lo que te permitiría calcular las diferencias entre un array @lineas que consiste en líneas de texto con un array @patrones que consiste en expresiones regulares.

Esta es en realidad la razón por la que escribí esta versión: no hay forma de hacer esto con una función generadora de claves como en el Algorithm::Diff estándar.
