NOMBRE

al_ustr_set_chr - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
size_t al_ustr_set_chr(ALLEGRO_USTR *us, int start_pos, int32_t c)

DESCRIPCIÓN

Reemplaza el punto de código que comienza en el desplazamiento de byte start_pos con c. start_pos no puede ser menor que 0. Si start_pos está más allá del final de us, el espacio entre el final de la cadena y start_pos se rellenará con bytes NUL ('\0'). Si start_pos no es el inicio de un punto de código válido, es un error y la cadena permanecerá sin modificar.

En caso de éxito, devuelve el número de bytes escritos, es decir, el desplazamiento al siguiente punto de código. En caso de error, devuelve 0.
