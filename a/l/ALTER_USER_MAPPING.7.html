ALTER_USER_MAPPING(7)

Paquete: postgresql

Licencias: PostgreSQL

ALTER USER MAPPING(7) Documentación de PostgreSQL 18.1 ALTER USER MAPPING(7)

NOMBRE

ALTER_USER_MAPPING - cambiar la definición de un mapeo de usuario

SINOPSIS

ALTER USER MAPPING FOR { nombre_usuario | USER | CURRENT_ROLE | CURRENT_USER | SESSION_USER | PUBLIC }
    SERVER nombre_servidor
    OPTIONS ( [ ADD | SET | DROP ] opción ['valor'] [, ... ] )

DESCRIPCIÓN

ALTER USER MAPPING cambia la definición de un mapeo de usuario.

El propietario de un servidor externo puede alterar mapeos de usuario para ese servidor para cualquier usuario. Además, un usuario puede alterar un mapeo de usuario para su propio nombre de usuario si se ha concedido el privilegio USAGE en el servidor al usuario.

PARÁMETROS

nombre_usuario

Nombre de usuario del mapeo. CURRENT_ROLE, CURRENT_USER y USER coinciden con el nombre del usuario actual. PUBLIC se utiliza para coincidir con todos los nombres de usuario presentes y futuros en el sistema.

nombre_servidor

Nombre del servidor del mapeo de usuario.

OPTIONS ( [ ADD | SET | DROP ] opción ['valor'] [, ... ] )

Cambia las opciones para el mapeo de usuario. Las nuevas opciones anulan cualquier opción especificada previamente. ADD, SET y DROP especifican la acción que se realizará. Se asume ADD si no se especifica explícitamente ninguna operación. Los nombres de las opciones deben ser únicos; las opciones también son validadas por el foreign-data wrapper del servidor.

EJEMPLOS

Cambiar la contraseña para el mapeo de usuario bob, servidor foo:

ALTER USER MAPPING FOR bob SERVER foo OPTIONS (SET password 'public');

COMPATIBILIDAD

ALTER USER MAPPING cumple con ISO/IEC 9075-9 (SQL/MED). Hay un problema de sintaxis sutil: el estándar omite la palabra clave FOR. Dado que CREATE USER MAPPING y DROP USER MAPPING usan FOR en posiciones análogas, y IBM DB2 (siendo la otra implementación principal de SQL/MED) también lo requiere para ALTER USER MAPPING, PostgreSQL se desvía del estándar aquí en aras de la coherencia e interoperabilidad.

VER TAMBIÉN

CREATE USER MAPPING (CREATE_USER_MAPPING(7)), DROP USER MAPPING (DROP_USER_MAPPING(7))
