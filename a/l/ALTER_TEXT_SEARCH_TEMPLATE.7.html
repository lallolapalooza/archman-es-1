NOMBRE

ALTER_TEXT_SEARCH_TEMPLATE - cambiar la definición de una plantilla de búsqueda de texto

SINOPSIS

ALTER TEXT SEARCH TEMPLATE nombre RENAME TO nuevo_nombre
ALTER TEXT SEARCH TEMPLATE nombre SET SCHEMA nuevo_esquema

DESCRIPCIÓN

ALTER TEXT SEARCH TEMPLATE cambia la definición de una plantilla de búsqueda de texto. Actualmente, la única funcionalidad admitida es cambiar el nombre de la plantilla.

Debes ser superusuario para usar ALTER TEXT SEARCH TEMPLATE.

PARÁMETROS

nombre

El nombre (opcionalmente cualificado por esquema) de una plantilla de búsqueda de texto existente.

nuevo_nombre

El nuevo nombre de la plantilla de búsqueda de texto.

nuevo_esquema

El nuevo esquema para la plantilla de búsqueda de texto.

COMPATIBILIDAD

No existe una sentencia ALTER TEXT SEARCH TEMPLATE en el estándar SQL.

VER TAMBIÉN

CREATE TEXT SEARCH TEMPLATE (CREATE_TEXT_SEARCH_TEMPLATE(7)), DROP TEXT SEARCH TEMPLATE (DROP_TEXT_SEARCH_TEMPLATE(7))
