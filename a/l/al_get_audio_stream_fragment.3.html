al_get_audio_stream_fragment(3) Manual de funciones de biblioteca al_get_audio_stream_fragment(3)

NOMBRE

al_get_audio_stream_fragment - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
void *al_get_audio_stream_fragment(const ALLEGRO_AUDIO_STREAM *stream)

DESCRIPCIÓN

Al usar la transmisión de audio de Allegro, usarás esta función para proporcionar continuamente nuevos datos de muestra a una transmisión.

Si la transmisión está lista para nuevos datos, la función devolverá la dirección de un búfer interno para llenarlo con datos de audio. La longitud y el formato del búfer se especifican con al_create_audio_stream(3) o se pueden consultar con las diversas funciones descritas aquí. Una vez que el búfer esté lleno, debes señalárselo a Allegro pasando el búfer a al_set_audio_stream_fragment(3).

Si la transmisión no está lista para nuevos datos, la función devolverá NULL.

Nota: Si escuchas eventos de la transmisión, se generará un evento ALLEGRO_EVENT_AUDIO_STREAM_FRAGMENT(3) cada vez que un nuevo fragmento esté listo. Sin embargo, recibir un evento *no* es una garantía de que al_get_audio_stream_fragment(3) no devolverá NULL, por lo que aún debes verificarlo.
