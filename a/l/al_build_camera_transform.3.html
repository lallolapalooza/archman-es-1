al_build_camera_transform(3) Manual de funciones de biblioteca al_build_camera_transform(3)

NOMBRE

al_build_camera_transform - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_build_camera_transform(ALLEGRO_TRANSFORM *trans,
   float position_x, float position_y, float position_z,
   float look_x, float look_y, float look_z,
   float up_x, float up_y, float up_z)

DESCRIPCIÓN

Construye una transformación que puede ser utilizada para transformar coordenadas 3D en el espacio del mundo al espacio de la cámara. Esto implica una traslación y una rotación. La función espera tres tripletas de coordenadas: la posición de la cámara, la posición a la que mira la cámara y un vector hacia arriba. El vector hacia arriba no necesita ser de longitud unitaria y tampoco necesita ser perpendicular a la dirección de la vista; comúnmente puede ser simplemente la dirección hacia arriba del mundo (más comúnmente 0/1/0).

Por ejemplo:

al_build_camera_transform(&t,
    1, 1, 1,
    5, 5, 5,
    0, 1, 0);

Esto crea una transformación para una cámara situada en 1/1/1 y mirando hacia 5/5/5.

Nota: Si los parámetros *position* y *look* son idénticos, o si la dirección *up* es paralela a la dirección de la vista, se crea una matriz de identidad.

Otro ejemplo que simplemente recreará la matriz de identidad:

al_build_camera_transform(&t,
    0, 0, 0,
    0, 0, -1,
    0, 1, 0);

Un ejemplo donde el vector hacia arriba hará que la cámara se incline (ruede) 45 grados:

al_build_camera_transform(&t,
    1, 1, 1,
    5, 5, 5,
    1, 1, 0);

Desde 5.1.9
