al_fixatan2(3) Manual de funciones de biblioteca al_fixatan2(3)

NOMBRE

al_fixatan2 - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
al_fixed al_fixatan2(al_fixed y, al_fixed x)

DESCRIPCIÓN

Esta es una versión de punto fijo de la rutina atan2() de libc. Calcula el arco tangente de y / x, pero los signos de ambos argumentos se utilizan para determinar el cuadrante del resultado, y se permite que x sea cero. Esta función es útil para convertir coordenadas cartesianas a polares.

Ejemplo:

al_fixed resultado;
/* Establece `resultado' a ángulo binario 64. */
resultado = al_fixatan2(al_itofix(1), 0);
/* Establece `resultado' a ángulo binario -109. */
resultado = al_fixatan2(al_itofix(-1), al_itofix(-2));
/* Falla la aserción. */
resultado = al_fixatan2(0, 0);
assert(!al_get_errno());

VALOR DE RETORNO

Devuelve el arco tangente de y / x en formato de ángulo binario de punto fijo, de -128 a 128. Si tanto x como y son cero, devuelve cero y establece errno de Allegro a EDOM.
