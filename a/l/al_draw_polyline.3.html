al_draw_polyline(3) Manual de funciones de la biblioteca al_draw_polyline(3)

NOMBRE

al_draw_polyline - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
void al_draw_polyline(const float* vertices, int vertex_stride,
   int vertex_count, int join_style, int cap_style,
   ALLEGRO_COLOR color, float thickness, float miter_limit)

DESCRIPCIÓN

Dibuja una serie de segmentos de línea.

•
vertices - Array intercalado de coordenadas de vértices (x, y)
•
vertex_stride - el número de bytes entre pares de vértices (el stride)
•
vertex_count - Número de vértices en el array
•
join_style - Miembro de ALLEGRO_LINE_JOIN(3) que especifica cómo renderizar las uniones entre segmentos de línea
•
cap_style - Miembro de ALLEGRO_LINE_CAP(3) que especifica cómo renderizar los extremos
•
color - Color de la línea
•
thickness - Grosor de la línea, pasar <= 0 para dibujar líneas de cabello
•
miter_limit - Parámetro para el estilo de unión miter

El stride es normalmente 2 * sizeof(float) pero puede ser mayor si las coordenadas de los vértices están en un array de algún tipo de estructura, por ejemplo:

struct VertexInfo {
   float x;
   float y;
   int id;
};
void my_draw(struct VertexInfo verts[], int vertex_count, ALLEGRO_COLOR c)
{
   al_draw_polyline((float *)verts, sizeof(VertexInfo), vertex_count,
      ALLEGRO_LINE_JOIN_NONE, ALLEGRO_LINE_CAP_NONE, c, 1.0, 1.0);
}

El stride también puede ser negativo si los vértices se almacenan en orden inverso.
