NOMBRE

al_install_haptic - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
bool al_install_haptic(void)

DESCRIPCIÓN

Instala el subsistema del dispositivo háptico (retroalimentación de fuerza). Esto debe llamarse antes de usar cualquier otra función relacionada con hápticas. Devuelve verdadero si el subsistema háptico pudo inicializarse correctamente, falso en caso de error.

Para portabilidad, primero debes abrir una pantalla antes de llamar a al_install_haptic(3). En algunas plataformas, como DirectInput en Windows, al_install_haptic(3) solo funcionará si hay al menos una pantalla activa disponible. Esta pantalla debe permanecer disponible hasta que se llame a al_uninstall_haptic(3).

Si necesitas cerrar y reabrir tu pantalla activa, por ejemplo, entonces deberías llamar a al_uninstall_haptic(3) antes de cerrar la pantalla, y a al_install_haptic(3) después de volver a abrirla.

DESDE
