ALBATROSS(1) Manual de comandos generales ALBATROSS(1)

NOMBRE

albatross - una herramienta para encontrar fuentes que contengan un glifo (Unicode) dado.

SINOPSIS

albatross [opciones] glifos...

DESCRIPCIÓN

albatross es una herramienta de línea de comandos para encontrar fuentes que contengan un glifo (Unicode) dado. Se basa en Fontconfig, una biblioteca para configurar y personalizar el acceso a fuentes.

Albatross toma una lista de glifos como entrada. Se admiten tres formatos:

#1
El glifo en sí, por ejemplo, ß (Eszett). Internamente, la herramienta lo convierte al punto de código Unicode correspondiente.
#2
El glifo como un punto de código Unicode en notación hexadecimal, por ejemplo, 0xDF. El prefijo 0x es obligatorio. Tenga en cuenta que la herramienta no distingue entre mayúsculas y minúsculas, por ejemplo, 0xDF es igual a 0xdf (o cualquier combinación de mayúsculas y minúsculas).
#3
El glifo como un punto de código Unicode utilizando la notación de unión de multiconjuntos, por ejemplo, U+DF. El prefijo U+ es obligatorio. Tenga en cuenta que esta notación espera una U en mayúscula.

OPCIONES

--show-styles
Mostrar estilos de fuente disponibles
--detailed
Mostrar una lista detallada de fuentes
--ansi-level [n|a16|a256|tc]
Establecer el nivel ANSI predeterminado
--border-style [0|1|2|3|4|5|6]
Establecer el estilo del borde
--or
Buscar cada glifo por separado
--version
Mostrar la versión y salir
--help
Mostrar un mensaje de ayuda y salir
