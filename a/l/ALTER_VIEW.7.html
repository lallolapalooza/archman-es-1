NOMBRE

ALTER_VIEW - cambia la definición de una vista

SINOPSIS

ALTER VIEW [ IF EXISTS ] nombre ALTER [ COLUMN ] nombre_columna SET DEFAULT expresión
ALTER VIEW [ IF EXISTS ] nombre ALTER [ COLUMN ] nombre_columna DROP DEFAULT
ALTER VIEW [ IF EXISTS ] nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER VIEW [ IF EXISTS ] nombre RENAME [ COLUMN ] nombre_columna TO nuevo_nombre_columna
ALTER VIEW [ IF EXISTS ] nombre RENAME TO nuevo_nombre
ALTER VIEW [ IF EXISTS ] nombre SET SCHEMA nuevo_esquema
ALTER VIEW [ IF EXISTS ] nombre SET ( nombre_opción_vista [= valor_opción_vista] [, ... ] )
ALTER VIEW [ IF EXISTS ] nombre RESET ( nombre_opción_vista [, ... ] )

DESCRIPCIÓN

ALTER VIEW cambia varias propiedades auxiliares de una vista. (Si desea modificar la consulta que define la vista, utilice CREATE OR REPLACE VIEW.)

Debe ser propietario de la vista para utilizar ALTER VIEW. Para cambiar el esquema de una vista, también debe tener el privilegio CREATE en el nuevo esquema. Para cambiar el propietario, debe poder utilizar SET ROLE al nuevo rol propietario, y ese rol debe tener el privilegio CREATE en el esquema de la vista. (Estas restricciones garantizan que cambiar el propietario no hace nada que no pudiera hacer eliminando y recreando la vista. Sin embargo, un superusuario puede cambiar la propiedad de cualquier vista de todos modos.)

PARÁMETROS

nombre

El nombre (opcionalmente calificado por el esquema) de una vista existente.

nombre_columna

Nombre de una columna existente.

nuevo_nombre_columna

Nuevo nombre para una columna existente.

IF EXISTS

No lance un error si la vista no existe. Se emitirá una notificación en este caso.

SET/DROP DEFAULT

Estas formas establecen o eliminan el valor predeterminado de una columna. El valor predeterminado de una columna de vista se sustituye en cualquier comando INSERT o UPDATE cuyo objetivo sea la vista, antes de aplicar cualquier regla o disparador para la vista. El valor predeterminado de la vista, por lo tanto, tendrá precedencia sobre cualquier valor predeterminado de las relaciones subyacentes.

nuevo_propietario

El nombre de usuario del nuevo propietario de la vista.

nuevo_nombre

El nuevo nombre para la vista.

nuevo_esquema

El nuevo esquema para la vista.

SET ( nombre_opción_vista [= valor_opción_vista] [, ... ] )
RESET ( nombre_opción_vista [, ... ] )

Establece o restablece una opción de vista. Las opciones actualmente admitidas son:

check_option (enum)

Cambia la opción de verificación de la vista. El valor debe ser local o en cascada.

security_barrier (boolean)

Cambia la propiedad security-barrier de la vista. El valor debe ser un valor booleano, como true o false.

security_invoker (boolean)

Cambia la propiedad security-invoker de la vista. El valor debe ser un valor booleano, como true o false.

NOTAS

Por razones históricas, ALTER TABLE también se puede utilizar con vistas; pero las únicas variantes de ALTER TABLE que se permiten con vistas son equivalentes a las que se muestran arriba.

EJEMPLOS

Para renombrar la vista foo a bar:

ALTER VIEW foo RENAME TO bar;

Para adjuntar un valor de columna predeterminado a una vista actualizable:

CREATE TABLE base_table (id int, ts timestamptz);
CREATE VIEW a_view AS SELECT * FROM base_table;
ALTER VIEW a_view ALTER COLUMN ts SET DEFAULT now();
INSERT INTO base_table(id) VALUES(1);  -- ts recibirá un NULL
INSERT INTO a_view(id) VALUES(2);  -- ts recibirá la hora actual

COMPATIBILIDAD

ALTER VIEW es una extensión de PostgreSQL del estándar SQL.

VER TAMBIÉN

CREATE VIEW (CREATE_VIEW(7)), DROP VIEW (DROP_VIEW(7))
