NOMBRE

al_color_rgb_to_html - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_color.h>
void al_color_rgb_to_html(float red, float green, float blue,
    char *string)

DESCRIPCIÓN

Crea una representación de cadena de texto estilo HTML de un ALLEGRO_COLOR(3), por ejemplo #00faff.

Parámetros:

•
red, green, blue - Los componentes del color en el rango 0..1.
•
string - Un puntero a un búfer de al menos 8 bytes, en el cual se escribirá el resultado (incluyendo el terminador NUL).

Ejemplo:

char html[8];
al_color_rgb_to_html(1, 0, 0, html);

Ahora html contendrá “#ff0000”.
