NOMBRE

al_create_vertex_buffer - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
ALLEGRO_VERTEX_BUFFER* al_create_vertex_buffer(ALLEGRO_VERTEX_DECL* decl,
   const void* initial_data, int num_vertices, int flags)

DESCRIPCIÓN

Crea un búfer de vértices. Puede devolver NULL si el búfer no pudo ser creado (p.ej., el sistema solo soporta búferes de solo escritura).

Nota:

Esta es una característica avanzada, a menudo no soportada en tarjetas gráficas de gama baja. Ten especial cuidado con el fallo de esta función y haz arreglos para funcionalidad de dibujo de respaldo o un mensaje de error agradable para usuarios con tales tarjetas de gama baja.

Parámetros:

•
decl - Tipo de vértice que contendrá este búfer. NULL implica que este búfer contendrá vértices de tipo ALLEGRO_VERTEX(3)
•
initial_data - Búfer de memoria para copiar para inicializar el búfer de vértices. Puede ser NULL, en cuyo caso el búfer no está inicializado.
•
num_vertices - Número de vértices que contendrá el búfer
•
flags - Una combinación de las banderas ALLEGRO_PRIM_BUFFER_FLAGS(3) que especifican cómo se creará este búfer. Pasar 0 es lo mismo que pasar ALLEGRO_PRIM_BUFFER_STATIC.
