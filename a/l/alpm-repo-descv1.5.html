%PACKAGER

El ID de usuario de la entidad que creó el paquete. El valor está destinado a ser utilizado para búsquedas de identidad y representa un ID de usuario OpenPGP[7]. Como tal, el valor es una cadena codificada en UTF-8, que convencionalmente se compone de un nombre y una dirección de correo electrónico, lo que se alinea con el formato descrito en RFC 28228.

%REPLACES%

Otro componente virtual o paquete que el paquete reemplaza al instalarse. Puede haber uno o más valores. Si el paquete no reemplaza nada, la sección se omite. El valor es una relación de paquete alpm de tipo reemplazo (por ejemplo, example o example=1.0.0).

%CONFLICTS%

Otro componente virtual o paquete con el que el paquete entra en conflicto. Puede haber uno o más valores. Si el paquete no entra en conflicto con nada, la sección se omite. El valor es una relación de paquete alpm de tipo conflicto (por ejemplo, example o example=1.0.0).

%PROVIDES%

Otro componente virtual o paquete que el paquete proporciona. Puede haber uno o más valores. Si el paquete no proporciona nada, la sección se omite. El valor es una relación de paquete alpm de tipo provisión (por ejemplo, example o example=1.0.0).

%DEPENDS%

Una dependencia en tiempo de ejecución del paquete (componente virtual o paquete). Puede haber uno o más valores. Si el paquete no tiene dependencias en tiempo de ejecución, la sección se omite. El valor es una relación de paquete alpm de tipo dependencia en tiempo de ejecución (por ejemplo, example o example=1.0.0).

%OPTDEPENDS%

Una dependencia opcional del paquete (componente virtual o paquete). Puede haber uno o más valores. Si el paquete no tiene dependencias opcionales, la sección se omite. El valor es una relación de paquete alpm de tipo dependencia opcional (por ejemplo, example o example: esta es una descripción).

%MAKEDEPENDS%

Una dependencia para construir el software upstream del paquete. Puede haber uno o más valores. Si el paquete no tiene dependencias de compilación, la sección se omite. El valor es una relación de paquete alpm de tipo dependencia de compilación (por ejemplo, example o example=1.0.0).

%CHECKDEPENDS%

Una dependencia para ejecutar pruebas del proyecto upstream del paquete. Puede haber uno o más valores. Si el paquete no tiene dependencias de prueba, la sección se omite. El valor es una relación de paquete alpm de tipo dependencia de prueba (por ejemplo, example o example=1.0.0).
