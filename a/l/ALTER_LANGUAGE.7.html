NOMBRE

ALTER_LANGUAGE - cambiar la definición de un lenguaje procedural

SINOPSIS

ALTER [ PROCEDURAL ] LANGUAGE nombre RENAME TO nuevo_nombre
ALTER [ PROCEDURAL ] LANGUAGE nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPCIÓN

ALTER LANGUAGE cambia la definición de un lenguaje procedural. La única funcionalidad es renombrar el lenguaje o asignarle un nuevo propietario. Debe ser superusuario o propietario del lenguaje para usar ALTER LANGUAGE.

PARÁMETROS

nombre

Nombre de un lenguaje

nuevo_nombre

El nuevo nombre del lenguaje

nuevo_propietario

El nuevo propietario del lenguaje

COMPATIBILIDAD

No existe una sentencia ALTER LANGUAGE en el estándar SQL.

VER TAMBIÉN

CREATE LANGUAGE (CREATE_LANGUAGE(7)), DROP LANGUAGE (DROP_LANGUAGE(7))
