alpm-package-version(7)

Paquete: alpm-docs

Licencias: CC-BY-SA-4.0

(7) Manual de Información Miscelánea (7)

NOMBRE

package version - versiones de paquetes para paquetes basados en ALPM.

DESCRIPCIÓN

El formato de versión de paquete representa información de versión para paquetes basados en ALPM. Este formato se utiliza en scripts de compilación o en formatos de archivo para metadatos de paquetes (por ejemplo, en PKGBUILD, PKGINFO, SRCINFO, alpm-repo-desc, o alpm-lib-desc) para describir las versiones de los paquetes, o las versiones de los componentes como parte de una relación de paquete.

El valor se representa mediante una cadena de versión compuesta, que puede constar de varios componentes (alpm-epoch, alpm-pkgver, alpm-pkgrel). Existen varias formas de cadenas de versión compuestas, pero solo se utilizan en contextos específicos.

Completa

El valor para esta forma consta de un alpm-pkgver, seguido directamente por un signo ‘-’, seguido directamente por un alpm-pkgrel (por ejemplo, 1.0.0-1). Esta forma de versión de paquete alpm se utiliza en varios escenarios, tales como:

  • nombres de archivo de paquetes
  • expresiones de relación de paquete
•
replaces, conflict, provides, depend, makedepend y checkdepend en archivos PKGINFO
  • pkgver en archivos BUILDINFO
  • pkgver en archivos PKGINFO
  • como parte de buildtoolver en archivos BUILDINFOv2
  • como parte de installed en archivos BUILDINFO

Completa con epoch

El valor para esta forma consta de un alpm-epoch, seguido directamente por un signo ‘:’, seguido directamente por un alpm-pkgver, seguido directamente por un signo ‘-’, seguido directamente por un alpm-pkgrel (por ejemplo, 1:1.0.0-1). Esta forma de versión de paquete alpm se utiliza en varios escenarios, tales como:

  • nombres de archivo de paquetes
  • expresiones de relación de paquete
•
replaces, conflict, provides, depend, makedepend y checkdepend en archivos PKGINFO
  • pkgver en archivos BUILDINFO
  • pkgver en archivos PKGINFO
  • como parte de buildtoolver en archivos BUILDINFOv2
  • como parte de installed en archivos BUILDINFO
  • como parte del contenido de alpm-state-repo

Mínima

El valor para esta forma consta de un alpm-pkgver (por ejemplo, 1.0.0). Esta forma de versión de paquete alpm se utiliza en varios escenarios, tales como:

•
expresiones de relación de paquete
  • replaces, conflicts, provides, depends, makedepends y checkdepends en archivos PKGBUILD
  • replaces, conflict, provides, depend, makedepend y checkdepend en archivos PKGINFO
  • pkgver en archivos PKGBUILD
  • pkgver en archivos SRCINFO
  • como parte de buildtoolver en archivos BUILDINFOv2

Mínima con epoch

El valor para esta forma consta de un alpm-epoch, seguido directamente por un signo ‘:’, seguido directamente por un alpm-pkgver (por ejemplo, 1:1.0.0). Esta forma de versión de paquete alpm se utiliza en varios escenarios, tales como:

•
como parte de expresiones de relación de paquete
  • replaces, conflicts, provides, depends, makedepends y checkdepends en archivos PKGBUILD
  • replaces, conflict, provides, depend, makedepend y checkdepend en archivos PKGINFO
  • pkgver en archivos PKGBUILD
  • pkgver en archivos SRCINFO
  • como parte de buildtoolver en archivos BUILDINFOv2

EJEMPLOS

"1.0.0-1"

Una versión de paquete completa.

"1:1.0.0-1"

Una versión de paquete completa con epoch.

"1.0.0"

Una versión de paquete mínima.

"1:1.0.0"

Una versión de paquete mínima con epoch.
