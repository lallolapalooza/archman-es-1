NOMBRE

al_reset_bitmap_blender - API de Allegro 5

SINÓPSIS

#include <allegro5/allegro.h>
void al_reset_bitmap_blender(void)

DESCRIPCIÓN

Restablece el mezclador para este mapa de bits a los valores predeterminados. Después de restablecer el mezclador de mapas de bits, se utilizarán los valores establecidos para al_set_bitmap_blender(3)/al_set_separate_bitmap_blender(3) en su lugar.

DESDE

5.2.5

[API inestable]: Nueva API.

VER TAMBIÉN
