NOMBRE

alpm-pkginfo-create - Crear un archivo PKGINFO según un esquema

SINOPSIS

alpm-pkginfo create [-h|--help] <subcomandos>

DESCRIPCIÓN

Crear un archivo PKGINFO según un esquema

Si la entrada se puede validar según el esquema, el programa escribe un archivo PKGINFO válido y sale sin ninguna salida y con un código de retorno de 0. Si la entrada no se puede validar según el esquema, se emite un error en stderr y el programa sale con un código de salida distinto de cero.

OPCIONES

-h, --help
Imprime la ayuda (ver un resumen con '-h')
