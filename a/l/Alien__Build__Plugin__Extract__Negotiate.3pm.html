NOMBRE

Alien::Build::Plugin::Extract::Negotiate - Plugin de negociación de extracción

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Extract' => (
  format => 'tar.gz',
);

DESCRIPCIÓN

Este es un plugin negociador para extraer paquetes descargados de internet. Este plugin elige el mejor plugin de Extracción para realizar el trabajo real. Los plugins que se eligen dependen de las propiedades que especifique, su plataforma y entorno. Generalmente es preferible usar un plugin negociador en lugar de usar un plugin de Extracción específico de su archivo alien.

PROPIEDADES

formato

El formato esperado para la descarga. Los valores posibles incluyen: "tar", "tar.gz", "tar.bz2", "tar.xz", "zip", "d".

MÉTODOS

elegir

my $name = Alien::Build::Plugin::Extract::Negotiate->pick($format);

Devuelve el nombre del mejor plugin para el formato dado.
