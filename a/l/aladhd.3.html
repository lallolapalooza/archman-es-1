subrutina aladhd (entero iounit, cadena*3 path)

ALADHD

Propósito:

!>
!> ALADHD imprime información de encabezado para las rutas de prueba de las rutinas del controlador.
!>

Parámetros

IOUNIT 
!>          IOUNIT es ENTERO
!>          El número de unidad al que se debe imprimir la información del encabezado.
!>

PATH

!>          PATH es CADENA*3
!>          El nombre de la ruta para la que se va a imprimir la información del encabezado. Las rutas actuales son
!>             _GE: Matrices generales
!>             _GB: Banda general
!>             _GT: Tridiagonal general
!>             _PO: Definida positiva simétrica o hermitiana
!>             _PS: Definida semi-positiva simétrica o hermitiana
!>             _PP: Definida positiva simétrica o hermitiana empaquetada
!>             _PB: Banda definida positiva simétrica o hermitiana
!>             _PT: Tridiagonal definida positiva simétrica o hermitiana
!>             _SY: Indefinida simétrica,
!>                     con pivoteo parcial (Bunch-Kaufman)
!>             _SR: Indefinida simétrica,
!>                     con pivoteo de torre (Bunch-Kaufman acotado)
!>             _SK: Indefinida simétrica,
!>                     con pivoteo de torre (Bunch-Kaufman acotado)
!>                     ( nuevo formato de almacenamiento para factores:
!>                       L y la diagonal de D se almacenan en A,
!>                       la subdiagonal de D se almacena en E )
!>             _SP: Empaquetada indefinida simétrica,
!>                     con pivoteo parcial (Bunch-Kaufman)
!>             _HA: Hermitiana (compleja),
!>                     Algoritmo de Assen
!>             _HE: Indefinida hermitiana (compleja),
!>                     con pivoteo parcial (Bunch-Kaufman)
!>             _HR: Indefinida hermitiana (compleja),
!>                     con pivoteo de torre (Bunch-Kaufman acotado)
!>             _HK: Indefinida hermitiana (compleja),
!>                     con pivoteo de torre (Bunch-Kaufman acotado)
!>                     ( nuevo formato de almacenamiento para factores:
!>                       L y la diagonal de D se almacenan en A,
!>                       la subdiagonal de D se almacena en E )
!>             _HP: Empaquetada indefinida hermitiana (compleja),
!>                     con pivoteo parcial (Bunch-Kaufman)
!>          El primer carácter debe ser S, D, C o Z (solo C o Z si es complejo).
!>
