alpm-split-package(7)

Paquete: alpm-docs

Licencias: CC-BY-SA-4.0

(7) Información Miscelánea Manual (7)

NOMBRE

split package - un paquete basado en ALPM que se compila junto con otros paquetes a partir de las mismas fuentes de paquetes.

DESCRIPCIÓN

Los paquetes divididos se refieren a dos o más paquetes basados en ALPM que se compilan a partir de las mismas fuentes de paquetes. Estos tipos de paquetes pueden crearse por razones arbitrarias, por ejemplo:

  • dividir diferentes tipos de funcionalidad (por ejemplo, un paquete que proporciona la interfaz gráfica de usuario y otro la interfaz de usuario de terminal de un proyecto)
  • extraer documentación específica (por ejemplo, la documentación para desarrolladores no es útil para todos los usuarios)
  • diversas funcionalidades de un proyecto son opcionales, se proporcionan como plugins, por ejemplo, y se pueden habilitar instalando paquetes divididos adicionales

Los paquetes divididos compilados a partir de las mismas fuentes de paquetes comparten algunos metadatos de paquete PKGINFO (es decir, pkgbase, pkgver, makedepends), mientras que otros metadatos pueden establecerse específicamente para cada paquete dividido individual.

Todos los archivos PKGINFOv2 para paquetes divididos definen un valor xdata de pkgtype=split, lo que indica que los metadatos describen un paquete dividido.

Los paquetes divididos son manejados como cualquier otro paquete basado en ALPM por un gestor de paquetes y requieren sus diversas relaciones de paquete tras la instalación.

EJEMPLOS

El siguiente ejemplo de PKGBUILD define dos paquetes divididos, que comparten example-split como pkgbase (virtual - sin ningún paquete real con ese nombre):

pkgbase=example-split
pkgname=(example-a example-b)
pkgver=0.1.0
pkgrel=1
pkgdesc="Un ejemplo de paquete dividido"
arch=(any)
url="https://archlinux.org"
license=(GPL-3.0-or-later)
makedepends=(
  meson
)
depends=(
  bash
  gcc-libs
)
package_example-a(){
  pkgdesc+=" - A"
  license+=" LGPL-2.1-or-later"
  depends+=" bash-completions"
}
package_example-b(){
  pkgdesc+=" - B"
  depends=(zsh)
}
