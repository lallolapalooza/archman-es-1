al_flip_display(3) Manual de funciones de la biblioteca al_flip_display(3)

NOMBRE

al_flip_display - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_flip_display(void)

DESCRIPCIÓN

Copia o actualiza los búferes frontal y trasero para que lo dibujado previamente en la pantalla seleccionada actualmente sea visible en pantalla. Los punteros al mapa de bits especial del búfer trasero permanecen válidos y conservan su semántica como búfer trasero, aunque el contenido pueda haber cambiado.

Nota: Si no se utiliza la opción ALLEGRO_SINGLE_BUFFER, normalmente querrá redibujar cada píxel del mapa de bits del búfer trasero para evitar artefactos de memoria no inicializada.

Varias opciones de pantalla cambian el comportamiento de esta función:

•
Con ALLEGRO_SINGLE_BUFFER, no se realiza ningún volteo. Aún tendrá que llamar a esta función para mostrar gráficos, dependiendo de cómo funcione el sistema gráfico utilizado.
•
La opción ALLEGRO_SWAP_METHOD puede tener información adicional sobre qué tipo de operación se utiliza internamente para voltear los búferes frontal y trasero.
•
Si ALLEGRO_VSYNC es 1, esta función forzará la espera de la sincronización vertical. Si ALLEGRO_VSYNC es 2, esta función no esperará la sincronización vertical. Con muchos controladores, el comportamiento de la sincronización vertical lo controla el usuario y no la aplicación, y ALLEGRO_VSYNC no se establecerá; en ese caso, al_flip_display(3) esperará la sincronización vertical dependiendo de la configuración establecida en las preferencias gráficas del sistema.
