NOMBRE

Alien::Build::Plugin::Fetch::Wget - Plugin para obtener archivos usando wget

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;

share {
  start_url 'https://www.openssl.org/source/';
  plugin 'Fetch::Wget';
};

DESCRIPCIÓN

ADVERTENCIA: Este plugin es algo experimental en este momento.

Este plugin proporciona una obtención basada en el comando "wget". Funciona con otros plugins de obtención (es decir, el primero que tenga éxito será utilizado). La mayoría de las veces, el mejor plugin para usar será Alien::Build::Plugin::Download::Negotiate, pero para algunas tareas de arranque SSL puede ser deseable intentar "wget" primero.

Protocolos soportados: "http", "https"

PROPIEDADES

wget_command

La ruta completa al comando "wget". El valor predeterminado suele ser correcto.

ssl

Ignorado por este plugin. Se proporciona por compatibilidad con algunos otros plugins de obtención.
