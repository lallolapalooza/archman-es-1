NOMBRE

al_draw_soft_line - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>

DESCRIPCIÓN

Dibuja una línea usando el rasterizador de software y funciones de píxel proporcionadas por el usuario. Para obtener ayuda para comprender qué hacen estas funciones, consulte la implementación de las diversas rutinas de sombreado en addons/primitives/line_soft.c. La línea se dibuja de arriba a abajo.

Parámetros:

•
v1, v2 - Los dos vértices de la línea
•
state - Un puntero a una estructura proporcionada por el usuario; esta estructura se pasará a todas las funciones de píxel
•
first - Se llama antes de dibujar el primer píxel de la línea. Se le pasan las coordenadas de este píxel, así como los dos vértices anteriores. Los vértices pasados pueden haber sido alterados por el recorte.
•
step - Se llama una vez por píxel. El segundo parámetro se establece en 1 si el paso es un paso menor y 0 si este paso es un paso mayor. Los pasos menores se toman solo en la dirección x o y. Los pasos mayores se toman en ambas direcciones diagonalmente. En todos los casos, el valor absoluto del cambio de coordenada es como máximo 1 en cualquier dirección.
•
draw - Se llama una vez por píxel. Se espera que la función dibuje el píxel en las coordenadas que se le pasan.
