NOMBRE

al_create_native_file_dialog - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_native_dialog.h>
ALLEGRO_FILECHOOSER *al_create_native_file_dialog(
   char const *initial_path,
   char const *title,
   char const *patterns,
   int mode)

DESCRIPCIÓN

Crea un nuevo diálogo nativo de archivo. Solo deberías tener un diálogo de este tipo abierto a la vez.

Parámetros:

•
initial_path: La ruta inicial de búsqueda y el nombre de archivo. Puede ser NULL. Para empezar con un nombre de archivo vacío, la cadena debe terminar con un separador de directorio (este debería ser el caso común).
•
title: Título del diálogo.
•
patterns: Una cadena que contiene conjuntos de patrones separados por saltos de línea para que coincidan. Un patrón es un patrón de estilo glob (por ejemplo, "*.txt") o un tipo MIME (por ejemplo, "image/png"). No todas las plataformas admiten ambos (y algunas ni siquiera admiten globs), por lo que una solución portátil es especificar un tipo MIME y patrones de estilo simple que Allegro elegirá para que coincidan con lo que la plataforma admite (por ejemplo, "image/png;*.png"). Múltiples patrones se separan con un punto y coma. Si la plataforma no proporciona soporte para patrones, este parámetro se ignora. Aquí hay algunos ejemplos de patrones:
•
"*.txt" – define un único filtro, que coincide con archivos *.txt.
•
"*.txt;*.md" – como el anterior, pero que coincide con dos tipos de archivos.
•
"Archivos de texto (*.txt, *.md) *.txt;*.md" – como el anterior, pero con una descripción personalizada (separada de los patrones con un espacio).
•
"Archivos de texto *.txt\nImágenes PNG image/png;*.png" – define dos filtros, con el segundo filtro usando un tipo MIME y una extensión al mismo tiempo.

Nota: Windows no admite tipos MIME. Android solo admite tipos MIME. En lugar de patrones de archivo, MacOS admite extensiones, por lo que la coincidencia basada en el nombre del archivo más allá del tipo de archivo no funciona. Allegro analizará tu patrón de archivo para intentar extraer la extensión del archivo. MacOS también admite tipos MIME, que se comportan de manera más predecible. MacOS no admite descripciones detalladas ni conjuntos de patrones múltiples; Allegro eliminará las descripciones detalladas y concatenará todos los patrones en una sola lista.

•
mode: 0, o una combinación de las siguientes banderas:
ALLEGRO_FILECHOOSER_FILE_MUST_EXIST
Si el diálogo nativo lo admite, no permitirá introducir nuevos nombres, sino que solo permitirá seleccionar archivos existentes. De lo contrario, se ignora.
ALLEGRO_FILECHOOSER_SAVE
Si el sistema de diálogo nativo tiene un diálogo diferente para guardar (por ejemplo, uno que permite crear nuevos directorios), se utiliza. De lo contrario, se ignora.
ALLEGRO_FILECHOOSER_FOLDER
Si hay soporte para un diálogo separado para seleccionar una carpeta en lugar de un archivo, se utilizará.
ALLEGRO_FILECHOOSER_PICTURES
Si hay un diálogo diferente disponible para seleccionar imágenes, se utiliza. De lo contrario, se ignora.
ALLEGRO_FILECHOOSER_SHOW_HIDDEN
Si la plataforma lo admite, también se mostrarán los archivos ocultos.
ALLEGRO_FILECHOOSER_MULTIPLE
Si se admite, permite seleccionar varios archivos.

Devuelve:

Un manejador para el diálogo que puedes pasar a al_show_native_file_dialog(3) para mostrarlo, y desde el cual luego puedes consultar los resultados usando al_get_native_file_dialog_count(3) y al_get_native_file_dialog_path(3). Cuando hayas terminado, llama a al_destroy_native_file_dialog(3) sobre él.

Si no se pudo crear una ventana de diálogo, esta función devuelve NULL.
