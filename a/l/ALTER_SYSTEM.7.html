NOMBRE

ALTER SYSTEM - cambiar un parámetro de configuración del servidor

SINOPSIS

ALTER SYSTEM SET parámetro_configuración { TO | = } { valor [, ...] | DEFAULT }
ALTER SYSTEM RESET parámetro_configuración
ALTER SYSTEM RESET ALL

DESCRIPCIÓN

ALTER SYSTEM se utiliza para cambiar los parámetros de configuración del servidor en todo el clúster de bases de datos. Puede ser más conveniente que el método tradicional de editar manualmente el archivo postgresql.conf. ALTER SYSTEM escribe la configuración del parámetro dado en el archivo postgresql.auto.conf, que se lee además de postgresql.conf. Establecer un parámetro en DEFAULT, o usar la variante RESET, elimina esa entrada de configuración del archivo postgresql.auto.conf. Usa RESET ALL para eliminar todas esas entradas de configuración.

Los valores establecidos con ALTER SYSTEM serán efectivos después de la próxima recarga de la configuración del servidor, o después del próximo reinicio del servidor en el caso de parámetros que solo se pueden cambiar al iniciar el servidor. Se puede solicitar una recarga de la configuración del servidor llamando a la función SQL pg_reload_conf(), ejecutando pg_ctl reload, o enviando una señal SIGHUP al proceso principal del servidor.

Solo los superusuarios y los usuarios con privilegio ALTER SYSTEM sobre un parámetro pueden cambiarlo usando ALTER SYSTEM. Además, dado que este comando actúa directamente sobre el sistema de archivos y no puede ser revertido, no está permitido dentro de un bloque de transacción o función.

PARÁMETROS

parámetro_configuración

Nombre de un parámetro de configuración modificable. Los parámetros disponibles se documentan en el Capítulo 19.

valor

Nuevo valor del parámetro. Los valores se pueden especificar como constantes de cadena, identificadores, números o listas separadas por comas de estos, según corresponda al parámetro en particular. Los valores que no son números ni identificadores válidos deben entrecomillarse. DEFAULT se puede escribir para especificar la eliminación del parámetro y su valor de postgresql.auto.conf.

Para algunos parámetros que aceptan listas, los valores entre comillas simples producirán una salida entre comillas dobles para preservar espacios en blanco y comas; para otros, se deben usar comillas dobles dentro de cadenas entre comillas simples para lograr este efecto.

NOTAS

Este comando no se puede usar para establecer data_directory, allow_alter_system, ni parámetros que no están permitidos en postgresql.conf (por ejemplo, opciones preestablecidas).

Ver la Sección 19.1 para otras formas de establecer los parámetros.

ALTER SYSTEM puede ser deshabilitado estableciendo allow_alter_system en off, pero esto no es un mecanismo de seguridad (como se explica en detalle en la documentación de este parámetro).

EJEMPLOS

Establecer el wal_level:

ALTER SYSTEM SET wal_level = replica;

Deshacer eso, restaurando cualquier configuración que estuviera activa en postgresql.conf:

ALTER SYSTEM RESET wal_level;

COMPATIBILIDAD

La declaración ALTER SYSTEM es una extensión de PostgreSQL.
