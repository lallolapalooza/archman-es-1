NOMBRE

ALTER_RULE - cambiar la definición de una regla

SINOPSIS

ALTER RULE nombre ON nombre_tabla RENAME TO nuevo_nombre

DESCRIPCIÓN

ALTER RULE cambia las propiedades de una regla existente. Actualmente, la única acción disponible es cambiar el nombre de la regla.

Para usar ALTER RULE, debes ser propietario de la tabla o vista a la que se aplica la regla.

PARÁMETROS

nombre

El nombre de una regla existente para modificar.

nombre_tabla

El nombre (opcionalmente calificado por esquema) de la tabla o vista a la que se aplica la regla.

nuevo_nombre

El nuevo nombre para la regla.

EJEMPLOS

Para renombrar una regla existente:

ALTER RULE notify_all ON emp RENAME TO notify_me;

COMPATIBILIDAD

ALTER RULE es una extensión del lenguaje de PostgreSQL, al igual que todo el sistema de reescritura de consultas.

VER TAMBIÉN

CREATE RULE (CREATE_RULE(7)), DROP RULE (DROP_RULE(7))
