NOMBRE

al_draw_justified_text - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_font.h>
void al_draw_justified_text(const ALLEGRO_FONT *font,
   ALLEGRO_COLOR color, float x1, float x2,
   float y, float diff, int flags, const char *text)

DESCRIPCIÓN

Al igual que al_draw_text(3), pero justificación de la cadena en la región x1-x2.

El parámetro diff es la cantidad máxima de espacio horizontal permitido entre palabras. Si la justificación del texto excediera los diff píxeles, o si la cadena contiene menos de dos palabras, la cadena se dibujará alineada a la izquierda.

El parámetro flags puede ser 0 o una de las siguientes banderas:

•
ALLEGRO_ALIGN_INTEGER - Dibujar texto alineado a posiciones de píxel enteras. Desde: 5.0.8, 5.1.5

VER TAMBIÉN

al_draw_justified_textf(3), al_draw_justified_ustr(3)
