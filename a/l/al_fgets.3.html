NOMBRE

al_fgets - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
char *al_fgets(ALLEGRO_FILE *f, char * const buf, size_t max)

DESCRIPCIÓN

Lee una cadena de bytes terminada por una nueva línea o fin de archivo en el búfer proporcionado. Los terminadores de línea, si los hay, se incluyen en la cadena devuelta. Se leen un máximo de `max-1` bytes, reservando un byte para un terminador NULO.

Parámetros:

•
f - archivo del que leer
•
buf - búfer a rellenar
•
max - tamaño máximo del búfer

Devuelve el puntero a `buf` si tiene éxito. Devuelve NULL si ocurrió un error o si se alcanzó el final del archivo sin leer ningún byte.

Consulte al_fopen(3) sobre las traducciones de caracteres de fin de línea.
