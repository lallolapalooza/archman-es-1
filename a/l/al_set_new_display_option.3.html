DESCRIPCIÓ

N

Establece una opción de pantalla adicional, que se utilizará al crear nuevas pantallas en el hilo de llamada. Las opciones de pantalla difieren de los indicadores de pantalla y especifican algunos detalles del contexto que se creará dentro de la propia ventana. Estas principalmente no tienen efecto en Allegro en sí, pero es posible que desee especificarlas, por ejemplo, si desea usar muestreo

múltiple.

El parámetro `importance' puede ser cualquiera de los

siguientes:
•
ALLEGRO_REQUIRE - La pantalla no se creará si no se puede cumplir la
configuración.
•
ALLEGRO_SUGGEST - Si la configuración no está disponible, la pantalla se creará de todos modos con una configuración lo más cercana posible a la solicitada. Puede consultar el valor real utilizado en ese caso llamando a al_get_display_option(3) después de que se haya creado la
pantalla.
•
ALLEGRO_DONTCARE - Si agregó una opción de pantalla con
una de las dos configuraciones anteriores, se e
liminará de nuevo. De lo contrario, no hace nada.

Las opciones soportadas

son:
ALLEGRO_COLOR_S
IZE
Esto se puede usar para solicitar una profundidad de bits específica. Por ejemplo, para forzar un framebuffer de 16 bits, establezca esto en
16.
ALLEGRO_RED_SIZE, ALLEGRO_GREEN_SIZE, ALLEGRO_BLUE_SIZE, ALLEGRO_ALPHA_S
IZE
Tamaño individual del componente de color en
bits.
ALLEGRO_RED_SHIFT, ALLEGRO_GREEN_SHIFT, ALLEGRO_BLUE_SHIFT, ALLEGRO_ALPHA_SH
IFT
Junto con las configuraciones anteriores, estas se pueden usar para especificar la disposición exacta de píxeles que la pantalla debe usar. Normalmente no hay razón para usar
estas.
ALLEGRO_ACC_RED_SIZE, ALLEGRO_ACC_GREEN_SIZE, ALLEGRO_ACC_BLUE_SIZE, ALLEGRO_ACC_ALPHA_S
IZE
Esto se puede usar para definir el tamaño requerido del búfer de
acumulación.
ALLEGRO_STER
EO
Si la pantalla es una pantalla
estéreo.
ALLEGRO_AUX_BUFF

Número de búferes auxiliares que la pantalla debe
tener.
ALLEGRO_DEPTH_S

usar.
ALLEGRO_STENCIL_S

Cuántos bits usar para el búfer de estarcido (stencil)
.
ALLEGRO_SAMPLE_BUFF
ERS
Si usar muestreo múltiple (1) o no (0)
.
ALLEGRO_SAMP

Si lo anterior es 1, el número de muestras a usar por píxel. De lo contrario,

Si lo anterior es 0, esto se establece en 1 para indicar que la pantalla está usando un método de copia para hacer disponible el siguiente búfer en la cadena de volteo, o en 2 para indicar un método de volteo u
otro.
ALLEGRO_COMPATIBLE_DISP
LAY
Indica si las funciones gráficas de Allegro pueden usar esta pantalla. Si solicita una pantalla no utilizable por Allegro, aún puede usar, por ejemplo, OpenGL para dibujar
gráficos.
ALLEGRO_UPDATE_DISPLAY_REG
ION
Establecido en 1 si la pantalla es capaz de actualizar solo una región, y en 0 si llamar a al_update_display_region(3) es equivalente a al_flip_display(3)
.
ALLEGRO_VSY
NC
Establecido en 1 para decirle al controlador que espere al vsync en al_flip_display(3), o en 2 para forzar el vsync desactivado. El valor predeterminado de 0 significa que Allegro no intenta modificar el comportamiento del vsync, por lo que puede estar activado o desactivado. Tenga en cuenta que incluso en el caso de 1 o 2, es posible anular el comportamiento del vsync en el controlador gráfico, por lo que no debe depender de
él.
ALLEGRO_MAX_BITMAP_S
IZE
Al consultar, devuelve el tamaño máximo (ancho y alto) que un mapa de bits puede tener para esta pantalla. Las llamadas a al_create_bitmap(3) o al_load_bitmap(3) para mapas de bits más grandes que este tamaño fallarán. No se aplica a los mapas de bits en memoria, que siempre pueden tener un tamaño arbitrario (pero son lentos para dibujar)
.
ALLEGRO_SUPPORT_NPOT_BIT
MAP
Establecido en 1 si las texturas utilizadas para los mapas de bits en esta pantalla pueden tener un tamaño que no sea una potencia de dos. Esto es principalmente útil si usa Allegro para cargar texturas, ya que de lo contrario solo se usarán internamente texturas de potencia de dos como almacenamiento de mapas de
bits.
ALLEGRO_CAN_DRAW_INTO_BIT
MAP
Establecido en 1 si puede usar al_set_target_bitmap(3) en mapas de bits de esta pantalla para dibujar en ellos. Si no es el caso, se usará emulación por software al dibujar en mapas de bits de la pantalla (lo cual puede ser muy lento)
.
ALLEGRO_SUPPORT_SEPARATE_AL
PHA
Esto se establece en 1 si la función al_set_separate_blender(3) es soportada. De lo contrario, los parámetros alfa serán
ignorados.
ALLEGRO_AUTO_CONVERT_BITM
APS
Esto está activado de forma predeterminada. Hace que cualquier mapa de bits
en memoria existente con el indicador ALLEGRO_CONVERT_BITMAP sea convertid
o a un mapa de bits de la pantalla recién creada con la opción establecida.
