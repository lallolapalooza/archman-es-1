NOMBRE

Alien::Build::Plugin::Prefer::GoodVersion - Plugin para filtrar versiones conocidas como buenas

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Prefer::GoodVersion' => '1.2.3';

DESCRIPCIÓN

Este plugin te permite especificar una o más versiones buenas de una biblioteca. Esto no afecta a una instalación del sistema en absoluto. Este plugin hace lo contrario del plugin "Prefer::BadVersion". Necesitas un plugin Prefer que filtre y ordene los archivos primero. Puedes especificar el filtro de una de las tres maneras:

como una cadena
Filtra cualquier archivo que coincida con la versión dada. 
use alienfile;
plugin 'Prefer::GoodVersion' => '1.2.3';
como un array
Filtra todos los archivos que coincidan con cualquiera de las versiones dadas. 
use alienfile;
plugin 'Prefer::GoodVersion' => [ '1.2.3', '1.2.4' ];
como una referencia de código
Filtra cualquier archivo que devuelva un valor verdadero. 
use alienfile;
plugin 'Prefer::GoodVersion' => sub {
  my($file) = @_;
  $file->{version} eq '1.2.3'; # lo mismo que la versión de cadena anterior
};

Este plugin también se puede utilizar para filtrar versiones conocidas como buenas de una biblioteca en una sola plataforma. Por ejemplo, si sabes que la versión 1.2.3 es buena en Windows, pero la lógica predeterminada está bien en otras plataformas:

use alienfile;
plugin 'Prefer::GoodVersion' => '1.2.3' if $^O eq 'MSWin32';

PROPIEDADES

filtro

Filtra las entradas que coinciden con el filtro.

ADVERTENCIAS

Si estás utilizando el modo de cadena o array, necesitas un plugin Prefer existente que establezca el número de versión para cada candidato de archivo, como Alien::Build::Plugin::Prefer::SortVersions.

A menos que quieras excluir la última versión de una instalación compartida, este plugin no es realmente muy útil. No tiene ningún efecto en las instalaciones del sistema, lo cual puede no ser obvio al principio.
