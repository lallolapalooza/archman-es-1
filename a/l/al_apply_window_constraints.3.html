NOMBRE

al_apply_window_constraints - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_apply_window_constraints(ALLEGRO_DISPLAY *display, bool onoff)

DESCRIPCIÓN

Habilita o deshabilita las restricciones previamente establecidas por la función al_set_window_constraints(3).

Si se habilita, la pantalla especificada se redimensionará automáticamente a nuevos tamaños para cumplir con las restricciones en los siguientes casos:

•
La pantalla especificada es redimensionable, no está maximizada y no está en modo de pantalla completa.
•
Si el tamaño actual apropiado de la pantalla (ancho o alto) es menor que el valor de la restricción. Aplicado a restricciones mínimas.
•
Si el tamaño actual apropiado de la pantalla (ancho o alto) es mayor que el valor de la restricción. Aplicado a restricciones máximas.

Las restricciones no se aplican cuando una pantalla cambia de modo ventana a maximizado o pantalla completa. Cuando una pantalla cambia de modo maximizado/pantalla completa a modo ventana, la pantalla puede ser redimensionada como se describe anteriormente. El último caso también es posible cuando un usuario arrastra la pantalla maximizada con el ratón.

Si se deshabilita, la pantalla especificada dejará de usar restricciones.
