(5) Manual de formatos de archivo (5)

NOMBRE

ALPM-MTREE - Formato de descripción de jerarquía de directorios de paquetes.

DESCRIPCIÓN

El formato mtree es un formato textual que describe la jerarquía y los metadatos de los archivos en un directorio.

mtree es un formato conocido que puede usarse, por ejemplo, para instrucciones de instalación o para verificar metadatos de archivos y la jerarquía de un directorio.

El formato ALPM-MTREE se adhiere a la especificación oficial de mtree. Sin embargo, los archivos .MTREE utilizados en el contexto de los paquetes ALPM solo usan un subconjunto del formato oficial mtree que tiene sentido en el ámbito del empaquetado.

Propiedades

Los archivos .MTREE que son generados por makepkg solo contienen las siguientes propiedades:

  • type
  • uid
  • gid
  • mode
  • time
  • size
  • md5
  • sha256
  • link

Los archivos .MTREE se usan en el ámbito de los paquetes basados en ALPM y generalmente se relacionan con archivos dentro de sus respectivos paquetes. Debido a esto, todas las rutas proporcionadas en un ALPM-MTREE deben ser relativas a la raíz del paquete, con la excepción de los destinos de los enlaces, que también pueden representar rutas absolutas.

Propiedad Tipo de Ruta

En contraste con todos los tipos disponibles en mtree, ALPM-MTREE solo permite tres tipos de archivo:

  • dir Un directorio
  • file Un archivo
  • link Un enlace simbólico

No se deben usar otros tipos de archivo, ya que representan tipos específicos de hardware o ad hoc, que no deben incluirse en un paquete.

Campos Requeridos por Tipo de Archivo

ALPM-MTREE requiere que se establezcan valores específicos para ciertos tipos de archivo, lo cual es algo que mtree no impone por especificación.

El tipo de ruta dir requiere que se establezcan las siguientes propiedades:

  • path
  • uid
  • gid
  • mode
  • time

El tipo de ruta file requiere que se establezcan las siguientes propiedades:

  • path
  • uid
  • gid
  • mode
  • size
  • md5_digest
  • sha256_digest
  • time

El tipo de ruta link requiere que se establezcan las siguientes propiedades:

  • path
  • uid
  • gid
  • mode
  • link
  • time

Uso en Pacman

En Pacman, los archivos ALPM-MTREE se utilizan únicamente para verificar que los archivos instalados son idénticos a los archivos originales sin tener que conservar el paquete original. Los archivos .MTREE se generan e incluyen implícitamente al crear paquetes a través de makepkg. El archivo .MTREE comprimido con gzip se encuentra en la raíz de los paquetes basados en ALPM.

Versionado

El formato ALPM-MTREE existe en múltiples versiones. La información en este documento es para la versión 1, que está obsoleta. El formato ALPM-MTREE versión 1 se introdujo con el lanzamiento de pacman 4.6.0 el 30/04/2012.

EJEMPLOS

#mtree
/set type=file uid=0 gid=0 mode=644
./.BUILDINFO time=1696727741.0 size=5574 md5digest=04a85103d4780101c710a297aae33837 sha256digest=708be566788a6a2712bcd40425d93761569ede07371781374edb1f22e2a3eb96
./.PKGINFO time=1696727741.0 size=830 md5digest=bde30355e5b95a86c59afbd149cc28da sha256digest=3aa17bec02b34c157e7c739c62e0e37a9d19f1459d404d7c6f2c14c6008127cd
set mode=755 type=dir
./usr time=1731613789.0
./usr/bin time=1731613789.0
./usr/bin/resolvconf time=1731613789.0 mode=777 type=link link=resolvectl

Generación

Los archivos mtree de ALPM se generan llamando a:

bsdtar \
  --format=mtree \
  --options='!all,use-set,type,uid,gid,mode,time,size,md5,sha256,link' \
  $folder

Usos

En el contexto de ALPM y pacman, el propósito principal del archivo mtree es proporcionar una forma eficiente de obtener los metadatos de archivos de un paquete sin tener que extraer y leer el paquete completo.

Estos datos se utilizan luego para verificar los archivos instalados en el sistema de destino frente a los archivos originales del paquete. Consulte la funcionalidad de verificación de consulta de pacman para más detalles.
