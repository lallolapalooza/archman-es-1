ALACRITTY-MSG(1) Manual de Comandos Generales ALACRITTY-MSG(1)

NOMBRE

alacritty-msg - Envía mensajes a Alacritty.

SINOPSIS

Este comando se comunica con instancias de Alacritty en ejecución a través de un socket, lo que permite controlar Alacritty sin acceder a él directamente.

OPCIONES

-s, --socket <SOCKET>

Ruta para la comunicación por socket IPC.

MENSAJES

create-window

Crea una nueva ventana en el mismo proceso de Alacritty.

FLAGS

--hold
Permanece abierto después de que el proceso hijo salga.

OPCIONES

--working-directory <DIRECTORIO_TRABAJO>
Inicia el shell en el directorio de trabajo especificado.

-T, --title <TÍTULO>

Define el título de la ventana.

Predeterminado: Alacritty

--class <GENERAL> | <GENERAL>,<INSTANCIA>

Define la clase/app_id de la ventana en X11/Wayland.

Predeterminado: Alacritty,Alacritty

-o, --option <OPCIÓN>...

Anula las opciones del archivo de configuración.

Ejemplo: alacritty msg create-window -o 'cursor.style="Beam"'

-e, --command <COMANDO>...

Comando y argumentos a ejecutar (debe ser el último argumento).

config

Actualiza la configuración de Alacritty.

ARGUMENTOS

<OPCIONES_CONFIG>...
Opciones del archivo de configuración.

Ejemplo: alacritty msg config 'cursor.style="Beam"'

FLAGS

-r, --reset
Borra todos los cambios de configuración en tiempo de ejecución.

OPCIONES

-w, --window-id <ID_VENTANA>
ID de la ventana para la nueva configuración.

Usa -1 para aplicar este cambio a todas las ventanas.

Predeterminado: $ALACRITTY_WINDOW_ID

get-config

Lee la configuración de Alacritty en tiempo de ejecución.

OPCIONES

-w, --window-id <ID_VENTANA>
ID de la ventana para la solicitud de configuración.

Usa -1 para obtener la configuración global.

Predeterminado: $ALACRITTY_WINDOW_ID

VER TAMBIÉN
