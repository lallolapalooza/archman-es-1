NOMBRE

ALTER_TEXT_SEARCH_PARSER - cambiar la definición de un analizador de búsqueda de texto

SINOPSIS

ALTER TEXT SEARCH PARSER nombre RENAME TO nuevo_nombre
ALTER TEXT SEARCH PARSER nombre SET SCHEMA nuevo_esquema

DESCRIPCIÓN

ALTER TEXT SEARCH PARSER cambia la definición de un analizador de búsqueda de texto. Actualmente, la única funcionalidad compatible es cambiar el nombre del analizador.

Debes ser superusuario para usar ALTER TEXT SEARCH PARSER.

PARÁMETROS

nombre

El nombre (con o sin calificador de esquema) de un analizador de búsqueda de texto existente.

nuevo_nombre

El nuevo nombre del analizador de búsqueda de texto.

nuevo_esquema

El nuevo esquema para el analizador de búsqueda de texto.

COMPATIBILIDAD

No existe una sentencia ALTER TEXT SEARCH PARSER en el estándar SQL.

VER TAMBIÉN

CREATE TEXT SEARCH PARSER (CREATE_TEXT_SEARCH_PARSER(7)), DROP TEXT SEARCH PARSER (DROP_TEXT_SEARCH_PARSER(7))
