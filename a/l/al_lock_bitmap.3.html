NOMBRE

al_lock_bitmap - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
ALLEGRO_LOCKED_REGION *al_lock_bitmap(ALLEGRO_BITMAP *bitmap,
   int format, int flags)

DESCRIPCIÓN

Bloquea un bitmap completo para lectura o escritura. Si el bitmap es un bitmap de pantalla, se actualizará desde la memoria del sistema después de desbloquear el bitmap (a menos que se bloquee solo para lectura). Devuelve NULL si el bitmap no se puede bloquear, por ejemplo, si el bitmap estaba bloqueado previamente y no se desbloqueó. Esta función también devuelve NULL si el formato es un formato comprimido.

Las banderas son:

•
ALLEGRO_LOCK_READONLY - La región bloqueada no se escribirá. Esto puede ser más rápido si el bitmap es una textura de video, ya que puede ser descartada después del bloqueo en lugar de cargarse de nuevo en la tarjeta.
•
ALLEGRO_LOCK_WRITEONLY - La región bloqueada no se leerá. Esto puede ser más rápido si el bitmap es una textura de video, ya que no se necesitan datos para leer de la tarjeta de video. Está obligado a rellenar todos los píxeles antes de volver a desbloquear el bitmap, así que tenga cuidado al usar esta bandera.
•
ALLEGRO_LOCK_READWRITE - La región bloqueada se puede escribir y leer. Use esta bandera si se necesita escribir un número parcial de píxeles, incluso si no se necesita leer.

formato indica el formato de píxel en el que estará el búfer devuelto. Para bloquear en el mismo formato en que el bitmap almacena sus datos internamente, llame con al_get_bitmap_format(bitmap) como formato o use ALLEGRO_PIXEL_FORMAT_ANY. Bloquear en el formato nativo generalmente será más rápido. Si el formato del bitmap está comprimido, usar ALLEGRO_PIXEL_FORMAT_ANY elegirá un formato no comprimido definido por la implementación.

En algunas plataformas, Allegro copia automáticamente el contenido de los bitmaps de video, ya que pueden perderse ocasionalmente (ver la discusión en la documentación de al_create_bitmap(3)). Si está recreando completamente el contenido del bitmap con frecuencia (por ejemplo, cada fotograma), obtendrá un rendimiento mucho mejor creando el bitmap de destino con la bandera ALLEGRO_NO_PRESERVE_TEXTURE.

Nota: Mientras un bitmap está bloqueado, no puede usar ninguna operación de dibujo sobre él (con la única excepción de al_put_pixel(3) y al_put_blended_pixel(3)).
