NOMBRE

al_hold_bitmap_drawing - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_hold_bitmap_drawing(bool hold)

DESCRIPCIÓN

Habilita o deshabilita el dibujo diferido de bitmaps. Esto permite el dibujo eficiente de muchos bitmaps que comparten un bitmap padre, como sub-bitmaps de una hoja de teselas o simplemente bitmaps idénticos. Dibujar bitmaps que no comparten un padre es menos eficiente, por lo que es aconsejable escalonar las llamadas de dibujo de bitmaps de tal manera que el bitmap padre sea el mismo para un gran número de esas llamadas. Mientras el dibujo diferido de bitmaps está habilitado, las únicas funciones que se pueden usar son las funciones de dibujo de bitmaps y las funciones de dibujo de fuentes. Cambiar el estado, como los modos de mezcla, resultará en un comportamiento indefinido. Una excepción a esta regla son las transformaciones no de proyección. Es posible establecer una nueva transformación mientras el dibujo está en espera.

No se garantiza que se realice ningún dibujo hasta que deshabilites la espera. Por lo tanto, el modismo de uso de esta función es habilitar el dibujo diferido de bitmaps, dibujar tantos bitmaps como sea posible, teniendo cuidado de escalonar los bitmaps que comparten bitmaps padres, y luego deshabilitar el dibujo diferido. Como se mencionó anteriormente, esta función también funciona con fuentes de bitmap y truetype, por lo que si se necesitan dibujar varias líneas de texto, esta función puede acelerar las cosas.
