NOMBRE

Alien::Build::Plugin::Build::CMake - Plugin CMake para Alien::Build

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;

share {
  plugin 'Build::CMake';
  build [
    # este es el paso de compilación predeterminado, si no especificas uno.
    [ '%{cmake}',
        @{ meta->prop->{plugin_build_cmake}->{args} },
        # ... pon argumentos cmake adicionales aquí ...
        '%{.install.extract}'
    ],
    '%{make}',
    '%{make} install',
  ];
};

DESCRIPCIÓN

Este plugin ayuda a compilar proyectos alienizados que utilizan "cmake". La intención es hacer de este un plugin central de Alien::Build si/cuando sea lo suficientemente estable.

Este plugin proporciona una propiedad meta "plugin_build_cmake.args" que puede cambiar con el tiempo, pero por el momento incluye:

-G %{cmake_generator}                          \
-DCMAKE_POSITION_INDEPENDENT_CODE:BOOL=true    \
-DCMAKE_INSTALL_PREFIX:PATH=%{.install.prefix} \
-DCMAKE_INSTALL_LIBDIR:PATH=lib                \
-DCMAKE_MAKE_PROGRAM:PATH=%{make}

Este plugin soporta compilaciones fuera de la fuente a través de la propiedad meta "out_of_source".

MÉTODOS

generador_cmake

Devuelve el generador de "cmake" según el "make" de tu Perl.

es_dmake

Devuelve verdadero si el "make" de tu Perl parece ser "dmake".

AYUDANTES

cmake

Este plugin reemplaza el ayudante "cmake" predeterminado con el que proviene de Alien::cmake3.

generador_cmake

Este es el generador de "cmake" apropiado para usar según el make utilizado por tu Perl. Frecuentemente es "Unix Makefiles". Un lugar donde puede ser diferente es si tu Perl de Windows utiliza "nmake", que viene con Visual C++.

make

Este plugin *puede* reemplazar el ayudante "make" predeterminado si el "make" predeterminado no es compatible con "cmake". Esto suele ser un problema con versiones antiguas de Strawberry Perl que utilizaban "dmake". En Perls que utilizan "dmake", este plugin buscará GNU Make en el PATH y, si no lo encuentra, recurrirá a usar Alien::gmake.
