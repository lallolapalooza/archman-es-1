NOMBRE

ALTER_SCHEMA - cambia la definición de un esquema

SINOPSIS

ALTER SCHEMA name RENAME TO new_name
ALTER SCHEMA name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPCIÓN

ALTER SCHEMA cambia la definición de un esquema.

Debes ser propietario del esquema para usar ALTER SCHEMA. Para renombrar un esquema, también debes tener el privilegio CREATE para la base de datos. Para cambiar el propietario, debes poder SET ROLE al nuevo rol propietario, y ese rol debe tener el privilegio CREATE para la base de datos. (Ten en cuenta que los superusuarios tienen todos estos privilegios automáticamente).

PARÁMETROS

name

El nombre de un esquema existente.

new_name

El nuevo nombre del esquema. El nuevo nombre no puede comenzar con pg_, ya que tales nombres están reservados para esquemas del sistema.

new_owner

El nuevo propietario del esquema.

COMPATIBILIDAD

No existe la sentencia ALTER SCHEMA en el estándar SQL.

VER TAMBIÉN

CREATE SCHEMA (CREATE_SCHEMA(7)), DROP SCHEMA (DROP_SCHEMA(7))
