NOMBRE

ALTER_TRIGGER - cambiar la definición de un disparador

SINOPSIS

ALTER TRIGGER nombre ON nombre_tabla RENAME TO nuevo_nombre
ALTER TRIGGER nombre ON nombre_tabla [ NO ] DEPENDS ON EXTENSION nombre_extension

DESCRIPCIÓN

ALTER TRIGGER cambia las propiedades de un disparador existente.

La cláusula RENAME cambia el nombre del disparador dado sin modificar de otra manera la definición del disparador. Si la tabla sobre la que actúa el disparador es una tabla particionada, los disparadores clonados correspondientes en las particiones también se renombran.

La cláusula DEPENDS ON EXTENSION marca el disparador como dependiente de una extensión, de modo que si la extensión se elimina, el disparador se eliminará automáticamente.

Debes ser propietario de la tabla sobre la que actúa el disparador para poder cambiar sus propiedades.

PARÁMETROS

nombre

El nombre de un disparador existente para modificar.

nombre_tabla

El nombre de la tabla sobre la que actúa este disparador.

nuevo_nombre

El nuevo nombre para el disparador.

nombre_extension

El nombre de la extensión de la que el disparador dependerá (o de la que ya no dependerá, si se especifica NO). Un disparador que está marcado como dependiente de una extensión se elimina automáticamente cuando se elimina la extensión.

NOTAS

La capacidad de habilitar o deshabilitar temporalmente un disparador la proporciona ALTER TABLE, no ALTER TRIGGER, ya que ALTER TRIGGER no tiene una forma conveniente de expresar la opción de habilitar o deshabilitar todos los disparadores de una tabla a la vez.

EJEMPLOS

Para renombrar un disparador existente:

ALTER TRIGGER emp_stamp ON emp RENAME TO emp_track_chgs;

Para marcar un disparador como dependiente de una extensión:

ALTER TRIGGER emp_stamp ON emp DEPENDS ON EXTENSION emplib;

COMPATIBILIDAD

ALTER TRIGGER es una extensión de PostgreSQL del estándar SQL.

VER TAMBIÉN

ALTER TABLE (ALTER_TABLE(7))
