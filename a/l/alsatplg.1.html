NOMBRE

alsatplg - Compilador de topología ALSA

SINOPSIS

alsatplg <opciones> [comando]

DESCRIPCIÓN

alsatplg (Compilador de topología ALSA) es un programa para compilar archivos de configuración de topología al archivo binario para los controladores del kernel.

Los controladores de audio actuales suelen codificar la información de topología en las fuentes del controlador: Esto acopla fuertemente el controlador de audio a la placa de desarrollo, lo que hace que sea un proceso que consume mucho tiempo modificar un controlador para que funcione en diferentes dispositivos. El controlador también está fuertemente acoplado a la versión del firmware DSP, lo que significa que se necesita cuidado adicional para mantener sincronizadas las versiones del controlador y del firmware. Las nuevas funciones del firmware también implican actualizaciones del controlador.

El proyecto de topología ALSA elimina la necesidad de reescribir o portar controladores de audio a diferentes dispositivos o firmwares: Los controladores no tienen datos de topología codificados, lo que significa que un único controlador se puede usar en diferentes dispositivos actualizando los datos de topología desde el sistema de archivos. Las actualizaciones de firmware se pueden implementar sin tener que actualizar los controladores. El nuevo firmware solo necesita incluir un archivo de topología actualizado que describa la actualización.

OPCIONES

Opciones disponibles:

-h, --help
esta ayuda
-V, --version
muestra la versión de la utilidad y las versiones de las bibliotecas utilizadas
-c, --compile ARCHIVO
archivo de configuración fuente para la compilación
-d, --decode ARCHIVO
archivo de topología binaria fuente para la decodificación
-n, --normalize ARCHIVO
analiza y guarda el archivo de configuración en formato normalizado
-u, --dump ARCHIVO
analiza y guarda el archivo de configuración en el formato especificado
-o, --output ARCHIVO
archivo de salida
-v, --verbose NIVEL
establece el nivel de verbosidad
-s, --sort
ordena los identificadores de configuración (establecido para normalización)
-x, --nocheck
guarda la configuración sin verificación de integridad adicional
-z, --dapm-nosort
no ordenar los elementos del grafo DAPM (como en la versión 1.2.1-)

ARCHIVOS

Los archivos maestros de topología para cada tarjeta de sonido soportada se encuentran en /usr/share/alsa/topology.

Por ejemplo, el archivo maestro de casos de uso para la tarjeta broadwell se encuentra en /usr/share/alsa/topology/broadwell/broadwell.conf, este archivo describe el hardware de audio para el controlador.

Para más detalles sobre la sintaxis de los archivos UCM, consulte el código fuente de alsa-lib:
http://git.alsa-project.org/?p=alsa-lib.git;a=blob;f=src/topology/parser.c
