NOMBRE

alpm-mtree format - Leer un archivo MTREE y devolverlo en otro formato de archivo

SINOPSIS

alpm-mtree format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Leer un archivo MTREE y devolverlo en otro formato de archivo

Lee y valida un archivo MTREE según un esquema y lo devuelve en otro formato de archivo (actualmente, solo se admite JSON). Si el archivo se puede validar, el programa sale con los datos devueltos en otro formato de archivo en la salida estándar y un código de salida de 0. Si el archivo no se puede validar, se emite un error en la salida de error estándar y el programa sale con un código de salida distinto de cero.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema MTREE a utilizar.

Si no se proporciona una versión del esquema, se deducirá del propio archivo.

Los valores válidos son ['1', '2'].

-o, --output-format <FORMATO_SALIDA> [predeterminado: json]
Proporciona el formato de salida

Posibles valores:

•
json: El formato de salida JSON
-p, --pretty
Determina si la salida se mostrará de forma atractiva y no minimizada.

Solo se aplica a los formatos que admiten salida atractiva, de lo contrario, simplemente se ignora.

-h, --help
Imprime la ayuda (ve un resumen con '-h')
[ARCHIVO]
Un archivo opcional para leer.

Si no se proporciona ningún archivo, se utiliza la entrada estándar.
