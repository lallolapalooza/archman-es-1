DESCRIPCIÓ

N

Es natural que te preocupe que un Alien pueda estar descargando algo aleatorio de internet. Este manual describirá algunos de los riesgos reales y repasará cómo puedes

mitigarlos.

sin

garantía

Alien::Build proporciona a los autores de Alien herramientas para añadir dependencias externas no-Perl a módulos de CPAN. Es software de código abierto impulsado enteramente por voluntarios, lo que significa que las personas que escriben este software no reciben compensación monetaria por el trabajo. Como tal, hacemos lo mejor posible para no introducir intencionalmente vulnerabilidades de seguridad en nuestros módulos, o en sus dependencias. Pero tampoco es nuestra responsabilidad. Si estás operando en un entorno donde necesitas seguridad absoluta, debes auditar cuidadosamente todo el softwar

e que u
tilizas.

Alien::Build vs.

CPAN

Supongo que podrías argumentar que los Aliens basados en Alien::Build y los Aliens en general son inherentemente menos seguros que los módulos de Perl en CPAN que no descargan cosas aleatorias de internet. Peor aún, los Aliens podrían estar descargando desde fuentes inseguras como "http" o "ftp"

.

Este argumento se desmorona bastante rápido cuando te das cuenta de

que
1
.
Los módulos de Perl de CPAN son de hecho cosas aleatorias de internet. La mayoría de los módulos, al instalarse, ejecutan un "Makefile.PL" que puede ejecutar código Perl completamente arbitrario. Sin una auditoría adecuada o firewalls, ese código de CPAN podría estar realizando conexiones a fuentes inseguras como "http" si ellos mismos no están haciendo algo
malicioso.
2
.
Por defecto, el cliente de CPAN más utilizado, App::cpanminus, usa "http" para obtener módulos de CPAN. Así que, a menos que hayas configurado específicamente para que se c
onecte a una fuente segura, estás descargando incluso
más cosas aleatorias de lo habitual desde internet.

El resumen es que si estás usando un módulo de Perl, ya sea "Foo::PP", "Foo::XS" o "Alien::libfoo" y te preocupa la seguridad, necesitas a

uditar todos tus módulos de
Perl, no solo los de Alien.

Restringiendo Alien::Build mediante el

entorno

De acuerdo, concedido que necesitas auditar el software por seguridad independientemente de si es Alien, aún no te gusta la idea de descargar dependencias externas y no puedes hacer firewall solo a las instalaciones de los módulos de

CPAN.

Los Aliens basados en Alien::Build respetan una serie de variables de entorno que al menos te dan algo de control sobre cuán agresivo será Alien::Build al buscar cosas aleatorias en

internet.
"ALIEN_DOWNLOAD_RU
LE"
Esta variable de entorno configura cómo Alien::Build tratará los protocolos inseguros y los archivos que no incluyen una firma criptográfica.

Parte del diseño del sistema Alien::Build es que típicamente intenta descargar la última versión de un paquete en lugar de una versión fija, para que el Alien no necesite ser actualizado cuando se publique un nuevo paquete alienizado. Esto significa que frecuentemente tenemos que depender de TLS o paquetes alienizados incluidos para asegurar que el paquete alienizado se descargue de forma

segura.

Recientemente (a partir de Alien::Build 2.59) comenzamos a soportar firmas criptog

ráficas definidas en los alienfiles, pero aún no son muy comunes, y solo funcionan
realmente cuando una sola URL de paquete alienizado está codificada en el alienf
ile en lugar del modo de operación más típico donde se descarga la última versión.
wa
rn
Este modo te advertirá si un Alien basado en Alien::Build intenta obtener un paquete alienizado de forma insegura. También te advertirá si un paquete no tiene una firma criptográfica. Ninguna de estas cosas detendría la instalación del Alien.

Desafortunadamente, este es actualmente el modo por defecto de Alien::Build, por razones históricas. Una vez que los plugins y los Aliens se actualicen para usar ya sea una obtención segura (TLS o paquetes alienizados incluidos) o firmas criptográficas, el valor por defecto cambiará a "digest_or

_encr
ypt".
digest_or_encr
ypt
Este modo requerirá que antes de que un paquete alienizado sea extraído, este haya sido obtenido mediante un protocolo seguro("https" o "file"), o que el paquete coincida con una firma criptográfica.

Esto probablemente será el valor por defe

cto para Alien::Build en un futuro cercan
o, pero no hace daño configurarlo ahora,
si no te importa enviar tickets a Aliens
o plugins que aún no soporten este modo.
"ALIEN_INSTALL_NETWO
RK"
Por diseño, los Aliens deberían usar instalaciones locales de bibliotecas y herramientas antes de descargar el código fuente desde internet. Establecer esta variable de entorno a falso, instruirá a Alien::Build para que no intente obtener el paquete alienizado de internet si no está disponible localmente o como un paquete incluido.

Esto es similar a establecer "ALIEN_INSTALL_TYPE" a "system" (ver abajo), excepto que sí permite a los Aliens que incluyan su paquete alienizado dentro del tarball del paquete de

CPAN.

Algunos Aliens no se instalarán correctamente al pri

ncipio, pero cuando den un error, puedes instalar el
paquete del sistema e intentar reinstalar el Alien.
"ALIEN_INSTALL_TY
PE"
Establecer "ALIEN_INSTALL_TYPE" a "system" es similar a establecer "ALIEN_INSTALL_NETWORK" a falso, excepto que los paquetes alienizados incluidos también serán rechazados. Esta variable de entorno está realmente destinada al uso por parte de proveedores de sistemas operativo
s que empaquetan Aliens, o para pruebas de desarrollo de Alien (en CI, por ejemplo). Para aquellos que qu
ieran restringir cómo se instalan los Aliens, esta podría ser la herramienta adecuada a la que recurrir.

Ten en cuenta que esto es definitivamente un esfuerzo de buena fe. Si el autor del Alien comete un error o es malicioso, podría anular estas variables de entorno dentro del "Makefile.PL", así que aún necesitas auditar cualquier softwar

e para asegurarte de que no obt
enga código fuente de internet.

Plugins relacionados con la

seguridad

Hay una serie de plugins que dan al usuario o instalador control sobre cómo se comporta Alien::Build, y pueden ser útiles para seguridad

básica.
Alien::Build::Plugin::Fetch::
Prompt
Este plugin solicitará confirmación antes de obtener cualquier archivo remoto. Esto solo funciona realmente cuando estás instalando Aliens de forma
interactiva.
Alien::Build::Plugin::Fetch::
HostAllowList
Este plugin solo permitirá obtener archivos de hosts que estén en una lista de
permitidos.
Alien::Build::Plugin::Fetch::
HostBlockList
Este plugin no permitirá obtener archivos de hosts que estén en una lista de
bloqueados.
Alien::Build::Plugin::Fetch::
Rewrite
Este plugin puede reescribir las URLs obtenidas antes de que se realice la solicitud. Esto puede ser útil si tienes un espejo local de ciertas fuentes que quieres usar en lugar de obtenerlas del internet en
general.
Alien::Build::Plugin::Probe::
Override
Este plugin puede sobrescribir el "ALIEN_INSTALL_TYPE" de forma independiente para cada perl-Alien. Esto puede ser útil si deseas instalar algunos Aliens en modo "share", pero generalmente quieres imponer el modo "sys
t
em
".

configuración

local

Puedes configurar la forma en que se instalan los Aliens basados en Alien::Build con el archivo de configuración local "~/.alienbuild/rc.pl". Consu

lta Alien::
Build::rc para
más detalles.
