al_stop_audio_recorder(3) Manual de funciones de biblioteca al_stop_audio_recorder(3)

NOMBRE

al_stop_audio_recorder - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
void al_stop_audio_recorder(ALLEGRO_AUDIO_RECORDER *r)

DESCRIPCIÓN

Detiene la captura de datos de audio. Tenga en cuenta que el grabador de audio todavía está activo y consumiendo recursos, por lo que si ha terminado de grabar, debe destruirlo con al_destroy_audio_recorder(3).

Es posible que reciba algunos eventos más después de llamar a esta función mientras el dispositivo vacía el búfer.

Si reinicia el grabador, comenzará a grabar al principio del siguiente búfer de fragmento.

DESDE

5.1.1

[API inestable]: Es posible que la API necesite un ligero rediseño.
