NOTA: Para el nuevo desarrollo de Aliens, considere usar Alien::Build y alienfile. Al igual que Alien::Base::ModuleBuild, funcionan con Alien::Base. A diferencia de Alien::Base::ModuleBuild, son más fáciles de personalizar y manejan mejor una serie de casos especiales. Para un buen punto de partida, consulte Alien::Build::Manual::AlienAuthor. Aunque el equipo de Alien-Base / Alien-Build continuará manteniendo este módulo (seguiremos corrigiendo errores cuando sea apropiado), no estamos añadiendo ninguna nueva característica a este

módulo.

Una lista de propiedades y métodos adicionales proporcionados por Alien::Base::ModuleBuild más allá de los contenidos en Module::Build::API. Tenga en cuenta que todos los nombres de propiedades y métodos tienen el prefijo "alien_" para evitar futuras colisiones con los incorporados de Module::

Build.

Tenga en cuenta que frecuentemente los usuarios tienen una buena razón para haber establecido variables de entorno, y no debería sobrescribirlas sin una buena razón. Un ejemplo de una buena justificación sería si un proyecto tiene un Makefile que interactúa mal con variables de entorno comunes.   ...

    foo => '$ENV{FOO}||"my preferred value if not already set"'
  },
  alien_env => {
    FOO => '%{foo}',
  },
  ...
)
; ...

Añade valores extra al archivo "config.site" cuando se usa

autoconf.

Cuando se detecta <autoconf>, se crea un archivo "config.site" con valores apropiados para compilar software que pueda vincularse contra el Perl con el que está compilando. Esto es importante en algunas plataformas, por ejemplo sistemas de 64 bits donde los compiladores generan código de 32 bits por defecto. También puede añadir valores al archivo "config.site" usando esta

directiva.

Para valores que ya son proporcionados por "Alien::Base::ModuleBuild", su valor se añadirá después del valor existente. Para valores que no son proporcionados, simplemente usará su valor por sí

Por ejemplo, si necesitaba añadir una definición a CFLAGS, podría hacer algo como

  ...

    CFLAGS => '-DFOO=1',
    # BAR usualmente no.
    BAR => 'baz',
  },
  ...

; ...

Y el valor real para CFLAGS en el "config.site" podría tener valores como
