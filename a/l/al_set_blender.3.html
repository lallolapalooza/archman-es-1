al_set_blender(3)

Paquete: allegro

Licencias: Zlib, BSD-3-Clause, OFL-1.1, LicenseRef-Custom

al_set_blender(3) Manual de funciones de biblioteca al_set_blender(3)

NOMBRE

al_set_blender - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_set_blender(int op, int src, int dst)

DESCRIPCIÓN

Establece la función a usar para la mezcla (blending) para el hilo actual.

La mezcla significa que los colores fuente y destino se combinan en las operaciones de dibujo.

Supongamos que el color fuente (por ejemplo, el color de un rectángulo a dibujar, o el píxel de un mapa de bits a dibujar) se da como sus componentes rojo/verde/azul/alfa (si el mapa de bits no tiene alfa, siempre se asume que es completamente opaco, por lo que 255 para 8 bits o 1.0 para punto flotante): s = s.r, s.g, s.b, s.a. Y este color se dibuja a un destino, que ya tiene un color: d = d.r, d.g, d.b, d.a.

La fórmula conceptual utilizada por Allegro para dibujar cualquier píxel depende entonces del parámetro op:

•
ALLEGRO_ADD
   r = d.r * df.r + s.r * sf.r
   g = d.g * df.g + s.g * sf.g
   b = d.b * df.b + s.b * sf.b
   a = d.a * df.a + s.a * sf.a
•
ALLEGRO_DEST_MINUS_SRC
   r = d.r * df.r - s.r * sf.r
   g = d.g * df.g - s.g * sf.g
   b = d.b * df.b - s.b * sf.b
   a = d.a * df.a - s.a * sf.a
•
ALLEGRO_SRC_MINUS_DEST
   r = s.r * sf.r - d.r * df.r
   g = s.g * sf.g - d.g * df.g
   b = s.b * sf.b - d.b * df.b
   a = s.a * sf.a - d.a * df.a

Los valores válidos para los factores sf y df pasados a esta función son los siguientes, donde s es el color fuente, d el color destino y cc el color establecido con al_set_blend_color(3) (blanco por defecto)

•
ALLEGRO_ZERO
   f = 0, 0, 0, 0
•
ALLEGRO_ONE
   f = 1, 1, 1, 1
•
ALLEGRO_ALPHA
   f = s.a, s.a, s.a, s.a
•
ALLEGRO_INVERSE_ALPHA
   f = 1 - s.a, 1 - s.a, 1 - s.a, 1 - s.a
•
ALLEGRO_SRC_COLOR (desde: 5.0.10, 5.1.0)
   f = s.r, s.g, s.b, s.a
•
ALLEGRO_DEST_COLOR (desde: 5.0.10, 5.1.8)
   f = d.r, d.g, d.b, d.a
•
ALLEGRO_INVERSE_SRC_COLOR (desde: 5.0.10, 5.1.0)
   f = 1 - s.r, 1 - s.g, 1 - s.b, 1 - s.a
•
ALLEGRO_INVERSE_DEST_COLOR (desde: 5.0.10, 5.1.8)
   f = 1 - d.r, 1 - d.g, 1 - d.b, 1 - d.a
•
ALLEGRO_CONST_COLOR (desde: 5.1.12, no soportado en OpenGLES 1.0)
   f = cc.r, cc.g, cc.b, cc.a
•
ALLEGRO_INVERSE_CONST_COLOR (desde: 5.1.12, no soportado en OpenGLES 1.0)
   f = 1 - cc.r, 1 - cc.g, 1 - cc.b, 1 - cc.a

Ejemplos de mezcla:

Así, por ejemplo, para restaurar el valor predeterminado de usar mezcla alfa pre-multiplicada, usarías:

al_set_blender(ALLEGRO_ADD, ALLEGRO_ONE, ALLEGRO_INVERSE_ALPHA);

Como fórmula:

r = d.r * (1 - s.a) + s.r * 1
g = d.g * (1 - s.a) + s.g * 1
b = d.b * (1 - s.a) + s.b * 1
a = d.a * (1 - s.a) + s.a * 1

Si estás usando alfa no pre-multiplicada, podrías usar

al_set_blender(ALLEGRO_ADD, ALLEGRO_ALPHA, ALLEGRO_INVERSE_ALPHA);

La mezcla aditiva se lograría con

al_set_blender(ALLEGRO_ADD, ALLEGRO_ONE, ALLEGRO_ONE);

Copiando la fuente al destino (incluyendo alfa) sin modificar

al_set_blender(ALLEGRO_ADD, ALLEGRO_ONE, ALLEGRO_ZERO);

Multiplicando los componentes fuente y destino

al_set_blender(ALLEGRO_ADD, ALLEGRO_DEST_COLOR, ALLEGRO_ZERO)

Tiñendo la fuente (como al_draw_tinted_bitmap(3))

al_set_blender(ALLEGRO_ADD, ALLEGRO_CONST_COLOR, ALLEGRO_ONE);
al_set_blend_color(al_map_rgb(0, 96, 255)); /* bonito azul Chrysler */

Promediando píxeles fuente y destino

al_set_blender(ALLEGRO_ADD, ALLEGRO_CONST_COLOR, ALLEGRO_CONST_COLOR);
al_set_blend_color(al_map_rgba_f(0.5, 0.5, 0.5, 0.5));

Como fórmula:

r = d.r * 0 + s.r * d.r
g = d.g * 0 + s.g * d.g
b = d.b * 0 + s.b * d.b
a = d.a * 0 + s.a * d.a
