al_grab_font_from_bitmap(3) Manual de funciones de la biblioteca al_grab_font_from_bitmap(3)

NOMBRE

al_grab_font_from_bitmap - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_font.h>
ALLEGRO_FONT *al_grab_font_from_bitmap(ALLEGRO_BITMAP *bmp,
   int ranges_n, const int ranges[])

DESCRIPCIÓN

Crea una nueva fuente a partir de un bitmap de Allegro. Puedes eliminar el bitmap después de que la función regrese, ya que la fuente contendrá una copia para sí misma.

Parámetros:

•
bmp: El bitmap con los glifos dibujados en él
•
n: Número de rangos unicode en el bitmap.
•
ranges: `n' pares de puntos unicode de inicio y fin para mapear glifos para cada rango.

El formato del bitmap es como en el siguiente ejemplo, que contiene tres glifos para 1, 2 y 3.

.............
. 1 .222.333.
. 1 .  2.  3.
. 1 .222.333.
. 1 .2  .  3.
. 1 .222.333.
.............

En la ilustración anterior, el punto representa píxeles que tienen el color de fondo. Se determina por el color del píxel superior izquierdo del bitmap. Debería haber un borde de al menos 1 píxel con este color hasta el borde del bitmap y entre todos los glifos.

Cada glifo está dentro de un rectángulo de píxeles que no contienen el color de fondo. La altura de todos los rectángulos de glifos debe ser la misma, pero el ancho puede variar.

La ubicación de los rectángulos no importa, excepto que los glifos se escanean de izquierda a derecha y de arriba a abajo para que coincidan con los puntos de código unicode especificados.

Los glifos simplemente se dibujarán usando al_draw_bitmap(3), por lo que normalmente querrás que los rectángulos estén llenos de transparencia total y los glifos se dibujen en blanco opaco.

Ejemplos:

int ranges[] = {32, 126};
al_grab_font_from_bitmap(bitmap, 1, ranges)
int ranges[] = {
    0x0020, 0x007F,  /* ASCII */
    0x00A1, 0x00FF,  /* Latin 1 */
    0x0100, 0x017F,  /* Extended-A */
    0x20AC, 0x20AC}; /* Euro */
al_grab_font_from_bitmap(bitmap, 4, ranges)

El primer ejemplo capturará glifos para los 95 caracteres ASCII imprimibles estándar, comenzando con el carácter de espacio (32) y terminando con el carácter tilde (126). El segundo ejemplo asignará los primeros 96 glifos encontrados en el bitmap al rango ASCII, los siguientes 95 glifos a Latin 1, los siguientes 128 glifos a Extended-A y el último glifo al carácter Euro. (Estos son solo los caracteres que se encuentran en la fuente de Allegro 4).
