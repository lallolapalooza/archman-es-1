ALLEGRO_USER_EVENT(3)

Paquete: allegro

ALLEGRO_USER_EVENT(3) Manual de funciones de la biblioteca ALLEGRO_USER_EVENT(3)

NOMBRE

ALLEGRO_USER_EVENT - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef struct ALLEGRO_USER_EVENT ALLEGRO_USER_EVENT;

DESCRIPCIÓN

Una estructura de evento que puede ser emitida por fuentes de eventos de usuario. Estos son los campos públicos:

•
ALLEGRO_EVENT_SOURCE *source;
•
intptr_t data1;
•
intptr_t data2;
•
intptr_t data3;
•
intptr_t data4;

Como todos los demás tipos de eventos, esta estructura es parte de la unión ALLEGRO_EVENT. Para acceder a los campos en una variable ALLEGRO_EVENT ev, usarías:

•
ev.user.source
•
ev.user.data1
•
ev.user.data2
•
ev.user.data3
•
ev.user.data4

Para crear un nuevo evento de usuario harías esto:

ALLEGRO_EVENT_SOURCE my_event_source;
ALLEGRO_EVENT my_event;
float some_var;
al_init_user_event_source(&my_event_source);
my_event.user.type = ALLEGRO_GET_EVENT_TYPE('M','I','N','E');
my_event.user.data1 = 1;
my_event.user.data2 = &some_var;
al_emit_user_event(&my_event_source, &my_event, NULL);

Los identificadores de tipo de evento para eventos de usuario son asignados por el usuario. Por favor, consulta la documentación de ALLEGRO_GET_EVENT_TYPE(3) para las reglas que debes seguir al asignar identificadores.

VER TAMBIÉN

al_emit_user_event(3), ALLEGRO_GET_EVENT_TYPE(3), al_init_user_event_source(3)
