NOMBRE

al_ustr_truncate - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
bool al_ustr_truncate(ALLEGRO_USTR *us, int start_pos)

DESCRIPCIÓN

Trunca una porción de una cadena desde el desplazamiento de bytes start_pos en adelante. start_pos puede estar más allá del final de la cadena (no tiene efecto) pero no puede ser menor que 0.

Devuelve true si tiene éxito, false si ocurre un error.
