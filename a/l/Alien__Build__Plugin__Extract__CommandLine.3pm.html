Alien__Build__Plugin__Extract__CommandLine(3pm)

Alien::Build::Plugin::Extract::CommandLine(3) Documentación de Perl aportada por el usuario Alien::Build::Plugin::Extract::CommandLine(3)

NOMBRE

Alien::Build::Plugin::Extract::CommandLine - Plugin para extraer un archivo usando herramientas de línea de comandos

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Extract::CommandLine' => (
  format => 'tar.gz',
);

DESCRIPCIÓN

Nota: en la mayoría de los casos querrás usar Alien::Build::Plugin::Extract::Negotiate en su lugar. Elige el plugin de extracción apropiado según tu plataforma y entorno. En algunos casos, puede que necesites usar este plugin directamente en su lugar.

Este plugin extrae de un archivo en varios formatos usando herramientas de línea de comandos.

PROPIEDADES

formato

Da una pista sobre el formato esperado.

comando_gzip

El comando "gzip", si está disponible. "undef" si no está disponible.

comando_bzip2

El comando "bzip2", si está disponible. "undef" si no está disponible.

comando_xz

El comando "xz", si está disponible. "undef" si no está disponible.

comando_tar

El comando "tar", si está disponible. "undef" si no está disponible.

comando_unzip

El comando "unzip", si está disponible. "undef" si no está disponible.

MÉTODOS

maneja

Alien::Build::Plugin::Extract::CommandLine->handles($ext);
$plugin->handles($ext);

Devuelve verdadero si el plugin puede manejar el archivo del formato dado.

disponible

Alien::Build::Plugin::Extract::CommandLine->available($ext);

Devuelve verdadero si el plugin está disponible para extraer sin instalar nada nuevo.

VER TAMBIÉN
