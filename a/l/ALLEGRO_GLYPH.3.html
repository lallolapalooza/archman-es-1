ALLEGRO_GLYPH(3) Manual de funciones de la biblioteca ALLEGRO_GLYPH(3)

NOMBRE

ALLEGRO_GLYPH - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_font.h>
typedef struct ALLEGRO_GLYPH ALLEGRO_GLYPH;

DESCRIPCIÓN

Una estructura que contiene las propiedades de un carácter en una fuente.

typedef struct ALLEGRO_GLYPH {
   ALLEGRO_BITMAP *bitmap;   // el mapa de bits en el que se encuentra el carácter
   int x;                    // la posición x del glifo en el mapa de bits
   int y;                    // la posición y del glifo en el mapa de bits
   int w;                    // el ancho del glifo en píxeles
   int h;                    // la altura del glifo en píxeles
   int kerning;              // píxeles de interletraje (ver más abajo)
   int offset_x;             // desplazamiento x para dibujar el glifo
   int offset_y;             // desplazamiento y para dibujar el glifo
   int advance;              // número de píxeles para avanzar después de este carácter
} ALLEGRO_GLYPH;

bitmap puede ser un sub-mapa de bits en el caso de fuentes de color. Bitmap también puede ser NULL, en cuyo caso no se debe dibujar nada (a veces es cierto para caracteres de espacio en blanco en fuentes TTF).

kerning se debe agregar a la posición x a la que se dibuja si desea que su texto tenga interletraje y depende de los puntos de código con los que se llamó a al_get_glyph(3).

Los glifos están empaquetados de forma ajustada en el mapa de bits, por lo que necesita agregar offset_x y offset_y a su posición de dibujo para que el texto se vea bien.

advance es el número de píxeles a agregar a su posición x para avanzar al siguiente carácter en una cadena e incluye el interletraje.

DESDE

5.2.1

[API inestable]: Esta API es nueva y está sujeta a refinamientos.
