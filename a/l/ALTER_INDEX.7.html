DESCRIPCIÓ

N

ALTER INDEX cambia la definición de un índice existente. Hay varios subformas descritas a continuación. Tenga en cuenta que el nivel de bloqueo requerido puede diferir para cada subforma. Se mantiene un bloqueo ACCESS EXCLUSIVE salvo que se indique explícitamente lo contrario. Cuando se listan varios subcomandos, el bloqueo mantenido será el más estricto requerido por cualquiera de los

subcomandos.

RENAM

E
La forma RENAME cambia el nombre del índice. Si el índice está asociado con una restricción de tabla (ya sea UNIQUE, PRIMARY KEY o EXCLUDE), la restricción también se renombra. No hay ningún efecto sobre los datos almacenados.

Renombrar un índice a

dquiere un bloqueo SH
ARE UPDATE EXCLUSIVE.

SET

TABLESPACE
Esta forma cambia el tablespace del índice al tablespace especificado y mueve el/los archivo(s) de datos asociados con el índice al nuevo tablespace. Para cambiar el tablespace de un índice, debe ser el propietario del índice y tener el privilegio CREATE en el nuevo tablespace. Todos los índices en la base de datos actual en un tablespace pueden moverse usando la forma ALL IN TABLESPACE, la cual bloqueará todos los índices a mover y luego moverá cada uno. Esta forma también soporta OWNED BY, la cual solo moverá los índices propiedad de los roles especificados. Si se especifica la opción NOWAIT, el comando fallará si no es capaz de adquirir inmediatamente todos los bloqueos requeridos. Tenga en cuenta que los catálogos del sistema no serán movidos por este comando, use ALTER DATABASE o invocaciones explícitas de ALTER INDEX en su lugar si lo desea. Véase también CREATE TABL
ESPACE.

ATTACH PARTITION index_nam

e
Hace que el índice nombrado (posiblemente calificado por esquema) se adjunte al índice alterado. El índice nombrado debe estar en una partición de la tabla que contiene el índice que se está alterando, y tener una definición equivalente. Un índice adjunto no puede ser eliminado por sí mismo, y será eliminado automáticamente si su índice padre es
eliminado.

DEPENDS ON EXTENSION extension_name
NO DEPENDS ON EXTENSION extension_nam

e
Esta forma marca el índice como dependiente de la extensión, o ya no dependiente de esa extensión si se especifica NO. Un índice que está marcado como dependiente de una extensión es eliminado automáticamente cuando la extensión es
eliminada.

SET ( storage_parameter [= value] [, ... ]

)
Esta forma cambia uno o más parámetros de almacenamiento específicos del método del índice. Véase CREATE INDEX para detalles sobre los parámetros disponibles. Tenga en cuenta que el contenido del índice no será modificado inmediatamente por este comando; dependiendo del parámetro, podría necesitar reconstruir el índice con REINDEX para obtener los efectos
deseados.

RESET ( storage_parameter [, ... ]

)
Esta forma restablece uno o más parámetros de almacenamiento específicos del método del índice a sus valores por defecto. Como con SET, podría ser necesario un REINDEX para actualizar el índice
completamente.

ALTER [ COLUMN ] column_number SET STATISTICS intege

r
Esta forma establece el objetivo de recopilación de estadísticas por columna para operaciones ANALYZE subsecuentes, aunque solo puede usarse en columnas de índice que están definidas como una expresión. Dado que las expresiones carecen de un nombre único, nos referimos a ellas usando el número ordinal de la columna del índice. El objetivo puede establecerse en el rang
o de 0 a 10000; alternativamente, establezca en -1 para revertir al objetivo de estadísticas por defecto del sistema (default_statistic
s_target). Para más información sobre el uso de estadísticas por el planificador de consultas de PostgreSQL, refiérase a la Sección 14.2.

NOTA

S

Estas operaciones también son posibles usando ALTER TABLE. ALTER INDEX es de hecho solo un alias para las formas de ALTER TABLE que se aplican a

índices.

Anteriormente existía una variante ALTER INDEX OWNER, pero ahora se ignora (con una advertencia). Un índice no puede tener un propietario diferente al de su tabla. Cambiar el propietario de la tabla cambia automáticamente el índice

también.

No se permite cambiar ning

una parte de un índice de
catálogo del sistema.
