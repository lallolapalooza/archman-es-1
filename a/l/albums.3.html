int LIBMTP_Create_New_Album (LIBMTP_mtpdevice_t * device, LIBMTP_album_t *const metadata)

Esta rutina crea un nuevo álbum basado en los metadatos proporcionados. Si el campo de pistas de los metadatos contiene una lista de pistas, estas pistas se añadirán al álbum.

Parámetros

device un puntero al dispositivo en el que crear el nuevo álbum.
metadata los metadatos para el nuevo álbum. Si la función sale con éxito, el campo album_id de esta estructura contendrá el nuevo ID del álbum.
  • metadata->parent_id debe establecerse en el padre (por ejemplo, carpeta) para almacenar esta pista. Dado que algunos dispositivos son un poco quisquillosos con dónde se colocan los archivos, se elegirá una carpeta predeterminada si libmtp ha detectado una para el tipo de archivo actual y este parámetro se establece en 0. Si esto es 0 y no se encuentra ninguna carpeta predeterminada, el archivo se almacenará en la carpeta raíz.
  • metadata->storage_id debe establecerse en el almacenamiento deseado (por ejemplo, tarjeta de memoria o lo que sea que presente su dispositivo) para almacenar esta pista. Establecer esto en 0 almacenará la pista en el almacenamiento principal.

Devuelve

0 en caso de éxito, cualquier otro valor significa fallo.

int LIBMTP_Set_Album_Name (LIBMTP_mtpdevice_t * device, LIBMTP_album_t * album, const char * newname)

Esta función renombra un solo álbum. Esto simplemente significa que la propiedad PTP_OPC_ObjectFileName se actualiza, si esto es compatible con el dispositivo. El nombre de archivo del álbum debería terminar nominalmente con una extensión como '.alb'.

NOTA: si desea cambiar los metadatos que muestra el dispositivo sobre una lista de reproducción, ¡*no* debe usar esta función, use LIBMTP_Update_Album()! en su lugar!

Parámetros

device un puntero al dispositivo que contiene el archivo.
album los metadatos del álbum a renombrar. En caso de éxito, el miembro name se actualiza. Tenga en cuenta que este nombre puede ser diferente de newname dependiendo de las restricciones del dispositivo.
newname el nuevo nombre para este objeto.

Devuelve

0 en caso de éxito, cualquier otro valor significa fallo.

int LIBMTP_Update_Album (LIBMTP_mtpdevice_t * device, LIBMTP_album_t const *const metadata)

Esta rutina actualiza un álbum basándose en los metadatos proporcionados. Si el campo tracks de los metadatos contiene una lista de pistas, estas pistas se añadirán al álbum en lugar de las ya presentes, es decir, la lista de pistas anterior será eliminada.

Parámetros

device un puntero al dispositivo en el que se creará el nuevo álbum.
metadata los metadatos del álbum a actualizar. tenga en cuenta que el campo album_id debe contener el ID de álbum correspondiente.

Devuelve

0 en caso de éxito, cualquier otro valor indica fallo.
