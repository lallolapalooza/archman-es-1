al_draw_glyph(3) Manual de funciones de biblioteca al_draw_glyph(3)

NOMBRE

al_draw_glyph - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_font.h>
void al_draw_glyph(const ALLEGRO_FONT *f, ALLEGRO_COLOR color, float x, float y,
   int codepoint)

DESCRIPCIÓN

Dibuja el glifo que corresponde con el punto de código en el color dado usando la fuente dada. Si la fuente no tiene dicho glifo, no se dibujará nada.

Para dibujar una cadena de texto de izquierda a derecha, necesitará usar al_get_glyph_advance(3) para determinar la posición de cada glifo. Para dibujar cadenas de texto en otras direcciones, como de arriba a abajo, use al_get_glyph_dimensions(3) para determinar el tamaño y la posición de cada glifo.

Si tiene que dibujar muchos glifos al mismo tiempo, use al_hold_bitmap_drawing(3) con true como parámetro, antes de dibujar los glifos, y luego llame a al_hold_bitmap_drawing(3) nuevamente con false como parámetro cuando haya terminado de dibujar los glifos para mejorar aún más el rendimiento.

DESDE

5.1.12

VER TAMBIÉN

al_get_glyph_width(3), al_get_glyph_dimensions(3), al_get_glyph_advance(3).
