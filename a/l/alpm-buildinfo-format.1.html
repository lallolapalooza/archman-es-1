NOMBRE

alpm-buildinfo-format - Analiza un archivo BUILDINFO y lo muestra en un formato diferente

SINOPSIS

alpm-buildinfo format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Analiza un archivo BUILDINFO y lo muestra en un formato diferente

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema BUILDINFO a utilizar.

Si no se proporciona una versión del esquema, se deducirá del propio archivo.

-o, --output-format <FORMATO_SALIDA> [por defecto: json]
Proporciona el formato de salida

Valores posibles:

•
json: El formato de salida JSON
-p, --pretty
Imprime la salida de forma legible
-h, --help
Imprime la ayuda (ver un resumen con '-h')
[ARCHIVO]
Proporciona el archivo a leer
