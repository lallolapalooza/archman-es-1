NOMBRE

al_show_native_message_box - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_native_dialog.h>
int al_show_native_message_box(ALLEGRO_DISPLAY *display,
   char const *title, char const *heading, char const *text,
   char const *buttons, int flags)

DESCRIPCIÓN

Muestra un cuadro de mensaje nativo de GUI. Esto se puede usar, por ejemplo, para mostrar un mensaje de error si falla la creación de una pantalla inicial. La pantalla puede ser NULL, de lo contrario, la pantalla dada se trata como la ventana padre si es posible.

El cuadro de mensaje tendrá un único botón "Aceptar" y usará el estilo que normalmente tienen los cuadros de diálogo informativos en el sistema nativo. Si el parámetro buttons no es NULL, puede especificar el texto del botón en una cadena, con los botones separados por una barra vertical (|).

Nota: El parámetro buttons no está implementado actualmente en Windows.

Las banderas disponibles son:

ALLEGRO_MESSAGEBOX_WARN
El mensaje es una advertencia. Esto puede causar un icono diferente (u otros efectos).
ALLEGRO_MESSAGEBOX_ERROR
El mensaje es un error.
ALLEGRO_MESSAGEBOX_QUESTION
El mensaje es una pregunta.
ALLEGRO_MESSAGEBOX_OK_CANCEL
Muestra un botón de cancelar junto al botón "Aceptar". Se ignora si buttons no es NULL.
ALLEGRO_MESSAGEBOX_YES_NO
Muestra los botones Sí/No en lugar del botón "Aceptar". Se ignora si buttons no es NULL.

al_show_native_message_box(3) se puede llamar sin que Allegro esté instalado. Esto es útil para informar un error durante la inicialización del propio Allegro.

Devuelve:

•
0 si se cerró la ventana del diálogo sin activar un botón.
•
1 si se presionó el botón Aceptar o Sí.
•
2 si se presionó el botón Cancelar o No.

Si buttons no es NULL, se devuelve el número del botón presionado, comenzando desde 1.

Todos los parámetros restantes no deben ser NULL.

Si no se pudo crear un cuadro de mensaje, devuelve 0, como si la ventana se hubiera cerrado sin activar un botón.

Ejemplo:

int button = al_show_native_message_box(
  display,
  "Advertencia",
  "¿Estás seguro?",
  "Si haces clic en sí, confirmas que "
  ""Sí" " es tu respuesta a la consulta que has "
  "generado con la acción que tomaste para abrir este "
  "cuadro de mensaje.",
  NULL,
  ALLEGRO_MESSAGEBOX_YES_NO
);
