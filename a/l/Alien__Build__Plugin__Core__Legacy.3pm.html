NOMBRE

Alien::Build::Plugin::Core::Legacy - Plugin principal de Alien::Build para mantener la compatibilidad con la interfaz de Alien::Base heredada

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
# ya cargado

DESCRIPCIÓN

Este plugin proporciona cierta compatibilidad con las interfaces heredadas de Alien::Base::ModuleBuild.

VER TAMBIÉN

Alien::Build, Alien::Base::ModuleBuild
