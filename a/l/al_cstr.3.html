al_cstr(3) Manual de funciones de la biblioteca al_cstr(3)

NOMBRE

al_cstr - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
const char *al_cstr(const ALLEGRO_USTR *us)

DESCRIPCIÓN

Obtiene un puntero char * a los datos de una cadena. Este puntero solo será válido mientras el objeto ALLEGRO_USTR no se modifique ni se destruya. El puntero puede pasarse a funciones que esperan cadenas de estilo C, con las siguientes advertencias:

•
Se permite que ALLEGRO_USTR contenga bytes NUL ('\0') incrustados. Esto significa que al_ustr_size(u) y strlen(al_cstr(u)) pueden no coincidir.
•
Un ALLEGRO_USTR puede crearse de tal manera que no termine en NUL. Una cadena que se asigna dinámicamente siempre terminará en NUL, pero una cadena que hace referencia a la mitad de otra cadena o región de memoria *no* terminará en NUL.
•
Si el ALLEGRO_USTR hace referencia a otra cadena, la cadena C devuelta apuntará a la cadena referenciada. De nuevo, no se agregará un terminador NUL a la cadena referenciada.

VER TAMBIÉN

al_ustr_to_buffer(3), al_cstr_dup(3)
