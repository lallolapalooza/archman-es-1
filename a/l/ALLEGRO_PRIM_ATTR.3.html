ALLEGRO_PRIM_ATTR(3) Manual de Funciones de Biblioteca ALLEGRO_PRIM_ATTR(3)

NOMBRE

ALLEGRO_PRIM_ATTR - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
typedef enum ALLEGRO_PRIM_ATTR

DESCRIPCIÓN

Enumera los tipos de atributos de vértice que puede tener un vértice personalizado.

•
ALLEGRO_PRIM_POSITION - Información de posición, solo puede almacenarse en ALLEGRO_PRIM_SHORT_2, ALLEGRO_PRIM_FLOAT_2 y ALLEGRO_PRIM_FLOAT_3.
•
ALLEGRO_PRIM_COLOR_ATTR - Información de color, almacenada en un ALLEGRO_COLOR(3). Se ignora el campo de almacenamiento de ALLEGRO_VERTEX_ELEMENT.
•
ALLEGRO_PRIM_TEX_COORD - Información de coordenada de textura, solo puede almacenarse en ALLEGRO_PRIM_FLOAT_2 y ALLEGRO_PRIM_SHORT_2. Estas coordenadas se normalizan por el ancho y alto de la textura, lo que significa que la esquina inferior derecha tiene coordenadas de textura (1, 1).
•
ALLEGRO_PRIM_TEX_COORD_PIXEL - Información de coordenada de textura, solo puede almacenarse en ALLEGRO_PRIM_FLOAT_2 y ALLEGRO_PRIM_SHORT_2. Estas coordenadas se miden en píxeles.
•
ALLEGRO_PRIM_USER_ATTR - Un atributo especificado por el usuario. Puede utilizar cualquier almacenamiento para este atributo. Puede tener como máximo ALLEGRO_PRIM_MAX_USER_ATTR (actualmente 10) de estos que puede especificar agregando un índice al valor de ALLEGRO_PRIM_USER_ATTR, por ejemplo, el primer atributo de usuario es ALLEGRO_PRIM_USER_ATTR + 0, el segundo es ALLEGRO_PRIM_USER_ATTR + 1 y así sucesivamente.

Para acceder a estos atributos personalizados desde los shaders GLSL, necesita declarar atributos que sigan esta nomenclatura: al_user_attr_# donde # es el índice del atributo.

Por ejemplo, para tener una posición y un vector normal para cada vértice, podría declararlo así:

ALLEGRO_VERTEX_ELEMENT elements[3] = {
    {ALLEGRO_PRIM_POSITION, ALLEGRO_PRIM_FLOAT_3, 0},
    {ALLEGRO_PRIM_USER_ATTR + 0, ALLEGRO_PRIM_FLOAT_3, 12},
    {0, 0, 0}};

Y luego, en su shader de vértices, acceda a él de esta manera:

attribute vec3 al_pos; // ALLEGRO_PRIM_POSITION
attribute vec3 al_user_attr_0; // ALLEGRO_PRIM_USER_ATTR + 0
varying float light;
const vec3 light_direction = vec3(0, 0, 1);
void main() {
    light = dot(al_user_attr_0, light_direction);
    gl_Position = al_pos;
}

Para acceder a estos atributos personalizados desde HLSL, necesita declarar un parámetro con las siguientes semánticas: TEXCOORD{# + 2} donde # es el índice del atributo. Por ejemplo, el primer atributo se puede acceder a través de TEXCOORD2, el segundo a través de TEXCOORD3 y así sucesivamente.

Desde: 5.1.6
