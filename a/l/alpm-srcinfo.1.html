alpm-srcinfo(1) Manual de Comandos Generales alpm-srcinfo(1)

NOMBRE

alpm-srcinfo - Biblioteca y herramienta de línea de comandos para la especificación y el análisis de archivos .SRCINFO de ALPM

SINOPSIS

alpm-srcinfo [-h|--help] [-V|--version] <subcomandos>

DESCRIPCIÓN

Biblioteca y herramienta de línea de comandos para la especificación y el análisis de archivos .SRCINFO de ALPM.

OPCIONES

-h, --help
Imprimir ayuda
-V, --version
Imprimir versión

SUBCOMANDOS

alpm-srcinfo-create(1)
Crear un archivo SRCINFO a partir de un archivo PKGBUILD en una ruta dada.
alpm-srcinfo-validate(1)
Validar un archivo SRCINFO desde una ruta o `stdin`.
alpm-srcinfo-format(1)
Formatear un archivo SRCINFO desde una ruta o `stdin`.
alpm-srcinfo-format-packages(1)
Formatear los paquetes de un archivo SRCINFO desde una ruta o `stdin`.
alpm-srcinfo-help(1)
Imprimir este mensaje o la ayuda del/de los subcomando(s) dado(s).

VERSIÓN

v0.6.0

AUTORES
