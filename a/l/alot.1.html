NOMBRE

alot - MUA de terminal que utiliza correo notmuch

SINOPSIS

alot [opciones ...] [subcomando]

DESCRIPCIÓN

Alot es un agente de usuario de correo basado en terminal para el sistema de correo notmuch. Presenta una interfaz modular y controlada por línea de comandos para proporcionar una experiencia MUA completa como alternativa al modo Emacs que se incluye con notmuch.

OPCIONES

-r, --solo-lectura
abrir la base de datos notmuch en modo de solo lectura
-c NOMBRE_ARCHIVO, --configuracion=NOMBRE_ARCHIVO
archivo de configuración (por defecto: ~/.config/alot/config)
-n NOMBRE_ARCHIVO, --configuracion-notmuch= NOMBRE_ARCHIVO
archivo de configuración de notmuch (por defecto: ver notmuch-config(1))
-C COLORES, --modo-color=COLORES
número de colores a usar en la terminal; debe ser 1, 16 o 256 (por defecto: opción de configuración modocolor o 256)
-p RUTA, --ruta-indice-correo=RUTA
ruta del índice de notmuch
-d NIVEL, --nivel-depuracion=NIVEL
nivel de depuración; debe ser uno de debug, info, warning o error (por defecto: info)
-l NOMBRE_ARCHIVO, --archivo-log=NOMBRE_ARCHIVO
archivo de log (por defecto: /dev/null)
-h, --ayuda
mostrar ayuda y salir
-v, --version
mostrar información de la versión y salir

COMANDOS

buscar
iniciar en un búfer de búsqueda usando la cadena de consulta proporcionada como parámetro (ver notmuch-search-terms(7))
escribir
escribir un nuevo mensaje
listabufers
iniciar solo con un búfer de lista de búferes abierto
listatags
iniciar solo con un búfer de lista de etiquetas abierto
consultasnombradas
iniciar con la lista de consultas nombradas
pyshell
iniciar el intérprete interactivo de python dentro de alot

USO

Se pueden usar las teclas de flecha, re-pág/av-pág, j, k y Espacio para mover el foco. Escape cancela los indicadores y Enter selecciona. Presiona : en cualquier momento y escribe comandos en el indicador.

La interfaz muestra un búfer a la vez, puedes usar Tab y Shift-Tab para cambiar entre ellos, cerrar el búfer actual con d y listarlos todos con ;.

El tipo de búfer o modo (mostrado en la parte inferior izquierda) determina qué comandos del indicador están disponibles. La información de uso sobre cualquier comando se puede listar escribiendo ayuda TU_COMANDO en el indicador. Los atajos de teclado para el modo actual se muestran al presionar ?.

SEÑALES UNIX

SIGUSR1
Actualiza el búfer actual.
SIGINT
Cierra la interfaz de usuario.
