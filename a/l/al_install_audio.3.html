al_install_audio(3) Manual de funciones de biblioteca al_install_audio(3)

NOMBRE

al_install_audio - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
bool al_install_audio(void)

DESCRIPCIÓN

Instala el subsistema de audio.

Devuelve true si tiene éxito, false si falla.

Nota: la mayoría de los usuarios llamarán a al_reserve_samples(3) y al_init_acodec_addon(3) después de esto.

VER TAMBIÉN

al_reserve_samples(3), al_uninstall_audio(3), al_is_audio_installed(3), al_init_acodec_addon(3)
