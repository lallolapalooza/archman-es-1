ALTER_SERVER(7)

Paquete: postgresql

Licencias: PostgreSQL

ALTER SERVER(7) Documentación de PostgreSQL 18.1 ALTER SERVER(7)

NOMBRE

ALTER_SERVER - cambiar la definición de un servidor externo

SINTAXIS

ALTER SERVER nombre [ VERSION 'nueva_version' ]
    [ OPTIONS ( [ ADD | SET | DROP ] opcion ['valor'] [, ... ] ) ]
ALTER SERVER nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER SERVER nombre RENAME TO nuevo_nombre

DESCRIPCIÓN

ALTER SERVER cambia la definición de un servidor externo. La primera forma cambia la cadena de versión del servidor o las opciones genéricas del servidor (se requiere al menos una cláusula). La segunda forma cambia el propietario del servidor.

Para alterar el servidor debes ser el propietario del servidor. Además, para alterar el propietario, debes poder ejecutar SET ROLE para el nuevo rol propietario y tener el privilegio USAGE sobre el wrapper de datos externos del servidor. (Ten en cuenta que los superusuarios cumplen todos estos criterios automáticamente).

PARÁMETROS

nombre

El nombre de un servidor existente.

nueva_version

Nueva versión del servidor.

OPTIONS ( [ ADD | SET | DROP ] opcion ['valor'] [, ... ] )

Cambia las opciones para el servidor. ADD, SET y DROP especifican la acción a realizar. Se asume ADD si no se especifica explícitamente ninguna operación. Los nombres de las opciones deben ser únicos; los nombres y valores también se validan utilizando la biblioteca del wrapper de datos externos del servidor.

nuevo_propietario

El nombre de usuario del nuevo propietario del servidor externo.

nuevo_nombre

El nuevo nombre para el servidor externo.

EJEMPLOS

Alterar el servidor foo, añadir opciones de conexión:

ALTER SERVER foo OPTIONS (host 'foo', dbname 'foodb');

Alterar el servidor foo, cambiar la versión, cambiar la opción host:

ALTER SERVER foo VERSION '8.4' OPTIONS (SET host 'baz');

COMPATIBILIDAD

ALTER SERVER cumple con ISO/IEC 9075-9 (SQL/MED). Las formas OWNER TO y RENAME son extensiones de PostgreSQL.

VER TAMBIÉN

CREATE SERVER (CREATE_SERVER(7)), DROP SERVER (DROP_SERVER(7))
