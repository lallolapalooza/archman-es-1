al_perspective_transform(3) Manual de funciones de la biblioteca al_perspective_transform(3)

NOMBRE

al_perspective_transform - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_perspective_transform(ALLEGRO_TRANSFORM *trans,
   float left, float top, float n,
   float right, float bottom, float f)

DESCRIPCIÓN

Al igual que al_orthographic_transform(3) pero respeta la perspectiva. Si todo está en una posición z de -near, se verá igual que con una transformación ortográfica.

Para usar un campo de visión horizontal específico, puedes usar la relación:

tan(hfov / 2) = (right - left) / 2 / near

y por lo tanto

near = (right - left) / 2 / tan(hfov / 2)

Ejemplo 1:

   float w = 800, h = 450; // asumimos que nuestra pantalla es de 800 x 450
   float fov = tan(90 * ALLEGRO_PI / 180 / 2); // campo de visión de 90 grados
   // Nuestra proyección va de 0/0 a w/h con el parámetro near configurado
   // para un ángulo de visión horizontal de 90 grados.
   ALLEGRO_TRANSFORM projection;
   al_identity_transform(&projection);
   al_perspective_transform(&projection, 0, 0,
    w / 2 / fov,
    w, h,
    2000);
   al_use_projection_transform(&projection);
   // Establecemos la z de la cámara a +400 (que es exactamente la distancia cercana)
   ALLEGRO_TRANSFORM camera;
   al_build_camera_transform(&camera, 0, 0, 400, 0, 0, 0, 0, 1, 0);
   al_use_transform(&camera);
   // Esto dibujará dos rectángulos en los bordes izquierdo y derecho de la
   // pantalla y centrados verticalmente. La distancia x entre ellos es 800
   // unidades, pero la transformación de la cámara los mueve 400 en z, por lo que con
   // un ángulo de visión de 90° ambos son visibles.
   al_draw_filled_rectangle(0, 200, 50, 250, red;
   al_draw_filled_rectangle(750, 200, 800, 250, red);

Ejemplo 2:

   float w = 800, h = 450; // asumimos que nuestra pantalla es de 800 x 450
   float fov = tan(90 * ALLEGRO_PI / 180 / 2); // campo de visión de 90 grados
   float aspect = h / w;
   float zoom = 2; // ampliar x 2
   // Esta proyección es muy diferente de la del primer ejemplo.
   // Aquí mapeamos el borde izquierdo y derecho de la pantalla a -1 y +1. Y
   // el eje y va de -1 en la parte inferior a +1 en la parte superior, escalado por
   // la relación de aspecto. También añadimos un parámetro de zoom para poder controlar
   // la porción visible de la escena independientemente del campo de visión.
   ALLEGRO_TRANSFORM projection;
   al_identity_transform(&projection);
   al_perspective_transform(&projection,
      -1 / zoom, aspect / zoom,
      1 / fov,
      1 / zoom, -aspect / zoom,
      2000);
   al_use_projection_transform(&projection);
   // Mueve todo -4 en la dirección z.
   ALLEGRO_TRANSFORM camera;
   al_build_camera_transform(&camera, 0, 0, 4, 0, 0, 0, 0, 1, 0);
   al_use_transform(&camera);
   // A una distancia z de 4 con un hfov de 90° todo se escalaría
   // a un 25%. Sin embargo, también ampliamos 2 veces, por lo que el escalado final es
   // 50%. Este rectángulo, por lo tanto, aparecerá con un tamaño de 400 x 225
   // píxeles (asumiendo que la pantalla es de 800 x 450).
   al_draw_filled_rectangle(-1, -1, 1, 1, red);
