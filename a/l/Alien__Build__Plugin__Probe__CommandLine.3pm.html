Alien::Build::Plugin::Probe::CommandLine(3) Documentación de Perl Contribuida por Usuarios Alien::Build::Plugin::Probe::CommandLine(3)

NOMBRE

Alien::Build::Plugin::Probe::CommandLine - Sonda para herramientas o comandos ya disponibles

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Probe::CommandLine' => (
  command => 'gzip',
  args    => [ '--version' ],
  match   => qr/gzip/,
  version => qr/gzip ([0-9\.]+)/,
);

DESCRIPCIÓN

Este plugin busca la existencia del programa de línea de comandos dado.

PROPIEDADES

comando

El nombre del comando.

argumentos

Los argumentos que se pasarán al comando.

secundario

Si estás usando otro plugin de sondeo (como Alien::Build::Plugin::Probe::CBuilder o Alien::Build::Plugin::PkgConfig::Negotiate) para detectar la existencia de una biblioteca, pero también necesitas que un programa exista, entonces debes establecer secondary a un valor verdadero. Por ejemplo, cuando necesitas ambos:

use alienfile;
# requiere tanto la biblioteca liblzma como el programa xz
plugin 'PkgConfig' => 'liblzma';
plugin 'Probe::CommandLine' => (
  command   => 'xz',
  secondary => 1,
);

Cuando no:

use alienfile;
plugin 'Probe::CommandLine' => (
  command   => 'gzip',
  secondary => 0, # por defecto
);

coincidencia

Expresión regular con la que debe coincidir la salida del programa.

coincidencia_error_estandar

Expresión regular con la que debe coincidir el error estándar del programa.

version

Expresión regular para extraer la versión de la salida del programa. La expresión regular debería almacenar el número de versión en $1.

version_error_estandar

Expresión regular para extraer la versión del error estándar del programa. La expresión regular debería almacenar el número de versión en $1.

al_menos_version

La versión mínima requerida tal como la proporciona el sistema.
