Alien::Build::Log(3) Documentación de Perl aportada por el usuario Alien::Build::Log(3)

NOMBRE

Alien::Build::Log - Registro de Alien::Build

VERSIÓN

versión 2.84

SINOPSIS

Crea tu clase de registro personalizada:

package Alien::Build::Log::MiRegistro;

use parent qw( Alien::Build::Log );

sub log
{
  my(undef, %opt)  = @_;
  my($package, $filename, $line) = @{ $opt{caller} };
  my $message = $opt{message};

  ...;
}

Anula la clase de registro:

% env ALIEN_BUILD_LOG=Alien::Build::Log::MiRegistro cpanm Alien::libfoo

DESCRIPCIÓN

CONSTRUCTORES

new

my $log = Alien::Build::Log->new;

Crea una instancia de la clase de registro.

default

my $log = Alien::Build::Log->default;

Devuelve la instancia singleton de la clase de registro utilizada por Alien::Build.

MÉTODOS

set_log_class

Alien::Build::Log->set_log_class($clase);

Establece la clase de registro predeterminada utilizada por Alien::Build. Este método también restablecerá la instancia predeterminada utilizada por Alien::Build. Si no se especifica, se utilizará Alien::Build::Log::Default.

log

$log->log(%opciones);

Método que se puede anular y que realiza el trabajo real de la clase de registro. Opciones:

llamada
Referencias de matriz que contienen el paquete, el archivo y el número de línea de dónde se llamó al registro.
mensaje
El mensaje a registrar.

ENTORNO

ALIEN_BUILD_LOG
La clase de registro predeterminada utilizada por Alien::Build.
