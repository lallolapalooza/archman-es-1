al_premul_rgba(3) Manual de funciones de la biblioteca al_premul_rgba(3)

NOMBRE

al_premul_rgba - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
ALLEGRO_COLOR al_premul_rgba(
   unsigned char r, unsigned char g, unsigned char b, unsigned char a)

DESCRIPCIÓN

Este es un atajo para al_map_rgba(3)(r * a / 255, g * a / 255, b * a / 255, a).

Por defecto, Allegro utiliza alfa pre-multiplicado para la mezcla transparente de mapas de bits y primitivas (ver al_load_bitmap_flags(3) para una discusión sobre esa característica). Esto significa que si desea dar tintes a un mapa de bits o primitiva para que sea transparente, debe multiplicar los componentes de color por los componentes alfa cuando los pase a esta función. Por ejemplo:

int r = 255;
int g = 0;
int b = 0;
int a = 127;
ALLEGRO_COLOR c = al_premul_rgba(r, g, b, a);
/* Dibuja el mapa de bits con tinte rojo y semitransparente. */
al_draw_tinted_bitmap(bmp, c, 0, 0, 0);

Esta función se puede llamar antes de que Allegro se inicialice.
