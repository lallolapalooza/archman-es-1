NOMBRE

ALTER POLICY - cambiar la definición de una política de seguridad a nivel de fila

SINOPSIS

ALTER POLICY nombre ON nombre_tabla RENAME TO nuevo_nombre
ALTER POLICY nombre ON nombre_tabla
    [ TO { nombre_rol | PUBLIC | CURRENT_ROLE | CURRENT_USER | SESSION_USER } [, ...] ]
    [ USING ( expresión_usar ) ]
    [ WITH CHECK ( expresión_verificar ) ]

DESCRIPCIÓN

ALTER POLICY cambia la definición de una política de seguridad a nivel de fila existente. Tenga en cuenta que ALTER POLICY solo permite modificar el conjunto de roles a los que se aplica la política y las expresiones USING y WITH CHECK. Para cambiar otras propiedades de una política, como el comando al que se aplica o si es permisiva o restrictiva, la política debe ser eliminada y recreada.

Para usar ALTER POLICY, debe ser propietario de la tabla a la que se aplica la política.

En la segunda forma de ALTER POLICY, la lista de roles, la expresión_usar y la expresión_verificar se reemplazan independientemente si se especifican. Cuando se omite una de esas cláusulas, la parte correspondiente de la política permanece sin cambios.

PARÁMETROS

nombre

El nombre de una política existente para alterar.

nombre_tabla

El nombre (opcionalmente calificado por esquema) de la tabla sobre la que se aplica la política.

nuevo_nombre

El nuevo nombre para la política.

nombre_rol

El(los) rol(es) a los que se aplica la política. Se pueden especificar varios roles a la vez. Para aplicar la política a todos los roles, use PUBLIC.

expresión_usar

La expresión USING para la política. Consulte CREATE POLICY (CREATE_POLICY(7)) para obtener detalles.

expresión_verificar

La expresión WITH CHECK para la política. Consulte CREATE POLICY (CREATE_POLICY(7)) para obtener detalles.

COMPATIBILIDAD

ALTER POLICY es una extensión de PostgreSQL.

VER TAMBIÉN

CREATE POLICY (CREATE_POLICY(7)), DROP POLICY (DROP_POLICY(7))
