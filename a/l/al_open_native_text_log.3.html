NOMBRE

al_open_native_text_log - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_native_dialog.h>
ALLEGRO_TEXTLOG *al_open_native_text_log(char const *title, int flags)

DESCRIPCIÓN

Abre una ventana a la que puedes añadir mensajes de registro con al_append_native_text_log(3). Esto puede ser útil para depurar si no quieres depender de una consola disponible.

Usa al_close_native_text_log(3) para cerrar la ventana de nuevo.

Las banderas disponibles son:

ALLEGRO_TEXTLOG_NO_CLOSE
Evita que la ventana tenga un botón de cierre. De lo contrario, si se pulsa el botón de cierre, se genera un evento; véase al_get_native_text_log_event_source(3).
ALLEGRO_TEXTLOG_MONOSPACE
Usa una fuente monoespaciada para mostrar el texto.

Devuelve NULL si hubo un error al abrir la ventana, o si las ventanas de registro de texto no están implementadas en la plataforma.

Nota: En Android, los registros se pueden ver usando logcat.

VER TAMBIÉN

al_append_native_text_log(3), al_close_native_text_log(3)
