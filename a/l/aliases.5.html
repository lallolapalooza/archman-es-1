ALIASES(5) Manual de formatos de archivo ALIASES(5)

NOMBRE

aliases — archivo de alias para smtpd

DESCRIPCIÓN

Esta página del manual describe el formato del archivo aliases, tal como lo utiliza smtpd(8). Un alias, en su forma más simple, se utiliza para asignar un nombre arbitrario a una dirección de correo electrónico o a un grupo de direcciones de correo electrónico. Esto proporciona una forma conveniente de enviar correo. Por ejemplo, un alias podría referirse a todos los usuarios de un grupo: el correo a ese alias se enviaría a todos los miembros del grupo. Sin embargo, se pueden definir alias mucho más complejos: un alias puede referirse a otros alias, usarse para enviar correo a un archivo en lugar de a otra persona, o para ejecutar varios comandos.

Dentro del archivo, ‘#’ es un delimitador de comentarios; todo lo que se coloque después de él se descarta. El archivo consta de mapeos de clave/valor de la forma:

clave: valor1, valor2, valor3, ...

clave siempre se convierte a minúsculas antes de buscar alias para garantizar que no haya ambigüedad. La clave se expande a los valores correspondientes, que consisten en uno o más de los siguientes:

usuario
Un usuario en la máquina host. El usuario debe tener una entrada válida en el archivo de base de datos passwd(5).
/ruta/al/archivo
Añadir mensajes a archivo, especificado por su ruta absoluta.
|comando
Pasar el mensaje a comando en su entrada estándar. El comando se ejecuta bajo los privilegios de la cuenta sin privilegios del demonio.
:incluir:/ruta/al/archivo
Incluir cualquier definición en archivo como entradas de alias. El formato del archivo es idéntico a este.
parte-usuario@parte-dominio
Una dirección de correo electrónico en formato RFC 5322. Si se añade una extensión de dirección a la parte-usuario, primero se compara para una coincidencia exacta. Luego se elimina para que una dirección como usuario+ext@example.com solo use la parte que precede a ‘+’ como clave.
error:código mensaje
Un código de estado y un mensaje para devolver. El código debe tener 3 dígitos, comenzando por 4XX (TempFail) o 5XX (PermFail). El mensaje debe estar presente y puede ser elegido libremente.

ARCHIVOS

/etc/smtpd/aliases
Archivo aliases predeterminado.

VER TAMBIÉN

smtpd.conf(5), makemap(8), newaliases(8), smtpd(8)
