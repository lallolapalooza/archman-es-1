ALLEGRO_LOCKED_REGION(3) Manual de funciones de la biblioteca ALLEGRO_LOCKED_REGION(3)

NOMBRE

ALLEGRO_LOCKED_REGION - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef struct ALLEGRO_LOCKED_REGION ALLEGRO_LOCKED_REGION;

DESCRIPCIÓN

Los usuarios que deseen editar o leer manualmente desde un mapa de bits deben bloquearlo primero. La estructura ALLEGRO_LOCKED_REGION representa la región bloqueada del mapa de bits. Esta llamada funcionará con cualquier mapa de bits, incluidos los mapas de bits en memoria.

typedef struct ALLEGRO_LOCKED_REGION {
   void *data;
   int format;
   int pitch;
   int pixel_size;
} ALLEGRO_LOCKED_REGION;
•
data apunta al píxel más a la izquierda de la primera fila (fila 0) de la región bloqueada. Para formatos bloqueados, esto apunta al bloque más a la izquierda de la primera fila de bloques.
•
format indica el formato de píxel de los datos.
•
pitch da el tamaño en bytes de una sola fila (también conocido como stride). El pitch puede ser mayor que ancho * tamaño_píxel debido al relleno; esto no es infrecuente. Tampoco es infrecuente que el pitch sea negativo (el mapa de bits puede estar boca abajo). Para formatos bloqueados, `fila' se refiere a la fila de bloques, no a la de píxeles.
•
pixel_size es el número de bytes utilizados para representar un solo bloque de píxeles para el formato de píxel de esta región bloqueada. Para la mayoría de los formatos (y históricamente, esto solía ser cierto para todos los formatos), este es solo el tamaño de un solo píxel, pero para formatos de píxeles bloqueados, este valor es diferente.
