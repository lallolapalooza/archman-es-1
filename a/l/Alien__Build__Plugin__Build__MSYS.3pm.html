NOMBRE

Alien::Build::Plugin::Build::MSYS - Plugin MSYS para Alien::Build

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Build::MSYS';

DESCRIPCIÓN

Este plugin configura el entorno MSYS para tu compilación en Windows. No hace nada en plataformas no Windows. MSYS proporciona las herramientas esenciales para compilar software que normalmente se espera en un entorno UNIX o POSIX. Como "sh", "awk" y "make". Para proporcionar MSYS, este plugin utiliza Alien::MSYS.

PROPIEDADES

msys_version

La versión de Alien::MSYS requerida si se considera necesaria. Si Alien::MSYS no es necesario (si se ejecuta bajo Unix, o MSYS2, por ejemplo), esto no hará nada.

AYUDANTES

make

%{make}

En windows, el ayudante predeterminado "%{make}" se reemplaza con el make que viene con Alien::MSYS. Esto es casi con seguridad lo que quieres, ya que la mayoría de los proyectos de make estilo unix no se compilarán con "nmake" o "dmake" que típicamente usa Perl en Windows.
