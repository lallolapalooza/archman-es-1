DESCRIPCIÓ

N

ALTER SEQUENCE cambia los parámetros de un generador de secuencias existente. Cualquier parámetro que no se establezca específicamente en el comando ALTER SEQUENCE conservará su configuración

anterior.

Debe ser propietario de la secuencia para usar ALTER SEQUENCE. Para cambiar el esquema de una secuencia, también debe tener el privilegio CREATE en el nuevo esquema. Para cambiar el propietario, debe poder hacer SET ROLE al nuevo rol propietario, y ese rol debe tener el privilegio CREATE en el

esquema de la secuencia. (Estas restricciones garantizan que cambiar el propietario no haga nada que no podría hacer eliminand
o y recreando la secuencia. Sin embargo, un superusuario puede cambiar la propiedad de cualquier secuencia de todos modos.)

PARÁMETRO

S

nombr

e
El nombre (opcionalmente calificado con el esquema) de una secuencia a
alterar.

IF

EXISTS
No lance un error si la secuencia no existe. En este caso se emite un
aviso.

tipo_de_dato

s
La cláusula opcional AS tipo_de_datos cambia el tipo de datos de la secuencia. Los tipos válidos son smallint, integer y bigint.

Cambiar el tipo de datos cambia automáticamente los valores mínimo y máximo de la secuencia si y solo si los valores mínimo y máximo anteriores eran el valor mínimo o máximo del ti

po de datos antiguo (en otras palabras, si la secuencia se había creado usando NO MINVALUE o NO MAXVALUE, implícita o explícitamente). De lo contrario, los valores mínimo y má
ximo se conservan, a menos que se proporcionen nuevos valores como parte del mismo comando. Si los valores mínimo y máximo no caben en el nuevo tipo de datos, se generará un error.

increment

o
La cláusula INCREMENT BY incremento es opcional. Un valor positivo hará una secuencia ascendente, uno negativo una secuencia descendente. Si no se especifica, se mantendrá el valor de incremento
anterior.

valor_minimo
NO

MINVALUE
La cláusula opcional MINVALUE valor_minimo determina el valor mínimo que una secuencia puede generar. Si se especifica NO MINVALUE, se usarán los valores predeterminados de 1 y el valor mínimo del tipo de datos para secuencias ascendentes y descendentes, respectivamente. Si no se especifica ninguna opción, se mantendrá el valor mínimo
actual.

valor_maximo
NO

MAXVALUE
La cláusula opcional MAXVALUE valor_maximo determina el valor máximo de la secuencia. Si se especifica NO MAXVALUE, se usarán los valores predeterminados del valor máximo del tipo de datos y -1 para secuencias ascendentes y descendentes, respectivamente. Si no se especifica ninguna opción, se mantendrá el valor máximo
actual.

CYCL

E
La palabra clave opcional CYCLE se puede usar para permitir que la secuencia se reinicie cuando una secuencia ascendente o descendente haya alcanzado el valor_maximo o valor_minimo, respectivamente. Si se alcanza el límite, el siguiente número generado será el valor_minimo o valor_maximo, respectivamente
.

NO

CYCLE
Si se especifica la palabra clave opcional NO CYCLE, cualquier llamada a nextval después de que la secuencia haya alcanzado su valor máximo devolverá un error. Si no se especifica CYCLE ni NO CYCLE, se mantendrá el comportamiento de ciclo
anterior.

inici

o
La cláusula opcional START WITH inicio cambia el valor de inicio registrado de la secuencia. Esto no tiene ningún efecto en el valor actual de la secuencia; simplemente establece el valor que los futuros comandos ALTER SEQUENCE RESTART
usarán.

reinici

o
La cláusula opcional RESTART [ WITH reinicio ] cambia el valor actual de la secuencia. Esto es similar a llamar a la función setval con is_called = false: el valor especificado será devuelto por la siguiente llamada de nextval. Escribir RESTART sin ningún valor de reinicio equivale a proporcionar el valor de inicio que fue registrado por CREATE SEQUENCE o establecido por última vez por ALTER SEQUENCE START WITH.

En contraste con una llamada a setval, una operación RESTART en una secuencia es transaccional y bloquea las transacciones concurrentes para que no obtengan números de la misma secuencia. Si ese no es el modo de operación deseado, debería usa

rse s
etval.

cach

é
La cláusula CACHE caché permite que los números de secuencia se preasignen y almacenen en memoria para un acceso más rápido. El valor mínimo es 1 (solo se puede generar un valor a la vez, es decir, sin caché). Si no se especifica, se mantendrá el valor de caché
anterior.

SET { LOGGED | UNLOGGED

}
Esta forma cambia la secuencia de no registrada a registrada o viceversa (ver CREATE SEQUENCE (CREATE_SEQUENCE(7))). No se puede aplicar a una secuencia
temporal.

OWNED BY nombre_tabla.nombre_columna
OWNED BY

NONE
La opción OWNED BY hace que la secuencia se asocie con una columna de tabla específica, de modo que si esa columna (o su tabla completa) se elimina, la secuencia también se eliminará automáticamente. Si se especifica, esta asociación reemplaza cualquier asociación previamente especificada para la secuencia. La tabla especificada debe tener el mismo propietario y estar en el mismo esquema que la secuencia. Especificar OWNED BY NONE elimina cualquier asociación existente, haciendo que la secuencia sea "independiente"
.

nuevo_propietar

io
El nombre de usuario del nuevo propietario de la
secuencia.

nuevo_nombr

e
El nuevo nombre de la
secuencia.

nuevo_esquem

a
El nuevo es
quema de la

NOTA

S

ALTER SEQUENCE no afectará inmediatamente a los resultados de nextval en backends, distintos del actual, que tengan valores de secuencia preasignados (en caché). Usarán todos los valores en caché antes de notar los parámetros de generación de secuencia cambiados. El backend actual se verá afectado

inmediatamente.

ALTER SEQUENCE no afecta el estado de currval de la secuencia. (Antes de PostgreSQL 8.3, a veces lo hacía.

)

ALTER SEQUENCE bloquea las llamadas concurrentes a nextval, currval, lastval y setval

.

Por razones históricas, ALTER TABLE se puede usar también con secuencias; pero las únicas variantes de ALTER TABLE que se permiten con secuencias

son equivalentes a las
formas mostradas arriba.

D
