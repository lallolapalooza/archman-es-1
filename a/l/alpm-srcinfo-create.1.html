NOMBRE

alpm-srcinfo-create - Crear un archivo SRCINFO a partir de un archivo PKGBUILD en una ruta dada

SINÓPSIS

alpm-srcinfo create [-o|--output-format] [-p|--pretty] [-h|--help] <ARCHIVO>

DESCRIPCIÓN

Crear un archivo SRCINFO a partir de un archivo PKGBUILD en una ruta dada.

Si el PKGBUILD se puede crear y validar, el programa sale sin salida y con un código de retorno de 0. Si el archivo falta o no se puede validar, se emite un error en stderr y el programa sale con un estado de salida distinto de cero.

OPCIONES

-o, --output-format <FORMATO_SALIDA> [predeterminado: srcinfo]
Proporcionar el formato de salida

Valores posibles:

  • json: El formato de salida JSON
  • srcinfo: El formato de salida SRCINFO
-p, --pretty
Imprimir la salida de forma legible.

Solo se aplica a formatos que admiten salida legible y de lo contrario se ignora.

-h, --help
Imprimir ayuda (ver un resumen con '-h')
<ARCHIVO>
Una ruta de archivo de entrada opcional para leer

Si no se especifica ningún archivo, se lee de la entrada estándar y se espera que contenga datos PKGINFO para validar.
