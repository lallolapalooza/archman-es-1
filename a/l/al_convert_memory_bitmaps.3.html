NOMBRE

al_convert_memory_bitmaps - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_convert_memory_bitmaps(void)

DESCRIPCIÓN

Si creas un mapa de bits sin una pantalla actual (por ejemplo, porque no has llamado a al_create_display(3) en el hilo actual) y estás usando la bandera de mapa de bits ALLEGRO_CONVERT_BITMAP (que está establecida por defecto), entonces el mapa de bits se creará con éxito, pero como un mapa de bits de memoria. Esta función convierte todos esos mapas de bits a mapas de bits de video apropiados que pertenecen a la pantalla actual.

Ten en cuenta que los mapas de bits de video se convierten automáticamente de nuevo a mapas de bits de memoria cuando se destruye la última pantalla.

Esta operación conservará todas las banderas de mapa de bits, excepto ALLEGRO_VIDEO_BITMAP y ALLEGRO_MEMORY_BITMAP.

DESDE

5.2.0

VER TAMBIÉN

al_convert_bitmap(3), al_create_bitmap(3)
