subrutina alareq (character*3 path, integer nmats, logical, dimension( * ) dotype, integer ntypes, integer nin, integer nout)

ALAREQ

Propósito:

!>
!> ALAREQ maneja la entrada para el programa de prueba LAPACK.  Se llama
!> para evaluar la línea de entrada que solicitó NMATS tipos de matrices para
!> PATH.  El flujo de control es el siguiente:
!>
!> SI NMATS = NTYPES ENTONCES
!>    DOTYPE(1:NTYPES) = .TRUE.
!> SI NO
!>    Leer la siguiente línea de entrada para NMATS tipos de matrices
!>    Establecer DOTYPE(I) = .TRUE. para cada tipo válido I
!> FIN SI
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          Un nombre de ruta LAPACK para pruebas.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matrices que se utilizarán en la prueba de esta ruta.
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensionado (NTYPES)
!>          El vector de banderas que indican si se probará cada tipo.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número máximo de tipos de matrices para esta ruta.
!>

NIN

!>          NIN es INTEGER
!>          El número de unidad para la entrada.  NIN >= 1.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad para la salida.  NOUT >= 1.
!>
