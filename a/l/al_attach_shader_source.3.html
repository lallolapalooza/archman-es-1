DESCRIPCIÓ

N

Adjunta el código fuente del shader al objeto shader y lo compila. Pasar NULL elimina el shader subyacente (OpenGL o DirectX). Ver también al_attach_shader_source_file(3) si prefiere obtener el código fuente de su shader desde un archivo

externo.

Si no usa ALLEGRO_PROGRAMMABLE_PIPELINE, las funciones gráficas de Allegro no usarán ninguna función específica de shaders por sí mismas. En el caso de un sistema sin pipeline de función fija (como OpenGL ES 2 u OpenGL 3 o 4), esto significa que las funciones de dibujo de Allegro no pueden

usarse.

POR HACER: ¿Se establece ALLEGRO_PROGRAMMABLE_PIPELINE automáticamente en este

caso?
