NOMBRE

al_set_haptic_autocenter - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
bool al_set_haptic_autocenter(ALLEGRO_HAPTIC *hap, double intensity)

DESCRIPCIÓN

Activa o desactiva la función de centrado automático del dispositivo háptico si es compatible. Dependiendo del dispositivo, el centrado automático puede asegurar que los ejes del dispositivo vuelvan a centrarse automáticamente después de reproducir un efecto háptico. El parámetro intensity debe pasarse con un valor entre 0.0 y 1.0. El valor 0.0 significa que el centrado automático está deshabilitado, y 1.0 significa centrado automático a máxima intensidad. Cualquier valor entre estos dos extremos dará como resultado un centrado automático parcial. Algunas plataformas no admiten el centrado automático parcial. Si ese es el caso, un valor inferior a 0.5 lo desactivará, mientras que un valor igual o superior a 0.5 lo activará. Devuelve true si se configuró correctamente, false si no. Solo puede funcionar si al_get_haptic_capabilities(3) devuelve un valor que tiene ALLEGRO_HAPTIC_AUTOCENTER(3) ALLEGRO_HAPTIC_CONSTANTS(3) establecido. Si no es así, esta función devuelve false.

DESDE
