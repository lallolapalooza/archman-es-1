NOMBRE

ALLEGRO_RENDER_STATE - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef enum ALLEGRO_RENDER_STATE {

DESCRIPCIÓN

Estados de renderizado posibles que se pueden establecer con al_set_render_state(3):

ALLEGRO_ALPHA_TEST
Si se establece en 1, los valores de ALLEGRO_ALPHA_FUNCTION y ALLEGRO_ALPHA_TEST_VALUE definen una función de comparación que se realiza en el componente alfa de cada píxel. Solo si se evalúa como verdadero, el píxel se escribe. De lo contrario, no se realiza ningún procesamiento posterior (como prueba de profundidad o mezcla). Esto puede ser muy útil, por ejemplo, si se utiliza un búfer de profundidad pero no desea que los píxeles completamente transparentes lo modifiquen.
ALLEGRO_ALPHA_FUNCTION
Una de las funciones ALLEGRO_RENDER_FUNCTION(3), solo se utiliza cuando ALLEGRO_ALPHA_TEST es 1.
ALLEGRO_ALPHA_TEST_VALUE
Solo se utiliza cuando ALLEGRO_ALPHA_TEST es 1. Debe ser un valor de 0 a 255.
ALLEGRO_WRITE_MASK
Esto determina cómo se actualizan el búfer de fotogramas y el búfer de profundidad cada vez que se escribe un píxel (en caso de que la prueba alfa y/o de profundidad estén habilitadas: después de que todas las pruebas habilitadas tengan éxito). Los valores de profundidad solo se escriben si ALLEGRO_DEPTH_TEST es 1, además de que se establezca la bandera de máscara de escritura.
ALLEGRO_DEPTH_TEST
Si se establece en 1, compara el valor de profundidad de cualquier píxel recién escrito con el valor de profundidad ya presente en el búfer, de acuerdo con ALLEGRO_DEPTH_FUNCTION. Las primitivas de Allegro sin una coordenada z explícita escribirán un valor de 0 en el búfer de profundidad.
ALLEGRO_DEPTH_FUNCTION
Una de las funciones ALLEGRO_RENDER_FUNCTION(3), solo se utiliza cuando ALLEGRO_DEPTH_TEST es 1.

5.1.2
