NOMBRE

al_play_sample - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
bool al_play_sample(ALLEGRO_SAMPLE *spl, float gain, float pan, float speed,
   ALLEGRO_PLAYMODE loop, ALLEGRO_SAMPLE_ID *ret_id)

DESCRIPCIÓN

Reproduce una muestra en una de las instancias de muestra creadas por al_reserve_samples(3). Devuelve true en caso de éxito, false en caso de error. La reproducción puede fallar porque todas las instancias de muestra reservadas están actualmente en uso.

Parámetros:

•
gain - volumen relativo al que se reproduce la muestra; 1.0 es normal.
•
pan - 0.0 es centrado, -1.0 es izquierdo, 1.0 es derecho, o ALLEGRO_AUDIO_PAN_NONE.
•
speed - velocidad relativa a la que se reproduce la muestra; 1.0 es normal.
•
loop - ALLEGRO_PLAYMODE_ONCE, ALLEGRO_PLAYMODE_LOOP, o ALLEGRO_PLAYMODE_BIDIR
•
ret_id - si no es NULL, la variable a la que apunta se le asignará un identificador que representa la muestra que se está reproduciendo. Si al_play_sample(3) devuelve false, entonces el contenido de ret_id no es válido y no debe usarse como argumento para otras funciones.
