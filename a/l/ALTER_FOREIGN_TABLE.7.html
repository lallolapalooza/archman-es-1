Hay varias subformas: ADD COLUMN Esta forma añade una nueva columna a la tabla externa, usando la misma sintaxis que CREATE FOREIGN TABLE . A diferencia del caso de añadir una columna a una tabla normal, no ocurre nada en el almacenamiento subyacente: esta acción simplemente declara que alguna nueva columna es ahora accesible a través de la tabla externa. DROP COLUMN [ IF EXISTS ]Esta forma elimina una columna de una tabla externa. Necesitará decir CASCADE si algo fuera de la tabla depende de la columna; por ejemplo, vistas. debe tener el privilegio USAGE en el tipo de datos.

PARÁMETROS

name
El nombre (posiblemente calificado por esquema) de una tabla externa existente a alterar. Si se especifica ONLY antes del nombre de la tabla, solo se altera esa tabla. Si no se especifica ONLY, se altera la tabla y todas sus tablas descendientes (si las hay). Opcionalmente, se puede especificar * después del nombre de la tabla para indicar explícitamente que se incluyen las tablas
descendientes.

CASCADE

Elimina automáticamente los objetos que dependen de la columna o restricción eliminada (por ejemplo, vistas que hacen referencia a la columna), y a su vez todos los objetos que dependen de esos objetos (véase la Sección 5.15).

RESTRICT

Se niega a eliminar la columna o restricción si existen objetos dependientes. Este es el comportamiento por defecto.

trigger_name

Nombre de un único disparador para deshabilitar o habilitar.

ALL

Deshabilita o habilita todos los disparadores pertenecientes a la tabla externa. (Esto requiere privilegio de superusuario si alguno de los disparadores son disparadores generados internamente. El sistema central no añade tales disparadores a las tablas externas, pero el código de complementos podría hacerlo.)

USER

Deshabilita o habilita todos los disparadores pertenecientes a la tabla externa excepto los disparadores generados internamente.

parent_table

Una tabla padre con la que asociar o desasociar esta tabla externa.

new_owner

El nombre de usuario del nuevo propietario de la tabla.

new_schema

El nombre del esquema al que se moverá la tabla.

NOTAS

La palabra clave COLUMN es superflua y puede omitirse.

No se comprueba la consistencia con el servidor externo cuando se añade o elimina una columna con ADD COLUMN o DROP COLUMN, se añade una restricción NOT NULL o CHECK, o se cambia el tipo de una columna con SET DATA TYPE. Es responsabilidad del usuario asegurarse de que la definición de la tabla coincida con el lado remoto.

Consulte CREATE FOREIGN TABLE para una descripción más detallada de los parámetros válidos.

EJEMPLOS

Para marcar una columna como not-null:

ALTER FOREIGN TABLE distributors ALTER COLUMN street SET NOT NULL;

Para cambiar opciones de una tabla externa:

ALTER FOREIGN TABLE myschema.distributors OPTIONS (ADD opt1 'value', SET opt2 'value2', DROP opt3);

COMPATIBILIDAD

Las formas ADD, DROP y SET DATA TYPE se ajustan al estándar SQL. Las demás formas son extensiones de PostgreSQL del estándar SQL. Además, la posibilidad de especificar más de una manipulación en un único ALTER FOREIGN TABLE comando es una extensión.

ALTER FOREIGN TABLE DROP COLUMN se puede utilizar para eliminar la única columna de una tabla externa, dejando una tabla de cero columnas. Esto es una extensión de SQL, que prohíbe las tablas externas de cero columnas.
