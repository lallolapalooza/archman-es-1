DESCRIPCIÓN

El objetivo del namespace Alien es proporcionar dependencias no CPAN (llamadas dependencias "Alien") para módulos CPAN. La historia y el propósito de esta idea se documentan en el módulo Alien, que solo tiene documentación. La distribución "Alien-Build" proporciona un framework para construir aliens. La intención es corregir errores y mejorar la interfaz de varias herramientas comunes para que todos los aliens puedan beneficiarse. La distribución se divide en estas partes:

El Instalador Alien (tiempo de configuración / construcción)
Alien::Build y alienfile se utilizan para detectar e instalar aliens. Se documentan adicionalmente en Alien::Build::Manual::AlienAuthor.
El Entorno de Ejecución Alien (tiempo de ejecución)
Alien::Base es la clase base para aliens en el sistema "Alien-Build". Su uso por parte de los consumidores de Alien se documenta en Alien::Build::Manual::AlienUser.
El sistema de Plugins (tiempo de configuración / construcción)
Dado que muchos paquetes se implementan utilizando diferentes herramientas, la lógica de detección, construcción e instalación para un Alien particular puede variar mucho. Por lo tanto, gran parte de Alien::Build se implementa como una serie de plugins que heredan de Alien::Build::Plugin. Una descripción general de cómo crear sus propios plugins se documenta en Alien::Build::Manual::PluginAuthor.
