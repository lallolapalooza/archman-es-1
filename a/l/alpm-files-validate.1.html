NOMBRE

alpm-files-validate - Valida un archivo de alpm-files.

SINOPSIS

alpm-files validate [-i|--input-file] [-h|--help]

DESCRIPCIÓN

Valida un archivo de alpm-files.

Si el archivo se puede validar, el programa sale sin ninguna salida y con un código de salida de cero. Si el archivo no se puede validar, se emite un error en stderr y el programa sale con un código de salida distinto de cero.

OPCIONES

-i, --input-file <ARCHIVO_ENTRADA>
Un archivo de entrada para leer.

Si no se proporciona ningún archivo, se utiliza la entrada estándar en su lugar.

También se puede especificar con la variable de entorno ALPM_FILES_VALIDATE_INPUT_FILE.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
alpm-files-validate
