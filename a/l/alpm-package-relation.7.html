DESCRIPCIÓ

N

Las relaciones de paquetes describen relaciones entre paquetes basados en ALPM para varios escenarios. Se utilizan en scripts de compilación o formatos de archivo para metadatos de paquetes (por ejemplo, en PKGBUILD, PKGINFO o SRCINFO) para describir relaciones de paquetes con otros paquetes. Programas como gestores de paquetes o software de compilación de paquetes se basan en relaciones de paquetes para resolver grafos de dependencias, por ejemplo, al instalar o desinstalar

paquetes.

Paquetes y componentes

virtuales

Cualquier relación de paquete puede contener un alpm-package-name, que puede usarse para referirse a un paquete existente o a un componente virtual. Los componentes virtuales no representan los nombres de paquetes existentes, sino un componente que está implícitamente definido por los metadatos del paquete. Con la ayuda de relaciones de paquetes, los componentes virtuales se definen y utilizan de manera similar a los nombres de paquetes existentes (ver EJEMPLOS para má

s infor
mación).

Soname

s

Una relación de paquete de tipo provisión o dependencia en tiempo de ejecución puede contener un alpm-soname que representa una dependencia dura basada en un objeto compartido específico en un paquete. Se utilizan para codificar garantías de compatibilidad entre ELF[1] y archivos de objetos compartidos con la ayuda de datos de soname[2] (ver EJEMPLOS para má

s infor
mación).

NOMBRE​

alpm-package-relation - Formato de las relaciones de paquetes de ALPM

DESCRIPCIÓN​

Las relaciones de paquetes son una característica clave de ALPM (Arch Linux Package Manager). Permiten especificar dependencias, conflictos, opciones, etc., entre paquetes.

Las relaciones se definen típicamente en el archivo PKGBUILD de un paquete. La sintaxis general para una relación es:

<nombre_paquete> [<operador><versión>]

Los operadores válidos son:

  • = : Igual a
  • != : No igual a
  • < : Menor que
  • <= : Menor o igual que
  • > : Mayor que
  • `>=` : Mayor o igual que

Si no se especifica un operador, se asume =.

Existen varios tipos de relaciones:

  • depends : Dependencias requeridas para que el paquete funcione.
  • makedepends : Dependencias requeridas para construir el paquete.
  • checkdepends : Dependencias requeridas para verificar el paquete.
  • optdepends : Dependencias opcionales.
  • provides : Capacidades que el paquete proporciona.
  • conflicts : Paquetes con los que este paquete entra en conflicto.
  • replaces : Paquetes que este paquete reemplaza.
  • alternatives : Paquetes que pueden ser sustituidos por este.

EJEMPLOS​

Definición de dependencias en un PKGBUILD:

depends=('bash' 'coreutils>=8.30' 'grep<4.0')
makedepends=('git')
optdepends=('vlc: para reproducir varios formatos de audio/vídeo'
            'gst-plugins-base: para soporte de códecs básicos')
conflicts=('otro-paquete')
replaces=('paquete-antiguo')
provides=('mi-libreria-base')
