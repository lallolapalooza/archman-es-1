ALTER MATERIALIZED VIEW(7) Documentación de PostgreSQL 18.1 ALTER MATERIALIZED VIEW(7)

NOMBRE

ALTER MATERIALIZED VIEW - cambiar la definición de una vista materializada

SINOPSIS

ALTER MATERIALIZED VIEW [ IF EXISTS ] nombre
    acción [, ...]
ALTER MATERIALIZED VIEW nombre
    [ NO ] DEPENDS ON EXTENSION nombre_extension
ALTER MATERIALIZED VIEW [ IF EXISTS ] nombre
    RENAME [ COLUMN ] nombre_columna TO nuevo_nombre_columna
ALTER MATERIALIZED VIEW [ IF EXISTS ] nombre
    RENAME TO nuevo_nombre
ALTER MATERIALIZED VIEW [ IF EXISTS ] nombre
    SET SCHEMA nuevo_esquema
ALTER MATERIALIZED VIEW ALL IN TABLESPACE nombre [ OWNED BY nombre_rol [, ...] ]
    SET TABLESPACE nuevo_tablespace [ NOWAIT ]
where acción is one of:
    ALTER [ COLUMN ] nombre_columna SET STATISTICS entero
    ALTER [ COLUMN ] nombre_columna SET ( opción_atributo = valor [, ...] )
    ALTER [ COLUMN ] nombre_columna RESET ( opción_atributo [, ...] )
    ALTER [ COLUMN ] nombre_columna SET STORAGE { PLAIN | EXTERNAL | EXTENDED | MAIN | DEFAULT }
    ALTER [ COLUMN ] nombre_columna SET COMPRESSION método_compresión
    CLUSTER ON nombre_índice
    SET WITHOUT CLUSTER
    SET ACCESS METHOD nuevo_método_acceso
    SET TABLESPACE nuevo_tablespace
    SET ( parámetro_almacenamiento [= valor] [, ...] )
    RESET ( parámetro_almacenamiento [, ...] )
    OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

DESCRIPCIÓN

ALTER MATERIALIZED VIEW cambia varias propiedades auxiliares de una vista materializada existente.

Debes ser el propietario de la vista materializada para usar ALTER MATERIALIZED VIEW. Para cambiar el esquema de una vista materializada, también debes tener el privilegio CREATE en el nuevo esquema. Para alterar el propietario, debes poder usar SET ROLE para el nuevo rol propietario, y ese rol debe tener el privilegio CREATE en el esquema de la vista materializada. (Estas restricciones garantizan que la alteración del propietario no haga nada que no pudieras hacer eliminando y recreando la vista materializada. Sin embargo, un superusuario puede alterar la propiedad de cualquier vista de todos modos.)

Las subformas y acciones disponibles para ALTER MATERIALIZED VIEW son un subconjunto de las disponibles para ALTER TABLE, y tienen el mismo significado cuando se usan para vistas materializadas. Consulta las descripciones de ALTER TABLE para obtener más detalles.

PARÁMETROS

nombre

El nombre (opcionalmente calificado por el esquema) de una vista materializada existente.

nombre_columna

Nombre de una columna existente.

nombre_extension

El nombre de la extensión de la que la vista materializada debe depender (o de la que ya no debe depender, si se especifica NO). Una vista materializada marcada como dependiente de una extensión se elimina automáticamente cuando se elimina la extensión.

nuevo_nombre_columna

Nuevo nombre para una columna existente.

nuevo_propietario

El nombre de usuario del nuevo propietario de la vista materializada.

nuevo_nombre

El nuevo nombre para la vista materializada.

nuevo_esquema

El nuevo esquema para la vista materializada.

EJEMPLOS

Para renombrar la vista materializada foo a bar:

ALTER MATERIALIZED VIEW foo RENAME TO bar;

COMPATIBILIDAD

ALTER MATERIALIZED VIEW es una extensión de PostgreSQL.
