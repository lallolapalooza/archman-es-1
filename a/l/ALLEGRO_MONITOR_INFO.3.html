NOMBRE

ALLEGRO_MONITOR_INFO - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef struct ALLEGRO_MONITOR_INFO

DESCRIPCIÓN

Describe el tamaño y la posición de un monitor en relación con otros monitores. x1, y1 serán 0, 0 en la pantalla principal. Otros monitores pueden tener valores negativos si están a la izquierda o encima de la pantalla principal. x2, y2 son las coordenadas una posición más allá del píxel de la esquina inferior derecha, de modo que x2-x1 da el ancho y y2-y1 da la altura de la pantalla.

typedef struct ALLEGRO_MONITOR_INFO
{
   int x1;
   int y1;
   int x2;
   int y2;
} ALLEGRO_MONITOR_INFO;
