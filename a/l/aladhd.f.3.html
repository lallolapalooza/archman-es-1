subrutina aladhd (integer iounit, character*3 path)

ALADHD

Propósito:

!>
!> ALADHD imprime información de encabezado para las rutas de prueba de las rutinas del controlador.
!>

Parámetros

IOUNIT 
!>          IOUNIT es INTEGER
!>          El número de unidad al que se debe imprimir la información de encabezado.
!>

PATH

!>          PATH es CHARACTER*3
!>          El nombre de la ruta para la que se imprimirá la información de encabezado.
!>          Las rutas actuales son
!>             _GE: Matrices generales
!>             _GB: Banda general
!>             _GT: Tridiagonal general
!>             _PO: Definida positiva simétrica o Hermítica
!>             _PS: Semidefinida positiva simétrica o Hermítica
!>             _PP: Empaquetada definida positiva simétrica o Hermítica
!>             _PB: Banda definida positiva simétrica o Hermítica
!>             _PT: Tridiagonal definida positiva simétrica o Hermítica
!>             _SY: Indefinida simétrica,
!>                     con pivoteo parcial (Bunch-Kaufman)
!>             _SR: Indefinida simétrica,
!>                     con pivoteo de torre ( Bunch-Kaufman acotado)
!>             _SK: Indefinida simétrica,
!>                     con pivoteo de torre ( Bunch-Kaufman acotado)
!>                     ( nuevo formato de almacenamiento para factores:
!>                       L y la diagonal de D se almacenan en A,
!>                       la subdiagonal de D se almacena en E )
!>             _SP: Empaquetada indefinida simétrica,
!>                     con pivoteo parcial (Bunch-Kaufman)
!>             _HA: (compleja) Hermítica,
!>                     Algoritmo de Assen
!>             _HE: Indefinida Hermítica (compleja),
!>                     con pivoteo parcial (Bunch-Kaufman)
!>             _HR: Indefinida Hermítica (compleja),
!>                     con pivoteo de torre ( Bunch-Kaufman acotado)
!>             _HK: Indefinida Hermítica (compleja),
!>                     con pivoteo de torre ( Bunch-Kaufman acotado)
!>                     ( nuevo formato de almacenamiento para factores:
!>                       L y la diagonal de D se almacenan en A,
!>                       la subdiagonal de D se almacena en E )
!>             _HP: Empaquetada indefinida Hermítica (compleja),
!>                     con pivoteo parcial (Bunch-Kaufman)
!>          El primer carácter debe ser uno de S, D, C o Z (solo C o Z
!>          si es compleja).
!>
