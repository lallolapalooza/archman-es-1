Alien::Build::Plugin::Build::Autoconf(3) Documentación de Perl aportada por el usuario Alien::Build::Plugin::Build::Autoconf(3)

NOMBRE

Alien::Build::Plugin::Build::Autoconf - Plugin de Autoconf para Alien::Build

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Build::Autoconf';

DESCRIPCIÓN

Este plugin proporciona algunas herramientas para construir proyectos que usan autoconf. Lo principal que proporciona es un "configure" auxiliar, documentado más abajo, y la etapa de construcción predeterminada, que es:

'%{configure} --disable-shared',
'%{make}',
'%{make} install',

En Windows, este plugin también incluye el Alien::Build::Plugin::Build::MSYS, que es necesario para proyectos de estilo autoconf en Windows.

Otra cosa que hace este plugin es que realiza una instalación escalonada doble con "DESTDIR" . El autor ha descubierto que esto mejora la fiabilidad general de los módulos Alien que se basan en paquetes autoconf.

Este plugin admite compilaciones fuera de origen (conocidas en términos de autoconf como compilaciones "VPATH") a través de la propiedad meta "out_of_source".

NOTA: por sí solo, este plugin está destinado a usarse solo con paquetes que incluyan un "configure" script. Para paquetes que esperan que uses Autotools para generar un script configure antes de compilar, puedes usar Alien::Autotools para generar el script "configure" y usar este plugin para ejecutarlo. Para más detalles, consulta la documentación de Alien::Autotools.

PROPIEDADES

with_pic

Añade la opción "--with-pic" al ejecutar "configure". Si tu paquete lo admite, generará código independiente de la posición en plataformas que lo soporten. Esto es necesario para los módulos XS, y generalmente es lo que quieres.

autoconf normalmente ignora opciones que no entiende, por lo que suele ser seguro y razonable incluirla por defecto. Un pequeño número de proyectos parecen usar autoconf, pero en realidad son una interfaz de estilo autoconf con una implementación diferente. Pueden fallar si intentas proporcionarles opciones como "--with-pic" que no reconocen. Tales paquetes son la razón de ser de esta propiedad.

msys_version

La versión de Alien::MSYS requerida si se considera necesaria. Si Alien::MSYS no es necesaria (por ejemplo, si se ejecuta bajo Unix o MSYS2), esto no hará nada.

config_site

El contenido para el "config.site"generado.

AYUDANTES

configure

%{configure}

La invocación correcta para iniciar un script "configure" de estilo autoconf en tu plataforma. Se proporcionarán algunos indicadores razonables por defecto.

ENTORNO

"SITE_CONFIG"
Para una instalación compartida, este plugin necesita alterar el comportamiento de autotools usando "site.config". Lo hace generando un archivo "site.config" al vuelo y configurando la variable de entorno "SITE_CONFIG" . En el caso de que ya tengas tu propio "SITE_CONFIG" configurado, ese archivo se incluirá desde el generado, por lo que tus valores predeterminados locales deberían seguir respetándose, a menos que sea uno que necesite cambiarse para una instalación compartida.

En particular, el directorio "lib" debe ser sobrescrito, porque en algunas plataformas las bibliotecas dinámicas de lo contrario se colocarían en directorios en los que Alien::Build normalmente no busca. Dado que el paquete alienizado se instalará en un directorio compartido, y no en un directorio del sistema, eso debería estar bien.

"ALIEN_BUILD_SITE_CONFIG"
Si está definido, este archivo también se incluirá en el "site.config"generado. Esto te permite tener valores predeterminados locales solo para instalaciones compartidas de alien.
