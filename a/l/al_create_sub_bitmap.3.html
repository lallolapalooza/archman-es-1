NOMBRE

al_create_sub_bitmap - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
ALLEGRO_BITMAP *al_create_sub_bitmap(ALLEGRO_BITMAP *parent,
   int x, int y, int w, int h)

DESCRIPCIÓN

Crea un sub-mapa de bits del mapa de bits padre, en las coordenadas especificadas y del tamaño especificado. Un sub-mapa de bits es un mapa de bits que comparte memoria de dibujo con un mapa de bits preexistente (padre), pero posiblemente con un tamaño y configuraciones de recorte diferentes.

El sub-mapa de bits puede originarse fuera o extenderse más allá del mapa de bits padre.

Vea la discusión en al_get_backbuffer(3) sobre el uso de sub-mapas de bits del búfer de reserva.

Se ignoran los rectángulos de recorte del mapa de bits padre.

Si un sub-mapa de bits no se pudo crear o no se pudo crear, se devuelve NULL.

Cuando haya terminado de usar el sub-mapa de bits, debe llamar a al_destroy_bitmap(3) en él para liberar cualquier recurso asignado para él.

Tenga en cuenta que destruir los padres de los sub-mapas de bits no destruirá los sub-mapas de bits; en cambio, los sub-mapas de bits se vuelven inválidos y ya no deben usarse para dibujar; sin embargo, aún deben destruirse con al_destroy_bitmap(3). No importa si destruye un sub-mapa de bits antes o después de su padre.
