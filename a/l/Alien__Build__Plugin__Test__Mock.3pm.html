Este plugin se utiliza para probar los plugins de Alien::Build. Normalmente solo deseas probar una o dos fases en un alienfile para tu plugin, pero aun así necesitas tener un alienfile completamente formado que contenga todas las fases requeridas. Este plugin te permite completar las demás fases con los hooks apropiados. Esto es generalmente mejor que usar plugins reales, los cuales pueden introducir requisitos dinámicos adicionales en

los que no quieres confiar en el momento de la prueba.
