NOMBRE

al_load_audio_stream_f - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_AUDIO_STREAM *al_load_audio_stream_f(ALLEGRO_FILE* fp, const char *ident,
   size_t buffer_count, unsigned int samples)

DESCRIPCIÓN

Carga un archivo de audio desde un stream de ALLEGRO_FILE(3) según sea necesario.

A diferencia de los streams normales, el devuelto por esta función no necesita ser alimentado por el usuario; la biblioteca leerá automáticamente más del archivo según sea necesario. El stream contendrá buffer_count buffers con samples muestras.

El tipo de archivo se determina por el parámetro `ident' pasado, que es una extensión de nombre de archivo que incluye el punto inicial.

El stream de audio comenzará en estado de reproducción. Debería adjuntarse a una voz o mezclador para generar alguna salida. Ver ALLEGRO_AUDIO_STREAM(3) para más detalles.

Devuelve el stream en caso de éxito, NULL en caso de fallo. En caso de éxito, el archivo se considera propiedad del stream de audio y se cerrará cuando el stream de audio se destruya. En caso de fallo, el archivo se cerrará.

Nota: la biblioteca allegro_audio no soporta ningún formato de archivo de audio por defecto. Debe usar el addon allegro_acodec o registrar su propio manejador de formato.

VER TAMBIÉN
