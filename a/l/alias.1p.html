ALIAS(1P) Manual del Programador POSIX ALIAS(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

alias — definir o mostrar alias

SINOPSIS

alias [nombre-alias[=cadena]...]

DESCRIPCIÓN

La utilidad alias creará o redefinirá definiciones de alias o escribirá los valores de las definiciones de alias existentes en la salida estándar. Una definición de alias proporciona un valor de cadena que reemplazará un nombre de comando cuando se encuentre; véase Sección 2.3.1, Sustitución de Alias.

Una definición de alias afectará al entorno de ejecución del shell actual y a los entornos de ejecución de los subshells del shell actual. Cuando se usa como se especifica en este volumen de POSIX.1‐2017, la definición de alias no afectará al proceso padre del shell actual ni a ninguna utilidad invocada por el shell; véase Sección 2.12, Entorno de Ejecución del Shell.

OPCIONES

Ninguna.

OPERANDOS

Se admitirán los siguientes operandos:

nombre-alias
Escribe la definición del alias en la salida estándar.
nombre-alias=cadena

Asigna el valor de cadena al alias nombre-alias.

Si no se proporcionan operandos, se escribirán todas las definiciones de alias en la salida estándar.

ENTRADA ESTÁNDAR

No se usa.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de alias:

LANG
Proporciona un valor por defecto para las variables de internacionalización que no están definidas o son nulas. (Véase el volumen de Definiciones Básicas de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de configuración regional.)
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la configuración regional para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a múltiples bytes en los argumentos).
LC_MESSAGES

Determina la configuración regional que debe usarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Por defecto.

SALIDA ESTÁNDAR

El formato para mostrar alias (cuando no se especifican operandos o solo se especifican operandos nombre ) será:

"%s=%s\n", nombre, valor

La cadena valor se escribirá con el comillado apropiado para que sea adecuada para ser reintroducida en el shell. Véase la descripción del comillado del shell en Sección 2.2, Comillado.

ERROR ESTÁNDAR

El error estándar se usará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

0
Finalización exitosa.
>0
Uno de los operandos nombre especificados no tenía una definición de alias, o se produjo un error.

USO DE LA APLICACIÓN

Ninguno.

EJEMPLOS

1.
Crear un alias corto para un comando ls de uso común:
alias lf="ls -CF"
2.
Crear un comando simple "repetir" para repetir entradas anteriores en el archivo de historial de comandos:
alias r='fc -s'
3.
Usar unidades de 1K para du:
alias du=du\ -k
4.
Configurar nohup para que pueda manejar un argumento que sea en sí mismo un nombre de alias:
alias nohup="nohup "

JUSTIFICACIÓN

La descripción de alias se basa en implementaciones históricas de KornShell. Existen diferencias conocidas entre esta y la C shell. Se adoptó la versión de KornShell para ser consistente con todas las demás características de KornShell en este volumen de POSIX.1‐2017, como la edición de línea de comandos.

Dado que alias afecta al entorno de ejecución del shell actual, generalmente se proporciona como un comando interno regular del shell.

Las versiones históricas de KornShell han permitido que los alias se exporten a scripts invocados por el mismo shell. Esto se activa con el indicador alias -x ; este volumen de POSIX.1‐2017 lo permite solo cuando se usa una extensión explícita como -x . Los desarrolladores del estándar consideraron que los alias eran de uso principalmente para usuarios interactivos y que normalmente no deberían afectar a scripts de shell llamados por estos usuarios; las funciones están disponibles para tales scripts.

Las versiones históricas de KornShell no escribían los alias de una manera comillada adecuada para la reintroducción en el shell, pero este volumen de POSIX.1‐2017 ha hecho de esto un requisito para todas las salidas similares. Por lo tanto, se eligió la consistencia sobre este detalle de la práctica histórica.
