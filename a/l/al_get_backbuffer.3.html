NOMBRE

al_get_backbuffer - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
ALLEGRO_BITMAP *al_get_backbuffer(ALLEGRO_DISPLAY *display)

DESCRIPCIÓN

Devuelve un bitmap especial que representa el búfer posterior (back-buffer) de la pantalla.

Se debe tener cuidado al usar el bitmap del búfer posterior (y sus sub-bitmaps) como bitmap de origen (por ejemplo, como argumento de bitmap para al_draw_bitmap(3)). Solo las operaciones no transformadas se aceleran por hardware. Estas consisten en al_draw_bitmap(3) y al_draw_bitmap_region(3) cuando la transformación actual es la identidad. Si la transformación no es la identidad, o se utiliza alguna otra operación de dibujo, la llamada se dirigirá a las rutinas de bitmap en memoria, que son lentas. Si necesita que esas operaciones se aceleren, primero copie una región del búfer posterior en un bitmap temporal (a través de al_draw_bitmap(3) y al_draw_bitmap_region(3)), y luego use ese bitmap temporal como el bitmap de origen.
