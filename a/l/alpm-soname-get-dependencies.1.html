NOMBRE

alpm-soname get-dependencies - Obtener dependencias

SINOPSIS

alpm-soname get-dependencies [-l|--lookup-dir] [-v|--verbose]... [-o|--output-format] [-q|--quiet]... [-p|--pretty] [-h|--help] [-V|--version] <PAQUETE>

DESCRIPCIÓN

Obtener dependencias

OPCIONES

-l, --lookup-dir <DIRECTORIO_BUSQUEDA> [por defecto: lib:/usr/lib]
El directorio de búsqueda para bibliotecas compartidas en formato `<prefijo>:<directorio>`
-v, --verbose
Aumentar la verbosidad del registro
-o, --output-format <FORMATO_SALIDA> [por defecto: plain]
El formato de salida

Valores posibles:

  • plain: El formato de salida de texto plano (línea por línea)
  • json: El formato de salida JSON
-q, --quiet
Disminuir la verbosidad del registro
-p, --pretty
Imprimir la salida de forma bonita

No tiene efecto si el formato de salida no se puede imprimir de forma bonita.

-h, --help
Imprimir ayuda (ver un resumen con '-h')
-V, --version
Imprimir versión
<PAQUETE>
El paquete a inspeccionar

VERSIÓN

v0.3.0
