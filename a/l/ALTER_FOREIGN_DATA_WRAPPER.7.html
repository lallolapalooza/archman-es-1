NOMBRE

ALTER_FOREIGN_DATA_WRAPPER - cambiar la definición de un adaptador de datos externos

SINOPSIS

ALTER FOREIGN DATA WRAPPER nombre
    [ HANDLER función_manejadora | NO HANDLER ]
    [ VALIDATOR función_validadora | NO VALIDATOR ]
    [ OPTIONS ( [ ADD | SET | DROP ] opción ['valor'] [, ... ]) ]
ALTER FOREIGN DATA WRAPPER nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER FOREIGN DATA WRAPPER nombre RENAME TO nuevo_nombre

DESCRIPCIÓN

ALTER FOREIGN DATA WRAPPER cambia la definición de un adaptador de datos externos. La primera forma del comando cambia las funciones de soporte o las opciones genéricas del adaptador de datos externos (se requiere al menos una cláusula). La segunda forma cambia el propietario del adaptador de datos externos.

Solo los superusuarios pueden modificar adaptadores de datos externos. Además, solo los superusuarios pueden ser propietarios de adaptadores de datos externos.

PARÁMETROS

nombre

El nombre de un adaptador de datos externos existente.

HANDLER función_manejadora

Especifica una nueva función manejadora para el adaptador de datos externos.

NO HANDLER

Se utiliza para especificar que el adaptador de datos externos ya no debe tener una función manejadora.

Tenga en cuenta que las tablas externas que utilizan un adaptador de datos externos sin manejador no se pueden acceder.

VALIDATOR función_validadora

Especifica una nueva función validadora para el adaptador de datos externos.

Tenga en cuenta que es posible que las opciones preexistentes del adaptador de datos externos, o de los servidores dependientes, mapeos de usuarios o tablas externas, no sean válidas según el nuevo validador. PostgreSQL no verifica esto. Es responsabilidad del usuario asegurarse de que estas opciones sean correctas antes de usar el adaptador de datos externos modificado. Sin embargo, todas las opciones especificadas en este comando ALTER FOREIGN DATA WRAPPER se verificarán utilizando el nuevo validador.

NO VALIDATOR

Se utiliza para especificar que el adaptador de datos externos ya no debe tener una función validadora.

OPTIONS ( [ ADD | SET | DROP ] opción ['valor'] [, ... ] )

Cambia las opciones para el adaptador de datos externos. ADD, SET y DROP especifican la acción a realizar. Se asume ADD si no se especifica explícitamente ninguna operación. Los nombres de las opciones deben ser únicos; los nombres y valores también son validados usando la función validadora del adaptador de datos externos, si existe.

nuevo_propietario

El nombre de usuario del nuevo propietario del adaptador de datos externos.

nuevo_nombre

El nuevo nombre para el adaptador de datos externos.

EJEMPLOS

Cambiar el adaptador de datos externos dbi, añadir la opción foo, eliminar bar:

ALTER FOREIGN DATA WRAPPER dbi OPTIONS (ADD foo '1', DROP bar);

Cambiar el validador del adaptador de datos externos dbi a bob.myvalidator:

ALTER FOREIGN DATA WRAPPER dbi VALIDATOR bob.myvalidator;

COMPATIBILIDAD

ALTER FOREIGN DATA WRAPPER cumple con ISO/IEC 9075-9 (SQL/MED), excepto que las cláusulas HANDLER, VALIDATOR, OWNER TO y RENAME son extensiones.

VER TAMBIÉN

CREATE FOREIGN DATA WRAPPER (CREATE_FOREIGN_DATA_WRAPPER(7)), DROP FOREIGN DATA WRAPPER (DROP_FOREIGN_DATA_WRAPPER(7))
