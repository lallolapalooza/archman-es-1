NOMBRE

alpm-buildinfo-validate - Valida un archivo BUILDINFO

SINOPSIS

alpm-buildinfo validate [-s|--schema] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Valida un archivo BUILDINFO

Valida un archivo BUILDINFO de acuerdo con un esquema. Si el archivo puede ser validado, el programa sale sin ninguna salida y con un código de retorno de 0. Si el archivo no puede ser validado, se emite un error en stderr y el programa sale con un código de salida distinto de cero.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema BUILDINFO a utilizar.

Si no se proporciona ninguna versión de esquema, se deducirá del propio archivo.

-h, --help
Imprime la ayuda (ve un resumen con '-h')
[ARCHIVO]
Proporciona el archivo a leer
