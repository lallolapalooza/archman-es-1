NOMBRE

Alien::Build::Plugin::Fetch::LocalDir - Plugin para obtener un directorio local

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
share {
  start_url 'patch/libfoo-1.00/';
  plugin 'Fetch::LocalDir';
};

DESCRIPCIÓN

Nota: en la mayoría de los casos querrás usar Alien::Build::Plugin::Download::Negotiate en su lugar. Este elige el plugin de obtención apropiado según tu plataforma y entorno. En algunos casos, puede que necesites usar este plugin directamente en su lugar.

Este plugin de obtención obtiene archivos del sistema de archivos local. Es principalmente útil si tienes la intención de empaquetar el código fuente con tu Alien. Si estás empaquetando archivos tar, consulta Alien::Build::Plugin::Fetch::Local.

PROPIEDADES

root

El directorio desde el cual la URL de inicio debe ser relativa. El valor predeterminado suele ser razonable.

ssl

Esta propiedad es para compatibilidad con otros plugins de obtención, pero no se utiliza.
