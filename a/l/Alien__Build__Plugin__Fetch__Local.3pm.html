NOMBRE

Alien::Build::Plugin::Fetch::Local - Plugin para obtener un archivo local

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
share {
  start_url 'patch/libfoo-1.00.tar.gz';
  plugin 'Fetch::Local';
};

DESCRIPCIÓN

Nota: en la mayoría de los casos querrás usar Alien::Build::Plugin::Download::Negotiate en su lugar. Este elige el plugin de obtención apropiado según tu plataforma y entorno. En algunos casos, es posible que necesites usar este plugin directamente en su lugar.

Este plugin de obtención obtiene archivos del sistema de archivos local. Es principalmente útil si tienes la intención de agrupar paquetes (como archivos tar o zip) con tu Alien. Si tienes la intención de agrupar un árbol de fuentes, usa Alien::Build::Plugin::Fetch::LocalDir.

PROPIEDADES

url

La URL inicial a obtener. Puede ser una URL de estilo "file://", o simplemente la ruta en el sistema local.

root

El directorio desde el cual la URL debe ser relativa. El valor predeterminado suele ser razonable.

ssl

Esta propiedad es para compatibilidad con otros plugins de obtención, pero no se utiliza.
