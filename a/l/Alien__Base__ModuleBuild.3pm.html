Alien::Base::ModuleBuild(3pm) Documentación de Perl contribuida por el usuario Alien::Base::ModuleBuild(3pm)

NOMBRE

Alien::Base::ModuleBuild - Una subclase de Module::Build para construir módulos Alien:: y sus bibliotecas

VERSIÓN

versión 1.17

SINOPSIS

En tu Build.PL:

use Alien::Base::ModuleBuild;

my $builder = Alien::Base::ModuleBuild->new(
  module_name => 'Alien::MyLibrary',

  configure_requires => {
    'Alien::Base::ModuleBuild' => '0.005',
    'Module::Build' => '0.28'
  },
  requires => {
    'Alien::Base' => '0.005',
  },

  alien_name => 'mylibrary', # el nombre pkg-config si quieres
                             # usar pkg-config para descubrir
                             # la versión del sistema de mylibrary

  alien_repository => {
    protocol => 'https',
    host     => 'myhost.org',
    location => '/path/to/tarballs',
    pattern  => qr{^mylibrary-([0-9\.]+)\.tar\.gz$},
  },

  # esto es el valor por defecto:
  alien_build_commands => [
    "%c --prefix=%s", # %c es una versión independiente de la plataforma de ./configure
    "make",
  ],

  # esto es el valor por defecto para la instalación:
  alien_install_commands => [
    "make install",
  ],

  alien_isolate_dynamic => 1,
);

DESCRIPCIÓN

NOTA: Por favor, considera para el nuevo desarrollo de Aliens que uses Alien::Build y alienfile en su lugar. Como este módulo, funcionan con Alien::Base. A diferencia de este módulo, son más fáciles de personalizar y manejan mejor una serie de casos especiales. Para un buen punto de partida, consulta Alien::Build::Manual::AlienAuthor. Aunque el equipo de Alien-Base / Alien-Build continuará manteniendo este módulo (seguiremos corrigiendo errores donde sea apropiado), no estamos añadiendo ninguna nueva característica a este módulo.

Esta es una subclase de Module::Build, que con Alien::Base permite la fácil creación de distribuciones Alien. Este módulo se usa durante el paso de construcción de tu distribución. Cuando se configura correctamente, hará

uso de pkg-config para encontrar y usar la versión del sistema de la biblioteca
descargar, construir e instalar la biblioteca si el sistema no la proporciona

MÉTODOS

alien_check_installed_version

[versión 0.001]

my $version = $abmb->alien_check_installed_version;

Esta función determina si la biblioteca ya está instalada como parte del sistema operativo, y devuelve la versión como una cadena de texto. Si no se puede detectar, debe devolver una lista vacía.

La implementación por defecto depende de "pkg-config", pero probablemente querrás sobreescribir esto con tu propia implementación si el paquete que estás construyendo no usa "pkg-config".

alien_check_built_version

[versión 0.006]

my $version = $amb->alien_check_built_version;

Esta función determina la versión de la biblioteca después de que haya sido construida desde el código fuente. Esta función solo se llama si la versión del sistema operativo no se puede encontrar y el paquete se construye con éxito. La versión se devuelve en caso de éxito. Si la versión no se puede detectar, debe devolver una lista vacía. Ten en cuenta que el fallo al detectar una versión se considera un fallo y la acción correspondiente "./Build" fallará.

Cualquier cadena de texto es válida como versión en lo que a Alien::Base le concierne. El valor más útil sería un número o un decimal con puntos que la mayoría de los desarrolladores de software reconozcan y que las herramientas de software puedan diferenciar. En algunos casos, los paquetes no tendrán un número de versión claro, en cuyo caso la cadena "unknown" sería una elección razonable.

La implementación por defecto depende de "pkg-config"y otras heurísticas, pero probablemente querrás sobreescribir esto con tu propia implementación si el paquete que estás construyendo no usa "pkg-config".

Cuando se llama a este método, el directorio de trabajo actual será la raíz de la construcción.

Si ves un mensaje de error como este:

Library looks like it installed, but no version was determined

Después de que el paquete se construye desde el código fuente, probablemente necesites proporcionar una implementación para este método.

alien_extract_archive

[versión 0.024]

my $dir = $amb->alien_extract_archive($filename);

Esta función desempaqueta el archivo dado y devuelve el directorio que contiene los archivos desempaquetados.

La implementación por defecto depende de Archive::Extract, que es capaz de manejar la mayoría de los formatos comunes. Para manejar otros formatos o archivos que requieran un tratamiento especial, puedes querer sobreescribir este método.

alien_do_system

[versión 0.024]

my %result = $amb->alien_do_system($cmd)

Similar a do_system de Module::Build, también establece la ruta y varias variables de entorno de acuerdo con la configuración del objeto (es decir, "alien_bin_requires") y realiza la interpolación de los patrones descritos en "COMMAND INTERPOLATION" en Alien::Base::ModuleBuild::API.

Devuelve un conjunto de pares clave-valor incluyendo "stdout", "stderr", "success" y "command".

alien_do_commands

$amb->alien_do_commands($phase);

Ejecuta los comandos para la fase dada.

alien_interpolate

my $string = $amb->alien_interpolate($string);

Toma la cadena de texto de entrada e interpola los resultados.

alien_install_network

[versión 1.16]

my $bool = $amb->alien_install_network;

Devuelve verdadero si se permite descargar el código fuente de Internet. Esto es verdadero a menos que "ALIEN_INSTALL_NETWORK" esté definido y sea falso.

alien_download_rule

[versión 1.16]

my $rule = $amb->alien_download_rule;

Esto devolverá uno de "warn", "digest", "encrypt", "digest_or_encrypt" o "digest_and_encrypt". Esto se basa en la variable de entorno "ALIEN_DOWNLOAD_RULE" .

GUÍA DE LA DOCUMENTACIÓN

La documentación para "Module::Build" está dividida en secciones:

Uso general (Module::Build)
Este es el documento de aterrizaje para la clase padre de Alien::Base::ModuleBuild. Describe el uso básico y la información de fondo. Su propósito principal es ayudar al usuario que quiere aprender a invocar y controlar los scripts "Module::Build" desde la línea de comandos.

También enumera la documentación adicional para su uso. Los usuarios y autores de módulos Alien:: deberían familiarizarse con estos documentos. Module::Build::API es de particular importancia para los autores.

Uso específico de Alien (Alien::Base::ModuleBuild)
Este es el documento que estás leyendo actualmente.
Referencia de autoría (Alien::Base::Authoring)
Este documento describe la estructura y/oorganización de "Alien::Base" proyectos basados en, más allá de lo contenido en "Module::Build::Authoring", y los conceptos relevantes necesarios por los autores que escriben Build.PL scripts para una distribución o controlando "Alien::Base::ModuleBuild" procesos programáticamente.

Tenga en cuenta que como contiene información tanto para las fases de construcción como de uso de los proyectos Alien::Base, se encuentra en el espacio de nombres superior.

Referencia de la API (Alien::Base::ModuleBuild::API)
Esta es una referencia de la "Alien::Base::ModuleBuild" API más allá de lo contenido en "Module::Build::API".
Uso del Alien resultante (Alien::Build::Manual::AlienUser)
Una vez que tenga un Alien, usted o sus usuarios pueden consultar este manual para saber cómo usarlo. En general, debería tener información de uso útil en el POD de su Alien, pero algunos autores eligen dirigir a sus usuarios a este manual en su lugar.
Uso de Alien::Build en su lugar (Alien::Build::Manual)
Como se mencionó al principio, se le anima a usar el sistema Alien::Build y alienfile en su lugar. Este manual es un punto de partida para la otra documentación de Alien::Build.

ENTORNO

ALIEN_ARCH
Establezca a un valor verdadero para instalar en un directorio específico de la arquitectura.
ALIEN_DOWNLOAD_RULE
Esto controla las opciones de seguridad para la obtención de paquetes alienizados a través de Internet. Los valores legales son:
"warn"
Advertir si el paquete está sin cifrar o carece de un resumen. Actualmente este es el valor predeterminado, pero cambiará en un futuro cercano.
"digest"
La obtención no ocurrirá a menos que haya un resumen para el paquete alienizado.
"encrypt"
La obtención no ocurrirá a menos que sea a través de un protocolo cifrado como "https", o si el paquete está incluido con el Alien.
"digest_or_encrypt"
La obtención solo ocurrirá si el paquete alienizado tiene una firma criptográfica de resumen, o si se usa un protocolo cifrado como "https" , o si el paquete está incluido con el Alien. Este será el valor predeterminado en un futuro cercano.
"digest_and_encrypt"
La obtención solo ocurrirá si el paquete alienizado tiene una firma criptográfica de resumen, y se obtiene a través de un protocolo seguro (como "https"). Los paquetes incluidos también se consideran obtenidos a través de un protocolo seguro, pero aún requerirán un resumen.
ALIEN_FORCE
Omite la verificación de una versión instalada y fuerza la reinstalación del objetivo Alien.
ALIEN_INSTALL_NETWORK
Si es verdadero (el valor predeterminado si no está definido), se permitirán las instalaciones de red. Establezca a 0 u otro valor falso para desactivar las instalaciones de red.
ALIEN_INSTALL_TYPE
Establezca a "share" o "system" para anular el tipo de instalación. Establezca a "default" o no establezca nada para restaurar el valor predeterminado.
ALIEN_VERBOSE
Habilita la salida detallada de M::B::do_system.
ALIEN_${MODULENAME}_REPO_${PROTOCOL}_${KEY}
Anula $KEY en la configuración del repositorio del módulo dado que coincida con $PROTOCOL$. Por ejemplo, "ALIEN_OPENSSL_REPO_FTP_HOST=ftp.example.com".
