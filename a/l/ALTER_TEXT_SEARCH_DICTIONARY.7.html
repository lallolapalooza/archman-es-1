NOMBRE

ALTER_TEXT_SEARCH_DICTIONARY - cambiar la definición de un diccionario de búsqueda de texto

SINOPSIS

ALTER TEXT SEARCH DICTIONARY nombre (
    opción [ = valor ] [, ... ]
)
ALTER TEXT SEARCH DICTIONARY nombre RENAME TO nuevo_nombre
ALTER TEXT SEARCH DICTIONARY nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER TEXT SEARCH DICTIONARY nombre SET SCHEMA nuevo_esquema

DESCRIPCIÓN

ALTER TEXT SEARCH DICTIONARY cambia la definición de un diccionario de búsqueda de texto. Puede cambiar las opciones específicas de la plantilla del diccionario, o cambiar el nombre o propietario del diccionario.

Debe ser el propietario del diccionario para usar ALTER TEXT SEARCH DICTIONARY.

PARÁMETROS

nombre

El nombre (opcionalmente calificado con esquema) de un diccionario de búsqueda de texto existente.

opción

El nombre de una opción específica de la plantilla que se establecerá para este diccionario.

valor

El nuevo valor a usar para una opción específica de la plantilla. Si se omiten el signo igual y el valor, se elimina cualquier configuración previa para la opción del diccionario, permitiendo que se use la predeterminada.

nuevo_nombre

El nuevo nombre del diccionario de búsqueda de texto.

nuevo_propietario

El nuevo propietario del diccionario de búsqueda de texto.

nuevo_esquema

El nuevo esquema para el diccionario de búsqueda de texto.

Las opciones específicas de la plantilla pueden aparecer en cualquier orden.

EJEMPLOS

El siguiente comando de ejemplo cambia la lista de palabras vacías para un diccionario basado en Snowball. Otros parámetros permanecen sin cambios.

ALTER TEXT SEARCH DICTIONARY my_dict ( StopWords = newrussian );

El siguiente comando de ejemplo cambia la opción de idioma a neerlandés y elimina por completo la opción de palabras vacías.

ALTER TEXT SEARCH DICTIONARY my_dict ( language = dutch, StopWords );

El siguiente comando de ejemplo "actualiza" la definición del diccionario sin cambiar realmente nada.

ALTER TEXT SEARCH DICTIONARY my_dict ( dummy );

(La razón por la que esto funciona es que el código de eliminación de opciones no se queja si no existe tal opción.) Este truco es útil al cambiar archivos de configuración para el diccionario: el ALTER forzará a las sesiones de base de datos existentes a releer los archivos de configuración, lo cual de otra manera nunca harían si los hubieran leído anteriormente.

COMPATIBILIDAD

No existe una sentencia ALTER TEXT SEARCH DICTIONARY en el estándar SQL.

VER TAMBIÉN

CREATE TEXT SEARCH DICTIONARY (CREATE_TEXT_SEARCH_DICTIONARY(7)), DROP TEXT SEARCH DICTIONARY (DROP_TEXT_SEARCH_DICTIONARY(7))
