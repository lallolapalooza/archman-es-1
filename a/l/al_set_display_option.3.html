al_set_display_option(3) Manual de funciones de la biblioteca al_set_display_option(3)

NOMBRE

al_set_display_option - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_set_display_option(ALLEGRO_DISPLAY *display, int option, int value)

DESCRIPCIÓN

Cambia una opción que se estableció previamente para una pantalla. Después de que se crean las pantallas, adoptan las opciones establecidas con al_set_new_display_option(3). Llamar a al_set_new_display_option(3) posteriormente solo cambia las opciones para las pantallas recién creadas y no afecta a las opciones de las pantallas ya creadas. al_set_display_option(3) permite cambiar algunos de estos valores. No todas las opciones de pantalla se pueden cambiar o cambiarlas no tendrá ningún efecto. Cambiar opciones distintas de las enumeradas a continuación no está definido.

•
ALLEGRO_SUPPORTED_ORIENTATIONS - Esto se puede cambiar para permitir orientaciones nuevas o restringir las previamente habilitadas de la pantalla/dispositivo. Consulte al_set_new_display_option(3) para obtener más información sobre esta opción.

DESDE

5.1.5
