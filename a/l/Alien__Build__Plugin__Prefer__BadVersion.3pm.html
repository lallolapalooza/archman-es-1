NOMBRE

Alien::Build::Plugin::Prefer::BadVersion - Plugin para filtrar versiones malas conocidas

VERSIÓN

versión 2.84

SINOPSIS

use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3';

DESCRIPCIÓN

Este plugin te permite filtrar fácilmente versiones de bibliotecas malas conocidas en una instalación compartida. No afecta en absoluto a una instalación del sistema. Necesitas un plugin Prefer que filtre y ordene archivos primero. Puedes especificar el filtro de una de las tres maneras:

como una cadena
Filtra cualquier archivo que coincida con la versión dada. 
use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3';
como un array
Filtra todos los archivos que coincidan con alguna de las versiones dadas. 
use alienfile;
plugin 'Prefer::BadVersion' => [ '1.2.3', '1.2.4' ];
como una referencia a código
Filtra cualquier archivo que devuelva un valor verdadero. 
use alienfile;
plugin 'Prefer::BadVersion' => sub {
  my($file) = @_;
  $file->{version} eq '1.2.3'; # igual que la versión de cadena anterior
};

Este plugin también se puede usar para filtrar versiones malas conocidas de una biblioteca solo en una plataforma. Por ejemplo, si sabes que la versión 1.2.3 es mala en Windows, pero aceptable en otras plataformas:

use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3' if $^O eq 'MSWin32';

PROPIEDADES

filter

Filtra entradas que coincidan con el filtro.

ADVERTENCIAS

Si estás usando el modo de cadena o de array, necesitas un plugin Prefer existente que establezca el número de versión para cada candidato a archivo, como Alien::Build::Plugin::Prefer::SortVersions.

A menos que quieras excluir la última versión de una instalación compartida, este plugin no es realmente muy útil. No tiene ningún efecto en las instalaciones del sistema, lo cual puede no ser obvio al principio.
