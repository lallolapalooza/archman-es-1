NOMBRE

alpm-pkginfo-validate - Valida un archivo PKGINFO

SINOPSIS

alpm-pkginfo validate [-s|--schema] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Valida un archivo PKGINFO

Valida un archivo PKGINFO de acuerdo con un esquema. Si el archivo se puede validar, el programa sale sin ninguna salida y con un código de retorno de 0. Si el archivo no se puede validar, se emite un error en stderr y el programa sale con un código de salida distinto de cero.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema PKGINFO a usar.

Si no se proporciona ninguna versión de esquema, esta se deducirá del propio archivo.

-h, --help
Imprime la ayuda (ver un resumen con '-h')
[ARCHIVO]
Una ruta de archivo de entrada opcional para leer

Si no se especifica ningún archivo, se lee desde la entrada estándar y se espera que contenga datos PKGINFO para validar.
