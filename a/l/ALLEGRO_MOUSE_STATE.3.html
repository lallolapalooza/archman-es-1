NOMBRE

ALLEGRO_MOUSE_STATE - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef struct ALLEGRO_MOUSE_STATE ALLEGRO_MOUSE_STATE;

DESCRIPCIÓN

Campos públicos (solo lectura):

•
x - posición x del ratón
•
y - posición y del ratón
•
w, z - posición de la rueda del ratón (ámbito 2D)
•
display - la pantalla en la que se encuentra el ratón (las coordenadas son relativas a esta)
•
buttons - campo de bits de los botones del ratón

El bit cero se establece si el botón primario del ratón está presionado, el bit uno se establece si el botón secundario del ratón está presionado, y así sucesivamente.

•
pressure - presión, que oscila entre 0.0 y 1.0
