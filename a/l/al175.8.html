NOMBRE

al175 - Controlador para modelos de SAI Eltek con módulo de alarma AL175

SINOPSIS

al175 -h

al175 -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas de hardware del controlador al175. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Se sabe que el controlador al175 funciona con los siguientes SAI:

•Eltek MPSU4000 con módulo de alarma AL175

También puede funcionar con otros SAI equipados con el módulo de alarma AL175, pero no han sido probados.

El AL175 debe configurarse para operar en modo COMLI. Consulte la documentación proporcionada con su hardware sobre cómo hacerlo.

ARGUMENTOS ADICIONALES

Este controlador no admite configuraciones adicionales en el archivo ups.conf(5).

COMANDOS INSTANTÁNEOS

Este controlador admite algunos comandos adicionales (consulte upscmd(8)):

test.battery.start

Inicia una prueba de batería.

test.battery.stop

Detiene una prueba de batería.

VARIABLES

Además del estado, este controlador lee el estado del SAI en las siguientes variables:

•ups.test.result
•output.voltage.nominal
•output.current
•battery.voltage.nominal
•battery.current
•battery.temperature
•input.transfer.boost.low

PROBLEMAS Y ERRORES CONOCIDOS

•El apagado no está soportado. CORREGIR
•El controlador fue rediseñado para cumplir con los criterios de calidad del código del proyecto, sin pruebas en hardware real. Pueden haberse introducido algunos errores.
