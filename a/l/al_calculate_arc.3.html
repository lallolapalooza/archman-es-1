al_calculate_arc(3) Manual de funciones de biblioteca al_calculate_arc(3)

NOMBRE

al_calculate_arc - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
void al_calculate_arc(float* dest, int stride, float cx, float cy,
   float rx, float ry, float start_theta, float delta_theta, float thickness,
   int num_points)

DESCRIPCIÓN

Cuando thickness <= 0 esta función calcula las posiciones de num_points puntos espaciados regularmente en un arco elíptico. Cuando thickness > 0 esta función calcula dos conjuntos de puntos, obtenidos de la siguiente manera: el primer conjunto se obtiene tomando los puntos calculados en el caso thickness <= 0 y desplazándolos thickness / 2 hacia afuera, en una dirección perpendicular a la curva del arco. El segundo conjunto es el mismo, pero desplazado thickness / 2 hacia adentro en relación con el arco. Los dos conjuntos de puntos se entrelazan en el búfer de destino (es decir, el primer par de puntos será colineal con el centro del arco, el primer punto del par estará más lejos del centro que el segundo punto; el siguiente par también será colineal, pero en un ángulo diferente y así sucesivamente).

El búfer de destino dest se interpreta como un conjunto de pares de flotantes espaciados regularmente, cada par contiene las coordenadas del punto correspondiente en el arco. Los dos flotantes del par son adyacentes, y la distancia (en bytes) entre las direcciones del primer flotante de dos pares sucesivos es stride. Por ejemplo, si tiene una matriz compacta de flotantes sin espacios entre pares, entonces stride será exactamente 2 * sizeof(float).

Ejemplo con thickness <= 0:

const int num_points = 4;
float points[num_points][2];
al_calculate_arc(&points[0][0], 2 * sizeof(float), 0, 0, 10, 10, 0, ALLEGRO_PI / 2, 0, num_points);
assert((int)points[0][0] == 10);
assert((int)points[0][1] == 0);
assert((int)points[num_points - 1][0] == 0);
assert((int)points[num_points - 1][1] == 10);

Ejemplo con thickness > 0:

const int num_points = 4;
float points[num_points * 2][2];
al_calculate_arc(&points[0][0], 2 * sizeof(float), 0, 0, 10, 10, 0, ALLEGRO_PI / 2, 2, num_points);
assert((int)points[0][0] == 11);
assert((int)points[0][1] == 0);
assert((int)points[1][0] == 9);
assert((int)points[1][1] == 0);
assert((int)points[(num_points - 1) * 2][0] == 0);
assert((int)points[(num_points - 1) * 2][1] == 11);
assert((int)points[(num_points - 1) * 2 + 1][0] == 0);
assert((int)points[(num_points - 1) * 2 + 1][1] == 9);

Parámetros:

•
dest - El búfer de destino
•
stride - Distancia (en bytes) entre el inicio de pares de puntos sucesivos
•
cx, cy - Centro del arco
•
rx, ry - Radios del arco
•
start_theta - El ángulo inicial desde el cual se calcula el arco en radianes
•
delta_theta - El rango angular del arco en radianes (pasa un número negativo para cambiar la dirección)
•
thickness - Grosor del arco
•
num_points - El número de puntos a calcular
