al_load_sample_f(3) Manual de funciones de la biblioteca al_load_sample_f(3)

NOMBRE

al_load_sample_f - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_SAMPLE *al_load_sample_f(ALLEGRO_FILE* fp, const char *ident)

DESCRIPCIÓN

Carga un archivo de audio desde un flujo ALLEGRO_FILE(3) en un ALLEGRO_SAMPLE(3). El tipo de archivo se determina mediante el parámetro `ident' pasado, que es la extensión de un nombre de archivo que incluye el punto inicial.

Tenga en cuenta que esto almacena todo el archivo en memoria a la vez, lo que puede llevar tiempo. Para leer el archivo según sea necesario, use al_load_audio_stream_f(3) o al_play_audio_stream_f(3).

Devuelve la muestra en caso de éxito, NULL en caso de fallo. El archivo permanece abierto después.

Nota: la biblioteca allegro_audio no admite ningún formato de archivo de audio por defecto. Debe utilizar el complemento allegro_acodec o registrar su propio manejador de formatos.

VER TAMBIÉN

al_register_sample_loader_f(3), al_init_acodec_addon(3)
