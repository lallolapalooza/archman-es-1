DESCRIPCIÓ

N

Este módulo proporciona herramientas para construir dependencias externas (no CPAN) para CPAN. Está diseñado principalmente para ser utilizado en el momento de la instalación de un cliente CPAN, y trabajar en estrecha colaboración con Alien::Base, que se utiliza en tiempo de

ejecución.

Esta es la documentación detallada de la clase Alien::Build. Si estás empezando, probablemente quieras hacerlo desde uno de estos

documentos:

ecosistema.

.

Si te preocupa que los Aliens puedan estar descargando tarballs de internet, entonces este
es el lugar para ti. Aquí se discutirán algunos de los riesgos de descargar (realmente cua

Ten en cuenta que normalmente no crearás una instancia de Alien::Build directamente, sino que usarás una cap

PROPIEDADE

S

Hay tres propiedades principales para Alien::Build. Hay una serie de propiedades documentadas aquí con un uso específico. Ten en cuenta que estas propiedades pueden necesitar ser serializadas en algo primitivo como JSON que no soporta: expresiones regulares, referencias a código de objetos

bendecidos.

Si estás escribiendo un complemento (Alien::Build::Plugin) deberías usar un prefijo como "plugin_nombre" (donde nombre es el nombre de tu complemento) para que no interfiera con otros complementos o futuras versiones de Alien::Build. Por ejemplo, si estuvieras escribiendo "Alien::Build::Plugin::Fetch::NewProtocol", por favor usa el prefijo "plugin_fetch_newprotocol"

: 
sub init
{
  my($self, $meta) = @_;

  $meta->prop( plugin_fetch_newprotocol_foo => 'some value' );

  $meta->register_hook(
    some_hook => sub {
      my($build) = @_;
      $build->install_prop->{plugin_fetch_newprotocol_bar} = 'some other value';
      $build->runtime_prop->{plugin_fetch_newprotocol_baz} = 'and another value';
    }
  );
}

Si estás escribiendo una receta alienfile, por favor usa el prefijo "my_"

: 
use alienfile;

meta_prop->{my_foo} = 'some value';

probe sub {
  my($build) = @_;
  $build->install_prop->{my_bar} = 'some other value';
  $build->install_prop->{my_baz} = 'and another value';
}
;

Cualquier propiedad puede ser usada desde un

comando: 
probe [ 'some command %{.meta.plugin_fetch_newprotocol_foo}' ];
probe [ 'some command %{.install.plugin_fetch_newprotocol_bar}' ];
probe [ 'some command %{.runtime.plugin_fetch_newprotocol_baz}' ];
probe [ 'some command %{.meta.my_foo}' ];
probe [ 'some command %{.install.my_bar}' ];
probe [ 'some command %{.runtime.my_baz}' ]
;

Esta propiedad contiene los resúmenes criptográficos (si los hay) que deben ser usados al verificar cualquier archivo recuperado y descargado. Es una referencia a un hash donde la clave es el nombre del archivo y el valor es un arreglo referencia que contiene un par de valores, siendo el primero el algoritmo (se recomienda 'SHA256') y el segundo el resumen real.   'foo-1.01.tar.gz' => [ SHA256 => '6bbde6a7f10ae5924cf74afc26ff5b7bc4b4f9dfd85c6b534c51bd254697b9e7' ],

], };

Si se establece en verdadero (el predeterminado), se permitirá la obtención por red. Si se establece en falso, no se permitirá la obtención por red.

Lo que constituye una obtención local vs. de red se determina basándose en el "start_url" y propiedades meta "local_source". Un alienfile o plugin "podría" anular esta detección (posiblemente de manera inapropiada), por lo que esta variable no es

Si se establece en "share" o "system", anulará la lógica de detección del sistema. Si se establece en "default", usará la configuración predeterminada para el alienfile. El comportamiento de otros valores es indefinido.

Aunque la forma recomendada para que un consumidor use un Alien basado en Alien::Base es declararlo como una dependencia estática de configuración y compilación, algunos consumidores pueden preferir recurrir a usar un Alien solo cuando el propio consumidor no pueda detectar el paquete necesario. En algunos casos, el consumidor puede querer que el usuario opte por usar un Alien antes de

requerirlo.

Para mantener la interfaz consistente entre los Aliens, el consumidor del Alien de opt-in por defecto puede recurrir al Alien si la variable de entorno "ALIEN_INSTALL_TYPE" está establecida en cualquier valor. La razón es que al establecer esta variable de entorno el usuario es consciente de que los mód

ulos Alien pueden instalarse y ha indicado su consentimiento. La implementación
real de esto, por su naturaleza, tendría que estar en el módulo CPAN consumidor.
