ALLEGRO_GET_EVENT_TYPE(3) Manual de funciones de la biblioteca ALLEGRO_GET_EVENT_TYPE(3)

NOMBRE

ALLEGRO_GET_EVENT_TYPE - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
#define ALLEGRO_GET_EVENT_TYPE(a, b, c, d)   AL_ID(a, b, c, d)

DESCRIPCIÓN

Crea un identificador de tipo de evento, que es un entero de 32 bits. Normalmente, pero no necesariamente, se creará a partir de cuatro códigos de caracteres de 8 bits, por ejemplo:

#define MI_TIPO_EVENTO   ALLEGRO_GET_EVENT_TYPE('M','I','O','S')

Los ID inferiores a 1024 están reservados para Allegro o sus complementos. No uses nada inferior a ALLEGRO_GET_EVENT_TYPE(0, 0, 4, 0).

Deberías intentar que tus ID sean únicos para que no entren en conflicto con ningún código de terceros que puedas estar utilizando. Sé creativo. Numerar a partir de 1024 no es creativo.

Si necesitas múltiples identificadores, podrías definirlos así:

#define EVENTO_BASE   ALLEGRO_GET_EVENT_TYPE('M','I','O','S')
#define EVENTO_GUAU   (EVENTO_BASE + 0)
#define EVENTO_MIAU   (EVENTO_BASE + 1)
#define EVENTO_PII   (EVENTO_BASE + 2)
/* Alternativamente */
enum {
   EVENTO_GUAU = ALLEGRO_GET_EVENT_TYPE('M','I','O','S'),
   EVENTO_MIAU,
   EVENTO_PII
};
