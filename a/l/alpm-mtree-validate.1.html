NOMBRE

alpm-mtree-validate - Valida un archivo MTREE

SINOPSIS

alpm-mtree validate [-s|--schema] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Valida un archivo MTREE

Valida un archivo MTREE de acuerdo con un esquema. Si el archivo se puede validar, el programa sale sin ninguna salida y con un código de retorno de 0. Si el archivo no se puede validar, se emite un error en stderr y el programa sale con un código de salida distinto de cero.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema MTREE a usar.

Si no se proporciona ninguna versión de esquema, se deducirá del propio archivo.

Los valores válidos son ['1', '2'].

-h, --help
Imprime la ayuda (ver un resumen con '-h')
[ARCHIVO]
Un archivo opcional para leer.

Si no se proporciona ningún archivo, se utiliza la entrada estándar (stdin) en su lugar.
