DESCRIPCIÓ

N

alsaucm (Gestor de Casos de Uso de ALSA) es un programa para usar la Interfaz de Casos de Uso de ALSA http://www.alsa-project.org/alsa-doc/alsa-lib/group__ucm.html
desde la línea de

comandos.

En tarjetas de sonido complejas, configurar las rutas de audio no es trivial y los ajustes del mezclador pueden entrar en conflicto entre sí, impidiendo que la tarjeta de sonido funcione en

absoluto.

El Gestor de Casos de Uso de ALSA es un mecanismo para controlar hardware de audio complejo estableciendo una relación entre configuraciones de hardware y casos de uso significativos con los que el usuario final puede

identificarse.

El gestor de casos de uso también puede usarse para cambiar entre casos de uso cuando sea necesario, de una manera

consistente.

A un nivel más bajo, el gestor de casos de uso funciona configurando los kcontrols de la tarjeta de sonido de ALSA para cambiar el enrutamiento de audio digital y analógico del hardware y así coincidir con el caso de uso del dispositivo

solicitado.

Las configuraciones de kcontrol del gestor de casos de uso se almacenan en archivos de texto fáciles de modificar. Un caso de uso de audio puede definirse por un verbo y un parámetro de

dispositivo.

El verbo describe la acción del caso de uso, es decir, una llamada telefónica, escuchar mús

ica, grabar una conversación, etc. El dispositivo describe el hardware físico de captura y r
eproducción de audio, es decir, auriculares, auricular de teléfono, auriculares Bluetooth, etc.

ARCHIVO

S

Los archivos maestros de casos de uso para cada tarjeta de sonido soportada están en /usr/share/alsa/ucm

.

Por ejemplo, el archivo maestro de casos de uso para la tarjeta Pandaboard está en /usr/share/alsa/ucm/PandaBoard/PandaBoard.conf, este archivo lista todos los casos de uso soportados, por

ejemplo 
SectionUseCase."HiFi" {
                File "hifi"
                Comment "Play HiFi quality Music."
}
.
.
.

Cada caso de uso define un _verb, el cual está descrito en el archivo especificado en la directiva File, como se ve

arriba.

El verbo HiFi de arriba está descrito en /usr/share/alsa/ucm/PandaBoard/hifi

.

Para más detalles sobre la sintaxis de los archivos UCM, consulte el código fuente de alsa-lib:
http://git.alsa-project

.org/?p=alsa-lib.git;a=
blob;f=src/ucm/parser.c

EJEMPLOS DE

USO

Algunos comandos, como por ejemplo list _devices, solo pueden funcionar después de establecer un _verb en la misma ejecución, por ejemplo esta secuencia no

funciona: 
# alsaucm -c bytcr-r
t5640 set _verb HiFi
# alsaucm -c bytcr-
rt5640 list _devices

Sin embargo, este comando sí lo

hace: 
# alsaucm -n -b -
<<EOM open bytcr-rt
5640 set _verb HiFi
list _devices EOM

Un ejemplo de cómo establecer el dispositivo Speaker para el verbo HiFi de la tarjeta bytcr-

rt5640: 
# alsaucm -n -b -
<<EOM open bytcr
-rt5640 reset set
_verb HiFi set _e
nadev Speaker EOM
