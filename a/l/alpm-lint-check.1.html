NOMBRE

alpm-lint-check - Ejecutar lints en un archivo o directorio

SINOPSIS

alpm-lint check [-s|--scope] [-v|--verbose]... [-f|--format] [-q|--quiet]... [-p|--pretty] [-l|--level] [-c|--config] [-o|--output] [-h|--help] [DIR]

DESCRIPCIÓN

Ejecutar lints en un archivo o directorio.

Por defecto, `alpm-lint` intentará determinar el ámbito de linting actual basándose en el nombre del archivo proporcionado o en los archivos disponibles en el directorio proporcionado.

OPCIONES

-s, --scope <AMBITO>
Definir explícitamente el ámbito de linting.

El uso de esta opción anula la detección automática.

Posibles valores:

  • source-repository: Las reglas de lint con este ámbito son específicas de un [alpm-source-repo]
  • package: Las reglas de lint con este ámbito son específicas de un [alpm-package]
  • build-info: Las reglas de lint con este ámbito son específicas de un único archivo [BUILDINFO]
  • package-build: Las reglas de lint con este ámbito son específicas de un único archivo [PKGBUILD]
  • package-info: Las reglas de lint con este ámbito son específicas de un único archivo [PKGINFO]
  • source-info: Las reglas de lint con este ámbito son específicas de un único archivo [SRCINFO]
-v, --verbose
Aumentar la verbosidad del registro
-f, --format <FORMATO_VERIFICACION> [por defecto: text]
El formato de salida a utilizar.

Si no se proporciona ninguno, los problemas se imprimirán en un formato legible por humanos.

Posibles valores:

  • text: Texto legible por humanos
  • json: El formato de salida JSON
-q, --quiet
Disminuir la verbosidad del registro
-p, --pretty
Imprimir la salida de forma bonita.

No tiene efecto si el formato de salida no se puede imprimir de forma bonita.

-l, --level <NIVEL> [por defecto: warn]
El nivel de lints a considerar.

Se mostrarán todos los lints con este nivel y superiores (más graves). Si se encuentran dichos lints, el comando devolverá un código de salida distinto de cero.

Posibles valores:

  • error: Reglas de lint que conducen a errores
  • deny: Reglas de lint que conducen a denegaciones
  • warn: Reglas de lint que conducen a advertencias
  • suggest: Reglas de lint que conducen a sugerencias
-c, --config <NIVEL>
Proporcionar una ruta de configuración de lint.

Esto sobrescribe cualquier opción del archivo de configuración general del proyecto.

-o, --output <ARCHIVO>
Ruta opcional del archivo de salida. Si no se proporciona, la salida va a stdout
-h, --help
Imprimir ayuda (ver un resumen con '-h')
[DIR]
Una ruta opcional a un archivo o directorio que se va a lintar
