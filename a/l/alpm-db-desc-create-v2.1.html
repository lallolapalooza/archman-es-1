NOMBRE

alpm-db-desc-create-v2 - Crear un archivo DB desc versión 2

SINOPSIS

alpm-db-desc create v2 <--name> <--version> <--base> [--description] [--url] <--arch> <--builddate> <--installdate> <--packager> <--size> [--groups] [--reason] [--license] <--validation> [--replaces] [--depends] [--optdepends] [--conflicts] [--provides] <--xdata> [-h|--help] [SALIDA]

DESCRIPCIÓN

Crear un archivo DB desc versión 2.

OPCIONES

--name <NOMBRE>
El nombre del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_NAME.
--version <VERSIÓN>
La versión del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_VERSION.
--base <BASE>
La base del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_BASE.
--description <DESCRIPCIÓN>
La descripción del paquete.

Si no se proporciona, se usa una cadena vacía.

También se puede especificar con la variable de entorno ALPM_DB_DESC_DESC.
--url <URL>
La URL del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_URL.
--arch <ARQUITECTURA>
La arquitectura del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_ARCH.
--builddate <FECHACMP>
La fecha de compilación del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_BUILDDATE.
--installdate <FECHAINSTAL>
La fecha de instalación del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_INSTALLDATE.
--packager <EMPAQUETADOR>
El empaquetador.
También se puede especificar con la variable de entorno ALPM_DB_DESC_PACKAGER.
--size <TAMAÑO>
El tamaño instalado.
También se puede especificar con la variable de entorno ALPM_DB_DESC_SIZE.
--groups <GRUPOS>
Los grupos del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_GROUPS.
--reason <RAZÓN>
La razón de instalación del paquete.

Si no se establece, se asume una razón de instalación de "0" (instalado explícitamente).

También se puede especificar con la variable de entorno ALPM_DB_DESC_REASON.
--license <LICENCIA>
Las licencias del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_LICENSE.
--validation <VALIDACIÓN>
Los métodos de validación del paquete.
También se puede especificar con la variable de entorno ALPM_DB_DESC_VALIDATION.
--replaces <REEMPLAZA>
Lo que reemplaza.
También se puede especificar con la variable de entorno ALPM_DB_DESC_REPLACES.
--depends <DEPENDENCIAS>
Las dependencias.
También se puede especificar con la variable de entorno ALPM_DB_DESC_DEPENDS.
--optdepends <DEPENDOPT>
Las dependencias opcionales.
También se puede especificar con la variable de entorno ALPM_DB_DESC_OPTDEPENDS.
--conflicts <CONFLICTOS>
Los conflictos.
También se puede especificar con la variable de entorno ALPM_DB_DESC_CONFLICTS.
--provides <PROPORCIONA>
Lo que proporciona.
También se puede especificar con la variable de entorno ALPM_DB_DESC_PROVIDES.
--xdata <XDATA>
Metadatos adicionales estructurados.
También se puede especificar con la variable de entorno ALPM_DB_DESC_XDATA.
-h, --help
Imprime la ayuda (ver un resumen con '-h').
[SALIDA]
El archivo de salida.
También se puede especificar con la variable de entorno ALPM_DB_DESC_OUTPUT_FILE.
