NOMBRE

al_draw_text - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_font.h>
void al_draw_text(const ALLEGRO_FONT *font,
   ALLEGRO_COLOR color, float x, float y, int flags,
   char const *text)

DESCRIPCIÓN

Escribe la cadena terminada en NUL text en el bitmap de destino en la posición x, y, usando la fuente especificada.

El parámetro flags puede ser 0 o una de las siguientes banderas:

•
ALLEGRO_ALIGN_LEFT - Dibuja el texto alineado a la izquierda (igual que 0).
•
ALLEGRO_ALIGN_CENTRE - Dibuja el texto centrado alrededor de la posición dada.
•
ALLEGRO_ALIGN_RIGHT - Dibuja el texto alineado a la derecha a la posición dada.

También se puede combinar con la siguiente bandera:

•
ALLEGRO_ALIGN_INTEGER - Siempre dibuja el texto alineado a una posición de píxel entero. Este era anteriormente el comportamiento por defecto. Desde: 5.0.8, 5.1.4

Esta función no admite caracteres de nueva línea (\n), pero puedes usar al_draw_multiline_text(3) para la salida de texto de varias líneas.

VER TAMBIÉN

al_draw_ustr(3), al_draw_textf(3), al_draw_justified_text(3), al_draw_multiline_text(3).
