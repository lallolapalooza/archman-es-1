NOMBRE

align_image_stack - Alinea imágenes superpuestas para la creación de pilas HDR o de enfoque

SINOPSIS

align_image_stack [opciones] archivos de entrada

DESCRIPCIÓN

align_image_stack se utiliza para la alineación de imágenes ligeramente desalineadas o para el registro de un par de imágenes estéreo. Cuando se toman varias imágenes con exposiciones diferentes en el proceso de creación de una imagen de Alto Rango Dinámico (HDR), las imágenes no están perfectamente alineadas y la calidad de la imagen HDR resultante se verá afectada. align_image_stack utiliza las herramientas disponibles para hugin para optimizar la inclinación (roll), cabeceo (pitch) y guiñada (yaw), así como algunos parámetros de la geometría de la lente, para alinear las imágenes.

OPCIONES

Modos de operación:

-p archivo
Archivo .pto de salida (útil para depuración o refinamiento posterior)
-a prefijo
Imágenes alineadas de salida como prefijo_xxxx.tif
-o salida
Alinear imágenes y fusionarlas a HDR, generar salida.hdr

Modificadores:

-v
Detallado, imprime mensajes de progreso. Repetir para mayor verbosidad
-e
Asume que las imágenes de entrada son ojo de pez de fotograma completo (por defecto: rectilínea)
-t num
Elimina todos los puntos de control con un error superior a num píxeles (por defecto: 3)
--corr=num
Umbral de correlación para identificar puntos de control (por defecto: 0.9)
-f HFOV
Campo de visión horizontal aproximado de las imágenes de entrada, úselo si la información EXIF no está completa
-m
Optimiza el campo de visión para todas las imágenes, excepto la primera. Útil para alinear pilas de enfoque con magnificaciones ligeramente diferentes.
-d
Optimiza la distorsión radial para todas las imágenes, excepto la primera.
-i
Optimiza el desplazamiento del centro de la imagen para todas las imágenes, excepto la primera.
-x
Optimiza la coordenada X de la posición de la cámara
-y
Optimiza la coordenada Y de la posición de la cámara
-z
Optimiza la coordenada Z de la posición de la cámara
-S
Asume imágenes estéreo - permite el desplazamiento horizontal de los puntos de control.
-A
Alinea la ventana estéreo - asume -S
-P
Alinea la ventana estéreo con efecto de salida - asume -S
-C
Recorta automáticamente la imagen al área cubierta por todas las imágenes
-c num
Número de puntos de control (por cuadrícula) a crear entre imágenes adyacentes (por defecto: 8)
-l
Asume archivos de entrada lineales
-s escala
Reduce la imagen en 2^escala (por defecto: 1 [submuestreo 2x])
-g tamano_g
Divide la imagen en una cuadrícula rectangular (tamano_g x tamano_g) e intenta encontrar num puntos de control en cada sección (por defecto: 5 [cuadrícula de 5x5])
--distortion
Intenta cargar información de distorsión de la base de datos de lentes
--use-given-order
Utiliza el orden de las imágenes tal como se indica en la línea de comandos. (Por defecto, las imágenes se ordenarán por valores de exposición.)
--gpu
Utiliza la GPU para el remapeo
-h
Muestra el resumen de ayuda.
