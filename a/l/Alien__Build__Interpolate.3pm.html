Alien::Build::Interpolate(3) Documentación de Perl contribuida por el usuario Alien::Build::Interpolate(3)

NOMBRE

Alien::Build::Interpolate - Motor de interpolación avanzado para compilaciones de Alien

VERSIÓN

versión 2.84

CONSTRUCTOR

new

my $intr = Alien::Build::Interpolate->new;

add_helper

$intr->add_helper($name => $code);
$intr->add_helper($name => $code, %requirements);

replace_helper

$intr->replace_helper($name => $code);
$intr->replace_helper($name => $code, %requirements);

has_helper

my $coderef = $intr->has_helper($name);

Se utiliza para descubrir si existe un ayudante con el nombre dado. Devuelve la referencia de código.

execute_helper

my $value = $intr->execute_helper($name);

Evalúa el ayudante dado y devuelve el resultado.

interpolate

my $string = $intr->interpolate($template, $build);
my $string = $intr->interpolate($template);

Toma una plantilla y rellena los valores apropiados de cualquier ayudante utilizado en la plantilla.

[versión 2.58]

Si se pasa una instancia de Alien::Build como segundo argumento, puede utilizar propiedades además de ayudantes en la plantilla. Ejemplo:

my $patch = $intr->template("%{.install.patch}/foo-%{.runtime.version}.patch", $build);

requires

my %requires = $intr->requires($template);

Devuelve un hash de módulos requeridos para ejecutar la plantilla dada. Las claves son los nombres de los módulos y los valores son las versiones. La versión se establecerá en 0 si cualquier versión es suficiente.

clone

my $intr2 = $intr->clone;

Crea un clon del interpolador.
