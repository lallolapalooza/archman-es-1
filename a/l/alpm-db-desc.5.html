alpm-db-desc - Formato de archivo para la representación de metadatos de paquetes basados en ALPM (versión

2)
.

DESCRIPCIÓ

N

El formato alpm-db-desc es un formato textual que representa los metadatos de un solo paquete. Cada archivo describe varias propiedades de un paquete, incluyendo su nombre, versión, dependencias, tamaño, información de licencia y más. Para una lista completa de propiedades, consulte secciones

.

Un sistema operativo que depende de Arch Linux Gestión de Paquetes mantiene una base de datos local de libalpm con un archivo alpm-db-desc por paquete, cada uno nombrado desc y ubicado en un directorio único y específico para cada

paquete.

La acumulación de todos los archivos alpm-db-desc en una base de datos libalpm describe el estado actual del sistema (es decir, qué paquetes se han instalado y cuándo, y bajo qué circunstancias). Más específicamente, el software de gestión de paquetes como pacman y las herramientas relacionadas usan este formato de archivo, por ejemplo, para resolver dependencias y para mostrar información del

paquete.

Los datos en un archivo alpm-db-desc se derivan de un alpm-package. Aquí, la mayoría de los metadatos provienen de los datos PKGINFO del

paquete.

El formato de archivo alpm-db-desc no debe confundirse con el formato de archivo alpm-repo-desc, que se usa en el contexto de una alpm-repo-db y contiene un conjunto diferente de metadatos, pero que generalmente también se llama desc

.

El formato alpm-db-desc existe en múltiples versiones. La información en este documento es para la versión 2, que es la versión actual y se introdujo con la versión de pacman 6.1.0 el

2024-03-04.

Formato

General

Un archivo alpm-db-desc es un archivo codificado en UTF-8 y delimitado por saltos de línea, que consta de una serie de secciones

.

Cada sección comienza con una línea de encabezado de sección única. La línea de encabezado de sección va seguida de una o más líneas, cada una con un valor específico de la sección. Todos los valores específicos de la sección deben consistir en caracteres ASCII imprimibles[1] a menos que se indique lo contrario. Una sección termina cuando se encuentra otra línea de encabezado de sección o se alcanza el final del

archivo.
