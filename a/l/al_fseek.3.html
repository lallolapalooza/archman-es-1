NOMBRE

al_fseek - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
bool al_fseek(ALLEGRO_FILE *f, int64_t offset, int whence)

DESCRIPCIÓN

Establece la posición actual del archivo dado a una posición relativa a la especificada por `whence', más `offset' bytes.

`whence' puede ser:

•
ALLEGRO_SEEK_SET - buscar relativo al principio del archivo
•
ALLEGRO_SEEK_CUR - buscar relativo a la posición actual del archivo
•
ALLEGRO_SEEK_END - buscar relativo al final del archivo

Devuelve true en caso de éxito, false en caso de fallo. `errno` se establece para indicar el error.

Después de una búsqueda exitosa, el indicador de fin de archivo se borra y se olvidan todos los bytes de retroceso.

En algunas plataformas, esta función puede no admitir archivos grandes.

VER TAMBIÉN

al_ftell(3), al_get_errno(3)
