ALTER_STATISTICS(7)

Paquete: postgresql

Licencias: PostgreSQL

ALTER STATISTICS(7) Documentación de PostgreSQL 18.1 ALTER STATISTICS(7)

NOMBRE

ALTER_STATISTICS - cambiar la definición de un objeto de estadísticas extendidas

SINOPSIS

ALTER STATISTICS nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER STATISTICS nombre RENAME TO nuevo_nombre
ALTER STATISTICS nombre SET SCHEMA nuevo_esquema
ALTER STATISTICS nombre SET STATISTICS { nuevo_objetivo | DEFAULT }

DESCRIPCIÓN

ALTER STATISTICS cambia los parámetros de un objeto de estadísticas extendidas existente. Cualquier parámetro que no se establezca específicamente en el comando ALTER STATISTICS conservará su configuración previa.

Debes ser propietario del objeto de estadísticas para usar ALTER STATISTICS. Para cambiar el esquema de un objeto de estadísticas, también debes tener el privilegio CREATE en el nuevo esquema. Para alterar el propietario, debes poder SET ROLE al nuevo rol propietario, y ese rol debe tener el privilegio CREATE en el esquema del objeto de estadísticas. (Estas restricciones garantizan que alterar el propietario no hace nada que no pudieras hacer eliminando y volviendo a crear el objeto de estadísticas. Sin embargo, un superusuario puede alterar la propiedad de cualquier objeto de estadísticas de todos modos.)

PARÁMETROS

nombre

El nombre (opcionalmente cualificado por el esquema) del objeto de estadísticas a modificar.

nuevo_propietario

El nombre de usuario del nuevo propietario del objeto de estadísticas.

nuevo_nombre

El nuevo nombre para el objeto de estadísticas.

nuevo_esquema

El nuevo esquema para el objeto de estadísticas.

nuevo_objetivo

El objetivo de recopilación de estadísticas para este objeto de estadísticas para futuras operaciones ANALYZE. El objetivo se puede establecer en el rango de 0 a 10000. Establécelo a DEFAULT para volver a usar el objetivo de estadísticas predeterminado del sistema (default_statistics_target). (Establecerlo a un valor de -1 es una forma obsoleta de lograr el mismo resultado.) Para más información sobre el uso de estadísticas por el planificador de consultas de PostgreSQL, consulta la Sección 14.2.

COMPATIBILIDAD

No existe un comando ALTER STATISTICS en el estándar SQL.

VER TAMBIÉN

CREATE STATISTICS (CREATE_STATISTICS(7)), DROP STATISTICS (DROP_STATISTICS(7))
