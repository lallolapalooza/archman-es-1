alsaloop(1)

Paquete: alsa-utils

ALSALOOP(1) Manual de Comandos Generales ALSALOOP(1)

NOMBRE

alsaloop - bucle de línea de comandos PCM

SINOPSIS

alsaloop [-opción] [comando]

DESCRIPCIÓN

alsaloop permite crear un bucle PCM entre un dispositivo de captura PCM y un dispositivo de reproducción PCM.

alsaloop soporta múltiples tarjetas de sonido, sincronización adaptativa de reloj, remuestreo de frecuencia adaptativa usando la biblioteca samplerate (si está disponible en el sistema). Además, los controles del mezclador pueden ser redirigidos de una tarjeta a otra (por ejemplo, Master y PCM).

OPCIONES

-h | --help

Imprime la información de ayuda.

-g <archivo> | --config=<archivo>

Utiliza el archivo de configuración dado. La sintaxis de este archivo es simple: una línea contiene las opciones de línea de comandos para un trabajo. El '#' significa comentario y el resto de la línea se ignora. Ejemplo:


# Primera línea - comentario, segunda línea - primer trabajo
-C hw:1,0 -P hw:0,0 -t 50000 -T 1
# Tercera línea - comentario, cuarta línea - segundo trabajo
-C hw:1,1 -P hw:0,1 -t 40000 -T 2

-d | --daemonize

Daemoniza el proceso principal y utiliza syslog para los mensajes.

-P <dispositivo> | --pdevice=<dispositivo>

Utiliza el dispositivo de reproducción dado.

-C <dispositivo> | --cdevice=<dispositivo>

Utiliza el dispositivo de captura dado.

-X <dispositivo> | --pctl=<dispositivo>

Utiliza el dispositivo CTL dado para la reproducción.

-Y <dispositivo> | --cctl=<dispositivo>

Utiliza el dispositivo CTL dado para la captura.

-x <nombre_ascii_ctl> | --prateshift=<nombre_ascii_ctl>

Especifica el nombre ascii ctl para el modo de sincronización playshift (ver la sección Ejemplos).

-l <latencia> | --latency=<fotogramas>

Latencia solicitada en fotogramas.

-t <usec> | --tlatency=<usec>

Latencia solicitada en useg (1/1000000 seg).

-f <formato> | --format=<formato>

Especificación del formato (generalmente S16_LE S32_LE). Use -h para listar todos los formatos. El formato predeterminado es S16_LE.

-c <canales> | --channels=<canales>

Especificación del número de canales. El valor predeterminado es 2.

-r <tasa> | --rate=<tasa>

Especificación de la tasa. El valor predeterminado es 48000 (Hz).

-n | --resample

Permite el remuestreo de frecuencia usando alsa-lib.

-A <conversor> | --samplerate=<conversor>

Usa libsamplerate y elige un conversor:


0 o sincbest - mejor calidad
1 o sincmedium - calidad media
2 o sincfastest - calidad más baja
3 o zerohold - mantiene cero muestras
4 o linear - peor calidad - remuestreo lineal
5 o auto - elige el mejor método

-B <tamaño> | --buffer=<tamaño>

Tamaño del búfer en fotogramas.

-E <tamaño> | --period=<tamaño>

Tamaño del período en fotogramas.

-s <segs> | --seconds=<segs>

Duración del bucle en segundos.

-b | --nblock

Modo no bloqueante (despertar muy temprano del proceso). Consume más CPU.

-S <modo> | --sync=<modo>

Especificación del modo de sincronización para el flujo de captura a reproducción:
0 o none - no tocar el flujo
1 o simple - añadir o quitar muestras para mantener
ambos flujos sincronizados
2 o captshift - usar el controlador del dispositivo de captura
(si es compatible) para compensar
el desplazamiento de frecuencia
3 o playshift - usar el controlador del dispositivo de reproducción
(si es compatible) para compensar
el desplazamiento de frecuencia
4 o samplerate - usar la biblioteca samplerate para realizar el remuestreo
de frecuencia
5 o auto - selecciona automáticamente el mejor método
en este orden: captshift, playshift,
samplerate, simple

-T <num> | --thread=<num>

Número de hilo (-1 significa crear un hilo único). Todos los trabajos con el mismo número de hilo se ejecutan dentro de un solo hilo.

-m <id_mezcla> | --mixer=<id_mezcla>

Redirige el control del mezclador de la tarjeta de reproducción a la tarjeta de captura. El formato de id_mezcla es SRCID(REPRODUCCIÓN)[@DSTID(REPRODUCCIÓN)]:


"name='Master Playback Switch'@name='Another Switch'"
"name='PCM Playback Volume'"

Atributos conocidos:


name - nombre del ID de control
index - índice del ID de control
device - dispositivo del ID de control
subdevice - subdispositivo del ID de control
iface - interfaz del ID de control
numid - numid del ID de control

-O <ossmixid> | --ossmixer=<ossmixid>

Redirige el control del mezclador de la capa de emulación de mezclador OSS (tarjeta de captura) a la capa ALSA (tarjeta de captura). El formato de ossmixid es ALSAID[,INDEX]@OSSID:


"Master@VOLUME"
"PCM,1@ALTPCM"

Atributos OSS conocidos:


VOLUME, BASS, TREBLE, SYNTH, PCM, SPEAKER, LINE, MIC, CD, IMIX, ALTPCM,
RECLEV, IGAIN, OGAIN, LINE1, LINE2, LINE3, DIGITAL1, DIGITAL2, DIGITAL3,
PHONEIN, PHONEOUT, VIDEO, RADIO, MONITOR

-v | --verbose

Modo detallado. Úselo varias veces para aumentar la verbosidad.

-U | --xrun

Perfilado detallado de xrun.

-W <tiempo_espera> | --wake=<tiempo_espera>

Establece el tiempo de espera de despertar del proceso.

EJEMPLOS

alsaloop -C hw:0,0 -P hw:1,0 -t 50000
alsaloop -C hw:tarjeta_sonido,0 -P hw:Loopback,0 -t 50000 -S playshift \
-x iface=PCM,name='PCM Rate Shift 100000',device=1

BUGS

Ninguno conocido.
