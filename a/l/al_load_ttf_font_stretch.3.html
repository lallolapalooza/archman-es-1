NOMBRE

al_load_ttf_font_stretch - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_ttf.h>
ALLEGRO_FONT *al_load_ttf_font_stretch(char const *filename, int w, int h,
   int flags)

DESCRIPCIÓN

Al igual que al_load_ttf_font(3), excepto que toma parámetros separados de ancho y alto en lugar de un único parámetro de tamaño.

Si la altura es un valor positivo, y el ancho cero o positivo, entonces la fuente se estirará de acuerdo con esos parámetros. El ancho no debe ser negativo si la altura es positiva.

Al igual que con al_load_ttf_font(3), la altura puede ser un valor negativo para especificar la altura total en píxeles. Entonces el ancho debe ser también un valor negativo, o cero.

Devuelve NULL si la altura es positiva mientras que el ancho es negativo, o si la altura es negativa mientras que el ancho es positivo.

DESDE

5.0.6, 5.1.0

VER TAMBIÉN

al_load_ttf_font(3), al_load_ttf_font_stretch_f(3)
