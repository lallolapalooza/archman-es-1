alpm-package-base(7)

Paquete: alpm-docs

(7) Manual de Información Miscelánea (7)

NOMBRE

package base - un identificador que rastrea de qué fuentes proviene un paquete basado en ALPM.

DESCRIPCIÓN

El formato de package base representa un identificador que describe el origen de la fuente de cada archivo alpm-package. Es particularmente útil en archivos alpm-split-package para rastrear las fuentes de las que se compila cada archivo de paquete.

Más específicamente, el formato alpm-package-base se utiliza durante todo el ciclo de vida de la gestión de paquetes:

  • en scripts de compilación y archivos de metadatos de origen (es decir, PKGBUILD y SRCINFO).
  • en formatos de archivo para metadatos de paquetes (es decir, BUILDINFO y PKGINFO).
  • en formatos de archivo para metadatos de repositorios (es decir, alpm-repo-desc).
  • y en metadatos de estado del sistema (es decir, alpm-db-desc).

Formato General

El nombre identificador para alpm-package-base puede variar dependiendo del contexto. Sin embargo, las restricciones de valor para el mismo son las mismas que las de alpm-package-name.

EJEMPLOS

El PKGBUILD de un paquete llamado example, que especifica implícitamente su alpm-package-base como example.

pkgname=example
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquete de ejemplo"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}

El PKGBUILD de un paquete llamado example, que especifica explícitamente su alpm-package-base como something-else.

pkgname=example
pkgbase=something-else
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquete de ejemplo"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}

El PKGBUILD de una configuración de paquetes divididos con los paquetes example y other-example que comparten el alpm-package-base implícito example.

pkgname=(
  example
  other-example
)
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquete de ejemplo"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package_example() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}
package_other-example() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "other-example\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}

El PKGBUILD de una configuración de paquetes divididos con los paquetes example1 y example2 que comparten el alpm-package-base explícito example.

pkgname=(
  example1
  example2
)
pkgbase=example
pkgver=1.0.0
pkgrel=1
pkgdesc="Un paquete de ejemplo"
arch=(any)
url="https://example.org"
license=('CC0-1.0')
package_example1() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example1\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}
package_example2() {
  install -vdm 755 "$pkgdir/usr/share/doc/$pkgname/"
  printf "example2\n" > "$pkgdir/usr/share/doc/$pkgname/example.txt"
}
