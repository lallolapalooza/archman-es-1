NOMBRE

al_get_standard_path - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
ALLEGRO_PATH *al_get_standard_path(int id)

DESCRIPCIÓN

Obtiene una ruta del sistema, dependiendo del parámetro id. Algunas de estas rutas pueden verse afectadas por el nombre de la organización y de la aplicación, así que asegúrate de establecerlos antes de llamar a esta función.

No se garantiza que las rutas sean únicas (por ejemplo, SETTINGS y DATA pueden ser iguales en algunas plataformas), así que asegúrate de que tus nombres de archivo sean únicos si necesitas evitar colisiones de nombres. Además, una ruta devuelta puede no existir realmente en el sistema de archivos.

ALLEGRO_RESOURCES_PATH
Si empaquetas datos en una ubicación relativa a tu ejecutable, entonces deberías usar esta ruta para localizar esos datos. En la mayoría de las plataformas, este es el directorio que contiene el archivo ejecutable.

Si se llama desde un paquete de aplicaciones OS X, entonces esto apuntará al directorio de recursos interno (<bundle.app>/Contents/Resources). Para mantener la coherencia, si pones tus recursos en un directorio llamado "data" debajo del ejecutable en otra plataforma (como Windows), entonces también deberías crear un directorio llamado "data" bajo la carpeta de recursos del paquete de aplicaciones OS X.

No deberías intentar escribir en esta ruta, ya que es muy probable que sea de solo lectura.

Si instalas tus recursos en algún otro directorio del sistema (por ejemplo, en /usr/share o C:\ProgramData), entonces eres responsable de hacerlo tú mismo.

ALLEGRO_TEMP_PATH
Ruta al directorio para archivos temporales.
ALLEGRO_USER_HOME_PATH
Este es el directorio de inicio del usuario. Normalmente no deberías escribir archivos directamente en este directorio, ni crear carpetas dentro de él, sin el permiso explícito del usuario. Una aplicación práctica de esta ruta sería usarla como punto de partida de un selector de archivos en una GUI.
ALLEGRO_USER_DOCUMENTS_PATH
Esta ubicación es fácilmente accesible por el usuario, y es el lugar para almacenar documentos y archivos que el usuario podría querer abrir más tarde con un programa externo o transferir a otro lugar.

No deberías guardar archivos aquí a menos que el usuario lo espere, generalmente con permiso explícito.

ALLEGRO_USER_DATA_PATH
Si tu programa guarda datos que el usuario no necesita acceder externamente, entonces deberías colocarlos aquí. Este es generalmente el lugar menos intrusivo para almacenar datos. Esta ruta generalmente no estará presente en el sistema de archivos, así que asegúrate de crearla antes de escribir en ella.
ALLEGRO_USER_SETTINGS_PATH
Si estás guardando archivos de configuración (especialmente si el usuario quiere editarlos fuera de tu programa), entonces deberías colocarlos aquí. Esta ruta generalmente no estará presente en el sistema de archivos, así que asegúrate de crearla antes de escribir en ella.
ALLEGRO_EXENAME_PATH
La ruta completa al ejecutable.

Devuelve NULL en caso de fallo. La ruta devuelta debe ser liberada con al_destroy_path(3).
