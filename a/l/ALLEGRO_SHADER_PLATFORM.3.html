ALLEGRO_SHADER_PLATFORM(3) Manual de funciones de la biblioteca ALLEGRO_SHADER_PLATFORM(3)

NOMBRE

ALLEGRO_SHADER_PLATFORM - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef enum ALLEGRO_SHADER_PLATFORM ALLEGRO_SHADER_PLATFORM;

DESCRIPCIÓN

La plataforma subyacente sobre la que se construye ALLEGRO_SHADER(3), que dicta el lenguaje utilizado para programar el sombreador.

•
ALLEGRO_SHADER_AUTO - Elige una plataforma automáticamente dadas las banderas de visualización actuales.
•
ALLEGRO_SHADER_GLSL - Lenguaje de sombreado de OpenGL
•
ALLEGRO_SHADER_HLSL - Lenguaje de sombreado de alto nivel (para Direct3D)
•
ALLEGRO_SHADER_AUTO_MINIMAL - Similar a ALLEGRO_SHADER_AUTO, pero elige una implementación más mínima que puede no admitir pruebas alfa.
•
ALLEGRO_SHADER_GLSL_MINIMAL - Sombreador GLSL mínimo.
•
ALLEGRO_SHADER_HLSL_MINIMAL - Sombreador HLSL mínimo.
•
ALLEGRO_SHADER_HLSL_SM_3_0 - Sombreador HLSL que utiliza el modelo de sombreado 3_0.
