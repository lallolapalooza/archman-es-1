al_insert_menu_item(3) Manual de funciones de la biblioteca al_insert_menu_item(3)

NOMBRE

al_insert_menu_item - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_native_dialog.h>
int al_insert_menu_item(ALLEGRO_MENU *padre, int pos, const char *titulo,
   uint16_t id, int flags, ALLEGRO_BITMAP *icono, ALLEGRO_MENU *submenu)

DESCRIPCIÓN

Inserta un elemento de menú en la posición especificada. Consulte el texto introductorio para una explicación detallada de cómo se interpreta el parámetro pos.

El menú padre puede ser un menú emergente o un menú normal. Para subrayar un carácter en el titulo, prefíjalo con un ampersand.

Los flags pueden ser cualquier combinación de:

ALLEGRO_MENU_ITEM_DISABLED
El elemento está "desactivado" y no se puede seleccionar.
ALLEGRO_MENU_ITEM_CHECKBOX
El elemento es una casilla de verificación. Esta bandera solo se puede establecer en el momento de crear el menú. Si se hace clic en una casilla de verificación, se alternará automáticamente.
ALLEGRO_MENU_ITEM_CHECKED
El elemento está marcado. Si se establece, ALLEGRO_MENU_ITEM_CHECKBOX también se establecerá automáticamente.

El icono aún no es compatible.

El parámetro submenu indica que este elemento contiene un menú hijo. El menú hijo debe haber sido creado previamente con al_create_menu y no estar asociado con ningún otro menú.

Devuelve el índice en el que se insertó el elemento (que puede ser diferente de lo que implica pos), o -1 si hubo un error.

DESDE

5.1.0
