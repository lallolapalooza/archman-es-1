NOMBRE

al_draw_scaled_bitmap - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_draw_scaled_bitmap(ALLEGRO_BITMAP *bitmap,
   float sx, float sy, float sw, float sh,
   float dx, float dy, float dw, float dh, int flags)

DESCRIPCIÓN

Dibuja una versión escalada del bitmap dado en el bitmap de destino.

•
sx - x de origen
•
sy - y de origen
•
sw - ancho de origen
•
sh - alto de origen
•
dx - x de destino
•
dy - y de destino
•
dw - ancho de destino
•
dh - alto de destino
•
flags - igual que para al_draw_bitmap(3)

Consulte al_draw_bitmap(3) para obtener una nota sobre las restricciones sobre qué bitmaps se pueden dibujar dónde.
