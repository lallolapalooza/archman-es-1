al_store_state(3) Manual de funciones de la biblioteca al_store_state(3)

NOMBRE

al_store_state - API de Allegro 5

SINOPSIS

void al_store_state(ALLEGRO_STATE *state, int flags)

DESCRIPCIÓN

Almacena parte del estado del hilo actual en el objeto ALLEGRO_STATE(3) proporcionado. El parámetro flags puede tomar cualquier combinación de bits de estas banderas:

•
ALLEGRO_STATE_NEW_DISPLAY_PARAMETERS - new_display_format, new_display_refresh_rate, new_display_flags
•
ALLEGRO_STATE_NEW_BITMAP_PARAMETERS - new_bitmap_format, new_bitmap_flags
•
ALLEGRO_STATE_DISPLAY - current_display
•
ALLEGRO_STATE_TARGET_BITMAP - target_bitmap
•
ALLEGRO_STATE_BLENDER - blender
•
ALLEGRO_STATE_TRANSFORM - current_transformation
•
ALLEGRO_STATE_PROJECTION_TRANSFORM - current_projection_transformation
•
ALLEGRO_STATE_NEW_FILE_INTERFACE - new_file_interface
•
ALLEGRO_STATE_BITMAP - igual que ALLEGRO_STATE_NEW_BITMAP_PARAMETERS y ALLEGRO_STATE_TARGET_BITMAP
•
ALLEGRO_STATE_ALL - todos los anteriores

VER TAMBIÉN

al_restore_state(3), ALLEGRO_STATE(3)
