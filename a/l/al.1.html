DESCRIPCIÓ

N

AL es el enlazador de ensamblados de

Mono.

Este enlazador se utiliza para unir ensamblados a partir de una colección de módulos (archivos .netmodule), archivos de manifiesto de ensamblados y

recursos.

No lo confunda con el monolinker, que es una herramienta para reducir el tamaño de los ensamblados basándose en el código

utilizado.

Utilice al para procesar ensamblados 1.0, utilice al2 para procesar ensamblados 2.0

.

OPCIONE

S
@<nombre-arch
ivo>
Leer archivo de respuesta para más
opciones.
-algid:
<id>
Algoritmo utilizado para resumir archivos. El <id> debe especificarse en
hexadecimal.
-base:<dirección> | -baseaddress:
<dirección>
Dirección base para la biblioteca. ESTA CARACTERÍSTICA NO ESTÁ
IMPLEMENTADA.
-bugreport:
<nombre-archivo>
Crear un archivo de 'Informe de errores'. ESTA CARACTERÍSTICA NO ESTÁ
IMPLEMENTADA.
-comp:<texto> | -company:
<texto>
Esto inserta el nombre de la compañía en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyCompany ("<texto>")] al código fuente en
C#.
-config:<texto> | -configuration:
<texto>
Esto inserta la cadena de configuración en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyConfiguration ("<texto>")] al código fuente en
C#.
-copy:<texto> | -copyright:
<texto>
Esto inserta el mensaje de copyright en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyCopyright ("<texto>")] al código fuente en
C#.
-c:<texto> | -culture:
<texto>
Esto inserta la cultura soportada en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyCulture ("<texto>")] al código fuente en
C#.
-delay | -delay+ | -delaysign |
-delaysign+
El ensamblado generado se firmará con retraso. Esto es equivalente a añadir el atributo [AssemblyDelaySignAttribute (true)] al código fuente en
C#.
-delay- |
-delaysign-
El ensamblado generado se firmará completamente (es decir, no con retraso). Esta es la opción predeterminada al firmar (-keyfile o -keyname)
.
-descr:<texto> | -description:
<texto>
Esto inserta una descripción del ensamblado en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyDescription ("<texto>")] al código fuente en
C#.
-e:<nombre-archivo> | -evidence:
<nombre-archivo>
Esto incrusta en el ensamblado el archivo especificado como evidencias de seguridad del
ensamblado.
-fileversion:
<versión>
Versión Win32 opcional. Esto anula la versión normal del
ensamblado.
-flags:
<flags>
Banderas del ensamblado. Los <flags> deben especificarse en
hexadecimal.
-fullpat
hs
Mostrar archivos usando nombres de archivo completamente
calificados.
-keyf:<nombre-archivo> | -keyfile:
<nombre-archivo>
Asignar nombre fuerte (firmar) el ensamblado de salida usando el par de claves presente en el archivo de clave de nombre fuerte (snk) especificado. Se requiere un par de claves completo a menos que también se especifique la opción de firma con retraso (-delay+). Esto es equivalente a añadir el atributo [AssemblyKeyFile ("<texto>")] al código fuente en
C#.
-keyn:<texto> | -keyname:
<texto>
Asignar nombre fuerte (firmar) el ensamblado de salida usando el par de claves presente en el contenedor especificado. La firma con retraso no está soportada al usar contenedores de claves. Esto es equivalente a añadir el atributo [AssemblyKeyName ("<texto>")] al código fuente en
C#.
-main:
<método>
Especifica el nombre del método del punto de entrada del
ensamblado.
-nolo
go
Suprimir el banner de inicio y el mensaje de
copyright.
-out:
<nombre-archivo>
Nombre del archivo de salida para el manifiesto del
ensamblado.
-prod:<texto> | product:
<texto>
Esto inserta el nombre del producto en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyProduct ("<texto>")] al código fuente en
C#.
-productv[ersion]:
<texto>
Esto inserta la versión del producto en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyInformationalVersion ("<texto>")] al código fuente en
C#.
-t[arget]:<objetivo> | -target=<objeti
vo>
Los <objetivo>s válidos son: lib | library para crear una biblioteca (.dll), exe para crear un ejecutable de consola (.exe), y win | winexe para crear un ejecutable de Windows (.
exe).
-template:
<nombre-archivo>
Especifica un ensamblado del cual obtener las opciones
predeterminadas.
-title:
<texto>
Esto inserta un título del ensamblado en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyTitle ("<texto>")] al código fuente en
C#.
-trade:<texto> | -trademark:
<texto>
Esto inserta un mensaje de marca registrada en los metadatos del ensamblado. Esto es equivalente a añadir el atributo [AssemblyTrademark ("<texto>")] al código fuente en
C#.
-v:<versión> | -version:
<versión>
Esto inserta la versión del ensamblado en los metadatos del ensamblado. Puede usar * para autogenerar los números restantes. Esto es equivalente a añadir el atributo [AssemblyVersion ("<texto>")] al código fuente en
C#.
-win32icon:
<nombre-archivo>
Usar este icono para la
salida.
-win32res:
<nombre-archivo>
Especifica el archivo de recursos de
Win32.
