Documentación de Función/Subrutina

subrutina alareq (character*3 path, integer nmats, logical, dimension( * ) dotype, integer ntypes, integer nin, integer nout)

ALAREQ

Propósito:

!>
!> ALAREQ maneja la entrada para el programa de pruebas de LAPACK. Se llama
!> para evaluar la línea de entrada que solicitó NMATS tipos de matriz para
!> PATH. El flujo de control es el siguiente:
!>
!> SI NMATS = NTYPES ENTONCES
!>    DOTYPE(1:NTYPES) = .TRUE.
!> SI NO
!>    Leer la siguiente línea de entrada para NMATS tipos de matriz
!>    Establecer DOTYPE(I) = .TRUE. para cada tipo I válido
!> FIN SI
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          Un nombre de ruta de LAPACK para pruebas.
!>

NMATS

!>          NMATS es INTEGER
!>          El número de tipos de matriz que se utilizarán en la prueba de esta ruta.
!>

DOTYPE

!>          DOTYPE es un array LOGICAL, dimensionado (NTYPES)
!>          El vector de indicadores que señalan si cada tipo será probado.
!>

NTYPES

!>          NTYPES es INTEGER
!>          El número máximo de tipos de matriz para esta ruta.
!>

NIN

!>          NIN es INTEGER
!>          La unidad de número para la entrada. NIN >= 1.
!>

NOUT

!>          NOUT es INTEGER
!>          La unidad de número para la salida. NOUT >= 1.
!>
