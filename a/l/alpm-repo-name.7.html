NOMBRE

alpm-repo-name - nombres para los repositorios de paquetes basados en el Arch Linux Package Management (ALPM).

DESCRIPCIÓN

El formato alpm-repo-name especifica nombres para repositorios de paquetes basados en ALPM. Este formato se utiliza en los archivos de configuración del software de gestión de paquetes (p. ej., pacman.conf para pacman) y en los nombres de archivo alpm-repo-database.

Un nombre de repositorio sirve como identificador para el software de gestión de paquetes y le permite descargar y direccionar archivos alpm-repo-database.

Formato

El valor de alpm-repo-name puede ser una cadena UTF-8 que no debe contener los caracteres /, ?, ! y no debe empezar con el carácter -.

EJEMPLOS

repo-name
