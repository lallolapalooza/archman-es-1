NOMBRE

alpm-srcinfo-format - Da formato a un archivo SRCINFO desde una ruta o `stdin`

SINOPSIS

alpm-srcinfo format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Da formato a un archivo SRCINFO desde una ruta o `stdin`.

Si el archivo es válido, el programa imprime los datos en el formato de archivo solicitado a stdout y retorna con un estado de salida de 0.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema SRCINFO a utilizar.

Si no se proporciona ninguna versión de esquema, se deducirá del propio archivo.

-o, --output-format <FORMATO_SALIDA> [predeterminado: srcinfo]
Proporciona el formato de salida.

Valores posibles:

  • json: El formato de salida JSON
  • srcinfo: El formato de salida SRCINFO
-p, --pretty
Imprime la salida de forma legible.

Solo se aplica a formatos que admiten salida legible y de lo contrario se ignora.

-h, --help
Imprime la ayuda (ver un resumen con '-h')
[ARCHIVO]
El archivo desde el que leer.

Si no se proporciona ningún archivo, se utiliza stdin en su lugar.
