NOMBRE

alpm-files-format - Lee y valida datos de alpm-files y los devuelve en otro formato de archivo.

SINOPSIS

alpm-files format [-i|--input-file] [-f|--format] [-o|--output] [-p|--pretty] [-s|--style] [-h|--help]

DESCRIPCIÓN

Lee y valida datos de alpm-files y los devuelve en otro formato de archivo.

Si los datos pueden ser validados, el programa sale con los datos devueltos en otro formato de archivo en la salida estándar (stdout) y un código de salida de cero. Si el archivo no puede ser validado, se emite un error en la salida de error (stderr) y el programa sale con un código de salida distinto de cero.

OPCIONES

-i, --input-file <ARCHIVO_ENTRADA>
Un archivo de entrada del cual leer.

Si no se proporciona ningún archivo, se utiliza la entrada estándar (stdin) en su lugar.

También se puede especificar con la variable de entorno ALPM_FILES_FORMAT_INPUT_FILE.
-f, --format <FORMATO_SALIDA> [por defecto: json]
Establece el formato de salida.

Valores posibles:

  • json: El formato de salida JSON.
  • v1: El formato de salida de alpm-files.
También se puede especificar con la variable de entorno ALPM_FILES_FORMAT_OUTPUT_FORMAT.
-o, --output <SALIDA>
Una ruta de archivo donde escribir.
También se puede especificar con la variable de entorno ALPM_FILES_FORMAT_OUTPUT.
-p, --pretty
Determina si la salida se mostrará de forma bonita y no minimizada.

Solo se aplica a los formatos que admiten salida bonita, de lo contrario, se ignora.

También se puede especificar con la variable de entorno ALPM_FILES_FORMAT_PRETTY.
-s, --style <ESTILO> [por defecto: db]
Qué estilo del formato alpm-files usar.

Solo se aplica a los formatos que admiten diferentes estilos del formato alpm-files.

Valores posibles:

  • db: El estilo alpm-db-files.
  • repo: El estilo alpm-repo-files.
También se puede especificar con la variable de entorno ALPM_FILES_FORMAT_STYLE.
-h, --help
Imprime la ayuda (ver un resumen con '-h').
