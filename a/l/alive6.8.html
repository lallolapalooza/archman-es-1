NOMBRE

alive6

SINOPSIS

alive6 [-CFHLMPSdlpvV] [-I srcip6] [-i archivo] [-o archivo] [-e opt] [-s puerto,..] [-a puerto,..] [-u puerto,..] [-T etiqueta] [-W TIEMPO] interfaz [direccion-unicast-o-multicast [router-remoto]]

OPCIONES

  -i archivo    comprobar sistemas desde el archivo de entrada
  -o archivo    escribir resultados en el archivo de salida
  -d            resolver DNS de direcciones IPv6 vivas
  -M            enumerar direcciones de hardware (MAC) de las direcciones de entrada (¡lento!)
  -C            enumerar direcciones comunes de redes de entrada, -CC para escaneo grande
  -4 ipv4/rango  probar varias codificaciones de direcciones IPv4 por red (ej. 1.2.3.4/24)
  -p            enviar un paquete de ping para la comprobación de vida (predeterminado)
  -e dst,hop    enviar paquetes erróneos: destino (predeterminado), hop-by-hop
  -s puerto,puerto,..  paquete TCP-SYN a puertos para la comprobación de vida o "portscan"
  -a puerto,puerto,..  paquete TCP-ACK a puertos para la comprobación de vida
  -u puerto,puerto,..  paquete UDP a puertos para la comprobación de vida
  -h            mostrar más opciones de línea de comandos y ayuda (-hh: más opciones)
La dirección de destino en la línea de comandos o en el archivo de entrada puede
incluir rangos de la forma
de 2001:db8::1-fff o 2001:db8::1-2:0-ffff:0-ffff, etc.
