Alien::Libxml2(3) Documentación de Perl aportada por el usuario Alien::Libxml2(3)

NOMBRE

Alien::Libxml2 - Instala la biblioteca C libxml2 en tu sistema

VERSIÓN

versión 0.20

SINOPSIS

En tu Makefile.PL:

use ExtUtils::MakeMaker;
use Alien::Base::Wrapper ();
WriteMakefile(
  Alien::Base::Wrapper->new('Alien::Libxml2')->mm_args2(
    # Argumentos de MakeMaker
    NAME => 'Mi::XS',
    ...
  ),
);

En tu Build.PL:

use Module::Build;
use Alien::Base::Wrapper qw( Alien::Libxml2 !export );
my $builder = Module::Build->new(
  ...
  configure_requires => {
    'Alien::Libxml2' => '0',
    ...
  },
  Alien::Base::Wrapper->mb_args,
  ...
);
$build->create_build_script;

En tu script o módulo FFI::Platypus:

use FFI::Platypus;
use Alien::Libxml2;
my $ffi = FFI::Platypus->new(
  lib => [ Alien::Libxml2->dynamic_libs ],
);

DESCRIPCIÓN

Este módulo proporciona "libxml2" para que otros módulos lo utilicen.

ADVERTENCIAS

Existía un Alien::LibXML anterior, pero utiliza el antiguo Alien::Build::ModuleBuild y el autor prefiere esta versión, que se basa en el sistema alienfile más robusto.

"libxml2" tiene algunas dependencias opcionales, incluyendo "zlib" y "iconv". Para una instalación "compartida", querrás asegurarte de que estas estén instaladas antes de instalar Alien::Libxml2 si deseas utilizar funciones que dependen de ellas.

Para una instalación en el sistema, querrás asegurarte de que los paquetes de desarrollo para "libxml2", "zlib" y "iconv" estén instalados si "libxml2" ha sido configurado para usarlos, de lo contrario XML::LibXML no se instalará como se espera. Si las pruebas de este módulo fallan con un "iconv.h" o "zlib.h" faltante, esta es probablemente la razón.

VER TAMBIÉN

Alien::LibXML
Alien anterior para la misma biblioteca.
XML::LibXML
Interfaz de Perl para "libxml2", que utiliza este Alien
