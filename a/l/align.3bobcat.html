FBB::Align(3bobcat) Alineación de Elementos de Tabla FBB::Align(3bobcat)

NOMBRE

FBB::Align - Clase para alinear elementos en objetos Table

SINOPSIS

#include <bobcat/align>

Opción de enlazado: -lbobcat

DESCRIPCIÓN

Esta clase define objetos utilizados por la clase FBB::Table para definir la alineación de sus columnas y/o elementos.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página manual, están definidos en el espacio de nombres FBB.

HEREDA DE

-

TIPODEF ADICIONAL

El tipo FBB::Manipulator puede usarse como una abreviatura para

        std::ios_base &(*)(std::ios_base &)

que es el prototipo de los manipuladores de e/s estándar como std::left.

MANIPULADOR

El siguiente manipulador (no parte de la FBB::Align, clase pero definido en el espacio de nombres FBB ) puede especificarse como argumentos del constructor de objetosAlign y puede almacenarse en objetos Align a través de, por ejemplo,setManip

:
oFBB::center

:

CONSTRUCTORES
oAlign(Manipulator manip)
: Este constructor se usa para especificar una alineación que, cuando se inserta en unTable
, se utiliza para todos los elementos de la tabla. Este tipo de alineación general puede modificarse para columnas y/o elementos específicos usando los siguientes constructores;
oAlign(size_t column = 0, Manipulator manip = std::right)
:Este constructor define cómo se alinea el contenido de la columna `column ’ de un objeto Table . Cuando se usa, es responsabilidad del programador asegurarse de que la columna de la tabla exista (es decir, que la Table tenga un índice de columnacolumn
);
oAlign(int row, size_t column, Manipulator manip)
: Este constructor define la alineación del elemento [row][column] de un objeto Table . Antes de usar este constructor, el elemento de la tabla [row][column] 
    debe haber sido definido. Por ejemplo,

Table tab{ 3, Table::ROWWISE }; tab << "xx00x " << " x01x " << " x02xx" << 10 << 11 << 12; tab << Align(1, 1, FBB::center);

Están disponibles constructores de copia y movimiento (y operadores de asignación).
