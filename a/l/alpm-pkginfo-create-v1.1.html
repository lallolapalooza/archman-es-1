NOMBRE

alpm-pkginfo-create-v1 - Crear un archivo PKGINFO versión 1

SINOPSIS

alpm-pkginfo create v1 <--pkgname> <--pkgbase> <--pkgver> <--pkgdesc> <--url> <--builddate> <--packager> <--size> <--arch> [--license] [--replaces] [--group] [--conflict] [--provides] [--backup] [--depend] [--optdepend] [--makedepend] [--checkdepend] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Crear un archivo PKGINFO versión 1

OPCIONES

--pkgname <NOMBREPAQUETE>
El nombre del paquete a usar en PKGINFO.

El nombre del paquete debe seguir el formato alpm-package-name (ver `man 7 alpm-package-name`).

También se puede especificar con la variable de entorno PKGINFO_PKGNAME.
--pkgbase <BASEPAQUETE>
El base del paquete a usar en PKGINFO.

El base del paquete debe seguir el formato alpm-package-name (ver `man 7 alpm-package-name`).

También se puede especificar con la variable de entorno PKGINFO_PKGBASE.
--pkgver <VERPAQUETE>
La versión del paquete a usar en PKGINFO.

El valor de la versión del paquete debe seguir el formato alpm-pkgver (ver `man 7 alpm-pkgver`).

También se puede especificar con la variable de entorno PKGINFO_PKGVER.
--pkgdesc <DESCRIPCIÓNPAQUETE>
La descripción del paquete a usar en PKGINFO.

El valor debe seguir el formato descrito en el formato PKGINFO (ver `man 5 PKGINFO`).

También se puede especificar con la variable de entorno PKGINFO_PKGDESC.
--url <URL>
Proporcionar una URL.
También se puede especificar con la variable de entorno PKGINFO_URL.
--builddate <FECHACOMPILACION>
Proporcionar una fecha de compilación.
También se puede especificar con la variable de entorno PKGINFO_BUILDDATE.
--packager <EMPAQUETADOR>
Proporcionar un empaquetador.
También se puede especificar con la variable de entorno PKGINFO_PACKAGER.
--size <TAMAÑO>
Proporcionar un tamaño.
También se puede especificar con la variable de entorno PKGINFO_SIZE.
--arch <ARQUITECTURA>
Proporcionar una arquitectura.
También se puede especificar con la variable de entorno PKGINFO_ARCH.
--license <LICENCIA>
Proporcionar una o más licencias.
También se puede especificar con la variable de entorno PKGINFO_LICENSE.
--replaces <REEMPLAZA>
Proporcionar uno o más reemplazos.
También se puede especificar con la variable de entorno PKGINFO_REPLACES.
--group <GRUPO>
Proporcionar uno o más grupos.
También se puede especificar con la variable de entorno PKGINFO_GROUP.
--conflict <CONFLICTO>
Proporcionar uno o más conflictos.
También se puede especificar con la variable de entorno PKGINFO_CONFLICT.
--provides <PROPORCIONA>
Proporcionar uno o más proporcionados.
También se puede especificar con la variable de entorno PKGINFO_PROVIDES.
--backup <RESPALDO>
Proporcionar uno o más respaldos.
También se puede especificar con la variable de entorno PKGINFO_BACKUP.
--depend <DEPENDENCIA>
Proporcionar una o más dependencias.
También se puede especificar con la variable de entorno PKGINFO_DEPEND.
--optdepend <DEPENDENCIA OPCIONAL>
Proporcionar una o más dependencias opcionales.
También se puede especificar con la variable de entorno PKGINFO_OPTDEPEND.
--makedepend <DEPENDENCIA DE COMPILACIÓN>
Proporcionar una o más dependencias de compilación.
También se puede especificar con la variable de entorno PKGINFO_MAKEDEPEND.
--checkdepend <DEPENDENCIA DE PRUEBA>
Proporcionar una o más dependencias de prueba.
También se puede especificar con la variable de entorno PKGINFO_CHECKDEPEND.
-h, --help
Imprimir ayuda (ver un resumen con '-h').
[ARCHIVO] [predeterminado: .PKGINFO]
Un archivo personalizado opcional para escribir.
También se puede especificar con la variable de entorno PKGINFO_OUTPUT_FILE.
