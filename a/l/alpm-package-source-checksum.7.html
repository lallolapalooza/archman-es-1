alpm-package-source-checksum(7)

Paquete: alpm-docs

Licencias: CC-BY-SA-4.0

(7) Manual de Información Diversa (7)

NOMBRE

checksum de fuente de paquete - un checksum para verificar la integridad de una fuente de paquete utilizada para construir un paquete basado en ALPM.

DESCRIPCIÓN

Los paquetes basados en ALPM pueden construirse utilizando fuentes de paquete y para cada una de ellas debe existir al menos un checksum de fuente de paquete válido para poder verificar la integridad de la fuente.

De manera análoga a las fuentes de paquete, los checksums de fuentes de paquete pueden especificarse de forma genérica o específica de la arquitectura.

El valor de un checksum de fuente de paquete es la salida de una función hash[1], o la cadena especial ‘SKIP’, que indica que no se debe realizar ninguna verificación de checksum para una fuente determinada.

Las siguientes funciones hash[1] son compatibles:

  • MD5[2]
  • SHA-1[3]
  • SHA-224 (parte de la familia SHA-2 [4])
  • SHA-256 (parte de la familia SHA-2 [4])
  • SHA-384 (parte de la familia SHA-2 [4])
  • SHA-512 (parte de la familia SHA-2 [4])
  • BLAKE2[5]
  • CRC-32/CKSUM (cksum[6] variante de la comprobación de redundancia cíclica (CRC) de 32 bits ( [7])

Si existen varios checksums de fuente de paquete para una fuente de paquete, deben usar funciones hash distintas (por ejemplo, SHA-512 y BLAKE2). El número de checksums de fuente de paquete en cada categoría de función hash debe coincidir siempre con el número de fuentes de paquetedisponibles.

En los archivos PKGBUILD , un checksum de fuente de paquete se define añadiendo un valor a una de las siguientes matrices:

  • md5sums (función hash: MD5)
  • sha1sums (función hash: SHA-1)
  • sha224sums (función hash: SHA-224)
  • sha256sums (función hash: SHA-256)
  • sha384sums (función hash: SHA-384)
  • sha512sums (función hash: SHA-512)
  • b2sums (función hash: BLAKE2)
  • cksums (función hash: CRC-32/CKSUM)

Cada matriz acepta exclusivamente la salida de la respectiva función hash o la cadena especial ‘SKIP’ como valor.

Alternativamente, cualquiera de los nombres de matriz anteriores, seguido directamente por un carácter de subrayado (“_”), seguido directamente por una arquitectura alpm (todas excepto any) puede usarse para definir un checksum de fuente para una arquitectura específica (por ejemplo, b2sums_aarch64).

En los archivos SRCINFO , un checksum de fuente de paquete se define asignando un valor a una de las siguientes palabras clave:

  • md5sums (función hash: MD5)
  • sha1sums (función hash: SHA-1)
  • sha224sums (función hash: SHA-224)
  • sha256sums (función hash: SHA-256)
  • sha384sums (función hash: SHA-384)
  • sha512sums (función hash: SHA-512)
  • b2sums (función hash: BLAKE2)
  • cksums (función hash: CRC-32/CKSUM)

Cada asignación de palabra clave acepta exclusivamente la salida de la respectiva función hash o la cadena especial ‘SKIP’ como valor.

Alternativamente, cualquiera de las palabras clave anteriores, seguido directamente por un carácter de subrayado (“_”), seguido directamente por una arquitectura alpm (todas excepto any) puede usarse para definir un checksum de fuente para una arquitectura específica (por ejemplo, b2sums_aarch64).

EJEMPLOS

Fuente remota con checksums

El ejemplo de PKGBUILD anterior define una configuración de fuente de paquete en la que una fuente remota se verifica usando un hash SHA-512 y un BLAKE2 . La verificación de checksum para la firma OpenPGP se omite usando la cadena SKIP .

pkgname=example
pkgver=0.1.0
pkgrel=1
pkgdesc="A package example"
arch=(x86_64)
url="https://example.org"
license=(GPL-3.0-or-later)
makedepends=(meson)
depends=(
  gcc-libs
  glibc
)
source=($pkgname-$pkgver.tar.gz::https://download.example.org/$pkgname-v$pkgver.tar.gz{,.sig})
sha512sums=(
  0cf9180a764aba863a67b6d72f0918bc131c6772642cb2dce5a34f0a702f9470ddc2bf125c12198b1995c233c34b4afd346c54a2334c350a948a51b6e8b4e6b6
  'SKIP'
)
b2sums=(
  d202d7951df2c4b711ca44b4bcc9d7b363fa4252127e058c1a910ec05b6cd038d71cc21221c031c0359f993e746b07f5965cf8c5c3746a58337ad9ab65278e77
  'SKIP'
)
validpgpkeys=(988881ADC9FC3655077DC2D4D757D480B5EA0E11)
build() {
  meson setup --prefix /usr $pkgname-$pkgver build
  meson compile -C build
}
package(){
  meson install -C build --destdir "$pkgdir"
}

El PKGBUILD se representa mediante el siguiente SRCINFO:

pkgbase = example
    pkgdesc = A package example
    pkgver = 0.1.0
    pkgrel = 1
    url = https://example.org
    arch = x86_64
    license = GPL-3.0-or-later
    makedepends = meson
    depends = gcc-libs
    depends = glibc
    source = example-0.1.0.tar.gz::https://download.example.org/example-v0.1.0.tar.gz
    sha512sums = 0cf9180a764aba863a67b6d72f0918bc131c6772642cb2dce5a34f0a702f9470ddc2bf125c12198b1995c233c34b4afd346c54a2334c350a948a51b6e8b4e6b6
    sha512sums = SKIP
    b2sums = d202d7951df2c4b711ca44b4bcc9d7b363fa4252127e058c1a910ec05b6cd038d71cc21221c031c0359f993e746b07f5965cf8c5c3746a58337ad9ab65278e77
    b2sums = SKIP
pkgname = example

Fuente remota con checksums para varias arquitecturas

El ejemplo de PKGBUILD siguiente define una configuración de fuente de paquete en la que dos fuentes remotas se verifican usando un hash SHA-512 y un BLAKE2 cada una. Una fuente se usa exclusivamente en la arquitectura x86_64 y la otra exclusivamente en la arquitectura aarch64 .

pkgname=example
pkgver=0.1.0
pkgrel=1
pkgdesc="A package example"
arch=(
  aarch64
  x86_64
)
url="https://example.org"
license=(GPL-3.0-or-later)
makedepends=(meson)
depends=(
  gcc-libs
  glibc
)
source_aarch64=(
  $pkgname-$pkgver.tar.gz::https://download.example.org/$pkgname-aarch64-v$pkgver.tar.gz
)
source_x86_64=(
  $pkgname-$pkgver.tar.gz::https://download.example.org/$pkgname-x86_64-v$pkgver.tar.gz
)
sha512sums_aarch64=(
  cc06808cbbee0510331aa97974132e8dc296aeb795be229d064bae784b0a87a5cf4281d82e8c99271b75db2148f08a026c1a60ed9cabdb8cac6d24242dac4063
)
sha512sums_x86_64=(
  0cf9180a764aba863a67b6d72f0918bc131c6772642cb2dce5a34f0a702f9470ddc2bf125c12198b1995c233c34b4afd346c54a2334c350a948a51b6e8b4e6b6
)
b2sums_aarch64=(
  a69cc58858cb37cf8da7f83f55c23f171ee3c59be76ad7edcf01dec36fd9d0104bb433cd863ee3f0b6a10a336cf2400688c57fd99392dc01c4585d8725547e8c
)
b2sums_x86_64=(
  d202d7951df2c4b711ca44b4bcc9d7b363fa4252127e058c1a910ec05b6cd038d71cc21221c031c0359f993e746b07f5965cf8c5c3746a58337ad9ab65278e77
)
build() {
  meson setup --prefix /usr $pkgname-$pkgver build
  meson compile -C build
}
package(){
  meson install -C build --destdir "$pkgdir"
}
