NOMBRE

al_open_video_f - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_video.h>
ALLEGRO_VIDEO* al_open_video_f(ALLEGRO_FILE *fp, const char *ident)

DESCRIPCIÓN

Abre un archivo de video desde un ALLEGRO_FILE* existente utilizando el sistema de interfaz de archivos de Allegro. Esto permite cargar videos desde fuentes personalizadas como flujos de memoria, sistemas de archivos virtuales, archivos o cualquier otra fuente compatible con una ALLEGRO_FILE_INTERFACE personalizada.

Parámetros:

•
file: Un puntero a un objeto ALLEGRO_FILE. La propiedad de este archivo se transfiere al objeto de video; el archivo se cerrará automáticamente cuando se llame a al_close_video.

Devuelve: Un puntero a un nuevo objeto ALLEGRO_VIDEO si tiene éxito, o NULL si falla.

Observaciones:

•
La función no requiere que el archivo sea buscable o rebobinado; lee desde la posición actual.
•
Después de llamar a al_open_video_f, no debe cerrar manualmente el ALLEGRO_FILE; llame a al_close_video para liberar todos los recursos asociados.
•
Esta función refleja el comportamiento de otras variantes _f en la API de Allegro, permitiendo la transmisión de video desde sistemas de archivos personalizados.

Ejemplo:

ALLEGRO_FILE *f = al_fopen("video.ogv", "rb");
if (f) {
    ALLEGRO_VIDEO *vid = al_open_video_f(f);
    if (vid) {
        float fps = al_get_video_fps(vid);
        // ... usar el video ...
        al_close_video(vid); // también cierra f
    }
}
