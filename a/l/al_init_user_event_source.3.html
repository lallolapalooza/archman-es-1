al_init_user_event_source(3) Manual de funciones de biblioteca al_init_user_event_source(3)

NOMBRE

al_init_user_event_source - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_init_user_event_source(ALLEGRO_EVENT_SOURCE *src)

DESCRIPCIÓN

Inicializa una fuente de eventos para emitir eventos de usuario. El espacio para la fuente de eventos ya debe haber sido asignado.

Una forma posible de crear fuentes de eventos personalizadas es derivar otras estructuras con ALLEGRO_EVENT_SOURCE en la cabeza, por ejemplo:

typedef struct THING THING;
struct THING {
    ALLEGRO_EVENT_SOURCE event_source;
    int field1;
    int field2;
    /* etc. */
};
THING *create_thing(void)
{
    THING *thing = malloc(sizeof(THING));
    if (thing) {
        al_init_user_event_source(&thing->event_source);
        thing->field1 = 0;
        thing->field2 = 0;
    }
    return thing;
}

La ventaja aquí es que el puntero THING será el mismo que el puntero ALLEGRO_EVENT_SOURCE. Los eventos emitidos por la fuente de eventos tendrán el puntero de la fuente de eventos como campo source, desde el cual puede obtener un puntero a THING mediante una simple conversión (después de asegurarse de verificar que el evento es del tipo correcto).

Sin embargo, es solo una técnica y no está obligado a usarla.

La fuente de eventos de usuario nunca se destruirá automáticamente. Debe destruirla manualmente con al_destroy_user_event_source(3).
