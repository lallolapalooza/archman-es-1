NOMBRE

ALTER_TEXT_SEARCH_CONFIGURATION - cambiar la definición de una configuración de búsqueda de texto

SINOPSIS

ALTER TEXT SEARCH CONFIGURATION nombre
    ADD MAPPING FOR tipo_token [, ... ] WITH nombre_diccionario [, ... ]
ALTER TEXT SEARCH CONFIGURATION nombre
    ALTER MAPPING FOR tipo_token [, ... ] WITH nombre_diccionario [, ... ]
ALTER TEXT SEARCH CONFIGURATION nombre
    ALTER MAPPING REPLACE diccionario_antiguo WITH diccionario_nuevo
ALTER TEXT SEARCH CONFIGURATION nombre
    ALTER MAPPING FOR tipo_token [, ... ] REPLACE diccionario_antiguo WITH diccionario_nuevo
ALTER TEXT SEARCH CONFIGURATION nombre
    DROP MAPPING [ IF EXISTS ] FOR tipo_token [, ... ]
ALTER TEXT SEARCH CONFIGURATION nombre RENAME TO nombre_nuevo
ALTER TEXT SEARCH CONFIGURATION nombre OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER TEXT SEARCH CONFIGURATION nombre SET SCHEMA esquema_nuevo

DESCRIPCIÓN

ALTER TEXT SEARCH CONFIGURATION cambia la definición de una configuración de búsqueda de texto. Puede modificar sus mapeos de tipos de token a diccionarios, o cambiar el nombre o propietario de la configuración.

Debe ser el propietario de la configuración para usar ALTER TEXT SEARCH CONFIGURATION.

PARÁMETROS

nombre

El nombre (opcionalmente calificado con esquema) de una configuración de búsqueda de texto existente.

tipo_token

El nombre de un tipo de token que emite el analizador de la configuración.

nombre_diccionario

El nombre de un diccionario de búsqueda de texto que se consultará para el(los) tipo(s) de token especificado(s). Si se enumeran varios diccionarios, se consultan en el orden especificado.

diccionario_antiguo

El nombre de un diccionario de búsqueda de texto que se reemplazará en el mapeo.

diccionario_nuevo

El nombre de un diccionario de búsqueda de texto que se sustituirá por diccionario_antiguo.

nombre_nuevo

El nuevo nombre de la configuración de búsqueda de texto.

nuevo_propietario

El nuevo propietario de la configuración de búsqueda de texto.

esquema_nuevo

El nuevo esquema para la configuración de búsqueda de texto.

La forma ADD MAPPING FOR instala una lista de diccionarios que se consultarán para el(los) tipo(s) de token especificado(s); es un error si ya existe un mapeo para alguno de los tipos de token. La forma ALTER MAPPING FOR hace lo mismo, pero primero elimina cualquier mapeo existente para esos tipos de token. Las formas ALTER MAPPING REPLACE sustituyen diccionario_nuevo por diccionario_antiguo en cualquier lugar donde aparezca este último. Esto se hace solo para los tipos de token especificados cuando aparece FOR, o para todos los mapeos de la configuración cuando no lo hace. La forma DROP MAPPING elimina todos los diccionarios para el(los) tipo(s) de token especificado(s), haciendo que los tokens de esos tipos sean ignorados por la configuración de búsqueda de texto. Es un error si no existe un mapeo para los tipos de token, a menos que aparezca IF EXISTS.

EJEMPLOS

El siguiente ejemplo reemplaza el diccionario inglés con el diccionario sueco dondequiera que se use inglés dentro de my_config.

ALTER TEXT SEARCH CONFIGURATION my_config
  ALTER MAPPING REPLACE english WITH swedish;

COMPATIBILIDAD

No existe la instrucción ALTER TEXT SEARCH CONFIGURATION en el estándar SQL.

VER TAMBIÉN

CREATE TEXT SEARCH CONFIGURATION (CREATE_TEXT_SEARCH_CONFIGURATION(7)), DROP TEXT SEARCH CONFIGURATION (DROP_TEXT_SEARCH_CONFIGURATION(7))
