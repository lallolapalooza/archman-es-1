al_fixsub(3) Manual de Funciones de Biblioteca al_fixsub(3)

NOMBRE

al_fixsub - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
al_fixed al_fixsub(al_fixed x, al_fixed y);

DESCRIPCIÓN

Aunque los números de punto fijo se pueden restar con el operador entero normal -, esto no proporciona ninguna protección contra desbordamientos. Si el desbordamiento es un problema, deberías usar esta función en su lugar. Es más lenta que usar operadores enteros, pero si ocurre un desbordamiento, establecerá el errno de Allegro y ajustará el resultado, en lugar de simplemente dejar que se desborde.

Ejemplo:

al_fixed resultado;
/* Esto pondrá 4965 en `resultado'. */
resultado = al_fixsub(al_itofix(5000), al_itofix(35));
/* Establece errno y pone -32768 en `resultado'. */
resultado = al_fixsub(al_itofix(-31000), al_itofix(3000));
assert(!al_get_errno()); /* Esto fallará. */

VALOR DE RETORNO

Devuelve el resultado ajustado de restar y de x, estableciendo el errno de Allegro a ERANGE si hubo un desbordamiento.

VER TAMBIÉN

al_fixadd(3), al_fixmul(3), al_fixdiv(3), al_get_errno(3).
