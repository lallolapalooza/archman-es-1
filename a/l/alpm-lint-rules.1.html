NOMBRE

alpm-lint-rules - Devuelve la definición de todas las reglas de linting como datos estructurados

SINOPSIS

alpm-lint rules [-f|--format] [-v|--verbose]... [-p|--pretty] [-q|--quiet]... [-o|--output] [-h|--help]

DESCRIPCIÓN

Devuelve la definición de todas las reglas de linting como datos estructurados

OPCIONES

-f, --format <FORMATO> [predeterminado: json]
El formato de salida a usar

Valores posibles:

•
json: El formato de salida JSON
-v, --verbose
Aumenta la verbosidad del registro
-p, --pretty
Imprime la salida de forma legible.

No tiene efecto si el formato de salida no puede imprimirse de forma legible.

-q, --quiet
Disminuye la verbosidad del registro
-o, --output <ARCHIVO>
Ruta opcional del archivo de salida.

Si no se proporciona, la salida va a stdout.

-h, --help
Imprime la ayuda (ver un resumen con '-h')
