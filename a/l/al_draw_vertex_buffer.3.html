NOMBRE

al_draw_vertex_buffer - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
int al_draw_vertex_buffer(ALLEGRO_VERTEX_BUFFER* vertex_buffer,
   ALLEGRO_BITMAP* texture, int start, int end, int type)

DESCRIPCIÓN

Dibuja un subconjunto del buffer de vértices proporcionado. El buffer de vértices no debe estar bloqueado. Además, para dibujar en mapas de bits de memoria o con texturas de mapas de bits de memoria, el buffer de vértices debe admitir lectura (es decir, debe crearse con ALLEGRO_PRIM_BUFFER_READWRITE).

Parámetros:

•
vertex_buffer - Buffer de vértices a dibujar
•
texture - Textura a utilizar, pasar NULL para usar solo primitivas con color sombreado
•
start - Índice de inicio del subconjunto del buffer de vértices a dibujar
•
end - Un índice posterior al último índice del subconjunto del buffer de vértices a dibujar
•
type - Un miembro de la enumeración ALLEGRO_PRIM_TYPE(3), que especifica qué tipo de primitiva dibujar

Devuelve: Número de primitivas dibujadas
