NOMBRE

al_android_open_fd - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_android.h>
int al_android_open_fd(const char *uri, const char *mode)

DESCRIPCIÓN

Abre un descriptor de archivo para acceder a datos bajo un Identificador Uniforme de Recurso (URI). Esta función acepta esquemas de URI content:// y file://. Usted es responsable de cerrar el descriptor de archivo devuelto.

El modo de archivo puede ser "r", "w", "rw", "wt", "wa" o "rwt". La implementación exacta de estos modos difiere según el proveedor de contenido subyacente. Por ejemplo, "w" puede o no truncar.

Devuelve un descriptor de archivo en caso de éxito o un valor negativo en caso de error. En caso de error, se establece el errno de Allegro.

Nota: Recuerde añadir los permisos relevantes a su aplicación en el archivo de manifiesto.

Ejemplo:

const char *content_uri = "content://...";
int fd = al_android_open_fd(content_uri, "r");
if (fd >= 0) {
    ALLEGRO_FILE *f = al_fopen_fd(fd, "r");
    if (f != NULL) {
        do_something_with(f);
        al_fclose(f);
    }
    else {
        handle_error(al_get_errno());
        close(fd);
    }
}
else {
    handle_error(al_get_errno());
}

DESDE

5.2.10

VER TAMBIÉN

al_fopen_fd(3), al_get_errno(3)

[API Inestable]: Esta API es nueva y está sujeta a refinamiento.
