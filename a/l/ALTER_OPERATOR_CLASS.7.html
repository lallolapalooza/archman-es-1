ALTER_OPERATOR_CLASS(7)

Paquete: postgresql

Licencias: PostgreSQL

ALTER OPERATOR CLASS(7) Documentación de PostgreSQL 18.1 ALTER OPERATOR CLASS(7)

NOMBRE

ALTER_OPERATOR_CLASS - cambia la definición de una clase de operador

SINOPSIS

ALTER OPERATOR CLASS nombre USING método_índice
    RENAME TO nuevo_nombre
ALTER OPERATOR CLASS nombre USING método_índice
    OWNER TO { nuevo_propietario | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER OPERATOR CLASS nombre USING método_índice
    SET SCHEMA nuevo_esquema

DESCRIPCIÓN

ALTER OPERATOR CLASS cambia la definición de una clase de operador.

Debes ser el propietario de la clase de operador para usar ALTER OPERATOR CLASS. Para cambiar el propietario, debes poder ejecutar SET ROLE al nuevo rol propietario, y ese rol debe tener privilegio CREATE en el esquema de la clase de operador. (Estas restricciones aseguran que al cambiar el propietario no se haga nada que no se pudiera hacer al eliminar y recrear la clase de operador. Sin embargo, un superusuario puede alterar la propiedad de cualquier clase de operador de todos modos).

PARÁMETROS

nombre

El nombre (opcionalmente calificado por esquema) de una clase de operador existente.

método_índice

El nombre del método de índice para el cual es esta clase de operador.

nuevo_nombre

El nuevo nombre de la clase de operador.

nuevo_propietario

El nuevo propietario de la clase de operador.

nuevo_esquema

El nuevo esquema para la clase de operador.

COMPATIBILIDAD

No existe una sentencia ALTER OPERATOR CLASS en el estándar SQL.

VER TAMBIÉN

CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7)), DROP OPERATOR CLASS (DROP_OPERATOR_CLASS(7)), ALTER OPERATOR FAMILY (ALTER_OPERATOR_FAMILY(7))
