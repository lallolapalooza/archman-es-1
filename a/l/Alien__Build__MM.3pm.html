DESCRIPCIÓ

N

Esta clase te permite usar Alien::Build y Alien::Base con ExtUtils::MakeMaker. Carga la receta alienfile en la raíz de tu dist Alien, actualiza los prerrequisitos pasados a "WriteMakefile" si alguno es especificado por tu alienfile o sus plugins, y añade un postamble al "Makefile" que descargará/compilará/probará el paquete alienizado según

corresponda.

El archivo alienfile debe llamarse "alienfile"

.

Si estás usando Dist::Zilla para autorar tu dist Alien, deberías considerar usar el plugin Dist::Zilla::Plugin::

AlienBuild.

Personalmente no lo recomiendo, pero s

i quieres usar Module::Build en s
u lugar, puedes usar Alien::Build::MB.

Devuelve el postamble para el "Makefile" necesario para Alien::Build. Esto añade los siguientes objetivos "make" que normalmente se ejecutan cuando ejecutas "make all", pero pueden ejecutarse individualmente si es necesario para

depurar.
alien_pref
ix
Determina el prefijo de instalación final ("%{.install.pre
fix}").
alien_versi
on
Determina la perl_module_version ("%{.runtime.perl_module
_version}")
alien_downlo
ad
Descarga el código fuente de internet. No hace nada para una instalación de
sistema.
alien_bui
ld
Compila desde el código fuente (si es una instalación share). Recopila la configuración (para instalación de sistema o
share).
alien_prop, alien_prop_meta, alien_prop_install, alien_prop_runt
ime
Imprime las propiedades meta, install y runtime para el
Alien.
alien_realclean,
alien_clean
Elimina los archivos específicos de Alien. Estos objetivos se ejecutan cuando llamas a los objetivos "realclean" y "clean" respecti
vamente.

all
Limpia el directorio share del Alien. Debe usarse
