al_draw_pixel(3) Manual de funciones de la biblioteca al_draw_pixel(3)

NOMBRE

al_draw_pixel - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_draw_pixel(float x, float y, ALLEGRO_COLOR color)

DESCRIPCIÓN

Dibuja un único píxel en x, y. Esta función, a diferencia de al_put_pixel(3), realiza mezcla y, a diferencia de al_put_blended_pixel(3), respeta las transformaciones (es decir, la posición del píxel se transforma, pero su tamaño no se ve afectado: sigue siendo un píxel). Esta función puede ser lenta si se llama con frecuencia; si necesita dibujar muchos píxeles, considere usar al_draw_prim(3) con ALLEGRO_PRIM_POINT_LIST del addon de primitivas.

•
x - destino x
•
y - destino y
•
color - color del píxel

Nota: Es posible que esta función no dibuje exactamente donde espera. Consulte la sección de salida precisa de píxeles en la documentación del addon de primitivas para obtener detalles sobre cómo controlar exactamente dónde se dibuja el píxel.

VEASE TAMBIÉN
