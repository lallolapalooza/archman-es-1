NOMBRE

al_ref_ustr - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
const ALLEGRO_USTR *al_ref_ustr(ALLEGRO_USTR_INFO *info, const ALLEGRO_USTR *us,
   int start_pos, int end_pos)

DESCRIPCIÓN

Crea una cadena de solo lectura que hace referencia al almacenamiento de otra cadena ALLEGRO_USTR(3). La información sobre la cadena (por ejemplo, su tamaño) se almacena en la estructura apuntada por el parámetro info. La nueva cadena no tendrá ningún otro almacenamiento asignado propio, por lo que si asigna la estructura info en la pila, no se requerirá ninguna operación explícita de "liberación".

El intervalo referenciado es [start_pos, end_pos). Ambos son desplazamientos de bytes.

La cadena es válida hasta que la cadena subyacente se modifique o se destruya.

Si necesita un rango de puntos de código en lugar de bytes, use al_ustr_offset(3) para encontrar los desplazamientos de bytes.

VER TAMBIÉN

al_ref_cstr(3), al_ref_buffer(3)
