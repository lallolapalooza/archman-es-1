Alien::Build::Plugin::Probe::Vcpkg(3) Documentación de Perl contribuida por el usuario Alien::Build::Plugin::Probe::Vcpkg(3)

NOMBRE

Alien::Build::Plugin::Probe::Vcpkg - Sondear bibliotecas del sistema usando Vcpkg

VERSIÓN

version 2.84

SINOPSIS

use alienfile;

plugin 'Probe::Vcpkg' => 'libffi';

DESCRIPCIÓN

Este plugin de sondeo se puede utilizar para encontrar paquetes del "sistema" usando el gestor de paquetes "Vcpkg" de Microsoft para compilaciones de Visual C++ de Perl. "Vcpkg" es un gestor de paquetes para Visual C++ que incluye una serie de paquetes de código abierto. Aunque "Vcpkg" también soporta Linux y macOS, este plugin no soporta la búsqueda de paquetes de "Vcpkg" en esas plataformas. Para más detalles sobre "Vcpkg", véase la página del proyecto en github aquí:

https://github.com/microsoft/vcpkg

Aquí tienes la guía de inicio rápido para que Alien::Build funcione con "Vpkg":

# instalar Vcpkg
C:\> git clone https://github.com/Microsoft/vcpkg.git
C:\> cd vcpkg
C:\vcpkg> .\bootstrap-vcpkg.bat
C:\vcpkg> .\vcpkg integrate install

# actualizar PATH para incluir el directorio bin
# para que los archivos .DLL puedan ser encontrados por Perl
C:\vcpkg> path c:\vcpkg\installed\x64-windows\bin;%PATH%

# instalar los paquetes que quieras
C:\vcpkg> .\vcpkg install libffi

# instalar el alien que lo utiliza
C:\vcpkg> cpanm Alien::FFI

Si estás utilizando una compilación de 32 bits de Perl, sustituye "x86-windows" por "x64-windows". Si no quieres añadir el directorio "bin" a "PATH", puedes usar "x64-windows-static" en su lugar, lo que proporcionará bibliotecas estáticas. (Hasta la fecha de redacción, las bibliotecas estáticas para Windows de 32 bits no están disponibles). La principal desventaja de usar "x64-windows-static" es que los Aliens que requieren bibliotecas dinámicas para FFI no se podrán instalar.

Si no quieres instalar "Vcpkg" en todo el sistema (el comando "integrate install" anterior), puedes usar la variable de entorno "PERL_WIN32_VCPKG_ROOT" en su lugar:

# instalar Vcpkg
C:\> git clone https://github.com/Microsoft/vcpkg.git
C:\> cd vcpkg
C:\vcpkg> .\bootstrap-vcpkg.bat
C:\vcpkg> set PERL_WIN32_VCPKG_ROOT=c:\vcpkg

PROPIEDADES

name

Especifica el nombre del Vcpkg. Esto no debe usarse con la propiedad "lib" más abajo, elige solo una.

Esta es la propiedad por defecto, por lo que estas dos son equivalentes:

plugin 'Probe::Vcpkg' => (name => 'foo');

y

plugin 'Probe::Vcpkg' => 'foo';

lib

Especifica la lista de bibliotecas que componen el Vcpkg. Esto no debe usarse con la propiedad "name" anterior, elige solo una. Ten en cuenta que usando este método de detección, el número de versión del paquete no se determinará automáticamente (ya que varios paquetes podrían componer la lista de bibliotecas), así que necesitas determinar el número de versión de otra manera si lo necesitas.

Debe ser una referencia a un array. No incluyas la extensión ".lib".

plugin 'Probe::Vcpkg' => (lib => ['foo','bar']);

ffi_name

Especifica un nombre ffi_name alternativo para encontrar bibliotecas dinámicas.
