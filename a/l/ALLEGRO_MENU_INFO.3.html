DESCRIPCIÓN

Una estructura que define cómo crear un sistema de menú completo. Para elementos de menú estándar, se utiliza el siguiente formato:

   { caption, id, flags, icon }

Para elementos especiales, estas macros son útiles:

ALLEGRO_START_OF_MENU(caption, id)
ALLEGRO_MENU_SEPARATOR
ALLEGRO_END_OF_MENU

Un menú bien definido comenzará con ALLEGRO_START_OF_MENU, contendrá uno o más elementos de menú y terminará con ALLEGRO_END_OF_MENU. Un menú puede contener submenús. Un ejemplo:

ALLEGRO_MENU_INFO menu_info[] = {
   ALLEGRO_START_OF_MENU("&File", 1),
      { "&Open", 2, 0, NULL },
      ALLEGRO_START_OF_MENU("Open &Recent...", 3),
         { "Recent 1", 4, 0, NULL },
         { "Recent 2", 5, 0, NULL },
         ALLEGRO_END_OF_MENU,
      ALLEGRO_MENU_SEPARATOR,
      { "E&xit", 6, 0, NULL },
      ALLEGRO_END_OF_MENU,
   ALLEGRO_START_OF_MENU("&Help", 7),
      {"&About", 8, 0, NULL },
      ALLEGRO_END_OF_MENU,
   ALLEGRO_END_OF_MENU
};
ALLEGRO_MENU *menu = al_build_menu(menu_info);

Si lo prefiere, puede construir el menú sin la estructura utilizando al_create_menu(3) y al_insert_menu_item(3).
