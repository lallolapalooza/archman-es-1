subroutine alaerh (character*3 path, character*( * ) subnam, integer info, integer infoe, character*( * ) opts, integer m, integer n, integer kl, integer ku, integer n5, integer imat, integer nfail, integer nerrs, integer nout)

ALAERH

Propósito:

!>
!> ALAERH es un manejador de errores para las rutinas de LAPACK. Imprime la
!> cabecera si este es el primer mensaje de error e imprime el código de
!> error y la forma de recuperación, si la hay. Las evaluaciones de caracteres en esta
!> rutina pueden hacerla lenta, pero no debe ser llamada una vez que las
!> rutinas de LAPACK estén completamente depuradas.
!>

Parámetros

PATH 
!>          PATH es CHARACTER*3
!>          El nombre de ruta de LAPACK de la subrutina SUBNAM.
!>

SUBNAM

!>          SUBNAM es CHARACTER*(*)
!>          El nombre de la subrutina que devolvió un código de error.
!>

INFO

!>          INFO es INTEGER
!>          El código de error devuelto por la rutina SUBNAM.
!>

INFOE

!>          INFOE es INTEGER
!>          El código de error esperado de la rutina SUBNAM, si SUBNAM
!>          no tuviera errores. Si INFOE = 0, se imprime un mensaje de error, pero
!>          si INFOE.NE.0, asumimos que solo el código de retorno INFO es incorrecto.
!>

OPTS

!>          OPTS es CHARACTER*(*)
!>          Las opciones de caracteres para la subrutina SUBNAM, concatenadas
!>          en una única cadena de caracteres. Por ejemplo, UPLO = 'U',
!>          TRANS = 'T', y DIAG = 'N' para una rutina triangular se
!>          especificarían como OPTS = 'UTN'.
!>

M

!>          M es INTEGER
!>          La dimensión de fila de la matriz.
!>

N

!>          N es INTEGER
!>          La dimensión de columna de la matriz. Se accede solo si PATH = xGE o
!>          xGB.
!>

KL

!>          KL es INTEGER
!>          El número de sub-diagonales de la matriz. Se accede solo si
!>          PATH = xGB, xPB, o xTB. También se usa para NRHS en PATH = xLS.
!>

KU

!>          KU es INTEGER
!>          El número de super-diagonales de la matriz. Se accede solo
!>          si PATH = xGB.
!>

N5

!>          N5 es INTEGER
!>          Un quinto parámetro entero, puede ser el tamaño del bloque NB o el
!>          número de lados derechos NRHS.
!>

IMAT

!>          IMAT es INTEGER
!>          El tipo de matriz.
!>

NFAIL

!>          NFAIL es INTEGER
!>          El número de pruebas previas que no pasaron el umbral;
!>          se utiliza para determinar si se debe imprimir la cabecera.
!>

NERRS

!>          NERRS es INTEGER
!>          A la entrada, el número de errores ya detectados; se utiliza para
!>          determinar si se debe imprimir la cabecera.
!>          A la salida, NERRS se incrementa en 1.
!>

NOUT

!>          NOUT es INTEGER
!>          El número de unidad en el que se imprimirán los resultados.
!>
