SINOPSI

S

Cree su

plugin: 
package Alien::Build::Plugin::Type::MyPlugin;

use Alien::Build::Plugin;
use Carp ();

has prop1 => 'default value';
has prop2 => sub { 'default value' };
has prop3 => sub { Carp::croak 'prop3 is a required property' };

sub init
{
  my($self, $meta) = @_;

  my $prop1 = $self->prop1;
  my $prop2 = $self->prop2;
  my $prop3 = $self->prop3;

  $meta->register_hook(sub {
    build => [ '%{make}', '%{make} install' ],
  });
}

Desde su

alienfile 
use alienfile;
plugin 'Type::MyPlugin' => (
  prop2 => 'different value',
  prop3 => 'need to provide since it is required',
)
;

instance_i

d

instance_id;

Devuelve un id de instancia para el plugin. Se calcula a partir de la clase y los ar

gumentos que se pasan al constructor del plugin, por lo que técnicamente dos instanc
ias con exactamente los mismos argumentos tendrán el mismo id de instancia, pero en l
a práctica nunca debería tener dos instancias con exactamente los mismos argumentos.
