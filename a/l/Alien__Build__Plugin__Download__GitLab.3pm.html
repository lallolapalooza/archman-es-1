Alien::Build::Plugin::Download::GitLab(3) Documentación de Perl de Contribución del Usuario Alien::Build::Plugin::Download::GitLab(3)

NOMBRE

Alien::Build::Plugin::Download::GitLab - plugin de Alien::Build para descargar desde GitLab

VERSIÓN

versión 0.01

SINOPSIS

use alienfile;

plugin 'Download::GitLab' => (
  gitlab_user    => 'plicease',
  gitlab_project => 'dontpanic',
);

DESCRIPCIÓN

Este plugin está diseñado para descargar activos de una instancia de GitLab.

PROPIEDADES

gitlab_host

El host desde el cual obtener, por defecto https://gitlab.com.

gitlab_user

El usuario desde el cual obtener.

gitlab_project

El proyecto desde el cual obtener.

tipo

El tipo de activo a obtener. Debe ser uno de "source" o "link".

formato

El formato esperado del activo. Debe ser uno que Alien::Build::Plugin::Extract::Negotiate entienda. El valor por defecto es "tar.gz".

version_from

De dónde obtener la versión. Debe ser uno de "tag_name" o "name". El valor por defecto es "tag_name".

convert_version

Esta es una referencia de código opcional, que puede ser utilizada para modificar la versión. Por ejemplo, si las etiquetas tienen un prefijo "v", podrías eliminarlo de esta manera:

plugin 'Download::GitLab' => (
  gitlab_user     => 'plicease',
  gitlab_project  => 'dontpanic',
  convert_version => sub {
    my $version = shift;
    $version =~ s/^v//;
    return $version;
  },
);

link_name

Para los tipos "link", esta es una expresión regular que filtra los nombres de archivo del activo. Por ejemplo, si hay varios formatos de archivo disponibles, puedes obtener solo el tarball comprimido con gzip estableciendo esto a "qr/\.tar\.gz$/".
