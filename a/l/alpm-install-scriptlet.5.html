alpm-install-scriptlet(5)

Paquete: alpm-docs

Licencias: CC-BY-SA-4.0

(5) Manual de formatos de archivo (5)

NOMBRE

alpm-install-scriptlet – un script de instalación personalizado para paquetes basados en ALPM.

DESCRIPCIÓN

Un script de shell opcional que define acciones personalizadas a realizar durante la instalación, actualización o eliminación de un paquete.

Las funciones del shell se ejecutan en la raíz (/) del sistema, por lo que todas las rutas dentro de él deben ser absolutas.

Dichos archivos se encuentran en la raíz de los paquetes ALPM y se denominan .INSTALL.

Formato general

Un alpm-install-scriptlet puede contener cero o más funciones de shell específicas que definen acciones para diferentes eventos del ciclo de vida del paquete. Todas las funciones son opcionales y solo aquellas necesarias para un paquete determinado pueden incluirse.

El script puede estar escrito en un lenguaje de shell que admita la opción de línea de comandos -c y la llamada a funciones con nombre con argumentos adicionales desde la interfaz de línea de comandos del intérprete.

Tenga en cuenta que el intérprete de shell utilizado por el software de gestión de paquetes para ejecutar el script se define globalmente (por ejemplo, por distribución). No se utiliza ninguna shebang en el script y la decisión sobre qué shell usar para ejecutarlo no se basa en los metadatos de un paquete, sino que generalmente se establece a nivel de distribución o sistema. Esto implica que el intérprete de shell no se puede cambiar por paquete.

Funciones

Las funciones disponibles se enumeran a continuación. Aceptan uno o dos argumentos que son versiones de paquetes, proporcionados como alpm-package-version.

pre_install

Se ejecuta antes de instalar un paquete, con la nueva versión del paquete como argumento.

post_install

Se ejecuta después de instalar un paquete, con la nueva versión del paquete como argumento.

pre_upgrade

Se ejecuta antes de actualizar un paquete, con los siguientes argumentos:

1.
Nueva versión del paquete
2.
Versión antigua del paquete
post_upgrade

Se ejecuta después de actualizar un paquete, con los siguientes argumentos:

1.
Nueva versión del paquete
2.
Versión antigua del paquete
pre_remove

Se ejecuta antes de eliminar un paquete, con la versión antigua del paquete como argumento.

post_remove

Se ejecuta después de eliminar un paquete, con la versión antigua del paquete como argumento.

EJEMPLOS

Ejemplo de especificación de un script de instalación en el archivo PKGBUILD:

install=example.install

Ejemplo de un script basic example.install:

pre_install() {
    echo "Preparando para instalar el paquete versión $1"
}
post_install() {
    echo "Paquete versión $1 instalado"
}
pre_upgrade() {
    echo "Preparando para actualizar de la versión $2 a la $1"
}
post_upgrade() {
    echo "Actualizado de la versión $2 a la $1"
}
pre_remove() {
    echo "Preparando para eliminar el paquete versión $1"
}
post_remove() {
    echo "Paquete versión $1 eliminado"
}
