NOMBRE

al_set_new_bitmap_samples - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_set_new_bitmap_samples(int samples)

DESCRIPCIÓN

Establece las muestras de multisampling utilizadas por los nuevos mapas de bits creados (en el hilo actual) si se usan con al_set_target_bitmap(3). 0 significa que no se usará multisampling al dibujar en el mapa de bits, que es el valor predeterminado. 1 significa que se usará multisampling pero solo usando una muestra por píxel (por lo que generalmente no habrá diferencia visual con no usar multisampling en absoluto).

Nota: Algunas plataformas tienen restricciones sobre cuándo se realiza la implementación del búfer de multisampling de un mapa de bits, es decir, se escala hacia atrás a las dimensiones reales del mapa de bits. Esto puede ocurrir solo después de una llamada a al_set_target_bitmap(3). Por ejemplo:

al_set_target_bitmap(multisample);
al_clear_to_color(blue);
al_draw_line(0, 0, 100, 100, red, 1);
al_lock_bitmap(multisample, ...)
// ERROR: el contenido del mapa de bits será indefinido
al_set_target_bitmap(backbuffer);
al_lock_bitmap(multisample, ...)
// CORRECTO: en este punto, el contenido del mapa de bits se ha actualizado y
// habrá una línea con anti-aliasing en él.

DESDE

5.2.1

[API inestable]: Esta es una característica experimental y actualmente solo funciona para el backend de OpenGL.
