NAME

alpm-state-repo - Arch Linux Package Manager (ALPM) repository state file

DESCRIPTION

The repository state file is used by libalpm to keep track of the state of the repositories. It is stored in /var/lib/pacman/sync. The file is named after the repository name, appended with .state. For example, the state file for the 'core' repository would be core.state.

The state file contains information about the packages available in the repository, including their names, versions, and dependencies. This information is used by libalpm to determine which packages need to be updated or installed.

FORMAT

The repository state file is a plain text file with the following format:

# <repository name>
# <creation date>
# <number of packages>
<package name> <package version> <package architecture> [<package description>]
<package name> <package version> <package architecture> [<package description>]
...

The first line is the repository name. The second line is the creation date in YYYY-MM-DD format. The third line is the number of packages in the repository. Each subsequent line represents a package and contains its name, version, architecture, and an optional description.

EXAMPLES

# core
# 2023-10-27
# 350
bash 5.2.015-1 x86_64 GNU Bourne Again shell
coreutils 9.4-1 x86_64 Core GNU utilities
...

SEE ALSO

alpm(3), pacman(8)

NOTES

The repository state file is automatically updated by pacman whenever the package database is synchronized. It is not recommended to manually edit this file.
