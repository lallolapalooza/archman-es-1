al_do_multiline_text(3) Manual de funciones de la biblioteca al_do_multiline_text(3)

NOMBRE

al_do_multiline_text - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_font.h>
void al_do_multiline_text(const ALLEGRO_FONT *font,
   float max_width, const char *text,
   bool (*cb)(int line_num, const char *line, int size, void *extra),
   void *extra)

DESCRIPCIÓN

Esta función procesa el text y lo divide en líneas como lo haría al_draw_multiline_text(3), y luego llama a la función de devolución de llamada cb una vez por cada línea. Esto es útil para dibujar texto multilínea personalizado o para calcular el tamaño del texto multilínea con antelación. Consulte la documentación de al_draw_multiline_text(3) para obtener una explicación del algoritmo de división.

Por cada línea en la que esta función divide text, se llamará a la función de devolución de llamada cb una vez con los siguientes parámetros:

•
line_num: el número de línea comenzando desde cero y contando hacia arriba
•
line: un puntero al carácter de inicio de la línea (ver abajo)
•
size: el tamaño de la línea (0 para líneas vacías)
•
extra: el mismo puntero que se pasó a al_do_multiline_text

Tenga en cuenta que line no está garantizado que sea una cadena terminada en NULO, sino que simplemente apuntará a un carácter dentro de text o a una cadena vacía en caso de una línea vacía. Si necesita una cadena terminada en NULO, deberá copiar line a un búfer y terminarla usted mismo con NULO. También deberá hacer su propia copia si necesita el contenido de line después de que cb haya retornado, ya que line no está garantizado que sea válido después de eso.

Si la función de devolución de llamada cb retorna falso, al_do_multiline_text se detendrá inmediatamente, de lo contrario continuará con la siguiente línea.
