NOMBRE

al_get_cpu_count - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
int al_get_cpu_count(void)

DESCRIPCIÓN

Devuelve el número de núcleos de CPU que tiene el sistema en el que se está ejecutando Allegro y que se pudieron detectar, o un número negativo si la detección falló. Incluso si se devuelve un número positivo, es posible que no sea correcto. Por ejemplo, Allegro ejecutándose en una máquina virtual devolverá la cantidad de CPU de la VM, y no la del sistema subyacente.

Además, incluso si el número es correcto, esto solo le proporciona información sobre los núcleos de CPU totales del sistema en el que se ejecuta Allegro. La cantidad de núcleos disponibles para su programa puede ser menor debido a circunstancias como programas que se están ejecutando actualmente.

Por lo tanto, es mejor usar esto solo con fines informativos. Ciertamente es una mala idea hacer que su programa sea exclusivo para sistemas para los que esta función devuelve un cierto número "deseable".

Esta función se puede llamar antes de al_install_system(3) o al_init(3).
