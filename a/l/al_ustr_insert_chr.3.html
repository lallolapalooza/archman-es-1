NOMBRE

al_ustr_insert_chr - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
size_t al_ustr_insert_chr(ALLEGRO_USTR *us, int pos, int32_t c)

DESCRIPCIÓN

Inserta un punto de código en us comenzando en el desplazamiento de bytes pos. pos no puede ser menor que 0. Si pos está más allá del final de us, el espacio entre el final de la cadena y pos se rellenará con bytes NUL ('\0').

Devuelve el número de bytes insertados, o 0 en caso de error.

VER TAMBIÉN

al_ustr_insert(3), al_ustr_insert_cstr(3)
