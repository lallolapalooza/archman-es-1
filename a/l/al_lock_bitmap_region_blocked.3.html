NOMBRE

al_lock_bitmap_region_blocked - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
ALLEGRO_LOCKED_REGION *al_lock_bitmap_region_blocked(ALLEGRO_BITMAP *bitmap,
   int x_block, int y_block, int width_block, int height_block, int flags)

DESCRIPCIÓN

Similar a al_lock_bitmap_blocked(3), pero permite bloquear una sub-región, para mejorar el rendimiento. A diferencia de al_lock_bitmap_region(3), la región se especifica en términos de bloques y no de píxeles.

DESDE

5.1.9

VER TAMBIÉN

al_lock_bitmap_region(3), al_lock_bitmap_blocked(3)
