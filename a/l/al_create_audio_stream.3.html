NOMBRE

al_create_audio_stream - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_AUDIO_STREAM *al_create_audio_stream(size_t fragment_count,
   unsigned int frag_samples, unsigned int freq, ALLEGRO_AUDIO_DEPTH depth,
   ALLEGRO_CHANNEL_CONF chan_conf)

DESCRIPCIÓN

Crea un ALLEGRO_AUDIO_STREAM(3). El stream se configurará para reproducirse por defecto. Alimentará datos de audio desde un buffer, que se divide en varios fragmentos.

Parámetros:

•
fragment_count - Cuántos fragmentos usar para el stream de audio. Normalmente solo se requieren dos fragmentos, dividiendo el buffer de audio en dos mitades. Pero esto significa que el único momento en que se pueden suministrar nuevos datos es cuando una mitad ha terminado de reproducirse. Al usar muchos fragmentos, normalmente usarás menos muestras para uno, por lo que siempre habrá fragmentos (pequeños) disponibles para ser llenados con nuevos datos.
•
frag_samples - El tamaño de un fragmento en muestras. Ver nota y explicación a continuación.
•
freq - La frecuencia, en Hertz.
•
depth - Debe ser uno de los valores listados para ALLEGRO_AUDIO_DEPTH(3).
•
chan_conf - Debe ser uno de los valores listados para ALLEGRO_CHANNEL_CONF(3).

Una muestra (sample) a la que se refiere el parámetro frag_samples se refiere a una secuencia de intensidades de canal. Por ejemplo, si estás creando un stream estéreo con frag_samples establecido en 4, la disposición de los datos en el fragmento será:

LRLRLRLR

Donde L y R son las intensidades para el canal izquierdo y derecho respectivamente. Una sola muestra, entonces, se refiere al par LR en este ejemplo.

La elección de fragment_count, frag_samples y freq influye directamente en el retardo del audio. El retardo en segundos se puede expresar como:

delay = fragment_count * frag_samples / freq

Este es solo el retardo debido al streaming de Allegro, puede haber un retardo adicional causado por los controladores de sonido y/o el hardware.

Nota: Si conoces el tamaño del fragmento en bytes, puedes obtener el tamaño en muestras de la siguiente manera:

sample_size = al_get_channel_count(chan_conf) * al_get_audio_depth_size(depth);
samples = bytes_per_fragment / sample_size;

El tamaño del buffer completo es:

buffer_size = bytes_per_fragment * fragment_count

Nota: A diferencia de muchos objetos de Allegro, los streams de audio no se destruyen implícitamente cuando Allegro se apaga. Debes destruirlos manualmente con al_destroy_audio_stream(3) antes de que el sistema de audio se apague.
