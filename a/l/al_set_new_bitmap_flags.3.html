NOMBRE

al_set_new_bitmap_flags - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
void al_set_new_bitmap_flags(int flags)

DESCRIPCIÓN

Establece las banderas a utilizar para los mapas de bits recién creados. Las banderas válidas son:

ALLEGRO_MEMORY_BITMAP
Crea un mapa de bits que reside en la memoria del sistema. Las operaciones sobre y con mapas de bits de memoria no serán aceleradas por hardware. Sin embargo, el acceso directo a píxeles puede ser relativamente rápido en comparación con los mapas de bits de video, que dependen del controlador de pantalla en uso.

Nota: Las rutinas de renderizado por software de Allegro están actualmente algo sin optimizar.

Nota: Combinar las banderas ALLEGRO_VIDEO_BITMAP y ALLEGRO_MEMORY_BITMAP es inválido.

ALLEGRO_VIDEO_BITMAP
Crea un mapa de bits que reside en la memoria de la tarjeta de video. Estos tipos de mapas de bits se benefician más de la aceleración por hardware.

Nota: La creación de un mapa de bits de video fallará si no hay una pantalla actual o si el controlador de pantalla actual no puede crear el mapa de bits. Esto último ocurrirá si, por ejemplo, el formato o las dimensiones no son compatibles.

Nota: Los mapas de bits creados con esta bandera se convertirán en mapas de bits de memoria cuando se destruya la última pantalla. En la mayoría de los casos, es más fácil usar la bandera ALLEGRO_CONVERT_BITMAP en su lugar.

Nota: Combinar las banderas ALLEGRO_VIDEO_BITMAP y ALLEGRO_MEMORY_BITMAP es inválido.

ALLEGRO_CONVERT_BITMAP
Este es el valor predeterminado. Intentará crear un mapa de bits de video y, si falla, creará un mapa de bits de memoria. Los mapas de bits creados con esta bandera cuando no hay una pantalla activa se convertirán en mapas de bits de video la próxima vez que se cree una pantalla. También permanecerán como mapas de bits de video si se destruye la última pantalla y luego se crea otra nuevamente. Desde 5.1.0.

Nota: Puede combinar esta bandera con ALLEGRO_MEMORY_BITMAP o ALLEGRO_VIDEO_BITMAP para forzar el tipo inicial (y fallar en el último caso si no se puede crear un mapa de bits de video), pero generalmente ninguna de esas combinaciones es muy útil.

Puede usar la opción de pantalla ALLEGRO_AUTO_CONVERT_BITMAPS para controlar qué pantallas intentarán convertir mapas de bits automáticamente.

ALLEGRO_FORCE_LOCKING
No hace nada desde 5.1.8. Se mantiene solo por compatibilidad con versiones anteriores.
ALLEGRO_NO_PRESERVE_TEXTURE
Normalmente, se hacen todos los esfuerzos para preservar el contenido de los mapas de bits, ya que algunas plataformas pueden olvidarlos. Esto puede llevar tiempo de procesamiento adicional. Si sabe que no importa si un mapa de bits conserva sus datos de píxeles, por ejemplo, cuando es un búfer temporal, use esta bandera para indicarle a Allegro que no intente preservar su contenido.
ALLEGRO_ALPHA_TEST
Esta es solo una sugerencia para el controlador. Indica al controlador gráfico que realice pruebas alfa en lugar de mezclas alfa en mapas de bits creados con esta bandera. Las pruebas alfa suelen ser más rápidas y se prefieren si sus mapas de bits tienen solo un nivel de alfa (0). Esta bandera actualmente no está ampliamente implementada (es decir, solo para mapas de bits de memoria).
ALLEGRO_MIN_LINEAR
Al dibujar una versión reducida del mapa de bits, use filtrado lineal. Esto generalmente se ve mejor. También puede combinarlo con la bandera MIPMAP para una calidad aún mayor.
ALLEGRO_MAG_LINEAR
Al dibujar una versión ampliada de un mapa de bits, use filtrado lineal. Esto hará que la imagen se difumine en lugar de crear un rectángulo grande para cada píxel. Depende de cómo desee que se vean las cosas si desea usar esto o no.
ALLEGRO_MIPMAP
Esto solo se puede usar para mapas de bits cuyo ancho y alto son una potencia de dos. En ese caso, generará mipmaps y los usará al dibujar versiones reducidas. Por ejemplo, si el mapa de bits es de 64x64, se crearán mapas de bits adicionales de tamaños 32x32, 16x16, 8x8, 4x4, 2x2 y 1x1, que siempre contendrán una versión reducida del original.
