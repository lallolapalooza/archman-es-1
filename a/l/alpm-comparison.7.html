NOMBRE

comparison - declaraciones de comparación para paquetes basados en ALPM.

DESCRIPCIÓN

El formato comparison es un formato de comparación de versiones, que se utiliza para representar declaraciones de comparación de versiones para paquetes basados en ALPM en una expresión de comparación compuesta. Este formato se utiliza en scripts de compilación o en formatos de archivos para metadatos de paquetes (por ejemplo, en PKGBUILD o PKGINFO) para describir límites de versión para una relación de paquete.

Una declaración comparison utiliza uno de los siguientes operadores comparison para especificar una relación de límite de versión:

  • < (menor que)
  • <= (menor o igual que)
  • = (igual a)
  • >= (mayor o igual que)
  • > (mayor que)

Expresiones de comparación compuestas

Las expresiones de comparación compuestas consisten en un nombre-paquete-alpm, seguido directamente por un operador comparison, seguido directamente por una versión-paquete-alpm.

Expresiones de comparación coincidentes

La coincidencia de nombres se realiza basándose en una coincidencia completa de cadenas utilizando el componente nombre-paquete-alpm de la expresión de comparación compuesta.

La comparación de versiones se realiza basándose en los componentes de una cadena de versión compuesta (ver, por ejemplo, alpm-epoch, alpm-pkgver y alpm-pkgrel). Dado que versión-paquete-alpm ofrece varias formas, esto permite la coincidencia de una variedad de escenarios.

Al proporcionar la forma *completa* o *completa con epoch* del formato versión-paquete-alpm, se coincide con *exactamente una* versión específica de una versión de paquete. Al proporcionar la forma *mínima* o *mínima con epoch* del formato versión-paquete-alpm, se coincide con *cualquier* versión de una versión de paquete.

Dependiendo del operador de comparación, la coincidencia dada con nombre-paquete-alpm y versión-paquete-alpm es estrecha (es decir, =), amplia con límite inferior (es decir, >, >=) o amplia con límite superior (es decir, <, <=).

EJEMPLOS

Las expresiones de comparación compuestas a continuación pueden ser coincidentes por un paquete llamado example en versiones específicas:

"example<1.0.0"

Una versión menor que ‘1.0.0’ (por ejemplo, ‘0.8.0-1’).

"example<=1.0.0"

Una versión menor o igual que ‘1.0.0’ (por ejemplo, ‘0.8.0-1’ o ‘1.0.0-3’).

"example<=1.0.0-1"

Una versión menor o igual que ‘1.0.0-1’ (por ejemplo, ‘0.8.0-1’ o ‘1.0.0-1’, pero ‘1.0.0-2’ no funciona).

"example=1.0.0"

Cualquier versión ‘1.0.0’ (por ejemplo, ‘1.0.0-1’ o ‘1.0.0-2’, etc.).

"example=1.0.0-1"

La versión ‘1.0.0-1’.

"example=1:1.0.0-1"

La versión ‘1:1.0.0-1’.

"example>=1.0.0"

Una versión mayor o igual que ‘1.0.0’ (por ejemplo, ‘1.0.0-1’ o ‘1.1.0-1’).

"example>1.0.0"

Una versión mayor que ‘1.0.0’ (por ejemplo, ‘1.1.0-1’ o ‘1:1.0.0-1’).
