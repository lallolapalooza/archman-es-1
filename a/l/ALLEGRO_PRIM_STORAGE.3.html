NOMBRE

ALLEGRO_PRIM_STORAGE - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_primitives.h>
typedef enum ALLEGRO_PRIM_STORAGE

DESCRIPCIÓN

Enumera los tipos de almacenamiento en los que se puede guardar un atributo de un vértice personalizado. Muchos de estos solo se pueden usar para atributos ALLEGRO_PRIM_USER_ATTR y solo se puede acceder a ellos a través de shaders. Normalmente, sin importar cuál sea el almacenamiento especificado, el atributo se convierte a punto flotante de precisión simple cuando se ejecuta el shader. A pesar de eso, puede ser ventajoso usar formatos de almacenamiento más densos (por ejemplo, ALLEGRO_PRIM_NORMALIZED_UBYTE_4 en lugar de ALLEGRO_PRIM_FLOAT_4) cuando el ancho de banda (cantidad de memoria enviada a la GPU) es un problema pero la precisión no lo es.

•
ALLEGRO_PRIM_FLOAT_1 - Un solo float

Desde: 5.1.6

•
ALLEGRO_PRIM_FLOAT_2 - Un doblete de floats
•
ALLEGRO_PRIM_FLOAT_3 - Un triplete de floats
•
ALLEGRO_PRIM_FLOAT_4 - Un cuádruple de floats

Desde: 5.1.6

•
ALLEGRO_PRIM_SHORT_2 - Un doblete de shorts
•
ALLEGRO_PRIM_SHORT_4 - Un cuádruple de shorts

Desde: 5.1.6

•
ALLEGRO_PRIM_UBYTE_4 - Un cuádruple de bytes sin signo

Desde: 5.1.6

•
ALLEGRO_PRIM_NORMALIZED_SHORT_2 - Un doblete de shorts. Antes de ser enviado al shader, cada componente se divide por 32767. Cada componente del doblete flotante resultante varía entre -1.0 y 1.0

Desde: 5.1.6

•
ALLEGRO_PRIM_NORMALIZED_SHORT_4 - Un cuádruple de shorts. Antes de ser enviado al shader, cada componente se divide por 32767. Cada componente del cuádruple flotante resultante varía entre -1.0 y 1.0

Desde: 5.1.6

•
ALLEGRO_PRIM_NORMALIZED_UBYTE_4 - Un cuádruple de bytes sin signo. Antes de ser enviado al shader, cada componente se divide por 255. Cada componente del cuádruple flotante resultante varía entre 0.0 y 1.0

Desde: 5.1.6

•
ALLEGRO_PRIM_NORMALIZED_USHORT_2 - Un doblete de shorts sin signo. Antes de ser enviado al shader, cada componente se divide por 65535. Cada componente del doblete flotante resultante varía entre 0.0 y 1.0

Desde: 5.1.6

•
ALLEGRO_PRIM_NORMALIZED_USHORT_4 - Un cuádruple de shorts sin signo. Antes de ser enviado al shader, cada componente se divide por 65535. Cada componente del cuádruple flotante resultante varía entre 0.0 y 1.0

Desde: 5.1.6

•
ALLEGRO_PRIM_HALF_FLOAT_2 - Un doblete de floats de media precisión. Tenga en cuenta que este formato de almacenamiento no es compatible en todas las plataformas. al_create_vertex_decl(3) devolverá NULL si lo usa en esas plataformas.

Desde: 5.1.6

•
ALLEGRO_PRIM_HALF_FLOAT_4 - Un cuádruple de floats de media precisión. Tenga en cuenta que este formato de almacenamiento no es compatible en todas las plataformas. al_create_vertex_decl(3) devolverá NULL si lo usa en esas plataformas.

Desde: 5.1.6
