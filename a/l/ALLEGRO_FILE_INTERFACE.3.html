ALLEGRO_FILE_INTERFACE(3) Manual de funciones de la biblioteca ALLEGRO_FILE_INTERFACE(3)

NOMBRE

ALLEGRO_FILE_INTERFACE - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
typedef struct ALLEGRO_FILE_INTERFACE

DESCRIPCIÓN

Una estructura que contiene punteros de función para manejar un tipo de “archivo”, real o virtual. Véase la discusión completa en al_set_new_file_interface(3).

Los campos son:

void*         (*fi_fopen)(const char *path, const char *mode);
bool          (*fi_fclose)(ALLEGRO_FILE *f);
size_t        (*fi_fread)(ALLEGRO_FILE *f, void *ptr, size_t size);
size_t        (*fi_fwrite)(ALLEGRO_FILE *f, const void *ptr, size_t size);
bool          (*fi_fflush)(ALLEGRO_FILE *f);
int64_t       (*fi_ftell)(ALLEGRO_FILE *f);
bool          (*fi_fseek)(ALLEGRO_FILE *f, int64_t offset, int whence);
bool          (*fi_feof)(ALLEGRO_FILE *f);
int           (*fi_ferror)(ALLEGRO_FILE *f);
const char *  (*fi_ferrmsg)(ALLEGRO_FILE *f);
void          (*fi_fclearerr)(ALLEGRO_FILE *f);
int           (*fi_fungetc)(ALLEGRO_FILE *f, int c);
off_t         (*fi_fsize)(ALLEGRO_FILE *f);

La función fi_open debe asignar memoria para la estructura de datos de usuario que necesite. El puntero a esa memoria debe ser devuelto; luego se asociará con el archivo. Las otras funciones pueden acceder a esos datos llamando a al_get_file_userdata(3) en el manejador de archivo. Si fi_open devuelve NULL, entonces al_fopen(3) también devolverá NULL.

La función fi_fclose debe limpiar y liberar los datos de usuario, pero Allegro liberará el manejador ALLEGRO_FILE(3).

Si fi_fungetc es NULL, entonces se usará la implementación por defecto de Allegro de un búfer de 16 caracteres.
