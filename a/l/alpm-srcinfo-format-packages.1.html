NOMBRE

alpm-srcinfo-format-packages - Formatea los paquetes de un archivo SRCINFO desde una ruta o `stdin`

SINOPSIS

alpm-srcinfo format-packages [-s|--schema] <-a|--architecture> [-o|--output-format] [-p|--pretty] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Formatea los paquetes de un archivo SRCINFO desde una ruta o `stdin`

Lee, valida e imprime todos los paquetes del SRCINFO en su representación final para una arquitectura específica. Si el archivo es válido, el programa imprime los datos en el formato de archivo solicitado a stdout y retorna con un estado de salida de 0.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema SRCINFO a utilizar.

Si no se proporciona ninguna versión de esquema, se deducirá del propio archivo.

-a, --architecture <ARQUITECTURA>
La arquitectura seleccionada que debe utilizarse para interpretar el archivo SRCINFO.

Solo se devolverán los paquetes [divididos] que sean aplicables para esta arquitectura.

-o, --output-format <FORMATO_SALIDA> [predeterminado: json]
Proporciona el formato de salida.

Valores posibles:

•
json: El formato de salida JSON
-p, --pretty
Imprime la salida de forma legible.

Solo se aplica a los formatos que admiten salida legible y de lo contrario se ignora.

-h, --help
Imprime la ayuda (ver un resumen con '-h').
[ARCHIVO]
Una ruta de archivo de entrada opcional para leer.

Si no se especifica ningún archivo, se lee desde stdin y se espera que contenga datos PKGINFO para validar.
