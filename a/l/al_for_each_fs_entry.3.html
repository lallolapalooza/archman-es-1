NOMBRE

al_for_each_fs_entry - API de Allegro 5

SINOPSIS

#include <allegro5/allegro.h>
int al_for_each_fs_entry(ALLEGRO_FS_ENTRY *dir,
                         int (*callback)(ALLEGRO_FS_ENTRY *dir, void *extra),
                         void *extra)

DESCRIPCIÓN

Esta función toma la entrada del sistema de archivos ALLEGRO_FS_ENTRY(3) dir, que debe representar un directorio, y busca cualquier otra entrada del sistema de archivos que se encuentre en él. Luego, esta función llama a la función de devolución de llamada (callback) callback una vez por cada entrada del sistema de archivos en el directorio dir.

El callback callback debe ser de tipo int callback(ALLEGRO_FS_ENTRY * entry, void * extra). El callback se llamará con un puntero a un ALLEGRO_FS_ENTRY(3) que coincida con un archivo o directorio en dir, y el puntero pasado en el parámetro extra a al_for_each_fs_entry(3).

Cuando callback devuelve ALLEGRO_FOR_EACH_FS_ENTRY_STOP o ALLEGRO_FOR_EACH_FS_ENTRY_ERROR, la iteración se detendrá inmediatamente y al_for_each_fs_entry(3) devolverá el valor que el callback devolvió.

Cuando callback devuelve ALLEGRO_FOR_EACH_FS_ENTRY_OK, la iteración continuará normalmente, y si el parámetro ALLEGRO_FS_ENTRY(3) de callback es un directorio, al_for_each_fs_entry(3) se llamará a sí misma en ese directorio. Por lo tanto, la función descenderá recursivamente en ese directorio.

Sin embargo, cuando callback devuelve ALLEGRO_FOR_EACH_FS_ENTRY_SKIP, la iteración continuará, pero al_for_each_fs_entry(3) NO descenderá recursivamente en el parámetro ALLEGRO_FS_ENTRY(3) de callback, incluso si es un directorio.

Esta función omitirá cualquier archivo o directorio llamado . o .. que pueda existir en ciertas plataformas y que pueda significar el directorio actual y el directorio padre. El callback no se llamará para archivos o directorios con dicho nombre.

Devuelve ALLEGRO_FOR_EACH_FS_ENTRY_OK si tiene éxito, o ALLEGRO_FOR_EACH_FS_ENTRY_ERROR si ocurrió algún error al procesar el directorio. En ese caso, utilizará al_set_errno(3) para indicar el tipo de error que ocurrió. Esta función devuelve ALLEGRO_FOR_EACH_FS_ENTRY_STOP en caso de que la iteración se detuviera al hacer que callback devuelva ese valor. En este caso, al_set_errno(3) no se utilizará.
