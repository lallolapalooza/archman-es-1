NOMBRE

alpm-db - un formato de base de datos para describir el estado de los paquetes en un sistema basado en Arch Linux Package Management (ALPM).

DESCRIPCIÓN

Las bases de datos en los sistemas basados en ALPM se representan mediante una estructura de directorios que contiene archivos de metadatos. El contenido de dicha base de datos describe el estado de todos los paquetes instalados. Aquí, los archivos ALPM-MTREE, alpm-db-desc y alpm-db-files proporcionan metadatos sobre versiones específicas de paquetes actualmente instalados.

Las entradas para las bases de datos se crean a partir de archivos alpm-package utilizando software de gestión de paquetes como pacman. El software de gestión de paquetes se basa en las estructuras alpm-db con el fin de buscar, resolver dependencias y gestionar el sistema.

El formato alpm-db existe en múltiples versiones. La información en este documento es para la versión 9, que es la versión actual y se introdujo con la versión de pacman 4.2.0 el 2014-12-19.

Contenido

El contenido de la base de datos del sistema depende del número de paquetes únicos que describe. Cada paquete solo puede aparecer una vez, en una única versión.

Metadatos

Los metadatos de un paquete se guardan en un directorio de nivel superior, que lleva el nombre del paquete y su versión específica. El nombre sigue este esquema:

Un nombre-paquete-alpm seguido directamente por un signo -, seguido directamente por una versión-paquete-alpm (en la forma *completa* o *completa con epoch*), por ejemplo:

  • ejemplo-paquete-1.0.0-1
  • ejemplo-paquete-1:1.0.0-1

En cada uno de estos directorios, se guardan un archivo ALPM-MTREE, un archivo alpm-db-desc y un archivo alpm-db-files para describir un paquete, por ejemplo:

.
└── ejemplo-paquete-1.0.0-1
    ├── desc
    ├── files
    └── mtree

Versión del esquema

La versión actual del esquema de la base de datos del sistema está codificada en el archivo de versión de nivel superior ALPM_DB_VERSION. Este archivo de texto ASCII contiene una sola línea con una cadena de versión numérica, por ejemplo:

9

Cuando son necesarios cambios en el formato de la base de datos del sistema, se indican incrementando la cadena de versión destinada al archivo de versión.

Se utilizan herramientas dedicadas como pacman-db-upgrade para actualizar el contenido de la base de datos del sistema (por ejemplo, archivos de metadatos, estructura de directorios) y eventualmente actualizar la versión en ALPM_DB_VERSION.

Creación

Los datos en un alpm-db se derivan de los archivos alpm-package y se crean utilizando software de gestión de paquetes como pacman. Para las entradas alpm-db-desc, se utilizan los datos PKGINFO del paquete, así como las propiedades del archivo del paquete. El archivo alpm-repo-files se deriva directamente de la lista de archivos de datos del archivo del paquete. El archivo ALPM-MTREE es una copia del archivo ALPM-MTREE del paquete.

              alpm-db -----------.
              /  |  \             \
             /   |   \             \
alpm-db-files    |    alpm-db-desc  |
    |            |         |        |
    |         ALPM-MTREE   |        |
 archivos de datos  |         |        |
       \         |       PKGINFO   /
        \        |     /          /
         \       |    /          /
          alpm-package-----------

EJEMPLOS

Instalar un paquete en un sistema

Suponiendo un sistema vacío, la instalación de un paquete ejemplo-paquete en la versión 1.0.0-1 da lugar a la siguiente adición en el alpm-db:

.
└── ejemplo-paquete-1.0.0-1
    ├── desc
    ├── files
    └── mtree

Actualizar un paquete existente en un sistema

Ampliando el ejemplo anterior sobre la instalación de un paquete en un sistema, la actualización de un paquete ejemplo-paquete a la versión 1.1.0-1 da lugar al siguiente cambio en el alpm-db:

.
└── ejemplo-paquete-1.1.0-1
    ├── desc
    ├── files
    └── mtree
