NOMBRE

package name - nombres de paquetes y componentes para paquetes basados en ALPM.

DESCRIPCIÓN

El formato package name representa nombres de paquetes y componentes para paquetes basados en ALPM. Este formato se utiliza en scripts de compilación o formatos de archivo para metadatos de paquetes (por ejemplo, en PKGBUILD, PKGINFO, SRCINFO, alpm-repo-desc o alpm-lib-desc) para describir nombres de paquetes o componentes, y relaciones de paquetes.

Si bien el formato package name se utiliza principalmente para describir paquetes existentes, también puede utilizarse para nombrar componentes virtuales. Un componente virtual se especifica implícitamente utilizando una alpm-package-relation.

El valor debe estar cubierto por el conjunto de caracteres alfanuméricos y los caracteres ‘@’, ‘.’, ‘_’, ‘+’, ‘-’, pero no debe empezar con ‘-’ o ‘.’ (por ejemplo, example es válido).

EJEMPLOS

"nombre-paquete"

VER TAMBIÉN

BUILDINFO(5), PKGBUILD(5), PKGINFO(5), SRCINFO(5), alpm-package-relation(7)
