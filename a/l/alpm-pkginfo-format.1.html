NOMBRE

alpm-pkginfo-format - Analiza un archivo PKGINFO y lo muestra en un formato de archivo diferente

SINOPSIS

alpm-pkginfo format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Analiza un archivo PKGINFO y lo muestra en un formato de archivo diferente.

Si la entrada se puede validar según un esquema conocido, el programa escribe los datos de PKGINFO en la salida estándar en un formato de archivo diferente (opcionalmente, se puede proporcionar una ruta de archivo donde escribir) y sale con un código de retorno de 0. Actualmente, solo se soporta JSON como formato de salida. Si la entrada no se puede validar según un esquema conocido, se emite un error en la salida de error estándar y el programa sale con un código de salida distinto de cero.

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema PKGINFO a utilizar.

Si no se proporciona una versión de esquema, se deducirá del propio archivo.

-o, --output-format <FORMATO_SALIDA> [por defecto: json]
El formato de salida a utilizar.

Actualmente solo se soporta "json" (el valor por defecto).

Posibles valores:

•
json: El formato de salida JSON.
-p, --pretty
Formatear la salida de forma legible.

No tiene ningún efecto si el formato de salida no se puede formatear de forma legible.

-h, --help
Imprimir ayuda (ver un resumen con '-h').
[ARCHIVO]
Una ruta de archivo de entrada opcional desde la que leer.

Si no se especifica una ruta de archivo, se lee de la entrada estándar, que se espera que contenga datos PKGINFO para formatear.
