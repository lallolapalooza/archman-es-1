NOMBRE

ALLEGRO_AUDIO_STREAM - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
typedef struct ALLEGRO_AUDIO_STREAM ALLEGRO_AUDIO_STREAM;

DESCRIPCIÓN

Un objeto ALLEGRO_AUDIO_STREAM se utiliza para transmitir audio generado al dispositivo de sonido, en tiempo real. Esto se hace leyendo desde un búfer, que se divide en un número de fragmentos. Cada vez que un fragmento ha terminado de reproducirse, el usuario puede rellenarlo con nuevos datos.

Al igual que con los objetos ALLEGRO_SAMPLE_INSTANCE(3), las transmisiones almacenan información necesaria para la reproducción, por lo que no puede reproducir la misma transmisión varias veces simultáneamente. Las transmisiones también necesitan adjuntarse a un ALLEGRO_MIXER(3), que, finalmente, llega a un objeto ALLEGRO_VOICE(3).

Mientras se reproduce, debe rellenar periódicamente los fragmentos con nuevos datos de audio. Para saber cuándo un nuevo fragmento está listo para ser rellenado, puede comprobar directamente con al_get_available_audio_stream_fragments(3), o escuchar eventos de la transmisión.

Puede registrar una fuente de eventos de transmisión de audio en una cola de eventos; consulte al_get_audio_stream_event_source(3). Se genera un evento ALLEGRO_EVENT_AUDIO_STREAM_FRAGMENT(3) cada vez que un nuevo fragmento está listo. Cuando reciba un evento, utilice al_get_audio_stream_fragment(3) para obtener un puntero al fragmento que debe rellenarse. El tamaño y el formato se determinan por los parámetros pasados a al_create_audio_stream(3).

Si tarda en suministrar nuevos datos, la transmisión estará en silencio hasta que se proporcionen nuevos datos. Debe llamar a al_drain_audio_stream(3) cuando haya terminado de suministrar datos a la transmisión.

A menudo es una buena idea prellenar la transmisión de audio con datos antes de que lleguen los eventos ALLEGRO_EVENT_AUDIO_STREAM_FRAGMENT(3). Aquí hay un fragmento que rellenará los búferes de la transmisión con silencio:

ALLEGRO_AUDIO_STREAM *stream = al_create_audio_stream(num_buffers,
   samples_per_buffer, freq, depth, channel_conf);
void *buf;
while ((buf = al_get_audio_stream_fragment(stream))) {
   al_fill_silence(buf, samples_per_buffer, depth, channel_conf);
   al_set_audio_stream_fragment(stream, buf);
}

Si la transmisión se crea mediante al_load_audio_stream(3) o al_play_audio_stream(3), también generará un evento ALLEGRO_EVENT_AUDIO_STREAM_FINISHED(3) si llega al final del archivo y no está configurada para repetirse.
