NOMBRE

alpm-db-desc-format - Analiza y muestra un archivo DB desc en un formato diferente

SINOPSIS

alpm-db-desc format [-s|--schema] [-o|--output-format] [-p|--pretty] [-h|--help] [ARCHIVO]

DESCRIPCIÓN

Analiza y muestra un archivo DB desc en un formato diferente

OPCIONES

-s, --schema <VERSIÓN>
Proporciona la versión del esquema a utilizar.

Si no se proporciona, la versión del esquema se detectará del archivo.

-o, --output-format <FORMATO_SALIDA> [predeterminado: json]
Proporciona el formato de salida

Valores posibles:

•
json: El formato de salida JSON
-p, --pretty
Imprime la salida de forma legible
-h, --help
Imprime la ayuda (ver un resumen con '-h')
[ARCHIVO]
Proporciona el archivo a leer
