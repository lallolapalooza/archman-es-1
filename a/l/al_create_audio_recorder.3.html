NOMBRE

al_create_audio_recorder - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_audio.h>
ALLEGRO_AUDIO_RECORDER *al_create_audio_recorder(size_t fragment_count,
   unsigned int samples, unsigned int frequency,
   ALLEGRO_AUDIO_DEPTH depth, ALLEGRO_CHANNEL_CONF chan_conf)

DESCRIPCIÓN

Crea un grabador de audio usando el dispositivo de grabación por defecto del sistema. (Así que si el dispositivo devuelto no funciona, intente actualizar el dispositivo de grabación por defecto del sistema.)

Allegro almacenará en búfer internamente varios segundos de audio capturado con una latencia mínima. (XXX: Estas configuraciones necesitan ser expuestas a través de la configuración o llamadas a la API.) El audio se copiará desde ese búfer privado a un búfer de fragmentos del tamaño especificado por el parámetro `samples`. Cada vez que un nuevo fragmento esté listo, se generará un evento.

El tamaño total del búfer de fragmentos es `fragment_count * samples * bytes_por_muestra`. Se trata como un búfer circular, sin fin. Si no procesa la información lo suficientemente rápido, se sobrescribirá. Debido a eso, incluso si solo necesita procesar un pequeño fragmento a la vez, aún debe usar un valor suficientemente grande para `fragment_count` para contener algunos segundos de audio.

`frequency` es el número de muestras por segundo a grabar. Los valores comunes son:

•
8000 - voz de calidad telefónica
•
11025
•
22050
•
44100 - música de calidad CD (si es de 16 bits, estéreo)

Para una máxima compatibilidad, use una profundidad de `ALLEGRO_AUDIO_DEPTH_UINT8` o `ALLEGRO_AUDIO_DEPTH_INT16`, y un solo canal (mono).

El grabador no grabará hasta que lo inicie con al_start_audio_recorder(3).

En caso de fallo, devuelve NULL.
