(7) Manual de Información Miscelánea (7)

NOMBRE

epoch - prefijo de versión para forzar una mayor consideración de versión para los paquetes basados en ALPM.

DESCRIPCIÓN

El formato epoch es un formato de versión que se utiliza como prefijo de pkgver en una cadena de versión compuesta. Este formato se utiliza en scripts de compilación o en formatos de descripción o reproducción de datos de paquetes para indicar que una versión compuesta se debe considerar más nueva que una sin ella o con un componente epoch más bajo. Esto permite a los mantenedores de paquetes lanzar versiones degradadas de un paquete si es necesario.

El valor epoch se representa mediante un entero no negativo y se considera que tiene el valor predeterminado de '0' si no está establecido.

Cuando se utiliza en una cadena de versión compuesta, epoch va seguido directamente por un signo ':' y el pkgver.

Si se ordenan dos cadenas de versión compuestas, primero se ordenan según su componente epoch y solo después según su componente pkgver.

Como regla general, la precedencia de ordenación es: epoch > pkgver.

EJEMPLOS

El componente epoch explícito 1 en la cadena de versión compuesta de la mano derecha anula el componente epoch implícito 0 de la cadena de versión compuesta de la mano izquierda. Dado que el epoch tiene precedencia, 1:0.9.0 se considera "más nuevo" que 1.0.0 a pesar de que la versión upstream representada por el componente pkgver sea más antigua.

"1.0.0" < "1:0.9.0"

Las cadenas de versión compuestas con el mismo componente pkgver también se ordenan primero según su componente epoch.

"1:1.0.0" < "2:1.0.0"
