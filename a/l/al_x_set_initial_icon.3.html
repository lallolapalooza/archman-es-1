NOMBRE

al_x_set_initial_icon - API de Allegro 5

SINOPSIS

#include <allegro5/allegro_x.h>
bool al_x_set_initial_icon(ALLEGRO_BITMAP *bitmap)

DESCRIPCIÓN

En algunos gestores de ventanas (notablemente Unity de Ubuntu) al_set_display_icon no funciona y necesitas usar un archivo .desktop. Pero con esta función puedes establecer un icono antes de llamar a al_create_display. Esto funciona estableciendo el icono antes de XMapWindow.

DESDE

5.2.3

[API inestable]: Nueva API.
