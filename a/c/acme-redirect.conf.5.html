acme-redirect.conf(5) Manual de formatos de archivo acme-redirect.conf(5)

NOMBRE

acme-redirect.conf - Archivos de configuración de acme-redirect

SINOPSIS

/etc/acme-redirect.conf

DESCRIPCIÓN

Este archivo configura ajustes generales para acme-redirect. Para configurar certificados, consulta acme-redirect.d(5).

OPCIONES ([acme])

acme_email=

El correo electrónico de contacto para que tu proveedor de acme se ponga en contacto contigo. Normalmente te notificarán si tu renovación automática no parece estar funcionando, o si el protocolo acme va a ser actualizado.

acme_url=

El punto final de acme a utilizar. El valor predeterminado es la producción de LetsEncrypt.

renew_if_days_left=

Renueva el certificado si el número de días es igual o inferior. Tendrás problemas si lo estableces por debajo de 1. El valor predeterminado es 30.

OPCIONES ([sistema])

exec=

Una lista de ganchos de respaldo globales que se ejecutan si la configuración del certificado no especificó ningún gancho. Se espera que los ganchos sean comandos de shell.

exec_extra=

Una lista de ganchos globales que se ejecutan después de que se renueve cualquier certificado y se ejecuten sus ganchos. Se espera que los ganchos sean comandos de shell.

EJEMPLO

[acme]
acme_email = "nadie@ejemplo.com"
acme_url = "https://acme-staging-v02.api.letsencrypt.org/directory"
renew_if_days_left = 30
[system]
## Ganchos predeterminados si la configuración del certificado no define ninguno
exec = [
    "systemctl reload nginx",
]
## Ejecuta estos ganchos globalmente para todos los certificados
exec_extra = [
    "systemctl reload dovecot",
]

VER TAMBIÉN

acme-redirect(1), acme-redirect.d(5).
