ACCERCISER(1) Manual de comandos generales ACCERCISER(1)

NOMBRE

ACCERCISER - un explorador interactivo de accesibilidad.

SINOPSIS

accerciser [--version] [--help]

DESCRIPCIÓN

Esta página del manual documenta brevemente accerciser.

accerciser es un explorador interactivo de accesibilidad en Python para el escritorio GNOME. Utiliza AT-SPI para inspeccionar y controlar widgets, permitiéndole comprobar si una aplicación está proporcionando información correcta a tecnologías de asistencia y frameworks de pruebas automatizadas. Accerciser tiene un framework de plugins simple que puede utilizar para crear vistas personalizadas de información de accesibilidad.

OPCIONES

--version Imprime el número de versión.

-?, --help
Muestra un resumen de las opciones.

CONFIGURACIÓN

La configuración de metacity se puede encontrar en Preferencias->Ventanas y Preferencias->Atajos de teclado en el panel del menú. La configuración avanzada se puede lograr directamente a través de la edición gconf (gconf-editor o gconftool-2).

VER TAMBIÉN

La documentación completa de accerciser se puede encontrar en el menú Ayuda de accerciser.
