acl_from_text(3)

Paquete: acl

Licencias: LGPL

ACL_FROM_TEXT(3) Manual de funciones de biblioteca ACL_FROM_TEXT(3)

NOMBRE

acl_from_text — crear una ACL a partir de texto

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

acl_t
acl_from_text(const char *buf_p);

DESCRIPCIÓN

La función acl_from_text() convierte la forma textual de la ACL referenciada por buf_p a la forma interna de una ACL y devuelve un puntero al espacio de trabajo que contiene la ACL. La función acl_from_text() acepta como entrada la forma textual larga y la forma textual corta de una ACL, como se describe en acl(5).

Esta función puede causar la asignación de memoria. El llamador debe liberar cualquier memoria liberable, cuando la nueva ACL ya no sea necesaria, llamando a acl_free(3) con el (void*)acl_t devuelto por acl_from_text() como argumento.

VALOR DE RETORNO

En caso de éxito, esta función devuelve un puntero al espacio de trabajo. En caso de error, se devuelve el valor (acl_t)NULL y se establece errno apropiadamente.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_from_text() devuelve un valor de (acl_t)NULL y establece errno al valor correspondiente:

[EINVAL]
El argumento buf_p no se puede traducir a una ACL.
[ENOMEM]
La acl_t a devolver requiere más memoria de la que permiten las limitaciones de gestión de memoria impuestas por el hardware o el sistema.

ESTÁNDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIÉN

acl_free(3), acl_get_entry(3), acl_to_text(3), acl(5)
