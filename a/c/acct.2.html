acct(2) Manual de llamadas al sistema acct(2)

NOMBRE

acct - activar o desactivar la contabilidad de procesos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int acct(const char *_Nullable path);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

acct():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

La llamada al sistema acct() activa o desactiva la contabilidad de procesos. Si se llama con la ruta de un archivo existente como argumento, la contabilidad se activa y los registros de cada proceso que finaliza se añaden al archivo a medida que este termina. Un argumento NULL desactiva la contabilidad.

VALOR DE RETORNO

Al éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EACCES
Se deniega el permiso de escritura para el archivo especificado, o se deniega el permiso de búsqueda para uno de los directorios en el prefijo de la ruta de path (ver también path_resolution(7)), o path no es un archivo regular.
EFAULT
path apunta fuera de su espacio de direcciones accesible.
EIO
Error al escribir en el archivo path.
EISDIR
path es un directorio.
ELOOP
Se encontraron demasiados enlaces simbólicos al resolver path.
ENAMETOOLONG
path era demasiado largo.
ENFILE
Se alcanzó el límite del sistema en el número total de archivos abiertos.
ENOENT
El path especificado no existe.
ENOMEM
Sin memoria.
ENOSYS
La contabilidad de procesos BSD no se ha activado cuando se compiló el núcleo del sistema operativo. El parámetro de configuración del núcleo que controla esta función es CONFIG_BSD_PROCESS_ACCT.
ENOTDIR
Un componente utilizado como directorio en path no es en realidad un directorio.
EPERM
El proceso que llama carece de privilegios suficientes para activar la contabilidad de procesos. En Linux, se requiere la capacidad CAP_SYS_PACCT.
EROFS
path se refiere a un archivo en un sistema de archivos de solo lectura.
EUSERS
No quedan estructuras de archivos libres o se agotó la memoria.

ESTÁNDARES

Ninguno.

HISTORIA

SVr4, 4.3BSD.

NOTAS

No se produce contabilidad para los programas que se ejecutan cuando ocurre un fallo del sistema. En particular, los procesos que no finalizan nunca se contabilizan.

La estructura de los registros escritos en el archivo de contabilidad se describe en acct(5).
