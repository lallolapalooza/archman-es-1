ACL_ENTRIES(3) Manual de funciones de la biblioteca ACL_ENTRIES(3)

NOMBRE

acl_entries — devuelve el número de entradas de una ACL

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_entries(acl_t acl);

DESCRIPCIÓN

La función acl_entries() devuelve el número de entradas de ACL que están contenidas en la ACL a la que se refiere el argumento acl.

VALOR DE RETORNO

La función acl_entries() devuelve el número de entradas en acl si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_entries() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento acl no es un puntero válido a una ACL.

ESTÁNDARES

Esta es una extensión no portátil y específica de Linux a las funciones de manipulación de ACL definidas en el borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado).
