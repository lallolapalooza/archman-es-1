NOMBRE

act - Ejecuta acciones de GitHub localmente especificando el nombre del evento (por ejemplo, push) o directamente el nombre de una acción.

SINOPSIS

**act [nombre del evento a ejecutar] [flags]

Si no se pasa ningún nombre de evento, se usará por defecto "on: push". Si las acciones manejan solo un evento, se usará como valor predeterminado en lugar de "on: push".**

DESCRIPCIÓN

Ejecuta acciones de GitHub localmente especificando el nombre del evento (por ejemplo, push) o directamente el nombre de una acción.

OPCIONES

--action-cache-path="/build/.cache/act" Define la ruta donde se almacenarán en caché las acciones y se crearán los espacios de trabajo del host.

--action-offline-mode[=false] Si el contenido de la acción existe, no se obtendrá ni se volverá a descargar. Si se activa esto, se desactivará la descarga forzada.

-a, --actor="nektos/act" Usuario que activó el evento

--artifact-server-addr="162.55.28.166" Define la dirección en la que se enlazará el servidor de artefactos.

--artifact-server-path="" Define la ruta donde el servidor de artefactos almacena las cargas y recupera las descargas. Si no se especifica, el servidor de artefactos no se iniciará.

--artifact-server-port="34567" Define el puerto en el que escuchará el servidor de artefactos.

-b, --bind[=false] Enlaza el directorio de trabajo al contenedor, en lugar de copiarlo.

--bug-report[=false] Muestra información del sistema para informes de errores.

--cache-server-addr="162.55.28.166" Define la dirección en la que se enlazará el servidor de caché.

--cache-server-external-url="" Define la URL externa en caso de que el servidor de caché esté detrás de un proxy. Por ejemplo: https://act-cache-server.example.com. Ten cuidado de no poner una barra inclinada al final.

--cache-server-path="/build/.cache/actcache" Define la ruta donde el servidor de caché almacena las cachés.

--cache-server-port=0 Define el puerto en el que escuchará el servidor de artefactos. 0 significa un puerto disponible aleatoriamente.

--concurrent-jobs=0 Número máximo de trabajos concurrentes a ejecutar. Por defecto es el número de CPUs disponibles.

--container-architecture="" Arquitectura que se utilizará para ejecutar contenedores, por ejemplo: linux/amd64. Si no se especifica, se utilizará la arquitectura predeterminada del host. Requiere la versión 1.41+ de la API del servidor de Docker. Se ignora en plataformas de servidor Docker anteriores.

--container-cap-add=[] Capacidades del kernel a añadir a los contenedores del flujo de trabajo (por ejemplo, --container-cap-add SYS_PTRACE)

--container-cap-drop=[] Capacidades del kernel a eliminar de los contenedores del flujo de trabajo (por ejemplo, --container-cap-drop SYS_PTRACE)

--container-daemon-socket="" URI del socket del motor Docker (por ejemplo: unix://~/.docker/run/docker.sock o - para deshabilitar el montaje enlazado del socket)

--container-options="" Opciones personalizadas de Docker para el contenedor del trabajo sin una propiedad de opciones en la definición del trabajo.

--defaultbranch="" el nombre de la rama principal.

--detect-event[=false] Utiliza el primer tipo de evento del flujo de trabajo como evento que activó el flujo de trabajo.

-C, --directory="." Directorio de trabajo.

-n, --dryrun[=false] Deshabilita la creación de contenedores, solo valida la corrección del flujo de trabajo.

--env=[] Variables de entorno a hacer disponibles para las acciones con valor opcional (por ejemplo, --env myenv=foo o --env myenv)

--env-file=".env" Archivo de variables de entorno a leer y usar como variables de entorno en los contenedores.

-e, --eventpath="" Ruta al archivo JSON del evento.

--github-instance="github.com" Instancia de GitHub a usar. Solo usa esto cuando uses GitHub Enterprise Server.

-g, --graph[=false] Dibuja flujos de trabajo.

-h, --help[=false] Ayuda para act.

--input=[] Entrada de acción a hacer disponible para las acciones (por ejemplo, --input myinput=foo).

--input-file=".input" Archivo de entrada a leer y usar como entrada de acción.

--insecure-secrets[=false] ¡NO RECOMENDADO! No oculta secretos al mostrar registros.

-j, --job="" Ejecuta un ID de trabajo específico.

--json[=false] Muestra los registros en formato JSON.

-l, --list[=false] Lista los flujos de trabajo.

--list-options[=false] Muestra una estructura JSON de opciones compatibles.

--local-repository=[] Reemplaza el repositorio y referencia especificados con una carpeta local (por ejemplo, https://github.com/test/test@v0=/home/act/test o test/test@v0=/home/act/test, este último coincide con cualquier host o protocolo)

--log-prefix-job-id[=false] Muestra el ID del trabajo dentro de registros no JSON en lugar del nombre completo.

--man-page[=false] Muestra una página de manual generada en stdout.

--matrix=[] Especifica qué configuración de matriz incluir (por ejemplo, --matrix java:13

--network="host" Establece un nombre de red de Docker. Por defecto es host.

--no-cache-server[=false] Deshabilita el servidor de caché.

--no-recurse[=false] Indicador para deshabilitar la ejecución de flujos de trabajo desde subdirectorios de la ruta especificada en el indicador '--workflows'/'-W'.

--no-skip-checkout[=false] Usa actions/checkout en lugar de copiar archivos locales al contenedor.

-P, --platform=[] Imagen personalizada a usar por plataforma (por ejemplo, -P ubuntu-18.04=nektos/act-environments-ubuntu:18.04)

--privileged[=false] Usa modo privilegiado.

-p, --pull[=true] Descarga la(s) imagen(es) de Docker incluso si ya están presentes.

-q, --quiet[=false] Deshabilita la visualización de la salida de los pasos.

--rebuild[=true] Reconstruye la(s) imagen(es) de Docker de acción local incluso si ya están presentes.

--remote-name="origin" Nombre del control remoto de git que se utilizará para recuperar la URL del repositorio git.

--replace-ghe-action-token-with-github-com="" Si estás usando replace-ghe-action-with-github-com y quieres usar acciones privadas en GitHub, debes establecer un token de acceso personal.

--replace-ghe-action-with-github-com=[] Si estás usando GitHub Enterprise Server y permites acciones específicas de GitHub (github.com), puedes configurarlas aquí. (por ejemplo, --replace-ghe-action-with-github-com =github/super-linter)

-r, --reuse[=false] No elimina el(los) contenedor(es) en caso de que el(los) flujo(s) de trabajo se complete(n) correctamente para mantener el estado entre ejecuciones.

--rm[=false] Elimina automáticamente el(los) contenedor(es)/volumen(es) después de un fallo en el(los) flujo(s) de trabajo.

-s, --secret=[] Secreto a hacer disponible para las acciones con valor opcional (por ejemplo, -s mysecret=foo o -s mysecret).

--secret-file=".secrets" Archivo con lista de secretos para leer (por ejemplo, --secret-file .secrets).

--strict[=false] Usa esquema de flujo de trabajo estricto.

--use-gitignore[=true] Controla si las rutas especificadas en .gitignore se copiarán al contenedor.

--use-new-action-cache[=false] Habilita el uso de la nueva caché de acciones para almacenar acciones localmente.

--userns="" Espacio de nombres de usuario a usar.

--validate[=false] Valida los flujos de trabajo.

--var=[] Variable a hacer disponible para las acciones con valor opcional (por ejemplo, --var myvar=foo o --var myvar).

--var-file=".vars" Archivo con lista de variables para leer (por ejemplo, --var-file .vars).

-v, --verbose[=false] Salida detallada.

--version[=false] Versión de act.

-w, --watch[=false] Observa el contenido del repositorio local y ejecuta cuando los archivos cambien.

-W, --workflows="./.github/workflows/" Ruta al(los) archivo(s) de flujo de trabajo.
