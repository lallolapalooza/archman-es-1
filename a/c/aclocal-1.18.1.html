ACLOCAL(1) Comandos de usuario ACLOCAL(1)

NOMBRE

aclocal - Genera aclocal.m4 escaneando configure.ac

SINOPSIS

aclocal [OPCIÓN]...

DESCRIPCIÓN

Genera 'aclocal.m4' escaneando 'configure.ac' o 'configure.in'

OPCIONES

--automake-acdir=DIR
directorio que contiene los archivos m4 proporcionados por automake
--aclocal-path=PATH
lista de directorios separados por dos puntos para buscar archivos locales de terceros
--system-acdir=DIR
directorio que contiene archivos de terceros a nivel del sistema
--diff[=COMANDO]
ejecuta COMANDO [diff -u] en los archivos M4 que se modificarían (implica --install y --dry-run)
--dry-run
simula, pero no actualiza ningún archivo
--force
actualiza siempre el archivo de salida
--help
muestra esta ayuda y sale
-I DIR
añade un directorio a la lista de búsqueda de archivos .m4
--install
copia archivos de terceros al primer directorio -I
--output=ARCHIVO
guarda la salida en ARCHIVO (por defecto aclocal.m4)
--print-ac-dir
muestra el nombre del directorio que contiene los archivos m4 de terceros a nivel del sistema y sale
--verbose
no seas silencioso
--version
muestra el número de versión y sale
-W, --warnings=CATEGORÍA
informa las advertencias que caen en CATEGORÍA, por defecto es $WARNINGS

Las categorías de advertencia son:

cross
problemas de compilación cruzada
gnu
estándares de codificación de GNU (por defecto en modos gnu y gnits)
obsolete
características o construcciones obsoletas (por defecto)
override
redefiniciones por el usuario de reglas o variables de Automake
portability
problemas de portabilidad (por defecto en modos gnu y gnits)
portability-recursive
variables anidadas de Make (por defecto con -Wportability)
extra-portability
problemas de portabilidad adicionales relacionados con herramientas poco comunes
syntax
construcciones sintácticas dudosas (por defecto)
unsupported
características no soportadas o incompletas (por defecto)

-W también entiende:

all
activa todas las advertencias
none
desactiva todas las advertencias
no-CATEGORÍA
desactiva las advertencias en CATEGORÍA
error
trata todas las advertencias habilitadas como errores
