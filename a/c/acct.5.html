acct(5) Manual de formatos de archivo acct(5)

NOMBRE

acct - archivo de contabilidad de procesos

SINOPSIS

#include <sys/acct.h>

DESCRIPCIÓN

Si el kernel se compila con la opción de contabilidad de procesos habilitada (CONFIG_BSD_PROCESS_ACCT), entonces llamar a acct(2) inicia la contabilidad de procesos, por ejemplo:


acct("/var/log/pacct");

Cuando la contabilidad de procesos está habilitada, el kernel escribe un registro en el archivo de contabilidad cada vez que un proceso en el sistema termina. Este registro contiene información sobre el proceso terminado, y está definido en <sys/acct.h> de la siguiente manera:


#define ACCT_COMM 16
typedef u_int16_t comp_t;
struct acct {
    char ac_flag;           /* Banderas de contabilidad */
    u_int16_t ac_uid;       /* ID de usuario de contabilidad */
    u_int16_t ac_gid;       /* ID de grupo de contabilidad */
    u_int16_t ac_tty;       /* Terminal de control */
    u_int32_t ac_btime;     /* Hora de creación del proceso
                               (segundos desde la época) */
    comp_t    ac_utime;     /* Tiempo de CPU de usuario */
    comp_t    ac_stime;     /* Tiempo de CPU de sistema */
    comp_t    ac_etime;     /* Tiempo transcurrido */
    comp_t    ac_mem;       /* Uso medio de memoria (kB) */
    comp_t    ac_io;        /* Caracteres transferidos (sin uso) */
    comp_t    ac_rw;        /* Bloques leídos o escritos (sin uso) */
    comp_t    ac_minflt;    /* Fallos de página menores */
    comp_t    ac_majflt;    /* Fallos de página mayores */
    comp_t    ac_swaps;     /* Número de intercambios (sin uso) */
    u_int32_t ac_exitcode;  /* Estado de terminación del proceso
                               (ver wait(2)) */
    char      ac_comm[ACCT_COMM+1];
                            /* Nombre del comando (nombre base del último
                               comando ejecutado; terminado en nulo) */
    char      ac_pad[X];    /* bytes de relleno */
};
enum {          /* Bits que pueden establecerse en el campo ac_flag */
    AFORK = 0x01,           /* Ha ejecutado fork, pero no exec */
    ASU   = 0x02,           /* Ha usado privilegios de superusuario */
    ACORE = 0x08,           /* Ha volcado el núcleo */
    AXSIG = 0x10            /* Ha sido terminado por una señal */
};

El tipo de datos comp_t es un valor de punto flotante que consta de un exponente de 3 bits en base 8, y una mantisa de 13 bits. Un valor, c, de este tipo puede convertirse a un entero (long) de la siguiente manera:

    v = (c & 0x1fff) << (((c >> 13) & 0x7) * 3);

Los campos ac_utime, ac_stimey ac_etime miden el tiempo en "ticks de reloj"; divida estos valores por sysconf(_SC_CLK_TCK) para convertirlos a segundos.

Formato de archivo de contabilidad versión 3

Desde Linux 2.6.8, se puede producir una versión alternativa opcional del archivo de contabilidad si la opción CONFIG_BSD_PROCESS_ACCT_V3 está establecida al compilar el kernel. Con esta opción establecida, los registros escritos en el archivo de contabilidad contienen campos adicionales, y el ancho de los campos c_uid y ac_gid se amplía de 16 a 32 bits (en línea con el tamaño aumentado de UID y GIDs en Linux 2.4 y posteriores). Los registros están definidos de la siguiente manera:


struct acct_v3 {
    char      ac_flag;      /* Banderas */
    char      ac_version;   /* Siempre establecido a ACCT_VERSION (3) */
    u_int16_t ac_tty;       /* Terminal de control */
    u_int32_t ac_exitcode;  /* Estado de terminación del proceso */
    u_int32_t ac_uid;       /* ID de usuario real */
    u_int32_t ac_gid;       /* ID de grupo real */
    u_int32_t ac_pid;       /* ID de proceso */
    u_int32_t ac_ppid;      /* ID del proceso padre */
    u_int32_t ac_btime;     /* Hora de creación del proceso */
    float     ac_etime;     /* Tiempo transcurrido */
    comp_t    ac_utime;     /* Tiempo de CPU de usuario */
    comp_t    ac_stime;     /* Tiempo de sistema */
    comp_t    ac_mem;       /* Uso medio de memoria (kB) */
    comp_t    ac_io;        /* Caracteres transferidos (sin uso) */
    comp_t    ac_rw;        /* Bloques leídos o escritos
                               (sin uso) */
    comp_t    ac_minflt;    /* Fallos de página menores */
    comp_t    ac_majflt;    /* Fallos de página mayores */
    comp_t    ac_swaps;     /* Número de intercambios (sin uso) */
    char      ac_comm[ACCT_COMM]; /* Nombre del comando */
};

VERSIONES

Aunque está presente en la mayoría de los sistemas, no está estandarizado, y los detalles varían algo entre sistemas.

ESTÁNDARES

Ninguno.

HISTORIA

glibc 2.6.

La contabilidad de procesos se originó en BSD.

NOTAS

Los registros en el archivo de contabilidad están ordenados por el tiempo de terminación del proceso.

Hasta y incluyendo Linux 2.6.9, se escribe un registro de contabilidad separado para cada hilo creado usando la biblioteca de hilos NPTL; desde Linux 2.6.10, se escribe un único registro de contabilidad para todo el proceso al terminar el último hilo en el proceso.

El archivo /proc/sys/kernel/acct , descrito en proc(5), define ajustes que controlan el comportamiento de la contabilidad de procesos cuando el espacio en disco se agota.
