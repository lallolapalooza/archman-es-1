NOMBRE

Acme::Alien::DontPanic - Módulo de prueba para Alien::Base::ModuleBuild

VERSIÓN

versión 2.7200

DESCRIPCIÓN

Alien::Base comprende las clases base para ayudar en la construcción de módulos "Alien::". Los módulos en el espacio de nombres Alien se utilizan para localizar e instalar (si es necesario) bibliotecas externas necesarias para otros módulos de Perl.

Este módulo es un módulo de juguete para probar la eficacia del sistema Alien::Base::ModuleBuild. Este módulo es dependido por otro módulo de juguete, Acme::Ford::Prefect, que necesita la biblioteca libdontpanic para poder decirnos la "respuesta".
