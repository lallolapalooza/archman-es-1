acme-redirect(1) Manual de Comandos Generales acme-redirect(1)

NOMBRE

acme-redirect - Pequeño demonio http que responde a desafíos acme y redirige todo lo demás a https

SINOPSIS

acme-redirect [-v|--verbose] [-c /etc/acme-redirect.conf] [--config-dir /etc/acme-redirect.d] [--acme-email <acme-email>] [--acme-url https://acme-v02.api.letsencrypt.org/directory] [--chall-dir /run/acme-redirect] [--data-dir /var/lib/acme-redirect] <subcomando>

DESCRIPCIÓN

acme-redirect es un pequeño servidor http que implementa el protocolo ACME (Automated Certificate Management Environment) y redirige todo lo demás a https. Puede ejecutarse directamente en el puerto 80 y admite la emisión y renovación automática de certificados listos para usar con una configuración mínima.

DAEMON

Ejecuta el demonio http.

-B <addr-enlace>, --bind-addr <addr-enlace>

La dirección en la que escuchar. El valor predeterminado es [::]:80.

--chroot

Chroot en el directorio de desafío.

--user <usuario>

Cambiar de root a este usuario.

acme-redirect daemon

RENOVAR

Renueva los certificados que están a punto de expirar y ejecuta los comandos dados para activar la recarga del certificado.

-n, --dry-run

No haga nada realmente, solo muestre lo que sucedería.

--force-renew

Renueva los certificados incluso si no están a punto de expirar.

--skip-cleanup

No limpie certificados antiguos que ya no estén activos.

--skip-restarts

No ejecute los comandos exec configurados.

<certificados ...>

Solo renueva certificados específicos. Si no se selecciona ningún certificado explícitamente, renueva todos los certificados.

acme-redirect renew

ESTADO

Muestra los certificados actualmente disponibles y su estado de expiración.

acme-redirect status

RENOVACIÓN AUTOMÁTICA

Simplemente puede ejecutar acme-redirect renew periódicamente. Si está usando systemd, puede usar el temporizador de systemd con:

systemctl enable --now acme-redirect-renew.timer

VER TAMBIÉN

acme-redirect.conf(5), acme-redirect.d(5).
