acl_delete_perm(3)

Paquete: acl

Licencias: LGPL

ACL_DELETE_PERM(3) Manual de funciones de biblioteca ACL_DELETE_PERM(3)

NOMBRE

acl_delete_perm — eliminar un permiso de un conjunto de permisos ACL

BIBLIOTECA

Biblioteca de listas de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_delete_perm(acl_permset_t permset_d, acl_perm_t perm);

DESCRIPCIÓN

La función acl_delete_perm() elimina el permiso contenido en el argumento perm (uno de ACL_READ, ACL_WRITE, ACL_EXECUTE) del conjunto de permisos al que se refiere el argumento permset_d. Un intento de eliminar un permiso que no está contenido en el conjunto de permisos no se considera un error.

Cualquier descriptor existente que haga referencia a permset_d seguirá haciendo referencia a ese conjunto de permisos.

VALOR DE RETORNO

La función acl_delete_perm() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_delete_perm() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento permset_d no es un descriptor válido para un conjunto de permisos dentro de una entrada ACL.

El argumento perm no contiene un valor acl_perm_t válido.

ESTÁNDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIÉN

acl_add_perm(3), acl_clear_perms(3), acl_get_perm(3), acl_get_permset(3), acl_set_permset(3), acl(5)
