acl_copy_entry(3)

Paquete: acl

Licencias: LGPL

ACL_COPY_ENTRY(3) Manual de funciones de la biblioteca ACL_COPY_ENTRY(3)

NOMBRE

acl_copy_entry — copia una entrada ACL

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_copy_entry(acl_entry_t dest_d, acl_entry_t src_d);

DESCRIPCIÓN

La función acl_copy_entry() copia el contenido de la entrada ACL indicada por el descriptor src_d a la entrada ACL existente indicada por el descriptor dest_d. Los descriptores src_d y dest_d pueden referirse a entradas en ACLs diferentes.

VALOR DE RETORNO

La función acl_copy_entry() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_copy_entry() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento src_d o dest_d no es un descriptor válido para una entrada ACL.

Los argumentos src_d y dest_d hacen referencia a la misma entrada ACL.

ESTÁNDARES

Borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado)

VER TAMBIÉN

acl_get_entry(3), acl(5)
