ACL_VALID(3) Manual de funciones de biblioteca ACL_VALID(3)

NOMBRE

acl_valid — validar un ACL

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_valid(acl_t acl);

DESCRIPCIÓN

La función acl_valid() comprueba la validez del ACL al que hace referencia el argumento acl.

Las tres entradas requeridas ACL_USER_OBJ, ACL_GROUP_OBJ y ACL_OTHER deben existir exactamente una vez en el ACL. Si el ACL contiene alguna entrada ACL_USER o ACL_GROUP, entonces también se requiere una entrada ACL_MASK. El ACL puede contener como máximo una entrada ACL_MASK.

Los identificadores de usuario deben ser únicos entre todas las entradas de tipo ACL_USER. Los identificadores de grupo deben ser únicos entre todas las entradas de tipo ACL_GROUP.

VALOR DE RETORNO

La función acl_valid() devuelve el valor 0 si tiene éxito; de lo contrario, devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_valid() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento acl no es un puntero válido a un ACL.

El argumento acl no apunta a un ACL válido.

Una o más de las entradas ACL requeridas no están presentes en acl.

El ACL contiene entradas que no son únicas.

ESTÁNDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIÉN

acl_check(3), acl_set_file(3), acl(5)
