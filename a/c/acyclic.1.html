CYCLIC(1) Manual de comandos generales CYCLIC(1)

NOMBRE

acyclic - hacer que un grafo dirigido sea acíclico

SINOPSIS

acyclic [ -nv? ] [ -o archivo_salida ] [ archivo ]

DESCRIPCIÓN

acyclic es un filtro que toma un grafo dirigido como entrada y genera una copia del grafo con suficientes aristas invertidas para hacerlo acíclico. La arista invertida hereda todos los atributos de la arista original. El argumento de archivo opcional especifica dónde se almacena el grafo de entrada; por defecto, el programa lee desde stdin.

OPCIONES

Se admiten las siguientes opciones:

-n
No se produce ninguna salida, aunque el valor de retorno indicará si el grafo es acíclico o no.
-v
Imprime información sobre si el archivo es acíclico, tiene un ciclo o es no dirigido.
-o archivo_salida
hace que la salida se escriba en el archivo especificado; por defecto, la salida se escribe en stdout.
-?
la opción hace que el programa imprima información de uso.

CÓDIGOS DE RETORNO

acyclic devuelve 0 si el grafo es acíclico; 1 si el grafo tiene un ciclo; 2 si el grafo es no dirigido; y 255 si hay algún error.

ERRORES CONOCIDOS

Si el grafo es estricto y hay un ciclo de longitud 2, los atributos de la arista invertida se pierden.

Algunos atributos de las aristas no son simétricos y hacen referencia al nodo de cabeza o de cola. En este momento, no existe ningún mecanismo o convención para cambiarlos o renombrarlos correctamente.
