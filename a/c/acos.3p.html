ACOS(3P) Manual del programador POSIX ACOS(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

acos, acosf, acosl — funciones de arcocoseno

SINOPSIS

#include <math.h>
double acos(double x);
float acosf(float x);
long double acosl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán el valor principal del arcocoseno de su argumento x. El valor de x debe estar en el rango [-1,1].

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, ha ocurrido un error.

VALOR DE RETORNO

Tras una finalización correcta, estas funciones devolverán el arcocoseno de x, en el rango [0,π] radianes.

Para valores finitos de x que no estén en el rango [-1,1], se producirá un error de dominio y se devolverá un NaN (si es compatible) o un valor definido por la implementación.

Si x es NaN, se devolverá un NaN.

Si x es +1, se devolverá +0.

Si x es ±Inf, se producirá un error de dominio y se devolverá un NaN.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El argumento x es finito y no está en el rango [-1,1], o es ±Inf.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante inválida.

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
