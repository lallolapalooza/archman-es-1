acl_extended_file(3)

Paquete: acl

Licencias: LGPL

ACL_EXTENDED_FILE(3) Manual de funciones de biblioteca ACL_EXTENDED_FILE(3)

NOMBRE

acl_extended_file, acl_extended_file_nofollow — comprobar información en ACLs por nombre de archivo

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_extended_file(const char *path_p);

int
acl_extended_file_nofollow(const char *path_p);

DESCRIPCIÓN

La función acl_extended_file() devuelve 1 si el archivo o directorio al que se refiere el argumento path_p está asociado con una ACL de acceso extendida, o si el directorio al que se refiere path_p está asociado con una ACL por defecto. La función devuelve 0 si el archivo no tiene ni una ACL de acceso extendida ni una ACL por defecto.

Una ACL extendida es una ACL que contiene entradas distintas de las tres entradas requeridas de tipos de etiqueta ACL_USER_OBJ, ACL_GROUP_OBJ y ACL_OTHER. Si el resultado de la función acl_extended_file() para un objeto de archivo es 0, entonces las ACLs no definen derechos de acceso discrecional distintos de los ya definidos por los bits de permisos de archivo tradicionales.

El acceso al objeto de archivo puede estar restringido adicionalmente por otros mecanismos, como esquemas de Control de Acceso Obligatorio. La llamada al sistema access(2) puede usarse para comprobar si un tipo de acceso dado a un objeto de archivo sería concedido.

acl_extended_file_nofollow() es idéntica a acl_extended_file(), excepto en el caso de un enlace simbólico, donde se interroga el enlace en sí, no el archivo al que se refiere. Dado que los enlaces simbólicos no tienen ACL por sí mismos, se supone que la operación falla en ellos.

VALOR DE RETORNO

Si tiene éxito, la función acl_extended_file() devuelve 1 si el objeto de archivo al que se refiere path_p tiene una ACL de acceso extendida o una ACL por defecto, y 0 si el objeto de archivo al que se refiere path_p no tiene ninguna de las dos. De lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_extended_file() devuelve -1 y establece errno con el valor correspondiente:

[EACCES]
Se deniega el permiso de búsqueda para un componente del prefijo de ruta.
[ENAMETOOLONG]
La longitud del argumento path_p es demasiado larga.
[ENOENT]
El objeto nombrado no existe o el argumento path_p apunta a una cadena vacía.
[ENOTDIR]
Un componente del prefijo de ruta no es un directorio.
[ENOTSUP]
El sistema de archivos en el que se encuentra el archivo identificado por path_p no admite ACLs, o las ACLs están deshabilitadas.

ESTÁNDARES

Esta es una extensión no portable y específica de Linux a las funciones de manipulación de ACL definidas en el borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado).

VER TAMBIÉN
