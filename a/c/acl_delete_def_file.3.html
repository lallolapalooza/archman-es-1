Paquete: acl

Licencias: LGPL

ACL_DELETE_DEF_FILE(3) Manual de funciones de biblioteca ACL_DELETE_DEF_FILE(3)

NOMBRE

acl_delete_def_file — eliminar un ACL predeterminado por nombre de archivo

BIBLIOTECA

Biblioteca de listas de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_delete_def_file(const char *path_p);

DESCRIPCIÓN

La función acl_delete_def_file() elimina un ACL predeterminado del directorio cuyo nombre de ruta se apunta mediante el argumento path_p.

El ID de usuario efectivo del proceso debe coincidir con el propietario del archivo o directorio, o el proceso debe tener la capacidad CAP_FOWNER para que la solicitud tenga éxito.

Si el argumento path_p no es un directorio, entonces la función falla. No es un error si el directorio cuyo nombre de ruta se apunta mediante el argumento path_p no tiene un ACL predeterminado.

VALOR DE RETORNO

La función acl_delete_def_file() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_delete_def_file() devuelve el valor -1 y establece errno al valor correspondiente:

[EINVAL]
El archivo al que se refiere path_p no es un directorio.
[ENOTSUP]
El sistema de archivos en el que se encuentra el archivo identificado por path_p no admite ACL, o los ACL están deshabilitados.
[EPERM]
El proceso no tiene el privilegio apropiado para realizar la operación de eliminar el ACL predeterminado.
[EROFS]
Esta función requiere la modificación de un sistema de archivos que actualmente está en modo de solo lectura.

ESTÁNDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIÉN
