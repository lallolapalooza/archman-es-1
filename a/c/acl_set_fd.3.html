acl_set_fd(3)

Paquete: acl

Licencias: LGPL

ACL_SET_FD(3) Manual de funciones de biblioteca ACL_SET_FD(3)

NOMBRE

acl_set_fd — establecer una ACL por descriptor de archivo

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_set_fd(int fd, acl_t acl);

DESCRIPCIÓN

La función acl_set_fd() asocia una ACL de acceso con el archivo al que se refiere fd.

El ID de usuario efectivo del proceso debe coincidir con el propietario del archivo o el proceso debe tener la capacidad CAP_FOWNER para que la solicitud tenga éxito.

VALOR DE RETORNO

La función acl_set_fd() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_set_fd() devuelve el valor -1 y establece errno al valor correspondiente:

[EBADF]
El argumento fd no es un descriptor de archivo válido.
[EINVAL]
El argumento acl no apunta a una ACL válida.

La ACL tiene más entradas de las que el archivo al que se refiere fd puede obtener.

[ENOSPC]
El directorio o sistema de archivos que contendría la nueva ACL no puede extenderse o al sistema de archivos le faltan recursos de asignación de archivos.
[ENOTSUP]
El archivo identificado por fd no puede asociarse con la ACL porque el sistema de archivos en el que se encuentra el archivo no lo admite.
[EPERM]
El proceso no tiene los privilegios adecuados para realizar la operación de establecer la ACL.
[EROFS]
Esta función requiere la modificación de un sistema de archivos que actualmente es de solo lectura.

ESTANDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)
