acl_calc_mask(3)

Paquete: acl

Licencias: LGPL

ACL_CALC_MASK(3) Manual de funciones de biblioteca ACL_CALC_MASK(3)

NOMBRE

acl_calc_mask — calcula la máscara de la clase de grupo de archivos

BIBLIOTECA

Biblioteca de listas de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_calc_mask(acl_t *acl_p);

DESCRIPCIÓN

La función acl_calc_mask() calcula y establece los permisos asociados con la entrada ACL_MASK de la ACL a la que se refiere acl_p. El valor de los nuevos permisos es la unión de los permisos otorgados por todas las entradas de tipo de etiqueta ACL_GROUP, ACL_GROUP_OBJ o ACL_USER. Si la ACL a la que se refiere acl_p ya contiene una entrada ACL_MASK, sus permisos se sobrescriben; si no contiene una entrada ACL_MASK, se añade una.

Si la ACL a la que se refiere acl_p no contiene suficiente espacio para la nueva entrada de ACL, entonces se puede asignar espacio de trabajo adicional. Si el espacio de trabajo no se puede aumentar en la ubicación actual, puede ser reubicado, se libera el espacio de trabajo anterior y se devuelve un puntero al nuevo espacio de trabajo a través de acl_p.

El orden de las entradas existentes en la ACL no está definido después de esta función.

Cualquier descriptor de entrada de ACL existente que haga referencia a entradas en la ACL continúa haciendo referencia a esas entradas. Cualquier puntero de ACL existente que haga referencia a la ACL a la que se refiere acl_p continúa haciendo referencia a la ACL.

VALOR DE RETORNO

La función acl_calc_mask() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_calc_mask() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento acl no es un puntero válido a una ACL.
[ENOMEM]
La función acl_calc_mask() no puede asignar la memoria necesaria para una entrada de ACL ACL_MASK.

ESTÁNDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIÉN
