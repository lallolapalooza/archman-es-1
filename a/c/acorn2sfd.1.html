NOMBRE

acorn2sfd - crea archivos sfd de FontForge a partir de fuentes Acorn RISCOS

SINOPSIS

acorn2sfd [--help] [--includestrokes] [--version] [directorios_acorn]

DESCRIPCIÓN

acorn2sfd toma una lista de nombres de directorios e intenta convertir los datos de fuentes dentro de cada directorio a uno de los archivos sfd de FontForge.

Las fuentes de Acorn RISCOS consisten en 2 archivos, Outlines y Intmetrics, dentro de un directorio.

OPCIONES

--help
Proporciona una descripción con una lista de opciones disponibles.
--includestrokes
Establece una bandera para incluir trazos.
--version
Muestra la versión actual.

VER TAMBIÉN

fontforge(1) showttf(1) ttf2eps(1)
