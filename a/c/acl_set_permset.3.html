acl_set_permset(3)

Paquete: acl

Licencias: LGPL

ACL_SET_PERMSET(3) Manual de funciones de la biblioteca ACL_SET_PERMSET(3)

NOMBRE

acl_set_permset — establece el conjunto de permisos en una entrada ACL

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_set_permset(acl_entry_t entry_d, acl_permset_t permset_d);

DESCRIPCIÓN

La función acl_set_permset() establece el conjunto de permisos de la entrada ACL indicada por el argumento entry_d a los permisos contenidos en el argumento permset_d.

Cualquier descriptor de entrada ACL que se refiera a la entrada que contiene el conjunto de permisos referenciado por permset_d continuará refiriéndose a esas entradas. Cualquier descriptor de entrada ACL que se refiera a la entrada referenciada por entry_d continuará refiriéndose a esa entrada.

VALOR DE RETORNO

La función acl_set_permset() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si se produce alguna de las siguientes condiciones, la función acl_set_permset() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento entry_d no es un descriptor válido para una entrada ACL.

El argumento permset_d no es un descriptor válido para un conjunto de permisos dentro de una entrada ACL.

El argumento permset_d contiene valores que no son valores válidos de acl_permset_t.

NORMAS

Borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado)
