acl_get_file(3)

Paquete: acl

Licencias: LGPL

ACL_GET_FILE(3) Manual de funciones de la biblioteca ACL_GET_FILE(3)

NOMBRE

acl_get_file — obtener un ACL por nombre de archivo

BIBLIOTECA

Lista de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

acl_t
acl_get_file(const char *path_p, acl_type_t type);

DESCRIPCIÓN

La función acl_get_file() recupera el ACL de acceso asociado a un archivo o directorio, o el ACL predeterminado asociado a un directorio. La ruta del archivo o directorio se señala mediante el argumento path_p. El ACL se coloca en el espacio de trabajo y acl_get_file() devuelve un puntero a dicho espacio.

Para leer un ACL de un objeto, un proceso debe tener permisos de lectura sobre los atributos del objeto.

El valor del argumento type se utiliza para indicar si se devuelve el ACL de acceso o el ACL predeterminado asociado a path_p. Si type es ACL_TYPE_ACCESS, se devuelve el ACL de acceso de path_p. Si type es ACL_TYPE_DEFAULT, se devuelve el ACL predeterminado de path_p. Si type es ACL_TYPE_DEFAULT y no hay ningún ACL predeterminado asociado con el directorio path_p, entonces se devuelve un ACL que contiene cero entradas de ACL. Si type especifica un tipo de ACL que no se puede asociar con path_p, la función falla.

Esta función puede asignar memoria. La parte que llama debe liberar cualquier memoria liberable, cuando el nuevo ACL ya no sea necesario, llamando a acl_free(3) con el (void*)acl_t devuelto por acl_get_file() como argumento.

VALOR DE RETORNO

En caso de éxito, esta función devuelve un puntero al espacio de trabajo. En caso de error, se devuelve el valor (acl_t)NULL y se establece errno apropiadamente.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_get_file() devuelve un valor de (acl_t)NULL y establece errno al valor correspondiente:

[EACCES]
Se deniega el permiso de búsqueda para un componente del prefijo de ruta o el objeto existe y el proceso no tiene los derechos de acceso apropiados.

El argumento type especifica un tipo de ACL que no se puede asociar con path_p.

[EINVAL]
El argumento type no es ACL_TYPE_ACCESS ni ACL_TYPE_DEFAULT.
[ENAMETOOLONG]
La longitud del argumento path_p es demasiado larga.
[ENOENT]
El objeto nombrado no existe o el argumento path_p apunta a una cadena vacía.
[ENOMEM]
El espacio de trabajo del ACL requiere más memoria de la permitida por el hardware o por las restricciones de gestión de memoria impuestas por el sistema.
[ENOTDIR]
Un componente del prefijo de ruta no es un directorio.
[ENOTSUP]
El sistema de archivos en el que se encuentra el archivo identificado por path_p no admite ACLs, o los ACLs están deshabilitados.

ESTANDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIEN
