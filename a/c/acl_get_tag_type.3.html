ACL_GET_TAG_TYPE(3) Manual de funciones de biblioteca ACL_GET_TAG_TYPE(3)

NOMBRE

acl_get_tag_type — obtener el tipo de etiqueta de una entrada ACL

BIBLIOTECA

Biblioteca de listas de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_get_tag_type(acl_entry_t entry_d, acl_tag_t *tag_type_p);

DESCRIPCIÓN

La función acl_get_tag_type() asigna al valor al que apunta tag_type_p el tipo de etiqueta para la entrada ACL indicada por el argumento entry_d.

El argumento entry_d y cualquier otro descriptor de entrada ACL que haga referencia a entradas en la misma ACL continúan haciendo referencia a esas entradas. El orden de todas las entradas existentes en la ACL permanece sin cambios.

VALOR DE RETORNO

La función acl_get_tag_type() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_get_tag_type() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento entry_d no es un descriptor válido para una entrada ACL.

ESTÁNDARES

IEEE Std 1003.1e borrador 17 (“POSIX.1e”, abandonado)

VER TAMBIÉN
