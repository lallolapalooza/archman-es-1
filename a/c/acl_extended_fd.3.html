ACL_EXTENDED_FD(3) Manual de funciones de biblioteca ACL_EXTENDED_FD(3)

NOMBRE

acl_extended_fd — prueba información en la ACL por descriptor de archivo

BIBLIOTECA

Biblioteca de listas de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_extended_fd(int fd);

DESCRIPCIÓN

La función acl_extended_fd() devuelve 1 si el archivo identificado por el argumento fd está asociado con una ACL de acceso extendida. La función devuelve 0 si el archivo no tiene una ACL de acceso extendida.

Una ACL extendida es una ACL que contiene entradas distintas de las tres entradas requeridas de tipos de etiqueta ACL_USER_OBJ, ACL_GROUP_OBJ y ACL_OTHER. Si el resultado de la función acl_extended_fd() para un objeto de archivo es 0, entonces la ACL no define derechos de acceso discrecionales distintos de los ya definidos por los bits de permisos de archivo tradicionales.

El acceso al objeto de archivo puede estar restringido adicionalmente por otros mecanismos, como los esquemas de Control de Acceso Obligatorio. La llamada al sistema access(2) se puede utilizar para comprobar si se concedería un tipo de acceso determinado al objeto de archivo.

VALOR DE RETORNO

Si tiene éxito, la función acl_extended_fd() devuelve 1 si el objeto de archivo identificado por fd tiene una ACL de acceso extendida, y 0 si el objeto de archivo identificado por fd no tiene una ACL de acceso extendida. En caso contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_extended_fd() devuelve -1 y establece errno al valor correspondiente:

[EBADF]
El argumento fd no es un descriptor de archivo válido.
[ENOTSUP]
El sistema de archivos en el que se encuentra el archivo identificado por fd no admite ACLs o las ACLs están deshabilitadas.

ESTÁNDARES

Esta es una extensión no portátil y específica de Linux a las funciones de manipulación de ACL definidas en el borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado).

VéASE TAMBIÉN

access(2), acl_get_fd(3), acl(5)
