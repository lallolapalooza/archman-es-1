acl_check(3)

Paquete: acl

Licencias: LGPL

ACL_CHECK(3) Manual de funciones de biblioteca ACL_CHECK(3)

NOMBRE

acl_check — comprueba la validez de una ACL

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

int
acl_check(acl_t acl, int *last);

DESCRIPCIÓN

La función acl_check() comprueba la validez de la ACL a la que se refiere el argumento acl.

Las tres entradas requeridas ACL_USER_OBJ, ACL_GROUP_OBJ y ACL_OTHER deben existir exactamente una vez en la ACL. Si la ACL contiene alguna entrada ACL_USER o ACL_GROUP, entonces también se requiere una entrada ACL_MASK. La ACL puede contener como máximo una entrada ACL_MASK.

Los identificadores de usuario deben ser únicos entre todas las entradas de tipo ACL_USER. Los identificadores de grupo deben ser únicos entre todas las entradas de tipo ACL_GROUP.

Si la ACL a la que se refiere acl es inválida, acl_check() devuelve un código de error positivo que indica qué tipo de error se detectó. Los siguientes códigos de error simbólicos están definidos:

ACL_MULTI_ERROR
La ACL contiene múltiples entradas que tienen un tipo de etiqueta que puede ocurrir como máximo una vez.
ACL_DUPLICATE_ERROR
La ACL contiene múltiples entradas ACL_USER con el mismo ID de usuario, o múltiples entradas ACL_GROUP con el mismo ID de grupo.
ACL_MISS_ERROR
Falta una entrada requerida.
ACL_ENTRY_ERROR
La ACL contiene un tipo de etiqueta de entrada inválido.

La función acl_error() se puede utilizar para traducir códigos de error a mensajes de texto.

Además, si el puntero last no es NULL, acl_check() asigna el número de la entrada ACL en la que se detectó el error al valor apuntado por last. Las entradas se numeran a partir de cero, en el orden en que serían devueltas por la función acl_get_entry().

VALOR DE RETORNO

Si tiene éxito, la función acl_check() devuelve 0 si la ACL a la que se refiere acl es válida, y un código de error positivo si la ACL es inválida. De lo contrario, se devuelve un valor de -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurren alguna de las siguientes condiciones, la función acl_check() devuelve -1 y establece errno al valor correspondiente:

[EINVAL]
El argumento acl no es un puntero válido a una ACL.

ESTÁNDARES

Esta es una extensión no portátil y específica de Linux a las funciones de manipulación de ACL definidas en el borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado).

VER TAMBIÉN

acl_valid(3), acl(5)
