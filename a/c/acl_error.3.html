acl_error(3)

Paquete: acl

Licencias: LGPL

ACL_CHECK(3) Manual de funciones de biblioteca ACL_CHECK(3)

NOMBRE

acl_error — convierte un código de error de ACL a un mensaje de texto

BIBLIOTECA

Biblioteca de Listas de Control de Acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <acl/libacl.h>

const char *
acl_error(int code);

DESCRIPCIÓN

La función acl_error() convierte un código de error de ACL, como el devuelto por la función acl_check(), a un mensaje de texto que describe la condición de error. En la configuración regional "POSIX", acl_check() devuelve las siguientes descripciones para los códigos de error.

ACL_MULTI_ERROR
«Múltiples entradas»
ACL_DUPLICATE_ERROR
«Entradas duplicadas»
ACL_MISS_ERROR
«Entrada faltante o incorrecta»
ACL_ENTRY_ERROR
«Tipo de entrada inválido»

VALOR DE RETORNO

La función acl_error() devuelve un mensaje de texto si el código de error es reconocido, y un valor de (const char *)NULL en caso contrario.

ESTÁNDARES

Esta es una extensión no portable y específica de Linux a las funciones de manipulación de ACL definidas en el borrador 17 de IEEE Std 1003.1e («POSIX.1e», abandonado).

VER TAMBIÉN

acl_check(3), acl_valid(3), acl(5)
