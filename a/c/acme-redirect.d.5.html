NOMBRE

acme-redirect.d - configuración de certificados de acme-redirect

SINOPSIS

/etc/acme-redirect.d/*.conf

DESCRIPCIÓN

Estos archivos configuran los certificados que deben ser solicitados y renovados por acme-redirect.

OPCIONES

nombre=

El nombre para identificar este certificado. El certificado no será válido para este nombre a menos que también esté listado en nombres_dns.

nombres_dns=

La lista de nombres para los que este certificado debe ser válido.

ejecutar=

La lista de comandos que deben ser ejecutados. Puedes usar esto para activar la recarga de certificados.

EJEMPLO

[certificado]
nombre = "ejemplo.com"
nombres_dns = [
    "ejemplo.com",
    "www.ejemplo.com",
]
ejecutar = [
    "systemctl reload nginx",
]

VER TAMBIÉN

acme-redirect(1), acme-redirect.conf(5).
