acl_free(3)

Licencias: LGPL

ACL_FREE(3) Manual de funciones de biblioteca ACL_FREE(3)

NOMBRE

acl_free — liberar memoria asignada a un objeto de datos ACL

BIBLIOTECA

Biblioteca de listas de control de acceso de Linux (libacl, -lacl).

SINOPSIS

#include <sys/types.h>
#include <sys/acl.h>

int
acl_free(void *obj_p);

DESCRIPCIÓN

La función acl_free() libera cualquier memoria liberable actualmente asignada al objeto de datos ACL identificado por obj_p. El argumento obj_p puede identificar una ACL, un calificador de entrada ACL o un puntero a una cadena asignada por la función acl_to_text().

VALOR DE RETORNO

La función acl_free() devuelve el valor 0 si tiene éxito; de lo contrario, se devuelve el valor -1 y la variable global errno se establece para indicar el error.

ERRORES

Si ocurre alguna de las siguientes condiciones, la función acl_free() devuelve el valor -1 y establece errno al valor correspondiente:

[EINVAL]
El valor del argumento obj_p es inválido.

ESTÁNDARES

Borrador 17 de IEEE Std 1003.1e (“POSIX.1e”, abandonado)
