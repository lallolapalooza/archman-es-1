NOMBRE

awesomerc - Archivo de configuración para el gestor de ventanas awesome

SINOPSIS

awesome busca un archivo de configuración en este orden:

•$XDG_CONFIG_HOME/awesome/rc.lua
•$HOME/.config/awesome/rc.lua
•$XDG_CONFIG_DIRS/awesome/rc.lua

DESCRIPCIÓN

El archivo rc.lua contiene información de configuración para awesome. Se puede usar para configurar el comportamiento y la apariencia de awesome de diversas maneras. Puede ser asimilado como un programa/script Lua ejecutado al inicio por awesome. Por lo tanto, debe usar la API Lua de awesome descrita en la sección de API. Este archivo se lee al inicio.

API LUA DE AWESOME

La documentación para la API Lua se puede encontrar en el directorio luadoc.

FORMATO DE COLORES

El formato de color en awesome es un nombre de color estándar de X (blue, darkblue, lightred, etc.) o un color formateado hexadecimal (#rrggbb o #rrggbbaa). Al usar el formato hexadecimal, también puedes especificar un canal alfa: esto significa que #00ff00 dibujará verde puro, pero #00ff00aa establecerá el canal alfa en 'aa' y mezclará el verde con el color debajo de él.

FORMATO DE TEXTO

Puedes usar marcado Pango en una cadena de texto. Esto permite formatear el texto renderizado dentro de los widgets. La documentación de marcado Pango se puede encontrar en la documentación de Pango en http://library.gnome.org/devel/pango/stable/PangoMarkupFormat.html.

Un ejemplo de marcado Pango: <span weight="bold" foreground="#336699">...</span>.
