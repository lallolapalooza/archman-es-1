NOMBRE

awesome-client - ejecución remota del gestor de ventanas awesome

SINOPSIS

awesome-client [-h|--help] [comando [comando...]]

DESCRIPCIÓN

awesome-client es una interfaz de línea de comandos remota para awesome. Se comunica con awesome a través de D-Bus, permitiendo la ejecución remota de código Lua.

USO

awesome-client lee los comandos pasados en la línea de comandos o desde la entrada estándar y los envía a través de D-Bus a awesome. Si rlwrap está instalado, se utilizará para proporcionar una interfaz de línea de comandos readline.

El módulo awful.remote debe cargarse si desea que este comando funcione.

EJEMPLOS

$ awesome-client 'return 1+1, "Hola, mundo"\
   double 2
   string "Hola, mundo"
# Lo siguiente no devuelve nada en la línea de comandos,
# pero mostrará una notificación.
$ awesome-client '
> naughty = require("naughty")
> naughty.notify({
> title="Notificación CLI",
> text="¡Esta es una notificación enviada desde la línea de comandos!"})
> '
# Entrando en modo read-eval-print-loop
# Este modo enviará cada línea a awesome, exactamente igual que pasando
# múltiples comandos en la línea de comandos.
$ awesome-client
awesome# return 1+1
   double 2
awesome# return 1+1, "Hola, mundo"
   double 2
   string "Hola, mundo"
awesome#
