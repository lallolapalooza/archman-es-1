aio_init(3) Manual de funciones de biblioteca aio_init(3)

NOMBRE

aio_init - inicialización de E/S asíncrona

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <aio.h>
void aio_init(const struct aioinit *init);

DESCRIPCIÓN

La función aio_init(), específica de GNU, permite al llamante proporcionar sugerencias de ajuste a la implementación AIO de POSIX de glibc. El uso de esta función es opcional, pero para que sea efectiva, debe llamarse antes de emplear cualquier otra función de la API AIO de POSIX.

La información de ajuste se proporciona en el búfer apuntado por el argumento init. Este búfer es una estructura del siguiente formato:


struct aioinit {
    int aio_threads;    /* Número máximo de hilos */
    int aio_num;        /* Número de solicitudes simultáneas
                           esperadas */
    int aio_locks;      /* No utilizado */
    int aio_usedba;     /* No utilizado */
    int aio_debug;      /* No utilizado */
    int aio_numusers;   /* No utilizado */
    int aio_idle_time;  /* Número de segundos antes de que un hilo inactivo
                           termine (desde glibc 2.2) */
    int aio_reserved;
};

Los siguientes campos se utilizan en la estructura aioinit:

aio_threads
Este campo especifica el número máximo de hilos trabajadores que puede utilizar la implementación. Si el número de operaciones de E/S pendientes supera este límite, las operaciones excedentes se pondrán en cola hasta que un hilo trabajador quede libre. Si este campo se especifica con un valor menor que 1, se utiliza el valor 1. El valor predeterminado es 20.
aio_num
Este campo debe especificar el número máximo de solicitudes de E/S simultáneas que el llamante espera encolar. Si se especifica un valor menor que 32 para este campo, se redondea hacia arriba a 32. El valor predeterminado es 64.
aio_idle_time
Este campo especifica el tiempo en segundos que un hilo trabajador debe esperar más solicitudes antes de terminar, después de haber completado una solicitud anterior. El valor predeterminado es 1.

ESTÁNDARES

GNU.

HISTORIA
