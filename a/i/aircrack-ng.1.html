AIRCRACK-NG(1) Manual de Comandos Generales AIRCRACK-NG(1)

NOMBRE

aircrack-ng - cracker de claves WEP / WPA-PSK 802.11

SINOPSIS

aircrack-ng [opciones] <archivo(s) de entrada>

DESCRIPCIÓN

aircrack-ng es un programa para descifrar claves WEP 802.11, WPA/WPA2 802.11i y WPA3 802.11w.

Puede recuperar la clave WEP una vez que se han capturado suficientes paquetes cifrados con airodump-ng. Esta parte de la suite aircrack-ng determina la clave WEP utilizando dos métodos fundamentales. El primer método es el enfoque PTW (Pyshkin, Tews, Weinmann). La principal ventaja del enfoque PTW es que se requieren muy pocos paquetes de datos para descifrar la clave WEP. El segundo método es el método FMS/KoreK. El método FMS/KoreK incorpora varios ataques estadísticos para descubrir la clave WEP y los utiliza en combinación con fuerza bruta.

Adicionalmente, el programa ofrece un método de diccionario para determinar la clave WEP. Para descifrar claves pre-compartidas WPA/WPA2, se debe utilizar una lista de palabras (archivo o stdin) o un airolib-ng.

ARCHIVOS DE ENTRADA

Archivos de captura (.cap, .pcap), IVS (.ivs) o archivos HCCAPX de Hashcat (.hccapx)

OPCIONES

Opciones comunes:
-a <modo>
Forzar el modo de ataque: 1 o wep para WEP (802.11) y 2 o wpa para WPA/WPA2 PSK (802.11i y 802.11w).
-e <essid>
Seleccionar la red objetivo basada en el ESSID. Esta opción también es necesaria para el descifrado WPA si el SSID está oculto. Para SSIDs que contienen caracteres especiales, ver https://www.aircrack-ng.org/doku.php?id=faq#how_to_use_spaces_double_quote_and_single_quote_etc_in_ap_names
-b <bssid> o --bssid <bssid>
Seleccionar la red objetivo basada en la dirección MAC del punto de acceso.
-p <numcpu>
Establecer esta opción al número de CPUs a usar (solo disponible en sistemas SMP) para descifrar la clave/frase de paso. Por defecto, usa todas las CPUs disponibles.
-q
Si se establece, no se muestra información de estado.
-C <macs> o --combine <macs>
Fusiona todas las MACs de AP (separadas por coma) en una virtual.
-l <archivo>
Escribir la clave en un archivo. Sobrescribe el archivo si ya existe.
Opciones de descifrado WEP estático:
-c
Buscar solo caracteres alfanuméricos.
-t
Buscar solo caracteres BCD (Binary Coded Decimal).
-h
Buscar la clave numérica para Fritz!BOX.
-d <máscara> o --debug <máscara>
Especificar la máscara de la clave. Por ejemplo: A1:XX:CF.
-m <maddr>
Mantener solo los IVs provenientes de paquetes que coinciden con esta dirección MAC. Alternativamente, usar -m ff:ff:ff:ff:ff:ff para usar todos los IVs, independientemente de la red (esto deshabilita el filtrado de ESSID y BSSID).
-n <numbits>
Especificar la longitud de la clave: 64 para WEP de 40 bits, 128 para WEP de 104 bits, etc., hasta 512 bits de longitud. El valor por defecto es 128.
-i <índice>
Mantener solo los IVs que tienen este índice de clave (1 a 4). El comportamiento por defecto es ignorar el índice de clave en el paquete y usar el IV independientemente.
-f <fudge>
Por defecto, este parámetro se establece en 2. Usar un valor más alto para aumentar el nivel de fuerza bruta: el descifrado llevará más tiempo, pero con una mayor probabilidad de éxito.
-k <korek>
Hay 17 ataques KoreK. A veces, un ataque crea un falso positivo enorme que impide encontrar la clave, incluso con muchos IVs. Prueba -k 1, -k 2, ... -k 17 para deshabilitar cada ataque selectivamente.
-x o -x0
Deshabilitar la fuerza bruta de los últimos bytes de la clave (no recomendado).
-x1
Habilitar fuerza bruta de los últimos bytes de la clave (por defecto).
-x2
Habilitar fuerza bruta de los últimos dos bytes de la clave.
-X
Deshabilitar la multihilo de fuerza bruta (solo SMP).
-s
Muestra la versión ASCII de la clave en el lado derecho de la pantalla.
-y
Este es un ataque experimental de fuerza bruta único que solo debe usarse cuando el modo de ataque estándar falla con más de un millón de IVs.
-z
Utiliza el ataque PTW (Andrei Pyshkin, Erik Tews y Ralf-Philipp Weinmann) (ataque por defecto).
-P <num> o --ptw-debug <num>
Depuración PTW: 1 Deshabilitar klein, 2 PTW.
-K
Usar ataques KoreK en lugar de PTW.
-D o --wep-decloak
Modo WEP decloak.
-1 o --oneshot
Ejecutar solo 1 intento para descifrar la clave con PTW.
-M <num>
Especificar el número máximo de IVs a usar.
-V o --visual-inspection
Ejecutar en modo de inspección visual. Solo se puede usar cuando se utiliza KoreK.
Opciones de descifrado WEP y WPA-PSK
-w <palabras>
Ruta a un archivo de diccionario para descifrado WPA. Separe los nombres de archivo con una coma cuando use múltiples diccionarios. Especifique "-" para usar stdin. Aquí hay una lista de wordlists: https://www.aircrack-ng.org/doku.php?id=faq#where_can_i_find_good_wordlists Para usar un diccionario con valores hexadecimales, prefije el diccionario con "h:". Cada byte en cada clave debe estar separado por ':'. Al usar con WEP, la longitud de la clave debe especificarse usando -n.
-N <archivo> o --new-session <archivo>
Crear una nueva sesión de descifrado. Permite interrumpir una sesión de descifrado y reiniciarla más tarde (usando -R o --restore-session). Los archivos de estado se guardan cada 10 minutos. No sobrescribe el archivo de sesión existente.
-R <archivo> o --restore-session <archivo>
Restaurar y continuar una sesión de descifrado previamente guardada. Este parámetro debe usarse solo, no se deben especificar otros parámetros al iniciar aircrack-ng (toda la información requerida está en el archivo de sesión).
Opciones WPA-PSK:
-E <archivo>
Crear un archivo de proyecto Elcomsoft Wireless Security Auditor (EWSA) v3.02.
-j <archivo>
Crear un archivo de captura Hashcat v3.6+ (HCCAPX).
-J <archivo>
Crear un archivo de captura Hashcat (HCCAP).
-S
Prueba de velocidad de descifrado WPA.
-Z <segundos>
Duración de la ejecución de la prueba de velocidad de descifrado WPA en segundos.
-r <base_de_datos>
Ruta a la base de datos de airolib-ng. No se puede usar con '-w'.
