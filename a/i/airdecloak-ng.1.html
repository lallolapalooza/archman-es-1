AIRDECLOAK-NG(1) Manual de comandos generales AIRDECLOAK-NG(1)

NOMBRE

airuncloak-ng - Elimina tramas wep enmascaradas de un archivo pcap.

SINOPSIS

airuncloak-ng <opciones>

DESCRIPCIÓN

airuncloak-ng es una herramienta que elimina el enmascaramiento WEP de un archivo pcap. Algunos IPS (en realidad uno) pueden "prevenir" activamente el descifrado de una clave WEP insertando señuelos (tramas wep falsas) en el aire para engañar a aircrack-ng. En algunos casos raros, el enmascaramiento falla y la clave se puede recuperar sin eliminar estos señuelos. En los casos en que la clave no se pueda recuperar, utilice esta herramienta para filtrar los señuelos.

El programa funciona leyendo el archivo de entrada y seleccionando tramas de una red específica. Cada trama seleccionada se coloca en una lista y se clasifica (el estado predeterminado es "desconocido"). Luego se aplican filtros (en el orden especificado por el usuario) a esta lista. Cambiarán el estado de las tramas (desconocido, desenmascarado, potencialmente enmascarado o enmascarado). El orden de los filtros es realmente importante, ya que cada filtro basará su análisis, entre otras cosas, en el estado de las tramas y diferentes órdenes darán resultados diferentes.

Requisito importante: el archivo pcap necesita tener todas las tramas (incluyendo beacons y todas las demás tramas "inútiles") para el análisis (y si es posible, cabeceras prism/radiotap).

OPCIONES

-h, --help
Muestra la pantalla de ayuda.
-i <archivo>
Ruta al archivo de captura.
--ssid <ESSID>
ESSID de la red (aún no implementado) para filtrar.
--bssid <BSSID>
BSSID de la red para filtrar.
--null-packets
Asume que las tramas nulas pueden estar enmascaradas.
--disable-base-filter
No aplicar el filtro base.
--drop-frag
Eliminar tramas fragmentadas.
--filters <filtros>
Aplicar diferentes filtros (separados por comas). Ver abajo.

FILTROS

signal
Intenta filtrar basándose en la señal (cabeceras prism o radiotap en el archivo pcap).
duplicate_sn
Elimina todos los números de secuencia duplicados tanto para el AP como para el cliente (que estén cerca entre sí).
duplicate_sn_ap
Elimina los números de secuencia duplicados solo para el AP (que estén cerca entre sí).
duplicate_sn_client
Elimina los números de secuencia duplicados solo para el cliente (que estén cerca entre sí).
consecutive_sn
Filtra basándose en el hecho de que las IV deberían ser consecutivas (solo para AP).
duplicate_iv
Filtra todas las IV duplicadas.
signal_dup_consec_sn
Utiliza la señal (si está disponible), números de secuencia duplicados y consecutivos (el filtrado es mucho más preciso que usar todos estos filtros uno por uno).
