aio_error(3) Manual de funciones de biblioteca aio_error(3)

NOMBRE

aio_error - obtener el estado de error de una operación de E/S asíncrona

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <aio.h>
int aio_error(const struct aiocb *aiocbp);

DESCRIPCIÓN

La función aio_error() devuelve el estado de error de la solicitud de E/S asíncrona con el bloque de control apuntado por aiocbp. (Ver aio(7) para una descripción de la estructura aiocb.)

VALOR DE RETORNO

Esta función devuelve uno de los siguientes:

EINPROGRESS
si la solicitud aún no se ha completado.
ECANCELED
si la solicitud fue cancelada.
0
si la solicitud se completó con éxito.
> 0
Un número de error positivo, si la operación de E/S asíncrona falló. Este es el mismo valor que se habría almacenado en la variable errno en caso de una llamada síncrona a read(2), write(2), fsync(2), o fdatasync(2).

ERRORES

EINVAL
aiocbp no apunta a un bloque de control de una solicitud de E/S asíncrona cuyo estado de retorno (ver aio_return(3)) aún no se haya recuperado.
ENOSYS
aio_error() no está implementado.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor

HISTORIA
