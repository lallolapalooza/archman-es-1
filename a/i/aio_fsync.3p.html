DESCRIPCIÓ

N

La función aio_fsync() realizará de forma asíncrona una operación de sincronización de archivos, como se especifica por el argumento op, para las operaciones de E/S asociadas con el archivo indicado por el descriptor de archivo miembro aio_fildes de la estructura aiocb referenciada por el argumento aiocbp y encoladas en el momento de la llamada a aio_fsync(). La llamada a la función retornará cuando la solicitud de sincronización haya sido iniciada o encolada en el archivo o dispositivo (incluso cuando los datos no puedan sincronizarse inmediatamente)

.

Si op es O_DSYNC, todas las operaciones de E/S actualmente encoladas deberán completarse como si se llamara a fdatasync(); es decir, como está definido para la finalización de integridad de datos de E/S

sincronizada.

Si op es O_SYNC, todas las operaciones de E/S actualmente encoladas deberán completarse como si se llamara a fsync(); es decir, como está definido para la finalización de integridad de archivos de E/S sincronizada. Si la función aio_fsync() falla, o si la operación encolada por aio_fsync() falla, entonces no se garantiza que las operaciones de E/S pendientes se hayan

completado.

Si aio_fsync() tiene éxito, entonces solo se garantiza que la E/S que fue encolada en el momento de la llamada a aio_fsync() sea forzada al estado de finalización relevante. No se garantiza que la finalización de la E/S posterior en el descriptor de archivo se complete de manera

sincronizada.

El argumento aiocbp se refiere a un bloque de control de E/S asíncrona. El valor aiocbp puede usarse como argumento para aio_error() y aio_return() con el fin de determinar el estado de error y el estado de retorno, respectivamente, de la operación asíncrona mientras se está llevando a cabo. Cuando la solicitud está encolada, el estado de error para la operación es [EINPROGRESS]. Cuando todos los datos se hayan transferido con éxito, el estado de error se restablecerá para reflejar el éxito o el fallo de la operación. Si la operación no se completa con éxito, el estado de error para la operación se establecerá para indicar el error. El miembro aio_sigevent determina la notificación asíncrona a ocurrir como se especifica en Sección 2.4.1, Generación y Entrega de Señales cuando todas las operaciones hayan alcanzado la finalización de E/S sincronizada. Todos los demás miembros de la estructura referenciada por aiocbp se ignoran. Si el bloque de control referenciado por aiocbp se convierte en una dirección ilegal antes de la finalización de la E/S asíncrona, entonces el comportamiento es

indefinido.

Si la función aio_fsync() falla o aiocbp indica una condición de error, no se garant

iza que los datos se hayan
transferido con éxito.
