AIO_CANCEL(3P) Manual del Programador POSIX AIO_CANCEL(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación en Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

aio_cancel — cancelar una solicitud de E/S asíncrona

SINOPSIS

#include <aio.h>
int aio_cancel(int fildes, struct aiocb *aiocbp);

DESCRIPCIÓN

La función aio_cancel() intentará cancelar una o más solicitudes de E/S asíncronas actualmente pendientes para el descriptor de archivo fildes. El argumento aiocbp apunta al bloque de control de E/S asíncrona para una solicitud particular a cancelar. Si aiocbp es NULL, entonces todas las solicitudes de E/S asíncronas cancelables pendientes para fildes serán canceladas.

Se producirá una notificación asíncrona normal para las operaciones de E/S asíncronas que se cancelen correctamente. Si hay solicitudes que no pueden ser canceladas, entonces el proceso de finalización asíncrona normal se llevará a cabo para esas solicitudes cuando se completen.

Para las operaciones solicitadas que se cancelen correctamente, el estado de error asociado se establecerá en [ECANCELED] y el estado de retorno será -1. Para las operaciones solicitadas que no se cancelen correctamente, aio_cancel() no modificará aiocbp.

Si aiocbp no es NULL, entonces si fildes no tiene el mismo valor que el descriptor de archivo con el que se inició la operación asíncrona, se producirán resultados no especificados.

Qué operaciones son cancelables está definido por la implementación.

VALOR DE RETORNO

La función aio_cancel() devolverá el valor AIO_CANCELED si la(s) operación(es) solicitada(s) fueron canceladas. El valor AIO_NOTCANCELED se devolverá si al menos una de las operaciones solicitadas no puede ser cancelada porque está en progreso. En este caso, el estado de las otras operaciones, si las hubiera, referenciadas en la llamada a aio_cancel() no se indica mediante el valor de retorno de aio_cancel(). La aplicación puede determinar el estado de las cosas para estas operaciones utilizando aio_error(). El valor AIO_ALLDONE se devuelve si todas las operaciones ya han completado. De lo contrario, la función devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función aio_cancel() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo válido.
