aio_return(3) Manual de Funciones de Biblioteca aio_return(3)

NOMBRE

aio_return - obtener el estado de retorno de una operación de I/O asíncrona

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <aio.h>
ssize_t aio_return(struct aiocb *aiocbp);

DESCRIPCIÓN

La función aio_return() devuelve el estado de retorno final para la solicitud de I/O asíncrona con el bloque de control apuntado por aiocbp. (Ver aio(7) para una descripción de la estructura aiocb.)

Esta función solo debe llamarse una vez para cualquier solicitud dada, después de que aio_error(3) devuelva algo distinto de EINPROGRESS.

VALOR DE RETORNO

Si la operación de I/O asíncrona ha completado, esta función devuelve el valor que se habría devuelto en caso de una llamada read(2), write(2), fsync(2), o fdatasync(2) síncrona. En caso de error, se devuelve -1 y se establece errno para indicar el error.

Si la operación de I/O asíncrona aún no ha completado, el valor de retorno y el efecto de aio_return() no están definidos.

ERRORES

EINVAL
aiocbp no apunta a un bloque de control para una solicitud de I/O asíncrona cuyo estado de retorno aún no se ha recuperado.
ENOSYS
aio_return() no está implementado.
