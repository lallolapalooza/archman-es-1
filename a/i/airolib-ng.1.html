AIROLIB-NG(1) Manual de comandos generales AIROLIB-NG(1)

NOMBRE

airolib-ng - administra y crea tablas de hashes precalculadas de WPA/WPA2

SINOPSIS

airolib-ng <base de datos> <operación> [opciones]

DESCRIPCIÓN

airolib-ng es una herramienta para el conjunto de herramientas aircrack-ng que permite almacenar y administrar listas de ESSID y contraseñas, calcular sus claves maestras de emparejamiento (PMK) y utilizarlas en la ruptura de WPA/WPA2. El programa utiliza la base de datos liviana SQLite3 como mecanismo de almacenamiento, la cual está disponible en la mayoría de las plataformas. La base de datos SQLite3 fue seleccionada teniendo en cuenta la disponibilidad de la plataforma, la gestión, la memoria y la sobrecarga de disco.

BASE DE DATOS

base de datos
Es el nombre del archivo de la base de datos. Opcionalmente, puede especificar la ruta completa.

OPERACIÓN

--stats
Muestra información sobre la base de datos.
--sql <sql>
Ejecuta la sentencia SQL especificada.
--clean [all]
Limpia la base de datos de datos antiguos innecesarios. Al especificar 'all', también reducirá el tamaño del archivo si es posible y ejecutará una comprobación de integridad.
--batch
Inicia/Reinicia el procesamiento por lotes de todas las combinaciones de ESSID y contraseñas. Para pausar, presione Ctrl-C.
--verify [all]
Verifica un conjunto de PMKs elegidos aleatoriamente. Si se proporciona 'all', se eliminarán todos los PMK inválidos en la base de datos.
--import [essid|passwd] <archivo>
Importa un archivo plano como una lista de ESSID o contraseñas.
import cowpatty <archivo>
Importa un archivo de coWPAtty.
--export cowpatty <essid> <archivo>
Exporta a un archivo de coWPAtty.
