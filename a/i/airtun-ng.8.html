AIRTUN-NG(8) Manual del administrador del sistema AIRTUN-NG(8)

NOMBRE

airtun-ng - creador de interfaces de túnel virtual para aircrack-ng

SINOPSIS

airtun-ng [opciones] <nombre de la interfaz>

DESCRIPCIÓN

airtun-ng crea una interfaz de túnel virtual (atX) para enviar paquetes IP arbitrarios mediante la inyección de paquetes ieee802.11 sin procesar.

OPCIONES

-H, --help
Muestra la pantalla de ayuda.
-x <pps>
Establece el número máximo de paquetes por segundo.
-a <BSSID>
Especifica el BSSID para la cabecera ieee802.11. En modo WDS, esto establece el receptor.
-h <SMAC>
Especifica la MAC de origen para la cabecera ieee802.11.
-i <interfaz>
Establece la interfaz de captura.
-r <archivo>
Especifica un archivo para leer tramas 802.11.
-y <archivo-PRGA>
Es el nombre del archivo que proporciona la secuencia de claves para la codificación WEP. (Sin recepción, solo transmisión de paquetes IP).
-w <clave-WEP>
Esta es la clave WEP para cifrar/descifrar todo el tráfico que pasa por el túnel.
-e <ESSID>
Establece el SSID de la red de destino (usar con -p).
-p <frase-contraseña>
Usa esta frase de contraseña WPA para descifrar paquetes (usar con -a y -e).
-t <tods>
Define el bit ToDS y FromDS en la cabecera ieee802.11. Para tods=1, el bit ToDS se establece en 1 y FromDS en 0, mientras que tods=0 los establece en la dirección opuesta. Si se establece en 2, se encapsulará en un túnel WDS/bridge.
-m <máscara-red>, --máscara-red <máscara-red>
Filtra redes basándose en la combinación BSSID ^ máscara de red. Necesita -d, usado en modo de repetición.
-d <BSSID>, --bssid <BSSID>
Filtra redes basándose en el <BSSID>. Usado en modo de repetición.
-f, --repeat
Habilita el modo de repetición. Se repetirán todas las tramas leídas, filtradas por BSSID y máscara de red (si se especifican).
-s <transmisor>
Establece la dirección MAC del transmisor para el modo WDS.
-b
Modo bidireccional. Esto habilita la comunicación en las redes del Transmisor Y del Receptor. Solo funciona si puedes ver ambas estaciones.

EJEMPLOS

airtun-ng -a 00:14:22:56:F3:4E -t 0 -y keystream.xor wlan0
