AIO_SUSPEND(3P) Manual del Programador POSIX AIO_SUSPEND(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

aio_suspend — esperar una solicitud de E/S asíncrona

SINAPSIS

#include <aio.h>
int aio_suspend(const struct aiocb *const list[], int nent,
    const struct timespec *timeout);

DESCRIPCIÓN

La función aio_suspend() suspenderá el hilo de llamada hasta que al menos una de las operaciones de E/S asíncrona referenciadas por el argumento list haya completado, hasta que una señal interrumpa la función o, si timeout no es NULL, hasta que haya transcurrido el intervalo de tiempo especificado por timeout. Si alguna de las estructuras aiocb de la lista corresponde a operaciones de E/S asíncrona completadas (es decir, el estado de error de la operación no es igual a [EINPROGRESS]) en el momento de la llamada, la función retornará sin suspender el hilo de llamada. El argumento list es una matriz de punteros a bloques de control de E/S asíncrona. El argumento nent indica el número de elementos en la matriz. Cada estructura aiocb apuntada ha sido utilizada para iniciar una solicitud de E/S asíncrona a través de aio_read(), aio_write() o lio_listio(). Esta matriz puede contener punteros nulos, que se ignoran. Si esta matriz contiene punteros que se refieren a estructuras aiocb que no se han utilizado para enviar E/S asíncronas, el efecto es indefinido.

Si el intervalo de tiempo indicado en la estructura timespec apuntada por timeout transcurre antes de que se completen las operaciones de E/S referenciadas por list, entonces aio_suspend() retornará con un error. Si se admite la opción de Reloj Monotónico, el reloj que se utilizará para medir este intervalo de tiempo será el reloj CLOCK_MONOTONIC.

VALOR DE RETORNO

Si la función aio_suspend() retorna después de que una o más operaciones de E/S asíncronas se hayan completado, la función retornará cero. De lo contrario, la función retornará un valor de -1 y establecerá errno para indicar el error.

La aplicación puede determinar qué E/S asíncrona se completó escaneando el estado de error y retorno asociado utilizando aio_error() y aio_return(), respectivamente.

ERRORES

La función aio_suspend() fallará si:

EAGAIN
Ninguna E/S asíncrona indicada en la lista referenciada por list se completó en el intervalo de tiempo indicado por timeout.
EINTR
Una señal interrumpió la función aio_suspend(). Tenga en cuenta que, dado que cada operación de E/S asíncrona puede provocar una señal cuando se completa, este retorno de error puede ser causado por la finalización de una (o más) de las operaciones de E/S que se están esperando.
