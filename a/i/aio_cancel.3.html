aio_cancel(3) Manual de funciones de biblioteca aio_cancel(3)

NOMBRE

aio_cancel - cancelar una solicitud de E/S asíncrona pendiente

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <aio.h>
int aio_cancel(int fd, struct aiocb *aiocbp);

DESCRIPCIÓN

La función aio_cancel() intenta cancelar las solicitudes de E/S asíncronas pendientes para el descriptor de archivo fd. Si aiocbp es NULL, se cancelan todas las solicitudes. De lo contrario, solo se cancela la solicitud descrita por el bloque de control apuntado por aiocbp. (Consulte aio(7) para ver una descripción de la estructura aiocb).

Se produce la notificación asíncrona normal para las solicitudes canceladas (consulte aio(7) y sigevent(3type)). El estado de retorno de la solicitud (aio_return(3)) se establece en -1, y el estado de error de la solicitud (aio_error(3)) se establece en ECANCELED. El bloque de control de las solicitudes que no se pueden cancelar no se modifica.

Si la solicitud no se pudo cancelar, finalizará de la forma habitual después de realizar la operación de E/S. (En este caso, aio_error(3) devolverá el estado EINPROGRESS).

Si aiocbp no es NULL, y fd es diferente del descriptor de archivo con el que se inició la operación asíncrona, se producen resultados indefinidos.

Qué operaciones son cancelables depende de la implementación.

VALOR DE RETORNO

La función aio_cancel() devuelve uno de los siguientes valores:

AIO_CANCELED
Todas las solicitudes se cancelaron correctamente.
AIO_NOTCANCELED
Al menos una de las solicitudes especificadas no se canceló porque estaba en progreso. En este caso, se puede verificar el estado de las solicitudes individuales usando aio_error(3).
AIO_ALLDONE
Todas las solicitudes ya se habían completado antes de la llamada.
-1
Ocurrió un error. El error se puede encontrar inspeccionando errno.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
ENOSYS
aio_cancel() no está implementado.
