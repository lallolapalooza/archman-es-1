PROLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

aio_return — recuperar el estado de retorno de una operación de E/S asíncrona

SINTAXIS

#include <aio.h>
ssize_t aio_return(struct aiocb *aiocbp);

DESCRIPCIÓN

La función aio_return() devolverá el estado de retorno asociado con la estructura aiocb a la que se refiere el argumento aiocbp. El estado de retorno para una operación de E/S asíncrona es el valor que devolvería la llamada correspondiente a la función read(), write() o fsync(). Si el estado de error de la operación es igual a [EINPROGRESS], entonces el estado de retorno de la operación no está definido. La función aio_return() solo puede llamarse una vez para recuperar el estado de retorno de una operación asíncrona dada; a partir de entonces, si la misma estructura aiocb se utiliza en una llamada a aio_return() o aio_error(), se puede devolver un error. Cuando la estructura aiocb a la que se refiere aiocbp se utiliza para enviar otra operación asíncrona, entonces aio_return() puede usarse exitosamente para recuperar el estado de retorno de esa operación.

VALOR DE RETORNO

Si la operación de E/S asíncrona se ha completado, se devolverá el estado de retorno, tal como se describe para read(), write() y fsync(). Si la operación de E/S asíncrona aún no se ha completado, los resultados de aio_return() no están definidos.

Si la función aio_return() falla, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función aio_return() puede fallar si:

EINVAL
El argumento aiocbp no se refiere a una operación asíncrona cuyo estado de retorno aún no se haya recuperado.
