AIRMON-NG(8) Manual del Administrador del Sistema AIRMON-NG(8)

NOMBRE

airmon-ng - Script sh POSIX diseñado para poner las tarjetas inalámbricas en modo monitor.

SINOPSIS

airmon-ng <start|stop> <interfaz> [canal] airmon-ng <check> [kill]

DESCRIPCIÓN

airmon-ng Este script se puede usar para habilitar el modo monitor en interfaces inalámbricas. También se puede usar para volver del modo monitor al modo gestionado. Introducir el comando airmon-ng sin parámetros mostrará el estado de las interfaces. También puede listar/matar programas que puedan interferir con el funcionamiento de la tarjeta inalámbrica.

PARÁMETROS OPCIONALES

start <interfaz> [canal]
Habilita el modo monitor en una interfaz (y especifica un canal). Nota: Madwifi-ng es un caso especial, 'start' debe usarse en interfaces wifi y 'stop' en interfaces ath.
start <interfaz> [frecuencia]
Habilita el modo monitor en una interfaz (y especifica una frecuencia en MHz). Nota: Madwifi-ng es un caso especial, 'start' debe usarse en interfaces wifi y 'stop' en interfaces ath.
stop <interfaz>
Deshabilita el modo monitor y vuelve al modo gestionado (excepto para madwifi-ng donde mata el VAP de ath).
check [kill]
Lista todos los programas posibles que podrían interferir con la tarjeta inalámbrica. Si se especifica 'kill', intentará matarlos a todos.
--verbose
Esta bandera debe preceder a start/stop/check y puede combinarse con otros parámetros o usarse sola. Esta bandera aumentará la verbosidad para proporcionar información útil adicional que puede no ser necesaria para la operación normal.
--debug
Esta bandera debe preceder a start/stop/check y puede combinarse con otros parámetros o usarse sola. Esta bandera aumentará la verbosidad a nivel de depuración para ayudar a solucionar errores en airmon-ng. Use esta bandera al abrir un error, pero solo use --verbose al solicitar soporte en IRC.
--elite
ADVERTENCIA: NO USAR: Esta bandera debe preceder a start o stop y evitará que airmon-ng elimine interfaces. ADVERTENCIA: El uso de esta bandera descalificará inmediatamente la recepción de cualquier soporte del equipo de aircrack-ng, debido al hecho de que se sabe que este comportamiento está roto. ¡ADVERTENCIA!
