A64L(3P) Manual del programador POSIX A64L(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

a64l, l64a — convertir entre un entero de 32 bits y una cadena ASCII de base 64

SINOPSIS

#include <stdlib.h>
long a64l(const char *s);
char *l64a(long value);

DESCRIPCIÓN

Estas funciones mantienen números almacenados en caracteres ASCII de base 64. Esta es una notación mediante la cual los enteros de 32 bits pueden representarse mediante hasta seis caracteres; cada carácter representa un dígito en notación de base 64. Si el tipo long contiene más de 32 bits, solo se utilizarán los 32 bits de orden inferior para estas operaciones.

Los caracteres utilizados para representar los dígitos son '.' (punto) para 0, '/' para 1, '0' a '9' para [2,11], 'A' a 'Z' para [12,37] y 'a' a 'z' para [38,63].

La función a64l() tomará un puntero a una representación de base 64, en la que el primer dígito es el menos significativo, y devolverá el valor long correspondiente. Si la cadena apuntada por s contiene más de seis caracteres, a64l() usará los primeros seis. Si los primeros seis caracteres de la cadena contienen un terminador nulo, a64l() usará solo los caracteres anteriores al terminador nulo. La función a64l() escaneará la cadena de caracteres de izquierda a derecha con el dígito menos significativo a la izquierda, decodificando cada carácter como un número de base 64 de 6 bits. Si el tipo long contiene más de 32 bits, el valor resultante se extenderá con signo. El comportamiento de a64l() no está especificado si s es un puntero nulo o si la cadena apuntada por s no fue generada por una llamada anterior a l64a().

La función l64a() tomará un argumento long y devolverá un puntero a la representación de base 64 correspondiente. El comportamiento de l64a() no está especificado si value es negativo.

El valor devuelto por l64a() puede ser un puntero dentro de un búfer estático. Las llamadas posteriores a l64a() pueden sobrescribir el búfer.

l64a() no necesita ser seguro para hilos.

VALOR DE RETORNO

Tras completarse con éxito, a64l() devolverá el valor long resultante de la conversión de la cadena de entrada. Si una cadena apuntada por s está vacía, a64l() devolverá 0L.

La función l64a() devolverá un puntero a la representación de base 64. Si value es 0L, l64a() devolverá un puntero a una cadena vacía.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

Si el tipo long contiene más de 32 bits, el resultado de a64l(l64a(x)) es x en los 32 bits de orden inferior.

JUSTIFICACIÓN
