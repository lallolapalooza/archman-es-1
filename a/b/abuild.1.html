abuild(1) Manual de Comandos Generales abuild(1)

NOMBRE

abuild - construye un apk a partir de un APKBUILD

SINOPSIS

abuild [opciones] [-C DIR] [-P REPODEST] [-s SRCDEST] [-D DESCRIPCIÓN] [cmd] ...

DESCRIPCIÓN

abuild construye un paquete binario apk basado en un APKBUILD(5) de entrada, así como otras operaciones relacionadas.

OPCIONES

-A

Imprime CARCH y sale

-c

Habilita la salida con colores

-C DIR

Cambia al directorio DIR antes de ejecutar cualquier comando

-d

Deshabilita la comprobación de dependencias

-D DESCRIPCIÓN

Establece la descripción de APKINDEX (por defecto: $repo $(git describe))

-f

Fuerza el cmd especificado (omite comprobaciones: apk actualizado, arquitectura)

-F

Fuerza la ejecución como root

-h

Muestra esta ayuda

-k

Conserva los paquetes construidos, incluso si APKBUILD o las fuentes son más recientes

-K

Conserva los directorios y archivos temporales de compilación (srcdir/pkgdir/deps)

-m

Deshabilita los colores (monocromo)

-P REPODEST

Establece REPODEST como la ubicación del repositorio para los paquetes creados

-q

Silencioso

-r

Instala las dependencias faltantes desde el repositorio del sistema

-s SRCDEST

Establece el directorio de destino del paquete fuente en SRCDEST

-v

Detallado: muestra cada comando a medida que se ejecuta (muy ruidoso)

COMANDOS

all

Ejecuta todo el proceso de compilación. Es el valor por defecto cuando no se especifica otro comando, y es aproximadamente un alias de validate builddeps clean fetch unpack prepare mkusers build check rootpkg.

build

Compila e instala el paquete en $pkgdir.

check

Ejecuta cualquier prueba definida sobre el paquete

checksum

Genera el checksum para incluir en el APKBUILD

clean

Elimina los directorios temporales de compilación e instalación

cleancache

Elimina los archivos descargados de $SRCDEST

cleanoldpkg

Elimina los paquetes binarios excepto la versión actual

cleanpkg

Elimina el paquete binario y el paquete fuente ya construidos

deps

Instala los paquetes listados en makedepends y depends

fetch

Obtiene las fuentes a $SRCDEST

index

Regenera los índices en $REPODEST

listpkg

Lista los paquetes objetivo

package

Instala el proyecto en

prepare

Aplica los parches

rootbld

Construye el paquete en un chroot limpio. Requiere abuild-rootbld.

rootpkg

Ejecuta 'package', las funciones de división y crea los apks como fakeroot

validate

Validación básica del APKBUILD

snapshot

Crea un $giturl snapshot y lo sube a $disturl

sourcecheck

Comprueba si el paquete fuente remoto existe en el origen

srcpkg

Crea un paquete fuente

undeps

Desinstala los paquetes listados en makedepends y depends

unpack

Descomprime las fuentes en $srcdir

up2date

Compara las fechas de los objetivos y las fuentes

ENTORNO

APKBUILD

Sobrescribe la ruta al APKBUILD archivo.

BOOTSTRAP

Se usa al iniciar desde cero sin paquetes existentes minimizando las dependencias de compilación. Este indicador solo tiene efecto en algunos paquetes seleccionados.

Un valor de nocc omite cualquier compilación (por ejemplo: incluye solo cabeceras de origen). Un valor de nolibc asume que no libc está disponible.

Esta lista de valores no es exhaustiva.

CHOST

Genera paquetes para la arquitectura o el trío especificados.

CTARGET

Genera el compilador para la arquitectura o el trío especificados.

PACKAGER

Nombre y correo electrónico de los paquetes en formato RFC5322. Ejemplo: John Doe <john@example.com>.

PACKAGER_PRIVKEY

Ruta a una clave privada utilizada para firmar paquetes.

REPODEST

Los paquetes se almacenarán en $REPODEST/$repo/$arch/$pkgname-$pkgver-r$pkgrel.apk, donde $repo es el nombre base del directorio padre de $startdir.

SOURCE_DATE_EPOCH

Usa esta marca de tiempo como referencia para compilaciones reproducibles. Ver https://reproducible-builds.org/docs/source-date-epoch/

SUDO_APK

Comando a usar para ejecutar apk como root. Por defecto es abuild-apk.

USE_CCACHE

Si se establece en un valor no vacío, habilita el soporte de ccache .

USE_COLORS

Si se establece en un valor no vacío, imprime salida con colores usando secuencias de escape ANSI.

ARCHIVOS

/etc/abuild.conf

La configuración se lee de este archivo por defecto.

$HOME/.abuild/abuild.conf

La configuración específica del usuario se lee de este archivo, si existe.

EJEMPLOS

Actualiza los checksums de un APKBUILD:

abuild checksum

Compila un APKBUILD e imprime salida con colores:

abuild -rc
