NOMBRE

abstractile - dibuja patrones de mosaico abstractos de fichas entrelazadas

SINOPSIS

abstractile [--sleep segundos] [--speed int] [--tile modo_ficha] [--visual visual] [--window] [--root] [--window-id número] [--fps]

DESCRIPCIÓN

El programa abstractile dibuja cuadrículas caóticas de fichas entrelazadas de colores y formas aleatorias.

OPCIONES

abstractile acepta las siguientes opciones:

--sleep segundos
Especifica el número de segundos para esperar entre pantallas (0-60).
--speed int
Un valor entre 0 y 5 utilizado para especificar la velocidad a la que se dibuja cada pantalla.
--tile modo_ficha
El tipo de ficha que se dibuja en cada pantalla. Los valores legales son random, flat, thin, outline, block, neon y tiled
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
