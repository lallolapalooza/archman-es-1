ABC2MIDI(1) Manual de Comandos Generales ABC2MIDI(1)

NOMBRE

abc2midi - convierte archivos abc a archivos MIDI

SINOPSIS

abc2midi archivo_entrada [refnum] [-c] [-v] [-ver] [-t] [-n límite] [-CS] [-quiet] [-silent] [-Q tempo] [-NFNP] [-NFER] [-NGRA] [-NGUI] [-STFW] [-OCC] [-NCOM] [-HARP] [-BF] [-TT] [-o archivo_salida] -CSM [nombre_archivo]

DESCRIPCIÓN


La acción por defecto es escribir un archivo MIDI por cada melodía abc
con el nombre de archivo <base>N.mid, donde <base> es la base del nombre del
archivo abc y N es el número de referencia de la melodía. Si se usa la opción -o
, solo se escribe un archivo. Esta es la melodía
especificada por el número de referencia o, si no se proporciona ningún número de referencia
, la primera melodía del archivo.

OPCIONES

refnum
procesar la melodía con el número de referencia refnum
-c
selecciona solo comprobación
-v n
selecciona la opción detallada donde n es el nivel (opcional)
-ver
imprime el número de versión y sale
-t
selecciona nombres de archivo derivados de los títulos de las melodías
-CS
usa 2:1 en lugar de 3:1 para ritmos rotos
-quiet
Suprime algunas advertencias comunes.
-silent
Suprime otros mensajes.
-n X
limita la longitud de la base del nombre del archivo a X caracteres
-Q tempo
establece el tempo por defecto en negras por minuto si no se especificó en la cabecera abc.
-NFNP
Ignora cualquier indicación dinámica !f! !ff! etc.
-NFER
Ignora cualquier indicación de fermata (ej. H o !fermata!).
-NGRA
Ignora las notas de adorno.
-NGUI
Ignora los acordes de guitarra encerrados entre comillas dobles.
-STFW
Coloca el texto de la letra en pistas MIDI separadas.
-NCOM
Suprime algunos comentarios en el archivo MIDI de salida.
-OCC
Acepta la convención de acordes antigua (ej. +D2G2+ en lugar de [DG]2).
-BF
Modo BarFly: invoca un modelo de estrés si es posible.
-HARP
Los adornos de trémolo=trémolo se generan para el arpista (misma nota).
-TT
Cambia la afinación de La = 440 Hz.
-o archivo_salida
escribe la salida en archivo_salida
-CSM archivo_entrada
carga un conjunto de modos de estrés personalizados desde un archivo

CARACTERÍSTICAS

* Ritmos rotos (>, <), acordes, n-tuplas, ligaduras, sostenidos, notas staccato, repeticiones, cambios de tempo/duración/compás dentro de la melodía son compatibles.

* R:hornpipe o r:hornpipe se reconoce y los tiempos de las notas se ajustan para dar un ritmo roto (ab se convierte en a>b).

* La mayoría de los errores en la entrada abc generarán un mensaje de error adecuado en la salida y el convertidor continuará.

* Los comentarios y campos de texto en la fuente abc se convierten en eventos de texto en la salida MIDI

* Si hay acordes de guitarra presentes, se utilizan para generar un acompañamiento en la salida MIDI.

* Si hay signos de repetición desajustados en el abc, el programa intenta arreglarlos. Sin embargo, no intentará esto si se ha utilizado una descripción de melodía multipartidista o si se están utilizando múltiples voces.

* Se pueden generar archivos MIDI de karaoke utilizando el campo w: para incluir letras.

* Se aceptan identificadores de voz no numéricos, por ejemplo, V: soprano, como se propuso para el nuevo estándar abc.

* Los silencios invisibles especificados por x se tratan de la misma manera que los silencios normales (z).

* Las decoraciones se pueden indicar utilizando la notación obsoleta (ej. !fermata!) o la notación estándar versión 2.0 (ej. +fermata+).

LIMITACIONES

* Ningún campo se hereda de encima del campo X: de la melodía.

EXTENSIONES DE SINTAXIS ABC

* Hay algunas extensiones a la sintaxis abc de la forma

%%MIDI canal n

Estos controlan la selección de canal y programa, la transposición y varias otras características de abc2midi.

Cada una de estas debería aparecer en una línea separada. Todas ellas están permitidas dentro del cuerpo de la melodía abc. Al usarlas en combinación con la notación de parte, se puede, por ejemplo, reproducir una parte transpuesta o en una tonalidad diferente.

La idea detrás de esta sintaxis es que otros programas la tratarán como un comentario y la ignorarán.

%%MIDI canal n

selecciona el canal de melodía n (en el rango 1-16).

%%MIDI programa [c] n

selecciona el programa n (en el rango 0-127) en el canal c. Si no se proporciona c, el programa se selecciona en el canal de melodía actual. La mayoría de los generadores de tono modernos siguen el estándar General MIDI, que define el tipo de instrumento para cada número de programa.

%%MIDI beat a b c n

controla la forma en que se seleccionan las velocidades de las notas. La primera nota en un compás tiene velocidad a. Otras notas "fuertes" tienen velocidad b y el resto tienen velocidad c. a, b y c deben estar en el rango 0-127. El parámetro n determina qué notas son "fuertes". Si el compás es x/y, cada nota recibe un número de posición k = 0, 1, 2 .. x-1 dentro de cada compás. Tenga en cuenta que las unidades para n no son la unidad de longitud de nota. Si k es un múltiplo de n, entonces la nota es "fuerte". Los especificadores de volumen !ppp! a !fff! son equivalentes a lo siguiente:

!ppp! = %%MIDI beat 30 20 10 1
!pp! = %%MIDI beat 45 35 20 1
!p! = %%MIDI beat 60 50 35 1
!mp! = %%MIDI beat 75 65 50 1
!mf! = %%MIDI beat 90 80 65 1
!f! = %%MIDI beat 105 95 80 1
!ff! = %%MIDI beat 120 110 95 1
!fff! = %%MIDI beat 127 125 110 1

%%MIDI beatmod n

Incrementa (o decrementa si n es negativo) las velocidades a, b y c descritas anteriormente. Las instrucciones !crescendo(! y !crescendo)! son equivalentes a insertar un %%MIDI beatmod 15 dondequiera que ocurran. (Alternativamente, puedes usar !<(! y !<)!.) De manera similar, las instrucciones !diminuendo(! y !diminuendo)! son equivalentes a %%MIDI beatmod -15.

%%MIDI deltaloudness n

donde n es un número positivo pequeño. Por defecto, las instrucciones crescendo y diminuendo modifican las variables de ritmo a, b y c en 15 unidades de velocidad. Esta instrucción permite establecer este valor por defecto a n.

%%MIDI nobeataccents

Para instrumentos como el órgano de iglesia que no tienen notas de ritmo muy enfatizadas, usar esto forzará el uso de la velocidad 'b' (ver %%MIDI beat) para cada nota independientemente de su posición en el compás. Esto permite usar la dinámica (ff, f, etc.) de la forma normal.

%%MIDI beataccents

Vuelve a enfatizar las notas de la forma habitual. (por defecto)

%%MIDI beatstring <cadena de f, m y p>

Esto proporciona una forma alternativa de especificar dónde caen los acentos fuertes y débiles dentro de un compás. 'f' significa velocidad a (normalmente fuerte), 'm' significa velocidad b (velocidad media) y 'p' significa velocidad c (velocidad suave). Por ejemplo, si el compás es 7/8 con acentos en la primera, cuarta y sexta nota del compás, podríamos usar lo siguiente

%%MIDI beatstring fppmpmp

%%MIDI transpose n

transpone la salida por el número especificado de semitonos. n puede ser positivo o negativo.

%%MIDI rtranspose n

Transposición relativa por el número especificado de semitonos. es decir, %%MIDI transpose a seguido de %%MIDI rtranspose b re

resulta en una transposición de a+b. %%MIDI transpose b resultará en una transposición de b semitonos, independientemente de cualquier transposición previa.

%%MIDI c n

especifica el tono MIDI que corresponde a c. El valor predeterminado es 60. Este número normalmente debería ser un múltiplo de 12.

%%MIDI grace a/b

establece la fracción de la nota siguiente que ocuparán las notas de adorno. a debe estar entre 1 y b-1. Las notas de adorno pueden no sonar naturales en este enfoque, ya que la longitud de las notas de adorno individuales varía con la complejidad del adorno y la longitud de la nota siguiente. Un enfoque diferente (que ahora es el predeterminado) asume que las notas de adorno siempre tienen una duración fija. Para usar el otro enfoque, especificaría,

%%MIDI gracedivider b

donde b especifica en cuántas partes dividir la longitud de unidad especificada por el comando de campo L:. Por ejemplo, si b = 4 y L: = 1/8, entonces cada nota de adorno sería 1/(8*4) o una nota de 32avos. Se robaría tiempo de la nota a la que se aplican las notas de adorno. Si esa nota no es lo suficientemente larga para manejar el adorno, entonces a las notas de adorno se les asignaría 0 duración.

%%MIDI chordname name n1 n2 n3 n4 n5 n6

Define cómo tocar un acorde de guitarra llamado "name". n1 es normalmente 0 y n2, n3 a n6 dan los tonos de las otras notas en semitonos relativos a la nota raíz. Puede haber menos de 6 notas en el acorde, pero no más. Si "name" ya está definido, este comando lo redefine. A diferencia de la mayoría de los otros comandos, las definiciones de chordname permanecen en efecto desde donde se definen hasta el final del archivo abc. Lo siguiente ilustra cómo m, 7, m7 y maj7 podrían configurarse si no estuvieran ya definidos.

%%MIDI chordname m 0 3 7
%%MIDI chordname 7 0 4 7 10
%%MIDI chordname m7 0 3 7 10
%%MIDI chordname maj7 0 4 7 11

%%MIDI gchord string

configura cómo se generan los acordes de guitarra. La cadena es una secuencia hecha de z's, c's, f's y b's para silencios, acordes, fundamental y fundamental más notas de acorde respectivamente. Esto especifica cómo debe tocarse cada compás. Se permite una longitud opcional después de las z's, c's, f's y b's p. ej. czf2zf3. Si el abc contiene acordes de guitarra, entonces abc2midi automáticamente añade acordes y fundamentales después de encontrar el primer acorde de guitarra. Sigue usando ese acorde hasta que se especifique un nuevo acorde en el abc. Siempre que se encuentre el campo M: en el abc, se establece una cadena predeterminada apropiada :

Para tiempo 2/4 o 4/4 el predeterminado es equivalente a : %%MIDI gchord fzczfzcz

Para tiempo 3/4 el predeterminado es equivalente a : %%MIDI gchord fzczcz

Para tiempo 6/8 el predeterminado es equivalente a : %%MIDI gchord fzcfzc

Para tiempo 9/8 el predeterminado es equivalente a : %%MIDI gchord fzcfzcfzc

El comando gchord ha sido extendido para permitirle tocar las notas individuales que componen el acorde de guitarra. Esto le permite tocar acordes rotos o arpegios. Los nuevos códigos g,h,i,j, G,H,I,J referencian las notas individuales empezando desde la nota más baja del acorde (no necesariamente la raíz en el caso de inversiones). Por ejemplo, para el acorde de Do mayor, g refiere a C, h refiere a E y i refiere a G. Para un comando gchord como,

%%MIDI gchord ghih

Abc2midi arpegiará el acorde de guitarra de Do mayor a CEGE. Las letras mayúsculas G,H,I, y J referencian las mismas notas excepto que están transpuestas una octava hacia abajo. Nota: para la primera inversión del acorde de Do mayor (indicada por "C/E"), E sería la nota más baja, así que g referiría a la nota E.

Como otros códigos gchord, puede añadir un número que indique la duración de la nota. Se aplican las mismas reglas que antes. Puede usar cualquier combinación de los códigos gchord, (fcbghijGHIJz).

%%MIDI chordprog n

Establece el instrumento MIDI para los acordes como n. Si el comando incluye la cadena octave=n donde n es un número entre -2 y 2 inclusive, entonces esto desplazará el tono del instrumento por n octavas. Por ejemplo %%MIDI chordprog 10 octave=1.)

%%MIDI bassprog n

Establece el instrumento MIDI para las notas de bajo como n. Si el comando incluye la cadena octave=n donde n es un número entre -2 y 2 inclusive, entonces esto desplazará el tono del instrumento por n octavas. Por ejemplo %%MIDI bassprog 10 octave=-1.)

%%MIDI chordvol n

Establece el volumen (velocidad) de las notas del acorde en n.

%%MIDI bassvol n

Establece el volumen (velocidad) de las notas de bajo en n. No hay un comando melodyvol correspondiente ya que hay 3 valores de velocidad para la melodía, establecidos usando el comando beat.

%%MIDI gchordon

Activa los acordes de guitarra (están activados por defecto al inicio de una melodía).

%%MIDI gchordoff

Desactiva los acordes de guitarra.

%%MIDI droneon

Activa un dron continuo (usado en música de gaita) que consiste en dos notas. Por defecto las notas son A, y A,, tocadas en un fagot a una velocidad de 80. Esto puede configurarse por el comando %%MIDI drone descrito a continuación.

%%MIDI droneoff

Desactiva el dron continuo.

%%MIDI drone n1 n2 n3 n4 n5

Establece los parámetros del dron donde n1 es el programa MIDI, n2 y n3 especifican los tonos MIDI de las dos notas del acorde, y n4 y n5 especifican las velocidades MIDI de las dos notas. Si no establece estos parámetros, por defecto son 70 45 33 80 80. Un valor de cero o menos indica que la configuración de este parámetro debería dejarse como está.

%%MIDI drum string [drum programs] [drum velocities]

Esto configura un patrón de percusión. La cadena determina cuándo hay un golpe de percusión y los valores del programa de percusión determinan cómo suena cada golpe de percusión.

p. ej. %%MIDI drum d2zdd 35 38 38 100 50 50

La cadena puede contener 'd' para un golpe de percusión o 'z' para un silencio. Por defecto una voz comienza sin patrón de percusión y se necesita '%%MIDI drumon' para habilitar la percusión. El patrón de percusión se repite durante cada compás hasta que se encuentra '%%MIDI drumoff'. El comando %%MIDI drum puede usarse dentro de una melodía para cambiar el patrón de percusión. Este comando coloca los sonidos de percusión en el canal 10 y asume que su generador de tonos cumple con el estándar General Midi - si no lo hace, entonces puede escuchar tonos en lugar de sonidos de percusión.

Tanto en los comandos gchord como drum, la longitud de nota estándar de una nota única f,c,z o d no está establecida por el comando L:. En su lugar se ajusta para que toda la cadena gchord o cadena de percusión quepa exactamente en un compás. En otras palabras, la duración de cada nota se divide por la duración total de la cadena. Esto significa que, por ejemplo, la cadena de percusión "dd" es equivalente a la cadena de percusión "d4d4". Actualmente no puede especificar fracciones directamente (p. ej. C3/2) como se hace en el cuerpo de la música, pero todavía es posible expresar ritmos complejos. Por ejemplo, para indicar un ritmo como (3ddd d/d/d/d, escribiría la cadena "d4d4d4d3d3d3d3".

%%MIDI drumbars n

La línea %%MIDI drum puede sonar bastante monótona si se repite en cada compás. Para sortear este problema, un nuevo comando MIDI %%MIDI drumbars n donde n es un número pequeño distribuirá la cadena de percusión a lo largo de n compases consecutivos. Por defecto drumbars está establecido en 1 manteniendo la compatibilidad con los archivos abc existentes. Debe asegurarse de que la cadena de percusión sea divisible uniformemente entre los compases de drumbar. Además, la firma de tiempo no debería cambiar entre compases en una unidad de drumbar. (Archivo abc de ejemplo en doc/CHANGES June 24 2008.)

%%MIDI gchordbars n

Este comando distribuye la cadena gchord a lo largo de n compases consecutivos, igual que drumbars (arriba). (Se encuentra un ejemplo en doc/CHANGES March 17 2009.)

Con la versión 1.54 Dec 4 2004 de abc2midi, las notas en los acordes (p. ej. [FAc]) no se tocan en el mismo instante sino desplazadas y acortadas en 10 unidades de tiempo MIDI. Así la primera nota del acorde (p. ej. F) se toca durante el tiempo indicado completo, la segunda nota (p. ej. A) comienza 10 unidades MIDI después y se acorta en la misma cantidad, y la tercera nota comienza otros 10 unidades MIDI después y se acorta en otras 10 unidades. Esto introduce una opción "expressivo" y evita el ataque fuerte. (Esto no se aplica a gchords ni a acordes multivoz.) La cantidad del retraso y el acortamiento puede configurarse por el comando MIDI

%%MIDI chordattack n

donde n es un número pequeño. Si n es cero, entonces abc2midi debería comportarse como en versiones anteriores. El retraso n está en unidades de tiempo MIDI donde hay 480 unidades en un tiempo de negra. El programa puede no funcionar correctamente si n es demasiado grande y hay acordes cortos.

%%MIDI randomchordattack n

Como arriba excepto que el retraso es una variable aleatoria uniformemente distribuida entre 0 y n-1.

%%MIDI trim x/y

donde x y y son dos números. Este comando controla la articulación de notas y acordes colocando huecos silenciosos entre las notas. La longitud de estos huecos está determinada por x/y y la longitud de unidad especificada por el comando L:. Estos huecos se producen acortando las notas en la misma cantidad. Si la nota ya es más corta que el hueco especificado, entonces el hueco se establece en la mitad de la longitud de la nota. La fracción x/y indica una duración de nota de la misma manera que se especifica en el archivo abc. La duración real se basa en la longitud de unidad especificada por el comando de campo L:. Se recomienda que x/y sea una fracción cercana a cero. El recorte de notas está deshabilitado dentro de ligaduras especificadas por paréntesis. Puede desactivar todo el recorte de notas estableciendo x en 0, p. ej. 0/1. Por defecto, el recorte de notas está desactivado al comienzo de una melodía o comando de voz.

%%MIDI expand x/y

donde x y y son dos números definiendo una fracción menor que 1. Este comando controla la articulación de notas y acordes de la manera inversa. Las notas se alargan por esta fracción para que se solapen con el comienzo de la nota siguiente.

%%MIDI drummap note midipitch

Por favor consulte abcguide.txt.

%%MIDI ptstress filename

Este comando carga el archivo filename en abc2midi, que contiene los parámetros de estrés de Phil Taylor, y pone a abc2midi en el modo donde aplica estos parámetros de estrés en cada nota. Este modelo funciona en oposición al modelo beat estándar, así que los comandos MIDI beat, beatstring, beatmod se vuelven inefectivos. Esto también significa que las indicaciones de dinámica !f! !pp! etc. ya no funcionan.

Hay dos implementaciones diferentes del modelo de estrés. El modelo 1 modifica la articulación de la nota y toma el control de los parámetros MIDI trim también. Para volver al modelo estándar, ponga el comando %%MIDI beataccents. El modelo 2 modifica tanto el comienzo como el final de cada nota permitiendo que un tiempo musical se expanda o contraiga en el tiempo. Sin embargo, la longitud de una medida musical debería preservarse. Nota: si usa el modelo 2, que es el predeterminado actual, debe incluir -BF como uno de los parámetros de tiempo de ejecución de abc2midi.

El modelo divide un compás en segmentos iguales. Para cada segmento, una un nivel de sonoridad o abc2midi(1) - Arch Linux man pages

convert ABC music notation to MIDI file

SYNOPSIS

DESCRIPTION

The abc2midi program converts tunes written in the ABC music notation into the Standard MIDI File format.

OPTIONS

The program supports a large number of options and extensions to the standard ABC syntax. Most of these are described in the abcguide.txt file which is supplied with the abcMIDI distribution. The most commonly used options are given below.

The option letter is followed by an integer or a file name. If the option requires an integer and none is given, it defaults to 1. If it is required to specify the option with an integer, then no space is permitted between the option letter and the integer.

GENERAL OPTIONS

-i infile
Read music from infile. If this option is omitted, then music is read from standard input.
-o outfile
Write MIDI output to outfile. If this option is omitted, then the output is written to standard output.

FEATURES

This program converts ABC files to Standard MIDI files. It supports most of the standard ABC syntax and has a number of extensions.

The program can generate a number of different MIDI files from the same ABC input. For example, it can generate a full score with all parts, or it can generate just one part.

The program can also generate Karaoke files and ABC files.

LIMITATIONS

The program does not support all of the ABC syntax. For example, it does not support the following:

  • Chords.
  • Bowing marks.
  • Graces.
  • Text annotations.
  • Multiple voices.

The program also has a number of other limitations:

  • The program assumes that the input file is a single tune.
  • The program assumes that the tempo is constant throughout the tune.
  • The program does not support all of the MIDI specification. For example, it does not support SysEx messages or system common messages.

ABC SYNTAX EXTENSIONS

The program supports a number of extensions to the standard ABC syntax.

These extensions are documented in the abcguide.txt file.

MIDI TEMPO AND VELOCITY

The program supports the following extensions to the ABC syntax:

%%MIDI tempo n
Sets the MIDI tempo to n, where n is in beats per minute.
%%MIDI velocity n
Sets the MIDI velocity to n, where n is in the range 0-127.
%%MIDI duration n
Sets the MIDI duration to n, where n is a decimal number.

The program also supports a number of extensions related to MIDI velocity and duration.

For example, the program can be used to specify a number of segments, each with its own velocity and duration multipliers. If a note falls into a specific segment, it assumes the velocity of that segment and its duration is modified accordingly. If the note overlaps more than one segment, then the note assumes the average of those segment values.

The input file specifies the number of segments and the loudness and duration multipliers for each segment. The file has the following format. The first value is the number of segments and each line specifies the velocity and duration multiplier of the specific segment. The velocity is limited to 127 and the duration is a decimal number. The note durations is modified by varying the gap between notes, so it is not possible to extend a note. This preserves the regular tempo of the music. The program scales, the note duration indications by dividing it by the maximum value which here is 1.4.

%%MIDI stressmodel n

where n is either 1 or 2, selects the stress model implementation.


other %%MIDI commands such as bendvelocity, bendstring, controlstring have been introduced recently and are described in the file abcguide.txt.

COMPATIBILITY WITH DRAFT STANDARD 2.0

The proposed standard introduces a new copyright field using the syntax

%%abc-copyright (c) Copyright John Smith 2003

Abc2midi now inserts this in the MIDI file in the form of a metatext copyright tag. Changes were made to the event_specific function in store.c to process the copyright information. It is also copied into the Karaoke track (if it is created) as as @T field.
