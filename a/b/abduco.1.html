ABDUCO(1) Manual de Comandos Generales ABDUCO(1)

NOMBRE

abduco - gestor de sesiones de terminal

SINOPSIS

abduco [-e tecla-desconectar] [-r] [-f] -c nombre comando [args ...]
abduco [-e tecla-desconectar] [-r] [-f] -n nombre comando [args ...]
abduco [-e tecla-desconectar] [-r] [-f] [-l] -A nombre comando [args ...]
abduco [-e tecla-desconectar] [-r] [-l] -a nombre

DESCRIPCIÓN

abduco proporciona una forma de desconectar una aplicación dada de su terminal de control, proporcionando así un soporte de adjuntar/desconectar sesiones muy similar a screen(1), tmux(1) o dtach(1).

Si no se especifica el comando a ejecutar, se examina la variable de entorno $ABDUCO_CMD; si no está establecida, se ejecuta dvtm(1).

Toda la información relacionada con las sesiones se almacena en los siguientes directorios (se usa el primero que tenga éxito):

$ABDUCO_SOCKET_DIR/abduco
$HOME/.abduco
$TMPDIR/abduco/$USER
/tmp/abduco/$USER

Sin embargo, si un nombre de sesión dado representa una ruta relativa o absoluta, se utiliza sin modificar.

Si por alguna razón el socket de dominio unix(7) que representa una sesión se elimina, enviar la señal SIGUSR1 al proceso servidor lo recreará.

OPCIONES

Si no se proporcionan argumentos en la línea de comandos, se imprimen todas las sesiones activas actualmente, ordenadas por su fecha de creación respectiva. Las líneas que comienzan con un asterisco * indican que al menos un cliente está conectado. Un signo más + indica que el comando terminó mientras ningún cliente estaba conectado; adjúntese para obtener su estado de salida.

-v
Imprime información de la versión en la salida estándar y sale.
-r
Sesión de solo lectura, es decir, la entrada del usuario se ignora.
-e tecla-desconectar
Establece la tecla para desconectar, que por defecto es CTRL+\, es decir, ^\ para la tecla-desconectar.
-f
Forzar la creación de una sesión cuando ya existe una sesión terminada del mismo nombre, después de mostrar su estado de salida.
-c
Crear una nueva sesión y adjuntarse inmediatamente a ella.
-n
Crear una nueva sesión pero no adjuntarse a ella.
-A
Intentar conectarse a una sesión existente; si falla, crear dicha sesión y adjuntarse inmediatamente a ella.
-a
Adjuntarse a una sesión existente.
-l
Adjuntarse con la menor prioridad, lo que significa que este cliente será el último en controlar el tamaño.

EJEMPLO

Inicia una nueva sesión (asumiendo que dvtm(1) está en $PATH) con

abduco -c mi-sesion

haz algo de trabajo, luego desconéctate presionando CTRL+\ y más tarde vuelve a adjuntarte con

abduco -a mi-sesion
