ABC2ABC(1) Manual de comandos generales ABC2ABC(1)

NOMBRE

abc2abc - un simple verificador/re-formateador/transpositor de abc

SINOPSIS

abc2abc archivo [ -s ] [ -n ] [ -b ] [ -r ] [ -e ] [ -t semitonos ] [ -nda ] [ -u ] [ -d ] [ -v ] [ -Vnúmero de voz] [-Pnúmero de voz] [-nokeys] [ -nokeyf] [ -usekey(sostenidos/bemoles)] [-useclef(sol/fa)] [ -OCC ]

DESCRIPCIÓN

abc2abc es un simple verificador/re-formateador/transpositor de abc. Comprobará si el archivo dado en la línea de comandos cumple con la sintaxis básica de abc.

Si desea verificar una melodía abc, se recomienda usar abc2midi con la opción -c. Esto realiza comprobaciones adicionales que abc2abc no hace.

La salida de abc2abc va a la salida estándar. Utilice la redirección para guardarla en un archivo.

OPCIONES

-s
Reorganiza el espaciado en el archivo (lo que afecta a cómo se agrupan las notas cuando la música se imprime). Esta opción parece no estar funcionando correctamente.
-n X
Reformula el archivo abc con saltos de línea cada X compases.
-b
No realizar comprobación de compases.
-r
No realizar comprobación de repeticiones.
-e
No informar de errores.
-t n
Transpone la melodía por n semitonos. Esta función también funciona con K: none o una de las opciones -nokeys o -nokeyf. Si una voz se asigna al canal 10 (canal de percusión) mediante un comando %%MIDI channel 10, esta voz nunca se transpón.
-nda
Convierte alteraciones dobles en acordes de guitarra a otro acorde, aunque estrictamente no sea correcto.
-u
Actualiza la notación; la notación antigua + + para acordes se reemplaza por [] y s s para ligaduras se reemplaza por ().
-OCC
Acepta la notación antigua para acordes. Normalmente está desactivada, ya que entra en conflicto con el borrador del estándar abc versión 2.0 para decoraciones (por ejemplo, +crescendo(+).
-d
Re-nota la melodía duplicando todas las duraciones de las notas. La duración de la unidad especificada por el comando de campo L: se reduce a la mitad (por ejemplo, L:1/8 a L:1/16).
-v
Re-nota la melodía reduciendo a la mitad todas las duraciones de las notas. La duración de la unidad especificada por el comando de campo L: se duplica (por ejemplo, L:1/8 a L:1/4).
-ver
Imprime el número de versión y sale.
-V X[,Y...]
Para archivos abc multivoz (es decir, que contienen comandos de campo V:), solo se copian las voces X[,Y,...].
-P X,[,Y...]
Para archivos abc multivoz (es decir, que contienen comandos de campo V:), todas las voces excepto X[,Y...] permanecen iguales. Las voces X, Y... se modifican de acuerdo con los otros parámetros en tiempo de ejecución.
-X n
Para un archivo que contiene muchas melodías, los números de referencia X: se renumeran secuencialmente a partir del número n.
-xref n
Solo se procesa la melodía con X: n.
-nokeys
No se asumirá ninguna armadura. En su lugar, se colocarán sostenidos y naturales donde sean necesarios.
-nokeyf
No se asumirá ninguna armadura. En su lugar, se colocarán bemoles y naturales donde sean necesarios.
-usekey sf
Esto forzará a abc2abc a generar las notas en las armaduras keys[sf], donde sf especifica el número de bemoles (-negativo) o sostenidos (+positivo) en la armadura. Es un número entre -5 y +5 inclusive.
-useclef
Esto funciona solo con la opción -t (transponer) y siempre que el archivo abc no tenga ya un comando de clave en el campo K:. No admite voces.

* Normalmente abc2abc convertirá la notación obsoleta para decoraciones (por ejemplo, !ppp!) al estándar draft versión 2.0 de abc (por ejemplo, +ppp+). Si no desea cambiar a este estándar, incluya la bandera -OCC.
