SALID

A

La siguiente lista describelos valores devueltos por ab:

Software del servidor
El valor, si existe, devuelto en el server cabecera HTTP de la primera respuesta exitosa. Esto incluye todos los caracteres en la cabecera desde el principio hasta el punto donde se detecta un carácter con valor decimal 32 (notablemente: un espacio o CR/LF).
Nombre de host del servidor
La dirección DNS o IP proporcionada en la línea de comandos
Puerto del servidor
El puerto al que se conecta ab. Si no se proporciona un puerto en la línea de comandos, este será 80 para http y 443 para https.
Protocolo SSL/TLS
Los parámetros del protocolo negociados entre el cliente y el servidor. Esto solo se imprimirá si se usa SSL.
Ruta del documento
La URI de la solicitud analizada desde la cadena de la línea de comandos.
Longitud del documento
Este es el tamaño en bytes del primer documento devuelto exitosamente. Si la longitud del documento cambia durante la prueba, la respuesta se considera un error.
Nivel de concurrencia
El número de clientes concurrentes utilizados durante la prueba
Tiempo tomado por las pruebas
Este es el tiempo transcurrido desde el momento en que se crea la primera conexión de socket hasta el momento en que se recibe la última respuesta
Solicitudes completas
El número de respuestas exitosas recibidas
Solicitudes fallidas
El número de solicitudes que se consideraron un fallo. Si el número es mayor que cero, se imprimirá otra línea mostrando el número de solicitudes que fallaron debido a la conexión, la lectura, una longitud de contenido incorrecta o excepciones.
Errores de escritura
El número de errores que fallaron durante la escritura (tubería rota).
Respuestas no-2xx
El número de respuestas que no estaban en la serie 200 de códigos de respuesta. Si todas las respuestas fueron 200, este campo no se imprime.
Solicitudes Keep-Alive
El número de conexiones que resultaron en solicitudes Keep-Alive
Cuerpo total enviado
Si está configurado para enviar datos como parte de la prueba, este es el número total de bytes enviados durante las pruebas. Este campo se omite si la prueba no incluyó un cuerpo para enviar.
Total transferido
El número total de bytes recibidos del servidor. Este número es esencialmente el número de bytes enviados a través del cable.
HTML transferido
El número total de bytes de documento recibidos del servidor. Este número excluye los bytes recibidos en las cabeceras HTTP
Solicitudes por segundo
Este es el número de solicitudes por segundo. Este valor es el resultado de dividir el número de solicitudes por el tiempo total transcurrido
Tiempo por solicitud
El tiempo promedio dedicado por solicitud. El primer valor se calcula con la fórmula concurrency * timetaken * 1000 / done mientras que el segundo valor se calcula con la fórmula timetaken * 1000 / done
Tasa de transferencia
La tasa de transferencia calculada por la fórmula totalread / 1024 / timetaken

ERRORES

Hay varios búferes declarados estáticamente de longitud fija. Combinado con el análisis perezoso de los argumentos de la línea de comandos, las cabeceras de respuesta del servidor y otras entradas externas, esto podría causar problemas.

No implementa HTTP/1.x completamente; solo acepta algunas formas 'esperadas' de respuestas. El uso bastante pesado de strstr(3) aparece en la parte superior del perfil, lo que podría indicar un problema de rendimiento; es decir, usted mediría el rendimiento de ab en lugar del del servidor.
