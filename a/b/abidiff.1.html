VALORES DE

RETORNO

El código de salida del comando abidiff es 0 si la ABI de los binarios comparados son iguales, o distinto de cero si difieren o si la herramienta encontró un

error.

En el último caso, el código de salida es un campo de bits de 8 bits en el que cada bit tiene un significado

específico.

El primer bit, de valor 1, llamado ABIDIFF_ERROR significa que hubo un

error.

El segundo bit, de valor 2, llamado ABIDIFF_USAGE_ERROR significa que hubo un error en la forma en que el usuario invocó la herramienta. Puede establecerse, por ejemplo, si el usuario invocó la herramienta con un interruptor de línea de comandos desconocido, con un número o argumento incorrecto, etc. Si este bit está establecido, entonces el bit ABIDIFF_ERROR también debe estar

establecido.

El tercer bit, de valor 4, llamado ABIDIFF_ABI_CHANGE significa que la ABI de los binarios comparados son

diferentes.

El cuarto bit, de valor 8, llamado ABIDIFF_ABI_INCOMPATIBLE_CHANGE significa que la ABI de los binarios comparados son diferentes de una manera incompatible. Si este bit está establecido, entonces el bit ABIDIFF_ABI_CHANGE también debe estar establecido. Si el bit ABIDIFF_ABI_CHANGE está establecido y el ABIDIFF_INCOMPATIBLE_CHANGE no está establecido, entonces significa que las ABIs comparadas podrían o no ser compatibles. En ese caso, un ser humano necesita revisar los cambios de ABI para decidir si son compatibles o

no.

Ten en cuenta que, en este momento, solo hay unos pocos tipos de cambios de ABI que resultarían en la configuración del indicador ABIDIFF_ABI_INCOMPATIBLE_CHANGE. Esos cambios de ABI

son:
  • la eliminación del símbolo de una función o variable que ha sido definida y
    • exportada.
  • la modificación del
    • índice de un miembro
de una tabla de fun
ciones virtuales (par
a programas y
bibliotecas en C++).

Con el tiempo, cuando se descubran más patrones de cambios de ABI que siempre constituyan cambios de ABI incompatibles, adaptaremos el código para reconocer esos casos y establecer el ABIDIFF_ABI_INCOMPATIBLE_CHANGE en consecuencia. Así que, si encuentras tales patrones, por favor, háznoslo

saber.

Los bits restant

es no se utilizan
por el momento.
