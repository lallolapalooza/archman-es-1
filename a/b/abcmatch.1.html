ABCMATCH(1) Manual de Comandos Generales ABCMATCH(1)

NOMBRE

abcmatch - Busca secuencias específicas de notas en un archivo abc compuesto por muchas melodías.

SINOPSIS

abcmatch archivo abc [-c] [-v] [-r] [-con] [-fixed nn] [-qnt] [-lev] [-a] [-ign] [-br %d] [-tp archivo de referencia abc] [-ver] [-pitch_hist] [-wpitch_hist] [-length_hist] [-interval_hist] [-pitch_table] [-interval_tablenúmero de referencia

DESCRIPCIÓN

abcmatch se utiliza para buscar secuencias específicas de notas en un archivo abc compuesto por muchas melodías. Por ejemplo, si conoce unos compases de una melodía, puede usar este programa para encontrar la melodía que contiene esta secuencia y así identificarla. Como mínimo, abcmatch requiere dos archivos. Un archivo de plantilla llamado match.abc que contiene los compases que está buscando y un archivo grande que consta de cien o más melodías abc. El programa carga automáticamente el archivo match.abc y luego escanea cada melodía en el archivo grande

OPCIONES

-v y -c
se utilizan principalmente para depurar cuando el programa no hace lo que se esperaba.
-ver
imprime el número de versión y luego sale
--norhythm
Hace que el algoritmo de coincidencia ignore la longitud de las notas en un compás, de modo que E3/2F/D GA2 coincidiría con EFD G2A. La opción ignora el parámetro -r ya que ahora es irrelevante.
-pitch_table
Se utiliza para producir un histograma de tono ponderado por intervalo para cada melodía en el archivo. Si esto se guarda en un archivo externo, ese archivo podría usarse como base de datos para encontrar melodías con funciones de densidad de probabilidad de tono (pdf) similares.
-r
Controla cómo el criterio de coincidencia maneja las pequeñas variaciones rítmicas en la melodía. La opción -r debe ir seguida de un número que especifica la resolución temporal para la coincidencia. Cuando el número es cero, esto indica que se debe realizar una coincidencia perfecta, lo que significa que las longitudes de cada nota en el compás deben coincidir exactamente para ser reportadas. Para valores más grandes, se realizará una coincidencia más laxa como se describe a continuación. Las longitudes de las notas se convierten en unidades temporales donde a una negra normalmente se le asigna un valor de 24. Por lo tanto, una corchea tiene un valor de 12, una semicorchea tiene un valor de 6, una blanca tiene un valor de 48, etc. Si especifica una resolución temporal de 12, entonces los valores de tono de las notas solo necesitan coincidir en unidades de tiempo que son múltiplos de una corchea.
-fixed n
Hace que el programa ignore las líneas de compás al hacer la coincidencia. Permite la coincidencia de notas entre melodías que tienen diferentes compases. n es un número que especifica el número exacto de notas a coincidir. Por ejemplo, si n es 4, el programa podría coincidir |C E G E| .. con |C E|G E|. Tenga en cuenta que el comparador aún comienza al principio de un compás dado tanto para la melodía como para la plantilla.
-con
Especifica la coincidencia de contorno. En este caso, el programa usa la armadura solo para indicar las alteraciones. El contorno del tono se calcula a partir de la diferencia de tono o el intervalo entre notas adyacentes.
-qnt
Usa el algoritmo de coincidencia de contorno pero también cuantiza los intervalos usando la siguiente tabla:

unísono y semitono 0 segunda menor a segunda mayor 1 tercera menor a tercera mayor 2 cualquier intervalo mayor 3

Los números negativos son intervalos descendentes.

-tp nombre de archivo, número de referencia
Sustituye cualquier melodía por la plantilla match.abc. Al usar esta función, la melodía completa se usa como plantilla. Abcmatch no compara la plantilla consigo misma, y solo se reportan los compases que coinciden con compases en otras melodías.
-br umbral
Ejecuta el programa en un modo breve diseñado para identificar grupos de melodías que comparten compases comunes. En este modo, el programa cuenta el número de compases en la melodía de prueba que también están presentes en match.abc. Si el número de compases comunes es mayor o igual al umbral, entonces el programa reporta la melodía y el número de compases comunes. El programa escanea todas las melodías en el archivo abc y devuelve una lista de todas las melodías que tienen más de un número específico de compases en común con la plantilla, match.abc. En el uso real, el programa se ejecuta repetidamente mediante un script. Para cada melodía en un archivo abc, crea un archivo de plantilla llamado match.abc y luego ejecuta abcmatch. Las salidas se muestran en la pantalla en una forma fácil de interpretar. El usuario no tiene control sobre el criterio de coincidencia. El ritmo debe coincidir exactamente y las notas se transponen para adaptarse a la armadura. En otras palabras, el parámetro -r es independiente de lo que se especifique en la lista de parámetros.
-pitch_hist o -length_hist
Ejecuta el programa en otro modo. Produce un histograma de la distribución de las notas en el archivo abc. El tono se indica en unidades midi. Así, el do central es 60 y los tonos suben en unidades de semitono. Después del tono sigue un conteo del número de veces que esa nota ocurrió.
-pitch_table o -interval_table
Se utiliza para crear una base de datos para una colección de melodías en un archivo para análisis futuro.
