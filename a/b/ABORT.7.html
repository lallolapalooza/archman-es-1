NOMBRE

ABORT - abortar la transacción actual

SINOPSIS

ABORT [ WORK | TRANSACTION ] [ AND [ NO ] CHAIN ]

DESCRIPCIÓN

ABORT deshace la transacción actual y hace que se descarten todas las actualizaciones realizadas por la transacción. Este comando es idéntico en su comportamiento al comando SQL estándar ROLLBACK, y existe solo por razones históricas.

PARÁMETROS

WORK
TRANSACTION

Palabras clave opcionales. No tienen ningún efecto.

AND CHAIN

Si se especifica AND CHAIN, se inicia inmediatamente una nueva transacción con las mismas características de transacción (ver SET TRANSACTION) que la recién terminada. De lo contrario, no se inicia ninguna nueva transacción.

NOTAS

Use COMMIT para terminar una transacción con éxito.

Emitir ABORT fuera de un bloque de transacción emite una advertencia y, por lo demás, no tiene ningún efecto.

EJEMPLOS

Para abortar todos los cambios:

ABORT;

COMPATIBILIDAD

Este comando es una extensión de PostgreSQL presente por razones históricas. ROLLBACK es el comando SQL estándar equivalente.

VER TAMBIÉN

BEGIN(7), COMMIT(7), ROLLBACK(7)
