ABIWORD(1) Manual de Comandos Generales ABIWORD(1)

NOMBRE

abiword — procesador de texto flexible multiplataforma

SINOPSIS

abiword [OPCIONES] [NOMBRE_ARCHIVO...]

DESCRIPCIÓN

AbiWord es una aplicación de procesamiento de textos completa y eficiente, adecuada para una amplia gama de tareas de procesamiento de textos y extensible con una variedad de complementos. Se integra con enchant(1) para proporcionar corrección ortográfica.

OPCIONES

-g AxA[+X+Y], --geometry=AxA[+X+Y]
Especifica la geometría de la ventana al inicio.
-E COMPLEMENTO, --plugin=COMPLEMENTO
Ejecuta el complemento especificado en lugar de la aplicación principal.
--import-extension=EXT
Importa el archivo dado como si tuviera la extensión EXT, anulando la detección automática del tipo de archivo.
-u PERFIL, --userprofile=PERFIL
Utiliza PERFIL para leer y almacenar configuraciones en lugar del directorio predeterminado XDG_CONFIG_HOME/abiword/profile.
-t DEST, --to=DEST
Convierte el archivo dado a otro formato, escribiendo el resultado en DEST. El formato de DEST se determina por su extensión.
Ver también --to=FORMATO y --to-name.
-t FORMATO, --to=FORMATO
Convierte los archivos dados al formato indicado. A menos que se especifique explícitamente con --to-name, se utilizará el nombre de archivo original (con una extensión diferente, si es necesario). Ver también EJEMPLOS.
Los valores más comunes para FORMATO incluyen:
abw Formato XML de AbiWord (zabw para compresión gzip, bzabw para compresión bzip2)
dbk DocBook XML
doc Formato binario de Microsoft Word
docx Office Open XML (versiones más recientes de Microsoft Word)
html Lenguaje de Marcado de Hipertexto
kwd KWord
odt OpenDocument Text
pdf Formato de Documento Portátil
rtf Rich Text Format
sxw OpenOffice.org Writer 1.0
txt Texto plano
--to-name=DEST
Solo útil junto con --to=FORMATO. Especifica dónde se escribirá el documento convertido.
--verbose=NIVEL
Establece el nivel de verbosidad [0-2], siendo 2 la salida más detallada.
-h, --help
Muestra un mensaje de ayuda corto y sale.
--version
Informa la versión de AbiWord.

VARIABLES DE ENTORNO

HOME
Define el directorio principal del usuario.
XDG_CONFIG_HOME
Define el directorio base en relación con el cual se deben almacenar los archivos de configuración específicos del usuario. (Ver la Especificación de Directorios Base XDG para detalles).

ARCHIVOS

XDG_CONFIG_HOME/abiword/profile
El archivo de perfil de usuario predeterminado. (Si XDG_CONFIG_HOME no está establecido o está vacío, se usará un valor predeterminado igual a HOME/.config).

EJEMPLOS

Para convertir el documento ejemplo.abw a RTF:
abiword --to=rtf ejemplo.abw
El archivo resultante se llamará ejemplo.rtf.

Para imprimir un documento:
abiword --to=ps --to-name=fd://1 NOMBRE_ARCHIVO | lp

REPORTE DE ERRORES

Reporte errores en el sistema de seguimiento de errores Bugzilla en http://bugzilla.abisource.com.

VER TAMBIÉN

enchant(1)

HISTORIA

AbiWord fue iniciado en 1998 por AbiSource Inc., una empresa fundada por SourceGear corporation. El plan inicial era construir una suite ofimática gratuita llamada AbiSuite, que abarcara aplicaciones de procesamiento de textos, hojas de cálculo y presentaciones. Como no tenían un producto usable cuando se agotó su capital de riesgo, el código ya desarrollado (es decir, AbiWord) se hizo de código abierto. Posteriormente, el desarrollo de AbiWord fue asumido por voluntarios y es impulsado por la comunidad hasta la fecha.
