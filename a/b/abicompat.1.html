VALORES DE

RETORNO

El código de salida del comando abicompat es 0 si el ABI de los binarios que se comparan son iguales, o distinto de cero si difieren o si la herramienta encontró un

error.

En el último caso, el código de salida es un campo de bits de 8 bits de ancho en el que cada bit tiene un significado

específico.

El primer bit, de valor 1, llamado ABIDIFF_ERROR significa que hubo un

error.

El segundo bit, de valor 2, llamado ABIDIFF_USAGE_ERROR significa que hubo un error en la forma en que el usuario invocó la herramienta. Puede establecerse, por ejemplo, si el usuario invocó la herramienta con un interruptor de línea de comandos desconocido, con un número o argumento incorrecto, etc. Si este bit está estable, entonces el bit ABIDIFF_ERROR también debe estar

estable.

El tercer bit, de valor 4, llamado ABIDIFF_ABI_CHANGE significa que el ABI de los binarios que se comparan son

diferentes.

El cuarto bit, de valor 8, llamado ABIDIFF_ABI_INCOMPATIBLE_CHANGE significa que el ABI de los binarios comparados son diferentes de una manera incompatible. Si este bit está estable, entonces el bit ABIDIFF_ABI_CHANGE también debe estar estable. Si el bit ABIDIFF_ABI_CHANGE está estable y el bit ABIDIFF_INCOMPATIBLE_CHANGE NO está estable, entonces significa que los ABIs que se comparan podrían o no ser compatibles. En ese caso, un ser humano necesita revisar los cambios de ABI para decidir si son compatibles o

no.

tes no se usan
por el momento.
