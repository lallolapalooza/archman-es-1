ASCIIDOC(1)   ASCIIDOC(1)

NOMBRE

asciidoc - convierte un archivo de texto AsciiDoc a HTML o DocBook

SINOPSIS

asciidoc [OPCIONES] ARCHIVO

DESCRIPCIÓN

El comando asciidoc(1) traduce el archivo de texto AsciiDoc ARCHIVO a DocBook o HTML. Si ARCHIVO es - entonces se utiliza la entrada estándar.

OPCIONES

-a, --attribute=ATRIBUTO

Define o elimina un atributo de documento. ATRIBUTO tiene el formato NOMBRE=VALOR. Los atributos de línea de comandos tienen precedencia sobre los atributos del documento y del archivo de configuración. Otras formas aceptables son NOMBRE (el VALOR por defecto es una cadena vacía); NOMBRE! (elimina el atributo NOMBRE); NOMBRE=VALOR@ (no anula los atributos del documento o del archivo de configuración). Los valores que contienen espacios deben ir entre comillas dobles. Esta opción se puede especificar más de una vez. Un atributo especial llamado trace controla la salida de información de diagnóstico.

-b, --backend=BACKEND

Formato del archivo de salida del backend: docbook45, docbook5, xhtml11, html4, html5, slidy, wordpress o latex (el backend latex es experimental). También puede usar los alias de backend html (alias de xhtml11) o docbook (alias de docbook45). Por defecto es html. La opción --backend también se utiliza para gestionar plugins de backend (ver COMANDOS DE PLUGIN).

-f, --conf-file=CONF_FILE

Utiliza el archivo de configuración CONF_FILE. Los archivos de configuración se procesan en el orden de la línea de comandos (después de los archivos de configuración implícitos). Esta opción se puede especificar más de una vez.

--doctest

Ejecuta las pruebas doctest de Python en el módulo asciidoc.

-d, --doctype=DOCTYPE

Tipo de documento: article, manpage o book. El tipo de documento book solo es compatible con los backends de docbook. El tipo de documento por defecto es article.

-c, --dump-conf

Volca la configuración a la salida estándar.

--filter=FILTRO

Especifica el nombre de un filtro a cargar (se usa para cargar filtros que no se cargan automáticamente). Esta opción se puede especificar más de una vez. La opción --filter también se utiliza para gestionar plugins de filtro (ver COMANDOS DE PLUGIN).

-h, --help [TEMA]

Imprime la ayuda del TEMA. --help temas imprimirá una lista de temas de ayuda, --help sintaxis resume la sintaxis de AsciiDoc, --help manpage imprime la página del manual de AsciiDoc.

-e, --no-conf

Excluye los archivos de configuración cargados implícitamente excepto aquellos con nombres como el archivo de entrada (infile.conf y infile-backend.conf).

-s, --no-header-footer

Suprime la salida del encabezado y pie de página del documento.

-o, --out-file=OUT_FILE

Escribe la salida al archivo OUT_FILE. Por defecto es el nombre base del archivo de entrada con la extensión del backend. Si la entrada es stdin, el archivo de salida por defecto es stdout. Si OUT_FILE es - entonces se utiliza la salida estándar.

-n, --section-numbers

Numera automáticamente los títulos de las secciones del artículo HTML. Sinónimo de --attribute numbered.

--safe

Habilita el modo seguro. El modo seguro está deshabilitado por defecto. El modo seguro de AsciiDoc omite secciones de scripts potencialmente peligrosas en los archivos fuente de AsciiDoc.

--theme=THEME

Especifica un nombre de tema. Sinónimo de --attribute theme=THEME. La opción --theme también se utiliza para gestionar plugins de tema (ver COMANDOS DE PLUGIN).

-v, --verbose

Imprime detalladamente información de procesamiento y verificaciones de archivos de configuración a stderr.

--version

Imprime el número de versión del programa.

COMANDOS DE PLUGIN

Las opciones --filter, --backend y --theme de asciidoc(1) se utilizan para instalar, eliminar y listar plugins de filtros, backends y temas de AsciiDoc. Sintaxis:

asciidoc OPCIÓN install ARCHIVO_ZIP [DIR_PLUGINS]
asciidoc OPCIÓN remove NOMBRE_PLUGIN [DIR_PLUGINS]
asciidoc OPCIÓN list
asciidoc OPCIÓN build ARCHIVO_ZIP FUENTE_PLUGIN

Donde:

OPCIÓN

La opción --filter, --backend o --theme de asciidoc(1) que especifica el tipo de plugin.

NOMBRE_PLUGIN

Un nombre de plugin único que contiene solo caracteres alfanuméricos o guiones bajos.

ARCHIVO_ZIP

Un archivo Zip que contiene los recursos del plugin, el nombre debe comenzar con el nombre del plugin, por ejemplo, my_filter-1.0.zip empaqueta el filtro my_filter.

DIR_PLUGINS

El directorio que contiene los plugins instalados. Cada plugin está contenido en su propio subdirectorio separado que tiene el mismo nombre que el plugin. DIR_PLUGINS es por defecto $HOME/.asciidoc/filters (para plugins de filtro) o $HOME/.asciidoc/backends (para plugins de backend) o $HOME/.asciidoc/themes (para plugins de tema).

FUENTE_PLUGIN

El nombre de un directorio que contiene los archivos fuente del plugin o el nombre de un único archivo fuente.

Los comandos de plugin realizan lo siguiente:

install

Crea un subdirectorio en DIR_PLUGINS con el mismo nombre que el plugin y luego extrae ARCHIVO_ZIP en él.

remove

Elimina el subdirectorio del plugin NOMBRE_PLUGIN y todos sus contenidos de DIR_PLUGINS.

list

Enumera los nombres y ubicaciones de todos los plugins de filtro o tema instalados (incluidos los plugins estándar instalados en el directorio de configuración global).

build

Crea un archivo de plugin llamado ARCHIVO_ZIP que contiene los archivos y subdirectorios especificados por FUENTE_PLUGIN. Se omiten los nombres de archivos y directorios que comienzan con un punto.

VARIABLES DE ENTORNO

SOURCE_DATE_EPOCH

Si la variable de entorno SOURCE_DATE_EPOCH está establecida a una marca de tiempo UNIX, entonces los atributos {docdate}, {doctime}, {localdate} y {localtime} se calculan en la zona horaria UTC, y las marcas de tiempo más nuevas que SOURCE_DATE_EPOCH se reemplazan por SOURCE_DATE_EPOCH. (Esto ayuda a que el software que utiliza AsciiDoc se compile de forma reproducible).

EJEMPLOS

asciidoc nombre_archivo_asciidoc.txt

Simplemente genera un archivo html a partir de nombre_archivo_asciidoc.txt que está en el directorio actual usando asciidoc.

asciidoc -b html5 nombre_archivo_asciidoc.txt

Utiliza la opción -b para usar uno de los backend propuestos u otro que hayas instalado en tu computadora.

asciidoc -a data-uri -a icons -a toc -a max-width=55em articulo.txt

Utiliza la opción -a para establecer atributos desde la línea de comandos. AsciiDoc generó su guía de usuario HTML autónoma que contiene CSS, JavaScript e imágenes incrustados a partir de la plantilla de artículo de AsciiDoc con este comando.

asciidoc -b html5 -d manpage asciidoc.1.txt

Genera la página del manual de asciidoc utilizando el backend html5.
