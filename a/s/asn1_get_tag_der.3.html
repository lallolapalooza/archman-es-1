asn1_get_tag_der(3) libtasn1 asn1_get_tag_der(3)

NOMBRE

asn1_get_tag_der - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_get_tag_der(const unsigned char * der, int der_len, unsigned char * cls, int * len, unsigned long * tag);

ARGUMENTOS

const unsigned char * der
Datos DER a decodificar.
int der_len
Longitud de los datos DER a decodificar.
unsigned char * cls
Variable de salida que contiene la clase decodificada.
int * len
Variable de salida que contiene la longitud de los datos de ETIQUETA DER.
unsigned long * tag
Variable de salida que contiene la etiqueta decodificada (puede ser NULL).

DESCRIPCIÓN

Decodifica la clase y la ETIQUETA del código DER.

RETORNA

Devuelve ASN1_SUCCESS en caso de éxito, o un error.
