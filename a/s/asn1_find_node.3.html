NOMBRE

asn1_find_node - función de API

SINOPSIS

#include <libtasn1.h>

asn1_node asn1_find_node(asn1_node_const pointer, const char * name);

ARGUMENTOS

asn1_node_const pointer
Puntero al elemento NODE_ASN.
const char * name
Cadena terminada en nulo con el nombre del elemento a buscar.

DESCRIPCIÓN

Busca un elemento llamado name comenzando desde pointer. El nombre está compuesto por diferentes identificadores separados por puntos. Cuando * pointer tiene un nombre, el primer identificador debe ser el nombre de * pointer, de lo contrario, debe ser el nombre de uno de los hijos de * pointer.

RETORNA

El resultado de la búsqueda, o NULL si no se encuentra.
