ASN1_STRING_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_STRING_NEW(3ssl) OpenSSL ASN1_STRING_NEW(3ssl)

NOMBRE

ASN1_STRING_new, ASN1_STRING_type_new, ASN1_STRING_free - funciones de asignación de ASN1_STRING

SINOPSIS

#include <openssl/asn1.h>
ASN1_STRING *ASN1_STRING_new(void);
ASN1_STRING *ASN1_STRING_type_new(int type);
void ASN1_STRING_free(ASN1_STRING *a);

DESCRIPCIÓN

ASN1_STRING_new() devuelve una estructura ASN1_STRING asignada. Su tipo no está definido.

ASN1_STRING_type_new() devuelve una estructura ASN1_STRING asignada del tipo type.

ASN1_STRING_free() libera a. Si a es NULL no se hace nada.

NOTAS

Otros tipos de cadenas llaman a las funciones ASN1_STRING. Por ejemplo, ASN1_OCTET_STRING_new() llama a ASN1_STRING_type_new(V_ASN1_OCTET_STRING).

VALORES DE RETORNO

ASN1_STRING_new() y ASN1_STRING_type_new() devuelven una estructura ASN1_STRING válida o NULL si ocurrió un error.

ASN1_STRING_free() no devuelve un valor.
