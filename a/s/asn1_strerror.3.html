asn1_strerror(3) libtasn1 asn1_strerror(3)

NOMBRE

asn1_strerror - Función de API

SINOPSIS

#include <libtasn1.h>

const char * asn1_strerror(int error);

ARGUMENTOS

int error
es un error devuelto por una función de libtasn1.

DESCRIPCIÓN

Devuelve una cadena con una descripción de un error. Esta función es similar a strerror. La única diferencia es que acepta un error (número) devuelto por una función de libtasn1.

VALORES DEVUELTOS

Puntero a una cadena estática terminada en cero que describe el código de error.
