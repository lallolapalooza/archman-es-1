NOMBRE

asciinema-auth - Autenticar esta CLI con una cuenta del servidor asciinema

SINOPSIS

asciinema auth [--server-url] [-q|--quiet] [-h|--help]

DESCRIPCIÓN

Autenticarse con un servidor asciinema.

Crea un enlace de cuenta de usuario entre tu CLI local y una cuenta de servidor asciinema. Opcional para subir con el comando upload, requerido para streaming remoto con los comandos stream y session.

OPCIONES

--server-url=URL
Especifica una URL de servidor asciinema personalizada para autenticarse con servidores autoalojados. Usa la URL base del servidor (ej., https://asciinema.example.com). También se puede configurar a través de la variable de entorno ASCIINEMA_SERVER_URL o la opción de archivo de configuración server.url. Si no se configura una URL de servidor a través de esta opción, variable de entorno o archivo de configuración, se te pedirá que elijas una (por defecto asciinema.org), que se guardará como predeterminada.
-q, --quiet
Suprimir mensajes de diagnóstico e indicadores de progreso. Solo se mostrarán mensajes de error.
-h, --help
Imprimir ayuda (ver un resumen con '-h')
