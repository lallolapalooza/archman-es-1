assert_perror(3) Manual de funciones de biblioteca assert_perror(3)

NOMBRE

assert_perror - prueba errnum y aborta

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <assert.h>
void assert_perror(int errnum);

DESCRIPCIÓN

Si la macro NDEBUG se definió en el momento en que se incluyó por última vez <assert.h>, la macro assert_perror() no genera código y, por lo tanto, no hace nada en absoluto. De lo contrario, la macro assert_perror() imprime un mensaje de error en la salida de error estándar y termina el programa llamando a abort(3) si errnum no es cero. El mensaje contiene el nombre del archivo, el nombre de la función y el número de línea de la llamada a la macro, y la salida de strerror(errnum).

VALOR DE RETORNO

No se devuelve ningún valor.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
assert_perror () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

ERRORES

El propósito de las macros assert es ayudar a los programadores a encontrar errores en sus programas, cosas que no pueden suceder a menos que haya habido un error de codificación. Sin embargo, con las llamadas al sistema o a la biblioteca, la situación es bastante diferente, y las devoluciones de error pueden ocurrir, ocurrirán y deben probarse. No mediante una assert, donde la prueba desaparece cuando se define NDEBUG, sino mediante un código de manejo de errores adecuado. Nunca use esta macro.

VER TAMBIÉN

abort(3), assert(3), exit(3), strerror(3)
