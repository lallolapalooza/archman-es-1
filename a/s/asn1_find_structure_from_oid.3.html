NOMBRE

asn1_find_structure_from_oid - función de API

SINOPSIS

#include <libtasn1.h>

const char * asn1_find_structure_from_oid(asn1_node_const definiciones, const char * oidValue);

ARGUMENTOS

asn1_node_const definiciones
Definiciones ASN1
const char * oidValue
valor del OID a buscar (ej. "1.2.3.4").

DESCRIPCIÓN

Busca la estructura que está definida justo después de una definición de OID.

VALOR DEVUELTO

NULL cuando no se encuentra oidValue, de lo contrario un puntero a una cadena constante que contiene el nombre del elemento definido justo después del OID.
