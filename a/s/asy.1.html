SINOPSI

asy [opciones] [archivo ..

DESCRIPCIÓ

N

Asymptote es un potente lenguaje descriptivo de gráficos vectoriales para dibujos técnicos, inspirado en MetaPost pero con una sintaxis mejorada s

imilar a C++. Asymptote proporciona a las figuras el mismo nivel de alta
calidad de composición tipográfica que LaTeX proporciona al texto científico.

OPCIONE

S

Si no se proporcionan argumentos, Asymptote se ejecuta en modo

interactivo.

Si se proporciona "-" como argumento de archivo, Asymptote lee desde la entrada

estándar.

A continuación se incluye un resumen de las opciones. El efecto de la mayoría de las opciones se puede negar anteponiendo no al nombre de la opción. Los valores predeterminados de la mayoría de las opciones también se pueden introducir en el archivo .asy/config.asy en el directorio personal del usuario usando la forma

larga:


import settings;
batchView=true

;

asy(1) — Asymptote manual

NAME

asy — vector graphics language

SYNOPSIS

asy [OPTION ... ] [FILE ... ]

DESCRIPTION

Asymptote is a powerful descriptive vector graphics language that bridges the gap between the two-dimensional and three-dimensional worlds. It combines the strengths of traditional graphics description languages (like MetaPost and PostScript) with the full power of a modern programming language.

The following options are available:

OPTIONS

-a,-animation n
Set the animation frame rate to n.
-A
Enable antialiasing.
-antialias n
Set the antialiasing level to n [4].
-a,-attach file
Attach a file to the current PDF page.
-autocentering
Automatically center the 3D scene [true].
-autoplay
Automatically play animations [false].
-background color
Set the background color. Use css color names or RRGGBB hex strings.
-batch
Run in batch mode (no interactive prompt).
-bbox
Compute the bounding box of the picture and exit.
-border n
Set the border width to n bp.
-boundbox
Center and scale the picture to fit the bounding box.
-c,-cd dir
Change directory to dir.
-camera str
Set camera position and orientation [str].
-center
Center the output image on the page.
-d,-debug
Enable debugging output.
-d,-density n
Set the image density to n.
-depth n
Set the 3D viewing depth to n.
-D,-DPI n
Set the default resolution to n DPI.
-disableprofile
Disable color management profiles.
-display str
Use display str to show the output.
-doscript str
Execute str as an Asymptote script.
-dviserver str
Use str as the DVI server.
-E
Strip off the trailing newline. Equivalent to Perl's -p.
-emulategreek
Emulate greek characters [true].
-enableprofile
Enable color management profiles.
-f,-false
Set boolean variables to false.
-fps
Print frames per second when playing animations.
-g,-gray
Convert colors to grayscale.
-h,-help
Display help message and exit.
-H,-header
Include a header in the output.
-imagebasedoc
Embed images in the output document.
-implicit_file
Implicitly use the input filename for output files.
-indigo
Use indigo colors.
-infile
Process input from stdin.
-inlineimages
Inline images in PostScript output.
-interactive
Enable interactive mode.
-iso_unit_length n
Set the ISO unit length to n bp.
-landscape
Use landscape orientation.
-latex str
Use str as the LaTeX engine.
-latex2pdf
Convert the output to PDF via LaTeX.
-level n
Set the PostScript level to n.
-L,-link n
Set the link level to n.
-loop
Loop animations indefinitely.
-m,-margin n
Set the margin width to n bp.
-marginheight bp
Set the vertical margin to bp.
-marginwidth bp
Set the horizontal margin to bp.
-mask
Enable masking.
-matrix
Print the transformation matrix.
-max_picture_height bp
Set the maximum picture height to bp.
-max_picture_width bp
Set the maximum picture width to bp.
-maxtile pair
Maximum rendering tile size [(1024,768)].
-maxviewport pair
Maximum viewport size [(0,0)].
-multiline
Input code over multiple lines at the prompt [false].
-multipleView
View output from multiple batch-mode files [false].
-multisample n
Multisampling width for screen images [4].
-offline
Produce offline html files [false].
-O,-offset pair
PostScript offset [(0,0)].
-f,-outformat format
Convert each output file to specified format.
-o,-outname name
Alternative output directory/file prefix.
-outpipe n
Output pipe [-1].
-paperheight bp
Default page height [0].
-paperwidth bp
Default page width [0].
-p,-parseonly
Parse file [false].
-pdfreload
Automatically reload document in pdfviewer [false]. -pdfreloadOptions str []
-pdfreloaddelay usec
Delay before attempting initial pdf reload [750000]. -pdfviewerOptions str []
-position pair
Initial 3D rendering screen position [(0,0)].
-prc
Embed 3D PRC graphics in PDF output [false].
-prerender resolution
Prerender V3D objects (0 implies vector output) [0].
-prompt str
Prompt [> ].
-prompt2 str
Continuation prompt for multiline input [..]. -psviewerOptions str []
-q,-quiet
Suppress welcome text and noninteractive stdout [false].
-render n
Render 3D graphics using n pixels per bp (-1=auto) [-1].
-resizestep step
Resize step [1.2].
-reverse
reverse 3D animations [false].
-rgb
Convert cmyk colors to rgb false.
-safe
Disable system call true.
-scroll n
Scroll standard output n lines at a time [0].
-shiftHoldDistance n
WebGL touch screen distance limit for shift mode [20].
-shiftWaitTime ms
WebGL touch screen shift mode delay [200].
-spinstep deg/s
Spin speed [60].
-svgemulation
Emulate unimplemented SVG shading [true].
-tabcompletion
Interactive prompt auto-completion [true].
-tex engine
latex|pdflatex|xelatex|lualatex|tex|pdftex|luatex|context|none [latex].
-thick
Render thick 3D lines [true].
-thin
Render thin 3D lines [true].
-threads
Use POSIX threads for 3D rendering [true].
-toolbar
Show 3D toolbar in PDF output [true].
-s,-translate
Show translated virtual machine code [false].
-twice
Run LaTeX twice (to resolve references) [false].
-twosided
Use two-sided 3D lighting model for rendering [true].
-u,-user str
General purpose user string.
-v3d
Embed 3D V3D graphics in PDF output [false].
-v,-verbose
Increase verbosity level (can specify multiple times) 0.
-version
Show version; command-line only.
-vibrateTime ms
WebGL shift mode vibrate duration [25].
-viewportmargin pair
Horizontal and vertical 3D viewport margin [(0.5,0.5)].
-wait
Wait for child processes to finish before exiting [false].
-warn str
Enable warning; command-line only.
-webgl2
Use webgl2 if available [false].
-where
Show where listed variables are declared [false].
-wsl
Run asy under the Windows Subsystem for Linux [false].
-xasy
Interactive mode for xasy [false].
-zoomPinchCap limit
WebGL maximum zoom pinch [100].
-zoomPinchFactor n
WebGL zoom pinch sensitivity [10].
-zoomfactor factor
Zoom step factor [1.05].
-zoomstep step
Mouse motion zoom step [0.1].
