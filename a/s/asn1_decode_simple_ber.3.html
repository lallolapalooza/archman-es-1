asn1_decode_simple_ber(3)

Licencias: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_decode_simple_ber(3) libtasn1 asn1_decode_simple_ber(3)

NOMBRE

asn1_decode_simple_ber - función de API

SINOPSIS

#include <libtasn1.h>

int asn1_decode_simple_ber(unsigned int etype, const unsigned char * der, unsigned int _der_len, unsigned char ** str, unsigned int * str_len, unsigned int * ber_len);

ARGUMENTOS

unsigned int etype
El tipo de la cadena a codificar (ASN1_ETYPE_)
const unsigned char * der
la cadena codificada
unsigned int _der_len
los bytes de la cadena codificada
unsigned char ** str
un puntero a los datos
unsigned int * str_len
la longitud de los datos
unsigned int * ber_len
la longitud total ocupada por BER (puede ser NULL)

DESCRIPCIÓN

Decodifica un tipo codificado en BER. La salida es un valor asignado de los datos. Esto decodifica solo cadenas BER. Otros tipos se decodifican como DER.

RETORNA

ASN1_SUCCESS si tiene éxito o un valor de error.
