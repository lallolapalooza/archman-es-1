asin(3) Manual de funciones de biblioteca asin(3)

NOMBRE

asin, asinf, asinl - función arcoseno

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double asin(double x);
float asinf(float x);
long double asinl(long double x);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

asinf(), asinl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones calculan el valor principal del arcoseno de x; es decir, el valor cuyo seno es x.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor principal del arcoseno de x en radianes; el valor de retorno está en el rango [-pi/2, pi/2].

Si x es un NaN, se devuelve un NaN.

Si x es +0 (-0), se devuelve +0 (-0).

Si x está fuera del rango [-1, 1], ocurre un error de dominio y se devuelve un NaN.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x está fuera del rango [-1, 1]
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
asin (), asinf (), asinl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

VER TAMBIÉN

acos(3), atan(3), atan2(3), casin(3), cos(3), sin(3), tan(3)
