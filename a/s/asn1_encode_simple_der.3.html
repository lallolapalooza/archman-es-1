NOMBRE

asn1_encode_simple_der - función API

SINOPSIS

#include <libtasn1.h>

int asn1_encode_simple_der(unsigned int etype, const unsigned char * str, unsigned int str_len, unsigned char * tl, unsigned int * tl_len);

ARGUMENTOS

unsigned int etype
El tipo de cadena a codificar (ASN1_ETYPE_)
const unsigned char * str
los datos de la cadena.
unsigned int str_len
la longitud de la cadena
unsigned char * tl
la etiqueta y longitud codificadas
unsigned int * tl_len
los bytes del campo tl

DESCRIPCIÓN

Crea la codificación DER para varios tipos ASN.1 simples como cadenas, etc. Almacena la etiqueta y la longitud en tl , que debería tener espacio para al menos ASN1_MAX_TL_SIZE bytes. Inicialmente, tl_len debería contener el tamaño de tl .

La codificación DER completa debe consistir en el valor en tl añadido a str proporcionado.

RETORNOS

ASN1_SUCCESS si tiene éxito o un valor de error.
