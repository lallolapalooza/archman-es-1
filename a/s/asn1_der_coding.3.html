NOMBRE

asn1_der_coding - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_der_coding(asn1_node_const element, const char * name, void * ider, int * len, char * ErrorDescription);

ARGUMENTOS

asn1_node_const element
puntero a un elemento ASN1
const char * name
el nombre de la estructura que desea codificar (debe estar dentro de *POINTER).
void * ider
vector que contendrá la codificación DER. DER debe ser un puntero a celdas de memoria ya asignadas.
int * len
número de bytes de * ider : ider [0].. ider [len-1], Inicialmente contiene el tamaño del vector der.
char * ErrorDescription
devuelve la descripción del error o una cadena vacía si el éxito.

DESCRIPCION

Crea la codificación DER para la estructura NAME (dentro de la estructura *POINTER).

RETORNOS

ASN1_SUCCESS si la codificación DER es correcta, ASN1_ELEMENT_NOT_FOUND si name no es un elemento válido, ASN1_VALUE_NOT_FOUND si hay un elemento sin valor, ASN1_MEM_ERROR si el vector ider no es lo suficientemente grande y en este caso len contendrá la longitud necesaria.
