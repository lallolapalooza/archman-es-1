asn1_delete_element(3) libtasn1 asn1_delete_element(3)

NOMBRE

asn1_delete_element - Función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_delete_element(asn1_node estructura, const char * nombre_elemento);

ARGUMENTOS

asn1_node estructura
puntero a la estructura que contiene el elemento que deseas eliminar.
const char * nombre_elemento
nombre del elemento que deseas eliminar.

DESCRIPCIÓN

Elimina el elemento llamado * nombre_elemento dentro de * estructura .

RETORNOS

ASN1_SUCCESS si tiene éxito, ASN1_ELEMENT_NOT_FOUND si no se encontró el nombre_elemento .
