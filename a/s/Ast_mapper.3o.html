La interfaz de un reescribidor -ppx

Un reescribidor -ppx es un programa que acepta un árbol de sintaxis abstracta serializado y produce otro árbol de sintaxis abstracta, posiblemente modificado. Este módulo encapsula la interfaz entre el compilador y los reescribidores -ppx, manejando detalles como el formato de serialización, el reenvío de indicadores de la línea de comandos y el almacenamiento de estado.

Ast_mapper.mapper permite la reescritura de AST utilizando recursión abierta. Un mapper típico se basaría en Ast_mapper.default_mapper , un mapper de identidad profunda, y recurriría a él para manejar la sintaxis que no modifica. Por ejemplo:

open Asttypes
open Parsetree
open Ast_mapper
let test_mapper argv =
  { default_mapper with
    expr = fun mapper expr ->
      match expr with
      | { pexp_desc = Pexp_extension ({ txt = "test" }, PStr [])} ->
        Ast_helper.Exp.constant (Pconst_integer ("42", None))
      | other -> default_mapper.expr mapper other; }
let () =
  register "ppx_test" test_mapper

Este reescribidor -ppx, que reemplaza [%test] en expresiones con la constante 42 , se puede compilar usando ocamlc -o ppx_test -I +compiler-libs ocamlcommon.cma ppx_test.ml .

Advertencia: este módulo es inestable y forma parte de Compiler_libs .

Un registro mapper implementa un "método" por categoría sintáctica, utilizando un estilo de recursión abierta: cada método toma como primer argumento el mapper que se aplicará a los hijos en el árbol de sintaxis.

val default_mapper : mapper

Un mapper predeterminado, que implementa un mapeo de "identidad profunda".

Aplicar mappers a unidades de compilación

val tool_name : unit -> string

Se puede usar dentro de un preprocesador ppx para saber qué herramienta lo está llamando "ocamlc" , "ocamlopt" , "ocamldoc" , "ocamldep" , "ocaml" , ... Algunas variables globales que reflejan las opciones de la línea de comandos se sincronizan automáticamente entre la herramienta que llama y el preprocesador ppx: Clflags.include_dirs , Clflags.hidden_include_dirs , Load_path , Clflags.open_modules , Clflags.for_package , Clflags.debug .

val apply : source:string -> target:string -> mapper -> unit

Aplica un mapper (parametrizado por el nombre de la unidad) a un parsetree volcado que se encuentra en el archivo source y coloca el resultado en el archivo target . El campo structure o signature del mapper se aplica a la implementación o a la interfaz.

val run_main : (string list -> mapper) -> unit

Punto de entrada para llamar e implementar un reescribidor -ppx independiente a partir de un mapper, parametrizado por los argumentos de la línea de comandos. El nombre de la unidad actual se puede obtener desde Location.input_name . Esta función implementa un informe de errores adecuado para excepciones no capturadas.

API de registro

val register_function : (string -> (string list -> mapper) -> unit) ref

val register : string -> (string list -&gt; mapper) -> unit

Aplicar la register_function . El comportamiento predeterminado es ejecutar el mapper inmediatamente, tomando los argumentos de la línea de comandos del proceso. Esto es para soportar un escenario donde un mapper está vinculado como un ejecutable independiente.

Es posible sobrescribir la register_function para definir "ppx drivers", que combinan varios mappers en un solo proceso. Típicamente, un driver comienza definiendo register_function a una implementación personalizada, luego deja que los reescritores ppx (vinculados estática o dinámicamente) se registren por sí mismos, y luego ejecuta todos o algunos de ellos. También es posible que los drivers -ppx apliquen reescritores solo a partes específicas de un AST.

El primer argumento de register es un nombre simbólico que será usado por el driver ppx.

Funciones de conveniencia para escribir mappers

val map_opt : ('a -> 'b) -> 'a option -> 'b option

val extension_of_error : Location.error -> Parsetree.extension

Codifica un error en un nodo de extensión 'ocaml.error' que puede ser insertado en un Parsetree generado. El compilador será responsable de reportar el error.

val attribute_of_warning : Location.t -> string -> Parsetree.attribute

Codifica un mensaje de advertencia en un atributo 'ocaml.ppwarning' que puede ser insertado en un Parsetree generado. El compilador será responsable de reportar la advertencia.

Funciones auxiliares para llamar a mappers externos

val add_ppx_context_str : tool_name:string -> Parsetree.structure -> Parsetree.structure

Extrae información del entorno actual y la codifica en un atributo que se antepone a la lista de elementos de estructura para pasar la información a un procesador externo.

val add_ppx_context_sig : tool_name:string -> Parsetree.signature -> Parsetree.signature

Igual que add_ppx_context_str , pero para firmas.

val drop_ppx_context_str : restore:bool -> Parsetree.structure -> Parsetree.structure

Elimina el atributo ocaml.ppx.context de una estructura. Si restore es true, también restaura los datos asociados en el proceso actual.

val drop_ppx_context_sig : restore:bool -> Parsetree.signature -> Parsetree.signature

Igual que drop_ppx_context_str , pero para firmas.
