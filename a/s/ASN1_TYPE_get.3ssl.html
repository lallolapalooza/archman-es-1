ASN1_TYPE_get(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_TYPE_GET(3ssl) OpenSSL ASN1_TYPE_GET(3ssl)

NOMBRE

ASN1_TYPE_get, ASN1_TYPE_set, ASN1_TYPE_set1, ASN1_TYPE_cmp, ASN1_TYPE_unpack_sequence, ASN1_TYPE_pack_sequence - Funciones de utilidad ASN1_TYPE

SINOPSIS

#include <openssl/asn1.h>
int ASN1_TYPE_get(const ASN1_TYPE *a);
void ASN1_TYPE_set(ASN1_TYPE *a, int type, void *value);
int ASN1_TYPE_set1(ASN1_TYPE *a, int type, const void *value);
int ASN1_TYPE_cmp(const ASN1_TYPE *a, const ASN1_TYPE *b);
void *ASN1_TYPE_unpack_sequence(const ASN1_ITEM *it, const ASN1_TYPE *t);
ASN1_TYPE *ASN1_TYPE_pack_sequence(const ASN1_ITEM *it, void *s,
                                   ASN1_TYPE **t);

DESCRIPCIÓN

Estas funciones permiten manipular una estructura ASN1_TYPE. La estructura ASN1_TYPE puede contener cualquier tipo ASN.1 o tipo construido como una SECUENCIA: es efectivamente equivalente al tipo ANY de ASN.1.

ASN1_TYPE_get() devuelve el tipo de a o 0 si falla.

ASN1_TYPE_set() establece el valor de a a type y value. Esta función utiliza el puntero value internamente, por lo que no debe liberarse después de la llamada.

ASN1_TYPE_set1() establece el valor de a a type y una copia de value.

ASN1_TYPE_cmp() compara los tipos ASN.1 a y b y devuelve 0 si son idénticos y distinto de cero en caso contrario.

ASN1_TYPE_unpack_sequence() intenta analizar la SECUENCIA presente en t utilizando la estructura ASN.1 it. Si tiene éxito, devuelve un puntero a la estructura ASN.1 correspondiente a it que debe ser liberada por el llamador. Si falla, devuelve NULL.

ASN1_TYPE_pack_sequence() intenta codificar la estructura ASN.1 s correspondiente a it en un ASN1_TYPE. Si tiene éxito, se devuelve el ASN1_TYPE codificado. Si t y *t no son NULL, el tipo codificado se escribe en t sobrescribiendo cualquier dato existente. Si t no es NULL pero *t es NULL, el ASN1_TYPE devuelto se escribe en *t.

NOTAS

El tipo y el significado del parámetro value para ASN1_TYPE_set() y ASN1_TYPE_set1() están determinados por el parámetro type. Si type es V_ASN1_NULL, se ignora value. Si type es V_ASN1_BOOLEAN, el booleano se establece en TRUE si value no es NULL. Si type es V_ASN1_OBJECT, entonces value es una estructura ASN1_OBJECT. De lo contrario, type es una estructura ASN1_STRING. Si type corresponde a un tipo primitivo (o un tipo de cadena) entonces el contenido de ASN1_STRING contiene los octetos de contenido del tipo. Si type corresponde a un tipo construido o un tipo etiquetado (V_ASN1_SEQUENCE, V_ASN1_SET o V_ASN1_OTHER) entonces el ASN1_STRING contiene toda la codificación ASN.1 verbatim (incluyendo las etiquetas y los octetos de longitud).

ASN1_TYPE_cmp() puede no devolver cero si dos tipos son equivalentes pero tienen codificaciones diferentes. Por ejemplo, el octeto de contenido único del valor booleano TRUE bajo BER puede tener cualquier codificación distinta de cero, pero ASN1_TYPE_cmp() solo devolverá cero si los valores son los mismos.

Si uno o ambos de los parámetros pasados a ASN1_TYPE_cmp() son NULL, el valor de retorno es distinto de cero. Técnicamente, si ambos parámetros son NULL, los dos tipos podrían ser campos OPCIONALES ausentes y por lo tanto deberían coincidir, sin embargo, pasar valores NULL también podría indicar un error de programación (por ejemplo, un tipo no analizable que devuelve NULL) para tipos que no coinciden. Por lo tanto, las aplicaciones deben manejar el caso de dos valores ausentes por separado.

VALORES DE RETORNO

ASN1_TYPE_get() devuelve el tipo del argumento ASN1_TYPE.

ASN1_TYPE_set() no devuelve ningún valor.

ASN1_TYPE_set1() devuelve 1 en caso de éxito y 0 en caso de fallo.

ASN1_TYPE_cmp() devuelve 0 si los tipos son idénticos y distinto de cero en caso contrario.

ASN1_TYPE_unpack_sequence() devuelve un puntero a una estructura ASN.1 o NULL en caso de fallo.

ASN1_TYPE_pack_sequence() devuelve una estructura ASN1_TYPE si tiene éxito o NULL en caso de fallo.
