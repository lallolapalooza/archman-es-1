ADVERTENCIAS

Seguridad en hilos

Las cuatro funciones asctime(), ctime(), gmtime() y localtime() devuelven un puntero a datos estáticos y, por lo tanto, no son seguras para hilos. Las versiones seguras para hilos, asctime_r(), ctime_r(), gmtime_r() y localtime_r(), están especificadas por SUSv2.

POSIX.1 dice: "Las funciones asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de dos objetos estáticos: una estructura de tiempo desglosada y un array de tipo char. La ejecución de cualquiera de las funciones que devuelven un puntero a uno de estos tipos de objeto puede sobrescribir la información en cualquier objeto del mismo tipo al que apunte el valor devuelto por cualquier llamada anterior a cualquiera de ellas." Esto puede ocurrir en la implementación de glibc.

mktime()

(time_t) -1 puede representar un tiempo válido (un segundo antes de la Época). Para determinar si mktime() falló, se debe usar el campo tm->tm_wday. Ver el programa de ejemplo en EJEMPLOS.

El manejo de un tm_isdst no negativo en mktime() está pobremente especificado, y pasar un valor que es incorrecto para el tiempo especificado produce resultados no especificados. Dado que mktime() es una de las pocas funciones que sabe cuándo está vigente el horario de verano, proporcionar un valor correcto puede ser difícil. Una solución para esto es llamar a mktime() dos veces, una con tm_isdst establecido a cero y otra con tm_isdst establecido a un valor positivo, y descartar los resultados de la llamada que lo cambia. Si ninguna llamada cambia tm_isdst, entonces el tiempo especificado probablemente ocurre durante un período de retroceso donde el horario de verano comienza o termina, y ambos resultados son válidos pero representan dos tiempos diferentes. Si ambas llamadas lo cambian, eso podría indicar una transición de avance rápido, o alguna otra razón por la cual el tiempo especificado no existe.

La especificación de zonas horarias y horario de verano depende de los gobiernos regionales, cambia a menudo y puede incluir discontinuidades más allá de la capacidad de mktime para documentar un resultado. Por ejemplo, un cambio en la definición de la zona horaria puede hacer que una hora del reloj se repita o se salte sin un cambio correspondiente del horario de verano.

#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return t;
}

NOMBRE

asctime, asctime_r - convierte la hora en una cadena

SINOPSIS

#include <time.h>

char *asctime(const struct tm *tm);

char *asctime_r(const struct tm *tm, char *buf, size_t len);

DESCRIPCIÓN

La función asctime() convierte una estructura struct tm que representa un tiempo (generalmente obtenido de gmtime() o localtime()) en una cadena de 26 caracteres. La cadena tiene el siguiente formato:

Tue Feb 16 21:04:37 2016

Esta cadena es generada por el programa.

La función asctime_r() es la versión reentrante de asctime(). Los resultados se almacenan en el búfer proporcionado por el llamante.

VALOR DE RETORNO

En caso de éxito, asctime() devuelve un puntero a la cadena resultante. En caso de error, devuelve NULL.

asctime_r() devuelve un puntero a buf en caso de éxito. En caso de error, devuelve NULL.

ERRORES

La función asctime() puede fallar si la hora representada por tm está fuera de rango.

asctime_r() puede fallar si buf es NULL o si len es menor que el tamaño requerido para la cadena.

ESTÁNDARES

asctime() cumple con POSIX.1-2001 y POSIX.1-2008.

asctime_r() cumple con POSIX.1-2001 y POSIX.1-2008.

HISTORIAL

asctime() y asctime_r() aparecieron en la primera versión de UNIX.

ADVERTENCIAS

La cadena devuelta por asctime() se almacena en un búfer estático y puede ser sobrescrita por llamadas posteriores a otras funciones de la biblioteca que también devuelven cadenas de este tipo (como ctime(), gmtime() y localtime()). Si necesita conservar el resultado, cópielo en su propio búfer.

La función asctime_r() es preferible cuando la reentrancia es necesaria.

EJEMPLOS

A continuación se muestra un ejemplo de uso de asctime():

#include <stdio.h>
#include <time.h>

int main() {
    time_t t = time(NULL);
    struct tm tm = *localtime(&t);
    char *str = asctime(&tm);
    printf("La hora actual es: %s", str);
    return 0;
}
