ASCII-XFR(1) Manual de Usuarios de Linux ASCII-XFR(1)

NOMBRE

ascii-xfr - subir/descargar archivos usando el protocolo ASCII

SINOPSIS

ascii-xfr -s|-r [-ednv] [-l retrasodelinea] [-c retrasodecaracter] nombrearchivo

DESCRIPCIÓN

Ascii-xfr Transfiere archivos en modo ASCII. Esto significa que no hay control de flujo, ni sumas de verificación, ni negociación de nombres de archivo. Solo debe usarse si el sistema remoto no entiende nada más.

El protocolo ASCII transfiere archivos línea por línea. El carácter EOL (Fin de Línea) se transmite como CRLF. Al recibir, el carácter CR se elimina del archivo entrante. El carácter Control-Z (ASCII 26) señala el Fin de Archivo, si se especifica la opción -e (a menos que la cambie a Control-D (ASCII 4) con -d).

Ascii-xfr lee desde stdin al recibir, y envía datos en stdout al enviar. Por lo tanto, se necesita alguna forma de redirección de entrada o salida al dispositivo módem al descargar o cargar, respectivamente.

OPCIONES

-s
Enviar un archivo.
-r
Recibir un archivo. Se debe presentar una de las opciones -s o -r.
-e
Enviar el carácter Fin de Archivo (Control-Z, ASCII 26 por defecto) cuando la carga haya finalizado.
-d
Usar Control-D (ASCII 4) como carácter Fin de Archivo.
-n
No traducir CR a CRLF y viceversa.
-v
Verboso: mostrar estadísticas de transferencia en la salida de stderr.
-l milisegundos
Al transmitir, pausar por este retraso después de cada línea.
-c milisegundos
Al transmitir, pausar por este retraso después de cada carácter.
nombrearchivo
Nombre del archivo a enviar o recibir. Al recibir, cualquier archivo existente con este nombre será truncado.

USO CON MINICOM

Si desea llamar a este programa desde minicom(1), inicie minicom y vaya al menú Opciones. Seleccione *Protocolos de transferencia de archivos*. Agregue las siguientes líneas, por ejemplo, como protocolos I y J.

I  Ascii    /usr/bin/ascii-xfr -sv   Y   U   N   Y
J  Ascii    /usr/bin/ascii-xfr -rv   Y   D   N   Y
