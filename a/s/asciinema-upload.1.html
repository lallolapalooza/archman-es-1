NOMBRE

asciinema upload - Subir una grabación a un servidor de asciinema

SINOPSIS

asciinema upload [--server-url] [-q|--quiet] [-h|--help] <ARCHIVO>

DESCRIPCIÓN

Sube una grabación a un servidor de asciinema.

Toma un archivo de grabación de asciinema local y lo sube a un servidor de asciinema (ya sea asciinema.org o un servidor autoalojado), devolviendo una URL de grabación que se puede compartir públicamente.

OPCIONES

--server-url=URL
Especifica una URL de servidor de asciinema personalizada para subir a servidores autoalojados. Utiliza la URL base del servidor (por ejemplo, https://asciinema.example.com). También se puede configurar a través de la variable de entorno ASCIINEMA_SERVER_URL o la opción de archivo de configuración server.url. Si no se configura una URL de servidor a través de esta opción, la variable de entorno o el archivo de configuración, se le pedirá que elija una (por defecto será asciinema.org), que se guardará como predeterminada.
-q, --quiet
Suprime los mensajes de diagnóstico y los indicadores de progreso. Solo se mostrarán los mensajes de error.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
<ARCHIVO>
La ruta al archivo de grabación de asciinema que se va a subir, en un formato de asciinema compatible (v1, v2 o v3)
