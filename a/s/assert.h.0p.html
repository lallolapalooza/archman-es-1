assert.h(0P) Manual del programador POSIX assert.h(0P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

assert.h — verificar aserción del programa

SINOPSIS

#include <assert.h>

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La cabecera <assert.h> definirá la macro assert(). Hace referencia a la macro NDEBUG que no está definida en la cabecera. Si NDEBUG se define como un nombre de macro antes de la inclusión de esta cabecera, la macro assert() se definirá simplemente como:

#define assert(ignore)((void) 0)

De lo contrario, la macro se comporta como se describe en assert().

La macro assert() se redefinirá de acuerdo con el estado actual de NDEBUG cada vez que se incluya <assert.h>.

La macro assert() se implementará como una macro, no como una función. Si la definición de la macro se suprime para acceder a una función real, el comportamiento es indefinido.
