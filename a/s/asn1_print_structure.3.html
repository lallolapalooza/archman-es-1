asn1_print_structure(3) libtasn1 asn1_print_structure(3)

NOMBRE

asn1_print_structure - función de la API

SINOPSIS

#include <libtasn1.h>

void asn1_print_structure(FILE * out, asn1_node_const structure, const char * name, int mode);

ARGUMENTOS

FILE * out
puntero al archivo de salida (por ejemplo, stdout).
asn1_node_const structure
puntero a la estructura que desea visitar.
const char * name
un elemento de la estructura
int mode
especifica cuánto de la estructura imprimir, puede ser ASN1_PRINT_NAME, ASN1_PRINT_NAME_TYPE, ASN1_PRINT_NAME_TYPE_VALUE, o ASN1_PRINT_ALL.

DESCRIPCIÓN

Imprime en el descriptor de archivo out el árbol de la estructura comenzando desde el elemento name dentro de la estructura structure.
