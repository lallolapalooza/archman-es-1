asn1_read_node_value(3) libtasn1 asn1_read_node_value(3)

NOMBRE

asn1_read_node_value - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_read_node_value(asn1_node_const node, asn1_data_node_st * data);

ARGUMENTOS

asn1_node_const node
puntero a un nodo.
asn1_data_node_st * data
un puntero a un asn1_data_node_st

DESCRIPCIÓN

Devuelve el valor de un nodo de datos dentro de una estructura asn1_node. Los datos devueltos deben tratarse como valores constantes.

RETORNA

ASN1_SUCCESS si el nodo existe.
