asn1_read_tag(3)

asn1_read_tag(3) libtasn1 asn1_read_tag(3)

NOMBRE

asn1_read_tag - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_read_tag(asn1_node_const root, const char * name, int * tagValue, int * classValue);

ARGUMENTOS

asn1_node_const root
puntero a una estructura
const char * name
el nombre del elemento dentro de una estructura.
int * tagValue
variable que contendrá el valor de la ETIQUETA (TAG).
int * classValue
variable que especificará el tipo de ETIQUETA (TAG).

DESCRIPCIÓN

Devuelve la ETIQUETA (TAG) y la CLASE de un elemento dentro de una estructura. La CLASE puede tener una de las siguientes constantes: ASN1_CLASS_APPLICATION, ASN1_CLASS_UNIVERSAL, ASN1_CLASS_PRIVATE o ASN1_CLASS_CONTEXT_SPECIFIC.

RETORNOS

ASN1_SUCCESS si la operación fue exitosa, ASN1_ELEMENT_NOT_FOUND si
name no es un elemento válido.
