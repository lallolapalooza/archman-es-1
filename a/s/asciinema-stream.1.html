NOMBRE

asciinema-stream - Transmite una sesión de terminal

SINOPSIS

asciinema stream [-l|--local] [-r|--remote] [-c|--command] [-I|--capture-input] [--capture-env] [-t|--title] [--headless] [--window-size] [--return] [--log-file] [--server-url] [-q|--quiet] [-h|--help]

DESCRIPCIÓN

Transmite una sesión de terminal en tiempo real.

Transmite una sesión de terminal en vivo a través del servidor HTTP local (para visualización local/LAN) o un servidor asciinema remoto (para compartir públicamente). Los espectadores pueden ver la sesión mientras ocurre a través de una interfaz web.

Pulsa <ctrl+d> o escribe 'exit' para finalizar la sesión de transmisión. Pulsa <ctrl+\> para pausar/reanudar la captura de la sesión.

Durante la sesión, la variable de entorno ASCIINEMA_SESSION se establece con un ID de sesión único.

OPCIONES

-l, --local=IP:PUERTO
Inicia el servidor HTTP local para transmitir la sesión en tiempo real. Crea una interfaz web accesible a través del navegador donde los espectadores pueden ver la sesión de terminal en vivo. Opcionalmente especifica la dirección de enlace como IP:PUERTO (por ejemplo, 0.0.0.0:8080 para permitir conexiones externas). Si no se proporciona ninguna dirección, escucha en un puerto efímero asignado automáticamente en 127.0.0.1.
-r, --remote=ID-STREAM|URL-WS
Transmite la sesión a un servidor asciinema remoto para visualización pública. Esto permite compartir tu sesión en la web con cualquiera que tenga la URL de la transmisión. Puedes proporcionar un ID de stream de una configuración de stream existente en la cuenta de tu servidor asciinema, o una URL WebSocket directa (ws:// o wss://) para servidores personalizados. Omitir el valor para esta opción hace que el servidor asciinema asigne automáticamente un nuevo ID de stream.
-c, --command=COMANDO
Especifica el comando a ejecutar en la sesión de transmisión. Si no se proporciona, asciinema usará tu shell predeterminado de la variable de entorno $SHELL. Este puede ser cualquier comando con argumentos, por ejemplo: --command "python script.py" o --command "bash -l". También puede establecerse mediante la opción de archivo de configuración session.command.
-I, --capture-input
Habilita la grabación de la entrada del teclado además de la salida de la terminal. Cuando está habilitado, tanto lo que escribes como lo que aparece en la pantalla serán capturados. Ten en cuenta que la entrada sensible como contraseñas también será grabada cuando esta opción está habilitada. Si el servidor tiene habilitada la grabación de streams, la entrada del teclado se incluirá en el archivo de grabación creado en el lado del servidor. También puede establecerse mediante la opción de archivo de configuración session.capture_input.
--capture-env=VARS
Especifica qué variables de entorno capturar e incluir en los metadatos del stream. Proporciona una lista de nombres de variables separados por comas, por ejemplo: --rec-env "USER,SHELL,TERM". Si no se especifica, solo se captura la variable SHELL por defecto. Si el servidor tiene habilitada la grabación de streams, estas variables de entorno se incluirán en el archivo de grabación creado en el lado del servidor. También puede establecerse mediante la opción de archivo de configuración session.capture_env.
-t, --title=TÍTULO
Establece un título descriptivo para la sesión de transmisión. Este título se muestra a los espectadores (al hacer streaming remoto con --remote). Por ejemplo: --title "Construyendo una API REST". Si el servidor tiene habilitada la grabación de streams, el título se incluirá en el archivo de grabación creado en el lado del servidor.
--headless
Transmite en modo headless sin usar la terminal para entrada/salida. Esto es útil para transmisiones automatizadas o por script donde no quieres que asciinema interfiera con la sesión de terminal actual. El comando transmitido seguirá ejecutándose normalmente y será visible para los espectadores, pero no se mostrará en tu terminal local. El modo headless se habilita automáticamente al ejecutarse en un entorno donde no hay una terminal disponible.
--window-size=COLSxFILAS
Anula el tamaño de la ventana de la terminal utilizado para la sesión de transmisión. Especifica las dimensiones como COLSxFILAS (por ejemplo, 80x24 para 80 columnas por 24 filas). Puedes especificar solo columnas (80x) o solo filas (x24) para anular solo una dimensión. Esto es útil para asegurar dimensiones de transmisión consistentes independientemente del tamaño de tu terminal actual.
--return
Hace que el comando asciinema salga con el mismo código de estado que la sesión transmitida. Por defecto, asciinema sale con estado 0 sin importar lo que suceda en la sesión transmitida. Con esta opción, si el comando transmitido sale con un estado distinto de cero, asciinema también saldrá con ese mismo estado.
--log-file=RUTA
Habilita el registro de eventos internos en un archivo en la ruta especificada. Útil para depurar problemas de transmisión (errores de conexión, desconexiones, etc.).
--server-url=URL
Especifica una URL personalizada del servidor asciinema para transmitir a servidores autoalojados. Usa la URL base del servidor (por ejemplo, https://asciinema.example.com). También puede establecerse mediante la variable de entorno ASCIINEMA_SERVER_URL o la opción de archivo de configuración server.url. Si no se configura ninguna URL de servidor mediante esta opción, la variable de entorno o el archivo de configuración, se te pedirá elegir una (por defecto asciinema.org), que se guardará como predeterminada.
-q, --quiet
Suprime los mensajes de diagnóstico e indicadores de progreso. Solo se mostrarán los mensajes de error.
-h, --help
Imprime la ayuda (ver un resumen con '-h')

EXTRA

Ejemplos:


asciinema stream --local
Transmite una sesión de shell a través del servidor HTTP local escuchando en un puerto efímero en 127.0.0.1


asciinema stream --local 0.0.0.0:8080
Transmite a través del servidor HTTP local escuchando en el puerto 8080 en todas las interfaces de red


asciinema stream --remote
Transmite a través de un servidor asciinema para visualización pública


asciinema stream -l -r
Transmite tanto local como remotamente simultáneamente


asciinema stream -r --command "ping asciinema.org"
Transmite la ejecución del comando ping


asciinema stream -r <ID> -t "Programación en vivo"
Transmite a través de un servidor remoto, reutilizando el ID de stream existente y estableciendo el título del stream
