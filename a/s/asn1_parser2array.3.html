asn1_parser2array(3) libtasn1 asn1_parser2array(3)

NOMBRE

asn1_parser2array - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_parser2array(const char * inputFileName, const char * outputFileName, const char * vectorName, char * error_desc);

ARGUMENTOS

const char * inputFileName
especifica la ruta y el nombre del archivo que contiene las declaraciones ASN.1.
const char * outputFileName
especifica la ruta y el nombre del archivo que contendrá la definición del vector C.
const char * vectorName
especifica el nombre del vector C.
char * error_desc
devuelve la descripción del error o una cadena vacía si el éxito.

DESCRIPCIÓN

Función que genera una estructura C a partir de un archivo ASN1. Crea un archivo que contiene un vector C para usar en la gestión de las definiciones incluidas en el archivo inputFileName. Si inputFileName es "/aa/bb/xx.yy" y outputFileName es NULL, el archivo creado es "/aa/bb/xx_asn1_tab.c". Si vectorName es NULL, el nombre del vector será "xx_asn1_tab".

RETORNA

ASN1_SUCCESS si el archivo tiene una sintaxis correcta y cada identificador es conocido, ASN1_FILE_NOT_FOUND si ocurrió un error al abrir inputFileName, ASN1_SYNTAX_ERROR si la sintaxis no es correcta, ASN1_IDENTIFIER_NOT_FOUND si en el archivo hay un identificador que no está definido, ASN1_NAME_TOO_LONG si en el archivo hay un identificador con más de ASN1_MAX_NAME_SIZE caracteres.
