DESCRIPCIÓ

N

Las plantillas de estructuras de datos ASN.1 se definen típicamente en OpenSSL usando una serie de macros como ASN1_SEQUENCE(), ASN1_SEQUENCE_END() y así sucesivamente. En su lugar, las plantillas también pueden definirse basándose completamente en funciones externas. Estas funciones externas se llaman para realizar operaciones como crear un nuevo ASN1_VALUE o convertir un ASN1_VALUE a o desde una codificación

DER.

La macro IMPLEMENT_EXTERN_ASN1() puede usarse para crear una estructura definida externamente de este tipo. El nombre de la estructura debe proporcionarse en el parámetro sname. La etiqueta (tag) para la estructura (por ejemplo, típicamente V_ASN1_SEQUENCE) debe proporcionarse en el parámetro tag. Finalmente, un puntero a una estructura ASN1_EXTERN_FUNCS debe proporcionarse en el parámetro f

ptrs.

La estructura ASN1_EXTERN_FUNCS tiene las siguientes

entradas.

Una función "d2i" responsable de convertir datos DER con la etiqueta tag y la clase class en un ASN1_VALUE. Si *pval no es NULL, entonces el ASN_VALUE al que apunta debe reutilizarse. De lo contrario, debe asignarse un nuevo ASN1_VALUE y almacenarse en *pval. *in apunta a los datos DER a decodificar y len es la longitud de esos datos. Después de decodificar, *in debe actualizarse para apuntar al siguiente byte después de los datos decodificados. Si el ASN1_VALUE se considera opcional en este contexto, entonces opt será distinto de cero. De lo contrario, será cero. El parámetro it es un puntero al objeto plantilla ASN1_ITEM creado mediante la macro IMPLEMENT_EXTERN_ASN1(). Se pasa un puntero al contexto actual ASN1_TLC (que puede ser necesario para otras llamadas a funciones ASN1) en el parámetro ctx.

La entrada asn1_ex_d2i puede ser NULL si se ha especificado asn1_ex_d2i_ex en su

lugar.

asn1_ex_i
2d
Una función "i2d" responsable de convertir un ASN1_VALUE en una codificación DER. Al entrar, *pval contendrá el ASN1_VALUE a codificar. Si se va a usar la etiquetado por defecto, entonces tag será -1 al entrar. De lo contrario, si se debe usar etiquetado implícito, entonces tag y aclass serán la etiqueta y la clase asociada.

Si out no es NULL, entonces esta función debe escribir los datos codificados en DER en el búfer en *out, y luego incrementar *out para que apunte inmediatamente después de los datos recién

escritos.

Si out es NULL, entonces no se debe escribir ningún dato, pero se debe calcular y devolver la longitud como si se hubiera

escrito.

La entrada asn1_ex_i2d puede ser NULL si se ha especificado asn1_ex_i2d_ex en su

lugar.

El valor de retorno debe ser negativo si ocurrió un error fat

al, o 0 si ocurrió un error no fatal. De lo contrario
, debe devolver la longitud de los datos codificados.

nt
Una función "print". out es el BIO al que imprimir la salida. *pval es el ASN1_VALUE a imprimir. indent es el número de espacios de sangría a imprimir antes de imprimir cualquier dato. fname no se usa actualmente y siempre es "". pctx es un puntero al ASN1_PCTX para la operación de impresión.

Devuelve 0 en caso de error o un valor positivo en caso de éxito.

Si el valor de retorno es 2, se imprimirá una nueva línea
adicional después de los datos impresos por esta función.
