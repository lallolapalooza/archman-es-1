NOMBRE

aseqnet - Conectores de secuenciador ALSA sobre red

SINOPSIS

aseqnet [hostremoto]

DESCRIPCIÓN

aseqnet es un cliente de secuenciador ALSA que envía y recibe paquetes de eventos a través de la red. Supongamos dos hosts conectados por red, hostA como servidor y hostB como cliente. El sistema de secuenciador ALSA debe estar ejecutándose en ambos hosts. Para crear el puerto del servidor, ejecute lo siguiente en hostA:

hostA% aseqnet
secuenciador abierto: 128:0

Entonces se abrió un cliente de usuario 128 con puerto 0 en hostA. (El número de cliente puede variar). Para crear el puerto de cliente (de red), ejecute aseqnet con el nombre de host del servidor:

hostB% aseqnet hostA
secuenciador abierto: 132:0

Ahora todos los eventos enviados a hostA:128:0 se transfieren a hostB:132:0, y viceversa.

Los puertos creados por aseqnet se pueden conectar arbitrariamente a otros puertos de secuenciador a través de aconnect(1). Por ejemplo, para conectar hostB:132:0 a un dispositivo de salida MIDI 65:0:

hostB% aconnect 132:0 65:0

Entonces los eventos dirigidos a hostA:128:0 se entregarán a hostB:65:0. El siguiente comando reproduce MIDI en hostB.

hostA% pmidi -p 128:0 foo.mid

Pueden existir múltiples clientes simultáneamente. Si hostC se conecta como cliente a hostA, los eventos de hostA se envían a todos los clientes de red conectados, es decir, hostB y hostC. Sin embargo, solo se permite una conexión de un cliente a un servidor.

Para desconectar la red, detenga todos los clientes antes que el servidor con ctrl-C o enviando una señal a ellos. El servidor se cerrará automáticamente.

OPCIONES

-p puerto
Especifica el número de puerto TCP o el nombre de servicio TCP.
-s dir
Suscríbete a la dirección dada para leer automáticamente.
-d dir
Suscríbete a la dirección dada para escribir automáticamente.
-n nombre
Especifica el nombre MIDI del proceso.
-v
Modo detallado.

VER TAMBIÉN

aconnect(1), pmidi(1)
