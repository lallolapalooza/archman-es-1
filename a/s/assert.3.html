assert(3) Manual de Funciones de Biblioteca assert(3)

NOMBRE

assert - abortar el programa si la aserción es falsa

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <assert.h>
void assert(bool expresión);

DESCRIPCIÓN

Esta macro puede ayudar a los programadores a encontrar errores en sus programas, o manejar casos excepcionales mediante un fallo que producirá una salida de depuración limitada.

Si expresión es falsa (es decir, es igual a cero), assert() imprime un mensaje de error en la salida de error estándar y termina el programa llamando a abort(3). El mensaje de error incluye el nombre del archivo y la función que contiene la llamada assert(), el número de línea del código fuente de la llamada y el texto del argumento; algo similar a:


prog: some_file.c:16: some_func: Assertion `val == 0' failed.

Si la macro NDEBUG está definida en el momento en que <assert.h> fue incluida por última vez, la macro assert() no genera código y, por lo tanto, no hace nada en absoluto. No se recomienda definir NDEBUG si se utiliza assert() para detectar condiciones de error, ya que el software puede comportarse de forma no determinista.

VALOR DE RETORNO

No se devuelve ningún valor.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
assert () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C89, C99, POSIX.1-2001.

En C89, se requiere que expresión sea de tipo int y el comportamiento indefinido resulta si no lo es, pero en C99 puede tener cualquier tipo escalar.

ERRORES CONOCIDOS

assert() se implementa como una macro; si la expresión probada tiene efectos secundarios, el comportamiento del programa será diferente dependiendo de si NDEBUG está definido. Esto puede crear Heisenbugs que desaparecen cuando la depuración está activada.

VER TAMBIÉN

abort(3), assert_perror(3), exit(3)
