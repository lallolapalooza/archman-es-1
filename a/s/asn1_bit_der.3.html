NOMBRE

asn1_bit_der - función de la API

SINOPSIS

#include <libtasn1.h>

void asn1_bit_der(const unsigned char * str, int bit_len, unsigned char * der, int * der_len);

ARGUMENTOS

const unsigned char * str
Cadena de bits.
int bit_len
número de bits significativos en STR.
unsigned char * der
cadena devuelta.
int * der_len
número de bytes significativos de DER (der[0]..der[ans_len-1]).

DESCRIPCIÓN

Crea una codificación DER de longitud-valor para los datos de entrada como si fuera para una cadena de bits (BIT STRING). Los datos codificados en DER se copiarán en der.

Tenga en cuenta que la etiqueta BIT STRING no está incluida en la salida.

Esta función no devuelve ningún valor ya que se espera que der_len contenga suficientes bytes para almacenar la cadena más la codificación DER. El tamaño de la codificación DER se puede obtener usando asn1_length_der().
