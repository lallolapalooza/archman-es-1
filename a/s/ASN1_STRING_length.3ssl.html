ASN1_STRING_length(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_STRING_LENGTH(3ssl) OpenSSL ASN1_STRING_LENGTH(3ssl)

NOMBRE

ASN1_STRING_dup, ASN1_STRING_cmp, ASN1_STRING_set, ASN1_STRING_length, ASN1_STRING_type, ASN1_STRING_get0_data, ASN1_STRING_data, ASN1_STRING_to_UTF8 - funciones de utilidad ASN1_STRING

SINOPSIS

#include <openssl/asn1.h>
int ASN1_STRING_length(ASN1_STRING *x);
const unsigned char *ASN1_STRING_get0_data(const ASN1_STRING *x);
unsigned char *ASN1_STRING_data(ASN1_STRING *x);
ASN1_STRING *ASN1_STRING_dup(const ASN1_STRING *a);
int ASN1_STRING_cmp(ASN1_STRING *a, ASN1_STRING *b);
int ASN1_STRING_set(ASN1_STRING *str, const void *data, int len);
int ASN1_STRING_type(const ASN1_STRING *x);
int ASN1_STRING_to_UTF8(unsigned char **out, const ASN1_STRING *in);

DESCRIPCIÓN

Estas funciones permiten manipular una estructura ASN1_STRING.

ASN1_STRING_length() devuelve la longitud del contenido de x. x NO DEBE SER NULL.

ASN1_STRING_get0_data() devuelve un puntero interno a los datos de x. Dado que es un puntero interno, NO DEBE liberarse ni modificarse de ninguna manera. x NO DEBE SER NULL.

ASN1_STRING_data() es similar a ASN1_STRING_get0_data() excepto que el valor devuelto no es constante. Esta función está obsoleta: las aplicaciones deben usar ASN1_STRING_get0_data() en su lugar.

ASN1_STRING_dup() devuelve una copia de la estructura a.

ASN1_STRING_cmp() compara a y b y devuelve 0 si los dos son idénticos. Se comparan los tipos de cadena y el contenido.

ASN1_STRING_set() establece los datos de la cadena str en el búfer data o la longitud len. Los datos suministrados se copian. Si len es -1, la longitud se determina por strlen(data).

ASN1_STRING_type() devuelve el tipo de x, usando constantes estándar como V_ASN1_OCTET_STRING.

ASN1_STRING_to_UTF8() convierte la cadena in al formato UTF8; los datos convertidos se asignan en un búfer en *out. Se devuelve la longitud de out o un código de error negativo. El búfer *out debe liberarse usando OPENSSL_free().

NOTAS

Casi todos los tipos ASN1 en OpenSSL se representan como una estructura ASN1_STRING. Otros tipos como ASN1_OCTET_STRING son simplemente typedef a ASN1_STRING y las funciones llaman a los equivalentes de ASN1_STRING. ASN1_STRING también se usa para algunos tipos CHOICE que consisten enteramente en tipos de cadena primitivos como DirectoryString y Time.

Estas funciones NO DEBEN usarse para examinar o modificar tipos ASN1_INTEGER o ASN1_ENUMERATED: deben usarse las funciones de utilidad INTEGER o ENUMERATED relevantes en su lugar.

En general, no se puede asumir que los datos devueltos por ASN1_STRING_data() no terminan en nulo o no contienen nulos incrustados. El formato real de los datos dependerá del tipo de cadena en sí: por ejemplo, para una IA5String los datos serán ASCII, para una BMPString dos bytes por carácter en formato big endian, y para una UTF8String estará en formato UTF8.

Se debe tener cuidado similar para asegurar que los datos tengan el formato correcto al llamar a ASN1_STRING_set().

VALORES DE RETORNO

ASN1_STRING_length() devuelve la longitud del contenido de x.

ASN1_STRING_get0_data() y ASN1_STRING_data() devuelven un puntero interno a los datos de x.

ASN1_STRING_dup() devuelve una estructura ASN1_STRING válida o NULL si ocurrió un error.

ASN1_STRING_cmp() devuelve un entero mayor que, igual a, o menor que 0, según si a es mayor que, igual a, o menor que b.

ASN1_STRING_set() devuelve 1 si la operación fue exitosa o 0 en caso de error.

ASN1_STRING_type() devuelve el tipo de x.

ASN1_STRING_to_UTF8() devuelve el número de bytes en la cadena de salida out o un valor negativo si ocurrió un error.
