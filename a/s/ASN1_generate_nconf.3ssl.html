DESCRIPCIÓ

N

Estas funciones generan la codificación ASN1 de una cadena en una estructura ASN

1_TYPE.

str contiene la cadena a codificar. nconf o cnf contiene la información de configuración opcional desde la que se leerán cadenas adicionales. nconf normalmente provendrá de un archivo de configuración, mientras que cnf se obtiene de una estructura X509V3_CTX, que normalmente será utilizada por las funciones de extensión de certificados X509 v3. cnf o nconf pueden establecerse en NULL si no

se utilizará configur
ación adicional.

FORMATO DE CADENA DE

GENERACIÓN

Los datos reales codificados están determinados por la cadena str y la información de configuración. El formato general de la cadena

es:
[modificador,]tipo[:valo
r]

Es decir, cero o más modificadores separados por comas, seguidos de un tipo, seguido de dos puntos opcionales y un valor. Los formatos de tipo, valor y modificador se explican a

continuación.

Tipos

soportados

Los tipos soportados se enumeran a continuación. Las mayúsculas y minúsculas no son significativas en los nombres de tipo. Salvo que se especifique lo contrario, solo se permite el formato ASCII

.
BOOLEAN, BO
OL
Este codifica un tipo booleano. La cadena de valor es obligatoria y debería ser TRUE o FALSE. Adicionalmente TRUE, true, Y, y, YES, yes, FALSE, false, N, n, NO y no son
aceptables.
NU
LL
Codifica el tipo NULL, la cadena de valor no debe estar
presente.
INTEGER, IN
T
Codifica un tipo INTEGER ASN1. La cadena de valor representa el valor del entero, puede ir precedida por un signo menos y normalmente se interpreta como un valor decimal a menos que el prefijo 0x esté
incluido.
ENUMERATED, EN
UM
Codifica el tipo ENUMERATED ASN1, es idéntico a INTEGER en todo lo
demás.
OBJECT, OI
D
Codifica un IDENTIFICADOR DE OBJETO ASN1, la cadena de valor puede ser un nombre corto, un nombre largo o un formato
numérico.
UTCTIME, UT
C
Codifica una estructura UTCTime ASN1, el valor debería estar en el formato YYMMDDHHMMSS
Z.
GENERALIZEDTIME, GENTI
ME
Codifica una estructura GeneralizedTime ASN1, el valor debería estar en el formato YYYYMMDDHHM
MSSZ.
OCTETSTRING, OC
T
Codifica una CADENA DE OCTETOS ASN1. value representa el contenido de esta estructura, las cadenas de formato ASCII y HEX pueden usarse para especificar el formato de valu
e.
BITSTRING, BITS
TR
Codifica una CADENA DE BITS ASN1. value representa el contenido de esta estructura, las cadenas de formato ASCII, HEX y BITLIST pueden usarse para especificar el formato de value.

Si el formato es cualquier cosa distinta de BITLIST, el número de bits no utilizados se establece

en
cero.
UNIVERSALSTRING, UNIV, IA5, IA5STRING, UTF8, UTF8String, BMP, BMPSTRING, VISIBLESTRING, VISIBLE, PRINTABLESTRING, PRINTABLE, T61, T61STRING, TELETEXSTRING, GeneralString, NUMERICSTRING, NUMER
IC
Estos codifican los tipos de cadena correspondientes. value representa el contenido de esta estructura. El formato puede ser ASCII o UTF
8.
SEQUENCE, SEQ, SE
T
Formatea el resultado como un tipo SEQUENCE o SET ASN1. value debería ser un nombre de sección que contendrá el contenido. Los nombres de campo en la sección se ignoran y los valores están en el formato de cadena generado. Si value está ausente, s
e codificar
á una SEQU
ENCE vacía.

Modificadore

s

Los modificadores afectan a la estructura siguiente, pueden usarse para añadir etiquetado EXPLICIT o IMPLICIT, añadir envoltorios o cambiar el formato de cadena del tipo y valor finales. Los formatos soportados se documentan a

continuación.
EXPLICIT, EX
P
Añade una etiqueta explícita a la estructura siguiente. Esta cadena debería ir seguida de dos puntos y el valor de la etiqueta a usar como valor decimal.

Siguiendo al número con U, A, P o C se puede usar etiquetado UNIVERSAL, APPLICATION, PRIVATE o CON

TEXT SPECIFIC, el valor
por defecto es CONTEXT SPECIFIC.
IMPLICIT, IM
P
Esto es lo mismo que EXPLICIT excepto que se usa etiquetado IMPLICIT en su
lugar.
OCTWRAP, SEQWRAP, SETWRAP, BITWR
AP
La estructura siguiente está rodeada por una CADENA DE OCTETOS, una SEQUENCE, una SET o una CADENA DE BITS respectivamente. Para una CADENA DE BITS el número de bits no utilizados se establece en
cero.
FORM
AT
Esto especifica el formato del valor final. Debería ir seguido de dos puntos y una de las cadenas ASCII, UTF8, HEX o BITLIST.

Si no se incluye ningún especificador de formato, se usa ASCII. Si se especifica UTF8, la cadena de valor debe ser una cadena UTF8 válida. Para HEX la salida debe ser un conjunto de dígitos hexadecimales. BITLIST (que solo es válido para una CADENA DE BI

TS) es una lista
separada por comas de l
os índices de los bits e
stablecidos, todos los de
más bits son cero.

VALORES DE

RETORNO

ASN1_generate_nconf() y ASN1_generate_v3() devuelven los datos codificados como una estructura ASN1_TYPE o NULL si ocurrió un

error.

Los códigos de error que se pueden obtener mediante ERR_get_

error
(3).
