asteroide - cliente de correo electrónico gráfico, ligero y rápido, estilo hilos-con-etiquetas, para Notmuchasteroide [opciones]Asteroide es un agente de usuario de correo electrónico (Mail User Agent) ligero y rápido que proporciona una interfaz gráfica para buscar, mostrar y componer correos electrónicos, organizados en hilos y etiquetas. Utiliza el backend de Notmuch para búsquedas ultrarrápidas a través de toneladas de correos electrónicos.-c, --config config Anula la ruta de configuración predeterminada. Consulte la sección CONFIGURACIÓN para obtener más detalles.

--disable-log Deshabilita el registro.

-h, --help Muestra el mensaje de ayuda y sale.

--log-level level Anula el nivel de registro configurado. Las opciones de nivel son: trace, debug (predeterminado), info, warn, error y fatal.

--log-stdout Envía los registros a la salida estándar, sin tener en cuenta ninguna otra configuración de registro.

-m, --mailto dest Abre la ventana de composición, enviando a la URL o dirección dest.

-n, --new-config Genera un nuevo archivo de configuración y sale.

--no-auto-poll Deshabilita la consulta automática.

--refresh revision Actualiza la vista del usuario de una instancia de asteroide en ejecución con cualquier cambio detectado en el directorio de correo desde la revisión. Puede obtener la revisión actual con notmuch count --lastmod | cut -f3 (0 actualizará todos los índices de hilos). Se puede usar --{start,stop}-polling como una *alternativa*, pero no con --refresh.

--start-polling Hace que una instancia de asteroide en ejecución vigile los cambios en el directorio de correo y muestre un indicador de sondeo. Se debe llamar a --stop-polling al final del sondeo externo (por ejemplo, con offlineimap) *incluso si falla*. Se puede usar --refresh como una *alternativa*, pero no con --{start,stop}-polling.

--stop-polling Detiene el sondeo iniciado por --start-polling y actualiza la vista del usuario con cualquier cambio detectado desde que se ejecutó --start-polling.

-t, --test-config Usa el archivo de configuración de prueba. Solo tiene sentido desde la raíz de origen.

--disable-plugins Deshabilita todos los complementos.La ubicación del archivo de configuración predeterminada es $XDG_CONFIG_HOME/astroid/config. La forma preferida de configurar una nueva instalación de asteroide es usar --new-config para generar un archivo de configuración inicial, luego editarlo para que coincida con las necesidades del usuario. Encontrará todos los detalles en la documentación en línea de Astroid: https://github.com/astroidmail/astroid/wiki. Si $NOTMUCH_CONFIG está configurado, tiene prioridad sobre el valor configurado para la base de datos de notmuch en el archivo de configuración.

Puede personalizar la vista de hilos colocando sus propios archivos HTML y SCSS en $XDG_CONFIG_HOME/astroid/ui/, como se explica en https://github.com/astroidmail/astroid/wiki/Customizing-the-user-interface.

Si $XDG_CONFIG_HOME no está configurado, se predetermina a ~/.config.Astroid es un *agente de usuario de correo electrónico* (Mail User Agent): todo lo que Astroid proporciona es una interfaz gráfica para su correo electrónico (leer, ver, escribir, modificar, organizar). Por lo tanto, Astroid le permite lanzar acciones que dependen del rendimiento de otros programas para recuperar, sincronizar, indexar, buscar y enviar su correo electrónico. Depende de Notmuch para la indexación y búsqueda, pero otras acciones pueden ser gestionadas por muchos programas diferentes:

  • La recuperación y sincronización de su correo electrónico entre su ordenador local y el proveedor de servicios de correo electrónico puede ser gestionada por cualquier programa que soporte el formato Maildir:
  • OfflineIMAP
  • mbsync
  • Gmailleer
  • ...
  • El envío de correos electrónicos a través de su proveedor de correo electrónico puede ser gestionado por cualquier programa compatible con sendmail:
  • msmtp
  • ...
  • La edición puede ser gestionada por casi cualquier editor:
  • vim
  • emacs
  • gedit
  • ...

Si bien todos estos programas (o programas equivalentes) deben ser configurados; una vez que estén configurados, no debería tener que pensar en ellos más allá de usar astroid. Las opciones de configuración pueden ser más o menos tediosas y complicadas, dependiendo del proveedor de servicios de correo electrónico que utilice.Mantenido por Gaute Hope eg@gaute.vetsj.com, quien está asistido por otros colaboradores de código abierto.
