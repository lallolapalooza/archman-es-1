ASN1_STRING_TABLE_add(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_STRING_TABLE_ADD(3ssl) OpenSSL ASN1_STRING_TABLE_ADD(3ssl)

NOMBRE

ASN1_STRING_TABLE, ASN1_STRING_TABLE_add, ASN1_STRING_TABLE_get, ASN1_STRING_TABLE_cleanup - funciones de manipulación de ASN1_STRING_TABLE

SINOPSIS

#include <openssl/asn1.h>
typedef struct asn1_string_table_st ASN1_STRING_TABLE;
int ASN1_STRING_TABLE_add(int nid, long minsize, long maxsize,
                          unsigned long mask, unsigned long flags);
ASN1_STRING_TABLE *ASN1_STRING_TABLE_get(int nid);
void ASN1_STRING_TABLE_cleanup(void);

DESCRIPCIÓN

Tipos

ASN1_STRING_TABLE es una tabla que almacena información de cadena (básicamente tamaño mínimo, tamaño máximo, tipo, etc.) para un objeto NID.

Funciones

ASN1_STRING_TABLE_add() añade un nuevo elemento ASN1_STRING_TABLE a la tabla de cadenas ASN1 local basándose en el nid junto con otros parámetros.

Si el elemento ya está en la tabla, los campos de ASN1_STRING_TABLE se actualizan (dependiendo de los valores de esos parámetros, por ejemplo, minsize y maxsize >= 0, mask y flags != 0). Si el nid es estándar, se crea una copia del ASN1_STRING_TABLE estándar y se actualiza con otros parámetros.

ASN1_STRING_TABLE_get() busca un elemento ASN1_STRING_TABLE basándose en el nid. Buscará primero en la tabla local, luego en la estándar.

ASN1_STRING_TABLE_cleanup() libera todos los elementos ASN1_STRING_TABLE añadidos por ASN1_STRING_TABLE_add().

VALORES DE RETORNO

ASN1_STRING_TABLE_add() devuelve 1 si tiene éxito, 0 si ocurrió un error.

ASN1_STRING_TABLE_get() devuelve una estructura ASN1_STRING_TABLE válida o NULL si no se encuentra nada.

ASN1_STRING_TABLE_cleanup() no devuelve ningún valor.
