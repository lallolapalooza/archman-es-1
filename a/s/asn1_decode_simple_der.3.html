NOMBRE

asn1_decode_simple_der - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_decode_simple_der(unsigned int etype, const unsigned char * der, unsigned int _der_len, const unsigned char ** str, unsigned int * str_len);

ARGUMENTOS

unsigned int etype
el tipo de la cadena a codificar (ASN1_ETYPE_)
const unsigned char * der
la cadena codificada
unsigned int _der_len
los bytes de la cadena codificada
const unsigned char ** str
un puntero a los datos
unsigned int * str_len
la longitud de los datos

DESCRIPCIÓN

Decodifica un tipo simple codificado en DER (por ejemplo, una cadena, que no es construida). La salida es un puntero dentro de der.

RETORNOS

ASN1_SUCCESS si tiene éxito o un valor de error.
