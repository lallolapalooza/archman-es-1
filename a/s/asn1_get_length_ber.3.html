asn1_get_length_ber(3) libtasn1 asn1_get_length_ber(3)

NOMBRE

asn1_get_length_ber - función de la API

SINOPSIS

#include <libtasn1.h>

long asn1_get_length_ber(const unsigned char * ber, int ber_len, int * len);

ARGUMENTOS

const unsigned char * ber
Datos BER para decodificar.
int ber_len
Longitud de los datos BER a decodificar.
int * len
Variable de salida que contiene la longitud del campo de longitud BER.

DESCRIPCIÓN

Extrae un campo de longitud de datos BER. La diferencia con asn1_get_length_der() es que esta función devolverá una longitud incluso si el valor tiene una codificación indefinida.

VALOR DEVUELTO

Devuelve el valor de longitud decodificado, o un valor negativo cuando el valor era demasiado grande.
