NOMBRE

asn1_object_id_der - función de API

SINOPSIS

#include <libtasn1.h>

int asn1_object_id_der(const char * str, unsigned char * der, int * der_len, unsigned flags);

ARGUMENTOS

const char * str
Un identificador de objeto en formato numérico, punto.
unsigned char * der
buffer para contener la codificación devuelta (puede ser NULL).
int * der_len
inicialmente el tamaño de der; contendrá el tamaño final.
unsigned flags
debe ser cero

DESCRIPCIÓN

Crea la codificación DER del identificador de objeto proporcionado.

RETORNOS

ASN1_SUCCESS si la codificación DER fue correcta, ASN1_VALUE_NOT_VALID si str no es un OID válido, ASN1_MEM_ERROR si el vector der no es lo suficientemente grande y en este caso der_len contendrá la longitud necesaria.
