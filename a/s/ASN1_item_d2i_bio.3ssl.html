ASN1_item_d2i_bio(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_ITEM_D2I_BIO(3ssl) OpenSSL ASN1_ITEM_D2I_BIO(3ssl)

NOMBRE

ASN1_item_d2i_ex, ASN1_item_d2i, ASN1_item_d2i_bio_ex, ASN1_item_d2i_bio, ASN1_item_d2i_fp_ex, ASN1_item_d2i_fp, ASN1_item_i2d_mem_bio, ASN1_item_pack, ASN1_item_unpack_ex, ASN1_item_unpack - decodifica y codifica estructuras ASN.1 codificadas en DER

SINOPSIS

#include <openssl/asn1.h>
ASN1_VALUE *ASN1_item_d2i_ex(ASN1_VALUE **pval, const unsigned char **in,
                             long len, const ASN1_ITEM *it,
                             OSSL_LIB_CTX *libctx, const char *propq);
ASN1_VALUE *ASN1_item_d2i(ASN1_VALUE **pval, const unsigned char **in,
                          long len, const ASN1_ITEM *it);
void *ASN1_item_d2i_bio_ex(const ASN1_ITEM *it, BIO *in, void *x,
                           OSSL_LIB_CTX *libctx, const char *propq);
void *ASN1_item_d2i_bio(const ASN1_ITEM *it, BIO *in, void *x);
void *ASN1_item_d2i_fp_ex(const ASN1_ITEM *it, FILE *in, void *x,
                          OSSL_LIB_CTX *libctx, const char *propq);
void *ASN1_item_d2i_fp(const ASN1_ITEM *it, FILE *in, void *x);
BIO *ASN1_item_i2d_mem_bio(const ASN1_ITEM *it, const ASN1_VALUE *val);
ASN1_STRING *ASN1_item_pack(void *obj, const ASN1_ITEM *it, ASN1_STRING **oct);
void *ASN1_item_unpack(const ASN1_STRING *oct, const ASN1_ITEM *it);
void *ASN1_item_unpack_ex(const ASN1_STRING *oct, const ASN1_ITEM *it,
                         OSSL_LIB_CTX *libctx, const char *propq);

DESCRIPCIÓN

ASN1_item_d2i_ex() decodifica el contenido de los datos almacenados en *in de longitud len, que debe ser una estructura ASN.1 codificada en DER, utilizando la plantilla ASN.1 it. Coloca el resultado en *pval a menos que pval sea NULL. Si *pval no es NULL al inicio, entonces se reutilizará el ASN1_VALUE presente. De lo contrario, se asignará un nuevo ASN1_VALUE. Si se requieren búsquedas de algoritmos durante el proceso, utilizarán el OSSL_LIB_CTX proporcionado en el parámetro libctx y la cadena de consulta de propiedades en propq. Consulte "ALGORITHM FETCHING" en crypto(7) para más información sobre la búsqueda de algoritmos. Al salir, *in se actualizará para apuntar al siguiente byte en el búfer después de la estructura decodificada.

ASN1_item_d2i() es lo mismo que ASN1_item_d2i_ex() excepto que se utiliza el OSSL_LIB_CTX por defecto (es decir, NULL) y con una cadena de consulta de propiedades NULL.

ASN1_item_d2i_bio_ex() decodifica el contenido de su BIO de entrada in, que debe ser una estructura ASN.1 codificada en DER, utilizando la plantilla ASN.1 it y coloca el resultado en *pval a menos que pval sea NULL. Si in es NULL, devuelve NULL, de lo contrario, un puntero a la estructura analizada. Si se requieren búsquedas de algoritmos durante el proceso, utilizarán el OSSL_LIB_CTX proporcionado en el parámetro libctx y la cadena de consulta de propiedades en propq. Consulte "ALGORITHM FETCHING" en crypto(7) para más información sobre la búsqueda de algoritmos.

ASN1_item_d2i_bio() es lo mismo que ASN1_item_d2i_bio_ex() excepto que se utiliza el OSSL_LIB_CTX por defecto (es decir, NULL) y con una cadena de consulta de propiedades NULL.

ASN1_item_d2i_fp_ex() es lo mismo que ASN1_item_d2i_bio_ex() excepto que se proporciona un puntero FILE en lugar de un BIO.

ASN1_item_d2i_fp() es lo mismo que ASN1_item_d2i_fp_ex() excepto que se utiliza el OSSL_LIB_CTX por defecto (es decir, NULL) y con una cadena de consulta de propiedades NULL.

ASN1_item_i2d_mem_bio() codifica el valor ASN.1 dado val utilizando la plantilla ASN.1 it y devuelve el resultado en un BIO de memoria.

ASN1_item_pack() codifica el valor ASN.1 dado en obj utilizando la plantilla ASN.1 it y devuelve un objeto ASN1_STRING. Si el pasado *oct no es NULL, se utiliza para almacenar el resultado devuelto, de lo contrario, se crea un nuevo objeto ASN1_STRING. Si oct no es NULL y *oct es NULL, el resultado devuelto también se establece en *oct. Si hay un error, el ASN1_STRING opcional pasado no se liberará, pero el valor anterior puede ser borrado cuando ASN1_STRING_set0(*oct, NULL, 0) se llama internamente.

ASN1_item_unpack() utiliza ASN1_item_d2i() para decodificar el ASN1_STRING oct codificado en DER utilizando la plantilla ASN.1 it.

ASN1_item_unpack_ex() es similar a ASN1_item_unpack(), pero utiliza ASN1_item_d2i_ex() para que libctx y propq puedan ser utilizados al realizar la búsqueda de algoritmos.

VALORES DE RETORNO

ASN1_item_d2i_bio(), ASN1_item_unpack_ex() y ASN1_item_unpack() devuelven un puntero a un ASN1_VALUE o NULL en caso de error.

ASN1_item_i2d_mem_bio() devuelve un puntero a un BIO de memoria o NULL en caso de error.

ASN1_item_pack() devuelve un puntero a un ASN1_STRING o NULL en caso de error.

HISTORIA

Las funciones ASN1_item_d2i_ex(), ASN1_item_d2i_bio_ex(), ASN1_item_d2i_fp_ex() y ASN1_item_i2d_mem_bio() se añadieron en OpenSSL 3.0.

La función ASN1_item_unpack_ex() se añadió en OpenSSL 3.2.
