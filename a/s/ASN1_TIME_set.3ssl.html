Se recomienda que se utilicen funciones que comiencen con ASN1_TIME en lugar de aquellas que comienzan con ASN1_UTCTIME o
    ASN1_GENERALIZEDTIME. Las funciones que comienzan con ASN1_UTCTIME
    y ASN1_GENERALIZEDTIME actúan solo sobre ese formato de tiempo específico. Las
    funciones que comienzan con ASN1_TIME operarán en cualquiera de los dos formatos.


Los usuarios familiarizados con RFC822 deben tener en cuenta que al especificar el
    indicador ASN1_DTFLGS_RFC822 el año se formateará como se documenta
    arriba, es decir, usando 4 dígitos, no 2 como se especifica en RFC822.






ERRORES


ASN1_TIME_print(), ASN1_UTCTIME_print() y
    ASN1_GENERALIZEDTIME_print() no imprimen la zona horaria: imprimen
    "GMT" o nada. Pero todos los certificados que cumplen con
    RFC5280 etc. usan GMT de todos modos.


ASN1_TIME_print(), ASN1_TIME_print_ex(),
    ASN1_UTCTIME_print() y ASN1_GENERALIZEDTIME_print() no
    distinguen si fallan debido a un error de E/S o a un formato de tiempo inválido.


Utilice la función ASN1_TIME_normalize() para normalizar el
    valor de tiempo antes de imprimirlo para obtener resultados en GMT.






VALORES DE RETORNO


ASN1_TIME_set(), ASN1_UTCTIME_set(),
    ASN1_GENERALIZEDTIME_set(), ASN1_TIME_adj(),
    ASN1_UTCTIME_adj() y ASN1_GENERALIZEDTIME_set() devuelven un
    puntero a una estructura de tiempo o NULL si ocurrió un error.


ASN1_TIME_set_string(), ASN1_UTCTIME_set_string(),
    ASN1_GENERALIZEDTIME_set_string() y
    ASN1_TIME_set_string_X509() devuelven 1 si el valor de tiempo se
    establece correctamente y 0 en caso contrario.


ASN1_TIME_normalize() devuelve 1 en caso de éxito y 0 en
  caso de error.


ASN1_TIME_check(), ASN1_UTCTIME_check y
    ASN1_GENERALIZEDTIME_check() devuelven 1 si la estructura es
    sintácticamente correcta y 0 en caso contrario.


ASN1_TIME_print(), ASN1_UTCTIME_print() y
    ASN1_GENERALIZEDTIME_print() devuelven 1 si el tiempo se imprime
    correctamente y 0 si ocurrió un error (error de E/S o
    formato de tiempo inválido).


ASN1_TIME_to_tm() devuelve 1 si el tiempo se analiza
    correctamente y 0 si ocurrió un error (formato de tiempo inválido).


ASN1_TIME_diff() devuelve 1 para éxito y 0 para fallo.
    Puede fallar si la estructura de tiempo pasada tiene una sintaxis inválida, por
  ejemplo.


ASN1_TIME_cmp_time_t() y ASN1_UTCTIME_cmp_time_t()
    devuelven -1 si s es anterior a t, 0 si s es igual a t, o
    1 si s es posterior a t. Se devuelve -2 en caso de error.


ASN1_TIME_compare() devuelve -1 si a es anterior a
    b, 0 si a es igual a b, o 1 si a es posterior a b.
    Se devuelve -2 en caso de error.


ASN1_TIME_to_generalizedtime() devuelve un puntero a la
    estructura de tiempo apropiada en caso de éxito o NULL si ocurrió un error.


ASN1_TIME_dup(), ASN1_UTCTIME_dup() y
    ASN1_GENERALIZEDTIME_dup() devuelven un puntero a una estructura de tiempo o
    NULL si ocurrió un error.






EJEMPLOS


Establecer una estructura de tiempo en una hora después de la hora actual e imprimirla:


#include <time.h>
#include <openssl/asn1.h>
ASN1_TIME *tm;
time_t t;
BIO *b;
t = time(NULL);
tm = ASN1_TIME_adj(NULL, t, 0, 60 * 60);
b = BIO_new_fp(stdout, BIO_NOCLOSE);
ASN1_TIME_print(b, tm);
ASN1_STRING_free(tm);
BIO_free(b);


Determinar si una hora es posterior o anterior a la hora
  actual:


int day, sec;
if (!ASN1_TIME_diff(&day, &sec, NULL, to))
    /* Invalid time format */
if (day > 0 || sec > 0)
    printf("Later\n");
else if (day < 0 || sec < 0)
    printf("Sooner\n");
else
    printf("Same\n");
