NOMBRE

asn1_parser2tree - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_parser2tree(const char * file, asn1_node * definitions, char * error_desc);

ARGUMENTOS

const char * file
especifica la ruta y el nombre del archivo que contiene las declaraciones ASN.1.
asn1_node * definitions
devuelve el puntero a la estructura creada a partir de las declaraciones ASN.1 de "file".
char * error_desc
devuelve la descripción del error o una cadena vacía si el éxito.

DESCRIPCIÓN

Función utilizada para iniciar el algoritmo de análisis. Crea las estructuras necesarias para gestionar las definiciones incluidas en el archivo file.

DEVUELVE

ASN1_SUCCESS si el archivo tiene una sintaxis correcta y todos los identificadores son conocidos, ASN1_ELEMENT_NOT_EMPTY si definitions no es NULL, ASN1_FILE_NOT_FOUND si se produjo un error al abrir file, ASN1_SYNTAX_ERROR si la sintaxis no es correcta, ASN1_IDENTIFIER_NOT_FOUND si en el archivo hay un identificador que no está definido, ASN1_NAME_TOO_LONG si en el archivo hay un identificador con más de ASN1_MAX_NAME_SIZE caracteres.
