asn1_get_octet_der(3) libtasn1 asn1_get_octet_der(3)

NOMBRE

asn1_get_octet_der - función de API

SINOPSIS

#include <libtasn1.h>

int asn1_get_octet_der(const unsigned char * der, int der_len, int * ret_len, unsigned char * str, int str_size, int * str_len);

ARGUMENTOS

const unsigned char * der
Datos DER a decodificar que contienen la SECUENCIA DE OCTETOS.
int der_len
La longitud de los datos der a decodificar.
int * ret_len
Variable de salida que contiene la longitud codificada de los datos DER.
unsigned char * str
Búfer de salida preasignado para colocar la SECUENCIA DE OCTETOS decodificada.
int str_size
Longitud del búfer de salida preasignado.
int * str_len
Variable de salida que contiene la longitud del contenido de la SECUENCIA DE OCTETOS.

DESCRIPCIÓN

Extrae una SECUENCIA DE OCTETOS de datos DER. Tenga en cuenta que esta función espera los datos DER después del campo de etiqueta, es decir, los octetos de longitud y contenido.

RETORNA

Devuelve ASN1_SUCCESS si la operación tiene éxito, o un error.
