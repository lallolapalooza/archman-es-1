NOMBRE

asdlgen - compilador del Lenguaje de Descripción de Sintaxis Abstracta (ASDL).

SINOPSIS

asdlgen COMANDO [ OPCIONES ] ARCHIVO ...

donde COMANDO es uno de los siguientes:

help

imprime información sobre las opciones disponibles en la salida estándar.

version

imprime la versión de asdlgen en la salida estándar.

c++ o cxx

genera código C++.

sml

genera código SML.

check

comprueba la corrección de las especificaciones de entrada, pero no genera salida.

DESCRIPCIÓN

Asdlgen lee los archivos especificados, que deben contener declaraciones de módulos y vistas ASDL, y produce código de serialización (pickling) y deserialización (unpickling).

OPCIONES

OPCIONES COMUNES

-n

No escriba ningún archivo de salida. En su lugar, escriba la lista de archivos que se habrían escrito en la salida estándar.

-d DIR, --output-directory=DIR

Especifique el directorio de salida donde se colocarán los archivos generados. Por defecto, la salida se colocará en el mismo directorio que el archivo de entrada del que se produjo.

--gen=NOMBRES

Especifica los componentes a generar, donde NOMBRES es una lista separada por comas de nombres tomados de lo siguiente:
•types — genera las definiciones de tipos a partir de la especificación ASDL.
•memory — genera el serializador de memoria.
•file — genera el serializador de archivos.
•sexp — genera el serializador de Expresiones S (solo SML).

OPCIONES C++

--base-include=ARCHIVO

Especifique el nombre del archivo de encabezado C++ que define los tipos y funciones primitivos ASDL. El valor predeterminado es asdl/asdl.hxx.

OPCIONES SML

--cm=ARCHIVO

Genera un archivo CM para el serializador; esto definirá una biblioteca CM. Tenga en cuenta que si la especificación ASDL incluye módulos primitivos, estos se incluirán en la lista de estructuras exportadas, pero los archivos fuente de soporte deberán agregarse al archivo CM manualmente.

--mlb=ARCHIVO

Genera un archivo MLB para el serializador. Tenga en cuenta que si la especificación ASDL incluye módulos primitivos, estos se incluirán en la lista de estructuras exportadas, pero los archivos fuente de soporte deberán agregarse al archivo MLB manualmente.
