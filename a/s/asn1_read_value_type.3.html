asn1_read_value_type(3)

Licencias: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_read_value_type(3) libtasn1 asn1_read_value_type(3)

NOMBRE

asn1_read_value_type - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_read_value_type(asn1_node_const root, const char * name, void * ivalue, int * len, unsigned int * etype);

ARGUMENTOS

asn1_node_const root
puntero a una estructura.
const char * name
el nombre del elemento dentro de una estructura que deseas leer.
void * ivalue
vector que contendrá el contenido del elemento, debe ser un puntero a celdas de memoria ya asignadas (puede ser NULL).
int * len
número de bytes de *value: value[0]..value[len-1]. Inicialmente contiene el tamaño de value.
unsigned int * etype
El tipo del valor leído (ASN1_ETYPE)

DESCRIPCIÓN

Devuelve el tipo y valor de un elemento dentro de una estructura. Si un elemento es OPCIONAL y esto devuelve ASN1_ELEMENT_NOT_FOUND, significa que este elemento no estaba presente en la codificación DER que creó la estructura. El primer elemento de un SEQUENCE_OF o SET_OF se llama "?1". El segundo "?2" y así sucesivamente. Si el root proporcionado es un nodo para un elemento de secuencia específico, entonces la palabra clave "?CURRENT" también es aceptable e indica el elemento de secuencia actual de este nodo.

Tenga en cuenta que puede haber valores válidos con longitud cero. En esos casos, esta función tendrá éxito y len será cero.

INTEGER

VALUE contendrá un entero en formato de complemento a dos.

entero=-1 -> value[0]=0xFF , len=1. entero=1 -> value[0]=0x01 , len=1.

ENUMERATED

Como INTEGER (pero solo con números no negativos).

BOOLEAN

VALUE será la cadena terminada en nulo "TRUE" o "FALSE" y LEN=5 o LEN=6.

IDENTIFICADOR DE OBJETO: VALUE será una cadena terminada en nulo con cada número separado por un punto (es decir, "1.2.3.543.1").

LEN = strlen(VALUE)+1

UTCTIME

VALUE será una cadena terminada en nulo en uno de estos formatos: "YYMMDDhhmmss+hh'mm'" o "YYMMDDhhmmss-hh'mm'". LEN=strlen(VALUE)+1.

GENERALIZEDTIME

VALUE será una cadena terminada en nulo en el mismo formato utilizado para establecer el valor.

OCTET STRING: VALUE contendrá la cadena octal y LEN será el número de octetos.

GENERALSTRING

VALUE contendrá la cadena general y LEN será el número de octetos.

BIT STRING: VALUE contendrá la cadena de bits organizada por bytes y LEN será el número de bits.

CHOICE

Si NAME indica un tipo de elección, VALUE especificará la alternativa seleccionada.

ANY

Si NAME indica un tipo ANY, VALUE indicará la codificación DER de la estructura utilizada realmente.

RETORNA

ASN1_SUCCESS si se devuelve el valor, ASN1_ELEMENT_NOT_FOUND si name no es un elemento válido, ASN1_VALUE_NOT_FOUND si no hay ningún valor para el elemento seleccionado, y ASN1_MEM_ERROR si el vector de valor no es lo suficientemente grande para almacenar el resultado, y en este caso len contendrá el número de bytes necesarios. En la ocasión en que los datos almacenados sean de longitud cero, esta función puede devolver ASN1_SUCCESS incluso si el len proporcionado es cero.
