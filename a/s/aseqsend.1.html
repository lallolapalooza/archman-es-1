ASEQSEND(1) Manual de Comandos Generales ASEQSEND(1)

NOMBRE

aseqsend - enviar mensajes arbitrarios a un puerto de secuenciador ALSA MIDI seleccionado

SINOPSIS

aseqsend -p cliente:puerto -s nombre-archivo
aseqsend -p cliente:puerto "cadena de bytes codificada en hexadecimal"

DESCRIPCIÓ

aseqsend es una utilidad de línea de comandos que permite enviar datos SysEx (system exclusive) a un puerto de secuenciador ALSA MIDI. También puede enviar cualquier otro comando MIDI. Los mensajes a enviar pueden proporcionarse en el último argumento como una cadena de bytes codificada en hexadecimal o pueden leerse de un archivo binario crudo. Al enviar varios mensajes SysEx a la vez, hay un retraso de 1 ms después de cada mensaje por defecto y se puede establecer un valor diferente con la opción -i.

Un cliente se puede especificar por su número, su nombre o un prefijo de su nombre. Un puerto se especifica por su número; para el puerto 0 de un cliente, se puede omitir la parte ":0" de la especificación del puerto.

aseqsend también puede enviar paquetes UMP como dispositivo MIDI 2.0 especificando la opción -u, mientras que la operación por defecto es el flujo de bytes legacy MIDI 1.0.

OPCIONES

-h, --help
Imprime una lista de opciones.
-V, --version
Imprime la versión actual.
-l, --list
Imprime una lista de posibles puertos de salida.
-v, --verbose
Imprime el número de bytes enviados realmente.
-p, --port=cliente:puerto
Puerto de destino por número o nombre.
-s, --file=nombrearchivo
Envía datos binarios crudos desde el nombre de archivo dado.
-i, --interval=msec
Intervalo entre mensajes SysEx en milisegundos.
-u, --ump=version
Especifica la versión de MIDI. 0 para el protocolo legacy MIDI 1.0 (por defecto), 1 para el protocolo UMP MIDI 1.0 y 2 para el protocolo UMP MIDI 2.0.

Cuando se especifica el protocolo UMP MIDI 1.0 o MIDI 2.0, aseqsend lee la entrada como paquetes UMP crudos, 4 bytes cada uno en big endian.

EJEMPLOS

aseqsend -p 128:0 "F0 41 10 00 00 64 12 18 00 21 06 59 41 59 4E F7"

aseqsend -p 128:0 -s I7BulkDump.syx
