ASN1_OBJECT_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_OBJECT_NEW(3ssl) OpenSSL ASN1_OBJECT_NEW(3ssl)

NOMBRE

ASN1_OBJECT_new, ASN1_OBJECT_free - funciones de asignación de objetos

SINOPSIS

#include <openssl/asn1.h>
ASN1_OBJECT *ASN1_OBJECT_new(void);
void ASN1_OBJECT_free(ASN1_OBJECT *a);

DESCRIPCIÓN

Las rutinas de asignación de ASN1_OBJECT asignan y liberan una estructura ASN1_OBJECT, que representa un IDENTIFICADOR DE OBJETO ASN1.

ASN1_OBJECT_new() asigna e inicializa una estructura ASN1_OBJECT.

ASN1_OBJECT_free() libera la estructura ASN1_OBJECT a. Si a es NULL, no se hace nada.

NOTAS

Aunque ASN1_OBJECT_new() asigna una nueva estructura ASN1_OBJECT, casi nunca se utiliza en aplicaciones. En su lugar se utilizan las funciones de utilidad de objetos ASN1, como OBJ_nid2obj().

VALORES DE RETORNO

Si falla la asignación, ASN1_OBJECT_new() devuelve NULL y establece un código de error que se puede obtener con ERR_get_error(3). De lo contrario, devuelve un puntero a la estructura recién asignada.

ASN1_OBJECT_free() no devuelve ningún valor.

VER TAMBIÉN

ERR_get_error(3), d2i_ASN1_OBJECT(3)
