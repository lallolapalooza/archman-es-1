NOMBRE

asn1_der_decoding2 - Función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_der_decoding2(asn1_node * element, const void * ider, int * max_ider_len, unsigned int flags, char * errorDescription);

ARGUMENTOS

asn1_node * element
puntero a una estructura ASN1.
const void * ider
vector que contiene la codificación DER.
int * max_ider_len
puntero a un entero que proporciona información sobre el número máximo de bytes ocupados por * ider. El tamaño real de la codificación DER se devuelve a través de este puntero.
unsigned int flags
banderas que controlan el comportamiento de la función.
char * errorDescription
cadena terminada en nulo que contiene detalles cuando ocurrió un error.

DESCRIPCION

Rellena la estructura * element con los valores de una cadena de codificación DER. La estructura debe haber sido creada previamente con la función asn1_create_element().

Si se establece la bandera ASN1_DECODE_FLAG_ALLOW_PADDING, la función ignorará el relleno después de los datos decodificados DER. Tras un retorno exitoso, el valor de * max_ider_len se establecerá en el número de bytes decodificados.

Si se establece la bandera ASN1_DECODE_FLAG_STRICT_DER, la función no decodificará ningún elemento codificado en BER.

RETORNOS

ASN1_SUCCESS si la codificación DER es correcta, ASN1_ELEMENT_NOT_FOUND si ELEMENT es NULL, y ASN1_TAG_ERROR o ASN1_DER_ERROR si la codificación DER no coincide con el nombre de la estructura (* ELEMENT se elimina).
