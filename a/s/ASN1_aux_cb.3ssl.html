ASN1_aux_cb(3ssl)

Paquete: openssl

Licencias: Apache-2.0

ASN1_AUX_CB(3ssl) OpenSSL ASN1_AUX_CB(3ssl)

NOMBRE

ASN1_AUX, ASN1_PRINT_ARG, ASN1_STREAM_ARG, ASN1_aux_cb, ASN1_aux_const_cb - Datos auxiliares ASN.1

SINOPSIS

#include <openssl/asn1t.h>
struct ASN1_AUX_st {
    void *app_data;
    int flags;
    int ref_offset;             /* Desplazamiento del valor de referencia */
    int ref_lock;               /* Desplazamiento hacia un CRYPTO_RWLOCK */
    ASN1_aux_cb *asn1_cb;
    int enc_offset;             /* Desplazamiento de la estructura ASN1_ENCODING */
    ASN1_aux_const_cb *asn1_const_cb; /* para ASN1_OP_I2D_ y ASN1_OP_PRINT_ */
};
typedef struct ASN1_AUX_st ASN1_AUX;
struct ASN1_PRINT_ARG_st {
    BIO *out;
    int indent;
    const ASN1_PCTX *pctx;
};
typedef struct ASN1_PRINT_ARG_st ASN1_PRINT_ARG;
struct ASN1_STREAM_ARG_st {
    BIO *out;
    BIO *ndef_bio;
    unsigned char **boundary;
};
typedef struct ASN1_STREAM_ARG_st ASN1_STREAM_ARG;
typedef int ASN1_aux_cb(int operation, ASN1_VALUE **in, const ASN1_ITEM *it,
                        void *exarg);
typedef int ASN1_aux_const_cb(int operation, const ASN1_VALUE **in,
                              const ASN1_ITEM *it, void *exarg);

DESCRIPCIÓN

Las estructuras de datos ASN.1 pueden asociarse con un objeto ASN1_AUX para proporcionar información adicional sobre la estructura ASN.1. Una estructura ASN1_AUX se asocia con la estructura durante la definición de la plantilla ASN.1. Por ejemplo, una estructura ASN1_AUX se asociará utilizando una de las diversas macros de definición de plantillas ASN.1 que proporcionan información auxiliar, como ASN1_SEQUENCE_enc(), ASN1_SEQUENCE_ref(), ASN1_SEQUENCE_cb_const_cb(), ASN1_SEQUENCE_const_cb(), ASN1_SEQUENCE_cb() o ASN1_NDEF_SEQUENCE_cb().

Una estructura ASN1_AUX contiene la siguiente información.

app_data
Datos arbitrarios de la aplicación.
flags
Banderas que indican la funcionalidad auxiliar soportada.

La bandera ASN1_AFLG_REFCOUNT indica que los objetos soportan conteo de referencias.

La bandera ASN1_AFLG_ENCODING indica que la codificación original del objeto será guardada.

La bandera ASN1_AFLG_BROKEN es una solución temporal para codificadores defectuosos donde el valor de longitud de la secuencia puede no ser correcto. Generalmente no debería usarse.

La bandera ASN1_AFLG_CONST_CB indica que la forma "const" del callback ASN1_AUX debería usarse en preferencia a la forma no const.

ref_offset
Si la bandera ASN1_AFLG_REFCOUNT está establecida, se asume que este valor es un desplazamiento dentro de la estructura ASN1_VALUE donde se puede encontrar un CRYPTO_REF_COUNT con el propósito del conteo de referencias.
ref_lock
Si la bandera ASN1_AFLG_REFCOUNT está establecida, se asume que este valor es un desplazamiento dentro de la estructura ASN1_VALUE donde se puede encontrar un CRYPTO_RWLOCK con el propósito del conteo de referencias.
asn1_cb
Un callback que será invocado en varios puntos durante el procesamiento de la ASN1_VALUE. Vea más abajo para más detalles.
enc_offset
Desplazamiento dentro del objeto ASN1_VALUE donde la codificación original de el objeto será guardada si la bandera ASN1_AFLG_ENCODING ha sido establecida.
asn1_const_cb
Un callback que será invocado en varios puntos durante el procesamiento de la ASN1_VALUE. Se usa en preferencia al callback asn1_cb si la bandera ASN1_AFLG_CONST_CB está establecida. Vea más abajo para más detalles.

Durante el procesamiento de un objeto ASN1_VALUE los callbacks establecidos vía asn1_cb o asn1_const_cb serán invocados como resultado de varios eventos indicados vía el parámetro operation . El valor de *in será el objeto ASN1_VALUE siendo procesado basado en la plantilla en it. Un parámetro adicional específico de la operación puede ser pasado en exarg. Las operaciones soportadas actualmente son las siguientes. Los callbacks deberían retornar un valor positivo en éxito o cero en error, a menos que se indique lo contrario más abajo.

ASN1_OP_NEW_PRE
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE antes de que un objeto ASN1_VALUE sea asignado. El callback puede asignar la ASN1_VALUE él mismo y almacenarla en *pval. Si lo hace, debería retornar 2 del callback. En caso de error debería retornar 0.
ASN1_OP_NEW_POST
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE después de que un objeto ASN1_VALUE ha sido asignado. El objeto asignado está en *pval.
ASN1_OP_FREE_PRE
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE inmediatamente antes de que una ASN1_VALUE sea liberada. Si el callback originalmente construyó la ASN1_VALUE vía ASN1_OP_NEW_PRE entonces debería liberarla en este punto y retornar 2 del callback. De lo contrario debería retornar 1 para éxito o 0 para error.
ASN1_OP_FREE_POST
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE inmediatamente después de que las sub-estructuras ASN1_VALUE sean liberadas.
ASN1_OP_D2I_PRE
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE inmediatamente antes de una operación "d2i" para la ASN1_VALUE.
ASN1_OP_D2I_POST
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE inmediatamente después de una operación "d2i" para la ASN1_VALUE.
ASN1_OP_I2D_PRE
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE inmediatamente antes de una operación "i2d" para la ASN1_VALUE.
ASN1_OP_I2D_POST
Invocado al procesar una estructura CHOICE, SEQUENCE o NDEF_SEQUENCE inmediatamente después de una operación "i2d" para la ASN1_VALUE.
ASN1_OP_PRINT_PRE
Invocado al procesar una estructura SEQUENCE o NDEF_SEQUENCE inmediatamente antes de imprimir la ASN1_VALUE. El argumento exarg será un puntero a una estructura ASN1_PRINT_ARG (vea más abajo).
ASN1_OP_PRINT_POST
Invocado al procesar una estructura SEQUENCE o NDEF_SEQUENCE inmediatamente después de imprimir la ASN1_VALUE. El argumento exarg será un puntero a una estructura ASN1_PRINT_ARG (vea más abajo).
ASN1_OP_STREAM_PRE
Invocado inmediatamente antes de transmitir los datos ASN1_VALUE usando codificación de longitud indefinida. El argumento exarg será un puntero a una estructura ASN1_STREAM_ARG (vea más abajo).
ASN1_OP_STREAM_POST
Invocado inmediatamente después de transmitir los datos ASN1_VALUE usando codificación de longitud indefinida. El argumento exarg será un puntero a una estructura ASN1_STREAM_ARG (vea más abajo).
ASN1_OP_DETACHED_PRE
Invocado inmediatamente antes de procesar los datos ASN1_VALUE como un valor "detached" (como se usa en CMS y PKCS7). El argumento exarg será un puntero a una estructura ASN1_STREAM_ARG (vea más abajo).
ASN1_OP_DETACHED_POST
Invocado inmediatamente después de procesar los datos ASN1_VALUE como un valor "detached"; valor (como se usa en CMS y PKCS7). El exarg argumento será un puntero a una ASN1_STREAM_ARG estructura (ver abajo).
ASN1_OP_DUP_PRE
Invocado inmediatamente antes de que un ASN1_VALUE sea duplicado mediante una llamada a ASN1_item_dup().
ASN1_OP_DUP_POST
Invocado inmediatamente después de que un ASN1_VALUE haya sido duplicado mediante una llamada a ASN1_item_dup().
ASN1_OP_GET0_LIBCTX
Invocado para obtener el OSSL_LIB_CTX asociado con un ASN1_VALUE si existe. Un puntero a un OSSL_LIB_CTX debe ser almacenado en *exarg si tal valor existe.
ASN1_OP_GET0_PROPQ
Invocado para obtener la cadena de consulta de propiedades asociada con un ASN1_VALUE si existe. Un puntero a la cadena de consulta de propiedades debe ser almacenado en *exarg si tal valor existe.

Un ASN1_PRINT_ARG objeto se usa durante el procesamiento de ASN1_OP_PRINT_PRE y ASN1_OP_PRINT_POST operaciones de retorno de llamada. Contiene la siguiente información.

out
El BIO que se está usando para imprimir los datos.
ndef_bio
El número actual de espacios de sangría que deben usarse para imprimir estos datos.
pctx
El contexto para la ASN1_PCTX operación.

Un ASN1_STREAM_ARG objeto se usa durante el procesamiento de ASN1_OP_STREAM_PRE, ASN1_OP_STREAM_POST, ASN1_OP_DETACHED_PRE y ASN1_OP_DETACHED_POST operaciones de retorno de llamada. Contiene la siguiente información.

out
El BIO a través del cual transmitir
ndef_bio
El BIO con filtros añadidos
boundary
El límite de E/S de transmisión.

VALORES DE RETORNO

Las devoluciones de retorno de llamada devuelven 0 en caso de error y un valor positivo en caso de éxito. Algunas operaciones requieren valores positivos de éxito específicos como se indica arriba.

VER TAMBIÉN

ASN1_item_new_ex(3)

HISTORIA
