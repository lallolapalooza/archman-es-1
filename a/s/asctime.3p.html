ASCTIME(3P) Manual del programador POSIX ASCTIME(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

asctime, asctime_r — convertir fecha y hora a una cadena

SINOPSIS

#include <time.h>
char *asctime(const struct tm *timeptr);
char *asctime_r(const struct tm *restrict tm, char *restrict buf);

DESCRIPCIÓN

Para asctime(): La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función asctime() convertirá la hora desglosada en la estructura apuntada por timeptr en una cadena con el formato:

Dom Sep 16 01:03:52 1973\n\0

utilizando el equivalente del siguiente algoritmo:

char *asctime(const struct tm *timeptr)
{
    static char wday_name[7][3] = {
        "Dom", "Lun", "Mar", "Mié", "Jue", "Vie", "Sáb"
    };
    static char mon_name[12][3] = {
        "Ene", "Feb", "Mar", "Abr", "May", "Jun",
        "Jul", "Ago", "Sep", "Oct", "Nov", "Dic"
    };
    static char result[26];
    sprintf(result, "%.3s %.3s%3d %.2d:%.2d:%.2d %d\n",
        wday_name[timeptr->tm_wday],
        mon_name[timeptr->tm_mon],
        timeptr->tm_mday, timeptr->tm_hour,
        timeptr->tm_min, timeptr->tm_sec,
        1900 + timeptr->tm_year);
    return result;
}

Sin embargo, el comportamiento no está definido si timeptr->tm_wday o timeptr->tm_mon están fuera de los rangos normales definidos en <time.h>, o si timeptr->tm_year excede {INT_MAX}-1990, o si el algoritmo anterior intentara generar más de 26 bytes de salida (incluyendo el nulo terminador).

La estructura tm se define en la cabecera <time.h>.

Las funciones asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de los dos objetos estáticos: una estructura de tiempo desglosada y un array de tipo char. La ejecución de cualquiera de las funciones puede sobrescribir la información devuelta en cualquiera de estos objetos por cualquiera de las otras funciones.

La función asctime() no tiene por qué ser segura para hilos.

La función asctime_r() convertirá la hora desglosada en la estructura apuntada por tm en una cadena (del mismo formato que la devuelta por asctime(), y con el mismo comportamiento indefinido cuando la entrada o salida esté fuera de rango) que se colocará en el búfer proporcionado por el usuario apuntado por buf (que debe contener al menos 26 bytes) y luego devolverá buf.

VALOR DE RETORNO

Si se completa con éxito, asctime() devolverá un puntero a la cadena. Si la función no tiene éxito, devolverá NULL.

Si se completa con éxito, asctime_r() devolverá un puntero a una cadena de caracteres que contiene la fecha y la hora. Esta cadena está apuntada por el argumento buf. Si la función no tiene éxito, devolverá NULL.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO POR LA APLICACIÓN

Estas funciones solo se incluyen por compatibilidad con implementaciones anteriores. Tienen comportamiento indefinido si la cadena resultante es demasiado larga, por lo que se debe desaconsejar el uso de estas funciones. En implementaciones que no detectan el desbordamiento de longitud de la cadena de salida, es posible desbordar los búferes de salida de tal manera que las aplicaciones fallen, o se produzcan posibles violaciones de seguridad del sistema. Además, estas funciones no admiten formatos de fecha y hora localizados. Para evitar estos problemas, las aplicaciones deben usar strftime() para generar cadenas a partir de tiempos desglosados.

Los valores para la estructura de tiempo desglosada se pueden obtener llamando a gmtime() o localtime().

La función asctime_r() es segura para hilos y devolverá valores en un búfer proporcionado por el usuario en lugar de usar potencialmente un área de datos estática que puede ser sobrescrita en cada llamada.

RATIONALE

Los desarrolladores del estándar decidieron marcar las funciones asctime() y asctime_r() como obsoletas, aunque asctime() está en el estándar ISO C, debido a la posibilidad de desbordamiento del búfer. El estándar ISO C también proporciona la función strftime() que se puede utilizar para evitar estos problemas.

DIRECCIONES FUTURAS

Estas funciones pueden eliminarse en una versión futura.

VER TAMBIÉN

clock(), ctime(), difftime(), gmtime(), localtime(), mktime(), strftime(), strptime(), time(), utime()

asctime(3p)

asctime(3p) - convierte la estructura tm en una cadena

SINOPSIS

#include <time.h>

char *asctime(const struct tm *tm);
char *asctime_r(const struct tm *tm, char *buf, size_t len);

DESCRIPCIÓN

La función asctime() convierte una estructura tm, que contiene representación de la hora y la fecha, en una cadena de caracteres de 26 bytes con el siguiente formato:

"Wed Jun 07 15:30:00 1995"

Esto es:

"<día de la semana> <mes> <día del mes> <hora>:<minuto>:<segundo> <año>\n\0"

Todas las salidas terminan con un carácter de nueva línea \n seguido de un carácter nulo \0.

La función asctime_r() es una versión reentrante de asctime(). Toma un puntero a un búfer buf de longitud len donde se escribirá la cadena resultante.

VALOR DE RETORNO

Al completarse con éxito, asctime() devuelve un puntero a la cadena que representa la hora y la fecha. De lo contrario, devuelve NULL.

asctime_r() devuelve un puntero a buf si tiene éxito, o NULL en caso de error (por ejemplo, si len es demasiado pequeño).

ERRORES

No se definen errores específicos para estas funciones, pero pueden fallar si la estructura tm proporcionada no es válida.

EJEMPLOS

#include <stdio.h>
#include <time.h>

int main() {
    time_t t = time(NULL);
    struct tm tm = *localtime(&t);
    char *s = asctime(&tm);
    printf("La hora actual es: %s", s);
    return 0;
}

USO EN APLICACIONES

La función asctime() es útil para obtener una representación legible por humanos de una hora y fecha dadas.

La función asctime_r() se prefiere en entornos multihilo ya que evita el uso de un búfer estático global, lo que podría causar condiciones de carrera.

FUNDAMENTO

asctime() es parte de la biblioteca estándar de C y proporciona una forma conveniente de formatear la hora.

asctime_r() se añadió para mejorar la seguridad en entornos multihilo.

DIRECCIONES FUTURAS

No hay direcciones futuras significativas para estas funciones. Se recomienda el uso de strftime() para un formato de hora más flexible.

VER TAMBIÉN

ctime(3), difftime(3), gmtime(3), localtime(3), mktime(3), strftime(3), time(3).
