asn1_read_value(3)

Paquete: libtasn1

Licencias: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_read_value(3) libtasn1 asn1_read_value(3)

NOMBRE

asn1_read_value - función de la API

SINOPSIS

#include <libtasn1.h>

int asn1_read_value(asn1_node_const root, const char * name, void * ivalue, int * len);

ARGUMENTOS

asn1_node_const root
puntero a una estructura.
const char * name
el nombre del elemento dentro de una estructura que se desea leer.
void * ivalue
vector que contendrá el contenido del elemento, debe ser un puntero a celdas de memoria ya asignadas (puede ser NULL).
int * len
número de bytes de *valor: valor[0]..valor[len-1]. Inicialmente contiene el tamaño de valor.

DESCRIPCIÓN

Devuelve el valor de un elemento dentro de una estructura. Si un elemento es OPCIONAL y esto devuelve ASN1_ELEMENT_NOT_FOUND, significa que ese elemento no estaba presente en la codificación DER que creó la estructura. El primer elemento de un SEQUENCE_OF o SET_OF se llama "?1". El segundo "?2" y así sucesivamente. Si el root proporcionado es un nodo para un elemento de secuencia específico, entonces la palabra clave "?CURRENT" también es aceptable e indica el elemento de secuencia actual de ese nodo.

Tenga en cuenta que puede haber valores válidos con longitud cero. En estos casos, esta función tendrá éxito y len será cero.

ENTER(O)

VALOR contendrá un entero en forma de complemento a dos.

entero=-1 -> valor[0]=0xFF , len=1. entero=1 -> valor[0]=0x01 , len=1.

ENUMERADO

Como ENTERO (pero solo con números no negativos).

BOOLEANO

VALOR será la cadena terminada en nulo "TRUE" o "FALSE" y LEN=5 o LEN=6.

IDENTIFICADOR DE OBJETO: VALOR será una cadena terminada en nulo con cada número separado por un punto (es decir, "1.2.3.543.1").

LEN = strlen(VALOR)+1

UTCTIME

VALOR será una cadena terminada en nulo en uno de estos formatos: "YYMMDDhhmmss+hh'mm'" o "YYMMDDhhmmss-hh'mm'". LEN=strlen(VALOR)+1.

GENERALIZEDTIME

VALOR será una cadena terminada en nulo en el mismo formato utilizado para establecer el valor.

CADENA DE OCTETOS: VALOR contendrá la cadena de octetos y LEN será el número de octetos.

GENERALSTRING

VALOR contendrá la cadena general y LEN será el número de octetos.

CADENA DE BITS: VALOR contendrá la cadena de bits organizada por bytes y LEN será el número de bits.

ELECCIÓN

Si NOMBRE indica un tipo de elección, VALOR especificará la alternativa seleccionada.

ANY

Si NOMBRE indica un tipo ANY, VALOR indicará la codificación DER de la estructura utilizada actualmente.

DEVOLUCIONES

ASN1_SUCCESS si se devuelve el valor, ASN1_ELEMENT_NOT_FOUND si name no es un elemento válido, ASN1_VALUE_NOT_FOUND si no hay ningún valor para el elemento seleccionado, y ASN1_MEM_ERROR si el vector de valor no es lo suficientemente grande para almacenar el resultado, y en este caso len contendrá el número de bytes necesarios. En la ocasión en que los datos almacenados sean de longitud cero, esta función puede devolver ASN1_SUCCESS incluso si el len proporcionado es cero.
