AGETTY(8) Administración del Sistema AGETTY(8)

NOMBRE

agetty - getty alternativo de Linux

SINOPSIS

agetty [opciones] puerto [velocidad_baud...] [terminal]

DESCRIPCIÓN

agetty abre un puerto tty, solicita un nombre de inicio de sesión e invoca el comando /bin/login. Normalmente es invocado por init(8).

agetty tiene varias características *no estándar* que son útiles para líneas cableadas y líneas de acceso telefónico:

•Adapta la configuración del tty a bits de paridad y a caracteres de borrado, eliminación, fin de línea y mayúsculas cuando lee un nombre de inicio de sesión. El programa puede manejar caracteres de 7 bits con paridad par, impar, ninguna o espacio, y caracteres de 8 bits sin paridad. Se reconocen los siguientes caracteres especiales: Control-U (eliminar línea); DEL y retroceso (borrar); retorno de carro y salto de línea (fin de línea). Ver también las opciones --erase-chars y --kill-chars.
•Opcionalmente deduce la velocidad en baudios de los mensajes CONNECT producidos por módems compatibles con Hayes(tm).
•Opcionalmente no cuelga cuando se le da una línea ya abierta (útil para aplicaciones de devolución de llamada).
•Opcionalmente no muestra el contenido del archivo /etc/issue.
•Opcionalmente muestra archivos o directorios de problemas alternativos en lugar de /etc/issue o /etc/issue.d.
•Opcionalmente no solicita un nombre de inicio de sesión.
•Opcionalmente invoca un programa de inicio de sesión no estándar en lugar de /bin/login.
•Opcionalmente activa el control de flujo por hardware.
•Opcionalmente fuerza que la línea sea local sin necesidad de detección de portadora.

Este programa no utiliza los archivos /etc/gettydefs (System V) ni /etc/gettytab (SunOS 4).

ARGUMENTOS

puerto

Un nombre de ruta relativo al directorio /dev. Si se especifica un "-", agetty asume que su entrada estándar ya está conectada a un puerto tty y que ya se ha establecido una conexión con un usuario remoto.

En System V, un argumento de puerto "-" debe ir precedido por un "--".

velocidad_baud,...

Una lista separada por comas de una o más velocidades en baudios. Cada vez que agetty recibe un carácter BREAK, avanza por la lista, que se trata como si fuera circular.

Las velocidades en baudios deben especificarse en orden descendente, para que el carácter nulo (Ctrl-@) también pueda usarse para cambiar la velocidad en baudios.

Este argumento es opcional y no es necesario para las terminales virtuales.

El valor predeterminado para las terminales serie es mantener la velocidad actual en baudios (ver --keep-baud) y, si no es exitoso, el valor predeterminado es '9600'.

terminal

El valor que se utilizará para la variable de entorno TERM. Esto anula cualquier valor que init(1) haya podido establecer, y es heredado por login y el shell.

El valor predeterminado es 'vt100', o 'linux' para Linux en una terminal virtual, o 'hurd' para GNU Hurd en una terminal virtual.

OPCIONES

-8, --8bits

Asume que el tty es compatible con 8 bits, por lo tanto, deshabilita la detección de paridad.

-a, --autologin nombre_usuario

Inicia sesión automáticamente del usuario especificado sin solicitar un nombre de usuario o contraseña. Usar esta opción agrega una opción -f nombre_usuario y un argumento a la línea de comandos de login(1). Ver --login-options, que puede usarse para modificar el comportamiento de esta opción.

Tenga en cuenta que --autologin puede afectar la forma en que getty inicializa la línea serie, ya que en el inicio de sesión automático agetty no lee de la línea y no tiene la oportunidad de optimizar la configuración de la línea.

-c, --noreset

No restablece las cflags (modos de control) del terminal. Ver termios(3) para más detalles.

-E, --remote

Típicamente, el comando login(1) recibe un nombre de host remoto cuando es llamado por algo como telnetd(8). Esta opción permite que agetty pase lo que está usando como nombre de host a login(1) para usarlo en utmp(5). Ver --host, login(1) y utmp(5).

Si se da la opción --host nombre_host_falso, entonces se agrega una opción -h nombre_host_falso y un argumento a la línea de comandos de /bin/login.

Si se da la opción --nohostname, entonces se agrega una opción -H a la línea de comandos de /bin/login.

Ver --login-options.

-f, --issue-file ruta

Especifica una lista de archivos y directorios delimitada por ":" para mostrar en lugar de /etc/issue (u otro). Se muestran todos los archivos y directorios especificados; los archivos faltantes o vacíos se ignoran silenciosamente. Si la ruta especificada es un directorio, entonces se muestran todos los archivos con extensión de archivo .issue en orden de clasificación de versión desde el directorio. Esto permite mostrar mensajes personalizados en diferentes terminales. La opción --noissue anulará esta opción.

--show-issue

Muestra el archivo de problemas actual (u otro) en la terminal actual y sale. Usa esta opción para revisar la configuración actual, no está diseñada para ningún otro propósito. Ten en cuenta que la salida puede usar información predeterminada o incompleta, ya que la salida correcta depende de la terminal y de la línea de comandos de agetty.

-h, --flow-control

Habilita el control de flujo por hardware (RTS/CTS). Se deja en manos de la aplicación deshabilitar el protocolo de control de flujo por software (XON/XOFF) cuando sea apropiado.

-H, --host nombre_host_falso

Escribe el nombre_host_falso especificado en el archivo utmp. Normalmente, no se proporciona un host de inicio de sesión, ya que agetty se utiliza para conexiones cableadas locales y consolas. Sin embargo, esta opción puede ser útil para identificar concentradores de terminales y similares.

-i, --noissue

No muestra el contenido de /etc/issue (u otro) antes de escribir el aviso de inicio de sesión. Los terminales o el hardware de comunicaciones pueden confundirse al recibir mucho texto a una velocidad en baudios incorrecta; los scripts de acceso telefónico pueden fallar si el aviso de inicio de sesión va precedido de demasiado texto.

-I, --init-string cadena_inicial

Establece una cadena inicial para enviarla al tty o módem antes de enviar cualquier otra cosa. Esto puede usarse para inicializar un módem. Los caracteres no imprimibles se pueden enviar escribiendo su código octal precedido por una barra invertida (\). Por ejemplo, para enviar un carácter de salto de línea (ASCII 10, octal 012), escribe \12.

-J, --noclear

No limpia la pantalla antes de solicitar el nombre de inicio de sesión. Por defecto, la pantalla se limpia.

-l, --login-program programa_login

Invoca el programa_login especificado en lugar de /bin/login. Esto permite el uso de un programa de inicio de sesión no estándar. Dicho programa podría, por ejemplo, solicitar una contraseña de acceso telefónico o usar un archivo de contraseñas diferente. Ver --login-options.

-L, --local-line[=modo]

Controla la bandera CLOCAL de la línea. El argumento opcional modo es auto, always o never. Si se omite el argumento modo, entonces el valor predeterminado es always. Si la opción --local-line no se da en absoluto, entonces el valor predeterminado es auto.

always

Fuerza que la línea sea una línea local sin necesidad de detección de portadora. Esto puede ser útil cuando tienes un terminal conectado localmente donde la línea serie no establece la señal de detección de portadora.

never

Borra explícitamente la bandera CLOCAL de la configuración de la línea y se espera la señal de detección de portadora en la línea.

auto

El valor predeterminado de agetty. No modifica la configuración de CLOCAL y sigue

ISSUE FILES

The /etc/issue file is printed before the login prompt. It can be used to display the name of the system and other information. The /etc/issue.net file is printed for network logins. Both files are expected to be plain ASCII files. The contents of /etc/issue are printed before the login prompt is displayed. The contents of /etc/issue.net are printed for network logins. The following escape sequences are recognized:

\
A backslash, followed by a newline.
\a
The ASCII bell character (007).
\b
A backspace character (010).
\c
Do not terminate the output with a newline. This is useful if you want to print a message, but do not want the login prompt to appear on the next line.
\e
An escape character (033).
\h
The hostname of the machine up to the first character of the domain. Same as hostname -s. See also \n. For example, if the hostname is bigserver.domain.com, then \h will display bigserver.
\H
The full hostname of the machine. Same as hostname -f. For example, if the hostname is bigserver.domain.com, then \H will display bigserver.domain.com.
\4{interface}
The IPv4 address of the specified network interface. If interface is not specified, then the IPv4 address of the hostname is used. See also \6.
\6{interface}
The IPv6 address of the specified network interface. If interface is not specified, then the IPv6 address of the hostname is used.
\l
The name of the current tty line. For example, ttyS0.
\m
The architecture identifier of the machine. Same as uname -m.
\n
The machine's network name (nodename). Same as uname -n.
\o
The NIS domain name of the machine. Same as hostname -d.
\O
The DNS domain name of the machine.
\r
The release number of the operating system. Same as uname -r.
\s
The name of the operating system. Same as uname -s.
\t
The current time in 24-hour HH:MM:SS format. See also \T and \@.
\T
The current time in 12-hour HH:MM:SS format. See also \t and \@.
\@
The current time in 12-hour am-pm format. See also \t and \T.
\u
The number of users currently logged in. See also \U.
\U
The string "1 user" or "<n> users" where <n> is the number of current users logged in. See also \u.
\v
The version of the operating system. Same as uname -v.
\xxx
The octal value of the character xxx (where xxx is one to three octal digits).
\N
The ASCII character corresponding to the control character N. For example, \_ for space, \n for newline, \r for carriage return.

Note that the contents of /etc/issue are not processed if the program is invoked with the --no-issue option.

The /etc/issue.net file is printed for network logins. This file is not processed if the program is invoked with the --no-issue option.

If a file named /etc/issue.ascii exists, it is used instead of /etc/issue. If a file named /etc/issue.utf-8 exists, it is used instead of /etc/issue and /etc/issue.ascii.

Insert the VARIABLE data from /etc/os-release. If this file does not exist then fall back to /usr/lib/os-release. If the VARIABLE argument is not specified, then use PRETTY_NAME from the file or the system name (see \s). This escape code can be used to keep /etc/issue distribution and release independent. CREDENTIALS

agetty supports configuration via systemd credentials (see https://systemd.io/CREDENTIALS/). agetty reads the following systemd credentials:

agetty.autologin (string)

If set, configures agetty to automatically log in the specified user without asking for a username or password, similarly to the --autologin option.

BUGS

The baud-rate detection feature (the --extract-baud option) requires that agetty be scheduled soon enough after completion of a dial-in call (within 30 ms with modems that talk at 2400 baud). For robustness, always use the --extract-baud option in combination with a multiple baud rate command-line argument, so that BREAK processing is enabled.

The text in the /etc/issue file (or other) and the login prompt are always output with 7-bit characters and space parity.

The baud-rate detection feature (the --extract-baud option) requires that the modem emits its status message after raising the DCD line.

DIAGNOSTICS

Depending on how the program was configured, all diagnostics are written to the console device or reported via the syslog(3) facility. Error messages are produced if the port argument does not specify a terminal device; if there is no utmp entry for the current process (System V only); and so on.
