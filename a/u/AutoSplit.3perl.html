AutoSplit(3perl) Guía de referencia para programadores de Perl AutoSplit(3perl)

NOMBRE

AutoSplit - divide un paquete para la carga automática

SINOPSIS

autosplit($file, $dir, $keep, $check, $modtime);
autosplit_lib_modules(@modules);

DESCRIPCIÓN

Esta función dividirá su programa en archivos que el módulo AutoLoader puede manejar. Es utilizada tanto por las bibliotecas estándar de perl como por la utilidad MakeMaker, para configurar automáticamente bibliotecas para la carga automática.

La "autosplit" interfaz divide el archivo especificado en una jerarquía con raíz en el directorio $dir. Crea directorios según sea necesario para reflejar la jerarquía de clases, y crea el archivo autosplit.ix. Este archivo actúa tanto como declaración anticipada de todas las rutinas del paquete, como como marca de tiempo para la última actualización de la jerarquía.

Los tres argumentos restantes de "autosplit" controlan otras opciones del divisor automático.

$keep
Si el tercer argumento, $keep, es falso, entonces cualquier archivo "*.al" preexistente en el directorio de carga automática se eliminará si ya no forma parte del módulo (funciones obsoletas). $keep por defecto es 0.
$check
El cuarto argumento, $check, instruye a "autosplit" para que compruebe el módulo que se está dividiendo actualmente para asegurarse de que incluye una especificación "use" para el módulo AutoLoader, y omite el módulo si no se detecta AutoLoader. $check por defecto es 1.
$modtime
Por último, el $modtime argumento especifica que "autosplit" debe comprobar la hora de modificación del módulo en comparación con la del archivo "autosplit.ix" , y solo dividir el módulo si es más reciente. $modtime por defecto es 1.

El uso típico de AutoSplit en la utilidad MakeMaker de perl es a través de la línea de comandos con:

perl -e 'use AutoSplit; autosplit($ARGV[0], $ARGV[1], 0, 1, 1)'

Definido como una macro de Make, se invoca con argumentos de archivo y directorio; "autosplit" dividirá el archivo especificado en el directorio especificado y eliminará los archivos ".al" obsoletos, después de comprobar primero que el módulo usa el AutoLoader, y asegurándose de que el módulo no esté ya dividido actualmente en su forma actual (la prueba de modtime).

La "autosplit_lib_modules" forma se utiliza en la construcción de perl. Toma como entrada una lista de archivos (módulos) que se supone residen en un directorio lib relativo al directorio actual. Cada archivo se envía al divisor automático uno a la vez, para ser dividido en el directorio lib/auto.

En ambos usos del divisor automático, solo las subrutinas definidas después del token __END__ de perl se dividen en archivos separados. Algunas rutinas pueden colocarse antes de este marcador para forzar su carga y análisis inmediatos.

Múltiples paquetes

A partir de la versión 1.01 del módulo AutoSplit, es posible tener múltiples paquetes dentro de un solo archivo. Se admiten ambos casos siguientes:

package NAME;
__END__
sub AAA { ... }
package NAME::option1;
sub BBB { ... }
package NAME::option2;
sub BBB { ... }
package NAME;
__END__
sub AAA { ... }
sub NAME::option1::BBB { ... }
sub NAME::option2::BBB { ... }

DIAGNÓSTICOS

"AutoSplit" informará al usuario si es necesario crear el directorio de nivel superior especificado en la invocación. Es preferible que el script o el proceso de instalación que invoca a "AutoSplit" haya creado la ruta completa del directorio de antemano. Esta advertencia puede indicar que el módulo se está dividiendo en una ruta incorrecta.

"AutoSplit" advertirá al usuario de todas las subrutinas cuyo nombre cause conflictos potenciales de nombres de archivo en máquinas con una longitud de nombre de archivo drásticamente limitada (8 caracteres o menos). Dado que el nombre de la subrutina se usa como nombre de archivo, estas advertencias pueden ayudar en la portabilidad a tales sistemas.

Se emiten advertencias y se omite el archivo si "AutoSplit" no puede localizar ni el marcador __END__ ni una especificación de estilo "package Name;".

"AutoSplit" también emitirá diagnósticos generales por la incapacidad de crear directorios o archivos.
