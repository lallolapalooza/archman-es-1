NOMBRE

autodie::Util - Subrutinas de utilidad internas para autodie y Fatal

SINOPSIS

# API INTERNA solo para autodie y Fatal!
use autodie::Util qw(on_end_of_compile_scope);
on_end_of_compile_scope(sub { print "Hallo world\n"; });

DESCRIPCIÓN

¡Utilidades internas para autodie y Fatal! Este módulo no forma parte de la API pública de autodie.

Este módulo contiene subrutinas de utilidad para abstraer la magia subyacente de autodie y el (mal) uso de "%^H" para llamar a subrutinas al final de ámbitos (de tiempo de compilación).

Tenga en cuenta que, debido a cómo funciona "%^H", algunas de estas utilidades solo son útiles durante la fase de compilación de un módulo perl y dependen de los internos de cómo perl maneja las referencias en "%^H".

MÉTODOS

on_end_of_compile_scope

on_end_of_compile_scope(sub { print "Hallo world\n"; });

Invocará una sub al final de un ámbito (de tiempo de compilación). La sub se llama una vez sin argumentos. Se puede llamar varias veces (incluso en el mismo ámbito de "tiempo de compilación") para instalar múltiples subs. Las subs se llaman en orden de "primero en entrar, último en salir" (FILO u orden de "pila").

fill_protos

fill_protos('*$$;$@')

Dado un prototipo de subrutina Perl, devuelve una lista de especificaciones de invocación. Cada especificación es una lista de referencias, donde el primer miembro es el número (mínimo) de argumentos para esta especificación de invocación. Los argumentos restantes son una representación en cadena de cómo pasar los argumentos correctamente a una sub con el prototipo dado, cuando se llama con el número de argumentos dado.

Las especificaciones se devuelven en orden ascendente de argumentos que comienzan en 0 (por ejemplo, ';$') o 1 (por ejemplo, '$@'). Tenga en cuenta que si el prototipo es "slurpy" (por ejemplo, termina con un "@"), el número de argumentos para la última especificación es un número "mínimo" en lugar de un número exacto. Esto se puede detectar por el último miembro de la última especificación que coincide con m/[@#]_/.

make_core_trampoline

make_core_trampoline('CORE::open', 'main', prototype('CORE::open'))

Crea una trampa (trampoline) para llamar a una subrutina principal (core). Esencialmente, una subrutina diminuta que determina cómo debemos llamar a nuestra subrutina principal, pone los argumentos de la manera correcta y nos redirige hacia ella.

Si pudiéramos usar `goto &` de manera confiable en los elementos básicos (builtins) principales, no necesitaríamos esta subrutina.

install_subs

install_subs('My::Module', { 'read' => sub { die("Hallo\n"), ... }})

Dado un nombre de paquete y un hashref que mapea nombres a una referencia de subrutina (o "undef"), esta subrutina instalará dichas subrutinas en su nombre dado en ese módulo. Si un nombre se mapea a "undef", cualquier subrutina con ese nombre en el módulo de destino será eliminada (posiblemente "desenmascarando" una sub principal (CORE) del mismo nombre).
