AUDIT_LOG_USER_COMMAND(3) API de auditoría de Linux AUDIT_LOG_USER_COMMAND(3)

NOMBRE

audit_log_user_command - registrar un comando de usuario

SINOPSIS

#include <libaudit.h>

int audit_log_user_command(intaudit_fd,int"type,constchar*"command,constchar*"tty,int"result);"

DESCRIPCIÓN

Esta función registrará un comando en el sistema de auditoría utilizando un formato de mensaje predefinido. Codifica el comando tal como lo espera el sistema de auditoría para cadenas no confiables. Todas las aplicaciones que necesiten registrar comandos deben usar esta función. Los parámetros de la función son los siguientes:

audit_fd - El fd devuelto por audit_open
type - tipo de mensaje, por ejemplo: AUDIT_USYS_CONFIG, AUDIT_USER_LOGIN
command - el comando que se está registrando
tty - el tty del usuario, si es NULL intentará averiguarlo
result - 1 es "éxito" y 0 es "fallido"

VALOR DE RETORNO

Devuelve el número de secuencia, que es > 0 en caso de éxito o <= 0 en caso de error.

ERRORES

Esta función devuelve -1 en caso de fallo. Examine errno para más información.

VER TAMBIÉN

audit_log_user_message(3), audit_log_user_comm_message(3), audit_log_acct_message(3), audit_log_user_avc_message(3), audit_log_semanage_message(3).
