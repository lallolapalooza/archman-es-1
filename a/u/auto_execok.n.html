varName d>Este es un procedimiento de búsqueda estándar para su uso por extensiones durante su inicialización. Llaman a este procedimiento para buscar su biblioteca de scripts en varios directorios estándar. El último componente del nombre del directorio de la biblioteca es normalmente basenameversion (por ejemplo, tk8.0), pero podría ser “library” cuando está en las jerarquías de compilación. El archivo initScript se cargará en el intérprete una vez que se encuentre. El directorio en el que se encuentra este archivo se almacena en la variable global varName. Si esta variable ya está definida (por ejemplo, por código C durante la inicialización de la aplicación), entonces no se realiza ninguna búsqueda. De lo contrario, la búsqueda se realiza en estos directorios: el directorio nombrado por la variable de entorno enVarName; relativo al directorio de la biblioteca Tcl; relativo al archivo ejecutable en la instalación estándar bin o bin/arch directorio; relativo al archivo ejecutable en el árbol de compilación actual; relativo al archivo ejecutable en un árbol de compilación paralelo.
parray arrayName ?pattern?
Imprime en la salida estándar los nombres y valores de todos los elementos en el array arrayName, o solo los nombres que coincidan con pattern (usando las reglas de coincidencia de string match) y sus valores si pattern se proporciona. ArrayName debe ser un array accesible para el llamador de parray. Puede ser local o global.

AYUDAS DE FRONTERA DE PALABRA

Estos procedimientos son utilizados principalmente internamente por Tk.

tcl_endOfWord str start
Devuelve el índice de la primera ubicación de fin de palabra que ocurre después de un índice de inicio start en la cadena str. Una ubicación de fin de palabra se define como el primer carácter no palabra que sigue al primer carácter de palabra después del punto de inicio. Devuelve -1 si no hay más ubicaciones de fin de palabra después del punto de inicio. Consulte la descripción de tcl_wordchars y tcl_nonwordchars a continuación para más detalles sobre cómo Tcl determina qué caracteres son caracteres de palabra.
tcl_startOfNextWord str start
Devuelve el índice de la primera ubicación de inicio de palabra que ocurre después de un índice de inicio start en la cadena str. Una ubicación de inicio de palabra se define como el primer carácter de palabra que sigue a un carácter no palabra. Devuelve -1 si no hay más ubicaciones de inicio de palabra después del punto de inicio.
tcl_startOfPreviousWord str start
Devuelve el índice de la primera ubicación de inicio de palabra que ocurre antes de un índice de inicio start en la cadena str. Devuelve -1 si no hay más ubicaciones de inicio de palabra antes del punto de inicio.
tcl_wordBreakAfter str start
Devuelve el índice de la primera frontera de palabra después del índice de inicio start en la cadena str. Devuelve -1 si no hay más fronteras después del punto de inicio en la cadena dada. El índice devuelto se refiere al segundo carácter del par que comprende una frontera.
tcl_wordBreakBefore str start
Devuelve el índice de la primera frontera de palabra antes del índice de inicio start en la cadena str. Devuelve -1 si no hay más fronteras antes del punto de inicio en la cadena dada. El índice devuelto se refiere al segundo carácter del par que comprende una frontera.

VARIABLES

Las siguientes variables globales son definidas o utilizadas por los procedimientos en la biblioteca Tcl. Se dividen en dos clases amplias: manejo de comandos y paquetes desconocidos, y determinación de qué son palabras.

VARIABLES DE AUTOEJECUCIÓN Y GESTIÓN DE PAQUETES

auto_execs
Utilizada por auto_execok para registrar información sobre si comandos particulares existen como archivos ejecutables.
auto_index
Utilizada por auto_load para guardar la información de índice leída del disco.
auto_noexec
Si se establece a cualquier valor, entonces unknown no intentará auto-ejecutar ningún comando.
auto_noload
Si se establece a cualquier valor, entonces unknown no intentará auto-cargar ningún comando.
auto_path
Si se establece, entonces debe contener una lista Tcl válida que proporcione directorios a buscar durante las operaciones de auto-carga (incluyendo para los archivos de índice de paquete al usar el manejador por defecto package unknown ). Esta variable se inicializa durante el arranque para contener, en orden: los directorios listados en la variable de entorno TCLLIBPATH , el directorio nombrado por la variable global tcl_library , el directorio padre de tcl_library, los directorios listados en la variable tcl_pkgPath . Las ubicaciones adicionales para buscar archivos e índices de paquete normalmente deben agregarse a esta variable usando lappend.
env(TCL_LIBRARY)
Si se establece, entonces especifica la ubicación del directorio que contiene scripts de biblioteca (el valor de esta variable se asignará a la variable tcl_library y por lo tanto será devuelto por el comando info library). Si esta variable no está establecida, entonces se usa un valor por defecto.
env(TCLLIBPATH)
Si se establece, entonces debe contener una lista Tcl válida que proporcione directorios a buscar durante las operaciones de auto-carga. Los directorios deben especificarse en formato Tcl, usando “/” como separador de ruta, independientemente de la plataforma. Esta variable solo se usa al inicializar la variable auto_path .

VARIABLES DE DETERMINACIÓN DE FRONTERA DE PALABRA

Estas variables solo se usan en los comandos tcl_endOfWord, tcl_startOfNextWord, tcl_startOfPreviousWord, tcl_wordBreakAfter, y tcl_wordBreakBefore .

tcl_nonwordchars
Esta variable contiene una expresión regular que es usada por rutinas como tcl_endOfWord para identificar si un carácter es parte de una palabra o no. Si el patrón coincide con un carácter, el carácter se considera un carácter no palabra. En las plataformas Windows, los espacios, tabulaciones y saltos de línea se consideran caracteres no palabra. En Unix, todo excepto números, letras y guiones bajos se consideran caracteres no palabra.
tcl_wordchars
Esta variable contiene una expresión regular que es usada por rutinas como tcl_endOfWord para identificar si un carácter es parte de una palabra o no. Si el patrón coincide con un carácter, el carácter se considera un carácter de palabra. En las plataformas Windows, las palabras están compuestas por cualquier carácter que no sea un espacio, tabulación o salto de línea. En Unix, las palabras están compuestas por números, letras o guiones bajos.
