Authen::SASL::Perl::CRAM_MD5(3) Documentación de Perl contribuida por el usuario Authen::SASL::Perl::CRAM_MD5(3)

NOMBRE

Authen::SASL::Perl::CRAM_MD5 - (DEPRECADO) Clase de autenticación CRAM MD5

VERSIÓN

versión 2.1900

SINOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'CRAM-MD5',
  callback  => {
    user => $user,
    pass => $pass
  },
);

DESCRIPCIÓN

Este método implementa la parte del cliente del algoritmo CRAM-MD5 SASL, tal como se describe en RFC 2195 o en el borrador de IETF draft-ietf-sasl-crammd5-XX.txt.

Tenga en cuenta que este mecanismo se ha movido a la sección de uso "LIMITADO" del registro de mecanismos https://www.iana.org/assignments/sasl-mechanisms/sasl-mechanisms.xhtml y está efectivamente obsoleto según RFC8314 https://www.rfc-editor.org/rfc/rfc8314.html (ver sección 5; consideraciones de seguridad).

CALLBACK

Los callbacks utilizados son:

user
El nombre de usuario que se utilizará para la autenticación
pass
La contraseña del usuario que se utilizará para la autenticación
