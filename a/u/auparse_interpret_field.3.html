AUPARSE_INTERPRET_FIELD(3) API de auditoría de Linux AUPARSE_INTERPRET_FIELD(3)

NOMBRE

auparse_interpret_field, auparse_interpret_realpath,auparse_interpret_sock_family,auparse_interpret_sock_port,auparse_interpret_sock_address - obtener el valor interpretado del campo actual

SINOPSIS

#include <auparse.h>

const char *auparse_interpret_field(const auparse_state_t *au);
const char *auparse_interpret_realpath(const auparse_state_t *au);
const char *auparse_interpret_sock_family(auparse_state_t *au);
const char *auparse_interpret_sock_port(auparse_state_t *au);
const char *auparse_interpret_sock_address(const auparse_state_t *au);

DESCRIPCIÓN

auparse_interpret_field permite el acceso al valor interpretado en el campo actual del registro actual en el evento actual. La cadena devuelta se escapa usando el método elegido. El valor devuelto se destruirá si llamas a esta función de nuevo. Si necesitas interpretar otro campo y conservar este valor, tendrás que copiarlo para su uso posterior.

Ejemplos de cosas que podrían interpretarse son: uid, gid, números de llamadas al sistema, códigos de salida, rutas de archivos, direcciones de socket, permisos, modos y capacidades. Es probable que haya más en el futuro. Si un valor no se puede interpretar, se devuelve su valor original.

auparse_interpret_realpath es como auparse_interpret_field excepto que llamará a realpath en los resultados de unir el cwd y el archivo. Esto también implica que solo es válido llamarlo para el nombre de archivo dado en un registro PATH.

auparse_interpret_sock_family solo devolverá la parte de la familia de socket de una dirección de socket.

auparse_interpret_sock_port solo devolverá la parte del puerto de una dirección de socket. No todas las familias de sockets tienen un puerto. Si ese es el caso, obtendrás un valor NULL, en cuyo caso tu mejor opción es usar la función de interpretación normal.

auparse_interpret_sock_address solo devolverá la parte de la dirección de una dirección de socket. No todas las familias de sockets tienen una dirección IP. Si ese es el caso, obtendrás un valor NULL, en cuyo caso tu mejor opción es usar la función de interpretación normal.

VALOR DE RETORNO

Devuelve NULL si hay un error, de lo contrario, un puntero al valor interpretado.

VER TAMBIÉN

auparse_get_field_int(3), auparse_get_field_str(3), auparse_set_escape_mode(3).
