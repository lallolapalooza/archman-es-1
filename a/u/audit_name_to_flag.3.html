AUDIT_NAME_TO_FLAG(3) API de auditoría de Linux AUDIT_NAME_TO_FLAG(3)

NOMBRE

audit_name_to_flag - Convierte el nombre del filtro de coincidencia de reglas al valor numérico del filtro de coincidencia de reglas

SINOPSIS

#include <libaudit.h>
int audit_name_to_flag(const char *flag);

DESCRIPCIÓN

audit_name_to_flag() convierte el nombre del filtro de coincidencia de reglas ("task", "exit", "user", "exclude", "filesystem") al valor numérico del filtro de coincidencia de reglas (AUDIT_FILTER_TASK, AUDIT_FILTER_EXIT, AUDIT_FILTER_USER, AUDIT_FILTER_EXCLUDE, AUDIT_FILTER_FS). flag es el nombre del filtro de coincidencia de reglas.

VALOR DEVUELTO

Devuelve -1 si ocurre un error; de lo contrario, el valor devuelto es el valor numérico del filtro de coincidencia de reglas.
