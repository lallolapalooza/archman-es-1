AUPARSE_GET_FIELD_INT(3) API de auditoría de Linux AUPARSE_GET_FIELD_INT(3)

NOMBRE

auparse_get_field_int - obtener el valor del campo actual como un int

SINOPSIS

#include <auparse.h>

int auparse_get_field_int(auparse_state_t *au);"

DESCRIPCIÓN

auparse_get_field_int permite acceder al valor como un int del campo actual del registro actual en el evento actual.

VALOR DEVUELTO

Devuelve -1 si hay un error con errno establecido apropiadamente o el valor si errno es cero.

VER TAMBIÉN

auparse_get_field_str(3).
