Authen::SASL::Perl::EXTERNAL(3) Documentación de Perl aportada por el usuario Authen::SASL::Perl::EXTERNAL(3)

NOMBRE

Authen::SASL::Perl::EXTERNAL - Clase de autenticación externa

VERSIÓN

versión 2.1900

SINOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'EXTERNAL',
  callback  => {
    user => $user
  },
);

DESCRIPCIÓN

Este método implementa la parte cliente del algoritmo SASL EXTERNAL, tal como se describe en RFC 2222.

CALLBACK

Los callbacks utilizados son:

usuario
El nombre de usuario a utilizar para la autenticación

VER TAMBIÉN

Authen::SASL, Authen::SASL::Perl
