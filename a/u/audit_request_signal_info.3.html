AUDIT_REQUEST_SIGNAL_INFO(3) API de auditoría de Linux AUDIT_REQUEST_SIGNAL_INFO(3)

NOMBRE

audit_request_signal_info - Solicitar información de señal para el sistema de auditoría

SINOPSIS

#include <libaudit.h>

int audit_request_signal_info(intfd);"

DESCRIPCIÓN

audit_request_signal_info solicita que el kernel envíe información sobre el remitente de una señal al demonio de auditoría. La estructura de información de señal es la siguiente:

struct audit_sig_info {
        uid_t           uid;
        pid_t           pid;
        char            ctx[0];
};

Es probable que esta función sea utilizada solo por demonios de auditoría y no deba ser llamada por ningún otro tipo de programa.

VALOR DE RETORNO

El valor de retorno es <= 0 en caso de error, de lo contrario es el número de secuencia de la red. Esta función puede tener cualquier error que sendto pudiera encontrar.

VER TAMBIÉN

audit_open(3), audit_get_reply(3).
