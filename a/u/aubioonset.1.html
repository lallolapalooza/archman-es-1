AUBIOONSET(1) Manual de usuario de aubio AUBIOONSET(1)

NOMBRE

aubioonset - una herramienta de línea de comandos para extraer los tiempos de ataque musical

SINOPSIS

aubioonset source
aubioonset [[-i] source] [-o sink]
           [-r rate] [-B win] [-H hop]
           [-O method] [-t thres]
           [-T time-format]
           [-s sil] [-m] [-f]
           [-j] [-N miditap-note] [-V miditap-velo]
           [-v] [-h]

DESCRIPCIÓN

aubioonset intenta detectar los tiempos de ataque, el comienzo de eventos sonoros discretos, en señales de audio.

Cuando se inicia con una fuente de entrada source (-i/--input), los tiempos de ataque detectados se muestran en la consola, en segundos.

Cuando se inicia sin una fuente de entrada source, o con la opción jack (-j/--jack), aubioonset se inicia en modo jack.

OPCIONES

Este programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (--). A continuación se incluye un resumen de las opciones.

-i, --input source
Ejecuta el análisis en este archivo de audio. Se admiten la mayoría de los archivos sin comprimir y comprimidos, dependiendo de cómo se compiló aubio.
-o, --output sink
Guarda los resultados en este archivo. El archivo se creará siguiendo el modelo del archivo de entrada. Los tiempos de ataque se marcan con un sonido corto similar a un bloque de madera.
-r, --samplerate rate
Obtiene la fuente de entrada source, remuestreada a la frecuencia de muestreo dada rate. La rate debe especificarse en Hertz como un entero. Si es 0, se utilizará la frecuencia de muestreo rate de la fuente source original. Por defecto es 0.
-B, --bufsize win
El tamaño del búfer a analizar, es decir, la longitud de la ventana utilizada para los cálculos espectrales y temporales. Por defecto es 512.
-H, --hopsize hop
El número de muestras entre dos análisis consecutivos. Por defecto es 256.
-O, --onset method
El método de detección de ataque method a utilizar. Véase MÉTODOS DE ATAQUE más abajo. Por defecto es 'default'.
-t, --onset-threshold thres
Establece el valor de umbral para la selección de picos de ataque. Los valores suelen estar en el rango [0.001, 0.900]. Valores de umbral más bajos implican que se detecten más ataques. Aumentar este umbral debería reducir el número de detecciones incorrectas. Por defecto es 0.3.
-M, --minioi value
Establece el intervalo mínimo entre ataques, en segundos, el intervalo más corto entre dos ataques consecutivos. Por defecto es 0.020
-s, --silence sil
Establece el umbral de silencio, en dB, por debajo del cual el ataque no se detectará. Un valor de -20.0 eliminaría la mayoría de los ataques excepto los más fuertes. Un valor de -90.0 seleccionaría todos los ataques. Por defecto es -90.0.
-T, --timeformat format
Establece el formato de tiempo (muestras, ms, segundos). Por defecto es segundos.
-m, --mix-input
Mezcla la señal de entrada source con la señal de salida antes de escribir en sink.
-f, --force-overwrite
Sobrescribe el archivo de salida si ya existe.
-j, --jack
Utiliza la entrada/salida de Jack. Necesitará un controlador de conexión Jack para alimentar a aubio con una señal y escuchar su salida.
-N, --miditap-note
Anula el valor de nota para MIDI tap. Por defecto es 69.
-V, --miditap-velop
Anula el valor de velocidad para MIDI tap. Por defecto es 65.
-h, --help
Imprime un breve mensaje de ayuda y sale.
-v, --verbose
Modo verboso.

MÉTODOS DE ATAQUE

Los métodos disponibles son:

default
Distancia por defecto, actualmente hfc

Por defecto: 'default' (actualmente establecido en hfc)

energy
Distancia basada en energía

Esta función calcula la energía local del marco espectral de entrada.

hfc
Contenido de alta frecuencia

Este método method calcula el Contenido de Alta Frecuencia (HFC) del marco espectral de entrada. La función resultante es eficiente para detectar ataques percusivos.

Paul Masri. Computer modeling of Sound for Transformation and Synthesis of Musical Signal. PhD dissertation, University of Bristol, UK, 1996.

complex
Función de detección de ataque en el dominio complejo

Esta función utiliza información tanto en frecuencia como en fase para determinar cambios en el contenido espectral que podrían corresponder a ataques musicales. Es más adecuada para señales complejas como grabaciones polifónicas.

Christopher Duxbury, Mike E. Davies, and Mark B. Sandler.
Complex domain onset detection for musical signals. In Proceedings of the Digital Audio Effects Conference, DAFx-03, pages 90-93, London, UK, 2003.
phase
Función de detección de ataque basada en la fase

Esta función utiliza información tanto en frecuencia como en fase para determinar cambios en el contenido espectral que podrían corresponder a ataques musicales. Es más adecuada para señales complejas como grabaciones polifónicas.

Juan-Pablo Bello, Mike P. Davies, and Mark B. Sandler.
Phase-based note onset detection for music signals. In Proceedings of the IEEE International Conference on Acoustics Speech and Signal Processing, pages 441­444, Hong-Kong, 2003.
specdiff
Función de detección de ataque por diferencia espectral

Jonhatan Foote and Shingo Uchihashi. The beat spectrum: a new approach to rhythm analysis. In IEEE International Conference on Multimedia and Expo (ICME 2001), pages 881­884, Tokyo, Japan, August 2001.

kl
Función de detección de ataque Kulback-Liebler

Stephen Hainsworth and Malcom Macleod. Onset detection in music audio signals. In Proceedings of the International Computer Music Conference (ICMC), Singapore, 2003.

mkl
Función de detección de ataque Kulback-Liebler modificada

Paul Brossier, ``Automatic annotation of musical audio for interactive systems'', Chapter 2, Temporal segmentation, PhD thesis, Centre for Digital music, Queen Mary University of London, London, UK, 2006.

specflux
Flujo espectral

Simon Dixon, Onset Detection Revisited, in ``Proceedings of the 9th International Conference on Digital Audio Effects'' (DAFx-06), Montreal, Canada, 2006.

NAME

aubioonset ‐ detect onsets in audio

SYNOPSIS

aubioonset [-h | -v] [-i input] [-o output] [-f format] [-s samplerate] [-b buffersize] [-p hopsize] [-m method] [-t threshold] [-d delay]

DESCRIPTION

The aubioonset utility takes an audio file as input and performs onset detection using the aubio library. It outputs the detected onset times to a specified file or standard output.

OPTIONS

-h
Show help message and exit.
-v
Show version information and exit.
-i input
Input audio file. If not specified, uses standard input.
-o output
Output file for onset times. If not specified, uses standard output.
-f format
Output format. Supported formats are: timestamp, midi, labels. Default is timestamp.
-s samplerate
Sample rate of the input audio. If not specified, aubio tries to detect it automatically.
-b buffersize
Size of the analysis buffer in samples. Default is 1024.
-p hopsize
Hop size (step) between consecutive analysis buffers in samples. Default is 512.
-m method
Onset detection method to use. See ONSET METHODS for details.
-t threshold
Onset detection threshold. The meaning of this value depends on the selected method. Default is 0.8.
-d delay
A small delay (in seconds) added to the detected onset times. This can help to align onsets more accurately with the start of notes. Default is 0.0.

ONSET METHODS

The following onset detection methods are available:

energy
Onset detection based on energy changes.
complex
Onset detection based on the complex domain.
spectral
Onset detection based on spectral flux.
mfcc
Onset detection based on Mel-Frequency Cepstral Coefficients (MFCCs).
beat
Beat detection (can also be used for onset detection).

The default method is energy.
