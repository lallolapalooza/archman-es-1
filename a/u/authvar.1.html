AUTHVAR(1) Manual de comandos generales AUTHVAR(1)

NOMBRE

authvar — maneja variables autenticadas para pesign

SINOPSIS

authvar ⟨-a | -c | -s⟩ -N {guid} -n nombre ⟨-v valor | -f archivo⟩ [-t tiempo] [-d directorio] [-S apodo] [-i archivo] [-e archivo]

DESCRIPCIÓN

authvar es una utilidad de línea de comandos para manejar variables UEFI autenticadas.

OPCIONES

-a | --append
Añadir a la variable
-c | --clear
Borrar variable
-s | --set
Establecer variable
-N ⟨{guid} | espacio de nombres⟩ | --namespace ⟨{guid} | espacio de nombres⟩
La variable está en el espacio de nombres o {guid} (por defecto: global)

Use -N help para listar los espacios de nombres.

-n nombre | --name nombre
Nombre de la variable nombre
-v valor | --value valor
Establecer o añadir valor a la variable
-f archivo | --valuefile archivo
Leer el valor desde el archivo
-t tiempo | --timestamp tiempo
Marca de tiempo para la variable (por defecto: ahora)
-d directorio | --certdir directorio
Especificar el directorio de la base de datos de certificados nss directorio (por defecto: /etc/pki/pesign)
-S apodo | --sign apodo
Firmar la variable con el apodo del certificado apodo de la base de datos NSS
-i archivo | --import archivo
Importar variable desde el archivo
-e archivo | --export archivo
Exportar la variable al archivo en lugar de establecerla en el firmware

ESTÁNDARES
