AUPARSE_GET_SERIAL(3) API de auditoría de Linux AUPARSE_GET_SERIAL(3)

NOMBRE

auparse_get_serial - obtener el número de serie del evento

SINOPSIS

#include <auparse.h>

unsigned long auparse_get_serial(const auparse_state_t *au);"

DESCRIPCIÓN

auparse_get_serial obtiene el valor del número de serie de la estructura de datos de marca de tiempo del evento actual.

VALOR DE RETORNO

Devuelve 0 si ocurre un error; de lo contrario, el número de serie del evento.

VER TAMBIÉN

auparse_get_timestamp(3), auparse_get_time(3), auparse_get_milli(3). auparse_get_node(3).
