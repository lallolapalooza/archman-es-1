AUTHOSCOPE(1) Comandos de usuario AUTHOSCOPE(1)

NOMBRE

authoscope - cracker de autenticación de red scriptable

SINOPSIS

authoscope [-nVh] comando

DESCRIPCIÓN

authoscope es un cracker de autenticación de red scriptable. Si bien el espacio para el fuerza bruta de servicios comunes ya está muy saturado, es posible que aún termine escribiendo sus propios scripts de Python al probar credenciales para aplicaciones web.

El alcance de authoscope es específicamente romper servicios personalizados. Esto se hace escribiendo scripts que se cargan en un tiempo de ejecución de Lua. Esos scripts representan un único servicio y proporcionan una función `verify(user, password)` que devuelve verdadero o falso. La concurrencia, la indicación de progreso y la generación de informes son proporcionadas mágicamente por el tiempo de ejecución de authoscope.

OPCIONES

-n, --workers <workers>
El número de trabajadores concurrentes a ejecutar.
-o, --output <salida>
Escribe los resultados en este archivo.
-v, --verbose
Habilita la salida detallada.
-h, --help
Imprime información de ayuda.
-V, --version
Imprime información de la versión.

SUBCOMANDOS

Elige uno de los siguientes subcomandos.

Ataque de diccionario

Intenta cada contraseña para cada usuario con cada script.

authoscope dict <usuarios> <contraseñas> [scripts]...

Confirmación de credenciales

Carga una lista de credenciales con el formato usuario:contraseña y las verifica con cada script.

authoscope creds <credenciales> [scripts]...

Enumeración de nombres de usuario

Toma una lista de nombres de usuario y verifica que existan en el sistema. Esto aún ejecuta la función verify con dos argumentos, pero la contraseña se establece en nil. Puedes escribir un script que pueda hacer ambas cosas comprobando si la contraseña es nil para detectar en qué modo se ejecuta el script.

authoscope enum <usuarios> [scripts]...

Un solo intento

Prueba una única combinación de nombre de usuario y contraseña utilizando un script específico. Este comando también es útil al desarrollar un nuevo script. Si se omite el argumento de contraseña, el script se ejecuta en modo de enumeración. Si deseas utilizar este comando en scripts, establece -x para que el código de salida se establezca en 2 si las credenciales son inválidas.

authoscope oneshot [-x] <script> <usuario> [contraseña]

VER authoscope(1) — authoscope — Arch Linux

NOMBRE

authoscope — genera claves de autenticación y descodifica credenciales.

SINOPSIS

authoscope [OPCIÓN]... [COMANDO] [ARGUMENTOS]...

DESCRIPCIÓN

authoscope es una herramienta de línea de comandos diseñada para gestionar la autenticación de forma segura. Permite generar claves de autenticación y decodificar credenciales cifradas, facilitando la integración con diversos sistemas y servicios.

OPCIONES

authoscope acepta las siguientes opciones:

-h, --help
Muestra un mensaje de ayuda y sale.
-v, --version
Muestra la información de la versión y sale.
-c, --config <archivo>
Especifica un archivo de configuración.
--verbose
Habilita la salida detallada.

SUBCOMANDOS

Los siguientes subcomandos están disponibles:

generate [OPCIONES]
Genera una nueva clave de autenticación.
decode <credencial> [OPCIONES]
Decodifica una credencial cifrada.
sign <mensaje> [OPCIONES]
Firma un mensaje con la clave actual.
verify <mensaje> <firma> [OPCIONES]
Verifica la firma de un mensaje.

REFERENCIA DE EJECUCIÓN

Este programa utiliza la biblioteca Lua para su lógica interna y el manejo de la autenticación.

SEGURIDAD

Maneje las claves de autenticación con cuidado. No las comparta ni las exponga en entornos no seguros.

VER TAMBIÉN

La documentación en lua.org.
