AUDIT_ENCODE_NV_STRING(3) API de auditoría de Linux AUDIT_ENCODE_NV_STRING(3)

NOMBRE

audit_encode_nv_string - codifica un par nombre/valor en una cadena

SINOPSIS

#include <libaudit.h>
char *audit_encode_nv_string(const char *nombre, const char *valor, unsigned int vlen)

DESCRIPCIÓN

Esta función se utiliza para codificar un par nombre/valor. Debe utilizarse en cualquier campo que se registre y que potencialmente contenga un espacio, una comilla doble o un carácter de control. Cualquier valor que contenga estos caracteres debe ser codificado especialmente para que la biblioteca auparse pueda manejar correctamente el valor. El método de codificación está diseñado para prevenir ataques de inyección de registros donde los valores maliciosos podrían causar errores de análisis.

Para usar esta función, pase las cadenas nombre y valor en sus argumentos respectivos. Si es probable que el valor contenga un byte NUL incrustado, deberá pasar una longitud en bytes vlen que indique el tamaño del valor. De lo contrario, puede pasar un 0 para vlen y la función simplemente usará strlen en el puntero valor. Tenga en cuenta también que el nombre del campo hará que auparse realice ciertas acciones al interpretar el valor. Si el nombre es uid, se espera un valor de ID de usuario en decimal. Asegúrese de que se utilizan nombres conocidos para su propósito previsto o de que no hay posibilidad de colisión de nombres con algo nuevo.

VALOR DE RETORNO

Devuelve una cadena recién asignada con malloc que el llamador debe liberar o NULL si ocurre un error.

VER TAMBIÉN
