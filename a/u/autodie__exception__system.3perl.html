autodie::exception::system(3perl) Guía de programación de Perl autodie::exception::system(3perl)

NOMBRE

autodie::exception::system - Excepciones de system() que fallan.

SINOPSIS

eval {
    use autodie qw(system);
    system($cmd, @args);
};
if (my $E = $@) {
    say "¡Uy!  ",$E->caller," tuvo problemas: $@";
}

DESCRIPCIÓN

Esta es una clase de excepción de autodie para fallos del comando "system".

Actualmente no hay forma de interrogar a un objeto "autodie::exception::system" para obtener el comando, el estado de salida y otra información que se esperaría que dicho objeto contuviera. La interfaz se ampliará para dar cabida a esto en el futuro.

stringify

Cuando se convierte en cadena, los objetos "autodie::exception::system" utilizan actualmente el mensaje generado por IPC::System::Simple.
