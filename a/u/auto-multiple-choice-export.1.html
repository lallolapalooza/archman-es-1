AUTO-MULTIPLE-CHOI(1) Auto Multiple Choice AUTO-MULTIPLE-CHOI(1)

NOMBRE

auto-multiple-choice-export - exporta las calificaciones de exámenes de opción múltiple de AMC.

SINOPSIS

auto-multiple-choice exportar --datos dir-datos-proyecto --módulo módulo --fich-noms lista-estudiantes.csv [--noms-encodage codificación-lista] --o archivo-salida

DESCRIPCIÓN

El comando auto-multiple-choice export exporta las calificaciones de un examen Auto Multiple Choice.

--datos dir-datos-proyecto

proporciona el directorio donde se encuentran los archivos de datos (ver, por ejemplo, auto-multiple-choice-prepare(1)).

--módulo módulo

selecciona un módulo para exportar. Consulte a continuación los módulos incluidos en la distribución estándar de AMC.

--fich-noms lista-estudiantes.csv

establece el archivo de la lista de estudiantes.

--noms-encodage codificación-lista

selecciona una codificación para el archivo lista-estudiantes.csv (por defecto es utf-8).

--o archivo-salida

proporciona el nombre del archivo de salida.

--opción-salida opciones

proporciona una opción para el módulo seleccionado, en el formato clave=valor (ver a continuación las opciones posibles para cada módulo). Para especificar múltiples opciones, use --opción varias veces.

--ordenar tipo-ordenación

ordena los nombres de los estudiantes, dependiendo de tipo-ordenación. Si tipo-ordenación es l, usa el número de línea del archivo de lista de estudiantes para ordenar. Si tipo-ordenación es m, usa la calificación (y el nombre si las calificaciones son iguales) para ordenar. Si tipo-ordenación es i, usa el número de estudiante para ordenar. Si tipo-ordenación es n, usa el nombre para ordenar (o la línea del archivo de lista de estudiantes si son iguales).

--usartodo todo

si todo es 0 o está vacío, solo los estudiantes con una hoja de respuestas escaneada aparecen en la salida. Si todo es 1, todos los estudiantes en la lista de estudiantes aparecen en la salida.

MÓDULOS

OpenDocument

Con "--módulo ods", se produce un OpenDocument (para usarlo con OpenOffice o LibreOffice, por ejemplo). Se reconocen las siguientes opciones:

nombre

proporciona un nombre para el examen, que se escribirá al principio de la hoja.

código

proporciona un nombre corto para el examen, que se usará como nombre de pestaña.

columnas

establece la lista de columnas que se añadirán a cada estudiante.

El valor por defecto es student.key,student.name.

estadísticas

con un valor verdadero, se añadirá una tabla con estadísticas para todas las preguntas.

indicador-estadísticas

con un valor verdadero, se añadirá una tabla con estadísticas para todas las preguntas indicativas.

CSV

Con "--módulo CSV", se produce un archivo CSV. Se reconocen las siguientes opciones:

columnas

establece la lista de columnas que se añadirán a cada estudiante.

El valor por defecto es student.copy,student.key,student.name.

decimal

establece el punto decimal (por defecto es un punto).

codificación

establece la codificación a usar para la salida (por defecto es utf-8).

separador

establece el carácter utilizado entre columnas (por defecto es una coma).

entrecomillado

establece el carácter utilizado para entrecomillar cadenas (por defecto son comillas dobles).

marcado

si no está vacío, se incluyen columnas adicionales (con prefijo "CHECKED:") para dar todas las casillas marcadas en todas las hojas. Esto puede ser utilizado por un programa externo para recuperar todas las casillas marcadas cuando las calificaciones no son suficientes. Usa el valor 01 para obtener 0;0;1;1;0 si las casillas 3 y 4 están marcadas, y el valor AB para obtener CD si las casillas 3 y 4 están marcadas.

Lista

Con "--módulo List", se produce un archivo PDF con una lista de calificaciones para todos los estudiantes. Se reconocen las siguientes opciones:

tamaño-página

El tamaño de la página. El valor por defecto es a4.

nombre

proporciona el nombre del examen, que se imprimirá en la parte superior de la página.

número-columnas

El número de columnas. El valor por defecto es 2.

decimal

establece el punto decimal (por defecto es un punto).
