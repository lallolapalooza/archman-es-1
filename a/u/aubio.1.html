AUBIO(1) Manual de usuario de aubio AUBIO(1)

NOMBRE

aubio - una herramienta de línea de comandos para extraer información de archivos de sonido

SINOPSIS

aubio [-h] [-V] <comando> ...

COMANDOS

La sintaxis general es "aubio <comando> <archivo_de_sonido> [opciones]". Los siguientes comandos están disponibles:

onset
obtener tiempos de onset
pitch
extraer frecuencia fundamental
beat
obtener ubicaciones de los beats
tempo
obtener tempo general en bpm
notes
obtener notas tipo midi
mfcc
extraer coeficientes cepstrales de frecuencia Mel
melbands
extraer energías de bandas de frecuencia Mel

Para una lista de comandos disponibles, usa "aubio -h". Para más información sobre cada comando, usa "aubio <comando> --help".

OPCIONES GENERALES

Estas opciones se pueden usar antes de especificar cualquier comando.

-h, --help
mostrar mensaje de ayuda y salir
-V, --version
mostrar versión

OPCIONES COMUNES

Las siguientes opciones se pueden usar con todos los comandos:

<uri_fuente>, -i <uri_fuente>, --input <uri_fuente>
archivo de sonido de entrada a analizar (requerido)
-r <freq>, --samplerate <freq>
frecuencia de muestreo a la que se debe representar el archivo (por defecto: 0, es decir, la frecuencia de muestreo del sonido de entrada)
-H <tamaño>, --hopsize <tamaño>
tamaño del salto, número de muestras entre dos análisis consecutivos (por defecto: 256)
-B <tamaño>, --bufsize <tamaño>
tamaño del búfer, número de muestras usadas para cada análisis (por ejemplo, longitud FFT, por defecto: 512)
-h, --help
mostrar mensaje de ayuda y salir
-T formato, --time-format formato
selecciona el formato de salida de los valores de tiempo (muestras, ms, segundos) (por defecto: segundos)
-v, --verbose
ser verboso (incrementa la verbosidad en 1, por defecto: 1)
-q, --quiet
ser silencioso (establece la verbosidad a 0)

ONSET

Las siguientes opciones adicionales se pueden usar con el subcomando "onset".

-m <método>, --method <método>
función de novedad de onset <default|energy|hfc|complex|phase|specdiff|kl|mkl|specflux> (por defecto: default)
-t <umbral>, --threshold <umbral>
umbral (por defecto: no establecido)
-s <valor>, --silence <valor>
umbral de silencio, en dB (por defecto: -70)
-M <valor>, --minioi <valor>
intervalo inter-onset mínimo (por defecto: 12ms)

PITCH

Las siguientes opciones adicionales se pueden usar con el subcomando "pitch".

-m <método>, --method <método>
método de detección de pitch <default|yinfft|yin|mcomb|fcomb|schmitt> (por defecto: default, es decir, yinfft)
-t <umbral>, --threshold <umbral>
tolerancia (por defecto: no establecido)
-s <valor>, --silence <valor>
umbral de silencio, en dB (por defecto: -70)

El tamaño de búfer por defecto para el algoritmo de beat es 2048. El tamaño de salto por defecto es 256.

BEAT

El comando "beat" acepta todas las opciones comunes y ninguna opción adicional.

El tamaño de búfer por defecto para el algoritmo de beat es 1024. El tamaño de salto por defecto es 512.

TEMPO

El comando "tempo" acepta todas las opciones comunes y ninguna opción adicional.

El tamaño de búfer por defecto para el algoritmo de beat es 1024. El tamaño de salto por defecto es 512.

NOTES

Las siguientes opciones adicionales se pueden usar con el subcomando "notes".

-s <valor>, --silence <valor>
umbral de silencio, en dB (por defecto: -70)
-d <valor>, --release-drop <valor>
nivel de caída de liberación, en dB. Si el nivel cae más que esta cantidad desde que comenzó la última nota, la nota se apagará (por defecto: 10).

MFCC

El comando "mfcc" acepta todas las opciones comunes y ninguna opción adicional.

MELBANDS

El comando "melbands" acepta todas las opciones comunes y ninguna opción adicional.

EJEMPLOS

Extraer onsets usando un intervalo inter-onset mínimo de 30ms:

    aubio onset /ruta/al/archivo_entrada -M 30ms
Extraer pitch con el método "mcomb" y un umbral de silencio de -90dB: 
    aubio pitch /ruta/al/archivo_entrada -m mcomb -s -90.0
Extraer MFCC usando la implementación estándar de Slaney: 
    aubio mfcc /ruta/al/archivo_entrada -r 44100
