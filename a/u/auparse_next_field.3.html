AUPARSE_NEXT_FIELD(3) API de Auditoría de Linux AUPARSE_NEXT_FIELD(3)

NOMBRE

auparse_next_field - mover el cursor del campo

SINOPSIS

#include <auparse.h>

int auparse_next_field(const auparse_state_t *au);"

DESCRIPCIÓN

auparse_next_field mueve el cursor interno de la biblioteca para que apunte al siguiente campo en el registro actual del evento actual.

VALOR DE RETORNO

Devuelve 0 si no existen más campos y 1 si la operación fue exitosa.

VER TAMBIÉN

auparse_next_record(3).
