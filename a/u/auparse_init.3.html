AUPARSE_INIT(3) API de auditoría de Linux AUPARSE_INIT(3)

NOMBRE

auparse_init - inicializa una instancia de la biblioteca de análisis de auditoría

SINOPSIS

#include <auparse.h>

auparse_state_t * auparse_init(ausource_tfuente,constvoid*"b);"

DESCRIPCIÓN

auparse_init inicializa una instancia de la biblioteca de análisis de auditoría. La función devuelve un puntero opaco al estado interno del analizador. Se utiliza en llamadas posteriores a la biblioteca. La variable `fuente` determina dónde busca la biblioteca los datos. Los valores legales pueden ser:

AUSOURCE_LOGS - usar registros de auditoría
AUSOURCE_FILE - usar un archivo
AUSOURCE_FILE_ARRAY - usar varios archivos
AUSOURCE_BUFFER - usar un búfer
AUSOURCE_BUFFER_ARRAY - usar una matriz de búferes
AUSOURCE_DESCRIPTOR - usar un descriptor particular
AUSOURCE_FILE_POINTER - usar un puntero FILE de stdio
AUSOURCE_FEED - alimentar datos al analizador con auparse_feed()

El puntero 'b' se utiliza para establecer el nombre del archivo, la matriz de nombres de archivos, la dirección del búfer o una matriz de punteros a búferes, o el número de descriptor según la fuente dada. Cuando la fuente de datos es una matriz de archivos o búferes, crearía una matriz de punteros con el último siendo un puntero NULL. Los búferes deben terminar en NUL.

La estructura de datos devuelta por auparse_init no es segura para subprocesos. Si necesita usarla en un programa multihilo, deberá agregar bloqueos alrededor de cualquier uso de la estructura de datos.

VALOR DE RETORNO

Devuelve un puntero NULL si ocurre un error; de lo contrario, el valor de retorno es un puntero opaco al estado interno del analizador.

VER TAMBIÉN

auparse_reset(3), auparse_destroy(3). auparse_feed(3).
