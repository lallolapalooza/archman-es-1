AUPARSE_ADD_CALLBACK(3) API de Auditoría de Linux AUPARSE_ADD_CALLBACK(3)

NOMBRE

auparse_add_callback - agregar un manejador de devolución de llamada para notificaciones

SINOPSIS

#include <auparse.h>

void auparse_add_callback(auparse_state_t *au, auparse_callback_ptr callback, void *user_data, user_destroy user_destroy_func);

DESCRIPCIÓN

auparse_add_callback agrega una función de devolución de llamada al estado de análisis que se invoca para notificar a la aplicación de eventos de análisis. Esto es parte de la API de fuente de eventos.

La firma de la devolución de llamada es:

void
auparse_callback(auparse_state_t *au, auparse_cb_event_t cb_event_type,
                 void *user_data);

Cuando se invoca la devolución de llamada, se le pasa:

au

un puntero al estado de análisis
cb_event_type
valor enumerado que indica la razón por la que se invocó la devolución de llamada
user_data
puntero a datos privados proporcionados por el usuario. Puede ser NULL.
user_destroy_func
puntero a una función que se llama cuando se destruyen los datos del usuario. Puede ser NULL. La firma es: 
void destroy(void *user_data);

La función destroy() debe estar preparada para aceptar que user_data pueda ser NULL.

El argumento cb_event_type indica por qué se invocó la devolución de llamada. Sus posibles valores son:

AUPARSE_CB_EVENT_READY
Se ha analizado un evento completo y está listo para ser examinado. Esto es lógicamente equivalente al estado de análisis inmediatamente posterior a auparse_next_event()

Consulte auparse_feed(3) para ver un ejemplo de código completo.

VALOR DE RETORNO

Ninguno.

VER TAMBIÉN

auparse_feed(3), auparse_flush_feed(3).
