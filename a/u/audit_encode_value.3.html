AUDIT_ENCODE_VALUE(3) API de auditoría de Linux AUDIT_ENCODE_VALUE(3)

NOMBRE

audit_encode_value - codifica una cadena de entrada a una cadena de código ASCII

SINOPSIS

#include <libaudit.h>
char *audit_encode_value(char *final, const char *buf, unsigned int size);

DESCRIPCIÓN

audit_encode_value() codifica una cadena dada por buf a una cadena de código ASCII. final es la cadena hexadecimal codificada a código ASCII. size es la longitud de la cadena dada por buf.

por ejemplo: "foo bar" se codifica como "666F6F20626172". "\1\2\3\4" se codifica como "01020304".

VALOR DE RETORNO

Devuelve una cadena codificada, igual que final o NULL si hay un error.

VER TAMBIÉN

audit_encode_nv_string(3), audit_value_needs_encoding(3).
