NOMBRE

auto-multiple-choice-prepare - Crea documentos a partir de archivos fuente LaTeX

SINOPSIS

auto-multiple-choice prepare --mode s --prefix dir-proyecto archivo-fuente-mcq

auto-multiple-choice prepare --mode b --data dir-datos-proyecto archivo-fuente-mcq

DESCRIPCIÓN

El comando auto-multiple-choice prepare genera documentos a partir de archivos fuente que describen preguntas de examen de opción múltiple. La salida depende del valor del argumento --mode. En cualquier modo, el nombre del archivo fuente debe especificarse como argumento.

• Al usar «--mode s», auto-multiple-choice prepare crea un archivo de preguntas de examen (papel de examen para imprimir y distribuir a los examinados), un archivo de soluciones modelo (papel con las respuestas marcadas) y un archivo de información de posición (archivo que contiene información sobre la posición de los cuadros en la página). Los siguientes argumentos pueden ser utilizados:

--out-sujet sujeto.pdf

Establece el nombre del archivo de preguntas de examen a crear.

--out-corrige corregido.pdf

Establece el nombre del archivo de soluciones modelo a crear.

--out-calage calage.xy

Establece el nombre del archivo de información de posición a crear.

--prefix directorio

Cuando alguno de los tres anteriores no se especifica, este directorio es necesario. Entonces, sus valores por defecto son directorio/sujet.pdf, directorio/corrige.pdf y directorio/calage.xy.
• Al usar «--mode b», auto-multiple-choice prepare extrae una base de corrección a partir del archivo fuente. En este modo, el argumento --data (ver abajo) debe ser utilizado.

Los siguientes argumentos de opción pueden usarse en cualquier modo:

--with motor-latex

Especifica el motor LaTeX (comando) a usar. motor-latex puede ser, por ejemplo, pdflatex o xelatex.

--filter filtro

Establece el nombre del filtro que convierte el archivo fuente de preguntas de examen de opción múltiple a un archivo LaTeX. Los filtros integrados son latex (sin conversión) y plain (fuente AMC-TXT).

--filtered-source archivo-latex-mcq

Especifica el nombre del archivo LaTeX generado a partir del archivo fuente usando el filtro especificado. Si se omite, se usa el nombre de archivo archivo-fuente-mcq con el sufijo _filtered.tex.

--n-copies n

Establece el número de copias del examen a generar y sobrescribe el número de copias especificado en el primer argumento de \onecopy en el archivo fuente LaTeX.

--debug archivo.log

Especifica el archivo donde se registrará la información de depuración.

--epoch EPOCH

Establece la fecha (número de segundos desde el 1 de enero de 1970) para que la generación del PDF sea siempre la misma, sin importar cuántas veces se genere.

--data dir-datos-proyecto

Especifica el directorio donde se almacenará el archivo de datos SQLite.
