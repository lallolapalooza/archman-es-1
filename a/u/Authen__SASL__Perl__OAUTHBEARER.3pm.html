Authen::SASL::Perl::OAUTHBEARER(3) Documentación de Perl contribuida por el usuario Authen::SASL::Perl::OAUTHBEARER(3)

NOMBRE

Authen::SASL::Perl::OAUTHBEARER - Clase de autenticación OAUTHBEARER

VERSIÓN

versión 2.1900

SINOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'OAUTHBEARER',
  callback  => {
    user => $user,
    pass => $access_token
  },
);

DESCRIPCIÓN

Este módulo implementa el lado del cliente del mecanismo SASL OAUTHBEARER, que se utiliza para la autenticación basada en OAuth 2.0.

CALLBACK

Los callbacks utilizados son:

Cliente

usuario
El nombre de usuario que se utilizará para la autenticación.
contraseña
El token de acceso OAuth 2.0 que se utilizará para la autenticación.
