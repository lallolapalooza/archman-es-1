Paquete: autoconf

AUTOM4TE(1) Comandos de usuario AUTOM4TE(1)

NOMBRE

autom4te - Genera archivos y scripts gracias a M4

SINOPSIS

autom4te [OPCIÓN]... [ARCHIVOS]

DESCRIPCIÓN

Ejecuta GNU M4 sobre los ARCHIVOS, evitando ejecuciones inútiles. Muestra las trazas si se realiza trazado, el archivo congelado si se realiza congelado, de lo contrario la expansión de los ARCHIVOS.

Si algunos de los ARCHIVOS se denominan 'ARCHIVO.m4f', se consideran archivos M4 congelados de todos los archivos anteriores (que por lo tanto no se cargan). Si no se encuentra 'ARCHIVO.m4f', se utilizará 'ARCHIVO.m4', junto con todos los archivos anteriores.

Algunos archivos pueden ser opcionales, es decir, solo se procesarán si se encuentran en la ruta de inclusión, pero entonces deben terminar en '.m4?'; el signo de interrogación no forma parte del nombre real del archivo.

Modos de operación:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra el número de versión y sale
-v, --verbose
informa detalladamente sobre el procesamiento
-d, --debug
no elimina los archivos temporales
-o, --output=ARCHIVO
guarda la salida en ARCHIVO (por defecto '-', salida estándar)
-f, --force
no confía en los valores en caché
-W, --warnings=CATEGORÍA
informa las advertencias que pertenecen a CATEGORÍA (se acepta una lista separada por comas)
-l, --language=IDIOMA
especifica el conjunto de macros M4 a utilizar
-C, --cache=DIRECTORIO
conserva los resultados para futuras ejecuciones en DIRECTORIO
--no-cache
desactiva la caché
-m, --mode=OCTAL
cambia el modo del archivo de salida sin traza (0666)
-M, --melt
no usa archivos M4 congelados

Los idiomas incluyen:

'Autoconf'
crea scripts de configuración de Autoconf
'Autotest'
crea suites de pruebas de Autotest
'M4sh'
crea scripts de shell M4sh
'M4sugar'
crea salida de M4sugar

Las categorías de advertencia son:

cross
problemas de compilación cruzada
gnu
estándares de codificación GNU (por defecto en los modos gnu y gnits)
obsolete
características o construcciones obsoletas (por defecto)
override
redefiniciones por parte del usuario de reglas o variables de Automake
portability
problemas de portabilidad (por defecto en los modos gnu y gnits)
portability-recursive
variables de Make anidadas (por defecto con -Wportability)
extra-portability
problemas de portabilidad adicionales relacionados con herramientas poco conocidas
syntax
construcciones sintácticas dudosas (por defecto)
unsupported
características no soportadas o incompletas (por defecto)

-W también entiende:

all
activa todas las advertencias
none
desactiva todas las advertencias
no-CATEGORÍA
desactiva las advertencias en CATEGORÍA
error
trata todas las advertencias activadas como errores

Se respetan las variables de entorno 'M4' y 'WARNINGS'.

Directorios de biblioteca:

-B, --prepend-include=DIR
antepone el directorio DIR a la ruta de búsqueda
-I, --include=DIR
añade el directorio DIR a la ruta de búsqueda

Trazado:

-t, --trace=MACRO[:FORMATO]
informa las invocaciones de MACRO
-p, --preselect=MACRO
prepara para rastrear MACRO en una ejecución futura

Congelado:

-F, --freeze
produce un archivo de estado congelado de M4 para los ARCHIVOS

FORMATO por defecto es '$f:$l:$n:$%', y puede usar los siguientes escapes:

$$
$ literal
$f
archivo donde se llamó a la macro
$l
línea donde se llamó a la macro
$d
profundidad de anidamiento de la llamada a la macro
$n
nombre de la macro
$NUM
argumento NUM, sin comillas y con saltos de línea
$SEP@
todos los argumentos, con saltos de línea, entrecomillados y separados por SEP
$SEP*
todos los argumentos, con saltos de línea, sin comillas y separados por SEP
$SEP%
todos los argumentos, sin saltos de línea, sin comillas y separados por SEP

SEP puede estar vacío para el valor por defecto (coma para @ y *, dos puntos para %), un solo carácter para ese carácter, o {CADENA} para usar una cadena.
