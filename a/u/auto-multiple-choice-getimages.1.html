NOMBRE

auto-multiple-choice-getimages - prepara las imágenes escaneadas antes de enviarlas a auto-multiple-choice-analyse(1) para su análisis

SINOPSIS

auto-multiple-choice getimages [--copy-to proyecto-escaneos-dir] [--vector-density densidad] --list archivo-lista [archivos-escaneados...]

DESCRIPCIÓN

El comando auto-multiple-choice getimages prepara los archivos escaneados antes de enviarlos a auto-multiple-choice-analyse(1):

•los archivos de imagen multipágina se dividen para obtener un archivo por página.
•las imágenes vectoriales (como PDF, EPS) se convierten a imágenes de mapa de bits.

Las imágenes de entrada se pueden proporcionar como argumentos a auto-multiple-choice getimages, o como el nombre de un archivo que contiene todas las rutas de los archivos escaneados.

--list archivo-lista

proporciona el nombre del archivo que opcionalmente contiene (uno por línea) las rutas de los archivos escaneados. Este archivo se borrará y se llenará con las rutas de los archivos escaneados después del procesamiento, de modo que la misma ruta se pueda pasar a auto-multiple-choice analyse como valor de la opción --list-fichiers.

--copy-to proyecto-escaneos-dir

proporciona un directorio donde copiar todos los archivos escaneados.

--vector-density densidad

establece la densidad utilizada para convertir escaneos de gráficos vectoriales a archivos de mapa de bits. El valor predeterminado es 300.
