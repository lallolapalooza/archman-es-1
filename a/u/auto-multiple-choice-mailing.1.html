NOMBRE

auto-multiple-choice-mailing - envía por correo electrónico las hojas de respuestas completas y anotadas en PDF a los estudiantes

SINOPSIS

auto-multiple-choice mailing [--xmlargs args.xml] --project dir-proyecto --students-list lista-estudiantes.csv [--list-encoding codificación] --email-column col --sender email-remitente --subject asunto --text cuerpo-del-email [--text-content-type tipo-contenido] [--debug archivo.log] [argumentos-transporte...]

DESCRIPCIÓN

El comando auto-multiple-choice mailing envía por correo electrónico las hojas de respuestas completas y anotadas en PDF a los estudiantes. Las direcciones de correo electrónico se toman del archivo de lista de estudiantes.

--project dir-proyecto

Indica el directorio del proyecto.

--students-list lista-estudiantes.csv

Establece el nombre del archivo de lista de estudiantes.

--list-encoding codificación

Selecciona una codificación para el archivo lista-estudiantes.csv (por defecto es utf-8).

--email-column col

Establece el nombre de la columna que contiene las direcciones de correo electrónico de los estudiantes en el archivo de lista de estudiantes.

--sender email-remitente

Establece el remitente del correo electrónico.

--cc direccion-email-cc

Establece la dirección de correo electrónico de copia carbón.

--bcc direccion-email-cco

Establece la dirección de correo electrónico de copia carbón oculta.

--subject asunto

Establece el asunto de los correos electrónicos a enviar.

--text cuerpo-del-email

Establece el texto del cuerpo de los correos electrónicos a enviar.

--text-content-type tipo-contenido

Establece el tipo de contenido del texto del correo electrónico. tipo-contenido puede ser text/plain o text/html.

--attach nombre-archivo

Añade el archivo nombre-archivo como un adjunto a todos los correos electrónicos enviados. Usa esta opción varias veces para adjuntar múltiples archivos.

--transport transporte

Establece el transporte a usar. transporte puede ser sendmail o SMTP.

--debug archivo.log

Indica un archivo para rellenar con información de depuración.

--delay tiempo

Establece un retardo de tiempo segundos entre cada envío.

ARGUMENTOS DE TRANSPORTE

Dependiendo del valor utilizado para el argumento transporte, se pueden añadir los siguientes argumentos:

Transporte sendmail

--sendmail-path ruta

Establece la ruta al comando sendmail (por defecto es /usr/sbin/sendmail).

Transporte SMTP

--smtp-host host

Establece el nombre de host SMTP (por defecto es smtp).

--smtp-port puerto

Establece el puerto a utilizar (el valor por defecto es 25).

--smtp-ssl modo

Establece el modo de seguridad para la conexión SMTP. La opción modo puede ser ssl, starttls, o 0 (no seguro).

--smtp-user usuario

Establece el nombre de usuario para SMTP autenticado.

--smtp-passwd-file archivo

Indica la ruta de un archivo que contiene la contraseña (como la primera línea del archivo) para SMTP autenticado.

ARGUMENTOS EN UN ARCHIVO XML

Para evitar problemas de codificación, se pueden colocar algunos argumentos en un archivo XML y usar el argumento --xmlargs archivo.xml como primer argumento del comando. Aquí hay un ejemplo de dicho archivo:

<?xml version="1.0" encoding="UTF-8"?>
<arguments>
  <arg>--sender</arg><arg>Bienvenüe &lt;paamc@passoire.fr&gt;</arg>
  <arg>--text</arg><arg>Voilà votre copie corrigée</arg>
  <arg>--subject</arg><arg>QCM</arg>
</arguments>
