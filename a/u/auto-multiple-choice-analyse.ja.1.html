NOMBRE

auto-multiple-choice-analyse - Analiza automáticamente imágenes escaneadas de exámenes de opción múltiple de AMC

RESUMEN

auto-multiple-choice analyse --proyecto directorio-proyecto [--umbral-marca umbral] [--tol-marca tol] [--lista-archivos lista-archivos.txt | archivos-escaneo...]

DESCRIPCIÓN

El comando auto-multiple-choice analyse realiza el reconocimiento automático de marcas en las imágenes escaneadas de los exámenes de opción múltiple de AMC. Antes de llamar a auto-multiple-choice analyse, debes llamar a auto-multiple-choice-prepare(1) para crear los archivos de trabajo (--modo s) y los archivos MEP (--modo m), y haber procesado el diseño con auto-multiple-choice-meptex(1).

--data directorio-datos

Especifica el directorio donde se encuentran los archivos de datos (ver auto-multiple-choice-meptex(1)). El valor por defecto es data en directorio-proyecto.

--cr directorio-cr-proyecto

Especifica el directorio donde se crean las imágenes para el reconocimiento de marcas (las imágenes de zoom para los casilleros se guardan en el subdirectorio zooms, las imágenes de las entradas de nombres en el archivo name-*.jpg, y las imágenes de los resultados del diseño en el archivo page-*.jpg).

--proyecto directorio-proyecto

Si no se usa --cr, esta opción se usa y directorio-cr-proyecto se establece en cr en directorio-proyecto.

Hay dos maneras de especificar los nombres de los archivos escaneados a procesar:

• Especificar los nombres de archivo como argumentos.
• Listar los nombres de archivo (un nombre de archivo por línea) en un archivo de lista-archivos y especificar este archivo con --lista-archivos.

Los parámetros para el reconocimiento de marcas se pueden establecer usando las siguientes opciones:

--prop proporción

Establece la proporción del área para determinar la presencia de marca para cada casillero. El valor por defecto es 0.8.

--bw-threshold umbral

Este parámetro se utiliza para convertir la imagen escaneada en escala de grises a blanco y negro. Aumentar el valor hará que más píxeles se consideren negros, y disminuirlo hará que más píxeles se consideren blancos. El valor debe estar entre 0 y 1. El valor por defecto es 0.6.

--ignorar-rojo

Usar esta opción hará que solo se utilice el canal rojo de las imágenes escaneadas en color. Esto significa que todo lo escrito en rojo en las imágenes escaneadas se ignorará. Es útil cuando los casilleros están impresos en rojo.

--tol-marca tol

Define la tolerancia para detectar las marcas en las esquinas de la imagen escaneada. Para detectar las marcas, se buscan áreas conectadas oscuras de un tamaño *cercano* al tamaño objetivo *target* (el tamaño exacto de la marca si la impresión y el escaneo fueran perfectos). Si tol es un número real simple, el tamaño se considera cercano si está entre (1-tol)*target y (1+tol)*target. Si tol tiene el formato "tinf,tsup" (donde tinf y tsup son números reales), entonces el rango es entre (1-tinf)*target y (1+tsup)*target. El valor por defecto es 0.2.

--multiple

Esta opción se usa cuando se copian los exámenes (es decir, cuando varios examinados responden al mismo examen). En este caso, se asigna un número de copia a los exámenes para que los exámenes de la misma pregunta puedan distinguirse.

--pre-allocate id_copia

Esta opción se usa junto con --multiple. Los números de copia para cada escaneo comienzan en id_copia y continúan según el número de escaneos proporcionados como argumento.

auto-multiple-choice-analyse(1) — auto-multiple-choice-analyse Manual

NOMBRE

auto-multiple-choice-analyse

SINOPSIS

auto-multiple-choice-analyse [options] <nomarchivo>

DESCRIPCIÓN

Analiza un archivo de entrada y genera varios archivos de salida.

El archivo de entrada especificado debe ser una imagen multipágina (como un PDF o un TIFF) que contenga las respuestas de los estudiantes.

Se pueden especificar varios argumentos de línea de comandos.

Cada opción de línea de comandos que espera un nombre de archivo se puede especificar varias veces. Los archivos se procesan en el mismo orden que se dan en la línea de comandos.

Cada opción de línea de comandos que espera un nombre de archivo puede ser especificada varias veces. Los archivos se procesan en el mismo orden que se dan en la línea de comandos.

Cada opción de línea de comandos que espera un nombre de archivo se puede especificar varias veces. Los archivos se procesan en el mismo orden que se dan en la línea de comandos.

OPCIONES

--verbose

Activa la información detallada sobre el progreso de análisis.

--quiet

Suprime la mayor parte de la información que se muestra en la pantalla.

--sheet <nomarchivo.pdf>

Especifica el nombre de un archivo que contiene las plantillas de las hojas de respuesta.

--list <nomarchivo.txt>

Especifica el nombre de un archivo que contiene la lista de nombres de estudiantes.

--layout <nomarchivo.xml>

Especifica el nombre de un archivo que contiene la disposición de las preguntas.

--filter <nomarchivo.tex>

Especifica el nombre de un archivo que contiene las instrucciones de filtrado para la creación de listas de nombres.

--grading <nomarchivo.txt>

Especifica el nombre de un archivo que contiene las respuestas correctas.

--images <directorio>

Especifica el nombre de un directorio donde se guardarán las imágenes de las preguntas.

--data <directorio>

Especifica el nombre de un directorio donde se guardarán los datos de análisis.

--append

Anexa los resultados de este análisis a los que ya existen en el directorio de datos.

--log <nomarchivo.log>

Especifica el nombre de un archivo donde se guardará la información de registro.

--n <número>

Especifica el número de copias de cada hoja de respuesta que se van a generar.

--multiple <número>

Especifica el número de hojas de respuesta que se van a imprimir en cada página.

--copy <número>

Especifica el número de copias de cada hoja de respuesta que se van a generar.

--print <nomarchivo.ps>

Especifica el nombre de un archivo PostScript que contendrá las hojas de respuesta impresas.

--no-print

No genera un archivo PostScript.

--crop <nomarchivo.pdf>

Especifica el nombre de un archivo PDF que contendrá las hojas de respuesta recortadas.

--no-crop

No genera un archivo PDF recortado.

--correct <nomarchivo.txt>

Especifica el nombre de un archivo de texto que contiene las respuestas correctas para cada pregunta.

--correction <nomarchivo.pdf>

Especifica el nombre de un archivo PDF que contendrá las hojas de respuesta corregidas.

--no-correction

No genera un archivo PDF corregido.

--strip <nomarchivo.pdf>

Especifica el nombre de un archivo PDF que contendrá las hojas de respuesta despojadas.

--no-strip

No genera un archivo PDF despojado.

--template <nomarchivo.tex>

Especifica el nombre de un archivo LaTeX que contendrá la plantilla para las hojas de respuesta.

--only-template

Genera solo la plantilla LaTeX.

--only-sheet

Genera solo las hojas de respuesta.

--only-log

Genera solo el archivo de registro.

--only-data

Genera solo el archivo de datos.

--only-images

Genera solo las imágenes de las preguntas.

--only-correction

Genera solo el archivo de corrección.

--try-three | --no-try-three

Indica si se deben procesar o no los casos en los que los cuatro marcadores no se pueden reconocer.

--debug <archivo.log>

Especifica el archivo donde se registrará la información de depuración.
