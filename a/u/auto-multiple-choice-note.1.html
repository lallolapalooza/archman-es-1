NOMBRE

auto-multiple-choice-note - calcula las calificaciones después de la captura de datos de escaneo para exámenes de opción múltiple de AMC.

SINOPSIS

auto-multiple-choice note --data dir-datos-proyecto [--seuil umbral] [--grain granularidad] [--arrondi redondeo] [--notemin min] [--notemax max] [--no-plafond | --plafond]

DESCRIPCIÓN

El comando auto-multiple-choice note calcula las calificaciones para todos los estudiantes a partir de la estrategia de puntuación extraída del archivo fuente LaTeX por auto-multiple-choice-prepare(1) y de los informes de captura de datos realizados por auto-multiple-choice-analyse(1).

--data dir-datos-proyecto

indica el directorio donde se encuentran los archivos de datos (ver por ejemplo auto-multiple-choice-meptex(1)).

--seuil umbral

indica el umbral de proporción de negro para decidir si una casilla está marcada o no. Al decidir si una casilla está marcada o no, auto-multiple-choice note compara la proporción de negro (número de píxeles negros sobre el número total de píxeles) con el umbral. Si la proporción de negro es mayor que el umbral, la casilla se declara marcada. Los valores estándar pueden ser 0.15 en el diseño estándar, o 0.5 para el diseño de hoja de respuestas separada (en este último caso, se dibujan letras en las casillas y se indica a los estudiantes que rellenen completamente las casillas).

--seuil-up umbral-superior

indica el umbral de proporción de negro por encima del cual una casilla se considera no marcada. Puede establecer este valor a (por ejemplo) 0.6 para permitir a los estudiantes cancelar una casilla marcada rellenándola por completo: si la proporción de negro está entre el umbral y el umbral-superior, la casilla se considera marcada, pero si la proporción de negro es mayor que el umbral-superior (por ejemplo, cuando la casilla está completamente rellena), la casilla se considera no marcada. El valor predeterminado es 1.0, por lo que esta función está deshabilitada.

--grain granularidad --arrondi redondeo

solicita que las calificaciones se redondeen a un múltiplo de granularidad. Si redondeo es 'i', el redondeo se hace por debajo (como con floor(3)). Si redondeo es 'n', el redondeo se hace al múltiplo más cercano de granularidad. Si redondeo es 's', el redondeo se hace por encima (como con ceil(3)). Por ejemplo, con las opciones "--grain 0.25 --arrondi s", la calificación 6.285 se redondea a 6.5.

--notemin min

con esta opción, todas las calificaciones inferiores a min serán reemplazadas por min.

--notemax max

indica la calificación a asociar a una hoja donde todas las respuestas son correctas. Si no se utiliza, las calificaciones no se escalan.

--plafond

con esta opción, todas las calificaciones superiores a max serán reemplazadas por max.

--debug archivo.log

indica un archivo para rellenar con información de depuración.

--postcorrect-student s --postcorrect-copy c

solicita corrección posterior a partir de la hoja de respuestas completada identificada por los números de estudiante y copia. En el modo de corrección posterior, las respuestas correctas no se extraen del archivo fuente LaTeX, sino que se toman de las respuestas dadas en esta hoja.
