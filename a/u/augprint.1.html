DESCRIPCIÓ

N

augprint crea un script de augtool para un FILE dado, que consta principalmente de comandos

"set".

El script de augtool resultante está diseñado para ser idempotente y no producirá ningún cambio cuando se aplique al archivo

original.

augprint reemplaza cada ubicación numerada en el árbol con una expresión de ruta que identifica de forma única la posición utilizando los valores dentro de esa

posición.

Esto hace que la expresión de ruta sea independiente del número de posición y, por lo tanto, aplicable a archivos en los que los mismos datos puedan existir en un número de posición

alternativo.

Consulte "Ejemplos" para ver una salida de

ejemplo.

Salida

de

Expresiones regulares Por defecto, augprint produce expresiones de ruta compuestas por comparaciones de igualdad simple

s

1'

La opción --regexp cambia la salida para producir comparaciones con expresiones

regulares 
set /files/etc/hosts/seq::*[ipaddr=~regexp('127\\.0\\..*')]/ipaddr '127.0.0.
1'

La longitud mínima N de la expresión regular puede especificarse usando "--regexp=N

"

augprint elegirá una expresión regular más larga que N si múltiples valores coincidirían usando la expresión regular d

e N c
aracteres.

Limitacione

s

Solo

adiciones

La salida se basa principalmente en operaciones de establecimiento (set). La operación set solo

puede:

a) cambiar un valor existente in

situ

b) añadir un nuevo valor después de la última posición del

grupo

Esto significa que cuando se vuelve a crear una entrada, esta puede no estar en la misma posición que la originalmente pretendida. Es decir, si la entrada para 192.0.2.3 no existe ya, se creará como la última entrada en /etc/host

s

A menudo, estas entradas fuera de secuencia no importarán para el archivo de configuración resultante. Si importa, se requerirá una edición manual adicional del script "aug

tool".

Valores

repetidos

augprint no siempre tiene éxito al encontrar una expresión de ruta única para una posición. En este caso, augprint añade una posición a una expresión que no es

única.

Esto ocurre en particular si hay valores repetidos dentro del

archivo.

Para un archivo /etc/hosts

de

#------

augprint produciría la

set /files/etc/hosts/#comment[.='--------'][2]
'--------'

Observe cómo a las rutas "#comment" se les añaden "[1]" y "[2]" respectivamente después del "[expr]

"

Usando

--lens

Si un archivo no está asociado con una lente de forma predeterminada, se puede usar --lens nombre-de-lente para especificar una

lente.

Cuando se especifica --lens, la salida se antepone con las declaraciones "transform" y "load-file" adecuadas, según se requiera para completar el script de augtool, y una declaración setm para excluir otras lentes cargadas automáticamente

.

bashrc" 
setm /augeas/load/*[incl='/etc/skel/.bashrc' and label() != 'shellvars']/excl '/etc/skel/.bashrc'
transform shellvars incl /etc/skel/.bashrc
load-file /etc/skel/.bashrc
set /files/etc/skel/.bashrc/#comment[.='.bashrc'] '.bashrc'
set /files/etc/skel/.bashrc/#comment[.='Source global definitions'] 'Source global definitions'
set /files/etc/skel/.bashrc/@if[.='[ -f /etc/bashrc ]'] '[ -f /etc/bashrc ]'
set /files/etc/skel/.bashrc/@if[.='[ -f /etc/bashrc ]']/.source '/etc/bashrc'
set /files/etc/skel/.bashrc/#comment[.='User specific environment'] 'User specific environment'
..
