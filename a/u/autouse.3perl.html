autouse(3perl) Guía de referencia para programadores de Perl autouse(3perl)

NOMBRE

autouse - posponer la carga de módulos hasta que se use una función

SINOPSIS

use autouse 'Carp' => qw(carp croak);
carp "esta carp fue predeclarada y autoused ";

DESCRIPCIÓN

Si el módulo "Module" ya está cargado, entonces la declaración

use autouse 'Module' => qw(func1 func2($;$));

es equivalente a

use Module qw(func1 func2);

si "Module" define func2() con el prototipo "($;$)", y func1() no tiene prototipos. (Al menos si "Module" usa el "import" de "Exporter", de lo contrario es un error fatal.)

Si el módulo "Module" aún no está cargado, entonces la declaración anterior declara las funciones func1() y func2() en el paquete actual. Cuando estas funciones se llaman, cargan el paquete "Module" si es necesario, y se sustituyen a sí mismas con las definiciones correctas.

ADVERTENCIA

Usar "autouse" moverá pasos importantes de la ejecución de su programa de tiempo de compilación a tiempo de ejecución. Esto puede

  • Romper la ejecución de su programa si el módulo que "autouse"d tiene alguna inicialización que espera que se haga temprano.
  • Ocultar errores en su código ya que las comprobaciones importantes (como la corrección de los prototipos) se mueven de tiempo de compilación a tiempo de ejecución. En particular, si el prototipo que especificó en la línea "autouse" es incorrecto, no lo descubrirá hasta que se ejecute la función correspondiente. Esto será muy desafortunado para las funciones que no se llaman siempre (tenga en cuenta que para tales funciones la "autouse" da la mayor ganancia, para una solución alternativa ver abajo).

Para aliviar el segundo problema (parcialmente) se aconseja escribir sus scripts de esta manera:

use Module;
use autouse Module => qw(carp($) croak(&$));
carp "esta carp fue predeclarada y autoused ";

La primera línea asegura que los errores en la especificación de sus argumentos se encuentran temprano. Cuando envíe su aplicación, debería comentar la primera línea, ya que hace que la segunda sea inútil.
