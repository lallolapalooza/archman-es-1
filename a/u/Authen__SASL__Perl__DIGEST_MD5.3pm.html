Authen::SASL::Perl::DIGEST_MD5(3) Documentación de Perl aportada por el usuario Authen::SASL::Perl::DIGEST_MD5(3)

NOMBRE

Authen::SASL::Perl::DIGEST_MD5 - (OBSOLETO) Clase de autenticación Digest MD5

VERSIÓN

versión 2.1900

SINOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'DIGEST-MD5',
  callback  => {
    user => $user, 
    pass => $pass,
    serv => $serv
  },
);

DESCRIPCIÓN

Este método implementa las partes del cliente y del servidor del algoritmo SASL DIGEST-MD5, según se describe en la RFC 2831.

Tenga en cuenta que este mecanismo se ha trasladado a la sección "OBSOLETO" del registro de mecanismos https://www.iana.org/assignments/sasl-mechanisms/sasl-mechanisms.xhtml según la RFC6331 https://www.rfc-editor.org/rfc/rfc6331.html.

CALLBACK

Los callbacks utilizados son:

cliente

authname
El ID de autorización a utilizar después de una autenticación exitosa
user
El nombre de usuario a utilizar en la respuesta
pass
La contraseña a utilizar para calcular la respuesta.
serv
El nombre del servicio al autenticarse en un servicio replicado
realm
El ámbito de autenticación al anular el predeterminado proporcionado por el servidor. Si no se proporciona, se utiliza el valor proporcionado por el servidor.

El callback recibirá la lista de ámbitos que el servidor proporcionó en la respuesta inicial.

servidor

realm
El ámbito predeterminado a proporcionar al cliente
getsecret(username, realm, authzid)
devuelve la contraseña asociada con "username" y "realm"

PROPIEDADES

Las propiedades utilizadas son:

maxbuf
El tamaño máximo del búfer para recibir texto cifrado
minssf
El valor SSF mínimo que debe proporcionar la capa de seguridad SASL. El valor predeterminado es 0
maxssf
El valor SSF máximo que debe proporcionar la capa de seguridad SASL. El valor predeterminado es 2**31
externalssf
El valor SSF proporcionado por una capa de seguridad externa subyacente. El valor predeterminado es 0
ssf
El valor SSF real proporcionado por la capa de seguridad SASL después de completar la fase de autenticación SASL. Este valor es de solo lectura y se establece por la implementación después de completar la fase de autenticación SASL.
maxout
El tamaño máximo del búfer de texto plano para enviar datos al par. Este valor se establece por la implementación después de completar la fase de autenticación SASL y cuando una capa de seguridad SASL está activa.
