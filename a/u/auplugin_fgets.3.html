auplugin_fgets(3)

Paquete: audit

Licencias: GPL-2.0-or-later, LGPL-2.0-or-later

AUPLUGIN_FGETS(3) API de auditoría de Linux AUPLUGIN_FGETS(3)

NOMBRE

auplugin_fgets, auplugin_fgets_more, auplugin_fgets_eof, auplugin_fgets_clear, auplugin_setvbuf, auplugin_setvbuf_r - auxiliares de lectura de línea en búfer

SINOPSIS

#include <auplugin.h>

int auplugin_fgets(char *buf, size_t blen, int fd);
int auplugin_fgets_more(size_t blen);
int auplugin_fgets_eof(void);
void auplugin_fgets_clear(void);
int auplugin_setvbuf(void *buf, size_t buff_size, enum auplugin_mem how);
int auplugin_setvbuf_r(auplugin_fgets_state_t *st, void *buf, size_t buff_size, enum auplugin_mem how);

DESCRIPCIÓN

auplugin_fgets lee desde fd hacia buf hasta blen bytes o hasta el siguiente salto de línea. El texto se acumula entre llamadas en un búfer interno para que se puedan devolver líneas completas. La cadena se termina con NUL.

auplugin_fgets_more comprueba si el búfer contiene un salto de línea o al menos blen - 1 bytes.

auplugin_fgets_eof indica si se ha alcanzado el final del archivo en fd

auplugin_fgets_clear reinicia el búfer interno y el estado de EOF, descartando cualquier texto almacenado. Cuando el tipo de memoria es MEM_MMAP_FILE, el búfer se rebobina al principio, haciendo que todo el archivo esté disponible nuevamente.

auplugin_setvbuf apunta el búfer interno a buf y establece cómo se liberará cuando se llame a auplugin_fgets_destroy. El parámetro how debe ser uno de MEM_SELF_MANAGED, MEM_MALLOC, MEM_MMAP, o MEM_MMAP_FILE. El valor predeterminado es MEM_SELF_MANAGED, lo que significa que no se realiza ninguna acción sobre el bloque de memoria. Cuando se usa MEM_MMAP_FILE, el búfer se trata como un búfer precargado (todo el archivo) y no se realizarán lecturas en el descriptor proporcionado a auplugin_fgets_r. La forma reentrante auplugin_setvbuf_r opera en un manejador de estado explícito.

Estas funciones mantienen un estado estático y, por lo tanto, no son seguras para hilos.

VALOR DE RETORNO

auplugin_fgets devuelve -1 en caso de error, 0 cuando no hay datos disponibles, o el número de caracteres copiados en caso contrario.

auplugin_fgets_more y auplugin_fgets_eof devuelven 1 para verdadero y 0 para falso.

auplugin_fgets_clear no devuelve ningún valor.

auplugin_setvbuf devuelve 0 en caso de éxito y 1 en caso de fallo.

ANTECEDENTES


La razón por la que se creó esta familia de funciones es que en los complementos de auditd, el flujo de eventos es la entrada estándar, que es el descriptor 0. Un patrón típico es llamar a select, poll o epoll para esperar a que llegue un registro. Tan pronto como lo hace, necesita leerlo. Si usa fgets, tendrá grandes problemas porque no puede mezclar descriptores de bajo nivel con construcciones de alto nivel como struct FILE. Esta familia de funciones le permite trabajar correctamente utilizando solo descriptores, pero con la conveniencia de fgets.
