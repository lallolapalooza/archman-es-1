Authen::SASL::Perl::PLAIN(3) Documentación de Perl aportada por el usuario Authen::SASL::Perl::PLAIN(3)

NOMBRE

Authen::SASL::Perl::PLAIN - Clase de autenticación de inicio de sesión PLAIN

VERSIÓN

versión 2.1900

SINOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'PLAIN',
  callback  => {
    user => $user,
    pass => $pass
  },
);

DESCRIPCIÓN

Este método implementa la parte cliente y servidor del algoritmo SASL PLAIN, como se describe en RFC 2595 respectivamente en el borrador de IETF draft-ietf-sasl-plain-XX.txt

CALLBACK

Los callbacks utilizados son:

Cliente

authname
El ID de autorización a utilizar después de la autenticación exitosa (cliente)
user
El nombre de usuario a utilizar para la autenticación (cliente)
pass
La contraseña del usuario a utilizar para la autenticación.

Servidor

checkpass(username, password, realm)
devuelve verdadero o falso dependiendo de la validez de las credenciales pasadas en los argumentos.

VER TAMBIÉN

Authen::SASL, Authen::SASL::Perl
