AUDIT_DELETE_RULE_DATA(3) API de auditoría de Linux AUDIT_DELETE_RULE_DATA(3)

NOMBRE

audit_delete_rule_data - Eliminar regla de auditoría

SINOPSIS

#include <libaudit.h>
int audit_delete_rule_data(int fd, struct audit_rule_data *rule, int flags, int action);"

DESCRIPCIÓN

audit_delete_rule_data se utiliza para eliminar reglas que están actualmente cargadas en el kernel. El descriptor de archivo se proporciona en fd y la descripción de la regla en rule. Para eliminar una regla, debe configurar las reglas de forma idéntica a la que se va a eliminar. Consulte audit_add_rule_data para las definiciones de flags y action.

VALOR DE RETORNO

El valor de retorno es <= 0 en caso de error, de lo contrario, es el número de identificación de secuencia netlink. Esta función puede tener cualquier error que sendto pudiera encontrar.

VER TAMBIÉN

audit_add_rule_data(3), auditctl(8).
