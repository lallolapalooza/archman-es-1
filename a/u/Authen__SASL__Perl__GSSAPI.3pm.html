Authen::SASL::Perl::GSSAPI(3) Documentación de Perl contribuida por usuarios Authen::SASL::Perl::GSSAPI(3)

NOMBRE

Authen::SASL::Perl::GSSAPI - Clase de autenticación GSSAPI (Kerberosv5)

VERSIÓN

versión 2.1900

SINOPSIS

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new( mechanism => 'GSSAPI' );
$sasl = Authen::SASL->new( mechanism => 'GSSAPI',
                           callback => { pass => $mycred });
$sasl->client_start( $service, $host );

DESCRIPCIÓN

Este método implementa la parte del cliente del algoritmo SASL GSSAPI, según se describe en la RFC 2222 sección 7.2.1 o draft-ietf-sasl-gssapi-XX.txt.

Con una caché de credenciales Kerberos 5 válida (también conocida como TGT) permite conectarse a service@host dados como los dos primeros parámetros al método client_start() de Authen::SASL. Alternativamente, un objeto GSSAPI::Cred puede pasarse a través del hash de callbacks de Authen::SASL usando la clave `pass'.

Tenga en cuenta que este módulo no implementa actualmente una capa de seguridad SASL después de la autenticación. A menos que la conexión esté protegida por otros medios, como TLS, será vulnerable a ataques de tipo man-in-the-middle. Si se requieren capas de seguridad, se debe usar el módulo Authen::SASL::XS GSSAPI en su lugar.

CALLBACK

Los callbacks utilizados son:

authname
La identidad de autorización a utilizar en el intercambio SASL
gssmech
El mecanismo GSS a utilizar en la conexión
pass
Las credenciales GSS a utilizar en la conexión (opcional)

EJEMPLO

 #! /usr/bin/perl -w
 use strict;
use warnings;
 use Net::LDAP 0.33;
 use Authen::SASL 2.10;
 # -------- Ajustar a tu entorno --------
 my $adhost      = 'theserver.bla.net';
 my $ldap_base   = 'dc=bla,dc=net';
 my $ldap_filter = '(&(sAMAccountName=BLAAGROL))';
 my $sasl = Authen::SASL->new(mechanism => 'GSSAPI');
 my $ldap;
 eval {
     $ldap = Net::LDAP->new($adhost,
                            onerror => 'die')
       or  die "No se puede conectar al host LDAP '$adhost': '$@'";
     $ldap->bind(sasl => $sasl);
 };
 if ($@) {
     chomp $@;
     die   "\nError de bind       : $@",
           "\nDetalle del error SASL: ", $sasl->error,
           "\nTerminado";
 }
 print "\nBind de LDAP() exitoso, trabajando en estado autenticado";
 my $mesg = $ldap->search(base   => $ldap_base,
                          filter => $ldap_filter);
 # -------- evaluar $mesg

PROPIEDADES

Las propiedades utilizadas son:

maxbuf
El tamaño máximo del búfer para recibir texto cifrado
minssf
El valor mínimo de SSF que debe proporcionar la capa de seguridad SASL. El valor predeterminado es 0
maxssf
El valor máximo de SSF que debe proporcionar la capa de seguridad SASL. El valor predeterminado es 2**31
externalssf
El valor SSF proporcionado por una capa de seguridad externa subyacente. El valor predeterminado es 0
ssf
El valor SSF real proporcionado por la capa de seguridad SASL después de que se haya completado la fase de autenticación SASL. Este valor es de solo lectura y lo establece la implementación después de que se haya completado la fase de autenticación SASL.
maxout
El tamaño máximo del búfer de texto plano para enviar datos al par. Este valor lo establece la implementación después de que se haya completado la fase de autenticación SASL y esté activa una capa de seguridad SASL.
