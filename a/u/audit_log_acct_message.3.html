AUDIT_LOG_ACCT_MESSAGE(3) API de auditoría de Linux AUDIT_LOG_ACCT_MESSAGE(3)

NOMBRE

audit_log_acct_message - registrar un mensaje de cuenta de usuario

SINOPSIS

#include <libaudit.h>

int audit_log_acct_message(intaudit_fd,int"type,constchar*"pgname,constchar*"op,constchar*"name,unsignedint"id,constchar*"host,constchar*"addr,constchar*"tty,int"result);"

DESCRIPCIÓN

Esta función registrará un mensaje en el sistema de auditoría utilizando un formato de mensaje predefinido. Debe usarse para todas las operaciones de manipulación de cuentas. Los parámetros de la función son los siguientes:

audit_fd - El fd devuelto por audit_open
type - tipo de mensaje: AUDIT_USER_CHAUTHTOK para cambiar cualquier atributo de cuenta.
pgname - nombre del programa, si es NULL intentará averiguarlo
op - operación. Ej: "adding-user", "changing-finger-info", "deleting-group". Este valor debe tener un guion o guion bajo entre las palabras para que los analizadores de informes los agrupen.
name - nombre de la cuenta o grupo de usuario. Si no está disponible, use NULL.
id - uid o gid sobre el que se está realizando la operación. Si el usuario es desconocido, pase un -1 y complete el parámetro name. Esto solo se usa cuando user es NULL.
host - El nombre del host si se conoce. Si no está disponible, pase NULL.
addr - La dirección de red del usuario. Si no está disponible, pase NULL.
tty - El tty del usuario, si es NULL intentará averiguarlo
result - 1 es "éxito" y 0 es "fallo"

VALOR DE RETORNO

Devuelve el número de secuencia que es > 0 en caso de éxito o <= 0 en caso de error.

ERRORES

Esta función devuelve -1 en caso de fallo. Examine errno para obtener más información.

VER TAMBIÉN

audit_log_user_message(3), audit_log_user_comm_message(3), audit_log_user_avc_message(3), audit_log_semanage_message(3).
