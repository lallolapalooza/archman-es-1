AUDIT_FSTYPE_TO_NAME(3) API de auditoría de Linux AUDIT_FSTYPE_TO_NAME(3)

NOMBRE

audit_fstype_to_name - Convierte el valor numérico de fstype al nombre de fstype

SINOPSIS

#include <libaudit.h>
const char *audit_fstype_to_name(int fstype);

DESCRIPCIÓN

audit_fstype_to_name() convierte el valor numérico de fstype (0x64626720 o 0x74726163) al nombre de fstype ("debugfs" o "tracefs"). fstype es el valor numérico de fstype.

VALOR DE RETORNO

Devuelve NULL si ocurre un error; de lo contrario, el valor de retorno es el nombre de fstype.
