int callrpc(const char *host, u_long prognum, u_long versnum,
    u_long procnum, xdrproc_t xdr_arg, char *argsp,
    xdrproc_t xdr_res, char *resp);



  

  
A simple interface to make an RPC call. This routine uses UDP and AUTH_UNIX
      authentication. It is useful for simple applications, but it cannot be
      used for applications that require TCP or other authentication methods.
      The callrpc routine returns 0 on success, or a non-zero value if an error
      occurs. The value returned is one of the RPC error codes defined in
      <rpc/rpc.h>.
