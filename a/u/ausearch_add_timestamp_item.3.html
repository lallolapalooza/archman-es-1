ausearch_add_timestamp_item(3)

Paquete: audit

Licencias: GPL-2.0-or-later, LGPL-2.0-or-later

AUSEARCH_ADD_TIMESTAMP_ITEM(3) API de auditoría de Linux AUSEARCH_ADD_TIMESTAMP_ITEM(3)

NOMBRE

ausearch_add_timestamp_item - construir regla de búsqueda

SINOPSIS

#include <auparse.h>

int ausearch_add_timestamp_item(auparse_state_t *au,constchar*"op,time_t"sec,unsigned"milli,ausearch_rule_t"how);"

DESCRIPCIÓN

ausearch_add_timestamp_item añade una condición de tiempo de evento a la expresión de búsqueda de auditoría actual. Las condiciones de búsqueda se pueden utilizar luego para escanear registros, archivos o búferes en busca de algo de interés. El parámetro op especifica la comparación deseada. Los valores legales de op son <, <=, >=, > y =. El operando izquierdo del operador de comparación es la marca de tiempo del evento examinado, el operando derecho se especifica mediante los parámetros sec y milli.

El valor how determina cómo afectará esta condición de búsqueda a la expresión de búsqueda existente si ya está definida. Los valores posibles son:

AUSEARCH_RULE_CLEAR
Borra la expresión de búsqueda actual, si la hay, y utiliza solo esta condición de búsqueda.
AUSEARCH_RULE_OR
Si ya hay una expresión de búsqueda E configurada, reemplázala por (E || esta_condición_de_búsqueda).
AUSEARCH_RULE_AND
Si ya hay una expresión de búsqueda E configurada, reemplázala por (E && esta_condición_de_búsqueda).

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, 0 para éxito.

USO DE APLICACIONES

Utilice ausearch_add_item(3) y ausearch_add_interpreted_item(3) para añadir condiciones que comprueben campos de registro de auditoría. Utilice ausearch_add_expression(3) para añadir expresiones de búsqueda complejas mediante una única llamada a función.
