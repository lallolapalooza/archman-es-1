autoopts-config(1) Manual del programador autoopts-config(1)

NOMBRE

autoopts-config - script para obtener información sobre la versión instalada de autoopts

SINOPSIS

autoopts-config { <nombre-valor> [...] | todo }

DESCRIPCIÓN

autoopts-config es una herramienta que utiliza configure para determinar las opciones de compilación y enlazado que deben usarse para compilar y enlazar programas que utilizan autoopts. Los nombres-valor pueden ir precedidos por uno o más guiones. Se ignoran silenciosamente.

NOMBRES DE VALOR

autogen

Imprime el nombre de ruta completo del ejecutable autogen.
El valor sin configurar es: ${bindir}/autogen${exeext}

bindir

El directorio de destino para los scripts ejecutables y programas instalados por el paquete autogen.
El valor sin configurar es: @bindir@

cflags

Imprime las opciones del compilador que son necesarias para compilar un programa autoopts.
El valor sin configurar es: -I${includedir}

datadir

El directorio para varios directorios de datos.
El valor sin configurar es: @datadir@

datarootdir

El directorio raíz para varios directorios de datos. En este caso, solo hay uno, "datadir".
El valor sin configurar es: @datarootdir@

dotver

Imprime la versión actualmente instalada de autoopts, en formato de puntos.
El valor sin configurar es: @AO_CURRENT@.@AO_REVISION@.@AO_AGE@

everything

Imprime la lista de todos los nombres y valores, uno por línea.

exec_prefix

La raíz de instalación para bibliotecas y ejecutables.
El valor sin configurar es: @exec_prefix@

exeext

La extensión de archivo ejecutable utilizada para el ejecutable autogen.
El valor sin configurar es: @EXEEXT@

includedir

El directorio donde se almacenan las cabeceras de AutoOpts. Esto no incluye el prefijo "-I" que se obtiene especificando "cflags".
El valor sin configurar es: @includedir@

ldflags

Imprime las opciones del enlazador que son necesarias para enlazar un programa autoopts en el modo de instalación predeterminado (estático o dinámico).
El valor sin configurar es: -L${libdir} -lopts

ldopts

Las opciones del enlazador a utilizar al enlazar un programa a libopts.
El valor sin configurar es: @AG_LDFLAGS@

libdir

El directorio de instalación de libopts.
El valor sin configurar es: @libdir@

libs

una ortografía alternativa de "ldflags".
El valor sin configurar es: ${ldflags}

libsrc

El nombre de ruta completo de la biblioteca fuente redistribuible de libopts extraíble. Este archivo está en formato tarball comprimido con gzi


El valor sin configurar es: ${pkgdatadir}/libopts-${dotver}.tar.gz

package

El nombre del paquete que proporciona autoopts. Siempre es "autogen".
El valor sin configurar es: @PACKAGE@

pkgdatadir

El directorio que contiene los archivos de soporte utilizados por autogen.
El valor sin configurar es: ${datadir}/${package}

prefix

El prefijo de instalación del paquete autogen.
El valor sin configurar es: @prefix@

static_libs

El nombre del archivo AR del código objeto de libopts.
El valor sin configurar es: ${libdir}/libopts.a

version

Imprime la versión actualmente instalada de autoopts.
El valor sin configurar es: @AO_CURRENT@:@AO_REVISION@:@AO_AGE@
