NOMBRE

auto-multiple-choice-mailing - Enviar por correo electrónico los PDF de exámenes con calificaciones a los examinados

SINOPSIS

auto-multiple-choice mailing [--xmlargsargs.xml] --projectproject-dir --students-liststudents-list.csv [--list-encodingencoding] --email-columncol --sendersender-email --subjectsubject --textemail-body [--text-content-typecontent-type] [--debugfile.log] [transport arguments...]

DESCRIPCIÓN

auto-multiple-choice mailingEl comando envía por correo electrónico los PDF de exámenes con calificaciones a los examinados. Las direcciones de correo electrónico se extraen del archivo de lista de examinados.

--project project-dir

Especifica el directorio del proyecto.

--students-list students-list.csv

Establece el nombre del archivo de lista de examinados.

--list-encoding encoding

Selecciona la codificación destudents-list.csv (por defecto es utf-8).

--email-column col

Establece el nombre de la columna que corresponde al correo electrónico del examinado en el archivo de lista de examinados.

--sender sender-email

Establece la dirección del remitente.

--cc cc-email-address

Establece la dirección Cc.

--bcc bcc-email-address

Establece la dirección Bcc.

--subject subject

Establece el asunto del correo electrónico a enviar.

--text email-body

Establece el cuerpo del correo electrónico a enviar.

--text-content-type content-type

Establece el content-type del cuerpo del correo electrónico.content-typepuede sertext/plainotext/html.

--attach filename

Adjunta el archivofilenamea cada correo electrónico enviado. Use esta opción varias veces para adjuntar varios archivos.

--transport transport

Establece el método de transporte. Los valores válidos paratransportsonsendmailoSMTP.

--debug file.log

Especifica el archivo en el que registrar la información de depuración.

--delay time

Establece un retraso detimesegundos entre cada envío.

ARGUMENTOS POR MÉTODO DE TRANSPORTE

Según el valor del argumentotransport , se añaden los siguientes argumentos:

Transporte sendmail

--sendmail-path path

Establece la ruta al comandosendmail (por defecto es /usr/sbin/sendmail).

Transporte SMTP

--smtp-host host

Establece el nombre del host SMTP (por defecto essmtp).

--smtp-port port

Establece el puerto a usar (por defecto es 25).

--smtp-ssl mode

Establece el modo de seguridad de la conexión SMTP.La opciónmode puede ser ssl, starttls o 0 (sin cifrado).

--smtp-user user

Establece el nombre de usuario para la autenticación SMTP.

--smtp-passwd-file file

Especifica la ruta a un archivo que contiene (en la primera línea) la contraseña para la autenticación SMTP.

ARGUMENTOS DESDE UN ARCHIVO XML

Para evitar problemas de codificación, puede poner los argumentos en un archivo XML y hacer que--xmlargs file.xmlsea el primer argumento del comando. He aquí un ejemplo de tal archivo:

<?xml version="1.0" encoding="UTF-8"?>
<arguments>
  <arg>--sender</arg><arg>Bienvenue &paamc@passoire.fr&</arg>
  <arg>--text</arg><arg>Voilà votre copie corrigée</arg>
  <arg>--subject</arg><arg>QCM</arg>
</arguments>
