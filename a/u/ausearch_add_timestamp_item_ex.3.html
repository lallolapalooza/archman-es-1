ausearch_add_timestamp_item_ex(3)

Paquete: audit

Licencias: GPL-2.0-or-later, LGPL-2.0-or-later

AUSEARCH_ADD_TIMESTAMP_ITEM_EX(3) API de auditoría de Linux AUSEARCH_ADD_TIMESTAMP_ITEM_EX(3)

NOMBRE

ausearch_add_timestamp_item_ex - construir una regla de búsqueda

SINOPSIS

#include <auparse.h>

int ausearch_add_timestamp_item_ex(auparse_state_t *au,constchar*"op,time_t"sec,unsigned"milli,unsigned"serial,ausearch_rule_t"how);"

DESCRIPCIÓN

ausearch_add_timestamp_item_ex agrega una condición de tiempo de evento a la expresión de búsqueda de auditoría actual. Las condiciones de búsqueda se pueden usar luego para escanear registros, archivos o búferes en busca de algo de interés. El parámetro op especifica la comparación deseada. Los valores legales de op son <, <=, >=, > e =. El operando izquierdo del operador de comparación es la marca de tiempo del evento examinado, el operando derecho se especifica mediante los parámetros sec, milli y serial.

El valor how determina cómo afectará esta condición de búsqueda a la expresión de búsqueda existente si ya hay una definida. Los valores posibles son:

AUSEARCH_RULE_CLEAR
Borra la expresión de búsqueda actual, si la hay, y utiliza solo esta condición de búsqueda.
AUSEARCH_RULE_OR
Si ya hay configurada una expresión de búsqueda E, la reemplaza por (E || esta_condición_de_búsqueda).
AUSEARCH_RULE_AND
Si ya hay configurada una expresión de búsqueda E, la reemplaza por (E && esta_condición_de_búsqueda).

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, 0 para éxito.

USO DE APLICACIONES

Use ausearch_add_item(3) y ausearch_add_interpreted_item(3) para agregar condiciones que verifican campos de registros de auditoría. Use ausearch_add_expression(3) para agregar expresiones de búsqueda complejas usando una sola llamada a función.

VER TAMBIÉN
