NOMBRE

auto-multiple-choice-annotate - Introduce los resultados de corrección en las respuestas del examen de opción múltiple de AMC

RESUMEN

auto-multiple-choice annotate --project dir-proyecto --names-file estudiantes.csv [opciones de anotación...]

DESCRIPCIÓN

El comando auto-multiple-choice annotate introduce en la respuesta las puntuaciones de cada pregunta y las puntuaciones totales, y genera archivos PDF (múltiples archivos por estudiante o un único archivo para todos los estudiantes).

Opciones generales

--project dir-proyecto

Especifica el nombre o directorio del proyecto.

--data dir-datos-proyecto

Especifica el directorio que contiene los archivos de datos (el valor predeterminado es dir-proyecto/data).

--pdf-dir dir-pdf

Especifica el directorio de pdf del proyecto (el valor predeterminado es dir-proyecto/cr/corrections/pdf).

--names-file lista-estudiantes.csv

Especifica el nombre del archivo de la lista de estudiantes.

--names-encoding codificación

Elige la codificación del archivo lista-estudiantes.csv (el valor predeterminado es utf-8).

--association-key clave

Especifica la columna que se utilizará para distinguir a los estudiantes (nombre de columna en el archivo de la lista de estudiantes). Este valor se almacena en la base de datos en tiempo de corrección, lo que lo convierte en el valor predeterminado, por lo que esta opción no es necesaria.

--subject sujeto.pdf

Especifica la ruta al archivo del examen (el valor predeterminado es dir-proyecto/DOC-sujet.pdf).

--compose modo

Esta opción se utiliza cuando las páginas sin recuadros de marcado (por ejemplo, páginas anteriores a la hoja de respuestas para las preguntas) deben incluirse en la hoja de respuestas. Si modo es 1, se extraen páginas de la hoja de respuestas, se marcan de la misma manera que la respuesta del estudiante y se escribe el mismo número de corrección en la hoja de respuestas. Si modo es 2, se extraen páginas de la hoja de respuestas corregidas (ya que se duplicarán), y no se escribe el número de corrección.

--corrected corregido.pdf

Especifica la ruta al PDF de corrección (el valor predeterminado es dir-proyecto/DOC-corrected.pdf; si el archivo no existe, se creará utilizando los valores de las opciones --n-copies, --with, --filter, --filtered-source).

--darkness-threshold t

Especifica el valor umbral de la proporción de píxeles oscuros. Este valor se almacena en la base de datos en tiempo de corrección, lo que lo convierte en el valor predeterminado, por lo que esta opción no es necesaria.

--darkness-threshold-up umbral_superior_t

Especifica el valor umbral superior de la proporción de píxeles oscuros. Este valor se almacena en la base de datos en tiempo de corrección, lo que lo convierte en el valor predeterminado, por lo que esta opción no es necesaria.

--csv-build-name modelo-nombre

Especifica el modelo para construir los nombres de los estudiantes a partir del archivo de la lista de estudiantes. El valor predeterminado es "(nom|surname) (prenom|name)", en cuyo caso, el apellido será el contenido de la columna nom (o surname si no existe la columna nom), seguido del contenido de la columna prenom (o name si no existe la columna name), lo que resulta en una simple hoja de datos CSV en francés o inglés.

--id-file ids.txt

Especifica el archivo de lista de ID para las hojas de respuesta donde se escribirán las correcciones (en modo de hoja de respuesta individual, el número de estudiante; en modo de hoja de respuesta copiada, estudiante:copia, una por línea). Si no se especifica el archivo, las correcciones se escribirán en todas las hojas de respuesta.

--debug archivo.log

Especifica el archivo donde se registrará la información de depuración.

Opciones de salida PDF

--output-dir output-dir

Especifica el directorio donde se guardarán los archivos PDF de salida (el valor predeterminado es dir-proyecto/cr/corrections/pdf).

--copies num

Especifica el número de copias a generar para cada hoja de respuestas.

--with formato

Especifica el formato de salida. Los valores posibles son: pages (una página por estudiante) y sheets (una hoja por estudiante). El valor predeterminado es sheets.

--filter filtro

Especifica el filtro a aplicar. Si se especifica, el PDF generado contendrá solo los estudiantes que coincidan con el filtro. El filtro es una expresión booleana que puede contener los nombres de las columnas de la lista de estudiantes. Por ejemplo: "section='A' and options='S'".

--filtered-source fuente-filtrada.pdf

Especifica el archivo PDF que se utilizará como fuente para la generación de archivos PDF filtrados. Si no se especifica, se utilizará el PDF de corrección generado anteriormente.

--silent

Suprime todos los mensajes de salida, excepto los errores.
