AUDIT_REQUEST_STATUS(3) API de auditoría de Linux AUDIT_REQUEST_STATUS(3)

NOMBRE

audit_request_status - Solicita el estado del sistema de auditoría

SINOPSIS

#include <libaudit.h>
int audit_request_status(int fd);"

DESCRIPCIÓN

audit_request_status solicita que el kernel envíe una estructura de estado que describe varios ajustes en el descriptor dado en fd. La estructura audit_status es la siguiente:

struct audit_status {
   __u32   mask;           /* Máscara de bits para entradas válidas */
   __u32   enabled;        /* 1 = habilitado, 0 = deshabilitado */
   __u32   failure;        /* Acción de fallo al registrar */
   __u32   pid;            /* pid del proceso auditd */
   __u32   rate_limit;     /* límite de tasa de mensajes (por segundo) */
   __u32   backlog_limit;  /* límite de mensajes en espera */
   __u32   lost;           /* mensajes perdidos */
   __u32   backlog;        /* mensajes esperando en cola */
};

VALOR DE RETORNO

El valor de retorno es <= 0 en caso de error, de lo contrario es el número de secuencia de netlink. Esta función puede tener cualquier error que sendto pudiera encontrar.

VER TAMBIÉN

audit_open(3), audit_get_reply(3), auditd(8).
