AUDIT_OPEN(3) API de Auditoría de Linux AUDIT_OPEN(3)

NOMBRE

audit_open - Abrir una conexión de socket netlink de auditoría

SINOPSIS

#include <libaudit.h>
int audit_open(void);

DESCRIPCIÓN

audit_open crea un socket NETLINK_AUDIT para la comunicación con la parte del kernel del Subconjunto de Auditoría de Linux. El subsistema de auditoría utiliza la característica ACK de netlink. Esto significa que cada mensaje al kernel devolverá un paquete de estado de netlink incluso si la operación tiene éxito.

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, el valor de retorno es un descriptor que hace referencia al socket.

ERRORES

La función audit_open() puede fallar y establecer errno para cualquiera de los errores especificados para las rutinas socket(2) y fcntl(2).

VER TAMBIÉN

netlink(7).
