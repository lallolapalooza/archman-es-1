AUPARSE_FIND_FIELD(3) API de auditoría de Linux AUPARSE_FIND_FIELD(3)

NOMBRE

auparse_find_field - buscar nombre de campo

SINOPSIS

#include <auparse.h>

const char * auparse_find_field(auparse_state_t *au,constchar*"name);"

DESCRIPCIÓN

auparse_find_field escaneará todos los registros de un evento para encontrar la primera ocurrencia del nombre de campo que se le pase. La búsqueda comienza desde la posición actual del cursor. El nombre del campo se almacena para búsquedas posteriores.

NOTA: auparse crea 2 campos pseudo que no existen en el registro natural para las decisiones y permisos de SELinux AVC y USER_AVC. Los nombres de los campos son `seresult` y `seperms` respectivamente.

VALOR DE RETORNO

Devuelve `NULL` si el campo no se encuentra. Si ocurre un error, `errno` se establecerá. De lo contrario, devuelve un puntero al valor de texto asociado con el campo.

VER TAMBIÉN

auparse_first_record(3), auparse_find_field_next(3).
