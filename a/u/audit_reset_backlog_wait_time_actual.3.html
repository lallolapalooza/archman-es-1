AUDIT_RESET_BACKLOG_WAIT_TIME_ACTUAL(3) API de auditoría de Linux AUDIT_RESET_BACKLOG_WAIT_TIME_ACTUAL(3)

NOMBRE

audit_reset_backlog_wait_time_actual - restablecer el contador real del tiempo de espera del backlog

SINOPSIS

#include <libaudit.h>

int audit_reset_backlog_wait_time_actual(int fd);

DESCRIPCIÓN

audit_reset_backlog_wait_time_actual() restablece el total acumulado del kernel sobre cuánto tiempo han esperado las llamadas al sistema para disponer de espacio en la cola de eventos de auditoría. El fd debe ser un socket netlink de auditoría abierto. Esta llamada es útil cuando los administradores habilitan la espera del backlog a través de la opción audit_set_backlog_wait_time(3) para preservar eventos en situaciones de memoria escasa. Borrar periódicamente el contador permite detectar la reanudación de la espera del backlog después de cambiar el tamaño de la cola o el tiempo de espera. El kernel debe admitir el campo AUDIT_STATUS_BACKLOG_WAIT_TIME_ACTUAL para que esta llamada tenga éxito.

VALOR DE RETORNO

El valor de retorno es <= 0 en caso de error, de lo contrario, es el número de secuencia de netlink.

VER TAMBIÉN

audit_set_backlog_wait_time(3), audit_open(3), auditctl(8).
