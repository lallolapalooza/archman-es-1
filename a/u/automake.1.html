NOMBRE

automake - Genera archivos Makefile.in para configure a partir de Makefile.am

SINOPSIS

automake [OPCIÓN]... [Makefile]...

DESCRIPCIÓN

Genera Makefile.in para configure a partir de Makefile.am.

Modos de operación:

--help
imprime esta ayuda y termina
--version
imprime el número de versión y termina
-v, --verbose
lista detalladamente los archivos procesados
--no-force
solo actualiza los Makefile.in desactualizados
-W, --warnings=CATEGORÍA
informa las advertencias que pertenecen a CATEGORÍA

Seguimiento de dependencias:

-i, --ignore-deps
desactiva el código de seguimiento de dependencias
--include-deps
activa el código de seguimiento de dependencias

Variantes:

--foreign
establece la estrictitud a foreign
--gnits
establece la estrictitud a gnits
--gnu
establece la estrictitud a gnu

Archivos de biblioteca:

-a, --add-missing
añade los archivos estándar faltantes al paquete
--libdir=DIR
establece el directorio que almacena los archivos de la biblioteca
--print-libdir
imprime el directorio que almacena los archivos de la biblioteca
-c, --copy
con -a, copia los archivos faltantes (por defecto, crea un enlace simbólico)
-f, --force-missing
fuerza la actualización de los archivos estándar

Las categorías de advertencia son:

cross
problemas de compilación cruzada
gnu
estándares de codificación GNU (por defecto en los modos gnu y gnits)
obsolete
características o construcciones obsoletas (por defecto)
override
redefiniciones por parte del usuario de reglas o variables de Automake
portability
problemas de portabilidad (por defecto en los modos gnu y gnits)
portability-recursive
variables Make anidadas (por defecto con -Wportability)
extra-portability
problemas de portabilidad adicionales relacionados con herramientas poco comunes
syntax
construcciones sintácticas dudosas (por defecto)
unsupported
características no soportadas o incompletas (por defecto)

-W también reconoce:

all
activa todas las advertencias
none
desactiva todas las advertencias
no-CATEGORÍA
desactiva las advertencias en CATEGORÍA
error
trata todas las advertencias activadas como errores
