AUDIT_NAME_TO_ERRNO(3) API de auditoría de Linux AUDIT_NAME_TO_ERRNO(3)

NOMBRE

audit_name_to_errno, audit_errno_to_name - Convertir el nombre errno y el valor numérico de errno entre sí

SINOPSIS

#include <libaudit.h>
int audit_name_to_errno(const char *error);
const char *audit_errno_to_name(int error);

DESCRIPCIÓN

audit_name_to_errno() convierte el nombre de errno ("EPERM", "ENOENT", "ESRCH", etc.) al valor numérico de errno (EPERM, ENOENT, ESRCH, etc.). error es el nombre del errno.

audit_errno_to_name() convierte el valor numérico de errno (EPERM, ENOENT, ESRCH, etc.) al nombre de errno ("EPERM", "ENOENT", "ESRCH", etc.). error es el valor numérico del errno.

VALOR DE RETORNO

audit_name_to_errno() devuelve 0 si ocurre un error; de lo contrario, el valor de retorno es el valor numérico del errno.

audit_errno_to_name() devuelve NULL si ocurre un error; de lo contrario, el valor de retorno es el nombre del errno.
