NOMBRE

autodie::Scope::Guard - Clase envoltorio para llamar a subs al final del ámbito

SINOPSIS

use autodie::Scope::Guard;
$^H{'my-key'} = autodie::Scope::Guard->new(sub {
    print "Hola mundo\n";
});

DESCRIPCIÓN

Esta clase se utiliza para bendecir subs de perl para que se invoquen cuando se destruyen. Esto es útil principalmente para asegurar que el código se invoque al final del ámbito. Este módulo no forma parte de la API pública de autodie.

Este módulo está directamente inspirado en el excelente módulo Scope::Guard de chocolateboy.

Métodos

new

my $hook = autodie::Scope::Guard->new(sub {});

Crea un nuevo "autodie::Scope::Guard", que invocará la subrutina dada una vez que salga del ámbito (es decir, se llame a su manejador DESTROY).
