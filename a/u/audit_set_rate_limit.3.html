AUDIT_SET_RATE_LIMIT(3) API de auditoría de Linux AUDIT_SET_RATE_LIMIT(3)

NOMBRE

audit_set_rate_limit - Establecer el límite de velocidad de auditoría

SINOPSIS

#include <libaudit.h>
int audit_set_rate_limit(int fd, uint32_t limit);"

DESCRIPCIÓN

audit_set_rate_limit establecerá el número máximo de mensajes que el kernel enviará por segundo. Esto se puede usar para limitar la velocidad si los sistemas se vuelven no responsivos. Por supuesto, la contrapartida es que los eventos serán descartados. El argumento limit controla cuántos mensajes se pueden enviar cada segundo. El valor predeterminado es 0, lo que significa que no hay límite.

VALOR DE RETORNO

El valor de retorno es <= 0 en caso de error, de lo contrario es el número de secuencia netlink. Esta función puede tener cualquier error que sendto pudiera encontrar.

VER TAMBIÉN

audit_open(3), auditd(8).
