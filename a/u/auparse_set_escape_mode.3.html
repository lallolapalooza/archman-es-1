auparse_set_escape_mode(3)

AUPARSE_SET_ESCAPE_MODE(3) API de auditoría de Linux AUPARSE_SET_ESCAPE_MODE(3)

NOMBRE

auparse_set_escape_mode - elige el método de escape

SINOPSIS

#include <auparse.h>

void auparse_set_escape_mode(auparse_state_t *au,auparse_esc_t"modo);"

DESCRIPCIÓN

auparse_set_escape_mode se usa para establecer el método de escape que se utilizará para generar texto interpretado. Las opciones para la variable modo son:

AUPARSE_ESC_RAW
No se realiza ningún tipo de escape.
AUPARSE_ESC_TTY
Escapa los caracteres de control TTY para que sean inofensivos al mostrarlos en una terminal. Cuando se encuentra algún carácter de control, se muestran como números octales. Este es el modo predeterminado con el que se inicializa la biblioteca auparse.
AUPARSE_ESC_SHELL
Además de escapar los caracteres de control, escapará algunos caracteres que pueden causar problemas cuando se usan con scripts de shell. Cualquier carácter de control escapado se muestra como números octales. Otros caracteres escapados van precedidos de una barra invertida. Los caracteres adicionales que escapa son: " ' ` $ \
AUPARSE_ESC_SHELL_QUOTE
Similar a AUPARSE_ESC_SHELL pero expande el conjunto de caracteres para incluir operadores de shell. Cualquier carácter de control escapado se muestra como números octales. Otros caracteres escapados van precedidos de una barra invertida. Los caracteres adicionales que escapa incluyen: ; '  " ` # $ & * ? [ ] < > { } \

VALOR DE RETORNO

Ninguno
