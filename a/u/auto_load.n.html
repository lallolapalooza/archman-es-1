La ubicación de la biblioteca de Tcl es devuelta por el comando info library. Además de la biblioteca de Tcl, cada aplicación normalmente tendrá su propia biblioteca de procedimientos de soporte; la ubicación de esta biblioteca normalmente se da mediante el valor de la $ app _library variable global, donde app es el nombre de laaplicación. Determina

Si es así, devuelve una lista de argumentos que se pasarán a exec para ejecutar el archivo ejecutable o el comando interno de shell nombrado por cmd. Si no, devuelve una cadena vacía. Este comando examina los directorios en la ruta de búsqueda actual (dada por la variable de entorno PATH) en su búsqueda de un archivo ejecutable llamado cmd. En las plataformas Windows, la búsqueda se amplía con los mismos directorios y extensiones de archivo que usa exec. Auto_execok recuerda información sobre búsquedas anteriores en un array llamado auto_execs; esto evita la búsqueda de ruta en llamadas futuras para el mismo cmd. El comando auto_reset puede usarse para forzar a auto_execok a olvidar su información en caché. auto_import
pattern
Auto_import se invoca
durante
namespace import para ver si los comandos importados especificados por pattern residen en una biblioteca de auto-carga. Si es así, los comandos se cargan para que estén disponibles para el intérprete al crear los enlaces de importación. Si los comandos no residen en una biblioteca de auto-carga, auto_import no hace nada. El emparejamiento de patrones se realiza de acuerdo con las reglas de emparejamiento de namespace import.
auto_load
cmd Este coma
ndo
intenta cargar la definición de un comando Tcl llamado cmd. Para hacer esto, busca en una ruta de auto-carga, que es una lista de uno o más directorios. La ruta de auto-carga está dada por la variable global auto_path si existe. Si no existe la variable auto_path, entonces se usa la variable de entorno TCLLIBPATH, si existe. De lo contrario, la ruta de auto-carga consiste solo en el directorio de la biblioteca de Tcl. Dentro de cada directorio en la ruta de auto-carga debe haber un archivo tclIndex que describe uno o más comandos definidos en ese directorio y un script para evaluar para cargar cada uno de los comandos. El archivo tclIndex debería generarse con el comando auto_mkindex. Si cmd se encuentra en un archivo de índice, entonces se evalúa el script apropiado para crear el comando. El comando auto_load devuelve 1 si cmd se creó correctamente. El comando devuelve 0 si no había una entrada de índice para cmd o si el script no definió realmente cmd (por ejemplo, porque la información del índice está desactualizada). Si ocurre un error mientras se procesa el script, entonces se devuelve ese error. Auto_load solo lee la información del índice una vez y la guarda en el array auto_index; las llamadas futuras a auto_load buscan cmd en el array en lugar de volver a leer los archivos de índice. La información del índice en caché puede eliminarse con el comando auto_reset. Esto forzará al siguiente comando auto_load a recargar la base de datos de índice desde el disco.
