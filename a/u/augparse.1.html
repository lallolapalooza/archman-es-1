NOMBRE

augparse - ejecutar un módulo de Augeas

SINOPSIS

augparse [OPCIONES] MÓDULO

DESCRIPCIÓN

Ejecuta un módulo de Augeas, más comúnmente para evaluar las pruebas que contiene.

OPCIONES

-I, --include=DIR
Añade DIR a la ruta de carga del módulo. Se puede dar varias veces. Los directorios especificados aquí se buscan antes que cualquier directorio especificado en la variable de entorno AUGEAS_LENS_LIB, y antes que el directorio por defecto /usr/share/augeas/lenses.
-t, --trace
Imprime un rastreo de los módulos que se están cargando.
--nostdinc
No buscar en ninguno de los directorios por defecto para módulos. Cuando esta opción está configurada, solo se buscarán en los directorios especificados explícitamente con -I o en AUGEAS_LENS_LIB los módulos.
--notypecheck
No realizar comprobaciones de tipo de lente. Solo use esta opción durante el desarrollo de lentes y asegúrese de que las lentes se comprueban al terminar el desarrollo; nunca debe usar una lente que no se haya comprobado. Esta opción es a veces útil cuando se trabaja en pruebas unitarias para una lente, para acelerar el tiempo que lleva ejecutar y corregir pruebas repetidamente.
--version
Imprime información de la versión y sale.
-h
Muestra esta ayuda y sale

EJEMPLOS

Para ejecutar las pruebas en lenses/tests/test_foo.aug y usar módulos del directorio lenses, ejecute

augparse -I lenses lenses/tests/test_foo.aug

PRUEBAS

Las pruebas pueden aparecer como formas de nivel superior en cualquier lugar de un módulo. Generalmente, las pruebas para un módulo lenses/foo.aug se guardan en un archivo separado, normalmente en lenses/tests/test_foo.aug.

Hay dos tipos diferentes de pruebas que Augeas puede ejecutar: pruebas get y put. La sintaxis para las pruebas get es

test LENS get STRING = RESULTADO

que aplica la dirección get de la lente LENS a STRING y la compara con el RESULTADO dado. RESULTADO puede ser un literal de árbol, el símbolo ? para imprimir el resultado de aplicar LENS a STRING, o el símbolo * para indicar que la prueba debe producir una excepción.

La sintaxis para las pruebas put es

test LENS put STRING después DE COMANDOS = RESULTADO

que primero aplica la dirección get de la lente LENS a STRING, luego aplica los COMANDOS dados al árbol resultante, y finalmente transforma el árbol modificado de nuevo a una cadena usando la dirección put de LENS. La cadena resultante se compara con RESULTADO, que puede ser una cadena, el símbolo ? para imprimir el resultado de aplicar LENS a STRING, o el símbolo * para indicar que la prueba debe producir una excepción.
