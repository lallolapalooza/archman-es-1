NOMBRE

auto-multiple-choice-annotate - Anota las hojas de respuestas completadas después de calificar los exámenes de opción múltiple de AMC.

SINOPSIS

auto-multiple-choice annotate --project directorio-proyecto --names-file estudiantes.csv [opciones-de-anotacion...]

DESCRIPCIÓN

El comando auto-multiple-choice annotate anota los escaneos de las preguntas con las puntuaciones de todas las preguntas, la puntuación global y la calificación, lo que resulta en archivos PDF (uno para cada estudiante, o un único archivo).

Opciones generales

--project directorio-proyecto

establece el nombre o directorio del proyecto.

--data directorio-datos-proyecto

indica el directorio donde se encuentran los archivos de datos (el valor predeterminado es directorio-proyecto/data).

--pdf-dir directorio-pdf

establece el directorio de PDF del proyecto, donde se generarán los escaneos anotados (el valor predeterminado es directorio-proyecto/cr/corrections/pdf).

--names-file lista-estudiantes.csv

establece el nombre del archivo de la lista de estudiantes.

--names-encoding codificacion

selecciona una codificación para el archivo lista-estudiantes.csv (el valor predeterminado es utf-8).

--association-key clave

establece la clave (nombre de columna en el archivo de la lista de estudiantes) que se utiliza para la asociación. El valor predeterminado se almacena en la base de datos del valor utilizado actualmente para la asociación, por lo que esta opción no debería usarse.

--subject pregunta-tema.pdf

establece la ruta al archivo de preguntas en PDF (el valor predeterminado es directorio-proyecto/DOC-sujet.pdf).

--compose modo

use esta opción si desea tomar páginas del tema cuando no hay casillas para rellenar en ellas (por ejemplo, páginas de preguntas antes de la hoja de respuestas anotada). Cuando modo es igual a 1, las páginas se toman del tema, se rellenan o no según las respuestas del estudiante (lo mismo que en la hoja de respuestas), y se dibujan las mismas marcas de corrección que en la hoja de respuestas. Cuando el modo es 2, las páginas se toman de la hoja de respuestas corregida (por lo que las respuestas marcadas son las correctas), y no se dibujan marcas de corrección.

--corrected corregido.pdf

establece la ruta al tema corregido en PDF (el valor predeterminado es directorio-proyecto/DOC-corrected.pdf). Si no está presente, este archivo se creará utilizando los valores de las opciones --n-copies, --with, --filter y --filtered-source).

--darkness-threshold t

establece el umbral de oscuridad. El valor predeterminado se almacena en la base de datos del valor utilizado actualmente para la puntuación, por lo que esta opción no debería usarse.

--darkness-threshold-up upper_t

establece el umbral de oscuridad superior. El valor predeterminado se almacena en la base de datos del valor utilizado actualmente para la puntuación, por lo que esta opción no debería usarse.

--csv-build-name modelo-nombre

establece el modelo para construir los nombres de los estudiantes a partir del archivo de lista de estudiantes. El valor predeterminado es '(nom|surname) (prenom|name)', de modo que el nombre se construye utilizando el contenido de la columna 'nom' (o la columna 'surname' si la columna 'nom' no existe), seguido del contenido de la columna 'prenom' (o la columna 'name'), por lo que el resultado debería ser correcto para archivos CSV simples en francés o inglés.

--id-file ids.txt

indica un nombre de archivo donde encontrar los IDs de las copias a anotar (una por línea, ya sea el número de estudiante si el modo fotocopia está desactivado, o estudiante:copia si el modo fotocopia está activado). Si no se proporciona ningún archivo, se anotarán todas las copias.

--debug archivo.log

proporciona un archivo para rellenar con información de depuración.

Opciones de salida PDF

--single-output

use esta opción si necesita todas las copias anotadas en un único archivo PDF. El comportamiento predeterminado es crear un archivo PDF por estudiante.

--sort s

establece la clave de ordenación (solo útil cuando se usa --single-output): use

l

para mantener a los estudiantes en el mismo orden que en el archivo de lista de estudiantes.

m

para ordenar a los estudiantes según sus calificaciones.

i

para ordenar a los estudiantes según su ID de copia.

n

para ordenar a los estudiantes según sus nombres.

--filename-model modelo

establece un modelo de nombre de archivo para los PDF anotados. En este modelo, se sustituirán algunas secuencias:

(ID)

se reemplaza por el nombre del estudiante (ver --csv-build-name).

(N)

se reemplaza por el número de estudiante.

(COL)

se reemplaza por el valor de la columna COL en la lista de estudiantes para el estudiante actual.

El valor predeterminado es '(N)-(ID).pdf'.

Opciones de archivo fuente

Estas opciones se utilizan cuando la ruta --corrected apunta a un archivo inexistente, para que este archivo pueda reconstruirse.

--src archivo-fuente-mcq --n-copies n --with motor-latex --filter nombre-filtro --filtered-source fs.tex

ver auto-multiple-choice-prepare(1).

Opciones para escaneos incrustados

Cuando están presentes, los escaneos se incrustan en el archivo PDF anotado. Las siguientes opciones controlan la calidad de los escaneos incrustados, para reducir el tamaño del archivo anotado.

--embedded-max-size tamañomax

establece el tamaño máximo para los escaneos (en formato anchoxalto, en píxeles). El valor predeterminado es una cadena vacía, lo que significa que no hay un tamaño máximo. Los escaneos más grandes se reducirán antes de incluirlos en el archivo anotado.

--embedded-format formato

establece el formato para la inclusión de escaneos: jpeg o png.

--embedded-jpeg-quality calidad

establece la calidad JPEG (de 1 a 100) para escaneos JPEG incrustados.

Opciones de anotación

Estas opciones controlan qué tipo de anotaciones se van a dibujar.

--font-size ta

establece el tamaño de fuente, en puntos, para las anotaciones.

--text-color color

color del texto para las anotaciones. El valor predeterminado es rojo.

--verdict encabezado

establece el encabezado de texto que se imprimirá en cada primera página de las copias de los estudiantes. Este texto puede contener caracteres CR para encabezados de varias líneas. Algunas secuencias se sustituyen en él:

%S

se reemplaza por la puntuación total del estudiante.

%M

se reemplaza por la puntuación máxima total.

%s

se reemplaza por la calificación del estudiante.

%m

se reemplaza por la calificación máxima.

%(ID)

se reemplaza por el nombre del estudiante.

%(COL)

se reemplaza por el valor de la columna COL en la lista de estudiantes para el estudiante actual.

--position pos

establece la posición donde se escribirán las puntuaciones de las preguntas:

marge

las puntuaciones se escribirán en el margen izquierdo

marges

las puntuaciones se escribirán en el margen más cercano (izquierdo o derecho).

case

las puntuaciones se escribirán cerca de las casillas

none

las puntuaciones no se escribirán.

--verdict-question expresion-perl

indent">establece el texto que se imprimirá junto a todas las preguntas, mediante una expresión perl a evaluar (si necesita un texto simple, simplemente entrecomíllelo con "). Algunas secuencias se sustituyen en ella antes de la evaluación:

%S

se sustituye por la puntuación del estudiante para esta pregunta.

%M

se sustituye por la puntuación máxima para esta pregunta.

%s

es lo mismo que %S, pero redondeado a nc dígitos significativos (vea la opción --ch-sign).

%m

es lo mismo que %M, pero redondeado a nc dígitos significativos (vea la opción --ch-sign).

Un valor estándar para esta opción es "\"%s/%m\"". También puede usar pruebas (con la sintaxis perl ( TEST ? SI-VERDADERO : SI-FALSO )) para escribir Válido si la puntuación es la puntuación máxima, o Fallido si no lo es, usando

--verdict-question "(%S==%M ? \"Valid\" : \"Failed\")"

--verdict-question-cancelled expresión-perl

igual que --verdict-question, pero se aplica a preguntas canceladas (vea la estrategia de puntuación allowempty). El valor por defecto es "X".

--indicatives

use esta opción para solicitar la anotación de las casillas de preguntas indicativas (las puntuaciones de estas preguntas no se tendrán en cuenta al calcular la puntuación global. El estado de correcto/incorrecto a menudo es irrelevante para estas preguntas, por lo que no tiene sentido corregir las casillas correspondientes).

--line-width ancho

establece el ancho de línea (en puntos) al dibujar símbolos para corregir respuestas.

--symbols definición-de-símbolos

define cómo se anotarán las casillas. definición-de-símbolos es una lista separada por comas de construcciones H-A:forma:color , donde H es 0 o 1 dependiendo de si la casilla debe marcarse o no, A es 0 o 1 dependiendo de si la casilla está realmente marcada o no, forma es una de none, circle, mark, box y color es un color (nombre o #RGB, vea la documentación de ImageMagick o GraphicsMagick para más detalles).

El valor por defecto es "0-0:none,0-1:circle:red,1-0:mark:red,1-1:mark:blue".

Longitudes

La siguiente longitud se puede dar con una unidad (in, ft, pt, cm o mm).

--dist-to-box d

establece la distancia desde las casillas (hacia la izquierda) donde escribir las puntuaciones de las preguntas al usar --position case.Por defecto es 1cm.

--dist-margin d

establece el tamaño del margen. Por defecto es 5mm.

--dist-margin-global d

establece el tamaño del margen para la cabecera. Por defecto es 3mm.
