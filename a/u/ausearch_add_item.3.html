Paquete: audit

AUSEARCH_ADD_ITEM(3) API de auditoría de Linux AUSEARCH_ADD_ITEM(3)

NOMBRE

ausearch_add_item - construir regla de búsqueda

SINOPSIS

#include <auparse.h>
int ausearch_add_item(auparse_state_t *au, const char *field, const char *op, const char *value, ausearch_rule_t how);

DESCRIPCIÓN

ausearch_add_item agrega una condición de búsqueda a la expresión de búsqueda de auditoría actual. Las condiciones de búsqueda se pueden usar luego para escanear registros, archivos o búferes en busca de algo de interés. El valor de field es el nombre del campo que se verificará con value. La variable op describe qué tipo de verificación se realizará. Los valores legales de op son:

existe

simplemente comprueba que existe un nombre de campo
=

localiza el nombre del campo y comprueba que el valor asociado a él es igual al valor dado en esta regla.
!=

localiza el nombre del campo y comprueba que el valor asociado a él NO es igual al valor dado en esta regla.

El parámetro value se compara con el valor del campo no interpretado. Si está intentando coincidir con un campo cuyo tipo es AUPARSE_TYPE_ESCAPED, querrá usar la función ausearch_add_interpreted_item() en su lugar.

El valor how determina cómo afectará esta condición de búsqueda a la expresión de búsqueda existente si ya hay una definida. Los valores posibles son:

AUSEARCH_RULE_CLEAR
Borra la expresión de búsqueda actual, si la hay, y usa solo esta condición de búsqueda.
AUSEARCH_RULE_OR
Si ya hay una expresión de búsqueda E configurada, reemplácela por (E || esta_condición_de_búsqueda).
AUSEARCH_RULE_AND
Si ya hay una expresión de búsqueda E configurada, reemplácela por (E && esta_condición_de_búsqueda).

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, 0 para éxito.

VER TAMBIÉN
