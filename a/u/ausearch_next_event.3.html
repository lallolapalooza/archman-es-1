AUSEARCH_NEXT_EVENT(3) API de auditoría de Linux AUSEARCH_NEXT_EVENT(3)

NOMBRE

ausearch_next_event - buscar el siguiente evento que cumpla los criterios de búsqueda

SINOPSIS

#include <auparse.h>

int ausearch_next_event(auparse_state_t *au);"

DESCRIPCIÓN

ausearch_next_event escaneará la fuente de entrada y evaluará si algún registro de un evento contiene los datos que se buscan. La evaluación se realiza a nivel de registro.

VALOR DE RETORNO

Devuelve -1 si ocurre un error, 0 si no hay coincidencias y 1 si es exitoso.

VER TAMBIÉN

ausearch_add_item(3), ausearch_add_regex(3), ausearch_set_stop(3).
