AUPARSE_NEW_BUFFER(3) API de auditoría de Linux AUPARSE_NEW_BUFFER(3)

NOMBRE

auparse_new_buffer - reemplaza el búfer en el analizador

SINOPSIS

#include <auparse.h>

int auparse_new_buffer(auparse_state_t *au,constchar*"data,size_t"data_len);"
au
El estado del análisis de auditoría
data
Un búfer de datos para pasar al analizador, tiene una longitud de data_len bytes. Los datos se copian en el analizador sin modificar el original. Al regresar, el llamador puede liberar o reutilizar el búfer de datos.
data_len
El número de bytes en data

DESCRIPCIÓN

auparse_new_buffer reemplaza los datos en los que trabaja el analizador. Se debe haber llamado a auparse_init() con un tipo de fuente de AUSOURCE_BUFFER.

VALOR DE RETORNO

Devuelve 1 si ocurre un error; de lo contrario, 0 si tiene éxito.

VER TAMBIÉN
