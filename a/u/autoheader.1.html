AUTOHEADER(1) Comandos de usuario AUTOHEADER(1)

NOMBRE

autoheader - Crea una plantilla de cabecera para configure

SINOPSIS

autoheader [OPCIÓN]... [ARCHIVO-PLANTILLA]

DESCRIPCIÓN

Crea un archivo de plantilla de directivas C '#define' para que 'configure' las use. Para ello, escanea ARCHIVO-PLANTILLA, o 'configure.ac' si está presente, o en su defecto 'configure.in'.

-h, --help
imprime esta ayuda y luego sale
-V, --version
imprime el número de versión y luego sale
-v, --verbose
informa detalladamente del procesamiento
-d, --debug
no elimina los archivos temporales
-f, --force
considera todos los archivos obsoletos
-W, --warnings=CATEGORÍA
informa de las advertencias que caen en CATEGORÍA (se acepta una lista separada por comas)

Las categorías de advertencia son:

cross
problemas de compilación cruzada
gnu
estándares de codificación de GNU (por defecto en modos gnu y gnits)
obsolete
características o construcciones obsoletas (por defecto)
override
redefiniciones por el usuario de reglas o variables de Automake
portability
problemas de portabilidad (por defecto en modos gnu y gnits)
portability-recursive
variables Make anidadas (por defecto con -Wportability)
extra-portability
problemas de portabilidad adicionales relacionados con herramientas poco comunes
syntax
construcciones sintácticas dudosas (por defecto)
unsupported
características no soportadas o incompletas (por defecto)

-W también entiende:

all
activar todas las advertencias
none
desactivar todas las advertencias
no-CATEGORÍA
desactivar las advertencias en CATEGORÍA
error
tratar todas las advertencias habilitadas como errores

Directorios de biblioteca:

-B, --prepend-include=DIR
anteponer el directorio DIR a la ruta de búsqueda
-I, --include=DIR
añadir el directorio DIR a la ruta de búsqueda
