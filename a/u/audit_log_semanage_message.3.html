AUDIT_LOG_SEMANAGE_MESSAGE(3) API de Auditoría de Linux AUDIT_LOG_SEMANAGE_MESSAGE(3)

NOMBRE

audit_log_semanage_message - registra un mensaje de semanage

SINOPSIS

#include <libaudit.h>

int audit_log_semanage_message(intaudit_fd,int"type,.Bconstchar*"pgname,constchar*"op,constchar*"name,unsignedint"id,.Bconstchar*"new_seuser,constchar*"new_role,constchar*"new_range,.Bconstchar*"old_seuser,constchar*"old_role,constchar*"old_range,.Bconstchar*"host,constchar*"addr,constchar*"tty,int"result);"

DESCRIPCIÓN

Esta función registrará un mensaje en el sistema de auditoría utilizando un formato de mensaje predefinido. Debe usarse para todas las operaciones de manipulación de usuarios y roles de SE Linux. Los parámetros de la función son los siguientes:

audit_fd - El descriptor de archivo devuelto por audit_open
type - tipo de mensaje: AUDIT_ROLE_ASSIGN/REMOVE para cambiar cualquier atributo de usuario o rol de SE Linux.
pgname - nombre del programa
op - operación. "adding-user", "adding-role", "deleting-user", "deleting-role"
name - cuenta de usuario. Si no está disponible, use NULL.
id - uid en el que se está realizando la operación. Esto solo se usa cuando name es NULL.
new_seuser - el nuevo seuser que obtiene el usuario que inicia sesión
new_role - el nuevo rol que obtiene el usuario que inicia sesión
new_range - el nuevo rango mls que obtiene el usuario que inicia sesión
old_seuser - el seuser antiguo que tenía el usuario que inicia sesión
old_role - el rol antiguo que tenía el usuario que inicia sesión
old_range - el rango mls antiguo que tenía el usuario que inicia sesión
host - El nombre del host si se conoce
addr - La dirección de red del usuario
tty - el tty del usuario
result - 1 es "éxito" y 0 es "fallo"

VALOR DE RETORNO

Devuelve el número de secuencia que es > 0 en caso de éxito o <= 0 en caso de error.

ERRORES

Esta función devuelve -1 en caso de fallo. Examine errno para más información.

VER TAMBIÉN

audit_log_user_message(3), audit_log_acct_message(3), audit_log_user_avc_message(3), audit_log_user_comm_message(3).
