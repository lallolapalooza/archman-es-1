NOMBRE

auto-multiple-choice-prepare - prepara documentos de trabajo a partir de un archivo fuente LaTeX

SINOPSIS

auto-multiple-choice prepare --mode s --prefix dir-proyecto archivo-fuente-mcq

auto-multiple-choice prepare --mode b --data dir-datos-proyecto archivo-fuente-mcq

DESCRIPCIÓN

El comando auto-multiple-choice prepare extrae documentos de trabajo del archivo fuente que describe el cuestionario de opción múltiple. La información a extraer depende del valor del argumento --mode. En cualquier modo, el nombre del archivo fuente debe proporcionarse como argumento.

•con "--mode s", auto-multiple-choice prepare crea el archivo de sujeto (hoja de respuestas para imprimir y entregar a los estudiantes), la corrección (hoja de respuestas corregida única) y el archivo de posiciones (archivo que contiene información sobre las posiciones de las casillas en las páginas). Los siguientes argumentos pueden ser utilizados:

--out-sujet sujeto.pdf

establece el archivo de sujeto a construir.

--out-corrige corregido.pdf

establece la corrección a construir.

--out-calage calage.xy

establece el archivo de posiciones a construir.

--prefix directorio

este directorio solo es necesario si una o más de las tres opciones anteriores no se utilizan: los valores predeterminados serán entonces directorio/sujet.pdf, directorio/corrige.pdf y directorio/calage.xy.
•con "--mode b", auto-multiple-choice prepare extrae datos de puntuación del archivo fuente. En este modo, el argumento --data debe ser utilizado (ver más abajo).

Los siguientes argumentos opcionales pueden ser utilizados en cualquier modo:

--with motor-latex

proporciona el motor LaTeX (comando) a utilizar. motor-latex puede ser pdflatex o xelatex por ejemplo.

--filter filtro

establece el nombre del filtro para transformar el archivo fuente MCQ en un archivo LaTeX. Los filtros nativos son latex (sin cambios) y plain (la fuente es un archivo AMC-TXT).

--filtered-source archivo-latex-mcq

proporciona el archivo LaTeX a crear a partir del archivo fuente utilizando el filtro especificado. Si se omite, se utiliza un nombre de archivo derivado de archivo-fuente-mcq añadiendo _filtered.tex.

--n-copies n

establece el número de copias a producir, anulando el número dado en el archivo fuente LaTeX (primer argumento del comando \onecopy).

--debug archivo.log

proporciona un archivo para rellenar con información de depuración.

--epoch EPOCH

proporciona una época (número de segundos desde el 1 de enero de 1970) para obtener una salida PDF reproducible.

--data dir-datos-proyecto

establece el directorio donde se encuentran los archivos de datos SQLite del proyecto.
