NOMBRE

auto-multiple-choice-imprime - imprime las hojas de respuestas de opción múltiple de AMC para distribuir a los estudiantes

SINOPSIS

auto-multiple-choice imprime --sujet=subject.pdf --fich-nums=numbers-file.txt --data=data-dir --methode=method [argumentos-de-impresion...]

DESCRIPCIÓN

El comando auto-multiple-choice imprime imprime copias seleccionadas de una hoja de respuestas de opción múltiple de AMC.

Qué imprimir

Los siguientes argumentos describen qué imprimir:

--sujet subject.pdf

establece el archivo de asunto (preparado por auto-multiple-choice-prepare(1)).

--fich-nums numbers-file.txt

proporciona un archivo donde se escriben los números de las copias a imprimir (un número por línea). Si no se proporciona este argumento, se imprimirán todas las copias.

--data data-dir

proporciona el directorio donde se encuentran los archivos de datos (ver por ejemplo auto-multiple-choice-meptex(1)). La base de datos de diseño en el directorio de datos se utiliza para saber en qué página del archivo de asunto comienza y termina cada copia.

--split

pide imprimir las hojas de respuesta por separado.

--answer-first

pide reordenar las páginas de cada copia para que la hoja de respuestas separada quede primero.

Dónde imprimir

Actualmente hay definidos varios métodos de impresión:

•con "--methode CUPS", auto-multiple-choice imprime imprime en una impresora CUPS. Se envía un trabajo de impresión por cada copia, permitiendo por ejemplo usar el grapado. Utilice las siguientes opciones con este método:

--imprimante printer

establece el nombre de la impresora CUPS a la que imprimir.

--options cups-options

proporciona opciones de CUPS, en el formato opt1=value1,opt2=value2,....
•con "--methode file", auto-multiple-choice imprime genera las hojas de respuesta en archivos (uno para cada copia).

--output filename

establece el nombre del archivo para las salidas. La secuencia '%e' se reemplazará por un número de copia de 4 dígitos. Si filename no contiene '%e', se añadirá la cadena '-%e.pdf' al final.
•con "--methode command", auto-multiple-choice imprime utilizará un comando proporcionado para cada copia.

--print-command command

proporciona el comando a utilizar para imprimir. La cadena de command se dividirá en cada carácter de espacio (incluso al usar comillas...). La secuencia '%f' se reemplazará por un nombre de archivo PDF (que contiene la copia a imprimir), y '%e' se reemplazará por el número de copia.

Otras opciones

Otras opciones disponibles:

--extract-with command

proporciona el comando a utilizar para extraer páginas del sujeto PDF. Actualmente, están disponibles pdftk, gs y qpdf. El valor predeterminado es pdftk, pero se utilizará qpdf y luego gs si el comando pdftk no está instalado.
