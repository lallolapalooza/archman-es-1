AUDIT_NAME_TO_FSTYPE(3) API de auditoría de Linux AUDIT_NAME_TO_FSTYPE(3)

NOMBRE

audit_name_to_fstype - Convierte el nombre fstype al valor numérico fstype

SINOPSIS

#include <libaudit.h>
int audit_name_to_fstype(const char *name);

DESCRIPCIÓN

audit_name_to_fstype() convierte el nombre fstype ("debugfs" o "tracefs") al valor numérico fstype (0x64626720 o 0x74726163). name es el nombre fstype.

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, el valor de retorno es el valor numérico fstype.
