NOM

auto-multiple-choice - Gestión automatizada de cuestionarios QCM

SINÓPSIS

auto-multiple-choice acción [argumentos...]

auto-multiple-choice [proyecto]

DESCRIPCIÓN

El comando auto-multiple-choice transmite a la comando AMC-acción.pl los argumentos que se le dan.

La segunda forma, que no menciona ninguna acción, llama a la interfaz gráfica auto-multiple-choice gui pasándole eventualmente el nombre de un proyecto a abrir.

VER TAMBIÉN

Diferentes acciones posibles: auto-multiple-choice-prepare(1), auto-multiple-choice-imprime(1), auto-multiple-choice-analyse(1), auto-multiple-choice-note(1), auto-multiple-choice-association-auto(1), auto-multiple-choice-export(1), auto-multiple-choice-annote(1), auto-multiple-choice-regroupe(1).
