NAME

aucat - audio mixer and record

SYNOPSIS

aucat [-a] [-b rate] [-c chn] [-f file] [-i file] [-m map] [-n] [-o file] [-q port] [-r rate] [-s port] [-t file] [-v] [-? ...]

DESCRIPTION

The aucat utility is a simple command-line audio mixer and recorder. It can play audio files, record audio streams, and mix multiple audio streams together. The utility supports a variety of audio file formats and allows for flexible configuration of input and output streams, sampling rates, and channel mapping.

By default, aucat reads from standard input and writes to standard output. This behavior can be modified using the various command-line options.

The core functionality of aucat revolves around mixing and routing audio data. It can accept multiple input files (-i) and mix them into a single output stream, which can then be saved to a file (-o) or played through an audio device.

The -m option allows for detailed channel mapping, enabling users to specify how channels from input files should be routed to output channels. This is particularly useful for handling stereo and mono audio sources.

The -r option sets the sampling rate for both input and output streams. This is crucial for ensuring compatibility between different audio sources and devices.

The -q option specifies a MIDI port for query, allowing aucat to listen for MIDI messages. This enables synchronization with external MIDI devices, such as sequencers.

The -s option specifies a MIDI port for synchronization, enabling aucat to act as a slave to an external MIDI clock or timecode source.

The -a option enables automatic resampling. When this option is used, aucat will automatically resample audio streams to match the output device's sample rate if they differ.

The -n option enables non-blocking mode. In this mode, aucat will not wait indefinitely for data if an input or output operation would block.

The -v option enables verbose output, providing more detailed information about the operations being performed.

The -b option specifies the buffer size in bytes. This can be used to tune performance or reduce latency.

The -c option specifies the number of channels for the output file. This is useful when creating files with a specific channel count, e.g., creating mono files from a stereo source.

The -f option specifies a default input file. This file will be read if no other input files are specified.

The -t option specifies a temporary file for intermediate storage. This can be useful for long recordings or complex mixing scenarios.

The -? option displays help information about the command-line arguments.

MIDI CONTROL

The aucat utility can be controlled via MIDI messages, allowing for synchronization with external sequencers or other MIDI devices. This is achieved using the -q and -s options to specify the MIDI ports for query and synchronization, respectively.

For example, to use aucat with a MIDI sequencer that sends MMC (MIDI Machine Control) commands on the midithru/0 port and uses snd/mmc as the MMC device, you would run:

$ aucat -f snd/mmc -q midithru/0 -i file.wav

At this stage, aucat will start, stop and relocate automatically following all user actions in the MIDI sequencer, assuming it's configured to transmit MMC on midithru/0 and snd/mmc. Furthermore, the MIDI sequencer could be configured to use the snd/mmc port as MTC clock source, assured to be synchronous to playback of file.wav.

EXAMPLES

Mix and play two files while recording a third file:

$ aucat -i file1.wav -i file2.wav -o file3.wav

Record channels 2 and 3 into one stereo file and channels 6 and 7 into another stereo file using a 44.1kHz sampling rate for both:

$ aucat -r 44100 -m 2:3/0:1 -o file1.wav -m 6:7/0:1 -o file2.wav

Split a stereo file into two mono files:

$ aucat -n -i stereo.wav -c 1 -m 0:0/0:0 -o left.wav \
	-m 1:1/0:0 -o right.wav

BUGS

Resampling is low quality.

There are limitations inherent to the wav, aiff, and au file formats: not all encodings are supported, file sizes are limited to 2GB, and the files must support the lseek(2) operation (e.g. pipes do not support it).
