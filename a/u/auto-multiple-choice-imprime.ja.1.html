NOMBRE

auto-multiple-choice-imprime - Imprime los exámenes de Auto Multiple Choice para su distribución a los examinados

SINOPSIS

auto-multiple-choice imprime --sujetsubject.pdf --fich-numsnumbers-file.txt --datadata-dir --methodemethod [where-to-print-arguments...]

DESCRIPCIÓN

auto-multiple-choice imprimeEl comando imprime los exámenes seleccionados.

Especificación de lo que se imprime

Los siguientes argumentos especifican qué se imprime:

--sujet subject.pdf

Establece el archivo de examen (creado porauto-multiple-choice-prepare(1)).

--fich-nums numbers-file.txt

Especifica un archivo que contiene los números de examen a imprimir (uno por línea). Si no se especifica este argumento, se imprimen todos los exámenes.

--data data-dir

Especifica el directorio que contiene los archivos de datos (verauto-multiple-choice-meptex(1), etc.). La base de datos de maquetación del directorio de datos se utiliza para saber de qué página a qué página va cada examen.

--split

Imprime las hojas de respuestas por separado.

--answer-first

Ordena para que las hojas de respuestas por separado vengan primero.

Especificación del método de impresión

Se definen varios métodos de impresión:

• Con «--methode CUPS», auto-multiple-choice imprimeimprime en una impresora CUPS. Se envía un trabajo de impresión por copia para que se pueda hacer, por ejemplo, un grapado automático de cada examen. Utilice las siguientes opciones con este método:

--imprimante printer

Establece el nombre de la impresora CUPS en la que imprimir.

--options cups-options

Especifica las opciones de CUPS en el formatoopt1=value1,opt2=value2,....
• Con «--methode file»,auto-multiple-choice imprimeimprime los exámenes en archivos (uno por copia).

--output filename

Establece el nombre del archivo de salida. Si contiene la secuencia «%e», esta se sustituye por el número de examen de cuatro dígitos.filenameSi
• Con «--methode command»,auto-multiple-choice imprimeejecuta el comando especificado para cada copia de examen.

--print-command command

Especifica el comando a utilizar para imprimir.La cadenacommand

Otras opciones

Las siguientes opciones también están disponibles:

--extract-with command

Especifica el comando para extraer páginas del PDF del examen. Actualmente se pueden especificarpdftk,gsoqpdf. El valor por defecto espdftk, pero si no está instalado, se utilizanqpdfygsen ese orden.
