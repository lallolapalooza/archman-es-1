AUSEARCH_ADD_REGEX(3) API de auditoría de Linux AUSEARCH_ADD_REGEX(3)

NOMBRE

ausearch_add_regex - utiliza una regla de búsqueda con expresión regular

SINOPSIS

#include <auparse.h>

int ausearch_add_regex(auparse_state_t *au,constchar*"regexp);"

DESCRIPCIÓN

ausearch_add_regex añade una condición de búsqueda basada en una expresión regular a la expresión de búsqueda de auditoría actual. Las condiciones de búsqueda se pueden utilizar luego para escanear registros, archivos o buffers en busca de algo de interés. La expresión regular sigue las convenciones de expresiones regulares extendidas de POSIX y se compara con el registro completo (sin interpretar los valores de los campos).

Si ya existe una expresión de búsqueda E definida, esta función la reemplaza por (E && this_regexp).

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, 0 para éxito.

VER TAMBIÉN

ausearch_add_expression(3), ausearch_add_item(3), ausearch_clear(3), ausearch_next_event(3), ausearch_cur_event(3), regcomp(3).
