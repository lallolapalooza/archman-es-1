NOMBRE

aurpublish - Marco de gestión de PKGBUILD para el Repositorio de Usuarios de Arch

SINOPSIS

aurpublish [opciones] PAQUETE

aurpublish log [<opciones>] PAQUETE

aurpublish setup

DESCRIPCIÓN

Aurpublish es una utilidad que ayuda a los mantenedores de paquetes del AUR a enviar actualizaciones.

CÓMO FUNCIONA

Confirma los PKGBUILDs en subdirectorios con nombre. Los exporta al AUR con el comando aurpublish, utilizando la estratagema de push de subárbol. Esto preserva un historial independiente para alojamiento de terceros, solicitudes de extracción... ;)

COMANDOS

setup

Inicializa un nuevo repositorio con hooks de git.

log <PAQUETE>

Ver el log de git de un subárbol de paquete.

OPCIONES

-p <PAQUETE>

En lugar de publicar, extrae cambios del AUR. Puede importar paquetes en un nuevo subárbol.

-s, --speedup <PAQUETE>

Acelera futuras publicaciones registrando el historial del subárbol durante un push. Esto crea un commit de fusión y una segunda copia de todos los commits en el subárbol. Para más detalles, véase la opción "--rejoin" en git-subtree(1).

-u, --url <URL>

Especifica la URL del servidor que debe ser utilizado para las operaciones de git.

-h, --help

Imprime una página de uso.

HOOKS

pre-commit

Advierte sobre errores de espacios en blanco, falla si las sumas de verificación no coinciden y genera automáticamente .SRCINFO para todos los PKGBUILDs modificados.

prepare-commit-msg

Pre-rellena el mensaje de commit con una lista de paquetes añadidos/actualizados/eliminados + versiones (si las hay).

ESPECIFICAR URL DEL SERVIDOR AUR

Puedes usar aurpublish para interactuar con un servidor git distinto del servidor git AUR por defecto en aur.archlinux.org. Esto puede ser útil si estás ejecutando tu propio servidor AUR.

La URL del servidor git ascendente se puede configurar de dos maneras. Puedes establecer la URL con las opciones -u/--url cuando ejecutas aurpublish. O puedes configurar el servidor persistentemente en git estableciendo la opción aurpublish.remoteUrl.

Establecer la URL con --url

aurpublish --url ssh://yo@example.com mi-paquete

Establecer la URL para el directorio git actual con git config

git config aurpublish.remoteUrl ssh://yo@example.com

Establecer la URL globalmente con git config

git config --global aurpublish.remoteUrl ssh://yo@example.com

Para más detalles sobre las opciones de git, consulta git-config(1).

EJEMPLOS

aurpublish setup

Inicializa un nuevo repositorio con hooks de git. Consulta la sección Hooks para más información.

aurpublish -p ansible-core-git

Clona un paquete existente del AUR y añade su URL como un subárbol de git al repositorio de git existente.

aurpublish ansible-core-git

Publica un subárbol existente en el AUR.

aurpublish log

Ver el log de git de un subárbol de paquete.

aurpublish --url ssh://yo@example.com ansible-core-git

Publica el subárbol en un servidor en ssh://example.com.
