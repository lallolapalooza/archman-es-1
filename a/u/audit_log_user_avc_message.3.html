AUDIT_LOG_USER_AVC_MESSAGE(3) API de auditoría de Linux AUDIT_LOG_USER_AVC_MESSAGE(3)

NOMBRE

audit_log_user_avc_message - registrar un mensaje avc de usuario

SINOPSIS

#include <libaudit.h>

int audit_log_user_avc_message(intaudit_fd,int"type,constchar*"message,constchar*"hostname,constchar*"addr,constchar*"tty,uid_t"auid);"

DESCRIPCIÓN

Esta función registrará un mensaje en el sistema de auditoría utilizando un formato de mensaje predefinido. Todas las aplicaciones que sean gestores de objetos de SE Linux deben utilizar esta función. Los parámetros de la función son los siguientes:

audit_fd - El descriptor de archivo devuelto por audit_open
type - tipo de mensaje, ej: AUDIT_USER_AVC
message - el mensaje que se envía
hostname - el nombre del host si se conoce
addr - La dirección de red del usuario
tty - El tty del usuario, si es NULL intentará averiguarlo
auid - El auid de la persona relacionada con el mensaje avc

Estos valores deben corresponder a la persona a la que se refiere el mensaje.

VALOR DE RETORNO

Devuelve el número de secuencia, que es > 0 en caso de éxito o <= 0 en caso de error.

ERRORES

Esta función devuelve -1 en caso de fallo. Examine errno para más información.

VER TAMBIÉN

audit_log_user_message(3), audit_log_acct_message(3), audit_log_user_comm_message(3), audit_log_semanage_message(3).
