AUDIT_GET_REPLY(3) API de auditoría de Linux AUDIT_GET_REPLY(3)

NOMBRE

audit_get_reply - Obtener la respuesta del sistema de auditoría

SINOPSIS

#include <libaudit.h>
int audit_get_reply(int fd, struct audit_reply *rep, reply_t block, int peek);"

DESCRIPCIÓN

Esta función obtiene el siguiente paquete de datos enviado en el socket netlink de auditoría. Esta función generalmente se llama después de enviar un comando al sistema de auditoría. fd debe ser un descriptor de archivo abierto devuelto por audit_open. rep debe ser una estructura de datos donde colocar la respuesta. block es de tipo reply_t, que puede ser: GET_REPLY_BLOCKING y GET_REPLY_NONBLOCKING. peek, si no es cero, obtiene los datos sin eliminarlos de la cola del socket netlink.

VALOR DE RETORNO

Esta función devuelve -errno en caso de error, 0 si se recibe una respuesta de error y un valor positivo si tiene éxito.

VER TAMBIÉN

audit_open(3).
