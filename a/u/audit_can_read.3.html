AUDIT_CAN_CONTROL(3) API de auditoría de Linux AUDIT_CAN_CONTROL(3)

NOMBRE

audit_can_control, audit_can_write, audit_can_read - probar capacidades relacionadas con la auditoría

SINOPSIS

#include <libaudit.h>

int audit_can_control(void);
int audit_can_write(void);
int audit_can_read(void);

DESCRIPCIÓN

audit_can_control() devuelve 1 si el proceso que llama posee la capacidad CAP_AUDIT_CONTROL, de lo contrario devuelve 0. audit_can_write() devuelve 1 si CAP_AUDIT_WRITE está disponible. audit_can_read() devuelve 1 si CAP_AUDIT_READ está presente. Cuando no hay soporte para libcap-ng, estas funciones solo devuelven 1 cuando el UID efectivo es 0.

VALOR DEVUELTO

Estas funciones devuelven 1 cuando la capacidad está presente y 0 en caso contrario.

VER TAMBIÉN

audit_open(3).
