AUTORECONF(1) Comandos de usuario AUTORECONF(1)

NOMBRE

autoreconf - Actualiza los archivos de configuración generados

SINOPSIS

autoreconf [OPCIÓN]... [DIRECTORIO]...

DESCRIPCIÓN

Ejecuta 'autoconf' y, cuando sea necesario, 'aclocal', 'autoheader', 'automake', 'autopoint' (anteriormente 'gettextize'), 'libtoolize', 'intltoolize' y 'gtkdocize' para regenerar los archivos del Sistema de Compilación GNU en los DIRECTORIOS especificados y sus subdirectorios (por defecto '.').

Por defecto, solo rehace aquellos archivos que están más anticuados que sus fuentes. Si instala nuevas versiones del Sistema de Compilación GNU, puede hacer que 'autoreconf' rehaga todos los archivos dándole la opción '--force'.

Modos de operación:

-h, --help
imprime esta ayuda y sale
-V, --version
imprime el número de versión y sale
-v, --verbose
informa detalladamente del procesamiento
-d, --debug
no elimina archivos temporales
-f, --force
considera obsoletos todos los archivos generados y estándar
-i, --install
copia archivos auxiliares estándar que falten
--no-recursive
no rehace subpaquetes
-s, --symlink
con -i, instala enlaces simbólicos en lugar de copias
-m, --make
cuando sea aplicable, re-ejecuta ./configure && make
-W, --warnings=CATEGORÍA
informa las advertencias que caen en CATEGORÍA (se acepta una lista separada por comas)

Las categorías de advertencia son:

cross
problemas de compilación cruzada
gnu
estándares de codificación de GNU (por defecto en modos gnu y gnits)
obsolete
características o construcciones obsoletas (por defecto)
override
redefiniciones por el usuario de reglas o variables de Automake
portability
problemas de portabilidad (por defecto en modos gnu y gnits)
portability-recursive
variables de Make anidadas (por defecto con -Wportability)
extra-portability
problemas adicionales de portabilidad relacionados con herramientas poco comunes
syntax
construcciones sintácticas dudosas (por defecto)
unsupported
características no compatibles o incompletas (por defecto)

-W también entiende:

all
activa todas las advertencias
none
desactiva todas las advertencias
no-CATEGORÍA
desactiva las advertencias en CATEGORÍA
error
trata todas las advertencias habilitadas como errores

Directorios de biblioteca:

-B, --prepend-include=DIR
antepone el directorio DIR a la ruta de búsqueda
-I, --include=DIR
añade el directorio DIR a la ruta de búsqueda

Se respetan las variables de entorno AUTOCONF, ACLOCAL, AUTOHEADER, AUTOM4TE, AUTOMAKE, AUTOPOINT, GTKDOCIZE, INTLTOOLIZE, LIBTOOLIZE, M4, MAKE y WARNINGS.
