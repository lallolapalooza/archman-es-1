NOMBRE

auto-multiple-choice-analyse - captura automática de datos de escaneos para exámenes de opción múltiple de AMC.

SINOPSIS

auto-multiple-choice analyse --projet directorio-proyecto [--seuil-coche umbral] [--tol-marque tol] [--list-fichiers lista-archivos.txt | archivos-escaneo...]

DESCRIPCIÓN

El comando auto-multiple-choice analyse realiza la captura automática de datos de escaneos de hojas de respuestas completadas de un cuestionario de opción múltiple de AMC. Antes de llamar a auto-multiple-choice analyse, se debería haber llamado a auto-multiple-choice-prepare(1) para crear los documentos de trabajo (--mode s) y el diseño debería haber sido procesado con auto-multiple-choice-meptex(1).

--data directorio-datos

especifica el directorio donde se encuentran los archivos de datos (ver por ejemplo auto-multiple-choice-meptex(1)). Por defecto es directorio-proyecto/data.

--cr directorio-proyecto-cr

especifica un directorio donde crear informes de imagen de la captura de datos (zumos en un subdirectorio de zumos, extracción de nombres de archivo como un archivo name-*.jpg, e informe de diseño como un archivo page-*.jpg).

--projet directorio-proyecto

Al usar esta opción, si no se usa --cr, directorio-proyecto-cr se establecerá a directorio-proyecto/cr.

Los nombres de los archivos de escaneo a procesar se pueden proporcionar de dos maneras:

•estos nombres se pueden dar como argumentos,
•estos nombres se pueden escribir en un archivo plano (un nombre de archivo por línea), usando --list-fichiers lista-archivos.txt para dar el nombre de este archivo.

Algunos parámetros para la captura de datos se pueden establecer usando las siguientes opciones:

--prop proporcion

establece la proporción de cada casilla que se medirá para decidir si la casilla está marcada o no. El valor por defecto es 0.8.

--bw-threshold umbral

Este parámetro se usa al convertir el archivo de escaneo en escala de grises a blanco y negro. Para obtener más píxeles negros, use un valor mayor. Para obtener más píxeles blancos, use un valor menor. El umbral debe estar entre 0 y 1. El valor por defecto es 0.6.

--ignore-red

Con esta opción, solo se usará el canal rojo de los escaneos a color. De esta manera, todo lo escrito en rojo se ignorará en el escaneo. Esto puede ser útil cuando las casillas están impresas en rojo.

--tol-marque tol

define la tolerancia al detectar las cuatro marcas en las esquinas de los escaneos. Estas marcas se detectan buscando componentes conectados negros cuyas dimensiones son cercanas a la dimensión objetivo objetivo (dimensiones exactas de las marcas si el proceso de impresión/escaneo fuera perfectamente preciso). Si tol es un número real, las dimensiones aceptadas son aquellas entre (1-tol)*objetivo y (1+tol)*objetivo. Si tol es "tinf,tsup" (donde tinf y tsup son números reales), las dimensiones aceptadas son aquellas entre (1-tinf)*objetivo y (1+tsup)*objetivo. Un valor estándar es 0.2.

--multiple

Esta opción debe usarse cuando los escaneos son fotocopias de algunos sujetos (diferentes estudiantes pueden tener el mismo sujeto). En este caso, se asignan números de copia a los estudiantes para que sus hojas de respuestas, con el mismo número de sujeto, puedan diferenciarse.

--pre-allocate id_copia

Esta opción se puede usar junto con --multiple. Los números de copia utilizados para los escaneos comenzarán desde id_copia, en el mismo orden que los escaneos proporcionados como argumentos.

--try-three | --no-try-three

Use una de estas opciones para indicar si se permite el procesamiento de escaneos donde solo hay tres marcas en las esquinas presentes.

--debug archivo.log

especifica un archivo para rellenar con información de depuración.
