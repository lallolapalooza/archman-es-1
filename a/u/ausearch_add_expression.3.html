ausearch_add_expression(3)

Paquete: audit

AUSEARCH_ADD_EXPRESSION(3) API de auditoría de Linux AUSEARCH_ADD_EXPRESSION(3)

NOMBRE

ausearch_add_expression - construir una expresión de búsqueda

SINOPSIS

#include <auparse.h>
int ausearch_add_expression(auparse_state_t *au, const char *expression, char **error, ausearch_rule_t how);

DESCRIPCIÓN

ausearch_add_item agrega una expresión a la expresión de búsqueda actual del auditor. Las condiciones de búsqueda se pueden usar luego para escanear registros, archivos o búferes en busca de algo de interés. El parámetro expression contiene una expresión, como se especifica en ausearch-expression(5). El parámetro how determina cómo esta expresión de búsqueda afectará la expresión de búsqueda existente, si ya hay una definida. Los valores posibles son:

AUSEARCH_RULE_CLEAR
Borra la expresión de búsqueda actual, si la hay, y usa solo esta expresión de búsqueda.
AUSEARCH_RULE_OR
Si ya hay configurada una expresión de búsqueda E, reemplázala por (E || esta_expresión_de_búsqueda).
AUSEARCH_RULE_AND
Si ya hay configurada una expresión de búsqueda E, reemplázala por (E && esta_expresión_de_búsqueda).
El llamador debe liberar el mensaje de error usando free(3). Si no hay un mensaje de error disponible o no se puede asignar, *error se establece en NULL.

VER TAMBIÉN
