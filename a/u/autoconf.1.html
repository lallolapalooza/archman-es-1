NOMBRE

autoconf - Generar scripts de configuración

SINOPSIS

autoconf [OPCIÓN]... [ARCHIVO-PLANTILLA]

DESCRIPCIÓN

Genera un script de configuración a partir de ARCHIVO-PLANTILLA si se proporciona, o 'configure.ac' si está presente, o de lo contrario 'configure.in'. La salida se envía a la salida estándar si se proporciona ARCHIVO-PLANTILLA, de lo contrario se guarda en 'configure'.

Modos de operación:

-h, --help
imprimir esta ayuda y salir
-V, --version
imprimir el número de versión y salir
-v, --verbose
informar detalladamente del procesamiento
-d, --debug
no eliminar archivos temporales
-f, --force
considerar todos los archivos obsoletos
-o, --output=ARCHIVO
guardar la salida en ARCHIVO (stdout es el predeterminado)
-W, --warnings=CATEGORÍA
informar de las advertencias que caen en CATEGORÍA (se acepta una lista separada por comas)

Las categorías de advertencia son:

cross
problemas de compilación cruzada
gnu
estándares de codificación de GNU (predeterminado en modos gnu y gnits)
obsolete
características o construcciones obsoletas (predeterminado)
override
redefiniciones de usuario de reglas o variables de Automake
portability
problemas de portabilidad (predeterminado en modos gnu y gnits)
portability-recursive
variables de Make anidadas (predeterminado con -Wportability)
extra-portability
problemas adicionales de portabilidad relacionados con herramientas oscuras
syntax
construcciones sintácticas dudosas (predeterminado)
unsupported
características no compatibles o incompletas (predeterminado)

-W también entiende:

all
activar todas las advertencias
none
desactivar todas las advertencias
no-CATEGORÍA
desactivar advertencias en CATEGORÍA
error
tratar todas las advertencias habilitadas como errores

Directorios de bibliotecas:

-B, --prepend-include=DIR
preponer el directorio DIR a la ruta de búsqueda
-I, --include=DIR
añadir el directorio DIR a la ruta de búsqueda

Seguimiento:

-t, --trace=MACRO[:FORMATO]
informar de la lista de llamadas a MACRO
-i, --initialization
seguir también el proceso de inicialización de Autoconf

En modo de seguimiento, no se crea ningún script de configuración. FORMATO tiene como valor predeterminado '$f:$l:$n:$%'; consulte 'autom4te --help' para obtener información sobre FORMATO.
