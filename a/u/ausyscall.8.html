AUSYSCALL(8) Utilidades de administración del sistema AUSYSCALL(8)

NOMBRE

ausyscall - un programa que permite mapear nombres y números de llamadas al sistema

SINOPSIS

ausyscall [arquitectura] nombre | número | --dump | --exact

DESCRIPCIÓN

ausyscall es un programa que muestra el mapeo de nombres de llamadas al sistema a números y viceversa para la arquitectura dada. La arquitectura puede ser cualquier cosa devuelta por `uname -m`. Si no se proporciona la arquitectura, el programa intentará adivinarla basándose en la imagen en ejecución. O, para mayor comodidad, puede pasar b32 o b64 para usar la arquitectura actual pero una ABI específica. Puede proporcionar el nombre o el número de la llamada al sistema y encontrará lo contrario. También puede volcar toda la tabla con la opción --dump. Por defecto, una búsqueda de nombre de llamada al sistema será una coincidencia parcial, lo que significa que intentará hacer coincidir todas las ocurrencias del nombre dado con las llamadas al sistema. Por lo tanto, dar un nombre como chown coincidirá tanto con fchown como con chown, así como con cualquier otra llamada al sistema que contenga chown en su nombre. Si este comportamiento no es deseado, pase la opción --exact y realizará una coincidencia de cadena exacta.

El programa toma la arquitectura especial, uring, para indicar que desea especificar operaciones io_uring. En este caso, se debe proporcionar la arquitectura porque de lo contrario detectará el hardware subyacente.

Este programa puede usarse para verificar números de llamadas al sistema en una plataforma bi-arquitectura para la optimización de reglas. Por ejemplo, suponga que tiene una regla de auditctl:

-a always, exit -S open -F exit=-EPERM -k fail-open

Si quisiera verificar que tanto los programas de 32 como los de 64 bits serán auditados, ejecute "ausyscall i386 open" y luego "ausyscall x86_64 open". (O use las opciones b32 y b64). Observe los números devueltos. Si son diferentes, tendrá que escribir dos reglas de auditctl para lograr una cobertura completa.

-a always,exit -F arch=b32 -S open -F exit=-EPERM -k fail-open
-a always,exit -F arch=b64 -S open -F exit=-EPERM -k fail-open

Para obtener más información sobre una llamada al sistema específica, use el programa man y pase el número 2 como argumento para asegurarse de que obtiene la información de la llamada al sistema en lugar de un programa de script de shell o una función de glibc del mismo nombre. Por ejemplo, si quisiera aprender sobre la llamada al sistema open, escriba: man 2 open.

OPCIONES

--dump
Imprime todas las llamadas al sistema para la arquitectura dada
--exact
En lugar de hacer una coincidencia de palabra parcial, coincida exactamente con el nombre de llamada al sistema dado.

VER TAMBIÉN

ausearch(8), auditctl(8).
