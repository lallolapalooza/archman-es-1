AUDIT_SETLOGINUID(3) API de auditoría de Linux AUDIT_SETLOGINUID(3)

NOMBRE

audit_setloginuid - Establecer el valor loginuid de un programa

SINOPSIS

#include <libaudit.h>

int audit_setloginuid(uid_tuid);"

DESCRIPCIÓN

Esta función establece el atributo de tarea loginuid con el valor de uid. El valor loginuid solo puede ser establecido por programas con la capacidad CAP_AUDIT_CONTROL. Normalmente, esto significa la cuenta root.

El valor loginuid es parte de la estructura de tareas y es heredado por los procesos hijos. Se utiliza para rastrear con qué cuenta un usuario obtuvo acceso al sistema. Todos los programas del punto de entrada del sistema deberían establecer este valor justo antes de cambiar a la uid del usuario al que se concedió el acceso, de modo que los eventos de auditoría se atribuyan correctamente a ese usuario.

VALOR DE RETORNO

Esta función devuelve 0 en caso de éxito y un valor distinto de cero en caso contrario.

VER TAMBIÉN

audit_getloginuid(3), pam_loginuid(8).
