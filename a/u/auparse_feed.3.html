AUPARSE_FEED(3) API de auditoría de Linux AUPARSE_FEED(3)

NOMBRE

auparse_feed - alimentar datos al analizador

SINOPSIS

#include <auparse.h>

int auparse_feed(auparse_state_t *au,constchar*"data,size_t"data_len);"
au
El estado de análisis de auditoría
data
un búfer de datos para alimentar al analizador, tiene una longitud de data_len bytes. Los datos se copian en el analizador; al regresar, el llamador puede liberar o reutilizar el búfer de datos.
data_len
número de bytes en data

DESCRIPCIÓN

auparse_feed suministra nuevos datos para que el analizador los consuma. Se debe haber llamado a auparse_init() con un tipo de origen de AUSOURCE_FEED y un puntero NULL.

El analizador consume tantos datos como puede, invocando una devolución de llamada proporcionada por el usuario especificada con auparse_add_callback con un tipo de evento de llamada de función de AUPARSE_CB_EVENT_READY cada vez que el analizador reconoce un evento completo en el flujo de datos. Los datos no analizados por completo persistirán y se antepondrán a los datos alimentados posteriormente. Después de que todos los datos se hayan alimentado al analizador, se debe llamar a auparse_flush_feed para señalar el fin de los datos de entrada y vaciar cualquier dato de análisis pendiente a través del sistema de análisis.

VALOR DE RETORNO

Devuelve -1 si ocurre un error; de lo contrario, 0 para éxito.

EJEMPLO

void
auparse_callback(auparse_state_t *au, auparse_cb_event_t cb_event_type,
                 void *user_data)
{
    int *event_cnt = (int *)user_data;
    if (cb_event_type == AUPARSE_CB_EVENT_READY) {
        if (auparse_first_record(au) <= 0) return;
        printf("event: %d\n", *event_cnt);
        printf("records:%d\n", auparse_get_num_records(au));
        do {
            printf("fields:%d\n", auparse_get_num_fields(au));
            printf("type=%d ", auparse_get_type(au));
            const au_event_t *e = auparse_get_timestamp(au);
            if (e == NULL) return;
            printf("event time: %lu.%u:%lu\n",
                    (long unsigned)e->sec, e->milli, e->serial);
            auparse_first_field(au);
            do {
                printf("%s=%s (%s)\n", auparse_get_field_name(au),
                       auparse_get_field_str(au),
                       auparse_interpret_field(au));
            } while (auparse_next_field(au) > 0);
            printf("\n");
        } while(auparse_next_record(au) > 0);
        (*event_cnt)++;
    }
}
main(int argc, char **argv)
{
    char *filename = argv[1];
    FILE *fp;
    char buf[256];
    size_t len;
    int *event_cnt = malloc(sizeof(int));
    au = auparse_init(AUSOURCE_FEED, 0);
    auparse_set_eoe_timeout(2);
    *event_cnt = 1;
    auparse_add_callback(au, auparse_callback, event_cnt, free);
    if ((fp = fopen(filename, "r")) == NULL) {
        fprintf(stderr, "could not open '%s', %s\n", filename, strerror(errno));
        return 1;
    }
    while ((len = fread(buf, 1, sizeof(buf), fp))) {
        auparse_feed(au, buf, len);
    }
    auparse_flush_feed(au);
    auparse_destroy(au);
}
