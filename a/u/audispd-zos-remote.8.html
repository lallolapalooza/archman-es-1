Data Field List

También conocido como relocates, esta lista incluirá todos los nombres de campo y valores en un fieldname=value formato, como un tipo 114Application specific Data) relocate. El complemento intentará interpretar esos campos (es decir: usar el nombre de usuario legible root en lugar del userid numérico 0) siempre que sea posible. Actualmente, este complemento también añadirá un relocate tipo 113 (Date And Time Security Event Occurred) con la Marca de tiempo del evento en el formato devuelto por ctime(3).

ERRORES

Los errores y advertencias se reportan a syslog (bajo la facilidad DAEMON). En situaciones donde el evento fue enviado pero el servidor z/OS devolvió una condición de error, el mensaje registrado trae un nombre seguido de una descripción legible. A continuación se presentan algunas condiciones de error comunes:

NOTREQ - No logging required
El recurso (tipo de registro de auditoría) no está configurado para ser registrado en el servidor RACF - El perfil de la Clase @LINUX que gobierna este tipo de registro de auditoría está configurado para ignorar. Ver IBM z/OS RACF Server configuration
UNDETERMINED - Undetermined result
No se encontró un perfil para el recurso especificado. No hay ninguna Clase @LINUX configurada o no hay ningún perfil de Clase @LINUX asociado con este tipo de registro de auditoría. Ver IBM z/OS RACF Server configuration
UNAUTHORIZED - The user does not have authority the R_auditx service
El ID de usuario asociado con el ITDS no tiene acceso de LECTURA al perfil de la Clase FACILITY IRR.AUDITX. Ver IBM z/OS RACF Server configuration
UNSUF_AUTH - The user has insufficient authority for the requested function
El ID de usuario de RACF utilizado para realizar solicitudes de Auditoría Remota (como se configura en zos-remote.conf(5)) no tiene acceso al perfil de la Clase FACILITY IRR.LDAP.REMOTE.AUDIT. Ver IBM z/OS RACF Server configuration

ERRORES

El complemento actualmente realiza auditoría remota sobre una base de mejor esfuerzo, y descartará los eventos en caso de que no se pueda contactar con el servidor z/OS (fallos de red) o en cualquier otro caso en el que falle el envío del evento.
