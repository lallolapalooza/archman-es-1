AUDIT_GET_FEATURES(3) API de auditoría de Linux AUDIT_GET_FEATURES(3)

NOMBRE

audit_get_features, audit_set_feature - consultar o cambiar las características de auditoría del kernel

SINOPSIS

#include <libaudit.h>

uint32_t audit_get_features(void);
int audit_set_feature(int fd, unsigned feature, unsigned value, unsigned lock);"

DESCRIPCIÓN

audit_get_features() devuelve un mapa de bits que describe qué características de auditoría del kernel son compatibles. El mapa de bits se almacena en caché internamente y se recupera del kernel en la primera llamada.

audit_set_feature() cambia un bit de característica para el kernel utilizando el descriptor fd, que debe ser un socket netlink de auditoría abierto. feature selecciona el bit a modificar. Si value no es cero, la característica se habilita; de lo contrario, se deshabilita. Si lock no es cero, la configuración de la característica se bloquea hasta el reinicio.

Los bits de característica definidos actualmente son:

AUDIT_FEATURE_BITMAP_BACKLOG_LIMIT
El kernel admite el cambio de la profundidad de la cola de respaldo.
AUDIT_FEATURE_BITMAP_BACKLOG_WAIT_TIME
El kernel admite el retraso de las llamadas al sistema cuando la cola está llena.
AUDIT_FEATURE_BITMAP_EXECUTABLE_PATH
El kernel incluirá la ruta ejecutable en los registros EXECVE.
AUDIT_FEATURE_BITMAP_EXCLUDE_EXTEND
Las reglas de exclusión se pueden usar con más campos que solo el tipo de mensaje.
AUDIT_FEATURE_BITMAP_SESSIONID_FILTER
Se admite el filtrado del identificador de sesión.
AUDIT_FEATURE_BITMAP_LOST_RESET
Permite restablecer el contador de eventos perdidos.
AUDIT_FEATURE_BITMAP_FILTER_FS
El kernel admite el filtrado de campos del sistema de archivos.

VALOR DE RETORNO

audit_get_features devuelve el mapa de bits de características o 0 si las consultas de características no son compatibles. audit_set_feature devuelve <= 0 en caso de error, de lo contrario, es el número de secuencia netlink.

VER TAMBIÉN

audit_request_features(3), audit_reset_lost(3), audit_open(3).
