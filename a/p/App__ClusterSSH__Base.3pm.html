DESCRIPCIÓN

Objeto base para proporcionar algunas funciones de utilidad en los objetos - no debe usarse directamente

MÉTODOS

Estos métodos adicionales se proporcionan en el objeto

$obj = App::ClusterSSH::Base->new({ arg => val, });
Crea el objeto. En niveles de depuración más altos, los argumentos se imprimen.
$obj->id
Devuelve el ID único del objeto para usarlo en subclases, como 
$info_for{ $self->id } = $info
$obj->debug_level();
Devuelve el nivel de depuración actual
$obj->set_debug_level( n )
Establece el nivel de depuración a 'n' para todos los objetos hijos.
$obj->debug($level, @text)
Muestra @text en STDOUT si $level es igual o inferior a debug_level
$obj->set_lang
Establece el idioma de Locale::Maketext. Por defecto es 'en'. Espera que el módulo App::ClusterSSH/L10N/{lang}.pm exista y contenga todas las traducciones relevantes, de lo contrario, utiliza el inglés por defecto.
$obj->loc('texto a traducir [_1]')
Usando el módulo App::ClusterSSH/L10N/{lang}.pm, convierte el texto dado al idioma apropiado. Ver App::ClusterSSH::L10N para más detalles. Esencialmente es un envoltorio para maketext en Locale::Maketext
$obj->stdout_output(@);
Muestra texto en STDOUT.
$obj->parent;
Devuelve el objeto que es el padre de este, si se estableció al crear el objeto
%obj->options;
Accesorio a las opciones configuradas, si están configuradas en este punto
$obj->exit;
Stub para permitir que el programa salga limpiamente desde cualquier lugar del código
$config = $obj->config;
Devuelve el objeto de configuración que se haya configurado. Croaks si set_config no se ha llamado
$obj->set_config($config);
Establece la configuración al valor dado - croaks si ya se ha llamado
$sort = $obj->sort
Referencia de código utilizada para ordenar listas; si está configurada (e instalada) utiliza Sort;:Naturally, de lo contrario, utiliza el ordenamiento de Perl
%results = $obj->load_file( filename => '/ruta/al/archivo', type => '(cluster|config}' )
Carga el archivo especificado y devuelve un hash, analizando el archivo dependiendo de si es un archivo de configuración (clave = valor) o un archivo de clúster (clave valor)
