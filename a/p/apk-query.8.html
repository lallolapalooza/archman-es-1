apk-query(8) Manual del Administrador del Sistema apk-query(8)

NOMBRE

apk query - consultar información sobre paquetes por varios criterios

SINOPSIS

apk query [<opciones>...] consulta...

apk query [<opciones>...] --recursive restricciones...

DESCRIPCIÓN

apk query busca paquetes coincidentes en las fuentes seleccionadas.

En el modo predeterminado, los especificadores de consulta se interpretan de la siguiente manera:

nombre{[<>~=]versión}
Selecciona paquetes por nombre y coincidencia de versión opcional.
texto
Selecciona paquetes por campos seleccionados que coinciden con texto.

En el modo --recursive, las restricciones especifican una lista de dependencias a satisfacer y el algoritmo de resolución se utiliza para determinar una lista de paquetes que cumplan estas restricciones.

La consulta se ejecuta en los siguientes pasos:

1.
Cada cadena de consulta se ejecuta de forma independiente para seleccionar paquetes candidatos
2.
Si no se especifica --all-matches, se añade el mejor candidato para el término dado a la lista de paquetes de resultado
3.
La lista de paquetes resultante se ordena

OPCIONES DE CONSULTA

Los applets que admiten especificadores de consulta reconocen las siguientes opciones:

--all-matches

Selecciona todas las coincidencias. De forma predeterminada, solo se selecciona la mejor coincidencia para cada elemento de la consulta.

--available

Filtra la selección a paquetes disponibles.

--fields CAMPOS[:CAMPO_INVERSO]

Una lista separada por comas de campos a incluir en la salida. Se puede especificar una especificación opcional para el campo a mostrar para los campos sintéticos de dependencia inversa (name, package u origin).

--format FORMATO

Especifica el formato de salida: default, yaml o json. El formato default es texto legible por humanos.

--from ORIGEN

Busca paquetes de: system (todas las fuentes del sistema), repositories (excluye la base de datos instalada), installed (excluye los repositorios normales) o none (solo repositorios de la línea de comandos).

--installed

Filtra la selección a paquetes instalados.

--match CAMPOS

Una lista separada por comas de campos con los que hacer coincidir la consulta.

--recursive

Ejecuta el algoritmo de resolución con las restricciones dadas para seleccionar paquetes.

--summarize CAMPO[:CAMPO_INVERSO]

Produce un resumen del campo especificado de todas las coincidencias. El resumen está disponible en los siguientes campos: package, name, origin, depends, provides, replaces, install_if, recommends, reverse-depends y reverse-install-if.

--upgradable

Filtra la selección a paquetes actualizables.

--world

Incluye las dependencias de apk-world(5) en las restricciones. Implica --recursive.

--orphaned

Filtra la selección a paquetes huérfanos.

CAMPOS

Los nombres de los campos están todos en minúsculas para las opciones --match y --fields y para la salida analizable por máquina (json y yaml). Para el formato predeterminado legible por humanos, los campos están en mayúsculas.

Los siguientes campos de metadatos de paquetes están disponibles: name, version, description, arch, license, origin, maintainer, url, commit, build-time, installed-size, file-size, provider-priority, depends, provides, replaces, install-if, layer, tags, triggers, scripts y replaces-priority. Consulte las secciones metadatos de información del paquete y metadatos del paquete de apk-package(8) para obtener la descripción de estos campos.

Además, los siguientes campos están disponibles:

contents

Nombres de archivos contenidos en un paquete.

download-url

URL completa para descargar el paquete.

owner

Busca el paquete propietario para un nombre de ruta dado. (Solo --match)

package

El identificador del paquete en el formato nombre-versión (por ejemplo, package-1.0-r0).

repositories

Lista de repositorios en los que está disponible el paquete.

status

Estado de un paquete instalado. Lista de una o más de las siguientes palabras clave:
  • installed
  • broken-files
  • broken-scripts
  • broken-xattr

EJEMPLOS

# buscar todos los paquetes que empiecen por apk
apk query "apk*"

# mostrar el paquete propietario del ejecutable sensors en json
apk query --format json --match owner /usr/bin/sensors

# mostrar apk-tools y sus dependencias en yaml
apk query --format yaml --recursive apk-tools

# imprimir paquetes de origen para todos los paquetes que proporcionan cmd:apk
apk query --match name,provides cmd:apk --fields origin

# imprimir paquetes de origen con un nombre de dependencia específico
apk query --match dependency so:libapk.so.2.14.9 --fields origin
