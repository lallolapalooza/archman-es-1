AppConfig::Sys(3) Documentación de Perl aportada por el usuario AppConfig::Sys(3)

NOMBRE

AppConfig::Sys - Módulo Perl5 que define información y métodos específicos de la plataforma para otros módulos AppConfig::*.

SINOPSIS

use AppConfig::Sys;
my $sys = AppConfig::Sys->new();
@fields = $sys->getpwuid($userid);
@fields = $sys->getpwnam($username);

DESCRIPCIÓN GENERAL

AppConfig::Sys es un módulo Perl5 que proporciona información y operaciones específicas de la plataforma según lo requieran otros módulos AppConfig::*.

AppConfig::Sys se distribuye como parte del paquete AppConfig.

DESCRIPCIÓN

USANDO EL MÓDULO AppConfig::Sys

Para importar y usar el módulo AppConfig::Sys, la siguiente línea debe aparecer en tu script Perl:

use AppConfig::Sys;

AppConfig::Sys se implementa utilizando métodos orientados a objetos. Se crea y se inicializa un nuevo objeto AppConfig::Sys utilizando el método AppConfig::Sys->new(). Esto devuelve una referencia a un nuevo objeto AppConfig::Sys.

my $sys = AppConfig::Sys->new();

Esto intentará detectar tu sistema operativo y creará una referencia a un nuevo objeto AppConfig::Sys aplicable a tu plataforma. Puedes especificar explícitamente un nombre de sistema operativo para anular esta detección automática:

$unix_sys = AppConfig::Sys->new("Unix");

Alternativamente, la variable del paquete $AppConfig::Sys::OS puede configurarse con un nombre de sistema operativo. Los nombres de sistema operativo válidos son: Win32, VMS, Mac, OS2 y Unix. No distinguen mayúsculas de minúsculas.

MÉTODOS de AppConfig::Sys

AppConfig::Sys define los siguientes métodos:

getpwnam()
Llama a la función del sistema getpwnam() si está disponible y devuelve el resultado. Devuelve undef si no está disponible. Se puede llamar al método can_getpwnam() para determinar si esta función está disponible.
getpwuid()
Llama a la función del sistema getpwuid() si está disponible y devuelve el resultado. Devuelve undef si no está disponible. Se puede llamar al método can_getpwuid() para determinar si esta función está disponible.
