NOMBRE

apt-config - Programa de consulta de configuración de APT

SINOPSIS

apt-config [--empty] [--format '%f "%v";%n'] [-o=cadena_config] [-c=archivo_config] {shell | dump | {-v | --version} | {-h | --help}}

DESCRIPCIÓN

apt-config es un programa interno utilizado por varias partes de la suite APT para proporcionar una configuración consistente. Accede al archivo de configuración principal /etc/apt/apt.conf de una manera fácil de usar para aplicaciones con scripts.

A menos que se proporcione la opción -h o --help, se debe presentar uno de los siguientes comandos.

shell

shell se utiliza para acceder a la información de configuración desde un script de shell. Se le proporcionan pares de argumentos, el primero es una variable de shell y el segundo es el valor de configuración a consultar. Como salida, lista comandos de asignación de shell para cada valor presente. En un script de shell, debe usarse de la siguiente manera: 
OPTS="-f"
RES=`apt-config shell OPTS MyApp::options`
eval $RES
Esto establecerá la variable de entorno del shell $OPTS con el valor de MyApp::options con un valor predeterminado de -f.

El elemento de configuración puede ir seguido de /[fdbi]. f devuelve nombres de archivo, d directorios, b valores verdaderos o falsos e i un entero. Cada uno de los retornos se normaliza y verifica internamente.

dump

Simplemente muestra el contenido del espacio de configuración.

OPCIONES

Todas las opciones de la línea de comandos se pueden establecer usando el archivo de configuración; las descripciones indican la opción de configuración a establecer. Para opciones booleanas, puede anular el archivo de configuración usando algo como -f-, --no-f, -f=no o varias otras variaciones.

--empty

Incluye opciones que tienen un valor vacío. Este es el valor predeterminado, por lo que use --no-empty para eliminarlas de la salida.

--format '%f "%v";%n'

Define la salida de cada opción de configuración. %t se reemplazará con su nombre individual, %f con su nombre jerárquico completo y %v con su valor. Use letras mayúsculas y caracteres especiales en el valor se codificarán para garantizar que pueda usarse, por ejemplo, de forma segura en una cadena entre comillas según lo define RFC822. Adicionalmente, %n será reemplazado por una nueva línea y %N por una tabulación. Se puede imprimir un % usando %%.

-h, --help

Muestra un resumen de uso corto.

-v, --version

Muestra la versión del programa.

--audit

Muestra mensajes de auditoría (y aviso). Esto anula la opción silenciosa, pero solo para los mensajes de aviso, no para los de progreso.

-c, --config-file

Archivo de Configuración; Especifica un archivo de configuración a utilizar. El programa leerá el archivo de configuración predeterminado y luego este archivo de configuración. Si se deben establecer configuraciones antes de que se analicen los archivos de configuración predeterminados, especifique un archivo con la variable de entorno APT_CONFIG. Consulte apt.conf(5) para obtener información sobre la sintaxis.

-o, --option

Establecer una Opción de Configuración; Esto establecerá una opción de configuración arbitraria. La sintaxis es -o Foo::Bar=bar. Se pueden usar -o y --option varias veces para establecer diferentes opciones.

--cli-version

Solicita una versión específica de CLI. Este es un patrón que toma una versión MAYOR.MENOR. Puede omitir la versión MENOR, en cuyo caso se utilizará el nivel menor más reciente compatible.

Los rastros de versión se presentan de la siguiente manera: La versión 3.2 tiene versiones equivalentes 0.32, 1.22 y 2.12, implementando nuevas características para sus versiones principales especificadas.

Un caso especial es el patrón de versión X.9: una versión como 2.9 va seguida de 3.0, pero 2.10 sigue directamente a 2.8; dado que usamos números de versión impares como series de desarrollo (2.9 es la serie de desarrollo 3.0).

Esta característica se introdujo en APT 3.1.10 y reemplaza la configuración específica de la binaria. Puede usar APT::Version para un efecto similar en binarios más antiguos, por ejemplo, use -o APT::Version=2 para que apt(8) se comporte como la serie 2.x.

El valor predeterminado es la versión actual de APT para apt(8) y 0.(10 * mayor + menor) para los comandos clásicos. La serie 0.X está suavemente obsoleta y los otros comandos pasarán a la serie 2.x en el futuro.

--no-color, --color

Activa o desactiva los colores. Los colores están activados por defecto en terminales compatibles para apt(8) y también se pueden desactivar usando las variables de entorno NO_COLOR o APT_NO_COLOR, o configurarse adicionalmente mediante la opción de configuración APT::Color y su alcance, consulte apt.conf(5) para obtener información al respecto.

apt.conf(5)

DIAGNÓSTICOS

apt-config devuelve cero en operación normal, 100 decimal en caso de error.

    apt-config(8)

    APT CONFIGURATION FILE PARSING UTILITY

    Name

    apt-config — APT configuration file parsing utility

    Synopsis

    apt-config [-f] [-p] [-s system-config] [-h home-config] [-t target-dir] [file ...]

    Description

    apt-config is a command-line tool that can be used to parse APT configuration files. It can be used to retrieve configuration options, their values, and their origins. This is useful for debugging APT configuration issues and for integrating APT configuration into other tools.

    The tool reads configuration files from a specified system-wide configuration directory and a user-specific configuration directory. By default, it uses /etc/apt/apt.conf and ~/.apt/apt.conf.

    The following options are available:

    -f
    Force parsing of configuration files, even if they are not readable.
    -p
    Print the configuration options in a machine-readable format.
    -s system-config
    Specify a system-wide configuration directory to use instead of the default.
    -h home-config
    Specify a user-specific configuration directory to use instead of the default.
    -t target-dir
    Specify a target directory to use for configuration files. This is useful for chroot environments.

    If no file arguments are given, apt-config will parse all configuration files in the specified directories.

    When parsing configuration files, apt-config will output the configuration options and their values. The output format depends on the options used. By default, it outputs a human-readable list of options and their values. With the -p option, it outputs a machine-readable list of options and their values.

    Examples

    To parse all configuration files in the default directories and print the options in a human-readable format:

    apt-config

    To parse a specific configuration file and print the options in a machine-readable format:

    apt-config -p /etc/apt/apt.conf.d/99-custom

    To parse configuration files in a chroot environment:

    apt-config -t /chroot/target -s /chroot/target/etc/apt -h /chroot/target/.apt

    apt.conf(5)
