NOMBRE

apparmor.vim - archivo de resaltado de sintaxis de vim para perfiles de AppArmor

SINOPSIS

Su sistema puede estar configurado para usar automáticamente el resaltado de sintaxis para las políticas de AppArmor instaladas. Si no es así, puede habilitar el resaltado de sintaxis en una sesión de vim específica realizando:

:set syntax=apparmor

DESCRIPCIÓN

apparmor.vim proporciona reglas de resaltado de sintaxis para el editor de texto vim(1); las reglas proporcionan un método visual fácil para inspeccionar los perfiles de AppArmor en busca de corrección de sintaxis y semántica.

Los colores indican la gravedad relativa de otorgar un conjunto específico de privilegios. Clasificar el acceso con colores es necesariamente genérico y vago, pero puede ayudarlo a comprender mejor sus perfiles.

ERRORES

apparmor.vim no detecta correctamente fondos oscuros o claros. Se aceptan parches. Si encuentra algún error, repórtelo en https://gitlab.com/apparmor/apparmor/-/issues.

VER TAMBIÉN

vim(1), apparmor(7), apparmor.d(5), aa_change_hat(2) y https://wiki.apparmor.net.
