NOMBRE

AppConfig::Getopt - Módulo de Perl5 para procesar argumentos de línea de comandos mediante delegación a Getopt::Long.

SINOPSIS

use AppConfig::Getopt;
my $state  = AppConfig::State->new(\%cfg);
my $getopt = AppConfig::Getopt->new($state);
$getopt->parse(\@args);            # leer argumentos

DESCRIPCIÓN GENERAL

AppConfig::Getopt es un módulo de Perl5 que delega al módulo Getopt::Long de Johan Vroman para analizar argumentos de línea de comandos y actualizar los valores en un objeto AppConfig::State en consecuencia.

AppConfig::Getopt se distribuye como parte del paquete AppConfig.

DESCRIPCIÓN

USANDO EL MÓDULO AppConfig::Getopt

Para importar y usar el módulo AppConfig::Getopt, la siguiente línea debe aparecer en su script Perl:

use AppConfig::Getopt;

AppConfig::Getopt se usa automáticamente si usa el módulo AppConfig y crea un objeto AppConfig::Getopt a través del método getopt().

AppConfig::Getopt se implementa utilizando métodos orientados a objetos. Se crea y se inicializa un nuevo objeto AppConfig::Getopt utilizando el método new(). Este devuelve una referencia a un nuevo objeto AppConfig::Getopt. Se debe pasar una referencia a un objeto AppConfig::State como primer parámetro:

my $state  = AppConfig::State->new();
my $getopt = AppConfig::Getopt->new($state);

Esto creará y devolverá una referencia a un nuevo objeto AppConfig::Getopt.

ANÁLISIS DE ARGUMENTOS DE LÍNEA DE COMANDOS

El método parse() se utiliza para leer una lista de argumentos de línea de comandos y actualizar el estado en consecuencia.

Los primeros parámetros (de referencia no de lista) pueden contener una serie de cadenas de configuración para pasar a Getopt::Long::Configure. Adicionalmente se puede pasar una referencia a una lista de argumentos o se usa @ARGV por defecto.

$getopt->parse();                       # usa @ARGV
$getopt->parse(\@myargs);
$getopt->parse(qw(auto_abbrev debug));  # usa @ARGV
$getopt->parse(qw(debug), \@myargs);

Consulte Getopt::Long para obtener detalles sobre las opciones de configuración disponibles.

Se construye una cadena de especificación Getopt::Long para cada variable definida en AppConfig::State. Esto consiste en el nombre, cualquier alias y el valor ARGS para la variable.

Estas cadenas de especificación se pasan luego a Getopt::Long, se analizan los argumentos y se actualizan los valores en AppConfig::State.

Consulte AppConfig para obtener información sobre el uso del módulo AppConfig::Getopt a través del método getopt().
