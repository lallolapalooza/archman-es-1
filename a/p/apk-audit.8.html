apk-audit(8) Manual del Administrador del Sistema apk-audit(8)

NOMBRE

apk audit - auditar directorios en busca de cambios

SINOPSIS

apk audit [<opciones>...] directorios...

DESCRIPCIÓN

apk audit audita el sistema o los directorios especificados en busca de cambios en comparación con la base de datos de paquetes.

La auditoría puede realizarse solo sobre archivos de configuración (--backup) para generar una lista de archivos que necesitan ser almacenados en la superposición en la configuración de ejecución desde temporales. Alternativamente, puede auditar todos los archivos instalados (--system o --full) para, por ejemplo, detectar modificaciones no autorizadas de archivos del sistema.

Por defecto, el formato de salida es una línea por archivo, para cada archivo modificado. Se imprime un carácter que indica el tipo de línea, seguido de un espacio, luego la ruta afectada o detalles. Los cambios detectados son:

- Registro de detalle de la base de datos
+ Registro de detalle en disco
A Archivo añadido
d Directorio añadido
D Directorio añadido (con archivos/subdirectorios no listados)
e se produjo un error durante la auditoría (p. ej., no hay permisos para leer el archivo)
M Metadatos del archivo modificados (uid, gid o modo)
m Metadatos del directorio modificados
U Contenido del archivo modificado
X Archivo eliminado
x xattrs modificados

OPCIONES

--backup

Auditar solo archivos de configuración (por defecto). La lista de archivos a auditar se genera a partir de las máscaras en protected_paths.d.

--check-permissions

Verificar también los permisos de archivo. Específicamente, se verificará el uid, gid y el modo del archivo además del contenido del archivo.

--details

Habilitar el reporte de registros de detalle.

--full

Igual que --system, pero además reporta todos los directorios y archivos añadidos. Se utiliza una anulación de omisión predeterminada para las rutas protegidas, a menos que se especifique explícitamente --protected-paths.

--ignore-busybox-symlinks

Ignorar enlaces simbólicos cuyo destino sea el binario busybox.

--packages

Imprimir solo los paquetes con archivos modificados. En lugar de la salida completa de cada modificación, se imprime el conjunto de paquetes con al menos un archivo modificado.

Para reparar todos los paquetes con archivos modificados, se podría usar:

apk audit --packages -q | xargs apk fix

--protected-paths ARCHIVO

Usar el ARCHIVO dado para las listas de rutas protegidas. Esto también hace que apk ignore los directorios regulares de protected_paths.d.

--recursive, -r

Descender en los directorios y auditarlos también.

--system

Auditar todos los archivos del sistema. Se verifica la integridad de todos los archivos proporcionados por los paquetes, con la excepción de los archivos de configuración (listados en protected_paths.d). Esto es útil para detectar modificaciones no autorizadas de archivos. Los archivos o directorios nuevos no se reportan.
