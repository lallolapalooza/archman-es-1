NOMBRE

appstreamcli - Maneja los formatos de metadatos de AppStream y consulta datos de AppStream

SINOPSIS

appstreamcli [COMANDO]

DESCRIPCIÓN

Esta página de manual documenta brevemente el comando appstreamcli .

appstreamcli es una pequeña herramienta auxiliar para trabajar con los metadatos de AppStream y acceder al índice de componentes de AppStream desde la línea de comandos. El índice de componentes de AppStream contiene una lista de todos los componentes de software disponibles para tu distribución, asociados a sus nombres de paquete. Se genera utilizando datos XML de AppStream o DEP-11 de Debian, proporcionados por tu distribuidor.

Para obtener más información sobre el proyecto AppStream y los demás componentes que forman parte de él, consulta las páginas de AppStream en Freedesktop.org[1].

OPCIONES

get ID

Obtiene un componente del conjunto de metadatos por su identificador.

s, search TÉRMINO

Busca un término de búsqueda dado en el conjunto de componentes de AppStream.

what-provides TIPO TÉRMINO

Devuelve los componentes que proporcionan un elemento dado. El tipo de elemento se puede especificar usando el parámetro TIPO , y el valor a buscar debe proporcionarse usando el parámetro TÉRMINO .

Ejemplos:

Obtener los componentes que manejan el tipo de medio "text/xml".

appstreamcli what-provides mediatype "text/xml"

Obtener el componente que proporciona la biblioteca "libfoo.so.2".

appstreamcli what-provides lib libfoo.so.2

refresh, refresh-cache

Activa una actualización de la base de datos, si es necesario. En caso de que quieras forzar la reconstrucción de la base de datos, proporciona la opción --force .

Este comando debe ejecutarse con permisos de root.

status

Muestra información diversa sobre los metadatos instalados y la caché de metadatos.

os-info

Muestra información sobre el sistema operativo actual a partir del índice de metadatos. Esto requiere que el sistema operativo proporcione un componente de tipo operating-system para sí mismo.

dump ID

Vuelca las descripciones XML completas de los componentes con el ID dado que se encontraron en el conjunto de metadatos.

validate ARCHIVOS

Valida los metadatos XML de AppStream en cuanto a su cumplimiento con la especificación.

Se manejan ambos tipos de metadatos XML, el XML upstream y el XML de la distribución. El tipo de formato que debe validarse se determina automáticamente.

La opción --pedantic activa una validación más exhaustiva del archivo, incluyendo problemas menores y de estilo en el informe.

validate-tree DIRECTORIO

Valida los metadatos XML de AppStream encontrados en un árbol de archivos.

Esto realiza una validación estándar de todos los metadatos encontrados, pero también comprueba errores adicionales, como la presencia de archivos .desktop y la validez de otros metadatos adicionales.

check-license LICENCIA

Prueba la validez de una cadena de licencia o expresión de licencia y muestra detalles sobre ella.

Esto comprobará si la cadena de licencia se considera válida para AppStream, y devolverá un código de salida distinto de cero si no lo es. El comando también mostrará información útil como el ID canónico de una licencia, si es adecuada como licencia para los metadatos de AppStream, y si la licencia se considera de software libre y de código abierto o de software propietario.

AppStream considerará como libre y de código abierto cualquier licencia que esté marcada como adecuada por la Free Software Foundation (FSF), la Open Source Initiative (OSI) o la lista de licencias explícita de las Directrices de Software Libre de Debian (DFSG).

install ID

Instala un componente de software por su ID usando el gestor de paquetes o Flatpak.

Esto resuelve el ID del componente de AppStream a un candidato de instalación y luego llama al gestor de paquetes nativo o a Flatpak (si está disponible) para instalar el componente.

remove ID

Desinstala un componente de software por su ID usando el gestor de paquetes o Flatpak.

Esto desinstalará el software que coincida con el ID seleccionado usando el gestor de paquetes nativo o Flatpak (si está disponible).

put ARCHIVO

Instala un archivo de metadatos en el directorio adecuado en la máquina actual.

compare-versions, vercmp VER1 [CMP] VER2

Compara dos números de versión. Si se proporcionan dos números de versión como parámetros, se compararán las versiones y el resultado de la comparación se imprimirá en la salida estándar.

Si se pasan como parámetros un número de versión, un operador de comparación y otro número de versión, el resultado de la operación de comparación se imprimirá en la salida estándar, y appstreamcli saldrá con un estado de salida distinto de cero en caso de que la comparación falle. El operador de comparación puede ser uno de los siguientes:

•eq - Igual a
•ne - Distinto de
•lt - Menor que
•gt - Mayor que
•le - Menor o igual que
•ge - Mayor o igual que

new-template TIPO ARCHIVO

Crea una plantilla de archivo metainfo para que la usen los proyectos de software. La opción --from-desktop se puede usar para utilizar un archivo .desktop como plantilla para generar el archivo de ejemplo.

Los archivos generados contienen entradas de ejemplo que deben ser rellenadas con los valores deseados reales por el autor del proyecto.

El primer TIPO parámetro es el nombre de un tipo de componente de AppStream. Para una lista completa, consulta la documentación[2] o la salida de ayuda de appstreamcli para este subcomando.

make-desktop-file ARCHIVO_MI ARCHIVO_DESKTOP

Crea un archivo de entrada de escritorio XDG a partir de un archivo metainfo. Si el archivo de entrada de escritorio especificado en ARCHIVO_DESKTOP ya existe, se ampliará con la nueva información extraída del archivo metainfo. De lo contrario, se creará un archivo nuevo.

Este comando usará el primer binario mencionado en una etiqueta provides del componente para el campo Exec= del nuevo archivo de entrada de escritorio. Si este no es el comportamiento deseado, se puede usar la opción --exec para definir explícitamente un binario a lanzar. Otros métodos para lanzar la aplicación no están soportados actualmente.

Para generar una entrada de escritorio adecuada, este comando asume que no solo están establecidas las etiquetas mínimamente requeridas para un componente de AppStream, sino que también tiene una etiqueta <icon/> de tipo "stock" para describir el icono predefinido que debe usarse, así como una etiqueta <categories/> que contiene las categorías en las que debe colocarse la aplicación.

news-to-metainfo ARCHIVO_NEWS ARCHIVO_MI [ARCHIVO_SALIDA]

Este comando convierte un archivo NEWS, tal como lo usan muchos proyectos de código abierto, al XML usado por AppStream. Dado que los archivos NEWS son texto libre, se aplicarán muchas heurísticas para obtener resultados razonables. El convertidor también puede leer una versión YAML de la descripción de la versión de AppStream y convertirla a XML también. Si el archivo metainfo ARCHIVO_MI ya existe, se ampliará con las nuevas entradas de versión; de lo contrario, las entradas de versión se escribirán sin ningún componente contenedor. Si se especifica [ARCHIVO_SALIDA] , en lugar de actuar sobre ARCHIVO_MI , los datos modificados se escribirán en el archivo particular. Si alguno de los nombres de archivo de salida se establece en "-", la salida se escribirá en la salida estándar.

La opción --format se puede usar para forzar la lectura del archivo de entrada en un formato específico ("text" o "yaml") en caso de que la autodetección del formato falle. La opción --limit se usa para limitar la cantidad de entradas de versión escritas (las entradas más recientes siempre estarán primero).

NOMBRE

appstreamcli - Herramienta de línea de comandos para AppStream

SINOPSIS

appstreamcli [OPCIONES] COMANDO [ARGUMENTOS]...

DESCRIPCIÓN

La herramienta appstreamcli es una interfaz de línea de comandos para la gestión de metadatos de AppStream.

COMANDOS

Los siguientes comandos están disponibles:

validate [OPCIONES] ARCHIVOS...
Valida uno o más archivos de metadatos de AppStream. Los archivos pueden ser archivos XML o directorios que contienen archivos de metadatos. Si se especifica un archivo de entrada como "-", se leerá desde la entrada estándar. Si el archivo de salida (consulte --output-file) está configurado como "-", los datos resultantes se escribirán en stdout en lugar de en un archivo.
convert ARCHIVO1 ARCHIVO2
Convierte metadatos XML de AppStream a su representación YAML y viceversa.
compose
Compone un catálogo de metadatos de AppStream a partir de un árbol de directorios con archivos de metadatos. Este comando solo está disponible si el componente org.freedesktop.appstream.compose está instalado. Consulte appstreamcli-compose(1) para obtener más información.

OPCIONES

--details
Muestra más información sobre un componente encontrado.
--format FORMATO
Especifica explícitamente el formato de salida ("yaml" o "text"). Si no se establece, appstreamcli intentará adivinar el formato más adecuado.
--output-file ARCHIVO
Especifica el archivo donde se escribirán los resultados. Si se establece en "-", los datos resultantes se escribirán en stdout en lugar de en un archivo.
--no-color
No muestra salida coloreada.
--no-net
No accede a la red al validar metadatos.
--version
Muestra el número de versión de appstreamcli.

El mismo efecto que --no-net se puede lograr estableciendo la variable de entorno AS_VALIDATE_NONET antes de ejecutar appstreamcli.
