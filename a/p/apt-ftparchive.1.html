DESCRIPCIÓ

N

apt-ftparchive es la herramienta de línea de comandos que genera los archivos de índice que APT utiliza para acceder a una fuente de distribución. Los archivos de índice deben generarse en el sitio de origen basándose en el contenido de ese

sitio.

apt-ftparchive es un superconjunto del programa dpkg-scanpackages(1), incorporando toda su funcionalidad mediante el comando packages. También contiene un generador de archivos de contenidos, contents, y un medio elaborado para 'programar' el proceso de generación para un archivo

completo.

Internamente apt-ftparchive puede hacer uso de bases de datos binarias para almacenar en caché el contenido de un archivo .deb y no depende de ningún programa externo aparte de gzip(1). Al realizar una generación completa, realiza automáticamente comprobaciones de cambios de archivos y construye los archivos de salida comprimidos

deseados.

A menos que se -h, o --help, se indique la opción, debe estar presente uno de los siguientes

comandos.

package

s
El comando packages genera un archivo de paquetes a partir de un árbol de directorios. Toma el directorio dado y lo busca recursivamente en busca de archivos .deb, emitiendo un registro de paquete a stdout por cada uno. Este comando es aproximadamente equivalente a dpkg-scanpackages(1).

La opción --db se puede utilizar para especifica

r una base de datos
binaria de caché.

source

s
El comando sources genera un archivo de índice de fuentes a partir de un árbol de directorios. Toma el directorio dado y lo busca recursivamente en busca de archivos .dsc, emitiendo un registro de fuente a stdout por cada uno. Este comando es aproximadamente equivalente a dpkg-scansources(1).

Si se especifica un archivo de anulación, se buscará un archivo de anulació

n de fuentes con una extensión de .src. La opción --source-override se puede
utilizar para cambiar el archivo de anulación de fuentes que se utilizará.

content

s
El comando contents genera un archivo de contenidos a partir de un árbol de directorios. Toma el directorio dado y lo busca recursivamente en busca de archivos .deb, y lee la lista de archivos de cada archivo. Luego ordena y escribe en stdout la lista de archivos asociados a los paquetes. Los directorios no se escriben en la salida. Si varios paquetes poseen el mismo archivo, cada paquete se separa por una coma en la salida.

La opción --db se puede utilizar para especifica

r una base de datos
binaria de caché.

releas

e
El comando release genera un archivo Release a partir de un árbol de directorios. Busca recursivamente en el directorio dado archivos Packages, Sources, Contents, Components e iconos sin comprimir y comprimidos, así como archivos Release, Index y md5sum.txt por defecto (APT::FTPArchive::Release::Default-Patterns). Se pueden agregar patrones de nombre de archivo adicionales listándolos en APT::FTPArchive::Release::Patterns. Luego escribe en stdout un archivo Release que contiene (por defecto) un resumen MD5, SHA1, SHA256 y SHA512 para cada archivo.

Los valores para los campos de metadatos adicionales en el archivo Release se toman de las variables correspondientes bajo APT::FTP

Archive::Release, por ejemplo APT::FTPArchive::Release::Origin. Los campos soportados son Origin, Label, Suite, Version, Codena
me, Date, NotAutomatic, ButAutomaticUpgrades, Acquire-By-Hash, Valid-Until, Signed-By, Architectures, Components y Description.

generat

e
El comando generate está diseñado para ser ejecutable desde un script cron y construye índices de acuerdo con el archivo de configuración dado. El lenguaje de configuración proporciona un medio flexible para especificar qué archivos de índice se construyen a partir de qué directorios, así como proporcionar un medio sencillo para mantener la configuración
requerida.

NAME

apt-ftparchive - APT's ftp archive generation tool

SYNOPSIS

apt-ftparchive [-h|--help] [-v|--version] [--audit] [-c|--config-file file] [-o|--option string] [--cli-version version] [--no-color|--color] [command] [args ...]

DESCRIPTION

apt-ftparchive is a utility for generating package index files for Debian archives. It can generate the Packages, Sources, Contents, and Release files. The default command is generate, which can be used to generate all of these files.

In addition to the standard generation of Release, Packages, Sources and Contents files, apt-ftparchive can also generate the Release file for a set of files using the release command.

The typical use of apt-ftparchive is to generate the index files for a distribution mirror or for a local package cache.

THE GENERATE CONFIGURATION

The generate command requires a configuration file that details the structure of the archive to be generated. The file is divided into sections, each corresponding to a subtree of the archive. Each section must be indexed by the directory path relative to the root of the archive, and contains a list of package stanzas.

The stanzas can be generated automatically by apt-ftparchive(1) using the packages, sources, and contents subcommands.

A stanza must contain a Packages, Sources, or Contents index file.

The generation process is controlled by the configuration file. The APT::FTPArchive::Generate section contains options that control the overall generation process, such as the distribution name, components, and architectures.

Example configuration file for a simple archive:

APT::FTPArchive::Generate::Distributions {
  "stable";
};
APT::FTPArchive::Generate::Components {
  "main";
  "contrib";
  "non-free";
};
APT::FTPArchive::Generate::Architectures {
  "i386";
  "amd64";
};

Dir {
  "dists/stable/main/binary-i386";
  "dists/stable/contrib/binary-i386";
  "dists/stable/non-free/binary-i386";
};

Bin {
  "dists/stable/main/binary-i386";
  "dists/stable/contrib/binary-i386";
  "dists/stable/non-free/binary-i386";
};

Src {
  "dists/stable/main/source";
  "dists/stable/contrib/source";
  "dists/stable/non-free/source";
};

Contents {
  "dists/stable/main/binary-i386";
  "dists/stable/contrib/binary-i386";
  "dists/stable/non-free/binary-i386";
};

THE BINARY OVERRIDE FILE

This file is used to override fields in the Packages index file. It is a list of package stanzas, where each stanza contains fields to be overridden. The syntax is similar to that of the Packages file itself.

Example override file:

Package: apt
Architecture: amd64
Description: Example override description

THE SOURCE OVERRIDE FILE

This file is used to override fields in the Sources index file. It is a list of source package stanzas, where each stanza contains fields to be overridden. The syntax is similar to that of the Sources file itself.

THE EXTRA OVERRIDE FILE

This file is used to add extra fields to package stanzas. The syntax is similar to that of the Packages file itself.

This option is useful for adding fields such as MD5Sum, SHA1, SHA256, Size, Filename, etc., to the Packages file, when these fields are not generated by default. For example, to add the MD5Sum field to all packages:

APT::FTPArchive::ExtraOverride "/path/to/extra-override.override"

And the content of /path/to/extra-override.override would be:

Package: *
MD5Sum: <md5sum>

This option is set to "false" by default. If it is enabled and the same file is recompiled and/or republished with the same version again, this will lead to problems as the now outdated cached metadata like size and checksums will be used. With this option enabled this will no longer happen as it will be checked if the file was changed. Note that this option is set to "false" by default as it is not recommend to upload multiple versions/builds of a package with the same version number, so in theory nobody will have these problems and therefore all these extra checks are useless.
