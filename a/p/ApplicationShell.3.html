DESCRIPCIÓ

N

ApplicationShell se utiliza como la ventana principal de nivel superior de una aplicación. Una aplicación solo debe tener más de un ApplicationShell si implementa múltiples aplicaciones

lógicas.

Clase

s

ApplicationShell hereda comportamiento y recursos de Core, Composite, Shell, WMShell, VendorShell, y TopLevelShell

.

Nuevos

recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos de las clases heredadas para establecer atributos para este widget. Para referirse a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya cualquier guion bajo entre palabras). Los códigos en la columna de acceso indican si el recurso dado puede establecerse en el momento de la creación (C), establecerse usando XtSetValues (S), recuperarse usando XtGetValues (G), o no es aplicable (N/A)
