NOMBRE

apptainer-cache-clean - Limpia la caché local de Apptainer

SINOPSIS

apptainer cache clean [opciones de limpieza...]

DESCRIPCIÓN

Esto limpiará tu caché local (almacenada en $HOME/.apptainer/cache si
APPTAINER_CACHEDIR no está configurada). Por defecto, se limpia toda la caché; utiliza
las opciones --days y --type para anular este comportamiento. Nota: si utilizas Apptainer
como root, la caché se almacenará en '/root/.apptainer/.cache'; para limpiar esa
caché, necesitarás ejecutar 'cache clean' como root o con 'sudo'.

OPCIONES

-D, --days=0 elimina todas las entradas de caché anteriores al número especificado de días

-n, --dry-run[=false] opera en modo de simulación y no limpia realmente la caché

-f, --force[=false] suprime cualquier aviso y limpia la caché

-h, --help[=false] ayuda para clean

-T, --type=[all] una lista de tipos de caché para limpiar (valores posibles: library, oci, shub, blob, net, oras, all)

EJEMPLO

  Todos los comandos de grupo tienen su propia salida de ayuda:
  $ apptainer help cache clean --days 30
  $ apptainer help cache clean --type=library,oci
  $ apptainer cache clean --help
