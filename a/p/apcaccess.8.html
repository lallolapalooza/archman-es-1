APCACCESS(8) Manual del Administrador del Sistema APCACCESS(8)

NOMBRE

apcaccess — recuperar información de estado de apcupsd(8)

SINOPSIS

apcaccess [-f <archivo-configuración>] [-h <host>[:<puerto>]] [-p <nombre-parámetro>] [-u] [<comando>] [<host>[:<puerto>]]

DESCRIPCIÓN

apcaccess es un programa que imprime el estado completo de la mayoría de los SAI (Sistema de Alimentación Ininterrumpida) de American Power Conversion Corp. (APC), siempre que tenga el demonio apcupsd(8) instalado, configurado correctamente y en ejecución. Puede acceder a la información de estado de cualquier SAI APC conectado a la máquina local o conectado a cualquier computadora en la red que esté ejecutando apcuspd en modo NIS.

Las opciones de línea de comandos son:

-f
archivo de configuración de apcupsd (el valor predeterminado suele ser /etc/apcupsd/apcupsd.conf)
-h
nombre de host y puerto de apcupsd con el que comunicarse. El nombre de host y el puerto predeterminados se obtienen del archivo de configuración.
-p
Informar solo el valor del parámetro nombrado en lugar de todos los parámetros y valores.
-u
Eliminar el campo de unidades para facilitar el análisis por scripts.
<comando>
Un comando opcional, a menos que también se esté especificando un nombre de host. El único comando implementado es status. Abreviatura de status localhost:3551. Esto produce una impresión completa de la información de estado disponible para el SAI asociado.
<host>
Un nombre de host opcional que puede ser un nombre de máquina simple, un nombre de dominio completamente calificado o una dirección IP.
:<puerto>
Un número de puerto opcional donde se ha especificado un argumento de nombre de host. El valor predeterminado es 3551, el número de puerto oficial asignado por IANA para el servidor NIS de apcupsd. El nombre de host y el puerto predeterminados se obtienen del archivo de configuración.

apcaccess utiliza el servidor de información de red (NIS) incorporado de apcupsd (sin relación con el servicio NIS/YP de Sun) para obtener la información de estado actual del SAI en la computadora local o remota. Por lo tanto, es necesario tener las siguientes directivas de configuración:


  • NETSERVER on

  • NISPORT 3551

en el archivo de configuración /etc/apcupsd/apcupsd.conf para que el Servidor de Información de Red sea accesible. También pueden ser necesarias reglas de firewall para el acceso de red apropiado.

FORMATO DEL INFORME DE ESTADO

El formato de salida del informe de estado es ASCII simple. Generalmente hay una sola pieza de información en cada línea de salida. El contenido varía según el modelo de SAI utilizado y, en algunos casos, la versión del firmware.

NOMBRE

apcaccess — información de estado de UPS APC

SINOPSIS

apcaccess [-dhs] [-t timeout] [-u user] [-p password] [-F filename] [-H host] [keyword ...]

DESCRIPCIÓN

apcaccess es una utilidad de línea de comandos que obtiene información de estado de un UPS APC y la muestra en formato de texto legible por humanos. Puede obtener información de un UPS en la máquina local o de un UPS remoto que esté siendo controlado por un servidor apcupsd.

Si no se especifican argumentos, apcaccess imprime una lista de todos los campos de estado disponibles y sus valores actuales.

Los siguientes argumentos opcionales están disponibles:

-d
Imprime la información de estado en formato de depuración.
-h
Imprime un mensaje de ayuda.
-s
Imprime solo los valores de los campos solicitados.
-t timeout
Establece un tiempo de espera en segundos para la comunicación con el servidor apcupsd.
-u user
Especifica el nombre de usuario para la autenticación con el servidor apcupsd.
-p password
Especifica la contraseña para la autenticación con el servidor apcupsd.
-F filename
Lee la información de estado de un archivo en lugar de comunicarse con un servidor apcupsd.
-H host
Especifica el nombre de host o la dirección IP del servidor apcupsd con el que comunicarse.

Si se proporcionan uno o más keywords, apcaccess solo imprimirá los valores de esos campos específicos.

EJEMPLOS

Para obtener el porcentaje de carga de la batería y el tiempo restante:

  $ apcaccess BCHARGE TIMELEFT

Para obtener el voltaje de salida y la frecuencia de línea desde un servidor remoto:

  $ apcaccess -H UPS_SERVER OUTPUTV LINEFREQ
