DESCRIPCIÓ

N

Cada página de manual tiene disponible una descripción breve. apropos busca en las descripciones instancias de palabra_clav

e.

palabra_clave es normalmente una expresión regular, como si se usara (-r), o puede contener comodines (-w), o coincidir exactamente con la palabra clave (-e). Al usar estas opciones, puede ser necesario entrecomillar la palabra_clave o escapar (\) los caracteres especiales para evitar que el shell los

interprete.

Las reglas estándar de coincidencia permiten hacer coincidencias con el nombre de la página y los límites de palabra en la

descripción.

La base de datos que apropos busca es actualizada por el programa mandb. Dependiendo de su instalación, esto puede ejecutarse mediante un trabajo periódico de cr

on, o puede necesitar ejecutarse manualmente después d
e que se hayan instalado nuevas páginas de manual.

Interpretar cada palabra clave como una expresión regular. Este es el comportamiento predeterminado. Cada palabra clave se comparará independientemente con los nombres de página y las descripciones. Puede coincidir con cualquier parte de cualquiera de los dos. La coincidencia no está limitada a los límites de

Interpretar cada palabra clave como un patrón que contiene comodines de estilo shell. Cada palabra clave se comparará independientemente con los nombres de página y las descripciones. Si --exact también se usa, solo se encontrará una coincidencia si una palabra clave expandida coincide con una descripción o nombre de página completo. De lo contrario, la palabra clave también puede coincidir con los límites de palabra en la
descripción.

Mostrar solo los elementos que coinciden con todas las palabras clave proporcionadas. El valor predeterminado es mostrar elementos que coinciden con cualquier palabra

-l, --lo

No recortar la salida al ancho de la terminal. Normalmente, la salida será truncada al ancho de la terminal para evitar resultados desagradables por secciones NOMBRE mal
escritas.
-s lista, --sections=lista, --section=lis
ta
Buscar solo en las secciones de manual dadas. lista es una lista de secciones separadas por dos puntos o comas. Si una entrada en lista es una sección simple, por ejemplo "3", entonces la lista mostrada de descripciones incluirá páginas en las secciones "3", "3perl", "3x", y así sucesivamente; mientras que si una entrada en lista tiene una extensión, por ejemplo "3perl", entonces la lista solo incluirá páginas en esa parte exacta de la sección del
manual.
-m sistema[,...], --systems=sistema[,.
..]
Si este sistema tiene acceso a las descripciones de páginas de manual de otros sistemas operativos, pueden buscarse usando esta opción. Para buscar las descripciones de páginas de manual de NewOS, use la opción -m NewOS.

El sistema especificado puede ser una combinación de nombres de sistemas operativos delimitados por comas. Para incluir una búsqueda de las descripciones whatis del sistema operativo nativo, incluya el nombre del sistema man en la cadena de argumentos. Esta opción anulará la variable de entorno $ SYSTEM.-

La salida, como el mensaje de ayuda, siempre se mostrará en la configuración regional inicialmente determinada. -
