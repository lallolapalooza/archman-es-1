App::ClusterSSH::L10N(3pm) Documentación de Perl aportada por el usuario App::ClusterSSH::L10N(3pm)

SINOPSIS

use ClusterSSH::L10N;
my $lang = ClusterSSH::L10N->get_handle('en');
$lang->maketext('texto a localizar con argumentos [_1]', $arg1);

DESCRIPCIÓN

Módulo de traducción basado en Locale::Maketext para ClusterSSH. Ver Locale::Maketext para más información y uso.

NOTA: el idioma predeterminado de este módulo es el inglés.
