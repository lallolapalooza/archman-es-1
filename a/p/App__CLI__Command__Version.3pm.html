App::CLI::Command::Version(3) Documentación de Contribución de Perl App::CLI::Command::Version(3)

NOMBRE

App::CLI::Command::Version - Imprime una cadena de versión preformateada

SINOPSIS

package MyApp;
use base qw(App::CLI App::CLI::Command);
use constant alias => (
    '--version' => '+App::CLI::Command::Version',
      'version' => '+App::CLI::Command::Version',
    # Otras alias
);
# Tu app ahora soporta un comando y opción de versión por defecto

DESCRIPCIÓN

Este paquete proporciona un comando "version" por defecto modelado a partir del de App::Cmd. Puedes modificar el mensaje por defecto subclaseando este comando y sobrescribiendo su método "run", o modificándolo con, por ejemplo, Class::Method::Modifiers.
