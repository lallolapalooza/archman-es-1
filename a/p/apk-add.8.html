apk-add(8) Manual del Administrador del Sistema apk-add(8)

NOMBRE

apk add - añadir o actualizar restricciones a world y confirmar cambios

SINOPSIS

apk add [<opciones>...] restricciones...

DESCRIPCIÓN

apk add añade o actualiza las restricciones dadas a world (ver apk-world(5)) y confirma los cambios en disco. Esto normalmente implica instalar nuevos paquetes, pero también puede causar otros cambios en los paquetes instalados.

Para actualizar paquetes individuales sin modificar world, usa apk-fix(8).

Por defecto, apk intenta seleccionar un conjunto de paquetes tal que todas las restricciones sean satisfechas. Esto significa que algunos paquetes pueden ser retenidos en una versión anterior si hay dependencias directas o implícitas a la versión anterior.

OPCIONES

apk add soporta las opciones de confirmación descritas en apk(8), así como las siguientes opciones:

--initdb

Inicializa una nueva base de datos de paquetes.

--latest, -l

Siempre elige el paquete más reciente por versión. Sin embargo, las versiones consideradas se basan en el anclaje de paquetes. Principalmente, esto anula la heurística por defecto y provocará un error si no se pueden satisfacer todas las dependencias.

--no-chown

Alias obsoleto para --usermode.

--upgrade, -u

Actualiza paquetes y sus dependencias. Normalmente apk add evitará cambiar los paquetes instalados a menos que sean requeridos por los paquetes recién añadidos o sus dependencias. Esto cambia la preferencia por defecto de actualizar el paquete a la última versión instalable.

--usermode

Crea una base de datos de modo de usuario con --initdb. En modo de usuario, apk operará de tal manera que no se requiera acceso root. Actualmente, esto implica:
  • comprobar que se está ejecutando como no root
  • no cambiar el propietario o grupo del archivo
  • no establecer xattrs del sistema

Esto implica que la instalación podría no ser completamente funcional. Sin embargo, este es un modo útil para propósitos de prueba o para crear un chroot donde algunas aplicaciones específicas puedan ejecutarse como no root.

--virtual, -t NOMBRE

Crea un paquete virtual NOMBRE con las dependencias dadas. Este nuevo paquete obtendrá los paquetes como dependencias en lugar de world. Finalmente, NOMBRE se añade a world. Se puede dar un especificador de versión opcional para el paquete virtual a través de la sintaxis NOMBRE=VERSIÓN. La versión por defecto es una versión sintetizada basada en el tiempo.

Uno puede usar esto para asegurarse de que un conjunto seleccionado de paquetes está instalado, y más tarde la modificación temporal se puede deshacer con apk-del(8) NOMBRE sin eliminar paquetes que fueron instalados previamente.
