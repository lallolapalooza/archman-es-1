apply(n) Comandos integrados de Tcl apply(n)

NOMBRE

apply - Aplicar una función anónima

SINOPSIS

apply func ?arg1 arg2 ...?

DESCRIPCIÓN

El comando apply aplica la función func a los argumentos arg1 arg2 ... y devuelve el resultado.

La función func es una lista de dos elementos {args body} o una lista de tres elementos {args body namespace} (como si se hubiera utilizado el comando list). El primer elemento args especifica los argumentos formales de func. La especificación de los argumentos formales args se comparte con el comando proc, y se describe en detalle en la página del manual correspondiente.

El contenido de body es ejecutado por el intérprete Tcl después de que a las variables locales correspondientes a los argumentos formales se les asignan los valores de los parámetros reales arg1 arg2 .... Cuando se ejecuta body, los nombres de las variables normalmente se refieren a variables locales, que se crean automáticamente al ser referenciadas y se eliminan cuando apply retorna. Se crea automáticamente una variable local para cada uno de los argumentos de la función. Las variables globales solo se pueden acceder invocando al comando global o al comando upvar. Las variables de espacio de nombres solo se pueden acceder invocando al comando variable o al comando upvar.

La invocación de apply agrega un marco de llamada a la pila de evaluación de Tcl (la pila de marcos a la que se accede mediante uplevel). La ejecución de body procede en este marco de llamada, en el espacio de nombres dado por namespace o en el espacio de nombres global si no se especificó ninguno. Si se proporciona, namespace se interpreta en relación con el espacio de nombres global, incluso si su nombre no comienza con “::”.

La semántica de apply también se puede describir mediante:

proc apply {fun args} {
    set len [llength $fun]
    if {($len < 2) || ($len > 3)} {
         error "no se puede interpretar \"$fun\" como función anónima"
    }
    lassign $fun argList body ns
    set name ::$ns::[getGloballyUniqueName]
    set body0 {
         rename [lindex [info level 0] 0] {}
    }
    proc $name $argList ${body0}$body
    set code [catch {uplevel 1 $name $args} res opt]
    return -options $opt $res
}

EJEMPLOS

Esto muestra cómo crear un comando general simple que aplica una transformación a cada elemento de una lista.

proc map {lambda list} {
    set result {}
    foreach item $list {
        lappend result [apply $lambda $item]
    }
    return $result
}
map {x {return [string length $x]:$x}} {a bb ccc dddd}
      → 1:a 2:bb 3:ccc 4:dddd
map {x {expr {$x**2 + 3*$x - 2}}} {-4 -3 -2 -1 0 1 2 3 4}
      → 2 -2 -4 -4 -2 2 8 16 26

El comando apply también es útil para definir callbacks para su uso en el comando trace:

set vbl "123abc"
trace add variable vbl write {apply {{v1 v2 op} {
    upvar 1 $v1 v
    puts "variable actualizada a \"$v\""
}}}
set vbl 123
set vbl abc
