NOMBRE

App::CLI - Módulo de despacho para programas de interfaz de línea de comandos

SINOPSIS

package MyApp;
use base 'App::CLI';        # el DESPACHADOR de tu App
                            # no es necesario poner el despachador
                            # en el nivel superior de tu App
package main;
MyApp->dispatch;            # llama al despachador donde quieras
package MyApp::List;
use base qw(App::CLI::Command); # cualquier (SUB)COMANDO de tu App
use constant options => (
    "h|help"   => "help",
    "verbose"  => "verbose",
    'n|name=s'  => 'name',
);
use constant subcommands => qw(User Nickname type); # si quieres que los subcomandos
                                                    # se despachen automáticamente a subcomandos
                                                    # cuando se invoca $ myapp list [user|nickname|--type]
                                                    # nota: 'type' no está en mayúsculas
                                                    # es un subcomando obsoleto
sub run {
    my ($self, @args) = @_;
    print "verbose" if $self->{verbose};
    my $name = $self->{name}; # obtén el argumento que sigue a la opción larga --name
    if ($self->{help}) {
        # si $ myapp list --help o $ myapp list -h
        # solo muestra los PODs
    } else {
        # haz algo al invocar $ myapp list
        # sin subcomando y sin --help
    }
}
package MyApp::List::User;
use base qw(App::CLI::Command);
use constant options => (
    "h|help"  =>  "help",
);
sub run {
    my ($self,@args) = @_;
    # código para listar usuario
}
pakcage MyApp::List::Nickname;
use base qw(App::CLI::Command);
use constant options => (
    "sort=s"  =>  "sort",
);
sub run {
    my ($self,@args) = @_;
    # código para listar apodo
}
package MyApp::List::type;   # un antiguo género de subcomando no puede anidarse infinitamente
use base qw(MyApp::List);    # debe heredar el comando de su padre
sub run {
    my ($self, @args);
    # ejecuta hasta aquí al invocar $ myapp list --type
}
package MyApp::Help;
use base 'App::CLI::Command::Help';
use constant options => (
    'verbose' => 'verbose',
);
sub run {
    my ($self, @arg) = @_;
    # haz algo
    $self->SUPER(@_); # App::CLI::Command::Help mostrará los PODs de cada comando
}

DESCRIPCIÓN

"App::CLI" despacha comandos de CLI (interfaz de línea de comandos) a clases de comandos. También admite subcomandos y opciones por comando.

Métodos

get_opt([@config], %opt_map)

Proporciona un mapa de opciones, procesado por Getopt::Long::Parser.

dispatch(@args)

Interfaz del despachador

cmd_map($cmd)

Busca el nombre del paquete que implementa el comando solicitado.

El comando se busca primero en "alias". Si el alias existe y apunta a un nombre de paquete que comienza con el signo "+", entonces se devuelve ese nombre de paquete (menos el signo "+"). Esto permite mapear comandos a paquetes arbitrarios.

De lo contrario, el paquete se busca en el resultado de llamar "commands", y se construye un nombre de paquete convirtiendo la primera letra del nombre del comando a mayúsculas y agregándola al nombre del paquete de la propia aplicación.

Si ambos fallan y el comando no se mapea a ningún nombre de paquete, se devuelve "undef".

get_cmd($cmd, @arg)

Devuelve el subcomando de primer nivel a través de $ARGV[0].
