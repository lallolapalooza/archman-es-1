NOMBRE

apptainer-pull - Descargar una imagen desde una URI

SINOPSIS

apptainer pull [opciones de pull...] [archivo de salida]

DESCRIPCIÓN

El comando 'pull' te permite descargar o construir un contenedor desde una
URI dada. Las URIs admitidas incluyen:

library: Descargar una imagen desde la biblioteca configurada actualmente
library://usuario/coleccion/contenedor[:etiqueta]

docker: Descargar una imagen Docker/OCI desde Docker Hub, u otro registro OCI.
docker://usuario/imagen:etiqueta

shub: Descargar una imagen desde Singularity Hub
shub://usuario/imagen:etiqueta

oras: Descargar una imagen SIF desde un registro OCI que soporte ORAS.
oras://registro/espacio-nombres/imagen:etiqueta

http, https: Descargar una imagen usando el protocolo http(s?)
https://example.com/alpine.sif

OPCIONES

--arch="amd64" arquitectura desde la que descargar desde la biblioteca

--arch-variant="" variante de arquitectura para descargar desde la biblioteca

--authfile="" archivo de autenticación estilo Docker para usar para escribir/leer credenciales del registro OCI

--dir="" descargar imágenes al directorio específico

--disable-cache[=false] no usar ni crear imágenes/blobs en caché

--docker-host="" especificar un host de demonio Docker personalizado

--docker-login[=false] iniciar sesión en un Repositorio Docker interactivamente

-F, --force[=false] sobrescribir un archivo de imagen si existe

-h, --help[=false] ayuda para pull

--library="" descargar imágenes de la biblioteca proporcionada

--no-cleanup[=false] NO limpiar el paquete después de una compilación fallida, puede ser útil para depuración

--no-https[=false] usar http en lugar de https para URIs docker://, oras:// y library:///...

--sandbox[=false] descargar imagen en formato sandbox (estructura de directorios chroot)

EJEMPLO

  Desde una biblioteca
  $ apptainer pull alpine.sif library://alpine:latest
  Desde Docker
  $ apptainer pull tensorflow.sif docker://tensorflow/tensorflow:latest
  $ apptainer pull --arch arm --arch-variant 6 alpine.sif docker://alpine:latest
  Desde Shub
  $ apptainer pull apptainer-images.sif shub://vsoch/apptainer-images
  Desde un registro OCI compatible (por ejemplo, Azure Container Registry)
  $ apptainer pull image.sif oras://<nombredeusuario>.azurecr.io/espacionombres/imagen:etiqueta
