NOMBRE

apptainer-overlay-create - Crea una imagen de superposición escribible EXT3

SINOPSIS

apptainer overlay create imagen

DESCRIPCIÓN

El comando overlay create permite crear una imagen de superposición escribible EXT3, ya sea
como una única imagen EXT3 o agregándola automáticamente a una imagen SIF existente.

OPCIONES

--create-dir=[] directorio a crear como parte del diseño de superposición

-f, --fakeroot[=false] hace que el diseño de superposición sea utilizable por acciones ejecutadas con --fakeroot

-h, --help[=false] ayuda para crear

-s, --size=64 tamaño de la superposición escribible EXT3 en MiB

-S, --sparse[=false] crea una superposición dispersa

EJEMPLO

  Para crear y agregar una superposición escribible a una imagen SIF existente:
  $ apptainer overlay create --size 1024 /tmp/image.sif
  Para crear una imagen de superposición escribible EXT3 única:
  $ apptainer overlay create --size 1024 /tmp/my_overlay.img
  Para crear una superposición dispersa al crear una imagen de sistema de archivos ext3 nueva:
  $ apptainer overlay create --size 1024 --sparse /tmp/ext3_overlay.img
  Para crear una imagen de superposición escribible EXT3 para usarla con acciones --fakeroot:
  $ apptainer overlay create --fakeroot --size 1024 /tmp/my_overlay.img
