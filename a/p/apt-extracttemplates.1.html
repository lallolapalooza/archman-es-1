NOMBRE

apt-extracttemplates - Utilidad para extraer debconf config y plantillas de paquetes Debian

SINOPSIS

apt-extracttemplates [-t=directorio_temporal] nombre_archivo... {-v | --version} {-h | --help}

DESCRIPCIÓN

apt-extracttemplates tomará uno o más archivos de paquetes Debian como entrada y escribirá (en un directorio temporal) todos los scripts de configuración y archivos de plantilla asociados. Para cada paquete pasado que contenga scripts de configuración y plantillas, se generará una línea de salida en el formato:

paquete versión archivo_plantilla script_configuración

archivo_plantilla y script_configuración se escriben en el directorio temporal especificado por el -t o --tempdir (APT::ExtractTemplates::TempDir), con nombres de archivo de la forma paquete.template.XXXXXX y paquete.config.XXXXXX

OPCIONES

Todas las opciones de la línea de comandos pueden establecerse usando el archivo de configuración, las descripciones indican la opción de configuración a establecer. Para opciones booleanas puede anular el archivo de configuración usando algo como -f-,--no-f, -f=no o varias otras variaciones.

-t, --tempdir

Directorio temporal en el que escribir los archivos de plantilla debconf extraídos y los scripts de configuración. Elemento de configuración: APT::ExtractTemplates::TempDir

-h, --help

Muestra un breve resumen de uso.

-v, --version

Muestra la versión del programa.

--audit

Muestra mensajes de auditoría (y de aviso). Esto anula la opción silenciosa, pero solo para los mensajes de aviso, no para los de progreso.

-c, --config-file

Archivo de configuración; Especifica un archivo de configuración a usar. El programa leerá el archivo de configuración predeterminado y luego este archivo de configuración. Si es necesario establecer configuraciones antes de que se analicen los archivos de configuración predeterminados, especifique un archivo con la APT_CONFIG variable de entorno. Vea apt.conf(5) para información de sintaxis.

-o, --option

Establece una opción de configuración; Esto establecerá una opción de configuración arbitraria. La sintaxis es -o Foo::Bar=bar. -o y --option pueden usarse varias veces para establecer diferentes opciones.

--cli-version

Solicita una versión específica de CLI. Este es un patrón que toma una versión MAJOR.MINOR. Puede omitir la versión MINOR, en cuyo caso se usará el nivel menor más reciente admitido.

Las pistas de versión se presentan como sigue: La versión 3.2 tiene versiones equivalentes 0.32, 1.22 y 2.12, implementando nuevas características para sus versiones mayores especificadas.

Un caso especial es el patrón de versión X.9: Una versión como 2.9 es seguida por 3.0, pero 2.10 sigue directamente a 2.8; dado que usamos números de versión impares como series de desarrollo (2.9 es la serie de desarrollo 3.0).

Esta característica se ha introducido en APT 3.1.10 y reemplaza la configuración específica del binario. Puede usar APT::Version para un efecto similar en binarios más antiguos, por ejemplo, use -o APT::Version=2 para hacer que apt(8) se comporte como la serie 2.x.

El valor predeterminado es la versión actual de APT para apt(8) y 0.(10 * mayor + menor) para los comandos clásicos. La serie 0.X está obsoleta de forma suave y los otros comandos pasarán a la serie 2.x en el futuro.

--no-color, --color

Activa o desactiva los colores. Los colores están activados por defecto en terminales compatibles para apt(8) y también pueden desactivarse usando las NO_COLOR o APT_NO_COLOR variables de entorno, o configurarse más mediante la APT::Color opción de configuración y ámbito, vea apt.conf(5) para información sobre eso.

VEA TAMBIÉN

apt.conf(5)

DIAGNÓSTICO

apt-extracttemplates devuelve cero en operación normal, decimal 100 en caso de error.
