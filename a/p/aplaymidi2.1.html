APLAYMIDI2(1) Manual de Comandos Generales APLAYMIDI2(1)

NOMBRE

aplaymidi2 - reproducir archivos MIDI Clip

SINOPSIS

aplaymidi2 -p cliente:puerto[,...] archivo2midi ...

DESCRIPCIÓN

aplaymidi2 es una utilidad de línea de comandos que reproduce los archivos MIDI Clip especificados en uno o más puertos del secuenciador ALSA.

OPCIONES

-h, --help
Imprime una lista de opciones.
-V, --version
Imprime la versión actual.
-p, --port=cliente:puerto,...
Establece el(los) puerto(s) del secuenciador a los que se envían los eventos del archivo(s) MIDI Clip.

Un cliente puede especificarse por su número, su nombre o un prefijo de su nombre. Un puerto se especifica por su número; para el puerto 0 de un cliente, la parte ":0" de la especificación del puerto puede omitirse.

Se pueden especificar múltiples puertos para permitir la reproducción de archivos MIDI Clip que contienen eventos para múltiples dispositivos (puertos) correspondientes a los múltiples Grupos UMP.

Para compatibilidad con pmidi(1), la especificación del puerto se toma de la variable de entorno ALSA_OUTPUT_PORTS si no se proporciona en la línea de comandos.

aplaymidi2 solo soporta eventos UMP básicos: además de los CVMs estándar MIDI1 y MIDI2 y SysEx de 7 bits, solo se soportan los siguientes: DCTPQ, DC, Set Tempo, Start Clip, End Clip. Las letras de canción y otros metadatos en Flex Data también se imprimen, a menos que se proporcione la opción -s.

Los múltiples puertos de salida son útiles cuando el archivo MIDI Clip dado contiene los paquetes UMP para múltiples Grupos. Cuando el puerto de destino es un puerto UMP MIDI 2.0, la conexión única debería ser suficiente, ya que un puerto MIDI 2.0 puede procesar las entradas para múltiples Grupos. Para otros casos (por ejemplo, conexión a un puerto MIDI heredado), necesitaría especificar el puerto de destino por Grupo. Si no se define, se envía al primer puerto de destino por defecto.

-d, --delay=segundos
Especifica cuánto tiempo esperar después del final de cada archivo MIDI Clip, para permitir que las últimas notas se apaguen. El valor predeterminado es 2 segundos.
-s, --silent
No mostrar mensajes de texto.
-a, --passall
Pasa todos los paquetes UMP tal cual.

Por defecto, aplaymidi2 solo pasa mensajes de voz de canal MIDI1 y MIDI2 y procesa otros paquetes UMP internamente. Con esta opción, pasa todos los paquetes UMP al destino.
