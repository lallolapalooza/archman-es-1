NOMBRE

apachectl - Interfaz de control del servidor HTTP Apache

SINOPSIS

Al actuar en modo de paso, apachectl puede tomar todos los argumentos disponibles para el binario httpd.

apachectl [ argumento-de-httpd ]

Al actuar en modo de inicio SysV, apachectl toma comandos simples de una sola palabra, definidos a continuación.

apachectl comando

RESUMEN

apachectl es una interfaz para el servidor HTTP (HyperText Transfer Protocol) de Apache. Está diseñado para ayudar al administrador a controlar el funcionamiento del demonio Apache httpd.

El script apachectl puede operar en dos modos. Primero, puede actuar como una interfaz simple al comando httpd que simplemente establece las variables de entorno necesarias e invoca httpd, pasando cualquier argumento de línea de comandos. Segundo, apachectl puede actuar como un script de inicio SysV, tomando argumentos simples de una sola palabra como start, restart y stop, y traduciéndolos a señales apropiadas para httpd.

Si su instalación de Apache utiliza rutas no estándar, deberá editar el script apachectl para establecer las rutas apropiadas al binario httpd. También puede especificar cualquier argumento de línea de comandos de httpd necesario. Consulte los comentarios en el script para obtener detalles.

El script apachectl devuelve un valor de salida de 0 si tiene éxito y >0 si ocurre un error. Para más detalles, consulte los comentarios en el script.

OPCIONES

Solo se definen aquí las opciones de estilo de inicio SysV. Otros argumentos se definen en la página del manual de httpd.

start
Inicia el demonio Apache httpd. Da un error si ya está en ejecución. Esto es equivalente a apachectl -k start.
stop
Detiene el demonio Apache httpd. Esto es equivalente a apachectl -k stop.
restart
Reinicia el demonio Apache httpd. Si el demonio no está en ejecución, se inicia. Este comando comprueba automáticamente los archivos de configuración como en configtest antes de iniciar el reinicio para asegurarse de que el demonio no se caiga. Esto es equivalente a apachectl -k restart.
fullstatus
Muestra un informe de estado completo del mod_status. Para que esto funcione, necesita tener mod_status habilitado en su servidor y un navegador de texto como lynx disponible en su sistema. La URL utilizada para acceder al informe de estado se puede establecer editando la variable STATUSURL en el script.
status
Muestra un informe de estado breve. Similar a la opción fullstatus, excepto que se omite la lista de solicitudes que se están sirviendo actualmente.
graceful
Reinicia de forma elegante el demonio Apache httpd. Si el demonio no está en ejecución, se inicia. Esto difiere de un reinicio normal en que las conexiones abiertas actualmente no se abortan. Un efecto secundario es que los archivos de registro antiguos no se cerrarán inmediatamente. Esto significa que si se utiliza en un script de rotación de registros, puede ser necesaria una demora sustancial para asegurar que los archivos de registro antiguos se cierren antes de procesarlos. Este comando comprueba automáticamente los archivos de configuración como en configtest antes de iniciar el reinicio para asegurarse de que Apache no se caiga. Esto es equivalente a apachectl -k graceful.
graceful-stop
Detiene de forma elegante el demonio Apache httpd. Esto difiere de una detención normal en que las conexiones abiertas actualmente no se abortan. Un efecto secundario es que los archivos de registro antiguos no se cerrarán inmediatamente. Esto es equivalente a apachectl -k graceful-stop.
configtest
Ejecuta una prueba de sintaxis de los archivos de configuración. Analiza los archivos de configuración e informa Syntax Ok o información detallada sobre el error de sintaxis particular. Esto es equivalente a apachectl -t.

La siguiente opción estaba disponible en versiones anteriores pero ha sido eliminada.

startssl
Para iniciar httpd con soporte SSL, debe editar su archivo de configuración para incluir las directivas relevantes y luego usar el comando normal apachectl start.
