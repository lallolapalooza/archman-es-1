apksigcopier(1) Manual de comandos generales apksigcopier(1)

NOMBRE

apksigcopier - copiar/extraer/modificar firmas de apk de Android y comparar apks

SINOPSIS

apksigcopier copy [opciones] apk_firmado apk_sin_firmar apk_salida

apksigcopier extract [opciones] apk_firmado directorio_salida

apksigcopier patch [opciones] directorio_metadatos apk_sin_firmar apk_salida

apksigcopier compare [opciones] primer_apk segundo_apk

apksigcopier --version

apksigcopier --help

apksigcopier [comando] --help

DESCRIPCIÓN

Una herramienta de línea de comandos para copiar firmas APK de Android de un APK firmado a uno sin firmar (con el fin de verificar compilaciones reproducibles). También se puede utilizar para comparar dos APKs con firmas diferentes.

COMANDOS

copy

Copia (extrae y modifica) firmas de un APK firmado a uno sin firmar.

extract

Extrae las firmas APK de un APK firmado.

patch

Aplica las firmas APK extraídas a un APK sin firmar.

compare

Compara dos APKs copiando la firma del primero a una copia del segundo y comprobando si el APK resultante se verifica correctamente.

Este comando requiere apksigner(1).

NB: Copiar de un APK firmado con v1 usando signflinger a un APK firmado con apksigner funciona, mientras que lo inverso falla; ver el FAQ en el README.

OPCIONES

copy/extract/patch

--v1-only [no|auto|yes]

Si se espera solo una firma v1: no significa que también se espera una firma v2, auto significa que la presencia de una firma v2 se detecta automáticamente y yes significa que no se espera una firma v2 (y se ignora si existe). Predeterminado: no.

También puede establecer la variable de entorno APKSIGCOPIER_V1_ONLY en su lugar.

compare

--unsigned

Acepta segundo_apk sin firmar.

--min-sdk-version

Pasado a apksigner(1) al verificar.

--verify-cmd

Comando (con argumentos) utilizado para verificar APKs. Predeterminado: apksigner verify.

VARIABLES DE ENTORNO

Las siguientes variables de entorno se pueden establecer en 1, yes, o true para anular el comportamiento predeterminado.

APKSIGCOPIER_EXCLUDE_ALL_META

Excluye todos los archivos de metadatos, no solo MANIFEST.MF.

APKSIGCOPIER_COPY_EXTRA_BYTES

Copia bytes adicionales después de los datos (por ejemplo, una firma v2 existente).

APKSIGCOPIER_SKIP_REALIGNMENT

Omite la realineación de entradas ZIP.

EJEMPLOS

extract

$ mkdir meta
$ apksigcopier extract signed.apk meta
$ ls -1 meta
8BEA2A77.RSA
8BEA2A77.SF
APKSigningBlock
APKSigningBlockOffset
MANIFEST.MF

patch

$ apksigcopier patch meta unsigned.apk out.apk

copy

$ apksigcopier copy signed.apk unsigned.apk out.apk

compare

$ apksigcopier compare foo-from-fdroid.apk foo-built-locally.apk
$ apksigcopier compare foo.apk --unsigned foo-unsigned.apk
