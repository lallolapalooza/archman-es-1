NOMBRE

/etc/apk/world - lista de restricciones para la selección de paquetes

DESCRIPCIÓN

En /etc/apk/world, apk mantiene el world, es decir, una lista de restricciones que la selección de paquetes debe cumplir.

Si editas este archivo manualmente, deberías ejecutar apk-fix(8) para aplicar los cambios.

ESPECIFICACIÓN DE PAQUETE

Este es un archivo de texto plano con una restricción por línea usando la notación de dependencias. Cada línea tiene el formato: [!]nombre{@etiqueta}{[<>~=]versión}.

Al modificar una instalación existente, se prefiere la versión instalada a menos que se solicite una actualización o una restricción del mundo o una dependencia de paquete requiera una versión alternativa.

Para permitir la selección desde un repositorio etiquetado, usa el formato nombre@etiqueta, por ejemplo, busybox@edge. Consulta apk-repositories(5) para obtener detalles sobre los repositorios de paquetes etiquetados. Los repositorios sin etiqueta también se consideran para las restricciones con una etiqueta. La etiqueta se hereda a todas las dependencias como un repositorio permitido. Es decir, las dependencias se seleccionan del repositorio etiquetado si el nombre@etiqueta tiene una dependencia con una restricción de versión que requiere una versión disponible solo desde el repositorio etiquetado. Si la dependencia se puede satisfacer desde un repositorio no etiquetado, se le dará preferencia.

Para restringir las versiones aceptables del paquete, usa los operadores =, <, >, >=, ~, >~ o <~. Respectivamente, estos requieren que el paquete sea igual a, menor que, mayor que, mayor o igual a, coincidencia de prefijo, mayor que o coincidencia de prefijo, o menor que o coincidencia de prefijo a la versión especificada. El operador ~ restringe el paquete a la coincidencia de prefijo del número de versión.

busybox

Instala busybox desde el repositorio sin etiqueta desde el cual está disponible.

busybox@edge

Permite la instalación de busybox y sus dependencias desde un repositorio etiquetado con "edge". Los repositorios etiquetados no tendrán prioridad. Si una versión de un repositorio sin etiqueta se ajusta mejor, se usará.

!unwanted

Evita la instalación de unwanted como dependencia creando un conflicto.

busybox=1.6.1

Instala la versión 1.6.1 de busybox.

busybox>1.6.1

Instala una versión de busybox mayor que 1.6.1.

busybox>=1.6.1

Instala una versión de busybox mayor o igual a 1.6.1.

busybox<1.6.1

Instala una versión de busybox menor que 1.6.1.

busybox~1.6

Instala cualquier versión de busybox que comience con 1.6. Ejemplos de coincidencia: 1.6, 1.6.0_pre1, 1.6.0, 1.6.5, 1.6.9_p1.

busybox>~1.6

Instala una versión de busybox mayor que o con coincidencia de prefijo de 1.6.

busybox<~1.6

Instala una versión de busybox menor que o con coincidencia de prefijo de 1.6.
