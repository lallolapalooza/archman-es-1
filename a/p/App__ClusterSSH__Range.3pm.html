SINÓPSIS

use App::ClusterSSH::Range;
my $range=App::ClusterSSH::Range->new();
my @list = $range->expand('range{0..5}');

DESCRIPCIÓN

Realiza la expansión de cadenas buscando rangos antes de finalizar usando "File::Glob::bsd_glob".

MÉTODOS

$range = App::ClusterSSH::Range->new();
Crea un nuevo objeto para realizar el procesamiento de rangos
@expanded = $range->expand(@strings);
Expande las cadenas dadas. Se buscan y procesan los rangos. La cadena resultante se pasa a través de File::Glob::bsd_glob antes de ser devuelta.

Los rangos tienen el formato:

base{inicio..fin}
a{0..3} => a0 a1 a2 a3 
b{4..6,9,12..14} => b4 b5 b6 b9 b12 b13 b14
