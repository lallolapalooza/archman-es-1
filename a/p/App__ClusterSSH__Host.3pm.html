App::ClusterSSH::Host(3pm) Documentación de Perl contribuida por el usuario App::ClusterSSH::Host(3pm)

SINOPSIS

use ClusterSSH::Host;
my $host = ClusterSSH::Host->new({
    hostname => 'nombre_del_host',
});
my $host = ClusterSSH::Host->parse_host_string('usuario@nombre_del_host:1234');

DESCRIPCIÓN

Objeto que representa un host. Incluye detalles para contactar el host como nombre de host/dirección IP, nombre de usuario y puerto.

Establece detalles específicos sobre el host después de haber sido creado.

Si el nombre del servidor proporcionado no es una dirección IP (IPv4 o IPv6) intenta resolverlo y devuelve los nombres descubiertos.
get_givenname
Alias de get_hostname, para usar cuando " get_realname " pueda devolver algo diferente

Dada una cadena de host, devuelve un objeto host. Analiza hosts como

Comprueba el nombre de host del objeto para ver si puede o no estar configurado en el archivo de configuración $HOME/.ssh/config del usuario
read_ssh_file
Método para facilitar la lectura de archivos de configuración ssh. Se utiliza para obtener nombres de host para validación cuando se usa en clústeres
