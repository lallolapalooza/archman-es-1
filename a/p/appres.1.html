APPRES(1) Manual de comandos generales APPRES(1)

NOMBRE

appres - lista la base de datos de recursos de aplicaciones X

SINOPSIS

appres [clase [instancia]] [-1] [-V] [opciones_toolkit]

DESCRIPCIÓN

El programa appres imprime los recursos que ve una aplicación (o una subjerarquía de una aplicación) con los nombres de clase e instancia especificados. Se puede usar para determinar qué recursos cargará un programa en particular. Por ejemplo,


% appres  XTerm

listarará los recursos que cargará cualquier programa xterm. Si no se especifica ninguna clase de aplicación, se usa la clase -AppResTest-.

Para coincidir con un nombre de instancia particular, especifique un nombre de instancia explícitamente después del nombre de la clase, o use la opción normal del toolkit Xt. Por ejemplo,


% appres  XTerm  mi_xterm
o 
% appres  XTerm  -name  mi_xterm

Para listar los recursos que coinciden con una subjerarquía de una aplicación, especifique nombres de clase e instancia jerárquicos. El número de componentes de clase e instancia debe ser igual, y el nombre de la instancia no debe especificarse con una opción de toolkit. Por ejemplo,


% appres  Xman.TopLevelShell.Form  xman.topBox.form

listarará los recursos de los widgets de la jerarquía topBox de xman. Para listar solo los recursos que coinciden con un nivel específico en la jerarquía, use la opción -1. Por ejemplo,


% appres  XTerm.VT100  xterm.vt100  -1

listarará los recursos que coinciden con el widget vt100 de xterm.

La opción -V imprime la versión del comando appres y sale.

VER TAMBIÉN

X(7), xrdb(1), listres(1)

AUTOR
