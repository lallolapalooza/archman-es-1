App::Prove::State::Result(3perl) Guía del programador de Perl App::Prove::State::Result(3perl)

NOMBRE

App::Prove::State::Result - Resultados individuales de suites de pruebas.

VERSIÓN

Versión 3.50

DESCRIPCIÓN

El comando "prove" soporta una opción "--state" que le indica que almacene estado persistente entre ejecuciones. Este módulo encapsula los resultados de una ejecución individual de una suite de pruebas.

SINOPSIS

# Re-ejecutar pruebas fallidas
$ prove --state=failed,save -rbv

MÉTODOS

Métodos de clase

"new"

my $result = App::Prove::State::Result->new({
    generation => $generation,
    tests      => \%tests,
});

Devuelve una nueva instancia de "App::Prove::State::Result".

"state_version"

Devuelve la versión actual del almacenamiento de estado.

"test_class"

Devuelve el nombre de la clase utilizada para rastrear pruebas individuales. Esta clase debe heredar de "App::Prove::State::Result::Test" o proporcionar una interfaz idéntica.

"generation"

Obtenedor/establecedor para la "generación" de la ejecución de la suite de pruebas. La primera generación es 1 (uno) y las generaciones subsiguientes son 2, 3, etc.

"last_run_time"

Obtenedor/establecedor para la hora de la ejecución de la suite de pruebas.

"tests"

Devuelve las pruebas para una generación dada. Esto es un hashref o un hash, dependiendo del contexto en el que se llame. Las claves del hash son los nombres de las pruebas individuales y el valor es un hashref con varios valores interesantes. Cada par clave/valor podría parecerse a esto:

't/foo.t' => {
   elapsed        => '0.0428488254547119',
   gen            => '7',
   last_pass_time => '1219328376.07815',
   last_result    => '0',
   last_run_time  => '1219328376.07815',
   last_todo      => '0',
   mtime          => '1191708862',
   seq            => '192',
   total_passes   => '6',
 }

"test"

my $test = $result->test('t/customer/create.t');

Devuelve una instancia individual de "App::Prove::State::Result::Test" para el nombre de prueba dado (generalmente el nombre del archivo). Devolverá una nueva instancia de "App::Prove::State::Result::Test" si el nombre no se encuentra.

"test_names"

Devuelve una lista de nombres de pruebas, ordenadas por orden de ejecución.

"remove"

$result->remove($test_name);            # eliminar la prueba
my $test = $result->test($test_name);   # error fatal

Elimina una prueba dada de los resultados. Esto no hace nada si el nombre de la prueba no se encuentra.

"num_tests"

Devuelve el número de pruebas para un resultado de suite de pruebas dado.

"raw"

Devuelve un hashref de resultados en bruto, adecuado para la serialización por YAML.
