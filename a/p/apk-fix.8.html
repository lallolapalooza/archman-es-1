apk-fix(8) Manual del Administrador del Sistema apk-fix(8)

NOMBRE

apk fix - reparar paquetes o el sistema

SINOPSIS

apk fix [<opciones>...] [paquetes...]

DESCRIPCIÓN

apk fix aplica estrategias de reparación para corregir errores en la instalación de los paquetes especificados, o en todos los paquetes instalados si no se especifica ninguno.

OPCIONES

apk fix soporta las opciones de confirmación descritas en apk(8), así como las siguientes opciones:

--depends, -d

Repara también las dependencias de los paquetes especificados.

--directory-permissions

Restablece todos los permisos de directorio.

--reinstall, -r

Reinstala los paquetes (por defecto).

--upgrade, -u

Actualiza el nombre PAQUETE si existe una actualización y no rompe las dependencias.

--xattr, -x

Repara paquetes con atributos extendidos (xattrs) rotos.
