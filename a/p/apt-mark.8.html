DESCRIPCIÓ

N

apt-mark puede usarse como una interfaz unificada para establecer varias configuraciones para un paquete, como marcar un paquete como instalado automáticamente/manualmente o cambiar selecciones de dpkg como hold, install, deinstall y purge, que son respetadas, por ejemplo, por apt-get dselect-upgrade o apti

tud
e.

PAQUETES INSTALADOS AUTOMÁTICA Y

MANUALMENTE

Cuando se solicita la instalación de un paquete y, como resultado, se instalan otros paquetes para satisfacer sus dependencias, las dependencias se marcan como instaladas automáticamente, mientras que el paquete que instaló explícitamente se marca como instalado manualmente. Una vez que un paquete instalado automáticamente ya no es requerido por ningún paquete instalado manualmente, se considera que ya no es necesario y, por ejemplo, apt-get o aptitude al menos sugerirán

eliminarlos.

aut

o
auto se usa para marcar un paquete como instalado automáticamente, lo que hará que el paquete se elimine cuando ningún paquete instalado manualmente dependa de
él.

manua

l
manual se usa para marcar un paquete como instalado manualmente, lo que evitará que el paquete se elimine automáticamente si ningún otro paquete depende de
él.

minimize-manua

l
minimize-manual se usa para marcar las dependencias (transitivas) de los metapaquetes como instaladas automáticamente. Esto puede usarse después de una instalación, por ejemplo, para minimizar el número de paquetes instalados manualmente; o continuamente en sistemas gestionados por metapaquetes de configuración del
sistema.

showaut

o
showauto se usa para imprimir una lista de paquetes instalados automáticamente, con cada paquete en una línea nueva. Se listarán todos los paquetes instalados automáticamente si no se proporciona ningún paquete. Si se proporcionan paquetes, solo se mostrarán aquellos que están instalados automáticamente
.

showmanua

l
showmanual puede usarse de la misma manera que showauto, excepto que imprimirá una lista de paquetes instalados
manualmente.

PROGRAMAR PAQUETES PARA INSTALAR, ELIMINAR Y

PURGAR

Algunas interfaces como apt-get dselect-upgrade pueden usarse para aplicar cambios programados previamente al estado de instalación de los paquetes. Dichos cambios pueden programarse con los comandos install, remove (también conocido como deinstall) y purge. Los paquetes con una selección específica pueden mostrarse con showinstall, showremove y showpurge respectivamente. Se puede encontrar más información sobre estas llamadas selecciones de dpkg en dpkg

(1
).

Archivo de Configuración; Especificar un archivo de configuración para usar. El programa leerá el archivo de configuración predeterminado y luego este archivo de configuración. Si es necesario establecer configuraciones antes de que se analicen los archivos de configuración predeterminados, especifique un archivo con la variable de entorno APT_CONFIG. Vea apt.conf(5) para información de
sintaxis.

-o, --optio

n
Establecer un Elemento de Configuración; Esto establecerá un elemento de configuración arbitrario. La sintaxis es -o Foo::Bar=bar. -o y --option pueden usarse varias veces para establecer diferentes
elementos.

--cli-versio

n
Solicitar una versión específica de CLI. Este es un patrón que toma una versión MAYOR.MENOR. Puede omitir la versión MENOR, en cuyo caso se usará el nivel menor más reciente admitido.

Las pistas de versión se presentan como sigue: La versión 3.2 tiene versiones equivalentes 0.32, 1.22 y 2.12, implementando nuevas características para sus versiones mayores

especificadas.

Un caso especial es el patrón de versión X.9: Una versión como 2.9 es seguida por 3.0, pero 2.10 sigue directamente a 2.8; dado que usamos números de versión impares como series de desarrollo (2.9 es la serie de desarrollo de la 3.0)

.

Esta característica se ha introducido en APT 3.1.10 y reemplaza la configuración específica del binario. Puede usar APT::Version para un efecto similar en binarios más antiguos, por ejemplo, use -o APT::Version=2 para hacer que apt(8) se comporte como la serie 2.

x.

El valor predeterminado es la versión actual de APT para apt(8) y 0.(10 * mayor + menor) para los comandos clásicos. La serie 0.X está

obsoleta de forma suave y los otros coma
ndos pasarán a la serie 2.x en el futuro.

--no-color, --colo

r
Activar o desactivar los colores. Los colores están activados de forma predeterminada en terminales compatibles para apt(8) y también pueden desactivarse usando las variables de entorno NO_COLOR o APT_NO_COLOR, o configurarse más mediante el elemento y ámbito de configuración APT::Color, vea apt.conf(5) para inf
ormación
sobre eso.
