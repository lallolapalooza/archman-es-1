App::perlbrew(3pm) Documentación de Perl aportada por el usuario App::perlbrew(3pm)

NOMBRE

App::perlbrew - Gestiona instalaciones de perl en tu "$HOME"

SINOPSIS

# Instalación
curl -L https://install.perlbrew.pl | bash
# Inicializar
perlbrew init
# Ver qué está disponible
perlbrew available
# Instalar algunos Perls
perlbrew install 5.32.1
perlbrew install perl-5.28.3
perlbrew install perl-5.33.6
# Ver qué se instalaron
perlbrew list
# Cambiar a una instalación y establecerla como predeterminada
perlbrew switch perl-5.32.1
# Usar temporalmente otra versión solo en el shell actual.
perlbrew use perl-5.28.3
perl -v
# Desactivarlo y volver al perl del sistema.
perlbrew off
# Activarlo de nuevo con 'switch', o 'use'
perlbrew switch perl-5.32.1
perlbrew use perl-5.32.1
# Ejecutar algo con todos los perls gestionados por perlbrew
perlbrew exec -- perl -E 'say $]'

DESCRIPCIÓN

perlbrew es un programa para automatizar la construcción e instalación de perl de una manera sencilla. Proporciona múltiples entornos de perl aislados y un mecanismo para que puedas cambiar entre ellos.

Todo se instala bajo "~/perl5/perlbrew". Luego necesitas incluir un bashrc/cshrc proporcionado por perlbrew para ajustar el PATH por ti. Luego puedes beneficiarte de no tener que ejecutar "sudo" comandos para instalar módulos cpan porque esos se instalan dentro de tu "HOME" también.

Para la documentación del uso de perlbrew consulta el comando perlbrew en MetaCPAN https://metacpan.org/, o ejecutando "perlbrew help", o visitando el sitio web oficial de perlbrew https://perlbrew.pl/. La siguiente documentación presenta la API del módulo "App::perlbrew" , y puede no estar remotamente cerca de lo que quieres leer.

INSTALACIÓN

Lo más simple es usar el instalador de perlbrew, simplemente pega esta instrucción en tu terminal:

curl -L https://install.perlbrew.pl | bash

O esta, si tienes "fetch" (predeterminado en FreeBSD):

fetch -o- https://install.perlbrew.pl | sh

Después de eso, "perlbrew" se instala a sí mismo en "~/perl5/perlbrew/bin", y deberías seguir las instrucciones en pantalla para modificar tu archivo rc del shell y ponerlo en tu PATH.

El comando perlbrew instalado es un ejecutable independiente que puede ejecutarse con el perl del sistema. La versión mínima requerida de perl del sistema es 5.8.0, lo cual debería ser suficiente para la mayoría de los sistemas operativos en la actualidad.

También se instala una versión empaquetada de patchperl en "~/perl5/perlbrew/bin", la cual es necesaria para construir perls antiguos.

El directorio "~/perl5/perlbrew" contendrá todos los ejecutables de perl instalados, bibliotecas, documentaciones, lib, site_libs. En la documentación, ese directorio se denomina "raíz de perlbrew". Si necesitas establecerlo en otro lugar porque, digamos, tu "HOME" tiene cuota limitada, puedes hacerlo estableciendo la variable de entorno "PERLBREW_ROOT" antes de ejecutar el instalador:

export PERLBREW_ROOT=/opt/perl5
curl -L https://install.perlbrew.pl | bash

Como resultado, diferentes usuarios en la misma máquina pueden compartir el mismo directorio raíz de perlbrew (aunque solo el usuario original que hizo la instalación tendría permiso para realizar instalaciones de perl.)

Si necesitas instalar perlbrew usando un Perl que no sea "/usr/bin/perl" ni "/usr/local/bin/perl", establece y exporta la variable de entorno "PERLBREW_SYSTEM_PERL" y luego instala como se describe arriba. Ten en cuenta que no debes usar un perl gestionado por perlbrew.

También puedes instalar perlbrew desde CPAN:

cpan App::perlbrew

En este caso, el comando perlbrew se instala como "/usr/bin/perlbrew" o "/usr/local/bin/perlbrew" u otros, dependiendo de la ubicación de la instalación de perl de tu sistema.

Por favor, asegúrate de no ejecutar esto con uno de los perls gestionados con perlbrew. Es mejor desactivar perlbrew antes de ejecutar eso, si estás actualizando.

perlbrew off
cpan App::perlbrew

Siempre deberías usar el cpan del sistema (como /usr/bin/cpan) para instalar "App::perlbrew" porque se instalará bajo un PATH del sistema como "/usr/bin", el cual no se ve afectado por los comandos "switch" o "use" de perlbrew.

El comando "self-upgrade" no actualizará el perlbrew instalado por el comando cpan, pero también es fácil actualizar perlbrew ejecutando "cpan App::perlbrew" de nuevo.
