App::CLI::Command(3) Documentación de Perl aportada por el usuario App::CLI::Command(3)

NOMBRE

App::CLI::Command - Clase base para comandos App::CLI

SINOPSIS

package MyApp::List;
use base qw(App::CLI::Command);
use constant options => (
    'verbose'   => 'verbose',
    'n|name=s'  => 'name',
);
sub run {
    my ( $self, $arg ) = @_;
    print "verbose" if $self->{verbose};
    my $name = $self->{name}; # obtener argumento que sigue a la opción larga --name
    # haz lo que quieras que haga este comando
}
# Consulta App::CLI para obtener información sobre cómo invocar subcomandos.

DESCRIPCIÓN

subcommand()

devuelve el subcomando del género antiguo de $self;

cascading()

Devuelve una instancia del subcomando en cascada invocado si estaba listado en tus subcomandos constantes.

cascadable()

Devuelve el nombre del paquete del subcomando si el subcomando invocado está en tus subcomandos constantes, de lo contrario, devuelve "undef".

app

Devuelve el objeto que hace referencia a la aplicación actual.

brief_usage ($file)

Muestra un breve uso de una línea del objeto comando. Opcionalmente, se puede proporcionar un archivo para extraer el uso del POD.

usage ($want_detail)

Muestra el uso. Si $want_detail es verdadero, también se muestra la sección "DESCRIPCIÓN".

loc_text $text

Localiza el cuerpo del texto (formateado) en $text y devuelve la versión localizada.

filename

Devuelve el nombre del archivo para el módulo de comando.

VER TAMBIÉN

App::CLI, Getopt::Long
