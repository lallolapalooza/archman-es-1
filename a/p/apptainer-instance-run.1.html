apptainer-instance-run - Ejecu

ta una instancia con nombre d
e la imagen de contenedor dada

SINOPSI

S

apptainer instance run [opciones de inicio...] [argumentos del script de ejecución.

..
]

DESCRIPCIÓ

N

El comando instance run le permite crear una nueva instancia con nombre a partir de una
imagen de contenedor existente que comenzará a ejecutarse en segundo plano. Si un
script de ejecución está definido en los metadatos del contenedor, los comandos de ese script
también se ejecutarán con el comando instance run. Opcionalmente, puede
pasar argumentos al script de

ejecución.

NOTA: Este comando se añadió a Apptainer significativamente más tarde que los otros
comandos de acción y no funcionará con contenedores antiguos. En ese caso, es posible que
necesite reconstruir el

contenedor.

apptainer instance run acepta los siguientes formatos de

contenedor

*.sif Formato de Imagen de Singularity (SIF). Nativo de Singularity
(3.0+) y Apptainer (v1.0.

0+)

*.sqsh Formato SquashFS. Nativo de Singularity 2.

4+

*.img Formato ext3. Nativo de versiones de Singularity < 2.

4.

directorio/ Formato sandbox. Directorio que contiene un sistema de archivos raíz
válido y opcionalmente metadatos de

Apptainer.

instance://* Una instancia local en ejecución de un contenedor. (Vea el grupo
de comandos instance.

)

library://* Un contenedor SIF alojado en una Biblioteca (sin valor por

defecto)

docker://* Un contenedor Docker/OCI alojado en Docker Hub u otro
registro

OCI.

shub://* Un contenedor alojado en Singularity

Hub.

oras://* Un contenedor SIF alojado en un registro OCI que soporta la
especificación

OCI Registry As
Storage (ORAS).

-B, --bind=[] especificación de ruta de enlace de usuario. La especificación tiene el formato src[:dest[:opts]], donde src y dest son rutas fuera y dentro respectivamente.
