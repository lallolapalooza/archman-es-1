NAME

apptainer-instance-run - Run a service within an instance

SYNOPSIS

apptainer instance run [--containall] [--no-home] [--no-shell] [--no-tmpdir] [--overlay] [--rw-dirs] [--scratch-dir] [--tmp-dir] [-W --workdir] [-w --writable] [--writable-tmpfs] container args...

DESCRIPTION

Run a service defined in the container's instance manifest.

This command allows you to run a specific service as defined within the container's instance manifest. The service name must be specified in the container's instance manifest and can be started via this command.

Use the apptainer instance list command to list the available instances on your system.

OPTIONS

--containall, --no-home, --no-shell, --no-tmpdir, --overlay, --rw-dirs, --scratch-dir, --tmp-dir

These options are deprecated and will be removed in future versions. Please use the new options listed below.

--containall: For backward compatibility, this option ensures that $HOME, and /tmp, /var/tmp are not bind mounted from the host. It also means that the container's /tmp and $HOME will be empty. If you want to use your home directory from the host, you should use the --bind option. If you want to use the container's home directory, use the --no-home option. If you want to use the container's tmp directory, use the --no-tmpdir option.

--no-home: Do not mount the user's home directory. Access to home is denied.

--no-shell: Do not start a shell after the instance is running.

--no-tmpdir: Do not mount the container's tmp directory.

--overlay: Enable overlay filesystem support.

--rw-dirs: Mount specified bind mount directories as read-write.

--scratch-dir: Define a directory to be used for scratch space inside the container.

--tmp-dir: Define a directory to be used for temporary files inside the container.

-W, --workdir=""
working directory to be used for /tmp, /var/tmp and $HOME (if -c/--contain was also used)
-w, --writable[=false]
by default all Apptainer containers are available as read only. This option makes the file system accessible as read/write.
--writable-tmpfs[=false]
makes the file system accessible as read-write with non persistent data (with overlay support only)

EXAMPLE

  $ apptainer instance run /tmp/my-sql.sif mysql
  $ apptainer shell instance://mysql
  Apptainer my-sql.sif> pwd
  /home/mibauer/mysql
  Apptainer my-sql.sif> ps
  PID TTY          TIME CMD
    1 pts/0    00:00:00 apptainer-exec
    2 pts/0    00:00:00 bash
    3 pts/0    00:00:00 ps
  Apptainer my-sql.sif>
  $ apptainer instance stop /tmp/my-sql.sif mysql
  Stopping /tmp/my-sql.sif mysql
