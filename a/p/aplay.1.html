APLAY(1) Manual de Comandos Generales APLAY(1)

NOMBRE

arecord, aplay - grabador y reproductor de sonido por línea de comandos para el controlador de tarjeta de sonido ALSA

SINOPSIS

arecord [banderas] [nombre_archivo]
aplay [banderas] [nombre_archivo [nombre_archivo]] ...

DESCRIPCIÓN

arecord es un grabador de archivos de sonido por línea de comandos para el controlador de tarjeta de sonido ALSA. Soporta varios formatos de archivo y múltiples tarjetas de sonido con múltiples dispositivos. Si se graba con el modo entrelazado, el archivo se divide automáticamente antes de alcanzar el tamaño de 2GB.

aplay es muy similar, solo que reproduce en lugar de grabar. Para los formatos de archivo de sonido soportados, la frecuencia de muestreo, la profundidad de bits, etc., se pueden determinar automáticamente a partir de la cabecera del archivo de sonido.

Si no se especifica el nombre de archivo, se utiliza la salida o entrada estándar. La utilidad aplay acepta múltiples nombres de archivo.

OPCIONES

-h, --help
Ayuda: muestra la sintaxis.
--version
Imprime la versión actual.
-l, --list-devices
Lista todas las tarjetas de sonido y dispositivos de audio digital
-L, --list-pcms
Lista todos los PCM definidos
-D, --device=NAME
Selecciona el PCM por nombre
-q --quiet
Modo silencioso. Suprime los mensajes (no el sonido :))
-t, --file-type TYPE
Tipo de archivo (voc, wav, raw o au). Si se omite este parámetro, se utiliza el formato WAVE.
-c, --channels=#
El número de canales. El valor predeterminado es un canal. Los valores válidos son del 1 al 32.
-f --format=FORMAT
Formato de muestra
Los formatos de muestra reconocidos son: S8 U8 S16_LE S16_BE U16_LE U16_BE S24_LE S24_BE U24_LE U24_BE S32_LE S32_BE U32_LE U32_BE FLOAT_LE FLOAT_BE FLOAT64_LE FLOAT64_BE IEC958_SUBFRAME_LE IEC958_SUBFRAME_BE MU_LAW A_LAW IMA_ADPCM MPEG GSM SPECIAL S24_3LE S24_3BE U24_3LE U24_3BE S20_3LE S20_3BE U20_3LE U20_3BE S18_3LE S18_3BE U18_3LE
Algunos de estos pueden no estar disponibles en el hardware seleccionado
Los atajos de formato disponibles son: 
-f cd (16 bits little endian, 44100, estéreo) [-f S16_LE -c2 -r44100]
-f cdr (16 bits big endian, 44100, estéreo) [-f S16_BE -c2 -r44100]
-f dat (16 bits little endian, 48000, estéreo) [-f S16_LE -c2 -r48000]
Si no se proporciona ningún formato, se utiliza U8.
-r, --rate=#<Hz>
Frecuencia de muestreo en Hertz. La frecuencia predeterminada es 8000 Hertz. Si el valor especificado es menor que 300, se toma como la frecuencia en kilohertz. Los valores válidos son de 2000 a 192000 Hertz.
-d, --duration=#
Interrumpir después de # segundos. Un valor de cero significa infinito. El valor predeterminado es cero, por lo que si se omite esta opción, el proceso de grabación/reproducción se ejecutará hasta que se termine. Las opciones '-d' o '-s' están disponibles de forma exclusiva.
-s, --samples=#
Interrumpir después de la transmisión de # tramas PCM. Un valor de cero significa infinito. El valor predeterminado es cero, por lo que si se omite esta opción, el proceso de grabación/reproducción se ejecutará hasta que se termine. Las opciones '-d' o '-s' están disponibles de forma exclusiva.
-M, --mmap
Usar el modo de E/S con memoria mapeada (mmap) para el flujo de audio. Si esta opción no está establecida, se usará el modo de E/S de lectura/escritura.
-N, --nonblock
Abrir el dispositivo de audio en modo no bloqueante. Si el dispositivo está ocupado, el programa saldrá inmediatamente. Si esta opción no está establecida, el programa se bloqueará hasta que el dispositivo de audio esté disponible de nuevo.
-F, --period-time=#
La distancia entre interrupciones es de # microsegundos. Si no se proporciona el tiempo de periodo ni el tamaño del periodo, se establece un cuarto del tiempo del búfer.
-B, --buffer-time=#
La duración del búfer es de # microsegundos. Si no se proporciona el tiempo del búfer ni el tamaño del búfer, se establece el tiempo de búfer máximo permitido, pero no más de 500ms.
--period-size=#
La distancia entre interrupciones es de # tramas. Si no se proporciona el tamaño del periodo ni el tiempo del periodo, se establece un cuarto del tamaño del búfer.
--buffer-size=#
La duración del búfer es de # tramas. Si no se proporciona el tiempo del búfer ni el tamaño del búfer, se establece el tiempo de búfer máximo permitido, pero no más de 500ms.
-A, --avail-min=#
El espacio mínimo disponible para despertar es de # microsegundos
-R, --start-delay=#
El retardo para el inicio automático del PCM es de # microsegundos (relativo al tamaño del búfer si es <= 0)
-T, --stop-delay=#
El retardo para la parada automática del PCM es de # microsegundos desde xrun
-v, --verbose
Muestra la estructura y configuración del PCM. Esta opción es acumulativa. El medidor VU se muestra cuando se proporciona dos o tres veces.
-V, --vumeter=TYPE
Especifica el tipo de medidor VU, ya sea stereo o mono. El medidor VU estéreo solo está disponible para muestras estéreo de 2 canales con formato entrelazado.
-I, --separate-channels
Un archivo para cada canal. Esta opción desactiva max-file-time y use-strftime, e ignora SIGUSR1. El medidor VU estéreo no está disponible con canales separados.
-P
Reproducción. Esta es la opción predeterminada si el programa se invoca escribiendo aplay.
-C
Grabar. Esta es la opción predeterminada si el programa se invoca escribiendo arecord.
-i, --interactive
Permitir operación interactiva a través de stdin. Actualmente solo está implementado la pausa/reanudación mediante la tecla espacio o intro.
-m, --chmap=ch1,ch2,...
Proporcionar el mapa de canales para anular o seguir. Pasa cadenas de posición de canal como FL, FR, etc.

Si un dispositivo soporta la anulación del mapa de canales, aplay intenta pasar el mapa de canales proporcionado. Si no soporta la anulación del mapa de canales pero aún proporciona la información del mapa de canales, aplay intenta reorganizar el orden de los canales en el búfer para que coincida con el mapa de canales devuelto por el dispositivo.

--disable-resample
Desactivar el remuestreo automático de frecuencia.
--disable-channels
Desactivar las conversiones automáticas de canales.
--disable-format
Desactivar las conversiones automáticas de formato.
--disable-softvol
Desactivar el control de volumen por software (softvol).
--test-position
Probar la posición del búfer circular.
--test-coef=<coef>
Probar el coeficiente para la posición del búfer circular; el valor predeterminado es 8. La expresión para la validación es: coef * (buffer_size / 2). El valor mínimo es 1.
--test-nowait
No esperar al búfer circular ‐ consume toda la CPU.
--max-file-time
Durante la grabación, cuando el archivo de salida ha acumulado sonido durante este tiempo, se cierra y se abre un nuevo archivo de salida. El valor predeterminado es el tamaño máximo soportado por el formato del archivo: 2 GiB para archivos WAV. Esta opción no tiene efecto si se especifica --separate-channels.
--process-id-file <file name>
aplay escribe aquí su ID de proceso, para que otros programas puedan enviarle señales.
--use-strftime
Al grabar, interpretar los códigos %- en el parámetro del nombre de archivo usando la utilidad strftime cuando

OPCIONES

--file-progress
Informa sobre el progreso de la grabación/reproducción. El nombre del archivo de salida se forma usando códigos `strftime` (ver `strftime(3)` para más detalles). Los códigos `strftime` importantes son: `%Y` es el año, `%m` mes, `%d` día del mes, `%H` hora, `%M` minuto y `%S` segundo. Adicionalmente, `%v` es el número de archivo, comenzando desde 1. Cuando esta opción se especifica, los directorios intermedios para el archivo de salida se crean automáticamente. Esta opción no tiene efecto si se especifica `--separate-channels`.
--dump-hw-params
Vuelca los parámetros de hardware (hw_params) del estado preconfigurado del dispositivo a stderr. El volcado lista las capacidades del dispositivo seleccionado, como formatos soportados, frecuencias de muestreo, números de canales, bytes/tamaños/tiempos de período y búfer. Para el dispositivo raw hw:X, esta opción básicamente lista las capacidades de hardware de la tarjeta de sonido.
--fatal-errors
Deshabilita los intentos de recuperación cuando se encuentran errores (p. ej., xrun); el proceso aplay abortará inmediatamente.

SEÑALES

Al grabar, SIGINT, SIGTERM y SIGABRT cerrarán el archivo de salida y saldrán. SIGUSR1 cerrará el archivo de salida, abrirá uno nuevo y continuará grabando. Sin embargo, SIGUSR1 no funciona con `--separate-channels`.

EJEMPLOS

aplay -c 1 -t raw -r 22050 -f mu_law foobar
reproducirá el archivo raw "foobar" como un archivo .au de 22050 Hz, mono, 8 bits, Mu-Law.
arecord -d 10 -f cd -t wav -D copy foobar.wav
grabarará foobar.wav como un archivo wave de calidad CD de 10 segundos, usando el PCM "copy" (que podría estar definido en el archivo .asoundrc del usuario como: 
pcm.copy {
  type plug
  slave {
    pcm hw
  }
  route_policy copy
}
arecord -t wav --max-file-time 30 mon.wav
Grabar desde la fuente de audio predeterminada en monoaural, 8000 muestras por segundo, 8 bits por muestra. Iniciar un nuevo archivo cada 30 segundos. Los nombres de archivo serán mon-nn.wav, donde nn aumenta desde 01. El archivo después de mon-99.wav será mon-100.wav.
arecord -f cd -t wav --max-file-time 3600 --use-strftime %Y/%m/%d/listen-%H-%M-%v.wav
Grabar en estéreo desde la fuente de audio predeterminada. Crear un nuevo archivo cada hora. Los archivos se colocarán en directorios basados en sus fechas de inicio y tendrán nombres que incluyan sus horas de inicio y números de archivo.
