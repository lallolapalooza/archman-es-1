apk-upgrade(8) Manual del Administrador del Sistema apk-upgrade(8)

NOMBRE

apk upgrade - actualizar paquetes instalados

SINOPSIS

apk upgrade [<opciones>...] [<paquetes>...]

DESCRIPCIÓN

apk upgrade actualiza los paquetes instalados a la última versión disponible en los repositorios de paquetes configurados (ver apk-repositories(5)). Cuando no se especifican paquetes, se actualizan todos los paquetes si es posible. Si se proporciona una lista de paquetes, solo se actualizarán esos paquetes junto con las dependencias necesarias.

Si las dependencias mencionadas en --preupgrade-depends (ver apk(8)) coinciden con un paquete actualizable, se realiza un paso de preactualización. Durante el paso de preactualización, los paquetes instalados que coinciden con las dependencias de preactualización se actualizan si es posible; sus dependencias se imponen (pero no se actualizan a menos que lo requieran las dependencias del nuevo paquete).

Se genera una dependencia de preactualización implícita para el paquete que posee el ejecutable de apk.

OPCIONES

apk upgrade admite las opciones de confirmación descritas en apk(8), así como las siguientes opciones:

--available, -a

Restablece todos los paquetes a las versiones disponibles en los repositorios actuales. Esto restablece todas las dependencias versionadas en el world (ver apk-world(5)). Además, los paquetes se seleccionan de los repositorios activos si es posible, incluso si eso implica reemplazar o degradar el paquete.

Esto es útil para restablecer el sistema frente a un nuevo conjunto de paquetes después de actualizar los repositorios.

--ignore

Actualiza todos los paquetes excepto los listados. Esto invierte la lista de nombres de paquetes dada para que signifique paquetes que no deben ser actualizados.

--latest, -l

Siempre elige el paquete más reciente por versión. Sin embargo, las versiones consideradas se basan en la fijación de paquetes. Principalmente, esto anula la heurística predeterminada y provocará un error si no se pueden satisfacer todas las dependencias.

--preupgrade[=BOOL]

Si se desactiva, deshabilita el paso de preactualización.

--preupgrade-only

Realiza solo la preactualización.

--prune

Poda el world eliminando paquetes que ya no están disponibles en ningún repositorio configurado.
