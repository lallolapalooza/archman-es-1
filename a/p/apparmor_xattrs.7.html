NOMBRE

apparmor_xattrs - Coincidencia de atributos extendidos (xattrs) de perfil de AppArmor

DESCRIPCIÓN

Los perfiles de AppArmor pueden coincidir condicionalmente con archivos basándose en la presencia y el valor de atributos extendidos, además de la ruta del archivo. El siguiente perfil se aplica a cualquier archivo bajo "/usr/bin" donde el atributo extendido "security.apparmor" tenga el valor "trusted":

profile trusted /usr/bin/* xattrs=(security.apparmor="trusted") {
        # ...
}

Tenga en cuenta que "security.apparmor" y "trusted" son arbitrarios, y los perfiles pueden coincidir basándose en el valor de cualquier atributo.

El valor de xattrs también puede contener una expresión regular de ruta:

profile trusted /usr/bin/* xattrs=(user.trust="tier/*") {
        # ...
}

Las herramientas getfattr(1) y setfattr(1) se pueden usar para ver y administrar los valores de xattr:

$ setfattr -n 'security.apparmor' -v 'trusted' /usr/bin/example-tool
$ getfattr --absolute-names -d -m - /usr/bin/example-tool
# file: usr/bin/example-tool
security.apparmor="trusted"

La prioridad de cada perfil se determina por la longitud de la ruta, luego por el número de xattrs especificados. Se prefiere una ruta más específica a las coincidencias de xattr:

# Mayor prioridad, ruta más larga.
profile example1 /usr/bin/example-tool {
        # ...
}
# Menor prioridad que la ruta más larga, pero mayor prioridad que una regla
# con menos coincidencias de xattr.
profile example2 /usr/** xattrs=(
        security.apparmor="trusted"
        user.domain="**"
) {
        # ...
}
# Menor prioridad. Misma longitud de ruta que el segundo perfil, pero tiene
# menos coincidencias de xattr.
profile example2 /usr/** {
        # ...
}

La coincidencia de xattr requiere la siguiente característica del kernel:

/sys/kernel/security/apparmor/features/domain/attach_conditions/xattr

PROBLEMAS CONOCIDOS

Actualmente, los perfiles de AppArmor no pueden coincidir de forma fiable con atributos extendidos con valores binarios como security.evm e security.ima. En el futuro, AppArmor puede obtener la capacidad de coincidir basándose en la presencia de ciertos atributos, ignorando sus valores.
