NAME

App::cpanminus - obtener, desempaquetar, compilar e instalar módulos desde CPAN

SYNOPSIS

cpanm Módulo

Ejecuta "cpanm -h" o "perldoc cpanm" para ver más opciones.

DESCRIPTION

cpanminus es un script para obtener, desempaquetar, compilar e instalar módulos desde CPAN y no hace nada más.

Es libre de dependencias (puede auto-inicializarse), requiere cero configuración y funciona de forma independiente. Al ejecutarse, solo requiere 10MB de RAM.

INSTALLATION

Hay varias formas de instalar cpanminus en su sistema.

Sistema de gestión de paquetes

Hay paquetes Debian, RPM, puertos FreeBSD y paquetes para otros sistemas operativos disponibles. Si desea utilizar el sistema de gestión de paquetes, busque cpanminus y utilice el comando apropiado para instalarlo. Esto facilita la instalación de "cpanm" en su sistema sin tener que pensar en dónde instalarlo, y permite actualizaciones posteriores.

Instalación en Perl del sistema

También puede utilizar la última versión de cpanminus para instalar cpanminus en sí mismo:

curl -L https://cpanmin.us | perl - --sudo App::cpanminus

Esto instalará "cpanm" en su directorio bin como "/usr/local/bin" y necesitará la opción "--sudo" para escribir en el directorio, a menos que haya configurado "INSTALL_BASE" con local::lib.

Instalación en Perl local (perlbrew, plenv, etc.)

Si tiene Perl en su directorio de hogar, lo cual es el caso si utiliza herramientas como perlbrew o plenv, no necesita la opción "--sudo", ya que es probable que tenga permisos de escritura en la ruta de la biblioteca de Perl. Simplemente puede hacer:

curl -L https://cpanmin.us | perl - App::cpanminus

para instalar el ejecutable "cpanm" en la ruta bin de Perl, como "~/perl5/perlbrew/bin/cpanm".

Descarga del ejecutable independiente

También puede copiar el ejecutable independiente en cualquier ubicación que desee.

cd ~/bin
curl -L https://cpanmin.us/ -o cpanm
chmod +x cpanm

Esto funciona de inmediato, pero asegúrese de obtener la nueva versión manualmente cuando realice una actualización, ya que "--self-upgrade" podría no funcionar con esta configuración de instalación.

Solución de problemas: Advertencias HTTPS

Cuando ejecute los comandos "curl" anteriores, puede encontrar errores de handshake SSL o advertencias de certificado. Esto se debe a que su cliente HTTP (curl) es antiguo, o los certificados SSL instalados en su sistema necesitan ser actualizados.

Se recomienda actualizar el software o el sistema si es posible. Si eso es imposible o difícil, utilice la opción "-k" con curl.

DEPENDENCIAS

perl 5.8.1 o posterior.

  • Ejecutable 'tar' (versión bsdtar o GNU tar 1.22 se recomienda) o Archive::Tar para desempaquetar archivos.
  • Compilador C, si desea compilar módulos XS.
  • make
  • Module::Build (núcleo en 5.10)

PREGUNTAS

¿Cómo obtiene/analiza/actualiza cpanm el índice de CPAN?

Consulta el sitio CPAN Meta DB en http://cpanmetadb.plackperl.org/. El sitio se actualiza al menos cada hora para reflejar los últimos cambios de los espejos de sincronización rápida. El script luego también cae de forma predeterminada para consultar el módulo en http://metacpan.org/ utilizando su API de búsqueda.

Al llamar a estos hosts de API, cpanm (1.6004 o posterior) enviará las versiones de Perl locales al servidor en la cadena User-Agent por defecto. Puede desactivarlo con la opción "--no-report-perl-version". Lea más sobre la opción con cpanm y lea más sobre la política de privacidad sobre esta recopilación de datos en http://cpanmetadb.plackperl.org/#privacy

Los archivos obtenidos se desempaquetan en "~/.cpanm" y se limpian automáticamente periódicamente. Puede configurar la ubicación de esto con la variable de entorno "PERL_CPANM_HOME".

¿Dónde instala este módulo? ¿Necesito acceso root?

Instala en donde ExtUtils::MakeMaker y Module::Build están configurados (vía "PERL_MM_OPT" y "PERL_MB_OPT").

Por defecto, instala en el directorio site_perl que pertenece a su Perl. Puede ver las ubicaciones de esto ejecutando "perl -V" y probablemente será algo bajo "/opt/local/perl/..." si está utilizando Perl del sistema, o bajo su directorio de hogar si ha compilado Perl usted mismo utilizando perlbrew o plenv.

Si ya ha configurado local::lib en su shell, cpanm respeta esos ajustes y los módulos se instalarán en su directorio local de Perl5.

En el momento del arranque, cpanminus verifica si ya ha configurado local::lib o tiene permisos para instalar módulos en el directorio site_perl. Si ninguno de los dos, es decir, si está utilizando Perl del sistema y no ejecuta cpanm como root, configura automáticamente una ruta de instalación compatible con local::lib en un directorio "perl5" bajo su directorio de hogar.

Para evitar esto, ejecute "cpanm" ya como usuario root, con la opción "--sudo" o con la opción "--local-lib".

cpanminus no puede instalar el módulo XYZ. ¿Es un error?

Es más probable que sea un problema con la distribución en sí. cpanminus no soporta o puede tener problemas con distribuciones como las siguientes:

  • Pruebas que requieren entrada desde STDIN.
  • Build.PL o Makefile.PL que pide entrada incluso cuando "PERL_MM_USE_DEFAULT" está habilitado.
  • Módulos que tienen valores numéricos inválidos como VERSION (como "1.1a")

Estos fallos pueden ser reportados al autor del módulo para que pueda corregirlo de manera adecuada, en lugar de a cpanminus.

¿cpanm soporta la característica XYZ de CPAN y CPANPLUS?

Probablemente no. Aquí están las cosas que cpanm no hace por sí mismo.

Si necesita estas características, utilice CPAN, CPANPLUS o las herramientas independientes que se mencionan.

  • Reportes de pruebas de CPAN. Ver App::cpanminus::reporter
  • Compilación de paquetes RPM desde módulos de CPAN
  • Listado de módulos obsoletos que necesitan actualización. Ver App::cpanoutdated
  • Mostrar los cambios de los módulos que está a punto de actualizar. Ver cpan-listchanges
  • Parchear módulos de CPAN con distroprefs.

Vea cpanm o "cpanm -h" para ver qué puede hacer cpanminus :)
