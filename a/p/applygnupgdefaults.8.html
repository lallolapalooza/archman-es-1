APPLYGNUPGDEFAULTS(8) Gnu Privacy Guard 2.4 APPLYGNUPGDEFAULTS(8)

NOMBRE

applygnupgdefaults - Ejecuta gpgconf --apply-defaults para todos los usuarios.

SINOPSIS

applygnupgdefaults

DESCRIPCIÓN

Este es un script obsoleto. Las aplicaciones modernas deberían usar los archivos de configuración globales por componente bajo ‘/etc/gnupg/’.

Este script es un envoltorio para gpgconf para ejecutarlo con el comando --apply-defaults para todos los usuarios reales con un directorio principal de GnuPG existente. Los administradores podrían querer usar este script para actualizar los archivos de configuración de GnuPG para todos los usuarios después de que se haya modificado ‘/etc/gnupg/gpgconf.conf’. Esto permite forzar ciertas políticas para todos los usuarios. Tenga en cuenta que esta no es una forma a prueba de fallos para obligar a un usuario a usar ciertas opciones. Un usuario siempre puede editar directamente los archivos de configuración y omitir gpgconf.

applygnupgdefaults es invocado por root como:

applygnupgdefaults
