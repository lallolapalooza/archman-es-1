apk-mkpkg(8) Manual del Administrador del Sistema apk-mkpkg(8)

NOMBRE

apk mkpkg - crear archivos de paquete apkv3

SINOPSIS

apk mkpkg [<opciones>...]

DESCRIPCIÓN

apk mkpkg crea un archivo de paquete a partir de los metadatos y archivos de datos proporcionados.

OPCIONES

--compat VERSIÓN_APK

Produce paquetes compatibles con las versiones de apk dadas. La versión predeterminada actualmente es 3.0.0_pre1.

--files, -F RUTA

Especifica la ruta raíz de compilación desde donde se recopilan los archivos que se incluirán en el paquete.

--info, -I CLAVE:VALOR

Especifica metadatos para el paquete. Asigna el campo de metadatos CLAVE con el valor VALOR. Consulte apk-package(5) para obtener la lista de campos de metadatos de APKv3. Esto puede asignarse al campo de metadatos de "información del paquete" o de "paquete".

--output, -o ARCHIVO

Especifica el ARCHIVO como nombre del archivo de salida. Si no se especifica, se deducirá un nombre predeterminado de los campos de metadatos del paquete.

--rootnode[=BOOL]

Alias obsoleto para establecer la versión de compatibilidad. yes se resuelve a --compat=3.0.0_pre1 y no a --compat=3.0.0_pre3.

--script, -s TIPO:SCRIPT

Añade el SCRIPT especificado con el TIPO. Consulte apk-package(5) METADATOS DEL PAQUETE / scripts para la lista de tipos de scripts y cuándo se ejecutan.

--stdout

Salida del paquete resultante a stdout.

--trigger, -t TRIGGER

Añade la especificación de la ruta del TRIGGER a la lista de triggers que afectan cuándo se ejecuta el script trigger.
