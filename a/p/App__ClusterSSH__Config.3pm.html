App::ClusterSSH::Config(3pm) Documentación de Perl contribuida por el usuario App::ClusterSSH::Config(3pm)

SINÓPSIS

DESCRIPCIÓN

Objeto que representa la configuración de la aplicación

MÉTODOS

$host=ClusterSSH::Config->new ({ })
Crea un nuevo objeto de configuración.
$config->parse_config_file('<nombre_archivo>');
Lee la configuración desde el archivo especificado
$config->validate_args();
Valida y aplica toda la configuración cargada hasta este momento
$path = $config->search_dirs('<nombre>', @directorios_de_busqueda);
Busca el nombre dado en los directorios especificados. Devuelve undef si no se encuentra.
$path = $config->find_binary('<nombre>');
Localiza el binario <nombre> y devuelve la ruta completa. No busca solo en $PATH en caso de que el entorno no esté configurado correctamente
$config->load_configs(@extras);
Carga la configuración desde ubicaciones conocidas (advierte si se encuentra el archivo .csshrc) y carga los archivos de opciones según sea necesario.
$config->write_user_config_file();
Escribe el archivo de configuración predeterminado de $HOME/.clusterssh/config (antes de cargar los archivos de configuración de opciones).
$config->dump()
Escribe la configuración actualmente definida en STDOUT
