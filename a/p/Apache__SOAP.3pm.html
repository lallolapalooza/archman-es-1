Apache::SOAP(3) Documentación de Perl aportada por el usuario Apache::SOAP(3)

NOMBRE

Apache::SOAP - servidor SOAP basado en mod_perl con configuración mínima

SINOPSIS

httpd.conf (Location), acceso basado en directorios
<Location /mod_soap>
  SetHandler perl-script
  PerlHandler Apache::SOAP
  PerlSetVar dispatch_to "/Tu/Ruta/A/Modulos/Desplegados, Modulo::Nombre, Modulo::metodo"
  PerlSetVar options "compress_threshold => 10000"
</Location>
httpd.conf (Files), acceso basado en archivos
<FilesMatch "\.soap$">
  SetHandler perl-script
  PerlHandler Apache::SOAP
  PerlSetVar dispatch_to "/Tu/Ruta/A/Modulos/Desplegados, Modulo::Nombre, Modulo::metodo"
  PerlSetVar options "compress_threshold => 10000"
</FilesMatch>
.htaccess, acceso basado en directorios
SetHandler perl-script
PerlHandler Apache::SOAP
PerlSetVar dispatch_to "/Tu/Ruta/A/Modulos/Desplegados, Modulo::Nombre, Modulo::metodo"
PerlSetVar options "compress_threshold => 10000"

DESCRIPCIÓN

Este módulo Perl de Apache proporciona la capacidad de añadir soporte para el protocolo SOAP (Simple Object Access Protocol) con una fácil configuración (ya sea en el archivo .conf o en el archivo .htaccess). Esta funcionalidad debería proporcionarle una opción ligera para alojar servicios SOAP y simplificar en gran medida los aspectos de configuración. Este módulo hereda la funcionalidad del componente SOAP::Transport::HTTP::Apache del módulo SOAP::Lite.

CONFIGURACIÓN

El módulo se puede colocar en directivas <Location>, <Directory>, <Files>, <FilesMatch> en áreas de configuración principal del servidor o directamente en el archivo .htaccess.

Todos los parámetros deben ir entre comillas y pueden separarse con comas o espacios para listas ("a, b, c") y con 'flechas anchas' y comas para parámetros hash ("clave1 => valor1, clave2 => valor2").

Todas las opciones que puede encontrar en el componente SOAP::Transport::HTTP::Apache están disponibles para la configuración. Aquí se describe las más importantes.

dispatch_to (LISTA)
Especifica la ruta a un directorio que contiene los módulos Perl a los que desea dar acceso, o simplemente una lista de módulos (para módulos pre-cargados). 
PerlSetVar dispatch_to "/Tu/Ruta/A/Modulos/Desplegados, Modulo::Nombre, Modulo::metodo"
options (HASH)
Especifica una lista de opciones para su módulo, por ejemplo, el umbral de compresión. Las versiones futuras admitirán más opciones. Consulte la documentación de SOAP::Transport::HTTP para otras opciones. 
PerlSetVar options "compress_threshold => 10000"
