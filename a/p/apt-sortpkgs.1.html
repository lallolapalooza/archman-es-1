NOMBRE

apt-sortpkgs - Utilidad para ordenar archivos de índice de paquetes

SINOPSIS

apt-sortpkgs [-s] [-o=cadena_config] [-c=archivo_config] nombre_archivo... {-v | --version} {-h | --help}

DESCRIPCIÓN

apt-sortpkgs tomará un archivo de índice (índice fuente o índice de paquetes) y ordenará los registros para que estén ordenados por el nombre del paquete. También ordenará los campos internos de cada registro según las reglas de ordenamiento internas.

Toda la salida se envía a la salida estándar; la entrada debe ser un archivo buscable.

OPCIONES

Todas las opciones de línea de comandos se pueden establecer usando el archivo de configuración; las descripciones indican la opción de configuración a establecer. Para opciones booleanas, puedes anular el archivo de configuración usando algo como -f-,--no-f, -f=no o varias otras variaciones.

-s, --source

Usa el orden de campos del índice fuente. Ítem de configuración: APT::SortPkgs::Source.

-h, --help

Muestra un resumen de uso corto.

-v, --version

Muestra la versión del programa.

--audit

Muestra mensajes de auditoría (y de aviso). Esto anula la opción de silencio, pero solo para los mensajes de aviso, no para los de progreso.

-c, --config-file

Archivo de Configuración; Especifica un archivo de configuración a usar. El programa leerá el archivo de configuración por defecto y luego este archivo de configuración. Si se necesitan establecer configuraciones antes de que se analicen los archivos de configuración por defecto, especifica un archivo con la variable de entorno APT_CONFIG. Vea apt.conf(5) para información de sintaxis.

-o, --option

Establecer una Opción de Configuración; Esto establecerá una opción de configuración arbitraria. La sintaxis es -o Foo::Bar=bar. -o y --option se pueden usar múltiples veces para establecer diferentes opciones.

--cli-version

Solicita una versión CLI específica. Este es un patrón que toma una versión MAYOR.MENOR. Puedes omitir la versión MENOR, en cuyo caso se usará el último nivel menor compatible.

Las series de versiones se presentan de la siguiente manera: La versión 3.2 tiene versiones equivalentes 0.32, 1.22 y 2.12, implementando nuevas características para sus versiones mayores especificadas.

Un caso especial es el patrón de versión X.9: Una versión como 2.9 es seguida por 3.0, pero 2.10 sigue directamente a 2.8; dado que usamos números impares de versión como series de desarrollo (2.9 es la serie de desarrollo 3.0).

Esta característica se introdujo en APT 3.1.10 y reemplaza la configuración específica de binarios. Puedes usar APT::Version para un efecto similar en binarios más antiguos, por ejemplo, usa -o APT::Version=2 para que apt(8) se comporte como la serie 2.x.

El valor por defecto es la versión actual de APT para apt(8) y 0.(10 * mayor + menor) para los comandos clásicos. La serie 0.X está suavemente obsoleta y los otros comandos pasarán a la serie 2.x en el futuro.

--no-color, --color

Activa o desactiva los colores. Los colores están activados por defecto en terminales compatibles para apt(8) y también se pueden desactivar usando las variables de entorno NO_COLOR o APT_NO_COLOR, o configurarse adicionalmente mediante la opción de configuración APT::Color y su ámbito, vea apt.conf(5) para información sobre eso.

VER TAMBIÉN

apt.conf(5)

DIAGNÓSTICOS

apt-sortpkgs devuelve cero en operación normal, diez en caso de error.
