apk-info(8) Manual del Administrador del Sistema apk-info(8)

NOMBRE

apk info - imprime información detallada sobre paquetes

SINOPSIS

apk info [<opciones>...] paquetes...

apk info -W archivo

DESCRIPCIÓN

apk info imprime la información conocida sobre los paquetes listados. Por defecto, imprime la descripción, página web y tamaño instalado del paquete (equivalente a apk info -dws).

Cada campo impreso va precedido por el nombre del paquete y su versión, luego el campo a mostrar, y un salto de línea. Las siguientes líneas muestran la información apropiada, y luego una línea vacía termina ese campo.

apk info -W archivo imprime el paquete que posee el archivo especificado.

OPCIONES

Además de las opciones globales (ver apk(8)), y opciones de consulta (ver apk-query(8)), se admiten las siguientes opciones:

--all, -a

Lista toda la información conocida sobre el paquete.

--contents, -L

Lista los archivos incluidos en el paquete.

--depends, -R

Lista las dependencias del paquete.

--description, -d

Imprime la descripción del paquete.

--exists, --installed, -e

Comprueba el estado de instalación del paquete. Para cada paquete instalado, imprime su nombre. El estado de salida es el número de paquetes dados que no están instalados. Por lo tanto, se devuelve cero (o éxito) si todos los paquetes nombrados están instalados. NOTA: --installed está obsoleto y se eliminará para permitir que la misma opción en el grupo query funcione.

--install-if

Lista la regla install_if del paquete. Cuando se cumplan las dependencias de esta lista, el paquete se instalará automáticamente.

--license

Imprime el identificador de licencia SPDX del paquete.

--provides, -P

Lista lo que proporciona el paquete.

--rdepends, -r

Lista las dependencias inversas del paquete (todos los demás paquetes que dependen del paquete).

--replaces

Lista los otros paquetes para los que este paquete está marcado como reemplazo.

--rinstall-if

Lista otros paquetes cuyas reglas install_if se refieren a este paquete.

--size, -s

Imprime el tamaño instalado del paquete.

--triggers, -t

Imprime los triggers activos para el paquete.

--webpage, -w

Imprime la URL de la página web del paquete.

--who-owns, -W

Imprime el paquete que posee el archivo especificado.
