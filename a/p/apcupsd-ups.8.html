NOMBRE

apcupsd-ups - Controlador para acceso de cliente apcupsd

SINOPSIS

apcupsd-ups -h

apcupsd-ups -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del controlador apcupsd-ups. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

DESCRIPCIÓN

Este controlador es un cliente de apcupsd (otro proyecto de monitorización de SAI).

apcupsd-ups actúa como un cliente de apcupsd, simplemente reenviando datos. Esto puede ser útil en casos donde ambos protocolos son necesarios en una red, o en caso de que la base de código de apcupsd tenga un modo de acceso a SAI necesario que NUT no posea.

ARGUMENTOS ADICIONALES

Este controlador soporta las siguientes configuraciones opcionales en nut.conf(5):

port=<nombre_host>[:<puerto>]

Este es el nombre de un host remoto que ejecuta apcupsd (más un puerto opcional).

Por ejemplo:

[apcupsd]
        driver = apcupsd-ups
        port = localhost
        desc = "Cliente apcupsd"

ANTECEDENTES

Este controlador fue escrito originalmente en una noche para permitir la interoperación con apcupsd.

LIMITACIONES

El acceso a apcupsd es estrictamente de solo lectura: no se pueden emitir comandos. Esto se deriva del diseño de apcupsd, donde las configuraciones se cambian en apctest. Para ejecutar apctest, se debe detener apcupsd (y es apcupsd quien expone el SAI a la red y a este controlador de NUT como su cliente).

apcupsd-ups — Interfaz de línea de comandos para apcupsd

NAME

apcupsd-ups — Interfaz de línea de comandos para apcupsd

SYNOPSIS

apcupsd-ups [ opciones ]

DESCRIPTION

apcupsd-ups es una utilidad de línea de comandos que permite a los usuarios consultar la base de datos de eventos de apcupsd y obtener información sobre el estado de la UPS (SAI).

OPTIONS

-a
Muestra información detallada sobre los eventos de la UPS.
-c
Muestra el estado de la UPS.
-d
Muestra la tabla de eventos de la UPS.
-e
Muestra la información de la batería.
-h
Muestra la información de la carga.
-l
Muestra el registro de eventos.
-p
Muestra la información de la línea eléctrica.
-r
Reinicia la tabla de eventos.
-s
Muestra la información del estado de la UPS.
-t
Muestra la información de la temperatura.
-u
Muestra la información de la UPS.
-v
Muestra la versión de apcupsd.
-w
Muestra la información de la energía.

ENVIRONMENT

apcupsd-ups no utiliza ninguna variable de entorno.

EXIT STATUS

0 si la operación fue exitosa.

1 si ocurrió un error.

FILES

/var/log/apcupsd.events — Registro de eventos de apcupsd.

NOTES

apcupsd-ups debe ejecutarse como root o con los privilegios adecuados para acceder a la base de datos de eventos de apcupsd.

REPORTING BUGS

Por favor, informe de cualquier error a la lista de correo de apcupsd: apcupsd@apcupsd.org
