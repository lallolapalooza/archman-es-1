MÉTODOS

$cluster=ClusterSSH::Cluster->new();
Crea un nuevo objeto. El objeto debe ser común a todas las invocaciones.
$cluster->get_cluster_entries($filename);
Lee /etc/clusters, $HOME/.clusterssh/clusters y cualquier otro nombre de archivo dado y registra las etiquetas encontradas.
@external_tags=list_external_clusters()
Llama a un script externo usando "-L" para listar las etiquetas disponibles.
@resolved_tags=get_external_clusters(@tags)
Usa un script externo para resolver @tags en nombres de host.
$cluster->get_tag_entries($filename);
Lee /etc/tags, $HOME/.clusterssh/tags y cualquier otro nombre de archivo dado y registra las etiquetas encontradas.
$cluster->read_cluster_file($filename);
Lee el archivo de clúster dado y registra las etiquetas encontradas.
$cluster->expand_filename($filename);
Expande ~ o $HOME en un nombre de archivo.
$cluster->read_tag_file($filename);
Lee el archivo de etiquetas dado y registra las etiquetas encontradas.
$cluster->register_tag($tag,@hosts);
Registra el nombre de etiqueta dado con los nombres de host dados.
$cluster->register_host($host,@tags);
Registra el host dado en las etiquetas proporcionadas.
@entries = $cluster->get_tag('tag');
$entries = $cluster->get_tag('tag');
Recupera todas las entradas para la etiqueta dada. Devuelve una matriz de hosts o el número de hosts en la matriz dependiendo del contexto.
@tags = $cluster->list_tags();
Devuelve una matriz con todos los nombres de etiquetas disponibles.
%tags = $cluster->dump_tags();
Devuelve un hash con todos los datos de etiquetas.
@tags = $cluster->expand_glob( $type, $name, @items );
Utiliza la expansión de shell contra cada elemento en @items, donde $type es 'node' o 'tag' y $name es el nombre del nodo o etiqueta. Estos atributos se presentan al usuario en caso de un problema con la expansión para rastrear el origen.
