apk-index(8) Manual del Administrador del Sistema apk-index(8)

NOMBRE

apk index - crea el archivo de índice del repositorio a partir de paquetes

SINOPSIS

apk index [<opciones>...] paquetes...

DESCRIPCIÓN

apk index crea un índice de repositorio a partir de una lista de archivos de paquetes. Consulte apk-repositories(5) para obtener más información sobre los índices de repositorios.

Generalmente, el índice resultante debe firmarse criptográficamente antes de que apk lo acepte. Consulte abuild-sign(1) para obtener más detalles.

OPCIONES

--description, -d TEXTO

Añade una descripción al índice. En upstream, esto se utiliza para añadir información de versión basada en el SHA del commit de git del HEAD de aports en el momento de la generación del índice.

--index, -x ÍNDICE

Lee un índice existente de ÍNDICE para acelerar la creación del nuevo índice reutilizando datos cuando sea posible.

--merge

Fusiona paquetes en el ÍNDICE existente.

--no-warnings

Deshabilita la advertencia sobre dependencias faltantes. Esto ocurre cuando A depende del paquete B, que no tiene un proveedor en el repositorio indexado.

--output, -o ARCHIVO

Genera la salida del índice en ARCHIVO.

--prune-origin

Elimina paquetes del ÍNDICE existente con el mismo origen que cualquiera de los nuevos paquetes durante la fusión.

--rewrite-arch ARCH

Establece la arquitectura de todos los paquetes en ARCH.

ENTORNO

SOURCE_DATE_EPOCH

Se utiliza como tiempo de construcción para las cabeceras de los archivos tar en APKINDEX.tar.gz.
