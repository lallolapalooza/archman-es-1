NOMBRE

appletviewer - Ejecuta applets fuera de un navegador web.

SINOPSIS

appletviewer [opciones] url...
opciones
Las opciones de la línea de comandos separadas por espacios. Ver Opciones.
url
La ubicación de los documentos o recursos que se mostrarán. Puedes especificar múltiples URLs separadas por espacios.

DESCRIPCIÓN

El comando appletviewer se conecta a los documentos o recursos designados por urls y muestra cada applet referenciado por los documentos en su propia ventana. Si los documentos referidos por las urls no referencian ningún applet con las etiquetas OBJECT, EMBED o APPLET, entonces el comando appletviewer no hace nada. Para obtener detalles sobre las etiquetas HTML que soporta el comando appletviewer, consulta Etiquetas de AppletViewer en http://docs.oracle.com/javase/8/docs/technotes/tools/appletviewertags.html

El comando appletviewer requiere URLs codificadas según el mecanismo de escape definido en RFC2396. Solo se admiten URLs codificadas. Sin embargo, los nombres de archivo deben estar sin codificar, como se especifica en RFC2396.

Nota: El comando appletviewer está destinado únicamente a fines de desarrollo. Para más información, consulta Aplicaciones de Muestra/Prueba y Código en http://docs.oracle.com/javase/8/docs/technotes/samples/aboutCodeSamples.html

OPCIONES

-debug

Inicia el Applet Viewer en el depurador de Java con el comando jdb para depurar los applets del documento.
-encoding nombre-codificacion

Especifica el nombre de codificación del archivo HTML de entrada.
-Jjavaoption

Pasa la cadena javaoption como un solo argumento al intérprete de Java, que ejecuta el Applet Viewer. El argumento no debe contener espacios. Múltiples palabras de argumento deben comenzar todas con el prefijo -J. Esto es útil para ajustar el entorno de ejecución o el uso de memoria del compilador.
