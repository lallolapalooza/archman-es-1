apk-mkndx(8) Manual del Administrador del Sistema apk-mkndx(8)

NOMBRE

apk mkndx - crea un archivo de índice de repositorio apkv3 a partir de paquetes

SINOPSIS

apk mkndx [<opciones>...] paquetes...

DESCRIPCIÓN

apk mkndx crea un índice de repositorio a partir de una lista de archivos de paquetes. Consulte apk-repositories(5) para obtener más información sobre los índices de repositorios.

OPCIONES

--description, -d TEXTO

Añade una descripción al índice. En el upstream, se utiliza para añadir información de versión basada en el SHA del commit de git del HEAD de aports en el momento de la generación del índice.

--filter-spec PKGNAME_SPEC

Filtra solo el índice anterior. Cada argumento debe ser un nombre de paquete del tipo PKGNAME_SPEC para incluirlo en el índice. Esto se puede usar para crear un subconjunto de un índice existente.

--hash HASH

Usa HASH como algoritmo para la integridad de apk v3. Actualmente se admiten:
  • sha256 (predeterminado)
  • sha256-160

sha256-160 permite generar un índice compatible con versiones preliminares antiguas de apkv3 que no manejan hashes más largos correctamente.

--index, -x INDEX

Lee un índice existente de INDEX para acelerar la creación del nuevo índice reutilizando datos cuando sea posible.

--output, -o ARCHIVO

Saca el índice generado a ARCHIVO.

--pkgname-spec PKGNAME_SPEC

Especifica la especificación del nombre del paquete para descargar los paquetes. APK construirá la URL de descarga en relación con el archivo de índice expandiendo esta especificación con valores específicos del paquete.

Si la especificación contiene :// se considera una URL absoluta en lugar de relativa. Esto no se recomienda para repositorios públicos, ya que el uso de una especificación de nombre de paquete absoluto impediría la duplicación (mirroring). Sin embargo, esto es útil en el entorno de compilación para crear un subconjunto de un índice y hacer que se refiera a paquetes en otro repositorio.

Si no se especifica, el valor predeterminado será determinado por apk en tiempo de ejecución según cómo se haga referencia al repositorio:

  • ${arch}/${name}-${version}.apk si se hace referencia por la URL de la ruta base del repositorio
  • ${name}-${version}.apk si se hace referencia por la URL del archivo de índice del repositorio

Las variables de sustitución actualmente admitidas son:

  • name
  • version
  • arch
  • hash

Adicionalmente, se puede usar un prefijo de la variable con la sintaxis: ${name:4}. Esto trunca la sustitución a un máximo de 4 caracteres.

El escritor de la especificación debe asegurarse de que el repositorio no contenga varios paquetes que se expandirían al mismo nombre de archivo de paquete.
