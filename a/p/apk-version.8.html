NOMBRE

apk version - compara versiones de paquetes

SINOPSIS

apk version [<opciones>...] [paquetes...]

apk version -c versiones...

apk version -t version1 version2

apk version -I

DESCRIPCIÓN

apk version compara las versiones de los paquetes instalados con las versiones de paquetes disponibles en los repositorios (ver apk-repositories(5)). También se puede usar para validar y comparar cadenas de versión.

En el modo predeterminado, si no se especifican paquetes, se consideran todos los paquetes instalados. De lo contrario, la comparación se limita a los paquetes listados explícitamente. Se imprime un resumen en stdout, con la diferencia entre las versiones de los paquetes representada como >, = o <.

Las opciones -c, -I y -t son mutuamente excluyentes.

OPCIONES

Estas opciones solo se aplican al verificar las versiones de paquetes instalados contra los paquetes disponibles en los repositorios (cuando no se especifica ni -c, ni -t, ni -I).

--all, -a

Considera los paquetes de todas las etiquetas de repositorio.

--check, -c

Verifica la validez de las versiones. Si una versión dada no es válida, se imprime. Sale con un código de estado cero si todas las versiones son válidas, y no cero en caso contrario.

--indexes, -I

Imprime la versión y la descripción de cada índice de repositorio. Ver apk-repositories(5) para más información.

--limit, -l operando

Limita a los paquetes cuya salida coincida con el operando dado. El operando puede especificarse como cualquier combinación de >, = y <.

--test, -t

Compara dos cadenas de versión. No consulta la base de datos. Imprime uno de >, = o <, si version1 es, respectivamente, mayor que, igual a, o menor que version2.
