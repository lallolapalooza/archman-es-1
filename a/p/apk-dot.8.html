NOMBRE

apk dot - generar gráficos graphviz

SINOPSIS

apk dot [<opciones>...] [máscara-de-paquete...]

DESCRIPCIÓN

apk dot renderiza las dependencias de paquetes como gráficos graphviz.

El gráfico se genera para los paquetes que coinciden con las máscaras dadas, o para cada paquete conocido si no se especifica (esto generará un gráfico grande y difícil de manejar).

OPCIONES

Además de las opciones globales (ver apk(8)), y las opciones de consulta (ver apk-query(8)) se admiten las siguientes opciones:

--errors

Considerar solo paquetes con errores. Esto es útil para informar visualmente, por ejemplo, dependencias cíclicas y paquetes faltantes.
