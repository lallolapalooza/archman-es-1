AppConfig::CGI(3) Documentación de Contribución de Usuarios de Perl AppConfig::CGI(3)

NOMBRE

AppConfig::CGI - Módulo de Perl5 para procesar parámetros de scripts CGI.

SINOPSIS

use AppConfig::CGI;
my $state = AppConfig::State->new(\%cfg);
my $cgi   = AppConfig::CGI->new($state);
$cgi->parse($cgi_query);
$cgi->parse();               # busca la consulta CGI en el entorno

DESCRIPCIÓN

AppConfig::CGI es un módulo de Perl5 que implementa una interfaz CGI para AppConfig. Examina la variable de entorno QUERY_STRING, o una cadena pasada explícitamente como parámetro, que representa los parámetros adicionales pasados a una consulta CGI. Esto se utiliza para actualizar los valores de las variables en un objeto AppConfig::State en consecuencia.

AppConfig::CGI se distribuye como parte del paquete AppConfig.

DESCRIPCIÓN DETALLADA

USANDO EL MÓDULO AppConfig::CGI

Para importar y usar el módulo AppConfig::CGI, la siguiente línea debe aparecer en tu script de Perl:

use AppConfig::CGI;

AppConfig::CGI se utiliza automáticamente si usas el módulo AppConfig y creas un objeto AppConfig::CGI a través del método cgi(). AppConfig::CGI está implementado usando métodos orientados a objetos. Se crea y se inicializa un nuevo objeto AppConfig::CGI usando el método new(). Esto devuelve una referencia a un nuevo objeto AppConfig::CGI. Se debe pasar una referencia a un objeto AppConfig::State como primer parámetro:

my $state = AppConfig::State->new(); 
my $cgi   = AppConfig::CGI->new($state);

Esto creará y devolverá una referencia a un nuevo objeto AppConfig::CGI.

PROCESANDO CONSULTAS CGI

El método parse() se utiliza para procesar una consulta CGI que se puede especificar explícitamente, o se extrae automáticamente de la variable de entorno CGI "QUERY_STRING". Actualmente, esto limita el módulo a solo admitir el método GET.

Consulte AppConfig para obtener información sobre el uso del módulo AppConfig::CGI a través del método cgi().
