AppConfig::Args(3) Documentación de Perl aportada por el usuario AppConfig::Args(3)

NOMBRE

AppConfig::Args - Módulo de Perl5 para leer argumentos de línea de comandos.

SINOPSIS

use AppConfig::Args;
my $state   = AppConfig::State->new(\%cfg);
my $cfgargs = AppConfig::Args->new($state);
$cfgargs->parse(\@args);            # leer argumentos

RESUMEN

AppConfig::Args es un módulo de Perl5 que lee argumentos de línea de comandos y utiliza las opciones de estos para actualizar valores de variables en un objeto AppConfig::State.

AppConfig::File se distribuye como parte del paquete AppConfig.

DESCRIPCIÓN

USO DEL MÓDULO AppConfig::Args

Para importar y usar el módulo AppConfig::Args, la siguiente línea debería aparecer en tu script Perl:

use AppConfig::Args;

AppConfig::Args se utiliza automáticamente si usas el módulo AppConfig y creas un objeto AppConfig::Args a través del método parse().

AppConfig::File se implementa utilizando métodos orientados a objetos. Se crea y se inicializa un nuevo objeto AppConfig::Args utilizando el método new(). Esto devuelve una referencia a un nuevo objeto AppConfig::File. Se debe pasar una referencia a un objeto AppConfig::State como primer parámetro:

my $state   = AppConfig::State->new();
my $cfgargs = AppConfig::Args->new($state);

Esto creará y devolverá una referencia a un nuevo objeto AppConfig::Args.

ANÁLISIS DE ARGUMENTOS DE LÍNEA DE COMANDOS

El método parse() se utiliza para leer una lista de argumentos de línea de comandos y actualizar el ESTADO en consecuencia. Se debe pasar una referencia a la lista de argumentos.

$cfgargs->parse(\@ARGV);

Si el método se llama sin una referencia a una lista de argumentos, examinará y manipulará @ARGV.

Si la opción PEDANTIC está desactivada en el objeto AppConfig::State, cualquier error de análisis (variables inválidas, valores no validados, etc.) generará advertencias, pero no hará que el método devuelva. Tras haber procesado todos los argumentos, el método devolverá 1 si se procesó sin advertencias o 0 si se emitieron una o más advertencias. Cuando la opción PEDANTIC está activada, el método genera una advertencia y devuelve inmediatamente un valor de 0 tan pronto como encuentra cualquier error de análisis.

El método continúa analizando argumentos hasta que detecta el primero que no comienza con un guion (-). Los argumentos que constituyen valores para otras opciones no se examinan de esta manera.

DESARROLLO FUTURO

Este módulo se desarrolló para proporcionar compatibilidad hacia atrás (hasta cierto punto) con el módulo App::Config anterior. El análisis de argumentos que proporciona es básico pero ofrece una solución rápida y eficiente para aquellas ocasiones en las que solo se requiere un manejo simple de opciones.

Si requieres más flexibilidad en el análisis de argumentos de línea de comandos, deberías considerar usar el módulo AppConfig::Getopt. Este se carga y utiliza automáticamente al llamar al método getopt() de AppConfig.

El módulo AppConfig::Getopt proporciona una funcionalidad considerablemente extendida sobre el módulo AppConfig::Args al delegar la tarea de análisis de argumentos al módulo Getopt::Long de Johan Vromans. Para un análisis avanzado de la línea de comandos, este módulo (ya sea Getopt::Long por sí solo, o en conjunción con AppConfig::Getopt) es muy recomendable.
