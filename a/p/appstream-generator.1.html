NOMBRE

appstream-generator - Genera metadatos AppStream a partir de repositorios de distribución

SINOPSIS

appstream-generator [COMANDO]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando appstream-generator.

appstream-generator genera metadatos de catálogo AppStream a partir de los repositorios de una distribución de software. Actualmente soporta los siguientes formatos/distribuciones de repositorio: Debian, Ubuntu, Arch Linux, RPM-MD (Fedora, Mageia).

El generador producirá archivos de metadatos de catálogo AppStream en formato YAML o XML de AppStream para ser distribuidos a los usuarios, así como informes detallados en HTML sobre los componentes encontrados e informes en HTML y JSON sobre problemas detectados al compilar los metadatos. Lee archivos .desktop así como archivos de metainformación, renderiza fuentes, escala imágenes, almacena en caché capturas de pantalla, etc., para producir metadatos de alta calidad para centros de software basados en AppStream y otras herramientas. Normalmente, appstream-generator se integra con el flujo de trabajo existente de compilación y entrega de software de una distribución.

La herramienta appstream-generator se basa en la biblioteca libappstream para la conversión y análisis de metadatos. Si solo deseas incrustar el procesamiento de metadatos AppStream en otra herramienta, usar directamente libappstream es probablemente una mejor opción. La herramienta generadora realiza un trabajo pesado como renderizar fuentes y escalar imágenes, lo cual podría no ser necesario para casos simples.

Para usar appstream-generator, se requiere un archivo asgen-config.json. Su formato se describe en detalle en la documentación de asgen-config.json[1].

El generador soporta una amplia gama de características que pueden configurarse individualmente para adaptarse a las necesidades de diferentes proyectos y ajustar los metadatos generados a casos de uso específicos. Consulta la documentación del archivo de configuración para obtener información sobre las opciones disponibles.

Para obtener más información sobre el proyecto AppStream y los demás componentes que lo integran, consulta las páginas de AppStream en Freedesktop.org[2].

OPCIONES

run SUITE [SECCIÓN]

Procesa nuevos metadatos para la suite de distribución dada y los publica.

cleanup

Limpia archivos de medios y metadatos antiguos/expirados de la caché y los directorios. Se recomienda ejecutar este comando cada semana, o al menos una vez al mes, dependiendo de cuántos cambios ocurran en el repositorio de software.

publish SUITE [SECCIÓN]

Exporta todos los metadatos y publica informes en los directorios de exportación.

Normalmente no querrás ejecutar esta tarea explícitamente, ya que ya es realizada automáticamente por el comando run.

remove-found SUITE

Elimina todos los metadatos procesados válidos y las pistas de la suite seleccionada.

forget PKID

Elimina toda la información que tenemos sobre este ID de paquete (parcial).

Un ID de paquete consiste en un triplete de nombre/versión/arquitectura. Para este comando, la versión y la arquitectura pueden omitirse para olvidar todos los paquetes que coincidan con un nombre o combinación nombre-versión particular.

info PKID

Muestra la información asociada con este ID de paquete (completo).

Un ID de paquete consiste en un triplete de nombre/versión/arquitectura.

-w|--workspace DIR

Define la ubicación del espacio de trabajo.

Si se omite esta bandera y no se proporciona un directorio de espacio de trabajo en el archivo de configuración del generador, se asume el directorio actual como ubicación del espacio de trabajo.

Este parámetro, si se proporciona, anula cualquier ubicación de espacio de trabajo definida en otro lugar.

-c|--config FILE

Define un archivo de configuración.

Establece explícitamente un archivo JSON de configuración del generador. Si se omite esta bandera, se utiliza el archivo asgen-config.json en el directorio de espacio de trabajo actual.

Si no se define un directorio de espacio de trabajo en el propio archivo de configuración, el directorio en el que se encuentra se utiliza como espacio de trabajo. Esto puede ser anulado definiendo un espacio de trabajo explícitamente con -w.

--force

Fuerza la ejecución del comando.

--verbose

Muestra información de depuración adicional.

--version

Muestra el número de versión de appstream-generator.
