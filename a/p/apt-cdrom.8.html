DESCRIPCIÓ

N

apt-cdrom se utiliza para añadir un nuevo CD-ROM a la lista de fuentes disponibles de APT. apt-cdrom se encarga de determinar la estructura del disco, así como de corregir varios posibles errores de grabación y de verificar los archivos de

índice.

Es necesario usar apt-cdrom para añadir CD al sistema APT; no se puede hacer manualmente. Además, cada disco de un conjunto de varios CD debe insertarse y escanearse por separado para tener en cuenta posibles errores de

grabación.

A menos que se proporcione la opción -h o --help, debe estar presente uno de los siguientes

comandos.

ad

d
add se utiliza para añadir un nuevo disco a la lista de fuentes. Desmontará el dispositivo de CD-ROM, pedirá que se inserte un disco y luego procederá a escanearlo y copiar los archivos de índice. Si el disco no tiene un directorio .disk adecuado, se le pedirá un título descriptivo.

APT utiliza un ID de CD-ROM para rastrear qué disc

o está actualmente en la unidad y mantiene una bas
e de datos de estos ID en /var/lib/apt/cdroms.list

t

mar de la identidad del disco actual, a
sí como del nombre de archivo almacenado

OPCIONE

S

Todas las opciones de la línea de comandos se pueden establecer mediante el archivo de configuración; las descripciones indican la opción de configuración que se debe establecer. Para opciones booleanas, puede anular el archivo de configuración usando algo como -f-,--no-f, -f=no o varias otras

variaciones.

--no-auto-detect, --cdro

m
No intentar detectar automáticamente la ruta del CD-ROM. Normalmente se combina con la opción --cdrom. Elemento de configuración: Acquire::cdrom::
AutoDetect.

-d, --cdro

m
Punto de montaje; especifique la ubicación donde montar el CD-ROM. Este punto de montaje debe estar listado en /etc/fstab y configurado correctamente. Elemento de configuración: Acquire::cdrom::
mount.

-r, --renam

e
Renombrar un disco; cambiar la etiqueta de un disco o anular la etiqueta proporcionada para el disco. Esta opción hará que apt-cdrom pida una nueva etiqueta. Elemento de configuración: APT::CDROM::
Rename.

-m, --no-moun

t
No montar; impide que apt-cdrom monte y desmonte el punto de montaje. Elemento de configuración: APT::CDROM::
NoMount.

-f, --fas

t
Copia rápida; Asume que los archivos de paquetes son válidos y no comprueba cada paquete. Esta opción solo debe usarse si apt-cdrom se ha ejecutado antes en este disco y no detectó ningún error. Elemento de configuración: APT::CDROM::
Fast.

-a, --thoroug

h
Escaneo exhaustivo de paquetes; Esta opción puede ser necesaria con algunos discos antiguos de Debian 1.1/1.2 que tienen archivos de paquetes en lugares extraños. Tarda mucho más en escanear el CD, pero los encontrará
todos.

-n, --just-print, --recon, --no-ac

t
Sin cambios; No cambiar el archivo sources.list(5) y no escribir archivos de índice. Sin embargo, todo se comprueba igualmente. Elemento de configuración: APT::CDROM::
NoAct.

-h, --hel

p
Mostrar un breve resumen de
uso.

-v, --versio

n
Mostrar la versión del
programa.

--audi

t
Mostrar mensajes de auditoría (y de aviso). Esto anula la opción silencioso, pero solo para los mensajes de aviso, no para los de
progreso.

-c, --config-fil

e
Archivo de configuración; Especifique un archivo de configuración para usar. El programa leerá el archivo de configuración predeterminado y luego este archivo de configuración. Si es necesario establecer ajustes de configuración antes de que se analicen los archivos de configuración predeterminados, especifique un archivo con la variable de entorno APT_CONFIG. Véase apt.conf(5) para información sobre la
sintaxis.

-o, --optio

n
Establecer una opción de configuración; Esto establecerá una opción de configuración arbitraria. La sintaxis es -o Foo::Bar=bar. -o y --option se pueden usar varias veces para establecer diferentes
opciones.

--cli-versio

n
Solicita una versión específica de la CLI. Este es un patrón que toma una versión MAJOR.MINOR. Puede omitir la versión MINOR, en cuyo caso se usará el nivel menor más reciente admitido.

Las pistas de versión se presentan como sigue: La versión 3.2 tiene versiones equivalentes 0.32, 1.22 y 2.12, que implementan nuevas funciones para sus versiones principales

especificadas.

Un caso especial es el patrón de versión X.9: Una versión como 2.9 va seguida de 3.0, pero 2.10 sigue directamente a 2.8; dado que usamos números de versión impares como series de desarrollo (2.9 es la serie de desarrollo de 3.0)

.

Esta función se ha introducido en APT 3.1.10 y reemplaza la configuración específica del binario. Puede usar APT::Version para un efecto similar en binarios más antiguos; por ejemplo, use -o APT::Version=2 para hacer que apt(8) se comporte como la serie 2.

x.

El valor predeterminado es la versión actual de APT para apt(8) y 0.(10 * major + minor) para los comandos clásicos. La serie 0.X e

stá en desuso suave y los otros comand
os pasarán a la serie 2.x en el futuro.

--no-color, --colo

r
Activar o desactivar los colores. Los colores están activados de forma predeterminada en los terminales compatibles para apt(8) y también se pueden desactivar usando las variables de entorno NO_COLOR o APT_NO_COLOR, o configurarse más mediante la opción y el ámbito de configuración APT::Color; véase apt.conf(5) para obtener
informació
n sobre eso.
