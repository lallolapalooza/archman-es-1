AXFER-LIST(1) Manual de Comandos Generales AXFER-LIST(1)

NOMBRE

axfer-list - vuelca listas de dispositivos de sonido y nodos disponibles para transferir fotogramas de datos de audio.

SINOPSIS

axfer list dirección objetivo

dirección = capture | playback

objetivo = device | pcm

DESCRIPCIÓN

El subcomando list de axfer vuelca listas de nodos disponibles para transferir fotogramas de datos de audio. Por el momento, el subcomando es útil solo para el backend libasound del subcomando transfer.

OPCIONES

Dirección

capture
Opera para la transmisión de captura.
playback
Opera para la transmisión de reproducción.

Objetivo

device
Vuelca una lista de todas las tarjetas de sonido y dispositivos de audio digital disponibles en el backend libasound para el subcomando transfer.
pcm
Vuelca una lista de todos los nodos PCM disponibles en el espacio de configuración de alsa-lib en el backend libasound para el subcomando transfer.

COMPATIBILIDAD CON APLAY

Las opciones -l y --list-devices se manejan como operación device. Las opciones -L y --list-pcms se manejan como operación pcm.

VER TAMBIÉN

axfer(1), axfer-transfer(1), alsamixer(1), amixer(1)
