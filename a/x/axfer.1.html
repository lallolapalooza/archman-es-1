AXFER(1) Manual de Comandos Generales AXFER(1)

NOMBRE

axfer - grabador y reproductor de sonido por línea de comandos para dispositivos y nodos de sonido compatibles con el subsistema de sonido de Linux (Advanced Linux Sound Architecture, también conocido como ALSA).

SINOPSIS

axfer subcomando dirección opciones

subcomando = transfer | list | version | help

dirección = capture | playback

opciones = ( depende de subcomando )

DESCRIPCIÓN

axfer es un grabador y reproductor por línea de comandos para transferir tramas de datos de audio entre dispositivos/nodos de sonido y archivos/stdin/stdout.

OPCIONES

Subcomando

transfer
Realiza la transmisión de tramas de datos de audio. Su detalle se describe en el manual de axfer-transfer(1).
list
Muestra listas de dispositivos y nodos de sonido disponibles. Su detalle se describe en el manual de axfer-list(1).
version
Imprime la versión de esta aplicación (la misma versión que el paquete alsa-utils).
help
Imprime un breve mensaje sobre los subcomandos para que los usuarios ingresen a esta aplicación.

Dirección

capture
Opera para la transmisión de captura.
playback
Opera para la transmisión de reproducción.

ESTADO DE SALIDA

EXIT_SUCCESS (0) si el tiempo de ejecución finalizó correctamente, de lo contrario EXIT_FAILURE (1).

PRUEBA UNITARIA

Este programa tiene pruebas unitarias para la implementación interna. Por favor, consulte el manual de axfer-transfer para obtener más detalles.

COMPATIBILIDAD CON APLAY

axfer está diseñado para ser compatible con aplay(1) tanto como sea posible. En la línea de comandos, las ejecuciones de archivos aplay/arecord bajo $PATH ejecutan axfer en modo de compatibilidad si el sistema de archivos tiene un enlace simbólico de aplay/arecord a axfer.


$ ln -s aplay axfer
$ ln -s arecord axfer

Una cadena a la que apunta arg[0]

Cuando args[0] en tiempo de ejecución apunta a una cadena que termina con 'aplay', tiene el mismo significado que la dirección playback. Cuando apunta a una cadena que termina con 'arecord', tiene el mismo significado que la dirección capture.

Opciones reconocidas como subcomando list

Las opciones -l , --list-devices , -L , --list-pcms son reconocidas como el subcomando list. Sin ellas, el tiempo de ejecución realiza el subcomando transfer.

REPORTAR ERRORES

Reporte cualquier error a la lista de correo de la comunidad ALSA <alsa-devel@alsa-project.org>, donde se realiza principalmente el desarrollo y mantenimiento. También está disponible el servicio de seguimiento de errores del repositorio de alsa-utils en github.com.

VER TAMBIÉN
