IÓN

Axel es un programa que descarga un archivo de un servidor FTP o HTTP a través de múltiples conexiones. Cada conexión descarga

su propia parte del archivo.

A diferencia de la mayoría de los otros programas, Axel descarga todos los datos directamente al archivo de destino. Esto ahorra algo de tiempo al final porque el programa no tiene que concatenar todas las partes descargadas.

Axel soporta los protocolos HTTP, HTTPS, FTP

y FTPS.

NAME

axel - acelerador de descarga para Linux

SYNOPSIS

axel [OPCIONES] [URL...]

DESCRIPTION

Axel es un acelerador de descargas para Linux.

Su propósito es acelerar las descargas dividiendo un archivo en partes y descargando cada parte simultáneamente.

OPTIONS

Las siguientes opciones están disponibles:

-n, --num-connections=N
Especifica el número de conexiones para descargar simultáneamente. El valor predeterminado es 4.
-o, --output=FILE
Especifica el nombre del archivo de salida. Si no se especifica, el nombre del archivo se deducirá de la URL.
-s, --max-speed=SPEED
Especifica la velocidad máxima de descarga en bytes/segundo. El valor predeterminado es ilimitado.
-S, --alternate-output=DIR
Especifica un directorio alternativo para guardar los archivos descargados. Si no se especifica, el archivo se guardará en el directorio actual.
-a, --alternate-header
Muestra una línea de encabezado de progreso simple en lugar de la interfaz de progreso completa. Esto es útil para scripts.
-H, --header=HEADER
Inserta un encabezado arbitrario en la solicitud HTTP.
-U, --user-agent=AGENT
Especifica el agente de usuario a utilizar. El valor predeterminado es Axel.
-v, --verbose
Muestra información detallada sobre la descarga.
-q, --quiet
Suprime la salida normal.
-h, --help
Muestra el mensaje de ayuda y sale.
-V, --version
Muestra información sobre la versión y sale.

NOTE

Axel solo puede descargar archivos desde servidores HTTP y FTP. No admite HTTPS.

RETURN VALUE

0 si la descarga fue exitosa, 1 si ocurrió un error.

EXAMPLES

Descargar un archivo con 8 conexiones:

axel -n 8 http://example.com/file.zip

Descargar un archivo y guardarlo como "my_download.zip":

axel -o my_download.zip http://example.com/file.zip
