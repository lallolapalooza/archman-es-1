CAXPY

Propósito:

!>
!>    CAXPY multiplica una constante por un vector y lo suma a otro vector.
!>

Parámetros

N 
!>          N es ENTERO
!>         número de elementos en el(los) vector(es) de entrada
!>

CA

!>          CA es COMPLEJO
!>           Al entrar, CA especifica el escalar alfa.
!>

CX

!>          CX es un arreglo de COMPLEJOS, dimensión ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX es ENTERO
!>         espaciado de almacenamiento entre elementos de CX
!>

CY

!>          CY es un arreglo de COMPLEJOS, dimensión ( 1 + ( N - 1 )*abs( INCY ) )
!>

INCY

!>          INCY es ENTERO
!>         espaciado de almacenamiento entre elementos de CY
!>
