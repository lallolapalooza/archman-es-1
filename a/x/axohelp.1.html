NOMBRE

axohelp - programa auxiliar para el uso del paquete LaTeX axohelp2 con pdflatex.

SINOPSIS

axohelp [opciones] [nombre_archivo]

DESCRIPCIÓN

Axohelp es un programa que se utiliza con axodraw2, que es un paquete de LaTeX para dibujar grafos de Feynman (y algunos otros gráficos simples) en documentos de LaTeX.

Cuando se utiliza el paquete axodraw2 con pdflatex (o lualatex o xelatex) crea un archivo con la extensión .ax1. Este contiene las especificaciones de los elementos gráficos. Axohelp lo convierte a un archivo con la extensión ax2 que contiene el código pdf necesario. El archivo .ax2 es leído por pdflatex (etc) en su próxima ejecución, y el contenido del archivo .ax2 se utiliza en el archivo de salida .pdf final para dibujar los gráficos deseados.

Los archivos procesados se especifican de la siguiente manera: Cuando el nombre del archivo en la línea de comandos tiene el formato archivo.ax1, entonces el archivo de entrada es archivo.ax1 y el archivo de salida es archivo.ax2. Si el nombre del archivo en la línea de comandos no tiene la extensión .ax1, entonces se añade esta extensión.

OPCIONES

Las opciones pueden introducirse con uno o dos guiones. Las opciones posibles son:

-h, --help
Proporciona información de uso.
-v, --version
Proporciona información de la versión.
-V
NO IMPLEMENTADO ACTUALMENTE: Proporciona información sobre cada función utilizada.
