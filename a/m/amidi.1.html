AMIDI(1) Manual de Comandos Generales AMIDI(1)

NOMBRE

amidi - leer y escribir en puertos ALSA RawMIDI

SINOPSIS

amidi [-p puerto] [-s archivo | -S datos] [-r archivo] [-d] [-t segundos] [-a]

DESCRIPCIÓN

amidi es una utilidad de línea de comandos que permite recibir y enviar datos SysEx (system exclusive) desde/hacia dispositivos MIDI externos. También puede enviar otros comandos MIDI.

amidi solo maneja archivos que contienen comandos MIDI crudos, sin información de temporización. amidi no soporta archivos MIDI estándar (.mid), pero aplaymidi(1) y arecordmidi(1) sí lo hacen.

OPCIONES

Use las opciones -h, -V, -l, o -L para mostrar información; o use al menos una de las opciones -s, -r, -S, o -d para especificar qué datos enviar o recibir.

-h, --help
Ayuda: imprime una lista de opciones.
-V, --version
Imprime la versión actual.
-l, --list-devices
Imprime una lista de todos los puertos MIDI de hardware.
-L, --list-rawmidis
Imprime todas las definiciones RawMIDI. (utilizado al depurar archivos de configuración)
-p, --port=nombre
Establece el nombre del puerto ALSA RawMIDI a utilizar. Si no se especifica, amidi utiliza el puerto predeterminado definido en el archivo de configuración (el valor predeterminado para esto es el puerto 0 en la tarjeta 0, que puede no existir).
-s, --send=nombre_archivo
Envía el contenido del archivo especificado al puerto MIDI. El archivo debe contener comandos MIDI crudos (por ejemplo, un archivo .syx); para archivos MIDI estándar (.mid), use aplaymidi(1).
-r, --receive=nombre_archivo
Escribe los datos recibidos del puerto MIDI en el archivo especificado. El archivo contendrá comandos MIDI crudos (como en un archivo .syx); para grabar un archivo MIDI estándar (.mid), use arecordmidi(1).

amidi filtrará los bytes de Active Sensing y Clock (FEh, F8h), a menos que se hayan proporcionado las opciones -a o -c.

-S, --send-hex="..."
Envía los bytes especificados como números hexadecimales al puerto MIDI.
-d, --dump
Imprime los datos recibidos del puerto MIDI como bytes hexadecimales. Los bytes de Active Sensing y Clock (FEh, F8h) no se mostrarán, a menos que se hayan proporcionado las opciones -a o -c.

Esta opción es útil para la depuración.

-t, --timeout=segundos
Deja de recibir datos cuando no se han recibido datos durante el tiempo especificado.

Si esta opción no se ha proporcionado, deberá presionar Ctrl+C (o matar amidi) para dejar de recibir datos.

-a, --active-sensing
No ignora los bytes de Active Sensing (FEh) al guardar o imprimir comandos MIDI recibidos.
-c, --clock
No ignora los bytes de Clock (F8h) al guardar o imprimir comandos MIDI recibidos.
-i, --sysex-interval=milisegundos
Añade un retardo entre cada mensaje SysEx enviado a un dispositivo. Es útil al enviar actualizaciones de firmware mediante mensajes SysEx a un dispositivo remoto.

EJEMPLOS

amidi -p hw:0 -s mis_configuraciones.syx
enviará los comandos MIDI en mis_configuraciones.syx al puerto hw:0.
amidi -p hw:1,0,0 -s firmware.syx -i 100
enviará los comandos MIDI en firmware.syx al puerto hw:1,0,0 con un retardo de 100 milisegundos entre cada mensaje SysEx.
amidi -S 'F0 43 10 4C 00 00 7E 00 F7'
envía un XG Reset al puerto predeterminado.
amidi -p hw:1,2 -S F0411042110C000000000074F7 -r volcado.syx -t 1
envía una "Solicitud de Volcado de Parámetros" a un dispositivo GS, guarda los datos de parámetros recibidos en el archivo volcado.syx, y se detiene después de que el dispositivo haya terminado de enviar datos (cuando no se han recibido datos durante un segundo).
amidi -p virtual -d
crea un puerto RawMIDI virtual e imprime todos los datos enviados a este puerto.

ARCHIVOS

/usr/share/alsa/alsa.conf definiciones rawmidi predeterminadas
/etc/asound.conf definiciones rawmidi para todo el sistema
~/.asoundrc definiciones rawmidi específicas del usuario
