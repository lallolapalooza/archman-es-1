NAME

amixer - mezclador de línea de comandos para el controlador de sonido ALSA

SYNOPSIS

amixer [-option] [cmd]

DESCRIPTION

amixer permite el control de línea de comandos del mezclador para el controlador de sonido ALSA. amixer soporta múltiples tarjetas de sonido.

Ejecutar amixer sin argumentos mostrará las configuraciones actuales del mezclador para la tarjeta de sonido y el dispositivo por defecto. Esto es una buena manera de ver una lista de los controles de mezclador simple que puedes usar.

COMMANDS

help
Muestra la sintaxis.
info
Muestra la información sobre un dispositivo de mezclador.
scontrols
Muestra una lista completa de controles de mezclador simple.
scontents
Muestra una lista completa de controles de mezclador simple con sus contenidos.
set o sset <SCONTROL> <PARAMETER> ...
Establece el contenido del control de mezclador simple. El parámetro puede ser el volumen ya sea como un porcentaje desde 0% a 100% con el sufijo %, una ganancia en dB con el sufijo dB (como -12.5dB), o un valor exacto de hardware. La ganancia en dB solo puede usarse para los elementos del mezclador que tengan información de dB disponible. Cuando se añade la letra plus (+) o menos (-) después del valor de volumen, el volumen se incrementa o decrementa desde el valor actual, respectivamente.

Los parámetros cap, nocap, mute, unmute, toggle se utilizan para cambiar la captura (grabación) y el silencio para el grupo especificado.

Los modificadores opcionales se pueden poner como parámetros adicionales antes del valor para especificar la dirección del flujo o los canales a aplicar. Los modificadores playback y capture especifican el flujo, y los modificadores front, frontleft, frontright, frontcenter, center, rear, rearright, rearleft, woofer se utilizan para especificar los canales a cambiar.

Debe especificarse un control de mezclador simple. Solo se puede controlar un dispositivo a la vez.

get o sget <SCONTROL>
Muestra el contenido del control de mezclador simple.

Debe especificarse un control de mezclador simple. Solo se puede controlar un dispositivo a la vez.

controls
Muestra una lista completa de controles de tarjeta.
contents
Muestra una lista completa de controles de tarjeta con sus contenidos.
cset <CONTROL> <PARAMETER> ...
Establece el contenido del control de tarjeta. El identificador tiene estos componentes: iface, name, index, device, subdevice, numid. El siguiente argumento especifica el valor del control.
cget <CONTROL>
Muestra el contenido del control de tarjeta. El identificador tiene la misma sintaxis que para el comando cset.

COMANDOS AVANZADOS

sevents
Muestra los eventos para los controles de mezclador simple.
events
Muestra los eventos para los controles de mezclador.

OPCIONES

-c card

Selecciona el número de tarjeta a controlar. El nombre del dispositivo creado con este parámetro tiene la sintaxis 'hw:N' donde N es el número de tarjeta especificado.

-D device

Selecciona el nombre del dispositivo a controlar. El nombre de control por defecto es 'default'.

-s | --stdin

Lee desde el stdin y ejecuta el comando en cada línea secuencialmente. Cuando se da esta opción, el comando en los argumentos de línea de comandos se ignora.

Solo se aceptan sset y cset. Otros comandos se ignoran. Los comandos para IDs no coincidentes se ignoran sin errores también.

-h
Ayuda: muestra la sintaxis.
-q
Modo silencioso. No mostrar resultados de cambios.
-R
Usa el valor crudo para evaluar la representación de porcentaje. Este es el modo por defecto.
-M
Usa el volumen mapeado para evaluar la representación de porcentaje como alsamixer, para ser más natural para el oído humano.

EJEMPLOS

amixer -c 1 sset Line,0 80%,40% unmute cap
establecerá el volumen de entrada de línea izquierda de la segunda tarjeta de sonido al 80% y la derecha al 40%, la desilenciará y la seleccionará como fuente de captura (grabación).
amixer -c 1 -- sset Master playback -20dB
establecerá el volumen maestro de la segunda tarjeta a -20dB. Si el maestro tiene múltiples canales, todos los canales se establecerán con el mismo valor.
amixer -c 1 set PCM 2dB+
incrementará el volumen PCM de la segunda tarjeta en 2dB. Cuando existen tanto volumen de reproducción como de captura, esto se aplica a ambos volúmenes.
amixer -c 2 cset iface=MIXER,name='Line Playback Volume",index=1 40%
establecerá el volumen de reproducción de línea (segundo) de la tercera tarjeta de sonido al 40%
amixer -c 2 cset numid=34 40%
establecerá el elemento 34 de la tarjeta de sonido al 40%
