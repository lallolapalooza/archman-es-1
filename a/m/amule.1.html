AMULE(1) aMule AMULE(1)

NOMBRE

amule - el cliente p2p eMule multiplataforma

SINOPSIS

amule [-c <ruta>] [-geometry <geom>] [-o] [-r] [-w <ruta>] [-d] [-i] [-t <num>] [enlace eD2k]

amule [-v]

amule [-h]

DESCRIPCIÓN

[ -c <ruta>, --config-dir=<ruta> ]
Lee la configuración desde <ruta> en lugar del directorio personal.
[ -geometry <geom> ]
Establece la geometría de la aplicación. <geom> utiliza el mismo formato que las aplicaciones X11 estándar: [=][<ancho>{xX}<alto>][{+-}<desplazamiento_x>{+-}<desplazamiento_y>]
[ -o, --log-stdout ]
Imprime los mensajes de registro en la salida estándar.
[ -r, --reset-config ]
Restablece la configuración a los valores predeterminados.
[ -w <ruta>, --use-amuleweb=<ruta> ]
Especifica la ubicación del binario amuleweb en <ruta>.
[ -d, --disable-fatal ]
No maneja excepciones fatales.
[ -i, --enable-stdin ]
No deshabilita la entrada estándar.
[ -t, --category=<num> ]
Establece la categoría para los enlaces eD2k pasados a <num>
[ -v, --version ]
Muestra el número de versión actual.
[ -h, --help ]
Imprime una breve descripción del uso.
[ enlace eD2k ]
Añade un enlace eD2k al núcleo.

El enlace eD2k a añadir puede ser:

  • un enlace de archivo (ed2k://|file|...), se añadirá a la cola de descarga;
  • un enlace de servidor (ed2k://|server|...), se añadirá a la lista de servidores;
  • un enlace de lista de servidores, en cuyo caso todos los servidores de la lista se añadirán a la lista de servidores;
  • un enlace magnet.

NOTAS

Rutas

Para todas las opciones que toman un valor de <ruta>, si la ruta no contiene parte de directorio (es decir, solo un nombre de archivo simple), se considera que está dentro del directorio de configuración de aMule, ~/.aMule.

ARCHIVOS
