AMSYNTH(1) Comandos de usuario AMSYNTH(1)

NOMBRE

amsynth - un sintetizador de software sustractivo de dos osciladores

SINOPSIS

amsynth [opciones]

DESCRIPCIÓN

amsynth es un sintetizador de software fácil de usar con una topología de sintetizador sustractivo clásica.

OPCIONES

-h
muestra un mensaje de ayuda
-v
muestra información de la versión
-x
ejecuta en modo sin cabeza (sin GUI)
-b <archivo>
usa <archivo> como banco para almacenar preajustes
-t <archivo>
usa <archivo> como archivo de afinación
-a <cadena>
establece el controlador de salida de sonido a usar [alsa/oss/auto(predeterminado)]
-r <entero>
establece la frecuencia de muestreo a usar
-m <cadena>
establece el controlador MIDI a usar [alsa/oss/auto(predeterminado)]
-c <entero>
establece el canal MIDI al que responder (predeterminado=todos)
-p <entero>
establece la polifonía (voces activas máximas)
-n <nombre>
especifica el nombre del cliente JACK a usar
--jack_autoconnect <true|false>
conecta automáticamente los puertos de audio JACK a los puertos de E/S de hardware. (Predeterminado: true)
--force-device-scale-factor <escala>
establece el factor de escala a usar para el panel de control

ARCHIVOS

$XDG_CONFIG_HOME/amsynth/config
Configuración para amsynth.
$XDG_DATA_HOME/amsynth/banks/*
Bancos de preajustes del usuario.

ENTORNO

AMSYNTH_NO_GUI
Si AMSYNTH_NO_GUI está establecido, amsynth se inicia en modo sin cabeza (sin GUI).
AMSYNTH_SKIN
Especifica el directorio desde el cual amsynth debe cargar su skin.
GDK_SCALE
Especifica el factor de escala a usar para el panel de control.

ERRORES & SOLICITUDES DE CARACTERÍSTICAS

Si encuentras un error o deseas proponer una nueva característica, por favor repórtalo en https://github.com/amsynth/amsynth/issues .
