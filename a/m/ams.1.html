NOMBRE

ams - Sintetizador de software modular

SINOPSIS

ams [OPCIONES] [archivo]

DESCRIPCIÓN

El AlsaModularSynth (AMS) es un sintetizador de software diseñado a imagen de los grandes sintetizadores modulares analógicos de la década de 1960. Emplea voltajes de control (VC) virtuales para el control de parámetros de cada módulo, utilizando la escala de control logarítmica 1V/octava del sintetizador Moog para sus funciones de oscilador y filtro.

Siguiendo el modelo de sintetizador modular, AMS proporciona al usuario una variedad de módulos de software para la producción y el procesamiento de sonido, como osciladores digitales, filtros, amplificadores y efectos DSP. Estos módulos se enlazan (conectan) para crear complejas redes de síntesis de sonido. Estas redes de conexión pueden reproducirse en tiempo real a través de MIDI o estructuras de control internas, y pueden guardarse y recargarse a voluntad.

OPCIONES

Las opciones de tiempo de ejecución para AMS se muestran aquí con sus valores predeterminados entre corchetes.

--jack
Forzar E/S JACK
--in <num>
Número de puertos de entrada JACK
--out <num>
Número de puertos de salida JACK
--poly <num>
Polifonía [1]
--periodsize <frames>
Tamaño del período [1024]
--alsa
Forzar E/S ALSA
--frag <num>
Número de fragmentos [2]
--rate <samples/s>
Frecuencia de muestreo [44100]
--edge <0...10>
Borde VCO [1.0]
--soundcard <plug>
Tarjeta de sonido [plughw:0,0]
--preset <archivo>
Archivo de preset
--presetpath <ruta>
Ruta de presets
--nogui
Iniciar sin GUI
--name <nombre>
Nombre de cliente ALSASEQ/JACK, título de ventana

ARCHIVOS

Numerosos ejemplos y parches tutoriales se pueden encontrar en /usr/share/ams o /usr/local/share/ams.

La documentación tutorial está disponible en http://alsamodular.sourceforge.net/alsamodularsynth_doc.html.
