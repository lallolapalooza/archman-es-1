Para todas las opciones que toman un valor <path>, si la ruta no contiene parte de directorio (es decir, solo un nombre de archivo simple), entonces se considera que está bajo el directorio de configuración de aMule, ~/.a

Idioma

s

El parámetro <lang> para la opción -l tiene la siguiente forma: lang[_LANG][.encoding][@modifier] donde lang es el idioma principal, LANG es un subidioma/territorio, encoding es el juego de caracteres a usar y modifier permite al usuario seleccionar una instancia específica de datos de localización dentro de una sola

categoría.

Por ejemplo, las siguientes cadenas son

válidas:
de
de_DE
de_DE.iso88591
de_DE@euro
de_DE.
iso88591@euro

Aunque todas las cadenas anteriores se aceptan como definiciones de idioma válidas, encoding y modifier aún no se

usan.

Además del formato anterior, también puede especificar nombres completos de idioma en inglés - así que -l german también es válido y es igual a -l de_

DE.

Cuando no se define ningún locale, ya

sea en la línea de comandos o en el a
rchivo de configuración, se usará
el idioma predeterminado del sistema.
