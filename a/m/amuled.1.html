NOMBRE

amuled - el cliente p2p eMule multiplataforma - versión demonizada

SINOPSIS

amuled [-c <ruta>] [-f] [-p <ruta>] [-e] [-o] [-r] [-w <ruta>] [-d] [-i] [-t <núm>] [enlace-eD2k]

amuled [-v]

amuled [-h]

DESCRIPCIÓN

[ -c <ruta>, --directorio-config=<ruta> ]
Leer la configuración de <ruta> en lugar del directorio personal
[ -f, --demonio-completo ]
Se bifurca a segundo plano.
[ -p <ruta>, --archivo-pid=<ruta> ]
Después de bifurcarse, crea un archivo pid en <ruta>. <ruta> debe contener el nombre del archivo.
[ -e, --config-ec ]
Configurar EC (Conexiones Externas).
[ -o, --salida-log ]
Imprime mensajes de registro en la salida estándar.
[ -r, --restablecer-config ]
Restablece la configuración a los valores predeterminados.
[ -w <ruta>, --usar-amuleweb=<ruta> ]
Especifica la ubicación del binario amuleweb en <ruta>.
[ -d, --deshabilitar-fatal ]
No maneja excepciones fatales.
[ -i, --habilitar-stdin ]
No deshabilita la entrada estándar.
[ -t, --categoria=<núm> ]
Establece la categoría para los enlaces eD2k pasados a <núm>
[ -v, --version ]
Muestra el número de versión actual.
[ -h, --help ]
Imprime una breve descripción del uso.
[ enlace-eD2k ]
Añade un enlace eD2k al núcleo.

El enlace eD2k a añadir puede ser:

  • un enlace de archivo (ed2k://|file|...), se añadirá a la cola de descargas;
  • un enlace de servidor (ed2k://|server|...), se añadirá a la lista de servidores;
  • un enlace de lista de servidores, en cuyo caso todos los servidores de la lista se añadirán a la lista de servidores;
  • un enlace magnético.
