NOMBRE

amulegui - programa de control de aMule con interfaz gráfica

SINOPSIS

amulegui [-c <ruta>] [-geometry <geom>] [-o] [-r] [-s] [-t <núm>]

amulegui [-v]

amulegui [-h]

DESCRIPCIÓN

amulegui es un programa cliente y puede conectarse a amule o amuled a través de EC. Puedes administrar tu programa amule con él. Proporciona casi las mismas funcionalidades que amule, incluso si el núcleo funciona en otra computadora.

[ -c <ruta>, --config-dir=<ruta> ]
Lee la configuración desde <ruta> en lugar del directorio personal.
[ -geometry <geom> ]
Establece la geometría de la aplicación. <geom> usa el mismo formato que las aplicaciones estándar de X11: [=][<ancho>{xX}<alto>][{+-}<desplazamiento_x>{+-}<desplazamiento_y>]
[ -o, --log-stdout ]
Imprime mensajes de registro en la salida estándar.
[ -r, --reset-config ]
Restaura la configuración a los valores predeterminados.
[ -s, --skip ]
Omite el diálogo de conexión.
[ -t, --category=<núm> ]
Establece la categoría para los enlaces eD2k pasados a <núm>
[ -h, --help ]
Imprime una breve descripción de uso.
[ -v, --version ]
Muestra el número de versión actual.
