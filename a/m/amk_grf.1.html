amk_grf(1) Manual de usuario de Scotch amk_grf(1)

NOMBRE

amk_grf - crear una arquitectura de destino a partir de un grafo fuente

SINOPSIS

amk_grf [opciones] [gfile] [tfile]

DESCRIPCIÓN

El programa amk_grf construye una arquitectura de destino definida por descomposición tfile a partir de un grafo fuente gfile.

Las arquitecturas de destino definen la topología de los grafos de destino utilizados por los programas de mapeo estático gmap(1) y dgmap(1). Las arquitecturas de destino pueden ser definidas algorítmicamente, para topologías comunes y regulares, o definidas por descomposición, como las producidas por amk_grf.

Cuando las bibliotecas adecuadas se han incluido en tiempo de compilación, amk_grf puede manejar directamente archivos comprimidos, tanto como entrada como salida. Un flujo se trata como comprimido siempre que su nombre tenga el sufijo de una extensión de archivo comprimido, como en 'brol.tgt.bz2' o '-.gz'. Los formatos de compresión que pueden ser soportados son el formato bzip2 ('.bz2'), el formato gzip ('.gz') y el formato lzma ('.lzma').

Dado que los archivos de arquitectura de destino definidos por descomposición tienen un tamaño cuadrático en el número de vértices de destino, debido a la presencia de una estructura de matriz de distancias, el uso de archivos comprimidos para almacenarlos puede ahorrar mucho espacio.

OPCIONES

-b?strat
Aplicar la estrategia de bipartición strat para calcular la bipartición recursiva del grafo fuente completo en subdominios de destino más pequeños.
-h
Mostrar ayuda.
-l?lfile
Conservar solo los vértices cuyos índices pertenecen a la lista separada por espacios almacenada en lfile. Esto permite crear arquitecturas de destino que pueden ser incluso subconjuntos disjuntos de una arquitectura de destino más grande, modelada como un grafo.
-V
Mostrar la versión del programa y los derechos de autor.

EJEMPLO

Crear una arquitectura de destino definida por descomposición a partir de un grafo fuente de malla regular 2D de dimensión 3x5, y guardarla, como una arquitectura de destino compilada, en formato gzip(1), en el archivo 'm3x5.tgt.gz'.

    $ gmk_m2 3 5 | amk_grf | acpl - m3x5.tgt.gz
Nótese que, en este caso particular, sería mucho más preferible usar directamente la arquitectura de destino definida algorítmicamente 'mesh2D'. 
    $ echo "mesh2D 3 5" > m3x5.tgt
