aerc-binds - formato del archivo de configuración de atajos de teclado para aerc(

1
)

SINOPSI

S

El archivo binds.conf se utiliza para configurar los atajos de teclado utilizados en el cliente interactivo aerc. Se espera que esté en tu directorio de configuración XDG más aerc, que por defecto es ~/.config/aerc/binds.conf. Si el archivo no existe, se instalará la configuración predeterminada incorporada. Un archivo alternativo se puede especificar mediante el argumento de línea de comandos --binds-conf, ver aerc(

1).

Este archivo está escrito en formato ini con los atajos de teclado definidos

como:
<secuencia de teclas> = <comando
>

Donde <secuencia de teclas> son las pulsaciones de teclas (en orden) para invocar este atajo de teclado, y <comando> especifica las pulsaciones de teclas que aerc simulará cuando se invoque el atajo. Generalmente se usa para ejecutar comandos, por

ejemplo:
rq = :reply
-q<Enter>

Pulsando r, y luego q, se simulará la escritura de :reply -q<Enter>, y se ejecutará :reply -q en consecuencia. También es posible invocar atajos de teclado de forma recursiva de manera

similar.

Puedes configurar diferentes atajos de teclado para diferentes contextos escribiéndolos en diferentes [secciones] de

l archi
vo ini.

Los contextos disponibles

passthrough]

)

[compose

atajos de teclado para el compositor de
mensajes

[compose::

atajos de teclado para el compositor, cuando el editor está
enfocado

[compose::

review]
atajos de teclado para el compositor, al revisar el correo electrónico antes de que se envíe

Para personalizar la descripción mostrada en la pantalla de revisión, añade un comentario (" # ") al final del atajo.

Ejemplo:
p = :postpone<Enter> # Lo trabajaré más
tarde

El orden en que se definen los atajos se conserva en la pantalla de revisión. Si un atajo no predeterminado no está anotado, se mostrará sin ninguna

descripción.

Para ocultar un atajo de la pantalla de revisión, anótalo explícitamente con un comentario " # -".

Ejemplo:
<C-e> = :encrypt<Enter>
#
-

[terminal

]
atajos de teclado para las pestañas de
terminal

También puedes configurar atajos de teclado específicos de la cuenta para cada

contexto:

[context:account=AccountName

]
atajos de teclado para este contexto y cuenta, donde AccountName es una expresión regular que coincide con el nombre de cuenta que proporcionaste en accounts.
conf.

Se pueden configurar atajos específicos de carpeta y contexto para las listas de

mensajes:

[messages:folder=FolderName]
[view:folder=FolderName]
[compose:folder=FolderName]
[compose::editor:folder=FolderName]
[compose::review:folder=FolderName

]
los atajos bajo esta sección serán específicos de la carpeta que coincida con la expresión regular FolderName. Los atajos de una especificación de carpeta
tendrán prioridad sobre la
s especificaciones de cuenta

[compose::editor:account=Mailbox2]
[compose::editor:folder=aerc]
y = :send -t aerc
[messages:folder=Drafts]
<Enter> = :recall<Enter>
[messages:folder=Archive/d+/.*]
gi = :cf Inbox<Enter>
.
.
.

También puedes configurar atajos de teclado globales colocándolos al principio del archivo, antes de especificar cualquier sección específica de

contexto.

"vacío":

OPCIONES

ESPECIALES

Además de las secuencias de teclas definidas por el usuario, las siguientes opciones especiales están disponibles en cada contexto de

atajo:

$noinherit = true|fals

e
Si se establece en true, los atajos de teclado globales no serán efectivos en este contexto.

Predeterminado: fa

l
se

$ex = <pulsación de

tecla>
Se puede establecer en una pulsación de tecla que abrirá la entrada de comandos en este contexto.

Predeterminado:

:

$complete = <pulsación de

tecla>
Se puede establecer en una pulsación de tecla que activará la finalización de comandos en este contexto para entradas de texto que lo admitan.

Predeterminado: <tab

>

Nota: la finalización automática de comandos se desactiva al simular pulsaciones de teclas y se vuelve a activar al final. Cuando [ui].completion-min-chars está establecido en manual (ver aerc-config(5)), es posible terminar un atajo con la tecla de finalización para mostrar explícitamente el menú de finalización. Ej.

:
o = :cf<
spac
e><
tab>

es:

>

Donde C es control, A es alt, S es shift, y tecla es la tecla con nombre o el

carácter.
