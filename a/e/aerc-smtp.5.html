NOMBRE

aerc-smtp - Configuración SMTP para aerc(1)

SINOPSIS

aerc implementa el protocolo SMTP según lo especificado por RFC 5321.

CONFIGURACIÓN

La configuración básica de SMTP se puede realizar interactivamente con el comando :new-account.

En accounts.conf (ver aerc-accounts(5)), las siguientes opciones específicas de SMTP están disponibles:

outgoing = <esquema>[+<autenticación>]://<nombreusuario>[:<contraseña>]<servidor>[:<puerto>]?[<parámetros_oauth2>]

Recuerda que todos los campos deben estar codificados en URL. El símbolo @, cuando está codificado en URL, es %40.

El valor de <esquema> puede ser:

smtp

SMTP con STARTTLS

smtp+insecure

SMTP sin STARTTLS

smtps

SMTP con TLS/SSL

Además, puedes especificar un mecanismo de autenticación así:

none

No se requiere autenticación para usar este servidor SMTP. Puedes omitir el nombre de usuario y la contraseña en este caso.

plain

Autenticarse con un nombre de usuario y contraseña usando AUTH PLAIN. Este es el comportamiento predeterminado.

login

Autenticarse con un nombre de usuario y contraseña usando AUTH LOGIN. Este es un protocolo obsoleto, pero es requerido para algunos proveedores comunes de webmail.

oauthbearer

SMTP con TLS/SSL usando autenticación OAUTHBEARER. Consulta la documentación en aerc-imap(5) para su uso.

xoauth2

SMTP con TLS/SSL usando autenticación XOAUTH2. Consulta la documentación en aerc-imap(5) para su uso.

outgoing-cred-cmd = <comando>

Especifica el comando a ejecutar para obtener la contraseña de la cuenta SMTP. Este comando se ejecutará usando sh -c [comando]. Si se especifica una contraseña en la opción outgoing, la contraseña tendrá prioridad sobre este comando.

Ejemplo:

outgoing-cred-cmd = pass hostname/username

smtp-domain = <dominio>

Nombre de dominio local a usar en el comando SMTP HELO/EHLO. Configúralo como un nombre de dominio completamente calificado si el servidor lo requiere como medida antispam.

Predeterminado: localhost
