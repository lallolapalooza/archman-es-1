NOMBRE

aerc-templates - especificación de archivos de plantilla para aerc(1)

SINOPSIS

aerc utiliza el paquete go text/template para el análisis de plantillas. Consulte la documentación de go text/template para la sintaxis general. La sintaxis de plantilla descrita a continuación se puede utilizar para archivos de plantillas de mensajes y para el formato dinámico de algunas aplicaciones de la interfaz de usuario.

Los archivos de plantilla se componen de encabezados, seguidos de un salto de línea, seguidos del texto del cuerpo.

Ejemplo:

X-Clacks-Overhead: GNU Terry Pratchett
Hola,
Saludos,
Chuck

Si tiene una plantilla que no agrega ningún encabezado, debe estar precedida por un salto de línea, para evitar el análisis de partes del cuerpo como texto de encabezado.

Todos los encabezados definidos en la plantilla tendrán prioridad sobre cualquier encabezado que sea inicializado por aerc (por ejemplo, Asunto, Para, De, Cc) al componer un nuevo mensaje, reenviar o responder.

DATOS DEL MENSAJE

Los siguientes datos se pueden utilizar en las plantillas. Aunque no todos están disponibles siempre.

Direcciones

Una matriz de mail.Address. Que se puede usar para agregar nombres de remitente o destinatario a la plantilla.
  • {{.From}}: Lista de remitentes.
  • {{.Peer}}: Lista de remitentes o destinatarios A si el mensaje es suyo.
  • {{.To}}: Lista de destinatarios A. No siempre disponible.
  • {{.ReplyTo}}: Lista de destinatarios de respuesta. No siempre disponible.
  • {{.Cc}}: Lista de destinatarios Cc. No siempre disponible.
  • {{.Bcc}}: Lista de destinatarios Cc. No siempre disponible.
  • {{.OriginalFrom}}: Lista de remitentes del mensaje original. Disponible para respuesta y reenvío citados.

Ejemplo:

Obtener el nombre del primer remitente.

{{(index .From 0).Name}}
{{index (.From | names) 0}}

Obtener la dirección de correo electrónico del primer remitente.

{{(index .From 0).Address}}

Fecha y Hora

La información de fecha y hora siempre está disponible y se puede formatear fácilmente.
  • {{.Date}}: Información de fecha y hora cuando se abre la ventana de redacción.
  • {{.OriginalDate}}: Fecha y hora en que se recibió el mensaje original. Disponible para respuesta y reenvío citados.

Para formatear los campos de fecha, se proporcionan dateFormat y .Local. Consulte la sección FUNCIONES DE PLANTILLA para obtener detalles.

Asunto

El asunto del correo electrónico (ThreadPrefix estará vacío a menos que el encadenamiento esté habilitado). 
{{.ThreadPrefix}}{{if .ThreadFolded}}{{printf "{%d}" .ThreadCount}}{{end}}{{.Subject}}

El asunto del correo electrónico despojado de cualquier prefijo Re: y Fwd:.

{{.SubjectBase}}
Encadenamiento
Cuando el encadenamiento está habilitado, estos atributos están disponibles en la lista de mensajes:

ThreadPrefix

Si el mensaje es parte de un hilo, contendrá flechas que representan el árbol del mensaje basado en los encabezados In-Reply-To y References.

ThreadFolded

Será true si el mensaje tiene hijos de hilo que están ocultos por :fold.

ThreadCount

El número de mensajes en el hilo.

ThreadUnread

El número de mensajes no leídos en el hilo.

Banderas

Lista de banderas de mensajes, no disponible al redactar, responder ni reenviar. Esta es una lista de cadenas que se pueden convertir en una sola cadena con join. 
{{.Flags | join ""}}

IsReplied, IsForwarded, HasAttachment, IsFlagged, IsRecent, IsUnread, IsMarked, IsDraft

Banderas booleanas individuales. no disponible al redactar, responder ni reenviar. 
{{if .IsFlagged}}★{{end}}

Etiquetas

Etiquetas de mensajes (por ejemplo, etiquetas de notmuch). No disponible al redactar, responder ni reenviar. Esta es una lista de cadenas que se pueden convertir en una sola cadena con join. 
{{.Labels | join " "}}

Tamaño

El tamaño del mensaje en bytes. No disponible al redactar, responder ni reenviar. Se puede formatear con humanReadable. 
{{.Size | humanReadable}}

Nombre de archivo

La ruta completa del archivo del mensaje. No disponible al redactar, responder ni reenviar. Para el backend de notmuch, devuelve un nombre de archivo aleatorio si hay varios archivos asociados con el mensaje.

Nombres de archivo

Una lista de las rutas completas de los archivos asociados con el mensaje. Para maildir, siempre es una lista con un solo elemento. No disponible al redactar, responder ni reenviar.

Cualquier valor de encabezado

Cualquier valor de encabezado del correo electrónico. 
{{.Header "x-foo-bar"}}

Cualquier valor de encabezado del mensaje original reenviado o respondido:

{{.OriginalHeader "x-foo-bar"}}
Message-ID
El Message-ID del mensaje. 
:term b4 am {{.MessageId}}

Tipo MIME

La información del tipo MIME está disponible para respuesta y reenvío citados.
•
{{.OriginalMIMEType}}: Información del tipo MIME de la parte del correo citada. Generalmente text/plain o text/html.

Mensaje Original

Al usar respuesta o reenvío citado, el mensaje original está disponible en un campo llamado OriginalText. 
{{.OriginalText}}

Firma

La firma de la cuenta actualmente seleccionada obtenida de signature-file o signature-cmd. 
{{.Signature}}

El nombre de la cuenta actual: 
{{.Account}}

{{.AccountBackend}}

{{.AccountFrom}}
{{.AccountFrom.Address}}

Carpeta del buzón de correo actualmente seleccionada:

{{.Folder}}

Conteo de mensajes actual para todas las carpetas:

{{.Recent}} {{.Unread}} {{.Exists}}
{{.RUE}}

El estado del nuevo mensaje para la cuenta. Los mensajes nuevos son aquellos que han llegado desde que la pestaña de la cuenta tuvo foco por última vez. La bandera actualmente solo se establece cuando aerc se está ejecutando en el momento de la llegada, es decir, los mensajes que llegaron mientras aerc no se estaba ejecutando no se indicarán.

{{.HasNew}}

El rol IANA del buzón, convertido a minúsculas:

{{.Role}}

aerc implementa dos roles personalizados adicionales: Se otorga un rol de 'consulta' a las carpetas de un mapa de consulta de notmuch y 'virtual' indica un nodo virtual en la lista del árbol de directorios:

{{if eq .Role "query"}}{{...}}{{else}}{{...}}{{end}}
