AERC-MAILDIR(5) Manual de formatos de archivo AERC-MAILDIR(5)

NOMBRE

aerc-maildir - configuración de maildir para aerc(1)

SINOPSIS

aerc implementa el formato maildir.

CONFIGURACIÓN

La configuración básica de Maildir se puede realizar interactivamente con el comando :new-account.

Las siguientes opciones específicas de maildir están disponibles:

check-mail-cmd = <comando>

Comando a ejecutar junto con la opción check-mail.

Ejemplo:

check-mail-cmd = mbsync -a

check-mail-timeout = <duración>

Tiempo de espera para check-mail-cmd. El comando se detendrá si no se completa en este intervalo y se mostrará un error. Aumente el valor predeterminado si se producen errores repetidos.

Predeterminado: 10s

source = maildir|maildirpp://<ruta>

El source indica la ruta al directorio que contiene sus maildirs en lugar de un maildir específico.

La porción de la ruta de la URL después de maildir:// debe ser una ruta absoluta precedida por / o una ruta relativa a su directorio de inicio precedida por ~. Por ejemplo:

source = maildir:///home/yo/mail

source = maildir://~/mail

Si su maildir utiliza el diseño de directorio Maildir++, puede usar el esquema maildirpp:// en su lugar:

source = maildirpp:///home/yo/mail

source = maildirpp://~/mail
