Este

módulo documenta la nueva y más simple API de AnyEvent. La razón de ser de la nueva API es que la experiencia con EV muestra que esta API realmente "funciona", a pesar de su

falta

de extensibilidad, lo que conduce a una API más corta, más fácil y más rápida. Las principales diferencias con AnyEvent es que se

usan

llamadas a funciones en lugar de llamadas a métodos, y que no se usan argumentos con nombre. Esto hace que las llamadas a las funciones de creación de observadores sean realmente cortas, lo que puede hacer que un programa sea más legible a pesar de la falta de

parámetros

con nombre. Las llamadas a funciones también permiten una verificación de tipos estática más estricta que las llamadas a métodos, de modo que muchos errores se detectan en tiempo de compilación con esta API. Además,

algunos

backends (Perl y EV) son tan rápidos que la sobrecarga de la llamada al método es muy notable (con EV aumenta el tiempo de ejecución cinco o seis veces, con Perl la sobrecarga de la llamada al método es de aproximadamente un

factor

de dos). Tenga en cuenta que la API "AE" es una alternativa a, no la versión futura de, la API de AnyEvent. Ambas APIs pueden usarse indistintamente y no hay planes para "cambiar", así que si tiene dudas, siéntase libre de

usar

la API de AnyEvent en código nuevo. Dado que la API AE es complementaria, no todo en la API de AnyEvent está disponible, y aún necesita usar

AnyEvent

par

a

las cosas más detalladas. Además, no debería "use AE" directamente, "use AnyEvent" proporcionará el espacio de nombres AE. En este momento, estas funciones se volverán más lentas que sus contrapartidas de llamada a método al usar AnyEvent::Strict o AnyEvent::Debug::wrap.
