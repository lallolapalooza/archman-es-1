COMANDOS EN TIEMPO DE

EJECUCIÓN

Para ejecutar un comando, presiona : para abrir la interfaz de comandos. Los comandos también pueden asignarse a teclas, ver aerc-binds(5) para más detalles. En algunos contextos, como el emulador de terminal, <c-x> se usa para abrir la interfaz de

comandos.

Diferentes comandos funcionan en diferentes contextos, dependiendo del tipo de pestaña que hayas

seleccionado.

Los argumentos dinámicos se expanden siguiendo aerc-templates(7) dependiendo del contexto. Por ejemplo, si tienes un mensaje seleccionado, el siguiente

comando: 
:filter -f "{{index (.From | emails) 0}
}
"

Filtrará todos los mensajes enviados por el mismo

remitente.

Aerc almacena un historial de comandos, por el que se puede navegar en el modo de comandos. Presionando la tecla arriba se retrocede en el historial, mientras que presionando abajo se

avanza.

:menu [-c "<shell-cmd>"] [-e] [-b] [-a] [-d] [-t "<título>"] <aerc-cmd ...>

Abre un cuadro de diálogo emergente ejecutando sh -c "<shell-cmd>" (si no se especifica, se usará [general].default-menu-cmd). Cuando el comando finaliza, todas las líneas impresas en su salida estándar se agregarán a <aerc-cmd ...> y se ejecutarán como un comando aerc estándar como lo haría xargs(1) cuando se usa en un shell. Se admite un prefijo de dos puntos (:) para <aerc-cmd ...>, pero no es obligatorio.

:menu se puede usar sin un programa externo estableciendo <shell-cmd> a -. Esto también actúa como una alternativa en los casos en que no se especificó ningún <shell-cmd> o no se encontró el ejecutable en <shell-cmd>.

-c "<shell-cmd>"

Anula [general].default-menu-cmd. Ver aerc-config(5) para más detalles.

-e: Detiene la ejecución de comandos ante el primer error.

-b: **NO** inicia el cuadro de diálogo emergente. Inicia los comandos en segundo plano ( **NO** en un terminal virtual). Usa esto si <shell-cmd> es una aplicación gráfica que no necesita un terminal.

-t: Anula el título del cuadro de diálogo (de lo contrario, se deriva de <shell-cmd>)

<shell-cmd> puede recibir texto de entrada utilizando las siguientes banderas:

-a: Todos los nombres de cuentas, una por línea. Por ejemplo:
'<cuenta>' LF

-d: Todos los nombres de directorios de cuentas actuales, una por línea. Por ejemplo:

'<directorio>' LF

-ad: Todos los directorios de todas las cuentas, una por línea. Por ejemplo:

'<cuenta>' '<directorio>' LF

Aerc puede agregar comillas cuando los tokens contienen caracteres especiales. Las comillas deben conservarse para <aerc-cmd ...>.

Ejemplos:

:menu -adc fzf :cf -a
:menu -c 'fzf --multi' :attach
:menu -dc 'fzf --multi' :cp
:menu -bc 'dmenu -l 20' :cf
:menu -c 'ranger --choosefiles=%f' :attach

Esto también se puede usar en enlaces de teclas (ver aerc-binds(5)):

<C-p> = :menu -adc fzf :cf -a<Enter>

:choose -o <tecla> <texto> <comando> [-o <tecla> <texto> <comando>]...

Pide al usuario que elija entre varias opciones.

:reload [-B] [-C] [-s <nombre-conjunto-estilos>]

Recarga en caliente los archivos de configuración para los enlaces de teclas y la configuración general de aerc. No se admite la recarga del archivo de configuración de la cuenta.

Si no se proporcionan banderas, se recargarán binds.conf, aerc.conf y el conjunto de estilos actual.

-B: Recarga binds.conf.

-C: Recarga aerc.conf.

-s <nombre-conjunto-estilos>

Carga el conjunto de estilos especificado.

:suspend

Suspende el proceso de aerc. Algunas conexiones en curso pueden terminarse.

:quit [-f]
:exit [-f]
:q [-f]

Sale de aerc. Si se está realizando una tarea que no debe interrumpirse (como enviar un mensaje), una llamada de salida normal podría fallar. En este caso, cerrar aerc se puede forzar con la opción -f.

:redraw

Fuerza un redibujo completo de la pantalla.

COMANDOS DE MENSAJE

Estos comandos son válidos en cualquier contexto que tenga un mensaje seleccionado (por ejemplo, la lista de mensajes, el mensaje en el visor de mensajes, etc.).

:archive [-m <estrategia>] <esquema>

Mueve el mensaje seleccionado al archivo. Los esquemas disponibles son:

flat: Sin estructura especial, todos los mensajes en el directorio de archivo

year: Los mensajes se almacenan en carpetas por año

month: Los mensajes se almacenan en carpetas por año y subcarpetas por mes

La opción -m establece la estrategia de múltiples archivos. Ver aerc-notmuch(5) para más detalles.

:accept [-e|-E] [-s]

Acepta una invitación de reunión de iCalendar. Esto abre una ventana de composición con un archivo adjunto especialmente diseñado. Enviar el correo electrónico informará al remitente que aceptaste y probablemente también actualizará su calendario. Esto **NO** agregará la reunión a tu propio calendario, eso debe hacerse como un paso manual separado (por ejemplo, enviando la parte text/calendar a un script apropiado).

-e: Fuerza [compose].edit-headers = true solo para este mensaje.

-E: Fuerza [compose].edit-headers = false solo para este mensaje.

-s: Omite el editor y va directamente a la pantalla de revisión.

:accept-tentative [-e|-E] [-s]

Acepta tentativamente una invitación de reunión de iCalendar.

-e: Fuerza [compose].edit-headers = true solo para este mensaje.

-E: Fuerza [compose].edit-headers = false solo para este mensaje.

-s: Omite el editor y va directamente a la pantalla de revisión.

:copy [-dp] [-a <cuenta>] [-m <estrategia>] <carpeta>
:cp [-dp] [-a <cuenta>] [-m <estrategia>] <carpeta>

Copia el(los) mensaje(s) seleccionado(s) a <carpeta>.

-d: Descifra el mensaje antes de copiarlo.

-p: Crea <carpeta> si no existe.

-a: Copia a la <carpeta> de <cuenta>. Si <carpeta> no existe, se creará independientemente de si se usa -p o no.

-m: Establece la estrategia de múltiples archivos. Ver aerc-notmuch(5) para más detalles.

:decline [-e|-E] [-s]

Rechaza una invitación de reunión de iCalendar.

-e: Fuerza [compose].edit-headers = true solo para este mensaje.

-E: Fuerza [compose].edit-headers = false solo para este mensaje.

-s: Omite el editor y va directamente a la pantalla de revisión.

:delete [-m <estrategia>]

Elimina el mensaje seleccionado.

-m: Establece la estrategia de múltiples archivos. Ver aerc-notmuch(5) para más detalles.

:envelope [-h] [-s <especificador-formato>]

Abre el sobre del mensaje en un cuadro de diálogo emergente.

-h: Muestra todos los campos de encabezado

-s <especificador-formato>

Especificador de formato definido por el usuario que requiere dos %s para las cadenas de clave y valor. Formato predeterminado: %-20.20s: %s

:recall [-f] [-e|-E] [-s]

Abre el mensaje seleccionado para volver a editarlo. Los mensajes solo se pueden recuperar del directorio de posponer.

-f: Abre el mensaje para volver a editarlo incluso si no está en el directorio de posponer. Aerc recuerda la carpeta, por lo que la llamada posterior a :postpone guardará el mensaje allí de nuevo.

-e: Fuerza [compose].edit-headers = true solo para este mensaje.

-E: Fuerza [compose].edit-headers = false solo para este mensaje.

-s: Omite el editor y va directamente a la pantalla de revisión.

Los mensajes recuperados originales se eliminan si se envían o posponen nuevamente. En ambos casos, tienes otra copia del mensaje en algún lugar. De lo contrario, el mensaje recuperado se deja intacto. Esto sucede si el mensaje recuperado se descarta después de editarlo. Se puede eliminar con :rm si no se necesita.
