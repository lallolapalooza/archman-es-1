NOMBRE

aerc-stylesets - especificación del archivo de styleset para aerc(1)

SINOPSIS

aerc utiliza una sintaxis de configuración simple para configurar el styleset de su interfaz de usuario.

CONFIGURACIÓN DEL STYLESET

El styleset se describe como pares <objeto>.<atributo> = <valor> .

Por ejemplo, en la línea siguiente, el color de primer plano del objeto de estilo msglist_unread se establece a cornflowerblue

msglist_unread.fg = cornflowerblue

La configuración también permite la coincidencia de comodines en las claves para configurar múltiples objetos de estilo a la vez.

ATRIBUTOS

Las siguientes opciones están disponibles para modificar cada uno de los objetos de estilo.

<objeto>.fg = <color>

Se establece el color de primer plano del objeto de estilo.

<objeto>.bg = <color>

Se establece el color de fondo del objeto de estilo.

<objeto>.bold = true|false|toggle

Se establece/quita el atributo de negrita del objeto de estilo.

<objeto>.blink = true|false|toggle

Se establece/quita el atributo de parpadeo del objeto de estilo. El terminal necesita soportar texto parpadeante.

<objeto>.underline = true|false|toggle

Se establece/quita el atributo de subrayado del objeto de estilo. El terminal necesita soportar texto subrayado.

<objeto>.italic = true|false|toggle

Se establece/quita el atributo de cursiva del objeto de estilo. El terminal necesita soportar texto en cursiva.

<objeto>.dim = true|false|toggle

Se establece/quita el atributo de atenuado del objeto de estilo. El terminal necesita soportar texto de brillo medio.

<objeto>.reverse = true|false|toggle

Invierte el color del objeto de estilo. Intercambia los colores de primer plano y de fondo.

Si el valor es false, no cambia nada.

<objeto>.normal = true

Se quitan todos los atributos del objeto de estilo.

El valor no importa.

<objeto>.default = true

Establece el objeto de estilo al estilo por defecto del contexto. Normalmente basado en el terminal.

El valor no importa.

OBJETOS DE ESTILO

Los objetos de estilo representan los varios elementos o instancias de la interfaz de usuario para el estilizado.

Objeto de Estilo Descripción
default El objeto de estilo por defecto utilizado para los elementos normales de la interfaz de usuario cuando no se usa una configuración especializada.
error El estilo utilizado para mostrar errores.
warning El estilo utilizado al mostrar advertencias.
success El estilo utilizado para mensajes de éxito.
title El objeto de estilo utilizado para estilizar títulos en los elementos de la interfaz de usuario.
header El objeto de estilo utilizado para estilizar encabezados en los elementos de la interfaz de usuario.
statusline_default El estilo por defecto aplicado a la línea de estado.
statusline_error El estilo utilizado para mensajes de error en la línea de estado.
statusline_success El estilo utilizado para mensajes de éxito en la línea de estado.
msglist_default El estilo por defecto para los mensajes en una lista de mensajes.
msglist_unread Mensajes no leídos en una lista de mensajes.
msglist_read Mensajes leídos en una lista de mensajes.
msglist_flagged Los mensajes con la marca de marcado (flagged).
msglist_deleted Los mensajes marcados como eliminados.
msglist_marked Los mensajes con la marca de marcado (marked).
msglist_result Los mensajes que coinciden con la búsqueda actual.
msglist_answered Los mensajes marcados como respondidos.
msglist_forwarded Los mensajes marcados como reenviados.
msglist_gutter El canal (gutter) de la lista de mensajes.
msglist_pill La barra de desplazamiento de la lista de mensajes.
msglist_thread_folded Mensajes visibles que tienen hilos hijos plegados.
msglist_thread_context Los mensajes que no coinciden con el buzón / consulta, mostrados para contexto.
msglist_thread_orphan Mensajes en hilo que tienen un mensaje padre faltante.
dirlist_default El estilo por defecto para los directorios en la lista de directorios.
dirlist_unread El estilo utilizado para directorios con mensajes no leídos
dirlist_recent El estilo utilizado para directorios con mensajes recientes
part_switcher Fondo para el selector de partes en el visor de mensajes.
part_filename Nombre del archivo adjunto en el selector de partes.
part_mimetype Tipo MIME del adjunto/parte en el selector de partes.
completion_default El estilo por defecto para el motor de autocompletado.
completion_description Descripciones de los elementos de autocompletado.
completion_gutter El canal (gutter) del autocompletado.
completion_pill La píldora del autocompletado.
tab El estilo para la barra de pestañas.
stack El estilo para el elemento de pila de la interfaz de usuario.
spinner El estilo para el indicador de carga (spinner).
border El estilo utilizado para dibujar bordes (solo se usa el bg color a menos que personalices border-char-vertical y/o border-char-horizontal en aerc.conf).
selector_default El estilo por defecto para el elemento de interfaz de usuario selector.
selector_focused El elemento enfocado en un elemento de interfaz de usuario selector.
selector_chooser El selector de elementos en un elemento de interfaz de usuario selector.

Los siguientes objetos de estilo solo afectan al filtro incorporado colorize y deben declararse bajo una sección [viewer] del archivo de styleset.

Objeto de Estilo Descripción
url URLs.
header Nombres de encabezados tipo RFC-822.
signature Firmas de correo electrónico.
diff_meta Líneas meta de diff de parche.
diff_chunk Bloques de diff de parche.
diff_chunk_func Nombres de funciones de bloques de diff de parche.
diff_add Líneas añadidas en el diff de parche.
diff_del Líneas eliminadas en el diff de parche.
quote_1 Texto citado de primer nivel.
quote_2 Texto citado de segundo nivel.
quote_3 Texto citado de tercer nivel.
quote_4 Texto citado de cuarto nivel.
quote_x Texto citado por encima del cuarto nivel.

Los estilos definidos por el usuario pueden usarse para estilizar cadenas arbitrarias en go-templates (ver .Style en aerc-templates(7)). Los estilos de usuario deben definirsed en la [user] sección ini. Los estilos pueden ser referenciados por su nombre (por ejemplo, red.

Ejemplo:

Los estilos de usuario se combinan con otros estilos aplicados al contexto en el que se renderizan. Los colores de estilo de usuario (fg y/o bg) solo serán efectivos si el estilo de contexto no define ninguno. Otros atributos booleanos se combinarán con los atributos booleanos del estilo

subyacente.

Por ejemplo, si el estilo de contexto
