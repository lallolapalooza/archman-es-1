AERC-TUTORIAL(7) Manual de Información Miscelánea AERC-TUTORIAL(7)

NOMBRE

aerc-tutorial - tutorial para aerc(1)

INTRODUCCIÓN

¡Bienvenido a aerc! Este tutorial te guiará en tus primeros pasos con el cliente. Este tutorial es una página de manual; puedes volver a leerlo más tarde con :help tutorial desde aerc, o man aerc-tutorial desde tu terminal.

Primero, presentemos algunos atajos de teclado básicos. Por convención, usaremos <C-p> para representar Ctrl+p, lo que coincide con la convención utilizada para escribir atajos de teclado para aerc.

<C-p>, <C-n>

Cicla a la pestaña anterior o siguiente

Intenta usarlos ahora para cambiar entre tu lista de mensajes y el tutorial. En tu lista de mensajes, usamos teclas al estilo de Vim para movernos.

k, j

Desplaza hacia arriba y hacia abajo entre los mensajes

<C-u>, <C-d>

Desplaza media página hacia arriba o hacia abajo

g, G

Selecciona el primer o último mensaje, respectivamente

K, J

Cambia entre carpetas en la barra lateral

<Enter>

Abre el mensaje seleccionado

También puedes buscar en la carpeta seleccionada con /, o filtrar con \ . Al buscar, puedes usar n y p para saltar al siguiente y anterior resultado. Filtrar oculta cualquier mensaje que no coincida.

EL VISOR DE MENSAJES

Presiona <Enter> para abrir un mensaje. Por defecto, el visor de mensajes mostrará tu mensaje usando less(1). Esto también debería tener atajos de teclado familiares al estilo de Vim para desplazarte por tu mensaje.

Los mensajes multipartes (mensajes con archivos adjuntos, o mensajes con varios formatos alternativos) muestran un selector de partes en la parte inferior del visor de mensajes.

<C-k>, <C-j>

Cicla entre las partes de un mensaje multiparte

q

Cierra el visor de mensajes

Para mostrar partes de mensajes HTML, el filtro text/html en tu archivo aerc.conf (que probablemente esté en ~/.config/aerc/) requiere w3m junto con dependencias opcionales para un aislamiento de red más seguro: unshare (de util-linux) o socksify (de dante-utils).

También puedes realizar muchas de las tareas que podías hacer en la lista de mensajes desde aquí, como responder a correos electrónicos, eliminar el correo, o ver el mensaje siguiente y anterior (J y K).

REDACCIÓN DE MENSAJES

Regresa a la lista de mensajes presionando q para descartar el visor de mensajes. Una vez allí, redactemos un mensaje.

C

Redacta un nuevo mensaje

rr

Responde a todos los destinatarios de un mensaje

rq

Responde a todos los destinatarios de un mensaje, y precarga el editor con una versión citada del mensaje al que se responde

Rr

Responde a un mensaje

Rq

Responde a un mensaje, y precarga el editor con una versión citada del mensaje al que se responde

Por ahora, usemos C para redactar un nuevo mensaje. Aparecerá el compositor de mensajes. Deberías ver las líneas Para, De y Asunto, así como tu editor. Puedes usar <Tab> o <C-j> y <C-k> para ciclar entre estos campos (Tab no ciclará entre campos una vez que ingreses al editor, pero <C-j> y <C-k> lo harán).

Enviemos un correo electrónico a ti mismo. Ten en cuenta que las cabeceras Para y De esperan direcciones RFC 5322, por ejemplo, John Doe <john@example.org>, o simplemente <john@example.org>. Separa varios destinatarios con comas. Continúa y completa un correo electrónico, luego cierra el editor.

A continuación, se muestra la pantalla de revisión del mensaje. Ahora tienes la oportunidad de revisar el correo electrónico antes de que se envíe. Presiona y para enviar el correo electrónico si se ve bien.

Nota: cuando uses la terminal en la vista de mensajes, puedes invocar la línea de comandos ex de aerc usando <C-x>. : se envía al editor.

USANDO LA TERMINAL

aerc viene con una terminal integrada, que ya has utilizado para ver y editar correos electrónicos. También podemos usarla para otros propósitos, como referenciar un repositorio git al revisar un parche. Desde la lista de mensajes, podemos usar los siguientes atajos de teclado para abrir una terminal:

<C-t>

Abre una nueva pestaña de terminal, ejecutando tu shell

$, !

Pide un comando para ejecutar, luego abre una nueva pestaña de terminal ejecutando ese comando

|

Pide un comando para ejecutar, luego canaliza el correo electrónico seleccionado a ese comando y muestra el resultado en una nueva pestaña de terminal

Intenta presionar $ e ingresar top. También puedes usar el comando :cd para cambiar el directorio de trabajo de aerc, y el directorio en el que se ejecutan las nuevas terminales. Usa :pwd para verlo de nuevo si no estás seguro de dónde estás.

NOTAS ADICIONALES

COMANDOS

Cada atajo de teclado está en última instancia enlazado a un comando de aerc. También puedes invocar la línea de comandos presionando :, y luego ingresando uno de estos comandos. Consulta aerc(1) o :help para obtener una lista completa de comandos.

FILTROS DE MENSAJES

Al mostrar mensajes en el visor de mensajes, aerc los canalizará a través de un filtro de mensajes primero. Esto te permite decodificar mensajes en formatos no de texto plano, agregar resaltado de sintaxis, etc. aerc incluye algunos filtros predeterminados:

  • Las partes text/plain se canalizan a través del filtro incorporado colorize, que maneja el resaltado de URL, citas y diferencias.
  • text/calendar se procesa para ser texto legible por humanos.
  • text/html (deshabilitado por defecto) se puede descomentar para canalizar a través del filtro incorporado html.

PERSONALIZACIÓN DE AERC

Aerc es altamente personalizable. Revisa aerc-config(5) (o usa :help config) para aprender más sobre cómo agregar atajos de teclado personalizados, instalar nuevos filtros de mensajes, cambiar su apariencia y comportamiento, y demás.
