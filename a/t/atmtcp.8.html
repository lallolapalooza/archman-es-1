    NAME

    atmtcp — TCP-ATM relay

    SYNOPSIS

    atmtcp [-d] [-v] [-c configfile] [-p pidfile]

    DESCRIPTION

    The atmtcp daemon is a relay for TCP-ATM traffic. It listens on a TCP port for incoming connections from ATM clients, and forwards the data to the appropriate ATM endpoint. It can also listen on an ATM endpoint and forward the data to a TCP client.

    The configuration of atmtcp is done via a configuration file, specified by the -c option. The default configuration file is /etc/atmtcp.conf.

    OPTIONS

    -d
    Run in foreground (debug mode).
    -v
    Increase verbosity.
    -c configfile
    Specify an alternative configuration file.
    -p pidfile
    Specify an alternative PID file.

    COMMANDS

    There are no specific commands for atmtcp. It is controlled by signals:

    SIGHUP
    Reload configuration.
    SIGTERM
    Terminate gracefully.
    SIGUSR1
    Toggle debug mode.
    SIGUSR2
    Dump statistics.

    RESTRICTIONS

    This daemon requires appropriate ATM network interface configuration and permissions.

    EXAMPLES

    Start atmtcp in the background with the default configuration file:

        # atmtcp

    Start atmtcp in debug mode with a custom configuration file:

        # atmtcp -d -c /etc/atmtcp.local.conf
