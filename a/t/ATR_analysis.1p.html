ATR_ANALYSIS(1p) Comandos de usuario ATR_ANALYSIS(1p)

NOMBRE

ATR_analysis - analiza el ATR de una tarjeta inteligente

SINOPSIS

ATR_analysis [cadena_ATR]

DESCRIPCIÓN

ATR_analysis se utiliza para analizar el ATR (Respuesta a Reset) enviado por una tarjeta inteligente.

El comando también intenta encontrar el modelo de tarjeta utilizando una base de datos de ATR almacenada en un archivo de texto llamado smartcard_list.txt.

El archivo smartcard_list.txt se busca en $XDG_CACHE_HOME/smartcard_list.txt, $HOME/.smartcardlist.txt y /usr/share/pcsc/smartcard_list.txt.

Ejemplo:
$ ATR_analysis '3B A7 00 40 18 80 65 A2 08 01 01 52'
ATR: 3B A7 00 40 18 80 65 A2 08 01 01 52
+ TS = 3B --> Convención Directa
+ T0 = A7, Y(1): 1010, K: 7 (bytes históricos)
TB(1) = 00 --> Parámetro de Programación P: 0, I: 0
TD(1) = 40 --> Y(i+1) = 0100, Protocolo T = 0
-----
TC(2) = 18 --> Tiempo de espera de trabajo: 960 x 24 x (Fi/F)
+ Bytes históricos: 80 65 A2 08 01 01 52


Tarjeta posiblemente identificada:
3B A7 00 40 18 80 65 A2 08 01 01 52
Gemplus GPK8000

ERRORES

Quizás muchos errores ya que no soy un experto en ISO 7816.

ARCHIVOS
