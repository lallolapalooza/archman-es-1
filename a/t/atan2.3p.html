ATAN2(3P) Manual de Programador POSIX ATAN2(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

atan2, atan2f, atan2l — funciones de arco tangente

SINOPSIS

#include <math.h>
double atan2(double y, double x);
float atan2f(float y, float x);
long double atan2l(long double y, long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 remite al estándar ISO C.

Estas funciones calcularán el valor principal del arco tangente de y/x, utilizando los signos de ambos argumentos para determinar el cuadrante del valor de retorno.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DE RETORNO

Tras una finalización exitosa, estas funciones devolverán el arco tangente de y/x en el rango [-π,π] radianes.

Si y es ±0 y x es < 0, se devolverá ±π.

Si y es ±0 y x es > 0, se devolverá ±0.

Si y es < 0 y x es ±0, se devolverá -π/2.

Si y es > 0 y x es ±0, se devolverá π/2.

Si x es 0, no ocurrirá un error de polo.

Si alguno de x o y es NaN, se devolverá un NaN.

Si el valor correcto causara un subdesbordamiento, puede ocurrir un error de rango, y atan(), atan2f(), y atan2l() devolverán un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si se soporta la opción de punto flotante IEC 60559, se devolverá y/x.

Si y es ±0 y x es -0, se devolverá ±π.

Si y es ±0 y x es +0, se devolverá ±0.

Para valores finitos de ±y > 0, si x es -Inf, se devolverá ±π.

Para valores finitos de ±y > 0, si x es +Inf, se devolverá ±0.

Para valores finitos de x, si y es ±Inf, se devolverá ±π/2.

Si y es ±Inf y x es -Inf, se devolverá ±3π/4.

Si y es ±Inf y x es +Inf, se devolverá ±π/4.

Si ambos argumentos son 0, no ocurrirá un error de dominio.

ERRORES

Estas funciones pueden fallar si:

Error de Rango
El resultado sufre subdesbordamiento.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante de subdesbordamiento.

EJEMPLOS

Conversión de Coordenadas Cartesianas a Polares

La función siguiente utiliza atan2() para convertir un vector 2d expresado en coordenadas cartesianas (x,y) a coordenadas polares (rho,theta). Hay otras formas de calcular el ángulo theta, usando asin(), acos(), o atan(). Sin embargo, atan2() presenta aquí dos ventajas:

*
El cuadrante del ángulo se determina automáticamente.
*
Se tienen en cuenta los casos singulares (0,y).

Finalmente, este ejemplo utiliza hypot() en lugar de sqrt() ya que es mejor para casos especiales; vea hypot() para más información.

#include <math.h>
void
cartesian_to_polar(const double x, const double y,
                   double *rho, double *theta
    )
{
    *rho   = hypot (x,y); /* mejor que sqrt(x*x+y*y) */
    *theta = atan2 (y,x);
}

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
