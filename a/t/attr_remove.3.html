attr_remove(3)

Paquete: attr

Licencias: LGPL

ATTR_REMOVE(3) API de compatibilidad XFS ATTR_REMOVE(3)

NOMBRE

attr_remove, attr_removef - eliminar un atributo de usuario de un objeto del sistema de archivos

SINOPSIS C

#include <attr/attributes.h>

int attr_remove (const char *path, const char *attrname, int flags);
int attr_removef (int fd, const char *attrname, int flags);

DESCRIPCIÓN

Las funciones attr_remove y attr_removef proporcionan una forma de eliminar atributos previamente creados de objetos del sistema de archivos.

Path apunta a un nombre de ruta para un objeto del sistema de archivos, y fd se refiere al descriptor de archivo asociado con un archivo. Si el atributo attrname existe, el nombre y el valor del atributo se eliminarán del objeto del sistema de archivos. El argumento flags puede contener los siguientes símbolos OR-eados bit a bit:

ATTR_ROOT
Busca attrname en el espacio de direcciones root, no en el espacio de direcciones user. (limitado al uso por el superusuario solamente)
ATTR_DONTFOLLOW
No sigas enlaces simbólicos al resolver una llamada a la función attr_remove con path. El valor predeterminado es seguir enlaces simbólicos.

attr_remove fallará si se cumple una o más de las siguientes condiciones:

[ENOATTR]
El nombre del atributo dado no está asociado con el objeto del sistema de archivos indicado.
[ENOENT]
El archivo nombrado no existe.
[EPERM]
El ID de usuario efectivo no coincide con el propietario del archivo y el ID de usuario efectivo no es el superusuario.
[ENOTDIR]
Un componente del prefijo de ruta no es un directorio.
[EACCES]
Se deniega el permiso de búsqueda en un componente del prefijo de ruta.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema.
[EFAULT]
Path apunta fuera del espacio de direcciones asignado del proceso.
[ELOOP]
La búsqueda de un nombre de ruta implicó demasiados enlaces simbólicos.
[ENAMETOOLONG]
La longitud de path excede {MAXPATHLEN}, o un componente del nombre de ruta es más largo que {MAXNAMELEN}.

attr_removef fallará si:

[ENOATTR]
El nombre del atributo dado no está asociado con el objeto del sistema de archivos indicado.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema, o fd se refiere a un socket, no a un archivo.
[EFAULT]
Attrname apunta fuera del espacio de direcciones asignado del proceso.
[EBADF]
Fd no se refiere a un descriptor válido.

DIAGNÓSTICOS

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno apropiadamente.
