NOMBRE

atmsigd - demonio de señalización ATM

SINOPSIS

atmsigd [-b] [-c archivo_config] [-d] [-D dir_volcado] [-l archivo_log] [-m modo] [-n] [-q qos] [-t longitud_traza] [-u version_uni] [[interfaz.]vpi.vci [entrada salida]]
atmsigd -V

DESCRIPCIÓN

atmsigd implementa el protocolo de señalización ATM UNI. Las solicitudes para establecer, aceptar o cerrar SVCs de ATM se envían desde el kernel (utilizando un protocolo comparativamente simple) al demonio de señalización, que luego realiza el diálogo con la red.

Tenga en cuenta que atmsigd no puede aceptar ni establecer conexiones hasta que la dirección ATM local de la interfaz sea configurada por ilmid o manualmente usando atmaddr.

El VC de señalización predeterminado (interfaz 0, VPI 0, VCI 5) puede ser anulado en la línea de comandos especificando una dirección PVC diferente.

Al anular el VC predeterminado, opcionalmente se pueden especificar un par de tuberías con nombre para comunicarse con el usuario de la señalización. Normalmente, el kernel es el usuario de la señalización y atmsigd abre un socket especial para comunicarse con él.

Si atmsigd es terminado, todas las llamadas al sistema que requieren interacción con él devolverán un error y establecerán errno a EUNATCH.

OPCIONES

-b
Ejecutar en segundo plano (es decir, en un proceso hijo bifurcado) después de inicializarse.
-c archivo_config
Usar el archivo de configuración especificado en lugar de /etc/atmsigd.conf. Si una opción se especifica en el archivo de configuración y en la línea de comandos, la línea de comandos tiene prioridad.
-d
Habilita (mucha) salida de depuración. Por defecto, atmsigd es comparativamente silencioso.
-D dir_volcado
Especifica el directorio al que atmsigd escribirá los volcados de estado y traza. Si no se especifica -D, los volcados se escriben en /var/tmp.
-l archivo_log
Escribir mensajes de diagnóstico en el archivo especificado. El nombre especial syslog se usa para enviar diagnósticos al registrador del sistema, stderr se usa para enviar diagnósticos al error estándar. Si -l está ausente, se utiliza la configuración en atmsigd.conf. Si atmsigd no especifica tampoco un destino, los mensajes se escriben en el error estándar.
-m modo
Establecer el modo de operación. Los siguientes modos están disponibles: user para el lado del usuario (el predeterminado), network para el lado de la red (útil si tiene dos PCs pero no un switch), y switch para operación con un relé de señalización en un switch.
-n
Imprime las direcciones solo en formato numérico, es decir, no se intenta traducir direcciones a nombres.
-q qos
Configura el VC de señalización para usar la calidad de servicio especificada (ver qos(7) para la sintaxis). Por defecto, se usa UBR a velocidad de enlace en el VC de señalización.
-t longitud_traza
Establece el número de entradas que deben mantenerse en el búfer de traza. -t 0 deshabilita el rastreo. Si -t no se especifica, atmsigd utiliza un valor predeterminado de 20 entradas de traza.
-u version_uni
Establece el modo de señalización. Los siguientes modos son compatibles: uni30 para UNI 3.0, uni31 para UNI 3.1, uni31+uni30 para UNI 3.1 con compatibilidad 3.0, uni40 para UNI 4.0, y uni40+q.2963.1 para UNI 4.0 con renegociación de tasa de celdas pico Q.2963.1.
-V
Imprime el número de versión de atmsigd en la salida estándar y sale.

ARCHIVOS

/etc/atmsigd.conf
archivo de configuración predeterminado
/var/tmp/atmsigd.pid.status.version
ubicación predeterminada de los volcados de estado
/var/tmp/atmsigd.pid.trace.version
ubicación predeterminada de los volcados de traza de señalización

DEPURACIÓN

Al recibir una señal SIGUSR1, atmsigd vuelca la lista de todos los descriptores de socket internos. Con SIGUSR2, vuelca el contenido del búfer de traza. Si se especificó un directorio de volcado, los volcados se escriben en archivos llamados atmsigd.pid.status.numero y atmsigd.pid.trace.numero, respectivamente, donde numero comienza en cero y se incrementa por cada volcado. Si no se establece un directorio de volcado, los volcados se escriben en el error estándar.

También se generan volcados cada vez que atmsigd detecta un error fatal y termina. No se intenta capturar señales como SIGSEGV.

ERRORES

La generación de trazas es un proceso comparativamente lento que puede tardar varios segundos incluso para solo 100 entradas de traza. Para generar un volcado de traza, atmsigd por lo tanto bifurca un proceso hijo que se ejecuta en paralelo al demonio de señalización.
