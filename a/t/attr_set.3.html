attr_set(3)

Paquete: attr

Licencias: LGPL

ATTR_SET(3) API de compatibilidad de XFS ATTR_SET(3)

NOMBRE

attr_set, attr_setf - establecer el valor de un atributo de usuario de un objeto del sistema de archivos

SINOPSIS C

#include <attr/attributes.h>

int attr_set (const char *path, const char *attrname, 
              const char *attrvalue, const int valuelength,
              int flags);
int attr_setf (int fd, const char *attrname, 
               const char *attrvalue, const int valuelength,
               int flags);

DESCRIPCIÓN

Las funciones attr_set y attr_setf proporcionan una forma de crear atributos y establecer/modificar sus valores.

Path apunta a un nombre de ruta para un objeto del sistema de archivos, y fd se refiere al descriptor de archivo asociado con un archivo. Si el atributo attrname no existe, se creará un atributo con el nombre y valor dados y se asociará con ese objeto del sistema de archivos indicado. Si ya existe un atributo con ese nombre en ese objeto del sistema de archivos, el valor existente se reemplazará con el nuevo valor dado en esta llamada. El nuevo valor del atributo se copia del búfer attrvalue por un total de valuelength bytes. El argumento flags puede contener los siguientes símbolos OR-eados bit a bit:

ATTR_ROOT
Buscar attrname en el espacio de direcciones root, no en el espacio de direcciones user. (solo para uso del superusuario)
ATTR_DONTFOLLOW
No seguir enlaces simbólicos al resolver una path en una llamada a la función attr_set. El valor predeterminado es seguir enlaces simbólicos.
ATTR_CREATE
Devolver un error (EEXIST) si ya existe un atributo con el nombre dado en el objeto del sistema de archivos indicado, de lo contrario, crear un atributo con el nombre y valor dados. Esta bandera se utiliza para implementar una operación de creación pura; sin esta bandera, attr_set creará el atributo si aún no existe. Se devolverá un error (EINVAL) si tanto ATTR_CREATE como ATTR_REPLACE se establecen en la misma llamada.
ATTR_REPLACE
Devolver un error (ENOATTR) si ya existe un atributo con el nombre dado en el objeto del sistema de archivos indicado, de lo contrario, reemplazar el valor del atributo existente con el valor dado. Esta bandera se utiliza para implementar una operación de reemplazo pura; sin esta bandera, attr_set creará el atributo si aún no existe. Se devolverá un error (EINVAL) si tanto ATTR_CREATE como ATTR_REPLACE se establecen en la misma llamada.

attr_set fallará si se cumple una o más de las siguientes condiciones:

[ENOATTR]
El nombre del atributo dado no está asociado con el objeto del sistema de archivos indicado y se estableció el bit de bandera ATTR_REPLACE.
[E2BIG]
El valor del atributo dado es demasiado grande, excede el tamaño máximo permitido de un valor de atributo.
[EEXIST]
El nombre del atributo dado ya está asociado con el objeto del sistema de archivos indicado y se estableció el bit de bandera ATTR_CREATE.
[ENOENT]
El archivo nombrado no existe.
[EPERM]
El ID de usuario efectivo no coincide con el propietario del archivo y el ID de usuario efectivo no es superusuario.
[ENOTDIR]
Un componente del prefijo de ruta no es un directorio.
[EACCES]
Se deniega el permiso de búsqueda en un componente del prefijo de ruta.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema, o se establecieron los bits de bandera ATTR_CREATE y ATTR_REPLACE.
[EFAULT]
Path, attrname, o attrvalue apunta fuera del espacio de direcciones asignado del proceso.
[ELOOP]
Una búsqueda de nombre de ruta involucró demasiados enlaces simbólicos.
[ENAMETOOLONG]
La longitud de path excede {MAXPATHLEN}, o un componente del nombre de ruta es más largo que {MAXNAMELEN}.

attr_setf fallará si:

[ENOATTR]
El nombre del atributo dado no está asociado con el objeto del sistema de archivos indicado y se estableció el bit de bandera ATTR_REPLACE.
[E2BIG]
El valor del atributo dado es demasiado grande, excede el tamaño máximo permitido de un valor de atributo.
[EEXIST]
El nombre del atributo dado ya está asociado con el objeto del sistema de archivos indicado y se estableció el bit de bandera ATTR_CREATE.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema, o se establecieron los bits de bandera ATTR_CREATE y ATTR_REPLACE, o fd se refiere a un socket, no a un archivo.
[EFAULT]
Attrname, o attrvalue apunta fuera del espacio de direcciones asignado del proceso.
[EBADF]
Fd no se refiere a un descriptor válido.

DIAGNÓSTICOS

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y errno se establece apropiadamente.
