Esta página del manual describe loscomandos de atool. Estos comandos se utilizan para gestionar archivos de archivo de varios tipos, como archivos tar y Zip. Cada comando puede ejecutarse individualmente o proporcionando las opciones apropiadas a atool(véase OPCIONES más abajo).
aunpackextrae archivos de un archivo. A menudo se desea extraer todos los archivos de un archivo a un único subdirectorio. Sin embargo, algunos archivos contienen múltiples archivos en sus directorios raíz. El programa aunpack supera este problema extrayendo primero los archivos a un directorio (temporal) único, y luego moviendo su contenido de vuelta si es posible. Esto también evita que los archivos locales se sobrescriban por error. apackcrea archivos (o comprime archivos). Si no se especifican argumentos de archivo, los nombres de archivo a añadir se leen de la entrada estándar.
alslista los archivos en un archivo. acat extrae archivos de un archivo a la salida estándar.
adiffgenera un diff entre dos archivos usando diff(1). arepack reempaqueta archivos a un formato diferente. Lo hace extrayendo primero todos los archivos del archivo antiguo a un directorio temporal, y luego empaquetando todos los archivos extraídos de ese directorio al nuevo archivo. Use la opción --each (-e) en combinación con --format (-F) para reempaquetar múltiples archivos usando una sola invocación de atool.

Tenga en cuenta que arepack
no eliminará el archivo antiguo.

A menos que se proporcione la opción -f (--format), el formato del archivo se determina por la extensión del archivo. Es decir, una extensión ".tar.gz" o ".tgz" significa formato tar+gzip. Tenga en cuenta que las extensiones se comprueban en el otro orden indicado anteriormente, por lo que un archivo con la extensión ".tar.gz" se considera un archivo tar+gzip, no un archivo gzip.

CONFIGURACIÓN

Desde la versión 0.8.0, atool puede leer archivos de configuración personalizados. Primero, se evalúan los valores predeterminados codificados en el archivo del programa atool. Luego se cargan los valores de configuración del sistema desde /etc/atool.conf si ese archivo existe. Finalmente, se cargan los valores de configuración por usuario desde .atoolrc en el directorio de inicio del usuario actual.

El formato de los archivos de configuración es simple:

variable valor

Aquí variable es una variable de la lista siguiente, y valor es el valor a asociar con la variable. variable y valor deben separarse con al menos un espacio en blanco (espacio, tabulador etc). Las líneas vacías y las líneas que comienzan con # se descartan.

Un valor de `1' significa que la opción está habilitada, y `0' que está deshabilitada. Las cadenas no deben estar entre comillas, ya que comienzan en el primer carácter que no es un espacio en blanco y terminan al final de la línea.

Las opciones son:

use_tar_bzip2_option (predeterminado: 1)
Habilite esto si usa GNU tar y este admite la opción --bzip2 para filtrar archivos comprimidos con bzip2 a través de bzip2. Las versiones 1.13.6 o posteriores de GNU tar admiten --bzip2. Por lo tanto, si usa una versión de GNU tar anterior a 1.13.6, deberá deshabilitar esta opción.

Esto solía ser use_tar_j_option pero usar --bzip2 es más portable.

use_tar_lzip_option (predeterminado: 0)
Habilite esto si usa GNU tar y este admite la opción --lzip para filtrar archivos comprimidos con lzip a través de lzip. Las versiones 1.23 o posteriores de GNU tar admiten --lzip. Por lo tanto, si usa una versión de GNU tar anterior a 1.23, deberá deshabilitar esta opción.
use_tar_z_option (predeterminado: 1)
Habilite esto si usa GNU tar y este admite la opción -z para filtrar archivos comprimidos con gzip a través de gzip. Necesitará deshabilitar esto y use_tar_j_option si no usa GNU tar.

Deshabilitar estas dos opciones no significa que atool no pueda extraer archivos bzip2/gzip. Si están deshabilitadas, atool usará una tubería para enviar la salida de bzip2/gzip a tar.

Si es posible, estas opciones deberían estar habilitadas ya que la gestión de errores es mejor cuando el filtrado lo realiza tar.

use_tar_lzma_option (predeterminado: 1)
Habilite esto si usa GNU tar y este admite la opción --lzma para filtrar archivos comprimidos con lzma a través de lzma. Las versiones 1.20 o posteriores de GNU tar admiten --lzma.
use_tar_lzop_option (predeterminado: 0)
Habilite esto si usa GNU tar y este admite la opción --lzop para filtrar archivos comprimidos con lzop a través de lzop. Las versiones 1.21 o posteriores de GNU tar admiten --lzop.
use_tar_xz_option (predeterminado: 0)
Habilite esto si usa GNU tar y este admite la opción --xz para filtrar archivos comprimidos con xz a través de xz. Las versiones 1.22 o posteriores de GNU tar admiten --xz.
use_gzip_for_z (predeterminado: 1)
Habilite esto si desea usar gzip en lugar de uncompress al descomprimir archivos comprimidos con compress (archivos `.Z').
use_rar_for_unpack (predeterminado: 0)
Habilite esto si desea usar siempre rar en lugar de unrar cuando sea posible. Esto hace que atool use el comando rar (path_rar) incluso al listar y extraer archivos RAR.
use_arc_for_unpack (predeterminado: 0)
Habilite esto si desea usar siempre arc en lugar de nomarch cuando sea posible. Esto hace que atool use el comando arc (path_arc) incluso al listar y extraer archivos ARC.
use_arj_for_unpack (predeterminado: 0)
Habilite esto si desea usar siempre arj en lugar de unarj cuando sea posible. Esto hace que atool use el comando arj (path_arj) incluso al listar y extraer archivos ARJ.
use_find_cpio_print0 (predeterminado: 1)
Habilite esto si find admite la opción -print0 y cpio admite la opción -0. Sin ella, es imposible/más difícil crear archivos cpio de archivos con caracteres de nueva línea en sus nombres.
extract_deb_control (predeterminado: 1)
Los archivos de paquetes .deb de Debian contienen información de control en un directorio DEBIAN, especialmente el archivo "control" del paquete. Habilite esto si desea que la información de control se extraiga durante la extracción además de los archivos normales.
strip_unknown_ext (predeterminado: 1)
Ciertos tipos de archivos son en realidad archivos, pero sus extensiones no lo indican. Ejemplos son los documentos de Open Office (archivos Zip) y los documentos de Gnumeric (archivos comprimidos con gzip). Dado que las extensiones de esos nombres de archivo son desconocidas para atool, no se eliminarían con esta opción establecida en 0. El archivo de salida en ese caso sería algo como Unpack-XYZW. Establecer esta opción en 1 hará que se elimine la extensión.
use_pbzip2 (predeterminado: 0)
Habilite esto si desea usar pbzip2 en lugar de bzip2. Tenga en cuenta que si use_tar_bzip2_option está habilitado, entonces tar usará bzip2 independientemente de la opción use_pbzip2. Así que si quiere que tar use pbzip2 en lugar de bzip2, establezca use_pbzip2 en 1 y use_tar_bzip2_option en 0.
use_lbzip2 (predeterminado: 0)
Habilite esto si desea usar lbzip2 en lugar de bzip2. Tenga en cuenta que si use_tar_bzip2_option está habilitado, entonces tar usará bzip2 independientemente de la opción use_lbzip2. Así que si quiere que tar use lbzip2 en lugar de bzip2, establezca use_lbzip2 en 1 y use_tar_bzip2_option en 0.
use_pigz (predeterminado: 0)
Habilite esto si desea usar pigz en lugar de gzip. Tenga en cuenta que si use_tar_z_option está habilitado, entonces tar usará gzip independientemente de la opción use_pigz. Así que si quiere que tar use pigz en lugar de gzip, establezca use_pigz en 1 y use_tar_z_option en 0.
use_plzip (predeterminado: 0)
<dd>Habilite esto si desea usar plzip en lugar de lzip. Tenga en cuenta que si use_tar_lzip_option está habilitado, se usará lzip con tar independientemente de la opción use_plzip. Por lo tanto, si desea que tar use plzip en lugar de lzip, establezca use_plzip en 1 y use_tar_lzip_option en 0.
use_jar (por defecto: 0)
Habilite esto si desea usar jar para gestionar archivos jar. Si deshabilita esta opción, se usará zip (que debería funcionar igual de bien y probablemente también sea más rápido).

Esta opción está deshabilitada por defecto ya que la extracción de archivos a la salida estándar (`cat') no es soportada por jar.

use_file (por defecto: 1)
Habilite esto si desea que atool identifique los tipos de archivo usando file(1) para aquellos archivos con una extensión no reconocida (o sin ninguna).
use_file_always (por defecto: 0)
Habilite esto si desea que atool siempre identifique los archivos usando file(1), independientemente de la extensión del archivo. Tenga en cuenta que esto actualmente tiene algunos inconvenientes, como no poder identificar todos los tipos de archivo (especialmente archivos tar comprimidos con 7zip, lzop, szip, etc).
tmpdir_name (por defecto: Unpack-%04d)
atool extrae a un directorio temporal creado en el directorio actual para que no se sobrescriba ningún archivo. Esta variable controla qué nombre debe tener ese directorio temporal.

La cadena `%d' en esta variable será reemplazada con un número aleatorio entre 0 y 9999. Es posible cambiar el formato de este número usando algo distinto a `%d' - consulte printf(3).

tmpfile_name (por defecto: Pack-%04d)
Al usar pbzip2 y crear archivos, es necesario crear un archivo temporal. Esta opción controla el nombre de ese archivo. Consulte tmpdir_name para más detalles sobre el formato.

args_diff (por defecto: -ru)
Esta variable especifica los argumentos de la línea de comandos a pasar al comando diff (como se especifica en path_diff) al usar adiff. Los espacios separan los argumentos en esta cadena.
path_syscfg (por defecto: /etc/atool.conf)
(Esta variable solo puede establecerse en el archivo de programa de atool.) Esta variable especifica el directorio donde se encuentra el archivo de configuración de todo el sistema.
path_usercfg (por defecto: .atoolrc)
(Esta variable solo puede establecerse en el archivo de programa de atool y en el archivo de configuración de todo el sistema.) Esta variable especifica dónde se encuentra el archivo de configuración del usuario. Tenga en cuenta que si este nombre de archivo es relativo (es decir, no comienza con `/'), será relativo al directorio de inicio del usuario actual (según lo determinado por la variable de entorno HOME).
default_verbosity (por defecto: 1)
Esta es la verbosidad predeterminada de atool. Usando las opciones -q y -v, el nivel de verbosidad puede aumentarse y disminuirse. El nivel 1 significa "verbosidad normal" - por ejemplo, al crear y extraer de archivos, los archivos se listarán.
show_extracted (por defecto: 1)
Si esto está establecido en 1, el comando aunpack siempre mostrará qué archivo o directorio fue extraído. De lo contrario, esto solo se imprimirá si el archivo fue extraído a una ubicación inesperada (como resultado de archivos locales que ya existen o de que el archivo tiene múltiples archivos en su directorio raíz).

Esto puede ser bastante útil en combinación con `default_verbosity 0'. Tenga en cuenta que esta opción no tendrá efecto cuando se use la opción -X con aunpack, y no tiene efecto en archivos comprimidos.

keep_compressed (por defecto: 1)
Al comprimir un archivo con gzip o bzip2, el archivo original (sin comprimir) usualmente se elimina una vez que ha sido comprimido. Es decir, si comprime un archivo "test" terminará con un solo archivo, "test.gz". Con esta opción establecida en 1, hará que atool conserve también el archivo original. El comportamiento original se logra estableciendo esta opción en 0.

Esta opción también tiene un efecto equivalente al descomprimir archivos comprimidos. Cuando se establece en 1, el archivo original (comprimido) se conservará. De lo contrario, se eliminará.

Tenga en cuenta, sin embargo, que esta opción no tiene efecto al empaquetar un archivo comprimido con la opción -X (para especificar un directorio de salida o archivo). En ese caso, el archivo original siempre se conserva.

decompress_to_cwd (por defecto: 1)
Al descomprimir un archivo con comandos como gzip o bzip2, el archivo descomprimido usualmente se coloca en el mismo directorio que el archivo comprimido. Con esta opción establecida en 1, el archivo descomprimido se coloca en cambio en el directorio de trabajo actual.

Tenga en cuenta que esta opción no tiene efecto cuando se usa -X.

PAGER El paginador predeterminado a usar cuando se especifica la opción -p/--page.

EJEMPLOS

Para extraer todos los archivos del archivo `foobar.tar.gz' a un subdirectorio (o al directorio actual si solo contiene un archivo):
aunpack foobar.tar.gz

Para extraer todos los archivos de todos los archivos `.tar.gz' en el directorio actual:
aunpack -e *.tar.gz

Para crear un archivo zip de dos archivos `foo' y `bar':
apack myarchive.zip foo bar

Para mostrar el archivo `baz' en el archivo `myarchive.zip' a través de un paginador:
acat -p myarchive.zip baz

Para listar el contenido del archivo rar `stuff.rar':
als stuff.rar

Para crear tres archivos, `dir1.tar.gz', `dir2.tar.gz' y `dir3.tar.gz', de modo que el primero contenga todos los archivos en dir1, el segundo todos en dir2 y el tercero todos en dir3:
apack -e -F .tar.gz dir1 dir2 dir3

Para mostrar todas las diferencias entre las versiones 2.4.17 y 2.4.18 del kernel:
adiff linux-2.4.17.tar.gz linux-2.4.18.tar.gz

Para reempaquetar todos los archivos .tar.gz en el directorio actual a .tar.7z (el archivo antiguo se mantendrá intacto):
arepack -F.tar.7z -e *.tar.gz>

Aquí hay una función de shell que hará que el comando aunpack cambie al directorio donde se extrajeron los archivos:
aunpack () {
TMP=`mktemp /tmp/aunpack.XXXXXXXXXX`
atool -x --save-outdir=$TMP "$@"
DIR="`cat $TMP`"
[ "$DIR" != "" -a -d "$DIR" ] && cd "$DIR"
rm $TMP
}
Si no tiene el programa mktemp, puede reemplazar la segunda línea con (sin embargo, tenga en cuenta que esto no es completamente seguro)
TMP="/tmp/atool_outdir.$$"

ERRORES CONOCIDOS

Intentar extraer archivos gzip y otros archivos comprimidos sin la extensión .gz (o .bz2 etc) no funcionará:


aunpack: foo: formato desconocido, identificando usando file
aunpack: foo: el formato es `gzip'
gzip: foo: sufijo desconocido -- ignorado

Este último error de arriba es generado por gzip -d foo.

Si encuentra un error que no está listado aquí, por favor repórtelo a <oskar@osk.mine.nu>.
