ATMARPD(8) Comandos de mantenimiento ATMARPD(8)

NOMBRE

atmarpd - demonio ATMARP

SINOPSIS

atmarpd [-b] [-d] [-D directorio] [-l archivo_log] [-m] [-n]
atmarpd -V

DESCRIPCIÓN

atmarpd implementa el protocolo ATMARP según lo especificado en RFC1577 y RFC1755. Las solicitudes de resolución de direcciones se envían desde el kernel (utilizando un protocolo comparativamente simple) al demonio ATMARP, que luego realiza el diálogo con la red.

atmarpd puede operar como cliente ATMARP y como servidor ATMARP. También soporta el uso concurrente de varias interfaces IP sobre ATM.

atmarpd se configura desde la línea de comandos utilizando el programa atmarp. A menos que la depuración esté habilitada, la tabla ATMARP se escribe después de cada cambio en el archivo /var/run/atmarpd.table (o en un archivo con el mismo nombre en un directorio diferente, si se utiliza la opción -D).

Tenga en cuenta que atmarpd deshabilita el soporte para SVCs si la señalización no está disponible en el momento de inicio, es decir, si atmsigd no se está ejecutando.

OPCIONES

-b
Ejecutar en segundo plano (es decir, en un proceso hijo bifurcado) después de inicializar.
-d
Habilita (mucha) salida de depuración. Por defecto, atmarpd es comparativamente silencioso.
-D directorio_volcado
Cambia el directorio donde atmarpd escribe su tabla (atmarpd.table). Por defecto, se utiliza /var/run.
-l archivo_log
Escribe mensajes de diagnóstico en el archivo especificado en lugar de en la salida estándar de error. El nombre especial syslog se utiliza para enviar diagnósticos al registrador del sistema.
-m
Habilita la fusión de llamadas entrantes si la dirección es conocida. Una conexión entrante para la que aún no se ha recibido una respuesta InARP, pero que se origina desde una dirección ATM para la que ya existe una entrada ATMARP, se añade automáticamente a esa entrada. Esto asume que hay una mapeo 1:1 entre direcciones IP y direcciones ATMARP. Por defecto, esta suposición no se hace, lo que a menudo resulta en la configuración de conexiones duplicadas. Tenga en cuenta que RFC1577 requiere que un servidor ATMARP envíe una solicitud InARP en una conexión entrante. Por lo tanto, la fusión puede violar RFC1577 en este caso.
-n
Imprime las direcciones solo en formato numérico, es decir, no se intenta ninguna traducción de dirección a nombre.
-V
Imprime el número de versión de atmarpd en la salida estándar y sale.

ARCHIVOS

/var/run/atmarpd.table
Tabla ATMARP
/proc/atm/arp
Tabla de VCs IP sobre ATM actualmente activos

ERRORES

atmarpd elimina las entradas ATMARP de la tabla del kernel mientras las actualiza.
