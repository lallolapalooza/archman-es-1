NOMBRE

atmsigd.conf - archivo de configuración para el demonio de señalización ATM

SINOPSIS

/etc/atmsigd.conf

DESCRIPCIÓN

atmsigd.conf contiene datos de configuración para atmsigd. atmsigd lee atmsigd.conf después de analizar las opciones de la línea de comandos, antes de conectarse a la red ATM.

Los parámetros de configuración están organizados en grupos funcionales. Para configurar un parámetro, se deben especificar el nombre del grupo, el nombre del parámetro y el(los) valor(es) del parámetro, por ejemplo:

     sig level debug
disminuye el umbral de registro de mensajes relacionados con la señalización al nivel debug. Se reconocen las siguientes opciones:
debug dump ruta
Especifica el directorio en el que atmsigd escribirá volcados de estado y de rastreo. Si el rastreo aún no está habilitado, el tamaño del rastreo se establece automáticamente a un valor (pequeño) predeterminado.
debug level nivel
Establece el nivel de depuración predeterminado a nivel. nivel puede ser cualquiera de debug, info, warn, error, y fatal. Solo se imprimen los mensajes con una prioridad igual o superior al nivel de depuración. Tenga en cuenta que la opción de línea de comandos -d genera aún más salida (por ejemplo, volcados hexadecimales de todos los paquetes que pasan entre atmsigd y la red) que debug level debug.
debug log ruta
Especifica el archivo en el que atmsigd escribe los mensajes de registro. Al usar el nombre de archivo especial syslog, los mensajes se envían al registrador del sistema. Los mensajes de registro se escriben en la salida estándar si no se especifica ningún archivo de registro. La escritura en la salida estándar también se puede solicitar explícitamente utilizando el nombre de archivo especial stderr.
debug trace [número]
Habilita el rastreo y opcionalmente establece el número de entradas que deben conservarse en el búfer de rastreo. Se utiliza un valor predeterminado (pequeño) si se omite el número.
io level nivel
Establece el nivel de depuración para mensajes relacionados con IO a nivel.
io max_rate tasa
Establece la tasa a señalar si una aplicación solicita el "máximo". Consulte qos(7) para ver la sintaxis que se utiliza para expresar la tasa. La tasa máxima predeterminada es 353207 celdas/segundo (OC3). (Tenga en cuenta que el valor de max_rate no restringe las tasas que una aplicación puede solicitar explícitamente).
io qos qos
Configura la VC de señalización para usar el QOS especificado (consulte qos(7) para ver la sintaxis). Por defecto, se utiliza UBR a la velocidad del enlace en la VC de señalización.
io vc [itf.]vpi.vci
Utiliza la VC especificada para los mensajes de señalización en lugar de la habitual 0.0.5.
saal level nivel
Establece el nivel de depuración para mensajes relacionados con SAAL (es decir, SSCF y SSCOP) a nivel.
sig level nivel
Establece el nivel de depuración para mensajes relacionados con la señalización (Q.2931 o ISP) a nivel.
sig mode modo
Establece el modo de operación. Los siguientes modos están disponibles: user para el lado del usuario, network para el lado de la red y switch para operar en un conmutador. El comportamiento predeterminado es user.
sig uni30
Utiliza señalización UNI 3.0. Si se especifica junto con sig uni31, esta opción configura la señalización UNI 3.1 con algunas extensiones de compatibilidad hacia atrás.
sig uni31
Utiliza señalización UNI 3.1. Esta opción se puede combinar con sig uni30 (ver arriba).
sig uni40
Utiliza señalización UNI 4.0. Esta opción se puede combinar con sig q.2963.1 (ver más abajo).
sig q.2963.1
Habilita la renegociación de la tasa de celdas pico. Esta opción solo está disponible con señalización UNI 4.0.
sig vpci vpci itf itf
Configura un tipo de enrutamiento muy simplista. Todas las llamadas con valores VPCI iguales o mayores que vpci se enrutarán a itf, y sus valores VPI se establecerán al VPCI señalado menos vpci. Se pueden usar múltiples entradas sig vpci para soportar un número arbitrario de interfaces. Ejemplo: con sig vpci 4 itf 1, una llamada señalada para VPCI/VCI 0.x se enruta a 0.0.x, una llamada señalada para 6.y se enruta a 1.2.y, etc.
policy level nivel
Establece el nivel de depuración para mensajes relacionados con decisiones de política a nivel.
policy decision direccion direccion
Toma la decision especificada para llamadas desde o hacia direccion. decision puede ser allow o reject. direccion es from o to. La direccion puede ser comodín anteponiendo una barra y el número de bits significativos (NSAP) o dígitos (E.164). Las reglas se buscan en el orden en que aparecen en atmsigd.conf hasta la primera coincidencia. Si ninguna regla coincide, se permite la llamada.
entity [itf.]vpi.vci { opciones ... }
Activa una entidad de señalización en esa VC específica. Pueden aparecer múltiples cláusulas entity en la misma configuración. Al usar entity, la opción io vc no está disponible. entity va seguida opcionalmente por las siguientes opciones, encerradas entre llaves: vpci (corresponde a sig vpci), mode (corresponde a sig mode), qos (corresponde a vc qos), route y default. Las dos últimas opciones determinan cómo se enrutan las llamadas salientes. La opción route va seguida de una dirección en el formato utilizado para las direcciones en policy. Si ninguna entrada de ruta coincide con el número de parte llamada de una llamada saliente, se selecciona la entrada marcada con default.

Al configurar múltiples parámetros en el mismo grupo, el nombre del grupo no tiene que repetirse si va seguido de los parámetros entre llaves. Ejemplo:

    debug {
        level warn
        dump /var/tmp
        log syslog
        trace 100
    }

Se pueden insertar saltos de línea en atmsigd.conf donde sea que se permitan espacios o tabulaciones. Todo lo que esté entre un `#` y el final de la línea se considera un comentario. El carácter `#` no se puede escapar.

Si una opción se especifica en atmsigd.conf y en la línea de comandos, la línea de comandos tiene prioridad.

COMPATIBILIDAD

Ciertas opciones utilizadas por versiones anteriores de atmsigd pero que ya no se documentan en la página del manual todavía se reconocen y admiten, pero también generan un mensaje de advertencia. Las versiones futuras de atmsigd no reconocerán esas opciones.
