attr_list(3)

Paquete: attr

Licencias: LGPL

ATTR_LIST(3) API de compatibilidad con XFS ATTR_LIST(3)

NOMBRE

attr_list, attr_listf - listar los nombres de los atributos de usuario de un objeto del sistema de archivos

SINOPSIS

#include <attr/attributes.h>

int attr_list (const char ∗path, char ∗buffer, 
               const int buffersize, int flags,
               attrlist_cursor_t ∗cursor);
int attr_listf (int fd, char ∗buffer, 
                const int buffersize, int flags,
                attrlist_cursor_t ∗cursor);

DESCRIPCIÓN

Las funciones attr_list y attr_listf proporcionan una forma de listar los atributos existentes de un objeto del sistema de archivos.

path apunta al nombre de una ruta de un objeto del sistema de archivos, y fd se refiere al descriptor de archivo asociado con un archivo. El buffer se llenará con una estructura que describe al menos una porción de los atributos asociados con el objeto del sistema de archivos dado. Buffer será sobrescrito con una estructura attrlist_t que contiene una lista de los atributos asociados con ese objeto del sistema de archivos, hasta un máximo de buffersize bytes. El buffer debe ser lo suficientemente grande como para contener las estructuras de datos apropiadas más al menos un nombre de atributo de tamaño máximo, pero no puede tener más de ATTR_MAX_VALUELEN (actualmente 64 KB) bytes de longitud.

El contenido de una estructura attrlist_t incluye los siguientes miembros:

int32_t al_count; /∗ número de entradas en attrlist ∗/
int32_t al_more; /∗ T/F: ¿más atributos (hacer syscall de nuevo)? ∗/
int32_t al_offset[1]; /∗ desplazamientos en bytes de los atributos [tamaño variable] ∗/

El campo al_count muestra el número de atributos representados en este buffer, que también es el número de elementos en el array al_offset. El campo al_more será distinto de cero si otra llamada a attr_list resultara en más atributos. El array al_offset contiene el desplazamiento en bytes dentro del buffer de la estructura que describe cada uno de los atributos, una estructura attrlist_ent_t. La macro ATTR_ENTRY(buffer, index) ayudará a decodificar la lista. Toma un puntero al buffer y un index en el array al_offset y devuelve un puntero a la estructura attrlist_ent_t correspondiente.

El contenido de una estructura attrlist_ent_t incluye los siguientes miembros:

uint32_t a_valuelen; /∗ número de bytes en el valor del atributo ∗/
char a_name[]; /∗ nombre del atributo (terminado en NULL) ∗/

El campo a_valuelen muestra el tamaño en bytes del valor asociado con el atributo cuyo nombre está almacenado en el campo a_name. El nombre es una cadena terminada en NULL.

Tenga en cuenta que el valor del atributo no se puede obtener a través de esta interfaz; se debe usar la llamada attr_get para obtener el valor. La interfaz attr_list le dice al proceso que llama qué tamaño de buffer necesita para obtener el valor del atributo.

El argumento flags puede contener los siguientes símbolos combinados con OR bit a bit:

ATTR_ROOT
Listar los atributos que están en el espacio de direcciones root, no en el espacio de direcciones user. (limitado al uso solo por el superusuario)
ATTR_DONTFOLLOW
No seguir los enlaces simbólicos al resolver una ruta en una llamada a la función attr_list. El valor predeterminado es seguir los enlaces simbólicos.

El argumento cursor es un puntero a una estructura de datos opaca que el kernel utiliza para rastrear la posición del proceso que llama en la lista de atributos. Las únicas operaciones válidas sobre un cursor son pasarlo a una llamada a la función attr_list o ponerlo a cero. Debe ponerse a cero antes de la primera llamada a attr_list. Tenga en cuenta que las aplicaciones multihilo pueden mantener más de un cursor para servir a múltiples contextos, es decir, la llamada a attr_list es "segura para hilos".

attr_list fallará si se cumple una o más de las siguientes condiciones:

[ENOENT]
El archivo nombrado no existe.
[EPERM]
El ID de usuario efectivo no coincide con el propietario del archivo y el ID de usuario efectivo no es superusuario.
[ENOTDIR]
Un componente del prefijo de ruta no es un directorio.
[EACCES]
Se deniega el permiso de búsqueda en un componente del prefijo de ruta.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema, o el buffer era demasiado pequeño o demasiado grande.
[EFAULT]
Tanto Path como buffer apuntan fuera del espacio de direcciones asignado del proceso, o buffer o bufsize no están alineados a 32 bits.
[ELOOP]
Una búsqueda de nombre de ruta implicó demasiados enlaces simbólicos.
[ENAMETOOLONG]
La longitud de path excede {MAXPATHLEN}, o un componente del nombre de ruta es más largo que {MAXNAMELEN}.
[ENOATTR]
El atributo no existe para este archivo.

attr_listf fallará si:

[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema, o fd se refiere a un socket, no a un archivo, o el buffer era demasiado pequeño o demasiado grande.
[EFAULT]
Tanto Path como buffer apuntan fuera del espacio de direcciones asignado del proceso, o buffer o bufsize no están alineados a 32 bits.
[EBADF]
Fd no se refiere a un descriptor válido.

DIAGNÓSTICOS

Al completarse con éxito, se devuelve el valor 0. De lo contrario, se devuelve el valor -1 y se establece errno para indicar el error.
