ATOPSAR(1) Manual de Comandos Generales ATOPSAR(1)

NOMBRE

atopsar - Informe Avanzado de Actividad del Sistema (relacionado con atop)

SINOPSIS

atopsar [-flags...] [-r archivo|fecha|- ] [-R cnt ] [-b [AAAA MM DD]hhmm[ss] ] [-e [AAAA MM DD]hhmm[ss] ]
atopsar [-flags...] intervalo [ muestras ]

DESCRIPCIÓN

El programa atopsar puede ser utilizado para reportar estadísticas a nivel de sistema.

En la primera línea de sinopsis (sin intervalo de muestreo especificado), atopsar extrae datos de un archivo de registro sin procesar que ha sido grabado previamente por el programa atop (opción -w del programa atop).
Puedes especificar el nombre del archivo de registro con la opción -r del programa atopsar. Cuando se utiliza un archivo de registro diario de atop, llamado /var/log/atop/atop_AAAA MM DD (donde AAAA MM DD refleja la fecha), la fecha requerida con formato AAAA MM DD se puede especificar con la opción -r en lugar del nombre del archivo, o se puede usar el nombre simbólico 'y' para el archivo de registro diario de ayer (esto se puede repetir, así 'yyyy' indica el archivo de registro de hace cuatro días), o se puede usar el nombre de archivo '-' para leer datos sin procesar desde la entrada estándar. Si la opción -r no se especifica en absoluto, se utiliza el archivo de registro diario de hoy por defecto.

Los tiempos de inicio y fin del informe se pueden definir usando las opciones -b y -e seguidas de un argumento de tiempo con el formato [AAAA MM DD]hhmm[ss].

En la segunda línea de sinopsis, atopsar lee los contadores de actividad actuales del kernel con el intervalo especificado (en segundos) y el número de muestras especificado (opcionalmente). Cuando atopsar se activa de esta manera, envía inmediatamente la salida para cada informe solicitado a la salida estándar. Si solo se solicita un tipo de informe, la cabecera se imprime una vez y después de cada intervalo de segundos se muestran los contadores estadísticos para ese período. Si se solicitan varios informes, se imprime una cabecera por muestra seguida de los contadores estadísticos para ese período.

Algunas banderas genéricas se pueden especificar para influir en el comportamiento del programa atopsar:

-S
Por defecto, la marca de tiempo al principio de una línea se suprime si se muestran más líneas para un intervalo. Con esta bandera, se proporciona una marca de tiempo para cada línea de salida (más fácil para post-procesamiento).
-a
Por defecto, ciertos recursos como discos e interfaces de red solo se muestran cuando estuvieron activos durante el intervalo. Con esta bandera, se muestran todos los recursos de un tipo dado, incluso si estuvieron inactivos durante el intervalo.
-x
Por defecto, atopsar solo usa colores si la salida se dirige a una terminal (ventana). Estos colores podrían indicar que se ha alcanzado un porcentaje de ocupación crítico (rojo) o casi se ha alcanzado (cian) para un recurso particular. Consulte la página man de atop para una descripción detallada de esta característica (sección COLORS).
Con la bandera -x, el uso de colores se suprime incondicionalmente.
-C
Por defecto, atopsar solo usa colores si la salida se dirige a una terminal (ventana). Estos colores podrían indicar que se ha alcanzado un porcentaje de ocupación crítico (rojo) o casi se ha alcanzado (cian) para un recurso particular. Consulte la página man de atop para una descripción detallada de esta característica (sección COLORS).
Con la bandera -C, los colores siempre se usarán, incluso si la salida no se dirige a una terminal.
-M
Utiliza marcadores al final de una línea para indicar que se ha alcanzado un porcentaje de ocupación crítico ('*') o casi se ha alcanzado ('+') para recursos particulares. El marcador '*' es similar al color rojo y el marcador '+' al color cian. Consulte la página man de atop para una descripción detallada de estos colores (sección COLORS).
-H
Repite la línea de cabecera dentro de un informe por cada N líneas de detalle. El valor de N se determina dinámicamente en caso de salida a tty/ventana (dependiendo del número de líneas); para salida a archivo o pipe, este valor es 23.
-R
Resume cnt muestras en una sola muestra. Cuando el archivo de registro contiene, por ejemplo, muestras de 10 minutos, el uso de la bandera '-R 6' muestra un informe con una muestra por cada hora.

Para más detalles sobre el formato de la salida, consulte la página man de atop.

atopsar produce una salida que contiene varias líneas por cada muestreo o intervalo. La primera línea es una cabecera que describe las columnas. Por defecto, las columnas que contienen valores de cero no se muestran, excepto cuando se utiliza la opción -a.

El formato de las líneas de informe se indica por la primera columna de la línea de cabecera.

CPU
Utilización de la CPU (porcentajes).
GPU
Utilización de la GPU (porcentajes).
GPU-MEM
Utilización de memoria de la GPU (porcentajes).
PROC
Uso de CPU, memoria y estado por proceso.
LOAD
Promedio de carga, interrupciones, etc.
MEM
Ocupación de memoria y swap.
PAGESWAP
Pagina y actividad de swap.
PSI
Pressure Stall Information.
LVDSK
Utilización de volúmenes lógicos y discos.
DSK
Utilización de discos.
NFS
Utilización de NFS.
NFSCLIENT
Actividad del cliente NFS.
NFS_SRV
Actividad del servidor NFS.
NET
Tráfico de red y errores por interfaz.
IP4
Tráfico IPv4 y errores.
ICMP4
Actividad ICMPv4.
UDP4
Tráfico UDPv4.
IP6
Tráfico IPv6 y errores.
ICMP6
Actividad ICMPv6.
UDP6
Tráfico UDPv6.
TCP4
Tráfico TCPv4 y errores.
TCP6
Tráfico TCPv6 y errores.
IB
Utilización de Infiniband.
TOP-PROC
3 procesos principales por consumo de CPU.

3 procesos principales por transferencias de disco.
TOP-NET
3 procesos principales por transferencias de socket de red.

EJEMPLOS

Mostrar la utilización de la CPU y la memoria para el día de hoy (si el archivo de registro existe):
atopsar -cm
Mostrar la utilización de la CPU y la memoria para el día de ayer:
atopsar -ym -cm
Mostrar la utilización de la CPU, memoria y disco para las últimas 24 horas, con marcas de tiempo completas:

       atopsar -r /var/log/atop/atop_20170315 -c -m -d -S

Muestre la utilización de la CPU y la memoria cada 5 segundos, 10 veces:

       atopsar 5 10 -cm

Resumir un archivo de registro de 10 minutos en intervalos de 1 hora:

       atopsar -r /var/log/atop/atop_20170315 -R 6 -A

Dependiendo del informe solicitado, se generan varias columnas con valores de salida. Los valores se presentan en su mayoría como una cantidad de eventos por segundo.

La salida para el indicador -c contiene las siguientes columnas por cpu:

usr%
Porcentaje de tiempo de cpu consumido en modo usuario (texto del programa) para todos los procesos activos que se ejecutan con un valor nice de cero (predeterminado) o un valor nice negativo (lo que significa una prioridad más alta de lo habitual). El consumo de cpu en modo usuario de los procesos con un valor nice mayor que cero (prioridad más baja) se indica en la columna nice%.
nice%
Porcentaje de tiempo de cpu consumido en modo usuario (es decir, texto del programa) para todos los procesos que se ejecutan con un valor nice mayor que cero (lo que significa una prioridad más baja de lo promedio).
sys%
Porcentaje de tiempo de cpu consumido en modo sistema (texto del kernel) para todos los procesos activos. Un porcentaje alto generalmente indica que se están realizando muchas llamadas al sistema.
irq%
Porcentaje de tiempo de cpu consumido para el manejo de interrupciones de dispositivos.
softirq%
Porcentaje de tiempo de cpu consumido para el manejo de interrupciones de software.
steal%
Porcentaje de tiempo de cpu robado por otras máquinas virtuales que se ejecutan en el mismo hardware.
guest%
Porcentaje de tiempo de cpu utilizado por otras máquinas virtuales que se ejecutan en el mismo hardware (se superpone con usr%/nice%).
wait%
Porcentaje de tiempo de cpu no utilizado mientras al menos uno de los procesos en estado de espera espera la finalización de la E/S de disco.
idle%
Porcentaje de tiempo de cpu no utilizado porque todos los procesos están en estado de espera pero no están esperando la E/S de disco.

La salida para el indicador -g contiene las siguientes columnas por GPU:

busaddr
Número de GPU y bus-ID (separados por '/').
gpubusy
Porcentaje de actividad de la GPU durante el intervalo.
membusy
Porcentaje de actividad de la memoria de la GPU durante el intervalo, es decir, el tiempo para emitir accesos de lectura y escritura en la memoria.
memocc
Porcentaje de ocupación de memoria en este momento.
memtot
Memoria total disponible.
memuse
Memoria de la GPU utilizada en este momento.
gputype
Tipo de GPU.

La salida para el indicador -p contiene los siguientes valores:

pswch/s
Número de cambios de proceso (también llamados cambios de contexto) por segundo en esta cpu. Un cambio de proceso ocurre en el momento en que un hilo activo (es decir, el hilo que está usando una cpu) entra en un estado de espera o ha utilizado completamente su porción de tiempo; entonces se elegirá otro hilo para usar la cpu.
devintr/s
Número de interrupciones de hardware manejadas por segundo en esta cpu.
clones/s
El número de nuevos hilos iniciados por segundo.
loadavg1
Carga promedio que refleja el número promedio de hilos en la cola de ejecución o en estado de espera no interrumpible (generalmente esperando la E/S de disco o cinta) durante el último minuto.
loadavg5
Carga promedio que refleja el número promedio de hilos en la cola de ejecución o en estado de espera no interrumpible (generalmente esperando la E/S de disco o cinta) durante los últimos 5 minutos.
loadavg15
Carga promedio que refleja el número promedio de hilos en la cola de ejecución o en estado de espera no interrumpible (generalmente esperando la E/S de disco o cinta) durante los últimos 15 minutos.

El número de nuevos hilos iniciados por segundo.
pexit/s
curproc

curzomb
Número de procesos zombi presentes en el sistema.
trun
Número total de hilos presentes en el sistema en estado 'ejecutándose'.
tslpi
Número total de hilos presentes en el sistema en estado 'durmiendo interrumpible'.
tslpu
Número total de hilos presentes en el sistema en estado 'durmiendo no interrumpible'.
tidle

La salida para el indicador -m contiene información sobre la utilización de memoria y swap:

memtotal
Tamaño total de la memoria principal utilizable.
memfree
Tamaño de la memoria principal disponible en este momento (instantánea).
buffers

cached

dirty
Cantidad de memoria en la caché de páginas que aún debe ser escrita en el disco en este momento (instantánea).
slabmem
Memoria principal utilizada en este momento para la memoria asignada dinámicamente por el kernel (instantánea).
swptotal
Tamaño total del espacio de swap en este momento (instantánea).
swpfree

La salida para el indicador -s contiene información sobre la frecuencia de intercambio (swapping):

pagescan/s
Número de páginas escaneadas por segundo debido a que la memoria libre cae por debajo de un umbral particular.
swapin/s
El número de páginas de memoria que el sistema leyó del dispositivo de swap por segundo.
swapout/s
El número de páginas de memoria que el sistema escribió en el dispositivo de swap por segundo.
oomkill
El número de procesos que fueron terminados durante el último intervalo debido a la falta de memoria/swap. El valor -1 significa que este contador no es compatible con la versión actual del kernel.
commitspc
El espacio de memoria virtual comprometido, es decir, el espacio virtual reservado para todas las asignaciones de espacio de memoria privada para los procesos.
commitlim
El límite máximo para el espacio comprometido, que por defecto es el tamaño del swap más el 50% del tamaño de la memoria. El kernel solo verifica si el espacio comprometido excede el límite si está configurado el manejo estricto de sobreasignación (vm.overcommit_memory es 2).
