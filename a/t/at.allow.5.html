NOMBRE

at.allow, at.deny - determinar quién puede enviar trabajos vía at o batch

DESCRIPCIÓN

Los archivos /etc/at.allow y /etc/at.deny determinan qué usuario puede enviar comandos para su ejecución posterior a través de at(1) o batch(1).

El formato de los archivos es una lista de nombres de usuario, uno en cada línea. No se permite el uso de espacios en blanco.

Si existe el archivo /etc/at.allow, solo los nombres de usuario mencionados en él pueden usar at.

Si /etc/at.allow no existe, se comprueba /etc/at.deny. A todos los usuarios no mencionados en él se les permite entonces usar at.

Un /etc/at.deny vacío significa que todos los usuarios pueden usar at.

Si ninguno de los dos existe, solo el superusuario puede usar at.

VER TAMBIÉN

at(1), cron(8), crontab(1), atd(8).
