ATOPRC(5) Manual de Formatos de Archivo ATOPRC(5)

NOMBRE

atoprc - archivo rc relacionado con atop/atopsar

DESCRIPCIÓN

Esta página de manual documenta el archivo rc de los comandos atop y atopsar . Estos comandos se pueden utilizar para monitorizar el sistema y la carga de procesos en un sistema Linux.

El archivo atoprc contiene la configuración predeterminada. Estos ajustes se leen durante el arranque, primero desde el archivo rc del sistema completo /etc/atoprc y después desde el archivo rc específico del usuario ~/.atoprc (de modo que la configuración del sistema completo puede ser anulada por un usuario individual). Las opciones en ambos archivos rc son idénticas.

OPCIONES

El archivo rc contiene pares clave-valor, uno en cada línea (las líneas en blanco y las líneas que comienzan con un signo # se ignoran).
Se pueden especificar las siguientes palabras clave:

flags
Aquí se puede definir una lista de banderas predeterminadas para atop . Las banderas permitidas son 't', 'B', 'H', 'G', '2' hasta '9', 'g', 'm', 'd', 'n', 'u', 'p', 's', 'c', 'v', 'C', 'M', 'D', 'N', 'A', 'a', 'y', 'Y', 'f', 'F', 'R', '1', 'e', 'E' y 'x'.
twindir
La ruta absoluta predeterminada del directorio temporal en el que debe ubicarse el archivo gemelo.
interval
El valor del intervalo predeterminado en segundos.
linelen
La longitud de una línea de pantalla al enviar la salida a un archivo o tubería (por defecto 80).
username
Expresión regular o un UID numérico para seleccionar los usuarios para los que se mostrarán los procesos (activos).
procname
La expresión regular predeterminada para los nombres de proceso que se mostrarán.
maxlinecpu
El número máximo de CPU activas que se mostrarán.
maxlinegpu
El número máximo de GPU activas que se mostrarán.
maxlinelvm
El número máximo de volúmenes lógicos activos que se mostrarán.
maxlinemdd
El número máximo de dispositivos múltiples activos que se mostrarán.
maxlinedisk
El número máximo de discos activos que se mostrarán.
maxlinenfsm
El número máximo de montajes NFS que se mostrarán en un cliente NFS.
maxlineintf
El número máximo de interfaces de red activas que se mostrarán.
maxlinecont
El número máximo de contenedores activos que se mostrarán.
maxlineifb
El número máximo de puertos Infiniband que se mostrarán.
maxlinenuma
El número máximo de métricas de nodos NUMA que se mostrarán. Tenga en cuenta que se muestran dos líneas para cada nodo NUMA.
maxlinellc
El número máximo de líneas con métricas de LLC que se mostrarán.
cpucritperc
El porcentaje de ocupación considerado crítico para un procesador (véase la sección COLORES en la página man del comando atop ). Este porcentaje se utiliza para determinar un porcentaje ponderado para el coloreado de líneas y la clasificación de los procesos activos en modo texto. Cuando este valor es cero, no se realiza ningún coloreado de líneas ni ordenación automática para este recurso.
dskcritperc
El porcentaje de ocupación considerado crítico para un disco (véase la sección COLORES en la página man del comando atop ). Este porcentaje se utiliza para determinar un porcentaje ponderado para el coloreado de líneas y la clasificación de los procesos activos en modo texto. Cuando este valor es cero, no se realiza ningún coloreado de líneas ni ordenación automática para este recurso.
netcritperc
El porcentaje de ocupación considerado crítico para una interfaz de red (véase la sección COLORES en la página man del comando atop ). Este porcentaje se utiliza para determinar un porcentaje ponderado para el coloreado de líneas y la clasificación de los procesos activos en modo texto. Cuando este valor es cero, no se realiza ningún coloreado de líneas ni ordenación automática para este recurso.
memcritperc
El porcentaje considerado crítico para la utilización de la memoria (véase la sección COLORES en la página man del comando atop ). Este porcentaje se utiliza para determinar un porcentaje ponderado para el coloreado de líneas y la clasificación de los procesos activos en modo texto. Cuando este valor es cero, no se realiza ningún coloreado de líneas ni ordenación automática para este recurso.
swpcritperc
El porcentaje de ocupación considerado crítico para el espacio de intercambio (véase la sección COLORES en la página man del comando atop ). Este porcentaje se utiliza para determinar un porcentaje ponderado para el coloreado de líneas y la clasificación de los procesos activos en modo texto. Cuando este valor es cero, no se realiza ningún coloreado de líneas ni ordenación automática para este recurso.
swoutcritsec
El número de páginas intercambiadas por segundo considerado crítico para la utilización de la memoria (véase la sección COLORES en la página man del comando atop ). Este umbral se utiliza en combinación con 'memcritperc' para determinar un porcentaje ponderado para el coloreado de líneas y la clasificación de los procesos activos en modo texto. Cuando este valor es cero, no se realiza ningún coloreado de líneas ni ordenación automática para este recurso.
almostcrit
Un porcentaje del porcentaje crítico para determinar si el recurso es casi crítico (véase la sección COLORES en la página man del comando atop ). Cuando este valor es cero, no se realiza ningún coloreado para 'casi crítico'.
cpubarwidth
Número de columnas utilizadas por barra en el gráfico de barras del procesador. El valor predeterminado es 0, lo que significa que el ancho de la barra se escalará automáticamente (cuanto más ancha sea la terminal, más columnas por barra, hasta un máximo de tres). Con el valor 1, 2 o 3, el número de barras se puede fijar estáticamente a ese número de columnas, con una columna de espacio en blanco entre las barras.
colorinfo
Definición del nombre del color para los mensajes de información (por defecto: verde) en modo texto.
Los colores permitidos son: red green yellow blue magenta cyan black white.
colorthread
Definición del nombre del color para las líneas específicas de hilo al usar la opción 'y' (por defecto: yellow).
Los colores permitidos son: red green yellow blue magenta cyan black white.
coloralmost
Definición del nombre del color para los recursos casi críticos (por defecto: cyan) en modo texto.
Los colores permitidos son: red green yellow blue magenta cyan black white.
colorcritical
Definición del nombre del color para los recursos críticos (por defecto: red) en modo texto.
Los colores permitidos son: red green yellow blue magenta cyan black white.
atopsarflags
Aquí se puede definir una lista de banderas predeterminadas para atopsar . Las banderas permitidas son 'S', 'x', 'C', 'M', 'H', 'a', 'A' y las banderas para seleccionar uno o más informes específicos.
perfevents
Define si el contador de ciclos de la CPU debe ser recuperado por atop a través de los contadores 'perf'. Se pueden especificar los valores 'auto' (por defecto), 'enable' o 'disable'. En el caso de 'auto', el contador de ciclos de la CPU no se recuperará en máquinas virtuales debido a la sobrecarga de leer este contador en un huésped.
pacctdir
El nombre del directorio superior utilizado por atodaemon. En este directorio, el demonio crea un subdirectorio pacct_shadow.d en el que se escribirán archivos que contienen los registros de contabilidad de procesos. El directorio principal predeterminado es /var/run y esta opción solo debe especificarse cuando el daemon atopacctd se inicia con un directorio principal alternativo como argumento de línea de comandos.
Esta opción solo se puede especificar en el archivo /etc/atoprc (a nivel de sistema).

Un ejemplo del archivo /etc/atoprc o ~/.atoprc:

 

flags         Aaf
interval      5
username
procname
maxlinecpu    4
maxlinedisk   10
maxlineintf   5
cpucritperc   80
almostcrit    90
atopsarflags  CMH
ownprocline   PID:50 VGROW:40 RGROW:45 COMMAND-LINE:50
ownpagline    PAGSCAN:3 BLANKBOX:0 PAGSWIN:3 PAGSWOUT:7

Las palabras clave 'ownprocline' y 'ownpagline' se explican en la sección siguiente.

DEFINICIÓN PROPIA DE LÍNEA DE SALIDA

A través del archivo rc es posible definir el diseño de las líneas de salida uno mismo, es decir, se puede definir el diseño de una línea con información de procesos con la palabra clave 'ownprocline' (a seleccionar con la tecla 'o' o el flag -o) y se pueden redefinir todas las líneas con información del sistema.

El diseño de una línea de salida se puede definir de la siguiente manera (observe que esto debe especificarse como una línea en el archivo rc):

   keyword   <columnid>:<prio> [<columnid>:<prio> ...]

El columnid es el nombre simbólico de una columna que se mostrará en esta posición en la línea de salida.
El prio es un valor entero positivo que determina qué columnas tienen precedencia cuando no todas las columnas especificadas caben en el ancho de pantalla actual. Cuanto mayor sea el valor, mayor será la prioridad.
Las especificaciones de columna deben estar separadas por un espacio. El orden en que se especifican las columnas es el orden en que se mostrarán, con respecto a su prioridad (las columnas que no caben se eliminarán dinámicamente).

Un columnid especial para las líneas del sistema es 'BLANKBOX'. Esto indica que se requiere una columna vacía en esta posición. También este columnid especial va seguido de una prioridad (generalmente baja).

La siguiente definición se puede especificar para información de procesos:

ownprocline
Los columnids son los nombres de las columnas que se muestran en la salida normal de las líneas relacionadas con procesos que muestra atop, como 'PID', 'CMD', 'S', etc. La única excepción es el columnid especial 'SORTITEM', que se utiliza para mostrar una de las columnas CPU%/DSK%/MEM%/NET%, dependiendo del criterio de ordenación elegido.
Un ejemplo de una línea de proceso definida por el usuario:
 
ownprocline   PID:20 PPID:10 SYSCPU:15 USRCPU:15 VGROW:14 VSIZE:12 RGROW:14 RSIZE:12 ST:8 EXC:7 S:11 SORTITEM:18 CMD:20

Las siguientes definiciones son utilizadas internamente por atop como las líneas del sistema predeterminadas (se puede redefinir cada una de ellas en el archivo rc como una sola línea):

ownsysprcline
Redefinición de la línea etiquetada con 'PRC':
 
ownsysprcline   PRCSYS:8 PRCUSER:8 BLANKBOX:0 PRCNPROC:7 PRCNZOMBIE:5 PRCCLONES:4 BLANKBOX:0 PRCNNEXIT:6
ownallcpuline
Redefinición de la línea etiquetada con 'CPU' para la utilización total de la CPU:
 
ownallcpuline   CPUSYS:8 CPUUSER:7 CPUIRQ:4 BLANKBOX:0 CPUIDLE:5 CPUWAIT:6 BLANKBOX:0 CPUSTEAL:1 CPUGUEST:3
ownonecpuline
Redefinición de la línea etiquetada con 'CPU' para la utilización de una CPU:
 
ownonecpuline   CPUISYS:8 CPUIUSER:7 CPUIIRQ:4 BLANKBOX:0 CPUIIDLE:5 CPUIWAIT:6 BLANKBOX:0 CPUISTEAL:1 CPUIGUEST:3
owncplline
Redefinición de la línea etiquetada con 'CPL':
 
owncplline   CPLAVG1:4 CPLAVG5:3 CPLAVG15:2 BLANKBOX:0 CPLCSW:6 CPLINTR:5 BLANKBOX:0 CPLNUMCPU:1
ownmemline
Redefinición de la línea etiquetada con 'MEM':
 
ownmemline   MEMTOT:2 MEMFREE:5 MEMCACHE:3 MEMDIRTY:1 MEMBUFFER:3 MEMSLAB:3 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0
ownswpline
Redefinición de la línea etiquetada con 'SWP':
 
ownswpline   SWPTOT:3 SWPFREE:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 SWPCOMMITTED:5 SWPCOMMITLIM:6
ownpagline
Redefinición de la línea etiquetada con 'PAG':
 
ownpagline   PAGSCAN:3 PAGSTALL:1 BLANKBOX:0 PAGSWIN:4 PAGSWOUT:3
owndskline
Redefinición de las líneas etiquetadas con 'LVM', 'MDD' y 'DSK':
 
owndskline   DSKNAME:8 DSKBUSY:7 DSKNREAD:6 DSKNWRITE:6 DSKKBPERRD:4 DSKKBPERWR:4 DSKMBPERSECRD:5 DSKMBPERSECWR:5 DSKAVQUEUE:1 DSKAVIO:5
ownnettrline
Redefinición de la línea etiquetada con 'NET' para transporte:
 
ownnettrline   NETTRANSPORT:9 NETTCPI:8 NETTCPO:8 NETUDPI:8 NETUDPO:8 NETTCPACTOPEN:6 NETTCPPASVOPEN:5 NETTCPRETRANS:4 NETTCPINERR:3 NETTCPORESET:20 NETUDPNOPORT:1 NETUDPINERR:3
ownnetnetline
Redefinición de la línea etiquetada con 'NET' para red:
 
ownnetnetline   NETNETWORK:5 NETIPI:4 NETIPO:4 NETIPFRW:4 NETIPDELIV:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 NETICMPIN:1 NETICMPOUT:1
ownnetifline
Redefinición de la línea etiquetada con 'NET' para interfaces:
 
ownnetifline   NETNAME:8 NETPCKI:7 NETPCKO:7 NETSPEEDIN:6 NETSPEEDOUT:6 NETCOLLIS:3 NETMULTICASTIN:2 NETRCVERR:5 NETSNDERR:5 NETRCVDROP:4 NETSNDDROP:4

Las líneas anteriores se muestran en el orden en que las muestra atop en combinación con el flag -f (en una ventana muy ancha deberías poder ver todas las columnas).
