ATOPACCTD(8) Manual del Administrador del Sistema ATOPACCTD(8)

NOMBRE

atopacctd - demonio de contabilidad de procesos

SINOPSIS

atopacctd [-v | directorio_superior]

DESCRIPCIÓN

El demonio atopacctd activa la característica de contabilidad de procesos en el kernel y permite que los registros de contabilidad de procesos se escriban en un archivo, denominado archivo fuente a partir de ahora. Después de que se activa la contabilidad de procesos, el demonio atopacctd transfiere cada registro de contabilidad de procesos que está disponible en el archivo fuente a un archivo sombra. Los procesos cliente (como los procesos atop) leerán los archivos sombra en lugar del archivo fuente de contabilidad de procesos.
De esta manera, el demonio atopacctd opera como una 'capa' entre el archivo de contabilidad de procesos que es escrito por el kernel y los archivos de contabilidad sombra que son leídos por los procesos de atop.

Este enfoque tiene las siguientes ventajas:

o
El demonio atopacctd se encarga de que el archivo fuente se mantenga a un tamaño limitado. Tan pronto como se alcanza su tamaño máximo, se trunca a un tamaño de cero nuevamente (esto no es notado por los procesos atop).
o
El demonio atopacctd se encarga de que un archivo sombra se mantenga a un tamaño limitado. Tan pronto como el archivo sombra actual alcanza este tamaño máximo, el demonio atopacctd crea un nuevo archivo sombra (subsiguiente). Mientras los procesos cliente todavía tienen la posibilidad de leer el archivo(s) sombra(s) anterior(es), el demonio atopacctd continúa escribiendo registros de contabilidad en el archivo sombra más reciente (actual). Por esta razón, el nombre de un archivo sombra consiste en un número de secuencia de 10 dígitos seguido de la extensión '.paf' (archivo de contabilidad de procesos). Los archivos sombra antiguos que ya no son utilizados por los procesos cliente son eliminados automáticamente por el recolector de basura en el demonio atopacctd.
o
Cuando no hay procesos cliente activos (más), todos los archivos sombra serán eliminados y no se transferirán más registros a un archivo sombra. Tan pronto como al menos un cliente esté activo nuevamente, el demonio atopacctd continuará escribiendo archivos sombra.

El directorio /var/run se utiliza como directorio superior predeterminado. Debajo de este directorio superior, se crea el archivo fuente pacct_source al que el kernel escribe los registros de contabilidad de procesos.
Además, se crea el subdirectorio pacct_shadow.d como un 'contenedor' para los archivos sombra. Aparte de los archivos sombra, también se mantiene el archivo current en este subdirectorio, que contiene el número de secuencia del archivo sombra actual (más reciente) y el número máximo de registros que se escribirán en cada archivo sombra.

Se puede especificar un directorio superior alternativo como argumento de línea de comandos. Cuando se define un directorio superior alternativo, modifique también el archivo de configuración /etc/atoprc para informar a los clientes atop sobre esta ubicación alternativa (ver la página del manual atoprc). Dicho directorio superior alternativo debe ser propiedad de root y no debe ser escribible para el grupo u otros (razones de seguridad).

Tenga en cuenta que el kernel suspende la escritura de registros de contabilidad de procesos cuando el espacio libre del sistema de archivos en el que reside el archivo de contabilidad de procesos cae por debajo del 2%. La escritura se reanuda cuando el espacio libre es del 4% o más. Estos porcentajes de límite inferior y superior se pueden configurar a través del pseudofichero /proc/sys/kernel/acct.
El demonio atopacctd suspende la transferencia de registros de contabilidad de procesos a archivos sombra cuando el espacio libre del sistema de archivos en el que reside el archivo de contabilidad de procesos cae por debajo del 5%. La transferencia se reanuda cuando el espacio libre es del 5% o más. Se generan mensajes de registro a través de syslog cuando se suspende o reanuda la escritura en el archivo sombra actual.

La bandera -v se puede usar para verificar la versión del demonio atopacctd.

ARCHIVOS

/var/run/pacct_source
Archivo regular al que el kernel escribe los registros de contabilidad de procesos. Este archivo se truncará periódicamente.
/var/run/pacct_shadow.d/current
Archivo regular que contiene el número de secuencia del archivo sombra actual y el número máximo de registros por archivo sombra.
/var/run/pacct_shadow.d/N.paf
Archivos regulares que contienen los registros de contabilidad de procesos que han sido copiados transparentemente desde el archivo fuente (N representa un número de secuencia de 10 dígitos).
