ATEXIT(3P) Manual del programador POSIX ATEXIT(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

atexit — registrar una función para que se ejecute al terminar el proceso

SINÓPSIS

#include <stdlib.h>
int atexit(void (*func)(void));

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función atexit() registrará la función apuntada por func, para que se llame sin argumentos al terminar el programa de forma normal. Al terminar el programa de forma normal, se llamarán todas las funciones registradas por la función atexit(), en orden inverso a su registro, excepto que una función se llamará después de cualquier función registrada previamente que ya haya sido llamada en el momento de su registro. La terminación normal ocurre ya sea mediante una llamada a exit() o un retorno desde main().

Se pueden registrar al menos 32 funciones con atexit().

Después de una llamada exitosa a cualquiera de las funciones exec, cualquier función registrada previamente por atexit() dejará de estar registrada.

VALOR DE RETORNO

Al completarse con éxito, atexit() devolverá 0; de lo contrario, devolverá un valor distinto de cero.

ERRORES

No se definen errores.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

Las funciones registradas por una llamada a atexit() deben devolver para asegurar que se llamen todas las funciones registradas.

La aplicación debe llamar a sysconf() para obtener el valor de {ATEXIT_MAX}, el número de funciones que se pueden registrar. No hay forma de que una aplicación sepa cuántas funciones se han registrado ya con atexit().

Dado que el comportamiento no está definido si la función exit() se llama más de una vez, las aplicaciones portátiles que llaman a atexit() deben asegurarse de que la función exit() no se llame al terminar el proceso de forma normal cuando se llaman todas las funciones registradas por la función atexit().

Todas las funciones registradas por la función atexit() se llaman al terminar el proceso de forma normal, lo que ocurre mediante una llamada a la función exit() o un retorno desde main() o al finalizar el último hilo, cuando el comportamiento es como si la implementación llamara a exit() con un argumento cero al momento de finalizar el hilo.

Si, al terminar el proceso de forma normal, se llama a una función registrada por la función atexit() y una aplicación portátil necesita detener el procesamiento posterior de exit(), debe llamar a la función _exit() o a la función _Exit() o a una de las funciones que provocan la terminación anormal del proceso.
