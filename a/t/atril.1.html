ATRIL(1) Manual de Comandos Generales ATRIL(1)

NOMBRE

Atril - El Visor de Documentos de MATE

SINTAXIS

atril [OPCIONES...] [ARCHIVOS...]

DESCRIPCIÓN

Atril es el Visor de Documentos oficial del Entorno de Escritorio MATE, es un visor de documentos simple de múltiples páginas. Puede mostrar e imprimir archivos PostScript (PS), Encapsulated PostScript (EPS), DJVU, DVI, epub, XPS y Portable Document Format (PDF).

Cuando es compatible con el documento, también permite buscar texto, copiar texto al portapapeles, navegación por hipervínculos y marcadores de tabla de contenidos.
Esta página del manual documenta brevemente el comando atril.

OPCIONES

nombre_de_archivo(s)...
Especifica el archivo a abrir cuando se inicia atril. Si esto no se especifica, atril se iniciará con una ventana en blanco y podrá abrir un archivo desde el menú o usando el atajo CTRL+O. Se pueden cargar múltiples archivos si están separados por espacios. atril también soporta el manejo de archivos remotos.
-p, --etiqueta-pagina=PAGINA
Aquí puede especificar una etiqueta de página, esta página se seleccionará en el documento si existe.
-i, --indice-pagina=NUMERO
Aquí puede especificar un número de página, esta página se seleccionará en el documento si existe.
-f, --pantalla-completa
Inicia atril en modo de pantalla completa. Debe especificar un documento para iniciar en modo de pantalla completa.
-s, --presentacion
Inicia atril en modo de presentación. Debe especificar un documento para iniciar en modo de presentación.
-w, --vista-previa
Inicia atril en modo de vista previa. Debe especificar un documento para iniciar en modo de vista previa.
--pantalla=PANTALLA
Pantalla X a utilizar.
--version
Muestra la información de la versión y sale.
-?, -h, --ayuda
Imprime las opciones estándar de la línea de comandos.
--ayuda-todo
Imprime todas las opciones de la línea de comandos.

Este programa también acepta las opciones estándar de GTK.

EJEMPLOS

atril --vista-previa ~/Escritorio/cosas.ps

Abre cosas.ps desde el escritorio del usuario actual, en modo de vista previa.

atril -i 2 -s ./documento.pdf

Abre documento.pdf desde el directorio de trabajo actual, en la página 2 en modo de presentación.
