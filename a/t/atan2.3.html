atan2(3) Manual de Funciones de Biblioteca atan2(3)

NOMBRE

atan2, atan2f, atan2l - función arcotangente de dos variables

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double atan2(double y, double x);
float atan2f(float y, float x);
long double atan2l(long double y, long double x);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

atan2f(), atan2l():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones calculan el valor principal de la arcotangente de y/x, utilizando los signos de ambos argumentos para determinar el cuadrante del resultado.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor principal de la arcotangente de y/x en radianes; el valor de retorno está en el rango [-pi, pi].

Si y es +0 (-0) y x es menor que 0, se devuelve +pi (-pi).

Si y es +0 (-0) y x es mayor que 0, se devuelve +0 (-0).

Si y es menor que 0 y x es +0 o -0, se devuelve -pi/2.

Si y es mayor que 0 y x es +0 o -0, se devuelve pi/2.

Si x o y es NaN, se devuelve un NaN.

Si y es +0 (-0) y x es -0, se devuelve +pi (-pi).

Si y es +0 (-0) y x es +0, se devuelve +0 (-0).

Si y es un valor finito mayor (menor) que 0, y x es infinito negativo, se devuelve +pi (-pi).

Si y es un valor finito mayor (menor) que 0, y x es infinito positivo, se devuelve +0 (-0).

Si y es infinito positivo (negativo), y x es finito, se devuelve pi/2 (-pi/2).

Si y es infinito positivo (negativo) y x es infinito negativo, se devuelve +3*pi/4 (-3*pi/4).

Si y es infinito positivo (negativo) y x es infinito positivo, se devuelve +pi/4 (-pi/4).

ERRORES

No ocurren errores.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
atan2 (), atan2f (), atan2l () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

VER TAMBIÉN

acos(3), asin(3), atan(3), carg(3), cos(3), sin(3), tan(3)
