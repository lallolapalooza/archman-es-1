ATMARP(8) Comandos de mantenimiento ATMARP(8)

NOMBRE

atmarp - administrar conexiones IP clásicas sobre ATM

SINOPSIS

atmarp -a
atmarp -c [[atm]número]
atmarp -q dir_ip [qos qos] [sndbuf bytes]
atmarp -s dir_ip [itf.]vpi.vci [qos qos] [sndbuf bytes] [temp] [pub] [null]
atmarp -s dir_ip dir_atm [qos qos] [sndbuf bytes] [temp] [pub] [arpsrv]
atmarp -d dir_ip [arpsrv]
atmarp -V

DESCRIPCIÓN

atmarp se utiliza para mantener la tabla ATMARP del demonio ATMARP. La tabla se puede listar, se pueden añadir nuevas entradas PVC y SVC, y se pueden eliminar las entradas existentes. Además de eso, atmarp también se utiliza para crear nuevas interfaces IP sobre ATM.

Tenga en cuenta que el kernel tiene su propia tabla ATMARP que contiene solo las entradas para destinos a los que existe una conexión. La tabla de atmarpd también puede contener entradas actualmente no utilizadas.

OPCIONES

-a
lista la tabla ATMARP actual.
-c
crea la interfaz IP especificada. Si se omite el número de interfaz, el sistema operativo asigna el siguiente número libre y atmarp imprime el nombre de la interfaz resultante (por ejemplo, `atm0') en la salida estándar.
-q
establece la QOS y el tamaño del búfer de envío que se utilizará como valor predeterminado para todas las VC generadas para esa red IP (dir_ip debe ser la dirección de la red).
-s
configura una PVC o crea una entrada SVC. Se reconocen las siguientes opciones:
qos qos
utiliza la Calidad de Servicio especificada (ver qos(7) para la sintaxis). Se utiliza UBR a la velocidad del enlace de forma predeterminada.
sndbuf bytes
intenta establecer el búfer de envío al número de bytes especificado. Se utiliza un valor predeterminado del sistema si no se especifica sndbuf.
temp
no marca la entrada como permanente, es decir, caducará y luego se eliminará.
pub
publica la entrada (solo relevante para el servidor ATMARP). Las solicitudes ATMARP para entradas no marcadas para publicación producen una respuesta ATMARP_NAK.
null
utiliza encapsulación NULL en lugar de encapsulación LLC/SNAP en la PVC. Esta opción no está disponible para las SVC, ya que la cabecera LLC/SNAP es necesaria para identificar los paquetes ATMARP. null también implica que la entrada es permanente.
arpsrv
identifica la entrada que apunta al servidor ATMARP. Tenga en cuenta que el nodo que actúa como servidor ATMARP no debe tener ninguna entrada de servidor ATMARP en su tabla ATMARP.
-d
elimina la entrada ARP especificada. Para evitar la eliminación accidental de la entrada del servidor ATMARP, se debe especificar la marca arpsrv al eliminarla.

-V
imprime el número de versión de atmarp en la salida estándar y sale.

ARCHIVOS

tabla ATMARP
