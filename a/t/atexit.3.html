atexit(3) Manual de funciones de biblioteca atexit(3)

NOMBRE

atexit - registrar una función para ser llamada al terminar el proceso normalmente

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int atexit(typeof(void (void)) *function);

DESCRIPCIÓN

La función atexit() registra la function dada para ser llamada al terminar el proceso normalmente, ya sea a través de exit(3) o mediante el retorno de la función main() del programa. Las funciones registradas de esta manera se llaman en orden inverso a su registro; no se pasan argumentos.

La misma función puede registrarse varias veces: se llama una vez por cada registro.

POSIX.1 requiere que una implementación permita registrar al menos ATEXIT_MAX (32) funciones de este tipo. El límite real admitido por una implementación se puede obtener usando sysconf(3).

Cuando se crea un proceso hijo a través de fork(2), hereda copias de los registros de su padre. Tras una llamada exitosa a una de las funciones exec(3), se eliminan todos los registros.

VALOR DE RETORNO

La función atexit() devuelve el valor 0 si tiene éxito; de lo contrario, devuelve un valor distinto de cero.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
atexit () Seguridad de hilos MT-Safe

VERSIONES

POSIX.1 dice que el resultado de llamar a exit(3) más de una vez (es decir, llamar a exit(3) dentro de una función registrada usando atexit()) no está definido. En algunos sistemas (pero no en Linux), esto puede resultar en una recursión infinita; los programas portátiles no deben invocar exit(3) dentro de una función registrada usando atexit().

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

POSIX.1-2001, C89, C99, SVr4, 4.3BSD.

NOTAS

Las funciones registradas usando atexit() (y on_exit(3)) no se llaman si un proceso termina de forma anormal debido a la recepción de una señal.

Si una de las funciones registradas llama a _exit(2), entonces las funciones restantes no se invocan y los otros pasos de terminación del proceso realizados por exit(3) no se realizan.

Las funciones atexit() y on_exit(3) registran funciones en la misma lista: al terminar el proceso normalmente, las funciones registradas se invocan en orden inverso a su registro por estas dos funciones.

Según POSIX.1, el resultado no está definido si longjmp(3) se utiliza para terminar la ejecución de una de las funciones registradas usando atexit().

Notas de Linux

Desde glibc 2.2.3, atexit() (y on_exit(3)) se puede utilizar dentro de una biblioteca compartida para establecer funciones que se llaman cuando se descarga la biblioteca compartida.

EJEMPLOS

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void
bye(void)
{
    printf("Eso fue todo, amigos\n");
}
int
main(void)
{
    long a;
    int i;
    a = sysconf(_SC_ATEXIT_MAX);
    printf("ATEXIT_MAX = %ld\n", a);
    i = atexit(bye);
    if (i != 0) {
        fprintf(stderr, "no se puede establecer la función de salida\n");
        exit(EXIT_FAILURE);
    }
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN

_exit(2), dlopen(3), exit(3), on_exit(3)
