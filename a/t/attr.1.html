ATTR(1) API de compatibilidad XFS ATTR(1)

NOMBRE

attr - atributos extendidos en objetos del sistema de archivos XFS

SINOPSIS

attr [ -LRSq ] -s nombre_attr [ -V valor_attr ] 
ruta_archivo

attr [ -LRSq ] -g nombre_attr ruta_archivo

attr [ -LRSq ] -r nombre_attr ruta_archivo

attr [ -LRSq ] -l ruta_archivo

DESCRIPCION GENERAL

Los atributos extendidos implementan la capacidad para que un usuario adjunte pares nombre:valor a objetos dentro del sistema de archivos XFS.

Este documento describe el comando attr, que es mayormente compatible con el comando IRIX del mismo nombre. Por lo tanto, está dirigido específicamente a usuarios del sistema de archivos XFS; para la manipulación de atributos extendidos independiente del sistema de archivos, consulte la documentación de getfattr(1) y setfattr(1).

Los atributos extendidos se pueden utilizar para almacenar metainformación sobre el archivo. Por ejemplo, "character-set=kanji" podría indicar a un navegador de documentos que use el conjunto de caracteres Kanji al mostrar ese documento y "thumbnail=..." podría proporcionar una vista previa de baja resolución de una imagen gráfica de alta resolución.

En el sistema de archivos XFS, los nombres pueden tener hasta 256 bytes de longitud, terminados por el primer byte 0. La intención es que sean nombres imprimibles en ASCII (u otro conjunto de caracteres) para el atributo. Los valores pueden ser hasta 64 KB de datos binarios arbitrarios.

Los atributos se pueden adjuntar a todos los tipos de inodos XFS: archivos regulares, directorios, enlaces simbólicos, nodos de dispositivo, etc.

XFS utiliza 2 espacios de nombres de atributos disjuntos asociados con cada objeto del sistema de archivos. Son los espacios de nombres de root y user. El espacio de nombres de root solo es accesible para el superusuario, y solo especificando un argumento de bandera a la llamada de función. Otros usuarios no verán ni podrán modificar atributos en el espacio de nombres de root. El espacio de nombres de user está protegido por el mecanismo de permisos de archivos normal, por lo que el propietario del archivo puede decidir quién puede ver y/o modificar el valor de los atributos en un archivo determinado.

DESCRIPCION

La utilidad attr permite la manipulación de atributos extendidos asociados con objetos del sistema de archivos desde scripts de shell.

Hay cuatro operaciones principales que attr puede realizar:

OBTENER
La opción -g nombre_attr indica a attr que busque el objeto nombrado e imprima (en stdout) el valor asociado con ese nombre de atributo. Con la bandera -q, stdout será exactamente y solo el valor del atributo, adecuado para almacenarlo directamente en un archivo o procesarlo mediante un comando canalizado.
LISTAR
La opción -l indica a attr que enumere los nombres de todos los atributos asociados con el objeto y el número de bytes en el valor de cada uno de esos atributos. Con la bandera -q, stdout será una lista simple solo de los nombres de los atributos, uno por línea, adecuada para la entrada de un script.
ELIMINAR
La opción -r nombre_attr indica a attr que elimine un atributo con el nombre dado del objeto si el atributo existe. No hay salida en caso de éxito.
ESTABLECER/CREAR
La opción -s nombre_attr indica a attr que establezca el atributo nombrado del objeto con el valor leído desde stdin. Si ya existe un atributo con ese nombre, su valor se reemplazará por este. Si no existe un atributo con ese nombre, se creará uno con este valor. Con la bandera -V valor_attr, el atributo se establecerá con el valor valor_attr y no se leerá stdin. Con la bandera -q, no se utilizará stdout. Sin la bandera -q, se imprimirá un mensaje que muestra el nombre del atributo y el valor completo.

Cuando se proporciona la opción -L y el objeto nombrado es un enlace simbólico, opere sobre los atributos del objeto al que hace referencia el enlace simbólico. Sin esta opción, opere sobre los atributos del enlace simbólico en sí.

Cuando se proporciona la opción -R y el proceso tiene los privilegios apropiados, opere en el espacio de nombres de atributos root en lugar del espacio de nombres de atributos USER.

La opción -S es similar, excepto que especifica el uso del espacio de nombres de atributos security.

Cuando se proporciona la opción -q, attr intentará permanecer en silencio. Imprimirá mensajes de error (en stderr) pero no imprimirá mensajes de estado (en stdout).

NOTAS

Los programas estándar de intercambio/archivo de archivos tar(1) y cpio(1) no archivarán ni restaurarán atributos extendidos, mientras que el programa xfsdump(8) sí lo hará.

ADVERTENCIAS

La opción de lista presente en la versión IRIX de este comando no es compatible. getfattr proporciona un mecanismo para recuperar todos los nombres de atributos.
