attr_get(3)

Paquete: attr

Licencias: LGPL

ATTR_GET(3) API de compatibilidad XFS ATTR_GET(3)

NOMBRE

attr_get, attr_getf - obtener el valor de un atributo de usuario de un objeto del sistema de archivos

SINOPSIS

#include <attr/attributes.h>

int attr_get (const char *path, const char *attrname, 
              char *attrvalue, int *valuelength, int flags);
int attr_getf (int fd, const char *attrname, 
               char *attrvalue, int *valuelength, int flags);

DESCRIPCIÓN

Las funciones attr_get y attr_getf proporcionan una forma de recuperar el valor de un atributo.

Path apunta a un nombre de ruta para un objeto del sistema de archivos, y fd se refiere al descriptor de archivo asociado con un archivo. Si el atributo attrname existe, el valor asociado con él se copiará en el búfer attrvalue. El argumento valuelength es un argumento de entrada/salida que, en la llamada a attr_get, debe contener el tamaño máximo del valor del atributo que el proceso está dispuesto a aceptar. Al regresar, valuelength se habrá modificado para mostrar el tamaño real del valor del atributo devuelto. El argumento flags puede contener los siguientes símbolos OR-eados bit a bit:

ATTR_ROOT
Busca attrname en el espacio de direcciones root, no en el espacio de direcciones user. (limitado al uso por el superusuario únicamente)
ATTR_DONTFOLLOW
No seguir enlaces simbólicos al resolver una path en una llamada a la función attr_get. El valor predeterminado es seguir enlaces simbólicos.

attr_get fallará si se cumplen una o más de las siguientes condiciones:

[ENOATTR]
El nombre del atributo dado no está asociado con el objeto del sistema de archivos indicado.
[E2BIG]
El valor del atributo dado es demasiado grande para caber en el búfer. El entero al que apunta el argumento valuelength se ha modificado para mostrar el número real de bytes que se requerirían para almacenar el valor de ese atributo.
[ENOENT]
El archivo nombrado no existe.
[EPERM]
El ID de usuario efectivo no coincide con el propietario del archivo y el ID de usuario efectivo no es el superusuario.
[ENOTDIR]
Un componente del prefijo de la ruta no es un directorio.
[EACCES]
Se deniega el permiso de búsqueda en un componente del prefijo de la ruta.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema.
[EFAULT]
Path, attrname, attrvalue, o valuelength apunta fuera del espacio de direcciones asignado del proceso.
[ELOOP]
Una búsqueda de nombre de ruta involucró demasiados enlaces simbólicos.
[ENAMETOOLONG]
La longitud de path excede {MAXPATHLEN}, o un componente del nombre de ruta es más largo que {MAXNAMELEN}.

attr_getf fallará si:

[ENOATTR]
El nombre del atributo dado no está asociado con el objeto del sistema de archivos indicado.
[E2BIG]
El valor del atributo dado es demasiado grande para caber en el búfer. El entero al que apunta el argumento valuelength se ha modificado para mostrar el número real de bytes que se requerirían para almacenar el valor de ese atributo.
[EINVAL]
Se estableció un bit en el argumento flag que no está definido para esta llamada al sistema, o fd se refiere a un socket, no a un archivo.
[EFAULT]
Attrname, attrvalue, o valuelength apunta fuera del espacio de direcciones asignado del proceso.
[EBADF]
Fd no se refiere a un descriptor válido.

DIAGNÓSTICOS

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno apropiadamente.
