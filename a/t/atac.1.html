atac(1) Manual de comandos generales atac(1)

NOMBRE

atac - Posiblemente un Cliente de API de Terminal. Completo, gratuito, de código abierto, sin conexión y sin cuenta.

SINOPSIS

atac [-d|--directory] [--filter] [--tui] [--dry-run] [--no-ansi-log] [-v|--verbose]... [-q|--quiet]... [-h|--help] [-V|--version] [subcomandos]

DESCRIPCIÓN

ATAC es Posiblemente un Cliente de API de Terminal. Se basa en clientes conocidos como Postman, Insomnia, o incluso Bruno, pero dentro de tu terminal sin necesidad de ningún entorno gráfico específico. La filosofía de ATAC es ser gratuito, sin cuenta y sin conexión, ahora y siempre.

OPCIONES

-d, --directory=DIRECTORIO
Directorio principal de la aplicación, que contiene archivos de colecciones JSON/YAML, el archivo de configuración atac.toml y el archivo atac.log
--filter=FILTRO
Solo permitirá archivos de colección que coincidan con el filtro regex
--tui
Ejecuta la TUI después del comando
--dry-run
Evita guardar datos en los archivos de colección y entorno
--no-ansi-log
Evita usar el formato ANSI para el archivo de registro/salida
-v, --verbose
Aumenta la verbosidad del registro
-q, --quiet
Disminuye la verbosidad del registro
-h, --help
Imprime la ayuda (ver un resumen con '-h')
-V, --version
Imprime la versión
