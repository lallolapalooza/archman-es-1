ATFTP(1) Manual de comandos generales ATFTP(1)

NOMBRE

atftp - Cliente TFTP (RFC1350).

SINOPSIS

atftp [opciones] [host [puerto]]

DESCRIPCIÓN

atftp se puede usar de forma interactiva o en modo por lotes para recuperar archivos de servidores TFTP. Cuando se usa de forma interactiva, se puede imprimir un resumen de los comandos escribiendo 'help'. Este cliente TFTP soporta todas las características básicas de RFC1350, RFC2347, RFC2348 y RFC2349. También soporta la implementación multicast de RFC2090 y mtftp según se define en la especificación PXE.

OPCIONES

Este programa soporta tanto la sintaxis habitual de línea de comandos de GNU, con opciones largas que empiezan con dos guiones ('--') como opciones cortas. Algunas opciones solo son utilizables en modo por lotes, no tienen significado cuando atftp se usa de forma interactiva. A continuación se muestra una descripción de las opciones.

-g, --get
Solo invocación no interactiva. Indica a atftp que obtenga un archivo de un servidor tftp.
--mget
Solo invocación no interactiva. Se utiliza para obtener un archivo de un servidor compatible con mtftp.
-p, --put
Solo invocación no interactiva. Indica a atftp que envíe un archivo a un servidor tftp.
-P, --password
Proporciona la contraseña al servidor tftp. Esta es una extensión no estándar del cliente atftp necesaria para los enrutadores Linksys y no debería usarse en otros lugares.
-l, --local-file
Solo invocación no interactiva. El nombre del archivo del lado del cliente (local) a leer o escribir. Debe usarse junto con --get o --put.
-r, --remote-file
Solo invocación no interactiva. El nombre del archivo del lado del servidor (remoto) a obtener o enviar. Debe usarse junto con --get o --put.
--tftp-timeout <valor>
Número de segundos para el tiempo de espera del cliente. El valor predeterminado es 5 segundos.
--option <"nombre valor">
Establece la opción "nombre" a "valor". Este comando soporta exactamente los mismos argumentos que el interactivo. Por ejemplo, use: --option "blksize 1428" para configurar el tamaño del bloque.
Las configuraciones posibles son:
--option "blksize disable"
--option "blksize 8"
--option "blksize 65464"
--option "timeout 1"
--option "tsize enable"
--option "tsize disable"
--option "windowsize disable"
--option "windowsize 4"
--option "multicast"
--mtftp <"nombre valor">
Establece las opciones posibles de mtftp. Acepta las mismas opciones que el comando interactivo mtftp. Por ejemplo, use: --mtftp "client-port 76" para configurar el puerto del lado del cliente a utilizar.
--no-source-port-checking
Ver la página del manual de atftpd.
--prevent-sas
Aborda la situación del Síndrome del Aprendiz de Brujo según lo solicitado por RFC 1350. Esta RFC requiere que se rechacen las respuestas repetidas a un solo paquete. Por lo tanto, un bloque solo se retransmitirá ante un tiempo de espera agotado. Por compatibilidad hacia atrás, el valor predeterminado sigue siendo ignorar esta RFC. Por lo tanto, los bloques se transmiten ante cada solicitud.
--verbose
Indica a atftp que sea verboso. Imprimirá más información sobre lo que está sucediendo.
--trace
Esto es útil para fines de depuración para mostrar todos los paquetes que van hacia y desde la red.
-V, --version
Imprime la versión.
-h, --help
Imprime un resumen de los argumentos de la línea de comandos.
