ATOPGPUD(8) Manual del Administrador del Sistema ATOPGPUD(8)

NOMBRE

atopgpud - demonio de estadísticas de GPU

SINOPSIS

atopgpud [-v]

DESCRIPCIÓN

El demonio atopgpud recopila información estadística de todas las GPUs Nvidia en el sistema actual. Con una tasa de muestreo de un segundo, mantiene las estadísticas de cada GPU, a nivel global (sistema) y por proceso. Cuando atopgpud está activo en el sistema de destino, atop se conecta a este demonio a través de un socket TCP y obtiene todas las estadísticas de la GPU en cada intervalo.

El enfoque de recopilar todas las estadísticas de la GPU en un demonio separado es necesario, porque el controlador Nvidia solo ofrece el porcentaje de ocupación de la GPU del último segundo. Supongamos que atop se ejecuta con un intervalo de 10 minutos y obtuviera el porcentaje de ocupación de la GPU directamente del controlador Nvidia, reflejaría el porcentaje de ocupación del último segundo en lugar del porcentaje de ocupación promedio durante 600 segundos. Por lo tanto, el demonio atopgpud obtiene el porcentaje de ocupación de la GPU cada segundo y lo acumula en un contador que puede ser recuperado por atop regularmente. El mismo enfoque se aplica a otras estadísticas de la GPU.

Cuando el demonio atopgpud se ejecuta con privilegios de root, se proporcionan más contadores a nivel de proceso (es decir, ocupación de GPU y ocupación de memoria de GPU por proceso) que de lo contrario no son aplicables.

Tenga en cuenta que ciertas estadísticas de la GPU solo se entregan para tipos de GPU específicos. Para GPUs más antiguas o menos sofisticadas, se devuelve el valor -1 para los contadores que no se mantienen. En la salida de atop, estos contadores se muestran como 'N/A'.

Cuando no se encuentran GPUs (Nvidia) en el sistema de destino, atopgpud termina inmediatamente con el código de salida 0.

Los mensajes de registro se escriben a través del demonio rsyslogd con la instalación 'daemon'. Con la bandera -v (verbose), atopgpud también registra mensajes de depuración.

INSTALACIÓN

El demonio atopgpud está escrito en Python, por lo que se debe instalar un intérprete de Python en el sistema de destino. Puede ser Python versión 2 o Python versión 3 (el código de atopgpud está escrito de manera genérica). ¡Tenga cuidado de que la primera línea del script atopgpud contenga el nombre de comando correcto para activar un intérprete de Python que esté instalado en el sistema de destino!

El demonio atopgpud depende del módulo Python pynvml para interactuar con el controlador Nvidia. Este módulo se puede instalar con el comando pip o pip3 y generalmente se empaqueta bajo el nombre nvidia-ml-py
Finalmente, el módulo pynvml es un envoltorio de Python para la biblioteca compartida libnvidia-ml que también debe instalarse.

Después de instalar el paquete atop, el demonio atopgpud no se inicia automáticamente, ni el servicio se habilitará por defecto. Si desea activar este servicio (permanentemente), ingrese los siguientes comandos (como root):

  systemctl enable atopgpu
  systemctl start atopgpu

DESCRIPCIÓN DE LA INTERFAZ

Los procesos cliente pueden conectarse al demonio atopgpud en el puerto TCP 59123. Posteriormente, dicho cliente puede enviar una solicitud de dos bytes, que consiste en un byte de código de solicitud seguido de un byte entero que es el número de versión de la API.
El código de solicitud en el primer byte puede ser 'T' para obtener información sobre los tipos de GPU instalados en este sistema (generalmente se solicita una sola vez).
El código de solicitud puede ser 'S' para obtener todos los valores de contador estadístico (solicitado para cada intervalo).

La respuesta del demonio comienza con un entero de 4 bytes. El primer byte es el número de versión de la API que determina el formato de la respuesta, mientras que los tres bytes subsiguientes indican la longitud (orden big endian) de la cadena de respuesta que sigue.
En las cadenas de respuesta, el carácter '@' introduce información a nivel de sistema de una GPU específica y el carácter '#' introduce información a nivel de proceso relacionada con esa GPU.
Para obtener más detalles sobre el significado de los contadores en una cadena de respuesta, consulte el código fuente.
