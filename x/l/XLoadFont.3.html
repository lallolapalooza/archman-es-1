Paquete: libx11

XLoadFont(3) FUNCIONES XLIB XLoadFont(3)

NOMBRE

XLoadFont, XQueryFont, XLoadQueryFont, XFreeFont, XGetFontProperty, XUnloadFont, XCharStruct, XFontProp, XChar2b, XFontStruct - cargar o descargar fuentes y estructuras de métricas de fuentes

SINTAXIS

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

ARGUMENTOS

atom
Especifica el átomo para el nombre de propiedad que desea obtener.
display
Especifica la conexión con el servidor X.
font
Especifica la fuente.
font_ID
Especifica el ID de la fuente o el ID de GContext.
font_struct
Especifica el almacenamiento asociado a la fuente.
gc
Especifica el GC.
name
Especifica el nombre de la fuente, que es una cadena terminada en nulo.
value_return
Devuelve el valor de la propiedad de la fuente.

DESCRIPCIÓN

La función XLoadFont carga la fuente especificada y devuelve su ID de fuente asociado. Si el nombre de la fuente no está en la Codificación de Caracteres Portátil del Host, el resultado es dependiente de la implementación. El uso de mayúsculas o minúsculas no importa. Cuando los caracteres “?” y “*” se utilizan en un nombre de fuente, se realiza una coincidencia de patrones y se utiliza cualquier fuente coincidente. En el patrón, el carácter “?” coincidirá con cualquier carácter individual, y el carácter “*” coincidirá con cualquier número de caracteres. Se especifica un formato estructurado para los nombres de fuentes en las convenciones de descripción de fuentes lógicas de X del estándar del Consorcio X. Si XLoadFont no tuvo éxito al cargar la fuente especificada, se produce un error BadName. Las fuentes no están asociadas con una pantalla particular y pueden almacenarse como un componente de cualquier GC. Cuando la fuente ya no es necesaria, llame a XUnloadFont.

XLoadFont puede generar errores BadAlloc y BadName.

La función XQueryFont devuelve un puntero a la estructura XFontStruct, que contiene información asociada a la fuente. Puede consultar una fuente o la fuente almacenada en un GC. El ID de fuente almacenado en la estructura XFontStruct será el ID de GContext, y deberá tener cuidado al usar este ID en otras funciones (consulte XGContextFromGC). Si la fuente no existe, XQueryFont devuelve NULL. Para liberar estos datos, use XFreeFontInfo.

XLoadQueryFont puede generar un error BadAlloc.

La función XLoadQueryFont proporciona la forma más común de acceder a una fuente. XLoadQueryFont abre (carga) la fuente especificada y devuelve un puntero a la estructura XFontStruct apropiada. Si el nombre de la fuente no está en la Codificación de Caracteres Portátil del Host, el resultado es dependiente de la implementación. Si la fuente no existe, XLoadQueryFont devuelve NULL.

La función XFreeFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada y libera la estructura XFontStruct. La fuente en sí se liberará cuando ningún otro recurso la referencie. No se deben volver a referenciar los datos ni la fuente.

XFreeFont puede generar un error BadFont.

Dado el átomo para esa propiedad, la función XGetFontProperty devuelve el valor de la propiedad de fuente especificada. XGetFontProperty también devuelve False si la propiedad no fue definida o True si fue definida. Existe un conjunto de átomos predefinidos para las propiedades de fuentes, que se pueden encontrar en X11/Xatom.h. Este conjunto contiene las propiedades estándar asociadas a una fuente. Aunque no está garantizado, es probable que las propiedades de fuentes predefinidas estén presentes.

La función XUnloadFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada. La fuente en sí se liberará cuando ningún otro recurso la referencie. No se debe volver a referenciar la fuente.

XUnloadFont puede generar un error BadFont.

ESTRUCTURAS

La estructura XFontStruct contiene toda la información de la fuente y consta de la información específica de la fuente, así como de un puntero a una matriz de estructuras XCharStruct para los caracteres contenidos en la fuente. Las estructuras XFontStruct, XFontProp y XCharStruct contienen:

typedef struct {
	short lbearing;	/* origen al borde izquierdo del raster */
	short rbearing;	/* origen al borde derecho del raster */
	short width;	/* avance al origen del siguiente carácter */
	short ascent;	/* línea base a borde superior del raster */
	short descent;	/* línea base a borde inferior del raster */
	unsigned short attributes;	/* flags por carácter (no predefinidos) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* los caracteres normales de 16 bits son de dos bytes */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* gancho para que la extensión cuelgue datos */
	Font fid;	/* ID de fuente para esta fuente */
	unsigned direction;	/* indicación sobre la dirección en que se pinta la fuente */
	unsigned min_char_or_byte2;	/* primer carácter */
	unsigned max_char_or_byte2;	/* último carácter */
	unsigned min_byte1;	/* primera fila que existe */
	unsigned max_byte1;	/* última fila que existe */
	Bool all_chars_exist;	/* flag si todos los caracteres tienen tamaño distinto de cero */
	unsigned default_char;	/* carácter a imprimir para carácter indefinido */
	int n_properties;	/* cuántas propiedades hay */
	XFontProp *properties;	/* puntero a la matriz de propiedades adicionales */
	XCharStruct min_bounds;	/* límites mínimos sobre todos los caracteres existentes */
	XCharStruct max_bounds;	/* límites máximos sobre todos los caracteres existentes */
	XCharStruct *per_char;	/* información del primer carácter al último carácter */
	int ascent;	/* extensión lógica por encima de la línea base para espaciado */
	int descent;	/* decente lógico por debajo de la línea base para espaciado */
} XFontStruct;

X admite operaciones de texto de un solo byte/carácter, dos bytes/carácter de matriz y 16 bits. Tenga en cuenta que cualquiera de estas formas se puede utilizar con una fuente, pero una solicitud de texto de un solo byte/carácter solo puede especificar un solo byte (es decir, la primera fila de una fuente de 2 bytes). Debe considerar las fuentes de 2 bytes como una matriz bidimensional de caracteres definidos: byte1 especifica el rango de filas definidas y byte2 define el rango de columnas definidas de la fuente. Las fuentes de un solo byte/carácter tienen una fila definida, y el rango de byte2 especificado en la estructura define un rango de caracteres.

El cuadro delimitador de un carácter se define mediante la XCharStruct de ese carácter. Cuando los caracteres están ausentes de una fuente, se utiliza el default_char. Cuando las fuentes tienen todos los caracteres del mismo tamaño, solo se utiliza la información en los límites mínimo y máximo de XFontStruct.

Los miembros de XFontStruct tienen la siguiente semántica:

  • El miembro direction puede ser FontLeftToRight o FontRightToLeft. Es solo una indicación de si la mayoría de los elementos XCharStruct tienen una métrica de ancho de carácter positiva (FontLeftToRight) o negativa (FontRightToLeft). El protocolo central no define soporte para texto vertical.
  • Si los miembros min_byte1 y max_byte1 son ambos cero, min_char_or_byte2 especifica el índice lineal del carácter correspondiente al primer elemento de la matriz per_char, y max_char_or_byte2 especifica el índice lineal del carácter del último elemento.
Si min_byte1 o max_byte1 no son cero, tanto min_char_or_byte2 como max_char_or_byte2 son menores que 256, y los valores del índice de carácter de 2 bytes correspondientes al elemento N de la matriz per_char (contando desde 0) son:
byte1 = N/D + min_byte1
byte2 = N\D + min_char_or_byte2
donde: 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = división entera
        \ = int
XLoadFont(3)

NAME

XLoadFont — load a font

SYNTAX

#include <X11/Xlib.h>


XFontStruct *XLoadFont(Display *display, const char *font_name);

ARGUMENTS

display
Specifies the connection to the X server.
font_name
Specifies the name of the font to be loaded.

DESCRIPTION

The XLoadFont function loads the specified font. The font name is a string, which is interpreted by the X server.

If the font name is not recognized or the font cannot be loaded for any reason, XLoadFont returns NULL.

A font is a collection of characters. Each character has a width, and may have different height characteristics. Fonts are used for rendering text. Characters can be defined with two bounding box values: left side bearing and right side bearing. The left side bearing is the horizontal distance from the character origin to the left edge of the character's ink. The right side bearing is the horizontal distance from the character origin to the right edge of the character's ink. The width of the character is the sum of the left side bearing, the ink width, and the right side bearing.

In addition, each character has vertical extent information: ascent and descent. The ascent is the vertical distance from the character origin to the top edge of the character's ink. The descent is the vertical distance from the character origin to the bottom edge of the character's ink.

The origin of a character is a reference point for positioning the character. For a character origin at coordinates (x,y), the bounding box of the character is a rectangle with its upper-left corner at (x + lbearing, y - ascent) and its lower-right corner at (x + rbearing, y + descent).

The width of the character is rbearing - lbearing.

The height of the character is ascent + descent.

The origin for the next character is defined to be at (x + width, y).

The XFontStruct structure contains information about the font, including the bounding box information for each character in the font. The structure is defined as follows:

STRUCTURES

typedef struct {
    XCharStruct       min_bounds;
    XCharStruct       max_bounds;
    int               min_char_or_byte2;
    int               max_char_or_byte2;
    int               default_char;
    int               first_col;
    int               last_col;
    int               min_row;
    int               max_row;
    Bool              all_chars_exist;
    char              *min_bounds_char;
    char              *max_bounds_char;
    char              *default_char_char;
    Font              fid;
    int               ascent;
    int               descent;
    unsigned int      draws_background;
} XFontStruct;

typedef struct {
    short   lbearing;
    short   rbearing;
    short   width;
    short   ascent;
    short   descent;
    unsigned short  attributes;
} XCharStruct;
  • If the per_char pointer is NULL, all glyphs between the first and last character indexes inclusive have the same information, as given by both min_bounds and max_bounds.
  • If all_chars_exist is True, all characters in the per_char array have nonzero bounding boxes.
  • The default_char member specifies the character that will be used when an undefined or nonexistent character is printed. The default_char is a 16-bit character (not a 2-byte character). For a font using 2-byte matrix format, the default_char has byte1 in the most-significant byte and byte2 in the least significant byte. If the default_char itself specifies an undefined or nonexistent character, no printing is performed for an undefined or nonexistent character.
  • The min_bounds and max_bounds members contain the most extreme values of each individual XCharStruct component over all elements of this array (and ignore nonexistent characters). The bounding box of the font (the smallest rectangle enclosing the shape obtained by superimposing all of the characters at the same origin [x,y]) has its upper-left coordinate at: 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
    • Its width is: 
    max_bounds.rbearing - min_bounds.lbearing
    Its height is: 
    max_bounds.ascent + max_bounds.descent
    • The ascent member is the logical extent of the font above the baseline that is used for determining line spacing. Specific characters may extend beyond this.
    • The descent member is the logical extent of the font at or below the baseline that is used for determining line spacing. Specific characters may extend beyond this.
    • If the baseline is at Y-coordinate y, the logical extent of the font is inclusive between the Y-coordinate values (y - font.ascent) and (y + font.descent - 1). Typically, the minimum interline spacing between rows of text is given by ascent + descent.

    For a character origin at [x,y], the bounding box of a character (that is, the smallest rectangle that encloses the character's shape) described in terms of XCharStruct components is a rectangle with its upper-left corner at:

    [x + lbearing, y - ascent]

    Its width is:

    rbearing - lbearing

    Its height is:

    ascent + descent

    The origin for the next character is defined to be:

    [x + width, y]

    The lbearing member defines the extent of the left edge of the character ink from the origin. The rbearing member defines the extent of the right edge of the character ink from the origin. The ascent member defines the extent of the top edge of the character ink from the origin. The descent member defines the extent of the bottom edge of the character ink from the origin. The width member defines the logical width of the character.

    DIAGNOSTICS

    BadAlloc
    The server failed to allocate the requested resource or server memory.
    BadFont
    A value for a Font or GContext argument does not name a defined Font.
    BadName
    A font or color of the specified name does not exist.
