XGetWindowProperty(3) FUNCIONES DE XLIB XGetWindowProperty(3)

NOMBRE

XGetWindowProperty, XListProperties, XChangeProperty, XRotateWindowProperties, XDeleteProperty - obtener y cambiar propiedades de ventanas

SINTAXIS

int XGetWindowProperty(Display *display, Window w, Atom property, long long_offset, long long_length, Bool delete, Atom req_type, Atom *actual_type_return, int *actual_format_return, unsigned long *nitems_return, unsigned long *bytes_after_return, unsigned char **prop_return);

Atom *XListProperties(Display *display, Window w, int *num_prop_return);

int XChangeProperty(Display *display, Window w, Atom property, Atom type, int format, int mode, _Xconst unsigned char *data, int nelements);

int XRotateWindowProperties(Display *display, Window w, Atom properties[], int num_prop, int npositions);

int XDeleteProperty(Display *display, Window w, Atom property);

ARGUMENTOS

actual_format_return
Devuelve el formato real de la propiedad.
actual_type_return
Devuelve el identificador del átomo que define el tipo real de la propiedad.
bytes_after_return
Devuelve el número de bytes restantes para leer en la propiedad si se realizó una lectura parcial.
data
Especifica los datos de la propiedad.
delete
Especifica un valor booleano que determina si la propiedad se elimina.
display
Especifica la conexión con el servidor X.
format
Especifica si los datos deben ser vistos como una lista de cantidades de 8, 16 o 32 bits. Los valores posibles son 8, 16 y 32. Esta información permite al servidor X realizar correctamente operaciones de intercambio de bytes según sea necesario. Si el formato es de 16 o 32 bits, debe convertir explícitamente su puntero de datos a (unsigned char *) en la llamada a XChangeProperty.
long_length
Especifica la longitud en múltiplos de 32 bits de los datos a recuperar.
long_offset
Especifica el desplazamiento en la propiedad especificada (en cantidades de 32 bits) donde se deben recuperar los datos.
mode
Especifica el modo de la operación. Puede pasar PropModeReplace, PropModePrepend o PropModeAppend.
nelements
Especifica el número de elementos del formato de datos especificado.
nitems_return
Devuelve el número real de elementos de 8, 16 o 32 bits almacenados en los datos de prop_return.
num_prop
Especifica la longitud del array de propiedades.
num_prop_return
Devuelve la longitud del array de propiedades.
npositions
Especifica la cantidad de rotación.
prop_return
Devuelve los datos en el formato especificado. Si el formato devuelto es 8, los datos devueltos se representan como un array de char. Si el formato devuelto es 16, los datos devueltos se representan como un array de tipo short int y deben convertirse a ese tipo para obtener los elementos. Si el formato devuelto es 32, los datos de la propiedad se almacenarán como un array de longs (que en una aplicación de 64 bits serán valores de 64 bits que se rellenan en los 4 bytes superiores).
property
Especifica el nombre de la propiedad.
properties
Especifica el array de propiedades que se van a rotar.
req_type
Especifica el identificador del átomo asociado con el tipo de propiedad o AnyPropertyType.
type
Especifica el tipo de la propiedad. El servidor X no interpreta el tipo, simplemente lo devuelve a una aplicación que posteriormente llama a XGetWindowProperty.
w
Especifica la ventana cuya propiedad desea obtener, cambiar, rotar o eliminar.

DESCRIPCIÓN

La función XGetWindowProperty devuelve el tipo real de la propiedad; el formato real de la propiedad; el número de elementos de 8, 16 o 32 bits transferidos; el número de bytes restantes para leer en la propiedad; y un puntero a los datos devueltos. XGetWindowProperty establece los argumentos de retorno de la siguiente manera:

  • Si la propiedad especificada no existe para la ventana especificada, XGetWindowProperty devuelve None a actual_type_return y el valor cero a actual_format_return y bytes_after_return. El argumento nitems_return está vacío. En este caso, el argumento delete se ignora.
  • Si la propiedad especificada existe pero su tipo no coincide con el tipo especificado, XGetWindowProperty devuelve el tipo real de la propiedad a actual_type_return, el formato real de la propiedad (nunca cero) a actual_format_return, y la longitud de la propiedad en bytes (incluso si actual_format_return es 16 o 32) a bytes_after_return. También ignora el argumento delete. El argumento nitems_return está vacío.
  • Si la propiedad especificada existe y o bien asigna AnyPropertyType al argumento req_type o el tipo especificado coincide con el tipo real de la propiedad, XGetWindowProperty devuelve el tipo real de la propiedad a actual_type_return y el formato real de la propiedad (nunca cero) a actual_format_return. También devuelve un valor a bytes_after_return y nitems_return, definiendo los siguientes valores:
N = longitud real de la propiedad almacenada en bytes
     (incluso si el formato es 16 o 32)
I = 4 * long_offset
T = N - I
L = MIN(T, 4 * long_length)
A = N - (I + L)
El valor devuelto comienza en el índice de byte I en la propiedad (indexando desde cero), y su longitud en bytes es L. Si el valor para long_offset hace que L sea negativo, se produce un error BadValue. El valor de bytes_after_return es A, que indica el número de bytes finales no leídos en la propiedad almacenada.

Si el formato devuelto es 8, los datos devueltos se representan como un array de char. Si el formato devuelto es 16, los datos devueltos se representan como un array short y deben convertirse a ese tipo para obtener los elementos. Si el formato devuelto es 32, los datos devueltos se representan como un array long y deben convertirse a ese tipo para obtener los elementos.

XGetWindowProperty siempre asigna un byte adicional en prop_return (incluso si la propiedad tiene longitud cero) y lo establece a cero para que las propiedades simples que consisten en caracteres no tengan que ser copiadas a otra cadena antes de usarse.

Si delete es True y bytes_after_return es cero, XGetWindowProperty elimina la propiedad de la ventana y genera un evento PropertyNotify en la ventana.

La función devuelve Success si se ejecuta correctamente. Para liberar los datos resultantes, use XFree.

XGetWindowProperty puede generar errores BadAtom, BadValue y BadWindow.

La función XListProperties devuelve un puntero a un array de propiedades de átomo que están definidas para la ventana especificada o devuelve NULL si no se encontraron propiedades. Para liberar la memoria asignada por esta función, use XFree.

XListProperties puede generar un error BadWindow.

La función XChangeProperty modifica la propiedad de la ventana especificada y hace que el servidor X genere un evento PropertyNotify.

  • Si el modo es PropModeReplace, XChangeProperty descarta el valor de la propiedad anterior y almacena los nuevos datos.
  • Si el modo es PropModePrepend o PropModeAppend, XChangeProperty inserta los datos especificados antes del inicio de los datos existentes o al final de los datos existentes, respectivamente. El tipo y el formato deben coincidir con el valor de la propiedad existente, o se producirá un error BadMatch. Si la propiedad no está definida, se trata como definida con el tipo y formato correctos con datos de longitud cero.

Si el formato especificado es 8, los datos de la propiedad deben ser una matriz de char. Si el formato especificado es 16, los datos de la propiedad deben ser una matriz de short. Si el formato especificado es 32, los datos de la propiedad deben ser una matriz de long.

La vida útil de una propiedad no está ligada al cliente que la almacena. Las propiedades permanecen hasta que se eliminan explícitamente, hasta que se destruye la ventana o hasta que se reinicia el servidor. Para discutir lo que sucede cuando se cierra la conexión con el servidor X, vea la sección 2.6. El tamaño máximo de una propiedad depende del servidor y puede variar dinámicamente según la cantidad de memoria disponible para el servidor. (Si no hay suficiente espacio, se producirá un error BadAlloc).

XChangeProperty puede generar errores BadAlloc, BadAtom, BadMatch, BadValue y BadWindow.

La función XRotateWindowProperties le permite rotar propiedades en una ventana y hace que el servidor X genere eventos PropertyNotify. Si los nombres de las propiedades en el arreglo de propiedades se consideran numerados a partir de cero y si hay num_prop nombres de propiedades en la lista, entonces el valor asociado con el nombre de propiedad I se convierte en el valor asociado con el nombre de propiedad (I + npositions) mod N para todo I de cero a N - 1. El efecto es rotar los estados en npositions posiciones alrededor del anillo virtual de nombres de propiedades (a la derecha para npositions positivas, a la izquierda para npositions negativas). Si npositions mod N no es cero, el servidor X genera un evento PropertyNotify por cada propiedad en el orden en que se enumeran en el arreglo. Si un átomo ocurre más de una vez en la lista o si no hay ninguna propiedad con ese nombre definida para la ventana, se producirá un error BadMatch. Si se produce un error BadAtom o BadMatch, no se cambiará ninguna propiedad.

XRotateWindowProperties puede generar errores BadAtom, BadMatch y BadWindow.

La función XDeleteProperty elimina la propiedad especificada solo si la propiedad estaba definida en la ventana especificada y hace que el servidor X genere un evento PropertyNotify en la ventana, a menos que la propiedad no exista.

XDeleteProperty puede generar errores BadAtom y BadWindow.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadAtom
Un valor para un argumento Atom no nombra un Átomo definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
