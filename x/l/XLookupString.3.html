NOMBRE

XLookupKeysym, XRefreshKeyboardMapping, XLookupString, XRebindKeysym - manejar eventos de entrada del teclado en Latin-1

SINTAXIS

KeySym XLookupKeysym(XKeyEvent *key_event, int index);

int XRefreshKeyboardMapping(XMappingEvent *event_map);

int XLookupString(XKeyEvent *event_struct, char *buffer_return, int bytes_buffer, KeySym *keysym_return, XComposeStatus *status_in_out);

int XRebindKeysym(Display *display, KeySym keysym, KeySym list[], int mod_count, _Xconst unsigned char *string, int num_bytes);

ARGUMENTOS

buffer_return
Devuelve los caracteres traducidos.
bytes_buffer
Especifica la longitud del búfer. No se devuelven más de bytes_buffer de traducción.
num_bytes
Especifica el número de bytes en el argumento de la cadena.
display
Especifica la conexión con el servidor X.
event_map
Especifica el evento de mapeo que se va a utilizar.
event_struct
Especifica la estructura del evento de tecla que se va a utilizar. Se pueden pasar XKeyPressedEvent o XKeyReleasedEvent.
index
Especifica el índice en la lista de KeySyms para el KeyCode del evento.
key_event
Especifica el evento KeyPress o KeyRelease.
keysym
Especifica el KeySym que se va a devolver.
keysym_return
Devuelve el KeySym calculado a partir del evento si este argumento no es NULL.
list
Especifica los KeySyms que se van a utilizar como modificadores.
mod_count
Especifica el número de modificadores en la lista de modificadores.
status_in_out
Especifica o devuelve la estructura XComposeStatus o NULL.
string
Especifica la cadena que se copia y que será devuelta por XLookupString.

DESCRIPCIÓN

La función XLookupKeysym utiliza un evento de teclado dado y el índice que especificó para devolver el KeySym de la lista que corresponde al miembro KeyCode en la estructura XKeyPressedEvent o XKeyReleasedEvent. Si no hay ningún KeySym definido para el KeyCode del evento, XLookupKeysym devuelve NoSymbol.

La función XRefreshKeyboardMapping actualiza la información almacenada sobre modificadores y mapas de teclas. Normalmente se llama a esta función cuando ocurre un evento MappingNotify con un miembro de solicitud de MappingKeyboard o MappingModifier. El resultado es actualizar el conocimiento de Xlib sobre el teclado.

La función XLookupString traduce un evento de tecla a un KeySym y una cadena. El KeySym se obtiene utilizando la interpretación estándar de los modificadores Shift, Lock, grupo y numlock tal como se definen en la especificación del protocolo X. Si el KeySym ha sido redefinido (ver XRebindKeysym), la cadena asociada se almacenará en el búfer. De lo contrario, el KeySym se mapea, si es posible, a un carácter ISO Latin-1 o (si el modificador Control está activado) a un carácter de control ASCII, y ese carácter se almacena en el búfer. XLookupString devuelve el número de caracteres que se almacenan en el búfer.

Si está presente (no es NULL), la estructura XComposeStatus registra el estado, que es privado de Xlib, que necesita conservarse entre llamadas a XLookupString para implementar el procesamiento de composición. La creación de estructuras XComposeStatus depende de la implementación; un programa portable debe pasar NULL para este argumento.

La función XRebindKeysym se puede usar para redefinir el significado de un KeySym para el cliente. No redefine ninguna tecla en el servidor X, sino que simplemente proporciona una forma fácil de adjuntar cadenas largas a las teclas. XLookupString devuelve esta cadena cuando se presionan las teclas modificadoras apropiadas y cuando el KeySym se habría utilizado para la traducción. No se realizan conversiones de texto; el cliente es responsable de proporcionar cadenas codificadas adecuadamente. Tenga en cuenta que puede redefinir un KeySym que puede no existir.
