XLISTINPUTDEVICES(3)   XLISTINPUTDEVICES(3)

NOMBRE

XListInputDevices, XFreeDeviceList - listar dispositivos de entrada disponibles

SINOPSIS

#include <X11/extensions/XInput.h>
XDeviceInfo *XListInputDevices( Display *display,
                                int *ndevices_return);
int XFreeDeviceList( XDeviceInfo *list);
display
       Especifica la conexión con el servidor X.
ndevices_return
       Especifica un puntero a una variable donde se puede devolver el número de
       dispositivos disponibles.
list
       Especifica la lista de dispositivos a liberar. La función
       XFreeDeviceList libera la lista de dispositivos de entrada de extensión disponibles.

DESCRIPCIÓN

La solicitud XListInputDevices lista los dispositivos de entrada disponibles. Esta lista incluye el teclado principal (core) y cualquier dispositivo de entrada físico actualmente accesible a través del servidor X, y cualquier dispositivo de entrada que no sea accesible actualmente a través del servidor X pero que podría ser accedido si se solicita.
Un puntero maestro (master pointer) es un dispositivo puntero virtual que no representa un dispositivo físico. Se representa visualmente a través de un cursor. Un teclado maestro (master keyboard) es un dispositivo de teclado virtual que no representa un dispositivo físico. Se representa virtualmente a través de un foco de teclado (keyboard focus). Un puntero maestro y un teclado maestro siempre están emparejados (es decir, si se presiona la tecla Shift en el teclado maestro, un clic del puntero sería un clic con Shift presionado). Pueden existir múltiples pares de puntero/teclado maestro.
Los servidores X que soportan la versión 2 de la Extensión de Entrada X (X Input Extension), XListInputDevices solo devuelve el primer puntero maestro, el primer teclado maestro y todos los dispositivos esclavo (slave). Los dispositivos maestro adicionales no se listan.
Los dispositivos físicos (llamados dispositivos esclavo) están conectados a un puntero maestro o a un teclado maestro, dependiendo de sus capacidades. Si un dispositivo esclavo genera un evento, el evento también es generado por el dispositivo maestro respectivo. Múltiples dispositivos esclavo pueden estar conectados a un solo dispositivo maestro.
Algunas implementaciones de servidor pueden hacer que todos los dispositivos de entrada físicos estén disponibles en el momento en que se inicializa el servidor. Otras pueden esperar hasta que un cliente lo solicite para acceder a un dispositivo de entrada. En este último caso, es posible que un dispositivo de entrada se liste como disponible en un momento dado pero no en otro.
Para cada dispositivo de entrada disponible para el servidor, la solicitud XListInputDevices devuelve una estructura XDeviceInfo. Esa estructura contiene un puntero a una lista de estructuras, cada una de las cuales contiene información sobre una clase de entrada soportada por el dispositivo. La estructura XDeviceInfo se define de la siguiente manera:
             typedef struct _XDeviceInfo {
             XID     id;
             Atom    type;
             char    *name;
             int         num_classes;
             int         use;
             XAnyClassPtr inputclassinfo;
             } XDeviceInfo;
El id es un número en el rango 0-128 que identifica de forma única el dispositivo. Se asigna al dispositivo cuando es inicializado por el servidor.
El campo type es de tipo Atom e indica la naturaleza del dispositivo. El type corresponderá a una de las siguientes cadenas (definidas en el archivo de cabecera XI.h):
XI_MOUSE XI_TABLET XI_KEYBOARD XI_TOUCHSCREEN XI_TOUCHPAD
XI_BUTTONBOX XI_BARCODE XI_TRACKBALL XI_QUADRATURE XI_ID_MODULE
XI_ONE_KNOB XI_NINE_KNOB XI_KNOB_BOX XI_SPACEBALL XI_DATAGLOVE
XI_EYETRACKER XI_CURSORKEYS XI_FOOTMOUSE XI_JOYSTICK
Estas cadenas pueden ser utilizadas en una solicitud XInternAtom para devolver un átomo que pueda ser comparado con el campo type de la estructura XDeviceInfo.
El campo name contiene un puntero a una cadena terminada en nulo que sirve como identificador del dispositivo. Este identificador puede ser configurado por el usuario o asignado automáticamente por el servidor.
El campo num_classes es un número en el rango 0-255 que especifica el número de clases de entrada soportadas por el dispositivo para las cuales se devuelve información en ListInputDevices. Algunas clases de entrada, como la clase Focus y la clase Proximity, no tienen información que deba ser devuelta por ListInputDevices.
Todos los dispositivos proporcionan una AttachClass. Esta clase especifica el dispositivo maestro al que está conectado un dispositivo esclavo dado. Para los dispositivos maestro, la clase especifica el dispositivo maestro emparejado respectivo.
El campo use especifica cómo se está utilizando actualmente el dispositivo. Si el valor es IsXKeyboard, el dispositivo es un teclado maestro. Si el valor es IsXPointer, el dispositivo es un puntero maestro. Si el valor es IsXExtensionPointer, el dispositivo es un puntero esclavo. Si el valor es IsXExtensionKeyboard, el dispositivo es un teclado esclavo. Si el valor es IsXExtensionDevice, el dispositivo está disponible para ser utilizado como dispositivo de extensión.
El campo inputclassinfo contiene un puntero a los primeros datos específicos de la clase de entrada. Los dos primeros campos son comunes a todas las clases.
El campo class es un número en el rango 0-255. Identifica de forma única la clase de entrada para la cual se devuelve información. Las clases definidas actualmente son KeyClass, ButtonClass y ValuatorClass.
El campo length es un número en el rango 0-255. Especifica el número de bytes de datos contenidos en esta clase de entrada. La longitud incluye los campos class y length.
La estructura XKeyInfo describe las características de las teclas del dispositivo. Se define de la siguiente manera:
typedef struct _XKeyInfo {
XID class;
int length;
unsigned short min_keycode;
unsigned short max_keycode;
unsigned short num_keys;
} XKeyInfo;
min_keycode es de tipo KEYCODE. Especifica el keycode mínimo que informará el dispositivo. El keycode mínimo no será menor que 8.
max_keycode es de tipo KEYCODE. Especifica el keycode máximo que informará el dispositivo. El keycode máximo no será mayor que 255.
num_keys especifica el número de teclas que tiene el dispositivo.
La estructura XButtonInfo define las características de los botones del dispositivo. Se define de la siguiente manera:
typedef struct _XButtonInfo {
XID class;
int length;
short num_buttons;
} XButtonInfo;
num_buttons especifica el número de botones que tiene el dispositivo.
La estructura XValuatorInfo define las características de los valuadores (valores de entrada) del dispositivo. Se define de la siguiente manera:
typedef struct  _XValuatorInfo {
XID class;
int length;
unsigned char num_axes;
unsigned char mode;
unsigned long motion_buffer;
XAxisInfoPtr axes;
} XValuatorInfo;
num_axes contiene el número de ejes que soporta el dispositivo.
mode es una constante que tiene uno de los siguientes valores:
Absolute o Relative. Algunos dispositivos permiten cambiar el modo dinámicamente a través de la solicitud SetDeviceMode.
motion_buffer_size es un número cardinal que especifica el número de elementos que puede contener el búfer de historial de movimiento para el dispositivo.
El campo axes contiene un puntero a una estructura XAxisInfo.
La estructura XAxisInfo se define de la siguiente manera:
typedef struct _XAxisInfo {
int resolution;
int min_value;
int max_value;
} XAxisInfo;
resolution contiene un número en cuentas/metro.
El campo min_val contiene un número que especifica el valor mínimo que el dispositivo informa para este eje. Para dispositivos cuyo modo es Relative, el campo min_val contendrá 0.
El campo max_val contiene un número que especifica el valor máximo que el dispositivo informa para este eje. Para dispositivos cuyo modo es Relative, el campo max_val contendrá 0.
La estructura XAttachInfo se define de la siguiente manera:
             typedef struct _XAttachInfo {
             int     attached;
             } XAttachInfo;
Si el dispositivo es un dispositivo esclavo, attached especifica el ID del dispositivo maestro al que está conectado este dispositivo. Si el dispositivo no está conectado a un dispositivo maestro, attached es Floating. Si el dispositivo es un dispositivo maestro, attached especifica el ID del dispositivo maestro con el que está emparejado este dispositivo.

VALOR DE RETORNO

XListInputDevices devuelve un puntero a una matriz de estructuras XDeviceInfo y establece ndevice

XListInputDevices(3) - Manual Page

NAME

XListInputDevices - list available input devices

SYNOPSIS

XListInputDevices(
    Display *display
);

DESCRIPTION

The XListInputDevices function returns a list of all input devices currently available to the X server. The list is terminated by a NULL entry.

Each device in the list is described by an XDeviceInfo structure, which contains the following members:

typedef struct {
    XID         id;             /* Device identifier */
    char        *name;          /* Device name */
    int         num_classes;    /* Number of device classes */
    XInputClassInfo *classes;   /* Array of device classes */
} XDeviceInfo;

The XDeviceInfo structure for each device is allocated by the X library. The name member points to a string that is also allocated by the X library.

The classes member points to an array of XInputClassInfo structures. Each XInputClassInfo structure describes a class of input provided by the device, such as keyboards, mice, or tablets. The XInputClassInfo structure contains the following members:

typedef struct {
    int         type;           /* Class identifier */
    short       atom;           /* Atom identifying the class */
    unsigned char rel;          /* Relative mode support */
    unsigned char label;        /* Label for the class */
} XInputClassInfo;

The type member is an integer that identifies the class of input. The atom member is an atom that can be used to obtain more information about the class. The rel member is a boolean that indicates whether the device supports relative mode for this class. The label member is a label for the class.

To free the XDeviceInfo array created by XListInputDevices, use XFreeDeviceList.

RETURN VALUE

On success, XListInputDevices returns a pointer to the first XDeviceInfo structure in the list. The number of devices returned is placed in the ndevices_return argument.

On error, XListInputDevices returns NULL and ndevices_return is left unmodified.
