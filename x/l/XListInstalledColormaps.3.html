Paquete: libx11

XInstallColormap(3) FUNCIONES XLIB XInstallColormap(3)

NOMBRE

XInstallColormap, XUninstallColormap, XListInstalledColormaps - controlar mapas de colores

SINTAXIS

int XInstallColormap(Display *display, Colormap colormap);

int XUninstallColormap(Display *display, Colormap colormap);

Colormap *XListInstalledColormaps(Display *display, Window w, int *num_return);

ARGUMENTOS

colormap
Especifica el mapa de colores.
display
Especifica la conexión con el servidor X.
num_return
Devuelve el número de mapas de colores actualmente instalados.
w
Especifica la ventana que determina la pantalla.

DESCRIPCIÓN

La función XInstallColormap instala el mapa de colores especificado para su pantalla asociada. Todas las ventanas asociadas con este mapa de colores se muestran inmediatamente con colores verdaderos. Asociaste las ventanas con este mapa de colores cuando las creaste llamando a XCreateWindow, XCreateSimpleWindow, XChangeWindowAttributes o XSetWindowColormap.

Si el mapa de colores especificado no es ya un mapa de colores instalado, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de colores. Además, para cada otro mapa de colores que se instala como resultado de una llamada a XInstallColormap, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de colores.

XInstallColormap puede generar un error BadColor.

La función XUninstallColormap elimina el mapa de colores especificado de la lista requerida para su pantalla. Como resultado, el mapa de colores especificado puede ser desinstalado, y el servidor X puede instalar o desinstalar implícitamente mapas de colores adicionales. Qué mapas de colores se instalan o desinstalan depende del servidor, excepto que la lista requerida debe permanecer instalada.

Si el mapa de colores especificado se desinstala, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de colores. Además, para cada otro mapa de colores que se instala o desinstala como resultado de una llamada a XUninstallColormap, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de colores.

XUninstallColormap puede generar un error BadColor.

La función XListInstalledColormaps devuelve una lista de los mapas de colores actualmente instalados para la pantalla de la ventana especificada. El orden de los mapas de colores en la lista no es significativo y no es una indicación explícita de la lista requerida. Cuando la lista asignada ya no sea necesaria, libérala usando XFree.

XListInstalledColormaps puede generar un error BadWindow.

DIAGNÓSTICOS

BadColor
Un valor para un argumento de Colormap no nombra un Colormap definido.
BadWindow
Un valor para un argumento de Window no nombra una Window definida.
