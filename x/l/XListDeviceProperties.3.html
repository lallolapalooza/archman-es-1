NOMBRE

XListDeviceProperties - Listar las propiedades de un dispositivo.

SINAPSIS

#include <X11/extensions/XInput.h>
Atom* XListDeviceProperties( Display *display,
                             XDevice *device,
                             int *nprops_return);
display
       Especifica la conexión con el servidor X.
device
       El dispositivo para el cual listar las propiedades.
nprops_return
       Especifica el número de Átomos devueltos.

DESCRIPCIÓN

La función XListDeviceProperties devuelve una lista de las
propiedades asociadas con el dispositivo de entrada especificado en
device. Cada dispositivo puede tener un número arbitrario de propiedades
adjuntas, algunas de las cuales fueron creadas por el controlador y/o
el servidor, otras creadas por clientes en tiempo de ejecución.
Se espera que el cliente libere la lista de propiedades usando
XFree.
XListDeviceProperties puede generar un error BadDevice.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe.

VER TAMBIÉN

XChangeDeviceProperty(3),
XGetDeviceProperty(3),
XDeleteDeviceProperty(3)
