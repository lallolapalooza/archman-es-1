XListFonts(3) FUNCIONES DE XLIB XListFonts(3)

NOMBRE

XListFonts, XFreeFontNames, XListFontsWithInfo, XFreeFontInfo - obtener o liberar nombres e información de fuentes

SINTAXIS

char **XListFonts(Display *display, _Xconst char *pattern, int maxnames, int *actual_count_return);

int XFreeFontNames(char *list[]);

char **XListFontsWithInfo(Display *display, _Xconst char *pattern, int maxnames, int *count_return, XFontStruct **info_return);

int XFreeFontInfo(char **names, XFontStruct *free_info, int actual_count);

ARGUMENTOS

actual_count
Especifica el número real de nombres de fuentes.
actual_count_return
Devuelve el número real de nombres de fuentes.
count_return
Devuelve el número real de nombres de fuentes coincidentes.
display
Especifica la conexión al servidor X.
info_return
Devuelve la información de la fuente.
free_info
Especifica la información de la fuente.
list
Especifica el array de cadenas que desea liberar.
maxnames
Especifica el número máximo de nombres a devolver.
names
Especifica la lista de nombres de fuentes.
pattern
Especifica la cadena de patrón terminada en nulo que puede contener caracteres comodín.

DESCRIPCIÓN

La función XListFonts devuelve un array de nombres de fuentes disponibles (según lo controlado por la ruta de búsqueda de fuentes; consulte XSetFontPath) que coinciden con la cadena que pasó al argumento patrón. La cadena de patrón puede contener cualquier carácter, pero cada asterisco (*) es un comodín para cualquier número de caracteres, y cada signo de interrogación (?) es un comodín para un solo carácter. Si la cadena de patrón no está en la Codificación de Caracteres Portátil de Host, el resultado depende de la implementación. El uso de mayúsculas o minúsculas no importa. Cada cadena devuelta está terminada en nulo. Si los datos devueltos por el servidor están en la Codificación de Caracteres Portátil Latina, entonces las cadenas devueltas están en la Codificación de Caracteres Portátil de Host. De lo contrario, el resultado depende de la implementación. Si no hay nombres de fuentes coincidentes, XListFonts devuelve NULL. El cliente debe llamar a XFreeFontNames cuando haya terminado con el resultado para liberar la memoria.

La función XFreeFontNames libera el array y las cadenas devueltas por XListFonts o XListFontsWithInfo.

La función XListFontsWithInfo devuelve una lista de nombres de fuentes que coinciden con el patrón especificado y su información de fuente asociada. La lista de nombres está limitada al tamaño especificado por maxnames. La información devuelta para cada fuente es idéntica a lo que XLoadQueryFont devolvería, excepto que no se devuelven las métricas por carácter. La cadena de patrón puede contener cualquier carácter, pero cada asterisco (*) es un comodín para cualquier número de caracteres, y cada signo de interrogación (?) es un comodín para un solo carácter. Si la cadena de patrón no está en la Codificación de Caracteres Portátil de Host, el resultado depende de la implementación. El uso de mayúsculas o minúsculas no importa. Cada cadena devuelta está terminada en nulo. Si los datos devueltos por el servidor están en la Codificación de Caracteres Portátil Latina, entonces las cadenas devueltas están en la Codificación de Caracteres Portátil de Host. De lo contrario, el resultado depende de la implementación. Si no hay nombres de fuentes coincidentes, XListFontsWithInfo devuelve NULL.

Para liberar solo el array de nombres asignado, el cliente debe llamar a XFreeFontNames. Para liberar tanto el array de nombres como el array de información de fuentes, o para liberar solo el array de información de fuentes, el cliente debe llamar a XFreeFontInfo.

La función XFreeFontInfo libera una estructura de fuente o un array de estructuras de fuentes y opcionalmente un array de nombres de fuentes. Si se pasa NULL para names, no se liberan nombres de fuentes. Si se pasa una estructura de fuente para una fuente abierta (devuelta por XLoadQueryFont), se libera la estructura, pero la fuente no se cierra; use XUnloadFont para cerrar la fuente.

Tenga en cuenta que XListFontsWithInfo no es seguro para hilos. Si otros hilos realizan solicitudes X en el mismo Display, el comportamiento de esta función no está definido.
