NOMBRE

XFree - liberar datos del cliente

SINTAXIS

int XFree(void *data);

ARGUMENTOS

data
Especifica los datos que se van a liberar.

DESCRIPCIÓN

La función XFree es una rutina de propósito general de Xlib que libera los datos especificados. Debes usarla para liberar cualquier objeto que haya sido asignado por Xlib, a menos que se especifique explícitamente una función alternativa para el objeto.

Si data es NULL, no se realiza ninguna operación.

VER TAMBIÉN
