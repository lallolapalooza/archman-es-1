NOMBRE

Xft - Biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca simple que dibuja texto y gráficos:

  • utilizando información proporcionada por la biblioteca Fontconfig,
  • Xft convierte glifos de fuentes usando el rasterizador FreeType, y
  • muestra los datos de fuente convertidos utilizando la extensión X Rendering Extension.

Esta página del manual apenas rasca la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión menor de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias para XFT_VERSION.

El siguiente ejemplo ilustra cómo se pueden usar las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("Versión 2.1.7 o posterior de la biblioteca Xft está en"
                " uso.");
    #else
    (void) printf("Versión insuficiente de Xft (%d.%d.%d) instalada;
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nomenclatura, prefijando todos los nombres con “Xft”

De Xlib...

Los tipos de datos de Xlib no siguen una convención de nomenclatura. Están documentados en Xlib - C Language Interface.

Xft utiliza estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, este es un ID de recurso X, por ejemplo, una ventana asociada a una pantalla. Tanto las ventanas como los pixmaps se pueden usar como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como drawables. Sin embargo, una ventana de tipo InputOnly no puede usarse como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa como la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica el alcance de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

De XRender...

Los tipos de datos de la biblioteca X Render Extension están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de encabezado para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft utiliza estos nombres: Picture, XGlyphInfo, XRenderColor.

De Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nomenclatura, prefijando todos los nombres con “Fc” que están documentados en Fontconfig Developers Reference.

Xft utiliza estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern y FcResult.

De FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nomenclatura, prefijando todos los nombres con “FT_” que están documentados en FreeType API Reference.

Xft utiliza estos nombres: FT_Face, FT_Library y FT_UInt.

FreeType 2 usa FT_UInt (un entero sin signo) para representar *glifos*.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que utilizan Xft; contiene métricas generales de la fuente y punteros al conjunto de caracteres y al patrón de Fontconfig asociados con la fuente.

Los XftFont se rellenan con cualquiera de las funciones XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), o XftFontOpenPattern(). XftFontCopy() se utiliza para duplicar XftFonts, y XftFontClose() se usa para marcar un XftFont como no utilizado. Los XftFonts son asignados internamente, contados por referencia y liberados por Xft; el programador no necesita asignar ni liberar almacenamiento para ellos normalmente.

XftDrawGlyphs(), la familia de funciones XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() utilizan XftFonts para renderizar texto en un objeto XftDraw, que puede corresponder a un drawable X central o a un drawable de la extensión X Rendering Extension.

XftGlyphExtents() y la familia de funciones XftTextExtents*() se utilizan para determinar las extensiones (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender() y la familia de funciones XftTextRender*() utilizan XftFonts para dibujar en estructuras Picture de la extensión X Rendering Extension.

Nota: XftDrawGlyphs(), la familia de funciones XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() proporcionan un medio de renderizar fuentes que es independiente de la disponibilidad de la extensión X Rendering Extension en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy() y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador no necesita asignar ni liberar almacenamiento para ellos normalmente.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que se puede recuperar con XftFontInfoHash(). Se puede abrir un XftFont basándose en datos de XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color del servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X a liberar el color actualmente asignado para un XftColor.

Una vez que un XftColor ha sido inicializado, XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec() y XftDrawRect() pueden usarse para dibujar varios objetos utilizando dicho color.

ESTRUCTURAS

XftDraw

es un objeto opaco que contiene información utilizada para renderizar en un drawable X usando el protocolo central o la extensión X Rendering.

Los objetos XftDraw se crean con cualquiera de los métodos XftDrawCreate() (que asocia un XftDraw con un drawable X existente), XftDrawCreateBitmap(), o XftDrawCreateAlpha(), y se destruyen con XftDrawDestroy(). El drawable X asociado con un XftDraw puede ser cambiado con XftDrawChange(). Los objetos XftDraw son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

Las propiedades Display, Drawable, Colormap, y Visual de un XftDraw pueden ser consultadas con XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap(), y XftDrawVisual(), respectivamente.

Varias funciones utilizan objetos XftDraw: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode(), y la familia XftDrawString*().

El Picture de la Extensión de Renderizado X asociado con un XftDraw es retornado por XftDrawPicture(), y XftDrawSrcPicture(). Es usado por XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender(), y la familia XftTextRender*().

FUNCIONES

Inicialización

Una aplicación típica que usa Xft no inicializa explícitamente la librería. Esto se hace normalmente como un efecto secundario al abrir una fuente.

Cuando Xft se inicializa, recopila información sobre la pantalla y almacena parte de esa información en un patrón Fontconfig (esencialmente una colección de propiedades con valores tipados). La aplicación que llama puede modificar ese patrón para cambiar el comportamiento de la librería.

No toda la información recopilada se almacena en un patrón. El resto se almacena en estructuras de datos internas. Xft hace que parte de esa información esté disponible para la aplicación a través de funciones.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y retorna verdadero si Xft encontró que la pantalla soporta la extensión X Render, y si es capaz de encontrar un XRenderPictFormat adecuado (el tipo de dato de X Render que es análogo al Visual de Xlib) en la pantalla.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y establece el patrón Fontconfig que contiene las propiedades predeterminadas que Xft usará para esta pantalla.

Xft utiliza estas propiedades inicialmente para obtener estos límites:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). Esta es la cantidad máxima de memoria de glifos para todas las fuentes usadas por Xft (predeterminado: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). Este es el número máximo de fuentes no referenciadas (predeterminado: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). Cuando es verdadero, Xft rastrea el uso de memoria de glifos para mejorar el rendimiento al decidir cuáles descargar cuando se alcanza la cantidad máxima de memoria de glifos (predeterminado: falso).
Xft también usa estas propiedades predeterminadas en XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft rellena las propiedades faltantes en el pattern proporcionado usando propiedades predeterminadas para la pantalla especificada dpy, por ejemplo, como se establece en XftDefaultSet().

Las aplicaciones Xft típicas usan esta función para ayudar a Fontconfig a elegir una fuente adecuada. Estas propiedades se sustituyen antes de llamar a FcDefaultSubstitute():
FC_ANTIALIAS
Verdadero si FreeType debe usar anti-aliasing (predeterminado: Falso). (predeterminado: Verdadero).
FC_AUTOHINT
Verdadero si FreeType debe usar autohinting (predeterminado: Falso).
FC_DPI
Puntos por pulgada usados para la resolución (predeterminado: calculado a partir de la altura de la pantalla).
FC_EMBOLDEN
Verdadero si FT_GlyphSlot_Embolden() debe usarse para poner en negrita una fuente (predeterminado: Falso).
FC_HINTING
Verdadero si se debe usar hinting al rellenar propiedades para abrir una fuente (predeterminado: Verdadero).
FC_HINT_STYLE
Estilo de hinting usado al rellenar propiedades para abrir una fuente (predeterminado: FC_HINT_FULL).
FC_LCD_FILTER
Parámetro pasado a FT_Library_SetLcdFilter() al cargar glifos (predeterminado: FC_LCD_DEFAULT).
FC_MINSPACE
Espacio mínimo usado al rellenar propiedades para abrir una fuente (predeterminado: Falso).
FC_RGBA
Valor RGBA usado al rellenar propiedades para abrir una fuente (predeterminado: calculado llamando a XRenderQuerySubpixelOrder()).
FC_SCALE
Escala usada en Fontconfig (predeterminado: 1.0).
XFT_MAX_GLYPH_MEMORY
Máxima memoria para una fuente (predeterminado: 1024*1024).
XFT_RENDER
Verdadero si la pantalla soporta la extensión X Render (predeterminado: resultado de XftDefaultHasRender()).

El parámetro config no se usa.

Abrir y Coincidir Fuentes



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen toma una lista de tríos de elementos de patrón
        del tipo campo, tipo, valor (terminada con un NULL),
        coincide ese patrón con las fuentes disponibles, y abre la fuente que
        coincide, dimensionándola correctamente para la pantalla número screen
        en la pantalla dpy. Retorna la fuente coincidente, o NULL si no se
        encuentra ninguna coincidencia.

  




Ejemplo:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);






  

  
Esto abre la fuente "charter" en 12 puntos. El tamaño en puntos se convierte
      automáticamente al tamaño de píxel correcto basado en la resolución del
      monitor.

    DESCRIPCIÓN
    
La biblioteca Xft proporciona una interfaz para abrir fuentes y renderizar texto utilizando la biblioteca Fontconfig. Fontconfig es un sistema de configuración de fuentes para sistemas X Window que permite la configuración dinámica de fuentes y el acceso a fuentes que no están en el sistema de fuentes X tradicional.

    

      Apertura de fuentes
      
Las siguientes funciones se utilizan para abrir fuentes:

      

        
XftFont *XftFontOpen (

        

          
	Display	*dpy,
	int	 screen,
	...);


          
XftFontOpen abre una fuente utilizando los
              argumentos de variable .... Estos argumentos se pasan a la
              función FcConfigSubstitute() y luego a la función
              FcFontOpen().

        

        
XftFont *XftFontOpenName (

        

          
	Display	*dpy,
	int	 screen,
	_Xconst char	*name,
	...);


          
XftFontOpenName se comporta como
              XftFontOpen hace, excepto que toma un nombre de fuente
              (que se pasa a la biblioteca Fontconfig's
              FcNameParse()).

	Display	*dpy,
	int	 screen,
	_Xconst char	*xlfd);


          
XftFontOpenXlfd se comporta como
              XftFontOpen hace, excepto que toma una cadena que contiene
              una Descripción Lógica de Fuente X (XLFD), y utiliza la función

      Determinación de Extents de Texto
      
Xft proporciona varias funciones para determinar la altura
          y anchura requeridas para mostrar una cadena de texto. Después de tener
          en cuenta el offset, en casos donde la cadena se desplazará hacia
          arriba, abajo, izquierda o derecha, estos números se conocen como
          text extents.

void XftGlyphFontSpecRender (

  

    
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
Esto implica varios pasos:

      completo usando XftFontCheckGlyph() y cargando cualquier glifo

NAME


XftLockFace, XftUnlockFace - Gestionar el acceso a los datos de la fuente FreeType






SYNOPSIS


#include <X11/Xft/Xft.h>

FT_Face
XftLockFace (
    XftFont *pub
);

void
XftUnlockFace (
    XftFont *pub
);







DESCRIPTION


La biblioteca Xft utiliza la biblioteca
    FreeType para cargar y manipular fuentes. Como FreeType puede tener muchos
    datos asociados con cada fuente, Xft utiliza un recuento
    de referencias para asegurarse de que los datos de la fuente no se liberen
    mientras sean necesarios. XftLockFace incrementa el
    recuento de referencias de la cara de FreeType asociada a la fuente
    [pub]. Si no existe una cara de FreeType, se crea
    una usando FT_New_Face.


XftUnlockFace decrementa el recuento de
    referencias de la cara de FreeType asociada a la fuente [pub].
    Si el recuento de referencias llega a cero, la cara se libera usando
    FT_Done_Face.


Estos mecanismos de bloqueo de cara se utilizan internamente en
    funciones como XftCharIndex y
    XftFontLoadGlyphs, y por lo tanto, en muchas otras
    funciones de Xft.




XftNameParse



  
FcPattern * XftNameParse (

  

    
	const char      *name);


    
Xft usa Fontconfig para analizar el nombre, pasando el
        name a FcNameParse(), devolviendo el resultado.

  








XftNameUnparse



  
FcBool XftNameUnparse (

  

    
	FcPattern	*pat,
	char	*dest,
	int	 len);


    
Al igual que XfgNameParse(), Xft utiliza Fontconfig.
        En este caso, utiliza FcNameUnparse(), que convierte el patrón
        pat de nuevo en una cadena que se puede analizar.
        XftNameUnparse() almacena el resultado a través del puntero
        del llamador dest, pero primero verifica si cabrá, usando el
        parámetro len. Si cabe, Xft copia la cadena y devuelve
        FcTrue, de lo contrario, devuelve FcFalse.

FT_Face XftLockFace (

  

    
	XftFont	*pub);


    
Si no se ha creado ninguna “cara” de FreeType
        2 (representación en memoria de un tipo de letra dado en un estilo
        determinado) para la fuente pub, créela usando
        FT_New_Face(). Los bloqueos de cara son un contador de
        referencias utilizado por Xft para garantizar que solo se cree
        una cara y que se conserve hasta que la fuente ya no se utilice.

  





  

  
El bloqueo de cara se utiliza directamente en XftCharIndex() y
        XftFontLoadGlyphs(), que a su vez se utilizan en muchas funciones
        de Xft.

  

  
El bloqueo de cara se introdujo en la versión 1 (octubre de 2002).
        Algunas aplicaciones, como Gdk/Gimp, dependían de estas funciones. En la
        versión 2.1.9 (junio de 2006), se mantuvo el bloqueo de cara como parte
        de la API pública cuando las configuraciones mejoradas de bibliotecas
        compartidas proporcionaron la ocultación de símbolos privados.

COMPATIBILIDAD


A partir de la versión 2 (mayo de 2002), Xft se volvió
    relativamente estable. Se espera que mantenga la compatibilidad de origen y
    binaria en futuras versiones.


Xft proporciona una interfaz de compatibilidad con su
    versión principal anterior, Xft 1.x, descrita a continuación.




Archivo de cabecera de Xft 1.x


#include <X11/Xft/XftCompat.h>






Tipos de datos de Xft 1.x



  
XftPattern

  
contiene un conjunto de nombres con listas de valores asociadas; cada nombre
      se refiere a una propiedad de una fuente. Los XftPattern se utilizan
      como entrada para el código de coincidencia, así como para contener
      información sobre fuentes específicas.

  
XftFontSet

  
contiene una lista de XftPattern. Internamente, Xft utiliza
      esta estructura de datos para mantener conjuntos de fuentes.
      Externamente, Xft devuelve los resultados de listar fuentes en este
      formato.

  
XftObjectSet

  
contiene un conjunto de nombres y se utiliza para especificar qué campos
      de las fuentes se colocan en la lista de patrones devueltos al listar
      fuentes.
