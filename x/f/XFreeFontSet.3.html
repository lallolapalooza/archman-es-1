XCreateFontSet(3) FUNCIONES DE XLIB XCreateFontSet(3)

NOMBRE

XCreateFontSet, XFreeFontSet - crear y liberar un conjunto de fuentes internacional para dibujar texto

SINTAXIS

XFontSet XCreateFontSet(Display *display, _Xconst char *base_font_name_list, char ***missing_charset_list_return, int *missing_charset_count_return, char **def_string_return);

void XFreeFontSet(Display *display, XFontSet font_set);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
base_font_name_list
Especifica los nombres base de las fuentes.
def_string_return
Devuelve la cadena que se dibuja para los conjuntos de caracteres faltantes.
font_set
Especifica el conjunto de fuentes.
missing_charset_count_return
Devuelve el número de conjuntos de caracteres faltantes.
missing_charset_list_return
Devuelve los conjuntos de caracteres faltantes.

DESCRIPCIÓN

La función XCreateFontSet crea un conjunto de fuentes para la pantalla especificada. El conjunto de fuentes está vinculado a la configuración regional actual cuando se llama a XCreateFontSet. El conjunto de fuentes puede ser utilizado en llamadas posteriores para obtener información de fuentes y caracteres, y para representar texto en la configuración regional del conjunto de fuentes.

El argumento base_font_name_list es una lista de nombres base de fuentes que Xlib utiliza para cargar las fuentes necesarias para la configuración regional. Los nombres base de las fuentes son una lista separada por comas. La cadena está terminada en nulo y se asume que está en la Codificación de Caracteres Portátil del Host; de lo contrario, el resultado depende de la implementación. El espacio en blanco inmediatamente a cada lado de una coma separadora se ignora.

El uso de nombres de fuentes XLFD permite a Xlib obtener las fuentes necesarias para una variedad de configuraciones regionales a partir de un único nombre base de fuente independiente de la configuración regional. El único nombre base de fuente debe nombrar una familia de fuentes cuyos miembros estén codificados en los diversos conjuntos de caracteres necesarios para las configuraciones regionales de interés.

Un nombre base de fuente XLFD puede nombrar explícitamente un conjunto de caracteres necesario para la configuración regional. Esto permite al usuario especificar una fuente exacta para usar con un conjunto de caracteres requerido por una configuración regional, controlando completamente la selección de la fuente.

Si un nombre base de fuente no es un nombre XLFD, Xlib intentará obtener un nombre XLFD de las propiedades de la fuente. Si esta acción tiene éxito en la obtención de un nombre XLFD, la función XBaseFontNameListOfFontSet devolverá este nombre XLFD en lugar del nombre proporcionado por el cliente.

Xlib utiliza el siguiente algoritmo para seleccionar las fuentes que se utilizarán para representar texto con el XFontSet.

Para cada conjunto de caracteres de fuente requerido por la configuración regional, la lista de nombres base de fuentes se busca para la primera aparición de uno de los siguientes casos que nombra un conjunto de fuentes que existen en el servidor:

  • El primer nombre base de fuente conforme a XLFD que especifica el conjunto de caracteres requerido o un superconjunto del conjunto de caracteres requerido en sus campos CharSetRegistry y CharSetEncoding. La implementación puede usar un nombre base de fuente cuyo conjunto de caracteres especificado sea un superconjunto del conjunto de caracteres requerido, por ejemplo, una fuente ISO8859-1 para un conjunto de caracteres ASCII.
  • El primer conjunto de uno o más nombres base de fuentes conformes a XLFD que especifican uno o más conjuntos de caracteres que pueden ser re-mapeados para soportar el conjunto de caracteres requerido. La implementación de Xlib puede reconocer varios mapeos de un conjunto de caracteres requerido a uno o más conjuntos de caracteres y usar las fuentes para esos conjuntos de caracteres. Por ejemplo, JIS Roman es ASCII con tilde y barra invertida reemplazadas por yen y barra superior; Xlib puede cargar una fuente ISO8859-1 para soportar este conjunto de caracteres si no hay una fuente JIS Roman disponible.
  • El primer nombre de fuente XLFD o el primer nombre de fuente no XLFD para el cual se puede obtener un nombre de fuente XLFD, combinado con el conjunto de caracteres requerido (reemplazando los campos CharSetRegistry y CharSetEncoding en el nombre de fuente XLFD). Como en el caso 1, la implementación puede usar un conjunto de caracteres que sea un superconjunto del conjunto de caracteres requerido.
  • El primer nombre de fuente que puede ser mapeado de alguna manera dependiente de la implementación a una o más fuentes que soporten la representación de texto en el conjunto de caracteres.

Por ejemplo, suponga que una configuración regional requería los conjuntos de caracteres:

ISO8859-1
JISX0208.1983
JISX0201.1976
GB2312-1980.0

El usuario podría proporcionar una lista de nombres base de fuentes que especifique explícitamente los conjuntos de caracteres, asegurando que se utilicen fuentes específicas si existen. Por ejemplo:

"-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-240-JISX0208.1983-0,\
-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-120-JISX0201.1976-0,\
-GB-Fixed-Medium-R-Normal--26-180-100-100-C-240-GB2312-1980.0,\
-Adobe-Courier-Bold-R-Normal--25-180-150-ISO8859-1"

Alternativamente, el usuario podría proporcionar una lista de nombres base de fuentes que omita los conjuntos de caracteres, permitiendo a Xlib seleccionar los conjuntos de caracteres de fuentes requeridos para la configuración regional. Por ejemplo:

"-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-240,\
-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-120,\
-GB-Fixed-Medium-R-Normal--26-180-100-100-C-240,\
-Adobe-Courier-Bold-R-Normal--25-180-100-100-M-150"

Alternativamente, el usuario podría simplemente proporcionar un único nombre base de fuente que permita a Xlib seleccionar entre todas las fuentes disponibles que cumplan ciertos requisitos mínimos de propiedades XLFD. Por ejemplo:

"-*-*-*-R-Normal--*-180-100-100-*-*"

Si XCreateFontSet no puede crear el conjunto de fuentes, ya sea porque hay memoria insuficiente o porque la configuración regional actual no es compatible, XCreateFontSet devuelve NULL, missing_charset_list_return se establece en NULL y missing_charset_count_return se establece en cero. Si existen fuentes para todos los conjuntos de caracteres requeridos por la configuración regional actual, XCreateFontSet devuelve un XFontSet válido, missing_charset_list_return se establece en NULL y missing_charset_count_return se establece en cero.

Si no existe una fuente para uno o más de los conjuntos de caracteres requeridos, XCreateFontSet establece missing_charset_list_return en una lista de uno o más nombres de conjuntos de caracteres terminados en nulo para los cuales no existe ninguna fuente y establece missing_charset_count_return en el número de fuentes faltantes. Los conjuntos de caracteres provienen de la lista de los conjuntos de caracteres requeridos para la codificación de la configuración regional y no incluyen ningún conjunto de caracteres al que Xlib pueda re-mapear un conjunto de caracteres requerido.

Si no existe ninguna fuente para ninguno de los conjuntos de caracteres requeridos o si la definición de configuración regional en Xlib requiere que exista una fuente para un conjunto de caracteres particular y no se encuentra una fuente para ese conjunto de caracteres, XCreateFontSet devuelve NULL. De lo contrario, XCreateFontSet devuelve un XFontSet válido a font_set.

Cuando se llama a una función de dibujo o medición Xmb/wc con un XFontSet que tiene conjuntos de caracteres faltantes, algunos caracteres en la configuración regional no serán dibujables. Si def_string_return no es NULL, XCreateFontSet devuelve un puntero a una cadena que representa los glifos que se dibujan con este XFontSet cuando los conjuntos de caracteres de las fuentes disponibles no incluyen todos los glifos de fuente requeridos para dibujar un punto de código. La cadena no consiste necesariamente en caracteres válidos en la configuración regional actual y no se dibuja necesariamente con las fuentes cargadas para el conjunto de fuentes, pero el cliente puede dibujar y medir los glifos predeterminados incluyendo esta cadena en una cadena que se está dibujando o midiendo con el XFontSet.

Si la cadena devuelta a def_string_return es la cadena vacía (""), no se dibujan glifos y el escapement es cero. La cadena devuelta está terminada en nulo. Es propiedad de Xlib y no debe ser modificada ni liberada por el cliente. Será liberada por una llamada a XFreeFontSet con el XFontSet asociado. Hasta que se libere, su contenido no será modificado por Xlib.

El cliente es responsable de construir un mensaje de error a partir de la información de conjuntos de caracteres faltantes y cadenas predeterminadas, y puede optar por continuar la operación en el caso de que algunas fuentes no existieran.

El XFontSet devuelto y la lista de conjuntos de caracteres faltantes deben liberarse con XFreeFontSet y XFreeStringList, respectivamente. El base_font_name_list proporcionado por el cliente puede ser liberado por el cliente después de llamar a XCreateFontSet.

La función XFreeFontSet libera el conjunto de fuentes especificado. La lista de nombres base de fuentes asociada, la lista de nombres de fuentes, la lista de XFontStruct y XFontSetExtents, si las hubiera, se liberan.
