NOMBRE

Xft - biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca sencilla que dibuja texto y gráficos:

  • utilizando información proporcionada por la biblioteca Fontconfig,
  • Xft convierte glifos de fuentes utilizando el rasterizador FreeType, y
  • muestra los datos de fuente convertidos utilizando la Extensión de Renderizado de X.

Esta página del manual apenas roza la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión menor de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias de XFT_VERSION.

El siguiente ejemplo ilustra cómo podrían usarse las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("Versión 2.1.7 o posterior de la biblioteca Xft está en"
                " uso.");
    #else
    (void) printf("Versión insuficiente de Xft (%d.%d.%d) instalada;
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nombres, anteponiendo todas las nombres con "Xft"

Desde Xlib...

Los tipos de datos de Xlib no siguen una convención de nombres. Están documentados en Xlib - Interfaz de Lenguaje C.

Xft utiliza estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, este es un ID de recurso X, por ejemplo, una ventana asociada a una pantalla. Tanto las ventanas como los pixmaps pueden usarse como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como drawables. Sin embargo, una ventana InputOnly no puede usarse como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa mediante la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica la extensión de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

Desde XRender...

Los tipos de datos de la biblioteca de Extensión de Renderizado X están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de cabecera para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft utiliza estos nombres: Picture, XGlyphInfo, XRenderColor.

Desde Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nombres, anteponiendo a todos los nombres "Fc", que están documentados en la Referencia para Desarrolladores de Fontconfig.

Xft utiliza estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern y FcResult.

Desde FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nombres, anteponiendo a todos los nombres "FT_", que están documentados en la Referencia de la API de FreeType.

Xft utiliza estos nombres: FT_Face, FT_Library y FT_UInt.

FreeType 2 utiliza FT_UInt (un entero sin signo) para representar glifos.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que utilizan Xft; contiene métricas generales de fuente y punteros al conjunto de caracteres y al patrón de Fontconfig asociados con la fuente.

Los XftFonts se popularizan con cualquiera de XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), o XftFontOpenPattern(). XftFontCopy() se utiliza para duplicar XftFonts, y XftFontClose() se utiliza para marcar un XftFont como no utilizado. Los XftFonts son asignados internamente, contados por referencia y liberados por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), y XftDrawGlyphSpec() utilizan XftFonts para renderizar texto a un objeto XftDraw, que puede corresponder a un drawable X principal o a un drawable de la Extensión de Renderizado X.

XftGlyphExtents() y la familia XftTextExtents*() se utilizan para determinar los límites (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender(), y la familia XftTextRender*() utilizan XftFonts para dibujar en estructuras Picture de la Extensión de Renderizado X.

Nota: XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), y XftDrawGlyphSpec() proporcionan un medio para renderizar fuentes que es independiente de la disponibilidad de la Extensión de Renderizado X en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy(), y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que puede obtenerse con XftFontInfoHash(). Se puede abrir un XftFont basándose en datos de XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color del servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X para que libere el color actualmente asignado para un XftColor.

Una vez que un XftColor ha sido inicializado, XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec(), y XftDrawRect() pueden usarse para dibujar varios objetos utilizando este.

XftDraw

es un objeto opaco que contiene información utilizada para renderizar a un drawable de X usando el protocolo principal o la extensión X Rendering.

Los objetos XftDraw se crean con cualquiera de las funciones XftDrawCreate() (que asocia un XftDraw con un drawable de X existente), XftDrawCreateBitmap(), o XftDrawCreateAlpha(), y se destruyen con XftDrawDestroy(). El drawable de X asociado con un XftDraw se puede cambiar con XftDrawChange(). Los objetos XftDraw son asignados y liberados internamente por Xft; el programador no necesita asignar o liberar espacio para ellos normalmente.

Las propiedades Display, Drawable, Colormap y Visual de un XftDraw se pueden consultar con XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap() y XftDrawVisual(), respectivamente.

Varias funciones utilizan objetos XftDraw: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode(), y la familia de funciones XftDrawString*().

La extensión X Rendering Picture asociada con un XftDraw se devuelve mediante XftDrawPicture() y XftDrawSrcPicture(). Es utilizada por XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender(), y la familia de funciones XftTextRender*().

FUNCIONES

Inicialización

Una aplicación típica que utiliza Xft no inicializa la biblioteca explícitamente. Eso generalmente se hace como un efecto secundario al abrir una fuente.

Cuando Xft se inicializa, recopila información sobre la pantalla y almacena parte de esa información en un patrón de Fontconfig (esencialmente una colección de propiedades con valores tipados). La aplicación que llama puede modificar ese patrón para cambiar el comportamiento de la biblioteca.

No toda la información recopilada se almacena en un patrón. El resto se almacena en estructuras de datos internas. Xft hace que parte de esa información esté disponible para la aplicación a través de funciones.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y devuelve verdadero si Xft determinó que la pantalla admite la extensión X Render, y si pudo encontrar un XRenderPictFormat adecuado (el tipo de datos de X Render análogo al Visual de Xlib) en la pantalla.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y establece el patrón de Fontconfig que contiene las propiedades predeterminadas que Xft utilizará para esta pantalla.

Xft utiliza estas propiedades inicialmente para obtener los siguientes límites:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). Esta es la cantidad máxima de memoria de glifos para todas las fuentes utilizadas por Xft (por defecto: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). Este es el número máximo de fuentes no referenciadas (por defecto: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). Cuando es verdadero, Xft rastrea el uso de memoria de glifos para mejorar el rendimiento al decidir cuáles descargar cuando se alcanza la cantidad máxima de memoria de glifos (por defecto: falso).
Xft también utiliza estas propiedades predeterminadas en XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft completa las propiedades faltantes en el pattern dado utilizando las propiedades predeterminadas para la pantalla especificada dpy, por ejemplo, como se establece en XftDefaultSet().

Las aplicaciones típicas de Xft utilizan esta función para ayudar a Fontconfig a elegir una fuente adecuada. Estas propiedades se sustituyen antes de llamar a FcDefaultSubstitute():
FC_ANTIALIAS
Verdadero si FreeType debe usar antialiasing (por defecto: Falso). (por defecto: Verdadero).
FC_AUTOHINT
Verdadero si FreeType debe usar autohinting (por defecto: Falso).
FC_DPI
Puntos por pulgada utilizados para la resolución (por defecto: calculado a partir de la altura de la pantalla).
FC_EMBOLDEN
Verdadero si FT_GlyphSlot_Embolden() debe usarse para hacer negrita una fuente (por defecto: Falso).
FC_HINTING
Verdadero si se debe usar hinting al completar propiedades para abrir una fuente (por defecto: Verdadero).
FC_HINT_STYLE
Estilo de hinting utilizado al completar propiedades para abrir una fuente (por defecto: FC_HINT_FULL).
FC_LCD_FILTER
Parámetro pasado a FT_Library_SetLcdFilter() al cargar glifos (por defecto: FC_LCD_DEFAULT).
FC_MINSPACE
Valor de espacio mínimo utilizado al completar propiedades para abrir una fuente (por defecto: Falso).
FC_RGBA
Valor RGBA utilizado al completar propiedades para abrir una fuente (por defecto: calculado llamando a XRenderQuerySubpixelOrder()).
FC_SCALE
Escala utilizada en Fontconfig (por defecto: 1.0).
XFT_MAX_GLYPH_MEMORY
Memoria máxima para una fuente (por defecto: 1024*1024).
XFT_RENDER
Verdadero si la pantalla admite la extensión X Render (por defecto: resultado de XftDefaultHasRender()).
FcBool XftInit (
	_Xconst char	*config);

Inicializa la biblioteca Fontconfig (llamando a FcInit()).

El parámetro config no se utiliza.
Xft no desinicializa la biblioteca Fontconfig cuando termina.
FcBool XftInitFtLibrary (void);

    
Inicializa la biblioteca FreeType (llamando a
        FT_Init_FreeType() para crear un objeto de biblioteca) si aún no se ha inicializado. Esto es necesario antes de utilizar la biblioteca FreeType para leer datos de fuentes de un archivo.

      XftFontInfoCreate() y XftFontOpenPattern().

  

  
Xft no descarta el objeto de biblioteca (por ejemplo, usando
      FT_Done_FreeType()) cuando termina.

Abrir y emparejar fuentes



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen toma una lista de triplete de elementos de patrón del tipo campo, tipo, valor (terminada con NULL), compara ese patrón con las fuentes disponibles y abre la fuente coincidente, dimensionándola correctamente para la pantalla número screen en la pantalla dpy. Devuelve la fuente coincidente o NULL si no se encuentra ninguna coincidencia.

  




Ejemplo:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
Esto abre la fuente “charter” a 12 puntos. El tamaño en puntos se convierte automáticamente al tamaño de píxel correcto según la resolución del monitor.





  
XftFont *XftFontOpenName (

  

    
	Display	*dpy,
	int	 screen,
	_Xconst char	*name);


    
XftFontOpenName se comporta como XftFontOpen,
        excepto que toma una cadena de patrón de Fontconfig (que se pasa a la
        función FcNameParse() de la biblioteca Fontconfig).

  

  
XftFont *XftFontOpenXlfd (

  

    
	Display	*dpy,
	int	 screen,
	_Xconst char	*xlfd)


    
XftFontOpenXlfd se comporta como XftFontOpen,
        excepto que toma una cadena que contiene una Descripción Lógica de Fuente
        X (XLFD), y utiliza la función XftXlfdParse().

  

  
FcPattern *XftFontMatch (

  

    
	Display	*dpy,
	int	 screen,
	_Xconst FcPattern	*pattern,
	FcResult	*result);


    
También utilizado internamente por las funciones
        XftFontOpen*, XftFontMatch también puede ser utilizado
        directamente para determinar el patrón de fuente de Fontconfig que
        resulta de una solicitud de apertura de fuente Xft.

  

  
FcPattern *XftXlfdParse (

  

    
	_Xconst char	*xlfd_orig,
	Bool	ignore_scalable,
	Bool	complete);


    
XftXlfdParse analiza el parámetro xlfd_orig
        de acuerdo con el documento X Logical Font Description
        Conventions, pero ignora algunos de los campos: setwidth_name,
        add_style_name, spacing, y average_width.

  





  

  
XftXlfdParse crea un patrón de Fontconfig, estableciendo la propiedad
      XFT_XLFD al valor xlfd_orig, y mapea la información recopilada
      a propiedades de Fontconfig. Los campos vacíos o " \* " se ignoran:







  
FC_FOUNDRY

  
de foundry.

  
FC_FAMILY

  
de family.

  
FC_WEIGHT

  
weight_name, con un valor predeterminado de FC_WEIGHT_MEDIUM.

  
FC_SLANT

  
de slant, con un valor predeterminado de FC_SLANT_ROMAN.

  
FC_SIZE

  
de point_size.

  
FC_PIXEL_SIZE

  
de pixel_size. Si se estableció point_size, así como
      resolution_x y resolution_y, entonces el valor se escala
      para convertir la altura de la fuente a puntos.

Determinación de Extensiones de Texto


Xft proporciona varias funciones para determinar la altura y
    el ancho requeridos para mostrar una cadena de texto. Después de tener en
    cuenta el offset, en casos donde la cadena se desplazará hacia arriba,
    abajo, izquierda o derecha, estos números se denominan extensiones de
    texto.



  
void XftTextExtents8 (

  

    
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	int	 len,
	XGlyphInfo	*extents);


    
XftTextExtents8 calcula las extensiones de píxeles en la
        pantalla dpy de no más de len glifos de una cadena
        que consiste en caracteres de ocho bits al dibujarse con font,
        almacenándolas en extents.

	Display	*dpy,

XftTextExtents16 calcula las extensiones de píxeles en la
        pantalla dpy de no más de len glifos de una cadena
        que consiste en caracteres de dieciséis bits al dibujarse con font,
        almacenándolas en extents.

  

  
void XftTextExtents32 (

  

    
	Display	*dpy,

XftTextExtents32 calcula las extensiones de píxeles en la

Gestión de XftColor



  
Bool XftColorAllocName (

  

    
	Display	*dpy,
	_Xconst Visual	*visual,
	Colormap	 cmap,
	_Xconst char	*name,
	XftColor	*result);


    
Utiliza XAllocNamedColor() para buscar el color con
        nombre name para la pantalla asociada con el mapa de colores
        cmap.

  






    
  
  • Si XAllocNamedColor() devuelve un valor distinto de cero,
      XftColorAllocName() rellena el campo de píxel XftColor resultante
      con el color más cercano admitido por la pantalla, así como los campos exactos
      rojo, verde y azul de la base de datos, y devuelve True.
    • 
  
  • Si XAllocNamedColor() devuelve cero, XftColorAllocName()
      devuelve False y no actualiza el XftColor al que se hace referencia
      en result.
    • 






  

  
El parámetro visual no se utiliza.





  
Bool XftColorAllocValue (

  

    
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);


    
Asigna un valor de color:

  






    
  
  • Si la clase visual es TrueColor, XftColorAllocValue() establece
      el campo pixel en el XftColor al que se hace referencia en
      result utilizando los campos rojo, verde y azul del parámetro
      color.
    • 
  
  • Si la clase visual no es TrueColor, XftColorAllocValue()
      llama a XAllocColor() para asignar una entrada en el mapa de colores
      cmap. que devuelve el valor de píxel del color más cercano a los
      elementos RGB especificados admitidos por el hardware.
    • 




  

  
Si XAllocColor() tiene éxito, XftColorAllocValue() almacena
      ese valor de píxel en el XRenderColor al que se hace referencia en
      result y devuelve True.

  

  
Si XAllocColor() falla, XftColorAllocValue() devuelve False
      y no modifica el resultado.

	Display	*dpy,

        cuyo valor de píxel en el parámetro color fue asignado por
        XftColorAllocName().

Bool XftDrawSetClip (

  

    
	XftDraw	*draw,
	Region	 r);


    
Configura el recorte para el parámetro XftDraw dado
        draw comenzando con una Region:

  






    
  
  • Si el parámetro Region r no es nulo, Xft crea una
        nueva Region (para copiar el parámetro),
    • 
  
  • Xft destruye cualquier región de recorte existente.
    • 
  
  • Xft establece el tipo de recorte (clip_type) para el parámetro
        draw a XftClipTypeRegion si el parámetro r no era

        XftClipTypeNone.
    • 
  
  • Finalmente, Xft actualiza el recorte para los objetos existentes,
        actualiza la máscara de recorte (clip_mask) para su objeto Picture
        de X Render y establece la máscara de recorte en el contexto gráfico
        (GC) asociado con el parámetro XftDraw.

XftDrawSetClip() devuelve True si no fue necesario ningún
        cambio, o si la operación tuvo éxito. Devuelve False si no pudo

void XftDrawSetSubwindowMode (

  

    
	XftDraw	*draw,

Establece el modo de subventana para el parámetro XftDraw

void XftDrawGlyphFontSpec (

  

    
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Dibuja una lista de glifos asociados con fuentes en coordenadas
        especificadas, pasados como un array de len estructuras
        XftGlyphFontSpec a través del parámetro glyphs. Todos los
        glifos se dibujan usando el color especificado en el parámetro
        color.

  





  

  
Para cada entrada en el array glyphs:






    
  
  • Si la fuente asociada usa la extensión X Render, entonces Xft usa
        XftGlyphFontSpecRender() para dibujar el glifo, usando una
        Picture obtenida al llamar a XftDrawSrcPicture () con los
        parámetros draw y color.
    • 
  
  • De lo contrario, Xft proporciona una característica análoga usando
        Xlib.
    • 






  
void XftGlyphFontSpecRender (

  

    
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
Esto implica varios pasos:

  






    
  
  • Primero, Xft asegura que el array glyphs esté completo usando
        XftFontCheckGlyph() y cargando cualquier glifo faltante con
        XftFontLoadGlyphs().
    • 
  
  • Luego Xft examina los glifos para encontrar el valor Unicode máximo.
        Eso determina el tamaño de codificación, es decir, el ancho.
    • 
  
  • Luego, para cada glifo, Xft verifica si su valor Unicode es manejado
        por la fuente correspondiente. Si no, el valor se establece en cero (0),
        para ignorarlo. Mientras hace esto, Xft también recuerda cuál fue
        la primera fuente utilizada y calcula la posición en la que se dibujará
        cada glifo.
    • 
  
  • Xft luego construye un array equivalente de glifos en el formato
        esperado por la biblioteca X Render.
    • 
  
  • Finalmente, XftGlyphFontSpecRender() utiliza la extensión X Render
        para dibujar los glifos, con la función apropiada XRenderCompositeText*()
        según el ancho, y descarta los datos temporales.
    • 




  

  
Los parámetros op, dst, src, srcx, y
        srcy se usan como se describe en la documentación de la biblioteca
        X Render.

void XftFontLoadGlyphs (




	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);



Utiliza FT_Load_Glyph() para cargar nglyphs para los índices de glifos (valores Unicode) listados en el array glyphs de la fuente dada pub.










Cargar un glifo implica más que simplemente leer datos en memoria. Xft usa el patrón de Fontconfig asociado a la pantalla dpy (por ejemplo, a través de XftDefaultSet()) para determinar si se debe usar un cuadro delimitador, recortar los glifos a esos límites, escalar los glifos, calcular las métricas de la fuente y agregarlo a la extensión X Render usando XRenderAddGlyphs().






void XftFontUnloadGlyphs (




	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);



Descarta datos para hasta nglyph glifos cuyos índices de glifos (valores Unicode) están listados en el array glyphs para la fuente dada pub. Si los glifos fueron agregados a la extensión X Render, Xft los elimina usando XRenderFreeGlyphs(). Xft rastrea la cantidad de memoria utilizada para los glifos y actualiza el uso asociado a la pantalla dpy.








FT_Face XftLockFace (




	XftFont	*pub);



Si no se ha creado ninguna "cara" de FreeType 2 (representación en memoria de una tipografía dada en un estilo dado) para la fuente pub, crea una usando FT_New_Face(). Los bloqueos de cara son un contador de referencias utilizado por Xft para garantizar que solo se cree una cara y que se mantenga hasta que la fuente ya no se use.










El bloqueo de cara se utiliza directamente en XftCharIndex() y XftFontLoadGlyphs(), que a su vez se utilizan en muchas funciones de Xft.




El bloqueo de cara se introdujo en la versión 1 (octubre de 2002). Algunas aplicaciones, como Gdk/Gimp, dependían de estas funciones. En la versión 2.1.9 (junio de 2006), se mantuvo el bloqueo de cara como parte de la API pública cuando las configuraciones mejoradas de bibliotecas compartidas proporcionaron la ocultación de símbolos privados.






void XftUnlockFace (




	XftFont	*pub);



Decrementa el contador de referencias para la "cara" de FreeType 2 asociada a la fuente.










Los objetos FT_Face se desasignan usando FT_Done_Face(). Xft lo hace en XftFontInfoDestroy() y al limpiar en caso de error en XftFontInfoCreate() y XftFontOpenPattern().








DEBUGGING


Xft lee la variable de entorno XFT_DEBUG y la convierte a un entero. Cada bit en el valor resultante le indica a Xft que imprima información de depuración en la salida estándar:




1


apertura de fuentes


2


coincidencia y apertura de fuentes adicionales (verboso)


4


muestra detalles sobre el XRenderPictFormat que se utilizará.


8


muestra la cadena que XftDrawString8() dibujará.


16


muestra qué IDs de fuente coinciden.


32


muestra información útil sobre los glifos que se dibujarán


64


muestra una representación en arte ASCII de los glifos.


128


muestra detalles sobre la gestión de la caché de memoria


256


muestra detalles sobre la gestión de la memoria caché de glifos


512


muestra un informe sobre el uso de memoria


1024


muestra detalles sobre la gestión extendida de la memoria caché de glifos








COMPATIBILITY


A partir de la versión 2 (mayo de 2002), Xft se volvió relativamente estable. Se espera que mantenga la compatibilidad de origen y binaria en futuras versiones.


Xft proporciona una interfaz de compatibilidad con su versión principal anterior, Xft 1.x, descrita a continuación.




Archivo de cabecera Xft 1.x


#include <X11/Xft/XftCompat.h>






Tipos de datos Xft 1.x




XftPattern


contiene un conjunto de nombres con listas de valores asociadas; cada nombre se refiere a una propiedad de una fuente. Los XftPatterns se utilizan como entradas para el código de coincidencia y también contienen información sobre fuentes específicas.


XftFontSet


contiene una lista de XftPatterns. Internamente, Xft utiliza esta estructura de datos para mantener conjuntos de fuentes. Externamente, Xft devuelve los resultados de la lista de fuentes en este formato.


XftObjectSet


contiene un conjunto de nombres y se utiliza para especificar qué campos de las fuentes se incluyen en la lista de patrones devueltos al listar fuentes.
