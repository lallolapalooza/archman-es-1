ARGUMENTOS

display
Especifica la conexión al servidor X.
screen
Especifica a qué número de pantalla se aplican los ajustes.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de video disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo; de lo contrario, cambia al modo anterior.
lock
Indica que el cambio de modo debe bloquearse, si no es cero.
modeline
Especifica o devuelve los valores de temporización para un modo de video.
aftermode
Especifica los valores de temporización para el modo de video después del cual se añadirá el nuevo modo.
modesinfo
Devuelve los valores de temporización y los relojes de puntos (dotclocks) para todos los modos de video disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para el viewport.
x_return
Devuelve la ubicación X actual del viewport.
y
Especifica la ubicación Y deseada para el viewport.
y_return
Devuelve la ubicación Y actual del viewport.

DESCRIPCIÓN

La biblioteca libXxf86vm proporciona acceso a la extensión XFree86-VidMode. Esta extensión permite a las aplicaciones controlar las capacidades de modo de video de una tarjeta gráfica.

Las funciones son:

XF86VidModeQueryExtension
Comprueba si la extensión VidMode está disponible en el servidor X. Si lo está, devuelve el número base de eventos y errores para la extensión.
XF86VidModeQueryVersion
Devuelve el número de versión mayor y menor de la extensión VidMode que el servidor entiende.
XF86VidModeSetClientVersion
Indica al servidor X la versión de la extensión VidMode que la biblioteca del cliente va a usar. Esto debe llamarse después de XF86VidModeQueryVersion.
XF86VidModeGetModeLine
Devuelve los valores de temporización actuales de la pantalla especificada. El valor de dotclock_return se devuelve en unidades de 1000.0 Hz.
XF86VidModeGetAllModeLines
Devuelve una lista de todas las líneas de modo configuradas actualmente en el servidor para la pantalla especificada. El recuento de modos se almacena en modecount_return y la lista de modos se almacena en modesinfo.
XF86VidModeAddModeLine
Añade la línea de modo especificada a la lista de modos para la pantalla especificada. La línea de modo se añadirá después de aftermode. Si aftermode es NULL, se añadirá al final de la lista.
XF86VidModeDeleteModeLine
Elimina la línea de modo especificada de la lista de modos para la pantalla especificada.
XF86VidModeModModeLine
Modifica la línea de modo actual para la pantalla especificada.
XF86VidModeValidateModeLine
Comprueba si la línea de modo especificada es válida para la pantalla especificada. Devuelve Success si es válida, o un código de error si no lo es.
XF86VidModeSwitchMode
Cambia al siguiente (si zoom es mayor que cero) o anterior (si zoom es menor o igual que cero) modo de video configurado para la pantalla especificada.
XF86VidModeSwitchToMode
Cambia al modo de video especificado para la pantalla especificada.
XF86VidModeLockModeSwitch
Bloquea o desbloquea los cambios de modo. Si lock no es cero, se bloquean los cambios de modo.
XF86VidModeGetMonitor
Devuelve información sobre el monitor conectado a la pantalla especificada.
XF86VidModeGetViewPort
Devuelve la posición actual del viewport de la pantalla especificada.
XF86VidModeSetViewPort
Establece la posición del viewport de la pantalla especificada a las coordenadas X e Y dadas.
XF86VidModeGetDotClocks
Devuelve una lista de las frecuencias de reloj de puntos disponibles para la pantalla especificada.
XF86VidModeGetGamma
Devuelve los valores de gamma actuales para la pantalla especificada.
XF86VidModeSetGamma
Establece los valores de gamma para la pantalla especificada.
XF86VidModeGetGammaRamp
Devuelve las rampas gamma de color para la pantalla especificada.
XF86VidModeSetGammaRamp
Establece las rampas gamma de color para la pantalla especificada.
XF86VidModeGetGammaRampSize
Devuelve el tamaño (número de entradas) de las rampas gamma de color para la pantalla especificada.

EVENTOS

La extensión VidMode puede generar los siguientes eventos:

XF86VidModeSwitchEvent
Se genera cuando se produce un cambio de modo.
XF86VidModePageFlipEvent
Se genera cuando se completa un volteo de página.
XF86VidModeGLEvent
Se genera cuando ocurre un error de GLX.
XF86VidModeClientSwapEvent
Se genera cuando el servidor cambia de cliente.

ERRORES

La extensión VidMode puede generar los siguientes errores:

BadMode
Se genera si se especifica un modo de video no válido.
BadDevice
Se genera si se especifica un dispositivo no válido.

VER TAMBIÉN

XOpenDisplay(3), XCloseDisplay(3), XSync(3)

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la extensión del servidor XFree86-VidModeExtension que permite consultar y ajustar dinámicamente los modos de vídeo y controlar el cambio de modo. Las aplicaciones que utilizan estas funciones deben enlazarse con -lXxf86vm

FUNCIONES DE MODELINE

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de vídeo seleccionado actualmente. El programa que llama debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si hay algún valor privado del servidor (actualmente solo aplicable al servidor S3), la función asignará almacenamiento para él. Por lo tanto, si el campo privsize no es cero, el programa que llama debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de vídeo. El programa que llama proporciona la dirección de un puntero que la función establecerá para que apunte a una matriz de estructuras XF86VidModeModeInfo. La memoria ocupada por la matriz es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamante. El primer elemento de la matriz corresponde al modo de vídeo actual.

La función XF86VidModeModModeLine se puede utilizar para cambiar la configuración del modo de vídeo actual siempre que la configuración solicitada sea válida (por ejemplo, no exceda las capacidades del monitor).

Para añadir un modo a la lista de modos disponibles, se puede usar la función XF86VidModeAddModeLine. Asumiendo que la configuración es válida, el modo de vídeo se añadirá después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se añadirá después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero ocurrirá un cambio de modo al siguiente modo. El último modo restante no se puede eliminar.

La validez de un modo se puede comprobar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser utilizado por el servidor (es decir, cumple todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario, devuelve un valor que indica la razón por la cual el modo no es válido (según se define en xf86.h)

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de vídeo al siguiente (o anterior) modo de vídeo. La función XF86VidModeSwitchToMode se puede utilizar para cambiar directamente al modo especificado. La coincidencia se especifica en la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch se puede utilizar para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, se necesita una llamada a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado del estado de ejecución de la solicitud, se debe instalar un manejador de errores personalizado utilizando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información que el servidor conoce sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a una matriz de estructuras XF86VidModeSyncRange. Las matrices contienen nhsync y nvsync elementos, respectivamente. Los valores hi y low serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamante.

FUNCIONES DE VIEWPORT

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort se pueden utilizar para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda del viewport en la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion se puede utilizar para determinar la versión de la extensión integrada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores de error y evento de menor número asignados a la extensión.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulta el código fuente para obtener información sobre cómo usarlas.
