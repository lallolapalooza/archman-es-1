XFIXES(3) X Versión 11 XFIXES(3)

NOMBRE

XFixes - Versiones aumentadas de las solicitudes del protocolo principal

SINTAXIS

#include <X11/extensions/Xfixes.h>

Bool XFixesQueryExtension (Display *dpy,
	int *event_base_return, int *error_base_return);

Status XFixesQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

void XFixesChangeSaveSet (Display *dpy,
	Window window,
	int mode,
	int target,
	int map);

ARGUMENTOS

display
Especifica la conexión al servidor X.
window
Especifica qué ventana.
mode
Especifica la operación del conjunto de guardado (SetModeInsert/SetModeDelete).
target
Especifica el objetivo al ejecutar el conjunto de guardado (SaveSetNearest/SaveSetRoot). En el modo SaveSetNearest, la ventana miembro del conjunto de guardado será reparentada a la ventana más cercana no propiedad del cliente del conjunto de guardado. En el modo SaveSetRoot, la ventana miembro del conjunto de guardado será reparentada a la ventana raíz.
map
Especifica el modo de mapeo (SaveSetMap/SaveSetUnmap) que selecciona si la ventana miembro del conjunto de guardado se mapeará o desempaquetará durante el procesamiento del conjunto de guardado.

DESCRIPCIÓN

Xfixes es una biblioteca simple diseñada para interactuar con la Extensión X Fixes. Esta extensión proporciona a las aplicaciones soluciones alternativas para varias limitaciones en el protocolo principal.

RESTRICCIONES

Xfixes seguirá siendo compatible hacia atrás después del lanzamiento 1.0.
