NOMBRE

Xft - Biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca simple que dibuja texto y gráficos:

  • utilizando información proporcionada por la biblioteca Fontconfig,
  • Xft convierte glifos de fuentes utilizando el rasterizador FreeType, y
  • muestra los datos de fuente convertidos utilizando la extensión X Rendering Extension.

Esta página del manual apenas roza la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión secundaria de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias para XFT_VERSION.

El siguiente ejemplo ilustra cómo podrían usarse las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("Está en uso la versión 2.1.7 o posterior de la biblioteca Xft.");
    #else
    (void) printf("Versión insuficiente de Xft instalada (%d.%d.%d);
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nomenclatura, anteponiendo a todos los nombres la cadena "Xft"

Desde Xlib...

Los tipos de datos de Xlib no siguen una convención de nomenclatura. Se documentan en Xlib - C Language Interface.

Xft utiliza estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, este es un ID de recurso X, por ejemplo, una ventana asociada a una pantalla. Tanto las ventanas como los pixmaps pueden usarse como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como "drawables". Sin embargo, una ventana de tipo InputOnly no puede usarse como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa mediante la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica la extensión de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

Desde XRender...

Los tipos de datos de la extensión X Render Extension están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de encabezado para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft utiliza estos nombres: Picture, XGlyphInfo, XRenderColor.

Desde Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nomenclatura, anteponiendo a todos los nombres la cadena "Fc", que se documentan en Fontconfig Developers Reference.

Xft utiliza estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern y FcResult.

Desde FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nomenclatura, anteponiendo a todos los nombres la cadena "FT_", que se documentan en FreeType API Reference.

Xft utiliza estos nombres: FT_Face, FT_Library y FT_UInt.

FreeType 2 utiliza FT_UInt (un entero sin signo) para representar glifos.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que usan Xft; contiene métricas generales de fuente y punteros al conjunto de caracteres y al patrón de Fontconfig asociados con la fuente.

Los XftFonts se rellenan con XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo() o XftFontOpenPattern(). XftFontCopy() se utiliza para duplicar XftFonts, y XftFontClose() se utiliza para marcar un XftFont como no utilizado. Los XftFonts son asignados internamente, contados por referencia y liberados por Xft; el programador normalmente no necesita asignar ni liberar almacenamiento para ellos.

XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() utilizan XftFonts para renderizar texto a un objeto XftDraw, que puede corresponder a un dibujable X principal o a un dibujable de la extensión X Rendering Extension.

XftGlyphExtents() y la familia XftTextExtents*() se utilizan para determinar las extensiones (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender() y la familia XftTextRender*() utilizan XftFonts para dibujar en estructuras Picture de la extensión X Rendering Extension.

Nota: XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() proporcionan un medio de renderizar fuentes que es independiente de la disponibilidad de la extensión X Rendering Extension en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy() y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar ni liberar almacenamiento para ellos.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que se puede obtener con XftFontInfoHash(). Se puede abrir un XftFont basándose en datos de XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color al servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X para que libere el color actualmente asignado para un XftColor.

Una vez que un XftColor ha sido inicializado, se pueden usar XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec() y XftDrawRect() para dibujar varios objetos

También utilizada internamente por las funciones XftFontOpen*, XftFontMatch también puede utilizarse directamente para determinar el patrón de fuente de Fontconfig resultante de una solicitud de apertura de fuente de Xft.

FcPattern *XftXlfdParse (
	_Xconst char	*xlfd_orig,
	Bool	ignore_scalable,
	Bool	complete);

XftXlfdParse analiza el parámetro xlfd_orig según el documento X Logical Font Description Conventions, pero ignora algunos de los campos: setwidth_name, add_style_name, spacing y average_width.

XftXlfdParse crea un patrón de Fontconfig, estableciendo la propiedad XFT_XLFD al valor xlfd_orig y mapea la información recopilada a propiedades de Fontconfig. Los campos vacíos o “*” se ignoran:
FC_FOUNDRY
de foundry.
FC_FAMILY
de family.
FC_WEIGHT
weight_name, con un valor predeterminado de FC_WEIGHT_MEDIUM.
FC_SLANT
de slant, con un valor predeterminado de FC_SLANT_ROMAN.
FC_SIZE
de point_size.
FC_PIXEL_SIZE
de pixel_size. Si se estableció point_size, así como resolution_x y resolution_y, entonces el valor se escala para convertir la altura de la fuente a puntos.

Xft proporciona varias funciones para determinar la altura y anchura requeridas para mostrar una cadena de texto. Después de tener en cuenta el desplazamiento, en los casos en que la cadena se desplazará hacia arriba, abajo, izquierda o derecha, estos números se denominan extensíones de texto.

Gestión de XftColor

Bool XftColorAllocName (
	Display	*dpy,
	_Xconst Visual	*visual,
	Colormap	 cmap,
	_Xconst char	*name,
	XftColor	*result);

Utiliza XAllocNamedColor() para buscar el color con nombre name para la pantalla asociada con el mapa de colores cmap.

  • Si XAllocNamedColor() devuelve un valor distinto de cero, XftColorAllocName() rellena el campo de píxel resultante de XftColor con el color más cercano admitido por la pantalla, así como los campos exactos de rojo, verde y azul de la base de datos, y devuelve True.
  • Si XAllocNamedColor() devuelve cero, XftColorAllocName() devuelve False y no actualiza el XftColor referenciado por result.
El parámetro visual no se utiliza.
Bool XftColorAllocValue (
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);

Asigna un valor de color:

  • Si la clase visual es TrueColor, XftColorAllocValue() establece el campo pixel en el XftColor referenciado por result utilizando los campos rojo, verde y azul del parámetro color.
  • Si la clase visual no es TrueColor, XftColorAllocValue() llama a XAllocColor() para asignar una entrada en el mapa de colores cmap, que devuelve el valor de píxel del color más cercano a los elementos RGB especificados admitidos por el hardware.
Si XAllocColor() tiene éxito, XftColorAllocValue() almacena ese valor de píxel en el XRenderColor referenciado por result y devuelve True.
Si XAllocColor() falla, XftColorAllocValue() devuelve False y no modifica el resultado.
void XftColorFree (
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	XftColor	*color);

Si la clase visual no es TrueColor, Xft llama a XFreeColors() para liberar la entrada del mapa de colores cmap cuyo valor de píxel en el parámetro color fue asignado por XftColorAllocName().

DESCRIPTION


The Xft library provides facilities for rendering fonts using the
    FreeType library. It integrates font selection with the Fontconfig library,
    and supports the X Rendering Extension for high-quality anti-aliased font
    rendering.

void XftDrawGlyphFontSpec (

  

    
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Draw a list of glyphs associated with fonts at specified
        coordinates, passed as an array of len XftGlyphFontSpec
        structures via the parameter glyphs. All of the glyphs are drawn
        using the color specified in the color parameter.

  







  

  
For each entry in the glyphs array:






    
  
  • If the associated font uses the X Render extension, then Xft uses
      XftGlyphFontSpecRender() to draw the glyph, using a Picture
      obtained from calling XftDrawSrcPicture () with the draw and
      color parameters.
    • 
  
  • Otherwise, Xft provides an analogous feature using Xlib.
    • 








  
void XftGlyphFontSpecRender (

  

    
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
This involves several steps:

  






    
  
  • First, Xft ensures that the glyphs array is complete using
      XftFontCheckGlyph() and loading any missing glyphs with
      XftFontLoadGlyphs().
    • 
  
  • Then Xft examines the glyphs to find the maximum Unicode value.
      That determines the encoding size, i.e., the width.
    • 
  
  • Then, for each glyph, Xft checks if its Unicode value is handled by
      the corresponding font. If not, the value is set to zero (0), to ignore
      it. While doing this, Xft also remembers which was the first font
      used, and computes the position at which each glyph will be drawn.
    • 
  
  • Xft then constructs an equivalent array of glyphs in the format
      expected by the X Render library.
    • 
  
  • Finally, XftGlyphFontSpecRender() uses the X Render extension to
      draw the glyphs, with the appropriate XRenderCompositeText*()
      function according to the width, and discards temporary data.
    • 




  

  
The op, dst, src, srcx, and srcy
      parameters are used as described in the documentation for the X Render
      library.

NOMBRE


Xft - Biblioteca de fuentes X, versión 2






SINOPSIS


#include <X11/Xft/Xft.h>








DESCRIPCIÓN


Xft es una biblioteca que proporciona acceso a fuentes
    utilizando Fontconfig y FreeType 2. Esto permite que las aplicaciones accedan
    a fuentes de una manera más consistente y flexible que el sistema de fuentes
    X tradicional. Xft se enfoca en las fuentes que se renderizan
    utilizando la extensión X Render, pero también puede renderizar fuentes
    pixmap o bitmap.


Esta página de manual describe las funciones que manejan nombres
    de fuentes y datos de fuentes.




Manejo de nombres de fuentes



  
FcPattern * XftNameParse (

  

    
	Display	*dpy,
	_Xconst FcChar8	*name);


    
Analiza la cadena de nombres de fuente name. Se usa la
        base de datos de fuentes de Fontconfig para resolver cualquier nombre
        generado. Si se proporciona un nombre de fuente completo (por ejemplo,
        "Times-12"), la función intentará resolverlo en un patrón de fuente
        completo. Si el nombre solo especifica algunas propiedades (por ejemplo,
        "family=Times:style=Bold"), solo se establecerán esas propiedades. El
        patrón de fuente resultante se asocia con la pantalla dpy.

  

  
FcBool XftNameUnparse (

  

    
	FcPattern	*pat,
	FcChar8	*dest,
	int	 len);


    
Convierte el patrón de fuente pat de nuevo a una cadena
        de nombre de fuente. La cadena resultante se escribe en el búfer
        apuntado por dest, que tiene un tamaño máximo de len bytes.
        Si la cadena cabe, la función devuelve FcTrue; de lo contrario,
        devuelve FcFalse.

COMPATIBILIDAD


A partir de la versión 2 (mayo de 2002), Xft alcanzó una
    estabilidad considerable. Se espera que mantenga la compatibilidad de origen y
    binaria en futuras versiones.


Xft proporciona una interfaz de compatibilidad con su
    versión principal anterior, Xft 1.x, descrita a continuación.




Archivo de cabecera Xft 1.x


#include <X11/Xft/XftCompat.h>






Tipos de datos Xft 1.x



  
XftPattern

  
Contiene un conjunto de nombres con listas de valores asociados; cada nombre
      se refiere a una propiedad de una fuente. Los XftPattern se utilizan
      como entrada para el código de coincidencia, así como para contener
      información sobre fuentes específicas.

  
XftFontSet

  
Contiene una lista de XftPattern. Internamente, Xft utiliza
      esta estructura de datos para mantener conjuntos de fuentes. Externamente,
      Xft devuelve los resultados de la enumeración de fuentes en este
      formato.

  
XftObjectSet

  
Contiene un conjunto de nombres y se utiliza para especificar qué campos
      de las fuentes se incluyen en la lista de patrones devueltos al enumerar
      fuentes.
