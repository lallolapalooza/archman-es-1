ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen
Especifica a qué número de pantalla se aplican las configuraciones.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de video disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo; de lo contrario, cambiará al modo anterior.
lock
Indica que el cambio de modo debe bloquearse, si no es cero.
modeline
Especifica o devuelve los valores de temporización para un modo de video.
aftermode
Especifica los valores de temporización para el modo de video después del cual se agregará el nuevo modo.
modesinfo
Devuelve los valores de temporización y los relojes de puntos para todos los modos de video disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para el viewport.
x_return
Devuelve la ubicación X actual del viewport.
y
Especifica la ubicación Y deseada para el viewport.
y_return
Devuelve la ubicación Y actual del viewport.

DESCRIPCIÓN

The XF86VidMode extension provides functions to control the video modes of the X server. These functions allow applications to query information about the available video modes, set new video modes, and control the monitor's display attributes.

The following functions are available:

XF86VidModeQueryExtension queries the server to see if the XFree86-VidMode extension is available. If it is, it returns the base event and error numbers for the extension.

XF86VidModeQueryVersion queries the server for the version number of the XFree86-VidMode extension.

XF86VidModeSetClientVersion informs the server about the client's version of the extension. This is primarily used for compatibility checks.

XF86VidModeGetModeLine retrieves the current video mode parameters for a given screen, including the dot clock and timing information.

XF86VidModeGetAllModeLines retrieves all available video mode parameters for a given screen.

XF86VidModeAddModeLine adds a new video mode to the server's list of available modes. The new mode is inserted after the specified aftermode.

XF86VidModeDeleteModeLine removes a video mode from the server's list.

XF86VidModeModModeLine modifies the current video mode parameters on the server.

XF86VidModeValidateModeLine checks if a given video mode line is valid according to the server's capabilities.

XF86VidModeSwitchMode attempts to switch to the next or previous video mode, depending on the value of the zoom argument.

XF86VidModeSwitchToMode switches the server to a specific video mode specified by modeline.

XF86VidModeLockModeSwitch locks or unlocks the ability to switch video modes. If lock is non-zero, mode switching is locked.

XF86VidModeGetMonitor retrieves information about the connected monitor, including its vendor, model, and supported synchronization ranges.

XF86VidModeGetViewPort retrieves the current position of the virtual viewport on the screen.

XF86VidModeSetViewPort sets the position of the virtual viewport.

XF86VidModeGetDotClocks retrieves information about the available dot clocks for the screen, including the maximum dot clock rate.

XF86VidModeGetGamma retrieves the current gamma settings for the screen.

XF86VidModeSetGamma sets the gamma settings for the screen.

XF86VidModeGetGammaRamp retrieves the current gamma ramp (color correction tables) for the screen.

XF86VidModeSetGammaRamp sets the gamma ramp for the screen.

XF86VidModeGetGammaRampSize retrieves the size of the gamma ramp arrays supported by the server.

XF86VidModeGetPermissions retrieves permission information related to video mode setting. Note: This function might not be universally implemented or required depending on the X server version and configuration.

DEVOLUCIONES

All functions return True on success, and False on failure, unless otherwise noted. XF86VidModeValidateModeLine returns True if the modeline is valid, and False otherwise.

ERRORES

Errors may be generated by the X server, and these are reported through the X error handling mechanism. Specific errors related to the XFree86-VidMode extension may include:

BadMatch
A value is invalid for the specified screen.
BadValue
An invalid value was passed to a function.
NotImplemented
The requested operation is not implemented by the server.
ScreenOf
The specified screen does not exist.

DESCRIPTION These functions provide an interface to the server extension XFree86-VidModeExtension which allows the video modes to be queried and adjusted dynamically and mode switching to be controlled. Applications that use these functions must be linked with -lXxf86vm
MODELINE FUNCTIONS The XF86VidModeGetModeLine function is used to query the settings for the currently selected video mode. The calling program should pass a pointer to a XF86VidModeModeLine structure that it has already allocated. The function fills in the fields of the structure. If there are any server private values (currently only applicable to the S3 server) the function will allocate storage for them. Therefore, if the privsize field is non-zero, the calling program should call Xfree(private) to free the storage. XF86VidModeGetAllModeLines returns the settings for all video modes. The calling program supplies the address of a pointer which will be set by the function to point to an array of XF86VidModeModeInfo structures. The memory occupied by the array is dynamically allocated by the XF86VidModeGetAllModeLines function and should be freed by the caller. The first element of the array corresponds to the current video mode. The XF86VidModeModModeLine function can be used to change the settings of the current video mode provided the requested settings are valid (e.g. they don't exceed the capabilities of the monitor). To add a mode to the list of available modes, the XF86VidModeAddModeLine function can be used. Assuming the settings are valid, the video mode will be added after the existing mode which matches the timings specified by the aftermode parameter. To be considered a match, all of the fields of the given XF86VidModeModeInfo structure must match, except the privsize and private fields. If the aftermode parameter is zero, the mode will be added after the current mode. Modes can be deleted with the XF86VidModeDeleteModeLine function. The specified mode must match an existing mode. To be considered a match, all of the fields of the given XF86VidModeModeInfo structure must match, except the privsize and private fields. If the mode to be deleted is the current mode, a mode switch to the next mode will occur first. The last remaining mode can not be deleted. The validity of a mode can be checked with the XF86VidModeValidateModeLine function. If the specified mode can be used by the server (i.e. meets all the constraints placed upon a mode by the combination of the server, card, and monitor) the function returns MODE_OK, otherwise it returns a value indicating the reason why the mode is invalid (as defined in xf86.h)
MODE SWITCH FUNCTIONS When the function XF86VidModeSwitchMode is called, the server will change the video mode to next (or previous) video mode. The XF86VidModeSwitchToMode function can be used to switch directly to the specified mode. Matching is as specified in the description of the XF86VidModeAddModeLine function above. The XF86VidModeLockModeSwitch function can be used to allow or disallow mode switching whether the request to switch modes comes from a call to the XF86VidModeSwitchMode or XF86VidModeSwitchToMode functions or from one of the mode switch key sequences. Note: Because of the asynchronous nature of the X protocol, a call to XFlush is needed if the application wants to see the mode change immediately. To be informed of the execution status of the request, a custom error handler should be installed using XSetErrorHandler before calling the mode switching function.
MONITOR FUNCTIONS Information known to the server about the monitor is returned by the XF86VidModeGetMonitor function. The hsync and vsync fields each point to an array of XF86VidModeSyncRange structures. The arrays contain nhsync and nvsync elements, respectively. The hi and low values will be equal if a discreate value was given in the XF86Config file. The vendor, model, hsync, and vsync fields point to dynamically allocated storage that should be freed by the caller.
VIEWPORT FUNCTIONS The XF86VidModeGetViewPort and XF86VidModeSetViewPort functions can be used to, respectively, query and change the location of the upper left corner of the viewport into the virtual screen.
OTHER FUNCTIONS The XF86VidModeQueryVersion function can be used to determine the version of the extension built into the server. The function XF86VidModeQueryExtension returns the lowest numbered error and event values assigned to the extension.
BUGS The XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize, and XF86VidModeGetPermissions functions need to be documented. In the meantime, check the source code for information about how to use them.
