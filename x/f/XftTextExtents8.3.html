NOMBRE

Xft - biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca sencilla que dibuja texto y gráficos:

  • utilizando la información proporcionada por la biblioteca Fontconfig,
  • Xft convierte glifos de fuentes utilizando el rasterizador FreeType, y
  • muestra los datos de fuente convertidos utilizando la extensión de renderizado de X.

Esta página del manual apenas araña la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión menor de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias para XFT_VERSION.

El siguiente ejemplo ilustra cómo podrían usarse las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("Versión 2.1.7 o posterior de la biblioteca Xft está en"
                " uso.");
    #else
    (void) printf("Versión insuficiente de Xft (%d.%d.%d) instalada;
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nomenclatura, prefijando todos los nombres con “Xft”

Desde Xlib...

Los tipos de datos de Xlib no siguen una convención de nomenclatura. Se documentan en Xlib - Interfaz del lenguaje C.

Xft utiliza estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, este es un ID de recurso X, por ejemplo, una ventana asociada a una pantalla. Tanto las ventanas como los pixmaps se pueden usar como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como drawables. Sin embargo, una ventana InputOnly no se puede usar como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa como la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica la extensión de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

Desde XRender...

Los tipos de datos de la biblioteca X Render Extension están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de encabezado para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft utiliza estos nombres: Picture, XGlyphInfo, XRenderColor.

Desde Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nomenclatura, prefijando todos los nombres con “Fc”, que se documentan en Fontconfig Developers Reference.

Xft utiliza estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern y FcResult.

Desde FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nomenclatura, prefijando todos los nombres con “FT_”, que se documentan en FreeType API Reference.

Xft utiliza estos nombres: FT_Face, FT_Library y FT_UInt.

FreeType 2 utiliza FT_UInt (un entero sin signo) para representar *glifos*.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que utilizan Xft; contiene métricas generales de la fuente y punteros al conjunto de caracteres y al patrón de Fontconfig asociados con la fuente.

Los XftFont se completan con cualquiera de las funciones XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), o XftFontOpenPattern(). XftFontCopy() se utiliza para duplicar XftFonts, y XftFontClose() se utiliza para marcar un XftFont como no utilizado. Los XftFonts son asignados internamente, contados por referencia y liberados por Xft; el programador normalmente no necesita asignar ni liberar almacenamiento para ellos.

XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() utilizan XftFonts para renderizar texto en un objeto XftDraw, que puede corresponder a un drawable de X principal o a un drawable de la extensión de renderizado de X.

XftGlyphExtents() y la familia XftTextExtents*() se utilizan para determinar los límites (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender() y la familia XftTextRender*() utilizan XftFonts para dibujar en estructuras Picture de la extensión de renderizado de X.

Nota: XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() proporcionan un medio para renderizar fuentes que es independiente de la disponibilidad de la extensión de renderizado de X en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy() y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar ni liberar almacenamiento para ellos.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que se puede obtener con XftFontInfoHash(). Se puede abrir un XftFont basándose en datos XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color del servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X para que libere el color actualmente asignado para un XftColor.

Una vez que un XftColor ha sido inicializado, XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec() y XftDrawRect() pueden ser utilizados para dibujar varios objetos usando i

STRUCTURES

XftDraw

es un objeto opaco que contiene información utilizada para renderizar en un drawable de X utilizando el protocolo principal o la extensión X Rendering.

Los objetos XftDraw se crean con cualquiera de las funciones XftDrawCreate() (que asocia un XftDraw con un drawable de X existente), XftDrawCreateBitmap(), o XftDrawCreateAlpha(), y se destruyen con XftDrawDestroy(). El drawable de X asociado con un XftDraw se puede cambiar con XftDrawChange(). Los objetos XftDraw son asignados y liberados internamente por Xft; el programador no necesita asignar ni liberar memoria para ellos de forma ordinaria.

Las propiedades de Display, Drawable, Colormap y Visual de X de un XftDraw se pueden consultar con XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap() y XftDrawVisual(), respectivamente.

Varias funciones utilizan objetos XftDraw: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode(), y la familia XftDrawString*().

El Picture de la Extensión de Renderizado de X asociado con un XftDraw se devuelve con XftDrawPicture() y XftDrawSrcPicture(). Es utilizado por XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender(), y la familia XftTextRender*().

FUNCIONES

Inicialización

Una aplicación típica que utiliza Xft no inicializa explícitamente la biblioteca. Eso se hace generalmente como un efecto secundario al abrir una fuente.

Cuando Xft se inicializa, recopila información sobre la pantalla y almacena parte de esa información en un patrón de Fontconfig (esencialmente una colección de propiedades con valores tipados). La aplicación que llama puede modificar ese patrón para cambiar el comportamiento de la biblioteca.

No toda la información recopilada se almacena en un patrón. El resto se almacena en estructuras de datos internas. Xft pone parte de esa información a disposición de la aplicación a través de funciones.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y devuelve verdadero si Xft determinó que la pantalla admite la extensión X Render, y si puede encontrar un XRenderPictFormat adecuado (el tipo de datos de X Render, análogo al Visual de Xlib) en la pantalla.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y establece el patrón de Fontconfig que contiene las propiedades predeterminadas que Xft utilizará para esta pantalla.

Xft utiliza esas propiedades inicialmente para obtener estos límites:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). Esta es la cantidad máxima de memoria de glifos para todas las fuentes utilizadas por Xft (predeterminado: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). Este es el número máximo de fuentes no referenciadas (predeterminado: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). Cuando es verdadero, Xft rastrea el uso de memoria de glifos para mejorar el rendimiento al decidir cuáles descargar cuando se alcanza la cantidad máxima de memoria de glifos (predeterminado: falso).
Xft también utiliza estas propiedades predeterminadas en XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft completa las propiedades que faltan en el pattern proporcionado utilizando las propiedades predeterminadas para la pantalla especificada dpy, por ejemplo, como se establece en XftDefaultSet().

Las aplicaciones Xft típicas utilizan esta función para ayudar a Fontconfig a elegir una fuente adecuada. Estas propiedades se sustituyen antes de llamar a FcDefaultSubstitute():
FC_ANTIALIAS
Verdadero si FreeType debe usar anti-aliasing (predeterminado: Falso). (predeterminado: Verdadero).
FC_AUTOHINT
Verdadero si FreeType debe usar autohinting (predeterminado: Falso).
FC_DPI
Puntos por pulgada utilizados para la resolución (predeterminado: calculado a partir de la altura de la pantalla).
FC_EMBOLDEN
Verdadero si FT_GlyphSlot_Embolden() debe usarse para poner en negrita una fuente (predeterminado: Falso).
FC_HINTING
Verdadero si se debe usar hinting al completar propiedades para abrir una fuente (predeterminado: Verdadero).
FC_HINT_STYLE
Estilo de hinting utilizado al completar propiedades para abrir una fuente (predeterminado: FC_HINT_FULL).
FC_LCD_FILTER
Parámetro pasado a FT_Library_SetLcdFilter() al cargar glifos (predeterminado: FC_LCD_DEFAULT).
FC_MINSPACE
Valor mínimo de espacio utilizado al completar propiedades para abrir una fuente (predeterminado: Falso).
FC_RGBA
Valor RGBA utilizado al completar propiedades para abrir una fuente (predeterminado: calculado llamando a XRenderQuerySubpixelOrder()).
FC_SCALE
Escala utilizada en Fontconfig (predeterminado: 1.0).
XFT_MAX_GLYPH_MEMORY
Memoria máxima para una fuente (predeterminado: 1024*1024).
XFT_RENDER
Verdadero si la pantalla admite la extensión X Render (predeterminado: resultado de XftDefaultHasRender()).

Abrir y emparejar fuentes



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen toma una lista de triplas de elementos de patrón
        de la forma campo, tipo, valor (terminada con NULL),
        empareja ese patrón con las fuentes disponibles, y abre la fuente coincidente,
        dimensionándola correctamente para la pantalla número screen en la
        pantalla dpy. Devuelve la fuente coincidente, o NULL si no se encuentra
        ninguna coincidencia.

  




Ejemplo:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
Esto abre la fuente “charter” a 12 puntos. El tamaño en puntos
      se convierte automáticamente al tamaño de píxel correcto según la resolución
      del monitor.

    anchura requeridas para mostrar una cadena de texto. Después de tener en
    cuenta el offset, en casos donde la cadena se desplazará hacia arriba,
    abajo, izquierda o derecha, estos números se denominan extremos de
    texto.

Administración   de XftColor



  
Bool XftColorAllocName (

  

    
	Display	*dpy,
	_Xconst Visual	*visual,
	Colormap	 cmap,
	_Xconst char	*name,
	XftColor	*result);


    
Utiliza XAllocNamedColor() para buscar el color con
        nombre name para la pantalla asociada con el mapa de colores
        cmap.

  






    
  
  • Si XAllocNamedColor() devuelve un valor distinto de cero,
      XftColorAllocName() rellena el campo de píxel XftColor
      resultante con el color más cercano admitido por la pantalla, así como
      los campos exactos de rojo, verde y azul de la base de datos, y devuelve
      True.
    • 
  
  • Si XAllocNamedColor() devuelve cero, XftColorAllocName()
      devuelve False y no actualiza el XftColor al que se hace referencia
      en result.
    • 






  

  
El parámetro visual no se utiliza.





  
Bool XftColorAllocValue (

  

    
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);


    
Asigna un valor de color:

  






    
  
  • Si la clase visual es TrueColor, XftColorAllocValue() establece
      el campo pixel en el XftColor al que se hace referencia en
      result utilizando los campos rojo, verde y azul del parámetro
      color.
    • 
  
  • Si la clase visual no es TrueColor, XftColorAllocValue()
      llama a XAllocColor() para asignar una entrada en el mapa de colores
      cmap, que devuelve el valor de píxel del color más cercano a los
      elementos RGB especificados admitidos por el hardware.
    • 




  

  
Si XAllocColor() tiene éxito, XftColorAllocValue() almacena
      ese valor de píxel en el XRenderColor al que se hace referencia en
      result y devuelve True.

  

  
Si XAllocColor() falla, XftColorAllocValue() devuelve False
      y no modifica el resultado.

Bool XftDrawSetClip (

  

    
	XftDraw	*draw,
	Region	 r);


    
Configura el recorte para el parámetro XftDraw dado
        draw comenzando con una Region:

  






    
  
  • Si el parámetro Region r no es nulo, Xft crea una
      nueva Region (para copiar el parámetro),
    • 
  
  • Xft destruye cualquier región de recorte existente.
    • 
  
  • Xft establece el tipo de recorte (clip_type) para el parámetro
      draw a XftClipTypeRegion si el parámetro r no era
      nulo. De lo contrario, establece el tipo de recorte a
      XftClipTypeNone.
    • 
  
  • Finalmente, Xft actualiza el recorte para los objetos existentes,
      actualiza la máscara de recorte (clip_mask) para su objeto Picture de X
      Render y establece la máscara de recorte en el contexto gráfico (GC)
      asociado con el parámetro XftDraw.
    • 






  

  
XftDrawSetClip() devuelve True si no se necesitó ningún cambio,
      o si la operación tuvo éxito. Devuelve False si no pudo crear la
      nueva Region().

	XftDraw	*draw,
	int	 mode);


    
Establece el modo de subventana para el parámetro XftDraw
        dado draw. El modo puede ser ClipByChildren (el valor

void XftDrawGlyphFontSpec (

  

    
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Dibuja una lista de glifos asociados con fuentes en coordenadas
        especificadas, pasados como un array de len estructuras
        XftGlyphFontSpec a través del parámetro glyphs. Todos los
        glifos se dibujan usando el color especificado en el parámetro
        color.

  





  

  
Para cada entrada en el array glyphs:






    
  
  • Si la fuente asociada utiliza la extensión X Render, entonces Xft
      utiliza XftGlyphFontSpecRender() para dibujar el glifo, usando una
      Picture obtenida al llamar a XftDrawSrcPicture() con los
      parámetros draw y color.
    • 
  
  • De lo contrario, Xft proporciona una característica análoga usando
      Xlib.
    • 






  
void XftGlyphFontSpecRender (

  

    
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
Esto implica varios pasos:

  






    
  
  • Primero, Xft asegura que el array glyphs esté completo
      usando XftFontCheckGlyph() y cargando cualquier glifo faltante con
      XftFontLoadGlyphs().
    • 
  
  • Luego Xft examina los glifos para encontrar el valor Unicode
      máximo. Eso determina el tamaño de la codificación, es decir, el
      width.
    • 
  
  • Luego, para cada glifo, Xft verifica si su valor Unicode es manejado
      por la fuente correspondiente. Si no, el valor se establece en cero (0),
      para ignorarlo. Mientras hace esto, Xft también recuerda cuál fue
      la primera fuente utilizada y calcula la posición en la que se dibujará
      cada glifo.
    • 
  
  • Xft luego construye un array equivalente de glifos en el formato
      esperado por la biblioteca X Render.
    • 
  
  • Finalmente, XftGlyphFontSpecRender() utiliza la extensión X
      Render para dibujar los glifos, con la función
      XRenderCompositeText*() apropiada según el width, y descarta
      los datos temporales.
    • 




  

  
Los parámetros op, dst, src, srcx, y srcy
      se utilizan como se describe en la documentación de la biblioteca X
      Render.

DESCRIPTION


The Xft library provides an interface to FreeType 2 fonts
    with X Rendering Extension (Xft) support. It uses Fontconfig to match fonts
    from a user-specified pattern and renders them using X Render extension
    primitives.




Font opening



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	FcPattern	*pat);


    
Opens a font matching the given Fontconfig pattern pat
        for the display dpy. This function searches for the best matching
        font and returns a handle to it. The returned font must be closed with
        XftFontClose().

  

  
void XftFontClose (

  

    
	Display	*dpy,
	XftFont	*pub);


    
Closes the font pub for the display dpy. This
        function decrements the font's reference count. If the count reaches
        zero, the font is freed.

  

  
XftFont *XftFontMatch (

  

    
	Display	*dpy,
	FcPattern	*pat);


    
Finds the best matching font for the pattern pat on
        display dpy, but does not open it. Returns the matching pattern.
        The caller is responsible for freeing the returned pattern using
        FcPatternDestroy().

  

  
XftFont *XftFontOpenName (

  

    
	Display	*dpy,
	const char	*name);


    
Opens a font specified by the string name. This is a
        convenience function that first calls XftNameParse() to create
        a pattern from the string, then calls XftFontOpen() with that
        pattern.

  

  
XftFont *XftFontOpenBDF (

Font name parsing



  
FcPattern *XftNameParse (

  

    
	const char	*name);


    
Parses the font name string name into a Fontconfig
        pattern. This pattern can then be used with XftFontOpen() or
        other Fontconfig functions. The caller is responsible for freeing the
        returned pattern using FcPatternDestroy().

  

  
FcBool XftNameUnparse (

  

    
	FcPattern	*pat,
	char	*dest,
	int	 len);


    
Converts the Fontconfig pattern pat back into a string
        representation. The resulting string is stored in the buffer pointed to
        by dest, which must have a size of at least len bytes. If
        the string fits in the buffer, FcTrue is returned; otherwise,
        FcFalse is returned and the buffer is not modified.

  








Manipulating   Font data



  
void XftFontLoadGlyphs (

  

    
	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


    
Loads glyphs for the given font. glyphs is an array of
        glyph indices (typically Unicode values), and nglyph is the
        number of glyphs in the array. If need_bitmaps is FcTrue,
        bitmap representations of the glyphs will also be loaded. This function
        uses FreeType 2 to load the glyphs and adds them to the X Render extension
        glyph cache.

  

  
void XftFontUnloadGlyphs (

  

    
	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


    
Unloads glyphs previously loaded with XftFontLoadGlyphs().
        glyphs is an array of glyph indices, and nglyph is the
        number of glyphs in the array. This function removes the glyphs from the
        X Render extension glyph cache.

  

  
FT_Face XftLockFace (

  

    
	XftFont	*pub);


    
Increments the reference count for the FreeType 2 face associated
        with the font pub. If no face has been created yet, it is created
        using FT_New_Face(). This function should be used when accessing
        the underlying FreeType 2 face directly. The returned FT_Face
        handle is valid as long as the font is open and the face is locked.

  

  
void XftUnlockFace (

  

    
	XftFont	*pub);


    
Decrements the reference count for the FreeType 2 face associated
        with the font pub. If the reference count drops to zero, the FreeType
        2 face is destroyed using FT_Done_Face().

  










DEBUGGING


The behavior of Xft can be modified by setting the
    XFT_DEBUG environment variable. This variable should be set to an
    integer value, where each bit in the value enables a different debugging
    output:



  
1

  
Print information about font opening.

  
2

  
Print verbose information about font matching and opening.

  
4

  
Print details about the XRenderPictFormat being used.

  
8

  
Print the string that XftDrawString8() is drawing.

  
16

  
Print which font IDs are matched.

  
32

  
Print useful information about the glyphs that will be drawn.

  
64

  
Print an ASCII-art representation of the glyphs.

  
128

  
Print details about memory cache management.

  
256

  
Print details about glyph cache memory management.

  
512

  
Print a report on memory usage.

  
1024

  
Print details on extended glyph cache memory management.








COMPATIBILITY


Xft provides a compatibility layer for applications written
    against older versions of the library. The primary compatibility interface is
    defined in the <X11/Xft/XftCompat.h> header file.




Xft   1.x Data Types



  
XftPattern

  
Represents a set of font properties. Used for matching fonts and storing
      font information.

  
XftFontSet

  
A collection of XftPattern objects, typically used to represent a
      list of matching fonts.

  
XftObjectSet

  
Used to specify which font properties to retrieve when listing fonts.
