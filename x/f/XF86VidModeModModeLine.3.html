ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen
Especifica a qué número de pantalla se aplican los ajustes.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de video disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo; de lo contrario, cambia al modo anterior.
lock
Indica que el cambio de modo debe bloquearse, si no es cero.
modeline
Especifica o devuelve los valores de temporización para un modo de video.
aftermode
Especifica los valores de temporización para el modo de video después del cual se agregará el nuevo modo.
modesinfo
Devuelve los valores de temporización y los relojes de puntos (dotclocks) para todos los modos de video disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para el viewport.
x_return
Devuelve la ubicación X actual del viewport.
y
Especifica la ubicación Y deseada para el viewport.
y_return
Devuelve la ubicación Y actual del viewport.

DESCRIPCIÓN

La biblioteca XF86VidMode proporciona una interfaz para la extensión XFree86-VidMode. Esta extensión permite a los clientes controlar los modos de visualización, incluidos los relojes de puntos, los modos de línea de video y la configuración de gamma.

Las funciones de esta biblioteca se dividen en las siguientes categorías:

Consulta de la extensión y su versión
XF86VidModeQueryExtension() se utiliza para determinar si la extensión XF86VidMode está disponible en el servidor X. Devuelve los números base del evento y del error si la extensión está disponible.
XF86VidModeQueryVersion() se utiliza para determinar la versión de la extensión XF86VidMode que está implementada en el servidor X.
XF86VidModeSetClientVersion() informa al servidor X de la versión de la extensión con la que el cliente está compilado. Esto es necesario para que el servidor X pueda devolver errores o eventos compatibles con versiones anteriores.
Manipulación de la línea de modo
XF86VidModeGetModeLine() recupera la línea de modo actual para una pantalla especificada.
XF86VidModeGetAllModeLines() recupera todas las líneas de modo configuradas actualmente para una pantalla especificada.
XF86VidModeAddModeLine() agrega una nueva línea de modo a la lista de modos disponibles para una pantalla especificada. La nueva línea de modo se inserta después de la línea de modo especificada por aftermode.
XF86VidModeDeleteModeLine() elimina una línea de modo especificada de la lista de modos disponibles para una pantalla especificada.
XF86VidModeModModeLine() modifica la línea de modo actual para una pantalla especificada.
XF86VidModeValidateModeLine() valida una línea de modo especificada para determinar si es compatible con el hardware de pantalla actual.
Cambio de modo y manipulación del viewport
XF86VidModeSwitchMode() cambia al siguiente o anterior modo de video disponible en la pantalla especificada.
XF86VidModeSwitchToMode() cambia a una línea de modo específica en la pantalla especificada.
XF86VidModeLockModeSwitch() bloquea o desbloquea la capacidad de cambiar de modo en la pantalla especificada.
XF86VidModeGetViewPort() recupera la posición actual del viewport en la pantalla especificada.
XF86VidModeSetViewPort() establece la posición del viewport en la pantalla especificada.
Información del monitor y del reloj de puntos
XF86VidModeGetMonitor() recupera información sobre el monitor conectado a la pantalla especificada.
XF86VidModeGetDotClocks() recupera información sobre los relojes de puntos disponibles para la pantalla especificada, incluido el número de relojes y el reloj de puntos máximo.
Control de gamma
XF86VidModeGetGamma() recupera la configuración de gamma actual para la pantalla especificada.
XF86VidModeSetGamma() establece la configuración de gamma para la pantalla especificada.
XF86VidModeGetGammaRamp() recupera la rampa de gamma actual para la pantalla especificada. La rampa de gamma se devuelve como tres arreglos de valores de 16 bits sin signo para rojo, verde y azul.
XF86VidModeSetGammaRamp() establece la rampa de gamma para la pantalla especificada. Se deben proporcionar los tres arreglos de valores de 16 bits sin signo.
XF86VidModeGetGammaRampSize() recupera el tamaño de la rampa de gamma para la pantalla especificada.

DEVOLUCIÓN DE VALORES

Todas las funciones que devuelven un Bool devuelven True si tienen éxito y False si fallan. Las funciones que devuelven un Status devuelven True si tienen éxito y False si fallan. Las funciones que devuelven punteros a estructuras o arreglos los asignarán y el llamador es responsable de liberarlos usando Xfree().

EVENTOS

La extensión XF86VidMode genera los siguientes eventos:

XF86VidModeScreenDirectSaveEvent
Se genera cuando el servidor X cambia directamente a un modo de pantalla diferente.
XF86VidModeScreenSyncEvent
Se genera cuando el servidor X ha cambiado el modo de pantalla y está listo para que el cliente sincronice su estado.

ERRORES

La extensión XF86VidMode define los siguientes errores:

XF86VidModeBadClock
Se genera cuando se proporciona un valor de reloj de puntos no válido.
XF86VidModeBadName
Se genera cuando se proporciona un nombre de modo no válido.
XF86VidModeBadTime
Se genera cuando se proporciona una marca de tiempo no válida.
XF86VidModeBusy
Se genera cuando la operación solicitada no se puede completar porque el hardware está ocupado.
XF86VidModeModeUnsuitable
Se genera cuando el modo solicitado no es adecuado para el hardware de pantalla actual.
XF86VidModePermissions
Se genera cuando el cliente no tiene los permisos necesarios para realizar la operación solicitada.

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la extensión del servidor XFree86-VidModeExtension que permite consultar y ajustar dinámicamente los modos de video y controlar el cambio de modos. Las aplicaciones que utilizan estas funciones deben enlazarse con -lXxf86vm.

FUNCIONES DE MODELINE

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de video actualmente seleccionado. El programa llamante debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si hay valores privados del servidor (actualmente solo aplicables al servidor S3), la función asignará almacenamiento para ellos. Por lo tanto, si el campo privsize no es cero, el programa llamante debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de video. El programa llamante proporciona la dirección de un puntero que será establecido por la función para apuntar a una matriz de estructuras XF86VidModeModeInfo. La memoria ocupada por la matriz es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamante. El primer elemento de la matriz corresponde al modo de video actual.

La función XF86VidModeModModeLine se puede utilizar para cambiar la configuración del modo de video actual, siempre que la configuración solicitada sea válida (por ejemplo, que no exceda las capacidades del monitor).

Para añadir un modo a la lista de modos disponibles, se puede utilizar la función XF86VidModeAddModeLine. Suponiendo que la configuración sea válida, el modo de video se añadirá después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para que se considere una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se añadirá después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para que se considere una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero ocurrirá un cambio de modo al siguiente modo. El último modo restante no se puede eliminar.

La validez de un modo se puede comprobar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser utilizado por el servidor (es decir, cumple todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario devuelve un valor que indica la razón por la que el modo es inválido (según se define en xf86.h).

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de video al siguiente (o anterior) modo de video. La función XF86VidModeSwitchToMode se puede utilizar para cambiar directamente al modo especificado. La coincidencia se especifica como se describe en la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch se puede utilizar para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, se necesita una llamada a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado del estado de ejecución de la solicitud, se debe instalar un manejador de errores personalizado utilizando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información que el servidor conoce sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a una matriz de estructuras XF86VidModeSyncRange. Las matrices contienen nhsync y nvsync elementos, respectivamente. Los valores hi y lo serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamante.

FUNCIONES DE VISOR

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort se pueden utilizar para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda del visor en la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion se puede utilizar para determinar la versión de la extensión integrada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores más bajos de error y evento asignados a la extensión.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulte el código fuente para obtener información sobre cómo utilizarlas.
