ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen
Especifica a qué número de pantalla se aplican las configuraciones.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de video disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo; de lo contrario, cambia al modo anterior.
lock
Indica que el cambio de modo debe bloquearse, si no es cero.
modeline
Especifica o devuelve los valores de temporización para un modo de video.
aftermode
Especifica los valores de temporización para el modo de video después del cual se añadirá el nuevo modo.
modesinfo
Devuelve los valores de temporización y los dotclocks para todos los modos de video disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para el viewport.
x_return
Devuelve la ubicación X actual del viewport.
y
Especifica la ubicación Y deseada para el viewport.
y_return
Devuelve la ubicación Y actual del viewport.

DESCRIPCIÓN

The XFree86-VidMode extension provides mechanisms for querying and setting video modes, including timings, dot clocks, gamma, and viewport settings. It also allows for locking mode switches and querying monitor capabilities.

DETALLES

Querying Extension and Version:

XF86VidModeQueryExtension
Checks if the XFree86-VidMode extension is available and retrieves its event and error base numbers.
XF86VidModeQueryVersion
Retrieves the major and minor version numbers of the extension supported by the server.
XF86VidModeSetClientVersion
Sets the client's version for the extension. This should typically be called after querying the version.

Mode Line Operations:

XF86VidModeGetModeLine
Retrieves the current mode line for a given screen.
XF86VidModeGetAllModeLines
Retrieves all available mode lines for a given screen, along with their dot clocks.
XF86VidModeAddModeLine
Adds a new mode line to the server's list of available modes. The aftermode argument specifies where in the list the new mode should be inserted.
XF86VidModeDeleteModeLine
Deletes a mode line from the server's list.
XF86VidModeModModeLine
Modifies the current mode line for a screen.
XF86VidModeValidateModeLine
Validates a given mode line to check if it's acceptable by the server.

Mode Switching:

XF86VidModeSwitchMode
Switches to the next or previous video mode based on the zoom argument.
XF86VidModeSwitchToMode
Switches directly to a specified video mode.
XF86VidModeLockModeSwitch
Locks or unlocks the ability to switch video modes. If lock is non-zero, mode switching is locked.

Monitor and Viewport Information:

XF86VidModeGetMonitor
Retrieves information about the connected monitor, including its vendor, model, and supported horizontal and vertical sync ranges.
XF86VidModeGetViewPort
Retrieves the current position of the viewport on the screen.
XF86VidModeSetViewPort
Sets the position of the viewport to the specified coordinates.

Dot Clock Information:

XF86VidModeGetDotClocks
Retrieves information about the available dot clocks for a screen, including flags, the number of clocks, the maximum dot clock value, and an array of the clock values.

Gamma Settings:

XF86VidModeGetGamma
Retrieves the current gamma correction values (red, green, blue) for a screen.
XF86VidModeSetGamma
Sets the gamma correction values for a screen.
XF86VidModeGetGammaRamp
Retrieves the gamma lookup tables (red, green, blue) for a screen. The size argument specifies the number of entries in the lookup tables.
XF86VidModeSetGammaRamp
Sets the gamma lookup tables for a screen.
XF86VidModeGetGammaRampSize
Retrieves the size of the gamma lookup tables supported by the screen.

Permissions:

XF86VidModeGetPermissions
This function is declared but not defined in the header. Its purpose is likely to query permissions related to video mode operations.

VÉA TAMBIÉN

X(7), XFree86-VidMode(7)

DESCRIPCIÓN

Estas funciones proporcionan una interfaz para la extensión del servidor XFree86-VidModeExtension que permite consultar y ajustar dinámicamente los modos de vídeo y controlar el cambio de modo. Las aplicaciones que utilizan estas funciones deben enlazarse con -lXxf86vm

FUNCIONES DE MODELINE

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de vídeo seleccionado actualmente. El programa que llama debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si hay algún valor privado del servidor (actualmente solo aplicable al servidor S3) la función asignará almacenamiento para él. Por lo tanto, si el campo privsize no es cero, el programa que llama debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de vídeo. El programa que llama proporciona la dirección de un puntero que será establecido por la función para apuntar a una matriz de estructuras XF86VidModeModeInfo. La memoria ocupada por la matriz es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamante. El primer elemento de la matriz corresponde al modo de vídeo actual.

La función XF86VidModeModModeLine puede ser utilizada para cambiar la configuración del modo de vídeo actual, siempre que la configuración solicitada sea válida (por ejemplo, que no exceda las capacidades del monitor).

Para añadir un modo a la lista de modos disponibles, se puede utilizar la función XF86VidModeAddModeLine. Suponiendo que la configuración es válida, el modo de vídeo se añadirá después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se añadirá después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero se producirá un cambio de modo al siguiente modo. El último modo restante no puede ser eliminado.

La validez de un modo se puede comprobar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser utilizado por el servidor (es decir, cumple todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario devuelve un valor que indica la razón por la que el modo no es válido (según se define en xf86.h)

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de vídeo al siguiente (o anterior) modo de vídeo. La función XF86VidModeSwitchToMode puede ser utilizada para cambiar directamente al modo especificado. La coincidencia se especifica en la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch puede ser utilizada para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, es necesario llamar a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado del estado de ejecución de la solicitud, se debe instalar un gestor de errores personalizado utilizando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información que el servidor conoce sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a una matriz de estructuras XF86VidModeSyncRange. Las matrices contienen nhsync y nvsync elementos, respectivamente. Los valores hi y low serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync, y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamante.

FUNCIONES DE PANTALLA VIRTUAL

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort pueden ser utilizadas para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda de la pantalla virtual dentro de la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion puede ser utilizada para determinar la versión de la extensión incorporada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores de error y evento de menor número asignados a la extensión.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize, y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulte el código fuente para obtener información sobre cómo utilizarlas.
