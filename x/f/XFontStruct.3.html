XLoadFont(3) FUNCIONES DE XLIB XLoadFont(3)

NOMBRE

XLoadFont, XQueryFont, XLoadQueryFont, XFreeFont, XGetFontProperty, XUnloadFont, XCharStruct, XFontProp, XChar2b, XFontStruct - cargar o descargar fuentes y estructuras de métricas de fuentes

SINTAXIS

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

ARGUMENTOS

atom
Especifica el átomo para el nombre de la propiedad que desea obtener.
display
Especifica la conexión al servidor X.
font
Especifica la fuente.
font_ID
Especifica el ID de la fuente o el ID de GContext.
font_struct
Especifica el almacenamiento asociado a la fuente.
gc
Especifica el GC.
name
Especifica el nombre de la fuente, que es una cadena terminada en nulo.
value_return
Devuelve el valor de la propiedad de la fuente.

DESCRIPCION

La función XLoadFont carga la fuente especificada y devuelve su ID de fuente asociado. Si el nombre de la fuente no está en la Codificación de Caracteres Portátil del Host, el resultado depende de la implementación. El uso de mayúsculas o minúsculas no importa. Cuando los caracteres “?” y “*” se utilizan en un nombre de fuente, se realiza una coincidencia de patrón y se utiliza cualquier fuente coincidente. En el patrón, el carácter “?” coincidirá con cualquier carácter individual, y el carácter “*” coincidirá con cualquier número de caracteres. El formato estructurado para los nombres de fuente se especifica en las convenciones de descripción de fuentes lógicas X del estándar del Consorcio X. Si XLoadFont no tuvo éxito al cargar la fuente especificada, se produce un error BadName. Las fuentes no están asociadas con una pantalla particular y pueden almacenarse como un componente de cualquier GC. Cuando la fuente ya no es necesaria, llame a XUnloadFont.

XLoadFont puede generar errores BadAlloc y BadName.

La función XQueryFont devuelve un puntero a la estructura XFontStruct, que contiene información asociada con la fuente. Puede consultar una fuente o la fuente almacenada en un GC. El ID de fuente almacenado en la estructura XFontStruct será el ID de GContext, y debe tener cuidado al usar este ID en otras funciones (ver XGContextFromGC). Si la fuente no existe, XQueryFont devuelve NULL. Para liberar estos datos, use XFreeFontInfo.

XLoadQueryFont puede generar un error BadAlloc.

La función XLoadQueryFont proporciona la forma más común de acceder a una fuente. XLoadQueryFont abre (carga) la fuente especificada y devuelve un puntero a la estructura XFontStruct adecuada. Si el nombre de la fuente no está en la Codificación de Caracteres Portátil del Host, el resultado depende de la implementación. Si la fuente no existe, XLoadQueryFont devuelve NULL.

La función XFreeFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada, y libera la estructura XFontStruct. La fuente en sí se liberará cuando ningún otro recurso la referencie. Los datos y la fuente no deben volver a consultarse.

XFreeFont puede generar un error BadFont.

Dado el átomo para esa propiedad, la función XGetFontProperty devuelve el valor de la propiedad de fuente especificada. XGetFontProperty también devuelve False si la propiedad no se definió o True si se definió. Existe un conjunto de átomos predefinidos para las propiedades de fuente, que se pueden encontrar en X11/Xatom.h. Este conjunto contiene las propiedades estándar asociadas con una fuente. Aunque no está garantizado, es probable que las propiedades de fuente predefinidas estén presentes.

La función XUnloadFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada. La fuente en sí se liberará cuando ningún otro recurso la referencie. La fuente no debe volver a consultarse.

XUnloadFont puede generar un error BadFont.

ESTRUCTURAS

La estructura XFontStruct contiene toda la información de la fuente y consta de la información específica de la fuente, así como un puntero a una matriz de estructuras XCharStruct para los caracteres contenidos en la fuente. Las estructuras XFontStruct, XFontProp y XCharStruct contienen:

typedef struct {
	short lbearing;	/* origen al borde izquierdo del raster */
	short rbearing;	/* origen al borde derecho del raster */
	short width;	/* avance al origen del siguiente carácter */
	short ascent;	/* línea base al borde superior del raster */
	short descent;	/* línea base al borde inferior del raster */
	unsigned short attributes;	/* flags por carácter (no predefinidos) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* los caracteres normales de 16 bits son dos bytes */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* hook para que la extensión cuelgue datos */
	Font fid;	/* ID de fuente para esta fuente */
	unsigned direction;	/* indicación sobre la dirección en la que se pinta la fuente */
	unsigned min_char_or_byte2;	/* primer carácter */
	unsigned max_char_or_byte2;	/* último carácter */
	unsigned min_byte1;	/* primera fila que existe */
	unsigned max_byte1;	/* última fila que existe */
	Bool all_chars_exist;	/* flag si todos los caracteres tienen tamaño distinto de cero */
	unsigned default_char;	/* carácter a imprimir para carácter indefinido */
	int n_properties;	/* cuántas propiedades hay */
	XFontProp *properties;	/* puntero a la matriz de propiedades adicionales */
	XCharStruct min_bounds;	/* límites mínimos sobre todos los caracteres existentes */
	XCharStruct max_bounds;	/* límites máximos sobre todos los caracteres existentes */
	XCharStruct *per_char;	/* información del primer carácter al último */
	int ascent;	/* extensión lógica por encima de la línea base para espaciado */
	int descent;	/* extensión lógica por debajo de la línea base para espaciado */
} XFontStruct;

X admite operaciones de texto de un solo byte/carácter, matriz de dos bytes/carácter y carácter de 16 bits. Tenga en cuenta que cualquiera de estas formas se puede usar con una fuente, pero una solicitud de texto de un solo byte/carácter solo puede especificar un solo byte (es decir, la primera fila de una fuente de 2 bytes). Debe considerar las fuentes de 2 bytes como una matriz bidimensional de caracteres definidos: byte1 especifica el rango de filas definidas y byte2 define el rango de columnas definidas de la fuente. Las fuentes de un solo byte/carácter tienen una fila definida, y el rango de byte2 especificado en la estructura define un rango de caracteres.

El cuadro delimitador de un carácter se define mediante la estructura XCharStruct de ese carácter. Cuando faltan caracteres en una fuente, se utiliza el `default_char`. Cuando las fuentes tienen todos los caracteres del mismo tamaño, solo se utilizan las información de los límites mínimo y máximo de XFontStruct.

Los miembros de XFontStruct tienen la siguiente semántica:

  • El miembro `direction` puede ser FontLeftToRight o FontRightToLeft. Es solo una indicación de si la mayoría de los elementos XCharStruct tienen una métrica de ancho de carácter positiva (FontLeftToRight) o negativa (FontRightToLeft). El protocolo principal no define soporte para texto vertical.
  • Si los miembros `min_byte1` y `max_byte1` son ambos cero, `min_char_or_byte2` especifica el índice lineal del carácter correspondiente al primer elemento de la matriz `per_char`, y `max_char_or_byte2` especifica el índice lineal del carácter del último elemento.
Si `min_byte1` o `max_byte1` no son cero, ambos `min_char_or_byte2` y `max_char_or_byte2` son menores que 256, y los valores del índice de carácter de 2 bytes correspondientes al elemento N de la matriz `per_char` (contando desde 0) son:
byte1 = N/D + min_byte1
byte2 = N%D + min_char_or_byte2
donde: 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = división entera
        % = módulo
(Nota: En la versión original, la división entera y el módulo se representaron con "/" y "%" respectivamente.)

XFontStruct - estructura de información de fuentes

typedef struct {

ARGUMENTOS

min_bounds

Especifica los límites más pequeños (mínimos) en los que se dibuja cualquier carácter de la fuente.

max_bounds

Especifica los límites más grandes (máximos) en los que se dibuja cualquier carácter de la fuente.

min_char_offset

Especifica el desplazamiento de la primera entrada de carácter válida en la matriz de caracteres de la fuente.

max_char_offset

Especifica el desplazamiento de la última entrada de carácter válida en la matriz de caracteres de la fuente.

default_char

Especifica el carácter que se utilizará cuando se imprima un carácter no definido o inexistente.

direction

Especifica la dirección de escritura (izquierda a derecha o derecha a izquierda) para la fuente.

min_left_ink

Especifica la tinta izquierda mínima (el valor más pequeño del margen izquierdo) para cualquier carácter de la fuente.

min_right_ink

Especifica la tinta derecha mínima (el valor más pequeño del margen derecho) para cualquier carácter de la fuente.

min_bottom_ink

Especifica la tinta inferior mínima (el valor más pequeño del descenso) para cualquier carácter de la fuente.

min_top_ink

Especifica la tinta superior mínima (el valor más pequeño del ascenso) para cualquier carácter de la fuente.

ncount

Especifica el número de entradas de la matriz de caracteres descritas por per_char y reply.

per_char

Puntero a una matriz de estructuras XCharStruct que contienen la información de límites para cada carácter de la fuente.

reply

Puntero a una estructura XCharStruct que contiene la información de límites para caracteres que no se especifican explícitamente en la matriz per_char.

DESCRIPCIÓN

La estructura XFontStruct contiene información sobre una fuente X. Se utiliza para obtener información sobre las dimensiones de los caracteres, el espaciado y otros atributos de la fuente.

min_bounds
Contiene los valores mínimos de lbearing, right, ascent y descent de todos los caracteres de la fuente.
max_bounds
Contiene los valores máximos de lbearing, right, ascent y descent de todos los caracteres de la fuente.
min_char_offset
Es el desplazamiento del primer carácter válido en la matriz de caracteres de la fuente. Se utiliza para indexar en la matriz per_char.
max_char_offset
Es el desplazamiento del último carácter válido en la matriz de caracteres de la fuente. Se utiliza para indexar en la matriz per_char.
default_char
Especifica el carácter que se utilizará cuando se imprima un carácter no definido o inexistente. El carácter default_char es un carácter de 16 bits (no un carácter de 2 bytes). Para una fuente que utiliza el formato de matriz de 2 bytes, el default_char tiene byte1 en el byte más significativo y byte2 en el byte menos significativo. Si el default_char en sí especifica un carácter no definido o inexistente, no se realiza ninguna impresión para un carácter no definido o inexistente.
direction
Especifica la dirección de escritura de la fuente. Puede ser False (de izquierda a derecha) o True (de derecha a izquierda).
min_left_ink
La extensión izquierda mínima de la tinta de cualquier carácter de la fuente desde el origen.
min_right_ink
La extensión derecha mínima de la tinta de cualquier carácter de la fuente desde el origen.
min_bottom_ink
La extensión inferior mínima de la tinta de cualquier carácter de la fuente desde el origen (descenso).
min_top_ink
La extensión superior mínima de la tinta de cualquier carácter de la fuente desde el origen (ascenso).
ncount
El número de caracteres descritos por per_char.
per_char
Puntero a una matriz de estructuras XCharStruct que contienen los límites para cada carácter de la fuente. Si per_char es NULL, todos los glifos entre los índices de carácter primero y último inclusive tienen la misma información, según lo dado por min_bounds y max_bounds.
noverall
El número total de caracteres en la fuente.
context
El contexto de la fuente (utilizado internamente por Xlib).
reply
Puntero a una estructura XCharStruct que contiene los límites para los caracteres que no se especifican explícitamente en la matriz per_char. Si all_chars_exist es True, todos los caracteres en la matriz per_char tienen cuadros de límites distintos de cero.

ESTRUCTURAS

La estructura XCharStruct define el cuadro de límites de un carácter individual y su espaciado.

typedef struct {
    short lbearing;
    short rbearing;
    short width;
    short ascent;
    short descent;
    unsigned int attributes; /* Currently unused */
} XCharStruct;
  • lbearing: La extensión del borde izquierdo de la tinta del carácter desde el origen.
  • rbearing: La extensión del borde derecho de la tinta del carácter desde el origen.
  • width: El ancho lógico del carácter. Este es el valor que se usa para avanzar el origen del cursor para el siguiente carácter.
  • ascent: La extensión superior del carácter desde la línea base.
  • descent: La extensión inferior del carácter desde la línea base.
  • attributes: Atributos adicionales del carácter (actualmente no utilizado).

Los campos min_bounds y max_bounds de XFontStruct contienen los valores más extremos de cada componente individual de XCharStruct sobre todos los elementos de esta matriz (e ignoran los caracteres inexistentes). El cuadro de límites de la fuente (el rectángulo más pequeño que encierra la forma obtenida al superponer todos los caracteres en el mismo origen [x,y]) tiene su coordenada superior izquierda en:

[x + min_bounds.lbearing, y - max_bounds.ascent]

Su ancho es:

max_bounds.rbearing - min_bounds.lbearing

Su altura es:

max_bounds.ascent + max_bounds.descent
  • El miembro ascent es la extensión lógica de la fuente por encima de la línea base que se utiliza para determinar el interlineado. Los caracteres específicos pueden extenderse más allá de esto.
  • El miembro descent es la extensión lógica de la fuente en la línea base o por debajo de ella que se utiliza para determinar el interlineado. Los caracteres específicos pueden extenderse más allá de esto.
  • Si la línea base está en la coordenada Y, la extensión lógica de la fuente está incluida entre los valores de la coordenada Y (y - font.ascent) y (y + font.descent - 1). Típicamente, el interlineado mínimo entre filas de texto se da por ascent + descent.

Para un origen de carácter en [x,y], el cuadro de límites de un carácter (es decir, el rectángulo más pequeño que encierra la forma del carácter) descrito en términos de los componentes de XCharStruct es un rectángulo con su esquina superior izquierda en:

[x + lbearing, y - ascent]

Su ancho es:

rbearing - lbearing

Su altura es:

ascent + descent

El origen para el siguiente carácter se define como:

[x + width, y]

El miembro lbearing define la extensión del borde izquierdo de la tinta del carácter desde el origen. El miembro rbearing define la extensión del borde derecho de la tinta del carácter desde el origen. El miembro ascent define la extensión del borde superior de la tinta del carácter desde el origen. El miembro descent define la extensión del borde inferior de la tinta del carácter desde el origen. El miembro width define el ancho lógico del carácter.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadFont
Un valor para un argumento de Font o GContext no nombra una Fuente definida.
BadName
No existe una fuente o color del nombre especificado.
