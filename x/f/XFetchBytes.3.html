XFetchBytes(3)

Paquete: libx11

Licencias: MIT AND X11

XStoreBytes(3) FUNCIONES DE XLIB XStoreBytes(3)

NOMBRE

XStoreBytes, XStoreBuffer, XFetchBytes, XFetchBuffer, XRotateBuffers - manipular búferes de copiar y pegar

SINTAXIS

int XStoreBytes(Display *display, _Xconst char *bytes, int nbytes);

int XStoreBuffer(Display *display, _Xconst char *bytes, int nbytes, int buffer);

char *XFetchBytes(Display *display, int *nbytes_return);

char *XFetchBuffer(Display *display, int *nbytes_return, int buffer);

int XRotateBuffers(Display *display, int rotate);

ARGUMENTOS

buffer
Especifica el búfer en el que desea almacenar los bytes o del cual desea obtener los datos almacenados.
bytes
Especifica los bytes, que no son necesariamente ASCII o con terminación nula.
display
Especifica la conexión con el servidor X.
nbytes
Especifica el número de bytes a almacenar.
nbytes_return
Devuelve el número de bytes en el búfer.
rotate
Especifica cuánto rotar los búferes de corte.

DESCRIPCIÓN

Los datos pueden tener caracteres nulos incrustados y no necesitan ser terminados en nulo. El contenido del búfer de corte se puede recuperar más tarde por cualquier cliente que llame a XFetchBytes.

XStoreBytes puede generar un error BadAlloc.

Si se especifica un búfer inválido, la llamada no tiene efecto. Los datos pueden tener caracteres nulos incrustados y no necesitan ser terminados en nulo.

XStoreBuffer puede generar un error BadAlloc.

La función XFetchBytes devuelve el número de bytes en el argumento nbytes_return, si el búfer contiene datos. De lo contrario, la función devuelve NULL y establece nbytes a 0. Se asignará la cantidad adecuada de almacenamiento y se devolverá el puntero. El cliente debe liberar este almacenamiento cuando haya terminado de usarlo llamando a XFree.

La función XFetchBuffer devuelve cero al argumento nbytes_return si no hay datos en el búfer o si se especifica un búfer inválido.

XFetchBuffer puede generar un error BadValue.

La función XRotateBuffers rota los búferes de corte, de modo que el búfer 0 se convierte en el búfer n, el búfer 1 se convierte en n + 1 mod 8, y así sucesivamente. Esta numeración de búferes de corte es global para la pantalla. Tenga en cuenta que XRotateBuffers genera errores BadMatch si alguno de los ocho búferes no se ha creado.

XRotateBuffers puede generar un error BadMatch.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadAtom
Un valor para un argumento Atom no nombra un Atom definido.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
