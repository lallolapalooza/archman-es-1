NOMBRE

XFilterEvent - filtrar eventos X para un método de entrada

SINTAXIS

Bool XFilterEvent(XEvent *event, Window w);

ARGUMENTOS

event
Especifica el evento a filtrar.
w
Especifica la ventana para la cual se aplicará el filtro.

DESCRIPCIÓN

Si el argumento de ventana es None, XFilterEvent aplica el filtro a la ventana especificada en la estructura XEvent. El argumento de ventana se proporciona para que las capas superiores a Xlib que realizan redirección de eventos puedan indicar a qué ventana se ha redireccionado un evento.

Si XFilterEvent devuelve True, entonces algún método de entrada ha filtrado el evento y el cliente debe descartar el evento. Si XFilterEvent devuelve False, entonces el cliente debe continuar procesando el evento.

Si se ha producido una captura en el cliente y XFilterEvent devuelve True, el cliente debe liberar la captura del teclado.
