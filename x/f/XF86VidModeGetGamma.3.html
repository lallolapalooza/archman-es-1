ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen
Especifica a qué número de pantalla se aplican los ajustes.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de video disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo; de lo contrario, al modo anterior.
lock
Indica que el cambio de modo debe bloquearse, si es distinto de cero.
modeline
Especifica o devuelve los valores de temporización para un modo de video.
aftermode
Especifica los valores de temporización para el modo de video después del cual se añadirá el nuevo modo.
modesinfo
Devuelve los valores de temporización y los dotclocks para todos los modos de video disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para el viewport.
x_return
Devuelve la ubicación X actual del viewport.
y
Especifica la ubicación Y deseada para el viewport.
y_return
Devuelve la ubicación Y actual del viewport.

DESCRIPCIÓN

La extensión XFree86-VidMode proporciona a las aplicaciones la capacidad de consultar y modificar la configuración de los modos de video (resolución, temporización, etc.).

Cuando se llama a XF86VidModeQueryExtension, verifica si la extensión está disponible en el servidor.

Si la extensión está disponible, se pueden consultar sus versiones mediante XF86VidModeQueryVersion. Se recomienda que los clientes establezcan su versión de cliente con XF86VidModeSetClientVersion.

Las funciones XF86VidModeGetModeLine y XF86VidModeGetAllModeLines devuelven la línea de modo actual o todas las líneas de modo disponibles, respectivamente. Las funciones XF86VidModeAddModeLine, XF86VidModeDeleteModeLine y XF86VidModeModModeLine se utilizan para añadir, eliminar y modificar líneas de modo, respectivamente. XF86VidModeValidateModeLine valida si una línea de modo dada es utilizable por el servidor.

Es posible cambiar el modo de video actual con XF86VidModeSwitchMode (para alternar entre modos) o XF86VidModeSwitchToMode (para ir a un modo específico). El bloqueo de cambios de modo se puede controlar con XF86VidModeLockModeSwitch.

La información del monitor y el viewport se pueden obtener con XF86VidModeGetMonitor y XF86VidModeGetViewPort, y el viewport se puede establecer con XF86VidModeSetViewPort.

Se pueden consultar los relojes de punto disponibles y el reloj máximo permitido con XF86VidModeGetDotClocks.

La configuración Gamma se puede consultar y establecer mediante XF86VidModeGetGamma y XF86VidModeSetGamma, respectivamente. Las rampas Gamma también se pueden gestionar con las funciones XF86VidModeGetGammaRamp, XF86VidModeSetGammaRamp y XF86VidModeGetGammaRampSize.

DEVOLVER VALORES

Todas las funciones de la extensión XFree86-VidMode devuelven True si la operación tuvo éxito, o False si falló.

La función XF86VidModeValidateModeLine devuelve Success si la línea de modo es válida, o un código de error específico si falla.

EJEMPLO

Obtener y establecer el gamma de una pantalla:

    Display *display = XOpenDisplay(NULL);
    if (!display) {
        fprintf(stderr, "Could not open display\n");
        exit(1);
    }

    /* Check if the extension is available */
    int event_base, error_base;
    if (!XF86VidModeQueryExtension(display, &event_base, &error_base)) {
        fprintf(stderr, "XFree86-VidMode extension not available\n");
        exit(1);
    }

    /* Get current gamma */
    XF86VidModeGamma gamma_current;
    if (!XF86VidModeGetGamma(display, 0, &gamma_current)) {
        fprintf(stderr, "Could not get gamma\n");
    } else {
        printf("Current gamma: R=%.2f G=%.2f B=%.2f\n",
               gamma_current.red, gamma_current.green, gamma_current.blue);
    }

    /* Set gamma to default (1.0, 1.0, 1.0) */
    XF86VidModeGamma gamma_new;
    gamma_new.red = gamma_new.green = gamma_new.blue = 1.0;
    if (!XF86VidModeSetGamma(display, 0, &gamma_new)) {
        fprintf(stderr, "Could not set gamma\n");
    } else {
        printf("Gamma set to default (1.0, 1.0, 1.0)\n");
    }

    XCloseDisplay(display);

    int vert-sync-margin;  /* vertical sync margin */

Esta estructura contiene la información de la configuración de una línea de modo de video.

Los campos horiz-sync-low y horiz-sync-high, vert-sync-low y vert-sync-high se usan para definir los rangos de sincronización horizontal y vertical, respectivamente. Si se especifica un valor discreto, ambos campos deben ser iguales.

Los campos x-offset y y-offset se usan para desplazar el origen de la pantalla.

El campo privsize es el tamaño de los datos privados de la línea de modo (específicos del servidor). El campo private apunta a estos datos.

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la extensión del servidor XFree86-VidModeExtension que permite consultar y ajustar los modos de video dinámicamente y controlar el cambio de modo. Las aplicaciones que utilizan estas funciones deben enlazarse con -lXxf86vm.

FUNCIONES DE LÍNEA DE MODO

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de video actualmente seleccionado. El programa que llama debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si hay algún valor privado del servidor (actualmente aplicable solo al servidor S3) la función asignará almacenamiento para ellos. Por lo tanto, si el campo privsize no es cero, el programa que llama debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de video. El programa que llama proporciona la dirección de un puntero que la función establecerá para apuntar a una matriz de estructuras XF86VidModeModeInfo. La memoria ocupada por la matriz es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamante. El primer elemento de la matriz corresponde al modo de video actual.

La función XF86VidModeModModeLine se puede usar para cambiar la configuración del modo de video actual, siempre que la configuración solicitada sea válida (por ejemplo, que no exceda las capacidades del monitor).

Para agregar un modo a la lista de modos disponibles, se puede usar la función XF86VidModeAddModeLine. Suponiendo que la configuración es válida, el modo de video se agregará después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se agregará después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero ocurrirá un cambio de modo al siguiente modo. No se puede eliminar el último modo restante.

La validez de un modo se puede verificar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser usado por el servidor (es decir, cumple con todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario devuelve un valor que indica la razón por la cual el modo es inválido (según se define en xf86.h).

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de video al siguiente (o anterior) modo de video. La función XF86VidModeSwitchToMode se puede usar para cambiar directamente al modo especificado. La coincidencia se especifica como se indica en la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch se puede usar para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode, o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, se necesita una llamada a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado del estado de ejecución de la solicitud, se debe instalar un controlador de errores personalizado usando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información conocida por el servidor sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a una matriz de estructuras XF86VidModeSyncRange. Las matrices contienen nhsync y nvsync elementos, respectivamente. Los valores hi y low serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync, y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamante.

FUNCIONES DE PUNTO DE VISTA

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort se pueden usar para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda del punto de vista en la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion se puede usar para determinar la versión de la extensión incorporada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores de error y evento de menor número asignados a la extensión.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize, y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulte el código fuente para obtener información sobre cómo usarlas.
