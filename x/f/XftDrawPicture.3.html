NOMBRE

Xft - biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca simple que dibuja texto y gráficos:

  • utilizando la información proporcionada por la biblioteca Fontconfig,
  • Xft convierte los glifos de fuentes utilizando el rasterizador FreeType, y
  • muestra los datos de fuentes convertidos utilizando la Extensión de Renderizado de X.

Esta página del manual apenas araña la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión secundaria de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias para XFT_VERSION.

El siguiente ejemplo ilustra cómo se podrían usar las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("Versión 2.1.7 o posterior de la biblioteca Xft está en"
                " uso.");
    #else
    (void) printf("Versión insuficiente de Xft (%d.%d.%d) instalada;
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nombres, prefijando todos los nombres con “Xft”

Desde Xlib...

Los tipos de datos de Xlib no siguen una convención de nombres. Se documentan en Xlib - C Language Interface.

Xft utiliza estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual, y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, este es un ID de recurso de X, por ejemplo, una ventana asociada a una pantalla. Tanto las ventanas como los pixmaps se pueden usar como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como 'drawables'. Sin embargo, una ventana de tipo InputOnly no puede usarse como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa mediante la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica la extensión de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

Desde XRender...

Los tipos de datos de la biblioteca X Render Extension están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de cabecera para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft utiliza estos nombres: Picture, XGlyphInfo, XRenderColor.

Desde Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nombres, prefijando todos los nombres con “Fc” que se documentan en Fontconfig Developers Reference.

Xft utiliza estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern, y FcResult.

Desde FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nombres, prefijando todos los nombres con “FT_” que se documentan en FreeType API Reference.

Xft utiliza estos nombres: FT_Face, FT_Library, y FT_UInt.

FreeType 2 utiliza FT_UInt (un entero sin signo) para representar glifos.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que utilizan Xft; contiene métricas generales de la fuente y punteros al conjunto de caracteres y al patrón de Fontconfig asociados con la fuente.

Los XftFonts se rellenan con XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), o XftFontOpenPattern(). XftFontCopy() se usa para duplicar XftFonts, y XftFontClose() se usa para marcar un XftFont como no utilizado. Los XftFonts son asignados internamente, contados por referencia y liberados por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), y XftDrawGlyphSpec() utilizan XftFonts para renderizar texto a un objeto XftDraw, que puede corresponder a un drawable X central o a un drawable de la Extensión de Renderizado de X.

XftGlyphExtents() y la familia XftTextExtents*() se utilizan para determinar las extensiones (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender(), y la familia XftTextRender*() utilizan XftFonts para dibujar en estructuras Picture de la Extensión de Renderizado de X.

Nota: XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), y XftDrawGlyphSpec() proporcionan un medio para renderizar fuentes que es independiente de la disponibilidad de la Extensión de Renderizado de X en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy(), y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que se puede recuperar con XftFontInfoHash(). Un XftFont puede abrirse basándose en datos de XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color del servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X para que libere el color actualmente asignado para un XftColor.

Una vez que un XftColor ha sido inicializado, XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec(), y XftDrawRect() pueden usarse para dibujar varios objetos utilizándolo.

XftDraw

es un objeto opaco que contiene información utilizada para renderizar a un drawable de X utilizando el protocolo principal o la extensión X Rendering.

Los objetos XftDraw se crean con cualquiera de XftDrawCreate() (que asocia un XftDraw con un drawable de X existente), XftDrawCreateBitmap() o XftDrawCreateAlpha(), y se destruyen con XftDrawDestroy(). El drawable de X asociado con un XftDraw se puede cambiar con XftDrawChange(). Los objetos XftDraw son asignados y liberados internamente por Xft; el programador no necesita asignar ni liberar espacio para ellos normalmente.

Las propiedades de Display, Drawable, Colormap y Visual de un XftDraw se pueden consultar con XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap() y XftDrawVisual(), respectivamente.

Varias funciones utilizan objetos XftDraw: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode() y la familia XftDrawString*().

La extensión de renderizado X Picture asociada con un XftDraw se devuelve con XftDrawPicture() y XftDrawSrcPicture(). La utilizan XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender() y la familia XftTextRender*().

FUNCIONES

Inicialización

Una aplicación típica que utiliza Xft no inicializa explícitamente la biblioteca. Eso se hace normalmente como efecto secundario de abrir una fuente.

Cuando Xft se inicializa, recopila información sobre la pantalla y almacena parte de esa información en un patrón de Fontconfig (esencialmente una colección de propiedades con valores tipados). La aplicación que llama puede modificar ese patrón para cambiar el comportamiento de la biblioteca.

No toda la información recopilada se almacena en un patrón. El resto se almacena en estructuras de datos internas. Xft pone parte de esa información a disposición de la aplicación a través de funciones.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y devuelve verdadero si Xft determinó que la pantalla admite la extensión X Render, y si es capaz de encontrar un XRenderPictFormat adecuado (tipo de datos de X Render análogo al Visual de Xlib) en la pantalla.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y establece el patrón de Fontconfig que contiene las propiedades predeterminadas que Xft utilizará para esta pantalla.

Xft utiliza esas propiedades inicialmente para obtener los siguientes límites:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). Esta es la cantidad máxima de memoria de glifos para todas las fuentes utilizadas por Xft (predeterminado: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). Este es el número máximo de fuentes no referenciadas (predeterminado: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). Cuando es verdadero, Xft rastrea el uso de la memoria de glifos para mejorar el rendimiento al decidir cuáles descargar cuando se alcanza la cantidad máxima de memoria de glifos (predeterminado: falso).
Xft también utiliza estas propiedades predeterminadas en XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft rellena las propiedades que faltan en el pattern dado utilizando las propiedades predeterminadas para la pantalla especificada dpy, por ejemplo, como se establece en XftDefaultSet().

Las aplicaciones típicas de Xft utilizan esta función para ayudar a Fontconfig a elegir una fuente adecuada. Estas propiedades se sustituyen antes de llamar a FcDefaultSubstitute():
FC_ANTIALIAS
Verdadero si FreeType debe usar antialiasing (predeterminado: Falso). (predeterminado: Verdadero).
FC_AUTOHINT
Verdadero si FreeType debe usar autohinting (predeterminado: Falso).
FC_DPI
Puntos por pulgada utilizados para la resolución (predeterminado: calculado a partir de la altura de la pantalla).
FC_EMBOLDEN
Verdadero si FT_GlyphSlot_Embolden() debe usarse para poner en negrita una fuente (predeterminado: Falso).
FC_HINTING
Verdadero si se debe usar hinting al rellenar propiedades para abrir una fuente (predeterminado: Verdadero).
FC_HINT_STYLE
Estilo de hinting utilizado al rellenar propiedades para abrir una fuente (predeterminado: FC_HINT_FULL).
FC_LCD_FILTER
Parámetro pasado a FT_Library_SetLcdFilter() al cargar glifos (predeterminado: FC_LCD_DEFAULT).
FC_MINSPACE
Valor de espacio mínimo utilizado al rellenar propiedades para abrir una fuente (predeterminado: Falso).
FC_RGBA
Valor RGBA utilizado al rellenar propiedades para abrir una fuente (predeterminado: calculado llamando a XRenderQuerySubpixelOrder()).
FC_SCALE
Escala utilizada en Fontconfig (predeterminado: 1.0).
XFT_MAX_GLYPH_MEMORY
Memoria máxima para una fuente (predeterminado: 1024*1024).
XFT_RENDER
Verdadero si la pantalla admite la extensión X Render (predeterminado: resultado de XftDefaultHasRender()).
FcBool XftInit (
	_Xconst char	*config);

Inicializa la biblioteca Fontconfig (llamando a FcInit()).

El parámetro config no se utiliza.
Xft no desinicializa la biblioteca Fontconfig cuando termina.

Abrir y comparar fuentes



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen toma una lista de triples de elementos de patrón
        del tipo campo, tipo, valor (terminada con NULL), compara ese
        patrón con las fuentes disponibles y abre la fuente coincidente,
        dimensionándola correctamente para la pantalla número screen en la
        pantalla dpy. Devuelve la fuente coincidente, o NULL si no se
        encuentra ninguna coincidencia.

  




Ejemplo:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
Esto abre la fuente "charter" a 12 puntos. El tamaño del punto se convierte
      automáticamente al tamaño de píxel correcto según la resolución del
      monitor.

XftXlfdParse parses the xlfd_orig parameter

        but ignores some of the fields: setwidth_name,
        add_style_name, spacing, and average_width.

      XFT_XLFD to the xlfd_orig value, and maps the collected

      are ignored:

Determinación   de Extensiones de Texto


Xft proporciona varias funciones para determinar la altura
    y anchura requeridas para mostrar una cadena de texto. Después de tener en
    cuenta el offset, en casos en que la cadena se desplazará hacia
    arriba, abajo, izquierda o derecha, estos números se denominan
    extensiones de texto.

        pantalla dpy de no más de len glifos de una cadena

Administración   de XftColor



  
Bool XftColorAllocName (

  

    
	Display	*dpy,
	_Xconst Visual	*visual,
	Colormap	 cmap,
	_Xconst char	*name,
	XftColor	*result);


    
Utiliza XAllocNamedColor() para buscar el color con
        nombre name para la pantalla asociada con el mapa de colores
        cmap.

  






    
  
  • Si XAllocNamedColor() devuelve un valor distinto de cero,
      XftColorAllocName() rellena el campo de píxel resultante de
      XftColor con el color más cercano admitido por la pantalla, así como
      los campos exactos de rojo, verde y azul de la base de datos, y devuelve
      True.
    • 
  
  • Si XAllocNamedColor() devuelve cero, XftColorAllocName()
      devuelve False y no actualiza el XftColor al que hace referencia
      result.
    • 






  

  
El parámetro visual no se utiliza.





  
Bool XftColorAllocValue (

  

    
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);


    
Asigna un valor de color:

  






    
  
  • Si la clase visual es TrueColor, XftColorAllocValue()
      establece el campo pixel en el XftColor al que hace
      referencia result utilizando los campos rojo, verde y azul del
      parámetro color.
    • 
  
  • Si la clase visual no es TrueColor, XftColorAllocValue()
      llama a XAllocColor() para asignar una entrada en el mapa de
      colores cmap. que devuelve el valor de píxel del color más
      cercano a los elementos RGB especificados admitidos por el hardware.
    • 




  

  
Si XAllocColor() tiene éxito, XftColorAllocValue() almacena
      ese valor de píxel en el XRenderColor al que hace referencia
      result y devuelve True.

  

  
Si XAllocColor() falla, XftColorAllocValue() devuelve False
      y no modifica el resultado.

.BI "XftDrawGlyphFontSpec ("
.BI "XftDraw *" draw ,
.BI "_Xconst XftColor *" color ,
.BI "_Xconst XftGlyphFontSpec *" glyphs ,
.BI "int len"
.BI ")"
Draw a list of glyphs associated with fonts at specified coordinates, passed as
an array of len XftGlyphFontSpec structures via the parameter
glyphs. All of the glyphs are drawn using the color specified in the
color parameter.
.TP
For each entry in the glyphs array:
.TP
.IP ""
If the associated font uses the X Render extension, then Xft uses
XftGlyphFontSpecRender() to draw the glyph, using a Picture
obtained from calling XftDrawSrcPicture () with the draw and
color parameters.
.TP
.IP ""
Otherwise, Xft provides an analogous feature using Xlib.
.TP
.BI "void"
.BI "XftGlyphFontSpecRender ("
.BI "Display *" dpy ,
.BI "int op" ,
.BI "Picture src" ,
.BI "Picture dst" ,
.BI "int srcx" ,
.BI "int srcy" ,
.BI "_Xconst XftGlyphFontSpec *" glyphs ,
.BI "int nglyphs"
.BI ")"
This involves several steps:
.TP
.IP ""
First, Xft ensures that the glyphs array is complete using
XftFontCheckGlyph() and loading any missing glyphs with
XftFontLoadGlyphs().
.TP
.IP ""
Then Xft examines the glyphs to find the maximum Unicode value. That
determines the encoding size, i.e., the width.
.TP
.IP ""
Then, for each glyph, Xft checks if its Unicode value is handled by the
corresponding font. If not, the value is set to zero (0), to ignore it. While
doing this, Xft also remembers which was the first font used, and
computes the position at which each glyph will be drawn.
.TP
.IP ""
Xft then constructs an equivalent array of glyphs in the format expected
by the X Render library.
.TP
.IP ""
Finally, XftGlyphFontSpecRender() uses the X Render extension to draw
the glyphs, with the appropriate XRenderCompositeText*() function
according to the width, and discards temporary data.
.TP
The op, dst, src, srcx, and srcy parameters are
used as described in the documentation for the X Render library.

NAME

    
XftDrawPicture - Dibujar texto en un contexto Xrender





    
SYNOPSIS

    
#include <X11/Xft/Xft.h>

void XftDrawPicture (
    Display       *dpy,
    XftDraw       *draw,
    XftFont       *font,
    const FcChar8 *string,
    int             len
);

void XftDrawGlyph (
    Display       *dpy,
    XftDraw       *draw,
    XftFont       *font,
    FcGlyphCache  *cache,
    FcGlyphSet    *set,
    FcBool          need_bitmaps,
    _Xconst FT_UInt *glyphs,
    int             nglyph
);





    
DESCRIPTION

    
XftDrawPicture dibuja una cadena de caracteres string
        en el contexto draw usando la fuente font.

    
La longitud de la cadena se proporciona en len. Si len
        es -1, se asume que la cadena está terminada en null. La cadena se
        interpreta como una matriz de UTF-8.

    
XftDrawGlyph dibuja glifos en el contexto draw
        usando la fuente font. Los glifos se extraen del conjunto de
        glifos set, que se espera que se construya a partir de los
        índices de glifos proporcionados en el array glyphs. Si
        need_bitmaps es verdadero, se cargarán los mapas de bits de los
        glifos. La matriz glyphs contiene nglyph índices de
        glifos.

    
Ambas funciones utilizan la biblioteca Fontconfig para el
        análisis de fuentes y la gestión de la caché de glifos.





    
CONSTANTS

    

        
FcTrue

        
Representa el valor booleano verdadero.

        
FcFalse

        
Representa el valor booleano falso.

Tipo de datos para cadenas de caracteres de 8 bits.

        
FcGlyphCache

        
Estructura opaca que representa una caché de glifos.

Estructura opaca que representa un conjunto de glifos.

FUNCTIONS

    

        
FcBool XftNameParse (
        

            
	const FcChar8	*name,
	int		 len);


            
Xft usa Fontconfig para analizar el nombre, pasando
                el name a FcNameParse(), que devuelve el resultado.

        

        
FcBool XftNameUnparse (
        

            
	FcPattern	*pat,
	char	*dest,
	int	 len);


            
Al igual que XfgNameParse(), Xft usa
                Fontconfig. En este caso, utiliza FcNameUnparse(), que
                convierte el patrón pat de nuevo en una cadena que se
                puede analizar. XftNameUnparse() almacena el resultado
                a través del puntero dest del llamador, pero primero
                verifica si encajará, utilizando el parámetro len. Si
                encaja, Xft copia la cadena y devuelve FcTrue,
                de lo contrario devuelve FcFalse.

        

    





    
Manipulación de datos de fuentes

    

        
void XftFontLoadGlyphs (
        

            
	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


            
Usando FT_Load_Glyph(), carga nglyphs para
                los índices de glifos (valores Unicode) listados en el array
                glyphs de la fuente dada pub.

        

    

    

        

        
Cargar un glifo implica más que solo leer datos en memoria.
            Xft usa el patrón de Fontconfig asociado con la pantalla
            dpy (por ejemplo, a través de XftDefaultSet()) para
            determinar si se debe usar un cuadro delimitador, recortar los
            glifos dentro de esos límites, escalar los glifos, calcular las
            métricas de la fuente y agregarla a la extensión X Render usando
            XRenderAddGlyphs().

    

    

        
void XftFontUnloadGlyphs (
        

            
	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


            
Descarta datos para hasta nglyph glifos cuyos
                índices de glifos (valores Unicode) están listados en el array
                glyphs para la fuente dada pub. Si los glifos se
                agregaron a la extensión X Render, Xft los elimina
                usando XRenderFreeGlyphs(). Xft realiza un
                seguimiento de la cantidad de memoria utilizada para los
                glifos y actualiza el uso asociado con la pantalla dpy.

        

        
FT_Face XftLockFace (
        

            
	XftFont	*pub);


            
Si no se ha creado ninguna cara de FreeType 2
                (“face”) (representación en memoria de una fuente dada
                en un estilo dado) para la fuente pub, créela usando
                FT_New_Face(). Los bloqueos de cara son un contador de
                referencias utilizado por Xft para asegurar que solo se
                cree una cara y que se retenga hasta que la fuente ya no se
                use.

        

    

    

        

        
El bloqueo de cara se utiliza directamente en XftCharIndex() y
            XftFontLoadGlyphs(), que a su vez se utilizan en muchas
            funciones de Xft.

        

        
El bloqueo de cara se introdujo en la versión 1 (octubre de 2002).
            Algunas aplicaciones, como Gdk/Gimp, dependían de estas funciones.
            En la versión 2.1.9 (junio de 2006), se conservó el bloqueo de cara
            como parte de la API pública cuando las configuraciones mejoradas
            de bibliotecas compartidas permitieron ocultar símbolos privados.

    

    

        
void XftUnlockFace (
        

            
	XftFont	*pub);


            
Decrementa el contador de referencias para la cara
                (“face”) de FreeType 2 asociada con la fuente.

        

    

    

        

        
Los objetos FT_Face se desasignan usando FT_Done_Face().
            Xft hace esto en XftFontInfoDestroy() y al limpiar en
            caso de fallo en XftFontInfoCreate() y
            XftFontOpenPattern().

    







    
DEBUGGING

    
Xft lee la variable de entorno XFT_DEBUG y la
        convierte a un entero. Cada bit en el valor resultante indica a Xft
        que imprima información de depuración en la salida estándar:

    

        
1

        
apertura de fuentes

        
2

        
coincidencia y apertura de fuentes adicionales (verboso)

        
4

        
muestra detalles sobre el XRenderPictFormat que se utilizará.

        
8

        
muestra la cadena que XftDrawString8() dibujará.

        
16

        
muestra qué IDs de fuentes coinciden.

        
32

        
muestra información útil sobre los glifos que se dibujarán

        
64

        
muestra una representación en arte ASCII de los glifos.

        
128

        
muestra detalles sobre la gestión de la caché de memoria

        
256

        
muestra detalles sobre la gestión de memoria caché de glifos

        
512

        
muestra un informe sobre el uso de memoria

        
1024

        
muestra detalles sobre la gestión extendida de memoria caché de glifos

    





    
COMPATIBILIDAD

    
A partir de la versión 2 (mayo de 2002), Xft se volvió
        relativamente estable. Se espera que mantenga la compatibilidad de
        código fuente y binaria en futuras versiones.

    
Xft proporciona una interfaz de compatibilidad con su
        versión principal anterior, Xft 1.x, descrita a continuación.

    

        
Archivo de cabecera de Xft 1.x

        
#include <X11/Xft/XftCompat.h>

    

    

        
Tipos de datos de Xft 1.x

        

            
XftPattern

            
contiene un conjunto de nombres con listas de valores asociadas; cada
                nombre se refiere a una propiedad de una fuente. Los XftPatterns
                se utilizan como entradas para el código de coincidencia, así como
                para contener información sobre fuentes específicas.

            
XftFontSet

            
contiene una lista de XftPatterns. Internamente, Xft
                utiliza esta estructura de datos para mantener conjuntos de fuentes.
                Externamente, Xft devuelve los resultados de listar fuentes en
                este formato.

            
XftObjectSet

            
contiene un conjunto de nombres y se utiliza para especificar qué
                campos de las fuentes se incluyen en la lista de patrones devueltos
                al listar fuentes.
