NOMBRE

Xft - biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca simple que dibuja texto y gráficos:

  • utilizando información proporcionada por la biblioteca Fontconfig,
  • Xft convierte glifos de fuentes utilizando el rasterizador FreeType, y
  • muestra los datos de fuentes convertidos utilizando la extensión X Rendering Extension.

Esta página del manual apenas rasca la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión secundaria de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias para XFT_VERSION.

El siguiente ejemplo ilustra cómo podrían usarse las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("La versión 2.1.7 o posterior de la biblioteca Xft está en"
                " uso.");
    #else
    (void) printf("Versión insuficiente de Xft (%d.%d.%d) instalada;
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nomenclatura, prefijando todos los nombres con “Xft”

De Xlib...

Los tipos de datos de Xlib no siguen una convención de nomenclatura. Se documentan en Xlib - Interfaz del Lenguaje C.

Xft usa estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, es un ID de recurso X, por ejemplo, una ventana asociada a una pantalla. Tanto las ventanas como los pixmaps se pueden usar como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como drawables. Sin embargo, una ventana de solo entrada (InputOnly) no puede usarse como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa como la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica la extensión de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

De XRender...

Los tipos de datos de la biblioteca X Render Extension están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de encabezado para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft usa estos nombres: Picture, XGlyphInfo, XRenderColor.

De Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nomenclatura, prefijando todos los nombres con “Fc” que se documentan en la Referencia para desarrolladores de Fontconfig.

Xft usa estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern y FcResult.

De FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nomenclatura, prefijando todos los nombres con “FT_” que se documentan en la Referencia de la API de FreeType.

Xft usa estos nombres: FT_Face, FT_Library y FT_UInt.

FreeType 2 usa FT_UInt (un entero sin signo) para representar *glifos*.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que usan Xft; contiene métricas generales de la fuente y punteros al conjunto de caracteres y al patrón de Fontconfig asociados con la fuente.

Los XftFont se rellenan con XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo() o XftFontOpenPattern(). XftFontCopy() se usa para duplicar XftFonts, y XftFontClose() se usa para marcar un XftFont como no utilizado. Los XftFont son asignados internamente, contados por referencia y liberados por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() usan XftFonts para renderizar texto en un objeto XftDraw, que puede corresponder a un drawable X principal o a un drawable de X Rendering Extension.

XftGlyphExtents() y la familia XftTextExtents*() se usan para determinar las extensiones (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender() y la familia XftTextRender*() usan XftFonts para dibujar en estructuras Picture de X Rendering Extension.

Nota: XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec() y XftDrawGlyphSpec() proporcionan un medio de renderizar fuentes que es independiente de la disponibilidad de la X Rendering Extension en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy() y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar o liberar almacenamiento para ellos.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que se puede obtener con XftFontInfoHash(). Se puede abrir un XftFont basándose en datos XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color al servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X a liberar el color actualmente asignado para un XftColor.

Una vez que se ha inicializado un XftColor, XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec(), y XftDrawRect() pueden usarse para dibujar varios objetos usándolo.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

XftDraw

es un objeto opaco que contiene información utilizada para renderizar en un drawable de X usando el protocolo principal o la extensión de Renderizado X.

Los objetos XftDraw se crean con cualquiera de XftDrawCreate() (que asocia un XftDraw con un drawable X existente), XftDrawCreateBitmap(), o XftDrawCreateAlpha(), y se destruyen con XftDrawDestroy(). El drawable X asociado con un XftDraw se puede cambiar con XftDrawChange(). Los objetos XftDraw son asignados y liberados internamente por Xft; el programador normalmente no necesita asignar o liberar memoria para ellos.

Las propiedades de Display, Drawable, Colormap, y Visual de X de un XftDraw se pueden consultar con XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap(), y XftDrawVisual(), respectivamente.

Varias funciones utilizan objetos XftDraw: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode(), y la familia XftDrawString*().

La extensión de Renderizado X Picture asociada con un XftDraw se devuelve por XftDrawPicture(), y XftDrawSrcPicture(). Es utilizada por XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender(), y la familia XftTextRender*().

FUNCIONES

Inicialización

Una aplicación típica que usa Xft no inicializa explícitamente la biblioteca. Eso generalmente se hace como un efecto secundario de abrir una fuente.

Cuando Xft se inicializa, recopila información sobre la pantalla y almacena parte de esa información en un patrón Fontconfig (esencialmente una colección de propiedades con valores tipados). La aplicación que llama puede modificar ese patrón para cambiar el comportamiento de la biblioteca.

No toda la información recopilada se almacena en un patrón. El resto se almacena en estructuras de datos internas. Xft pone parte de eso a disposición de la aplicación a través de funciones.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y devuelve verdadero si Xft determinó que la pantalla soporta la extensión de Renderizado X y si puede encontrar un XRenderPictFormat adecuado (el tipo de datos de X Render que es análogo al Visual de Xlib) en la pantalla.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtiene información sobre la pantalla dpy si aún no se ha hecho y establece el patrón Fontconfig que contiene las propiedades predeterminadas que Xft utilizará para esta pantalla.

Xft utiliza esas propiedades inicialmente para obtener estos límites:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). Esta es la cantidad máxima de memoria de glifos para todas las fuentes utilizadas por Xft (predeterminado: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). Este es el número máximo de fuentes no referenciadas (predeterminado: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). Cuando es verdadero, Xft rastrea el uso de la memoria de glifos para mejorar el rendimiento al decidir qué descargar cuando se alcanza la cantidad máxima de memoria de glifos (predeterminado: falso).
Xft también utiliza estas propiedades predeterminadas en XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft completa las propiedades faltantes en el pattern dado utilizando las propiedades predeterminadas para la pantalla especificada dpy, por ejemplo, como se establece en XftDefaultSet().

Las aplicaciones típicas de Xft utilizan esta función para ayudar a Fontconfig a elegir una fuente adecuada. Estas propiedades se sustituyen antes de llamar a FcDefaultSubstitute():
FC_ANTIALIAS
Verdadero si FreeType debe usar suavizado (predeterminado: Falso). (predeterminado: Verdadero).
FC_AUTOHINT
Verdadero si FreeType debe usar autohinting (predeterminado: Falso).
FC_DPI
Puntos por pulgada utilizados para la resolución (predeterminado: calculado a partir de la altura de la pantalla).
FC_EMBOLDEN
Verdadero si FT_GlyphSlot_Embolden() debe usarse para poner en negrita una fuente (predeterminado: Falso).
FC_HINTING
Verdadero si se debe usar hinting al completar propiedades para abrir una fuente (predeterminado: Verdadero).
FC_HINT_STYLE
Estilo de hinting utilizado al completar propiedades para abrir una fuente (predeterminado: FC_HINT_FULL).
FC_LCD_FILTER
Parámetro pasado a FT_Library_SetLcdFilter() al cargar glifos (predeterminado: FC_LCD_DEFAULT).
FC_MINSPACE
Valor de espacio mínimo utilizado al completar propiedades para abrir una fuente (predeterminado: Falso).
FC_RGBA
Valor RGBA utilizado al completar propiedades para abrir una fuente (predeterminado: calculado llamando a XRenderQuerySubpixelOrder()).
FC_SCALE
Escala utilizada en Fontconfig (predeterminado: 1.0).
XFT_MAX_GLYPH_MEMORY
Memoria máxima para una fuente (predeterminado: 1024*1024).
XFT_RENDER
Verdadero si la pantalla soporta la extensión de Renderizado X (predeterminado: resultado de XftDefaultHasRender()).

Abrir y Emparejar Fuentes



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen toma una lista de triples de elementos de patrón del tipo
        campo, tipo, valor (terminada con un NULL), empareja ese patrón
        con las fuentes disponibles, y abre la fuente emparejada, dimensionándola
        correctamente para el número de pantalla screen en la pantalla dpy. Devuelve
        la fuente emparejada, o NULL si no se encuentra ninguna coincidencia.

  




Ejemplo:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
Esto abre la fuente “charter” a 12 puntos. El tamaño en puntos se
      convierte automáticamente al tamaño de píxel correcto según la resolución del monitor.

DESCRIPTION


The Xft library provides access to the
    Fontconfig font matching and substitution library. It supports drawing glyphs
    using the X Rendering Extension.




Opening Fonts


XftFontOpenName opens a font. The
    name parameter is a string that is parsed by
    Fontconfig's FcNameParse(). The actual font opened
    is determined by Fontconfig's font matching algorithm.


XftFontOpen opens a font given a Fontconfig
    pattern. Fontconfig's font matching algorithm is used to find the best
    matching font.


XftFontOpenXlfd opens a font given an X
    Logical Font Description (XLFD) string. This string is parsed using
    XftXlfdParse(), and the resulting Fontconfig pattern
    is used to find the best matching font.


XftFontMatch can be used to determine the
    Fontconfig font pattern that would result from an Xft font open
    request. This function is also used internally by the
    XftFontOpen* functions.


XftXlfdParse parses an XLFD string according
    to the X Logical Font Description Conventions document. It creates a
    Fontconfig pattern and maps the XLFD fields to Fontconfig properties. Some
    fields (setwidth_name, add_style_name, spacing, and
    average_width) are ignored. Empty or "*" fields are also ignored. The
    resulting Fontconfig pattern will have the XFT_XLFD property set to
    the original XLFD string.

from foundry.

  
FC_FAMILY

  
from family.

from weight_name, defaulting to FC_WEIGHT_MEDIUM.

XftFontOpenXlfd behaves as
    XftFontOpen does, except that it takes a string
    containing an X Logical Font Description (XLFD), and uses the
    XftXlfdParse() function.

Determining Text Extents


Xft provides several functions for determining the required
    height and width for displaying a text-string. After accounting for the
    offset, in cases where the string will be shifted up, down, left or
    right, these numbers are referred to as text extents.

DESCRIPTION


The Xft library provides access to TrueType fonts through the FreeType
    library, and provides a clean, efficient, and customizable API for font
    handling. Xft relies on Fontconfig for font matching and substitution.


The following functions are provided:



  
XftFontOpen (), XftFontMatch (), XftFontOpenName (),
      XftFontOpenPdc (), XftFontOpenXlfd ()

  






These functions all open fonts. The XftFontOpen()
    function takes a list of font patterns and returns the font that best matches
    the list. The patterns are searched in order, and the first match is
    returned. The list is terminated by a NULL pointer. The
    XftFontOpenName() function takes a font name string, parses it into
    a list of patterns, and then calls XftFontOpen(). The
    XftFontOpenXlfd() function takes an X Logical Font Description
    (XLFD) string, converts it into a font pattern, and then calls
    XftFontOpen(). The XftFontOpenPdc() function takes a
    Fontconfig pattern and returns the best matching font. The
    XftFontMatch() function takes a pattern and returns the best matching
    font. If failed is not NULL, it is filled with the pattern that
    failed to match.


Fontconfig is used to translate the patterns into font
    files. If no font matches, NULL is returned.





  
XftFontClose ()

  

    
Closes the font referred to by font. The font data is
        freed if this is the last reference to the font.

  

  
XftFontFromFile ()

  

    
Opens a font file specified by filename. If
        cascade is true, then if the font file contains multiple fonts,
        all of them are returned in a font set. Otherwise, only the first font
        is returned. Note that this function is not related to Fontconfig, and
        is intended for use in applications that wish to open fonts directly
        from font files, without using Fontconfig's font matching capabilities.

  

  
XftFontLoadGlyphs ()

  

    
Loads the specified glyphs for the given font. If
        need_bitmaps is true, then bitmaps for the glyphs will be loaded.
        Otherwise, only scalable outlines will be loaded. The glyph indices are
        specified in the glyphs array. The nglyph parameter
        specifies the number of glyphs in the array.

    
Xft uses the Fontconfig pattern associated with the
        display (e.g., via XftDefaultSet()) to determine whether to use a
        bounding box, clip the glyphs into those bounds, scale the glyphs,
        compute font metrics, and add it to the X Render extension using
        XRenderAddGlyphs().

  

  
XftFontUnloadGlyphs ()

  

    
Unloads the specified glyphs for the given font. This frees
        any memory associated with the glyphs. The glyphs array contains
        the glyph indices to unload, and nglyph specifies the number of
        glyphs.

    
If the glyphs were added to the X Render extension,
        Xft removes those using XRenderFreeGlyphs().
        Xft keeps track of the amount of memory used for glyphs, and
        updates the usage associated with the display dpy.

  

  
XftGlyphCache (), XftGlyphCacheSubfont (),
      XftGlyphCacheRelease ()

  

    
These functions manage the glyph cache. XftGlyphCache()
        returns the glyph cache associated with the display. XftGlyphCacheSubfont()
        returns the subfont cache for a given font. XftGlyphCacheRelease()
        releases the glyph cache.

  

  
XftCharIndex ()

  

    
Returns the glyph index for the given character. If the
        character does not exist in the font, 0 is returned.

  

  
XftCharExists ()

  

    
Returns FcTrue if the given glyph exists in the font,
        and FcFalse otherwise.

  

  
XftTextExtents8 (), XftTextExtents16 (),
      XftTextExtents32 (), XftTextExtentsUtf8 ()

  

    
These functions compute the extents of a string of text. The
        extents include the bounding box of the text, as well as the ink and
        logical extents. The extents parameter is a pointer to an
        XftXlibFont structure that will be filled with the computed
        extents.

  

  
XftDrawCreate (), XftDrawDestroy (), XftDrawSetClip (),
      XftDrawSetGlyphFont (), XftDrawGlyphSpec (),
      XftDrawGlyphMask (), XftDrawString8 (),
      XftDrawString16 (), XftDrawString32 (),
      XftDrawStringUtf8 ()

  

    
These functions are used for drawing text to a drawable.
        XftDrawCreate() creates a drawing context for the given drawable,
        visual, and depth. XftDrawDestroy() destroys the drawing context.
        XftDrawSetClip() sets the clip region for the drawing context.
        XftDrawSetGlyphFont() sets the default font to use for drawing
        glyphs. XftDrawGlyphSpec() and XftDrawGlyphMask() draw
        glyphs. XftDrawString8()*, XftDrawString16()*,
        XftDrawString32()*, and XftDrawStringUtf8() draw strings of
        text.

    
The color parameter specifies the color of the text or
        glyphs. The font parameter specifies the font to use. The
        x and y parameters specify the position at which to draw
        the text. The string parameter is the text to draw, and len
        is the length of the string.

  

  
XftDefaultSet (), XftDefaultSetInitialFont (),
      XftDefaultSetInitialSecondaryFont (),
      XftDefaultSetInitialPicture (), XftDefaultGet (),
      XftDefaultGetInitialFont (),
      XftDefaultGetInitialSecondaryFont (),
      XftDefaultGetInitialPicture (), XftDefaultRelease ()

  

    
These functions manage the default font patterns used by
        Xft. XftDefaultSet() sets the default font pattern for the given
        display and screen. XftDefaultGet() retrieves the default font
        pattern. The other functions manage initial fonts and pictures.

COMPATIBILITY


As of version 2 (May 2002), Xft became relatively stable.
    It is expected to retain source and binary compatibility in future
  releases.


Xft provides a compatibility interface to its previous
    major version, Xft 1.x, described below.




Xft   1.x Header File


#include <X11/Xft/XftCompat.h>






Xft   1.x Data Types



  
XftPattern

  
holds a set of names with associated value lists; each name refers to a
      property of a font. XftPatterns are used as inputs to the matching
      code as well as holding information about specific fonts.

  
XftFontSet

  
contains a list of XftPatterns. Internally, Xft uses this
      data structure to hold sets of fonts. Externally, Xft returns the
      results of listing fonts in this format.

  
XftObjectSet

  
holds a set of names and is used to specify which fields from fonts are
      placed in the list of returned patterns when listing fonts.
