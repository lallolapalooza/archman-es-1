DESCRIPTION

The XFree86-VidMode Extension provides a mechanism for clients to query and control the video modes supported by the X server. This includes querying available modes, setting new modes, switching between modes, and controlling the viewport. The extension also provides functionality for querying and setting monitor characteristics, gamma correction, and dot clocks.

The functions provided by the extension library can be broadly categorized as follows:

  • Extension Initialization and Versioning:

    XF86VidModeQueryExtension() checks if the VidMode extension is available and retrieves its base event and error numbers.

    XF86VidModeQueryVersion() retrieves the major and minor version numbers of the VidMode extension supported by the server.

    XF86VidModeSetClientVersion() is used to indicate the client's version to the server, usually called after querying the extension version.

  • Mode Management:

    XF86VidModeGetModeLine() retrieves the current video mode line for a given screen.

    XF86VidModeGetAllModeLines() retrieves a list of all available video modes for a screen, along with their timing information.

    XF86VidModeAddModeLine() adds a new video mode to the server's list of available modes.

    XF86VidModeDeleteModeLine() removes a video mode from the server's list.

    XF86VidModeModModeLine() modifies an existing video mode.

    XF86VidModeValidateModeLine() checks if a given mode line is valid according to the server's capabilities.

  • Mode Switching:

    XF86VidModeSwitchMode() switches to the next or previous video mode.

    XF86VidModeSwitchToMode() switches to a specific video mode.

    XF86VidModeLockModeSwitch() locks or unlocks the ability to switch video modes.

  • Viewport Control:

    XF86VidModeGetViewPort() retrieves the current position of the virtual screen (viewport).

    XF86VidModeSetViewPort() sets the position of the virtual screen.

  • Monitor and Clock Information:

    XF86VidModeGetMonitor() retrieves information about the connected monitor, including its vendor, model, and supported sync ranges.

    XF86VidModeGetDotClocks() retrieves information about the dot clocks supported by the graphics hardware, including the maximum dot clock and a list of available clock frequencies.

  • Gamma Correction:

    XF86VidModeGetGamma() retrieves the current gamma settings for a screen.

    XF86VidModeSetGamma() sets the gamma settings for a screen.

    XF86VidModeGetGammaRamp() retrieves the gamma ramp lookup tables for red, green, and blue color channels.

    XF86VidModeSetGammaRamp() sets the gamma ramp lookup tables.

    XF86VidModeGetGammaRampSize() retrieves the size of the gamma ramp lookup tables.

    XF86VidModeGetPermissions() retrieves the current gamma and gamma ramp permissions for the client.

RETURN VALUES

Most functions return True on success and False on failure. XF86VidModeValidateModeLine() returns Success if the mode line is valid, and an error code otherwise.

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la extensión del servidor XFree86-VidModeExtension que permite consultar y ajustar los modos de video dinámicamente y controlar el cambio de modo. Las aplicaciones que usan estas funciones deben enlazarse con -lXxf86vm

FUNCIONES DE LÍNEA DE MODO

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de video seleccionado actualmente. El programa que llama debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si existen valores privados del servidor (actualmente solo aplicables al servidor S3), la función asignará almacenamiento para ellos. Por lo tanto, si el campo privsize no es cero, el programa que llama debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de video. El programa que llama proporciona la dirección de un puntero que será establecido por la función para apuntar a una matriz de estructuras XF86VidModeModeInfo. La memoria ocupada por la matriz es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamador. El primer elemento de la matriz corresponde al modo de video actual.

La función XF86VidModeModModeLine se puede usar para cambiar la configuración del modo de video actual, siempre que la configuración solicitada sea válida (por ejemplo, que no exceda las capacidades del monitor).

Para añadir un modo a la lista de modos disponibles, se puede usar la función XF86VidModeAddModeLine. Suponiendo que la configuración es válida, el modo de video se añadirá después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para ser considerado una coincidencia, todos los campos de la estructura dada XF86VidModeModeInfo deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se añadirá después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para ser considerado una coincidencia, todos los campos de la estructura dada XF86VidModeModeInfo deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero ocurrirá un cambio de modo al siguiente modo. No se puede eliminar el último modo restante.

La validez de un modo se puede comprobar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser utilizado por el servidor (es decir, cumple con todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario, devuelve un valor que indica la razón por la cual el modo no es válido (según se define en xf86.h)

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de video al siguiente (o anterior) modo de video. La función XF86VidModeSwitchToMode se puede utilizar para cambiar directamente al modo especificado. La coincidencia se especifica según la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch se puede utilizar para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode, o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, se necesita una llamada a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado del estado de ejecución de la solicitud, se debe instalar un manejador de errores personalizado usando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información conocida por el servidor sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a una matriz de estructuras XF86VidModeSyncRange. Las matrices contienen elementos nhsync y nvsync, respectivamente. Los valores hi y low serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamador.

FUNCIONES DE VIEWPORT

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort se pueden utilizar para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda del viewport dentro de la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion se puede utilizar para determinar la versión de la extensión incorporada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores de error y evento con el número más bajo asignados a la extensión.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulte el código fuente para obtener información sobre cómo usarlas.
