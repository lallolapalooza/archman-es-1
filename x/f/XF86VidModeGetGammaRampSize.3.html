ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen
Especifica a qué número de pantalla se aplican los ajustes.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de vídeo disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo; de lo contrario, cambiar al modo anterior.
lock
Indica que el cambio de modo debe bloquearse, si no es cero.
modeline
Especifica o devuelve los valores de temporización para un modo de vídeo.
aftermode
Especifica los valores de temporización del modo de vídeo después del cual se añadirá el nuevo modo.
modesinfo
Devuelve los valores de temporización y los relojes de puntos de todos los modos de vídeo disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para la ventana de visualización.
x_return
Devuelve la ubicación X actual de la ventana de visualización.
y
Especifica la ubicación Y deseada para la ventana de visualización.
y_return
Devuelve la ubicación Y actual de la ventana de visualización.
