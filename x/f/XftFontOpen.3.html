NOMBRE

Xft - Biblioteca de interfaz X FreeType

SINOPSIS

#include <X11/Xft/Xft.h>

DESCRIPCIÓN

Xft es una biblioteca simple que dibuja texto y gráficos:

  • utilizando información proporcionada por la biblioteca Fontconfig,
  • Xft convierte glifos de fuentes utilizando el rasterizador FreeType, y
  • muestra los datos de fuente convertidos utilizando la Extensión de Renderizado X.

Esta página del manual apenas rasca la superficie de esta biblioteca.

CONSTANTES

XFT_MAJOR
es el número de versión principal de Xft.
XFT_MINOR
es el número de versión secundaria de Xft.
XFT_REVISION
es el número de revisión de Xft.
XFT_VERSION
es XFT_MAJOR multiplicado por 10000 (diez mil), más XFT_MINOR multiplicado por 100, más XFT_REVISION.
XftVersion
es un alias de XFT_VERSION.

El siguiente ejemplo ilustra cómo podrían usarse las constantes de versión de Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("Versión 2.1.7 o posterior de la biblioteca Xft está en"
                " uso.");
    #else
    (void) printf("Versión insuficiente de Xft (%d.%d.%d) instalada;
                  " se necesita al menos la versión 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

TIPOS DE DATOS

Los tipos de datos de Xft siguen una convención de nomenclatura, prefijando todos los nombres con "Xft"

Desde Xlib...

Los tipos de datos de Xlib no siguen una convención de nomenclatura. Se documentan en Xlib - Interfaz de Lenguaje C.

Xft utiliza estos nombres: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual y XRectangle.

Algunos tipos de datos son especialmente relevantes para Xft:

Drawable
Declarado en <X11/X.h>, este es un ID de recurso X, por ejemplo, una ventana asociada con una pantalla. Tanto las ventanas como los pixmaps pueden usarse como fuentes y destinos en operaciones gráficas. Estas ventanas y pixmaps se conocen colectivamente como drawables. Sin embargo, una ventana de tipo InputOnly no puede usarse como fuente o destino en una operación gráfica.
Region
Declarado en <X11/Xutil.h> y <X11/Xregion.h>, una Region es un conjunto arbitrario de ubicaciones de píxeles que Xlib puede manipular. Internamente, una Region se representa como la unión de un número arbitrario de rectángulos. Xlib mantiene un rectángulo que le indica la extensión de esta unión.
Visual
Declarado en <X11/Xutil.h>, esta estructura contiene información sobre el mapeo de color posible.

Desde XRender...

Los tipos de datos de la biblioteca X Render Extension están inspirados en Xlib, pero carecen de la documentación correspondiente. Consulte el archivo de encabezado para obtener detalles:

<X11/extensions/Xrender.h>

o lea el código fuente (que proporciona un esquema de libXrender).

Xft utiliza estos nombres: Picture, XGlyphInfo, XRenderColor.

Desde Fontconfig...

Los tipos de datos de Fontconfig siguen una convención de nomenclatura, prefijando todos los nombres con "Fc", que se documentan en la Referencia para Desarrolladores de Fontconfig.

Xft utiliza estos nombres de Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern y FcResult.

Desde FreeType 2...

Los tipos de datos de FreeType 2 siguen una convención de nomenclatura, prefijando todos los nombres con "FT_", que se documentan en la Referencia de la API de FreeType.

Xft utiliza estos nombres: FT_Face, FT_Library y FT_UInt.

FreeType 2 utiliza FT_UInt (un entero sin signo) para representar *glifos*.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

Un XftFont es la estructura de datos principal de interés para los programadores que utilizan Xft; contiene métricas generales de fuente y punteros al conjunto de caracteres de Fontconfig y al patrón asociados con la fuente.

Los XftFonts se poblan con cualquiera de las funciones XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), o XftFontOpenPattern(). XftFontCopy() se utiliza para duplicar XftFonts, y XftFontClose() se utiliza para marcar un XftFont como no utilizado. Los XftFonts son asignados internamente, contados por referencia y liberados por Xft; el programador no necesita normalmente asignar o liberar almacenamiento para ellos.

XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), y XftDrawGlyphSpec() utilizan XftFonts para renderizar texto en un objeto XftDraw, que puede corresponder a un drawable X principal o a un drawable de la Extensión de Renderizado X.

XftGlyphExtents() y la familia XftTextExtents*() se utilizan para determinar las extensiones (dimensiones máximas) de un XftFont.

La cobertura de glifos o caracteres de un XftFont se puede determinar con XftFontCheckGlyph() o XftCharExists(). XftCharIndex() devuelve el índice de carácter específico de XftFont correspondiente a un punto de código Unicode dado.

XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender(), y la familia XftTextRender*() utilizan XftFonts para dibujar en estructuras Picture de la Extensión de Renderizado X.

Nota: XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), y XftDrawGlyphSpec() proporcionan un medio para renderizar fuentes que es independiente de la disponibilidad de la Extensión de Renderizado X en el servidor X.

XftFontInfo

es un objeto opaco que almacena información sobre una fuente. Las estructuras XftFontInfo se crean con XftFontInfoCreate(), se liberan con XftFontInfoDestroy() y se comparan con XftFontInfoEqual(). Los objetos XftFontInfo son asignados y liberados internamente por Xft; el programador no necesita normalmente asignar o liberar almacenamiento para ellos.

Cada estructura XftFontInfo en uso está asociada con un identificador único, que se puede recuperar con XftFontInfoHash(). Se puede abrir un XftFont basándose en los datos de XftFontInfo con XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

Un objeto XftColor permite que el texto y otros elementos se rendericen en un color particular (o la aproximación más cercana ofrecida por el visual X en uso).

XftColorAllocName() y XftColorAllocValue() solicitan una asignación de color del servidor X (si es necesario) e inicializan los miembros de XftColor. XftColorFree() instruye al servidor X para que libere el color actualmente asignado para un XftColor.

Una vez que un XftColor ha sido inicializado, XftDrawSrcPicture(), XftDrawGlyphs(), la familia XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec(), y XftDrawRect() pueden usarse para dibujar varios objetos utilizándolo.

XftDraw

es un objeto opaco que contiene información utilizada para renderizar en un drawable X utilizando el protocolo principal o la extensión de renderizado X.

Los objetos XftDraw se crean con cualquiera de XftDrawCreate() (que asocia un XftDraw con un drawable X existente), XftDrawCreateBitmap() o XftDrawCreateAlpha(), y se destruyen con XftDrawDestroy(). El drawable X asociado con un XftDraw se puede cambiar con XftDrawChange(). Los objetos XftDraw son asignados y liberados internamente por Xft; el programador no necesita asignar ni liberar espacio de almacenamiento para ellos normalmente.

Las propiedades X Display, Drawable, Colormap y Visual de un XftDraw se pueden consultar con XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap() y XftDrawVisual(), respectivamente.

Varias funciones utilizan objetos XftDraw: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode() y la familia XftDrawString*().

La extensión de renderizado X Picture asociada con un XftDraw se devuelve mediante XftDrawPicture() y XftDrawSrcPicture(). Es utilizada por XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender() y la familia XftTextRender*().

FUNCIONES

Inicialización

Una aplicación típica que utiliza Xft no inicializa explícitamente la biblioteca. Esto se realiza normalmente como un efecto secundario de abrir una fuente.

Cuando Xft se inicializa, recopila información sobre la pantalla y almacena parte de esa información en un patrón de Fontconfig (esencialmente una colección de propiedades con valores tipados). La aplicación que llama puede modificar ese patrón para cambiar el comportamiento de la biblioteca.

No toda la información recopilada se almacena en un patrón. El resto se almacena en estructuras de datos internas. Xft pone parte de esa información a disposición de la aplicación a través de funciones.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y devuelve verdadero si Xft descubrió que la pantalla soporta la extensión X Render, y si puede encontrar un XRenderPictFormat adecuado (el tipo de dato de X Render que es análogo al Visual de Xlib) en la pantalla.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtiene información sobre la pantalla dpy si aún no se ha hecho, y establece el patrón de Fontconfig que contiene las propiedades predeterminadas que Xft utilizará para esa pantalla.

Xft utiliza esas propiedades inicialmente para obtener estos límites:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). Esta es la cantidad máxima de memoria de glifos para todas las fuentes utilizadas por Xft (predeterminado: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). Este es el número máximo de fuentes no referenciadas (predeterminado: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). Cuando es verdadero, Xft rastrea el uso de la memoria de glifos para mejorar el rendimiento al decidir qué descargar cuando se alcanza la cantidad máxima de memoria de glifos (predeterminado: falso).
Xft también utiliza estas propiedades predeterminadas en XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft rellena las propiedades faltantes en el pattern dado utilizando las propiedades predeterminadas para la pantalla especificada dpy, por ejemplo, como se establece en XftDefaultSet().

Las aplicaciones típicas de Xft utilizan esta función para ayudar a Fontconfig a elegir una fuente adecuada. Estas propiedades se sustituyen antes de llamar a FcDefaultSubstitute():
FC_ANTIALIAS
Verdadero si FreeType debe usar antialiasing (predeterminado: Falso). (predeterminado: Verdadero).
FC_AUTOHINT
Verdadero si FreeType debe usar autohinting (predeterminado: Falso).
FC_DPI
Puntos por pulgada utilizados para la resolución (predeterminado: calculado a partir de la altura de la pantalla).
FC_EMBOLDEN
Verdadero si FT_GlyphSlot_Embolden() debe usarse para engrosar una fuente (predeterminado: Falso).
FC_HINTING
Verdadero si se debe usar hinting al rellenar propiedades para abrir una fuente (predeterminado: Verdadero).
FC_HINT_STYLE
Estilo de hinting utilizado al rellenar propiedades para abrir una fuente (predeterminado: FC_HINT_FULL).
FC_LCD_FILTER
Parámetro pasado a FT_Library_SetLcdFilter() al cargar glifos (predeterminado: FC_LCD_DEFAULT).
FC_MINSPACE
Valor de espacio mínimo utilizado al rellenar propiedades para abrir una fuente (predeterminado: Falso).
FC_RGBA
Valor RGBA utilizado al rellenar propiedades para abrir una fuente (predeterminado: calculado llamando a XRenderQuerySubpixelOrder()).
FC_SCALE
Escala utilizada en Fontconfig (predeterminado: 1.0).
XFT_MAX_GLYPH_MEMORY
Memoria máxima para una fuente (predeterminado: 1024*1024).
XFT_RENDER
Verdadero si la pantalla soporta la extensión X Render (predeterminado: resultado de XftDefaultHasRender()).

Abrir y Emparejar Fuentes



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen toma una lista de triplas de elementos de patrón del tipo
        campo, tipo, valor (terminada con un NULL), empareja ese patrón con las fuentes disponibles, y abre la fuente emparejada, dimensionándola correctamente para la pantalla número screen en la pantalla dpy. Devuelve la fuente emparejada, o NULL si no se encuentra ninguna coincidencia.

  




Ejemplo:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
Esto abre la fuente "charter" a 12 puntos. El tamaño en puntos se convierte automáticamente al tamaño de píxel correcto según la resolución del monitor.

DESCRIPTION
:
: The Xft library provides the following functions for accessing and
: rendering fonts.
:
: The following functions are used for opening fonts:
:
: * XftFontOpenName() returns a pointer to an XftFont structure,
:   containing information about the font chosen to match the
:   given pattern.
:
: * XftFontOpen() returns a pointer to an XftFont structure,
:   containing information about the font chosen to match the
:   given pattern. This function is identical to XftFontOpenName()
:   except that it takes a Fontconfig pattern string (which is passed to
:   the Fontconfig library's FcNameParse() function).
:
: * XftFontOpenXlfd() behaves as XftFontOpen() does, except that it
:   takes a string containing an X Logical Font Description (XLFD), and
:   uses the XftXlfdParse() function.
:
: * XftFontMatch() can also be used directly to determine the
:   Fontconfig font pattern resulting from an Xft font open request.
:
: * XftXlfdParse() parses the xlfd_orig parameter according to the
:   X Logical Font Description Conventions document, but ignores some of
:   the fields: setwidth_name, add_style_name, spacing, and average_width.
:
: XftXlfdParse() creates a Fontconfig pattern, setting the property
: XFT_XLFD to the xlfd_orig value, and maps the collected information to
: Fontconfig properties. Empty or " * " fields are ignored:
:
: FC_FOUNDRY
:   from foundry.
: FC_FAMILY
:   from family.
: FC_WEIGHT
:   weight_name, defaulting to FC_WEIGHT_MEDIUM.
: FC_SLANT
:   slant, defaulting to FC_SLANT_ROMAN.
: FC_SIZE
:   point_size.
: FC_PIXEL_SIZE
:   pixel_size. If point_size was set, as well as resolution_x
:   and resolution_y, then the value is scaled convert the font's
:   height to points.
:
: Families of Functions
:
: Xft provides groups of drawing functions which differ according to the way
: the data is encoded, e.g., 8-bit (ISO-8859-1) versus UTF-8. Here is a
: summary of these related functions:
:
: +--------------------+------------------------+-----------------------+------------------------+
: | Encoding           | XftDrawString*         | XftTextExtents*       | XftTextRender*         |

: Determining Text Extents
:
: Xft provides several functions for determining the required height and
: width for displaying a text-string. After accounting for the offset, in
: cases where the string will be shifted up, down, left or right, these
: numbers are referred to as text extents.
:
: * XftTextExtents8() computes the pixel extents on display dpy of no more
:   than len glyphs of a string consisting of eight-bit characters when
:   drawn with font, storing them in extents.
:
: * XftTextExtents16() computes the pixel extents on display dpy of no more
:   than len glyphs of a string consisting of sixteen-bit characters when
:   drawn with font, storing them in extents.
:
: * XftTextExtents32() computes the pixel extents on display dpy of no more
:   than len glyphs of a string consisting of thirty-two-bit characters when
:   drawn with font, storing them in extents.
:
: * XftTextExtentsUtf8() computes the pixel extents on display dpy of no more
:   than len bytes of a UTF-8 encoded string when drawn with font, storing
:   them in extents.
:
: * XftTextExtentsUtf16() computes the pixel extents on display dpy of no more
:   than len bytes of a UTF-16LE- or UTF-16BE-encoded string when drawn with
:   font, storing them in extents. The endianness of string must be specified
:   in endian.
:
: * XftGlyphExtents() computes the pixel extents on display dpy of no more
:   than nglyphs in the array glyphs drawn with font, storing them in
:   extents.
:
:   If any of the glyphs are missing (determined by a check with
:   XftFontCheckGlyph()), the corresponding entry in extents is filled
:   with zeroes.

:

void XftDrawGlyphFontSpec (

  

    
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Dibuja una lista de glifos asociados con fuentes en coordenadas
        especificadas, pasados como un array de len estructuras
        XftGlyphFontSpec a través del parámetro glyphs. Todos los glifos
        se dibujan utilizando el color especificado en el parámetro
        color.

  





  

  
Para cada entrada en el array glyphs:






    
  
  • Si la fuente asociada utiliza la extensión X Render, entonces Xft
      utiliza XftGlyphFontSpecRender() para dibujar el glifo, utilizando una
      Picture obtenida al llamar XftDrawSrcPicture () con los
      parámetros draw y color.
    • 
  
  • De lo contrario, Xft proporciona una característica análoga usando
      Xlib.
    • 






  
void XftGlyphFontSpecRender (

  

    
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
Esto implica varios pasos:

  






    
  
  • Primero, Xft asegura que el array glyphs está completo usando
      XftFontCheckGlyph() y cargando cualquier glifo faltante con
      XftFontLoadGlyphs().
    • 
  
  • Luego Xft examina los glifos para encontrar el valor Unicode máximo.
      Eso determina el tamaño de la codificación, es decir, el width.
    • 
  
  • Luego, para cada glifo, Xft comprueba si su valor Unicode es manejado
      por la fuente correspondiente. Si no, el valor se establece a cero (0), para
      ignórarlo. Mientras hace esto, Xft también recuerda cuál fue la primera
      fuente utilizada, y calcula la posición en la que se dibujará cada
      glifo.
    • 
  
  • Xft luego construye un array equivalente de glifos en el formato esperado
      por la biblioteca X Render.
    • 
  
  • Finalmente, XftGlyphFontSpecRender() utiliza la extensión X Render para
      dibujar los glifos, con la función XRenderCompositeText*() apropiada
      según el width, y descarta los datos temporales.
    • 




  

  
Los parámetros op, dst, src, srcx, y srcy
      se utilizan como se describe en la documentación de la biblioteca X
      Render.

NAME


Xft - X FreeType library






SYNOPSIS


#include <X11/Xft/Xft.h>







DESCRIPTION


The Xft library is an X11 font library that allows applications to use
    FreeType 2 fonts. It provides functions for opening, loading, and rendering
    fonts. It also provides functions for manipulating font patterns and
    managing font data.
