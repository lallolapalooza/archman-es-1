DESCRIPTION

The XFree86-VidMode Extension allows clients to query and modify the video modes supported by the X server. This manual page describes the functions provided by the Xlib wrapper library for this extension.

XF86VidModeQueryExtension() checks if the VidMode extension is available on the specified display. If it is available, it returns the major and minor version numbers of the extension and the base numbers for events and errors generated by the extension.

XF86VidModeQueryVersion() queries the version of the XFree86-VidMode extension implemented by the server.

XF86VidModeSetClientVersion() sets the client's version of the XFree86-VidMode extension. This function should be called before any other VidMode functions.

XF86VidModeGetModeLine() retrieves the current video mode line for the specified screen.

XF86VidModeGetAllModeLines() retrieves all the video mode lines currently available on the specified screen.

XF86VidModeAddModeLine() adds a new video mode line to the server's list of modes for the specified screen. The new mode is inserted after the specified `aftermode`.

XF86VidModeDeleteModeLine() removes a video mode line from the server's list of modes for the specified screen.

XF86VidModeModModeLine() modifies an existing video mode line for the specified screen.

XF86VidModeValidateModeLine() checks if the specified mode line is valid for the specified screen.

XF86VidModeSwitchMode() switches to the next or previous video mode for the specified screen. If `zoom` is non-zero, switches to the next mode; otherwise, switches to the previous mode.

XF86VidModeSwitchToMode() switches the specified screen to the specified video mode.

XF86VidModeLockModeSwitch() locks or unlocks mode switching for the specified screen. If `lock` is non-zero, mode switching is locked.

XF86VidModeGetMonitor() retrieves information about the monitor attached to the specified screen.

XF86VidModeGetViewPort() retrieves the current viewport origin for the specified screen.

XF86VidModeSetViewPort() sets the viewport origin for the specified screen.

XF86VidModeGetDotClocks() retrieves information about the dot clocks supported by the specified screen.

XF86VidModeGetGamma() retrieves the current gamma settings for the specified screen.

XF86VidModeSetGamma() sets the gamma settings for the specified screen.

XF86VidModeGetGammaRamp() retrieves the current gamma ramp settings for the specified screen.

XF86VidModeSetGammaRamp() sets the gamma ramp settings for the specified screen.

XF86VidModeGetGammaRampSize() retrieves the size of the gamma ramp for the specified screen.

RETURN VALUES

All functions return True on success and False on failure, except for XF86VidModeValidateModeLine() which returns Status (1 if valid, 0 if invalid).

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la extensión del servidor XFree86-VidModeExtension que permite consultar y ajustar los modos de video dinámicamente y controlar el cambio de modo. Las aplicaciones que utilizan estas funciones deben enlazarse con -lXxf86vm

FUNCIONES DE MODELINE

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de video seleccionado actualmente. El programa que llama debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si hay algún valor privado del servidor (actualmente solo aplicable al servidor S3), la función asignará almacenamiento para él. Por lo tanto, si el campo privsize no es cero, el programa que llama debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de video. El programa que llama proporciona la dirección de un puntero que será establecido por la función para apuntar a un array de estructuras XF86VidModeModeInfo. La memoria ocupada por el array es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamador. El primer elemento del array corresponde al modo de video actual.

La función XF86VidModeModModeLine se puede utilizar para cambiar la configuración del modo de video actual, siempre que la configuración solicitada sea válida (por ejemplo, que no exceda las capacidades del monitor).

Para añadir un modo a la lista de modos disponibles, se puede usar la función XF86VidModeAddModeLine. Suponiendo que la configuración es válida, el modo de video se añadirá después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se añadirá después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero ocurrirá un cambio de modo al siguiente modo. El último modo restante no se puede eliminar.

La validez de un modo se puede comprobar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser utilizado por el servidor (es decir, cumple todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario devuelve un valor que indica la razón por la que el modo no es válido (tal como se define en xf86.h)

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de video al siguiente (o anterior) modo de video. La función XF86VidModeSwitchToMode se puede utilizar para cambiar directamente al modo especificado. La coincidencia se especifica en la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch se puede utilizar para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, se necesita una llamada a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado del estado de ejecución de la solicitud, se debe instalar un manejador de errores personalizado usando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información conocida por el servidor sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a un array de estructuras XF86VidModeSyncRange. Los arrays contienen nhsync y nvsync elementos, respectivamente. Los valores hi y low serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamador.

FUNCIONES DE VIEWPORT

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort se pueden utilizar para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda del viewport dentro de la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion se puede utilizar para determinar la versión de la extensión integrada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores de error y evento asignados a la extensión con el número más bajo.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulte el código fuente para obtener información sobre cómo utilizarlas.

Xorg(1), xorg.conf(5), XFlush(3), XSetErrorHandler(3), xvidtune(1)
