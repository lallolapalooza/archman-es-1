display
Especifica la conexión con el servidor X.
screen
Especifica a qué número de pantalla se aplican los ajustes.
event_base_return
Devuelve el número base de eventos para la extensión.
error_base_return
Devuelve el número base de errores para la extensión.
major_version_return
Devuelve el número de versión principal de la extensión.
minor_version_return
Devuelve el número de versión secundaria de la extensión.
dotclock_return
Devuelve el reloj para la línea de modo.
modecount_return
Devuelve el número de modos de video disponibles en el servidor.
zoom
Si es mayor que cero, indica que el servidor debe cambiar al siguiente modo, de lo contrario, cambiar al modo anterior.
lock
Indica que el cambio de modo debe ser bloqueado, si no es cero.
modeline
Especifica o devuelve los valores de temporización para un modo de video.
aftermode
Especifica los valores de temporización para el modo de video después del cual se añadirá el nuevo modo.
modesinfo
Devuelve los valores de temporización y los dotclocks para todos los modos de video disponibles.
monitor
Devuelve información sobre el monitor.
x
Especifica la ubicación X deseada para el viewport.
x_return
Devuelve la ubicación X actual del viewport.
y
Especifica la ubicación Y deseada para el viewport.
y_return
Devuelve la ubicación Y actual del viewport.

DESCRIPCIÓN

Esta extensión proporciona una interfaz para el control de la configuración de video y modos de la placa de video.

Las siguientes funciones están disponibles:

XF86VidModeQueryExtension
Verifica si la extensión XF86VidMode está disponible en el servidor X y devuelve los números base de eventos y errores.
XF86VidModeQueryVersion
Devuelve la versión de la extensión XF86VidMode soportada por el servidor.
XF86VidModeSetClientVersion
La biblioteca cliente envía su versión al servidor. Debe llamarse después de XF86VidModeQueryVersion.
XF86VidModeGetModeLine
Obtiene la línea de modo actual para la pantalla especificada.
XF86VidModeGetAllModeLines
Obtiene todas las líneas de modo disponibles para la pantalla especificada.
XF86VidModeAddModeLine
Añade una nueva línea de modo a la lista de modos para la pantalla especificada. El parámetro aftermode especifica después de qué modo existente se insertará el nuevo modo.
XF86VidModeDeleteModeLine
Elimina una línea de modo de la lista de modos para la pantalla especificada.
XF86VidModeModModeLine
Modifica una línea de modo existente para la pantalla especificada.
XF86VidModeValidateModeLine
Valida una línea de modo. Devuelve True si la línea de modo es válida, False en caso contrario.
XF86VidModeSwitchMode
Cambia al siguiente modo de video (si zoom es mayor que 0) o al modo anterior (si zoom es 0).
XF86VidModeSwitchToMode
Cambia al modo de video especificado por modeline.
XF86VidModeLockModeSwitch
Bloquea o desbloquea el cambio de modo. Si lock no es cero, el cambio de modo se bloquea.
XF86VidModeGetMonitor
Obtiene información sobre el monitor conectado a la pantalla especificada.
XF86VidModeGetViewPort
Obtiene la posición actual del viewport para la pantalla especificada.
XF86VidModeSetViewPort
Establece la posición del viewport para la pantalla especificada.
XF86VidModeGetDotClocks
Obtiene información sobre los dot clocks disponibles para la pantalla especificada.
XF86VidModeGetGamma
Obtiene la configuración gamma actual para la pantalla especificada.
XF86VidModeSetGamma
Establece la configuración gamma para la pantalla especificada.
XF86VidModeGetGammaRamp
Obtiene la rampa gamma actual para la pantalla especificada.
XF86VidModeSetGammaRamp
Establece la rampa gamma para la pantalla especificada.
XF86VidModeGetGammaRampSize
Obtiene el tamaño de la rampa gamma soportada por la pantalla especificada.

DESCRIPCIÓN

Estas funciones proporcionan una interfaz a la extensión del servidor XFree86-VidModeExtension, que permite consultar y ajustar dinámicamente los modos de video y controlar el cambio de modo. Las aplicaciones que utilizan estas funciones deben enlazarse con -lXxf86vm.

FUNCIONES DE MODELINE

La función XF86VidModeGetModeLine se utiliza para consultar la configuración del modo de video actualmente seleccionado. El programa que llama debe pasar un puntero a una estructura XF86VidModeModeLine que ya haya asignado. La función rellena los campos de la estructura.

Si hay algún valor privado del servidor (actualmente solo aplicable al servidor S3), la función asignará almacenamiento para él. Por lo tanto, si el campo privsize no es cero, el programa que llama debe llamar a Xfree(private) para liberar el almacenamiento.

XF86VidModeGetAllModeLines devuelve la configuración de todos los modos de video. El programa que llama proporciona la dirección de un puntero que será establecido por la función para apuntar a una matriz de estructuras XF86VidModeModeInfo. La memoria ocupada por la matriz es asignada dinámicamente por la función XF86VidModeGetAllModeLines y debe ser liberada por el llamante. El primer elemento de la matriz corresponde al modo de video actual.

La función XF86VidModeModModeLine se puede usar para cambiar la configuración del modo de video actual, siempre que la configuración solicitada sea válida (por ejemplo, que no exceda las capacidades del monitor).

Para añadir un modo a la lista de modos disponibles, se puede usar la función XF86VidModeAddModeLine. Asumiendo que la configuración es válida, el modo de video se añadirá después del modo existente que coincida con los tiempos especificados por el parámetro aftermode. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el parámetro aftermode es cero, el modo se añadirá después del modo actual.

Los modos se pueden eliminar con la función XF86VidModeDeleteModeLine. El modo especificado debe coincidir con un modo existente. Para ser considerado una coincidencia, todos los campos de la estructura XF86VidModeModeInfo dada deben coincidir, excepto los campos privsize y private. Si el modo a eliminar es el modo actual, primero ocurrirá un cambio de modo al siguiente modo. El último modo restante no se puede eliminar.

La validez de un modo se puede comprobar con la función XF86VidModeValidateModeLine. Si el modo especificado puede ser utilizado por el servidor (es decir, cumple con todas las restricciones impuestas a un modo por la combinación del servidor, la tarjeta y el monitor), la función devuelve MODE_OK, de lo contrario devuelve un valor que indica la razón por la que el modo es inválido (tal como se define en xf86.h).

FUNCIONES DE CAMBIO DE MODO

Cuando se llama a la función XF86VidModeSwitchMode, el servidor cambiará el modo de video al siguiente (o anterior) modo de video. La función XF86VidModeSwitchToMode se puede usar para cambiar directamente al modo especificado. La coincidencia se especifica en la descripción de la función XF86VidModeAddModeLine anterior. La función XF86VidModeLockModeSwitch se puede usar para permitir o denegar el cambio de modo, ya sea que la solicitud de cambio de modo provenga de una llamada a las funciones XF86VidModeSwitchMode o XF86VidModeSwitchToMode o de una de las secuencias de teclas de cambio de modo.

Nota: Debido a la naturaleza asíncrona del protocolo X, se necesita una llamada a XFlush si la aplicación desea ver el cambio de modo inmediatamente. Para ser informado sobre el estado de ejecución de la solicitud, se debe instalar un manejador de errores personalizado usando XSetErrorHandler antes de llamar a la función de cambio de modo.

FUNCIONES DE MONITOR

La información que el servidor conoce sobre el monitor es devuelta por la función XF86VidModeGetMonitor. Los campos hsync y vsync apuntan cada uno a una matriz de estructuras XF86VidModeSyncRange. Las matrices contienen nhsync y nvsync elementos, respectivamente. Los valores hi y low serán iguales si se dio un valor discreto en el archivo XF86Config.

Los campos vendor, model, hsync y vsync apuntan a almacenamiento asignado dinámicamente que debe ser liberado por el llamante.

FUNCIONES DE VIEWPORT

Las funciones XF86VidModeGetViewPort y XF86VidModeSetViewPort se pueden usar para, respectivamente, consultar y cambiar la ubicación de la esquina superior izquierda del viewport en la pantalla virtual.

OTRAS FUNCIONES

La función XF86VidModeQueryVersion se puede usar para determinar la versión de la extensión integrada en el servidor.

La función XF86VidModeQueryExtension devuelve los valores de error y evento asignados a la extensión con el número más bajo.

ERRORES

Las funciones XF86VidModeSetClientVersion, XF86VidModeGetDotClocks, XF86VidModeGetGamma, XF86VidModeSetGamma, XF86VidModeSetGammaRamp, XF86VidModeGetGammaRamp, XF86VidModeGetGammaRampSize y XF86VidModeGetPermissions necesitan ser documentadas. Mientras tanto, consulte el código fuente para obtener información sobre cómo utilizarlas.
