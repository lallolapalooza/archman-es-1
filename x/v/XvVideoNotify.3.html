XvVideoNotify(3) Funciones de libXv XvVideoNotify(3)

NOMBRE

XvVideoNotify - evento generado para el procesamiento de video

SINOPSIS

#include <X11/extensions/Xvlib.h>

     typedef union {
       int type;
       XvVideoNotifyEvent xvvideo;
       XvPortNotifyEvent xvport;
       long pad[24];
     } XvEvent;
     typedef struct {
       int type;
       unsigned long serial;
       Bool send_event;
       Display *display;
       Drawable drawable;
       unsigned long reason;
       XvPortID port_id;
       Time time;
     } XvVideoNotifyEvent;
type
Especifica el tipo de evento: XvVideoNotify.
serial
Número de la última solicitud procesada por el servidor.
send_event
Verdadero si el evento fue generado por una solicitud SendEvent.
display
Un puntero a la pantalla desde la que se leyó el evento.
drawable
El drawable para el que se generó el evento.
reason
La razón por la que se generó el evento: XvStarted, XvStopped, XvPreempted, XvBusy, XvHardError.
port_id
El puerto que procesa el video para el cual se generó el evento.

DESCRIPCIÓN

Los eventos XvVideoNotify se generan cuando el video se inicia, se detiene, es preempted (interrumpido) por otra solicitud de video, se ignora porque el puerto está grabbed (capturado) por otro cliente, o se interrumpe debido a un error de transmisión o recepción grave.

VER TAMBIÉN

XvPutVideo(3), XvPutStill(3), XvGetVideo(3), XvGetStill(3), XvStopVideo(3), XvSelectVideoNotify(3)
