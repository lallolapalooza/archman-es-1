XvGrabPort(3) Funciones libXv XvGrabPort(3)

NOMBRE

XvGrabPort - bloquear puerto para uso exclusivo por el cliente

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvGrabPort(Display *dpy, XvPortID port, Time time);

ARGUMENTOS

dpy
Especifica la conexión al servidor X.
port
Define el puerto a bloquear.
time
Especifica la marca de tiempo de la solicitud.

DESCRIPCIÓN

XvGrabPort(3) bloquea un puerto. Una vez que un cliente bloquea un puerto, solo ese cliente puede realizar solicitudes de video a ese puerto.

Si la marca de tiempo es anterior a la marca de tiempo actual del puerto, la solicitud XvGrabPort se ignora y se devuelve XvInvalidTime. Si el puerto ya está bloqueado por otro cliente, se devuelve XvAlreadyGrabbed. De lo contrario, devuelve un estado de Success. La marca de tiempo del puerto se actualiza cuando se procesan las siguientes solicitudes: XvGrabPort(3), XvUngrabPort(3), XvPutVideo(3), XvPutStill(3), XvGetVideo(3), XvGetStill(3).

Si el puerto está procesando activamente video para otro cliente, el video se interrumpe y se genera un evento XvVideoNotify con el detalle XvPreempted para su drawable.

VALORES DE RETORNO

[Success]
Devuelto si XvGrabPort(3) se completó con éxito.
[XvInvalidTime]
Devuelto si la marca de tiempo solicitada es anterior a la marca de tiempo actual del puerto.
[XvAlreadyGrabbed]
Devuelto si el puerto ya está bloqueado por otro cliente.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvGrabPort(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.

VER TAMBIÉN

XvUngrabPort(3), XvVideoNotify(3)
