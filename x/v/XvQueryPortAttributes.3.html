XvQueryPortAttributes(3) Funciones de libXv XvQueryPortAttributes(3)

NOMBRE

XvQueryPortAttributes - devuelve una lista de atributos de un puerto de video

SINOPSIS

#include <X11/extensions/Xvlib.h>

XvAttribute* XvQueryPortAttributes(Display *dpy,
                 XvPortID port,  int *p_num_attributes);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto cuyo adaptador se consultará para obtener su lista de atributos.
p_num_attributes
Un puntero a donde se escribirá el número de atributos devueltos en la matriz.

DESCRIPCIÓN

XvQueryPortAttributes(3)devuelveelnúmerodeatributos y una matriz de XvAttributes válidos para el puerto dado. La matriz se puede liberar con XFree(3).

VALORES DE RETORNO

XvAttribute tiene la siguiente estructura:

    typedef struct {
      int flags;
      int min_value;
      int max_value;
      char *name;
    } XvAttribute;
flags
Puede ser XvGettable o XvSettable o ambos OR'd juntos, indicando que el atributo particular es legible, escribible o legible y escribible.
min_value
Los valores mínimos de atributos que son válidos para el controlador.
Los valores máximos de atributos que son válidos para el controlador.
name
Una cadena que describe el nombre del atributo que se puede utilizar para obtener el átomo del atributo particular.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.

VER TAMBIÉN

XvGetPortAttribute(3), XvSetPortAttribute(3)
