XvGetPortAttribute(3) Funciones de libXv XvGetPortAttribute(3)

NOMBRE

XvGetPortAttribute - devuelve el valor actual de un atributo de puerto

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvGetPortAttribute(Display *dpy, XvPortID port,
                       Atom attribute, int p_value);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto, asociado con la pantalla dada, para el cual se deben devolver los valores del atributo.
attribute
Un átomo que identifica el atributo a consultar por esta solicitud. Los átomos de control se obtienen utilizando la solicitud XInternAtom con una cadena de la siguiente tabla.
p_value
Puntero a la ubicación donde se escribe el valor del atributo al regresar.

DESCRIPCIÓN

XvGetPortAttribute(3) devuelve el valor actual del atributo de puerto solicitado en el entero apuntado por p_value. El atributo se identifica utilizando un Átomo que equivale al nombre del atributo. La solicitud XInternAtom se puede usar con una de las siguientes cadenas para devolver un Átomo coincidente.

Cadena de Atributo Tipo Por Defecto
"XV_ENCODING" XvEncodingID Depende del servidor
"XV_HUE" [-1000...1000] 0
"XV_SATURATION" [-1000...1000] 0
"XV_BRIGHTNESS" [-1000...1000] 0
"XV_CONTRAST" [-1000...1000] 0

VALORES DE RETORNO

[Éxito]
Devuelto si XvGetPortAttribute(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvGetPortAttribute(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
[BadMatch]
Generado si el átomo de atributo solicitado no especifica un atributo soportado por el adaptador.

VER TAMBIÉN

XvSetPortAttribute(3), XvPortNotify(3)
