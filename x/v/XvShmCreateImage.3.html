XvShmCreateImage(3)

Paquete: libxv

Licencias: SMLNJ, HPND-sell-variant

XvShmCreateImage(3) Funciones de libXv XvShmCreateImage(3)

NOMBRE

XvCreateImage, XvShmCreateImage - crear una XvImage

SINOPSIS

#include <X11/extensions/Xvlib.h>

XvImage * XvCreateImage (Display *dpy, XvPortID port,
                         int id, char *data,
                         int width, int height);

XvImage * XvShmCreateImage (Display *dpy, XvPortID port,
                            int id, char *data,
                            int width, int height,
                            XShmSegmentInfo *shminfo);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto con el que se utilizará la XvImage.
id
Especifica el formato de la imagen a crear mediante el id de XvImageFormatValues.
data
Especifica los datos de la imagen.
width, height
Especifica el ancho y alto deseado de la imagen.

DESCRIPCIÓN

XvCreateImage(3) es similar a XCreateImage(3). XvShmCreateImage(3) es similar a XShmCreateImage(3). La biblioteca asignará la estructura XvImage y rellenará todos los campos excepto el de data. El width y height pueden ampliarse en algunos formatos YUV. El tamaño del búfer de datos que necesita ser asignado se indicará en el campo data_size de la XvImage. Los datos de la imagen no son asignados por esta función. El cliente puede pasar un puntero a la memoria preasignada como data o puede asignar la memoria y rellenar el campo data de la estructura XvImage después de que el campo data_size haya sido rellenado por el servidor. La estructura XvImage puede ser liberada por XFree(3). Los segmentos de memoria compartida se conectan/desconectan con XShmAttach(3)/XShmDetach(3).

VALORES DE RETORNO

XvImage tiene la siguiente estructura:

typedef struct {
   int id;
   int width, height;
   int data_size;
   int num_planes;
   int *pitches;
   int *offsets;
   char *data;
   XPointer obdata;
} XvImage;
id
Un descriptor para el formato de la estructura XvImageFormatValues devuelta por XvListImageFormats(3).
width, height
El ancho y alto de la imagen en píxeles.
data_size
El tamaño del búfer de datos en bytes.
num_planes
El número de planos de imagen.
pitches
Un array de tamaño num_planes que indica el paso de línea de escaneo en bytes. Cada plano puede tener un paso diferente.
offsets
Un array de tamaño num_planes que indica el desplazamiento en bytes desde data hasta el inicio de cada plano.
data
Un puntero al inicio del búfer de datos.
obdata
Un campo privado para mantener información SHM. Este campo será configurado por las bibliotecas cliente para que el programador generalmente no necesite preocuparse por él.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
[XvBadAlloc]
Generado si el servidor X no pudo asignar los recursos necesarios para completar la operación.
[BadMatch]
Generado si se suministraron argumentos incompatibles, como un puerto que no es capaz de mostrar XvImages.

VER TAMBIÉN

XvListImageFormats(3), XCreateImage(3), XShmCreateImage(3), XShmAttach(3), XShmDetach(3).
