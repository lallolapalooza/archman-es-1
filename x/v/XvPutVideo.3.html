XvPutVideo(3) Funciones de libXv XvPutVideo(3)

NOMBRE

XvPutVideo - escribir vídeo en un drawable

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvPutVideo(Display *dpy, XvPortID port, Drawable d, GC gc,
               int vx, int vy, unsigned int vw, unsigned int vh,
               int dx, int dy, unsigned int dw, unsigned int dh);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Define el puerto del que obtener el vídeo.
d
Define el drawable (ventana) en el que se va a escribir el vídeo.
gc
Define el contexto gráfico. Los componentes del GC son: subwindow-mode, clip-x-origin, clip-y-origin y clip-mask.
vx,vy,vw,vh
Definen el tamaño y la ubicación de la región de origen (vídeo) a escribir. vx e vy definen el píxel superior izquierdo de la región. vw y vh definen el ancho y la altura, en píxeles, de la región.
dx,dy,dw,dh
Definen la ubicación y el tamaño de la región de destino (drawable) en la que se escribe la imagen de vídeo. dx e dy definen el píxel superior izquierdo de la región. dw y dh definen el ancho y la altura, en píxeles, de la región.

DESCRIPCIÓN

XvPutVideo escribe vídeo en un drawable. La posición y el tamaño del rectángulo de origen (vídeo) se especifican mediante vx, vy, vw y vh. La posición y el tamaño del rectángulo de destino (drawable) se especifican mediante dx, dy, dw y dh.

Los datos de vídeo se recortan a los límites de la codificación de vídeo, se escalan al tamaño de la región de drawable solicitada (o al tamaño más cercano soportado) y se recortan a los límites del drawable.

Si el vídeo se inicia correctamente, se genera un evento XvVideoNotify con el detalle XvStarted para el drawable. Si el puerto ya está en uso, su vídeo se interrumpe, y si el nuevo drawable es diferente del anterior, se genera un evento XvVideoNotify con el detalle XvPreempted para el drawable antiguo. Si el puerto está ocupado por otro cliente, esta solicitud se ignora y se genera un evento XvVideoNotify con el detalle XvBusy para el drawable. Si el puerto no recibe una señal de vídeo válida o si la señal de vídeo se interrumpe mientras el vídeo está activo, se genera un evento VideoNotify con el detalle XvHardError para el drawable.

VALORES DE RETORNO

[Éxito]
Devuelto si XvPutVideo(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si hubo recursos insuficientes para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
[BadDrawable]
Generado si el drawable solicitado no existe.
[BadGC]
Generado si el contexto gráfico solicitado no existe.
[BadAlloc]
Generado si hubo recursos insuficientes para procesar la solicitud.

VER TAMBIÉN
