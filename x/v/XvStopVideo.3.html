XvStopVideo(3) Funciones de libXv XvStopVideo(3)

NOMBRE

XvStopVideo - detener video activo

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvStopVideo(Display *dpy, XvPortID port, Drawable draw);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto para el cual se debe detener el video.
draw
Especifica el drawable asociado con el puerto nombrado.

DESCRIPCIÓN

XvStopVideo(3) detiene el video activo para el puerto y drawable especificados. Si el puerto no está procesando video, o si está procesando video en un drawable diferente, la solicitud se ignora. Cuando el video se detiene, se genera un evento XvVideoNotify(3) con el detalle XvStopped para el drawable asociado.

VALORES DE RETORNO

[Éxito]
Devuelto si XvStopVideo(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvStopVideo(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
[BadDrawable]
Generado si el drawable solicitado no existe.

VER TAMBIÉN

XvGetVideo(3), XvPutVideo(3), XvVideoNotify(3)
