XvPortNotify(3) Funciones de libXv XvPortNotify(3)

NOMBRE

XvPortNotify - evento generado cuando cambian los atributos del puerto

SINOPSIS

#include <X11/extensions/Xvlib.h>

     typedef union {
       int type;
       XvVideoNotifyEvent xvvideo;
       XvPortNotifyEvent xvport;
       long pad[24];
     } XvEvent;
     typedef struct {
       int type;
       unsigned long serial;
       Bool send_event;
       Display *display;
       XvPortID port_id;
       Time time;
       Atom attribute;
       long value;
     } XvPortNotifyEvent;
type
Especifica el tipo de evento: XvPortNotify.
serial
Número de la última solicitud procesada por el servidor.
send_event
Verdadero si el evento fue generado por una solicitud SendEvent.
display
Un puntero a la pantalla desde la que se leyó el evento.
port_id
El puerto cuyo atributo ha cambiado.
attribute
Un átomo que especifica el atributo que cambió.
value
El nuevo valor del atributo.

DESCRIPCIÓN

Los eventos XvPortNotify se generan cuando se establece un atributo de puerto utilizando la función XvSetPortAttribute(3).

VER TAMBIÉN

XvSetPortAttribute(3), XvGetPortAttribute(3), XvSelectPortNotify(3).
