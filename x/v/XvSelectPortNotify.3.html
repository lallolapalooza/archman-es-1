NOMBRE

XvSelectPortNotify - habilitar o deshabilitar eventos XvPortNotify

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvSelectPortNotify(Display *dpy, XvPortID port, Bool onoff);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto para el cual se generarán eventos PortNotify cuando sus atributos sean modificados usando XvSetPortAttribute(3)
onoff
Especifica si la notificación se habilitará o deshabilitará.

DESCRIPCIÓN

XvSelectPortNotify(3) habilita o deshabilita la entrega de eventos PortNotify al cliente solicitante. Los eventos XvPortNotify(3) se generan cuando los atributos del puerto son modificados usando XvSetPortAttribute(3).

VALORES DE RETORNO

[Éxito]
Devuelto si XvSelectPortNotify(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvSelectPortNotify(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.

VER TAMBIÉN

XvSetPortNotify(3), XvSetPortAttribute(3), XvPortNotify(3)
