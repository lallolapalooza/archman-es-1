XvQueryEncodings(3) Funciones de libXv XvQueryEncodings(3)

NOMBRE

XvQueryEncodings - devuelve la lista de codificaciones para un adaptador

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvQueryEncodings(Display *dpy, XvPortID port,
                     unsigned int *p_num_encodings,
                     XvEncodingInfo **pp_encoding_info);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto cuyo adaptador se va a consultar por su lista de codificaciones.
p_num_encodings
Un puntero a donde se escribe el número de codificaciones admitidas por el adaptador.
pp_encoding_info
Un puntero a donde se devuelve la lista de información de codificación recibida. XvEncodingInfo tiene la siguiente estructura: 
    typedef struct {
      XvEncodingID encoding_id;
      char *name;
      unsigned long width;
      unsigned long height;
      XvRational rate;
      unsigned long num_encodings;
    } XvEncodingInfo;
encoding_id
Especifica el id de codificación de la codificación. El id de codificación se utiliza para identificar una codificación cuando se cambia el atributo de codificación de un puerto.
name
Un puntero a una cadena de texto con formato que identifica la codificación. La cadena tiene el formato "timing-signaltype". Por ejemplo "ntsc-composite".
width,height
El ancho y alto, en píxeles, de la imagen de vídeo decodificada.
rate
La tasa de campo del vídeo decodificado.

La estructura XvRational se utiliza para especificar un número fraccionario. Tiene la siguiente estructura:

    typedef struct {
      int numerator;
      int denominator;
    } XvRational;

Los campos numerator y denominator especifican las partes apropiadas de un número fraccionario.

DESCRIPCIÓN

XvQueryEncodings(3) devuelve información de codificación sobre un adaptador. Cada codificación se describe mediante la estructura XvEncodingInfo descrita anteriormente. Las codificaciones se identifican mediante un id de codificación, que puede utilizarse para establecer o obtener el atributo de codificación de un puerto.

VALORES DE RETORNO

[Éxito]
Devuelto si XvQueryEncodings(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvQueryEncodings(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
