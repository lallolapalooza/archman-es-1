NOMBRE

XvQueryAdaptors - devuelve información del adaptador para una pantalla

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvQueryAdaptors(Display *dpy, Window window,
                    unsigned int *p_num_adaptors,
                    XvAdaptorInfo **pp_adaptor_info);

ARGUMENTOS

dpy
Especifica la conexión al servidor X.
window
Especifica una ventana de la pantalla para la que se desea la información del adaptador.
p_num_adaptors
Un puntero donde se devuelve el número de adaptadores para la pantalla especificada.
pp_adaptor_info
Un puntero donde se devuelve la lista de la información del adaptador devuelta.

DESCRIPCIÓN

XvQueryAdaptors(3)
devuelve información del adaptador de video para la pantalla del dibujable especificado. La estructura XvAdaptorInfo tiene la siguiente organización:

     typedef struct {
       XvPortID base_id;
       unsigned long num_ports;
       char type;
       char *name;
       unsigned long num_formats;
       XvFormat *formats;
       unsigned long num_adaptors;
     } XvAdaptorInfo;
base_id
El ID del recurso de el primer puerto del adaptador.
num_ports
El número de puertos soportados por el adaptador.
type
Una máscara de bits con el valor XvInputMask activado si el adaptador soporta entrada de video, y el valor XvOutputMask activado si el adaptador soporta salida de video. En el protocolo Xv 2.2 y posteriores, se definen 3 bits nuevos: XvVideoMask, XvStillMask y XvImageMask, que indican que el adaptador es capaz de primitivas de video, fijas o de imagen, respectivamente.
name
Un nombre específico del proveedor que identifica al adaptador.
num_formats
El número de formatos de profundidad/visual soportados por el adaptador.
formats
Un puntero a una matriz de estructuras XvFormat.

La estructura XvFormat tiene la siguiente organización:

     typedef struct {
       char depth;
       unsigned long visual_id;
     } XvFormat;
depth
Una profundidad de dibujable soportada por el adaptador.
visual_id
Un ID visual soportado para la profundidad dada por el adaptador.

VALORES DE RETORNO

[Éxito]
Devuelto si XvQueryAdaptors(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvQueryAdaptors(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[Dibujable]
Devuelto si el dibujable solicitado no existe.
