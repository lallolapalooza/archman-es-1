XvQueryBestSize(3) Funciones de libXv XvQueryBestSize(3)

NOMBRE

XvQueryBestSize - determinar el tamaño óptimo de la región de dibujo

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvQueryBestSize(Display *dpy, XvPort port, Bool motion,
                    unsigned int vw, unsigned int vh,
                    unsigned int dw, unsigned int dh,
                    unsigned int *p_dw, unsigned int *p_dh);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Define el puerto asociado con la pantalla y el adaptador para el cual se calculará el tamaño óptimo.
motion
Especifica True si el tamaño de destino necesita soportar movimiento completo, y False si el tamaño de destino solo necesita soportar imágenes fijas.
vw,vh
Especifica el tamaño deseado de la región de video fuente.
dw,dh
Especifica el tamaño deseado de la región de dibujo de destino.
p_dw,p_dh
Punteros a dónde se devolverán los tamaños de destino más cercanos soportados por el servidor.

DESCRIPCIÓN

Algunos puertos pueden ser capaces de escalar video entrante o saliente. XvQueryBestSize(3) devuelve el tamaño de la región de destino más cercana que es soportada por el adaptador. Se garantiza que el tamaño devuelto será menor que el tamaño solicitado si se soporta un tamaño menor.

VALORES DE RETORNO

[Éxito]
Devuelto si XvQueryBestSize(3) se completó con éxito.
[XvBadExtension]
Devuelto si la extensión Xv no está disponible.
[XvBadAlloc]
Devuelto si XvQueryBestSize(3) no pudo asignar memoria para procesar la solicitud.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
