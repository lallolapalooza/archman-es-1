XvListImageFormats(3)

Paquete: libxv

Licencias: SMLNJ, HPND-sell-variant

XvListImageFormats(3) Funciones de libXv XvListImageFormats(3)

NOMBRE

XvListImageFormats - devuelve la lista de formatos de imagen compatibles con un puerto de vídeo

SINTAXIS

#include <X11/extensions/Xvlib.h>

XvImageFormatValues * XvListImageFormats (Display *dpy,
                 XvPortID port,  int *p_num_formats);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
Especifica el puerto cuyo adaptador se va a consultar para obtener su lista de atributos.
p_num_formats
Un puntero a donde se escribe el número de formatos devueltos en la matriz.

DESCRIPCIÓN

XvListImageFormats(3) devuelve los XvImageFormatValues compatibles con el puerto especificado. Esta lista debe liberarse con XFree(3).

VALORES DE RETORNO

XvImageFormatValues tiene la siguiente estructura:

    typedef struct {
      int id;                      /* Identificador único para el formato */
      int type;                    /* XvRGB, XvYUV */
      int byte_order;              /* LSBFirst, MSBFirst */
      char guid[16];               /* Identificador único global */
      int bits_per_pixel;
      int format;                  /* XvPacked, XvPlanar */
      int num_planes;
      /* para formatos RGB */
      int depth;
      unsigned int red_mask;
      unsigned int green_mask;
      unsigned int blue_mask;
      /* para formatos YUV */
      unsigned int y_sample_bits;
      unsigned int u_sample_bits;
      unsigned int v_sample_bits;
      unsigned int horz_y_period;
      unsigned int horz_u_period;
      unsigned int horz_v_period;
      unsigned int vert_y_period;
      unsigned int vert_u_period;
      unsigned int vert_v_period;
      char component_order[32];    /* ej. UYVY */
      int scanline_order;          /* XvTopToBottom, XvBottomToTop */
    } XvImageFormatValues;
id
Un identificador único para el formato. A menudo es el FOURCC para el formato, cuando es aplicable. Este id se utiliza para describir el formato durante la creación de XvImage.
type
XvRGB o XvYUV.
byte_order
El orden de bytes de la imagen. Es LSBFirst o MSBFirst.
guid
El Identificador Único Global (también conocido como Identificador Universalmente Único). Cuando no es aplicable, todos los caracteres son NULL.
bits_per_pixel
Los bits ocupados (pero no necesariamente utilizados) por cada píxel. Tenga en cuenta que para algunos formatos planares que tienen bits fraccionarios por píxel (como IF09) este número puede redondearse _hacia abajo_.
format
XvPacked o XvPlanar.
num_planes
El número de planos en formatos planares.
depth
Bits significativos por píxel.
red_mask, green_mask, blue_mask
Las máscaras de bits rojo, verde y azul (solo formatos RGB).
?_sample_bits
El tamaño de cada muestra en bits (solo formatos YUV).
horz_?_period, vert_?_period
El período (en píxeles) en el que ocurren las muestras en las direcciones horizontal y vertical (solo formatos YUV).
component_order
Caracteres ASCII en mayúsculas que representan el orden en que se almacenan las muestras dentro de formatos empaquetados. Para formatos planares, esto representa el orden de los planos.
scanline_order
XvTopToBottom o XvBottomToTop.

NOTAS

Dado que algunos formatos (particularmente algunos formatos YUV planares) pueden no estar completamente definidos por los parámetros anteriores, el guid, cuando esté disponible, debería proporcionar la descripción más precisa del formato.

DIAGNÓSTICOS

[XvBadPort]
Generado si el puerto solicitado no existe.
