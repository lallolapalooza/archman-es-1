XvPutImage(3) Funciones de libXv XvPutImage(3)

NOMBRE

XvPutImage, XvShmPutImage - mostrar una XvImage

SINOPSIS

#include <X11/extensions/Xvlib.h>

int XvPutImage (Display *dpy, XvPortID port,
                Drawable d, GC gc, XvImage *image,
                int src_x, int src_y,
                unsigned int src_w, unsigned int src_h,
                int dest_x, int dest_y,
                unsigned int dest_w, unsigned int dest_h);

int XvShmPutImage (Display *dpy, XvPortID port,
                   Drawable d, GC gc, XvImage *image,
                   int src_x, int src_y,
                   unsigned int src_w, unsigned int src_h,
                   int dest_x, int dest_y,
                   unsigned int dest_w, unsigned int dest_h,
                   Bool send_event);

ARGUMENTOS

dpy
Especifica la conexión con el servidor X.
port
El ID del puerto de un puerto en un adaptador capaz de XvImage.
d
gc
el contexto gráfico que especifica la máscara de recorte a usar, si la hay.
image
Un puntero a la XvImage a mostrar.
src_?
La porción de la XvImage a mostrar.
dest_?
La porción del dibujo de destino a rellenar por la imagen.
send_event
Indica si se debe enviar o no un evento XShmCompletionEvent. Si se envía, los campos major_code y minor_code del evento indicarán el código principal de la extensión Xv y el código secundario de XvShmPutImage.

DESCRIPCIÓN

XvPutImage(3) es similar a XPutImage(3). XvShmPutImage(3) es similar a XShmPutImage(3). La biblioteca asignará la estructura XvImage y rellenará todos los campos excepto data. Width y height pueden ser ampliados en algunos formatos YUV. El tamaño del búfer de datos que necesita ser asignado se dará en el campo data_size en la XvImage. Los datos de la imagen no son asignados por esta función. El cliente puede pasar un puntero a la memoria preasignada como data o puede asignar la memoria y rellenar el campo de datos de la estructura XvImage después de que el campo data_size haya sido rellenado por el servidor. La estructura XvImage puede ser liberada por XFree(3).

DIAGNÓSTICO

[XvBadPort]
Generado si el puerto solicitado no existe.
[XvBadAlloc]
Generado si el servidor X no pudo asignar los recursos necesarios para completar la operación.
[BadMatch]
Generado si se suministraron argumentos incompatibles, como un puerto que no es capaz de mostrar XvImages.
[BadShmSegCode]
Generado si se especifica un segmento de memoria compartida inválido.
