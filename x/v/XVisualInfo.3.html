XVisualInfo(3)

Paquete: libx11

Licencias: MIT AND X11

XGetVisualInfo(3) FUNCIONES DE XLIB XGetVisualInfo(3)

NOMBRE

XGetVisualInfo, XMatchVisualInfo, XVisualIDFromVisual, XVisualInfo - obtener información visual y estructura visual

SINTAXIS

XVisualInfo *XGetVisualInfo(Display *display, long vinfo_mask, XVisualInfo *vinfo_template, int *nitems_return);

Status XMatchVisualInfo(Display *display, int screen, int depth, int class, XVisualInfo *vinfo_return);

VisualID XVisualIDFromVisual(Visual *visual);

ARGUMENTOS

class
Especifica la clase de la pantalla.
depth
Especifica la profundidad de la pantalla.
display
Especifica la conexión con el servidor X.
nitems_return
Devuelve el número de estructuras visuales coincidentes.
screen
Especifica la pantalla.
visual
Especifica el tipo visual.
vinfo_mask
Especifica el valor de la máscara visual.
vinfo_return
Devuelve la información visual coincidente.
vinfo_template
Especifica los atributos visuales que se utilizarán para hacer coincidir las estructuras visuales.

DESCRIPCIÓN

La función XGetVisualInfo devuelve una lista de estructuras visuales que tienen atributos iguales a los especificados por vinfo_template. Si ninguna estructura visual coincide con la plantilla utilizando la vinfo_mask especificada, XGetVisualInfo devuelve NULL. Para liberar los datos devueltos por esta función, utilice XFree.

La función XMatchVisualInfo devuelve la información visual para un visual que coincide con la profundidad y clase especificadas para una pantalla. Dado que pueden existir múltiples visuales que coincidan con la profundidad y clase especificadas, el visual exacto elegido no está definido. Si se encuentra un visual, XMatchVisualInfo devuelve un valor distinto de cero y la información del visual en vinfo_return. De lo contrario, cuando no se encuentra un visual, XMatchVisualInfo devuelve cero.

La función XVisualIDFromVisual devuelve el ID visual para el tipo visual especificado.

ESTRUCTURAS

La estructura XVisualInfo contiene:

/* Bits de máscara de información visual */

#define VisualNoMask 0x0
#define VisualIDMask 0x1
#define VisualScreenMask 0x2
#define VisualDepthMask 0x4
#define VisualClassMask 0x8
#define VisualRedMaskMask 0x10
#define VisualGreenMaskMask 0x20
#define VisualBlueMaskMask 0x40
#define VisualColormapSizeMask 0x80
#define VisualBitsPerRGBMask 0x100
#define VisualAllMask 0x1FF 
/* Valores */
typedef struct {
        Visual *visual;
        VisualID visualid;
        int screen;
        int depth;
        int class;
        unsigned long red_mask;
        unsigned long green_mask;
        unsigned long blue_mask;
        int colormap_size;
        int bits_per_rgb;
} XVisualInfo;
