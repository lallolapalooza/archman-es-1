XNoExposeEvent(3)

Paquete: libx11

Licencias: MIT AND X11

XGraphicsExposeEvent(3) FUNCIONES XLIB XGraphicsExposeEvent(3)

NOMBRE

XGraphicsExposeEvent, XNoExposeEvent - estructuras de eventos GraphicsExpose y NoExpose

ESTRUCTURAS

Las estructuras para los eventos GraphicsExpose y NoExpose contienen:

typedef struct {
        int type;       /* GraphicsExpose */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* verdadero si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del cual se leyó el evento */
        Drawable drawable;
        int x, y;
        int width, height;
        int count;      /* si no es cero, al menos tantos más */
        int major_code; /* core es CopyArea o CopyPlane */
        int minor_code; /* no definido en el core */
} XGraphicsExposeEvent;
typedef struct {
        int type;       /* NoExpose */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* verdadero si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del cual se leyó el evento */
        Drawable drawable;
        int major_code; /* core es CopyArea o CopyPlane */
        int minor_code; /* no definido en el core */
} XNoExposeEvent;

Cuando recibes estos eventos, los miembros de su estructura se configuran de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero a la pantalla en la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero se expande de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

Ambas estructuras tienen estos miembros comunes: drawable, major_code y minor_code. El miembro drawable se establece en el drawable de la región de destino en la que se iba a realizar la solicitud de gráficos. El miembro major_code se establece en la solicitud de gráficos iniciada por el cliente y puede ser X_CopyArea o X_CopyPlane. Si es X_CopyArea, una llamada a XCopyArea inició la solicitud. Si es X_CopyPlane, una llamada a XCopyPlane inició la solicitud. Estas constantes están definidas en X11/Xproto.h. El miembro minor_code, al igual que el miembro major_code, indica qué solicitud de gráficos fue iniciada por el cliente. Sin embargo, el miembro minor_code no está definido por el protocolo X principal y será cero en estos casos, aunque puede ser utilizado por una extensión.

La estructura XGraphicsExposeEvent tiene estos miembros adicionales: x, y, width, height y count. Los miembros x e y se establecen en las coordenadas relativas al origen del drawable e indican la esquina superior izquierda del rectángulo. Los miembros width y height se establecen en el tamaño (extensión) del rectángulo. El miembro count se establece en el número de eventos GraphicsExpose que seguirán. Si count es cero, no seguirán más eventos GraphicsExpose para esta ventana. Sin embargo, si count es distinto de cero, seguirán al menos esa cantidad de eventos GraphicsExpose (y posiblemente más) para esta ventana.
