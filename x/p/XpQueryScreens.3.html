XpQueryScreens(3)

Paquete: libxp

XpQueryScreens(3Xp) FUNCIONES DE XPRINT XpQueryScreens(3Xp)

NOMBRE

XpQueryScreens - Consulta un servidor X para determinar qué pantallas, de todas las pantallas del servidor, admiten la Extensión del Servicio de Impresión X

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

Screen **XpQueryScreens ( display, list_count_return )
Display *display;
int *list_count_return;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
list_count_return
Devuelve el número de pantallas en la lista.

DESCRIPCIÓN

Esta solicitud devuelve un puntero no NULL a una lista de punteros de pantalla si una o más pantallas admiten la Extensión del Servicio de Impresión X; de lo contrario, devuelve NULL.

XpQueryScreens determina si la Extensión del Servicio de Impresión X está presente y, si es así, cuáles de todas las pantallas del servidor X admiten la Extensión del Servicio de Impresión X. A diferencia de muchas otras extensiones, la Extensión del Servicio de Impresión X puede estar restringida a un subconjunto de todas las pantallas disponibles; por ejemplo, un único servidor X puede admitir visualizaciones de vídeo en algunas pantallas y impresoras en otras.

La lista de punteros de pantalla puede liberarse llamando a XFree.
