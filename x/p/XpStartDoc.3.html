XpStartDoc(3Xp) FUNCIONES DE XPRINT XpStartDoc(3Xp)

NOMBRE

XpStartDoc - Indica el inicio de un documento de impresión.

SINOPSIS


cc [ flag... ] archivo... -lXp [ librería... ]
#include <X11/extensions/Print.h>

void XpStartDoc ( display, type )
Display *display;
XPDocumentType type;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
type
Especifica el tipo de documento. Puede ser XPDocRaw o XPDocNormal.

DESCRIPCIÓN

XpStartDoc señala el inicio de un nuevo documento de impresión.

Si type es XPDocRaw, entonces el cliente proporcionará todos los datos para el documento resultante utilizando XpPutDocumentData; el Servidor de Impresión X no escribirá ningún dato en el documento resultante. Llamar a XpStartPage en un documento XPDocRaw generará un error XPBadSequence. Para más información, ver XpPutDocumentData.

Si type es XPDocNormal, entonces el Servidor de Impresión X generará datos del documento, y dependiendo del controlador DDX, puede incorporar datos adicionales de XpPutDocumentData en la salida. Para más información, ver XpPutDocumentData.

Todos los cambios en el pool de atributos XPDocAttr (ver XpSetAttributes) deben hacerse antes de llamar a XpStartDoc, después de lo cual se generará un XPBadSequence si se intentan realizar cambios, hasta que se llame a XpEndDoc.

La aplicación no está obligada a llamar a XpStartDoc y XpEndDoc en el proceso de impresión. La delimitación de "documento" puede no ser útil desde la perspectiva de la aplicación o del gestor de colas, por lo tanto, es opcional. Si se llama a XpStartPage inmediatamente después de XpStartJob, el Servidor de Impresión X asumirá un XpStartDoc sintético con XPDocNormal antes de XpStartPage (es decir, los eventos XPStartDocNotify y XPStartPageNotify tendrán el mismo número de secuencia). De manera similar, si se llama a XpEndJob inmediatamente después de XpEndPage, el Servidor de Impresión X asumirá un XpEndDoc sintético antes de XpEndJob (es decir, los eventos XPEndDocNotify y XPEndJobNotify tendrán el mismo número de secuencia).

Para los clientes que seleccionan XPPrintMask (ver XpSelectInput), se generará el evento XPPrintNotify con su campo de detalle establecido en XPStartDocNotify.

ESTRUCTURAS

Los valores de XPDocumentType se definen en <X11/extensions/Print.h>:

    #define   XPDocNormal     1     /∗ Los datos del doc son manejados por el Xserver*/
    #define   XPDocRaw        2     /∗ Los datos del doc se pasan a través del Xserver*/

DIAGNÓSTICOS

XPBadContext
No se ha establecido un id de contexto de impresión válido antes de hacer esta llamada.
XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas a la Extensión de Servicio de Impresión X (ejemplo, XpEndDoc antes de XpStartDoc).
BadValue
El valor especificado para type no es válido.
