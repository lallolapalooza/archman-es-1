XpSetContext(3Xp) FUNCIONES DE XPRINT XpSetContext(3Xp)

NOMBRE

XpSetContext - Establece o anula el contexto de impresión con la conexión de pantalla especificada al Servidor de Impresión X.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

void XpSetContext ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
print_context
Un contexto de impresión preexistente en el mismo Servidor X.

DESCRIPCIÓN

XpSetContext establece el contexto de impresión para una conexión de pantalla. Todas las operaciones de impresión posteriores que no tomen explícitamente un ID de contexto de impresión (por ejemplo, XpStartJob) en la pantalla usarán y actuarán sobre el contexto de impresión establecido por esta llamada, hasta que el contexto de impresión se anule o se llame a XpDestroyContext. El contexto de impresión se puede establecer y usar en múltiples trabajos, si no se destruye.

Si print_context es None, XpSetContext anulará (desasociará) el contexto de impresión previamente asociado con la pantalla. Si no había un contexto de impresión asociado previamente, no se realiza ninguna acción. El contenido del contexto de impresión anteriormente asociado no se ve afectado por esta llamada, y otras conexiones de pantalla pueden seguir utilizando el contexto de impresión.

Dado que las capacidades de las fuentes pueden variar de una impresora a otra, XpSetContext puede modificar la lista de fuentes disponibles (ver XListFonts) en la pantalla, y el conjunto real de fuentes utilizables (ver XLoadFont). Una combinación única de fuentes puede estar disponible dentro de un contexto de impresión dado; un cliente no debe asumir que todas las fuentes disponibles cuando no hay un contexto de impresión establecido estarán disponibles cuando se establezca un contexto de impresión.

Cuando se establece un contexto de impresión en una conexión de pantalla, el comportamiento predeterminado de ListFonts y ListFontsWithInfo es listar todas las fuentes normalmente asociadas con el servidor de impresión X (es decir, fuentes que contienen glifos), así como cualquier fuente interna de la impresora definida para la impresora. El atributo xp-listfonts-modes se proporciona para que las aplicaciones puedan controlar el comportamiento de ListFonts y ListFontsWithInfo y se utiliza típicamente para mostrar solo fuentes internas de la impresora. Usar solo fuentes internas de la impresora es útil por razones de rendimiento; los glifos asociados con la fuente están contenidos dentro de la impresora y no tienen que ser descargados.

Si el valor de xp-listfonts-modes incluye xp-list-glyph-fonts, ListFonts y ListFontsWithInfo incluirán todas las fuentes disponibles para el servidor que tengan glifos asociados con ellas. Si el valor de xp-listfonts-modes incluye xp-list-internal-printer-fonts, entonces ListFonts y ListFontsWithInfo incluirán todas las fuentes definidas como fuentes internas de la impresora.

Cuando se anula el contexto de impresión o se llama a XpDestroyContext, las fuentes disponibles en la pantalla vuelven a ser las que eran anteriormente.

DIAGNOSTICO

XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.

VER TAMBIÉN

XpDestroyContext(3Xp), XpStartJob(3Xp)
