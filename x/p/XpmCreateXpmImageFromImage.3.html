XpmCreateXpmImageFromImage(3)

Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmCreateXpmImage(3) Funciones de libXpm XpmCreateXpmImage(3)

NOMBRE

XpmCreateXpmImage - crear una imagen Xpm

SINOPSIS

int XpmCreateXpmImageFromData(char **data, XpmImage *image,
XpmInfo *info);
int XpmCreateXpmImageFromBuffer(char *buffer, XpmImage *image,
XpmInfo *info);
int XpmCreateXpmImageFromImage(Display *display,
XImage *image, XImage *shapeimage,
XpmImage *xpmimage, XpmAttributes *attributes);
int XpmCreateXpmImageFromPixmap(Display *display,
Pixmap *pixmap, Pixmap *shapemask,
XpmImage *xpmimage, XpmAttributes *attributes);

ARGUMENTOS

data
Especifica la ubicación de los datos.
image
Especifica la ubicación de la estructura de la imagen.
info
Especifica la ubicación de una estructura XpmInfo para obtener y almacenar información (o NULL).
display
Especifica la conexión con el servidor X.
image
Especifica la imagen X utilizada como origen.
shapeimage
Especifica la máscara de forma, si la hay.
xpmimage
Especifica la imagen XPM que se crea.
attributes
Especifica la ubicación de una estructura que contiene información (o NULL).

DESCRIPCION

XpmCreateXpmImageFromBuffer

Para crear una XpmImage a partir de un búfer XPM, usa XpmCreateXpmImageFromBuffer(). La función XpmCreateXpmImageFromBuffer() lee el búfer dado para rellenar la estructura XpmImage proporcionada. Si el búfer no contiene datos XPM válidos, devuelve XpmFileInvalid. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory. En caso de éxito, devuelve XpmSuccess. Si el puntero a la estructura XpmInfo pasado no es NULL, XpmCreateXpmImageFromBuffer() busca los siguientes atributos: XpmReturnComments y XpmReturnExtensions, y posiblemente establece el atributo XpmHotspot al devolver. Como se especifica en la tabla (página 28), si los datos relacionados con los atributos XpmReturnComments y XpmReturnExtensions no se pueden devolver según lo solicitado debido a una insuficiente cantidad de memoria, XpmCreateXpmImageFromBuffer() cambiará la máscara de valores para mencionarlo e intentará continuar. Por lo tanto, el llamante debe verificar esto antes de acceder a los datos solicitados.

Nota: La máscara de valores de la estructura XpmInfo pasada debe establecerse en algún valor válido, al menos cero, de lo contrario pueden producirse errores impredecibles.

XpmCreateXpmImageFromData

Para crear una XpmImage a partir de datos XPM, usa XpmCreateXpmImageFromData(). XpmCreateXpmImageFromData() rellena la estructura XpmImage proporcionada a partir de los datos dados. Si los datos no contienen datos XPM válidos, devuelve XpmFileInvalid. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory. En caso de éxito, devuelve XpmSuccess. Si el puntero a la estructura XpmInfo pasado no es NULL, XpmCreateXpmImageFromData() busca los siguientes atributos: XpmReturnExtensions, y posiblemente establece el atributo XpmHotspot al devolver. Como se especifica en la tabla (página 28), si los datos relacionados con el atributo XpmReturnExtensions no se pueden devolver según lo solicitado debido a una insuficiente cantidad de memoria, XpmCreateXpmImageFromData() cambiará la máscara de valores para mencionarlo e intentará continuar. Por lo tanto, el llamante debe verificar esto antes de acceder a los datos solicitados.

Nota: La máscara de valores de la estructura XpmInfo pasada debe establecerse en algún valor válido, al menos cero, de lo contrario pueden producirse errores impredecibles.

XpmCreateXpmImageFromImage

Para crear una XpmImage a partir de una XImage, usa XpmCreateXpmImageFromImage(). A partir de las imágenes X dadas y XpmAttributes si no es NULL, XpmCreateXpmImageFromImage() crea una XpmImage siguiendo el mismo mecanismo que XpmWriteFileFromImage(3).

XpmCreateXpmImageFromPixmap

Para crear una XpmImage a partir de un Pixmap, usa XpmCreateXpmImageFromPixmap(). A partir de los pixmaps dados y XpmAttributes si no es NULL, XpmCreateXpmImageFromPixmap() obtiene las XImages relacionadas llamando a XGetImage, luego se las proporciona a XpmCreateXpmImageFromImage() para crear una XpmImage que se devuelve a xpmimage. Finalmente, destruye las imágenes X creadas usando XDestroyImage(3).
