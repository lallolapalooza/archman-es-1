XpGetScreenOfContext(3Xp) FUNCIONES DE XPRINT XpGetScreenOfContext(3Xp)

NOMBRE

XpGetScreenOfContext - Obtiene un puntero a la pantalla asociada con el contexto de impresión especificado.

SINOPSIS


cc [ flag... ] archivo... -lXp [ librería... ]
#include <X11/extensions/Print.h>

Screen *XpGetScreenOfContext ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
print_context
Un contexto de impresión preexistente. Este argumento se ignora actualmente, pero debe especificarse.

DESCRIPCIÓN

XpGetScreenOfContext devuelve la pantalla que está asociada con el contexto de impresión actual de la pantalla. Esta llamada debe realizarse después de XpSetContext para determinar en qué pantalla específica se deben crear otros recursos X.

Cada impresora soportada por un servidor de impresión está asociada con exactamente una de las pantallas devueltas en la respuesta de configuración de conexión.

Esta función devuelve NULL si falla la obtención de la pantalla.

DIAGNÓSTICOS

XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.

VER TAMBIÉN
