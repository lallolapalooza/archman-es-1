XpQueryExtension(3Xp) FUNCIONES XPRINT XpQueryExtension(3Xp)

NOMBRE

XpQueryExtension - Consulta un servidor X para determinar si admite la extensión del servicio de impresión X y, si es así, cuáles son los desplazamientos para los eventos y errores asociados.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

Bool XpQueryExtension ( display, event_base_return error_base_return )
Display *display;
int *event_base_return;
int *error_base_return;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
event_base_return
El valor base para los eventos de la extensión del servicio de impresión X
error_base_return
El valor base para los errores de la extensión del servicio de impresión X.

DESCRIPCIÓN

XpQueryExtension determina si la extensión del servicio de impresión X está presente. Devuelve True si la extensión es compatible, de lo contrario False. Si la extensión está presente, se devuelven los valores base para eventos y errores, y se pueden usar para decodificar los valores entrantes de eventos y errores.

La extensión del servicio de impresión X se inicializa en la primera llamada a cualquier función del servicio de impresión X; no es necesario inicializar explícitamente la extensión del servicio de impresión X.
