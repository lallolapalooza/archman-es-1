XPresentSelectInput(3) Versión X11 XPresentSelectInput(3)

NOMBRE

XPresentSelectInput - seleccionar eventos de la extensión X Present para recibir

SINTAXIS

#include <X11/extensions/Xpresent.h>

XID XPresentSelectInput (Display *display,
	Window window,
	unsigned int event_mask);

void XPresentFreeInput (Display *display,
        Window window,
        XID event_id);

DESCRIPCIÓN

XPresentSelectInput selecciona un conjunto de eventos de Presentación que se entregarán para la ventana especificada en el servidor X especificado por display.

XPresentSelectInput devuelve un XID que puede pasarse a XPresentFreeInput para dejar de recibir los eventos solicitados.

VER TAMBIÉN

Xpresent(3), XPresentNotifyMSC(3), XPresentPixmap(3), XPresentQueryCapabilities(3)
