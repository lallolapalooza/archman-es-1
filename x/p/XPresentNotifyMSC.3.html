XPresentNotifyMSC(3) Versión X 11 XPresentNotifyMSC(3)

NOMBRE

XPresentNotifyMSC - Extensión X Present

SINTAXIS

#include <X11/extensions/Xpresent.h>

void XPresentNotifyMSC (Display *display,
	Window window,
	uint32_t serial,
	uint64_t target_msc,
	uint64_t divisor,
	uint64_t remainder);

DESCRIPCIÓN

XPresentNotifyMSC solicita que el servidor X especificado por display entregue un PresentCompleteNotifyEvent con el tipo PresentCompleteKindNotifyMSC después del tiempo especificado por target-msc, divisor y remainder.

serial es un valor arbitrario especificado por el cliente que se devolverá en el evento para que el cliente pueda asociar el evento y la solicitud.

Si target-msc es mayor que el contador de flujo multimedia (msc) actual para window, el evento se entregará en (o después de) el campo target-msc. De lo contrario, la entrega del evento ocurrirá después del próximo campo donde msc % divisor == remainder.

Si window se destruye antes de que se entregue el evento, la entrega del evento no se completará.

VER TAMBIÉN

Xpresent(3), XPresentPixmap(3), XPresentQueryCapabilities(3), XPresentSelectInput(3)
