Licencias: X11, X11-distribute-modifications-variant

XpSetImageResolution(3Xp) FUNCIONES DE XPRINT XpSetImageResolution(3Xp)

NOMBRE

XpSetImageResolution - Establece la resolución para las solicitudes PutImage subsiguientes

SINOPSIS


cc [ opción... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

Bool XpSetImageResolution ( display, print_context, image_res, prev_res_return )
Display * display ;
XPContext print_context ;
int image_res ;
int * prev_res_return ;

ARGUMENTOS

- display
Especifica un puntero a la estructura Display.
- print_context
Especifica el contexto de impresión en el que se establecerá la resolución.
- image_res
Especifica la resolución de la imagen en píxeles por pulgada.
- prev_res_return
Devuelve la resolución de imagen anterior en píxeles por pulgada.

DESCRIPCIÓN

XpSetImageResolution devuelve True si el servidor de impresión permitió que se estableciera la resolución, de lo contrario, devuelve False.

XpSetImageResolution establece la resolución para las solicitudes PutImage subsiguientes a la pantalla del contexto de impresión especificado. Si el valor de retorno es False, entonces el servidor de impresión no admite el escalado de imágenes para la resolución dada con la configuración actual de la impresora, y la aplicación es responsable de cualquier escalado deseado. Si el valor de retorno es True, entonces el contenido de cualquier solicitud PutImage subsiguiente a un Pixmap o a una Ventana en la pantalla del contexto de impresión especificado se escalará automáticamente como parte de la solicitud PutImage. El factor de escala es:

    resolución_predeterminada_impresora / image_res

Donde resolución_predeterminada_impresora es el valor actual de ese atributo de página. Solo se escala la imagen en sí (lo que significa que el ancho y alto efectivos de la imagen cambian), los parámetros dst-x y dst-y de PutImage no se alteran.

Como caso especial, un valor de cero para image_res restablece la resolución para que siga automáticamente la resolución de la impresora; en este caso (que también es la configuración predeterminada para un contexto de impresión recién creado), las imágenes subsiguientes no se escalarán.

Si el valor de retorno es True y prev_res_return es un puntero no nulo, entonces la resolución de imagen anterior que se estableció para el contexto de impresión se almacena en prev_res_return.

XpSetImageResolution devuelve False inmediatamente si image_res es negativo o mayor que 65535.

DIAGNÓSTICOS

XpBadContext
