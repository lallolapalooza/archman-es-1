XpEndDoc(3Xp) FUNCIONES DE IMPRESIÓN XpEndDoc(3Xp)

NOMBRE

XpEndDoc - Indica el final de un documento de impresión.

SINOPSIS


cc [ indicador... ] archivo... -lXp [ librería... ]
#include <X11/extensions/Print.h>

void XpEndDoc ( display )
Display *display;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.

DESCRIPCIÓN

XpEndDoc señala el final de un documento de impresión. Todos los datos resultantes del documento se ensamblan y combinan con los datos enviados previamente por XpPutDocumentData.

Para clientes que seleccionan XPPrintMask (ver XpSelectInput), el evento XPPrintNotify se genera con su campo de detalle establecido a XPEndDocNotify.

DIAGNÓSTICOS

XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.
XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas de la extensión X Print Service. (Ejemplo, XpEndDoc antes de XpStartDoc).

VER TAMBIÉN

XpPutDocumentData(3Xp), XpSelectInput(3Xp), XpStartDoc(3Xp)
