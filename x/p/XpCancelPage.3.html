XpCancelPage(3Xp) FUNCIONES DE XPRINT XpCancelPage(3Xp)

NOMBRE

XpCancelPage - Cancela una página de impresión.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

void XpCancelPage ( display, discard )
Display *display;
Bool discard;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
discard
Cuando es TRUE, especifica que los eventos XPPrintNotify con un detalle de XPEndPageNotify deben ser descartados.

DESCRIPCIÓN

XpCancelPage cancela una página de impresión en curso. Si el trabajo se inició con output_mode XPGetData, el flujo de datos a XpGetDocumentData se interrumpe; no se genera más datos para la página actual, pero se pueden generar datos para páginas posteriores. Para muchos lenguajes de descripción de página, tales interrupciones arbitrarias pueden invalidar la salida.

Si el trabajo se inició con output_mode XPSpool, dependiendo del controlador y la implementación del spooler, la página completa puede ser cancelada o se puede generar una página parcial.

Si discard es True, todos los eventos XPPrintNotify con un campo de detalle XPEndPageNotify se descartan antes de que XpCancelPage devuelva.

Para los clientes que seleccionan XPPrintMask (ver XpSelectInput), el evento XPPrintNotify se genera con su campo de detalle establecido a XPEndPageNotify cuando el Servidor de Impresión X ha completado XpCancelPage.

DIAGNÓSTICOS

XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas del Servicio de Impresión X; por ejemplo, se llamó a XpStartPage antes que a XpStartJob o se llamó para un documento de tipo XPDocRaw.

VER TAMBIÉN

XpGetDocumentData(3Xp), XpSelectInput(3Xp), XpStartJob(3Xp), XpStartPage(3Xp)
