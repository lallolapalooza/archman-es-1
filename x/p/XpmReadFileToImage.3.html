XpmReadFileToImage(3)

Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmRead(3) Funciones de libXpm XpmRead(3)

NOMBRE

XpmRead - leer un archivo XPM

SINOPSIS

int XpmReadFileToImage(Display *display, char *filename,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmReadFileToPixmap(Display *display, Drawable d, char *filename,
Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmReadFileToXpmImage(char *filename, XpmImage *image,
XpmInfo *info);
int XpmReadFileToBuffer(char *filename, char **buffer_return);
int XpmReadFileToData(char *filename, char ***data_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
filename
Especifica el nombre del archivo a utilizar.
image_return
Devuelve la imagen que se crea.
shapeimage_return
Devuelve la imagen de máscara de forma que se crea si se utiliza el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información (o NULL).
buffer_return
Devuelve el buffer creado.
data_return
Devuelve el array de datos creado.
image
Especifica la ubicación de la estructura de imagen.
info
Especifica la ubicación de una estructura para almacenar información posible (o NULL).

DESCRIPCIÓN

XpmReadFileToImage

La función XpmReadFileToImage() lee un archivo en formato XPM. Si el archivo no puede ser abierto, devuelve XpmOpenFailed. Si el archivo puede ser abierto pero no contiene datos XPM válidos, devuelve XpmFileInvalid. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory. Si el puntero de la estructura XpmAttributes pasado no es NULL, XpmReadFileToImage() busca los siguientes atributos: XpmVisual, XpmColormap, XpmDepth, XpmColorSymbols, XpmExactColors, XpmCloseness, XpmRGBCloseness, XpmAllocCloseColors, XpmReturnPixels, XpmReturnAllocPixels, XpmAllocColor, XpmFreeColors, XpmColorClosure, XpmReturnExtensions, XpmReturnColorTable, XpmBitmapFormat, establece XpmSize, XpmCharsPerPixel y posiblemente XpmHotspot al devolver. Como característica de compatibilidad con versiones anteriores, XpmReadFileToImage() también busca los atributos XpmReturnInfos. Como se especifica en la tabla (página 12), si los datos relacionados con los atributos XpmReturnExtensions, XpmReturnColorTable y XpmReturnInfos no pueden devolverse según lo solicitado debido a una insuficiencia de memoria, XpmReadFileToImage() cambiará la máscara de valor para mencionarlo e intentará continuar. Por lo tanto, el llamador debe verificar esto antes de acceder a estos datos.

Nota: La máscara de valor del XpmAttributes pasado debe establecerse en algún valor válido, al menos cero, de lo contrario, pueden ocurrir errores impredecibles.

XpmReadFileToImage() asigna colores, según lo leído del archivo o posiblemente anulado como se especifica en los atributos XpmColorSymbols. Los colores se asignan utilizando la configuración de color para la visual especificada por el atributo XpmColorKey, que tiene el valor XPM_MONO, XPM_GRAY4, XPM_GRAY o XPM_COLOR. Si no se establece el atributo XpmColorKey, se determina examinando el tipo de visual. Si no existe un valor predeterminado para la visual especificada, primero busca otros predeterminados más cercanos al tipo de visual monocromática y luego más cercanos al tipo de visual en color. Si el color que se encuentra no es válido (no se puede analizar), busca otro predeterminado según el mismo algoritmo. Si la asignación de un color falla, y se establece el atributo de cercanía, intenta encontrar un color ya en el mapa de colores que sea el más cercano al color deseado y lo utiliza. Si el atributo alloc_close_colors está establecido en False, el color cercano encontrado no se asigna pero se usa de todos modos. Esto es especialmente útil para aplicaciones que utilizan un mapa de colores privado que contiene celdas de lectura/escritura y tienen control total sobre el mapa de colores. Por otro lado, dado que en tal caso no hay garantía de que el píxel de color no cambie en ningún momento, esto debe evitarse al usar el mapa de colores predeterminado. Si no se encuentra ningún color, y no existe ni se desea un color cercano, y se han agotado todas las visuales, se devuelve XpmColorFailed.

Los componentes RGB son enteros en el rango de 0 (negro) a 65535 (blanco). Una cercanía de menos de 10000, por ejemplo, provocará que solo coincidan colores bastante cercanos, mientras que una cercanía de más de 50000 permitirá que coincidan colores bastante dispares. Especificar una cercanía de más de 65535 permitirá que cualquier color coincida, forzando así que el icono se dibuje en color sin importar cuán malo sea el mapa de colores. El valor 40000 parece ser bastante adecuado para muchas situaciones que requieren coincidencias razonables pero no perfectas. Con esta configuración, el color solo debe estar dentro del área general del cubo RGB del color deseado. Si se establece el atributo exactColors, devuelve XpmColorError, de lo contrario, crea las imágenes y devuelve XpmSuccess. Si no se encuentra ningún color, no existe ni se desea un color cercano, y se han agotado todas las visuales, se devuelve XpmColorFailed.

XpmReadFileToImage() devuelve la imagen creada a image_return si no es NULL y posiblemente la máscara de forma creada a shapeimage_return si no es NULL y se utiliza el color None. Si es necesario, almacena en la estructura XpmAttributes la lista de los píxeles utilizados. Cuando la profundidad de la imagen es uno, el formato de la imagen es el especificado por el atributo bitmap_format si está establecido o ZPixmap. Cuando la profundidad es diferente de uno, el formato de la imagen es siempre ZPixmap. Al finalizar, el llamador debe liberar las imágenes usando XDestroyImage(3), los colores asignados usando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3). Además, en sistemas que soportan tales características, XpmReadFileToImage() maneja archivos comprimidos creando un proceso uncompress o gzip y leyendo desde el resultado de la tubería. Asume que el archivo especificado está comprimido si el nombre del archivo dado termina en '.Z' o '.gz'. En caso de que el nombre del archivo no termine así, XpmReadFileToImage() busca el nombre del archivo dado asumiendo que no es un archivo comprimido. Y si en lugar de un nombre de archivo se pasa NULL a XpmReadFileToImage(), lee desde la entrada estándar.

XpmReadFileToPixmap

La función XpmReadFileToPixmap() crea imágenes X utilizando XpmReadFileToImage() y, por lo tanto, devuelve los mismos errores. Además, con éxito, crea los pixmaps relacionados, utilizando XPutImage(3), que se devuelven a pixmap_return y shapemask_return si no son NULL, y finalmente destruye las imágenes creadas usando XDestroyImage(3). Al finalizar, el llamador debe liberar los pixmaps usando XFreePixmap(3), los colores asignados usando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3).

XpmReadFileToBuffer

XpmReadFileToBuffer() asigna y llena un buffer desde un archivo. XpmReadFileToBuffer() devuelve

NOMBRE

XpmReadFileToBuffer, XpmReadFileToData, XpmReadFileToXpmImage, XpmReadFileToPixmap - leer datos de imagen XPM desde un archivo

SINOPSIS

#include <X11/xpm.h>

unsigned int
XpmReadFileToBuffer(
    const char *filename,
    char **buffer_return
);

unsigned int
XpmReadFileToData(
    const char *filename,
    char **data_return
);

unsigned int
XpmReadFileToXpmImage(
    const char *filename,
    XpmImage *image,
    XpmInfo *info
);

unsigned int
XpmReadFileToPixmap(
    Display *display,
    Window drawable,
    const char *filename,
    Pixmap *pixmap_return,
    Pixmap *shapemask_return,
    XpmInfo *info
);

ARGUMENTOS

display
Especifica la conexión al servidor X.
drawable
Especifica una ventana o pixmap en la que se desea leer la imagen.
filename
Especifica el nombre del archivo a leer.
buffer_return
Puntero al puntero que se llenará con la dirección del buffer asignado que contiene los datos del archivo.
data_return
Puntero al puntero que se llenará con la dirección de los datos asignados que contienen la imagen XPM.
pixmap_return
Puntero al pixmap que se llenará con el identificador del pixmap creado a partir del archivo XPM.
shapemask_return
Puntero al pixmap que se llenará con el identificador de la máscara de forma creada a partir del archivo XPM. Si no se requiere máscara de forma, se establecerá en None.
image
Puntero a la estructura XpmImage que se llenará con los datos de la imagen XPM.
info
Puntero a la estructura XpmInfo que se llenará con información sobre la imagen XPM leída.

DESCRIPCIÓN

La función XpmReadFileToPixmap lee un archivo en formato XPM y crea un pixmap y opcionalmente una máscara de forma. Los argumentos pixmap_return y shapemask_return se llenarán con los identificadores de los pixmaps creados. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si el archivo no contiene datos XPM válidos, devuelve XpmFileInvalid. Si no se asigna suficiente memoria de trabajo, devuelve XpmNoMemory. Si tiene éxito, devuelve XpmSuccess.

Las funciones XpmReadFileToBuffer, XpmReadFileToData y XpmReadFileToXpmImage son utilidades para leer un archivo XPM en diferentes formatos. Devuelven XpmOpenFailed si no pueden abrir el archivo, XpmNoMemory si no se asigna suficiente memoria de trabajo y XpmSuccess en caso contrario. XpmReadFileToData además devuelve XpmFileInvalid si el archivo no es un archivo XPM válido.

El buffer asignado devuelto por XpmReadFileToBuffer() debe liberarse con XpmFree(3) al finalizar.

Como conveniencia, se proporcionan XpmReadFileToBuffer() y XpmWriteFileFromBuffer(3) para copiar un archivo a un buffer y escribir un archivo desde un buffer. Por lo tanto, por ejemplo, se puede decidir utilizar XpmReadFileToBuffer(), XpmCreatePixmapFromBuffer(3) y XpmFree(3) en lugar de XpmReadFileToPixmap. En algunos sistemas, esto puede conducir a una mejora del rendimiento, ya que el análisis se realizará en memoria, pero utiliza más memoria.

XpmReadFileToData

XpmReadFileToData() devuelve XpmOpenFailed si no puede abrir el archivo, XpmNoMemory si no se asigna suficiente memoria de trabajo, XpmFileInvalid si no es un archivo XPM válido y XpmSuccess en caso contrario. Los datos asignados devueltos por XpmReadFileToData() deben liberarse con XpmFree(3) al finalizar.

XpmReadFileToXpmImage

La función XpmReadFileToXpmImage() lee un archivo en formato XPM. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si el archivo se puede abrir pero no contiene datos XPM válidos, devuelve XpmFileInvalid. Si no se asigna suficiente memoria de trabajo, devuelve XpmNoMemory. En caso de éxito, llena la estructura XpmImage proporcionada y devuelve XpmSuccess.

VER TAMBIÉN
