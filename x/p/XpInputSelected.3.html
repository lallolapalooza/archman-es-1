XpInputSelected(3Xp) FUNCIONES DE XPRINT XpInputSelected(3Xp)

NOMBRE

XpInputSelected - Consulta qué eventos de X Print ha seleccionado el cliente para recibir del contexto de impresión específico.

SINOPSIS


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

unsigned long XpInputSelected ( display, context, event_mask )
Display *display;
XPContext context;
unsigned long *all_event_mask_return;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
context
Especifica el contexto de impresión al que se está realizando la consulta.
all_event_mask_return
Devuelve el conjunto de eventos que cualquier cliente ha seleccionado.

DESCRIPCIÓN

XpInputSelected devuelve una máscara de bits que describe qué clases de eventos ha seleccionado el cliente para recibir. El valor devuelto a all_event_mask_return es la unión de la máscara de eventos de cada cliente. XpInputSelected consulta qué eventos de X Print del contexto de impresión especificado ha seleccionado el cliente para recibir. Los eventos de X Print se generan a partir de un contexto de impresión, y no de una ventana como es el caso de XSelectInput. A medida que llegan los eventos, el campo de contexto en el evento se utiliza para determinar qué contexto de impresión generó el evento. Consulte XpSelectInput para los valores de event_mask y all_event_mask (??devolución??).

DIAGNÓSTICOS

XPBadContext
El contexto de impresión especificado no es válido.
