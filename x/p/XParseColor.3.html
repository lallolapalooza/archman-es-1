XQueryColor(3) FUNCIONES DE XLIB XQueryColor(3)

NOMBRE

XQueryColor, XQueryColors, XLookupColor, XParseColor - obtener valores de color

SINTAXIS

int XQueryColor(Display *display, Colormap colormap, XColor *def_in_out);

int XQueryColors(Display *display, Colormap colormap, XColor defs_in_out[], int ncolors);

Status XLookupColor(Display *display, Colormap colormap, _Xconst char *nombre_color, XColor *exact_def_return, XColor *screen_def_return);

Status XParseColor(Display *display, Colormap colormap, _Xconst char *spec, XColor *exact_def_return);

ARGUMENTOS

colormap
Especifica el mapa de colores.
nombre_color
Especifica la cadena del nombre del color (por ejemplo, rojo) de la cual desea obtener la estructura de definición de color.
def_in_out
Especifica y devuelve los valores RGB para el píxel especificado en la estructura.
defs_in_out
Especifica y devuelve una matriz de estructuras de definición de color para el píxel especificado en la estructura.
display
Especifica la conexión con el servidor X.
exact_def_return
Devuelve los valores RGB exactos.
ncolors
Especifica el número de estructuras XColor en la matriz de definición de color.
screen_def_return
Devuelve los valores RGB más cercanos proporcionados por el hardware.
spec
Especifica la cadena del nombre del color; no distingue entre mayúsculas y minúsculas.
exact_def_return
Devuelve el valor exacto del color para su uso posterior y establece las banderas DoRed, DoGreen y DoBlue.

DESCRIPCIÓN

La función XQueryColor devuelve el valor RGB actual para el píxel en la estructura XColor y establece las banderas DoRed, DoGreen y DoBlue. La función XQueryColors devuelve el valor RGB para cada píxel en cada estructura XColor y establece las banderas DoRed, DoGreen y DoBlue en cada estructura.

XQueryColor y XQueryColors pueden generar errores BadColor y BadValue.

La función XLookupColor busca el nombre de cadena de un color con respecto a la pantalla asociada con el mapa de colores especificado. Devuelve tanto los valores exactos del color como los valores más cercanos proporcionados por la pantalla con respecto al tipo visual del mapa de colores especificado. Si el nombre del color no está en la codificación de caracteres portátil del host, el resultado es dependiente de la implementación. El uso de mayúsculas o minúsculas no importa. XLookupColor devuelve un valor distinto de cero si el nombre se resuelve; de lo contrario, devuelve cero.

La función XParseColor busca el nombre de cadena de un color con respecto a la pantalla asociada con el mapa de colores especificado. Devuelve el valor exacto del color. Si el nombre del color no está en la codificación de caracteres portátil del host, el resultado es dependiente de la implementación. El uso de mayúsculas o minúsculas no importa. XParseColor devuelve un valor distinto de cero si el nombre se resuelve; de lo contrario, devuelve cero.

XLookupColor y XParseColor pueden generar el error BadColor.

NOMBRES DE COLOR

Una especificación de Dispositivo RGB se identifica por el prefijo "rgb:" y se ajusta a la siguiente sintaxis:

rgb:<rojo>/<verde>/<azul>
    <rojo>, <verde>, <azul> := h | hh | hhh | hhhh
    h := dígitos hexadecimales únicos (sin distinción de mayúsculas y
    minúsculas)

Tenga en cuenta que h indica el valor escalado en 4 bits, hh el valor escalado en 8 bits, hhh el valor escalado en 12 bits y hhhh el valor escalado en 16 bits, respectivamente.

Por compatibilidad con versiones anteriores, se admite una sintaxis más antigua para Dispositivo RGB, pero no se recomienda su uso continuo. La sintaxis es un signo de almohadilla inicial seguido de una especificación numérica, en uno de los siguientes formatos:

#RGB (4 bits cada uno)
#RRGGBB (8 bits cada uno)
#RRRGGGBBB (12 bits cada uno)
#RRRRGGGGBBBB (16 bits cada uno)

R, G y B representan dígitos hexadecimales únicos. Cuando se especifican menos de 16 bits cada uno, representan los bits más significativos del valor (a diferencia de la sintaxis "rgb:", en la que los valores se escalan). Por ejemplo, la cadena "#3a7" es lo mismo que "#3000a0007000".

Una especificación de intensidad RGB se identifica por el prefijo "rgbi:" y se ajusta a la siguiente sintaxis:

rgbi:<rojo>/<verde>/<azul>

Tenga en cuenta que rojo, verde y azul son valores de punto flotante entre 0.0 y 1.0, inclusive. El formato de entrada para estos valores es un signo opcional, una cadena de números que puede contener un punto decimal y un campo exponencial opcional que contiene una E o e seguida de una cadena entera posiblemente con signo.

Las especificaciones de cadena estándar independientes del dispositivo tienen la siguiente sintaxis:

CIEXYZ:<X>/<Y>/<Z>
CIEuvY:<u>/<v>/<Y>
CIExyY:<x>/<y>/<Y>
CIELab:<L>/<a>/<b>
CIELuv:<L>/<u>/<v>
TekHVC:<H>/<V>/<C>

Todos los valores (C, H, V, X, Y, Z, a, b, u, v, y, x) son valores de punto flotante. La sintaxis para estos valores es un signo más o menos opcional, una cadena de dígitos que posiblemente contiene un punto decimal y un campo exponencial que consta de una "E" o "e" seguida de un signo más o menos opcional seguido de una cadena de dígitos.

DIAGNÓSTICOS

BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.

XParseColor - parse a color string

NAME

XParseColor - parse a color string

SYNOPSIS

#include <Xlib.h>

int XParseColor(Display *display, Colormap colormap, const char *spec, XColor *def_return);

DESCRIPTION

The XParseColor function parses the color string spec and returns the closest color that can be represented in the specified colormap .

The spec string can be in RGB format (e.g., “rgb:rrr/ggg/bbb”, where rrr, ggg, and bbb are hexadecimal values between 0 and FFFF) or in a named color format.

The def_return structure is filled with the closest color that can be represented in the specified colormap .

DIAGNOSTICS

The XParseColor function returns 0 if the color string cannot be parsed or if the color cannot be represented in the specified colormap . Otherwise, it returns a non-zero value.
