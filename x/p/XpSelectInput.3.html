XpSelectInput(3)

Paquete: libxp

Licencias: X11, X11-distribute-modifications-variant

XpSelectInput(3Xp) FUNCIONES DE XPRINT XpSelectInput(3Xp)

NOMBRE

XpSelectInput - Especifica qué eventos de X Print, del contexto de impresión especificado, son de interés para el cliente.

SINOPSIS

void XpSelectInput ( display, context, event_mask )
Display *display;
XPContext context;
unsigned long event_mask;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
context
Especifica el contexto de impresión del cual seleccionar eventos.
event_mask
Especifica la máscara de eventos. Esta máscara es la OR a nivel de bits de uno o más de los bits válidos de la máscara de eventos (ver abajo).

DESCRIPCIÓN

XpSelectInput selecciona qué eventos de X Print del contexto de impresión especificado son de interés para el cliente. Los eventos de X Print se generan a partir de un contexto de impresión actual, y no de una ventana como es el caso de XSelectInput.

ESTRUCTURAS

Los bits para event_mask se definen en <X11/extensions/Print.h>:

    #define XPNoEventMask		0
    #define XPPrintMask			(1L<<0)
    #define XPAttributeMask		(1L<<1)
Los eventos resultantes se definen en <X11/extensions/Print.h>: 
    #define XPPrintNotify		0
    #define XPAttributeNotify		1

DIAGNÓSTICOS

BadValue
El valor especificado para event_mask no es válido.
XPBadContext
El contexto de impresión especificado no es válido.

ARCHIVOS

<X11/extensions/Print.h>
libXp 1.0.4 Versión X 11
