XpmMisc(3) Funciones de libXpm XpmMisc(3)

NOMBRE

XpmMisc - funciones misceláneas de xpm para liberar memoria usada y manejar errores

SINOPSIS

int XpmFreeXpmImage(XpmImage *image);
int XpmFreeXpmInfo(XpmInfo *info);
int XpmFreeAttributes(XpmAttributes *attributes);
int XpmAttributesSize(void);
int XpmFreeExtensions(XpmExtension *extensions,  int nextensions);
int XpmFree(char *ptr);
char *XpmGetErrorString(int errorcode);
int XpmLibraryVersion(void);

ARGUMENTOS

image
Especifica la estructura a liberar
info
Especifica la estructura a liberar
ptr
Especifica los datos a liberar
errorcode
Especifica el error XPM
extensions
Especifica el array a liberar
nextensions
Especifica el número de extensiones
attributes
Especifica la estructura a liberar

DESCRIPCION

Para liberar posibles datos almacenados en una estructura XpmImage, usa XpmFreeXpmImage(). La función XpmFreeXpmImage() libera los miembros de la estructura que no son NULL, pero no la estructura en sí.

Para liberar posibles datos almacenados en una estructura XpmInfo, usa XpmFreeXpmInfo().

Para liberar datos posiblemente almacenados en un array de XpmExtension, usa XpmFreeExtensions().

Para liberar cualquier dato asignado por una función XPM, usa la función XpmFree(). La distribución actual de la biblioteca XPM utiliza las funciones de asignación de memoria estándar y, por lo tanto, XpmFree() no es más que una macro para la función estándar free(3). Sin embargo, dado que estas funciones pueden redefinirse en entornos específicos, es prudente usar XpmFree().

Para liberar datos posiblemente almacenados en una estructura XpmAttributes, usa XpmFreeAttributes(). La función XpmFreeAttributes() libera los miembros de la estructura que han sido asignados con malloc, como la lista de píxeles.

Para asignar dinámicamente una estructura XpmAttributes, usa la función XpmAttributesSize(). La función XpmAttributesSize() proporciona a las aplicaciones que utilizan bibliotecas dinámicas una forma segura de asignar y luego referenciar una estructura XpmAttributes, sin importar si el tamaño de la estructura XpmAttributes ha cambiado o no desde la compilación.

Para obtener datos al construir un mensaje de error, se puede usar XpmGetErrorString(). XpmGetErrorString() devuelve una cadena relacionada con el código de error XPM dado.

La función XpmLibraryVersion() puede ser utilizada cuando se necesita determinar qué versión de la biblioteca está en uso. El valor devuelto por XpmLibraryVersion() puede compararse con el valor de XpmIncludeVersion, que está definido en el archivo de cabecera "xpm.h". Estos números se calculan con la siguiente fórmula:

 (XpmFormat * 100 + XpmVersion) * 100 + XpmRevision

donde XpmFormat es el número de versión del formato, XpmVersion es el número de versión de la biblioteca (que solo cambia si la API cambia) y XpmRevision es el número de versión menor de la biblioteca.

La función XpmFreeExtensions() libera todos los datos almacenados en cada extensión y el propio array. Nótese que XpmFreeAttributes() llama a esta función y, por lo tanto, la mayoría de las veces no necesita ser llamada explícitamente.
