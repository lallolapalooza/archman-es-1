Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmRead(3) Funciones de libXpm XpmRead(3)

NOMBRE

XpmRead - leer un archivo XPM

SINOPSIS

int XpmReadFileToImage(Display *display, char *filename,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmReadFileToPixmap(Display *display, Drawable d, char *filename,
Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmReadFileToXpmImage(char *filename, XpmImage *image,
XpmInfo *info);
int XpmReadFileToBuffer(char *filename, char **buffer_return);
int XpmReadFileToData(char *filename, char ***data_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
filename
Especifica el nombre de archivo a utilizar.
image_return
Devuelve la imagen que se crea.
shapeimage_return
Devuelve la imagen de máscara de forma que se crea si se usa el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información (o NULL).
buffer_return
Devuelve el búfer creado.
data_return
Devuelve el array de datos creado.
image
Especifica la ubicación de la estructura de imagen.
info
Especifica la ubicación de una estructura para almacenar posible información (o NULL).

DESCRIPCIÓN

XpmReadFileToImage

La función XpmReadFileToImage() lee un archivo en formato XPM. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si el archivo se puede abrir pero no contiene datos XPM válidos, devuelve XpmFileInvalid. Si no se puede asignar suficiente espacio de trabajo, devuelve XpmNoMemory. Si el puntero de estructura XpmAttributes pasado no es NULL, XpmReadFileToImage() busca los siguientes atributos: XpmVisual, XpmColormap, XpmDepth, XpmColorSymbols, XpmExactColors, XpmCloseness, XpmRGBCloseness, XpmAllocCloseColors, XpmReturnPixels, XpmReturnAllocPixels, XpmAllocColor, XpmFreeColors, XpmColorClosure, XpmReturnExtensions, XpmReturnColorTable, XpmBitmapFormat, establece XpmSize, XpmCharsPerPixel, y posiblemente el atributo XpmHotspot al devolver. Como característica de compatibilidad con versiones anteriores, XpmReadFileToImage() también busca el atributo XpmReturnInfos. Como se especifica en la tabla (página 12), si los datos relacionados con los atributos XpmReturnExtensions, XpmReturnColorTable y XpmReturnInfos no se pueden devolver según lo solicitado debido a una memoria insuficiente, XpmReadFileToImage() cambiará el máscara de valores para indicar esto e intentará continuar. Por lo tanto, el llamador debe verificar esto antes de acceder a estos datos.

Nota: La máscara de valores del XpmAttributes pasado debe establecerse en algún valor válido, al menos cero, de lo contrario, pueden producirse errores impredecibles.

XpmReadFileToImage() asigna colores, tal como se leen del archivo o posiblemente se anulan según lo especificado en los atributos XpmColorSymbols. Los colores se asignan utilizando la configuración de color para la visual especificada por el atributo XpmColorKey, que tiene el valor XPM_MONO, XPM_GRAY4, XPM_GRAY o XPM_COLOR. Si el atributo XpmColorKey no está establecido, se determina examinando el tipo de visual. Si no existe un valor predeterminado para la visual especificada, primero busca otros predeterminados más cercanos al tipo de visual monocromática y, en segundo lugar, más cercanos al tipo de visual de color. Si el color que se encuentra no es válido (no se puede analizar), busca otro valor predeterminado según el mismo algoritmo. Si la asignación de un color falla, y el atributo de cercanía está establecido, intenta encontrar un color ya en la tabla de colores que sea el más cercano al color deseado, y lo usa. Si el atributo alloc_close_colors está establecido en False, el color cercano encontrado no se asigna, pero se usa de todos modos. Esto es especialmente útil para aplicaciones que utilizan una tabla de colores privada que contiene celdas de lectura/escritura y tienen control total sobre la tabla de colores. Por otro lado, dado que en tal caso no hay garantía de que el píxel de color no cambie en ningún momento, esto debe evitarse al usar la tabla de colores predeterminada. Si no se encuentra ningún color, y no existe o no se desea un color cercano, y se han agotado todas las visuales, se devuelve XpmColorFailed.

Los componentes RGB son enteros dentro del rango de 0 (negro) a 65535 (blanco). Una cercanía de menos de 10000, por ejemplo, solo hará que se emparejen colores bastante cercanos, mientras que una cercanía de más de 50000 permitirá que se emparejen colores bastante dispares. Especificar una cercanía de más de 65535 permitirá que cualquier color coincida, obligando así a que el icono se dibuje en color, sin importar lo mala que sea la tabla de colores. El valor 40000 parece ser aproximadamente adecuado para muchas situaciones que requieren coincidencias razonables pero no perfectas. Con esta configuración, el color solo debe estar dentro de la misma área general del cubo RGB que el color deseado. Si el atributo exactColors está establecido, devuelve XpmColorError; de lo contrario, crea las imágenes y devuelve XpmSuccess. Si no se encuentra ningún color, y no existe ni se desea un color cercano, y se han agotado todas las visuales, se devuelve XpmColorFailed.

XpmReadFileToImage() devuelve la imagen creada a image_return si no es NULL y posiblemente la máscara de forma creada a shapeimage_return si no es NULL y se usa el color None. Si es necesario, almacena en la estructura XpmAttributes la lista de los píxeles utilizados. Cuando la profundidad de la imagen es uno, el formato de la imagen es el especificado por el atributo bitmap_format si está establecido o ZPixmap. Cuando la profundidad es diferente de uno, el formato de la imagen es siempre ZPixmap. Al finalizar, el llamador debe liberar las imágenes usando XDestroyImage(3), los colores asignados usando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3). Además, en sistemas que soportan tales características, XpmReadFileToImage() maneja archivos comprimidos creando un proceso de descompresión o gzip y leyendo desde el resultado canalizado. Asume que el archivo especificado está comprimido si el nombre de archivo dado termina en '.Z' o '.gz'. En caso de que el nombre de archivo no termine así, XpmReadFileToImage() busca el nombre de archivo dado asumiendo que no es un archivo comprimido. Y si en lugar de un nombre de archivo se pasa NULL a XpmReadFileToImage(), lee de la entrada estándar.

XpmReadFileToPixmap

La función XpmReadFileToPixmap() crea imágenes X usando XpmReadFileToImage() y, por lo tanto, devuelve los mismos errores. Además, al tener éxito, crea los pixmaps relacionados, usando XPutImage(3), que se devuelven a pixmap_return y shapemask_return si no son NULL, y finalmente destruye las imágenes creadas usando XDestroyImage(3). Al finalizar, el llamador debe liberar los pixmaps usando XFreePixmap(3), los colores asignados usando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3).

NAME

XpmRead, XpmReadFileToBuffer, XpmReadFileToData, XpmReadFileToXpmImage - read XPM file

SYNOPSIS

```c
#include <X11/xpm.h>

int XpmReadFileToBuffer(const char *filename, char **buffer_return);

int XpmReadFileToData(const char *filename, char **data_return);

int XpmReadFileToXpmImage(const char *filename, XpmImage *image, XpmInfo *info);
```

ARGUMENTS

filename Pointer to a null-terminated string containing the name of the file to read.

buffer_return Pointer to a buffer to store the file contents.

data_return Pointer to a buffer to store the file contents.

image Pointer to an XpmImage structure to be filled with the image data.

info Pointer to an XpmInfo structure to be filled with information about the image.

DESCRIPTION

The XpmReadFileToBuffer() function reads the contents of the specified file into a buffer. The allocated buffer returned by XpmReadFileToBuffer() should be freed with XpmFree(3) when done.

The function returns XpmOpenFailed if it cannot open the file, XpmNoMemory if insufficient working storage is allocated, and XpmSuccess otherwise. The allocated buffer returned by XpmReadFileToBuffer() should be freed with XpmFree(3) when done.

As a convenience, the XpmReadFileToBuffer() and XpmWriteFileFromBuffer(3) are provided to copy a file to a buffer and to write a file from a buffer. Thus for instance one may decide to use XpmReadFileToBuffer(), XpmCreatePixmapFromBuffer(3), and XpmFree(3) instead of XpmReadFileToPixmap(). On some systems this may lead to a performance improvement, since the parsing will be performed in memory, but it uses more memory.

XpmReadFileToData

XpmReadFileToData() returns XpmOpenFailed if it cannot open the file, XpmNoMemory if insufficient working storage is allocated, XpmFileInvalid if this is not a valid XPM file, and XpmSuccess otherwise. The allocated data returned by XpmReadFileToData() should be freed with XpmFree(3) when done.

XpmReadFileToXpmImage

The XpmReadFileToXpmImage() function reads in a file in the XPM format. If the file cannot be opened it returns XpmOpenFailed. If the file can be opened but does not contain valid XPM data, it returns XpmFileInvalid. If insufficient working storage is allocated, it returns XpmNoMemory. On success it fills in the given XpmImage structure and returns XpmSuccess.
