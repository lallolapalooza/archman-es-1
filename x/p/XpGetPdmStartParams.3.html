XpGetPdmStartParams(3Xp) FUNCIONES XPRINT XpGetPdmStartParams(3Xp)

NOMBRE

XpGetPdmStartParams - Construye parámetros de acuerdo con el Protocolo de Selección PDM como una función de conveniencia estándar.

SINOPSIS


cc [ indicador... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

Status XpGetPdmStartParams ( print_display print_window print_context video_display video_window selection_display_return selection_return type_return format_return data_return nelements_return )
Display *print_display;
Window print_window;
XPContext print_context;
Display *video_display;
Window video_window;
Display **selection_display_return;
Atom *selection_return;
Atom *type_return;
int *format_return;
unsigned char **data_return;
int *nelements_return;

ARGUMENTOS

print_display
Especifica un puntero a la estructura de visualización de impresión; devuelto por XOpenDisplay en el servidor X de impresión.
print_window
Especifica una ventana del cliente en cualquier pantalla de print_display lo suficientemente duradera para las comunicaciones ICCCM del estado final del PDM ("OK" o "CANCEL" ClientMessage) enviado a print_window.
print_context
Un contexto de impresión existente al que debe hacer referencia el PDM.
video_display
Especifica un puntero a la estructura de visualización de video; devuelto por XOpenDisplay en el servidor X de video.
video_window
Especifica la ventana en video_display cerca de la cual se deben publicar los diálogos transitorios del PDM.
selection_display_return
Devuelve la conexión de visualización en la que se debe realizar la selección del PDM. Puede ser igual a print_display o video_display, o puede ser una nueva conexión de visualización que el llamador debe cerrar cuando termine.
selection_return
Devuelve el átomo de selección para el cual se debe realizar una selección PDM.
type_return
Devuelve el tipo de la propiedad del Protocolo de Selección PDM que se espera que el llamador cree.
format_return
Devuelve el formato de la propiedad del Protocolo de Selección PDM que se espera que el llamador cree.
data_return
Devuelve los datos establecidos para la propiedad del Protocolo de Selección PDM que se espera que el llamador cree. Se espera que el llamador libere los datos usando XFree cuando termine.
nelements_return
Devuelve el número de elementos para la propiedad del Protocolo de Selección PDM que se espera que el llamador cree.

DESCRIPCIÓN

Esta solicitud devuelve un estado cero si ocurrió un error, de lo contrario, no cero.

XpGetPdmStartParams es una rutina de conveniencia utilizada para construir la información de propiedad necesaria y la información de conexión de visualización de selección necesaria para iniciar una Selección PDM según el "Protocolo de Selección PDM". Una vez que se construye la información, el llamador es responsable de la creación de una propiedad, la generación de una Solicitud de Selección, la recepción de un evento SelectionNotify y la recepción de un evento ClientMessage, como se describe en el Protocolo de Selección PDM.

Cuando termine, se espera que el llamador libere los datos usando XFree. XpGetPdmStartParams devuelve cero si ocurrió un error, de lo contrario, no cero. Si ocurre un error, todos los valores other_return no están definidos.

Establecer la variable de entorno XPDMSELECTION hace que XpGetPdmStartParams utilice un nombre de selección alternativo. Si no está establecido, se utiliza el nombre de selección PDM_MANAGER.

Establecer la variable de entorno XPDMDISPLAY hace que XpGetPdmStartParams localice la selección en un servidor X alternativo. Si no está establecido, selection_display_return
se establece igual a print_display. Si XPDMDISPLAY se establece en una de las palabras clave "print" o "video", selection_display_return se establece en print_display o video_display, respectivamente. Si XPDMDISPLAY se establece en una cadena válida estilo DISPLAY, selection_display_return puede establecerse, según corresponda, en uno de print_display, video_display, o en una nueva conexión de visualización abierta desde dentro de XpGetPdmStartParams. Solo en el único caso en que se realiza una nueva conexión de visualización, el llamador debe cerrar selection_display_return usando XCloseDisplay.

Cuando se llama a XpGetPdmStartParams, la configuración regional del llamador (ver XpSetLocaleHinter) se incluye en la información como una "pista" para el Administrador de Diálogos de Impresión (PDM). Si la implementación lo admite, el PDM utilizará la pista para mostrar diálogos etiquetados de manera más apropiada para la configuración regional del cliente. Si el Administrador de Diálogos de Impresión no puede entender la pista, el PDM elegirá una predeterminada. Tenga en cuenta que la configuración regional de los atributos de impresión que el PDM accederá posteriormente, ya se habrá determinado cuando el cliente llamó a XpCreateContext.

Las variables de entorno XPDMDISPLAY y XPDMSELECTION se re-leen cada vez que se llama a XpGetPdmStartParams.
