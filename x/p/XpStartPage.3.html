XpStartPage(3Xp) FUNCIONES XPRINT XpStartPage(3Xp)

NOMBRE

XpStartPage - Indica el inicio de una página de impresión.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

void XpStartPage ( display, window )
Display *display;
Window window;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
window
Especifica el ID de la ventana.

DESCRIPCION

XpStartPage señala el comienzo de una nueva página de impresión, con la ventana sirviendo como el drawable que representa la página. Se requiere que window sea un descendiente de la ventana raíz de la ventana de contexto de impresión actual, de lo contrario se generará un BadWindow. No se generarán datos de documento para operaciones de renderizado contra la ventana o sus inferiores antes de XpStartPage.

XpStartPage hace que la ventana sea mapeada. Ver XpGetPageDimensions y XResizeWindow para detalles sobre cómo redimensionar la ventana al tamaño del medio seleccionado antes de llamar a XpStartPage. Dentro de la secuencia XpStartPage y XpEndPage, los intentos de redimensionar, mover o desmapear la ventana producirán resultados indefinidos. Para redimensionar o mover inferiores de la ventana, se aplican las semánticas estándar de ConfigureWindow, excepto que el contenido de cualquier ventana configurada puede ser descartado. Se generará un evento Expose si se descarta el contenido de una ventana.

Todos los cambios en el grupo de atributos XPPageAttr (ver XpSetAttributes) deben hacerse antes de llamar a XpStartPage, después de lo cual se generará un error XPBadSequence si se intentan cambios, hasta que se llame a XpEndPage.

Para los clientes que seleccionan XPPrintMask (ver XpSelectInput), el evento XPPrintNotify se generará con su campo de detalle establecido en XPStartPageNotify cuando el Servidor de Impresión X haya completado XpStartPage. Si también se selecciona el evento Expose (ver XSelectInput), los eventos de exposición se generarán antes que XPPrintNotify.

El cliente no necesita esperar a XPStartPageNotify antes de llamar a cualquier otra rutina de renderizado X.

DIAGNÓSTICO

BadWindow
El valor especificado para la ventana no es válido.
XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.
XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas de la Extensión de Impresión X; por ejemplo, XpStartPage se llamó antes que XpStartJob o se llamó para un tipo de documento XPDocRaw.

VER TAMBIÉN

XpEndPage(3Xp), XpGetPageDimensions(3Xp), XpSelectInput(3Xp), XpSetAttributes(3Xp)
