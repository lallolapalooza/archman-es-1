XpGetPrinterList(3Xp) FUNCIONES DE XPRINT XpGetPrinterList(3Xp)

NOMBRE

XpGetPrinterList - Recupera una lista de todas las impresoras soportadas en un Servidor de Impresión X.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

XPPrinterList XpGetPrinterList ( display, nombre_impresora, contador_lista_retorno )
Display *display;
char *nombre_impresora;
int *contador_lista_retorno;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
nombre_impresora
Especifica el nombre de la impresora para la cual se desea información. Si es NULL, se devuelve información para todas las impresoras asociadas al servidor.
contador_lista_retorno
Devuelve el número de impresoras en la lista.

DESCRIPCION

XpGetPrinterList devuelve una lista de registros de impresoras donde cada registro describe una impresora soportada por el Servidor de Impresión X, o NULL si ocurre algún error.

Si nombre_impresora es NULL, se devuelve una lista de todas las impresoras soportadas. Si nombre_impresora no es NULL, solo se devuelven los registros de impresión que coinciden con nombre_impresora, y si ningún registro coincide con nombre_impresora, se devuelve NULL.

nombre_impresora es una cadena COMPOUND_TEXT, y los campos name y desc en la lista devuelta estarán en COMPOUND_TEXT (nota, ISO 8859-1 (Latin-1) es un subconjunto propio de COMPOUND_TEXT, por lo que se puede usar directamente). Si nombre_impresora está en un conjunto de códigos que el Servidor de Impresión X no puede convertir (a su conjunto de códigos operativo), entonces el Servidor de Impresión X puede fallar al localizar la impresora solicitada. Si nombre_impresora es NULL, entonces los nombres de todas las impresoras, independientemente de su conjunto de códigos, pueden ser devueltos, dejando la tarea de reconocimiento de impresoras específicas al llamador.

Cuando se llama a XpGetPrinterList, la configuración regional del llamador (ver XpSetLocaleHinter) se incluye en la solicitud como una "sugerencia" al Servidor de Impresión X. Si es soportado por la implementación, el Servidor de Impresión X utilizará la sugerencia para localizar una descripción localizada para cada impresora en la lista. Si el Servidor de Impresión X no puede entender la sugerencia, el Servidor de Impresión X elegirá una por defecto. La lista de impresoras devuelta puede ser liberada llamando a XpFreePrinterList.

La estructura XPPrinterList definida en <X11/extensions/Print.h> contiene:

typedef struct {
    char *name;	/∗ name */
    char *desc;	/∗ localized description */
} XPPrinterRec, *XPPrinterList;

DIAGNOSTICOS

BadAlloc
Memoria insuficiente.

VER TAMBIÉN

XpFreePrinterList(3Xp), XpSetLocaleHinter(3Xp)
