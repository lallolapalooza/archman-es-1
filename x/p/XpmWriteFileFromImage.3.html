NOMBRE

XpmWriteFileFromImage - escribir un archivo XPM

SINOPSIS

int XpmWriteFileFromPixmap(Display *display, char *filename,
Pixmap pixmap, Pixmap shapemask, XpmAttributes *attributes);
int XpmWriteFileFromImage(Display *display , char *filename,
XImage *image, XImage *shapeimage, XpmAttributes *attributes);
int XpmWriteFileFromData(char *filename, char **data);
int XpmWriteFileFromXpmImage(char *filename, XpmImage *image,
XImage *shapeimage, XpmInfo *info);
int XpmWriteFileFromBuffer(char *filename, char *buffer);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
filename
Especifica el nombre del archivo a utilizar.
pixmap
Especifica el pixmap.
shapemask
Especifica el pixmap de máscara de forma.
attributes
Especifica la ubicación de una estructura que contiene información (o NULL).
data
Especifica la matriz de datos de la que leer.
image
Especifica la imagen.
info
Especifica la ubicación de una estructura para obtener información (o NULL).
buffer
Especifica el búfer del que leer.

DESCRIPCION

XpmWriteFileFromImage

La función XpmWriteFileFromImage() escribe una imagen y su posible shapeimage en un archivo en formato XPM. Si no se puede abrir el archivo, devuelve XpmOpenFailed. Si se asigna almacenamiento de trabajo insuficiente, devuelve XpmNoMemory. Si no ocurre ningún error, devuelve XpmSuccess. Si el puntero a la estructura XpmAttributes proporcionado no es NULL, XpmWriteFileFromImage() busca los siguientes atributos: XpmColormap, XpmHotspot, XpmCharsPerPixel, XpmRgbFilename y XpmExtensions. Como característica de compatibilidad retroactiva, XpmWriteFileFromImage() también busca los atributos XpmInfos. Si el nombre del archivo contiene una extensión como “.xpm”, para obtener un nombre de variable C válido, el carácter del punto se reemplaza por un guion bajo ’_’ al escribir. Como característica de compatibilidad retroactiva, si los atributos XpmInfos están definidos, escribe la información que se pueda haber almacenado, como comentarios, valores predeterminados de color y símbolos. Finalmente, si se define el atributo XpmRgbFilename, XpmWriteFileFromImage() busca nombres de color en este archivo y, si los encuentra, los escribe en lugar de los valores rgb.

Además, en sistemas que admiten dichas características, si el nombre del archivo dado termina en ’.Z’ o ’.gz’, se asume que es un archivo comprimido. Entonces, XpmWriteFileFromImage() escribe en un proceso de compresión o gzip canalizado. Y si en lugar de un nombre de archivo, se pasa NULL a XpmWriteFileFromImage(), escribe en la salida estándar.

XpmWriteFileFromPixmap

Para escribir un Pixmap en un archivo XPM, use XpmWriteFileFromPixmap().

Si el puntero a la estructura XpmAttributes proporcionado no es NULL, XpmWriteFileFromPixmap() busca los siguientes atributos: XpmSize. Si no están definidos, realiza una operación XGetGeometry. Luego, utiliza XGetImage para obtener de los pixmaps dados las imágenes X relacionadas, que se pasan a XpmWriteFileFromImage(). Finalmente, XpmWriteFileFromPixmap() destruye las imágenes creadas usando XDestroyImage. La función XpmWriteFileFromPixmap() devuelve los mismos errores que XpmWriteFileFromImage().

XpmWriteFileFromData

XpmWriteFileFromData() escribe una matriz de datos XPM en un archivo XPM.

XpmWriteFileToData() devuelve XpmOpenFailed si no puede abrir el archivo, XpmFileInvalid si no son datos XPM válidos y XpmSuccess en caso contrario.

XpmWriteFileFromXpmImage

Para escribir una XpmImage en un archivo XPM, use XpmWriteFileFromXpmImage(). La función XpmWriteFileFromXpmImage() escribe una imagen en un archivo en formato XPM. Si no se puede abrir el archivo, devuelve XpmOpenFailed. Si se asigna almacenamiento de trabajo insuficiente, devuelve XpmNoMemory. Si no ocurre ningún error, devuelve XpmSuccess. Si el puntero a la estructura XpmInfo proporcionado no es NULL, XpmWriteFileFromXpmImage() busca los siguientes atributos: XpmComments, XpmExtensions y XpmHotspot, y también escribe la información relacionada. Además, en sistemas que admiten dichas características, si el nombre del archivo dado termina en ’.Z’ o ’.gz’, se asume que es un archivo comprimido. Entonces, XpmWriteFileFromXpmImage() escribe en un proceso de compresión o gzip canalizado. Y si en lugar de un nombre de archivo, se pasa NULL a XpmWriteFileFromXpmImage(), escribe en la salida estándar.

XpmWriteFileFromBuffer

XpmWriteFileFromBuffer() escribe un búfer XPM en un archivo. XpmWriteFileFromBuffer() devuelve XpmOpenFailed si no puede abrir el archivo, y XpmSuccess en caso contrario.

Como conveniencia, se proporcionan las funciones XpmReadFileToBuffer() y XpmWriteFileFromBuffer() para copiar un archivo a un búfer y escribir un archivo desde un búfer. Por lo tanto, por ejemplo, uno puede decidir usar XpmCreateBufferFromPixmap(), XpmWriteFileFromBuffer() y XpmFree() en lugar de XpmWriteFileFromPixmap(). En algunos sistemas, esto puede mejorar el rendimiento, ya que el análisis se realizará en memoria, pero consume más memoria.

Manuales

Las páginas del manual se generan a partir de los archivos fuente de los programas y suelen contener una descripción de los comandos y sus opciones, así como información sobre cómo utilizarlos.

Las páginas del manual se almacenan en un conjunto de directorios dentro del sistema de archivos. Cada página del manual está contenida en un archivo de texto sin formato. El nombre de cada archivo de página del manual sigue el formato:

comando(sección)

Donde:

  • comando es el nombre del comando para el que está escrita la página del manual.
  • sección es un número que indica la sección a la que pertenece la página del manual. Las secciones más comunes son:
    • 1: Comandos de usuario generales
    • 2: Llamadas del sistema
    • 3: Funciones de la biblioteca C
    • 4: Archivos especiales y dispositivos
    • 5: Formatos de archivo y convenciones
    • 6: Juegos
    • 7: Varios
    • 8: Comandos de administración del sistema y demonios

Para ver una página del manual, puede utilizar el comando man. Por ejemplo, para ver la página del manual del comando ls, escriba:

man ls

Esto abrirá la página del manual en un visor de texto. Puede desplazarse por la página del manual utilizando las teclas de flecha o la barra espaciadora. Para salir del visor, presione la tecla q.

Las páginas del manual son un recurso valioso para los usuarios de Linux. Proporcionan información completa sobre los comandos y programas disponibles en el sistema. Al aprender a utilizar el comando man, puede obtener el máximo provecho de su sistema Linux.
