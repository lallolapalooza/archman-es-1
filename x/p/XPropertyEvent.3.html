NOMBRE

XPropertyEvent - Estructura del evento PropertyNotify

ESTRUCTURAS

La estructura para los eventos PropertyNotify contiene:

typedef struct {
        int type;       /* PropertyNotify */
        unsigned long serial;   /* # de la última petición procesada por el servidor */
        Bool send_event;        /* true si esto provino de una petición SendEvent */
        Display *display;       /* Display desde el que se leyó el evento */
        Window window;
        Atom atom;
        Time time;
        int state;      /* PropertyNewValue o PropertyDelete */
} XPropertyEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa de un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero al display en el que se leyó el evento. El miembro send_event se establece en True si el evento provino de una petición de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo pero expandido desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

El miembro window se establece en la ventana cuya propiedad asociada fue modificada. El miembro atom se establece en el átomo de la propiedad e indica qué propiedad fue modificada o deseada. El miembro time se establece en la hora del servidor en que se modificó la propiedad. El miembro state se establece para indicar si la propiedad fue modificada a un nuevo valor o eliminada, y puede ser PropertyNewValue o PropertyDelete. El miembro state se establece en PropertyNewValue cuando se modifica una propiedad de la ventana utilizando XChangeProperty o XRotateWindowProperties (incluso al agregar datos de longitud cero usando XChangeProperty) y al reemplazar todo o parte de una propiedad con datos idénticos usando XChangeProperty o XRotateWindowProperties. El miembro state se establece en PropertyDelete cuando se elimina una propiedad de la ventana utilizando XDeleteProperty o, si el argumento de eliminación es True, XGetWindowProperty.
