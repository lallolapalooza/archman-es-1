XpGetOneAttribute(3)

Paquete: libxp

Licencias: X11, X11-distribute-modifications-variant

XpGetOneAttribute(3Xp) FUNCIONES DE IMPRESIÓN XpGetOneAttribute(3Xp)

NOMBRE

XpGetOneAttribute - Obtiene un único atributo de impresión del contexto de impresión especificado.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

char *XpGetOneAttribute ( display, context, type, attribute_name )
Display *display;
XPContext context;
XPAttributes type;
char *attribute_name;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
context
El contexto de impresión del cual se va a recuperar el pool de atributos.
type
Especifica el pool de atributos.
attribute_name
El nombre del atributo que se va a devolver.

DESCRIPCIÓN

Esta solicitud devuelve un atributo de tipo COMPOUND_TEXT attribute_value, de lo contrario, NULL si ocurrió algún error. XpGetOneAttribute es una variación de XpGetAttributes para obtener un único valor de atributo de un pool de atributos. A diferencia de XpGetAttributes, donde la respuesta contiene un pool de atributos completo, XpGetOneAttribute devuelve solo un attribute_value. attribute_name no debe incluir dos puntos. Se espera que el llamante libere el valor del atributo devuelto usando XFree.

DIAGNÓSTICOS

BadAlloc
Memoria insuficiente.
BadValue
El valor especificado para type no es válido.
XPBadContext
El ID de contexto de impresión especificado no es válido.

VER TAMBIÉN
