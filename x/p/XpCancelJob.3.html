XpCancelJob(3)

Paquete: libxp

XpCancelJob(3Xp) FUNCIONES DE XPRINT XpCancelJob(3Xp)

NOMBRE

XpCancelJob - Cancela un trabajo de impresión individual.

SINOPSIS


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpCancelJob ( display, discard )
Display *display;
Bool discard;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
discard
Cuando es TRUE, especifica que todos los eventos XPPrintNotify deben ser descartados.

DESCRIPCIÓN

XpCancelJob cancela un trabajo en curso. Si el trabajo se inició con el modo de salida XPGetData, entonces la transmisión de datos a XpGetDocumentData se termina. Para muchos lenguajes de descripción de página, una terminación tan arbitraria puede invalidar la salida.

Si el trabajo se inició con el modo de salida XPSpool, dependiendo del controlador y la configuración del gestor de colas, se puede cancelar todo el trabajo o se puede generar un trabajo parcial.

Si discard es TRUE, todos los eventos XPPrintNotify con un campo de detalle de XPEndPageNotify, XPEndDocNotify, o XPEndJobNotify se descartan antes de que XpCancelJob devuelva.

Para los clientes que seleccionan XPPrintMask (ver XpSelectInput), se generará el evento XPPrintNotify con su campo de detalle establecido a XPEndJobNotify.

DIAGNÓSTICOS

XPBadContext
No se ha establecido un contexto de impresión válido antes de realizar esta llamada.
XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas del servicio de impresión X (por ejemplo, XpEndJob antes de XpStartJob).

VER TAMBIÉN

XpEndJob(3Xp), XpGetDocumentData(3Xp), XpSelectInput(3Xp), XpStartJob(3Xp)
