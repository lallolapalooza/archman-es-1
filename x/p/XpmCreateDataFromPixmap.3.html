XpmCreateData(3) Funciones de libXpm XpmCreateData(3)

NOMBRE

XpmCreateData - crear una estructura de datos

SINOPSIS

int XpmCreateDataFromImage(Display *display, char ***data_return,
XImage *image, XImage *shapeimage, XpmAttributes *attributes);
int XpmCreateDataFromPixmap(Display *display, char ***data_return,
Pixmap pixmap, Pixmap shapemask, XpmAttributes *attributes);
int XpmCreateDataFromXpmImage(char ***data_return, XpmImage *image,
XpmInfo *info);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
data_return
Devuelve los datos que se crean.
pixmap
Especifica el pixmap.
shapemask
Especifica el pixmap de máscara de forma.
attributes
Especifica la ubicación de una estructura que contiene información (o NULL).
info
Especifica la ubicación de una estructura para obtener información.
image
Especifica la imagen

DESCRIPCIÓN

XpmCreateDataFromImage

En algunos casos, se puede querer crear datos XPM a partir de un XImage, para ello use XpmCreateDataFromImage(). La función XpmCreateDataFromImage() funciona exactamente igual que XpmWriteFileFromImage(3) y devuelve el mismo resultado. Simplemente escribe en un único bloque de datos asignado con malloc en lugar de un archivo. Es responsabilidad del llamador liberar los datos, usando XpmFree(3) cuando haya terminado.

XpmCreateDataFromPixmap

XpmCreateDataFromPixmap() crea datos XPM a partir de un Pixmap. La función XpmCreateDataFromPixmap() utiliza XGetImage(3) para obtener de los pixmaps dados las imágenes X relacionadas, que se pasan a XpmCreateDataFromImage(). Luego destruye las imágenes creadas usando XDestroyImage(3). XpmCreateDataFromPixmap() devuelve los mismos errores que XpmCreateDataFromImage().

XpmCreateDataFromXpmImage

XpmCreateDataFromXpmImage() crea datos XPM a partir de un XpmImage. La función XpmCreateDataFromXpmImage() escribe la imagen dada en un único bloque de datos asignado con malloc en formato XPM. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory, y devuelve XpmSuccess en caso de éxito. Si el puntero de estructura XpmInfo proporcionado no es NULL, XpmCreateDataFromXpmImage() busca los siguientes atributos: XpmExtensions y XpmHotspot, y escribe la información relacionada también. Es responsabilidad del llamador liberar los datos, usando XpmFree(3) cuando haya terminado.

VER TAMBIÉN

XpmFree(3), XpmWriteFileFromImage(3)
