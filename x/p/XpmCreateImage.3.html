Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmCreateImage(3) Funciones de libXpm XpmCreateImage(3)

NOMBRE

XpmCreateImage - crear una XImage a partir de una XPM

SINOPSIS

int XpmCreateImageFromData(Display *display, char **data,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmCreateImageFromBuffer(Display *display, char *buffer,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmCreateImageFromXpmImage(Display *display,  XpmImage *image,
XImage *image_return, XImage *shapeimage_return,
XpmAttributes *attributes);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
data
Especifica la ubicación de los datos.
image_return
Devuelve la imagen que se crea.
shapeimage_return
Devuelve la imagen de máscara de forma que se crea si se utiliza el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información (o NULL).
shapeimage
Especifica la imagen de máscara de forma que se crea, si la hubiera.

DESCRIPCION

XpmCreateImageFromData

Para crear una XImage a partir de datos XPM, utiliza XpmCreateImageFromData().

La función XpmCreateImageFromData() te permite incluir en tu programa C un archivo XPM que fue exportado por funciones como XpmWriteFileFromImage(3) o XpmWriteFileFromPixmap(3) sin tener que leer el archivo. XpmCreateImageFromData() funciona exactamente igual que XpmReadFileToImage(3) y devuelve los mismos resultados. Simplemente lee datos en lugar de un archivo. Aquí también, es responsabilidad del que llama liberar las imágenes devueltas, los colores y posiblemente los datos devueltos en la estructura XpmAttributes.

XpmCreateImageFromBuffer

Para crear una XImage a partir de un búfer XPM, utiliza XpmCreateImageFromBuffer(). La función XpmCreateImageFromBuffer() funciona de la misma manera que XpmReadFileToImage(3), solo que analiza el búfer en lugar del archivo. Ten en cuenta que la función proporcionada en algunos sistemas por XpmReadFileToImage(3) para tratar archivos comprimidos no está disponible aquí.

XpmCreateImageFromXpmImage

Para crear una XImage a partir de una XpmImage, utiliza XpmCreateImageFromXpmImage(). A partir de la XpmImage y XpmAttributes dadas (si no son NULL), XpmCreateImageFromXpmImage() asigna colores y crea imágenes X siguiendo el mismo mecanismo que XpmReadFileToImage(3). Al finalizar, el que llama debe liberar las imágenes usando XDestroyImage(3), los colores usando XFreeColors(3) y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3).

VER TAMBIÉN

XpmFreeAttributes(3), XpmReadFileToImage(3)
