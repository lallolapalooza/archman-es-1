XpCreateContext(3Xp) FUNCIONES DE IMPRESIÓN XpCreateContext(3Xp)

NOMBRE

XpCreateContext - Crea e inicializa un nuevo contexto de impresión.

SINOPSIS


cc [ indicación... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

XPContext XpCreateContext ( display, nombre_impresora )
Display *display;
char *nombre_impresora;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
nombre_impresora
El nombre de una impresora en la pantalla. Cadena codificada como COMPOUND_TEXT.

DESCRIPCIÓN

XpCreateContext crea un nuevo contexto de impresión que se inicializa con los atributos predeterminados de la impresora y otra información disponible para nombre_impresora en la pantalla. Un contexto de impresión mantiene el nombre de la impresora, los atributos de impresión, las capacidades de fuente, el estado de impresión (renderizado) y los resultados, y es el objeto sobre el cual actúan las llamadas Xp.

Si la biblioteca no logra generar un nuevo ID de contexto de impresión, se devuelve un valor de None, de lo contrario, siempre se devuelve un ID de contexto de impresión. Si nombre_impresora es inválido, el Servidor de impresión X generará un BadMatch más adelante.

Una llamada a XpGetPrinterList devolverá una lista válida de valores para nombre_impresora. Todos los nombres de impresora en el Servicio de impresión X están codificados como COMPOUND_TEXT (del cual el conjunto de códigos ISO-8859-1 es un subconjunto propio).

Tan pronto como se crea un contexto de impresión, se puede acceder y modificar los atributos de impresión en él llamando a XpGetAttributes y XpSetAttributes, y las selecciones de eventos en él se pueden modificar llamando a XpSelectInput y XpInputSelected. Otras llamadas Xp que toman explícitamente un ID de contexto de impresión como parámetro actuarán directamente sobre ese contexto de impresión. Todas las llamadas Xp y X sin un parámetro de ID de contexto de impresión (por ejemplo, todas las llamadas orientadas a renderizado como XpStartJob y XDrawLine) requieren que se establezca un contexto de impresión en la conexión de pantalla (ver XpSetContext). El no establecer un contexto de impresión antes de llamar a una llamada dependiente del contexto de impresión generará un error de XPBadContext.

El XPContext devuelto por XpCreateContext es un XID y puede usarse para establecer el contexto de impresión en las conexiones de pantalla llamando a XpSetContext. El ID de XPContext puede ser compartido entre procesos y conexiones de pantalla. Es responsabilidad de los clientes que comparten un contexto de impresión coordinar su uso del contexto; por ejemplo, deben asegurarse de que los contextos de impresión en uso no se destruyan prematuramente.

El context_id permanece válido para todos los clientes hasta que 1) el cliente que crea el contexto de impresión cierre su conexión de pantalla, o 2) cualquier cliente llame a XpDestroyContext. El context_id puede mantenerse válido después de que la conexión de pantalla del cliente creador se cierre si se llama a XSetCloseDownMode en la pantalla con RetainPermanent o RetainTemporary.

Después de crear un contexto de impresión y, posiblemente, modificar el atributo de formato del documento XPDocAttr utilizando un valor de la lista de formatos disponibles que se muestran en los formatos-de-documento-soportados del atributo XPPrinterAttr, la aplicación debe consultar al Servidor de impresión X a través de XpGetScreenOfContext para obtener la pantalla que se ha asociado con el contexto de impresión, y luego crear todos los recursos del servidor que se utilizarán en el trabajo de impresión en esa pantalla. El no hacerlo resultará en un comportamiento indefinido.

Cuando se llama a XpCreateContext, la configuración regional del cliente (ver XpSetLocaleHinter) se incluye en la solicitud como una "sugerencia" para el Servidor de impresión X. Si es compatible con la implementación, el Servidor de impresión X utilizará la sugerencia para inicializar los grupos de atributos con cualquier valor de atributo localizado (por ejemplo, el atributo XPPrinterAttr legible por humanos "descriptor" puede estar disponible en varios idiomas diferentes, y la sugerencia se utilizará para seleccionar uno). Si el Servidor de impresión X no puede entender la sugerencia, el Servidor de impresión X elegirá un valor predeterminado.

Esta función puede generar un error BadMatch si el nombre_impresora especificado no existe en la pantalla, o si el servidor de impresión no pudo interpretar el conjunto de códigos especificado en nombre_impresora.

DIAGNÓSTICOS

BadMatch
El valor especificado para doc_fmt no es válido para el tipo de documento actual o el valor especificado para drawable no es válido para el contexto de impresión y la pantalla de impresión.
