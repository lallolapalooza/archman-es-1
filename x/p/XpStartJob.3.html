XpStartJob(3Xp) FUNCIONES XPRINT XpStartJob(3Xp)

NOMBRE

XpStartJob - Indica el inicio de un único trabajo de impresión.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

void XpStartJob ( display, output_mode )
Display *display;
XPSaveData output_mode;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
output_mode
Especifica cómo se manejarán los datos de salida de la impresora.

DESCRIPCIÓN

XpStartJob señala el inicio de un nuevo trabajo de impresión.

Si output_mode es XPSpool, el Servidor de Impresión X enviará automáticamente la salida de la impresora a la cola. Si output_mode es XPGetData, el Servidor de Impresión X almacenará en búfer la salida del documento para su recuperación por XpGetDocumentData. En este caso, el servidor de impresión suspende el procesamiento de más solicitudes en este contexto de impresión hasta que otro cliente envíe XpGetDocumentData. Las operaciones subsiguientes que utilizan el contexto de impresión pueden suspenderse en cualquier momento a la espera del procesamiento de las respuestas de XpGetDocumentData para leer cualquier salida almacenada en búfer.

XpStartJob establece el atributo job-owner del trabajo (incluido en el grupo XPJobAttr) inmediatamente antes de emitir la solicitud PrintStartJob. En sistemas POSIX, el atributo job-owner se establece usando getpwuid_r sobre el resultado de getuid. Este atributo puede ser utilizado por el Servidor de Impresión X para identificar al usuario ante el gestor de colas.

Todos los cambios en el grupo de atributos XPJobAttr (ver XpSetAttributes) deben realizarse antes de llamar a XpStartJob, después de lo cual se generará un XPBadSequence si se intentan realizar cambios, hasta que se llame a XpEndJob.

Para los clientes que seleccionan XPPrintMask (ver XpSelectInput), el evento XPPrintNotify se generará con su campo detail establecido a XPStartJobNotify cuando el Servidor de Impresión X haya completado la solicitud PrintStartJob.

Conceptualmente, un "Trabajo" es una colección de "Documentos", donde cada Documento es a su vez una colección de "Páginas". Dependiendo de las facilidades de impresión subyacentes al Servidor de Impresión X, estas delimitaciones pueden ser mapeadas por un controlador DDX en funcionalidades reales (por ejemplo, ver el atributo del servidor multiple-documents-supported).

ESTRUCTURAS

Los valores de XPSaveData para output_mode se definen en <X11/extensions/Print.h>. :

    #define XPSpool               1   /* Job data sent to spooler */
    #define XPGetData             2   /* Job data via XpGetDocumentData */

DIAGNOSTICOS

BadValue
El valor especificado para output_mode no es válido.
XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.
XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas del Servicio de Extensión de Impresión X (ejemplo, XpEndDoc antes de XpStartDoc).

VER TAMBIÉN

XpEndJob(3Xp), XpGetDocumentData(3Xp), XpSelectInput(3Xp), XpSetAttributes(3Xp), XpStartJob(3Xp)
