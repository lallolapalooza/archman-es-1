Licencias: X11, X11-distribute-modifications-variant

XpQueryVersion(3Xp) FUNCIONES DE XPRINT XpQueryVersion(3Xp)

NOMBRE

XpQueryVersion - Consulta un servidor X para determinar si soporta la Extensión de Servicio de Impresión X y, si es así, qué versión de la Extensión de Servicio de Impresión X.

SINOPSIS


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

Status XpQueryVersion ( display, major_version_return, minor_version_return )
Display *display;
short *major_version_return;
short *minor_version_return;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
major_version_return
Devuelve la versión principal si existe la Extensión de Servicio de Impresión X, de lo contrario cero.
minor_version_return
Devuelve la versión secundaria si existe la Extensión de Servicio de Impresión X, de lo contrario cero.

DESCRIPCION

XpQueryVersion determina si la Extensión de Servicio de Impresión X está presente. Se devuelve un Status distinto de cero si la extensión es soportada, de lo contrario se devuelve un Status cero. Si la extensión es soportada, se devuelven los números de versión principal y secundaria para indicar el nivel de soporte de la Extensión de Servicio de Impresión X.

La Extensión de Servicio de Impresión X se inicializa en la primera llamada a cualquier función de Servicio de Impresión X; no es necesario inicializar explícitamente la Extensión de Servicio de Impresión X.
