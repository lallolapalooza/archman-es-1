XpmWriteFileFromBuffer(3)

Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmWrite(3) Funciones de libXpm XpmWrite(3)

NOMBRE

XpmWrite - escribir un archivo XPM

SINOPSIS

int XpmWriteFileFromPixmap(Display *display, char *filename,
Pixmap pixmap, Pixmap shapemask, XpmAttributes *attributes);
int XpmWriteFileFromImage(Display *display , char *filename,
XImage *image, XImage *shapeimage, XpmAttributes *attributes);
int XpmWriteFileFromData(char *filename, char **data);
int XpmWriteFileFromXpmImage(char *filename, XpmImage *image,
XImage *shapeimage, XpmInfo *info);
int XpmWriteFileFromBuffer(char *filename, char *buffer);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
filename
Especifica el nombre del archivo a usar.
pixmap
Especifica el pixmap.
shapemask
Especifica el pixmap de máscara de forma.
attributes
Especifica la ubicación de una estructura que contiene información (o NULL).
data
Especifica el array de datos a leer.
image
Especifica la imagen.
info
Especifica la ubicación de una estructura para obtener información (o NULL).
buffer
Especifica el buffer a leer.

DESCRIPCIÓN

XpmWriteFileFromImage

La función XpmWriteFileFromImage() escribe una imagen y su posible shapeimage en un archivo con el formato XPM. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory. Si no ocurre ningún error, devuelve XpmSuccess. Si el puntero de estructura XpmAttributes pasado no es NULL, XpmWriteFileFromImage() busca los siguientes atributos: XpmColormap, XpmHotspot, XpmCharsPerPixel, XpmRgbFilename y XpmExtensions. Como característica de compatibilidad posterior, XpmWriteFileFromImage() también busca los atributos XpmInfos. Si el nombre de archivo contiene una extensión como “.xpm”, para obtener un nombre de variable C válido, el punto se reemplaza por un guion bajo ’_’ al escribir. Como característica de compatibilidad posterior, si se definen los atributos XpmInfos, escribe información potencialmente almacenada como comentarios, valores predeterminados de color y símbolos. Finalmente, si se define el atributo XpmRgbFilename, XpmWriteFileFromImage() busca nombres de color en este archivo y, si los encuentra, los escribe en lugar de los valores rgb.

Además, en sistemas que admiten tales características, si el nombre de archivo dado termina en ’.Z’ o ’.gz’, se asume que es un archivo comprimido. Entonces, XpmWriteFileFromImage() escribe a un proceso compress o gzip canalizado. Y si en lugar de un nombre de archivo, se pasa NULL a XpmWriteFileFromImage(), escribe a la salida estándar.

XpmWriteFileFromPixmap

Para escribir un Pixmap en un archivo XPM, use XpmWriteFileFromPixmap().

Si el puntero de estructura XpmAttributes pasado no es NULL, XpmWriteFileFromPixmap() busca los siguientes atributos: XpmSize. Si no están definidos, realiza una operación XGetGeometry. Luego usa XGetImage para obtener de los pixmaps dados las imágenes X relacionadas que se pasan a XpmWriteFileFromImage(). Finalmente, XpmWriteFileFromPixmap() destruye las imágenes creadas usando XDestroyImage. La función XpmWriteFileFromPixmap() devuelve los mismos errores que XpmWriteFileFromImage().

XpmWriteFileFromData

XpmWriteFileFromData() escribe un array de datos XPM en un archivo XPM.

XpmWriteFileToData() devuelve XpmOpenFailed si no puede abrir el archivo, XpmFileInvalid si no son datos XPM válidos, y XpmSuccess en caso contrario.

XpmWriteFileFromXpmImage

Para escribir una XpmImage en un archivo XPM, use XpmWriteFileFromXpmImage(). La función XpmWriteFileFromXpmImage() escribe una imagen en un archivo con formato XPM. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory. Si no ocurre ningún error, devuelve XpmSuccess. Si el puntero de estructura XpmInfo pasado no es NULL, XpmWriteFileFromXpmImage() busca los siguientes atributos: XpmComments, XpmExtensions y XpmHotspot, y escribe también la información relacionada. Además, en sistemas que admiten tales características, si el nombre de archivo dado termina en ’.Z’ o ’.gz’, se asume que es un archivo comprimido. Entonces, XpmWriteFileFromXpmImage() escribe a un proceso compress o gzip canalizado. Y si en lugar de un nombre de archivo, se pasa NULL a XpmWriteFileFromXpmImage(), escribe a la salida estándar.

XpmWriteFileFromBuffer

XpmWriteFileFromBuffer() escribe un buffer XPM en un archivo. XpmWriteFileFromBuffer() devuelve XpmOpenFailed si no puede abrir el archivo, y XpmSuccess en caso contrario.

Como conveniencia, se proporcionan las funciones XpmReadFileToBuffer() y XpmWriteFileFromBuffer() para copiar un archivo a un buffer y para escribir un archivo desde un buffer. Así, por ejemplo, se puede optar por usar XpmCreateBufferFromPixmap(), XpmWriteFileFromBuffer() y XpmFree() en lugar de XpmWriteFileFromPixmap(). En algunos sistemas esto puede mejorar el rendimiento, ya que el análisis se realizará en memoria, pero consume más memoria.
