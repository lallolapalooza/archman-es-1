XpGetImageResolution(3Xp) FUNCIONES DE XPRINT XpGetImageResolution(3Xp)

NOMBRE

XpGetImageResolution - Obtiene la resolución de imagen actual para un contexto de impresión.

SINOPSIS


cc [ flag... ] archivo... -lXp [ librería... ]
#include <X11/extensions/Print.h>

int XpGetImageResolution ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTOS

display
Especifica un puntero a la estructura Display.
print_context
Especifica el contexto de impresión sobre el cual obtener la resolución.

DESCRIPCIÓN

XpGetImageResolution devuelve la resolución de imagen actual para el contexto de impresión especificado. Un valor de cero significa que la resolución sigue automáticamente la resolución de la impresora. Si la solicitud falla de alguna manera, se devuelve un valor negativo.

DIAGNÓSTICOS

XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.
