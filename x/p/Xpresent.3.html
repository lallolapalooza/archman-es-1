NOMBRE

Xpresent - Extensión X Present

SINTAXIS

#include <X11/extensions/Xpresent.h>

Bool XPresentQueryExtension (Display *dpy, int *major_opcode_return,
	int *event_base_return, int *error_base_return);

Status XPresentQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

int XPresentVersion (void);

ARGUMENTOS

dpy
Especifica la conexión al servidor X.

DESCRIPCIÓN

Xpresent es una biblioteca diseñada para interactuar con la Extensión X Present. La extensión Present proporciona una forma para que las aplicaciones actualicen el contenido de sus ventanas desde un pixmap de manera bien definida, sincronizándose con la actualización de la pantalla y potencialmente utilizando un mecanismo más eficiente que copiar el contenido del pixmap de origen.

La función XPresentQueryExtension verifica si el servidor X especificado por dpy soporta la extensión X Present. Si el servidor no soporta la extensión, devuelve False. Si el servidor soporta la extensión, devuelve True y establece los valores de major_opcode_return, event_base_return y error_base_return si los punteros no son NULL.

Los clientes deben llamar a la función XPresentQueryExtension para verificar que el servidor soporta la extensión antes de llamar a cualquier otra función para esta extensión.

La función XPresentQueryVersion establece los valores a los que apuntan major_version_return y minor_version_return a la versión de la extensión soportada por el servidor X especificado por dpy. La función XPresentQueryVersion devuelve la versión de la biblioteca libXpresent en uso, tal como se define en la macro PRESENT_VERSION en <X11/extensions/Xpresent.h>.

VER TAMBIÉN

XPresentNotifyMSC(3), XPresentPixmap(3), XPresentQueryCapabilities(3), XPresentSelectInput(3)

RESTRICCIONES

Xpresent seguirá siendo compatible con versiones anteriores después del lanzamiento 1.0.
