XpmMisc(3) Funciones de libXpm XpmMisc(3)

NOMBRE

XpmMisc - funciones varias de xpm para liberar memoria usada y manejar errores

SINOPSIS

int XpmFreeXpmImage(XpmImage *imagen);
int XpmFreeXpmInfo(XpmInfo *info);
int XpmFreeAttributes(XpmAttributes *atributos);
int XpmAttributesSize(void);
int XpmFreeExtensions(XpmExtension *extensiones,  int nextensiones);
int XpmFree(char *ptr);
char *XpmGetErrorString(int codigodeerror);
int XpmLibraryVersion(void);

ARGUMENTOS

imagen
Especifica la estructura a liberar
info
Especifica la estructura a liberar
ptr
Especifica los datos a liberar
codigodeerror
Especifica el error de XPM
extensiones
Especifica el array a liberar
nextensiones
Especifica el número de extensiones
atributos
Especifica la estructura a liberar

DESCRIPCIÓN

Para liberar posibles datos almacenados en una estructura XpmImage, usa XpmFreeXpmImage(). La función XpmFreeXpmImage() libera los miembros de la estructura que no son NULL, pero no la estructura en sí.

Para liberar posibles datos almacenados en una estructura XpmInfo, usa XpmFreeXpmInfo().

Para liberar posibles datos almacenados en un array de XpmExtension, usa XpmFreeExtensions().

Para liberar cualquier dato asignado por una función de XPM, usa la función XpmFree(). La distribución actual de la biblioteca XPM usa las funciones de asignación de memoria estándar y, por lo tanto, XpmFree() no es más que una macro para la función estándar free(3). Sin embargo, dado que estas funciones pueden ser redefinidas en entornos específicos, es aconsejable usar XpmFree().

Para liberar posibles datos almacenados en una estructura XpmAttributes, usa XpmFreeAttributes(). La función XpmFreeAttributes() libera los miembros de la estructura que han sido asignados con malloc(), como la lista de píxeles.

Para asignar dinámicamente una estructura XpmAttributes, usa la función XpmAttributesSize(). La función XpmAttributesSize() proporciona a las aplicaciones que usan bibliotecas dinámicas una forma segura de asignar y luego referirse a una estructura XpmAttributes, sin importar si el tamaño de la estructura XpmAttributes ha cambiado o no desde la compilación.

Para obtener datos al construir un mensaje de error, se puede usar XpmGetErrorString(). XpmGetErrorString() devuelve una cadena relacionada con el código de error XPM dado.

La función XpmLibraryVersion() puede ser usada cuando se necesita averiguar qué versión de la biblioteca se está utilizando. El valor devuelto por XpmLibraryVersion() puede compararse con el valor de XpmIncludeVersion, que está definido en el archivo de cabecera "xpm.h". Estos números se calculan con la siguiente fórmula:

 (XpmFormat * 100 + XpmVersion) * 100 + XpmRevision

donde XpmFormat es el número de versión del formato, XpmVersion es el número de versión de la biblioteca (que solo cambia si la API cambia), y XpmRevision es el número de versión menor de la biblioteca.

La función XpmFreeExtensions() libera todos los datos almacenados en cada extensión y el array en sí. Ten en cuenta que XpmFreeAttributes() llama a esta función y, por lo tanto, la mayoría de las veces no necesitará ser llamada explícitamente.
