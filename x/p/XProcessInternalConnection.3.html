XAddConnectionWatch(3) FUNCIONES XLIB XAddConnectionWatch(3)

NOMBRE

XAddConnectionWatch, XRemoveConnectionWatch, XProcessInternalConnection, XInternalConnectionNumbers - gestionar conexiones internas de Xlib

SINTAXIS

typedef void (*XConnectionWatchProc)(Display *display, XPointer client_data, int fd, Bool opening, XPointer *watch_data);

Status XAddConnectionWatch(Display *display, XConnectionWatchProc procedure, XPointer client_data);

void XRemoveConnectionWatch(Display *display, XConnectionWatchProc procedure, XPointer client_data);

void XProcessInternalConnection(Display *display, int fd);

Status XInternalConnectionNumbers(Display *display, int **fd_return, int *count_return);

ARGUMENTOS

client_data
Especifica los datos adicionales del cliente.
count_return
Devuelve el número de descriptores de archivo.
display
Especifica la conexión al servidor X.
fd
Especifica el descriptor de archivo.
fd_return
Devuelve los descriptores de archivo.
procedure
Especifica el procedimiento a llamar.

DESCRIPCIÓN

La función XAddConnectionWatch registra un procedimiento que se llamará cada vez que Xlib abra o cierre una conexión interna para la pantalla especificada. Al procedimiento se le pasan la pantalla, el client_data especificado, el descriptor de archivo para la conexión, un booleano que indica si la conexión se está abriendo o cerrando, y un puntero a una ubicación para datos privados de vigilancia. Si opening es True, el procedimiento puede almacenar un puntero a datos privados en la ubicación apuntada por watch_data; cuando el procedimiento se llame más tarde para esta misma conexión y opening sea False, la ubicación apuntada por watch_data contendrá el mismo puntero de datos privados.

Esta función puede ser llamada en cualquier momento después de que se abra una pantalla. Si ya existen conexiones internas, el procedimiento registrado se llamará inmediatamente para cada una de ellas, antes de que XAddConnectionWatch devuelva. XAddConnectionWatch devuelve un estado distinto de cero si el procedimiento se registra correctamente; de lo contrario, devuelve cero.

El procedimiento registrado no debe llamar a ninguna función de Xlib. Si el procedimiento causa directa o indirectamente que el estado de las conexiones internas o los procedimientos de vigilancia cambie, el resultado no está definido. Si Xlib se ha inicializado para hilos, el procedimiento se llama con la pantalla bloqueada y el resultado de una llamada del procedimiento a cualquier función de Xlib que bloquee la pantalla no está definido a menos que el hilo que se ejecuta haya bloqueado externamente la pantalla usando XLockDisplay.

La función XRemoveConnectionWatch elimina un procedimiento de vigilancia de conexión registrado previamente. El client_data debe coincidir con el client_data utilizado cuando el procedimiento se registró inicialmente.

La función XProcessInternalConnection procesa la entrada disponible en una conexión interna. Esta función debe llamarse para una conexión interna solo después de que una instalación del sistema operativo (por ejemplo, select o poll) haya indicado que hay entrada disponible; de lo contrario, el efecto no está definido.

La función XInternalConnectionNumbers devuelve una lista de los descriptores de archivo para todas las conexiones internas actualmente abiertas para la pantalla especificada. Cuando la lista asignada ya no sea necesaria, libérela usando XFree. Esta función devuelve un estado distinto de cero si la lista se asigna correctamente; de lo contrario, devuelve cero.
