XpGetAttributes(3Xp) FUNCIONES DE XPRINT XpGetAttributes(3Xp)

NOMBRE

XpGetAttributes - Obtiene un conjunto de atributos del contexto de impresión especificado.

SINOPSIS


cc [ flag... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

char *XpGetAttributes ( display, context, type )
Display *display;
XPContext context;
XPAttributes type;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
context
El contexto de impresión del cual se va a recuperar el conjunto de atributos.
type
Especifica el conjunto de atributos.

DESCRIPCIÓN

XpGetAttributes devuelve un conjunto (pool), una cadena de recursos COMPOUND_TEXT que representa el conjunto de atributos especificado por type. Se espera que el llamante libere el conjunto (pool) cuando ya no sea necesario utilizando XFree.

El conjunto de atributos (y por lo tanto la cadena de recursos) consta de muchos pares nombre-valor (por ejemplo, "copy-count: 3"). La sintaxis de un conjunto de atributos es la misma que la de un archivo de recursos X (ver "Sintaxis de archivos de recursos" en la especificación de Xlib).

Los caracteres válidos para cada nombre (lado izquierdo) se derivan de Posix, que son "a"-"z" y "A"="Z" y "0"-"9" y "_" y "-". Los caracteres válidos para cada valor (lado derecho) son todos los caracteres excepto NULL y NEWLINE sin escapar, aunque todos los valores predefinidos en el Servicio de Impresión X están confinados a caracteres del Conjunto de Caracteres Portátil X (XPCS). Los valores que no son XPCS normalmente se limitan a cadenas de "descripción" localizadas. Ver XpCreateContext sobre la pista de localización para más información sobre valores localizados.

Si ocurre algún error, XpGetAttributes devuelve NULL.

ESTRUCTURAS

Los valores para el typedef XPAttributes en <X11/extensions/Print.h> son:

 #define  XPJobAttr		1 /∗ obtener/establecer */
 #define  XPDocAttr		2 /∗ obtener/establecer */
 #define  XPPageAttr	3 /∗ obtener/establecer-subconjunto de XPDocAttr */
 #define  XPPrinterAttr	4 /∗ solo obtener (biblioteca) */
 #define  XPServerAttr	5 /∗ solo obtener (biblioteca), no se necesita contexto */

DIAGNÓSTICOS

BadAlloc
Memoria insuficiente.
BadValue
El valor especificado para type no es válido.
XPBadContext
El ID de contexto de impresión especificado no es válido.
