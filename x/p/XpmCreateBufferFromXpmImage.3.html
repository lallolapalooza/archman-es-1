XpmCreateBufferFromXpmImage(3)

Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmCreateBuffer(3) Funciones de libXpm XpmCreateBuffer(3)

NOMBRE

XpmCreateBuffer - crear un buffer XPM

SINOPSIS

int XpmCreateBufferFromImage(Display *display , char **buffer_return,
XImage *image, XImage *shapeimage, XpmAttributes *attributes);
int XpmCreateBufferFromPixmap(Display *display, char **buffer_return,
Pixmap pixmap, Pixmap shapemask, XpmAttributes *attributes);
int XpmCreateBufferFromXpmImage(char **buffer_return, XpmImage *image,
XpmInfo *info);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
buffer_return
Devuelve el buffer que se crea.
image
Especifica la imagen.
shapeimage
Especifica la máscara de forma de la imagen.
attributes
Especifica la ubicación de una estructura que contiene información (o NULL).
info
Especifica la ubicación de una estructura para obtener información posible (o NULL).

DESCRIPCION

XpmCreateBufferFromPixmap

XpmCreateBufferFromPixmap() crea un buffer XPM a partir de un Pixmap. La función XpmCreateBufferFromPixmap() funciona como XpmWriteFileFromPixmap(3), simplemente llama a XpmCreateBufferFromImage() en lugar de a XpmWriteFileFromImage(3). Una vez más, el llamante debe liberar el buffer usando XpmFree(3) cuando haya terminado.

Como conveniencia, se proporcionan las funciones XpmReadFileToBuffer(3) y XpmWriteFileFromBuffer(3) para copiar un archivo a un buffer y escribir un archivo desde un buffer. Por lo tanto, por ejemplo, uno puede decidir usar XpmCreateBufferFromPixmap(), XpmWriteFileFromBuffer(3) y XpmFree(3) en lugar de XpmWriteFileFromPixmap(3). En algunos sistemas esto puede llevar a una mejora del rendimiento, ya que el procesamiento se realizará en memoria, pero consume más memoria.

XpmCreateBufferFromImage

La función XpmCreateBufferFromImage() funciona como XpmWriteFileFromImage(3), simplemente escribe en un buffer reservado con malloc en lugar de en un archivo. El llamante debe liberar el buffer usando XpmFree(3) cuando haya terminado.

XpmCreateBufferFromXpmImage.

Para crear un buffer XPM a partir de un XpmImage, use XpmCreateBufferFromXpmImage(). La función XpmCreateBufferFromXpmImage() escribe la imagen dada en un único bloque de buffer reservado con malloc en formato XPM. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory y devuelve XpmSuccess en caso de éxito. Si el puntero de la estructura XpmInfo pasado no es NULL, XpmCreateBufferFromXpmImage() busca los siguientes atributos: XpmComments, XpmExtensions y XpmHotspot, y escribe la información relacionada también. El llamante debe liberar el buffer usando XpmFree(3) cuando haya terminado.

VER TAMBIÉN

XpmFree(3), XpmWriteFileFromBuffer(3), XpmWriteFileFromImage(3), XpmWriteFileFromPixmap(3)
