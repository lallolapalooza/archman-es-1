XpSetAttributes(3)

Paquete: libxp

Licencias: X11, X11-distribute-modifications-variant

XpSetAttributes(3Xp) FUNCIONES DE XPRINT XpSetAttributes(3Xp)

NOMBRE

XpSetAttributes - Establece o actualiza un grupo de atributos en el contexto de impresión especificado.

SINOPSIS


cc [ indicador... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

void XpSetAttributes ( display, context, type, pool, replacement_rule )
Display *display;
XPContext context;
XPAttributes type;
char *pool;
XPAttrReplacement replacement_rule;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
context
El contexto de impresión cuyo grupo de atributos se va a modificar.
type
Especifica el grupo de atributos.
pool
Un grupo de atributos representado como una cadena de recursos. Codificado en COMPOUND_TEXT.
replacement_rule
XPAttrReplace o XPAttrMerge.

DESCRIPCION

XpSetAttributes acepta pool, una cadena de recursos COMPOUND_TEXT que representa nuevos pares nombre-valor para el grupo de atributos especificado por type. El grupo de atributos se modifica con los nuevos pares nombre-valor según replacement_rule. Para XPAttrReplace, el grupo de atributos existente se descarta y se reemplaza por pool. Para XPAttrMerge, pool se fusiona en el grupo de atributos existente; los pares nombre-valor preexistentes se reemplazan y los pares nombre-valor no existentes se añaden. El contenido de pool no se ve afectado por esta llamada y puede ser liberado por el llamador posteriormente.

Al establecer nombres de atributos compatibles, el Servidor de Impresión X y el controlador asociado validarán los nuevos valores e ignorarán los que no sean válidos; los valores anteriores permanecerán sin cambios. Al establecer nombres de atributos no compatibles (es decir, desconocidos), no se realiza ninguna validación y los pares nombre-valor se establecerán, aunque no se utilizarán.

Al establecer ciertos atributos compatibles, el Servidor de Impresión X puede modificar otros atributos asociados. Por ejemplo, considerando el atributo XPPrinterAttr document-formats-supported, al establecer el atributo XPDocAttr document-format puede hacer que otros atributos cambien.

Para los grupos de atributos que son de solo lectura (ver "solo lectura" en la definición de XPAttributes), intentar usar XpSetAttributes genera un BadMatch. Para los grupos de atributos que son escribibles, las listas de atributos compatibles se pueden encontrar en el grupo XPPrinterAttr.

La vida útil de todos los grupos de atributos está limitada por la vida útil del contexto de impresión en el que se encuentran. Una vez establecidos, todos los valores de los atributos se conservarán en todas las operaciones de Xp, hasta que sean cambiados directamente por el usuario, directamente por el Servidor de Impresión X, o cambiados debido a un efecto secundario cuando el usuario o el Servidor de Impresión X cambiaron otro valor de atributo.

Consulte una descripción completa de todos los atributos de impresión, la precedencia entre los atributos de impresión y los efectos secundarios de establecer ciertos atributos de impresión en otros atributos de impresión, etc.

Para supervisar los cambios en los grupos de atributos, consulte XpSelectInput y el evento XPAttributeNotify. Dado que un contexto de impresión puede ser compartido entre clientes, los cambios realizados por un cliente serán vistos por todos los demás, y si se selecciona, el evento XPAttributeNotify se enviará a todos los clientes que referencien el contexto de impresión cuando ocurran cambios. Es responsabilidad de los clientes que comparten un contexto de impresión coordinar sus operaciones.

ESTRUCTURAS

Los valores para el tipo definido XPAttributes en <X11/extensions/Print.h> son:

    #define XPJobAttr		1	/∗ obtener/establecer */
    #define XPDocAttr		2	/∗ obtener/establecer */
    #define XPPageAttr		3	/∗ obtener/establecer - subconjunto de XPDocAttr */
    #define XPPrinterAttr	4	/∗ solo obtener (biblioteca) */
    #define XPServerAttr		5	/∗ solo obtener (biblioteca), no se necesita contexto */

Los valores para el tipo definido XPAttrReplacement en <X11/extensions/Print.h> son:

    #define XPAttrReplace	1
    #define XPAttrMerge		2

DIAGNÓSTICOS

BadAlloc
Memoria insuficiente.
BadMatch
El grupo de atributos especificado por pool no se puede establecer.
BadValue
El valor especificado para type no es válido.
XPBadContext
El ID del contexto de impresión especificado no es válido.
XPBadSequence
Se realizó una solicitud para establecer un grupo de atributos en un momento en que el grupo de atributos no se podía modificar (por ejemplo, modificar XPJobAttr inmediatamente después de llamar a XpStartJob).
