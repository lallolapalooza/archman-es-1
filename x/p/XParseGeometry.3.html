NOMBRE

XParseGeometry, XWMGeometry - analizar la geometría de la ventana

SINTAXIS

int XParseGeometry(_Xconst char *cadena_analizar, int *x_retorno, int *y_retorno, unsigned int *ancho_retorno, unsigned int *alto_retorno);

int XWMGeometry(Display *display, int pantalla, _Xconst char *geom_usuario, _Xconst char *geom_def, unsigned int ancho_borde, XSizeHints *indicaciones, int *x_retorno, int *y_retorno, int *ancho_retorno, int *alto_retorno, int *gravedad_retorno);

DESCRIPCIÓN

Por convención, las aplicaciones X utilizan una cadena estándar para indicar el tamaño y la colocación de la ventana. XParseGeometry facilita el cumplimiento de este estándar porque le permite analizar la geometría estándar de la ventana. Específicamente, esta función le permite analizar cadenas del siguiente formato:

[=][<ancho>{xX}<alto>][{+-}<desplazamiento_x>{+-}<desplazamiento_y>]

Los campos se mapean en los argumentos asociados con esta función. (Los elementos entre <> son enteros, los elementos entre [] son opcionales y los elementos entre {} indican "elige uno". Tenga en cuenta que los corchetes no deben aparecer en la cadena real). Si la cadena no está en la Codificación de Caracteres Portátil del Host, el resultado depende de la implementación.

La función XParseGeometry devuelve una máscara de bits que indica cuáles de los cuatro valores (ancho, alto, desplazamiento_x y desplazamiento_y) se encontraron realmente en la cadena y si los valores x e y son negativos. Por convención, -0 no es igual a +0, porque el usuario debe poder decir "coloca la ventana relativa al borde derecho o inferior". Por cada valor encontrado, se actualiza el argumento correspondiente. Para cada valor no encontrado, el argumento se deja sin cambios. Los bits están representados por XValue, YValue, WidthValue, HeightValue, XNegative o YNegative y están definidos en X11/Xutil.h. Se establecerán cada vez que se defina uno de los valores o se establezca uno de los signos.

Si la función devuelve el indicador XValue o YValue, debe colocar la ventana en la posición solicitada.

La función XWMGeometry combina cualquier información de geometría (dada en el formato utilizado por XParseGeometry) especificada por el usuario y por el programa que llama, con indicaciones de tamaño (generalmente las que se almacenarán en WM_NORMAL_HINTS) y devuelve la posición, el tamaño y la gravedad (NorthWestGravity, NorthEastGravity, SouthEastGravity o SouthWestGravity) que describen la ventana. Si el tamaño base no está establecido en la estructura XSizeHints, se utiliza el tamaño mínimo si está establecido. De lo contrario, se asume un tamaño base de cero. Si no se establece un tamaño mínimo en la estructura de indicaciones, se utiliza el tamaño base. Se devuelve una máscara (en el formato devuelto por XParseGeometry) que describe qué valores provinieron de la especificación del usuario y si las coordenadas de posición son relativas a los bordes derecho e inferior. Tenga en cuenta que estas coordenadas ya se han tenido en cuenta en los valores x_retorno y y_retorno.

Tenga en cuenta que las especificaciones de geometría no válidas pueden provocar que se devuelva un ancho o alto de cero. El llamador puede pasar la dirección del campo win_gravity de las indicaciones como gravity_return para actualizar las indicaciones directamente.
