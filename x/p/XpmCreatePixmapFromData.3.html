XpmCreatePixmap(3) Funciones de libXpm XpmCreatePixmap(3)

NOMBRE

XpmCreatePixmap - crear un pixmap

SINOPSIS

int XpmCreatePixmapFromData(Display *display, Drawable d,
char **data, Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmCreatePixmapFromBuffer(Display *display, Drawable d,
char *buffer, Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmCreatePixmapFromXpmImage(Display *display, Drawable d,
XpmImage *image, Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
d
Especifica en qué pantalla se crea el pixmap.
buffer
Especifica la ubicación del buffer.
pixmap_return
Devuelve el pixmap que se crea si el color es None.
shapemask_return
Devuelve el pixmap de máscara de forma que se crea si se utiliza el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información.
image
Especifica la XpmImage.

DESCRIPCIÓN

XpmCreatePixmapFromData

Para crear un Pixmap a partir de datos XPM, utilice XpmCreatePixmapFromData(). La función XpmCreatePixmapFromData() crea imágenes X utilizando XpmCreateImageFromData(3) y, por lo tanto, devuelve los mismos errores. Además, en caso de éxito, crea los pixmaps relacionados utilizando XPutImage(3), que se devuelven a pixmap_return y shapemask_return si no son NULL, y finalmente destruye las imágenes creadas utilizando XDestroyImage(3). No olvide liberar los pixmaps devueltos, los colores y, posiblemente, los datos devueltos en la estructura XpmAttributes cuando haya terminado.

XpmCreatePixmapFromBuffer

Para crear un Pixmap a partir de un buffer XPM, utilice XpmCreatePixmapFromBuffer(). La función XpmCreatePixmapFromBuffer() funciona de la misma manera que XpmReadFileToPixmap(3), solo llama a XpmCreateImageFromBuffer(3) en lugar de XpmReadFileToImage(3).

XpmCreatePixmapFromXpmImage

XpmCreatePixmapFromXpmImage() crea imágenes X llamando a XpmCreateImageFromXpmImage(3) con la XpmImage y XpmAttributes dadas, luego crea los pixmaps relacionados que se devuelven a pixmap_return y shapemask_return utilizando XPutImage(3). Finalmente, destruye las imágenes X con XDestroyImage(3). Al finalizar, el llamador debe liberar los pixmaps utilizando XFreePixmap(3), los colores utilizando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes utilizando XpmFreeAttributes(3).

VER TAMBIÉN

XpmCreateImageFromData(3), XpmCreateImageFromXpmImage(3), XpmFreeAttributes(3), XpmReadFileToPixmap(3)
