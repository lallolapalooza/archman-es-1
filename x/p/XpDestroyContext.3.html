XpDestroyContext(3Xp) FUNCIONES DE XPRINT XpDestroyContext(3Xp)

NOMBRE

XpDestroyContext - Obtiene el ID del contexto de impresión actual para una conexión de pantalla.

SINOPSIS


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpDestroyContext ( display, print_context )
Display *display;
XPContext print_context;

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.
print_context
Especifica el contexto de impresión a destruir.

DESCRIPCIÓN

XpDestroyContext cierra cualquier asociación pendiente entre el contexto de impresión y las conexiones de pantalla, y luego destruye el contexto de impresión. Todas las conexiones de pantalla que utilicen el contexto de impresión ya no podrán acceder al contexto de impresión.

La destrucción de un contexto de impresión provocará la cancelación de cualquier página, documento o trabajo en curso dentro del Servidor de Impresión X.

DIAGNÓSTICOS

XPBadContext
No se ha establecido un ID de contexto de impresión válido antes de realizar esta llamada.
