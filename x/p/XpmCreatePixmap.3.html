XpmCreatePixmap(3)

Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmCreatePixmap(3) Funciones de libXpm XpmCreatePixmap(3)

NOMBRE

XpmCreatePixmap - crear un pixmap

SINOPSIS

int XpmCreatePixmapFromData(Display *display, Drawable d,
char **data, Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmCreatePixmapFromBuffer(Display *display, Drawable d,
char *buffer, Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmCreatePixmapFromXpmImage(Display *display, Drawable d,
XpmImage *image, Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
d
Especifica en qué pantalla se crea el pixmap.
buffer
Especifica la ubicación del búfer.
pixmap_return
Devuelve el pixmap que se crea si el color es None.
shapemask_return
Devuelve el pixmap de máscara de forma que se crea si se utiliza el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información.
image
Especifica la XpmImage.

DESCRIPCIÓN

XpmCreatePixmapFromData

Para crear un Pixmap a partir de datos XPM, utiliza XpmCreatePixmapFromData(). La función XpmCreatePixmapFromData() crea imágenes X utilizando XpmCreateImageFromData(3) y, por lo tanto, devuelve los mismos errores. Además, al tener éxito, crea los pixmaps relacionados, utilizando XPutImage(3), que se devuelven a pixmap_return y shapemask_return si no son NULL, y finalmente destruye las imágenes creadas utilizando XDestroyImage(3). No olvides liberar los pixmaps devueltos, los colores y posiblemente los datos devueltos en la estructura XpmAttributes cuando hayas terminado.

XpmCreatePixmapFromBuffer

Para crear un Pixmap a partir de un búfer XPM, utiliza XpmCreatePixmapFromBuffer(). La función XpmCreatePixmapFromBuffer() funciona de manera similar a XpmReadFileToPixmap(3), simplemente llama a XpmCreateImageFromBuffer(3) en lugar de XpmReadFileToImage(3).

XpmCreatePixmapFromXpmImage

XpmCreatePixmapFromXpmImage() crea imágenes X llamando a XpmCreateImageFromXpmImage(3) con la XpmImage y XpmAttributes dadas, luego crea los pixmaps relacionados que se devuelven a pixmap_return y shapemask_return utilizando XPutImage(3). Finalmente, destruye las imágenes X con XDestroyImage(3). Cuando hayas terminado, el llamador debe liberar los pixmaps utilizando XFreePixmap(3), los colores utilizando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilicen las funciones estándar de Xlib, y posiblemente los datos devueltos en las XpmAttributes utilizando XpmFreeAttributes(3).

VER TAMBIÉN

XpmCreateImageFromData(3), XpmCreateImageFromXpmImage(3), XpmFreeAttributes(3), XpmReadFileToPixmap(3)
