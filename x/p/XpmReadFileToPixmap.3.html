Paquete: libxpm

XpmRead(3) Funciones de libXpm XpmRead(3)

NOMBRE

XpmRead - leer un archivo XPM

SINOPSIS

int XpmReadFileToImage(Display *display, char *filename,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmReadFileToPixmap(Display *display, Drawable d, char *filename,
Pixmap *pixmap_return, Pixmap *shapemask_return,
XpmAttributes *attributes);
int XpmReadFileToXpmImage(char *filename, XpmImage *image,
XpmInfo *info);
int XpmReadFileToBuffer(char *filename, char **buffer_return);
int XpmReadFileToData(char *filename, char ***data_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
filename
Especifica el nombre del archivo a usar.
image_return
Devuelve la imagen que se crea.
shapeimage_return
Devuelve la imagen de máscara de forma que se crea si se usa el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información (o NULL).
buffer_return
Devuelve el búfer creado.
data_return
Devuelve el array de datos creado.
image
Especifica la ubicación de la estructura de imagen.
info
Especifica la ubicación de una estructura para almacenar posible información (o NULL).

DESCRIPCIÓN

XpmReadFileToImage

La función XpmReadFileToImage() lee un archivo en formato XPM. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si el archivo se puede abrir pero no contiene datos XPM válidos, devuelve XpmFileInvalid. Si no se asigna suficiente espacio de trabajo, devuelve XpmNoMemory. Si el puntero a la estructura XpmAttributes pasado no es NULL, XpmReadFileToImage() busca los siguientes atributos: XpmVisual, XpmColormap, XpmDepth, XpmColorSymbols, XpmExactColors, XpmCloseness, XpmRGBCloseness, XpmAllocCloseColors, XpmReturnPixels, XpmReturnAllocPixels, XpmAllocColor, XpmFreeColors, XpmColorClosure, XpmReturnExtensions, XpmReturnColorTable, XpmBitmapFormat, establece XpmSize, XpmCharsPerPixel, y posiblemente el atributo XpmHotspot al devolver. Como característica de compatibilidad hacia atrás, XpmReadFileToImage() también busca los atributos XpmReturnInfos. Como se especifica en la tabla (página 12), si los datos relacionados con los atributos XpmReturnExtensions, XpmReturnColorTable y XpmReturnInfos no se pueden devolver según lo solicitado debido a una memoria insuficiente, XpmReadFileToImage() cambiará la máscara de valores para indicarlo e intentará continuar. Por lo tanto, el llamador debe verificar esto antes de acceder a estos datos.

Nota: La máscara de valores del puntero XpmAttributes pasado debe establecerse en algún valor válido, al menos cero, de lo contrario, pueden producirse errores impredecibles.

XpmReadFileToImage() asigna colores, según lo leído del archivo o posiblemente anulado según lo especificado en los atributos XpmColorSymbols. Los colores se asignan utilizando la configuración de color para la visual especificada por el atributo XpmColorKey, que tiene el valor XPM_MONO, XPM_GRAY4, XPM_GRAY o XPM_COLOR. Si el atributo XpmColorKey no está establecido, se determina examinando el tipo de visual. Si no existe un valor predeterminado para la visual especificada, primero busca otros valores predeterminados más cercanos al tipo de visual monocromo y, en segundo lugar, más cercanos al tipo de visual de color. Si el color que se encuentra no es válido (no se puede analizar), busca otro valor predeterminado según el mismo algoritmo. Si la asignación de un color falla y se establece el atributo de cercanía, intenta encontrar un color ya en el mapa de colores que sea el más cercano al color deseado y lo usa. Si el atributo alloc_close_colors está establecido en False, el color cercano encontrado no se asigna pero se usa de todos modos. Esto es especialmente útil para aplicaciones que utilizan un mapa de colores privado que contiene celdas de lectura/escritura y tienen control completo sobre el mapa de colores. Por otro lado, dado que en tal caso no hay garantía de que el píxel de color no cambie en ningún momento, esto debe evitarse al usar el mapa de colores predeterminado. Si no se encuentra ningún color, y ningún color cercano existe o se desea, y se han agotado todas las visuales, se devuelve XpmColorFailed.

Los componentes RGB son enteros dentro del rango de 0 (negro) a 65535 (blanco). Una cercanía de menos de 10000, por ejemplo, hará que solo coincidan colores bastante cercanos, mientras que una cercanía de más de 50000 permitirá que coincidan colores bastante dispares. Especificar una cercanía de más de 65535 permitirá que coincida cualquier color, forzando así que el icono se dibuje en color sin importar cuán malo sea el mapa de colores. El valor 40000 parece ser adecuado para muchas situaciones que requieren coincidencias razonables pero no perfectas. Con esta configuración, el color solo debe estar dentro de la misma área general del cubo RGB que el color deseado. Si se establece el atributo exactColors, devuelve XpmColorError; de lo contrario, crea las imágenes y devuelve XpmSuccess. Si no se encuentra ningún color, y no existe ni se desea un color cercano, y se han agotado todas las visuales, se devuelve XpmColorFailed.

XpmReadFileToImage() devuelve la imagen creada a image_return si no es NULL y posiblemente la máscara de forma creada a shapeimage_return si no es NULL y se utiliza el color None. Si es necesario, almacena en la estructura XpmAttributes la lista de los píxeles utilizados. Cuando la profundidad de la imagen es uno, el formato de la imagen es el especificado por el atributo bitmap_format si está establecido o ZPixmap. Cuando la profundidad es diferente de uno, el formato de la imagen es siempre ZPixmap. Al terminar, el llamador debe liberar las imágenes usando XDestroyImage(3), los colores asignados usando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3). Además, en sistemas que admiten tales características, XpmReadFileToImage() maneja archivos comprimidos bifurcando un proceso uncompress o gzip y leyendo del resultado canalizado. Asume que el archivo especificado está comprimido si el nombre del archivo dado termina en ’.Z’ o ’.gz’. En caso de que el nombre del archivo no termine así, XpmReadFileToImage() busca el nombre del archivo dado asumiendo que no es un archivo comprimido. Y si en lugar de un nombre de archivo se pasa NULL a XpmReadFileToImage(), lee de la entrada estándar.

XpmReadFileToPixmap

La función XpmReadFileToPixmap() crea imágenes X usando XpmReadFileToImage() y, por lo tanto, devuelve los mismos errores. Además, en caso de éxito, crea los pixmaps relacionados, usando XPutImage(3), que se devuelven a pixmap_return y shapemask_return si no son NULL, y finalmente destruye las imágenes creadas usando XDestroyImage(3). Al terminar, el llamador debe liberar los pixmaps usando XFreePixmap(3), los colores asignados usando XFreeColors(3) o la función equivalente de la aplicación cuando no se utilizan las funciones estándar de Xlib, y posiblemente los datos devueltos en XpmAttributes usando XpmFreeAttributes(3).

Como conveniencia, se proporcionan XpmReadFileToBuffer() y XpmWriteFileFromBuffer(3) para copiar un archivo a un búfer y escribir un archivo desde un búfer. En algunos sistemas esto puede conducir a una mejora del rendimiento, ya que el análisis se realizará en memoria, pero utiliza más memoria.

XpmReadFileToData

XpmReadFileToData() devuelve XpmOpenFailed si no puede abrir el archivo, XpmNoMemory si no se asigna suficiente espacio de trabajo, XpmFileInvalid si no es un archivo XPM válido y XpmSuccess en caso contrario. Los datos asignados devueltos por XpmReadFileToData() deben liberarse con XpmFree(3) cuando se termine.

XpmReadFileToXpmImage

La función XpmReadFileToXpmImage() lee un archivo en formato XPM. Si el archivo no se puede abrir, devuelve XpmOpenFailed. Si el archivo se puede abrir pero no contiene datos XPM válidos, devuelve XpmFileInvalid. Si se asigna almacenamiento de trabajo insuficiente, devuelve XpmNoMemory. En caso de éxito, rellena la estructura XpmImage proporcionada y devuelve XpmSuccess.
