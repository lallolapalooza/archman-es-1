XpEndPage(3Xp) FUNCIONES DE XPRINT XpEndPage(3Xp)

NOMBRE

XpEndPage - Indica el final de una página de impresión.

SINOPSIS


cc [ indicador... ] archivo... -lXp [ biblioteca... ]
#include <X11/extensions/Print.h>

void XpEndPage ( display )
Display *display;

DESCRIPCIÓN

XpEndPage señala el final de una página de impresión y provoca que la ventana se desmapee. Todos los datos de página resultantes se ensamblan y combinan con los datos enviados previamente por XpPutDocumentData. No ocurrirá ninguna generación de datos de documento para las operaciones de renderizado a las ventanas correspondientes después de que se llame a XpEndPage.

Para los clientes que seleccionan XPPrintMask (ver XpSelectInput), el evento XPPrintNotify se genera con su campo de detalle establecido a XPEndPageNotify cuando el Servidor de Impresión X ha completado XpEndPage.

ARGUMENTOS

display
Especifica un puntero a la estructura Display; devuelto por XOpenDisplay.

DIAGNÓSTICOS

XPBadSequence
La función no se llamó en el orden correcto con respecto a las otras llamadas a la Extensión de Impresión X; por ejemplo, se llamó a XpStartPage antes que a XpStartJob o se llamó para un tipo de documento XPDocRaw.

VER TAMBIÉN

XpPutDocumentData.(3Xp), XpSelectInput(3Xp), XpStartPage(3Xp)
