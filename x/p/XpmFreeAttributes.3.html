XpmMisc(3) Funciones de libXpm XpmMisc(3)

NOMBRE

XpmMisc - funciones varias de xpm para liberar memoria utilizada y manejar errores

SINOPSIS

int XpmFreeXpmImage(XpmImage *image);
int XpmFreeXpmInfo(XpmInfo *info);
int XpmFreeAttributes(XpmAttributes *attributes);
int XpmAttributesSize(void);
int XpmFreeExtensions(XpmExtension *extensions,  int nextensions);
int XpmFree(char *ptr);
char *XpmGetErrorString(int errorcode);
int XpmLibraryVersion(void);

ARGUMENTOS

image
Especifica la estructura a liberar
info
Especifica la estructura a liberar
ptr
Especifica los datos a liberar
errorcode
Especifica el error de XPM
extensions
Especifica el array a liberar
nextensions
Especifica el número de extensiones
attributes
Especifica la estructura a liberar

DESCRIPCION

Para liberar datos posibles almacenados en una estructura XpmImage utilice XpmFreeXpmImage(). La función XpmFreeXpmImage() libera los miembros de la estructura que no son NULL, pero no la estructura en sí misma.

Para liberar datos posibles almacenados en una estructura XpmInfo utilice XpmFreeXpmInfo().

Para liberar datos posibles almacenados en un array de XpmExtension utilice XpmFreeExtensions().

Para liberar cualquier dato asignado por una función XPM utilice la función XpmFree(). La distribución actual de la biblioteca XPM usa las funciones de asignación de memoria estándar y, por lo tanto, XpmFree() no es más que una definición para la función estándar free(3). Sin embargo, dado que estas funciones pueden ser redefinidas en entornos específicos, es recomendable usar XpmFree().

Para liberar datos posibles almacenados en una estructura XpmAttributes utilice XpmFreeAttributes(). La función XpmFreeAttributes() libera los miembros de la estructura que han sido asignados con malloc, como la lista de píxeles.

Para asignar dinámicamente una estructura XpmAttributes utilice la función XpmAttributesSize(). La función XpmAttributesSize() proporciona a las aplicaciones que utilizan bibliotecas dinámicas una forma segura de asignar y luego referenciar una estructura XpmAttributes, sin tener en cuenta si el tamaño de la estructura XpmAttributes ha cambiado o no desde la compilación.

Para obtener datos al construir un mensaje de error, se puede utilizar XpmGetErrorString(). XpmGetErrorString() devuelve una cadena relacionada con el código de error XPM dado.

La función XpmLibraryVersion() puede ser utilizada cuando se necesita averiguar qué versión de la biblioteca se está utilizando. El valor devuelto por XpmLibraryVersion() puede compararse con el valor de XpmIncludeVersion, que está definido en el archivo de cabecera "xpm.h". Estos números se calculan con la siguiente fórmula:

 (XpmFormat * 100 + XpmVersion) * 100 + XpmRevision

donde XpmFormat es el número de versión del formato, XpmVersion es el número de versión de la biblioteca (que solo cambia si la API cambia) y XpmRevision es el número de versión menor de la biblioteca.

La función XpmFreeExtensions() libera todos los datos almacenados en cada extensión y el propio array. Tenga en cuenta que XpmFreeAttributes() llama a esta función y, por lo tanto, la mayor parte del tiempo no debería ser necesario llamarla explícitamente.
