XpmCreateImageFromData(3)

Paquete: libxpm

Licencias: MIT, X11-distribute-modifications-variant

XpmCreateImage(3) Funciones de libXpm XpmCreateImage(3)

NOMBRE

XpmCreateImage - crear una imagen X a partir de un XPM

SINOPSIS

int XpmCreateImageFromData(Display *display, char **data,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmCreateImageFromBuffer(Display *display, char *buffer,
XImage **image_return, XImage **shapeimage_return,
XpmAttributes *attributes);
int XpmCreateImageFromXpmImage(Display *display,  XpmImage *image,
XImage *image_return, XImage *shapeimage_return,
XpmAttributes *attributes);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
data
Especifica la ubicación de los datos.
image_return
Devuelve la imagen que se crea.
shapeimage_return
Devuelve la imagen de máscara de forma que se crea si se utiliza el color None.
attributes
Especifica la ubicación de una estructura para obtener y almacenar información (o NULL).
shapeimage
Especifica la imagen de máscara de forma que se crea, en su caso.

DESCRIPCIÓN

XpmCreateImageFromData

Para crear una imagen X a partir de datos XPM, utilice XpmCreateImageFromData().

La función XpmCreateImageFromData() le permite incluir en su programa C un archivo XPM que fue guardado por funciones como XpmWriteFileFromImage(3) o XpmWriteFileFromPixmap(3) sin leer el archivo. XpmCreateImageFromData() funciona exactamente igual que XpmReadFileToImage(3) y devuelve los mismos resultados. Simplemente lee datos en lugar de un archivo. Aquí también, es responsabilidad del llamador liberar las imágenes devueltas, los colores y posiblemente los datos devueltos en la estructura XpmAttributes.

XpmCreateImageFromBuffer

Para crear una imagen X a partir de un búfer XPM, utilice XpmCreateImageFromBuffer(). La función XpmCreateImageFromBuffer() funciona de la misma manera que XpmReadFileToImage(3), simplemente analiza el búfer en lugar del archivo. Tenga en cuenta que la característica que proporciona XpmReadFileToImage(3) en algunos sistemas para tratar con archivos comprimidos no está disponible aquí.

XpmCreateImageFromXpmImage

Para crear una imagen X a partir de una XpmImage, utilice XpmCreateImageFromXpmImage(). A partir de la XpmImage y XpmAttributes dadas (si no son NULL), XpmCreateImageFromXpmImage() asigna colores y crea imágenes X siguiendo el mismo mecanismo que XpmReadFileToImage(3). Cuando haya terminado, el llamador debe liberar las imágenes usando XDestroyImage(3), los colores usando XFreeColors(3), y posiblemente los datos devueltos en la XpmAttributes usando XpmFreeAttributes(3).

VER TAMBIÉN

XpmFreeAttributes(3), XpmReadFileToImage(3)
