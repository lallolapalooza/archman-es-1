XConfigureWindow(3) FUNCIONES DE XLIB XConfigureWindow(3)

NOMBRE

XConfigureWindow, XMoveWindow, XResizeWindow, XMoveResizeWindow, XSetWindowBorderWidth, XWindowChanges - configurar ventanas y estructura de cambios de ventana

SINTAXIS

int XConfigureWindow(Display *display, Window w, unsigned value_mask, XWindowChanges *changes);

int XMoveWindow(Display *display, Window w, int x, y);

int XResizeWindow(Display *display, Window w, unsigned width, unsigned height);

int XMoveResizeWindow(Display *display, Window w, int x, int y, unsigned width, unsigned height);

int XSetWindowBorderWidth(Display *display, Window w, unsigned width);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
value_mask
Especifica qué valores se establecerán utilizando la información de la estructura de valores. Esta máscara es el OR inclusivo a nivel de bits de los bits de valores de ventana de configuración válidos.
values
Especifica la estructura XWindowChanges.
w
Especifica la ventana a reconfigurar, mover o redimensionar.
width
Especifica el ancho del borde de la ventana.
width

height
Especifican el ancho y el alto, que son las dimensiones interiores de la ventana.
x

y
Especifican las coordenadas x e y, que definen la nueva ubicación del píxel superior izquierdo del borde de la ventana o de la ventana misma si no tiene borde, o definen la nueva posición de la ventana en relación con su padre.

DESCRIPCIÓN

La función XConfigureWindow utiliza los valores especificados en la estructura XWindowChanges para reconfigurar el tamaño, la posición, el borde y el orden de apilamiento de una ventana. Los valores no especificados se toman de la geometría existente de la ventana.

Si se especifica un hermano sin un modo de apilamiento (`stack_mode`) o si la ventana en realidad no es un hermano, se produce un error BadMatch. Tenga en cuenta que los cálculos para BottomIf, TopIf y Opposite se realizan con respecto a la geometría final de la ventana (según lo controlado por los otros argumentos pasados a XConfigureWindow), no a su geometría inicial. Cualquier contenido de almacenamiento de respaldo de la ventana, sus inferiores y otras ventanas recién visibles se descartan o cambian para reflejar el contenido actual de la pantalla (dependiendo de la implementación).

XConfigureWindow puede generar errores BadMatch, BadValue y BadWindow.

La función XMoveWindow mueve la ventana especificada a las coordenadas x e y especificadas, pero no cambia el tamaño de la ventana, no la eleva (`raise`) ni cambia su estado de mapeo (`mapping state`). Mover una ventana mapeada puede o no perder el contenido de la ventana dependiendo de si la ventana está oscurecida por ventanas no hijas y si no existe un almacenamiento de respaldo (`backing store`). Si se pierden los contenidos de la ventana, el servidor X genera eventos Expose. Mover una ventana mapeada genera eventos Expose en cualquier ventana anteriormente oscurecida.

Si la bandera `override-redirect` de la ventana es False y otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún otro procesamiento. De lo contrario, la ventana se mueve.

XMoveWindow puede generar un error BadWindow.

La función XResizeWindow cambia las dimensiones interiores de la ventana especificada, sin incluir sus bordes. Esta función no cambia la coordenada superior izquierda ni el origen de la ventana, y no la reorganiza en el apilamiento. Cambiar el tamaño de una ventana mapeada puede perder su contenido y generar eventos Expose. Si una ventana mapeada se hace más pequeña, cambiar su tamaño genera eventos Expose en las ventanas que la ventana mapeada anteriormente oscurecía.

Si la bandera `override-redirect` de la ventana es False y otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún otro procesamiento. Si el ancho o el alto son cero, se produce un error BadValue.

XResizeWindow puede generar errores BadValue y BadWindow.

La función XMoveResizeWindow cambia el tamaño y la ubicación de la ventana especificada sin elevarla. Mover y redimensionar una ventana mapeada puede generar un evento Expose en la ventana. Dependiendo de los nuevos parámetros de tamaño y ubicación, mover y redimensionar una ventana puede generar eventos Expose en las ventanas que la ventana anteriormente oscurecía.

Si la bandera `override-redirect` de la ventana es False y otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún otro procesamiento. De lo contrario, se cambian el tamaño y la ubicación de la ventana.

XMoveResizeWindow puede generar errores BadValue y BadWindow.

La función XSetWindowBorderWidth establece el ancho del borde de la ventana especificada al ancho especificado.

XSetWindowBorderWidth puede generar un error BadWindow.

ESTRUCTURAS

La estructura XWindowChanges contiene:

// Bits de máscara de valor de configuración de ventana

#define CWX (1<<0)
#define CWY (1<<1)
#define CWWidth (1<<2)
#define CWHeight (1<<3)
#define CWBorderWidth (1<<4)
#define CWSibling (1<<5)
#define CWStackMode (1<<6) 
/* Valores */
typedef struct {
        int x, y;
        int width, height;
        int border_width;
        Window sibling;
        int stack_mode;
} XWindowChanges;

Los miembros `x` e `y` se utilizan para establecer las coordenadas x e y de la ventana, que son relativas al origen del padre e indican la posición de la esquina exterior superior izquierda de la ventana. Los miembros `width` y `height` se utilizan para establecer el tamaño interior de la ventana, sin incluir el borde, y deben ser distintos de cero, o se producirá un error BadValue. Los intentos de configurar una ventana raíz no tienen ningún efecto.

El miembro `border_width` se utiliza para establecer el ancho del borde en píxeles. Tenga en cuenta que establecer solo el ancho del borde deja la esquina exterior izquierda de la ventana en una posición fija, pero mueve la posición absoluta del origen de la ventana. Si intenta establecer el atributo `border-width` de una ventana InputOnly a un valor distinto de cero, se producirá un error BadMatch.

El miembro `sibling` se utiliza para establecer la ventana hermana para operaciones de apilamiento. El miembro `stack_mode` se utiliza para establecer cómo se debe reorganizar la ventana en el apilamiento y puede configurarse en Above, Below, TopIf, BottomIf u Opposite.

DIAGNÓSTICOS

BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos, pero falla en alguna otra forma requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor de ventana inválido.

XWindowChanges(3) — libX11 1.8.12

NAME

XWindowChanges

-- specify changes to a window's geometry

SYNTAX

XWindowChanges x, y, width, height, border_width, sibling, stack_mode;

ARGUMENTS

x
Specifies the new x-coordinate for the window.
y
Specifies the new y-coordinate for the window.
width
Specifies the new width for the window.
height
Specifies the new height for the window.
border_width
Specifies the new border width for the window.
sibling
Specifies the window to be used for stacking order. It must be a sibling of the window or a child of the parent.
stack_mode
Specifies the stacking order. It can be Above, Below, TopIf, BottomIf, or Opposite.

DESCRIPTION

The XWindowChanges structure contains values that are used to change the geometry of a window.

The structure is used by functions such as XConfigureWindow, XResizeWindow, XMoveWindow, XRestackWindows, XLowerWindow, XRaiseWindow, XWarpPointer.

Not all fields are used by all functions. The specific fields that are used depend on the function. The values for each field are the desired new values for the window attributes. If a value is not specified, the current value is retained.

The sibling argument is used in conjunction with stack_mode to specify the stacking order of the window relative to other windows.

The stack_mode argument can be one of the following:

Above
The window is placed above the sibling window.
Below
The window is placed below the sibling window.
TopIf
If the window is not the top-most window, it is moved to the top.
BottomIf
If the window is not the bottom-most window, it is moved to the bottom.
Opposite
The window is placed directly above or below the sibling window, depending on whether the window is currently above or below the sibling window.

STRUCTURES

The XWindowChanges structure is defined as follows:

typedef struct {
    int x;
    int y;
    int width;
    int height;
    int border_width;
    Window sibling;
    int stack_mode;
} XWindowChanges;

DIAGNOSTICS

A BadWindow error is generated if a value for a Window argument does not name a defined Window.
