Xorg.wrap(1) Manual de comandos generales Xorg.wrap(1)

NOMBRE

Xorg.wrap - script de envoltura binaria del servidor X de Xorg

DESCRIPCIÓN

El servidor X de Xorg puede necesitar derechos de root para funcionar correctamente. Para iniciar el servidor X de Xorg con estos derechos, tu sistema está utilizando un script de envoltura con permisos de root (suid root) instalado como /usr/libexec/Xorg.wrap, el cual ejecutará el servidor X real, instalado como /usr/libexec/Xorg.

Por defecto, Xorg.wrap detectará automáticamente si son necesarios los derechos de root y, si no lo son, renunciará a sus privilegios elevados antes de iniciar el servidor X real. Por defecto, Xorg.wrap solo permitirá ejecutar el servidor X real desde sesiones de inicio de sesión en una consola física.

ARCHIVO DE CONFIGURACIÓN

El comportamiento predeterminado de Xorg.wrap puede ser anulado desde el archivo de configuración /etc/X11/Xwrapper.config. Las líneas que comienzan con un # en Xwrapper.config se consideran comentarios y serán ignoradas. Cualquier otra línea no vacía debe tener el formato clave = valor.

usuarios_permitidos = solo_root|consola|cualquiera
Especifica qué usuarios pueden iniciar el servidor X a través del script de envoltura. Usa solo_root para permitir solo a root, usa consola para permitir solo a usuarios iniciados en una consola física, y usa cualquiera para permitir a cualquiera. El valor predeterminado es consola.
necesita_derechos_root = sí|no|auto
Configura si el script de envoltura debe renunciar a sus privilegios elevados (root) antes de iniciar el servidor X. Usa sí para forzar la ejecución como root, no para forzar la ejecución con todos los privilegios suid descartados, y auto para que el script de envoltura lo detecte automáticamente. El valor predeterminado es auto.

Al detectar automáticamente, el script renunciará a los privilegios si los gráficos kms están disponibles y no lo hará si no se detectan gráficos kms. Si un sistema tiene múltiples tarjetas gráficas y algunas no son compatibles con kms, la detección automática puede fallar; en este caso, se debe usar la configuración manual.
