Paquete: libx11

Licencias: MIT AND X11

XAllocWMHints(3) FUNCIONES DE XLIB XAllocWMHints(3)

NOMBRE

XAllocWMHints, XSetWMHints, XGetWMHints, XWMHints - asignar estructura de pistas del gestor de ventanas y establecer o leer la propiedad WM_HINTS de una ventana

SINTAXIS

XWMHints *XAllocWMHints(void);

int XSetWMHints(Display *display, Window w, XWMHints *wmhints);

XWMHints *XGetWMHints(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.
wmhints
Especifica la estructura XWMHints a utilizar.

DESCRIPCIÓN

La función XAllocWMHints asigna y devuelve un puntero a una estructura XWMHints. Ten en cuenta que todos los campos de la estructura XWMHints se establecen inicialmente a cero. Si no hay suficiente memoria disponible, XAllocWMHints devuelve NULL. Para liberar la memoria asignada a esta estructura, usa XFree.

La función XSetWMHints establece las pistas del gestor de ventanas que incluyen información y ubicación de iconos, el estado inicial de la ventana y si la aplicación depende del gestor de ventanas para recibir entrada del teclado.

XSetWMHints puede generar errores BadAlloc y BadWindow.

La función XGetWMHints lee las pistas del gestor de ventanas y devuelve NULL si no se estableció ninguna propiedad WM_HINTS en la ventana o devuelve un puntero a una estructura XWMHints si tiene éxito. Cuando hayas terminado con los datos, libera el espacio utilizado llamando a XFree.

XGetWMHints puede generar un error BadWindow.

PROPIEDADES

WM_HINTS
Pistas adicionales establecidas por el cliente para uso del gestor de ventanas. El tipo C de esta propiedad es XWMHints.

ESTRUCTURAS

La estructura XWMHints contiene:

/* Bits de máscara de pistas de gestor de ventanas */

#define InputHint (1L << 0)
#define StateHint (1L << 1)
#define IconPixmapHint (1L << 2)
#define IconWindowHint (1L << 3)
#define IconPositionHint (1L << 4)
#define IconMaskHint (1L << 5)
#define WindowGroupHint (1L << 6)
#define XUrgencyHint (1L << 8)
#define AllHints (InputHint| StateHint| IconPixmapHint| IconWindowHint| IconPositionHint| IconMaskHint| WindowGroupHint) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        Bool input;     /* ¿depende esta aplicación del gestor de ventanas para
                        recibir entrada del teclado? */
        int initial_state;      /* ver abajo */
        Pixmap icon_pixmap;     /* pixmap a usar como icono */
        Window icon_window;     /* ventana a usar como icono */
        int icon_x, icon_y;     /* posición inicial del icono */
        Pixmap icon_mask;       /* pixmap a usar como máscara para icon_pixmap */
        XID window_group;       /* id del grupo de ventanas relacionadas */
        /* esta estructura puede ser extendida en el futuro */
} XWMHints;

El miembro input se usa para comunicar al gestor de ventanas el modelo de foco de entrada utilizado por la aplicación. Las aplicaciones que esperan entrada pero nunca establecen explícitamente el foco en ninguna de sus subventanas (es decir, usan el modelo de gestión de foco "push"), como las aplicaciones estilo X Versión 10 que usan el foco impulsado por el espacio de bienes raíces, deberían establecer este miembro a True. De manera similar, las aplicaciones que establecen el foco de entrada en sus subventanas solo cuando un gestor de ventanas les da el foco a sus ventanas de nivel superior también deberían establecer este miembro a True. Las aplicaciones que gestionan su propio foco de entrada estableciendo explícitamente el foco en una de sus subventanas siempre que desean entrada del teclado (es decir, usan el modelo "pull" de gestión de foco) deberían establecer este miembro a False. Las aplicaciones que nunca esperan ninguna entrada del teclado también deberían establecer este miembro a False.

Los gestores de ventanas del modelo "pull" deberían hacer posible que las aplicaciones del modelo "push" reciban entrada estableciendo el foco de entrada en las ventanas de nivel superior de las aplicaciones cuyo miembro input sea True. Los gestores de ventanas del modelo "push" deberían asegurarse de que las aplicaciones del modelo "pull" no los rompan reestableciendo el foco de entrada a PointerRoot cuando sea apropiado (por ejemplo, cada vez que una aplicación cuyo miembro input sea False establezca el foco de entrada en una de sus subventanas).

Las definiciones para el indicador initial_state son:

#define WithdrawnState 0
#define NormalState 1 /* la mayoría de las aplicaciones comienzan así */
#define IconicState 3 /* la aplicación quiere empezar como un icono */
El icon_mask especifica qué píxeles del icon_pixmap deben usarse como icono. Esto permite iconos no rectangulares. Tanto icon_pixmap como icon_mask deben ser mapas de bits. El icon_window permite a una aplicación proporcionar una ventana para usar como icono para los gestores de ventanas que admiten dicho uso. El window_group le permite especificar que esta ventana pertenece a un grupo de otras ventanas. Por ejemplo, si una sola aplicación manipula múltiples ventanas de nivel superior, esto le permite proporcionar suficiente información para que un gestor de ventanas pueda minimizar (iconify) todas las ventanas en lugar de solo una.

El indicador UrgencyHint, si se establece en el campo flags, indica que el cliente considera que el contenido de la ventana es urgente, requiriendo la respuesta oportuna del usuario. El gestor de ventanas hará un esfuerzo para llamar la atención del usuario sobre esta ventana mientras este indicador esté activo. El cliente debe proporcionar algún medio por el cual el usuario pueda hacer que el indicador de urgencia se borre (ya sea mitigando la condición que hizo que la ventana fuera urgente o simplemente apagando la alarma) o que la ventana sea retirada.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.

XWMHints(3)

NAME

XWMHints - hints for window managers

SYNTAX

int XWMHints (Display *display, Window w, XWMHints *hints)

ARGUMENTS

display

Specifies the connection to the X server.

w

Specifies the window.

hints

Specifies the pointer to the XWMHints structure which contains the hints.

DESCRIPTION

XWMHints returns the XWMHints structure for the specified window. The hints are used by window managers to control the appearance and behavior of windows.

The XWMHints structure has the following members:

typedef struct {
    long flags;
    int x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int width_inc, height_inc;
    /* ... other members ... */
} XWMHints;

The flags member is a bitmask that indicates which of the other members are set.

PROPERTIES

The XWMHints structure is associated with the WM_HINTS property of a window. This property is set by the client application and read by the window manager.

STRUCTURES

The XWMHints structure is defined in the <X11/Xutil.h> header file.

DIAGNOSTICS

If XWMHints encounters an error, it returns 0. Otherwise, it returns the number of hints set.
