XWarpPointer(3) FUNCIONES DE XLIB XWarpPointer(3)

NOMBRE

XWarpPointer - mover el puntero

SINTAXIS

int XWarpPointer(Display *display, Window src_w, Window dest_w, int src_x, int src_y, unsigned int src_width, unsigned int src_height, int dest_x, int dest_y);

ARGUMENTOS

dest_w
Especifica la ventana de destino o None.
dest_x

dest_y
Especifica las coordenadas x e y dentro de la ventana de destino.
display
Especifica la conexión con el servidor X.
src_x

src_y

src_width

src_height
Especifica un rectángulo en la ventana de origen.
src_w
Especifica la ventana de origen o None.

DESCRIPCIÓN

Si dest_w es None, XWarpPointer mueve el puntero mediante los desplazamientos (dest_x, dest_y) relativos a la posición actual del puntero. Si dest_w es una ventana, XWarpPointer mueve el puntero a los desplazamientos (dest_x, dest_y) relativos al origen de dest_w. Sin embargo, si src_w es una ventana, el movimiento solo se realiza si la ventana src_w contiene el puntero y si el rectángulo especificado de src_w contiene el puntero.

Las coordenadas src_x y src_y son relativas al origen de src_w. Si src_height es cero, se reemplaza con la altura actual de src_w menos src_y. Si src_width es cero, se reemplaza con el ancho actual de src_w menos src_x.

Raramente hay alguna razón para llamar a esta función. El puntero normalmente debe dejarse al usuario. Si usas esta función, sin embargo, genera eventos como si el usuario hubiera movido instantáneamente el puntero de una posición a otra. Ten en cuenta que no puedes usar XWarpPointer para mover el puntero fuera de la ventana de confinamiento de un agarre de puntero activo. Un intento de hacerlo solo moverá el puntero hasta el borde más cercano de la ventana de confinamiento.

XWarpPointer puede generar un error BadWindow.

DIAGNÓSTICOS

BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
