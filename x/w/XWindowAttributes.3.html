XGetWindowAttributes(3) FUNCIONES DE XLIB XGetWindowAttributes(3)

NOMBRE

XGetWindowAttributes, XGetGeometry, XWindowAttributes - obtener atributos actuales de la ventana o geometría y estructura de atributos de ventana actuales

SINTAXIS

Status XGetWindowAttributes(Display *display, Window w, XWindowAttributes *window_attributes_return);

Status XGetGeometry(Display *display, Drawable d, Window *root_return, int *x_return, int *y_return, unsigned int *width_return, unsigned int *height_return, unsigned int *border_width_return, unsigned int *depth_return);

ARGUMENTOS

border_width_return
Devuelve el ancho del borde en píxeles.
d
Especifica el drawable, que puede ser una ventana o un pixmap.
depth_return
Devuelve la profundidad del drawable (bits por píxel del objeto).
display
Especifica la conexión con el servidor X.
root_return
Devuelve la ventana raíz.
w
Especifica la ventana cuyos atributos actuales se desean obtener.
width_return

height_return
Devuelven las dimensiones del drawable (ancho y alto).
window_attributes_return
Devuelve los atributos de la ventana especificada en la estructura XWindowAttributes.
x_return

y_return
Devuelven las coordenadas x e y que definen la ubicación del drawable. Para una ventana, estas coordenadas especifican la esquina exterior superior izquierda relativa al origen de su padre. Para pixmaps, estas coordenadas son siempre cero.

DESCRIPCIÓN

La función XGetWindowAttributes devuelve los atributos actuales de la ventana especificada a una estructura XWindowAttributes. Devuelve un estado distinto de cero si tiene éxito; de lo contrario, devuelve un estado cero.

XGetWindowAttributes puede generar errores BadDrawable y BadWindow.

La función XGetGeometry devuelve la ventana raíz y la geometría actual del drawable. La geometría del drawable incluye las coordenadas x e y, el ancho y alto, el ancho del borde y la profundidad. Estos se describen en la lista de argumentos. Es legal pasar a esta función una ventana cuya clase sea InputOnly. Devuelve un estado distinto de cero si tiene éxito; de lo contrario, devuelve un estado cero.

ESTRUCTURAS

La estructura XWindowAttributes contiene:

typedef struct {
        int x, y;       /* ubicación de la ventana */
        int width, height;      /* ancho y alto de la ventana */
        int border_width;       /* ancho del borde de la ventana */
        int depth;      /* profundidad de la ventana */
        Visual *visual; /* puntero a la estructura visual asociada */
        Window root;    /* raíz de la pantalla que contiene la ventana */
        int class;      /* InputOutput, InputOnly */
        int bit_gravity;        /* uno de los valores de gravedad de bits */
        int win_gravity;        /* uno de los valores de gravedad de ventana */
        int backing_store;      /* NotUseful, WhenMapped, Always */
        unsigned long backing_planes;   /* planos a preservar si es posible */
        unsigned long backing_pixel;    /* valor a usar al restaurar planos */
        Bool save_under;        /* booleano, ¿se deben guardar los bits debajo? */
        Colormap colormap;      /* mapa de color a asociar con la ventana */
        Bool map_installed;     /* booleano, ¿está instalado el mapa de color actualmente? */
        int map_state;  /* IsUnmapped, IsUnviewable, IsViewable */
        long all_event_masks;   /* conjunto de eventos que interesan a todos */
        long your_event_mask;   /* mi máscara de eventos */
        long do_not_propagate_mask;     /* conjunto de eventos que no deben propagarse */
        Bool override_redirect; /* valor booleano para override-redirect */
        Screen *screen; /* puntero de retroceso a la pantalla correcta */
} XWindowAttributes;

Los miembros x e y se establecen en la esquina exterior superior izquierda relativa al origen de la ventana padre. Los miembros width y height se establecen en el tamaño interior de la ventana, sin incluir el borde. El miembro border_width se establece en el ancho del borde de la ventana en píxeles. El miembro depth se establece en la profundidad de la ventana (es decir, bits por píxel para el objeto). El miembro visual es un puntero a la estructura Visual de la pantalla. El miembro root se establece en la ventana raíz de la pantalla que contiene la ventana. El miembro class se establece en la clase de la ventana y puede ser InputOutput o InputOnly.

El miembro bit_gravity se establece en la gravedad de bits de la ventana y puede ser uno de los siguientes:

ForgetGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

El miembro win_gravity se establece en la gravedad de ventana de la ventana y puede ser uno de los siguientes:

UnmapGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

Para obtener información adicional sobre la gravedad, consulte la sección 3.3.

El miembro backing_store se establece para indicar cómo el servidor X debe mantener el contenido de una ventana y puede ser WhenMapped, Always o NotUseful. El miembro backing_planes se establece para indicar (con bits establecidos en 1) qué planos de bits de la ventana contienen datos dinámicos que deben conservarse en backing_stores y durante save_unders. El miembro backing_pixel se establece para indicar qué valores se deben usar para los planos no establecidos en backing_planes.

El miembro save_under se establece en True o False. El miembro colormap se establece en el mapa de colores para la ventana especificada y puede ser un ID de mapa de colores o None. El miembro map_installed se establece para indicar si el mapa de colores está instalado actualmente y puede ser True o False. El miembro map_state se establece para indicar el estado de la ventana y puede ser IsUnmapped, IsUnviewable o IsViewable. IsUnviewable se utiliza si la ventana está mapeada pero algún ancestro no está mapeado.

El miembro all_event_masks se establece en el OR inclusivo de bits de todas las máscaras de eventos seleccionadas en la ventana por todos los clientes. El miembro your_event_mask se establece en el OR inclusivo de bits de todas las máscaras de eventos seleccionadas por el cliente que consulta. El miembro do_not_propagate_mask se establece en el OR inclusivo de bits del conjunto de eventos que no deben propagarse.

El miembro override_redirect se establece para indicar si esta ventana anula las instalaciones de control de estructura y puede ser True o False. Los clientes del gestor de ventanas deben ignorar la ventana si este miembro es True.

El miembro screen se establece en un puntero de pantalla que le proporciona un puntero de retroceso a la pantalla correcta. Esto facilita la obtención de la información de la pantalla sin tener que recorrer los campos de la ventana raíz para ver qué campo coincide.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.

XWindowAttributes(3) libX11 Commands XWindowAttributes(3)

NAME

XWindowAttributes - Estructura de atributos de ventana X

SYNTAX

typedef struct {
    int         x, y;
    int         width, height;
    int         border_width;
    int         depth;
    int         visual;

    unsigned long   your_event_mask;
    unsigned long   your_do_not_propagate_mask;

    int         backing_store;

    unsigned long   windows_event_mask;
    unsigned long   windows_do_not_propagate_mask;

    int         backing_planes;
    int         backing_pixel;

    int         save_under;

    int         event_list;
    int         event_list_count;
} XWindowAttributes;

ARGUMENTS

x, y
Coordenadas de la esquina superior izquierda de la ventana, relativas a su padre.
width, height
Dimensiones de la ventana.
border_width
Ancho del borde de la ventana.
depth
Profundidad de bits de la ventana (número de bits por píxel).
visual
Puntero al tipo de visual de la ventana. Indica cómo se representan los colores.
your_event_mask
Máscara de eventos que se envían al cliente propietario de esta ventana.
your_do_not_propagate_mask
Máscara de eventos que no se deben propagar al propietario de la ventana.
backing_store
Estrategia de almacenamiento de respaldo para la ventana. Puede ser NotUseful, WhenMapped o Always.
windows_event_mask
Máscara de eventos que se envían a las ventanas secundarias (hijas).
windows_do_not_propagate_mask
Máscara de eventos que no se deben propagar a las ventanas secundarias.
backing_planes
Planos de bits que se deben guardar para el almacenamiento de respaldo.
backing_pixel
Valor de píxel para el almacenamiento de respaldo.
save_under
Indica si la ventana debe guardarse debajo de otras ventanas cuando se mapea.
event_list
Lista de manejadores de eventos para esta ventana. (Nota: Este campo es obsoleto en implementaciones modernas).
event_list_count
Número de manejadores de eventos en la lista. (Nota: Este campo es obsoleto en implementaciones modernas).

DESCRIPTION

La estructura XWindowAttributes se utiliza para almacenar varios atributos de una ventana en el sistema X Window.

Cuando se crea una ventana o se obtienen sus atributos, esta estructura se rellena con la información relevante.

Los campos your_event_mask y your_do_not_propagate_mask especifican qué tipos de eventos recibirá esta ventana del servidor X. Si se establece un bit en your_event_mask, el servidor X enviará los eventos correspondientes a esta ventana. Si se establece un bit en your_do_not_propagate_mask, los eventos de ese tipo no se propagarán más allá de esta ventana.

El campo backing_store controla cómo el servidor X maneja el contenido de la ventana cuando esta se solapa y se descubre parcialmente. NotUseful significa que el servidor no hará ningún esfuerzo especial. WhenMapped indica que el contenido se conservará mientras la ventana esté mapeada. Always significa que el contenido se conservará siempre, incluso cuando la ventana no esté mapeada.

Los campos windows_event_mask y windows_do_not_propagate_mask se aplican a las ventanas secundarias (hijas) de esta ventana. Permiten controlar la propagación de eventos a través de la jerarquía de ventanas.

Los campos backing_planes y backing_pixel se utilizan en conjunto con el backing_store para especificar qué partes de la ventana deben guardarse y con qué valor de píxel.

El campo save_under es una solicitud al gestor de ventanas para que mantenga el contenido de esta ventana visible cuando se superpone a otras ventanas, útil para menús emergentes o diálogos temporales.

Los campos event_list y event_list_count están obsoletos y generalmente no se utilizan en las implementaciones modernas de Xlib. La gestión de eventos se maneja principalmente a través de la máscara de eventos.

STRUCTURES

Esta estructura es una definición de C para los atributos de una ventana X.

DIAGNOSTICS

No hay diagnósticos específicos para esta estructura. Los errores relacionados con la obtención o establecimiento de atributos de ventana generalmente se informan a través de las funciones de Xlib que utilizan esta estructura.
