XdbeSwapBuffers(3) FUNCIONES DE X XdbeSwapBuffers(3)

NOMBRE

XdbeSwapBuffers - intercambia los búferes frontales y traseros de DBE.

SINOPSIS

#include <X11/extensions/Xdbe.h>

Status XdbeSwapBuffers(
Display *dpy,
XdbeSwapInfo *swap_info,
int num_windows)

DESCRIPCIÓN

Esta función intercambia los búferes frontales y traseros para una lista de ventanas. El argumento num_windows especifica cuántas ventanas tendrán sus búferes intercambiados; es el número de elementos en la matriz swap_info. El argumento swap_info especifica la información necesaria por ventana para realizar el intercambio.

La estructura XdbeSwapInfo tiene los siguientes campos:


Window swap_window
XdbeSwapAction swap_action

swap_window especifica la ventana para la cual intercambiar búferes. swap_action especifica la acción de intercambio a usar para esta swap_window.

swap_action determina qué sucederá con el nuevo búfer trasero de la swap_window con la que se empareja en la lista, además de hacer visible el antiguo búfer trasero. Las acciones definidas son las siguientes:

XdbeUndefined
El contenido del nuevo búfer trasero se vuelve indefinido. Esta puede ser la acción más eficiente ya que permite a la implementación descartar el contenido del búfer si lo necesita.
XdbeBackground
La región no oscurecida del nuevo búfer trasero se repetirá con el fondo de la ventana. La acción de fondo permite a los dispositivos usar una capacidad de borrado rápido durante un intercambio.
XdbeUntouched
La región no oscurecida del nuevo búfer trasero no se modificará por el intercambio.
XdbeCopied
La región no oscurecida del nuevo búfer trasero contendrá el contenido del antiguo búfer trasero.

ERRORES

BadMatch
Se especificó una ventana no doblemente bufferizada o se especificó una ventana dos veces.
BadWindow
Se especificó una ventana inválida.
BadValue
Se especificó una acción de intercambio inválida.
