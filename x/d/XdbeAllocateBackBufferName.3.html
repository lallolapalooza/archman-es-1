NOMBRE

XdbeAllocateBackBufferName - asigna un búfer de DBE.

SINOPSIS

#include <X11/extensions/Xdbe.h>

XdbeBackBuffer XdbeAllocateBackBufferName(
Display *dpy,
Window window,
XdbeSwapAction swap_action)

DESCRIPCIÓN

Esta función devuelve un ID de drawable que se utiliza para referirse al búfer trasero de la ventana especificada. El `swap_action` es una pista para indicar la acción de intercambio que probablemente se usará en llamadas posteriores a XdbeSwapBuffers(). La acción de intercambio real utilizada en las llamadas a XdbeSwapBuffers() no tiene que ser la misma que el `swap_action` pasado a esta función, aunque se anima a los clientes a proporcionar información precisa siempre que sea posible.

ERRORES

BadAlloc
BadIDChoice
BadMatch
La ventana especificada no es una ventana InputOutput o su visual no soporta DBE.
BadValue
Se especificó una acción de intercambio inválida.
BadWindow
Se especificó una ventana inválida.

VER TAMBIÉN

DBE, XdbeBeginIdiom(), XdbeDeallocateBackBufferName(), XdbeEndIdiom(), XdbeFreeVisualInfo(), XdbeGetBackBufferAttributes(), XdbeGetVisualInfo(), XdbeQueryExtension(), XdbeSwapBuffers().
