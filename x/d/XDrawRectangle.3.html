XDrawRectangle(3)

Paquete: libx11

Licencias: MIT AND X11

XDrawRectangle(3) FUNCIONES DE XLIB XDrawRectangle(3)

NOMBRE

XDrawRectangle, XDrawRectangles, XRectangle - dibuja rectángulos y estructura de rectángulos

SINTAXIS

int XDrawRectangle(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height);

int XDrawRectangles(Display *display, Drawable d, GC gc, XRectangle rectangles[], int nrectangles);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
nrectangles
Especifica el número de rectángulos en el array.
rectangles
Especifica un array de rectángulos.
width

height
Especifican el ancho y la altura, que definen las dimensiones del rectángulo.
x

y
Especifican las coordenadas x e y, que definen la esquina superior izquierda del rectángulo.

DESCRIPCIÓN

Las funciones XDrawRectangle y XDrawRectangles dibujan los contornos del rectángulo o rectángulos especificados como si se hubiera especificado una solicitud de protocolo PolyLine de cinco puntos para cada rectángulo:

[x,y] [x+width,y] [x+width,y+height] [x,y+height] [x,y]

Para el rectángulo o rectángulos especificados, estas funciones no dibujan un píxel más de una vez. XDrawRectangles dibuja los rectángulos en el orden listado en el array. Si los rectángulos se intersecan, los píxeles que se intersecan se dibujan varias veces.

Ambas funciones utilizan estos componentes del GC: function, plane-mask, line-width, line-style, cap-style, join-style, fill-style, subwindow-mode, clip-x-origin, clip-y-origin y clip-mask. También utilizan estos componentes dependientes del modo del GC: foreground, background, tile, stipple, tile-stipple-x-origin, tile-stipple-y-origin, dash-offset y dash-list.

XDrawRectangle y XDrawRectangles pueden generar errores BadDrawable, BadGC y BadMatch.

ESTRUCTURAS

La estructura XRectangle contiene:

typedef struct {
        short x, y;
        unsigned short width, height;
} XRectangle;

Todos los miembros x e y son enteros con signo. Los miembros width y height son enteros sin signo de 16 bits. Debes tener cuidado de no generar coordenadas y tamaños fuera de los rangos de 16 bits, ya que el protocolo solo tiene campos de 16 bits para estos valores.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.
