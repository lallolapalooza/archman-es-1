XDEVICEBELL(3)   XDEVICEBELL(3)

NOMBRE

XDeviceBell - hacer sonar una campana en un dispositivo compatible a través de la extensión de entrada

SINOPSIS

#include <X11/extensions/XInput.h>
Status XDeviceBell( Display *display,
                    XDevice *device,
                    XID feedbackclass,
                    XID feedbackid,
                    int percent);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo con el que está asociada la campana.
feedbackclass
       Especifica la clase de retroalimentación con la que está asociada la campana.
feedbackid
       Especifica el id de la retroalimentación con la que está asociada la campana.
percent
       Especifica el volumen en el rango de -100 a 100 en el que debe sonar la campana.

DESCRIPCIÓN

La solicitud XDeviceBell hace que el servidor haga sonar una campana en la retroalimentación especificada del dispositivo especificado, si es posible. El volumen especificado es relativo al volumen base para la campana.
Si se especifica un dispositivo inválido, se devolverá un error BadDevice. Los parámetros feedbackclass y feedbackid contienen valores devueltos por una solicitud XGetFeedbackControl e identifican de forma única la campana que debe sonar. Si se especifica una clase de retroalimentación que no admite una campana, o si se especifica un feedbackid inexistente, o si se especifica un valor de percent que no está en el rango de -100 a 100, se devolverá un error BadValue.
El volumen en el que suena la campana cuando el argumento percent es no negativo es: base - [(base * percent) / 100] + percent
El volumen en el que suena la campana cuando el argumento percent es negativo es: base + [(base * percent) / 100]
Para cambiar el volumen base de la campana, utilice
XChangeFeedbackControl.
XDeviceBell puede generar un error BadDevice o BadValue.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe, o no ha sido abierto por este cliente
       a través de XOpenInputDevice.
BadValue
       Se especificó una clase de retroalimentación (feedbackclass), un id de retroalimentación (feedbackid) o un valor percent inválido.

VÉASE TAMBIÉN

XChangeFeedbackControl(3), XBell(3)
