DESCRIPCIÓN

Las funciones XmbTextListToTextProperty, XwcTextListToTextProperty y Xutf8TextListToTextProperty establecen el valor XTextProperty especificado a un conjunto de elementos separados por nulos que representan la concatenación de la lista especificada de cadenas de texto terminadas en nulo. Las cadenas de texto de entrada deben proporcionarse en la codificación de la configuración regional actual (para XmbTextListToTextProperty y XwcTextListToTextProperty), o en codificación UTF-8 (para Xutf8TextListToTextProperty).

Las funciones establecen el campo de codificación de text_prop_return a un Atom para el display especificado que nombra la codificación determinada por el estilo especificado y convierten la lista de texto especificada a esta codificación para su almacenamiento en el campo de valor de text_prop_return. Si se especifica el estilo XStringStyle o XCompoundTextStyle, esta codificación es "STRING" o "COMPOUND_TEXT", respectivamente. Si se especifica el estilo XUTF8StringStyle, esta codificación es "UTF8_STRING". (Esta es una extensión introducida por The XFree86 Project, Inc., en su lanzamiento 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.) Si se especifica el estilo XTextStyle, esta codificación es la codificación de la configuración regional actual. Si se especifica el estilo XStdICCTextStyle, esta codificación es "STRING" si el texto es totalmente convertible a STRING, de lo contrario es "COMPOUND_TEXT". Un byte nulo final se almacena al final del campo de valor de text_prop_return pero no se incluye en el miembro nitems.

Si no hay suficiente memoria disponible para la nueva cadena de valor, las funciones devuelven XNoMemory. Si la configuración regional actual no es compatible, las funciones devuelven XLocaleNotSupported. En ambos casos de error, las funciones no establecen text_prop_return.

Para determinar si las funciones garantizan no devolver XLocaleNotSupported, utiliza XSupportsLocale.

Si el texto suministrado no es totalmente convertible a la codificación especificada, las funciones devuelven el número de caracteres no convertibles. Cada carácter no convertible se convierte en una cadena por defecto definida por la implementación y específica de la codificación. De lo contrario, las funciones devuelven Success. Ten en cuenta que se garantiza la convertibilidad total a todos los estilos excepto a XStringStyle.

Para liberar el almacenamiento del campo de valor, utiliza XFree.

Las funciones XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven una lista de cadenas de texto que representan los elementos separados por nulos de la estructura XTextProperty especificada. Las cadenas devueltas se codifican utilizando la codificación de la configuración regional actual (para XmbTextPropertyToTextList y XwcTextPropertyToTextList) o en UTF-8 (para Xutf8TextPropertyToTextList). Los datos en text_prop deben ser del formato 8.

Múltiples elementos de la propiedad (por ejemplo, las cadenas en una selección de texto discontinua) están separados por un byte nulo. Los contenidos de la propiedad no son necesariamente terminados en nulo; cualquier nulo final no debe incluirse en text_prop.nitems.

Si no hay suficiente memoria disponible para la lista y sus elementos, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven XNoMemory. Si la configuración regional actual no es compatible, las funciones devuelven XLocaleNotSupported. De lo contrario, si el campo de codificación de text_prop no es convertible a la codificación de la configuración regional actual, las funciones devuelven XConverterNotFound. Para las configuraciones regionales compatibles, la existencia de un conversor desde COMPOUND_TEXT, STRING, UTF8_STRING o la codificación de la configuración regional actual está garantizada si XSupportsLocale devuelve True para la configuración regional actual (pero el texto real puede contener caracteres no convertibles). La conversión de otras codificaciones depende de la implementación. En todos estos casos de error, las funciones no establecen ningún valor de retorno.

De lo contrario, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven la lista de cadenas de texto terminadas en nulo a list_return y el número de cadenas de texto a count_return.

Si el campo de valor de text_prop no es totalmente convertible a la codificación de la configuración regional actual, las funciones devuelven el número de caracteres no convertibles. Cada carácter no convertible se convierte en una cadena en la configuración regional actual que es específica de la configuración regional actual. Para obtener el valor de esta cadena, utiliza XDefaultString. De lo contrario, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven Success.

Para liberar el almacenamiento de la lista y su contenido devuelto por XmbTextPropertyToTextList o Xutf8TextPropertyToTextList, utiliza XFreeStringList. Para liberar el almacenamiento de la lista y su contenido devuelto por XwcTextPropertyToTextList, utiliza XwcFreeStringList.

La función XwcFreeStringList libera la memoria asignada por XwcTextPropertyToTextList.

La función XDefaultString devuelve la cadena por defecto utilizada por Xlib para la conversión de texto (por ejemplo, en XmbTextPropertyToTextList). La cadena por defecto es la cadena en la configuración regional actual que se genera cuando se encuentra un carácter no convertible durante la conversión de texto. Si la cadena devuelta por XDefaultString es la cadena vacía (""), no se genera ningún carácter en el texto convertido. XDefaultString no devuelve NULL.

La cadena devuelta por XDefaultString es independiente de la cadena por defecto para el dibujo de texto; consulta XCreateFontSet para obtener la cadena por defecto de un XFontSet.

El comportamiento cuando se suministra un punto de código inválido a cualquier función de Xlib no está definido.

La cadena devuelta está terminada en nulo. Es propiedad de Xlib y no debe ser modificada ni liberada por el cliente. Puede ser liberada después de que la configuración regional actual cambie. Hasta que se libere, Xlib no la modificará.

NAME

XDefaultString, XDefaultTextProperty, XGetTextProperty, XSetTextProperty, XFetchName, XFetchTextProperty, XlibTextPropertyToString, XTextPropertyToString, Xutf8TextListToTextProperty, Xutf8TextPropertyToTextList - propiedades de texto X, conversión de cadenas y conversión de texto UTF-8

    #include <X11/Xlocale.h>

    XGetTextProperty(Display *display, Window w, XTextProperty *text_prop_return,

    Status
    XSetTextProperty(Display *display, Window w, XTextProperty *text_prop,
                     Atom property);

    Status
    XFetchName(Display *display, Window w, XTextProperty *text_prop_return);

    Status
    XFetchTextProperty(Display *display, Window w, XTextProperty *text_prop_return,
                       Atom property);

    char *
    XlibTextPropertyToString(XTextProperty *text_prop);

    char *
    XTextPropertyToString(XTextProperty *text_prop);

    Status
    Xutf8TextListToTextProperty(Display *display, char **list, int count,
                                XICCEncodingStyle style, XTextProperty *text_prop_return);

    Xutf8TextPropertyToTextList(Display *display, XTextProperty *text_prop,
                                char ***list_return, int *count_return);

ARGUMENTS

display
Especifica el puntero a la estructura `Display`.
w
Especifica la ventana.
property
Especifica el átomo de la propiedad a leer o escribir.
text_prop_return
Devuelve la estructura `XTextProperty`. Ver más abajo.
text_prop
Puntero a la estructura `XTextProperty` que contiene la información de la propiedad a escribir.
list
Puntero a una lista de cadenas de texto.
count
El número de cadenas en la lista.
style
Especifica el estilo de codificación deseado para la propiedad de texto.
list_return
Devuelve un puntero a una lista de cadenas de texto.
count_return
Devuelve el número de cadenas de texto en la lista devuelta.

DESCRIPTION

Estas funciones operan en las propiedades de texto X. La propiedad de texto X más comúnmente utilizada es la propiedad de nombre de ventana (_NET_WM_NAME y WM_NAME).

La función XDefaultString devuelve el nombre de visualización predeterminado como una cadena.

La función XDefaultTextProperty obtiene la propiedad de texto predeterminada para una ventana y la almacena en la estructura `XTextProperty` especificada. Si la propiedad solicitada no existe, se recuperará la propiedad `_XTEXTRESOURCE`.

La función XGetTextProperty obtiene el valor de una propiedad de ventana y lo devuelve como una estructura `XTextProperty`. La propiedad puede ser cualquier átomo X válido. Si se especifica el átomo `XA_STRING`, se recupera la propiedad `WM_NAME`. Si la propiedad especificada no existe, la estructura `text_prop_return` se deja sin inicializar.

La función XSetTextProperty establece una propiedad de ventana a partir de una estructura `XTextProperty`. Si la propiedad especificada ya existe, se reemplaza. Si la propiedad no existe, se crea. Si se especifican `None` para el valor o el tipo, la propiedad se elimina.

La función XFetchName recupera la propiedad `WM_NAME` para una ventana y la devuelve como una estructura `XTextProperty`. Si la propiedad `WM_NAME` no existe, se recupera la propiedad `_XTEXTRESOURCE`.

La función XFetchTextProperty recupera el valor de una propiedad de ventana especificada y la devuelve como una estructura `XTextProperty`. Si la propiedad especificada no existe, la estructura `text_prop_return` se deja sin inicializar.

Las funciones XlibTextPropertyToString y XTextPropertyToString convierten una estructura `XTextProperty` en una cadena C. La función XlibTextPropertyToString es la interfaz de nivel inferior más antigua y siempre devuelve una cadena en la codificación del sistema X. La función XTextPropertyToString es una interfaz de nivel superior que intenta devolver una cadena en la codificación `STRING` (ASCII) o `COMPOUND_TEXT` si es posible.

Las funciones Xutf8TextListToTextProperty y Xutf8TextPropertyToTextList son extensiones introducidas por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.

STRUCTURES

La estructura XTextProperty contiene:

typedef struct {
        unsigned char *value;   /* property data */
        Atom encoding;  /* type of property */
        int format;     /* 8, 16, or 32 */
        unsigned long nitems;   /* number of items in value */
} XTextProperty;

La estructura XICCEncodingStyle contiene:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* text in owner's encoding (current locale) */
        XStdICCTextStyle,       /* STRING, else COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;
