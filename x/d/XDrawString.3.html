XDrawString(3)

Paquete: libx11

Licencias: MIT AND X11

XDrawString(3) FUNCIONES XLIB XDrawString(3)

NOMBRE

XDrawString, XDrawString16 - dibuja caracteres de texto

SINTAXIS

int XDrawString(Display *display, Drawable d, GC gc, int x, int y, _Xconst char *string, int length);

int XDrawString16(Display *display, Drawable d, GC gc, int x, int y, _Xconst XChar2b *string, int length);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
length
Especifica el número de caracteres en el argumento string.
string
Especifica la cadena de caracteres.
x

y
Especifican las coordenadas x e y, que son relativas al origen del drawable especificado y definen el origen del primer carácter.

DESCRIPCIÓN

Cada imagen de carácter, según se define en la fuente del GC, se trata como una máscara adicional para una operación de relleno en el drawable. El drawable se modifica solo donde el carácter de la fuente tiene un bit establecido en 1. Para fuentes definidas con indexación de matriz de 2 bytes y utilizadas con XDrawString16, cada byte se utiliza como byte2 con un byte1 de cero.

Ambas funciones utilizan estos componentes del GC: function, plane-mask, fill-style, font, subwindow-mode, clip-x-origin, clip-y-origin y clip-mask. También utilizan estos componentes dependientes del modo del GC: foreground, background, tile, stipple, tile-stipple-x-origin y tile-stipple-y-origin.

XDrawString y XDrawString16 pueden generar errores BadDrawable, BadGC y BadMatch.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero falla al coincidir de alguna otra manera requerida por la solicitud.
