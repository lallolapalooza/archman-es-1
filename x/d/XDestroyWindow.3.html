XDestroyWindow(3)

Paquete: libx11

Licencias: MIT AND X11

XDestroyWindow(3) FUNCIONES DE XLIB XDestroyWindow(3)

NOMBRE

XDestroyWindow, XDestroySubwindows - destruir ventanas

SINTAXIS

int XDestroyWindow(Display *display, Window w);

int XDestroySubwindows(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión al servidor X.
w
Especifica la ventana.

DESCRIPCIÓN

La función XDestroyWindow destruye la ventana especificada así como todas sus subventanas y provoca que el servidor X genere un evento DestroyNotify para cada ventana. La ventana nunca debe ser referenciada de nuevo. Si la ventana especificada por el argumento w está mapeada, se desmapea automáticamente. El orden de los eventos DestroyNotify es tal que para cualquier ventana que se esté destruyendo, DestroyNotify se genera en cualquier inferior de la ventana antes de generarse en la ventana misma. El orden entre hermanos y a través de subjerarquías no está restringido de otra manera. Si la ventana que especificaste es una ventana raíz, no se destruye ninguna ventana. Destruir una ventana mapeada generará eventos Expose en otras ventanas que fueron oscurecidas por la ventana que se está destruyendo.

XDestroyWindow puede generar un error BadWindow.

La función XDestroySubwindows destruye todas las ventanas inferiores de la ventana especificada, en orden de apilamiento de abajo hacia arriba. Provoca que el servidor X genere un evento DestroyNotify para cada ventana. Si se destruyeron subventanas mapeadas, XDestroySubwindows provoca que el servidor X genere eventos Expose en la ventana especificada. Esto es mucho más eficiente que eliminar muchas ventanas una a una, ya que gran parte del trabajo solo necesita realizarse una vez para todas las ventanas, en lugar de para cada ventana. Las subventanas nunca deben ser referenciadas de nuevo.

XDestroySubwindows puede generar un error BadWindow.

DIAGNÓSTICOS

BadWindow
Un valor para un argumento Window no nombra una Ventana definida.
