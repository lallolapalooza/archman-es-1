XDeleteContext(3)

Paquete: libx11

Licencias: MIT AND X11

XSaveContext(3) FUNCIONES XLIB XSaveContext(3)

NOMBRE

XSaveContext, XFindContext, XDeleteContext, XUniqueContext - rutinas de búsqueda asociativa

SINTAXIS

int XSaveContext(Display *display, XID rid, XContext context, _Xconst char *data);

int XFindContext(Display *display, XID rid, XContext context, XPointer *data_return);

int XDeleteContext(Display *display, XID rid, XContext context);

XContext XUniqueContext(void);

ARGUMENTOS

context
Especifica el tipo de contexto al que pertenecen los datos.
data
Especifica los datos a asociar con la ventana y el tipo.
data_return
Devuelve los datos.
display
Especifica la conexión con el servidor X.
rid
Especifica el ID del recurso con el que se asocian los datos.

DESCRIPCIÓN

Si ya existe una entrada con el ID de recurso y tipo especificados, XSaveContext la reemplaza con el contexto especificado. La función XSaveContext devuelve un código de error distinto de cero si ha ocurrido un error y cero en caso contrario. Los posibles errores son XCNOMEM (sin memoria).

Debido a que es un valor de retorno, los datos son un puntero. La función XFindContext devuelve un código de error distinto de cero si ha ocurrido un error y cero en caso contrario. Los posibles errores son XCNOENT (contexto no encontrado).

La función XDeleteContext elimina la entrada para el ID de recurso y tipo dados de la estructura de datos. Esta función devuelve los mismos códigos de error que XFindContext si se llama con los mismos argumentos. XDeleteContext no libera los datos cuya dirección se guardó.

La función XUniqueContext crea un tipo de contexto único que puede utilizarse en llamadas posteriores a XSaveContext.
