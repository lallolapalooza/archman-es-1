XAddHost(3) FUNCIONES DE XLIB XAddHost(3)

NOMBRE

XAddHost, XAddHosts, XListHosts, XRemoveHost, XRemoveHosts, XSetAccessControl, XEnableAccessControl, XDisableAccessControl, XHostAddress, XServerInterpretedAddress - controlar el acceso de host y la estructura de control de host

SINTAXIS

int XAddHost(Display *display, XHostAddress *host);

int XAddHosts(Display *display, XHostAddress *hosts, int num_hosts);

XHostAddress *XListHosts(Display *display, int *nhosts_return, Bool *state_return);

int XRemoveHost(Display *display, XHostAddress *host);

int XRemoveHosts(Display *display, XHostAddress *hosts, int num_hosts);

int XSetAccessControl(Display *display, int mode);

int XEnableAccessControl(Display *display);

int XDisableAccessControl(Display *display);

ARGUMENTOS

display
Especifica la conexión al servidor X.
host
Especifica el host que se va a añadir o eliminar.
hosts
Especifica cada host que se va a añadir o eliminar.
mode
Especifica el modo. Puedes pasar EnableAccess o DisableAccess.
nhosts_return
Devuelve el número de hosts actualmente en la lista de control de acceso.
num_hosts
Especifica el número de hosts.
state_return
Devuelve el estado del control de acceso.

DESCRIPCIÓN

La función XAddHost añade el host especificado a la lista de control de acceso para esa pantalla. El servidor debe estar en el mismo host que el cliente que emite el comando, o se producirá un error BadAccess.

XAddHost puede generar errores BadAccess y BadValue.

La función XAddHosts añade cada host especificado a la lista de control de acceso para esa pantalla. El servidor debe estar en el mismo host que el cliente que emite el comando, o se producirá un error BadAccess.

XAddHosts puede generar errores BadAccess y BadValue.

La función XListHosts devuelve la lista de control de acceso actual, así como si el uso de la lista en la configuración de la conexión estaba habilitado o deshabilitado. XListHosts permite a un programa averiguar qué máquinas pueden realizar conexiones. También devuelve un puntero a una lista de estructuras de host que fueron asignadas por la función. Cuando ya no se necesite, esta memoria debe liberarse llamando a XFree.

La función XRemoveHost elimina el host especificado de la lista de control de acceso para esa pantalla. El servidor debe estar en el mismo host que el proceso cliente, o se producirá un error BadAccess. Si eliminas tu máquina de la lista de acceso, ya no podrás conectarte a ese servidor y esta operación no se puede revertir a menos que reinicies el servidor.

XRemoveHost puede generar errores BadAccess y BadValue.

La función XRemoveHosts elimina cada host especificado de la lista de control de acceso para esa pantalla. El servidor X debe estar en el mismo host que el proceso cliente, o se producirá un error BadAccess. Si eliminas tu máquina de la lista de acceso, ya no podrás conectarte a ese servidor y esta operación no se puede revertir a menos que reinicies el servidor.

XRemoveHosts puede generar errores BadAccess y BadValue.

La función XSetAccessControl habilita o deshabilita el uso de la lista de control de acceso en cada configuración de conexión.

XSetAccessControl puede generar errores BadAccess y BadValue.

La función XEnableAccessControl habilita el uso de la lista de control de acceso en cada configuración de conexión.

XEnableAccessControl puede generar un error BadAccess.

La función XDisableAccessControl deshabilita el uso de la lista de control de acceso en cada configuración de conexión.

XDisableAccessControl puede generar un error BadAccess.

ESTRUCTURAS

La estructura XHostAddress contiene:

typedef struct {
        int family;     /* por ejemplo FamilyInternet */
        int length;     /* longitud de la dirección, en bytes */
        char *address;  /* puntero a dónde encontrar la dirección */
} XHostAddress;

El miembro family especifica qué familia de direcciones de protocolo usar (por ejemplo, TCP/IP o DECnet) y puede ser FamilyInternet, FamilyInternet6, FamilyServerInterpreted, FamilyDECnet, o FamilyChaos. El miembro length especifica la longitud de la dirección en bytes. El miembro address especifica un puntero a la dirección.

Para la familia ServerInterpreted, la longitud se ignora y el miembro address es un puntero a una estructura XServerInterpretedAddress que contiene:

typedef struct {
        int typelength;         /* longitud de la cadena de tipo, en bytes */
        int valuelength;        /* longitud de la cadena de valor, en bytes */
        char *type;             /* puntero a dónde encontrar la cadena de tipo */
        char *value;            /* puntero a dónde encontrar la dirección */
} XServerInterpretedAddress;

Los miembros type y value apuntan a cadenas que representan el tipo y el valor de la entrada interpretada por el servidor. Estas cadenas pueden no terminar en nulo, por lo que se debe tener cuidado al acceder a ellas. Los miembros typelength y valuelength especifican la longitud en bytes de las cadenas de tipo y valor.

DIAGNÓSTICOS

BadAccess
Un cliente intentó modificar la lista de control de acceso desde un host que no era el local (o autorizado de otra manera).
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta todo el rango definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
