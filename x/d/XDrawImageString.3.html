XDrawImageString(3)

Paquete: libx11

Licencias: MIT AND X11

XDrawImageString(3) FUNCIONES DE XLIB XDrawImageString(3)

NOMBRE

XDrawImageString, XDrawImageString16 - dibujar texto de imagen

SINTAXIS

int XDrawImageString(Display *display, Drawable d, GC gc, int x, int y, _Xconst char *string, int length);

int XDrawImageString16(Display *display, Drawable d, GC gc, int x, int y, _Xconst XChar2b *string, int length);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
length
Especifica el número de caracteres en el argumento string.
string
Especifica la cadena de caracteres.
x

y
Especifican las coordenadas x e y, que son relativas al origen del drawable especificado y definen el origen del primer carácter.

DESCRIPCIÓN

La función XDrawImageString16 es similar a XDrawImageString excepto que utiliza caracteres de 2 bytes o de 16 bits. Ambas funciones también utilizan los píxeles de primer plano y de fondo del GC en el destino.

El efecto es primero llenar un rectángulo de destino con el píxel de fondo definido en el GC y luego pintar el texto con el píxel de primer plano. La esquina superior izquierda del rectángulo rellenado está en:

[x, y - font-ascent]

El ancho es:

overall-width

La altura es:

font-ascent + font-descent

El ancho general (overall-width), el ascenso de la fuente (font-ascent) y el descenso de la fuente (font-descent) son los que devolvería XQueryTextExtents utilizando el gc y el string. La función y el estilo de relleno definidos en el GC se ignoran para estas funciones. La función efectiva es GXcopy, y el estilo de relleno efectivo es FillSolid.

Para fuentes definidas con indexación matricial de 2 bytes y utilizadas con XDrawImageString, cada byte se utiliza como byte2 con un byte1 de cero.

Ambas funciones utilizan estos componentes del GC: plane-mask, foreground, background, font, subwindow-mode, clip-x-origin, clip-y-origin, y clip-mask.

XDrawImageString y XDrawImageString16 pueden generar errores BadDrawable, BadGC y BadMatch.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.

NOTAS

A diferencia de XDrawString y XDrawString16, estas funciones no envían más de 255 caracteres a la vez al servidor. Cuando el número total de caracteres a enviar es mayor que 255, estas funciones dividen la cadena en fragmentos de hasta 255 caracteres. Después de enviar cada fragmento, estas funciones consultan al servidor para determinar la extensión real del texto.
