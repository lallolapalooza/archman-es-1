Paquete: libx11

XDestroyWindowEvent(3) FUNCIONES DE XLIB XDestroyWindowEvent(3)

NOMBRE

XDestroyWindowEvent - estructura de evento DestroyNotify

ESTRUCTURAS

La estructura para los eventos DestroyNotify contiene:

typedef struct {
        int type;       /* DestroyNotify */
        unsigned long serial;   /* # de la última petición procesada por el servidor */
        Bool send_event;        /* true si esto vino de una petición SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window event;
        Window window;
} XDestroyWindowEvent;

Cuando recibes este evento, los miembros de la estructura se configuran de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa de un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido a GraphicsExpose. El miembro display se establece en un puntero al display sobre el que se leyó el evento. El miembro send_event se establece en True si el evento provino de una petición de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo pero expandido de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de herramientas (toolkits).

El miembro event se establece bien en la ventana destruida o en su padre, dependiendo de si se seleccionó StructureNotify o SubstructureNotify. El miembro window se establece en la ventana que está siendo destruida.
