XdbeGetVisualInfo(3) FUNCIONES X XdbeGetVisualInfo(3)

NOMBRE

XdbeGetVisualInfo - Obtener información visual dbe

SINOPSIS

#include <X11/extensions/Xdbe.h>

XdbeScreenVisualInfo *XdbeGetVisualInfo(
Display *dpy,
Drawable *screen_specifiers,
int *num_screens)

DESCRIPCIÓN

Esta función devuelve información sobre qué visuales soportan el doble búfer. El argumento num_screens especifica cuántos elementos hay en la lista screen_specifiers. Cada drawable en screen_specifiers designa una pantalla para la cual se solicitan los visuales soportados. Si num_screens es cero, se solicita información para todas las pantallas. En este caso, al regresar de esta función, num_screens se establecerá en el número de pantallas encontradas. Si ocurre un error, esta función devuelve NULL, de lo contrario, devuelve un puntero a una lista de estructuras XdbeScreenVisualInfo de longitud num_screens. El enésimo elemento en la lista devuelta corresponde al enésimo drawable en la lista screen_specifiers, a menos que se haya pasado num_screens con el valor cero, en cuyo caso el enésimo elemento en la lista devuelta corresponde a la enésima pantalla del servidor, comenzando con la pantalla cero. La estructura XdbeScreenVisualInfo tiene los siguientes campos:


int count
XdbeVisualInfo *visinfo

count especifica el número de elementos en visinfo. visinfo especifica una lista de visuales, profundidades y sugerencias de rendimiento para esta pantalla.

La estructura XdbeVisualInfo tiene los siguientes campos:


VisualID visual
int depth
int perflevel

visual especifica un ID visual que soporta el doble búfer. depth especifica la profundidad del visual. perflevel es una sugerencia de rendimiento.

La única operación definida en un perflevel es la comparación con un perflevel de otro visual en la misma pantalla. El visual que tiene el perflevel más alto es probable que tenga un mejor rendimiento gráfico de doble búfer que el visual que tiene el perflevel más bajo. Nada se puede deducir de lo siguiente: la magnitud de la diferencia de dos perflevels, un valor de perflevel de forma aislada, o la comparación de perflevels de diferentes servidores.

ERRORES

BadDrawable
Uno o más valores pasados en screen_specifiers no son drawables válidos.
