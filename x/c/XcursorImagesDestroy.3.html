NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que construye cursores ya sea a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere utilizar la solicitud `CreateCursor` de la extensión Render si el servidor X lo soporta. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud `CreateCursor` del núcleo.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición absoluta en bytes del archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtype:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


header:	20 Las cabeceras de comentario tienen 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


header:	36 Las cabeceras de imagen tienen 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual a la altura
delay:	CARD32 Retraso entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor sigue (en su mayoría) la especificación de freedesktop.org para los temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas en este formato:
Inherits = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como el nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Inherits=. La especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor verifica el tema “default”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* altura real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Referencia un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden referenciar el mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

NAME

Xcursor - cursor loading library

SYNOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPTION

The Xcursor library provides functions for loading and displaying X cursors from cursor themes, as defined by the Freedesktop.org desktop entry specification.

It supports static cursors, animated cursors, and cursors that are defined by a list of glyphs in a font.

Basic APIs

XcursorCursors * XcursorCursorsCreate (
	Display 	*dpy)

Creates a new, empty XcursorCursors structure.

void XcursorCursorsDestroy (
	XcursorCursors 	*cursors)

Frees all memory associated with the given XcursorCursors structure.

XcursorBool XcursorCursorsAdd (
	XcursorCursors 	*cursors,
	int 	 x,
	int 	 y,
	const char 	*name,
	XcursorPixel 	*pixels,
	int 	 width,
	int 	 height,
	unsigned int 	 hotX,
	unsigned int 	 hotY)

Adds a cursor to the given XcursorCursors list. The cursor is identified by name, and described by pixel data.

	XcursorCursors 	*cursors,

	const char 	*name)

Loads a cursor theme named name from the display dpy into the cursors structure.

XcursorBool XcursorCursorsGet (
	XcursorCursors 	*cursors,
	Display 	*dpy,
	const char 	*name)

Loads a cursor named name for the display dpy into the cursors structure.

Cursor XcursorCursorsCreateCursor (
	XcursorCursors 	*cursors,
	Display 	*dpy,
	const char 	*name)

Creates a single X cursor from the given name and display.

void XcursorImageDestroy (
	XcursorImage 	*image)

Frees the memory associated with the given XcursorImage.

XcursorImage * XcursorLoadIcon (
	Display 	*dpy,
	const char 	*name)

Loads a cursor named name for the display dpy.

XcursorImage * XcursorLoadIconFixed (
	Display 	*dpy,
	const char 	*name,
	int 	 size)

Loads a cursor named name of the specified size for the display dpy.

Comment Handling

XcursorComments * XcursorCommentsCreate (
	Display 	*dpy)

Creates a new, empty XcursorComments structure.

void XcursorCommentsDestroy (
	XcursorComments 	*comments)

Deallocates the given XcursorComments structure as well as the XcursorComment structures which it points to.

Animated Cursors

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Wrap the given array of cursors in a newly allocated XcursorAnimate structure, which adds a sequence number used in XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Discards the given animate data, freeing both the XcursorCursors array of cursors as well as the XcursorAnimate structure.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Cyclically returns the next Cursor in the array, incrementing the sequence number to prepare for the next call.

The caller is responsible for displaying the series of Cursor images. Xcursor does not do that.

	Display 	*dpy,

If the display supports either ARGB or themes, try to load a cursor into Xcursor's cache using the source parameter as a Pixmap-id. The source may no longer be in the cache. Xcursor uses the hash value to identify the desired image.

	Display 	*dpy,
	Font 	 source_font,
	Font 	 mask_font,
	unsigned int 	 source_char,
	unsigned int 	 mask_char,

If the display supports either ARGB or themes, try to load a cursor into Xcursor's cache using the source_char parameter as a shape. Using

  • the source_char parameter as a shape,

ENVIRONMENT

Environment variables can be used to override resource settings, which in turn override compiled-in default values.

Some of the environment variables recognized by Xcursor are booleans, specified as follows:

true for “t”, “1”, “y” or “on”
false for “f”, “0”, “n” or “off”

Xcursor ignores other values for these booleans.

HOME
Xcursor interprets “~” in the search list as the home directory, using this variable rather than the password database.
XCURSOR_ANIM
If the display supports the Render CreateCursor request, and the Render feature is enabled, disable animated cursors if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.anim.
XCURSOR_CORE
If the display supports the Render CreateCursor request disable the Render feature if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.core.
XCURSOR_DISCOVER
If the variable is set, Xcursor turns on a logging feature. It displays the hash value and the image so that users can see which cursor name is associated with each image.
There is no corresponding resource setting.
XCURSOR_DITHER
This variable sets the desired dither.
If the environment variable is not given, Xcursor uses the resource Xcursor.dither.

XCURSOR_PATH
This variable sets the list of paths in which to search for cursors, rather than the compiled-in default list.
Directories in this path are separated by colons (:).
XCURSOR_RESIZED
Enables automatic resizing of cursors to improve their displayed size if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.resized resource.
XCURSOR_SIZE
This variable sets the desired cursor size, in pixels.
If the environment variable is not given, Xcursor tries the Xcursor.size resource.
If no size is given, whether by environment variable or resource setting, Xcursor next tries the Xft.dpi resource setting to guess the size of a 16-point cursor.
Finally, if Xft.dpi is not set, Xcursor uses the display height, dividing by 48 (assuming that the height is 768).
XCURSOR_THEME
This variable selects the desired theme.
If the environment variable is not given, Xcursor tries the Xcursor.theme resource.
If neither environment variable or resource is found, Xcursor uses the default theme.

XcursorSetTheme (3) — libXcursor — X Version 11

NAME

XcursorSetTheme, XcursorGetTheme, XcursorSetThemeCore, XcursorGetThemeCore \- set and get the cursor theme

LIBRARY

Xcursor (libXcursor, -lXcursor)

SYNOPSIS

    #include <Xcursor/Xcursor.h>

    Bool
    XcursorSetTheme
    (
        Display * dpy,
        const char * theme
    );

    char *
    XcursorGetTheme
    (
        Display * dpy
    );

    Bool
    XcursorSetThemeCore
    (
        Display * dpy,
        const char * theme
    );

    char *
    XcursorGetThemeCore
    (
        Display * dpy
    );

DESCRIPTION

The functions described in this page allow applications to set and get the cursor theme used by the X server.

XcursorSetTheme sets the cursor theme for the display dpy to theme. If theme is NULL, the default cursor theme is restored. The theme name is a string, typically the name of the theme directory, like "Adwaita" or "Breeze". The function returns True if the theme was successfully set, and False otherwise.

XcursorGetTheme returns the name of the currently active cursor theme for the display dpy. The returned string is allocated by the library and should be freed by the caller using Xfree(). If no theme is set, or an error occurs, it returns NULL.

XcursorSetThemeCore sets the cursor theme for the core pointer for the display dpy to theme. This affects the default cursors (like arrow, hand, etc.) that are used when no specific cursor is set for a window. If theme is NULL, the default cursor theme is restored. The function returns True if the theme was successfully set, and False otherwise.

XcursorGetThemeCore returns the name of the currently active cursor theme for the core pointer for the display dpy. The returned string is allocated by the library and should be freed by the caller using Xfree(). If no theme is set, or an error occurs, it returns NULL.

FUNCTIONAL OVERVIEW

The Xcursor library provides functions to manage cursor themes. Cursor themes are collections of cursor images that applications can use to change the appearance of the mouse pointer. This allows for customization of the user interface.

The library interacts with the X server to load and apply the specified cursor themes. It supports setting a general theme for all cursors and a specific theme for the core pointer, which represents the default cursors.

DATATYPES

Display
Represents a connection to an X server. This is a standard Xlib type.
char *
A pointer to a null-terminated string, used to represent theme names.
Bool
A boolean type, typically representing True or False. Returns indicate success or failure of an operation.

FUNCTIONS

XcursorSetTheme
Sets the cursor theme for the entire display.
XcursorGetTheme
Retrieves the name of the currently set cursor theme.
XcursorSetThemeCore
Sets the cursor theme specifically for the core pointer (default cursors).
XcursorGetThemeCore
Retrieves the name of the currently set core cursor theme.

ENVIRONMENT

XCURSOR_THEME
If this environment variable is set to a theme name (e.g., "Adwaita"), this theme will be used for all cursors unless overridden by XcursorSetTheme. If set to an empty string or the string "NONE", cursor theming will be disabled.
XCURSOR_THEME_CORE
If this environment variable is set to a theme name (e.g., "Adwaita"), this theme will be used for the core cursors (like arrow, hand, etc.) unless overridden by XcursorSetThemeCore. If set to an empty string or the string "NONE", core cursor theming will be disabled.
If the environment variables are not given, Xcursor tries the following resources:
Xcursor.theme
Corresponds to the XCURSOR_THEME environment variable.
Xcursor.theme_core
Corresponds to the XCURSOR_THEME_CORE environment variable.
An application can enable or disable themes using XcursorSetTheme and XcursorSetThemeCore.
