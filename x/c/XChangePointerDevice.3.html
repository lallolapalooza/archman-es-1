XCHANGEPOINTERDEVICE(3)   XCHANGEPOINTERDEVICE(3)

NOMBRE

XChangePointerDevice - cambia qué dispositivo es el puntero X

SINOPSIS

#include <X11/extensions/XInput.h>
Status XChangePointerDevice( Display *display,
                             XDevice *device,
                             int xaxis,
                             int yaxis);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo que se utilizará como puntero X.
xaxis
       Especifica el eje del dispositivo que se utilizará como
       eje X del puntero X.
yaxis
       Especifica el eje del dispositivo que se utilizará como
       eje Y del puntero X.

DESCRIPCIÓN

La solicitud XChangePointerDevice hace que el servidor utilice
el dispositivo especificado como el puntero X. El dispositivo
debe haber sido abierto por el cliente a través de XOpenDevice
o se producirá un error BadDevice. El dispositivo debe soportar
la clase de entrada Valuators o se producirá un error BadMatch.
Si la implementación no soporta el uso del dispositivo
especificado como puntero X, se producirá un error BadDevice.
Si el dispositivo especificado está capturado por otro cliente,
se devolverá AlreadyGrabbed. Si el dispositivo especificado está
congelado por una captura en otro dispositivo, se devolverá
GrabFrozen. Si la solicitud es exitosa, se devolverá Success.
Si la solicitud tiene éxito, se enviará un evento
ChangeDeviceNotify a todos los clientes que hayan seleccionado
ese evento. Se enviará un evento MappingNotify con request =
MappingPointer a todos los clientes. El dispositivo especificado
se convierte en el puntero X, y el puntero X antiguo se vuelve
accesible a través de las solicitudes del protocolo de extensión
de entrada.
XChangePointerDevice puede generar un error BadDevice o BadMatch.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo
       especificado no existe, no ha sido abierto por este cliente
       a través de XOpenInputDevice, o ya es uno de los dispositivos
       de entrada X principales (puntero o teclado). Este error
       también puede ocurrir si la implementación del servidor no
       soporta el uso del dispositivo especificado como puntero X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud
       XChangePointerDevice especificando un dispositivo que tiene
       menos de dos valuators, o especificando un índice de
       valuator fuera del rango soportado por el dispositivo.
