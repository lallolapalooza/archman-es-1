NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursor estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursor desde archivos. Por encima de eso hay una capa que localiza archivos de cursor basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere utilizar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor X estándar y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSOR

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes de cursor del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursor se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de fragmentos. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo tiene el siguiente aspecto:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTa de toc tabla de contenidos

Cada entrada de la tabla de contenidos tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en el TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en el TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursor; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentarios son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTa de CARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imágenes son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual que 0x7fff
alto:	CARD32 Debe ser menor o igual que 0x7fff
xhot:	CARD32 Debe ser menor o igual que el ancho
yhot:	CARD32 Debe ser menor o igual que el alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTa de CARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio de “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma de cursor, por ejemplo, como se utiliza en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio de “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas con el siguiente formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para utilizarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Nombre” (es decir, el nombre que una aplicación gráfica puede utilizar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
mantiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más significativo. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
mantiene múltiples estructuras XcursorImage. Todas se liberan cuando se liberan las XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* matriz de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Mantiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Referencia un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden referenciar el mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera la XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* qué cursor es el siguiente */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las de stdio.

STRUCTURES

XcursorFile

This structure provides a way to abstract reading/writing cursor data from various sources. The read and write functions are expected to take the file pointer as the first argument, and the remaining arguments are the buffer and length. The seek function takes the file pointer, an offset, and a whence flag. Note that the read and write functions in this structure are flipped in their argument order compared to the standard POSIX read and write functions, to place the file pointer first in the list of arguments. This is done to match the argument order in the return value and expected argument values; the read and write functions flip the arguments around to match the POSIX versions.


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lectura de imágenes de la biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se utiliza ese.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, se utiliza "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

ENTORNO


Las variables de entorno se pueden usar para anular la configuración
    de recursos, que a su vez anulan los valores predeterminados compilados.


Algunas de las variables de entorno reconocidas por Xcursor son
    booleanas, especificadas de la siguiente manera:





  
verdadero para
    “t”, “1”, “y” o
    “on”

  

  
falso para
    “f”, “0”, “n” o
    “off”

  






Xcursor ignora otros valores para estos booleanos.



  
HOME

  
Xcursor interpreta “~” en la lista de búsqueda como el directorio
      de inicio, utilizando esta variable en lugar de la base de datos de
      contraseñas.

  
XCURSOR_ANIM

  
Si la pantalla soporta la solicitud Render CreateCursor, y la función Render
      está habilitada, deshabilita los cursores animados si la variable de
      entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.anim.





  
XCURSOR_CORE

  
Si la pantalla soporta la solicitud Render CreateCursor, deshabilita la
      función Render si la variable de entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.core.





  
XCURSOR_DISCOVER

  
Si la variable está establecida, Xcursor activa una función de registro.
      Muestra el valor hash y la imagen para que los usuarios puedan ver qué
      nombre de cursor está asociado con cada imagen.





  

  
No hay una configuración de recurso correspondiente.





  
XCURSOR_DITHER

  
Esta variable establece el dither deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.dither.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor
      utiliza “threshold”

  

  
Estos son los valores reconocidos:

XCURSOR_PATH

  
Esta variable establece la lista de rutas en las que buscar cursores, en
      lugar de la lista predeterminada compilada.





  

  
Los directorios en esta ruta están separados por dos puntos (:).





  
XCURSOR_RESIZED

  
Habilita el redimensionamiento automático de cursores para mejorar su
      tamaño mostrado si la variable de entorno es true.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.resized.





  
XCURSOR_SIZE

  
Esta variable establece el tamaño deseado del cursor, en píxeles.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.size.

  

  
Si no se proporciona ningún tamaño, ya sea por variable de entorno o por
      configuración de recurso, Xcursor prueba a continuación la configuración
      del recurso Xft.dpi para adivinar el tamaño de un cursor de 16
      puntos.

  

  
Finalmente, si Xft.dpi no está establecido, Xcursor utiliza la
      altura de la pantalla, dividiendo por 48 (asumiendo que la altura es 768).





  
XCURSOR_THEME

  
Esta variable selecciona el tema deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.theme.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor
      utiliza el tema predeterminado.

XCURSOR_THEME

  
Sets the application-specific theme. If set, this overrides the
      default theme. For example,
      

      XCURSOR_THEME=Adwaita
      

      selects the Adwaita theme.

  
XCURSOR_SIZE

  
Sets the application-specific size. If set, this overrides the
      default size. For example,
      

      XCURSOR_SIZE=24
      

      selects cursors of size 24.

  
XCURSOR_THEME_CORE

  
Enable themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.
