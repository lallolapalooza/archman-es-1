NOMBRE

XcmsDefaultCCC - obtener el CCC predeterminado para una pantalla

SINTAXIS

XcmsCCC XcmsDefaultCCC(Display *display, int screen_number);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen_number
Especifica el número de pantalla apropiado en el servidor host.

DESCRIPCIÓN

La función XcmsDefaultCCC devuelve el CCC predeterminado para la pantalla especificada. Su visual es el visual predeterminado de la pantalla. Sus procedimientos iniciales de compresión de gama y ajuste de punto blanco, así como los datos del cliente asociados, son específicos de la implementación.
