XCrossingEvent(3)

Paquete: libx11

Licencias: MIT AND X11

XCrossingEvent(3) FUNCIONES XLIB XCrossingEvent(3)

NOMBRE

XCrossingEvent - estructura de eventos EnterNotify y LeaveNotify

ESTRUCTURAS

La estructura para los eventos EnterNotify y LeaveNotify contiene:

typedef struct {
        int type;       /* EnterNotify o LeaveNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window window;  /* Ventana de "evento" respecto a la que se informa */
        Window root;    /* ventana raíz en la que ocurrió el evento */
        Window subwindow;       /* ventana hija */
        Time time;      /* milisegundos */
        int x, y;       /* coordenadas x, y del puntero en la ventana de evento */
        int x_root, y_root;     /* coordenadas relativas a la raíz */
        int mode;       /* NotifyNormal, NotifyGrab, NotifyUngrab */
        int detail;
                /*
                * NotifyAncestor, NotifyVirtual, NotifyInferior,
                * NotifyNonlinear,NotifyNonlinearVirtual
                */
        Bool same_screen;       /* indicador same_screen */
        Bool focus;     /* indicador focus */
        unsigned int state;     /* máscara de tecla o botón */
} XCrossingEvent;
typedef XCrossingEvent XEnterWindowEvent;
typedef XCrossingEvent XLeaveWindowEvent;

Cuando recibes estos eventos, los miembros de la estructura se configuran como sigue.

El miembro type se establece en el nombre constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero a la pantalla en la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero ampliado desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkit.

El miembro window se establece en la ventana en la que se generó el evento EnterNotify o LeaveNotify y se denomina ventana de evento. Esta es la ventana utilizada por el servidor X para informar el evento, y es relativa a la ventana raíz en la que ocurrió el evento. El miembro root se establece en la ventana raíz de la pantalla en la que ocurrió el evento.

Para un evento LeaveNotify, si una hija de la ventana de evento contiene la posición inicial del puntero, el componente subwindow se establece en esa hija. De lo contrario, el servidor X establece el miembro subwindow en None. Para un evento EnterNotify, si una hija de la ventana de evento contiene la posición final del puntero, el componente subwindow se establece en esa hija o en None.

El miembro time se establece en el momento en que se generó el evento y se expresa en milisegundos. Los miembros x y y se establecen en las coordenadas de la posición del puntero en la ventana de evento. Esta posición es siempre la posición final del puntero, no su posición inicial. Si la ventana de evento está en la misma pantalla que la ventana raíz, x e y son las coordenadas del puntero relativas al origen de la ventana de evento. De lo contrario, x e y se establecen en cero. Los miembros x_root e y_root se establecen en las coordenadas del puntero relativas al origen de la ventana raíz en el momento del evento.

El miembro same_screen se establece para indicar si la ventana de evento está en la misma pantalla que la ventana raíz y puede ser True o False. Si es True, las ventanas de evento y raíz están en la misma pantalla. Si es False, las ventanas de evento y raíz no están en la misma pantalla.

El miembro focus se establece para indicar si la ventana de evento es la ventana de foco o un inferior de la ventana de foco. El servidor X puede establecer este miembro en True o False. Si es True, la ventana de evento es la ventana de foco o un inferior de la ventana de foco. Si es False, la ventana de evento no es la ventana de foco o un inferior de la ventana de foco.

El miembro state se establece para indicar el estado de los botones del puntero y las teclas modificadoras justo antes del evento. El servidor X puede establecer este miembro en el OR inclusivo a nivel de bits de una o más de las máscaras de botón o tecla modificadora: Button1Mask, Button2Mask, Button3Mask, Button4Mask, Button5Mask, ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask, Mod5Mask.

El miembro mode se establece para indicar si los eventos son eventos normales, eventos de pseudo-movimiento cuando se activa un grab, o eventos de pseudo-movimiento cuando se desactiva un grab. El servidor X puede establecer este miembro en NotifyNormal, NotifyGrab, o NotifyUngrab.

El miembro detail se establece para indicar el detalle de la notificación y puede ser NotifyAncestor, NotifyVirtual, NotifyInferior, NotifyNonlinear, o NotifyNonlinearVirtual.
