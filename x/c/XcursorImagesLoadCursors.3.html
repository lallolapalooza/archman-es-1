NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores ya sea a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud `CreateCursor` de la extensión Render si es soportada por el servidor X. Donde no se soporta, Xcursor mapea la imagen del cursor a un cursor estándar de X y usa la solicitud `CreateCursor` principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor se etiqueta con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de bloques. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en TOC para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en TOC para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imágenes tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayor parte) sigue la especificación de freedesktop.org para la tematización de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma (shape) del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra ningún archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas con este formato:
Hereda = nombre-tema

Xcursor utiliza el primer `nombre-tema` heredado, ignorando otros que puedan existir en un archivo `index.theme` dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras `claves` en el archivo `index.theme`, incluido `Name` (es decir, el nombre que una aplicación gráfica puede usar como `nombre de presentación`).

Se puede listar más de un `nombre-tema` en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no es clara sobre si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras `XcursorImage`. Todas se liberan cuando se libera `XcursorImages` en `XcursorImagesDestroy`. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* array de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera `XcursorCursors`. Estos tienen un contador de referencias para que múltiples estructuras `XcursorAnimate` puedan usar el mismo `XcursorCursors`. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras `XcursorAnimate` pueden hacer referencia al mismo `XcursorCursors`; cada una mantiene una referencia que se elimina cuando se libera `XcursorAnimate`. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las de stdi

    void *closure;

Lectura de imágenes de la biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úselo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, use "default" para el nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

.SH ENVIRONMENT
Environment variables can be used to override resource settings,
which in turn override compiled-in default values.
.PP
Some of the environment variables recognized by Xcursor are
booleans, specified as follows:
.TP
true for
“t”, “1”, “y” or
“on”
.TP
false for
“f”, “0”, “n” or
“off”
.PP
Xcursor ignores other values for these booleans.
.TP
HOME
Xcursor interprets “~” in the search list as the home
directory, using this variable rather than the password database.
.TP
XCURSOR_ANIM
If the display supports the Render CreateCursor request, and the Render
feature is enabled, disable animated cursors if the environment
variable is false.
.TP
If the environment variable is not given, Xcursor uses the resource
Xcursor.anim.
.TP
XCURSOR_CORE
If the display supports the Render CreateCursor request disable the Render
feature if the environment variable is false.
.TP
If the environment variable is not given, Xcursor uses the resource
Xcursor.core.
.TP
XCURSOR_DISCOVER
If the variable is set, Xcursor turns on a logging feature. It displays
the hash value and the image so that users can see which cursor name is
associated with each image.
.TP
There is no corresponding resource setting.
.TP
XCURSOR_DITHER
This variable sets the desired dither.
.TP
If the environment variable is not given, Xcursor uses the resource
Xcursor.dither.
.TP
If neither environment variable or resource is found, Xcursor uses
“threshold”
.TP
These are the recognized values:
.TP
diffuse
.TP
median
.TP
ordered
.TP
threshold
.TP
XCURSOR_PATH
This variable sets the list of paths in which to search for cursors,
rather than the compiled-in default list.
.TP
Directories in this path are separated by colons (:).
.TP
XCURSOR_RESIZED
Enables automatic resizing of cursors to improve their displayed size if
the environment variable is true.
.TP
If the environment variable is not given, Xcursor tries the
Xcursor.resized resource.
.TP
XCURSOR_SIZE
This variable sets the desired cursor size, in pixels.
.TP
If the environment variable is not given, Xcursor tries the
Xcursor.size resource.
.TP
If no size is given, whether by environment variable or resource setting,
Xcursor next tries the Xft.dpi resource setting to guess the size
of a 16-point cursor.
.TP
Finally, if Xft.dpi is not set, Xcursor uses the display height,
dividing by 48 (assuming that the height is 768).
.TP
XCURSOR_THEME
This variable selects the desired theme.
.TP
If the environment variable is not given, Xcursor tries the
Xcursor.theme resource.
.TP
If neither environment variable or resource is found, Xcursor uses the
default theme.
.TP
XCURSOR_THEME_CORE
