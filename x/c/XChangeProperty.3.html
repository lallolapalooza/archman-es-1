XGetWindowProperty(3) XLIB FUNCTIONS XGetWindowProperty(3)

NOMBRE

XGetWindowProperty, XListProperties, XChangeProperty, XRotateWindowProperties, XDeleteProperty - obtener y cambiar propiedades de ventanas

SINTAXIS

int XGetWindowProperty(Display *display, Window w, Atom property, long long_offset, long long_length, Bool delete, Atom req_type, Atom *actual_type_return, int *actual_format_return, unsigned long *nitems_return, unsigned long *bytes_after_return, unsigned char **prop_return);

Atom *XListProperties(Display *display, Window w, int *num_prop_return);

int XChangeProperty(Display *display, Window w, Atom property, Atom type, int format, int mode, _Xconst unsigned char *data, int nelements);

int XRotateWindowProperties(Display *display, Window w, Atom properties[], int num_prop, int npositions);

int XDeleteProperty(Display *display, Window w, Atom property);

ARGUMENTOS

actual_format_return
Devuelve el formato real de la propiedad.
actual_type_return
Devuelve el identificador de átomo que define el tipo real de la propiedad.
bytes_after_return
Devuelve el número de bytes restantes por leer en la propiedad si se realizó una lectura parcial.
data
Especifica los datos de la propiedad.
delete
Especifica un valor booleano que determina si se elimina la propiedad.
display
Especifica la conexión con el servidor X.
format
Especifica si los datos deben ser vistos como una lista de cantidades de 8, 16 o 32 bits. Los valores posibles son 8, 16 y 32. Esta información permite al servidor X realizar correctamente las operaciones de intercambio de bytes según sea necesario. Si el formato es de 16 o 32 bits, debe convertir explícitamente su puntero de datos a (unsigned char *) en la llamada a XChangeProperty.
long_length
Especifica la longitud en múltiplos de 32 bits de los datos que se van a recuperar.
long_offset
Especifica el desplazamiento en la propiedad especificada (en cantidades de 32 bits) donde se deben recuperar los datos.
mode
Especifica el modo de la operación. Puede pasar PropModeReplace, PropModePrepend o PropModeAppend.
nelements
Especifica el número de elementos del formato de datos especificado.
nitems_return
Devuelve el número real de elementos de 8, 16 o 32 bits almacenados en los datos de prop_return.
num_prop
Especifica la longitud del array de propiedades.
num_prop_return
Devuelve la longitud del array de propiedades.
npositions
Especifica la cantidad de rotación.
prop_return
Devuelve los datos en el formato especificado. Si el formato devuelto es 8, los datos devueltos se representan como un array de char. Si el formato devuelto es 16, los datos devueltos se representan como un array de tipo short int y deben convertirse a ese tipo para obtener los elementos. Si el formato devuelto es 32, los datos de la propiedad se almacenarán como un array de long (que en una aplicación de 64 bits serán valores de 64 bits que se rellenan en los 4 bytes superiores).
property
Especifica el nombre de la propiedad.
properties
Especifica el array de propiedades que se van a rotar.
req_type
Especifica el identificador de átomo asociado con el tipo de propiedad o AnyPropertyType.
type
Especifica el tipo de la propiedad. El servidor X no interpreta el tipo, sino que lo devuelve a una aplicación que más tarde llama a XGetWindowProperty.
w
Especifica la ventana cuya propiedad desea obtener, cambiar, rotar o eliminar.

DESCRIPCIÓN

La función XGetWindowProperty devuelve el tipo real de la propiedad; el formato real de la propiedad; el número de elementos de 8, 16 o 32 bits transferidos; el número de bytes restantes por leer en la propiedad; y un puntero a los datos realmente devueltos. XGetWindowProperty establece los argumentos de retorno de la siguiente manera:

  • Si la propiedad especificada no existe para la ventana especificada, XGetWindowProperty devuelve None a actual_type_return y el valor cero a actual_format_return y bytes_after_return. El argumento nitems_return está vacío. En este caso, el argumento delete se ignora.
  • Si la propiedad especificada existe pero su tipo no coincide con el tipo especificado, XGetWindowProperty devuelve el tipo de propiedad real a actual_type_return, el formato de propiedad real (nunca cero) a actual_format_return y la longitud de la propiedad en bytes (incluso si actual_format_return es 16 o 32) a bytes_after_return. También ignora el argumento delete. El argumento nitems_return está vacío.
  • Si la propiedad especificada existe y o bien asigna AnyPropertyType al argumento req_type o bien el tipo especificado coincide con el tipo de propiedad real, XGetWindowProperty devuelve el tipo de propiedad real a actual_type_return y el formato de propiedad real (nunca cero) a actual_format_return. También devuelve un valor a bytes_after_return y nitems_return, definiendo los siguientes valores:
N = longitud real de la propiedad almacenada en bytes
     (incluso si el formato es 16 o 32)
I = 4 * long_offset
T = N - I
L = MIN(T, 4 * long_length)
A = N - (I + L)
El valor devuelto comienza en el índice de byte I en la propiedad (indexando desde cero) y su longitud en bytes es L. Si el valor de long_offset hace que L sea negativo, se produce un error BadValue. El valor de bytes_after_return es A, que indica el número de bytes finales no leídos en la propiedad almacenada.

Si el formato devuelto es 8, los datos devueltos se representan como un array de char. Si el formato devuelto es 16, los datos devueltos se representan como un array de short y deben convertirse a ese tipo para obtener los elementos. Si el formato devuelto es 32, los datos devueltos se representan como un array de long y deben convertirse a ese tipo para obtener los elementos.

XGetWindowProperty siempre asigna un byte adicional en prop_return (incluso si la propiedad tiene longitud cero) y lo establece a cero para que las propiedades simples que consisten en caracteres no tengan que copiarse en otra cadena antes de usarse.

Si delete es True y bytes_after_return es cero, XGetWindowProperty elimina la propiedad de la ventana y genera un evento PropertyNotify en la ventana.

La función devuelve Success si se ejecuta correctamente. Para liberar los datos resultantes, use XFree.

XGetWindowProperty puede generar errores BadAtom, BadValue y BadWindow.

La función XListProperties devuelve un puntero a un array de propiedades de átomos que están definidas para la ventana especificada o devuelve NULL si no se encontraron propiedades. Para liberar la memoria asignada por esta función, use XFree.

XListProperties puede generar un error BadWindow.

La función XChangeProperty modifica la propiedad de la ventana especificada y hace que el servidor X genere un evento PropertyNotify.

El valor mode puede ser PropModeReplace, PropModePrepend o PropModeAppend.

El valor format puede ser 8, 16 o 32.

XChangeProperty puede generar errores BadAtom, BadMatch, BadValue y BadWindow.

La función XRotateWindowProperties rota las propiedades especificadas para la ventana dada. El argumento npositions especifica cuánto se deben rotar las propiedades. Si npositions es positivo, las propiedades se rotan hacia adelante en el array. Si es negativo, las propiedades se rotan hacia atrás. La rotación se realiza de forma circular.

XRotateWindowProperties puede generar errores BadAtom, BadValue y BadWindow.

La función XDeleteProperty elimina la propiedad especificada de la ventana dada y genera un evento PropertyNotify en la ventana.

XDeleteProperty puede generar errores BadAtom, BadValue y BadWindow.

NOMBRE

XChangeProperty, XGetWindowProperty, XRotateWindowProperties, XDeleteProperty — cambiar o obtener propiedades de ventana

SINTAXIS

#include <X11/Xlib.h>

int XChangeProperty(Display *display, Window w, Atom property, Atom type,
    int format, int mode, const unsigned char *data, int nelements);

int XGetWindowProperty(Display *display, Window w, Atom property,
    long long_offset, long long_count, Bool delete, Atom req_type,
    Atom *actual_type_return, int *actual_format_return,
    unsigned long *nitems_return, unsigned long *bytes_after_return,
    unsigned char **prop_return);

int XRotateWindowProperties(Display *display, Window w,
    Atom *atoms, int npositions);

int XDeleteProperty(Display *display, Window w, Atom property);

ARGUMENTOS

Describe los argumentos de las funciones.

DESCRIPCIÓN

Las propiedades son pares de nombre-valor que se asocian con ventanas. Se utilizan para almacenar información sobre la ventana, como el título de la ventana, el tamaño, los iconos y otra información específica del cliente. Las propiedades son definidas por el protocolo X pero son utilizadas principalmente por los clientes. La información se almacena en propiedades por el cliente que es propietario de la ventana.

XChangeProperty escribe datos en una propiedad de ventana. Si la propiedad especificada no existe, se crea. Si existe, su valor se reemplaza o se modifica según el valor del argumento de modo. El tipo, formato y datos de la propiedad se especifican en los argumentos type, format, data y nelements. El argumento nelements es el número de elementos de datos, no el número de bytes. El formato especifica el tamaño de cada elemento de datos en bits. Solo los formatos 8, 16 y 32 son válidos. Si el formato es 8, los datos son caracteres. Si el formato es 16, los datos son cortos. Si el formato es 32, los datos son largos.

El argumento de modo puede ser:

  • Si el modo es PropModeReplace, XChangeProperty descarta el valor de la propiedad anterior y almacena los nuevos datos.
  • Si el modo es PropModePrepend o PropModeAppend, XChangeProperty inserta los datos especificados antes del inicio de los datos existentes o al final de los datos existentes, respectivamente. El tipo y el formato deben coincidir con el valor de la propiedad existente, o se producirá un error BadMatch. Si la propiedad no está definida, se trata como definida con el tipo y formato correctos con datos de longitud cero.

Si el formato especificado es 8, los datos de la propiedad deben ser una matriz char. Si el formato especificado es 16, los datos de la propiedad deben ser una matriz short. Si el formato especificado es 32, los datos de la propiedad deben ser una matriz long.

La vida útil de una propiedad no está ligada al cliente que la almacena. Las propiedades permanecen hasta que se eliminan explícitamente, hasta que se destruye la ventana o hasta que se reinicia el servidor. Para una discusión sobre lo que sucede cuando se cierra la conexión al servidor X, consulte la sección 2.6. El tamaño máximo de una propiedad depende del servidor y puede variar dinámicamente según la cantidad de memoria que el servidor tenga disponible. (Si no hay suficiente espacio, se producirá un error BadAlloc).

XChangeProperty puede generar errores BadAlloc, BadAtom, BadMatch, BadValue y BadWindow.

La función XRotateWindowProperties le permite rotar propiedades en una ventana y hace que el servidor X genere eventos PropertyNotify. Si los nombres de propiedad en la matriz de propiedades se consideran numerados a partir de cero y si hay num_prop nombres de propiedad en la lista, entonces el valor asociado con el nombre de propiedad I se convierte en el valor asociado con el nombre de propiedad (I + npositions) mod N para todo I desde cero hasta N - 1. El efecto es rotar los estados en npositions posiciones alrededor del anillo virtual de nombres de propiedad (derecha para npositions positivas, izquierda para npositions negativas). Si npositions mod N no es cero, el servidor X genera un evento PropertyNotify para cada propiedad en el orden en que aparecen en la matriz. Si un átomo ocurre más de una vez en la lista o no hay ninguna propiedad con ese nombre definida para la ventana, se producirá un error BadMatch. Si se produce un error BadAtom o BadMatch, no se cambiará ninguna propiedad.

XRotateWindowProperties puede generar errores BadAtom, BadMatch y BadWindow.

La función XDeleteProperty elimina la propiedad especificada solo si la propiedad estaba definida en la ventana especificada y hace que el servidor X genere un evento PropertyNotify en la ventana, a menos que la propiedad no exista.

XDeleteProperty puede generar errores BadAtom y BadWindow.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadAtom
Un valor para un argumento de Átomo no nombra un Átomo definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
