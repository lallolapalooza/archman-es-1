NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que construye cursores ya sea a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas de archivos, Xcursor prefiere utilizar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de bloques. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en el TOC para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en el TOC para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imágenes tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles con formato ARGB empaquetado

TEMAS

Xcursor (principalmente) sigue la especificación de freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de la forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas con este formato:
Hereda = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Nombre” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;

Some of the environment variables recognized by Xcursor are booleans, specified as follows: *true* for “t”, “1”, “y” or “on” *false* for “f”, “0”, “n” or “off” Xcursor ignores other values for these booleans. If the environment variable is not given, Xcursor uses the resource Xcursor.anim. If the environment variable is not given, Xcursor uses the resource Xcursor.core. XCURSOR_DISCOVER If the variable is set, Xcursor turns on a logging feature. XCURSOR_DITHER This variable sets the desired *dither*. If the environment variable is not given, Xcursor uses the resource Xcursor.dither. If the environment variable is not given, Xcursor tries the Xcursor.size resource. SYNOPSIS

#include <Xcursor/Xcursor.h>

DESCRIPTION

The Xcursor library provides functions for loading and manipulating cursor images for the X Window System. It supports various cursor image formats and allows for dynamic theme switching.

FUNCTIONAL OVERVIEW

The library provides functions to:

  • Load cursor images from files or strings.
  • Save cursor images to files.
  • Create and destroy cursor renditions.
  • Set and retrieve cursor themes.
  • Handle cursor display and updates.

DATATYPES

XcursorImage
Structure representing a single cursor image, including dimensions, hotspot, and pixel data.
XcursorImages
Structure representing a collection of cursor images, typically for a single cursor name.
XcursorRendition
Internal structure used by the library to manage cursor renditions.

FUNCTIONS

Loads a single cursor image from a file.
XcursorFileLoadImages
Loads multiple cursor images from a file.
XcursorFileSaveImage
Saves a single cursor image to a file.
XcursorFileSaveImages
Saves multiple cursor images to a file.
XcursorLibraryNotify
Callback function for library notifications.
XcursorLoadCursor
Loads a cursor from a named image.
XcursorParseImageFromFile
Parses a cursor image from a file.
XcursorParseImageFromString
Parses a cursor image from a string.
XcursorRenditionCreate
Creates a new cursor rendition.
XcursorRenditionDestroy
Destroys a cursor rendition.
XcursorRenditionGetImage
Retrieves an image from a cursor rendition.
XcursorRenditionGetInfo
Gets information about a cursor rendition.
XcursorRenditionMerge
Merges two cursor renditions.
XcursorRenditionServerOwns
Checks if the server owns a rendition.
XcursorRenditionSet
Sets a cursor rendition.
XcursorRenditionSize
Gets the size of a cursor rendition.
XcursorSetDefault
Sets the default cursor.
XcursorSetDefaultRootWindow
Sets the default cursor for the root window.
XcursorSetTheme
Sets the cursor theme.
XcursorSetThemeCore
Sets the core cursor theme.
XcursorSupports
Checks if a feature is supported.

ENVIRONMENT

Xcursor.theme
Specifies the cursor theme to use. If set to none, the system default theme is used. If not specified, the theme specified by Xcursor.theme_core is used.
Xcursor.theme_core

Specifies the core cursor theme to use. If the environment variable is set to true, themes for core cursors are enabled. If not specified, Xcursor tries the Xcursor.theme_core resource.

An application can enable or disable themes using XcursorSetThemeCore.

CAVEATS

Xcursor will probably change radically in the future; weak attempts will be made to retain some level of source-file compatibility.
