XConfigureRequestEvent(3) FUNCIONES DE XLIB XConfigureRequestEvent(3)

NOMBRE

XConfigureRequestEvent - estructura del evento ConfigureRequest

ESTRUCTURAS

La estructura para los eventos ConfigureRequest contiene:

typedef struct {
        int type;       /* ConfigureRequest */
        unsigned long serial;   /* # de la última petición procesada por el servidor */
        Bool send_event;        /* true si esto vino de una petición SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window parent;
        Window window;
        int x, y;
        int width, height;
        int border_width;
        Window above;
        int detail;     /* Above, Below, TopIf, BottomIf, Opposite */
        unsigned long value_mask;
} XConfigureRequestEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro type se establece con el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa de un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido a GraphicsExpose. El miembro display se establece en un puntero al display en el que se leyó el evento. El miembro send_event se establece en True si el evento provino de una petición de protocolo SendEvent. El miembro serial se establece a partir del número serial informado en el protocolo pero expandido de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

El miembro parent se establece en la ventana padre. El miembro window se establece en la ventana cuyo tamaño, posición, ancho de borde y/o orden de apilamiento se va a reconfigurar. El miembro value_mask indica qué componentes se especificaron en la petición de protocolo ConfigureWindow. Los valores correspondientes se informan tal como se dieron en la petición. Los valores restantes se rellenan a partir de la geometría actual de la ventana, excepto en el caso de above (hermano) y detail (modo de pila), que se informan como None y Above, respectivamente, si no se dan en la petición.
