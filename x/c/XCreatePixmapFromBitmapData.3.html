XCreatePixmapFromBitmapData(3)

Paquete: libx11

Licencias: MIT AND X11

XReadBitmapFile(3) FUNCIONES DE XLIB XReadBitmapFile(3)

NOMBRE

XReadBitmapFile, XReadBitmapFileData, XWriteBitmapFile, XCreatePixmapFromBitmapData, XCreateBitmapFromData - manipular mapas de bits

SINTAXIS

int XReadBitmapFile(Display *display, Drawable d, _Xconst char *filename, unsigned int *width_return, unsigned int *height_return, Pixmap *bitmap_return, int *x_hot_return, int *y_hot_return);

int XReadBitmapFileData(_Xconst char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

int XWriteBitmapFile(Display *display, _Xconst char *filename, Pixmap bitmap, unsigned int width, unsigned int height, int x_hot, int y_hot);

Pixmap XCreatePixmapFromBitmapData(Display *display, Drawable d, char *data, unsigned int width, unsigned int height, unsigned long fg, unsigned long bg, unsigned int depth);

Pixmap XCreateBitmapFromData(Display *display, Drawable d, _Xconst char *data, unsigned int width, unsigned int height);

ARGUMENTOS

bitmap
Especifica el mapa de bits.
bitmap_return
Devuelve el mapa de bits que se crea.
d
Especifica el drawable que indica la pantalla.
data
Especifica los datos en formato de mapa de bits.
data
Especifica la ubicación de los datos del mapa de bits.
data_return
Devuelve los datos del mapa de bits.
depth
Especifica la profundidad del pixmap.
display
Especifica la conexión con el servidor X.
fg

bg
Especifica los valores de píxel de primer plano y fondo a usar.
filename
Especifica el nombre del archivo a usar. El formato del nombre de archivo depende del sistema operativo.
width

height
Especifica el ancho y el alto.
width_return

height_return
Devuelve los valores de ancho y alto del archivo de mapa de bits leído.
x_hot

y_hot
Especifica dónde colocar las coordenadas del punto de acceso (o -1,-1 si no hay ninguna) en el archivo.
x_hot_return

y_hot_return
Devuelve las coordenadas del punto de acceso.

DESCRIPCIÓN

La función XReadBitmapFile lee un archivo que contiene un mapa de bits. El archivo se analiza en la codificación de la configuración regional actual. La capacidad de leer formatos distintos al estándar depende de la implementación. Si el archivo no se puede abrir, XReadBitmapFile devuelve BitmapOpenFailed. Si el archivo se puede abrir pero no contiene datos de mapa de bits válidos, devuelve BitmapFileInvalid. Si no se asigna suficiente espacio de trabajo, devuelve BitmapNoMemory. Si el archivo es legible y válido, devuelve BitmapSuccess.

XReadBitmapFile devuelve la altura y el ancho del mapa de bits, tal como se leen del archivo, a width_return y height_return. Luego crea un pixmap del tamaño apropiado, lee los datos del mapa de bits del archivo en el pixmap y asigna el pixmap a la variable bitmap del llamador. El llamador debe liberar el pixmap usando XFreePixmap cuando haya terminado. Si existen name_x_hot y name_y_hot, XReadBitmapFile los devuelve a x_hot_return y y_hot_return; de lo contrario, devuelve -1,-1.

XReadBitmapFile puede generar errores BadAlloc y BadDrawable.

La función XReadBitmapFileData lee un archivo que contiene un mapa de bits, de la misma manera que XReadBitmapFile, pero devuelve los datos directamente en lugar de crear un pixmap en el servidor. Los datos del mapa de bits se devuelven en data_return; el cliente debe liberar este almacenamiento cuando haya terminado con él llamando a XFree. El estado y otros valores de retorno son los mismos que para XReadBitmapFile.

La función XWriteBitmapFile escribe un mapa de bits en un archivo en el formato X Versión 11. El nombre utilizado en el archivo de salida se deriva del nombre del archivo eliminando el prefijo del directorio. El archivo se escribe en la codificación de la configuración regional actual. Si el archivo no se puede abrir para escribir, devuelve BitmapOpenFailed. Si se asigna memoria insuficiente, XWriteBitmapFile devuelve BitmapNoMemory; de lo contrario, si no hay error, devuelve BitmapSuccess. Si x_hot y y_hot no son -1, -1, XWriteBitmapFile los escribe como las coordenadas del punto de acceso para el mapa de bits.

XWriteBitmapFile puede generar errores BadDrawable y BadMatch.

La función XCreatePixmapFromBitmapData crea un pixmap de la profundidad dada y luego realiza un XPutImage en formato de mapa de bits de los datos en él. La profundidad debe ser compatible con la pantalla del drawable especificado, o se producirá un error BadMatch.

XCreatePixmapFromBitmapData puede generar errores BadAlloc y BadMatch.

La función XCreateBitmapFromData le permite incluir en su programa C (usando #include) un archivo de mapa de bits que fue escrito por XWriteBitmapFile (solo formato X versión 11) sin leer el archivo de mapa de bits. El siguiente ejemplo crea un mapa de bits gris:

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

Si se asignó almacenamiento de trabajo insuficiente, XCreateBitmapFromData devuelve None. Es su responsabilidad liberar el pixmap usando XFreePixmap cuando haya terminado.

XCreateBitmapFromData puede generar un error BadAlloc.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadMatch
Se utiliza una ventana InputOnly como Drawable.

XCreatePixmapFromBitmapData(3)

NAME

XCreatePixmapFromBitmapData - crea un pixmap a partir de datos de mapa de bits

SYNTAX

Pixmap XCreatePixmapFromBitmapData (
    Display *display,
    Drawable drawable,
    const char *data,
    unsigned int width,
    unsigned int height,
    unsigned long forecolor,
    unsigned long backcolor,
    int depth
);

ARGUMENTS

  • display: Especifica la conexión con el servidor X.
  • drawable: Especifica el Drawable para obtener la profundidad y el sistema de coordenadas.
  • data: Especifica los datos del mapa de bits.
  • width: Especifica el ancho del mapa de bits en bytes.
  • height: Especifica el alto del mapa de bits en líneas.
  • forecolor: Especifica el color de primer plano (primero).
  • backcolor: Especifica el color de fondo (segundo).
  • depth: Especifica la profundidad del pixmap.

DESCRIPTION

La función XCreatePixmapFromBitmapData crea un pixmap en el servidor X y lo llena con los datos de mapa de bits especificados. Los datos del mapa de bits se interpretan como un arreglo de bytes donde cada bit representa un píxel. Los bits 1 se dibujan con el forecolor y los bits 0 se dibujan con el backcolor.

El width se especifica en bytes, no en píxeles. El número de píxeles en cada línea es el width multiplicado por 8. El height se especifica en líneas.

La depth especifica la profundidad del pixmap. Debe ser una profundidad válida para el servidor X.

Si la operación tiene éxito, la función devuelve el Pixmap creado. Si ocurre un error, devuelve None.

DIAGNOSTICS

BadAlloc: No se pudo asignar memoria para el pixmap.
