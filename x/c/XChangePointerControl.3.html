XChangePointerControl(3) FUNCIONES DE XLIB XChangePointerControl(3)

NOMBRE

XChangePointerControl, XGetPointerControl - controlar el puntero

SINTAXIS

int XChangePointerControl(Display *display, Bool do_accel, Bool do_threshold, int accel_numerator, int accel_denominator, int threshold);

int XGetPointerControl(Display *display, int *accel_numerator_return, int *accel_denominator_return, int *threshold_return);

ARGUMENTOS

accel_denominator
Especifica el denominador para el multiplicador de aceleración.
accel_denominator_return
Devuelve el denominador para el multiplicador de aceleración.
accel_numerator
Especifica el numerador para el multiplicador de aceleración.
accel_numerator_return
Devuelve el numerador para el multiplicador de aceleración.
display
Especifica la conexión con el servidor X.
do_accel
Especifica un valor booleano que controla si se utilizan los valores de accel_numerator o accel_denominator.
do_threshold
Especifica un valor booleano que controla si se utiliza el valor de threshold.
threshold
Especifica el umbral de aceleración.
threshold_return
Devuelve el umbral de aceleración.

DESCRIPCIÓN

La función XChangePointerControl define cómo se mueve el dispositivo señalador. La aceleración, expresada como una fracción, es un multiplicador para el movimiento. Por ejemplo, especificar 3/1 significa que el puntero se mueve tres veces más rápido de lo normal. La fracción puede ser redondeada arbitrariamente por el servidor X. La aceleración solo entra en efecto si el puntero se mueve más de umbral píxeles a la vez y solo se aplica a la cantidad que excede el valor del argumento threshold. Establecer un valor a -1 restaura los valores predeterminados. Los valores de los argumentos do_accel y do_threshold deben ser True para que se establezcan los valores del puntero, o los parámetros no se modificarán. Los valores negativos (distintos de -1) generan un error BadValue, al igual que un valor cero para el argumento accel_denominator.

XChangePointerControl puede generar un error BadValue.

La función XGetPointerControl devuelve el multiplicador de aceleración y el umbral de aceleración actuales del puntero.

DIAGNÓSTICOS

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
