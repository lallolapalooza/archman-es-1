NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o desde memoria. Existe una biblioteca de cursores comunes que se corresponden con los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

DESCRIPCIÓN GENERAL DE LA FUNCIONALIDAD

Xcursor está construida en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores bien a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es soportada por el servidor X. Donde no es soportada, Xcursor mapea la imagen del cursor a un cursor estándar de X y usa la solicitud CreateCursor del núcleo.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Múltiples cursores del mismo tamaño nominal se pueden cargar juntos; se espera que las aplicaciones los usen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de fragmentos. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenidos
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos se ve así:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición de byte absoluta de la tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en la tabla de contenidos para este fragmento
subtype:	CARD32 debe coincidir con el subtipo en la tabla de contenidos para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


header:	20 Las cabeceras de comentarios son de 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


header:	36 Las cabeceras de imágenes son de 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual a la altura
delay:	CARD32 Retardo entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para los temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma (shape) del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra ningún archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas con este formato:
Inherits = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Inherits=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Inherits=; la especificación de freedesktop.org no es clara sobre si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor verifica el tema “default”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* altura real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio
acciones en el valor de retorno y los valores esperados de los argumentos; las funciones de lectura y escritura invierten los argumentos para que coincidan con las versiones POSIX. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lectura de imágenes de la biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úsalo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, usa "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

ENTORNO


Las variables de entorno se pueden usar para anular la configuración
    de recursos, que a su vez anulan los valores predeterminados compilados.


Algunas de las variables de entorno reconocidas por Xcursor son
    booleanas, especificadas de la siguiente manera:





  
verdadero para
    “t”, “1”, “y” o
    “on”

  

  
falso para
    “f”, “0”, “n” o
    “off”

  






Xcursor ignora otros valores para estos booleanos.



  
HOME

  
Xcursor interpreta “~” en la lista de búsqueda como el directorio
      personal, utilizando esta variable en lugar de la base de datos de contraseñas.

  
XCURSOR_ANIM

  
Si la pantalla soporta la solicitud Render CreateCursor, y la función Render
      está habilitada, deshabilita los cursores animados si la variable de
      entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.anim.





  
XCURSOR_CORE

  
Si la pantalla soporta la solicitud Render CreateCursor, deshabilita la
      función Render si la variable de entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.core.





  
XCURSOR_DISCOVER

  
Si la variable está establecida, Xcursor activa una función de registro.
      Muestra el valor hash y la imagen para que los usuarios puedan ver qué nombre
      de cursor está asociado con cada imagen.





  

  
No hay una configuración de recurso correspondiente.





  
XCURSOR_DITHER

  
Esta variable establece el dither deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.dither.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza
      “umbral”

  

  
Estos son los valores reconocidos:







  
difuso

  

  
mediana

  

  
ordenado

  

  
umbral

  







  
XCURSOR_PATH

  
Esta variable establece la lista de rutas en las que buscar cursores, en
      lugar de la lista predeterminada compilada.





  

  
Los directorios en esta ruta están separados por dos puntos (:).





  
XCURSOR_RESIZED

  
Habilita el redimensionamiento automático de cursores para mejorar su tamaño
      mostrado si la variable de entorno es true.





  

  
Si no se proporciona la variable de entorno, Xcursor intenta el recurso
      Xcursor.resized.





  
XCURSOR_SIZE

  
Esta variable establece el tamaño de cursor deseado, en píxeles.





  

  
Si no se proporciona la variable de entorno, Xcursor intenta el recurso
      Xcursor.size.

  

  
Si no se proporciona ningún tamaño, ya sea por variable de entorno o por
      configuración de recurso, Xcursor intenta a continuación la configuración
      del recurso Xft.dpi para adivinar el tamaño de un cursor de 16
      puntos.

  

  
Finalmente, si Xft.dpi no está establecido, Xcursor utiliza la
      altura de la pantalla, dividiendo por 48 (asumiendo que la altura es
      768).





  
XCURSOR_THEME

  
Esta variable selecciona el tema deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor intenta el recurso
      Xcursor.theme.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza
      el tema predeterminado.





  
XCURSOR_THE


ME_CORE



  

  
Habilita los temas para los cursores principales si la variable de entorno es
      true.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.theme_core.

  

  
Una aplicación puede habilitar o deshabilitar temas usando
    XcursorSetThemeCore.
