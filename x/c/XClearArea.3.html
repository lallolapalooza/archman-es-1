XClearArea(3) FUNCIONES DE XLIB XClearArea(3)

NOMBRE

XClearArea, XClearWindow - limpiar área o ventana

SINTAXIS

int XClearArea(Display *display, Window w, int x, int y, unsigned width, unsigned height, Bool exposures);

int XClearWindow(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
exposures
Especifica un valor booleano que indica si se deben generar eventos Expose.
w
Especifica la ventana.
width

height
Especifican el ancho y el alto, que son las dimensiones del rectángulo.
x

y
Especifican las coordenadas x e y, que son relativas al origen de la ventana y especifican la esquina superior izquierda del rectángulo.

DESCRIPCIÓN

La función XClearArea pinta un área rectangular en la ventana especificada de acuerdo con las dimensiones especificadas con el píxel o pixmap de fondo de la ventana. El modo de subventana es efectivamente ClipByChildren. Si el ancho es cero, se reemplaza con el ancho actual de la ventana menos x. Si el alto es cero, se reemplaza con el alto actual de la ventana menos y. Si la ventana tiene una baldosa de fondo definida, el rectángulo recortado por cualquier hijo se rellena con esta baldosa. Si la ventana tiene fondo None, el contenido de la ventana no cambia. En cualquier caso, si exposures es True, se generan uno o más eventos Expose para las regiones del rectángulo que son visibles o se están conservando en una tienda de respaldo. Si especifica una ventana cuya clase es InputOnly, se produce un error BadMatch.

XClearArea puede generar errores BadMatch, BadValue y BadWindow.

La función XClearWindow borra toda el área en la ventana especificada y es equivalente a XClearArea (display, w, 0, 0, 0, 0, False). Si la ventana tiene una baldosa de fondo definida, el rectángulo se baldosará con una máscara de plano de todos los unos y la función GXcopy. Si la ventana tiene fondo None, el contenido de la ventana no cambia. Si especifica una ventana cuya clase es InputOnly, se produce un error BadMatch.

XClearWindow puede generar errores BadMatch y BadWindow.

DIAGNÓSTICOS

BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
