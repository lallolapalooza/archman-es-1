NOMBRE

XcupGetReservedColormapEntries - lista las entradas de mapa de colores reservadas por el sistema

SINOPSIS

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/Xcup.h>
Status XcupGetReservedColormapEntries(Display *display,
int screen, XColor **colors_out, int *ncolors);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen
Número de pantalla en el servidor host.
colors_out
Devuelve los valores reservados por el servidor.
ncolors
Devuelve el número de elementos en colors_out.

DESCRIPCIÓN

La función XcupGetReservedColormapEntries devuelve una lista de entradas de mapa de colores (píxeles) que están reservadas por el sistema. Esta lista contendrá, como mínimo, entradas para BlackPixel y WhitePixel de la pantalla especificada. Utilice XFree para liberar colors_out.

Para minimizar el parpadeo del mapa de colores, una aplicación que instala su propio mapa de colores privado debe consultar los colores especiales llamando a XCupGetReservedColormapEntries y luego puede almacenar esas entradas (en la ubicación correcta) en su mapa de colores privado usando XCupStoreColors.
