NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior se encuentra el código que puede cargar imágenes de cursores desde archivos. Por encima de eso, hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores ya sea a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes de cursor del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de bloques. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenidos
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imagen tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma de cursor, p. ej., como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Nombre” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede enumerar más de un nombre-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* array de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* recuento de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las st
dio funciones en el valor de retorno y valores esperados de los argumentos; las funciones de lectura y escritura intercambian los argumentos para que coincidan con las versiones POSIX. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lectura de imágenes de biblioteca

const char 	*name,

	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del *tamaño* deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si *theme* no es NULL, úsalo.
  • Si *theme* es NULL, o si no hubo coincidencia para el tema deseado, usa "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar *name* con el resultado.

NAME


XcursorFilenameLoadCursors, XcursorFilenameLoadImage


load cursors from disk






SYNOPSIS


#include <Xcursor.h>


XcursorCursors
    *XcursorFilenameLoadCursors(const char *filename);


XcursorImages
    *XcursorFilenameLoadImage(const char *filename);






DESCRIPTION


The function XcursorFilenameLoadCursors loads a set of
    cursor images from the specified filename. The file format is
    expected to be the Xcursor file format.


The function XcursorFilenameLoadImage is similar, but loads
    a single cursor image instead of a set of cursors.


The Xcursor file format is a simple binary format. It consists of
    a header followed by a sequence of images. The header contains information
    about the number of images in the file, the size of the images, and the
    hotspot for each image. Each image is stored as a series of ARGB pixels.


The file format is described in detail in the Xcursor specification,
    which can be found at
    https://www.x.org/releases/X11R7.7/doc/libXcursor/Xcursor.html.






FUNCTIONAL OVERVIEW


The Xcursor library provides functions for loading, creating, and
    manipulating cursor images. The library supports the Xcursor file format, as
    well as the XBM and XPM file formats.


The library also provides functions for setting the cursor for a
    window, and for changing the cursor theme. The cursor theme is a set of
    cursor images that are used by the window manager to display cursors.






DATATYPES


The following datatypes are defined by the Xcursor library:



  
XcursorCursors

  
Represents a set of cursor images. This structure contains an array of
      XcursorImage structures, as well as information
      about the size and hotspot of each cursor.

  
XcursorImage

  
Represents a single cursor image. This structure contains information about
      the width, height, hotspot, and pixel data of the cursor.

  
XcursorImages

  
Represents a list of cursor images. This structure is similar to
      XcursorCursors, but it contains a list of
      XcursorImage structures instead of an array.

Enables or disables themes for core cursors.

  
XcursorGetTheme

  
Gets the name of the current cursor theme.

  
XcursorGetDefaultTheme

  
Gets the name of the default cursor theme.

  
XcursorGetThemeName

  
Gets the name of the current cursor theme.

  
XcursorGetDefaultThemeName

  
Gets the name of the default cursor theme.








ENVIRONMENT



  
Xcursor.theme

  
Specifies the cursor theme to be used. If this resource is not set, the
      default theme will be used.

  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.
