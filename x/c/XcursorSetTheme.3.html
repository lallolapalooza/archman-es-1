NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o desde memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor se construye en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores ya sea a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas de archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y usa la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar varios cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los usen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imágenes tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor sigue (en su mayor parte) la especificación de freedesktop.org para los iconos temáticos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio con el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio "cursors".
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio "cursors", Xcursor busca a continuación un archivo "index.theme" en cada directorio de tema para buscar temas heredados. Esas son líneas con este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo "index.theme" dado. Si encuentra un tema heredado, Xcursor también busca en la ruta para usarlo. Xcursor ignora otras claves en el archivo "index.theme", incluido "Name" (es decir, el nombre que una aplicación gráfica puede usar como *nombre de presentación*).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor comprueba el tema "predeterminado".

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
almacena una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a píxeles */
} XcursorImage;
XcursorImages
almacena múltiples estructuras XcursorImage. Todas se liberan cuando se liberan las XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Almacena múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Tienen conteo de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera la XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio.
ns en el valor de retorno y los valores esperados de los argumentos; las funciones de lectura y escritura invierten los argumentos para que coincidan con las versiones POSIX. 


typedef struct _XcursorFile {
    void *closure;

	const char 	*name,

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úselo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, use "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

DESCRIPTION


The Xcursor library provides APIs for loading and managing X cursor
    images, supporting features like themes, animated cursors, and ARGB
    cursors.




Cursor   Data Structures


The library uses several data structures to represent cursor data:



  
XcursorImage

  
Represents a single cursor image, including its dimensions, hotspot, and
      pixel data (either in X standard 32-bit BGRA format, or X core
      monochromatic format).

  
XcursorImages

  
A collection of XcursorImage structures, typically representing all the
      images associated with a single cursor name (e.g., "left_ptr"). It also
      stores the nominal size and name of the cursor.

  
XcursorComments

  
A collection of XcursorComment structures, used for storing metadata about
      cursors.

  
XcursorComment

  
Represents a single comment string associated with a cursor.

  
XcursorAnimate

  
A structure to manage a sequence of cursors for animated cursor display.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for
    “t”, “1”, “y” or
    “on”

  

  
false for
    “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.

NAME

    
XcursorSetTheme, XcursorGetTheme, XcursorSetThemeDottedPairs, XcursorSetThemeCore, XcursorGetDefaultTheme — set cursor theme





    
SYNOPSIS

    
#include <Xcursor/Xcursor.h>

    
Bool XcursorSetTheme (Display *dpy, const char *theme_name);

    
const char* XcursorGetTheme (Display *dpy);

    
void XcursorSetThemeDottedPairs (Display *dpy, const char *theme_name);

    
void XcursorSetThemeCore (Display *dpy, const char *theme_name);

    
const char* XcursorGetDefaultTheme (void);





    
DESCRIPTION

    
These functions set or get the cursor theme to be used by the
        Xcursor library. A cursor theme is a collection of cursors, usually in
        PNG or XPM format, specified by a name. When an application needs a
        cursor, it asks the Xcursor library for a cursor of a specific size and
        type. Xcursor tries to find a matching cursor in the currently set theme.

    
If no theme is set, or if the requested cursor is not found
        in the current theme, Xcursor tries to find a cursor in the default
        theme (usually named "default" or "core").

    
Themes are looked up in directories specified by the
        XCURSOR_PATH environment variable, or in standard system
        locations like $XCURSOR_CONFIG_PATH/cursors and
        /usr/share/icons/cursors.

    
The specification for icon themes, which cursor themes
        follow, can be found at https://specifications.freedesktop.org/icon-theme-spec/.





    
FUNCTIONAL OVERVIEW

    

        
XcursorSetTheme

        
Sets the cursor theme for the given display. If theme_name
            is NULL, the default theme is used. This function
            returns True if the theme was successfully set, and
            False otherwise.

        
XcursorGetTheme

        
Returns the name of the currently set cursor theme for the given
            display, or NULL if no theme is explicitly set (meaning
            the default theme is in use). The returned string is owned by the
            library and should not be freed.

        
XcursorSetThemeDottedPairs

        
This function is similar to XcursorSetTheme, but it allows
            specifying a list of themes separated by colons (e.g., "MyTheme:Default").
            Xcursor will try to load cursors from the first theme in the list,
            and if not found, it will try the next one, and so on. This is
            useful for creating fallback themes.

        
XcursorSetThemeCore

        
This function is intended for setting the "core" theme, which is
            typically used as a fallback when no other theme is found. It might
            be influenced by the Xcursor.theme_core resource or the
            XCURSOR_THEME_CORE environment variable.

        
XcursorGetDefaultTheme

        
Returns the name of the system's default cursor theme. This is often
            "default" or "core" and is used when no other theme is specified.

    





    
DATATYPES

    
None.





    
FUNCTIONS

    
See DESCRIPTION.





    
ENVIRONMENT

    

        
XCURSOR_THEME

        
Sets the default cursor theme name. This is equivalent to setting the
            Xcursor.theme X resource.

        
XCURSOR_THEME_CORE

        
Sets the core cursor theme name. This is equivalent to setting the
            Xcursor.theme_core X resource.

        
XCURSOR_CONFIG_PATH

        
Specifies a path for cursor theme configuration files. This is a
            colon-separated list of directories.

    

    
If the environment variable XCURSOR_THEME is set to
        true, the library enables themes for core cursors.

    
If the environment variable is not given, Xcursor tries the
        Xcursor.theme_core resource.

    
An application can enable or disable themes using
        XcursorSetThemeCore.

        attempts will be made to retain some level of source-file compatibility.
