NOMBRE

XChangeKeyboardControl, XGetKeyboardControl, XAutoRepeatOn, XAutoRepeatOff, XBell, XQueryKeymap, XKeyboardControl - manipular la configuración del teclado y la estructura de control del teclado

SINTAXIS

int XChangeKeyboardControl(Display *display, unsigned long value_mask, XKeyboardControl *values);

int XGetKeyboardControl(Display *display, XKeyboardState *values_return);

int XAutoRepeatOn(Display *display);

int XAutoRepeatOff(Display *display);

int XBell(Display *display, int percent);

int XQueryKeymap(Display *display, char keys_return[32]);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
keys_return
Devuelve un array de bytes que identifica qué teclas están presionadas. Cada bit representa una tecla del teclado.
percent
Especifica el volumen de la campana, que puede variar entre -100 y 100 inclusive.
value_mask
Especifica qué controles cambiar. Esta máscara es la OR inclusiva a nivel de bits de los bits de control válidos.
values
Especifica un valor por cada bit establecido a 1 en la máscara.
values_return
Devuelve los valores de control actuales del teclado en la estructura XKeyboardState especificada.

DESCRIPCIÓN

La función XChangeKeyboardControl controla las características del teclado definidas por la estructura XKeyboardControl. El argumento value_mask especifica qué valores se van a cambiar.

XChangeKeyboardControl puede generar errores BadMatch y BadValue.

La función XGetKeyboardControl devuelve los valores de control actuales del teclado a la estructura XKeyboardState.

La función XAutoRepeatOn activa la repetición automática del teclado en la pantalla especificada.

La función XAutoRepeatOff desactiva la repetición automática del teclado en la pantalla especificada.

La función XBell hace sonar la campana del teclado en la pantalla especificada, si es posible. El volumen especificado es relativo al volumen base del teclado. Si el valor del argumento percent no está en el rango de -100 a 100 inclusive, se produce un error BadValue. El volumen al que suena la campana cuando el argumento percent es no negativo es:

base - [(base * percent) / 100] + percent

El volumen al que suena la campana cuando el argumento percent es negativo es:

base + [(base * percent) / 100]

Para cambiar el volumen base de la campana, utilice XChangeKeyboardControl.

XBell puede generar un error BadValue.

La función XQueryKeymap devuelve un vector de bits para el estado lógico del teclado, donde cada bit establecido a 1 indica que la tecla correspondiente está actualmente presionada. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits de las teclas 8N a 8N + 7, siendo el bit menos significativo del byte el que representa la tecla 8N.

Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente) puede retrasarse respecto al estado físico si el procesamiento de eventos del dispositivo está congelado.

ESTRUCTURAS

La estructura XKeyboardControl contiene:

/* Máscaras de bits para ChangeKeyboardControl */

#define KBKeyClickPercent (1L<<0)
#define KBBellPercent (1L<<1)
#define KBBellPitch (1L<<2)
#define KBBellDuration (1L<<3)
#define KBLed (1L<<4)
#define KBLedMode (1L<<5)
#define KBKey (1L<<6)
#define KBAutoRepeatMode (1L<<7) 
/* Valores */
typedef struct {
        int key_click_percent;
        int bell_percent;
        int bell_pitch;
        int bell_duration;
        int led;
        int led_mode;   /* LedModeOn, LedModeOff */
        int key;
        int auto_repeat_mode;   /* AutoRepeatModeOff, AutoRepeatModeOn,
                                AutoRepeatModeDefault */
} XKeyboardControl;

El miembro key_click_percent establece el volumen de los clics de tecla entre 0 (apagado) y 100 (alto) inclusive, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

El miembro bell_percent establece el volumen base de la campana entre 0 (apagado) y 100 (alto) inclusive, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_pitch establece el tono (especificado en Hz) de la campana, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_duration establece la duración de la campana especificada en milisegundos, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

Si se especifican tanto led_mode como led, se cambia el estado de ese LED, si es posible. El miembro led_mode se puede establecer en LedModeOn o LedModeOff. Si solo se especifica led_mode, se cambia el estado de todos los LEDs, si es posible. Se admiten como máximo 32 LEDs numerados a partir de uno. No se define ninguna interpretación estándar de los LEDs. Si se especifica led sin led_mode, se produce un error BadMatch.

Si se especifican tanto auto_repeat_mode como key, se cambia el auto_repeat_mode de esa tecla (según AutoRepeatModeOn, AutoRepeatModeOff, o AutoRepeatModeDefault), si es posible. Si solo se especifica auto_repeat_mode, se cambia el auto_repeat_mode global para todo el teclado, si es posible, y no afecta a la configuración por tecla. Si se especifica una tecla sin auto_repeat_mode, se produce un error BadMatch. Cada tecla tiene un modo individual de si debe repetirse o no y una configuración predeterminada para el modo. Además, existe un modo global de si la repetición automática debe estar activada o no y una configuración predeterminada para ese modo. Cuando el modo global es AutoRepeatModeOn, las teclas deben obedecer sus modos de repetición automática individuales. Cuando el modo global es AutoRepeatModeOff, ninguna tecla debe repetirse automáticamente. Una tecla que se repite automáticamente genera eventos alternos KeyPress y KeyRelease. Cuando una tecla se utiliza como modificador, es deseable que la tecla no se repita automáticamente, independientemente de su configuración de repetición automática.

La estructura XKeyboardState contiene:

typedef struct {
        int key_click_percent;
        int bell_percent;
        unsigned int bell_pitch, bell_duration;
        unsigned long led_mask;
        int global_auto_repeat;
        char auto_repeats[32];
} XKeyboardState;

Para los LEDs, el bit menos significativo de led_mask corresponde al LED uno, y cada bit establecido a 1 en led_mask indica un LED que está encendido. El miembro global_auto_repeat se puede establecer en AutoRepeatModeOn o AutoRepeatModeOff. El miembro auto_repeats es un vector de bits. Cada bit establecido a 1 indica que la repetición automática está habilitada para la tecla correspondiente. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits de las teclas 8N a 8N + 7, siendo el bit menos significativo del byte el que representa la tecla 8N.

NAME

XChangeKeyboardControl, XGetKeyboardControl, XKeyboardControl — modify and query keyboard attributes

SYNTAX

#include <X11/Xlib.h>
#include <X11/Xutil.h>
#include <X11/keysym.h>

int XChangeKeyboardControl(
    Display *display,
    unsigned long value_mask,
    XKeyboardControl *values
);

int XGetKeyboardControl(
    Display *display,
    XKeyboardControl *control_return
);

typedef struct {
    int key_click_percent;
    int bell_percent;
    int mode;
    unsigned int num_groups;
    int scroll_speed_multiply;
    int scroll_speed_divisor;
    int auto_repeat_mode;
    unsigned int led_mode;
    int led_value;
    unsigned int global_auto_repeat;
    XID led_class;
    XID led_curve;
} XKeyboardControl;

ARGUMENTS

display
Specifies the connection to the X server.
value_mask
Specifies which of the fields in the `values’ structure are valid. This mask is the bitwise OR of any of the following values:

KBKeyClickPercent, KBBellPercent, KBMode, KBGroupNumber, KBScrollSpeedMultiply, KBScrollSpeedDivisor, KBAutoRepeatMode, KBLEDMode, KBLEDValue, KBGlobalAutoRepeat, KBLEDClass, KBLEDCurve.

The following values are defined:

KBKeyClickPercent
Controls the volume of the key-click audio.
KBBellPercent
Controls the volume of the bell.
KBMode
Sets the internal mode of the keyboard.
KBGroupNumber
Sets the current group for the keyboard.
KBScrollSpeedMultiply
Sets the scroll speed multiply factor.
KBScrollSpeedDivisor
Sets the scroll speed divisor.
KBAutoRepeatMode
Controls the auto-repeat mode of the keyboard.
KBLEDMode
Controls the mode of the keyboard LEDs.
KBLEDValue
Controls the values of the keyboard LEDs.
KBGlobalAutoRepeat
Controls the global auto-repeat state of the keyboard.
KBLEDClass
Controls the LED class.
KBLEDCurve
Controls the LED curve.
values
Contains the XKeyboardControl structure, which specifies the keyboard attributes to be changed.
control_return
Returns the current keyboard attributes.

DESCRIPTION

The XChangeKeyboardControl function modifies the keyboard attributes specified by the `value_mask’.

The XGetKeyboardControl function retrieves the current keyboard attributes.

The XKeyboardControl structure contains the following members:

key_click_percent
Specifies the key click volume (0 to 100).
bell_percent
Specifies the bell volume (0 to 100).
mode
Specifies the internal mode of the keyboard. Valid values are Explicit and SemiExplicit.
num_groups
Specifies the number of groups for the keyboard.
scroll_speed_multiply
Specifies the scroll speed multiply factor.
scroll_speed_divisor
Specifies the scroll speed divisor.
auto_repeat_mode
Specifies the auto-repeat mode. Valid values are AutoRepeatModeOn, AutoRepeatModeOff, and AutoRepeatModeDefault.
led_mode
Specifies the LED mode. Valid values are LedModeOn and LedModeOff.
led_value
Specifies the values of the keyboard LEDs.
global_auto_repeat
Specifies the global auto-repeat state. Valid values are AutoRepeatModeOn and AutoRepeatModeOff.
led_class
Specifies the LED class.
led_curve
Specifies the LED curve.

STRUCTURES

The XKeyboardControl structure is defined as shown in SYNTAX.

DIAGNOSTICS

If the keyboard control cannot be changed, XChangeKeyboardControl returns BadValue. This can occur if an invalid value is provided for any of the parameters.

Other errors that may be generated by XChangeKeyboardControl include BadAlloc, BadValue, and BadMatch.
