Paquete: libx11

XCirculateRequestEvent(3) FUNCIONES DE XLIB XCirculateRequestEvent(3)

NOMBRE

XCirculateRequestEvent - estructura del evento CirculateRequest

ESTRUCTURAS

La estructura para los eventos CirculateRequest contiene:

typedef struct {
        int type;       /* CirculateRequest */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* verdadero si esto provino de una solicitud SendEvent */
        Display *display;       /* Display desde el que se leyó el evento */
        Window parent;
        Window window;
        int place;      /* PlaceOnTop, PlaceOnBottom */
} XCirculateRequestEvent;

Cuando recibe este evento, los miembros de la estructura se configuran de la siguiente manera.

El miembro de tipo se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro de tipo establecido en GraphicsExpose. El miembro de visualización se establece en un puntero a la visualización en la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero expandido de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

El miembro parent se establece en la ventana padre. El miembro window se establece en la subventana que se va a reorganizar. El miembro place se establece en la nueva posición en el orden de apilamiento y es PlaceOnTop o PlaceOnBottom. Si es PlaceOnTop, la subventana debe estar encima de todos los hermanos. Si es PlaceOnBottom, la subventana debe estar debajo de todos los hermanos.
