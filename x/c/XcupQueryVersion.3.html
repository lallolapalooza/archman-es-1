XcupQueryVersion(3) Funciones X XcupQueryVersion(3)

NOMBRE

XcupQueryVersion - Devuelve la versión del protocolo TOG-CUP soportada por el servidor X

SINOPSIS

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/Xcup.h>
Status XcupQueryVersion(Display *display,
int *major_version_return, int *minor_version_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X
major_version_return
Devuelve la versión principal soportada por el servidor
minor_version_return
Devuelve la versión menor soportada por el servidor

DESCRIPCIÓN

XcupQueryVersion establece major_version_return y minor_version_return a la versión principal y menor del protocolo TOG-CUP soportada por el servidor. Si la biblioteca TOG-CUP es compatible con la versión devuelta por el servidor, devuelve un valor distinto de cero. Si el servidor no soporta la extensión TOG-CUP, o si hubo un error durante la comunicación con el servidor, o si las versiones del protocolo del servidor y la biblioteca son incompatibles, devuelve cero. No se pueden llamar otras funciones Xcup antes que esta función. Si un cliente viola esta regla, los efectos de todas las llamadas subsiguientes a Xcup que realice no están definidos.

Para obtener la lista de entradas de mapa de colores reservadas, use XcupGetReservedColormapEntries.

Para asignar una o más celdas de color de solo lectura con valores RGB, use XcupStoreColors.

VER TAMBIÉN

XcupGetReservedColormapEntries(3Xext), XcupStoreColors(3Xext),
Colormap Utilization Policy and Extension
