NOMBRE

Xcursor - Librería de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una librería simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una librería de cursores comunes que se mapean a los nombres de cursor estándar de X. Los cursores pueden existir en varios tamaños y la librería elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construida en un par de capas; en la capa inferior está el código que puede cargar imágenes de cursor desde archivos. Por encima hay una capa que localiza archivos de cursor basándose en la ruta de la librería y el tema. En la parte superior hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es soportada por el servidor X. Donde no es soportada, Xcursor mapea la imagen del cursor a un cursor X estándar y usa la solicitud CreateCursor principal.

ARCHIVOS DE CURSOR

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar varios cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los usen como una secuencia animada.

Los archivos de cursor se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de bloques. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo tiene el siguiente aspecto:


mágic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición de byte absoluta de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en TOC para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en TOC para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para los archivos de cursor; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imagen tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (principalmente) sigue la especificación de freedesktop.org para los temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas con el siguiente formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor verifica el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* x del punto activo (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* y del punto activo (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* array de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se usa ese.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, se usa "default" como nombre de tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

ENTORNO


Las variables de entorno se pueden usar para anular la configuración
    de recursos, que a su vez anula los valores predeterminados compilados.


Algunas de las variables de entorno reconocidas por Xcursor son
    booleanas, especificadas de la siguiente manera:





  
verdadero para
    “t”, “1”, “y” o
    “on”

  

  
falso para
    “f”, “0”, “n” o
    “off”

  






Xcursor ignora otros valores para estos booleanos.



  
HOME

  
Xcursor interpreta “~” en la lista de búsqueda como el directorio
      principal, utilizando esta variable en lugar de la base de datos de
      contraseñas.

  
XCURSOR_ANIM

  
Si la pantalla admite la solicitud Render CreateCursor y la función Render
      está habilitada, deshabilita los cursores animados si la variable de
      entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.anim.





  
XCURSOR_CORE

  
Si la pantalla admite la solicitud Render CreateCursor, deshabilita la
      función Render si la variable de entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.core.





  
XCURSOR_DISCOVER

  
Si la variable está establecida, Xcursor activa una función de registro.
      Muestra el valor hash y la imagen para que los usuarios puedan ver qué
      nombre de cursor está asociado con cada imagen.





  

  
No hay una configuración de recurso correspondiente.





  
XCURSOR_DITHER

  
Esta variable establece el dithering deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.dither.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza
      “threshold”.

  

  
Estos son los valores reconocidos:







  
difuso

  

  
mediana

  

  
ordenado

  

  
umbral

  







  
XCURSOR_PATH

  
Esta variable establece la lista de rutas en las que buscar cursores, en
      lugar de la lista predeterminada compilada.





  

  
Los directorios en esta ruta están separados por dos puntos (:).





  
XCURSOR_RESIZED

  
Habilita el redimensionamiento automático de cursores para mejorar su
      tamaño mostrado si la variable de entorno es true.





  

  
Si no se proporciona la variable de entorno, Xcursor intenta el recurso
      Xcursor.resized.





  
XCURSOR_SIZE

  
Esta variable establece el tamaño de cursor deseado, en píxeles.





  

  
Si no se proporciona la variable de entorno, Xcursor intenta el recurso
      Xcursor.size.

  

  
Si no se proporciona ningún tamaño, ya sea por variable de entorno o por
      configuración de recurso, Xcursor intenta a continuación la configuración
      del recurso Xft.dpi para adivinar el tamaño de un cursor de 16
      puntos.

  

  
Finalmente, si Xft.dpi no está establecido, Xcursor usa la altura
      de la pantalla, dividiendo por 48 (asumiendo que la altura es 768).





  
XCURSOR_THEME

  
Esta variable selecciona el tema deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor intenta el recurso
      Xcursor.theme.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza
      el tema predeterminado.

DESCRIPTION

                    
The Xcursor library provides functions for loading,
                        manipulating, and displaying cursors, using the standard Xcursor
                        file format, as well as other cursor formats.

                    
An XcursorImage is a structure
                        containing cursor data. It has fields for width, height, X and Y
                        hotspots, and two arrays for the ARGB color data and the mask
                        data.

                    
typedef struct {
    unsigned int width, height;
    unsigned int xhot, yhot;
    unsigned char *rgba; /* ARGB pixel data */
    unsigned char *mask; /* Monochrome mask data */
    unsigned int size; /* Size of rgba and mask in bytes */
    unsigned int version;
} XcursorImage;
                    

                    
An XcursorIcon is a structure
                        containing a list of XcursorImages, a
                        name, and a size.

                    
typedef struct {
    char *name;
    int size;
    XcursorImage **images;
    int nimages;
} XcursorIcon;
                    

                    
An Xcursor is a structure
                        used to manage cursors. It is created with XcursorCreate
                        and destroyed with XcursorDestroy.

                

                

                    
FUNCTIONAL OVERVIEW

                    
XcursorImageCreate allocates
                        and returns a new XcursorImage structure
                        with the specified width and height. The pixel data is not
                        initialized.

                    
XcursorImageCreateFromData
                        allocates and returns a new XcursorImage
                        structure using the provided pixel data. The data
                        pointer points to the ARGB pixel data and the mask
                        pointer points to the monochrome mask data. Both arrays must be of
                        size width * height bytes.

                    
XcursorImageDestroy frees the
                        memory associated with the given XcursorImage.

                    
XcursorCreate allocates and
                        returns a new Xcursor structure associated
                        with the given display. This structure is used to manage cursors
                        and their themes.

                    
XcursorCreateFromData creates a
                        cursor from raw ARGB and mask data, similar to
                        XcursorImageCreateFromData but directly
                        associating it with a display.

                    
XcursorDestroy frees the memory
                        associated with the given Xcursor structure.

                    
XcursorFillImage fills in the
                        rgba and mask members
                        of an XcursorImage structure with default
                        values. The default values are a fully transparent black cursor.

                    
XcursorCreateResized creates a
                        new XcursorImage by resizing the given
                        XcursorImage to the specified dimensions.

                    
XcursorGetImage retrieves a
                        cursor image matching the given name, shape, and function. The
                        Xcursor structure is used to manage the theme
                        lookup. If the requested cursor is not found in the current theme,
                        the default theme is tried.

                    
XcursorGetImageFromFile retrieves
                        a cursor image from a file. This function is useful for loading
                        custom cursor formats or cursors not part of a theme.

                    
XcursorGetIcon is similar to
                        XcursorGetImage but retrieves an
                        XcursorIcon structure, which may contain
                        multiple XcursorImages of different sizes.

                    
XcursorGetIconFromFile is similar
                        to XcursorGetImageFromFile but retrieves an
                        XcursorIcon structure.

                    
XcursorSetTheme sets the cursor
                        theme for the given display. The theme name should correspond to a
                        directory in the standard theme search path. Returns True
                        on success, False otherwise.

                    
XcursorGetTheme returns the name
                        of the currently active cursor theme for the display.

                    
XcursorGetDefaultTheme returns the
                        name of the default cursor theme. This is usually determined by
                        system configuration or the Xcursor.theme
                        resource.

                    
XcursorSetDefaultTheme sets the
                        default cursor theme for the display. This change takes effect for
                        subsequently loaded cursors.

                    
XcursorGetThemeCore returns True
                        if core cursor themes are enabled, False
                        otherwise.

                    
XcursorSetThemeCore enables or
                        disables the use of core cursor themes. Core themes are standard
                        cursors provided by the X server.

                

                

                    
DATATYPES

                    

                        
XcursorImage

                        
Structure representing a single cursor image, containing
                            dimensions, hotspot, RGBA pixel data, and mask data.

                        
XcursorIcon

                        
Structure representing a cursor icon, which can contain multiple
                            XcursorImages of different sizes, along
                            with its name.

                        
Xcursor

                        
Opaque structure used to manage cursor resources and theme
                            lookups.

                        
CursorFunction

                        
Enumeration defining cursor rendering behavior (e.g., normal,
                            left_ptr, wait).
