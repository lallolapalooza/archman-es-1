Paquete: libx11

XColormapEvent(3) FUNCIONES DE XLIB XColormapEvent(3)

NOMBRE

XColormapEvent - estructura del evento ColormapNotify

ESTRUCTURAS

La estructura para los eventos ColormapNotify contiene:

typedef struct {
        int type;       /* ColormapNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* verdadero si esto vino de una solicitud SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window window;
        Colormap colormap;      /* mapa de colores o None */
        Bool new;
        int state;      /* ColormapInstalled, ColormapUninstalled */
} XColormapEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro type se establece en la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa de un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero a la pantalla en la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero ampliado de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los distribuidores de toolkits.

El miembro window se establece en la ventana cuyo mapa de colores asociado se cambia, instala o desinstala. Para un mapa de colores que se cambia, se instala o se desinstala, el miembro colormap se establece en el mapa de colores asociado con la ventana. Para un mapa de colores que se cambia mediante una llamada a XFreeColormap, el miembro colormap se establece en None. El miembro new se establece para indicar si el mapa de colores de la ventana especificada se cambió, se instaló o se desinstaló, y puede ser True o False. Si es True, el mapa de colores se cambió. Si es False, el mapa de colores se instaló o se desinstaló. El miembro state siempre se establece para indicar si el mapa de colores está instalado o desinstalado y puede ser ColormapInstalled o ColormapUninstalled.
