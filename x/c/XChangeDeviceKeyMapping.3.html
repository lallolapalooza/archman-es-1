Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGETDEVICEKEYMAPPING(3)   XGETDEVICEKEYMAPPING(3)

NOMBRE

XGetDeviceKeyMapping, XChangeDeviceKeyMapping - consulta o cambia los mapeos de teclas del dispositivo

SINOPSIS

#include <X11/extensions/XInput.h>
KeySym *XGetDeviceKeyMapping( Display *display,
                              XDevice *device,
                              KeyCode first_keycode,
                              int keycode_count,
                              int *keysyms_per_keycode_return);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyo mapeo de teclas se va a
       consultar o modificar.
first_keycode
       Especifica el primer KeyCode que se va a devolver.
keycode_count
       Especifica el número de KeyCodes que se van a devolver o
       modificar.
keysyms_per_keycode
       Especifica el número de KeySyms por KeyCode.
keysyms_per_keycode_return
       Especifica la dirección de una variable en la que se
       devolverá el número de KeySyms por KeyCode.
keysyms
       Especifica la dirección de una matriz de KeySyms.

DESCRIPCIÓN

Para el dispositivo especificado, la solicitud XGetDeviceKeyMapping
devuelve los símbolos para el número especificado de KeyCodes
comenzando con first_keycode. El valor especificado en
first_keycode debe ser mayor o igual que min_keycode según lo
devuelto por XListInputDevices, o se producirá un error BadValue.
Además, la siguiente expresión debe ser menor o igual que
max_keycode según lo devuelto por XListInputDevices:
first_keycode + keycode_count - 1
Si no es así, se producirá un error BadValue. El número de
elementos en la lista KeySyms es:
keycode_count * keysyms_per_keycode_return
El número de KeySym N, contando desde cero, para el KeyCode K
tiene el siguiente índice en la lista, contando desde cero: (K -
first_code) * keysyms_per_code_return + N
El servidor X elige arbitrariamente el valor
keysyms_per_keycode_return para que sea lo suficientemente grande
como para informar todos los símbolos solicitados. Un valor especial
de KeySym, NoSymbol, se utiliza para completar los elementos no
utilizados para KeyCodes individuales. Para liberar el
almacenamiento devuelto por XGetDeviceKeyMapping, usa XFree.
Si el dispositivo especificado no admite teclas de clase de
entrada, se producirá un error BadMatch.
XGetDeviceKeyMapping puede generar un error BadDevice, BadMatch o
BadValue.
Para el dispositivo especificado, la solicitud
XChangeDeviceKeyMapping define los símbolos para el número
especificado de KeyCodes comenzando con first_keycode. Los
símbolos para KeyCodes fuera de este rango permanecen sin
cambiar. El número de elementos en keysyms debe ser:
num_codes * keysyms_per_keycode
El first_keycode especificado debe ser mayor o igual que
min_keycode devuelto por XListInputDevices, o se producirá un
error BadValue. Además, la siguiente expresión debe ser menor o
igual que max_keycode según lo devuelto por XListInputDevices, o
se producirá un error BadValue:
first_keycode + num_codes - 1
El número de KeySym N, contando desde cero, para el KeyCode K
tiene el siguiente índice en keysyms, contando desde cero:
(K - first_keycode) * keysyms_per_keycode + N
El keysyms_per_keycode especificado puede ser elegido
arbitrariamente por el cliente para que sea lo suficientemente
grande como para contener todos los símbolos deseados. Se debe
utilizar un valor especial de KeySym, NoSymbol, para completar
los elementos no utilizados para KeyCodes individuales. Es legal
que NoSymbol aparezca en posiciones no finales de la lista
efectiva para un KeyCode. XChangeDeviceKeyMapping genera un
evento DeviceMappingNotify que se envía a todos los clientes que
han seleccionado ese tipo de evento.
No hay ningún requisito de que el servidor X interprete este
mapeo. Simplemente se almacena para que los clientes lo lean y
escriban.
Si el dispositivo especificado no admite teclas de clase de
entrada, se producirá un error BadMatch.
XChangeDeviceKeyMapping puede generar un error BadDevice,
BadMatch, BadAlloc o BadValue.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo
       especificado no existe o no ha sido abierto por este
       cliente a través de XOpenInputDevice. Este error también
       puede ocurrir si el dispositivo especificado es el teclado X
       o el dispositivo puntero X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud
       XGetDeviceKeyMapping o XChangeDeviceKeyMapping especificando
       un dispositivo que no tiene teclas.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un
       rango específico para un argumento, se acepta el rango
       completo definido por el tipo del argumento. Cualquier
       argumento definido como un conjunto de alternativas puede
       generar este error.
BadAlloc
       El servidor no pudo asignar el recurso solicitado o memoria
       del servidor.
