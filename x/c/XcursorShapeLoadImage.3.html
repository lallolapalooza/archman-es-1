NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursor estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor se construye en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursor desde archivos. Por encima de eso, hay una capa que localiza archivos de cursor basándose en la ruta de la biblioteca y el tema. En la parte superior, hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud `CreateCursor` de la extensión Render si es soportada por el servidor X. Donde no es soportado, Xcursor mapea la imagen del cursor a un cursor estándar de X y usa la solicitud `CreateCursor` del núcleo.

ARCHIVOS DE CURSOR

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples cursores del mismo tamaño nominal; se espera que las aplicaciones las usen como una secuencia animada.

Los archivos de cursor se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de bloques (chunks). La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo tiene el siguiente aspecto:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas en la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido tiene el siguiente aspecto:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en la TOC para este bloque
subtype:	CARD32 debe coincidir con el subtipo en la TOC para este bloque
version:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloque definidos para los archivos de cursor; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


header:	20 Las cabeceras de comentario son de 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


header:	36 Las cabeceras de imagen son de 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual a la altura
delay:	CARD32 Retraso entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 píxeles en formato ARGB empaquetado

TEMAS

Xcursor (principalmente) sigue la especificación de freedesktop.org para los temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de *forma* del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra ningún archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas con el siguiente formato:
Inherits = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras *claves* en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como *nombre de presentación*).

Se puede listar más de un nombre-tema en la línea Inherits=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Inherits=; la especificación de freedesktop.org no es clara sobre si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor verifica el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* altura real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Referencia un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden referenciar el mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

NAME

Xcursor - cursor loading and management library

SYNOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPTION

The Xcursor library is used to load, manage, and display cursors. It supports standard X cursors, animated cursors, and cursors from Xcursor themes.

Cursor Loading APIs

XcursorImages * XcursorImagesCreate (
	int 	 width)

Allocate and initialize a new XcursorImages structure which will hold cursors of the given width.

void XcursorImagesDestroy (
	XcursorImages 	*images)

Deallocates the given XcursorImages structure as well as the XcursorImage structures which it points to.

XcursorBool XcursorImagesInc (
	XcursorImages 	*images)

Increment the reference count of the given images structure.

XcursorBool XcursorImagesLoadCursor (
	Display 	*dpy,
	XcursorImages 	*images)

Load the cursor images into the display.

XcursorImages * XcursorImagesLoadFromName (
	Display 	*dpy,
	const char 	*name)

Load a cursor image from the current theme with the given name.

XcursorImages * XcursorImagesLoadTheme (
	Display 	*dpy,
	const char 	*name)

Load a cursor image from the current theme with the given name.

XcursorImages * XcursorImagesLoadFile (
	Display 	*dpy,
	const char 	*file)

Load a cursor image from the given file.

XcursorImage * XcursorImagesTake (
	XcursorImages 	*images,
	int 	 width)

Take ownership of the XcursorImage with the given width from the images structure. The images structure will no longer hold a reference to this image.

XcursorBool XcursorImageSet (
	XcursorImages 	*images,
	int 	 width,
	XImage 	*image,
	XImage 	*mask,
	int 	 hot_x,
	int 	 hot_y)

Add the given image and mask to the images structure, associating it with the given width.

XcursorBool XcursorImageSetName (
	XcursorImages 	*images,
	int 	 width,
	const char 	*name)

Set the name of the image with the given width.

XcursorBool XcursorImageSetSerial (
	XcursorImages 	*images,
	int 	 width,
	unsigned long 	 serial)

Set the serial number of the image with the given width.

XcursorBool XcursorImageSetSize (
	XcursorImages 	*images,
	int 	 width,
	unsigned int 	 size)

Set the size of the image with the given width.

XcursorBool XcursorImageSetMaskSize (
	XcursorImages 	*images,
	int 	 width,
	unsigned int 	 size)

Set the size of the mask of the image with the given width.

Allocate and initialize a new XcursorCursors structure, which holds a list of cursors. If is_animated is true, the cursors will be treated as an animated sequence.

Deallocates the given XcursorCursors structure as well as the cursors it points to.

XcursorBool XcursorCursorsAdd (
	XcursorCursors 	*cursors,
	const char 	*name,
	int 	 hot_x,
	int 	 hot_y)

Add a cursor with the given name and hotspot to the XcursorCursors structure.

int XcursorCursorsSize (
	XcursorCursors 	*cursors)

Returns the number of cursors in the XcursorCursors structure.

int XcursorCursorsIndex (
	XcursorCursors 	*cursors)

Returns the index of the current cursor in the sequence. This index is used internally to keep track of the current frame in an animation. The initial value is -1, and it will be incremented each time XcursorAnimateNext is called. The value will wrap around when it reaches the end of the index. It is not intended to be set directly by the caller. This value indicates how many pointers will be in the index.

void XcursorCommentsDestroy (
	XcursorComments 	*comments)

Deallocates the given XcursorComments structure as well as the XcursorComment structures which it points to.

Animated Cursors

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Wrap the given array of cursors in a newly allocated XcursorAnimate structure, which adds a sequence number used in XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Discards the given animate data, freeing both the XcursorCursors array of cursors as well as the XcursorAnimate structure.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Cyclically returns the next Cursor in the array, incrementing the sequence number to prepare for the next call.

The caller is responsible for displaying the series of Cursor images. Xcursor does not do that.

ENVIRONMENT

Environment variables can be used to override resource settings, which in turn override compiled-in default values.

Some of the environment variables recognized by Xcursor are booleans, specified as follows:

true for “t”, “1”, “y” or “on”
false for “f”, “0”, “n” or “off”

Xcursor ignores other values for these booleans.

HOME
Xcursor interprets “~” in the search list as the home directory, using this variable rather than the password database.
XCURSOR_ANIM
If the display supports the Render CreateCursor request, and the Render feature is enabled, disable animated cursors if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.anim.
XCURSOR_CORE
If the display supports the Render CreateCursor request disable the Render feature if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.core.
XCURSOR_DISCOVER
If the variable is set, Xcursor turns on a logging feature. It displays the hash value and the image so that users can see which cursor name is associated with each image.
There is no corresponding resource setting.
XCURSOR_DITHER
This variable sets the desired dither.
If the environment variable is not given, Xcursor uses the resource Xcursor.dither.
If neither environment variable or resource is found, Xcursor uses “threshold”
These are the recognized values:
diffuse
median
ordered
threshold
XCURSOR_PATH
This variable sets the list of paths in which to search for cursors, rather than the compiled-in default list.
Directories in this path are separated by colons (:).
XCURSOR_RESIZED
Enables automatic resizing of cursors to improve their displayed size if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.resized resource.
XCURSOR_SIZE
This variable sets the desired cursor size, in pixels.
If the environment variable is not given, Xcursor tries the Xcursor.size resource.
If no size is given, whether by environment variable or resource setting, Xcursor next tries the Xft.dpi resource setting to guess the size of a 16-point cursor.
Finally, if Xft.dpi is not set, Xcursor uses the display height, dividing by 48 (assuming that the height is 768).
XCURSOR_THEME
This variable selects the desired theme.
If the environment variable is not given, Xcursor tries the Xcursor.theme resource.
If neither environment variable or resource is found, Xcursor uses the default theme.
XCURSOR_T XcursorShapeLoadImage 3

NAME

XcursorShapeLoadImage, XcursorFileLoadImage, XcursorFileLoadImages — load cursor images from files

SYNOPSIS

#include <Xcursor/Xcursor.h>

XcursorImages *XcursorFileLoadImage(const char *file);

XcursorImages *XcursorFileLoadImages(const char *file);

XcursorImages *XcursorShapeLoadImage(const char *file);

DESCRIPTION

The XcursorFileLoadImage function loads a cursor image from the given filename.

The XcursorFileLoadImages function loads one or more cursor images from the given filename. The filename is typically a cursor theme directory.

The XcursorShapeLoadImage function loads a single cursor image from the given filename. It expects the file to contain a single cursor shape. This function is generally used internally by XcursorFileLoadImage and XcursorFileLoadImages.

All three functions return a pointer to a XcursorImages structure which contains the loaded cursor images, or NULL if an error occurred.

The returned XcursorImages structure should be freed with XcursorImagesDestroy.
