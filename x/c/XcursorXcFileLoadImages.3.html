NOMBRE

Xcursor — Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que crea cursores a partir de una imagen cargada desde un archivo o uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no sea compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor se etiqueta con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos (chunks). La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas en la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición absoluta en bytes del archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtype:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


header:	20 Las cabeceras de comentarios tienen 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


header:	36 Las cabeceras de imágenes tienen 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual a width
yhot:	CARD32 Debe ser menor o igual a height
delay:	CARD32 Retraso entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor (principalmente) sigue la especificación de freedesktop.org para tematizar iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma (shape) del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra ningún archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Herencia = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Herencia=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Herencia=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor verifica el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* arreglo de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* arreglo de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y a una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

XcursorBool XcursorGetThemeCore (
	Display 	*dpy)

Devuelve cierto si el tema está habilitado para cursores centrales.

XcursorBool XcursorSetThemeCore (
	Display 	*dpy,
	XcursorBool 	 theme_core)

Establece el estado de temas para cursores centrales.

Comments

XcursorComments * XcursorCommentsCreate (
	const char 	*filename)

Lee todos los comentarios de un archivo de cursor.

XcursorComment * XcursorCommentsNext (
	XcursorComments 	*comments)

Devuelve el siguiente comentario en la estructura XcursorComments. El valor de retorno es un puntero a la estructura XcursorComment que contiene el comentario. Devuelve NULL si no hay más comentarios. El número de punteros en el índice será el número de comentarios en la estructura XcursorComments.

void XcursorCommentsDestroy (
	XcursorComments 	*comments)

Desasigna la estructura XcursorComments dada, así como las estructuras XcursorComment a las que apunta.

Animated Cursors

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Envuelve la matriz dada de cursores en una estructura XcursorAnimate recién asignada, que agrega un número de secuencia utilizado en XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Descarta los datos de animate dados, liberando tanto la matriz de cursores XcursorCursors como la estructura XcursorAnimate.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Devuelve cíclicamente el siguiente Cursor en la matriz, incrementando el número de secuencia para prepararse para la siguiente llamada.

El llamador es responsable de mostrar la serie de imágenes de Cursor. Xcursor no hace eso.

Glyph Cursor APIs

Las funciones X11 XCreateFontCursor y XCreateGlyphCursor utilizan esta parte de la API para extender la función de cursores centrales de X para usar temas.

void XcursorImageHash (
	XImage 	*image,
	unsigned char 	 hash[XCURSOR_BITMAP_HASH_SIZE])

Calcula un hash de la imagen, para mostrar cuando la variable de entorno XCURSOR_DISCOVER esté configurada.

void XcursorImagesSetName (
	XcursorImages 	*images,
	const char 	*name)

Asocia el nombre dado con las imágenes.

void XcursorNoticeCreateBitmap (
	Display 	*dpy,
	Pixmap 	 pid,
	unsigned int 	 width,
	unsigned int 	 height)

Comprueba si la pantalla admite ARGB o temas, y también si el tamaño de la imagen encaja dentro del tamaño máximo del cursor (64 píxeles). Si es así, crea un mapa de bits del tamaño especificado y almacena el resultado en caché en Xcursor, identificándolo con el valor del ID del Pixmap (pid).

void XcursorNoticePutBitmap (
	Display 	*dpy,
	Drawable 	 draw,
	XImage 	*image)

Actualiza el contenido de la imagen en el mapa de bits especificado por el valor de dibujo (un ID de Pixmap). El mapa de bits debe haber sido creado por XcursorNoticeCreateBitmap.

Cursor XcursorTryShapeBitmapCursor (
	Display 	*dpy,
	Pixmap 	 source,
	Pixmap 	 mask,
	XColor 	*foreground,
	XColor 	*background,
	unsigned int 	 x,
	unsigned int 	 y)

Si la pantalla admite ARGB o temas, intenta cargar un cursor en la caché de Xcursor utilizando el parámetro source como ID de Pixmap. Es posible que la fuente ya no esté en la caché. Xcursor utiliza el valor hash para identificar la imagen deseada.

Cursor XcursorTryShapeCursor (
	Display 	*dpy,
	Font 	 source_font,
	Font 	 mask_font,
	unsigned int 	 source_char,
	unsigned int 	 mask_char,
	XColor _Xconst 	*foreground,
	XColor _Xconst 	*background)

Si la pantalla admite ARGB o temas, intenta cargar un cursor en la caché de Xcursor utilizando el parámetro source_char como forma. Usando

  • el tamaño predeterminado de XcursorGetDefaultSize,
  • el tema predeterminado de XcursorGetTheme, y
  • el parámetro source_char como forma,
Xcursor llama a XcursorShapeLoadImages para cargar las imágenes del cursor. Si tiene éxito, Xcursor utiliza XcursorImagesLoadCursor para cargar la información del cursor.

Display Information APIs

XcursorBool XcursorSupportsARGB (
	Display 	*dpy)

Devuelve verdadero si la pantalla admite cursores ARGB. De lo contrario, los cursores se asignarán a un cursor X central.

XcursorBool XcursorSupportsAnim (
	Display 	*dpy)

Devuelve verdadero si la pantalla admite cursores animados. De lo contrario, los cursores se asignarán a un cursor X central.

	Display 	*dpy,
	int 	 size)

Establece el tamaño predeterminado para los cursores en la pantalla especificada. Al cargar cursores, se preferirán aquellos cuyo tamaño nominal sea el más cercano a este tamaño.

int XcursorGetDefaultSize (
	Display 	*dpy)

Obtiene el tamaño predeterminado del cursor.

XcursorBool XcursorSetResizable (

ENVIRONMENT

Las variables de entorno se pueden usar para anular la configuración de recursos, que a su vez anulan los valores predeterminados compilados.

Algunas de las variables de entorno reconocidas por Xcursor son booleanos, especificadas de la siguiente manera:

true para "t", "1", "y" o "on"
false para "f", "0", "n" o "off"

Xcursor ignora otros valores para estos booleanos.

HOME
Xcursor interpreta "~" en la lista de búsqueda como el directorio de inicio, utilizando esta variable en lugar de la base de datos de contraseñas.
XCURSOR_ANIM
Si la pantalla admite la solicitud Render CreateCursor y la función Render está habilitada, deshabilita los cursores animados si la variable de entorno es false.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.anim.
XCURSOR_CORE
Si la pantalla admite la solicitud Render CreateCursor, deshabilita la función Render si la variable de entorno es false.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.core.
XCURSOR_DISCOVER
Si la variable está configurada, Xcursor activa una función de registro. Muestra el valor hash y la imagen para que los usuarios puedan ver qué nombre de cursor está asociado con cada imagen.
No hay una configuración de recurso correspondiente.
XCURSOR_DITHER
Esta variable establece el dither deseado.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.dither.
Si no se encuentran ni la variable de entorno ni el recurso, Xcursor utiliza "threshold".
Estos son los valores reconocidos:
diffuse
median
ordered
threshold
XCURSOR_PATH
Esta variable establece la lista de rutas en las que buscar cursores, en lugar de la lista predeterminada compilada.
Los directorios en esta ruta están separados por dos puntos (:).
XCURSOR_RESIZED
Habilita el redimensionamiento automático de cursores para mejorar su tamaño de visualización si la variable de entorno es true.
Si no se proporciona la variable de entorno, Xcursor prueba el recurso Xcursor.resized.
XCURSOR_SIZE
Esta variable establece el tamaño deseado del cursor, en píxeles.
Si no se proporciona la variable de entorno, Xcursor prueba el recurso Xcursor.size.
Si no se proporciona ningún tamaño, ya sea por variable de entorno o configuración de recurso, Xcursor prueba a continuación la configuración del recurso Xft.dpi para adivinar el tamaño de un cursor de 16 puntos.
Finalmente, si Xft.dpi no está configurado, Xcursor utiliza la altura de la pantalla, dividiendo por 48 (asumiendo que la altura es 768).
XCURSOR_THEME
Esta variable selecciona el tema deseado.
Si no se proporciona la variable de entorno, Xcursor prueba el recurso Xcursor.theme.
Si no se encuentran ni la variable de entorno ni el recurso, Xcursor utiliza el tema predeterminado.

 XcursorXcFileLoadImages(3) — libXcursor 1.2.3

NAME

XcursorXcFileLoadImages, XcursorXcFileLoadImage, XcursorXcFileLoadQuery — load cursor images from Xcursor files

SYNOPSIS

XcursorXcFileLoadImages(XcursorFile*, char***, int*);
XcursorXcFileLoadImage(XcursorFile*, char*, XcursorImage**);
XcursorXcFileLoadQuery(XcursorFile*);

DESCRIPTION

The Xcursor library provides support for loading and saving cursors in the Xcursor file format. This format is used by the Xorg server and is also used by cursor themes.

The XcursorXcFileLoadImages function loads all cursor images from an Xcursor file. The cursor images are returned as an array of XcursorImage structures, and the names of the cursors are returned in an array of strings. The number of cursors loaded is returned in the n_images argument.

The XcursorXcFileLoadImage function loads a single cursor image from an Xcursor file. The name of the cursor to load is specified by the name argument.

The XcursorXcFileLoadQuery function returns true if the Xcursor file contains cursor images, and false otherwise.

FUNCTIONAL OVERVIEW

The Xcursor library provides a set of functions for manipulating cursor images. These functions include:

XcursorCreateCursor(3)
Creates a cursor from an XcursorImage structure.
XcursorDestroyCursor(3)
Destroys a cursor.
XcursorFillImage(3)
Fills an XcursorImage structure with data.
XcursorGetCursor(3)
Gets the cursor image for a given cursor.
XcursorLoadCursor(3)
Loads a cursor from a file.
XcursorSaveCursor(3)
Saves a cursor to a file.
XcursorSetThemeCursor(3)
Sets the theme cursor for a given cursor.
XcursorXcFileLoadImages(3)
Loads all cursor images from an Xcursor file.
XcursorXcFileLoadImage(3)
Loads a single cursor image from an Xcursor file.
XcursorXcFileLoadQuery(3)
Checks if an Xcursor file contains cursor images.

DATATYPES

XcursorFile
Represents an open Xcursor file.
XcursorImage
Represents a cursor image. It contains the image data, hotspot, dimensions, and other metadata.

FUNCTIONS

XcursorXcFileLoadImages(XcursorFile* file, char*** names, int* n_images)
Loads all cursor images from the given file. The cursor names are returned in names, and the number of cursors is returned in n_images. The caller is responsible for freeing the memory allocated for names and the strings it contains.
XcursorXcFileLoadImage(XcursorFile* file, char* name, XcursorImage** image)
Loads a single cursor image named name from the given file. The loaded cursor image is returned in image. The caller is responsible for freeing the memory allocated for the XcursorImage using XcursorDestroyImage.
XcursorXcFileLoadQuery(XcursorFile* file)
Returns true if the Xcursor file contains cursor images, false otherwise.

ENVIRONMENT

Xcursor.theme_core
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.

CAVEATS

Xcursor will probably change radically in the future; weak attempts will be made to retain some level of source-file compatibility.
