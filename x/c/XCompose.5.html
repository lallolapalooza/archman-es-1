NOMBRE

Compose - Mapeos de cliente X para secuencias de entrada de varias teclas

DESCRIPCIÓN

La biblioteca X, libX11, proporciona un método de entrada simple para caracteres que van más allá de los representados en teclados típicos, utilizando secuencias de pulsaciones de teclas que se combinan para introducir un solo carácter.

El archivo Compose se busca en el siguiente orden:

-
Si la variable de entorno $XCOMPOSEFILE está configurada, su valor se utiliza como el nombre del archivo Compose.
-
Si el directorio personal del usuario tiene un archivo llamado .XCompose, se utiliza como el archivo Compose.
-
Se utiliza el archivo compose proporcionado por el sistema mapeando la localización a un archivo compose de la lista en /usr/share/X11/locale/compose.dir.

Los archivos Compose pueden usar una instrucción de "include". Esto permite realizar modificaciones locales en archivos compose existentes sin incluir todo el contenido directamente. Por ejemplo, el archivo compose iso8859-1 del sistema puede incluirse con una línea como esta:

include "%S/iso8859-1/Compose"

Hay varias sustituciones que se pueden hacer en el nombre del archivo de la instrucción include:

%H
se expande al directorio personal del usuario (la variable de entorno $HOME)
%L
se expande al nombre del archivo Compose específico de la localización (es decir, "/usr/share/X11/locale/<nombre_localizacion>/Compose")
%S
se expande al nombre del directorio del sistema para archivos Compose (es decir, "/usr/share/X11/locale")

Por ejemplo, puede incluir en su archivo compose el archivo Compose predeterminado usando:

include "%L"
y luego reescribir solo las pocas reglas que necesita cambiar. Se pueden añadir nuevas reglas compose y reemplazar las anteriores.

FORMATO DEL ARCHIVO

Los archivos Compose son archivos de texto plano, con una línea separada para cada secuencia compose. Los comentarios comienzan con caracteres de #. Cada secuencia compose especifica uno o más eventos y una secuencia de entrada resultante, con un comentario opcional al final de la línea:

EVENTO [EVENTO...] : RESULTADO [# COMENTARIO]

Cada evento consiste en un keysym de entrada especificado y estados modificadores opcionales:

[([!] ([~] MODIFICADOR)...) | None] <keysym>

Si la lista de modificadores está precedida por "!", debe coincidir exactamente. MODIFICADOR puede ser uno de Ctrl, Lock, Caps, Shift, Alt o Meta. Cada modificador puede estar precedido por un carácter "~" para indicar que el modificador no debe estar presente. Si se especifica "None", no puede haber ningún modificador.

El resultado especifica una cadena, un keysym, o ambos, que el cliente X recibe como entrada cuando se introduce la secuencia de eventos:

"CADENA" | keysym | "CADENA" keysym

Los keysym se especifican sin el prefijo XK_.

Las cadenas pueden ser texto directo codificado en la localización para la que se utilizará el archivo compose, o un código de carácter octal o hexadecimal escapado. Los códigos octales se especifican como "\123" y los códigos hexadecimales como "\x3a". No es necesario especificar en la parte derecha de una regla una cadena codificada en la localización además del nombre del keysym. Si la cadena se omite, Xlib la deduce del keysym de acuerdo con la localización actual. Es decir, si una regla se ve así:

<dead_grave> <A> : "\300" Agrave
el resultado de la composición es siempre la letra con el código "\300". Pero si la regla es:
<dead_grave> <A> : Agrave
el resultado depende de cómo Agrave esté mapeado en la localización actual.

ENTORNO

XCOMPOSEFILE
Archivo a utilizar para secuencias compose.
XCOMPOSECACHE
Directorio a utilizar para almacenar en caché archivos compose compilados.

ARCHIVOS

$HOME/.XCompose
Archivo compose predeterminado del usuario si XCOMPOSEFILE no está configurado.
/usr/share/X11/locale/compose.dir
Archivo que enumera la ruta del archivo compose a utilizar para cada localización.
/usr/share/X11/locale/<mapeo_localizacion>/Compose
Archivo compose predeterminado del sistema para la localización, mapeado a través de compose.dir.
/var/cache/libx11/compose/
Directorio de caché a nivel de sistema para archivos compose compilados.
$HOME/.compose-cache/
Directorio de caché por usuario para archivos compose compilados.
