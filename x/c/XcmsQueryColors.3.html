XcmsQueryColors(3)

Paquete: libx11

Licencias: MIT AND X11

XcmsQueryColor(3) FUNCIONES DE XLIB XcmsQueryColor(3)

NOMBRE

XcmsQueryColor, XcmsQueryColors, XcmsLookupColor - obtener valores de color

SINTAXIS

Status XcmsQueryColor(Display *display, Colormap colormap, XcmsColor *color_in_out, XcmsColorFormat result_format);

Status XcmsQueryColors(Display *display, Colormap colormap, XcmsColor colors_in_out[], unsigned int ncolors, XcmsColorFormat result_format);

Status XcmsLookupColor(Display *display, Colormap colormap, _Xconst char *color_string, XcmsColor *color_exact_return, XcmsColor *color_screen_return, XcmsColorFormat result_format);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
colormap
Especifica el mapa de colores.
color_exact_return
Devuelve la especificación de color analizada de la cadena de color o analizada de la cadena correspondiente encontrada en una base de datos de nombres de colores.
color_in_out
Especifica el miembro pixel que indica la celda de color a consultar. La especificación de color almacenada para la celda de color se devuelve en esta estructura XcmsColor.
color_screen_return
Devuelve el color que se puede reproducir en la pantalla.
color_string
Especifica la cadena de color.
result_format
Especifica el formato de color para las especificaciones de color devueltas (argumentos color_screen_return y color_exact_return). Si el formato es XcmsUndefinedFormat y la cadena de color contiene una especificación de color numérica, la especificación se devuelve en el formato utilizado en esa especificación de color numérica. Si el formato es XcmsUndefinedFormat y la cadena de color contiene un nombre de color, la especificación se devuelve en el formato utilizado para almacenar el color en la base de datos.
ncolors
Especifica el número de estructuras XcmsColor en la matriz de especificaciones de color.

DESCRIPCIÓN

La función XcmsQueryColor obtiene el valor RGB para el valor del píxel en el miembro pixel de la estructura XcmsColor especificada y luego convierte el valor al formato de destino según lo especificado por el argumento result_format. Si el píxel no es un índice válido en el mapa de colores especificado, se produce un error BadValue. La función XcmsQueryColors obtiene los valores RGB para los valores de píxel en los miembros pixel de las estructuras XcmsColor y luego convierte los valores al formato de destino según lo especificado por el argumento result_format. Si un píxel no es un índice válido en el mapa de colores especificado, se produce un error BadValue. Si más de un píxel tiene un error, el que se informa es arbitrario.

XcmsQueryColor y XcmsQueryColors pueden generar errores BadColor y BadValue.

La función XcmsLookupColor busca el nombre de cadena de un color con respecto a la pantalla asociada con el mapa de colores especificado. Devuelve tanto los valores de color exactos como los valores más cercanos proporcionados por la pantalla con respecto al tipo visual del mapa de colores especificado. Los valores se devuelven en el formato especificado por result_format. Si el nombre del color no está en la codificación de caracteres portátil del host (Host Portable Character Encoding), el resultado depende de la implementación. El uso de mayúsculas o minúsculas no importa. XcmsLookupColor devuelve XcmsSuccess o XcmsSuccessWithCompression si se resuelve el nombre; de lo contrario, devuelve XcmsFailure. Si se devuelve XcmsSuccessWithCompression, la especificación de color devuelta en color_screen_return es el resultado de la compresión de la gama (gamut compression).

DIAGNÓSTICOS

BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
