NOMBRE

Xcursor — Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que construye cursores ya sea a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es soportada por el servidor X. Donde no es soportado, Xcursor mapea la imagen del cursor a un cursor estándar de X y usa la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor se etiqueta con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Múltiples cursores del mismo tamaño nominal se pueden cargar juntos; se espera que las aplicaciones los utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magia:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posicion:	CARD32 posición absoluta en bytes del tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en TOC para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentarios son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imágenes son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
pixeles:	LISTofCARD32 Pixeles en formato ARGB empaquetado

TEMAS

Xcursor sigue (en su mayoría) la especificación freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, p. ej., como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas en este formato:
Hereda = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Nombre” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor verifica el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixeles; 	/* puntero a pixeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imagenes; 	/* array de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Referencia un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden referenciar el mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio.

STRUCTS

XcursorFile

The `XcursorFile` structure is used to abstract different file types. The read and write functions provided by the user are expected to use the `closure` pointer to refer to file-specific data. The default implementations for the read and write functions will use the `closure` pointer as a `FILE*`. The read and write functions have different argument orders than the standard POSIX `read` and `write` calls, so that the Xcursor library functions can be written more generically. The Xcursor read and write functions take the `XcursorFile` pointer as the first argument, while the POSIX functions take the file descriptor as the first argument. The read and write functions flip the arguments around to match the POSIX versions.


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se usa ese.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, se usa “default” para el nombre del tema.
  • Si ninguna de las búsquedas tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

NAME

                    
XcursorGetTheme, XcursorGetThemeCore - get the cursor theme

                

                

                    
SYNOPSIS

                    
#include <Xcursor/Xcursor.h>
const char *
XcursorGetTheme(
    Display *dpy,
    int *hot_x,
    int *hot_y
);
const char *
XcursorGetThemeCore(
    Display *dpy,
    int *hot_x,
    int *hot_y
);
                    

                

                

                    
DESCRIPTION

                    
These functions return the name of the cursor theme
                        currently in use for the display dpy. The theme name
                        is returned as a string literal, which must not be freed.
                        The hotspot coordinates for the default cursor of the theme are
                        returned in hot_x and hot_y.

                    
XcursorGetTheme queries the standard cursor theme
                        resource, Xcursor.theme.

                    
XcursorGetThemeCore queries the core cursor theme
                        resource, Xcursor.theme_core.

                

                

                    
FUNCTIONAL OVERVIEW

                    
When the window manager starts, it queries the current
                        cursor theme. If a theme is found, it is used. Otherwise, the
                        default theme is used.

                    
The theme is set by the Xcursor.theme resource. If
                        this resource is not set, the Xcursor.theme_core resource
                        is checked. If neither resource is set, the cursor theme defaults
                        to the system default.

                    
The theme name can also be set using the
                        XcursorSetTheme() and
                        XcursorSetThemeCore() functions.

                

                

                    
DATATYPES

                    

                        
XcursorCursor

                        
Structure representing a cursor.

                        
XcursorHints

                        
Structure representing cursor hints.

                    

                

                

                    
FUNCTIONS

                    

                        
XcursorThemeLoadCursor

                        
Loads a cursor from a theme.

                        
XcursorThemeNextCursor

                        
Gets the next cursor in a theme.

                        
XcursorThemeDestroy

                        
Destroys a cursor theme.

                        
XcursorThemeEnumErrors

                        
Enumerates errors in a cursor theme.

                        
XcursorThemeFind

                        
Finds a cursor theme.

                        
XcursorThemeGetIconSizes

                        
Gets the available icon sizes for a theme.

                        
XcursorThemeLoadAllIcons

                        
Loads all icons from a theme.

                        
XcursorThemeLoadIcon

                        
Loads a specific icon from a theme.

                        
XcursorThemeRead

                        
Reads a cursor theme from a file.

                        
XcursorSetTheme

                        
Sets the cursor theme.

                        
XcursorSetThemeCore

                        
Sets the core cursor theme.

                    

                

                

                    
ENVIRONMENT

                    

                        
Xcursor.theme_core

                        
Enables themes for core cursors if the environment variable is
                            true.

                    

                    

                        

                        
If the environment variable is not given, Xcursor tries the
                            Xcursor.theme_core resource.

                        

                        
An application can enable or disable themes using
                            XcursorSetThemeCore.
