XConfigureWindow(3) FUNCIONES DE XLIB XConfigureWindow(3)

NOMBRE

XConfigureWindow, XMoveWindow, XResizeWindow, XMoveResizeWindow, XSetWindowBorderWidth, XWindowChanges - configurar ventanas y estructura de cambios de ventana

SINTAXIS

int XConfigureWindow(Display *display, Window w, unsigned value_mask, XWindowChanges *changes);

int XMoveWindow(Display *display, Window w, int x, y);

int XResizeWindow(Display *display, Window w, unsigned width, unsigned height);

int XMoveResizeWindow(Display *display, Window w, int x, int y, unsigned width, unsigned height);

int XSetWindowBorderWidth(Display *display, Window w, unsigned width);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
value_mask
Especifica qué valores se establecerán utilizando la información en la estructura de valores. Esta máscara es la operación OR inclusiva a nivel de bits de los bits de valores válidos para configurar la ventana.
changes
Especifica la estructura XWindowChanges.
w
Especifica la ventana a reconfigurar, mover o redimensionar.
width
Especifica el ancho del borde de la ventana.
width

height
Especifican el ancho y alto, que son las dimensiones interiores de la ventana.
x

y
Especifican las coordenadas x e y, que definen la nueva ubicación del píxel superior izquierdo del borde de la ventana o de la ventana misma si no tiene borde, o definen la nueva posición de la ventana con respecto a su padre.

DESCRIPCIÓN

La función XConfigureWindow utiliza los valores especificados en la estructura XWindowChanges para reconfigurar el tamaño, la posición, el borde y el orden de apilamiento de una ventana. Los valores no especificados se toman de la geometría existente de la ventana.

Si se especifica un hermano sin un modo de apilamiento o si la ventana no es realmente un hermano, se produce un error BadMatch. Tenga en cuenta que los cálculos para BottomIf, TopIf y Opposite se realizan con respecto a la geometría final de la ventana (según lo controlado por los otros argumentos pasados a XConfigureWindow), no a su geometría inicial. Cualquier contenido almacenado en caché de la ventana, sus inferiores y otras ventanas recién visibles se descartan o se cambian para reflejar el contenido actual de la pantalla (dependiendo de la implementación).

XConfigureWindow puede generar errores BadMatch, BadValue y BadWindow.

La función XMoveWindow mueve la ventana especificada a las coordenadas x e y especificadas, pero no cambia el tamaño de la ventana, ni la eleva, ni cambia su estado de mapeo. Mover una ventana mapeada puede o no perder el contenido de la ventana dependiendo de si la ventana está oscurecida por clientes no hijos y si no existe un almacenamiento de respaldo. Si se pierden los contenidos de la ventana, el servidor X genera eventos Expose. Mover una ventana mapeada genera eventos Expose en cualquier ventana previamente oscurecida.

Si la bandera override-redirect de la ventana es False y algún otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún procesamiento adicional. De lo contrario, la ventana se mueve.

XMoveWindow puede generar un error BadWindow.

La función XResizeWindow cambia las dimensiones interiores de la ventana especificada, sin incluir sus bordes. Esta función no cambia la coordenada superior izquierda ni el origen de la ventana, ni la reordena. Cambiar el tamaño de una ventana mapeada puede perder su contenido y generar eventos Expose. Si una ventana mapeada se hace más pequeña, cambiar su tamaño genera eventos Expose en las ventanas que la ventana mapeada anteriormente oscurecía.

Si la bandera override-redirect de la ventana es False y algún otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún procesamiento adicional. Si el ancho o el alto son cero, se produce un error BadValue.

XResizeWindow puede generar errores BadValue y BadWindow.

La función XMoveResizeWindow cambia el tamaño y la ubicación de la ventana especificada sin elevarla. Mover y redimensionar una ventana mapeada puede generar un evento Expose en la ventana. Dependiendo de los nuevos parámetros de tamaño y ubicación, mover y redimensionar una ventana puede generar eventos Expose en las ventanas que la ventana antes oscurecía.

Si la bandera override-redirect de la ventana es False y algún otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún procesamiento adicional. De lo contrario, se cambian el tamaño y la ubicación de la ventana.

XMoveResizeWindow puede generar errores BadValue y BadWindow.

La función XSetWindowBorderWidth establece el ancho del borde de la ventana especificada al ancho especificado.

XSetWindowBorderWidth puede generar un error BadWindow.

ESTRUCTURAS

La estructura XWindowChanges contiene:

// Máscara de bits de valores de configuración de ventana

#define CWX (1<<0)
#define CWY (1<<1)
#define CWWidth (1<<2)
#define CWHeight (1<<3)
#define CWBorderWidth (1<<4)
#define CWSibling (1<<5)
#define CWStackMode (1<<6) 
/* Valores */
typedef struct {
        int x, y;
        int width, height;
        int border_width;
        Window sibling;
        int stack_mode;
} XWindowChanges;

Los miembros x e y se utilizan para establecer las coordenadas x e y de la ventana, que son relativas al origen del padre e indican la posición de la esquina exterior superior izquierda de la ventana. Los miembros width y height se utilizan para establecer el tamaño interior de la ventana, sin incluir el borde, y deben ser distintos de cero, o se producirá un error BadValue. Los intentos de configurar una ventana raíz no tienen efecto.

El miembro border_width se utiliza para establecer el ancho del borde en píxeles. Tenga en cuenta que al establecer solo el ancho del borde se deja la esquina superior izquierda de la ventana en una posición fija, pero se mueve la posición absoluta del origen de la ventana. Si intenta establecer el atributo border_width de una ventana InputOnly en un valor distinto de cero, se producirá un error BadMatch.

El miembro sibling se utiliza para establecer la ventana hermana para las operaciones de apilamiento. El miembro stack_mode se utiliza para establecer cómo se debe volver a apilar la ventana y puede establecerse en Above, Below, TopIf, BottomIf u Opposite.

DIAGNÓSTICOS

BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos, pero no coincide de alguna otra manera requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Se proporciona un identificador de ventana no válido.

XConfigureWindow(3) — libX11 1.8.12

NAME

XConfigureWindow, XMoveWindow, XResizeWindow, XWarpPointer, XConfigureBounds, XSetNormalHints, XSetSizeHints, XSetWMProperties, XSetClassHint, XSetCommand — configure window attributes

SYNTAX

XConfigureWindow(Display *display, Window w, unsigned int value_mask, XWindowChanges *changes);
XMoveWindow(Display *display, Window w, int x, int y);
XResizeWindow(Display *display, Window w, unsigned int width, unsigned int height);
XWarpPointer(Display *display, Window src_w, Window dest_w, int src_x, int src_y, unsigned int src_width, unsigned int src_height, int dest_x, int dest_y);
XConfigureBounds(Display *display, Window w, int x, int y, unsigned int width, unsigned int height);
XSetNormalHints(Display *display, Window w, XSizeHints *hints);
XSetSizeHints(Display *display, Window w, XSizeHints *hints, Atom atom);
XSetWMProperties(Display *display, Window w, XTextProperty *wmname, XTextProperty *iconname, char **argv, int argc, XSizeHints *normal_hints, XWMHints *wmh, XClassHint *class_hints);
XSetClassHint(Display *display, Window w, XClassHint *hints);
XSetCommand(Display *display, Window w, char **argv, int argc, XClassHint *hints);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
value_mask
Specifies which components of the changes structure are valid. This must be a bitwise inclusive OR of the following values: CWX, CWY, CWWidth, CWHeight, CWBorderWidth, CWSibling, CWStackMode.
changes
Specifies the new configuration values.
x
Specifies the new x-coordinate of the window.
y
Specifies the new y-coordinate of the window.
width
Specifies the new width of the window.
height
Specifies the new height of the window.
src_w
Specifies the source window.
dest_w
Specifies the destination window.
src_x
Specifies the x-coordinate relative to the source window.
src_y
Specifies the y-coordinate relative to the source window.
src_width
Specifies the width of the source rectangle.
src_height
Specifies the height of the source rectangle.
dest_x
Specifies the x-coordinate relative to the destination window.
dest_y
Specifies the y-coordinate relative to the destination window.
hints
Specifies the size hints.
atom
Specifies the atom associated with the size hints.
wmname
Specifies the window manager name property.
iconname
Specifies the icon name property.
argv
Specifies the command line arguments.
argc
Specifies the number of command line arguments.
normal_hints
Specifies the normal size hints.
wmh
Specifies the window manager hints.
class_hints
Specifies the class hints.

DESCRIPTION

The XConfigureWindow function reconfigures the specified window. You can change the window's position, size, border width, and stacking order. The value_mask argument specifies which components of the changes structure are to be used. The XWindowChanges structure is defined as follows:

typedef struct {
    int         x, y;
    int         width, height;
    int         border_width;
    Window      sibling;
    int         stack_mode;
    } XWindowChanges;

XMoveWindow, XResizeWindow, and XConfigureBounds are convenience functions that call XConfigureWindow with the appropriate value_mask and changes arguments.

XWarpPointer moves the pointer to the specified position relative to the specified destination window.

XSetNormalHints and XSetSizeHints set the size hints for a window. The XSizeHints structure is used to provide information about the window's size, including minimum and maximum dimensions, and aspect ratios.

XSetWMProperties is a convenience function that sets multiple window manager properties, including the name, icon name, command line, size hints, window manager hints, and class hints.

XSetClassHint sets the class hint for a window, which is used by the window manager to determine how to handle the window.

XSetCommand sets the command line arguments for a window, which is used by the window manager to determine how to restart the application.

        unsigned int   period;
        int             numerator;
        int             denominator;

    long         flags;
    int         input;
    int         initial_state;
    Pixmap      icon;
    Window      icon_window;
    int         gravity;
    int         back_x, back_y;
    unsigned long  your_x, your_y;
    unsigned long  width, height;
    unsigned int   min_width, min_height;
    unsigned int   max_width, max_height;
    unsigned int   width_inc, height_inc;
    struct {
        unsigned int   period;
        int             numerator;

    } XClassHint;

DIAGNOSTICS

If a Window argument does not name a defined Window, or if the value_mask is not valid, a BadValue or BadWindow error occurs.
