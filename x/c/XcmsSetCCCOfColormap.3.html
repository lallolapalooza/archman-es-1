XcmsSetCCCOfColormap(3)

Paquete: libx11

Licencias: MIT AND X11

XcmsSetCCCOfColormap(3) FUNCIONES DE XLIB XcmsSetCCCOfColormap(3)

NOMBRE

XcmsCCCOfColormap, XcmsSetCCCOfColormap - consultar y modificar el CCC de un mapa de colores

SINTAXIS

XcmsCCC XcmsCCCOfColormap(Display *display, Colormap colormap);

XcmsCCC XcmsSetCCCOfColormap(Display *display, Colormap colormap, XcmsCCC ccc);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
ccc
Especifica el CCC.
colormap
Especifica el mapa de colores.

DESCRIPCIÓN

La función XcmsCCCOfColormap devuelve el CCC asociado con el mapa de colores especificado. Una vez obtenido, los atributos del CCC pueden ser consultados o modificados. A menos que el CCC asociado con el mapa de colores especificado sea cambiado con XcmsSetCCCOfColormap, este CCC se utiliza cuando el mapa de colores especificado se usa como argumento para funciones de color.

La función XcmsSetCCCOfColormap cambia el CCC asociado con el mapa de colores especificado. Devuelve el CCC previamente asociado con el mapa de colores. Si no se vuelven a usar en la aplicación, los CCC deben ser liberados llamando a XcmsFreeCCC. Varios mapas de colores pueden compartir el mismo CCC sin restricciones; esto incluye los CCC generados por Xlib con cada mapa de colores. Sin embargo, Xlib crea un nuevo CCC con cada mapa de colores nuevo.
