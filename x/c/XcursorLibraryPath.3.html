NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud `CreateCursor` de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud `CreateCursor` principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en TOC para este fragmento
subtype:	CARD32 debe coincidir con el subtipo en TOC para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


header:	20 Las cabeceras de comentarios tienen 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


header:	36 Las cabeceras de imágenes tienen 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual a width
yhot:	CARD32 Debe ser menor o igual a height
delay:	CARD32 Retardo entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para tematizar iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio de cursores.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio de cursores, Xcursor busca a continuación un archivo `index.theme` en cada directorio de tema para buscar temas heredados. Estas son líneas en este formato:
Inherits = nombre-tema

Xcursor utiliza el primer `nombre-tema` heredado, ignorando otros que puedan existir en un archivo `index.theme` dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras `claves` en el archivo `index.theme`, incluido `Name` (es decir, el nombre que una aplicación gráfica puede usar como `nombre de presentación`).

Se puede listar más de un `nombre-tema` en la línea `Inherits=`. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea `Inherits=`; la especificación de freedesktop.org no es clara sobre si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema `default`.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor que encuentra mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* posición x del punto caliente (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* posición y del punto caliente (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras `XcursorImage`. Todas se liberan cuando se libera `XcursorImages` en `XcursorImagesDestroy`. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* array de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera `XcursorCursors`. Estos tienen un recuento de referencias para que múltiples estructuras `XcursorAnimate` puedan usar el mismo `XcursorCursors`. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Referencia un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras `XcursorAnimate` pueden referenciar el mismo `XcursorCursors`; cada una mantiene una referencia que se elimina cuando se libera `XcursorAnimate`. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del `size` deseado, utilizando una función privada (`XcursorScanTheme`) para encontrar el tema apropiado:

  • Si `theme` no es `NULL`, se usa ese.
  • Si `theme` es `NULL`, o si no hubo coincidencia para el tema deseado, se usa "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven `NULL`.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • `XcursorLibraryLoadImage` llama a `XcursorFileLoadImage` pero
  • `XcursorLibraryLoadImages` llama a `XcursorFileLoadImages`, y (en caso de éxito) llama a `XcursorImagesSetName` para asociar `name` con el resultado.

NAME


Xcursor - cursor loading routines






SYNOPSIS


#include <X11/Xcursor/Xcursor.h>







DESCRIPTION


The Xcursor library provides a mechanism for loading and managing
    cursor images. It supports loading cursors from files in the Xcursor
    file format, which can contain multiple images of varying sizes, as well as
    animated cursors and cursors based on glyphs. The library also provides
    APIs for querying display capabilities and configuring cursor settings such as
    size and theme.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for
    “t”, “1”, “y” or
    “on”

  

  
false for
    “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.





  
XCURSOR_THEM



ENVIRONMENT



  
Xcursor.theme_core

  
Habilita temas para cursores centrales si la variable de entorno es
      true.





  

  
Si la variable de entorno no se proporciona, Xcursor intenta usar el
      recurso Xcursor.theme_core.

  

  
Una aplicación puede habilitar o deshabilitar temas usando
    XcursorSetThemeCore.
