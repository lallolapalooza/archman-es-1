NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores X estándar. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores X estándar. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor X estándar y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar varios cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La cabecera del archivo se parece a:


magia:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se parece a:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del archivo de la tabla

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se parecen a:


cabecera:	20 Las cabeceras de comentarios son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se parecen a:


cabecera:	36 Las cabeceras de imagen son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor sigue (en su mayoría) la especificación de freedesktop.org para la tematización de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio "cursors".
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio "cursors", Xcursor busca a continuación un archivo "index.theme" en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo "index.theme" determinado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo "index.theme", incluido "Nombre" (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede enumerar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten varias claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema "predeterminado".

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
almacena una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
almacena múltiples estructuras XcursorImage. Todas se liberan cuando se liberan las XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Almacena múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* recuento de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera la XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el próximo cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio

ESTRUCTURAS

XcursorFile
typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Esta estructura representa un manejador de archivo para cursores. Contiene punteros a funciones para leer, escribir y buscar dentro del archivo. El campo closure puede ser utilizado por el usuario para almacenar información adicional específica del archivo. Los argumentos para las funciones read y write se invierten en comparación con las versiones POSIX para que coincidan con la forma en que suelen ser utilizadas en el contexto de la biblioteca Xcursor.

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se utiliza ese tema.
  • Si theme es NULL, o si no se encontró una coincidencia para el tema deseado, se utiliza "default" como nombre del tema.
  • Si ninguna de las búsquedas tiene éxito, estas funciones retornan NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

ENTORNO
\n
Las variables de entorno se pueden usar para anular la configuración de recursos, que a su vez anulan los valores predeterminados compilados.
\n
Algunas de las variables de entorno reconocidas por Xcursor son booleanas, especificadas de la siguiente manera:
\n
\n
\n  
verdadero para “t”, “1”, “y” o “on”
\n  
\n  
falso para “f”, “0”, “n” o “off”
\n  
\n
\n

                    NAME
                

                
Xcursor.h — X cursor library header

            

            

                

                    SYNOPSIS
                

                
#include <Xcursor/Xcursor.h>
                

            

            

                

                    DESCRIPTION
                

                
The Xcursor library provides a way to load cursors in
                    the Xcursor file format. This library is intended to replace
                    the older cursor loading functions provided by Xlib.

                
The primary benefit of the Xcursor library is its
                    support for animated cursors and cursors defined using
                    renderable primitives. It also provides a mechanism for
                    theming cursors, allowing applications to use a consistent
                    set of cursors across different environments.

            

            

                

                    FUNCTIONAL OVERVIEW
                

                
The Xcursor library provides functions for:

                

                    
Loading Cursors:

                    
Loading individual cursor images or animated cursor
                        sequences from Xcursor files.

                    
Cursor Creation:

                    
Creating X cursor objects from loaded images or sequences.

                    
Cursor Theming:

                    
Setting and retrieving cursor themes, enabling applications
                        to use a consistent look and feel.

                    
Cursor Management:

                    
Managing the lifecycle of cursor objects, including their
                        creation and destruction.

                

            

            

                

                    DATATYPES
                

                
The Xcursor library defines several key data types:

                

                    
XcursorImages

                    
Represents a collection of cursor images, potentially
                        including animation frames and hotspot information.

                    
XcursorImage

                    
Represents a single cursor image, including its dimensions,
                        hotspot, and pixel data.

                    
XcursorFile

                    
An opaque type representing an open Xcursor file.

                

            

            

                

                    FUNCTIONS
                

                
Key functions provided by the Xcursor library include:

                

                    
XcursorImagesCreateFromFile

                    
Loads cursor images from an Xcursor file.

                    
XcursorImagesCreate

                    
Creates an XcursorImages structure from raw pixel
                        data.

                    
XcursorImagesDestroy

                    
Frees memory associated with an XcursorImages
                        structure.

                    
XcursorFilenameToXcursorImages

                    
Loads cursor images from a file specified by its path.

                    
XcursorCreateCursor

                    
Creates an X cursor object from an XcursorImages
                        structure.

                    
XcursorSetTheme

                    
Sets the current cursor theme for the application.

                    
XcursorGetTheme

                    
Retrieves the name of the current cursor theme.

                    
XcursorSetThemeCore

                    
Enables or disables the use of core cursors within a
                        theme.

                    
XcursorGetDefaultTheme

                    
Gets the default cursor theme name.

                    
XcursorGetDefaultSize

                    
Gets the default cursor size.

                

            

            

                

                    ENVIRONMENT
                

                

                    

                        Xcursor.theme_core

                    
Enables themes for core cursors if the environment variable is
                        true.

                

                

                    

                    
If the environment variable is not given, Xcursor tries the
                        Xcursor.theme_core resource.

                    

                    
An application can enable or disable themes using
                        XcursorSetThemeCore.

                

            

            

                

                    CAVEATS
                

                
Xcursor will probably change radically in the
                    future; weak attempts will be made to retain some level of
                    source-file compatibility.
