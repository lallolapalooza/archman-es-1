XStringToKeysym(3) FUNCIONES DE XLIB XStringToKeysym(3)

NOMBRE

XStringToKeysym, XKeysymToString, XKeycodeToKeysym, XKeysymToKeycode, XConvertCase - convertir keysyms

SINTAXIS

KeySym XStringToKeysym(_Xconst char *string);

char *XKeysymToString(KeySym keysym);

KeySym XKeycodeToKeysym(Display *display, KeyCode keycode, int index);

KeyCode XKeysymToKeycode(Display *display, KeySym keysym);

void XConvertCase(KeySym keysym, KeySym *lower_return, KeySym *upper_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
index
Especifica el elemento del vector KeyCode.
keycode
Especifica el KeyCode.
keysym
Especifica el KeySym que se va a buscar o convertir.
lower_return
Devuelve la forma en minúsculas del keysym, o el keysym.
string
Especifica el nombre del KeySym que se va a convertir.
upper_return
Devuelve la forma en mayúsculas del keysym, o el keysym.

DESCRIPCION

Los nombres estándar de KeySym se obtienen de X11/keysymdef.h eliminando el prefijo XK_ de cada nombre. Los KeySyms que no forman parte del estándar Xlib también pueden obtenerse con esta función. El conjunto de KeySyms que están disponibles de esta manera y los mecanismos mediante los cuales Xlib los obtiene dependen de la implementación.

Si el nombre del KeySym no está en la Codificación de Caracteres Portátil del Host, el resultado depende de la implementación. Si la cadena especificada no coincide con un KeySym válido, XStringToKeysym devuelve NoSymbol.

La cadena devuelta está en un área estática y no debe modificarse. La cadena devuelta está en la Codificación de Caracteres Portátil del Host. Si el KeySym especificado no está definido, XKeysymToString devuelve un NULL.

La función XKeycodeToKeysym utiliza tablas internas de Xlib y devuelve el KeySym definido para el KeyCode y el elemento especificados del vector KeyCode. Si no se define ningún símbolo, XKeycodeToKeysym devuelve NoSymbol. XKeycodeToKeysym es anterior a la extensión XKB. Si desea buscar un KeySym mientras utiliza XKB, debe utilizar XkbKeycodeToKeysym.

Si el KeySym especificado no está definido para ningún KeyCode, XKeysymToKeycode devuelve cero.

La función XConvertCase devuelve las formas en mayúsculas y minúsculas del Keysym especificado, si el Keysym está sujeto a conversión de mayúsculas/minúsculas; de lo contrario, el Keysym especificado se devuelve a lower_return y upper_return. El soporte para la conversión de otros KeySyms que no sean latinos y cirílicos depende de la implementación.
