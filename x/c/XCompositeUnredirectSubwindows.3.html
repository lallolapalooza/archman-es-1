NOMBRE

Xcomposite - biblioteca de la extensión X Composite

SINOPSIS

#include <X11/extensions/Xcomposite.h>

Bool XCompositeQueryExtension(Display *dpy, int *event_base_return, int *error_base_return);

Status XCompositeQueryVersion(Display *dpy, int *major_version_return, int *minor_version_return);

int XCompositeVersion(void);

void XCompositeRedirectWindow(Display *dpy, Window window, int update);

void XCompositeRedirectSubwindows(Display *dpy, Window window, int update);

void XCompositeUnredirectWindow(Display *dpy, Window window, int update);

void XCompositeUnredirectSubwindows(Display *dpy, Window window, int update);

XserverRegion XCompositeCreateRegionFromBorderClip(Display *dpy, Window window);

Pixmap XCompositeNameWindowPixmap(Display *dpy, Window window);

Window XCompositeGetOverlayWindow(Display *dpy, Window window);

void XCompositeReleaseOverlayWindow(Display *dpy, Window window);

DESCRIPCIÓN

La extensión composite proporciona varios mecanismos relacionados:

Almacenamiento por jerarquía

La representación de una jerarquía completa de ventanas se redirecciona a un almacenamiento fuera de pantalla. Los píxeles de esa jerarquía están disponibles siempre que sea visible. El almacenamiento se reasigna automáticamente cuando la ventana de nivel superior cambia de tamaño. El contenido más allá de la geometría de la ventana superior no se conserva.

Actualización automática de sombra

Cuando una jerarquía se representa fuera de pantalla, el servidor X proporciona un mecanismo automático para presentar ese contenido dentro de la ventana padre. La implementación es libre de hacer que esta actualización se retrase con respecto a las operaciones de representación reales en una cantidad de tiempo no especificada. Este mecanismo de actualización automática puede deshabilitarse para que el contenido de la ventana padre pueda ser determinado completamente por una aplicación externa.

Ventana de superposición compuesta (Composite Overlay Window)

La versión 0.3 del protocolo añade la Ventana de superposición compuesta, que proporciona a los gestores de composición una superficie sobre la que dibujar sin interferencias. Esta ventana está siempre por encima de las ventanas normales y siempre por debajo de la ventana del protector de pantalla. Es una ventana de Entrada/Salida (InputOutput) cuyas dimensiones son las de la pantalla. Su visual es el visual raíz y su borde tiene un ancho de cero. Los intentos de redirigirla usando la extensión composite se ignoran. Esta ventana no aparece en la respuesta de la solicitud QueryTree. También es una ventana de redirección de anulación (override redirect). Estas dos últimas características la hacen invisible para los gestores de ventanas y otros clientes X11. La única forma de acceder al XID de esta ventana es a través de la solicitud CompositeGetOverlayWindow. Inicialmente, la Ventana de superposición compuesta está desmapeada.

Recorte de ventana padre

La versión 0.4 del protocolo modifica la semántica del recorte de la ventana padre en presencia de hijos redirigidos manualmente. Con esta versión, el área en el padre cubierta por hijos redirigidos manualmente se deja en la lista de recortes del padre en lugar de eliminarse como en versiones anteriores.

El almacenamiento fuera de pantalla puede crearse para ventanas individuales o para todos los hijos de una ventana. La actualización manual de sombras puede ser seleccionada por una sola aplicación para cada ventana; la actualización manual también puede ser seleccionada por ventana o para cada hijo de una ventana. La detección de cuándo actualizar puede hacerse con la extensión Damage.

El almacenamiento fuera de pantalla incluye el contenido de la ventana, sus bordes y el contenido de todos sus descendientes.

ARGUMENTOS

display

Puntero a la estructura Display devuelta por XOpenDisplay para la conexión con el servidor X.

event_base_return

Puntero a un entero donde se almacenará el valor base para los eventos de la Extensión Composite.

error_base_return

Puntero a un entero donde se almacenará el valor base para los errores de la Extensión Composite.

major_version_return

Puntero a un entero donde se almacenará la versión mayor de la Extensión Composite soportada por el servidor X.

minor_version_return

Puntero a un entero donde se almacenará la versión menor de la Extensión Composite soportada por el servidor X.

window

Especifica el ID de la ventana sobre la que operar.

update

Especifica el modo de actualización del contenido de la ventana. Debe ser CompositeRedirectAutomatic o CompositeRedirectManual.

FUNCIONES

XCompositeQueryExtension

XCompositeQueryExtension determina si la Extensión Composite está disponible en la pantalla dada. Devuelve True si la extensión se soporta, de lo contrario False. Si la extensión está presente, se devuelven los valores base para eventos y errores, y pueden usarse para decodificar valores de eventos y errores entrantes.

XCompositeQueryVersion

XCompositeQueryVersion determina si el Servidor X soporta una versión de la Extensión X Composite que sea compatible con la biblioteca cliente. Se devuelve un Status distinto de cero si se soporta una versión compatible de la extensión, de lo contrario se devuelve un Status cero. Si la extensión se soporta, se devuelven los números de versión mayor y menor para indicar el nivel de soporte de la Extensión Composite. No se pueden llamar a otras funciones XComposite (excepto XCompositeQueryExtension) antes de esta función. Si un cliente viola esta regla, los efectos de todas las llamadas XComposite subsiguientes que haga no están definidos.

XCompositeVersion

XCompositeVersion devuelve la versión de la biblioteca X Composite. El número de versión se codifica como: (mayor * 10000) + (menor * 100) + revisión

Por ejemplo, la versión 1.4.6 se codificaría como el entero 10406.

XCompositeRedirectWindow

XCompositeRedirectWindow solicita al servidor X que redireccione la jerarquía que comienza en window a un almacenamiento fuera de pantalla. El argumento update especifica si el contenido se refleja automáticamente en la ventana padre o no. Solo un cliente a la vez puede especificar un tipo de actualización de CompositeRedirectManual, otro intento resultará en un error BadAccess. Cuando todos los clientes que habilitan la redirección terminan, la redirección se deshabilitará automáticamente.

La ventana raíz no puede ser redirigida. Hacerlo resulta en un error BadMatch. Especificar un ID de ventana inválido resultará en un error BadWindow.

XCompositeRedirectSubwindows

XCompositeRedirectSubwindows solicita al servidor X que redirija las jerarquías que comienzan en todos los hijos actuales y futuros de window como en XCompositeRedirectWindow. Si update es CompositeRedirectManual, entonces se inhibe la pintura del fondo de la ventana durante la manipulación de ventanas y las solicitudes ClearArea.

XCompositeUnredirectWindow

XCompositeUnredirectWindow solicita al servidor X que termine la redirección de window. Si la ventana especificada no fue seleccionada para redirección por el cliente actual, resulta un error BadValue.

XCompositeUnredirectSubwindows

XCompositeUnredirectSubwindows solicita al servidor X que termine la redirección de todos los hijos de window. Si la ventana especificada no fue seleccionada para sub-redirección por el cliente actual, resulta un error BadValue.

XCompositeCreateRegionFromBorderClip

XCompositeCreateRegionFromBorderClip crea una región que contiene el área "usual" del borde.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap devuelve un pixmap que contiene el contenido de la ventana especificada. Esto solo es válido si la ventana ha sido redirigida (ya sea automática o manualmente). Si la ventana no ha sido redirigida, o si el pixmap no se puede crear, se devuelve un 0 (cero) Pixmap.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow devuelve la ventana de superposición compuesta para la pantalla dada. La ventana de superposición compuesta es una ventana de nivel superior que está siempre por encima de las ventanas normales y siempre por debajo de la ventana del protector de pantalla. Es una ventana IO, con el visual raíz, sin borde y con ID de redirección de anulación.

XCompositeReleaseOverlayWindow

XCompositeReleaseOverlayWindow libera el uso de la ventana de superposición compuesta. Debe llamarse cuando ya no se necesite la ventana de superposición compuesta.

ERRORES

Se generan los siguientes errores:

BadSubwindow
Un valor de ventana no es una ventana válida.
BadMatch
Se intentó redirigir la ventana raíz o se llamó a una función de forma inapropiada.
BadValue
Se proporcionó un valor inválido para el argumento update o la ventana no estaba siendo redirigida (para XCompositeUnredirect*).
Access
Otro cliente ya ha redirigido la ventana con CompositeRedirectManual.

XCompositeUnredirectSubwindows(3) — libxcb

NAME

XCompositeUnredirectSubwindows - unredirect a window's subwindows

SYNOPSIS

Status XCompositeUnredirectSubwindows(
                        Display *display,
                        Window window,
                        unsigned int update_child_needs
                    );

DESCRIPTION

The XCompositeUnredirectSubwindows function unredirects a window's subwindows. When a window is redirected, its contents are made available to the Composite Manager. The Composite Manager may then choose to display the window's contents as part of a composed screen. When a window is unredirected, its contents are no longer directly accessible to the Composite Manager.

The update_child_needs argument is used to inform the compositor that the redirected children may need updates. When set to `True`, the X server is asked to re-evaluate the needs of the children of the unredirected window.

If update_child_needs is `True`, and if the server supports XCompositeQueryExtension version 0.4 or greater, the server will validate that the children of window are not themselves redirected.

When a window is unredirected, the Composite Manager is no longer responsible for updating its contents. The client that originally redirected the window is responsible for updating its contents.

The X server must support at least version 0.2 of the Composite Extension for XCompositeUnredirectSubwindows.

This function generates a BadMatch error if window is not redirected or is not visible.

ARGUMENTS

display
Specifies the connection to the X server.
window
Specifies the window whose subwindows are to be unredirected.
update_child_needs
A boolean value that indicates whether to update the child needs.

FUNCTIONS

XCompositeRedirectWindow

XCompositeRedirectWindow redirects the contents of window to be made available to the Composite Manager. The update_child_needs argument controls whether the server should also redirect the children of the window. If update_child_needs is `True`, then all subwindows of window are also redirected. If it is `False`, then only window itself is redirected.

The X server must support at least version 0.2 of the Composite Extension for XCompositeRedirectWindow.

Generates a BadMatch error if window is already redirected or is not viewable.

XCompositeRedirectSubwindow

XCompositeRedirectSubwindow redirects the contents of subwindow, a child of window, to be made available to the Composite Manager. The subwindow is redirected independently of whether its parent window is redirected.

The X server must support at least version 0.3 of the Composite Extension for XCompositeRedirectSubwindow.

Generates a BadMatch error if subwindow is already redirected or is not viewable.

XCompositeQueryExtension

XCompositeQueryExtension queries the Composite Extension to determine if it is supported by the X server, and if so, returns its version number.

The major_version_in_out and minor_version_in_out arguments are used to specify the desired version of the extension. On return, they are updated to the actual version supported by the server.

Returns `True` if the extension is supported, `False` otherwise.

XCompositeQuerySubwindows

XCompositeQuerySubwindows returns a list of all subwindows of window that are currently redirected. The number of redirected subwindows is returned as the function's result.

The list_of_windows_ret argument is a pointer to a pointer to a Window. If not NULL, this pointer will be updated to point to a dynamically allocated list of Window IDs. The caller is responsible for freeing this list using XFree.

The X server must support at least version 0.2 of the Composite Extension for XCompositeQuerySubwindows.

XCompositeGetClippingRedirectWindow

XCompositeGetClippingRedirectWindow retrieves the clipping region for a redirected window. The clipping region is the area of the window that is visible after being clipped against its siblings and parent. This region can be used to restrict rendering to suitable areas while updating only a single window. The region is copied at the moment the request is executed; future changes to the window hierarchy will not be reflected in this region.

Generates a BadMatch error if window is not redirected.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap creates and returns a pixmap id that serves as a reference to the off-screen storage for window. This pixmap will remain allocated until freed, even if the window is unmapped, reconfigured or destroyed. However, the window will get a new pixmap allocated each time it is mapped or resized, so this function will need to be reinvoked for the client to continue to refer to the storage holding the current window contents. Generates a BadMatch error if window is not redirected or is not visible.

The X server must support at least version 0.2 of the Composite Extension for XCompositeNameWindowPixmap.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow returns the window ID of the Composite Overlay Window for the screen specified by the argument window. This function notifies the X server that the client wishes to use the Composite Overlay Window of this screen. If this Composite Overlay Window has not yet been mapped, it is mapped by this request.

The Composite Overlay Window for a particular screen will be unmapped when all clients who have called this function have either called XCompositeReleaseOverlayWindow for that screen, or terminated their connection to the X server.

The X server must support at least version 0.3 of the Composite Extension for XCompositeGetOverlayWindow.

XCompositeReleaseOverlayWindow

This request specifies that the client is no longer using the Composite Overlay Window on the screen specified by the argument window. A screen's Composite Overlay Window is unmapped when there are no longer any clients using it.

The X server must support at least version 0.3 of the Composite Extension for XCompositeReleaseOverlayWindow.
