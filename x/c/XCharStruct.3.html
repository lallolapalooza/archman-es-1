XLoadFont(3) FUNCIONES DE XLIB XLoadFont(3)

NOMBRE

XLoadFont, XQueryFont, XLoadQueryFont, XFreeFont, XGetFontProperty, XUnloadFont, XCharStruct, XFontProp, XChar2b, XFontStruct - cargar o descargar fuentes y estructuras de métricas de fuentes

SINTAXIS

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

ARGUMENTOS

atom
Especifica el átomo para el nombre de la propiedad que deseas obtener.
display
Especifica la conexión con el servidor X.
font
Especifica la fuente.
font_ID
Especifica el ID de la fuente o el ID de GContext.
font_struct
Especifica el almacenamiento asociado con la fuente.
gc
Especifica el GC.
name
Especifica el nombre de la fuente, que es una cadena terminada en nulo.
value_return
Devuelve el valor de la propiedad de la fuente.

DESCRIPCIÓN

La función XLoadFont carga la fuente especificada y devuelve su ID de fuente asociado. Si el nombre de la fuente no está en la Codificación de Caracteres Portátil del Host, el resultado es dependiente de la implementación. El uso de mayúsculas o minúsculas no importa. Cuando los caracteres “?” y “*” se utilizan en un nombre de fuente, se realiza una coincidencia de patrones y se utiliza cualquier fuente coincidente. En el patrón, el carácter “?” coincidirá con cualquier carácter individual, y el carácter “*” coincidirá con cualquier número de caracteres. Un formato estructurado para los nombres de fuentes se especifica en las convenciones de X Logical Font Description del X Consortium. Si XLoadFont no tuvo éxito al cargar la fuente especificada, se produce un error BadName. Las fuentes no están asociadas con una pantalla en particular y pueden almacenarse como un componente de cualquier GC. Cuando la fuente ya no sea necesaria, llame a XUnloadFont.

XLoadFont puede generar errores BadAlloc y BadName.

La función XQueryFont devuelve un puntero a la estructura XFontStruct, que contiene información asociada con la fuente. Puede consultar una fuente o la fuente almacenada en un GC. El ID de fuente almacenado en la estructura XFontStruct será el ID de GContext, y debe tener cuidado al usar este ID en otras funciones (vea XGContextFromGC). Si la fuente no existe, XQueryFont devuelve NULL. Para liberar estos datos, use XFreeFontInfo.

XLoadQueryFont puede generar un error BadAlloc.

La función XLoadQueryFont proporciona la forma más común de acceder a una fuente. XLoadQueryFont abre (carga) la fuente especificada y devuelve un puntero a la estructura XFontStruct apropiada. Si el nombre de la fuente no está en la Codificación de Caracteres Portátil del Host, el resultado es dependiente de la implementación. Si la fuente no existe, XLoadQueryFont devuelve NULL.

La función XFreeFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada, y libera la estructura XFontStruct. La fuente en sí se liberará cuando ningún otro recurso la referencie. Los datos y la fuente no deben volver a ser referenciados.

XFreeFont puede generar un error BadFont.

Dada la átomo para esa propiedad, la función XGetFontProperty devuelve el valor de la propiedad de fuente especificada. XGetFontProperty también devuelve False si la propiedad no fue definida o True si fue definida. Un conjunto de átomos predefinidos existe para las propiedades de fuentes, que se pueden encontrar en X11/Xatom.h. Este conjunto contiene las propiedades estándar asociadas con una fuente. Aunque no está garantizado, es probable que las propiedades de fuentes predefinidas estén presentes.

La función XUnloadFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada. La fuente en sí se liberará cuando ningún otro recurso la referencie. La fuente no debe ser referenciada nuevamente.

XUnloadFont puede generar un error BadFont.

ESTRUCTURAS

La estructura XFontStruct contiene toda la información de la fuente y consta de la información específica de la fuente, así como un puntero a un array de estructuras XCharStruct para los caracteres contenidos en la fuente. Las estructuras XFontStruct, XFontProp, y XCharStruct contienen:

typedef struct {
	short lbearing;	/* origen al borde izquierdo del raster */
	short rbearing;	/* origen al borde derecho del raster */
	short width;	/* avance al origen del siguiente carácter */
	short ascent;	/* línea base al borde superior del raster */
	short descent;	/* línea base al borde inferior del raster */
	unsigned short attributes;	/* flags por carácter (no predefinidos) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* los caracteres normales de 16 bits son de dos bytes */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* gancho para que la extensión adjunte datos */
	Font fid;	/* ID de Fuente para esta fuente */
	unsigned direction;	/* indicación sobre la dirección en que se pinta la fuente */
	unsigned min_char_or_byte2;	/* primer carácter */
	unsigned max_char_or_byte2;	/* último carácter */
	unsigned min_byte1;	/* primera fila que existe */
	unsigned max_byte1;	/* última fila que existe */
	Bool all_chars_exist;	/* flag si todos los caracteres tienen tamaño distinto de cero */
	unsigned default_char;	/* carácter a imprimir para carácter indefinido */
	int n_properties;	/* cuántas propiedades hay */
	XFontProp *properties;	/* puntero al array de propiedades adicionales */
	XCharStruct min_bounds;	/* límites mínimos de todos los caracteres existentes */
	XCharStruct max_bounds;	/* límites máximos de todos los caracteres existentes */
	XCharStruct *per_char;	/* información de first_char a last_char */
	int ascent;	/* extensión lógica por encima de la línea base para el espaciado */
	int descent;	/* descenso lógico por debajo de la línea base para el espaciado */
} XFontStruct;

X soporta operaciones de texto de un solo byte/carácter, dos bytes/carácter matriz y carácter de 16 bits. Tenga en cuenta que cualquiera de estas formas puede utilizarse con una fuente, pero una solicitud de texto de un solo byte/carácter solo puede especificar un solo byte (es decir, la primera fila de una fuente de 2 bytes). Debe considerar las fuentes de 2 bytes como una matriz bidimensional de caracteres definidos: byte1 especifica el rango de filas definidas y byte2 define el rango de columnas definidas de la fuente. Las fuentes de un solo byte/carácter tienen una fila definida, y el rango de byte2 especificado en la estructura define un rango de caracteres.

El cuadro delimitador de un carácter se define por el XCharStruct de ese carácter. Cuando los caracteres están ausentes en una fuente, se utiliza el `default_char`. Cuando las fuentes tienen todos los caracteres del mismo tamaño, solo se utilizan las información en los límites mínimos y máximos de XFontStruct.

Los miembros de XFontStruct tienen las siguientes semánticas:

  • El miembro `direction` puede ser FontLeftToRight o FontRightToLeft. Es solo una indicación de si la mayoría de los elementos de XCharStruct tienen una métrica de ancho de carácter positiva (FontLeftToRight) o negativa (FontRightToLeft). El protocolo principal no define soporte para texto vertical.
  • Si los miembros `min_byte1` y `max_byte1` son ambos cero, `min_char_or_byte2` especifica el índice lineal de carácter correspondiente al primer elemento del array `per_char`, y `max_char_or_byte2` especifica el índice lineal de carácter del último elemento.
Si `min_byte1` o `max_byte1` no son cero, tanto `min_char_or_byte2` como `max_char_or_byte2` son menores que 256, y los valores del índice de carácter de 2 bytes correspondientes al elemento N del array `per_char` (contando desde 0) son:

SYNTAX

typedef struct {
    short lbearing;
    short rbearing;
    short ascent;
    short descent;
    unsigned short width;
    int attributes;
} XCharStruct;

ARGUMENTS

lbearing
The logical distance from the drawing origin to the left edge of the character's ink.
rbearing
The logical distance from the drawing origin to the right edge of the character's ink.
ascent
The logical distance from the drawing origin to the top edge of the character's ink.
descent
The logical distance from the drawing origin to the bottom edge of the character's ink.
width
The logical width of the character, which is the distance from the drawing origin to the origin of the next character.
attributes
Font-specific information. This member is not typically used.

DESCRIPTION

The XCharStruct structure contains information about the metrics of a single character, including its bounding box and its logical width.

The bounding box of a character is the smallest rectangle that encloses the character's ink. It is defined by the lbearing, rbearing, ascent, and descent members.

The lbearing and rbearing members define the horizontal extent of the character's ink relative to the drawing origin. A positive lbearing means the ink extends to the left of the origin, while a negative lbearing means it extends to the right.

The ascent and descent members define the vertical extent of the character's ink relative to the drawing origin. A positive ascent means the ink extends above the origin, while a positive descent means it extends below the origin.

The width member defines the logical width of the character, which is the distance from the drawing origin to the origin of the next character. This is used for character spacing and line breaking.

STRUCTURES

The XFontStruct structure contains an array of XCharStruct structures, one for each character in the font. It also contains information about the font as a whole, including the minimum and maximum bounding boxes for all characters in the font, and the default character.

per_char
A pointer to an array of XCharStruct structures. Each structure describes a single character in the font. The array is indexed by the character code.
min_bounds
The minimum bounding box values over all characters in the font.
max_bounds
The maximum bounding box values over all characters in the font.
all_chars_exist
A boolean value indicating whether all characters in the font have non-zero bounding boxes.
default_char
The character code of the default character, which is used when a character is not found in the font.
max_overlap
The maximum overlap between characters in the font.
min_left_bearing
The minimum left bearing over all characters in the font.
min_right_bearing
The minimum right bearing over all characters in the font.
min_ascent
The minimum ascent over all characters in the font.
min_descent
The minimum descent over all characters in the font.
max_overlap
The maximum overlap between characters in the font.
font_ascent
The logical extent of the font above the baseline.
font_descent
The logical extent of the font at or below the baseline.
draw_mode
Specifies how characters are drawn. This field is not typically used.
line_space
The minimum interline spacing between rows of text.
  • If the per_char pointer is NULL, all glyphs between the first and last character indexes inclusive have the same information, as given by both min_bounds and max_bounds.
  • If all_chars_exist is True, all characters in the per_char array have nonzero bounding boxes.
  • The default_char member specifies the character that will be used when an undefined or nonexistent character is printed. The default_char is a 16-bit character (not a 2-byte character). For a font using 2-byte matrix format, the default_char has byte1 in the most-significant byte and byte2 in the least significant byte. If the default_char itself specifies an undefined or nonexistent character, no printing is performed for an undefined or nonexistent character.
  • The min_bounds and max_bounds members contain the most extreme values of each individual XCharStruct component over all elements of this array (and ignore nonexistent characters). The bounding box of the font (the smallest rectangle enclosing the shape obtained by superimposing all of the characters at the same origin [x,y]) has its upper-left coordinate at: 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
Its width is: 
max_bounds.rbearing - min_bounds.lbearing
Its height is: 
max_bounds.ascent + max_bounds.descent
  • The ascent member is the logical extent of the font above the baseline that is used for determining line spacing. Specific characters may extend beyond this.
  • The descent member is the logical extent of the font at or below the baseline that is used for determining line spacing. Specific characters may extend beyond this.
  • If the baseline is at Y-coordinate y, the logical extent of the font is inclusive between the Y-coordinate values (y - font.ascent) and (y + font.descent - 1). Typically, the minimum interline spacing between rows of text is given by ascent + descent.

For a character origin at [x,y], the bounding box of a character (that is, the smallest rectangle that encloses the character's shape) described in terms of XCharStruct components is a rectangle with its upper-left corner at:

[x + lbearing, y - ascent]

Its width is:

rbearing - lbearing

Its height is:

ascent + descent

The origin for the next character is defined to be:

[x + width, y]

The lbearing member defines the extent of the left edge of the character ink from the origin. The rbearing member defines the extent of the right edge of the character ink from the origin. The ascent member defines the extent of the top edge of the character ink from the origin. The descent member defines the extent of the bottom edge of the character ink from the origin. The width member defines the logical width of the character.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadFont
A value for a Font or GContext argument does not name a defined Font.
BadName
A font or color of the specified name does not exist.
