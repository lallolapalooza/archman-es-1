XOpenDisplay(3) FUNCIONES DE XLIB XOpenDisplay(3)

NOMBRE

XOpenDisplay, XCloseDisplay - conectar o desconectar al servidor X

SINTAXIS

Display *XOpenDisplay(_Xconst char *nombre_pantalla);

int XCloseDisplay(Display *pantalla);

ARGUMENTOS

pantalla
Especifica la conexión al servidor X.
nombre_pantalla
Especifica el nombre de la pantalla de hardware, que determina la pantalla y el dominio de comunicaciones a utilizar. En un sistema conforme a POSIX, si nombre_pantalla es NULL, se utilizará por defecto el valor de la variable de entorno DISPLAY.

DESCRIPCION

La función XOpenDisplay devuelve una estructura Display que sirve como conexión al servidor X y que contiene toda la información sobre dicho servidor X. XOpenDisplay conecta tu aplicación al servidor X a través de los protocolos de comunicación TCP o DECnet, o a través de algún protocolo de comunicación local entre procesos. Si el nombre de host es el nombre de una máquina host y un solo dos puntos (:) separa el nombre de host y el número de pantalla, XOpenDisplay se conecta usando flujos TCP. Si no se especifica el nombre de host, Xlib usa el que considera que es el transporte más rápido. Si el nombre de host es el nombre de una máquina host y un doble dos puntos (::) separa el nombre de host y el número de pantalla, XOpenDisplay se conecta usando DECnet. Un único servidor X puede soportar cualquiera o todos estos mecanismos de transporte simultáneamente. Una implementación particular de Xlib puede soportar muchos más de estos mecanismos de transporte.

Si tiene éxito, XOpenDisplay devuelve un puntero a una estructura Display, que se define en X11/Xlib.h. Si XOpenDisplay no tiene éxito, devuelve NULL. Después de una llamada exitosa a XOpenDisplay, todas las pantallas de la pantalla pueden ser utilizadas por el cliente. El número de pantalla especificado en el argumento nombre_pantalla es devuelto por la macro DefaultScreen (o la función XDefaultScreen). Puedes acceder a los elementos de las estructuras Display y Screen solo usando las macros o funciones de información. Para obtener información sobre el uso de macros y funciones para obtener información de la estructura Display, consulta la sección 2.2.1.

La función XCloseDisplay cierra la conexión al servidor X para la pantalla especificada en la estructura Display y destruye todas las ventanas, IDs de recursos (Window, Font, Pixmap, Colormap, Cursor y GContext), u otros recursos que el cliente haya creado en esta pantalla, a menos que el modo de cierre del recurso haya sido cambiado (ver XSetCloseDownMode). Por lo tanto, estas ventanas, IDs de recursos y otros recursos nunca deben ser referenciados de nuevo o se generará un error. Antes de salir, deberías llamar explícitamente a XCloseDisplay para que cualquier error pendiente sea reportado, ya que XCloseDisplay realiza una operación final de XSync.

XCloseDisplay puede generar un error BadGC.
