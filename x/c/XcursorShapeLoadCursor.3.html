NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o desde memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior se encuentra el código que puede cargar imágenes de cursores desde archivos. Por encima, hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior, hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si el servidor X la soporta. Donde no se soporta, Xcursor mapea la imagen del cursor a un cursor X estándar y usa la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar múltiples cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de bloques. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo tiene el siguiente aspecto:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas toc
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en TOC para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en TOC para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para los archivos de cursores; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentario tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imagen tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para los iconos temáticos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se utiliza en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas con el siguiente formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para utilizarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Name” (es decir, el nombre que una aplicación gráfica puede utilizar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor que encuentra mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se liberan las XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* recuento de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y a una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera la XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las de stdio

ESTRUCTURAS

struct _XcursorFile

Las funciones de manejo de archivos XcursorXcFile* operan sobre un puntero a XcursorFile. El usuario debe inicializar los punteros de función en XcursorFile. La mayoría de los usuarios encontrarán que es más fácil usar las interfaces XcursorFileLoad* o XcursorFileSave*, que inicializan este puntero a una estructura de archivo FILE estándar. Tenga en cuenta que la implementación de read() y write() en XcursorFile está orientada a los argumentos para que coincida con los valores de retorno esperados y de los argumentos esperados; las funciones read y write invierten los argumentos para que coincidan con las versiones POSIX.


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage(const char *name, const char *theme, int size)
XcursorImages *XcursorLibraryLoadImages(const char *name, const char *theme, int size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se utiliza ese.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, se utiliza “default” como nombre del tema.
  • Si ninguna de las búsquedas tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

NAME


Xcursor - Cursor loading library






SYNOPSIS


#include <X11/Xcursor/Xcursor.h>







DESCRIPTION


The Xcursor library provides functions for loading, manipulating,
    and displaying cursors. It supports various cursor formats, including animated
    cursors and cursors with alpha channels. It also allows for theming and
    customization of cursors.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for
    “t”, “1”, “y” or
    “on”

  

  
false for
    “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.





  
XCURSOR_

  





  

  
This variable tells Xcursor whether to enable themes for core cursors,
      if the display supports it.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.
