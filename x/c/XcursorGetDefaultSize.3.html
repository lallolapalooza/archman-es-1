XCURSOR(3) Versión X 11 XCURSOR(3)

NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursor desde archivos. Encima de eso hay una capa que localiza archivos de cursor basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores ya sea a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere utilizar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSOR

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar varios cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los utilicen como una secuencia animada.

Los archivos de cursor se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo tiene el siguiente aspecto:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada fragmento del archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursor; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imágenes tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayor parte) sigue la especificación freedesktop.org para tematizar iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio de cursores.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio de cursores, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Name” (es decir, el nombre que una aplicación gráfica puede utilizar como nombre de presentación).

Se puede enumerar más de un nombre-del-tema en la línea Hereda=. La especificación freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación freedesktop.org no aclara si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema de “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
almacena una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más alto. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
almacena múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Almacena múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* recuento de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a f de stdio

NAME


libXcursor - X cursor management library






SYNOPSIS


#include <Xcursor/Xcursor.h>







DESCRIPTION


The Xcursor library provides functions for loading, creating, and
    managing cursors for the X Window System. It supports various cursor formats,
    including animated cursors and cursors with alpha channels.




Cursor Structures


The library defines several structures for representing cursors:



  
XcursorImage

  
Represents a single cursor image, including its dimensions, hotspot, and
      pixel data (usually RGBA). Note that the pixel data is not in standard
      XImage format.

  
XcursorImages

  
A list of XcursorImage structures, representing all the images for a
      single cursor name (e.g., "left_ptr"). It also stores the name of the
      cursor.

  
XcursorComment

  
Represents a single comment associated with a cursor.

  
XcursorComments

  
A list of XcursorComment structures.

  
XcursorCursors

  
A dynamically sized array of XcursorImages structures. This is used to
      hold all the cursors that are part of a cursor theme.

  
XcursorAnimate

  
A structure used to manage animated cursors. It contains a pointer to an
      XcursorCursors array and a sequence number.

ENVIRONMENT


Several environment variables can be used to configure the behavior
    of the Xcursor library, overriding resource settings and compiled-in defaults.


Boolean environment variables accept the following values:





  
true

  
Accepts 't', '1', 'y', or 'on'.

  
false

  
Accepts 'f', '0', 'n', or 'off'.






Any other value for boolean variables is ignored.



  
HOME

  
If the path search list contains '~', this variable is used to expand it
      to the user's home directory, instead of querying the password database.

  
XCURSOR_ANIM

  
Controls whether animated cursors are used. If the display supports
      Render CreateCursor and the Render feature is enabled, setting this to
      false disables animated cursors. Defaults to using the
      Xcursor.anim resource. If neither is set, animated cursors are
      enabled by default if supported.

  
XCURSOR_CORE

  
Controls whether the Render feature is used for cursors. Setting this to
      false disables the Render feature. Defaults to using the
      Xcursor.core resource. If neither is set, the Render feature is
      enabled by default if supported.

  
XCURSOR_DISCOVER

  
If set, enables a debugging feature that logs cursor hashes and image data.
      This helps in identifying which cursor name is associated with which image.
      There is no corresponding resource setting.

  
XCURSOR_DITHER

  
Specifies the dithering method to use. Defaults to the
      Xcursor.dither resource. If neither is set, it defaults to
      "threshold". Recognized values are:
    

      
diffuse

      
median

      
ordered

      
threshold

    

  

  
XCURSOR_PATH

  
Defines a colon-separated list of directories to search for cursor themes
      and files, overriding the compiled-in default search path.

  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to match the default size if set to
      true. Defaults to the Xcursor.resized resource. If neither
      is set, automatic resizing is disabled by default.

  
XCURSOR_SIZE

  
Specifies the preferred cursor size in pixels. Defaults to the
      Xcursor.size resource. If neither is set, it attempts to derive a
      size from the Xft.dpi resource. If that's also unavailable, it
      defaults to a size based on the display height (typically height/48).

  
XCURSOR_THEME

  
Selects the cursor theme to use. Defaults to the Xcursor.theme
      resource. If neither is set, the system default theme is used.

  
XCURSOR_THEME_CORE

  
Determines whether to use core X cursors when a theme is active. Defaults
      to the Xcursor.theme_core resource. If neither is set, the behavior
      depends on the theme's capabilities.

NAME


XcursorGetDefaultSize, XcursorSetDefaultSize, XcursorGetTheme, XcursorSetTheme, XcursorGetThemeCore, XcursorSetThemeCore — get and set default cursor size and theme






SYNOPSIS


#include <Xcursor/Xcursor.h>
int XcursorGetDefaultSize(Display *display);
void XcursorSetDefaultSize(Display *display, int size);
const char *XcursorGetTheme(Display *display);
void XcursorSetTheme(Display *display, const char *theme_name);
int XcursorGetThemeCore(Display *display);
void XcursorSetThemeCore(Display *display, int enable);







DESCRIPTION


The Xcursor library provides functions for loading and using Xcursor
    cursor images.


XcursorGetDefaultSize returns the default cursor size for the
    display.


XcursorSetDefaultSize sets the default cursor size for the display.
    This is the size that will be used for cursors if no other size is specified.
    The size argument is the desired size in pixels. A size of 0 means
    use the default size for the cursor theme.


XcursorGetTheme returns the name of the cursor theme currently in
    use for the display.


XcursorSetTheme sets the cursor theme for the display. The
    theme_name argument is the name of the theme to load. If
    theme_name is NULL, the default theme will be loaded.


XcursorGetThemeCore returns whether core cursors are themed.
    A return value of 1 means core cursors are themed, 0 means they are not.


XcursorSetThemeCore enables or disables theming of core cursors.
    If enable is non-zero, core cursors will be themed. If
    enable is zero, core cursors will not be themed.






FUNCTIONAL OVERVIEW


The Xcursor library handles the loading and management of Xcursor
    cursor themes. Themes are collections of cursor images that can be used to
    customize the appearance of the mouse pointer.


The library provides functions for setting and getting the default
    cursor size and theme. It also allows for controlling whether core cursors
    are themed.






DATATYPES


The library uses the following data types:



  
Display

  
A pointer to an X display structure. This structure contains information
      about the connection to the X server.

  
const char *

  
A pointer to a null-terminated string. Used for theme names.

  
int

  
An integer. Used for cursor sizes and enable/disable flags.








FUNCTIONS



  
XcursorGetDefaultSize

  
Returns the default cursor size for the display.

  
XcursorSetDefaultSize

  
Sets the default cursor size for the display.

  
XcursorGetTheme

  
Returns the name of the current cursor theme.

  
XcursorSetTheme

  
Sets the cursor theme for the display.

  
XcursorGetThemeCore

  
Returns whether core cursors are themed.

  
XcursorSetThemeCore

  
Enables or disables theming of core cursors.








ENVIRONMENT



  
XCURSOR_SIZE

  
Specifies the default cursor size. If set to a positive integer, that
      integer is used as the default size. Otherwise, the value from the
      Xcursor.default_size resource is used.





  
XCURSOR_THEME

  
Specifies the default cursor theme. If set to a non-empty string, that
      string is used as the default theme name. Otherwise, the value from the
      Xcursor.theme resource is used.





  
XCURSOR_THEME_CORE

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.
