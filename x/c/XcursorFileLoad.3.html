NOMBRE

Xcursor - Gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

DESCRIPCIÓN FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas de archivos, Xcursor prefiere utilizar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor X estándar y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos (chunks). La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imágenes tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual que 0x7fff
alto:	CARD32 Debe ser menor o igual que 0x7fff
xhot:	CARD32 Debe ser menor o igual que el ancho
yhot:	CARD32 Debe ser menor o igual que el alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor sigue (en su mayor parte) la especificación de freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de la forma del cursor, p. ej., como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ninguna parte de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, usando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úselo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, use "default" como nombre del tema.
  • Si ninguna de las búsquedas tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

ENTORNO


Las variables de entorno se pueden usar para anular la configuración
    de recursos, que a su vez anula los valores predeterminados compilados.


Algunas de las variables de entorno reconocidas por Xcursor son
    booleanas, especificadas de la siguiente manera:





  
verdadero para
    “t”, “1”, “y” o
    “on”

  

  
falso para
    “f”, “0”, “n” o
    “off”

  






Xcursor ignora otros valores para estas booleanas.



  
HOME

  
Xcursor interpreta “~” en la lista de búsqueda como el directorio
      personal, utilizando esta variable en lugar de la base de datos de
      contraseñas.

  
XCURSOR_ANIM

  
Si la pantalla soporta la solicitud Render CreateCursor y la función Render
      está habilitada, deshabilita los cursores animados si la variable
      de entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.anim.





  
XCURSOR_CORE

  
Si la pantalla soporta la solicitud Render CreateCursor, deshabilita la
      función Render si la variable de entorno es false.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.core.





  
XCURSOR_DISCOVER

  
Si la variable está establecida, Xcursor activa una función de registro.
      Muestra el valor hash y la imagen para que los usuarios puedan ver qué
      nombre de cursor está asociado con cada imagen.





  

  
No hay una configuración de recurso correspondiente.





  
XCURSOR_DITHER

  
Esta variable establece el dither deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso
      Xcursor.dither.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor usa
      “threshold”

  

  
Estos son los valores reconocidos:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
Esta variable establece la lista de rutas en las que buscar cursores, en
      lugar de la lista predeterminada compilada.





  

  
Los directorios en esta ruta están separados por dos puntos (:).





  
XCURSOR_RESIZED

  
Habilita el redimensionamiento automático de cursores para mejorar su
      tamaño mostrado si la variable de entorno es true.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.resized.





  
XCURSOR_SIZE

  
Esta variable establece el tamaño deseado del cursor, en píxeles.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.size.

  

  
Si no se proporciona ningún tamaño, ya sea por variable de entorno o por
      configuración de recurso, Xcursor a continuación prueba la configuración
      del recurso Xft.dpi para adivinar el tamaño de un cursor de 16
      puntos.

  

  
Finalmente, si Xft.dpi no está establecido, Xcursor utiliza la
      altura de la pantalla, dividiendo por 48 (asumiendo que la altura es
      768).





  
XCURSOR_THEME

  
Esta variable selecciona el tema deseado.





  

  
Si no se proporciona la variable de entorno, Xcursor prueba el recurso
      Xcursor.theme.

  

  
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor usa el
      tema predeterminado.

NAME


XcursorFileLoad, XcursorFileLoadImage - load a cursor image from a file






SYNOPSIS


#include <Xcursor/Xcursor.h>


XcursorImage *XcursorFileLoad(const char *fileName);

XcursorImage *XcursorFileLoadImage(const char *fileName, const char *imageName);






DESCRIPTION


The function XcursorFileLoad loads a cursor image
    from the file named fileName. The file is expected to
    be in the Xcursor file format (typically ending in .xcur). This format is
    documented in the Xcursor file format specification.


The function XcursorFileLoadImage is similar
    to XcursorFileLoad, but allows you to load a specific
    image from within the file by providing its name in imageName.


Both functions return a pointer to a newly allocated
    XcursorImage structure, which contains the cursor
    data. The memory for this structure must be freed by the caller using
    XcursorFileDestroy.


If the specified file or image cannot be found, or if an error
    occurs during loading, these functions will return NULL.






FUNCTIONAL OVERVIEW


These functions are part of the Xcursor library, which provides
    support for loading and managing cursor images in the X Window System. The
    Xcursor file format is a relatively new format designed to store cursor
    images efficiently, including support for different sizes, depths, and
    animations.






DATATYPES



  
XcursorImage

  
This structure represents a cursor image. It contains fields such as width,
      height, xhot, yhot (the hotspot coordinates), and a pointer to the pixel
      data. It may also contain information for animation frames.








FUNCTIONS



  
XcursorFileLoad

  
Loads the first cursor image found in the specified file.

  
XcursorFileLoadImage

  
Loads a specific cursor image by name from the specified file.

  
XcursorFileDestroy

  
Frees the memory allocated for an XcursorImage structure
      by XcursorFileLoad or XcursorFileLoadImage.








ENVIRONMENT



  
Xcursor.theme

  
Specifies the name of the cursor theme to use. If set, applications will
      try to load cursors from this theme.

  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.

NOMBRE


XcursorFileLoad, XcursorFileLoadImage - cargar una imagen de cursor desde un archivo






SINOPSIS


#include <Xcursor/Xcursor.h>


XcursorImage *XcursorFileLoad(const char *fileName);

XcursorImage *XcursorFileLoadImage(const char *fileName, const char *imageName);






DESCRIPCIÓN


La función XcursorFileLoad carga una imagen de
    cursor desde el archivo llamado fileName. Se espera que el
    archivo esté en el formato de archivo Xcursor (generalmente con extensión
    .xcur). Este formato está documentado en la especificación del formato de
    archivo Xcursor.


La función XcursorFileLoadImage es similar a
    XcursorFileLoad, pero le permite cargar una imagen
    específica dentro del archivo proporcionando su nombre en
    imageName.


Ambas funciones devuelven un puntero a una estructura
    XcursorImage recién asignada, que contiene los datos
    del cursor. La memoria para esta estructura debe ser liberada por el
    llamador usando XcursorFileDestroy.


Si el archivo o imagen especificados no se encuentran, o si ocurre
    un error durante la carga, estas funciones devolverán NULL.






VISIÓN GENERAL FUNCIONAL


Estas funciones forman parte de la biblioteca Xcursor, que proporciona
    soporte para cargar y gestionar imágenes de cursor en el sistema de ventanas
    X. El formato de archivo Xcursor es un formato relativamente nuevo diseñado para
    almacenar imágenes de cursor de manera eficiente, incluyendo soporte para
    diferentes tamaños, profundidades y animaciones.






TIPOS DE DATOS



  
XcursorImage

  
Esta estructura representa una imagen de cursor. Contiene campos como
      ancho, alto, xhot, yhot (las coordenadas del punto de activación) y un
      puntero a los datos de píxeles. También puede contener información para
      fotogramas de animación.








FUNCIONES



  
XcursorFileLoad

  
Carga la primera imagen de cursor encontrada en el archivo especificado.

  
XcursorFileLoadImage

  
Carga una imagen de cursor específica por nombre desde el archivo
      especificado.

  
XcursorFileDestroy

  
Libera la memoria asignada para una estructura XcursorImage
      por XcursorFileLoad o XcursorFileLoadImage.








ENTORNO



  
Xcursor.theme

  
Especifica el nombre del tema del cursor a utilizar. Si está configurado,
      las aplicaciones intentarán cargar cursores desde este tema.

  
Xcursor.theme_core

  
Habilita los temas para los cursores principales si la variable de entorno
      es true.





  

  
Si la variable de entorno no se proporciona, Xcursor intenta el recurso
      Xcursor.theme_core.

    XcursorSetThemeCore.
