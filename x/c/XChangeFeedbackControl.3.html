Paquete: libxi

XGETFEEDBACKCONTROL(3)   XGETFEEDBACKCONTROL(3)

NOMBRE

XGetFeedbackControl, XChangeFeedbackControl - consultar y cambiar los retroalimentaciones de dispositivos de entrada

SINOPSIS

#include <X11/extensions/XInput.h>
XFeedbackState *XGetFeedbackControl( Display *display,
                                     XDevice *device,
                                     int *num_feedbacks);
int XChangeFeedbackControl( Display *display,
                            XDevice *device,
                            Mask mask,
                            XFeedbackControl *control);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyas retroalimentaciones se van a consultar
       o modificar.
num_feedbacks
       Especifica una dirección a la que se va a devolver el número de retroalimentaciones
       soportadas por el dispositivo.
mask
       Especifica una máscara específica para cada tipo de retroalimentación que
       describe cómo se va a modificar la retroalimentación.
control
       Especifica la dirección de una estructura XFeedbackControl
       que contiene los nuevos valores para la retroalimentación.

DESCRIPCIÓN

Estas solicitudes se proporcionan para manipular aquellos dispositivos de entrada
que soportan retroalimentaciones. Se generará un error BadMatch si
el dispositivo solicitado no soporta retroalimentaciones. Si un
dispositivo dado soporta retroalimentaciones se puede determinar
examinando la información devuelta por la solicitud XOpenDevice.
Para aquellos dispositivos que soportan retroalimentaciones, XOpenDevice
devolverá una estructura XInputClassInfo con el campo input_class igual a
la constante FeedbackClass (definida en el archivo XI.h).
La solicitud XGetFeedbackControl devuelve un puntero a una lista de
estructuras XFeedbackState. Cada elemento de esta lista describe una
de las retroalimentaciones soportadas por el dispositivo.
Los elementos son de longitud variable, por lo que cada uno contiene su longitud para permitir el avance al siguiente elemento de la lista.
Las clases de retroalimentación que están actualmente definidas son:
KbdFeedbackClass, PtrFeedbackClass, StringFeedbackClass,
IntegerFeedbackClass, LedFeedbackClass y BellFeedbackClass.
Estas constantes están definidas en el archivo XI.h. Un dispositivo de entrada puede
soportar cero o más clases de retroalimentación, y puede soportar
múltiples retroalimentaciones de la misma clase. Cada retroalimentación contiene un identificador de clase y un id
que es único dentro de esa clase para ese dispositivo de entrada. El id se utiliza para identificar la retroalimentación al realizar una solicitud XChangeFeedbackControl.
XGetFeedbackControl puede generar un error BadDevice o BadMatch.
La solicitud XChangeFeedbackControl modifica los valores de una
retroalimentación en el dispositivo especificado. La retroalimentación se identifica por el campo id
de la estructura XFeedbackControl que se pasa con la solicitud.
Los campos de la retroalimentación que se van a modificar se identifican por los bits de la máscara que se pasa
con la solicitud.
XChangeFeedbackControl puede generar un error BadDevice, BadMatch o
BadValue.

Estructuras

Cada clase de retroalimentación se describe mediante una estructura específica para
esa clase. Estas estructuras están definidas en el archivo XInput.h.
XFeedbackState y XFeedbackControl son estructuras genéricas que
contienen tres campos que están al principio de cada clase de retroalimentación:
typedef struct {
    XID class;
    int length;
    XID id;
} XFeedbackState, XFeedbackControl;
La estructura XKbdFeedbackState define los atributos que se devuelven para retroalimentaciones equivalentes a las del teclado X.
typedef struct {
    XID class;
    int length;
    XID id;
    int click;
    int percent;
    int pitch;
    int duration;
    int led_mask;
    int global_auto_repeat;
    char auto_repeats[32];
} XKbdFeedbackState;
La estructura XPtrFeedbackState define los atributos que se devuelven para retroalimentaciones equivalentes a las del puntero X.
typedef struct {
    XID class;
    int length;
    XID id;
    int accelNum;
    int accelDenom;
    int threshold;
} XPtrFeedbackState;
La estructura XIntegerFeedbackState define los atributos que se devuelven para retroalimentaciones de enteros.
typedef struct {
    XID class;
    int length;
    XID id;
    int resolution;
    int minVal;
    int maxVal;
} XIntegerFeedbackState;
La estructura XStringFeedbackState define los atributos que se devuelven para retroalimentaciones de cadenas.
typedef struct {
    XID class;
    int length;
    XID id;
    int max_symbols;
    int num_syms_supported;
    KeySym *syms_supported;
} XStringFeedbackState;
La estructura XBellFeedbackState define los atributos que se devuelven para retroalimentaciones de campana.
typedef struct {
    XID class;
    int length;
    XID id;
    int percent;
    int pitch;
    int duration;
} XBellFeedbackState;
La estructura XLedFeedbackState define los atributos que se devuelven para retroalimentaciones de LED.
typedef struct {
    XID class;
    int length;
    XID id;
    int led_values;
} XLedFeedbackState;
La estructura XPrtFeedbackControl define los atributos que se pueden controlar para las retroalimentaciones del puntero.
typedef struct {
    XID class;
    int length;
    XID id;
    int accelNum;
    int accelDenom;
    int threshold;
} XPtrFeedbackControl;
La estructura XKbdFeedbackControl define los atributos que se pueden controlar para las retroalimentaciones del teclado.
typedef struct {
    XID class;
    int length;
    XID id;
    int click;
    int percent;
    int pitch;
    int duration;
    int led_mask;
    int led_value;
    int key;
    int auto_repeat_mode;
} XKbdFeedbackControl;
La estructura XStringFeedbackControl define los atributos que se pueden controlar para las retroalimentaciones de cadenas.
typedef struct {
    XID class;
    int length;
    XID id;
    int num_keysyms;
    KeySym  *syms_to_display;
} XStringFeedbackControl;
La estructura XIntegerFeedbackControl define los atributos que se pueden controlar para las retroalimentaciones de enteros.
typedef struct {
    XID class;
    int length;
    XID id;
    int int_to_display;
} XIntegerFeedbackControl;
La estructura XBellFeedbackControl define los atributos que se pueden controlar para las retroalimentaciones de campana.
typedef struct {
    XID     class;
    int     length;
    XID     id;
    int     percent;
    int     pitch;
    int     duration;
} XBellFeedbackControl;
La estructura XLedFeedbackControl define los atributos que se pueden controlar para las retroalimentaciones de LED.
typedef struct {
    XID     class;
    int     length;
    XID     id;
    int     led_mask;
    int     led_values;
} XLedFeedbackControl;

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si algún
       otro cliente ha causado que el dispositivo especificado se convierta en el
       teclado X o el dispositivo de puntero X a través de las
       solicitudes XChangeKeyboardDevice o XChangePointerDevice.
BadMatch
       Este error puede ocurrir si se realizó una solicitud XGetFeedbackControl
       especificando un dispositivo que no tiene retroalimentaciones, o
       se realizó una solicitud XChangeFeedbackControl con una
       estructura XFeedbackControl que contiene un tipo de retroalimentación inválido.
       También puede ocurrir si se especifica una combinación inválida de bits de máscara
       (DvKey pero sin DvAutoRepeatMode para retroalimentaciones de teclado), o si se especifica un
       KeySym inválido para una retroalimentación de cadena.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud XChangeFeedbackControl. A menos que se
       especifique un rango para un argumento, se acepta el rango completo
       definido por el tipo del argumento. Cualquier
       argumento definido como un conjunto de alternativas puede generar
       este error.
