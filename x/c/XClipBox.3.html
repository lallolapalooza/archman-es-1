XPolygonRegion(3) FUNCIONES XLIB XPolygonRegion(3)

NOMBRE

XPolygonRegion, XClipBox - generar regiones

SINTAXIS

Region XPolygonRegion(XPoint puntos[], int n, int regla_relleno);

int XClipBox(Region r, XRectangle *rect_devolucion);

ARGUMENTOS

regla_relleno
Especifica la regla de relleno que desea establecer para el GC especificado. Puede pasar EvenOddRule o WindingRule.
n
Especifica el número de puntos en el polígono.
puntos
Especifica un array de puntos.
r
Especifica la región.
rect_devolucion
Devuelve el rectángulo envolvente más pequeño.

DESCRIPCIÓN

La función XPolygonRegion devuelve una región para el polígono definido por el array de puntos. Para una explicación de rule_fill, consulte XCreateGC.

La función XClipBox devuelve el rectángulo más pequeño que encierra la región especificada.

VER TAMBIÉN

XCreateGC(3), XDrawPoint(3), XDrawRectangle(3)
