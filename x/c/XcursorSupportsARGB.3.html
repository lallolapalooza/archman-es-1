XcursorSupportsARGB(3)

Paquete: libxcursor

Licencias: HPND-sell-variant

XCURSOR(3) Versión X 11 XCURSOR(3)

NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres estándar de cursores de X. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

DESCRIPCIÓN FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores ya sea a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas de archivos, Xcursor prefiere usar la solicitud `CreateCursor` de la extensión Render si el servidor X la soporta. Donde no se soporta, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud `CreateCursor` principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor se etiqueta con un tamaño nominal para que el mejor tamaño se pueda seleccionar automáticamente. Múltiples cursores del mismo tamaño nominal se pueden cargar juntos; se espera que las aplicaciones los usen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo tiene el siguiente aspecto:


mágic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del contenido en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentarios son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imagen son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 el subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayor parte) sigue la especificación de freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en `XcursorLibraryLoadImage` o `XcursorLibraryShape`.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas en este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org establece que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más significativo. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras `XcursorImage`. Todas se liberan cuando se liberan las `XcursorImages` en `XcursorImagesDestroy`. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* array de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras `XcursorAnimate` puedan usar el mismo `XcursorCursors`. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras `XcursorAnimate` pueden hacer referencia al mismo `XcursorCursors`; cada una mantiene una referencia que se elimina cuando se libera la `XcursorAnimate`. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio

APIs de índice

XcursorBool XcursorIndexClear (
	XcursorIndex 	*index)

Elimina todos los cursores del índice dado. El índice se vacía, pero no se elimina la memoria asignada para el índice.

XcursorBool XcursorIndexCreate (
	XcursorIndex 	**index_return)

Crea un nuevo índice vacío y lo devuelve en index_return.

void XcursorIndexDestroy (
	XcursorIndex 	*index)

Elimina el índice dado y toda la memoria asociada.

XcursorBool XcursorIndexFindName (
	XcursorIndex 	*index,
	const char 	*name,
	int 	 size,
	int 	 direction,
	Cursor 	*cursor_return)

Busca un cursor en el índice por nombre, tamaño y dirección. Si se encuentra, el identificador del cursor se devuelve en cursor_return.

XcursorBool XcursorIndexFindSerial (
	XcursorIndex 	*index,
	int 	 serial,
	int 	 size,
	int 	 direction,
	Cursor 	*cursor_return)

Busca un cursor en el índice por número de serie, tamaño y dirección. Si se encuentra, el identificador del cursor se devuelve en cursor_return.

XcursorBool XcursorIndexLoad (
	XcursorIndex 	*index,
	Display 	*dpy,
	const char 	*theme)

Carga cursores desde el tema dado y los almacena en el índice proporcionado. La búsqueda de temas se realiza a través de la ruta definida por la variable de entorno XCURSOR_PATH.

XcursorBool XcursorIndexPush (
	XcursorIndex 	*index,
	XcursorImage 	*image,
	const char 	*name,
	int 	 size,
	int 	 direction)

Inserta una imagen de cursor en el índice. Si el nombre, tamaño y dirección ya existen, se reemplaza la imagen antigua. De lo contrario, se agrega un nuevo elemento al índice.

XcursorBool XcursorIndexPushName (
	XcursorIndex 	*index,
	const char 	*name)

Inserta un nombre en el índice. Si el nombre ya existe, no hace nada. De lo contrario, agrega el nombre al índice. Esto se usa para encontrar cursores que no tienen un tamaño definido. Tenga en cuenta que el índice debe haber sido inicializado con XcursorIndexCreate, y que muchos punteros estarán en el índice.

Cursores animados

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Envuelve la matriz de cursores dada en una estructura XcursorAnimate recién asignada, que agrega un número de secuencia utilizado en XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Descarta los datos animate dados, liberando tanto la matriz de cursores XcursorCursors como la estructura XcursorAnimate.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Devuelve cíclicamente el siguiente Cursor en la matriz, incrementando el número de secuencia para prepararse para la próxima llamada.

El llamador es responsable de mostrar la serie de imágenes de Cursor. Xcursor no hace eso.

APIs de cursores de glifos

Las funciones X11 XCreateFontCursor y XCreateGlyphCursor utilizan esta parte de la API para extender la característica de cursores principales de X para usar temas.

void XcursorImageHash (
	XImage 	*image,
	unsigned char 	 hash[XCURSOR_BITMAP_HASH_SIZE])

Calcula un hash de la imagen, para mostrar cuando la variable de entorno XCURSOR_DISCOVER está configurada.

void XcursorImagesSetName (
	XcursorImages 	*images,
	const char 	*name)

Asocia el nombre dado con las imágenes.

void XcursorNoticeCreateBitmap (
	Display 	*dpy,
	Pixmap 	 pid,
	unsigned int 	 width,
	unsigned int 	 height)

Verifica si la pantalla admite ARGB o temas, y también si el tamaño de la imagen cabe dentro del tamaño máximo del cursor (64 píxeles). Si es así, crea un mapa de bits del tamaño especificado y almacena el resultado en caché en Xcursor, identificándolo con el valor del ID de Pixmap (pid).

void XcursorNoticePutBitmap (
	Display 	*dpy,
	Drawable 	 draw,
	XImage 	*image)

Actualiza el contenido de la imagen en el mapa de bits especificado por el valor de dibujo (un ID de Pixmap). El mapa de bits debe haber sido creado por XcursorNoticeCreateBitmap.

Cursor XcursorTryShapeBitmapCursor (
	Display 	*dpy,
	Pixmap 	 source,
	Pixmap 	 mask,
	XColor 	*foreground,
	XColor 	*background,
	unsigned int 	 x,
	unsigned int 	 y)

Si la pantalla admite ARGB o temas, intenta cargar un cursor en la caché de Xcursor usando el parámetro source como ID de Pixmap. Es posible que la fuente ya no esté en la caché. Xcursor usa el valor hash para identificar la imagen deseada.

Cursor XcursorTryShapeCursor (
	Display 	*dpy,
	Font 	 source_font,
	Font 	 mask_font,
	unsigned int 	 source_char,
	unsigned int 	 mask_char,
	XColor _Xconst 	*foreground,
	XColor _Xconst 	*background)

Si la pantalla admite ARGB o temas, intenta cargar un cursor en la caché de Xcursor usando el parámetro source_char como forma. Usando

  • el tamaño predeterminado de XcursorGetDefaultSize,
  • el tema predeterminado de XcursorGetTheme, y
  • el parámetro source_char como forma,
Xcursor llama a XcursorShapeLoadImages para cargar las imágenes del cursor. Si tiene éxito, Xcursor utiliza XcursorImagesLoadCursor para cargar la información del cursor.

ENTORNO

Las variables de entorno se pueden utilizar para anular la configuración de recursos, que a su vez anulan los valores predeterminados compilados.

Algunas de las variables de entorno reconocidas por Xcursor son booleanas, especificadas de la siguiente manera:

verdadero para "t", "1", "y" o "on"
falso para "f", "0", "n" o "off"

Xcursor ignora otros valores para estos booleanos.

HOME
Xcursor interpreta "~" en la lista de búsqueda como el directorio principal, utilizando esta variable en lugar de la base de datos de contraseñas.
XCURSOR_ANIM
Si la pantalla admite la solicitud Render CreateCursor y la función Render está habilitada, deshabilita los cursores animados si la variable de entorno es false.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.anim.
XCURSOR_CORE
Si la pantalla admite la solicitud Render CreateCursor, deshabilita la función Render si la variable de entorno es false.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.core.
XCURSOR_DISCOVER
Si la variable está configurada, Xcursor activa una función de registro. Muestra el valor hash y la imagen para que los usuarios puedan ver qué nombre de cursor está asociado con cada imagen.
No hay una configuración de recurso correspondiente.
XCURSOR_DITHER
Esta variable establece el dither deseado.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.dither.
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza "threshold".
Estos son los valores reconocidos:
diffuse
median
ordered
threshold
XCURSOR_PATH
Esta variable establece la lista de rutas en las que buscar cursores, en lugar de la lista predeterminada compilada.
Los directorios en esta ruta están separados por dos puntos (:).
XCURSOR_RESIZED
Habilita el redimensionamiento automático de cursores para mejorar su tamaño mostrado si la variable de entorno es true.
Si no se proporciona la variable de entorno, Xcursor intenta el recurso Xcursor.resized.
XCURSOR_SIZE
Esta variable establece el tamaño deseado del cursor, en píxeles.
Si no se proporciona la variable de entorno, Xcursor intenta el recurso Xcursor.size.
Si no se proporciona ningún tamaño, ni por variable de entorno ni por recurso, Xcursor intenta a continuación la configuración del recurso Xft.dpi para adivinar el tamaño de un cursor de 16 puntos.
Finalmente, si Xft.dpi no está configurado, Xcursor utiliza la altura de la pantalla, dividiendo por 48 (asumiendo que la altura es 768).
XCURSOR_THEME
Esta variable selecciona el tema deseado.
Si no se proporciona la variable de entorno, Xcursor intenta el recurso Xcursor.theme.
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza el tema predeterminado.

);

DESCRIPTION

The XcursorSupportsARGB function returns true if the server and the cursor extension support ARGB cursors, and false otherwise. Applications should call this function to determine if they can use ARGB cursors.

The XcursorGetDefaultTheme function returns the name of the default cursor theme for the given screen on the display dpy. This is typically derived from the XCURSOR_THEME environment variable, or the Xcursor.theme_default X resource.

The XcursorGetTheme function returns the name of the cursor theme currently in use for the given screen on the display dpy. This may be NULL if no theme is currently set.

The XcursorSetTheme function sets the cursor theme for all screens on the display dpy to theme_name. If theme_name is NULL, the default theme is restored. This function attempts to load the specified theme.

The XcursorSetThemeCore function sets the cursor theme for core cursors only. This is used when the XCURSOR_THEME_CORE environment variable is set. See the ENVIRONMENT section.

FUNCTIONAL OVERVIEW

The libXcursor library provides functions to load and manage X cursor images. It supports the standard X cursor fonts and also allows loading themes of cursors according to the Icon Theme Specification.

Themes are searched for in the standard theme directories, such as /usr/share/icons/. The specific theme to be used can be set using the XcursorSetTheme function, or via the XCURSOR_THEME environment variable.

The library attempts to load the cursors defined by the theme. If the theme is not found or does not contain the requested cursor, it falls back to the default theme or standard X cursors.

Support for ARGB cursors is also provided. Applications can check for support using XcursorSupportsARGB before attempting to load ARGB cursor images.

DATATYPES

XcursorCursor: A structure representing a cursor, typically containing its image data, hotspot, and dimensions.

XcursorImages: A structure containing an array of XcursorCursor structures, used to represent a cursor theme or a set of animated cursors.

ENVIRONMENT

XCURSOR_THEME
Specifies the cursor theme to be loaded by default. If this environment variable is set, it overrides any theme specified by the Xcursor.theme X resource. If not set, XcursorGetDefaultTheme falls back to the X resource.
XCURSOR_THEME_CORE
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.
