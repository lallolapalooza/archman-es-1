XcursorXcFileLoadAllImages(3)

Paquete: libxcursor

Licencias: HPND-sell-variant

XcursorXcFileLoadAllImages(3) X Version 11 XcursorXcFileLoadAllImages(3)

NOMBRE

XcursorXcFileLoadAllImages - Cargar todos los cursores desde un archivo.

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

XcursorImages *
XcursorXcFileLoadAllImages(XcursorFile *file);

DESCRIPCIÓN

La función XcursorXcFileLoadAllImages lee todos los cursores del archivo especificado por file. El archivo debe estar abierto en modo binario y el puntero del archivo debe estar posicionado al inicio de un archivo de cursores Xcursor válido. El objeto XcursorFile* se crea usando XcursorXcFileOpen().

Si la operación es exitosa, se devuelve un puntero a una estructura XcursorImages. Esta estructura contiene una matriz de punteros a estructuras XcursorImage, cada una representando un cursor. La memoria asignada para esta estructura y sus miembros debe liberarse utilizando XcursorImagesDestroy().

Si ocurre un error durante la lectura o análisis del archivo, se devuelve NULL.

ARGUMENTOS

XcursorFile *file
Un puntero a un objeto XcursorFile previamente inicializado, que representa el archivo de cursores abierto.

VALOR DE RETORNO

Devuelve un puntero a una estructura XcursorImages si la carga tiene éxito, o NULL si ocurre un error.

VER TAMBIÉN

XcursorFileOpen(3), XcursorXcFileLoadImage(3), XcursorImagesDestroy(3)

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úselo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, use "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

NAME

                    
Xcursor, XcursorGetDefaultTheme, XcursorGetDefaultSize, XcursorSetDefaultTheme, XcursorSetDefaultSize, XcursorGetTheme, XcursorSetTheme, XcursorGetThemeSize, XcursorSetThemeSize, XcursorGetCursor, XcursorGetDefault, XcursorCreatePnP, XcursorCreatePixmap, XcursorCreateFont, XcursorCreateNone, XcursorDestroy, XcursorBlock, XcursorUnblock, XcursorGetDefaultClass, XcursorGetDefaultSubclass, XcursorGetClass, XcursorGetSubclass, XcursorGetCursorName, XcursorGetCursorImage, XcursorGetColor, XcursorGetImage, XcursorGetImageSize, XcursorGetHotspot, XcursorGetMaxWidth, XcursorGetMaxHeight, XcursorGetWidth, XcursorGetHeight, XcursorGetSize, XcursorGetColorMap, XcursorGetAlpha, XcursorGetImageSize32, XcursorGetPointer, XcursorSetPointer, XcursorXcFileLoadAllImages, XcursorXcFileLoadImage, XcursorXcFileSaveAllImages, XcursorXcFileSaveImage, XcursorXcFileCreate, XcursorXcFileDestroy, XcursorGetThemeCore, XcursorSetThemeCore - Cursor loading and management library

                

                

                    
SYNOPSIS

                    
#include <Xcursor/Xcursor.h>
                    

                

                

                    
DESCRIPTION

                    
The Xcursor library provides functions for loading,
                        managing, and creating cursor images. It supports various
                        cursor formats, including Xcursor, XBM, and Pixmap. The library
                        allows applications to set and get default cursor themes and sizes,
                        as well as individual cursor properties.

                    
Key features include:

                    
    
                        
  • Loading cursors from files and applications.
    • 
                        
  • Managing cursor themes and sizes.
    • 
                        
  • Creating cursors from Pixmaps, XBMs, and other sources.
    • 
                        
  • Setting and getting cursor hot spots and colors.
    • 
                        
  • Support for animated cursors.
    • 
                        
  • Integration with X rendering extensions.
    • 
                    

                

                

                    
FUNCTIONAL OVERVIEW

                    

                        
Cursor Loading:

                        
Functions like XcursorXcFileLoadAllImages and
                            XcursorXcFileLoadImage are used to load cursor data
                            from files. The library automatically detects the cursor
                            format.

                        
Cursor Management:

                        
Functions like XcursorSetTheme, XcursorGetTheme,
                            XcursorSetDefaultTheme, and
                            XcursorGetDefaultTheme allow applications to specify and
                            query cursor themes and their default settings.

                        
Cursor Creation:

                        
Various functions like XcursorCreatePixmap,
                            XcursorCreateFont, and XcursorCreatePnP enable the
                            creation of cursor objects from different sources, such as
                            X Pixmaps, font characters, or predefined cursor shapes.

                        
Cursor Properties:

                        
Functions like XcursorGetHotspot, XcursorGetColor,
                            and XcursorGetImage retrieve specific properties of a
                            cursor, including its hotspot, color information, and image
                            data.

                        
Theme Configuration:

                        
The library reads configuration from
                            ~/.icons/ and
                            /usr/share/icons/ directories for cursor
                            themes. The Icon Theme Specification (see SEE ALSO)
                            details the structure and format of these themes.

                    

                

                

                    
DATATYPES

                    
The library defines several key data types:

                    

                        
XcursorImage:

                        
Represents a single cursor image, including its dimensions,
                            hotspot, delay (for animations), and pixel data.

                        
XcursorChunk:

                        
A structure used internally for managing cursor data chunks,
                            particularly during file loading and saving.

                        
XcursorFile:

                        
Represents an opened cursor file, containing metadata and a
                            list of associated images.

                    

                

                

                    
FUNCTIONS

                    
The library exposes a wide range of functions for cursor
                        manipulation. Notable functions include:

                    

                        
XcursorGetDefaultTheme,
                            XcursorSetDefaultTheme:

                        
Get and set the name of the default cursor theme.

                        
XcursorGetDefaultSize,
                            XcursorSetDefaultSize:

                        
Get and set the default size for cursors.

                        
XcursorSetTheme:

                        
Sets the current cursor theme for the application.

                        
XcursorGetCursor:

                        
Retrieves a cursor image for a given name and theme.

                        
XcursorCreatePixmap:

                        
Creates a cursor from an X Pixmap.

                        
XcursorDestroy:

                        
Frees resources associated with a cursor.

                        
XcursorXcFileLoadAllImages:

                        
Loads all cursor images from a specified Xcursor file.

                    

                

                

                    
ENVIRONMENT

                    

                        
XCURSOR_THEME:

                        
Specifies the default cursor theme to use. If not set,
                            Xcursor.theme resource is used.

                        
XCURSOR_SIZE:

                        
Specifies the default cursor size. If not set,
                            Xcursor.size resource is used.

                        
XCURSOR_THEME_CORE:

                        
Enables themes for core cursors if the environment variable is
                            true.

                    

                    

                        

                        
If the environment variable is not given, Xcursor tries the
                            Xcursor.theme_core resource.

                        

                        
An application can enable or disable themes using
                            XcursorSetThemeCore.

                    

                

                

                    
CAVEATS

                    
Xcursor will probably change radically in the future;
                        weak attempts will be made to retain some level of
                        source-file compatibility.
