NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

DESCRIPCIÓN FUNCIONAL

Xcursor está construida en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que construye cursores ya sea a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es soportada por el servidor X. Donde no es soportada, Xcursor mapea la imagen del cursor a un cursor X estándar y usa la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las usen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de TOC
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición absoluta en bytes del archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en el TOC para este fragmento
subtype:	CARD32 debe coincidir con el subtipo en el TOC para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


header:	20 Las cabeceras de comentario tienen 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


header:	36 Las cabeceras de imagen tienen 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual a width
yhot:	CARD32 Debe ser menor o igual a height
delay:	CARD32 Retraso entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 píxeles en formato ARGB empaquetado

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para los temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma (shape) del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Inherits = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor también busca en la ruta para utilizarlo. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Puede haber más de un nombre-del-tema en la línea Inherits=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Inherits=; la especificación de freedesktop.org no es clara sobre si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor verifica el tema “default”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy.

    int 	 nimage; 	/* número de imágenes */

XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;

Xcursor - Cursor File Handling

DESCRIPTION

The Xcursor library provides functions for loading, saving, and manipulating cursor images. It supports various formats and methods for accessing cursor data, including file-based and library-based loading.

The XcursorFile structure is used to define an abstract interface for reading from and writing to cursor files. The library provides default implementations for these functions (using stdio FILE streams), but users can also provide their own implementations by filling in the appropriate function pointers. Note that the library's internal functions expect the read and write functions to be passed a XcursorFile structure pointer as the first argument, while the POSIX standard read and write functions expect a file descriptor as the first argument. The library functions provide callbacks that flip the arguments around to match the POSIX versions.


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

Lectura de imágenes de biblioteca

const char 	*name,
const char 	*theme,
int 	 size)

	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úselo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, use "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for “t”, “1”, “y” or
    “on”

  

  
false for “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.

DESCRIPTION


The Xcursor library provides functions for loading, managing, and
    displaying cursors. It is designed to work with Xcursor theme files, which
    allow for customizable cursor sets. This library allows applications to load
    cursor images, create X cursors, and manage cursor themes.






FUNCTIONAL OVERVIEW


The Xcursor library can be broadly categorized into the following
    areas:



  
Cursor Image Loading and Management:
    
Functions like XcursorGetImage and
        XcursorGetImageFromFile allow loading cursor
        images from files. XcursorDestroyImage is used
        to free the memory associated with a cursor image.

  
  
Cursor Creation:
    
XcursorCreateCursor and
        XcursorCreateRenderCursor create actual X cursor
        objects from loaded images. The latter allows specifying a hot spot for
        the cursor.

  
  
Cursor Destruction:
    
XcursorDestroyCursor frees an X cursor object.

  
  
Theme Management:
    
Functions like XcursorGetTheme,
        XcursorSetTheme, XcursorGetDefaultTheme,
        and XcursorSetThemeForDisplay allow applications
        to query and set the current cursor theme. This includes setting the
        theme name and size.

  
  
Library Information:
    
XcursorLibraryVersion retrieves the version of the
        Xcursor library.

  
  
Rendering Support:
    
XcursorSupportsRender checks if the X server
        supports the render extension, which is often required for advanced
        cursor features.

  
  
Core Cursors:
    
XcursorGetThemeCore and
        XcursorSetThemeCore control whether themes are
        used for core X cursors.

  
  
Filename Handling:
    
XcursorFilename is a utility to find the actual
        filename of a cursor, potentially searching through theme directories.

  
  
Image Manipulation:
    
XcursorSetOpaque can be used to make a cursor image
        opaque.

  







DATATYPES


The primary data types used by the Xcursor library include:



  
XcursorCursors

  
Represents a collection of cursors, typically loaded from a theme.

  
XcursorImage

  
Represents a single cursor image, including its dimensions, hotspot, and
      pixel data.








FUNCTIONS


XcursorCursorsDestroy frees the memory
    associated with a XcursorCursors structure.


XcursorLibraryVersion retrieves the major
    and minor version numbers of the Xcursor library.


XcursorSupportsRender returns True
    if the X server supports the Render extension, False
    otherwise.


XcursorGetTheme,
    XcursorGetDefaultTheme, and
    XcursorGetThemeName retrieve the name of the current
    cursor theme. XcursorGetDefaultTheme retrieves the
    default theme name from the system configuration, while
    XcursorGetThemeName retrieves the currently set theme
    for the application. XcursorGetTheme is a combined
    function.


XcursorSetTheme and
    XcursorSetThemeForDisplay set the cursor theme for the
    specified display. The theme name should be a valid cursor theme directory
    name.


XcursorGetDefaultSize,
    XcursorGetDefaultSizeForDisplay,
    XcursorSetDefaultSize, and
    XcursorSetDefaultSizeForDisplay manage the default
    size of cursors. The size is typically specified in pixels.


XcursorGetThemeCore retrieves the setting
    for whether core X cursors should be themed. XcursorSetThemeCore
    sets this behavior.


XcursorGetImage and
    XcursorGetImageFromFile load a cursor image from the
    specified file. The file is searched for in standard theme directories if
    necessary. XcursorDestroyImage frees the memory
    allocated for an XcursorImage.


XcursorCreateCursor creates an X cursor
    object from an XcursorImage. The cursor object can
    then be used with Xlib functions like XDefineCursor.


XcursorCreateRenderCursor is similar to
    XcursorCreateCursor but allows specifying the hot-spot
    coordinates explicitly. This is useful for cursors that are not centered.


XcursorDestroyCursor destroys an X cursor
    object created by the Xcursor library or Xlib.


XcursorFilename attempts to find the full
    path to a cursor file, searching in the current theme and system-wide cursor
    directories.


XcursorSetOpaque makes the specified cursor
    image fully opaque by filling in transparent areas with the color of the
    pixel at the given coordinates (x, y).






ENVIRONMENT



  
Xcursor CURSOR_THEME

  
Specifies the default cursor theme to use. If this is set, it overrides
      system-wide defaults.

  
Xcursor THEME CORE

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.
