NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursor estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

DESCRIPCIÓN FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursor desde archivos. Por encima de eso hay una capa que localiza archivos de cursor basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores ya sea a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud `CreateCursor` de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud `CreateCursor` principal.

ARCHIVOS DE CURSOR

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes de cursor del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursor se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


mágic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición de byte absoluta de la tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursor; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentario son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imagen son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor sigue (en su mayor parte) la especificación de freedesktop.org para la tematización de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio "cursors".
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en `XcursorLibraryLoadImage` o `XcursorLibraryShape`.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio "cursors", Xcursor busca a continuación un archivo `index.theme` en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo `index.theme` determinado. Si encuentra un tema heredado, Xcursor también busca en la ruta para utilizarlo. Xcursor ignora otras claves en el archivo `index.theme`, incluido `Name` (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea `Inherits=`; la especificación de freedesktop.org no está clara sobre si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema "predeterminado".

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
almacena una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
almacena múltiples estructuras `XcursorImage`. Todas se liberan cuando se libera `XcursorImages` en `XcursorImagesDestroy`. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* matriz de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Almacena múltiples objetos Cursor. Todos se liberan cuando se libera `XcursorCursors`. Estos tienen un contador de referencias para que múltiples estructuras `XcursorAnimate` puedan usar el mismo `XcursorCursors`. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras `XcursorAnimate` pueden hacer referencia al mismo `XcursorCursors`; cada una mantiene una referencia que se elimina cuando se libera `XcursorAnimate`. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio.

Comments API

XcursorComments * XcursorCommentsCreate (
	const char 	*filename,
	int 	 size)

Reads a cursor theme file and returns a list of comments. The filename is the name of the cursor theme directory. The size is the default size of cursors in the theme.

The returned list is NULL-terminated, and may contain many pointers to XcursorComment structures. Each XcursorComment structure contains a name, and a description string. The name is used to identify the cursor. The description string is a short text description of the cursor.

The returned list is allocated with malloc() and should be freed by XcursorCommentsDestroy().

void XcursorCommentsDestroy (
	XcursorComments 	*comments)

Deallocates the given XcursorComments structure as well as the XcursorComment structures which it points to.

Animated Cursors

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Wrap the given array of cursors in a newly allocated XcursorAnimate structure, which adds a sequence number used in XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Discards the given animate data, freeing both the XcursorCursors array of cursors as well as the XcursorAnimate structure.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Cyclically returns the next Cursor in the array, incrementing the sequence number to prepare for the next call.

The caller is responsible for displaying the series of Cursor images. Xcursor does not do that.

Glyph Cursor APIs

The X11 XCreateFontCursor and XCreateGlyphCursor functions use this part of the API to extend the X core cursors feature to use themes.

Compute a hash of the image, to display when the environment variable XCURSOR_DISCOVER is set.

void XcursorImagesSetName (

	const char 	*name)

Associates the given name with the images.

void XcursorNoticeCreateBitmap (
	Display 	*dpy,
	Pixmap 	 pid,
	unsigned int 	 width,
	unsigned int 	 height)

Check if the display supports either ARGB or themes, and also if the image size fits within the maximum cursor size (64 pixels). If so, create a bitmap of the specified size, and cache the result in Xcursor, identifying it with the Pixmap-id (pid) value.

void XcursorNoticePutBitmap (
	Display 	*dpy,
	Drawable 	 draw,
	XImage 	*image)

Update the image contents in the bitmap specified by the draw value (a Pixmap-id). The bitmap must have been created by XcursorNoticeCreateBitmap.

Cursor XcursorTryShapeBitmapCursor (
	Display 	*dpy,
	Pixmap 	 source,
	Pixmap 	 mask,
	XColor 	*foreground,
	XColor 	*background,
	unsigned int 	 x,
	unsigned int 	 y)

If the display supports either ARGB or themes, try to load a cursor into Xcursor's cache using the source parameter as a Pixmap-id. The source may no longer be in the cache. Xcursor uses the hash value to identify the desired image.

Cursor XcursorTryShapeCursor (
	Display 	*dpy,
	Font 	 source_font,
	Font 	 mask_font,
	unsigned int 	 source_char,
	unsigned int 	 mask_char,
	XColor _Xconst 	*foreground,
	XColor _Xconst 	*background)

If the display supports either ARGB or themes, try to load a cursor into Xcursor's cache using the source_char parameter as a shape. Using

  • the default size from XcursorGetDefaultSize,
  • the default theme from XcursorGetTheme, and
  • the source_char parameter as a shape,
Xcursor calls XcursorShapeLoadImages to load the cursor images. If successful, Xcursor uses XcursorImagesLoadCursor to load the cursor information.

ENVIRONMENT

Environment variables can be used to override resource settings, which in turn override compiled-in default values.

Some of the environment variables recognized by Xcursor are booleans, specified as follows:

true for “t”, “1”, “y” or “on”
false for “f”, “0”, “n” or “off”

Xcursor ignores other values for these booleans.

HOME
Xcursor interprets “~” in the search list as the home directory, using this variable rather than the password database.
XCURSOR_ANIM
If the display supports the Render CreateCursor request, and the Render feature is enabled, disable animated cursors if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.anim.
XCURSOR_CORE
If the display supports the Render CreateCursor request disable the Render feature if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.core.
XCURSOR_DISCOVER
If the variable is set, Xcursor turns on a logging feature. It displays the hash value and the image so that users can see which cursor name is associated with each image.
There is no corresponding resource setting.
XCURSOR_DITHER
This variable sets the desired dither.
If the environment variable is not given, Xcursor uses the resource Xcursor.dither.
If neither environment variable or resource is found, Xcursor uses “threshold”
These are the recognized values:
diffuse
median
ordered
threshold
XCURSOR_PATH
This variable sets the list of paths in which to search for cursors, rather than the compiled-in default list.
Directories in this path are separated by colons (:).
XCURSOR_RESIZED
Enables automatic resizing of cursors to improve their displayed size if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.resized resource.
XCURSOR_SIZE
This variable sets the desired cursor size, in pixels.
If the environment variable is not given, Xcursor tries the Xcursor.size resource.
If no size is given, whether by environment variable or resource setting, Xcursor next tries the Xft.dpi resource setting to guess the size of a 16-point cursor.
Finally, if Xft.dpi is not set, Xcursor uses the display height, dividing by 48 (assuming that the height is 768).
XCURSOR_THEME
This variable selects the desired theme.
If the environment variable is not given, Xcursor tries the Xcursor.theme resource.
If neither environment variable or resource is found, Xcursor uses the default theme.
XCURSOR_THEME_CORE
If the environment variable is set to true, this enables theming for core X cursors. If it is set to false, it disables theming for core X cursors.
If the environment variable is not given, Xcursor uses the resource Xcursor.theme_core.

DESCRIPTION

The libXcursor library provides functions for loading and managing Xcursor images, which are used for cursors in the X Window System. This page describes the configuration and theme management functions.

XcursorConfig(), XcursorConfig_internal(), XcursorThemeLoadConfig(), XcursorThemeConfig(), and XcursorThemeConfig_internal() are internal functions used by the library to load and manage theme configuration. They are generally not intended for direct use by applications.

XcursorGetDefaultTheme() returns the name of the default cursor theme. This is typically read from the Xcursor.theme resource.

XcursorGetTheme() returns the name of the currently active cursor theme for the given display. This is typically read from the Xcursor.theme resource or set using XcursorSetTheme().

XcursorSetTheme() sets the cursor theme for the given display. The theme name should be a string that can be found in the cursor theme search path. It returns 0 on success and -1 on failure.

XcursorGetDefaultSize() returns the default cursor size. This is typically read from the Xcursor.size resource.

XcursorGetSize() returns the current cursor size for the given display. This is typically read from the Xcursor.size resource or set using XcursorSetSize().

XcursorSetSize() sets the cursor size for the given display. The size should be a positive integer representing the desired cursor size in pixels. It returns 0 on success and -1 on failure.

XcursorGetThemeCore() returns whether core cursor themes are enabled. This is typically read from the Xcursor.theme_core resource or the XCURSORS_THEME_CORE environment variable.

XcursorSetThemeCore() enables or disables the use of core cursor themes. Core cursors are standard cursors provided by the X server.

FUNCTIONAL OVERVIEW

These functions provide a way to configure and manage cursor themes and sizes within an X application. They allow applications to query the current settings, set new themes and sizes, and control the use of core cursor themes.
