NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima, hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior, hay una capa que crea cursores a partir de una imagen cargada desde un archivo o uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere utilizar la solicitud `CreateCursor` de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud `CreateCursor` principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo tiene el siguiente aspecto:


mágic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la tabla de contenido para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la tabla de contenido para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmento definidos para archivos de cursores; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentarios tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imágenes tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual que 0x7fff
alto:	CARD32 Debe ser menor o igual que 0x7fff
xhot:	CARD32 Debe ser menor o igual que el ancho
yhot:	CARD32 Debe ser menor o igual que el alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para tematizar iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se utiliza en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas en este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Nombre” (es decir, el nombre que una aplicación gráfica puede usar como el nombre de presentación).

Se puede enumerar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org establece que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* x del punto activo (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* y del punto activo (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* recuento de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;

Lectura de imágenes de biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, úselo.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, use “default” para el nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

XcursorFilenameLoadAllImages, XcursorLibraryLoadAllImages, XcursorLibraryLoadImages — load cursor images from files or directories






SYNOPSIS


#include <Xcursor/Xcursor.h>



int
XcursorFilenameLoadAllImages(
    XcursorImage **images,
    const char * filename,
    unsigned int *screen_min_width,
    unsigned int *screen_max_width
);
int
XcursorLibraryLoadAllImages(
    XcursorImage ***images,
    unsigned int *screen_min_width,
    unsigned int *screen_max_width
);
int
XcursorLibraryLoadImages(
    XcursorImage ***images,
    unsigned int *screen_min_width,
    unsigned int *screen_max_width,
    const char * name
);







DESCRIPTION


The Xcursor library provides functions for loading cursor
    images.


XcursorFilenameLoadAllImages loads all cursor images
    specified by the file filename. The images are returned in the
    images argument. The minimum and maximum screen width for which the
    images are suitable are returned in screen_min_width and
    screen_max_width, respectively.


XcursorLibraryLoadAllImages loads all cursor images from
    the standard cursor image directories. The images are returned in the
    images argument. The minimum and maximum screen width for which the
    images are suitable are returned in screen_min_width and
    screen_max_width, respectively.


XcursorLibraryLoadImages loads the cursor image named
    name from the standard cursor image directories. The images are
    returned in the images argument. The minimum and maximum screen width
    for which the images are suitable are returned in screen_min_width and
    screen_max_width, respectively.


These functions are useful for applications that want to load
    cursor images dynamically.






FUNCTIONAL OVERVIEW


The Xcursor library uses a simple file format for storing
    cursor images. The format is a binary file that contains a header followed by
    a series of cursor images. The header contains information about the number
    of images, the width and height of each image, and the offset to the image
    data.


The image data is stored in ARGB format. The alpha channel is used
    to control the transparency of the cursor.


The Xcursor library searches for cursor images in the
    following directories:



  

  
$HOME/.icons/cursors

  

  
/usr/share/icons/cursors




The search order can be modified by setting the
    XCURSOR_THEME_DIRS environment variable.






DATATYPES


The following data types are used by the Xcursor library:



  
XcursorImage

  
Represents a single cursor image. It contains the width, height, hotspot,
      and image data.

  
XcursorImage

  
Represents a list of cursor images. Each element in the list is a
      pointer to an XcursorImage structure.








FUNCTIONS


The following functions are provided by the Xcursor
    library:



  
XcursorFilenameLoadAllImages

  
Loads all cursor images from a file.

  
XcursorLibraryLoadAllImages

  
Loads all cursor images from the standard cursor image directories.

  
XcursorLibraryLoadImages

  
Loads a specific cursor image from the standard cursor image
      directories.

  
XcursorFreeImages

  
Frees the memory allocated for cursor images.








ENVIRONMENT



  
URSOR_THEME_CORE

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.

    attempts will be made to retain some level of source-file compatibility.
