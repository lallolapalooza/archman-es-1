NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o desde memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior se encuentra el código que puede cargar imágenes de cursores desde archivos. Por encima de eso, hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior, hay una capa que construye cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene un índice seguido de una secuencia de bloques. El índice indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo tiene este aspecto:


mágia:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas del índice
toc:	LISTofTOC tabla de contenido

Cada entrada del índice tiene este aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición de byte absoluta de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en el índice para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en el índice para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para los archivos de cursores; comentarios e imágenes. Los comentarios tienen este aspecto:


cabecera:	20 Las cabeceras de comentarios son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTRO) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen este aspecto:


cabecera:	36 Las cabeceras de imágenes son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayor parte) sigue la especificación de freedesktop.org para tematizar iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio que utiliza el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas con este formato:
Hereda = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para utilizarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluido “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-tema en la línea Inherits=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Inherits=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se liberan las XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar los mismos XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y a una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera la XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* qué cursor es el siguiente */
} XcursorAnimate;

const char 	*name,

	const char 	*name,
	const char 	*theme,
	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del size deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se utiliza ese.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, se utiliza "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones retornan NULL.
Las dos funciones difieren en algo más que el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage, pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

NAME



  
Xcursor - cursor loading library








SYNOPSIS


#include <X11/Xcursor/Xcursor.h>







DESCRIPTION


The Xcursor library provides an interface to load X cursors from
    either files or memory. It supports multiple image sizes and animations.


The library is intended to be used by applications that want to
    load cursors, and by the X server to provide cursors to applications.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for
    “t”, “1”, “y” or
    “on”

  

  
false for
    “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.

DESCRIPTION


The Xcursor library provides functions for reading and writing
    cursor themes. Cursor themes are collections of cursors.


Cursors can contain arbitrary comments. The functions described
    here manipulate lists of these comments. Comments are stored as name-value
    pairs.


A comment list is represented by a pointer to an
    XcursorComment structure. An iterator for traversing the list is
    represented by an XcursorCommentIter structure.




Creation and Destruction



  
XcursorCommentCreate()

  
Creates and returns a new, empty comment list.

  
XcursorCommentDestroy()

  
Frees the memory associated with the comment list comment.








Access and Modification



  
XcursorCommentGet()

  
Returns the value associated with the name name in the comment
      list comment, or 0 if no such name exists.

  
XcursorCommentSet()

  
Sets the value associated with the name name in the comment list
      comment to value. If name already exists, its value
      is updated. If value is 0, the comment entry is deleted.

  
XcursorCommentAddEntry()

  
Adds a new comment entry with the name name and value value
      to the list comment. Returns XcursorTrue on success, or
      XcursorFalse if the name already exists.

  
XcursorCommentDeleteEntry()

  
Deletes the comment entry with the name name from the list
      comment. Returns XcursorTrue on success, or
      XcursorFalse if the name does not exist.

  
XcursorCommentUpdateEntry()

  
Updates the value of the comment entry with the name name to
      value. Returns XcursorTrue on success, or
      XcursorFalse if the name does not exist.

  
XcursorCommentFindEntry()

  
Returns the value associated with the name name in the comment
      list comment, or 0 if no such name exists. This is equivalent to
      XcursorCommentGet.








Iteration



  
XcursorCommentFirst()

  
Initializes the iterator iter and points it to the first comment
      entry in the list comment. Returns the name of the first comment
      entry, or 0 if the list is empty.

  
XcursorCommentLast()

  
Initializes the iterator iter and points it to the last comment
      entry in the list comment. Returns the name of the last comment
      entry, or 0 if the list is empty.

  
XcursorCommentNext()

  
Advances the iterator iter to the next comment entry in the list
      and returns its name. Returns 0 if the end of the list is reached.

  
XcursorCommentPrev()

  
Moves the iterator iter to the previous comment entry in the list
      and returns its name. Returns 0 if the beginning of the list is reached.








Status Queries



  
XcursorCommentIsEmpty()

  
Returns XcursorTrue if the comment list comment is empty,
      and XcursorFalse otherwise.

  
XcursorCommentGetNumEntries()

  
Returns the number of comment entries in the list comment.










ENVIRONMENT



  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.
