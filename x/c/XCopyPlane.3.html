XCopyArea(3) FUNCIONES DE XLIB XCopyArea(3)

NOMBRE

XCopyArea, XCopyPlane - copiar áreas

SINTAXIS

int XCopyArea(Display *display, Drawable src, Drawable dest, GC gc, int src_x, int src_y, unsigned int width, unsigned height, int dest_x, int dest_y);

int XCopyPlane(Display *display, Drawable src, Drawable dest, GC gc, int src_x, int src_y, unsigned width, unsigned height, int dest_x, int dest_y, unsigned long plane);

ARGUMENTOS

dest_x

dest_y
Especifican las coordenadas x e y, que son relativas al origen del rectángulo de destino y especifican su esquina superior izquierda.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
plane
Especifica el plano de bits. Debes establecer exactamente un bit a 1.
src

dest
Especifican los rectángulos de origen y destino a combinar.
src_x

src_y
Especifican las coordenadas x e y, que son relativas al origen del rectángulo de origen y especifican su esquina superior izquierda.
width

height
Especifican el ancho y alto, que son las dimensiones de ambos rectángulos, el de origen y el de destino.

DESCRIPCIÓN

La función XCopyArea combina el rectángulo especificado de src con el rectángulo especificado de dest. Los dibujables deben tener la misma raíz y profundidad, o se producirá un error BadMatch.

Si las regiones del rectángulo de origen están oscurecidas y no se han conservado en almacenamiento intermedio (backing store) o si se especifican regiones fuera de los límites del dibujable de origen, esas regiones no se copian. En su lugar, ocurre lo siguiente en todas las regiones de destino correspondientes que están visibles o se conservan en almacenamiento intermedio. Si el destino es una ventana con un fondo distinto de None, las regiones correspondientes del destino se rellenan con ese fondo (con una máscara de plano de todos unos y la función GXcopy). Independientemente del relleno o de si el destino es una ventana o un pixmap, si graphics-exposures es True, entonces se generan eventos GraphicsExpose para todas las regiones de destino correspondientes. Si graphics-exposures es True pero no se generan eventos GraphicsExpose, se genera un evento NoExpose. Ten en cuenta que por defecto graphics-exposures es True en los GC nuevos.

Esta función utiliza los siguientes componentes del GC: función, máscara de plano, modo subventana, graphics-exposures, clip-x-origin, clip-y-origin y clip-mask.

XCopyArea puede generar errores BadDrawable, BadGC y BadMatch.

La función XCopyPlane utiliza un único plano de bits del rectángulo de origen especificado, combinado con el GC especificado, para modificar el rectángulo de destino especificado. Los dibujables deben tener la misma raíz, pero no es necesario que tengan la misma profundidad. Si los dibujables no tienen la misma raíz, se produce un error BadMatch. Si plane no tiene exactamente un bit establecido en 1 y el valor de plane no es menor que %2 sup n%, donde n es la profundidad de src, se produce un error BadValue.

Efectivamente, XCopyPlane forma un pixmap de la misma profundidad que el rectángulo de destino y con un tamaño especificado por la región de origen. Utiliza los píxeles de primer plano/fondo en el GC (primer plano donde el plano de bits en src contiene un bit establecido en 1, fondo donde el plano de bits en src contiene un bit establecido en 0) y el equivalente a una solicitud de protocolo CopyArea se realiza con toda la misma semántica de exposición. Esto también se puede pensar como el uso de la región especificada del plano de bits de origen como un relleno con un estilo de relleno de FillOpaqueStippled para rellenar un área rectangular del destino.

Esta función utiliza los siguientes componentes del GC: función, máscara de plano, primer plano, fondo, modo subventana, graphics-exposures, clip-x-origin, clip-y-origin y clip-mask.

XCopyPlane puede generar errores BadDrawable, BadGC, BadMatch y BadValue.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
