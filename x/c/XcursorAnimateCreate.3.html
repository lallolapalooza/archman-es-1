NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que crea cursores a partir de una imagen cargada desde un archivo o de uno de los cursores estándar de X. Al utilizar imágenes cargadas desde archivos, Xcursor prefiere utilizar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no sea compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para los cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar varios cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de fragmentos. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo tiene el siguiente aspecto:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenidos
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos tiene el siguiente aspecto:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes del archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la tabla de contenidos de este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en la tabla de contenidos de este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente, hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios tienen el siguiente aspecto:


cabecera:	20 Las cabeceras de comentario son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes tienen el siguiente aspecto:


cabecera:	36 Las cabeceras de imagen son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayor parte) sigue la especificación de freedesktop.org para los temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma (shape) del cursor, por ejemplo, como se utiliza en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra ningún archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Estas son líneas con el siguiente formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para utilizarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Nombre” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* array de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Referencia un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden referenciar el mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;

void XcursorCommentsDestroy (
	XcursorComments 	*comments)

Deasigna la estructura XcursorComments dada, así como las estructuras XcursorComment a las que apunta.

Cursores Animados

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Envuelve el array de cursores dado en una estructura XcursorAnimate recién asignada, que añade un número de secuencia usado en XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Descarta los datos animate dados, liberando tanto el array de cursores XcursorCursors como la estructura XcursorAnimate.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Devuelve cíclicamente el siguiente Cursor en el array, incrementando el número de secuencia para prepararse para la próxima llamada.

El llamador es responsable de mostrar la serie de imágenes de Cursor. Xcursor no hace eso.

APIs de cursores de glifos

Las funciones X11 XCreateFontCursor y XCreateGlyphCursor utilizan esta parte de la API para extender la característica de cursores básicos de X para usar temas.

void XcursorImageHash (
	XImage 	*image,
	unsigned char 	 hash[XCURSOR_BITMAP_HASH_SIZE])

Calcula un hash de la imagen, para mostrarlo cuando la variable de entorno XCURSOR_DISCOVER esté configurada.

void XcursorImagesSetName (
	XcursorImages 	*images,
	const char 	*name)

Asocia el nombre dado con las imágenes.

void XcursorNoticeCreateBitmap (
	Display 	*dpy,
	Pixmap 	 pid,
	unsigned int 	 width,
	unsigned int 	 height)

Comprueba si la pantalla soporta ARGB o temas, y también si el tamaño de la imagen cabe dentro del tamaño máximo del cursor (64 píxeles). Si es así, crea un mapa de bits del tamaño especificado y almacena en caché el resultado en Xcursor, identificándolo con el valor del identificador del mapa de bits (pid).

void XcursorNoticePutBitmap (
	Display 	*dpy,
	Drawable 	 draw,
	XImage 	*image)

Actualiza el contenido de la imagen en el mapa de bits especificado por el valor de dibujo (un identificador de mapa de bits). El mapa de bits debe haber sido creado por XcursorNoticeCreateBitmap.

Cursor XcursorTryShapeBitmapCursor (
	Display 	*dpy,
	Pixmap 	 source,
	Pixmap 	 mask,
	XColor 	*foreground,
	XColor 	*background,
	unsigned int 	 x,
	unsigned int 	 y)

Si la pantalla soporta ARGB o temas, intenta cargar un cursor en la caché de Xcursor usando el parámetro source como identificador de mapa de bits. La fuente puede que ya no esté en la caché. Xcursor utiliza el valor hash para identificar la imagen deseada.

Cursor XcursorTryShapeCursor (
	Display 	*dpy,
	Font 	 source_font,
	Font 	 mask_font,
	unsigned int 	 source_char,
	unsigned int 	 mask_char,
	XColor _Xconst 	*foreground,
	XColor _Xconst 	*background)

Si la pantalla soporta ARGB o temas, intenta cargar un cursor en la caché de Xcursor usando el parámetro source_char como forma. Usando

  • el tamaño predeterminado de XcursorGetDefaultSize,
  • el tema predeterminado de XcursorGetTheme, y
  • el parámetro source_char como forma,
Xcursor llama a XcursorShapeLoadImages para cargar las imágenes del cursor. Si tiene éxito, Xcursor utiliza XcursorImagesLoadCursor para cargar la información del cursor.

AMBIENTE

Las variables de entorno se pueden utilizar para anular la configuración de recursos, que a su vez anulan los valores predeterminados compilados.

Algunas de las variables de entorno reconocidas por Xcursor son booleanas, especificadas de la siguiente manera:

verdadero para "t", "1", "y" o "on"
falso para "f", "0", "n" o "off"

Xcursor ignora otros valores para estos booleanos.

INICIO
Xcursor interpreta "~" en la lista de búsqueda como el directorio de inicio, utilizando esta variable en lugar de la base de datos de contraseñas.
XCURSOR_ANIM
Si la pantalla soporta la solicitud Render CreateCursor y la característica Render está habilitada, deshabilita los cursores animados si la variable de entorno es falso.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.anim.
XCURSOR_CORE
Si la pantalla soporta la solicitud Render CreateCursor, deshabilita la característica Render si la variable de entorno es falso.
Si no se proporciona la variable de entorno, Xcursor utiliza el recurso Xcursor.core.
XCURSOR_DISCOVER
Si la variable está configurada, Xcursor activa una función de registro. Muestra el valor hash y la imagen para que los usuarios puedan ver qué nombre de cursor está asociado con cada imagen.
No hay una configuración de recurso correspondiente.
XCURSOR_DITHER
Esta variable establece el dither deseado.

DESCRIPTION

The Xcursor library provides functions for loading and managing cursor images. It supports animated cursors, cursors loaded from files, shape-based cursors, and theme-based cursors.

The animation functions allow for the creation, destruction, and manipulation of animated cursors. XcursorAnimateCreate creates a new animation object based on an existing one, while XcursorAnimationCreate creates a new, empty animation object. XcursorAnimationNextFrame advances the animation to the next frame. XcursorAnimationSetPaused and XcursorAnimationGetPaused control and query the paused state of an animation.

The file functions allow loading cursor images from files. XcursorFileLoadQuery checks if a file can be loaded, and XcursorFileParse loads and parses the file into an XcursorImage. XcursorFileDestroy frees the memory associated with an XcursorImage.

The shape functions allow loading cursors based on predefined shapes. XcursorShapeLoadQuery checks if a shape is supported, and XcursorShapeLoad loads the cursor image for that shape. XcursorShapeDestroy frees the memory associated with an XcursorImage.

The theme functions provide a mechanism for managing cursor themes. XcursorThemeCreate creates a theme object for a given display and cursor size. XcursorThemeDestroy destroys the theme object. XcursorThemeLoadTheme and XcursorThemeLoadAllThemes load cursor themes from specified directories. XcursorThemeSetTheme and XcursorThemeGetTheme set and get the name of the currently active theme. XcursorThemeSetThemeGroupName and XcursorThemeGetThemeGroupName set and get the name of the theme group. XcursorThemeSetThemeArgs and XcursorThemeGetThemeArgs set and get the arguments for the theme. XcursorThemeSetDefaultTheme and XcursorThemeGetDefaultTheme manage the default theme for the display. XcursorSetDefaultTheme and XcursorGetDefaultTheme provide a simpler interface for setting and getting the default theme.

The functions XcursorSetThemeCore, XcursorGetThemeCore, XcursorSetThemeAnimateCore, XcursorGetThemeAnimateCore, XcursorSetThemeAnimate, and XcursorGetThemeAnimate control whether animated or core cursors are used.

FUNCTIONAL OVERVIEW

The Xcursor library is designed to abstract the complexity of cursor management. It allows applications to easily load and display cursors, supporting various formats and themes. The library handles the details of parsing cursor files, applying theme settings, and managing animated cursors.

The theme functions are particularly important for customizing the user interface. By setting a cursor theme, applications can ensure a consistent look and feel across the entire desktop environment.

The core functions provide a way to control the use of system-defined (core) cursors versus theme-defined cursors, and also control the behavior of animated cursors.

ENVIRONMENT

Xcursor.theme_core
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
