DESCRIPCIÓN

La extensión composite proporciona varios mecanismos relacionados:

Almacenamiento por jerarquía

La representación de una jerarquía completa de ventanas se redirecciona a un almacenamiento fuera de pantalla. Los píxeles de esa jerarquía están disponibles siempre que sea visible. El almacenamiento se reasigna automáticamente cuando la ventana de nivel superior cambia de tamaño. El contenido más allá de la geometría de la ventana superior no se conserva.

Actualización automática de sombras

Cuando una jerarquía se representa fuera de pantalla, el servidor X proporciona un mecanismo automático para presentar ese contenido dentro de la ventana padre. La implementación es libre de hacer que esta actualización se retrase una cantidad de tiempo no especificada con respecto a las operaciones de representación reales. Este mecanismo de actualización automática puede deshabilitarse para que el contenido de la ventana padre sea completamente determinado por una aplicación externa.

Ventana de superposición compuesta

La versión 0.3 del protocolo agrega la Ventana de Superposición Compuesta, que proporciona a los gestores de composición una superficie sobre la cual dibujar sin interferencias. Esta ventana está siempre por encima de las ventanas normales y siempre por debajo de la ventana del protector de pantalla. Es una ventana de EntradaSalida cuyos ancho y alto son las dimensiones de la pantalla. Su visual es el visual raíz y su ancho de borde es cero. Los intentos de redirigirla usando la extensión compuesta se ignoran. Esta ventana no aparece en la respuesta de la solicitud QueryTree. También es una ventana de redirección de anulación. Estas dos últimas características la hacen invisible para los gestores de ventanas y otros clientes X11. La única forma de acceder al XID de esta ventana es a través de la solicitud CompositeGetOverlayWindow. Inicialmente, la Ventana de Superposición Compuesta está desmapeada.

Recorte de ventana padre

La versión 0.4 del protocolo modifica la semántica del recorte de la ventana padre en presencia de hijos redirigidos manualmente. Con esta versión, el área en el padre cubierta por hijos redirigidos manualmente se deja en la lista de recortes del padre en lugar de eliminarse como en versiones anteriores.

El almacenamiento fuera de pantalla incluye el contenido de la ventana, sus bordes y el contenido de todos los descendientes.

El almacenamiento fuera de pantalla puede crearse para ventanas individuales o para todos los hijos de una ventana. La actualización manual de sombras puede ser seleccionada por una sola aplicación para cada ventana; la actualización manual también puede seleccionarse por ventana o por cada hijo de una ventana. La detección de cuándo actualizar puede hacerse con la extensión Damage.

ARGUMENTOS

display

Puntero a la estructura Display devuelta por XOpenDisplay para la conexión con el servidor X.

event_base_return

Puntero a un entero donde se almacenará el valor base para los eventos de la Extensión Compuesta.

error_base_return

Puntero a un entero donde se almacenará el valor base para los errores de la Extensión Compuesta.

major_version_return

Puntero a un entero donde se almacenará la versión mayor de la Extensión Compuesta compatible con el servidor X.

minor_version_return

Puntero a un entero donde se almacenará la versión menor de la Extensión Compuesta compatible con el servidor X.

window

Especifica el ID de ventana sobre el que operar.

update

Especifica el modo de actualización del contenido de la ventana. Debe ser CompositeRedirectAutomatic o CompositeRedirectManual.

FUNCIONES

XCompositeQueryExtension

XCompositeQueryExtension determina si la Extensión Compuesta está disponible en la pantalla dada. Devuelve True si la extensión es compatible, de lo contrario False. Si la extensión está presente, se devuelven los valores base para los eventos y errores, y se pueden usar para decodificar los valores de eventos y errores entrantes.

XCompositeQueryVersion

XCompositeQueryVersion determina si el servidor X admite una versión de la Extensión X Composite compatible con la biblioteca cliente. Se devuelve un Status distinto de cero si se admite una versión compatible de la extensión, de lo contrario se devuelve un Status cero. Si la extensión es compatible, se devuelven los números de versión mayor y menor para indicar el nivel de compatibilidad de la Extensión Compuesta. No se pueden llamar a otras funciones XComposite (excepto XCompositeQueryExtension) antes de esta función. Si un cliente viola esta regla, los efectos de todas las llamadas posteriores de XComposite que realice no están definidos.

XCompositeVersion

XCompositeVersion devuelve la versión de la biblioteca X Composite. El número de versión está codificado como: (mayor * 10000) + (menor * 100) + revisión

Por ejemplo, la versión 1.4.6 se codificaría como el entero 10406.

XCompositeRedirectWindow

XCompositeRedirectWindow solicita al servidor X que redirija la jerarquía que comienza en window a un almacenamiento fuera de pantalla. El argumento update especifica si el contenido se refleja automáticamente en la ventana padre o no. Solo un cliente a la vez puede especificar un tipo de actualización de CompositeRedirectManual; otro intento resultará en un error BadAccess. Cuando todos los clientes que habilitan la redirección terminan, la redirección se deshabilitará automáticamente.

La ventana raíz no puede ser redirigida. Hacerlo resulta en un error BadMatch. Especificar un ID de ventana inválido resultará en un error BadWindow.

XCompositeRedirectSubwindows

XCompositeRedirectSubwindows solicita al servidor X que redirija las jerarquías que comienzan en todos los hijos actuales y futuros de window como en XCompositeRedirectWindow. Si update es CompositeRedirectManual, entonces la pintura del fondo de la ventana durante la manipulación de la ventana y las solicitudes ClearArea se inhiben.

XCompositeUnredirectWindow

XCompositeUnredirectWindow solicita al servidor X que termine la redirección de window. Si la ventana especificada no fue seleccionada para redirección por el cliente actual, resulta un error BadValue.

XCompositeUnredirectSubwindows

XCompositeUnredirectWindow solicita al servidor X que termine la redirección de todos los hijos de window. Si la ventana especificada no fue seleccionada para sub-redirección por el cliente actual, resulta un error BadValue.

XCompositeCreateRegionFromBorderClip

XCompositeCreateRegionFromBorderClip crea una región que contiene el borde "usual" de la ventana.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap devuelve un identificador a un Pixmap que contiene los contenidos de la ventana especificada. Este Pixmap es propiedad del servidor y se vuelve inválido cuando la ventana se destruye o su contenido se actualiza.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow devuelve el ID de ventana de la Ventana de Superposición Compuesta. Ver la sección DESCRIPCIÓN para más detalles.

XCompositeReleaseOverlayWindow

XCompositeReleaseOverlayWindow libera la Ventana de Superposición Compuesta si el cliente actual fue el que la obtuvo. Si la ventana ya está desmapeada, esta llamada no tiene ningún efecto.

NAME

XCompositeUnredirectWindow, XCompositeRedirectWindow, XCompositeNameWindowPixmap, XCompositeGetOverlayWindow, XCompositeReleaseOverlayWindow — request redirection of a window

SYNOPSIS

#include <X11/extensions/Xcomposite.h>

void
XCompositeUnredirectWindow(Display *dpy, Window window,
    int update_type);

void
XCompositeRedirectWindow(Display *dpy, Window window,
    int update_type);

Pixmap
XCompositeNameWindowPixmap(Display *dpy, Window window,
    unsigned int *serial_num_ret);

Window
XCompositeGetOverlayWindow(Display *dpy, Window window);

void
XCompositeReleaseOverlayWindow(Display *dpy, Window window);

DESCRIPTION

The Composite extension allows applications to redirect the contents of a window to an off-screen pixmap. This is primarily useful for implementing effects such as transparency, shadows, and complex window compositing. The extension also provides support for overlay windows, which can be used to display special content, such as damage regions or cursors, on top of other windows.

The behavior of the Composite extension depends on the version supported by the X server. The functions described here require specific minimum versions to be available.

ARGUMENTS

dpy
Specifies the connection to the X server.
window
Specifies the window of interest.
update_type
Specifies how the redirection should be handled. It can be one of the following values:
XCompositeRedirectAutomatic
The server automatically redirects the window and its children. When the window is unmapped or reconfigured, it is automatically unredirected.
XCompositeRedirectManual
The client is responsible for manually redirecting and unredirecting the window. The server will only redirect the window when requested and will not automatically unredirect it under any circumstances.
serial_num_ret
If not NULL, the serial number of the request will be stored here.

FUNCTIONS

XCompositeUnredirectWindow

XCompositeUnredirectWindow instructs the X server to stop redirecting the specified window. If update_type is XCompositeRedirectAutomatic, the server will automatically unredirect the window when it is unmapped or reconfigured. If update_type is XCompositeRedirectManual, the window will remain unredirected until explicitly redirected again.

A BadMatch error is generated if the specified window is not currently redirected.

The X server must support at least version 0.2 of the Composite Extension for XCompositeUnredirectWindow.

XCompositeRedirectWindow

XCompositeRedirectWindow instructs the X server to redirect the specified window. The update_type argument determines whether the redirection is automatic or manual. If XCompositeRedirectAutomatic is used, the server will automatically redirect the window and its children whenever the window is mapped or reconfigured. If XCompositeRedirectManual is used, the client must explicitly redirect the window using this function, and the server will not automatically unredirect it.

A BadMatch error is generated if the specified window is already redirected or if the window is not redirectable (e.g., it is a root window).

The X server must support at least version 0.2 of the Composite Extension for XCompositeRedirectWindow.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap returns a pixmap that contains the contents of the specified window. This pixmap is created by the X server and is managed by the Composite extension. The pixmap will remain valid even if the window is unmapped, reconfigured, or destroyed. However, if the window is remapped or resized, a new pixmap will be allocated, and this function must be called again to obtain a reference to the new pixmap.

The serial_num_ret argument, if provided, will be set to the serial number of the request. This can be used to correlate the returned pixmap with the request.

A BadMatch error is generated if the specified window is not redirected or is not visible.

The X server must support at least version 0.2 of the Composite Extension for XCompositeNameWindowPixmap.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow returns the window ID of the Composite Overlay Window for the screen associated with the specified window. This function signals to the X server that the client intends to use the overlay window. If the overlay window has not yet been mapped, it will be mapped by this request.

The overlay window for a screen will remain mapped as long as at least one client is using it. It will be unmapped when all clients that have called XCompositeGetOverlayWindow have either called XCompositeReleaseOverlayWindow for that screen or have terminated their connection to the X server.

The X server must support at least version 0.3 of the Composite Extension for XCompositeGetOverlayWindow.

XCompositeReleaseOverlayWindow

XCompositeReleaseOverlayWindow indicates that the client is no longer using the Composite Overlay Window on the screen associated with the specified window. The overlay window for a screen is unmapped when no clients are using it.

The X server must support at least version 0.3 of the Composite Extension for XCompositeReleaseOverlayWindow.
