XChangeWindowAttributes(3)

Paquete: libx11

Licencias: MIT AND X11

XChangeWindowAttributes(3) FUNCIONES DE XLIB XChangeWindowAttributes(3)

NOMBRE

XChangeWindowAttributes, XSetWindowBackground, XSetWindowBackgroundPixmap, XSetWindowBorder, XSetWindowBorderPixmap, XSetWindowColormap - cambiar atributos de ventana

SINTAXIS

int XChangeWindowAttributes(Display *display, Window w, unsigned long valuemask, XSetWindowAttributes *attributes);

int XSetWindowBackground(Display *display, Window w, unsigned long background_pixel);

int XSetWindowBackgroundPixmap(Display *display, Window w, Pixmap background_pixmap);

int XSetWindowBorder(Display *display, Window w, unsigned long border_pixel);

int XSetWindowBorderPixmap(Display *display, Window w, Pixmap border_pixmap);

int XSetWindowColormap(Display *display, Window w, Colormap colormap);

ARGUMENTOS

attributes
Especifica la estructura de la cual se tomarán los valores (según lo especificado por la máscara de valor). La máscara de valor debe tener los bits apropiados configurados para indicar qué atributos se han establecido en la estructura.
background_pixel
Especifica el píxel que se utilizará para el fondo.
background_pixmap
Especifica el pixmap de fondo, ParentRelative, o None.
border_pixel
Especifica la entrada en el mapa de colores.
border_pixmap
Especifica el pixmap de borde o CopyFromParent.
display
Especifica la conexión con el servidor X.
valuemask
Especifica qué atributos de ventana están definidos en el argumento attributes. Esta máscara es la OR inclusiva a nivel de bits de los bits de máscara de atributo válidos. Si valuemask es cero, los atributos se ignoran y no se referencian.
w
Especifica la ventana.
colormap
Especifica el mapa de colores.

DESCRIPCIÓN

Dependiendo de la máscara de valor, la función XChangeWindowAttributes utiliza los atributos de ventana en la estructura XSetWindowAttributes para cambiar los atributos de ventana especificados. Cambiar el fondo no provoca que el contenido de la ventana cambie. Para repintar la ventana y su fondo, utilice XClearWindow. Establecer el borde o cambiar el fondo de tal manera que el origen de la tesela del borde cambie provoca que el borde se repinte. Cambiar el fondo de una ventana raíz a None o ParentRelative restaura el pixmap de fondo predeterminado. Cambiar el borde de una ventana raíz a CopyFromParent restaura el pixmap de borde predeterminado. Cambiar la gravedad de la ventana no afecta la posición actual de la ventana. Cambiar el backing-store de una ventana oscurecida a WhenMapped o Always, o cambiar los backing-planes, backing-pixel, o save-under de una ventana mapeada puede no tener un efecto inmediato. Cambiar el mapa de colores de una ventana (es decir, definir un nuevo mapa, no cambiar el contenido del mapa existente) genera un evento ColormapNotify. Cambiar el mapa de colores de una ventana visible puede no tener un efecto inmediato en la pantalla porque el mapa puede no estar instalado (ver XInstallColormap). Cambiar el cursor de una ventana raíz a None restaura el cursor predeterminado. Siempre que sea posible, se recomienda compartir los mapas de colores.

Múltiples clientes pueden seleccionar la entrada en la misma ventana. Sus máscaras de eventos se mantienen por separado. Cuando se genera un evento, se informa a todos los clientes interesados. Sin embargo, solo un cliente a la vez puede seleccionar para SubstructureRedirectMask, ResizeRedirectMask y ButtonPressMask. Si un cliente intenta seleccionar alguna de estas máscaras de eventos y algún otro cliente ya ha seleccionado una, se produce un error BadAccess. Solo hay una do-not-propagate-mask para una ventana, no una por cliente.

XChangeWindowAttributes puede generar errores BadAccess, BadColor, BadCursor, BadMatch, BadPixmap, BadValue y BadWindow.

La función XSetWindowBackground establece el fondo de la ventana al valor de píxel especificado. Cambiar el fondo no provoca que el contenido de la ventana cambie. XSetWindowBackground utiliza un pixmap de tamaño indefinido rellenado con el valor de píxel que usted pasó. Si intenta cambiar el fondo de una ventana InputOnly, se produce un error BadMatch.

XSetWindowBackground puede generar errores BadMatch y BadWindow.

La función XSetWindowBackgroundPixmap establece el pixmap de fondo de la ventana al pixmap especificado. El pixmap de fondo puede ser liberado inmediatamente si no se van a realizar más referencias explícitas a él. Si se especifica ParentRelative, se utiliza el pixmap de fondo del padre de la ventana, o en la ventana raíz, se restaura el fondo predeterminado. Si intenta cambiar el fondo de una ventana InputOnly, se produce un error BadMatch. Si el fondo se establece en None, la ventana no tiene un fondo definido.

XSetWindowBackgroundPixmap puede generar errores BadMatch, BadPixmap y BadWindow.

La función XSetWindowBorder establece el borde de la ventana al valor de píxel que usted especifica. Si intenta realizar esto en una ventana InputOnly, se produce un error BadMatch.

XSetWindowBorder puede generar errores BadMatch y BadWindow.

La función XSetWindowBorderPixmap establece el pixmap de borde de la ventana al pixmap que usted especifica. El pixmap de borde puede ser liberado inmediatamente si no se van a realizar más referencias explícitas a él. Si especifica CopyFromParent, se utiliza una copia del pixmap de borde de la ventana padre. Si intenta realizar esto en una ventana InputOnly, se produce un error BadMatch.

XSetWindowBorderPixmap puede generar errores BadMatch, BadPixmap y BadWindow.

La función XSetWindowColormap establece el mapa de colores especificado de la ventana especificada. El mapa de colores debe tener el mismo tipo visual que la ventana, o se producirá un error BadMatch.

XSetWindowColormap puede generar errores BadColor, BadMatch y BadWindow.

DIAGNÓSTICO

BadAccess
Un cliente intentó liberar una entrada de mapa de color que no había asignado previamente.
BadAccess
Un cliente intentó almacenar en una entrada de mapa de color de solo lectura.
BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadCursor
Un valor para un argumento Cursor no nombra un Cursor definido.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero falla al coincidir de alguna otra manera requerida por la solicitud.
BadMatch
Una ventana InputOnly bloquea este atributo.
BadPixmap
Un valor para un argumento Pixmap no nombra un Pixmap definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
