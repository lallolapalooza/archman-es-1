XCreatePixmap(3)

Paquete: libx11

Licencias: MIT AND X11

XCreatePixmap(3) FUNCIONES DE XLIB XCreatePixmap(3)

NOMBRE

XCreatePixmap, XFreePixmap - crear o destruir pixmaps

SINTAXIS

Pixmap XCreatePixmap(Display *display, Drawable d, unsigned int width, unsigned int height, unsigned int depth);

int XFreePixmap(Display *display, Pixmap pixmap);

ARGUMENTOS

d
Especifica en qué pantalla se crea el pixmap.
profundidad
Especifica la profundidad del pixmap.
pantalla
Especifica la conexión con el servidor X.
pixmap
Especifica el pixmap.
ancho

alto
Especifican el ancho y el alto, que definen las dimensiones del pixmap.

DESCRIPCIÓN

La función XCreatePixmap crea un pixmap con el ancho, alto y profundidad que usted especificó y devuelve un ID de pixmap que lo identifica. Es válido pasar una ventana InputOnly al argumento drawable. Los argumentos de ancho y alto deben ser distintos de cero, o se producirá un error BadValue. El argumento de profundidad debe ser una de las profundidades soportadas por la pantalla del drawable especificado, o se producirá un error BadValue.

El servidor utiliza el drawable especificado para determinar en qué pantalla se debe crear el pixmap. El pixmap solo se puede usar en esta pantalla y solo con otros drawables de la misma profundidad (ver XCopyPlane para una excepción a esta regla). El contenido inicial del pixmap no está definido.

XCreatePixmap puede generar errores BadAlloc, BadDrawable y BadValue.

La función XFreePixmap primero elimina la asociación entre el ID del pixmap y el pixmap. Luego, el servidor X libera el almacenamiento del pixmap cuando no hay referencias a él. El pixmap nunca debe ser referenciado de nuevo.

XFreePixmap puede generar un error BadPixmap.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadPixmap
Un valor para un argumento Pixmap no nombra un Pixmap definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
