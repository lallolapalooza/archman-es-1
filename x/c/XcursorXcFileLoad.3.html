NOMBRE

Xcursor - Gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca sencilla diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursor estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso, hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior, hay una capa que crea cursores a partir de una imagen cargada de un archivo o de uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor estándar de X y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar varios cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los usen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de fragmentos. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 bytes en esta cabecera
version:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


type:	CARD32 tipo de entrada
subtype:	CARD32 etiqueta específica del tipo - tamaño para imágenes
position:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


header:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
type:	CARD32 debe coincidir con el tipo en la TOC para este fragmento
subtype:	CARD32 debe coincidir con el subtipo en la TOC para este fragmento
version:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


header:	20 Las cabeceras de comentario son de 20 bytes
type:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtype:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
version:	1
length:	CARD32 longitud en bytes de la cadena UTF-8
string:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


header:	36 Las cabeceras de imagen son de 36 bytes
type:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtype:	CARD32 El subtipo de imagen es el tamaño nominal
version:	1
width:	CARD32 Debe ser menor o igual a 0x7fff
height:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual a la altura
delay:	CARD32 Retraso entre fotogramas de animación en milisegundos
pixels:	LISTofCARD32 Píxeles en formato ARGB empaquetado

TEMAS

Xcursor (en su mayor parte) sigue la especificación de freedesktop.org para los iconos de temas. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas con este formato:
Inherits = nombre-tema

Xcursor utiliza el primer nombre-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Name” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-tema en la línea Inherits=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Inherits=; la especificación de freedesktop.org no es clara sobre si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún punto de la ruta, Xcursor comprueba el tema “default”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* altura real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio

Cursores Animados

XcursorAnimate * XcursorAnimateCreate (
	XcursorCursors 	*cursors)

Envuelve el array de cursores dado en una estructura XcursorAnimate recién asignada, que añade un número de secuencia utilizado en XcursorAnimateNext.

void XcursorAnimateDestroy (
	XcursorAnimate 	*animate)

Descarta los datos animate dados, liberando tanto el array de cursores XcursorCursors como la estructura XcursorAnimate.

Cursor XcursorAnimateNext (
	XcursorAnimate 	*animate)

Devuelve cíclicamente el siguiente Cursor en el array, incrementando el número de secuencia para prepararse para la siguiente llamada.

El llamador es responsable de mostrar la serie de imágenes de Cursor. Xcursor no lo hace.

APIs de Cursores con Glosas

Las funciones X11 XCreateFontCursor y XCreateGlyphCursor utilizan esta parte de la API para extender la característica de cursores principales de X para usar temas.

void XcursorImageHash (
	XImage 	*image,
	unsigned char 	 hash[XCURSOR_BITMAP_HASH_SIZE])

Calcula un hash de la imagen, para mostrar cuando la variable de entorno XCURSOR_DISCOVER está establecida.

void XcursorImagesSetName (
	XcursorImages 	*images,
	const char 	*name)

Asocia el nombre dado con las imágenes.

void XcursorNoticeCreateBitmap (
	Display 	*dpy,
	Pixmap 	 pid,
	unsigned int 	 width,
	unsigned int 	 height)

Comprueba si la pantalla soporta ARGB o temas, y también si el tamaño de la imagen cabe dentro del tamaño máximo del cursor (64 píxeles). Si es así, crea un bitmap del tamaño especificado, y almacena en caché el resultado en Xcursor, identificándolo con el valor Pixmap-id (pid).

void XcursorNoticePutBitmap (
	Display 	*dpy,
	Drawable 	 draw,
	XImage 	*image)

Actualiza el contenido de la imagen en el bitmap especificado por el valor draw (un Pixmap-id). El bitmap debe haber sido creado por XcursorNoticeCreateBitmap.

Cursor XcursorTryShapeBitmapCursor (
	Display 	*dpy,
	Pixmap 	 source,
	Pixmap 	 mask,
	XColor 	*foreground,
	XColor 	*background,
	unsigned int 	 x,
	unsigned int 	 y)

Si la pantalla soporta ARGB o temas, intenta cargar un cursor en la caché de Xcursor usando el parámetro source como Pixmap-id. La fuente ya no puede estar en la caché. Xcursor utiliza el valor hash para identificar la imagen deseada.

Cursor XcursorTryShapeCursor (
	Display 	*dpy,
	Font 	 source_font,
	Font 	 mask_font,
	unsigned int 	 source_char,
	unsigned int 	 mask_char,
	XColor _Xconst 	*foreground,
	XColor _Xconst 	*background)

Si la pantalla soporta ARGB o temas, intenta cargar un cursor en la caché de Xcursor usando el parámetro source_char como forma. Usando

  • el tamaño predeterminado de XcursorGetDefaultSize,
  • el tema predeterminado de XcursorGetTheme, y
  • el parámetro source_char como forma,
Xcursor llama a XcursorShapeLoadImages para cargar las imágenes del cursor. Si tiene éxito, Xcursor utiliza XcursorImagesLoadCursor para cargar la información del cursor.

APIs de Información de Pantalla

XcursorBool XcursorSupportsARGB (
	Display 	*dpy)

Devuelve true si la pantalla soporta cursores ARGB. De lo contrario, los cursores se mapearán a un cursor X principal.

XcursorBool XcursorSupportsAnim (
	Display 	*dpy)

Devuelve true si la pantalla soporta cursores animados. De lo contrario, los cursores se mapearán a un cursor X principal.

XcursorBool XcursorSetDefaultSize (
	Display 	*dpy,
	int 	 size)

Establece el tamaño predeterminado para los cursores en la pantalla especificada. Al cargar cursores, se preferirán aquellos cuyo tamaño nominal sea el más cercano a este tamaño.

int XcursorGetDefaultSize (
	Display 	*dpy)

Obtiene el tamaño predeterminado del cursor.

XcursorBool XcursorSetResizable (
	Display 	*dpy,
	XcursorBool 	 resizable)

Establece el estado actual de cursores redimensionables.

XcursorBool XcursorGetResizable (
	Display 	*dpy)

Obtiene el estado actual de cursores redimensionables.

XcursorBool XcursorSetTheme (
	Display 	*dpy,
	const char 	*theme)

Establece el nombre del tema actual.

char *XcursorGetTheme (
	Display 	*dpy)

Obtiene el nombre del tema actual.

XcursorBool XcursorGetThemeCore (
Display 	*dpy)
XcursorBool XcursorSetThemeCore (
	Display 	*dpy,
	XcursorBool 	 theme_core)

Obtiene o establece la propiedad que indica a Xcursor si habilitar temas para cursores principales.

ENTORNO

Las variables de entorno pueden usarse para anular la configuración de recursos, que a su vez anulan los valores predeterminados compilados.

Algunas de las variables de entorno reconocidas por Xcursor son booleanos, especificados de la siguiente manera:

verdadero para “t”, “1”, “y” o “on”
falso para “f”, “0”, “n” o “off”

Xcursor ignora otros valores para estos booleanos.

HOME
Xcursor interpreta “~” en la lista de búsqueda como el directorio personal, utilizando esta variable en lugar de la base de datos de contraseñas.
XCURSOR_ANIM
Si la pantalla soporta la solicitud Render CreateCursor, y la función Render está habilitada, deshabilita los cursores animados si la variable de entorno es false.
Si la variable de entorno no se proporciona, Xcursor usa el recurso Xcursor.anim.
XCURSOR_CORE
Si la pantalla soporta la solicitud Render CreateCursor, deshabilita la función Render si la variable de entorno es false.
Si la variable de entorno no se proporciona, Xcursor usa el recurso Xcursor.core.
XCURSOR_DISCOVER
Si la variable está establecida, Xcursor activa una función de registro. Muestra el valor hash y la imagen para que los usuarios puedan ver qué nombre de cursor está asociado con cada imagen.
No hay una configuración de recurso correspondiente.
XCURSOR_DITHER
Esta variable establece el dither deseado.
Si la variable de entorno no se proporciona, Xcursor usa el recurso Xcursor.dither.
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor utiliza “threshold”
Estos son los valores reconocidos:
difuso
mediana
ordenado
umbral
XCURSOR_PATH
Esta variable establece la lista de rutas en las que buscar cursores, en lugar de la lista predeterminada compilada.
Los directorios en esta ruta están separados por dos puntos (:).
XCURSOR_RESIZED
Habilita el redimensionamiento automático de cursores para mejorar su tamaño mostrado si la variable de entorno es true.
Si la variable de entorno no se proporciona, Xcursor prueba el recurso Xcursor.resized.
XCURSOR_SIZE
Esta variable establece el tamaño deseado del cursor, en píxeles.
Si la variable de entorno no se proporciona, Xcursor prueba el recurso Xcursor.size.
Si no se proporciona ningún tamaño, ya sea por variable de entorno o configuración de recurso, Xcursor prueba a continuación la configuración del recurso Xft.dpi para adivinar el tamaño de un cursor de 16 puntos.
Finalmente, si Xft.dpi no está establecido, Xcursor utiliza la altura de la pantalla, dividiendo por 48 (suponiendo que la altura es 768).
XCURSOR_THEME
Esta variable selecciona el tema deseado.
Si la variable de entorno no se proporciona, Xcursor prueba el recurso Xcursor.theme.
Si no se encuentra ni la variable de entorno ni el recurso, Xcursor usa el tema predeterminado.
XCURSOR_THEME

ENVIRONMENT

Xcursor.theme
Specifies the cursor theme to use. If unset, the default theme is used. Applications can override this setting using XcursorSetTheme.
Xcursor.theme_core
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.
