NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursor desde archivos. Por encima de eso hay una capa que localiza archivos de cursor basándose en la ruta de la biblioteca y el tema. En la capa superior hay una capa que construye cursores a partir de una imagen cargada de un archivo o uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor X estándar y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSOR

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas varias imágenes de cursor del mismo tamaño nominal; se espera que las aplicaciones las usen como una secuencia animada.

Los archivos de cursor se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de bloques. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la tabla de contenido para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en la tabla de contenido para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para los archivos de cursor; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentario tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imagen tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor sigue (en su mayor parte) la especificación de freedesktop.org para tematizar iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio usando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursor en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, p. ej., como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo “index.theme” dado. Si encuentra un tema heredado, Xcursor busca en la ruta para usarlo también. Xcursor ignora otras claves en el archivo “index.theme”, incluyendo “Nombre” (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede listar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no aclara si se permiten claves múltiples.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “predeterminado”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca en la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte superior. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para la coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* matriz de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Estos tienen un contador de referencias para que múltiples estructuras XcursorAnimate puedan usar el mismo XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Display que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* matriz de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál es el siguiente cursor */
} XcursorAnimate;

resource settings, which in turn override compiled-in default values. .PP Some of the environment variables recognized by Xcursor are booleans, specified as follows: .TP .B true for "t", "1", "y" or "on" .TP .B false for "f", "0", "n" or "off" .PP Xcursor ignores other values for these booleans. .TP .B HOME Xcursor interprets "~" in the search list as the home directory, using this variable rather than the password database. .TP .B XCURSOR_ANIM If the display supports the Render CreateCursor request, and the Render feature is enabled, disable *animated* cursors if the environment variable is *false*. .PP If the environment variable is not given, Xcursor uses the resource Xcursor.anim. .TP .B XCURSOR_CORE If the display supports the Render CreateCursor request disable the Render feature if the environment variable is *false*. .PP If the environment variable is not given, Xcursor uses the resource Xcursor.core. .TP .B XCURSOR_DISCOVER If the variable is set, Xcursor turns on a logging feature. It displays the hash value and the image so that users can see which cursor name is associated with each image. .PP There is no corresponding resource setting. .TP .B XCURSOR_DITHER This variable sets the desired *dither*. .PP If the environment variable is not given, Xcursor uses the resource Xcursor.dither. .PP If neither environment variable or resource is found, Xcursor uses "threshold". .PP These are the recognized values: .TP .B diffuse .TP .B median .TP .B ordered .TP .B threshold .TP .B XCURSOR_PATH This variable sets the list of paths in which to search for cursors, rather than the compiled-in default list. .PP Directories in this path are separated by colons (:). .TP .B XCURSOR_RESIZED Enables automatic resizing of cursors to improve their displayed size if the environment variable is *true*. .PP If the environment variable is not given, Xcursor tries the Xcursor.resized resource. .TP .B XCURSOR_SIZE This variable sets the desired cursor size, in pixels. .PP If the environment variable is not given, Xcursor tries the Xcursor.size resource. .PP If no size is given, whether by environment variable or resource setting, Xcursor next tries the Xft.dpi resource setting to guess the size of a 16-point cursor. .PP Finally, if Xft.dpi is not set, Xcursor uses the display height, dividing by 48 (assuming that the height is 768). .TP .B XCURSOR_THEME This variable selects the desired *theme*. .PP If the environment variable is not given, Xcursor tries the Xcursor.theme resource. .PP If neither environment variable or resource is found, Xcursor uses the *default* theme. .TP .B XCURSOR_THEME_CORE This variable selects whether to enable themes for core cursors. .PP If the environment variable is not given, Xcursor uses the resource Xcursor.theme_core. .SH SEE ALSO X(7), Xcursor.h .SH AUTHOR Kevin E. ENVIRONMENT

Xcursor.theme_core
Habilita los temas para los cursores principales si la variable de entorno es true.
Si la variable de entorno no se proporciona, Xcursor intenta usar el recurso Xcursor.theme_core.
Una aplicación puede habilitar o deshabilitar temas usando XcursorSetThemeCore.
