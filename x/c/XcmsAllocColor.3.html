XcmsAllocColor(3) FUNCIONES DE XLIB XcmsAllocColor(3)

NOMBRE

XcmsAllocColor, XcmsAllocNamedColor - asignar colores

SINTAXIS

Status XcmsAllocColor(Display *display, Colormap colormap, XcmsColor *color_in_out, XcmsColorFormat result_format);

Status XcmsAllocNamedColor(Display *display, Colormap colormap, _Xconst char *color_string, XcmsColor *color_screen_return, XcmsColor *color_exact_return, XcmsColorFormat result_format);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
colormap
Especifica el mapa de colores.
color_exact_return
Devuelve la especificación del color analizada a partir de la cadena de color o analizada a partir de la cadena correspondiente encontrada en una base de datos de nombres de color.
color_in_out
Especifica el color a asignar y devuelve el píxel y el color que se utilizan realmente en el mapa de colores.
color_screen_return
Devuelve el valor del píxel de la celda de color y la especificación del color que se almacena realmente para esa celda. Especifica la cadena de color cuya estructura de definición de color se va a devolver.
result_format
Especifica el formato del color para la especificación del color devuelta.

DESCRIPCIÓN

La función XcmsAllocColor es similar a XAllocColor excepto que el color se puede especificar en cualquier formato. La función XcmsAllocColor llama finalmente a XAllocColor para asignar una celda de color de solo lectura (entrada del mapa de colores) con el color especificado. XcmsAllocColor primero convierte el color especificado a un valor RGB y luego lo pasa a XAllocColor. XcmsAllocColor devuelve el valor del píxel de la celda de color y la especificación del color que realmente se asigna. Esta especificación de color devuelta es el resultado de convertir el valor RGB devuelto por XAllocColor al formato especificado con el argumento result_format. Si no hay interés en una especificación de color devuelta, se pueden omitir cálculos innecesarios si result_format se establece en XcmsRGBFormat. La celda de mapa de colores correspondiente es de solo lectura. Si esta rutina devuelve XcmsFailure, la especificación de color color_in_out no se modifica.

XcmsAllocColor puede generar errores BadColor.

La función XcmsAllocNamedColor es similar a XAllocNamedColor excepto que el color devuelto puede estar en cualquier formato especificado. Esta función llama finalmente a XAllocColor para asignar una celda de color de solo lectura con el color especificado por una cadena de color. La cadena de color se analiza en una estructura XcmsColor (ver XcmsLookupColor), se convierte a un valor RGB y finalmente se pasa a XAllocColor. Si el nombre del color no está en la Codificación de Caracteres Portátil del Host, el resultado es dependiente de la implementación. El uso de mayúsculas o minúsculas no importa.

Esta función devuelve tanto la especificación del color como resultado del análisis (especificación exacta) como la especificación real del color almacenada (especificación de pantalla). Esta especificación de pantalla es el resultado de convertir el valor RGB devuelto por XAllocColor al formato especificado en result_format. Si no hay interés en una especificación de color devuelta, se pueden omitir cálculos innecesarios si result_format se establece en XcmsRGBFormat. Si color_screen_return y color_exact_return apuntan a la misma estructura, el campo píxel se establecerá correctamente, pero los valores de color no están definidos.

XcmsAllocNamedColor puede generar errores BadColor.

DIAGNÓSTICOS

BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
