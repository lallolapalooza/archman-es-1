XcmsCreateCCC(3)

Paquete: libx11

Licencias: MIT AND X11

XcmsCreateCCC(3) FUNCIONES DE XLIB XcmsCreateCCC(3)

NOMBRE

XcmsCreateCCC, XcmsFreeCCC - crear y destruir CCCs

SINTAXIS

XcmsCCC XcmsCreateCCC(Display *display, int screen_number, Visual *visual, XcmsColor *client_white_point, XcmsCompressionProc compression_proc, XPointer compression_client_data, XcmsWhiteAdjustProc white_adjust_proc, XPointer white_adjust_client_data);

void XcmsFreeCCC(XcmsCCC ccc);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
ccc
Especifica el CCC.
client_white_point
Especifica el Punto Blanco del Cliente. Si se especifica NULL, se asume que el Punto Blanco del Cliente es el mismo que el Punto Blanco de la Pantalla. Tenga en cuenta que el miembro pixel se ignora.
compression_client_data
Especifica los datos del cliente para su uso por el procedimiento de compresión de la gama de colores o NULL.
compression_proc
Especifica el procedimiento de compresión de la gama de colores que se va a aplicar cuando un color se encuentra fuera de la gama de colores de la pantalla. Si se especifica NULL y una función que utiliza este CCC debe convertir una especificación de color a un formato dependiente del dispositivo y encuentra un color que está fuera de la gama de colores de la pantalla, esa función devolverá XcmsFailure.
screen_number
Especifica el número de pantalla apropiado en el servidor host.
visual
Especifica el tipo de visualización.
white_adjust_client_data
Especifica los datos del cliente para su uso con el procedimiento de ajuste del punto blanco o NULL.
white_adjust_proc
Especifica el procedimiento de ajuste del punto blanco que se va a aplicar cuando el Punto Blanco del Cliente difiere del Punto Blanco de la Pantalla. NULL indica que no se desea ningún ajuste del punto blanco.

DESCRIPCIÓN

La función XcmsCreateCCC crea un CCC para la pantalla, la pantalla y la visualización especificadas.

La función XcmsFreeCCC libera la memoria utilizada para el CCC especificado. Tenga en cuenta que los CCC predeterminados y los actualmente asociados con mapas de colores son ignorados.
