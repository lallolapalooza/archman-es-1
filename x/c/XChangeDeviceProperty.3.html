XChangeDeviceProperty(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGETDEVICEPROPERTY(3)   XGETDEVICEPROPERTY(3)

NOMBRE

XGetDeviceProperty, XChangeDeviceProperty, XDeleteDeviceProperty - Obtener, cambiar o eliminar una propiedad de dispositivo.

SINOPSIS

#include <X11/extensions/XInput.h>
int XGetDeviceProperty( Display *display,
                        XDevice *device,
                        Atom property,
                        long offset,
                        long length,
                        Bool delete,
                        Atom req_type,
                        Atom *actual_type_return,
                        int *actual_format_return,
                        unsigned long *nitems_return,
                        unsigned long *bytes_after_return,
                        unsigned char **prop_return)
void XChangeDeviceProperty( Display *display,
                            XDevice *device,
                            Atom property,
                            Atom type,
                            int format,
                            int mode,
                            const unsigned char *data,
                            int nelements)
void XDeleteDeviceProperty( Display *display,
                            XDevice *device,
                            Atom property)
actual_type_return
       Devuelve un identificador de átomo que define el tipo real
       de la propiedad.
actual_format_return
       Devuelve el formato real de la propiedad.
bytes_after_return
       Devuelve el número de bytes restantes para leer en la
       propiedad si se realizó una lectura parcial.
data
       Especifica los datos de la propiedad.
delete
       Especifica un valor booleano que determina si la
       propiedad se elimina.
display
       Especifica la conexión con el servidor X.
device
       El dispositivo a capturar.
format
       Especifica si los datos deben ser vistos como una lista de
       cantidades de 8 bits, 16 bits o 32 bits. Los valores posibles son
       8, 16 y 32. Esta información permite al servidor X
       realizar correctamente las operaciones de intercambio de bytes según sea necesario. Si
       el formato es de 16 bits o 32 bits, debes convertir explícitamente
       el puntero de datos a (unsigned char*) en la llamada a
       XChangeDeviceProperty.
length
       Especifica la longitud en múltiplos de 32 bits de los datos a
       recuperar.
mode
       Especifica el modo de operación. Puedes pasar
       PropModeReplace, PropModePrepend o PropModeAppend.
nelements
       Especifica el número de elementos en data.
nitems_return
       Devuelve el número real de elementos de 8 bits, 16 bits o 32 bits
       almacenados en el array prop_return.
num_values
       Especifica el número de elementos en la lista de valores.
offset
       Especifica el desplazamiento en la propiedad especificada (en
       cantidades de 32 bits) donde se deben recuperar los datos.
property
       Especifica la propiedad a modificar o consultar.
prop_return
       Devuelve los datos en el formato especificado. Si el
       formato devuelto es 8, los datos devueltos se representan
       como un array de caracteres. Si el formato devuelto es 16, los
       datos devueltos se representan como una array de tipo entero corto
       y deben ser convertidos a ese tipo para obtener los
       elementos. Si el formato devuelto es 32, los datos de la propiedad
       se almacenarán como una array de longitudes (que en una
       aplicación de 64 bits serán valores de 64 bits que se rellenan
       en los 4 bytes superiores).
req_type
       Especifica el identificador de átomo asociado con el
       tipo de propiedad o AnyPropertyType.

DESCRIPCIÓN

La función XGetDeviceProperty devuelve el tipo real de la propiedad; el formato real de la propiedad; el número de elementos de 8 bits, 16 bits o 32 bits transferidos; el número de bytes restantes para leer en la propiedad; y un puntero a los datos realmente devueltos. Para una descripción detallada de esta función, consulta la página del manual de XGetWindowProperty.

La función XChangeDeviceProperty modifica la propiedad para el dispositivo especificado y provoca que el servidor genere un evento XPropertyNotifyEvent en ese dispositivo. Para una descripción detallada de esta función, consulta la página del manual de XChangeProperty.

La función XDeleteDeviceProperty elimina la propiedad de dispositivo especificada. Ten en cuenta que un cliente no puede eliminar una propiedad creada por un controlador o el servidor. Intentarlo resultará en un error BadAtom.

XGetDeviceProperty puede generar errores BadAtom, BadDevice.

XChangeDeviceProperty puede generar errores BadDevice, BadMatch, BadAtom y BadValue.

XDeleteDeviceProperty puede generar errores BadDevice y BadAtom.

DIAGNÓSTICO

BadAtom
       Un valor no describe un identificador con nombre válido o
       el cliente intentó eliminar una propiedad asignada por el controlador.
BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe.
