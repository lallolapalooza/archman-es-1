XCreateIC(3)

Paquete: libx11

Licencias: MIT AND X11

XCreateIC(3) FUNCIONES DE XLIB XCreateIC(3)

NOMBRE

XCreateIC, XDestroyIC, XIMOfIC - crear, destruir y obtener el método de entrada de un contexto de entrada

SINTAXIS

XIC XCreateIC(XIM im, ...);

void XDestroyIC(XIC ic);

XIM XIMOfIC(XIC ic);

ARGUMENTOS

ic
Especifica el contexto de entrada.
im
Especifica el método de entrada.
...
Especifica la lista de argumentos de longitud variable para establecer los valores de XIC.

DESCRIPCIÓN

La función XCreateIC crea un contexto dentro del método de entrada especificado.

Algunos de los argumentos son obligatorios en el momento de la creación, y el contexto de entrada no se creará si no se proporcionan dichos argumentos. Los argumentos obligatorios son el estilo de entrada y el conjunto de callbacks de texto (si el estilo de entrada seleccionado requiere callbacks). Todos los demás valores del contexto de entrada se pueden establecer más tarde.

XCreateIC devuelve un valor NULL si no se pudo crear ningún contexto de entrada. Se puede devolver un valor NULL por cualquiera de las siguientes razones:

  • No se estableció un argumento requerido.
  • Se estableció un argumento de solo lectura (por ejemplo, XNFilterEvents).
  • El nombre del argumento no es reconocido.
  • El método de entrada encontró un error dependiente de la implementación del método de entrada.

XCreateIC puede generar errores BadAtom, BadColor, BadPixmap y BadWindow.

XDestroyIC destruye el contexto de entrada especificado.

La función XIMOfIC devuelve el método de entrada asociado con el contexto de entrada especificado.

DIAGNÓSTICOS

BadAtom
Un valor para un argumento Atom no nombra un Atom definido.
BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadPixmap
Un valor para un argumento Pixmap no nombra un Pixmap definido.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
