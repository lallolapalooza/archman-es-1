NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores X estándar. Los cursores pueden existir en varios tamaños y la biblioteca selecciona automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construido en un par de capas; en la capa inferior se encuentra el código que puede cargar imágenes de cursores desde archivos. Por encima hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores a partir de una imagen cargada desde un archivo o uno de los cursores X estándar. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud CreateCursor de la extensión Render si es compatible con el servidor X. Donde no es compatible, Xcursor mapea la imagen del cursor a un cursor X estándar y utiliza la solicitud CreateCursor principal.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursores. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar múltiples cursores del mismo tamaño nominal juntos; se espera que las aplicaciones los utilicen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenidos seguida de una secuencia de fragmentos. La tabla de contenidos indica el tipo, subtipo y posición en el archivo de cada fragmento. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de TOC
toc:	LISTofTOC tabla de contenidos

Cada entrada de la tabla de contenidos se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada fragmento en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del fragmento (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en TOC para este fragmento
subtipo:	CARD32 debe coincidir con el subtipo en TOC para este fragmento
versión:	CARD32 número de versión para este tipo de fragmento

Actualmente hay dos tipos de fragmentos definidos para los archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentario son de 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 Cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imagen son de 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (principalmente) sigue la especificación de freedesktop.org para la tematización de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio que utilice el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio de cursores.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en XcursorLibraryLoadImage o XcursorLibraryShape.
•
Si no encuentra ningún archivo de cursor coincidente en el subdirectorio de cursores, Xcursor busca a continuación un archivo de índice.theme en cada directorio de tema para buscar temas heredados. Esas son líneas en este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer nombre-del-tema heredado, ignorando otros que puedan existir en un archivo de índice.theme dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras claves en el archivo de índice.theme, incluyendo Nombre (es decir, el nombre que una aplicación gráfica puede usar como nombre de presentación).

Se puede enumerar más de un nombre-del-tema en la línea Hereda=. La especificación de freedesktop.org establece que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea de Hereda=; la especificación de freedesktop.org no aclara si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema de "predeterminado".

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una sola imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte alto. 


typedef struct _XcursorImage {
    XcursorDim 	 tamaño; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 ancho; 	/* ancho real */
    XcursorDim 	 alto; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto caliente x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto caliente y (debe estar dentro de la imagen) */
    XcursorPixel 	*píxeles; 	/* puntero a los píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras XcursorImage. Todas se liberan cuando se libera XcursorImages en XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimagen; 	/* número de imágenes */
    XcursorImage 	**imágenes; 	/* array de punteros a XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos Cursor. Todos se liberan cuando se libera XcursorCursors. Tienen un recuento de referencias para que múltiples estructuras XcursorAnimate puedan usar los mismos XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* recuento de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursores; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras XcursorAnimate pueden hacer referencia al mismo XcursorCursors; cada una mantiene una referencia que se elimina cuando se libera XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursores; 	/* lista de cursores a usar */
    int 	 secuencia; 	/* cuál es el siguiente cursor */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio

const char 	*name,

int 	 size)

	const char 	*name,

	int 	 size)

Estas funciones buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si theme no es NULL, se utiliza ese.
  • Si theme es NULL, o si no hubo coincidencia para el tema deseado, se utiliza "default" como nombre del tema.
  • Si ninguna búsqueda tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que en el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar name con el resultado.

NAME



  
Xcursor - cursor loading library








SYNOPSIS


#include <Xcursor/Xcursor.h>






DESCRIPTION


The Xcursor library provides an interface to load X cursors from
    theme files. It handles loading, parsing, and displaying cursors, as well as
    managing cursor themes and sizes.




Cursor   File Format


Xcursor supports cursors in the Xcursor file format, which is a
    binary format that stores cursor images and metadata. Cursor files are
    typically found in directories specified by the XCURSOR_PATH environment
    variable or the default system cursor path.

ENVIRONMENT


Environment variables can be used to override resource settings,
    which in turn override compiled-in default values.


Some of the environment variables recognized by Xcursor are
    booleans, specified as follows:





  
true for
    “t”, “1”, “y” or
    “on”

  

  
false for
    “f”, “0”, “n” or
    “off”

  






Xcursor ignores other values for these booleans.



  
HOME

  
Xcursor interprets “~” in the search list as the home
      directory, using this variable rather than the password database.

  
XCURSOR_ANIM

  
If the display supports the Render CreateCursor request, and the Render
      feature is enabled, disable animated cursors if the environment
      variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.anim.





  
XCURSOR_CORE

  
If the display supports the Render CreateCursor request disable the Render
      feature if the environment variable is false.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.core.





  
XCURSOR_DISCOVER

  
If the variable is set, Xcursor turns on a logging feature. It displays
      the hash value and the image so that users can see which cursor name is
      associated with each image.





  

  
There is no corresponding resource setting.





  
XCURSOR_DITHER

  
This variable sets the desired dither.





  

  
If the environment variable is not given, Xcursor uses the resource
      Xcursor.dither.

  

  
If neither environment variable or resource is found, Xcursor uses
      “threshold”

  

  
These are the recognized values:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
This variable sets the list of paths in which to search for cursors,
      rather than the compiled-in default list.





  

  
Directories in this path are separated by colons (:).





  
XCURSOR_RESIZED

  
Enables automatic resizing of cursors to improve their displayed size if
      the environment variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.resized resource.





  
XCURSOR_SIZE

  
This variable sets the desired cursor size, in pixels.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.size resource.

  

  
If no size is given, whether by environment variable or resource setting,
      Xcursor next tries the Xft.dpi resource setting to guess the size
      of a 16-point cursor.

  

  
Finally, if Xft.dpi is not set, Xcursor uses the display height,
      dividing by 48 (assuming that the height is 768).





  
XCURSOR_THEME

  
This variable selects the desired theme.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme resource.

  

  
If neither environment variable or resource is found, Xcursor uses the
      default theme.

NOMBRE


XcursorSetThemeCore, XcursorGetThemeCore - establecer el tema del cursor básico






SINOPSIS


#include <Xcursor/Xcursor.h>


Bool
XcursorSetThemeCore(Display *display, const char *theme_name);

const char *
XcursorGetThemeCore(Display *display);







DESCRIPCIÓN


La biblioteca Xcursor proporciona las funciones
    XcursorSetThemeCore y
    XcursorGetThemeCore para gestionar el tema de los cursores
    básicos. Estas funciones le permiten establecer y obtener el nombre del tema
    de cursor que se utilizará para los cursores básicos.




XcursorSetThemeCore


XcursorSetThemeCore establece el nombre del tema
    del cursor básico. El argumento display es una conexión
    abierta al servidor X. El argumento theme_name es una
    cadena de caracteres que especifica el nombre del tema del cursor a utilizar.
    Si theme_name es NULL, se
    deshabilitarán los temas de cursores básicos.


La función devuelve True si el tema se
    estableció correctamente y False en caso contrario.






XcursorGetThemeCore


XcursorGetThemeCore recupera el nombre del
    tema del cursor básico actualmente establecido. El argumento
    display es una conexión abierta al servidor X.


La función devuelve un puntero a una cadena de caracteres que
    contiene el nombre del tema del cursor básico. Si no hay ningún tema
    establecido, devuelve NULL.








VISIÓN GENERAL FUNCIONAL


La biblioteca Xcursor permite a las aplicaciones especificar un tema
    de cursor para que se utilice en todo el sistema. Esto permite a los usuarios
    personalizar la apariencia de sus cursores. Las funciones
    XcursorSetThemeCore y
    XcursorGetThemeCore son parte de esta funcionalidad,
    permitiendo a las aplicaciones interactuar programáticamente con el sistema de
    temas de cursores.






TIPOS DE DATOS


No se definen tipos de datos específicos para estas funciones.






FUNCIONES



  
XcursorSetThemeCore

  
Establece el tema del cursor básico.

  
XcursorGetThemeCore

  
Obtiene el tema del cursor básico.








AMBIENTE



  
Xcursor.theme_core

  
Recurso X que establece el tema del cursor básico. Si este recurso está
      establecido en el archivo de configuración de X, se utilizará para los
      cursores básicos. Este recurso se puede establecer mediante la utilidad
      xrdb.





  
XCURSORTYPE

  
Variable de entorno que puede usarse para establecer el tema del cursor
      básico. Si se establece esta variable de entorno, su valor se utilizará como
      nombre del tema del cursor básico. Por ejemplo,
      export XCURSORTYPE=MyTheme establecerá el tema del
      cursor básico en "MyTheme".





  

  
Si la variable de entorno no se proporciona, Xcursor intenta con el
      recurso Xcursor.theme_core.

  

  
Una aplicación puede habilitar o deshabilitar temas usando
      XcursorSetThemeCore.
