XCURSOR(3) Versión X 11 XCURSOR(3)

NOMBRE

Xcursor - Biblioteca de gestión de cursores

SINOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPCIÓN

Xcursor es una biblioteca simple diseñada para ayudar a localizar y cargar cursores. Los cursores se pueden cargar desde archivos o memoria. Existe una biblioteca de cursores comunes que se mapean a los nombres de cursores estándar de X. Los cursores pueden existir en varios tamaños y la biblioteca elige automáticamente el mejor tamaño.

VISIÓN GENERAL FUNCIONAL

Xcursor está construida en un par de capas; en la capa inferior hay código que puede cargar imágenes de cursores desde archivos. Por encima de eso hay una capa que localiza archivos de cursores basándose en la ruta de la biblioteca y el tema. En la parte superior hay una capa que construye cursores a partir de una imagen cargada desde un archivo o uno de los cursores estándar de X. Al usar imágenes cargadas desde archivos, Xcursor prefiere usar la solicitud `CreateCursor` de la extensión Render si es soportada por el servidor X. Donde no es soportada, Xcursor mapea la imagen del cursor a un cursor estándar de X y usa la solicitud `CreateCursor` del núcleo.

ARCHIVOS DE CURSORES

Xcursor define un nuevo formato para cursores en disco. Cada archivo contiene una o más imágenes de cursor. Cada imagen de cursor está etiquetada con un tamaño nominal para que se pueda seleccionar automáticamente el mejor tamaño. Se pueden cargar juntas múltiples imágenes de cursores del mismo tamaño nominal; se espera que las aplicaciones las usen como una secuencia animada.

Los archivos de cursores se almacenan como una cabecera que contiene una tabla de contenido seguida de una secuencia de bloques. La tabla de contenido indica el tipo, subtipo y posición en el archivo de cada bloque. La cabecera del archivo se ve así:


mágica:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
cabecera:	CARD32 bytes en esta cabecera
versión:	CARD32 número de versión del archivo
ntoc:	CARD32 número de entradas de la tabla de contenido
toc:	LISTofTOC tabla de contenido

Cada entrada de la tabla de contenido se ve así:


tipo:	CARD32 tipo de entrada
subtipo:	CARD32 etiqueta específica del tipo - tamaño para imágenes
posición:	CARD32 posición absoluta en bytes de la tabla en el archivo

Cada bloque en el archivo tiene un conjunto de campos de cabecera comunes seguidos de campos adicionales específicos del tipo:


cabecera:	CARD32 bytes en la cabecera del bloque (incluyendo campos específicos del tipo)
tipo:	CARD32 debe coincidir con el tipo en la TOC para este bloque
subtipo:	CARD32 debe coincidir con el subtipo en la TOC para este bloque
versión:	CARD32 número de versión para este tipo de bloque

Actualmente hay dos tipos de bloques definidos para archivos de cursores; comentarios e imágenes. Los comentarios se ven así:


cabecera:	20 Las cabeceras de comentario tienen 20 bytes
tipo:	0xfffe0001 El tipo de comentario es 0xfffe0001
subtipo:	{ 1 (COPYRIGHT), 2 (LICENSE), 3 (OTHER) }
versión:	1
longitud:	CARD32 longitud en bytes de la cadena UTF-8
cadena:	LISTofCARD8 cadena UTF-8

Las imágenes se ven así:


cabecera:	36 Las cabeceras de imagen tienen 36 bytes
tipo:	0xfffd0002 El tipo de imagen es 0xfffd0002
subtipo:	CARD32 El subtipo de imagen es el tamaño nominal
versión:	1
ancho:	CARD32 Debe ser menor o igual a 0x7fff
alto:	CARD32 Debe ser menor o igual a 0x7fff
xhot:	CARD32 Debe ser menor o igual al ancho
yhot:	CARD32 Debe ser menor o igual al alto
retraso:	CARD32 Retraso entre fotogramas de animación en milisegundos
píxeles:	LISTofCARD32 Píxeles empaquetados en formato ARGB

TEMAS

Xcursor (en su mayoría) sigue la especificación de freedesktop.org para temas de iconos. La ruta de búsqueda predeterminada que utiliza es

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

Dentro de cada uno de estos directorios, busca un directorio utilizando el nombre del tema:

•
Dentro del directorio del tema, busca archivos de cursores en el subdirectorio “cursors”.
Xcursor busca un archivo específico, que debe ser uno de los nombres de forma del cursor, por ejemplo, como se usa en `XcursorLibraryLoadImage` o `XcursorLibraryShape`.
•
Si no encuentra un archivo de cursor coincidente en el subdirectorio “cursors”, Xcursor busca a continuación un archivo “index.theme” en cada directorio de tema para buscar temas heredados. Esas son líneas con este formato:
Hereda = nombre-del-tema

Xcursor utiliza el primer `nombre-del-tema` heredado, ignorando otros que puedan existir en un archivo `index.theme` dado. Si encuentra un tema heredado, Xcursor busca a lo largo de la ruta para usarlo también. Xcursor ignora otras `claves` en el archivo `index.theme`, incluido `Name` (es decir, el nombre que una aplicación gráfica puede usar como `nombre de presentación`).

Se puede enumerar más de un `nombre-del-tema` en la línea Hereda=. La especificación de freedesktop.org indica que los elementos de la lista están separados por comas. Xcursor también acepta punto y coma, pero traduce ambos a dos puntos al buscar en la ruta. Xcursor espera solo una línea Hereda=; la especificación de freedesktop.org no es clara sobre si se permiten múltiples claves.

Si no se establece ningún tema, o si no se encuentra ningún cursor para el tema especificado en ningún lugar de la ruta, Xcursor comprueba el tema “default”.

Cuando Xcursor encuentra un archivo de cursor, deja de buscar. Siempre utiliza el primer archivo de cursor encontrado mientras busca a lo largo de la ruta.

TIPOS DE DATOS

XcursorImage
contiene una única imagen de cursor en memoria. Cada píxel del cursor es un valor de 32 bits que contiene ARGB con A en el byte más alto. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* tamaño nominal para coincidencia */
    XcursorDim 	 width; 	/* ancho real */
    XcursorDim 	 height; 	/* alto real */
    XcursorDim 	 xhot; 	/* punto activo x (debe estar dentro de la imagen) */
    XcursorDim 	 yhot; 	/* punto activo y (debe estar dentro de la imagen) */
    XcursorPixel 	*pixels; 	/* puntero a píxeles */
} XcursorImage;
XcursorImages
contiene múltiples estructuras `XcursorImage`. Todas se liberan cuando se libera `XcursorImages` en `XcursorImagesDestroy`. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* número de imágenes */
    XcursorImage 	**images; 	/* array de punteros XcursorImage */
} XcursorImages;
XcursorCursors
Contiene múltiples objetos `Cursor`. Todos se liberan cuando se libera `XcursorCursors`. Tienen un contador de referencias para que múltiples estructuras `XcursorAnimate` puedan usar el mismo `XcursorCursors`. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* Pantalla que contiene los cursores */
    int 	 ref; 	/* contador de referencias */
    int 	 ncursor; 	/* número de cursores */
    Cursor 	*cursors; 	/* array de cursores */
} XcursorCursors;
XcursorAnimate
Hace referencia a un conjunto de cursores y una secuencia dentro de ese conjunto. Múltiples estructuras `XcursorAnimate` pueden referenciar el mismo `XcursorCursors`; cada una mantiene una referencia que se elimina cuando se libera `XcursorAnimate`. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* lista de cursores a usar */
    int 	 sequence; 	/* cuál cursor es el siguiente */
} XcursorAnimate;
XcursorFile
Xcursor proporciona una API abstracta para acceder a los datos del archivo. Xcursor proporciona una implementación stdio de esta API abstracta; las aplicaciones son libres de crear implementaciones adicionales. Estas funciones son paralelas a las funciones stdio. 


typedef struct _XcursorFile {
    int (*read)(
       struct _XcursorFile *	/* file */
    );
    int (*write)(
       struct _XcursorFile *	/* file */
    );
    int (*seek)(
       struct _XcursorFile *	/* file */
    );
    int (*close)(
       struct _XcursorFile *	/* file */
    );
    void 	*private_data; 	/* private data for the implementation */
} XcursorFile;

NAME

xcursor - cursor loading library

SYNOPSIS

#include <X11/Xcursor/Xcursor.h>

DESCRIPTION

The Xcursor library provides utilities for loading cursors from cursor theme directories, and for creating and managing animated cursors. It supports cursors of arbitrary size and color depth, and provides fallback mechanisms for displays which do not support these features.

Cursor Loading APIs

XcursorImages * XcursorImagesCreate (
	int 	 width,
	int 	 height)

Allocate a new XcursorImages structure to hold images of the given size. The images should be stored in Xcursor's internal format.

void XcursorImagesDestroy (
	XcursorImages 	*images)

Destroy the given XcursorImages structure and free all associated memory.

void XcursorImagesSetCursor (
	XcursorImages 	*images,
	Cursor 	 cursor)

Set the given cursor to be the actual cursor represented by the XcursorImages structure. This is typically called after a cursor has been created by XcursorImagesLoadCursor.

Cursor XcursorImagesLoadCursor (
	Display 	*dpy,
	XcursorImages 	*images)

Load the cursor described by the XcursorImages structure onto the specified display. This function will attempt to create the cursor with the highest possible color depth, falling back to a core X cursor if necessary. It returns the X11 Cursor ID.

XcursorImages * XcursorImagesLoad (
	const char 	*file)

Load cursor images from the specified file. The file is expected to be in the Xcursor file format (typically ending in .xmc).

XcursorImages * XcursorImagesLoadQuery (
	Display 	*dpy,
	const char 	*name)

Load cursor images from the named cursor within the current cursor theme. If no theme is set, or the name is not found in the theme, it will try to load it from the default cursor theme.

XcursorImages * XcursorShapeLoadImages (
	Display 	*dpy,
	XcursorShape 	 shape)

Load the images for the specified cursor shape from the current cursor theme. This is the preferred way to load standard cursors.

XcursorImages * XcursorFileLoadImages (
	FILE 	*file)

Load cursor images from the given file stream.

void XcursorImagesSetName (
	XcursorImages 	*images,
	const char 	*name)

Associates the given name with the images. This is used internally for lookup.

const char * XcursorImagesGetName (
	XcursorImages 	*images)

Returns the name associated with the images.

XcursorSize * XcursorSizesCreate (
	void)

Create an empty list of cursor sizes.

void XcursorSizesAdd (
	XcursorSize 	*sizes,
	int 	 width,
	int 	 height)

Add a new size to the list.

void XcursorSizesDestroy (
	XcursorSize 	*sizes)

Destroy the list of cursor sizes.

XcursorImages * XcursorThemeFindSize (
	XcursorSize 	*sizes,
	int 	 width,
	int 	 height)

Find a cursor image from the current theme that best matches the specified size.

XcursorImages * XcursorThemeFindName (
	const char 	*name,
	int 	 width,
	int 	 height)

Find a cursor image by name from the current cursor theme, attempting to match the specified size.

XcursorImages * XcursorThemeLoadImages (
	const char 	*theme,
	const char 	*name,

ENVIRONMENT

Environment variables can be used to override resource settings, which in turn override compiled-in default values.

Some of the environment variables recognized by Xcursor are booleans, specified as follows:

true for “t”, “1”, “y” or “on”
false for “f”, “0”, “n” or “off”

Xcursor ignores other values for these booleans.

HOME
Xcursor interprets “~” in the search list as the home directory, using this variable rather than the password database.
XCURSOR_ANIM
If the display supports the Render CreateCursor request, and the Render feature is enabled, disable animated cursors if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.anim.
XCURSOR_CORE
If the display supports the Render CreateCursor request disable the Render feature if the environment variable is false.
If the environment variable is not given, Xcursor uses the resource Xcursor.core.
XCURSOR_DISCOVER
If the variable is set, Xcursor turns on a logging feature. It displays the hash value and the image so that users can see which cursor name is associated with each image.
There is no corresponding resource setting.
XCURSOR_DITHER
This variable sets the desired dither.
If the environment variable is not given, Xcursor uses the resource Xcursor.dither.
If neither environment variable or resource is found, Xcursor uses “threshold”
These are the recognized values:
diffuse
median
ordered
threshold
XCURSOR_PATH
This variable sets the list of paths in which to search for cursors, rather than the compiled-in default list.
Directories in this path are separated by colons (:).
XCURSOR_RESIZED
Enables automatic resizing of cursors to improve their displayed size if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.resized resource.
XCURSOR_SIZE
This variable sets the desired cursor size, in pixels.
If the environment variable is not given, Xcursor tries the Xcursor.size resource.
If no size is given, whether by environment variable or resource setting, Xcursor next tries the Xft.dpi resource setting to guess the size of a 16-point cursor.
Finally, if Xft.dpi is not set, Xcursor uses the display height, dividing by 48 (assuming that the height is 768).
XCURSOR_THEME
This variable selects the desired theme.
If the environment variable is not given, Xcursor tries the Xcursor.theme resource.
If neither environment variable or resource is found, Xcursor uses the default theme.
XCURSOR_TH
If the environment variable is set to true, Xcursor enables themes for core pointers.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.

NAME

XcursorSetThemeCore, XcursorGetThemeCore - enable/disable core cursor themes

SYNOPSIS

void XcursorSetThemeCore
(Display *display,
int enable);
int XcursorGetThemeCore
(Display *display);

DESCRIPTION

The Xcursor library provides functions to load and manage cursors for the X Window System. This library is part of the Xcursor library, which provides a more flexible and efficient way to handle cursors compared to the traditional X cursor functions.

The functions XcursorSetThemeCore and XcursorGetThemeCore are used to control whether the Xcursor library should attempt to load cursor themes for core cursors. Core cursors are the standard cursors provided by the X server (e.g., left_ptr, hand2, text).

FUNCTIONAL OVERVIEW

When cursor theming is enabled for core cursors, the Xcursor library will look for cursor theme files in standard locations (e.g., /usr/share/icons/default/cursors or ~/.icons/default/cursors) and try to load the appropriate cursor for each core cursor name. This allows applications to use custom cursor themes provided by the user or system.

If cursor theming is disabled for core cursors, the Xcursor library will use the default core cursors provided by the X server.

DATATYPES

No specific datatypes are introduced by these functions. They operate on the standard X Window System Display structure.

FUNCTIONS

void XcursorSetThemeCore(Display *display,
int enable);
Sets the state for enabling or disabling core cursor themes.

The display argument is a pointer to the Display structure representing the connection to the X server.

The enable argument is an integer. If it is non-zero (typically 1), core cursor themes are enabled. If it is zero, core cursor themes are disabled.

int XcursorGetThemeCore(Display *display);
Retrieves the current state for enabling or disabling core cursor themes.

The display argument is a pointer to the Display structure representing the connection to the X server.

Returns a non-zero integer if core cursor themes are currently enabled, and zero otherwise.

ENVIRONMENT

Xcursor.theme_core
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.

CAVEATS

Xcursor will probably change radically in the future; weak attempts will be made to retain some level of source-file compatibility.
