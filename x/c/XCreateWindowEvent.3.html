XCreateWindowEvent(3)

Paquete: libx11

Licencias: MIT AND X11

XCreateWindowEvent(3) FUNCIONES DE XLIB XCreateWindowEvent(3)

NOMBRE

XCreateWindowEvent - estructura del evento CreateNotify

ESTRUCTURAS

La estructura para los eventos CreateNotify contiene:

typedef struct {
        int type;       /* CreateNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del cual se leyó el evento */
        Window parent;  /* padre de la ventana */
        Window window;  /* id de la ventana creada */
        int x, y;       /* ubicación de la ventana */
        int width, height;      /* tamaño de la ventana */
        int border_width;       /* ancho del borde */
        Bool override_redirect; /* la creación debe ser anulada */
} XCreateWindowEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero a la pantalla en la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero expandido de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

El miembro parent se establece en el padre de la ventana creada. El miembro window especifica la ventana creada. Los miembros x e y se establecen en las coordenadas de la ventana creada relativas al origen de la ventana padre e indican la posición de la esquina exterior superior izquierda de la ventana creada. Los miembros width y height se establecen en el tamaño interior de la ventana creada (sin incluir el borde) y son siempre distintos de cero. El miembro border_width se establece en el ancho del borde de la ventana creada, en píxeles. El miembro override_redirect se establece en el atributo override-redirect de la ventana. Los clientes del gestor de ventanas normalmente deberían ignorar esta ventana si el miembro override_redirect es True.
