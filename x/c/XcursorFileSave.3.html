XcursorFileSave(3)

Paquete: libxcursor

Licencias: HPND-sell-variant

XcursorFileSave(3) X Version 11 XcursorFileSave(3)

NOMBRE

XcursorFileSave - Guardar un cursor en un archivo

SINOPSIS

#include <X11/Xcursor/Xcursor.h>


Status
XcursorFileSave(
    const char *filename,
    XcursorImages *images
);


Status
XcursorFileSaveToHeap(
    char **buf,
    int *size,
    XcursorImages *images
);

DESCRIPCIÓN

La biblioteca Xcursor proporciona las rutinas para guardar un conjunto de imágenes de cursor en un archivo en el formato de archivo de cursor Xcur. Esto incluye imágenes de diferentes tamaños para que el sistema pueda elegir el mejor tamaño para la resolución actual.

XcursorFileSave() guarda las imágenes de cursor en el archivo especificado por filename. El archivo se sobrescribirá si ya existe.

XcursorFileSaveToHeap() guarda las imágenes de cursor en un búfer en memoria. El búfer se asigna dentro de esta función y el puntero se devuelve en buf. El tamaño asignado del búfer se devuelve en size.

El programador es responsable de liberar el búfer en memoria asignado por XcursorFileSaveToHeap() usando free(3).

En el caso de los archivos de cursor Xcur, los diferentes tamaños se empaquetan en un solo archivo. El programa que lee los archivos de cursor puede entonces elegir el tamaño que mejor se adapte a la pantalla.

La secuencia de imágenes puede ser una animación. La biblioteca Xcursor no hace nada especial con las animaciones, sino que las empaqueta en el archivo.

VALOR DE RETORNO

Ambas funciones devuelven XcursorSuccess si tienen éxito o XcursorFailure si fallan. Los errores pueden incluir la imposibilidad de abrir el archivo (para XcursorFileSave), o la imposibilidad de asignar memoria suficiente.

Lectura de imágenes de la biblioteca

XcursorImage *XcursorLibraryLoadImage (
const char 	*nombre,
const char 	*tema,
int 	 tamaño)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*nombre,
	const char 	*tema,
	int 	 tamaño)

Estas buscan en la ruta de la biblioteca, cargando el primer archivo encontrado del tamaño deseado, utilizando una función privada (XcursorScanTheme) para encontrar el tema apropiado:

  • Si tema no es NULL, se utiliza ese.
  • Si tema es NULL, o si no hubo coincidencia para el tema deseado, se utiliza "default" como nombre del tema.
  • Si ninguna de las búsquedas tiene éxito, estas funciones devuelven NULL.
Las dos funciones difieren en algo más que en el número de imágenes cargadas:
  • XcursorLibraryLoadImage llama a XcursorFileLoadImage pero
  • XcursorLibraryLoadImages llama a XcursorFileLoadImages, y (en caso de éxito) llama a XcursorImagesSetName para asociar nombre con el resultado.

AMBIENTE




Xcursor.theme_core


Habilita temas para cursores principales si la variable de entorno es
true.








Si no se proporciona la variable de entorno, Xcursor intenta el recurso
Xcursor.theme_core.




Una aplicación puede habilitar o deshabilitar temas usando
XcursorSetThemeCore.
