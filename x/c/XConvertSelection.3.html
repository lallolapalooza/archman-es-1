XSetSelectionOwner(3) FUNCIONES DE XLIB XSetSelectionOwner(3)

NOMBRE

XSetSelectionOwner, XGetSelectionOwner, XConvertSelection - manipular la selección de ventanas

SINTAXIS

int XSetSelectionOwner(Display *display, Atom selection, Window owner, Time time);

Window XGetSelectionOwner(Display *display, Atom selection);

int XConvertSelection(Display *display, Atom selection, Atom target, Atom property, Window requestor, Time time);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
owner
Especifica el propietario del átomo de selección especificado. Puedes pasar una ventana o None.
property
Especifica el nombre de la propiedad. También puedes pasar None.
requestor
Especifica el solicitante.
selection
Especifica el átomo de selección.
target
Especifica el átomo de destino.
time
Especifica la hora. Puedes pasar una marca de tiempo o CurrentTime.

DESCRIPCIÓN

La función XSetSelectionOwner cambia el propietario y la hora del último cambio para la selección especificada y no tiene ningún efecto si la hora especificada es anterior a la hora del último cambio de la selección especificada o es posterior a la hora actual del servidor X. De lo contrario, la hora del último cambio se establece en la hora especificada, reemplazando CurrentTime por la hora actual del servidor. Si la ventana propietaria se especifica como None, entonces el propietario de la selección se convierte en None (es decir, sin propietario). De lo contrario, el propietario de la selección se convierte en el cliente que ejecuta la solicitud.

Si el nuevo propietario (ya sea un cliente o None) no es el mismo que el propietario actual de la selección y el propietario actual no es None, al propietario actual se le envía un evento SelectionClear. Si el cliente que es el propietario de una selección termina más tarde (es decir, su conexión se cierra) o si la ventana propietaria que ha especificado en la solicitud se destruye más tarde, el propietario de la selección revierte automáticamente a None, pero la hora del último cambio no se ve afectada. El átomo de selección no es interpretado por el servidor X. XGetSelectionOwner devuelve el ID de la ventana propietaria, que se informa en los eventos SelectionRequest y SelectionClear. Las selecciones son globales al servidor X.

XSetSelectionOwner puede generar errores BadAtom y BadWindow.

La función XGetSelectionOwner devuelve el ID de ventana asociado con la ventana que actualmente posee la selección especificada. Si no se especificó ninguna selección, la función devuelve la constante None. Si se devuelve None, no hay propietario para la selección.

XGetSelectionOwner puede generar un error BadAtom.

XConvertSelection solicita que la selección especificada se convierta al tipo de destino especificado:

  • Si la selección especificada tiene un propietario, el servidor X envía un evento SelectionRequest a ese propietario.
  • Si no existe ningún propietario para la selección especificada, el servidor X genera un evento SelectionNotify al solicitante con la propiedad None.

Los argumentos se pasan sin cambios en cualquiera de los eventos. Existen dos átomos de selección predefinidos: PRIMARY y SECONDARY.

XConvertSelection puede generar errores BadAtom y BadWindow.

DIAGNÓSTICOS

BadAtom
Un valor para un argumento Atom no nombra un Átomo definido.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.
