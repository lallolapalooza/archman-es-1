XcmsSetWhiteAdjustProc(3) FUNCIONES DE XLIB XcmsSetWhiteAdjustProc(3)

NOMBRE

XcmsSetWhitePoint, XcmsSetWhiteAdjustProc - modificar atributos de CCC

SINTAXIS

Status XcmsSetWhitePoint(XcmsCCC ccc, XcmsColor *color);

XcmsWhiteAdjustProc XcmsSetWhiteAdjustProc(XcmsCCC ccc, XcmsWhiteAdjustProc white_adjust_proc, XPointer client_data);

ARGUMENTOS

ccc
Especifica el CCC.
client_data
Especifica los datos del cliente para el procedimiento de ajuste del punto blanco o NULL.
color
Especifica el nuevo Punto Blanco del Cliente.
white_adjust_proc
Especifica el procedimiento de ajuste del punto blanco.

DESCRIPCIÓN

La función XcmsSetWhitePoint cambia el Punto Blanco del Cliente en el CCC especificado. Tenga en cuenta que el miembro `pixel` se ignora y que la especificación del color no se modifica al regresar. El formato para el nuevo punto blanco debe ser XcmsCIEXYZFormat, XcmsCIEuvYFormat, XcmsCIExyYFormat o XcmsUndefinedFormat. Si el argumento `color` es NULL, esta función establece el componente de formato de la especificación del Punto Blanco del Cliente a XcmsUndefinedFormat, indicando que se asume que el Punto Blanco del Cliente es el mismo que el Punto Blanco de la Pantalla.

Esta función devuelve un estado distinto de cero si el formato para el nuevo punto blanco es válido; de lo contrario, devuelve cero.

La función XcmsSetWhiteAdjustProc primero establece el procedimiento de ajuste del punto blanco y los datos del cliente en el CCC especificado con el procedimiento y los datos del cliente recién especificados, y luego devuelve el procedimiento antiguo.
