NOMBRE

Xcomposite - biblioteca de la extensión X Composite

SINOPSIS

#include <X11/extensions/Xcomposite.h>

Bool XCompositeQueryExtension(Display *dpy, int *event_base_return, int *error_base_return);

Status XCompositeQueryVersion(Display *dpy, int *major_version_return, int *minor_version_return);

int XCompositeVersion(void);

void XCompositeRedirectWindow(Display *dpy, Window window, int update);

void XCompositeRedirectSubwindows(Display *dpy, Window window, int update);

void XCompositeUnredirectWindow(Display *dpy, Window window, int update);

void XCompositeUnredirectSubwindows(Display *dpy, Window window, int update);

XserverRegion XCompositeCreateRegionFromBorderClip(Display *dpy, Window window);

DESCRIPCIÓN

La extensión composite proporciona varios mecanismos relacionados:

Almacenamiento por jerarquía

La renderización de toda una jerarquía de ventanas se redirige a un almacenamiento fuera de pantalla. Los píxeles de esa jerarquía están disponibles siempre que sea visible. El almacenamiento se reasigna automáticamente cuando la ventana de nivel superior cambia de tamaño. El contenido más allá de la geometría de la ventana superior no se conserva.

Actualización automática de sombra

Cuando una jerarquía se renderiza fuera de pantalla, el servidor X proporciona un mecanismo automático para presentar ese contenido dentro de la ventana padre. La implementación es libre de hacer que esta actualización se retrase una cantidad de tiempo no especificada respecto a las operaciones de renderización reales. Este mecanismo de actualización automática puede deshabilitarse para que el contenido de la ventana padre pueda ser determinado completamente por una aplicación externa.

Ventana de superposición compuesta (Composite Overlay Window)

La versión 0.3 del protocolo agrega la Ventana de superposición compuesta, que proporciona a los gestores de composición una superficie sobre la cual dibujar sin interferencias. Esta ventana está siempre encima de las ventanas normales y siempre debajo de la ventana del protector de pantalla. Es una ventana InputOutput con el ancho y alto de las dimensiones de la pantalla. Su visual es el visual de la raíz y su borde tiene un ancho de cero. Los intentos de redirigirla usando la extensión composite se ignoran. Esta ventana no aparece en la respuesta de la solicitud QueryTree. También es una ventana de redirección automática (override redirect). Estas dos últimas características la hacen invisible para los gestores de ventanas y otros clientes de X11. La única forma de acceder al XID de esta ventana es a través de la solicitud CompositeGetOverlayWindow. Inicialmente, la Ventana de superposición compuesta está desmapeada.

Recorte de la ventana padre

La versión 0.4 del protocolo modifica la semántica del recorte de la ventana padre en presencia de hijos redirigidos manualmente. Con esta versión, el área en el padre cubierta por hijos redirigidos manualmente se deja en la lista de recorte del padre en lugar de eliminarse como en versiones anteriores.

El almacenamiento fuera de pantalla puede crearse para ventanas individuales o para todos los hijos de una ventana. La actualización manual de sombra puede ser seleccionada por una sola aplicación por ventana; la actualización manual también puede seleccionarse por ventana o por cada hijo de una ventana. La detección de cuándo actualizar puede hacerse con la extensión Damage.

El almacenamiento fuera de pantalla incluye el contenido de la ventana, sus bordes y el contenido de todos los descendientes.

ARGUMENTOS

display

Puntero a la estructura Display devuelta por XOpenDisplay para la conexión con el servidor X.

event_base_return

Puntero a un entero donde se almacenará el valor base para los eventos de la Extensión Composite.

error_base_return

Puntero a un entero donde se almacenará el valor base para los errores de la Extensión Composite.

major_version_return

Puntero a un entero donde se almacenará la versión mayor de la Extensión Composite soportada por el servidor X.

minor_version_return

Puntero a un entero donde se almacenará la versión menor de la Extensión Composite soportada por el servidor X.

window

Especifica el ID de la ventana sobre la que operar.

update

Especifica el modo de actualización del contenido de la ventana. Debe ser CompositeRedirectAutomatic o CompositeRedirectManual.

FUNCIONES

XCompositeQueryExtension

XCompositeQueryExtension determina si la Extensión Composite está disponible en la pantalla dada. Devuelve True si la extensión es soportada, de lo contrario False. Si la extensión está presente, se devuelven los valores base para los eventos y errores, y pueden usarse para decodificar los valores de eventos y errores entrantes.

XCompositeQueryVersion

XCompositeQueryVersion determina si el Servidor X soporta una versión de la Extensión X Composite compatible con la biblioteca cliente. Se devuelve un Status distinto de cero si se soporta una versión compatible de la extensión, de lo contrario se devuelve un Status cero. Si la extensión es soportada, se devuelven los números de versión mayor y menor para indicar el nivel de soporte de la Extensión Composite. Ninguna otra función de XComposite (excepto XCompositeQueryExtension) puede ser llamada antes de esta función. Si un cliente viola esta regla, los efectos de todas las llamadas posteriores de XComposite que realice no están definidos.

XCompositeVersion

XCompositeVersion devuelve la versión de la biblioteca X Composite. El número de versión está codificado como: (mayor * 10000) + (menor * 100) + revisión

Por ejemplo, la versión 1.4.6 se codificaría como el entero 10406.

XCompositeRedirectWindow

XCompositeRedirectWindow solicita al servidor X que dirija la jerarquía que comienza en window a un almacenamiento fuera de pantalla. El argumento update especifica si el contenido se refleja automáticamente en la ventana padre o no. Solo un cliente a la vez puede especificar un tipo de actualización de CompositeRedirectManual, otro intento resultará en un error BadAccess. Cuando todos los clientes que habilitan la redirección terminan, la redirección se deshabilitará automáticamente.

La ventana raíz no puede ser redirigida. Hacerlo resulta en un error BadMatch. Especificar un ID de ventana inválido resultará en un error BadWindow.

XCompositeRedirectSubwindows

XCompositeRedirectSubwindows solicita al servidor X que redirija las jerarquías que comienzan en todos los hijos actuales y futuros de window como en XCompositeRedirectWindow. Si update es CompositeRedirectManual, entonces se inhibe la pintura del fondo de la ventana durante la manipulación de ventanas y las solicitudes ClearArea.

XCompositeUnredirectWindow

XCompositeUnredirectWindow solicita al servidor X que termine la redirección de window. Si la ventana especificada no fue seleccionada para redirección por el cliente actual, resulta un error BadValue.

XCompositeUnredirectSubwindows

XCompositeUnredirectSubwindows solicita al servidor X que termine la redirección de todos los hijos de window. Si la ventana especificada no fue seleccionada para sub-redirección por el cliente actual, resulta un error BadValue.

NAME

Xcomposite - Composite extension for the X Window System

SYNOPSIS

#include <X11/Xcomposite.h>

/*
 * Composite Extension version 0.2
 */
typedef struct {
    CARD16 minor_version;
    CARD16 major_version;
} XCompositeVersion;

/*
 * Composite Extension version 0.3
 */
typedef struct {
    CARD16 minor_version;
    CARD16 major_version;
} XCompositeOverlayWindowVersion;

/*
 * XCompositeRedirectWindow / XCompositeRedirectSubwindow
 */
Status XCompositeRedirectWindow(Display *dpy, Window window,
                                XCompositeRedirectType type);
Status XCompositeRedirectSubwindow(Display *dpy, Window window,
                                   XCompositeRedirectType type);
void XCompositeUnredirectWindow(Display *dpy, Window window);
void XCompositeUnredirectSubwindow(Display *dpy, Window window);

/*
 * XCompositeGetWindowAttributes
 */
Status XCompositeGetWindowAttributes(Display *dpy, Window window,
                                     XWindowAttributes *attr,
                                     XCompositeWindowAttributes *composite_attr);

/*
 * XCompositeNameWindowPixmap
 */
Pixmap XCompositeNameWindowPixmap(Display *dpy, Window window);

/*
 * XCompositeGetOverlayWindow
 */
Window XCompositeGetOverlayWindow(Display *dpy, Window window);
void XCompositeReleaseOverlayWindow(Display *dpy, Window window);

/*
 * XCompositeQueryExtension
 */
Bool XCompositeQueryExtension(Display *dpy, int *event_base_return,
                              int *error_base_return);
Bool XCompositeQueryVersion(Display *dpy, XCompositeVersion *version_return);
Bool XCompositeQueryOverlayWindowExtension(Display *dpy,
                                          XCompositeOverlayWindowVersion
                                          *version_return);

DESCRIPTION

The Composite Extension allows clients to redirect the output of other windows to an off-screen pixmap. This is useful for implementing effects such as transparency, shadows, and compositing multiple windows together. The extension also provides an overlay window which can be used for high-performance drawing.

XCompositeRedirectWindow and XCompositeRedirectSubwindow redirect the specified window's output to an off-screen pixmap. The type argument specifies whether to redirect the window itself (CompositeRedirectAutomatic) or its children (CompositeRedirectManual). CompositeRedirectAutomatic should be used when the client will be rendering the window content itself, for example, by capturing the window's content using XCompositeNameWindowPixmap and then modifying and displaying it. CompositeRedirectManual should be used when the client only wants to composite other windows on top of the redirected window, without affecting the window's own rendering.

XCompositeUnredirectWindow and XCompositeUnredirectSubwindow disable the redirection for the specified window.

XCompositeGetWindowAttributes retrieves the window attributes, including those specific to the Composite Extension. The composite_attr argument will be filled with the composite attributes of the window.

XCompositeNameWindowPixmap creates a pixmap that can be used to hold the contents of the specified window. This pixmap can be used to access the window's contents off-screen.

XCompositeGetOverlayWindow returns the window ID of the Composite Overlay Window for the screen. This window can be used for efficient, direct rendering of composited content.

XCompositeReleaseOverlayWindow indicates that the client no longer needs the Composite Overlay Window.

XCompositeQueryExtension checks if the Composite Extension is available on the server and returns the event and error base numbers.

XCompositeQueryVersion queries the version of the Composite Extension supported by the server.

XCompositeQueryOverlayWindowExtension queries the version of the Composite Overlay Window extension.

ARGUMENTS

dpy
Specifies the connection to the X server.
window
Specifies the window.
type
Specifies the type of redirection. Must be either CompositeRedirectAutomatic or CompositeRedirectManual.
attr
Pointer to a XWindowAttributes structure to be filled with the window's attributes.
composite_attr
Pointer to a XCompositeWindowAttributes structure to be filled with the window's composite attributes.
event_base_return
If not NULL, filled with the event base number for the extension.
error_base_return
If not NULL, filled with the error base number for the extension.
version_return
If not NULL, filled with the version information of the extension.

FUNCTIONS

XCompositeGetWindowAttributes

XCompositeGetWindowAttributes retrieves the attributes of the specified window. If the window is not redirected, the fields in composite_attr are undefined. If the window is redirected, the redirect_window field is set to True. The clip_ நல்லது field contains the area of the window clipped against siblings and the parent. This region can be used to restrict rendering to suitable areas while updating only a single window. The region is copied at the moment the request is executed; future changes to the window hierarchy will not be reflected in this region.

XCompositeNameWindowPixmap

XCompositeNameWindowPixmap creates and returns a pixmap id that serves as a reference to the off-screen storage for window. This pixmap will remain allocated until freed, even if the window is unmapped, reconfigured or destroyed. However, the window will get a new pixmap allocated each time it is mapped or resized, so this function will need to be reinvoked for the client to continue to refer to the storage holding the current window contents. Generates a BadMatch error if window is not redirected or is not visible.

The X server must support at least version 0.2 of the Composite Extension for XCompositeNameWindowPixmap.

XCompositeGetOverlayWindow

XCompositeGetOverlayWindow returns the window ID of the Composite Overlay Window for the screen specified by the argument window. This function notifies the X server that the client wishes to use the Composite Overlay Window of this screen. If this Composite Overlay Window has not yet been mapped, it is mapped by this request.

The Composite Overlay Window for a particular screen will be unmapped when all clients who have called this function have either called XCompositeReleaseOverlayWindow for that screen, or terminated their connection to the X server.

The X server must support at least version 0.3 of the Composite Extension for XCompositeGetOverlayWindow.

XCompositeReleaseOverlayWindow

This request specifies that the client is no longer using the Composite Overlay Window on the screen specified by the argument window. A screen's Composite Overlay Window is unmapped when there are no longer any clients using it.

The X server must support at least version 0.3 of the Composite Extension for XCompositeReleaseOverlayWindow.
