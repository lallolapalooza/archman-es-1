Paquete: libx11

Licencias: MIT AND X11

XCreateFontCursor(3) FUNCIONES DE XLIB XCreateFontCursor(3)

NOMBRE

XCreateFontCursor, XCreatePixmapCursor, XCreateGlyphCursor - crear cursores

SINTAXIS

#include <X11/cursorfont.h>

Cursor XCreateFontCursor(Display *display, unsigned int shape);

Cursor XCreatePixmapCursor(Display *display, Pixmap source, Pixmap mask, XColor *foreground_color, XColor *background_color, unsigned int x, unsigned int y);

Cursor XCreateGlyphCursor(Display *display, Font source_font, Font mask_font, unsigned int source_char, unsigned int mask_char, XColor _Xconst *foreground_color, XColor _Xconst *background_color);

ARGUMENTOS

background_color
Especifica los valores RGB para el fondo de la fuente.
display
Especifica la conexión con el servidor X.
foreground_color
Especifica los valores RGB para la fuente de la fuente.
mask
Especifica los bits de la fuente de origen que se mostrarán o None.
mask_char
Especifica el carácter de glifo para la máscara.
mask_font
Especifica la fuente para el glifo de la máscara o None.
shape
Especifica la forma del cursor.
source
Especifica la forma del cursor de origen.
source_char
Especifica el carácter de glifo para la fuente.
source_font
Especifica la fuente para el glifo de la fuente.
x

y
Especifican las coordenadas x e y, que indican el punto de activación en relación con el origen de la fuente.

DESCRIPCIÓN

X proporciona un conjunto de formas de cursor estándar en una fuente especial llamada cursor. Se anima a las aplicaciones a usar esta interfaz para sus cursores, ya que la fuente se puede personalizar para el tipo de pantalla individual. El argumento shape especifica qué glifo de las fuentes estándar se utilizará.

El punto de activación proviene de la información almacenada en la fuente del cursor. Los colores iniciales de un cursor son un primer plano negro y un fondo blanco (ver XRecolorCursor).

XCreateFontCursor puede generar errores BadAlloc y BadValue.

La función XCreatePixmapCursor crea un cursor y devuelve el ID del cursor asociado con él. Los valores RGB del primer plano y del fondo deben especificarse usando foreground_color y background_color, incluso si el servidor X solo tiene una pantalla StaticGray o GrayScale. El color del primer plano se utiliza para los píxeles establecidos en 1 en la fuente, y el color del fondo se utiliza para los píxeles establecidos en 0. Tanto la fuente como la máscara, si se especifican, deben tener profundidad uno (o se producirá un error BadMatch) pero pueden tener cualquier raíz. El argumento mask define la forma del cursor. Los píxeles establecidos en 1 en la máscara definen qué píxeles de la fuente se muestran, y los píxeles establecidos en 0 definen qué píxeles se ignoran. Si no se proporciona máscara, se muestran todos los píxeles de la fuente. La máscara, si está presente, debe tener el mismo tamaño que el pixmap definido por el argumento source, o se producirá un error BadMatch. El punto de activación debe ser un punto dentro de la fuente, o se producirá un error BadMatch.

Los componentes del cursor se pueden transformar arbitrariamente para cumplir con las limitaciones de la pantalla. Los pixmaps se pueden liberar inmediatamente si no se van a hacer más referencias explícitas a ellos. El dibujo posterior en el pixmap de origen o máscara tiene un efecto no definido en el cursor. El servidor X puede o no hacer una copia del pixmap.

XCreatePixmapCursor puede generar errores BadAlloc y BadPixmap.

La función XCreateGlyphCursor es similar a XCreatePixmapCursor excepto que los mapas de bits de origen y máscara se obtienen de los glifos de fuente especificados. El source_char debe ser un glifo definido en source_font, o se producirá un error BadValue. Si se proporciona mask_font, mask_char debe ser un glifo definido en mask_font, o se producirá un error BadValue. La máscara y el carácter de máscara son opcionales. Los orígenes de los glifos source_char y mask_char (si están definidos) se posicionan de forma coincidente y definen el punto de activación. Los glifos source_char y mask_char no necesitan tener las mismas métricas de cuadro delimitador, y no hay restricciones en la colocación del punto de activación en relación con los cuadros delimitadores. Si no se proporciona mask_char, se muestran todos los píxeles de la fuente. Puede liberar las fuentes inmediatamente llamando a XFreeFont si no se van a hacer más referencias explícitas a ellas.

Para fuentes de matriz de 2 bytes, el valor de 16 bits debe formarse con el miembro byte1 en el byte más significativo y el miembro byte2 en el byte menos significativo.

XCreateGlyphCursor puede generar errores BadAlloc, BadFont y BadValue.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadFont
Un valor para un argumento de Fuente o GContext no nombra una Fuente definida.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.
BadPixmap
Un valor para un argumento de Pixmap no nombra un Pixmap definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
