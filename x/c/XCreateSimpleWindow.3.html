XCreateSimpleWindow(3)

Paquete: libx11

Licencias: MIT AND X11

XCreateSimpleWindow(3) FUNCIONES DE XLIB XCreateSimpleWindow(3)

NOMBRE

XCreateWindow, XCreateSimpleWindow, XSetWindowAttributes - crear ventanas y estructura de atributos de ventana

SINTAXIS

Window XCreateWindow(Display *display, Window parent, int x, int y, unsigned int width, unsigned int height, unsigned int border_width, int depth, unsigned int class, Visual *visual, unsigned long valuemask, XSetWindowAttributes *attributes);

Window XCreateSimpleWindow(Display *display, Window parent, int x, int y, unsigned int width, unsigned int height, unsigned int border_width, unsigned long border, unsigned long background);

ARGUMENTOS

attributes
Especifica la estructura de la que se tomarán los valores (según lo indicado por la máscara de valores). La máscara de valores debe tener los bits apropiados establecidos para indicar qué atributos se han establecido en la estructura.
background
Especifica el valor del píxel de fondo de la ventana.
border
Especifica el valor del píxel del borde de la ventana.
border_width
Especifica el ancho del borde de la ventana creada en píxeles.
class
Especifica la clase de la ventana creada. Puede pasar InputOutput, InputOnly o CopyFromParent. Una clase de CopyFromParent significa que la clase se toma del padre.
depth
Especifica la profundidad de la ventana. Una profundidad de CopyFromParent significa que la profundidad se toma del padre.
display
Especifica la conexión con el servidor X.
parent
Especifica la ventana padre.
valuemask
Especifica qué atributos de ventana están definidos en el argumento `attributes`. Esta máscara es el OR inclusivo a nivel de bits de los bits de máscara de atributo válidos. Si `valuemask` es cero, los atributos se ignoran y no se referencian.
visual
Especifica el tipo visual. Un visual de CopyFromParent significa que el tipo visual se toma del padre.
width

height
Especifican el ancho y el alto, que son las dimensiones internas de la ventana creada y no incluyen los bordes de la ventana creada.
x

y
Especifican las coordenadas x e y, que son la esquina superior izquierda exterior de los bordes de la ventana y son relativas al interior de los bordes de la ventana padre.

DESCRIPCIÓN

La función XCreateWindow crea una subventana no mapeada para una ventana padre especificada, devuelve el ID de la ventana creada y hace que el servidor X genere un evento CreateNotify. La ventana creada se coloca en la parte superior en el orden de apilamiento con respecto a los hermanos.

El sistema de coordenadas tiene el eje X horizontal y el eje Y vertical con el origen [0, 0] en la esquina superior izquierda. Las coordenadas son integrales, en términos de píxeles, y coinciden con los centros de los píxeles. Cada ventana y pixmap tiene su propio sistema de coordenadas. Para una ventana, el origen está dentro del borde, en la esquina interior superior izquierda.

El `border_width` para una ventana InputOnly debe ser cero, o se produce un error BadMatch. Para la clase InputOutput, el tipo visual y la profundidad deben ser una combinación compatible con la pantalla, o se produce un error BadMatch. La profundidad no tiene que ser la misma que la del padre, pero el padre no debe ser una ventana de clase InputOnly, o se produce un error BadMatch. Para una ventana InputOnly, la profundidad debe ser cero y el visual debe ser uno compatible con la pantalla. Si no se cumple alguna de las condiciones, se produce un error BadMatch. Sin embargo, la ventana padre puede tener cualquier profundidad y clase. Si especifica algún atributo de ventana no válido para una ventana, se produce un error BadMatch.

La ventana creada aún no se muestra (mapea) en la pantalla del usuario. Para mostrar la ventana, llame a XMapWindow. La nueva ventana utiliza inicialmente el mismo cursor que su padre. Se puede definir un nuevo cursor para la nueva ventana llamando a XDefineCursor. La ventana no será visible en la pantalla a menos que ella y todos sus ancestros estén mapeados y no esté oscurecida por ninguno de sus ancestros.

XCreateWindow puede generar errores BadAlloc, BadColor, BadCursor, BadMatch, BadPixmap, BadValue y BadWindow.

La función XCreateSimpleWindow crea una subventana InputOutput no mapeada para una ventana padre especificada, devuelve el ID de la ventana creada y hace que el servidor X genere un evento CreateNotify. La ventana creada se coloca en la parte superior en el orden de apilamiento con respecto a los hermanos. Cualquier parte de la ventana que se extienda fuera de la ventana padre se recorta. El `border_width` para una ventana InputOnly debe ser cero, o se produce un error BadMatch. XCreateSimpleWindow hereda su profundidad, clase y visual de su padre. Todos los demás atributos de ventana, excepto el fondo y el borde, tienen sus valores predeterminados.

XCreateSimpleWindow puede generar errores BadAlloc, BadMatch, BadValue y BadWindow.

ESTRUCTURAS

La estructura XSetWindowAttributes contiene:

/* Bits de máscara de valor de atributo de ventana */

#define CWBackPixmap (1L<<0)
#define CWBackPixel (1L<<1)
#define CWBorderPixmap (1L<<2)
#define CWBorderPixel (1L<<3)
#define CWBitGravity (1L<<4)
#define CWWinGravity (1L<<5)
#define CWBackingStore (1L<<6)
#define CWBackingPlanes (1L<<7)
#define CWBackingPixel (1L<<8)
#define CWOverrideRedirect (1L<<9)
#define CWSaveUnder (1L<<10)
#define CWEventMask (1L<<11)
#define CWDontPropagate (1L<<12)
#define CWColormap (1L<<13)
#define CWCursor (1L<<14) 
/* Valores */
typedef struct {
        Pixmap background_pixmap;       /* fondo, None, o ParentRelative */
        unsigned long background_pixel; /* píxel de fondo */
        Pixmap border_pixmap;           /* borde de la ventana o CopyFromParent */
        unsigned long border_pixel;     /* valor de píxel de borde */
        int bit_gravity;        /* uno de los valores de bit gravity */
        int win_gravity;        /* uno de los valores de window gravity */
        int backing_store;      /* NotUseful, WhenMapped, Always */
        unsigned long backing_planes;   /* planos a preservar si es posible */
        unsigned long backing_pixel;    /* valor a usar al restaurar planos */
        Bool save_under;        /* ¿deberían guardarse los bits debajo? (popups) */
        long event_mask;        /* conjunto de eventos que deben guardarse */
        long do_not_propagate_mask;     /* conjunto de eventos que no deben propagarse */
        Bool override_redirect; /* valor booleano para override_redirect */
        Colormap colormap;      /* mapa de colores a asociar con la ventana */
        Cursor cursor;          /* cursor a mostrar (o None) */
} XSetWindowAttributes;

Para una explicación detallada de los miembros de esta estructura, consulte Xlib - Interfaz C de X.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadCursor
Un valor para un argumento Cursor no nombra un Cursor definido.
BadMatch
Los valores no existen para una ventana InputOnly.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.
BadPixmap
Un valor para un argumento Pixmap no nombra un Pixmap definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
