NOMBRE

XChangeKeyboardDevice - cambia el dispositivo que se usa como teclado de X

SINOPSIS

#include <X11/extensions/XInput.h>
Status XChangeKeyboardDevice( Display *display,
                              XDevice *device);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo que se usará como teclado de X.

DESCRIPCIÓN

La solicitud XChangeKeyboardDevice hace que el servidor use el
dispositivo especificado como el teclado de X. El dispositivo debe haber sido
abierto previamente por el cliente que realiza la solicitud a través de
XOpenDevice o se producirá un error BadDevice. El dispositivo debe admitir la
clase de entrada Keys, o se producirá un error BadMatch. Si la implementación del
servidor no admite el uso del dispositivo solicitado como teclado de X, se
producirá un error BadDevice.
Si el dispositivo especificado está capturado por otro cliente,
se devolverá AlreadyGrabbed. Si el dispositivo especificado está congelado
por una captura en otro dispositivo, se devolverá GrabFrozen. Si la solicitud
es exitosa, se devolverá Success.
Si la solicitud tiene éxito, se enviará un evento ChangeDeviceNotify
a todos los clientes que hayan seleccionado ese evento. Se enviará un evento
MappingNotify con request = MappingKeyboard a todos los clientes.
El dispositivo especificado se convierte en el teclado de X y el teclado de X
anterior se vuelve accesible a través de las solicitudes del protocolo de
extensión de entrada.
XChangeKeyboardDevice puede generar un error BadDevice o BadMatch.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe, no ha sido abierto por este cliente a través de
       XOpenInputDevice, o ya es uno de los dispositivos principales de X
       (puntero o teclado). Este error también puede ocurrir si la
       implementación del servidor no admite el uso del dispositivo
       especificado como teclado de X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud
       XChangeKeyboardDevice especificando un dispositivo que no tiene
       teclas.
