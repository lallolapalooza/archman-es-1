NOMBRE

X11::Protocol::Ext::RENDER - Módulo Perl para la extensión X Rendering

SINOPSIS

use X11::Protocol;
$x = X11::Protocol->new($ENV{'DISPLAY'});
$x->init_extension('RENDER') or die;

DESCRIPCIÓN

La extensión RENDER añade un nuevo conjunto de primitivas de dibujo que efectivamente representan un reemplazo de las rutinas de dibujo del protocolo central, rediseñadas basándose en las necesidades de clientes más modernos. Añade características muy deseadas como posicionamiento de subpíxeles, composición alfa, especificación directa de colores y cursores multicolores o animados. Por otro lado, omite características que ya no se usan comúnmente: líneas anchas, polígonos arbitrarios (solo se admiten triángulos y trapezoides alineados horizontalmente), elipses, operaciones de dibujo a nivel de bits y fuentes del lado del servidor (en favor de "glifos" que se renderizan en el lado del cliente y se transmiten una vez).

Hasta la fecha de redacción (principios de 2004), la especificación y la implementación tienen aspectos mejorables, pero hay relativamente pocas alternativas para descargar el procesamiento gráfico avanzado al servidor, como es necesario en enlaces lentos o si el cliente está escrito en un lenguaje lento. Otra posibilidad que podría considerar es el subconjunto 2D de OpenGL, aunque aún no tiene una interfaz compatible con X11::Protocol.

CONSTANTES SIMBÓLICAS

Esta extensión añade los tipos de constantes 'PictType', 'PictOp', 'SubPixel', 'PolyEdge' y 'PolyMode', con valores según se definen en el estándar.

SOLICITUDES

Esta extensión añade varias solicitudes, que se llaman como se muestra a continuación:

$x->RenderQueryVersion($major, $minor)
=>
($major, $minor)
$x->RenderQueryPictFormats()
=>
([[$id, $type, $depth,
   $red, $red_m, $green, $green_m, $blue, $blue_m,
   $alpha, $alpha_m, $cmap], ...],
 [[$fallback, [$depth, [$visual, $format], ...], ...], ...],
 [$subpixel, ...])
$x->RenderQueryPictIndexValues($pict_format)
=>
([$index, $red, $green, $blue, $alpha], ...)
$x->RenderQueryFilters($drawable)
=>
([@filters], [@aliases])
$x->RenderCreatePicture($picture, $drawable, $format,
                        'attribute' => $value, ...)
$x->RenderChangePicture($picture, 'attribute' => $value, ...)
$x->RenderSetPictureClipRectangles($pic, $x_origin, $y_origin,
                                   [$x, $y, $width, $height], ...)
$x->RenderSetPictureTransform($pict, $m11, $m12, $m13,
                                     $m21, $m22, $m23,
                                     $m31, $m32, $m33);
$x->RenderSetPictureFilter($pict, $filter, @args)
$x->RenderComposite($op, $src, $mask, $dst, $src_x, $src_y,
                    $mask_x, $mask_y, $dst_x, $dst_y,
                    $width, $height)
$x->RenderFillRectangles($op, $dst, [$red, $green, $blue, $alpha],
                         [$x, $y, $width, $height], ...)
$x->RenderTrapezoids($op, $src, $src_x, $src_y, $dst, $mask_format,
                     [$top, $bottom, $lx1, $ly1, $lx2, $ly2,
                                     $rx1, $ry1, $rx2, $ry2] ,...)
$x->RenderTriangles($op, $src, $src_x, $src_y, $dst, $mask_format,
                    [$x1, $y1, $x2, $y2, $x3, $y3])
$x->RenderTriStrip($op, $src, $src_x, $src_y, $dst, $mask_format,
                    [$x, $y], [$x, $y], [$x, $y], [$x, $y], ...)
$x->RenderTriFan($op, $src, $src_x, $src_y, $dst, $mask_format,
                 [$x, $y], [$x, $y], [$x, $y], [$x, $y], ...)
$x->RenderCreateGlyphSet($gsid, $format)
$x->RenderReferenceGlyphSet($gsid, $existing)
$x->RenderFreeGlyphSet($gsid)
$x->RenderAddGlyphs($gsid, [$glyph, $width, $height,
                            $x, $y, $x_off, $y_off, $data], ...)

Advertencia: con algunas implementaciones de servidor (incluyendo XFree86 hasta la 4.4) pasar más de un glifo a AddGlyphs puede colgar o crashear el servidor. Así que no lo haga.

$x->RenderFreeGylphs($gsid, @glyphs)
$x->RenderCompositeGlyphs8($op, $src, $dst, $mask_format, $gsid,
                           $src_x, $src_y,
                           [$delta_x, $delta_y, $str], ...)
$x->RenderCompositeGlyphs16($op, $src, $dst, $mask_format, $gsid,
                            $src_x, $src_y,
                            [$delta_x, $delta_y, $str], ...)
$x->RenderCompositeGlyphs32($op, $src, $dst, $mask_format, $gsid,
                            $src_x, $src_y,
                            [$delta_x, $delta_y, $str], ...)

En estas tres solicitudes, también se pueden intercalar nuevos IDs de GlyphSet con las referencias a arreglos.

$x->RenderCreateCursor($cid, $source, $hot_x, $hot_y)
$x->RenderCreateAnimCursor($cid, [$cursor, $delay], ...)
