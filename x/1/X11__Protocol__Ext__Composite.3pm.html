X11::Protocol::Ext::Composite(3) Documentación de Perl contribuida por el usuario X11::Protocol::Ext::Composite(3)

NOMBRE

X11::Protocol::Ext::Composite - contenido de ventana fuera de pantalla

SINOPSIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('Composite')
  or print "La extensión Composite no está disponible";
$X->CompositeRedirectWindow ($mi_ventana, 'Automatic');

DESCRIPCIÓN

La extensión Composite mantiene el contenido completo de píxeles de las ventanas en almacenamiento fuera de pantalla, listo para cosas como CopyArea(). Normalmente el servidor solo mantiene las partes visibles de una ventana, no las áreas superpuestas u oscurecidas.

En modo "Automático", las partes visibles de una ventana se muestran en pantalla como de costumbre. El almacenamiento fuera de pantalla es entonces un poco como la característica de almacenamiento de respaldo, pero solo cuando uno o más clientes declaran interés en el contenido completo.

En modo "Manual", el contenido de la ventana no se dibuja en pantalla, solo se mantiene fuera de pantalla. Este modo es para uso de programas especiales de "gestor de composición" que podrían hacer una pantalla de composición (de ahí el nombre de la extensión) de las ventanas superpuestas con efectos de transparencia parcial o sombras.

No hay nada aquí para dibujar o combinar para crear realmente un resultado de ventana compuesta. Cuando sea necesario, se hace con el dibujo del protocolo principal habitual o con extensiones de dibujo como RENDER (ver X11::Protocol::Ext::RENDER).

SOLICITUDES

Las siguientes solicitudes se ponen a disposición con una init_extension(), según "EXTENSIONS" en X11::Protocol.

my $disponible = $X->init_extension('Composite');

Composite 0.1

"($version_servidor, $version_menor_servidor) = $X->CompositeQueryVersion ($version_cliente, $version_menor_cliente)"
Negocia una versión del protocolo con el servidor. $version_cliente y $version_menor_cliente es lo que el cliente desearía, los devueltos $version_servidor y $version_menor_servidor es lo que el servidor hará, que podría ser menos de lo solicitado (pero no más).

De hecho, el servidor X.org alrededor de la versión 1.10 devolverá una versión menor más alta de la que solicita el cliente.

El código actual admite hasta la versión 0.3 y la intención es negociar automáticamente en init_extension() si/cuando sea necesario.

"$X->CompositeRedirectWindow ($ventana, $actualizacion)"
"$X->CompositeRedirectSubwindows ($ventana, $actualizacion)"
"$X->CompositeUnredirectWindow ($ventana, $actualizacion)"
"$X->CompositeUnredirectSubwindows ($ventana, $actualizacion)"
Habilita o deshabilita una redirección de $ventana al almacenamiento fuera de pantalla.

Window() actúa solo sobre la $ventana dada. Subwindows() actúa sobre $ventana y también sobre todas sus subventanas, ahora o en el futuro. La ventana raíz no puede ser redirigida.

$actualizacion es la cadena "Automatic" o "Manual". Solo un cliente a la vez puede usar el modo Manual en una $ventana dada (normalmente un programa "gestor de composición").

La redirección es una configuración por cliente y se desredirige automáticamente si el cliente se desconecta. Una desredirección cuando no está redirigida es un error de "BadValue". El almacenamiento fuera de pantalla permanece en vigor mientras al menos un cliente actual lo haya solicitado.

"$X->CompositeCreateRegionFromBorderClip ($region, $ventana)"
Crea $region (un nuevo XID) como un objeto de región del lado del servidor inicializado a, bueno, algo sobre $ventana y su borde actual o partes visibles o lo que sea.

Los objetos de región son de XFIXES 2.0 (X11::Protocol::Ext::XFIXES). CompositeCreateRegionFromBorderClip() se puede usar sin init_extension() de XFIXES, pero no hay mucho que se pueda hacer con una región excepto a través de XFIXES.

Composite 0.2

"$X->CompositeNameWindowPixmap ($ventana, $pixmap)"
Establece $pixmap (un nuevo XID) para que haga referencia al almacenamiento fuera de pantalla de $ventana. $ventana debe ser visible (mapeada y todos sus padres mapeados) y debe estar redirigida (por cualquier cliente). 
my $pixmap = $X->new_rsrc;
$X->CompositeNameWindowPixmap ($ventana, $pixmap);

$pixmap se libera con FreePixmap() de la manera habitual. Si $ventana o un padre no está mapeado, entonces $pixmap continúa existiendo, pero su asociación con $ventana se pierde. Si $ventana está mapeada y redirigida nuevamente más tarde, tiene un nuevo almacenamiento fuera de pantalla y se debe llamar a un nuevo CompositeNameWindowPixmap() para obtener un nuevo pixmap para ella.

Composite 0.3

"$ventana_overlay = $X->CompositeGetOverlayWindow ($ventana)"
Devuelve la ventana de superposición de composición para la pantalla de $ventana.

Esta ventana cubre toda la pantalla y siempre está por encima de las ventanas ordinarias pero por debajo de cualquier salvapantallas, y no aparece en una QueryTree(). Se crea cuando el primer cliente la solicita y es compartida por cualquier cliente posterior que la solicite.

"$X->CompositeReleaseOverlayWindow ($ventana)"
Libera la ventana de superposición de composición para la pantalla de $ventana. Cuando todos los clientes la liberan, la ventana de superposición se destruye.
