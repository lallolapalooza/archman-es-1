X11::Protocol::Ext::TOG_CUP(3) Documentación de Perl aportada por el usuario X11::Protocol::Ext::TOG_CUP(3)

NOMBRE

X11::Protocol::Ext::TOG_CUP - extensión de política de utilización de mapa de colores

SINOPSIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('TOG-CUP')
  or print "La extensión TOG-CUP no está disponible";

DESCRIPCIÓN

La extensión TOG-CUP ayuda a las aplicaciones con mapas de colores privados a utilizar el mismo píxel para el mismo color en diferentes mapas de colores.

El uso de valores de píxeles comunes, cuando sea posible, significa que cuando se utiliza un mapa de colores privado ("$x->InstallColormap()", generalmente hecho por el gestor de ventanas), algunos de los colores en otras ventanas aún aparecerán correctamente.

Tenga en cuenta que esta extensión realiza un cambio sutil en las solicitudes principales de "$X->AllocColor()" y "$X->AllocNamedColor()". Normalmente, asignan el primer píxel disponible, pero con TOG-CUP, si hay un color correspondiente en el mapa de colores predeterminado y ese mismo píxel en el mapa de colores de destino está libre, entonces ese píxel se asigna, haciendo que ese color sea el mismo en los dos mapas de colores.

SOLICITUDES

Los siguientes se ponen a disposición con una init_extension() por "EXTENSIONS" en X11::Protocol.

my $bool = $X->init_extension('TOG-CUP');
"($server_major, $server_minor) = $X->CupQueryVersion ($client_major, $client_minor)"
Negocia una versión del protocolo con el servidor. $client_major y $client_minor es lo que el cliente desearía, $server_major y $server_minor devueltos es lo que el servidor hará, lo cual podría ser diferente.

El código actual soporta hasta 1.0. La intención sería negociar automáticamente en init_extension() si fuera necesario, lo cual actualmente no ocurre.

"@colors = $X->CupGetReservedColormapEntries ($screen)"
Devuelve una lista de entradas de mapa de colores reservadas en el mapa de colores predeterminado de la pantalla número $screen (un entero de 0 hacia arriba). Cada elemento devuelto es un arrayref 
[ $pixel, $red16, $blue16, $green16, $alloc_flags ]

$red16, $blue16 y $green16 son componentes de color RGB en el rango de 0 a 65535. $alloc_flags no se utiliza actualmente.

Los colores reservados están preasignados e inmutables. El protocolo central especifica "$X->{'black_pixel'}" y "$X->{'white_pixel'}" y se incluyen en el resultado, además de cualquier color adicional que pueda estar reservado.

Por ejemplo, bajo el gestor de superposición gráfica de MS-DOS, hay un cierto conjunto de colores de "escritorio" que un servidor en ese sistema podría tratar como reservados.

"@colors = $X->CupStoreColors ($colormap, [$pixel,$red16,$green16,$blue16],...)"
Asigna colores de solo lectura en $colormap en píxeles particulares.

Cada argumento es un arrayref del píxel y color RGB deseados. (Un parámetro $do_mask puede estar presente al final también, pero no se utiliza y puede omitirse.)

[ $pixel, $red16, $blue16, $green16 ]

El color deseado se asigna de forma compartida de solo lectura (como "$X->AllocColor()") en el $pixel dado si es posible, o en otro si es necesario. El resultado es una lista similar de elementos arrayref, uno por cada argumento

[ $pixel, $red16, $blue16, $green16, $alloc_flags ]

El $pixel devuelto puede diferir del solicitado. Si el $pixel solicitado ya está asignado y tiene un color diferente, entonces se elige otro valor de píxel.

Los componentes RGB devueltos son el tono de color real asignado. Esto puede diferir si la visualización tiene una resolución de color limitada (lo cual es probable).

El $alloc_flags devuelto tiene el bit 0x08 establecido si el píxel se asignó correctamente, o claro si no. Otros bits en $alloc_flags no se utilizan actualmente.

Por ejemplo

my @ret = $X->CupStoreColors
            ($colormap,
             [ 2,  65535,0,0],           # rojo   
             [ 3,  0,65535,0],           # verde
             [ 4,  16383,16383,16383]);  # gris
foreach my $elem (@ret) {
  my ($pixel, $red,$green,$blue, $alloc_ok) = @$elem;
  my $ok = ($alloc_ok & 8 ? "asignado" : "ups, no asignado");
  print "en $pixel actual $red,$green,$blue  $ok\n";
}
