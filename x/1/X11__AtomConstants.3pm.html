X11::AtomConstants(3) Documentación de Perl aportada por el usuario X11::AtomConstants(3)

NOMBRE

X11::AtomConstants -- átomos predefinidos de X11

SINOPSIS

use X11::AtomConstants;
$X->ChangeProperty($window,
                   X11::AtomConstants::WM_NAME,  # propiedad
                   X11::AtomConstants::PIXMAP,   # tipo
                   8,                            # formato
                   'Replace',
                   'Título de mi Ventana');

DESCRIPCIÓN

Estos son los átomos predefinidos de X11 como constantes de Perl. Por ejemplo, "PIXMAP" es 20, el átomo PIXMAP.

my $atom_id = X11::AtomConstants::PIXMAP;  # $atom_id es 20
my $name = $X->GetAtomName($atom_id);      # $name es "PIXMAP"

La constante "LAST_PREDEFINED" no es un átomo en sí mismo, sino el último de los valores predefinidos, que resulta ser "WM_TRANSIENT_FOR".

EXPORTA

Nada se exporta por defecto, pero las constantes se pueden solicitar al estilo habitual de "Exporter".

use X11::AtomConstants 'PIXMAP';
blah (atom => PIXMAP);

La etiqueta ":all" importa todo.

use X11::AtomConstants ':all';
blah (atom1 => POINT,
      atom2 => RECTANGLE);

Muchos átomos como "STRING" o "WEIGHT" tienen nombres bastante genéricos y importarlos puede ser indeseable. Siempre se pueden usar con el nombre de paquete completo.

use X11::AtomConstants;
blah (atom => X11::AtomConstants::PIXMAP);
