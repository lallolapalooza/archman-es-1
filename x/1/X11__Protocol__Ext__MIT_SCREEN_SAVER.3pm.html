X11__Protocol__Ext__MIT_SCREEN_SAVER(3pm)

X11::Protocol::Ext::MIT_SCREEN_SAVER(3) Documentación de Perl contribuida por el usuario X11::Protocol::Ext::MIT_SCREEN_SAVER(3)

NOMBRE

X11::Protocol::Ext::MIT_SCREEN_SAVER - soporte de salvapantallas externo

SINOPSIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('MIT-SCREEN-SAVER')
  or print "La extensión MIT-SCREEN-SAVER no está disponible";

DESCRIPCIÓN

La extensión MIT-SCREEN-SAVER permite que un programa salvapantallas cliente dibuje un salvapantallas. Cualquier cliente también puede escuchar la activación del salvapantallas.

Un programa salvapantallas se registra a sí mismo y los atributos de ventana deseados con MitScreenSaverSetAttributes() y selecciona eventos de notificación del salvapantallas con MitScreenSaverSelectInput(). Solo puede haber un programa salvapantallas externo a la vez.

Ver examples/mit-screen-saver-external.pl para un programa salvapantallas completo.

Ver el núcleo SetScreenSaver() para el tiempo de espera habitual de inactividad de pantalla, el período de ciclo del salvapantallas y los estilos de salvapantallas integrados "Blank" o "Internal". Ver el núcleo ForceScreenSaver() para activar forzosamente el salvapantallas.

SOLICITUDES

Las siguientes solicitudes se ponen a disposición con una init_extension() por "EXTENSIONS" en X11::Protocol.

my $bool = $X->init_extension('MIT-SCREEN-SAVER');
"($server_major, $server_minor) = $X->MitScreenSaverQueryVersion ($client_major, $client_minor)"
Negociar una versión de protocolo con el servidor. $client_major y $client_minor es lo que le gustaría al cliente, el retornado $server_major y $server_minor es lo que hará el servidor, que será lo más cercano a la versión solicitada por el cliente que el servidor soporta.

El código en este módulo soporta 1.0. La intención sería negociar automáticamente dentro de init_extension() si/cuando sea necesario.

"($state, $window, $til_or_since, $idle, $event_mask, $kind) = $X->MitScreenSaverQueryInfo ($drawable)"
Devuelve información sobre el salvapantallas en la pantalla de $drawable (un XID entero).

$state es una cadena enumerada "Off", "On", o "Disabled", según "MitScreenSaverState" abajo.

$window es la ventana del salvapantallas, o "None". Cuando esta ventana existe, es un hijo con override-redirect de la ventana raíz, pero no aparece en los hijos de la raíz de QueryTree(). Esta ventana existe cuando se activa un salvapantallas externo, pero podría no existir en otros momentos (en cuyo caso $window es "None").

$til_or_since es un período en milisegundos. Si $state es "Off" entonces es cuánto tiempo falta hasta que el salvapantallas se active debido a la inactividad. Si $state es "On" entonces es cuánto tiempo en milisegundos ha pasado desde que se activó el salvapantallas. Pero ver "BUGS" abajo.

$idle es cuánto tiempo en milisegundos ha estado inactiva la pantalla. En los servidores X.org, esto también está disponible como un contador "IDLETIME" en la extensión SYNC (ver X11::Protocol::Ext::SYNC).

$event_mask es la máscara del cliente actual establecida por MitScreenSaverSelectInput() abajo.

$kind es una cadena enumerada "Blanked", "Internal" o "External" para cómo se realiza el salvapantallas ahora o cómo se realizará en la próxima activación, según "MitScreenSaverKind" abajo.

"$X->MitScreenSaverSelectInput ($drawable, $event_mask)"
Selecciona eventos "MitScreenSaverNotify" de la pantalla de $drawable (un XID). $event_mask tiene dos bits, 
              bitpos  bitval
NotifyMask      0      0x01
CycleMask       1      0x02

Todavía no hay una función de empaquetado para estos, así que solo proporcione los valores enteros de los bits, por ejemplo, 0x03 para ambos.

"$X->MitScreenSaverSetAttributes ($drawable, $class, $depth, $visual, $x, $y, $width, $height, $border_width, key => value, ...)"
Configura la ventana del salvapantallas en la pantalla de $drawable (un XID).

Los argumentos son los mismos que los de la solicitud central CreateWindow(), excepto que no hay ningún XID nuevo que crear y la ventana padre es siempre la ventana raíz en la pantalla de $drawable ($drawable podría ser ya la ventana raíz).

Esta configuración hace que el salvapantallas sea de tipo "External" en su próxima activación. Si el salvapantallas está actualmente activo, no se cambia. El cliente puede escuchar "MitScreenSaverNotify" (ver "EVENTOS" abajo) para saber cuándo se activa el salvapantallas. El XID de la ventana del salvapantallas se informa en esa notificación y se pueden seleccionar exposiciones, etc., en ella en ese momento para saber cuándo dibujar, a menos que quizás un píxel o mapa de bits de fondo en esta MitScreenSaverSetAttributes() sea suficiente.

Solo un cliente a la vez puede configurar una ventana de salvapantallas de esta manera. Si otro lo ha hecho, se produce un error de "Access".

"$X->MitScreenSaverUnsetAttributes ($drawable)"
Anula la configuración de la ventana del salvapantallas. Si el cliente no configuró la ventana, no hace nada.

Esto cambia el salvapantallas de tipo "External" de nuevo al integrado del servidor. Si el salvapantallas está actualmente activo, esto ocurre inmediatamente.

Al cerrar el cliente, se realiza automáticamente un Anulación de configuración, a menos que se use el modo de cierre "RetainPermanent".

EVENTOS

Se envían eventos "MitScreenSaverNotify" al cliente cuando se seleccionan mediante MitScreenSaverSelectInput() arriba. Estos eventos informan cuándo cambia el estado del salvapantallas. El evento tiene los campos habituales

nombre             "MitScreenSaverNotify"
sintetico        true si es de un SendEvent
codigo            opcode entero
numero_secuencia  entero

y campos específicos del evento

estado         "Off", "On", "Cycle"
tiempo          marca de tiempo del servidor (entero)
raiz            ventana raíz de la pantalla afectada (XID)
ventana        la ventana del salvapantallas (XID)
tipo          "Blanked", "Internal", "External"
forzado        entero 0 o 1

"estado" es "Off" si el salvapantallas se ha apagado o "On" si se ha encendido. "forzado" es 1 si el cambio se debió a una solicitud ForceScreenSaver() en lugar de actividad/inactividad del usuario. Los eventos On/Off se seleccionan mediante NotifyMask a MitScreenSaverSelectInput() arriba.

"estado" es "Cycle" si ha expirado el período de ciclo del salvapantallas, lo que significa que es hora de mostrar algo diferente. Esto se selecciona mediante CycleMask a MitScreenSaverSelectInput() arriba.

"tipo" es el tipo de salvapantallas actual según "MitScreenSaverKind" abajo.

TIPOS ENUMERADOS

Los siguientes tipos están disponibles para "$X->interp()" y "$X->num()" después de init_extension().

MitScreenSaverKind
"Blanked"    0     salida de video apagada
"Internal"   1     salvapantallas integrado del servidor
"External"   2     cliente salvapantallas externo
MitScreenSaverState
El estado del salvapantallas, como lo devuelve MitScreenSaverQueryInfo() y en "MitScreenSaverNotif

BUGS

La descripción de MitScreenSaverQueryInfo() para $til_or_since es engañosa. En realidad, ese campo contiene el tiempo en milisegundos desde que se activó el salvapantallas, independientemente de si está actualmente encendido o apagado. Para saber cuánto falta para la próxima activación, se debe calcular la diferencia entre el tiempo de inactividad del sistema y el tiempo de actividad desde la última vez que se habilitó el salvapantallas.
