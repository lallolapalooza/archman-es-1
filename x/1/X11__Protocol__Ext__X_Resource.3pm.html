NOMBRE

X11::Protocol::Ext::X_Resource - uso de recursos del servidor

SINOPSIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('X-Resource')
  or print "La extensión X-Resource no está disponible";
my @clientes = $X->XResourceQueryClients();
my %recursos = $X->XResourceQueryClientResources ($xid_cliente);
my $bytes = $X->XResourceQueryClientPixmapBytes ($xid_cliente);

DESCRIPCIÓN

La extensión X-Resource proporciona información sobre la utilización de recursos del servidor, principalmente para diagnóstico.

  • Conexiones de clientes actuales y sus rangos de XID.
  • Cuántas ventanas, pixmaps, GCs, etc., están en uso por un cliente dado.
  • Memoria total utilizada por todos los pixmaps de un cliente dado.

Los "Recursos" aquí se refieren a memoria, objetos, etc., y no deben confundirse con la base de datos de recursos de preferencias del usuario y configuraciones de widgets de "RECURSOS" en X(7).

Ver examples/xresource-print.pl para un volcado simple de los recursos reportados.

SOLICITUDES

Las siguientes solicitudes se ponen a disposición con una init_extension(), según "EXTENSIONS" en X11::Protocol.

my $esta_disponible = $X->init_extension('X-Resource');
"($mayor_servidor, $menor_servidor) = $X->XResourceQueryVersion ($mayor_cliente, $menor_cliente)"
Negocia la versión de la extensión. $mayor_cliente y $menor_cliente son lo que el cliente desearía, el valor devuelto de $mayor_servidor y $menor_servidor es lo que el servidor hará, lo que podría ser menor que lo solicitado (pero no mayor).

El código actual soporta X-Resource 1.0. La intención es que este módulo negocie automáticamente en "$X->init_extension()" si/cuando sea necesario.

"@clientes = $X->XResourceQueryClients ()"
Devuelve una lista de conexiones de clientes en el servidor. Cada valor devuelto es un par de arrayref 
[ $xid_base, $mascara_xid ]

$xid_base (un entero) es el inicio de los XID para el cliente.

$mascara_xid (un entero) es una máscara de bits para los XID superiores a esa base que el cliente puede usar. Por ejemplo, $xid_base podría ser 0xA00000 y $mascara_xid 0x1FFFFF, lo que significa que 0xA00000 a 0xBFFFFF pertenecen a este cliente.

my @clientes = $X->XResourceQueryClients;
print "hay ",scalar(@clientes)," clientes\n";
foreach my $aref (@clientes) {
  my $xid_base = $aref->[0];
  my $mascara_xid = $aref->[1];
  printf "cliente base %X mascara %X\n", $xid_base, $mascara_xid;
}

La conexión $X dada se incluye en la devolución. Su base y máscara son por "$X->{'resource_id_base'}" y "$X->{'resource_id_mask'}".

"($atom,$conteo,...) = $X->XResourceQueryClientResources ($xid)"
Devuelve una lista de cuántas de varias cosas del servidor están siendo utilizadas por un cliente dado.

El cliente se identifica por un $xid. Puede ser cualquier valor dentro del rango de XID del cliente y no tiene que estar asignado o creado actualmente. Por ejemplo, para consultar el uso del cliente actual, usa "$X->{'resource_id_base'}".

La devolución es una lista de tipo de recurso (un entero de átomo) y la cantidad de esas cosas,

($atom, $conteo, $atom, $conteo, ...)

Así, por ejemplo, para imprimir todos los recursos,

my @res = $X->XResourceQueryClientResources ($xid);
while (@res) {
  my $atom_tipo = shift @res;
  my $conteo = shift @res;
  my $nombre_tipo = $X->atom_name($atom_tipo);
  printf "tipo $nombre_tipo conteo $conteo\n";
}

O para poner la lista en un hash y buscar un tipo de recurso particular,

my %res = $X->XResourceQueryClientResources ($xid);
my $atom_ventana = X11::AtomConstants::WINDOW();
my $ventanas = $res{$atom_ventana} || 0;
my $atom_grab = $X->atom('PASSIVE GRAB');
my $grabs = $res{$atom_grab} || 'no';
print "usando $ventanas ventanas, y $grabs grabs pasivos";

"List::Pairwise" tiene mapp() y otras funciones para trabajar con este tipo de listas de dos elementos. Ver examples/xresource-pairwise.pl para un programa completo.

Generalmente, una entrada de conteo solo está presente cuando el cliente tiene 1 o más del elemento. Así que si no hay pixmaps, no hay entrada de "PIXMAP" en absoluto.

Básicos como "WINDOW", "PIXMAP", "GC" "COLORMAP", "FONT" y "CURSOR" indican cuántos de esos están en uso. El servidor también puede reportar cosas como "PASSIVE GRAB" o "COLORMAP ENTRY" (átomos con espacios en sus nombres). El servidor X.org (alrededor de la versión 1.9) incluso reporta a veces cosas como "Unregistered resource 30" (un átomo con ese nombre), que es algo.

Si el $xid proporcionado no es un cliente conectado, se produce un error "BadValue". Ten cuidado con eso al consultar recursos de otro cliente, ya que el cliente podría desconectarse en cualquier momento. "$X->robust_req()" es útil, o quizás "GrabServer" para mantener las conexiones entre XResourceQueryClients() y XResourceQueryClientResources().

"$bytes = $X->XResourceQueryClientPixmapBytes ($xid)"
Devuelve los bytes totales de memoria en el servidor utilizados por todos los pixmaps de un cliente dado. Se incluyen, o deberían incluirse, los pixmaps que solo existen como fondos de ventana o teselas/patrones de GC. Si el cliente no tiene ningún pixmap, la devolución es 0.

El cliente se identifica por un $xid, como se describe en XResourceQueryClientResources() anteriormente. Puede ser cualquier valor dentro del rango de XID del cliente, asignado o no.

my $pixmap = $X->new_rsrc;
$X->CreatePixmap ($pixmap,
                  $X->{'root'},
                  $X->{'root_depth'},
                  100, 100);  # ancho, alto
my $xid = $X->{'resource_id_base'};  # uso propio
my $bytes = $X->XResourceQueryClientPixmapBytes ($xid);
print "el total de todos los pixmaps es de $bytes bytes de memoria\n";

La devolución es un valor de 64 bits. En un Perl de 32 bits, un valor mayor a 32 bits se devuelve como punto flotante, o mayor a 53 bits como "Math::BigInt". La mayoría de las veces, 32 bits es suficiente, ya que serían 4 Gbytes de pixmaps, y el punto flotante de 53 bits debería ser suficiente, ¡lo que equivale a unos 8192 terabytes!

Como referencia, el servidor X.org en la versión 1.11.4 tenía un error por el cual no contaba el espacio utilizado por pixmaps de profundidad menor a 8 (incluyendo bitmaps de profundidad 1) en los bytes devueltos.

NAME

X11::Protocol::Ext::X_Resource - Extension for X Protocol

SYNOPSIS

  use X11::Protocol::Ext::X_Resource;
  my $ext = X11::Protocol::Ext::X_Resource->new;

DESCRIPTION

This module provides access to the X_Resource extension for the X Window System Protocol.

The X_Resource extension allows clients to query information about X resources, such as windows, pixmaps, and GCs.

REQUESTS

This extension defines the following requests:

QueryExtension
Queries the server for information about the X_Resource extension.
QueryResourceInfo
Queries the server for information about a specific X resource.
ListResourceTypes
Lists the available resource types on the server.
