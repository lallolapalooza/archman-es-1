NOMBRE

X11::Protocol::Connection::INETSocket - Módulo Perl para conexiones X11 basadas en IO::Socket::INET

SINOPSIS

use X11::Protocol;
use X11::Protocol::Connection::INETSocket;
$conn = X11::Protocol::Connection::INETSocket
  ->open($host, $display_number);
$x = X11::Protocol->new($conn);

DESCRIPCIÓN

Este módulo es utilizado por X11::Protocol para establecer una conexión y comunicarse con un servidor a través de una conexión TCP/IP, utilizando el módulo IO::Socket::INET.
