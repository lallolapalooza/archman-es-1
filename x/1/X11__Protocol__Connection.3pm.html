NOMBRE

X11::Protocol::Connection - clase base abstracta del módulo Perl para conexiones de cliente a servidor X11

SINOPSIS

# En el módulo de objeto de conexión
package X11::Protocol::Connection::CarrierPigeon;
use X11::Protocol::Connection;
@ISA = ('X11::Protocol::Connection');
sub open { ... }
sub give { ... }
sub get { ... }
sub fh { ... }
...
# En el programa
$connection = X11::Protocol::Connection::CarrierPigeon
  ->open($host, $display_number);
$x = X11::Protocol->new($connection);
$connection->give($data);
$reply = unpack("I", $connection->get(4));
use IO::Select;
$sel = IO::select->new($connection->fh);
if ($sel->can_read == $connection->fh) ...

DESCRIPCIÓN

Este módulo es una clase base abstracta para los diversos módulos X11::Protocol::Connection::* que proporcionan conexiones a servidores X para el módulo X11::Protocol. Proporciona plantillas para los siguientes métodos:

open

$conn = X11::Protocol::Connection::Foo->open($host, $display_num)

Abre una conexión a la pantalla especificada (numerada desde 0) en el $host especificado.

give

$conn->give($data)

Envía los datos dados al servidor. Normalmente, este método solo es utilizado por el propio módulo de protocolo.

get

$data = $conn->get($n)

Lee $n bytes de datos del servidor. Normalmente, este método solo es utilizado por el propio módulo de protocolo.

fh

$filehandle = $conn->fh

Devuelve un objeto adecuado para usar como manejador de archivo. Esto es útil principalmente para realizar select() y otras llamadas al sistema similares.
