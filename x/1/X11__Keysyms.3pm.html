Keysyms(3) Documentación de Perl contribuida por el usuario Keysyms(3)

NOMBRE

X11::Keysyms - Módulo Perl para nombres de keysyms de X11

SINOPSIS

use X11::Keysyms '%Keysyms', qw(MISCELLANY XKB_KEYS LATIN1);
%Keysyms_name = reverse %Keysyms;
$ks = $Keysyms{'BackSpace'};
$name = $Keysysms_name{$ks};

DESCRIPCIÓN

Este módulo exporta una tabla hash que mapea los nombres de los keysyms de X11, como 'A' o 'Linefeed' o 'Hangul_J_YeorinHieuh', a los números que los representan. El primer argumento para 'use' es el nombre de la variable a la que se debe exportar la tabla hash, y los restantes son nombres de subconjuntos de los keysyms a exportar: uno o más de

'MISCELLANY', 'XKB_KEYS', '3270', 'LATIN1', 'LATIN2',
'LATIN3', 'LATIN4', 'KATAKANA', 'ARABIC', 'CYRILLIC',
'GREEK', 'TECHNICAL', 'SPECIAL', 'PUBLISHING', 'APL',
'HEBREW', 'THAI', 'KOREAN'.

Si esta lista se omite, se utiliza la lista

'MISCELLANY', 'XKB_KEYS', 'LATIN1', 'LATIN2', 'LATIN3',
'LATIN4', 'GREEK'

.
