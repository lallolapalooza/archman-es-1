NOMBRE

X11::Protocol::Ext::XC_MISC - Módulo Perl para la Extensión XC-MISC del Protocolo X11

SINOPSIS

use X11::Protocol;
$x = X11::Protocol->new();
$x->init_extension('XC-MISC');

DESCRIPCIÓN

Este módulo es utilizado por el programador para adquirir previamente un gran número de IDs de recursos X que se usarán con el módulo X11::Protocol.

Si el servidor lo soporta, X11::Protocol cargará este módulo automáticamente cuando se necesiten IDs de recursos adicionales a través de la interfaz estándar new_rsrc(). Sin embargo, si se prevé que un programa se ejecutará durante mucho tiempo y asignará muchos recursos, sería una buena idea inicializar la extensión al inicio para verificar su existencia.

SOLICITUDES

Esta extensión añade tres solicitudes, llamadas como se muestra a continuación:

$x->XCMiscGetVersion => ($major, $minor)
$x->XCMiscGetXIDRange => ($start_id, $count)
$x->XCMiscGetXIDList($count) => ($count, @ids)
