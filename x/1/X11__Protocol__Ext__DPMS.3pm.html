Protocol::Ext::DPMS(3) Documentación Perl aportada por el usuario Protocol::Ext::DPMS(3)

NOMBRE

X11::Protocol::Ext::DPMS - Módulo Perl para la extensión DPMS del protocolo X11

SINOPSIS

use X11::Protocol;
$x = X11::Protocol->new();
$x->init_extension('DPMS');

DESCRIPCIÓN

Este módulo se utiliza para controlar las funciones DPMS de los monitores compatibles.

CONSTANTES SIMBÓLICAS

Esta extensión añade el tipo de constante DPMSPowerLevels, con valores según se definen en el estándar.

SOLICITUDES

Esta extensión añade varias solicitudes, que se llaman como se muestra a continuación:

$x->DPMSGetVersion => ($major, $minor)
$x->DPMSCapable => ($capable)
$x->DPMSGetTimeouts => ($standby_timeout, $suspend_timeout, $off_timeout)
$x->DPMSSetTimeouts($standby_timeout, $suspend_timeout, $off_timeout) => ()
$x->DPMSEnable => ()
$x->DPMSDisable => ()
$x->DPMSForceLevel($power_level) => ()
$x->DPMSInfo => ($power_level,$state)
