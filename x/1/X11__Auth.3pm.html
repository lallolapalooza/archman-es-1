NOMBRE

X11::Auth - Módulo Perl para leer archivos de autorización X11

SINOPSIS

require X11::Auth;
$a = new X11::Auth;
($auth_type, $auth_data) = $a->get_by_host($host, $disp_num);

DESCRIPCIÓN

Este módulo es un reemplazo aproximado en Perl para la biblioteca C libXau y el programa xauth(1). Lee e interpreta los archivos (normalmente '~/.Xauthority') que contienen datos de autorización utilizados para conectarse a servidores X. Dado que fue escrito principalmente para el uso de X11::Protocol, su funcionalidad se limita actualmente a la lectura, no a la escritura, de estos archivos.

MÉTODOS

new

$auth = X11::Auth->new;
$auth = X11::Auth->open($filename);

Abre un archivo de autorización y crea un objeto para manejarlo. El nombre del archivo se tomará de la variable de entorno XAUTHORITY, si está presente, o de '.Xauthority' en el directorio de inicio del usuario, o puede ser anulado por un argumento. 'open' puede usarse como sinónimo.

get_one

($family, $host_addr, $display_num, $auth_name, $auth_data)
   = $auth->get_one;

Lee una entrada del archivo. Devuelve una lista nula al final del archivo. $family suele ser 'Internet' o 'Local', y $display_num puede ser cualquier cadena.

get_all

@auth_data = $auth->get_all;

Lee todas las entradas del archivo. Cada miembro del array devuelto es una referencia a un array similar a la lista devuelta por get_one().

get_by_host

($auth_name, $auth_data)
   = $auth->get_by_host($host, $family, $display_num);

Obtiene datos de autenticación para una conexión de tipo $family a la pantalla $display_num en $host. Si $family es 'Internet', el host se traducirá a una dirección adecuada mediante gethostbyname(). Si no se encuentran datos, devuelve una lista vacía.
