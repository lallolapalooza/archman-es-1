X11::Protocol::Other(3) Documentación de Perl aportada por el usuario X11::Protocol::Other(3)

NOMBRE

X11::Protocol::Other -- utilidades varias de X11::Protocol

SINOPSIS

use X11::Protocol::Other;

DESCRIPCIÓN

Esta son algunas funciones de utilidad para "X11::Protocol".

EXPORTACIÓN

No se exporta nada por defecto, pero las funciones se pueden solicitar al estilo habitual de "Exporter",

use X11::Protocol::Other 'visual_is_dynamic';
if (visual_is_dynamic ($X, $visual_id)) {
  ...
}

O simplemente llamarlas con el nombre completo del paquete

use X11::Protocol::Other;
if (X11::Protocol::Other::visual_is_dynamic ($X, $visual_id)) {
  ...
}

No hay una etiqueta ":all" ya que este módulo está pensado como un cajón de sastre de funciones y para importar cosas aún desconocidas se pedirían colisiones de nombres.

FUNCIONES

Búsqueda de Pantalla

"$numero = root_to_screen ($X, $root)"
"$hashref = root_to_screen_info ($X, $root)"
Devuelve el número de pantalla o la información de la pantalla (hash) para una ventana raíz dada. $root puede ser cualquier entero XID en $X. Si no es una de las ventanas raíz, la devolución es "undef".
"$numero = default_colormap_to_screen ($X, $colormap)"
"$hashref = default_colormap_to_screen_info ($X, $colormap)"
Devuelve el número de pantalla o la información de la pantalla (hash) para un mapa de colores predeterminado dado. $colormap puede ser cualquier entero XID en $X. Si no es uno de los mapas de colores predeterminados de la pantalla, la devolución es "undef".

Visuales

"$bool = visual_is_dynamic ($X, $visual_id)"
"$bool = visual_class_is_dynamic ($X, $visual_class)"
Devuelve verdadero si el visual dado es dinámico, lo que significa que las entradas del mapa de colores en él pueden cambiarse para cambiar el color de un valor de píxel dado.

$visual_id es uno de los números de ID visual, es decir, una de las claves en "$X->{'visuals'}". O $visual_class es una cadena de ClaseVisual como "PseudoColor" o un entero correspondiente como 3.

Información de Ventana

"($width, $height) = window_size ($X, $window)"
"$visual_id = window_visual ($X, $window)"
Devuelve el tamaño o el ID visual de una ventana dada.

$window es un entero XID en $X. Si es una de las ventanas raíz, los valores de retorno provienen del hash de información de pantalla en $X, de lo contrario, el servidor es consultado con GetGeometry() (para el tamaño) o GetWindowAttributes() (para el visual).

Estas funciones son útiles cuando existe una alta probabilidad de que $window sea una ventana raíz y, por lo tanto, no necesite un viaje de ida y vuelta al servidor.

"@atoms = get_property_atoms($X, $window, $property)"
Obtiene de $window (entero XID) una propiedad de lista de átomos $property (entero de átomo). La devolución es una lista de enteros de átomos, posiblemente una lista vacía. Si $property no existe o no son átomos, devuelve una lista vacía.
"set_property_atoms($X, $window, $property, @atoms)"
Establece en $window (entero XID) una propiedad de lista de átomos $property (entero de átomo) como la lista dada de @atoms (posiblemente vacía).

Análisis de Color

"($red16, $green16, $blue16) = hexstr_to_rgb($str)"
Analiza una cadena de color RGB dada como "#FF00FF" en componentes rojo, verde y azul de 16 bits. Los valores de retorno están siempre en el rango de 0 a 65535. Las cadenas reconocidas son hexadecimales de 1, 2, 3 o 4 dígitos. 
#RGB
#RRGGBB
#RRRGGGBBB
#RRRRGGGGBBBB

Si $str no se reconoce, la devolución es una lista vacía, por ejemplo:

my @rgb = hexstr_to_rgb($str)
  or die "Color no reconocido: $str";

Los dígitos de las formas de 1, 2 y 3 se replican según sea necesario para dar un rango de 16 bits. Por ejemplo, el estilo de 3 dígitos "#321FFF000" devuelve los valores 0x3213, 0xFFFF, 0. O el de 1 dígito "#F0F" es 0xFFFF, 0, 0xFFFF. Nótese que "F" se expande a 0xFFFF, por lo que "F", "FF" o "FFF" significan saturación completa, igual que un "FFFF" de 4 dígitos.

¿Valdría la pena reconocer el estilo Xcms "rgb:RR/GG/BB"? Quizás eso sea mejor dejarlo a Xcms completo, o a módulos de conversión de color generales. La página del manual X(7) de X11R6 describe el formato "rgb:", pero solo "#" es mucho más común.
