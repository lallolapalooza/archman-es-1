X11::Protocol::ChooseWindow(3) Documentación de Perl aportada por el usuario X11::Protocol::ChooseWindow(3)

NOMBRE

X11::Protocol::ChooseWindow -- el usuario hace clic para elegir una ventana

SINOPSIS

use X11::Protocol::ChooseWindow;
my $client_window = X11::Protocol::ChooseWindow->choose (X => $X);

DESCRIPCIÓN

Este fragmento de código permite al usuario hacer clic en una ventana de nivel superior para elegirla, de forma similar a los programas "xwininfo" o "xkill".

Implementación

La elección se implementa de forma similar a los programas "xwininfo", etc. Consiste en GrabPointer() en la ventana raíz, esperar una "ButtonPress" y "ButtonRelease" del usuario, obtener la ventana del marco a partir del evento "ButtonPress", y luego la ventana cliente que se encuentra debajo mediante frame_window_to_client() de "X11::Protocol::WM".

Los eventos "KeyPress" no se utilizan y van a la ventana de foco de la forma habitual. Esto puede ser bueno en un programa de línea de comandos, ya que permite al usuario presionar "^C" ("SIGINT") en un "xterm" o similar. Quizás en el futuro podría haber una opción para esperar "Esc" para cancelar o algo parecido.

Se utiliza una raíz virtual según root_to_virtual_root() en "X11::Protocol::WM" si está presente. Esto ayuda a "ChooseWindow" a funcionar con "amiwm" y gestores de ventanas de raíz virtual similares.

FUNCIONES

La siguiente función choose() está en estilo de método de clase con la intención de, en el futuro, tener objetos de tipo "X11::Protocol::ChooseWindow" que mantengan el estado y que sean avanzados por eventos proporcionados por un bucle principal externo.

Elección

"$window = X11::Protocol::ChooseWindow->choose (key=>value,...)"
Lee la pulsación de un botón del usuario para elegir una ventana de nivel superior. Las opciones clave/valor son las siguientes: 
X        => Objeto X11::Protocol
display  => cadena, ":0:0" etc.
screen   => entero, p. ej., 0
root     => XID de la ventana raíz
time     => marca de tiempo del servidor entero
event    => hashref del evento que inicia la elección
cursor       => XID del cursor
cursor_glyph => glifo entero de la fuente de cursor
cursor_name  => nombre de cadena de la fuente de cursor

"X" o "display" proporciona el servidor, o por defecto abre la variable de entorno "DISPLAY". "X" para un objeto "X11::Protocol" es lo habitual, pero a veces puede tener sentido abrir una nueva conexión solo para elegir.

"root" o "screen" proporciona la ventana raíz sobre la que elegir, o por defecto es la pantalla actual de $X, que a su vez por defecto es la parte de pantalla del nombre de visualización. Si hay una raíz virtual del gestor de ventanas, se utiliza automáticamente según sea necesario.

"time" o el campo de tiempo en "event" es una marca de tiempo del servidor para GrabPointer(). Esto protege contra el robo de un grab de otro cliente si hay un retraso considerable. Omitido o "undef" significa "CurrentTime". En un programa de línea de comandos, puede que no haya un evento iniciador, lo que hace que "CurrentTime" sea lo único posible.

"cursor" etc. es el cursor del puntero del ratón que se mostrará durante la elección, como indicación visual para el usuario. El valor predeterminado es una "mira". "cursor_name" o "cursor_glyph" provienen de la fuente de cursor habitual. Consulte X11::CursorFont para ver los nombres disponibles. Por ejemplo, quizás el cursor "exchange" para elegir una ventana para algún tipo de intercambio o volteo,

$window = X11::Protocol::ChooseWindow->choose
            (X => $X,
             cursor_name => "exchange");

Un XID de "cursor" puede ser creado por cualquier cliente como de costumbre. No olvide hacer flush si crea un cursor desde una conexión, para que esté listo para ser utilizado desde otra.

VEA TAMBIÉN

X11::Protocol, X11::Protocol::WM, X11::CursorFont

xwininfo(1), xkill(1), y su código Select_Window() de dsimple.c

Sección "Inter-Client Communication Conventions Manual" "WM_STATE Property" para notas sobre el uso de "WM_STATE" para identificar ventanas cliente.
