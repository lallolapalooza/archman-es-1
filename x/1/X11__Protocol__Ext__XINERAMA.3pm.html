X11::Protocol::Ext::XINERAMA(3) Documentación de Perl aportada por el usuario X11::Protocol::Ext::XINERAMA(3)

NOMBRE

X11::Protocol::Ext::XINERAMA - información de pantalla multimonitor

SINOPSIS

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('XINERAMA')
  or print "La extensión XINERAMA no está disponible";

DESCRIPCIÓN

Xinerama une dos o más monitores físicos para crear una única pantalla grande. La extensión XINERAMA permite a los clientes consultar la configuración.

Las solicitudes de "PanoramiX" 1.0 toman un parámetro $window aparentemente para permitir más de una pantalla X compuesta por múltiples monitores físicos, pero en la práctica los servidores solo han creado una pantalla de esta manera y las solicitudes de "Xinerama" 1.1 no tienen eso.

Ver examples/xinerama-info.pl para un programa de ejemplo que volca la información de estado de Xinerama.

SOLICITUDES

Las siguientes solicitudes se ponen a disposición con un init_extension() por cada "EXTENSIONS" en X11::Protocol.

my $bool = $X->init_extension('XINERAMA');

Xinerama 1.0

"($server_major, $server_minor) = $X->PanoramiXQueryVersion ($client_major, $client_minor)"
Negocia una versión del protocolo con el servidor. $client_major y $client_minor es lo que el cliente desearía, $server_major y $server_minor devueltos es lo que el servidor hará, que puede ser menos de lo solicitado (pero no más).

El código actual en este módulo soporta hasta 1.1. La intención sería negociar automáticamente dentro de init_extension() si/cuando fuera necesario.

"$flag = $X->PanoramiXGetState ($window)"
Devuelve un valor distinto de cero si Xinerama está activo en la pantalla de $window (un XID).
"$count = $X->PanoramiXGetScreenCount ($window)"
Devuelve el número de monitores físicos en la pantalla de $window (un XID).
"($width, $height) = $X->PanoramiXGetScreenSize ($window, $monitor)"
Devuelve el tamaño en píxeles del monitor físico número $monitor (entero, 0 para el primer monitor) en la pantalla de $window (un XID).

Xinerama 1.1

"$bool = $X->XineramaIsActive ()"
Devuelve un valor distinto de cero si Xinerama está activo en el servidor $X.
"@rectangles = $X->XineramaQueryScreens ()"
Devuelve las áreas rectangulares compuestas por los monitores físicos. La devolución es una lista de referencias a arrays, 
[ $x,$y, $width,$height ]

$x,$y es la esquina superior izquierda del monitor en la pantalla combinada.

ERRORES

"Xsun"

Los rumores dicen que el servidor "Xsun" con Xinerama 1.0 tenía un número de solicitud 4 diferente al "XineramaIsActive" de Xinerama 1.1 arriba.

http://blogs.sun.com/alanc/entry/xinerama_protocol_clashes_on_solaris

No se intenta hacer nada al respecto aquí, hasta ahora. Si PanoramiXQueryVersion() informa 1.0, entonces no deberías usar XineramaIsActive() de todos modos, así que no hay conflicto. Si lo haces y es el servidor "Xsun", entonces espera una respuesta de error de Longitud, o que el servidor se adapte a la longitud de la solicitud y se comporte como "XineramaIsActive".

Desbordamiento de búfer de PanoramiXGetScreenSize()

El código temprano del servidor, como X11R6.4, puede no verificar el rango del número de monitor en PanoramiXGetScreenSize(). ¿Los valores grandes leen fragmentos de memoria arbitraria o causan un segfault? No hagas eso.

X.org algún tiempo después de 1.5.x, "Prevenir desbordamiento de búfer en ProcPanoramiXGetScreenSize", http://cgit.freedesktop.org/xorg/xserver/commit/?id=2b266eda6e23d16116f8a8e258192df353970279

OTRAS NOTAS

Para simular Xinerama para pruebas, el servidor "Xdmx" puede multiplexar dos o más servidores otros para presentar una pantalla grande. Esos sub-servidores pueden ser incluso ventanas de "Xnest" o "Xephyr" en una pantalla X existente. Por ejemplo, ejecutando "Xdmx" como display ":102",

Xephyr :5 -screen 200x100 &
Xephyr :6 -screen 190x110 &
sleep 1
Xdmx -display :5 -display :6 +xinerama -input :5 -input :6 :102

"Xephyr" implementa algunas extensiones nativamente, mientras que "Xnest" depende de las capacidades del servidor objetivo. O para ejecutar sin molestarse en mirar nada "Xvfb" en memoria o un archivo en disco.
