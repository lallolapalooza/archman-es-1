Xorg.wrap(1) Manual de Comandos Generales Xorg.wrap(1)

NOMBRE

Xorg.wrap - wrapper binario del servidor Xorg X

DESCRIPCIÓN

El servidor X Xorg puede necesitar privilegios de root para funcionar correctamente. Para iniciar el servidor X Xorg con estos privilegios, su sistema está utilizando un wrapper suid root instalado como /usr/libexec/Xorg.wrap que ejecutará el servidor X real, instalado como /usr/libexec/Xorg.

Por defecto, Xorg.wrap detectará automáticamente si se necesitan privilegios de root y, si no es así, renunciará a sus privilegios elevados antes de iniciar el servidor X real. Por defecto, Xorg.wrap solo permitirá ejecutar el servidor X real desde sesiones de inicio de sesión en una consola física.

ARCHIVO DE CONFIGURACIÓN

El comportamiento predeterminado de Xorg.wrap se puede anular desde el archivo de configuración /etc/X11/Xwrapper.config. Las líneas que comienzan con un # en Xwrapper.config se consideran comentarios y se ignoran. Cualquier otra línea no vacía debe tener el formato clave = valor.

usuarios_permitidos = solo_root|consola|cualquiera
Especifica qué usuarios pueden iniciar el servidor X a través del wrapper. Utilice solo_root para permitir solo a root, consola para permitir solo a usuarios que hayan iniciado sesión en una consola física y cualquiera para permitir a cualquiera. El valor predeterminado es consola.
necesita_privilegios_de_root = sí|no|auto
Configura si el wrapper debe renunciar a sus privilegios elevados (root) antes de iniciar el servidor X. Utilice sí para forzar la ejecución como root, no para forzar la ejecución con todos los privilegios suid renunciados y auto para dejar que el wrapper lo detecte automáticamente. El valor predeterminado es auto.

Al detectar automáticamente, el wrapper renunciará a los privilegios si hay gráficos KMS disponibles y no los renunciará si no se detectan gráficos KMS. Si un sistema tiene múltiples tarjetas gráficas y algunas no son compatibles con KMS, la detección automática puede fallar; en ese caso, se debe utilizar la configuración manual.
