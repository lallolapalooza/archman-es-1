NOMBRE

XIntersectRegion, XUnionRegion, XUnionRectWithRegion, XSubtractRegion, XXorRegion, XOffsetRegion, XShrinkRegion - aritmética de regiones

SINTAXIS

int XIntersectRegion(Region sra, Region srb, Region dr_return);

int XUnionRegion(Region sra, Region srb, Region dr_return);

int XUnionRectWithRegion(XRectangle *rectangle, Region src_region, Region dest_region_return);

int XSubtractRegion(Region sra, Region srb, Region dr_return);

int XXorRegion(Region sra, Region srb, Region dr_return);

int XOffsetRegion(Region r, int dx, int dy);

int XShrinkRegion(Region r, int dx, int dy);

ARGUMENTOS

dest_region_return
Devuelve la región de destino.
dr_return
Devuelve el resultado del cálculo.
dx

dy
Especifican las coordenadas x e y, que definen la cantidad que desea mover o reducir la región especificada.
r
Especifica la región.
rectangle
Especifica el rectángulo.
sra

srb
Especifican las dos regiones con las que desea realizar el cálculo.
src_region
Especifica la región de origen a utilizar.

DESCRIPCIÓN

La función XIntersectRegion calcula la intersección de dos regiones.

La función XUnionRegion calcula la unión de dos regiones.

La función XUnionRectWithRegion actualiza la región de destino a partir de la unión del rectángulo especificado y la región de origen especificada.

La función XSubtractRegion resta srb de sra y almacena los resultados en dr_return.

La función XXorRegion calcula la diferencia entre la unión y la intersección de dos regiones.

La función XOffsetRegion mueve la región especificada la cantidad especificada.

La función XShrinkRegion reduce la región especificada la cantidad especificada. Los valores positivos reducen el tamaño de la región, y los valores negativos la expanden.
