XEmptyRegion(3) FUNCIONES XLIB XEmptyRegion(3)

NOMBRE

XEmptyRegion, XEqualRegion, XPointInRegion, XRectInRegion - determinar si las regiones están vacías o son iguales

SINTAXIS

Bool XEmptyRegion(Region r);

Bool XEqualRegion(Region r1, Region r2);

Bool XPointInRegion(Region r, int x, int y);

int XRectInRegion(Region r, int x, int y, unsigned int width, unsigned int height);

ARGUMENTOS

r
Especifica la región.
r1

r2
Especifican las dos regiones.
width

height
Especifican el ancho y alto, que definen el rectángulo.
x

y
Especifican las coordenadas x e y, que definen el punto o las coordenadas de la esquina superior izquierda del rectángulo.

DESCRIPCIÓN

La función XEmptyRegion devuelve True si la región está vacía.

La función XEqualRegion devuelve True si las dos regiones tienen la misma posición, tamaño y forma.

La función XPointInRegion devuelve True si el punto (x, y) está contenido en la región r.

La función XRectInRegion devuelve RectangleIn si el rectángulo está completamente dentro de la región especificada, RectangleOut si el rectángulo está completamente fuera de la región especificada, y RectanglePart si el rectángulo está parcialmente dentro de la región especificada.

VER TAMBIÉN
