Xephyr(1) Manual de Comandos Generales Xephyr(1)

NOMBRE

Xephyr - servidor X que genera salida en una ventana en una pantalla X preexistente

SINOPSIS

Xephyr [:pantalla] [opción ...]

DESCRIPCIÓN

Xephyr es un servidor kdrive que genera salida en una ventana en una pantalla X "host" preexistente. Piensa en Xnest pero con soporte para extensiones modernas como composite, damage y randr.

A diferencia de Xnest, que es un proxy X, es decir, limitado a las capacidades del servidor X host, Xephyr es un servidor X real que utiliza la ventana del servidor X host como "framebuffer" a través de XImages SHM rápidos.

También tiene soporte para depurar "visualmente" lo que el servidor está pintando.

OPCIONES

El servidor acepta todas las opciones estándar de Xserver(1) y las siguientes opciones adicionales:

-pantalla anchoxalto
establece el tamaño de la pantalla.
-padre id
usa la ventana existente id. Si un argumento -pantalla sigue a un argumento -padre, esta pantalla se incrusta en la ventana dada.
-cursor-host
establece la 'aceleración del cursor': Se reutiliza el cursor del host. Esto es solo para ayudar a la depuración al evitar que el servidor pinte el cursor. La mejora de rendimiento es insignificante.
-redimensionable
Permite que la ventana de Xephyr se redimensione, incluso si no está incrustada en una ventana padre. Por defecto, la ventana de Xephyr tiene un tamaño fijo.
-no-grab-host
Deshabilita la captura del teclado y el ratón.

SEÑALES

Envía una SIGUSR1 al servidor (por ejemplo, pkill -USR1 Xephyr) para activar/desactivar el modo de depuración. En este modo, se pintan rectángulos rojos en las áreas de la pantalla que se están pintando antes de pintar el contenido real. El retraso entre estos puede alterarse estableciendo una variable de entorno XEPHYR_PAUSE a un valor en microsegundos.

COMENTARIOS

  • Las pantallas rotadas actualmente se actualizan mediante blits completos. Esto es más lento que una pantalla con orientación normal. Por lo tanto, el modo de depuración no será de mucha utilidad cuando esté rotado.
  • El cursor '-cursor-host' es estático en su apariencia.
  • La compilación muestra una advertencia sobre 'nanosleep'. Creo que las diversas banderas de compilación '-D' están causando esto. Aún no he encontrado cómo solucionarlo. Sin embargo, no parece romper nada.
  • El manejo del teclado es básico pero funciona.
  • Es probable que el botón 5 del ratón no funcione.
