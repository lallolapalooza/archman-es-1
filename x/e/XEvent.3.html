XAnyEvent(3) FUNCIONES DE XLIB XAnyEvent(3)

NOMBRE

XAnyEvent, XEvent - estructuras genéricas de eventos X

ESTRUCTURAS

Todas las estructuras de eventos declaradas en <X11/Xlib.h> tienen los siguientes miembros comunes:

typedef struct {
        int type;
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window window;
} XAnyEvent;

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero a la pantalla en la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero se expande de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

La estructura XEvent es una unión de las estructuras individuales declaradas para cada tipo de evento:

typedef union _XEvent {
        int type;       /* no debe cambiarse */
        XAnyEvent xany;
        XKeyEvent xkey;
        XButtonEvent xbutton;
        XMotionEvent xmotion;
        XCrossingEvent xcrossing;
        XFocusChangeEvent xfocus;
        XExposeEvent xexpose;
        XGraphicsExposeEvent xgraphicsexpose;
        XNoExposeEvent xnoexpose;
        XVisibilityEvent xvisibility;
        XCreateWindowEvent xcreatewindow;
        XDestroyWindowEvent xdestroywindow;
        XUnmapEvent xunmap;
        XMapEvent xmap;
        XMapRequestEvent xmaprequest;
        XReparentEvent xreparent;
        XConfigureEvent xconfigure;
        XGravityEvent xgravity;
        XResizeRequestEvent xresizerequest;
        XConfigureRequestEvent xconfigurerequest;
        XCirculateEvent xcirculate;
        XCirculateRequestEvent xcirculaterequest;
        XPropertyEvent xproperty;
        XSelectionClearEvent xselectionclear;
        XSelectionRequestEvent xselectionrequest;
        XSelectionEvent xselection;
        XColormapEvent xcolormap;
        XClientMessageEvent xclient;
        XMappingEvent xmapping;
        XErrorEvent xerror;
        XKeymapEvent xkeymap;
        long pad[24];
} XEvent;

La primera entrada de una estructura XEvent es siempre el miembro type, que se establece en el tipo de evento. El segundo miembro es siempre el número de serie de la solicitud de protocolo que generó el evento. El tercer miembro es siempre send_event, que es un Bool que indica si el evento fue enviado por un cliente diferente. El cuarto miembro es siempre display, que es la pantalla de la que se leyó el evento. Excepto por los eventos keymap, el quinto miembro es siempre window, que ha sido cuidadosamente seleccionado para ser útil a los despachadores de toolkits. Para evitar romper los toolkits, el orden de estas cinco primeras entradas no cambiará. La mayoría de los eventos también contienen un miembro time, que es el tiempo en el que ocurrió un evento. Además, un puntero al evento genérico debe ser convertido antes de ser usado para acceder a cualquier otra información en la estructura.
