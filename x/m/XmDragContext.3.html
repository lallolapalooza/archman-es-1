NOMBRE

XmDragContext — La clase de widget DragContext

SINOPSIS

#include <Xm/DragDrop.h>

DESCRIPCIÓN

Los DragContexts son widgets especiales utilizados en transacciones de arrastrar y soltar. Un DragContext se implementa como un widget, pero un cliente no crea explícitamente un widget DragContext. En su lugar, un cliente inicia una transacción de arrastrar y soltar llamando a XmDragStart, y esta rutina inicializa y devuelve un widget DragContext. Hay un DragContext único para cada operación de arrastre. El toolkit libera un DragContext cuando una transacción se completa; por lo tanto, un programador de aplicaciones no debe destruir explícitamente un DragContext.

Los clientes iniciadores y receptores utilizan DragContexts para realizar un seguimiento del estado de una transacción. Cuando el iniciador y el receptor de una transacción están en el mismo cliente, comparten la misma instancia de DragContext. Si están en clientes diferentes, hay dos DragContexts separados. En este caso, el iniciador llama a XmDragStart y el toolkit proporciona un DragContext para el cliente receptor. Los únicos recursos pertinentes para el receptor son XmNexportTargets y XmNnumExportTargets. Ambos se pueden pasar como argumentos a la función XmDropSiteRetrieve para obtener información sobre el sitio de destino actual.

En general, para recibir datos, un sitio de destino debe compartir al menos un tipo de destino y una operación en común con una fuente de arrastre. El recurso DragContext, XmNexportTargets, identifica los destinos de selección para la fuente de arrastre. Estos destinos de exportación se comparan con la lista de recursos XmNimportTargets especificada por un sitio de destino. El recurso DragContext, XmNdragOperations, identifica las operaciones válidas que pueden aplicarse a los datos de origen por el iniciador. El recurso correspondiente del sitio de destino es XmNdropSiteOperations, que indica las operaciones admitidas por un sitio de destino.

Un cliente utiliza widgets DragIcon para definir los efectos de animación al pasar por encima del arrastre asociados con una determinada transacción de arrastrar y soltar. Un iniciador especifica un conjunto de iconos de arrastre, selecciona un modelo de mezcla y establece los colores del cursor frontal y de fondo con los recursos de DragContext.

El tipo de visualización al pasar por encima del arrastre que se utiliza para representar una operación de arrastre depende del estilo del protocolo de arrastre. En el modo de preregistro, el servidor se agarra, y se puede utilizar un cursor o un pixmap como visualización al pasar por encima del arrastre. En el modo dinámico, las visualizaciones al pasar por encima del arrastre deben implementarse con el cursor X. Si el estilo del protocolo de arrastre resultante es Solo destino o Ninguno y XmNdragInitiatorProtocolStyle es XmDRAG_DYNAMIC o XmDRAG_PREFER_DYNAMIC, entonces se utiliza un estilo visual dinámico (cursor). De lo contrario, se utiliza un estilo visual de preregistro.

CLASES

DragContext hereda el comportamiento y los recursos de Core.

El puntero de clase es xmDragContextClass.

El nombre de la clase es XmDragContext.

XmNblendModel
Especifica qué combinación de DragIcons se mezclan para producir una imagen visual de "arrastrar y soltar".
XmBLEND_ALL
Mezcla los tres DragIcons: el icono de origen, el de estado y el de operación. Los iconos se superponen de arriba hacia abajo, con el icono de operación encima y el icono de origen debajo. El punto de enfoque se deriva del icono de estado.
XmBLEND_STATE_SOURCE
Mezcla solo los iconos de estado y origen. El punto de enfoque se deriva del icono de estado.
XmBLEND_JUST_SOURCE
Especifica que solo se utiliza el icono de origen, que el iniciador actualiza según sea necesario.
XmBLEND_NONE
Especifica que no se genera ninguna imagen visual de "arrastrar y soltar". El cliente rastrea el estado del sitio de destino a través de las rutinas de callback y actualiza las imágenes visuales según sea necesario.
XmNclientData
Especifica los datos del cliente que se pasarán a XmNconvertProc cuando se invoque.
XmNconvertProc
Si XmNincremental es True, especifica un procedimiento de tipo XtConvertSelectionIncrProc que convierte los datos de origen al(a los) formato(s) solicitado(s) por el cliente receptor. El argumento widget pasado a este procedimiento es el widget DragContext. El átomo de selección pasado es _MOTIF_DROP. Si XmNincremental es False, el procedimiento es un XtConvertSelectionProc, y debe ignorar los argumentos max_length, client_data y request_id, y debe manejar la conversión de forma atómica. Los datos devueltos por XmNconvertProc deben ser asignados usando XtMalloc, y serán liberados automáticamente por el toolkit después de la transferencia. Para obtener más información sobre los procedimientos de conversión de selección, consulte X Toolkit Intrinsics—C Language Interface.
XmNcursorBackground
Especifica el valor de píxel de fondo del cursor.
XmNcursorForeground
Especifica el valor de píxel de primer plano del cursor cuando el icono de estado no se mezcla. Este recurso, por defecto, toma el color de primer plano del widget pasado a la función XmDragStart.

RESOURCES

XmNdragDropFinishCallback
Specifies the list of callbacks that are invoked when the drag and drop operation is completed. The type of the structure whose address is passed to this callback is XmDragDropFinishCallbackStruct. The reason sent by the callback is XmCR_DRAG_DROP_FINISH.
XmNdragMotionCallback
Specifies the list of callbacks that are invoked when the pointer moves. The type of structure whose address is passed to this callback is XmDragMotionCallbackStruct. The reason sent by the callback is XmCR_DRAG_MOTION.
XmNdragOperations
Specifies the set of valid operations associated with an initiator client for a drag transaction. This resource is a bit mask that is formed by combining one or more of the following values using a bitwise operation such as inclusive OR (|): XmDROP_COPY, XmDROP_LINK, XmDROP_MOVE. The value XmDROP_NOOP for this resource indicates that no operations are valid. For Text and TextField widgets, this resource is set to XmDROP_COPY | XmDROP_MOVE; for List widgets, it is set to XmDROP_COPY.
XmNdropFinishCallback
Specifies the list of callbacks that are invoked when the drop is completed. The type of the structure whose address is passed to this callback is XmDropFinishCallbackStruct. The reason sent by the callback is XmCR_DROP_FINISH.
XmNdropSiteEnterCallback
Specifies the list of callbacks that are invoked when the pointer enters a drop site. The type of the structure whose address is passed to this callback is XmDropSiteEnterCallbackStruct. The reason sent by the callback is XmCR_DROP_SITE_ENTER.
XmNdropSiteLeaveCallback
Specifies the list of callbacks that are invoked when the pointer leaves a drop site. The type of the structure whose address is passed to this callback is XmDropSiteLeaveCallbackStruct. The reason sent by the callback is XmCR_DROP_SITE_LEAVE.
XmNdropStartCallback
Specifies the list of callbacks that are invoked when a drop is initiated. The type of the structure whose address is passed to this callback is XmDropStartCallbackStruct. The reason sent by the callback is XmCR_DROP_START.
XmNexportTargets
Specifies the list of target atoms associated with this source. This resource identifies the selection targets this source can be converted to.
XmNincremental
Specifies a Boolean value that indicates whether the transfer on the initiator side uses the Xt incremental selection transfer mechanism described in X Toolkit Intrinsics—C Language Interface. If the value is True, the initiator uses incremental transfer; if the value is False, the initiator uses atomic transfer.
XmNinvalidCursorForeground
Specifies the foreground pixel value of the cursor when the state is invalid. This resource defaults to the value of the XmNcursorForeground resource.
XmNnoneCursorForeground
Specifies the foreground pixel value of the cursor when the state is none. This resource defaults to the value of the XmNcursorForeground resource.
XmNnumExportTargets
Specifies the number of entries in the list of export targets.
XmNoperationChangedCallback
Specifies the list of callbacks that are invoked when the drag is started and when the user requests that a different operation be applied to the drop. The type of the structure whose address is passed to this callback is XmOperationChangedCallbackStruct. The reason sent by the callback is XmCR_OPERATION_CHANGED.
XmNoperationCursorIcon
Specifies the cursor icon used to designate the type of operation performed by the drag transaction. If NULL, XmScreen resources provide default icons for copy, link, and move operations.
XmNsourceCursorIcon
Specifies the cursor icon used to represent the source when a dynamic visual style is used. If NULL, the XmNdefaultSourceCursorIcon resource of XmScreen provides a default cursor icon.
XmNsourcePixmapIcon
Specifies the pixmap icon used to represent the source when a preregister visual style is used. The icon is used in conjunction with the colormap of the widget passed to XmDragStart. If NULL, XmNsourceCursorIcon is used.
XmNstateCursorIcon
Specifies the cursor icon used to designate the state of a drop site. If NULL, XmScreen resources provide default icons for a valid, invalid, and no drop site condition.
XmNtopLevelEnterCallback
Specifies the list of callbacks that are called when the pointer enters a top-level window or root window (due to changing screens). The type of the structure whose address is passed to this callback is XmTopLevelEnterCallbackStruct. The reason sent by the callback is XmCR_TOP_LEVEL_ENTER.
XmNtopLevelLeaveCallback
Specifies the list of callbacks that are called when the pointer leaves a top level window or the root window (due to changing screens). The type of the structure whose address is passed to this callback is XmTopLevelLeaveCallbackStruct. The reason sent by the callback is XmCR_TOP_LEVEL_LEAVE.
XmNvalidCursorForeground
Specifies the foreground pixel value of the cursor designated as a valid cursor icon.

Información de Callback

Cada uno de los callbacks de DragContext tiene una estructura de callback asociada.

Se pasa un puntero a la siguiente estructura al callback XmNdragDropFinishCallback:

typedef struct
{
        int reason;
        XEvent  *event;
        Time timeStamp;
}XmDragDropFinishCallbackStruct, *XmDragDropFinishCallback;
reason
Indica por qué se invocó el callback.
event
Apuntador al XEvent que desencadenó el callback.
timeStamp
Especifica el momento en que se completó la operación de arrastrar o soltar.

Se pasa un puntero a la siguiente estructura a los callbacks para XmNdragMotionCallback:

typedef struct
{
        int reason;
        XEvent *event;
        Time timeStamp;
        unsigned char operation;
        unsigned char operations;
        unsigned char dropSiteStatus;
        Position x;
        Position y;
}XmDragMotionCallbackStruct, *XmDragMotionCallback;
reason
Indica por qué se invocó el callback.
event
Apuntador al XEvent que desencadenó el callback.
timeStamp
Especifica la marca de tiempo del evento lógico.
operation
Identifica una operación.
Si el toolkit acaba de llamar a un XmNdragProc de un DropSite, el toolkit inicializa operation al valor del miembro operation de la XmDragProcCallbackStruct en el momento en que el XmNdragProc del DropSite devuelve.
Si el toolkit no ha llamado a un XmNdragProc y el puntero se encuentra dentro de un sitio de soltado activo, el toolkit inicializa operation seleccionando una operación del AND bit a bit del valor inicial del miembro operations y el valor del recurso XmNdropSiteOperations del DropSite. El toolkit busca en este conjunto primero XmDROP_MOVE, luego XmDROP_COPY, luego XmDROP_LINK, y inicializa operation a la primera operación que encuentra en el conjunto. Si el toolkit no encuentra ninguna de estas operaciones en el conjunto, inicializa operation a XmDROP_NOOP.
Si el toolkit no ha llamado a un XmNdragProc y el puntero no se encuentra dentro de un sitio de soltado activo, el toolkit inicializa operation seleccionando una operación del valor inicial del miembro operations. El toolkit busca en este conjunto primero XmDROP_MOVE, luego XmDROP_COPY, luego XmDROP_LINK, y inicializa operation a la primera operación que encuentra en el conjunto. Si el toolkit no encuentra ninguna de estas operaciones en el conjunto, inicializa operation a XmDROP_NOOP.
operations
Indica el conjunto de operaciones soportadas para los datos de origen.
Si el toolkit acaba de llamar a un XmNdragProc de un DropSite, el toolkit inicializa operations al AND bit a bit de los XmNdropOperations del DropSite y el valor del miembro operations de la XmDragProcCallbackStruct en el momento en que el XmNdragProc del DropSite devuelve. Si el conjunto resultante de operaciones está vacío, el toolkit inicializa operations a XmDROP_NOOP.
Si el toolkit no ha llamado a un XmNdragProc y el usuario no selecciona una operación (presionando una tecla modificadora), el toolkit inicializa operations al valor del recurso XmNdragOperations del DragContext.
Si el toolkit no ha llamado a un XmNdragProc y el usuario selecciona una operación, el toolkit inicializa operations al AND bit a bit de la operación correspondiente y el valor del recurso XmNdragOperations del DragContext. Si el conjunto resultante de operaciones está vacío, el toolkit inicializa operations a XmDROP_NOOP.
dropSiteStatus
Indica si un sitio de soltado es válido o no.
Si el toolkit acaba de llamar a un XmNdragProc de un DropSite, el toolkit inicializa dropSiteStatus al valor del miembro dropSiteStatus de la XmDragProcCallbackStruct en el momento en que el XmNdragProc del DropSite devuelve.
Si el toolkit no ha llamado a un XmNdragProc, inicializa dropSiteStatus de la siguiente manera: el toolkit inicializa dropSiteStatus a XmNO_DROP_SITE si el puntero está sobre un sitio de soltado inactivo o no está sobre un sitio de soltado. El toolkit inicializa dropSiteStatus a XmDROP_SITE_VALID si todas las siguientes cond

Las siguientes condiciones se cumplen:

•
El puntero está sobre un sitio de destino activo.
•
Los XmNexportTargets del DragContext y los XmNimportTargets del DropSite son compatibles.
•
El valor inicial del miembro operation no es XmDROP_NOOP.
De lo contrario, el toolkit inicializa dropSiteStatus a XmDROP_SITE_INVALID.

Se pasa un puntero a la siguiente estructura para la devolución de llamada XmNdropFinishCallback:

typedef struct
{
        int reason;
        XEvent *event;
        Time timeStamp;
        unsigned char operation;
        unsigned char operations;
        unsigned char dropSiteStatus;
        unsigned char dropAction;
        unsigned char completionStatus;
}XmDropFinishCallbackStruct, *XmDropFinishCallback;
reason
Indica por qué se invocó la devolución de llamada.
event
Punta al XEvent que activó la devolución de llamada.
timeStamp
Especifica el momento en que se completó la operación de arrastrar y soltar.
operation
Identifica una operación.
Si el puntero está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar, el toolkit inicializa operation con el valor del miembro operation de la XmDropProcCallbackStruct en el momento en que retorna el XmNdropProc del DropSite.
Si el puntero no está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar, el toolkit inicializa operation seleccionando una operación del valor inicial del miembro operations. El toolkit busca primero en este conjunto XmDROP_MOVE, luego XmDROP_COPY, luego XmDROP_LINK, y inicializa operation con la primera operación que encuentra en el conjunto. Si no encuentra ninguna de estas operaciones en el conjunto, inicializa operation a XmDROP_NOOP.
operations
Indica el conjunto de operaciones admitidas para los datos de origen.
Si el puntero está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar, el toolkit inicializa operations con el AND bit a bit de los XmNdropOperations del DropSite y el valor del miembro operations de la XmDropProcCallbackStruct en el momento en que retorna el XmNdropProc del DropSite. Si el conjunto resultante de operaciones está vacío, el toolkit inicializa operations a XmDROP_NOOP.
Si el puntero no está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar y si el usuario no selecciona una operación (presionando una tecla modificadora), el toolkit inicializa operations con el valor del recurso XmNdragOperations del DragContext.
Si el puntero no está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar y si el usuario selecciona una operación, el toolkit inicializa operations con el AND bit a bit de la operación correspondiente y el valor del recurso XmNdragOperations del DragContext. Si el conjunto resultante de operaciones está vacío, el toolkit inicializa operations a XmDROP_NOOP.
dropSiteStatus
Indica si un sitio de destino es válido o no.
Si el puntero está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar, el toolkit inicializa dropSiteStatus con el valor del miembro dropSiteStatus de la XmDropProcCallbackStruct en el momento en que retorna el XmNdropProc del DropSite.
Si el puntero no está sobre un sitio de destino activo cuando comienza la operación de arrastrar y soltar, el toolkit inicializa dropSiteStatus a XmNO_DROP_SITE.
dropAction
Identifica la acción de arrastrar y soltar. Los valores son XmDROP, XmDROP_CANCEL, XmDROP_HELP y XmDROP_INTERRUPT. El valor XmDROP_INTERRUPT no es compatible actualmente; si se especifica, se interpretaría como XmDROP_CANCEL.
completionStatus
Un miembro de entrada/salida que indica el estado de la acción de arrastrar y soltar. Después de que ha retornado el último procedimiento de devolución de llamada, el valor final de este miembro determina qué efectos de transición visual se aplicarán. Hay dos valores:
XmDROP_SUCCESS
La operación de arrastrar y soltar fue exitosa.
XmDROP_FAILURE
La operación de arrastrar y soltar no fue exitosa.

NOMBRE

XmDragContext - Un widget de contexto de arrastre para la transferencia de datos de arrastre.

SINOPSIS

#include <Xm/DragC.h>

DESCRIPCIÓN

El widget XmDragContext proporciona la funcionalidad para realizar operaciones de arrastrar y soltar. No es un widget visible, sino que se utiliza para gestionar el estado y los eventos asociados con la transferencia de datos de arrastre entre aplicaciones.

La siguiente tabla enumera las acciones que se pueden asociar con eventos de teclado y ratón. Estas acciones se especifican utilizando la sintaxis de la tabla de traducción de eventos de clave estándar X. Este formato es el utilizado por Motif para especificar las acciones del widget correspondientes a una clave dada. Una breve descripción general del formato se proporciona en VirtualBindings(3). Para una descripción completa del formato, consulte la Documentación de Intrínsecos del Kit de Herramientas X.

Rutinas de Acción

Las rutinas de acción de XmDragContext son:

CancelDrag():
Cancela la operación de arrastre y libera el contexto de arrastre asociado.
DragKey(String)
Si el valor de String es Left, Right, Up o Down, esta acción mueve el objeto arrastrado a la ubicación correspondiente. Cualquier otro valor de String se ignora.
DragMotion():
Arrastra los datos seleccionados mientras se mueve el puntero.
FinishDrag():
Finaliza la operación de arrastre e inicia la operación de soltar.
HelpDrag():
Inicia una operación de soltar condicional que permite al receptor proporcionar información de ayuda al usuario. El usuario puede cancelar o continuar la operación de soltar en respuesta a esta información.

Vinculaciones Virtuales

Las vinculaciones para teclas virtuales son específicas del proveedor. Para obtener información sobre las vinculaciones de botones y teclas virtuales, consulte VirtualBindings(3).
