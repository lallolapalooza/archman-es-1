NOMBRE

XmArrowButton — La clase del widget ArrowButton

SINOPSIS

#include <Xm/ArrowB.h>

DESCRIPCIÓN

ArrowButton consiste en una flecha direccional rodeada por una sombra de borde. Cuando se selecciona, la sombra cambia para dar la apariencia de que el ArrowButton ha sido presionado. Cuando el ArrowButton no está seleccionado, la sombra vuelve a su estado original para dar la apariencia de que el ArrowButton está liberado, o hacia afuera.

ArrowButton posee el rasgo XmQTactivatable.

Clases

ArrowButton hereda comportamiento, recursos y rasgos de las clases Core y XmPrimitive.

El puntero de clase es xmArrowButtonWidgetClass.

El nombre de la clase es XmArrowButton.

NAME

XmArrowButton — a widget that provides a widget with an arrow that can be pressed.

SYNOPSIS

#include <Xm/ArrowB.h>

Gadget:

XmArrowButton
WidgetClass = xmArrowButtonGadgetClass

Managed Widget:

XmArrowButton
WidgetClass = xmArrowButtonWidgetClass

DESCRIPTION

The XmArrowButton widget is a primitive component that displays an arrow that can be pressed. The arrow can point up, down, left, or right. The widget's appearance is determined by its background color, border, and shadow.

A typical use is in a dialog box to allow the user to navigate between items or to perform an action.

XmArrowButton includes the XmArrowButtonGadget. The gadget is a component of the XmBulletinBoard widget and other manager widgets. A manager widget can contain an XmArrowButtonGadget if the manager widget's widget class is derived from xmBulletinBoardWidgetClass. XmArrowButtonGadget provides the same functionality as XmArrowButton.

WIDGETS

The XmArrowButton widget and its gadget counterpart.

CHOOSING

When choosing between XmArrowButton and XmArrowButtonGadget, consider the following:

Widget
Use XmArrowButton when you need a stand-alone widget.
Gadget
Use XmArrowButtonGadget when you need an arrow button within a manager widget such as XmBulletinBoard or XmForm.

The XmArrowButton widget's resources are the same as the XmArrowButtonGadget's resources.

CALLBACKS

The XmArrowButton widget supports the following callbacks:

XmNactivateCallback
Invoked when the button is activated (pressed and released).
XmNarmCallback
Invoked when the button is armed (pressed).
XmNdisarmCallback
Invoked when the button is disarmed (released).
XmNhelpCallback
Invoked when the Help key is pressed.

FEATURE SET

The XmArrowButton widget supports the following features:

Arrow Direction
The arrow can point up, down, left, or right.
Multi-click
The widget supports multi-click behavior, allowing multiple activations with a single press and hold.
Visual Feedback
The widget provides visual feedback when the button is armed and activated.

RELATIONSHIP TO SUPERCLASS

The XmArrowButton widget is a subclass of XmManager. XmManager is a subclass of XmPrimitive. XmPrimitive is a subclass of XmManager. XmManager is a subclass of Core.

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        int click_count;
} XmArrowButtonCallbackStruct;
reason
Indicates why the callback was invoked.
event
Points to the XEvent that triggered the callback.
click_count
This value is valid only when the reason is XmCR_ACTIVATE. It contains the number of clicks in the last multiclick sequence if the XmNmultiClick resource is set to XmMULTICLICK_KEEP; otherwise it contains 1. The activate callback is invoked for each click if XmNmultiClick is set to XmMULTICLICK_KEEP.

Action Routines

The XmArrowButton action routines are

Activate():
Draws the shadow in the unselected state. If the pointer is within the ArrowButton, calls the callbacks for XmNactivateCallback.
Arm():
Draws the shadow in the selected state and calls the callbacks for XmNarmCallback.
ArmAndActivate():
Draws the shadow in the selected state and calls the callbacks for XmNarmCallback. Arranges for the shadow to be drawn in the unselected state and the callbacks for XmNactivateCallback and XmNdisarmCallback to be called, either immediately or at a later time.

NAME

XmArrowButton - An ArrowButton widget

SYNOPSIS

#include <Xm/ArrowB.h>

DESCRIPTION

The XmArrowButton widget is a simple button that displays an arrow. Clicking the arrow activates the button, invoking callbacks. The arrow can point up, down, left, or right.

CALLBACKS

The XmArrowButton widget defines the following callback lists:

XmNactivateCallback
Callback invoked when the button is activated (e.g., by releasing the mouse button over it).
XmNarmCallback
Callback invoked when the button is armed (e.g., by pressing the mouse button over it).
XmNdisarmCallback
Callback invoked when the button is disarmed (e.g., by releasing the mouse button over it, but not activating it).
XmNhelpCallback
Callback invoked when the help key is pressed or the help menu is selected.

ACTIONS

The XmArrowButton widget has the following actions:

ButtonTakeFocus():
Causes the ArrowButton to take keyboard focus when Ctrl<Btn1Down> is pressed, without activating the widget.
Disarm():
Draws the shadow in the unselected state and calls the callbacks for XmNdisarmCallback.
Help():
Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
MultiActivate():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP, this action increments click_count in the callback structure and draws the shadow in the unselected state. If the pointer is within the ArrowButton, this action calls the callbacks for XmNactivateCallback and XmNdisarmCallback.
MultiArm():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing. If XmNmultiClick is XmMULTICLICK_KEEP, this action draws the shadow in the selected state and calls the callbacks for XmNarmCallback.

Additional Behavior

This widget has the following additional behavior:

<EnterWindow>:
Draws the ArrowButton shadow in its selected state if the pointer leaves and re-enters the window while <Btn1> is pressed.
<LeaveWindow>:
Draws the ArrowButton shadow in its unselected state if the pointer leaves the window while <Btn1> is pressed.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3).
