XmClipboardStartCopy(3)

Licencias: LGPL-2.1-or-later

XmClipboardStartCopy(llamada a librería) XmClipboardStartCopy(llamada a librería)

NOMBRE

XmClipboardStartCopy — Función del portapapeles que configura una estructura de almacenamiento y datos

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardStartCopy (display, window, clip_label,
        timestamp, widget, callback, item_id)
        Display * display;
        Window  window;
        XmString        clip_label;
        Time    timestamp;
        Widget  widget;
        XmCutPasteProc  callback;
        long    * item_id;
(void)

DESCRIPCIÓN

XmClipboardStartCopy configura el almacenamiento y las estructuras de datos para recibir datos del portapapeles. Una aplicación llama a esta función durante una operación de cortar o copiar. El elemento de datos que estas estructuras reciben se convierte entonces en el siguiente elemento de datos en el portapapeles.

Copiar una gran cantidad de datos al portapapeles puede llevar mucho tiempo. Es posible que, una vez copiados los datos, ninguna aplicación los solicite jamás. El Toolkit Motif proporciona un mecanismo para que una aplicación no necesite pasar realmente datos al portapapeles hasta que los datos hayan sido solicitados por alguna aplicación.

En su lugar, la aplicación pasa información de formato y longitud en XmClipboardCopy a las funciones del portapapeles, junto con un ID de widget y la dirección de una función de devolución de llamada que se pasa en XmClipboardStartCopy. El ID del widget es necesario para las comunicaciones entre las funciones del portapapeles en la aplicación que posee los datos y las funciones del portapapeles en la aplicación que solicita los datos.

Las funciones de devolución de llamada son responsables de copiar los datos reales al portapapeles a través de XmClipboardCopyByName. La función de devolución de llamada también se llama si el elemento de datos se elimina del portapapeles y los datos reales ya no son necesarios.

display
Especifica un puntero a la estructura Display que fue devuelta en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de la ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de la ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llama.
clip_label
Especifica la etiqueta que se asociará con el elemento de datos. Este argumento se utiliza para identificar el elemento de datos, como en un visor de portapapeles. Un ejemplo de etiqueta es el nombre de la aplicación que coloca los datos en el portapapeles.
timestamp
Especifica la hora del evento que activó la copia. Se debe proporcionar una marca de tiempo válida; no es suficiente usar CurrentTime.
widget
Especifica el ID del widget que recibe mensajes solicitando datos pasados anteriormente por nombre. Este argumento debe estar presente para poder pasar datos por nombre. Se puede utilizar cualquier ID de widget válido en su aplicación para este propósito y todo el manejo de mensajes es gestionado por las funciones de cortar y pegar.
callback
Especifica la dirección de la función de devolución de llamada que se llama cuando el portapapeles necesita datos que se pasaron originalmente por nombre. Esta es también la devolución de llamada para recibir el mensaje delete para los elementos que se pasaron originalmente por nombre. Este argumento debe estar presente para poder pasar datos por nombre.
item_id
Especifica el número asignado a este elemento de datos. La aplicación utiliza este número en las llamadas a XmClipboardCopy, XmClipboardEndCopy y XmClipboardCancelCopy.

Para más información sobre cómo pasar datos por nombre, ver XmClipboardCopy(3) y XmClipboardCopyByName(3).

Los argumentos widget y callback deben estar presentes para poder pasar datos por nombre. El formato de la devolución de llamada es el siguiente:

void (*callback) (widget, data_id, private, reason)
        Widget  widget;
        long    *data_id;
        long    *private;
        int     *reason;
(void)
widget
Especifica el ID del widget pasado a esta función.
data_id
Especifica el número de identificación devuelto por XmClipboardCopy, que identifica los datos pasados por nombre.
private
Especifica la información privada pasada a XmClipboardCopy.
reason
Especifica la razón. XmCR_CLIPBOARD_DATA_DELETE o XmCR_CLIPBOARD_DATA_REQUEST son los valores posibles.

RETORNO

XmClipboardSuccess
La función fue exitosa.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede continuar llamando a la función nuevamente con los mismos parámetros hasta que el bloqueo desaparezca. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o abandonar la operación.
