NOMBRE

XmFontListAdd — Una función de lista de fuentes que crea una nueva lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
XmFontList XmFontListAdd(
XmFontList oldlist,
XFontStruct *font,
XmStringCharSet charset);

DESCRIPCIÓN

XmFontListAdd crea una nueva lista de fuentes que consiste en el contenido de oldlist y el nuevo elemento de lista de fuentes que se está agregando. Esta función libera oldlist después de extraer la información requerida; por lo tanto, no haga referencia a oldlist a partir de entonces.

NOTA: Esta función es obsoleta y existe por compatibilidad con versiones anteriores. Ha sido reemplazada por XmFontListAppendEntry.

oldlist
Especifica un puntero a la lista de fuentes a la que se agregará una entrada.
font
Especifica un puntero a una estructura de fuente para la cual se genera la nueva lista de fuentes. Esta es la estructura devuelta por la función XLib XLoadQueryFont.
charset
Especifica el identificador del conjunto de caracteres para la fuente. Puede ser XmSTRING_DEFAULT_CHARSET, pero este valor no cumple con las normas AES y puede ser eliminado en futuras versiones de Motif. Si el valor es XmSTRING_DEFAULT_CHARSET, la rutina deriva el conjunto de caracteres del entorno lingüístico actual.

RETORNO

Devuelve NULL si oldlist es NULL; devuelve oldlist si font o charset es NULL; de lo contrario, devuelve una nueva lista de fuentes.

RELACIONADO

XmFontList(3) y XmFontListAppendEntry(3).
