NOMBRE

Attribute - un atributo único

API

nuevo ( clave, valor, prefijo )

Crea un nuevo nodo de atributo.

obtenerNombre

Devuelve la clave del atributo

obtenerNombreLocal

Igual que obtenerNombre anterior, pero sin información de namespace

obtenerValorNodo / obtenerDatos

Devuelve el valor

establecerValorNodo

Establece el valor del nodo de atributo.

obtenerPrefijo

Devuelve el prefijo

obtenerNamespace

Devuelve el namespace.

aCadena

Genera clave="valor", codificado correctamente.
