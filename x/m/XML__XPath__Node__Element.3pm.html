XML::XPath::Node::Element(3) Documentación de Perl contribuida por el usuario XML::XPath::Node::Element(3)

NOMBRE

Element - un <elemento>

API

new ( nombre, prefijo )

Crea un nuevo nodo Element con el nombre "nombre" y el prefijo "prefijo". El nombre será "prefijo:local" si el prefijo está definido. Sé que suena raro, ¡pero funciona ;-)

getName

Devuelve el nombre (incluyendo "prefijo:" si está definido) de este elemento.

getLocalName

Devuelve solo la parte local del nombre (la parte después de "prefijo:").

getChildNodes

Devuelve los hijos de este elemento. En contexto de lista devuelve una lista. En contexto de escalar devuelve una referencia a un array.

getChildNode ( pos )

Devuelve el hijo en la posición pos.

appendChild ( childnode )

Añade el nodo hijo a la lista de nodos hijos actuales.

removeChild ( childnode )

Elimina el nodo hijo proporcionado de la lista de nodos hijos actuales.

getAttribute ( name )

Devuelve el nodo atributo con la clave nombre.

getAttributes / getAttributeNodes

Devuelve los nodos de atributo. En contexto de lista devuelve una lista. En contexto de escalar devuelve una referencia a un array.

appendAttribute ( attrib_node)

Añade el nodo atributo a la lista de atributos (XML::XPath almacena los atributos en orden).

getNamespace ( prefix )

Devuelve el nodo de namespace por el prefijo dado

getNamespaces / getNamespaceNodes

Devuelve los nodos de namespace. En contexto de lista devuelve una lista. En contexto de escalar devuelve una referencia a un array.

appendNamespace ( ns_node )

Añade el nodo de namespace a la lista de namespaces.

getPrefix

Devuelve el prefijo de este elemento

getExpandedName

Devuelve el nombre expandido de este elemento (aún no implementado correctamente).

string_value

Para los elementos, el valor_cadena es la concatenación de todos los valores_cadena de todos los descendientes de texto del nodo elemento en orden del documento.

toString ( [ norecurse ] )

Muestra (y todos los hijos) el nodo como una cadena. No procesa los hijos si la opción sinRecursion es un valor verdadero.
