NOMBRE

XmTextReplace — Función de Texto que reemplaza parte de una cadena de texto

SINOPSIS

#include <Xm/Text.h>
void XmTextReplace(
Widget widget,
XmTextPosition from_pos,
XmTextPosition to_pos,
char * value);

DESCRIPCIÓN

XmTextReplace reemplaza parte de la cadena de texto en el widget de Texto. Las posiciones de los caracteres comienzan en 0 (cero) y se numeran secuencialmente desde el principio del texto.

Un ejemplo de reemplazo de texto sería reemplazar el segundo y tercer carácter de la cadena de texto. Para lograr esto, el parámetro from_pos debe ser 1 y to_pos debe ser 3. Para insertar una cadena después del cuarto carácter, ambos parámetros, from_pos y to_pos, deben ser 4.

Esta rutina llama a las devoluciones de llamada de XmNvalueChangedCallback y de verificación del widget, ya sea XmNmodifyVerifyCallback o XmNmodifyVerifyCallbackWcs, o ambas. Si se registran ambas listas de devoluciones de llamada de verificación, los procedimientos de la lista XmNmodifyVerifyCallback se ejecutan primero y los datos resultantes se pasan a las devoluciones de llamada XmNmodifyVerifyCallbackWcs. La devolución de llamada XmNmotionVerifyCallback se genera si to_pos es menor o igual a la posición del cursor y la longitud de value no es la misma que la longitud del texto que se está reemplazando, o si la posición del cursor está entre from_pos y to_pos, y la distancia desde la posición del cursor hasta from_pos es mayor que la longitud de value.

widget
Especifica el ID del widget de Texto
from_pos
Especifica la posición de inicio del texto a reemplazar
to_pos
Especifica la posición final del texto a reemplazar
value
Especifica el valor de la cadena de caracteres a añadir al widget de texto

Para una definición completa de Texto y sus recursos asociados, consulte XmText(3).

RELACIONADO

XmText(3) y XmTextReplaceWcs(3).
