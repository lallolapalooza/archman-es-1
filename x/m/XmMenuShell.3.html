NOMBRE

XmMenuShell — La clase de widget MenuShell

SINOPSIS

#include <Xm/MenuShell.h>

DESCRIPCIÓN

El widget MenuShell es un widget OverrideShell personalizado. Un widget OverrideShell omite mwm al mostrarse. Está diseñado específicamente para contener paneles de menú emergentes (Popup) o desplegables (Pulldown).

La mayoría de los programadores de aplicaciones nunca se encuentran con este widget si utilizan las funciones de conveniencia del sistema de menús, XmCreatePopupMenu o XmCreatePulldownMenu, para crear un panel de menú emergente o desplegable. Las funciones de conveniencia crean automáticamente un widget MenuShell como padre del panel de menú. Sin embargo, si no se utilizan las funciones de conveniencia, el programador de la aplicación debe crear el MenuShell requerido. En este caso, es importante tener en cuenta que el padre del MenuShell depende del tipo de sistema de menú que se esté construyendo.

•
Si el MenuShell es para el panel de menú emergente de nivel superior, el padre del MenuShell debe ser el widget desde el cual se despliega el panel de menú emergente.
•
Si el MenuShell es para un panel de menú que se despliega desde un menú emergente o desde otro panel de menú desplegable, el padre del MenuShell debe ser el menú emergente o el panel de menú desplegable.
•
Si el MenuShell es para un panel de menú que se despliega desde una barra de menú (MenuBar), el padre del MenuShell debe ser la barra de menú.
•
Si el MenuShell es para un panel de menú desplegable en un OptionMenu, el padre del MenuShell debe ser el padre del OptionMenu.

Establecer XmNheight, XmNwidth, o XmNborderWidth para un MenuShell o su hijo establece ese recurso al mismo valor en ambos, el padre y el hijo. Una aplicación siempre debe especificar estos recursos para el hijo, no para el padre.

Para el hijo gestionado de un MenuShell, independientemente del valor de XmNallowShellResize del shell, establecer XmNx o XmNy establece el recurso correspondiente del padre pero no cambia la posición del hijo en relación con el padre. XtGetValues para XmNx o XmNy del hijo devuelve el valor del recurso correspondiente en el padre. Las coordenadas x e y de la esquina exterior superior izquierda del hijo en relación con la esquina interior superior izquierda del padre son ambas 0 (cero) menos el valor de XmNborderWidth.

MenuShell utiliza el trait XmQTmenuSystem y posee el trait XmQTspecifyRenderTable.

Clases

MenuShell hereda comportamiento, recursos y traits de Core, Composite, Shell, y OverrideShell.

El puntero de clase es xmMenuShellWidgetClass.

El nombre de la clase es XmMenuShell.

RESOURCES

XmNdefaultFontList
Especifica una lista de fuentes predeterminada para los descendientes de MenuShell. Este recurso es obsoleto y existe por compatibilidad con versiones anteriores. Ha sido reemplazado por XmNbuttonFontList y XmNlabelFontList.
XmNlabelFontList
Especifica la lista de fuentes utilizada para los descendientes de etiquetas. Ver el recurso XmNlabelRenderTable.
XmNlabelRenderTable
Especifica la tabla de renderizado utilizada para los descendientes de etiquetas de MenuShell (Etiquetas y LabelGadgets). Si este valor es NULL en la inicialización y si el valor de XmNdefaultFontList no es NULL, XmNlabelRenderTable se inicializa con el valor de XmNdefaultFontList. Si el valor de XmNdefaultFontList es NULL, se busca en la jerarquía padre del widget un ancestro que posea el rasgo XmQTspecifyRenderTable. Si se encuentra dicho ancestro, XmNlabelRenderTable se inicializa con el valor XmLABEL_RENDER_TABLE del widget ancestro. Si no se encuentra ningún ancestro, el valor predeterminado depende de la implementación. Consultar XmRenderTable(3) para más información sobre la creación y estructura de una tabla de renderizado.
XmNlayoutDirection
Especifica la dirección en la que se distribuirán los subwidgets, hijos de un widget, u otros componentes visuales. Esta política se aplicará como política de distribución predeterminada para todos los descendientes de este MenuShell.
XmNanimate
Controla si los menús se mostrarán de forma animada.

Nombre

XmMenuShell - un shell de menú de nivel superior

Sinopsis

Con las bibliotecas de Motif:

     #include <Xm/MenuShell.h>

Con las bibliotecas de X Toolkit:

     #include <X11/Shell.h>

Descripción

El widget XmMenuShell es un widget de shell que se utiliza para implementar menús de nivel superior en Motif. Debe ser un widget hijo directo de un Shell de nivel superior (por ejemplo, un widget TopLevelShell o ApplicationShell) y solo puede contener un widget hijo. Este widget hijo suele ser un XmRowColumn con su política de gestión establecida en XmMENU_POSTING o XmWORK_AREA, y su estilo establecido en XmSTRING_MENU o Xm செயின்.

La principal función de XmMenuShell es proporcionar el entorno necesario para mostrar y gestionar menús de nivel superior. Maneja la interacción del ratón y el teclado para la activación y desactivación del menú, y gestiona la entrada del ratón fuera del menú para desactivarlo.

Los widgets XmMenuShell heredan de Shell y OverrideShell. Proporcionan los siguientes recursos:

Rutinas de Acción

Las rutinas de acción de XmMenuShell son:

ClearTraversal():
Inhabilita la traversal (recorrido) del teclado para el menú, habilita la traversal del ratón y despublica cualquier menú publicado por este menú.
MenuShellPopdownDone():
Despublica la jerarquía de menús y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco al widget que tenía el foco antes de entrar en el sistema de menús.
MenuShellPopdownOne():
En un Menú de Desplegable de nivel superior desde una Barra de Menús, esta acción despublica el menú, desarma el Botón de Cascada de la Barra de Menús y la Barra de Menús, y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de entrar en la Barra de Menús. En otros Menús Desplegables, esta acción despublica el menú.
En un Menú Emergente, esta acción despublica el menú y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget desde el cual se publicó el menú.

Bindings Virtuales
