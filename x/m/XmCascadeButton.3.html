NOMBRE

XmCascadeButton — La clase de widget CascadeButton

SINOPSIS

#include <Xm/CascadeB.h>

DESCRIPCIÓN

CascadeButton enlaza dos paneles de menú o una Barra de Menú a un panel de menú.

Se utiliza en sistemas de menús y debe tener un padre RowColumn con su recurso XmNrowColumnType establecido a XmMENU_BAR, XmMENU_POPUP o XmMENU_PULLDOWN.

Es el único widget que puede tener un panel de menú desplegable (Pulldown) adjunto como submenú. El submenú se muestra cuando este widget se activa dentro de una Barra de Menú (MenuBar), un Menú Emergente (PopupMenu) o un Menú Desplegable (PulldownMenu). Sus elementos visuales pueden incluir una etiqueta o un pixmap y un indicador de cascada cuando se encuentra en un panel de menú emergente o desplegable; o puede incluir solo una etiqueta o un pixmap cuando se encuentra en una Barra de Menú. El posicionamiento del Menú Desplegable con respecto al CascadeButton depende del recurso XmNlayoutDirection del MenuShell.

El comportamiento predeterminado asociado con un CascadeButton depende del tipo de sistema de menús en el que reside. Por defecto, BSelect controla el comportamiento del CascadeButton. Además, BMenu controla el comportamiento del CascadeButton si reside en un sistema PopupMenu. El botón del ratón real utilizado se determina por su padre RowColumn. BMenu también realiza las acciones BSelect en todos los tipos de sistemas de menús.

Los elementos visuales de un CascadeButton difieren de la mayoría de los demás gadgets de botón. Cuando el botón se arma, sus elementos visuales cambian de un aspecto 2D a uno 3D, y muestra el submenú que se le ha adjuntado. Si no hay ningún submenú adjunto, simplemente cambia sus elementos visuales.

Cuando un CascadeButton dentro de un panel de menú desplegable o emergente se arma como resultado de que el usuario mueva el puntero del ratón hacia el widget, no muestra inmediatamente su submenú. En su lugar, espera un corto período de tiempo para ver si el armado fue temporal (es decir, el usuario simplemente estaba pasando por el widget) o si el usuario realmente quería que se mostrara el submenú. Este retraso es configurable usando XmNmappingDelay.

CascadeButton proporciona un único mecanismo para activar el widget desde el teclado. Este mecanismo se conoce como mnemotecnia de teclado. Si se ha especificado una mnemotecnia para el widget, el usuario puede activar el CascadeButton simplemente escribiendo la mnemotecnia mientras el CascadeButton es visible. Si el CascadeButton está en una Barra de Menú y la Barra de Menú no tiene el foco, se debe presionar el modificador MAlt junto con la mnemotecnia. Las mnemotecnias se utilizan típicamente para interactuar con un menú utilizando la interfaz del teclado.

Si el Cascadebutton está en un panel de menú desplegable o emergente y hay un submenú adjunto, los recursos XmNmarginBottom, XmNmarginLeft, XmNmarginRight y XmNmarginTop pueden ampliarse para acomodar XmNcascadePixmap. XmNmarginWidth tiene un valor predeterminado de 6 si este recurso está en una Barra de Menú; de lo contrario, toma el valor predeterminado de Label, que es 2.

CascadeButton utiliza los rasgos XmQTmenuSystem y XmQTspecifyRenderTable.

CLASES

CascadeButton hereda comportamiento, recursos y rasgos de las clases Core, XmPrimitive y XmLabel.

El puntero de clase es xmCascadeButtonWidgetClass.

El nombre de la clase es XmCascadeButton.

Especifica el ID del widget para el panel de menú desplegable que se asociará con este CascadeButton. El panel de menú especificado se muestra cuando el CascadeButton se activa. CascadeButton(3)

NAME

CascadeButton — a button that cascades a menu

SYNOPSIS

WidgetCascadeButton(w)

All attribute strings are for the Convenience Routine XmCascadeButton(3).

#include <Xm/CascadeB.h>
Widget XmCreateCascadeButton(
        Widget parent,
        char *name,
        ArgList arglist,
        Cardinal argcount);
Widget XmCreateCascadeToggleButton(
        Widget parent,
        char *name,
        ArgList arglist,
        Cardinal argcount);

DESCRIPTION

The XmCascadeButton widget is a button that, when selected, causes a menu pane to be displayed. The menu pane is associated with the cascade button through the XmNsubMenuId resource.

The cascade button is a primitive component. It has no children of its own. A cascade button can be used to create menu bars, pull-down menus, and pop-up menus.

The cascade button itself consists of a label and a cascade widget. The label can be specified using either the XmLabel(3) resources or the XmBulletinB(3) resources.

The cascade widget itself is responsible for displaying the cascade indicator (a small triangle) if the label is not a pixmap. The cascade indicator points in the direction of the associated menu pane. This is typically to the right.

The widget can be created using either XmCreateCascadeButton or XmCreateCascadeToggleButton. The cascade toggle button is identical to the cascade button except that it is sensitive to the XmNarmCallback and XmNdisarmCallback callbacks.

WIDGET TREE

The widget tree for the cascade button is:

XmCascadeButton : XmLabel : XmPrimitive : core

XmCascadeButton(3)

NAME

XmCascadeButton — A cascade button widget

SYNOPSIS

#include <Xm/CascadeB.h>

DESCRIPTION

The XmCascadeButton widget is a button that, when selected, posts a pulldown menu or popup menu. It is typically used in a menubar to cascade to a pulldown menu, or as an item in a pulldown menu to cascade to another pulldown menu.

The XmCascadeButton widget inherits from XmLabel.

Callbacks

The XmCascadeButton widget provides the following callbacks:

XmNactivateCallback
Called when the widget is activated. This typically happens when the CascadeButton does not have a submenu attached.
XmNcascadingCallback
Called when a submenu is about to be posted.
XmNhelpCallback
Called when the widget is supposed to bring up help.

Actions

The XmCascadeButton widget has the following actions:

<EnterWindow>:
CheckArm()
<LeaveWindow>:
CheckDisarm()
<Btn2Down>:
ProcessDrag()
c<BtnDown>:
MenuButtonTakeFocus()
c<BtnUp>:
MenuButtonTakeFocusUp()
∼c<BtnDown>:
StartDrag()
∼c<BtnUp>:
DoSelect()
:<Key><osfSelect>:
KeySelect()
:<Key><osfActivate>:
KeySelect()
:<Key><osfHelp>:

:<Key><osfCancel>:

∼s<Key>Return:

Action Routines

The XmCascadeButton action routines are

CleanupMenuBar():
In a MenuBar, disarms the CascadeButton and the menu and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the menu was entered.
In a toplevel Pulldown MenuPane from a MenuBar, unposts the menu, disarms the MenuBar CascadeButton and the MenuBar, and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the MenuBar was entered. In other Pulldown MenuPanes, unposts the menu.
In a Popup MenuPane, unposts the menu and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget from which the menu was posted.
DoSelect():
Calls the callbacks in XmNcascadingCallback, posts the submenu attached to the CascadeButton and enables keyboard traversal within the menu. If the CascadeButton does not have a submenu attached, this action calls the callbacks in XmNactivateCallback, activates the CascadeButton, and unposts all posted menus in the cascade.
Help():
Unposts all menus in the menu hierarchy and, when the shell's keyboard focus policy is XmEXPLICIT, restores keyboard focus to the widget that had the focus before the menu system was entered. Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
KeySelect():
Calls the callbacks in XmNcascadingCallback, and posts the submenu attached to the CascadeButton if keyboard traversal is enabled in the menu. If the CascadeButton does not have a submenu attached, this action calls the callbacks in XmNactivateCallback, activates the CascadeButton, and unposts all posted menus in the cascade.
MenuBarSelect():
Unposts any menus posted by the parent menu. Arms both the CascadeButton and the MenuBar, posts the associated submenu, and enables mouse traversal. If the menu is already active, this event disables keyboard traversal for the menu and returns the menu to mouse traversal mode.
StartDrag():
Arms the CascadeButton, posts the associated submenu, and enables mouse traversal. If the menu is already active, this event disables keyboard traversal for the menu and returns the menu to mouse traversal mode.

Additional Behavior

Posting a submenu calls the XmNcascadingCallback callbacks. This widget has the following additional behavior:

<EnterWindow>:
If keyboard traversal is enabled, does nothing. Otherwise, in a MenuBar that is armed, unposts any MenuPanes associated with another MenuBar entry, arms the CascadeButton, and posts the associated submenu. In other menus, arms the CascadeButton and posts the associated submenu after the delay specified by XmNmappingDelay.
<LeaveWindow>:
If keyboard traversal is enabled does nothing. Otherwise, in a MenuBar that is armed, disarms the CascadeButton if the submenu associated with the CascadeButton is not currently posted or if there is no submenu associated with the CascadeButton.
In other menus, if the pointer moves anywhere except into a submenu associated with the CascadeButton, the CascadeButton is disarmed and its submenu is unposted.
