SOPORTE

Sitios web

Los siguientes sitios web tienen más información sobre este módulo y pueden serle de ayuda. Como siempre, además de esos sitios web, utilice su motor de búsqueda favorito para descubrir más recursos.

  • MetaCPAN

    Un motor de búsqueda CPAN moderno y de código abierto, útil para ver POD en formato HTML.

    https://metacpan.org/release/XML-RSS

  • RT: Rastreador de errores de CPAN

    El sitio web RT (Request Tracker) es el sistema predeterminado de seguimiento de errores/incidencias para CPAN.

    https://rt.cpan.org/Public/Dist/Display.html?Name=XML-RSS

  • CPANTS

    CPANTS es un sitio web que analiza la calidad (métricas de código) de una distribución.

    http://cpants.cpanauthors.org/dist/XML-RSS

  • CPAN Testers

    CPAN Testers es una red de probadores que ejecutan pruebas automatizadas en distribuciones de CPAN cargadas.

    http://www.cpantesters.org/distro/X/XML-RSS

  • Matriz de CPAN Testers

    La Matriz de CPAN Testers es un sitio web que proporciona una visión general visual de los resultados de las pruebas de una distribución en varios Perl/plataformas.

    http://matrix.cpantesters.org/?dist=XML-RSS

  • Dependencias de CPAN Testers

    Dependencias de CPAN Testers es un sitio web que muestra un gráfico de los resultados de las pruebas de todas las dependencias de una distribución.

    http://deps.cpantesters.org/?module=XML::RSS

Errores / Solicitudes de características

Por favor, informe de cualquier error o solicitud de características por correo electrónico a "bug-xml-rss at rt.cpan.org", o a través de la interfaz web en https://rt.cpan.org/Public/Bug/Report.html?Queue=XML-RSS. Será notificado automáticamente de cualquier progreso en la solicitud por el sistema.
