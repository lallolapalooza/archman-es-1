NOMBRE

XmParseTable — Tipo de datos para una tabla de análisis de cadena compuesta

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCION

XmParseTable es el tipo de datos para una matriz de asignaciones de análisis (objetos de tipo XmParseMapping).

Una tabla de análisis es utilizada por algunas rutinas que analizan y desempaquetan cadenas compuestas. La tabla es una lista ordenada de asignaciones de análisis. Una rutina de análisis que utiliza una tabla de análisis escanea el texto de entrada y busca en las asignaciones de análisis, en orden, una que contenga un patrón que coincida con el texto de entrada. La asignación de análisis coincidente suministra una cadena compuesta para que se incluya en la cadena compuesta en construcción.

Una rutina de desempaquetado que utiliza una tabla de análisis busca las asignaciones de análisis, en orden, una que contenga una cadena compuesta que coincida con la cadena compuesta de entrada. La rutina de desempaquetado puede entonces incluir el patrón de texto de la asignación de análisis en el texto de salida en construcción.

RELACIONADO

XmParseMapping(3), XmParseTableFree(3), y XmString(3).
