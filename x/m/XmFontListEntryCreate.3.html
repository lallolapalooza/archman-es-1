XmFontListEntryCreate(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmFontListEntryCreate(llamada de biblioteca) XmFontListEntryCreate(llamada de biblioteca)

NOMBRE

XmFontListEntryCreate — una función de lista de fuentes que crea una entrada de lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
XmFontListEntry XmFontListEntryCreate(
char *tag,
XmFontType type,
XtPointer font);

DESCRIPCIÓN

XmFontListEntryCreate crea una entrada de lista de fuentes que contiene una fuente o un conjunto de fuentes y se identifica mediante una etiqueta.

etiqueta
Especifica una cadena terminada en NULL para la etiqueta de la entrada de la lista de fuentes. La etiqueta puede especificarse como XmFONTLIST_DEFAULT_TAG, que se utiliza para identificar el elemento predeterminado de la lista de fuentes en una lista de fuentes.
tipo
Especifica si el argumento fuente es una estructura de fuente o un conjunto de fuentes. Los valores válidos son XmFONT_IS_FONT y XmFONT_IS_FONTSET.
fuente
Especifica un XFontSet devuelto por XCreateFontSet o un puntero a una XFontStruct devuelta por XLoadQueryFont.

El toolkit no copia la estructura X Font especificada por el argumento fuente. Por lo tanto, un programador de aplicaciones no debe liberar XFontStruct o XFontSet hasta que se hayan liberado todas las listas de fuentes y/o las entradas de fuentes que hagan referencia a ella.

RETORNO

Devuelve una entrada de lista de fuentes. La función asigna espacio para contener la entrada de lista de fuentes devuelta. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmFontListEntryFree.

RELACIONADO

XmFontList(3), XmFontListAppendEntry(3), XmFontListEntryFree(3), XmFontListEntryGetFont(3), XmFontListEntryGetTag(3), XmFontListEntryLoad(3), y XmFontListRemoveEntry(3).
