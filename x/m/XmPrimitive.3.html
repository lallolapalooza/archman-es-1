NOMBRE

XmPrimitive — La clase de widget Primitive

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

Primitive es una clase de widget utilizada como superclase de soporte para otras clases de widget. Maneja el dibujo y resaltado de bordes, la activación y desactivación de traversal, y varias listas de callbacks necesarias para los widgets Primitive. Primitive y todas sus subclases poseen el rasgo XmQTcareParentVisual.

Comportamiento de transferencia de datos

Primitive no tiene procedimientos de conversión o destino de clase de widget. Las subclases y los procedimientos XmNconvertCallback son responsables de cualquier conversión de selecciones. Las subclases y los procedimientos XmNdestinationCallback de las subclases son responsables de cualquier transferencia de datos al widget.

Clases

Primitive hereda comportamiento, recursos y rasgos de Core.

El puntero de clase es xmPrimitiveWidgetClass.

El nombre de la clase es XmPrimitive.

Nuevos recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado puede ser establecido en tiempo de creación (C), establecido usando XtSetValues (S), recuperado usando XtGetValues (G), o no es aplicable (N/A).

Indica que el widget no es un grupo de pestañas.

Indica que el widget es un grupo de pestañas, a menos que el XmNnavigationType de otro widget en la jerarquía sea XmEXCLUSIVE_TAB_GROUP.
XmSTICKY_TAB_GROUP
Indica que el widget es un grupo de pestañas, incluso si el XmNnavigationType de otro widget en la jerarquía es XmEXCLUSIVE_TAB_GROUP.

•
Si la profundidad de la pantalla es solo una.
Por ejemplo, si se crea un widget con el mismo color de sombra superior y de fondo, se genera un pixmap de sombra predeterminado. Dicho pixmap debe eliminarse para que el recurso XmNtopShadowColor tenga efecto.

Permite a la aplicación adjuntar cualquier dato específico necesario al widget. Es un recurso no utilizado internamente.

Valores Predeterminados Dinámicos de Color

Los recursos de color de primer plano, fondo, sombra superior, sombra inferior y resaltado se establecen de forma predeterminada dinámicamente. Si no se especifican datos de color, los colores se generan automáticamente. En un sistema de un solo plano, se genera un esquema de color en blanco y negro. De lo contrario, se generan cuatro colores que muestran el sombreado correcto para las visualizaciones 3D. Si el fondo es el único color especificado para un widget, los colores de la sombra superior y la sombra inferior se generan para dar la apariencia 3D. Los colores de primer plano y resaltado se generan para proporcionar suficiente contraste con el color de fondo.

Los colores solo se generan en la creación. Restablecer el fondo a través de XtSetValues no regenera los otros colores. XmChangeColor se puede utilizar para recalcular todos los colores asociados basándose en un nuevo color de fondo.

Información de Callback

Se pasa un puntero a la siguiente estructura a cada llamada para XmNhelpCallback:

typedef struct
{
        int reason;
        XEvent * event;
} XmAnyCallbackStruct;
reason
Indica por qué se invocó la llamada. Para esta llamada, reason se establece en XmCR_HELP.
event
Punta al XEvent que activó la llamada.

Se pasa un puntero a la siguiente estructura de llamada a los procedimientos XmNconvertCallback:

typedef struct
{
        int reason;
        XEvent *event;
        Atom selection;
        Atom target;
        XtPointer source_data;
        XtPointer location_data;
        int flags;
        XtPointer parm;
        int parm_format;
        unsigned long parm_length;
        Atom parm_type;
        int status;
        XtPointer value;
        Atom type;
        int format;
        unsigned long length;
} XmConvertCallbackStruct;
reason
Indica por qué se invocó la llamada.
event
Punta al XEvent que activó la llamada. Puede ser NULL.
selection
Indica la selección para la que se solicita la conversión. Los valores posibles son CLIPBOARD, PRIMARY, SECONDARY y _MOTIF_DROP.
target
Indica el objetivo de la conversión.
source_data
Contiene información sobre el origen de la selección. Cuando la selección es _MOTIF_DROP, source_data es el DragContext. De lo contrario, es NULL.
location_data
Contiene información sobre la ubicación de los datos que se van a convertir. Si el valor es NULL, los datos a transferir consisten en la selección actual del widget. De lo contrario, el tipo y la interpretación del valor son específicos de la clase del widget.
flags
Indica el estado de la conversión. Los siguientes son los valores posibles:
XmCONVERTING_NONE
Este flag no se utiliza actualmente.
XmCONVERTING_PARTIAL
El widget de destino pudo ser convertido, pero se perdieron algunos datos.
XmCONVERTING_SAME
El objetivo de la conversión es el origen de los datos a transferir.
XmCONVERTING_TRANSACT
Este flag no se utiliza actualmente.
parm
Contiene datos de parámetros para este objetivo. Si no existen datos de parámetros, el valor es NULL.
Cuando selection es CLIPBOARD y target es _MOTIF_CLIPBOARD_TARGETS o _MOTIF_DEFERRED_CLIPBOARD_TARGETS, el valor es la operación solicitada (XmCOPY, XmMOVE o XmLINK).
parm_format
Especifica si los datos en parm deben verse como una lista de elementos char, short o long. Los valores posibles son 0 (cuando parm es NULL), 8 (cuando los datos en parm deben verse como una lista de char), 16 (cuando los datos en parm deben verse como una lista de short) o 32 (cuando los datos en parm deben verse como una lista de long). Tenga en cuenta que parm_format simboliza un tipo de dato, no el número de bits en cada elemento de la lista. Por ejemplo, en algunas máquinas, un parm_format de 32 significa que los datos en parm deben verse como una lista de cantidades de 64 bits, no de 32 bits.
parm_length
Especifica el número de elementos de datos en parm, donde cada elemento tiene el tamaño especificado por parm_format. Cuando parm es NULL, el valor es 0.
parm_type
Especifica el tipo de parámetro de parm.
status
Un miembro IN/OUT que especifica el estado de la conversión. El valor inicial es XmCONVERT_DEFAULT. El procedimiento de llamada puede establecer este miembro en uno de los siguientes valores:
XmCONVERT_DEFAULT
Este valor significa que el procedimiento de conversión de la clase del widget, si lo hay, se llama después de que los procedimientos de llamada regresen. Si el procedimiento de conversión de la clase del widget produce algún dato, sobrescribe los datos proporcionados por los procedimientos de llamada en el miembro value.
XmCONVERT_MERGE
Este valor significa que el procedimiento de conversión de la clase del widget, si lo hay, se llama después de que los procedimientos de llamada regresen. Si el procedimiento de conversión de la clase del widget produce algún dato, añade sus datos a los datos proporcionados por los procedimientos de llamada en el miembro value. Este valor está destinado a ser utilizado con objetivos que resultan en listas de datos, como TARGETS.
XmCONVERT_DONE
Este valor significa que el procedimiento de llamada ha finalizado la conversión con éxito. El procedimiento de conversión de la clase del widget, si lo hay, no se llama después de que los procedimientos de llamada regresen.
XmCONVERT_REFUSE
Este valor significa que el procedimiento de llamada ha terminado el proceso de conversión sin completar la conversión solicitada. El procedimiento de conversión de la clase del widget, si lo hay, no se llama después de que los procedimientos de llamada regresen.
value
Punta a los datos convertidos.
type
El tipo de los datos convertidos.
format
Especifica si los datos en value deben verse como una lista de elementos char, short o long. Los valores posibles son 8, 16 o 32.
length
Especifica el número de elementos de datos en value, donde cada elemento tiene el tamaño especificado por format.
>value
Un parámetro IN/OUT que contiene cualquier dato que el procedimiento de callback produce como resultado de la conversión. El valor inicial es NULL. Si el procedimiento de callback establece este miembro, debe asegurarse de que los miembros type, format y length correspondan a los datos en value. El procedimiento de callback es responsable de asignar memoria cuando establece este miembro. El toolkit libera esta memoria cuando ya no es necesaria.
type
Un parámetro IN/OUT que indica el tipo de los datos en el miembro value. El valor inicial es INTEGER.
format
Un parámetro IN/OUT que especifica si los datos en value deben ser vistos como una lista de cantidades char, short o long. El valor inicial es 8. El procedimiento de callback puede establecer este miembro a 8 (para una lista de char), 16 (para una lista de short) o 32 (para una lista de long).
length
Un miembro IN/OUT que especifica el número de elementos de datos en value, donde cada elemento tiene el tamaño simbolizado por format. El valor inicial es 0.

target

Rutinas de Acción

Las rutinas de acción de XmPrimitive son

PrimitiveHelp():
Llama a los callbacks para XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a los callbacks de ayuda del ancestro más cercano que los tenga.
PrimitiveNextTabGroup():
Esta acción depende del valor del recurso de visualización XmNenableButtonTab. Cuando XmNenableButtonTab es False (predeterminado), esta acción se desplaza al primer elemento del siguiente grupo de tabulación. Si el grupo de tabulación actual es la última entrada en la lista de grupos de tabulación, se salta al principio de la lista de grupos de tabulación.
Cuando XmNenableButtonTab es True, esta acción se mueve al siguiente elemento dentro del grupo de tabulación actual, a menos que sea el último elemento del grupo. Cuando el elemento es el último del grupo, la acción se desplaza al primer elemento del siguiente grupo de tabulación. El comportamiento de XmNenableButtonTab se aplica solo a PushButton, ArrowButton y DrawnArrow.
PrimitiveParentActivate():
Si el padre es un gestor, pasa el evento KActivate recibido por el widget a su padre.
PrimitiveParentCancel():
Si el padre es un gestor, pasa el evento KCancel recibido por el widget a su padre.
PrimitivePrevTabGroup():
Esta acción depende del valor del recurso de visualización XmNenableButtonTab. Cuando XmNenableButtonTab es False (predeterminado), esta acción se desplaza al primer elemento del grupo de tabulación anterior. Si se llega al principio de la lista de grupos de tabulación, se salta al final de la lista de grupos de tabulación.
Cuando XmNenableButtonTab es True, esta acción se mueve al elemento anterior dentro del grupo de tabulación actual a menos que sea el primer elemento del grupo. Cuando el elemento es el primero del grupo, la acción se desplaza al primer elemento del grupo de tabulación anterior. El comportamiento de XmNenableButtonTab se aplica solo a PushButton, ArrowButton y DrawnButton.
PrimitiveTraverseDown():
Se desplaza al siguiente elemento debajo del widget actual en el grupo de tabulación actual, saltando si es necesario. La dirección del salto depende de la dirección de diseño del grupo de tabulación del widget.
PrimitiveTraverseHome():
Se desplaza al primer widget o gadget en el grupo de tabulación actual.
PrimitiveTraverseLeft():
Se desplaza al siguiente elemento a la izquierda del widget actual en el grupo de tabulación actual, saltando si es necesario. La dirección del salto depende de la dirección de diseño del grupo de tabulación del widget.
PrimitiveTraverseNext():
Se desplaza al siguiente elemento en el grupo de tabulación actual, saltando si es necesario. La dirección del salto depende de la dirección de diseño del grupo de tabulación del widget.
PrimitiveTraversePrev():
Se desplaza al elemento anterior en el grupo de tabulación actual, saltando si es necesario. La dirección del salto depende de la dirección de diseño del grupo de tabulación del widget.
PrimitiveTraverseRight():
Se desplaza al siguiente elemento a la derecha del gadget actual en el grupo de tabulación actual, saltando si es necesario. La dirección del salto depende de la dirección de diseño del grupo de tabulación del widget.
PrimitiveTraverseUp():
Se desplaza al siguiente elemento encima del gadget actual en el grupo de tabulación actual, saltando si es necesario. La dirección del salto depende de la dirección de diseño del grupo de tabulación del widget.

Comportamiento Adicional

Este widget tiene el siguiente comportamiento adicional:

<FocusIn>:
Si la política de foco de teclado del shell es XmEXPLICIT, resalta el widget y le otorga el foco.
<FocusOut>:
Si la política de foco de teclado del shell es XmEXPLICIT, quita el resalte del widget y le quita el foco.

XmPrimitive(3)

NAME

XmPrimitive — una familia de widgets del Toolkit de Widgets de Motif

SYNOPSIS

#include <Xm/Primitive.h>

DESCRIPTION

El widget XmPrimitive es el widget padre de todos los widgets primitivos de Motif. Los widgets primitivos son aquellos que no tienen un contenido de aplicación independiente sino que se centran en la gestión de la interacción del usuario y la presentación visual.

Los widgets que heredan de XmPrimitive incluyen XmLabel, XmPushButton, XmDrawnButton, XmCascadeButton, XmTextField, XmText, XmList, XmScrollBar, XmSeparator, XmScale, etc.

XmPrimitive proporciona funcionalidades comunes a todos los widgets primitivos, como:

  • Gestión de eventos del teclado y del ratón.
  • Manejo de recursos comunes como colores, fuentes y bordes.
  • Soporte para el desplazamiento.
  • Habilitación y deshabilitación de widgets.
  • Gestión del estado de foco.
  • Definición de estilos de borde.

Los desarrolladores rara vez utilizan XmPrimitive directamente. En su lugar, trabajan con los widgets específicos que heredan de él.

CALLBACKS

XmPrimitive no proporciona callbacks directamente, pero sus widgets hijos lo hacen. Los callbacks comunes son:

  • XmNactivateCallback: Se llama cuando el widget se activa (por ejemplo, al presionar un botón).
  • XmNhelpCallback: Se llama cuando se solicita ayuda para el widget.
  • XmNfocusCallback: Se llama cuando el widget recibe el foco.
  • XmNlosingFocusCallback: Se llama cuando el widget pierde el foco.

RECURSOS

XmPrimitive define numerosos recursos que son heredados por sus widgets hijos. Algunos de los más importantes incluyen:

  • XmNforeground: Color del primer plano del widget.
  • XmNbackground: Color de fondo del widget.
  • XmNfontList: Lista de fuentes utilizada por el widget.
  • XmNhighlightThickness: Grosor del borde de resaltado cuando el widget tiene el foco.
  • XmNshadowThickness: Grosor de las sombras del borde.
  • XmNtraversalOn: Indica si el widget participa en la navegación por teclado.
  • XmNarmed: Indica si el widget está en estado "armado" (por ejemplo, un botón presionado).

Para una lista completa de recursos, consulte la documentación de cada widget primitivo específico.

ESTILO

XmPrimitive define un conjunto de estilos visuales que sus widgets hijos pueden utilizar. Esto incluye cómo se renderizan los bordes, las sombras y los indicadores de foco. Los estilos pueden variar según la configuración del gestor de ventanas y el tema de Motif utilizado.

EJEMPLO

Este es un ejemplo conceptual de cómo se podría usar un widget que hereda de XmPrimitive, como XmPushButton: 

Widget button;

button = XtVaCreateManagedWidget("myButton", xmPushButtonWidgetClass, parent,
    XmNlabelString, "Click Me",
    XmNforeground, color_red,
    NULL);

XtAddCallback(button, XmNactivateCallback, button_callback, NULL);

En este ejemplo, "myButton" es el nombre del widget, "xmPushButtonWidgetClass" es la clase del widget (que hereda de XmPrimitive), "parent" es el widget padre, y se configuran algunos recursos comunes como la etiqueta y el color.
