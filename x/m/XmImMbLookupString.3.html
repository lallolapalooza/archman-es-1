NOMBRE

XmImMbLookupString — Una función del gestor de entrada que recupera una cadena compuesta de un método de entrada

SINOPSIS

#include <Xm/XmIm.h>
int XmImMbLookupString(
Widget widget,
XKeyPressedEvent *event,
char *buffer_return,
int bytes_buffer,
KeySym *keysym_return,
int *status_return);

DESCRIPCIÓN

XmImMbLookupString devuelve una cadena compuesta en la localización asociada con el método de entrada del widget y un KeySym que está actualmente mapeado al keycode en un evento KeyPress. El KeySym se obtiene utilizando la interpretación estándar de los modificadores Shift, Lock y Group tal como se definen en la especificación del Protocolo X.

Se creará un XIM, pero no se creará un XIC. Una de las funciones, XmImSetValues, XmImVaSetValues, o XmImGetXIC, debe ser llamada para crear un XIC.

widget
Especifica el ID del widget registrado con el gestor de entrada
event
Especifica el evento de pulsación de tecla
buffer_return
Especifica el buffer en el que se devuelve la cadena
bytes_buffer
Especifica el tamaño del buffer en bytes
keysym_return
Especifica un puntero al KeySym devuelto si existe
status_return
Especifica los valores de estado devueltos por la función. Estos valores de estado son los mismos que los de la función XmbLookupString. Los valores de estado posibles son:
XBufferOverflow
El tamaño del buffer fue insuficiente para manejar la cadena devuelta. El contenido de buffer_return y keysym_return no se modifica. El tamaño de buffer requerido se devuelve como un valor de la función. El cliente debe repetir la llamada con un tamaño de buffer mayor para recibir la cadena.
XLookupNone
No se compuso ninguna entrada coherente. El contenido de buffer_return y keysym_return no se modifica y la función devuelve un valor de 0.
XLookupChars
Se compusieron y devolvieron algunos caracteres de entrada en buffer_return. El contenido de keysym_return no se modifica. La función devuelve la longitud de la cadena en bytes.
XLookupKeysym
Se devolvió un valor keysym en lugar de una cadena. El contenido de buffer_return no se modifica y la función devuelve un valor de 0.
XLookupBoth
Se devolvieron un valor keysym y una cadena. El valor keysym no se corresponde necesariamente con la cadena devuelta. La función devuelve la longitud de la cadena en bytes.

RETORNO

Los valores de retorno dependen del estado devuelto por la función. Consulte la descripción de los valores de estado anteriores.

RELACIONADO

XmImGetXIM(3), XmImGetXIC(3), XmImRegister(3), XmImSetValues(3), y XmImUnregister(3).
