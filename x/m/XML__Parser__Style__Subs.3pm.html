Licencias: GPL, PerlArtistic

Parser::Style::Subs(3) Documentación de Perl contribuida por el usuario Parser::Style::Subs(3)

NOMBRE

XML::Parser::Style::Subs - pegamento para manejar devoluciones de llamada de elementos

SINOPSIS

use XML::Parser;
my $p = XML::Parser->new(Style => 'Subs', Pkg => 'MySubs');
$p->parsefile('foo.xml');

{
  package MySubs;

  sub foo {
    # inicio de la etiqueta foo
  }

  sub foo_ {
    # fin de la etiqueta foo
  }
}

DESCRIPCIÓN

Cada vez que un elemento comienza, se llama a una subrutina con ese nombre en el paquete especificado por la opción Pkg con los mismos parámetros con los que se llama al manejador Start.

Cada vez que un elemento termina, se llama a una subrutina con ese nombre seguido de un guion bajo ("_"), con los mismos parámetros con los que se llama al manejador End.

No se devuelve nada especial de parse.
