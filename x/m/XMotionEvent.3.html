XMotionEvent(3)

Paquete: libx11

Licencias: MIT AND X11

XButtonEvent(3) FUNCIONES DE XLIB XButtonEvent(3)

NOMBRE

XButtonEvent, XKeyEvent, XMotionEvent - Estructuras de eventos KeyPress, KeyRelease, ButtonPress, ButtonRelease y MotionNotify

ESTRUCTURAS

Las estructuras para los eventos KeyPress, KeyRelease, ButtonPress, ButtonRelease y MotionNotify contienen:

typedef struct {
        int type;       /* ButtonPress o ButtonRelease */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Pantalla desde la que se leyó el evento */
        Window window;  /* Ventana de "evento" relativa a la que se informa */
        Window root;    /* Ventana raíz en la que ocurrió el evento */
        Window subwindow;       /* Ventana hija */
        Time time;      /* milisegundos */
        int x, y;       /* coordenadas x, y del puntero en la ventana de evento */
        int x_root, y_root;     /* coordenadas relativas a la raíz */
        unsigned int state;     /* máscara de tecla o botón */
        unsigned int button;    /* detalle */
        Bool same_screen;       /* indicador de misma pantalla */
} XButtonEvent;
typedef XButtonEvent XButtonPressedEvent;
typedef XButtonEvent XButtonReleasedEvent;
typedef struct {
        int type;       /* KeyPress o KeyRelease */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Pantalla desde la que se leyó el evento */
        Window window;  /* Ventana de "evento" relativa a la que se informa */
        Window root;    /* Ventana raíz en la que ocurrió el evento */
        Window subwindow;       /* Ventana hija */
        Time time;      /* milisegundos */
        int x, y;       /* coordenadas x, y del puntero en la ventana de evento */
        int x_root, y_root;     /* coordenadas relativas a la raíz */
        unsigned int state;     /* máscara de tecla o botón */
        unsigned int keycode;   /* detalle */
        Bool same_screen;       /* indicador de misma pantalla */
} XKeyEvent;
typedef XKeyEvent XKeyPressedEvent;
typedef XKeyEvent XKeyReleasedEvent;
typedef struct {
        int type;       /* MotionNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Pantalla desde la que se leyó el evento */
        Window window;  /* Ventana de "evento" relativa a la que se informa */
        Window root;    /* Ventana raíz en la que ocurrió el evento */
        Window subwindow;       /* Ventana hija */
        Time time;      /* milisegundos */
        int x, y;       /* coordenadas x, y del puntero en la ventana de evento */
        int x_root, y_root;     /* coordenadas relativas a la raíz */
        unsigned int state;     /* máscara de tecla o botón */
        char is_hint;   /* detalle */
        Bool same_screen;       /* indicador de misma pantalla */
} XMotionEvent;
typedef XMotionEvent XPointerMovedEvent;

Cuando recibes estos eventos, los miembros de su estructura se establecen de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa de un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido a GraphicsExpose. El miembro display se establece a un puntero a la pantalla desde la que se leyó el evento. El miembro send_event se establece a True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número serial informado en el protocolo pero expandido desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece a la ventana que es más útil para los despachadores de toolkits.

Estas estructuras tienen los siguientes miembros comunes: window, root, subwindow, time, x, y, x_root, y_root, state y same_screen. El miembro window se establece a la ventana en la que se generó el evento y se le denomina ventana de evento. Siempre que se cumplan las condiciones discutidas previamente, esta es la ventana utilizada por el servidor X para informar del evento. El miembro root se establece a la ventana raíz de la ventana de origen. Los miembros x_root e y_root se establecen a las coordenadas del puntero relativas al origen de la ventana raíz en el momento del evento.

El miembro same_screen se establece para indicar si la ventana de evento está en la misma pantalla que la ventana raíz y puede ser True o False. Si es True, las ventanas de evento y raíz están en la misma pantalla. Si es False, las ventanas de evento y raíz no están en la misma pantalla.

Si la ventana de origen es inferior a la ventana de evento, el miembro subwindow de la estructura se establece a la ventana hija de la ventana de evento que es la ventana de origen o la ventana hija de la ventana de evento que es un antecesor de la ventana de origen. De lo contrario, el servidor X establece el miembro subwindow a None. El miembro time se establece a la hora en que se generó el evento y se expresa en milisegundos.

Si la ventana de evento está en la misma pantalla que la ventana raíz, los miembros x e y se establecen a las coordenadas relativas al origen de la ventana de evento. De lo contrario, estos miembros se establecen a cero.

El miembro state se establece para indicar el estado lógico de los botones del puntero y las teclas modificadoras justo antes del evento, que es el OR inclusivo a nivel de bits de una o más de las máscaras de botón o tecla modificadora: Button1Mask, Button2Mask, Button3Mask, Button4Mask, Button5Mask, ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask y Mod5Mask.

Cada una de estas estructuras también tiene un miembro que indica el detalle. Para las estructuras XKeyPressedEvent y XKeyReleasedEvent, este miembro se llama keycode. Se establece a un número que representa una tecla física en el teclado. El keycode es una representación arbitraria para cualquier tecla del teclado (ver secciones 12.7 y 16.1).

Para las estructuras XButtonPressedEvent y XButtonReleasedEvent, este miembro se llama button. Representa el botón del puntero que cambió de estado y puede ser el valor Button1, Button2, Button3, Button4 o Button5. Para la estructura XPointerMovedEvent, este miembro se llama is_hint. Puede establecerse a NotifyNormal o NotifyHint.
