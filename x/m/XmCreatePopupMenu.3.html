NOMBRE

XmCreatePopupMenu — Función de conveniencia para la creación de un widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmCreatePopupMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreatePopupMenu crea una instancia de un widget RowColumn de tipo XmMENU_POPUP y devuelve el ID del widget asociado. Cuando esta función se utiliza para crear el panel de menú emergente, se crea automáticamente un widget MenuShell como padre del panel de menú. El padre del widget MenuShell es el widget indicado por el parámetro parent.

XmCreatePopupMenu se proporciona como una función de conveniencia para crear widgets RowColumn configurados para operar como paneles de menú emergentes y no se implementa como una clase de widget separada.

El panel de menú emergente se utiliza como el primer panel de menú dentro de un sistema de menú emergente; todos los demás paneles de menú son del tipo desplegable. Un panel de menú emergente muestra una sombra 3D, a menos que la aplicación deshabilite esta característica. La sombra aparece alrededor del borde del panel de menú.

El panel de menú emergente debe crearse como hijo de un widget MenuShell para funcionar correctamente cuando se incorpora a un menú. Si la aplicación utiliza esta función de conveniencia para crear un panel de menú emergente, el MenuShell se crea automáticamente como el padre real del panel de menú. Si la aplicación no utiliza esta función de conveniencia para crear el RowColumn para que funcione como un panel de menú emergente, es responsabilidad de la aplicación crear el widget MenuShell.

Para acceder al menú emergente, la aplicación primero debe posicionar el widget utilizando la función XmMenuPosition y luego gestionarlo utilizando XtManageChild.

padre
Especifica el ID del widget padre
nombre
Especifica el nombre del widget creado
lista_de_argumentos
Especifica la lista de argumentos
numero_de_argumentos
Especifica el número de pares atributo/valor en la lista de argumentos (lista_de_argumentos)

Los paneles de menú emergentes admiten capacidades de extracción para menús extraíbles a través de los recursos de XmRowColumn. Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.

RELACIONADOS

XmCreateSimplePopupMenu(3), XmMenuPosition(3), XmMenuShell(3), XmRowColumn(3), y XmVaCreateSimplePopupMenu(3).
