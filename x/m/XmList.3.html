NOMBRE

XmList — La clase del widget List

SINOPSIS

#include <Xm/List.h>

DESCRIPCIÓN

List permite a un usuario seleccionar uno o varios elementos de un grupo de opciones. Los elementos se seleccionan de la lista de diversas maneras, utilizando tanto el puntero como el teclado. List opera sobre un array de cadenas compuestas definidas por la aplicación. Cada cadena compuesta se convierte en un elemento de la Lista, siendo la primera cadena compuesta el elemento en la posición 1, la segunda el elemento en la posición 2, y así sucesivamente.

Especificar el número de elementos visibles establece el tamaño de la Lista. Si no se especifica el número de elementos visibles, la altura de la lista controla el número de elementos visibles. Cada elemento tiene la altura del elemento más alto de la lista. Para crear una lista que permita al usuario desplazarse fácilmente por un gran número de elementos, utilice la función de conveniencia XmCreateScrolledList.

Para seleccionar elementos, mueva el puntero o el cursor al elemento deseado y presione el botón del ratón <Btn1> o la tecla definida como <osfSelect>. Existen varios estilos de comportamiento de selección, y todos resaltan el/los elemento/s seleccionado/s mostrándolo/s en colores invertidos. Se invoca una rutina de devolución de llamada adecuada para notificar a la aplicación de la elección del usuario. La aplicación toma entonces la acción requerida para la selección especificada. Cuando una Lista está inactiva, todos los elementos de la lista se muestran con un patrón de relleno tramado.

List utiliza los rasgos XmQTspecifyRenderTable, XmQTscrollFrame y XmQTnavigator, y mantiene el rasgo XmQTtransfer.

Selección

Cada lista tiene uno de los cuatro modelos de selección:

•
Selección Única
•
Selección de Navegación
•
Selección Múltiple
•
Selección Extendida

En Selección Única y Selección de Navegación, se selecciona como máximo un elemento a la vez. En Selección Única, presionar <Btn1> sobre un elemento cambia su estado de selección y anula la selección de cualquier otro elemento seleccionado. En Selección de Navegación, presionar <Btn1> sobre un elemento lo selecciona y anula la selección de cualquier otro elemento seleccionado; arrastrar <Btn1> mueve la selección a medida que se mueve el puntero. Soltar <Btn1> sobre un elemento mueve el cursor de ubicación a ese elemento.

En Selección Múltiple, se pueden seleccionar cualquier número de elementos a la vez. Presionar <Btn1> sobre un elemento cambia su estado de selección pero no anula la selección de ningún otro elemento seleccionado.

En Selección Extendida, se pueden seleccionar cualquier número de elementos a la vez, y el usuario puede seleccionar fácilmente rangos de elementos. Presionar <Btn1> sobre un elemento lo selecciona y anula la selección de cualquier otro elemento seleccionado. Arrastrar <Btn1> o presionar o arrastrar <Shift><Btn1> después de una acción <Btn1> selecciona todos los elementos entre el elemento bajo el puntero y el elemento sobre el que se presionó <Btn1>. Esta acción también anula la selección de cualquier otro elemento seleccionado fuera de ese rango.

Selección Extendida también permite al usuario seleccionar y anular la selección de rangos de elementos no contiguos. Presionar <Ctrl><Btn1> sobre un elemento cambia su estado de selección pero no anula la selección de ningún otro elemento seleccionado. Arrastrar <Ctrl><Btn1> o presionar o arrastrar <Shift><Btn1> después de una acción <Ctrl><Btn1> establece el estado de selección de todos los elementos entre el elemento bajo el puntero y el elemento sobre el que se presionó <Ctrl><Btn1> al estado del elemento sobre el que se presionó <Ctrl><Btn1>. Esta acción no anula la selección de ningún otro elemento seleccionado fuera de ese rango.

Todas las operaciones de selección disponibles desde el ratón también están disponibles desde el teclado. List tiene dos modos de selección por teclado, Modo Normal y Modo Añadir. En Modo Normal, las operaciones de navegación y <osfSelect> seleccionan el elemento en el cursor de ubicación y anulan la selección de cualquier otro elemento seleccionado. En Modo Añadir, las operaciones de navegación no tienen efecto en la selección, y <osfSelect> cambia el estado de selección del elemento en el cursor de ubicación sin anular la selección de ningún otro elemento seleccionado, excepto en Selección Única.

Selección Única y Selección Múltiple usan Modo Añadir, y Selección de Navegación usa Modo Normal.

Selección Extendida puede usar cualquiera de los modos; el usuario cambia de modo presionando <osfAddMode>. En Selección Extendida Modo Normal, presionar <osfSelect> tiene el mismo efecto que presionar <Btn1>; <osfExtend> y la navegación con desplazamiento tienen el mismo efecto que presionar <Shift><Btn1> después de una acción <Btn1>. En Selección Extendida Modo Añadir, presionar <osfSelect> tiene el mismo efecto que presionar <Ctrl><Btn1>; <osfExtend> y la navegación con desplazamiento tienen el mismo efecto que presionar <Shift><Btn1> después de una acción <Ctrl><Btn1>.

El Modo Normal se indica con un cursor de ubicación sólido, y el Modo Añadir se indica con un cursor de ubicación discontinuo.

Comportamiento de transferencia de datos

List admite arrastrar elementos desde la Lista y transferir elementos al portapapeles. Cuando el usuario presiona BTransfer sobre un elemento seleccionado, el widget transfiere todos los elementos seleccionados. Cuando el usuario presiona BTransfer sobre un elemento no seleccionado, el widget transfiere solo ese elemento. Dependiendo del valor de XmNprimaryOwnership, List también puede admitir la selección primaria.

Cuando se llaman los procedimientos XmNconvertCallback, el miembro location_data del miembro XmConvertCallbackStruct es NULL si se están transfiriendo los elementos seleccionados. Si no se están transfiriendo los elementos seleccionados, este miembro tiene el siguiente valor: Si se está transfiriendo un solo elemento, el valor es un entero que representa la posición del elemento en la Lista. Un valor de 1 transfiere el primer elemento de la Lista; un valor de 2 transfiere el segundo elemento; y así sucesivamente. Si se está transfiriendo todo el contenido de la Lista, el valor es -1.

Como fuente de datos, List admite los siguientes objetivos y conversiones de datos asociadas a estos objetivos:

locale
Si el objetivo locale coincide con la configuración regional del widget, el widget transfiere los elementos de la lista seleccionados en la codificación de la configuración regional. Cada elemento transferido, excepto el último, incluye un separador final.
COMPOUND_TEXT
El widget transfiere los elementos de la lista seleccionados como tipo COMPOUND_TEXT. Cada elemento transferido, excepto el último, incluye un separador final.
UTF8_STRING
El widget transfiere los elementos de la lista seleccionados como tipo UTF8_STRING. Cada elemento transferido, excepto el último, incluye un separador final.
STRING
El widget transfiere los elementos de la lista seleccionados como tipo STRING. Cada elemento transferido, excepto el último, incluye un separador final.
TEXT
Si los elementos de la lista seleccionados son completamente convertibles a la codificación de la configuración regional, el widget transfiere los elementos de la lista seleccionados en la codificación de la configuración regional. De lo contrario, el widget transfiere los elementos de la lista seleccionados como tipo COMPOUND_TEXT. Cada elemento transferido, excepto el último, incluye un separador final.
_MOTIF_CLIPBOARD_TARGETS
El widget transfiere, como tipo ATOM, una lista de los objetivos que admite para transferencia inmediata para la selección CLIPBOARD. Estos incluyen _MOTIF_COMPOUND_STRING. Si los elementos de la lista seleccionados son completamente convertibles a STRING, estos también incluyen STRING; de lo contrario, también incluyen COMPOUND_TEXT y UTF8_STRING.
_MOTIF_COMPOUND_STRING
El widget transfiere los elementos de la lista seleccionados como una cadena compuesta en formato de Flujo de Bytes. Cada elemento transferido, excepto el último, incluye un separador final.
_MOTIF_DEFERRED_CLIPBOARD_TARGETS
El widget transfiere, como tipo ATOM, una lista de los objetivos que admite para transferencia diferida para la selección CLIPBOARD. Actualmente, este widget no proporciona ningún objetivo para _MOTIF_DEFERRED_CLIPBOARD_TARGETS.
_MOTIF_EXPORT_TARGETS
El widget transfiere, como tipo
ATOM, una lista de los objetivos que se utilizarán como valor de XmNexportTargets del DragContext en una transferencia de arrastrar y soltar. Estos incluyen _MOTIF_COMPOUND_STRING, COMPOUND_TEXT, UTF8_STRING, la codificación de la localización, STRING, TEXT, BACKGROUND y FOREGROUND.
_MOTIF_LOSE_SELECTION
Cuando el widget pierde la selección, deselecciona todos los elementos de la lista.

Como fuente de datos, List también soporta los siguientes objetivos estándar de Motif:

BACKGROUND
El widget transfiere XmNbackground como tipo PIXEL.
CLASS
El widget encuentra la primera ventana principal en la jerarquía del widget que tiene una propiedad WM_CLASS y transfiere su contenido como texto en la localización actual.
CLIENT_WINDOW
El widget encuentra la primera ventana principal en la jerarquía del widget y transfiere su ventana como tipo WINDOW.
COLORMAP
El widget transfiere XmNcolormap como tipo COLORMAP.
FOREGROUND
El widget transfiere XmNforeground como tipo PIXEL.
NAME
El widget encuentra la primera ventana principal en la jerarquía del widget que tiene una propiedad WM_NAME y transfiere su contenido como texto en la localización actual.
TARGETS
El widget transfiere, como tipo ATOM, una lista de los objetivos que soporta. Estos incluyen los objetivos estándar de esta lista. También incluyen _MOTIF_COMPOUND_STRING, COMPOUND_TEXT, UTF8_STRING, la codificación de la localización, STRING y TEXT.
TIMESTAMP
El widget transfiere la marca de tiempo utilizada para adquirir la selección como tipo INTEGER.
_MOTIF_RENDER_TABLE
El widget transfiere XmNrenderTable si existe, o la tabla de renderización de texto predeterminada, como tipo STRING.
_MOTIF_ENCODING_REGISTRY
El widget transfiere su registro de codificación como tipo STRING. El valor es una lista de elementos separados por NULL en forma de pares de etiqueta y codificación. Este objetivo simboliza el objetivo de transferencia para el Registro de Codificación de Segmentos de Motif. Los widgets y aplicaciones pueden usar este Registro llamando a XmRegisterSegmentEncoding y XmMapSegmentEncoding.

List no tiene un procedimiento de clase de widget de destino. Las subclases y los procedimientos XmNdestinationCallback son responsables de cualquier transferencia de datos al widget.

XmNautomaticSelection
Invoca XmNbrowseSelectionCallback o XmNextendedSelectionCallback cuando se presiona <Btn1> y los elementos que se muestran como seleccionados cambian si el valor es True (o XmAUTO) y el modo de selección es XmBROWSE_SELECT o XmEXTENDED_SELECT respectivamente. Si es False (XmNO_AUTO_SELECT), no se invoca ninguna devolución de llamada de selección hasta que el usuario suelta el botón del ratón. Consulte Comportamiento para obtener más detalles sobre la interacción de este recurso con los modos de selección.
XmNbrowseSelectionCallback
Especifica una lista de devoluciones de llamada que se invoca cuando se selecciona un elemento en el modo de selección de exploración. La razón es XmCR_BROWSE_SELECT.
XmNdefaultActionCallback
Especifica una lista de devoluciones de llamada que se invoca cuando se hace doble clic en un elemento o se presiona <osfActivate>. La razón es XmCR_DEFAULT_ACTION.
XmNdestinationCallback
Especifica una lista de devoluciones de llamada que se invocan cuando la Lista es el destino de una operación de transferencia. El tipo de la estructura cuya dirección se pasa a estas devoluciones de llamada es XmDestinationCallbackStruct. La razón es XmCR_OK.
XmNdoubleClickInterval
Si un clic de botón va seguido de otro clic de botón dentro del lapso de tiempo especificado por este recurso (en milisegundos), los clics de botón se consideran una acción de doble clic, en lugar de dos acciones de un solo clic. El valor no debe ser negativo. El valor predeterminado es el tiempo de clic múltiple de la pantalla.
XmNextendedSelectionCallback
Especifica una lista de devoluciones de llamada que se invoca cuando se seleccionan elementos utilizando el modo de selección extendida. La razón es XmCR_EXTENDED_SELECT.
XmNfontList
Especifica la lista de fuentes asociada con los elementos de la lista. XmNfontList está obsoleto y existe solo por compatibilidad con versiones anteriores. Ahora debe usar XmNrenderTable en lugar de XmNfontList. Si se especifican ambos, la tabla de renderizado tendrá prioridad. La lista de fuentes se utiliza junto con el recurso XmNvisibleItemCount para determinar la altura del widget Lista. Si este valor es NULL en la inicialización, se busca en la jerarquía principal del widget un widget que contenga el rasgo XmQTspecifyRenderTable. Si se encuentra dicho ancestro, la lista de fuentes se inicializa al valor XmTEXT_RENDER_TABLE del widget ancestro. Si no se encuentra ningún widget dicho, el valor predeterminado depende de la implementación. Consulte XmFontList(3)Aquí tienes la traducción del contenido a español, manteniendo la estructura del archivo: for more information on a font list structure.
XmNitemCount
Especifica el número total de elementos. El valor debe ser el número de elementos en XmNitems y no debe ser negativo. Es actualizado automáticamente por la lista cada vez que se añade o elimina un elemento de la lista.
XmNitems
Punta a un array de cadenas compuestas que se mostrarán como los elementos de la lista. Consulte XmString(3) para obtener más información sobre la creación y estructura de cadenas compuestas. XtGetValues para este recurso devuelve los elementos de la lista en sí, no una copia de los elementos de la lista. La aplicación no debe liberar los elementos devueltos.
XmNlistMarginHeight
Especifica la altura del margen entre el borde de la lista y los elementos.
XmNlistMarginWidth
Especifica el ancho del margen entre el borde de la lista y los elementos.
XmNlistSizePolicy
Controla la reacción de la Lista cuando un elemento crece horizontalmente más allá del área de trabajo actual de la lista. Si el valor es XmCONSTANT, el área de visualización de la lista no crece y se añade una ScrollBar horizontal para una Lista cuyo padre es una ScrolledWindow. Si este recurso se establece en XmVARIABLE, la Lista crece para coincidir con el tamaño del elemento más largo y no aparece ninguna ScrollBar horizontal.
Cuando el valor de este recurso es XmRESIZE_IF_POSSIBLE, la Lista intenta crecer o encogerse para coincidir con el ancho del elemento más ancho. Si no puede crecer para coincidir con el tamaño más ancho, se añade una ScrollBar horizontal para una Lista cuyo padre es una ScrolledWindow si el elemento más largo es más ancho que el área de visualización de la lista.
La política de tamaño debe establecerse en el momento en que se crea el widget List. No se puede cambiar más tarde a través de XtSetValues.
XmNlistSpacing
Especifica el espaciado entre los elementos de la lista. Este espaciado aumenta por el valor del recurso XmNhighlightThickness en Primitive.
XmNmatchBehavior
Especifica el comportamiento de coincidencia seguido por XmList. Los valores actuales son XmNONE y XmQUICK_NAVIGATE, como se indica a continuación:
XmNONE
Especifica que los caracteres introducidos se ignoran.
XmQUICK_NAVIGATE
Especifica que la navegación de 1 carácter se admitirá cuando la Lista tenga el foco. Si el carácter escrito es el carácter inicial de algún conjunto de elementos en la Lista, se navegará al primero de esos elementos que siga al elemento actual (se convertirá en el elemento actual). Si todos esos elementos preceden al elemento actual, el primer elemento de ese tipo se convertirá en el elemento actual. Posteriormente, escribir el mismo carácter navegará cíclicamente entre los elementos con el mismo primer carácter.
XmNmultipleSelectionCallback
Especifica una lista de callbacks que se llama cuando se selecciona un elemento en modo de selección múltiple. La razón es XmCR_MULTIPLE_SELECT.
XmNprimaryOwnership
Especifica si XmContainer toma posesión de la selección primaria cuando se realiza una selección dentro de él. Este recurso puede tomar los siguientes valores:
XmOWN_NEVER
Nunca toma posesión.
XmOWN_ALWAYS
Siempre toma posesión.
XmOWN_MULTIPLE
Solo toma posesión si se ha seleccionado más de un elemento.
XmOWN_POSSIBLE_MULTIPLE
Solo toma posesión si se pueden seleccionar más de un elemento a la vez.
XmNrenderTable
Especifica la tabla de renderizado asociada a los elementos de la lista. La tabla de renderizado se utiliza junto con el recurso XmNvisibleItemCount para determinar la altura del widget List. Si este valor es NULL en la inicialización, List busca en la jerarquía de sus padres un widget que contenga el rasgo XmQTspecifyRenderTable. Si se encuentra un ancestro de este tipo, la tabla de renderizado se inicializa al valor XmTEXT_RENDER_TABLE del widget ancestro. Si no se encuentra ningún widget de este tipo, el valor predeterminado depende de la implementación. Si se especifican tanto una lista de fuentes como una tabla de renderizado, la tabla de renderizado tendrá prioridad. Consulte XmRenderTable(3) para obtener más información sobre la creación y estructura de una tabla de renderizado.
XmNscrollBarDisplayPolicy
Controla la visualización de las ScrollBars verticales en una Lista cuyo padre es una ScrolledWindow. Cuando el valor de este recurso es XmAS_NEEDED, una ScrollBar vertical se muestra solo cuando el número de elementos en la Lista excede el número de elementos visibles. Cuando el valor es XmSTATIC, una ScrollBar vertical se muestra siempre.
XmNselectColor
Permite a la aplicación especificar el color del rectángulo de fondo que indica el texto seleccionado. Toma dos valores:
XmDEFAULT_SELECT_COLOR
Hace que el color de selección se establezca en un color entre el fondo y el color de la sombra inferior.
XmREVERSED_GROUND_COLORS
Fuerza el color de selección al color de primer plano y el color de cualquier texto renderizado sobre el color de selección al color de fondo.
HIGHLIGHT_COLOR
Fuerza el color de relleno a usar el color de resaltado.
XmNselectedItemCount
Especifica el número de cadenas en la lista de elementos seleccionados. El valor debe ser el número de elementos en XmNselectedItems y no debe ser negativo.
XmNselectedItems
Punta a un array de cadenas compuestas que representa los elementos de la lista que están actualmente seleccionados, ya sea por el usuario o por la aplicación. XtGetValues para este recurso devuelve los elementos de la lista en sí, no una copia de los elementos de la lista. La aplicación no debe liberar los elementos devueltos ni el array.
Establecer XmNselectedItems selecciona aquellos elementos de la lista que coinciden exactamente con los elementos de la lista XmNselectedItems dada. Puede haber elementos adicionales en XmNselectedItems que no coincidan con los elementos de la lista. Estos elementos permanecen hasta que se actualiza XmNselectedItems. Si se cambia XmNitems de tal manera que la lista ahora contenga elementos que coinciden con elementos previamente no coincidentes en XmNselectedItems, esos nuevos elementos también aparecerán seleccionados.
Cualquier interacción del usuario con la lista que cause que al menos un elemento sea seleccionado o deseleccionado y cualquier llamada a XmListDeleteAllItems, XmListDeleteItem, XmListDeleteItems, XmListDeleteItemsPos, XmListDeletePos, XmListDeletePositions, XmListDeselectAllItems, XmListDeselectItem, XmListDeselectPos, XmSelectItem, XmListSelectPos o XmListUpdateSelectedList causan que XmNselectedItems se actualice inmediatamente para reflejar exactamente el estado visual de la lista. Las llamadas a cualquier otra función XmList no afectan a XmNselectedItems.
XmNselectedPositionCount
Especifica el número de posiciones en la lista de posiciones seleccionadas. El valor debe ser el número de elementos en XmNselectedPositions
XmNselectedPositions
Punta a un array de las posiciones de los elementos seleccionados en la Lista. XtGetValues para este recurso devuelve los elementos de la lista en sí, no una copia de los elementos de la lista. La aplicación no debe liberar los elementos devueltos ni el array.
XmNselectionMode
Define qué efecto tienen las navegaciones del teclado en la selección. Los modos válidos son:
XmADD_MODE
Permite que ninguna operación de navegación tenga efecto en la selección, y <osfSelect> alterna el estado de selección del elemento en el cursor de ubicación sin deseleccionar ningún otro elemento seleccionado, excepto en Selección Única. Sin embargo, el widget no se puede poner en modo de adición si el recurso XmNselectionPolicy es un modo incompatible (XmNselectionPolicy no puede ser XmBROWSE_SELECT).
XmNORMAL_MODE
Permite que las operaciones de navegación y <osfSelect> seleccionen el elemento en el cursor de ubicación y deseleccionen cualquier otro elemento seleccionado. Sin embargo, el widget no se puede poner en modo normal si el recurso XmNselectionPolicy es un modo incompatible (XmNselectionPolicy no puede ser XmSINGLE_SELECT o XmMULTIPLE_SELECT).
XmNselectionPolicy

Información de Devolución de Llamada

List define una nueva estructura de devolución de llamada. La aplicación debe primero examinar el campo `reason` y utilizar solo los miembros de la estructura que sean válidos para esa razón en particular, ya que no todos los campos son relevantes para cada razón posible. La estructura de devolución de llamada se define de la siguiente manera:

typedef struct
{
        int reason;
        XEvent *event;
        XmString item;
        int item_length;
        int item_position;
        XmString *selected_items;
        int selected_item_count;
        int *selected_item_positions;
        char selection_type;
        unsigned char auto_selection_type;
} XmListCallbackStruct;
reason
Indica por qué se invocó la devolución de llamada.
event
Puntero a la estructura de evento X que activó la devolución de llamada. Si el evento no fue un evento X, este campo es NULL.
item
Un puntero a la cadena XmString del elemento seleccionado. Este campo solo es válido para las razones XmCR_SINGLE_SELECTION, XmCR_BROWSE_SELECTION, XmCR_DEFAULT_ACTION y XmCR_EXTENSION.
item_length
La longitud del elemento seleccionado. Este campo solo es válido para las razones XmCR_SINGLE_SELECTION, XmCR_BROWSE_SELECTION, XmCR_DEFAULT_ACTION y XmCR_EXTENSION.
item_position
La posición del elemento seleccionado (basado en 0). Este campo solo es válido para las razones XmCR_SINGLE_SELECTION, XmCR_BROWSE_SELECTION, XmCR_DEFAULT_ACTION y XmCR_EXTENSION.
selected_items
Un puntero a una matriz de cadenas XmString de los elementos seleccionados. Este campo solo es válido para las razones XmCR_MULTIPLE_SELECTION y XmCR_EXTENDED_SELECTION.
selected_item_count
El número de elementos seleccionados. Este campo solo es válido para las razones XmCR_MULTIPLE_SELECTION y XmCR_EXTENDED_SELECTION.
selected_item_positions
Un puntero a una matriz de enteros que indica las posiciones de los elementos seleccionados. Este campo solo es válido para las razones XmCR_MULTIPLE_SELECTION y XmCR_EXTENDED_SELECTION.
selection_type
Indica el tipo de selección que se ha realizado. Este campo solo es válido para la razón XmCR_EXTENDED_SELECTION.
auto_selection_type
Indica el tipo de selección automática que se ha realizado. Este campo solo es válido para la razón XmCR_EXTENDED_SELECTION.

Rutinas de Acción

Las rutinas de acción de XmList se describen en la siguiente lista. La selección actual siempre se muestra con colores invertidos.

ListAddMode():
Activa o desactiva el modo de adición para la selección por teclado.
ListBeginData():
Mueve el cursor de ubicación al primer elemento de la lista. En modo Normal, esto también deselecciona cualquier selección actual, selecciona el primer elemento de la lista y llama a las rutinas de devolución de llamada de selección apropiadas (XmNbrowseSelectionCallback cuando XmNselectionPolicy está establecido en XmBROWSE_SELECT, XmNextendedSelectionCallback cuando XmNselectionPolicy está establecido en XmEXTENDED_SELECT).
ListBeginDataExtend():
Si XmNselectionPolicy está establecido en XmMULTIPLE_SELECT o XmEXTENDED_SELECT, esta acción mueve el cursor de ubicación al primer elemento de la lista.
Si XmNselectionPolicy está establecido en XmEXTENDED_SELECT, esta acción hace lo siguiente: Si se ha realizado una selección extendida desde el punto de ancla actual, restaura el estado de selección de los elementos en ese rango a su estado anterior a la selección extendida; cambia el estado de selección del primer elemento y de todos los elementos entre él y el punto de ancla actual al estado del elemento en el punto de ancla actual; llama a las rutinas de devolución de llamada XmNextendedSelectionCallback.
ListBeginExtend():
Si XmNselectionPolicy está establecido en XmEXTENDED_SELECT, esta acción hace lo siguiente: Si se ha realizado una selección extendida desde el punto de ancla actual, restaura el estado de selección de los elementos en ese rango a su estado anterior a la selección extendida y cambia el estado de selección del elemento bajo el puntero y todos los elementos entre él y el punto de ancla actual al estado del elemento en el punto de ancla actual. Si XmNautomaticSelection está establecido en True, esta acción llama a las rutinas de devolución de llamada XmNextendedSelectionCallback. El componente auto_selection_type de la estructura de devolución de llamada se establecerá en XmAUTO_BEGIN.
ListBeginLine():
Mueve la región de desplazamiento horizontal al principio de la línea.
ListBeginSelect():
Si XmNselectionPolicy está establecido en XmSINGLE_SELECT, deselecciona cualquier selección actual y alterna el estado de selección del elemento bajo el puntero.
Si XmNselectionPolicy está establecido en XmBROWSE_SELECT, deselecciona cualquier selección actual y selecciona el elemento bajo el puntero. Si XmNautomaticSelection está establecido en True, llama a las rutinas de devolución de llamada XmNbrowseSelectionCallback. El componente auto_selection_type de la estructura de devolución de llamada se establecerá en XmAUTO_BEGIN.
Si XmNselectionPolicy está establecido en XmMULTIPLE_SELECT, alterna el estado de selección del elemento bajo el puntero. Cualquier selección anterior permanece.
Si XmNselectionPolicy está establecido en XmEXTENDED_SELECT, esta acción deselecciona cualquier selección actual, selecciona el elemento bajo el puntero y establece el punto de ancla actual en ese elemento. Si XmNautomaticSelection está establecido en True, esta acción llama a las rutinas de devolución de llamada XmNextendedSelectionCallback. El componente auto_selection_type de la estructura de devolución de llamada se establecerá en XmAUTO_BEGIN.
ListBeginToggle():
Si XmNselectionPolicy está establecido en XmEXTENDED_SELECT, esta acción mueve el punto de ancla actual al elemento bajo el puntero sin cambiar la selección actual. Si el elemento no está seleccionado, esta acción lo selecciona; si el elemento está seleccionado, esta acción lo deselecciona. Si XmNautomaticSelection está establecido en True, esta acción llama a las rutinas de devolución de llamada XmNextendedSelectionCallback.
De lo contrario, la lista toma el foco del teclado. No ocurre ninguna otra acción. El componente auto_selection_type de la estructura de devolución de llamada se establecerá en XmAUTO_BEGIN.
ListButtonMotion():
Si XmNselectionPolicy está establecido en XmBROWSE_SELECT, esta acción deselecciona cualquier selección actual y selecciona el elemento bajo el puntero. Si XmNautomaticSelection está establecido en True y el puntero ha entrado en un nuevo elemento de lista, esta acción llama a las rutinas de devolución de llamada XmNbrowseSelectionCallback.
Si XmNselectionPolicy está establecido en XmEXTENDED_SELECT, esta acción hace lo siguiente: Si se está realizando una selección extendida y se ha realizado previamente una selección extendida desde el punto de ancla actual, restaura el estado de selección de los elementos en ese rango a su estado anterior a la selección extendida anterior y cambia el estado de selección del elemento bajo el puntero y todos los elementos entre él y el punto de ancla actual al estado del elemento en el punto de ancla actual. Si XmNautomaticSelection está establecido en True y el puntero ha entrado en un nuevo elemento de lista, llama a las rutinas de devolución de llamada XmNextendedSelectionCallback.
Si el puntero abandona una lista desplazada, esta acción desplaza la lista en la dirección del movimiento del puntero. El componente auto_selection_type de la estructura de devolución de llamada se establecerá en XmAUTO_MOTION.

Comportamiento Adicional

El widget List tiene el siguiente comportamiento adicional:

<Doble clic>
Si un clic de botón es seguido por otro clic de botón dentro del lapso de tiempo especificado por el tiempo de múltiples clics de la pantalla, List lo interpreta como un doble clic y llama a las callbacks de XmNdefaultActionCallback. Los colores del elemento se invierten para indicar que está seleccionado. El recurso XmNdoubleClickInterval se puede utilizar para especificar un lapso de tiempo que anula el tiempo de múltiples clics de la pantalla.
<FocusIn>:
Si la política de foco es Explícita, esta acción establece el foco y dibuja el cursor de ubicación.
<FocusOut>:
Si la política de foco es Explícita, esta acción elimina el foco y borra el cursor de ubicación.
