NOMBRE

XmImGetXIC — Una función del gestor de entrada que obtiene un XIC para un widget

SINOPSIS

#include <Xm/XmIm.h>
XIC XmImGetXIC(
Widget widget,
XmInputPolicy input_policy,
ArgList args,
Cardinal num_args);

DESCRIPCIÓN

XmImGetXIC crea y registra un Contexto de Entrada X (XIC) con los argumentos especificados para widget. Si se especifica XmINHERIT_POLICY para input_policy, se creará un nuevo XIC solo si los argumentos o la política de entrada de VendorShell lo requieren. Cualquier XIC existente registrado con widget se anulará el registro.

Consulte la página de referencia de VendorShell para más detalles.

widget
Especifica el ID de un widget para el que se va a crear un Contexto de Entrada.
input_policy
Especifica el tipo de política de entrada. Acepta los siguientes valores:
XmINHERIT_POLICY
Hereda la política de VendorShell.
XmPER_WIDGET
Crea un nuevo XIC para este widget.
XmPER_SHELL
Crea un nuevo XIC para la ventana principal, si es necesario.
args
Especifica un parámetro XtArgList para usar al crear el XIC.
num_args
Especifica el número de argumentos en el parámetro args.

RETORNO

Devuelve el XIC creado. La aplicación es responsable de liberar el XIC devuelto llamando a XmImFreeXIC.

RELACIONADO

XmImSetXIC(3) y XmImFreeXIC(3).
