NOMBRE

XmTextSetMaxLength — Una función de Texto que establece el valor de la longitud máxima actual permitida de una cadena de texto introducida desde el teclado

SINOPSIS

#include <Xm/Text.h>
void XmTextSetMaxLength(
Widget widget,
int max_length);

DESCRIPCIÓN

XmTextSetMaxLength establece el valor de la longitud máxima actual permitida de la cadena de texto en el widget Text. La longitud máxima permitida evita que el usuario introduzca una cadena de texto desde el teclado que sea mayor que este límite. Las cadenas que se introducen utilizando el recurso XmNvalue (o XmNvalueWcs), o la función XmTextSetString (o XmTextSetStringWcs) ignoran este recurso.

widget
Especifica el ID del widget Text
max_length
Especifica la longitud máxima permitida de la cadena de texto

Para una definición completa de Text y sus recursos asociados, consulte XmText(3).

RELACIONADO

XmText(3), XmTextSetString(3) y XmTextSetStringWcs(3).
