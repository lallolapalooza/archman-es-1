NOMBRE

XmPrintPopupPDM — Envía una notificación para que el PDM se muestre

SINOPSIS

#include <Xm/Print.h>
XtEnum XmPrintPopupPDM(
Widgetprint_shell,
Widgetvideo_transient_for);

DESCRIPCIÓN

Una función de conveniencia que envía una notificación para iniciar un Gestor de Diálogos de Impresión en nombre de la aplicación, XmPrintPopupPDM oculta los detalles del mecanismo de selección de X utilizado para notificar al PDM que se debe mostrar un nuevo diálogo para esta aplicación.

XmPrintPopupPDM envía una solicitud de selección a la pantalla de impresión del shell de impresión, o a la pantalla de video del widget de video transitorio (dependiendo de la variable de entorno XPDMDISPLAY, que solo puede tomar el valor "print" o "video"), pidiendo que se muestren las ventanas del PDM en nombre de la aplicación.

Retorna inmediatamente con el estado de XmPDM_NOTIFY_FAIL (por ejemplo, si la función no pudo asignar memoria para el valor de selección, o si XPDMDISPLAY no es "print" o "video") o con XmPDM_NOTIFY_SUCCESS, lo que solo significa que se envió un "mensaje" al PDM especificado por XPDMSELECTION, no que ya esté visible en la pantalla.

Para saber si el PDM está visible o no se está ejecutando, la aplicación debe registrar un XmNpdmNotificationCallback con el Shell de Impresión.

XmPrintPopupPDM muestra una ventana de Solo Entrada encima del diálogo, para que el usuario final no utilice el diálogo de configuración de impresión mientras el PDM intenta aparecer. Esta ventana se elimina automáticamente cuando el shell está a punto de llamar al callback por primera vez.

print_shell
El Shell de Impresión utilizado para este trabajo y contexto de impresión.
video_transient_for
El widget de video que maneja la configuración de impresión de la aplicación.

VALOR DE RETORNO

Retorna XmPDM_NOTIFY_SUCCESS si la función pudo enviar la notificación al proceso PDM, XmPDM_NOTIFY_FAIL en caso contrario.

ERRORES/ADVERTENCIAS

No aplicable.

EJEMPLOS

Ejemplo de callback desde el botón "Configurar..." de un cuadro de diálogo de configuración de impresión:

PrintSetupCallback(print_dialog...)
/*-------------*/
{
    if (XmPrintPopupPDM (pshell, XtParent(print_dialog)) !=
                                    XmPDM_NOTIFY_SUCCESS) {
        /* algún cuadro de diálogo de error */
    }
}

Ejemplo de XmNpdmNotificationCallback desde un Shell de Impresión:

pdmNotifyCB(print_shell...)
{
    XmPrintShellCallBackStruct * pr_cb = ...
    switch (pr_cb->reason) {
       case XmCR_PDM_NONE:
           /* no hay PDM disponible */
           PostErrorDialog(...);
           break;
       case XmCR_PDM_VXAUTH:
           /* el PDM no está autorizado ... */
           PostErrorDialog(...);
           break;
       case XmCR_PDM_UP: el PDM está funcionando
           /* todo está bien */
           break;
               default: /* otros casos */
   }
}
