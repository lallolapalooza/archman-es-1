XML::LibXML::SAX(3) Documentación de Perl aportada por el usuario XML::LibXML::SAX(3)

NOMBRE

XML::LibXML::SAX - Analizador SAX directo de XML::LibXML

DESCRIPCIÓN

XML::LibXML proporciona una interfaz a la interfaz SAX directa de libxml2. A través de esta interfaz es posible generar eventos SAX directamente mientras se analiza un documento. Al usar el analizador SAX, XML::LibXML no creará un árbol de documento DOM.

Una interfaz como esta es útil si se deben procesar documentos XML muy grandes y no se requieren funciones DOM. Utilizando esta interfaz es posible leer datos almacenados dentro de un documento XML directamente en las estructuras de datos de la aplicación sin cargar el documento en memoria.

La interfaz SAX de XML::LibXML se basa en la famosa interfaz XML::SAX. Utiliza la interfaz genérica tal como la proporciona XML::SAX::Base.

Además de las funciones genéricas, que solo son capaces de procesar documentos completos, XML::LibXML::SAX proporciona parse_chunk(). Este método genera eventos SAX a partir de datos bien equilibrados, como los que a menudo proporcionan las bases de datos.

CARACTERÍSTICAS

NOTA: Esta característica es experimental.

Puede habilitar la unión de datos de caracteres, lo que puede generar una mejora significativa en la velocidad de procesamiento de XML en situaciones con una menor proporción de marcado, habilitando la característica http://xmlns.perl.org/sax/join-character-data de este analizador. Esto se hace a través del método set_feature de esta manera:

$p->set_feature('http://xmlns.perl.org/sax/join-character-data', 1);

También puede especificar un 0 para deshabilitar. Por defecto, esta característica está deshabilitada.
