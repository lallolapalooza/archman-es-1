NOMBRE

XmFontListNextEntry — Una función de lista de fuentes que devuelve la siguiente entrada en una lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
XmFontListEntry XmFontListNextEntry(
XmFontContext context);

DESCRIPCIÓN

XmFontListNextEntry devuelve la siguiente entrada en la lista de fuentes. La aplicación utiliza la rutina XmFontListInitFontContext para crear un contexto de lista de fuentes. La primera llamada a XmFontListNextEntry establece el contexto a la primera entrada de la lista de fuentes. Luego, la aplicación llama a XmFontListNextEntry repetidamente con el mismo contexto. Cada llamada sucesiva accede a la siguiente entrada de la lista de fuentes. Al finalizar, la aplicación llama a XmFontListFreeFontContext para liberar el contexto de lista de fuentes asignado.

context
Especifica el contexto de la lista de fuentes.

RETORNO

Devuelve NULL si el contexto no se refiere a una entrada válida o si está al final de la lista de fuentes; de lo contrario, devuelve una entrada de lista de fuentes. Si la función devuelve una entrada de lista de fuentes, esta entrada no es una copia. Por lo tanto, la aplicación no debe liberar la entrada de lista de fuentes devuelta.

RELACIONADOS

XmFontList(3), XmFontListEntryFree(3), XmFontListEntryGetFont(3), XmFontListEntryGetTag(3), XmFontListFreeFontContext(3), y XmFontListInitFontContext(3).
