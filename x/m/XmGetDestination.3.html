NOMBRE

XmGetDestination — Una función que devuelve el ID del widget a utilizar como destino actual para la pegada rápida y ciertas operaciones del portapapeles

SINOPSIS

#include <Xm/Xm.h>
Widget XmGetDestination(
Display *display);

DESCRIPCIÓN

XmGetDestination devuelve el widget que es el destino actual en la pantalla especificada. El destino es generalmente el último widget editable en el que se realizó una operación de selección, edición, inserción o pegado y es el destino para la pegada rápida y ciertas funciones del portapapeles. El destino es NULL hasta que se haya realizado una operación de teclado o ratón en un widget editable. Consulte la Guía del programador de Motif para obtener una descripción del foco del teclado.

display
Especifica la pantalla cuyo widget de destino se va a consultar

RETORNO

Devuelve el ID del widget para el destino actual o NULL si no hay un destino actual.
