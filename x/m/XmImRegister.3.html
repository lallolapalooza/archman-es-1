XmImRegister(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmImRegister(llamada de librería) XmImRegister(llamada de librería)

NOMBRE

XmImRegister — Función del gestor de entrada que registra un widget con un gestor de entrada

SINOPSIS

#include <Xm/XmIm.h>
void XmImRegister(
Widget widget,
unsigned int reserved);

DESCRIPCIÓN

XmImRegister registra un widget con su gestor de entrada. Esto añade el widget especificado a una lista de widgets que son compatibles con el gestor de entrada para un método de entrada. Si un método de entrada no ha sido abierto por una llamada previa a XmImRegister, la primera vez que se llame a esta rutina, abrirá un método de entrada usando el recurso XmNinputMethod para el VendorShell. Si XmNinputMethod es NULL, se abrirá un método de entrada usando la configuración regional actual.

Si no se puede abrir un método de entrada en la configuración regional actual, XLookupString proporciona el procesamiento de entrada.

La aplicación es responsable de anular el registro de un widget llamando a XmImUnregister.

Tenga en cuenta que los widgets Text, TextField y List ya llaman a la función XmImRegister internamente. No debería llamar a esta función para estos widgets antes de llamar primero a XmImUnregister.

widget
Especifica el ID del widget a registrar.
reserved
Este argumento no se utiliza en la versión actual de Motif. El valor siempre debe ser 0 (cero).

RELACIONADOS

XmImGetXIM(3), XmImMbLookupString(3), y XmImUnregister(3).
