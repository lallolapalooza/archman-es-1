XML::LibXML::Devel(3) Documentación Perl contribuida por el usuario XML::LibXML::Devel(3)

NOMBRE

XML::LibXML::Devel - hace que las funciones de LibXML.xs estén disponibles

SINOPSIS

/**********************************************
 * Funciones C que deseas acceder
 */
xmlNode *return_node();
void receive_node(xmlNode *);
###############################################
# Código XS
void *
  xs_return_node
  CODE:
      RETVAL = return_node();
  OUTPUT:
      RETVAL
void
  xs_receive_node
      void *n
  CODE:
      receive_node(n);
###############################################
# Código Perl
use XML::LibXML::Devel;
sub return_node
{
  my $raw_node = xs_return_node();
  my $node = XML::LibXML::Devel::node_to_perl($raw_node);
  XML::LibXML::Devel::refcnt_inc($raw_node);
  return $node;
}
sub receive_node
{
  my ($node) = @_;
  my $raw_node = XML::LibXML::Devel::node_from_perl($node);
  xs_receive_node($raw_node);
  XML::LibXML::Devel::refcnt_inc($raw_node);
}

DESCRIPCIÓN

"XML::LibXML::Devel" hace que las funciones de LibXML.xs estén disponibles, las cuales son necesarias para envolver nodos de XML::LibXML en y desde Nodos de XML::LibXML. Esto proporciona dependencias más limpias que usar LibXML.so directamente.

Para hacer XS de una librería que utiliza nodos de libxml2, el primer paso es hacer esto para que xmlNodePtr se pase como void *. Estos nodos crudos se convierten luego en nodos de libxml utilizando estas funciones de "Devel".

Ten en cuenta que este módulo es actualmente bastante experimental. Los nombres de las funciones pueden cambiar si hago más funciones XS e introduzco una convención de nombres razonable.

Ten también en cuenta que este módulo es una gran herramienta para provocar fallos de segmentación e introducir fugas de memoria. Sin embargo, proporciona una cura parcial al poner a disposición "xmlMemUsed" como "mem_used".

FUNCIONES

GESTIÓN DE NODOS

node_to_perl
node_to_perl($raw_node);

Devuelve un objeto LibXML::Node. Este tiene un nodo proxy con un contador de referencias y un propietario adjunto. El nodo crudo se eliminará tan pronto como el contador de referencias llegue a cero. Si la librería C mantiene un puntero al nodo crudo, debes llamar a refcnt_inc inmediatamente. También debes reemplazar xmlFreeNode por una llamada a refcnt_dec.

node_to_perl
node_from_perl($node);

Devuelve un nodo crudo. Este es un puntero void * y no puedes hacer nada más que pasarlo a funciones que lo traten como un xmlNodePtr. El nodo crudo se liberará tan pronto como su contador de referencias llegue a cero. Si la librería C mantiene un puntero al nodo crudo, debes llamar a refcnt_inc inmediatamente. También debes reemplazar xmlFreeNode por una llamada a refcnt_dec.

refcnt_inc
refcnt_inc($raw_node);

Incrementa el contador de referencias del nodo crudo. El nodo crudo ya debe ser conocido por Perl para tener un contador de referencias.

refcnt_dec
refcnt_dec($raw_node);

Decrementa el contador de referencias del nodo crudo y devuelve el valor que tenía antes. Si el contador llega a cero o menos, este método liberará el nodo proxy que contiene el contador de referencias. Si el nodo es parte de un subárbol, refcnt_dec corregirá los contadores de referencias y eliminará el subárbol si ya no es necesario.

refcnt
refcnt($raw_node);

Devuelve el valor del contador de referencias.

fix_owner
fix_owner($raw_node, $raw_parent);

Esta función corrige los contadores de referencias para un subárbol completo. Es muy importante corregir un subárbol completo después de operaciones de nodo donde el documento o el nodo propietario puedan ser cambiados. este método es consciente de los nodos que ya pertenecen a un nodo propietario determinado.

DEPURACIÓN DE MEMORIA

$ENV{DEBUG_MEMORY}
BEGIN {$ENV{DEBUG_MEMORY} = 1;};
use XML::LibXML;

Esto activa la depuración de memoria de libxml2. Debe establecerse antes de cargar XML::LibXML.

mem_used
mem_used();

Devuelve el número de bytes actualmente asignados.

EXPORTACIÓN

Ninguna por defecto.
