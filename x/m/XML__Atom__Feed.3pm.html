XML::Atom::Feed(3pm) Documentación de Perl contribuida por usuarios XML::Atom::Feed(3pm)

NOMBRE

XML::Atom::Feed - Feed Atom

SINOPSIS

use XML::Atom::Feed;
use XML::Atom::Entry;
my $feed = XML::Atom::Feed->new;
$feed->title('Mi Weblog');
$feed->id('tag:example.com,2006:feed-id');
my $entry = XML::Atom::Entry->new;
$entry->title('Primera Publicación');
$entry->id('tag:example.com,2006:entry-id');
$entry->content('Cuerpo de la Publicación');
$feed->add_entry($entry);
$feed->add_entry($entry, { mode => 'insert' });
my @entries = $feed->entries;
my $xml = $feed->as_xml;
## Obtener una lista de las etiquetas <link rel="..." /> en el feed.
my $links = $feed->link;
## Encontrar todos los feeds de Atom en una página dada, usando descubrimiento automático.
my @uris = XML::Atom::Feed->find_feeds('http://www.example.com/');
## Usar descubrimiento automático para cargar el primer feed de Atom en una página dada.
my $feed = XML::Atom::Feed->new(URI->new('http://www.example.com/'));

USO

XML::Atom::Feed->new([ $stream ])

Crea un nuevo objeto de feed y, si se proporciona $stream, lo llena con los datos especificados por $stream.

Maneja automáticamente el descubrimiento automático si $stream es una URI (ver más abajo).

Devuelve el nuevo objeto XML::Atom::Feed. En caso de error, devuelve "undef".

$stream puede ser cualquiera de los siguientes:

  • Referencia a un escalar

    Esto se trata como el cuerpo XML del feed.

  • Escalar

    Esto se trata como el nombre de un archivo que contiene el XML del feed.

  • Filehandle

    Esto se trata como un filehandle abierto desde el cual se puede leer el XML del feed.

  • Objeto URI

    Esto se trata como una URI, y el XML del feed se recuperará de la URI.

    Si el tipo de contenido devuelto al obtener el contenido en la URI es text/html, este método intentará automáticamente realizar un descubrimiento automático buscando una etiqueta <link> que describa la URL del feed. Si se encuentra dicha URL, el XML del feed se recuperará automáticamente.

    Si la URI ya es de un feed, no es necesario ningún descubrimiento automático, y el XML del feed se recuperará y analizará normalmente.

XML::Atom::Feed->find_feeds($uri)

Dada una URI $uri, utiliza el descubrimiento automático para encontrar todos los feeds de Atom enlazados desde esa página (usando etiquetas <link>).

Devuelve una lista de URIs de feed.

$feed->link

Si se llama en contexto escalar, devuelve un objeto XML::Atom::Link correspondiente a la primera etiqueta <link> encontrada en el feed.

Si se llama en contexto de lista, devuelve una lista de objetos XML::Atom::Link correspondientes a todas las etiquetas <link> encontradas en el feed.

$feed->add_link($link)

Añade el enlace $link, que debe ser un objeto XML::Atom::Link, al feed como una nueva etiqueta <link>. Por ejemplo:

my $link = XML::Atom::Link->new;
$link->type('text/html');
$link->rel('alternate');
$link->href('http://www.example.com/');
$feed->add_link($link);

$feed->add_entry($entry)

Añade la entrada $entry, que debe ser un objeto XML::Atom::Entry, al feed. Si desea añadir una entrada antes de las entradas existentes, puede pasar una referencia hash opcional que contenga el valor "mode" establecido en "insert".

$feed->add_entry($entry, { mode => 'insert' });

$feed->entries

Devuelve una lista de objetos XML::Atom::Entry contenidos en el feed.

$feed->language

Devuelve el idioma del feed, desde xml:lang.

$feed->author([ $author ])

Devuelve un objeto XML::Atom::Person que representa al autor de la entrada, o "undef" si no hay información de autor presente.

Si se proporciona $author, debe ser un objeto XML::Atom::Person que represente al autor. Por ejemplo:

my $author = XML::Atom::Person->new;
$author->name('Foo Bar');
$author->email('foo@bar.com');
$feed->author($author);

$feed->id([ $id ])

Devuelve un ID para el feed. Si se proporciona $id, establece el ID. Al generar el nuevo feed, es su responsabilidad generar un ID único para el feed y establecerlo en el objeto XML::Atom::Feed. Puede usar un permalink http, el esquema URI tag o urn:uuid para mayor comodidad.

BANDERA UNICODE

Por defecto, XML::Atom elimina todas las banderas Unicode del contenido del feed. Por ejemplo,

my $title = $feed->title;

la variable $title contiene bytes UTF-8 sin la bandera Unicode activada, incluso si el título del feed contiene algunos caracteres multibyte.

Si no le gusta este comportamiento y desea manejar todo como caracteres Unicode (en lugar de bytes UTF-8), establezca la bandera $XML::Atom::ForceUnicode a 1.

$XML::Atom::ForceUnicode = 1;

entonces todos los datos devueltos por el objeto XML::Atom::Feed y el objeto XML::Atom::Entry, etc., tendrán la bandera Unicode activada.

La única excepción será "$entry->content->body", si el tipo de contenido no es text/* (por ejemplo, image/gif). En ese caso, el cuerpo del contenido sigue siendo datos binarios, sin la bandera Unicode activada.

CREACIÓN DE FEEDS ATOM 1.0

Por defecto, XML::Atom::Feed y otras clases (Entry, Link y Content) crearán entidades usando los espacios de nombres de Atom 0.3. Para crear elementos 1.0 de feed y entrada, puede establecer el parámetro Version, como:

$feed = XML::Atom::Feed->new(Version => 1.0);
$entry = XML::Atom::Entry->new(Version => 1.0);

Establecer estas Versiones en cada elemento puede ser a veces tedioso. En ese caso, puede sobrescribir el número de versión por defecto estableciendo la variable global $XML::Atom::DefaultVersion a "1.0".

use XML::Atom;
$XML::Atom::DefaultVersion = "1.0";
my $feed = XML::Atom::Feed->new;
$feed->title("blah");
my $entry = XML::Atom::Entry->new;
$feed->add_entry($entry);
$feed->version; # 1.0
