Licencias: LGPL-2.1-or-later

XmStringHasSubstring(llamada a biblioteca) XmStringHasSubstring(llamada a biblioteca)

NOMBRE

XmStringHasSubstring — Función de cadena compuesta que indica si una cadena compuesta está contenida dentro de otra

SINOPSIS

#include <Xm/Xm.h>
Boolean XmStringHasSubstring(
XmString string,
XmString substring);

DESCRIPCIÓN

XmStringHasSubstring indica si una cadena compuesta está contenida o no dentro de otra.

string
Especifica la cadena compuesta que se va a buscar.
substring
Especifica la cadena compuesta que se va a buscar.

RETORNO

Devuelve True si substring tiene un único componente de texto y si su texto está completamente contenido dentro de cualquier componente de texto individual de string; de lo contrario, devuelve False.

RELACIONADO

XmStringCreate(3) y XmStringCreateLocalized(3).
