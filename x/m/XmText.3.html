NOMBRE

XmText — La clase del widget Text

SINOPSIS

#include <Xm/Text.h>

DESCRIPCIÓN

Text proporciona un editor de texto de una sola línea y multilinea para personalizar las interfaces de usuario y programáticas. Se puede utilizar para la entrada de cadenas de una sola línea, entrada de formularios con procedimientos de verificación y edición de ventana completa. Proporciona a una aplicación un sistema de edición coherente para datos textuales. Los datos textuales de la pantalla se ajustan a las necesidades del escritor de la aplicación.

Text proporciona listas de devolución de llamada separadas para verificar el movimiento del cursor de inserción, la modificación del texto y los cambios en el foco de entrada. Cada una de estas devoluciones de llamada proporciona a la función de verificación la instancia del widget, el evento que causó la devolución de llamada y una estructura de datos específica del tipo de verificación. A partir de esta información, la función puede verificar si la aplicación considera que este es un cambio de estado legítimo y puede indicar al widget si debe continuar con la acción.

La interfaz de usuario adapta un nuevo conjunto de traducciones. Las traducciones predeterminadas proporcionan enlaces de teclas para el movimiento del cursor de inserción, la eliminación, la inserción y la selección de texto.

Text permite al usuario seleccionar regiones de texto. La selección se basa en el modelo especificado en el Inter-Client Communication Conventions Manual (ICCCM). Text admite la selección primaria y secundaria.

En algunos idiomas asiáticos, los textos se dibujan verticalmente. Además, algunos caracteres se muestran con una rotación de 90 grados en el sentido de las agujas del reloj, y otros caracteres se mapean a glifos verticales que difieren de los glifos horizontales normales. La información sobre qué caracteres requieren rotación o mapeo a glifos verticales se especifica en la Base de datos de locales de X (bases de datos NLS) y es manejada por la biblioteca X, dependiendo de los valores de XNOrientation XOC. El widget XmText también debería manejar las líneas alineadas verticalmente para editar, ingresar o seleccionar textos.

La característica de escritura vertical del widget XmText se habilita cuando se especifica el valor XmTOP_TO_BOTTOM para el recurso XmNlayoutDirection del widget XmText. En ese caso, la barra de desplazamiento horizontal se muestra en la parte inferior del widget XmText y la barra de desplazamiento vertical se muestra en el lado izquierdo.

Selección con el ratón

El widget Text permite editar, insertar y seleccionar texto. El usuario puede cortar, copiar y pegar texto utilizando el portapapeles, la transferencia primaria o la transferencia secundaria. Text también proporciona una función de arrastrar y soltar que permite al usuario copiar o mover datos dentro de Text o a un widget diferente. Cuando la política de foco de teclado se establece en EXPLICIT, el widget que recibe el foco es el widget de destino. En modo POINTER, cualquier operación de teclado o ratón (excepto la selección secundaria) en un widget editable establece ese widget como el destino.

Si un widget de destino se vuelve insensible o no editable, renuncia a su estado de destino. En modo EXPLICIT, cuando un widget se vuelve insensible, el foco se traslada a otro widget. Si ese widget es editable, se convierte en el widget de destino; de lo contrario, no hay widget de destino. El texto de cualquier widget Text insensible se muestra con puntos, indicando su estado al usuario.

El cursor de inserción, mostrado como una barra vertical, indica dónde se inserta la entrada. La entrada se inserta justo antes del cursor de inserción.

Text utiliza los rasgos XmQTnavigator, XmQTspecifyRenderTable y XmQTscrollFrame, y mantiene los rasgos XmQTaccessTextual y XmQTtransfer. El widget comprueba su padre en busca del rasgo XmQTscrollFrame. Si este rasgo no existe, entonces el widget no tiene desplazamiento. Si el rasgo existe y el widget ScrollFrame no se ha inicializado, el widget crea dos navegadores y configura las barras de desplazamiento.

Si una aplicación o widget llama al método de rasgo setValue de XmQTaccessTextual, entonces XmText llamará a XmTextSetString para establecer el valor de la cadena.

Comportamiento de transferencia de datos

Text admite la transferencia de las selecciones primaria, secundaria y del portapapeles, y el arrastre de texto seleccionado desde el widget. Text también puede ser el destino de las selecciones primaria, secundaria y del portapapeles, y admite la caída de datos que se arrastran sobre el widget.

Cuando se llaman los procedimientos de XmNconvertCallback, el miembro location_data del miembro XmConvertCallbackStruct es NULL si se está transfiriendo el texto seleccionado. Si se está transfiriendo el texto completo, no el texto seleccionado, el valor de este miembro es el ID del widget Text.

Como origen de datos, Text admite los siguientes destinos y las conversiones asociadas de datos a estos destinos:

locale
Si el destino locale coincide con el locale del widget, el widget transfiere el texto seleccionado en la codificación del locale.
COMPOUND_TEXT
El widget transfiere el texto seleccionado como tipo COMPOUND_TEXT.
STRING
El widget transfiere el texto seleccionado como tipo STRING.
TEXT
Si el texto seleccionado es completamente convertible a la codificación del locale, el widget transfiere el texto seleccionado en la codificación del locale. De lo contrario, el widget transfiere el texto seleccionado como tipo COMPOUND_TEXT.
UTF8_STRING
El widget transfiere el texto seleccionado como tipo UTF8_STRING.
DELETE
El widget elimina el texto seleccionado.
_MOTIF_CLIPBOARD_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos a los que el widget puede convertir datos para colocarlos en el portapapeles inmediatamente. Si el texto seleccionado es completamente convertible a STRING, estos incluyen STRING; de lo contrario, incluyen COMPOUND_TEXT.
_MOTIF_DEFERRED_CLIPBOARD_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que admite para transferencia diferida para la selección CLIPBOARD. Actualmente, este widget no proporciona destinos para _MOTIF_DEFERRED_CLIPBOARD_TARGETS.
_MOTIF_EXPORT_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que se utilizarán como valor de XmNexportTargets del DragContext en una transferencia de arrastrar y soltar. Estos incluyen COMPOUND_TEXT, UTF8_STRING, la codificación del locale, STRING, TEXT, BACKGROUND y FOREGROUND.
_MOTIF_LOSE_SELECTION
El widget realiza las siguientes acciones:
•
Al perder la selección PRIMARY, anula el resaltado del texto seleccionado y llama a los procedimientos XmNlosePrimaryCallback.
•
Al perder la selección SECONDARY, elimina el resaltado de la selección secundaria.
•
Al perder la selección _MOTIF_DESTINATION, si el widget no tiene el foco, cambia el cursor para indicar que el widget ya no es el destino.

CLIENT_WINDOW
El widget encuentra la primera shell en la jerarquía de widgets y transfiere su ventana como tipo WINDOW.

FOREGROUND

">FOREGROUND
El widget transfiere XmNforeground como tipo PIXEL.
NAME
El widget busca la primera ventana en la jerarquía de widgets que tiene una propiedad WM_NAME y transfiere su contenido como texto en la configuración regional actual.
TARGETS
El widget transfiere, como tipo ATOM, una lista de los objetivos que soporta. Estos incluyen los objetivos estándar de esta lista. También incluyen COMPOUND_TEXT, UTF8_STRING, la codificación de la configuración regional, STRING y TEXT.
TIMESTAMP
El widget transfiere la marca de tiempo utilizada para adquirir la selección como tipo INTEGER.
_MOTIF_RENDER_TABLE
El widget transfiere XmNrenderTable si existe, o bien la tabla de renderizado de texto predeterminada, como tipo STRING.
_MOTIF_ENCODING_REGISTRY
El widget transfiere su registro de codificación como tipo STRING. El valor es una lista de elementos separados por NULL en forma de pares de etiqueta y codificación. Este objetivo simboliza el objetivo de transferencia para el Registro de Codificación de Segmentos de Motif. Los widgets y las aplicaciones pueden utilizar este Registro para registrar formatos de codificación de texto para etiquetas de tabla de renderizado especificadas. Las aplicaciones acceden a este Registro llamando a XmRegisterSegmentEncoding y XmMapSegmentEncoding.

XmNcursorPosition
Indica la posición en el texto donde se ubicará el cursor de inserción actual. La posición se determina por el número de caracteres desde el principio del texto. La primera posición de carácter es 0 (cero).
XmNcursorPositionVisible
Si el widget tiene un XmPrintShell como uno de sus ancestros, el valor predeterminado es False; de lo contrario, es True.
XmNdestinationCallback
Especifica una lista de callbacks que se llaman cuando el widget es el destino de una operación de transferencia. El tipo de la estructura cuya dirección se pasa a estos callbacks es XmDestinationCallbackStruct. La razón es XmCR_OK.

Specifies whether the cursor position should be automatically shown when the widget receives focus. When this resource is True, the cursor is automatically moved to the position specified by XmNcursorPosition when the widget gains focus. Otherwise, the cursor position remains unchanged.
XmNblinkRate
Controls the blink rate of the cursor. The value is specified in milliseconds. A value of 0 disables blinking. The default value is implementation-dependent (typically 500).
XmNcursorPosition
Specifies the initial cursor position in the text. The position is an index into the text string, where 0 represents the beginning of the text. The default value is 0.
XmNcursorPositionVisible
Controls the visibility of the cursor. When True, the cursor is visible. When False, the cursor is hidden. The default value is True.
XmNdisplayHotKeys
Specifies whether hot key mnemonics are displayed in the text widget. When True, accelerators are displayed as underlined characters. The default is implementation-dependent.
XmNeditMode
Specifies the editing mode of the Text widget. The possible values are XmSINGLE_LINE_EDIT and XmMULTI_LINE_EDIT. The default value is XmMULTI_LINE_EDIT.

If the list contains no font sets, the first font in the font list will be used. Refer to XmFontList(3) for more information on a font list structure.

The Text widget defines a new callback structure for use with verification callbacks. Note that not all fields are relevant for every callback reason. The application must first look at the reason field and use only the structure members that are valid for the particular reason. The values startPos, endPos, and text in the callback structure XmTextVerifyCallbackStruct may be modified when the callback is received, and these changes will be reflected as changes made to the source of the Text widget. (For example, all keystrokes can be converted to spaces or NULL characters when a password is entered into a Text widget.) The application programmer should not overwrite the text field, but should attach data to that pointer.

Alterna el estado del modo de inserción de texto. Por defecto, los caracteres escritos en el widget Text se insertan en la posición del cursor de inserción. En modo de sobrescritura, los caracteres introducidos en el widget Text reemplazan los caracteres que siguen inmediatamente al cursor de inserción. En modo de sobrescritura, al llegar al final de una línea, los caracteres se añaden al final de la línea.
Las siguientes acciones de desplazamiento generan callbacks solo si resultan en la pérdida de foco del widget en cuestión, como cuando XmNnavigationType es XmNONE. En este caso, producen llamadas a los procedimientos XmNlosingFocusCallback, con el valor de razón XmCR_FOCUS_MOVED.
traverse-home():
Se desplaza al primer widget del grupo de tabulación.
traverse-next():
Se desplaza al siguiente widget del grupo de tabulación.
traverse-prev():
Se desplaza al widget anterior del grupo de tabulación.
unkill():
Restaura el último texto eliminado a la posición del cursor de inserción (o lo que sea que esté actualmente en el CUT_BUFFER0). El texto insertado aparece antes del cursor de inserción.
La acción unkill() produce llamadas a los procedimientos XmNmodifyVerifyCallback con el valor de razón XmCR_MODIFYING_TEXT_VALUE, los procedimientos XmNvalueChangedCallback con el valor de razón XmCR_VALUE_CHANGED, y los procedimientos XmNmotionVerifyCallback con el valor de razón XmCR_MOVING_INSERT_CURSOR.

Comportamiento Adicional

Este widget tiene el siguiente comportamiento adicional:

<FocusIn>:
Dibuja el cursor de inserción sólido y comienza a parpadear el cursor.
<FocusOut>:
Muestra el cursor de inserción como una viga en I punteada, a menos que sea el widget de destino, y detiene el parpadeo del cursor.
