XML::Atom::Entry(3pm) Documentación de Perl aportada por el usuario XML::Atom::Entry(3pm)

NOMBRE

XML::Atom::Entry - Entrada de Atom

SINOPSIS

use XML::Atom::Entry;
my $entry = XML::Atom::Entry->new;
$entry->title('Mi publicación');
$entry->content('El contenido de mi publicación.');
my $xml = $entry->as_xml;
my $dc = XML::Atom::Namespace->new(dc => 'http://purl.org/dc/elements/1.1/');
$entry->set($dc, 'subject', 'Comida y bebida');

USO

XML::Atom::Entry->new([ $flujo ])

Crea un nuevo objeto de entrada y, si se proporciona $flujo, lo llena con los datos especificados por $flujo.

Maneja automáticamente la autodetección si $flujo es una URI (ver más abajo).

Devuelve el nuevo objeto XML::Atom::Entry. En caso de error, devuelve "undef".

$flujo puede ser cualquiera de los siguientes:

  • Referencia a un escalar

    Esto se trata como el cuerpo XML de la entrada.

  • Escalar

    Esto se trata como el nombre de un archivo que contiene el XML de la entrada.

  • Filehandle

    Esto se trata como un filehandle abierto desde el cual se puede leer el XML de la entrada.

$entrada->contenido([ $contenido ])

Devuelve el contenido de la entrada. Si se proporciona $contenido, establece el contenido de la entrada. Maneja automáticamente todo el escape necesario.

$entrada->autor([ $autor ])

Devuelve un objeto XML::Atom::Person que representa al autor de la entrada, o "undef" si no hay información del autor presente.

Si se proporciona $autor, debe ser un objeto XML::Atom::Person que represente al autor. Por ejemplo:

my $autor = XML::Atom::Person->new;
$autor->name('Foo Bar');
$autor->email('foo@bar.com');
$entrada->autor($autor);

$entrada->enlace

Si se llama en contexto escalar, devuelve un objeto XML::Atom::Link correspondiente a la primera etiqueta <link> encontrada en la entrada.

Si se llama en contexto de lista, devuelve una lista de objetos XML::Atom::Link correspondientes a todas las etiquetas <link> encontradas en la entrada.

$entrada->agregar_enlace($enlace)

Agrega el enlace $enlace, que debe ser un objeto XML::Atom::Link, a la entrada como una nueva etiqueta <link>. Por ejemplo:

my $enlace = XML::Atom::Link->new;
$enlace->type('text/html');
$enlace->rel('alternate');
$enlace->href('http://www.example.com/2003/12/post.html');
$entrada->agregar_enlace($enlace);

$entrada->obtener($ns, $elemento)

Dado un elemento XML::Atom::Namespace $ns y un nombre de elemento $elemento, recupera el valor del elemento en ese namespace.

Esto es útil para recuperar el valor de elementos que no están en el namespace principal de Atom, como las categorías. Por ejemplo:

my $dc = XML::Atom::Namespace->new(dc => 'http://purl.org/dc/elements/1.1/');
my $subj = $entrada->obtener($dc, 'subject');

$entrada->obtener_lista($ns, $elemento)

Al igual que $entrada->obtener, pero si hay varias instancias del elemento $elemento en el namespace $ns, devuelve todas ellas. obtener devolverá solo la primera.
