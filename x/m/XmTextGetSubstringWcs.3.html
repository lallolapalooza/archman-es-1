Licencias: LGPL-2.1-or-later

NOMBRE

XmTextGetSubstringWcs — Una función de Texto que recupera una porción de un búfer de texto interno de caracteres anchos

SINOPSIS

#include <Xm/Text.h>
int XmTextGetSubstringWcs(
Widget widget,
XmTextPosition start,
int num_chars,
int buffer_size,
wchar_t *buffer);

DESCRIPCIÓN

XmTextGetSubstringWcs recupera una copia de una porción del búfer de texto interno de un widget Text que se almacena en formato de caracteres anchos. La función copia un número especificado de caracteres desde una posición de inicio dada en el búfer de texto interno a un búfer proporcionado por la aplicación. Se coloca un terminador NULL al final de los datos copiados.

widget
Especifica el ID del widget Text.
start
Especifica la posición del carácter inicial desde la cual se recuperarán los datos. Es un número entero de caracteres desde el principio del búfer de texto. La primera posición de carácter es 0 (cero).
num_chars
Especifica el número de caracteres wchar_t que se copiarán en el búfer proporcionado.
buffer_size
Especifica el tamaño del búfer suministrado como número de ubicaciones de almacenamiento wchar_t. El tamaño mínimo es num_chars + 1.
buffer
Especifica el búfer de caracteres anchos en el que se copiará el búfer de texto interno.

Para una definición completa de Text y sus recursos asociados, consulte XmText(3).

RETORNO

XmCOPY_SUCCEEDED
La función fue exitosa.
XmCOPY_FAILED
La función falló porque no pudo copiar el número especificado de caracteres en el búfer proporcionado. El tamaño del búfer puede ser insuficiente. El contenido de buffer no está definido.
XmCOPY_TRUNCATED
El número de caracteres solicitado se extendió más allá del búfer interno. La función copió caracteres entre start y el final del búfer del widget y terminó la cadena con un terminador NULL; se copiaron menos de num_chars caracteres.

RELACIONADOS

XmText(3) y XmTextGetSubstring(3).
