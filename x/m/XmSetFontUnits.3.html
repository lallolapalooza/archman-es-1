NOMBRE

XmSetFontUnits — Una función que establece el valor de las unidades de fuente para una pantalla

SINOPSIS

#include <Xm/Xm.h>
void XmSetFontUnits(
Display * display,
int h_value,
int v_value);

DESCRIPCIÓN

XmSetFontUnits proporciona una función externa para inicializar los valores de las unidades de fuente. Las aplicaciones pueden querer especificar datos independientes de la resolución basándose en un tamaño de fuente global. Esta función debe ser llamada antes de que se creen widgets con datos independientes de la resolución. Consulte la descripción del recurso XmNunitType en las páginas de referencia de XmGadget, XmManager y XmPrimitive para obtener más información sobre la independencia de la resolución.

Esta función establece las unidades de fuente para todas las pantallas de la pantalla.

NOTA: XmSetFontUnits es obsoleto y existe por compatibilidad con versiones anteriores. En lugar de usar esta función, proporcione valores iniciales o llame a XtSetValues para los recursos XmScreen XmNhorizontalFontUnit y XmNverticalFontUnit.

display
Define la pantalla para la que se aplicará este valor de unidad de fuente.
h_value
Especifica el valor que se utilizará para las unidades horizontales en los cálculos de conversión.
h_value
Especifica el valor que se utilizará para las unidades verticales en los cálculos de conversión.

RELACIONADO

XmConvertUnits(3), XmSetFontUnit(3), XmGadget(3), XmManager(3), XmPrimitive(3), y XmScreen(3).
