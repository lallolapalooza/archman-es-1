XmVaCreateHierarchy(llamada a biblioteca) XmVaCreateHierarchy(llamada a biblioteca)

NOMBRE

XmVaCreateHierarchy, XmVaCreateManagedHierarchy — Funciones de conveniencia para la creación de widgets de Jerarquía.

SINOPSIS

#include <Xm/Hierarchy.h>
Widget XmVaCreateHierarchy(
Widget parent,
String name,
...);
Widget XmVaCreateManagedHierarchy(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget Jerarquía y devuelven el ID de widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos de longitud variable (varargs) de ANSI C.

La función XmVaCreateHierarchy es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreateManagedHierarchy es una rutina de conveniencia que llama a XtCreateManagedWidget.

padre
Especifica el ID del widget padre.
nombre
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de Jerarquía y sus recursos asociados, consulte XmHierarchy(3).

RETORNO

Devuelve el ID del widget Jerarquía.

RELACIONADOS

XmCreateHierarchy(3), XtCreateWidget(3), XtCreateManagedWidget(3), y XmHierarchy(3).
