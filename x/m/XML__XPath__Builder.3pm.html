NOMBRE

XML::XPath::Builder - Manejador SAX para construir un árbol XPath

SINOPSIS

use AnySAXParser;
use XML::XPath::Builder;
$builder = XML::XPath::Builder->new();
$parser = AnySAXParser->new( Handler => $builder );
$root_node = $parser->parse( Source => [FUENTE] );

DESCRIPCIÓN

"XML::XPath::Builder" es un manejador SAX para construir un árbol XML::XPath.

"XML::XPath::Builder" se usa creando una nueva instancia de "XML::XPath::Builder" y proporcionándola como el Handler para un analizador SAX. Llamar a `parse()' en el analizador SAX devolverá el nodo raíz del árbol construido a partir de ese análisis.
