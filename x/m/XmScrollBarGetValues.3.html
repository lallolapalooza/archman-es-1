NOMBRE

XmScrollBarGetValues — Una función de ScrollBar que devuelve los valores de incremento del ScrollBar

SINOPSIS

#include <Xm/ScrollBar.h>
void XmScrollBarGetValues (widget, value_return, slider_size_return,
increment_return, page_increment_return)
        Widget  widget;
        int     * value_return;
        int     * slider_size_return;
        int     * increment_return;
        int     * page_increment_return;
(void)

DESCRIPCIÓN

XmScrollBarGetValues devuelve los valores de incremento del ScrollBar. La región de desplazamiento está superpuesta con una barra deslizante que se ajusta en tamaño y posición utilizando los atributos de la función principal del ScrollBar o del deslizador establecido.

widget
Especifica el ID del widget ScrollBar.
value_return
Devuelve la posición del deslizador del ScrollBar entre los recursos XmNminimum y XmNmaximum. Especifique NULL para evitar la devolución de un valor particular.
slider_size_return
Devuelve el tamaño del deslizador como un valor entre 0 (cero) y el valor absoluto de XmNmaximum menos XmNminimum. El tamaño del deslizador varía, dependiendo de cuánto del área de desplazamiento del deslizador representa.
increment_return
Devuelve la cantidad de incremento y decremento.
page_increment_return
Devuelve la cantidad de incremento y decremento de página.

Para una definición completa de ScrollBar y sus recursos asociados, vea XmScrollBar(3).

RETORNAR

Devuelve los valores de incremento del ScrollBar.

RELACIONADO

XmScrollBar(3).
