NOMBRE

XmTrackingEvent — Una función del Toolkit que proporciona una interacción modal

SINOPSIS

#include <Xm/Xm.h>
Widget XmTrackingEvent(
Widget widget,
Cursor cursor,
Boolean confine_to,
XEvent *event_return);

DESCRIPCIÓN

XmTrackingEvent proporciona una interfaz modal para la selección de un componente. Está pensado para soportar la ayuda contextual. La función llama a la función XmUpdateDisplay. Luego, XmTrackingEvent captura el puntero y descarta los eventos subsiguientes hasta que se suelta BSelect o se presiona y suelta una tecla. Luego, la función devuelve el widget o gadget que contiene el puntero cuando se suelta BSelect o se suelta una tecla, y libera la captura del puntero.

widget
Especifica el ID del widget a utilizar como base de la interacción modal. Es decir, el widget dentro del cual debe ocurrir la interacción, usualmente una ventana de nivel superior (shell).
cursor
Especifica el cursor a utilizar para el puntero durante la interacción. Este es un nombre de cursor X estándar.
confine_to
Especifica si el cursor debe o no ser confinado a widget.
event_return
Devuelve el evento ButtonRelease o KeyRelease que causa que la función retorne.

RETORNO

Devuelve el widget o gadget que contiene el puntero cuando se suelta BSelect o se suelta una tecla. Si ningún widget o gadget contiene el puntero, la función devuelve NULL.
