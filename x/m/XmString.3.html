NOMBRE

XmString — Tipo de dato para una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

XmString es el tipo de dato para una cadena compuesta. Las cadenas compuestas consisten en una secuencia de componentes, incluyendo, pero no limitándose a, los siguientes:

•
XmSTRING_COMPONENT_SEPARATOR
•
XmSTRING_COMPONENT_TAB
•
XmSTRING_COMPONENT_LAYOUT_POP
•
XmSTRING_COMPONENT_DIRECTION
•
XmSTRING_COMPONENT_LAYOUT_PUSH
•
XmSTRING_COMPONENT_CHARSET
•
XmSTRING_COMPONENT_FONTLIST_ELEMENT_TAG
•
XmSTRING_COMPONENT_LOCALE
•
XmSTRING_COMPONENT_LOCALE_TEXT
•
XmSTRING_COMPONENT_TAG
•
XmSTRING_COMPONENT_TEXT
•
XmSTRING_COMPONENT_END
•
XmSTRING_COMPONENT_RENDITION_BEGIN
•
XmSTRING_COMPONENT_RENDITION_END
•
XmSTRING_COMPONENT_UNKNOWN
•
XmSTRING_COMPONENT_WIDECHAR_TEXT

y también una tabla de etiquetas de representación, texto y componente de texto. Cuando se muestra una cadena compuesta, las etiquetas de representación y la dirección se utilizan para determinar cómo mostrar el texto.

Al llamar a XtGetValues para un recurso cuyo tipo es XmString, se obtiene una copia del valor del recurso de cadena compuesta. La aplicación es responsable de usar XmStringFree para liberar la memoria asignada para la copia.

Por favor, consulte la página de referencia XmStringComponentType para obtener más detalles sobre los componentes de cadena compuesta y una descripción del orden en que deben aparecer los componentes en una cadena compuesta. Consulte la página de referencia XmRenderTable para obtener una descripción del algoritmo que asocia las etiquetas de representación utilizadas para mostrar un componente de texto de cadena compuesta con una representación en una tabla de representaciones.
