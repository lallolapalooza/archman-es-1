NOMBRE

XmTabListFree — Una función de conveniencia que libera la memoria de una nueva lista de pestañas

SINOPSIS

#include <Xm/Xm.h>
void XmTabListFree(
XmTabList tablist);

DESCRIPCIÓN

XmTabListFree recupera memoria utilizada por una lista de pestañas. Además, esta función libera todas las pestañas contenidas. Si tablist es NULL, la función regresa inmediatamente.

tablist
Especifica la lista de pestañas a liberar.

RELACIONADO

XmTabList(3).
