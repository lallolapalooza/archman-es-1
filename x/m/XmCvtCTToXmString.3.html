NOMBRE

XmCvtCTToXmString — Una función de cadena compuesta que convierte texto compuesto a una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmString XmCvtCTToXmString(
char * texto);

DESCRIPCIÓN

XmCvtCTToXmString convierte una cadena (char *) en formato de texto compuesto a una cadena compuesta. La aplicación debe llamar a XtAppInitialize antes de llamar a esta función. La conversión de texto compuesto a cadenas compuestas depende de la implementación.

texto
Especifica una cadena en formato de texto compuesto para ser convertida a una cadena compuesta.

RETORNO

Devuelve una cadena compuesta derivada del texto compuesto. La función asigna espacio para contener la cadena compuesta devuelta. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmStringFree. Se asume que el texto compuesto está terminado en NULL; los NULL dentro del texto compuesto se manejan correctamente. El manejo de caracteres de control de TABULADOR HORIZONTAL (HT) dentro del texto compuesto no está definido. El formato de texto compuesto se describe en el estándar X Consortium Compound Text Encoding.

RELACIONADOS
