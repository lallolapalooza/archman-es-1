NOMBRE

XmGetTabGroup — Devuelve el ID del widget de un grupo de pestañas

SINOPSIS

#include <Xm/Xm.h>
Widget XmGetTabGroup(
Widget widget);

DESCRIPCIÓN

XmGetTabGroup devuelve el ID del widget del grupo de pestañas que contiene el widget especificado.

widget
Especifica un ID de widget dentro de un grupo de pestañas.

RETORNO

Devuelve el ID del widget de un grupo de pestañas o una ventana, determinado de la siguiente manera:

•
Si widget es un grupo de pestañas o una ventana, devuelve widget.
•
Si ni widget ni ningún ancestro hasta la ventana más cercana es un grupo de pestañas, devuelve el ancestro más cercano de widget que sea una ventana.
•
De lo contrario, devuelve el ancestro más cercano de widget que sea un grupo de pestañas.

RELACIONADOS

XmAddTabGroup(3), XmManager(3), y XmPrimitive(3).
