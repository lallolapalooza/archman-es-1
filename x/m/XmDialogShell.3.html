NOMBRE

XmDialogShell — La clase de widget DialogShell

SINOPSIS

#include <Xm/DialogS.h>

DESCRIPCIÓN

Los diálogos modales y no modales utilizan DialogShell como padre Shell. Los widgets DialogShell no pueden ser minimizados. En su lugar, todos los widgets DialogShell secundarios asociados con un widget ApplicationShell se minimizan y restauran como un grupo con el widget principal.

El cliente manipula indirectamente DialogShell a través de las interfaces de conveniencia durante la creación, y puede manipular directamente su hijo derivado de BulletinBoard. Gran parte de la funcionalidad de DialogShell asume que su hijo es una subclase de BulletinBoard, aunque potencialmente puede funcionar de forma independiente.

Establecer XmNheight, XmNwidth o XmNborderWidth para un DialogShell o su hijo gestionado generalmente establece ese recurso al mismo valor en ambos, el padre y el hijo. Cuando existe un método de entrada "off-the-spot", la altura y el ancho del shell pueden ser mayores que los del hijo gestionado para acomodar el método de entrada. En este caso, establecer XmNheight o XmNwidth para el shell no necesariamente establece ese recurso al mismo valor en el hijo gestionado, y establecer XmNheight o XmNwidth para el hijo no necesariamente establece ese recurso al mismo valor en el shell.

Para el hijo gestionado de un DialogShell, independientemente del valor del recurso XmNallowShellResize del shell, establecer XmNx o XmNy establece el recurso correspondiente del padre pero no cambia la posición del hijo en relación con el padre. El recurso XtGetValues para XmNx o XmNy del hijo devuelve el valor del recurso correspondiente en el padre. Las coordenadas x e y de la esquina superior izquierda exterior del hijo relativas a la esquina superior izquierda interior del padre son ambas 0 (cero) menos el valor de XmNborderWidth.

Tenga en cuenta que el *Manual de Convenciones de Comunicación Inter-cliente* (ICCCM) permite a un administrador de ventanas cambiar o controlar el ancho del borde de una ventana de nivel superior reparentada.

DialogShell utiliza el rasgo XmQTdialogShellSavvy.

CLASES

DialogShell hereda comportamiento, recursos y rasgos de las clases Core, Composite, Shell, WMShell, VendorShell y TransientShell.

El puntero de clase es xmDialogShellWidgetClass.

El nombre de la clase es XmDialogShell.

NUEVOS RECURSOS

DialogShell no define nuevos recursos, pero anula el recurso XmNdeleteResponse de la clase VendorShell.

RECURSOS HEREDADOS

DialogShell hereda comportamiento y recursos de las superclases descritas en las siguientes tablas, que definen conjuntos de recursos de widget utilizados por el programador para especificar datos.

Para una descripción completa de cada recurso, consulte la página de referencia de esa superclase. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los subrayados entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o no es aplicable (N/A).

NAME

XmDialogShell — A dialog shell widget

SYNOPSIS

#include <Xm/DialogS.h>

A dialog shell widget is created by calling:

widget = XmCreateDialogShell(parent, name, arglist);
widget = XmCreatePopupMenuShell(parent, name, arglist);
widget = XmCreateDropdownMenuShell(parent, name, arglist);

DESCRIPTION

The XmDialogShell widget is a subclass of the XmShell widget. It is intended for creating dialog boxes. Dialog shells have certain constraints that are useful for dialogs, such as prohibiting the user from manipulating the dialog shell's geometry directly.

The XmDialogShell widget is a subclass of the XmShell widget and is subclassed by XmBulletinBoard, XmMessageBox, etc.

A dialog shell provides an environment for creating dialog boxes. The parent of a dialog shell must be a shell widget.

The functions XmCreateDialogShell, XmCreatePopupMenuShell, and XmCreateDropdownMenuShell create a dialog shell widget.

A dialog shell is a subclass of XmShell, which is a subclass of Core. The following table lists the dialog shell widgets and their associated resources.
