NOMBRE

XmDropSiteQueryStackingOrder — Una función de Arrastrar y Soltar que devuelve el padre, una lista de hijos y el número de hijos para un widget especificado

SINOPSIS

#include <Xm/DragDrop.h>
Status XmDropSiteQueryStackingOrder(
Widget widget,
Widget *parent_return,
Widget **child_returns,
Cardinal *num_child_returns);

DESCRIPCIÓN

XmDropSiteQueryStackingOrder obtiene el padre, una lista de hijos registrados como sitios de destino y el número de hijos registrados como sitios de destino para un widget dado. Los hijos se enumeran en orden de apilamiento actual, desde el más bajo (primer hijo) hasta el más alto (último hijo). Esta función asigna memoria para los datos devueltos que deben liberarse llamando a XtFree.

widget
Especifica el ID del widget. Para este widget, se obtiene la lista de sus hijos, su padre y el número de hijos.
parent_return
Devuelve el ID del widget padre del sitio de destino del widget especificado.
child_returns
Devuelve un puntero a la lista de hijos de sitios de destino asociados con el widget especificado. La función asigna memoria para mantener la lista. La aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XtFree.
num_child_returns
Devuelve el número de hijos de sitios de destino para el widget especificado.

Para una definición completa de DropSite y sus recursos asociados, consulte XmDropSite(3).

RETORNO

Devuelve 0 (cero) si la rutina falla; devuelve un valor distinto de cero si tiene éxito.

RELACIONADO

XmDropSite(3) y XmDropSiteConfigureStackingOrder(3).
