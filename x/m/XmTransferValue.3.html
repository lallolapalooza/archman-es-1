NOMBRE

XmTransferValue -- Una función del toolkit que transfiere datos a un destino

SINOPSIS

#include <Xm/Xm.h>

void XmTransferValue(
XtPointer transfer_id,
Atom target,
XtCallbackProc proc,
XtPointer client_data,
Time time);

DESCRIPCIÓN

XmTransferValue convierte una selección, transfiriendo cualquier dato del propietario de la selección, en el contexto de una operación de transferencia de datos ya iniciada. Una aplicación puede llamar a esta rutina desde un procedimiento XmNdestinationCallback o cualquier función llamada como resultado.

El llamador de XmTransferValue proporciona el destino al que se convierte la selección. El llamador también proporciona un procedimiento de devolución de llamada para manejar los datos resultantes de la conversión.

transfer_id
Especifica un identificador único para la operación de transferencia de datos. El valor debe ser el mismo que el valor del miembro transfer_id de la XmDestinationCallbackStruct pasada al procedimiento XmNdestinationCallback.
target
Especifica el destino al que se va a convertir la selección.
proc
Especifica un procedimiento de devolución de llamada que se invocará cuando la selección se haya convertido y los datos, si los hay, estén disponibles. Este procedimiento es responsable de insertar o manejar de otro modo cualquier dato transferido. El procedimiento también puede finalizar la transferencia de datos llamando a XmTransferDone. El proc recibe tres argumentos:
•
El widget que solicitó la conversión
•
El valor del argumento client_data
•
Un puntero a una XmSelectionCallbackStruct
Este procedimiento puede ser llamado antes o después de que XmTransferValue retorne.
client_data
Especifica los datos que se pasarán al procedimiento de devolución de llamada (el valor del argumento proc) cuando la selección se haya convertido.
time
Especifica la hora del XEvent que activó la transferencia de datos. Normalmente, deberías establecer este campo en XtLastTimestampProcessed.

El procedimiento de devolución de llamada (el valor del argumento proc) recibe un puntero a una XmSelectionCallbackStruct, que tiene la siguiente definición:

typedef struct
{
        int reason;
        XEvent *event;
        Atom selection;
        Atom target;
        Atom type;
        XtPointer transfer_id;
        int flags;
        int remaining;
        XtPointer value;
        unsigned long length;
        int format;
} XmSelectionCallbackStruct;
reason
Indica por qué se invocó la devolución de llamada.
event
Punta al XEvent que activó la devolución de llamada. Puede ser NULL.
selection
Especifica la selección que se ha convertido.
target
Especifica el destino al que XmTransferValue solicitó la conversión. El valor es el mismo que el valor del argumento target a XmTransferValue.
type
Especifica el tipo del valor de la selección. Este no es el destino, sino el tipo utilizado para representar el destino. El valor XT_CONVERT_FAIL significa que el propietario de la selección no respondió a la solicitud de conversión dentro del intervalo de tiempo de espera de selección de los Intrinsics.
transfer_id
Especifica un identificador único para la operación de transferencia de datos. El valor es el mismo que el valor del argumento transfer_id a XmTransferValue.
flags
Este miembro no se utiliza actualmente. El valor es siempre XmSELECTION_DEFAULT.
remaining
Indica el número de transferencias restantes para la operación especificada por transfer_id.
value
Representa los datos transferidos por esta solicitud. La aplicación es responsable de liberar el valor llamando a XtFree.
length
Indica el número de elementos de datos en value, donde cada elemento tiene el tamaño simbolizado por format. Si value es NULL, length es 0.
format
Indica si los datos en value deben considerarse como una lista de cantidades char, short o long. Los valores posibles son 8 (para una lista de char), 16 (para una lista de short) o 32 (para una lista de long).
