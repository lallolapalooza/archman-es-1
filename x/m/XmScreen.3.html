NOMBRE

XmScreen — La clase del widget Screen

SINOPSIS

#include <Xm/Screen.h>

DESCRIPCIÓN

El objeto XmScreen es utilizado por los widgets de Motif para almacenar información específica de una pantalla. También permite que el toolkit almacene cierta información en jerarquías de widgets que de otro modo no estaría disponible. Cada cliente tiene un objeto XmScreen por cada pantalla a la que accede.

Un objeto XmScreen se crea automáticamente cuando la aplicación crea la primera shell en una pantalla (normalmente logrado mediante una llamada a XtAppInitialize o XtAppCreateShell). No es necesario crear un objeto XmScreen por ningún otro medio. Una aplicación puede utilizar la función XmGetXmScreen para obtener el ID del widget del objeto XmScreen para una pantalla dada.

Una aplicación no puede proporcionar valores iniciales para los recursos de XmScreen como argumentos en una llamada a cualquier función que cree widgets. La aplicación o el usuario pueden proporcionar valores iniciales en un archivo de recursos. Después de crear la primera shell en la pantalla, la aplicación puede utilizar XmGetXmScreen para obtener el ID del widget del objeto XmScreen y luego llamar a XtSetValues para establecer los recursos de XmScreen.

Clases

Screen hereda comportamiento y recursos de Core.

El puntero de clase es xmScreenClass.

El nombre de la clase es XmScreen.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer mediante XtSetValues (S), recuperar mediante XtGetValues (G), o no es aplicable (N/A).

XmNbitmapConversionModel
Proporciona una política para la conversión de archivos xbm y xpm al tipo Pixmap. Este recurso toma los siguientes valores:
XmMATCH_DEPTH
A partir de un archivo xbm o xpm proporcionado, genera un archivo pixmap convertido que tiene la misma profundidad que el widget.
XmDYNAMIC_DEPTH
Convierte un archivo xbm de entrada a un Pixmap de profundidad 1, o convierte un archivo xpm de entrada a un Pixmap con la misma profundidad que el widget.
XmNcolorAllocationProc
Identifica el procedimiento que se utilizará para la asignación de color. Normalmente, este procedimiento es un procedimiento de asignación de color definido por la aplicación. Sin embargo, si no se establece ningún procedimiento de asignación de color definido por la aplicación, el sistema utiliza el procedimiento de asignación de color predefinido de Motif.
XmNcolorCalculationProc
Identifica el procedimiento que se utilizará para el cálculo de color por widget. Normalmente, este procedimiento es un procedimiento de cálculo de color definido por la aplicación. Sin embargo, si no se establece ningún procedimiento de cálculo de color definido por la aplicación, el sistema utiliza el procedimiento de cálculo de color predefinido de Motif.
XmNdarkThreshold
Un entero entre 0 (cero) y 100, inclusive, que especifica un nivel de brillo percibido para un color. Si el brillo percibido del color de fondo está por debajo de este nivel, Motif trata el fondo como "oscuro" al calcular los colores predeterminados de sombra y selección. Si este recurso se especifica para una pantalla particular, se aplica a los widgets creados en esa pantalla; de lo contrario, se aplica a los widgets creados en todas las pantallas. El valor predeterminado depende de la implementación.
XmNdefaultCopyCursorIcon
Especifica el DragIcon utilizado durante una operación de arrastre cuando la operación es una copia y la aplicación no especifica ningún otro pixmap. Si este recurso es NULL, se utiliza un icono predeterminado del sistema. El icono predeterminado del sistema está determinado por el recurso de visualización XmNenableDragIcon.
XmNdefaultInvalidCursorIcon
Especifica el DragIcon utilizado para indicar que el cursor está sobre un sitio de colocación no válido durante una operación de arrastre cuando la aplicación no especifica ningún otro símbolo de pixmap. Si este recurso es NULL, se utiliza un icono predeterminado del sistema. El icono predeterminado del sistema está determinado por el recurso de visualización XmNenableDragIcon.
XmNdefaultLinkCursorIcon
Especifica el DragIcon utilizado durante una operación de arrastre cuando la operación es un enlace y la aplicación no especifica ningún otro pixmap. Si este recurso es NULL, se utiliza un icono predeterminado del sistema. El icono predeterminado del sistema está determinado por el recurso de visualización XmNenableDragIcon.
XmNdefaultMoveCursorIcon
Especifica el DragIcon utilizado durante una operación de arrastre cuando la operación es un movimiento y la aplicación no especifica ningún otro pixmap. Si este recurso es NULL, se utiliza un icono predeterminado del sistema. El icono predeterminado del sistema está determinado por el recurso de visualización XmNenableDragIcon.
XmNdefaultNoneCursorIcon
Especifica el DragIcon utilizado para indicar que el cursor no está sobre un sitio de colocación durante una operación de arrastre cuando la aplicación no especifica ningún otro pixmap. Especifica una fuente para su uso en el cálculo de valores para XmNhorizontalFontUnit y XmNverticalFontUnit. Un entero entre 0 (cero) y 100, inclusive, que especifica un nivel de brillo percibido para un color. Si el brillo percibido del color de fondo es igual o inferior a este nivel, Motif trata el fondo como "oscuro" al calcular los colores predeterminados de primer plano y resaltado. XmNhorizontalFontUnit
Especifica el componente horizontal de las unidades de fuente utilizadas por XmConvertUnits y se utiliza para interpretar los valores de los recursos de geometría cuando el recurso XmNshellUnitType de VendorShell o el recurso XmNunitType de Gadget, Manager o Primitive tiene el valor Xm100TH_FONT_UNITS. Si no se proporciona un valor inicial para este recurso, el valor predeterminado se calcula a partir de la fuente especificada en XmNfont. Si no se proporciona un valor inicial para este recurso o para XmNfont, el valor predeterminado es 10.
Si una llamada a XtSetValues especifica un valor para XmNhorizontalFontUnit, este recurso se establece en ese valor. Si una llamada a XtSetValues especifica un valor para XmNfont pero no para XmNhorizontalFontUnit, este recurso se establece en un valor calculado a partir del nuevo XmNfont.
Una unidad de fuente horizontal se deriva de una fuente de la siguiente manera:
•
Si la fuente tiene una propiedad AVERAGE_WIDTH, la unidad de fuente horizontal es la propiedad AVERAGE_WIDTH dividida por 10.
•
Si la fuente no tiene una propiedad AVERAGE_WIDTH pero tiene una propiedad QUAD_WIDTH, la unidad de fuente horizontal es la propiedad QUAD_WIDTH.
•
Si la fuente no tiene una propiedad AVERAGE_WIDTH ni QUAD_WIDTH, la unidad de fuente horizontal es la suma de los valores min_bounds.width y max_bounds.width de la estructura de la fuente dividida por 2.3.

NAME

XmScreen — A Screen widget that manages screen-specific resources

SYNOPSIS

XmScreen(3)

DESCRIPTION

The XmScreen widget is a subclass of the primitive widget, Core. It is used to manage screen-specific resources. A single XmScreen widget instance is created for each screen in an application. This widget is used to hold information that is applicable to the entire screen, such as default font lists, color maps, and cursor definitions.

The XmScreen widget is not a visible widget. It is used internally by the Motif toolkit to manage screen-specific resources. Applications typically do not interact directly with the XmScreen widget. Instead, they use functions such as XmGetXmScreen to retrieve a pointer to the XmScreen widget for the current screen.

XmNallowShellResize
Specifies whether a shell widget is allowed to resize its children. The default value is False.
XmNautoUnmanageChildren
Specifies whether children that are unmanaged should also be destroyed. The default value is False.
XmNcolormap
Specifies the colormap to be used for the screen. The default value is the default colormap for the screen.
XmNdefaultFontList
Specifies the default font list for the screen. This font list is used by widgets that do not have a specific font list resource set.
XmNdefaultVendorPrimitiveStyle
Specifies the default style for vendor-specific primitive resources. This resource is typically set by the application and is used to control the appearance of certain widgets.
XmNdefaultVendorWidgetStyle
Specifies the default style for vendor-specific widget resources. This resource is typically set by the application and is used to control the appearance of certain widgets.
XmNfontset
Specifies the default fontset for the screen. This resource is used by widgets that do not have a specific fontset resource set.
XmNkeyboardElevation
Specifies the keyboard elevation for the screen. This resource is used to control the accessibility of the keyboard.
XmNkeyboardHighlightColor
Specifies the color used to highlight keyboard focus. The default value is implementation-dependent.
XmNkeyboardManner
Specifies the keyboard manner for the screen. This resource is used to control the accessibility of the keyboard.
XmNkeyboardPointerEnhancement
Specifies the keyboard pointer enhancement for the screen. This resource is used to control the accessibility of the keyboard.
XmNkeyboardPointerMapping
Specifies the keyboard pointer mapping for the screen. This resource is used to control the accessibility of the keyboard.
XmNkeyboardPointerMode
Specifies the keyboard pointer mode for the screen. This resource is used to control the accessibility of the keyboard.
XmNkeyboardPointerSensitivity
Specifies the keyboard pointer sensitivity for the screen. This resource is used to control the accessibility of the keyboard.
XmNkeyboardPointerThreshold
Specifies the keyboard pointer threshold for the screen. This resource is used to control the accessibility of the keyboard.
XmNmenuCursor
Specifies the cursor to be used when a menu is active. The default value is implementation-dependent.
XmNmultiClickTime
Specifies the multi-click time in milliseconds. This value is used to determine how quickly multiple clicks are registered as a single multi-click event. The default value is implementation-dependent.
XmNnumButtons
Specifies the number of buttons on the mouse. This value is used by the toolkit to determine the number of buttons available for user interaction.
XmNpointerColor
Specifies the default color of the pointer. The default value is implementation-dependent.
XmNpointerColorBackground
Specifies the background color of the pointer. The default value is implementation-dependent.
XmNpointerColorForeground
Specifies the foreground color of the pointer. The default value is implementation-dependent.
XmNpointerGrabTime
Specifies the time in milliseconds for which the pointer is grabbed. This resource is used to control the behavior of the pointer when it is grabbed by a widget.
XmNpointerMotionHintWindow
Specifies a window that is used to receive pointer motion hints. This resource is used to optimize pointer motion events.
XmNscreen
Specifies the screen associated with this XmScreen widget. This resource is set automatically when the widget is created.
XmNskipDismissCallback
Specifies whether the dismiss callback for a dialog should be skipped. The default value is False.
XmNtitleEncoding
Specifies the title encoding for the screen. This resource is used to control how titles are encoded for display.
XmNtitleHorizontalAlignment
Specifies the horizontal alignment of the title. The default value is XmALIGNMENT_CENTER.
XmNtitleVerticalAlignment
Specifies the vertical alignment of the title. The default value is XmALIGNMENT_CENTER.
XmNtopShadowContrast
Specifies the contrast for the top shadow. The value is typically between 0 and 100. The default value is implementation-dependent.
XmNtopShadowHighlightThickness
Specifies the thickness of the top shadow highlight. The default value is implementation-dependent.
XmNvisualID
Specifies the visual ID for the screen. This resource is set automatically when the widget is created.
XmNwaitingCursor
Specifies the cursor to be used when the application is waiting for user input. The default value is implementation-dependent.
XmNwindowBackground
Specifies the default background color for windows on the screen. The default value is implementation-dependent.
XmNwindowBackgroundPixmap
Specifies the default background pixmap for windows on the screen. The default value is XmUNSPECIFIED_PIXMAP.
XmNwindowBorderColor
Specifies the default border color for windows on the screen. The default value is implementation-dependent.
XmNwindowForeground
Specifies the default foreground color for windows on the screen. The default value is implementation-dependent.
XmNwindowShadowThickness
Specifies the thickness of the window shadow. The default value is implementation-dependent.
XmNwindowTopShadowContrast
Specifies the contrast for the top window shadow. The value is typically between 0 and 100. The default value is implementation-dependent.
XmNwindowTopShadowHighlightThickness
Specifies the thickness of the top window shadow highlight. The default value is implementation-dependent.
