NOMBRE

XmLabelGadget — La clase de widget LabelGadget

SINOPSIS

#include <Xm/LabelG.h>

DESCRIPCIÓN

LabelGadget es un widget instanciable y también se utiliza como superclase para otros gadgets de botones, como PushButtonGadget y ToggleButtonGadget.

LabelGadget puede contener texto o un pixmap. El texto de LabelGadget es una cadena de caracteres compuesta. Consulte la guía del programador de *Motif* para obtener más información sobre las cadenas de caracteres compuestas. El texto puede ser multilingüe, multilinea y/o con múltiples fuentes. Cuando un LabelGadget está inactivo, su texto se puntua, o se muestra el pixmap inactivo proporcionado por el usuario.

LabelGadget admite tanto aceleradores como mnemónicos, principalmente para su uso en widgets de subclase de LabelGadget que se encuentran en menús. Los mnemónicos están disponibles en un sistema de menús cuando el botón es visible. Los aceleradores en un sistema de menús son accesibles incluso cuando el botón no es visible. LabelGadget muestra el mnemónico subrayando el primer carácter coincidente en la cadena de texto. El acelerador se muestra como una cadena de texto adyacente al texto o pixmap de la etiqueta, dependiendo de la dirección de la disposición.

LabelGadget consta de muchos campos de margen que rodean el texto o el pixmap. Estos campos de margen son recursos que pueden ser establecidos por el usuario, pero las subclases de LabelGadget y los padres de tipo Manager también modifican algunos de estos campos. Tienden a modificar los recursos XmNmarginLeft, XmNmarginRight, XmNmarginTop y XmNmarginBottom, y dejan los recursos XmNmarginWidth y XmNmarginHeight como los estableció la aplicación.

LabelGadget tiene en cuenta XmNshadowThickness al determinar su disposición, pero no dibuja la sombra. Es decir, si XmNshadowThickness es mayor que 0 (cero), LabelGadget deja espacio para la sombra, pero la sombra no aparece.

En un LabelGadget, XmNtraversalOn y XmNhighlightOnEnter se fuerzan a False dentro de los paneles de menú emergentes, los paneles de menú desplegables y los menús de opciones. De lo contrario, estos recursos tienen el valor predeterminado de False.

LabelGadget utiliza los rasgos XmQTmenuSystem y XmQTspecifyRenderTable, y tiene los rasgos XmQTaccessTextual, XmQTcareParentVisual, XmQTmenuSavvy y XmQTtransfer.

Comportamiento de transferencia de datos

LabelGadget y sus subclases, excepto cuando se utilizan en un sistema de menús, admiten la transferencia del contenido de la etiqueta desde el LabelGadget. Sin embargo, el contenido de la etiqueta solo es arrastrable si el recurso XmNenableUnselectableDrag de XmDisplay está establecido en True.

Como fuente de datos, LabelGadget y sus subclases admiten los siguientes destinos y las conversiones asociadas de datos a estos destinos:

local
Si el destino local coincide con la configuración regional del widget, el widget transfiere XmNlabelString en la codificación de la configuración regional. Este destino solo se admite cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
COMPOUND_TEXT
El widget transfiere XmNlabelString como tipo COMPOUND_TEXT. Este destino solo se admite cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
UTF8_STRING
El widget transfiere XmNlabelString como tipo UTF8_STRING. Este destino solo se admite cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
PIXMAP
El widget transfiere XmNlabelPixmap como tipo DRAWABLE. Este destino se admite cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING.
STRING
El widget transfiere XmNlabelString como tipo STRING. Este destino se admite cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
TEXT
Si XmNlabelString es completamente convertible a la codificación de la configuración regional, el widget transfiere XmNlabelString en la codificación de la configuración regional. De lo contrario, el widget transfiere XmNlabelString como tipo COMPOUND_TEXT. Este destino se admite cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
_MOTIF_CLIPBOARD_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que admite para la selección CLIPBOARD. Cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING, estos incluyen los siguientes destinos:
•
_MOTIF_COMPOUND_STRING
•
COMPOUND_TEXT
•
UTF8_STRING
•
La codificación de la configuración regional, si XmNlabelString es completamente convertible a la codificación de la configuración regional
•
STRING, si XmNlabelString es completamente convertible a STRING
Cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, los destinos incluyen PIXMAP.
_MOTIF_COMPOUND_STRING
El widget transfiere XmNlabelString como una cadena compuesta en formato Byte Stream. Este destino se admite cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
_MOTIF_EXPORT_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que se utilizarán como valor de XmNexportTargets del DragContext en una transferencia de arrastrar y soltar. Cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING, estos incluyen _MOTIF_COMPOUND_STRING, COMPOUND_TEXT, UTF8_STRING, la codificación de la configuración regional, STRING, TEXT, BACKGROUND y FOREGROUND. Cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, estos incluyen PIXMAP, BACKGROUND y FOREGROUND.

Como fuente de datos, LabelGadget también admite los siguientes destinos estándar de Motif:

BACKGROUND
El widget transfiere el XmNbackground del padre como tipo PIXEL.
CLASS
El widget encuentra la primera ventana shell en la jerarquía de widgets que tiene una propiedad WM_CLASS y transfiere su contenido como texto en la configuración regional actual.
CLIENT_WINDOW
El widget encuentra la primera ventana shell en la jerarquía de widgets y transfiere su ventana como tipo WINDOW.
COLORMAP
El widget transfiere el XmNcolormap del padre como tipo COLORMAP.
FOREGROUND
El widget transfiere el XmNforeground del padre como tipo PIXEL.
NAME
El widget encuentra la primera ventana shell en la jerarquía de widgets que tiene una propiedad WM_NAME y transfiere su contenido como texto en la configuración regional actual.
TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que admite. Estos incluyen los destinos estándar de esta lista. Cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING, estos también incluyen _MOTIF_COMPOUND_STRING, COMPOUND_TEXT, UTF8_STRING, la codificación de la configuración regional, STRING y TEXT. Cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, estos también incluyen PIXMAP.
TIMESTAMP
El widget transfiere la marca de tiempo utilizada para adquirir la selección como tipo INTEGER.
_MOTIF_RENDER_TABLE
El widget transfiere XmNrenderTable si existe, o la tabla de renderizado de texto predeterminada si no, como tipo STRING.
_MOTIF_ENCODING_REGISTRY
El widget transfiere su registro de codificación como tipo STRING. El valor es una lista de elementos separados por NULL en el formato de pares etiqueta-codificación. Este destino simboliza el destino de transferencia para el Registro de Codificación de Segmentos de Motif. Los widgets y las aplicaciones pueden usar este Registro para registrar formatos de codificación de texto para etiquetas de tabla de renderizado específicas. Appl

XmNaccelerator
Establece el acelerador en un widget de botón en un menú, que activa un botón visible o invisible, pero gestionado, desde el teclado. Este recurso es una cadena que describe un conjunto de modificadores y la tecla que puede usarse para seleccionar el botón. El formato de esta cadena es idéntico al utilizado por el gestor de traducciones, con la excepción de que solo se puede especificar un único evento y solo se permiten eventos KeyPress.
Los aceleradores para botones solo son compatibles con los Gadgets de Botón de Pulsación (PushButtonGadgets) y los Gadgets de Botón de Conmutación (ToggleButtonGadgets) en menús desplegables (Pulldown) y emergentes (Popup).
XmNacceleratorText
Especifica el texto que se muestra para el acelerador. El texto se muestra adyacente a la cadena de etiqueta o al mapa de bits. La dirección de su disposición depende del recurso XmNlayoutDirection del widget. El texto del acelerador para los botones se muestra solo para los PushButtonGadgets y ToggleButtonGadgets en los menús desplegables y emergentes.
XmNalignment
Especifica la alineación de la etiqueta para texto o mapa de bits.
XmALIGNMENT_BEGINNING (alineación izquierda)
Hace que los lados izquierdos de las líneas de texto se alineen verticalmente con el borde izquierdo del gadget. Para un mapa de bits, su lado izquierdo se alinea verticalmente con el borde izquierdo del gadget.
XmALIGNMENT_CENTER (alineación central)
Hace que los centros de las líneas de texto se alineen verticalmente en el centro del gadget. Para un mapa de bits, su centro se alinea verticalmente con el centro del gadget.
XmALIGNMENT_END (alineación derecha)
Hace que los lados derechos de las líneas de texto se alineen verticalmente con el borde derecho del gadget. Para un mapa de bits, su lado derecho se alinea verticalmente con el borde derecho del gadget.
Las descripciones anteriores para el texto son correctas cuando XmNlayoutDirection es XmLEFT_TO_RIGHT. Cuando ese recurso es XmRIGHT_TO_LEFT, las descripciones para XmALIGNMENT_BEGINNING y XmALIGNMENT_END se intercambian.
Si el padre es un RowColumn cuyo recurso XmNisAligned es Verdadero, XmNalignment se fuerza al mismo valor que el XmNentryAlignment del RowColumn si el XmNrowColumnType del RowColumn es XmWORK_AREA o si el gadget es una subclase de XmLabelGadget. De lo contrario, el valor predeterminado es XmALIGNMENT_CENTER.
XmNfontList
Especifica la fuente del texto utilizado en el gadget. XmNfontList está obsoleto y existe para compatibilidad con versiones anteriores. Ahora debe usar XmNrenderTable en lugar de XmNfontList. Si se especifican ambos, la tabla de renderizado tendrá prioridad. Si XmNfontList es NULL al inicializarse, se busca en la jerarquía padre del widget un ancestro que sea una subclase de las clases de widget XmBulletinBoard, VendorShell o XmMenuShell. Si se encuentra un ancestro de este tipo, la lista de fuentes se inicializa con XmNbuttonFontList (para subclases de gadget de botón) o XmNlabelFontList del widget ancestro. Si no se encuentra ningún ancestro de este tipo, el valor predeterminado depende de la implementación. Consulte XmFontList(3) para obtener más información sobre la creación y la estructura de una lista de fuentes.
XmNlabelInsensitivePixmap
Especifica un mapa de bits que se utiliza como cara del botón si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING y el botón está inactivo. El valor predeterminado, XmUNSPECIFIED_PIXMAP, muestra una etiqueta vacía.
XmNlabelPixmap
Especifica el mapa de bits cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING. El valor predeterminado, XmUNSPECIFIED_PIXMAP, muestra una etiqueta vacía.
XmNlabelString
Especifica la cadena compuesta cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING. Si el valor de este recurso es NULL, se inicializa con el nombre del gadget convertido en una cadena compuesta. Consulte XmString(3) para obtener más información sobre la creación y la estructura de cadenas compuestas.
XmNlabelType
Especifica el tipo de etiqueta.
XmSTRING
El texto muestra XmNlabelString
XmPIXMAP
Los datos del icono en mapa de bits muestran XmNlabelPixmap o XmNlabelInsensitivePixmap XmPIXMAP_AND_STRING Los datos del icono en mapa de bits muestran XmNlabelPixmap o XmNlabelInsensitivePixmap y el texto muestra XmNlabelString
XmNmarginBottom
Especifica la cantidad de espacio entre la parte inferior del texto de la etiqueta y la parte superior del margen inferior especificado por XmNmarginHeight. Esto puede ser modificado por las subclases de LabelGadget. Por ejemplo, CascadeButtonGadget puede aumentar este campo para hacer espacio para el mapa de bits de cascada.
XmNmarginHeight
Especifica una cantidad igual de espacio por encima del margen definido por XmNmarginTop y por debajo del margen definido por XmNmarginBottom. XmNmarginHeight especifica la cantidad de espacio entre el borde superior del margen establecido por XmNmarginTop y el borde inferior de la sombra superior, y la cantidad de espacio entre el borde inferior del margen especificado por XmNmarginBottom y el borde superior de la sombra inferior.
XmNmarginLeft
Especifica la cantidad de espacio entre el borde izquierdo del texto de la etiqueta y el lado derecho del margen izquierdo (especificado por XmNmarginWidth). Esto puede ser modificado por las subclases de LabelGadget. Por ejemplo, ToggleButtonGadget puede aumentar este campo para hacer espacio para el indicador de conmutación y para el espacio entre el indicador y la etiqueta. Si esto se aplica realmente al lado izquierdo o derecho de la etiqueta depende del valor de XmNlayoutDirection.
XmNmarginRight
Especifica la cantidad de espacio entre el borde derecho del texto de la etiqueta y el lado izquierdo del margen derecho (especificado por XmNmarginWidth). Esto puede ser modificado por las subclases de LabelGadget. Por ejemplo, CascadeButtonGadget puede aumentar este campo para hacer espacio para el mapa de bits de cascada. Si esto se aplica realmente al lado izquierdo o derecho de la etiqueta depende del valor de XmNlayoutDirection.
XmNmarginTop
Especifica la cantidad de espacio entre la parte superior del texto de la etiqueta y la parte inferior del margen superior especificado por XmNmarginHeight. Esto puede ser modificado por las subclases de LabelGadget. Por ejemplo, CascadeButtonGadget puede aumentar este campo para hacer espacio para el mapa de bits de cascada.
XmNmarginWidth
Especifica una cantidad igual de espacio a la izquierda del margen definido por XmNmarginLeft y a la derecha del margen definido por XmNmarginRight. XmNmarginWidth especifica la cantidad de espacio entre el borde izquierdo del margen establecido por XmNmarginLeft y el borde derecho de la sombra izquierda, y la cantidad de espacio entre el borde derecho del margen especificado por XmNmarginRight y el borde izquierdo de la sombra derecha.
XmNmnemonic
Proporciona al usuario un medio alternativo para activar un botón. Un botón en una Barra de Menú (MenuBar), un panel de menú emergente (Popup) o un panel de menú desplegable (Pulldown) puede tener una mnemotecnia.
Este recurso contiene una clave simbólica (keysym) tal como se lista en la tabla de claves simbólicas de X11. El primer carácter de la cadena de etiqueta que coincida exactamente con la mnemotecnia en el conjunto de caracteres especificado en XmNmnemonicCharSet se subrayará cuando se muestre el botón.
Cuando se ha especificado una mnemotecnia, el usuario activa el botón presionando la tecla mnemotécnica mientras el botón es visible. Si el botón es un CascadeButtonGadget en una MenuBar y la MenuBar no tiene el foco, el usuario debe usar el modificador MAlt mientras presiona la mnemotecnia. El usuario puede activar el botón presionando la tecla mnemotécnica con o sin mayúsculas.
XmNmnemonicCharSet
Especifica el conjunto de caracteres de la mnemotecnia para la etiqueta. El valor predeterminado es XmFONTLIST_DEFAULT_TAG.
XmNpixmapPlacement
La ubicación del mapa de bits con respecto a la etiqueta de texto. Este recurso puede tomar uno de los siguientes valores: XmPIXMAP_TOP, XmPIXMAP_BOTTOM, XmPIXMAP_LEFT y XmPIXMAP_RIGHT. Se ha registrado un convertidor de tipos que convierte las siguientes cadenas: "top", "bottom", "left" y
"derecho".
XmNpixmapTextPadding
La cantidad de espacio que se dejará entre el pixmap y la cadena de etiqueta.
XmNrecomputeSize
Especifica un valor booleano que indica si el gadget se encoge o se expande para acomodar su contenido (cadena de etiqueta o pixmap) como resultado de un valor de recurso XtSetValues que cambiaría el tamaño del gadget. Si es Verdadero, el gadget se encoge o se expande para ajustarse exactamente a la cadena de etiqueta o al pixmap. Si es Falso, el gadget nunca intenta cambiar de tamaño por sí mismo.
XmNrenderTable
Especifica la tabla de renderizado asociada con XmNlabelString. Si este valor es NULL al inicializarse, Label busca en la jerarquía de su padre un ancestro que posea el trait XmQTspecifyRenderTable. Si se encuentra dicho ancestro, Label inicializa XmNrenderTable al valor XmLABEL_RENDER_TABLE del widget ancestro. De manera similar, las subclases de botón de Label inicializan XmNrenderTable al valor XmBUTTON_RENDER_TABLE del widget ancestro. (Tenga en cuenta que todas las subclases actuales de Label son subclases de botón.) Si no se encuentra dicho ancestro, el valor predeterminado depende de la implementación. Si se especifican tanto una lista de fuentes como una tabla de renderizado, la tabla de renderizado tendrá prioridad. Consulte XmRenderTable(3) para obtener más información sobre la creación y la estructura de una tabla de renderizado.
XmNstringDirection
Es un recurso sintético para establecer XmNlayoutDirection. Los valores para este recurso son XmSTRING_DIRECTION_L_TO_R y XmSTRING_DIRECTION_R_TO_L. Consulte la descripción del recurso XmNlayoutDirection. El recurso XmNstringDirection está obsoleto por XmNlayoutDirection, pero se mantiene aquí por compatibilidad con versiones anteriores.

Behavior

XmLabelGadget includes behavior from XmGadget. Additional XmLabelGadget behavior is described in the following list:

<Btn2Down>:
Arrastra el contenido de un LabelGadget, identificado cuando se presiona BTransfer. Esta acción no está definida para LabelGadgets utilizados en un sistema de menú.
<Key><osfHelp>:
En un Menú Emergente o Menú Desplegable, despublica todos los menús en la jerarquía de menús y, cuando la política de foco de teclado del shell es XmEXPLICIT, restaura el foco de teclado al widget que tenía el foco antes de entrar en el sistema de menús. Llama a las callbacks de XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a las callbacks de ayuda del ancestro más cercano que las tenga.
<key><osfCancel>:
En una Barra de Menú, desarma el Botón en Cascada y el menú y, cuando la política de foco de teclado del shell es XmEXPLICIT, restaura el foco de teclado al widget que tenía el foco antes de entrar en el menú.
En un Menú Desplegable de nivel superior desde una Barra de Menú, despublica el menú, desarma el Botón en Cascada de la Barra de Menú y la Barra de Menú, y, cuando la política de foco de teclado del shell es XmEXPLICIT, restaura el foco de teclado al widget que tenía el foco antes de entrar en la Barra de Menú. En otros Menús Desplegables, despublica el menú.
En un Menú Emergente, despublica el menú y, cuando la política de foco de teclado del shell es XmEXPLICIT, restaura el foco de teclado al widget desde el cual se publicó el menú.
<Key><osfDown>:
Si el elemento de menú actual tiene un submenú y está en una Barra de Menú, entonces esta acción publica el submenú, desarma el elemento de menú actual y arma el primer elemento de menú transitable del submenú.
Si el elemento de menú actual está en un Panel de Menú, entonces esta acción desarma el elemento de menú actual y arma el elemento debajo de él. Esta acción se envuelve dentro del Panel de Menú. La dirección del envoltorio depende del recurso XmNlayoutDirection.
<Key><osfLeft>:
Cuando el elemento de menú actual está en una Barra de Menú, entonces esta acción desarma el elemento actual y arma el elemento de la Barra de Menú a la izquierda. Esta acción se envuelve dentro de la Barra de Menú.

NAME

XmLabelGadget, XmLabelWidget, XmCreateLabelGadget, XmVaCreateLabelGadget, XmVaCreateManagedLabelGadget — a manager widget that displays a string or icon (a label gadget)

SYNOPSIS

#include <Xm/LabelGadget.h>

Widget XmCreateLabelGadget( Widget parent, const char *name, ArgList arglist, Cardinal argCount );
Widget XmVaCreateLabelGadget( Widget parent, const char *name, ... );
Widget XmVaCreateManagedLabelGadget( Widget parent, const char *name, ... );

DESCRIPTION

The XmLabelGadget is a manager widget that displays a string or icon. It is used to provide a label for another widget, or as a single item in a menu bar or menu pane. The label can be a string, a pixmap, or both. The label can be aligned within the gadget's bounding box. The gadget can also have a shadow, which gives it a 3-D appearance.

The gadget supports the following resources:

XmNalignment
Specifies the alignment of the label within the gadget. Can be XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER, or XmALIGNMENT_END.
XmNfontList
Specifies the font list for the label string.
XmNlabelInsensitivePixmap
Specifies the pixmap to be used for the label when the gadget is insensitive.
XmNlabelPixmap
Specifies the pixmap to be used for the label.
XmNlabelString
Specifies the string to be used for the label.
XmNlabelType
Specifies the type of the label. Can be XmSTRING, XmPIXMAP, or Xm julg.
XmNrecomputeSize
Specifies whether the gadget's size should be recomputed when the label changes.
XmNseparatorType
Specifies the type of separator to be drawn if the label type is XmSEPARATOR.
XmNshadowThickness
Specifies the thickness of the shadow around the gadget.
XmNtopShadowPixmap
Specifies the pixmap to be used for the top shadow.
XmNbottomShadowPixmap
Specifies the pixmap to be used for the bottom shadow.
XmNuserData
Allows the application to attach user data to the gadget.

The functions XmCreateLabelGadget, XmVaCreateLabelGadget, and XmVaCreateManagedLabelGadget create a Label Gadget. XmCreateLabelGadget takes a variable number of arguments for resource settings. XmVaCreateLabelGadget takes a variable number of arguments in va_list format. XmVaCreateManagedLabelGadget is similar to XmVaCreateLabelGadget but also manages the created gadget.

The following describes the traversal actions for a Label Gadget:

<Key><osfRight>:
If the current menu item is a CascadeButton, then this action posts its associated submenu. If the current menu item is not a CascadeButton and is not at the right edge of a MenuPane, this action disarms the current item and arms the item to its right, wrapping if necessary. If the current menu item is not a CascadeButton and is at the right edge of a submenu that is a descendent of a MenuBar, then this action unposts all submenus and traverses to the MenuBar item to the right. If that MenuBar item has a submenu, it posts the submenu and arms the submenu's first traversable item.
In Popup or Torn-off menus, if the current menu item is not a CascadeButton and is at the right edge of a row (except the bottom row), this action wraps to the leftmost menu item in the row below. If the current menu item is not a CascadeButton and is in the bottom, rightmost corner of a Popup or Pulldown MenuPane, this action wraps to the tear-off control, if present, or else it wraps to the top, leftmost menu item of the MenuPane. The preceding description applies when the XmNlayoutDirection horizontal direction is XmLEFT_TO_RIGHT. If the XmNlayoutDirection horizontal direction is XmRIGHT_TO_LEFT, then the following applies.
When the current menu item is in a MenuBar, then this action disarms the current item and arms the MenuBar item to the right. This action wraps within the MenuBar.
In MenuPanes, if the current menu item is not at the right edge of a MenuPane, this action disarms the current item and arms the item to its right. If the current menu item is at the right edge of a submenu attached to a MenuBar item, then this action unposts the submenu and traverses to the MenuBar item to the right, wrapping if necessary. If that MenuBar item has a submenu, it posts the submenu and arms the first traversable item in the submenu. If the current menu item is at the right edge of a submenu not directly attached to a MenuBar item, then this action unposts the current submenu only.
In Popup or Torn-off MenuPanes, when the current menu item is at the right edge, this action wraps within the MenuPane. If the current menu item is at the right edge of the MenuPane and not in the top row, this action wraps to the leftmost menu item in the row above. If the current menu item is in the upper, rightmost corner, this action wraps to the tear-off control, if present, or else it wraps to the bottom, leftmost menu item in the MenuPane.
<Key><osfUp>:
When the current menu item is in a MenuPane, then this action disarms the current menu item and arms the item above it. This action wraps within the MenuPane. The direction of the wrapping depends on the XmNlayoutDirection resource.
