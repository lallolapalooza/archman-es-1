NOMBRE

XmImSetValues — Una función del gestor de entrada que actualiza atributos de un contexto de entrada

SINOPSIS

#include <Xm/XmIm.h>
void XmImSetValues(
Widget widget,
ArgList arglist,
Cardinal argcount,
);

DESCRIPCIÓN

XmImSetValues actualiza atributos del contexto de entrada asociado con el widget especificado. El argumento arglist es una lista de pares atributo/valor para el contexto de entrada. Esta función pasa los atributos y valores a XICSetValues. La llamada inicial a esta rutina debe pasar todos los atributos del contexto de entrada. Después, el programador de la aplicación llama a XmImSetValues, para un XIC, solo si un valor ha cambiado.

Si los parámetros anteriores para el XIC del widget no permiten que el XIC previamente registrado se reutilice, dicho XIC se anulará su registro y se creará uno nuevo y se registrará con el widget. Tenga en cuenta que se preserva el uso compartido de datos.

Tenga en cuenta que los widgets Text y TextField llaman a la función XmImSetValues cuando reciben el foco. Por lo tanto, las llamadas adicionales a la función XmImSetValues para estos widgets son innecesarias.

widget
Especifica el ID del widget registrado con el gestor de entrada.
arglist
Especifica la lista de pares atributo/valor que se pasarán a XICSetValues; se aceptan los siguientes atributos: XmNpreeditStartCallback XmNpreeditDoneCallback XmNpreeditDrawCallback y XmNpreeditCaretCallback. Estos atributos aceptan un valor asociado de tipo puntero a una estructura de tipo XIMCallback.
Estas llamadas de retorno solo se utilizan cuando el recurso XmNpreeditType del VendorShell relevante tiene el valor "onthespot" y el XIM soporta el estilo de entrada XIMPreeditCallbacks. Estos valores se ignoran si la condición no se cumple.
Para cada una de estas llamadas de retorno, si el valor de la llamada de retorno no se establece mediante esta función, no se realizará ninguna acción cuando el Método de Entrada intente llamar a esta llamada de retorno. Consulte el capítulo 13 del manual "Xlib - C Language X Interface, X Version 11, Release 6" para obtener detalles sobre estas llamadas de retorno.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Los recursos que se pueden establecer para el contexto de entrada incluyen:

XmNbackground
Especifica el valor de píxel para el color de fondo.
XmNbackgroundPixmap
Especifica un pixmap para recubrir el fondo.
XmNfontList
Especifica la lista de fuentes utilizada por el widget. El método de entrada utiliza la primera ocurrencia de un conjunto de fuentes etiquetado con XmFONTLIST_DEFAULT_TAG. Si no se encuentra tal instancia, se utiliza el primer conjunto de fuentes en la lista de fuentes. Si la lista de fuentes no contiene un conjunto de fuentes, no se pasa ningún valor a XICSetValues.
XmNforeground
Especifica el valor de píxel para el color de primer plano.
XmNlineSpace
Especifica el espaciado entre líneas utilizado en la ventana de preedición.
XmNrenderTable
Especifica la tabla de renderizado utilizada por el widget.
XmNspotLocation
Especifica las coordenadas x e y de la posición donde se insertará el texto en el widget que maneja la entrada, cuyo estilo de método de entrada es "OverTheSpot". La coordenada y es la posición de la línea base utilizada por la línea de texto actual.

El llamador también puede pasar otros recursos definidos por el proveedor a esta función. Para obtener información adicional sobre la interfaz de internacionalización, consulte la documentación de Xlib.
