Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmIconButton(3X) XmIconButton(3X)

NOMBRE

El widget Icon Button

SINOPSIS

Documenta el widget XmIconButton

DESCRIPCIÓN

El widget Icon Button es un área seleccionable de la pantalla que contiene tanto una etiqueta como una cadena de texto. Cuando el usuario selecciona este botón con el botón de selección de OSF/Motif, se llama a su activateCallback. Este widget también se puede usar como un botón Toggle, aunque no tendrá ningún indicador. La ubicación del icono con respecto al texto se puede modificar utilizando el recurso iconPlacement.

Nota: Este widget toma una cadena de texto (String) como etiqueta, no una XmString, por lo que no es necesario usar XmStringCreate para obtener una cadena con formato adecuado. El texto internacionalizado no es compatible actualmente.

Todos los nombres de recursos comienzan con XmN y todos los nombres de clase de recursos comienzan con XmC.

activateCallback

Esta lista de rutinas de callback se llama cada vez que el usuario hace clic en el botón de icono. El formato de las rutinas de callback se especifica a continuación.

armColor

Este es el índice de píxel que describe el color con el que se rellenará el widget cuando esté activado.

doubleClickCallback

Esta lista de rutinas de callback se llama cada vez que el usuario hace doble clic en este widget. El formato de las rutinas de callback se especifica a continuación.

fontList

La fuente predeterminada en esta lista se utiliza para renderizar la cadena de etiqueta del botón de icono.

horizontalMargin

verticalMargin

La cantidad de espacio que se dejará entre el borde de la sombra y el texto o el pixmap que se muestra. El espaciado vertical y horizontal se puede controlar de forma independiente.

iconTextPadding

La cantidad de espacio que se dejará entre el pixmap y la cadena de etiqueta.

iconPlacement

La ubicación del pixmap (icono) con respecto al texto mostrado. Este recurso puede tomar uno de los siguientes valores: XmIconTop, XmIconBottom, XmIconLeft, XmIconRight, XmIconNone y XmIconOnly. Se ha registrado un convertidor de tipos que convierte las siguientes cadenas: "top", "bottom", "left", "right", "none" y "iconOnly".

Si solo se muestra una cadena en el Icon Button, este recurso se puede utilizar para cambiar la justificación de la etiqueta. XmIconTop=bottom, XmIconBottom=top, XmIconRight=Left, XmIconLeft=Right, XmIconNone=Center. Para utilizar estas opciones, el pixmap debe establecerse en None.

label

La cadena de texto que se mostrará en este botón. Esta cadena solo puede tener una fuente, pero puede tener cualquier número de líneas. Utilice el carácter NEW_LINE ( '\n' ) para separar las líneas. Este recurso ha sido reemplazado por labelString, pero se incluye por compatibilidad hacia atrás. Si se establece XmNlabelString, se ignora XmNlabel.

labelString

Especifica la cadena compuesta que se mostrará en el botón. Si este valor es NULL, se utiliza el valor de XmNlabel. Si ambos son NULL, labelString se inicializa convirtiendo el nombre del widget en una cadena compuesta. Consulte XmString(3X) en la Referencia del Programador de OSD/Motif para obtener más información sobre la creación y estructura de cadenas compuestas.

pixmap

El pixmap a mostrar. Este pixmap puede ser de profundidad uno (1) o de la misma profundidad que la pantalla en la que se está mostrando este widget. Si el pixmap es de profundidad uno, se utiliza XCopyPlane para renderizar el pixmap en los colores de primer plano y de fondo. Si el pixmap no es de profundidad uno, se utiliza XCopyArea y se conservan todos los colores originales del pixmap. A diferencia del widget PushButton de Motif, el pixmap se difumina automáticamente cuando el Icon Button se vuelve insensible.

recomputeSize

Si este valor booleano es True, el botón de icono solicitará a su padre que lo redimensione para que sea lo suficientemente grande como para contener el pixmap, la etiqueta y las sombras. Si es False, el botón de icono no intentará redimensionarlo.

set

Este valor booleano representa el estado actual del botón de icono. Si este valor es True, el botón de icono está activado y se renderiza como presionado. De lo contrario, está desactivado y se renderiza normalmente.

stringDirection

Especifica la dirección en la que se dibujará la cadena. XmNSTRING_DIRECTION_L_TO_R se dibuja de izquierda a derecha, mientras que XmNSTRING_DIRECTION_R_TO_L se dibuja de derecha a izquierda. El valor predeterminado para este recurso se determina en el momento de la creación. Si no se especifica ningún valor para este recurso y el padre del widget es un gestor, el valor se hereda del padre; de lo contrario, se establece por defecto en XmNSTRING_DIRECTION_L_TO_R.

Rutinas de Callback

Cada vez que el usuario selecciona el botón de icono, se llamarán los callbacks de activación. Cada vez que el usuario hace doble clic en este widget, el primer clic llamará al activateCallback, y si el segundo ocurre dentro de MultiClickTime, llamará al doubleClickCallback. Estos callbacks tienen los siguientes parámetros:

void (activate_callback)(Widget w, XtPointer client_data, XtPointer call_data)

w el widget Icon Button

client_data los datos del cliente especificados por la aplicación

call_data un puntero a una estructura XmIconButtonCallbackInfo

void (double_click_callback)(Widget w, XtPointer client_data, XtPointer call_data)

w el widget Icon Button

client_data los datos del cliente especificados por la aplicación

call_data un puntero a una estructura XmIconButtonCal

XmIconButton(3)

NAME

XmIconButton - a widget that displays an icon and a label

SYNOPSIS

#include <Xm/IconG.h>

DESCRIPTION

The Icon Button widget displays an icon and a label. The label can be either text or a pixmap. The Icon Button widget can be used as a push button or a toggle button. It supports callbacks for activation and double-clicking.

Normal Resources

The Icon Button widget has the following resources:

activateCallback
Specifies the list of functions to call when the icon button is activated. The default is NULL.
armColor
The color to use when the icon button is armed. The default is implementation-defined.
doubleClickCallback
Specifies the list of functions to call when the icon button is double-clicked. The default is NULL.
fontList
Specifies the font to use for the label. The default is implementation-defined.
horizontalMargin
Specifies the horizontal margin between the icon and the label. The default is implementation-defined.
verticalMargin
Specifies the vertical margin between the icon and the label. The default is implementation-defined.
iconTextPadding
Specifies the padding between the icon and the text. The default is implementation-defined.
iconPlacement
Specifies the placement of the icon relative to the text. The default is XmTOP_LEFT.
label
Specifies the label for the icon button. This can be either a string or a pixmap. The default is NULL.
labelString
Specifies the string to use as the label. This resource is obsolete and has been replaced by label.
pixmap
Specifies the pixmap to use as the icon. This resource is obsolete and has been replaced by label.
recomputeSize
Specifies whether the widget should recompute its size when the label changes. The default is True.
set
Specifies the initial state of the icon button. The default is False.
stringDirection
Specifies the direction of the string in the label. The default is implementation-defined.

Callback Routines

All procedures on the Icon Button's activateCallback and doubleClickCallback lists will have a pointer to an IconButtonCallbackInfo structure passed to them in the call_data field. This structure is defined in the Icon Button widget's public header file as follows:

typedef struct _XmIconButtonCallbackInfo {

Boolean state; /* The current state of the icon button.*/

XEvent * event; /* The event that caused this action.*/

} XmIconButtonCallbackInfo;

state the current state of the icon button. When this is used as a push button (the default) the state variable will always be True.

event the X Event that caused this action, see Translations and Actions below for details on the events that can cause these callbacks to be called.

Convenience Routine

XmCreateIconButton - Widget creation convenience routine

Widget XmCreateIconButton(
	Widget parent,		/* Widget id of parent for IconButton */
	String name, 		/* Name of the created widget */
	ArgList args,		/* argument list */
	Cardinal num_args	/* number of items in argument list */
	)



Translations and Actions:
The following are the default translation bindings used by the icon button:
<Btn1Down>,<Btn1Up>: XmToggle() XmNotify()
<Btn1Down>(2): XmDoubleNotify()
<Btn1Down>: XmGetFocus() XmToggle()
<Key>osfSelect: XmArmAndActivate()
<Key>osfActivate: XmArmAndActivate()
None<Key>space: XmArmAndActivate()
None<Key>Return: XmArmAndActivate()
<Btn1Down>,<Leave> XmToggle() 
The following actions are supported by the icon button:
XmToggle()	Toggles the state of the icon button.
XmNotify()	Calls all routines on activateCallback list.
XmDoubleNotify()	Calls all routines on the doubleClickCallback list. 
XmArmAndActivated()	This action will arm the button, call the actions on the activateCallback
list, wait a fraction of a second and then disarm the button.
To use this button as a toggle button rather than a push button, replace the default
translation table with the following table.
<Btn1Down>: XmToggle() XmNotify()
<Btn1Up>(2): XmDoubleNotify()
<Key>osfSelect: XmToggle() XmNotify()
<Key>osfActivate: XmToggle() XmNotify()
None<Key>space: XmToggle() XmNotify()
None<Key>Return: XmToggle() XmNotify()
