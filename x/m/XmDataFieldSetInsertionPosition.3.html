NOMBRE

XmDataFieldSetInsertionPosition — Una función de DataField que establece la posición del cursor de inserción

SINOPSIS

#include <Xm/DataF.h>
void XmDataFieldSetInsertionPosition(
Widget widget,
XmDataPosition position);

DESCRIPCIÓN

XmDataFieldSetInsertionPosition establece la posición del cursor de inserción del widget DataField. Esta rutina también llama a las devoluciones de llamada XmNmotionVerifyCallback del widget si la posición del cursor de inserción cambia.

widget
Especifica el ID del widget DataField
position
Especifica la posición del cursor de inserción. Este es un número entero de caracteres desde el principio del búfer de texto. La primera posición de caracter es 0 (cero).

Para una definición completa de DataField y sus recursos asociados, consulte XmDataField(3).

RELACIONADO

XmDataField(3).
