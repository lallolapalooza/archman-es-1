XmPrintToFile(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmPrintToFile(llamada a biblioteca) XmPrintToFile(llamada a biblioteca)

NOMBRE

XmPrintToFile — Recupera y guarda datos que normalmente serían impresos por el servidor de impresión X.

SINOPSIS

#include <Xm/Print.h>
XtEnumXmPrintToFile(
Display*dpy,
Stringfilename,
XPFinishProcfinish_proc,
XtPointerclient_data);

DESCRIPCIÓN

XmPrintToFile oculta los detalles de la conexión de pantalla X y de XpGetDocumentData al programador de aplicaciones de Motif.

Esta función es una rutina de conveniencia que oculta los detalles internos de X y Xp al programador de aplicaciones llamando a la función XpGetDocumentData con las devoluciones de llamada de guardado y finalización apropiadas.

Esto se utiliza en el contexto de Impresión X cuando el usuario ha especificado la opción "imprimir a archivo" desde un cuadro de diálogo de Configuración de Impresión normal.

XmPrintToFile primero intenta abrir el nombre de archivo dado para escritura y devuelve False si no puede. De lo contrario, utiliza XpGetDocumentData, proporcionándole un procedimiento de guardado que escribe los datos recibidos en el archivo y un procedimiento de finalización que cierra el archivo o lo elimina en caso de una terminación insatisfactoria. Llama a finish_proc en ese momento, pasándole el argumento recibido de la capa Xp (status == XPGetDocFinished significa que el archivo es válido y se cerró, de lo contrario el archivo se eliminó).

XmPrintToFile no es bloqueante; si devuelve éxito, solo significa que el archivo se abrió correctamente, no que se recibieron todos los datos.

dpy
Conexión de pantalla de impresión.
filename
Nombre del archivo donde se colocarán los datos de impresión.
finish_proc
Se llama cuando se han recibido todos los datos.
client_data
Se pasa con finish_proc.

VALOR DE RETORNO

Devuelve False si el nombre de archivo no pudo ser creado o abierto para escritura, True en caso contrario.

ERRORES/ADVERTENCIAS

No aplicable

EJEMPLOS

Una devolución de llamada OK típica de un DtPrintSetupBox:

PrintOKCallback(widget...)
/*-------------*/
{   int save_data = XPSpool;
    pshell = XmPrintSetup (widget, pbs->print_screen,
                                   "Imprimir", NULL, 0);
    XtAddCallback(pshell, XmNstartJobCallback, startJobCB, data);
    if (pbs->destination == DtPRINT_TO_FILE)
                 save_data = XPGetData;
    /* start job debe preceder a XpGetDocumentData en XmPrintToFile */
    XpStartJob(XtDisplay(pshell), save_data);
    XFlush(XtDisplay(pshell));  /* mantener la secuencia
                                 entre startjob y getdocument */
    /* configurar impresión a archivo */
    if (pbs->destination == DtPRINT_TO_FILE)
        XmPrintToFile(XtDisplay(pshell),
                                 pbs->dest_info, FinishPrintToFile, NULL);
    }
}
static void
startJobCB(Widget, XtPointer call_data, XtPointer client_data)
{
  print(p);   /* el renderizado ocurre aquí */
  XpEndJob(XtDisplay(p->print_shell));
  /* limpieza */
  XtDestroyWidget(p->print_shell);
          XtCloseDisplay(XtDisplay(p->print_shell));
}
