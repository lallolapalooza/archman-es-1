NOMBRE

XmTextSetAddMode — Una función de Texto que establece el estado del modo de adición

SINOPSIS

#include <Xm/Text.h>
void XmTextSetAddMode(
Widget widget,
Boolean state);

DESCRIPCIÓN

XmTextSetAddMode controla si el widget de Texto está en modo de adición o no. Cuando el widget está en modo de adición, el cursor de inserción puede moverse sin alterar la selección principal.

widget
Especifica el ID del widget de Texto
state
Especifica si el widget está en modo de adición o no. Un valor de True activa el modo de adición; un valor de False desactiva el modo de adición.

Para una definición completa de Texto y sus recursos asociados, consulte XmText(3).
