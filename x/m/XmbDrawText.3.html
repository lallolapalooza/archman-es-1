XmbDrawText(3) FUNCIONES DE XLIB XmbDrawText(3)

NOMBRE

XmbDrawText, XwcDrawText, Xutf8DrawText - dibujar texto usando múltiples conjuntos de fuentes

SINTAXIS

void XmbDrawText(Display *display, Drawable d, GC gc, int x, int y, XmbTextItem *items, int nitems);

void XwcDrawText(Display *display, Drawable d, GC gc, int x, int y, XwcTextItem *items, int nitems);

void Xutf8DrawText(Display *display, Drawable d, GC gc, int x, int y, XmbTextItem *items, int nitems);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
items
Especifica un array de elementos de texto.
nitems
Especifica el número de elementos de texto en el array.
x

y
Especifican las coordenadas x e y.

DESCRIPCIÓN

Las funciones XmbDrawText, XwcDrawText y Xutf8DrawText permiten un espaciado complejo y cambios de conjunto de fuentes entre cadenas de texto. Cada elemento de texto se procesa en orden, con el origen de un elemento de texto avanzado en la dirección de dibujo primaria por el escapement del elemento de texto anterior. Un delta de elemento de texto especifica un escapement adicional del origen de dibujo del elemento de texto en la dirección de dibujo primaria. Un miembro font_set distinto de None en un elemento provoca que el conjunto de fuentes se utilice para este y los elementos de texto subsiguientes en la lista text_items. Los elementos de texto iniciales con un miembro font_set establecido en None no se dibujarán.

XmbDrawText, XwcDrawText y Xutf8DrawText no realizan ninguna representación dependiente del contexto entre los segmentos de texto. Los clientes pueden calcular las métricas de dibujo pasando cada segmento de texto a XmbTextExtents, XwcTextExtents, Xutf8TextExtents o XmbTextPerCharExtents, XwcTextPerCharExtents. Xutf8TextPerCharExtents. Cuando el XFontSet tiene conjuntos de caracteres faltantes, cada carácter no disponible se dibuja con la cadena predeterminada devuelta por XCreateFontSet. El comportamiento para un codepoint inválido no está definido.

La función Xutf8DrawText es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.

ESTRUCTURAS

La estructura XmbTextItem contiene:

typedef struct {
        char *chars;    /* puntero a la cadena */
        int nchars;     /* número de bytes */
        int delta;      /* delta de píxeles entre cadenas */
        XFontSet font_set;      /* fuentes, None significa no cambiar */
} XmbTextItem;

La estructura XwcTextItem contiene:

typedef struct {
        wchar_t *chars; /* puntero a la cadena de caracteres anchos */
        int nchars;     /* número de caracteres anchos */
        int delta;      /* delta de píxeles entre cadenas */
        XFontSet font_set;      /* fuentes, None significa no cambiar */
} XwcTextItem;
