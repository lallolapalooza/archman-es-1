NOMBRE

XmDropTransferAdd — Una función de Arrastrar y Soltar que permite procesar entradas de transferencia de soltar adicionales después de iniciar una transferencia de soltar

SINOPSIS

#include <Xm/DragDrop.h>
void XmDropTransferAdd(
Widget drop_transfer,
XmDropTransferEntryRec *transfers,
Cardinal num_transfers);

DESCRIPCIÓN

XmDropTransferAdd identifica una lista de entradas de transferencia de soltar adicionales que se procesarán después de que se inicie una transferencia de soltar.

drop_transfer
Especifica el ID del widget DropTransfer devuelto por XmDropTransferStart
transfers
Especifica las entradas de transferencia de soltar adicionales que el receptor desea que se procesen
num_transfers
Especifica el número de elementos en el array transfers

Para obtener una definición completa de DropTransfer y sus recursos asociados, consulte XmDropTransfer(3).

RELACIONADOS

XmDragContext(3), XmDropTransfer(3), y XmDropTransferStart(3).
