XML::Stream::Namespace(3) Documentación de Perl aportada por el usuario XML::Stream::Namespace(3)

NOMBRE

XML::Stream::Namespace - Objeto para facilitar la definición de Espacios de Nombres en
XML::Stream.

SINOPSIS

XML::Stream::Namespace es un paquete auxiliar para XML::Stream. Proporciona una forma limpia de definir Espacios de Nombres para que XML::Stream los utilice al conectarse.

DESCRIPCIÓN

Este módulo le permite establecer y leer elementos de un Espacio de Nombres de XML::Stream.

MÉTODOS

SetNamespace("mi_espacio_de_nombres");
SetXMLNS("http://www.mi_espacio_de_nombres.com/xmlns");
SetAttributes(atributo1=>"valor1",
              atributo2=>"valor2");
GetNamespace() devuelve "mi_espacio_de_nombres"
GetXMLNS() devuelve "http://www.mi_espacio_de_nombres.com/xmlns"
GetAttributes() devuelve un hash ( atributo1=>"valor1",atributo2=>"valor2")
GetStream() devuelve la siguiente cadena:
  "xmlns:mi_espacio_de_nombres='http://www.mi_espacio_de_nombres.com/xmlns' 
   mi_espacio_de_nombres:atributo1='valor1' 
   mi_espacio_de_nombres:atributo2='valor2'"

EJEMPLOS

$miNamespace = XML::Stream::Namespace->new("mi_espacio_de_nombres");
$miNamespace->SetXMLNS("http://www.mi_espacio_de_nombres.org/xmlns");
$miNamespace->SetAttributes(foo=>"bar",
                            bob=>"vila");
$stream = XML::Stream->new;
$stream->Connect(name=>"foo.bar.org",
                 port=>1234,
                 namespace=>"foo:bar",
                 namespaces=>[ $miNamespace ]);
#
# Lo anterior en Connect enviará la siguiente cadena de apertura
# del stream a foo.bar.org:1234...
#
#   <stream:stream 
#    xmlns:stream="http://etherx.jabber.org/streams"
#    to="foo.bar.org"
#    xmlns="foo:bar" 
#    xmlns:mi_espacio_de_nombres="http://www.mi_espacio_de_nombres.org/xmlns"
#    mi_espacio_de_nombres:foo="bar"
#    mi_espacio_de_nombres:bob="vila">
#
