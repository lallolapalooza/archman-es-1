XmSpinBoxValidatePosition(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmSpinBoxValidatePosition(llamada a biblioteca) XmSpinBoxValidatePosition(llamada a biblioteca)

NOMBRE

XmSpinBoxValidatePosition — traduce el valor actual del hijo XmSpinBox especificado a una posición válida

SINOPSIS

#include <Xm/SpinBox.h>
int XmSpinBoxValidatePosition(
Widget textfield,
int *position);

DESCRIPCIÓN

La función XmSpinBoxValidatePosition es una utilidad que puede ser utilizada por aplicaciones que deseen implementar una política para rastrear las modificaciones del usuario en hijos editables de XmSpinBox de tipo XmNUMERIC. Los detalles de cuándo y cómo las modificaciones del usuario surten efecto quedan a cargo de la aplicación.

textfield
El argumento textfield especifica el ID del widget del hijo del XmSpinBox que está siendo modificado. El requisito sobre textfield es que posea el rasgo accessTextual (que ya es un requisito para los hijos de XmSpinBox). De esta manera, XmSpinBox puede extraer la cadena del widget textfield (incluso si no es un XmTextField).
position
A la ubicación apuntada por el argumento position se le asigna el resultado de la traducción realizada por XmSpinBoxValidatePosition. XmSpinBoxValidatePosition primero verifica que sea un hijo de XmNUMERIC XmSpinBox. Si no lo es, XSmpinBoxValidatePosition establece position al valor actual y devuelve XmCURRENT_VALUE.

XmSpinBoxValidatePosition intenta traducir la cadena de entrada a un número de punto flotante. Si esta traducción falla, XmSpinBoxValidatePosition establece position al valor actual y devuelve XmCURRENT_VALUE.

XmSpinBoxValidatePosition convierte el número de punto flotante a un entero utilizando el recurso XmNdecimalPoints. Se truncan los lugares decimales adicionales. El entero resultante se comprueba para asegurarse de que esté dentro del rango válido definido por XmNminimumValue y XmNmaximumValue inclusive. Si la entrada cae fuera de este rango, XmSpinBoxValidatePosition establece position al límite más cercano y devuelve XmMINIMUM_VALUE o XmMAXIMUM_VALUE.

Finalmente, XmSpinBoxValidatePosition comprueba el entero para asegurarse de que pertenezca a la serie definida por XmNminimumValue ... XmNminimumValue + ((n - 1) * XmNincrementValue). Si el entero no pertenece a esta serie, XmSpinBoxValidatePosition establece position al elemento más cercano que sea menor o igual al entero y devuelve XmINCREMENT_VALUE.

De lo contrario, XmSpinBoxValidatePosition asigna el entero a position y devuelve XmVALID_VALUE.

VALOR DE RETORNO

La función XmSpinBoxValidatePosition devuelve el estado de la validación. El conjunto de valores posibles devueltos es el siguiente:

XmCURRENT_VALUE
No se puede convertir, devuelve el valor de posición actual.
XmMINIMUM_VALUE
Menor que el mínimo.
XmMAXIMUM_VALUE
Mayor que el máximo.
XmINCREMENT_VALUE
No está en el incremento.
XmVALID_VALUE
Correcto.

EJEMPLOS

El primer ejemplo demuestra cómo se podría usar la función XmSpinBoxValidatePosition desde dentro de una devolución de llamada XmNmodifyVerifyCallback instalada en el XmSpinBox o en el XmSimpleSpinBox:

/*
 * Instalar una devolución de llamada en la pulsación de una flecha de spin box.
 */
  XtAddCallback(sb, XmNmodifyVerifyCallback, ModifyVerifyCB, NULL);
  XtAddCallback(simple_sb, XmNmodifyVerifyCallback, ModifyVerifyCB, NULL);

con la devolución de llamada haciendo:

void ModifyVerifyCB(widget, call_data, client_data) {
    XmSpinBoxCallbackStruct *cbs = (XmSpinBoxCallbackStruct*) call_data;
    int position;
    Widget textual = NULL;
    if (XtIsSubclass(w, xmSimpleSpinBoxWidgetClass))
    {
        Arg args[1];
        XtSetArg(args[0], XmNtextField, &textual);
        XtGetValues(w, args, 1);
    }
    else if (XtIsSubclass(w, xmSpinBoxWidgetClass))
      textual = cbs->widget;
    else
      textual = (Widget) NULL;
    ...
    if (XmSpinBoxValidatePosition(textual, &position) == XmCURRENT_VALUE)
      XBell(XtDisplay(w), 0);
    else
      cbs->position = position;
}

Este segundo ejemplo demuestra cómo se podría usar la función XmSpinBoxValidatePosition desde dentro de una devolución de llamada XmNactivateCallback instalada en el hijo TextField del XmSpinBox:

/*
 * Instalar una devolución de llamada en la pulsación de una flecha de spin box.
 */
XtAddCallback(tf, XmNactivateCallback, ModifyVerifyChildCB, NULL);

con la devolución de llamada haciendo:

void ModifyVerifyChildCB(widget, call_data, client_data) {
    int     position;
    Widget  textual = widget;
    Arg     args[1];
    if (XmSpinBoxValidatePosition (textual, &position) == XmCURRENT_VALUE)
      XBell(XtDisplay(widget), 0);
    /* Establecer el recurso de restricción de posición del textfield */
    XtSetArg(args[0], XmNposition, position);
    XtSetValues(textual, args, 1);
}
