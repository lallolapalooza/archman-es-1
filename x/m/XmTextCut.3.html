NOMBRE

XmTextCut — Una función de texto que copia la selección primaria al portapapeles y elimina el texto seleccionado

SINOPSIS

#include <Xm/Text.h>
Boolean XmTextCut(
Widget widget,
Time time);

DESCRIPCIÓN

XmTextCut copia el texto seleccionado primariamente al portapapeles y luego elimina el texto seleccionado primariamente. Esta rutina llama a los callbacks de XmNvalueChangedCallback y de verificación del widget, ya sea XmNmodifyVerifyCallback o XmNmodifyVerifyCallbackWcs, o ambos. Si ambas listas de callbacks de verificación están registradas, los procedimientos de la lista XmNmodifyVerifyCallback se ejecutan primero y los datos resultantes se pasan a los callbacks de XmNmodifyVerifyCallbackWcs.

Esta rutina llama a los procedimientos XmNconvertCallback, posiblemente varias veces, con el miembro selection de XmConvertCallbackStruct establecido a CLIPBOARD y con el miembro parm establecido a XmMOVE. Si la transferencia es exitosa, esta rutina luego llama a los procedimientos XmNconvertCallback para la selección CLIPBOARD y el objetivo DELETE.

widget
Especifica el ID del widget de Texto.
time
Especifica la hora del servidor en la que se va a modificar el valor de la selección. Esta debería ser la hora del evento que desencadenó esta solicitud. Una fuente de una marca de tiempo válida es la función XtLastTimestampProcessed().

Para una definición completa de Texto y sus recursos asociados, consulte XmText(3).

RETORNO

Esta función devuelve False si la selección primaria es NULL, si el widget no posee la selección primaria, si la función no puede obtener la propiedad de la selección del portapapeles, o si no se colocan datos en el portapapeles. De lo contrario, devuelve True.

RELACIONADO
