NOMBRE

XmRemoveWMProtocolCallback — Una interfaz de conveniencia de VendorShell que elimina un callback de la lista interna

SINOPSIS

#include <Xm/Xm.h>
#include <Xm/Protocols.h>
void XmRemoveWMProtocolCallback(
Widget shell,
Atom protocol,
XtCallbackProc callback,
XtPointer closure);

DESCRIPCIÓN

XmRemoveWMProtocolCallback es una interfaz de conveniencia. Llama a XmRemoveProtocolCallback con el valor de propiedad establecido en el átomo devuelto al internar WM_PROTOCOLS.

shell
Especifica el widget al que está asociada la propiedad del protocolo.
protocol
Especifica el átomo del protocolo.
callback
Especifica el procedimiento a llamar cuando se recibe un mensaje de protocolo.
closure
Especifica los datos del cliente que se pasarán al callback cuando se invoque.

Para obtener una definición completa de VendorShell y sus recursos asociados, consulte VendorShell(3).

RELACIONADO

VendorShell(3), XmAddWMProtocolCallback(3), XmInternAtom(3), y XmRemoveProtocolCallback(3).
