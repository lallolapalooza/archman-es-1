XMappingEvent(3)

Paquete: libx11

Licencias: MIT AND X11

XMapEvent(3) FUNCIONES DE XLIB XMapEvent(3)

NOMBRE

XMapEvent, XMappingEvent - Estructuras de eventos MapNotify y MappingNotify

ESTRUCTURAS

La estructura para eventos MapNotify contiene:

typedef struct {
        int type;       /* MapNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display desde el que se leyó el evento */
        Window event;
        Window window;
        Bool override_redirect; /* booleano, ¿está configurado override...? */
} XMapEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero al display en el que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número serial reportado en el protocolo pero expandido desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

El miembro event se establece en la ventana que se mapeó o en su padre, dependiendo de si se seleccionó StructureNotify o SubstructureNotify. El miembro window se establece en la ventana que se mapeó. El miembro override_redirect se establece en el atributo override-redirect de la ventana. Los clientes del gestor de ventanas normalmente deberían ignorar esta ventana si el atributo override-redirect es True, porque estos eventos generalmente se generan a partir de pop-ups, que anulan el control de la estructura.

La estructura para eventos MappingNotify es:

typedef struct {
        int type;       /* MappingNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display desde el que se leyó el evento */
        Window window;  /* no utilizado */
        int request;    /* uno de MappingModifier, MappingKeyboard,
                   MappingPointer */
        int first_keycode;      /* keycode inicial */
        int count;      /* define el rango de cambio con first_keycode*/
} XMappingEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero al display en el que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número serial reportado en el protocolo pero expandido desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkits.

El miembro request se establece para indicar el tipo de cambio de mapeo que ocurrió y puede ser MappingModifier, MappingKeyboard, MappingPointer. Si es MappingModifier, el mapeo del modificador cambió. Si es MappingKeyboard, el mapeo del teclado cambió. Si es MappingPointer, el mapeo de los botones del puntero cambió. Los miembros first_keycode y count se establecen solo si el miembro request se estableció en MappingKeyboard. El número en first_keycode representa el primer número en el rango del mapeo alterado, y count representa el número de keycodes alterados.
