NOMBRE

XmListGetSelectedPos — Una función de Lista que devuelve la posición de cada elemento seleccionado en la lista

SINOPSIS

#include <Xm/List.h>
Boolean XmListGetSelectedPos(
Widget widget,
int **position_list,
int *position_count);

DESCRIPCIÓN

Esta rutina está obsoleta. Está reemplazada por la llamada a XtGetValues para los recursos de la Lista XmNselectedPositions y XmNselectedPositionCount. XmListGetSelectedPos es una función booleana que devuelve una matriz de las posiciones de los elementos seleccionados en una Lista.

widget
Especifica el ID del widget Lista.
position_list
Devuelve una matriz de las posiciones de los elementos seleccionados en la Lista. La posición del primer elemento en la lista es 1; la posición del segundo elemento es 2; y así sucesivamente. Cuando el valor de retorno es True, XmListGetSelectedPos asigna memoria para esta matriz. El llamador es responsable de liberar esta memoria. El llamador puede recuperar la memoria asignada llamando a XtFree.
position_count
Devuelve el número de elementos en la position_list.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).

RETORNO

Devuelve True si la lista tiene algún elemento seleccionado y False si no.

RELACIONADO

XmList(3).
