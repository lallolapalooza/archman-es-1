NOMBRE

XmScaleSetTicks — Una función de Scale que controla las marcas de graduación

SINOPSIS

#include <Xm/Scale.h>
void XmScaleSetTicks(
Widget scale,
int big_every,
Cardinal num_medium,
Cardinal num_small,
Dimension size_big,
Dimension size_medium,
Dimension size_small);

DESCRIPCIÓN

XmScaleSetTicks controla el número, la ubicación y el tamaño de las marcas de graduación en un Scale. Cada marca de graduación es un SeparatorGadget orientado perpendicularmente a la orientación del Scale. Por ejemplo, si el Scale está orientado horizontalmente, las marcas de graduación estarán orientadas verticalmente.

Si especifica marcas de graduación para un Scale y luego cambia la orientación del Scale, deberá hacer lo siguiente:

•
Eliminar todas las marcas de graduación. Para eliminar las marcas de graduación de un Scale, debe destruir (con XtDestroyChildren) las marcas de graduación SeparatorGadget. Los dos primeros hijos de un Scale son su título y su barra de desplazamiento, y todos los hijos adicionales son marcas de graduación.
•
Volver a crear las marcas de graduación llamando a XmScaleSetTicks.
scale
Especifica el identificador del widget Scale al que se le están añadiendo las marcas de graduación.
big_every
Especifica el número de valores de escala entre las marcas grandes.
num_medium
Especifica el número de marcas medianas entre los valores grandes.
num_small
Especifica el número de marcas pequeñas entre los valores medianos.
size_big
Especifica el tamaño (ancho o alto) de las marcas grandes.
size_medium
Especifica el tamaño (ancho o alto) de las marcas medianas.
size_small
Especifica el tamaño (ancho o alto) de las marcas pequeñas.

Para una definición completa de Scale y sus recursos asociados, consulte XmScale(3).
