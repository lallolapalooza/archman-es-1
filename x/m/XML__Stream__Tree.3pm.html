XML::Stream::Tree(3) Documentación de Perl aportada por el usuario XML::Stream::Tree(3)

NOMBRE

XML::Stream::Tree - Funciones para facilitar la construcción y el análisis del árbol.

SINOPSIS

  Solo una colección de funciones que no necesitan estar en memoria si eliges uno de los otros métodos de almacenamiento de datos.

FORMATO

El resultado del análisis:

<foo><head id="a">Hola <em>ahí</em></head><bar>Saludos

sería:
  

   Etiqueta Contenido
  

   ==================================================================
  

   [foo, [{},
  

   head, [{id => "a"},
  

   0, "Hola ",
  

   em, [{},
  

   0, "ahí"
  

   ]
  

   ],
  

   bar, [{},
  

   0, "Saludos",
  

   ref, [{}]
  

   ],
  

   0, "do"
  

   ]
  

   ]
