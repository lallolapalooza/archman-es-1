NOMBRE

XmSetFontUnit — Una función que establece el valor de la unidad de fuente para una pantalla

SINOPSIS

#include <Xm/Xm.h>
void XmSetFontUnit(
Display * display,
int font_unit_value);

DESCRIPCIÓN

XmSetFontUnit proporciona una función externa para inicializar valores de unidades de fuente. Las aplicaciones pueden querer especificar datos independientes de la resolución basándose en un tamaño de fuente global. Consulte la descripción del recurso XmNunitType en las páginas de referencia de XmGadget, XmManager y XmPrimitive para obtener más información sobre la independencia de la resolución.

Esta función establece las unidades de fuente para todas las pantallas de la pantalla.

NOTA: XmSetFontUnit es obsoleto y existe por compatibilidad con versiones anteriores. En lugar de usar esta función, proporcione valores iniciales o llame a XtSetValues para los recursos XmScreen XmNhorizontalFontUnit y XmNverticalFontUnit.

display
Define la pantalla para la cual se aplicará este valor de unidad de fuente.
font_unit_value
Especifica el valor que se utilizará tanto para las unidades de fuente horizontales como verticales en los cálculos de conversión.

RELACIONADOS

XmConvertUnits(3), XmSetFontUnits(3), XmGadget(3), XmManager(3), XmPrimitive(3), y XmScreen(3).
