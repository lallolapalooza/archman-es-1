XML::XPath::XMLParser(3) Documentación de Perl aportada por el usuario XML::XPath::XMLParser(3)

NOMBRE

XML::XPath::XMLParser - La clase de análisis XML por defecto que produce un árbol de nodos

SINOPSIS

my $parser = XML::XPath::XMLParser->new(
            filename => $self->get_filename,
            xml => $self->get_xml,
            ioref => $self->get_ioref,
            parser => $self->get_parser,
        );
my $root_node = $parser->parse;

DESCRIPCIÓN

Este módulo genera un árbol de nodos para usarlo como nodo de contexto para el procesamiento de XPath. Su objetivo es ser un analizador rápido, nada sofisticado, y aun así tiene que almacenar más información que la mayoría de los analizadores. Para lograr esto, he utilizado referencias a arrays en todas partes, sin hashes. No tengo cifras de rendimiento para las mejoras logradas, así que no me disculpo con nadie que no esté acostumbrado a usar arrays en lugar de hashes. Creo que tienen buen sentido aquí, donde conocemos los atributos de cada tipo de nodo.

ESTRUCTURA DE NODO

Todos los nodos tienen las dos primeras entradas en el array: node_parent y node_pos. El tipo de nodo se determina usando la función ref(). El node_parent siempre contiene una entrada para el padre del nodo actual, excepto para el nodo raíz que tiene undef ahí. Y node_pos es la posición de este nodo en el array en el que se encuentra (piensa: $node == $node->[node_parent]->[node_children]->[$node->[node_pos]] )

Los nodos se estructuran de la siguiente manera:

NODO RAÍZ

El nodo raíz es simplemente un nodo de elemento sin padre.

[
  undef, # node_parent - comprueba undef para identificar el nodo raíz
  undef, # node_pos
  undef, # node_prefix
  [ ... ], # node_children (ver más abajo)
]

NODO DE ELEMENTO

[
  $parent, # node_parent
  <posición en el array actual>, # node_pos
  'xxx', # node_prefix - prefijo de espacio de nombres en este elemento
  [ ... ], # node_children
  'yyy', # node_name - nombre de etiqueta del elemento
  [ ... ], # node_attribs - atributos en este elemento
  [ ... ], # node_namespaces - espacios de nombres actualmente en ámbito
]

NODO DE ATRIBUTO

[
  $parent, # node_parent - el nodo de elemento
  <posición en el array actual>, # node_pos
  'xxx', # node_prefix - prefijo de espacio de nombres en este elemento
  'href', # node_key - nombre del atributo
  'ftp://ftp.com/', # node_value - valor en el nodo
]

NODOS DE ESPACIO DE NOMBRES

Cada elemento tiene un conjunto asociado de nodos de espacio de nombres que están actualmente en ámbito. Cada nodo de espacio de nombres almacena un prefijo y el nombre expandido (obtenido del atributo xmlns:prefix="...").

[
  $parent,
  <pos>,
  'a', # node_prefix - el espacio de nombres tal como se escribió como prefijo
  'http://my.namespace.com', # node_expanded - el nombre expandido.
]

NODOS DE TEXTO

[
  $parent,
  <pos>,
  'Este es algo de texto' # node_text - el texto en el nodo
]

NODOS DE COMENTARIO

[
  $parent,
  <pos>,
  'Este es un comentario' # node_comment
]

NODOS DE INSTRUCCIÓN DE PROCESAMIENTO

[
  $parent,
  <pos>,
  'target', # node_target
  'data', # node_data
]

USO

Si sientes la necesidad de usar este módulo fuera de XML::XPath (por ejemplo, podrías usar este módulo directamente para poder almacenar en caché árboles analizados), puedes seguir la siguiente API:

new

El método new no toma parámetros, o toma cualquiera de los siguientes parámetros:

filename
xml
parser
ioref

Esto utiliza la sintaxis familiar de hash, así que un ejemplo podría ser:

use XML::XPath::XMLParser;
my $parser = XML::XPath::XMLParser->new(filename => 'ejemplo.xml');

Los parámetros representan un nombre de archivo, una cadena que contiene XML, una instancia de XML::Parser y una referencia a un manejador de archivos abierto respectivamente. También puedes establecer u obtener todas estas propiedades usando las funciones get_ y set_ que tienen el mismo nombre que la propiedad: por ejemplo, get_filename, set_ioref, etc.

parse

El método parse generalmente no toma parámetros, sin embargo, eres libre de pasar una referencia a un manejador de archivos abierto o una cadena XML si lo deseas. El valor de retorno es un árbol que XML::XPath puede usar. El método parse fallará si hay un error en tu XML, así que asegúrate de usar el mecanismo de manejo de excepciones de perl (eval{};) si quieres evitar esto.

parsefile

El método parsefile es idéntico a parse() excepto que espera un solo parámetro que es una cadena que nombra un archivo para abrir y analizar. De nuevo, devuelve un árbol y también falla si hay errores XML.
