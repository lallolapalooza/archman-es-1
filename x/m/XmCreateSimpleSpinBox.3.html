NOMBRE

XmCreateSimpleSpinBox — la función de creación del widget SimpleSpinBox

SINOPSIS

#include <Xm/SSpinB.h>
Widget XmCreateSimpleSpinBox(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

La función XmCreateSimpleSpinBox crea una instancia de un widget SpinBox y devuelve su ID de widget.

El argumento parent especifica el ID del widget padre.

El argumento name especifica el nombre del widget creado.

El argumento arglist especifica la lista de argumentos.

El argumento argcount especifica el número de pares atributo/valor en la lista de argumentos.

VALOR DE RETORNO

Al completarse con éxito, la función XmCreateSimpleSpinBox devuelve el ID del widget SimpleSpinBox.
