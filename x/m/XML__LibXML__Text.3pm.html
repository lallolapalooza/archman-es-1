XML::LibXML::Text(3) Documentación de Perl aportada por el usuario XML::LibXML::Text(3)

NOMBRE

XML::LibXML::Text - Clase de XML::LibXML para Nodos de Texto

SINOPSIS

use XML::LibXML;
# Solo se enumeran aquí los métodos específicos para nodos de Texto,
# ver la página del manual de XML::LibXML::Node para otros métodos
$texto = XML::LibXML::Text->new( $contenido );
$datos_nodo = $texto->data;
$texto->setData( $contenido_texto );
$texto->substringData($offset, $longitud);
$texto->appendData( $algunos_datos );
$texto->insertData($offset, $cadena);
$texto->deleteData($offset, $longitud);
$texto->deleteDataString($cadena_a_eliminar, $todo);
$texto->replaceData($offset, $longitud, $cadena);
$texto->replaceDataString($cadena_antigua, $cadena_nueva, $bandera);
$texto->replaceDataRegEx( $condicion_busqueda, $condicion_reemplazo, $banderas_re );

DESCRIPCIÓN

A diferencia de la especificación DOM, XML::LibXML implementa el nodo de texto como la clase base de todos los nodos de datos de caracteres. Por lo tanto, no existe una clase CharacterData. Esto permite aplicar métodos de nodos de texto también a Comentarios y secciones CDATA.

MÉTODOS

La clase hereda de XML::LibXML::Node. La documentación de los métodos heredados no se lista aquí.

Muchas de las funciones enumeradas aquí están extensamente documentadas en la especificación DOM Nivel 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Por favor, consulte la especificación para obtener documentación detallada.

new
$texto = XML::LibXML::Text->new( $contenido );

El constructor de la clase. Crea un nodo de texto no enlazado.

data
$datos_nodo = $texto->data;

Aunque existe el atributo "nodeValue" en la clase Node, la especificación DOM define los datos como un atributo separado. "XML::LibXML" implementa estos dos atributos no como atributos diferentes, sino como alias, tal como lo hace "libxml2". Por lo tanto

$texto->data;

y

$texto->nodeValue;

tendrán el mismo resultado y no son entidades diferentes.

setData($cadena)
$texto->setData( $contenido_texto );

Esta función establece o reemplaza el contenido de texto de un nodo. El nodo debe ser del tipo "text", "cdata" o "comment".

substringData($offset,$longitud)
$texto->substringData($offset, $longitud);

Extrae un rango de datos del nodo. (Especificación DOM) Esta función toma los dos parámetros $offset y $longitud y devuelve la subcadena, si está disponible.

Si el nodo no contiene datos o $offset se refiere a un índice de cadena inexistente, esta función devolverá undef. Si $longitud está fuera de rango, "substringData" devolverá los datos comenzando en $offset en lugar de generar un error.

appendData($cadena)
$texto->appendData( $algunos_datos );

Añade una cadena al final de los datos existentes. Si el nodo de texto actual no contiene datos, esta función tiene el mismo efecto que "setData".

insertData($offset,$cadena)
$texto->insertData($offset, $cadena);

Inserta el parámetro $cadena en el $offset dado de los datos existentes del nodo. Esta operación no eliminará datos existentes, sino que cambiará el orden de los datos existentes.

El $offset debe ser un valor positivo. Si $offset está fuera de rango, "insertData" tendrá el mismo comportamiento que "appendData".

deleteData($offset, $longitud)
$texto->deleteData($offset, $longitud);

Este método elimina un fragmento de los datos del nodo existente en el desplazamiento dado. El parámetro $longitud indica cuántos caracteres deben eliminarse de la cadena.

deleteDataString($cadena, [$todo])
$texto->deleteDataString($cadena_a_eliminar, $todo);

Este método elimina un fragmento de los datos del nodo. Dado que la especificación DOM es bastante poco práctica si ya conoces "qué" cadena eliminar de un nodo de texto, este método permite un código más al estilo Perl :)

La función toma dos parámetros: $cadena y opcionalmente la bandera $todo. Si $todo no está establecido, undef o 0, "deleteDataString" eliminará solo la primera ocurrencia de $cadena. Si $todo es TRUE"deleteDataString" eliminará todas las ocurrencias de $cadena de los datos del nodo .

replaceData($offset, $longitud, $cadena)
$texto->replaceData($offset, $longitud, $cadena);

La versión estilo DOM para reemplazar datos de nodos.

replaceDataString($cadena_antigua, $cadena_nueva, [$todo])
$texto->replaceDataString($antigua, $nueva, $bandera);

La versión más amigable para el programador de replaceData() :)

En lugar de proporcionar desplazamientos y longitudes, se puede especificar la cadena exacta ($cadena_antigua) a reemplazar. Además, la bandera $todo permite reemplazar todas las ocurrencias de $cadena_antigua.

replaceDataRegEx( $condicion_busqueda, $condicion_reemplazo, $banderas_re )
$texto->replaceDataRegEx( $condicion_busqueda, $condicion_reemplazo, $banderas_re );

Este método reemplaza los datos del nodo mediante una expresión regular "simple". Opcionalmente, esta función permite pasar algunas banderas que se añadirán como bandera a la sentencia de reemplazo.

NOTA: Esto es un atajo para

my $datastr = $nodo->getData();
 $datastr =~ s/condicion_alguna/reemplazo/g; # 'g' es solo un ejemplo de cualquier bandera
 $nodo->setData( $datastr );

Esta función puede hacer que las cosas sean más fáciles de leer para reemplazos simples. Para variantes más complejas, se recomienda usar el fragmento de código anterior.

XML::LibXML::Text(3pm)

NOMBRE

XML::LibXML::Text - Nodo de texto para XML::LibXML

SINÓPSIS

use XML::LibXML::Text;

my $text = XML::LibXML::Text->new( data => "Hola mundo" );
print $text->toString();

DESCRIPCIÓN

Esta clase representa un nodo de texto en un árbol DOM de XML::LibXML.

MÉTODOS

new( data => "...", )
Crea un nuevo nodo de texto con los datos especificados.
toString()
Devuelve los datos del nodo de texto como una cadena.
