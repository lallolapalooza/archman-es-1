NOMBRE

XmOptionLabelGadget — Una función de RowColumn que obtiene el ID del widget para el LabelGadget en un OptionMenu

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmOptionLabelGadget(
Widget option_menu);

DESCRIPCIÓN

XmOptionLabelGadget proporciona a la aplicación los medios para obtener el ID del widget para el LabelGadget creado internamente. Una vez que la aplicación ha obtenido el ID del widget, puede ajustar la apariencia del LabelGadget, si lo desea.

option_menu
Especifica el ID del widget OptionMenu

Cuando una aplicación crea una instancia del widget OptionMenu, el widget crea dos gadgets internos. Uno es un LabelGadget que se utiliza para mostrar el recurso XmNlabelString de RowColumn. El otro es un CascadeButtonGadget que muestra la selección actual y proporciona los medios para mostrar el submenú del OptionMenu.

El usuario puede especificar recursos en un archivo de recursos para los widgets y gadgets creados automáticamente de un OptionMenu. La siguiente lista identifica los nombres de estos widgets (o gadgets) y las áreas asociadas del OptionMenu.

Gadget de etiqueta del menú de opciones
OptionLabel
Botón de cascada del menú de opciones
OptionButton

Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget para la etiqueta interna.

RELACIONADOS

XmCreateOptionMenu(3), XmLabelGadget(3), XmOptionButtonGadget(3) y XmRowColumn(3).
