NOMBRE

XmTextInsert — Una función de texto que inserta una cadena de caracteres en una cadena de texto

SINOPSIS

#include <Xm/Text.h>
void XmTextInsert(
Widget widget,
XmTextPosition position,
char * value);

DESCRIPCIÓN

XmTextInsert inserta una cadena de caracteres en la cadena de texto del widget Text. Las posiciones de los caracteres comienzan en 0 (cero) y se numeran secuencialmente desde el principio del texto. Por ejemplo, para insertar una cadena después del cuarto carácter, el parámetro position debe ser 4.

Esta rutina llama a los callbacks de XmNvalueChangedCallback del widget y a los callbacks de verificación, ya sea XmNmodifyVerifyCallback o XmNmodifyVerifyCallbackWcs, o ambos. Si ambas listas de callbacks de verificación están registradas, los procedimientos de la lista XmNmodifyVerifyCallback se ejecutan primero y los datos resultantes se pasan a los callbacks de XmNmodifyVerifyCallbackWcs. Si el recurso XmNcursorPosition es mayor o igual al valor de position, se llama a XmNmotionVerifyCallback.

Tenga en cuenta que, si value es una cadena nula, no se generarán callbacks, ya que no se habrán realizado modificaciones.

widget
Especifica el ID del widget Text.
position
Especifica la posición en la cadena de texto donde se insertará la cadena de caracteres.
value
Especifica el valor de la cadena de caracteres que se añadirá al widget de texto.

Para una definición completa de Text y sus recursos asociados, consulte XmText(3).

RELACIONADO

XmText(3) y XmTextInsertWcs(3).
