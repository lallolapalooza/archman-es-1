NOMBRE

XmPushButton — Clase del widget PushButton

SINOPSIS

#include <Xm/PushB.h>

DESCRIPCIÓN

PushButton emite comandos dentro de una aplicación. Consiste en una etiqueta de texto o un pixmap rodeado por una sombra de borde. Cuando un PushButton se selecciona, la sombra cambia para dar la apariencia de que ha sido presionado. Cuando un PushButton se deselecciona, la sombra cambia para dar la apariencia de que está hacia afuera.

El comportamiento predeterminado asociado con un PushButton en un menú depende del tipo de sistema de menú en el que reside. Por defecto, <Btn1> controla el comportamiento del PushButton. Además, <Btn3> controla el comportamiento del PushButton si reside en un sistema PopupMenu. El botón del ratón real utilizado se determina por su padre RowColumn.

El grosor de una segunda sombra, utilizada cuando el PushButton es el botón predeterminado, se puede especificar con el recurso XmNshowAsDefault. Si tiene un valor distinto de cero, los recursos del Label XmNmarginLeft, XmNmarginRight, XmNmarginTop, y XmNmarginBottom pueden modificarse para acomodar la segunda sombra.

Si se especifica un valor inicial para XmNarmPixmap pero no para XmNlabelPixmap, el valor de XmNarmPixmap se utiliza para XmNlabelPixmap.

PushButton utiliza los traits XmQTmenuSystem y XmQTspecifyRenderTable, y posee los traits XmQactivatable, XmQTmenuSavvy, y XmQTtakesDefault.

CLASES

PushButton hereda comportamiento, recursos y traits de Core, XmPrimitive, y XmLabel.

El puntero de clase es xmPushButtonWidgetClass.

El nombre de la clase es XmPushButton.

Resources

XmNarmColor
Specifies the color to be used for the background of the PushButton when it is armed. For a color display, this color is between the background and the bottom shadow color. For a monochrome display, the default is set to the foreground color, and any text in the label appears in the background color when the button is armed.
XmNarmShadowThickness
Specifies the width of the shadow for the PushButton when it is armed. For a color display, this resource is a color between the background and the bottom shadow color. For a monochrome display, the default is set to the foreground color, and any text in the label appears in the background color when the button is armed.
This resource is also used when the button is armed in a menu and the XmNenableEtchedInMenu resource is True.
XmNarmPixmap
Specifies the pixmap to be used as the button face if XmNlabelType is XmPIXMAP or XmPIXMAP_AND_STRING and PushButton is armed. This resource is disabled when the PushButton is in a menu.
XmNdefaultButtonShadowThickness
This resource specifies the width of the default button indicator shadow. If this resource is 0 (zero), the width of the shadow comes from the value of the XmNshowAsDefault resource. If this resource is greater than 0, the XmNshowAsDefault resource is only used to specify whether this button is the default. The default value is the initial value of XmNshowAsDefault.
XmNdisarmCallback
Specifies the list of callbacks that is called when PushButton is disarmed. PushButton is disarmed when the user presses and releases the active mouse button while the pointer is inside that widget. For this callback, the reason is XmCR_DISARM.
XmNfillOnArm
Forces the PushButton to fill the background of the button with the color specified by XmNarmColor when the button is armed and when this resource is set to True. If False, only the top and bottom shadow colors are switched. When the PushButton is in a menu, this resource is ignored and assumed to be False.
XmNmultiClick
If a button click is followed by another button click within the time span specified by the display's multiclick time, and this resource is set to XmMULTICLICK_DISCARD, do not process the second click. If this resource is set to XmMULTICLICK_KEEP, process the event and increment click_count in the callback structure. When the button is in a menu, the default is XmMULTICLICK_DISCARD; otherwise, for a button not in a menu, XmMULTICLICK_KEEP is the default value.
XmNshowAsDefault
If XmNdefaultButtonShadowThickness is greater than 0 (zero), a value greater than 0 in this resource specifies to mark this button as the default button. If XmNdefaultButtonShadowThickness is 0, a value greater than 0 in this resource specifies to mark this button as the default button with the shadow thickness specified by this resource. When the Display resource XmNdefaultButtonEmphasis has a value of XmEXTERNAL_HIGHLIGHT (the default), PushButton draws the location cursor outside of the outer shadow. When this resource has a value of XmINTERNAL_HIGHLIGHT, the highlight is drawn between the inner and outer shadows. The space between the shadow and the default shadow is equal to the sum of both shadows. The default value is 0. When this value is not 0, the Label resources XmNmarginLeft, XmNmarginRight, XmNmarginTop, and XmNmarginBottom may be modified to accommodate the second shadow. This resource is disabled when the PushButton is in a menu.

Información de Callback

Se pasa un puntero a la siguiente estructura a cada callback:

typedef struct
{
        int reason;
        XEvent * event;
        int click_count;
} XmPushButtonCallbackStruct;
reason
Indica por qué se invocó el callback.
event
Punta a la XEvent que activó el callback.
click_count
Este valor es válido solo cuando la razón es XmCR_ACTIVATE. Contiene el número de clics en la última secuencia de múltiples clics si el recurso XmNmultiClick está configurado en XmMULTICLICK_KEEP, de lo contrario contiene 1. El callback de activación se invoca para cada clic si XmNmultiClick está configurado en XmMULTICLICK_KEEP.

Rutinas de Acción

Las rutinas de acción de XmPushButton son:

Activate():
Esta acción dibuja la sombra en el estado desarmado. Si el botón no está en un menú y si XmNfillOnArm está configurado en True, el color de fondo vuelve al color desarmado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNlabelPixmap para la cara del botón. Si el puntero todavía está dentro del botón, esta acción llama a los callbacks para XmNactivateCallback.
Arm():
Esta acción arma el PushButton. Dibuja la sombra en el estado armado. Si el botón no está en un menú y si XmNfillOnArm está configurado en True, rellena el botón con el color especificado por XmNarmColor. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNarmPixmap para la cara del botón. Llama a los callbacks XmNarmCallback.
ArmAndActivate():
En un menú, despublica todos los menús de la jerarquía de menús y, a menos que el botón ya esté armado, llama a los callbacks XmNarmCallback. Esta acción llama a los callbacks XmNactivateCallback y XmNdisarmCallback.
Fuera de un menú, dibuja la sombra en el estado armado y, si XmNfillOnArm está configurado en True, rellena el botón con el color especificado por XmNarmColor. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNarmPixmap para la cara del botón. Esta acción llama a los callbacks XmNarmCallback.
Fuera de un menú, esta acción también organiza que sucedan lo siguiente, ya sea de inmediato o en un momento posterior: la sombra se dibuja en el estado desarmado y, si XmNfillOnArm está configurado en True, el color de fondo vuelve al color desarmado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNlabelPixmap para la cara del botón. Se llaman los callbacks XmNactivateCallback y XmNdisarmCallback.
BtnDown():
Esta acción despublica cualquier menú publicado por el menú padre del PushButton, deshabilita el recorrido del teclado para el menú y habilita el recorrido del mouse para el menú. Dibuja la sombra en el estado armado y, a menos que el botón ya esté armado, llama a los callbacks XmNarmCallback.
BtnUp():
Esta acción despublica todos los menús de la jerarquía de menús y activa el PushButton. Llama a los callbacks XmNactivateCallback y luego a los callbacks XmNdisarmCallback.
ButtonTakeFocus():
Hace que el PushButton tome el foco del teclado cuando se presiona Ctrl<Btn1Down>, sin activar el widget.
Disarm():
Llama a los callbacks para XmNdisarmCallback.
Help():
En un Pulldown o Popup MenuPane, despublica todos los menús de la jerarquía de menús y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de ingresar al sistema de menús. Esta acción llama a los callbacks para XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a los callbacks de ayuda del ancestro más cercano que los tenga.
MenuShellPopdownOne():
En un Pulldown MenuPane de nivel superior desde una MenuBar, despublica el menú, desarma el MenuBar CascadeButton y la MenuBar; y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de ingresar a la MenuBar. En otros Pulldown MenuPanes, despublica el menú.
En un Popup MenuPane, esta acción despublica el menú y restaura el foco del teclado al widget desde el cual se publicó el menú.
MultiActivate():
Si XmNmultiClick es XmMULTICLICK_DISCARD, esta acción no hace nada.
Si XmNmultiClick es XmMULTICLICK_KEEP, esta acción incrementa click_count en la estructura de callback y dibuja la sombra en el estado desarmado. Si el botón no está en un menú y si XmNfillOnArm está configurado en True, el color de fondo vuelve al color desarmado. Si XmNlabelType es XmPIXMAP, se utiliza XmNlabelPixmap para la cara del botón. Si el puntero está dentro del PushButton, llama a los callbacks para XmNactivateCallback y XmNdisarmCallback.
MultiArm():
Si XmNmultiClick es XmMULTICLICK_DISCARD, esta acción no hace nada.
Si XmNmultiClick es XmMULTICLICK_KEEP, esta acción dibuja la sombra en el estado armado. Si el botón no está en un menú y si XmNfillOnArm está configurado en True, esta acción rellena el botón con el color especificado por XmNarmColor. Si XmNlabelType es XmPIXMAP, se utiliza XmNarmPixmap para la

cara del botón.

ACTIONS

Arm():
Cambia la apariencia del botón para indicar que está armado. Esta acción llama a las devoluciones de llamada XmNarmCallback.
ProcessDrag():
Arrastra el contenido de la etiqueta de un PushButton, identificado cuando se presiona BTransfer. Esta acción establece el XmNconvertProc del DragContext a una función que llama a los procedimientos XmNconvertCallback, posiblemente varias veces, para la selección _MOTIF_DROP. Esta acción no está definida para PushButtons utilizados en un sistema de menú.

Comportamiento Adicional

Este widget tiene el siguiente comportamiento adicional:

<EnterWindow>:
En un menú, si la navegación por teclado está habilitada, esta acción no hace nada. De lo contrario, dibuja la sombra en el estado armado y llama a las devoluciones de llamada XmNarmCallback.
Si el PushButton no está en un menú y el cursor sale y luego vuelve a entrar en la ventana del PushButton mientras el botón está presionado, esta acción dibuja la sombra en el estado armado. Si XmNfillOnArm está establecido en True, también rellena el botón con el color especificado por XmNarmColor. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNarmPixmap para la cara del botón.
<LeaveWindow>:
En un menú, si la navegación por teclado está habilitada, esta acción no hace nada. De lo contrario, dibuja la sombra en el estado no armado y llama a las devoluciones de llamada XmNdisarmCallback.
Si el PushButton no está en un menú y el cursor sale de la ventana del PushButton mientras el botón está presionado, esta acción dibuja la sombra en el estado no armado. Si XmNfillOnArm está establecido en True, el color de fondo vuelve al color no armado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNlabelPixmap para la cara del botón.
