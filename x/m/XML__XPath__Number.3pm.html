XML::XPath::Number(3) Documentación de Perl aportada por el usuario XML::XPath::Number(3)

NOMBRE

XML::XPath::Number - Valores numéricos simples.

DESCRIPCIÓN

Esta clase almacena valores numéricos simples. No soporta -0, Infinito +/- ni NaN, como se supone que debería hacer la especificación XPath, pero no creo que esté perjudicando a nadie.

API

new($num)

Crea un nuevo objeto XML::XPath::Number, con el valor en $num. Realiza una comprobación numérica rudimentaria en $num para asegurarse de que realmente es un número.

value()

También como cadena de caracteres sobrecargada. Devuelve el valor numérico almacenado.
