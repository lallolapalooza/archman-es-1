NOMBRE

XmMapSegmentEncoding — Una función de cadena compuesta que devuelve el formato de codificación de texto compuesto asociado con la etiqueta de lista de fuentes especificada

SINOPSIS

#include <Xm/Xm.h>
char * XmMapSegmentEncoding(
char *fontlist_tag);

DESCRIPCIÓN

XmMapSegmentEncoding busca en el registro de codificación de segmentos una entrada que coincida con la etiqueta de lista de fuentes especificada y devuelve una copia del formato de codificación de texto compuesto asociado. La aplicación es responsable de liberar el almacenamiento asociado con los datos devueltos llamando a XtFree.

fontlist_tag
Especifica la etiqueta de lista de fuentes de cadena compuesta.

RETORNO

Devuelve una copia del formato de codificación de texto compuesto asociado si la etiqueta de lista de fuentes se encuentra en el registro; de lo contrario, devuelve NULL.

RELACIONADOS

XmCvtXmStringToCT(3), XmFontList(3), XmRegisterSegmentEncoding(3) y XmString(3).
