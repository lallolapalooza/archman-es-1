NOMBRE

XmTextFieldShowPosition — Función de TextField que fuerza la visualización de texto en una posición dada

SINOPSIS

#include <Xm/TextF.h>
void XmTextFieldShowPosition(
Widget widget,
XmTextPosition position);

DESCRIPCIÓN

XmTextFieldShowPosition fuerza la visualización de texto en la posición especificada. La posición del cursor no se actualiza ni se muestra el cursor en esta posición.

widget
Especifica el ID del widget TextField
position
Especifica la posición del carácter que se va a mostrar. Es un número entero de caracteres desde el principio del búfer de texto. La primera posición de carácter es 0 (cero). Consulte XmTextPosition(3) para obtener detalles sobre el tipo de dato XmTextPosition.

Para una definición completa de TextField y sus recursos asociados, consulte XmTextField(3).

RELACIONADOS

XmTextField(3) y XmTextPosition(3).
