NOMBRE

XmTextSetSelection — Una función de Texto que establece la selección primaria del texto

SINOPSIS

#include <Xm/Text.h>
void XmTextSetSelection(
Widget widget,
XmTextPosition first,
XmTextPosition last,
Time time);

DESCRIPCIÓN

XmTextSetSelection establece la selección primaria del texto en el widget. También establece la posición del cursor de inserción a la última posición de la selección y llama a las devoluciones de llamada XmNmotionVerifyCallback del widget.

widget
Especifica el ID del widget de Texto
first
Marca la posición del primer carácter del texto a seleccionar
last
Marca la última posición del texto a seleccionar
time
Especifica el tiempo en el que se desea el valor de la selección. Este debe ser el mismo que el tiempo del evento que desencadenó esta solicitud. Una fuente de una marca de tiempo válida es la función XtLastTimestampProcessed.

Para una definición completa de Texto y sus recursos asociados, consulte XmText(3).

RELACIONADO

XmText(3).
