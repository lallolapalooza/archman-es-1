NOMBRE

XML::Parser::Style::Tree - Analizador de estilo de árbol

SINOPSIS

use XML::Parser;
my $p = XML::Parser->new(Style => 'Tree');
my $tree = $p->parsefile('foo.xml');

DESCRIPCIÓN

Este módulo implementa el analizador de estilo Tree de XML::Parser.

Al analizar un documento, parse() devolverá un árbol de análisis para el documento. Cada nodo del árbol toma la forma de un par de etiqueta, contenido. Los nodos de texto se representan con una pseudoetiqueta de "0" y la cadena que es su contenido. Para los elementos, el contenido es una referencia de matriz. El primer elemento de la matriz es una referencia a un hash (posiblemente vacía) que contiene atributos. El resto de la matriz es una secuencia de pares etiqueta-contenido que representan el contenido del elemento.

Así, por ejemplo, el resultado de analizar:

<foo><head id="a">Hola <em>allí</em></head><bar>Saludos<ref/></bar>do</foo>

sería:

           Tag   Content
==================================================================
[foo, [{}, head, [{id => "a"}, 0, "Hola ",  em, [{}, 0, "allí"]],
            bar, [         {}, 0, "Saludos",  ref, [{}]],
              0, "do"
      ]
]

El documento raíz "foo", tiene 3 hijos: un elemento "head", un elemento "bar" y el texto "do". Después del hash de atributos vacío, estos se representan en su contenido mediante 3 pares etiqueta-contenido.
