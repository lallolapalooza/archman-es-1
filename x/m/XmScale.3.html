NOMBRE

XmScale — La clase del widget Scale

SINOPSIS

#include <Xm/Scale.h>

DESCRIPCIÓN

Scale es utilizado por una aplicación para indicar un valor dentro de un rango de valores, y permite al usuario introducir o modificar un valor dentro del mismo rango.

Un Scale tiene una región rectangular alargada similar a una ScrollBar. Un deslizador dentro de esta región indica el valor actual a lo largo del Scale. El usuario también puede modificar el valor del Scale moviendo el deslizador dentro de la región rectangular del Scale. Un Scale también puede incluir un conjunto de etiquetas ubicado fuera de la región del Scale. Estas pueden indicar el valor relativo en varias posiciones a lo largo del scale. La ubicación de esta etiqueta depende del recurso XmNlayoutDirection del widget.

Un Scale puede ser de entrada/salida o solo de salida. Un Scale de entrada/salida puede tener su valor establecido por la aplicación y también modificado por el usuario con el deslizador. Un Scale solo de salida se usa estrictamente como un indicador del valor actual de algo y no puede ser modificado interactivamente por el usuario. El recurso XmNeditable de XmScale especifica si el usuario puede modificar interactivamente el valor del Scale.

El usuario puede especificar recursos en un archivo de recursos para el gadget creado automáticamente que contiene el título del widget Scale. El nombre del gadget es Title. La ubicación del título depende del recurso XmNlayoutDirection del widget. La dirección del título se basa en la dirección de diseño del widget.

Scale utiliza el rasgo XmQTspecifyRenderTable y posee el rasgo XmQTtransfer.

Comportamiento de transferencia de datos

Scale soporta el arrastre de la representación del valor del Scale desde el Scale cuando el valor se muestra y cuando el valor del recurso XmNenableUnselectableDrag de XmDisplay está establecido en True.

Como fuente de datos, Scale soporta los siguientes destinos y conversiones asociadas de datos a estos destinos:

COMPOUND_TEXT
El widget transfiere una representación de cadena de XmNvalue como tipo COMPOUND_TEXT.
UTF8_STRING
El widget transfiere una representación de cadena de XmNvalue como tipo UTF8_STRING.
STRING
El widget transfiere una representación de cadena de XmNvalue como tipo STRING.
_MOTIF_CLIPBOARD_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que soporta para la selección CLIPBOARD. Estos incluyen STRING, COMPOUND_TEXT y UTF8_STRING.
_MOTIF_EXPORT_TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que se utilizarán como valor de XmNexportTargets del DragContext en una transferencia de arrastrar y soltar. Estos incluyen STRING, COMPOUND_TEXT y UTF8_STRING.

Como fuente de datos, Scale también soporta los siguientes destinos estándar de Motif:

BACKGROUND
El widget transfiere XmNbackground como tipo PIXEL.
CLASS
El widget encuentra el primer shell en la jerarquía de widgets que tiene una propiedad WM_CLASS y transfiere el contenido como texto en la configuración regional actual.
CLIENT_WINDOW
El widget encuentra el primer shell en la jerarquía de widgets y transfiere su ventana como tipo WINDOW.
COLORMAP
El widget transfiere XmNcolormap como tipo COLORMAP.
FOREGROUND
El widget transfiere XmNforeground como tipo PIXEL.
NAME
El widget encuentra el primer shell en la jerarquía de widgets que tiene una propiedad WM_NAME y transfiere el contenido como texto en la configuración regional actual.
TARGETS
El widget transfiere, como tipo ATOM, una lista de los destinos que soporta. Estos incluyen los destinos estándar en esta lista. Estos también incluyen STRING, COMPOUND_TEXT y UTF8_STRING.
TIMESTAMP
El widget transfiere la marca de tiempo utilizada para adquirir la selección como tipo INTEGER.
_MOTIF_RENDER_TABLE
El widget transfiere XmNrenderTable si existe, o la tabla de renderizado de texto predeterminada, como tipo STRING.
_MOTIF_ENCODING_REGISTRY
El widget transfiere su registro de codificación como tipo STRING. El valor es una lista de elementos separados por NULL en forma de pares de etiqueta codificación. Este destino simboliza el destino de transferencia para el Registro de Codificación de Segmentos de Motif. Las aplicaciones y los widgets pueden acceder a este Registro llamando a XmRegisterSegmentEncoding y XmMapSegmentEncoding.

Clases

Scale hereda comportamiento, recursos y rasgos de las clases Core, Composite, Constraint y XmManager.

El puntero de clase es xmScaleWidgetClass.

El nombre de la clase es XmScale.

Nuevos recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado puede ser establecido en el momento de la creación (C), establecido usando XtSetValues (S), recuperado usando XtGetValues (G), o no es aplicable (N/A).

XmNconvertCallback
Especifica una lista de callbacks que se llaman cuando se le pide a la Escala que convierta una selección. El tipo de la estructura cuya dirección se pasa a estos callbacks es XmConvertCallbackStruct. La razón es XmCR_OK.
XmNdecimalPoints
Especifica el número de puntos decimales a desplazar el valor del deslizador al mostrarlo. Por ejemplo, un valor de deslizador de 2.350 y un valor de XmNdecimalPoints de 2 dan como resultado un valor de visualización de 23.50. El valor no debe ser negativo.
XmNdragCallback
Especifica la lista de callbacks que se llama cuando la posición del deslizador cambia mientras se está arrastrando el deslizador. La razón enviada por el callback es XmCR_DRAG.
XmNeditable
Especifica cómo reaccionará la barra de desplazamiento de la Escala a la entrada del usuario. Este recurso puede tener valores True o False, como sigue:
True
Permite que la barra de desplazamiento responda a la entrada del usuario. Este es el valor predeterminado.
False
Hace que la barra de desplazamiento de la Escala no responda a la entrada del usuario. La apariencia visual no se atenúa. Este valor se utilizaría principalmente en el modo XmTHERMOMETER.
Cuando se utiliza XmNeditable en un widget, se establece el sitio de colocación en XmDROP_SITE_ACTIVE.
XmNfontList
Especifica la lista de fuentes a utilizar para la cadena de texto del título especificada por XmNtitleString, y la etiqueta mostrada cuando XmNshowValue es True. La lista de fuentes es una estructura obsoleta y se conserva solo por compatibilidad con versiones anteriores de Motif. Consulte el recurso XmNrenderTable.
XmNhighlightOnEnter
Especifica si el rectángulo de resaltado se dibuja cuando el cursor entra en el widget. Si la política de enfoque del shell es XmEXPLICIT, este recurso se ignora y el widget se resalta cuando tiene el foco. Si la política de enfoque del shell es XmPOINTER y si este recurso es True, el rectángulo de resaltado se dibuja cuando el cursor entra en el widget. Si la política de enfoque del shell es XmPOINTER y si este recurso es False, el rectángulo de resaltado no se dibuja cuando el cursor entra en el widget. El valor predeterminado es False.
XmNhighlightThickness
Especifica el tamaño del rectángulo de dibujo del borde del deslizador utilizado para el dibujo de resaltado de entrada de ventana y de recorrido.
XmNmaximum
Especifica el valor máximo del deslizador. XmNmaximum debe ser mayor que XmNminimum.
XmNminimum
Especifica el valor mínimo del deslizador. XmNmaximum debe ser mayor que XmNminimum.
XmNorientation
Muestra la Escala vertical u horizontalmente. Este recurso puede tener los valores de XmVERTICAL y XmHORIZONTAL.
XmNprocessingDirection
Especifica si el valor para XmNmaximum está en el lado derecho o izquierdo de XmNminimum para las Escalas horizontales o por encima o por debajo de XmNminimum para las Escalas verticales. Este recurso puede tener los valores de XmMAX_ON_TOP, XmMAX_ON_BOTTOM, XmMAX_ON_LEFT y XmMAX_ON_RIGHT. Si la Escala está orientada verticalmente, el valor predeterminado es XmMAX_ON_TOP. Si la XmScale está orientada horizontalmente, el valor predeterminado depende del recurso XmNlayoutDirection del widget.
XmNrenderTable
Especifica la tabla de renderizado a utilizar para la cadena de texto del título especificada por XmNtitleString, y la etiqueta mostrada cuando XmNshowValue es True. Si este valor es NULL al inicializar, la jerarquía padre se busca para encontrar un ancestro que posea el rasgo XmQTspecifyRenderTable. Si se encuentra dicho ancestro, la tabla de renderizado se inicializa al valor XmLABEL_RENDER_TABLE del widget ancestro. Si no se encuentra ningún ancestro, el valor predeterminado depende de la implementación. Si se especifican tanto una lista de fuentes (XmNfontList) como una tabla de renderizado, la tabla de renderizado tendrá prioridad. Consulte XmRenderTable(3) para obtener más información sobre la creación y la estructura de una tabla de renderizado.
XmNscaleHeight
Especifica la altura del área del deslizador. El valor debe estar en el tipo de unidad especificado (el valor predeterminado es píxeles). Si no se especifica ningún valor, se calcula una altura predeterminada.
XmNscaleMultiple
Especifica la cantidad a mover el deslizador cuando el usuario realiza una acción que mueve el deslizador en un incremento múltiple. El valor predeterminado es (XmNmaximum - XmNminimum) dividido por 10, con un mínimo de 1.
XmNscaleWidth
Especifica el ancho del área del deslizador. El valor debe estar en el tipo de unidad especificado (el valor predeterminado es píxeles). Si no se especifica ningún valor, se calcula un ancho predeterminado.
XmNshowArrows
Especifica si las flechas se muestran y cómo se muestran. Este recurso puede tomar los siguientes valores:
XmEACH_SIDE
Indica que se muestra una flecha en cada extremo del deslizador de la Barra de desplazamiento.
XmMAX_SIDE
Indica que se muestra una flecha en el lado XmNmaximum del deslizador de la Barra de desplazamiento.
XmMIN_SIDE
Indica que se muestra una flecha en el lado XmNminimum del deslizador de la Barra de desplazamiento.
XmNONE
Indica que no se muestran flechas.
XmNONE es el valor predeterminado.
XmNshowValue
Especifica si se debe mostrar una etiqueta para el valor actual del deslizador junto al deslizador. Si el valor es XmNEAR_SLIDER, se muestra el valor actual del deslizador. Si el valor es XmNONE, no se muestra ningún valor de deslizador. Si el valor es XmNEAR_BORDER, se muestra el valor actual del deslizador cerca del borde.
XmNsliderMark
Especifica la forma en que se mostrará el deslizador. Este recurso puede tomar los siguientes valores:
XmETCHED_LINE
Especifica el deslizador como una línea grabada. Este es el valor predeterminado cuando XmNslidingMode es XmSLIDER.
XmNONE
Especifica el deslizador como un rectángulo en primer plano. Este es el valor predeterminado cuando XmNslidingMode es XmTHERMOMETER y la barra de desplazamiento de la Escala no responde a la entrada del usuario (XmNeditable es False).
XmROUND_MARK
Especifica el deslizador como un círculo sombreado. Este es el valor predeterminado cuando XmNslidingMode es XmTHERMOMETER y la barra de desplazamiento de la Escala responde a la entrada del usuario (XmNeditable es True).
XmTHUMB_MARK
Especifica el deslizador como una serie de tres líneas grabadas centradas en el medio del deslizador.
XmNslidingMode
Especifica el modo en que funciona el deslizador. Hay dos modos posibles:
XmSLIDER
Permite que el deslizador se mueva libremente entre los extremos mínimo y máximo de la escala. Este es el valor predeterminado.
XmTHERMOMETER
Fuerza al deslizador a anclarse a un lado del área del canal.
XmNsliderVisual
Especifica el color de la apariencia visual del deslizador. Este recurso puede tomar los siguientes valores:
XmBACKGROUND_COLOR
Especifica que la apariencia visual del deslizador está en el color de fondo.
XmFOREGROUND_COLOR
Especifica que la apariencia visual del deslizador está en el color de primer plano.
XmSHADOWED_BACKGROUND
Especifica que la apariencia visual del deslizador está en el color de fondo, con una sombra. Este es el valor predeterminado cuando el recurso XmNslidingModel es XmSLIDER.
XmTROUGH_COLOR
Especifica que la apariencia visual del deslizador está en el color del canal. Este es el valor predeterminado cuando el recurso XmNslidingModel es XmTHERMOMETER.
XmNtitleString
Especifica la cadena de texto del título que aparecerá en la ventana del widget Escala.
XmNvalue
Especifica la posición actual del deslizador a lo largo de la escala, entre XmNminimum y XmNmaximum. El valor se restringe para que esté dentro de estos límites inclusivos. El valor inicial de este recurso es el mayor de 0 (cero) y XmNminimum.
XmNvalueChangedCallback
Especifica la lista de callbacks que se llama cuando ha cambiado el valor del deslizador. La razón enviada por el callback es XmCR_VALUE_CHANGED.

NAME

XmConvertCallbackStruct — structure for conversion callbacks

SYNOPSIS

typedef struct {
        int             reason;
        XEvent          *event;
        Atom            selection;
        Atom            target;
        XtPointer       source_data;
        XtPointer       location_data;
        int             flags;
        XtPointer       parm;
        int             parm_format;
        unsigned long   parm_length;
        int             status;
        XtPointer       value;
        Atom            type;
        int             format;
        unsigned long   length;
} XmConvertCallbackStruct;

DESCRIPTION

The structure XmConvertCallbackStruct is used for the callbacks generated when a widget needs to convert data to a different selection target. This structure is passed to the conversion callback procedures registered through the XmNconvertCallback resource.

reason
Indica por qué se invocó la devolución de llamada. Los valores posibles son:
XmCR_CONVERT
Se solicita una conversión de selección.
event
Punta al XEvent que desencadenó la devolución de llamada. Puede ser NULL.
selection
Indica la selección para la que se solicita la conversión. Los valores posibles son CLIPBOARD, PRIMARY, SECONDARY y _MOTIF_DROP.
target
Indica el objetivo de la conversión.
source_data
Contiene información sobre el origen de la selección. Cuando la selección es _MOTIF_DROP, source_data es el DragContext. De lo contrario, es NULL.
location_data
Contiene información sobre la ubicación de los datos que se van a convertir. Si el valor es NULL, los datos que se van a transferir consisten en la selección actual del widget.
flags
Indica el estado de la conversión. Los siguientes son los valores posibles:
XmCONVERTING_NONE
Esta bandera no se utiliza actualmente.
XmCONVERTING_PARTIAL
El widget de destino pudo ser convertido, pero se perdió algo de información.
XmCONVERTING_SAME
El objetivo de la conversión es el origen de los datos que se van a transferir.
XmCONVERTING_TRANSACT
Esta bandera no se utiliza actualmente.
parm
Contiene datos de parámetros para este objetivo. Si no existen datos de parámetros, el valor es NULL.
Cuando selection es CLIPBOARD y target es _MOTIF_CLIPBOARD_TARGETS o _MOTIF_DEFERRED_CLIPBOARD_TARGETS, el valor es la operación solicitada (XmCOPY, XmMOVE o XmLINK).
parm_format
Especifica si los datos en parm deben ser vistos como una lista de cantidades char, short o long. Los valores posibles son 0 (cuando parm es NULL), 8 (cuando los datos en parm deben ser vistos como una lista de char), 16 (cuando los datos en parm deben ser vistos como una lista de short) o 32 (cuando los datos en parm deben ser vistos como una lista de long). Tenga en cuenta que parm_format simboliza un tipo de dato, no el número de bits en cada elemento de la lista. Por ejemplo, en algunas máquinas, un parm_format de 32 significa que los datos en parm deben ser vistos como una lista de cantidades de 64 bits, no de 32 bits.
parm_length
Especifica el número de elementos de datos en parm, donde cada elemento tiene el tamaño especificado por parm_format. Cuando parm es NULL, el valor es 0.
status
Un miembro IN/OUT que especifica el estado de la conversión. El valor inicial es XmCONVERT_DEFAULT. El procedimiento de devolución de llamada puede establecer este miembro en uno de los siguientes valores:
XmCONVERT_DEFAULT
Este valor significa que el procedimiento de conversión de la clase del widget, si existe, se llama después de que los procedimientos de devolución de llamada retornan. Si el procedimiento de conversión de la clase del widget produce algún dato, este sobrescribe los datos proporcionados por los procedimientos de devolución de llamada en el miembro value.
XmCONVERT_MERGE
Este valor significa que el procedimiento de conversión de la clase del widget, si existe, se llama después de que los procedimientos de devolución de llamada retornan. Si el procedimiento de conversión de la clase del widget produce algún dato, este se adjunta a los datos proporcionados por los procedimientos de devolución de llamada en el miembro value. Este valor está destinado a ser utilizado con objetivos que resultan en listas de datos, como TARGETS.
XmCONVERT_DONE
Este valor significa que el procedimiento de devolución de llamada ha finalizado con éxito la conversión. El procedimiento de conversión de la clase del widget, si existe, no se llama después de que los procedimientos de devolución de llamada retornan.
XmCONVERT_REFUSE
Este valor significa que el procedimiento de devolución de llamada ha terminado el proceso de conversión sin completar la conversión solicitada. El procedimiento de conversión de la clase del widget, si existe, no se llama después de que los procedimientos de devolución de llamada retornan.
value
Un parámetro IN/OUT que contiene cualquier dato que el procedimiento de devolución de llamada produzca como resultado de la conversión. El valor inicial es NULL. Si el procedimiento de devolución de llamada establece este miembro, debe asegurarse de que los miembros type, format y length correspondan a los datos en value. El procedimiento de devolución de llamada es responsable de asignar, pero no de liberar, memoria cuando establece este miembro.
type
Un parámetro IN/OUT que indica el tipo de los datos en el miembro value. El valor inicial es INTEGER.
format
Un parámetro IN/OUT que especifica si los datos en value deben ser vistos como una lista de cantidades char, short o long. El valor inicial es 8. El procedimiento de devolución de llamada puede establecer este miembro a 8 (para una lista de char), 16 (para una lista de short) o 32 (para una lista de long).
length
Un miembro IN/OUT que especifica el número de elementos de datos en value, donde cada elemento tiene el tamaño simbolizado por format. El valor inicial es 0.

Comportamiento

XmScale tiene el siguiente comportamiento:

<Btn1Down> o <Btn2Down>:
En la región entre un extremo de la Escala y el deslizador: Mueve el deslizador un incremento múltiple en la dirección del extremo de la Escala y llama a las devoluciones de llamada XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o hacia abajo incrementa el valor de la Escala, y el movimiento hacia la izquierda o hacia arriba decrementa el valor de la Escala. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o hacia abajo decrementa el valor de la Escala, y el movimiento hacia la izquierda o hacia arriba incrementa el valor de la Escala. Si el botón se mantiene presionado durante más tiempo que un período de retraso, el deslizador se mueve nuevamente en el mismo incremento y se llaman las mismas devoluciones de llamada.
En el deslizador: Activa el arrastre interactivo del deslizador.
<Btn2Down> en la etiqueta de valor:
Arrastra el contenido de la etiqueta que muestra el valor actual del deslizador. Esta acción establece el XmNconvertProc del DragContext a una función que llama a los procedimientos XmNconvertCallback, posiblemente varias veces, para la selección _MOTIF_DROP.
<Btn1Motion> o <Btn2Motion>:
Si la pulsación del botón ocurre dentro del deslizador, los eventos de movimiento subsiguientes mueven el deslizador a la posición del puntero y llaman a las devoluciones de llamada para XmNdragCallback.
<Btn1Up> o <Btn2Up>:
Si la pulsación del botón ocurre dentro del deslizador y la posición del deslizador se cambia, se llaman las devoluciones de llamada para XmNvalueChangedCallback.
<Ctrl><Btn1Down>:
En la región entre un extremo de la Escala y el deslizador: Mueve el deslizador a ese extremo de la Escala y llama a las devoluciones de llamada XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o hacia abajo incrementa el valor de la Escala, y el movimiento hacia la izquierda o hacia arriba decrementa el valor de la Escala. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o hacia abajo decrementa el valor de la Escala, y el movimiento hacia la izquierda o hacia arriba incrementa el valor de la Escala.
<Key><osfUp>:
Para Escalas verticales, mueve el deslizador hacia arriba un incremento y llama a las devoluciones de llamada XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_TOP, el movimiento hacia arriba incrementa el valor de la Escala. Si XmNprocessingDirection es XmMAX_ON_BOTTOM, el movimiento hacia arriba decrementa el valor de la Escala.
<Key><osfDown>:
Para Escalas verticales, mueve el deslizador hacia abajo un incremento y llama a las devoluciones de llamada XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_BOTTOM, el movimiento hacia abajo incrementa el valor de la Escala. Si XmNprocessingDirection es XmMAX_ON_TOP, el movimiento hacia abajo decrementa el valor de la Escala.
<Key><osfLeft>:
Para Escalas horizontales, mueve el deslizador un incremento hacia la izquierda y llama a las devoluciones de llamada XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT, el movimiento hacia la izquierda incrementa el valor de la Escala. Si XmNprocessingDirection es XmMAX_ON_RIGHT, el movimiento hacia la izquierda decrementa el valor de la Escala.
<Key><osfRight>:
Para Escalas horizontales, mueve el deslizador un incremento hacia la derecha y llama a las devoluciones de llamada XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_RIGHT, el movimiento hacia la derecha incrementa el valor de la Escala. Si XmNprocessingDirection es XmMAX_ON_LEFT, el movimiento hacia la derecha decrementa el valor de la Escala.
<Ctrl><Key><osfUp> o <
;Key><osfPageUp>:
Para Scales verticales, mueve el deslizador hacia arriba un incremento múltiple y llama a las callbacks XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_TOP, el movimiento hacia arriba incrementa el valor de la escala. Si XmNprocessingDirection es XmMAX_ON_BOTTOM, el movimiento hacia arriba decrementa el valor de la escala.
<Ctrl><Key><osfDown> o <Key><osfPageDown>:
Para Scales verticales, mueve el deslizador hacia abajo un incremento múltiple y llama a las callbacks XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_BOTTOM, el movimiento hacia abajo incrementa el valor de la escala. Si XmNprocessingDirection es XmMAX_ON_TOP, el movimiento hacia abajo decrementa el valor de la escala.
<Ctrl><Key><osfLeft> o <Key><osfPageLeft>:
Para Scales horizontales, mueve el deslizador un incremento múltiple hacia la izquierda y llama a las callbacks XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT, el movimiento hacia la izquierda incrementa el valor de la escala. Si XmNprocessingDirection es XmMAX_ON_RIGHT, el movimiento hacia la izquierda decrementa el valor de la escala.
<Ctrl><Key><osfRight> o <Key><osfPageRight>:
Para Scales horizontales, mueve el deslizador un incremento múltiple hacia la derecha y llama a las callbacks XmNvalueChangedCallback. Si XmNprocessingDirection es XmMAX_ON_RIGHT, el movimiento hacia la derecha incrementa el valor de la escala. Si XmNprocessingDirection es XmMAX_ON_LEFT, el movimiento hacia la derecha decrementa el valor de la escala.
<Key><osfBeginLine> o <Key><osfBeginData>:
Mueve el deslizador al valor mínimo y llama a las callbacks XmNvalueChangedCallback.
<Key><osfEndLine> o <Key><osfEndData>:
Mueve el deslizador al valor máximo y llama a las callbacks XmNvalueChangedCallback.
<Key><osfNextField>:
Se desplaza al primer elemento del siguiente grupo de pestañas. Si el grupo de pestañas actual es la última entrada en la lista de grupos de pestañas, vuelve al principio de la lista de grupos de pestañas.
<Key><osfPrevField>:
Se desplaza al primer elemento del grupo de pestañas anterior. Si se alcanza el principio de la lista de grupos de pestañas, vuelve al final de la lista de grupos de pestañas.
<Key><osfHelp>:
Llama a las callbacks para XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a las callbacks de ayuda para el ancestro más cercano que las tenga.
