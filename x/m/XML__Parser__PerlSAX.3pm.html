NOMBRE

XML::Parser::PerlSAX - Analizador SAX de Perl que utiliza XML::Parser

SINOPSIS

use XML::Parser::PerlSAX;
$parser = XML::Parser::PerlSAX->new( [OPCIONES] );
$result = $parser->parse( [OPCIONES] );
$result = $parser->parse($string);

DESCRIPCIÓN

"XML::Parser::PerlSAX" es un analizador PerlSAX que utiliza el módulo XML::Parser. Esta página de manual resume las opciones, manejadores y propiedades específicas admitidas por "XML::Parser::PerlSAX"; consulte el estándar PerlSAX en `"PerlSAX.pod"' para obtener información general sobre su uso.

MÉTODOS

new
Crea un nuevo objeto analizador. Las opciones predeterminadas para el análisis, descritas a continuación, se pasan como pares clave-valor o como un único hash. Las opciones se pueden cambiar directamente en el objeto analizador a menos que se indique lo contrario. Las opciones pasadas a `parse()' anulan las opciones predeterminadas en el objeto analizador durante la duración del análisis.
parse
Analiza un documento. Las opciones, descritas a continuación, se pasan como pares clave-valor o como un único hash. Las opciones pasadas a `parse()' anulan las opciones predeterminadas en el objeto analizador.
location
Devuelve la ubicación como un hash: 
ColumnNumber    El número de columna del análisis.
LineNumber      El número de línea del análisis.
BytePosition    La posición actual de bytes del análisis.
PublicId        Una cadena que contiene el identificador público, o undef
                si no hay ninguno disponible.
SystemId        Una cadena que contiene el identificador del sistema, o undef
                si no hay ninguno disponible.
Base            El valor actual de la base para resolver URIs relativas.

ADVERTENCIA ALFA: Las propiedades `"SystemId"' y `"PublicId"' devueltas son los identificadores del sistema y públicos del documento pasado a `parse()', no los identificadores de la entidad externa que se está analizando actualmente. Las posiciones de columna, línea y bytes *son* de la entidad actual que se está analizando.

OPCIONES

Las siguientes opciones son admitidas por "XML::Parser::PerlSAX":

Handler          manejador predeterminado para recibir eventos
DocumentHandler  manejador para recibir eventos de documento
DTDHandler       manejador para recibir eventos DTD
ErrorHandler     manejador para recibir eventos de error
EntityResolver   manejador para resolver entidades
Locale           localización para proporcionar localización para errores
Source           hash que contiene la fuente de entrada para el análisis
UseAttributeOrder establecido a true para proporcionar propiedades AttributeOrder y Defaulted
                  en `start_element()'

Si no se proporcionan manejadores, todos los eventos se ignorarán silenciosamente, excepto `fatal_error()', que provocará una llamada a `die()' después de llamar a `end_document()'.

Si se pasa un único argumento de cadena al método `parse()', se trata como si se hubiera dado una opción `"Source"' con un parámetro `"String"'.

El hash `"Source"' puede contener los siguientes parámetros:

ByteStream       El flujo de bytes crudo (manejador de archivo) que contiene el
                 documento.
String           Una cadena que contiene el documento.
SystemId         El identificador del sistema (URI) del documento.
PublicId         El identificador público.
Encoding         Una cadena que describe la codificación de caracteres.

Si se proporcionan más de uno de `"ByteStream"', `"String"', o `"SystemId"', la preferencia se da primero a `"ByteStream"', luego a `"String"', y luego a `"SystemId"'.

MANEJADORES

Los siguientes manejadores y propiedades son admitidos por "XML::Parser::PerlSAX":

Métodos DocumentHandler

start_document
Recibe notificación del inicio de un documento.

No se definen propiedades.

end_document
Recibe notificación del final de un documento.

No se definen propiedades.

start_element
Recibe notificación del inicio de un elemento. 
Name             El nombre del tipo de elemento.
Attributes       Un hash que contiene los atributos adjuntos al
                 elemento, si los hay.

El hash `"Attributes"' contiene solo valores de cadena.

Si la opción del analizador `"UseAttributeOrder"' es verdadera, las siguientes propiedades también se pasan a `"start_element"':

AttributeOrder   Una matriz de nombres de atributos en el orden en que se
                 especificaron, seguidos por los nombres de atributos
                 predeterminados.
Defaulted        El número de índice del primer atributo predeterminado en
                 `AttributeOrder'. Si este índice es igual a la longitud de
                 `AttributeOrder', no hubo valores predeterminados.

Nota para los usuarios de "XML::Parser": `"Defaulted"' será la mitad del valor de la función `specified_attr()' de "XML::Parser::Expat"' porque solo se proporcionan nombres de atributos, no sus valores.

end_element
Recibe notificación del final de un elemento. 
Name             El nombre del tipo de elemento.
characters
Recibe notificación de datos de caracteres. 
Data             Los caracteres del documento XML.
processing_instruction
Recibe notificación de una instrucción de procesamiento. 
Target           El destino de la instrucción de procesamiento.
Data             Los datos de la instrucción de procesamiento, si los hay.
comment
Recibe notificación de un comentario. 
Data             Los datos del comentario, si los hay.
start_cdata
Recibe notificación del inicio de una sección CDATA.

No se definen propiedades.

end_cdata
Recibe notificación del final de una sección CDATA.

No se definen propiedades.

entity_reference
Recibe notificación de una referencia de entidad interna. Si este manejador está definido, las entidades internas no se expandirán y no se pasarán al manejador `characters()'. Si este manejador no está definido, las entidades internas se expandirán si es posible y se pasarán al manejador `characters()'. 
Name             El nombre de la referencia de entidad
Value            El valor de la referencia de entidad

Métodos DTDHandler

notation_decl
Recibe notificación de un evento de declaración de notación. 
Name             El nombre de la notación.
PublicId         El identificador público de la notación, si lo hay.
SystemId         El identificador del sistema de la notación, si lo hay.
Base             La base para resolver una URI relativa, si la hay.
unparsed_entity_decl

Name             El nombre de la entidad no analizada.
SystemId         El identificador del sistema de la entidad.
PublicId         El identificador público de la entidad, si existe.
Base             La base para resolver una URI relativa, si existe.
entity_decl
Recibe notificación de un evento de declaración de entidad. 
Name             El nombre de la entidad.
Value            El valor de la entidad, si existe.
PublicId         El identificador público de la notación, si existe.
SystemId         El identificador del sistema de la notación, si existe.
Notation         La notación declarada para esta entidad, si existe.

Para entidades internas, el parámetro `"Value"' contendrá el valor y `"PublicId"', `"SystemId"' y `"Notation"' serán indefinidos. Para entidades externas, el parámetro `"Value"' será indefinido, el parámetro `"SystemId"' tendrá el id del sistema, el parámetro `"PublicId"' tendrá el id público si se proporcionó (será indefinido de lo contrario), el parámetro `"Notation"' contendrá el nombre de la notación para entidades no analizadas. Si esta es una declaración de entidad de parámetro, entonces se prefijará un '%' al nombre de la entidad.

Tenga en cuenta que `entity_decl()' y `unparsed_entity_decl()' se superponen. Si ambos métodos son implementados por un manejador, entonces este manejador no será llamado para entidades no analizadas.

element_decl
Recibe notificación de un evento de declaración de elemento. 
Name             El nombre del tipo de elemento.
Model            El modelo de contenido como una cadena.
attlist_decl
Recibe notificación de un evento de declaración de lista de atributos.

Este manejador se llama para cada atributo en una declaración ATTLIST encontrada en el subconjunto interno. Por lo tanto, una declaración ATTLIST que tiene múltiples atributos generará múltiples llamadas a este manejador.

ElementName      El nombre del tipo de elemento.
AttributeName    El nombre del atributo.
Type             El tipo del atributo.
Fixed            Verdadero si este es un atributo fijo.

El valor predeterminado para `"Type"' es el valor predeterminado, que será "#REQUIRED", "#IMPLIED" o una cadena entre comillas (es decir, la cadena devuelta comenzará y terminará con un carácter de comilla).

doctype_decl
Recibe notificación de un evento de declaración DOCTYPE. 
Name             El nombre del tipo de documento.
SystemId         El identificador del sistema del documento.
PublicId         El identificador público del documento, si existe.
Internal         El subconjunto interno como una cadena, si existe.

Internal contendrá todos los espacios en blanco, comentarios, instrucciones de procesamiento y declaraciones vistas en el subconjunto interno. Las declaraciones estarán allí, independientemente de si han sido procesadas por otro manejador (excepto las entidades no analizadas procesadas por el manejador Unparsed). Sin embargo, los comentarios y las instrucciones de procesamiento no aparecerán si han sido procesados por sus respectivos manejadores.

xml_decl
Recibe notificación de un evento de declaración XML. 
Version          La versión.
Encoding         La cadena de codificación, si existe.
Standalone       Verdadero, falso o indefinido si no se declara.

EntityResolver

resolve_entity
Permite al manejador resolver entidades externas. 
Name             El nombre de la notación.
SystemId         El identificador del sistema de la notación.
PublicId         El identificador público de la notación, si existe.
Base             La base para resolver una URI relativa, si existe.

`resolve_entity()' debe devolver undef para solicitar que el analizador abra una conexión URI regular al identificador del sistema o un hash que describa la nueva fuente de entrada. Este hash tiene las mismas propiedades que el parámetro `"Source"' de `parse()':

PublicId    El identificador público de la entidad externa que se está
            referenciando, o undef si no se proporcionó ninguno. 
SystemId    El identificador del sistema de la entidad externa que se está
            referenciando.
String      Cadena que contiene texto XML
ByteStream  Un manejador de archivo abierto.
CharacterStream
            Un manejador de archivo abierto.
Encoding    La codificación de caracteres, si se conoce.
