XML::LibXML::PI(3) Documentación de Perl aportada por el usuario XML::LibXML::PI(3)

NOMBRE

XML::LibXML::PI - Instrucciones de procesamiento de XML::LibXML

SINOPSIS

use XML::LibXML;
# Solo se listan aquí los métodos específicos de los nodos de Instrucción de Procesamiento,
# consulta la página del manual de XML::LibXML::Node para otros métodos
$pinode->setData( $data_string );
$pinode->setData( name=>string_value [...] );

DESCRIPCIÓN

Las instrucciones de procesamiento se implementan con XML::LibXML con acceso de lectura y escritura. Los datos de la PI son la PI sin el objetivo de la PI (según se especifica en XML 1.0 [17]) como una cadena. Esta cadena se puede acceder con getData tal como se implementa en XML::LibXML::Node.

El acceso de escritura es consciente del hecho de que muchas instrucciones de procesamiento tienen datos similares a atributos. Por lo tanto, setData() proporciona, además de la interfaz conforme a la especificación DOM, la capacidad de pasar un conjunto de parámetros con nombre. Así, el segmento de código

my $pi = $dom->createProcessingInstruction("abc");
$pi->setData(foo=>'bar', foobar=>'foobar');
$dom->appendChild( $pi );

resultará en la siguiente PI en el DOM:

<?abc foo="bar" foobar="foobar"?>

Que es como se especifica en la especificación DOM. Esta interfaz de tres pasos crea temporalmente un nodo en el espacio de Perl. Esto se puede evitar utilizando el método insertProcessingInstruction(). En lugar de las tres llamadas descritas anteriormente, la llamada

$dom->insertProcessingInstruction("abc",'foo="bar" foobar="foobar"');

tendrá el mismo resultado que el anterior.

La implementación de setData() de XML::LibXML::PI, que se documenta a continuación, difiere un poco de la versión estándar disponible en XML::LibXML::Node:

setData
$pinode->setData( $data_string );
$pinode->setData( name=>string_value [...] );

Este método permite cambiar los datos del contenido de una PI. Además de la interfaz especificada para DOM Level2, el método proporciona una interfaz de parámetros con nombre para establecer los datos. Esta lista de parámetros se convierte en una cadena antes de adjuntarse a la PI.
