NOMBRE

XmIconBox — La clase del widget IconBox

SINOPSIS

#include <Xm/IconBox.h>

DESCRIPCIÓN

El widget Icon Box organiza sus hijos en una cuadrícula con cada hijo forzado a tener el mismo tamaño y con la ubicación de cada hijo especificada como una ubicación X e Y en la cuadrícula.

El tamaño del Icon Box, sus hijos y el número de celdas mostradas se calculan como se describe a continuación. La idea general es que todos los hijos se muestren siempre y se les dé su tamaño deseado siempre que sea posible. El usuario puede agregar o eliminar celdas redimensionando esta ventana usando el widget del administrador de ventanas.

El tamaño preferido se calcula utilizando la altura o anchura deseada máxima del hijo y asegurándose de que no sean menores que los tamaños mínimos. Este tamaño se multiplica por el número de celdas en el eje y se le añade el relleno adecuado para obtener un tamaño preferido. El número de celdas es el máximo entre el valor más grande de cellX o cellY y el número mínimo de celdas horizontales o verticales.

Si el Icon Box se fuerza a ser más grande que su tamaño preferido, se agregan más celdas en la parte inferior derecha del widget, mientras que los hijos permanecen con sus tamaños preferidos.

Si el Icon Box se fuerza a ser más pequeño que su tamaño preferido, cada celda se ve forzada a ser más pequeña para permitir que todos los hijos encajen dentro del Icon Box. Todos los hijos se verán forzados al mismo tamaño más pequeño.

Clases

Icon Box hereda comportamiento, recursos y rasgos de Core, Composite, Constraint y XmManager.

El puntero de clase es xmIconBoxWidgetClass.

El nombre de la clase es XmIconBox.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNcellX

La ubicación de esta celda en el espacio de celdas. Estas coordenadas pueden ser cualquier entero positivo. Determinan dónde se colocará este widget en relación con sus vecinos. Tener dos hijos en la misma ubicación de celda X y celda Y resultará en un comportamiento indefinido. Para colocar una celda en cualquier celda vacía, establezca cell X y cell Y al valor XmIconBoxAnyCell.
