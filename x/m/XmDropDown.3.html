NOMBRE

XmDropDown — La clase de widget DropDown

SINOPSIS

#include <Xm/DropDown.h>

DESCRIPCIÓN

El widget DropDown permite al usuario seleccionar elementos de una lista de opciones e ingresar sus propios valores en un widget de texto. Para conservar espacio en pantalla, la lista de opciones solo se muestra cuando el usuario selecciona el botón de flecha hacia abajo. Luego se pueden seleccionar las opciones de esta lista. Si el widget de lista está en modo de selección de navegación (el predeterminado) o en modo de selección única, la lista se eliminará automáticamente cuando el usuario seleccione un elemento de la lista. Cuando la lista está en otros modos, se pueden seleccionar varios elementos y la lista se puede cerrar haciendo clic nuevamente en el botón de flecha, haciendo clic fuera de la lista o haciendo doble clic en un elemento. Al usar la navegación por teclado, la lista se puede cerrar seleccionando el botón de flecha o Alt + flecha abajo, y volver a abrirse escribiendo la tecla osfActivate, un retorno de carro o Alt + flecha arriba. En cualquier caso, cuando se elimina la lista, el elemento o los elementos seleccionados se colocarán en el widget de texto separados por comas. Escribir la tecla escape cuando la lista está activa cancela la aparición de la lista, restaurando el widget DropDown al estado en el que se encontraba antes de que la lista apareciera. Si el área del campo de texto no es editable, hacer clic en cualquier lugar del campo de texto también cerrará la lista.

Hay recursos disponibles para cambiar los tamaños de margen, la posición del borde izquierdo de la lista emergente, si la etiqueta se muestra o no, si el widget de campo de texto puede ser editado, y si el texto de la lista se verifica o no contra las opciones disponibles en la lista. Al establecer recursos que ocurren en los hijos del widget DropDown, el contenido de la lista, el número de elementos visibles en la lista, el valor inicial del campo de texto y el valor de la etiqueta se pueden establecer o cambiar dinámicamente.

Si un desarrollador desea que la lista emergente de la ventana sea redimensionable, debe establecer allowShellResize en True en el momento de la creación.

CLASES

XmDropDown hereda comportamiento, recursos y rasgos de las clases Core, Composite y XmManager.

El puntero de clase es xmDropDownWidgetClass.

El nombre de la clase es XmDropDown.

XmNcustomizedCombinationBox
Si este recurso es True, el widget no creará automáticamente un shell emergente y un widget de lista. Este recurso se puede utilizar, como su nombre indica, para crear un cuadro combinado personalizado que tenga algo más que una lista. Si este recurso es verdadero, se debe proporcionar un shell al widget DropDown a través del recurso popupShellWidget. Justo antes de que se muestre el shell, se llama a updateShellCallback. Justo después de que se oculte el shell, se llama a updateTextCallback. Si verify es verdadero, se llama a verifyTextCallback cuando el cuadro combinado necesita verificar el contenido del widget de texto contra los valores permitidos en el shell personalizado.
XmNeditable
Este valor booleano determina si el usuario puede escribir en el widget TextField del widget DropDown. Si este valor es False, al seleccionar el campo de texto se mostrará la lista del cuadro combinado.
XmNhorizontalMargin
Especifica el espaciado horizontal entre los widgets hijos y el borde del widget DropDown.
XmNverticalMargin
Especifica el espaciado vertical entre los widgets hijos y el borde del widget DropDown.
XmNitemCount
El número de elementos en la lista emergente.
XmNitems
La lista de todas las opciones que se mostrarán en la lista emergente.
XmNlabelString
La cadena que se muestra como etiqueta del widget DropDown.
XmNpopupCursor
El cursor que se mostrará al usuario cuando se muestre la lista del DropDown. Consulte X Window System, Robert Scheiffler et al., Apéndice B, para ver las opciones.
XmNpopupOffset
La cantidad de espacio en píxeles entre el borde izquierdo del widget Text y el borde izquierdo de la lista cuando se muestra la lista. Los valores positivos significan que el borde izquierdo del texto está más a la izquierda, los valores negativos significan que el borde de la lista está más a la izquierda. Si se trata de un widget DropDown no personalizado, los bordes derechos del texto y del botón de flecha siempre estarán alineados.
XmNpopupShellWidget
El identificador del widget para el shell que se muestra cuando se hace clic en la flecha. Si customizedCombinationBox es False, este widget es creado automáticamente por el widget DropDown.
XmNshowLabel
Un valor booleano que especifica si se debe mostrar o no el widget Label del DropDown.
XmNupdateShellCallback
XmNupdateTextCallback
La rutina de devolución de llamada que se llamará cuando el contenido del widget shell o el widget Text necesiten actualizarse para corresponder con el otro. El shell se actualiza justo antes de que se muestre. El texto se actualiza justo después de que se oculte el shell. Si customizedComboBox es False, las actualizaciones se realizan automáticamente por el cuadro combinado. Estas rutinas se llaman para informar a la aplicación de que se ha tomado una acción, en caso de que desee realizar algún procesamiento adicional.
XmNuseTextField
Un valor booleano que especifica si se debe utilizar un widget XmTextField o XmText para la parte de entrada de texto del widget DropDown.
XmNvalue
La cadena que se muestra en el widget Text.
XmNverify
Si este recurso es verdadero, el widget DropDown verificará su valor contra la lista cada vez que pierda el foco o el usuario presione <Retorno de carro>. Si la verificación falla, se genera una advertencia de Xt con el nombre XmNtextVerifyFailed. Para capturar este mensaje, registre un XtWarningMsgHandler.
XmNverifyTextCallback
Esta rutina se llama cada vez que el contenido del widget Text puede necesitar ser verificado contra el contenido del shell emergente. Si el recurso customizedComboBox es False, el widget DropDown ya ha realizado la verificación cuando se llama a esta rutina.
XmNvisibleItemCount
El número de elementos visibles en la lista emergente a la vez.

Hijos

El DropDown está compuesto por muchos sub-widgets. La mayor parte de la información mostrada al usuario se establece a través de estos sub-widgets. La mayoría de los valores pasados a este widget a través de la lista de argumentos en el momento de la creación o mediante set values se pasan a cada uno de los hijos de este widget. Las solicitudes de get values deben realizarse caso por caso. Los hijos del DropDown se enumeran a continuación. Se debe consultar la documentación de OSF/Motif para obtener un conjunto completo de recursos para cada hijo. Aquí se enumera una lista parcial de los recursos más comunes para mayor comodidad.

XmDropDown comboBox

XmLabel label

XmTextField text

XmArrowButton arrow

OverrideShell popupShell

XmScrolledWindow listSW

XmScrollBar ListvScrollBar

XmScrollBar ListhScrollBar

XmList list

El shell emergente y sus hijos solo se crean cuando customizedCombinationBox es False.

Información de Callback

Ninguno de los procedimientos de callback de DropDown tiene actualmente datos de llamada definidos para ellos. El widget pasado a cada una de estas funciones es el widget DropDown.

void (Callback)(Widget cbw, XtPointer client_data, XtPointer unused)

cbw Es el identificador del widget del widget DropDown.

client_data Los datos del cliente pasados a este widget por el programador de la aplicación.

unused Este valor no está definido.

Gestión de Geometría

El widget DropDown organiza sus hijos (la etiqueta, el texto y la flecha) en una fila. La cantidad de espacio que se les asigna cuando al DropDown no se le permite tener el tamaño exacto que desea se determina utilizando las siguientes reglas:

1. A la flecha siempre se le da su tamaño solicitado.

2. Si el cuadro combinado es más grande de lo que desea ser, todo el espacio extra se le da al widget de texto.

3. Si el cuadro combinado es más pequeño de lo que desea ser, los widgets de texto y etiqueta se reducen en exactamente la misma proporción que desean.

Por ejemplo:

Si la cantidad de espacio para la etiqueta y el texto es de 100 píxeles y la etiqueta desea tener 50 píxeles de ancho y el texto desearía tener 100 píxeles de ancho, entonces la etiqueta recibirá 34 píxeles y el texto 66.

El widget del shell emergente se dimensiona de tal manera que el ancho del widget de la lista desplazable sea igual al ancho del widget de texto menos el valor del recurso "popupOffset". Sin embargo, si el shell emergente reside en un cuadro combinado personalizado, se le permite tener el tamaño que el hijo del shell emergente desee.
