NOMBRE

XML::LibXML::Pattern - Interfaz para patrones XPath de XML::LibXML

SINOPSIS

use XML::LibXML;
my $patron = XML::LibXML::Pattern->new('/x:html/x:body//x:div', { 'x' => 'http://www.w3.org/1999/xhtml' });
# probar una coincidencia en un nodo XML::LibXML::Node $nodo
if ($patron->matchesNode($nodo)) { ... }
# o en un lector XML::LibXML::Reader
if ($reader->matchesPattern($patron)) { ... }
# o saltar la lectura de todos los nodos que no coincidan
print $reader->nodePath while $reader->nextPatternMatch($patron);
$patron = XML::LibXML::Pattern->new( patron, { prefijo => uri_namespace, ... } );
$bool = $patron->matchesNode($nodo);

DESCRIPCION

Esta es una interfaz perl para el soporte de coincidencia de patrones de libxml2 http://xmlsoft.org/html/libxml-pattern.html. Esta característica requiere versiones recientes de libxml2.

Los patrones son un pequeño subconjunto del lenguaje XPath, que se limita a (disyunciones de) caminos de ubicación que involucran los ejes hijo y descendiente en forma abreviada, como se describe en la siguiente BNF extendida:

Selector ::=     Camino ( '|' Camino )*
Camino     ::=     ('.//' | '//' | '/' )? Paso ( '/' Paso )*
Paso     ::=     '.' | NameTest
NameTest ::=     QName | '*' | NCName ':' '*'

Para mayor legibilidad, se pueden usar espacios en blanco en las expresiones XPath del selector, aunque no estén explícitamente permitidos por la gramática: los espacios en blanco se pueden añadir libremente dentro de los patrones antes o después de cualquier token, donde

token     ::=     '.' | '/' | '//' | '|' | NameTest

Tenga en cuenta que no se permiten predicados ni pruebas de atributos.

Los patrones son particularmente útiles para el análisis de flujos proporcionado a través de la interfaz "XML::LibXML::Reader".

new()
$patron = XML::LibXML::Pattern->new( patron, { prefijo => uri_namespace, ... } );

El constructor de un patrón toma una expresión de patrón (según la describe la gramática BNF anterior) y una referencia HASH opcional que mapea prefijos a URIs de espacio de nombres. El método devuelve un objeto patrón compilado.

Tenga en cuenta que si el documento tiene un espacio de nombres predeterminado, aún se le debe asignar un prefijo para que pueda ser coincidido (según lo exige la especificación XPath 1.0). Por ejemplo, para coincidir con un elemento "<a xmlns="http://foo.bar"</a>", se debe usar un patrón como este:

$patron = XML::LibXML::Pattern->new( 'foo:a', { foo => 'http://foo.bar' });
matchesNode($nodo)
$bool = $patron->matchesNode($nodo);

Dado un objeto XML::LibXML::Node, devuelve un valor verdadero si el nodo coincide con la expresión del patrón compilado.

VER TAMBIÉN

XML::LibXML::Reader para otros métodos que involucran patrones compilados.
