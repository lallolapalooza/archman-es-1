NOMBRE

XmDirection — Tipo de dato para la dirección de los componentes del widget

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

XmDirection es el tipo de dato que especifica la dirección en la que el sistema muestra subwidgets, hijos de widgets u otros componentes visuales que se van a organizar. Este tipo de dato también afecta el orden de recorrido dentro de los grupos de pestañas.

XmDirection se implementa como una máscara de bits de carácter sin signo. Las direcciones horizontal y vertical se pueden especificar independientemente la una de la otra. XmDirection también especifica la precedencia de las direcciones horizontal y vertical entre sí. Por ejemplo, un valor de XmRIGHT_TO_LEFT_TOP_TO_BOTTOM organiza un componente horizontalmente de derecha a izquierda primero, luego verticalmente de arriba a abajo.

XmDirection proporciona las siguientes máscaras, cada una de las cuales corresponde a un bit particular en XmDirection:

•
XmRIGHT_TO_LEFT_MASK
•
XmLEFT_TO_RIGHT_MASK
•
XmTOP_TO_BOTTOM_MASK
•
XmBOTTOM_TO_TOP_MASK
•
XmPRECEDENCE_HORIZ_MASK
•
XmPRECEDENCE_VERT_MASK

Además de las máscaras de bits individuales anteriores, XmDirection también proporciona las siguientes máscaras de bits múltiples. Estas máscaras de bits múltiples son particularmente útiles como argumentos para XmDirectionMatchPartial:

•
XmHORIZONTAL_MASK
•
XmPRECEDENCE_MASK
•
XmVERTICAL_MASK

Motif también proporciona las siguientes constantes enumeradas para especificar varias combinaciones de direcciones:

XmRIGHT_TO_LEFT_TOP_TO_BOTTOM
Especifica que los componentes se organizan de derecha a izquierda primero, luego de arriba a abajo.
XmLEFT_TO_RIGHT_TOP_TO_BOTTOM
Especifica que los componentes se organizan de izquierda a derecha primero, luego de arriba a abajo.
XmRIGHT_TO_LEFT_BOTTOM_TO_TOP
Especifica que los componentes se organizan de derecha a izquierda primero, luego de abajo a arriba.
XmLEFT_TO_RIGHT_BOTTOM_TO_TOP
Especifica que los componentes se organizan de izquierda a derecha primero, luego de abajo a arriba.
XmTOP_TO_BOTTOM_RIGHT_TO_LEFT
Especifica que los componentes se organizan de arriba a abajo primero, luego de derecha a izquierda.
XmTOP_TO_BOTTOM_LEFT_TO_RIGHT
Especifica que los componentes se organizan de arriba a abajo primero, luego de izquierda a derecha.
XmBOTTOM_TO_TOP_RIGHT_TO_LEFT
Especifica que los componentes se organizan de abajo a arriba primero, luego de derecha a izquierda.
XmBOTTOM_TO_TOP_LEFT_TO_RIGHT
Especifica que los componentes se organizan de abajo a arriba primero, luego de izquierda a derecha.
XmTOP_TO_BOTTOM
Especifica que los componentes se organizan de arriba a abajo. Si la dirección horizontal es importante, no use esta constante.
XmBOTTOM_TO_TOP
Especifica que los componentes se organizan de abajo a arriba. Si la dirección horizontal es importante, no use esta constante.
XmDEFAULT_DIRECTION
Especifica que los componentes se organizan de acuerdo con la dirección por defecto. (Esta constante es principalmente para escritores de widgets.)
XmLEFT_TO_RIGHT
Especifica que los componentes se organizan de izquierda a derecha. Si la dirección vertical es importante, no use esta constante.
XmRIGHT_TO_LEFT
Especifica que los componentes se organizan de derecha a izquierda. Si la dirección vertical es importante, no use esta constante.
