NAME

XmOutline — La clase del widget Outline

SYNOPSIS

#include <Xm/Outline.h>

DESCRIPTION

El widget Outline es un contenedor que muestra la relación de sus hijos en un formato gráfico similar a un árbol. Cada hijo del widget Outline es un nodo en el Outline. Las relaciones padre-hijo entre estos nodos son completamente distintas de la jerarquía de widgets. La jerarquía de nodos se crea especificando el "padre" del árbol de cada nodo como un recurso de restricción. Si el padre de un nodo es NULL, se asume que es una raíz del árbol. Aunque cada widget solo puede tener un padre, el widget Outline soporta la adición de más de una nodo "raíz" a un solo Outline.

Nota: El widget Outline asume que será totalmente responsable de mapear y desmapear a sus hijos. Por lo tanto, ningún hijo de este widget debería modificar su recurso mappedWhenManaged. Si un hijo modifica este recurso, el comportamiento no está definido.

Interacción del Usuario

Cada nodo en el outline puede tener uno de cuatro estados: abierto, cerrado, siempre abierto y oculto. El estado de un nodo cambia cómo se presenta al usuario y qué acciones están disponibles para el usuario.

Abierto Este nodo tendrá una carpeta abierta mostrada a su izquierda que puede ser seleccionada por el usuario para cerrar este nodo. Cuando un nodo está abierto, todos sus hijos serán visibles para el usuario.

Cerrado Este nodo tendrá una carpeta cerrada mostrada a su izquierda que puede ser seleccionada por el usuario para abrir este nodo. Cuando un nodo está cerrado, ninguno de sus hijos será visible para el usuario.

Siempre Abierto Este nodo no tendrá ningún botón de carpeta asociado. Todos sus hijos serán visibles para el usuario.

Oculto Este nodo no se mostrará al usuario y todos sus hijos se presentarán y actuarán exactamente como si fueran hijos del padre de este nodo. Al usuario le parecerá que este nodo no existe.

Para mantener la consistencia de la interfaz de usuario, hemos encontrado que es mejor usar el estado del nodo "Siempre Abierto" para los nodos sin hijos. De esta manera, el usuario solo verá un botón de carpeta al lado de un nodo que tenga hijos que mostrar. Un botón de carpeta asociado a un nodo sin hijos no tiene semántica definida.

Clases

Outline hereda comportamiento y recursos de las clases Core, Composite, Constraint, XmManager y XmHierarchy.

El puntero de clase es xmOutlineWidgetClass.

El nombre de la clase es XmOutline.

XmOutline(3)

NAME

XmOutline

outline widget

SYNOPSIS

#include <Xm/Outline.h>

A widget that displays a hierarchy of nodes.

DESCRIPTION

The XmOutline widget is a widget that allows the user to display and manipulate a hierarchy of nodes. Each node can have children, and the widget provides a way to expand and collapse nodes to show or hide their children. The widget automatically manages the display of the hierarchy, and provides callbacks for user interaction.

The size of the outline widget will be just large enough to contain all nodes in the hierarchy. As the node state changes the outline will attempt to resize itself to just contain its currently visible children. If the outline is forced away from its desired size the children will not be moved and will either be clipped, or appear in the upper left hand corner of the window. For this reason it is usually desirable to put the outline into a Scrolled Window widget.

RELATED

Composite(3), Constraint(3), Core(3), XmCreateHierarchy(3), XmHierarchy(3), XmManager(3).
