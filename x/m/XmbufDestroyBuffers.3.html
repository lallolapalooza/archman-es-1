DESCRIPCIÓN

La biblioteca de programación de aplicaciones para la *Extensión de Doble Buffer, Multi-Buffer y Estéreo X11* contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede establecer con XSetExtensionErrorHandler y funciona de la misma manera que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve *True* si la extensión de multibuffer/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe sumarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe sumarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión mayor y menor de la extensión. El valor de retorno es cero si ocurre un error o distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con la acción de actualización y la pista de actualización dadas y se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores de Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus ventanas apropiadas dentro de los max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers con la misma ventana o se generará un error de Coincidencia (Match).

XmbufGetWindowAttributes obtiene los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve distinto de cero si tiene éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita a la pista de actualización (update_hint).

XmbufGetBufferAttributes obtiene los atributos del buffer indicado. Devuelve distinto de cero si tiene éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del buffer indicado. Actualmente, esto se limita a la máscara de eventos (event_mask).

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Los números de conjuntos de visualizaciones y profundidades se devuelven en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen las diversas visualizaciones y profundidades que se pueden utilizar. De lo contrario, mono_info_return se establece en NULL. Del mismo modo, stereo_info_return se establece de acuerdo con nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los ID de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que devuelve, se devolverá *None* si la extensión no está disponible en este display.

NAME

XmbufDestroyBuffers – libera los búferes asociados con un objeto MultiBuffer.

SYNTAX

    void XmbufDestroyBuffers(Display *dpy, XID buffer_group);

STRUCTURES

    typedef XID XmbufBufferGroup;
    typedef XID XmbufBuffer;

DESCRIPTION

El búfer de grupo XID especificado por buffer_group se destruye, liberando todos los recursos asociados con él. La llamada a esta función debe ser precedida por la llamada a XmbufSetBufferGroup para establecer el grupo de búfer activo.

PREDEFINED VALUES

    ferUpdateNotifyMask
    MultibufferClobberNotify
    MultibufferUpdateNotify
    MultibufferNumberEvents
    MultibufferBadBuffer
    MultibufferNumberErrors
