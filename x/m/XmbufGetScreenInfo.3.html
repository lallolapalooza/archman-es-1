DESCRIPCIÓN

La biblioteca de programación de aplicaciones para la Extensión de Doble Búfer, Multibúfer y Estéreo de X11 contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede establecer con XSetExtensionErrorHandler y funciona igual que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de multitarea/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe agregarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe agregarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión principal y secundaria de la extensión. El valor de retorno es cero si ocurre un error o no cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con la acción de actualización y la pista de actualización dadas y se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores de Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus respectivas ventanas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers con la misma ventana o se generará un error de Coincidencia.

XmbufGetWindowAttributes obtiene los atributos de multitarea que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multitarea que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita a la pista de actualización.

XmbufGetBufferAttributes obtiene los atributos para el buffer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos para el buffer indicado. Actualmente, esto se limita a la máscara de eventos.

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Los números de conjuntos de visuales y profundidades se devuelven en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen los diversos visuales y profundidades que se pueden utilizar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece de acuerdo con nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los identificadores de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en este display.

NOMBRE

XmbufGetScreenInfo - obtener información sobre la pantalla de búfer múltiple

SINTAXIS

int XmbufGetScreenInfo(Display *dpy, int screen_number,
    XmbufScreenInfo *info_return);

ESTRUCTURAS

typedef struct {
    int major_version;
    int minor_version;
    unsigned int capabilities;
    int max_buffers;
    int num_buffers;
    int num_events;
    int num_errors;
} XmbufScreenInfo;

DESCRIPCIÓN

La función XmbufGetScreenInfo recupera información sobre las capacidades de búfer múltiple de una pantalla X específica.

Los parámetros son:

dpy
Un puntero a la estructura Display que representa la conexión al servidor X.
screen_number
El número de pantalla para el que se solicita la información.
info_return
Un puntero a una estructura XmbufScreenInfo donde se devolverá la información de la pantalla.

La estructura XmbufScreenInfo contiene los siguientes campos:

major_version
La versión principal de la extensión de búfer múltiple.
minor_version
La versión secundaria de la extensión de búfer múltiple.
capabilities
Una máscara de bits que indica las capacidades admitidas por la pantalla. Consulte VALORES PREDEFINIDOS.
max_buffers
El número máximo de búferes que se pueden asociar con una ventana.
num_buffers
El número de búferes actualmente asociados con una ventana (normalmente 1 si la extensión no está en uso).
num_events
El número de eventos de búfer múltiple definidos.
num_errors
El número de errores de búfer múltiple definidos.

La función devuelve un entero que indica el éxito o el fracaso. Un valor de 0 indica éxito, mientras que un valor distinto de cero indica un error.

VALORES PREDEFINIDOS

Los siguientes valores se pueden usar en el campo capabilities de la estructura XmbufScreenInfo:

XmbufNotifyMask
    XmbufClobberNotifyMask
    XmbufUpdateNotifyMask
    XmbufNumberEvents
    XmbufBadBuffer
    XmbufNumberErrors
