NOMBRE

XmSeparator — La clase del widget Separator

SINOPSIS

#include <Xm/Separator.h>

DESCRIPCIÓN

Separator es un widget primitivo que separa elementos en una pantalla. Se proporcionan varios estilos de dibujo de líneas, así como orientación horizontal o vertical.

El dibujo de la línea del Separator se centra automáticamente en la altura del widget para una orientación horizontal y se centra en el ancho del widget para una orientación vertical. Una llamada a XtSetValues con un nuevo valor para XmNseparatorType redimensiona el widget a su altura mínima (para orientación horizontal) o a su anchura mínima (para orientación vertical) a menos que la altura o la anchura se establezcan explícitamente en la llamada a XtSetValues.

Separator no dibuja sombras alrededor del separador. El recurso primitivo XmNshadowThickness se utiliza para el grosor del Separator cuando XmNseparatorType es XmSHADOW_ETCHED_IN, XmSHADOW_ETCHED_IN_DASH, XmSHADOW_ETCHED_OUT, o XmSHADOW_ETCHED_OUT_DASH.

Separator no resalta y no permite la navegación. El recurso primitivo XmNtraversalOn se fuerza a False.

El valor XmNseparatorType de XmNO_LINE proporciona una vía de escape al programador de aplicaciones que necesita un estilo de dibujo diferente. Se puede crear un pixmap con la altura del widget y usarlo como pixmap de fondo construyendo una lista de argumentos utilizando el tipo de argumento XmNbackgroundPixmap tal como lo define Core. Cada vez que el widget se redibuje, se mostrará su fondo conteniendo el dibujo del separador deseado. Separator mantiene el trait XmQTmenuSavvy.

Clases

Separator hereda comportamiento, recursos y traits de Core y XmPrimitive.

El puntero de clase es xmSeparatorWidgetClass.

El nombre de la clase es XmSeparator.

Recursos Nuevos

La siguiente tabla define un conjunto de recursos del widget que el programador utiliza para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), se puede establecer usando XtSetValues (S), se puede recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNmargin
Para orientación horizontal, especifica el espacio a la izquierda y derecha entre el borde del Separator y la línea dibujada. Para orientación vertical, especifica el espacio arriba y abajo entre el borde del Separator y la línea dibujada.
XmNorientation
Muestra el Separator vertical u horizontalmente. Este recurso puede tener valores de XmVERTICAL y XmHORIZONTAL.
XmNseparatorType
Especifica el tipo de dibujo de línea que se realizará en el widget Separator.
XmSINGLE_LINE
Línea simple
XmDOUBLE_LINE
Línea doble
XmSINGLE_DASHED_LINE
Línea simple con guiones
XmDOUBLE_DASHED_LINE
Línea doble con guiones
XmNO_LINE
Sin línea
XmSHADOW_ETCHED_IN
Una línea cuyas sombras dan el efecto de una línea grabada en la ventana. El grosor de la línea es igual al valor de XmNshadowThickness. Para orientación horizontal, la sombra superior se dibuja en XmNtopShadowColor y la sombra inferior se dibuja en XmNbottomShadowColor. Para orientación vertical, el borde izquierdo se dibuja en XmNtopShadowColor y el borde derecho se dibuja en XmNbottomShadowColor.
XmSHADOW_ETCHED_OUT
Una línea cuyas sombras dan el efecto de una línea grabada que sale de la ventana. El grosor de la línea es igual al valor de XmNshadowThickness. Para orientación horizontal, la sombra superior se dibuja en XmNbottomShadowColor y la sombra inferior se dibuja en XmNtopShadowColor. Para orientación vertical, el borde izquierdo se dibuja en XmNbottomShadowColor y el borde derecho se dibuja en XmNtopShadowColor.
XmSHADOW_ETCHED_IN_DASH
Idéntico a XmSHADOW_ETCHED_IN excepto que una serie de líneas crea una línea discontinua.
XmSHADOW_ETCHED_OUT_DASH
Idéntico a XmSHADOW_ETCHED_OUT excepto que una serie de líneas crea una línea discontinua.
