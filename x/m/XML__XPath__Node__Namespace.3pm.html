NOMBRE

Namespace - nodo de espacio de nombres XML

API

new ( prefijo, expandido )

Crea un nuevo nodo de espacio de nombres, expandido es la URI del espacio de nombres expandido.

getPrefix

Devuelve el prefijo

getExpanded

Devuelve la URI expandida

toString

Devuelve una cadena que puedes añadir a la lista de atributos de un elemento: xmlns:prefijo="expandido"
