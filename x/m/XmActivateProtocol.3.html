NOMBRE

XmActivateProtocol — Una función de VendorShell que activa un protocolo

SINOPSIS

#include <Xm/Protocols.h>
void XmActivateProtocol(
Widget shell,
Atom property,
Atom protocol);

DESCRIPCIÓN

XmActivateProtocol activa un protocolo. Actualiza los manejadores y la property si el shell está realizado. A veces es útil permitir que la información de estado de un protocolo (listas de callbacks, etc.) persista, aunque el cliente elija renunciar temporalmente a la interacción. Esto se admite al permitir que un protocol esté en uno de dos estados: activo o inactivo. Si el protocol está activo y el shell está realizado, la property contiene el Atom del protocolo. Si el protocolo está inactivo, el Atom no está presente en la property.

XmActivateWMProtocol es una interfaz de conveniencia. Llama a XmActivateProtocol con el valor de la propiedad establecido en el átomo devuelto por interning WM_PROTOCOLS.

shell
Especifica el widget con el que se asocia la propiedad del protocolo
property
Especifica la propiedad del protocolo
protocol
Especifica el Atom del protocolo

Para una definición completa de VendorShell y sus recursos asociados, consulte VendorShell(3).

RELACIONADO

VendorShell(3), XmActivateWMProtocol(3), XmRemoveProtocols(3) y XmInternAtom(3).
