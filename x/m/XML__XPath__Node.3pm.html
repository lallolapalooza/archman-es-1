NOMBRE

XML::XPath::Node - representación interna de un nodo

API

La API de Node intenta emular a DOM hasta cierto punto, sin embargo, la API no es completamente compatible con DOM. Esto es para facilitar la transición desde la programación XML::DOM a XML::XPath. La compatibilidad con DOM puede surgir una vez que XML::DOM obtenga soporte para namespaces.

new

Crea un nuevo nodo. Consulte las sub-clases para los parámetros que se pasarán a new().

getNodeType

Devuelve uno de los tipos ELEMENT_NODE, TEXT_NODE, COMMENT_NODE, ATTRIBUTE_NODE, PROCESSING_INSTRUCTION_NODE o NAMESPACE_NODE. Se devuelve UNKNOWN_NODE si la sub-clase no implementa getNodeType, ¡pero eso significa que algo está roto! Las constantes se exportan por defecto desde XML::XPath::Node. Las constantes tienen el mismo valor numérico que las versiones de XML::DOM.

getParentNode

Devuelve el padre de este nodo, o undef si este es el nodo raíz. Tenga en cuenta que el nodo raíz es el nodo raíz en términos de XPath, no el nodo elemento raíz.

to_sax ( $handler | %handlers )

Genera llamadas SAX para el manejador o manejadores. Consulte la documentación de PerlSAX para obtener más detalles (aún no implementado correctamente).
