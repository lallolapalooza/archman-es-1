XmStringTableToXmString(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringTableToXmString(llamada de biblioteca) XmStringTableToXmString(llamada de biblioteca)

NOMBRE

XmStringTableToXmString — Una función de conveniencia que convierte una tabla de cadenas compuestas en una única cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringTableToXmString(
XmStringTable table,
Cardinal count,
XmString break_component);

DESCRIPCIÓN

XmStringTableToXmString toma como entrada una table de cadenas compuestas y un componente de cadena especificado (como una tabulación) y devuelve una única cadena compuesta que consiste en cada uno de los elementos de table concatenados juntos con una única copia de break_component insertada entre cada elemento.

table
Especifica una XmStringTable que contiene las cadenas compuestas a convertir.
count
Especifica el número de cadenas compuestas en table.
break_component
Especifica el XmStringComponent que se insertará en el resultado para separar los elementos individuales de table. Los tipos más útiles serán XmSTRING_COMPONENT_SEPARATOR y XmSTRING_COMPONENT_TAB. Consulte la página de referencia de XmStringComponentType(3) para obtener una lista completa de los tipos de componentes posibles. Tenga en cuenta, sin embargo, que el componente XmSTRING_COMPONENT_UNKNOWN no es un tipo posible.

RETORNO

Devuelve una nueva XmString. La función asignará espacio para contener la cadena compuesta devuelta. Cuando la aplicación ya no necesite la cadena compuesta devuelta, la aplicación deberá llamar a XmStringFree.

RELACIONADO

XmString(3), XmStringComponentType(3) y XmStringFree(3).
