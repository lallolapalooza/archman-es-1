NOMBRE

XmMultiListSelectRow — Una función de MultiList que selecciona una fila en la lista

SINOPSIS

#include <Xm/MultiList.h>
void XmMultiListSelectRow(
Widget widget,
XmString row,
Boolean notify);

DESCRIPCIÓN

XmMultiListSelectRow resalta la fila especificada en el widget MultiList.

widget
Especifica el ID del widget MultiList de cuya lista se selecciona un elemento.
row
Especifica el número de fila (empezando desde 0) a seleccionar en el widget MultiList.
notify
Especifica un valor Booleano que, cuando es TRUE, invoca la devolución de llamada de selección para el modo actual. Desde una perspectiva de interfaz de aplicación, llamar a esta función con notify en True es indistinguible de una acción de selección iniciada por el usuario. Cuando notify es FALSE, no se llama a ninguna devolución de llamada.

Para una definición completa de MultiList y sus recursos asociados, consulte XmMultiList(3).

RELACIONADOS

XmMultiList(3).
