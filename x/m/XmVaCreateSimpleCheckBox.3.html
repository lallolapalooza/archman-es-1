NOMBRE

XmVaCreateSimpleCheckBox — Función de conveniencia para la creación de un widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleCheckBox(
Widget parent,
String name,
XtCallbackProc callback);

DESCRIPCIÓN

XmVaCreateSimpleCheckBox crea una instancia de un widget RowColumn de tipo XmWORK_AREA y devuelve el ID del widget asociado. Esta rutina utiliza la convención de llamada de lista de argumentos de longitud variable (varargs) de ANSI C.

Esta rutina crea un CheckBox y sus elementos hijos ToggleButtonGadget. Un CheckBox es similar a un RadioBox, excepto que se pueden seleccionar varios botones a la vez. El nombre de cada botón es button_n, donde n es un entero desde 0 (cero) hasta el número de botones en el menú menos 1. Los botones se nombran y crean en el orden en que se especifican en la parte variable de la lista de argumentos.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
callback
Especifica un procedimiento de devolución de llamada que se llamará cuando cambie el valor de un botón. Esta función de devolución de llamada se añade a cada botón después de la creación como XmNvalueChangedCallback del botón. La función de devolución de llamada se llama cuando cambia el valor de un botón, y el número del botón se devuelve en el campo client_data.

La parte variable de la lista de argumentos consta de grupos de argumentos. El primer argumento de cada grupo es una constante o una cadena y determina qué argumentos siguen en ese grupo. El último argumento de la lista debe ser NULL. La siguiente lista describe los posibles primeros argumentos en cada grupo de varargs:

XmVaCHECKBUTTON
A esto le siguen cuatro argumentos adicionales. El conjunto especifica un botón en el CheckBox y algunos de sus valores de recurso. La siguiente lista describe los cuatro argumentos adicionales, en orden.
label
La cadena de etiqueta, de tipo XmString
mnemonic
El mnemotécnico, de tipo KeySym. Se ignora en esta versión.
accelerator
El acelerador, de tipo String. Se ignora en esta versión.
accelerator_text
El texto del acelerador, de tipo XmString. Se ignora en esta versión.
resource_name
A esto le sigue un argumento adicional, el valor del recurso, de tipo XtArgVal. El par especifica un recurso y su valor para el widget RowColumn.
XtVaTypedArg
A esto le siguen cuatro argumentos adicionales. El conjunto especifica un recurso y su valor para el widget RowColumn. Se realiza una conversión de tipo de recurso si es necesario. A continuación se describen los cuatro argumentos adicionales, en orden:
name
El nombre del recurso, de tipo String
type
El tipo del valor del recurso proporcionado, de tipo String
value
El valor del recurso (o un puntero al valor del recurso, dependiendo del tipo y tamaño del valor), de tipo XtArgVal
size
El tamaño del valor del recurso en bytes, de tipo int
XtVaNestedList
A esto le sigue un argumento adicional de tipo XtVarArgsList. Este argumento es una lista anidada de varargs devuelta por XtVaCreateArgsList.

Para obtener más información sobre listas de argumentos de longitud variable, consulte la documentación de X Toolkit Intrinsics.

Existen varios recursos específicamente para su uso con esta y otras rutinas de creación de menús simples. Para obtener una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

DEVOLUCIÓN

Devuelve el ID del widget RowColumn.

RELACIONADOS
