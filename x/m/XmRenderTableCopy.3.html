NOMBRE

XmRenderTableCopy -- una función de tabla de renderizado que copia representaciones

SINOPSIS

#include <Xm/Xm.h>
XmRenderTable XmRenderTableCopy(
XmRenderTable table,
XmStringTag *tags,
int tag_count);

DESCRIPCIÓN

XmRenderTableCopy crea una nueva tabla de renderizado que contendrá las representaciones de la table cuyas etiquetas coincidan con las de tags.

table
Especifica la tabla que contiene las representaciones a copiar.
tags
Especifica una matriz de etiquetas, cuyas representaciones correspondientes se copiarán. NULL indica que se debe copiar la tabla completa.
tag_count
Especifica el número de etiquetas en tags.

RETORNO

Devuelve NULL si table es NULL. De lo contrario, esta función devuelve la nueva tabla de renderizado. Esta función asigna espacio para almacenar la nueva tabla de renderizado. La aplicación es responsable de gestionar este espacio asignado. La aplicación puede recuperar este espacio asignado llamando a XmRenderTableFree.

RELACIONADO

XmRendition(3) y XmRenderTableFree(3).
