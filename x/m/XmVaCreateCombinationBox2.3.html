XmVaCreateCombinationBox2(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmVaCreateCombinationBox2(llamada de biblioteca) XmVaCreateCombinationBox2(llamada de biblioteca)

NOMBRE

XmVaCreateCombinationBox2, XmVaCreateManagedCombinationBox2 — Funciones de creación de conveniencia para el widget Form.

SINOPSIS

#include <Xm/ComboBox2.h>
Widget XmVaCreateCombinationBox2(
Widget parent,
String name,
...);
Widget XmVaCreateManagedCombinationBox2(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget CombinationBox2 y devuelven el ID del widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos variables (varargs) ANSI C.

La función XmVaCreateCombinationBox2 es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreateManagedCombinationBox2 es una rutina de conveniencia que llama a XtCreateManagedWidget.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de Form y sus recursos asociados, consulte XmCombinationBox2(3).

DEVOLUCIÓN

Devuelve el ID del widget CombinationBox2.

RELACIONADO

XmCombinationBox2(3), XmCreateCombinationBox2(3), XtCreateManagedWidget(3), y XtCreateWidget(3).
