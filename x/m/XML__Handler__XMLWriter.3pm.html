NOMBRE

XML::Handler::XMLWriter - un manejador PerlSAX para escribir XML legible

SINOPSIS

use XML::Parser::PerlSAX;
use XML::Handler::XMLWriter;
$mi_manejador = XML::Handler::XMLWriter->new( OPCIONES );
XML::Parser::PerlSAX->new->parse(Source => { SystemId => 'REC-xml-19980210.xml' },
                                 Handler => $mi_manejador);

DESCRIPCIÓN

"XML::Handler::XMLWriter" es un manejador PerlSAX para escribir XML legible (en contraste con XML Canónico, por ejemplo). XML::Handler::XMLWriter puede ser usado con un analizador para reformatear XML, con XML::DOM o XML::Grove para escribir XML, o con otros módulos PerlSAX que generan eventos.

"XML::Handler::XMLWriter" está destinado a ser usado con generadores de eventos PerlSAX y no realiza ninguna verificación por sí mismo (por ejemplo, para emparejar eventos de inicio y fin de elemento). Si desea generar XML directamente desde su código Perl, use el módulo XML::Writer. XML::Writer tiene una interfaz fácil de usar y realiza muchas verificaciones para asegurarse de que el XML que genera esté bien formado.

"XML::Handler::XMLWriter" es una subclase de "XML::Handler::Subs". "XML::Handler::XMLWriter" puede ser subclaseada adicionalmente para alterar su comportamiento o para añadir manejo específico de elementos. En la subclase, cada vez que un elemento comienza, se llama a un método con ese nombre prefijado con `s_' con el elemento a procesar. Cada vez que un elemento termina, se llama a un método con ese nombre prefijado con `e_'. Cualquier carácter especial en el nombre del elemento se reemplaza por guiones bajos. Si no hay un método de inicio o fin para un elemento, la acción predeterminada es escribir la etiqueta de inicio o fin. Los métodos de inicio y fin pueden usar los métodos `print_start_element()' y `print_end_element()' para imprimir las etiquetas de inicio o fin. Las subclases pueden llamar al método `print()' para escribir salida adicional.

Subclasear XML::Handler::XMLWriter de esta manera es similar al estilo Stream de XML::Parser.

XML::Handler::Subs mantiene una pila de nombres de elementos, `"$self-"{Names}', y una pila de nodos de elementos, `"$self-"{Nodes}>' que pueden ser utilizados por las subclases. El elemento actual se inserta en las pilas antes de llamar a un método de inicio de nombre de elemento y se saca de las pilas después de llamar al método de fin de nombre de elemento.

Ver XML::Handler::Subs para métodos adicionales.

Además de los métodos estándar del manejador PerlSAX (ver PerlSAX para descripciones), XML::Handler::XMLWriter soporta los siguientes métodos:

nuevo( OPCIONES )
Crea y devuelve una nueva instancia de XML::Handler::XMLWriter con las OPCIONES dadas. Las opciones pueden ser cambiadas en cualquier momento modificándolas directamente en el hash devuelto. OPCIONES pueden ser una lista de pares clave, valor o un hash. Las siguientes OPCIONES son soportadas:
Salida
Un IO::Handle o uno de sus subclases (como IO::File), si este parámetro no está presente y la opción AsString no se usa, el módulo escribirá en la salida estándar.
ComoCadena
Devuelve el XML generado como una cadena desde el método `parse()' del generador de eventos PerlSAX.
SaltosDeLinea
Un valor verdadero o falso; si este parámetro está presente y su valor es verdadero, entonces el módulo insertará un salto de línea adicional antes del delimitador de cierre de las etiquetas de inicio, fin y vacías para garantizar que el documento no termine como una sola línea larga. Si el parámetro no está presente, el módulo no insertará los saltos de línea.
EsSGML
Un valor verdadero o falso; si este parámetro está presente y su valor es verdadero, entonces el módulo generará SGML en lugar de XML.
imprimir_etiqueta_inicio($elemento)
Imprime una etiqueta de inicio para `$elemento'. Esta es la acción predeterminada para el manejador PerlSAX `start_element()', pero las subclases pueden usarla si definen un método de inicio para un elemento.
imprimir_etiqueta_fin($elemento)
Imprime una etiqueta de fin para `$elemento'. Esta es la acción predeterminada para el manejador PerlSAX `end_element()', pero las subclases pueden usar esto si definen un método de inicio para un elemento.
imprimir($salida)
Escribe `$salida' en Salida y/o lo añade a la cadena a devolver. Las subclases pueden usar esto para escribir salida adicional.

PENDIENTE

  • Una opción Elementos que proporciona un control más fino sobre los saltos de línea que la opción SaltosDeLinea, donde se puede elegir antes y después de un salto de línea para las etiquetas de inicio y fin de elementos. Inspirado por el XMLWriter de Python.
  • Soporte para declaraciones Doctype y XML.
