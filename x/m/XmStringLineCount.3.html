XmStringLineCount(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringLineCount(llamada a biblioteca) XmStringLineCount(llamada a biblioteca)

NOMBRE

XmStringLineCount — una función de cadena compuesta que devuelve el número de separadores más uno en la cadena compuesta proporcionada

SINOPSIS

#include <Xm/Xm.h>
int XmStringLineCount(
XmString string);

DESCRIPCIÓN

XmStringLineCount devuelve el número de separadores más uno en la cadena compuesta proporcionada. En efecto, cuenta las líneas de texto.

string
Especifica la cadena.

RETORNO

Devuelve el número de líneas en la cadena compuesta. Si string está vacía, la función devuelve 1. Si se pasa NULL a string, la función devuelve 0 (cero).

RELACIONADOS

XmStringCreate(3).
