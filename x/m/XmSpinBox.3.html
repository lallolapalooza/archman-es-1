NOMBRE

XmSpinBox — La clase de widget SpinBox

SINOPSIS

#include <Xm/SpinB.h>

DESCRIPCIÓN

SpinBox permite al usuario seleccionar un valor de un anillo de opciones relacionadas pero mutuamente excluyentes que se muestran en secuencia. El SpinBox siempre tiene una flecha de incremento, una flecha de decremento y uno o más hijos. Las opciones se muestran, una a la vez, en un hijo de texto transitable ( XmText o XmTextField. El usuario hace clic en <Btn1> en una flecha para mostrar el elemento siguiente (o anterior) en el anillo de opciones. Al mantener presionado <Btn1> en una flecha, el usuario cicla continuamente a través de las opciones.

Los hijos transitables en un SpinBox pueden ser de tipo XmNUMERIC o XmSTRING, según lo definen el recurso de restricción XmNspinBoxChildType. El anillo de opciones para los hijos numéricos se define por los valores mínimo, máximo, incremental y punto decimal. El anillo de opciones para los hijos de cadena se define en una matriz de cadenas compuestas.

El programador de aplicaciones puede incluir varios hijos transitables en el SpinBox. Por ejemplo, un SpinBox podría consistir en un par de flechas y campos de texto de mes, día y año. Las flechas solo giran el hijo que actualmente tiene el foco.

El tamaño de las flechas se especifica mediante el recurso SpinBox XmNarrowSize. Este valor establece tanto el ancho como la altura de cada flecha en píxeles.

El programador puede mostrar las flechas del SpinBox en uno de varios diseños, según lo especificado por el recurso XmNarrowLayout:

XmARROWS_BEGINNING
Coloca un par de flechas izquierda y derecha antes de los hijos.
XmARROWS_END
Coloca un par de flechas izquierda y derecha después de los hijos.
XmARROWS_SPLIT
Coloca una flecha a cada lado de los hijos.
XmARROWS_FLAT_BEGINNING
Coloca un par de flechas una al lado de la otra antes de los hijos de XmSpinBox.
XmARROWS_FLAT_BEGINNING
Coloca un par de flechas una al lado de la otra después de los hijos de XmSpinBox.

Las posiciones para XmARROWS_BEGINNING y XmARROWS_END dependen del recurso XmNlayoutDirection del VendorShell. Cuando la dirección del diseño es de izquierda a derecha, las flechas de inicio se colocan a la izquierda de los hijos. Cuando la dirección del diseño es de derecha a izquierda, las flechas de inicio se colocan a la derecha.

Las acciones de las flechas están determinadas por el recurso XmNlayoutDirection del VendorShell. Para diseños de izquierda a derecha, la flecha derecha es la flecha de incremento y la flecha izquierda es la flecha de decremento. Para diseños de derecha a izquierda, la flecha derecha es la flecha de decremento y la flecha izquierda es la flecha de incremento.

Para un hijo de tipo numérico, la flecha de incremento aumenta el valor mostrado en el valor incremental hasta el máximo. La flecha de decremento disminuye el valor mostrado en el valor incremental dado hasta el mínimo.

La flecha de incremento para un hijo de tipo cadena se mueve hacia la última entrada de la matriz de cadenas compuestas (aumentando el recurso de restricción SpinBox XmNposition). La flecha de decremento se mueve hacia la primera entrada de la matriz de cadenas compuestas.

El programador también puede controlar la sensibilidad de cada flecha en el SpinBox. Las flechas sensibles giran las opciones; las flechas insensibles no giran las opciones. La sensibilidad de las flechas se establece para el widget SpinBox utilizando el recurso XmNdefaultArrowSensitivity, pero se puede modificar por hijo utilizando el recurso de restricción XmNarrowSensitivity.

SpinBox proporciona dos callbacks a los programadores de aplicaciones. (Además, se pueden invocar los callbacks de los hijos del SpinBox.) Cada uno de estos callbacks recibe un puntero a XmSpinBoxCallbackStruct. Los procedimientos XmNmodifyVerifyCallback se llaman *antes* de que se muestre una nueva opción. Los procedimientos XmNvalueChangedCallback se llaman *después* de que se muestre una nueva opción.

XmNmodifyVerifyCallback informa a la aplicación cuál será la nueva posición en el anillo de opciones. Este callback se puede usar para que el SpinBox se detenga en los límites superior e inferior o para ir a una opción diferente y no consecutiva. La aplicación permite el cambio de posición dejando el miembro doit establecido en True. La aplicación puede girar a una posición distinta de la posición consecutiva siguiente dejando doit establecido en True y cambiando el miembro position a la posición deseada. Cuando doit se establece en False por una aplicación, no hay ningún cambio en la opción mostrada.

Después de que se muestra una nueva opción, se llama al procedimiento XmNvalueChangedCallback. La aplicación puede usar este procedimiento para realizar tareas cuando se alcanzan valores específicos o cuando se cruzan límites. Por ejemplo, si el usuario gira de enero a diciembre, la aplicación podría cambiar al año anterior. Si el usuario gira de diciembre a enero, la aplicación podría cambiar al año siguiente.

Las dimensiones de SpinBox se pueden establecer utilizando los recursos principales XmNheight y XmNwidth. Si no se especifican las dimensiones, el tamaño del SpinBox se determina por el tamaño de sus flechas e hijos. El SpinBox intentará crecer para que las flechas y todos los hijos sean visibles.

SpinBox utiliza el trait XmQTaccessTextual y mantiene el trait XmQTnavigator.

CLASES

SpinBox hereda el comportamiento, los recursos y los traits de las clases Core, Composite, Constraint y XmManager.

El puntero de clase es xmSpinBoxWidgetClass.

El nombre de la clase es XmSpinBox.

Este callback se llama antes de que cambie la posición del SpinBox (ver el recurso de restricción XmNposition). Por ejemplo, este callback se puede utilizar para detener el giro justo antes de pasar los límites superior e inferior de posición. Si el miembro doit se establece en False, no sucede nada. De lo contrario, la posición cambia. Las razones enviadas por el callback son XmCR_SPIN_NEXT, XmCR_SPIN_PRIOR, XmCR_SPIN_FIRST, o XmCR_SPIN_LAST.

Cuando el usuario selecciona y mantiene presionado un botón de flecha manteniendo presionado <Btn1>, comienza el giro. Después de que transcurre el tiempo especificado en XmNinitialDelay, la posición del SpinBox cambia automáticamente hasta que se suelta el botón de flecha. El recurso XmNrepeatDelay especifica el retraso en milisegundos entre cada cambio automático. Si XmNrepeatDelay se establece en 0 (cero), el giro automático se desactiva y se ignora XmNinitialDelay.
XmNspacing
Especifica el espaciado horizontal y vertical entre los elementos contenidos dentro del widget SpinBox.
XmNvalueChangedCallback
Se llama n+1 veces para n cambios de posición del SpinBox (ver el recurso de restricción XmNposition). Las razones enviadas por el callback son XmCR_OK, XmCR_SPIN_NEXT, XmCR_SPIN_PRIOR, XmCR_SPIN_FIRST, o XmCR_SPIN_LAST. Otros miembros se detallan en la descripción de la estructura del callback.

Especifica la sensibilidad de las flechas para un hijo de SpinBox. XmNincrementValue
Especifica la cantidad en la que se incrementa o decrementa un hijo de tipo numérico del SpinBox. Esto se utiliza solo cuando XmNspinBoxChildType es XmNUMERIC.
XmNmaximumValue
Especifica el valor más alto posible para un SpinBox numérico. Esto se utiliza solo cuando XmNspinBoxChildType es XmNUMERIC.
XmNminimumValue
Especifica el valor más bajo posible para un SpinBox numérico. Esto se utiliza solo cuando XmNspinBoxChildType es XmNUMERIC.
XmNnumValues
Especifica el número de cadenas en XmNvalues. La aplicación debe cha
este valor cuando se agregan o eliminan cadenas de XmNvalues. Esto se usa solo cuando XmNspinBoxChildType es XmSTRING.
XmNposition
Especifica la posición del elemento que se muestra actualmente. La interpretación de XmNposition depende del valor del recurso XmNpositionType.
Cuando XmNpositionType es XmPOSITION_INDEX, el valor XmNposition se interpreta de la siguiente manera: Para hijos XmSpinBox de tipo XmNUMERIC, el recurso XmNposition se interpreta como un índice en una matriz de elementos. El valor mínimo admisible para XmNposition es 0. El valor máximo admisible para XmNposition es (XmNmaximumValue-XmNminimumValue)/XmNincrementValue. El valor mostrado por el hijo XmSpinBox es XmNminimumValue+(XmNposition*XmNincrementValue). Para hijos XmSpinBox de tipo XmSTRING, el recurso XmNposition se interpreta como un índice en una matriz de XmNnumValues elementos. El valor mínimo admisible para XmNposition es 0. El valor máximo admisible para XmNposition es XmNnumValues - 1. El valor mostrado por el XmSpinBox es el valor XmNposition en la matriz XmNvalues.
Cuando XmNpositionType es XmPOSITION_VALUE, el valor XmNposition se interpreta de la siguiente manera:
Para hijos XmSpinBox de tipo XmNUMERIC, el recurso XmNposition se interpreta como el valor real a mostrar. El valor mínimo admisible para XmNposition es XmNminimumValue. El valor máximo admisible para XmNposition es XmNmaximumValue. El valor mostrado por el hijo XmSpinBox es XmNposition. Para hijos XmSpinBox de tipo XmSTRING, la interpretación es la misma para XmPOSITION_VALUE que para XmPOSITION_INDEX.
Los valores de posición que caen fuera del rango especificado no son válidos. Cuando una aplicación asigna un valor a XmNposition que es inferior al mínimo, XmNposition se establece en el mínimo y se muestra un mensaje de error. Cuando una aplicación asigna un valor a XmNposition que es superior al máximo, XmNposition se establece en el máximo y se muestra un mensaje de error.
XmNpositionType
Especifica cómo se deben interpretar los valores del recurso XmNposition. Los valores válidos incluyen XmPOSITION_INDEX y XmPOSITION_VALUE.
XmNspinBoxChildType
Especifica el tipo de datos que se muestran en el hijo:
XmNUMERIC
El rango de elección de SpinBox se define por valores numéricos mínimo, máximo e incremental.
XmSTRING
Las elecciones de SpinBox son alfanuméricas.
XmNvalues
Especifica la matriz de XmStrings a mostrar en un hijo de tipo SpinBox de cadena. La aplicación debe cambiar XmNnumValues cuando se agreguen o eliminen cadenas de XmNvalues. Esto se usa solo cuando XmNspinBoxChildType es XmSTRING.

Callback

Se pasa un puntero a la siguiente estructura a cada callback:

typedef struct
{
        int reason;
        XEvent * event;
        Widget widget;
        Boolean doit;
        int position;
        XmString value;
        Boolean crossed_boundary;
} XmSpinBoxCallbackStruct;
reason
Indica por qué se invocó el callback. Las razones pueden ser las siguientes:
XmCR_OK
El giro se ha detenido porque la flecha de SpinBox se ha desarmado. XmCR_OK es la última o la única llamada.
XmCR_SPIN_NEXT
La flecha de incremento se ha armado y la posición está aumentando. Habrá más callbacks. Para un hijo de tipo numérico, los valores mostrados se acercan al máximo. Para un SpinBox de cadena, los valores mostrados se acercan a la última entrada en la matriz de XmStrings.
XmCR_SPIN_PRIOR
La flecha de decremento se ha armado y la posición está disminuyendo. Habrá más callbacks. Para un hijo de tipo numérico, los valores mostrados se acercan al mínimo. Para un hijo de tipo cadena, los valores mostrados se acercan a la primera entr
y en el array de XmStrings.
XmCR_SPIN_FIRST
Se ha presionado la secuencia de teclas de inicio de datos (<osfBeginData>). El SpinBox está en su primera posición, mostrando el valor más bajo o la primera entrada en el array de XmStrings.
XmCR_SPIN_LAST
Se ha presionado la secuencia de teclas de fin de datos (<osfEndData>). El SpinBox está en su última posición, mostrando el valor más alto o la última entrada en el array de XmStrings.
event
Apuntador a XEvent que activó este callback.
widget
Especifica el widget hijo afectado por este callback.
doit
Cuando el callback es XmNmodifyVerifyCallback, doit indica si se realizará una acción antes de que cambie la posición del SpinBox. Si el callback deja doit establecido en True (el valor predeterminado), se realiza la acción de giro. Si el callback establece doit en False, la acción de giro no se realiza. Cuando el callback es XmNvalueChangedCallback, doit se ignora.
position
Especifica el siguiente valor de la posición del SpinBox (igual que XmNposition). Este es un campo de salida para el XmNmodifyVerifyCallback, que puede cambiar la siguiente posición según las necesidades de una aplicación.
value
Especifica el nuevo valor XmString en el widget de texto hijo. El programa de usuario debe copiar esta cadena si se va a utilizar fuera de la rutina de callback.
crossed_boundary
Especifica si el SpinBox ha cruzado el límite superior o inferior (la última o primera cadena compuesta, o el valor máximo o mínimo). El valor de crossed_boundary es True si el SpinBox acaba de cruzar un límite, y False si no lo ha hecho.

Rutinas de Acción

Las rutinas de acción de XmSpinBox son las siguientes:

SpinBArm():
Prepara visualmente el SpinBox dibujando la flecha preparada para que parezca presionada. Esta acción se inicia cuando el usuario presiona <Btn1> mientras el puntero está dentro de los límites de la flecha de incremento o decremento. La flecha permanece visualmente preparada mientras <Btn1> permanezca presionado.
Si el período de tiempo especificado por XmNrepeatDelay no es mayor que cero milisegundos, no ocurre nada más mientras <Btn1> permanezca presionado.
Si el período de tiempo especificado por XmNrepeatDelay es mayor que cero milisegundos, y la flecha se desarma antes de que haya transcurrido el período de tiempo especificado por XmNinitialDelay, nada más sucede en esta acción.
Si el período de tiempo especificado por XmNrepeatDelay es mayor que cero milisegundos, y la flecha sigue preparada después de que haya transcurrido el período de tiempo especificado por XmNinitialDelay, ocurre lo siguiente:
•

XmSpinBox(3)

NAME

XmSpinBox - SpinBox widget

SYNOPSIS

SpinBFirst():
SpinBLast():
SpinBLeft():
SpinBNext():
SpinBPrior():
SpinBRight():

DESCRIPTION

The SpinBox widget provides a simple way to enter a value that can be incremented or decremented. It consists of a text field and two small buttons that trigger the increment and decrement actions.

SpinBFirst():
The following occurs:
•
The reason member of the SpinBox callback structure, XmSpinBoxCallbackStruct, is set to XmCR_SPIN_FIRST.
•
The position member is set to the first position.
•
The doit member is set to True.
•
XmNmodifyVerifyCallback, if it exists, is invoked. The application may change the value of position and doit. If the application sets doit to False, nothing else happens until the XmNrepeatDelay period has elapsed, or until <Btn1> is released.
If doit remains set to True, the following occurs:
•
The value of XmNposition is changed to the value of position in the SpinBox callback structure.
•
The text corresponding to the new position is displayed in the traversable text child that currently has focus.
•
The reason member of the SpinBox callback structure is set to XmCR_SPIN_FIRST.
•
The position member is set to the current (new) value of XmNposition.
•
XmNvalueChangedCallback, if it exists, is called.
•
The reason member of the SpinBox callback structure is set to XmCR_OK.
•
The position member is set to the current (new) XmNposition value.
•
The XmNvalueChangedCallback is called again. SpinBox ignores any changes to position or doit members made by XmNvalueChangedCallback.
SpinBLast():
The following occurs:
•
The reason member of the SpinBox callback structure, XmSpinBoxCallbackStruct, is set to XmCR_SPIN_LAST.
•
The position member is set to the last position.
•
The doit member is set to True.
•
XmNmodifyVerifyCallback, if it exists, is invoked. The application may change the value of position and doit. If the application sets doit to False, nothing else happens until the XmNrepeatDelay period has elapsed, or until <Btn1> is released.
If doit remains set to True, the following occurs:
•
The value of XmNposition is changed to the value of position in the SpinBox callback structure.
•
The text corresponding to the new position is displayed in the traversable text child that currently has focus.
•
The reason member of the SpinBox callback structure is set to XmCR_SPIN_LAST.
•
The position member is set to the current (new) value XmNposition.
•
XmNvalueChangedCallback, if it exists, is called.
•
The reason member of the SpinBox callback structure is set to XmCR_OK.
•
The position member is set to the current (new) of XmNposition.
•
XmNvalueChangedCallback is called again. SpinBox ignores any changes to the position or doit members made by XmNvalueChangedCallback.
SpinBLeft():
If the VendorShell resource XmNlayoutDirection is left-to-right, the SpinBPrior action is invoked. Otherwise, the SpinBNext action is invoked.
