NOMBRE

XmPanedWindow — La clase de widget PanedWindow

SINOPSIS

#include <Xm/PanedW.h>

DESCRIPCIÓN

PanedWindow es un widget compuesto que organiza a los hijos en un formato de mosaico vertical. Los hijos aparecen de arriba a abajo, con el primer hijo insertado apareciendo en la parte superior del PanedWindow y el último hijo insertado apareciendo en la parte inferior. El PanedWindow crece para igualar el ancho de su hijo más ancho y todos los demás hijos se fuerzan a este ancho. La altura del PanedWindow es igual a la suma de las alturas de todos sus hijos, el espaciado entre ellos y el tamaño de los márgenes superior e inferior.

El usuario también puede ajustar el tamaño de los paneles. Para facilitar este ajuste, se crea un tirador de control de panel para la mayoría de los hijos. El tirador aparece como un cuadro cuadrado posicionado en la parte inferior del panel que controla. El usuario puede ajustar el tamaño de un panel usando el ratón o el teclado.

El PanedWindow es también un widget de restricción, lo que significa que crea y gestiona un conjunto de restricciones para cada hijo. Puede especificar un tamaño mínimo y máximo para cada panel. El PanedWindow no permite que un panel se redimensione por debajo de su tamaño mínimo o más allá de su tamaño máximo. Además, cuando el tamaño mínimo de un panel es igual a su tamaño máximo, no se presenta ningún tirador de control para ese panel ni para el panel inferior.

El procedimiento predeterminado XmNinsertPosition para PanedWindow hace que todos los paneles aparezcan primero en la lista XmNchildren y todos los tiradores aparezcan después de los paneles. Para un hijo de panel, devuelve el valor de XmNpositionIndex si se ha especificado para el hijo. De lo contrario, devuelve el número de *paneles* en la lista XmNchildren del PanedWindow. Aparte del hecho de que todos los tiradores aparecen después de todos los paneles, el orden de inserción de los tiradores no está especificado. Este procedimiento también hace que los widgets que no son tiradores se inserten después de otros hijos que no son tiradores pero antes que cualquier tirador. El comportamiento de PanedWindow no está definido si XmNinsertPosition se establece en un procedimiento que no sea el predeterminado.

Todos los paneles y tiradores en un PanedWindow deben ser grupos de tabulación. Cuando un panel se inserta como hijo del PanedWindow, si el XmNnavigationType del panel no es XmEXCLUSIVE_TAB_GROUP, PanedWindow lo establece en XmSTICKY_TAB_GROUP.

NAME

XmPanedWindow — A manager that allows you to adjust the size of adjacent panes

SYNOPSIS

#include <Xm/PanedW.h>

DESCRIPTION

The XmPanedWindow widget is a manager that allows you to adjust the size of adjacent panes. It supports adding and removing panes, as well as manipulating the sash between panes. The sash is the control used to resize the panes.

The XmPanedWindow widget is a subclass of XmManager.

XmPanedWindow Resources

The XmPanedWindow widget has the following resources:

XmNallowPaneResize:
Specifies whether the panes can be resized. The default is True.
XmNbeforeSeparator:
Specifies a widget that will be placed before the separator. This resource is used for special cases, such as placing a menu bar above the pane window.
XmNorientation:
Specifies the orientation of the sash. Can be XmHORIZONTAL or XmVERTICAL. The default is XmVERTICAL.
XmNpaneMaximum:
Specifies the maximum size of a pane. The default is 0.
XmNpaneMinimum:
Specifies the minimum size of a pane. The default is 0.
XmNsashHeight:
Specifies the height of the sash. The default is 8.
XmNsashIndent:
Specifies the indentation of the sash from the left or top edge of the pane. The default is 0.
XmNsashShadowThickness:
Specifies the thickness of the sash shadow. The default is 2.
XmNseparatorOn:
Specifies whether the separator is displayed. The default is True.
XmNshowGrip:
Specifies whether the sash grip is displayed. The default is True.

Action Routines

The XmPanedWindow action routines are

Help():
Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
NextTabGroup():
Moves the keyboard focus to the next tab group. By default, each pane and sash is a tab group.
PrevTabGroup():
Moves the keyboard focus to the previous tab group. By default, each pane and sash is a tab group.
SashAction(action) or SashAction(Key,increment,direction):
The Start action activates the interactive placement of the pane's borders. The Move action causes the sash to track the position of the pointer. If one of the panes reaches its minimum or maximum size, adjustment continues with the next adjustable pane. The Commit action ends sash motion.
When sash action is caused by a keyboard event, the sash with the keyboard focus is moved according to the increment and direction specified. DefaultIncr adjusts the sash by one line. LargeIncr adjusts the sash by one view region. The direction is specified as either Up, Down, Left, or Right.
Note that the SashAction action routine is not a direct action routine of the XmPanedWindow, but rather an action of the Sash control created by the XmPanedWindow.

Additional Behavior

This widget has the following additional behavior:

<FocusIn>:
Moves the keyboard focus to the sash and highlights it
<FocusOut>:
Unsets the keyboard focus in the sash and unhighlights it
