NOMBRE

XmStringGetLtoR — Función de cadena compuesta que busca un segmento de texto en la cadena compuesta de entrada

SINAPSIS

#include <Xm/Xm.h>
Boolean XmStringGetLtoR(
XmString string,
XmStringCharSet tag,
char **text);

DESCRIPCIÓN

Esta función es obsoleta y existe por compatibilidad con versiones anteriores. Ha sido reemplazada por XmStringUnparse. XmStringGetLtoR devuelve el primer componente de texto en la cadena compuesta de entrada que está etiquetado con el componente de etiqueta dado. El texto devuelto debe ser una secuencia de caracteres de un solo byte terminada en NULL. Si la función devuelve True, la función asignará espacio para contener el text devuelto. La aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XtFree.

string
Especifica la cadena compuesta.
tag
Especifica la etiqueta del elemento de la lista de fuentes asociada con el texto. Un valor de XmFONTLIST_DEFAULT_TAG identifica un segmento de texto local.
text
Especifica un puntero a una cadena terminada en NULL.

RETORNO

Devuelve True si se puede encontrar el segmento de texto coincidente. Al regresar, text tendrá una secuencia de bytes terminada en NULL que contiene el segmento coincidente.
