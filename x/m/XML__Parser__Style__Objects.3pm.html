NOMBRE

XML::Parser::Style::Objects - Analizador de estilo de objetos

SINOPSIS

use XML::Parser;
my $p = XML::Parser->new(Style => 'Objects', Pkg => 'MyNode');
my $tree = $p->parsefile('foo.xml');

DESCRIPCIÓN

Este módulo implementa el analizador de estilo Objects de XML::Parser.

Esto es similar al estilo Tree, excepto que se crea un objeto hash para cada elemento. El objeto correspondiente estará en la clase cuyo nombre se crea al añadir "::" y el nombre del elemento al paquete establecido con la opción Pkg. El texto no marcado estará en la clase ::Characters. El contenido del objeto correspondiente estará en un array anónimo que es el valor de la propiedad Kids para ese objeto.
