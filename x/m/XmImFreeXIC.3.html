NOMBRE

XmImFreeXIC — Una función del gestor de entrada que anula el registro de widgets para un XIC

SINOPSIS

#include <Xm/XmIm.h>
void XmImFreeXIC(
Widget widget,
XIC xic);

DESCRIPCIÓN

XmImFreeXIC anula el registro de todos los widgets asociados con el Contexto de Entrada X (XIC) especificado. El widget especificado debe estar asociado con el xic especificado.

Después de anular el registro de los widgets asociados, esta llamada libera el xic.

widget
Especifica el ID de un widget utilizado para identificar el VendorShell y XmDisplay que mantienen el registro de widget-XIC.
xic
Especifica el Contexto de Entrada asociado con el widget.

RELACIONADOS

XmImGetXIC(3) y XmImSetXIC(3).
