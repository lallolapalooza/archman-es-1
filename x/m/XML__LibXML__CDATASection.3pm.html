NOMBRE

XML::LibXML::CDATASection - Clase de XML::LibXML para secciones CDATA

SINOPSIS

use XML::LibXML;
# Solo se enumeran aquí los métodos específicos de los nodos CDATA,
# consulta la página del manual de XML::LibXML::Node para otros métodos.
$nodo = XML::LibXML::CDATASection->new( $contenido );

DESCRIPCIÓN

Esta clase proporciona todas las funciones de XML::LibXML::Text, pero para nodos CDATA.

MÉTODOS

La clase hereda de XML::LibXML::Node. La documentación de los métodos heredados no se incluye aquí.

Muchas de las funciones aquí listadas están extensamente documentadas en la especificación DOM Nivel 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Por favor, consulta la especificación para obtener documentación exhaustiva.

new
$nodo = XML::LibXML::CDATASection->new( $contenido );

El constructor es la única función proporcionada para este paquete. Es necesario, porque *libxml2* trata los diferentes tipos de nodos de texto de manera ligeramente distinta.
