NOMBRE

XmCreateSelectionBox — La función de creación del widget SelectionBox

SINOPSIS

#include <Xm/SelectioB.h>
Widget XmCreateSelectionBox(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateSelectionBox crea un SelectionBox no administrado. Un SelectionBox se utiliza para obtener una selección de una lista de alternativas del usuario e incluye lo siguiente:

•
Una lista con desplazamiento de alternativas
•
Un campo de texto editable para la alternativa seleccionada
•
Etiquetas para la lista y el campo de texto
•
Tres o cuatro botones

Las etiquetas de los botones por defecto son OK, Cancel y Help. Por defecto, también se crea un botón Apply. Si el padre del SelectionBox es un DialogShell, se administra; de lo contrario, no se administra. Se pueden añadir hijos adicionales del área de trabajo al SelectionBox después de la creación.

parent
Especifica el ID del widget padre
name
Especifica el nombre del widget creado
arglist
Especifica la lista de argumentos
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist)

Para una definición completa de SelectionBox y sus recursos asociados, consulte XmSelectionBox(3).

VALOR DE RETORNO

Devuelve el ID del widget SelectionBox.

RELACIONADOS

XmSelectionBox(3).
