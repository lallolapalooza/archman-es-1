DESCRIPCIÓN

La biblioteca de aplicaciones de programación para la Extensión de Doble Buffer, Multibuffer y Estéreo de X11 contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede establecer con XSetExtensionErrorHandler y funciona igual que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de multibuffer/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe añadirse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe añadirse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión principal y secundaria de la extensión. El valor de retorno es cero si ocurre un error o no cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con la acción de actualización y la pista de actualización dadas y que se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus ventanas apropiadas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers a la misma ventana o se generará un error de Coincidencia (Match).

XmbufGetWindowAttributes obtiene los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita a la pista de actualización (update_hint).

XmbufGetBufferAttributes obtiene los atributos del buffer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del buffer indicado. Actualmente, esto se limita a la máscara de eventos (event_mask).

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Se devuelven los números de conjuntos de visuales y profundidades en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen los diversos visuales y profundidades que se pueden utilizar. De lo contrario, mono_info_return se establece en NULL. Del mismo modo, stereo_info_return se establece según nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los identificadores de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en este display.

NOMBRE

XmbufGetBufferAttributes - obtener atributos de buffer

SINTAXIS

#include <X11/extensions/Xmuu.h>

XBufferAttributes *
XmbufGetBufferAttributes(Display *display, XID buffer_id,
    XBufferAttributes *attributes);

ESTRUCTURAS

typedef struct { int width; int height; int red_precision; int green_precision; int blue_precision; Bool stereo_3X; int buffer_size; int double_buffer; int max_buffers; int bits_per_buffer; int render_mode; } XBufferAttributes;

DESCRIPCIÓN

El procedimiento XmbufGetBufferAttributes recupera los atributos del buffer especificado por buffer_id y los almacena en la estructura apuntada por attributes. Si attributes es NULL, se asigna y devuelve una nueva estructura XBufferAttributes. De lo contrario, se utiliza la estructura existente y se devuelve su puntero.

Los campos de la estructura XBufferAttributes son:

width, height
Dimensiones del buffer.
red_precision, green_precision, blue_precision
Precisión de los componentes de color.
stereo_3X
Indica si se admite estéreo 3X.
buffer_size
Tamaño del buffer en bytes.
double_buffer
Indica si se admite doble buffer.
max_buffers
Número máximo de buffers admitidos.
bits_per_buffer
Número de bits por buffer.
render_mode
Modo de renderizado del buffer.

VALORES PREDEFINIDOS

Los siguientes valores pueden aparecer en el campo render_mode:

    Retained
    Instantaneous

Los siguientes valores pueden aparecer en el campo double_buffer:

    DoubleBufferDisabled
    DoubleBufferEnabled

Los siguientes valores pueden aparecer en el campo stereo_3X:

    StereoDisabled
    StereoEnabled
