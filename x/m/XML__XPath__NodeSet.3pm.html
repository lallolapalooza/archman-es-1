NOMBRE

XML::XPath::NodeSet - un conjunto de nodos de documentos XML

DESCRIPCIÓN

Un objeto XML::XPath::NodeSet contiene una lista ordenada de nodos. Los nodos tienen el mismo formato que se describe en XML::XPath::XMLParser.

SINOPSIS

my $resultados = $xp->find('//algun_elemento');
if (!$resultados->isa('XML::XPath::NodeSet')) {
        print "Encontrado $resultados\n";
        exit;
}
foreach my $contexto ($resultados->get_nodelist) {
        my $nuevos_resultados = $xp->find('./otro/elemento', $contexto);
        ...
}

API

new()

Casi nunca tendrás que crear un nuevo objeto NodeSet, ya que XPath lo hace todo por ti.

get_nodelist()

Devuelve una lista de nodos. Consulta XML::XPath::XMLParser para ver el formato de los nodos.

string_value()

Devuelve el valor de cadena del primer nodo de la lista. Consulta la especificación XPath para saber qué significa "valor de cadena".

to_literal()

Devuelve la concatenación de todos los valores de cadena de todos los nodos de la lista.

get_node($pos)

Devuelve el nodo en la posición $pos. La posición del nodo en XPath se basa en 1, no en 0.

size()

Devuelve el número de nodos en el NodeSet.

pop()

Equivalente a la función pop de Perl.

push(@nodes)

Equivalente a la función push de Perl.

append($nodeset)

Dado un conjunto de nodos, añade la lista de nodos en $nodeset al final de la lista actual.

shift()

Equivalente a la función shift de Perl.

unshift(@nodes)

Equivalente a la función unshift de Perl.

prepend($nodeset)

Dado un conjunto de nodos, antepone la lista de nodos en $nodeset al principio de la lista actual.
