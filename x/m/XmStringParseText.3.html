NOMBRE

XmStringParseText — Una función que convierte una cadena de caracteres en una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringParseText(
XtPointer text,
XtPointer *text_end,
XmStringTag tag,
XmTextType type,
XmParseTable parse_table,
Cardinal parse_count,
XtPointer call_data);

DESCRIPCIÓN

XmStringParseText convierte los caracteres especificados en text en los componentes correspondientes de la cadena compuesta devuelta. La cadena compuesta resultante consta de al menos un componente de etiqueta de localidad o conjunto de caracteres y una serie de componentes de texto XmString y otros componentes. La conversión procede de acuerdo con la información de análisis contenida en parse_table. Consulte la *Motif Programmer's Guide* para obtener más información sobre el análisis y las tablas de análisis.

•
Si type es XmCHARSET_TEXT, la etiqueta asociada tag se interpreta como un nombre de conjunto de caracteres. Si tag tiene un valor NULL, se crea un componente de conjunto de caracteres cuyo valor es el resultado de mapear XmFONTLIST_DEFAULT_TAG.
•
Si type es XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT, la etiqueta asociada tag se interpreta como un nombre de entorno de localidad. Si tag tiene un valor NULL, se crea un componente de localidad con un valor de _MOTIF_DEFAULT_LOCALE. Si type es XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT, tag debe ser NULL o _MOTIF_DEFAULT_LOCALE.

XmStringParseText también escanea la cadena en busca de caracteres que tengan coincidencias en parse_table. Cada vez que se encuentra una coincidencia, el texto hasta ese punto se concatena con el componente mapeado.

text
Especifica la cadena terminada en NULL que contiene caracteres de un tipo determinado por type. Esto se actualiza para apuntar después del último carácter escaneado.
text_end
Especifica un puntero dentro de text. Si se suministra un NULL al parámetro text_end, entonces XmStringParseText analiza text hasta que se encuentre NULL, o hasta que llegue a un punto en text donde se le indique que se detenga (por ejemplo, por un parse_proc). De lo contrario, el valor suministrado al parámetro text_end es el puntero dentro de text donde se detendrá el análisis, y el carácter devuelto es aquel donde se detuvo el análisis.
tag
Especifica la etiqueta que se utilizará para crear el resultado. El tipo de etiqueta de cadena creada (conjunto de caracteres o localidad) depende del tipo de texto y del valor de tag proporcionado. Si el valor de tag es NULL y si type indica que se debe crear una etiqueta de cadena de conjunto de caracteres, la etiqueta de cadena tendrá el valor que resulta de mapear XmFONTLIST_DEFAULT_TAG. Si type indica una etiqueta de cadena de localidad, la etiqueta de cadena tendrá el valor _MOTIF_DEFAULT_LOCALE.
type
Especifica el tipo de texto y el tipo de etiqueta. Si se debe crear una etiqueta de localidad, type tendrá un valor de XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT. Si type tiene el valor XmCHARSET_TEXT, se creará una etiqueta de conjunto de caracteres.
parse_table
Especifica la tabla de análisis que se utilizará para escanear los caracteres que se convertirán en otros componentes de cadena compuesta.
parse_count
Especifica el número de entradas en parse_table.
call_data
Especifica los datos que se pasarán a los procedimientos de análisis.

DEVOLVER

Devuelve una nueva cadena compuesta. La función asigna espacio para almacenar la cadena compuesta devuelta. Cuando la aplicación ya no necesite la cadena compuesta devuelta, la aplicación debe llamar a XmStringFree.

RELACIONADO

XmString(3), XmStringFree(3), XmParseTable(3), XmParseMapping(3).
