XML::LibXML::Boolean(3) Documentación de Perl aportada por el usuario XML::LibXML::Boolean(3)

NOMBRE

XML::LibXML::Boolean - Valores booleanos verdadero/falso

DESCRIPCIÓN

Los objetos XML::LibXML::Boolean implementan objetos simples de verdadero/falso.

API

XML::LibXML::Boolean->Verdadero

Crea un nuevo objeto Booleano con un valor verdadero.

XML::LibXML::Boolean->Falso

Crea un nuevo objeto Booleano con un valor falso.

valor()

Devuelve verdadero o falso.

a_literal()

Devuelve la cadena "verdadero" o "falso".
