XmStringGetNextComponent(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringGetNextComponent(llamada a biblioteca) XmStringGetNextComponent(llamada a biblioteca)

NOMBRE

XmStringGetNextComponent — Una función de cadena compuesta que devuelve el tipo y el valor del siguiente componente en una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmStringComponentType XmStringGetNextComponent(
XmStringContext context,
char **text,
XmStringTag *tag,
XmStringDirection *direction,
XmStringComponentType *unknown_tag,
unsigned short *unknown_length,
unsigned char **unknown_value);

DESCRIPCIÓN

Esta función es obsoleta y existe para compatibilidad con versiones anteriores. Ha sido reemplazada por XmStringGetNextTriple. XmStringGetNextComponent devuelve el tipo y valor del siguiente componente en la cadena compuesta identificada por context. Los componentes se devuelven de uno en uno. Al regresar, solo algunos parámetros de salida serán válidos; cuáles se pueden determinar examinando el tipo de componente devuelto. La siguiente tabla describe los retornos válidos para cada tipo de componente.

Campos Válidos Tipo de Componente
tag XmSTRING_COMPONENT_LOCALE, XmSTRING_COMPONENT_TAG
text XmSTRING_COMPONENT_LOCALE_TEXT, XmSTRING_COMPONENT_TEXT, XmSTRING_COMPONENT_WIDECHAR_TEXT
direction XmSTRING_COMPONENT_DIRECTION
unknown_tag, unknown_length, unknown_value XmSTRING_COMPONENT_LAYOUT_POP, XmSTRING_COMPONENT_LAYOUT_PUSH, XmSTRING_COMPONENT_TAB, XmSTRING_COMPONENT_RENDITION_BEGIN, XmSTRING_COMPONENT_ RENDITION_END
ningún campo válido XmSTRING_COMPONENT_SEPARATOR, XmSTRING_COMPONENT_END, XmSTRING_COMPONENT_UNKNOWN

Tenga en cuenta que varios componentes producen un valor de retorno de XmSTRING_COMPONENT_UNKNOWN. Los datos devueltos por estos componentes se devuelven en los campos unknown_tag, unknown_length y unknown_value. Esta aparente inconsistencia está diseñada para acomodar aplicaciones antiguas que quizás no estén equipadas para manejar los tipos de componentes más nuevos de Motif versión 2.0 y posteriores. En consecuencia, no se recomienda el uso de este procedimiento. En su lugar, use el procedimiento XmStringGetNextTriple, que proporciona toda la funcionalidad de XmStringGetNextComponent y es totalmente compatible con los tipos de componentes más nuevos.

Si el valor de retorno de la función es XmSTRING_COMPONENT_LOCALE_TEXT o XmSTRING_COMPONENT_TEXT, la función asigna espacio para contener el text devuelto. Si el valor de retorno de la función es XmSTRING_COMPONENT_FONTLIST_ELEMENT_TAG o XmSTRING_COMPONENT_TAG, entonces la función asigna espacio para contener el tag devuelto. La aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XtFree.

context
Especifica la estructura de contexto de cadena que fue asignada por la función XmStringInitContext.
text
Especifica un puntero a una cadena terminada en NULL.
tag
Especifica un puntero al componente de etiqueta asociado con el texto. El valor XmFONTLIST_DEFAULT_TAG identifica un segmento de texto local.
direction
Especifica un puntero a la dirección del texto.
unknown_tag
Especifica un puntero a la etiqueta de un componente desconocido.
unknown_length
Especifica un puntero a la longitud de un componente desconocido.
unknown_value
Especifica un puntero al valor de un componente desconocido.

RETORNO

Devuelve el tipo de componente encontrado. Consulte la página de referencia de XmStringComponentType(3) para obtener una lista de tipos de componentes.

RELACIONADO

XmStringComponentType(3), XmStringCreate(3) y XmStringInitContext(3).
