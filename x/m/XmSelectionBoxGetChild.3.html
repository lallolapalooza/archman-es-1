NOMBRE

XmSelectionBoxGetChild — Una función de SelectionBox que se utiliza para acceder a un componente

SINOPSIS

#include <Xm/SelectioB.h>
Widget XmSelectionBoxGetChild(
Widget widget,
unsigned char child);

DESCRIPCIÓN

XmSelectionBoxGetChild se utiliza para acceder a un componente dentro de un SelectionBox. Los parámetros dados a la función son el widget SelectionBox y un valor que indica qué componente acceder.

NOTA: Esta rutina es obsoleta y existe por compatibilidad con versiones anteriores. En lugar de llamar a XmSelectionBoxGetChild, deberías llamar a XtNameToWidget como se describe en la página de referencia de XmSelectionBox(3).

widget
Especifica el ID del widget SelectionBox.
child
Especifica un componente dentro del SelectionBox. Los siguientes valores son legales para este parámetro:
•
XmDIALOG_APPLY_BUTTON
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_DEFAULT_BUTTON
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_LIST
•
XmDIALOG_LIST_LABEL
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_SELECTION_LABEL
•
XmDIALOG_SEPARATOR
•
XmDIALOG_TEXT
•
XmDIALOG_WORK_AREA

Para una definición completa de SelectionBox y sus recursos asociados, ver XmSelectionBox(3).

RETORNO

Devuelve el ID del widget del componente SelectionBox especificado. Una aplicación no debe asumir que el widget devuelto será de ninguna clase particular.

RELACIONADO

XmSelectionBox(3).
