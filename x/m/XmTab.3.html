NOMBRE

XmTab — Tipo de datos para una parada de tabulación

SINOPSIS

#include <Xm/Xm.h>
XmTab

DESCRIPCIÓN

XmTab es una estructura de datos que especifica una parada de tabulación para ser utilizada en la representación de un XmString que contiene componentes de tabulación. Un valor XmTab contiene un valor, un tipo de unidad, un modelo de desplazamiento (XmABSOLUTE o XmRELATIVE), un modelo de alineación (XmALIGNMENT_BEGINNING) y un carácter de punto decimal. La sintaxis del archivo de recursos para XmTab se especifica en la página de referencia de XmTabList.

RELACIONADO

XmTabCreate(3), XmTabFree(3), XmTabGetValues(3), XmTabList(3), y XmTabSetValue(3).
