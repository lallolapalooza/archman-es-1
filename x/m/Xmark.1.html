Xmark(1) Manual de comandos generales Xmark(1)

NOMBRE

Xmark - resume los resultados de x11perf

SINTAXIS

Xmark archivo_de_datos

DESCRIPCIÓN

Xmark es un script de shell que lee el archivo de datos indicado y compila un benchmark que escribe en la salida estándar. Escribe tres números:

Un número de rendimiento ponderado para los resultados de x11perf.

Un número de rendimiento ponderado para una SparcStation 1 estándar, con SunOS 4.1.2, X11R5 Xsun y un Buffer de fotogramas de color tonto CG3.

El Xmark, que es la relación de los dos números anteriores.

El archivo de datos debe ser un archivo ordinario, producido por x11perf de la siguiente manera:

x11perf -display pantalla -v1.3 -rop GXcopy GXxor -all > archivo_de_datos

Es posible ejecutar las pruebas GXcopy y GXxor por separado, siempre que se concatenen al mismo archivo de salida:

x11perf -display pantalla -v1.3 -rop GXcopy -all > archivo_de_datos
x11perf -display pantalla -v1.3 -rop GXxor -all >> archivo_de_datos
o 
x11perf -display pantalla -v1.3 -rop GXxor -all > archivo_de_datos
x11perf -display pantalla -v1.3 -rop GXcopy -all >> archivo_de_datos

ARCHIVOS

temp.$$
Archivo temporal creado en el directorio actual, eliminado después de su uso.

DIAGNÓSTICOS

Uso: Xmark archivo_de_datos
Xmark se invocó sin argumentos o con más de un argumento, o con opciones. Xmark no toma opciones.
Error: el archivo de datos no existe o no es ordinario.
Xmark no puede encontrar el archivo de datos nombrado en su línea de comandos, o el archivo de datos es un archivo especial como un directorio.
ADVERTENCIA: el archivo de datos contiene nnn, no 441 o 447 resultados 'trep';
El archivo nombrado en la línea de comandos no parece ser un archivo generado por x11perf de la manera esperada.
Diagnóstico: ERROR: suma de pesos =nnn, no igual a 4566.0;
Hay un error interno en Xmark.

VER TAMBIÉN

X(7), x11perf(1), x11perfcomp(1)
