DESCRIPCIÓN

La biblioteca de programación de aplicaciones para la Extensión de Doble Búfer, Búfer Múltiple y Estéreo X11 contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede configurar con XSetExtensionErrorHandler y funciona igual que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de búfer múltiple/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe sumarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe sumarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión principal y secundaria de la extensión. El valor de retorno es cero si ocurre un error o un valor distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" búferes con la acción de actualización y la sugerencia de actualización dadas y que se asocien con la ventana indicada. Se devuelve el número de búferes creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores Multibuffer.

XmbufDestroyBuffers destruye los búferes asociados con la ventana dada.

XmbufDisplayBuffers muestra los búferes indicados en sus respectivas ventanas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos búferes con la misma ventana o de lo contrario se generará un error de coincidencia (Match).

XmbufGetWindowAttributes obtiene los atributos de búfer múltiple que se aplican a todos los búferes asociados con la ventana dada. La lista de búferes devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de búfer múltiple que se aplican a todos los búferes asociados con la ventana dada. Actualmente, esto se limita a la sugerencia de actualización (update_hint).

XmbufGetBufferAttributes obtiene los atributos del búfer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del búfer indicado. Actualmente, esto se limita a la máscara de eventos (event_mask).

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Se devuelven los números de conjuntos de visualización y profundidades en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen las diversas visualizaciones y profundidades que se pueden utilizar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece según nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los identificadores de búfer para los búferes izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si hay instalado un manejador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en este display.

XmbufChangeWindowAttributes(3)

NAME

XmbufChangeWindowAttributes, XmbufGetWindowAttributes, XmbufGetScreenAttributes, XmbufGetWindowBufferAttributes, XmbufChangeWindowBufferAttributes, XmbufSetBackground, XmbufSetBorder, XmbufClearAttributes - multi-buffering extension window attributes

STRUCTURES

The following structures are defined for the multi-buffering extension.

typedef struct {
    int                event_mode;
    int                n_buffered_windows;
    int                n_available_buffers;
    int                n_min_buffers;
    int                n_max_buffers;
} XScreenAttributes;
typedef struct {
    int                buffer_mode;
    int                buffer_size;
    int                n_buffers;
} XWindowBufferAttributes;
typedef struct {
    unsigned long      background_pixmap;
    unsigned long      background_pixel;
    unsigned long      border_pixmap;
    unsigned long      border_pixel;
    int                bitwise_sybmol;
    int                event_mask;
    int                your_event_mask;
    int                do_not_propagate_mask;
    int                override_redirect;
    int                colormap;
    int                cursor;
} XSetWindowAttributes;

DESCRIPTION

The multi-buffering extension allows the application to manage multiple buffers for a window. This can be used to implement smooth animations, avoid flickering, etc.

The function XmbufChangeWindowAttributes changes the attributes for a given window w. The valuemask specifies which attributes are to be changed.

The function XmbufGetWindowAttributes retrieves the current attributes for a given window w.

The function XmbufGetScreenAttributes retrieves the multi-buffering capabilities for the given screen screen.

The function XmbufGetWindowBufferAttributes retrieves the current buffer attributes for a given window w.

The function XmbufChangeWindowBufferAttributes changes the buffer attributes for a given window w. The valuemask specifies which attributes are to be changed.

The function XmbufSetBackground sets the background for the window. The option can be XmbufBackgroundPixmap or XmbufBackgroundPixel.

The function XmbufSetBorder sets the border for the window. The option can be XmbufBorderPixmap or XmbufBorderPixel.

The function XmbufClearAttributes clears all multi-buffering related attributes for the window.

PREDEFINED VALUES

The following values can be used for the valuemask parameters:

XmbufBackgroundPixmap
Use the background_pixmap field.
XmbufBackgroundPixel
Use the background_pixel field.
XmbufBorderPixmap
Use the border_pixmap field.
XmbufBorderPixel
Use the border_pixel field.
XmbufEventMode
Use the event_mode field in XScreenAttributes.
XmbufBufferMode
Use the buffer_mode field in XWindowBufferAttributes.
XmbufBufferSize
Use the buffer_size field in XWindowBufferAttributes.
XmbufNBuffers
Use the n_buffers field in XWindowBufferAttributes.

The following event masks are defined:

MultibufferUpdateNotifyMask
MultibufferClobberNotify
MultibufferUpdateNotify
MultibufferNumberEvents
MultibufferBadBuffer
MultibufferNumberErrors

DESCRIPCIÓN

La extensión de multi-buffering permite a la aplicación gestionar múltiples buffers para una ventana. Esto se puede usar para implementar animaciones fluidas, evitar parpadeos, etc.

La función XmbufChangeWindowAttributes cambia los atributos para una ventana dada w. La máscara valuemask especifica qué atributos se van a cambiar.

La función XmbufGetWindowAttributes recupera los atributos actuales para una ventana dada w.

La función XmbufSetBorder establece el borde para la ventana. La option puede ser XmbufBorderPixmap o XmbufBorderPixel.

La función XmbufClearAttributes borra todos los atributos relacionados con el multi-buffering para la ventana.
