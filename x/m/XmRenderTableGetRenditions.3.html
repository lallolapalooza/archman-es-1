NOMBRE

XmRenderTableGetRenditions — Una función de conveniencia que empareja etiquetas de renderizado

SINOPSIS

#include <Xm/Xm.h>
XmRendition *XmRenderTableGetRenditions(
XmRenderTable table,
XmStringTag *tags,
Cardinal tag_count);

DESCRIPCIÓN

XmRenderTableGetRenditions busca en table y devuelve una matriz de copias de las renderizaciones cuyas etiquetas XmNtag coinciden con una etiqueta en tags. Si no hay coincidencias de renderizaciones, se devuelve NULL. El tamaño de la matriz devuelta es tag_count. La etiqueta XmNtag de cada renderización coincidirá con la etiqueta correspondiente en tags. Si no se encuentra una coincidencia para una etiqueta en particular, la ranura correspondiente en el valor de retorno será NULL.

Es responsabilidad del llamador llamar a la función XmRenditionFree para liberar las nuevas renderizaciones y a la función XtFree para liberar la matriz.

table
Especifica la tabla que contiene las renderizaciones a buscar.
tags
Especifica las etiquetas a buscar.
tag_count
Especifica el número de etiquetas en tags.

DEVOLUCIÓN

Devuelve NULL si no hay coincidencias; de lo contrario, esta función devuelve una matriz de nuevas XmRenditions.

RELACIONADO

XmRenderTableGetRendition(3), XmRenderTableGetTags(3) y XmRendition(3).
