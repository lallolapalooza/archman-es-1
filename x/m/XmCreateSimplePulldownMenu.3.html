NOMBRE

XmCreateSimplePulldownMenu — Función de conveniencia para la creación de widgets RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmCreateSimplePulldownMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateSimplePulldownMenu crea una instancia de un widget RowColumn de tipo XmMENU_PULLDOWN y devuelve el ID del widget asociado.

Esta rutina crea un panel de menú desplegable y sus botones hijos. El nombre de cada botón es button_n, donde n es un entero de 0 (cero) al número de botones del menú menos 1. El nombre de cada separador es separator_n, donde n es un entero de 0 (cero) al número de separadores del menú menos 1. El nombre de cada título es label_n, donde n es un entero de 0 (cero) al número de títulos del menú menos 1. Los botones, separadores y títulos se nombran y crean en el orden en que se especifican en los recursos de creación de menú simple de RowColumn proporcionados en la lista de argumentos.

parent
Especifica el ID del widget padre de MenuShell.
name
Especifica el nombre del widget creado.
arglist
Especifica la lista de argumentos.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Existen varios recursos específicamente para su uso con esta y otras rutinas de creación de menú simple. Los únicos tipos de botón permitidos en el recurso XmNbuttonType son XmCASCADEBUTTON, XmPUSHBUTTON, XmRADIOBUTTON, XmCHECKBUTTON, XmTITLE, XmSEPARATOR y XmDOUBLE_SEPARATOR. Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.

RELACIONADO

XmCreatePulldownMenu(3), XmCreateRowColumn(3), XmRowColumn(3) y XmVaCreateSimplePulldownMenu(3).
