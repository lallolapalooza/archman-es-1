NOMBRE

XmTextFieldSetInsertionPosition — Una función de TextField que establece la posición del cursor de inserción

SINOPSIS

#include <Xm/TextF.h>
void XmTextFieldSetInsertionPosition(
Widget widget,
XmTextPosition position);

DESCRIPCIÓN

XmTextFieldSetInsertionPosition establece la posición del cursor de inserción del widget TextField. Esta rutina también llama a los callbacks XmNmotionVerifyCallback del widget si cambia la posición del cursor de inserción.

widget
Especifica el ID del widget TextField
position
Especifica la posición del cursor de inserción. Este es un número entero de caracteres desde el principio del búfer de texto. La primera posición de caracter es 0 (cero).

Para una definición completa de TextField y sus recursos asociados, consulte XmTextField(3).
