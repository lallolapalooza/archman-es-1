NOMBRE

XML::Smart::Tutorial - Tutorial y ejemplos para XML::Smart.

SINOPSIS

Este documento es un tutorial para XML::Smart y muestra algunos ejemplos de cosas habituales.

Trabajando con contenidos:

En XML::Smart la clave CONTENT está reservada y no debe usarse directamente, ya que XML::Smart se encargará de la conversión de argumentos a contenidos de nodos, incluyendo múltiples contenidos automáticamente.

¿Qué sucede cuando estableces un valor:

$xml->{root}{foo} = 'valor simple' ;

Aquí foo será un argumento/valor de atributo normal, y generará estos datos XML:

<root foo="valor simple"/>

Pero si insertas alguna etiqueta o líneas en los valores, por defecto XML::Smart lo convertirá en un contenido de nodo:

$xml->{root}{foo} = "línea0\nlien1\nlínea2\n" ;

Y generará estos datos XML:

<root>
<foo>línea0
lien1
línea2
</foo>
</root>

Pero, ¿qué puedes hacer si quieres forzar algún tipo, por ejemplo, tener un contenido de nodo con un valor simple?

$xml->{root}{foo} = 'valor simple' ;
$xml->{root}{foo}->set_node(1) ;

Y generará estos datos XML:

<root>
  <foo>valor simple</foo>
</root>

Contenidos múltiples:

Cuando tienes contenido/datos interpolados, necesitas trabajar de manera diferente. Digamos que cargas estos datos XML:

<root>
contenido0
<tag1 arg="1"/>
contenido1
</root>

Si accedes directamente a la clave root como cadena, obtendrás todas las partes de contenido agrupadas. Por lo tanto, este código:

my $xml = new XML::Smart(q`
<root>
contenido0
<tag1 arg="1"/>
contenido1
</root>
`,'smart') ;

print "#$xml->{root}#" ;

Imprimirá esto:

#
contenido0

contenido1
#

Para acceder a cada parte del contenido de forma independiente, debes usar un array que reciba el método content():

my @content = $xml->{root}->content ;

print "#$content[0]#\n" ;

Y esto imprimirá esto:

#
contenido0
#

Ahora, para establecer los valores de contenido múltiple, debes usar el método content() con 2 argumentos:

$xml->{root}->content(0,'nuevo contenido') ;

Y ahora los datos XML producidos serán:

<root>nuevo contenido<tag1 arg="1"/>
contenido1
</root>

Si usas el método content() con solo un argumento, eliminará todos los contenidos múltiples y establecerá el nuevo valor en el lugar del primer contenido.

Estableciendo el Parser XML.

Por defecto, XML::Smart usará XML::Parser o XML::Smart::Parser (en este orden de preferencia) para cargar datos XML.

Para forzar o definir tú mismo el parser, puedes usar la opción del segundo argumento al crear un objeto XML::Smart:

my $xml = new XML::Smart( 'alguno.xml' , 'XML::Parser' ) ;

## y

my $xml = new XML::Smart( 'alguno.xml' , 'XML::Smart::Parser' ) ;

XML::Smart también tiene un parser extra, XML::Smart::HTMLParser, que puede usarse para cargar HTML como XML, o para cargar XML salvaje:

my $xml = new XML::Smart( 'alguno.xml' , 'XML::Smart::HTMLParser' ) ;

Alias para las opciones del parser:

SMART|REGEXP   => XML::Smart::Parser
HTML           => XML::Smart::HTMLParser

Por lo tanto, puedes usarlo como:

my $xml = new XML::Smart( 'alguno.xml' , 'smart' ) ;
my $xml = new XML::Smart( 'alguno.xml' , 'html' ) ;

Personalizando el Parser.

Puedes personalizar la forma en que el parser tratará los datos XML:

Forzando nodos/etiquetas y argumentos/atributos a minúsculas o mayúsculas:

## Para minúsculas:
my $xml = new XML::Smart( 'alguno.xml' ,
lowtag => 1 ,
lowarg => 1 ,
) ;

## Para mayúsculas:

my $xml = new XML::Smart( 'alguno.xml' ,
upertag => 1 ,
uperarg => 1 ,
) ;

Cargando argumentos sin valores (flags) como un booleano VERDADERO:

** Nota, esta opción solo funcionará cuando el XML sea parseado por XML::Smart::HTMLParser, ¡ya que solo este acepta argumentos sin valores!

my $xml = new XML::Smart(
'<root><foo arg1="" flag></root>' ,
'XML::Smart::HTMLParser' ,
arg_single => 1 ,
) ;

Este es el árbol del ejemplo anterior:

'root' => {
            'foo' => {
                       'flag' => 1,
                       'arg1' => ''
                     },
          },

Personalizando los eventos del parseo:

XML::Smart puede redirigir el proceso de parseo a funciones personalizadas:

my $xml = XML::Smart->new( 'alguno.xml' ,
on_start => \&on_start ,
on_char  => \&on_char ,
on_end   => \&on_end ,
) ;

sub on_start {
  my ( $tag , $pointer , $pointer_back ) = @_ ;
  $pointer->{$tag}{type_user} = 1 if $tag =~ /(?:name|age)/ ;
}
sub on_char {
  my ( $tag , $pointer , $pointer_back , $content) = @_ ;
  $$content =~ s/\s+/ /gs ;
}

sub on_end {
  my ( $tag , $pointer , $pointer_back ) = @_ ;
  $pointer->{$tag}{type_extra} = 1 if $tag =~ /(?:more|tel|address)/ ;
}
