NOMBRE

XmTranslateKey — El traductor predeterminado de código de tecla a keysym

SINOPSIS

#include <Xm/Xm.h>
void XmTranslateKey(
Display *display,
KeyCode keycode,
Modifiers modifiers,
Modifiers *modifiers_return,
KeySym *keysym_return);

DESCRIPCIÓN

XmTranslateKey es el procedimiento de traducción predeterminado XtKeyProc para aplicaciones Motif. La función toma un código de tecla y modificadores y devuelve el keysym correspondiente.

XmTranslateKey cumple dos propósitos principales: habilitar nuevos traductores con funcionalidad ampliada para obtener la traducción de código de tecla a keysym predeterminada de Motif además de lo que sea que añadan, y reinstalar el traductor predeterminado. Esta función permite usar los keysyms definidos por las vinculaciones virtuales de Motif cuando una aplicación requiere que se instale su propio XtKeyProc.

display
Especifica la pantalla de la que proviene el código de tecla
keycode
Especifica el código de tecla a traducir
modifiers
Especifica las teclas modificadoras que se aplicarán al código de tecla
modifiers_return
Especifica una máscara de las teclas modificadoras realmente utilizadas para generar el keysym (un AND de modifiers y cualquier modificador predeterminado aplicado por el traductor registrado actualmente)
keysym_return
Especifica un puntero al keysym resultante
