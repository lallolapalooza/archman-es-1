NOMBRE

XmRendition — El registro de Rendition

SINOPSIS

#include <Xm/Xm.h>
XmRendition

DESCRIPCIÓN

XmRendition es un pseudo widget utilizado para la representación de XmStrings. XmRendition tiene dos partes: XmStringTag e información de representación. La parte XmStringTag puede coincidir con un XmStringTag asociado a un componente LOCALE, CHARSET o RENDITION[BEGIN|END] dentro de XmString. La información de representación contiene información sobre la fuente o conjunto de fuentes, colores, tabulaciones y líneas que se utilizarán en la representación de un componente de texto.

Si un recurso en una rendition no está especificado, usualmente al establecerlo en XmAS_IS o XmUNSPECIFIED_PIXEL, entonces el valor que se utilizará para ese recurso es el valor de la rendition inmediatamente anterior en XmString. Si ese valor no está especificado, entonces se usará el valor anterior, y así sucesivamente. Si ninguna rendition especifica un valor para un recurso, se utilizará un valor predeterminado.

Clases

XmRendition no hereda de ninguna clase de widget.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. Para referirse a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XmRenditionUpdate (S), recuperar usando XmRenditionRetrieve (G), o no es aplicable (N/A).

Especifica el color de dibujo de fondo. Un valor de XmUNSPECIFIED_PIXEL indica que el fondo no está especificado para esta rendition.
XmNfont
Especifica la fuente o conjunto de fuentes real que será utilizada por esta rendition. Establecer este recurso forzará que XmNloadModel sea XmLOAD_IMMEDIATE. DESCRIPCIÓN

XmNfontName
Especifica el nombre de una fuente o una lista de nombres base de fuentes. Esta cadena de recursos se pasa directamente a la función XLib XLoadQueryFont o XLoadFont. Si tanto XmNfontName como XmNfont se especifican en un archivo de recursos, la especificación XmNfont tendrá prioridad.
XmNfontType
Especifica si el recurso XmNfontName se refiere a un nombre de fuente o a una lista de nombres base de fuentes. Los valores válidos son XmFONT_IS_FONT y XmFONT_IS_FONTSET.
XmNrenditionForeground
Especifica el color de dibujo de primer plano. Un valor de XmUNSPECIFIED_PIXEL indica que el primer plano no está especificado para esta rendition.
XmNloadModel
Especifica si la fuente o el fontset especificado por XmNfontName debe cargarse cuando se crea la rendition (XmLOAD_IMMEDIATE) o solo cuando la fuente es necesaria para renderizar un segmento de XmString (XmLOAD_DEFERRED). Tenga en cuenta que especificar XmLOAD_IMMEDIATE para XmNloadModel solo es válido si se especifica XmNfontName, en cuyo caso la fuente especificada se cargará en la creación, o si se especifica XmNfont, en cuyo caso la fuente ya está cargada. XmLOAD_DEFERRED solo es válido cuando se especifica XmNfontName.
XmNstrikethruType
Especifica el tipo de línea que se utilizará para tachar un segmento de texto. Los valores válidos son XmNO_LINE, XmSINGLE_LINE, XmDOUBLE_LINE, XmSINGLE_DASHED_LINE y XmDOUBLE_DASHED_LINE. Un valor de XmAS_IS indica que el tipo de tachado no está especificado para esta rendition.
XmNtabList
Especifica la lista de tabulaciones que se utilizará al renderizar cadenas compuestas que contienen componentes de tabulación.
XmNtag
Especifica la cadena de etiqueta que se utilizará para hacer coincidir las rendiciones con otras rendiciones o con componentes XmStringTag en XmStrings. Este recurso siempre debe especificarse. Es decir, NULL no es un valor legal, pero la cadena vacía sí lo es. Este recurso se establece automáticamente con el valor del parámetro tag en la llamada XmRenditionCreate.
XmNunderlineType
Especifica el tipo de línea que se utilizará para subrayar un segmento de texto. Los valores válidos son XmNO_LINE, XmSINGLE_LINE, XmDOUBLE_LINE, XmSINGLE_DASHED_LINE y XmDOUBLE_DASHED_LINE. Un valor de XmAS_IS indica que el tipo de subrayado no está especificado para esta rendition.

RELACIONADO

XmRenditionCreate(3), XmRenditionFree(3), XmRenditionRetrieve(3), XmRenditionUpdate(3), y XmString(3).
