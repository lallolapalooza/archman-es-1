NOMBRE

XmVaCreateButtonBox, XmVaCreateManagedButtonBox — Funciones de creación de conveniencia para el widget ButtonBox.

SINOPSIS

#include <Xm/ButtonBox.h>
Widget XmVaCreateButtonBox(
Widget parent,
String name,
...);
Widget XmVaCreateManagedButtonBox(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget ButtonBox y devuelven el ID del widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos variables (varargs) de ANSI C.

La función XmVaCreateButtonBox es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreateManagedButtonBox es una rutina de conveniencia que llama a XtCreateManagedWidget.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de ButtonBox y sus recursos asociados, consulte XmButtonBox(3).

RETORNO

Devuelve el ID del widget ButtonBox.

RELACIONADO

XmButtonBox(3), XmCreateButtonBox(3), XtCreateWidget(3) y XtCreateManagedWidget(3).
