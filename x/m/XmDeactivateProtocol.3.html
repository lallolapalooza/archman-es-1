NOMBRE

XmDeactivateProtocol — Una función de VendorShell que desactiva un protocolo sin eliminarlo

SINOPSIS

#include <Xm/Xm.h>
#include <Xm/Protocols.h>
void XmDeactivateProtocol(
Widget shell,
Atom property,
Atom protocol);

DESCRIPCIÓN

XmDeactivateProtocol desactiva un protocolo sin eliminarlo. Actualiza los manejadores y la property si la shell está realizada. A veces es útil permitir que la información de estado de un protocolo (listas de devolución de llamada, etc.) persista, aunque el cliente elija renunciar temporalmente a la interacción. El uso principal de esta capacidad es poner en gris/no poner en gris las entradas f.send_msg en el menú del sistema MWM. Para soportar esta capacidad, se permite que el protocol esté en uno de dos estados: activo o inactivo. Si el protocol está activo y la shell está realizada, la property contiene el Atom del protocol. Si el protocol está inactivo, el Atom no está presente en la property.

XmDeactivateWMProtocol es una interfaz de conveniencia. Llama a XmDeactivateProtocol con el valor de la propiedad establecido en el átomo devuelto por la internación de WM_PROTOCOLS.

shell
Especifica el widget con el que se asocia la propiedad del protocolo
property
Especifica la propiedad del protocolo
protocol
Especifica el átomo del protocolo

Para obtener una definición completa de VendorShell y sus recursos asociados, consulte VendorShell(3).

RELACIONADO

mwm(1), VendorShell(3), XmActivateProtocol(3), XmDeactivateWMProtocol(3), y XmInternAtom(3).
