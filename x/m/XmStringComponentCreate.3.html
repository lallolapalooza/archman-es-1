NOMBRE

XmStringComponentCreate — Una función de cadena compuesta que crea componentes arbitrarios

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringComponentCreate(
XmStringComponentType c_type,
unsigned int length,
XtPointer value);

DESCRIPCIÓN

XmStringComponentCreate crea un nuevo componente XmString de tipo c_type, que contiene value. Si value no es válido para el tipo de componente particular, esta función falla y devuelve NULL.

c_type
Especifica el tipo de componente a crear.
length
Especifica la longitud en bytes de value. Tenga en cuenta que esta debe ser exactamente la longitud de la cadena value, sin incluir ningún carácter nulo de terminación.
value
Especifica el valor a utilizar en la creación del componente.

Consulte la página de referencia de XmStringComponentType(3) para obtener una lista de los tipos de componentes posibles de XmString.

RETORNO

Si value no es válido para c_type, falla y devuelve NULL. De lo contrario, esta función devuelve una nueva cadena compuesta. Cuando la aplicación ya no necesite la cadena compuesta devuelta, la aplicación debe llamar a XmStringFree.

RELACIONADO

XmString(3), XmStringGetNextTriple, XmStringComponentType, y XmStringFree(3).
