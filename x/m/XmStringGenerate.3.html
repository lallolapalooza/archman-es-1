XmStringGenerate(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringGenerate(llamada de biblioteca) XmStringGenerate(llamada de biblioteca)

NOMBRE

XmStringGenerate — Una función de conveniencia que genera una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringGenerate(
XtPointer text,
XmStringTag tag,
XmTextType type,
XmStringTag rendition);

DESCRIPCIÓN

XmStringGenerate llama a la función XmStringParseText con una tabla de análisis predeterminada de entradas que consisten en '0&', que se mapea a Separador, y '', que se mapea a Tabulador. Los componentes RENDITION_BEGIN y RENDITION_END coincidentes que contienen rendition se colocan alrededor del XmString resultante.

text
Especifica una cadena terminada en NULL que contiene caracteres de un tipo determinado por type.
tag
Especifica la etiqueta a utilizar en la creación del resultado. El tipo de etiqueta creada (charset o locale) depende del tipo de texto y del valor proporcionado. Si se especifica un valor NULL, y type indica que se debe crear una etiqueta de conjunto de caracteres (charset), entonces la etiqueta tendrá el valor de XmFONTLIST_DEFAULT_TAG. Si tag es NULL, y type indica una etiqueta de configuración regional (locale), entonces la etiqueta tendrá el valor de _MOTIF_DEFAULT_LOCALE.
type
Especifica el tipo de texto a pasar y el tipo de etiqueta. Si se debe crear una etiqueta de configuración regional (locale), entonces type tiene un valor de XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT. Si se debe crear un conjunto de caracteres (charset), type tiene un valor de XmCHARSET_TEXT.
rendition
Especifica la etiqueta de rendition a utilizar en un componente XmSTRING_COMPONENT_RENDITION_BEGIN que iniciará la cadena devuelta y en un componente XmSTRING_COMPONENT_RENDITION_END que la finalizará. Si rendition es NULL, no se colocará ninguna etiqueta de rendition.

RETORNO

Devuelve una nueva cadena compuesta. La función asignará espacio para contener la cadena compuesta devuelta. Cuando la aplicación ya no necesite la cadena compuesta devuelta, la aplicación deberá llamar a XmStringFree.

RELACIONADO

XmString(3) y XmStringFree(3).
