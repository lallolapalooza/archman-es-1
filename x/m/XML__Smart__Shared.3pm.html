NOMBRE

XML::Smart::Shared - Funciones y variables compartidas para XML::Smart.

VERSIÓN

Versión 0.01

SINOPSIS

Funciones y variables compartidas para XML::Smart.

EXPORTAR

Todas las funciones se exportan a través de export_ok

VARIABLES GLOBALES

our ( $SIG_WARN , $SIG_DIE ) ;

SUBRUTINAS/MÉTODOS

_unset_sig_warn

Esta función guarda __WARN__ actual y lo establece a none.

_reset_sig_warn

Esta función reemplaza __WARN__ con el valor guardado por _unset_sig_warn

_unset_sig_die

Esta función guarda __DIE__ actual y lo establece a none.

_reset_sig_die

Esta función reemplaza __DIE__ con el valor guardado por _unset_sig_warn
