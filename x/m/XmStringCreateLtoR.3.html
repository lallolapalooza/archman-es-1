NOMBRE

XmStringCreateLtoR — Una función de cadena compuesta que crea una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringCreateLtoR(
char *text,
char *tag);

DESCRIPCIÓN

Esta función es obsoleta y existe para compatibilidad con versiones anteriores. Está reemplazada por XmStringGenerate. XmStringCreateLtoR crea una cadena compuesta con dos componentes: texto y un componente de etiqueta. Esta función busca caracteres de \n en el texto. Cuando se encuentra uno, el texto hasta ese punto se coloca en un segmento seguido de un componente separador. No se añade un componente separador final al final de la cadena compuesta. El componente de dirección por defecto es de izquierda a derecha. Esta función asume que la codificación es de un solo byte en lugar de multibyte.

La función asignará espacio para contener la cadena compuesta devuelta. La aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmStringFree.

text
Especifica una cadena terminada en NULL para ser utilizada como el componente de texto de la cadena compuesta.
tag
Especifica el componente de etiqueta que se asociará con el texto dado. El valor XmFONTLIST_DEFAULT_TAG se conserva para compatibilidad con versiones anteriores.

RETORNO

Devuelve una nueva cadena compuesta.

RELACIONADO

XmStringCreate(3) y XmStringGenerate(3).
