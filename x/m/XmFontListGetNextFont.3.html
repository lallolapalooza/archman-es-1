NOMBRE

XmFontListGetNextFont — Una función de lista de fuentes que permite a las aplicaciones acceder a las fuentes y conjuntos de caracteres en una lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
Boolean XmFontListGetNextFont(
XmFontContext context,
XmStringCharSet *charset,
XFontStruct **font);

DESCRIPCIÓN

XmFontListGetNextFont accede al conjunto de caracteres y la fuente para la siguiente entrada de la lista de fuentes. La aplicación utiliza primero la rutina XmFontListInitFontContext para crear un contexto de lista de fuentes. La aplicación luego llama repetidamente a XmFontListGetNextFont con el mismo contexto. Cada llamada sucesiva accede al siguiente elemento de la lista de fuentes. Cuando termina, la aplicación llama a XmFontListFreeFontContext para liberar el contexto de lista de fuentes asignado.

Esta rutina asigna memoria para la cadena del conjunto de caracteres que debe ser liberada por la aplicación. La función asigna memoria para charset. La aplicación es responsable de administrar la memoria asignada. La aplicación puede recuperar la memoria asignada llamando a XtFree.

Esta función está obsoleta y existe por compatibilidad con versiones anteriores. Ha sido reemplazada por XmFontListNextEntry. Si a XmFontListGetNextFont se le pasa un contexto que contiene una entrada de conjunto de fuentes, devolverá la primera fuente del conjunto de fuentes. La siguiente llamada a la función pasará a la siguiente entrada en la lista de fuentes.

context
Especifica el contexto de la lista de fuentes.
charset
Especifica un puntero a una cadena de conjunto de caracteres; la rutina devuelve el conjunto de caracteres del elemento actual de la lista de fuentes.
font
Especifica un puntero a un puntero a una estructura de fuente; la rutina devuelve la fuente del elemento actual de la lista de fuentes.

RETORNO

Devuelve True si los valores devueltos son válidos; de lo contrario, devuelve False.

RELACIONADO

XmFontList(3) y XmFontListNextEntry(3).
