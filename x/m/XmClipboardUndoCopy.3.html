NOMBRE

XmClipboardUndoCopy — Una función del portapapeles que elimina el último elemento colocado en el portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardUndoCopy (display, window)
        Display * display;
        Window  window;
(void)

DESCRIPCIÓN

XmClipboardUndoCopy elimina el último elemento colocado en el portapapeles si el elemento fue colocado allí por una aplicación con los argumentos display y window pasados. Cualquier elemento de datos eliminado del portapapeles por la llamada original a XmClipboardCopy se restaura. Si los IDs de display o window no coinciden con el último elemento copiado, no se toma ninguna medida y esta función no tiene ningún efecto.

display
Especifica un puntero a la estructura Display que fue devuelta en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debería pasar el mismo ID de ventana a cada función del portapapeles que llame.

RETORNO

XmClipboardSuccess
La función fue exitosa.
XmClipboardLocked
La función falló porque el portapapeles fue bloqueado por otra aplicación. La aplicación puede continuar llamando a la función de nuevo con los mismos parámetros hasta que el bloqueo desaparezca. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentándolo o abandonar la operación.

RELACIONADO

XmClipboardLock(3) y XmClipboardStartCopy(3).
