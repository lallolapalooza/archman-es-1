XmVaCreateDropDown(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmVaCreateDropDown(library call) XmVaCreateDropDown(library call)

NOMBRE

XmVaCreateDropDown, XmVaCreateManagedDropDown — Funciones de creación de conveniencia para el widget DropDown.

SINOPSIS

#include <Xm/DropDown.h>
Widget XmVaCreateDropDown(
Widget parent,
String name,
...);
Widget XmVaCreateManagedDropDown(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget DropDown y devuelven el ID del widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos variables (varargs) de ANSI C.

La función XmVaCreateDropDown es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreateManagedDropDown es una rutina de conveniencia que llama a XtCreateManagedWidget.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de DropDown y sus recursos asociados, consulte XmDropDown(3).

RETORNO

Devuelve el ID del widget DropDown.

RELACIONADO

XmDropDown(3), XmCreateDropDown(3), XtCreateWidget(3) y XtCreateManagedWidget(3).
