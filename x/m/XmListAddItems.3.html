NOMBRE

XmListAddItems — Una función de Lista que añade elementos a la lista

SINOPSIS

#include <Xm/List.h>
void XmListAddItems(
Widget widget,
XmString *items,
int item_count,
int position);

DESCRIPCIÓN

XmListAddItems añade los elementos especificados a la lista en la posición dada. Los primeros item_count elementos del array items se añaden a la lista. Cuando los elementos se insertan en la lista, se comparan con la lista actual XmNselectedItems. Si alguno de los nuevos elementos coincide con un elemento de la lista seleccionada, aparecerá seleccionado.

widget
Especifica el ID de la Lista a la que se añade un elemento.
items
Especifica un puntero a los elementos que se van a añadir a la lista.
item_count
Especifica el número de elementos en items. Este número debe ser no negativo.
position
Especifica la posición del primer nuevo elemento en la lista. Un valor de 1 hace que el primer nuevo elemento sea el primer elemento de la lista; un valor de 2 lo hace el segundo elemento; y así sucesivamente. Un valor de 0 (cero) hace que el primer nuevo elemento siga al último elemento de la lista.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).
