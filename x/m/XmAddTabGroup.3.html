NOMBRE

XmAddTabGroup — Una función que añade un widget gestor o primitivo a la lista de grupos de pestañas

SINOPSIS

#include <Xm/Xm.h>
void XmAddTabGroup(
Widget tab_group);

DESCRIPCIÓN

Esta función está obsoleta y su comportamiento se reemplaza estableciendo XmNnavigationType a XmEXCLUSIVE_TAB_GROUP. Cuando se utiliza el teclado para recorrer una jerarquía de widgets, los widgets primitivos o gestores se agrupan en lo que se conoce como grupos de pestañas. Cualquier widget gestor o primitivo puede ser un grupo de pestañas. Dentro de un grupo de pestañas, mueva el foco al siguiente widget del grupo de pestañas utilizando las teclas de flecha. Para moverse a otro grupo de pestañas, utilice KNextField o KPrevField.

Los grupos de pestañas se especifican normalmente mediante el recurso XmNnavigationType. Se llama a XmAddTabGroup para controlar el orden de recorrido de los grupos de pestañas. El widget especificado por tab_group se añade a la lista de grupos de pestañas que se recorrerán, y el XmNnavigationType del widget se establece en XmEXCLUSIVE_TAB_GROUP.

tab_group
Especifica el ID del widget gestor o primitivo.

RELACIONADOS

XmManager(3), XmGetTabGroup(3), XmPrimitive(3), y XmRemoveTabGroup(3).
