NOMBRE

XmColumn — La clase de widget XmColumn

SINOPSIS

#include <Xm/Column.h>

DESCRIPCIÓN

XmColumn muestra sus hijos apilados en una columna, cada uno con una etiqueta opcional asociada: las etiquetas aparecen en una columna y los hijos en otra. Esto es útil para mostrar, por ejemplo, campos de entrada de datos etiquetados. También puede mostrar todos los pares etiqueta-hijo en una orientación horizontal. Este widget ofrece varios recursos de restricción que permiten la especificación de características de la etiqueta, como mostrar texto o un pixmap, alineación del texto, fuente a utilizar, y demás. También ofrece varios recursos para establecer valores predeterminados para los hijos que no especifican valores concretos.

CLASES

XmColumn hereda el comportamiento y los recursos de Core, Composite, Constraint, XmManager y XmBulletinBoard.

El puntero de clase es xmColumnWidgetClass.

El nombre de la clase es XmColumn.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes (en minúscula o mayúscula, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado puede ser utilizado en el momento de la creación (C), o no es aplicable (N/A).

XmColumn(3)

NAME

XmColumn — A manager widget that arranges its children into columns.

SYNOPSIS

DESCRIPTION

The XmColumn widget is a subclass of XmManager. It arranges its children into one or more columns. The widget is intended to be used as a container for other widgets, which are called children. The XmColumn widget defines a default arrangement for its children and can be configured to control the arrangement of the children.

The XmColumn widget arranges its children within a single column unless the XmNcolumns resource is set to a value greater than 1. When XmNcolumns is set to a value greater than 1, the children are arranged into the specified number of columns. The children are laid out from left to right, top to bottom.

XmColumn supports the XmNentryAlignment resource, which controls the alignment of entries within a column. The alignment can be set to XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER, or XmALIGNMENT_END. The default value is XmALIGNMENT_UNSPECIFIED, which means that the alignment is inherited from the parent widget.

XmColumn also supports the XmNentrySpacing resource, which specifies the spacing between entries in a column. The spacing is specified in screen units.

XmColumn also supports the XmNentryShadowThickness resource, which specifies the shadow thickness for each entry in the column. The shadow thickness is specified in screen units.

The XmColumn widget supports the constraint resources defined by XmColumnConstraintResourceSet. These resources are derived from those supported by XmLabel; see the manual page for XmLabel for valid values and usage.
