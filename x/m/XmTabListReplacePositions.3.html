NOMBRE

XmTabListReplacePositions — Una función de conveniencia que crea una nueva lista de pestañas con pestañas de reemplazo

SINOPSIS

#include <Xm/Xm.h>
XmTabList XmTabListReplacePositions(
XmTabList oldlist,
Cardinal *position_list,
XmTab *tabs,
Cardinal tab_count);

DESCRIPCIÓN

XmTabListReplacePositions crea una nueva lista de pestañas que contiene el contenido de oldlist, pero con las pestañas en las posiciones de position_list reemplazadas con copias de las pestañas correspondientes en tabs. Se muestra un mensaje de advertencia si una posición especificada no es válida; por ejemplo, si el valor es un número mayor que el número de pestañas en la lista de pestañas.

Esta función libera la lista de pestañas original después de extraer la información requerida. Es responsabilidad del llamador liberar las pestañas en tabs utilizando la función XmTabFree.

oldlist
Especifica la lista de pestañas. La función libera la lista de pestañas después de extraer la información requerida.
position_list
Especifica una matriz de posiciones de las pestañas a reemplazar. La posición de la primera pestaña es 0 (cero), la posición de la segunda pestaña es 1, y así sucesivamente.
tabs
Especifica una matriz de las pestañas de reemplazo.
tab_count
Especifica el número de elementos en position_list y tabs.

RETORNO

Si tabs, oldlist o position_list son NULL, o tab_count es 0 (cero), devuelve oldlist. De lo contrario, esta función devuelve la nueva lista de pestañas. La función asigna espacio para contener la lista de pestañas devuelta. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmTabListFree.
