NOMBRE

XmAddProtocolCallback — Una función de VendorShell que añade callbacks de cliente para un protocolo

SINOPSIS

#include <Xm/Protocols.h>
void XmAddProtocolCallback(
Widget shell,
Atom property,
Atom protocol,
XtCallbackProc callback,
XtPointer closure);

DESCRIPCIÓN

XmAddProtocolCallback añade callbacks de cliente para un protocolo. Comprueba si el protocolo está registrado y, si no lo está, llama a XmAddProtocols. Luego añade el callback a la lista interna. Estos callbacks se llaman cuando se recibe el mensaje de cliente correspondiente.

XmAddWMProtocolCallback es una interfaz de conveniencia. Llama a XmAddProtocolCallback con el valor de la propiedad establecido en el átomo devuelto por la internación de WM_PROTOCOLS.

shell
Especifica el widget con el que se asocia la propiedad del protocolo
property
Especifica la propiedad del protocolo
protocol
Especifica el Atom del protocolo
callback
Especifica el procedimiento a llamar cuando se recibe un mensaje de protocolo
closure
Especifica los datos del cliente que se pasarán al callback cuando se invoque

Para una definición completa de VendorShell y sus recursos asociados, vea VendorShell(3).

RELACIONADO

VendorShell(3), XmAddWMProtocolCallback(3), XmInternAtom(3) y XmRemoveProtocolCallback(3).
