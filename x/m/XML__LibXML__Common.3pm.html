XML::LibXML::Common(3) Documentación de Perl contribuida por el usuario XML::LibXML::Common(3)

NOMBRE

XML::LibXML::Common - Constantes y Rutinas de Codificación de Caracteres

SINOPSIS

use XML::LibXML::Common;
$cadena_codificada = encodeToUTF8( $nombre_de_codificacion, $cadena_a_codificar );
$cadena_decodificada = decodeFromUTF8($nombre_de_codificacion, $cadena_a_decodificar );

DESCRIPCION

XML::LibXML::Common define constantes para todos los tipos de nodos y proporciona interfaz a las funciones de conversión de juegos de caracteres de libxml2.

Dado que XML::LibXML usa sus propias definiciones de tipos de nodo, se puede querer usar XML::LibXML::Common en su modo de compatibilidad:

TAGS DEL EXPORTADOR

use XML::LibXML::Common qw(:libxml);

La etiqueta ":libxml" usará el modo de Compatibilidad de XML::LibXML, que define las antiguas definiciones de tipo de nodo 'XML_'.

use XML::LibXML::Common qw(:gdome);

La etiqueta ":gdome" usará el modo de Compatibilidad de XML::GDOME, que define las antiguas definiciones de tipo de nodo 'GDOME_'.

use XML::LibXML::Common qw(:w3c);

Esto usa los nombres de definición de tipo de nodo según lo especificado para DOM.

use XML::LibXML::Common qw(:encoding);

Esta etiqueta se puede usar para exportar solo las funciones de codificación de juegos de caracteres de XML::LibXML::Common.

Exportaciones

Por defecto, las definiciones W3 tal como se definen en las especificaciones DOM y las funciones de codificación son exportadas por XML::LibXML::Common.

Funciones de codificación

Para codificar o decodificar una cadena desde o hacia UTF-8, XML::LibXML::Common exporta dos funciones, que proporcionan una interfaz a la soporte de codificación en "libxml2". Qué codificaciones son soportadas por estas funciones depende de cómo fue compilado "libxml2". UTF-16 siempre es soportado y en la mayoría de las instalaciones, las codificaciones ISO también son soportadas.

Esta interfaz fue útil para versiones antiguas de Perl. Desde que Perl >= 5.8 proporciona funciones similares a través del módulo "Encode", probablemente sea una buena idea usar esas en su lugar.

encodeToUTF8
$cadena_codificada = encodeToUTF8( $nombre_de_codificacion, $cadena_a_codificar );

La función convertirá una cadena de bytes de la codificación especificada a una cadena de caracteres codificada en UTF-8.

decodeToUTF8
$cadena_decodificada = decodeFromUTF8($nombre_de_codificacion, $cadena_a_decodificar );

Esta función convierte una cadena de caracteres codificada en UTF-8 a una codificación especificada. Tenga en cuenta que la conversión puede generar un error si la cadena dada contiene caracteres que no pueden ser representados en la codificación de destino.

Ambas funciones reportan sus errores en la salida de error estándar. Si ocurre un error, la función hará un croak(). Para capturar la información del error, se requiere llamar a la función de codificación desde dentro de un bloque eval para evitar que todo el script se detenga por un error de codificación.

Una nota sobre la historia

Antes de XML::LibXML 1.70, esta clase estaba disponible como una distribución separada de CPAN, destinada a proporcionar funcionalidad compartida entre XML::LibXML, XML::GDOME y posiblemente otros módulos. Dado que parece no haber progreso en esta dirección, decidimos fusionar XML::LibXML::Common 0.13 y XML::LibXML 1.70 en una sola distribución de CPAN.

La fusión también elimina naturalmente un problema práctico y urgente experimentado por muchos usuarios de XML::LibXML en ciertas plataformas, a saber, el misterioso mal comportamiento de XML::LibXML que ocurre si la versión instalada (a menudo pre-empaquetada) de XML::LibXML::Common se compiló contra una versión más antigua de libxml2 que XML::LibXML.
