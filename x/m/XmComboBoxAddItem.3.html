NOMBRE

XmComboBoxAddItem — añade un elemento al widget ComboBox

SINOPSIS

#include <Xm/ComboBox.h>
void XmComboBoxAddItem(
Widget w,
XmString item,
int pos,
Boolean unique);

DESCRIPCIÓN

La función XmComboBoxAddItem añade el elemento dado a XmComboBox en la posición dada.

El argumento w especifica el ID del widget XmComboBox.

El argumento item especifica el XmString para el nuevo elemento.

El argumento pos especifica la posición del nuevo elemento.

El argumento unique especifica si este elemento debe duplicar un elemento idéntico o no.

VALOR DE RETORNO

La función XmComboBoxAddItem no devuelve ningún valor.

USO DE APLICACIÓN

Las funciones XmComboBoxAddItem y XmComboBoxDeletePos tienen convenciones de nomenclatura diferentes (Item versus Pos) debido a los objetos que están manipulando. El Item es una cadena que se va a añadir, el Pos es un número de posición numérico.

VER TAMBIÉN

XmComboBoxDeletePos(3), XmComboBoxSetItem(3), XmComboBoxSelectItem(3).
