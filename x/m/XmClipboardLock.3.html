NOMBRE

XmClipboardLock — Una función del portapapeles que bloquea el portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardLock (display, window)
        Display * display;
        Window  window;
(void)

DESCRIPCIÓN

XmClipboardLock bloquea el portapapeles para que no sea accesible por otra aplicación hasta que se llame a XmClipboardUnlock. Todas las funciones del portapapeles bloquean y desbloquean el portapapeles para prevenir el acceso simultáneo. Esta función permite a la aplicación evitar que los datos del portapapeles cambien entre llamadas a Inquire y otras funciones del portapapeles. La aplicación no necesita bloquear el portapapeles entre llamadas a XmClipboardStartCopy y XmClipboardEndCopy o a XmClipboardStartRetrieve y XmClipboardEndRetrieve.

Si el portapapeles ya está bloqueado por otra aplicación, XmClipboardLock devuelve un estado de error. Múltiples llamadas a esta función por la misma aplicación incrementan el nivel de bloqueo.

display
Especifica un puntero a la estructura Display que fue devuelta en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llame.

RETORNO

XmClipboardSuccess
La función se ejecutó correctamente.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función nuevamente con los mismos parámetros hasta que el bloqueo desaparezca. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o abandonar la operación.

RELACIONADO

XmClipboardEndCopy(3), XmClipboardEndRetrieve(3), XmClipboardStartCopy(3), XmClipboardStartRetrieve(3), y XmClipboardUnlock(3).
