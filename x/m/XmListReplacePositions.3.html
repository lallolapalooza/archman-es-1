NOMBRE

XmListReplacePositions — Una función de Lista que reemplaza elementos en una lista basándose en su posición

SINOPSIS

#include <Xm/List.h>
void XmListReplacePositions(
Widget widget,
int *position_list,
XmString *item_list,
int item_count;);

DESCRIPCIÓN

XmListReplacePositions reemplaza elementos no contiguos en una lista. El elemento en cada posición especificada en position_list es reemplazado con la entrada correspondiente en item_list. Cuando los elementos se insertan en la lista, se comparan con la lista XmNselectedItems actual. Cualquier elemento nuevo que coincida con elementos de la lista seleccionada aparecerá seleccionado. Se muestra un mensaje de advertencia si una posición especificada es inválida; es decir, el valor es 0 (cero), un entero negativo o un número mayor que el número de elementos en la lista.

widget
Especifica el ID del widget Lista.
position_list
Especifica un array de las posiciones de los elementos a reemplazar. La posición del primer elemento en la lista es 1; la posición del segundo elemento es 2; y así sucesivamente.
item_list
Especifica un array de los elementos de reemplazo.
item_count
Especifica el número de elementos en position_list y item_list. Este número debe ser no negativo.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).

RELACIONADO

XmList(3).
