NOMBRE

XML::Writer - Extensión de Perl para escribir documentos XML.

SINOPSIS

use XML::Writer;
use IO::File;
my $output = IO::File->new(">output.xml");
my $writer = XML::Writer->new(OUTPUT => $output);
$writer->startTag("greeting",
                  "class" => "simple");
$writer->characters("¡Hola, mundo!");
$writer->endTag("greeting");
$writer->end();
$output->close();

DESCRIPCIÓN

XML::Writer es un módulo auxiliar para programas Perl que escriben un documento XML. El módulo maneja todo el escapado para valores de atributos y datos de caracteres, y construye diferentes tipos de marcas, como etiquetas, comentarios e instrucciones de procesamiento.

Por defecto, el módulo realiza varias comprobaciones de validez para detectar errores durante la salida. Este comportamiento puede ser extremadamente útil durante el desarrollo y la depuración, pero se puede desactivar para el código de nivel de producción.

El módulo puede operar en modo normal o en modo de procesamiento de espacios de nombres. En modo de espacios de nombres, el módulo generará declaraciones de espacios de nombres por sí mismo y realizará comprobaciones adicionales en la salida.

Hay soporte adicional para un modo de datos simplificado sin contenido mixto: se insertan saltos de línea automáticamente alrededor de los elementos y los elementos pueden ser indentados opcionalmente según su nivel de anidamiento.

MÉTODOS

Escribiendo XML

new([$params])
Crea un nuevo objeto XML::Writer: 
my $writer = XML::Writer->new(OUTPUT => $output, NEWLINES => 1);

Los argumentos son un array hash anónimo de parámetros:

OUTPUT
Un objeto bendecido en IO::Handle o una de sus subclases (como IO::File), o una referencia a una cadena, o cualquier objeto bendecido que tenga un método print(); si este parámetro no está presente, el módulo escribirá en la salida estándar. Si se pasa una referencia de cadena, capturará el XML generado (como una cadena; para obtener bytes, use el módulo "Encode").

Si se pasa la cadena self, la salida será capturada internamente por el objeto y se podrá acceder a ella a través del método to_string(), o llamando al objeto en un contexto de cadena.

my $writer = XML::Writer->new( OUTPUT => 'self' );
$writer->dataElement( hello => 'world' );
print $writer->to_string;  # imprime <hello>world</hello>
print "$writer";           # lo mismo
NAMESPACES
Un valor verdadero (1) o falso (0, undef); si este parámetro está presente y su valor es verdadero, entonces el módulo aceptará una referencia a un array de dos miembros en lugar de nombres de elementos y atributos, como en el siguiente ejemplo: 
my $rdfns = "http://www.w3.org/1999/02/22-rdf-syntax-ns#";
my $writer = XML::Writer->new(NAMESPACES => 1);
$writer->startTag([$rdfns, "Description"]);

El primer miembro del array es una URI de espacio de nombres y la segunda parte es la parte local de un nombre calificado. El módulo generará automáticamente las declaraciones de espacios de nombres apropiadas y reemplazará la parte de la URI con un prefijo.

PREFIX_MAP
Una referencia a un hash; si este parámetro está presente y el módulo está procesando espacios de nombres (ver el parámetro NAMESPACES), entonces el módulo utilizará este hash para buscar prefijos preferidos para las URIs de espacios de nombres: 
my $rdfns = "http://www.w3.org/1999/02/22-rdf-syntax-ns#";
my $writer = XML::Writer->new(NAMESPACES => 1,
                             PREFIX_MAP => {$rdfns => 'rdf'});

Las claves en la tabla hash son URIs de espacios de nombres y los valores son los prefijos asociados. Si no hay un prefijo preferido para la URI del espacio de nombres en este hash, entonces el módulo generará automáticamente prefijos del tipo "__NS1", "__NS2", etc.

Para establecer el espacio de nombres predeterminado, use '' como prefijo.

FORCED_NS_DECLS
Una referencia a un array; si este parámetro está presente, el elemento del documento contendrá declaraciones para todas las URIs de espacios de nombres dadas. Declarar espacios de nombres por adelantado es particularmente útil cuando un gran número de elementos de un espacio de nombres son hermanos, pero no comparten un ancestro directo del mismo espacio de nombres.
NEWLINES
Un valor verdadero o falso; si este parámetro está presente y su valor es verdadero, entonces el módulo insertará un salto de línea adicional antes del delimitador de cierre de las etiquetas de inicio, fin y vacías para garantizar que el documento no termine como una sola línea larga. Si el parámetro no está presente, el módulo no insertará los saltos de línea.
UNSAFE
Un valor verdadero o falso; si este parámetro está presente y su valor es verdadero, entonces el módulo omitirá la mayoría de las comprobaciones de errores de validez. Si el parámetro no está presente, el módulo realizará las comprobaciones de errores de validez por defecto. ¡Desactive la comprobación de errores bajo su propio riesgo!
DATA_MODE
Un valor verdadero o falso; si este parámetro está presente y su valor es verdadero, entonces el módulo entrará en un modo de datos especial, insertando saltos de línea automáticamente alrededor de los elementos y (a menos que UNSAFE también se especifique) informando un error si algún elemento tiene tanto caracteres como elementos como contenido.
DATA_INDENT
Un valor numérico o espacio en blanco; si este parámetro está presente, representa el paso de indentación para los elementos en modo de datos (se ignorará cuando no esté en modo de datos). Si es espacio en blanco, se repetirá para cada nivel de indentación.
ENCODING
Una codificación de caracteres a utilizar para la salida; actualmente debe ser una de 'utf-8' o 'us-ascii'. Si está presente, se utilizará para la codificación de caracteres subyacente y como valor predeterminado en la declaración XML. Todos los datos de caracteres deben pasarse como cadenas Unicode cuando se establece una codificación.
CHECK_PRINT
Un valor verdadero o falso; si este parámetro está presente y su valor es verdadero, todas las impresiones a la salida subyacente se comprobarán para ver si tuvieron éxito. Los fallos causarán un "croak" en lugar de ser ignorados.
end()
Finaliza la creación de un documento XML. Este método comprobará que el documento tenga exactamente un elemento raíz y que todas las etiquetas de inicio estén cerradas: 
$writer->end();

Si OUTPUT se ha establecido en self, end() también devolverá el documento generado.

xmlDecl([$encoding, $standalone])
Agrega una declaración XML al principio de un documento XML. La versión siempre será "1.0". Si proporciona un argumento de codificación o autónomo no nulo, su valor aparecerá en la declaración (cualquier valor no nulo para autónomo excepto 'no' se convertirá automáticamente a 'yes'). Si no se proporciona aquí, la codificación se tomará del argumento ENCODING. Pase la cadena vacía para suprimir este comportamiento. 
$writer->xmlDecl("UTF-8");
doctype($name, [$publicId, $systemId])
Agrega una declaración DOCTYPE a un documento XML. La declaración debe aparecer antes del inicio del elemento raíz. Si proporciona un publicId, debe proporcionar también un systemId, pero puede proporcionar solo un system ID pasando 'undef' para el publicId. 
$writer->doctype("html");
comment($text)
Agrega un comentario a un documento XML. Si el comentario aparece fuera del elemento del documento (ya sea antes de la primera etiqueta de inicio o después de la última etiqueta de fin), el módulo agregará un retorno de carro después de él para mejorar la legibilidad. En modo de datos, los comentarios se tratarán como etiquetas vacías: 
$writer->comment("Este es un comentario"

ESCRIBIR XML

Estas son las operaciones que se pueden realizar con un objeto XML::Writer:

new([OPTION => VALUE, ...])
Crea y devuelve un nuevo objeto XML::Writer. Las opciones son:
OUTPUT
A dónde enviar la salida XML. Por defecto es la salida estándar. Si se establece en self, el objeto mismo será el destino, y se puede obtener el documento resultante llamando a to_string(). Si se establece en una referencia a un manejador de archivo Perl, la salida se escribirá en ese manejador de archivo.
UNSAFE
Si es verdadero, algunas comprobaciones de seguridad y de formato XML se desactivan para permitir la escritura de datos "crudos" (ver raw()).
DATA_MODE
Si es verdadero, se habilitará el modo de datos (ver más abajo).
DATA_INDENT
Establece el nivel de sangría para el modo de datos.
PREFIX_MAP
Un hash que mapea URIs de espacio de nombres a prefijos preferidos.
pi($target [, $data])
Agrega una instrucción de procesamiento a un documento XML: 
$writer->pi('xml-stylesheet', 'href="style.css" type="text/css"');

Si la instrucción de procesamiento aparece fuera del elemento documento (ya sea antes de la primera etiqueta de inicio o después de la última etiqueta de fin), el módulo agregará un retorno de carro después de ella para mejorar la legibilidad.

El argumento $target debe ser un único nombre XML. Si proporciona el argumento $data, el módulo insertará su contenido después del argumento $target, separado por un único espacio.

startTag($name [, $aname1 => $value1, ...])
Agrega una etiqueta de inicio a un documento XML. Cualquier argumento después del nombre del elemento se asume como pares nombre/valor para los atributos: el módulo escapará todos los caracteres '&', '<', '>' y '"' en los valores de los atributos usando las entidades XML predefinidas: 
$writer->startTag('doc', 'version' => '1.0',
                         'status' => 'draft',
                         'topic' => 'AT&T');

Todas las etiquetas de inicio deben tener eventualmente etiquetas de fin coincidentes.

emptyTag($name [, $aname1 => $value1, ...])
Agrega una etiqueta vacía a un documento XML. Cualquier argumento después del nombre del elemento se asume como pares nombre/valor para los atributos (ver startTag() para más detalles): 
$writer->emptyTag('img', 'src' => 'portrait.jpg',
                         'alt' => 'Portrait of Emma.');
endTag([$name])
Agrega una etiqueta de fin a un documento XML. La etiqueta de fin debe coincidir con la etiqueta de inicio abierta más cercana, y debe haber una etiqueta de fin coincidente y correctamente anidada para cada etiqueta de inicio: 
$writer->endTag('doc');

Si se omite el argumento $name, el módulo suministrará automáticamente el nombre del elemento abierto actualmente:

$writer->startTag('p');
$writer->endTag();
dataElement($name, $data [, $aname1 => $value1, ...])
Imprime un elemento completo que contiene solo datos de caracteres. Esto es equivalente a 
$writer->startTag($name [, $aname1 => $value1, ...]);
$writer->characters($data);
$writer->endTag($name);
characters($data)
Agrega datos de caracteres a un documento XML. Todos los caracteres '<', '>' y '&' en el argumento $data se escaparán automáticamente usando las entidades XML predefinidas: 
$writer->characters("Here is the formula: ");
$writer->characters("a < 100 && a > 5");

Solo puede invocar este método dentro del elemento documento (es decir, después de la primera etiqueta de inicio y antes de la última etiqueta de fin).

En modo de datos, no debe usar este método para agregar espacios en blanco entre elementos.

raw($data)
Imprime datos completamente sin comillas y sin verificar en el documento XML. Por ejemplo raw('<') imprimirá un carácter < literal. Esto necesariamente omite todas las comprobaciones de formato correcto, y por lo tanto, solo está disponible en modo inseguro.

Esto puede ser útil a veces para imprimir entidades que están definidas para su formato XML pero que el módulo no conoce, por ejemplo &nbsp; para XHTML.

cdata($data)
Igual que characters() pero escribe los datos entre comillas en una sección CDATA, es decir, entre <![CDATA[ y ]]>. Si los datos a escribir contienen ellos mismos ]]>, se escribirán como varias secciones CDATA consecutivas.
cdataElement($name, $data [, $aname1 => $value1, ...])
Igual que dataElement() pero el contenido del elemento se escribe como una o más secciones CDATA (ver cdata()).
setOutput($output)
Establece el destino de salida actual, como en el parámetro OUTPUT para el constructor.
getOutput()
Devuelve el destino de salida actual, como en el parámetro OUTPUT para el constructor.
setDataMode($mode)
Habilita o deshabilita el modo de datos, como en el parámetro DATA_MODE para el constructor.
getDataMode()
Devuelve el modo de datos actual, como en el parámetro DATA_MODE para el constructor.
setDataIndent($step)
Establece el paso de sangría para el modo de datos, como en el parámetro DATA_INDENT para el constructor.
getDataIndent()
Devuelve el paso de sangría para el modo de datos, como en el parámetro DATA_INDENT para el constructor.

CONSULTAR XML

in_element($name)
Devuelve un valor verdadero si el elemento abierto más reciente coincide con $name: 
if ($writer->in_element('dl')) {
  $writer->startTag('dt');
} else {
  $writer->startTag('li');
}
within_element($name)
Devuelve un valor verdadero si algún elemento abierto coincide con $name: 
if ($writer->within_element('body')) {
  $writer->startTag('h1');
} else {
  $writer->startTag('title');
}
current_element()
Devuelve el nombre del elemento abierto actualmente: 
my $name = $writer->current_element();

Esto es el equivalente a

my $name = $writer->ancestor(0);
ancestor($n)
Devuelve el nombre del enésimo ancestro, donde $n=0 para el elemento abierto actual.

SOPORTE ADICIONAL DE ESPACIOS DE NOMBRES

A partir de la versión 0.510, estos métodos pueden ser utilizados mientras se escribe un documento.

addPrefix($uri, $prefix)
Agrega un mapeo preferido entre una URI de espacio de nombres y un prefijo. Ver también el parámetro del constructor PREFIX_MAP.

Para establecer el espacio de nombres predeterminado, omita el parámetro $prefix o establézcalo en ''.

removePrefix($uri)
Elimina un mapeo preferido entre una URI de espacio de nombres y un prefijo.
forceNSDecl($uri)
Indica que una declaración de espacio de nombres para esta URI debe incluirse con el próximo elemento que se inicie.

REPORTE DE ERRORES

Con la configuración predeterminada, el módulo XML::Writer puede detectar varios errores básicos de formato XML:

  • Falta de un elemento documento (de nivel superior), o múltiples elementos documento.
  • Etiquetas de inicio sin cerrar.
  • Delimitadores mal colocados en el contenido de instrucciones de procesamiento o comentarios.
  • Declaración(es) XML mal colocadas o duplicadas.
  • Declaración(es) DOCTYPE mal colocadas o duplicadas.
  • Discrepancia entre el nombre del tipo de documento en la declaración DOCTYPE y el nombre del elemento documento.
  • Etiquetas de inicio y fin que no coinciden.
  • Intentos de insertar datos de caracteres fuera del elemento documento.
  • Atributos duplicados con el mismo nombre.

Durante el procesamiento de Espacios de Nombres, el módulo puede detectar los siguientes errores adicionales:

  • Intentos de usar objetivos de PI o nombres de elementos o atributos que contienen dos puntos.
  • Intentos de usar atributos con nombres que comienzan con "xmlns".

Para garantizar la detección completa de errores, un programa también debe invocar el método end() cuando haya terminado de escribir un documento:

$writer->startTag('greeting');
$writer->characters("Hello, world!");
$writer->endTag('greeting');
$writer->end();

Este reporte de errores puede detectar muchos errores ocultos en programas Perl que crean documentos XML; sin embargo, si es necesario, se puede desactivar proporcionando un parámetro UNSAFE:

my $writer = XML::Writer->new(OUTPUT => $output, UNSAFE => 1);

IMPRIMIR SALIDA

Si OUTPUT se ha establecido en self y el objeto se ha llamado en un contexto de cadena, devolverá el documento xml.

to_string
Si OUTPUT se ha establecido en self, llama implícitamente a un end() en el documento y lo imprime. Termina si OUTPUT se ha establecido en cualquier otra cosa.
