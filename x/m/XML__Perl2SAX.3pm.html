NOMBRE

XML::SAX2Perl -- traduce métodos SAX de Perl a métodos de estilo Java/CORBA

SINOPSIS

use XML::Perl2SAX;
$perl2sax = XML::Perl2SAX(handler => $manejador_estilo_java);

DESCRIPCIÓN

"XML::Perl2SAX" es un filtro SAX que traduce métodos SAX de estilo Perl a llamadas de método de estilo Java/CORBA. Este módulo realiza la operación inversa de "XML::SAX2Perl".

"Perl2SAX" es un manejador de documentos SAX de Perl. El método `"new"' toma un argumento `"handler"' que es un manejador de estilo Java/CORBA al que la nueva instancia de Perl2SAX llamará. Las interfaces SAX se definen en http://www.megginson.com/SAX/.
