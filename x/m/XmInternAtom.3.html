NOMBRE

XmInternAtom — Una macro que devuelve un átomo para un nombre dado

SINOPSIS

#include <Xm/AtomMgr.h>
Atom XmInternAtom(
Display * display,
String name,
Boolean only_if_exists);

DESCRIPCIÓN

XmInternAtom devuelve un átomo para un nombre dado. El átomo devuelto permanece definido incluso después de que la conexión del cliente se cierre. El átomo devuelto se vuelve indefinido cuando se cierra la última conexión con el servidor X.

display
Especifica la conexión con el servidor X
name
Especifica el nombre asociado con el átomo que desea que se devuelva. El valor de name depende de mayúsculas y minúsculas.
only_if_exists
Especifica un valor booleano. Si es Falso, el átomo se crea incluso si no existe. (Si no existe, el átomo devuelto será None.) Si es Verdadero, el átomo se crea solo si existe.

RETORNO

Devuelve un átomo.
