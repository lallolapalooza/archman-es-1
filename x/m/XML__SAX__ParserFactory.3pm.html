XML::SAX::ParserFactory(3) Documentación de Perl aportada por el usuario XML::SAX::ParserFactory(3)

NOMBRE

XML::SAX::ParserFactory - Obtener un analizador SAX

SINOPSIS

use XML::SAX::ParserFactory;
use XML::SAX::XYZHandler;
my $handler = XML::SAX::XYZHandler->new();
my $p = XML::SAX::ParserFactory->parser(Handler => $handler);
$p->parse_uri("foo.xml");
# o $p->parse_string("<foo/>") o $p->parse_file($fh);

DESCRIPCIÓN

XML::SAX::ParserFactory es una clase fábrica para proporcionar a una aplicación un analizador XML SAX2 de Perl. Es similar a DBI: un front-end para otras clases de analizadores. Cada nuevo analizador SAX2 instalado se registrará en XML::SAX, y luego estará disponible para todas las aplicaciones que utilicen XML::SAX::ParserFactory para obtener un analizador SAX.

Sin embargo, a diferencia de DBI, los analizadores XML/SAX funcionan casi todos de la misma manera (especialmente si heredan de XML::SAX::Base, como deberían), por lo que en lugar de especificar el analizador que deseas en la llamada a parser(), XML::SAX tiene varias formas de elegir automáticamente qué analizador usar:

  • $XML::SAX::ParserPackage

    Si esta variable de paquete está establecida, entonces este paquete se carga con require() y se devuelve una instancia de este paquete llamando al método de clase new() en ese paquete. Si no se puede cargar o hay un error, se lanzará una excepción. La variable también puede contener un número de versión:

    $XML::SAX::ParserPackage = "XML::SAX::Expat (0.72)";

    Y el número se tratará como un número de versión mínimo.

  • Funcionalidades requeridas

    Es posible requerir funcionalidades de los analizadores. Por ejemplo, puedes desear un analizador que admita validación a través de DTD. Para hacerlo, usa el siguiente código:

    use XML::SAX::ParserFactory;
my $factory = XML::SAX::ParserFactory->new();
$factory->require_feature('http://xml.org/sax/features/validation');
my $parser = $factory->parser(...);

    Alternativamente, especifica las funcionalidades requeridas en la llamada al constructor de ParserFactory:

    my $factory = XML::SAX::ParserFactory->new(
        RequiredFeatures => {
             'http://xml.org/sax/features/validation' => 1,
             }
        );

    Si las funcionalidades que has solicitado no están disponibles (por ejemplo, el usuario podría no tener un analizador de validación instalado), se lanzará una excepción.

    La lista de analizadores conocidos se busca en orden inverso, por lo que siempre devolverá el último analizador instalado que admita todas las funcionalidades solicitadas (Nota: esto está sujeto a cambios si alguien encuentra una mejor manera de hacer que funcione).

  • SAX.ini

    ParserFactory buscará en @INC un archivo llamado SAX.ini, que tiene un formato simple:

    # un comentario se ve así,
; o así, y se eliminan en cualquier parte del archivo
clave = valor # SAX.in contiene pares clave/valor.

    Todo el espacio en blanco no es significativo.

    Este archivo puede contener una línea:

    ParserPackage = MyParserModule (1.02)

    Donde MyParserModule es el módulo a cargar y usar para el analizador, y el número entre paréntesis es una versión mínima a cargar.

    O puedes listar las funcionalidades requeridas:

    http://xml.org/sax/features/validation = 1

    Y cada funcionalidad con un valor verdadero será requerida.

  • Reserva

    Si nada de lo anterior funciona, se utilizará el último analizador instalado en el sistema del usuario. El paquete XML::SAX incluye un analizador XML puro de Perl, XML::SAX::PurePerl, para que siempre haya un analizador de reserva.
