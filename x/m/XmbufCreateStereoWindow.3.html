DESCRIPCION

La biblioteca de aplicaciones (API) para la Extensión de doble buffer, multibuffer y estéreo de X11 contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con una pantalla que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede configurar con XSetExtensionErrorHandler y funciona de la misma manera que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de multibuffer/estéreo está disponible en la pantalla dada. Si la extensión existe, el valor del primer código de evento (que debe añadirse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe añadirse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión mayor y menor de la extensión. El valor de retorno es cero si ocurre un error o distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con la acción de actualización y la pista de actualización dadas y que se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus ventanas apropiadas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers a la misma ventana o se generará un error de coincidencia.

XmbufGetWindowAttributes obtiene los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita a la pista de actualización.

XmbufGetBufferAttributes obtiene los atributos del buffer indicado. Devuelve distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del buffer indicado. Actualmente, esto se limita a la máscara de eventos.

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Los números de conjuntos de visualizaciones y profundidades se devuelven en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen las diversas visualizaciones y profundidades que se pueden utilizar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece según nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los IDs de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un controlador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en esta pantalla.

XmbufCreateStereoWindow(3) — libXext 1.3.6

NAME

XmbufCreateStereoWindow, XmbufDestroyWindow, XmbufReset — create and destroy stereo windows

SYNTAX

Bool XmbufCreateStereoWindow(Display *dpy, Window parent, int x, int y,
    unsigned int width, unsigned int height, int border_width,
    unsigned int depth, unsigned int class, Visual *visual,
    unsigned long valuemask, XSetWindowAttributes *attributes,
    Window *left_return, Window *right_return);
void XmbufDestroyWindow(Display *dpy, Window window);
void XmbufReset(Display *dpy);

STRUCTURES

The XmbufCreateStereoWindow function creates two windows, one for the left eye and one for the right eye. The actual windows created depend on the stereo visual selected. The XmbufDestroyWindow function destroys a previously created stereo window. The XmbufReset function resets the stereo buffer extension, releasing any resources and destroying any stereo windows.

DESCRIPTION

The XmbufCreateStereoWindow function creates a pair of stereo windows. These windows are linked together and are intended to be used for stereo display. The arguments are similar to those for XCreateWindow.

The XmbufDestroyWindow function destroys a single stereo window. When one window of a stereo pair is destroyed, the other window is also destroyed.

The XmbufReset function is used to clean up the stereo buffer extension. It should be called before the connection to the X server is closed.

PREDEFINED VALUES

The following event masks are defined for stereo buffering:

ibufferUpdateNotifyMask
MultibufferClobberNotify
MultibufferUpdateNotify
MultibufferNumberEvents
MultibufferBadBuffer
MultibufferNumberErrors
