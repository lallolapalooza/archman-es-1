XmCvtXmStringToByteStream(3)

Licencias: LGPL-2.1-or-later

NOMBRE

XmCvtXmStringToByteStream — una función de cadena compuesta que convierte una cadena compuesta a formato Byte Stream

SINOPSIS

#include <Xm/Xm.h>
unsigned int XmCvtXmStringToByteStream(
XmString string,
unsigned char **prop_return);

DESCRIPCIÓN

XmCvtXmStringToByteStream convierte una cadena compuesta a una cadena de bytes que representa la cadena compuesta en formato Byte Stream. Esta rutina se usa típicamente en el origen de una operación de transferencia de datos para producir una representación Byte Stream para transferir una cadena compuesta a un destino.

Si prop_return no es NULL, esta función crea una cadena de caracteres en formato Byte Stream y la devuelve en prop_return. La función también devuelve el número de bytes en prop_return. Si prop_return es NULL, la función no devuelve la cadena de formato Byte Stream, pero sí calcula y devuelve el número de bytes que aparecerían en la cadena de formato Byte Stream.

string
Especifica una cadena compuesta que se convertirá al formato Byte Stream.
prop_return
Especifica un puntero a una cadena en formato Byte Stream que es creada y devuelta por esta función. Si prop_return es NULL, no se devuelve ninguna cadena de formato Byte Stream. Cuando se devuelve una cadena de formato Byte Stream, la función asigna espacio para contenerla. La aplicación es responsable de administrar este espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XtFree.

RETORNO

Devuelve el número de bytes en la representación Byte Stream (tanto si se devuelve la representación Byte Stream como si no).

RELACIONADO

XmString(3) y XmCvtByteStreamToXmString(3).
