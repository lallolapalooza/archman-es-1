NOMBRE

XML::Stream::Parser - Analizador XML SAX para flujos XML

SINOPSIS

Analizador XML de peso ligero que construye objetos XML::Parser::Tree a partir del
flujo entrante y los pasa a una función para notificar a quien lo esté usando
que hay nuevos paquetes.

DESCRIPCION

Este módulo proporciona un analizador de peso muy ligero
