NOMBRE

XmToggleButtonGadget — La clase Gadget de Botón de Alternancia

SINOPSIS

#include <Xm/ToggleBG.h>

DESCRIPCIÓN

ToggleButtonGadget establece datos de estado no transitorios dentro de una aplicación. Normalmente, este gadget consiste en un indicador (cuadrado, diamante o redondo) con texto o un pixmap en un lado. Sin embargo, también puede consistir solo en texto o un pixmap sin el indicador.

Los gráficos de alternancia muestran un estado de selección de 1 de muchos, N de muchos, o N de muchos-redondo. Cuando se muestra un indicador de alternancia, un indicador cuadrado muestra un estado de selección N de muchos, un indicador en forma de diamante muestra un estado de selección 1 de muchos, y un indicador en forma de círculo muestra un estado de selección 1 de muchos-redondo.

ToggleButtonGadget implica un estado establecido o no establecido. En el caso de una etiqueta y un indicador, un indicador vacío (cuadrado, diamante o redondo) indica que ToggleButtonGadget no está establecido, y un indicador relleno muestra que está establecido. El indicador puede rellenarse con una marca de verificación o el color de selección. En el caso de una alternancia de pixmap, se utilizan diferentes pixmaps para mostrar los estados establecido/no establecido. ToggleButtonGadget también puede indicar un estado indeterminado. En el caso de una etiqueta y un indicador, un estado indeterminado se indica mediante un cuadro plano punteado. En el caso de una alternancia de pixmap, se utiliza un pixmap diferente para mostrar el estado indeterminado.

El comportamiento predeterminado asociado con un ToggleButtonGadget en un menú depende del tipo de sistema de menú en el que reside. Por predeterminado, <Btn1> controla el comportamiento del ToggleButtonGadget. Además, <Btn3> controla el comportamiento del ToggleButtonGadget si reside en un sistema PopupMenu. El botón del ratón real utilizado viene determinado por su padre RowColumn.

El recurso XmNmarginLeft de Label puede aumentarse para acomodar el indicador de alternancia cuando se crea.

ToggleButtonGadget utiliza los rasgos XmQTmenuSystem y XmQTspecifyRenderTable.

CLASES

ToggleButtonGadget hereda el comportamiento, los recursos y los rasgos de Object, RectObj, XmGadget y XmLabelGadget.

El puntero de clase es xmToggleButtonGadgetClass.

El nombre de la clase es XmToggleButtonGadget.

CALLBACKS

ToggleButtonGadget puede enviar callbacks al programador. Los siguientes callbacks son específicos de ToggleButtonGadget:

XmNarmCallback: Este callback se llama cuando el gadget se dispara. El reason code es XmCR_ARM.

XmNdisarmCallback: Este callback se llama cuando el gadget se desarma. El reason code es XmCR_DISARM.

XmNactivateCallback: Este callback se llama cuando el gadget se activa. El reason code es XmCR_ACTIVATE.

XmNhelpCallback: Este callback se llama cuando se invoca la ayuda. El reason code es XmCR_HELP.

El puntero de datos de entrada (pasado a los callbacks) para cada uno de estos callbacks es XmToggleButtonGadgetCallbackStruct.

La estructura XmToggleButtonGadgetCallbackStruct contiene:

typedef struct {
     int reason;                /* Identifica la causa del callback */
     XEvent *event;             /* Puntero al evento que causó el callback */
     Boolean set;               /* Valor booleano del estado establecido/no establecido */
} XmToggleButtonGadgetCallbackStruct;

COMPORTAMIENTO

Los ToggleButtonGadgets se pueden invocar de diversas maneras, dependiendo de la opción XmNinvocationCallback del gadget padre RowColumn.

Default Button behavior: Si un ToggleButtonGadget está dentro de un menú, el botón de alternancia se puede seleccionar o deseleccionar, y el menú padre permanece visible. Esto es útil para establecer opciones que afectan a la configuración de la aplicación.

Menu Button behavior: Si un ToggleButtonGadget está en un menú emergente, puede ser seleccionado o deseleccionado. La selección de un elemento de menú causa que el menú emergente desaparezca.

ESTADO INICIAL

Los ToggleButtonGadgets se inicializan a un estado no establecido a menos que se especifique lo contrario. El valor predeterminado es XmNset = False.

EJEMPLOS

Para crear un ToggleButtonGadget:

Widget toggle_button;
 toggle_button = XtCreateWidget ("toggle_button",
     xmToggleButtonGadgetClass, parent, NULL, 0);

XmNarmCallback
Especifica una lista de callbacks que se llama cuando el ToggleButtonGadget es activado. Para activar este gadget, presione el botón del ratón activo mientras el puntero está dentro del ToggleButtonGadget. Para este callback, la razón es XmCR_ARM.
XmNdetailShadowThickness
Especifica el grosor de la sombra del indicador. El grosor predeterminado es de 2 píxeles.
XmNdisarmCallback
Especifica una lista de callbacks que se llama cuando el ToggleButtonGadget se desactiva. Para desactivar este gadget, presione y suelte el botón del ratón activo mientras el puntero está dentro del ToggleButtonGadget. El gadget también se desactiva cuando el usuario mueve el puntero fuera del gadget y suelta el botón del ratón cuando el puntero está fuera del gadget. Para este callback, la razón es XmCR_DISARM.
XmNfillOnSelect
Rellena el indicador con el color especificado en XmNselectColor y cambia los colores de sombra superior e inferior cuando se establece en True. Si se deja sin seleccionar, rellena el indicador con el color de deselección. Si es indeterminado, rellena el indicador con mitad del color de selección y mitad del color de deselección. De lo contrario, solo cambia los colores de sombra superior e inferior. El valor predeterminado es True solo si se especifica un tipo de indicador de caja (como una casilla de verificación), o si XmNindicatorType es de tipo 1-de y se dibuja un indicador de alternancia. Si XmNfillOnSelect es True, XmNset es XmSET, y XmNindicatorOn es XmINDICATOR_NONE, el fondo del ToggleButtonGadget se establece en XmNselectColor. Para los otros valores de XmNindicatorOn, solo el indicador se rellena con XmNselectColor.
XmNindeterminateInsensitivePixmap
Especifica el pixmap que se mostrará como la cara del botón cuando el recurso XmNlableType de la etiqueta sea XmPIXMAP o XmPIXMAP_AND_STRING, el recurso XmNset del ToggleButtonGadget sea XmINDETERMINATE, y el recurso Core XmNsensitive sea False.
XmNindeterminatePixmap
Especifica el pixmap que se mostrará como la cara del botón cuando el recurso XmNlableType de la etiqueta sea XmPIXMAP o XmPIXMAP_AND_STRING, el recurso XmNset del ToggleButtonGadget sea XmINDETERMINATE, y el recurso Core XmNsensitive sea True.
XmNindicatorOn
Especifica que si se va a dibujar un indicador de alternancia, se dibujará a un lado del texto o pixmap de alternancia, dependiendo del recurso XmNlayoutDirection del widget. El valor predeterminado es XmINDICATOR_FILL. Las alternancias aceptan los siguientes valores:
XmINDICATOR_NONE
No se asigna espacio para el indicador y no se muestra. Cualquier sombra alrededor del widget completo se invierte cuando la alternancia se selecciona o deselecciona.
XmINDICATOR_BOX
El indicador de alternancia tiene la forma de una caja sombreada.
XmINDICATOR_FILL
Si el valor del recurso XmDisplay XmNenableToggleVisual es True, las visuales son las de XmINDICATOR_CHECK_BOX; si es False, las visuales del indicador son las de XmINDICATOR_BOX.
XmINDICATOR_CHECK
El indicador de alternancia tiene la forma de una marca de verificación en el color de primer plano.
XmINDICATOR_CHECK_BOX
El indicador de alternancia tiene la forma de una marca de verificación encerrada en una caja. Este es el valor predeterminado si el recurso XmDisplay XmNenableToggleVisual está establecido.
XmINDICATOR_CROSS_BOX
El indicador de alternancia tiene la forma de una cruz encerrada en una caja.
XmINDICATOR_CROSS
El indicador de alternancia tiene la forma de una cruz.
Todas las marcas y cruces de ToggleButton deben dibujarse en el color de primer plano.
Si este recurso no es XmINDICATOR_NONE, controlará la apariencia de la visual de alternancia. Si XmNset es XmINDETERMINATE y XmNindicatorOn no es XmINDICATOR_NONE, este recurso muestra una caja plana punteada. Si XmNset es XmINDETERMINATE, XmNindicatorOn es XmINDICATOR_NONE, y XmNtoggleMode es XmTOGGLE_INDETERMINATE, la etiqueta y el ToggleButton se puntúan con una combinación del color XmNselectColor y el color XmNunselectColor, y el borde es plano.
XmNindicatorSize
Establece el tamaño del indicador. Si no se especifica ningún valor, el tamaño del indicador se basa en el tamaño de la cadena o pixmap de la etiqueta. Si la cadena o pixmap de la etiqueta cambia, el tamaño del indicador se recalcula basándose en el tamaño de la cadena o pixmap de la etiqueta. Una vez que se ha especificado un valor para XmNindicatorSize, el indicador tiene ese tamaño, independientemente del tamaño de la cadena o pixmap de la etiqueta, hasta que se especifique un nuevo valor. El tamaño de los indicadores dentro de los menús puede diferir de los que están fuera de los menús. Tenga en cuenta que un cambio en este recurso también puede provocar un cambio en los valores de los recursos heredados XmNmarginTop, XmNmarginBottom y XmNmarginLeft.
XmNindicatorType
Especifica si el indicador es de tipo 1-de o N-de. Para el indicador 1-de, el valor puede ser XmONE_OF_MANY, XmONE_OF_MANY_ROUND, o XmONE_OF_MANY_DIAMOND. Para el indicador N-de, el valor es XmN_OF_MANY. Este valor especifica solo la apariencia visual y no impone el comportamiento. Cuando el ToggleButton está en una caja de radio, el valor predeterminado es XmONE_OF_MANY; de lo contrario, el valor predeterminado es XmN_OF_MANY. Los valores legales son:
XmONE_OF_MANY
Cuando el recurso XmDisplay XmNenableToggleVisual está establecido, los indicadores se dibujan con la misma apariencia que XmONE_OF_MANY_ROUND; de lo contrario, aparecen igual que XmONE_OF_MANY_DIAMOND.
XmN_OF_MANY
Los indicadores se dibujan según lo especificado por el recurso XmNindicatorOn.
XmONE_OF_MANY_ROUND
Un círculo sombreado.
XmONE_OF_MANY_DIAMOND
Un rombo sombreado.
XmNselectColor
Permite a la aplicación especificar qué color rellena el centro del indicador cuadrado, en forma de diamante o redondo cuando está activado. Si este color es el mismo que el color de la sombra superior o inferior del indicador, se deja un margen de un píxel de ancho entre las sombras y el relleno; de lo contrario, se rellena completamente. Los resultados de este recurso dependen del valor del recurso de visualización XmNenableToggleColor. Un valor de True hace que el color de relleno utilice el color XmHIGHLIGHT_COLOR por defecto. Un valor de False hace que el color de relleno utilice el color de fondo. El valor por defecto de este recurso para una pantalla en color es un color entre el color de fondo y el color de la sombra inferior. Para una pantalla monocromática, el valor por defecto se establece en el color de primer plano. Para establecer el fondo del botón a XmNselectColor cuando XmNindicatorOn es XmINDICATOR_NONE, el valor de XmNfillOnSelect debe establecerse explícitamente en True.
Este recurso puede tomar los siguientes valores:
XmDEFAULT_SELECT_COLOR
Es el mismo que el valor dinámico actual por defecto, que es un color entre el color de fondo y el color de la sombra inferior.
XmREVERSED_GROUND_COLORS
Fuerza el color de selección al color de primer plano y hace que el color por defecto de cualquier texto renderizado sobre el color de selección sea el color de fondo.
XmHIGHLIGHT_COLOR
Fuerza el color de relleno a utilizar el color de resaltado.
XmNselectInsensitivePixmap
Especifica un pixmap utilizado como cara del botón cuando el ToggleButtonGadget está seleccionado, el botón es insensible y el recurso LabelGadget XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING. Si el ToggleButtonGadget no está seleccionado y el botón es insensible, el pixmap en XmNlabelInsensitivePixmap se utiliza como la cara del botón. Si no se especifica ningún valor para XmNlabelInsensitivePixmap, ese recurso se establece en el valor especificado para XmNselectInsensitivePixmap.
XmNselectPixmap
Especifica el pixmap a utilizar como cara del botón si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, y el ToggleButtonGadget está seleccionado. Cuando el ToggleButtonGadget no está seleccionado, se utiliza el pixmap especificado en XmNlabelPixmap de LabelGadget. Si no se especifica ningún valor para XmNlabelPixmap, ese recurso se establece en el valor especificado para XmNselectPixmap.
XmNset
Representa el estado del ToggleButton. Un valor de XmUNSET indica que el ToggleButton no está activado. Un valor de XmSET indica que el ToggleButton está activado. Un valor de XmINDETERMINATE indica que el ToggleButton está en un estado indeterminado (ni activado ni desactivado). Los estados del ToggleButton ciclan en el orden de XmSET, XmINDETERMINATE (si XmNtoggleMode está establecido en XmTOGGLE_INDETERMINATE), y XmUNSET, y luego de vuelta a XmSET. Si XmNtoggleMode está establecido en XmTOGGLE_BOOLEAN, entonces los estados del ToggleButton ciclan en el orden de XmSET, luego XmUNSET, y luego de vuelta a XmSET. Establecer este recurso establece el estado del ToggleButton.
XmNspacing
Especifica la cantidad de espacio entre el indicador de alternancia y la etiqueta de alternancia (texto o pixmap).
XmNtoggleMode
Especifica el modo del ToggleButtonGadget como XmTOGGLE_BOOLEAN o XmTOGGLE_INDETERMINATE. El valor XmTOGGLE_INDETERMINATE permite que el recurso XmNset acepte los valores XmINDETERMINATE, XmSET y XmUNSET. El recurso XmNtoggleMode se fuerza a XmTOGGLE_BOOLEAN si la alternancia está en un widget XmRowColumn cuyo comportamiento de radio es XmONE_OF_MANY. En modo XmTOGGLE_BOOLEAN, el recurso XmNset solo puede aceptar XmSET y XmUNSET.
XmNunselectColor
Permite a la aplicación especificar qué color rellena el centro del indicador cuadrado, en forma de diamante o redondo cuando no está activado. Si este color es el mismo que el color de la sombra superior o inferior del indicador, se deja un margen de un píxel de ancho entre las sombras y el relleno; de lo contrario, se rellena completamente. El valor por defecto de este recurso para una pantalla en color es XmNbackground. Para una pantalla monocromática, el valor por defecto se establece en el color de fondo. Para establecer el fondo del botón a XmNunselectColor cuando XmNindicatorOn es XmINDICATOR_NONE, el valor de XmNfillOnSelect debe establecerse explícitamente en True. Este recurso funciona como el recurso XmNselectColor, pero para el caso en que XmNset es XmUNSET.
XmNvalueChangedCallback
Especifica una lista de callbacks que se llaman cuando cambia el valor del ToggleButtonGadget. Para cambiar el valor, presione y suelte el botón del ratón activo mientras el puntero está dentro del ToggleButtonGadget. Esta acción también hace que el gadget se desarme. Para este callback, la razón es XmCR_VALUE_CHANGED.
XmNvisibleWhenOff
Indica que el indicador de alternancia es visible en el estado no seleccionado cuando el valor booleano es True. Cuando el ToggleButtonGadget está en un menú, el valor por defecto es False. Cuando el ToggleButtonGadget está en un RadioBox, el valor por defecto es True.

Información de Callback

Se pasa un puntero a la siguiente estructura a cada callback:

typedef struct
{
        int reason;
        XEvent * event;
        int set;
} XmToggleButtonCallbackStruct;
reason
Indica por qué se invocó el callback.
event
Punta a XEvent que activó el callback.
set
Refleja el estado del ToggleButtonGadget, ya sea XmSET (seleccionado), XmUNSET (no seleccionado), o XmINDETERMINATE (ninguno). Tenga en cuenta que el estado reportado es el estado en el que se encuentra el ToggleButtonGadget después de que se ha procesado el event. Por ejemplo, suponga que un usuario hace clic en un ToggleButtonGadget para cambiarlo de un estado no seleccionado a un estado seleccionado. En este caso, el ToggleButtonGadget cambia el valor de set de XmUNSET a XmSET antes de llamar al callback.

BEHAVIOR

Behavior

XmToggleButtonGadget incluye el comportamiento de XmGadget. XmToggleButtonGadget incluye el comportamiento de recorrido de menú de XmLabelGadget. El comportamiento adicional de XmToggleButtonGadget se describe en la siguiente lista:

<Btn2Down>:
Arrastra el contenido de la etiqueta de un ToggleButtonGadget, identificado cuando se presiona <Btn2>. Esta acción no está definida para los ToggleButtonGadgets utilizados en un sistema de menú.
<Btn1Down>:
En un menú, esta acción despublica cualquier menú publicado por el menú padre del ToggleButtonGadget, deshabilita el recorrido del teclado para el menú y habilita el recorrido del ratón para el menú. Dibuja la sombra en el estado armado y, a menos que el botón ya esté armado, llama a las callbacks de XmNarmCallback.
Fuera de un menú, si el botón no estaba configurado previamente, esta acción realiza lo siguiente: si XmNindicatorOn es True, dibuja la sombra del indicador para que parezca presionado; si XmNfillOnSelect es True, rellena el indicador con el color especificado por XmNselectColor. Si XmNindicatorOn es False, dibuja la sombra del botón para que parezca presionado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNselectPixmap como cara del botón. Este recurso llama a las callbacks de XmNarmCallback.
Fuera de un menú, si el botón estaba configurado previamente, esta acción realiza lo siguiente: si tanto XmNindicatorOn como XmNvisibleWhenOff son True, dibuja la sombra del indicador para que parezca levantado; si XmNfillOnSelect es True, rellena el indicador con el color de fondo. Si XmNindicatorOn es False, dibuja la sombra del botón para que parezca levantado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNlabelPixmap como cara del botón. Este recurso llama a las callbacks de XmNarmCallback.
<Btn1Up>:
En un menú, esta acción despublica todos los menús de la jerarquía de menús. Si el ToggleButtonGadget estaba configurado previamente, esta acción lo desconfigura; si el ToggleButtonGadget no estaba configurado previamente, esta acción lo configura. Llama a las callbacks de XmNvalueChangedCallback y luego a las callbacks de XmNdisarmCallback.
Si el botón está fuera de un menú y el puntero está dentro del botón, esta acción hace lo siguiente: si el botón no estaba configurado previamente, lo configura; si el botón estaba configurado previamente, lo desconfigura. Esta acción llama a las callbacks de XmNvalueChangedCallback.
Si el botón está fuera de un menú, esta acción llama a las callbacks de XmNdisarmCallback.
<Key><osfHelp>:
En un Pulldown o Popup MenuPane, despublica todos los menús de la jerarquía de menús y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de entrar al sistema de menús. Llama a las callbacks de XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a las callbacks de ayuda del ancestro más cercano que las tenga.
<Key><osfActivate>:
En un menú, esta acción despublica todos los menús de la jerarquía de menús. A menos que el botón ya esté armado, esta acción llama a las callbacks de XmNarmCallback; y llama a las callbacks de XmNvalueChangedCallback y XmNdisarmCallback. Fuera de un menú, si el padre es un gestor, esta acción pasa el evento al padre.
<Key><osfSelect>:
Si el ToggleButtonGadget estaba configurado previamente, esta acción lo desconfigura; si el ToggleButtonGadget no estaba configurado previamente, esta acción lo configura.
En un menú, esta acción despublica todos los menús de la jerarquía de menús. A menos que el botón ya esté armado, esta acción llama a las callbacks de XmNarmCallback, XmNvalueChangedCallback y XmNdisarmCallback.
Fuera de un menú, si el botón no estaba configurado previamente, esta acción realiza lo siguiente: Si XmNindicatorOn es True, dibuja la sombra del indicador para que parezca presionado; si XmNfillOnSelect es True, rellena el indicador con el color especificado por XmNselectColor. Si XmNindicatorOn es False, dibuja la sombra del botón para que parezca presionado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNselectPixmap como cara del botón. Esta acción llama a las callbacks de XmNarmCallback, XmNvalueChangedCallback, XmNdisarmCallback.
Fuera de un menú, si el botón estaba configurado previamente, esta acción realiza lo siguiente: Si tanto XmNindicatorOn como XmNvisibleWhenOff son True, dibuja la sombra del indicador para que parezca levantado; si XmNfillOnSelect es True, rellena el indicador con el color de fondo. Si XmNindicatorOn es False, dibuja la sombra del botón para que parezca levantado. Si XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING, se utiliza XmNlabelPixmap como cara del botón. Llama a las callbacks de XmNarmCallback, XmNvalueChangedCallback y XmNdisarmCallback.
<Key><osfCancel>:
En un Pulldown MenuPane de nivel superior de una MenuBar, despublica el menú, desarma el CascadeButton de la MenuBar y la MenuBar, y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de entrar a la MenuBar. En otros Pulldown MenuPanes, esta acción despublica el menú. Fuera de un menú, si el padre es un gestor, esta acción pasa el evento al padre.
En un Popup MenuPane, esta acción despublica el menú y restaura el foco del teclado al widget desde el cual se publicó el menú.
<Enter>:
En un menú, si el recorrido del teclado está habilitado, esta acción no hace nada. De lo contrario, dibuja la sombra en el estado armado y llama a las callbacks de XmNarmCallback.
Si el ToggleButtonGadget no está en un menú y el cursor sale y luego vuelve a entrar al ToggleButtonGadget mientras el botón está presionado, esta acción restaura la apariencia armada del botón.
<Leave>:
En un menú, si el recorrido del teclado está habilitado, esta acción no hace nada. De lo contrario, dibuja la sombra en el estado desarmado y llama a las callbacks de XmNdisarmCallback.
Si el ToggleButtonGadget no está en un menú y el cursor sale del ToggleButtonGadget mientras el botón está presionado, esta acción restaura la apariencia desarmada del botón.
