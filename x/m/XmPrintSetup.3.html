XmPrintSetup(llamada a biblioteca) XmPrintSetup(llamada a biblioteca)

NOMBRE

XmPrintSetup — configuración y creación de un widget Print Shell

SINOPSIS

#include <Xm/Print.h>
Widget XmPrintSetup(
Widget video_widget,
Screen *print_screen,
String print_shell_name,
ArgList args,
Cardinal num_args);

DESCRIPCIÓN

Una función que realiza la configuración adecuada y crea un XmPrintShell realizado que devuelve al llamador. Esta función oculta los detalles de Xt para configurar una jerarquía de impresión válida para la aplicación. También está pensada para fomentar la consistencia en la forma en que las aplicaciones enraízan su jerarquía de widgets de impresión.

print_screen debe pertenecer a una conexión de Display que ya haya sido inicializada con Xt.

El video_widget se utiliza para acceder al contexto de la aplicación, el nombre y la clase de la aplicación, y argc/argv almacenados en el applicationShell que es la raíz de este widget. Si no se encuentra ningún applicationShell, se utilizan NULL argv/argc.

XmPrintSetup crea entonces un ApplicationShell no realizado con el mismo nombre y clase que el proporcionado por la pantalla de vídeo, en la pantalla de impresión y en la pantalla de impresión especificada.

Luego se crea un XmPrintShell como hijo de este shell de nivel superior, usando XtCreatePopupShell, con el nombre print_shell_name, y utilizando los args proporcionados. Luego realiza y mapea el shell de impresión, usando XtPopup con XtGrabNone.

De esta manera, los archivos de recursos de la aplicación y los usuarios pueden especificar atributos específicos de impresión utilizando la siguiente sintaxis (si print_shell_name es "Print"):

Dtpad.Print*textFontList: somefont
*Print*background:white
*Print*highlightThickness:0
video_widget
Un widget de video para obtener datos de video de la aplicación.
print_screen
Una pantalla de impresión en la conexión de impresión - especifica la pantalla en la que se crea el nuevo shell.
print_shell_name
Especifica el nombre del XmPrintShell creado en el servidor de impresión X.
args
Especifica la lista de argumentos de la que se obtendrán los recursos para el XmPrintShell.
num_args
Especifica el número de argumentos en la lista de argumentos.

VALOR DE RETORNO

El ID del widget XmPrintShell creado en la conexión del servidor de impresión X, o NULL si ha ocurrido un error.

ERRORES/ADVERTENCIAS

Ninguno.

EJEMPLOS

Desde la devolución de llamada OK y la devolución de llamada SetUp del widget de diálogo de impresión principal:

static void
printOKCB(Widget, XtPointer call_data, XtPointer client_data)
{
  AppPrint *p = (AppPrint *) client_data;
  DtPrintSetupCallbackStruct *pbs =
                         (XmPrintCallbackStruct *) call_data;
  /* conectar si aún no se ha hecho.
     la devolución de llamada del diálogo de impresión siempre proporciona
             un nombre de impresora, pantalla de impresión y pantalla
             ya inicializadas: XpInitContext llamado */
 */
  p->print_shell = XmPrintSetup (widget, pbs->print_screen,
                                              "Print", NULL, 0);
  ...
}
