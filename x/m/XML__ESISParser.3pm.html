NOMBRE

XML::ESISParser - Analizador SAX de Perl usando nsgmls

SINOPSIS

use XML::ESISParser;
$parser = XML::ESISParser->new( [OPCIONES] );
$result = $parser->parse( [OPCIONES] );
$result = $parser->parse($cadena);

DESCRIPCIÓN

"XML::ESISParser" es un analizador SAX de Perl que utiliza el comando `nsgmls' del Analizador XML y SGML de James Clark (SP), un analizador validador de XML y SGML. Esta página del manual resume las opciones, manejadores y propiedades específicas compatibles con "XML::ESISParser"; por favor, consulte el estándar SAX de Perl en `"SAX.pod"' para obtener información general sobre su uso.

"XML::ESISParser" está configurado por defecto para analizar XML y tiene una opción para analizar SGML.

El código fuente de `"nsgmls"', y binarios para algunas plataformas, está disponible en http://www.jclark.com/. `"nsgmls"' está incluido tanto en los paquetes SP como en los paquetes Jade.

MÉTODOS

new
Crea un nuevo objeto analizador. Las opciones por defecto para el análisis, descritas a continuación, se pasan como pares clave-valor o como un solo hash. Las opciones se pueden cambiar directamente en el objeto analizador a menos que se indique lo contrario. Las opciones pasadas a `parse()' anulan las opciones por defecto en el objeto analizador durante la duración del análisis.

OPCIONES

Las siguientes opciones son compatibles con "XML::ESISParser":

Handler          manejador por defecto para recibir eventos
DocumentHandler  manejador para recibir eventos de documento
DTDHandler       manejador para recibir eventos de DTD
ErrorHandler     manejador para recibir eventos de error
Source           hash que contiene la fuente de entrada para el análisis
IsSGML           el documento a analizar está en SGML

Si no se proporcionan manejadores, todos los eventos serán ignorados silenciosamente.

Si se pasa un único argumento de cadena al método `parse()', se trata como si se hubiera dado una opción `"Source"' con un parámetro `"String"'.

El hash `"Source"' puede contener los siguientes parámetros:

ByteStream       El flujo de bytes crudos (manejador de archivo) que contiene el
                 documento.
String           Una cadena que contiene el documento.
SystemId         El identificador de sistema (URI) del documento.

Si se especifican más de uno de `"ByteStream"', `"String"', o `"SystemId"', la preferencia se da primero a `"ByteStream"', luego a `"String"', y luego a `"SystemId"'.

MANEJADORES

Los siguientes manejadores y propiedades son compatibles con "XML::ESISParser":

Métodos DocumentHandler

start_document
Recibe notificación del inicio de un documento.

No hay propiedades definidas.

end_document
Recibe notificación del final de un documento.

No hay propiedades definidas.

start_element
Recibe notificación del inicio de un elemento. 
Name             El nombre del tipo de elemento.
Attributes       Un hash que contiene los atributos adjuntos al
                 elemento, si los hay.
IncludedSubelement Este elemento es un subelemento incluido.
Empty            Este elemento está declarado como vacío.

El hash `"Attributes"' contiene solo valores de cadena. La bandera `"Empty"' no se establece para un elemento que simplemente no tiene contenido, solo se establece si la DTD lo declara vacío.

BETA: Los valores de los atributos actualmente no expanden entidades SData en objetos de entidad, todavía están en la notación de datos del sistema utilizada por nsgmls (dentro de `|'). Una versión futura de XML::ESISParser también convertirá otros tipos de atributos en sus respectivos objetos, actualmente solo se dan sus nombres de notación o entidad.

end_element
Recibe notificación del final de un elemento. 
Name             El nombre del tipo de elemento.
characters
Recibe notificación de datos de caracteres. 
Data             Los caracteres del documento.
record_end
Recibe notificación de una secuencia de fin de registro. Las aplicaciones XML deben convertir esto a una nueva línea.
processing_instruction
Recibe notificación de una instrucción de procesamiento. 
Target           El objetivo de la instrucción de procesamiento en XML.
Data             Los datos de la instrucción de procesamiento, si los hay.
internal_entity_ref
Recibe notificación de una referencia a una entidad interna de datos del sistema (SData). 
Name             El nombre de la referencia a la entidad interna.
external_entity_ref
Recibe notificación de una referencia a una entidad externa. 
Name             El nombre de la referencia a la entidad externa.
start_subdoc
Recibe notificación del inicio de un subdocumento. 
Name             El nombre de la referencia a la entidad externa.
end_subdoc
Recibe notificación del final de un subdocumento. 
Name             El nombre de la referencia a la entidad externa.
conforming
Recibe notificación de que el documento recién analizado se ajusta a su declaración de tipo de documento (DTD).

No hay propiedades definidas.

Métodos DTDHandler

external_entity_decl
Recibe notificación de una declaración de entidad externa. 
Name             El nombre de la entidad.
Type             El tipo de entidad (CDATA, NDATA, etc.)
SystemId         El identificador del sistema de la entidad.
PublicId         El identificador público de la entidad, si existe.
GeneratedId      Identificadores del sistema generados, si existen.
internal_entity_decl
Recibe notificación de una declaración de entidad interna. 
Name             El nombre de la entidad.
Type             El tipo de entidad (CDATA, NDATA, etc.)
Value            El valor de caracteres de la entidad.
notation_decl
Recibe notificación de una declaración de notación. 
Name             El nombre de la notación.
SystemId         El identificador del sistema de la notación.
PublicId         El identificador público de la notación, si existe.
GeneratedId      Identificadores del sistema generados, si existen.
subdoc_entity_decl
Recibe notificación de una declaración de entidad de subdocumento. 
Name             El nombre de la entidad.
SystemId         El identificador del sistema de la entidad.
PublicId         El identificador público de la entidad, si existe.
GeneratedId      Identificadores del sistema generados, si existen.
external_sgml_entity_decl
Recibe notificación de una declaración de entidad SGML externa. 
Name             El nombre de la entidad.
SystemId         El identificador del sistema de la entidad.
PublicId         El identificador público de la entidad.
's identificador público, si existe. GeneratedId Identificadores de sistema generados, si existen.
