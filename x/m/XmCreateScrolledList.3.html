Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmCreateScrolledList(llamada a biblioteca) XmCreateScrolledList(llamada a biblioteca)

NOMBRE

XmCreateScrolledList — La función de creación conveniente de List ScrolledList

SINOPSIS

#include <Xm/List.h>
Widget XmCreateScrolledList(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateScrolledList crea una instancia de un widget List que está contenido dentro de un ScrolledWindow. El padre ScrolledWindow se crea gestionado. Todos los widgets de subárea de ScrolledWindow son creados automáticamente por esta función. El ID devuelto por esta función es el del widget List (no el del widget ScrolledWindow). Utilice este ID de widget para todas las operaciones en el widget List. Utilice el ID del widget padre del widget List para todas las operaciones en el ScrolledWindow. Para obtener el ID del widget ScrolledWindow asociado con el widget List, utilice la función XtParent de Xt Intrinsics. El nombre del ScrolledWindow creado por esta función se forma concatenando SW al final del nombre especificado en la lista de parámetros.

Todos los argumentos para el widget List o ScrolledWindow se pueden especificar en el momento de la creación utilizando esta función. Los cambios en la posición y el tamaño iniciales se envían solo al widget ScrolledWindow. Otros recursos se envían al widget List o ScrolledWindow según corresponda. Tenga en cuenta que el resultado de proporcionar el recurso XmNdestroyCallback en la lista de argumentos de creación (arglist) no está especificado. La aplicación debe utilizar la función XtAddCallback para añadir callbacks al widget apropiado (List o ScrolledWindow) después de crearlo.

Esta función fuerza los siguientes valores iniciales para los recursos de ScrolledWindow:

•
XmNscrollingPolicy se establece en XmAPPLICATION_DEFINED.
•
XmNvisualPolicy se establece en XmVARIABLE.
•
XmNscrollBarDisplayPolicy se establece en XmSTATIC. (No se fuerza ningún valor inicial para el XmNscrollBarDisplayPolicy de List.)
•
XmNshadowThickness se establece en 0 (cero).
parent
Especifica el ID del widget padre
name
Especifica el nombre del widget creado
arglist
Especifica la lista de argumentos
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist)

Para una definición completa de List y sus recursos asociados, consulte XmList(3).

RETORNO

Devuelve el ID del widget List.

RELACIONADO

XmList(3) y XmScrolledWindow(3).
