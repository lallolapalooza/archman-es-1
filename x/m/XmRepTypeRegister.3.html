NOMBRE

XmRepTypeRegister — Una función del gestor de tipos de representación que registra un recurso de tipo de representación

SINOPSIS

#include <Xm/RepType.h>
XmRepTypeId XmRepTypeRegister(
String rep_type,
String *value_names,
unsigned char *values,
unsigned char num_values);

DESCRIPCIÓN

XmRepTypeRegister registra un recurso de tipo de representación con el gestor de tipos de representación. Todas las características de la instalación de gestión de tipos de representación estarán disponibles para el tipo de representación especificado. La función instala un convertidor de tipo hacia adelante para convertir valores de cadena en valores numéricos de tipo de representación.

Cuando el argumento values es NULL, se asumen valores numéricos consecutivos. El orden de las cadenas en la matriz value_names determina los valores numéricos para el recurso. Por ejemplo, el primer nombre de valor es 0 (cero); el segundo nombre de valor es 1; y así sucesivamente.

Si no es NULL, el argumento values puede usarse para asignar valores a tipos de representación que tienen valores no consecutivos o nombres duplicados para el mismo valor. Los tipos de representación registrados de esta manera consumirán almacenamiento adicional y serán ligeramente más lentos que los tipos de representación con valores consecutivos.

Un tipo de representación solo se puede registrar una vez; si el mismo nombre de tipo de representación se registra más de una vez, el comportamiento no está definido.

La función XmRepTypeAddReverse instala un convertidor inverso para un tipo de representación registrado. El convertidor inverso toma un valor numérico de tipo de representación y devuelve el valor de cadena correspondiente. Si la lista de valores numéricos para un tipo de representación contiene valores duplicados, el convertidor inverso utiliza el primer nombre en la lista value_names que coincide con el valor numérico especificado. Por ejemplo, si una matriz value_names tiene cancel, proceed, y abort, y la matriz values correspondiente contiene 0, 1 y 0, el convertidor inverso devolverá cancel en lugar de abort para un valor de entrada de 0.

rep_type
Especifica el nombre del tipo de representación.
value_names
Especifica un puntero a una matriz de nombres de valores asociados con el tipo de representación. Un nombre de valor se especifica en caracteres minúsculos sin el prefijo Xm. Las palabras dentro de un nombre se separan con guiones bajos.
values
Especifica un puntero a una matriz de valores asociados con el tipo de representación. Un valor en esta matriz se asocia con el nombre de valor en la posición correspondiente de la matriz value_names.
num_values
Especifica el número de entradas en las matrices value_names y values.

RETORNO

Devuelve el número de identificación para el tipo de representación especificado.
