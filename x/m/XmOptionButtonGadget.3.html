Licencias: LGPL-2.1-or-later

XmOptionButtonGadget(llamada de biblioteca) XmOptionButtonGadget(llamada de biblioteca)

NOMBRE

XmOptionButtonGadget — Una función de RowColumn que obtiene el ID del widget para el CascadeButtonGadget en un OptionMenu

SINOSIS

#include <Xm/RowColumn.h>
Widget XmOptionButtonGadget(
Widget option_menu);

DESCRIPCIÓN

XmOptionButtonGadget proporciona a la aplicación los medios para obtener el ID del widget del CascadeButtonGadget creado internamente. Una vez que la aplicación ha obtenido el ID del widget, puede ajustar la apariencia del CascadeButtonGadget, si lo desea.

Cuando una aplicación crea una instancia del widget OptionMenu, el widget crea dos gadgets internos. Uno es un LabelGadget que se utiliza para mostrar el recurso XmNlabelString de RowColumn. El otro es un CascadeButtonGadget que muestra la selección actual y proporciona los medios para mostrar el submenú del OptionMenu.

El usuario puede especificar recursos en un archivo de recursos para los widgets y gadgets creados automáticamente de un OptionMenu. La siguiente lista identifica los nombres de estos widgets (o gadgets) y las áreas asociadas del OptionMenu.

Etiqueta del Menú de Opciones Gadget
OptionLabel
Botón de Cascada del Menú de Opciones
OptionButton
ID del widget option_menu
Especifica el ID del widget OptionMenu

Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget para el botón interno.

RELACIONADOS

XmCreateOptionMenu(3), XmCascadeButtonGadget(3), XmOptionLabelGadget(3), y XmRowColumn(3).
