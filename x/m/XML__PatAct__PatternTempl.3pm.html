NOMBRE

XML::PatAct::PATTERN - Un módulo de patrón para

SINOPSIS

use XML::PatAct::PATTERN;
my $patterns = [ PATTERN => ACTION,
                 ... ]
my $matcher = XML::PatAct::PATTERN->new( Patterns => $patterns );

DESCRIPCIÓN

XML::PatAct::PATTERN es un módulo de patrón para usar con módulos de acción PatAct para aplicar listas de patrón-acción a análisis o árboles XML. XML::PatAct::PATTERN ...

Los parámetros se pueden pasar como una lista de pares clave, valor o un hash.
