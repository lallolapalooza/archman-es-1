NOMBRE

XmRepTypeGetRecord — Función del gestor de tipos de representación que devuelve información sobre un tipo de representación

SINOPSIS

#include <Xm/RepType.h>
XmRepTypeEntry XmRepTypeGetRecord(
XmRepTypeId rep_type_id);

DESCRIPCIÓN

XmRepTypeGetRecord recupera información sobre un tipo de representación particular que está registrado en el gestor de tipos de representación. Esta rutina asigna memoria para los datos devueltos. La aplicación debe liberar esta memoria utilizando XtFree.

rep_type_id
El número de identificación del tipo de representación

La estructura de entrada del tipo de representación contiene la siguiente información:

typedef struct
{
        String  rep_type_name;
        String  *value_names;
        unsigned char   *values;
        unsigned char   num_values;
        Boolean reverse_installed;
        XmRepTypeId     rep_type_id;
} XmRepTypeEntryRec, *XmRepTypeEntry;
(void)
rep_type_name
El nombre del tipo de representación
value_names
Una matriz de nombres de valores de tipo de representación
values
Una matriz de valores numéricos de tipo de representación
num_values
El número de valores asociados con el tipo de representación
reverse_installed
Un indicador que señala si el convertidor inverso está instalado o no
rep_type_id
El número de identificación del tipo de representación

DEVOLVER

Devuelve un puntero a la estructura de entrada del tipo de representación que describe el tipo de representación.

RELACIONADOS

XmRepTypeGetId(3), XmRepTypeGetRegistered(3) y XmRepTypeRegister(3).
