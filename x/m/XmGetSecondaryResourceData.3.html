NOMBRE

XmGetSecondaryResourceData — Función que proporciona acceso a los datos de recursos secundarios de un widget

SINOPSIS

#include <Xm/Xm.h>
Cardinal XmGetSecondaryResourceData(
WidgetClass widget_class,
XmSecondaryResourceData **secondary_data_return);

DESCRIPCIÓN

Algunas clases de widgets de Motif (como Gadget, Text y VendorShell) tienen recursos que no son accesibles a través de las funciones XtGetResourceList y XtGetConstraintResourceList. Para recuperar las descripciones de estos recursos, una aplicación debe usar XmGetSecondaryResourceData.

Cuando una clase de widget tiene dichos recursos, esta función proporciona descripciones de los recursos en una o más estructuras de datos. XmGetSecondaryResourceData toma un argumento de clase de widget y devuelve el número de estas estructuras de datos asociadas con la clase de widget. Si el valor de retorno es mayor que 0 (cero), la función asigna y rellena una matriz de punteros a las estructuras de datos correspondientes. Devuelve esta matriz en la dirección que es el valor del argumento secondary_data_return.

El tipo XmSecondaryResourceData es un puntero a una estructura con dos miembros que son útiles para una aplicación: resources, de tipo XtResourceList, y num_resources, de tipo Cardinal. El miembro resources es una lista de los recursos del widget que no son accesibles usando funciones Xt. El miembro num_resources es la longitud de la lista resources.

Si el valor de retorno es mayor que 0 (cero), XmGetSecondaryResourceData asigna memoria que la aplicación debe liberar. Utilice XtFree para liberar la lista de recursos en cada estructura (el valor del miembro resources), las estructuras mismas y la matriz de punteros a las estructuras (la matriz cuya dirección es secondary_data_return).

widget_class
Especifica la clase de widget para la cual se recuperarán los datos de recursos secundarios.
secondary_data_return
Especifica un puntero a una matriz de punteros XmSecondaryResourceData que será devuelta por esta función. Si la clase de widget no tiene datos de recursos secundarios, por ejemplo, si el valor devuelto por la función es 0 (cero), la función no devuelve ningún valor significativo para este argumento.

DEVOLVER

Devuelve el número de estructuras de datos de recursos secundarios asociadas con esta clase de widget.

EJEMPLO

El siguiente ejemplo utiliza XmGetSecondaryResourceData para imprimir los nombres de los recursos secundarios del widget Motif Text y luego libera los datos asignados por la función:

XmSecondaryResourceData * block_array;
Cardinal num_blocks, i, j;
if (num_blocks = XmGetSecondaryResourceData (xmTextWidgetClass,
                                             &block_array)) {
  for (i = 0; i < num_blocks; i++) {
    for (j = 0; j < block_array[i]->num_resources; j++) {
      printf("%s\n", block_array[i]->resources[j].resource_name);
    }
    XtFree((char*)block_array[i]->resources);
    XtFree((char*)block_array[i]);
  }
  XtFree((char*)block_array);
}
