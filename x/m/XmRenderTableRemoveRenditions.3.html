NOMBRE

XmRenderTableRemoveRenditions — Una función de conveniencia que elimina representaciones

SINOPSIS

#include <Xm/Xm.h>
XmRenderTable XmRenderTableRemoveRenditions(
XmRenderTable oldtable,
XmStringTag *tags,
int tag_count);

DESCRIPCIÓN

XmRenderTableRemoveRenditions elimina de oldtable las representaciones cuyas etiquetas coinciden con las etiquetas especificadas en tags, luego coloca las representaciones restantes en una tabla de representaciones recién creada.

oldtable
Especifica la tabla de representaciones de la cual se eliminarán las representaciones. Esta función libera la tabla de representaciones original y las representaciones coincidentes después de extraer la información requerida.
tags
Especifica un array de etiquetas, cuyas representaciones correspondientes se eliminarán de oldtable.
tag_count
Especifica el número de etiquetas en tags.

RETORNO

Si oldtable o tags es NULL, o tag_count es 0 (cero), o no se eliminan representaciones de oldtable, esta función devuelve oldtable. De lo contrario, devuelve una XmRenderTable recién asignada. La aplicación es responsable de gestionar esta tabla de representaciones asignada. La aplicación puede liberar este espacio asignado llamando a XmRenderTableFree.

RELACIONADO

XmRendition(3) y XmRenderTableFree(3).
