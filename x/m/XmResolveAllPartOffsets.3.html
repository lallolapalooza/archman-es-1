XmResolveAllPartOffsets(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmResolveAllPartOffsets(llamada a biblioteca) XmResolveAllPartOffsets(llamada a biblioteca)

NOMBRE

XmResolveAllPartOffsets — Una función que permite escribir aplicaciones y widgets compatibles hacia arriba

SINOPSIS

#include <Xm/Xm.h>
void XmResolveAllPartOffsets(
WidgetClass widget_class,
XmOffsetPtr * offset,
XmOffsetPtr * constraint_offset);

DESCRIPCIÓN

Nota:

Esta rutina es obsoleta y existe por compatibilidad con versiones anteriores. Debe llamar a XmeResolvePartOffsets en su lugar.

El uso de registros de desplazamiento requiere dos variables globales adicionales por clase de widget. Las variables consisten en punteros a arreglos de desplazamientos dentro del registro del widget y del registro de restricciones para cada parte de la estructura del widget. La función XmResolveAllPartOffsets asigna los registros de desplazamiento necesarios para que una aplicación garantice un acceso compatible hacia arriba a los registros de instancia y de restricciones del widget por parte de aplicaciones y widgets. Estos registros de desplazamiento son utilizados por el widget para acceder a todas las variables del widget. Un widget necesita realizar los pasos descritos en los siguientes párrafos.

En lugar de crear una lista de recursos, el widget crea una lista de recursos de desplazamiento. Para lograr esto, use la estructura XmPartResource y la macro XmPartOffset. La estructura de datos XmPartResource se ve igual que una lista de recursos, pero en lugar de tener un entero para su desplazamiento, tiene dos shorts. Esta estructura se inserta en el registro de clase como si fuera una lista de recursos normal. En lugar de usar XtOffset para el desplazamiento, el widget usa XmPartOffset.

Si el widget es una subclase de la clase Constraint y define recursos de restricción adicionales, cree también una lista de recursos de desplazamiento para la parte de restricción. En lugar de usar XtOffset para el desplazamiento, el widget usa XmConstraintPartOffset en la lista de recursos de restricción.

XmPartResource resources[] = {
        {       BarNxyz, BarCXyz, XmRBoolean, sizeof(Boolean),
                XmPartOffset(Bar,xyz), XmRImmediate, (XtPointer)False } };
XmPartResource constraints[] = {
        {       BarNmaxWidth, BarNMaxWidth,
          XmRDimension, sizeof(Dimension),
          XmConstraintPartOffset(Bar,max_width),
          XmRImmediate, (XtPointer)100 } };

En lugar de colocar el tamaño del widget en el registro de clase, el widget coloca el tamaño de la parte del widget en el mismo campo. Si el widget es una subclase de la clase Constraint, en lugar de colocar el tamaño del registro de restricciones del widget en el registro de clase, el widget coloca el tamaño de la parte de restricciones del widget en el mismo campo.

En lugar de colocar XtVersion en el registro de clase, el widget coloca XtVersionDontCheck en el registro de clase.

Defina una variable, de tipo XmOffsetPtr, para que apunte al registro de desplazamiento. Si el widget es una subclase de la clase Constraint, defina una variable de tipo XmOffsetPtr para que apunte al registro de desplazamiento de restricciones. Estas pueden ser parte del registro de clase del widget o variables globales separadas.

En la inicialización de clase, el widget llama a XmResolveAllPartOffsets, pasándole punteros al registro de clase, la dirección del registro de desplazamiento y la dirección del registro de desplazamiento de restricciones. Si el widget no es una subclase de la clase Constraint, debe pasar NULL como la dirección del registro de desplazamiento de restricciones. Esto hace varias cosas:

•
Suma el campo de tamaño de la superclase (que, por definición, ya ha sido inicializado) al campo de tamaño de la parte
•
Si el widget es una subclase de la clase Constraint, suma el campo de tamaño de restricciones de la superclase al campo de tamaño de restricciones
•
Asigna un arreglo basado en el número de superclases
•
Si el widget es una subclase de la clase de restricciones, asigna un arreglo para el registro de desplazamiento de restricciones
•
Rellena los desplazamientos de todas las partes del widget y las partes de restricciones con los valores apropiados, determinados al examinar los campos de tamaño de todos los registros de superclases
•
Utiliza el arreglo de desplazamientos de partes para modificar las entradas de desplazamiento en la lista de recursos a desplazamientos reales, en su lugar

El widget define una constante que será el índice de su parte de estructura en el arreglo de desplazamientos. El valor debe ser 1 mayor que el índice de la superclase del widget. Las constantes definidas para todos los widgets de Xm se encuentran en XmP.h.

#define BarIndex (XmBulletinBIndex + 1)

En lugar de acceder a los campos directamente, el widget debe pasar siempre a través de la tabla de desplazamientos. Las macros XmField y XmConstraintField le ayudan a acceder a estos campos. Debido a que las macros XmPartOffset, XmConstraintPartOffset, XmField y XmConstraintField concatenan elementos, debe asegurarse de que no haya espacios después de la parte del argumento. Por ejemplo, las siguientes macros no funcionan debido al espacio después del argumento de la parte (Label):

XmField(w, offset, Label, text, char *)
XmPartOffset(Label, text).

Por lo tanto, no debe haber ningún espacio después del argumento de la parte (Label), como se ilustra aquí:

XmField(w, offset, Label, text, char *)

Puede definir macros para cada campo para facilitar esto. Suponga un campo entero xyz:

#define BarXyz(w) (*(int *)(((char *) w) + \
        offset[BarIndex] + XtOffset(BarPart,xyz)))

Para el campo de restricción max_width:

#define BarMaxWidth(w) \
        XmConstraintField(w,constraint_offsets,Bar,max_width,Dimension)

Los parámetros para XmResolveAllPartOffsets son

widget_class
Especifica el puntero a la clase del widget para el widget creado
offset
Devuelve el registro de desplazamiento
constraint_offset
Devuelve el registro de desplazamiento de restricciones
