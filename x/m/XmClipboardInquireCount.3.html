NOMBRE

XmClipboardInquireCount — Una función del portapapeles que devuelve el número de formatos de elementos de datos

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardInquireCount (display, window, count,
        max_format_name_length)
        Display * display;
        Window  window;
        int     * count;
        unsigned long   * max_format_name_length;
(void)

DESCRIPCIÓN

XmClipboardInquireCount devuelve el número de formatos de elementos de datos disponibles para el elemento de datos en el portapapeles. Esta función también devuelve la longitud máxima del nombre para todos los formatos en los que se almacena el elemento de datos.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llama.
count
Devuelve el número de formatos de elementos de datos disponibles para el elemento de datos en el portapapeles. Si no hay formatos disponibles, este argumento es igual a 0 (cero). El recuento incluye los formatos que se pasaron por nombre.
max_format_name_length
Especifica la longitud máxima de todos los nombres de formato para el elemento de datos en el portapapeles.

RETORNO

XmClipboardSuccess
La función se realizó con éxito.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función de nuevo con los mismos parámetros hasta que desaparezca el bloqueo. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o abandonar la operación.
XmClipboardNoData
La función no pudo encontrar datos en el portapapeles que correspondieran al formato solicitado. Esto podría ocurrir porque el portapapeles está vacío; hay datos en el portapapeles, pero no en el formato solicitado; o los datos en el formato solicitado se pasaron por nombre y ya no están disponibles.
