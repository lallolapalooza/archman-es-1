XML::Atom::Client(3pm) Documentación de Perl contribuida por el usuario XML::Atom::Client(3pm)

NOMBRE

XML::Atom::Client - Un cliente para la API de Atom

SINOPSIS

use XML::Atom::Client;
use XML::Atom::Entry;
my $api = XML::Atom::Client->new;
$api->username('Melody');
$api->password('Nelson');
my $entry = XML::Atom::Entry->new;
$entry->title('New Post');
$entry->content('Content of my post.');
my $EditURI = $api->createEntry($PostURI, $entry);
my $feed = $api->getFeed($FeedURI);
my @entries = $feed->entries;
my $entry = $api->getEntry($EditURI);

DESCRIPCIÓN

XML::Atom::Client implementa un cliente para la API de Atom descrita en http://bitworking.org/projects/atom/draft-gregorio-09.html, con el esquema de autenticación descrito en http://www.intertwingly.net/wiki/pie/DifferentlyAbledClients.

NOTA: La API, y en particular el esquema de autenticación, aún están en proceso de cambio.

USO

XML::Atom::Client->new(%param)

$api->use_soap([ 0 | 1 ])

XML::Atom::Client soporta tanto la versión REST como la versión con envoltorio SOAP de la API de Atom. Por defecto, se utilizará la versión REST de la API, pero puedes activar el envoltorio SOAP —por ejemplo, si necesitas conectarte a un servidor que solo soporta el envoltorio SOAP— llamando a use_soap con un valor de 1:

$api->use_soap(1);

Si se llama sin argumentos, devuelve el valor actual de la bandera.

$api->username([ $username ])

Si se llama con un argumento, establece el nombre de usuario para el inicio de sesión a $username.

Devuelve el nombre de usuario actual que se utilizará al iniciar sesión en el servidor de Atom.

$api->password([ $password ])

Si se llama con un argumento, establece la contraseña para el inicio de sesión a $password.

Devuelve la contraseña actual que se utilizará al iniciar sesión en el servidor de Atom.

$api->createEntry($PostURI, $entry)

Crea una nueva entrada.

$entry debe ser un objeto XML::Atom::Entry.

$api->getEntry($EditURI)

Recupera la entrada con la URL dada $EditURI.

Devuelve un objeto XML::Atom::Entry.

$api->updateEntry($EditURI, $entry)

Actualiza la entrada en la URL $EditURI con la entrada $entry, que debe ser un objeto XML::Atom::Entry.

Devuelve verdadero en caso de éxito, falso en caso contrario.

$api->deleteEntry($EditURI)

Elimina la entrada en la URL $EditURI.

$api->getFeed($FeedURI)

Recupera el feed en $FeedURI.

Devuelve un objeto XML::Atom::Feed que representa el feed devuelto por el servidor.

MANEJO DE ERRORES

Los métodos devuelven "undef" en caso de error, y el mensaje de error se puede obtener utilizando el método errstr.
