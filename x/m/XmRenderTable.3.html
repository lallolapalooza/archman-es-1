XmRenderTable(llamada a librería) XmRenderTable(llamada a librería)

NOMBRE

XmRenderTable -- tipo de dato para una tabla de renderizado

SINOPSIS

#include <Xm/Xm.h>
XmRenderTable

DESCRIPCIÓN

XmRenderTable es el tipo de dato para una tabla de renderizado, la cual contiene una tabla de renderizados (XmRenditions). Cada renderizado consiste en un conjunto de atributos para renderizar texto, incluyendo una fuente o conjunto de fuentes, colores, tabulaciones y líneas. Cada renderizado se identifica con una etiqueta.

Cuando se muestra una cadena compuesta, para cada segmento de la cadena, el renderizado que se utiliza para mostrar esa cadena se forma de la siguiente manera. Si el segmento tiene al menos una etiqueta de inicio de renderizado o si la lista de etiquetas formada al acumular desde segmentos anteriores las etiquetas de inicio de renderizado y eliminar las etiquetas de fin de renderizado no está vacía, estas etiquetas se emparejan con los renderizados en la tabla de renderizado. El renderizado efectivo utilizado para renderizar el segmento se forma fusionando sucesivamente cada renderizado encontrado en el renderizado actual con valores que no sean XmAS_IS (XmUNSPECIFIED_PIXEL para recursos de color), reemplazando así los valores correspondientes de los recursos en el renderizado a fusionar. Finalmente, si el renderizado resultante todavía tiene recursos con valores no especificados y el segmento tiene una etiqueta de localización o conjunto de caracteres (estas son opcionales y mutuamente excluyentes), esta etiqueta se empareja con un renderizado en la tabla de renderizado y los valores faltantes del renderizado se completan a partir de esa entrada.

Si no se encuentra ningún renderizado coincidente para una etiqueta particular, se llama a XmNnoRenditionCallback del objeto XmDisplay y se vuelve a buscar en la tabla de renderizado esa etiqueta.

Si el renderizado resultante no especifica una fuente o conjunto de fuentes, entonces para los segmentos cuyo tipo de texto es XmCHARSET_TEXT, se buscará en la tabla de renderizado un renderizado etiquetado con XmFONTLIST_DEFAULT_TAG, y si se encuentra un renderizado coincidente, se fusionará en el renderizado actual. Si el renderizado resultante no contiene ninguna fuente, se llamará a XmNnoFontCallback con el renderizado predeterminado y "" como nombre de fuente. Si no se encuentra ningún renderizado coincidente o no se encuentra ninguna fuente después de la llamada de retorno, se fusionará el primer renderizado de la tabla de renderizado en el renderizado actual. Si este renderizado aún no tiene fuente, el segmento no se renderizará y se emitirá una advertencia.

Para los segmentos cuyo tipo de texto es XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT, se buscará en la tabla de renderizado un renderizado etiquetado con _MOTIF_DEFAULT_LOCALE, y si se encuentra un renderizado coincidente, se fusionará en el renderizado actual. Si el renderizado resultante no contiene ninguna fuente, se llamará a XmNnoFontCallback con el renderizado predeterminado y "" como nombre de fuente. Una aplicación puede hacer que esta llamada de retorno intente solucionar este problema llamando a XmRenditionUpdate en el renderizado de entrada para proporcionar una fuente que el widget pueda usar. Esto se puede hacer proporcionando un nombre de fuente alternativo para cargar utilizando los recursos XmNfontName y XmNfontType o con una fuente ya cargada utilizando el recurso XmNfont. Si no se encuentra ningún renderizado coincidente o no se encuentra ninguna fuente después de la llamada de retorno, el segmento no se renderizará y se emitirá una advertencia.

Las tablas de renderizado se especifican en archivos de recursos con la siguiente sintaxis:

especificación_recurso: [ etiqueta [, etiqueta ]* ]

donde etiqueta es una cadena adecuada para el recurso XmNtag de un renderizado.

Si no se especifican etiquetas, se creará una tabla de renderizado que estará vacía o contendrá solo un renderizado con la etiqueta _MOTIF_DEFAULT_LOCALE.

Los valores específicos para recursos de renderizado específicos se especifican utilizando la siguiente sintaxis:

especificación_recurso [*|.] renderizado[*|.] nombre_recurso: valor

donde:

especificación_recurso
Especifica la tabla de renderizado.
renderizado
Es la clase Rendition o una etiqueta.
nombre_recurso
Es la clase o el nombre de un recurso particular.
valor
Es la especificación del valor a establecer.

Cualquier línea de recurso que consista solo en un componente de nombre o clase de recurso sin un componente de renderizado o enlace suelto se asumirá que especifica valores de recurso para un renderizado con la etiqueta _MOTIF_DEFAULT_LOCALE. En efecto, esto crea un renderizado predeterminado de manera muy similar a como especificar una etiqueta de fontlist nula para un recurso de fontlist hace que la fontlist creada contenga una entrada etiquetada con XmFONTLIST_DEFAULT_TAG:

especificación_recurso.nombre_recurso: valor

Por ejemplo, lo siguiente establecería el recurso XmNrenderTable de label1 a una tabla de renderizado que consta de tres renderizados etiquetados como _MOTIF_DEFAULT_LOCALE, bold y oblique, con valores para los recursos establecidos como se describe en las especificaciones de recursos.

*label1.renderTable: bold, oblique
*label1.renderTable.bold.renditionForeground: Green
*label1.renderTable.bold.fontName: *-*-*-bold-*-iso8859-1
*label1.renderTable.bold.fontType: FONT_IS_FONT
*label1.renderTable.oblique.renditionBackground: Red
*label1.renderTable.oblique.fontName: *-*-*-italic-*-iso8859-1
*label1.renderTable.oblique.fontType: FONT_IS_FONT
*label1.renderTable.oblique.underlineType: AS_IS
*label1.renderTable.fontName: fixed
*label1.renderTable.fontType: FONT_IS_FONT
*label1.renderTable.renditionForegound: black
*label1.renderTable*tabList: 1in, +1.5in, +3in
