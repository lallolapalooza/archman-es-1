NOMBRE

XmListReplaceItemsPos — Una función de lista que reemplaza los elementos especificados en la lista

SINOPSIS

#include <Xm/List.h>
void XmListReplaceItemsPos(
Widget widget,
XmString *new_items,
int item_count,
int position);

DESCRIPCIÓN

XmListReplaceItemsPos reemplaza el número especificado de elementos de la Lista con nuevos elementos, comenzando en la posición especificada en la Lista. Cuando los elementos se insertan en la lista, se comparan con la lista actual de XmNselectedItems. Si alguno de los nuevos elementos coincide con un elemento de la lista seleccionada, aparecerá seleccionado.

widget
Especifica el ID del widget de Lista.
new_items
Especifica los elementos de reemplazo.
item_count
Especifica el número de elementos en new_items y el número de elementos de la lista a reemplazar. Este número debe ser no negativo.
position
Especifica la posición del primer elemento de la lista a reemplazar. Un valor de 1 indica que el primer elemento reemplazado es el primer elemento de la lista; un valor de 2 indica que es el segundo elemento; y así sucesivamente.
Comenzando con el elemento especificado en position, se reemplazan item_count elementos de la lista con los elementos correspondientes de new_items. Es decir, el elemento en position se reemplaza con el primer elemento de new_items; el elemento después de position se reemplaza con el segundo elemento de new_items; y así sucesivamente, hasta que se alcance item_count.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).

RELACIONADO

XmList(3).
