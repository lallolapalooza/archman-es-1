NOMBRE

XML::PatAct::ToObjects - Un módulo de acción para crear objetos Perl

SINOPSIS

use XML::PatAct::ToObjects;
my $patterns = [ PATTERN => [ OPTIONS ],
                 PATTERN => "PERL-CODE",
                 ... ];
my $matcher = XML::PatAct::ToObjects->new( Patterns => $patterns,
                                           Matcher => $matcher,
                                           CopyId => 1,
                                           CopyAttributes => 1 );

DESCRIPCIÓN

XML::PatAct::ToObjects es un manejador PerlSAX para aplicar listas de patrones-acciones a analizadores o árboles XML. XML::PatAct::ToObjects crea objetos Perl de los tipos y contenidos de los elementos de acción que defines.

Se crean nuevas instancias de XML::PatAct::ToObject llamando a `new()'. Se pueden pasar parámetros como una lista de pares clave, valor o un hash. `new()' requiere los parámetros Patterns y Matcher, los demás son opcionales:

Patterns
La lista de patrones-acciones a aplicar.
Matcher
Una instancia del módulo de coincidencia de patrones o consultas.
CopyId
Hace que el atributo `ID', si existe, en un elemento XML de origen se copie a un atributo `ID' en los objetos recién creados. Tenga en cuenta que los IDs pueden perderse si ningún patrón coincide con ese elemento o si no se crea un objeto ("-make") para ese elemento.
CopyAttributes
Hace que todos los atributos del elemento se copien a los objetos recién creados.

Cada acción puede ser una lista de opciones definidas a continuación o una cadena que contiene un fragmento de código Perl. Si la acción es una cadena de código Perl, entonces se realizan algunas sustituciones simples como se describe más adelante.

Opciones que se pueden usar en un elemento de acción que contiene una lista de opciones:

-holder
Ignora este elemento, pero continúa procesando sus hijos (comparar con -ignore). "-pcdata" puede usarse con esta opción.
-ignore
Ignora (descarta) este elemento y sus hijos (comparar con -holder).
-pcdata
Los datos de caracteres en este elemento se copiarán al campo "Contents".
-make PACKAGE
Crea un objeto bendecido en PACKAGE y continúa procesando este elemento y sus hijos. PACKAGE puede ser el tipo `"HASH"' para simplemente crear un hash anónimo.
-args ARGUMENTS
Usa ARGUMENTS al crear el objeto especificado por -make. Esto se usa comúnmente para copiar atributos de elementos en campos del objeto recién creado. Por ejemplo: 
-make => 'HASH', -args => 'URL => %{href}'

copiaría el atributo `"href"' en un elemento al campo `"URL"' del hash recién creado.

-field FIELD
Almacena este elemento, objeto o hijos de este elemento en el campo del objeto padre llamado por FIELD.
-push-field FIELD
Similar a -field, excepto que FIELD es un array y los contenidos se añaden a ese array.
-value VALUE
Usa VALUE como un valor literal para almacenar en FIELD, ignorando de lo contrario este elemento y sus hijos. Solo válido con -field o -push-field. Se puede usar la notación `"%{ATTRIBUTE}"' para sustituir el valor de un atributo en el valor literal.
-as-string
Convierte el contenido de este elemento a una cadena (como en "XML::Grove::AsString") y lo almacena en FIELD. Solo válido con -field o -push-field.
-grove
Copia este elemento a FIELD sin procesamiento adicional. El elemento puede ser procesado posteriormente mientras se manipulan los objetos Perl. Solo válido con -field o -push-field. Si ToObjects se usa con PerlSAX, utilizará XML::Grove::Builder para construir el elemento grove.
-grove-contents
Usado con -make, -grove-contents crea un objeto pero luego toma todo el contenido de ese elemento y lo almacena en Contents.

Si un elemento de acción es una cadena, esa cadena se trata como un fragmento de código Perl. Se realizan las siguientes sustituciones simples en el fragmento para proporcionar un fácil acceso a la información que se está convirtiendo:

@ELEM@
El objeto que provocó la llamada a esta acción. Si ToObjects se usa con PerlSAX, este será un hash con el nombre del elemento y los atributos; con XML::Grove será el objeto del elemento; con Data::Grove será el objeto coincidente; y con XML::DOM será un XML::DOM::Element.

EJEMPLO

La siguiente lista de patrones-acciones de ejemplo convertirá el siguiente XML que representa un esquema de base de datos:

<schema>
  <table>
    <name>MyTable</name>
    <summary>A short summary</summary>
    <description>A long description that may
      contain a subset of HTML</description>
    <column>
      <name>MyColumn1</name>
      <summary>A short summary</summary>
      <description>A long description</description>
      <unique/>
      <non-null/>
      <default>42</default>
    </column>
  </table>
</schema>

en objetos Perl que se parezcan a:

[
  { Name => "MyTable",
    Summary => "A short summary",
    Description => $grove_object,
    Columns => [
      { Name => "MyColumn1",
        Summary => "A short summary",
        Description => $grove_object,
        Unique => 1,
        NonNull => 1,
        Default => 42
      }
    ]
  }
]

Aquí hay un script Perl y una lista de patrones-acciones que realizarán la conversión utilizando el módulo de coincidencia de nombres simple XML::PatAct::MatchName. El script acepta un archivo XML de Esquema como argumento ($ARGV[0]) al script. Este script crea un grove como uno de sus objetos, por lo que requiere el módulo XML::Grove.

use XML::Parser::PerlSAX;
use XML::PatAct::MatchName;
use XML::PatAct::ToObjects;
my $patterns = [
  'schema'      => [ qw{ -holder                                  } ],
  'table'       => [ qw{ -make Schema::Table                      } ],
  'name'        => [ qw{ -field Name -as-string                   } ],
  'summary'     => [ qw{ -field Summary -as-string                } ],
  'description' => [ qw{ -field Description -grove                } ],
  'column'      => [ qw{ -make Schema::Column -push-field Columns } ],
  'unique'      => [ qw{ -field Unique -value 1                   } ],
  'non-null'    => [ qw{ -field NonNull -value 1                  } ],
  'default'     => [ qw{ -field Default -as-string                } ],
];
my $matcher = XML::PatAct::MatchName->new( Patterns => $patterns );
my $handler = XML::PatAct::ToObjects->new( Patterns => $patterns,
                                           Matcher => $matcher);
my $parser = XML::Parser::PerlSAX->new( Handler => $handler );
my $schema = $parser->parse(Source => { SystemId => $ARGV[0] } );

PENDIENTES

  • Sería bueno si los patrones pudieran aplicarse incluso en -as-string y -grove.
  • Implementar acciones de código Perl.
  • -as-xml para escribir XML en el campo.
