XML::LibXML::RelaxNG(3) Documentación de Perl aportada por el usuario XML::LibXML::RelaxNG(3)

NOMBRE

XML::LibXML::RelaxNG - Validación de Esquemas RelaxNG

SINOPSIS

use XML::LibXML;
$doc = XML::LibXML->new->parse_file($url);
$rngschema = XML::LibXML::RelaxNG->new( location => $filename_or_url, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( string => $xmlschemastring, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( DOM => $doc, no_network => 1 );
eval { $rngschema->validate( $doc ); };

DESCRIPCIÓN

La clase XML::LibXML::RelaxNG es una pequeña interfaz para la implementación RelaxNG de libxml2. Actualmente solo soporta el análisis de esquemas y la validación de documentos.

MÉTODOS

new
$rngschema = XML::LibXML::RelaxNG->new( location => $filename_or_url, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( string => $xmlschemastring, no_network => 1 );
$rngschema = XML::LibXML::RelaxNG->new( DOM => $doc, no_network => 1 );

El constructor de XML::LibXML::RelaxNG debe ser llamado con una lista de parámetros. Se requiere al menos el parámetro location, string o DOM para especificar la fuente del esquema. El parámetro opcional no_network establecido a 1 hará que el analizador no acceda a la red y el parámetro opcional recover establecido a 1 hará que el analizador no llame a die() en caso de errores.

Es importante que cada esquema tenga una única fuente.

El parámetro location permite analizar un esquema desde el sistema de archivos o una URL (no HTTPS).

El parámetro string analizará el esquema de la cadena XML dada.

El parámetro DOM permite analizar el esquema de un documento XML::LibXML::Document pre-analizado.

Tenga en cuenta que el constructor llamará a die() si el esquema no cumple con las restricciones de la especificación RelaxNG.

validate
eval { $rngschema->validate( $doc ); };

Esta función permite validar un documento (analizado) contra el esquema RelaxNG dado. El argumento de esta función debe ser un objeto XML::LibXML::Document. Si esta función tiene éxito, devolverá 0, de lo contrario llamará a die() e informará de los errores encontrados. Debido a esto, validate() siempre debe ser evaluado.
