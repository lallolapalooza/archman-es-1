XmVaCreateNotebook(llamada a biblioteca) XmVaCreateNotebook(llamada a biblioteca)

NOMBRE

XmVaCreateNotebook, XmVaCreateManagedNotebook — Funciones de conveniencia para la creación de widgets Notebook.

SINOPSIS

#include <Xm/Notebook.h>
Widget XmVaCreateNotebook(
Widget parent,
String name,
...);
Widget XmVaCreateManagedNotebook(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget ToggleButtonGadget y devuelven el ID del widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos variables (varargs) de ANSI C.

La función XmVaCreateNotebook es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreateNotebook es una rutina de conveniencia que llama a XtCreateManagedWidget.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de Notebook y sus recursos asociados, consulte XmNotebook(3).

RETORNAR

Devuelve el ID del widget Notebook.

RELACIONADOS

XmNotebook(3), XmCreateNotebook(3), XtCreateWidget(3) y XtCreateManagedWidget(3).
