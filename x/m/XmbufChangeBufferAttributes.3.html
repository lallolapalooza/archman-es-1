DESCRIPCIÓN

La biblioteca de programación de aplicaciones para la Extensión X11 de Doble Búfer, Múltiple Búfer y Estéreo contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que puede configurarse con XSetExtensionErrorHandler y funciona igual que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de búfer múltiple/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe sumarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe sumarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión principal y secundaria de la extensión. El valor de retorno es cero si ocurre un error o un valor distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" búferes con la acción de actualización y la pista de actualización dadas y que se asocien con la ventana indicada. Se devuelve el número de búferes creados (cero si ocurrió un error) y buffers_update se llena con esa cantidad de identificadores de Multibuffer.

XmbufDestroyBuffers destruye los búferes asociados con la ventana dada.

XmbufDisplayBuffers muestra los búferes indicados en sus respectivas ventanas dentro de un máximo de max_delay milisegundos después de que hayan transcurrido min_delay milisegundos. No se pueden asociar dos búferes con la misma ventana o se generará un error Match.

XmbufGetWindowAttributes obtiene los atributos de búfer múltiple que se aplican a todos los búferes asociados con la ventana dada. La lista de búferes devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de búfer múltiple que se aplican a todos los búferes asociados con la ventana dada. Actualmente, esto se limita a la pista de actualización.

XmbufGetBufferAttributes obtiene los atributos del búfer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del búfer indicado. Actualmente, esto se limita a la máscara de eventos.

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Los números de conjuntos de visual y profundidades se devuelven en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen los diversos visuales y profundidades que se pueden usar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece de acuerdo con nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los identificadores de búfer para los búferes izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en este display.

DESCRIPTION

The Multi-Buffering extension provides a way to perform double or triple buffering on a window. This extension is intended to be used for applications requiring smooth animation, such as games or multimedia applications.

The primary interface to the multi-buffering extension is through the XmbufCreateBuffer(3) function. This function creates a buffer associated with a given window. The buffer can then be manipulated using other functions such as XmbufSetBufferAttributes(3), XmbufSwapBuffer(3), and XmbufDestroyBuffer(3).

The extension also provides functions for querying and changing buffer attributes, managing buffer creation and destruction, and selecting which buffer is currently active.

The XmbufSwapWindow(3) function is a convenience function that swaps the buffers for all windows that have multi-buffering enabled.

The XmbufGetVersion(3) function can be used to determine the version of the multi-buffering extension supported by the server.

The XmbufTripleBufferAttributes(3) function is used to configure triple buffering specific attributes.

The extension also defines event types for notifying clients about buffer updates and clobbers. These events can be selected using XmbufSelectBuffer(3) and other related functions.

PREDEFINED VALUES

The following constants are defined for use with the multi-buffering extension:

MultibufferUpdateNotifyMask
Selects buffer update notification events.
MultibufferClobberNotify
A flag indicating that a buffer has been clobbered.
MultibufferUpdateNotify
A flag indicating that a buffer has been updated.
MultibufferNumberEvents
The number of event types defined by the multi-buffering extension.
MultibufferBadBuffer
An error code indicating an invalid buffer ID.
MultibufferNumberErrors
The number of error codes defined by the multi-buffering extension.
