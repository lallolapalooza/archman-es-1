XmTextFieldGetSubstring(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmTextFieldGetSubstring(llamada a la biblioteca) XmTextFieldGetSubstring(llamada a la biblioteca)

NOMBRE

XmTextFieldGetSubstring — Una función de TextField que recupera una copia de una porción del búfer de texto interno

SINOPSIS

#include <Xm/TextF.h>
int XmTextFieldGetSubstring(
Widget widget,
XmTextPosition start,
int num_chars,
int buffer_size,
char *buffer);

DESCRIPCIÓN

XmTextFieldGetSubstring recupera una copia de una porción del búfer de texto interno de un widget TextField. La función copia un número especificado de caracteres desde una posición de inicio dada en el búfer de texto interno a un búfer proporcionado por la aplicación. Se coloca un terminador NULL al final de los datos copiados.

El tamaño del búfer requerido depende del número máximo de bytes por carácter (MB_CUR_MAX) para la configuración regional actual. MB_CUR_MAX es una macro definida en stdlib.h. El búfer debe ser lo suficientemente grande como para contener la subcadena a copiar y un terminador NULL. Utilice la siguiente ecuación para calcular el tamaño del búfer que la aplicación debe proporcionar:

buffer_size = (num_chars* MB_CUR_MAX) + 1
(void)
widget
Especifica el ID del widget TextField.
start
Especifica la posición del carácter inicial desde la que se recuperarán los datos. Es un número entero de caracteres desde el principio del búfer de texto. La primera posición de carácter es 0 (cero).
num_chars
Especifica el número de caracteres a copiar en el búfer proporcionado.
buffer_size
Especifica el tamaño del búfer proporcionado en bytes. Este tamaño debe tener en cuenta un terminador NULL.
buffer
Especifica el búfer de caracteres en el que se copiará el búfer de texto interno.

Para una definición completa de TextField y sus recursos asociados, consulte XmTextField(3).

RETORNO

XmCOPY_SUCCEEDED
La función se realizó con éxito.
XmCOPY_FAILED
La función falló porque no pudo copiar el número especificado de caracteres en el búfer proporcionado. El tamaño del búfer puede ser insuficiente. El contenido de buffer no está definido.
XmCOPY_TRUNCATED
El número solicitado de caracteres se extendió más allá del búfer interno. La función copió caracteres entre start y el final del búfer del widget y terminó la cadena con un terminador NULL; se copiaron menos de num_chars caracteres.

RELACIONADO

XmTextField(3) y XmTextFieldGetSubstringWcs(3).
