NOMBRE

XmListGetKbdItemPos — Una función de Lista que devuelve la posición del elemento en el cursor de ubicación

SINOPSIS

#include <Xm/List.h>
int XmListGetKbdItemPos(
Widget widget);

DESCRIPCIÓN

XmListGetKbdItemPos devuelve la posición del elemento de la lista en el cursor de ubicación.

widget
Especifica el ID del widget List

Para una definición completa de List y sus recursos asociados, consulte XmList(3).

RETORNO

Devuelve la posición del elemento de teclado actual. Un valor de 1 indica que el cursor de ubicación está en el primer elemento de la lista; un valor de 2 indica que está en el segundo elemento; y así sucesivamente. Un valor de 0 (cero) indica que el widget List está vacío.

RELACIONADO

XmList(3).
