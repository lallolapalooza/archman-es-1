NOMBRE

XML::LibXML::Error - Errores Estructurados

SINOPSIS

eval { ... };
        if (ref($@)) {
          # manejar un error estructurado (objeto XML::LibXML::Error)
        } elsif ($@) {
          # error, pero no un objeto XML::LibXML::Error
        } else {
          # sin error
        }
$XML::LibXML::Error::WARNINGS=1;
$mensaje = $@->as_string();
print $@->dump();
$dominio_error = $@->domain();
$codigo_error = $@->code();
$mensaje_error = $@->message();
$nivel_error = $@->level();
$archivo = $@->file();
$linea = $@->line();
$nombre_nodo = $@->nodename();
$str_error1 = $@->str1();
$str_error2 = $@->str2();
$str_error3 = $@->str3();
$num_error1 = $@->num1();
$num_error2 = $@->num2();

DESCRIPCIÓN

La clase XML::LibXML::Error es un pequeño frontend para el soporte de errores estructurados de libxml2. Si XML::LibXML está compilado con soporte de errores estructurados, todos los errores reportados por libxml2 se transforman en objetos XML::LibXML::Error. Estos objetos se serializan automáticamente a los mensajes de error correspondientes cuando se imprimen o se utilizan en una operación de cadena, pero como objetos, también pueden ser utilizados para obtener información detallada y estructurada sobre el error que ocurrió.

A diferencia de la mayoría de los otros objetos XML::LibXML, XML::LibXML::Error no envuelve directamente una estructura libxml2 subyacente, sino que la transforma en una referencia de hash Perl bendecida que contiene los campos individuales de la información de error estructurada como pares clave-valor de hash. Los elementos individuales (campos) de un error estructurado se pueden obtener directamente como $@->{campo}, o utilizando métodos auto-cargados como $@->campo() (donde campo es el nombre del campo). Los objetos XML::LibXML::Error tienen los siguientes campos: domain, code, level, file, line, nodename, message, str1, str2, str3, num1, num2 y _prev (algunos de ellos pueden ser indefinidos).

$XML::LibXML::Error::WARNINGS
$XML::LibXML::Error::WARNINGS=1;

Tradicionalmente, XML::LibXML suprimía las advertencias del analizador estableciendo la variable global de libxml2 xmlGetWarningsDefaultValue a 0. Desde 1.70 ya no cambiamos las variables globales de libxml2; por compatibilidad hacia atrás, XML::LibXML suprime las advertencias. Esta variable se puede establecer a 1 para habilitar el reporte de estas advertencias a través de "warn" de Perl y a 2 para reportarlas a través de "die".

as_string
$mensaje = $@->as_string();

Esta función serializa un objeto XML::LibXML::Error a una cadena que contiene el mensaje de error completo, de forma similar al mensaje producido por los manejadores de errores predeterminados de libxml2 y herramientas como xmllint. Este método también se utiliza para sobrecargar el operador de conversión a cadena "" en XML::LibXML::Error, por lo que se llama automáticamente cada vez que un objeto XML::LibXML::Error se trata como una cadena (por ejemplo, en print $@).

dump
print $@->dump();

Esta función serializa un XML::LibXML::Error a una cadena mostrando todos los campos de la estructura de error individualmente en líneas separadas con el formato 'nombre' => 'valor'.

domain
$dominio_error = $@->domain();

Devuelve una cadena que contiene información sobre qué parte de la biblioteca generó el error. Puede ser una de las siguientes: "parser", "tree", "namespace", "validity", "HTML parser", "memory", "output", "I/O", "ftp", "http", "XInclude", "XPath", "xpointer", "regexp", "Schemas datatype", "Schemas parser", "Schemas validity", "Relax-NG parser", "Relax-NG validity", "Catalog", "C14N", "XSLT", "validity".

code
$codigo_error = $@->code();

Devuelve el código de error real de libxml2. El módulo XML::LibXML::ErrNo define constantes para los códigos de error individuales. Actualmente libxml2 utiliza más de 480 códigos de error diferentes.

message
$mensaje_error = $@->message();

Devuelve un mensaje de error informativo y legible por humanos.

level
$nivel_error = $@->level();

Devuelve un valor entero que describe la gravedad del error. XML::LibXML::Error define las siguientes constantes:

  • XML_ERR_NONE = 0
  • XML_ERR_WARNING = 1 : Una advertencia simple.
  • XML_ERR_ERROR = 2 : Un error recuperable.
  • XML_ERR_FATAL = 3 : Un error fatal.
file
$archivo = $@->file();

Devuelve el nombre del archivo que se estaba procesando cuando ocurrió el error.

line
$linea = $@->line();

El número de línea, si está disponible.

nodename
$nombre_nodo = $@->nodename();

Nombre del nodo donde ocurrió el error, si está disponible. Cuando este campo no está vacío, libxml2 devolvió realmente un puntero físico al nodo especificado. Debido a problemas de gestión de memoria, es muy difícil implementar una forma de exponer el puntero al nivel de Perl como un XML::LibXML::Node. Por esta razón, XML::LibXML::Error actualmente solo expone el nombre del nodo.

str1
$str_error1 = $@->str1();

Específico del error. Información de cadena adicional.

str2
$str_error2 = $@->str2();

Específico del error. Información de cadena adicional.

str3
$str_error3 = $@->str3();

Específico del error. Información de cadena adicional.

num1
$num_error1 = $@->num1();

Específico del error. Información numérica adicional.

num2
$num_error2 = $@->num2();

En versiones recientes de libxml2, este valor contiene el número de columna del error o 0 si no aplica.

context
$cadena = $@->context();

Para errores de análisis, este campo contiene aproximadamente 80 caracteres del XML cerca del lugar donde ocurrió el error. El campo "$@->column()" contiene el desplazamiento correspondiente. Donde no aplica, el campo es indefinido.

column
$offset = $@->column();

Ver "$@->column()" arriba.

_prev
$error_anterior = $@->_prev();

Este campo puede contener una referencia a otro objeto XML::LibXML::Error que representa un error que ocurrió justo antes de este error.
