NOMBRE

XmTrackingLocate — Una función de Toolkit que proporciona una interacción modal

SINOPSIS

#include <Xm/Xm.h>
Widget XmTrackingLocate(
Widget widget,
Cursor cursor,
Boolean confine_to);

DESCRIPCIÓN

XmTrackingLocate proporciona una interfaz modal para la selección de un componente. Está destinada a soportar la ayuda contextual. Esta función se implementa como XmTrackingEvent.

NOTA: Esta función es obsoleta y existe por compatibilidad con lanzamientos anteriores. Ha sido reemplazada por XmTrackingEvent.

widget
Especifica el ID del widget a utilizar como base de la interacción modal. Es decir, el widget dentro del cual debe ocurrir la interacción, generalmente una ventana de nivel superior (shell).
cursor
Especifica el cursor a utilizar para el puntero durante la interacción. Este es un nombre de cursor X estándar.
confine_to
Especifica si el cursor debe o no limitarse a widget

RETORNO

Devuelve el widget o gadget que contiene el puntero cuando se libera el Botón de Selección o se suelta una tecla. Si ningún widget o gadget contiene el puntero, la función devuelve NULL.

RELACIONADO

XmTrackingEvent(3).
