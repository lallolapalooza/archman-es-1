NOMBRE

XmClipboardCopy — Una función del portapapeles que copia un elemento de datos al almacenamiento temporal para su posterior copia al portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardCopy (display, window, item_id, format_name,
        buffer, length, private_id, data_id)
        Display * display;
        Window  window;
        long    item_id;
        char    * format_name;
        XtPointer       buffer;
        unsigned long   length;
        long    private_id;
        long    * data_id;
(void)

DESCRIPCIÓN

XmClipboardCopy copia un elemento de datos al almacenamiento temporal. El elemento de datos se mueve del almacenamiento temporal a la estructura de datos del portapapeles cuando se realiza una llamada a XmClipboardEndCopy. Las llamadas adicionales a XmClipboardCopy antes de una llamada a XmClipboardEndCopy añaden formatos de elementos de datos adicionales al mismo elemento de datos o añaden datos a un formato existente. Los formatos se describen en el Manual de convenciones de comunicación entre clientes (ICCCM) como objetivos.

NOTA: No llame a XmClipboardCopy antes de que se haya realizado una llamada a XmClipboardStartCopy. Esta última función asigna el almacenamiento temporal requerido por XmClipboardCopy.

Si el argumento buffer es NULL, los datos se consideran pasados por nombre. Cuando los datos que se han pasado por nombre son solicitados posteriormente por otra aplicación, la aplicación que posee los datos recibe una llamada de retorno con una solicitud de los datos. La aplicación que posee los datos debe transferir los datos al portapapeles con la función XmClipboardCopyByName. Cuando un elemento de datos que se pasó por nombre se elimina del portapapeles, la aplicación que posee los datos recibe una llamada de retorno indicando que los datos ya no son necesarios.

Para obtener información sobre la función de llamada de retorno, consulte la descripción del argumento de llamada de retorno para XmClipboardStartCopy.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llame.
item_id
Especifica el número asignado a este elemento de datos. Este número fue devuelto por una llamada anterior a XmClipboardStartCopy.
format_name
Especifica el nombre del formato en el que se almacena el elemento de datos en el portapapeles. El formato se conocía como objetivo en el ICCCM.
buffer
Especifica el búfer desde el cual el portapapeles copia los datos.
length
Especifica la longitud, en bytes, de los datos que se copian al portapapeles.
private_id
Especifica los datos privados que la aplicación desea almacenar con el elemento de datos.
data_id
Especifica un número de identificación asignado al elemento de datos que identifica de forma única el elemento de datos y el formato. Este argumento solo es necesario para los datos que se pasan por nombre.

DEVOLVER

XmClipboardSuccess
La función se realizó con éxito.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función de nuevo con los mismos parámetros hasta que desaparezca el bloqueo. Esto da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o abandonar la operación.
XmClipboardFail
La función falló porque no se llamó a XmClipboardStartCopy o porque el elemento de datos contiene demasiados formatos.

RELACIONADO

XmClipboardCopyByName(3), XmClipboardEndCopy(3), y XmClipboardStartCopy(3).
