NOMBRE

XML::XPath::Functions - implementaciones de funciones XPath

DESCRIPCIÓN

Se admiten XPath 1.0 y algunas funciones posteriores.

Tenga en cuenta que las funciones que toman expresiones regulares utilizan REs de sintaxis Perl, no el lenguaje descrito en la especificación XPath.

FUNCIONES

FUNCIONES DE NODESET

  • last()
  • position()
  • count()
  • id()
  • "local-name()"
  • name()
  • "namespace-uri()"

FUNCIONES DE CADENA

Funciones sobre valores de cadena

  • string()
  • concat()
  • substring()
  • "string-length()"
  • "normalize-space()"
  • translate()

Funciones basadas en coincidencia de subcadenas

  • contains()
  • "starts-with()"
  • "substring-before()"
  • "substring-after()"
