NOMBRE

XmContainerCut — Función del widget Container para mover elementos al portapapeles

SINOPSIS

#include <Xm/Container.h>
Boolean XmContainerCut(
Widget container,
Time timestamp);

DESCRIPCIÓN

XmContainerCut corta los elementos seleccionados primariamente al portapapeles. Esta rutina llama a los procedimientos XmNconvertCallback, posiblemente múltiples veces, con el miembro selection de XmConvertCallbackStruct establecido a CLIPBOARD y con el miembro parm establecido a XmMOVE. Si la transferencia es exitosa, esta rutina llama entonces a los procedimientos XmNconvertCallback para la selección CLIPBOARD y el objetivo DELETE.

container
Especifica el ID del widget Container.
timestamp
Especifica la hora del servidor en la que modificar el valor de la selección.

Para una definición completa de Container y sus recursos asociados, consulte XmContainer(3).

RETORNO

La función devuelve False en los siguientes casos: si la selección primaria es NULL, si el widget no posee la selección primaria, o si la función no puede obtener la propiedad de la selección del portapapeles. De lo contrario, devuelve True.
