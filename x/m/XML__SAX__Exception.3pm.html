NOMBRE

XML::SAX::Exception - Clases de excepción para XML::SAX

SINOPSIS

throw XML::SAX::Exception::NotSupported(
        Message => "La característica foo no está soportada",
        );

DESCRIPCIÓN

Este módulo es la clase base para todas las Excepciones SAX, aquellas definidas en la especificación, así como aquellas que uno pueda crear para sus propios errores SAX.

Se incluyen tres subclases, correspondientes a las de la especificación SAX:

XML::SAX::Exception::NotSupported
XML::SAX::Exception::NotRecognized
XML::SAX::Exception::Parse

Úsalas donde quieras, y tanto como sea posible cuando encuentres tales errores. SAX está destinado a usar excepciones tanto como sea posible para señalar problemas.

CREACIÓN DE NUEVAS CLASES DE EXCEPCIÓN

Todo lo que necesitas hacer para crear una nueva clase de excepción es:

@XML::SAX::Exception::MyException::ISA = ('XML::SAX::Exception')

El paquete dado no necesita existir, se comportará correctamente de esta manera. Si tu excepción refina una clase de excepción existente, entonces también puedes heredar de ella en lugar de la clase base.

LANZAMIENTO DE EXCEPCIONES

Esto es tan simple como se ejemplifica en la SINOPSIS. De hecho, no hay nada más que saber. Todo lo que tienes que hacer es:

throw XML::SAX::Exception::MyException( Message => 'Algo salió mal' );

Y listo, has lanzado una excepción que puede ser capturada en un bloque eval.
