NOMBRE

XmListAddItemsUnselected — una función de Lista que agrega elementos a una lista

SINOPSIS

#include <Xm/List.h>
void XmListAddItemsUnselected(
Widget widget,
XmString *items,
int item_count,
int position);

DESCRIPCIÓN

XmListAddItemsUnselected agrega los elementos especificados a la lista en la posición dada. Los elementos insertados permanecen sin seleccionar, incluso si actualmente aparecen en la lista XmNselectedItems.

widget
Especifica el ID del widget de Lista al que se agregarán los elementos.
items
Especifica un puntero a los elementos que se agregarán a la lista.
item_count
Especifica el número de elementos en items. Este número debe ser no negativo.
position
Especifica la posición del primer elemento nuevo en la lista. Un valor de 1 hace que el primer elemento nuevo sea el primer elemento de la lista; un valor de 2 lo hace el segundo elemento; y así sucesivamente. Un valor de 0 (cero) hace que el primer elemento nuevo siga al último elemento de la lista.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).
