XML::PatAct::Amsterdam(3) Documentación de Perl aportada por el usuario XML::PatAct::Amsterdam(3)

NOMBRE

XML::PatAct::Amsterdam - Un módulo de acción para hojas de estilo simplistas

SINOPSIS

use XML::PatAct::Amsterdam;
my $patterns = [ PATTERN => { Before => 'antes',
                              After => 'después' },
                 ... ];
my $matcher = XML::PatAct::Amsterdam->new( OPCIONES );

DESCRIPCIÓN

XML::PatAct::Amsterdam es un manejador PerlSAX para aplicar listas de patrones-acciones a parses o árboles XML. XML::PatAct::Amsterdam aplica una hoja de estilo muy simple a una instancia y genera el resultado. Amsterdam recibe su nombre del Analizador SGML de Ámsterdam (ASP) que inspiró este módulo.

PRECAUCIÓN: Amsterdam es un módulo de estilo muy simple, te encontrarás con sus limitaciones rápidamente incluso con instancias XML moderadamente complejas, sé consciente y prepárate para cambiar a módulos de estilo más completos.

Las nuevas instancias de XML::PatAct::Amsterdam se crean llamando a `new()'. Los parámetros se pueden pasar como una lista de pares clave, valor o un hash. Se requieren opciones de Patrones y Coincidencia (Matcher). Las siguientes *OPCIONES* son compatibles:

Patterns
La lista de patrones-acciones a aplicar. La lista es un array anónimo de pares patrón, acción. Cada acción en la lista contiene uno o ambos cadenas Before y After para copiar a la salida antes y después de procesar un elemento XML. Las cadenas Before y After pueden contener nombres de atributos encerrados entre corchetes (`"["' *NOMBRE* `"]"'), estos se reemplazan con el valor del atributo con ese nombre. El *NOMBRE* especial `"_element"' se reemplazará con el nombre del elemento.
Matcher
Una instancia del módulo de coincidencia de patrones o consulta.
Output
Un IO::Handle o una de sus subclases (como IO::File), si este parámetro no está presente y la opción AsString no se usa, el módulo escribirá en la salida estándar.
AsString
Devuelve la salida generada como una cadena del `parse()' método del generador de eventos PerlSAX.
