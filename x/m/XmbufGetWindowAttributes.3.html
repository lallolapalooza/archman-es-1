DESCRIPCIÓN

La biblioteca de aplicaciones de programación para la Extensión de Doble Buffering, Multibuffering y Estéreo de X11 contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede establecer con XSetExtensionErrorHandler y funciona igual que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de multibuffering/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe agregarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe agregarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión mayor y menor de la extensión. El valor de retorno es cero si ocurre un error o distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con la acción de actualización y la sugerencia de actualización dadas y se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores de Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus ventanas apropiadas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers a la misma ventana o se generará un error de Coincidencia.

XmbufGetWindowAttributes obtiene los atributos de multibuffering que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multibuffering que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita a la sugerencia de actualización.

XmbufGetBufferAttributes obtiene los atributos del buffer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del buffer indicado. Actualmente, esto se limita a event_mask.

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Se devuelven los números de conjuntos de visual y profundidades en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen los diversos visuales y profundidades que se pueden usar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece de acuerdo con nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los identificadores de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que retorna, se devolverá None si la extensión no está disponible en este display.

STRUCTURES

In addition to the standard Xlib window attributes, this extension introduces attributes for multi-buffering.

MultibufferAttributes
This structure holds the multi-buffering specific attributes for a window.

DESCRIPTION

The XmbufGetWindowAttributes function returns the specified window's attributes. The attributes are returned in the structure pointed to by wa_return. If the specified window has multi-buffering attributes, they will be returned in the ext_data field of the XWindowAttributes structure.

The multi-buffering extension adds its own attributes to the standard X window attributes. These are stored in a MultibufferAttributes structure, which is then placed in the ext_data field of the standard XWindowAttributes structure.

If the multi-buffering extension is not available, or if the window does not have multi-buffering attributes, the ext_data field will be NULL.
