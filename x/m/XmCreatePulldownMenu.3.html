NOMBRE

XmCreatePulldownMenu — Función de conveniencia para crear un widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmCreatePulldownMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreatePulldownMenu crea una instancia de un widget RowColumn de tipo XmMENU_PULLDOWN y devuelve el ID del widget asociado.

padre
Especifica el ID del widget padre
nombre
Especifica el nombre del widget creado
arglist
Especifica la lista de argumentos
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist)

Especifica el número de pares atributo/valor en la lista de argumentos (arglist). Cuando esta función se utiliza para crear el panel del menú desplegable, se crea automáticamente un widget MenuShell como padre del panel del menú. Si el widget especificado por el parámetro padre es un panel de menú emergente o desplegable, el widget MenuShell se crea como hijo del MenuShell padre; de lo contrario, se crea como hijo del widget padre especificado.

XmCreatePulldownMenu se proporciona como una función de conveniencia para crear widgets RowColumn configurados para operar como paneles de menú desplegables y no está implementada como una clase de widget separada.

Un panel de menú desplegable muestra una sombra tridimensional, a menos que la aplicación deshabilite la función. La sombra aparece alrededor del borde del panel del menú.

Un panel de menú desplegable se utiliza con submenús que se adjuntarán a un CascadeButton o a un CascadeButtonGadget. Este es el caso de todos los paneles de menú que forman parte de un sistema PulldownMenu (una MenuBar), el panel de menú asociado a un OptionMenu y cualquier panel de menú que se despliegue desde un panel de menú emergente. Los paneles de menú desplegables que se asociarán a un OptionMenu deben crearse antes de que se cree el OptionMenu.

El panel de menú desplegable debe adjuntarse a un CascadeButton o CascadeButtonGadget que resida en una MenuBar, un panel de menú emergente, un panel de menú desplegable o un OptionMenu. Se adjunta con el recurso del botón XmNsubMenuId.

Se requiere un widget MenuShell entre el panel de menú desplegable y su padre. Si la aplicación utiliza esta función de conveniencia para crear un panel de menú desplegable, el MenuShell se crea automáticamente como el padre real del panel del menú; de lo contrario, es responsabilidad de la aplicación crear el widget MenuShell.

Para funcionar correctamente al incorporarse a un menú, se debe considerar la jerarquía del panel de menú desplegable. Esta jerarquía depende del tipo de sistema de menú que se esté construyendo, de la siguiente manera:

•
Si el panel de menú desplegable se va a desplegar desde una MenuBar, su padre debe ser la MenuBar.
•
Si el panel de menú desplegable se va a desplegar desde un menú emergente o desde otro panel de menú desplegable, su padre debe ser ese menú emergente o desplegable.
•
Si el panel de menú desplegable se va a desplegar desde un OptionMenu, su padre debe ser el mismo que el padre del OptionMenu.

Los paneles de menú desplegable admiten capacidades de "tear-off" para menús extraíbles a través de los recursos de XmRowColumn. Para obtener una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.
