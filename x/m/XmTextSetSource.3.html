NOMBRE

XmTextSetSource — Una función de Text que establece el origen del widget

SINOPSIS

#include <Xm/Text.h>
void XmTextSetSource(
Widget widget,
XmTextSource source,
XmTextPosition top_character,
XmTextPosition cursor_position);

DESCRIPCIÓN

XmTextSetSource establece el origen del widget Text. Los widgets Text pueden compartir orígenes de texto para que la edición en un widget se refleje en otro. Esta función establece el origen de un widget para que pueda compartir el origen de otro widget.

Establecer un nuevo origen de texto destruye el origen de texto anterior si ningún otro widget Text está usando ese origen. Para reemplazar un origen de texto pero conservarlo para uso posterior, cree un widget Text no gestionado y establezca su origen al origen de texto que desea conservar.

widget
Especifica el ID del widget Text.
source
Especifica el origen con el que el widget muestra texto. Este puede ser un valor devuelto por la función XmTextGetSource(3). Si no se especifica ningún origen, el widget crea un origen de cadena predeterminado.
top_character
Especifica la posición en el texto que se mostrará en la parte superior del widget. Es un número entero de caracteres desde el principio del búfer de texto. La primera posición de carácter es 0 (cero).
cursor_position
Especifica la posición en el texto en la que se encuentra el cursor de inserción. Es un número entero de caracteres desde el principio del búfer de texto. La primera posición de carácter es 0 (cero).

Para una definición completa de Text y sus recursos asociados, consulte XmText(3).

RELACIONADO

XmText(3).
