NOMBRE

XmRepTypeAddReverse — Función del gestor de tipos de representación que instala el convertidor inverso para un tipo de representación registrado previamente

SINOPSIS

#include <Xm/RepType.h>
void XmRepTypeAddReverse(
XmRepTypeId rep_type_id);

DESCRIPCIÓN

XmRepTypeAddReverse instala el convertidor inverso para un tipo de representación previamente registrado. El convertidor inverso toma un valor numérico de tipo de representación y devuelve su valor de cadena correspondiente. Ciertas aplicaciones pueden requerir esta capacidad para obtener un valor de cadena para mostrar en pantalla o para construir un archivo de recursos.

El argumento values de la función XmRepTypeRegister se puede utilizar para registrar tipos de representación con valores no consecutivos o con nombres duplicados para el mismo valor. Si la lista de valores numéricos para un tipo de representación contiene valores duplicados, el convertidor inverso utiliza el primer nombre en la lista value_names que coincide con el valor numérico especificado. Por ejemplo, si un array value_names tiene cancel, proceed y abort, y el array values correspondiente contiene 0, 1 y 0, el convertidor inverso devolverá cancel en lugar de abort para un valor de entrada de 0.

rep_type_id
Especifica el número de identificación del tipo de representación

RELACIONADO

XmRepTypeGetId(3) y XmRepTypeRegister(3).
