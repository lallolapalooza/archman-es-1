NOMBRE

XML::Parser::Lite - Analizador XML ligero en Perl puro (basado en expresiones regulares)

SINOPSIS

use XML::Parser::Lite;
$p1 = new XML::Parser::Lite;
$p1->setHandlers(
  Start => sub { shift; print "inicio: @_\n" },
  Char => sub { shift; print "caracter: @_\n" },
  End => sub { shift; print "fin: @_\n" },
);
$p1->parse('<foo id="yo">Hola Mundo!</foo>');
$p2 = new XML::Parser::Lite
  Handlers => {
    Start => sub { shift; print "inicio: @_\n" },
    Char => sub { shift; print "caracter: @_\n" },
    End => sub { shift; print "fin: @_\n" },
  }
;
$p2->parse('<foo id="yo">Hola <bar>cruel</bar> Mundo!</foo>');

DESCRIPCIÓN

Este módulo implementa un analizador XML con una interfaz similar a XML::Parser. Aunque no todos los callbacks son compatibles, deberías poder usarlo de la misma manera que usas XML::Parser. Debido al uso de características experimentales de expresiones regulares, solo funcionará en Perl 5.6 y superiores y puede comportarse de manera diferente en distintas plataformas.

Ten en cuenta que no puedes usar expresiones regulares o `split` en los callbacks. Esto se debe a una limitación de la implementación de expresiones regulares de perl (que no es reentrante).

SUBRUTINAS/MÉTODOS

new

Constructor.

El método new() devuelve el objeto sobre el que se llama cuando se invoca como método de objeto. Este comportamiento se heredó de SOAP::Lite, del cual se extrajo XML::Parser::Lite. Esto significa que lo siguiente es efectivamente una operación nula si $obj es un objeto:

$obj = $obj->new();

New acepta un único parámetro con nombre, "Handlers" con una referencia de hash como valor:

my $parser = XML::Parser::Lite->new(
   Handlers => {
       Start => sub { shift; print "inicio: @_\n" },
       Char => sub { shift; print "caracter: @_\n" },
       End => sub { shift; print "fin: @_\n" },
   }
);

Los manejadores proporcionados se pasarán a setHandlers.

setHandlers

Establece (o reinicia) los manejadores de análisis. Acepta un hash con los nombres de los manejadores y referencias de código de los manejadores como parámetros. Pasar "undef" en lugar de una referencia de código reemplaza el manejador por una operación nula.

Los siguientes manejadores pueden establecerse:

Init
Start
Char
End
Final

Se ignoran todos los demás manejadores.

Llamar a setHandlers sin parámetros reinicia todos los manejadores a operaciones nulas.

parse

Analiza el XML proporcionado. A diferencia del método parse de XML::Parser, parse() solo analiza cadenas.

Métodos de manejador

Init

Se llama antes de que comience el análisis. Debes realizar cualquier inicialización necesaria en Init.

Start

Se llama al inicio de cada nodo XML. Ver XML::Parser para más detalles.

Char

Se llama para cada secuencia de caracteres. Puede ser llamado múltiples veces para los caracteres contenidos en un nodo XML (incluso para cada carácter individual). Tu implementación debe asegurarse de capturar todos los caracteres.

End

Se llama al final de cada nodo XML. Ver XML::Parser para más detalles.

Comment

Ver XML::Parser para más detalles.

XMLDecl

Ver XML::Parser para más detalles.

Doctype

Ver XML::Parser para más detalles.

Final

Se llama al final del proceso de análisis. Debes realizar cualquier limpieza necesaria aquí.

VER TAMBIÉN

XML::Parser - un analizador XML completo, en el que se basa XML::Parser::Lite. Requiere un compilador C y el analizador XML expat.

XML::Parser::LiteCopy - una bifurcación en XML::Parser::Lite::Tree.

YAX - otro módulo en Perl puro para análisis XML.

XML::Parser::REX - otro módulo que analiza XML con expresiones regulares.
