NOMBRE

XmScrollBarSetValues — Una función de ScrollBar que cambia los valores de incremento del ScrollBar y el tamaño y posición del control deslizante

SINOPSIS

#include <Xm/ScrollBar.h>
void XmScrollBarSetValues (widget, value, slider_size, increment, page_increment,
notify)
        Widget  widget;
        int     value;
        int     slider_size;
        int     increment;
        int     page_increment;
        Boolean notify;
(void)

DESCRIPCIÓN

XmSetScrollBarValues cambia los valores de incremento del ScrollBar y el tamaño y posición del control deslizante. La región de desplazamiento se superpone con una barra deslizante que se ajusta en tamaño y posición utilizando los atributos principales del ScrollBar o la función de establecer el control deslizante.

widget
Especifica el ID del widget ScrollBar.
value
Especifica la posición del control deslizante del ScrollBar. Consulte el recurso XmNvalue descrito en XmScrollBar(3).
slider_size
Especifica el tamaño del control deslizante. Consulte el recurso XmNsliderSize descrito en XmScrollBar(3). Este argumento establece ese recurso. Especifique un valor de 0 (cero) si no desea cambiar el valor.
increment
Especifica la cantidad de incremento y decremento del botón. Consulte el recurso XmNincrement descrito en XmScrollBar(3). Este argumento establece ese recurso. Especifique un valor de 0 (cero) si no desea cambiar el valor.
page_increment
Especifica la cantidad de incremento y decremento de página. Consulte el recurso XmNpageIncrement descrito en XmScrollBar(3). Este argumento establece ese recurso. Especifique un valor de 0 (cero) si no desea cambiar el valor.
notify
Especifica un valor booleano que, cuando es True, indica un cambio en el valor del ScrollBar y también especifica que el widget ScrollBar activa automáticamente el XmNvalueChangedCallback con el cambio reciente. Si se establece en False, especifica cualquier cambio que haya ocurrido en el valor del ScrollBar, pero no activa XmNvalueChangedCallback.

Para obtener una definición completa de ScrollBar y sus recursos asociados, consulte XmScrollBar(3).
