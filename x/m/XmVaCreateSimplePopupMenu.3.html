XmVaCreateSimplePopupMenu(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmVaCreateSimplePopupMenu(library call) XmVaCreateSimplePopupMenu(library call)

NAME

XmVaCreateSimplePopupMenu — Una función de conveniencia para crear un widget RowColumn

SYNOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePopupMenu(
Widget parent,
String name,
XtCallbackProc callback);

DESCRIPTION

XmVaCreateSimplePopupMenu crea una instancia de un widget RowColumn de tipo XmMENU_POPUP y devuelve el ID del widget asociado. Esta rutina utiliza la convención de llamada de lista de argumentos de longitud variable ANSI C (varargs).

Esta rutina crea un panel de menú emergente y sus botones hijos. El nombre de cada botón es button_n, donde n es un entero de 0 (cero) al número de botones en el menú menos 1. El nombre de cada separador es separator_n, donde n es un entero de 0 (cero) al número de separadores en el menú menos 1. El nombre de cada título es label_n, donde n es un entero de 0 (cero) al número de títulos en el menú menos 1. Los botones, separadores y títulos se nombran y crean en el orden en que se especifican en la porción variable de la lista de argumentos.

parent
Especifica el ID del widget padre del MenuShell
name
Especifica el nombre del widget creado
callback
Especifica un procedimiento de callback a ser llamado cuando se activa un botón o cuando cambia su valor. Esta función de callback se agrega a cada botón después de su creación. Para un CascadeButtonGadget o un PushButtonGadget, el callback se agrega como XmNactivateCallback del botón, y se llama cuando el botón se activa. Para un ToggleButtonGadget, el callback se agrega como XmNvalueChangedCallback del botón, y se llama cuando cambia el valor del botón. El número del botón se devuelve en el campo client_data.

La porción variable de la lista de argumentos consiste en grupos de argumentos. El primer argumento en cada grupo es una constante o una cadena y determina qué argumentos siguen en ese grupo. El último argumento de la lista debe ser NULL. La siguiente lista describe los posibles primeros argumentos en cada grupo de varargs.

XmVaCASCADEBUTTON
A esto le siguen dos argumentos adicionales. El conjunto especifica un botón en el PopupMenu y algunos de sus valores de recursos. El botón creado es un CascadeButtonGadget. A continuación se presentan los dos argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString
mnemonic
La mnemotecnia, de tipo KeySym
XmVaPUSHBUTTON
A esto le siguen cuatro argumentos adicionales. El conjunto especifica un botón en el PopupMenu y algunos de sus valores de recursos. El botón creado es un PushButtonGadget. A continuación se presentan los cuatro argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString
mnemonic
La mnemotecnia, de tipo KeySym
accelerator
El acelerador, de tipo String
accelerator_text
El texto del acelerador, de tipo XmString
XmVaRADIOBUTTON
A esto le siguen cuatro argumentos adicionales. El conjunto especifica un botón en el PopupMenu y algunos de sus valores de recursos. El botón creado es un ToggleButtonGadget. A continuación se presentan los cuatro argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString
mnemonic
La mnemotecnia, de tipo KeySym
accelerator
El acelerador, de tipo String
accelerator_text
El texto del acelerador, de tipo XmString
XmVaCHECKBUTTON
A esto le siguen cuatro argumentos adicionales. El conjunto especifica un botón en el PopupMenu y algunos de sus valores de recursos. El botón creado es un ToggleButtonGadget. A continuación se presentan los cuatro argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString
mnemonic
La mnemotecnia, de tipo KeySym
accelerator
El acelerador, de tipo String
accelerator_text
El texto del acelerador, de tipo XmString
XmVaTITLE
A esto le sigue un argumento adicional. El par especifica un LabelGadget de título en el PopupMenu. A continuación se presenta el argumento adicional:
title
La cadena de título, de tipo XmString
XmVaSEPARATOR
A esto le siguen cero argumentos adicionales. Especifica un separador en el PopupMenu.
XmVaDOUBLE_SEPARATOR
A esto le siguen cero argumentos adicionales. Especifica un separador en el PopupMenu. El tipo de separador es XmDOUBLE_LINE.
resource_name
A esto le sigue un argumento adicional, el valor del recurso, de tipo XtArgVal. El par especifica un recurso y su valor para el widget RowColumn.
XtVaTypedArg
A esto le siguen cuatro argumentos adicionales. El conjunto especifica un recurso y su valor para el widget RowColumn. Se realiza una conversión de tipo de recurso si es necesario. A continuación se presentan los cuatro argumentos adicionales, en orden:
name
El nombre del recurso, de tipo String
type
El tipo del valor del recurso proporcionado, de tipo String
value
El valor del recurso (o un puntero al valor del recurso, dependiendo del tipo y tamaño del valor), de tipo XtArgVal
size
El tamaño del valor del recurso en bytes, de tipo int
XtVaNestedList
A esto le sigue un argumento adicional de tipo XtVarArgsList. Este argumento es una lista anidada de varargs devuelta por XtVaCreateArgsList.

Para obtener más información sobre listas de argumentos de longitud variable, consulte la documentación de X Toolkit Intrinsics.

Existen varios recursos específicos para su uso con esta y otras rutinas de creación de menús simples. Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETURN

Devuelve el ID del widget RowColumn.

XmVaCreateSimplePopupMenu(3)

XmVaCreateSimplePopupMenu, XmVaCreateSimpleMenuBar, XmVaCreateSimpleOptionMenu

create simple pop-up menus, menus, and option menus

SYNOPSIS

#include <Xm/Xm.h>
#include <Xm/RowColumn.h>

Widget XmVaCreateSimplePopupMenu(
    Widget parent,
    String name,
    ArgList arglist,
    Cardinal argcount,
    ... );

Widget XmVaCreateSimpleMenuBar(
    Widget parent,
    String name,
    ArgList arglist,
    Cardinal argcount,
    ... );

Widget XmVaCreateSimpleOptionMenu(
    Widget parent,
    String name,
    ArgList arglist,
    Cardinal argcount,
    ... );

DESCRIPTION

The XmVaCreateSimplePopupMenu, XmVaCreateSimpleMenuBar, and XmVaCreateSimpleOptionMenu functions create a menu bar, a pop-up menu, or an option menu, respectively. They are simplified interfaces that allow the creation of standard menus with a variable number of children. The specific type of widget created depends on the XmNrowColumnType resource specified in the arglist.

The functions accept a variable argument list (indicated by ...) that describes the children to be created. Each argument in the list must be a pointer to a structure containing the widget class, a string for the widget name, and a list of arguments for the child widget.

The XmNrowColumnType resource determines the type of menu:

XmPopupmenu
Creates a pop-up menu.
XmMenuBar
Creates a menu bar.
XmOptionMenu
Creates an option menu.

The variable argument list should consist of structures of type XmMenuOptionRec. Each XmMenuOptionRec structure defines a menu item and its associated resources. The list is terminated by a NULL pointer.

The XmMenuOptionRec structure is defined as follows: 

typedef struct {
    WidgetClass   widget_class;
    String        widget_name;
    ArgList       arglist;
    Cardinal      argcount;
} XmMenuOptionRec, *XmMenuOptionList;

The widget_class specifies the class of the widget to create (e.g., xmPushButtonWidgetClass, xmCascadeButtonWidgetClass).

The widget_name is the name to be assigned to the widget.

The arglist and argcount specify the resources for the child widget.

RETURN

Upon successful creation, these functions return the widget ID of the created menu shell. Otherwise, they return NULL.

RELATED

XmCreatePopupMenu(3), XmCreateRowColumn(3), XmCreateSimplePopupMenu(3), and XmRowColumn(3).
