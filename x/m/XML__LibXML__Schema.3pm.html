XML::LibXML::Schema(3) Documentación de Perl contribuida por el usuario XML::LibXML::Schema(3)

NOMBRE

XML::LibXML::Schema - Validación de esquemas XML

SINOPSIS

use XML::LibXML;
$doc = XML::LibXML->new->parse_file($url);
$xmlschema = XML::LibXML::Schema->new( location => $filename_or_url, no_network => 1 );
$xmlschema = XML::LibXML::Schema->new( string => $xmlschemastring, no_network => 1 );
eval { $xmlschema->validate( $doc ); };

DESCRIPCIÓN

La clase XML::LibXML::Schema es una pequeña interfaz para la implementación de esquemas XML de libxml2. Actualmente solo admite el análisis de esquemas y la validación de documentos. A partir de la versión 2.6.32, libxml2 solo admite tipos decimales de hasta 24 dígitos (el estándar requiere al menos 18).

MÉTODOS

new
$xmlschema = XML::LibXML::Schema->new( location => $filename_or_url, no_network => 1 );
$xmlschema = XML::LibXML::Schema->new( string => $xmlschemastring, no_network => 1 );

El constructor de XML::LibXML::Schema debe llamarse con una lista de parámetros. Se requiere al menos un parámetro de ubicación o cadena para especificar la fuente del esquema. El parámetro opcional `no_network` establecido en 1 hace que el analizador no acceda a la red y el parámetro opcional `recover` establecido en 1 hace que el analizador no llame a die() en caso de error.

Es importante que cada esquema tenga una única fuente.

El parámetro `location` permite analizar un esquema desde el sistema de archivos o una URL (no HTTPS).

El parámetro `string` analizará el esquema a partir de la cadena XML dada.

Tenga en cuenta que el constructor fallará (die()) si el esquema no cumple con las restricciones de la especificación de Esquemas XML.

validar
eval { $xmlschema->validate( $doc ); };

Esta función permite validar un documento (analizado) contra el Esquema XML dado. El argumento de esta función debe ser un objeto XML::LibXML::Document. Si esta función tiene éxito, devolverá 0, de lo contrario, fallará (die()) e informará los errores encontrados. Debido a esto, validate() siempre debe ser evaluado.
