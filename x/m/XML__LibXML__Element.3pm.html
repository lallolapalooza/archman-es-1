NAME

XML::LibXML::Element - XML::LibXML Class for Element Nodes

SYNOPSIS

use XML::LibXML;
# Only methods specific to Element nodes are listed here,
# see the XML::LibXML::Node manpage for other methods
$node = XML::LibXML::Element->new( $name );
$node->setAttribute( $aname, $avalue );
$node->setAttributeNS( $nsURI, $aname, $avalue );
$avalue = $node->getAttribute( $aname );
$avalue = $node->getAttributeNS( $nsURI, $aname );
$attrnode = $node->getAttributeNode( $aname );
$attrnode = $node->getAttributeNodeNS( $namespaceURI, $aname );
$node->removeAttribute( $aname );
$node->removeAttributeNS( $nsURI, $aname );
$boolean = $node->hasAttribute( $aname );
$boolean = $node->hasAttributeNS( $nsURI, $aname );
@nodes = $node->getChildrenByTagName($tagname);
@nodes = $node->getChildrenByTagNameNS($nsURI,$tagname);
@nodes = $node->getChildrenByLocalName($localname);
@nodes = $node->getElementsByTagName($tagname);
@nodes = $node->getElementsByTagNameNS($nsURI,$localname);
@nodes = $node->getElementsByLocalName($localname);
$node->appendWellBalancedChunk( $chunk );
$node->appendText( $PCDATA );
$node->appendTextNode( $PCDATA );
$node->appendTextChild( $childname , $PCDATA );
$node->setNamespace( $nsURI , $nsPrefix, $activate );
$node->setNamespaceDeclURI( $nsPrefix, $newURI );
$node->setNamespaceDeclPrefix( $oldPrefix, $newPrefix );

METHODS

The class inherits from XML::LibXML::Node. The documentation for Inherited methods is not listed here.

Many functions listed here are extensively documented in the DOM Level 3 specification (http://www.w3.org/TR/DOM-Level-3-Core/). Please refer to the specification for extensive documentation.

new
$node = XML::LibXML::Element->new( $name );

This function creates a new node unbound to any DOM.

setAttribute
$node->setAttribute( $aname, $avalue );

This method sets or replaces the node's attribute $aname to the value $avalue

setAttributeNS
$node->setAttributeNS( $nsURI, $aname, $avalue );

Namespace-aware version of "setAttribute", where $nsURI is a namespace URI, $aname is a qualified name, and $avalue is the value. The namespace URI may be null (empty or undefined) in order to create an attribute which has no namespace.

The current implementation differs from DOM in the following aspects

If an attribute with the same local name and namespace URI already exists on the element, but its prefix differs from the prefix of $aname, then this function is supposed to change the prefix (regardless of namespace declarations and possible collisions). However, the current implementation does rather the opposite. If a prefix is declared for the namespace URI in the scope of the attribute, then the already declared prefix is used, disregarding the prefix specified in $aname. If no prefix is declared for the namespace, the function tries to declare the prefix specified in $aname and dies if the prefix is already taken by some other namespace.

According to DOM Level 2 specification, this method can also be used to create or modify special attributes used for declaring XML namespaces (which belong to the namespace "http://www.w3.org/2000/xmlns/" and have prefix or name "xmlns"). This should work since version 1.61, but again the implementation differs from DOM specification in the following: if a declaration of the same namespace prefix already exists on the element, then changing its value via this method automatically changes the namespace of all elements and attributes in its scope. This is because in libxml2 the namespace URI of an element is not static but is computed from a pointer to a namespace declaration attribute.

getAttribute
$avalue = $node->getAttribute( $aname );

If $node has an attribute with the name $aname, the value of this attribute will get returned.

getAttributeNS
$avalue = $node->getAttributeNS( $nsURI, $aname );

Retrieves an attribute value by local name and namespace URI.

getAttributeNode
$attrnode = $node->getAttributeNode( $aname );

Retrieve an attribute node by name. If no attribute with a given name exists, "undef" is returned.

getAttributeNodeNS
$attrnode = $node->getAttributeNodeNS( $namespaceURI, $aname );

Retrieves an attribute node by local name and namespace URI. If no attribute with a given localname and namespace exists, "undef" is returned.

removeAttribute
$node->removeAttribute( $aname );

The method removes the attribute $aname from the node's attribute list, if the attribute can be found.

removeAttributeNS
$node->removeAttributeNS( $nsURI, $aname );

Namespace version of "removeAttribute"

hasAttribute
$boolean = $node->hasAttribute( $aname );

This function tests if the named attribute is set for the node. If the attribute is specified, TRUE (1) will be returned, otherwise the return value is FALSE (0).

hasAttributeNS
$boolean = $node->hasAttributeNS( $nsURI, $aname );

namespace version of "hasAttribute"

getChildrenByTagName
@nodes = $node->getChildrenByTagName($tagname);

The function gives direct access to all child elements of the current node with a given tagname, where tagname is a qualified name, that is, in case of namespace usage it may consist of a prefix and local name. This function makes things a lot easier if one needs to handle big data sets. A special tagname '*' can be used to match any name.

If this function is called in SCALAR context, it returns the number of elements found.

getChildrenByTagNameNS
@nodes = $node->getChildrenByTagNameNS($nsURI,$tagname);

Namespace version of "getChildrenByTagName". A special nsURI '*' matches any namespace URI, in which case the function behaves just like "getChildrenByLocalName".

If this function is called in SCALAR context, it returns the number of elements found.

getChildrenByLocalName
@nodes = $node->getChildrenByLocalName($localname);

The function gives direct access to all child elements of the current node with a given local name. It makes things a lot easier if one needs to handle big data sets. A special "localname" '*' can be used to match any local name.

If this function is called in SCALAR context, it returns the number of elements found.

getElementsByTagName
@nodes = $node->getElementsByTagName($tagname);

This function behaves just like "getChildrenByTagName", except that it searches the whole document tree, not just the direct children.

If this function is called in SCALAR context, it returns the number of elements found.

getElementsByTagNameNS
@nodes = $node->getElementsByTagNameNS($nsURI,$tagname);

Namespace version of "getElementsByTagName". A special nsURI '*' matches any namespace URI, in which case the function behaves just like "getElementsByLocalName".

If this function is called in SCALAR context, it returns the number of elements found.

getElementsByLocalName
@nodes = $node->getElementsByLocalName($localname);

This function behaves just like "getChildrenByLocalName", except that it searches the whole document tree, not just the direct children.

If this function is called in SCALAR context, it returns the number of elements found.

appendWellBalancedChunk
$node->appendWellBalancedChunk( $chunk );

Appends a chunk of HTML or XML markup to the node. The chunk has to be well-balanced, otherwise an exception is thrown.

appendText
$node->appendText( $PCDATA );

Replaces the content of the element with the given text node. This will remove all children and attributes of the element.

appendTextNode
$node->appendTextNode( $PCDATA );

Appends a text node to the current node. The text is added after the last child of the node.

appendTextChild
$node->appendTextChild( $childname , $PCDATA );

Creates a new element specified by $childname and appends it as a child to the current node. If $PCDATA is given, it is appended as a text node to the new child.

setNamespace
$node->setNamespace( $nsURI , $nsPrefix, $activate );

Declares a namespace URI with a given prefix on the element. If $activate is true, the namespace is declared on the element itself. If $activate is false, the namespace is declared on the parent element. This is useful for declaring namespaces that are used by child elements but not by the element itself.

If an error occurs, an exception is thrown.

setNamespaceDeclURI
$node->setNamespaceDeclURI( $nsPrefix, $newURI );

Changes the namespace URI associated with a given namespace prefix on the element.

If an error occurs, an exception is thrown.

setNamespaceDeclPrefix
$node->setNamespaceDeclPrefix( $oldPrefix, $newPrefix );

Changes the namespace prefix associated with a given namespace URI on the element. This operation can fail if the new prefix is already in use.

If an error occurs, an exception is thrown.

toString
$string = $node->toString( \$indent_size, \$format );

Returns a string representation of the node. If \$indent_size is defined, the output will be pretty-printed with the specified indentation. If \$format is true, XML declaration will be included.

toStringEx
$string = $node->toStringEx( \$indent_size, \$format, \$encoding, \$xmlOutput );

Same as toString but allows specifying the output encoding and whether to output the XML declaration.

MÉTODOS

getElementsByTagName
@nodos = $nodo->getElementsByTagName($nombreEtiqueta);

Esta función es parte de la especificación. Recupera todos los descendientes de un nodo con un nombre de etiqueta dado, donde "nombreEtiqueta" es un nombre calificado, es decir, en caso de uso de espacios de nombres puede consistir en un prefijo y un nombre local. Se puede usar un "nombreEtiqueta" especial "*" para que coincida con cualquier nombre de etiqueta.

En contexto ESCALAR, esta función devuelve un objeto XML::LibXML::NodeList.

getElementsByTagNameNS
@nodos = $nodo->getElementsByTagNameNS($URI_ns,$nombreLocal);

Versión para espacios de nombres de "getElementsByTagName" como se encuentra en la especificación DOM. Se puede usar un "nombreLocal" especial "*" para que coincida con cualquier nombre local y "URI_ns" "*" para que coincida con cualquier URI de espacio de nombres.

En contexto ESCALAR, esta función devuelve un objeto XML::LibXML::NodeList.

getElementsByLocalName
@nodos = $nodo->getElementsByLocalName($nombreLocal);

Esta función no se encuentra en la especificación DOM. Es una combinación de getElementsByTagName y getElementsByTagNameNS. Recuperará todas las etiquetas que coincidan con el nombre local dado. Esto permite seleccionar etiquetas con el mismo nombre local a través de los bordes de los espacios de nombres.

En contexto ESCALAR, esta función devuelve un objeto XML::LibXML::NodeList.

appendWellBalancedChunk
$nodo->appendWellBalancedChunk( $trozo );

A veces es necesario añadir un árbol XML codificado en cadena a un nodo. appendWellBalancedChunk hará el truco por usted. Pero esto solo se hace si la cadena está "bien balanceada".

Tenga en cuenta que appendWellBalancedChunk() solo se deja por razones de compatibilidad. Implícitamente utiliza

my $fragmento = $parser->parse_balanced_chunk( $trozo );
 $nodo->appendChild( $fragmento );

Esta forma es más explícita y facilita el control del flujo de un script.

appendText
$nodo->appendText( $PCDATA );

alias de appendTextNode().

appendTextNode
$nodo->appendTextNode( $PCDATA );

Esta función envoltorio le permite añadir una cadena directamente a un nodo de elemento.

appendTextChild
$nodo->appendTextChild( $nombreHijo , $PCDATA );

Algo similar a "appendTextNode": Le permite establecer un elemento, que contiene solo un "nodo de texto" directamente especificando el nombre y el contenido de texto.

setNamespace
$nodo->setNamespace( $URI_ns , $prefijo_ns, $activar );

setNamespace() permite aplicar un espacio de nombres a un elemento. La función toma tres parámetros: 1. la URI del espacio de nombres, que es obligatoria y los dos valores opcionales prefijo, que es el prefijo del espacio de nombres, tal como debe usarse en elementos hijos o atributos, así como el parámetro adicional de activación. Si el prefijo no se proporciona, es indefinido o está vacío, esta función intenta crear una declaración del espacio de nombres predeterminado.

El parámetro de activación es muy útil: si este parámetro se establece en FALSE (0), simplemente se añade una nueva declaración de espacio de nombres al elemento, mientras que el espacio de nombres del propio elemento no se altera. Sin embargo, activar se establece en TRUE (1) por defecto. En este caso, el espacio de nombres se utiliza como el espacio de nombres efectivo del nodo. Esto significa que el prefijo del espacio de nombres se añade al nombre del nodo y si ya había un espacio de nombres activo para el nodo, será reemplazado (pero su declaración no se elimina del documento). Solo se crea una nueva declaración de espacio de nombres si es necesario (es decir, si el elemento ya está en el ámbito de una declaración de espacio de nombres que asocia el prefijo con la URI del espacio de nombres, entonces se reutiliza esa declaración).

El siguiente ejemplo puede aclarar esto:

my $e1 = $doc->createElement("bar");
 $e1->setNamespace("http://foobar.org", "foo")

resultados

<foo:bar xmlns:foo="http://foobar.org"/>

mientras que

my $e2 = $doc->createElement("bar");
 $e2->setNamespace("http://foobar.org", "foo",0)

solo da como resultado

<bar xmlns:foo="http://foobar.org"/>

Al usar $activar == 0 es posible crear múltiples declaraciones de espacio de nombres en un solo elemento.

La función falla si es necesario crear una declaración que asocie el prefijo con la URI del espacio de nombres, pero el elemento ya tiene una declaración con el mismo prefijo pero diferente URI del espacio de nombres.

setNamespaceDeclURI
$nodo->setNamespaceDeclURI( $prefijo_ns, $nueva_URI );

¡EXPERIMENTAL EN 1.61!

Esta función manipula directamente una declaración de espacio de nombres existente en un elemento. Toma dos parámetros: el prefijo por el que busca la declaración del espacio de nombres y una nueva URI del espacio de nombres que reemplaza su valor anterior.

Devuelve 1 si se encontró y modificó la declaración del espacio de nombres, 0 en caso contrario.

Todos los elementos y atributos (incluso aquellos previamente no vinculados al documento) para los que la declaración del espacio de nombres determina su espacio de nombres pertenecen al nuevo espacio de nombres después del cambio.

Si la nueva URI es indefinida o está vacía, los nodos no tienen espacio de nombres ni prefijo después del cambio. Las declaraciones de espacio de nombres una vez anuladas de esta manera no aparecen más en la salida serializada (pero permanecen en el documento para la integridad interna de las estructuras de datos de libxml2).

Esta función NO forma parte de ninguna API DOM.

setNamespaceDeclPrefix
$nodo->setNamespaceDeclPrefix( $prefijo_antiguo, $prefijo_nuevo );

¡EXPERIMENTAL EN 1.61!

Esta función manipula directamente una declaración de espacio de nombres existente en un elemento. Toma dos parámetros: el prefijo antiguo por el que busca la declaración del espacio de nombres y un nuevo prefijo que reemplazará al antiguo.

La función muere con un error si el elemento está en el ámbito de otra declaración cuyo prefijo es igual al prefijo nuevo, o si el cambio resultaría en una declaración con un prefijo no vacío pero una URI de espacio de nombres vacía. De lo contrario, devuelve 1 si se encontró y modificó la declaración del espacio de nombres y 0 si no se encontró.

Todos los elementos y atributos (incluso aquellos previamente no vinculados al documento) para los que la declaración del espacio de nombres determina su espacio de nombres cambian su prefijo al nuevo valor.

Si el prefijo nuevo es indefinido o está vacío, la declaración del espacio de nombres se convierte en una declaración de un espacio de nombres predeterminado. Los nodos correspondientes pierden su prefijo de espacio de nombres (pero permanecen en el espacio de nombres, ahora predeterminado). En este caso, la función falla si el elemento contenedor está en el ámbito de otra declaración de espacio de nombres predeterminado.

Esta función NO forma parte de ninguna API DOM.

SOBRECARGA

XML::LibXML::Element sobrecarga la desreferenciación de hashes para proporcionar acceso a los atributos del elemento. Para atributos que no usan espacios de nombres, el nombre del atributo es la clave del hash y el valor del atributo es el valor del hash. Para atributos que usan espacios de nombres, la clave del hash está calificada con la URI del espacio de nombres, utilizando la notación de Clark.

Se utiliza la característica de Perl "hash enlazado", lo que significa que el hash le da acceso de lectura/escritura a los atributos del elemento. Para más información, consulte XML::LibXML::AttributeHash
