NOMBRE

XmDropDownGetChild — Una función DropDown que se utiliza para acceder a un componente

SINOPSIS

#include <Xm/DropDown.h>
Widget XmDropDownGetChild(
Widget widget,
int child);

DESCRIPCIÓN

XmDropDownGetChild se utiliza para acceder a un componente dentro de un DropDown. Los parámetros dados a la función son el widget DropDown y un valor que indica qué componente acceder.

widget
Especifica el ID del widget DropDown.
child
Especifica un componente dentro del DropDown. Los siguientes son valores legales para este parámetro:
•
XmDROPDOWN_LABEL
•
XmDROPDOWN_TEXT
•
XmDROPDOWN_ARROW_BUTTON
•
XmDROPDOWN_LIST

Para una definición completa de DropDown y sus recursos asociados, consulte XmDropDown(3).

RETORNO

Devuelve el ID del widget del componente DropDown especificado. Una aplicación no debe asumir que el widget devuelto será de ninguna clase en particular.

RELACIONADO

XmDropDown(3).
