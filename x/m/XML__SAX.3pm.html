XML::SAX(3) Documentación de Perl contribuida por el usuario XML::SAX(3)

NOMBRE

XML::SAX - API Simple para XML

SINOPSIS

use XML::SAX;

# obtener una lista de analizadores conocidos
my $parsers = XML::SAX->parsers();

# añadir/actualizar un analizador
XML::SAX->add_parser(q(XML::SAX::PurePerl));
# eliminar analizador
XML::SAX->remove_parser(q(XML::SAX::Foodelberry));
# guardar analizadores
XML::SAX->save_parsers();

DESCRIPCIÓN

XML::SAX es una API de analizador SAX para Perl. Incluye clases y APIs necesarias para implementar drivers SAX, junto con una clase fábrica para devolver cualquier analizador SAX instalado en el sistema del usuario.

USANDO UN ANALIZADOR SAX2

La clase fábrica es XML::SAX::ParserFactory. Por favor, consulte la documentación de ese módulo para saber cómo instanciar un analizador SAX: XML::SAX::ParserFactory. Sin embargo, si no desea cargar otra página de manual, aquí tiene una breve sinopsis:

use XML::SAX::ParserFactory;
use XML::SAX::XYZHandler;
my $handler = XML::SAX::XYZHandler->new();
my $p = XML::SAX::ParserFactory->parser(Handler => $handler);
$p->parse_uri("foo.xml");
# o $p->parse_string("<foo/>") o $p->parse_file($fh);

Esto cargará automáticamente un analizador SAX2 (por defecto XML::SAX::PurePerl si no se encuentran otros) y se lo devolverá.

Para aprender a usar SAX para analizar XML, necesitará leer XML::SAX::Intro y como referencia, XML::SAX::Specification.

ESCRIBIENDO UN ANALIZADOR SAX2

Lo primero que hay que recordar al escribir un analizador SAX2 es subclasar XML::SAX::Base. Esto hará su vida infinitamente más fácil, proporcionando automáticamente varios métodos. Consulte XML::SAX::Base para más detalles.

Al escribir un analizador SAX2 que sea compatible con XML::SAX, debe informar a XML::SAX de la presencia de ese driver al instalarlo. Para ello, XML::SAX contiene métodos para guardar el hecho de que el analizador existe en su sistema en un archivo "INI", que luego se carga para determinar qué analizadores están instalados.

La mejor manera de hacerlo es seguir estas reglas:

  • Añada XML::SAX como requisito previo en Makefile.PL: 
    WriteMakefile(
    ...
    PREREQ_PM => { 'XML::SAX' => 0 },
    ...
);

    Alternativamente, puede que desee comprobarlo de otras maneras que causen más que una advertencia.

  • Añada el siguiente fragmento de código a su Makefile.PL: 
    sub MY::install {
  package MY;
  my $script = shift->SUPER::install(@_);
  if (ExtUtils::MakeMaker::prompt(
    "¿Desea modificar ParserDetails.ini?", 'Y')
    =~ /^y/i) {
    $script =~ s/install :: (.*)$/install :: $1 install_sax_driver/m;
    $script .= <<"INSTALL";

install_sax_driver :
\t\@\$(PERL) -MXML::SAX -e "XML::SAX->add_parser(q(\$(NAME)))->save_parsers()"

INSTALL
  }
  return $script;
}

    Tenga en cuenta que debe comprobar la salida de esto - \$(NAME) utilizará el nombre de su distribución, que puede no ser exactamente lo que desea. Por ejemplo, XML::LibXML tiene un driver llamado XML::LibXML::SAX::Generator, que se utiliza en lugar de \$(NAME) en el anterior.

  • Añada una prueba de XML::SAX:

    Se debe añadir un archivo de prueba al directorio t/ que contenga algo como lo siguiente:

    use Test;
BEGIN { plan tests => 3 }
use XML::SAX;
use XML::SAX::PurePerl::DebugHandler;
XML::SAX->add_parser(q(XML::SAX::MyDriver));
local $XML::SAX::ParserPackage = 'XML::SAX::MyDriver';
eval {
  my $handler = XML::SAX::PurePerl::DebugHandler->new();
  ok($handler);
  my $parser = XML::SAX::ParserFactory->parser(Handler => $handler);
  ok($parser);
  ok($parser->isa('XML::SAX::MyDriver');
  $parser->parse_string("<tag/>");
  ok($handler->{seen}{start_element});
};

EXPORTA

Por defecto, XML::SAX no exporta nada al espacio de nombres del llamante. Sin embargo, puede solicitar los símbolos "Namespaces" y "Validation" que son las URIs para esas características, permitiendo una forma más fácil de solicitar esas características a través de ParserFactory:

use XML::SAX qw(Namespaces Validation);
my $factory = XML::SAX::ParserFactory->new();
$factory->require_feature(Namespaces);
$factory->require_feature(Validation);
my $parser = $factory->parser();
