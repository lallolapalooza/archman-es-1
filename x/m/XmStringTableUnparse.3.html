XmStringTableUnparse(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringTableUnparse(llamada a biblioteca) XmStringTableUnparse(llamada a biblioteca)

NOMBRE

XmStringTableUnparse — Una función de conveniencia que convierte una tabla de cadenas compuestas a un array de texto

SINOPSIS

#include <Xm/Xm.h>
XtPointer * XmStringTableUnparse(
XmStringTable table,
Cardinal count,
XmStringTag tag,
XmTextType tag_type,
XmTextType output_type,
XmParseTable parse,
Cardinal parse_count,
XmParseModel parse_model);

DESCRIPCIÓN

XmStringTableUnparse toma un array de cadenas compuestas, asigna un array de cadenas para el tipo de caracteres determinado por type con un número igual de ranuras, llama a XmStringUnparse en cada cadena compuesta en table, e inserta la cadena resultante en la ranura correspondiente del array.

table
Especifica una XmStringTable que contiene la cadena compuesta a convertir.
count
Especifica el número de cadenas compuestas en table.
tag
Especifica la etiqueta a utilizar para la coincidencia con segmentos de texto. Los dos tipos de etiquetas son XmFONTLIST_DEFAULT_TAG y _MOTIF_DEFAULT_LOCALE. Solo se devolverán los segmentos etiquetados con tag. Si tag es NULL, se coincidirán todos los segmentos.
tag_type
Especifica el tipo de etiqueta a buscar. Estos tipos incluyen XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT y XmCHARSET_TEXT.
output_type
Especifica el tipo de texto a generar. Estos tipos incluyen XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT y XmCHARSET_TEXT.
parse
Especifica la tabla de análisis a utilizar.
parse_count
Especifica el número de elementos en parse.
parse_model
Especifica qué componentes no textuales se deben considerar en la coincidencia en parse_table. Los valores posibles son:
XmOUTPUT_ALL
Genera todos los componentes coincidentes.
XmOUTPUT_BETWEEN
Genera solo aquellos componentes coincidentes que se encuentran entre dos componentes de texto coincidentes.
XmOUTPUT_BEGINNING
Genera solo aquellos componentes coincidentes que se encuentran al principio de un componente de texto coincidente.
XmOUTPUT_END
Genera solo aquellos componentes coincidentes que se encuentran al final de un componente de texto coincidente.
XmOUTPUT_BOTH
Genera solo aquellos componentes coincidentes que se encuentran al principio o al final de un componente de texto coincidente.

RETORNO

Devuelve un array asignado de cadenas asignadas. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio de las cadenas asignadas llamando a XtFree count veces (es decir, una vez por cada cadena asignada). Luego, la aplicación puede recuperar el array asignado llamando a XtFree en el propio array asignado.

RELACIONADO

XmStringTab.
