XmTextFindString(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmTextFindString(llamada a biblioteca) XmTextFindString(llamada a biblioteca)

NOMBRE

XmTextFindString — Una función de Texto que encuentra la posición inicial de una cadena de texto

SINOPSIS

#include <Xm/Xm.h>
Boolean XmTextFindString(
Widget widget,
XmTextPosition start,
char *string,
XmTextDirection direction,
XmTextPosition *position);

DESCRIPCIÓN

XmTextFindString localiza la posición inicial de una cadena de texto especificada. Esta rutina busca hacia adelante o hacia atrás la primera ocurrencia de la cadena comenzando desde la posición de inicio dada. Si encuentra una coincidencia, la función devuelve la posición del primer carácter de la cadena en position. Si la cadena de coincidencia comienza en la posición actual, esta rutina devuelve la posición actual.

widget
Especifica el ID del widget de Texto.
start
Especifica la posición del carácter desde la cual se realiza la búsqueda. Este es un número entero de caracteres desde el principio del búfer de texto. La primera posición de carácter es 0 (cero).
string
Especifica la cadena de búsqueda.
direction
Indica la dirección de la búsqueda. Es relativa a la dirección principal del texto. Los valores posibles son
XmTEXT_FORWARD
La búsqueda procede hacia el final del búfer de texto.
XmTEXT_BACKWARD
La búsqueda procede hacia el principio del búfer de texto.
position
Especifica el puntero en el cual se devuelve la posición del primer carácter de la coincidencia de cadena. Este es un número entero de caracteres desde el principio del búfer. La primera posición de carácter es 0 (cero). Si la función devuelve False, este valor no está definido.

Para una definición completa de Texto y sus recursos asociados, consulte XmText(3).

RETORNAR

Devuelve True si se encuentra una coincidencia de cadena; de lo contrario, devuelve False.

RELACIONADO

XmText(3) y XmTextFindStringWcs(3).
