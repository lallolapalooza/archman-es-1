XmClipboardInquireLength(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

NOMBRE

XmClipboardInquireLength — Una función del portapapeles que devuelve la longitud de los datos almacenados

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardInquireLength (display, window, format_name, length)
        Display * display;
        Window  window;
        char    * format_name;
        unsigned long   * length;
(void)

DESCRIPCIÓN

XmClipboardInquireLength devuelve la longitud de los datos almacenados bajo un nombre de formato especificado para el elemento de datos del portapapeles. Si no se encuentran datos para el formato especificado, o si no hay ningún elemento en el portapapeles, esta función devuelve un valor de 0 (cero) en el argumento length.

Se asume que cualquier formato pasado por nombre tiene length pasado en una llamada a XmClipboardCopy, aunque los datos aún no se hayan transferido al portapapeles en ese formato.

display
Especifica un puntero a la estructura Display que fue devuelta en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debería pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llame.
format_name
Especifica el nombre del formato para el elemento de datos.
length
Especifica la longitud del siguiente elemento de datos en el formato especificado. Este argumento es igual a 0 (cero) si no se encuentran datos para el formato especificado, o si no hay ningún elemento en el portapapeles.

RETORNAR

XmClipboardSuccess
La función se realizó con éxito.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función de nuevo con los mismos parámetros hasta que el bloqueo desaparezca. Esto da a la aplicación la oportunidad de preguntar si el usuario quiere seguir intentando o abandonar la operación.
XmClipboardNoData
La función no pudo encontrar datos en el portapapeles correspondientes al formato solicitado. Esto podría ocurrir porque el portapapeles está vacío; hay datos en el portapapeles, pero no en el formato solicitado; o los datos en el formato solicitado se pasaron por nombre y ya no están disponibles.

RELACIONADO

XmClipboardCopy(3) y XmClipboardStartCopy(3).
