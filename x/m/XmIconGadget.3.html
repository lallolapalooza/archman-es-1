NOMBRE

XmIconGadget — La clase del widget IconGadget

SINOPSIS

#include <Xm/IconG.h>

DESCRIPCIÓN

IconGadget es un widget instanciable utilizado para mostrar tanto texto como un pixmap en varias combinaciones. Otros widgets que contienen el rasgo XmQTcontainer, como Container, pueden usar IconGadget para representar objetos.

El texto de IconGadget es una cadena compuesta. Si no se proporciona texto, la cadena compuesta se genera a partir del nombre del gadget. El texto de IconGadget se coloca en relación con el tipo de pixmap asociado.

Dependiendo del recurso XmNviewType, IconGadget puede mostrar dos vistas:

XmLARGE_ICON
La cadena de texto de IconGadget se muestra debajo del pixmap y centrada.
XmSMALL_ICON
La cadena de texto de IconGadget se coloca al lado del icono pequeño, en la dirección XmNlayoutDirection del widget.

Se puede proporcionar una máscara de mapa de bits para cada pixmap para recortar el pixmap a una forma distinta de un rectángulo. Los recursos XmNlargeIconMask y XmNsmallIconMask especifican las máscaras de mapa de bits grandes y pequeñas respectivamente. El énfasis visual para IconGadget se proporciona con el recurso XmNvisualEmphasis. Los recursos XmNdetail y XmNdetailCount de IconGadget proporcionan una vista detallada para IconGadgets, permitiendo la visualización de cadenas junto al IconGadget. El orden exacto de la disposición de las cadenas depende del widget contenedor asociado.

IconGadget utiliza los rasgos XmQTcontainer y XmQTspecifyRenderTable, y contiene los rasgos XmQTcareParentVisual y XmQTcontainerItem.

CLASES

IconGadget hereda comportamiento, recursos y rasgos de las clases Object, RectObject y XmGadget.

El puntero de clase es xmIconGadgetClass.

El nombre de la clase es XmIconGadget.

NUEVOS RECURSOS

La siguiente tabla define un conjunto de recursos del widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúsculas o mayúsculas, pero incluya cualquier guión bajo entre palabras). Los códigos en la columna de acceso indican si el recurso dado puede establecerse en el momento de la creación (C), establecerse mediante XtSetValues (S), recuperarse mediante XtGetValues (G), o no es aplicable (N/A).

XmNalignment
Especifica la alineación horizontal del píxel con respecto a la etiqueta cuando el icono está en la vista LARGE_ICON. Los valores válidos son XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER y XmALIGNMENT_END.
XmNdetail
Especifica una matriz de XmString que son la información de detalle asociada con el gadget.
XmNdetailCount
Especifica el tamaño de la matriz XmNdetail.
XmNfontList
Especifica la lista de fuentes asociada con XmIconGadget. La lista de fuentes es una construcción obsoleta y ha sido reemplazada por la tabla de renderizado. Se incluye para compatibilidad con versiones anteriores de Motif y para aplicaciones que no admiten fácilmente tablas de renderizado. La lista de fuentes predeterminada se deriva de la tabla de renderizado predeterminada, y si se especifican tanto una lista de fuentes como una tabla de renderizado, la tabla de renderizado tiene prioridad.
XmNlabelString
Especifica la cadena compuesta. Si este valor es NULL, se inicializa convirtiendo el nombre del gadget a una cadena compuesta. Consulte XmString(3) para obtener más información sobre la creación y estructura de las cadenas compuestas.
XmNlargeIconMask
Especifica la máscara de icono utilizada cuando XmNviewType es XmLARGE_ICON.
XmNlargeIconPixmap
Especifica el píxel cuando XmNviewType es XmLARGE_ICON. Si el valor de este recurso es XmUNSPECIFIED_PIXMAP, no hay píxel. Si se especifica un píxel de icono grande y si durante la conversión se puede obtener una máscara asociada, entonces el recurso XmNlargeIconMask se establece en esa máscara.
XmNmarginHeight
Especifica la cantidad de espacio vertical entre el resaltado y el interior (píxel y etiqueta).
XmNmarginWidth
Especifica la cantidad de espacio horizontal entre el resaltado y el interior (píxel y etiqueta).
XmNrenderTable
Especifica la XmRenderTable del texto utilizado en el gadget. Si XmNrenderTable es NULL cuando se crea el IconGadget, se utiliza el valor del recurso de la tabla de renderizado del padre si existe una tabla de renderizado. Si el padre no tiene una tabla de renderizado, se busca en la jerarquía del padre un widget que contenga el trait XmQTspecifyRenderTable. Si se encuentra un antecesor de este tipo, la tabla de renderizado se inicializa con el valor XmLABEL_RENDER_TABLE del widget antecesor. Si no se encuentra dicho widget, el valor predeterminado depende de la implementación. Consulte XmRenderTable(3) para obtener más información sobre la creación y estructura de una XmRenderTable. Si se especifican tanto una tabla de renderizado como una lista de fuentes, la tabla de renderizado tendrá prioridad.
XmNsmallIconMask
Especifica la máscara de icono utilizada cuando XmNviewType es XmSMALL_ICON.
XmNsmallIconPixmap
Especifica el píxel cuando XmNviewType es XmSMALL_ICON. Si el valor de este recurso es XmUNSPECIFIED_PIXMAP, no hay píxel. Si se especifica un píxel de icono pequeño y si durante la conversión se puede obtener una máscara asociada, entonces el recurso XmNsmallIconMask se establece en esa máscara.
XmNspacing
Especifica la cantidad de espacio entre las partes del píxel y la etiqueta del icono.
XmNviewType
Especifica la vista (combinación de píxeles/texto) que se mostrará. Si el IconGadget es un hijo de un widget Container, sin embargo, la especificación de este recurso se tomará del Container; si XmNentryViewType del Container es XmLARGE_ICON o XmSMALL_ICON, entonces el XmNviewType del IconGadget toma ese valor; de lo contrario, el valor predeterminado es XmLARGE_ICON. Este recurso se establece en uno de los siguientes:
XmLARGE_ICON
Se muestra el píxel especificado por XmNlargeIconPixmap con el XmNlabelString debajo.
XmSMALL_ICON
Se muestra el píxel especificado por XmNsmallIconPixmap con el XmNlabelString mostrado en la dirección del recurso XmNlayoutDirection.
XmNvisualEmphasis
Especifica el estado visual del IconGadget. Si el IconGadget está en un estado seleccionado, todas las visuales se muestran utilizando el recurso XmNselectColor del Container. Se establece en uno de los siguientes:
XmSELECTED
El IconGadget está en estado seleccionado y muestra las visuales apropiadas.
XmNOT_SELECTED
El IconGadget no está en estado seleccionado.
