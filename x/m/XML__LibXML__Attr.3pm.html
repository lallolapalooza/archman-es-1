XML::LibXML::Attr(3) Documentación contribuida por el usuario de Perl XML::LibXML::Attr(3)

NOMBRE

XML::LibXML::Attr - Clase de Atributos de XML::LibXML

SINOPSIS

use XML::LibXML;
# Solo se enumeran aquí los métodos específicos de los nodos de Atributo,
# consulta la página del manual de XML::LibXML::Node para otros métodos
$attr = XML::LibXML::Attr->new($nombre [,$valor]);
$cadena = $attr->getValue();
$cadena = $attr->value;
$attr->setValue( $cadena );
$nodo = $attr->getOwnerElement();
$attr->setNamespace($nsURI, $prefijo);
$booleano = $attr->isId;
$cadena = $attr->serializeContent;

DESCRIPCIÓN

Esta es la interfaz para manejar Atributos como nodos ordinarios. La denominación de la clase se basa en la documentación W3C DOM.

MÉTODOS

La clase hereda de XML::LibXML::Node. La documentación de los métodos heredados no se incluye aquí.

Muchas de las funciones enumeradas aquí están extensamente documentadas en la especificación DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Por favor, consulta la especificación para obtener documentación exhaustiva.

new
$attr = XML::LibXML::Attr->new($nombre [,$valor]);

Constructor de clase. Si necesitas trabajar con cadenas codificadas en ISO, deberías usar *siempre* la función "createAttribute" de XML::LibXML::Document.

getValue
$cadena = $attr->getValue();

Devuelve el valor almacenado para el atributo. Si se devuelve undef, el atributo no tiene valor, lo cual es diferente de estar "no especificado".

value
$cadena = $attr->value;

Alias de getValue()

setValue
$attr->setValue( $cadena );

Esto es necesario para establecer un nuevo valor de atributo. Si se pasan cadenas codificadas en ISO como parámetro, el nodo debe estar vinculado a un documento, de lo contrario, la codificación podría realizarse incorrectamente.

getOwnerElement
$nodo = $attr->getOwnerElement();

devuelve el nodo al que pertenece el atributo. Si el atributo no está vinculado a un nodo, se devolverá undef. Al sobrescribir la implementación subyacente, la función parentNode devolverá undef, en lugar del elemento propietario.

setNamespace
$attr->setNamespace($nsURI, $prefijo);

Esta función intenta vincular el atributo a un espacio de nombres dado. Si $nsURI es indefinido o vacío, la función descarta cualquier asociación previa del atributo con un espacio de nombres. Si el espacio de nombres no se declaró previamente en el contexto del atributo, esta función fallará. En este caso, puede que desees llamar a setNamespace() en el elemento propietario. Si el URI del espacio de nombres no está vacío y se declara en el contexto del atributo, pero solo con un prefijo diferente (no vacío), entonces el atributo todavía está vinculado al espacio de nombres pero obtiene un prefijo diferente al de $prefijo. La función también falla si el prefijo está vacío pero el URI del espacio de nombres no lo está (porque los atributos sin prefijo, por definición, no deben pertenecer a ningún espacio de nombres). Esta función devuelve 1 si tiene éxito, 0 en caso contrario.

isId
$booleano = $attr->isId;

Determina si un atributo es de tipo ID. Para documentos con una DTD, esta información solo está disponible si se solicitó la carga/validación de la DTD. Para documentos HTML analizados con el analizador HTML, la detección de ID se realiza automáticamente. En documentos XML, todos los atributos "xml:id" se consideran de tipo ID.

serializeContent($docencoding)
$cadena = $attr->serializeContent;

Esta función no forma parte de la API DOM. Devuelve el contenido del atributo en la forma en que se serializa en XML, es decir, con todos los metacaracteres debidamente citados y con referencias a entidades crudas (excepto las entidades expandidas durante el análisis). Establecer el parámetro opcional $docencoding a 1 fuerza la codificación del documento para la cadena de salida (que luego se pasa a Perl como una cadena de bytes). De lo contrario, la cadena se pasa a Perl como caracteres (codificados en UTF-8).
