XmStringTableParseStringArray(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringTableParseStringArray(llamada de biblioteca) XmStringTableParseStringArray(llamada de biblioteca)

NOMBRE

XmStringTableParseStringArray — Una función de conveniencia que convierte un array de cadenas en una tabla de cadenas compuestas

SINOPSIS

#include <Xm/Xm.h>
XmStringTable XmStringTableParseStringArray(
XtPointer *strings,
Cardinal count,
XmStringTag tag,
XmTextType type,
XmParseTable parse,
Cardinal parse_count,
XtPointer call_data);

DESCRIPCIÓN

XmStringTableParseStringArray toma un array de cadenas, asigna una XmStringTable con un número igual de ranuras, llama a XmStringParseText en cada cadena de strings, e inserta la resultante XmString en la ranura correspondiente de la XmStringTable.

strings
Especifica un array de cadenas de caracteres determinado por type.
count
Especifica el número de cadenas en strings.
tag
Especifica la etiqueta que se utilizará en la creación del resultado. El tipo de etiqueta creada (charset o locale) depende del tipo del texto y el valor dado. Si el valor especificado es NULL, y type indica que se debe crear una etiqueta charset, entonces la etiqueta tendrá el valor de XmFONTLIST_DEFAULT_TAG. Si type indica una etiqueta locale, entonces la etiqueta tendrá el valor de XmFONTLIST_DEFAULT_TAG.
type
Especifica el tipo de texto a pasar y el tipo de etiqueta. Si el tipo es XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT, se debe crear una etiqueta locale. Si el tipo es XmCHARSET_TEXT, se creará una etiqueta charset.
parse
Especifica la tabla de análisis a utilizar.
parse_count
Especifica el número de entradas en la tabla de análisis.
call_data
Especifica los datos a pasar a los procedimientos de análisis.

RETORNO

Devuelve una nueva XmStringTable. La función asigna espacio para contener la XmStringTable. Cuando la aplicación ya no necesite la XmStringTable devuelta, la aplicación debe llamar a XmStringFree count veces (es decir, una vez por cada cadena compuesta devuelta) y luego llamar a XtFree para desasignar la propia XmStringTable.

RELACIONADO

XmStringFree(3) y XmTabList(3).
