NOMBRE

XmTabList — Tipo de datos para una lista de tabulaciones

SINOPSIS

#include <Xm/Xm.h>
XmTabList

DESCRIPCIÓN

XmTabList es el tipo de datos para una lista de tabulaciones. Una lista de tabulaciones consta de entradas de lista de puntos de tabulación (XmTabs). Cada vez que se encuentra un componente de tabulación mientras se está representando un XmString, el origen del siguiente dibujo X depende del siguiente XmTab. Si un punto de tabulación hiciera que el texto se solapara, la posición x del segmento se restablecería para seguir inmediatamente después del final del segmento anterior.

Las listas de tabulaciones se especifican en archivos de recursos con la siguiente sintaxis:

especificación_recurso: tabulación ESPACIO [, ESPACIO tabulación ]*

La cadena del valor del recurso consta de una o más tabulaciones separadas por comas. Cada tabulación identifica el valor de la tabulación, el tipo de unidad y si el desplazamiento es relativo o absoluto. Por ejemplo:

tabulación := flotante [ ESPACIO unidades ]
flotante := [ signo ] [[ DÍGITO]*. ]DÍGITO+
signo := +

donde la presencia o ausencia de signo indica, respectivamente, un desplazamiento relativo o un desplazamiento absoluto. Tenga en cuenta que no se permiten valores de tabulación negativos. unidades indica el tipo de unidad a utilizar, tal como se describe en la página de referencia de XmConvertUnits.

Por ejemplo, lo siguiente especifica una lista de tabulaciones que consta de una tabulación absoluta de una pulgada seguida de una tabulación relativa de una pulgada:

*tabList: 1in, +1in

Para recursos de tipo, dimensión o posición, puede especificar unidades como se describe en el recurso XmNunitType de la página de referencia de XmGadget, XmManager o XmPrimitive.

RELACIONADO

Consulte la Motif Programmer's Guide para obtener más información sobre tabulaciones y listas de tabulaciones. XmTabListCopy(3), XmTabListFree(3), XmTabListGetTab(3), XmTabListInsertTabs(3), XmTabListRemoveTabs(3), XmTabListReplacePositions(3) y XmTabListTabCount(3).
