NOMBRE

XML::RegExp - Expresiones regulares para tokens XML

SINOPSIS

use XML::RegExp;
if ($my_name =~ /^$XML::RegExp::Name$/)
{
  # $my_name es un 'Name' XML válido
}

DESCRIPCIÓN

Este paquete contiene expresiones regulares para los siguientes tokens XML: BaseChar, Ideographic, Letter, Digit, Extender, CombiningChar, NameChar, EntityRef, CharRef, Reference, Name, NmToken, y AttValue.

Las definiciones de estos tokens se tomaron de la especificación XML (Lenguaje de Marcado Extensible 1.0) en http://www.w3.org/TR/REC-xml.

También contiene las expresiones regulares para los siguientes tokens de la especificación de Nombres XML en http://www.w3.org/TR/REC-xml-names: NCNameChar, NCName, QName, Prefix y LocalPart.
