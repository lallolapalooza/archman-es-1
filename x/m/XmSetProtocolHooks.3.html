XmSetProtocolHooks(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmSetProtocolHooks(llamada de biblioteca) XmSetProtocolHooks(llamada de biblioteca)

NOMBRE

XmSetProtocolHooks — una función de VendorShell que permite que las pre-acciones y post-acciones se ejecuten cuando se recibe un mensaje de protocolo de MWM

SINOPSIS

#include <Xm/Xm.h>
#include <Xm/Protocols.h>
void XmSetProtocolHooks(
Widget shell,
Atom property,
Atom protocol,
XtCallbackProc prehook,
XtPointer pre_closure,
XtCallbackProc posthook,
XtPointer post_closure);

DESCRIPCIÓN

XmSetProtocolHooks es utilizada por los shells que desean que se ejecuten pre-acciones y post-acciones cuando se recibe un mensaje de protocolo de MWM. Dado que no hay un orden garantizado en la ejecución de manejadores de eventos o listas de callbacks, esto permite al shell controlar el flujo mientras deja las estructuras del gestor de protocolos opacas.

XmWMProtocolHooks es una interfaz de conveniencia. Llama a XmSetProtocolHooks con el valor de la propiedad establecido en el átomo devuelto por la internación de WM_PROTOCOLS.

shell
Especifica el widget con el que se asocia la propiedad de protocolo
property
Especifica la propiedad de protocolo
protocol
Especifica el átomo de protocolo
prehook
Especifica el procedimiento a llamar antes de llamar a las entradas en la lista de callbacks del cliente
pre_closure
Especifica los datos del cliente que se pasarán al prehook cuando se invoque
posthook
Especifica el procedimiento a llamar después de llamar a las entradas en la lista de callbacks del cliente
post_closure
Especifica los datos del cliente que se pasarán al posthook cuando se invoque

Para una definición completa de VendorShell y sus recursos asociados, consulte VendorShell(3).

RELACIONADO

VendorShell(3), XmInternAtom(3), y XmSetWMProtocolHooks(3).
