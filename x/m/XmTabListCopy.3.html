NOMBRE

XmTabListCopy — Una función de conveniencia que crea una nueva lista de tabulaciones a partir de una lista existente

SINOPSIS

#include <Xm/Xm.h>
XmTabList XmTabListCopy(
XmTabList tablist,
int offset,
Cardinal count);

DESCRIPCIÓN

XmTabListCopy crea una nueva lista de tabulaciones que consiste en una copia de una porción del contenido del argumento tablist. Esta función comienza a copiar desde el valor de desplazamiento especificado de la lista de tabulaciones y copia count valores.

tablist
Especifica una lista de tabulaciones que se copiará.
offset
Especifica dónde comenzar la copia. Un valor de 0 (cero) indica comenzar desde el principio, un valor de 1 indica omitir la primera tabulación, y así sucesivamente. Un valor negativo indica comenzar a contar hacia atrás desde el final. Un valor de -1 indica comenzar a copiar desde la última tabulación.
count
Especifica el número de tabulaciones a copiar. Un valor de 0 (cero) indica copiar todos los elementos desde el punto de inicio hasta el final (principio si offset es negativo) de la lista de tabulaciones.

RETORNO

Si tablist es NULL, esta función devuelve NULL. De lo contrario, esta función devuelve un XmTabList recién asignado. Si la función asigna un XmTabList, la aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmTabListFree.

RELACIONADO

XmTabList(3) y XmTabListFree(3).
