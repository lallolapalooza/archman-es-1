XmbTextListToTextProperty(3) FUNCIONES DE XLIB XmbTextListToTextProperty(3)

NOMBRE

XmbTextListToTextProperty, XwcTextListToTextProperty, Xutf8TextListToTextProperty, XmbTextPropertyToTextList, XwcTextPropertyToTextList, Xutf8TextPropertyToTextList, XwcFreeStringList, XDefaultString - convertir listas de texto y estructuras de propiedad de texto

SINTAXIS

int XmbTextListToTextProperty(Display *display, char **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int XwcTextListToTextProperty(Display *display, wchar_t **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int Xutf8TextListToTextProperty(Display *display, char **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int XmbTextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, char ***list_return, int *count_return);

int XwcTextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, wchar_t ***list_return, int *count_return);

int Xutf8TextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, char ***list_return, int *count_return);

void XwcFreeStringList(wchar_t **list);

char *XDefaultString(void)

ARGUMENTOS

display
Especifica la conexión con el servidor X.
list
Especifica una lista de cadenas de caracteres terminadas en nulo.
count
Especifica el número de cadenas proporcionadas.
style
Especifica la forma en que se codifica la propiedad.
text_prop_return
Devuelve la estructura XTextProperty.
text_prop
Especifica la estructura XTextProperty que se va a utilizar.
list_return
Devuelve una lista de cadenas de caracteres terminadas en nulo.
count_return
Devuelve el número de cadenas.
list
Especifica la lista de cadenas que se van a liberar.

DESCRIPCIÓN

Las funciones XmbTextListToTextProperty, XwcTextListToTextProperty y Xutf8TextListToTextProperty establecen el valor XTextProperty especificado a un conjunto de elementos separados por nulos que representan la concatenación de la lista especificada de cadenas de texto terminadas en nulo. Las cadenas de texto de entrada deben proporcionarse en la codificación de la configuración regional actual (para XmbTextListToTextProperty y XwcTextListToTextProperty), o en codificación UTF-8 (para Xutf8TextListToTextProperty).

Las funciones establecen el campo de codificación de text_prop_return a un Atom para el visualizador especificado que nombra la codificación determinada por el estilo especificado y convierten la lista de texto especificada a esta codificación para su almacenamiento en el campo de valor text_prop_return. Si se especifica el estilo XStringStyle o XCompoundTextStyle, esta codificación es "STRING" o "COMPOUND_TEXT", respectivamente. Si se especifica el estilo XUTF8StringStyle, esta codificación es "UTF8_STRING". (Esta es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.) Si se especifica el estilo XTextStyle, esta codificación es la codificación de la configuración regional actual. Si se especifica el estilo XStdICCTextStyle, esta codificación es "STRING" si el texto es completamente convertible a STRING, de lo contrario es "COMPOUND_TEXT". Un byte nulo final de terminación se almacena al final del campo de valor de text_prop_return pero no se incluye en el miembro nitems.

Si no hay suficiente memoria disponible para la nueva cadena de valor, las funciones devuelven XNoMemory. Si la configuración regional actual no es compatible, las funciones devuelven XLocaleNotSupported. En ambos casos de error, las funciones no establecen text_prop_return.

Para determinar si las funciones garantizan no devolver XLocaleNotSupported, utilice XSupportsLocale.

Si el texto proporcionado no es completamente convertible a la codificación especificada, las funciones devuelven el número de caracteres no convertibles. Cada carácter no convertible se convierte a una cadena por defecto definida por la implementación y específica de la codificación. De lo contrario, las funciones devuelven Success. Tenga en cuenta que se garantiza la convertibilidad completa a todos los estilos excepto a XStringStyle.

Para liberar el almacenamiento del campo de valor, utilice XFree.

Las funciones XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven una lista de cadenas de texto que representan los elementos separados por nulos de la estructura XTextProperty especificada. Las cadenas devueltas están codificadas utilizando la codificación de la configuración regional actual (para XmbTextPropertyToTextList y XwcTextPropertyToTextList) o en UTF-8 (para Xutf8TextPropertyToTextList). Los datos en text_prop deben ser de formato 8.

Múltiples elementos de la propiedad (por ejemplo, las cadenas en una selección de texto discontinua) están separados por un byte nulo. El contenido de la propiedad no requiere estar terminado en nulo; cualquier nulo de terminación no debe incluirse en text_prop.nitems.

Si no hay suficiente memoria disponible para la lista y sus elementos, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven XNoMemory. Si la configuración regional actual no es compatible, las funciones devuelven XLocaleNotSupported. De lo contrario, si el campo de codificación de text_prop no es convertible a la codificación de la configuración regional actual, las funciones devuelven XConverterNotFound. Para las configuraciones regionales compatibles, la existencia de un convertidor de COMPOUND_TEXT, STRING, UTF8_STRING o la codificación de la configuración regional actual está garantizada si XSupportsLocale devuelve True para la configuración regional actual (pero el texto real puede contener caracteres no convertibles). La conversión de otras codificaciones depende de la implementación. En todos estos casos de error, las funciones no establecen ningún valor de retorno.

De lo contrario, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven la lista de cadenas de texto terminadas en nulo a list_return y el número de cadenas de texto a count_return.

Si el campo de valor de text_prop no es completamente convertible a la codificación de la configuración regional actual, las funciones devuelven el número de caracteres no convertibles. Cada carácter no convertible se convierte a una cadena en la configuración regional actual que es específica de la configuración regional actual. Para obtener el valor de esta cadena, utilice XDefaultString. De lo contrario, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven Success.

Para liberar el almacenamiento de la lista y su contenido devuelto por XmbTextPropertyToTextList o Xutf8TextPropertyToTextList, utilice XFreeStringList. Para liberar el almacenamiento de la lista y su contenido devuelto por XwcTextPropertyToTextList, utilice XwcFreeStringList.

La función XwcFreeStringList libera la memoria asignada por XwcTextPropertyToTextList.

La función XDefaultString devuelve la cadena predeterminada utilizada por Xlib para la conversión de texto (por ejemplo, en XmbTextPropertyToTextList). La cadena predeterminada es la cadena en la configuración regional actual que se emite cuando se encuentra un carácter no convertible durante la conversión de texto. Si la cadena devuelta por XDefaultString es una cadena vacía (""), no se emite ningún carácter en el texto convertido. XDefaultString no devuelve NULL.

La cadena devuelta por XDefaultString es independiente de la cadena predeterminada para el dibujo de texto; consulte XCreateFontSet para obtener la cadena predeterminada de un XFontSet.

El comportamiento cuando se proporciona un punto de código no válido a cualquier función de Xlib es indefinido.

La cadena devuelta está terminada en nulo. Es propiedad de Xlib y no debe ser modificada ni liberada por el cliente. Puede ser liberada después de cambiar la configuración regional actual. Hasta que se libere, Xlib no la modificará.

NAME

XmbTextListToTextProperty, Xutf8TextListToTextProperty, XwcTextListToTextProperty, XmbTextPropertyToTextList, Xutf8TextPropertyToTextList, XwcTextPropertyToTextList - convertir listas de cadenas en propiedades de texto X y viceversa

SYNTAX

#include <X11/Xutil.h>

Status XmbTextListToTextProperty(Display *display, char **list, int count,
    XICCEncodingStyle style, XTextProperty *text_prop_return);
Status Xutf8TextListToTextProperty(Display *display, char **list, int count,
    XICCEncodingStyle style, XTextProperty *text_prop_return);
Status XwcTextListToTextProperty(Display *display, wchar_t **list, int count,
    XICCEncodingStyle style, XTextProperty *text_prop_return);

Status XmbTextPropertyToTextList(Display *display, XTextProperty *text_prop,
    char ***list_return, int *count_return);
Status Xutf8TextPropertyToTextList(Display *display, XTextProperty *text_prop,
    char ***list_return, int *count_return);
Status XwcTextPropertyToTextList(Display *display, XTextProperty *text_prop,
    wchar_t ***list_return, int *count_return);

ARGUMENTS

--
especifica los argumentos de las funciones.

DESCRIPTION

Las funciones XmbTextListToTextProperty, XwcTextListToTextProperty y Xutf8TextListToTextProperty convierten una lista de cadenas en una única propiedad de texto X. El argumento list apunta a una matriz de cadenas, count es el número de cadenas en la matriz y style especifica el estilo de codificación deseado para la propiedad de texto.

Las funciones XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList realizan la operación inversa, convirtiendo una propiedad de texto X en una lista de cadenas.

Las funciones Xutf8TextListToTextProperty y Xutf8TextPropertyToTextList son extensiones introducidas por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.

STRUCTURES

La estructura XTextProperty contiene:

typedef struct {
        unsigned char *value;   /* property data */
        Atom encoding;  /* type of property */
        int format;     /* 8, 16, or 32 */
        unsigned long nitems;   /* number of items in value */
} XTextProperty;

La estructura XICCEncodingStyle contiene:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* text in owner's encoding (current locale) */
        XStdICCTextStyle,       /* STRING, else COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;
