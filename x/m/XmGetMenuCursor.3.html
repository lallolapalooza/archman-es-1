NOMBRE

XmGetMenuCursor — Una función que devuelve el ID del cursor del menú actual

SINOPSIS

#include <Xm/Xm.h>
Cursor XmGetMenuCursor(
Display * display);

DESCRIPCIÓN

XmGetMenuCursor consulta el cursor del menú que está siendo utilizado actualmente por este cliente en la pantalla especificada y devuelve el ID del cursor. Esta función devuelve el cursor del menú para la pantalla predeterminada de la pantalla.

NOTA: XmGetMenuCursor es obsoleto y existe por compatibilidad con versiones anteriores. En lugar de usar esta función, llame a XtGetValues para el recurso XmScreen XmNmenuCursor.

display
Especifica la pantalla cuyo cursor de menú se va a consultar

RETORNO

Devuelve el ID del cursor para el cursor de menú actual o el valor None si aún no se ha definido un cursor. Un cursor no se definirá si la aplicación realiza esta llamada antes de que el cliente haya creado algún menú en la pantalla especificada.

RELACIONADOS

XmScreen(3).
