XmFontListEntryLoad(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmFontListEntryLoad(llamada de biblioteca) XmFontListEntryLoad(llamada de biblioteca)

NOMBRE

XmFontListEntryLoad — Una función de lista de fuentes que carga una fuente o crea un conjunto de fuentes y crea una entrada de lista de fuentes acompañante.

SINOPSIS

#include <Xm/Xm.h>
XmFontListEntry XmFontListEntryLoad(
Display *display,
char *font_name,
XmFontType type,
char *tag);

DESCRIPCIÓN

XmFontListEntryLoad carga una fuente o crea un conjunto de fuentes basándose en el valor del argumento type. Crea y devuelve una entrada de lista de fuentes que contiene la fuente o el conjunto de fuentes y la etiqueta especificada.

Si el valor de type es XmFONT_IS_FONT, la función utiliza la rutina XtCvtStringToFontStruct para convertir el valor de font_name a una estructura de fuente. Si el valor de type es XmFONT_IS_FONTSET, la función utiliza el conversor XtCvtStringToFontSet para crear un conjunto de fuentes en la configuración regional actual. XmFontListEntryLoad crea una entrada de lista de fuentes que contiene la fuente o el conjunto de fuentes derivado del conversor. Para obtener más información sobre XtCvtStringToFontStruct y XtCvtStringToFontSet, consulte X Toolkit Intrinsics—Interfaz en Lenguaje C.

display
Especifica la pantalla donde se utilizará la lista de fuentes.
font_name
Especifica una cadena de Descripción de Fuente Lógica de X (XLFD), que se interpreta como un nombre de fuente o como una lista de nombres de fuentes base. Una lista de nombres de fuentes base es una cadena separada por comas y terminada en NULL.
type
Especifica si el argumento font_name se refiere a un nombre de fuente o a una lista de nombres de fuentes base. Los valores válidos son XmFONT_IS_FONT y XmFONT_IS_FONTSET.
tag
Especifica la etiqueta de la entrada de lista de fuentes que se va a crear. La etiqueta puede especificarse como XmFONTLIST_DEFAULT_TAG, que se utiliza para identificar el elemento predeterminado de la lista de fuentes cuando se especifica como parte de un recurso.

RETORNO

Si la fuente especificada no se encuentra, o si el conjunto de fuentes especificado no se puede crear, se abrirá una fuente definida por la implementación o se creará un conjunto de fuentes, y se generará un mensaje de advertencia. Si no se encuentra ninguna fuente adecuada o no se puede crear un conjunto de fuentes, se generará otro mensaje y la función devolverá NULL; de lo contrario, la función devolverá una entrada de lista de fuentes. Si la función devuelve una entrada de lista de fuentes, la función asigna espacio para almacenar la entrada de lista de fuentes. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmFontListEntryFree.

RELACIONADO

XmFontList(3), XmFontListAppendEntry(3), XmFontListEntryCreate(3), XmFontListEntryFree(3), XmFontListEntryGetFont(3), XmFontListEntryGetTag(3), y XmFontListRemoveEntry(3).
