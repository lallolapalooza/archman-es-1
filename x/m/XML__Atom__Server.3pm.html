NOMBRE

XML::Atom::Server - Un servidor para la API de Atom

SINOPSIS

package My::Server;
use base qw( XML::Atom::Server );
sub handle_request {
    my $server = shift;
    $server->authenticate or return;
    my $method = $server->request_method;
    if ($method eq 'POST') {
        return $server->new_post;
    }
    ...
}
my %Passwords;
sub password_for_user {
    my $server = shift;
    my($username) = @_;
    $Passwords{$username};
}
sub new_post {
    my $server = shift;
    my $entry = $server->atom_body or return;
    ## $entry es un objeto XML::Atom::Entry.
    ## ... Guarda la nueva entrada ...
}
package main;
my $server = My::Server->new;
$server->run;

DESCRIPCIÓN

XML::Atom::Server proporciona una clase base para servidores de la API de Atom. Maneja todo el procesamiento central del servidor, tanto los formatos SOAP como REST del protocolo, y la autenticación WSSE. También puede ejecutarse como un manejador de mod_perl o como parte de un programa CGI.

No proporciona funciones específicas para ninguna implementación particular, como la publicación de una entrada, la recuperación de una lista de entradas, la eliminación de una entrada, etc. Las implementaciones deben heredar de XML::Atom::Server, sobrescribiendo el método handle_request, y manejar todas las funciones como estas ellas mismas.

SUBCLASES

Manejo de Solicitudes

Las subclases de XML::Atom::Server deben sobrescribir el método handle_request para realizar todo el procesamiento de solicitudes. La implementación debe establecer todas las cabeceras de respuesta, incluido el código de respuesta y cualquier cabecera HTTP relevante, y debe devolver un escalar que represente el cuerpo de la respuesta que se enviará de vuelta al cliente.

Por ejemplo:

sub handle_request {
    my $server = shift;
    my $method = $server->request_method;
    if ($method eq 'POST') {
        return $server->new_post;
    }
    ## ... manejar GET, PUT, etc
}

sub new_post {
    my $server = shift;
    my $entry = $server->atom_body or return;
    my $id = save_this_entry($entry);  ## Específico de la implementación
    $server->response_header(Location => $server->uri . '/entry_id=' . $id);
    $server->response_code(201);
    $server->response_content_type('application/x.atom+xml');
    return serialize_entry($entry);    ## Específico de la implementación
}

Autenticación

Los servidores que requieren autenticación para publicar o recuperar entradas o feeds deben sobrescribir el método password_for_user. Dado un nombre de usuario (de la cabecera WSSE), password_for_user debe devolver la contraseña de ese usuario en texto claro. Esto se combinará con el nonce y la hora de creación para generar el resumen, que se comparará con el resumen enviado en la cabecera WSSE. Si el nombre de usuario proporcionado no existe en tu base de datos de usuarios o similar, simplemente devuelve "undef".

Por ejemplo:

my %Passwords = ( foo => 'bar' );   ## La contraseña para "foo" es "bar".
sub password_for_user {
    my $server = shift;
    my($username) = @_;
    $Passwords{$username};
}

MÉTODOS

XML::Atom::Server proporciona una variedad de métodos para ser utilizados por las subclases para recuperar cabeceras, contenido y otra información de la solicitud, y para establecer lo mismo en la respuesta.

Parámetros de Solicitud del Cliente

  • $server->uri

    Devuelve la URI de la implementación del servidor Atom.

  • $server->request_method

    Devuelve el nombre del método de solicitud enviado al servidor desde el cliente (por ejemplo, "GET", "POST", etc.). Ten en cuenta que si el cliente envió la solicitud en un sobre SOAP, el método se obtiene de la cabecera HTTP SOAPAction.

  • $server->request_header($header)

    Recupera el valor de la cabecera de solicitud HTTP $header.

  • $server->request_content

    Devuelve un escalar que contiene el contenido de una solicitud POST o PUT del cliente.

  • $server->request_param($param)

    XML::Atom::Server analiza automáticamente PATH_INFO enviado en la solicitud y lo divide en pares clave-valor. Esto se puede utilizar para pasar parámetros. Por ejemplo, en la URI

    http://localhost/atom-server/entry_id=1

    el parámetro entry_id se establecería en 1.

    request_param devuelve el valor del parámetro $param.

Configuración de la Respuesta

  • $server->response_header($header, $value)

    Establece el valor de la cabecera de respuesta HTTP $header a $value.

  • $server->response_code([ $code ])

    Devuelve el código de respuesta actual que se enviará de vuelta al cliente, y si se proporciona $code, establece el código de respuesta.

  • $server->response_content_type([ $type ])

    Devuelve la cabecera Content-Type actual que se enviará de vuelta al cliente, y si se proporciona $type, establece el valor para esa cabecera.

Procesamiento de la Solicitud

  • $server->authenticate

    Intenta autenticar la solicitud basándose en la información de autenticación presente en la solicitud (actualmente solo WSSE). Esto llamará al método password_for_user en la subclase para obtener la contraseña en texto claro del nombre de usuario proporcionado en la solicitud.

  • $server->atom_body

    Devuelve un objeto XML::Atom::Entry que contiene la entrada enviada en la solicitud.

USO

Una vez que hayas definido tu subclase de servidor, puedes configurarla como un programa CGI o como un manejador de mod_perl.

Un programa CGI simple se vería algo así:

#!/usr/bin/perl -w
use strict;
use My::Server;
my $server = My::Server->new;
$server->run;

Una configuración simple de manejador de mod_perl se vería algo así:

PerlModule My::Server
<Location /atom-server>
    SetHandler perl-script
    PerlHandler My::Server
</Location>

MANEJO DE ERRORES

Si deseas devolver un error desde handle_request, puedes utilizar el método incorporado error:

sub handle_request {
    my $server = shift;
    ...
    return $server->error(500, "Algo salió mal");
}

Esto se devolverá al cliente con un código de respuesta de 500 y una cadena de error de "Algo salió mal". Los errores se serializan automáticamente en fallos SOAP si la solicitud entrante está encerrada en un sobre SOAP.
