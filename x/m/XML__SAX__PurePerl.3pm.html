NOMBRE

XML::SAX::PurePerl - Analizador XML puro en Perl con interfaz SAX2

SINOPSIS

use XML::Handler::Foo;
use XML::SAX::PurePerl;
my $handler = XML::Handler::Foo->new();
my $parser = XML::SAX::PurePerl->new(Handler => $handler);
$parser->parse_uri("myfile.xml");

DESCRIPCIÓN

Este módulo implementa un analizador XML en Perl puro. Está escrito en torno al soporte de Unicode de perl 5.8 y el soporte para múltiples codificaciones de documentos (utilizando la capa PerlIO), sin embargo, ha sido portado para funcionar con documentos ASCII/UTF8 en versiones de perl anteriores.

La API SAX2 se describe en detalle en http://sourceforge.net/projects/perl-xml/, en el archivo CVS, bajo libxml-perl/docs. Esperemos que esos documentos se encuentren pronto en una ubicación mejor.

Consulte la documentación de SAX2 para saber cómo utilizar este módulo; es simplemente una interfaz para SAX2 y no implementa nada que no esté en esa especificación (o al menos intenta no hacerlo; por favor, envíeme un correo electrónico si encuentra errores en esta implementación).

ERRORES

XML::SAX::PurePerl es **lento**. Muy lento. De hecho, sugiero que use algo más. Sin embargo, es excelente como analizador de respaldo para XML::SAX, donde el usuario podría no poder instalar un analizador basado en XS o una biblioteca C.

Actualmente, probablemente hay muchos. En este momento, el área más débil es el análisis de las declaraciones DOCTYPE, aunque el código está en su lugar para comenzar a hacerlo. El análisis de referencias a entidades paramétricas también me causa mucha confusión, ya que no es exactamente lo que yo llamaría trivial, ni está bien documentado en la gramática XML. Es probable que los documentos XML con subconjuntos internos fallen.

Sin embargo, estoy intentando trabajar hacia la conformidad completa utilizando el conjunto de pruebas Oasis.
