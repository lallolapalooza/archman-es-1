XMapWindow(3) FUNCIONES XLIB XMapWindow(3)

NOMBRE

XMapWindow, XMapRaised, XMapSubwindows - mapear ventanas

SINTAXIS

int XMapWindow(Display *display, Window w);

int XMapRaised(Display *display, Window w);

int XMapSubwindows(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.

DESCRIPCIÓN

La función XMapWindow mapea la ventana y todas sus subventanas que han tenido solicitudes de mapeo. Mapear una ventana que tiene un ancestro sin mapear no muestra la ventana pero la marca como elegible para ser mostrada cuando el ancestro se mapea. Tal ventana se llama no visible. Cuando todos sus ancestros se mapean, la ventana se vuelve visible y aparecerá en la pantalla si no está oscurecida por otra ventana. Esta función no tiene efecto si la ventana ya está mapeada.

Si la opción override-redirect de la ventana es False y si algún otro cliente ha seleccionado SubstructureRedirectMask en la ventana padre, entonces el servidor X genera un evento MapRequest, y la función XMapWindow no mapea la ventana. De lo contrario, la ventana se mapea, y el servidor X genera un evento MapNotify.

Si la ventana se vuelve visible y no se recuerdan contenidos anteriores para ella, el servidor X rellena la ventana con su fondo. Si el fondo de la ventana no está definido, el contenido existente de la pantalla no se altera, y el servidor X genera cero o más eventos Expose. Si se mantuvo el backing-store mientras la ventana no estaba mapeada, no se generan eventos Expose. Si ahora se mantendrá el backing-store, siempre se generará una exposición de ventana completa. De lo contrario, solo se pueden reportar regiones visibles. Relleno y exposición similares ocurren para cualquier inferior recién visible.

Si la ventana es una ventana de InputOutput, XMapWindow genera eventos Expose en cada ventana de InputOutput que causa que se muestre. Si el cliente mapea y pinta la ventana y si el cliente comienza a procesar eventos, la ventana se pintará dos veces. Para evitar esto, primero solicita eventos Expose y luego mapea la ventana, para que el cliente procese los eventos de entrada como de costumbre. La lista de eventos incluirá Expose para cada ventana que ha aparecido en la pantalla. La respuesta normal del cliente a un evento Expose debería ser repintar la ventana. Este método generalmente lleva a programas más simples y a una interacción adecuada con los gestores de ventanas.

XMapWindow puede generar un error BadWindow.

La función XMapRaised es esencialmente similar a XMapWindow en que mapea la ventana y todas sus subventanas que han tenido solicitudes de mapeo. Sin embargo, también eleva la ventana especificada a la parte superior de la pila.

XMapRaised puede generar un error BadWindow.

La función XMapSubwindows mapea todas las subventanas de una ventana especificada en orden de apilamiento de arriba hacia abajo. El servidor X genera eventos Expose en cada ventana recién mostrada. Esto puede ser mucho más eficiente que mapear muchas ventanas una por una, ya que el servidor necesita realizar gran parte del trabajo solo una vez, para todas las ventanas, en lugar de para cada ventana.

XMapSubwindows puede generar un error BadWindow.

DIAGNÓSTICOS

BadWindow
Un valor para un argumento de Window no nombra una Window definida.
