NOMBRE

XmImSetXIC — Una función del gestor de entrada que registra un XIC existente con un widget

SINOPSIS

#include <Xm/XmIm.h>
XIC XmImSetXIC(
Widget widget,
XIC xic);

DESCRIPCIÓN

XmImSetXIC registra el Contexto de Entrada X (XIC) especificado con widget. Cualquier XIC existente registrado para widget se desregistra. Se devuelve el nuevo XIC registrado para widget.

Si xic no fue creado por XmImGetXIC o XmImRegister, no estará sujeto a actividades de cierre cuando no tenga widgets registrados con él.

widget
Especifica el ID de un widget para el cual se va a registrar un nuevo Contexto de Entrada.
xic
Especifica el Contexto de Entrada a registrar con el widget. Si xic es NULL, la función devuelve el XIC actual utilizado por widget.

RETORNO

Devuelve el nuevo XIC registrado para widget. La aplicación es responsable de liberar el XIC devuelto. Para liberar el XIC, llame a XmImFreeXIC.

RELACIONADO

XmImGetXIC(3) y XmImFreeXIC(3).
