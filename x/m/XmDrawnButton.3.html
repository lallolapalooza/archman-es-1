NOMBRE

XmDrawnButton — La clase de widget DrawnButton

SINOPSIS

#include <Xm/DrawnB.h>

DESCRIPCIÓN

El widget DrawnButton consiste en una ventana de widget vacía rodeada por un borde de sombra. Proporciona al desarrollador de aplicaciones un área gráfica que puede tener la semántica de entrada de un PushButton.

Los tipos de callback se definen para la exposición del widget y el redimensionamiento del widget para permitir a la aplicación redibujar o reposicionar sus gráficos. Si el widget DrawnButton tiene un grosor de resalte y sombra, la aplicación no debe dibujar en esa área. Para evitar dibujar en el área de resalte y sombra, cree el contexto gráfico con un rectángulo de recorte para dibujar en el widget. El rectángulo de recorte debe tener en cuenta el tamaño del grosor de resalte y sombra del widget. DrawnButton utiliza los rasgos XmQTmenuSystem y XmQTspecifyRenderTable, y mantiene el rasgo XmQTactivatable.

Clases

DrawnButton hereda el comportamiento, los recursos y los rasgos de las clases Core, Primitive y XmLabel.

El puntero de clase es xmDrawnButtonWidgetClass.

El nombre de la clase es XmDrawnButton.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya cualquier guion bajo entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNactivateCallback
Especifica la lista de callbacks que se llama cuando el widget se selecciona. La razón enviada por el callback es XmCR_ACTIVATE. Este callback utiliza el rasgo XmQTactivatable.
XmNarmCallback
Especifica la lista de callbacks que se llama cuando el widget se arma. La razón enviada por el callback es XmCR_ARM.
XmNdisarmCallback
Especifica la lista de callbacks que se llama cuando el widget se desarma. La razón enviada por el callback es XmCR_DISARM.
XmNexposeCallback
Especifica la lista de callbacks que se llama cuando el widget recibe un evento de exposición. La razón enviada por el callback es XmCR_EXPOSE.
XmNmultiClick
Si un clic de botón es seguido por otro clic de botón dentro del período de tiempo especificado por el tiempo de multiclic de la pantalla, y este recurso se establece en XmMULTICLICK_DISCARD, el segundo clic no se procesa. Si este recurso se establece en XmMULTICLICK_KEEP, el evento se procesa y click_count se incrementa en la estructura de callback. Cuando el botón no está en un menú, el valor por defecto es XmMULTICLICK_KEEP.
XmNpushButtonEnabled
Habilita o deshabilita el dibujo de sombra tridimensional como en PushButton.
XmNresizeCallback
Especifica la lista de callbacks que se llama cuando el widget recibe un evento de redimensionamiento. La razón enviada por el callback es XmCR_RESIZE. El evento devuelto para este callback es NULL.
XmNshadowType
Especifica el tipo de sombra utilizado en el widget DrawnButton. Las sombreados disponibles son XmSHADOW_IN, XmSHADOW_OUT, XmSHADOW_ETCHED_IN y XmSHADOW_ETCHED_OUT.

CALLBACKS

El DrawnButton widget puede agregar callbacks en las siguientes categorías: activateCallback, armCallback, disarmCallback, exposeCallback y resizeCallback.

Consulte XmLabel(3) para obtener información sobre los callbacks de armCallback y disarmCallback.

num_args
El número de argumentos en la lista de argumentos.

NAME

XmDrawnButton — a managed widget that supports drawing and user interaction

SYNTAX

#include <Xm/DrawnB.h>

Where:

XmDrawnButtonWidgetClass is returned by xmDrawnButtonWidgetClass().

DESCRIPTION

The XmDrawnButton widget is a managed widget that supports drawing and user interaction. The widget provides a drawing area where application-defined drawing can be performed. It also supports the definition of callback routines that are invoked when the widget is activated.

The XmDrawnButton widget is a subclass of XmManager. It inherits the resources defined by that subclass.

The XmDrawnButton widget supports the following resources. For a complete definition of Primitive and Manager resources, refer to XmPrimitive(3) and XmManager(3).

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        Window window;
        int click_count;
} XmDrawnButtonCallbackStruct;
reason
Indicates why the callback was invoked.
event
Points to the XEvent that triggered the callback. This is NULL for XmNresizeCallback.
window
Is set to the window ID in which the event occurred.
click_count
Contains the number of clicks in the last multiclick sequence if the XmNmultiClick resource is set to XmMULTICLICK_KEEP, otherwise it contains 1. The activate callback is invoked for each click if XmNmultiClick is set to XmMULTICLICK_KEEP.

NAME

XmDrawnButton — A drawn button widget that allows application-defined drawing

SYNOPSIS

#include <Xm/DrawnB.h>


   WidgetClass     xmDrawnButtonWidgetClass;

   Widget          xmCreateDrawnButton(
                        Widget          parent,
                        char            *name,
                        ArgList         arglist,
                        Cardinal        argCount );

   Widget          xmCreateManagedDrawnButton(
                        Widget          parent,
                        char            *name,
                        ArgList         arglist,
                        Cardinal        argCount );

   Widget          xmVaCreateDrawnButton(
                        Widget          parent,
                        char            *name,
                        ... );

   Widget          xmVaCreateManagedDrawnButton(
                        Widget          parent,
                        char            *name,

DESCRIPTION

The XmDrawnButton widget is a button that can contain application-defined graphics. The widget provides callbacks for drawing and for user interaction. The XmDrawnButton widget inherits from XmPrimitive and Core.

The widget can be used to create command buttons, toggle buttons, option buttons, or check buttons. The appearance and behavior of the XmDrawnButton depend on its resources.

XmDrawnButton Resources

The following resources are specific to the XmDrawnButton widget.

XmNarmCallback:
Specifies the list of callbacks that are called when the button is armed. The callback reason is XmCR_ARM.
XmNbottomShadowColor:
The color of the bottom shadow. Inherited from XmPrimitive.
XmNbottomShadowPixmap:
The pixmap of the bottom shadow. Inherited from XmPrimitive.
XmNconvertCallback:
Specifies the list of callbacks that are called to convert the widget's content. This resource is used when the widget is embedded in a XmBulletinBoard or other container widgets that use the data conversion mechanism.
XmNdeactivateCallback:
Specifies the list of callbacks that are called when the button is deactivated. The callback reason is XmCR_DEACTIVATE.
XmNdestroyCallback:
Specifies the list of callbacks that are called when the widget is destroyed. The callback reason is XmCR_DESTROY.
XmNdisarmCallback:
Specifies the list of callbacks that are called when the button is disarmed. The callback reason is XmCR_DISARM.
XmNdrawCallback:
Specifies the list of callbacks that are called when the widget needs to be redrawn. The callback reason is XmCR_DRAW.
XmNfillOnArm:
Specifies whether the background of the widget should be filled when it is armed. The default value is True.
XmNfontList:
Specifies the font list to be used for rendering text within the widget. Inherited from XmPrimitive.
XmNforeground:
The foreground color of the widget. Inherited from XmPrimitive.
XmNhelpCallback:
Specifies the list of callbacks that are called when the help key is pressed. The callback reason is XmCR_HELP.
XmNhighlightColor:
The color used for highlighting the widget. Inherited from XmPrimitive.
XmNhighlightPixmap:
The pixmap used for highlighting the widget. Inherited from XmPrimitive.
XmNlabelInsensitivePixmap:
The pixmap to be used when the widget is insensitive. Inherited from XmLabel.
XmNlabelPixmap:
The pixmap to be used as the label of the widget. Inherited from XmLabel.
XmNmargin:
The margin between the widget's border and its content. Inherited from XmLabel.
XmNmarginBottom:
The bottom margin of the widget. Inherited from XmLabel.
XmNmarginLeft:
The left margin of the widget. Inherited from XmLabel.
XmNmarginRight:
The right margin of the widget. Inherited from XmLabel.
XmNmarginTop:
The top margin of the widget. Inherited from XmLabel.
XmNmultiClick:
Specifies the behavior of the widget when multiple clicks occur within the widget's traversal time. Valid values are XmMULTICLICK_DISCARD and XmMULTICLICK_KEEP.
XmNorientation:
Specifies the orientation of the widget (horizontal or vertical). Inherited from XmLabel.
XmNpattern:
Specifies a pixmap to be used for filling the background of the widget. Inherited from XmLabel.
XmNpushButtonEnabled:
Specifies whether the widget should behave like a push button. If this resource is True, the widget will have a shadow that changes appearance when armed or activated. The default value is True.
XmNrecomputeSize:

XmNseparatorOn:

XmNstringDirection:

XmNtopShadowColor:

XmNtopShadowPixmap:

XmNwidth:

Action Bindings

The XmDrawnButton widget supports the following actions:

ArmAndActivate():
Arms the widget, then activates it. If XmNpushButtonEnabled is True, the shadow is drawn in the selected state. Otherwise, the shadow is drawn according to XmNshadowType. The XmNarmCallback and XmNactivateCallback callbacks are invoked.
Help():
Invokes the XmNhelpCallback callbacks. If no help callbacks are defined for the widget, it searches for the nearest ancestor with help callbacks.

Key Bindings

The XmDrawnButton widget supports the following key bindings:

Ctrl+~ Return:
Calls the PrimitiveParentActivate action.
Ctrl+~ space:
Calls the ArmAndActivate action.

Action Routines

The XmDrawnButton action routines are:

Activate():
If XmNpushButtonEnabled is True, redraws the shadow in the unselected state; otherwise, redraws the shadow according to XmNshadowType. If the pointer is within the DrawnButton, calls the XmNactivateCallback callbacks.
Arm():
If XmNpushButtonEnabled is True, redraws the shadow in the selected state; otherwise, redraws the shadow according to XmNshadowType. Calls the callbacks for XmNarmCallback.
ArmAndActivate():
If XmNpushButtonEnabled is True, redraws the shadow in the selected state; otherwise, redraws the shadow according to XmNshadowType. Calls the callbacks for XmNarmCallback.
If XmNpushButtonEnabled is True, the shadow is redrawn in the unselected state; otherwise, the shadow is redrawn according to XmNshadowType. The callbacks for XmNactivateCallback and XmNdisarmCallback are called. These actions happen either immediately or at a later time.
ButtonTakeFocus():
Causes the PushButton to take keyboard focus when Ctrl<Btn1Down> is pressed, without activating the widget.
Disarm():
Marks the DrawnButton as unselected and calls the callbacks for XmNdisarmCallback.
Help():
Calls the callbacks for XmNhelpCallback if any exist. If there are no help callbacks for this widget, this action calls the help callbacks for the nearest ancestor that has them.
MultiActivate():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP, this action increments click_count in the callback structure. If XmNpushButtonEnabled is True, this action redraws the shadow in the unselected state; otherwise, it redraws the shadow according to XmNshadowType. If the pointer is within the DrawnButton, this action calls the XmNactivateCallback callbacks and calls the callbacks for XmNdisarmCallback.
MultiArm():
If XmNmultiClick is XmMULTICLICK_DISCARD, this action does nothing.
If XmNmultiClick is XmMULTICLICK_KEEP and if XmNpushButtonEnabled is True, this action redraws the shadow in the selected state; otherwise, it redraws the shadow according to XmNshadowType and calls the callbacks for XmNarmCallback.

Additional Behavior

This widget has the following additional behavior:

<EnterWindow>:
Draws the shadow in its selected state if XmNpushButtonEnabled is True and if the cursor leaves and re-enters the window while BSelect is pressed.
<LeaveWindow>:
Draws the shadow in its unselected state if XmNpushButtonEnabled is True and if the cursor leaves the window while BSelect is pressed.

Virtual Bindings

The bindings for virtual keys are vendor specific. For information about bindings for virtual buttons and keys, see VirtualBindings(3).
