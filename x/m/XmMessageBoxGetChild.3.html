NOMBRE

XmMessageBoxGetChild — Una función de MessageBox que se usa para acceder a un componente

SINOPSIS

#include <Xm/MessageB.h>
Widget XmMessageBoxGetChild(
Widget widget,
unsigned char child);

DESCRIPCIÓN

XmMessageBoxGetChild se usa para acceder a un componente dentro de un MessageBox. Los parámetros dados a la función son el widget MessageBox y un valor que indica qué componente acceder.

NOTA: Esta rutina está obsoleta y existe por compatibilidad con versiones anteriores. En lugar de llamar a XmMessageBoxGetChild, debería llamar a XtNameToWidget como se describe en la página de referencia de XmMessageBox(3).

widget
Especifica el ID del widget MessageBox.
child
Especifica un componente dentro del MessageBox. Los siguientes son valores legales para este parámetro:
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_DEFAULT_BUTTON
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_MESSAGE_LABEL
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_SEPARATOR
•
XmDIALOG_SYMBOL_LABEL

Para una definición completa de MessageBox y sus recursos asociados, consulte XmMessageBox(3).

RETORNO

Devuelve el ID del widget del componente MessageBox especificado. Una aplicación no debe asumir que el widget devuelto será de ninguna clase en particular.

RELACIONADO

XmMessageBox(3).
