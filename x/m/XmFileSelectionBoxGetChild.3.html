NOMBRE

XmFileSelectionBoxGetChild — Función FileSelectionBox utilizada para acceder a un componente

SINOPSIS

#include <Xm/FileSB.h>
Widget XmFileSelectionBoxGetChild(
Widget widget,
unsigned char child);

DESCRIPCIÓN

XmFileSelectionBoxGetChild se utiliza para acceder a un componente dentro de un FileSelectionBox. Los parámetros dados a la función son el widget FileSelectionBox y un valor que indica qué componente acceder.

NOTA: Esta rutina es obsoleta y existe por compatibilidad con versiones anteriores. En lugar de llamar a XmFileSelectionBoxGetChild, deberías llamar a XtNameToWidget como se describe en la página de referencia de XmFileSelectionBox(3).

widget
Especifica el ID del widget FileSelectionBox.
child
Especifica un componente dentro del FileSelectionBox. Los siguientes son valores legales para este parámetro:
•
XmDIALOG_APPLY_BUTTON
•
XmDIALOG_CANCEL_BUTTON
•
XmDIALOG_DEFAULT_BUTTON
•
XmDIALOG_DIR_LIST
•
XmDIALOG_DIR_LIST_LABEL
•
XmDIALOG_FILTER_LABEL
•
XmDIALOG_FILTER_TEXT
•
XmDIALOG_HELP_BUTTON
•
XmDIALOG_LIST
•
XmDIALOG_LIST_LABEL
•
XmDIALOG_OK_BUTTON
•
XmDIALOG_SELECTION_LABEL
•
XmDIALOG_SEPARATOR
•
XmDIALOG_TEXT
•
XmDIALOG_WORK_AREA

Para una definición completa de FileSelectionBox y sus recursos asociados, consulta XmFileSelectionBox(3).

RETORNO

Devuelve el ID del widget del componente FileSelectionBox especificado. Una aplicación no debe asumir que el widget devuelto será de ninguna clase en particular.

RELACIONADO

XmFileSelectionBox(3).
