NOMBRE

XML::XPath::PerlSAX - Un generador de eventos PerlSAX para mi extraña estructura de nodos

SINOPSIS

use XML::XPath;
use XML::XPath::PerlSAX;
use XML::DOM::PerlSAX;
my $xp = XML::XPath->new(filename => 'test.xhtml');
my $paras = $xp->find('/html/body/p');
my $handler = XML::DOM::PerlSAX->new();
my $generator = XML::XPath::PerlSAX->new( Handler => $handler );
foreach my $node ($paras->get_nodelist) {
        my $domtree = $generator->parse($node);
        # hacer algo con $domtree
}

DESCRIPCIÓN

Este módulo genera eventos PerlSAX para pasarlos a un manejador PerlSAX como XML::DOM::PerlSAX. Opera específicamente en mi extraña estructura de árbol.

Desafortunadamente, SAX no parece manejar bien los namespaces, por lo que se pierden por completo. Creo que SAX2 sí maneja namespaces.

Otro

El manejador XML::DOM::PerlSAX que probé estaba completamente roto (ni siquiera compilaba antes de que lo parcheara un poco), así que no sé cuán correcto es esto ni hasta dónde funcionará.
