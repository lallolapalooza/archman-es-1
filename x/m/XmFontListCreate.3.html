XmFontListCreate(llamada a biblioteca) XmFontListCreate(llamada a biblioteca)

NOMBRE

XmFontListCreate — Una función de lista de fuentes que crea una lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
XmFontList XmFontListCreate(
XFontStruct * font,
XmStringCharSet charset);

DESCRIPCIÓN

XmFontListCreate crea una nueva lista de fuentes con un único elemento especificado por la fuente y el conjunto de caracteres proporcionados. También asigna espacio para la lista de fuentes.

NOTA: Esta función es obsoleta y existe para la compatibilidad con versiones anteriores. Está reemplazada por XmFontListAppendEntry.

font
Especifica un puntero a una estructura de fuente para la cual se genera la nueva lista de fuentes. Esta es la estructura devuelta por la función de XLib XLoadQueryFont.
charset
Especifica el identificador del conjunto de caracteres para la fuente. Puede ser XmSTRING_DEFAULT_CHARSET, pero este valor no cumple con AES y puede ser eliminado en futuras versiones de Motif. Si el valor es XmSTRING_DEFAULT_CHARSET, la rutina deriva el conjunto de caracteres del entorno de idioma actual.

RETORNO

Devuelve NULL si font o charset son NULL; de lo contrario, devuelve una nueva lista de fuentes.

RELACIONADO

XmFontList(3) y XmFontListAppendEntry(3).
