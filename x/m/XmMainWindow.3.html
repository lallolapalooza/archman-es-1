NOMBRE

XmMainWindow — La clase de widget MainWindow

SINOPSIS

#include <Xm/MainW.h>

DESCRIPCIÓN

MainWindow proporciona un diseño estándar para la ventana principal de una aplicación. Este diseño incluye una barra de menú, una ventana de comandos, una región de trabajo, una ventana de mensajes y barras de desplazamiento. Cualquiera o todas estas áreas son opcionales. La región de trabajo y las barras de desplazamiento en MainWindow se comportan idénticamente a la región de trabajo y las barras de desplazamiento en ScrolledWindow. El usuario puede pensar en MainWindow como una ScrolledWindow extendida con una barra de menú opcional y una ventana de comandos y una ventana de mensajes opcionales.

En un MainWindow completamente cargado, la barra de menú se extiende horizontalmente por la parte superior de la ventana. La ventana de comandos se extiende horizontalmente por MainWindow justo debajo de la barra de menú, y la región de trabajo se encuentra debajo de la ventana de comandos. La ventana de mensajes está debajo de la región de trabajo. Cualquier espacio restante debajo de la ventana de mensajes se gestiona de manera idéntica a ScrolledWindow. El comportamiento de ScrolledWindow se puede controlar mediante los recursos de ScrolledWindow. Para crear un MainWindow, primero cree los elementos de la región de trabajo, una barra de menú, una ventana de comandos, una ventana de mensajes, una barra de desplazamiento horizontal y un widget de barra de desplazamiento vertical, y luego llame a XmMainWindowSetAreas con esos IDs de widget.

MainWindow también puede crear tres widgets Separator que proporcionan una separación visual de los cuatro componentes de MainWindow. El usuario puede especificar recursos en un archivo de recursos para los gadgets creados automáticamente que contienen los separadores de MainWindow. El nombre del primer gadget separador es Separator1; el segundo es Separator2; y el tercero es Separator3.

MainWindow también proporciona los siguientes tres tipos de hijos para la disposición en el momento de la creación:

•
XmMENU_BAR
•
XmCOMMAND_WINDOW
•
XmMESSAGE_WINDOW

MainWindow puede usar estos tipos de hijos en el momento de la creación en lugar de sus valores de recursos asociados. MainWindow utiliza el rasgo XmQTmenuSystem.

CLASES

MainWindow hereda comportamiento y recursos de Core, Composite, Constraint, XmManager y XmScrolledWindow.

El puntero de clase es xmMainWindowWidgetClass.

El nombre de la clase es XmMainWindow.

NAME

xmbind - Interface to the Motif MainWindow widget

SYNOPSIS

#include <Xm/MainW.h>

DESCRIPTION

The MainWindow widget is a composite widget that provides a standard layout for a main application window. It includes areas for a menu bar, a command window, a message window, and a work area. The widget manages the placement and sizing of these child widgets.

XmNcommandWindow
Specifies the widget to be laid out as the CommandWindow. This widget must have been previously created and managed as a child of MainWindow.
XmNcommandWindowLocation
Controls the position of the command window. XmCOMMAND_ABOVE_WORKSPACE locates the command window between the menu bar and the work window. XmCOMMAND_BELOW_WORKSPACE locates the command window between the work window and the message window.
XmNmainWindowMarginHeight
Specifies the margin height on the top and bottom of MainWindow. This resource overrides any setting of the ScrolledWindow resource XmNscrolledWindowMarginHeight.
XmNmainWindowMarginWidth
Specifies the margin width on the right and left sides of MainWindow. This resource overrides any setting of the ScrolledWindow resource XmNscrolledWindowMarginWidth.
XmNmenuBar
Specifies the widget to be laid out as the MenuBar. This widget must have been previously created and managed as a child of MainWindow.
XmNmessageWindow
Specifies the widget to be laid out as the MessageWindow. This widget must have been previously created and managed as a child of MainWindow. The MessageWindow is positioned at the bottom of the MainWindow. If this value is NULL, no message window is included in the MainWindow.
XmNshowSeparator
Displays separators between the components of the MainWindow when set to True. If set to False, no separators are displayed.

NAME

XmMainWindow - MainWindow widget class

SYNOPSIS

A MainWindow widget consists of a command window, a menu bar, a work area, a scroll bar, and three separator lines.

#include <Xm/MainW.h>

All declarations for MainWindow will be found in:

Widget w;
w = XmCreateMainWindow(parent, name, arglist, argcount);
w = XmVaCreateMainWindow(parent, name, arglist, ...);
w = XmCreateManagedMainWindow(parent, name, arglist, argcount);
w = XmVaCreateManagedMainWindow(parent, name, arglist, ...);

DESCRIPTION

The XmMainWindow widget is a composite widget that provides a standard layout for applications that have a command area, a menu bar, a work area, and one or more scroll bars.

The XmMainWindow widget is intended to be used as a container for other widgets. It defines specific areas for certain types of child widgets: the menu bar, the command widget, the work area, and the scroll bars. The widget automatically manages the placement of these child widgets within its boundaries.

The areas are defined by the following callbacks:

XmNcommandWindow
Specifies the widget to be placed in the command window area.
XmNmenuBar
Specifies the widget to be placed in the menu bar area.
XmNworkWindow
Specifies the widget to be placed in the work area.

The XmMainWindow widget also provides three separator lines that can be used to visually separate the menu bar from the work area, the work area from the command window, and the command window from the scroll bars. These separators are created automatically by the XmMainWindow widget.

The XmMainWindow widget inherits from XmManager and implements the resource sets for Core, Composite, Constraint, and XmManager.

Resources

The class record name is xmMainWindowClass.

The structure of the resources is:

include <Xm/Manager.h>
typedef struct XmMainWindowRec {
    CoreRec          core;
    CompositeRec     composite;
    ConstraintRec    constraint;
    XmManagerRec     manager;
    XmMainWindowRec  mainWindow;
} XmMainWindowRec;

XmMainWindow Geometry Management

The XmMainWindow widget provides geometry management for its children. It determines the size and position of the command window, menu bar, work window, and scroll bars based on the values of the associated constraint resources.
