XmbSetWMProperties(3)

Paquete: libx11

Licencias: MIT AND X11

XSetWMProperties(3) FUNCIONES DE XLIB XSetWMProperties(3)

NOMBRE

XSetWMProperties, XmbSetWMProperties, Xutf8SetWMProperties - establecer propiedades estándar de ventana

SINTAXIS

void XSetWMProperties(Display *display, Window w, XTextProperty *window_name, XTextProperty *icon_name, char **argv, int argc, XSizeHints *normal_hints, XWMHints *wm_hints, XClassHint *class_hints);

void XmbSetWMProperties(Display *display, Window w, _Xconst char *window_name, _Xconst char *icon_name, char *argv[], int argc, XSizeHints *normal_hints, XWMHints *wm_hints, XClassHint *class_hints);

void Xutf8SetWMProperties(Display *display, Window w, _Xconst char *window_name, _Xconst char *icon_name, char *argv[], int argc, XSizeHints *normal_hints, XWMHints *wm_hints, XClassHint *class_hints);

ARGUMENTOS

argc
Especifica el número de argumentos.
argv
Especifica la lista de argumentos de la aplicación.
class_hints
Especifica la estructura XClassHint a utilizar.
display
Especifica la conexión con el servidor X.
icon_name
Especifica el nombre del icono, que debe ser una cadena terminada en nulo.
normal_hints
Especifica las sugerencias de tamaño para la ventana en su estado normal.
w
Especifica la ventana.
window_name
Especifica el nombre de la ventana, que debe ser una cadena terminada en nulo.
wm_hints
Especifica la estructura XWMHints a utilizar.

DESCRIPCIÓN

La función de conveniencia XSetWMProperties proporciona una única interfaz de programación para establecer aquellas propiedades de ventana esenciales que se utilizan para comunicarse con otros clientes (particularmente gestores de ventanas y de sesiones).

Si el argumento window_name no es NULL, XSetWMProperties llama a XSetWMName, que a su vez, establece la propiedad WM_NAME (ver sección 14.1.4). Si el argumento icon_name no es NULL, XSetWMProperties llama a XSetWMIconName, que establece la propiedad WM_ICON_NAME (ver sección 14.1.5). Si el argumento argv no es NULL, XSetWMProperties llama a XSetCommand, que establece la propiedad WM_COMMAND (ver sección 14.2.1). Tenga en cuenta que se permite un argc de cero para indicar un comando de longitud cero. Tenga en cuenta también que el nombre de host de esta máquina se almacena utilizando XSetWMClientMachine (ver sección 14.2.2).

Si el argumento normal_hints no es NULL, XSetWMProperties llama a XSetWMNormalHints, que establece la propiedad WM_NORMAL_HINTS (ver sección 14.1.7). Si el argumento wm_hints no es NULL, XSetWMProperties llama a XSetWMHints, que establece la propiedad WM_HINTS (ver sección 14.1.6).

Si el argumento class_hints no es NULL, XSetWMProperties llama a XSetClassHint, que establece la propiedad WM_CLASS (ver sección 14.1.8). Si el miembro res_name en la estructura XClassHint se establece en el puntero NULL y la variable de entorno RESOURCE_NAME está establecida, entonces el valor de la variable de entorno se sustituye por res_name. Si el miembro res_name es NULL, la variable de entorno no está establecida, y argv y argv[0] están establecidos, entonces el valor de argv[0], despojado de cualquier prefijo de directorio, se sustituye por res_name.

Las funciones de conveniencia XmbSetWMProperties y Xutf8SetWMProperties proporcionan una interfaz de programación simple para establecer aquellas propiedades de ventana esenciales que se utilizan para comunicarse con otros clientes (particularmente gestores de ventanas y de sesiones).

Si el argumento window_name no es NULL, establecen la propiedad WM_NAME. Si el argumento icon_name no es NULL, establecen la propiedad WM_ICON_NAME. Los argumentos window_name e icon_name son cadenas terminadas en nulo, para XmbSetWMProperties en la codificación de la localidad actual, para Xutf8SetWMProperties en codificación UTF-8. Si los argumentos pueden convertirse completamente a la codificación STRING, las propiedades se crean con el tipo “STRING”; de lo contrario, los argumentos se convierten a Compound Text, y las propiedades se crean con el tipo “COMPOUND_TEXT”.

Si el argumento normal_hints no es NULL, XmbSetWMProperties y Xutf8SetWMProperties llaman a XSetWMNormalHints, que establece la propiedad WM_NORMAL_HINTS (ver sección 14.1.7). Si el argumento wm_hints no es NULL, XmbSetWMProperties y Xutf8SetWMProperties llaman a XSetWMHints, que establece la propiedad WM_HINTS (ver sección 14.1.6).

Si el argumento argv no es NULL, XmbSetWMProperties y Xutf8SetWMProperties establecen la propiedad WM_COMMAND a partir de argv y argc. Un argc de cero indica un comando de longitud cero.

El nombre de host de la máquina se almacena utilizando XSetWMClientMachine (ver sección 14.2.2).

Si el argumento class_hints no es NULL, XmbSetWMProperties y Xutf8SetWMProperties establecen la propiedad WM_CLASS. Si el miembro res_name en la estructura XClassHint se establece en el puntero NULL y la variable de entorno RESOURCE_NAME está establecida, el valor de la variable de entorno se sustituye por res_name. Si el miembro res_name es NULL, la variable de entorno no está establecida, y argv y argv[0] están establecidos, entonces el valor de argv[0], despojado de cualquier prefijo de directorio, se sustituye por res_name.

Se asume que los miembros class_hints.res_name y argv proporcionados, la variable de entorno RESOURCE_NAME y el nombre de host de la máquina están en la codificación de la localidad actual. Las propiedades WM_CLASS, WM_COMMAND y WM_CLIENT_MACHINE correspondientes se tipifican según el anunciador de la localidad del host local. No se realiza ninguna conversión de codificación para estas cadenas antes de almacenarlas en las propiedades.

Para los clientes que necesiten procesar el texto de la propiedad en una localidad, XmbSetWMProperties y Xutf8SetWMProperties establecen la propiedad WM_LOCALE_NAME para que sea el nombre de la localidad actual. Se asume que el nombre está en la Codificación de Caracteres Portátil del Host y se convierte a STRING para su almacenamiento en la propiedad.

XSetWMProperties, XmbSetWMProperties y Xutf8SetWMProperties pueden generar errores BadAlloc y BadWindow.

La función Xutf8SetWMProperties es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia está indicada por la macro X_HAVE_UTF8_STRING.

PROPIEDADES

WM_CLASS
Establecida por programas de aplicación para permitir a los gestores de ventanas y de sesiones obtener los recursos de la aplicación de la base de datos de recursos.
WM_CLIENT_MACHINE
El nombre de cadena de la máquina en la que se está ejecutando la aplicación cliente.
WM_COMMAND
El comando y los argumentos, separados por nulos, utilizados para invocar la aplicación.
WM_HINTS
Sugerencias adicionales establecidas por el cliente para su uso por el gestor de ventanas. El tipo C de esta propiedad es XWMHints.
WM_ICON_NAME
El nombre que se utilizará en un icono.
WM_NAME
El nombre de la aplicación.
WM_NORMAL_HINTS
Sugerencias de tamaño para una ventana en su estado normal. El tipo C de esta propiedad es XSizeHints.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.
