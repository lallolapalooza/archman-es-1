NOMBRE

XML::LibXML::XPathExpression - interfaz para expresiones XPath precompiladas de libxml2

SINOPSIS

use XML::LibXML;
my $compiled_xpath = XML::LibXML::XPathExpression->new('//foo[@bar="baz"][position()<4]');
# Interfaz desde XML::LibXML::Node
my $result = $node->find($compiled_xpath);
my @nodes = $node->findnodes($compiled_xpath);
my $value = $node->findvalue($compiled_xpath);
# Interfaz desde XML::LibXML::XPathContext
my $result = $xpc->find($compiled_xpath,$node);
my @nodes = $xpc->findnodes($compiled_xpath,$node);
my $value = $xpc->findvalue($compiled_xpath,$node);
$compiled = XML::LibXML::XPathExpression->new( string_xpath );

DESCRIPCIÓN

Esta es una interfaz de Perl para las expresiones XPath precompiladas de libxml2. Precompilar una consulta XPath puede ofrecer un beneficio de rendimiento si la misma consulta XPath se evalúa muchas veces. Los objetos "XML::LibXML::XPathExpression" pueden ser pasados a todas las funciones "find..." de "XML::LibXML" que esperan una expresión XPath.

new()
$compiled = XML::LibXML::XPathExpression->new( xpath_string );

El constructor toma una expresión XPath 1.0 como una cadena y devuelve un objeto que representa la expresión precompilada (la estructura de datos real es interna a libxml2).
