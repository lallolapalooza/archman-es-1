NOMBRE

XmDataField — La clase de widget DataField

SINOPSIS

#include <Xm/DataF.h>

DESCRIPCIÓN

El widget DataField es un widget de Presentación de Datos que maneja la visualización y la entrada de datos como texto. El widget DataField es una subclase del widget XmTextField destinada a aplicaciones de entrada de datos. Además de toda la funcionalidad normal de XmTextField, admite el análisis basado en expresiones regulares y la aceptación/rechazo de su entrada a través del recurso XmNpicture, y la justificación a la derecha a través del recurso XmNalignment.

El widget DataField proporciona capacidad adicional al admitir varios tipos de validación: un widget DataField que contiene un valor inválido no cederá el foco; el usuario debe ingresar un valor correcto antes de pasar a otro campo.

Clases

DataField hereda comportamiento, recursos y rasgos de Core, XmPrimitive y XmTextField.

El puntero de clase es xmDataFieldWidgetClass.

El nombre de la clase es XmDataField.

XmNalignment
Cuando se establece en XmALIGNMENT_END, el widget alinea todo su texto con el lado derecho del área de entrada.
XmNautoFill
Cuando se establece en True, el widget "auto-completa" su contenido cuando puede determinar que el siguiente carácter en la cadena debe ser un literal particular. Por ejemplo, la imagen "###-####" inserta automáticamente un carácter '-' después de recibir tres dígitos numéricos como entrada.
XmNpicture
Especifica una imagen para la entrada de datos en el widget. Una imagen actúa como una plantilla que formatea el valor que ingresa en un campo. Un ejemplo sería la imagen del número de teléfono de EE. UU .: (###)###-####. La imagen se utiliza para convertir los caracteres ingresados en el campo en un valor formateado.

NAME

XmDataField — A widget that allows the user to enter a string into a field

SYNOPSIS

#include <Xm/DataF.h>

A DataField widget has the following resources:

 XmNmaxLength               XmNmaxLength          int          0

 XmNpostCutCallback         XmCpostCutCallback    Proc         NULL

The DataField widget also inherits resources from the Core, XmPrimitive, and XmText widgets.

DESCRIPTION

The XmDataField widget is a convenience widget that simplifies the use of the XmText widget. It is intended to be used for simple data entry tasks. The DataField widget is constructed using an XmText widget.

The DataField widget handles the creation of the associated XmText widget and manages its geometry. A DataField widget's primary purpose is to provide a simple interface to the Text widget for basic string editing and display.

The DataField widget supports the following callback reasons:

  • XmCR_DATA_CHANGE: Invoked when the text in the widget has changed.
  • XmCR_DATA_VERIFY: Invoked when the text in the widget is about to change. This callback is used for validation.
  • XmCR_DISPLAY: Invoked when the text needs to be displayed. This is typically used for text conversion.
  • XmCR_POST_COPY: Invoked after a copy operation.
  • XmCR_POST_CUT: Invoked after a cut operation.
  • XmCR_POST_DELETE: Invoked after a delete operation.
  • XmCR_POST_INSERT: Invoked after an insert operation.
  • XmCR_POST_MOVE: Invoked after a move operation.
  • XmCR_POST_PASTE: Invoked after a paste operation.
  • XmCR_POST_REPLACE: Invoked after a replace operation.
  • XmCR_TEXT_CREATE: Invoked when the associated Text widget is created.
  • XmCR_TEXT_DESTROY: Invoked when the associated Text widget is destroyed.
  • XmCR_TEXT_RESIZE: Invoked when the associated Text widget is resized.
  • XmCR_TRAVERSE_OBSCURED: Invoked when traversing into a widget that is completely obscured.
  • XmCR_TRAVERSE_SIDE: Invoked when traversing into a widget that is partially obscured and the traversal is into the obscured side.

Callback Routines

Callback routines are invoked in the order they are added to the widget. They are not invoked if the widget is insensitive.

A callback routine has the following structure:

typedef struct _XmDataFieldCallbackStruct {
	Widget   w;       /* The XmDataField */   
	String   text;    /* Proposed string */   
	Boolean  accept;  /* Accept return value, for validation */
} XmDataFieldCallbackStruct;
