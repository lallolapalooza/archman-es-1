NOMBRE

XmStringComponentType — Tipo de datos para componentes de cadena compuesta

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

XmStringComponentType es el tipo de datos que especifica los tipos de componentes de cadena compuesta. Un componente de cadena compuesta identifica una parte de una cadena compuesta y puede tener un valor y una longitud. Un componente de cadena compuesta puede ser de uno de los siguientes tipos. Estos tipos de componentes se agrupan según su longitud y tipos de valor.

Los siguientes componentes tienen valores NULL y longitudes de 0 (cero).

XmSTRING_COMPONENT_SEPARATOR
Este componente generalmente se mapea a un salto de línea o retorno de carro en el texto mostrado.
XmSTRING_COMPONENT_TAB
Este componente puede considerarse como un componente de texto que contiene solo una tabulación única.
XmSTRING_COMPONENT_LAYOUT_POP
La dirección de diseño se mantiene en una pila, con la dirección actual en la cima de la pila. Cuando se lee este componente, la dirección de diseño leída más recientemente se saca de la pila y se reemplaza por la dirección inmediatamente anterior a ella.
XmSTRING_COMPONENT_END
Este componente marca el final de una cadena compuesta. No deben seguir otros componentes. Si una aplicación no coloca un componente XmSTRING_COMPONENT_END al final de una XmString, Motif lo hace automáticamente por la aplicación.

El siguiente componente tiene un valor de XmDirection y la longitud de esa dirección.

XmSTRING_COMPONENT_LAYOUT_PUSH
La dirección de diseño se mantiene en una pila, con la dirección actual en la cima de la pila. Este componente reemplaza la dirección de diseño actual y hace que se empuje otra en la cima de esta pila.

El siguiente componente tiene un valor de XmStringDirection y la longitud de esa dirección.

XmSTRING_COMPONENT_DIRECTION
Este componente establece la dirección de la cadena anulando la dirección de cadena anterior.

Los siguientes componentes tienen valores de tipo char * o un tipo equivalente, y las longitudes de esos tipos.

XmSTRING_COMPONENT_LOCALE_TEXT
Este componente contiene el texto multibyte de una cadena compuesta.
XmSTRING_COMPONENT_WIDECHAR_TEXT
Este componente contiene el texto widechar de una cadena compuesta.
XmSTRING_COMPONENT_TEXT
Este componente contiene el texto charset de una cadena compuesta. Tenga en cuenta que una cadena compuesta no puede contener texto charset y locale (multibyte o widechar).
XmSTRING_COMPONENT_RENDITION_BEGIN
Este componente marca el inicio de una nueva representación. Todo el texto que siga a este componente se renderizará utilizando esta representación como principal. Si ya hay una representación en vigor, se mantiene en memoria y se utiliza para completar cualquier valor no especificado en la representación principal. Las representaciones se mantienen hasta que se encuentra un componente XmSTRING_COMPONENT_RENDITION_END correspondiente.
XmSTRING_COMPONENT_RENDITION_END
Este componente indica que la representación especificada ya no se utilizará para renderizar texto y no estará disponible para completar los valores no especificados de representaciones más nuevas.
XmSTRING_COMPONENT_UNKNOWN
Este tipo de componente indica que el contenido del componente pertenece a un tipo de componente desconocido.
XmSTRING_COMPONENT_LOCALE
Utilice este componente para especificar la configuración regional en la que se ejecutará una aplicación internacionalizada. La única cadena de caracteres válida para este componente es _MOTIF_DEFAULT_LOCALE.
XmSTRING_COMPONENT_TAG
Para texto charset, esta es la etiqueta de la fuente que se utilizará para mostrar el texto. Esta etiqueta a veces se denomina etiqueta charset o etiqueta fontlist.
XmSTRING_COMPONENT_CHARSET
Este componente está obsoleto y se mantiene por compatibilidad con versiones anteriores. Ha sido reemplazado por XmSTRING_COMPONENT_TAG.
XmSTRING_COMPONENT_FONTLIST_ELEMENT_TAG
Este componente está obsoleto y se mantiene por compatibilidad con versiones anteriores. Ha sido reemplazado por XmSTRING_COMPONENT_TAG.

Algunos componentes de cadena compuesta dependen de valores definidos en otros componentes. La definición del componente XmSTRING_COMPONENT_TAB, por ejemplo, depende de la información en XmSTRING_COMPONENT_RENDITION_BEGIN. Para tener en cuenta estas dependencias, una cadena compuesta típica tendrá sus componentes miembros en el siguiente orden:

[
  [ XmSTRING_COMPONENT_LAYOUT_PUSH ]
  [ XmSTRING_COMPONENT_RENDITION_BEGIN ]*
  [ XmSTRING_COMPONENT_TAG | XmSTRING_COMPONENT_LOCALE ]
  [ XmSTRING_COMPONENT_TAB ]*
  [ XmSTRING_COMPONENT_DIRECTION ]
  [ XmSTRING_COMPONENT_TEXT |
    XmSTRING_COMPONENT_LOCALE_TEXT |
    XmSTRING_COMPONENT_WIDECHAR_TEXT ]
  [ XmSTRING_COMPONENT_RENDITION_END ]*
  [ XmSTRING_COMPONENT_LAYOUT_POP ]
  [ XmSTRING_COMPONENT_SEPARATOR ]
]*
XmSTRING_COMPONENT_END
