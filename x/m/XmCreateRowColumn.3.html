NOMBRE

XmCreateRowColumn — La función de creación del widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmCreateRowColumn(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateRowColumn crea una instancia de un widget RowColumn y devuelve su ID. Si no se especifica XmNrowColumnType, se crea con XmWORK_AREA, que es el valor por defecto.

Si esta función se usa para crear un menú emergente (Popup Menu) de tipo XmMENU_POPUP o un menú desplegable (Pulldown Menu) de tipo XmMENU_PULLDOWN, no se crea automáticamente un widget MenuShell como padre del panel del menú. La aplicación debe crear primero el MenuShell utilizando XmCreateMenuShell o la función de creación estándar del toolkit.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
arglist
Especifica la lista de argumentos.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Para una definición completa de RowColumn y sus recursos asociados, vea XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.
