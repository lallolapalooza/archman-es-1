XML::XPath::Boolean(3) Documentación de Perl aportada por el usuario XML::XPath::Boolean(3)

NOMBRE

XML::XPath::Boolean - Valores booleanos verdadero/falso

DESCRIPCIÓN

Los objetos XML::XPath::Boolean implementan objetos simples de valor booleano verdadero/falso.

API

XML::XPath::Boolean->True

Crea un nuevo objeto Booleano con un valor verdadero.

XML::XPath::Boolean->False

Crea un nuevo objeto Booleano con un valor falso.

value()

Devuelve verdadero o falso.

to_literal()

Devuelve la cadena "true" o "false".
