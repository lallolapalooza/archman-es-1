NOMBRE

XmParseMapping — Tipo de dato para un mapeo de análisis de cadenas compuestas

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

XmParseMapping es un tipo de dato opaco para un mapeo de análisis utilizado por XmStringParseText para crear una cadena compuesta. Un mapeo de análisis contiene un patrón para ser comparado en el texto que se está analizando para crear una cadena compuesta. También contiene una cadena compuesta, o una función que se invocará para proporcionar una cadena compuesta, que se incluirá en la cadena compuesta que se está creando cada vez que se encuentre una coincidencia con el patrón.

Una aplicación utiliza una interfaz de estilo de recursos para especificar componentes para un XmParseMapping. XmParseMappingCreate crea un mapeo de análisis, utilizando una lista de argumentos de estilo de recursos. XmParseMappingGetValues y XmParseMappingSetValues recuperan y establecen los componentes de un mapeo de análisis. XmParseMappingFree recupera la memoria utilizada por un mapeo de análisis. XmParseTable es un array de objetos XmParseMapping.

El recurso XmNinvokeParseProc es una función de tipo XmParseProc, que se define de la siguiente manera:

XmIncludeStatus (*XmParseProc) (text_in_out, text_end, type, tag, entry, pattern_length,
str_include, call_data)
        XtPointer *text_in_out;
        XtPointer text_end;
        XmTextType type;
        XmStringTag tag;
        XmParseMapping entry;
        int pattern_length;
        XmString *str_include;
        XtPointer call_data;

Un procedimiento de análisis proporciona un mecanismo de escape para el análisis arbitrariamente complejo. Este procedimiento se invoca cuando un patrón en el texto de entrada coincide con un patrón en un mapeo de análisis cuyo XmNincludeStatus es XmINVOKE.

El texto de entrada es un puntero al primer byte del patrón que coincidió para activar la llamada al procedimiento de análisis. El procedimiento de análisis consume tantos bytes de la cadena de entrada como necesite y establece el puntero de texto de entrada al byte siguiente. Devuelve una cadena compuesta para ser incluida en la cadena compuesta que se está construyendo, y también devuelve un XmIncludeStatus que indica cómo debe manejarse la cadena compuesta devuelta. Si el procedimiento de análisis no avanza el puntero de texto de entrada al menos un byte, la rutina de análisis continúa intentando comparar el texto de entrada con los patrones en los mapeos de análisis restantes en la tabla de análisis. De lo contrario, la rutina de análisis comienza con el nuevo puntero de texto de entrada y trata de comparar el texto de entrada con los patrones en los mapeos de análisis a partir del principio de la tabla de análisis.

text_in_out
Especifica el texto que se está analizando. El valor es un puntero al primer byte de texto que coincide con el patrón que activó la llamada al procedimiento de análisis. Cuando el procedimiento de análisis regresa, este argumento se establece en la posición en el texto donde debe reanudar el análisis, es decir, al byte siguiente al último carácter analizado por el procedimiento de análisis.
text_end
Especifica un puntero al final de la cadena text_in_out. Si text_end es NULL, la cadena se escanea hasta encontrar un carácter NULL. De lo contrario, la cadena se escanea hasta, pero sin incluir, el carácter cuya dirección es text_end.
type
Especifica el tipo de texto y el tipo de etiqueta. Si se debe crear una etiqueta de local, type tiene un valor de XmMULTIBYTE_TEXT o XmWIDECHAR_TEXT. Si se debe crear un conjunto de caracteres, type tiene un valor de XmCHARSET_TEXT.
tag
Especifica la etiqueta que se utilizará al crear el resultado. El tipo de etiqueta de cadena creada (conjunto de caracteres o local) depende del tipo de texto y del valor de tag pasado. Si el valor de tag es NULL y si type indica que se debe crear una etiqueta de cadena de conjunto de caracteres, la etiqueta de cadena tiene el valor que es el resultado de mapear XmSTRING_DEFAULT_CHARSET. Si type indica una etiqueta de cadena de local, la etiqueta de cadena tiene el valor _MOTIF_DEFAULT_LOCALE.
entry
Especifica el mapeo de análisis que activó la llamada al procedimiento de análisis.
pattern_length
Especifica el número de bytes en el texto de entrada, que siguen a text_in_out, que constituyen el patrón que coincidió.
str_include
Especifica un puntero a una cadena compuesta. El procedimiento de análisis crea una cadena compuesta para ser incluida en la cadena compuesta que se está construyendo. El procedimiento de análisis luego devuelve la cadena compuesta en este argumento.
call_data
Especifica los datos pasados por la aplicación a la rutina de análisis.

El procedimiento de análisis devuelve un XmIncludeStatus que indica cómo se debe incluir str_include en la cadena compuesta que se está construyendo. A continuación se presentan los valores posibles:

XmINSERT
Concatena el resultado a la cadena compuesta que se está construyendo y continúa el análisis.
XmTERMINATE
Concatena el resultado a la cadena compuesta que se está construyendo y termina el análisis.

NAME

XmParseMappingSetValues, XmParseMappingGetValues, XmParseMappingCreate, XmParseMappingFree — create, manage, and retrieve parsing information

    ArgList             args,

DESCRIPTION

The functions XmParseMappingCreate, XmParseMappingFree, XmParseMappingGetValues, and XmParseMappingSetValues manage the mapping table for a widget. A mapping table defines how to parse text, how to substitute the parsed text, and how to invoke a parsing procedure.

A mapping table is defined by a set of resources. These resources can be set when the mapping table is created using XmParseMappingCreate or modified later using XmParseMappingSetValues. The current values of the resources can be retrieved using XmParseMappingGetValues. The mapping table widget itself is created as a child of the widget specified by the widget argument.

The following resources are used to define the mapping table:

Resource Default Value Type Description Status
XmNclientData NULL XtPointer Specifies data to be used by the parse procedure. CSG
XmNincludeStatus XmINSERT Unsigned char Specifies how the result of the mapping is to be included in the compound string being constructed. Unless the value is XmINVOKE, the result of the mapping is the value of XmNsubstitute. CSG
XmNinvokeParseProc NULL XmParseProc Specifies the parse procedure to be invoked when XmNincludeStatus is XmINVOKE. CSG
XmNpattern NULL String Specifies a pattern to be matched in the text being parsed. This is a maximum of one character. CSG
XmNpatternType XmCHARSET_TEXT XmParsePatternType Specifies the type of the pattern that is the value of XmNpattern. CSG
XmNsubstitute NULL XmString Specifies the compound string to be included in the compound string being constructed when XmNincludeStatus is XmINSERT or XmTERMINATE. CSG
XmNclientData
Specifies data to be used by the parse procedure.
XmNincludeStatus
Specifies how the result of the mapping is to be included in the compound string being constructed. Unless the value is XmINVOKE, the result of the mapping is the value of XmNsubstitute. Following are the possible values for XmNincludeStatus:
XmINSERT
Concatenate the result to the compound string being constructed and continue parsing.
XmINVOKE
Invoke the XmNinvokeParseProc on the text being parsed and use the returned compound string instead of XmNsubstitute as the result to be inserted into the compound string being constructed. The include status returned by the parse procedure (XmINSERT or XmTERMINATE) determines how the returned compound string is included.
XmTERMINATE
Concatenate the result to the compound string being constructed and terminate parsing.
XmNinvokeParseProc
Specifies the parse procedure to be invoked when XmNincludeStatus is XmINVOKE.
XmNpattern
Specifies a pattern to be matched in the text being parsed. This is a maximum of one character.
XmNpatternType
Specifies the type of the pattern that is the value of XmNpattern. Following are the possible values:
•
XmCHARSET_TEXT
•
XmMULTIBYTE_TEXT
•
XmWIDECHAR_TEXT
XmNsubstitute
Specifies the compound string to be included in the compound string being constructed when XmNincludeStatus is XmINSERT or XmTERMINATE.
