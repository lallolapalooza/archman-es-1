NOMBRE

XmCreateMenuBar — Función de conveniencia para la creación de un widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmCreateMenuBar(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateMenuBar crea una instancia de un widget RowColumn de tipo XmMENU_BAR y devuelve el ID del widget asociado. Se proporciona como una función de conveniencia para crear widgets RowColumn configurados para funcionar como una barra de menú y no se implementa como una clase de widget separada.

El widget MenuBar se utiliza generalmente para construir un sistema de menús desplegables. Típicamente, se crea una MenuBar y se coloca en la parte superior de la ventana de la aplicación, y se insertan varios CascadeButtons como hijos. Cada uno de los CascadeButtons tiene asociado un panel de menú desplegable. Estos paneles de menú desplegables deben haber sido creados como hijos de la MenuBar. El usuario interactúa con la MenuBar utilizando el ratón o el teclado.

El widget MenuBar muestra una sombra 3D a lo largo de su borde. La aplicación controla los atributos de la sombra utilizando los recursos relacionados con la visualización admitidos por XmManager.

El widget MenuBar es homogéneo, ya que solo acepta hijos que sean una subclase de XmCascadeButton o XmCascadeButtonGadget. Intentar insertar un hijo de una clase diferente genera un mensaje de advertencia.

Si la MenuBar no tiene suficiente espacio para contener todos sus subwidgets en una sola línea, la MenuBar intenta ajustar las entradas restantes en líneas adicionales si el gestor de geometría del widget padre lo permite.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
arglist
Especifica la lista de argumentos.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.

RELACIONADOS

XmCascadeButton(3), XmCascadeButtonGadget(3), XmCreatePulldownMenu(3), XmCreateSimpleMenuBar(3), XmManager(3), XmRowColumn(3), y XmVaCreateSimpleMenuBar(3).
