NOMBRE

XmClipboardCopyByName — Una función del portapapeles que copia un elemento de datos pasado por nombre

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardCopyByName (display, window, data_id,
        buffer, length, private_id)
        Display * display;
        Window  window;
        long    data_id;
        XtPointer       buffer;
        unsigned long   length;
        long    private_id;
(void)

DESCRIPCIÓN

XmClipboardCopyByName copia los datos reales de un elemento de datos que se pasó previamente por nombre al portapapeles. Los datos se consideran pasados por nombre cuando se realiza una llamada a XmClipboardCopy con un parámetro de búfer NULL. Las llamadas adicionales a esta función añaden nuevos datos a los datos existentes.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de la ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de la ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debería pasar el mismo ID de ventana a cada función del portapapeles que llame.
data_id
Especifica un número de identificación asignado al elemento de datos que identifica de forma única el elemento de datos y el formato. Este número fue asignado por XmClipboardCopy al elemento de datos.
buffer
Especifica el búfer desde el que el portapapeles copia los datos.
length
Especifica el número de bytes en el elemento de datos.
private_id
Especifica los datos privados que la aplicación desea almacenar con el elemento de datos.

RETORNAR

XmClipboardSuccess
La función se realizó con éxito.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función de nuevo con los mismos parámetros hasta que el bloqueo desaparezca. Esto da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentándolo o renunciar a la operación.

RELACIONADO

XmClipboardCopy(3), XmClipboardLock(3), XmClipboardStartCopy(3), y XmClipboardUnlock(3).
