NOMBRE

XmGetPixmapByDepth — Una función de caché de pixmaps que genera un pixmap, lo almacena en una caché de pixmaps y devuelve el pixmap

SINOPSIS

#include <Xm/Xm.h>
Pixmap XmGetPixmapByDepth(
Screen *screen,
char *image_name,
Pixel foreground,
Pixel background,
int depth);

DESCRIPCIÓN

XmGetPixmapByDepth utiliza los datos de los parámetros para realizar una búsqueda en la caché de pixmaps y ver si ya se ha generado un pixmap que coincida con los datos. Si se encuentra uno, se incrementa un contador de referencias y se devuelve el pixmap. Las aplicaciones deben usar XmDestroyPixmap cuando el pixmap ya no sea necesario.

screen
Especifica la pantalla del dispositivo en la que se dibujará el pixmap
image_name
Especifica el nombre de la imagen que se utilizará para generar el pixmap
foreground
Combina la imagen con el color de primer plano para crear el pixmap si la imagen referenciada es una imagen de bits por píxel
background
Combina la imagen con el color de fondo para crear el pixmap si la imagen referenciada es una imagen de bits por píxel
depth
Especifica la profundidad del pixmap

Si no se encuentra un pixmap coincidente, image_name se utiliza para realizar una búsqueda en la caché de imágenes. Si se encuentra una imagen, se utiliza para generar el pixmap, que luego se almacena en caché y se devuelve.

Si no se encuentra una imagen, image_name se utiliza como nombre de archivo y se realiza una búsqueda de un archivo de mapa de bits X10 o X11. Si se encuentra, el archivo se lee, se convierte en una imagen y se almacena en caché en la caché de imágenes. Luego, la imagen se utiliza para generar un pixmap, que se almacena en caché y se devuelve.

Si image_name tiene una barra inclinada / (barra) al principio, especifica una ruta completa y XmGetPixmapByDepth abre el archivo según lo especificado. De lo contrario, image_name especifica un nombre de archivo. En este caso, XmGetPixmapByDepth busca el archivo a lo largo de una ruta de búsqueda especificada por la variable de entorno XBMLANGPATH o por una ruta de búsqueda predeterminada, que varía según si la variable de entorno XAPPLRESDIR está establecida o no. La ruta de búsqueda predeterminada contiene muchos directorios. Por lo tanto, XmGetPixmapByDepth necesitará un tiempo relativamente largo para buscar en todos estos directorios pixmaps y mapas de bits. Las aplicaciones que utilizan muchos pixmaps y mapas de bits probablemente se ejecutarán más rápido si XBMLANGPATH se establece en una lista corta de directorios. Además de los archivos de mapa de bits X (XBM), Motif también soporta formatos de archivo XPM (X Pixmap) y, a partir de la versión 2.3, formatos de imagen JPEG y PNG. (Tenga en cuenta que el soporte de los formatos de imagen JPEG y PNG es una característica opcional de Motif; para verificar si la versión actual admite los formatos de imagen PNG y JPEG, se deben verificar las macros PNG_SUPPORT y JPEG_SUPPORT correspondientemente). La variable XBMLANGPATH especifica la ruta para archivos XBM, XPM, PNG y JPEG. Los archivos XPM se describen con más detalle más adelante en esta página de referencia.

La variable de entorno XBMLANGPATH especifica una ruta de búsqueda para archivos de mapa de bits X. Puede contener el campo de sustitución %B, donde el argumento image_name de XmGetPixmapByDepth se sustituye por %B. También puede contener los campos de sustitución aceptados por XtResolvePathname. El campo de sustitución %T siempre se mapea a bitmaps y %S siempre se mapea a NULL.

NAME

XmGetPixmapByDepth — A convenient way to obtain a pixmap by name and screen

SYNOPSIS

#include <Xm/Xm.h>
Pixmap XmGetPixmapByDepth(
        Widget widget,
        _In_z_ String pixmap_name,
        _In_opt_ Pixmap pixmap_mask,
        unsigned int depth );

DESCRIPTION

The function XmGetPixmapByDepth retrieves a pixmap resource. The widget argument is used to determine the screen and visual. The pixmap_name argument specifies the name of the pixmap to retrieve. The pixmap_mask argument is optional and can be None. The depth argument specifies the desired depth of the pixmap. If the pixmap is not found, XmUNSPECIFIED_PIXMAP is returned. Otherwise, a valid pixmap is returned.

The function first searches for the pixmap in the installed pixmap cache. If it is not found in the cache, the function searches for the pixmap in the application's pixmap directory. The application's pixmap directory is determined by the XmNbitmapDirectory resource. If the pixmap is not found in the application's pixmap directory, the function searches for the pixmap in the system's default pixmap directory. The system's default pixmap directory is usually /usr/lib/X11/pixmaps.

If the pixmap is found in either the application's or the system's pixmap directory, it is loaded into the pixmap cache and then returned.

If the pixmap cannot be found, XmUNSPECIFIED_PIXMAP is returned.

The following is an example of how to use XmGetPixmapByDepth:

    Pixmap my_pixmap;
    my_pixmap = XmGetPixmapByDepth(widget, "my_pixmap_name", None, 24);
    if (my_pixmap == XmUNSPECIFIED_PIXMAP) {
        fprintf(stderr, "Could not find pixmap my_pixmap_name\n");
    } else {
        // Use the pixmap
    }
