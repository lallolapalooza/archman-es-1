NOMBRE

XmCreateFileSelectionBox — La función de creación del widget FileSelectionBox

SINOPSIS

#include <Xm/FileSB.h>
Widget XmCreateFileSelectionBox(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateFileSelectionBox crea un FileSelectionBox no gestionado. Un FileSelectionBox se utiliza para seleccionar un archivo e incluye lo siguiente:

•
Un campo de texto editable para la máscara del directorio
•
Una lista de desplazamiento de nombres de archivo
•
Un campo de texto editable para el archivo seleccionado
•
Etiquetas para la lista y los campos de texto
•
Cuatro botones

Las etiquetas de los botones por defecto son OK, Filter, Cancel y Help. Se pueden añadir hijos adicionales al área de trabajo del FileSelectionBox después de la creación. FileSelectionBox hereda la funcionalidad de diseño proporcionada por SelectionBox para cualquier hijo adicional del área de trabajo.

Si el padre del FileSelectionBox es un DialogShell, use XtManageChild para mostrar el FileSelectionDialog (pasando el FileSelectionBox como parámetro del widget); use XtUnmanageChild para ocultarlo.

parent
Especifica el ID del widget padre
name
Especifica el nombre del widget creado
arglist
Especifica la lista de argumentos
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist)

Para una definición completa de FileSelectionBox y sus recursos asociados, consulte XmFileSelectionBox(3).

RETORNO

Devuelve el ID del widget FileSelectionBox.

RELACIONADO

XmFileSelectionBox(3).
