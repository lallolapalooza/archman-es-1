NOMBRE

XmScrollBar — La clase del widget ScrollBar

SINOPSIS

#include <Xm/ScrollBar.h>

DESCRIPCIÓN

El widget ScrollBar permite al usuario ver datos que son demasiado grandes para ser mostrados a la vez. Los ScrollBars se encuentran normalmente dentro de una ScrolledWindow y adyacentes al widget que contiene los datos a ser vistos. Cuando el usuario interactúa con el ScrollBar, los datos dentro del otro widget se desplazan.

Un ScrollBar consiste en dos flechas colocadas en cada extremo de un rectángulo. El rectángulo se llama región de desplazamiento. Un rectángulo más pequeño, llamado deslizador, se coloca dentro de la región de desplazamiento. Los datos se desplazan haciendo clic en cualquiera de las flechas, seleccionando en la región de desplazamiento o arrastrando el deslizador. Cuando se selecciona una flecha, el deslizador dentro de la región de desplazamiento se mueve en la dirección de la flecha en una cantidad proporcionada por la aplicación. Si se mantiene presionado el botón del ratón, el deslizador continúa moviéndose a una velocidad constante.

La relación del tamaño del deslizador con el tamaño de la región de desplazamiento generalmente corresponde a la relación entre el tamaño de los datos visibles y el tamaño total de los datos. Por ejemplo, si el 10 por ciento de los datos es visible, el deslizador ocupa típicamente el 10 por ciento de la región de desplazamiento. Esto proporciona al usuario una pista visual del tamaño de los datos invisibles.

Si el padre del ScrollBar es una ScrolledWindow automática, el valor predeterminado de XmNtraversalOn es True. De lo contrario, el valor predeterminado es False.

ScrollBar posee los rasgos de XmQTnavigator.

Clases

ScrollBar hereda comportamiento, recursos y rasgos de las clases Core y XmPrimitive.

El puntero de clase es xmScrollBarWidgetClass.

El nombre de la clase es XmScrollBar.

Razones de Callback

El widget ScrollBar define las siguientes razones de callback:

XmCR_DECREMENT
Se invoca cuando el usuario selecciona la flecha de decremento.
XmCR_DRAG
Se invoca cuando el usuario arrastra el deslizador.
XmCR_INCREMENT
Se invoca cuando el usuario selecciona la flecha de incremento.
XmCR_PAGE_DECREMENT
Se invoca cuando el usuario selecciona la región de desplazamiento por encima del deslizador.
XmCR_PAGE_INCREMENT
Se invoca cuando el usuario selecciona la región de desplazamiento por debajo del deslizador.
XmCR_TO_TOP
Se invoca cuando el usuario selecciona la flecha de arriba.
XmCR_TO_BOTTOM
Se invoca cuando el usuario selecciona la flecha de abajo.
XmCR_TO_LEFT
Se invoca cuando el usuario selecciona la flecha de la izquierda.
XmCR_TO_RIGHT
Se invoca cuando el usuario selecciona la flecha de la derecha.

La estructura XmScrollBarCallbackStruct se proporciona a cada rutina de callback. La estructura tiene los siguientes miembros:

typedef struct {
    int reason;
    XEvent *event;
    int value;
    int page_increment;
    int increment;
    int minimum;
    int maximum;
    int slider_size;
    int slider_min_value;
    int slider_max_value;
} XmScrollBarCallbackStruct;

value: Contiene la posición del deslizador.

page_increment: Contiene el valor de XmNpageIncrement.

increment: Contiene el valor de XmNincrement.

minimum: Contiene el valor de XmNminimum.

maximum: Contiene el valor de XmNmaximum.

slider_size: Contiene el tamaño del deslizador.

slider_min_value: Contiene el valor mínimo del deslizador.

slider_max_value: Contiene el valor máximo del deslizador.

Recorrido

Los recorridos horizontales y verticales están habilitados de forma predeterminada. El usuario puede recorrer el widget ScrollBar usando las teclas de flecha.

Comportamiento del Widget

El widget ScrollBar permite al usuario controlar la posición de un deslizador dentro de un canal. El canal es el área del widget que contiene el deslizador. El deslizador es un rectángulo dentro del canal que se puede mover hacia arriba, hacia abajo, hacia la izquierda o hacia la derecha, dependiendo de la orientación del ScrollBar.

El usuario puede mover el deslizador de las siguientes maneras:

  • Haciendo clic en una de las flechas del ScrollBar.
  • Arrastrando el deslizador.
  • Haciendo clic en el canal del ScrollBar.

Cuando el usuario mueve el deslizador, el widget ScrollBar invoca las rutinas de callback apropiadas.

El rango del ScrollBar se define mediante los recursos XmNminimum y XmNmaximum. El valor del deslizador se puede establecer mediante el recurso XmNvalue.

El tamaño del deslizador se calcula en función de la relación entre el valor visible y el valor total de los datos. Por ejemplo, si solo se puede ver una pequeña parte de los datos, el deslizador será pequeño. Si se pueden ver la mayoría de los datos, el deslizador será grande.

El widget ScrollBar tiene dos orientaciones: vertical y horizontal.

XmVERTICAL
XmHORIZONTAL

La orientación predeterminada es XmVERTICAL.

Interacción con ScrolledWindow

El widget ScrollBar se utiliza normalmente junto con el widget ScrolledWindow. El widget ScrolledWindow proporciona un marco alrededor de un widget de contenido y ScrollBars para desplazar el contenido.

Cuando se colocan juntos, el ScrollBar desplaza el contenido del widget de contenido dentro de la ScrolledWindow.

Hay dos formas de usar ScrollBars con ScrolledWindows:

Manual
El usuario crea explícitamente los widgets ScrollBar y ScrolledWindow y los gestiona él mismo.
Automático
El widget ScrolledWindow crea automáticamente los ScrollBars para el usuario si se establece el recurso XmNScrollSide en un valor apropiado.

EJEMPLO

Para crear un ScrollBar vertical:

Widget scrollbar;

scrollbar = XmCreateScrollBar(parent, "scrollbar", NULL, 0);

Para crear un ScrollBar horizontal:

Widget scrollbar;

scrollbar = XmCreateScrollBar(parent, "scrollbar", NULL, 0);
XtVaSetValues(scrollbar, XmNorientation, XmHORIZONTAL, NULL);

XmNdecrementCallback
Especifica la lista de callbacks que se llama cuando el usuario realiza una acción que mueve la Barra de Desplazamiento un incremento y el valor disminuye. La razón pasada al callback es XmCR_DECREMENT.
XmNdragCallback
Especifica la lista de callbacks que se llama en cada cambio incremental de posición cuando el deslizador está siendo arrastrado. La razón enviada por el callback es XmCR_DRAG.
XmNeditable
Especifica cómo reaccionará la Barra de Desplazamiento a la entrada del usuario. Este recurso puede tener valores True o False, como sigue:
True
Permite que la barra de desplazamiento sea sensible a la entrada del usuario. Este es el valor predeterminado.
False
Hace que la barra de desplazamiento de la Escala sea insensible a la entrada del usuario. El aspecto visual no se atenúa. Este valor se usaría principalmente en modo XmTHERMOMETER.
Cuando se usa XmNeditable en un widget, establece el sitio de caída a XmDROP_SITE_ACTIVE.
XmNincrement
Especifica la cantidad en la que el valor aumenta o disminuye cuando el usuario realiza una acción que mueve el deslizador un incremento. El cambio real en el valor es el menor entre XmNincrement y (valor XmNvalue anterior - XmNminimum) cuando el deslizador se mueve al final de la Barra de Desplazamiento con el valor mínimo, y el menor entre XmNincrement y (XmNmaximum - XmNsliderSize - valor XmNvalue anterior) cuando el deslizador se mueve al final de la Barra de Desplazamiento con el valor máximo. El valor de este recurso debe ser mayor que 0 (cero).
XmNincrementCallback
Especifica la lista de callbacks que se llama cuando el usuario realiza una acción que mueve la Barra de Desplazamiento un incremento y el valor aumenta. La razón pasada al callback es XmCR_INCREMENT.
XmNinitialDelay
Especifica el tiempo en milisegundos a esperar antes de iniciar el movimiento continuo del deslizador mientras se presiona un botón en una flecha o en la región de desplazamiento. El valor de este recurso debe ser mayor que 0 (cero).
XmNmaximum
Especifica el valor máximo del deslizador. XmNmaximum debe ser mayor que XmNminimum.
XmNminimum
Especifica el valor mínimo del deslizador. XmNmaximum debe ser mayor que XmNminimum.
XmNorientation
Especifica si la Barra de Desplazamiento se muestra vertical u horizontalmente. Este recurso puede tener los valores XmVERTICAL y XmHORIZONTAL.
XmNpageDecrementCallback
Especifica la lista de callbacks que se llama cuando el usuario realiza una acción que mueve la Barra de Desplazamiento un incremento de página y el valor disminuye. La razón pasada al callback es XmCR_PAGE_DECREMENT.
XmNpageIncrement
Especifica la cantidad en la que el valor aumenta o disminuye cuando el usuario realiza una acción que mueve el deslizador un incremento de página. El cambio real en el valor es el menor entre XmNpageIncrement y (valor XmNvalue anterior - XmNminimum) cuando el deslizador se mueve al final de la Barra de Desplazamiento con el valor mínimo, y el menor entre XmNpageIncrement y (XmNmaximum - XmNsliderSize - valor XmNvalue anterior) cuando el deslizador se mueve al final de la Barra de Desplazamiento con el valor máximo. El valor de este recurso debe ser mayor que 0 (cero).

RESOURCES

XmNbackground
Specifies the background color of the ScrollBar trough. The default value is the background color of the parent window.
XmNdecrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one unit and the value decreases. The reason passed to the callback is XmCR_DECREMENT.
XmNfontList
Specifies the font list for the ScrollBar. The default value is the default font list for the widget.
XmNforeground
Specifies the foreground color of the ScrollBar trough. The default value is the foreground color of the parent window.
XmNinitialDelay
Specifies the amount of time in milliseconds to wait before the first subsequent slider movement occurs after the user presses and holds an arrow button. The value must be greater than 0 (zero).
XmNincrement
Specifies the distance the slider moves when an arrow button is clicked. The default value is 1.
XmNincrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one unit and the value increases. The reason passed to the callback is XmCR_INCREMENT.
XmNmaximum
Specifies the maximum value of the ScrollBar. The default value is 100.
XmNminimum
Specifies the minimum value of the ScrollBar. The default value is 0.
XmNpageDecrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one page increment and the value decreases. The reason passed to the callback is XmCR_PAGE_DECREMENT.
XmNpageIncrement
Specifies the distance the slider moves when the user clicks in the trough area of the ScrollBar. The default value is 10.
XmNpageIncrementCallback
Specifies the list of callbacks that is called when the user takes an action that moves the ScrollBar by one page increment and the value increases. The reason passed to the callback is XmCR_PAGE_INCREMENT.
XmNprocessingDirection
Specifies whether the value for XmNmaximum should be on the right or left side of XmNminimum for horizontal ScrollBars or above or below XmNminimum for vertical ScrollBars. This resource can have values of XmMAX_ON_TOP, XmMAX_ON_BOTTOM, XmMAX_ON_LEFT, and XmMAX_ON_RIGHT. If the ScrollBar is oriented vertically, the default value is XmMAX_ON_BOTTOM. If the ScrollBar is oriented horizontally, the default value depends on the XmNlayoutDirection resource of the widget.
XmNrepeatDelay
Specifies the amount of time in milliseconds to wait between subsequent slider movements after the XmNinitialDelay has been processed. The value of this resource must be greater than 0 (zero).
XmNshowArrows
Specifies whether the arrows are displayed and how they are to be displayed. This resource can take the following values:
XmEACH_SIDE
Indicates that one arrow is displayed on each end of the ScrollBar slider. This corresponds to a value of True in previous releases.
XmMAX_SIDE
Indicates that both arrows are displayed on the XmNmaximum side of the ScrollBar slider.
XmMIN_SIDE
Indicates that both arrows are displayed on the XmNminimum side of the ScrollBar slider.
XmNONE
Indicates that no arrows are displayed. This corresponds to a value of False in previous releases.
XmEACH_SIDE is the default value.
XmNsliderMark
Specifies the shape the slider is to be displayed in. This resource can take the following values:
XmETCHED_LINE
Specifies the slider as an etched line.
XmNONE
Specifies the slider as a foregrounded rectangle. This is the default for a regular slider.
XmROUND_MARK
Specifies the slider as a shadowed circle. This is the default when the slider is a thermometer.
XmTHUMB_MARK
Specifies the slider as a series of three etched lines centered in the middle of the slider.
XmNslidingMode
Specifies the mode the slider works in. There are two possible modes:
XmSLIDER
Allows the slider to move freely between the minimum and maximum ends of the scale. This is the default value.
XmTHERMOMETER
Forces the slider to be anchored to one side of the trough area.
XmNsliderSize
Specifies the length of the slider between the values of 1 and (XmNmaximum - XmNminimum). The value is constrained to be within these inclusive bounds. The default value is (XmNmaximum - XmNminimum) divided by 10, with a minimum of 1.
XmNsliderVisual
Specifies the color of the slider visual. This resource can take the following values:
XmBACKGROUND_COLOR
Specifies that the slider visual is in the background color.
XmFOREGROUND_COLOR
Specifies that the slider visual is in the foreground color.
XmSHADOWED_BACKGROUND
Specifies that the slider visual is in the background color, with a shadow. This is the default for a regular slider.
XmTROUGH_COLOR
Specifies that the slider visual is in the trough color. This is the default when the slider is a thermometer.
XmNsnapBackMultiple
Specifies the distance over which the scrollbar slider snaps back to its original position when the user drags the mouse outside the ScrollBar edge. This distance is defined in terms of multiples of the width of the slider. For example, a multiple of 0 (zero) causes the slider to snap back as soon as the pointer moves out of the ScrollBar frame, a multiple of 1 causes the slider to snap back as soon as the pointer moves beyond 1 ScrollBar width of the ScrollBar edge. Whenever the slider snaps back, the ScrollBar dragCallback is called if there is one.
The default value is large enough to prevent unwanted snapBack activity if the mouse is moved within the boundaries of any reasonable screen. To reset the default, set this resource to a large value, such as 10000.
XmNtoBottomCallback
Specifies the list of callbacks that is called when the user takes an action that moves the slider to the end of the ScrollBar with the maximum value. The reason passed to the callback is XmCR_TO_BOTTOM.
XmNtoTopCallback
Specifies the list of callbacks that is called when the user takes an action that moves the slider to the end of the ScrollBar with the minimum value. The reason passed to the callback is XmCR_TO_TOP.
XmNtroughColor
Specifies the color of the slider trough. This color defaults to the color used for selections.
XmNvalue
Specifies the slider's position, between XmNminimum and (XmNmaximum - XmNsliderSize). The value is constrained to be within these inclusive bounds. The initial value of this resource is the larger of 0 (zero) and XmNminimum.
XmNvalueChangedCallback
Specifies the list of callbacks that is called when the slider is released after being dragged. These callbacks are also called in place of XmNincrementCallback, XmNdecrementCallback, XmNpageIncrementCallback, XmNpageDecrementCallback, XmNtoTopCallback, or XmNtoBottomCallback when one of these callback lists would normally be called but the value of the corresponding resource is NULL. The reason passed to the callback is XmCR_VALUE_CHANGED.

Información de Callback

Se pasa a cada callback un puntero a la siguiente estructura:

typedef struct
{
        int reason;
        XEvent * event;
        int value;
        int pixel;
} XmScrollBarCallbackStruct;
reason
Indica por qué se invocó el callback.
event
Punta a la XEvent que activó el callback.
value
Contiene el nuevo valor de la ubicación del deslizador.
pixel
Se utiliza solo para XmNtoTopCallback y XmNtoBottomCallback. Para las barras de desplazamiento horizontales, contiene la coordenada x de dónde ocurrió la selección del botón del ratón. Para las barras de desplazamiento verticales, contiene la coordenada y.

Rutinas de Acción

Las rutinas de acción de la barra de desplazamiento son

CancelDrag():
Si la pulsación de tecla ocurre durante el desplazamiento, cancela el desplazamiento y devuelve el deslizador a su ubicación anterior en la barra de desplazamiento; de lo contrario, y si el padre es un gestor, pasa el evento al padre.
IncrementDownOrRight(Down|Right):
Con un argumento de Down, o 0 (cero) para compatibilidad, mueve el deslizador hacia abajo un incremento. Con un argumento de Right, o 1 para compatibilidad, mueve el deslizador hacia la derecha un incremento. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o hacia abajo llama a los callbacks para XmNincrementCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o hacia abajo llama a los callbacks para XmNdecrementCallback.
callbacks para XmNdecrementCallback. El XmNvalueChangedCallback se llama si XmNincrementCallback o XmNdecrementCallback es NULL.
IncrementUpOrLeft(Up|Left):
Con un argumento de Up, o 0 (cero) para compatibilidad, mueve el control deslizante hacia arriba en un incremento. Con un argumento de Left, o 1 para compatibilidad, mueve el control deslizante hacia la izquierda en un incremento. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la izquierda o arriba llama a los callbacks para XmNdecrementCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la izquierda o arriba llama a los callbacks para XmNincrementCallback. El XmNvalueChangedCallback se llama si XmNincrementCallback o XmNdecrementCallback es NULL.
Moved():
Si el clic del botón ocurre dentro del control deslizante, los eventos de movimiento subsiguientes mueven el control deslizante a la posición del puntero y llaman a los callbacks para XmNdragCallback.
PageDownOrRight(Down|Right):
Con un argumento de Down, o 0 (cero) para compatibilidad, mueve el control deslizante hacia abajo en un incremento de página. Con un argumento de Right, o 1 para compatibilidad, mueve el control deslizante hacia la derecha en un incremento de página. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o abajo llama a los callbacks para XmNpageIncrementCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o abajo llama a los callbacks XmNpageDecrementCallback. El XmNvalueChangedCallback se llama si XmNpageIncrementCallback o XmNpageDecrementCallback es NULL.
PageUpOrLeft(Up|Left):
Con un argumento de Up, o 0 (cero) para compatibilidad, mueve el control deslizante hacia arriba en un incremento de página. Con un argumento de Left, o 1 para compatibilidad, mueve el control deslizante hacia la izquierda en un incremento de página. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la izquierda o arriba llama a los callbacks para XmNpageDecrementCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la izquierda o arriba llama a los callbacks XmNpageIncrementCallback. El XmNvalueChangedCallback se llama si XmNpageIncrementCallback o XmNpageDecrementCallback es NULL.
PrimitiveHelp():
Llama a los callbacks para XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a los callbacks de ayuda para el ancestro más cercano que los tenga.
PrimitiveNextTabGroup():
Se desplaza al primer elemento del siguiente grupo de pestañas. Si el grupo de pestañas actual es la última entrada en la lista de grupos de pestañas, vuelve al principio de la lista de grupos de pestañas.
PrimitiveParentActivate():
Si el padre es un gestor, pasa el evento al padre.
PrimitivePrevTabGroup():
Se desplaza al primer elemento del grupo de pestañas anterior. Si se llega al principio de la lista de grupos de pestañas, vuelve al final de la lista de grupos de pestañas.
Release():
Si el clic del botón ocurre dentro del control deslizante y la posición del control deslizante se cambia, se llaman los callbacks para XmNvalueChangedCallback.
Select():
En la flecha: Mueve el control deslizante un incremento en la dirección de la flecha. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o abajo llama a los callbacks para XmNincrementCallback, y el movimiento hacia la izquierda o arriba llama a los callbacks para XmNdecrementCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o abajo llama a los callbacks para XmNdecrementCallback, y el movimiento hacia la izquierda o arriba llama a los callbacks para XmNincrementCallback. El XmNvalueChangedCallback se llama si XmNincrementCallback o XmNdecrementCallback es NULL.
En la región de desplazamiento entre una flecha y el control deslizante: Mueve el control deslizante un incremento de página en la dirección de la flecha. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o abajo llama a los callbacks para XmNpageIncrementCallback, y el movimiento hacia la izquierda o arriba llama a los callbacks para XmNpageDecrementCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o abajo llama a los callbacks para XmNpageDecrementCallback, y el movimiento hacia la izquierda o arriba llama a los callbacks para XmNpageIncrementCallback. El XmNvalueChangedCallback se llama si XmNpageIncrementCallback o XmNpageDecrementCallback es NULL.
En el control deslizante: Activa el arrastre interactivo del control deslizante.
Si el botón se mantiene presionado en cualquiera de las flechas o en la región de desplazamiento durante más tiempo que el recurso XmNinitialDelay, el control deslizante se mueve nuevamente por el mismo incremento y se llaman los mismos callbacks. Después de que se ha utilizado el retraso inicial, el retraso de tiempo cambia al tiempo definido por el recurso XmNrepeatDelay.
TopOrBottom():
<Ctrl><Btn1Down> en una flecha o en la región de desplazamiento entre una flecha y el control deslizante mueve el control deslizante lo más lejos posible en la dirección de la flecha. Si XmNprocessingDirection es XmMAX_ON_RIGHT o XmMAX_ON_BOTTOM, el movimiento hacia la derecha o abajo llama a los callbacks para XmNtoBottomCallback, y el movimiento hacia la izquierda o arriba llama a los callbacks para XmNtoTopCallback. Si XmNprocessingDirection es XmMAX_ON_LEFT o XmMAX_ON_TOP, el movimiento hacia la derecha o abajo llama a los callbacks para XmNtoTopCallback, y el movimiento hacia la izquierda o arriba llama a los callbacks para XmNtoBottomCallback. El XmNvalueChangedCallback se llama si XmNtoTopCallback o XmNtoBottomCallback es NULL. Presionar <Key><osfBeginLine> o <Key><osfBeginData> mueve el control deslizante al valor mínimo e invoca XmNtoTopCallback. Presionar <Key><osfEndLine> o <Key><osfEndData> mueve el control deslizante al valor máximo e invoca XmNtoBottomCallback.
