DESCRIPCIÓN

La biblioteca de programación de aplicaciones para la Extensión X11 de Doble Buffer, Multibuffer y Estéreo contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con un display que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede configurar con XSetExtensionErrorHandler y funciona igual que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de multibuffer/estéreo está disponible en el display dado. Si la extensión existe, el valor del primer código de evento (que debe sumarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe sumarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión mayor y menor de la extensión. El valor de retorno es cero si ocurre un error o distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con la acción de actualización y la pista de actualización dadas y se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus ventanas apropiadas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers con la misma ventana o se generará un error Match.

XmbufGetWindowAttributes obtiene los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita a la pista de actualización.

XmbufGetBufferAttributes obtiene los atributos del buffer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del buffer indicado. Actualmente, esto se limita a la event_mask.

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. Los números de conjuntos de visual y profundidades se devuelven en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen los diversos visuales y profundidades que se pueden usar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece de acuerdo con nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los IDs de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en este display.

NAME

Xmbuf - Multi-Buffering extension

SYNTAX

```c

    #include <X11/extensions/Xmuu.h>
```

DESCRIPTION

The multi-buffering extension provides a mechanism for applications to use multiple drawing buffers for a single window. This can be used for effects such as double buffering, stereo rendering, and animation.

The extension defines several functions for querying, initializing, and manipulating the multi-buffering capabilities of a window.

XInitMultibufferExtension initializes the multi-buffering extension for the given display. It returns True if the extension is available, and False otherwise.

XMultibufferQueryExtension queries the multi-buffering extension. It returns the major opcode for the extension if it is available, and -1 otherwise.

XMultibufferGetWindowAttributes retrieves the multi-buffering attributes of a window.

XMultibufferSetWindowAttributes sets the multi-buffering attributes of a window.

XMultibufferSwapWindow swaps the contents of the specified buffers for a window.

XMultibufferClearWindow clears the specified buffers for a window.

XMultibufferCopyWindow copies the contents of one buffer to another within a window.

XMultibufferGetBufferAttributes retrieves the buffer attributes for a window.

XMultibufferGetErrorAttributes retrieves the error attributes for a window.

XMultibufferGetNumberEvents retrieves the number of events supported by the multi-buffering extension.

XMultibufferGetNumberErrors retrieves the number of errors supported by the multi-buffering extension.
