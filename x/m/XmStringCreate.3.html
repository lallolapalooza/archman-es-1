NOMBRE

XmStringCreate — Una función de cadena compuesta que crea una cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringCreate(
char *text,
char *tag);

DESCRIPCIÓN

XmStringCreate crea una cadena compuesta con dos componentes: texto y una etiqueta de lista de fuentes. La función asignará espacio para contener la cadena compuesta devuelta. Cuando la aplicación ya no necesite la cadena compuesta devuelta, la aplicación debe llamar a XmStringFree.

text
Especifica una cadena terminada en NULL para que se use como componente de texto de la cadena compuesta.
tag
Especifica el componente de etiqueta que se asociará con el texto dado. El valor XmFONTLIST_DEFAULT_TAG identifica un segmento de texto localizado.

RETORNO

Devuelve una nueva cadena compuesta.
