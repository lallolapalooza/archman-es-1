NOMBRE

XML::Handler::Subs - una clase base de manejador PerlSAX para llamar a subs definidas por el usuario

SINOPSIS

use XML::Handler::Subs;
package MyHandlers;
use vars qw{ @ISA };
sub s_NOMBRE { my ($self, $element) = @_ };
sub e_NOMBRE { my ($self, $element) = @_ };
$self->{Nombres};    # un array de nombres
$self->{Nodos};    # un array de nodos $element
$handler = MyHandlers->new();
$self->in_element($name);
$self->within_element($name);

DESCRIPCIÓN

"XML::Handler::Subs" es una clase base para manejadores PerlSAX. "XML::Handler::Subs" se hereda para implementar un comportamiento completo y para añadir manejo específico de elementos.

Cada vez que un elemento comienza, se llama a un método con ese nombre prefijado con `s_' con el elemento a procesar. Cada vez que un elemento termina, se llama a un método con ese nombre prefijado con `e_'. Cualquier carácter especial en el nombre del elemento se reemplaza por guiones bajos.

Heredar de XML::Handler::Subs de esta manera es similar al estilo Subs de XML::Parser.

XML::Handler::Subs mantiene una pila de nombres de elementos, `"$self-"{Nombres}', y una pila de nodos de elementos, `"$self-"{Nodos}>', que pueden ser utilizados por las subclases. El elemento actual se empuja en las pilas antes de llamar a un método de inicio con nombre de elemento y se saca de las pilas después de llamar al método de fin con nombre de elemento. Las llamadas a `in_element()' y `within_element()' utilizan estas pilas.

Si la subclase implementa `start_document()', `end_document()', `start_element()' y `end_element()', asegúrate de usar `"SUPER::"' para llamar también a los métodos de la superclase. Ver perlobj(1) para detalles sobre SUPER::. `SUPER::start_element()' y `SUPER::end_element()' devuelven 1 si se llama a un método con nombre de elemento, devuelven 0 si no se llamó a ningún método.

XML::Handler::Subs no implementa ningún otro manejador PerlSAX.

XML::Handler::Subs soporta los siguientes métodos:

new( OPCIONES )
Un método `new()' básico. `new()' toma una lista de pares clave, valor o un hash y crea y devuelve un hash con esas opciones; el hash es bendecido en la subclase.
in_element($name)
Devuelve verdadero si `$name' es igual al nombre del elemento más interno actualmente abierto.
within_element($name)
Devuelve el número de veces que `$name' aparece en Nombres.
