XmClipboardEndCopy(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmClipboardEndCopy(llamada a biblioteca) XmClipboardEndCopy(llamada a biblioteca)

NOMBRE

XmClipboardEndCopy — Una función del portapapeles que completa la copia de datos al portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardEndCopy (display, window, item_id)
        Display * display;
        Window  window;
        long    item_id;
(void)

DESCRIPCIÓN

XmClipboardEndCopy bloquea el portapapeles para evitar el acceso por parte de otras aplicaciones, coloca los datos en la estructura de datos del portapapeles y desbloquea el portapapeles. Los elementos de datos copiados al portapapeles mediante XmClipboardCopy no se introducen realmente en la estructura de datos del portapapeles hasta la llamada a XmClipboardEndCopy.

Esta función también libera el almacenamiento temporal que fue asignado por XmClipboardStartCopy, que debe ser llamado antes de XmClipboardEndCopy. Esta última función no debe ser llamada si se ha llamado a XmClipboardCancelCopy.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de la ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de la ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada función del portapapeles que llame.
item_id
Especifica el número asignado a este elemento de datos, que fue devuelto por una llamada anterior a XmClipboardStartCopy.

RETORNO

XmClipboardSuccess
La función se ejecutó correctamente.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función nuevamente con los mismos parámetros hasta que el bloqueo desaparezca. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o renunciar a la operación.
XmClipboardFail
La función falló porque no se llamó a XmClipboardStartCopy.

RELACIONADOS

XmClipboardCancelCopy(3), XmClipboardCopy(3) y XmClipboardStartCopy(3).
