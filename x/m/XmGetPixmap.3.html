XmGetPixmap(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmGetPixmap(llamada a biblioteca) XmGetPixmap(llamada a biblioteca)

NOMBRE

XmGetPixmap — Una función de caché de pixmaps que genera un pixmap, lo almacena en una caché de pixmaps y devuelve el pixmap

SINOPSIS

#include <Xm/Xm.h>
Pixmap XmGetPixmap(
Screen *screen,
char *image_name,
Pixel foreground,
Pixel background);

DESCRIPCIÓN

XmGetPixmap utiliza los datos de los parámetros para realizar una búsqueda en la caché de pixmaps para ver si ya se ha generado un pixmap que coincida con los datos. Si se encuentra uno, se incrementa un contador de referencias y se devuelve el pixmap. Las aplicaciones deben usar XmDestroyPixmap cuando el pixmap ya no sea necesario.

screen
Especifica la pantalla de visualización en la que se dibujará el pixmap. La profundidad del pixmap es la profundidad predeterminada para esta pantalla.
image_name
Especifica el nombre de la imagen que se utilizará para generar el pixmap
foreground
Combina la imagen con el color de primer plano (foreground) para crear el pixmap si la imagen referenciada es una imagen de bits por píxel.
background
Combina la imagen con el color de fondo (background) para crear el pixmap si la imagen referenciada es una imagen de bits por píxel.

Si no se encuentra un pixmap, se utiliza image_name para realizar una búsqueda en la caché de imágenes. Si se encuentra una imagen, se utiliza para generar el pixmap, que luego se almacena en caché y se devuelve.

Si no se encuentra una imagen, el image_name se utiliza como nombre de archivo, y se realiza una búsqueda de un archivo de mapa de bits X10 o X11. Si se encuentra, el archivo se lee, se convierte en una imagen y se almacena en caché en la caché de imágenes. La imagen se utiliza luego para generar un pixmap, que se almacena en caché y se devuelve.

Si image_name tiene una barra inclinada inicial (/), especifica una ruta completa, y XmGetPixmap abre el archivo según lo especificado. De lo contrario, image_name especifica un nombre de archivo. En este caso, XmGetPixmap busca el archivo a lo largo de una ruta de búsqueda especificada por la variable de entorno XBMLANGPATH o por una ruta de búsqueda predeterminada, que varía dependiendo de si la variable de entorno XAPPLRESDIR está establecida o no. La ruta de búsqueda predeterminada contiene muchos directorios. Por lo tanto, XmGetPixmap necesitará un tiempo relativamente largo para buscar en todos estos directorios pixmaps y mapas de bits. Las aplicaciones que utilizan muchos pixmaps y mapas de bits probablemente se ejecutarán más rápido si XBMLANGPATH se establece en una lista corta de directorios. Además de los archivos de mapa de bits de X (XBM), Motif también admite los formatos de archivo XPM (X Pixmap) y, a partir de la versión 2.3, los formatos de imagen JPEG y PNG. (Tenga en cuenta que el soporte de formatos de imagen JPEG y PNG es una característica opcional de Motif; para verificar si la versión actual admite los formatos de imagen PNG y JPEG, se deben verificar las macros PNG_SUPPORT y JPEG_SUPPORT respectivamente). XBMLANGPATH especifica la ruta para archivos XBM, XPM, PNG y JPEG. Consulte la página de referencia de XmGetPixmapByDepth para obtener más detalles.

La variable de entorno XBMLANGPATH especifica una ruta de búsqueda para archivos de mapa de bits de X. Puede contener el campo de sustitución %B, donde el argumento image_name de XmGetPixmap se sustituye por %B. También puede contener los campos de sustitución aceptados por XtResolvePathname. El campo de sustitución %T siempre se mapea a bitmaps, y %S siempre se mapea a NULL.

Si XBMLANGPATH no está establecida pero la variable de entorno XAPPLRESDIR está establecida, se buscan las siguientes rutas:

•
%B
•
$XAPPLRESDIR/%L/bitmaps/%N/%B
•
$XAPPLRESDIR/%l_%t/bitmaps/%N/%B
•
$XAPPLRESDIR/%l/bitmaps/%N/%B
•
$XAPPLRESDIR/bitmaps/%N/%B
•
$XAPPLRESDIR/%L/bitmaps/%B
•
$XAPPLRESDIR/%l_%t/bitmaps/%B
•
$XAPPLRESDIR/%l/bitmaps/%B
•
$XAPPLRESDIR/bitmaps/%B
•
$HOME/bitmaps/%B
•
$HOME/%B
•
/usr/lib/X11/%L/bitmaps/%N/%B
•
/usr/lib/X11/%l_%t/bitmaps/%N/%B
•
/usr/lib/X11/%l/bitmaps/%N/%B
•
/usr/lib/X11/bitmaps/%N/%B
•
/usr/lib/X11/%L/bitmaps/%B
•
/usr/lib/X11/%l_%t/bitmaps/%B
•
/usr/lib/X11/%l/bitmaps/%B
•
/usr/lib/X11/bitmaps/%B
•
/usr/include/X11/bitmaps/%B

Si no están establecidas ni XBMLANGPATH ni XAPPLRESDIR, se buscan las siguientes rutas:

•
%B
•
$HOME/%L/bitmaps/%N/%B

$HOME/%l_%t/bitmaps/%N/%B
•
$HOME/%l/bitmaps/%N/%B
•
$HOME/bitmaps/%N/%B
•
$HOME/%L/bitmaps/%B
•
$HOME/%l_%t/bitmaps/%B
•
$HOME/%l/bitmaps/%B
•
$HOME/bitmaps/%B
•

•
/usr/lib/X11/%L/bitmaps/%N/%B
•
/usr/lib/X11/%l_%t/bitmaps/%N/%B
•
/usr/lib/X11/%l/bitmaps/%N/%B
•
/usr/lib/X11/bitmaps/%N/%B
•
/usr/lib/X11/%L/bitmaps/%B
•
/usr/lib/X11/%l_%t/bitmaps/%B
•
/usr/lib/X11/%l/bitmaps/%B
•
/usr/lib/X11/bitmaps/%B
•
/usr/include/X11/bitmaps/%B

Estas rutas son valores predeterminados que los proveedores pueden cambiar. Por ejemplo, un proveedor puede usar directorios diferentes para /usr/lib/X11 y /usr/include/X11.

Las siguientes sustituciones se utilizan en estas rutas:

%B
El nombre de la imagen, del argumento image_name
%N
El nombre de la clase de la aplicación
%L
La cadena de idioma de la pantalla. Esta cadena está influenciada por XtSetLanguageProc. La cadena predeterminada se determina llamando a setlocale(LC_ALL, NULL).
%l_%t
El componente de idioma y territorio de la cadena de idioma de la pantalla
%l
El componente de idioma de la cadena de idioma de la pantalla

El contenido del archivo debe cumplir las reglas para los archivos de mapa de bits X11. En otras palabras, Motif puede leer cualquier archivo de mapa de bits compatible con X11.

RETORNO

Devuelve un pixmap cuando tiene éxito; devuelve XmUNSPECIFIED_PIXMAP si la imagen correspondiente a image_name no se puede encontrar.

RELACIONADO

XmDestroyPixmap(3), XmGetPixmapByDepth(3), XmInstallImage(3), y XmUninstallImage(3).
