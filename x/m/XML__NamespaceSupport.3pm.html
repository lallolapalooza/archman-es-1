XML::NamespaceSupport(3) Documentación de Perl contribuida por el usuario XML::NamespaceSupport(3)

NOMBRE

XML::NamespaceSupport - Un procesador genérico simple de espacios de nombres

VERSIÓN

versión 1.12

SINOPSIS

use XML::NamespaceSupport;
my $nsup = XML::NamespaceSupport->new;
# añadir un nuevo contexto vacío
$nsup->push_context;
# declarar algunos prefijos
$nsup->declare_prefix($prefijo1, $uri1);
$nsup->declare_prefix($prefijo2, $uri2);
# lo mismo más corto
$nsup->declare_prefixes($prefijo1 => $uri1, $prefijo2 => $uri2);
# obtener un prefijo único para una URI (aleatoriamente)
$prefijo = $nsup->get_prefix($uri);
# obtener todos los prefijos para una URI (probablemente mejor)
@prefijos = $nsup->get_prefixes($uri);
# obtener todos los prefijos en ámbito
@prefijos = $nsup->get_prefixes();
# obtener todos los prefijos que fueron declarados para el ámbito actual
@prefijos = $nsup->get_declared_prefixes;
# obtener una URI para un prefijo dado
$uri = $nsup->get_uri($prefijo);
# obtener información de un qname (forma java, es un poco raro)
($ns_uri, $nombre_local, $qname) = $nsup->process_name($qname, $es_attr);
# lo mismo, más al estilo Perl
($ns_uri, $prefijo, $nombre_local) = $nsup->process_element_name($qname);
($ns_uri, $prefijo, $nombre_local) = $nsup->process_attribute_name($qname);
# eliminar el contexto actual
$nsup->pop_context;
# restablecer el objeto para su reutilización en otro documento
$nsup->reset;
# un simple ayudante para procesar Notación Clarkiana
my ($ns, $lname) = $nsup->parse_jclark_notation('{http://foo}bar');
# o (dado que no le importa el objeto
my ($ns, $lname) = XML::NamespaceSupport->parse_jclark_notation('{http://foo}bar');

DESCRIPCIÓN

Este módulo ofrece una forma sencilla de procesar nombres XML con espacios de nombres (unames) desde dentro de cualquier aplicación que pueda necesitarlos. También ayuda a mantener un mapa de prefijo a URI de espacio de nombres y proporciona una serie de verificaciones básicas.

El modelo para este módulo es la clase NamespaceSupport de SAX2, que se puede leer en http://www.saxproject.org/namespaces.html. Añade algunas perlisaciones donde pensamos que eran apropiadas.

NOMBRE

XML::NamespaceSupport - una clase simple de soporte de espacios de nombres genérica

MÉTODOS

  • XML::NamespaceSupport->new(\%opciones)

    Un constructor simple.

    Las opciones son "xmlns", "fatal_errors" y "auto_prefix"

    Si "xmlns" está activado (está desactivado por defecto) se añade el mapeo del prefijo xmlns a la URI definida para él en DOM nivel 2 a la lista de mapeos predefinidos (que normalmente solo contiene el mapeo del prefijo xml).

    Si "fatal_errors" está desactivado (está activado por defecto) una serie de errores de validez simplemente se marcarán como fallos, en lugar de lanzar un die().

    Si "auto_prefix" está activado (está desactivado por defecto) cuando se proporciona un prefijo de "undef" a "declare_prefix" generará un prefijo aleatorio mapeado a ese espacio de nombres. De lo contrario, un prefijo undef provocará una advertencia (probablemente sepa lo que está haciendo si activa esta opción).

    Si "xmlns_11" está desactivado, se vuelve ilegal desdeclarar prefijos de espacio de nombres. Está activado por defecto. Este comportamiento es compatible con Namespaces in XML 1.1, desactivarlo le devuelve a la versión 1.0.

  • $nsup->push_context

    Añade un nuevo contexto vacío a la pila. Puede poblarlo entonces con nuevos prefijos definidos en este nivel.

  • $nsup->pop_context

    Elimina el contexto superior de la pila y vuelve al anterior. Lanzará un die() si intenta extraer más de lo que ha introducido.

  • $nsup->declare_prefix($prefijo, $uri)

    Declara un mapeo de $prefijo a $uri, en el nivel actual.

    Tenga en cuenta que con "auto_prefix" activado, si declara un mapeo de prefijo en el que $prefijo es undef(), obtendrá un prefijo automático seleccionado para usted. Si está desactivado obtendrá una advertencia.

    Esto es útil cuando se trata con código que no ha conservado los prefijos y necesita volver a serializar los nodos. También significa que si desea establecer el espacio de nombres predeterminado (es decir, con un prefijo vacío) debe usar la cadena vacía en lugar de undef. Este comportamiento es coherente con la especificación SAX 2.0.

  • $nsup->declare_prefixes(%prefijos2uris)

    Declara un mapeo de varios prefijos a URIs, en el nivel actual.

  • $nsup->get_prefix($uri)

    Devuelve un prefijo dado una URI. Tenga en cuenta que como varios prefijos pueden mapearse a la misma URI, devuelve uno arbitrario. Devolverá undef en caso de fallo.

  • $nsup->get_prefixes($uri)

    Devuelve una lista de prefijos dada una URI. Devolverá todos los prefijos si la uri es undef.

  • $nsup->get_declared_prefixes

    Devuelve una lista de todos los prefijos que han sido declarados dentro de este contexto, es decir, aquellos que fueron declarados en el último elemento, no aquellos que fueron declarados arriba y simplemente están en ámbito.

    Tenga en cuenta que al menos un contexto debe añadirse a la pila mediante "push_context" antes de que este método pueda ser llamado.

  • $nsup->get_uri($prefijo)

    Devuelve una URI para un prefijo dado. Devuelve undef en caso de fallo.

  • $nsup->process_name($qname, $es_attr)

    Dado un nombre calificado y un booleano que indica si se trata de un atributo u otro tipo de nombre (estos se ven afectados de manera diferente por los espacios de nombres predeterminados), devuelve una tupla de URI de espacio de nombres, nombre local, nombre calificado. Sé que esa es una lista bastante anormal para devolver, pero es así por compatibilidad con la especificación Java. Vea abajo alternativas más al estilo Perl.

    Si el prefijo no está declarado, o si el nombre no es válido, lanzará un die() o devolverá undef dependiendo de la configuración actual de "fatal_errors".

  • $nsup->undeclare_prefix($prefijo);

    Elimina un prefijo de espacio de nombres del contexto actual. Esta función puede usarse en end_prefix_mapping de SAX cuando hay temor de que una declaración de espacio de nombres pueda estar disponible fuera de su ámbito (lo que normalmente no debería ocurrir, pero nunca se sabe ;) ). Esto puede ser necesario para soportar correctamente Namespace 1.1.

  • $nsup->process_element_name($qname)

    Dado un nombre calificado, devuelve una tupla de URI de espacio de nombres, prefijo y nombre local. Este método se aplica a los nombres de elementos.

    Si el prefijo no está declarado, o si el nombre no es válido, lanzará un die() o devolverá undef dependiendo de la configuración actual de "fatal_errors".

  • $nsup->process_attribute_name($qname)

    Dado un nombre calificado, devuelve una tupla de URI de espacio de nombres, prefijo y nombre local. Este método se aplica a los nombres de atributos.

    Si el prefijo no está declarado, o si el nombre no es válido, lanzará un die() o devolverá undef dependiendo de la configuración actual de "fatal_errors".

  • $nsup->reset

    Restablece el objeto para que pueda ser reutilizado en otro documento.

Todos los métodos de la interfaz tienen un alias que es el nombre utilizado en la especificación original de Java. Puede usar cualquiera de los dos nombres indistintamente. Aquí está el mapeo:

---------------------------------------------------

popContext                pop_context
declarePrefix             declare_prefix
declarePrefixes           declare_prefixes
getPrefix                 get_prefix
getPrefixes               get_prefixes
getDeclaredPrefixes       get_declared_prefixes
getURI                    get_uri

XML::NamespaceSupport(3pm)

NAME

XML::NamespaceSupport - Perl extension for handling XML namespaces

VERSION

1.12

SYNOPSIS

 use XML::NamespaceSupport;

 my $ns = XML::NamespaceSupport->new();

 # Push a new namespace context
 $ns->push_context(prefix, uri, localname);

 # Pop a namespace context
 $ns->pop_context();

 # Get the URI for a prefix
 my $uri = $ns->get_uri($prefix);

 # Get prefixes for a URI
 my @prefixes = $ns->get_prefix($uri);

 # Declare a namespace
 $ns->declare_prefix($prefix, $uri);

 # Undeclare a namespace
 $ns->undeclare_prefix($prefix);

DESCRIPTION

This module provides a simple way to handle XML namespaces. It allows you to push and pop namespace contexts, get URIs for prefixes, and get prefixes for URIs.

NAME

XML::NamespaceSupport

METHODS

new
Creates a new XML::NamespaceSupport object.
push_context(prefix, uri, localname)
Pushes a new namespace context onto the stack.

prefix is the namespace prefix, uri is the namespace URI, and localname is the local name of the element or attribute.

pop_context
Pops the current namespace context from the stack.
get_uri(prefix)
Returns the URI associated with the given prefix.
get_prefix(uri)
Returns a list of prefixes associated with the given URI.
declare_prefix(prefix, uri)
Declares a namespace binding. This is equivalent to adding an xmlns:prefix="uri" attribute.
undeclare_prefix(prefix)
Undeclares a namespace binding. This is equivalent to removing an xmlns:prefix="uri" attribute.

The following methods are provided for convenience and are mostly used by SAX drivers:

processName               process_name
processElementName        process_element_name
processAttributeName      process_attribute_name
parseJClarkNotation       parse_jclark_notation
undeclarePrefix           undeclare_prefix

VARIABLES

Two global variables are made available to you. They used to be constants but simple scalars are easier to use in a number of contexts. They are not exported but can easily be accessed from any package, or copied into it.

  • $NS_XMLNS

    The namespace for xmlns prefixes, http://www.w3.org/2000/xmlns/.

  • $NS_XML

    The namespace for xml prefixes, http://www.w3.org/XML/1998/namespace.
