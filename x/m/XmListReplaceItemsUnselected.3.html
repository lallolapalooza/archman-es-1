NOMBRE

XmListReplaceItemsUnselected — Una función de Lista que reemplaza elementos en una lista

SINOPSIS

#include <Xm/List.h>
void XmListReplaceItemsUnselected(
Widget widget,
XmString *old_items,
int item_count,
XmString *new_items);

DESCRIPCIÓN

XmListReplaceItemsUnselected reemplaza cada elemento especificado en la lista con un nuevo elemento correspondiente. Los elementos de reemplazo permanecen sin seleccionar, incluso si actualmente aparecen en la lista XmNselectedItems.

widget
Especifica el ID del widget de Lista en el que se reemplazarán los elementos.
old_items
Especifica un puntero a los elementos de la lista que se reemplazarán.
item_count
Especifica el número de elementos en old_items y new_items. Este número debe ser no negativo.
new_items
Especifica un puntero a los elementos de reemplazo. Cada ocurrencia de cada elemento de old_items se reemplaza con el elemento correspondiente de new_items. Es decir, el primer elemento de old_items se reemplaza con el primer elemento de new_items. El segundo elemento de old_items se reemplaza con el segundo elemento de new_items, y así sucesivamente hasta alcanzar item_count. Si un elemento en old_items no existe en la lista, se omite la entrada correspondiente en new_items.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).

RELACIONADO

XmList(3).
