NOMBRE

XmClipboardRetrieve — Una función del portapapeles que recupera un elemento de datos del portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardRetrieve (display, window, format_name,
        buffer, length, num_bytes, private_id)
        Display * display;
        Window  window;
        char    * format_name;
        XtPointer       buffer;
        unsigned long   length;
        unsigned long   * num_bytes;
        long    * private_id;
(void)

DESCRIPCIÓN

XmClipboardRetrieve recupera el elemento de datos actual del almacenamiento del portapapeles. Devuelve una advertencia si el portapapeles está bloqueado, si no hay datos en el portapapeles o si los datos necesitan ser truncados porque la longitud del búfer es insuficiente.

Entre una llamada a XmClipboardStartRetrieve y una llamada a XmClipboardEndRetrieve, varias llamadas a XmClipboardRetrieve con el mismo nombre de formato dan como resultado la copia incremental de datos desde el portapapeles hasta que se hayan copiado todos los datos en ese formato.

El valor de retorno XmClipboardTruncate de las llamadas a XmClipboardRetrieve indica que queda más datos por copiar en el formato dado. Se recomienda que cualquier llamada a las funciones Inquire que la aplicación necesite para efectuar la copia desde el portapapeles se realice entre la llamada a XmClipboardStartRetrieve y la primera llamada a XmClipboardRetrieve. De esta manera, la aplicación no necesita llamar a XmClipboardLock y XmClipboardUnlock.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llame.
format_name
Especifica el nombre de un formato en el que se almacenan los datos en el portapapeles.
buffer
Especifica el búfer al que la aplicación desea que el portapapeles copie los datos. La función asigna espacio para contener los datos devueltos en el búfer. La aplicación es responsable de gestionar este espacio asignado. La aplicación puede recuperar este espacio asignado llamando a XtFree.
length
Especifica la longitud del búfer de la aplicación.
num_bytes
Especifica el número de bytes de datos copiados en el búfer de la aplicación.
private_id
Especifica los datos privados almacenados con el elemento de datos por la aplicación que colocó el elemento de datos en el portapapeles. Si la aplicación no almacenó datos privados con el elemento de datos, este argumento devuelve 0 (cero).

RETORNO

XmClipboardSuccess
La función se realizó con éxito.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función nuevamente con los mismos parámetros hasta que el bloqueo desaparezca. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentándolo o abandonar la operación.
XmClipboardTruncate
Los datos devueltos están truncados porque el usuario no proporcionó un búfer lo suficientemente grande para contener los datos.
XmClipboardNoData
La función no pudo encontrar datos en el portapapeles correspondientes al formato solicitado. Esto podría ocurrir porque el portapapeles está vacío; hay datos en el portapapeles pero no en el formato solicitado; o los datos en el formato solicitado se pasaron por nombre y ya no están disponibles.

RELACIONADOS

XmClipboardEndRetrieve(3), XmClipboardLock(3), XmClipboardStartCopy(3), XmClipboardStartRetrieve(3), y XmClipboardUnlock(3).
