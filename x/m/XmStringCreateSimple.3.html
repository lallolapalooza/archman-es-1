NOMBRE

XmStringCreateSimple — Función de cadena compuesta que crea una cadena compuesta en el entorno lingüístico de un widget

SINOPSIS

#include <Xm/Xm.h>
XmString XmStringCreateSimple(
char * texto);

DESCRIPCIÓN

XmStringCreateSimple crea una cadena compuesta con un componente de texto y una etiqueta de conjunto de caracteres. Obtiene el conjunto de caracteres del entorno lingüístico actual.

La rutina intenta obtener un conjunto de caracteres del valor de la variable de entorno LANG. Si esto no produce un conjunto de caracteres válido, la rutina utiliza un valor predeterminado específico del proveedor. Si el proveedor no ha especificado un valor diferente, este valor predeterminado es ISO8859-1.

La función asignará espacio para contener la cadena compuesta devuelta. La aplicación es responsable de administrar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmStringFree.

NOTA: Esta rutina es obsoleta y existe por compatibilidad con versiones anteriores. Ha sido reemplazada por XmStringCreateLocalized.

texto
Especifica una cadena terminada en NULL que se utilizará como componente de texto de la cadena compuesta.

RETORNO

Devuelve una nueva cadena compuesta.

RELACIONADO

XmStringCreate(3) y XmStringCreateLocalized(3).
