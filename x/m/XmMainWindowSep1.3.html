NOMBRE

XmMainWindowSep1 — Función de MainWindow que devuelve el ID del widget del primer Separador

SINOPSIS

#include <Xm/MainW.h>
Widget XmMainWindowSep1(
Widget widget);

DESCRIPCIÓN

XmMainWindowSep1 devuelve el ID del widget del primer Separador en el MainWindow. El primer Separador se encuentra entre la MenuBar y el widget de Comando. Este Separador solo es visible cuando XmNshowSeparator es True.

NOTA: XmMainWindowSep1 es obsoleto y existe por compatibilidad con versiones anteriores. Use XtNameToWidget en su lugar. Pase una variable MainWindow como primer argumento a XtNameToWidget y pase Separator1 como segundo argumento.

widget
Especifica el ID del widget MainWindow

Para una definición completa de MainWindow y sus recursos asociados, consulte XmMainWindow(3).

RETORNO

Devuelve el ID del widget del primer Separador.

RELACIONADO

XmMainWindow(3).
