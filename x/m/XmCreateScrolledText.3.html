NOMBRE

XmCreateScrolledText — La función de conveniencia de creación de Text ScrolledText

SINOPSIS

#include <Xm/Text.h>
Widget XmCreateScrolledText(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateScrolledText crea una instancia de un widget Text que está contenido dentro de una ScrolledWindow. La ScrolledWindow padre se crea gestionada. Todos los widgets de subárea de ScrolledWindow son creados automáticamente por esta función. El ID devuelto por esta función es el del widget Text (no el de la ScrolledWindow). Utilice este ID de widget para todas las operaciones en el widget Text. Utilice el ID del padre del widget Text para todas las operaciones en la ScrolledWindow. Para obtener el ID del widget ScrolledWindow asociado con el widget Text, utilice la función de Intrínsecos de Xt XtParent. El nombre de la ScrolledWindow creada por esta función se forma concatenando las letras SW al final del name especificado en la lista de parámetros.

El widget Text tiene por defecto edición de texto de una sola línea; por lo tanto, no se muestran barras de desplazamiento. El recurso Text XmNeditMode debe establecerse en XmMULTI_LINE_EDIT para mostrar las barras de desplazamiento. Los resultados de colocar un widget Text dentro de una ScrolledWindow cuando XmNeditMode de Text es XmSINGLE_LINE_EDIT no están definidos.

Todos los argumentos para el widget Text o ScrolledWindow pueden especificarse en el momento de la creación con esta función. Los cambios en la posición y tamaño iniciales se envían solo al widget ScrolledWindow. Otros recursos se envían al widget Text o ScrolledWindow según corresponda. Tenga en cuenta que el resultado de proporcionar el recurso XmNdestroyCallback en la lista de argumentos de creación (arglist) no está especificado. La aplicación debe usar la función XtAddCallback para agregar callbacks al widget apropiado (Text o ScrolledWindow) después de crearlo.

Esta función fuerza los siguientes valores iniciales para los recursos de ScrolledWindow:

•
XmNscrollingPolicy se establece en XmAPPLICATION_DEFINED.
•
XmNvisualPolicy se establece en XmVARIABLE.
•
XmNscrollBarDisplayPolicy se establece en XmSTATIC.
•
XmNshadowThickness se establece en 0 (cero).
parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
arglist
Especifica la lista de argumentos.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Para una definición completa de Text y sus recursos asociados, consulte XmText(3).

RETORNO

Devuelve el ID del widget Text.

RELACIONADO

XmScrolledWindow(3) y XmText(3).
