NOMBRE

XmVaCreateSimpleRadioBox — Función de conveniencia para la creación de un widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleRadioBox(
Widget parent,
String name,
int button_set,
XtCallbackProc callback);

DESCRIPCIÓN

XmVaCreateSimpleRadioBox crea una instancia de un widget RowColumn de tipo XmWORK_AREA y devuelve el ID del widget asociado. Esta rutina utiliza la convención de llamada de lista de argumentos de longitud variable (varargs) de ANSI C.

Esta rutina crea un RadioBox y sus hijos ToggleButtonGadget. El nombre de cada botón es button_n, donde n es un entero desde 0 (cero) hasta el número de botones en el menú menos 1.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
button_set
Especifica qué botón está inicialmente seleccionado. El valor es el entero n en el nombre del botón button_n.
callback
Especifica un procedimiento de devolución de llamada que se llamará cuando el valor de un botón cambie. Esta función de devolución de llamada se agrega a cada botón después de su creación como XmNvalueChangedCallback del botón. La función de devolución de llamada se llama cuando cambia el valor de un botón, y el número de botón se devuelve en el campo client_data.

La porción variable de la lista de argumentos consta de grupos de argumentos. El primer argumento en cada grupo es una constante o una cadena y determina qué argumentos siguen en ese grupo. El último argumento de la lista debe ser NULL. A continuación se presentan los primeros argumentos posibles en cada grupo de varargs:

XmVaRADIOBUTTON
Esto va seguido de cuatro argumentos adicionales. El conjunto especifica un botón en el RadioBox y algunos de sus valores de recurso. A continuación se presentan los cuatro argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString.
mnemonic
La mnemotecnia, de tipo KeySym. Se ignora en esta versión.
accelerator
El acelerador, de tipo String. Se ignora en esta versión.
accelerator_text
El texto del acelerador, de tipo XmString. Se ignora en esta versión.
resource_name
Esto va seguido de un argumento adicional, el valor del recurso, de tipo XtArgVal. El par especifica un recurso y su valor para el widget RowColumn.
XtVaTypedArg
Esto va seguido de cuatro argumentos adicionales. El conjunto especifica un recurso y su valor para el widget RowColumn. Se realiza una conversión de tipo de recurso si es necesario. A continuación se presentan los cuatro argumentos adicionales, en este orden:
name
El nombre del recurso, de tipo String
type
El tipo del valor del recurso proporcionado, de tipo String
value
El valor del recurso (o un puntero al valor del recurso, dependiendo del tipo y tamaño del valor), de tipo XtArgVal
size
El tamaño del valor del recurso en bytes, de tipo int
XtVaNestedList
Esto va seguido de un argumento adicional de tipo XtVarArgsList. Este argumento es una lista anidada de varargs devuelta por XtVaCreateArgsList.

Para obtener más información sobre listas de argumentos de longitud variable, consulte la documentación de X Toolkit Intrinsics.

Existe una serie de recursos específicamente para su uso con esta y otras rutinas de creación de menús simples. Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.
