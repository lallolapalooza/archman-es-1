NOMBRE

XmRepTypeGetRegistered — Función del gestor de tipos de representación que devuelve una copia de la lista de registro

SINOPSIS

#include <Xm/RepType.h>
XmRepTypeList XmRepTypeGetRegistered(void)

DESCRIPCIÓN

XmRepTypeGetRegistered recupera información sobre todos los tipos de representación que están registrados con el gestor de tipos de representación. La lista de registro es un array de estructuras, cada una de las cuales contiene información para una entrada de tipo de representación. El final de la lista de registro está marcado con una entrada de tipo de representación cuyo campo rep_type_name tiene un puntero NULL. Esta rutina asigna memoria para los datos devueltos. La aplicación debe liberar esta memoria usando XtFree.

La estructura de entrada del tipo de representación contiene la siguiente información:

typedef struct
{
        String  rep_type_name;
        String  *value_names;
        unsigned char   *values;
        unsigned char   num_values;
        Boolean reverse_installed;
        XmRepTypeId     rep_type_id;
} XmRepTypeEntryRec, *XmRepTypeList;
(void)
rep_type_name
El nombre del tipo de representación
value_names
Un array de nombres de valores del tipo de representación
values
Un array de valores numéricos del tipo de representación
num_values
El número de valores asociados con el tipo de representación
reverse_installed
Un indicador que señala si el convertidor inverso está instalado o no
rep_type_id
El número de identificación del tipo de representación

RETORNO

Devuelve un puntero a la lista de registro de tipos de representación.

RELACIONADO

XmRepTypeRegister(3) y XmRepTypeGetRecord(3).
