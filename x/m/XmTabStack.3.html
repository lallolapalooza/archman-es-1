NOMBRE

XmTabStack - Clase del widget TabStack

SINOPSIS

#include <Xm/TabStack.h>

DESCRIPCIÓN

El widget XmTabStack administra un grupo de widgets de tal manera que solo un widget del grupo es visible a la vez. Cada hijo está asociado con una "pestaña" que muestra una etiqueta de texto y/o un pixmap. Al seleccionar la "pestaña", el usuario determina interactivamente qué hijo se muestra. Este widget presenta un comportamiento similar al Control de Pestañas de Microsoft Windows(TM).

Las pestañas se pueden configurar para aparecer encima, debajo, a la derecha y a la izquierda de un área de trabajo, con el texto orientado en cualquiera de las cuatro direcciones cardinales.

TabStack permite al usuario seleccionar, ya sea por puntero o por recorrido del teclado, las pestañas. Cuando se selecciona una pestaña, esta cambia de apariencia para parecer que está elevada por encima de las demás. Cuando se selecciona una pestaña, se hace visible el hijo asociado a ella. Una pestaña está seleccionada en todo momento.

Clases

TabStack hereda comportamiento y recursos de las clases Core, Composite, Constraint, XmManager y XmBulletinBoard.

El puntero de clase es xmTabStackWidgetClass.

El nombre de la clase es XmTabStack.

CALLBACKS

XmNtabSelectedCallback

Este recurso define una lista de devoluciones de llamada que se invocan cada vez que el usuario selecciona una pestaña. El widget pasa un puntero a una estructura XmTabStackCallbackStruct a cada una de las devoluciones de llamada. Esta estructura tiene los siguientes campos:

    typedef struct {
        int reason;
        XEvent *event;
        int set;
        Widget tab;
    } XmTabStackCallbackStruct;

Los campos son:

reason
Indica la razón por la que se activó la devolución de llamada. Este campo solo puede tener el valor XmCR_TAB_SELECTED.
event
Un puntero al evento X que activó la devolución de llamada.
set
El número de índice (basado en cero) de la pestaña seleccionada.
tab
El widget de la pestaña que fue seleccionada.

WIDGETS

Los hijos del widget XmTabStack son las áreas de contenido de las pestañas. El widget TabStack administra la visibilidad de sus hijos. El primer hijo agregado al TabStack se considera la pestaña seleccionada actualmente. Los hijos del TabStack pueden ser cualquier widget.

Para crear un TabStack, primero cree el widget TabStack y luego cree los widgets hijos que se mostrarán en cada pestaña. Si desea que la primera pestaña sea la que está visible cuando se crea el TabStack, puede crearlo o establecer el recurso XmNலாமல் en el índice 0.

VIRTUAL KEY BINDINGS

El widget TabStack proporciona los siguientes enlaces de teclas virtuales:

NextTab
Selecciona la siguiente pestaña.
PrevTab
Selecciona la pestaña anterior.
GoToTab
Selecciona una pestaña específica.

NAME

XmTabStack - A widget that manages a stack of child widgets, displaying one child at a time.

SYNOPSIS

#include <Xm/TabStack.h>

A TabStack widget is created using the following functions:

Widget XmCreateTabStack(
    Widget parent,
    const char *name,
    Arg *arglist,
    Cardinal argcount
);
Widget XmCreateTabStackExt(
    Widget parent,
    const char *name,
    Arg *arglist,
    Cardinal argcount
);
Widget XmVaCreateTabStack(
    Widget parent,
    const char *name,
    ...
);
Widget XmVaCreateManagedTabStack(
    Widget parent,
    const char *name,
    ...
);

DESCRIPTION

The XmTabStack widget is a container widget that manages a stack of child widgets. It displays one child widget at a time, the currently selected child. The user can select different children by interacting with the widget, typically through a set of tabs or other selection mechanisms provided by the application.

Calback Information

A pointer to the following structure is passed to each callback:

typedef struct _XmTabStackCallbackStruct {
	int	reason;
	XEvent	*event;
	Widget	selected_child;
} XmTabStackCallbackStruct;
reason
Indicates why the callback was invoked. Valid callbacks reasons include:
XmCR_TAB_SELECTED
Indicates that a child has been made the selected widget.
event
Points to the XEvent that triggered the callback.
selected_child
Contains the widget ID of the selected child.

Additional Behavior

The XmTabStack has no additional behavior.
