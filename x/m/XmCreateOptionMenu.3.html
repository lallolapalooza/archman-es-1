Paquete: openmotif

XmCreateOptionMenu(llamada a biblioteca) XmCreateOptionMenu(llamada a biblioteca)

NOMBRE

XmCreateOptionMenu — Una función de conveniencia para la creación del widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmCreateOptionMenu(
Widget parent,
String name,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmCreateOptionMenu crea una instancia de un widget RowColumn de tipo XmMENU_OPTION y devuelve el ID del widget asociado.

Se proporciona como una función de conveniencia para crear un widget RowColumn configurado para operar como un OptionMenu y no está implementado como una clase de widget separada.

El widget OptionMenu es un gestor RowColumn especializado compuesto por una etiqueta, un área de selección y un único panel de menú desplegable. Cuando una aplicación crea un widget OptionMenu, proporciona la cadena de la etiqueta y el panel del menú desplegable. Para que la operación sea exitosa, debe haber un recurso XmNsubMenuId válido establecido cuando se llama a esta función. El LabelGadget y el área de selección (un CascadeButtonGadget) son creados por el OptionMenu.

El panel del menú desplegable del OptionMenu no debe contener ningún ToggleButton o ToggleButtonGadget. Los resultados de incluir CascadeButtons o CascadeButtonGadgets en el panel del menú desplegable del OptionMenu no están definidos.

Un OptionMenu se organiza con la etiqueta mostrada en un lado del widget y el área de selección en el otro lado cuando XmNorientation es XmHORIZONTAL. La disposición de la etiqueta con respecto al área de selección depende del recurso XmNlayoutDirection en la orientación horizontal. Si el valor es XmVERTICAL, la etiqueta está encima del área de selección. El área de selección tiene un doble propósito; muestra la etiqueta del último elemento seleccionado del panel del menú desplegable asociado y proporciona el medio para mostrar el panel del menú desplegable.

El OptionMenu típicamente no muestra ninguna visualización 3D alrededor de sí mismo o del LabelGadget interno. Por defecto, el CascadeButtonGadget interno tiene una sombra 3D visible. La aplicación puede cambiar esto obteniendo el ID del CascadeButtonGadget usando XmOptionButtonGadget y luego llamando a XtSetValues usando los recursos estándar relacionados con la visualización.

El panel del menú desplegable se muestra cuando el puntero del ratón se mueve sobre el área de selección y se presiona un botón del ratón definido por el padre RowColumn del OptionMenu. El panel del menú desplegable se muestra y se posiciona de modo que el último elemento seleccionado esté directamente sobre el área de selección. Luego se utiliza el ratón para activar el elemento de menú deseado. Cuando se suelta el botón del ratón, el elemento de menú activado se selecciona y la etiqueta dentro del área de selección se cambia para que coincida con la del elemento seleccionado. Por defecto, BSelect se utiliza para interactuar con un OptionMenu. El valor predeterminado se puede cambiar con el recurso RowColumn XmNmenuPost.

El OptionMenu también opera con el mecanismo de interfaz de teclado. Si la aplicación ha establecido una mnemotecnia con el OptionMenu, presionar <Alt> con la mnemotecnia hace que el panel del menú desplegable se muestre con la navegación habilitada. Las teclas de navegación estándar se pueden utilizar para moverse dentro del panel del menú. Presionar <Return> o escribir una mnemotecnia o un acelerador para uno de los elementos del menú selecciona ese elemento.

Una aplicación puede usar el recurso XmNmenuHistory para indicar qué elemento del panel del menú desplegable debe tratarse como la elección actual y tener su etiqueta mostrada en el área de selección. Por defecto, se utiliza el primer elemento seleccionable del panel del menú desplegable.

parent
Especifica el ID del widget padre
name
Especifica el nombre del widget creado
arglist
Especifica la lista de argumentos
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist)

El usuario puede especificar recursos en un archivo de recursos para los widgets y gadgets creados automáticamente de un OptionMenu. Estos widgets (o gadgets) y las áreas asociadas del OptionMenu son:

Etiqueta del Menú de Opciones Gadget
OptionLabel
Botón de Cascada del Menú de Opciones
OptionButton

Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNAR

Devuelve el ID del widget RowColumn.
