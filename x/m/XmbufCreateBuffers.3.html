DESCRIPCIÓN

La biblioteca de programación de aplicaciones para la Extensión de Doble Buffer, Multibuffer y Estéreo de X11 contiene las interfaces descritas a continuación. Con la excepción de XmbufQueryExtension, si alguna de estas rutinas se llama con una pantalla que no soporta la extensión, se llamará al ExtensionErrorHandler (que se puede establecer con XSetExtensionErrorHandler y funciona de la misma manera que XSetErrorHandler) y la función devolverá.

XmbufQueryExtension devuelve True si la extensión de multibuffer/estéreo está disponible en la pantalla dada. Si la extensión existe, el valor del primer código de evento (que debe agregarse a las constantes de tipo de evento MultibufferClobberNotify y MultibufferUpdateNotify para obtener los valores reales) se almacena en event_base_return y el valor del primer código de error (que debe agregarse a la constante de tipo de error MultibufferBadBuffer para obtener el valor real) se almacena en error_base_return.

XmbufGetVersion obtiene los números de versión principal y secundaria de la extensión. El valor de retorno es cero si ocurre un error o distinto de cero si no ocurre ningún error.

XmbufCreateBuffers solicita que se creen "count" buffers con el update_action y update_hint dados y que se asocien con la ventana indicada. Se devuelve el número de buffers creados (cero si ocurrió un error) y buffers_update se rellena con esa cantidad de identificadores Multibuffer.

XmbufDestroyBuffers destruye los buffers asociados con la ventana dada.

XmbufDisplayBuffers muestra los buffers indicados en sus ventanas apropiadas dentro de max_delay milisegundos después de que hayan pasado min_delay milisegundos. No se pueden asociar dos buffers con la misma ventana o se generará un error Match.

XmbufGetWindowAttributes obtiene los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. La lista de buffers devuelta puede liberarse con XFree. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeWindowAttributes establece los atributos de multibuffer que se aplican a todos los buffers asociados con la ventana dada. Actualmente, esto se limita al update_hint.

XmbufGetBufferAttributes obtiene los atributos del buffer indicado. Devuelve un valor distinto de cero en caso de éxito y cero si ocurre un error.

XmbufChangeBufferAttributes establece los atributos del buffer indicado. Actualmente, esto se limita al event_mask.

XmbufGetScreenInfo obtiene los parámetros que controlan cómo se pueden crear ventanas mono y estéreo en la pantalla del drawable dado. El número de conjuntos de visualización y profundidades se devuelve en nmono_return y nstereo_return. Si nmono_return es mayor que cero, entonces mono_info_return se establece en la dirección de una matriz de estructuras XmbufBufferInfo que describen las diversas visualizaciones y profundidades que se pueden usar. De lo contrario, mono_info_return se establece en NULL. De manera similar, stereo_info_return se establece según nstereo_return. El almacenamiento devuelto en mono_info_return y stereo_info_return puede ser liberado por XFree. Si no se encuentran errores, se devolverá un valor distinto de cero.

XmbufCreateStereoWindow crea una ventana estéreo de la misma manera que XCreateWindow crea una ventana mono. Los IDs de buffer para los buffers izquierdo y derecho se devuelven en left_return y right_return, respectivamente. Si se instala un manejador de errores de extensión que devuelve, se devolverá None si la extensión no está disponible en esta pantalla.

XmbufCreateBuffers(3)

NAME

XmbufCreateBuffers — crear y enlazar búferes para doble buffer, multi-buffer y estéreo

SYNTAX

    XmbufCreateBuffers(
        Display *dpy,
        Window win,
        int num_buffers,
        Bool sync_to_vblank,
        int *error_code_return
    );

STRUCTURES

struct _XExtData *
Estrucura de datos de extensión para el cliente X.

DESCRIPTION

La extensión Multi-Buffering permite a una aplicación de cliente crear múltiples búferes (generalmente uno frontal y uno o más traseros) para una ventana dada. El servidor X gestiona el intercambio de estos búferes para producir animaciones fluidas, presentación de video o efectos estéreo.

La función XmbufCreateBuffers crea el conjunto de búferes especificado para la ventana dada.

  • dpy: El puntero a la estructura Display.
  • win: La ventana para la que se crearán los búferes.
  • num_buffers: El número total de búferes a crear (incluyendo el búfer frontal). Debe ser al menos 2 para la funcionalidad de doble buffer.
  • sync_to_vblank: Un valor booleano. Si es True, el servidor X intentará sincronizar el intercambio de búferes con el barrido vertical del monitor para evitar el parpadeo y el desgarro de pantalla. Si es False, el intercambio se produce lo más rápido posible.
  • error_code_return: Un puntero a un entero donde se devolverá el código de error si la operación falla. Si tiene éxito, se establecerá en 0.

Los posibles códigos de error devueltos son:

MultibufferBadBuffer
El número de búferes especificado no es válido.
MultibufferNumberErrors
Un error genérico relacionado con el número de errores.

Después de crear los búferes, la aplicación puede usar las funciones proporcionadas por la extensión Multi-Buffering para realizar operaciones como el intercambio de búferes y la configuración de eventos de notificación.

PREDEFINED VALUES

Los siguientes valores predefinidos están asociados con la extensión Multi-Buffering:

#define MultibufferClobberNotify     (1 << 0)
