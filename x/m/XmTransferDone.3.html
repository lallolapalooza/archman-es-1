NOMBRE

XmTransferDone — Una función del toolkit que completa una transferencia de datos

SINOPSIS

#include <Xm/Xm.h>

void XmTransferDone(
XtPointer transfer_id,
XmTransferStatus status);

DESCRIPCIÓN

XmTransferDone completa una operación de transferencia de datos ya iniciada. Una aplicación puede llamar a esta rutina desde un procedimiento XmNdestinationCallback o cualquier función llamada como resultado, incluyendo los procedimientos de selección llamados como resultado de llamadas a XmTransferValue.

El llamador de XmTransferDone proporciona un identificador para la operación de transferencia y una indicación del estado de finalización. XmTransferDone descarta cualquier transferencia restante para la operación.

transfer_id
Especifica un identificador único para la operación de transferencia de datos. El valor debe ser el mismo que el valor del miembro transfer_id de la estructura XmDestinationCallbackStruct pasada al procedimiento XmNdestinationCallback.
status
Especifica el estado de finalización de la transferencia de datos. A continuación se muestran los posibles valores:
XmTRANSFER_DONE_SUCCEED
La transferencia se completó con éxito. Este estado tiene los siguientes efectos adicionales:
•
Para una operación de mover, el propietario de la selección recibe una solicitud para convertir la selección al destino DELETE.
•
Si una operación TRANSACT está en curso, el propietario recibe una solicitud para confirmar la transacción.
•
Si una operación PERSIST o _MOTIF_SNAPSHOT está en curso, el propietario recibe una notificación de que la operación ha finalizado.
•
No se llama al procedimiento de destino de la clase del widget.
XmTRANSFER_DONE_FAIL
La transferencia se completó sin éxito. Este estado tiene los siguientes efectos adicionales:
•
Para una operación de mover, el propietario de la selección no recibe una solicitud para convertir la selección al destino DELETE.
•
Para una operación de arrastrar y soltar, el XmNtransferStatus del DropTransfer se establece en XmTRANSFER_FAILURE.
•
Si una operación TRANSACT está en curso, el propietario recibe una solicitud para abortar la transacción.
•
Si una operación PERSIST o _MOTIF_SNAPSHOT está en curso, el propietario recibe una notificación de que la operación ha finalizado.
•
No se llama al procedimiento de destino de la clase del widget.
XmTRANSFER_DONE_CONTINUE
Este estado tiene el mismo efecto que XmTRANSFER_DONE_SUCCEED, excepto que si una operación PERSIST o _MOTIF_SNAPSHOT está en curso, el propietario no recibe una notificación de que la operación ha finalizado.
XmTRANSFER_DONE_DEFAULT
Se llama al procedimiento de destino de la clase del widget. Los efectos adicionales dependen de las acciones de dicho procedimiento.

RELACIONADO
