NOMBRE

XmMainWindowSetAreas — Una función de MainWindow que identifica los hijos administrables para cada área

SINOPSIS

#include <Xm/MainW.h>
void XmMainWindowSetAreas(
Widget widget,
Widget menu_bar,
Widget command_window,
Widget horizontal_scrollbar,
Widget vertical_scrollbar,
Widget work_region);

DESCRIPCIÓN

XmMainWindowSetAreas identifica cuáles de los hijos válidos para cada área (como la barra de menú y la región de trabajo) serán administrados activamente por MainWindow. Esta función también configura o añade los widgets de la barra de menú, ventana de trabajo, ventana de comandos y barras de desplazamiento al widget de la ventana principal de la aplicación.

Cada área es opcional; por lo tanto, el usuario puede pasar NULL a uno o más de los siguientes argumentos. El gestor de ventanas proporciona la barra de título.

NOTA: XmMainWindowSetAreas es obsoleto y existe para compatibilidad con versiones anteriores. La información devuelta previamente por esta función ahora se puede obtener a través de una llamada a XtGetValues en el recurso XmNscrolledWindowChildType.

widget
Especifica el ID del widget MainWindow.
menu_bar
Especifica el ID del widget para la barra de menú que se asociará con el widget MainWindow. Establezca este ID solo después de crear una instancia del widget MainWindow. El nombre del atributo asociado con este argumento es XmNmenuBar.
command_window
Especifica el ID del widget para la ventana de comandos que se asociará con el widget MainWindow. Establezca este ID solo después de crear una instancia del widget MainWindow. El nombre del atributo asociado con este argumento es XmNcommandWindow.
horizontal_scrollbar
Especifica el ID del widget ScrollBar para la barra de desplazamiento horizontal que se asociará con el widget MainWindow. Establezca este ID solo después de crear una instancia del widget MainWindow. El nombre del atributo asociado con este argumento es XmNhorizontalScrollBar.
vertical_scrollbar
Especifica el ID del widget ScrollBar para la barra de desplazamiento vertical que se asociará con el widget MainWindow. Establezca este ID solo después de crear una instancia del widget MainWindow. El nombre del atributo asociado con este argumento es XmNverticalScrollBar.
work_region
Especifica el ID del widget para la ventana de trabajo que se asociará con el widget MainWindow. Establezca este ID solo después de crear una instancia del widget MainWindow. El nombre del atributo asociado con este argumento es XmNworkWindow.

Para una definición completa de MainWindow y sus recursos asociados, consulte XmMainWindow(3).
