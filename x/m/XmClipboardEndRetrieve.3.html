NOMBRE

XmClipboardEndRetrieve — Una función del portapapeles que completa la recuperación de datos del portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardEndRetrieve (display, window)
        Display * display;
        Window  window;
(void)

DESCRIPCIÓN

XmClipboardEndRetrieve suspende la copia de datos incrementalmente del portapapeles. Indica a las rutinas del portapapeles que la aplicación ha terminado de copiar un elemento del portapapeles. Hasta que se llama a esta función, los elementos de datos se pueden recuperar incrementalmente del portapapeles con XmClipboardRetrieve. El acto de copiar datos se inicia con la función XmClipboardStartRetrieve.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener con XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llama.

RETORNO

XmClipboardSuccess
La función se realizó correctamente.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función de nuevo con los mismos parámetros hasta que desaparezca el bloqueo. Esto da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentándolo o abandonar la operación.

RELACIONADOS

XmClipboardRetrieve(3), XmClipboardStartCopy(3), y XmClipboardStartRetrieve(3).
