NOMBRE

XmClipboardRegisterFormat — Una función del portapapeles que registra un nuevo formato

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardRegisterFormat (display, format_name, format_length)
        Display * display;
        char    * format_name;
        int     format_length;
(void)

DESCRIPCIÓN

XmClipboardRegisterFormat registra un nuevo formato. Cada formato almacenado en el portapapeles debe tener una longitud asociada; esta longitud debe ser conocida por las rutinas del portapapeles. Los formatos se conocen como objetivos en el Inter-Client Communication Conventions Manual (ICCCM). Todos los formatos especificados por la versión 1.1 de las convenciones ICCCM están pre-registrados. Cualquier otro formato que la aplicación quiera utilizar debe ser datos de 8 bits o ser registrado a través de esta rutina. El fallo al registrar la longitud de los datos resulta en aplicaciones incompatibles entre plataformas con diferentes órdenes de intercambio de bytes.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
format_name
Especifica el nombre de cadena para el nuevo formato (objetivo).
format_length
Especifica la longitud del formato en bits (8, 16 o 32).

RETORNO

XmClipboardBadFormat
El format_name no debe ser NULL, y el format_length debe ser 8, 16 o 32.
XmClipboardSuccess
La función fue exitosa.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función nuevamente con los mismos parámetros hasta que el bloqueo desaparezca. Esto da a la aplicación la oportunidad de preguntar si el usuario quiere seguir intentándolo o abandonar la operación.
XmClipboardFail
La función falló porque el formato especificado ya estaba registrado con una longitud diferente a la especificada ahora. Si un formato especificado ya estaba registrado con la misma longitud que la especificada ahora, se devuelve XmClipboardSuccess.
