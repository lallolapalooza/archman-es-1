NOMBRE

XmVaCreateSimplePulldownMenu — una función de creación de conveniencia del widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimplePulldownMenu(
Widget parent,
String name,
int post_from_button,
XtCallbackProc callback);

DESCRIPCIÓN

XmVaCreateSimplePulldownMenu crea una instancia de un widget RowColumn de tipo XmMENU_PULLDOWN y devuelve el ID del widget asociado. Esta rutina utiliza la convención de llamada de lista de argumentos de longitud variable (varargs) de ANSI C.

Esta rutina crea un panel de menú desplegable y sus botones hijos. El nombre de cada botón es button_n, donde n es un entero desde 0 hasta el número de botones en el menú menos 1. El nombre de cada separador es separator_n, donde n es un entero desde 0 hasta el número de separadores en el menú menos 1. El nombre de cada título es label_n, donde n es un entero desde 0 (cero) hasta el número de títulos en el menú menos 1. Los botones, separadores y títulos se nombran y crean en el orden en que se especifican en la parte variable de la lista de argumentos.

Esta rutina también adjunta el PulldownMenu a un CascadeButton o CascadeButtonGadget en el padre. Luego, el PulldownMenu se publica desde este botón.

parent
Especifica el ID del widget padre de MenuShell.
name
Especifica el nombre del widget creado.
post_from_button
Especifica el CascadeButton o CascadeButtonGadget en el padre al que se adjunta el panel del menú desplegable. El valor es el entero n que corresponde al n-ésimo CascadeButton o CascadeButtonGadget especificado para el padre del panel del menú desplegable. Un panel de menú desplegable solo se puede adjuntar a un CascadeButton o CascadeButtonGadget, y solo los CascadeButtons y CascadeButtonGadgets se cuentan al determinar el entero n. El primer CascadeButton o CascadeButtonGadget es el número 0 (cero).
callback
Especifica un procedimiento de callback que se llamará cuando se active un botón o cuando cambie su valor. Esta función de callback se agrega a cada botón después de su creación. Para un CascadeButtonGadget o un PushButtonGadget, el callback se agrega como XmNactivateCallback del botón, y se llama cuando el botón se activa. Para un ToggleButtonGadget, el callback se agrega como XmNvalueChangedCallback del botón, y se llama cuando cambia el valor del botón. El número del botón se devuelve en el campo client_data.

La parte variable de la lista de argumentos consta de grupos de argumentos. El primer argumento de cada grupo es una constante o una cadena y determina qué argumentos le siguen en ese grupo. El último argumento de la lista debe ser NULL. A continuación se presentan los posibles primeros argumentos en cada grupo de varargs:

Va seguido de dos argumentos adicionales. El conjunto especifica un botón en el PulldownMenu y algunos de sus valores de recursos. El botón creado es un CascadeButtonGadget. A continuación se presentan los dos argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString
mnemonic
La mnemotecnia, de tipo KeySym

Va seguido de cuatro argumentos adicionales. El conjunto especifica un botón en el PulldownMenu y algunos de sus valores de recursos. El botón creado es un PushButtonGadget. A continuación se presentan los cuatro argumentos adicionales, en orden:

La cadena de etiqueta, de tipo XmString

La mnemotecnia, de tipo KeySym

El acelerador, de tipo String

El texto del acelerador, de tipo XmString

Va seguido de cuatro argumentos adicionales. El conjunto especifica un botón en el PulldownMenu y algunos de sus valores de recursos. El botón creado es un ToggleButtonGadget. A continuación se presentan los cuatro argumentos adicionales, en orden:

NAME

XmVaCreateSimplePulldownMenu – A function that creates a simple pulldown menu widget that can contain only push buttons, separators, and cascade buttons.

SYNOPSIS

#include <Xm/Xm.h>
Widget XmVaCreateSimplePulldownMenu(
    Widget parent,
    String name,
    ArgList args,
    Cardinal arg_count,
    ...);
Widget XmVaCreateSimplePulldownMenuFromWidget(
    Widget menu_bar,
    String name,
    ArgList args,
    Cardinal arg_count,
    ...);

DESCRIPTION

The XmVaCreateSimplePulldownMenu function creates a simple pulldown menu. A pulldown menu is a menu that appears when a user clicks on a cascade button in a menubar. The created menu is a child of the parent widget. The name argument is the name of the created pulldown menu widget.

The args and arg_count arguments specify the resources for the pulldown menu widget itself. The simple pulldown menu widget supports only a limited set of resources. See the Resource subroutine in XmRowColumn(3) for a description of the RowColumn widget resources.

The remaining arguments are a variable-length argument list, which is a list of resources used to create the menu items within the pulldown menu. This list must end with NULL. The simple pulldown menu widget supports only a limited set of menu items: push buttons, separators, and cascade buttons.

The XmVaCreateSimplePulldownMenuFromWidget function is identical to XmVaCreateSimplePulldownMenu except that it takes a menu_bar widget as its first argument instead of a parent widget. This allows the pulldown menu to be directly associated with a menu bar.

The variable-length argument list must contain entries for each menu item, in order. Each entry consists of the item type, followed by the item's name, and then the list of resources for that item. The list of resources for each item must be terminated by NULL.

XtVaNestedList
This is followed by one additional argument of type XtVarArgsList. This argument is a nested list of varargs returned by XtVaCreateArgsList.

For more information on variable-length argument lists, see the X Toolkit Intrinsics documentation.

A number of resources exist specifically for use with this and other simple menu creation routines. For a complete definition of RowColumn and its associated resources, see XmRowColumn(3).

RETURN

Returns the RowColumn widget ID.
