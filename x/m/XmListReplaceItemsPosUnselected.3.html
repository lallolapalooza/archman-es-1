NOMBRE

XmListReplaceItemsPosUnselected — Función de Lista que reemplaza elementos en una lista sin seleccionar los elementos de reemplazo

SINOPSIS

#include <Xm/List.h>
void XmListReplaceItemsPosUnselected(
Widget widget,
XmString *new_items,
int item_count,
int position);

DESCRIPCIÓN

XmListReplaceItemsPosUnselected reemplaza el número especificado de elementos en la lista con nuevos elementos, comenzando en la posición dada. Los elementos de reemplazo permanecen sin seleccionar, incluso si actualmente aparecen en la lista XmNselectedItems.

widget
Especifica el ID del widget de Lista en el que reemplazar elementos.
new_items
Especifica un puntero a los elementos de reemplazo.
item_count
Especifica el número de elementos en new_items y el número de elementos en la lista a reemplazar. Este número debe ser no negativo.
position
Especifica la posición del primer elemento en la lista que será reemplazado. Un valor de 1 indica que el primer elemento reemplazado es el primer elemento de la lista; un valor de 2 indica que es el segundo elemento; y así sucesivamente.
Comenzando con el elemento especificado en position, se reemplazan item_count elementos en la lista con los elementos correspondientes de new_items. Es decir, el elemento en position se reemplaza con el primer elemento de new_items; el elemento después de position se reemplaza con el segundo elemento de new_items; y así sucesivamente, hasta que se alcance item_count.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).

RELACIONADOS
