XmStringUnparse(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringUnparse(llamada a biblioteca) XmStringUnparse(llamada a biblioteca)

NOMBRE

XmStringUnparse — Una función de cadena compuesta que analiza texto

SINOPSIS

#include <Xm/Xm.h>
XtPointer XmStringUnparse(
XmString string,
XmStringTag tag,
XmTextType tag_type,
XmTextType output_type,
XmParseTable parse_table,
Cardinal parse_count,
XmParseModel parse_model);

DESCRIPCIÓN

XmStringUnparse busca en la string de entrada segmentos de texto que estén etiquetados con etiquetas de localización o de conjunto de caracteres que coincidan con tag. El parámetro tag_type especifica si la etiqueta es de tipo localización o conjunto de caracteres. Si tag tiene un valor NULL, todos los segmentos coinciden. Cuando se encuentra un segmento de texto con una etiqueta coincidente, se añade al final de una cadena resultante. Los caracteres de la cadena resultante son del tipo output_type.

XmStringUnparse también verifica string en busca de componentes que coincidan con los componentes de parse_table, y también para ver si el componente coincide con la condición especificada por parse_model. Si el componente de cadena coincide en ambas verificaciones, el carácter asociado se añade al final de la cadena resultante.

string
Especifica la XmString a convertir.
tag
Especifica la etiqueta a utilizar para la coincidencia con los segmentos de texto. Solo se incluirán en la cadena resultante los segmentos de texto que coincidan con tag. Si tag tiene un valor NULL, todos los segmentos se consideran coincidencias y se ignora tag_type.
tag_type
Especifica el tipo de etiqueta a buscar, incluyendo XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT, y XmCHARSET_TEXT.
output_type
Especifica el tipo de texto a devolver en la cadena, incluyendo XmMULTIBYTE_TEXT, XmWIDECHAR_TEXT, y XmCHARSET_TEXT.
parse_table
Especifica la tabla de análisis a utilizar para buscar componentes de cadena compuestos que se convertirán a otros caracteres.
parse_count
Especifica cuántas entradas hay en parse_table.
parse_model
Especifica qué componentes no textuales se considerarán al buscar coincidencias en parse_table. Estos incluyen:
XmOUTPUT_ALL
Emite todos los componentes coincidentes.
XmOUTPUT_BETWEEN
Emite solo aquellos componentes coincidentes que se encuentran entre dos componentes de texto coincidentes.
XmOUTPUT_BEGINNING
Emite solo aquellos componentes coincidentes que se encuentran al principio de un componente de texto coincidente.
XmOUTPUT_END
Emite solo aquellos componentes coincidentes que se encuentran al final de un componente de texto coincidente.
XmOUTPUT_BOTH
Emite solo aquellos componentes coincidentes que se encuentran al principio o al final de un componente de texto coincidente.

DEVOLVER

Devuelve una cadena recién asignada que contiene caracteres de un tipo determinado por output_type. La aplicación es responsable de gestionar este espacio asignado. La aplicación puede recuperar este espacio asignado llamando a XtFree.

RELACIONADO

XmString(3), XmParseTable(3), XmParseMapping(3).
