NOMBRE

XmSeparatorGadget — clase del widget SeparatorGadget

SINOPSIS

#include <Xm/SeparatoG.h>

DESCRIPCIÓN

SeparatorGadget separa elementos en una pantalla. Se proporcionan varios estilos de dibujo de líneas, así como orientación horizontal o vertical.

Las líneas dibujadas dentro de SeparatorGadget se centran automáticamente dentro de la altura del gadget para una orientación horizontal y se centran dentro del ancho del gadget para una orientación vertical. Una llamada a XtSetValues con un nuevo XmNseparatorType redimensiona el widget a su altura mínima (para orientación horizontal) o su ancho mínimo (para orientación vertical) a menos que la altura o el ancho se establezcan explícitamente en la llamada a XtSetValues.

SeparatorGadget no dibuja sombras alrededor del separador. El recurso del Gadget XmNshadowThickness se utiliza para el grosor del SeparatorGadget cuando XmNseparatorType es XmSHADOW_ETCHED_IN, XmSHADOW_ETCHED_IN_DASH, XmSHADOW_ETCHED_OUT o XmSHADOW_ETCHED_OUT_DASH.

SeparatorGadget no resalta y no permite la navegación. El recurso del Gadget XmNtraversalOn se fuerza a False. SeparatorGadget tiene el rasgo XmQTmenuSavvy.

Clases

SeparatorGadget hereda comportamiento, recursos y rasgos de Object, RectObj y XmGadget.

El puntero de clase es xmSeparatorGadgetClass.

El nombre de la clase es XmSeparatorGadget.

NAME

XmSeparatorGadget - A separator gadget

SYNOPSIS

#include <Xm/SeparatorG.h>

DESCRIPTION

The XmSeparatorGadget is a primitive gadget that provides a horizontal or vertical line separating other gadgets or widgets. It has no children and supports only the resources defined for primitive gadgets and its own specific resources.

The XmSeparatorGadget supports the following resources:
