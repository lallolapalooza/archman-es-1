NOMBRE

XmFontList — Tipo de datos para una lista de fuentes

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

XmFontList es el tipo de datos para una lista de fuentes. Una lista de fuentes consta de entradas de lista de fuentes. Cada entrada contiene una fuente o un conjunto de fuentes (un grupo de fuentes) y se identifica con una etiqueta, que es opcional. Si esta etiqueta es NULL, se establece en XmFONTLIST_DEFAULT_TAG.

El valor de XmFONTLIST_DEFAULT_TAG es XmFONTLIST_DEFAULT_TAG_STRING.

Cuando se muestra una cadena compuesta, la etiqueta del elemento de la lista de fuentes del segmento de cadena compuesta se compara con una etiqueta de entrada de lista de fuentes en la lista de fuentes y se utiliza la entrada de lista de fuentes coincidente para mostrar la cadena compuesta. Una entrada de lista de fuentes se elige de la siguiente manera:

•
Se utiliza la primera entrada de la lista de fuentes cuya etiqueta coincida con la etiqueta del segmento de cadena compuesta.
•
Si no se ha encontrado ninguna coincidencia y si la etiqueta del segmento de cadena compuesta es XmFONTLIST_DEFAULT_TAG, se utiliza la primera entrada de la lista de fuentes cuya etiqueta coincida con la etiqueta que resultaría al crear una entrada con XmSTRING_DEFAULT_CHARSET. Por ejemplo, si la creación de una entrada con XmSTRING_DEFAULT_CHARSET resultara en la etiqueta ISO8859-1, la etiqueta del segmento de cadena compuesta XmFONTLIST_DEFAULT_TAG coincidiría con la etiqueta de la entrada de la lista de fuentes ISO8859-1.
•
Si no se ha encontrado ninguna coincidencia y si la etiqueta del segmento de cadena compuesta coincide con la etiqueta que resultaría al crear un segmento con XmSTRING_DEFAULT_CHARSET, se utiliza la primera entrada de la lista de fuentes cuya etiqueta sea XmFONTLIST_DEFAULT_TAG.
•
Si no se ha encontrado ninguna coincidencia, se utiliza la primera entrada de la lista de fuentes.

La interfaz de la lista de fuentes consta de las rutinas enumeradas en Información Relacionada.

Las listas de fuentes se especifican en los archivos de recursos con la siguiente sintaxis:

especificación_recurso:  entrada_fuente [, entrada_fuente ]+

La cadena de valor del recurso consta de una o más entradas de lista de fuentes separadas por comas. Cada entrada_fuente identifica una fuente o un conjunto de fuentes y una etiqueta opcional de entrada de lista de fuentes. Una etiqueta especificada para una fuente individual sigue el nombre de la fuente y está separada por = (signo igual); de lo contrario, en un conjunto de fuentes, la etiqueta está separada por dos puntos. Los dos puntos son obligatorios, ya sea que se especifique una etiqueta o no. Una entrada de fuente utiliza la siguiente sintaxis para especificar una fuente individual:

nombre_fuente [ '=' etiqueta ]

Por ejemplo, la siguiente entrada especifica una fuente Times Italic de 10 puntos sin etiqueta de entrada de lista de fuentes;

*fontList:  -Adobe-Times-Medium-I-Normal--10*

Una entrada de fuente que contiene un conjunto de fuentes es similar, excepto que un punto y coma separa varios nombres de fuente y la especificación termina con dos puntos seguidos de una etiqueta opcional:

nombre_fuente [ ';' nombre_fuente ]+ ':' [ etiqueta ]

Un nombre_fuente es una cadena de Descripción Lógica de Fuentes X (XLFD) y etiqueta son cualquier conjunto de caracteres de ISO646IRV excepto espacios, comas, dos puntos, signos de igual y puntos y comas. A continuación, se muestra un ejemplo de una entrada de conjunto de fuentes. Consiste en tres fuentes (excepto para los conjuntos de caracteres) y una etiqueta de entrada de lista de fuentes explícita.

*fontList: -Adobe-Courier-Bold-R-Normal--25-180-100-100-M-150;-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-240;-JIS-Fixed-Medium-R-Normal--26-180-100-100-C-120:MY_TAG

Tenga en cuenta que XmRenderTable es otro tipo de datos que se puede utilizar para listas de fuentes. Consulte XmRenderTable(3) para obtener detalles.
