NOMBRE

XML::LibXML::XPathContext - Evaluación XPath

SINOPSIS

my $xpc = XML::LibXML::XPathContext->new();
my $xpc = XML::LibXML::XPathContext->new($node);
$xpc->registerNs($prefijo, $uri_namespace)
$xpc->unregisterNs($prefijo)
$uri = $xpc->lookupNs($prefijo)
$xpc->registerVarLookupFunc($callback, $datos)
$datos = $xpc->getVarLookupData();
$callback = $xpc->getVarLookupFunc();
$xpc->unregisterVarLookupFunc($nombre);
$xpc->registerFunctionNS($nombre, $uri, $callback)
$xpc->unregisterFunctionNS($nombre, $uri)
$xpc->registerFunction($nombre, $callback)
$xpc->unregisterFunction($nombre)
@nodos = $xpc->findnodes($xpath)

DESCRIPCIÓN

La clase XML::LibXML::XPathContext proporciona una interfaz casi completa a la implementación XPath de libxml2. Con XML::LibXML::XPathContext, es posible evaluar expresiones XPath en el contexto de nodos arbitrarios, tamaño de contexto y posición de contexto, con un mapeo de prefijo de espacio de nombres definido por el usuario, funciones XPath personalizadas escritas en Perl, e incluso un resolutor de variables XPath personalizado.

EJEMPLOS

Espacios de nombres

Este ejemplo demuestra el método registerNs(). Encuentra todos los nodos de párrafo en un documento XHTML.

my $xc = XML::LibXML::XPathContext->new($doc_xhtml);
$xc->registerNs('xhtml', 'http://www.w3.org/1999/xhtml');
my @nodos = $xc->findnodes('//xhtml:p');

Funciones XPath personalizadas

Este ejemplo demuestra el método registerFunction() definiendo una función que filtra nodos basándose en una expresión regular de Perl:

sub grep_nodos {
  my ($lista_nodos,$regexp) =  @_;
  my $resultado = XML::LibXML::NodeList->new;
  for my $nodo ($lista_nodos->get_nodelist()) {
    $resultado->push($nodo) if $nodo->textContent =~ $regexp;
  }
  return $resultado;
};
my $xc = XML::LibXML::XPathContext->new($nodo);
$xc->registerFunction('grep_nodos', \&grep_nodos);
my @nodos = $xc->findnodes('//section[grep_nodos(para,"\bsearch(ing|es)?\b")]');

Variables

Este ejemplo demuestra el método registerVarLookup(). Usamos variables XPath para reciclar resultados de evaluaciones previas:

sub lookup_variable {
  my ($nombre_variable,$ns,$datos)=@_;
  return $datos->{$nombre_variable};
}
my $areas = XML::LibXML->new->parse_file('areas.xml');
my $empl = XML::LibXML->new->parse_file('empleados.xml');
my $xc = XML::LibXML::XPathContext->new($empl);
my %variables = (
  A => $xc->find('/empleados/empleado[@salario>10000]'),
  B => $areas->find('/areas/area[distrito='Brooklyn']/calle'),
);
# obtener nombres de empleados de $A que trabajan en un área listada en $B
$xc->registerVarLookupFunc(\&lookup_variable, \%variables);
my @nodos = $xc->findnodes('$A[area_trabajo/calle = $B]/nombre');

MÉTODOS

new
my $xpc = XML::LibXML::XPathContext->new();

Crea un nuevo objeto XML::LibXML::XPathContext sin nodo de contexto.

my $xpc = XML::LibXML::XPathContext->new($nodo);

Crea un nuevo objeto XML::LibXML::XPathContext con el nodo de contexto establecido en $nodo.

registerNs
$xpc->registerNs($prefijo, $uri_namespace)

Registra el espacio de nombres $prefijo con $uri_namespace.

unregisterNs
$xpc->unregisterNs($prefijo)

Anula el registro del espacio de nombres $prefijo.

lookupNs
$uri = $xpc->lookupNs($prefijo)

Devuelve la URI del espacio de nombres registrada con $prefijo. Si $prefijo no está registrado con ninguna URI de espacio de nombres, devuelve "undef".

registerVarLookupFunc
$xpc->registerVarLookupFunc($callback, $datos)

Registra la función de búsqueda de variables $callback. La función registrada es ejecutada por el motor XPath cada vez que se evalúa una variable XPath. Toma tres argumentos: $datos, nombre de la variable y URI del espacio de nombres de la variable, y debe devolver un valor: un número, una cadena o cualquier objeto "XML::LibXML::" que pueda ser el resultado de findnodes: Booleano, Literal, Número, Nodo (ej. Documento, Elemento, etc.) o NodeList. Para conveniencia, se pueden usar referencias de array simples (sin bendecir) que contengan solo objetos XML::LibXML::Node en lugar de un XML::LibXML::NodeList.

getVarLookupData
$datos = $xpc->getVarLookupData();

Devuelve los datos que se han asociado con una función de búsqueda de variables durante una llamada anterior a "registerVarLookupFunc".

getVarLookupFunc
$callback = $xpc->getVarLookupFunc();

Devuelve la función de búsqueda de variables registrada previamente con "registerVarLookupFunc".

unregisterVarLookupFunc
$xpc->unregisterVarLookupFunc($nombre);

Anula el registro de la función de búsqueda de variables y los datos de búsqueda asociados.

registerFunctionNS
$xpc->registerFunctionNS($nombre, $uri, $callback)

Registra una función de extensión $nombre en el espacio de nombres $uri. $callback debe ser una referencia a CODE. Los argumentos de la función callback son escalares simples u objetos "XML::LibXML::*" dependiendo de los tipos de argumentos XPath. La función es responsable de verificar el número y los tipos de los argumentos. El resultado del código callback debe ser un único valor de los siguientes tipos: un escalar simple (número, cadena) o un objeto arbitrario "XML::LibXML::*" que pueda ser el resultado de findnodes: Booleano, Literal, Número, Nodo (ej. Documento, Elemento, etc.) o NodeList. Para conveniencia, se pueden usar referencias de array simples (sin bendecir) que contengan solo objetos XML::LibXML::Node en lugar de una XML::LibXML::NodeList.

unregisterFunctionNS
$xpc->unregisterFunctionNS($nombre, $uri)

Anula el registro de la función de extensión $nombre en el espacio de nombres $uri. Tiene el mismo efecto que pasar "undef" como $callback a registerFunctionNS.

registerFunction
$xpc->registerFunction($nombre, $callback)

Igual que "registerFunctionNS" pero sin un espacio de nombres.

unregisterFunction
$xpc->unregisterFunction($nombre)

Igual que "unregisterFunctionNS"

XML::LibXML::XPathContext - Perl 5.42.0 documentation

NAME

XML::LibXML::XPathContext - XPath context for the DOM

SYNOPSIS

    use XML::LibXML;

    my $dom = XML::LibXML->load_xml('file:doc.xml');
    my $xpc = XML::LibXML::XPathContext->new($dom);

    # Register extension functions
    $xpc->registerFunc('myfunc', sub { ... });

    # Register namespaces
    $xpc->registerNs('html', 'http://www.w3.org/1999/xhtml');

    # Evaluate XPath expressions
    my @nodes = $xpc->findnodes('//foo');
    my $num   = $xpc->find('count(//bar)');
    my $str   = $xpc->findvalue('string(//baz)');

    # Use a specific node as context
    my $context_node = XML::LibXML::XPath->find('//a[@id="foo"]', $dom);
    my @results = $xpc->findnodes('descendant::b', $context_node);

DESCRIPTION

This class provides a context for evaluating XPath queries against an XML::LibXML document. It allows to register custom XPath functions, namespaces and variables.

The context can be initialized with a node or a document. If a document is given, the context node defaults to the document root.

The XPath engine can be controlled by setting the context node, position and size. This is useful for implementing XPath extensions that need access to the context of the evaluation.

EXAMPLES

Registering Namespaces
    use XML::LibXML;

    my $dom = XML::LibXML->load_xml(qq{
        <root xmlns:foo="http://example.com/foo">
            <foo:bar>content</foo:bar>
        </root>
    });
    my $xpc = XML::LibXML::XPathContext->new($dom);
    $xpc->registerNs('f', 'http://example.com/foo');
    my @nodes = $xpc->findnodes('//f:bar');
    print $nodes[0]->textContent; # prints content
Registering Extension Functions
    use XML::LibXML;

    my $dom = XML::LibXML->load_xml('file:doc.xml');
    my $xpc = XML::LibXML::XPathContext->new($dom);

    # Register a simple function that concatenates two strings
    $xpc->registerFunc('concat', sub {
        my ($xpc, $str1, $str2) = @_;
        return $str1 . $str2;
    });

    # Use the extension function in an XPath query
    # Assuming the document has a 'name' element
    my $full_name = $xpc->findvalue("//name/text() |',' , 'user')");
    # The above will effectively call concat('John Doe', ', ', 'user')
Using a Specific Node as Context
    use XML::LibXML;

    my $dom = XML::LibXML->load_xml('file:doc.xml');
    my $xpc = XML::LibXML::XPathContext->new($dom);

    # Find a specific node to use as context
    my $context_node = $xpc->findnode('//div[@id="main"]/p[1]');

    # Find nodes relative to the context node
    my @images = $xpc->findnodes('//img', $context_node);

METHODS

new
    $xpc = XML::LibXML::XPathContext->new($context_node_or_document)

Creates a new XPath context. The optional argument is either a document or a node. If it's a document, the context node defaults to the document root. If it's a node, that node becomes the context node. If no argument is given, the context node is undefined (which means that most XPath expressions will fail unless a context node is set later).

registerNs
    $xpc->registerNs($prefix, $uri)

Registers a namespace prefix and URI for use in XPath expressions.

registerNsList
    $xpc->registerNsList($ns_ref)

Registers a list of namespaces. The list is expected to be a hash reference, where keys are prefixes and values are URIs.

registerFunc
    $xpc->registerFunc($name, $callback)
    $xpc->registerFunc($name, $arg_count, $callback)
    $xpc->registerFunc($name, $arg_count, $callback, $flags)

Registers an XPath extension function. The function name is given as a string, e.g. "myfunc". The callback is a Perl subroutine reference.

The callback function receives the XPath context object as its first argument, followed by the evaluated arguments of the XPath expression. The return value of the callback is converted to an XPath value.

The optional $arg_count argument allows to specify the number of arguments the function takes. If omitted, the function is assumed to take a variable number of arguments.

The optional $flags argument can be used to control the behavior of the function. Currently, the only supported flag is XML_XPATH_FUNC_ALIAS, which indicates that the function is an alias for another function.

Note that registered functions are visible in all contexts created from the same XPathContext object, but not in contexts created independently. Also, do not register functions from within other extension functions or variable lookup functions unless you want to experience untested behavior.

registerFuncList
    $xpc->registerFuncList($func_ref)

Registers a list of extension functions. The list is expected to be a hash reference, where keys are function names and values are either callback subroutines or arrays containing the argument count, callback subroutine and flags.

registerVar
    $xpc->registerVar($name, $value)

Registers an XPath variable. The value is automatically converted to an XPath value.

findnodes
@nodes = $xpc->findnodes($xpath)
@nodes = $xpc->findnodes($xpath, $context_node )
$nodelist = $xpc->findnodes($xpath, $context_node )

Performs the xpath statement on the current node and returns the result as an array. In scalar context, returns an XML::LibXML::NodeList object. Optionally, a node may be passed as a second argument to set the context node for the query.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

find
$object = $xpc->find($xpath )
$object = $xpc->find($xpath, $context_node )

Performs the xpath expression using the current node as the context of the expression, and returns the result depending on what type of result the XPath expression had. For example, the XPath "1 * 3 + 52" results in an XML::LibXML::Number object being returned. Other expressions might return a XML::LibXML::Boolean object, or a XML::LibXML::Literal object (a string). Each of those objects uses Perl's overload feature to ``do the right thing'' in different contexts. Optionally, a node may be passed as a second argument to set the context node for the query.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

findvalue
$value = $xpc->findvalue($xpath )
$value = $xpc->findvalue($xpath, $context_node )

Is exactly equivalent to:

$xpc->find( $xpath, $context_node )->to_literal;

That is, it returns the literal value of the results. This enables you to ensure that you get a string back from your search, allowing certain shortcuts. This could be used as the equivalent of <xsl:value-of select=``some_xpath''/>. Optionally, a node may be passed in the second argument to set the context node for the query.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

exists
$bool = $xpc->exists( $xpath_expression, $context_node );

This method behaves like findnodes, except that it only returns a boolean value (1 if the expression matches a node, 0 otherwise) and may be faster than findnodes, because the XPath evaluation may stop early on the first match (this is true for libxml2 >= 2.6.27).

For XPath expressions that do not return node-set, the method returns true if the returned value is a non-zero number or a non-empty string.

setContextNode
$xpc->setContextNode($node)

Set the current context node.

getContextNode
my $node = $xpc->getContextNode;

Get the current context node.

setContextPosition
$xpc->setContextPosition($position)

Set the current context position. By default, this value is -1 (and evaluating XPath function position() in the initial context raises an XPath error), but can be set to any value up to context size. This usually only serves to cheat the XPath engine to return given position when position() XPath function is called. Setting this value to -1 restores the default behavior.

getContextPosition
my $position = $xpc->getContextPosition;

Get the current context position.

setContextSize
$xpc->setContextSize($size)

Set the current context size. By default, this value is -1 (and evaluating XPath function last() in the initial context raises an XPath error), but can be set to any non-negative value. This usually only serves to cheat the XPath engine to return the given value when last() XPath function is called. If context size is set to 0, position is automatically also set to 0. If context size is positive, position is automatically set to 1. Setting context size to -1 restores the default behavior.

getContextSize
my $size = $xpc->getContextSize;

Get the current context size.

findnode
$node = $xpc->findnode($xpath, $context_node)

Finds the first node matching the xpath expression. Returns undef if no node is found.

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

findvalue
$value = $xpc->findvalue($xpath, $context_node)

Finds the value of the first node matching the xpath expression. Returns undef if no node is found. This is equivalent to calling find() and then to_literal().

The xpath expression can be passed either as a string, or as a XML::LibXML::XPathExpression object.

setContextNode
$xpc->setContextNode($node)

Set the current context node.

BUGS AND CAVEATS

XML::LibXML::XPathContext objects are reentrant, meaning that you can call methods of an XML::LibXML::XPathContext even from XPath extension functions registered with the same object or from a variable lookup function. On the other hand, you should rather avoid registering new extension functions, namespaces and a variable lookup function from within extension functions and a variable lookup function, unless you want to experience untested behavior.
