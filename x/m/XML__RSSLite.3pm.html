NOMBRE

XML::RSSLite - analizador de RSS (y similar a XML) ligero y "relajado"

SINOPSIS

use XML::RSSLite;
parseRSS(\%result, \$content);
print "=== Canal ===\n",
      "Título: $result{'title'}\n",
      "Desc:  $result{'description'}\n",
      "Enlace:  $result{'link'}\n\n";
foreach $item (@{$result{'items'}}) {
print "  --- Artículo ---\n",
      "  Título: $item->{'title'}\n",
      "  Desc:  $item->{'description'}\n",
      "  Enlace:  $item->{'link'}\n\n";
}

DESCRIPCIÓN

Este módulo intenta extraer la máxima cantidad de contenido de los documentos disponibles, y está menos preocupado por el cumplimiento de XML que otras alternativas. En lugar de depender de XML::Parser, utiliza heurísticas y expresiones regulares de Perl de toda la vida. Almacena los datos en una estructura de hash simple y "alias" ciertas etiquetas para que, una vez hecho, puedas contar con tener los datos mínimos necesarios para reconstruir un archivo RSS válido. Esto significa que obtienes el título, descripción y enlace básicos para un canal y sus artículos.

Este módulo extrae más enlaces utilizables analizando los formatos "scriptingNews" y "weblog" además de RDF y RSS. También "saneaa" la salida para obtener los mejores resultados. El procesamiento incluye:

Eliminar etiquetas html para dejar texto plano
Eliminar espacios en blanco iniciales de las URI
Por defecto, elimina caracteres excepto 0-9~!@#$%^&*()-+=a-zA-Z[];',.:"<>?\s
Usar etiquetas <url> cuando <link> está vacío
Usar URLs mal ubicadas en <title> cuando <link> está vacío
Extraer enlaces de <a href=...> si es necesario
Limitar enlaces a ftp y http(s)
Unir URLs de artículos relativas (que comienzan con / o #) a la base del sitio

EXPORTAR

parseRSS($outHashRef, $inScalarRef, [$strip])
inScalarRef - obligatorio
Referencia a un escalar que contiene el documento a analizar. NOTA: El contenido se destruirá efectivamente. Haz una copia profunda primero si te importa.
outHashRef - obligatorio
Referencia al hash dentro del cual se almacenará el contenido analizado.
strip - opcional
Una expresión que indica el nivel de filtrado que se realizará sobre los caracteres permitidos en los resultados.
1 filtra caracteres no imprimibles
0 no se eliminan caracteres
undefined (Por defecto) filtra todo excepto:
0-9~!@#$%^&*()-+= a-zA-Z[];',.:"<>?\t\n

EXPORTABLE

parseXML(\%parsedTree, \$parseThis, 'topTag', $comments);
parsedTree - obligatorio
Referencia al hash donde se almacenará el documento analizado.
parseThis - obligatorio
Referencia al escalar que contiene el documento a analizar.
topTag - opcional
Etiqueta a considerar como nodo raíz; no se recomienda dejar esto indefinido.
comments - opcional
false eliminará el contenido de parseThis
true no eliminará los comentarios de parseThis
una referencia a un array es verdadera, los comentarios se almacenan aquí

CUIDADOS

Este no es un analizador que cumpla las normas. No maneja lo siguiente:

  • <foo bar=">">

  • <foo><bar> <bar></bar> <bar></bar> </bar></foo>

  • <![CDATA[ ]]>

  • PI

No valida; sin un DTD, lo siguiente no puede abordarse correctamente:

entidades
espacios de nombres
Esto puede o no llegar en alguna versión futura.
