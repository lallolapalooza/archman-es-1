NOMBRE

XmDropSiteRegister — Una función de Arrastrar y Soltar que identifica un sitio de destino y asigna recursos que especifican su comportamiento

SINOPSIS

#include <Xm/DragDrop.h>
void XmDropSiteRegister(
Widget widget,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmDropSiteRegister identifica el widget o gadget especificado como un sitio de destino y establece valores de recursos que definen el comportamiento del sitio de destino. La rutina asigna valores predeterminados a cualquier recurso que no se especifique en la lista de argumentos. El toolkit genera un mensaje de advertencia si un sitio de destino se registra con XmNdropSiteActivity establecido en XmDROP_SITE_ACTIVE y el recurso XmNdropProc es NULL.

Si el sitio de destino es un descendiente de un widget que está registrado como sitio de destino, el recurso XmNdropSiteType del sitio de destino ancestro debe especificarse como XmDROP_SITE_COMPOSITE. El ancestro debe registrarse antes que el descendiente. El sitio de destino se apila por encima de todos los demás sitios de destino hermanos ya registrados.

widget
Especifica el ID del widget a registrar.
arglist
Especifica la lista de argumentos.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Para una definición completa de DropSite y sus recursos asociados, consulte XmDropSite(3).

RELACIONADO

XmDisplay(3), XmDropSite(3), XmDropSiteEndUpdate(3), XmDropSiteStartUpdate(3), XmDropSiteUpdate(3), XmDropSiteUnregister(3), y XmScreen(3).
