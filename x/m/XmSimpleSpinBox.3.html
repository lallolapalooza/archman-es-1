Paquete: openmotif

XmSimpleSpinBox(llamada de librería) XmSimpleSpinBox(llamada de librería)

NOMBRE

XmSimpleSpinBox — una clase de widget SpinBox simple

SINOPSIS

#include <Xm/SSpinB.h>

DESCRIPCIÓN

El widget XmSimpleSpinBox es un control de interfaz de usuario para incrementar y decrementar un TextField arbitrario. Por ejemplo, puede ser usado para ciclar entre los meses del año o los días del mes.

No se admite la herencia de subtipos para la clase de widget XmSimpleSpinBox.

Clases

El widget XmSimpleSpinBox hereda el comportamiento y los recursos de las clases Core, Composite y XmManager.

El puntero de clase es XmSimpleSpinBoxWidgetClass.

El nombre de la clase es XmSimpleSpinBoxWidget.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget que la aplicación utiliza para especificar datos. La aplicación también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, la aplicación debe eliminar el prefijo XmN o XmC y usar las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, la aplicación debe eliminar el prefijo Xm y usar las letras restantes (en minúsculas o mayúsculas, pero incluyendo los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado puede ser establecido en tiempo de creación (C), establecido usando XtSetValues (S), recuperado usando XtGetValues (G), o no es aplicable (N/A).

Especifica el estilo y la posición de las flechas del SpinBox. Los siguientes valores son compatibles:

Las flechas se colocan una al lado de la otra a la derecha del TextField.
XmARROWS_FLAT_END
Las flechas se colocan una al lado de la otra a la izquierda del TextField.
XmARROWS_SPLIT
La flecha hacia abajo está a la izquierda y la flecha hacia arriba está a la derecha del TextField.
XmARROWS_BEGINNING
Las flechas están apiladas y colocadas a la izquierda del TextField.
XmARROWS_END
Las flechas están apiladas y colocadas a la derecha del TextField.
XmNarrowSensitivity
Especifica la sensibilidad de las flechas en el XmSimpleSpinBox. Los siguientes valores son compatibles:
XmARROWS_SENSITIVE
Ambas flechas son activas para la selección del usuario.
XmARROWS_DECREMENT_SENSITIVE
La flecha hacia abajo está activa y la flecha hacia arriba está inactiva para la selección del usuario.
XmARROWS_INCREMENT_SENSITIVE
La flecha hacia arriba está activa y la flecha hacia abajo está inactiva para la selección del usuario.
XmARROWS_INSENSITIVE
Ambas flechas están inactivas para la selección del usuario.
XmNcolumns
Especifica el número de columnas del campo de texto.
XmNdecimalPoints
Especifica la posición del carácter radix dentro del valor numérico cuando XmNspinBoxChildType es XmNUMERIC. Este recurso se usa para permitir valores de punto flotante en el widget XmSimpleSpinBox.
XmNeditable
Especifica si el campo de texto puede recibir entrada.
Cuando se usa XmNeditable en un widget, establece el dropsite a XmDROP_SITE_ACTIVE.
XmNincrementValue
Especifica la cantidad a incrementar o decrementar XmNposition cuando XmNspinBoxChildType es XmNUMERIC. Cuando la acción Arriba se activa, XmNincrementValue se suma al valor de XmNposition; cuando la acción Abajo se activa, XmNincrementValue se resta del valor de XmNposition. Cuando XmNspinBoxChildType es XmSTRING, este recurso se ignora.
XmNinitialDelay
Especifica la cantidad de tiempo en milisegundos antes de que los botones de Flecha comiencen a girar continuamente.
XmNnumValues
Especifica el número de elementos en la lista XmNvalues cuando el recurso XmNspinBoxChildType es XmSTRING. El valor de este recurso debe ser un entero positivo. XmNnumValues es mantenido por el widget XmSimpleSpinBox cuando se añaden o eliminan elementos de la lista XmNvalues. Cuando XmNspinBoxChildType no es XmSTRING, este recurso se ignora.
XmNvalues
Suministra la lista de cadenas para ciclar cuando el recurso XmNspinButtonChildType es XmSTRING. Cuando XmNspinBoxChildType no es XmSTRING, este recurso se ignora.
XmNmaximumValue
Especifica el valor máximo permitida cuando el recurso XmNspinBoxChildType es XmNUMERIC. Cuando la flecha hacia arriba se presiona, si el valor actual es menor que el valor máximo, el valor se incrementa en XmNincrementValue. Cuando la flecha hacia abajo se presiona, si el valor actual es mayor que el valor mínimo, el valor se decrementar en XmNincrementValue.
XmNminimumValue
Especifica el valor mínimo permitida cuando el recurso XmNspinBoxChildType es XmNUMERIC. Cuando la flecha hacia arriba se presiona, si el valor actual es menor que el valor máximo, el valor se incrementa en XmNincrementValue. Cuando la flecha hacia abajo se presiona, si el valor actual es mayor que el valor mínimo, el valor se decrementar en XmNincrementValue.
XmNmodifyVerifyCallback
Define una lista de callbacks que se invocan cuando se intenta modificar el contenido del TextField. La aplicación puede usar este callback para validar o modificar la entrada del usuario antes de que se aplique al TextField. El siguiente tipo de dato es pasado al callback:
XmSpinBoxVerifyCallbackStruct
reason
Indica la razón por la cual se invocó el callback. Para el callback XmNmodifyVerifyCallback, la razón es XmCR_VERIFY.
event
Un puntero al evento que causó la verificación.
curr_value
El valor actual en el TextField.
new_value
El nuevo valor propuesto para el TextField.
new_value
Un puntero a una cadena que contiene el texto que se insertará en el TextField. Si se establece a NULL, no se realizará ninguna inserción. Este campo puede ser modificado por el callback para cambiar el texto que se inserta.
do_it
Un booleano que indica si la modificación debe proceder. Si el callback lo establece a False, la modificación se cancelará.
widget
El widget XmSpinBox.
XmNposition
Especifica la posición actual del valor en el SpinBox. Si XmNspinBoxChildType es XmNUMERIC, este recurso se usa para establecer el valor numérico actual. Si XmNspinBoxChildType es XmSTRING, este recurso se usa para establecer el índice de la cadena actual en la lista de XmNvalues. El valor se ajusta a los límites establecidos por XmNminimumValue y XmNmaximumValue para los tipos numéricos, o a los límites de 0 y (XmNnumValues - 1) para los tipos de cadena.
XmNrepeatDelay
Especifica la cantidad de tiempo en milisegundos entre repeticiones una vez que los botones de Flecha han comenzado a girar continuamente.
XmNspinBoxChildType
Especifica si el SpinBox opera con cadenas o valores numéricos. Los valores posibles son:
XmSTRING
El SpinBox opera con una lista de cadenas proporcionada por el recurso XmNvalues.
XmNUMERIC
El SpinBox opera con valores numéricos dentro de los límites definidos por XmNminimumValue y XmNmaximumValue. Los recursos XmNdecimalPoints y XmNincrementValue también son aplicables en este modo.
XmNtextField
Este recurso es un puntero al widget XmTextField subyacente que se crea automáticamente cuando se crea un widget XmSimpleSpinBox. Solo se puede acceder a través de XtGetValues.
XmNvalueChangedCallback
Define una lista de callbacks que se invocan cuando el valor del SpinBox cambia debido a una interacción del usuario o una llamada a XtSetValues. El siguiente tipo de dato es pasado al callback:
XmSpinBoxCallbackStruct
reason
Indica la razón por la cual se invocó el callback. Para el callback XmNvalueChangedCallback, la razón es XmCR_VALUE_CHANGED.
event
Un puntero al evento que causó el cambio de valor (puede ser NULL si el cambio fue realizado por XtSetValues).
value
El nuevo valor del SpinBox. Es un entero si XmNspinBoxChildType es XmNUMERIC, o un índice si XmNspinBoxChildType es XmSTRING.
widget
El widget XmSpinBox.

Callbacks

El XmSimpleSpinBox widget soporta los siguientes callbacks:

XmNmodifyVerifyCallback
Se invoca antes de que se realice un cambio en el valor del SpinBox. Permite validar o modificar la entrada.
XmNvalueChangedCallback
Se invoca después de que el valor del SpinBox ha cambiado.

Translations

El XmSimpleSpinBox widget hereda las traducciones de XmManager. Las traducciones añadidas son:

    ~Shift <Key>osfDown:         SpinBox Down()
    ~Shift <Key>osfLeft:         SpinBox Down()
    ~Shift <Key>osfRight:        SpinBox Up()
    ~Shift Ctrl <Key>osfUp:      SpinBox Beginning()
    ~Shift Ctrl <Key>osfDown:    SpinBox End()
    ~Shift Ctrl <Key>osfLeft:    SpinBox Beginning()
    ~Shift Ctrl <Key>osfRight:   SpinBox End()

    <Btn1Up>:            SpinBox Accept()
    <Btn1Down><Shift>:   SpinBox Activate()
    <Btn1Up><Shift>:     SpinBox Accept()

Default Actions

Los siguientes son los actions por defecto del XmSimpleSpinBox:

SpinBox Up()
Incrementa el valor actual en XmNincrementValue si el tipo de SpinBox es numérico, o avanza al siguiente elemento en la lista de cadenas si el tipo es de cadena.
SpinBox Down()
Decrementa el valor actual en XmNincrementValue si el tipo de SpinBox es numérico, o retrocede al elemento anterior en la lista de cadenas si el tipo es de cadena.
SpinBox Beginning()
Establece el valor actual al mínimo (si es numérico) o al primer elemento (si es de cadena).
SpinBox End()
Establece el valor actual al máximo (si es numérico) o al último elemento (si es de cadena).
SpinBox Activate()
Activa el botón del SpinBox (ya sea hacia arriba o hacia abajo).
SpinBox Accept()
Acepta el valor actual del SpinBox.

Creation

El widget XmSimpleSpinBox se puede crear con la siguiente llamada a la función:

    widget = XtCreateWidget(name, xmSimpleSpinBoxWidgetClass, parent,
                            args, num_args);

La creación de un widget XmSimpleSpinBox también crea automáticamente un widget XmTextField hijo. Este TextField se puede acceder usando el recurso XmNtextField.

EJEMPLO

El siguiente ejemplo crea un SpinBox que opera con cadenas:

    Widget spinbox;
    Arg args[10];
    XmString months[] = {
        XmStringCreateLtoR("January", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("February", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("March", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("April", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("May", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("June", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("July", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("August", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("September", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("October", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("November", XmSTRING_DEFAULT_CHARSET),
        XmStringCreateLtoR("December", XmSTRING_DEFAULT_CHARSET)
    };
    int num_months = sizeof(months) / sizeof(XmString);

    XtSetArg(args[0], XmNspinBoxChildType, XmSTRING);
    XtSetArg(args[1], XmNvalues, months);
    XtSetArg(args[2], XmNnumValues, num_months);
    XtSetArg(args[3], XmNcolumns, 10);

    spinbox = XtCreateWidget("month_spinbox", xmSimpleSpinBoxWidgetClass, parent, args, 4);

El siguiente ejemplo crea un SpinBox que opera con números:

    Widget spinbox;
    Arg args[10];

    XtSetArg(args[0], XmNspinBoxChildType, XmNUMERIC);
    XtSetArg(args[1], XmNminimumValue, 1);
    XtSetArg(args[2], XmNmaximumValue, 31);
    XtSetArg(args[3], XmNincrementValue, 1);
    XtSetArg(args[4], XmNcolumns, 2);
    XtSetArg(args[5], XmNdecimalPoints, 0);

    spinbox = XtCreateWidget("day_spinbox", xmSimpleSpinBoxWidgetClass, parent, args, 6);

>XmNmaximumValue
Especifica el límite superior en el rango de XmSimpleSpinBox cuando XmNspinBoxChildType es XmNUMERIC.
XmNminimumValue
Especifica el límite inferior en el rango de XmSimpleSpinBox cuando XmNspinBoxChildType es XmNUMERIC.
XmNmodifyVerifyCallback
Especifica la rutina de devolución de llamada que se invocará justo antes de que cambie la posición de XmSimpleSpinBox. La aplicación puede utilizar esta rutina de devolución de llamada para implementar nueva lógica relacionada con la aplicación (incluyendo establecer la nueva posición de giro, o cancelar la acción inminente). Por ejemplo, esta rutina de devolución de llamada se puede usar para detener el giro justo antes de alcanzar los límites superior e inferior de la posición. Si la aplicación establece el miembro doit de la estructura XmSimpleSpinBoxCallbackStruct a False, no sucede nada. De lo contrario, la posición cambia. Las razones enviadas por la rutina de devolución de llamada son XmCR_SPIN_NEXT, o XmCR_SPIN_PRIOR.
XmNposition
El recurso XmNposition tiene un valor diferente según el recurso XmNspinBoxChildType. Cuando XmNspinBoxChildType es XmSTRING, XmNposition es el índice en la lista XmNvalues para el elemento actual. Cuando el recurso XmNspinBoxChildType es XmNUMERIC, XmNposition es el valor entero de XmSimpleSpinBox que cae dentro del rango de XmNmaximumValue y XmNminimumValue.
XmNrepeatDelay
Especifica el número de milisegundos entre llamadas repetidas a XmNvalueChangedCallback mientras el usuario está girando XmSimpleSpinBox.
XmNspinBoxChildType
Especifica el estilo de XmSimpleSpinBox. Se admiten los siguientes valores:
XmSTRING
El hijo es un valor de cadena que se especifica a través del recurso XmNvalues y se incrementa y decrementa cambiando el recurso XmNposition.
XmNUMERIC
El hijo es un valor numérico que se especifica a través del recurso XmNposition y se incrementa de acuerdo con el recurso XmNincrementValue.
XmtextField
Especifica el widget del campo de texto.
XmNvalueChangedCallback
Especifica la rutina de devolución de llamada que se invocará siempre que cambie el valor del recurso XmNposition mediante el uso de las flechas del spinner. XmNvalueChangedCallback pasa la estructura XmSimpleSpinBoxCallbackStruct call_data.

Información de Devolución de Llamada

Se pasa un puntero a la siguiente estructura a cada devolución de llamada de XmSimpleSpinBox:

typedef struct {
        int             reason;
        XEvent          *event;
        Widget          widget;
        Boolean doit;
        int             position;
        XmString        value;
        Boolean crossed_boundary;
} XmSimpleSpinBoxCallbackStruct;

El argumento reason indica por qué se invocó la devolución de llamada. Hay tres razones posibles para que se emita esta devolución de llamada. La razón es XmCR_OK cuando esta es la primera llamada a la devolución de llamada al principio de un giro o si es una activación única de las flechas del spinner. Si el XmSimpleSpinBox está en proceso de girar continuamente, entonces la razón será XmCR_SPIN_NEXT o XmCR_SPIN_PRIOR, dependiendo de la flecha que esté girando.

El argumento event apunta a la XEvent que activó la devolución de llamada. Puede ser NULL cuando el XmSimpleSpinBox está girando continuamente.

DESCRIPTION

The XmSimpleSpinBoxAddItem routine adds a new item to the SpinBox widget at the specified position. If position is -1, the item is added to the end of the list.

The XmSimpleSpinBoxDeletePos routine deletes the item at the specified position.

The XmSimpleSpinBoxSetItem routine sets the current item to the item at the specified position.

The XmSimpleSpinBoxGetItem routine returns the position of the current item.

The XmSpinBoxCallbackStruct structure is used for callbacks.

The reason argument indicates why the callback was invoked. It can be either XmCR_VALUE_CHANGED or XmCR_INCREMENT.

The event argument points to the X event that caused the callback to be invoked.

The argument is the widget identifier for the simple spin box widget that has been affected by this callback.

The doit argument is set only when the call_data comes from the XmNmodifyVerifyCallback. It indicates that the action that caused the callback to be called should be performed. The action is not performed if doit is set to False.

The position argument is the new value of the XmNposition resource as a result of the spin.

The value argument is the new XmString value displayed in the Text widget as a result of the spin. The application must copy this string if it is used beyond the scope of the call_data structure.

The crossed_boundary argument is True when the spinbox cycles. This is the case when a XmNspinBoxChildType of XmSTRING wraps from the first item to the last or the last item to the first. In the case of the XmNspinBoxChildType of XmNUMERIC, the boundary is crossed when the XmSimpleSpinBox cycles from the maximum value to the minimum or vice versa.

ERRORS/WARNINGS

The toolkit will display a warning if the application tries to set the value of the XmNtextField resource, which is read-only (marked G in the resource table).
