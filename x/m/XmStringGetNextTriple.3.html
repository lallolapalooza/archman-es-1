Licencias: LGPL-2.1-or-later

XmStringGetNextTriple(llamada a biblioteca) XmStringGetNextTriple(llamada a biblioteca)

NOMBRE

XmStringGetNextTriple — Una función XmString que devuelve el tipo, la longitud y el valor del siguiente componente en la cadena compuesta

SINOPSIS

#include <Xm/Xm.h>
XmStringComponentType XmStringGetNextTriple(
XmStringContext context,
unsigned int *length,
XtPointer *value);

DESCRIPCIÓN

XmStringGetNextTriple devuelve el tipo, la longitud y el valor del siguiente componente en la cadena compuesta identificada por context. Esta función devuelve un componente a la vez.

context
Especifica la estructura de contexto de cadena que fue asignada por la función XmStringInitContext.
length
Especifica un puntero a la longitud del valor del componente devuelto.
value
Especifica un puntero al valor del componente devuelto. Si el valor devuelto no es NULL, la función asigna espacio para contener el valor devuelto. Cuando la aplicación ya no necesita la cadena compuesta devuelta, la aplicación debería llamar a XtFree.

DEVOLUCIÓN

Devuelve el tipo del componente encontrado. Consulte la página de referencia de XmStringComponentType(3) para obtener una lista de tipos de componentes.

RELACIONADO

XmDirection(3), XmString(3), XmStringComponentType(3), XmStringGetNextComponent(3), y XmStringPeekNextTriple(3).
