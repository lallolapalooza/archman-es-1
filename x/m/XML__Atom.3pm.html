NOMBRE

XML::Atom - Implementación de feed y API de Atom

SINOPSIS

use XML::Atom;

DESCRIPCIÓN

Atom es un formato de sindicación, API y archivo para weblogs y otros datos. XML::Atom implementa el formato de feed así como un cliente para la API.
