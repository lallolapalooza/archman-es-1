XML::LibXML::ErrNo(3) Documentación de Perl aportada por el usuario XML::LibXML::ErrNo(3)

NOMBRE

XML::LibXML::ErrNo - Errores estructurados

DESCRIPCIÓN

Este módulo se basa en el archivo de cabecera C xmlerror.h de libxml2. Define constantes simbólicas para todos los códigos de error de libxml2. Actualmente, libxml2 utiliza más de 480 códigos de error diferentes. Ver también XML::LibXML::Error.
