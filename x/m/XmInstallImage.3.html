XmInstallImage(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmInstallImage(llamada a biblioteca) XmInstallImage(llamada a biblioteca)

NOMBRE

XmInstallImage — Una función de caché de pixmaps que añade una imagen a la caché de imágenes

SINOPSIS

#include <Xm/Xm.h>
Boolean XmInstallImage(
XImage * image,
char * image_name);

DESCRIPCIÓN

XmInstallImage almacena una imagen en una caché de imágenes que posteriormente puede ser utilizada para generar un pixmap. Parte del proceso de instalación es extender el convertidor de recursos utilizado para hacer referencia a estas imágenes. Al convertidor de recursos se le da el nombre de la imagen para que la imagen pueda ser referenciada en un archivo .Xdefaults. Dado que un widget puede hacer referencia a una imagen a través de sus recursos de pixmap, es responsabilidad de la aplicación asegurarse de que la imagen se instale antes de que se cree el widget.

image
Puntero a la estructura de imagen a instalar. El proceso de instalación no realiza una copia local de la imagen. Por lo tanto, la aplicación no debe destruir la imagen hasta que se desinstale de las funciones de caché.
image_name
Especifica una cadena que la aplicación utiliza para nombrar la imagen. Después de la instalación, este nombre se puede usar en .Xdefaults para referenciar la imagen. Las funciones de caché de imágenes crean una copia local del nombre.

Las funciones de caché de imágenes proporcionan un conjunto de ocho imágenes preinstaladas. Estos nombres se pueden utilizar dentro de un archivo .Xdefaults para generar pixmaps para el recurso para el que se proporcionan.

Nombre de la imagen Descripción
background Un mosaico de fondo sólido
25_foreground Un mosaico del 25% de primer plano, 75% de fondo
50_foreground Un mosaico del 50% de primer plano, 50% de fondo
75_foreground Un mosaico del 75% de primer plano, 25% de fondo
horizontal Un mosaico de líneas horizontales de los dos colores
vertical Un mosaico de líneas verticales de los dos colores
slant_right Un mosaico de líneas inclinadas de los dos colores
slant_left Un mosaico de líneas inclinadas de los dos colores
menu_cascade Un mosaico de una flecha del color de primer plano
menu_checkmark Un mosaico de una marca de verificación del color de primer plano
menu_dash Un mosaico de una línea horizontal del color de primer plano

RETORNO

Devuelve True si tiene éxito; devuelve False si se usa NULL image, NULL image_name, o un image_name duplicado como valor de parámetro.

RELACIONADO

XmUninstallImage(3), XmGetPixmap(3), y XmDestroyPixmap(3).
