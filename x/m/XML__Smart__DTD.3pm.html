XML::Smart::DTD(3) Documentación de Perl contribuida por el usuario XML::Smart::DTD(3)

NOMBRE

XML::Smart::DTD - Analizador de DTD para XML::Smart.

DESCRIPCIÓN

Esto analizará la DTD y proporcionará métodos para acceder a la información almacenada en la DTD.

USO

use XML::Smart::DTD ;
my $dtd = XML::Smart::DTD->new('some.dtd') ;

if ( $dtd->child_exists('tag1','subtag1') ) {
...
}
use Data::Dumper ;
print Dumper( $dtd->tree ) ;

new

MÉTODOS

attr_exists ( TAG , ATTR )

Devuelve *TRUE* si el atributo existe en el elemento TAG.

child_exists ( TAG , CHILD )

Devuelve *TRUE* si el hijo existe en el elemento TAG.

elem_exists ( TAG )

Devuelve *TRUE* si el elemento TAG existe.

error

Devuelve la lista de errores.

get_attr_def ( TAG , ATTR )

Devuelve el valor por defecto de un atributo.

get_attr_type ( TAG , ATTR )

Devuelve el tipo de atributo.

get_attr_values ( TAG , ATTR )

Devuelve los valores definidos de un atributo.

get_attrs ( TAG )

Devuelve la lista de atributos de un elemento.

get_attrs_req ( TAG )

Devuelve la lista de atributos requeridos de un elemento.

get_childs ( TAG )

Devuelve la lista de hijos de un elemento.

get_childs_req ( TAG )

Devuelve la lista de hijos requeridos de un elemento.

get_elem_opt ( TAG )

Devuelve la opción de ocurrencia de un elemento:

!  REQUERIDO Y ÚNICA COINCIDENCIA
+  1 o más
*  0 o más
?  0 o 1

get_elem_child_opt ( TAG , CHILD )

Igual que get_elem_opt() pero este elemento como hijo de un elemento.

is_attr_fix ( TAG , ATTR )

Devuelve *TRUE* si un atributo es *FIXED*.

is_attr_req ( TAG , ATTR )

Devuelve *TRUE* si un atributo es *REQUIRED*.

is_elem_any ( TAG )

Devuelve *TRUE* si un elemento es *ANY*.

is_elem_child_multi ( TAG , CHILD )

Devuelve *TRUE* si un elemento puede tener múltiples ocurrencias como hijo de TAG.

is_elem_child_opt ( TAG , CHILD )

Devuelve *TRUE* si un elemento es opcional como hijo de TAG.

is_elem_child_req ( TAG , CHILD )

Devuelve *TRUE* si un elemento es opcional como hijo de TAG.

is_elem_child_uniq ( TAG , CHILD )

Devuelve *TRUE* si un elemento es requerido y único como hijo de TAG.

is_elem_pcdata ( TAG )

Devuelve *TRUE* si un elemento es *PCDATA* (tiene contenido).

is_elem_empty ( TAG )

Devuelve *TRUE* si un elemento está *VACÍO* (no tiene atributos, contenido ni hijos).

is_elem_multi ( TAG )

Devuelve *TRUE* si un elemento puede tener múltiples ocurrencias globalmente.

is_elem_opt ( TAG )

Devuelve *TRUE* si un elemento es opcional globalmente.

is_elem_parent ( TAG , @PARENTS )

Devuelve *TRUE* si la lista de @PARENTS puede ser padre del elemento TAG.

is_elem_req

Devuelve *TRUE* si un elemento es requerido globalmente.

is_elem_uniq

Devuelve *TRUE* si un elemento es único y requerido globalmente.

root

Devuelve el nombre raíz de la DTD.

tree

Devuelve el árbol HASH de la DTD.
