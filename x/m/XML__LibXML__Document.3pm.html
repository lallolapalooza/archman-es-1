DESCRIPCIÓN

La clase Document es, en la mayoría de los casos, el resultado de un proceso de análisis. Pero a veces es necesario crear un Documento desde cero. La clase DOM Document proporciona funciones que se ajustan al estilo de nomenclatura DOM Core.

Hereda todas las funciones de XML::LibXML::Node, según lo especificado en la especificación DOM Core. Esto permite el acceso a los nodos además del elemento raíz a nivel de documento; por ejemplo, una "DTD". El soporte para estos nodos es limitado en este momento.

Si bien, en general, los nodos están vinculados a un documento en el concepto DOM, se sugiere que siempre se cree un nodo no vinculado a ningún documento. No hay necesidad de incluir realmente el nodo en el documento, pero una vez que el nodo está vinculado a un documento, es bastante seguro que todas las cadenas tendrán la codificación correcta. Si se crea un nodo de texto no vinculado con una cadena codificada en ISO (por ejemplo, con $CLASS->new()), la función "toString" puede no devolver el resultado esperado.

Para evitar tales problemas, se recomienda pasar todos los datos a los métodos de XML::LibXML como cadenas de caracteres (es decir, codificadas en UTF-8, con la bandera UTF8 activada).

MÉTODOS

Muchas de las funciones que se enumeran aquí están ampliamente documentadas en la especificación DOM Level 3 (http://www.w3.org/TR/DOM-Level-3-Core/). Por favor, consulte la especificación para obtener documentación exhaustiva.

new
$dom = XML::LibXML::Document->new( $version, $encoding );

alias de createDocument()

createDocument
$dom = XML::LibXML::Document->createDocument( $version, $encoding );

El constructor para la clase de documento. Como parámetro toma la cadena de versión y (opcionalmente) la cadena de codificación. Simplemente llamando a createDocument() se creará el documento:

<?xml version="tu versión" encoding="tu codificación"?>

Ambos parámetros son opcionales. El valor predeterminado para $version es 1.0, por supuesto. Si el parámetro $encoding no se establece, la codificación quedará sin establecer, lo que implica UTF-8.

La llamada a createDocument() sin ningún parámetro resultará en el siguiente código:

<?xml version="1.0"?>

Alternativamente, se puede llamar a este constructor directamente desde el nivel de clase de XML::LibXML, para evitar escribir mucho. Esto no tendrá ningún efecto en la instancia de la clase, que siempre es XML::LibXML::Document.

my $document = XML::LibXML->createDocument( "1.0", "UTF-8" );

es, por lo tanto, un atajo para

my $document = XML::LibXML::Document->createDocument( "1.0", "UTF-8" );
URI
$strURI = $doc->URI();

Devuelve la URI (o nombre de archivo) del documento original. Para documentos obtenidos analizando una cadena de un FH sin usar el argumento de análisis de URI de la función correspondiente de "parse_*", el resultado es una cadena generada unknown-XYZ donde XYZ es algún número; para documentos creados con el constructor "new", la URI no está definida.

El valor puede ser modificado llamando al método "setURI" en el nodo del documento.

setURI
$doc->setURI($strURI);

Establece la URI del documento informada por el método URI (ver también el argumento URI en las diversas funciones "parse_*").

encoding
$strEncoding = $doc->encoding();

devuelve la cadena de codificación del documento.

my $doc = XML::LibXML->createDocument( "1.0", "ISO-8859-15" );
print $doc->encoding; # imprime ISO-8859-15
actualEncoding
$strEncoding = $doc->actualEncoding();

devuelve la codificación en la que se devolverá el XML por $doc->toString(). Esta es generalmente la codificación original del documento tal como se declara en la declaración XML y se devuelve por $doc->encoding. Si la codificación original no se conoce (por ejemplo, si se creó en memoria o se analizó a partir de un XML sin una codificación declarada), se devuelve 'UTF-8'.

my $doc = XML::LibXML->createDocument( "1.0", "ISO-8859-15" );
print $doc->encoding; # imprime ISO-8859-15
setEncoding
$doc->setEncoding($new_encoding);

Este método permite cambiar la declaración de codificación en la declaración XML del documento. El valor también afecta a la codificación en la que se serializa el documento a XML mediante $doc->toString(). Usa setEncoding() para eliminar la declaración de codificación.

version
$strVersion = $doc->version();

devuelve la cadena de versión del documento

getVersion() es una forma alternativa de esta función.

standalone
$doc->standalone

Esta función devuelve el valor numérico del atributo independiente (standalone) de las declaraciones XML de un documento. Devuelve 1 si se encontró standalone="yes", 0 si se encontró standalone="no" y -1 si standalone no se especificó (predeterminado en la creación).

setStandalone
$doc->setStandalone($numvalue);

Este método permite establecer el atributo standalone="yes" o standalone="no" del documento. $numvalue debe ser 1 o 0.

compression
my $compression = $doc->compression;

Devuelve el nivel de compresión de la salida (si se está comprimiendo).

setCompression
$doc->setCompression($ziplevel);

Establece el nivel de compresión de la salida. Un valor de 0 deshabilita la compresión (predeterminado).

toString
$docstring = $dom->toString($format);

Serializa el documento DOM en una cadena. El parámetro $format es opcional y se usa para especificar si la salida debe estar formateada (con sangría). Si se omite o es 0, la salida no estará formateada. Si se especifica como 1, la salida estará formateada.

toStringC14N
$c14nstr = $doc->toStringC14N($comment_flag, $xpath [, $xpath_context ]);

Serializa el documento usando la canonización XML (C14N). El parámetro $comment_flag es un valor booleano que indica si se deben incluir los comentarios en la salida (1 para incluir, 0 para omitir). El parámetro $xpath es una cadena XPath opcional para seleccionar subconjuntos del documento a canonizar. $xpath_context es un contexto XPath opcional.

toStringEC14N
$ec14nstr = $doc->toStringEC14N($comment_flag, $xpath [, $xpath_context ], $inclusive_prefix_list);

Serializa el documento usando la canonización XML exclusiva (EC14N). Consulta la documentación de XML::LibXML::Node::toStringEC14N para obtener más detalles.

serialize
$str = $doc->serialize($format);

Alias de toString().

toFile
$state = $doc->toFile($filename, $format);

Serializa el documento DOM a un archivo. El parámetro $format es opcional y se usa para especificar si la salida debe estar formateada (con sangría). Devuelve 1 en caso de éxito, 0 en caso contrario.

toFH
$state = $doc->toFH($fh, $format);

Serializa el documento DOM a un manejador de archivos (file handle). El parámetro $format es opcional y se usa para especificar si la salida debe estar formateada (con sangría). Devuelve 1 en caso de éxito, 0 en caso contrario.

toStringHTML
$str = $document->toStringHTML();

Serializa el documento DOM como HTML. Es similar a toString() pero está optimizado para HTML.

serialize_html
$str = $document->serialize_html();

Alias de toStringHTML().

is_valid
$bool = $dom->is_valid();

Comprueba si el documento es válido según su DTD. Devuelve verdadero si es válido, falso en caso contrario.

validate
$dom->validate();

Valida el documento DOM según su DTD. Si no es válido, genera una excepción.

documentElement
$root = $dom->documentElement();

Devuelve el nodo raíz del documento.

setDocumentElement
$dom->setDocumentElement( $root );

Establece el nodo raíz del documento. El nodo proporcionado debe ser un nodo de tipo Element.

createElement
$element = $dom->createElement( $nodename );

Crea un nodo de elemento con el nombre de nodo dado.

createElementNS
$element = $dom->createElementNS( $namespaceURI, $nodename );

Crea un nodo de elemento con el URI de espacio de nombres y el nombre de nodo dados.

createTextNode
$text = $dom->createTextNode( $content_text );

Crea un nodo de texto con el contenido de texto dado.

createComment
$comment = $dom->createComment( $comment_text );

Crea un nodo de comentario con el texto del comentario dado.

createAttribute
$attrnode = $doc->createAttribute($name [,$value]);

Crea un nodo de atributo con el nombre dado. Opcionalmente, se puede proporcionar un valor.

createAttributeNS
$attrnode = $doc->createAttributeNS( namespaceURI, $name [,$value] );

Crea un nodo de atributo con el URI de espacio de nombres y el nombre dados. Opcionalmente, se puede proporcionar un valor.

createDocumentFragment
$fragment = $doc->createDocumentFragment();

Crea un fragmento de documento.

createCDATASection
$cdata = $dom->createCDATASection( $cdata_content );

Crea una sección CDATA con el contenido CDATA dado.

createProcessingInstruction
my $pi = $doc->createProcessingInstruction( $target, $data );

Crea una instrucción de procesamiento con el objetivo y los datos dados.

createEntityReference
my $entref = $doc->createEntityReference($refname);

Crea una referencia a una entidad con el nombre de referencia dado.

createInternalSubset
$dtd = $document->createInternalSubset( $rootnode, $public, $system);

Crea un subconjunto interno DTD para el documento.

createExternalSubset
$dtd = $document->createExternalSubset( $rootnode_name, $publicId, $systemId);

Crea un subconjunto externo DTD para el documento.

importNode
$document->importNode( $node );

Importa un nodo de otro documento a este documento. El nodo importado no estará vinculado a su documento original.

adoptNode
$document->adoptNode( $node );

Adopta un nodo de otro documento. El nodo se elimina de su documento original y se vincula a este documento.

externalSubset
my $dtd = $doc->externalSubset;

Devuelve el nodo DTD del subconjunto externo, si existe.

internalSubset
my $dtd = $doc->internalSubset;

Devuelve el nodo DTD del subconjunto interno, si existe.

setExternalSubset
$doc->setExternalSubset($dtd);

Establece el subconjunto externo DTD del documento. El nodo DTD proporcionado debe haber sido creado por este documento o importado previamente.

setInternalSubset
$doc->setInternalSubset($dtd);

Establece el subconjunto interno DTD del documento. El nodo DTD proporcionado debe haber sido creado por este documento o importado previamente.

removeExternalSubset
my $dtd = $doc->removeExternalSubset();

Elimina el subconjunto externo DTD del documento y lo devuelve.

removeInternalSubset
my $dtd = $doc->removeInternalSubset();

Elimina el subconjunto interno DTD del documento y lo devuelve.

getElementsByTagName
my @nodelist = $doc->getElementsByTagName($tagname);

Devuelve una lista de todos los nodos de elementos que tienen el nombre de etiqueta dado en el documento.

getElementsByTagNameNS
my @nodelist = $doc->getElementsByTagNameNS($nsURI,$tagname);

Devuelve una lista de todos los nodos de elementos que tienen el URI de espacio de nombres y el nombre de etiqueta dados en el documento.

getElementsByLocalName
my @nodelist = $doc->getElementsByLocalName($localname);

Devuelve una lista de todos los nodos de elementos que tienen el nombre de etiqueta local dado en el documento.

getElementById
my $node = $doc->getElementById($id);

Devuelve el nodo de elemento que tiene el ID dado en el documento.

indexElements
$dom->indexElements();

Indexa los elementos del documento por su atributo ID. Esto mejora el rendimiento de las llamadas posteriores a getElementById().

setStandalone
$doc->setStandalone($numvalue);

A través de este método es posible modificar el valor del atributo standalone de un documento. Establécelo a 1 para establecer standalone="yes", a 0 para establecer standalone="no", o a -1 para eliminar el atributo standalone de la declaración XML.

compression
my $compression = $doc->compression;

libxml2 permite leer documentos directamente desde archivos comprimidos con gzipped. En este caso, la variable compression se establece al nivel de compresión de ese archivo (0-8). Si XML::LibXML analizó una fuente diferente o el archivo no estaba comprimido, el valor devuelto será -1.

setCompression
$doc->setCompression($ziplevel);

Si se pretende escribir el documento directamente a un archivo, es posible establecer el nivel de compresión para un documento dado. Este nivel puede estar en el rango de 0 a 8. Si XML::LibXML no debe intentar comprimir, usa -1 (por defecto).

Ten en cuenta que esta característica solo funcionará si libxml2 está compilado con soporte zlib y se utiliza toFile() para la salida.

toString
$docstring = $dom->toString($format);

toString es una función de serialización DOM, por lo que el árbol DOM se serializa en una cadena XML, lista para su salida.

IMPORTANTE: a diferencia de toString para otros nodos, en los nodos de documento esta función devuelve el XML como una cadena de bytes en la codificación original del documento (¡ver el método actualEncoding()!). Esto significa que puedes hacer simplemente:

open my $out_fh, '>', $file;
print {$out_fh} $doc->toString;

independientemente de la codificación real del documento. Ver la sección sobre codificaciones en XML::LibXML para más detalles.

El parámetro opcional $format establece la indentación de la salida. Se espera que este parámetro sea un valor "integer", que especifica que se debe utilizar la indentación. El parámetro format puede tener tres valores diferentes si se utiliza:

Si $format es 0, entonces el documento se vuelca tal como se analizó originalmente.

Si $format es 1, libxml2 agregará espacios en blanco ignorables, por lo que el contenido de los nodos es más fácil de leer. Los nodos de texto existentes no se modificarán.

Si $format es 2 (o superior), libxml2 actuará como $format == 1, pero agregará un salto de línea inicial y final a cada nodo de texto.

libxml2 utiliza una indentación codificada de 2 caracteres de espacio por nivel de indentación. Este valor no se puede modificar en tiempo de ejecución.

toStringC14N
$c14nstr = $doc->toStringC14N($comment_flag, $xpath [, $xpath_context ]);

Ver la documentación en XML::LibXML::Node.

toStringEC14N
$ec14nstr = $doc->toStringEC14N($comment_flag, $xpath [, $xpath_context ], $inclusive_prefix_list);

Ver la documentación en XML::LibXML::Node.

serialize
$str = $doc->serialize($format);

Un alias para toString(). Esta función se nombró para ser más consistente con libxml2.

serialize_c14n
Un alias para toStringC14N().
serialize_exc_c14n
Un alias para toStringEC14N().
toFile
$state = $doc->toFile($filename, $format);

Esta función es similar a toString(), pero escribe el documento directamente en el sistema de archivos. Esta función es muy útil si se necesitan almacenar documentos grandes.

El parámetro format tiene el mismo comportamiento que en toString().

toFH
$state = $doc->toFH($fh, $format);

Esta función es similar a toString(), pero escribe el documento directamente en un manejador de archivos o un stream. Se pasa un stream de bytes en la codificación del documento al manejador de archivos. ¡NO apliques ninguna capa PerlIO de :encoding(...) o ":utf8" al manejador de archivos! Ver la sección sobre codificaciones en XML::LibXML para más detalles.

El parámetro format tiene el mismo comportamiento que en toString().

toStringHTML
$str = $document->toStringHTML();

toStringHTML serializa el árbol a una cadena de bytes en la codificación del documento como HTML. Con este método, la indentación es automática y gestionada internamente por libxml2. Ten en cuenta que la cadena debe contener <meta http-equiv="Content-Type" content="text/html; charset=utf-8"> (en lugar del más nuevo <meta charset="utf-8">), de lo contrario, todos los caracteres no ASCII se convertirán en entidades.

serialize_html
$str = $document->serialize_html();

Un alias para toStringHTML().

is_valid
$bool = $dom->is_valid();

Devuelve TRUE o FALSE dependiendo de si el árbol DOM es un Documento válido o no.

También puedes pasar un objeto XML::LibXML::Dtd para validar contra un DTD externo:

if (!$dom->is_valid($dtd)) {
     warn("document is not valid!");
 }
validate
$dom->validate();

Este es un equivalente que lanza excepciones de is_valid. Si el documento no es válido, lanzará una excepción que contiene el error. Esto te permite una mejor presentación de errores que simplemente is_valid o no.

De nuevo, puedes pasar un objeto DTD.

documentElement
$root = $dom->documentElement();

Devuelve el elemento raíz del Documento. Un documento puede tener solo un elemento raíz para contener los datos del documento.

Opcionalmente, se puede usar getDocumentElement.

setDocumentElement
$dom->setDocumentElement( $root );

Esta función te permite establecer el elemento raíz para un documento. La función admite la importación de un nodo de un árbol de documento diferente, pero no admite un fragmento de documento como $root.

createElement
$element = $dom->createElement( $nodename );

Esta función crea un nuevo Nodo de Elemento vinculado al DOM con el nombre $nodename.

createElementNS
$element = $dom->createElementNS( $namespaceURI, $nodename );

Esta función crea un nuevo Nodo de Elemento vinculado al DOM con el nombre $nodename y ubicado en el espacio de nombres dado.

createTextNode
$text = $dom->createTextNode( $content_text );

Como equivalente de createElement, pero crea un Nodo de Texto vinculado al DOM.

createComment
$comment = $dom->createComment( $comment_text );

Como equivalente de createElement, pero crea un Nodo de Comentario vinculado al DOM.

createAttribute
$attrnode = $doc->createAttribute($name [,$value]);

Crea un nuevo nodo de Atributo.

createAttributeNS
$attrnode = $doc->createAttributeNS( namespaceURI, $name [,$value] );

Crea un Atributo vinculado a un espacio de nombres.

createDocumentFragment
$fragment = $doc->createDocumentFragment();

Esta función crea un DocumentFragment.

createCDATASection
$cdata = $dom->createCDATASection( $cdata_content );

Similar a createTextNode y createComment, esta función crea una Sección CData vinculada al DOM actual.

createProcessingInstruction
my $pi = $doc->createProcessingInstruction( $target, $data );

Crea un nodo de instrucción de procesamiento.

Dado que este método es bastante largo, se puede usar su forma corta createPI().

createEntityReference
my $entref = $doc->createEntityReference($refname);

Si un documento tiene un DTD especificado, se pueden crear referencias de entidad utilizando esta función. Si se desea agregar una referencia de entidad al documento, esta referencia debe ser creada por esta función.

Una referencia de entidad es única para un documento y no puede ser pasada a otros documentos como se pueden pasar otros nodos.

NOTA: Un contenido de texto que contenga algo que parezca una referencia de entidad, no se expandirá a una referencia de entidad real a menos que sea una entidad predefinida.

my $string = "&foo;";
 $some_element->appendText( $string );
 print $some_element->textContent; # imprime "&amp;foo;"
createInternalSubset
$dtd =
$document->createInternalSubset( $rootnode, $public, $system);

Esta función crea y agrega un subconjunto interno al documento dado. Dado que la función agrega automáticamente el DTD al documento, no es necesario agregar el nodo creado explícitamente al documento.

my $document = XML::LibXML::Document->new();
 my $dtd      = $document->createInternalSubset( "foo", undef, "foo.dtd" );

dará como resultado el siguiente documento XML:

<?xml version="1.0"?>
 <!DOCTYPE foo SYSTEM "foo.dtd">

Al establecer el parámetro público, es posible establecer DTDs PÚBLICAS para un documento dado. Así que

my $document = XML::LibXML::Document->new();
my $dtd      = $document->createInternalSubset( "foo", "-//FOO//DTD FOO 0.1//EN", undef );

provocará que la siguiente declaración se cree en el documento:

<?xml version="1.0"?>
<!DOCTYPE foo PUBLIC "-//FOO//DTD FOO 0.1//EN">
createExternalSubset
$dtd = $document->createExternalSubset( $rootnode_name, $publicId, $systemId);

Esta función es similar a createInternalSubset() pero este DTD se considera externo y, por lo tanto, no se agrega al documento en sí. Sin embargo, puede usarse para fines de validación.

importNode
$document->importNode( $node );

Si un nodo no forma parte de un documento, puede ser importado a otro documento. Como se especifica en la Especificación DOM Nivel 2, el nodo no se alterará ni se eliminará de su documento original (se llamará implícitamente a "$node->cloneNode(1)").

NOTA: No intente usar importNode() para importar subárboles que contengan referencias a entidades, incluso si la referencia a la entidad es el nodo raíz del subárbol. Esto causará graves problemas a su programa. Esta es una limitación de libxml2 y no de XML::LibXML en sí.

adoptNode
$document->adoptNode( $node );

Si un nodo no forma parte de un documento, puede ser importado a otro documento. Como se especifica en la Especificación DOM Nivel 3, el nodo no se alterará, pero se eliminará de su documento original.

Después de que un documento adopta un nodo, el nodo, sus atributos y todos sus descendientes pertenecen al nuevo documento. Dado que el nodo no pertenece al documento antiguo, primero se desvinculará de su ubicación anterior.

NOTA: No intente adoptNode() para importar subárboles que contengan referencias a entidades, incluso si la referencia a la entidad es el nodo raíz del subárbol. Esto causará graves problemas a su programa. Esta es una limitación de libxml2 y no de XML::LibXML en sí.

externalSubset
my $dtd = $doc->externalSubset;

Si un documento tiene un subconjunto externo definido, será devuelto por esta función.

NOTA Los nodos Dtd no son nodos ordinarios en libxml2. El soporte para estos nodos en XML::LibXML todavía es limitado. En particular, es posible que no desee usar funciones de nodo comunes en nodos de declaración doctype.

internalSubset
my $dtd = $doc->internalSubset;

Si un documento tiene un subconjunto interno definido, será devuelto por esta función.

NOTA Los nodos Dtd no son nodos ordinarios en libxml2. El soporte para estos nodos en XML::LibXML todavía es limitado. En particular, es posible que no desee usar funciones de nodo comunes en nodos de declaración doctype.

setExternalSubset
$doc->setExternalSubset($dtd);

¡EXPERIMENTAL!

Este método establece un nodo DTD como un subconjunto externo del documento dado.

setInternalSubset
$doc->setInternalSubset($dtd);

¡EXPERIMENTAL!

Este método establece un nodo DTD como un subconjunto interno del documento dado.

removeExternalSubset
my $dtd = $doc->removeExternalSubset();

¡EXPERIMENTAL!

Si un documento tiene un subconjunto externo definido, puede ser eliminado del documento usando esta función. Se devolverá el nodo dtd eliminado.

removeInternalSubset
my $dtd = $doc->removeInternalSubset();

Si un documento tiene un subconjunto interno definido, puede ser eliminado del documento usando esta función. Se devolverá el nodo dtd eliminado.

getElementById
my $node = $doc->getElementById($id);

Devuelve el elemento que tiene un atributo ID con el valor dado. Si no existe tal elemento, devuelve undef.

Nota: el ID de un elemento puede cambiar mientras se manipula el documento. Para documentos con un DTD, la información sobre los atributos ID solo está disponible si se ha solicitado la carga/validación del DTD. Para documentos HTML analizados con el analizador HTML, la detección de ID se realiza automáticamente. En documentos XML, todos los atributos "xml:id" se consideran de tipo ID. Puede probar la ID de un nodo de atributo con $attr->isId().

En las versiones 1.59 y anteriores, esta función se llamaba getElementsById() (en plural) por error. A partir de la 1.60, este nombre se mantiene como un alias solo por compatibilidad con versiones anteriores.

indexElements
$dom->indexElements();

Esta función hace que libxml2 marque todos los elementos de un documento con su índice de posición de documento, lo que acelera considerablemente las consultas XPath para documentos grandes. Solo debe usarse con documentos estáticos que no se modificarán más mediante ningún método DOM, ya que una vez que un documento está indexado, XPath siempre preferirá el índice a otros métodos de determinación del orden de los nodos en el documento. Por lo tanto, XPath podría devolver listas de nodos desordenadas incorrectamente cuando se aplica a un documento que ha sido modificado después de ser indexado. Por supuesto, es posible usar este método para reindexar un documento modificado antes de volver a usarlo con XPath. Esta función no forma parte de la especificación DOM.

Esta función devuelve el número de elementos indexados, -1 si ocurrió un error, o -2 si esta característica no está disponible en la versión de libxml2 en ejecución.
