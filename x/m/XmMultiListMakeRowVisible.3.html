NOMBRE

XmMultiListMakeRowVisible — Una función de MultiList que desplaza las filas visibles de la lista según sea necesario

SINOPSIS

#include <Xm/MultiList.h>
void XmMultiListMakeRowVisible(
Widget widget,
int row);

DESCRIPCIÓN

XmMultiListMakeRowVisible hace visible la fila especificada.

widget
Especifica el ID del widget MultiList de cuya lista se selecciona un elemento.
row
Especifica el número de fila (empezando desde 0) que será visible en el widget MultiList.

Para una definición completa de MultiList y sus recursos asociados, consulte XmMultiList(3).
