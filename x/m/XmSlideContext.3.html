NOMBRE

XmSlideContext - Clase de widget SlideContext

SINOPSIS

#include <Xm/SlideC.h>

DESCRIPCIÓN


SlideContext se puede utilizar para cambiar la geometría de un widget a lo largo del tiempo.

Clases

SlideContext hereda el comportamiento y los recursos de la clase Object.

El puntero de clase es XmSlideContextWidgetClass.

El nombre de la clase es XmSlideContext.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widgets utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G) o no es aplicable (N/A).

Comportamiento

El comportamiento de XmSlideContext se describe a continuación: XmSlideContext instala un temporizador Xt que se llama cada XmNslideInterval milisegundos. En cada llamada del procedimiento del temporizador, la geometría de XmNslideWidget se ajusta de tal manera que X/Y/Ancho/Alto estén un 10 por ciento más cerca de los valores finales. El XmSlideContext se destruye automáticamente cuando XmNslideWidget alcanza su destino. Si XmNslideWidget se destruye antes de que termine la animación, el XmSlideContext se destruye.

Asociaciones Virtuales

Las asociaciones para teclas virtuales dependen del proveedor. Para obtener información sobre las asociaciones de botones y teclas virtuales, consulte VirtualBindings(3X).
