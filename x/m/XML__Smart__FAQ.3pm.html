¿Necesito instalar XML::Parser para poder usar XML::Smart?

¡No! XML::Smart ya viene con 2 analizadores independientes, XML::Smart::Parser y XML::Smart::HTMLParser.

Si se encuentra XML::Parser, XML::Smart lo usará por defecto, y las 2da opciones serán XML::Smart::Parser.

Tenga en cuenta que para un análisis complejo se recomienda XML::Parser, pero XML::Smart::Parser también funcionará bien.

¿Cuál es la mejor versión de XML::Smart para instalar?

¡Siempre es la última! Siempre eche un vistazo a las nuevas versiones antes de pedir ayuda sobre XML::Smart.

Tenga en cuenta que internamente XML::Smart es complejo, ya que la idea principal es eliminar la complejidad de las manos del programador. En realidad, la idea es permitir al programador de Perl usar y crear datos XML sin conocer realmente el formato XML.

¿Dónde puedo aprender sobre XML?

http://www.xml.com

¿Cómo aplicar un DTD a un árbol de objetos XML::Smart?

Eche un vistazo al método apply_dtd(). Ejemplo de uso:

$xml->apply_dtd(q`
<!DOCTYPE cds [
<!ELEMENT cds (album+)>
<!ATTLIST cds
          creator  CDATA
          date     CDATA #REQUIRED
>
<!ELEMENT album (artist , tracks+)>
<!ELEMENT artist (#PCDATA)>
<!ELEMENT tracks (#PCDATA)>
]>
`);

Esto formateará automáticamente elementos, atributos, etc...

¿Cómo funciona XML::Smart?

Para crear XML::Smart, primero creé el módulo Object::MultiType. Con él, puedes tener un objeto que funcione al mismo tiempo como HASH, ARRAY, SCALAR, CODE y GLOB. Así puedes hacer cosas como estas con el mismo objeto:

$obj = Object::MultiType->new() ;

$obj->{key} ;
$obj->[0] ;
$obj->method ;

@l = @{$obj} ;
%h = %{$obj} ;

&$obj(args) ;

print $obj "send data\n" ;

Parece una locura, y puede ser más si usas tie() dentro de él, y esto es lo que hace XML::Smart.

Para XML::Smart, el acceso en forma de HASH y ARRAY pasa por tie(). En otras palabras, tienes un HASH enlazado y un ARRAY enlazado dentro de él. Este HASH y ARRAY enlazados funcionan juntos, de modo que puedes acceder a una clave de HASH como el índice 0 de un ARRAY, o acceder a un índice 0 como la clave de HASH:

%hash = (
key => ['a','b','c']
) ;

$hash->{key}    ## devuelve $hash{key}[0]
$hash->{key}[0] ## devuelve $hash{key}[0]
$hash->{key}[1] ## devuelve $hash{key}[1]

## Inverso:

%hash = ( key => 'a' ) ;

$hash->{key}    ## devuelve $hash{key}
$hash->{key}[0] ## devuelve $hash{key}
$hash->{key}[1] ## devuelve undef

Lo mejor de este nuevo recurso es evitar accesos erróneos a los datos y advertencias cuando intentas acceder a un HASH que tiene un ARRAY (y viceversa). Algo que generalmente hace que el script muera().

Una vez que tienes un acceso fácil a los datos, ¡puedes usar el mismo recurso para crear datos! Por ejemplo:

## Datos anteriores:
<hosts>
  <server address="192.168.2.100" os="linux" type="conectiva" version="9.0"/>
</hosts>

## Ahora tienes {address} como una clave normal con una cadena dentro:
$XML->{hosts}{server}{address}

## Y para agregar una nueva dirección, ¡la clave {address} necesita ser una referencia ARRAY!
## Entonces, XML::Smart hace la conversión: ;-P
$XML->{hosts}{server}{address}[1] = '192.168.2.101' ;

## Agregar a una lista cuyo tamaño no conoces:
push(@{$XML->{hosts}{server}{address}} , '192.168.2.102') ;

## Los datos ahora:
<hosts>
  <server os="linux" type="conectiva" version="9.0"/>
    <address>192.168.2.100</address>
    <address>192.168.2.101</address>
    <address>192.168.2.102</address>
  </server>
</hosts>

Luego, después de cambiar tu árbol XML usando los recursos HASH y ARRAY, simplemente obtienes los datos rehechos (a través del árbol HASH dentro del objeto):

my $xmldata = $XML->data ;

Pero ten en cuenta que XML::Smart siempre devuelve un objeto! Incluso cuando obtienes una clave final. Así que esto en realidad devuelve otro objeto, apuntando (en su interior) a la clave:

$addr = $XML->{hosts}{server}{address}[0] ;

## Como $addr es un objeto puedes INTENTAR acceder a más datos:
$addr->{foo}{bar} ; ## Esto no genera advertencias! solo devuelve UNDEF.
## Pero también puedes usarlo como un SCALAR normal:
print "$addr\n" ;
$addr .= ':80' ; ## ¡Después de esto $addr ya no es un objeto, solo un SCALAR!

¿Cuando genero los datos XML, se añaden saltos de línea (\n) al contenido!

Deberías usar las opciones para el método data() y save() para no agregar indentación a los datos generados:

$XML->data( noident => 1 ) ;
## o mejor:
$XML->data( nospace => 1 ) ;
