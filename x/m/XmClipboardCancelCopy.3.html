NOMBRE

XmClipboardCancelCopy — Una función del portapapeles que cancela una copia al portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardCancelCopy (display, window, item_id)
        Display * display;
        Window  window;
        long    item_id;
(void)

DESCRIPCIÓN

XmClipboardCancelCopy cancela la copia al portapapeles que está en curso y libera el almacenamiento temporal. Cuando se va a realizar una copia, XmClipboardStartCopy asigna almacenamiento temporal para los datos del portapapeles. XmClipboardCopy copia los datos apropiados en el almacenamiento temporal. XmClipboardEndCopy copia los datos a la estructura del portapapeles y libera las estructuras de almacenamiento temporal. Si se llama a XmClipboardCancelCopy, no es necesario llamar a la función XmClipboardEndCopy. Una llamada a XmClipboardCancelCopy solo es válida después de una llamada a XmClipboardStartCopy.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llama.
item_id
Especifica el número asignado a este elemento de datos. Este número fue devuelto por una llamada anterior a XmClipboardStartCopy.

RETORNAR

XmClipboardSuccess
La función se realizó con éxito.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función nuevamente con los mismos parámetros hasta que desaparezca el bloqueo. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o renunciar a la operación.
XmClipboardFail
La función falló porque no se llamó a XmClipboardStartCopy o porque el elemento de datos contiene demasiados formatos.

RELACIONADO

XmClipboardCopy(3), XmClipboardEndCopy(3), y XmClipboardStartCopy(3).
