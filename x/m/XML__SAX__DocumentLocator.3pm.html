XML::SAX::DocumentLocator(3) Documentación de Perl contribuida por el usuario XML::SAX::DocumentLocator(3)

NOMBRE

XML::SAX::DocumentLocator - Clase auxiliar para localizadores de documentos

SINOPSIS

my $locator = XML::SAX::DocumentLocator->new(
    sub { $object->get_public_id },
    sub { $object->get_system_id },
    sub { $reader->current_line },
    sub { $reader->current_column },
    sub { $reader->get_encoding },
    sub { $reader->get_xml_version },
);

DESCRIPCIÓN

Este módulo te proporciona una referencia de hash vinculada que llama a los cierres especificados cuando se le solicitan PublicId, SystemId, LineNumber y ColumnNumber.

Es útil para escribir analizadores SAX para que no tengas que actualizar constantemente los números de línea en una referencia de hash en el objeto que pasas a set_document_locator(). Consulta el código fuente de XML::SAX::PurePerl para ver un ejemplo de uso.

API

Solo hay 1 método: "new". Simplemente pásale una lista de cierres que, al ser llamados, devolverán el PublicId, el SystemId, el LineNumber, el ColumnNumber, la Codificación y la XMLVersion respectivamente.

A los cierres se les pasa un solo parámetro, la clave que se está solicitando. Pero eres libre de ignorarlo.
