NOMBRE

XML::SAX2Perl -- traduce métodos SAX de estilo Java/CORBA a métodos Perl

SINOPSIS

use XML::SAX2Perl;
$sax2perl = XML::SAX2Perl(Handler => $mi_manejador);
$sax->setDocumentHandler($sax2perl);

DESCRIPCION

"XML::SAX2Perl" es un filtro SAX que traduce métodos SAX de estilo Java/CORBA a llamadas de métodos estilo Perl. Esta página de manual resume las opciones, manejadores y propiedades específicas soportadas por "XML::SAX2Perl"; por favor, consulte el estándar SAX de Perl "XML::SAX" para obtener información general de uso.

MÉTODOS

new
Crea un nuevo objeto analizador. Las opciones predeterminadas para el análisis, descritas a continuación, se pasan como pares clave-valor o como un solo hash. Las opciones pueden cambiarse directamente en el objeto analizador a menos que se indique lo contrario. Las opciones pasadas a `parse()' anulan las opciones predeterminadas en el objeto analizador durante la duración del análisis.
parse
Analiza un documento. Las opciones, descritas a continuación, se pasan como pares clave-valor o como un solo hash. Las opciones pasadas a `parse()' anulan las opciones predeterminadas en el objeto analizador.
location
Devuelve la ubicación como un hash: 
ColumnNumber    El número de columna del análisis.
LineNumber      El número de línea del análisis.
PublicId        Una cadena que contiene el identificador público, o undef
                si no hay ninguno disponible.
SystemId        Una cadena que contiene el identificador del sistema, o undef
                si no hay ninguno disponible.
Métodos de DocumentHandler SAX
Los siguientes son métodos de DocumentHandler que el analizador SAX 1.0 llamará y que "XML::SAX2Perl" traducirá a llamadas de métodos SAX de Perl. Consulte SAX 1.0 para obtener detalles. 
setDocumentLocator(locator)
startDocument()
endDocument()
startElement(name, atts)
endElement(name)
characters(ch, start, length)
ignorableWhitespace(ch, start, length)
processingInstruction(target, data)

OPCIONES

Las siguientes opciones son soportadas por "XML::SAX2Perl":

Handler          manejador predeterminado para recibir eventos
DocumentHandler  manejador para recibir eventos de documento
DTDHandler       manejador para recibir eventos DTD
ErrorHandler     manejador para recibir eventos de error
EntityResolver   manejador para resolver entidades
Locale           localización para proporcionar internacionalización para errores
Source           hash que contiene la fuente de entrada para el análisis

Si no se proporcionan manejadores, todos los eventos serán ignorados silenciosamente, excepto por `fatal_error()' que provocará una llamada a `die()' después de llamar a `end_document()'.

Si se pasa un único argumento de cadena al método `parse()', se trata como si se hubiera proporcionado una opción `"Source"' con un parámetro `"String"'.

El hash `"Source"' puede contener los siguientes parámetros:

ByteStream       El flujo de bytes crudos (identificador de archivo) que contiene
                 el documento.
String           Una cadena que contiene el documento.
SystemId         El identificador del sistema (URI) del documento.
PublicId         El identificador público.
Encoding         Una cadena que describe la codificación de caracteres.

Si se usan más de uno de `"ByteStream"', `"String"', o `"SystemId"', entonces la preferencia se da primero a `"ByteStream"', luego a `"String"', y finalmente a `"SystemId"'.

MANEJADORES

Los siguientes manejadores y propiedades son soportados por "XML::SAX2Perl":

DocumentHandler métodos

start_document
Recibe notificación del inicio de un documento. 
Locator          Un objeto que puede devolver la ubicación de cualquier evento
                 de documento SAX.
end_document
Recibe notificación del final de un documento.

No hay propiedades definidas.

start_element
Recibe notificación del inicio de un elemento. 
Name             El nombre del tipo de elemento.
Attributes       Atributos adjuntos al elemento, si los hay.

ADVERTENCIA ALFA: El valor de `"Attributes"' no se traduce desde el valor SAX 1.0, por lo que contendrá un objeto AttributeList.

end_element
Recibe notificación del final de un elemento. 
Name             El nombre del tipo de elemento.
characters
Recibe notificación de datos de caracteres. 
Data             Los caracteres del documento XML.
ignorable_whitespace
Recibe notificación de espacios en blanco ignorables en el contenido del elemento. 
Data             Los caracteres del documento XML.
processing_instruction
Recibe notificación de una instrucción de procesamiento. 
Target           El objetivo de la instrucción de procesamiento.
Data             Los datos de la instrucción de procesamiento, si los hay.
