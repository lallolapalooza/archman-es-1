NOMBRE

XmCvtXmStringToCT — Una función de cadena compuesta que convierte una cadena compuesta a texto compuesto

SINOPSIS

#include <Xm/Xm.h>
char * XmCvtXmStringToCT(
XmString string);

DESCRIPCIÓN

XmCvtXmStringToCT convierte una cadena compuesta a una cadena (char *) en formato de texto compuesto. La aplicación debe llamar a XtAppInitialize antes de llamar a esta función. El convertidor utiliza la etiqueta de la lista de fuentes asociada con un segmento de cadena compuesto dado para seleccionar un formato de texto compuesto para ese segmento. Un registro define un mapeo entre las etiquetas de la lista de fuentes y los formatos de codificación de texto compuesto. El convertidor utiliza el siguiente algoritmo para cada segmento de cadena compuesto:

1.
Si la etiqueta del segmento de cadena compuesto está mapeada a XmFONTLIST_DEFAULT_TAG en el registro, el convertidor pasa el texto del segmento de cadena compuesto a XmbTextListToTextProperty con un estilo de codificación de XCompoundTextStyle y utiliza el texto compuesto resultante para ese segmento.
2.
Si la etiqueta del segmento de cadena compuesto está mapeada a un charset registrado por MIT en el registro, el convertidor crea el texto compuesto para ese segmento utilizando el charset (del registro) y el texto del segmento de cadena compuesto, tal como se define en el estándar del X Consortium Compound Text Encoding.
3.
Si la etiqueta del segmento de cadena compuesto está mapeada a un charset en el registro que no es ni XmFONTLIST_DEFAULT_TAG ni un charset registrado por MIT, el convertidor crea el texto compuesto para ese segmento utilizando el charset (del registro) y el texto del segmento de cadena compuesto como un "segmento extendido" con un número variable de octetos por carácter.
4.
Si la etiqueta del segmento de cadena compuesto no está mapeada en el registro, el resultado depende de la implementación.
string
Especifica una cadena compuesta que se convertirá a texto compuesto.

DEVOLVER

Devuelve una cadena (char *) en formato de texto compuesto. Este formato se describe en el estándar del X Consortium Compound Text Encoding. La función asigna espacio para contener la cadena devuelta. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XtFree.

RELACIONADOS

XmCvtCTToXmString(3), XmFontList(3), XmMapSegmentEncoding(3), XmRegisterSegmentEncoding(3), y XmString.
