XML::LibXML::RegExp(3) Documentación de Perl aportada por el usuario XML::LibXML::RegExp(3)

NOMBRE

XML::LibXML::RegExp - Interfaz de XML::LibXML para expresiones regulares de libxml2

SINOPSIS

use XML::LibXML;
my $compiled_re = XML::LibXML::RegExp->new('[0-9]{5}(-[0-9]{4})?');
if ($compiled_re->isDeterministic()) { ... }
if ($compiled_re->matches($string)) { ... }
$compiled_re = XML::LibXML::RegExp->new( $regexp_str );
$bool = $compiled_re->matches($string);
$bool = $compiled_re->isDeterministic();

DESCRIPCIÓN

Esta es una interfaz de perl para la implementación de expresiones regulares de libxml2, que se utilizan, por ejemplo, para la validación de tipos simples de XML Schema (facetas de patrón).

new()
$compiled_re = XML::LibXML::RegExp->new( $regexp_str );

El constructor toma una cadena que contiene una expresión regular y devuelve un objeto de expresión regular compilada.

matches($string)
$bool = $compiled_re->matches($string);

Dado un valor de cadena, devuelve un valor verdadero si el valor coincide con la expresión regular compilada.

isDeterministic()
$bool = $compiled_re->isDeterministic();

Devuelve un valor verdadero si la expresión regular es determinista; de lo contrario, devuelve falso. (Ver la definición de determinismo en la especificación XML (http://www.w3.org/TR/REC-xml/#determinism))
