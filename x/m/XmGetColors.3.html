NOMBRE

XmGetColors — Una función que genera colores de primer plano, de selección y de sombra

SINOPSIS

#include <Xm/Xm.h>
void XmGetColors(
Screen * screen,
Colormap colormap,
Pixel background,
Pixel * foreground,
Pixel * top_shadow,
Pixel * bottom_shadow,
Pixel * select);

DESCRIPCIÓN

XmGetColors toma una pantalla, un mapa de colores y un píxel de fondo, y devuelve valores de píxel para los colores de primer plano, de selección y de sombra.

screen
Especifica la pantalla para la cual se deben asignar estos colores.
colormap
Especifica el mapa de colores del cual se deben asignar estos colores.
background
Especifica el fondo sobre el cual se deben basar los colores.
foreground
Especifica un puntero al valor de píxel de primer plano devuelto. Si este argumento es NULL, no se asigna ni se devuelve ningún valor para este color.
top_shadow
Especifica un puntero al valor de píxel de sombra superior devuelto. Si este argumento es NULL, no se asigna ni se devuelve ningún valor para este color.
bottom_shadow
Especifica un puntero al valor de píxel de sombra inferior devuelto. Si este argumento es NULL, no se asigna ni se devuelve ningún valor para este color.
select
Especifica un puntero al valor de píxel de selección devuelto. Si este argumento es NULL, no se asigna ni se devuelve ningún valor para este color.

RELACIONADO

XmChangeColor(3), XmGetColorCalculation(3), y XmSetColorCalculation(3).
