NOMBRE

XmListItemExists — Una función de Lista que comprueba si un elemento especificado está en la lista

SINOPSIS

#include <Xm/List.h>
Boolean XmListItemExists(
Widget widget,
XmString item);

DESCRIPCIÓN

XmListItemExists es una función Booleana que comprueba si un elemento especificado está presente en la lista.

widget
Especifica el ID del widget de Lista
item
Especifica el elemento cuya presencia se comprueba

Para una definición completa de Lista y sus recursos asociados, ver XmList(3).

RETORNO

Devuelve True si el elemento especificado está presente en la lista.

RELACIONADO

XmList(3).
