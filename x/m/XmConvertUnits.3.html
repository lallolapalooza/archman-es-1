NOMBRE

XmConvertUnits — Una función que convierte un valor de un tipo de unidad a otro tipo de unidad

SINOPSIS

#include <Xm/Xm.h>
int XmConvertUnits(
Widget widget,
int orientation,
int from_unit_type,
int from_value,
int to_unit_type);

DESCRIPCIÓN

XmConvertUnits convierte el valor y lo devuelve como valor de retorno de la función. Para recursos de tipo, dimensión o posición, puede especificar unidades utilizando la sintaxis descrita en el recurso XmNunitType de la página de referencia de XmPrimitive.

widget
Especifica el widget para el cual se deben convertir los datos.
orientation
Especifica si el conversor utiliza la resolución de pantalla horizontal o vertical al realizar las conversiones. El parámetro orientation puede tener los valores XmHORIZONTAL o XmVERTICAL.
from_unit_type
Especifica el tipo de unidad actual del valor proporcionado.
from_value
Especifica el valor que se va a convertir.
to_unit_type
Convierte el valor al tipo de unidad especificado.

Los parámetros from_unit_type y to_unit_type pueden tener los siguientes valores:

XmPIXELS
Todos los valores proporcionados al widget se tratan como valores de píxeles. Este es el valor predeterminado para el recurso.
XmMILLIMETERS
Todos los valores proporcionados al widget se tratan como valores en milímetros.
Xm100TH_MILLIMETERS
Todos los valores proporcionados al widget se tratan como 1/100 de milímetro.
XmCENTIMETERS
Todos los valores proporcionados al widget se tratan como valores en centímetros.
XmINCHES
Todos los valores proporcionados al widget se tratan como valores en pulgadas.
Xm1000TH_INCHES
Todos los valores proporcionados al widget se tratan como 1/1000 de pulgada.
XmPOINTS
Todos los valores proporcionados al widget se tratan como valores de puntos. Un punto es una unidad utilizada en aplicaciones de procesamiento de texto y se define como 1/72 de pulgada.
Xm100TH_POINTS
Todos los valores proporcionados al widget se tratan como 1/100 de punto. Un punto es una unidad utilizada típicamente en aplicaciones de procesamiento de texto y se define como 1/72 de pulgada.
XmFONT_UNITS
Todos los valores proporcionados al widget se tratan como unidades de fuente normales. Una unidad de fuente tiene componentes horizontal y vertical. Estos son los valores de los recursos XmNhorizontalFontUnit y XmNverticalFontUnit de XmScreen.
Xm100TH_FONT_UNITS
Todos los valores proporcionados al widget se tratan como 1/100 de unidad de fuente. Una unidad de fuente tiene componentes horizontal y vertical. Estos son los valores de los recursos XmNhorizontalFontUnit y XmNverticalFontUnit de XmScreen.

RETORNO

Devuelve el valor convertido. Si se proporciona un widget nulo, una orientation incorrecta o un unit_type incorrecto como datos de parámetro, se devuelve 0 (cero).

RELACIONADO

XmPrimitive, XmSetFontUnits(3) y XmScreen(3).
