NOMBRE

XmStringCompare — Una función de cadena compuesta que compara dos cadenas

SINOPSIS

#include <Xm/Xm.h>
Boolean XmStringCompare(
XmString s1,
XmString s2);

DESCRIPCIÓN

XmStringCompare devuelve un valor booleano que indica los resultados de una comparación semánticamente equivalente de dos cadenas compuestas.

Semánticamente equivalente significa que las cadenas tienen los mismos componentes de texto, etiquetas de elementos de lista de fuentes, direcciones y separadores. En general, si dos cadenas compuestas se crean con la misma cadena (char *) utilizando XmStringCreateLocalized en el mismo entorno de idioma, las cadenas compuestas se comparan como iguales. Si dos cadenas compuestas se crean con el mismo texto y argumento de etiqueta utilizando XmStringCreate, las cadenas se comparan como iguales.

s1
Especifica una cadena compuesta para ser comparada con s2
s2
Especifica una cadena compuesta para ser comparada con s1

VALOR DE RETORNO

Devuelve True si dos cadenas compuestas son equivalentes.

RELACIONADOS

XmStringCreate(3) y XmStringCreateLocalized(3).
