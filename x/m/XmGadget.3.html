NOMBRE

XmGadget — La clase de widget Gadget

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

Gadget es una clase de widget utilizada como superclase de soporte para otras clases de gadget. Maneja el dibujo y resaltado del borde de sombra, la activación y desactivación de la navegación, y varias listas de callbacks necesarias para los gadgets.

Los recursos de color y pixmap definidos por XmManager son utilizados directamente por los gadgets. Si se usa XtSetValues para cambiar uno de los recursos para un widget gestor, todos los hijos gadget dentro del gestor también cambian.

Clases

Gadget hereda el comportamiento y los recursos de Object y RectObj.

El puntero de clase es xmGadgetClass.

El nombre de la clase es XmGadget.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para referenciar un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), se puede establecer usando XtSetValues (S), se puede recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNhighlightOnEnter
Especifica si el rectángulo de resaltado se dibuja cuando el cursor entra en el widget. Si la política de foco del shell es XmEXPLICIT, este recurso se ignora y el widget se resalta cuando tiene el foco. Si la política de foco del shell es XmPOINTER y si este recurso es Verdadero, el rectángulo de resaltado se dibuja cuando el cursor entra en el widget. Si la política de foco del shell es XmPOINTER y si este recurso es Falso, el rectángulo de resaltado no se dibuja cuando el cursor entra en el widget. El valor predeterminado es Falso.

Si el padre del widget es un gestor o un shell, el valor se hereda del padre del widget. De lo contrario, se hereda del ancestro más cercano proveedor o shell de menú.
XmNnavigationType
Determina si el widget es un grupo de pestañas.
XmNONE
Indica que el widget no es un grupo de pestañas.
XmTAB_GROUP
Indica que el widget es un grupo de pestañas, a menos que el XmNnavigationType de otro widget en la jerarquía sea XmEXCLUSIVE_TAB_GROUP.
XmSTICKY_TAB_GROUP
Indica que el widget es un grupo de pestañas, incluso si el XmNnavigationType de otro widget en la jerarquía es XmEXCLUSIVE_TAB_GROUP.
XmEXCLUSIVE_TAB_GROUP
Indica que el widget es un grupo de pestañas y que los widgets en la jerarquía cuyo XmNnavigationType es XmTAB_GROUP no son grupos de pestañas.
Cuando un widget padre tiene un XmNnavigationType de XmEXCLUSIVE_TAB_GROUP, la navegación de widgets que no son grupos de pestañas dentro del grupo se basa en el orden de dichos widgets en la lista XmNchildren de su padre.

XmNtraversalOn
Especifica la activación de la navegación para este gadget.
XmNunitType
Proporciona el soporte básico para la independencia de resolución. Define el tipo de unidades que utiliza un widget con los recursos de tamaño y posición. NAME

gadget — Gadget widget

SYNOPSIS

#include <Xm/Gadget.h>

DESCRIPTION

Gadget is an abstract widget class. It provides the basic functionality for all gadget subclasses. Gadgets are non-manager, non-primitive widgets that are used to create composite widgets. Gadgets cannot have traversable input focus and do not accept or generate events. Instead, events are passed to them by their Manager widget parent. Gadgets have no window associated with them.

The following resource lists are for the Gadget widget class. Refer to the appropriate superclass reference page for the discussion of each resource or the list of resources that are specific to the superclass.

Resources

Gadget defines the following resources:

XmNunitType
Specifies the units used for widget geometry resources (e.g., XmNwidth, XmNheight, XmNborderWidth) when they are specified by the application. The default value is Xm1000TH_INCHES. The following unit types are available:
XmINCHES
All values provided to the widget are treated as normal inch values.
Xm1000TH_INCHES
All values provided to the widget are treated as 1/1000 of an inch.
XmPOINTS
All values provided to the widget are treated as normal point values. A point is a unit used in text processing applications and is defined as 1/72 of an inch.
Xm100TH_POINTS
All values provided to the widget are treated as 1/100 of a point. A point is a unit used in text processing applications and is defined as 1/72 inch.
XmFONT_UNITS
All values provided to the widget are treated as normal font units. A font unit has horizontal and vertical components. These are the values of the XmScreen resources XmNhorizontalFontUnit and XmNverticalFontUnit.
Xm100TH_FONT_UNITS
All values provided to the widget are treated as 1/100 of a font unit. A font unit has horizontal and vertical components. These are the values of the XmScreen resources XmNhorizontalFontUnit and XmNverticalFontUnit.
XmNuserData
Allows the application to attach any necessary specific data to the gadget. This is an internally unused resource.
XmNtoolTipString
The XmString to display as the toolTip. If this resource is NULL, no tip will be displayed. ToolTips are described in VendorShell(3)

Callback Information

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
} XmAnyCallbackStruct;
reason
Indicates why the callback was invoked. For this callback, reason is set to XmCR_HELP.
event
Points to the XEvent that triggered the callback.

Behavior

Gadgets cannot have translations associated with them. Because of this, a Gadget's behavior is determined by the Manager widget into which the Gadget is placed. If focus is on a Gadget, events are passed to the Gadget by its Manager.
