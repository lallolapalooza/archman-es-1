XmVaCreateSimpleOptionMenu(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmVaCreateSimpleOptionMenu(llamada a biblioteca) XmVaCreateSimpleOptionMenu(llamada a biblioteca)

NOMBRE

XmVaCreateSimpleOptionMenu — Una función de creación de conveniencia para el widget RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleOptionMenu(
Widget parent,
String name,
XmString option_label,
KeySym option_mnemonic,
int button_set,
XtCallbackProc callback);

DESCRIPCIÓN

XmVaCreateSimpleOptionMenu crea una instancia de un widget RowColumn de tipo XmMENU_OPTION y devuelve el ID del widget asociado. Esta rutina utiliza la convención de llamada de lista de argumentos de longitud variable (varargs) de ANSI C.

Esta rutina crea un OptionMenu y su submenú desplegable que contiene hijos PushButtonGadget o CascadeButtonGadget. El nombre de cada botón es button_n, donde n es un número entero de 0 (cero) al número de botones en el menú menos 1. El nombre de cada separador es separator_n, donde n es un número entero de 0 (cero) al número de separadores en el menú menos 1. Los botones y separadores se nombran y crean en el orden en que se especifican en la parte variable de la lista de argumentos.

parent
Especifica el ID del widget padre
name
Especifica el nombre del widget creado
option_label
Especifica la cadena de etiqueta que se utilizará en el lado izquierdo del OptionMenu.
option_mnemonic
Especifica un keysym para una tecla que, cuando el usuario la presiona, muestra el panel de menú desplegable asociado.
button_set
Especifica qué PushButtonGadget está establecido inicialmente. El valor es el número entero n que corresponde al n-ésimo PushButtonGadget especificado en la parte variable de la lista de argumentos. Solo un PushButtonGadget puede ser establecido, y solo los PushButtonGadgets se cuentan al determinar el número entero n. El primer PushButtonGadget es el número 0 (cero).
callback
Especifica un procedimiento de callback que se llamará cuando se active un botón. Esta función de callback se agrega a cada botón después de la creación como XmNactivateCallback del botón. La función de callback se llama cuando se activa un botón, y el número del botón se devuelve en el campo client_data.

La parte variable de la lista de argumentos consta de grupos de argumentos. El primer argumento en cada grupo es una constante o una cadena y determina qué argumentos le siguen en ese grupo. El último argumento en la lista debe ser NULL. A continuación se presentan los posibles primeros argumentos en cada grupo de varargs:

XmVaPUSHBUTTON
Seguido de cuatro argumentos adicionales. El conjunto especifica un botón en el submenú desplegable del OptionMenu y algunos de sus valores de recurso. El botón creado es un PushButtonGadget. A continuación se presentan los cuatro argumentos adicionales, en orden:
label
La cadena de etiqueta, de tipo XmString
mnemonic
El mnemotécnico, de tipo KeySym
accelerator
El acelerador, de tipo String
accelerator_text
El texto del acelerador, de tipo XmString
XmVaSEPARATOR
Seguido de ningún argumento adicional. Especifica un separador en el submenú desplegable del OptionMenu.
XmVaDOUBLE_SEPARATOR
Seguido de ningún argumento adicional. Especifica un separador en el submenú desplegable del OptionMenu. El tipo de separador es XmDOUBLE_LINE.
resource_name
Seguido de un argumento adicional, el valor del recurso, de tipo XtArgVal. El par especifica un recurso y su valor para el submenú desplegable.
XtVaTypedArg
Seguido de cuatro argumentos adicionales. El conjunto especifica un recurso y su valor para el submenú desplegable. Se realiza una conversión de tipo de recurso si es necesario. A continuación se presentan los cuatro argumentos adicionales, en orden:
name
El nombre del recurso, de tipo String
type
El tipo del valor del recurso proporcionado, de tipo String
value
El valor del recurso (o un puntero al valor del recurso, dependiendo del tipo y tamaño del valor), de tipo XtArgVal
size
El tamaño del valor del recurso en bytes, de tipo int
XtVaNestedList
Seguido de un argumento adicional de tipo XtVarArgsList. Este argumento es una lista anidada de varargs devuelta por XtVaCreateArgsList.

El usuario puede especificar recursos en un archivo de recursos para los widgets y gadgets creados automáticamente de un OptionMenu. La siguiente lista identifica los nombres de estos widgets (o gadgets) y las áreas asociadas del OptionMenu:

Etiqueta del Gadget del Menú de Opciones
OptionLabel
Botón de Cascada del Menú de Opciones
OptionButton

Para obtener más información sobre las listas de argumentos de longitud variable, consulte la documentación de X Toolkit Intrinsics.

Existen varios recursos específicamente para usar con esta y otras rutinas de creación de menús simples. Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNAR

Devuelve el ID del widget RowColumn.

RELACIONADO

XmCreateOptionMenu(3), XmCreateRowColumn(3), XmCreateSimpleOptionMenu(3), y XmRowColumn(3).
