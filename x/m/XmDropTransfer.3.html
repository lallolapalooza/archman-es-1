NOMBRE

XmDropTransfer — La clase del widget DropTransfer

SINOPSIS

#include <Xm/DragDrop.h>

DESCRIPCIÓN

DropTransfer proporciona un conjunto de recursos que identifican los procedimientos y la información asociada requerida por el toolkit para procesar y completar una transacción de arrastrar y soltar. Los clientes no deben crear explícitamente un widget DropTransfer. En su lugar, un cliente inicia una transferencia llamando a XmDropTransferStart, que inicializa y devuelve un widget DropTransfer. Si esta función se llama dentro de una devolución de llamada XmNdropProc, las transferencias reales se inician después de que la devolución de llamada retorne. Incluso si no se necesita transferir ningún dato, se debe llamar a XmDropTransferStart (típicamente sin argumentos, o solo estableciendo XmNtransferStatus) para finalizar la transacción de arrastrar y soltar.

El recurso XmNdropTransfers especifica una lista de transferencias que describe los tipos de destino solicitados para los datos de origen. Una lista de transferencias es un array de estructuras XmDropTransferEntryRec, cada una de las cuales identifica un tipo de destino. La lista de transferencias es análoga a la capacidad de selecciones MULTIPLE definida en el Manual de convenciones de comunicación entre clientes (ICCCM).

El recurso DropTransfer, XmNtransferProc, especifica un procedimiento de transferencia de tipo XtSelectionCallbackProc que entrega los datos de selección solicitados. Este procedimiento opera en conjunto con las capacidades de selección subyacentes de Xt y se llama para cada destino en la lista de transferencias. Se pueden solicitar tipos de destino adicionales después de que se inicia una transferencia llamando a la función XmDropTransferAdd.

Estructuras

Una XmDropTransferEntry es un puntero a la siguiente estructura de tipo XmDropTransferEntryRec, que identifica un destino de selección asociado con una determinada transacción de arrastrar y soltar:

typedef struct
{
        XtPointer       client_data;
        Atom target;
} XmDropTransferEntryRec, *XmDropTransferEntry;
client_data
Especifica cualquier información adicional requerida por este destino de selección
target
Especifica un destino de selección asociado con la operación de arrastrar y soltar

Clases

DropTransfer hereda el comportamiento y un recurso de Object.

El puntero de clase es xmDropTransferObjectClass.

El nombre de la clase es XmDropTransfer.

Recursos Nuevos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para establecer atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G), o no es aplicable (N/A).

XmNdropTransfers
Especifica la dirección de un array de registros de entrada de transferencia de arrastrar y soltar. La transferencia de arrastrar y soltar se completa cuando se procesan todas las entradas de la lista.
XmNincremental
Especifica un valor booleano que indica si la transferencia en el lado del receptor utiliza el mecanismo de transferencia de selección incremental de Xt descrito en X Toolkit Intrinsics—C Language Interface. Si el valor es True, el receptor utiliza la transferencia incremental; si el valor es False, el receptor utiliza la transferencia atómica.
XmNnumDropTransfers
Especifica el número de entradas en XmNdropTransfers. Si este recurso se establece en 0 en cualquier momento, la transferencia se considera completa. El valor de XmNtransferStatus determina el proceso de apretón de manos de finalización.

ERRORES COMUNES

Failed to create transfer object
Este error se produce si XmDropTransferStart no puede crear el objeto de transferencia.
Transfer object was already destroyed
Este error se produce si llama a XmDropTransferStart con un objeto de transferencia que ya ha sido destruido.
Transfer object is NULL
Este error se produce si llama a XmDropTransferStart con un puntero NULL al objeto de transferencia.
No drop site registered for this transfer
Este error se produce si intenta iniciar una transferencia sin registrar un sitio de caída.
Transfer failed
Este es un error genérico que indica que la transferencia falló. Puede deberse a una variedad de razones, como problemas de red o errores en el manejador de destino.
