XmClipboardUnlock(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmClipboardUnlock(llamada a biblioteca) XmClipboardUnlock(llamada a biblioteca)

NOMBRE

XmClipboardUnlock — Una función del portapapeles que desbloquea el portapapeles

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardUnlock (display, window, remove_all_locks)
        Display * display;
        Window  window;
        Boolean remove_all_locks;
(void)

DESCRIPCIÓN

XmClipboardUnlock desbloquea el portapapeles, permitiendo que sea accedido por otras aplicaciones.

Si se han realizado múltiples llamadas a XmClipboardLock, se necesita el mismo número de llamadas a XmClipboardUnlock para desbloquear el portapapeles, a menos que remove_all_locks se establezca en True.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de la ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de la ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debería pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llama.
remove_all_locks
Cuando es True, indica que se deben eliminar todos los bloqueos anidados. Cuando es False, indica que solo se debe eliminar un nivel de bloqueo.

RETORNAR

XmClipboardSuccess
La función fue exitosa.
XmClipboardFail
La función falló porque el portapapeles no estaba bloqueado o estaba bloqueado por otra aplicación.
