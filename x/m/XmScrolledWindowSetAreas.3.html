XmScrolledWindowSetAreas(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmScrolledWindowSetAreas(llamada de librería) XmScrolledWindowSetAreas(llamada de librería)

NOMBRE

XmScrolledWindowSetAreas — Una función de ScrolledWindow que añade o cambia una región de trabajo de ventana y un widget de ScrollBar horizontal o vertical al widget ScrolledWindow

SINOPSIS

#include <Xm/ScrolledW.h>
void XmScrolledWindowSetAreas(
Widget widget,
Widget horizontal_scrollbar,
Widget vertical_scrollbar,
Widget work_region);

DESCRIPCIÓN

XmScrolledWindowSetAreas añade o cambia una región de trabajo de ventana y un widget de ScrollBar horizontal o vertical al widget ScrolledWindow para la aplicación. Cada widget es opcional y puede ser pasado como NULL. Esta función es obsoleta y existe para compatibilidad con otras versiones. Utilice el recurso XmNscrolledWindowChildType de XmScrolledWindow en su lugar.

widget
Especifica el ID del widget ScrolledWindow.
horizontal_scrollbar
Especifica el ID del widget ScrollBar para el ScrollBar horizontal que se asociará con el widget ScrolledWindow. Establezca este ID solo después de crear una instancia del widget ScrolledWindow. El nombre del recurso asociado con este argumento es XmNhorizontalScrollBar.
vertical_scrollbar
Especifica el ID del widget ScrollBar para el ScrollBar vertical que se asociará con el widget ScrolledWindow. Establezca este ID solo después de crear una instancia del widget ScrolledWindow. El nombre del recurso asociado con este argumento es XmNverticalScrollBar.
work_region
Especifica el ID del widget para la ventana de trabajo que se asociará con el widget ScrolledWindow. Establezca este ID solo después de crear una instancia del widget ScrolledWindow. El nombre del atributo asociado con este argumento es XmNworkWindow.

Para una definición completa de ScrolledWindow y sus recursos asociados, consulte XmScrolledWindow(3).

RELACIONADO
