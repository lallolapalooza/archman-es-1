NOMBRE

XmCommand — La clase del widget Command

SINOPSIS

#include <Xm/Command.h>

DESCRIPCIÓN

Command es un widget compuesto de propósito especial para la entrada de comandos que proporciona un mecanismo de historial de comandos incorporado. Command incluye un campo de entrada de texto para la línea de comandos, un prompt para la línea de comandos y una región de lista de historial de comandos.

Se puede añadir un WorkArea adicional a Command después de su creación.

Cada vez que se introduce un comando, se añade automáticamente al final de la lista de historial de comandos y se hace visible. Esto no cambia el elemento seleccionado en la lista, si lo hay.

Muchos de los nuevos recursos especificados para Command son en realidad recursos de SelectionBox que han sido renombrados para mayor claridad y facilidad de uso.

Descendientes

Command crea automáticamente los descendientes que se muestran en la siguiente tabla. Una aplicación puede usar XtNameToWidget para acceder al descendiente con nombre. Además, un usuario o una aplicación pueden usar el descendiente con nombre al especificar valores de recursos.

Descendiente con nombre Clase Identidad
ItemsList XmList región de lista de historial de comandos
ItemsListSW XmScrolledWindow el padre ScrolledWindow de ItemsList
Selection XmLabelGadget prompt de la línea de comandos
Text XmTextField campo de entrada de texto de la línea de comandos

Clases

Command hereda comportamiento, recursos y rasgos de Core, Composite, Constraint, XmManager, XmBulletinBoard y XmSelectionBox.

El puntero de clase es xmCommandWidgetClass.

El nombre de la clase es XmCommand.

CALLBACKS

Command define dos tipos de callbacks para notificar al usuario cuando ocurre un evento específico:

XmNcommandChangedCallback
Se invoca cuando el contenido del campo de entrada de texto cambia.
XmNcommandEnteredCallback
Se invoca cuando el usuario presiona Enter en el campo de entrada de texto.

Cada callback recibe un puntero a una estructura XmCommandCallbackStruct, que contiene la siguiente información:

typedef struct {
    int         reason;
    XEvent      *event;
    XmString    value;
} XmCommandCallbackStruct;
reason
Indica la razón por la que se activó el callback. Puede ser XmCR_COMMAND_CHANGED o XmCR_COMMAND_ENTERED.
event
Puntero al evento X que desencadenó el callback.
value
La cadena de texto que contiene el contenido actual del campo de entrada de comandos.

Para obtener más información sobre los callbacks, consulte la documentación de XmNactivateCallback, XmNmodifyBehaviorCallback y XmNtraverseCallback para el widget XmCommand.

XmNcommandChangedCallback
Especifica la lista de callbacks que se llama después de cada vez que el valor del comando cambia. La razón del callback es XmCR_COMMAND_CHANGED. Esto es equivalente a XmNvalueChangedCallback del widget Text, excepto que se pasa un puntero a una XmCommandCallbackStructure, y el miembro value de la estructura contiene el XmString.
XmNcommandEnteredCallback

Enumera los elementos XmString que componen el contenido de la lista del historial. Este es el recurso XmNlistItems en SelectionBox, renombrado para Command. XmNhistoryItemCount
Especifica el número de XmStrings en XmNhistoryItems. Este es el recurso XmNlistItemCount en SelectionBox, renombrado para Command. El valor no debe ser negativo.
XmNhistoryMaxItems
Especifica el número máximo de elementos permitidos en la lista del historial. Una vez alcanzado este número, se debe eliminar un elemento existente de la lista antes de poder añadir un nuevo elemento a la lista. Por cada comando introducido, se elimina el primer elemento de la lista, para que el nuevo comando pueda ser añadido a la lista. El valor debe ser mayor que 0 (cero).
XmNhistoryVisibleItemCount
Especifica el número de elementos en la lista del historial que deben ser visibles a la vez. En efecto, establece la altura (en líneas) de la ventana de la lista del historial. Este es el recurso XmNlistVisibleItemCount en SelectionBox, renombrado para Command. El valor debe ser mayor que 0 (cero). El valor predeterminado es dinámico basado en la altura de la lista.
XmNpromptString
Especifica una indicación para la línea de comandos. Este es el recurso XmNselectionLabelString en SelectionBox, renombrado para Command. El valor predeterminado puede variar dependiendo del valor del recurso XmNlayoutDirection y de la configuración regional (locale). En la configuración regional C, el valor predeterminado es > (signo de mayor que).
Ahora que se proporcionan algunas cadenas de etiquetas localizadas predeterminadas a través de catálogos de mensajes para los hijos de los widgets compuestos, los recursos labelString no se pueden establecer en el hijo a través de archivos de recursos predeterminados. En su lugar, se debe usar el recurso proporcionado en el nivel principal.

XmCommand(3) — openmotif — Arch manual pages

NAME

XmCommand — A command widget that allows users to enter commands and displays command history.

SYNOPSIS

#include <Xm/Command.h>

DESCRIPTION

The XmCommand widget is a composite widget that allows users to enter commands in a text field and view command history. It is derived from XmBulletinBoard and incorporates a text edit widget for command input and a list widget for displaying command history.

The XmCommand widget includes the following children:

CommandWindow:
A XmCommandWindow widget, which contains the CommandArea and the List.
CommandArea:
A XmTextField widget, which is used for entering commands.
List:
A XmList widget, which displays the command history.

WIDGETS

The class record name is xmCommandClass.

The resource name for the XmCommand widget is XmCommand.

CALLBACKS

The XmCommand widget has the following callbacks:

XmNcommandChangedCallback:
Invoked when the text in the CommandArea changes.
XmNcommandEnteredCallback:
Invoked when the user presses Enter in the CommandArea or selects an item from the List.
XmNfocusCallback:
Invoked when the widget receives focus.
XmNmapCallback:
Invoked when the widget is mapped.
XmNunmapCallback:
Invoked when the widget is unmapped.

A pointer to the following structure is passed to each callback:

typedef struct
{
        int reason;
        XEvent * event;
        XmString value;
        int length;
} XmCommandCallbackStruct;
reason
Indicates why the callback was invoked.
event
Points to the XEvent that triggered the callback.
value
Specifies the XmString in the CommandArea.
length
Specifies the size in bytes of the XmString value. This member is obsolete and exists for compatibility with earlier releases.

Translations

XmCommand inherits translations from XmSelectionBox.

Accelerators

The XmNtextAccelerators from XmSelectionBox are added to the Text descendant of XmCommand.

Action Routines

The XmCommand action routines are:

SelectionBoxUpOrDown(Previous|Next|First|Last):
When called with an argument of Previous, or 0 (zero) for compatibility, selects the previous item in the history list and replaces the text with that item.
When called with an argument of Next, or 1 for compatibility, selects the next item in the history list and replaces the text with that item.
When called with an argument of First, or 2 for compatibility, selects the first item in the history list and replaces the text with that item.
When called with an argument of Last, or 3 for compatibility, selects the last item in the history list and replaces the text with that item.
Calls the callbacks for XmNcommandChangedCallback.

Additional Behavior

The Command widget has the following additional behavior:

<Key><osfCancel>:
If the parent of the Command is a manager, the event is passed to the parent.
<Key><osfActivate> in Text:
Calls the Text widget's XmNactivateCallback callbacks. If the text is empty, this action then returns. Otherwise, if the history list has XmNhistoryMaxItems items, it removes the first item in the list. It adds the text to the history list as the last item, clears the text, and calls the XmNcommandEnteredCallback callbacks.
<Key> in Text:
When any change is made to the text edit widget, this action calls the callbacks for XmNcommandChangedCallback.
<BtnDown>(2+) or <Key><osfActivate> in List:
Calls the List widget's XmNdefaultActionCallback callbacks. If the history list has XmNhistoryMaxItems items, this action removes the first item in the list. It adds the selected List item to the history list as the last item, clears the text, and calls the XmNcommandEnteredCallback callbacks.
<FocusIn>:
Calls the callbacks for XmNfocusCallback.
<MapWindow>:
When a Command that is the child of a DialogShell is mapped, this action calls the callbacks for XmNmapCallback.
<UnmapWindow>:
When a Command that is the child of a DialogShell is unmapped, this action calls the callbacks for XmNunmapCallback.
