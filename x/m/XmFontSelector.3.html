NOMBRE

El widget Selector de Fuentes

SINOPSIS

#include <Xm/FontS.h>

DESCRIPCIÓN

El widget Selector de Fuentes permite a los usuarios elegir fácilmente una fuente seleccionando la familia de fuentes y el tamaño de la fuente. Los atributos negrita y cursiva también se pueden configurar para cualquier fuente para la que estén disponibles. Cualquier fuente puede ser pasada al selector de fuentes por la aplicación como el valor inicial mostrado al usuario. Las características avanzadas extienden enormemente la funcionalidad del widget.

Características Básicas

El widget selector de fuentes presenta al usuario dos widgets de caja combinada, uno con una lista de opciones para la familia de fuentes y otro con las opciones para el tamaño de la fuente. Además, hay dos botones de alternancia independientes que permiten al usuario poner la fuente en negrita o cursiva, o negrita/cursiva. Debajo del área de selección de fuentes hay un widget de texto que muestra texto de ejemplo de la fuente elegida al usuario. Esta área de texto es editable, lo que permite al usuario agregar o eliminar texto para ver cómo aparecen los diversos caracteres en la fuente elegida. Para el usuario novato, este conjunto de características permite el acceso a todas las fuentes estándar del sistema. El selector de fuentes elimina dinámicamente las opciones que son inapropiadas, por lo que el usuario es libre de experimentar con diferentes combinaciones y siempre puede estar seguro de que una vez que haya seleccionado una fuente, esta existirá en la máquina en la que se está ejecutando el selector de fuentes. Por ejemplo, si no hay una fuente Times Roman de 14 puntos disponible y el usuario selecciona un tamaño de punto de 14, entonces Times Roman no estará disponible en la caja combinada de familias. Del mismo modo, si el usuario hubiera elegido Times Roman del cuadro de diálogo de familias, entonces no se mostraría un tamaño de 14. Para tener todas las opciones disponibles, simplemente elija un tamaño y una familia de "Cualquiera".

Características Avanzadas

Para el usuario avanzado, el selector de fuentes proporciona una tremenda flexibilidad en las opciones de fuentes. Al activar el botón de opciones, se presenta al usuario un panel adicional de controles. Esto permite al usuario obtener acceso a fuentes no XLFD, controlar las resoluciones de las fuentes elegidas, elegir solo entre fuentes fijas o proporcionales, eliminar el uso de escalado de fuentes, permitir la visualización de fuentes no iso8859-1 y ver el nombre XLFD que el selector de fuentes está construyendo.

Fuentes No XLFD

Al elegir la opción "Otras Fuentes" del panel de opciones, las listas de familias y tamaños, así como los botones de alternancia de negrita y cursiva, se reemplazan por una caja combinada que contiene todas las fuentes no XLFD disponibles en su sistema. Esta característica permite a los usuarios seleccionar fuentes no XLFD con el FontSelector. El campo de texto de la caja combinada puede ser editado por el usuario y cualquier cadena introducida se interpretará como un nombre de fuente. Cabe señalar que los nombres XLFD se pueden escribir a mano aquí. Esta característica permite utilizar el selector de fuentes para obtener cualquier fuente del sistema completo.

Control de Resolución

El selector de fuentes determina cuál de las dos resoluciones estándar está más cerca de la pantalla actual y la utiliza como predeterminada. Para permitir un rango más amplio de opciones, un usuario puede optar por acceder a fuentes de una resolución diferente, o resoluciones de 75 y 100 dpi.

Fijo o Proporcional

En la mayoría de los casos, el hecho de que una fuente sea de ancho fijo o proporcional no es de gran interés para el usuario. Pero algunas aplicaciones requieren una fuente de ancho fijo, como los emuladores de terminal, y a la mayoría de la gente le parece que las fuentes proporcionales se ven mejor. El selector de fuentes permite a los usuarios limitar las opciones de fuentes a ancho fijo o proporcional, o permitir ambas.

Escalado de Fuentes

La tecnología de escalado de fuentes disponible en X11R5 utiliza escalado de mapas de bits que, aunque útil en algunos casos, generalmente produce fuentes muy feas. Notamos que los usuarios a menudo querían saber qué fuentes están escaladas y cuáles existen como mapas de bits hechos a mano. Para eliminar las fuentes escaladas de la lista de opciones, desactive el botón "Usar Escalado de Fuentes". Este valor es controlable por recursos y, por defecto, está activado, lo que utiliza el escalado de fuentes.

Codificación

El programador puede especificar qué codificaciones son selecciones válidas. Estas opciones de codificación aparecen en un menú de opciones. La lista de opciones de fuentes se restringe a aquellas que utilizan la codificación seleccionada actualmente.

Visualización de Nombre XLFD

Hacer clic en la opción "Mostrar" muestra el nombre XLFD de la fuente actual en la parte inferior del selector de fuentes.

XmFontSelector(3)

XmFontSelector - Un widget selector de fuentes.

DESCRIPCIÓN

El widget XmFontSelector es un widget de selección de fuentes compuesto. Permite a un usuario seleccionar una fuente de una lista de fuentes disponibles y ver una muestra de esa fuente. El widget XmFontSelector se puede usar como un widget independiente o como un widget dentro de un cuadro de diálogo.

Este widget está diseñado para ser un widget compuesto que contiene una serie de otros widgets para proporcionar la funcionalidad de selección de fuentes. Estos sub-widgets incluyen:

  • Un área para mostrar el nombre de la fuente seleccionada (XmNfontSelector.fontNamesWidget).
  • Un área para mostrar el tipo de fuente seleccionada (XmNfontSelector.fontTypeWidget).
  • Un área para mostrar una muestra de la fuente seleccionada (XmNfontSelector.sampleTextWidget).
  • Un área para mostrar la vista previa de la fuente seleccionada (XmNfontSelector.fontPreviewWidget).
  • Un área para mostrar detalles sobre la fuente seleccionada (XmNfontSelector.fontDetailsWidget).
  • Un área para mostrar la vista previa de los detalles de la fuente (XmNfontSelector.fontPreviewTextWidget).

El widget XmFontSelector también admite recursos para personalizar su apariencia y comportamiento, como:

  • XmNfontSelector.title: El título del widget XmFontSelector.
  • XmNfontSelector.isEditable: Un valor booleano que indica si el widget es editable.
  • XmNfontSelector.fontList: Una lista de fuentes para mostrar en el widget.
  • XmNfontSelector.defaultFont: La fuente predeterminada que se mostrará cuando se cree el widget.
  • XmNfontSelector.callback: Una función de retorno de llamada que se invocará cuando se seleccione una nueva fuente.

EJEMPLO

El siguiente ejemplo muestra cómo crear un widget XmFontSelector:

Widget font_selector;

font_selector = XmCreateFontSelector(parent, "font_selector", NULL, 0);
XtManageChild(font_selector);

XmNfontSelector.fontType

Este recurso especifica el tipo de fuentes que se mostrarán en el widget XmFontSelector. Los valores posibles son:

  • XmFONT_TYPE_ALL: Muestra todas las fuentes.
  • XmFONT_TYPE_XLFD: Muestra solo fuentes XLFD.
  • XmFONT_TYPE_NON_XLFD: Muestra solo fuentes no XLFD.

XmNfontSelector.fontlist

Este recurso especifica una lista de fuentes que se mostrarán en el widget XmFontSelector. Si este recurso se establece en NULL, el widget cargará todas las fuentes disponibles en el sistema.

XmNfontSelector.filterCb

Este recurso especifica una función de retorno de llamada que se invocará cada vez que se filtre la lista de fuentes. La función de retorno de llamada recibe un puntero a una estructura XmFontSelectorCallbackStruct como argumento.

XmNfontSelector.pattern

Este recurso especifica un patrón para filtrar los nombres de las fuentes. El patrón se puede utilizar para seleccionar fuentes que coincidan con un determinado nombre o parte de un nombre.

XmNfontSelector.editorType

Este recurso especifica el tipo de editor de fuentes que se utilizará con el widget XmFontSelector. Los valores posibles son:

  • XmEDIT_NONE: No se utiliza ningún editor de fuentes.
  • XmEDIT_ALL: Se utiliza un editor de fuentes completo.
  • XmEDIT_PARTIAL: Se utiliza un editor de fuentes parcial.

XmNfontSelector.listVisibleItemCount

Este recurso especifica el número de elementos visibles en las listas del widget XmFontSelector. El valor predeterminado es 10.

XmNfontSelector.selectedFont

XmNfontSelector.selectedFontCount

Características de Fuente

Los siguientes recursos se pueden utilizar para filtrar las fuentes por sus características:

  • XmNfontSelector.fontType: Tipo de fuente (XLFD, no XLFD, todas).
  • XmNfontSelector.spacing: Espaciado (fijo, proporcional, ambos).
  • XmNfontSelector.averageWidth: Ancho promedio de los caracteres.
  • XmNfontSelector.registry: Registro de la fuente.
  • XmNfontSelector.encoding: Codificación de la fuente.
  • XmNfontSelector.font: Nombre de la fuente.
  • XmNfontSelector.fontHeight: Altura de la fuente.
  • XmNfontSelector.fontWidth: Ancho de la fuente.
  • XmNfontSelector.fontName: Nombre completo de la fuente.
  • XmNfontSelector.fontClass: Clase de la fuente.
  • XmNfontSelector.fontWeight: Peso de la fuente (negrita, normal).
  • XmNfontSelector.fontStyle: Estilo de la fuente (itálica, normal).
  • XmNfontSelector.fontVersion: Versión de la fuente.
  • XmNfontSelector.fontResolution: Resolución de la fuente.
  • XmNfontSelector.fontScalable: Indica si la fuente es escalable.
  • XmNfontSelector.fontInformation: Información adicional sobre la fuente.

Fuentes No XLFD

El widget XmFontSelector admite fuentes no XLFD. Estas fuentes se pueden especificar utilizando el recurso XmNfontSelector.fontType establecido en XmFONT_TYPE_NON_XLFD.

Control de Resolución

El widget XmFontSelector permite el control de la resolución de la fuente a través de los siguientes recursos:

  • XmNfontSelector.resolutionX: Resolución horizontal de la fuente.
  • XmNfontSelector.resolutionY: Resolución vertical de la fuente.

Fija o Proporcional

El widget XmFontSelector permite filtrar las fuentes por espaciado fijo o proporcional utilizando el siguiente recurso:

  • XmNfontSelector.spacing: Especifica el tipo de espaciado de la fuente (XmFIXED o XmPROPORTIONAL).

Escalado de Fuentes

El widget XmFontSelector admite el escalado de fuentes. Los siguientes recursos se pueden utilizar para controlar el escalado de fuentes:

  • XmNfontSelector.useScaling: Un valor booleano que indica si se debe usar el escalado de fuentes.
  • XmNfontSelector.scalingFactor: El factor de escalado a aplicar a la fuente.
  • XmNfontSelector.fontName: El nombre de la fuente a escalar.

Codificación

El widget XmFontSelector admite diferentes codificaciones de fuentes. Los siguientes recursos se pueden utilizar para especificar la codificación de la fuente:

  • XmNfontSelector.encoding: La codificación de la fuente.
  • XmNfontSelector.encodingList: Una lista de codificaciones de fuentes disponibles.

Visualización de Nombre XLFD

El widget XmFontSelector puede mostrar el nombre completo de la fuente XLFD. Esto se puede habilitar o deshabilitar utilizando el siguiente recurso:

  • XmNfontSelector.showXLFDName: Un valor booleano que indica si se debe mostrar el nombre XLFD completo.

Rutina de Conveniencia

XmCreateFontSelector - Rutina de conveniencia para la creación de widgets

La rutina XmCreateFontSelector se utiliza para crear un widget XmFontSelector. Toma los siguientes argumentos:

Widget XmCreateFontSelector(Widget parent, String name, ArgList args, Cardinal argCount);
  • parent: El widget padre.
  • name: El nombre del widget XmFontSelector.
  • args: Una lista de argumentos para establecer los recursos del widget.
  • argCount: El número de argumentos en la lista args.

La rutina devuelve el widget XmFontSelector recién creado.
