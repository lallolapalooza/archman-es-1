NOMBRE

XML::LibXSLT::Quick - una interfaz más fácil de usar (= "más rápida") para XML::LibXSLT

SINOPSIS

use XML::LibXSLT::Quick ();
my $stylesheet =
    XML::LibXSLT::Quick->new( { location => 'example/1.xsl', } );
my $xml1_text = _utf8_slurp('example/1.xml');
my $out_fn = 'foo.xml';
$stylesheet->generic_transform(
    +{
        type => 'file',
        path => $out_fn,
    },
    $xml1_text,
);

DESCRIPCIÓN

Este es un módulo que envuelve a XML::LibXSLT con una interfaz más fácil de usar.

Se puede utilizar para procesar documentos XML usando Hojas de Estilo XSLT (Extensible Stylesheet Language Transformations) https://en.wikipedia.org/wiki/XSLT.

MÉTODOS

XML::LibXSLT::Quick->new({ location=>"./xslt/my.xslt", });

PENDIENTE DE DOCUMENTACIÓN.

$obj->stylesheet()

El resultado de parse_stylesheet().

$obj->xml_parser()

La instancia de XML::LibXML.

$obj->generic_transform($dest, $source)

A discutir.

Ver "t/using-quick-wrapper.t".

$dest puede ser:

"\$my_string_var"

"{type => 'dom', }" - Se devolverá el DOM.

"{type => 'file', path => $filepath, }" - La cadena de salida se escribirá en $filepath.

"{type => 'implicit', }" - Se calculará la cadena de salida pero se descartará implícitamente y se devolverá undef(). (Añadido en la versión 2.00300).

"{type => 'return', }" - Se devolverá la cadena de salida.

$source puede ser:

Una cadena.

"{type => 'file', path => $filepath, params => +{}, }" - Se analizará el archivo.

"{type => 'string', string => $my_xml_string, params => +{}, }" - Se analizará la cadena.

$obj->output_as_chars($dom)

$obj->transform(...)

$obj->transform_into_chars(...)

Delegando desde $obj->stylesheet(). Ver XML::LibXSLT.
