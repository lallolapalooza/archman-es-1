Paquete: perl-xml-stream

XML::Stream::Node(3) Documentación de Perl contribuida por el usuario XML::Stream::Node(3)

NOMBRE

XML::Stream::Node - Funciones para facilitar el trabajo con la construcción y el análisis del árbol.

SINOPSIS

  Solo una colección de funciones que no necesitan estar en memoria si eliges
uno de los otros métodos de almacenamiento de datos.
  Esto crea una jerarquía de objetos Perl y proporciona varios métodos
para manipular la estructura del árbol. Es muy similar a la biblioteca C
libxml.

FORMATO

El resultado del análisis:

<foo><head id="a">Hola <em>ahí</em></head><bar>Qué tal<ref/></bar>hace</foo>

sería:

[ tag:       foo
  att:       {}
  children:  [ tag:      head
               att:      {id=>"a"}
               children: [ tag:      "__xmlstream__:node:cdata"
                           children: "Hola "
                         ]
                         [ tag:      em
                           children: [ tag:      "__xmlstream__:node:cdata"
                                       children: "ahí"
                                     ]
                         ]
             ]
             [ tag:      bar
               children: [ tag:      "__xmlstream__:node:cdata"
                           children: "Qué tal "
                         ]
                         [ tag:      ref
                         ]
             ]
             [ tag:      "__xmlstream__:node:cdata"
               children: "hace"
             ]
]

MÉTODOS

new()          - crea un nuevo nodo. Si especificas una etiqueta, la raíz
new(tag)         se establece. Si especificas datos, también se añaden cdata
new(tag,cdata)   al nodo. Devuelve el nodo creado.
get_tag() - devuelve la etiqueta raíz del nodo.
set_tag(tag) - establece la etiqueta raíz del nodo a tag.
add_child(node)      - añade el nodo especificado como hijo al nodo actual,
add_child(tag)         o crea un nuevo nodo con la etiqueta especificada
add_child(tag,cdata)   como nodo raíz. Devuelve el nodo añadido.
remove_child(node) - elimina el nodo hijo del nodo actual.

remove_cdata() - elimina todos los nodos hijos cdata del nodo actual.
add_cdata(string) - añade la cadena como cdata a la lista de hijos del nodo actual.
get_cdata() - devuelve todos los nodos hijos cdata concatenados en una sola cadena.
get_attrib(attrib) - devuelve el valor del atributo si es válido,
                     o devuelve undef si el atributo no es un atributo real.
put_attrib(hash) - para cada par clave/valor especificado, crea un
                   atributo en el nodo.
remove_attrib(attrib) - elimina el atributo especificado del nodo.
add_raw_xml(string,[string,...]) - añade directamente una cadena al paquete XML
                                   como último hijo, sin traducción.
get_raw_xml() - devuelve todo el XML en una sola cadena, undef si no hay
                XML crudo que incluir.
remove_raw_xml() - elimina todas las cadenas XML crudas.
children() - devuelve todos los hijos del nodo en una lista.
attrib() - devuelve un hash que contiene todos los atributos de este
           nodo.
copy() - devuelve una copia recursiva del nodo.
XPath(path) - ejecuta XML::Stream::XPath en este nodo.

XPathCheck(path) - ejecuta XML::Stream::XPath en este nodo y devuelve 1 o 0
                   para ver si coincide o no.
GetXML() - devuelve el nodo en formato de cadena XML.
