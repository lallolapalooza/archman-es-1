NOMBRE

XmListGetMatchPos — Una función de Lista que devuelve todas las instancias de un elemento en la lista

SINOPSIS

#include <Xm/List.h>
Boolean XmListGetMatchPos(
Widget widget,
XmString item,
int **position_list,
int *position_count);

DESCRIPCIÓN

XmListGetMatchPos es una función booleana que devuelve una matriz de posiciones donde se encuentra un elemento especificado en una Lista.

widget
Especifica el ID del widget de Lista.
item
Especifica el elemento a buscar.
position_list
Devuelve una matriz de posiciones en las que aparece el elemento en la Lista. La posición del primer elemento de la lista es 1; la posición del segundo elemento es 2; y así sucesivamente. Cuando el valor de retorno es True, XmListGetMatchPos asigna memoria para esta matriz. El llamador es responsable de liberar esta memoria. El llamador puede recuperar la memoria asignada llamando a XtFree.
position_count
Devuelve el número de elementos en la position_list.

Para una definición completa de Lista y sus recursos asociados, consulte XmList(3).

RETORNO

Devuelve True si el elemento especificado está presente en la lista y False si no lo está.

RELACIONADOS

XmList(3).
