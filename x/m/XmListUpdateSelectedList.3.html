NOMBRE

XmListUpdateSelectedList — Una función de Lista que actualiza el recurso XmNselectedItems

SINOPSIS

#include <Xm/List.h>
void XmListUpdateSelectedList(
Widget widget);

DESCRIPCIÓN

XmListUpdateSelectedList libera el contenido de la lista actual XmNselectedItems. La rutina recorre la lista XmNitems y añade cada elemento actualmente seleccionado a la lista XmNselectedItems. Por cada elemento seleccionado, hay una entrada correspondiente en la lista actualizada XmNselectedItems.

widget
Especifica el ID del widget Lista a actualizar

Para una definición completa de Lista y sus recursos asociados, ver XmList(3).

RELACIONADO

XmList(3).
