NOMBRE

XmStringTableProposeTablist — Una función de conveniencia que devuelve una lista de tabulaciones

SINOPSIS

#include <Xm/Xm.h>
XmTabList XmStringTableProposeTablist(
XmStringTable strings,
Cardinal num_strings,
Widget widget,
float pad_value,
XmOffsetModel offset_model);

DESCRIPCIÓN

XmStringTableProposeTablist toma una estructura XmStringTable que contiene cadenas compuestas tabuladas, información sobre el relleno entre columnas y información de renderizado, y devuelve una lista de tabulaciones que, si se utiliza para renderizar las cadenas de la tabla, haría que las cadenas se alinearan en columnas sin solapamiento y con la cantidad especificada de relleno entre el elemento más ancho de cada columna y el inicio de la siguiente columna. Cada tabulación en la lista de tabulaciones tendría el mismo tipo de unidad que units, un modelo de desplazamiento de offset_model y un tipo de alineación de XmALIGNMENT_BEGINNING.

strings
Especifica una matriz de cadenas compuestas.
num_strings
Especifica el número de cadenas compuestas en strings.
widget
Especifica el widget utilizado para derivar cualquier información necesaria para crear la representación. En particular, el XmNunitType del widget se utilizará para especificar el tipo de unidad que se utilizará para determinar la cantidad de relleno que separa las columnas y para las tabulaciones en la lista de tabulaciones propuesta. Además, la tabla de renderizado del widget se utilizará para interpretar las etiquetas de renderizado dentro de las cadenas.
pad_value
Especifica el valor de la cantidad de relleno que se utilizará para separar las columnas. Las unidades para este parámetro se especifican como el XmNunitType establecido para el parámetro widget. Consulte la recurso XmNunitType de la página de referencia de XmGadget, XmManager o XmPrimitive.
offset_model
Especifica el modelo de desplazamiento que se utilizará al crear las tabulaciones. Puede ser XmABSOLUTE o XmRELATIVE.

RETORNO

Devuelve una nueva XmTabList. La función asigna espacio para alojar la lista de tabulaciones devuelta. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmTabListFree.

RELACIONADO

XmTabList(3) y XmTabListFree(3).
