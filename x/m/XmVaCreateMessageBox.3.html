XmVaCreateMessageBox(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmVaCreateMessageBox(llamada a biblioteca) XmVaCreateMessageBox(llamada a biblioteca)

NOMBRE

XmVaCreateMessageBox, XmVaCreateManagedMessageBox — Funciones de conveniencia para la creación de MessageBox.

SINOPSIS

#include <Xm/MessageB.h>
Widget XmVaCreateMessageBox(
Widget parent,
String name,
...);
Widget XmVaCreateManagedMessageBox(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget ToggleButtonGadget y devuelven el ID del widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos variables ANSI C (varargs).

La función XmVaCreateMessageBox es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreateMessageBox es una rutina de conveniencia que llama a XtCreateManagedWidget.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de MessageBox y sus recursos asociados, consulte XmMessageBox(3).

RETORNO

Devuelve el ID del widget MessageBox.

RELACIONADO

XmMessageBox(3), XmCreateMessageBox(3), XtCreateWidget(3), y XtCreateManagedWidget(3).
