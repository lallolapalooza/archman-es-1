NOMBRE

XML::LibXML::SAX::Builder - Construye árboles DOM a partir de eventos SAX.

SINOPSIS

use XML::LibXML::SAX::Builder;
my $builder = XML::LibXML::SAX::Builder->new();
my $gen = XML::Generator::DBI->new(Handler => $builder, dbh => $dbh);
$gen->execute("SELECT * FROM Users");
my $doc = $builder->result();

DESCRIPCIÓN

Este es un manejador SAX que genera un árbol DOM a partir de eventos SAX. El uso es como se muestra arriba. Se acepta entrada de cualquier generador de eventos SAX1 o SAX2.

Construir árboles DOM a partir de eventos SAX es bastante fácil con XML::LibXML::SAX::Builder. La clase está diseñada como un manejador final de SAX2, ¡no como un filtro!

Dado que SAX está estrictamente orientado a flujos, no esperes que nada devuelva un generador. En su lugar, debes solicitar directamente a la instancia del constructor que obtenga el documento construido. La función result() de XML::LibXML::SAX::Builder contiene el documento generado a partir del último flujo SAX.
