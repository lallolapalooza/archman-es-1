NOMBRE

XmRegisterSegmentEncoding — Una función de cadena compuesta que registra un formato de codificación de texto compuesto para una etiqueta de elemento de lista de fuentes especificada

SINOPSIS

#include <Xm/Xm.h>
char * XmRegisterSegmentEncoding(
char *fontlist_tag,
char *ct_encoding);

DESCRIPCIÓN

XmRegisterSegmentEncoding registra un formato de codificación de texto compuesto con la etiqueta de elemento de lista de fuentes especificada. La función XmCvtXmStringToCT utiliza este registro para mapear las etiquetas de lista de fuentes de los segmentos de cadena compuesta a los formatos de codificación de texto compuesto. Registrar una etiqueta de lista de fuentes que ya existe en el registro sobrescribe la entrada original. Puede anular el registro de una etiqueta de lista de fuentes pasando un valor NULL para el parámetro ct_encoding.

fontlist_tag
Especifica la etiqueta del elemento de lista de fuentes a registrar. La etiqueta debe ser una cadena ISO8859-1 terminada en NULL.
ct_encoding
Especifica el conjunto de caracteres de texto compuesto que se utilizará para los segmentos con la etiqueta de lista de fuentes. El valor debe ser una cadena ISO8859-1 terminada en NULL. Un valor de XmFONTLIST_DEFAULT_TAG mapea la etiqueta de lista de fuentes especificada al conjunto de códigos de la configuración regional.

RETORNO

Devuelve NULL para una nueva etiqueta de lista de fuentes o el valor antiguo de ct_encoding para una etiqueta de lista de fuentes ya registrada. La aplicación es responsable de liberar el almacenamiento asociado con los datos devueltos (si los hay) llamando a XtFree.

RELACIONADO

XmCvtXmStringToCT(3), XmFontList(3), XmMapSegmentEncoding(3), y XmString(3).
