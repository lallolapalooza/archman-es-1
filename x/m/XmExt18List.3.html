NOMBRE

El widget de lista extendida internacionalizada

SINOPSIS

#include <Xm/Ext18List.h>

DESCRIPCIÓN

Este widget contiene una lista de varias columnas con encabezados en la parte superior y un área de búsqueda en la parte inferior. La lista tiene barras de desplazamiento en los bordes derecho e inferior que permiten el desplazamiento vertical y horizontal tanto por columna como por píxel. La porción de los datos de la lista que es actualmente visible puede ser alterada por las acciones de la barra de desplazamiento, el establecimiento de recursos del widget y la redibujación de los datos de la lista después de que una búsqueda de cadenas se haya completado con éxito. También se admite la ordenación de elementos dentro de una columna determinada. Para ordenar la lista por los elementos de una columna dada, seleccione el título de la columna.

Para buscar una cadena particular en la lista, escriba el valor de la cadena a buscar en el campo de texto asociado a la lista y luego presione el botón "Find". La búsqueda de la cadena comienza en la fila actualmente seleccionada, después de la ubicación de la cadena buscada previamente, o en la primera columna y primera fila si no hay ninguna columna seleccionada. Si la cadena no se encuentra en esa fila, la búsqueda continúa a través de todas las filas posteriores y luego anteriores a la fila actualmente seleccionada. Si se encuentra la cadena, la visualización de la lista se ajusta para hacer visible la cadena. Si la cadena no se encontró, o si la cadena es visible, la aplicación emitirá un pitido de advertencia.

El botón uno del puntero permite al usuario seleccionar una fila o una columna para ordenarla. Las devoluciones de llamada en la lista doubleClickCallback se llaman cuando el usuario hace doble clic con el botón uno del puntero. Si los datos de la lista pueden contener un mapa de bits de fila para mostrar en el extremo izquierdo de la fila.

Todos los nombres de recursos comienzan con XmN y todos los nombres de clases de recursos comienzan con XmC.

columnTitles

Este es un array de longitud numColumns de cadenas que se muestran en la parte superior de cada columna. Los datos son asignados y mantenidos por el cliente.

doubleClickCallback

Todas las rutinas en esta lista se llamarán cada vez que el usuario haga doble clic en una fila de la lista.

entryData

Este recurso son los datos asociados con cada fila de la lista. Los datos son un array de estructuras Xm18RowInfo de longitud numRows asignadas por el cliente. Los datos son asignados y mantenidos por el cliente. La estructura Xm18RowInfo se define a continuación.

findLabel

La etiqueta que se mostrará en el botón de búsqueda.

firstColumn

Este recurso permite al cliente ajustar la vista actual de los datos de la lista para tener una nueva ubicación de columna superior izquierda. Al establecer este recurso, firstRow también debe actualizarse.

firstColumnPixmaps

Este recurso especifica que el mapa de bits almacenado en la estructura de información de fila se utilizará en lugar de Xm18RowInfo values[0]. Si hay mapas de bits presentes, las filas pueden ser arrastradas presionando en el mapa de bits con el botón tres del puntero. Si este recurso es True, entonces values[0] nunca se referencia. Si es False, entonces el mapa de bits de datos de Xm18RowInfo nunca se referencia.

firstRow

Este recurso permite al cliente ajustar la vista actual de los datos de la lista para tener una nueva ubicación de fila superior izquierda. Al establecer este recurso, firstColumn también debe actualizarse.

fontList

Esta es una lista de fuentes estilo OSF/Motif. La primera fuente en esta lista se utilizará para mostrar todo el texto en el widget de Lista Extendida. Actualmente, el widget de Lista Extendida solo admite una fuente.

height

Este es el valor general de altura asignado al widget de Lista Extendida. Modificar este recurso afectará el tamaño y la ubicación de las barras de desplazamiento.

numColumns

numRows

Estos recursos especifican el número de columnas y filas que el widget espera mostrar. Estos recursos se utilizan como índices máximos para muchos de los otros recursos en este widget. Se debe tener cuidado al modificar estos recursos para garantizar que los otros valores también se hayan modificado.

selectedColumn

Este es el índice de la columna actualmente seleccionada. Esta es también la columna por la que se está ordenando la lista.

selectionPolicy

Define la interpretación de la acción de selección. Este recurso puede tener los valores XmSINGLE_SELECT o XmEXTENDED_SELECT. Otros valores dan como resultado un comportamiento indefinido.

showFind

Este booleano gestiona y desgestiona el botón de búsqueda

singleSelectionCallback

Todas las rutinas en esta lista se llamarán cada vez que el usuario haga clic en una línea de la lista. Se pasa un puntero a la estructura Xm18RowInfo correspondiente a la línea seleccionada como call_data. Si está en modo de selección extendida, el valor de call_data es indefinido.

sortFunctions

Este es un array de funciones, una para cada columna, que se llaman para determinar el orden de las filas en la columna, similar a qsort.

title

Este es el título que se muestra en la parte superior del widget de Lista Extendida. Si este valor es NULL, el área del título no se mostrará.

NAME

XmExt18List

extended list widget

SYNOPSIS

#include <Xm/Ext18List.h>

DESCRIPTION

The Extended List widget provides a table-oriented view of data. It is composed of a label, a scrollable list, and an optional find area. The list itself is made up of rows and columns. The Extended List widget provides a convenient way to display and manipulate this data.

The Extended List widget allows the user to select multiple rows, and provides callbacks for single clicks, double clicks, and selection changes.

Resources

The class record name is XmExt18List.

The following resources are available for the XmExt18List widget.

Normal Resources

columnTitles
A String array which contains the titles for each column. This resource is initialized from the XmNcolumnTitles resource of the XmList widget. See the XmList man page for details.
doubleClickCallback
A list of callbacks that are invoked when the user double clicks on a row. The callback reason is XmCR_DOUBLE_CLICK.
entryData
This resource is used to associate data with each row of the list. It is an array of Xm18RowInfo structures. See "The Xm18RowInfo Structure" section below for details.
findLabel
A String which is displayed as the label for the find area. If this resource is NULL or an empty string, the find area will not be displayed.
firstColumn
A Boolean which, if True, indicates that the first column is reserved for pixmaps. If True, the first element of the XmNentryData resource's values field will not be used.
firstColumnPixmaps
A Boolean which, if True, indicates that the first column is reserved for pixmaps. If True, the first element of the XmNentryData resource's values field will not be used. This resource is initialized from the XmNfirstColumnPixmaps resource of the XmList widget. See the XmList man page for details.
firstRow
A Boolean which, if True, indicates that the first row is reserved for the widget's label. If True, the first element of the XmNentryData resource will not be used. This resource is initialized from the XmNfirstRow resource of the XmList widget. See the XmList man page for details.
labelString
The label for the Extended List widget. This resource is initialized from the XmNlabelString resource of the XmLabel widget.
list
A pointer to the XmList widget which is the core of the Extended List widget. This resource is read-only.
numColumns
The number of columns in the list. This resource is initialized from the XmNnumColumns resource of the XmList widget.
scrollBarDisplayPolicy
Determines when the scrollbars are displayed. This resource is initialized from the XmNscrollBarDisplayPolicy resource of the XmScrolledWindow widget. See the XmScrolledWindow man page for details.
scrollBarPlacement
Determines the placement of the scrollbars. This resource is initialized from the XmNscrollBarPlacement resource of the XmScrolledWindow widget. See the XmScrolledWindow man page for details.
singleSelectionCallback
A list of callbacks that are invoked when the user clicks on a row. The callback reason is XmCR_SINGLE_SELECTION.
sortCallback
A callback that is invoked when the user selects the sort option from the pop-up menu. This callback is responsible for sorting the list. The callback is passed a pointer to the Xm18SortRec structure, which contains the column to be sorted and a pointer to the XmList widget.
textTranslations
A XtTranslations string which is appended to the translations for the text widget in the find area. This allows the application programmer to add new translations to the find area's text widget.
width
This is the overall width value assigned to the Extended List widget. Modifying this resource will affect scrollbar size and location.

Specifying Children Resources

The Extended List widget is composed of many simple widgets. In order to achieve full functionality of the Toolkit, it is sometimes desirable to set attribute values directly on those widgets. The widget ids of the sub-widgets can be obtained by using the XtNameToWidget() function provided by the Xt Intrinsics.

XmText findText

Using the Resource Database

The Extended List widget is actually a collection of pieces. It provides the geometry layout for the collection as well as tying together the pieces to form a consistent package. Many of the resources that are documented as being part of the Extended List widget are really part of the internal list sub-component. The Extended List widget will pass these values through to the proper child when they are set at time of creation or with XtSetValues or XtGetValues. However, when setting a resource via the resource database you must use either the name of the child or the general specification (*) rather than the specific one (.).

The Xm18RowInfo Structure

The Xm18RowInfo structure is used to contain the entryData associated with each Row in the Extended List.

typedef struct _Xm18RowInfo{

/*


* Used by the IList widget


*/

String * values; /* The array of column strings */

Pixmap pixmap; /* mini-icon pixmaps. */

Boolean selected; /* row selected. */

/*

* Provided for the convenience of the application programmer

*/

short * sort_id;

XtPointer data;

/*

* Private to the Extended List widget (do not modify these)

*/

short pix_width; /* of the pixmap. */

short pix_height; /* of the pixmap. */

short pix_depth; /* of the pixmap. */

Boolean old_sel_state;

} Xm18RowInfo;

values This is an array of strings of length numColumns which represents the strings displayed in each column of this row. The data is allocated and maintained by the client. If firstColumnPixmaps is True, then value[0] is never referenced.

pixmap This is the pixmap displayed to the left of this row. If firstColumnPixmaps is True then this value is never referenced and mayn remain unset. If no pixmap is desired for this row, even though firstColumnPixmaps is True, set the value of pixmap to None. Color pixmaps may be used.

sort_id This is provided for the convenience of the client and is expected to be used as a sort index for this row. One value should be specified for each column of the row. See "sortFunctions" below for details.

data This is provided for the convenience of the client and may be used for any purpose. It is intended to be used as an identifier for the object pointed to by this row

selected This value is True if this row is selected; may be set by the application.

Neither sort_id nor data are used by the Extended List widget; they exist solely for the convenience of the programmer.

Translations and Actions

The following are the default translation bindings used by the icon button:

~Ctrl ~Shift <Btn1Down>: ButtonDown()
Ctrl ~Shift <Btn1Down>: ButtonDown(Toggle)
~Ctrl Shift <Btn1Down>: ButtonDown(Extend)
Button1 <Motion>: Motion()
<Btn1Up>: ButtonUpOrLeave()

The following actions are supported by the icon button:

ButtonDown(type)

Processes a button press action that may begin with either a select or a double click. The type argument can be either Toggle or Extend. These values determine which mode of an extended select will be initiated on this button event. Consult the OSF/Motif Style Guide for details.

Motion()

Processes motion events to allow the selection region to be modified when in extended selection mode. It is assumed that this action is called between a ButtonDown() and ButtonUpOrLeave() action.

ButtonUpOrLeave()

Cleans up after ButtonDown() and Motion().

Callback Routines

All procedures on the Extended List's singleSelectionCallback and doubleClickCallback lists will have a pointer to a Xm18RowInfo structure passed to them in the call_data field. This structure is defined above.

Note: if a single SelectionCallback is registered on an extended list in extended_se- lect_mode, the value of call_data is undefined.

void (callback)(Widget w, XtPointer client_data, XtPointer call_data)

w the Extended List widget

client_data the client data specified by the application

call_data a pointer to an Xm18RowInfo structure corrsponding the the row selected

Sort Function

typedef int (Xm18SortFunction) (short column, Xm18RowInfo * row1, Xm18RowInfo * row2);

column the column currently being sorted

row1, row2 the two rows being compared. The return value must be an integer less than, equal to, or greater than 0, depending on whether the first argument is less than, equal to, or greater than the second.

Convenience Routines

XmExt18ListGetSelectedRows

Xm18RowInfo ** XmExt18ListGetSelectedRows (Widget w)

w extended list widget

Use the XmExt18ListGetSelectedRows function to find the rows that currently are selected in an extended list. The Xm18RowInfo ** returned by this function contains a NULL terminated array of Xm18RowInfo pointers. The calling routine is responsible for freeing the returned pointer with XtFree(). The function will return NULL if no elements are selected.

XmCreateExtended18List

Widget XmCreateExtended18List(Widget parent, String name, ArgList args, Cardinal num_args)

parent parent of the extended list widget to be created
name name of the extended list widget to be created
args arguments to pass to XtCreateWidget for the extended list
num_args number of arguments passed

This convenience routine simply takes the passed parameters and calls XtCreateWidget, returning the widget created.

XmExt18ListUnselectAllItems

void XmExt18ListUnselectAllItems( Widget w )

w the extended list widget to be modified

Unselects all rows of the passed extended list widget and returns nothing.

XmExt18ListUnselectItem

void XmExt18ListUnselectItem(Widget w, Xm18RowInfo *row_info)

w extended list widget
row_info pointer to the row which is to be unselected.

Unselects the row designated by row_info of the passed extended list widget w

    NOMBRE

    XmExt18List - Un widget de lista extendida.

    SINOPSIS

    #include <Xm/Ext18List.h>

    Un widget XmExt18List es un widget de lista para mostrar una lista de elementos en varias columnas. Los elementos pueden ser seleccionados por el usuario. El widget permite la selección de varios elementos, la especificación de encabezados para columnas, y la definición de funciones de ordenación y búsqueda.

    DESCRIPCIÓN

    El widget XmExt18List proporciona una lista de elementos que se pueden organizar en múltiples columnas. Soporta la selección de elementos, la visualización de encabezados de columna y la personalización del comportamiento mediante callbacks y funciones de ordenación.

    INSTRUCCIONES

    El widget XmExt18List puede ser creado usando la siguiente función: 

    Widget XmCreateExtended18List(Widget parent, const char *name,
                              ArgList arglist, Cardinal argcount);
