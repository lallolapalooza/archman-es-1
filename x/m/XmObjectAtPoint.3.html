NOMBRE

XmObjectAtPoint — Una función del toolkit que determina qué hijo (child) intersecta o se aproxima más a un punto especificado

SINOPSIS

#include <Xm/Xm.h>
Widget XmObjectAtPoint(
Widget widget,
Position x,
Position y);

DESCRIPCIÓN

XmObjectAtPoint busca en la lista de hijos del widget gestor especificado y devuelve el hijo más estrechamente asociado con el par de coordenadas x,y especificado.

Para el widget gestor típico de Motif, XmObjectAtPoint utiliza las siguientes reglas para determinar el objeto devuelto:

•
Si un hijo intersecta x,y, XmObjectAtPoint devuelve el ID del widget de ese hijo.
•
Si más de un hijo intersecta x,y, XmObjectAtPoint devuelve el ID del widget del hijo visible.
•
Si ningún hijo intersecta x,y, XmObjectAtPoint devuelve NULL.

Las reglas anteriores son solo generales. De hecho, cada widget gestor es libre de definir "más estrechamente asociado" como desee. Por ejemplo, si ningún hijo intersecta x,y, un gestor podría devolver el hijo más cercano a x,y.

widget
Especifica un widget gestor.
x
Especifica la coordenada x sobre la que se busca información del hijo. La coordenada x debe especificarse en píxeles, relativa al lado izquierdo del gestor.
y
Especifica la coordenada y sobre la que se busca información del hijo. La coordenada y debe especificarse en píxeles, relativa a la parte superior del gestor.

RETORNO

Devuelve el hijo del gestor más estrechamente asociado con x,y. Si ninguno de sus hijos está suficientemente asociado con x,y, devuelve NULL.

RELACIONADO

XmManager(3).
