XmVaCreateContainer(llamada a biblioteca) XmVaCreateContainer(llamada a biblioteca)

NOMBRE

XmVaCreateContainer, XmVaCreateManagedContainer — Funciones de conveniencia para la creación de widgets Container.

SINOPSIS

#include <Xm/Container.h>
Widget XmVaCreateContainer(
Widget parent,
String name,
...);
Widget XmVaCreateManagedContainer(
Widget parent,
String name,
...);

DESCRIPCIÓN

Estas funciones crean una instancia de un widget Container y devuelven el ID del widget asociado. Estas rutinas utilizan la convención de llamada de lista de argumentos variables (varargs) de ANSI C.

La función XmVaCreateContainer es una rutina de conveniencia que llama a XtCreateWidget.

La función XmVaCreatemanagedContainer es una rutina de conveniencia que llama a XtCreateManagedWidget.

parent
Especifica el ID del widget padre.
name
Especifica el nombre del widget creado.
...
Especifica la lista de argumentos variables para anular los valores predeterminados de los recursos.

Para una definición completa de Container y sus recursos asociados, consulte XmContainer(3).

RETORNO

Devuelve el ID del widget Container.

RELACIONADOS

XmContainer(3), XmCreateContainer(3), XtCreateWidget(3) y XtCreateManagedWidget(3).
