NOMBRE

XmContainerReorder — Función del widget Container para reordenar hijos

SINOPSIS

#include <Xm/Container.h>
void XmContainerReorder(
Widget container,
WidgetList widgets,
int num_widgets);

DESCRIPCIÓN

XmContainerReorder obtiene los recursos de restricción XmNpositionIndex de cada widget especificado en widgets, los ordena en orden ascendente e inserta los recursos de restricción XmNpositionIndex en el nuevo orden en cada widget. Si el recurso XmNlayoutType de Container es XmOUTLINE o XmDETAIL, XmContainerReorder forzará una disposición de todos los elementos.

container
Especifica el ID del widget Container.
widgets
Especifica un array de widgets hijos de container.
num_widgets
Especifica el número de elementos en el array widgets.

Para una definición completa de Container y sus recursos asociados, consulte XmContainer(3).

RELACIONADO

XmContainer(3).
