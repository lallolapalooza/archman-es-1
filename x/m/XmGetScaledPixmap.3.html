XmGetScaledPixmap(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmGetScaledPixmap(llamada a biblioteca) XmGetScaledPixmap(llamada a biblioteca)

NOMBRE

XmGetScaledPixmap — lee un archivo pixmap y lo escala según la resolución del pixmap y de la impresión

SINOPSIS

#include <Xm/Xm.h>
XtEnum XmGetScaledPixmap(
Widget widget,
String image_name,
Pixel foreground,
Pixel background,
int depth,
Double scaling_ratio);

DESCRIPCIÓN

XmGetScaledPixmap utiliza su argumento Widget para buscar un ancestro de tipo Print Shell y obtener la resolución del pixmap y la información de resolución de la impresora predeterminada para ser utilizada si scaling_ratio ==0.

Si el escalado es 0, y hay un PrintShell válido presente, XmGetScaledPixmap aplica una relación igual a (resolución de la impresora / resolución predeterminada del pixmap) antes de crear el Pixmap en la Pantalla del widget. De lo contrario, el scaling_ratio se utiliza para escalar ambas dimensiones de la imagen que se está convirtiendo en un Pixmap.

XmGetScaledPixmap completa la API existente de XmGetPixmapByDepth al utilizar el XmNdefaultPixmapResolution del XmPrintShell anfitrión. Consulte la documentación de XmGetPixmapByDepth para obtener más detalles.

widget
Widget utilizado para determinar la resolución predeterminada del pixmap (del ancestro de tipo Print Shell).
image_name
Ver XmGetPixmapByDepth para la descripción.
foreground
Ver XmGetPixmapByDepth para la descripción.
background
Ver XmGetPixmapByDepth para la descripción.
depth
Ver XmGetPixmapByDepth para la descripción.
scaling_ratio
Indica la relación de escalado a aplicar, o 0.

VALOR DE RETORNO

Devuelve un Pixmap o NULL si falla.

ERRORES/ADVERTENCIAS

Igual que para XmGetPixmapByDepth.

VER TAMBIÉN

XmPrintSetup(3), XmPrintShell(3), XmRedisplayWidget(3)
