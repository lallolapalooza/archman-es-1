NOMBRE

XmLabel — La clase de widget Label

SINOPSIS

#include <Xm/Label.h>

DESCRIPCIÓN

Label es un widget instanciable y también se utiliza como superclase para otros widgets de botón, como PushButton y ToggleButton. El widget Label no acepta ninguna entrada de botón o teclado, y la devolución de llamada de ayuda es la única devolución de llamada definida. Label también recibe eventos de entrada y salida.

Label puede contener texto o un pixmap. El texto de Label es una cadena compuesta. Consulte la Motif Programmer's Guide para obtener más información sobre cadenas compuestas. El texto puede ser multilingüe, multilínea y/o de múltiples fuentes. Cuando un Label está inactivo, su texto se puntuea, o se muestra el pixmap inactivo proporcionado por el usuario.

Label admite tanto aceleradores como mnemónicos, principalmente para su uso en widgets subclase de Label contenidos en menús. Los mnemónicos están disponibles en un sistema de menús cuando el botón es visible. Los aceleradores en un sistema de menús son accesibles incluso cuando el botón no es visible. El widget Label muestra el mnemónico subrayando el primer carácter coincidente en la cadena de texto. El acelerador se muestra como una cadena de texto adyacente al texto o pixmap de la etiqueta, dependiendo de la dirección de diseño.

Label consta de muchos campos de margen que rodean el texto o pixmap. Estos campos de margen son recursos que pueden ser establecidos por el usuario, pero las subclases de Label y los padres Manager también modifican algunos de estos campos. Tienden a modificar los recursos XmNmarginLeft, XmNmarginRight, XmNmarginTop y XmNmarginBottom, y dejan los recursos XmNmarginWidth y XmNmarginHeight como los estableció la aplicación.

Label tiene en cuenta XmNshadowThickness al determinar su diseño, pero no dibuja la sombra. Es decir, si XmNshadowThickness es mayor que 0 (cero), Label deja espacio para la sombra, pero la sombra no aparece.

En un Label, XmNtraversalOn y XmNhighlightOnEnter se fuerzan a False dentro de los paneles de menú emergentes, los paneles de menú desplegables y los menús de opciones. De lo contrario, estos recursos tienen el valor predeterminado de False.

Label utiliza los rasgos XmQTmenuSystem y XmQTspecifyRenderTable, y posee los rasgos XmQTaccessTextual, XmQTmenuSavvy y XmQTtransfer.

Comportamiento de transferencia de datos

Label y sus subclases, excepto cuando se usan en un sistema de menús, admiten la extracción del contenido de la etiqueta desde el Label. Sin embargo, el contenido de la etiqueta solo se puede extraer si el recurso XmNenableUnselectableDrag de XmDisplay está establecido en True.

Como fuente de datos, Label y sus subclases admiten los siguientes objetivos y las conversiones asociadas de datos a estos objetivos:

local
Si el objetivo local coincide con el local del widget, el widget transfiere XmNlabelString en la codificación del local. Este objetivo es compatible cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
COMPOUND_TEXT
El widget transfiere XmNlabelString como tipo COMPOUND_TEXT. Este objetivo es compatible cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
UTF8_STRING
El widget transfiere XmNlabelString como tipo UTF8_STRING. Este objetivo es compatible cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
PIXMAP
El widget transfiere XmNlabelPixmap como tipo DRAWABLE. Este objetivo es compatible cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING.
STRING
El widget transfiere XmNlabelString como tipo STRING. Este objetivo es compatible cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
TEXT
Si XmNlabelString es completamente convertible a la codificación del local, el widget transfiere XmNlabelString en la codificación del local. De lo contrario, el widget transfiere XmNlabelString como tipo COMPOUND_TEXT. Este objetivo es compatible solo cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.

El widget transfiere XmNlabelString como una cadena compuesta en formato Byte Stream. Este objetivo es compatible cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING.
_MOTIF_EXPORT_TARGETS
El widget transfiere, como tipo ATOM, una lista de los objetivos que se utilizarán como valor de XmNexportTargets del DragContext en una transferencia de arrastrar y soltar. Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widgets utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar atributos para este widget. Para hacer referencia a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y use las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y use las letras restantes (en minúscula o mayúscula, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), establecer usando XtSetValues (S), recuperar usando XtGetValues (G) o no es aplicable (N/A).

XmNaccelerator
Establece el acelerador en un widget de botón en un menú, el cual activa un botón visible o invisible, pero administrado, desde el teclado. Este recurso es una cadena que describe un conjunto de modificadores y la tecla que se puede usar para seleccionar el botón. El formato de esta cadena es idéntico al utilizado por el administrador de traducciones, con la excepción de que solo se puede especificar un evento y solo se permiten eventos KeyPress.
Los aceleradores para botones solo se admiten para PushButtons y ToggleButtons en paneles de menú desplegables y emergentes.
XmNacceleratorText
Especifica el texto que se muestra para el acelerador. El texto se muestra adyacente a la cadena de etiqueta o al mapa de bits. La dirección de su diseño depende del recurso XmNlayoutDirection del widget. El texto del acelerador para los botones solo se muestra para PushButtons y ToggleButtons en menús desplegables y emergentes.
XmNalignment
Especifica la alineación de la etiqueta para texto o mapa de bits.
XmALIGNMENT_BEGINNING (alineación a la izquierda)
Hace que los lados izquierdos de las líneas de texto se alineen verticalmente con el borde izquierdo de la ventana del widget. Para un mapa de bits, su lado izquierdo se alinea verticalmente con el borde izquierdo de la ventana del widget.
XmALIGNMENT_CENTER (alineación al centro)
Hace que los centros de las líneas de texto se alineen verticalmente en el centro de la ventana del widget. Para un mapa de bits, su centro se alinea verticalmente con el centro de la ventana del widget.
XmALIGNMENT_END (alineación a la derecha)
Hace que los lados derechos de las líneas de texto se alineen verticalmente con el borde derecho de la ventana del widget. Para un mapa de bits, su lado derecho se alinea verticalmente con el borde derecho de la ventana del widget.
Las descripciones anteriores para el texto son correctas cuando XmNlayoutDirection es XmLEFT_TO_RIGHT. Cuando ese recurso es XmRIGHT_TO_LEFT, las descripciones para XmALIGNMENT_BEGINNING y XmALIGNMENT_END se intercambian.
Si el padre es un RowColumn cuyo recurso XmNisAligned es True, XmNalignment se fuerza al mismo valor que XmNentryAlignment del RowColumn si XmNrowColumnType del RowColumn es XmWORK_AREA o si el widget es una subclase de XmLabel. De lo contrario, el valor predeterminado es XmALIGNMENT_CENTER.
XmNfontList
Especifica la fuente del texto utilizado en el widget. XmNfontList está obsoleto y existe por compatibilidad con versiones anteriores. Ahora debe usar XmNrenderTable en lugar de XmNfontList. Si se especifican ambos, la tabla de renderizado tendrá prioridad. Si XmNfontList es NULL al inicializar, Label busca en su jerarquía de padres un ancestro que sea una subclase de las clases de widgets XmBulletinBoard, VendorShell o XmMenuShell. Si se encuentra dicho ancestro, Label inicializa XmNfontList con el XmNlabelFontList del widget ancestro. Del mismo modo, las subclases de botón de Label inicializan XmNfontList con el XmNbuttonFontList del widget ancestro. (Actualmente, todas las subclases de Label son subclases de botón). Si no se encuentra ningún ancestro de este tipo, el valor predeterminado depende de la implementación. Consulte XmFontList(3) para obtener más información sobre la creación y estructura de una lista de fuentes.
XmNlabelInsensitivePixmap
Especifica un mapa de bits que se utilizará como cara del botón si XmNlabelType es XmPIXMAP y el botón es insensible. El valor predeterminado, XmUNSPECIFIED_PIXMAP, muestra una etiqueta vacía.
XmNlabelPixmap
Especifica el mapa de bits cuando XmNlabelType es XmPIXMAP o XmPIXMAP_AND_STRING. El valor predeterminado, XmUNSPECIFIED_PIXMAP, muestra una etiqueta vacía.
XmNlabelString
Especifica la cadena compuesta cuando XmNlabelType es XmSTRING o XmPIXMAP_AND_STRING. Si este valor es NULL, se inicializa convirtiendo el nombre del widget en una cadena compuesta. Consulte XmString(3) para obtener más información sobre la creación y estructura de cadenas compuestas.
XmNlabelType
Especifica el tipo de etiqueta.
XmSTRING
Muestra texto utilizando XmNlabelString.
XmPIXMAP
Muestra mapa de bits utilizando XmNlabelPixmap o
XmPIXMAP_AND_STRING
Muestra texto y mapa de bits utilizando XmNlabelPixmap o XmNlabelInsensitivePixmap y XmNlabelString.
XmNmarginBottom
Especifica la cantidad de espacio entre la parte inferior del texto de la etiqueta y la parte superior del margen inferior especificado por XmNmarginHeight. Esto puede ser modificado por las subclases de Label. Por ejemplo, CascadeButton puede aumentar este campo para dejar espacio para el mapa de bits de cascada.
XmNmarginHeight
Especifica una cantidad igual de espacio por encima del margen definido por XmNmarginTop y por debajo del margen definido por XmNmarginBottom. XmNmarginHeight especifica la cantidad de espacio entre el borde superior del margen establecido por XmNmarginTop y el borde inferior de la sombra superior, y la cantidad de espacio entre el borde inferior del margen especificado por XmNmarginBottom y el borde superior de la sombra inferior.
XmNmarginLeft
Especifica la cantidad de espacio entre el borde izquierdo del texto de la etiqueta y el lado derecho del margen izquierdo (especificado por XmNmarginWidth). Esto puede ser modificado por las subclases de Label. Por ejemplo, ToggleButton puede aumentar este campo para dejar espacio para el indicador de alternancia y el espacio entre el indicador y la etiqueta. Si esto se aplica realmente al lado izquierdo o derecho de la etiqueta depende del valor del recurso XmNlayoutDirection.
XmNmarginRight
Especifica la cantidad de espacio entre el borde derecho del texto de la etiqueta y el lado izquierdo del margen derecho (especificado por XmNmarginWidth). Esto puede ser modificado por las subclases de Label. Por ejemplo, CascadeButton puede aumentar este campo para dejar espacio para el mapa de bits de cascada. Si esto se aplica realmente al lado izquierdo o derecho de la etiqueta depende del valor del recurso XmNlayoutDirection.
XmNmarginTop
Especifica la cantidad de espacio entre la parte superior del texto de la etiqueta y la parte inferior del margen superior especificado por XmNmarginHeight. Esto puede ser modificado por las subclases de Label. Por ejemplo, CascadeButton puede aumentar este campo para dejar espacio para el mapa de bits de cascada.
XmNmarginWidth
Especifica una cantidad igual de espacio a la izquierda del margen definido por XmNmarginLeft y a la derecha del margen definido por XmNmarginRight. XmNmarginWidth especifica la cantidad de espacio entre el borde izquierdo del margen establecido por XmNmarginLeft y el borde derecho de la sombra izquierda, y la cantidad de espacio entre el borde derecho del margen especificado por XmNmarginRight y el borde izquierdo de la sombra derecha.
XmNmnemonic
Proporciona al usuario un medio alternativo para activar un botón. Un botón en una barra de menú, un panel de menú emergente o un panel de menú desplegable puede tener una mnemotecnia.
Este recurso contiene una tecla simbólica (keysym) tal como se enumera en la tabla de teclas simbólicas de X11. El primer carácter de la cadena de etiqueta que coincide exactamente con la mnemotecnia en el conjunto de caracteres especificado en XmNmnemonicCharSet se subraya cuando se muestra el botón.
Cuando se ha especificado una mnemotecnia, el usuario activa el botón presionando la tecla mnemotécnica mientras el botón es visible. Si el botón es un CascadeButton en una barra de menú y la barra de menú no tiene el foco, el usuario debe usar el modificador MAlt mientras presiona la mnemotecnia. El usuario puede activar el botón presionando la tecla mnemotécnica, ya sea con mayúsculas o sin ellas.
XmNmnemonicCharSet
Especifica el conjunto de caracteres de la mnemotecnia para la etiqueta. El valor predeterminado es XmFONTLIST_DEFAULT_TAG.
XmNpixmapPlacement
La ubicación del mapa de bits con respecto a la etiqueta de texto. Este recurso puede tomar uno de los siguientes valores: XmPIXMAP_TOP, XmPIXMAP_BOTTOM, XmPIXMAP_LEFT y XmPIXMAP_RIGHT. Se ha registrado un convertidor de tipos que convierte las siguientes cadenas: "top", "bottom", "left" y "right".
XmNpixmapTextPadding
La cantidad de espacio que se dejará entre el pixmap y la cadena de la etiqueta.
XmNrecomputeSize
Especifica un valor booleano que indica si el widget se encoge o se expande para acomodar su contenido (cadena de etiqueta o pixmap) como resultado de un valor de recurso XtSetValues que cambiaría el tamaño del widget. Si es True, el widget se encoge o expande para ajustarse exactamente a la cadena de etiqueta o al pixmap. Si es False, el widget nunca intenta cambiar de tamaño por sí mismo.
XmNrenderTable
Especifica la tabla de renderizado asociada con labelString. Si este valor es NULL en la inicialización, Label busca en la jerarquía de su padre un ancestro que contenga el rasgo XmQTspecifyRenderTable. Si se encuentra dicho ancestro, Label inicializa XmNrenderTable al valor XmLABEL_RENDER_TABLE del widget ancestro. De manera similar, las subclases de botón de Label inicializan XmNrenderTable al valor XmBUTTON_RENDER_TABLE del widget ancestro. (Tenga en cuenta que todas las subclases actuales de Label son subclases de botón.) Si no se encuentra ningún ancestro de este tipo, el valor predeterminado depende de la implementación. Si se especifican una lista de fuentes y una tabla de renderizado, la tabla de renderizado tendrá prioridad. Consulte XmRenderTable(3) para obtener más información sobre la creación y la estructura de una tabla de renderizado.
XmNstringDirection
Es un recurso sintético para establecer XmNlayoutDirection. Los valores para este recurso son XmSTRING_DIRECTION_L_TO_R y XmSTRING_DIRECTION_R_TO_L. Consulte la descripción del recurso XmNlayoutDirection. El recurso XmNstringDirection ha sido obsoleto por XmNlayoutDirection, pero se mantiene aquí por compatibilidad retroactiva.

Routines de Acción

Las routines de acción de XmLabel son:

Help():
En un Panel de Menú Emergente o Desplegable, despublica todos los menús en la jerarquía de menús y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de entrar en el sistema de menús. Llama a los callbacks para XmNhelpCallback si existen. Si no hay callbacks de ayuda para este widget, esta acción llama a los callbacks de ayuda del ancestro más cercano que los tenga.
MenuEscape():
En una Barra de Menú, desarma el Botón de Cascada y el menú y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de entrar en el menú.
En un Panel de Menú Desplegable de nivel superior de una Barra de Menú, despublica el menú, desarma el Botón de Cascada de la Barra de Menú y la Barra de Menú, y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget que tenía el foco antes de entrar en la Barra de Menú. En otros Paneles de Menú Desplegables, despublica el menú y mueve el foco a su Botón de Cascada.
En un Panel de Menú Emergente, despublica el menú y, cuando la política de foco del teclado del shell es XmEXPLICIT, restaura el foco del teclado al widget desde el cual se publicó el menú.
MenuTraverseDown():
Si el elemento de menú actual tiene un submenú y está en una Barra de Menú, esta acción publica el submenú, desarma el elemento de menú actual y arma el primer elemento de menú transitable del submenú.
Si el elemento de menú actual está en un Panel de Menú, esta acción desarma el elemento de menú actual y arma el elemento de debajo. Esta acción se envuelve dentro del Panel de Menú. La dirección del envolvimiento depende del recurso XmNlayoutDirection.
MenuTraverseLeft():
Cuando el elemento de menú actual está en una Barra de Menú, esta acción desarma el elemento actual y arma el elemento de la Barra de Menú a la izquierda. Esta acción se envuelve dentro de la Barra de Menú.
En Paneles de Menú, si el elemento de menú actual no está en el borde izquierdo de un Panel de Menú, esta acción desarma el elemento actual y arma el elemento a su izquierda. Si el elemento de menú actual está en el borde izquierdo de un submenú adjunto a un elemento de la Barra de Menú, entonces esta acción despublica el submenú y se desplaza al elemento de la Barra de Menú a la izquierda, envolviéndose si es necesario. Si ese elemento de la Barra de Menú tiene un submenú, publica el submenú y arma el primer elemento transitable del submenú. Si el elemento de menú actual está en el borde izquierdo de un submenú no adjunto directamente a un elemento de la Barra de Menú, entonces esta acción solo despublica el submenú actual.
En Paneles de Menú Emergentes o Desprendibles, cuando el elemento de menú actual está en el borde izquierdo, esta acción se envuelve dentro del Panel de Menú. Si el elemento de menú actual está en el borde izquierdo del Panel de Menú y no está en la fila superior, esta acción se envuelve al elemento de menú más a la derecha en la fila superior. Si el elemento de menú actual está en la esquina superior izquierda, esta acción se envuelve al control desprendible, si está presente, o de lo contrario, se envuelve al elemento de menú inferior más a la derecha en el Panel de Menú. La descripción anterior se aplica cuando la dirección horizontal de XmNlayoutDirection es XmLEFT_TO_RIGHT. Si la dirección horizontal de XmNlayoutDirection es XmRIGHT_TO_LEFT, entonces se aplica lo siguiente.

En Paneles de Menú, si el elemento de menú actual es un Botón de Cascada, entonces esta acción publica su submenú asociado. Si el elemento de menú actual no es un Botón de Cascada y no está en el borde izquierdo de un Panel de Menú, esta acción desarma el elemento actual y arma el elemento a su izquierda, envolviéndose si es necesario. Si el elemento de menú actual no es un Botón de Cascada y está en el borde izquierdo de un submenú que es un descendiente de una Barra de Menú, entonces esta acción despublica todos los submenús y se desplaza al elemento de la Barra de Menú a la izquierda. En menús emergentes o desprendibles, si el elemento de menú actual no es un Botón de Cascada y está en el borde izquierdo de una fila (excepto la fila inferior), esta acción se envuelve al elemento de menú más a la derecha en la fila inferior. ProcessDrag():
Arrastra el contenido de una Etiqueta, identificado cuando se presiona BTransfer. Esta acción establece el XmNconvertProc del DragContext a una función que llama a los procedimientos XmNconvertCallback, posiblemente varias veces, para la selección _MOTIF_DROP. Esta acción no está definida para Etiquetas utilizadas en un sistema de menús.
