XmVaCreateSimpleMenuBar(3)

Licencias: LGPL-2.1-or-later

XmVaCreateSimpleMenuBar(llamada de biblioteca) XmVaCreateSimpleMenuBar(llamada de biblioteca)

NOMBRE

XmVaCreateSimpleMenuBar — una función de conveniencia para la creación de widgets RowColumn

SINOPSIS

#include <Xm/RowColumn.h>
Widget XmVaCreateSimpleMenuBar(
Widget parent,
String name);

DESCRIPCIÓN

XmVaCreateSimpleMenuBar crea una instancia de un widget RowColumn de tipo XmMENU_BAR y devuelve el ID del widget asociado. Esta rutina utiliza la convención de llamada de lista de argumentos de longitud variable (varargs) de ANSI C.

Esta rutina crea una Barra de Menú y sus hijos CascadeButtonGadget. El nombre de cada botón es button_n, donde n es un entero desde 0 (cero) hasta el número de botones en el menú menos 1. Los botones se nombran y crean en el orden en que se especifican en la parte variable de la lista de argumentos.

parent
Especifica el ID del widget padre
name
Especifica el nombre del widget creado

La parte variable de la lista de argumentos consiste en grupos de argumentos. El primer argumento de cada grupo es una constante o una cadena y determina qué argumentos siguen en ese grupo. El último argumento de la lista debe ser NULL. A continuación se muestran los posibles primeros argumentos en cada grupo de varargs:

XmVaCASCADEBUTTON
Esto va seguido de dos argumentos adicionales. El conjunto especifica un botón en la Barra de Menú y algunos de sus valores de recurso. A continuación se muestran los dos argumentos adicionales, en orden:
etiqueta
La cadena de etiqueta, de tipo XmString
mnemotecnico
El mnemotécnico, de tipo KeySym
nombre_recurso
Esto va seguido de un argumento adicional, el valor del recurso, de tipo XtArgVal. El par especifica un recurso y su valor para el widget RowColumn.
XtVaTypedArg
Esto va seguido de cuatro argumentos adicionales. El conjunto especifica un recurso y su valor para el widget RowColumn. Se realiza una conversión de tipo de recurso si es necesario. A continuación se muestran los cuatro argumentos adicionales, en orden:
nombre
El nombre del recurso, de tipo String
tipo
El tipo del valor del recurso proporcionado, de tipo String
valor
El valor del recurso (o un puntero al valor del recurso, dependiendo del tipo y tamaño del valor), de tipo XtArgVal
tamaño
El tamaño del valor del recurso en bytes, de tipo int
XtVaNestedList
Esto va seguido de un argumento adicional de tipo XtVarArgsList. Este argumento es una lista anidada de varargs devuelta por XtVaCreateArgsList.

Para obtener más información sobre listas de argumentos de longitud variable, consulte la documentación de X Toolkit Intrinsics.

Existen varios recursos específicamente para su uso con esta y otras rutinas de creación de menús simples. Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RETORNO

Devuelve el ID del widget RowColumn.

RELACIONADO

XmCreateMenuBar(3), XmCreateRowColumn(3), XmCreateSimpleMenuBar(3), y XmRowColumn(3).
