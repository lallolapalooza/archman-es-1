NOMBRE

XmClipboardInquirePendingItems — Una función del portapapeles que devuelve una lista de pares ID de datos/ID privado

SINOPSIS

#include <Xm/CutPaste.h>
int XmClipboardInquirePendingItems (display, window, format_name, item_list, count)
        Display * display;
        Window  window;
        char    * format_name;
        XmClipboardPendingList  * item_list;
        unsigned long   * count;
(void)

DESCRIPCIÓN

XmClipboardInquirePendingItems devuelve una lista de pares ID de datos/ID privado para el nombre de formato especificado. Un elemento de datos se considera pendiente si la aplicación lo pasó originalmente por nombre, la aplicación aún no ha copiado los datos y el elemento no ha sido eliminado del portapapeles. La aplicación es responsable de liberar la memoria proporcionada por esta función para almacenar la lista. Para liberar la memoria, llame a XtFree.

Esta función es utilizada por una aplicación al salir, para determinar si los datos que se pasan por nombre deben enviarse al portapapeles.

display
Especifica un puntero a la estructura Display que se devolvió en una llamada anterior a XOpenDisplay o XtDisplay.
window
Especifica el ID de ventana de un widget que relaciona la ventana de la aplicación con el portapapeles. El ID de ventana del widget se puede obtener a través de XtWindow. La misma instancia de aplicación debe pasar el mismo ID de ventana a cada una de las funciones del portapapeles que llama.
format_name
Especifica una cadena que contiene el nombre del formato para el cual se va a obtener la lista de pares ID de datos/ID privado.
item_list
Especifica la dirección del array de pares ID de datos/ID privado para el nombre de formato especificado. Este argumento es de tipo XmClipboardPendingList. La aplicación es responsable de liberar la memoria proporcionada por esta función para almacenar la lista.
count
Especifica el número de elementos devueltos en la lista. Si no hay datos para el nombre de formato especificado, o si no hay ningún elemento en el portapapeles, este argumento es igual a 0 (cero).

RETORNO

XmClipboardSuccess
La función se ejecutó correctamente.
XmClipboardLocked
La función falló porque el portapapeles estaba bloqueado por otra aplicación. La aplicación puede seguir llamando a la función nuevamente con los mismos parámetros hasta que el bloqueo desaparezca. Esto le da a la aplicación la oportunidad de preguntar si el usuario desea seguir intentando o renunciar a la operación.
