XmNotebookGetPageInfo(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmNotebookGetPageInfo(llamada de biblioteca) XmNotebookGetPageInfo(llamada de biblioteca)

NOMBRE

XmNotebookGetPageInfo -- una función de Notebook que devuelve información de la página

SINOPSIS

#include <Xm/Notebook.h>
XmNotebookPageStatus XmNotebookGetPageInfo(
Widget notebook,
int page_number,
XmNotebookPageInfo *page_info);

DESCRIPCIÓN

XmNotebookGetPageInfo devuelve información de estado para la página de Notebook especificada.

notebook
Especifica el widget Notebook.
page_number
Especifica el número de página que se consulta.
page_info
Punta a la estructura que contiene la información de la página. La estructura tiene la siguiente forma:
typedef struct
{
        int     page_number;
        Widget  page_widget;
        Widget  status_area_widget;
        Widget  major_tab_widget;
        Widget  minor_tab_widget;
} XmNotebookPageInfo;
(void)
page_number
Especifica el page_number pasado a la función.
page_widget
Especifica un widget hijo del Notebook con un XmNchildType de XmPAGE y un XmNpageNumber igual a page_number si existe uno; de lo contrario, se establece en NULL.
status_area_widget
Especifica un widget hijo del Notebook con un XmNchildType de XmSTATUS_AREA y un XmNpageNumber igual a page_number si existe uno; de lo contrario, se establece en NULL.
major_tab_widget
Especifica un widget hijo del Notebook con un XmNchildType de XmMAJOR_TAB y el XmNpageNumber más cercano igual o menor que page_number si existe uno; de lo contrario, se establece en NULL.
minor_tab_widget
Especifica un widget hijo del Notebook con un XmNchildType de XmMINOR_TAB y el XmNpageNumber más cercano igual o menor que page_number si existe uno; de lo contrario, se establece en NULL.

Para una definición completa de Notebook y sus recursos asociados, consulte XmNotebook(3).

REGRESO

Devuelve uno de los siguientes valores de estado de página:

XmPAGE_FOUND
Se encontró la página especificada.
XmPAGE_INVALID
El número de página especificado está fuera del rango de números de página.
XmPAGE_EMPTY
La página especificada no tiene un widget de página.
XmPAGE_DUPLICATED
Hay más de un widget de página con el número de página especificado. El widget de página gestionado más recientemente se utiliza para la estructura de información de la página.

RELACIONADO

XmNotebook(3).
