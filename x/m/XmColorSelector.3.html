NOMBRE

El widget Selector de Color

SINOPSIS

#include <Xm/ColorS.h>

DESCRIPCIÓN

El widget Selector de Color permite a los usuarios elegir un color utilizando un conjunto de deslizadores RGB o seleccionando de una lista de todos los colores disponibles en la base de datos rgb. El nombre o el valor rgb, así como el color seleccionado, se muestran dinámicamente al usuario mientras este elige diferentes colores.

Todos los nombres de recursos comienzan con XmN y todos los nombres de clase de recursos comienzan con XmC.

blueSliderLabel

La cadena que aparece como etiqueta del deslizador azul

colorListTogLabel

La cadena que aparece como etiqueta del botón de selección de la lista de colores

colorMode

La lista de colores puede usarse en modo deslizador o en modo lista. Los valores aceptables son XmListMode y XmScaleMode. Este recurso permite a la aplicación determinar el modo que debe usar el selector de color cuando se crea. Después de este punto, el usuario puede cambiar libremente de modo utilizando un par de botones de radio en el selector de color. Se registra un convertidor de tipos para convertir las cadenas "ScaleMode" y "ListMode" a modos de color para su uso con la base de datos de recursos.

colorName

Este recurso controla el nombre del color que se muestra actualmente al usuario. Este valor se puede modificar para cambiar el color mostrado en el selector de color o consultar para encontrar el color que el usuario ha seleccionado. La cadena devuelta aquí es un nombre de color o un signo de almohadilla (#) seguido de un conjunto de valores rgb según se especifica en la especificación de Xlib.

fileReadError

El mensaje que se muestra cuando el Selector de Color no puede leer el archivo rgb.txt. El mensaje se muestra en la parte superior de la ventana en la que normalmente aparecería la lista de colores.

greenSliderLabel

La cadena que aparece como etiqueta del deslizador verde

marginHeight

marginWidth

Esta es la cantidad de espacio que queda entre cada uno de los hijos en el selector de color y entre los hijos exteriores y el borde del widget selector de color.

noCellError

Este recurso controla el mensaje que se muestra en el campo de color de muestra cuando el Selector de Color no puede asignar una celda de color de lectura/escritura.

redSliderLabel

La cadena que aparece como etiqueta del deslizador rojo

rgbFile

Este es el nombre del archivo que se cargará, que contiene los nombres de colores válidos. Cada uno de estos nombres se ordena y se eliminan los duplicados antes de mostrarlos al usuario.

sliderTogLabel

La cadena que aparece como etiqueta del botón de selección de deslizadores de color

Hijos

El selector de color está compuesto por muchos sub-widgets. Como con todos los widgets, la mayoría de los valores se pasan a este widget a través de la lista de argumentos en el momento de la creación o a través de `set values`, y se pasan a cada uno de los hijos de este widget, aunque las solicitudes de `get values` deben hacerse de forma individual para cada hijo. Los hijos del selector de color se enumeran a continuación. Se debe consultar la documentación de cada uno de los hijos para obtener una lista de los recursos de cada hijo.
