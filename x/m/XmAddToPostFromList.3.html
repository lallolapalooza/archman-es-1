NOMBRE

XmAddToPostFromList — una función de RowColumn que hace que un menú sea accesible desde más de un widget

SINOPSIS

#include <Xm/RowColumn.h>

void XmAddToPostFromList(
Widget menu,
Widget post_from_widget);

DESCRIPCIÓN

XmAddToPostFromList hace que un menú sea accesible desde más de un widget. Después de que un menú se crea una vez, esta función puede ser utilizada para hacer que ese menú sea accesible desde un segundo widget. El proceso puede repetirse indefinidamente. En otras palabras, donde una aplicación usaría XmCreatePopupMenu o XmCreatePulldownMenu o sus equivalentes para crear un nuevo menú idéntico a uno que ya existe, puede utilizar esta función para reutilizar ese menú anterior.

Si menu se refiere a un menú emergente (Popup), entonces el widget post_from_widget ahora puede mostrar el menú especificado. La visualización real del menú ocurre como siempre, ya sea a través de un manejador de eventos o del soporte automático de menús emergentes (ver la página de referencia de XmRowColumn(3)).

Si menu se refiere a un menú desplegable (Pulldown), su ID se coloca en el recurso XmNsubMenuId del widget post_from_widget especificado. En este caso, el widget post_from_widget debe ser un CascadeButton o un CascadeButtonGadget.

Tenga en cuenta que esta función manipula las estructuras internas en sí, no una copia de ellas.

menu
Especifica el ID del widget RowColumn que contiene el menú (Emergente o Desplegable) que se hará accesible desde el widget.
post_from_widget
Especifica el ID del widget que ahora podrá mostrar el menú especificado por menu.

Para una definición completa de RowColumn y sus recursos asociados, consulte XmRowColumn(3).

RELACIONADO

XmGetPostedFromWidget(3), XmRemoveFromPostFromList(3), y XmRowColumn(3).
