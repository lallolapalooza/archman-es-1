NOMBRE

XmFontListInitFontContext — Función de lista de fuentes que permite a las aplicaciones acceder a las entradas de una lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
Boolean XmFontListInitFontContext(
XmFontContext *context,
XmFontList fontlist);

DESCRIPCIÓN

XmFontListInitFontContext establece un contexto para permitir a las aplicaciones acceder al contenido de una lista de fuentes. Este contexto se utiliza al leer la etiqueta de la entrada de la lista de fuentes, la fuente o el conjunto de fuentes asociado con cada entrada en la lista de fuentes. Se devuelve un estado booleano para indicar si la lista de fuentes es válida o no.

Si una aplicación desasigna la lista de fuentes pasada a XmFontListInitFontContext como argumento fontlist, el contexto establecido por esta función deja de ser válido.

context
Especifica un puntero al contexto asignado
fontlist
Especifica la lista de fuentes

RETORNO

Devuelve True si el contexto fue asignado; de lo contrario, devuelve False. Si la función asignó un contexto, la aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmFontListFreeFontContext.

RELACIONADO

XmFontList(3), XmFontListFreeFontContext(3), y XmFontListNextEntry(3).
