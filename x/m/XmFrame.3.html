NOMBRE

XmFrame — Clase del widget Frame

SINOPSIS

#include <Xm/Frame.h>

DESCRIPCIÓN

Frame es un gestor muy simple utilizado para encerrar un único hijo de área de trabajo en un borde dibujado por Frame. Utiliza los recursos de la clase Manager para el dibujo del borde y realiza la gestión de geometría para que su tamaño siempre coincida con el tamaño exterior de su hijo más los márgenes y el grosor de la sombra de Frame.

Frame se utiliza con mayor frecuencia para encerrar otros gestores cuando el desarrollador de la aplicación desea que el gestor tenga la misma apariencia de borde que los widgets primitivos. Frame también se puede usar para encerrar widgets primitivos que no soportan el mismo tipo de dibujo de borde. Esto proporciona consistencia visual cuando desarrollas aplicaciones utilizando diversos conjuntos de widgets. Los recursos de restricción se utilizan para designar a un hijo como título de Frame, alinear su texto y controlar su alineación vertical en relación con la sombra superior de Frame. El título aparece solo en la parte superior de Frame.

Si el padre de Frame es un widget Shell, el recurso XmNshadowType tiene el valor predeterminado XmSHADOW_OUT, y el recurso XmNshadowThickness de Manager tiene el valor predeterminado 1.

Si el padre de Frame no es un widget Shell, el recurso XmNshadowType tiene el valor predeterminado XmSHADOW_ETCHED_IN, y el recurso XmNshadowThickness de Manager tiene el valor predeterminado 2.

Clases

Frame hereda el comportamiento y los recursos de las clases Core, Composite, Constraint y XmManager.

El puntero de clase es xmFrameWidgetClass.

El nombre de la clase es XmFrame.

Nuevos Recursos

La siguiente tabla define un conjunto de recursos de widget utilizados por el programador para especificar datos. El programador también puede establecer los valores de los recursos para las clases heredadas para configurar los atributos de este widget. Para referirse a un recurso por nombre o por clase en un archivo .Xdefaults, elimine el prefijo XmN o XmC y utilice las letras restantes. Para especificar uno de los valores definidos para un recurso en un archivo .Xdefaults, elimine el prefijo Xm y utilice las letras restantes (en minúsculas o mayúsculas, pero incluya los guiones bajos entre palabras). Los códigos en la columna de acceso indican si el recurso dado se puede establecer en el momento de la creación (C), se puede establecer usando XtSetValues (S), se puede recuperar usando XtGetValues (G) o no es aplicable (N/A).

XmNmarginWidth
Especifica el espacio de relleno en los lados izquierdo y derecho entre el hijo de Frame y el dibujo de la sombra de Frame.
XmNmarginHeight
Especifica el espacio de relleno en los lados superior e inferior entre el hijo de Frame y el dibujo de la sombra de Frame. Cuando hay un título, el margen superior es igual al valor especificado por este recurso más la distancia (si la hay) que el título se extiende por debajo de la sombra superior.
XmNshadowType
Describe el estilo de dibujo de Frame. Este recurso puede tener los siguientes valores:
XmSHADOW_IN
Dibuja Frame de manera que parezca inset. Esto significa que los visuales de la sombra inferior y los visuales de la sombra superior se invierten.
XmSHADOW_OUT
Dibuja Frame de manera que parezca outset. Este es el valor predeterminado si el padre de Frame es un widget Shell.
XmSHADOW_ETCHED_IN
Dibuja Frame utilizando una línea doble que da el efecto de una línea grabada en la ventana. El grosor de la línea doble es igual al valor de XmNshadowThickness. Este es el valor predeterminado cuando el padre de Frame no es un widget Shell.
XmSHADOW_ETCHED_OUT
Dibuja Frame utilizando una línea doble que da el efecto de una línea que sale de la ventana. El grosor de la línea doble es igual al valor de XmNshadowThickness.

XmNchildHorizontalSpacing
Especifica la distancia mínima entre cualquier borde del texto del título y el borde interior de la sombra del Marco. El recorte del texto del título se produce para mantener este espaciado. El valor predeterminado es el ancho del margen del Marco.
XmNchildVerticalAlignment
Especifica la alineación vertical del texto del título, o del área del título en relación con la sombra superior del Marco.
XmALIGNMENT_BASELINE_BOTTOM
Hace que la línea base del título se alinee verticalmente con la sombra superior del Marco. En el caso de un título de varias líneas, la línea base de la última línea de texto se alinea verticalmente con la sombra superior del Marco.
XmALIGNMENT_BASELINE_TOP
Hace que la línea base de la primera línea del título se alinee verticalmente con la sombra superior del Marco.
XmALIGNMENT_CHILD_TOP
Hace que el borde superior del área del título se alinee verticalmente con la sombra superior del Marco.
XmALIGNMENT_CENTER
Hace que el centro del área del título se alinee verticalmente con la sombra superior del Marco.
XmALIGNMENT_CHILD_BOTTOM
Hace que el borde inferior del área del título se alinee verticalmente con la sombra superior del Marco.
XmNframeChildType
Especifica si un hijo es un título o un área de trabajo. Frame admite un único título y/o un área de trabajo como hijo. Los valores posibles son
•
XmFRAME_TITLE_CHILD
•
XmFRAME_WORKAREA_CHILD
•
XmFRAME_GENERIC_CHILD
El gestor de geometría de Frame ignora cualquier hijo de tipo XmFRAME_GENERIC_CHILD. Este recurso reemplaza XmNchildType.

NAME

XmFrame - Frame widget class

SYNOPSIS

#include <Xm/Frame.h>

A Frame widget has the geometry management behavior of XmManager and the traversal behavior of XmManager. Frame widgets do not have any specific actions, translations, or accelerators.

The Frame widget is a container widget that can contain a single child widget. It supports a shadow border around the child widget and an optional title bar.

The Frame widget supports the Core, Composite, Constraint, XmManager, and XmFrame resource types.

Default Frame resource values are inherited from the parent XmManager widget.

DESCRIPTION

The Frame widget is a container widget that provides a visual border around its child widget. It can also display a title string above or below the child widget. The Frame widget's primary purpose is to provide a visual grouping for a single widget, such as a ScrolledWindow or a DialogShell.

The Frame widget manages its child using the geometry management rules of XmManager. It provides the following resources:
