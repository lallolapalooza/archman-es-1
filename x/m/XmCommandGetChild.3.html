NOMBRE

XmCommandGetChild — Una función de Command que se utiliza para acceder a un componente

SINOPSIS

#include <Xm/Command.h>
Widget XmCommandGetChild(
Widget widget,
unsigned char child);

DESCRIPCIÓN

XmCommandGetChild se utiliza para acceder a un componente dentro de un Command. Los parámetros dados a la función son el widget Command y un valor que indica qué componente acceder.

widget
Especifica el ID del widget Command.
child
Especifica un componente dentro del Command. Los siguientes valores son legales para este parámetro:
•
XmDIALOG_COMMAND_TEXT
•
XmDIALOG_PROMPT_LABEL
•
XmDIALOG_HISTORY_LIST
•
XmDIALOG_WORK_AREA

Para una definición completa de Command y sus recursos asociados, consulte XmCommand(3).

RETORNO

Devuelve el ID del widget del componente Command especificado. Una aplicación no debe asumir que el widget devuelto será de ninguna clase en particular.

RELACIONADO

XmCommand(3).
