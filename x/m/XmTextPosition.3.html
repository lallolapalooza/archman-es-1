NOMBRE

XmTextPosition — Tipo de dato para una posición de carácter dentro de una cadena de texto

SINOPSIS

#include <Xm/Xm.h>

DESCRIPCIÓN

XmTextPosition es un tipo de dato entero que almacena la posición de un carácter dentro de una cadena de texto para Text y TextField.

Un valor de XmTextPosition apunta conceptualmente al hueco entre dos caracteres. Por ejemplo, considera una cadena de texto que consta de N caracteres. Un valor de 0 se refiere a la posición inmediatamente anterior al primer carácter. Un valor de 1 se refiere a la posición entre el primer y el segundo carácter. Un valor de N se refiere a la posición inmediatamente posterior al último carácter. Por lo tanto, una cadena de texto de N caracteres contiene en realidad N + 1 posiciones.
