NOMBRE

XmFontListRemoveEntry — Una función de lista de fuentes que elimina una entrada de lista de fuentes de una lista de fuentes

SINOPSIS

#include <Xm/Xm.h>
XmFontList XmFontListRemoveEntry(
XmFontList oldlist,
XmFontListEntry entry);

DESCRIPCIÓN

XmFontListRemoveEntry crea una nueva lista de fuentes que contiene el contenido de oldlist menos las entradas especificadas en entry. La rutina elimina cualquier entrada de oldlist que coincida con los componentes (etiqueta, tipo fuente/conjunto de fuentes) de la entrada especificada. La función libera la lista de fuentes original después de extraer la información requerida. El llamador usa XmFontListEntryFree para recuperar la memoria asignada para la entrada especificada. Esta rutina no libera el XFontSet o XFontStruct asociado con la entrada de lista de fuentes que se elimina.

oldlist
Especifica la lista de fuentes
entry
Especifica la entrada de lista de fuentes a eliminar

RETORNO

Si oldlist es NULL, la función devuelve NULL. Si entry es NULL o no se elimina ninguna entrada, la función devuelve oldlist. De lo contrario, devuelve una nueva lista de fuentes. Si la función devuelve una nueva lista de fuentes, la función asigna espacio para contener la nueva lista de fuentes. La aplicación es responsable de gestionar el espacio asignado. La aplicación puede recuperar el espacio asignado llamando a XmFontListFree.

RELACIONADO

XmFontList(3), XmFontListAppendEntry(3), XmFontListEntryCreate(3), XmFontListEntryFree(3), XmFontListEntryLoad(3), y XmFontListFree(3).
