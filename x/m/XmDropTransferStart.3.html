NOMBRE

XmDropTransferStart — Una función de Arrastrar y Soltar que inicia una transferencia de soltar

SINOPSIS

#include <Xm/DragDrop.h>
Widget XmDropTransferStart(
Widget widget,
ArgList arglist,
Cardinal argcount);

DESCRIPCIÓN

XmDropTransferStart inicia una transferencia de soltar y utiliza la lista de argumentos especificada para inicializar un objeto XmDropTransfer. El objeto DropTransfer puede ser manipulado con XtSetValues y XtGetValues hasta que se realiza la última llamada al procedimiento XmNtransferProc. Después de ese punto, el resultado de usar el puntero del widget no está definido. El toolkit libera el objeto DropTransfer cuando la transferencia se completa.

widget
Especifica el ID del widget DragContext asociado con la transacción.
arglist
Especifica la lista de argumentos.
argcount
Especifica el número de pares atributo/valor en la lista de argumentos (arglist).

Para una definición completa de DropTransfer y sus recursos asociados, consulte XmDropTransfer(3).

RETORNO

Devuelve el ID del widget DropTransfer.

RELACIONADO

XmDragContext(3), XmDropTransfer(3), y XmDropTransferAdd(3).
