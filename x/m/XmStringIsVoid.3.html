NOMBRE

XmStringIsVoid — Una función de cadena compuesta que proporciona información sobre la existencia de componentes de texto de longitud distinta de cero, componentes de tabulación o componentes separadores

SINOPSIS

#include <Xm/Xm.h>
Boolean XmStringIsVoid(
XmString s1);

DESCRIPCIÓN

XmStringIsVoid devuelve un valor booleano que indica si la cadena s1 está vacía o no.

s1
Especifica la cadena compuesta

RETORNO

Devuelve True si existen componentes de texto de longitud distinta de cero, componentes de tabulación o componentes separadores en s1. Es decir, la función devuelve True si la cadena no tiene texto, tabulaciones o separadores. Si s1 contiene la cadena NULL, la función devuelve True.

RELACIONADO

XmStringCreate(3).
