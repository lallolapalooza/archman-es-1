XML::LibXML::Reader(3) Documentación de Contribución del Usuario Perl XML::LibXML::Reader(3)

NOMBRE

XML::LibXML::Reader - Interfaz de XML::LibXML::Reader a al analizador de extracción de libxml2

SINOPSIS

use XML::LibXML::Reader;
my $reader = XML::LibXML::Reader->new(location => "file.xml")
       or die "no se puede leer file.xml\n";
while ($reader->read) {
  processNode($reader);
}
sub processNode {
    my $reader = shift;
    printf "%d %d %s %d\n", ($reader->depth,
                             $reader->nodeType,
                             $reader->name,
                             $reader->isEmptyElement);
}

o

my $reader = XML::LibXML::Reader->new(location => "file.xml")
       or die "no se puede leer file.xml\n";
  $reader->preservePattern('//table/tr');
  $reader->finish;
  print $reader->document->toString(1);

DESCRIPCIÓN

Esta es una interfaz perl para la implementación del analizador de extracción de libxml2, xmlTextReader http://xmlsoft.org/html/libxml-xmlreader.html. Esta característica requiere al menos libxml2-2.6.21. Los analizadores de extracción (como StAX en Java o XmlReader en C#) utilizan un enfoque de iterador para analizar documentos XML. Son más fáciles de programar que los analizadores basados en eventos (SAX) y mucho más ligeros que los analizadores basados en árboles (DOM), que cargan el árbol completo en memoria.

El Lector actúa como un cursor que avanza por el flujo del documento y se detiene en cada nodo en el camino. En cada punto, los métodos similares a DOM del objeto Lector permiten examinar el nodo actual (nombre, espacio de nombres, atributos, etc.)

El código del usuario mantiene el control del progreso y simplemente llama a la función read() repetidamente para avanzar al siguiente nodo en el orden del documento. Otras funciones proporcionan medios para omitir subárboles completos o nodos hasta un elemento específico, etc.

En cada momento, solo una porción muy limitada del documento se mantiene en memoria, lo que hace que la API sea más eficiente en cuanto a memoria que el uso de DOM. Sin embargo, también es posible mezclar Lector con DOM. En cualquier momento, el usuario puede copiar el nodo actual (opcionalmente expandido en un subárbol completo) del documento procesado a otro árbol DOM, o instruir al Lector para que recopile subdocumentos en forma de un árbol DOM compuesto por nodos seleccionados.

La API del Lector también admite espacios de nombres, xml:base, manejo de entidades y validación DTD. Es probable que la validación de esquemas RelaxNG se añada en alguna revisión posterior de la interfaz Perl.

Los nombres de los métodos en comparación con libxml2 y C# XmlTextReader se han modificado ligeramente para que coincidan con las convenciones de XML::LibXML. Algunas funciones se han cambiado o añadido con respecto a la interfaz C.

CONSTRUCTOR

Dependiendo de la fuente XML, el objeto Lector se puede crear con uno de los siguientes:

my $reader = XML::LibXML::Reader->new( location => "file.xml", ... );
  my $reader = XML::LibXML::Reader->new( string => $xml_string, ... );
  my $reader = XML::LibXML::Reader->new( IO => $file_handle, ... );
  my $reader = XML::LibXML::Reader->new( FD => fileno(STDIN), ... );
  my $reader = XML::LibXML::Reader->new( DOM => $dom, ... );

donde ... son opciones de lector (opcionales) descritas a continuación en "Opciones del Lector" o varias opciones de analizador descritas en XML::LibXML::Parser. El constructor reconoce las siguientes fuentes XML:

Especificación de fuente

location
Lee XML desde un archivo local o una URL (no HTTPS).
string
Lee XML desde una cadena.
IO
Lee XML desde un manejador de archivos IO de Perl.
FD
Lee XML desde un descriptor de archivo (omite la capa de E/S de Perl, solo aplicable a manejadores de archivos para archivos regulares o tuberías). Posiblemente más rápido que IO.
DOM
Usa la API del lector para recorrer un Documento XML::LibXML pre-analizado.

Opciones del Lector

encoding => $encoding
anula la codificación del documento.
RelaxNG => $rng_schema
se puede usar para pasar un objeto XML::LibXML::RelaxNG o un nombre de archivo o una URL (no HTTPS) de un esquema RelaxNG al constructor. El esquema se utiliza luego para validar el documento a medida que se procesa.
Schema => $xsd_schema
se puede usar para pasar un objeto XML::LibXML::Schema o un nombre de archivo o una URL (no HTTPS) de un esquema W3C XSD al constructor. El esquema se utiliza luego para validar el documento a medida que se procesa.
...
el lector también admite varias opciones de analizador descritas en XML::LibXML::Parser (específicamente aquellas etiquetadas por /reader/).

MÉTODOS QUE CONTROLAN EL PROGRESO DEL ANÁLISIS

read ()
Mueve la posición al siguiente nodo en el flujo, exponiendo sus propiedades.

Devuelve 1 si el nodo se leyó correctamente, 0 si no hay más nodos que leer, o -1 en caso de error.

readAttributeValue ()
Analiza el valor de un atributo en uno o más nodos de Texto y Referencia de Entidad.

Devuelve 1 en caso de éxito, 0 si el lector no estaba posicionado en un nodo de atributo o si se han leído todos los valores de atributo, o -1 en caso de error.

readState ()
Obtiene el estado de lectura del lector. Devuelve el valor del estado, o -1 en caso de error. El módulo exporta constantes para los estados del Lector, ver ESTADOS a continuación.
depth ()
La profundidad del nodo en el árbol, comienza en 0 para el nodo raíz.
next ()
Salta al nodo siguiente en el orden del documento evitando el subárbol si lo hay. Devuelve 1 si el nodo se leyó correctamente, 0 si no hay más nodos que leer, o -1 en caso de error.
nextElement (localname?,nsURI?)
Salta nodos siguientes en el orden del documento hasta que se alcanza un elemento específico. El nombre del elemento debe ser igual al localname dado si se define, y su espacio de nombres debe ser igual al nsURI dado si se define. Cualquiera de los argumentos puede ser indefinido (o omitido, en el caso de estos últimos o ambos).

Devuelve 1 si se encontró el elemento, 0 si no hay más nodos que leer, o -1 en caso de error.

nextPatternMatch (compiled_pattern)
Salta nodos siguientes en el orden del documento hasta que se alcanza un elemento que coincide con un patrón compilado dado. Ver XML::LibXML::Pattern para obtener información sobre patrones compilados. Ver también el método "matchesPattern".

Devuelve 1 si se encontró el elemento, 0 si no hay más nodos que leer, o -1 en caso de error.

skipSiblings ()
Salta todos los nodos en el mismo nivel o en un nivel inferior hasta que se alcanza el primer nodo en un nivel superior. En particular, si el nodo actual se encuentra dentro de un elemento, el lector se detiene en la etiqueta de cierre del elemento padre, de lo contrario, se detiene en un nodo inmediatamente posterior al nodo padre.

Devuelve 1 si tiene éxito, 0 si se alcanza el final del documento, o -1 en caso de error.

nextSibling ()
Salta al nodo siguiente en el orden del documento evitando el subárbol si lo hay.

Devuelve 1 si el nodo se leyó correctamente, 0 si no hay más nodos que leer, o -1 en caso de error.

nextSiblingElement (name?,nsURI?)
Similar a nextElement pero solo procesa elementos hermanos del nodo actual.
(avanzando usando "nextSibling ()" en lugar de "read ()", internamente).

Devuelve 1 si se encontró el elemento, 0 si no hay más nodos hermanos, o -1 en caso de error.

finish ()
Omite todos los nodos restantes en el documento, llegando al final del documento.

Devuelve 1 si tiene éxito, 0 en caso de error.

close ()
Este método libera cualquier recurso asignado por la instancia actual y cierra cualquier entrada subyacente. Devuelve 0 en caso de fallo y 1 en caso de éxito. Este método es llamado automáticamente por el destructor cuando el lector es olvidado, por lo tanto, no tienes que llamarlo directamente.

MÉTODOS DE EXTRACCIÓN DE INFORMACIÓN

name ()
Devuelve el nombre calificado del nodo actual, igual a (Prefijo:)NombreLocal.
nodeType ()
Devuelve el tipo del nodo actual. Ver TIPOS DE NODO abajo.
localName ()
Devuelve el nombre local del nodo.
prefix ()
Devuelve el prefijo del espacio de nombres asociado con el nodo.
namespaceURI ()
Devuelve el URI que define el espacio de nombres asociado con el nodo.
isEmptyElement ()
Comprueba si el nodo actual está vacío. Esto es un poco extraño, ya que <a/> se considerará vacío mientras que <a></a> no lo será.
hasValue ()
Devuelve verdadero si el nodo puede tener un valor de texto.
value ()
Proporciona el valor de texto del nodo si está presente o undef si no está disponible.
readInnerXml ()
Lee el contenido del nodo actual, incluyendo nodos hijos y marcado. Devuelve una cadena que contiene el XML del contenido del nodo, o undef si el nodo actual no es un elemento ni un atributo, o no tiene nodos hijos.
readOuterXml ()
Lee el contenido del nodo actual, incluyendo nodos hijos y marcado.

Devuelve una cadena que contiene el XML del nodo, incluyendo su contenido, o undef si el nodo actual no es ni un elemento ni un atributo.

nodePath()
Devuelve una ruta de ubicación canónica al elemento actual desde el nodo raíz hasta el nodo actual. Los elementos con espacios de nombres se coinciden con '*', ya que no hay forma de declarar prefijos dentro de los patrones XPath. A diferencia de XML::LibXML::Node::nodePath(), esta función no proporciona recuentos de hermanos (es decir, en lugar de, por ejemplo, '/a/b[1]' y '/a/b[2]', obtienes '/a/b' para ambas coincidencias).
matchesPattern(compiled_pattern)
Devuelve un valor verdadero si el nodo actual coincide con un patrón compilado. Ver XML::LibXML::Pattern para obtener información sobre patrones compilados. Ver también el método "nextPatternMatch".

MÉTODOS PARA EXTRAER NÓDULOS DOM

document ()
Proporciona acceso al árbol de documentos construido por el lector. Esta función se puede utilizar para recopilar los nodos conservados (ver preserveNode() y preservePattern).

¡PRECAUCIÓN: Nunca uses esta función para modificar el árbol a menos que se haya completado la lectura de todo el documento!

copyCurrentNode (deep)
Esta función es similar a la función DOM copyNode(). Devuelve una copia del nodo procesado actualmente como un objeto DOM correspondiente. Usa deep = 1 para obtener el subárbol completo.
preserveNode ()
Esto indica al Lector XML que conserve el nodo actual en el árbol del documento. Un árbol de documentos que consiste en los nodos conservados y su contenido se puede obtener usando el método document() una vez que se ha completado el análisis.

Devuelve el nodo o NULL en caso de error.

preservePattern (pattern,\%ns_map)
Esto indica al Lector XML que conserve todos los nodos que coinciden con el patrón (que es un subconjunto de XPath de streaming). Un árbol de documentos que consiste en los nodos conservados y su contenido se puede obtener usando el método document() una vez que se ha completado el análisis.

Se puede utilizar un segundo argumento opcional para proporcionar una referencia HASH que mapea prefijos utilizados por XPath a URIs de espacios de nombres.

El subconjunto de XPath disponible con esta función se describe en

http://www.w3.org/TR/xmlschema-1/#Selector

y coincide con la producción

Path ::= ('.//')? ( Step '/' )* ( Step | '@' NameTest )

Devuelve un número positivo en caso de éxito y -1 en caso de error.

MÉTODOS PARA PROCESAR ATRIBUTOS

attributeCount ()
Proporciona el número de atributos del nodo actual.
hasAttributes ()
Si el nodo tiene atributos.
getAttribute (name)
Proporciona el valor del atributo con el nombre calificado especificado.

Devuelve una cadena que contiene el valor del atributo especificado, o undef en caso de error.

getAttributeNs (localName, namespaceURI)
Proporciona el valor del atributo especificado.

Devuelve una cadena que contiene el valor del atributo especificado, o undef en caso de error.

getAttributeNo (no)
Proporciona el valor del atributo con el índice especificado relativo al elemento contenedor.

Devuelve una cadena que contiene el valor del atributo especificado, o undef en caso de error.

isDefault ()
Devuelve verdadero si el nodo de atributo actual se generó a partir del valor predeterminado definido en el DTD.
moveToAttribute (name)
Mueve la posición al atributo con el nombre local y URI de espacio de nombres especificados.

Devuelve 1 en caso de éxito, -1 en caso de error, 0 si no se encontró

moveToAttributeNo (no)
Mueve la posición al atributo con el índice especificado relativo al elemento contenedor.

Devuelve 1 en caso de éxito, -1 en caso de error, 0 si no se encontró

moveToAttributeNs (localName,namespaceURI)
Mueve la posición al atributo con el nombre local y URI de espacio de nombres especificados.

Devuelve 1 en caso de éxito, -1 en caso de error, 0 si no se encontró

moveToFirstAttribute ()
Mueve la posición al primer atributo asociado con el nodo actual.

Devuelve 1 en caso de éxito, -1 en caso de error, 0 si no se encontró

moveToNextAttribute ()
Mueve la posición al siguiente atributo asociado con el nodo actual.

Devuelve 1 en caso de éxito, -1 en caso de error, 0 si no se encontró

moveToElement ()
Mueve la posición al nodo que contiene el nodo de atributo actual.

Devuelve 1 en caso de éxito, -1 en caso de error, 0 si no se movió

isNamespaceDecl ()
Determina si el nodo actual es una declaración de espacio de nombres en lugar de un atributo regular.

Devuelve 1 si el nodo actual es una declaración de espacio de nombres, 0 si es un atributo regular u otro tipo de nodo, o -1 en caso de error.

OTROS MÉTODOS

lookupNamespace (prefix)
Resuelve un prefijo de espacio de nombres en el ámbito del elemento actual.

Devuelve una cadena que contiene el URI del espacio de nombres al que se mapea el prefijo o undef en caso de error.

encoding ()
Devuelve una cadena que contiene la codificación del documento o undef en caso de error.
standalone ()
Determina el estado independiente del documento que se está leyendo. Devuelve 1 si se declaró que el documento es independiente, 0 si se declaró que no es independiente, o -1 si el documento no especificó su estado independiente o en caso de error.
xmlVersion ()
Determina la versión XML del documento que se está leyendo. Devuelve una cadena que contiene la versión XML del documento o undef en caso de error.
baseURI ()
Devuelve el URI base de un nodo dado.
isValid ()
Recupera el estado de validez del analizador.

Devuelve 1 si es válido, 0 si no, y -1 en caso de error.

XML::LibXML::Reader(3pm)

NAME

XML::LibXML::Reader - An interface to the libxml2's XML reader API

SYNOPSIS

use XML::LibXML::Reader;

my $reader = XML::LibXML::Reader->new( string => $xml_string );
# or
# my $reader = XML::LibXML::Reader->new( file => $file_path );
# or
# my $reader = XML::LibXML::Reader->new( IO => $io_object );

while ($reader->read) {
    if ($reader->nodeType == XML_READER_TYPE_ELEMENT) {
        my $name = $reader->name;
        my $depth = $reader->depth;
        # ...
    }
}

DESCRIPTION

This module implements the libxml2 xmlTextReader API. It is a fast, forward-only, streaming interface for reading XML documents. It is designed to be simple to use and to provide efficient access to XML data without loading the entire document into memory.

CONSTRUCTOR

new ( string => $xml_string )
Constructs a new XML::LibXML::Reader object from an XML string.
new ( file => $file_path )
Constructs a new XML::LibXML::Reader object from a file.
new ( IO => $io_object )
Constructs a new XML::LibXML::Reader object from an IO object (e.g. from IO::File, IO::Stringy or IO::Memory).
new ( opts )
More complex constructor accepting a hash of options.

METHODS CONTROLLING PARSING PROGRESS

read()
Reads the next node from the XML document. Returns true on success, false on end of document, and undef on error.
readState()
Returns the current state of the reader. See the STATES section below.
next( [name] )
Moves the reader to the next sibling node with the given name, or to the next node if no name is supplied. Returns true on success, false on end of document, and undef on error.

METHODS EXTRACTING INFORMATION

nodeType()
Returns the type of the current node. See the NODE TYPES section below.
name()
Returns the qualified name of the current node.
localName()
Returns the local name of the current node.
prefix()
Returns the namespace prefix of the current node.
value()
Returns the data value of the current node.
depth()
Returns the depth of the current node in the document tree.
hasValue()
Returns true if the current node has a data value.
isEmptyElement()
Returns true if the current node is an empty element.
namespaceUri()
Returns the namespace URI of the current node.
baseUri()
Returns the base URI of the current node.

METHODS EXTRACTING DOM NODES

document()
Returns the XML::LibXML::Document object. Note that this will only work if the reader was created with a file or IO object, and not a string. This operation loads the entire document into memory.
node()
Returns the current node as an XML::LibXML::Node object. This operation loads the entire document into memory.
preserveNode()
If this method is called, the reader will not destroy the DOM nodes it creates. This is useful if you want to extract a subtree from a large document without loading the entire document into memory.

METHODS PROCESSING ATTRIBUTES

moveToAttribute( name )
Moves the reader to the attribute with the specified name. Returns true on success, false otherwise.
moveToAttributeNo( index )
Moves the reader to the attribute with the specified index. Returns true on success, false otherwise.
moveToFirstAttribute()
Moves the reader to the first attribute of the current element. Returns true on success, false otherwise.
moveToNextAttribute()
Moves the reader to the next attribute of the current element. Returns true on success, false otherwise.
hasAttributes()
Returns true if the current node has attributes.
attributeCount()
Returns the number of attributes on the current node.

OTHER METHODS

encoding()
Returns the character encoding of the document.
standalone()
Returns true if the document is standalone, false otherwise.
version()
Returns the XML version of the document.
filename()
Returns the filename of the document, if it was created from a file.
set_base_uri( uri )
Sets the base URI for the current node.
get_reader()
Returns the underlying libxml text reader object.
parseSubtree()
Parses a subtree starting from the current node. Returns an XML::LibXML::Node object representing the subtree. Note that this will consume the reader until the end of the subtree.
lineNumber()
Provide the line number of the current parsing point.
columnNumber()
Provide the column number of the current parsing point.
byteConsumed()
This function provides the current index of the parser relative to the start of the current entity. This function is computed in bytes from the beginning starting at zero and finishing at the size in bytes of the file if parsing a file. The function is of constant cost if the input is UTF-8 but can be costly if run on non-UTF-8 input.
setParserProp(prop => value, ...)
Change the parser processing behaviour by changing some of its internal properties. The following properties are available with this function: ``load_ext_dtd'', ``complete_attributes'', ``validation'', ``expand_entities''.

Since some of the properties can only be changed before any read has been done, it is best to set the parsing properties at the constructor.

Returns 0 if the call was successful, or -1 in case of error

getParserProp(prop)
Get value of an parser internal property. The following property names can be used: ``load_ext_dtd'', ``complete_attributes'', ``validation'', ``expand_entities''.

Returns the value, usually 0 or 1, or -1 in case of error.

DESTRUCTION

XML::LibXML takes care of the reader object destruction when the last reference to the reader object goes out of scope. The document tree is preserved, though, if either of $reader->document or $reader->preserveNode was used and references to the document tree exist.

NODE TYPES

The reader interface provides the following constants for node types (the constant symbols are exported by default or if tag ":types" is used).

XML_READER_TYPE_ELEMENT                 => 1
XML_READER_TYPE_ATTRIBUTE               => 2
XML_READER_TYPE_TEXT                    => 3
XML_READER_TYPE_CDATA                   => 4
XML_READER_TYPE_ENTITY_REFERENCE        => 5
XML_READER_TYPE_ENTITY                  => 6
XML_READER_TYPE_PROCESSING_INSTRUCTION  => 7
XML_READER_TYPE_COMMENT                 => 8
XML_READER_TYPE_DOCUMENT                => 9
XML_READER_TYPE_DOCUMENT_TYPE           => 10
XML_READER_TYPE_DOCUMENT_FRAGMENT       => 11
XML_READER_TYPE_NOTATION                => 12
XML_READER_TYPE_WHITESPACE              => 13
XML_READER_TYPE_SIGNIFICANT_WHITESPACE  => 14
XML_READER_TYPE_END_ELEMENT             => 15

XML_READER_DONE      =>  5
XML_READER_ERROR     =>  6
