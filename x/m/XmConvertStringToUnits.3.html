NOMBRE

XmConvertStringToUnits — Una función que convierte una especificación de cadena a un valor de unidad

SINOPSIS

#include <Xm/Xm.h>
int XmConvertStringToUnits(
Screen *screen,
String spec,
int orientation,
int to_type,
XtEnum *parse_error);

DESCRIPCIÓN

XmConvertStringToUnits convierte un valor de especificación de cadena y devuelve el valor convertido como valor de retorno de la función. Esta función utiliza la resolución de la pantalla especificada para calcular el número de unidades para la especificación de cadena.

screen
Especifica la pantalla cuya resolución se utilizará para el cálculo.
spec
Especifica la cadena, en formato <valor flotante><unidad>, a convertir.
orientation
Especifica si el convertidor utiliza la resolución de pantalla horizontal o vertical al realizar la conversión. El parámetro orientation puede tener los valores XmHORIZONTAL o XmVERTICAL.
to_type
Convierte el valor al tipo de unidad especificado. Consulte el recurso XmNunitType de la página de referencia de XmGadget, XmManager o XmPrimitive. Este parámetro puede tener uno de los siguientes valores:
XmPIXELS
El valor devuelto será el número de píxeles.
XmMILLIMETERS
El valor devuelto será el número de milímetros.
Xm100TH_MILLIMETERS
El valor devuelto será el número de 1/100 de milímetro.
XmCENTIMETERS
El valor devuelto será el número de centímetros.
XmINCHES
El valor devuelto será el número de pulgadas.
Xm1000TH_INCHES
El valor devuelto será el número de 1/1000 de pulgada.
XmPOINTS
El valor devuelto será el número de puntos. Un punto es una unidad de procesamiento de texto definida como 1/72 de pulgada.
Xm100TH_POINTS
El valor devuelto será el número de 1/100 de puntos.
XmFONT_UNITS
Todos los valores proporcionados al widget se tratan como unidades de fuente. Una unidad de fuente tiene componentes horizontal y vertical. Estos son los valores de los recursos XmScreen XmNhorizontalFontUnit y XmNverticalFontUnit.
Xm100TH_FONT_UNITS
Todos los valores proporcionados al widget se tratan como 1/100 de unidad de fuente. Una unidad de fuente tiene componentes horizontal y vertical. Estos son los valores de los recursos XmScreen XmNhorizontalFontUnit y XmNverticalFontUnit.
parse_error
Especifica si ocurrió un error de análisis. Si este valor es True, indica que ocurrió un error; si es False, indica que no hubo error.

RETORNO

Devuelve el valor convertido. Si se proporciona una pantalla NULL, una orientation incorrecta o un unit_type incorrecto como datos de parámetro, o si ocurrió un error de análisis, se devuelve 0 (cero).

RELACIONADO

XmConvertUnits(3), XmSetFontUnits(3), y XmScreen(3).
