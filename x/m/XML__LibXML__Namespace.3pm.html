XML::LibXML::Namespace(3) Documentación de Contribución de Usuarios de Perl XML::LibXML::Namespace(3)

NOMBRE

XML::LibXML::Namespace - Implementación de Espacios de Nombres de XML::LibXML

SINOPSIS

use XML::LibXML;
# Solo se listan aquí los métodos específicos de los nodos de Espacio de Nombres,
# consulte la página del manual de XML::LibXML::Node para otros métodos
my $ns = XML::LibXML::Namespace->new($nsURI);
print $ns->nodeName();
print $ns->name();
$localname = $ns->getLocalName();
print $ns->getData();
print $ns->getValue();
print $ns->value();
$known_uri = $ns->getNamespaceURI();
$known_prefix = $ns->getPrefix();
$key = $ns->unique_key();

DESCRIPCIÓN

Los nodos de espacio de nombres son devueltos por $element->findnodes('namespace::foo') o por $node->getNamespaces().

La API de nodos de espacio de nombres no forma parte de ninguna API DOM actual, y por lo tanto es bastante mínima. Cabe señalar que los nodos de espacio de nombres *no* son una subclase de XML::LibXML::Node, sin embargo, los nodos de Espacio de Nombres se comportan de manera similar a los nodos de atributo, y los métodos con nombres similares devolverán lo que esperaría si tratara el nodo de espacio de nombres como un atributo. Tenga en cuenta que para corregir varias inconsistencias entre la API y la documentación, el comportamiento de algunas funciones se ha modificado en 1.64.

MÉTODOS

new
my $ns = XML::LibXML::Namespace->new($nsURI);

Crea un nuevo nodo de Espacio de Nombres. Tenga en cuenta que este no es un 'nodo' como un nodo de atributo o elemento. Por lo tanto, no puede llamar a todas las funciones de XML::LibXML::Node. Todas las funciones disponibles para este nodo se enumeran a continuación.

Opcionalmente, puede pasar el prefijo al constructor del espacio de nombres. Si se omite este segundo parámetro, creará un espacio de nombres predeterminado. Tenga en cuenta que el espacio de nombres recién creado no está vinculado a ningún documento o nodo, por lo tanto, no debe esperar que esté disponible en un documento existente.

declaredURI
Devuelve la URI para este espacio de nombres.
declaredPrefix
Devuelve el prefijo para este espacio de nombres.
nodeName
print $ns->nodeName();

Devuelve "xmlns:prefijo", donde prefijo es el prefijo para este espacio de nombres.

name
print $ns->name();

Alias de nodeName()

getLocalName
$localname = $ns->getLocalName();

Devuelve el nombre local de este nodo como si fuera un atributo, es decir, el prefijo asociado con el espacio de nombres.

getData
print $ns->getData();

Devuelve la URI del espacio de nombres, es decir, el valor de este nodo como si fuera un atributo.

getValue
print $ns->getValue();

Alias de getData()

value
print $ns->value();

Alias de getData()

getNamespaceURI
$known_uri = $ns->getNamespaceURI();

Devuelve la cadena "http://www.w3.org/2000/xmlns/"

getPrefix
$known_prefix = $ns->getPrefix();

Devuelve la cadena "xmlns"

unique_key
$key = $ns->unique_key();

Este método devuelve una clave garantizada para ser única para este espacio de nombres, y para ser siempre el mismo valor para este espacio de nombres. Dos objetos de espacio de nombres devuelven la misma clave si y solo si tienen el mismo prefijo y la misma URI. El valor de clave devuelto es útil como clave en hashes.
