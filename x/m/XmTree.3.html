NOMBRE

XmTree - La clase del widget Tree

SINOPSIS

#include <Xm/XTree.h>

DESCRIPCIÓN

El widget Tree es un contenedor que muestra la relación de sus hijos en un formato gráfico similar a un árbol. Cada hijo del widget Tree es un nodo en el árbol. Las relaciones padre-hijo entre estos nodos son completamente distintas de la jerarquía de widgets. La jerarquía de nodos se crea especificando el "padre" del árbol de cada nodo como un recurso de restricción. Si el padre de un nodo es NULL, se asume que es una raíz del árbol. Aunque cada widget solo puede tener un padre, el widget Tree admite la adición de más de una raíz de nodo a un solo árbol.

Nota: el widget Tree asume que será totalmente responsable de mapear y desmapear a sus hijos. Por lo tanto, ningún hijo de este widget debe modificar nunca su recurso mappedWhenManaged. Si un hijo modifica este recurso, el comportamiento no está definido.

Interacción con el usuario

Cada nodo en el árbol puede estar en cuatro estados: abierto, cerrado, siempre abierto y oculto. El estado de un nodo cambia cómo se le presenta al usuario y qué acciones están disponibles para el usuario.

Abierto: Este nodo tendrá una carpeta abierta mostrada a su izquierda que el usuario puede seleccionar para cerrar este nodo. Cuando un nodo está abierto, todos sus hijos serán visibles para el usuario.

Cerrado: Este nodo tendrá una carpeta cerrada mostrada a su izquierda que el usuario puede seleccionar para abrir este nodo. Cuando un nodo está cerrado, ninguno de sus hijos será visible para el usuario.

Siempre abierto: Este nodo no tendrá un botón de carpeta asociado. Todos sus hijos serán visibles para el usuario.

Oculto: Este nodo no se mostrará al usuario y todos sus hijos aparecerán y actuarán exactamente como si fueran hijos del padre de este nodo. Parecerá al usuario que este nodo no existe.

Para mantener la coherencia de la interfaz de usuario, hemos descubierto que es mejor usar el estado del nodo "Siempre abierto" para los nodos sin hijos. De esta manera, el usuario solo verá un botón de carpeta junto a un nodo que tenga hijos que mostrar. Un botón de carpeta asociado con un nodo que no tiene hijos no tiene semántica definida.

Todos los nombres de recursos comienzan con XmN y todos los nombres de clase de recursos comienzan con XmC. Administración de Geometría:

La disposición se realiza asignando a cada nodo un cuadro que es lo suficientemente grande como para contenerse a sí mismo y a todos sus hijos. Luego, se realiza una disposición recursiva que centra cada nodo verticalmente en su cuadro y horizontalmente en el extremo izquierdo. Los cuadros de los hijos se colocan entonces a la derecha del nodo, separados por horizontalNodeSpace de su padre, apilados uno encima del otro y separados por verticalNodeSpace. Este proceso se repite recursivamente para cada hijo en el árbol.

El tamaño preferido de todo el árbol será lo suficientemente grande como para contener todos los nodos de la jerarquía. A medida que cambian los estados de los nodos, el árbol intentará redimensionarse para contener su configuración actual. Si el árbol se fuerza a ser más grande que el tamaño deseado, los nodos se centrarán verticalmente y se alinearán al borde izquierdo del widget tree. Si el árbol se fuerza a ser más pequeño, algunos nodos pueden moverse o dibujarse fuera del final del árbol. Por esta razón, generalmente es deseable poner el árbol en un widget Scrolled Window.

    SYNOPSIS

    El widget XmTree permite la visualización de datos en un formato de árbol. Permite a los usuarios navegar y seleccionar elementos dentro de la estructura del árbol. El widget proporciona varias opciones de personalización para la apariencia y el comportamiento.

    DESCRIPTION

    El widget XmTree es un widget de Motif que implementa una vista de árbol para mostrar datos jerárquicos. Admite la expansión y el colapso de nodos, la selección de elementos y proporciona recursos para controlar la apariencia de los nodos y las líneas que los conectan.

    Interacción del Usuario

    • Expansión/Colapso de Nodos: Los usuarios pueden hacer clic en los indicadores de expansión/colapso para mostrar u ocultar los nodos hijos.
    • Selección de Nodos: Los usuarios pueden seleccionar nodos individuales o múltiples según la configuración de selección del árbol.

    Recursos Normales

    Los siguientes recursos controlan el comportamiento y la apariencia del widget XmTree:

    connectStyle

    connectStyle (XmRConnectStyle): Especifica el estilo de las líneas que conectan los nodos. Los valores posibles incluyenXmSTATIC_LINE,XmPOLYLINEyXmCURVE.

    horizontalNodeSpace

    horizontalNodeSpace (XmRHorizontalNodeSpace): Define el espacio horizontal entre los nodos en el mismo nivel.

    verticalNodeSpace

    verticalNodeSpace (XmRVerticalNodeSpace): Define el espacio vertical entre los nodos en diferentes niveles.

    Recursos de Restricción

    Los siguientes recursos se pueden usar para aplicar restricciones a los nodos dentro del widget XmTree:

    lineColor

    lineColor (XmRColor): Especifica el color de las líneas que conectan los nodos.

    lineWidth

    lineWidth (XmRInt): Define el ancho de las líneas que conectan los nodos.
