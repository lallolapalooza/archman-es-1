XmStringDrawImage(3)

Paquete: openmotif

Licencias: LGPL-2.1-or-later

XmStringDrawImage(llamada a biblioteca) XmStringDrawImage(llamada a biblioteca)

NOMBRE

XmStringDrawImage — Una función de cadena compuesta que dibuja una cadena compuesta en una ventana X y crea una imagen

SINOPSIS

#include <Xm/Xm.h>
void XmStringDrawImage(
Display * d,
Window w,
XmRenderTable rendertable,
XmString string,
GC gc,
Position x,
Position y,
Dimension width,
unsigned char alignment,
unsigned char layout_direction,
XRectangle * clip);

DESCRIPCIÓN

XmStringDrawImage dibuja una cadena compuesta en una ventana X y pinta los bits de primer plano y de fondo de cada carácter. Si un segmento de cadena compuesta utiliza una representación que contiene un conjunto de fuentes, el contexto gráfico pasado a esta rutina dejará el miembro de la fuente del GC en un estado indefinido. La función subyacente XmbStringDraw llamada por esta rutina modifica el campo ID de fuente del GC que se le pasa y no intenta restaurar el ID de fuente a su valor inicial. Si el segmento de cadena compuesta no se dibuja usando un conjunto de fuentes, el contexto gráfico debe contener un miembro de fuente válido. Los contextos gráficos creados por XtGetGC no son aceptados por esta rutina; en su lugar, use XtAllocateGC para crear un contexto gráfico.

d
Especifica la pantalla.
w
Especifica la ventana.
rendertable
Especifica la tabla de representaciones.
string
Especifica la cadena.
gc
Especifica el contexto gráfico a usar.
x
Especifica una coordenada del rectángulo que contendrá la cadena compuesta mostrada.
y
Especifica una coordenada del rectángulo que contendrá la cadena compuesta mostrada.
width
Especifica el ancho del rectángulo que contendrá la cadena compuesta mostrada.
alignment
Especifica cómo se alineará la cadena dentro del rectángulo especificado. Es XmALIGNMENT_BEGINNING, XmALIGNMENT_CENTER o XmALIGNMENT_END.
layout_direction
Controla la dirección en la que se distribuirán los segmentos de la cadena compuesta. También determina el significado del parámetro alignment.
clip
Permite a la aplicación restringir el área en la que se dibujará la cadena compuesta. Si es NULL, el recorte se determinará por el GC.
