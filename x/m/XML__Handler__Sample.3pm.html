XML::Handler::Sample(3) Documentación de Perl aportada por el usuario XML::Handler::Sample(3)

NOMBRE

XML::Handler::Sample - un manejador PerlSAX trivial

SINOPSIS

use XML::Parser::PerlSAX;
use XML::Handler::Sample;
$my_handler = XML::Handler::Sample->new;
XML::Parser::PerlSAX->new->parse(Source => { SystemId => 'REC-xml-19980210.xml' },
                                 Handler => $my_handler);

DESCRIPCIÓN

"XML::Handler::Sample" es un manejador PerlSAX trivial que imprime el nombre de cada evento que recibe. El código fuente de "XML::Handler::Sample" enumera todos los métodos de manejador PerlSAX conocidos actualmente.

"XML::Handler::Sample" está pensado para autores de módulos Perl que deseen ver módulos manejadores PerlSAX de ejemplo. "XML::Handler::Sample" puede utilizarse como plantilla para escribir sus propios módulos manejadores PerlSAX. "XML::Handler::Sample" es de Dominio Público y puede ser utilizado para cualquier propósito sin restricción.
