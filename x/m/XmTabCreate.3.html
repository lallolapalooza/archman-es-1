NOMBRE

XmTabCreate — Una función de conveniencia que crea una marca de tabulación

SINOPSIS

#include <Xm/Xm.h>
XmTab XmTabCreate(
float value,
unsigned char units,
XmOffsetModel offset_model,
unsigned char alignment,
char *decimal);

DESCRIPCIÓN

XmTabCreate crea una marca de tabulación en una posición definida por los argumentos value y units.

value
Especifica el valor de punto flotante que se utilizará junto con units para calcular la ubicación de la marca de tabulación. Tenga en cuenta que no se permiten valores negativos.
units
Especifica el tipo de unidad (por ejemplo, XmMILLIMETERS) que se utilizará junto con value para calcular la ubicación de la marca de tabulación. Puede especificar cualquier unidad descrita en la página de referencia de XmConvertUnits. Para recursos de tipo dimensión o posición, puede especificar unidades como se describe en el recurso XmNunitType de la página de referencia de XmGadget, XmManager o XmPrimitive.
offset_model
Especifica si el valor de tabulación representa una posición absoluta o un desplazamiento relativo desde la tabulación anterior. Los valores válidos son XmABSOLUTE y XmRELATIVE.
alignment
Especifica cómo se alineará el texto con respecto a esta marca de tabulación. Los valores válidos son XmALIGNMENT_BEGINNING.
decimal
Especifica el carácter multibyte en el entorno de idioma actual que se utilizará como punto decimal para una tabulación alineada decimalmente. Actualmente no se utiliza.

RETORNO

Devuelve un XmTab recién asignado. La aplicación es responsable de administrar este espacio asignado. La aplicación puede recuperar este espacio asignado llamando a XmTabFree.

RELACIONADOS

XmTab(3) y XmTabFree(3).
