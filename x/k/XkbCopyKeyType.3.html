XkbCopyKeyType(3)

Paquete: libx11

Licencias: MIT AND X11

XkbCopyKeyType(3) FUNCIONES DE XKB XkbCopyKeyType(3)

NOMBRE

XkbCopyKeyType - Copiar una estructura XkbKeyTypeRec

SINOPSIS

Estado XkbCopyKeyType (XkbKeyTypePtr from, XkbKeyTypePtr into);

ARGUMENTOS

from
puntero a XkbKeyTypeRec a copiar
into
puntero a XkbKeyTypeRec a modificar

DESCRIPCIÓN

XkbCopyKeyType copia el tipo de tecla especificado por from al tipo de tecla especificado por into. Ambos deben apuntar a estructuras XkbKeyTypeRec legales. Xkb asume que from e into apuntan a lugares diferentes. Como resultado, las superposiciones pueden ser fatales. XkbCopyKeyType libera cualquier map, preserve, y level_names existente en into antes de copiar. Si ocurre algún error de asignación al copiar de from a into, XkbCopyKeyType devuelve BadAlloc. De lo contrario, XkbCopyKeyType copia from a into y devuelve Success.

ESTRUCTURAS

Los tipos de tecla se utilizan para determinar el nivel de modificación de una tecla dado el estado actual del teclado. El conjunto de todos los tipos de tecla posibles para la descripción del teclado Xkb se mantiene en el campo types del mapa del cliente, cuyo tamaño total se almacena en size_types, y cuyo número total de entradas válidas se almacena en num_types. Los tipos de tecla se definen utilizando la siguiente estructura:

typedef struct {                   /* Tipo de Tecla */
    XkbModsRec        mods;        /* modificadores utilizados para calcular el nivel de modificación */
    unsigned char     num_levels;  /* # total de niveles de modificación, no modificar directamente */
    unsigned char     map_count;   /* # de entradas en map, preserve (si no es NULL) */
    XkbKTMapEntryPtr  map;         /* vector de modificadores para cada nivel de modificación */
    XkbModsPtr        preserve;    /* modificadores a preservar para la entrada de mapa correspondiente */
    Atom              name;        /* nombre del tipo de tecla */
    Atom *            level_names; /* matriz de nombres de cada nivel de modificación */
} XkbKeyTypeRec, *XkbKeyTypePtr;
