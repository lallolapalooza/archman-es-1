NOMBRE

XkbAllocGeomOverlayRows - Asigna filas en una superposición

SINOPSIS

Status XkbAllocGeomOverlayRows (XkbOverlayPtr overlay, int num_needed);

ARGUMENTOS

overlay
sección para la que se deben asignar filas
num_needed
número de filas nuevas requeridas

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Use estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted completar los valores explícitamente en su código. Estas funciones de asignación aumentan sz_* pero nunca tocan num_* (a menos que haya un fallo en la asignación, en cuyo caso, reinician tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no son capaces de asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomOverlayRows asigna num_needed filas y las añade a la overlay. No se realiza ninguna inicialización de las filas.

Para liberar filas en una superposición, use XkbFreeGeomOverlayRows.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango

VER TAMBIÉN

XkbFreeGeomOverlayRows(3)
