NOMBRE

XkbAllocGeomKeyAliases - Asigna alias de teclas de geometría

SINOPSIS

Status XkbAllocGeomKeyAliases (XkbGeometryPtr geom, int num_needed);

ARGUMENTOS

geom
geometría para la cual se deben asignar alias de teclas
num_needed
número de alias de teclas nuevos requeridos

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Use estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted completar los valores explícitamente en su código. Estas funciones de asignación incrementan sz_* pero nunca tocan num_* (a menos que haya un fallo de asignación, en cuyo caso restablecen tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomKeyAliases asigna espacio para num_needed alias de teclas y los añade a la geometría especificada geom. Un alias de tecla es un par de cadenas que asocia un nombre alternativo para una tecla con el nombre real de esa tecla.

Para liberar alias de teclas de geometría, use XkbFreeGeomKeyAliases.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango

VER TAMBIÉN

XkbFreeGeomKeyAliases(3)
