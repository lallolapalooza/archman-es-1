XkbSelectEventDetails(3) FUNCIONES XKB XkbSelectEventDetails(3)

NOMBRE

XkbSelectEventDetails - Selecciona o deselecciona un evento Xkb específico y, opcionalmente, establece condiciones sobre cuándo se informan eventos de ese tipo a tu cliente.

SINOPSIS

Bool XkbSelectEventDetails (Display *display, unsigned int device_spec, unsigned int event_type, unsigned long int bits_to_change, unsigned long int values_for_bits);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo o XkbUseCoreKbd
event_type
tipo de evento Xkb de interés
bits_to_change
determina los eventos a seleccionar/deseleccionar
values_for_bits
1=>seleccionar, 0=>deseleccionar; para eventos en bits_to_change

DESCRIPCIÓN

Los eventos Xkb se seleccionan usando una máscara de eventos, muy parecido a como se seleccionan los eventos centrales normales de X. Sin embargo, a diferencia de la selección de eventos centrales de X, donde debes especificar el estado de selección (activado o desactivado) para todos los tipos de eventos posibles cada vez que desees cambiar los criterios de selección para algún evento, Xkb te permite restringir la especificación solo a los tipos de eventos que deseas cambiar. Esto significa que no necesitas recordar los valores de selección de eventos para todos los tipos cada vez que quieras cambiar uno de ellos.

Muchos tipos de eventos Xkb se generan en varias circunstancias diferentes. Al seleccionar recibir un evento Xkb, puedes especificar si deseas que se entregue en todas las circunstancias o si deseas que se entregue solo para un subconjunto de las circunstancias posibles.

También puedes deseleccionar un tipo de evento para el que previamente se había seleccionado, utilizando la misma granularidad.

Xkb proporciona dos funciones para seleccionar y deseleccionar la entrega de eventos Xkb. XkbSelectEvents te permite seleccionar o deseleccionar la entrega de más de un tipo de evento Xkb a la vez. Los eventos seleccionados usando XkbSelectEvents se entregan a tu programa en todas las circunstancias que generan los eventos. Para restringir la entrega de un evento a un subconjunto de las condiciones bajo las cuales ocurre, usa XkbSelectEventDetails. XkbSelectEventDetails solo te permite cambiar las condiciones de selección para un solo evento a la vez, pero proporciona un medio para ajustar las condiciones bajo las cuales se entrega el evento.

Para seleccionar o deseleccionar un evento Xkb específico y, opcionalmente, establecer condiciones sobre cuándo se informan eventos de ese tipo a tu cliente, usa XkbSelectEventDetails. Esto te permite ejercer una granularidad de control más fina sobre la entrega de eventos Xkb con XkbSelectEvents.

Mientras que XkbSelectEvents permite seleccionar múltiples eventos, XkbSelectEventDetails cambia los criterios de selección para un solo tipo de evento Xkb. La interpretación de las máscaras bits_to_change y values_for_bits depende del tipo de evento en cuestión.

XkbSelectEventDetails cambia la máscara de selección de eventos Xkb para el teclado especificado por device_spec y el evento Xkb especificado por event_type. Para activar la selección de eventos para un detalle de evento, establece el bit del detalle en el parámetro bits_to_change y establece el bit correspondiente en el parámetro values_for_bits. Para desactivar la selección de detalles de eventos para un detalle, establece el bit del detalle en el parámetro bits_to_change y no establezcas el bit correspondiente en el parámetro values_for_bits.

Si se especifica un tipo de evento inválido, se produce un error de protocolo BadValue. Si un bit no está establecido en el parámetro bits_to_change, pero el bit correspondiente está establecido en el parámetro values_for_bits, se produce un error de protocolo BadMatch. Si se establece un bit indefinido en el parámetro bits_to_change o values_for_bits, se produce un error de protocolo BadValue.

Para cada tipo de evento Xkb, los detalles de eventos legales que puedes especificar en la solicitud XkbSelectEventDetails se enumeran en los capítulos que describen cada evento en detalle.

DIAGNÓSTICOS

BadMatch
No se encontró una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otro modo.
BadValue
Un argumento está fuera de rango.
