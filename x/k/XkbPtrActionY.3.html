XkbPtrActionY(3) FUNCIONES XKB XkbPtrActionY(3)

NOMBRE

XkbPtrActionY - Devuelve los campos high_YYY y low_YYY de act convertidos a un entero con signo

SINOPSIS

int XkbPtrActionY (XkbPtrAction act);

ARGUMENTOS

act
acción de la que extraer Y

DESCRIPCIÓN

Las acciones asociadas con la estructura XkbPtrAction mueven el puntero cuando se presionan y sueltan las teclas.

Si el control MouseKeys no está habilitado, los eventos KeyPress y KeyRelease se tratan como si la acción fuera XkbSA_NoAction.

Si el control MouseKeys está habilitado, una acción del servidor de tipo XkbSA_MovePtr instruye al servidor a generar eventos core MotionNotify en lugar del evento KeyPress habitual, y el evento KeyRelease correspondiente deshabilita cualquier temporizador de teclas del ratón que se haya creado como resultado del manejo de la acción XkbSA_MovePtr.

El campo type de la estructura XkbPtrAction es siempre XkbSA_MovePtr.

El campo flags es un OR inclusivo a nivel de bits de las máscaras que se muestran en la Tabla 1.

Tabla 1 Tipos de Acción de Puntero
Tipo de Acción Significado
XkbSA_NoAcceleration Si no está configurado, y el control MouseKeysAccel está habilitado, el KeyPress inicia un temporizador de teclas del ratón para esta tecla; cada vez que el temporizador expira, el cursor se mueve.
XkbSA_MoveAbsoluteX Si está configurado, la porción X de la estructura especifica la nueva coordenada X del puntero. De lo contrario, la porción X se añade a la coordenada X actual del puntero para determinar la nueva coordenada X del puntero.
XkbSA_MoveAbsoluteY Si está configurado, la porción Y de la estructura especifica la nueva coordenada Y del puntero. De lo contrario, la porción Y se añade a la coordenada Y actual del puntero para determinar la nueva coordenada Y del puntero.

Cada una de las coordenadas X e Y de la estructura XkbPtrAction está compuesta por dos valores de 16 bits con signo, es decir, la coordenada X está compuesta por high_XXX y low_XXX, y de forma similar para la coordenada Y. Xkb proporciona las siguientes macros para convertir entre un entero con signo y dos valores de 16 bits con signo en las estructuras XkbPtrAction.

ESTRUCTURAS

    typedef struct _XkbPtrAction {
        unsigned char    type;         /* XkbSA_MovePtr */
        unsigned char    flags;        /* determina el tipo de movimiento del puntero */
        unsigned char    high_XXX;     /* coordenada X, bits altos*/
        unsigned char    low_XXX;      /* coordenada Y, bits bajos */
        unsigned char    high_YYY;     /* coordenada X, bits altos */
        unsigned char    low_YYY;      /* coordenada Y, bits bajos */
    } XkbPtrAction;
