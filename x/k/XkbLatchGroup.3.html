NOMBRE

XkbLatchGroup - Fija el grupo de glifos

SINOPSIS

Bool XkbLatchGroup (Display *display, unsigned int device_spec, unsigned int group);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo, o XkbUseCoreKbd
group
índice del grupo de glifos a fijar

DESCRIPCIÓN

XkbLatchGroup envía una solicitud al servidor para fijar el group especificado y no espera una respuesta. Devuelve True si la solicitud se envió y False en caso contrario.

Consulte los índices de grupos de glifos con estas constantes simbólicas:

Tabla 1 Nombres de Grupos Simbólicos
Nombre Simbólico Valor
XkbGroup1Index 0
XkbGroup2Index 1
XkbGroup3Index 2
XkbGroup4Index 3

VALORES DE RETORNO

True
La función XkbLatchGroup devuelve True si se envió una solicitud al servidor para fijar el group especificado.
False
La función XkbLatchGroup devuelve False si la solicitud no se envió.
