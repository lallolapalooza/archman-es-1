XkbSAScreen(3)

Paquete: libx11

Licencias: MIT AND X11

XkbSAScreen(3) FUNCIONES XKB XkbSAScreen(3)

NOMBRE

XkbSAScreen - Devuelve el campo screenXXX de act convertido a un entero con signo

SINOPSIS

int XkbSAScreen (XkbSwitchScreenAction act);

ARGUMENTOS

act
acción de la cual extraer la pantalla

DESCRIPCIÓN

Las acciones asociadas con la estructura de acción XkbSwitchScreen cambian la pantalla activa en una pantalla múltiple.

El campo type de la estructura XkbSwitchScreenAction siempre debe ser XkbSA_SwitchScreen.

El campo flags se compone de la operación OR inclusiva a nivel de bits de las máscaras que se muestran en la Tabla 1.

Tabla 1 Banderas de acción de cambio de pantalla
Bandera Significado
XkbSA_SwitchAbsolute Si está establecida, el campo screenXXX representa el índice de la nueva pantalla. De lo contrario, representa un desplazamiento desde la pantalla actual a la nueva pantalla.
XkbSA_SwitchApplication Si no está establecida, la acción debe cambiar a otra pantalla en el mismo servidor. De lo contrario, debe cambiar a otro servidor X o aplicación que comparta la misma pantalla física.

El campo screenXXX es un valor de carácter con signo que representa el índice de pantalla relativo o absoluto, dependiendo del estado del bit XkbSA_SwitchAbsolute en el campo flags. Xkb proporciona las siguientes macros para convertir entre el valor entero y el valor de carácter con signo para los números de pantalla en las estructuras XkbSwitchScreenAction.

La macro XkbSAScreen devuelve el campo screenXXX de act convertido a un entero con signo.

ESTRUCTURAS

    typedef struct _XkbSwitchScreenAction {
        unsigned char    type;        /* XkbSA_SwitchScreen */
        unsigned char    flags;       /* controla el cambio de pantalla */
        char             screenXXX;   /* número de pantalla o delta */
    } XkbSwitchScreenAction;

NOTAS

La acción XkbSwitchScreen es opcional. Los servidores son libres de ignorar la acción o cualquiera de sus banderas si no admiten el comportamiento solicitado. Si la acción se ignora, se comporta como XkbSA_NoAction. De lo contrario, las pulsaciones y liberaciones de teclas no generan un evento.
