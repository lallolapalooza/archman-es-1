XkbKeyGroupInfo(3)

Paquete: libx11

Licencias: MIT AND X11

XkbKeyGroupInfo(3) FUNCIONES XKB XkbKeyGroupInfo(3)

NOMBRE

XkbKeyGroupInfo - Devuelve el número de grupos de símbolos vinculados a la tecla que corresponde a keycode

SINOPSIS

unsigned char XkbKeyGroupInfo (XkbDescPtr xkb, KeyCode keycode);

ARGUMENTOS

xkb
Descripción Xkb de interés
keycode
keycode de interés

DESCRIPCIÓN

El campo group_info de un XkbSymMapRec es un valor codificado que contiene el número de grupos de símbolos vinculados a la tecla, así como la especificación del tratamiento de los grupos fuera de rango. Es legal que una tecla tenga cero grupos, en cuyo caso también tiene cero símbolos y todos los eventos de esa tecla producen NoSymbol. Para obtener el número de grupos de símbolos vinculados a la tecla, utilice XkbKeyNumGroups. Para cambiar el número de grupos vinculados a una tecla, utilice XkbChangeTypesOfKey. Para obtener una máscara que determine el tratamiento de los grupos fuera de rango, utilice XkbKeyGroupInfo y XkbOutOfRangeGroupInfo.

Los controles del teclado contienen un campo groups_wrap que especifica el manejo de grupos ilegales a nivel global. Es decir, cuando el usuario realiza una acción que provoca que el grupo efectivo salga del rango legal, el campo groups_wrap especifica cómo normalizar el grupo efectivo del teclado a un grupo que sea legal para el teclado en su conjunto, pero no hay garantía de que el grupo normalizado esté dentro del rango de grupos legales para ninguna tecla individual. El campo group_info de cada tecla especifica cómo una tecla trata un grupo efectivo legal si la tecla no tiene un tipo especificado para el grupo en cuestión. Por ejemplo, la tecla Enter normalmente solo tiene un grupo definido. Si el usuario realiza una acción que hace que el grupo global del teclado cambie a Grupo2, el campo group_info para la tecla Enter describe cómo manejar esta situación.

Los grupos fuera de rango para teclas individuales se mapean a un grupo legal utilizando las mismas opciones que se utilizan para el grupo del teclado en general. El tipo particular de mapeo utilizado está controlado por los bits establecidos en el indicador group_info, como se muestra en la Tabla 1.

Tabla 1 Normalización de rango de group_info
Bits establecidos en group_info Método de normalización
XkbRedirectIntoRange XkbRedirectIntoRange
XkbClampIntoRange XkbClampIntoRange
ninguno de los anteriores XkbWrapIntoRange

XkbKeyGroupInfo devuelve el campo group_info de la estructura XkbSymMapRec asociada con la tecla correspondiente a keycode.

ESTRUCTURAS

La estructura KeySymMapRec se define de la siguiente manera:

#define XkbNumKbdGroups             4
#define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
typedef struct {                    /* map to keysyms for a single keycode */
    unsigned char       kt_index[XkbNumKbdGroups];  /* índice de tipo de tecla para cada grupo */
    unsigned char       group_info; /* # de grupos y manejo de grupo fuera de rango */
    unsigned char       width;      /* # máximo de niveles de shift para la tecla */
    unsigned short      offset;     /* índice a la tabla de keysyms en el array syms */
} XkbSymMapRec, *XkbSymMapPtr;
La estructura XkbControlsRec se define de la siguiente manera:
#define XkbMaxLegalKeyCode     255
#define XkbPerKeyBitArraySize  ((XkbMaxLegalKeyCode+1)/8)
typedef struct {
    unsigned char   mk_dflt_btn;      /* botón predeterminado para ratón controlado por teclado */
    unsigned char   num_groups;       /* número de grupos de teclado */
    unsigned char   groups_wrap;      /* cómo envolver grupos fuera de límites */
    XkbModsRec      internal;         /* define modificadores internos del servidor */
    XkbModsRec      ignore_lock;      /* modificadores a ignorar al comprobar un grab */
    unsigned int    enabled_ctrls;    /* 1 bit => control booleano correspondiente habilitado */
    unsigned short  repeat_delay;     /* retraso en ms hasta la primera repetición */
    unsigned short  repeat_interval;  /* retraso en ms entre repeticiones */
    unsigned short  slow_keys_delay;  /* tiempo mínimo en ms que la tecla debe estar pulsada para ser válida */
    unsigned short  debounce_delay;   /* retraso en ms antes de reactivar la tecla */
    unsigned short  mk_delay;         /* retraso en ms para el segundo evento de movimiento del ratón */
    unsigned short  mk_interval;      /* retraso en ms entre eventos repetidos del ratón */
    unsigned short  mk_time_to_max;   /* # intervalos hasta movimiento constante del ratón */
    unsigned short  mk_max_speed;     /* multiplicador para la velocidad máxima del ratón */
    short           mk_curve;         /* determina el tipo de curva de movimiento del ratón */
    unsigned short  ax_options;       /* 1 bit => opción Access X habilitada */
    unsigned short  ax_timeout;       /* segundos hasta que Access X se deshabilite */
    unsigned short  axt_opts_mask;    /* 1 bit => opciones a restablecer al tiempo de espera de Access X */
    unsigned short  axt_opts_values;  /* 1 bit => activa la opción, 0=> la desactiva */
    unsigned int    axt_ctrls_mask;   /* qué bits en enabled_ctrls modificar */
    unsigned int    axt_ctrls_values; /* valores para los nuevos bits en enabled_ctrls */
    unsigned char   per_key_repeat[XkbPerKeyBitArraySize];  /* repetición por tecla */
} XkbControlsRec, *XkbControlsPtr;
