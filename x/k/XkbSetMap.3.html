XkbSetMap(3) FUNCIONES DE XKB XkbSetMap(3)

NOMBRE

XkbSetMap - Envía un nuevo conjunto completo de valores para componentes enteros al servidor.

SINOPSIS

Bool XkbSetMap (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara que selecciona los subcomponentes a actualizar
xkb
descripción de la cual se toman los nuevos valores

DESCRIPCIÓN

Hay dos formas de realizar cambios en los componentes del mapa: o bien cambiar una copia local del mapa del teclado y llamar a XkbSetMap para enviar el mapa modificado al servidor, o bien, para reducir el tráfico de red, usar una estructura XkbMapChangesRec y llamar a XkbChangeMap.

Utilice XkbSetMap para enviar un nuevo conjunto completo de valores para componentes enteros (por ejemplo, todos los símbolos, todas las acciones, etc.) al servidor. El parámetro which especifica los componentes que se enviarán al servidor, y es una combinación OR inclusiva a nivel de bits de las máscaras listadas en la Tabla 1. El parámetro xkb es un puntero a una estructura XkbDescRec y contiene la información que se copiará al servidor. Por cada bit establecido en el parámetro which, XkbSetMap toma los valores de la estructura correspondiente del parámetro xkb y lo envía al servidor especificado por dpy.

Si algún componente especificado por which no está presente en el parámetro xkb, XkbSetMap devuelve False. De lo contrario, envía la solicitud de actualización al servidor y devuelve True. XkbSetMap puede generar errores de protocolo BadAlloc, BadLength y BadValue.

Los tipos de teclas, los mapas de símbolos y las acciones están interrelacionados; los cambios en uno requieren cambios en los otros. Xkb proporciona funciones para facilitar la edición de estos componentes y el manejo de las interdependencias. La Tabla 1 enumera estas funciones de ayuda y proporciona un puntero a dónde están definidas.

El campo changed identifica los componentes del mapa que han cambiado en una estructura XkbDescRec y puede contener cualquiera de los bits de la Tabla 1, que también se muestran en la Tabla 2. Cada bit 1 en changed identifica también qué otros campos en la estructura XkbMapChangesRec contienen valores válidos, como se indica en la Tabla 2. Los campos min_key_code y max_key_code son solo de referencia; se ignoran en cualquier solicitud enviada al servidor y siempre son actualizados por el servidor cuando devuelve los datos para una XkbMapChangesRec.

VALORES DE RETORNO

Verdadero
La función XkbSetMap devuelve Verdadero si todos los componentes especificados por which están presentes en el parámetro xkb.
Falso
La función XkbSetMap devuelve Falso si algún componente especificado por which no está presente en el parámetro xkb.

ESTRUCTURAS

Utilice la estructura XkbMapChangesRec para identificar y rastrear modificaciones parciales en los componentes del mapa y para reducir la cantidad de tráfico entre el servidor y los clientes.

typedef struct _XkbMapChanges {
    unsigned short   changed;            /* identifica componentes válidos en la estructura */
    KeyCode          min_key_code;       /* keycode con el número más bajo para el dispositivo */
    KeyCode          max_key_code;       /* keycode con el número más alto para el dispositivo */
    unsigned char    first_type;         /* índice del primer tipo de tecla modificado */
    unsigned char    num_types;          /* # tipos modificados */
    KeyCode          first_key_sym;      /* primera tecla cuyo mapa_símbolos_tecla cambió */
    unsigned char    num_key_syms;       /* # entradas mapa_símbolos_tecla cambiadas */
    KeyCode          first_key_act;      /* primera tecla cuya entrada acciones_tecla cambió */
    unsigned char    num_key_acts;       /* # entradas acciones_tecla cambiadas */
    KeyCode          first_key_behavior; /* primera tecla cuyos comportamientos cambiaron */
    unsigned char    num_key_behaviors;  /* # entradas de comportamientos cambiadas */
    KeyCode          first_key_explicit; /* primera tecla cuya entrada explícita cambió */
    unsigned char    num_key_explicit;   /* # entradas explícitas cambiadas */
    KeyCode          first_modmap_key;

La descripción completa de un teclado Xkb se da mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado para Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de teclas del servidor */
   XkbClientMapPtr    map;          /* mapa de teclas del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de pantalla X. El campo flags es privado para la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede devolver el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos de la XkbDescRec se muestran en la Tabla 3.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadLength
La longitud de una solicitud es más corta o más larga de lo que se requiere para contener mínimamente los argumentos
BadValue
Un argumento está fuera de rango
