XkbSASetScreen(3)

Paquete: libx11

Licencias: MIT AND X11

XkbSASetScreen(3) FUNCIONES XKB XkbSASetScreen(3)

NOMBRE

XkbSASetScreen - Establece el campo screenXXX de act desde s

SINOPSIS

void XkbSASetScreen (XkbSwitchScreenAction act, int s);

ARGUMENTOS

act
acción en la que establecer screenXXX
s
valor a establecer en screenXXX

DESCRIPCIÓN

Las acciones asociadas a la estructura de acción XkbSwitchScreen cambian la pantalla activa en una pantalla múltiple.

El campo type de la estructura XkbSwitchScreenAction siempre debe ser XkbSA_SwitchScreen.

El campo flags se compone del OR inclusivo a nivel de bits de las máscaras que se muestran en la Tabla 1.

Tabla 1 Banderas de Acción de Cambio de Pantalla
Bandera Significado
XkbSA_SwitchAbsolute Si está activada, el campo screenXXX representa el índice de la nueva pantalla. De lo contrario, representa un desplazamiento desde la pantalla actual a la nueva pantalla.
XkbSA_SwitchApplication Si no está activada, la acción debe cambiar a otra pantalla en el mismo servidor. De lo contrario, debe cambiar a otro servidor X o aplicación que comparta la misma pantalla física.

El campo screenXXX es un valor de carácter con signo que representa el índice de pantalla relativo o absoluto, dependiendo del estado del bit XkbSA_SwitchAbsolute en el campo flags. Xkb proporciona las siguientes macros para convertir entre el valor entero y de carácter con signo para los números de pantalla en las estructuras XkbSwitchScreenAction.

ESTRUCTURAS

    typedef struct _XkbSwitchScreenAction {
        unsigned char    type;        /* XkbSA_SwitchScreen */
        unsigned char    flags;       /* controla el cambio de pantalla */
        char             screenXXX;   /* número de pantalla o delta */
    } XkbSwitchScreenAction;

NOTAS

Esta acción es opcional. Los servidores son libres de ignorar la acción o cualquiera de sus banderas si no admiten el comportamiento solicitado. Si la acción es ignorada, se comporta como XkbSA_NoAction. De lo contrario, los eventos de pulsación y liberación de teclas no generan un evento.
