NOMBRE

XkbLatchModifiers - Fija y desbloquea cualquiera de los ocho modificadores reales del teclado

SINOPSIS

Bool XkbLatchModifiers (Display *display, unsigned int device_spec, unsigned int affect, unsigned int values);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo o XkbUseCoreKbd
affect
máscara de modificadores reales cuyo estado de bloqueo se va a cambiar
values
1 => fijar, 0 => desbloquear; solo para los modificadores seleccionados por affect

DESCRIPCIÓN

XkbLatchModifiers envía una solicitud al servidor para fijar los modificadores reales seleccionados por tanto affect como values y para desbloquear los modificadores reales seleccionados por affect, pero no seleccionados por values.

XkbLatchModifiers no espera una respuesta del servidor. Devuelve True si la solicitud fue enviada y False en caso contrario.

Las funciones de esta sección que cambian el uso de modificadores utilizan una máscara en el parámetro affect. Es una operación OR inclusiva a nivel de bits de las máscaras de modificadores legales:

Tabla 1 Máscaras de Modificadores Reales
Máscara
ShiftMask
LockMask
ControlMask
Mod1Mask
Mod2Mask
Mod3Mask
Mod4Mask
Mod5Mask

VALORES DEVUELTOS

True
La función XkbLatchModifiers devuelve True si se envió una solicitud al servidor para fijar los modificadores reales seleccionados por tanto affect como values y para desbloquear los modificadores reales seleccionados por affect, pero no seleccionados por values.
False
La función XkbLatchModifiers devuelve False si la solicitud no se envió.
