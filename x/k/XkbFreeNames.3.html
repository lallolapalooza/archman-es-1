XkbFreeNames(3) FUNCIONES XKB XkbFreeNames(3)

NOMBRE

XkbFreeNames - Liberar estructuras de nombres simbólicos

SINOPSIS

void XkbFreeNames (XkbDescPtr xkb, unsigned int which, Bool free_map);

ARGUMENTOS

xkb
descripción del teclado para el cual se liberarán los nombres
which
máscara de componentes de nombres a liberar
free_map
Verdadero => la estructura XkbNamesRec en sí misma debe ser liberada

DESCRIPCIÓN

No libere las estructuras de nombres simbólicos directamente usando free o XFree. Use XkbFreeNames en su lugar.

El parámetro which es el OR a nivel de bits inclusivo de los bits de máscara de nombres válidos definidos en la Tabla 1.

Xkb proporciona varias funciones que trabajan con nombres simbólicos. Cada una de estas funciones usa una máscara para especificar campos individuales de las estructuras descritas anteriormente. Estas máscaras y sus relaciones con los campos de una descripción de teclado se muestran en la Tabla 1.
