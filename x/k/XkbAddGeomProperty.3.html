XkbAddGeomProperty(3) FUNCIONES XKB XkbAddGeomProperty(3)

NOMBRE

XkbAddGeomProperty - Añadir una propiedad a una descripción de geometría de teclado existente

SINOPSIS

XkbPropertyPtr XkbAddGeomProperty (XkbGeometryPtr geom, _Xconst char *name, _Xconst char *value);

ARGUMENTOS

geom
geometría a actualizar
name
nombre de la nueva propiedad
value
valor para la nueva propiedad

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría de teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no cambian sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debes escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades de geometría. Una propiedad de geometría asocia una cadena de caracteres arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar propiedades de geometría como indicaciones, pero Xkb no las interpreta. Ninguna otra estructura de geometría hace referencia a propiedades de geometría.

XkbAddGeomProperty añade una propiedad con el nombre y valor especificados a la geometría del teclado especificada por geom. XkbAddGeomProperty devuelve NULL si alguno de los parámetros está vacío o si no pudo asignar espacio para la propiedad. Para asignar espacio para un número arbitrario de propiedades, usa la función XkbAllocGeomProps.

ESTRUCTURAS

    typedef struct _XkbProperty {
        char *         name;       /* nombre de la propiedad */
        char *         value;      /* valor de la propiedad */
    } XkbPropertyRec,*XkbPropertyPtr;

VER TAMBIÉN
