XkbChangeEnabledControls(3)

Paquete: libx11

Licencias: MIT AND X11

XkbChangeEnabledControls(3) FUNCIONES XKB XkbChangeEnabledControls(3)

NOMBRE

XkbChangeEnabledControls - Manipula el control EnabledControls

SINOPSIS

Bool XkbChangeEnabledControls (Display *dpy, unsigned int device_spec, unsigned int mask, unsigned int values);

ARGUMENTOS

dpy
conexión al servidor X
device_spec
dispositivo de teclado a modificar
mask
1 bit -> controles a habilitar / deshabilitar
values
1 bit => habilitar, 0 bit => deshabilitar

DESCRIPCIÓN

El control EnabledControls es una máscara de bits donde cada bit que se activa significa que el control correspondiente está habilitado, y cuando se desactiva, deshabilitado. Corresponde al campo enabled_ctrls de una estructura XkbControlsRec (ver ESTRUCTURAS). Los bits que describen qué controles están activados o desactivados se definen en la Tabla 1.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar controles para su modificación y para habilitar y deshabilitar el control. Tenga en cuenta que el mismo bit de máscara se utiliza para especificar modificaciones generales a los parámetros utilizados para configurar el control (cuál), y para habilitar y deshabilitar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no se pueden habilitar o deshabilitar.

Tabla 1 Bits de Máscara de Controles

XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)

XkbGroupsWrapMask ok (1L<<27)

El parámetro mask especifica los controles booleanos que se habilitarán o deshabilitarán, y la máscara values especifica el nuevo estado para esos controles. Los valores válidos para ambas máscaras se componen de una OR inclusiva a nivel de bits tomada del conjunto de bits de máscara de la Tabla 1, utilizando solo aquellas máscaras con "ok" en la columna enabled_ctrls.

Si el servidor X no admite una versión compatible de Xkb o la extensión Xkb no se ha inicializado correctamente, XkbChangeEnabledControls devuelve False; de lo contrario, envía la solicitud al servidor X y devuelve True.

Tenga en cuenta que el control EnabledControls solo habilita y deshabilita controles; no los configura. Algunos controles, como el control AudibleBell, no tienen atributos de configuración y, por lo tanto, se manipulan únicamente habilitándolos y deshabilitándolos. Otros, sin embargo, tienen atributos adicionales para configurar su comportamiento. Por ejemplo, el control RepeatControl utiliza los campos repeat_delay y repeat_interval para describir el comportamiento temporal de las teclas que se repiten. El comportamiento de RepeatControl se activa o desactiva según el valor del bit XkbRepeatKeysMask, pero debe utilizar otros medios, como se describe en este capítulo, para configurar su comportamiento en detalle.

VALORES DE RETORNO

True
El servidor X admite una versión compatible de Xkb.
False
El servidor X no admite una versión compatible de Xkb o la extensión Xkb no se ha inicializado correctamente.

ESTRUCTURAS

La estructura XkbControlsRec se define de la siguiente manera:
    #define XkbMaxLegalKeyCode     255
    #define XkbPerKeyBitArraySize  ((XkbMaxLegalKeyCode+1)/8)
    typedef struct {
        unsigned char   mk_dflt_btn;      /* botón por defecto para ratón controlado por teclado */
        unsigned char   num_groups;       /* número de grupos de teclado */
        unsigned char   groups_wrap;      /* cómo envolver grupos fuera de límites */
        XkbModsRec      internal;         /* define los modificadores internos del servidor */
        XkbModsRec      ignore_lock;      /* modificadores a ignorar al comprobar capturas */
        unsigned int    enabled_ctrls;    /* 1 bit => control booleano correspondiente habilitado */
        unsigned short  repeat_delay;     /* retraso en ms hasta la primera repetición */
        unsigned short  repeat_interval;  /* retraso en ms entre repeticiones */
        unsigned short  slow_keys_delay;  /* tiempo mínimo en ms que la tecla debe estar pulsada para ser válida */
        unsigned short  debounce_delay;   /* retraso en ms antes de reactivar la tecla */
        unsigned short  mk_delay;         /* retraso en ms hasta el segundo evento de movimiento del ratón */
        unsigned short  mk_interval;      /* retraso en ms entre eventos de repetición del ratón */
        unsigned short  mk_time_to_max;   /* # intervalos hasta movimiento constante del ratón */
        unsigned short  mk_max_speed;     /* multiplicador para la velocidad máxima del ratón */
        short           mk_curve;         /* determina el tipo de curva de movimiento del ratón */
        unsigned short  ax_options;       /* 1 bit => opción Access X habilitada */
        unsigned short  ax_timeout;       /* segundos hasta que Access X se deshabilite */
        unsigned short  axt_opts_mask;    /* 1 bit => opciones a restablecer en el tiempo de espera de Access X */
        unsigned short  axt_opts_values;  /* 1 bit => activa la opción, 0=> desactiva */
        unsigned int    axt_ctrls_mask;   /* qué bits en enabled_ctrls modificar */
        unsigned int    axt_ctrls_values; /* valores para los nuevos bits en enabled_ctrls */
        unsigned char   per_key_repeat[XkbPerKeyBitArraySize];  /* repetición automática por tecla */
     } XkbControlsRec, *XkbControlsPtr;
