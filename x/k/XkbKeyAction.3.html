XkbKeyAction(3) FUNCIONES XKB XkbKeyAction(3)

NOMBRE

XkbKeyAction - Devuelve la acción de la tecla

SINOPSIS

XkbAction XkbKeyAction (XkbDescPtr xkb, KeyCode keycode, int idx);

ARGUMENTOS

xkb
descripción Xkb de interés
keycode
código de tecla de interés
idx
índice para grupo y nivel de mayúsculas/minúsculas

DESCRIPCIÓN

Una acción de tecla define el efecto que tienen las pulsaciones y liberaciones de teclas en el estado interno del servidor. Por ejemplo, la acción de tecla esperada asociada con la pulsación de la tecla Shift es establecer el modificador Shift. Hay cero o una acción de tecla asociada con cada keysym enlazado a cada tecla.

Así como la lista completa de símbolos de tecla para la asignación del teclado se mantiene en el campo syms del mapa del cliente, la lista completa de acciones de tecla para la asignación del teclado se mantiene en el array acts del mapa del servidor. El tamaño total de acts se especifica por size_acts y el número de entradas se especifica por num_acts.

El array key_acts, indexado por código de tecla, describe las acciones asociadas con una tecla. El array key_acts tiene min_key_code entradas no utilizadas al principio para permitir el indexado directo usando un código de tecla. Si una entrada de key_acts es cero, significa que la tecla no tiene ninguna acción asociada. Si una entrada no es cero, la entrada representa un índice en el campo acts del mapa del servidor, de forma muy similar a como el campo offset de una estructura XkbSymMapRec es un índice en el campo syms del mapa del cliente.

La razón por la que el campo acts es una lista lineal de XkbActions es para reducir el consumo de memoria asociado con un mapa de teclas. Dado que Xkb permite que las teclas individuales tengan múltiples niveles de mayúsculas/minúsculas y un número diferente de grupos por tecla, una única matriz bidimensional de KeySyms sería potencialmente muy grande y dispersa. En su lugar, Xkb proporciona una pequeña matriz bidimensional de XkbActions para cada tecla. Para almacenar todas estas matrices individuales, Xkb concatena cada matriz en el campo acts del mapa del servidor.

Las estructuras de acciones de tecla consisten solo en campos de tipo char o unsigned char. Esto se hace para optimizar la transferencia de datos cuando el servidor envía bytes a través de la red. Si los campos son algo más que bytes, el servidor tiene que examinar todas las acciones e intercambiar cualquier campo no byte. Como consisten únicamente en bytes, simplemente puede copiarlos.

XkbKeyAction devuelve la acción de tecla indexada por idx en la matriz bidimensional de acciones de tecla asociadas con la tecla correspondiente a keycode. idx puede calcularse a partir del grupo y el nivel de mayúsculas/minúsculas de interés de la siguiente manera:

    idx = group_index * key_width + shift_level

ESTRUCTURAS

La estructura XkbSymMapRec se define de la siguiente manera:

    #define XkbNumKbdGroups             4
    #define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
    typedef struct {                    /* map to keysyms for a single keycode */
        unsigned char       kt_index[XkbNumKbdGroups];  /* key type index for each group */
        unsigned char       group_info; /* # of groups and out of range group handling */
        unsigned char       width;      /* max # of shift levels for key */
        unsigned short      offset;     /* index to keysym table in syms array */
} XkbSymMapRec, *XkbSymMapPtr;
