XkbFreeGeometry(3) FUNCIONES XKB XkbFreeGeometry(3)

NOMBRE

XkbFreeGeometry - Liberar una geometría completa

SINOPSIS

void XkbFreeGeometry (XkbGeometryPtr geom, unsigned int which, Bool free_all);

ARGUMENTOS

geom
geometría a liberar
which
máscara de componentes de la geometría a liberar
free_all
True => la geometría completa es liberada

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted rellenar los valores explícitamente en su código. Estas funciones de asignación incrementan sz_* pero nunca tocan num_* (a menos que haya un fallo de asignación, en cuyo caso restablecen tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

Los valores de which y free_all determinan cuánto de la geometría especificada se libera. Los valores válidos para which son:

    #define   XkbGeomPropertiesMask      (1<<0)
    #define   XkbGeomColorsMask          (1<<1)
    #define   XkbGeomShapesMask          (1<<2)
    #define   XkbGeomSectionsMask        (1<<3)
    #define   XkbGeomDoodadsMask         (1<<4)
    #define   XkbGeomKeyAliasesMask      (1<<5)
    #define   XkbGeomAllMask             (0x3f)
Si free_all es True, se libera la geometría completa independientemente del valor de which. De lo contrario, se liberan las partes de la geometría especificadas por which.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango
