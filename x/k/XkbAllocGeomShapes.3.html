NOMBRE

XkbAllocGeomShapes - Asigna espacio para un número arbitrario de formas geométricas

SINOPSIS

Status XkbAllocGeomShapes (XkbGeometryPtr geom, int num_needed);

ARGUMENTOS

geom
geometría para la que se deben asignar formas
num_needed
número de formas nuevas requeridas

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted completar los valores explícitamente en su código. Estas funciones de asignación aumentan sz_* pero nunca tocan num_* (a menos que haya un error de asignación, en cuyo caso reinician tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomShapes asigna espacio para num_needed formas en la geometría especificada geom. Las formas no se inicializan.

Para liberar formas geométricas, utilice XkbFreeGeomShapes.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango

VER TAMBIÉN

XkbFreeGeomShapes(3)
