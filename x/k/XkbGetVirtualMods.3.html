XkbGetVirtualMods(3) FUNCIONES DE XKB XkbGetVirtualMods(3)

NOMBRE

XkbGetVirtualMods - Obtiene un subconjunto de las vinculaciones de modificadores virtuales (el array vmods) en una descripción de teclado

SINOPSIS

Status XkbGetVirtualMods (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor
which
máscara que indica las vinculaciones de modificadores virtuales a obtener
xkb
descripción Xkb donde se colocarán los resultados

DESCRIPCIÓN

XkbGetVirtualMods envía una solicitud al servidor para obtener las entradas vmods de los modificadores virtuales especificados en la máscara which, y espera una respuesta.

Los modificadores virtuales se nombran convirtiendo su nombre de cadena a un átomo X y almacenando el átomo en el array names.vmods de una estructura XkbDescRec. La posición de un átomo de nombre en el array names.vmods define la posición de bit utilizada para representar el modificador virtual y también el índice utilizado al acceder a la información del modificador virtual en los arrays: el nombre en la i-ésima entrada (0 relativa) de names.vmods es el i-ésimo modificador virtual, representado por la máscara (1<<i). En todas las funciones de Xkb, varias funciones tienen un parámetro que es una máscara que representa las opciones de modificadores virtuales. En cada caso, el i-ésimo bit (0 relativa) de la máscara representa el i-ésimo modificador virtual.

Para establecer el nombre de un modificador virtual, use XkbSetNames, usando XkbVirtualModNamesMask en which y el nombre en el argumento xkb; para recuperar los nombres de los indicadores, use XkbGetNames.

Para cada bit establecido en which, XkbGetVirtualMods actualiza la definición correspondiente del modificador virtual en el array server->vmods de xkb. El parámetro xkb debe ser un puntero a una descripción de teclado Xkb válida. Si tiene éxito, XkbGetVirtualMods devuelve Success.

Nombres y Máscaras de Modificadores Virtuales

En todas las funciones de Xkb, varias funciones tienen un parámetro que es una máscara que representa las opciones de modificadores virtuales. En cada caso, el i-ésimo bit (0 relativa) de la máscara representa el i-ésimo modificador virtual.

Para establecer el nombre de un modificador virtual, use XkbSetNames, usando XkbVirtualModNamesMask en which y el nombre en el argumento xkb; para recuperar los nombres de los indicadores, use XkbGetNames.

Si el mapa server no se ha asignado en el parámetro xkb, XkbGetVirtualMods lo asigna e inicializa antes de obtener las vinculaciones de modificadores virtuales.

Si el servidor no tiene una versión compatible de Xkb, o la extensión Xkb no se ha inicializado correctamente, XkbGetVirtualMods devuelve BadMatch. Cualquier error en la asignación provoca que XkbGetVirtualMods devuelva BadAlloc.

VALORES DE RETORNO

Success
La función XkbGetVirtualMods devuelve Success cuando actualiza correctamente la definición correspondiente del modificador virtual en el array server->vmods de xkb.

ESTRUCTURAS

La descripción completa de un teclado Xkb se proporciona mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado para Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de claves del servidor */
   XkbClientMapPtr    map;          /* mapa de claves del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de pantalla X. El campo flags es privado para la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede devolver el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en la XkbDescRec se muestran en la Tabla 1.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadMatch
No había una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera

NOMBRE

XkbGetVirtualMods - Obtener los modificadores virtuales para un tipo de clave.

SINOPSIS

#include <X11/extensions/XKBparse.h>

unsigned int XkbGetVirtualMods (Display *display, unsigned int affect);

DESCRIPCIÓN

XkbGetVirtualMods consulta el servidor X para obtener los modificadores virtuales que son asignados a las teclas que afectan a los grupos y niveles especificados por el argumento affect.

El argumento display identifica la conexión con el servidor X.

El argumento affect indica los grupos y niveles que deben ser considerados. Puede ser una combinación de las siguientes mascaras:

  • XkbGroupActiveMask: Considera el grupo activo.
  • XkbGroupAllMask: Considera todos los grupos.
  • XkbLevelActiveMask: Considera el nivel activo.
  • XkbLevelAllMask: Considera todos los niveles.

Por ejemplo, para obtener los modificadores virtuales para el grupo activo y todos los niveles, se usaría XkbGroupActiveMask | XkbLevelAllMask.

VALOR DE RETORNO

Devuelve un entero sin signo de 32 bits que representa los modificadores virtuales. Cada bit en el entero corresponde a un modificador virtual específico. Si ocurre un error, se devuelve 0.

DIAGNÓSTICOS

Esta función no proporciona diagnósticos específicos. En caso de error, el comportamiento dependerá de la implementación subyacente de XKB.
