XkbResizeDeviceButtonActions(3) FUNCIONES XKB XkbResizeDeviceButtonActions(3)

NOMBRE

XkbResizeDeviceButtonActions - Asigna espacio adicional para las acciones de los botones en una estructura XkbDeviceInfoRec

SINOPSIS

Status XkbResizeDeviceButtonActions (XkbDeviceInfoPtr device_info, unsigned int new_total);

ARGUMENTOS

device_info
estructura en la que asignar acciones de botones
new_total
nuevo número total de acciones de botones necesarias

DESCRIPCIÓN

XkbResizeDeviceButtonActions reasigna espacio, si es necesario, para asegurar que haya lugar para un total de new_total acciones de botones en la estructura device_info. Las nuevas entradas que se asignen se pondrán a cero. Si tiene éxito, XkbResizeDeviceButtonActions devuelve Success. Si new_total es cero, se eliminan todas las acciones de botones, device_info->num_btns se establece en cero, y device_info->btn_acts se establece en NULL. Si device_info no es válido o new_total es mayor que 255, se devuelve BadValue. Si ocurre un error de asignación de memoria, se devuelve BadAlloc.

Para liberar una estructura XkbDeviceInfoRec, use XkbFreeDeviceInfo.

ESTRUCTURAS

La información sobre los dispositivos de la Extensión de Entrada X se transfiere entre un programa cliente y la extensión Xkb en una estructura XkbDeviceInfoRec:

    typedef struct {
        char *               name;          /* nombre del dispositivo */
        Atom                 type;          /* nombre de la clase de dispositivos */
        unsigned short       device_spec;   /* dispositivo de interés */
        Bool                 has_own_state; /* True=>este dispositivo tiene su propio estado */
        unsigned short       supported;     /* bits que indican capacidades soportadas */
        unsigned short       unsupported;   /* bits que indican capacidades no soportadas */
        unsigned short       num_btns;      /* número de entradas en btn_acts */
        XkbAction *          btn_acts;      /* acciones de botones */
        unsigned short       sz_leds;       /* número total de entradas en el vector LEDs */
        unsigned short       num_leds;      /* número de entradas válidas en el vector LEDs */
        unsigned short       dflt_kbd_fb;   /* ID de la extensión de entrada del indicador por defecto (teclado principal) */
        unsigned short       dflt_led_fb;   /* ID de la extensión de entrada de la retroalimentación del indicador por defecto */
        XkbDeviceLedInfoPtr  leds;          /* descripciones de LEDs */
    } XkbDeviceInfoRec, *XkbDeviceInfoPtr;

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango
