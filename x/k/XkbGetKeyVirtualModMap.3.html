XkbGetKeyVirtualModMap(3)

Paquete: libx11

Licencias: MIT AND X11

XkbGetKeyVirtualModMap(3) FUNCIONES XKB XkbGetKeyVirtualModMap(3)

NOMBRE

XkbGetKeyVirtualModMap - Obtiene el mapa de modificadores virtuales (el array vmodmap) para un subconjunto de las teclas de una descripción de teclado

SINOPSIS

Status XkbGetKeyVirtualModMap (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor
first
código de tecla de la primera tecla a obtener
num
número de teclas para las que se desean mapas de modificadores virtuales
xkb
descripción Xkb donde se colocarán los resultados

DESCRIPCION

XkbGetKeyVirutalModmap envía una solicitud al servidor para obtener los mapeos de modificadores virtuales para num teclas del teclado comenzando con la tecla first. Espera una respuesta y devuelve los mapeos de modificadores virtuales en el array server->vmodmap de xkb. Si tiene éxito, XkbGetKeyVirtualModMap devuelve Success. El parámetro xkb debe ser un puntero a una descripción de teclado Xkb válida.

Si el mapa server en el parámetro xkb no ha sido asignado, XkbGetKeyVirtualModMap lo asigna e inicializa antes de obtener los mapeos de modificadores virtuales.

Si el servidor no tiene una versión compatible de Xkb, o la extensión Xkb no ha sido inicializada correctamente, XkbGetKeyVirtualModMap devuelve BadMatch. Si num es menor que 1 o mayor que XkbMaxKeyCount, XkbGetKeyVirtualModMap devuelve BadValue. Si ocurre algún error de asignación, XkbGetKeyVirtualModMap devuelve BadAlloc.

VALORES DE RETORNO

Success
La función XkbGetKeyVirutalModmap devuelve Success tras una respuesta exitosa del servidor para obtener los mapeos de modificadores virtuales para num teclas del teclado comenzando con la tecla first.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadMatch
No se encontró una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
BadValue
Un argumento está fuera de rango
