NOMBRE

XkbLookupKeySym - Encuentra el símbolo asociado con una tecla para un estado particular

SINOPSIS

Bool XkbLookupKeySym (Display *dpy, KeyCode key, unsigned int state, unsigned int *mods_rtrn, KeySym *sym_rtrn);

ARGUMENTOS

dpy
conexión al servidor X
key
tecla para la cual se buscarán los símbolos
state
estado para el cual se buscará el símbolo
mods_rtrn
rellenado con los modificadores consumidos
sym_rtrn
rellenado con el símbolo asociado a la tecla + estado

DESCRIPCIÓN

XkbLookupKeySym es el equivalente de la función principal XLookupKeySym. Para el teclado principal, dada una keycode key y un estado Xkb state, XkbLookupKeySym devuelve el símbolo asociado con la tecla en sym_rtrn y la lista de modificadores que aún deben aplicarse en mods_rtrn. El parámetro state es el estado de un evento KeyPress o KeyRelease. XkbLookupKeySym devuelve True si tiene éxito.
