XkbAddDeviceLedInfo(3) FUNCIONES XKB XkbAddDeviceLedInfo(3)

NOMBRE

XkbAddDeviceLedInfo - Inicializa una estructura XkbDeviceLedInfoRec

SINOPSIS

XkbDeviceLedInfoPtr XkbAddDeviceLedInfo (XkbDeviceInfoPtr device_info, unsigned int led_class, unsigned int led_id);

ARGUMENTOS

device_info
estructura en la que añadir información del LED
led_class
clase de extensión de entrada para el dispositivo LED de interés
led_id
ID de extensión de entrada para el dispositivo LED de interés

DESCRIPCIÓN

XkbAddDeviceLedInfo primero comprueba si ya existe una entrada que coincida con led_class y led_id en el array device_info->leds. Si encuentra una entrada coincidente, devuelve un puntero a esa entrada. De lo contrario, comprueba que haya al menos una entrada vacía en device_info->leds y la extiende si no hay suficiente espacio. Luego incrementa device_info->num_leds y rellena la siguiente entrada disponible en device_info->leds con led_class y led_id.

Si tiene éxito, XkbAddDeviceLedInfo devuelve un puntero a la estructura XkbDeviceLedInfoRec que fue inicializada. Si no puede asignar suficiente almacenamiento, o si device_info apunta a una estructura XkbDeviceInfoRec inválida, o si led_class o led_id son inapropiados, XkbAddDeviceLedInfo devuelve NULL.

Para asignar espacio adicional para acciones de botones en una estructura XkbDeviceInfoRec, utilice XkbResizeDeviceButtonActions.

ESTRUCTURAS

La información sobre los dispositivos de extensión de entrada X se transfiere entre un programa cliente y la extensión Xkb en una estructura XkbDeviceInfoRec:

    typedef struct {
        char *               name;          /* nombre para el dispositivo */
        Atom                 type;          /* nombre para la clase de dispositivos */
        unsigned short       device_spec;   /* dispositivo de interés */
        Bool                 has_own_state; /* True=>este dispositivo tiene su propio estado */
        unsigned short       supported;     /* bits que indican capacidades soportadas */
        unsigned short       unsupported;   /* bits que indican capacidades no soportadas */
        unsigned short       num_btns;      /* número de entradas en btn_acts */
        XkbAction *          btn_acts;      /* acciones de botones */
        unsigned short       sz_leds;       /* número total de entradas en el vector LEDs */
        unsigned short       num_leds;      /* número de entradas válidas en el vector LEDs */
        unsigned short       dflt_kbd_fb;   /* ID de extensión de entrada del indicador por defecto (kbd principal) */
        unsigned short       dflt_led_fb;   /* ID de extensión de entrada del feedback indicador por defecto */
        XkbDeviceLedInfoPtr  leds;          /* descripciones de LEDs */
    } XkbDeviceInfoRec, *XkbDeviceInfoPtr;
    typedef struct {
        unsigned short      led_class;        /* clase para este dispositivo LED */
        unsigned short      led_id;           /* ID para este dispositivo LED */
        unsigned int        phys_indicators;  /* bits para qué LEDs están físicamente presentes */
        unsigned int        maps_present;     /* bits para qué LEDs tienen mapas en maps */
        unsigned int        names_present;    /* bits para qué LEDs están en names */
        unsigned int        state;            /* 1 bit => el LED correspondiente está encendido */
        Atom                names[XkbNumIndicators];   /* nombres para los LEDs */
        XkbIndicatorMapRec  maps;             /* mapas de indicadores para cada LED */
    } XkbDeviceLedInfoRec, *XkbDeviceLedInfoPtr;
