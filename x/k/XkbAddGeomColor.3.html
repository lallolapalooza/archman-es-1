NOMBRE

XkbAddGeomColor - Añade un nombre de color a una descripción de geometría de teclado existente

SINOPSIS

XkbColorPtr XkbAddGeomColor (XkbGeometryPtr geom, _Xconst char *spec, unsigned int pixel);

ARGUMENTOS

geom
geometría a actualizar
spec
color a añadir
pixel
color a añadir

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_* de la estructura correspondiente se incrementan en 1. Estas funciones no modifican sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debe escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de *propiedades de geometría*. Una propiedad de geometría asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar las propiedades de geometría como pistas, pero Xkb no las interpreta. Ninguna otra estructura de geometría hace referencia a las propiedades de geometría.

XkbAddGeomColor añade el nombre y el píxel de color especificados a la geometría geom especificada. La descripción de la geometría de nivel superior incluye una lista de hasta MaxColors (32) *nombres de color*. Un *nombre de color* es una cadena cuya interpretación no está especificada por Xkb, al igual que la interpretación del valor del *píxel*. Todas las demás estructuras de datos de geometría hacen referencia a los colores utilizando sus índices en esta lista global o punteros a colores en esta lista. XkbAddGeomColor devuelve NULL si alguno de los parámetros está vacío o si no ha podido asignar espacio para el color. Para asignar espacio para un número arbitrario de colores a una geometría, utilice la función XkbAllocGeomColors.

ESTRUCTURAS

    typedef struct _XkbColor {
        unsigned int    pixel;      /* color */
        char *          spec;       /* nombre del color */
    } XkbColorRec,*XkbColorPtr;
