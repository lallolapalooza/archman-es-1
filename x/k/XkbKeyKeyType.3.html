XkbKeyKeyType(3) FUNCIONES DE XKB XkbKeyKeyType(3)

NOMBRE

XkbKeyKeyType - Obtener el índice de un tipo de tecla o el puntero a un tipo de tecla

SINOPSIS

XkbKeyTypePtr XkbKeyKeyType (XkbDescPtr xkb, KeyCode keycode, int group);

ARGUMENTOS

xkb
Descripción Xkb de interés
keycode
keycode de interés
group
índice del grupo

DESCRIPCIÓN

XkbKeyKeyType devuelve un puntero al tipo de tecla en el vector types del mapa del cliente en xkb correspondiente al keycode y al índice de group dados.

ESTRUCTURAS

typedef struct {                             /* Key Type */
	XkbModsRec              mods;           /* modificadores utilizados para calcular el nivel de mayúsculas */
	unsigned char           num_levels;     /* # total de niveles de mayúsculas, no modificar directamente */
	unsigned char           map_count;      /* # entradas en el mapa, preservar (si no es NULL) */
	XkbKTMapEntryPtr        map;            /* vector de modificadores para cada nivel de mayúsculas */
	XkbModsPtr              preserve;       /* modificadores a preservar para la entrada de mapa correspondiente */
	Atom                    name;           /* nombre del tipo de tecla */
	Atom *                  level_names;    /* array de nombres de cada nivel de mayúsculas */
} XkbKeyTypeRec, *XkbKeyTypePtr;
