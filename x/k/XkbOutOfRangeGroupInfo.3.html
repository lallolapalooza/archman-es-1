XkbOutOfRangeGroupInfo(3)

Paquete: libx11

Licencias: MIT AND X11

XkbOutOfRangeGroupInfo(3) FUNCIONES DE XKB XkbOutOfRangeGroupInfo(3)

NOMBRE

XkbOutOfRangeGroupInfo - Devuelve solo la información de procesamiento fuera de rango del campo group_info de una estructura XkbSymMapRec

SINOPSIS

unsigned char XkbOutOfRangeGroupInfo (unsigned char grp_inf);

ARGUMENTOS

grp_inf
Descripción Xkb de interés

DESCRIPCIÓN

XkbOutOfRangeGroupInfo devuelve solo la información de procesamiento fuera de rango del campo group_info de una estructura XkbSymMapRec.

El campo group_info de una XkbSymMapRec es un valor codificado que contiene el número de grupos de símbolos enlazados a la tecla, así como la especificación del tratamiento de los grupos fuera de rango. Es legal que una tecla tenga cero grupos, en cuyo caso también tiene cero símbolos y todos los eventos de esa tecla producen NoSymbol. Para obtener el número de grupos de símbolos enlazados a la tecla, use XkbKeyNumGroups. Para cambiar el número de grupos enlazados a una tecla, use XkbChangeTypesOfKey. Para obtener una máscara que determine el tratamiento de los grupos fuera de rango, use XkbKeyGroupInfo y XkbOutOfRangeGroupInfo.

Los controles del teclado contienen un campo groups_wrap que especifica el manejo de grupos ilegales a nivel global. Es decir, cuando el usuario realiza una acción que provoca que el grupo efectivo salga del rango legal, el campo groups_wrap especifica cómo normalizar el grupo de teclado efectivo a un grupo que sea legal para el teclado en su conjunto, pero no hay garantía de que el grupo normalizado esté dentro del rango de grupos legales para ninguna tecla individual. El campo group_info por tecla especifica cómo una tecla trata un grupo efectivo legal si la tecla no tiene un tipo especificado para el grupo en cuestión. Por ejemplo, la tecla Enter normalmente solo tiene un grupo definido. Si el usuario realiza una acción que provoca que el grupo global del teclado cambie a Grupo2, el campo group_info para la tecla Enter describe cómo manejar esta situación.

Los grupos fuera de rango para teclas individuales se mapean a un grupo legal utilizando las mismas opciones que se utilizan para el grupo general del teclado. El tipo particular de mapeo utilizado se controla mediante los bits establecidos en el indicador group_info, como se muestra en la Tabla 1.

Tabla 1 Normalización de Rango group_info
Bits establecidos en group_info Método de normalización
XkbRedirectIntoRange XkbRedirectIntoRange
XkbClampIntoRange XkbClampIntoRange
ninguno de los anteriores XkbWrapIntoRange

ESTRUCTURAS

La estructura KeySymMapRec se define de la siguiente manera:

    #define XkbNumKbdGroups             4
    #define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
    typedef struct {                    /* map to keysyms for a single keycode */
        unsigned char       kt_index[XkbNumKbdGroups];  /* key type index for each group */
        unsigned char       group_info; /* # of groups and out of range group handling */
        unsigned char       width;      /* max # of shift levels for key */
        unsigned short      offset;     /* index to keysym table in syms array */
} XkbSymMapRec, *XkbSymMapPtr;
La estructura XkbControlsRec se define de la siguiente manera:
    #define XkbMaxLegalKeyCode     255
    #define XkbPerKeyBitArraySize  ((XkbMaxLegalKeyCode+1)/8)
    typedef struct {
        unsigned char   mk_dflt_btn;      /* default button for keyboard driven mouse */
        unsigned char   num_groups;       /* number of keyboard groups */
        unsigned char   groups_wrap;      /* how to wrap out-of-bounds groups */
        XkbModsRec      internal;         /* defines server internal modifiers */
        XkbModsRec      ignore_lock;      /* modifiers to ignore when checking for grab */
        unsigned int    enabled_ctrls;    /* 1 bit => corresponding boolean control enabled */
        unsigned short  repeat_delay;     /* ms delay until first repeat */
        unsigned short  repeat_interval;  /* ms delay between repeats */
        unsigned short  slow_keys_delay;  /* ms minimum time key must be down to be ok */
        unsigned short  debounce_delay;   /* ms delay before key reactivated */
        unsigned short  mk_delay;         /* ms delay to second mouse motion event */
        unsigned short  mk_interval;      /* ms delay between repeat mouse events */
        unsigned short  mk_time_to_max;   /* # intervals until constant mouse move */
        unsigned short  mk_max_speed;     /* multiplier for maximum mouse speed */
        short           mk_curve;         /* determines mouse move curve type */
        unsigned short  ax_options;       /* 1 bit => Access X option enabled */
        unsigned short  ax_timeout;       /* seconds until Access X disabled */
        unsigned short  axt_opts_mask;    /* 1 bit => options to reset on Access X timeout */
        unsigned short  axt_opts_values;  /* 1 bit => turn option on, 0=> off */
        unsigned int    axt_ctrls_mask;   /* which bits in enabled_ctrls to modify */
        unsigned int    axt_ctrls_values; /* values for new bits in enabled_ctrls */
        unsigned char   per_key_repeat[XkbPerKeyBitArraySize];  /* per key auto repeat */
     } XkbControlsRec, *XkbControlsPtr;
