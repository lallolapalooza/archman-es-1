XkbAddGeomOverlayRow(3) FUNCIONES DE XKB XkbAddGeomOverlayRow(3)

NOMBRE

XkbAddGeomOverlayRow - Añadir una fila a un overlay existente

SINOPSIS

XkbOverlayRowPtr XkbAddGeomOverlayRow (XkbOverlayPtr overlay, XkbRowPtr row_under, int sz_keys);

ARGUMENTOS

overlay
overlay a actualizar
row_under
fila a superponer en la sección de overlays de la sección subyacente
sz_keys
número de teclas a reservar en la fila

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no cambian sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debe escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades geométricas. Una propiedad geométrica asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden utilizar las propiedades geométricas como pistas, pero Xkb no las interpreta. Ninguna otra estructura geométrica hace referencia a propiedades geométricas.

XkbAddGeomOverlayRow añade una fila al overlay. La nueva fila contiene espacio para sz_keys teclas. Si row_under especifica una fila que no existe en la sección subyacente, XkbAddGeomOverlayRow devuelve NULL y no modifica el overlay. XkbAddGeomOverlayRow devuelve NULL si alguno de los parámetros está vacío o si no ha podido asignar espacio para el overlay.

ESTRUCTURAS

    typedef struct _XkbOverlayRow {
        unsigned short      row_under;    /* índice en la fila bajo esta fila de overlay */
        unsigned short      num_keys;     /* número de teclas en el array de teclas */
        unsigned short      sz_keys;      /* tamaño del array de teclas */
        XkbOverlayKeyPtr    keys;         /* array de teclas en la fila de overlay */
    } XkbOverlayRowRec,*XkbOverlayRowPtr;
