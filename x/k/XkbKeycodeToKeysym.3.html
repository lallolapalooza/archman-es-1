XkbKeycodeToKeysym(3) FUNCIONES XKB XkbKeycodeToKeysym(3)

NOMBRE

XkbKeycodeToKeysym - Encuentra el keysym enlazado a una tecla particular en un grupo y nivel de turno especificados

SINOPSIS

KeySym XkbKeycodeToKeysym (Display *dpy, KeyCode kc, unsigned int group, unsigned int level);

ARGUMENTOS

dpy
conexión al servidor X
kc
tecla de interés
group
grupo de interés
level
nivel de turno de interés

DESCRIPCIÓN

XkbKeycodeToKeysym devuelve el keysym enlazado a un grupo y nivel de turno particulares para una tecla determinada en el teclado principal. Si kc no es un código de tecla válido para el teclado principal, o si group o level están fuera de rango para la tecla especificada, XkbKeycodeToKeysym devuelve NoSymbol.
