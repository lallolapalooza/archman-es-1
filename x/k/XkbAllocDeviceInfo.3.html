XkbAllocDeviceInfo(3)

Paquete: libx11

Licencias: MIT AND X11

XkbAllocDeviceInfo(3) FUNCIONES XKB XkbAllocDeviceInfo(3)

NOMBRE

XkbAllocDeviceInfo - Obtener una estructura XkbDeviceInfoRec

SINOPSIS

XkbDeviceInfoPtr XkbAllocDeviceInfo (unsigned int device_spec, unsigned int n_buttons, unsigned int sz_leds);

ARGUMENTOS

device_spec
ID del dispositivo con el que se utilizará la estructura
n_buttons
número de acciones de botones para las que asignar espacio
sz_leds
número de feedbacks LED para los que asignar espacio

DESCRIPCIÓN

XkbAllocDeviceInfo asigna espacio para una estructura XkbDeviceInfoRec e inicializa el campo device_spec de esa estructura con el ID del dispositivo especificado por device_spec. Si n_buttons no es cero, se enlazan n_buttons XkbActions en la estructura XkbDeviceInfoRec y se inicializan a cero. Si sz_leds no es cero, también se asignan sz_leds estructuras XkbDeviceLedInfoRec y se enlazan en la estructura XkbDeviceInfoRec. Si solicita que se asignen estructuras XkbDeviceLedInfoRec usando esta solicitud, debe inicializarlas explícitamente, utilizando XkbAddDeviceLedInfo(3).

ESTRUCTURAS

La información sobre los dispositivos de la Extensión de Entrada de X se transfiere entre un programa cliente y la extensión Xkb en una estructura XkbDeviceInfoRec:

    typedef struct {
        char *               name;          /* nombre para el dispositivo */
        Atom                 type;          /* nombre para la clase de dispositivos */
        unsigned short       device_spec;   /* dispositivo de interés */
        Bool                 has_own_state; /* True=>este dispositivo tiene su propio estado */
        unsigned short       supported;     /* bits que indican capacidades soportadas */
        unsigned short       unsupported;   /* bits que indican capacidades no soportadas */
        unsigned short       num_btns;      /* número de entradas en btn_acts */
        XkbAction *          btn_acts;      /* acciones de botones */
        unsigned short       sz_leds;       /* número total de entradas en el vector LEDs */
        unsigned short       num_leds;      /* número de entradas válidas en el vector LEDs */
        unsigned short       dflt_kbd_fb;   /* ID de extensión de entrada del indicador por defecto (kbd principal) */
        unsigned short       dflt_led_fb;   /* ID de extensión de entrada del feedback indicador por defecto */
        XkbDeviceLedInfoPtr  leds;          /* descripciones de LEDs */
    } XkbDeviceInfoRec, *XkbDeviceInfoPtr;
    typedef struct {
        unsigned short      led_class;        /* clase para este dispositivo LED */
        unsigned short      led_id;           /* ID para este dispositivo LED */
        unsigned int        phys_indicators;  /* bits para qué LEDs están físicamente presentes */
        unsigned int        maps_present;     /* bits para qué LEDs tienen mapas en maps */
        unsigned int        names_present;    /* bits para qué LEDs están en names */
        unsigned int        state;            /* 1 bit => el LED correspondiente está encendido */
        Atom                names[XkbNumIndicators];   /* nombres para los LEDs */
        XkbIndicatorMapRec  maps;             /* mapas indicadores para cada LED */
    } XkbDeviceLedInfoRec, *XkbDeviceLedInfoPtr;
