Paquete: libx11

Licencias: MIT AND X11

XkbGetDeviceInfo(3) FUNCIONES XKB XkbGetDeviceInfo(3)

NOMBRE

XkbGetDeviceInfo - Determina si el servidor X permite el acceso Xkb a capacidades particulares de dispositivos de entrada distintos del teclado principal de X, o para determinar el estado de los mapas de indicadores, nombres de indicadores o acciones de botones en un dispositivo de extensión que no sea KeyClass.

SINOPSIS

XkbDeviceInfoPtr XkbGetDeviceInfo (Display *dpy, unsigned int which, unsigned int device_spec, unsigned int ind_class, unsigned int ind_id);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara que indica la información a devolver
device_spec
ID del dispositivo, o XkbUseCoreKbd
ind_class
clase de retroalimentación para solicitudes de indicadores
ind_id
ID de retroalimentación para solicitudes de indicadores

DESCRIPCIÓN

Para determinar si el servidor X permite el acceso Xkb a capacidades particulares de dispositivos de entrada distintos del teclado principal de X, o para determinar el estado de los mapas de indicadores, nombres de indicadores o acciones de botones en un dispositivo de extensión que no sea KeyClass, use XkbGetDeviceInfo.

XkbGetDeviceInfo devuelve información sobre el dispositivo de entrada especificado por device_spec. A diferencia del parámetro device_spec de la mayoría de las funciones Xkb, device_spec no necesita ser un dispositivo de teclado. Sin embargo, debe indicar el teclado principal o un dispositivo válido de la Extensión de Entrada de X.

El parámetro which es una máscara que especifica información opcional a devolver. Es una OR inclusiva de uno o más de los valores de la Tabla 1 y hace que el XkbDeviceInfoRec devuelto contenga valores para los campos correspondientes especificados en la tabla.

El XkbDeviceInfoRec devuelto por XkbGetDeviceInfo siempre tiene valores para name (puede ser una cadena nula, ""), type, supported, unsupported, has_own_state, dflt_kbd_fd, y dflt_kbd_fb. Otros campos se completan según lo especificado por which.

Al regresar, el campo supported se establecerá en la OR inclusiva de cero o más bits de la Tabla 1; cada bit establecido indica una característica opcional del dispositivo de extensión Xkb soportada por la implementación del servidor, y un cliente puede modificar el comportamiento asociado.

Si el bit XkbButtonActionsMask está establecido en which, el XkbDeviceInfoRec devuelto tendrá las acciones de botones (campo btn_acts) completadas para todos los botones.

Si which incluye uno de los bits en XkbXI_IndicatorsMask, la clase de retroalimentación de los indicadores debe especificarse en ind_class, y el ID de retroalimentación de los indicadores debe especificarse en ind_id. Si la solicitud no incluye ninguno de los bits en XkbXI_IndicatorsMask, los parámetros ind_class y ind_id se ignoran. La clase y el ID se pueden obtener a través de la solicitud de extensión del dispositivo de entrada XListInputDevices.

Si alguno de los bits XkbXI_IndicatorsMask está establecido en which, el XkbDeviceInfoRec devuelto tendrá completadas las porciones de la estructura leds correspondientes a la retroalimentación del indicador identificada por ind_class e ind_id. El vector leds del XkbDeviceInfoRec se asigna si es necesario y se completan sz_leds y num_leds. Los campos led_class, led_id y phys_indicators de la entrada leds correspondiente a ind_class e ind_id se completan siempre. Si which contiene XkbXI_IndicatorNamesMask, se devuelven los campos names_present y names de la estructura leds correspondiente a ind_class e ind_id. Si which contiene XkbXI_IndicatorStateMask, se actualiza el campo state correspondiente. Si which contiene XkbXI_IndicatorMapsMask, se actualizan los campos maps_present y maps.

Xkb proporciona funciones de conveniencia para solicitar subconjuntos de la información disponible a través de XkbGetDeviceInfo. Estas funciones de conveniencia reflejan algunos de los bits de máscara. Todas las funciones toman un XkbDeviceInfoPtr como argumento de entrada y operan sobre el dispositivo de Extensión de Entrada de X especificado por el campo device_spec de la estructura. Solo se actualizan las partes de la estructura indicadas en la descripción de la función. El XkbDeviceInfoRec utilizado en la llamada a la función se puede obtener llamando a XkbGetDeviceInfo o se puede asignar llamando a XkbAllocDeviceInfo.

ESTRUCTURAS

La información sobre los dispositivos de Extensión de Entrada de X se transfiere entre un programa cliente y la extensión Xkb en una estructura XkbDeviceInfoRec:

typedef struct {
    char *               name;          /* nombre para el dispositivo */
    Atom                 type;          /* nombre para la clase de dispositivos */
    unsigned short       device_spec;   /* dispositivo de interés */
    Bool                 has_own_state; /* True=>este dispositivo tiene su propio estado */
    unsigned short       supported;     /* bits que indican capacidades soportadas */
    unsigned short       unsupported;   /* bits que indican capacidades no soportadas */
    unsigned short       num_btns;      /* número de entradas en btn_acts */
    XkbAction *          btn_acts;      /* acciones de botones */
    unsigned short       sz_leds;       /* número total de entradas en el vector LEDs */
    unsigned short       num_leds;      /* número de entradas válidas en el vector LEDs */
    unsigned short       dflt_kbd_fb;   /* ID de la extensión de entrada del indicador predeterminado (teclado principal) */
    unsigned short       dflt_led_fb;   /* ID de la extensión de entrada del indicador predeterminado */
    XkbDeviceLedInfoPtr  leds;          /* descripciones de LED */
} XkbDeviceInfoRec, *XkbDeviceInfoPtr;
