NOMBRE

XkbAllocGeomDoodads - Asigna "doodads" que son globales para la geometría de un teclado

SINOPSIS

Status XkbAllocGeomDoodads (XkbGeometryPtr geom, int num_needed);

ARGUMENTOS

geom
geometría para la cual se deben asignar los "doodads"
num_needed
número de "doodads" nuevos requeridos

DESCRIPCION

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Usa estas funciones para crear o modificar geometrías de teclado. Ten en cuenta que estas funciones meramente asignan espacio para el(los) nuevo(s) elemento(s), y depende de ti completar los valores explícitamente en tu código. Estas funciones de asignación incrementan sz_* pero nunca tocan num_* (a menos que haya un fallo de asignación, en cuyo caso reinician tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomDoodads asigna num_needed "doodads" y los agrega a la geometría especificada geom. No se realiza ninguna inicialización de los "doodads".

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango
