NOMBRE

XkbGetGeometry - Carga una geometría de teclado si ya tienes la descripción del teclado

SINOPSIS

Status XkbGetGeometry (Display *dpy, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
xkb
descripción del teclado que contiene el ID del teclado y en la que se cargará la geometría

DESCRIPCIÓN

Puedes cargar una geometría de teclado como parte de la descripción del teclado devuelta por XkbGetKeyboard. Sin embargo, si una descripción de teclado se cargó previamente, puedes obtener la geometría llamando a XkbGetGeometry. En este caso, la geometría devuelta es la asociada con el teclado cuyo ID de dispositivo está contenido en la descripción del teclado.

XkbGetGeometry puede devolver errores BadValue, BadImplementation, BadName, BadAlloc, o Success si tiene éxito.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadImplementation
Respuesta inválida del servidor
BadLength
La longitud de una solicitud es más corta o más larga de lo necesario para contener mínimamente los argumentos
BadName
No existe una fuente o color con el nombre especificado
BadValue
Un argumento está fuera de rango
