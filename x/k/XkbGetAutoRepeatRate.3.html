XkbGetAutoRepeatRate(3) FUNCIONES XKB XkbGetAutoRepeatRate(3)

NOMBRE

XkbGetAutoRepeatRate - Obtiene los atributos actuales del control RepeatKeys para un dispositivo de teclado

SINOPSIS

Bool XkbGetAutoRepeatRate (Display *display, unsigned int device_spec, unsigned int *timeout_rtrn, unsigned int *interval_rtrn);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo deseado, o XkbUseCoreKbd
timeout_rtrn
rellenado con el retardo de repetición inicial, ms
interval_rtrn
rellenado con el retardo de repetición subsiguiente, ms

DESCRIPCIÓN

El protocolo principal solo permite controlar si el teclado completo o teclas individuales deben repetirse automáticamente cuando se mantienen presionadas. RepeatKeys es un control booleano que extiende esta capacidad al añadir control sobre el retardo hasta que una tecla comience a repetirse y la velocidad a la que se repite. RepeatKeys está acoplado al control de repetición automática principal: cuando RepeatKeys está habilitado o deshabilitado, la repetición automática principal está habilitada o deshabilitada y viceversa.

Las teclas con repetición automática se controlan mediante dos atributos. El primero, timeout, es el retardo después de la pulsación inicial de una tecla de repetición automática y el primer evento de repetición generado. El segundo, interval, es el retardo entre todos los eventos de repetición subsiguientes generados. Al igual que con todos los controles booleanos, la configuración de los atributos que determinan cómo funciona el control no habilita automáticamente el control en su conjunto.

XkbGetAutoRepeatRate consulta al servidor los valores actuales de los atributos de control RepeatControls, rellena timeout_rtrn y interval_rtrn con ellos y devuelve True. Si una versión compatible de la extensión Xkb no está disponible en el servidor, XkbGetAutoRepeatRate devuelve False.

VALORES DE RETORNO

True
La función XkbGetAutoRepeatRate devuelve True si una versión compatible de la extensión Xkb está disponible en el servidor.
False
La función XkbGetAutoRepeatRate devuelve False si una versión compatible de la extensión Xkb no está disponible en el servidor.
