XkbChangeTypesOfKey(3) FUNCIONES DE XKB XkbChangeTypesOfKey(3)

NOMBRE

XkbChangeTypesOfKey - Cambiar el número de grupos y los tipos vinculados a una tecla

SINOPSIS

Estado XkbChangeTypesOfKey (XkbDescPtr xkb, int tecla, int n_grupos, unsigned int grupos, int *nuevos_tipos_entrada, XkbMapChangesPtr p_cambios);

ARGUMENTOS

xkb
descripción del teclado a modificar
tecla
código de tecla de interés
n_grupos
nuevo número de grupos para la tecla
grupos
máscara que indica los grupos a cambiar
nuevos_tipos_entrada
índices para los nuevos grupos especificados en grupos
p_cambios
registra los cambios realizados en xkb

DESCRIPCIÓN

XkbChangeTypesOfKey reasigna los símbolos y acciones vinculados a la tecla, si es necesario, e inicializa cualquier símbolo o acción nueva a NoSymbol o NoAction, según corresponda. Si el parámetro p_cambios no es NULL, XkbChangeTypesOfKey añade XkbKeySymsMask al campo de cambios de p_cambios y modifica los campos first_key_sym y num_key_syms de p_cambios para incluir la tecla que se cambió. Consulte STRUCTURE para obtener más información sobre la estructura XkbMapChangesPtr. Si tiene éxito, XkbChangeTypesOfKey devuelve Success.

El parámetro n_grupos especifica el nuevo número de grupos para la tecla. El parámetro grupos es una máscara que especifica los grupos para los que se proporcionan nuevos tipos y es una OR inclusiva de bits de las siguientes máscaras: XkbGroup1Mask, XkbGroup2Mask, XkbGroup3Mask y XkbGroup4Mask.

El parámetro nuevos_tipos_entrada es un array de enteros de longitud n_grupos. Cada entrada representa el tipo a usar para el grupo asociado y es un índice en xkb->map->types. El array nuevos_tipos_entrada se indexa por el índice del grupo; si n_grupos es cuatro y grupos solo tiene Group1Mask y Group3Mask establecidos, nuevos_tipos_entrada se ve así:

    nuevos_tipos_entrada[0] = tipo para Grupo1
    nuevos_tipos_entrada[1] = ignorado
    nuevos_tipos_entrada[2] = tipo para Grupo3
    nuevos_tipos_entrada[3] = ignorado
Como conveniencia, Xkb proporciona las siguientes constantes para usarlas como índices de los grupos:
Tabla 1 Constantes de Índice de Grupo
Nombre de la constante Valor
XkbGroup1Index 0
XkbGroup2Index 1
XkbGroup3Index 2
XkbGroup4Index 3

Si la extensión Xkb no se ha inicializado correctamente, XkbChangeTypesOfKey devuelve BadAccess. Si el parámetro xkb no es válido (es decir, es NULL o no contiene un mapa de cliente válido), XkbChangeTypesOfKey devuelve BadMatch. Si la tecla no es un código de tecla válido, n_grupos es mayor que XkbNumKbdGroups, o la máscara grupos no contiene ninguno de los bits de máscara de grupo válidos, XkbChangeTypesOfKey devuelve BadValue. Si es necesario redimensionar los arrays de símbolos de tecla o acciones de tecla y ocurren errores de asignación, XkbChangeTypesOfKey devuelve BadAlloc.

ESTRUCTURAS

Utilice la estructura XkbMapChangesRec para identificar y rastrear modificaciones parciales de los componentes del mapeo y para reducir la cantidad de tráfico entre el servidor y los clientes.

typedef struct _XkbMapChanges {
    unsigned short   cambiado;            /* identifica componentes válidos en la estructura */
    KeyCode          codigo_tecla_min;       /* código de tecla de menor número para el dispositivo */
    KeyCode          codigo_tecla_max;       /* código de tecla de mayor número para el dispositivo */
    unsigned char    tipo_primero;         /* índice del primer tipo de tecla modificado */
    unsigned char    num_tipos;          /* # de tipos modificados */
    KeyCode          simbolo_tecla_primero;      /* primera tecla cuyo simbolo_tecla_map cambió */
    unsigned char    num_simbolos_tecla;      /* # de entradas simbolo_tecla_map cambiadas */
    KeyCode          accion_tecla_primero;      /* primera tecla cuya entrada de acciones cambió */
    unsigned char    num_acciones_tecla;       /* # de entradas de acciones de tecla cambiadas */
    KeyCode          comportamiento_tecla_primero; /* primera tecla cuyos comportamientos cambiaron */
    unsigned char    num_comportamientos_tecla;  /* # de entradas de comportamiento cambiadas */
    KeyCode          explicit_tecla_primero; /* primera tecla cuya entrada explícita cambió */
    unsigned char    num_explicit_tecla;   /* # de entradas explícitas cambiadas */
    KeyCode          modmap_tecla_primero;   /* primera tecla cuyo modmap cambió */
    unsigned char    num_teclas_modmap;    /* # de entradas modmap cambiadas */
    KeyCode          vmodmap_tecla_primero;  /* primera tecla cuyo vmodmap cambió */
    unsigned char    num_teclas_vmodmap;   /* # de entradas vmodmap cambiadas */
    unsigned char    relleno1;               /* reservado */
    unsigned short   vmods;              /* máscara que indica qué vmods cambiaron */
} XkbMapChangesRec,*XkbMapChangesPtr;

DIAGNÓSTICOS

BadAccess
La extensión Xkb no se ha inicializado correctamente
BadAlloc
No se ha podido asignar almacenamiento
BadMatch
No había una versión compatible de Xkb disponible en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
BadValue
Un argumento está fuera de rango
