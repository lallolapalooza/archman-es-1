XkbSetPtrActionY(3)

Paquete: libx11

Licencias: MIT AND X11

XkbSetPtrActionY(3) FUNCIONES DE XKB XkbSetPtrActionY(3)

NOMBRE

XkbSetPtrActionY - Establece los campos high_YYY y low_YYY de act a partir del valor entero con signo y

SINOPSIS

void XkbSetPtrActionY (XkbPtrAction act, int y);

ARGUMENTOS

act
acción en la que establecer Y
y
nuevo valor a establecer

DESCRIPCIÓN

Las acciones asociadas con la estructura XkbPtrAction mueven el puntero cuando las teclas se presionan y sueltan.

Si el control MouseKeys no está habilitado, los eventos KeyPress y KeyRelease se tratan como si la acción fuera XkbSA_NoAction.

Si el control MouseKeys está habilitado, una acción del servidor de tipo XkbSA_MovePtr instruye al servidor para que genere eventos core MotionNotify en lugar del evento KeyPress habitual, y el evento KeyRelease correspondiente deshabilita cualquier temporizador de teclas del ratón que se haya creado como resultado del manejo de la acción XkbSA_MovePtr.

El campo type de la estructura XkbPtrAction es siempre XkbSA_MovePtr.

El campo flags es una OR inclusiva a nivel de bits de las máscaras que se muestran en la Tabla 1.

Tabla 1 Tipos de Acción del Puntero
Tipo de Acción Significado
XkbSA_NoAcceleration Si no está establecido, y el control MouseKeysAccel está habilitado, el KeyPress inicia un temporizador de teclas del ratón para esta tecla; cada vez que expira el temporizador, el cursor se mueve.
XkbSA_MoveAbsoluteX Si está establecido, la porción X de la estructura especifica la nueva coordenada X del puntero. De lo contrario, la porción X se añade a la coordenada X actual del puntero para determinar la nueva coordenada X del puntero.
XkbSA_MoveAbsoluteY Si está establecido, la porción Y de la estructura especifica la nueva coordenada Y del puntero. De lo contrario, la porción Y se añade a la coordenada Y actual del puntero para determinar la nueva coordenada Y del puntero.

Cada una de las coordenadas X e Y de la estructura XkbPtrAction se compone de dos valores con signo de 16 bits, es decir, la coordenada X se compone de high_XXX y low_XXX, y de forma similar para la coordenada Y. Xkb proporciona las siguientes macros para convertir entre un entero con signo y dos valores con signo de 16 bits en las estructuras XkbPtrAction.

ESTRUCTURAS

    typedef struct _XkbPtrAction {
        unsigned char    type;         /* XkbSA_MovePtr */
        unsigned char    flags;        /* determina el tipo de movimiento del puntero */
        unsigned char    high_XXX;     /* coordenada x, bits altos */
        unsigned char    low_XXX;      /* coordenada x, bits bajos */
        unsigned char    high_YYY;     /* coordenada y, bits altos */
        unsigned char    low_YYY;      /* coordenada y, bits bajos */
    } XkbPtrAction;
