XkbFreeKeyboard(3) FUNCIONES XKB XkbFreeKeyboard(3)

NOMBRE

XkbFreeKeyboard - Destruye un XkbDescRec completo o solo algunos de sus miembros

SINOPSIS

void XkbFreeKeyboard (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTOS

xkb
descripción del teclado con los componentes a liberar
which
máscara que selecciona los componentes a liberar
free_all
Verdadero => libera todos los componentes y xkb

DESCRIPCIÓN

XkbFreeKeyboard libera los componentes de xkb especificados por which y establece los valores correspondientes a NULL. Si free_all es Verdadero, XkbFreeKeyboard libera cada componente no-NULL de xkb y luego libera la propia estructura xkb.

Si kbd es NULL, no se realiza ninguna operación.
