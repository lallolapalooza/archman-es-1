NOMBRE

XkbChangeNames - Cambia nombres simbólicos en el servidor

SINOPSIS

Bool XkbChangeNames (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara de nombres o componentes del mapa a actualizar
xkb
descripción del teclado a actualizar

DESCRIPCIÓN

XkbChangeNames proporciona un método más flexible para cambiar los nombres simbólicos que XkbSetNames y requiere el uso de una estructura XkbNameChangesRec.

XkbChangeNames copia cualquier nombre especificado por changes desde la descripción del teclado, xkb, al servidor X especificado por dpy. XkbChangeNames aborta y devuelve False si se especifican nombres de tipo ilegales o nombres de nivel de cambio de tipo por medio de changes.

Para cambiar los nombres simbólicos en el servidor, primero modifica una copia local de la descripción del teclado y luego usa XkbSetNames o, para ahorrar tráfico de red, usa una estructura XkbNameChangesRec y llama a XkbChangeNames para descargar los cambios al servidor. XkbSetNames y XkbChangeNames pueden generar errores BadAlloc, BadAtom, BadLength, BadMatch y BadImplementation.

ESTRUCTURAS

XkbNameChangesRec permite a las aplicaciones identificar modificaciones pequeñas en los nombres simbólicos y reduce efectivamente la cantidad de tráfico enviado al servidor:

    typedef struct _XkbNameChanges {
        unsigned int   changed;            /* componentes de nombre que han cambiado */
        unsigned char  first_type;         /* primer tipo de tecla con un nombre nuevo */
        unsigned char  num_types;          /* número de tipos con nombres nuevos */
        unsigned char  first_lvl;          /* primer tipo de tecla con nombres de nivel nuevos */
        unsigned char  num_lvls;           /* número de tipos de tecla con nombres de nivel nuevos */
        unsigned char  num_aliases;        /* si los alias de teclas cambiaron, número total de alias de teclas */
        unsigned char  num_rg;             /* si los grupos de radio cambiaron, número total de grupos de radio */
        unsigned char  first_key;          /* primera tecla con un nombre nuevo */
        unsigned char  num_keys;           /* número de teclas con nombres nuevos */
        unsigned short changed_vmods;      /* máscara de modificadores virtuales cuyos nombres han cambiado */
        unsigned long  changed_indicators; /* máscara de indicadores cuyos nombres fueron cambiados */
        unsigned char  changed_groups;     /* máscara de grupos cuyos nombres fueron cambiados */
    } XkbNameChangesRec, *XkbNameChangesPtr

El campo changed especifica los componentes del nombre que han cambiado y es la unión inclusiva bit a bit de los bits de máscara de nombres válidos definidos en la Tabla 1. El resto de los campos en la estructura especifican los rangos que han cambiado para los diversos tipos de nombres simbólicos, como se muestra en la Tabla 2.

Xkb proporciona varias funciones que trabajan con nombres simbólicos. Cada una de estas funciones utiliza una máscara para especificar campos individuales de las estructuras descritas anteriormente. Estas máscaras y sus relaciones con los campos en una descripción de teclado se muestran en la Tabla 1.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadAtom
Un nombre no es ni un Átomo válido ni None
BadImplementation
Respuesta inválida del servidor
BadLength
La longitud de una solicitud es más corta o más larga de lo necesario para contener mínimamente los argumentos
BadMatch
No había una versión compatible de Xkb disponible en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
