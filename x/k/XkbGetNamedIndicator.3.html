XkbGetNamedIndicator(3)

Paquete: libx11

Licencias: MIT AND X11

XkbGetNamedIndicator(3) FUNCIONES XKB XkbGetNamedIndicator(3)

NOMBRE

XkbGetNamedIndicator - Busca el mapa del indicador y otra información para un indicador por nombre

SINOPSIS

Bool XkbGetNamedDeviceIndicator (Display *dpy, unsigned int dev_spec, unsigned int led_class, unsigned int led_id, Atom name, int *ndx_rtrn, Bool *state_rtrn, XkbIndicatorMapPtr map_rtrn, Bool *real_rtrn);

Bool XkbGetNamedIndicator (Display *dpy, Atom name, int *ndx_rtrn, Bool *state_rtrn, XkbIndicatorMapPtr map_rtrn, Bool *real_rtrn);

ARGUMENTOS

dpy
conexión al servidor X
dev_spec
ID del dispositivo de teclado, o XkbUseCoreKbd
led_class
clase de retroalimentación, o XkbDfltXIClass
led_id
ID de retroalimentación, o XkbDfltXIId
name
nombre del indicador a recuperar
ndx_rtrn
rellenado con el índice del indicador recuperado
state_rtrn
rellenado con el estado actual del indicador recuperado
map_rtrn
rellenado con el mapeo del indicador recuperado
real_rtrn
rellenado con True si el indicador con nombre es real (físico)

DESCRIPCIÓN

Xkb también permite a las aplicaciones referirse a indicadores por nombre. Utilice XkbGetNames para obtener los nombres de los indicadores. El uso de nombres elimina la necesidad de codificar valores de máscaras de bits para teclados específicos. Por ejemplo, en lugar de usar constantes específicas del proveedor como la máscara WSKBLed_ScrollLock en estaciones de trabajo Digital o XLED_SCROLL_LOCK en estaciones de trabajo Sun, puede usar XkbGetNamedDeviceIndicator para buscar información sobre el indicador llamado "Scroll Lock".

Si el dispositivo especificado por device_spec tiene un indicador llamado name, XkbGetNamedDeviceIndicator devuelve True y rellena el resto de los parámetros con información sobre el indicador. De lo contrario, XkbGetNamedDeviceIndicator devuelve False.

El campo ndx_rtrn devuelve el índice basado en cero del indicador con nombre. Este índice es la posición de bit a usar en cualquier llamada a función que requiera una máscara de bits de indicadores, así como el índice del indicador en la matriz XkbIndicatorRec de mapas de indicadores. state_rtrn devuelve el estado actual del indicador con nombre (True = activado, False = desactivado). map_rtrn devuelve el mapa del indicador para el indicador con nombre. Además, si el indicador está mapeado a un LED físico, el parámetro real_rtrn se establece en True.

Cada uno de los argumentos " _rtrn " es opcional; puede pasar NULL para cualquier argumento " _rtrn " que no necesite.

XkbGetNamedIndicator es una función de conveniencia que llama a XkbGetNamedDeviceIndicator con un device_spec de XkbUseCoreKbd, una led_class de XkbDfltXIClass y un led_id de XkbDfltXIId. Devuelve el valor de retorno de XkbGetNamedDeviceIndicator.

VALORES DE RETORNO

True
Las funciones XkbGetNamedIndicator y XkbGetNamedDeviceIndicator devuelven True si el dispositivo especificado por device_spec tiene un indicador llamado name.
False
Las funciones XkbGetNamedIndicator y XkbGetNamedDeviceIndicator devuelven False si el dispositivo especificado por device_spec no tiene un indicador llamado name.
