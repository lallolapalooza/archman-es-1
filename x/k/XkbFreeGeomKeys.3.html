XkbFreeGeomKeys(3) FUNCIONES XKB XkbFreeGeomKeys(3)

NOMBRE

XkbFreeGeomKeys - Liberar teclas de geometría

SINOPSIS

void XkbFreeGeomKeys (XkbRowPtr row, int first, int count, Bool free_all);

ARGUMENTOS

row
fila en la que se liberarán las teclas
first
primera tecla a liberar
count
número de teclas a liberar
free_all
Verdadero => se liberan todas las teclas

DESCRIPCIÓN

Si free_all es Verdadero, se liberan todas las teclas independientemente del valor de first o count. De lo contrario, se liberan count teclas comenzando por la especificada por first.
