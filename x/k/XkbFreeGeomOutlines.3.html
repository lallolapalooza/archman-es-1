NOMBRE

XkbFreeGeomOutlines - Liberar contornos de geometría

SINOPSIS

void XkbFreeGeomOutlines (XkbShapePtr shape, int first, int count, Bool free_all);

ARGUMENTOS

shape
forma en la que se liberarán los contornos
first
primer contorno a liberar
count
número de contornos a liberar
free_all
True => se liberan todos los contornos

DESCRIPCIÓN

Si free_all es True, se liberan todos los contornos independientemente del valor de first o count. De lo contrario, se liberan count contornos comenzando desde el especificado por first.
