XkbFreeServerMap(3) FUNCIONES XKB XkbFreeServerMap(3)

NOMBRE

XkbFreeServerMap - Libera la memoria utilizada por el miembro del servidor de una estructura XkbDescRec

SINOPSIS

void XkbFreeServerMap (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTOS

xkb
descripción del teclado que contiene el mapa del servidor a liberar
which
máscara que identifica los componentes del mapa a liberar
free_all
True => libera todos los componentes del mapa del servidor y el propio servidor

DESCRIPCIÓN

La función XkbFreeServerMap libera los componentes especificados del mapa del servidor en la estructura XkbDescRec especificada por el parámetro xkb y establece los valores de los componentes de la estructura correspondientes a NULL. El parámetro which especifica una combinación de las máscaras del mapa del servidor y es una operación OR a nivel de bits inclusiva de las máscaras enumeradas en la Tabla 1. Si free_all es True, which se ignora y XkbFreeServerMap libera cada componente de la estructura no NULL en el mapa del servidor, libera la estructura XkbServerMapRec referenciada por el miembro server del parámetro xkb y establece el miembro server a NULL.

Tabla 1 Máscaras de XkbAllocServerMap
Máscara Efecto
XkbExplicitComponentsMask Los campos min_key_code y max_key_code del parámetro xkb se utilizan para asignar el campo explicit del mapa del servidor.
XkbKeyActionsMask Los campos min_key_code y max_key_code del parámetro xkb se utilizan para asignar el campo key_acts del mapa del servidor. El parámetro count_acts se utiliza para asignar el campo acts del mapa del servidor.
XkbKeyBehaviorsMask Los campos min_key_code y max_key_code del parámetro xkb se utilizan para asignar el campo behaviors del mapa del servidor.
XkbVirtualModMapMask Los campos min_key_code y max_key_code del parámetro xkb se utilizan para asignar el campo vmodmap del mapa del servidor.

ESTRUCTURAS

La descripción completa de un teclado Xkb se da por una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado de Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de claves del servidor */
   XkbClientMapPtr    map;          /* mapa de claves del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de pantalla X. El campo flags es privado de la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode más bajo y más alto que puede ser devuelto por el teclado.

Cada componente de la estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en la XkbDescRec se muestran en la Tabla 2.

Tabla 2 Bits de Máscara para XkbDescRec
Bit de Máscara Campo XkbDescRec Valor
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Todos los Campos (0x7f)

El mapa del servidor Xkb contiene la información que el servidor necesita para interpretar los eventos de teclado y es del tipo XkbServerMapRec:

#define XkbNumVirtualMods          16
typedef struct {                    /* Mapa del Servidor */
    unsigned short    num_acts;     /* # de entradas ocupadas en acts */
    unsigned short    size_acts;    /* # de entradas en acts */
    XkbAction *       acts;         /* tablas 2d lineales de acciones de clave, 1 por keycode */
    XkbBehavior *     behaviors;    /* comportamientos de clave, 1 por keycode */
    unsigned short *  key_acts;     /* índice en acts, 1 por keycode */
    unsigned char *   explicit;     /* sobrescrituras explícitas de la reasignación principal, 1 por clave */
    unsigned char     vmods[XkbNumVirtualMods]; /* mods reales enlazados a mods virtuales */
    unsigned short *  vmodmap;      /* mods virtuales enlazados a clave, 1 por keycode*/
} XkbServerMapRec, *XkbServerMapPtr;
