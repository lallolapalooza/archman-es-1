XkbFreeDeviceInfo(3) FUNCIONES XKB XkbFreeDeviceInfo(3)

NOMBRE

XkbFreeDeviceInfo - Liberar una estructura XkbDeviceInfoRec

SINOPSIS

void XkbFreeDeviceInfo (XkbDeviceInfoPtr device_info, unsigned int which, Bool free_all);

ARGUMENTOS

device_info
puntero a XkbDeviceInfoRec en la que liberar elementos
which
máscara de componentes de device_info para liberar
free_all
True => liberar todo, incluyendo device_info

DESCRIPCION

Si free_all es True, XkbFreeDeviceInfo libera todos los componentes de device_info y la propia estructura XkbDeviceInfoRec apuntada por device_info. Si free_all es False, el valor de which determina qué subcomponentes se liberan. which es una combinación OR de uno o más de los valores de la Tabla 1. Si which contiene XkbXI_ButtonActionsMask, se liberan todas las acciones de botones asociadas con device_info, device_info->btn_acts se establece a NULL, y device_info->num_btns se establece a cero. Si which contiene todos los bits en XkbXI_IndicatorsMask, se liberan todas las estructuras XkbDeviceLedInfoRec asociadas con device_info, device_info->leds se establece a NULL, y device_info->sz_leds y device_info->num_leds se establecen a cero. Si which contiene XkbXI_IndicatorMapsMask, se limpian todos los mapas de indicadores asociados con device_info, pero se conservan el número de LEDs y las propias estructuras de leds. Si which contiene XkbXI_IndicatorNamesMask, se limpian todos los nombres de indicadores asociados con device_info, pero se conservan el número de LEDs y las propias estructuras de leds. Si which contiene XkbXI_IndicatorStateMask, el estado del indicador asociado con los leds de device_info se establece a ceros, pero se conservan el número de LEDs y las propias estructuras de leds.

ESTRUCTURAS

La información sobre los dispositivos de extensión de entrada X se transfiere entre un programa cliente y la extensión Xkb en una estructura XkbDeviceInfoRec:

typedef struct {
    char *               name;          /* nombre del dispositivo */
    Atom                 type;          /* nombre de la clase de dispositivos */
    unsigned short       device_spec;   /* dispositivo de interés */
    Bool                 has_own_state; /* True=>este dispositivo tiene su propio estado */
    unsigned short       supported;     /* bits que indican las capacidades soportadas */
    unsigned short       unsupported;   /* bits que indican las capacidades no soportadas */
    unsigned short       num_btns;      /* número de entradas en btn_acts */
    XkbAction *          btn_acts;      /* acciones de botones */
    unsigned short       sz_leds;       /* número total de entradas en el vector de LEDs */
    unsigned short       num_leds;      /* número de entradas válidas en el vector de LEDs */
    unsigned short       dflt_kbd_fb;   /* ID de extensión de entrada del indicador por defecto (teclado principal) */
    unsigned short       dflt_led_fb;   /* ID de extensión de entrada de la retroalimentación del indicador por defecto */
    XkbDeviceLedInfoPtr  leds;          /* descripciones de LEDs */
} XkbDeviceInfoRec, *XkbDeviceInfoPtr;
typedef struct {
    unsigned short      led_class;        /* clase para este dispositivo LED */
    unsigned short      led_id;           /* ID para este dispositivo LED */
    unsigned int        phys_indicators;  /* bits para qué LEDs están físicamente presentes */
    unsigned int        maps_present;     /* bits para qué LEDs tienen mapas en maps */
    unsigned int        names_present;    /* bits para qué LEDs están en names */
    unsigned int        state;            /* 1 bit => el LED correspondiente está encendido */
    Atom                names[XkbNumIndicators];   /* nombres para los LEDs */
    XkbIndicatorMapRec  maps;             /* mapas de indicadores para cada LED */
} XkbDeviceLedInfoRec, *XkbDeviceLedInfoPtr;
