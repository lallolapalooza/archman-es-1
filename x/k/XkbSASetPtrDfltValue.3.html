XkbSASetPtrDfltValue(3) FUNCIONES DE XKB XkbSASetPtrDfltValue(3)

NOMBRE

XkbSASetPtrDfltValue - Establece el campo valueXXX de act a partir de val

SINOPSIS

void XkbSASetPtrDfltValue (XkbAction act, int val);

ARGUMENTOS

act
acción en la que establecer valueXXX
val
valor a establecer en valueXXX

DESCRIPCIÓN

Las acciones asociadas a la estructura XkbPtrDfltAction cambian el atributo mk_dflt_btn del control MouseKeys.

Si el control MouseKeys no está habilitado, los eventos KeyPress y KeyRelease se tratan como si la acción fuera XkbSA_NoAction. De lo contrario, esta acción cambia el atributo mk_dflt_btn del control MouseKeys.

El campo type de la estructura XkbPtrDfltAction siempre debe ser XkbSA_SetPtrDflt.

El campo flags se compone de la OR inclusiva a nivel de bits de los valores que se muestran en la Tabla 1 (actualmente solo hay un valor definido).

Tabla 1 Flags por defecto del puntero
Flag Significado
XkbSA_DfltBtnAbsolute Si se establece, el campo value representa un botón de puntero absoluto. De lo contrario, el campo value representa la cantidad a sumar al botón por defecto actual.

El campo affect especifica qué cambios se producen como resultado de esta acción. El único valor válido para el campo affect es XkbSA_AffectDfltBtn.

El campo valueXXX es un carácter con signo que representa el nuevo valor del botón para el atributo mk_dflt_btn del control MouseKeys. Si XkbSA_DfltBtnAbsolute está establecido en flags, valueXXX especifica el botón a usar; de lo contrario, valueXXX especifica la cantidad a sumar al botón por defecto actual. En cualquier caso, las elecciones de botones ilegales se envuelven de nuevo en el rango. Xkb proporciona macros para convertir entre los valores enteros y los de carácter con signo en las estructuras XkbPtrDfltAction.

ESTRUCTURAS

    typedef struct _XkbPtrDfltAction {
        unsigned char    type;      /* XkbSA_SetPtrDflt */
        unsigned char    flags;     /* controla el número del botón del puntero */
        unsigned char    affect;    /* XkbSA_AffectDfltBtn */
        char             valueXXX;  /* nuevo miembro del botón por defecto */
    } XkbPtrDfltAction;
