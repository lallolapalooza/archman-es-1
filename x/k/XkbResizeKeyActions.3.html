XkbResizeKeyActions(3) FUNCIONES XKB XkbResizeKeyActions(3)

NOMBRE

XkbResizeKeyActions - Cambia el número de acciones asociadas a una tecla

SINOPSIS

XkbAction * XkbResizeKeyActions (XkbDescRec *xkb, int key, int needed);

ARGUMENTOS

xkb
descripción del teclado a modificar
key
código de la tecla a modificar
needed
nuevo número de acciones requeridas

DESCRIPCIÓN

El parámetro xkb apunta a la descripción del teclado que contiene la key cuyo número de acciones se va a cambiar. El parámetro key es el código de la tecla a modificar, y needed especifica el nuevo número de acciones requeridas para la tecla.

XkbResizeKeyActions reserva el espacio necesario para las acciones y devuelve un puntero al inicio del nuevo array que contiene las acciones. Puede cambiar los campos acts, num_acts, y size_acts de xkb->server si es necesario reasignar el array acts.

Si needed es mayor que el número actual de keysyms para la tecla, XkbResizeKeyActions inicializa todas las nuevas acciones en el array a NoAction.

Dado que el número de acciones necesarias por una tecla se calcula normalmente como ancho * número de grupos, y XkbResizeKeyActions no modifica ni el ancho ni el número de grupos para la tecla, existe una discrepancia al regresar de XkbResizeKeyActions entre el espacio asignado para las acciones y el número requerido. Las entradas no utilizadas en la lista de acciones devueltas por XkbResizeKeyActions no se conservan en llamadas futuras a ninguna de las funciones de edición de mapas, por lo que debes actualizar las acciones de la tecla (que actualiza el ancho y el número de grupos para la tecla) antes de llamar a otra función asignadora. Una llamada a XkbChangeTypesOfKey actualiza estos.

Si ocurren errores de asignación al redimensionar el número de acciones asociadas a la tecla, XkbResizeKeyActions devuelve NULL.

VER TAMBIÉN

XkbChangeTypesOfKey(3), XkbResizeKeySyms(3)

NOTAS

Un cambio en el número de acciones asociadas a una tecla debe ir acompañado de un cambio en el número de símbolos asociados a una tecla. Consulta XkbResizeKeySyms para más información sobre cómo cambiar el número de símbolos asociados a una tecla.
