XkbAddGeomOverlay(3) FUNCIONES XKB XkbAddGeomOverlay(3)

NOMBRE

XkbAddGeomOverlay - Añadir una superposición a una sección

SINOPSIS

XkbOverlayPtr XkbAddGeomOverlay (XkbSectionPtr seccion, Atom nombre, int tam_filas);

ARGUMENTOS

seccion
sección a la que se añadirá una superposición
nombre
nombre de la superposición
tam_filas
número de filas a reservar en la superposición

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no cambian sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debe escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades geométricas. Una propiedad geométrica asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden utilizar las propiedades geométricas como indicadores, pero Xkb no las interpreta. Ninguna otra estructura geométrica hace referencia a propiedades geométricas.

XkbAddGeomOverlay añade una superposición con el nombre especificado a la sección especificada. La nueva superposición se crea con espacio asignado para tam_filas filas. Si ya existe una superposición con el nombre nombre en la sección, se devuelve un puntero a la superposición existente. XkbAddGeomOverlay devuelve NULL si alguno de los parámetros está vacío o si no ha podido asignar espacio para la superposición. Para asignar espacio para un número arbitrario de superposiciones a una sección, utilice la función XkbAllocGeomOverlay.

ESTRUCTURAS

    typedef struct _XkbOverlayRec {
        Atom                  name;            /* nombre de la superposición */
        XkbSectionPtr         section_under;   /* la sección debajo de esta superposición */
        unsigned short        num_rows;        /* número de filas en el array de filas */
        unsigned short        sz_rows;         /* tamaño del array de filas */
        XkbOverlayRowPtr      rows;            /* array de filas en la superposición */
        XkbBoundsPtr          bounds;          /* caja delimitadora para la superposición */
    } XkbOverlayRec,*XkbOverlayPtr;
