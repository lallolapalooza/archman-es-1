XkbSetServerInternalMods(3) FUNCIONES DE XKB XkbSetServerInternalMods(3)

NOMBRE

XkbSetServerInternalMods - Establece los modificadores que son consumidos por el servidor antes de que los eventos se entreguen al cliente

SINOPSIS

Bool XkbSetServerInternalMods (Display *display, unsigned int device_spec, unsigned int affect_real, unsigned int real_values, unsigned int affect_virtual, unsigned int virtual_values);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo, o XkbUseCoreKbd
affect_real
máscara de modificadores reales afectados por esta llamada
real_values
valores para los modificadores reales afectados (1=>establecer, 0=>desestablecer)
affect_virtual
máscara de modificadores virtuales afectados por esta llamada
virtual_values
valores para los modificadores virtuales afectados (1=>establecer, 0=>desestablecer)

DESCRIPCIÓN

El protocolo principal no proporciona ningún medio para evitar que un modificador se informe en los eventos enviados a los clientes; Xkb, sin embargo, hace esto posible a través del control InternalMods. Especifica los modificadores que deben ser consumidos por el servidor y no informados a los clientes. Cuando se presiona una tecla y se informa un modificador cuyo bit está establecido en el control InternalMods al servidor, el servidor utiliza el modificador al determinar las acciones a aplicar para la tecla. Luego, el servidor borra el bit, por lo que en realidad no se informa al cliente. Además, los modificadores especificados en el control InternalMods no se utilizan para determinar los grabs y no se utilizan para calcular el estado de compatibilidad del protocolo principal.

Manipule el control InternalMods a través del campo internal en la estructura XkbControlsRec, utilizando XkbSetControls y XkbGetControls. Alternativamente, use XkbSetServerInternalMods.

XkbSetServerInternalMods envía una solicitud al servidor para cambiar los modificadores internos consumidos por el servidor. affect_real y real_values son máscaras de bits de modificadores reales que indican qué modificadores reales se agregarán y eliminarán del control de modificadores internos del servidor. Los modificadores seleccionados tanto por affect_real como por real_values se agregan al control de modificadores internos del servidor; aquellos seleccionados por affect_real pero no por real_values se eliminan de la máscara de modificadores internos del servidor. Los valores válidos para affect_real y real_values consisten en cualquier combinación de los ocho bits de modificadores principales: ShiftMask, LockMask, ControlMask, Mod1Mask - Mod5Mask. affect_virtual y virtual_values son máscaras de bits de modificadores virtuales que indican qué modificadores virtuales se agregarán y eliminarán del control de modificadores internos del servidor. Los modificadores seleccionados tanto por affect_virtual como por virtual_values se agregan al control de modificadores internos del servidor; aquellos seleccionados por affect_virtual pero no por virtual_values se eliminan del control de modificadores internos del servidor. Consulte a continuación una discusión sobre las máscaras de modificadores virtuales a utilizar en affect_virtual y virtual_values. XkbSetServerInternalMods no espera una respuesta del servidor. Devuelve True si la solicitud se envió y False en caso contrario.

Los modificadores virtuales se nombran convirtiendo su nombre de cadena a un átomo X y almacenando el átomo en la matriz names.vmods en una estructura XkbDescRec. La posición de un nombre de átomo en la matriz names.vmods define la posición del bit utilizada para representar el modificador virtual y también el índice utilizado al acceder a la información del modificador virtual en las matrices: el nombre en la entrada i-ésima (relativa a 0) de names.vmods es el modificador virtual i-ésimo, representado por la máscara (1<<i). En todo Xkb, varias funciones tienen un parámetro que es una máscara que representa las opciones de modificadores virtuales. En cada caso, el bit i-ésimo (relativo a 0) de la máscara representa el modificador virtual i-ésimo.

Para establecer el nombre de un modificador virtual, use XkbSetNames, utilizando XkbVirtualModNamesMask en which y el nombre en el argumento xkb; para recuperar los nombres de los indicadores, use XkbGetNames.

ESTRUCTURAS

La descripción completa de un teclado Xkb se proporciona mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb descritos en la Figura 1.1.

typedef struct {
    struct _XDisplay * display;      /* conexión al servidor X */
    unsigned short     flags;        /* privado para Xkb, no modificar */
    unsigned short     device_spec;  /* dispositivo de interés */
    KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
    KeyCode            max_key_code; /* keycode máximo para el dispositivo */
    XkbControlsPtr     ctrls;        /* controles */
    XkbServerMapPtr    server;       /* mapa de teclas del servidor */
    XkbClientMapPtr    map;          /* mapa de teclas del cliente */
    XkbIndicatorPtr    indicators;   /* mapa de indicadores */
    XkbNamesPtr        names;        /* nombres para todos los componentes */
    XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
    XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;

El campo display apunta a una estructura de pantalla X. El campo flags es privado de la biblioteca: modificar flags puede dar resultados impredecibles. El campo device_spec especifica el identificador del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode más bajo y más alto que puede ser devuelto por el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe manipularse de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en la XkbDescRec se muestran en la Tabla 1.

    NAME

    XkbSetServerInternalMods - Establece los modificadores internos del servidor.

    SYNOPSIS

    #include <X11/extensions/XKBcomp.h>

    void XkbSetServerInternalMods(Display *display, XkbSrvIntMods srv_mods);

    ARGUMENTS

    display
    Display: Especifica la conexión con el servidor X.
    srv_mods
    XkbSrvIntMods: Especifica los modificadores internos del servidor que se van a establecer.

    DESCRIPTION

    XkbSetServerInternalMods establece los modificadores internos del servidor para el servidor X especificado por display. Los modificadores internos del servidor son un conjunto de modificadores que el servidor X utiliza internamente para ciertas operaciones, como el manejo de la disposición del teclado y la gestión de eventos.

    El argumento srv_mods es un valor de tipo XkbSrvIntMods, que es un máscara de bits. Los bits disponibles en esta máscara son:

    • XkbStateUseSymGroup: Indica que el grupo de símbolos debe usarse para determinar el estado del modificador.
    • XkbStateUseLockGroup: Indica que el grupo de bloqueo debe usarse para determinar el estado del modificador.
    • XkbStateUseModifierMapping: Indica que el mapeo de modificadores debe usarse para determinar el estado del modificador.

    Por ejemplo, para establecer los modificadores internos del servidor para usar el grupo de símbolos y el mapeo de modificadores, puede llamar a la función de la siguiente manera:

    XkbSetServerInternalMods(display, XkbStateUseSymGroup | XkbStateUseModifierMapping);

    STRUCTURES

    La estructura XkbSrvIntMods es un tipo de máscara de bits definido en <X11/extensions/XKBcomp.h>. Los bits disponibles son:

    • XkbStateUseSymGroup
    • XkbStateUseLockGroup
    • XkbStateUseModifierMapping
