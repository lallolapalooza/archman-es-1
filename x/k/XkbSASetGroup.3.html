XkbSASetGroup(3) FUNCIONES XKB XkbSASetGroup(3)

NOMBRE

XkbSASetGroup - Establece el campo group_XXX de act a partir del índice de grupo grp

SINOPSIS

void XkbSASetGroup (XkbAction act, int grp);

ARGUMENTOS

act
acción de la que se establecerá el grupo
grp
índice de grupo a establecer en group_XXX

DESCRIPCIÓN

XkbSASetGroup establece el campo group_XXX de act a partir del índice de grupo grp.

ESTRUCTURA

Las acciones asociadas con la estructura XkbGroupAction cambian el estado del grupo actual cuando se presionan y sueltan las teclas:

    typedef struct _XkbGroupAction {
        unsigned char    type;       /* XkbSA_{Set|Latch|Lock}Group */
        unsigned char    flags;      /* con type, controla el efecto en los grupos */
        char             group_XXX;  /* representa un índice de grupo o un delta */
    } XkbGroupAction;
