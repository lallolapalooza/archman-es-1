XkbGetUpdatedMap(3) FUNCIONES XKB XkbGetUpdatedMap(3)

NOMBRE

XkbGetUpdatedMap - Actualizar la información del mapa del cliente o del servidor en una descripción de teclado existente

SINOPSIS

Status XkbGetUpdatedMap (Display *display, unsigned int which, XkbDescPtr xkb);

ARGUMENTOS

display
conexión al servidor X
which
máscara que selecciona los subcomponentes a poblar
xkb
descripción del teclado a actualizar

DESCRIPCIÓN

El parámetro which es un OR inclusivo a nivel de bits de las máscaras de la Tabla 1. Si los componentes necesarios de la estructura xkb no están ya asignados, XkbGetUpdatedMap los asigna. XkbGetUpdatedMap obtiene la información solicitada para el dispositivo especificado en el XkbDescRec pasado en el parámetro xkb.

XkbGetUpdatedMap es síncrono; consulta al servidor la información deseada, espera una respuesta y luego devuelve el control. Si tiene éxito, XkbGetUpdatedMap devuelve Success. Si no tiene éxito, XkbGetUpdatedMap devuelve uno de los siguientes: BadAlloc (no se pudo asignar un componente en la estructura XkbDescRec), BadValue (algún bit de la máscara en which no está definido), BadImplementation (no hay una versión compatible de la extensión Xkb disponible en el servidor o la respuesta del servidor fue inválida).

VALORES DE RETORNO

Éxito
La función XkbGetUpdatedMap devuelve Éxito si se recibe una respuesta a la consulta del servidor para la información deseada.

ESTRUCTURAS

La descripción completa de un teclado Xkb se proporciona mediante un XkbDescRec. Las estructuras de componentes en el XkbDescRec representan los principales componentes Xkb.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado para Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de claves del servidor */
   XkbClientMapPtr    map;          /* mapa de claves del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de visualización X. El campo flags es privado de la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede ser devuelto por el teclado.

Cada componente de la estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos del XkbDescRec se muestran en la Tabla 2.
