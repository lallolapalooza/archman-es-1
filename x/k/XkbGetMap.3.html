XkbGetMap(3) FUNCIONES XKB XkbGetMap(3)

NOMBRE

XkbGetMap - Asigna una estructura XkbDescRec y la rellena con el mapa de cliente y el mapa del servidor del teclado del servidor

SINOPSIS

XkbDescPtr XkbGetMap (Display *display, unsigned int which, unsigned int device_spec);

ARGUMENTOS

display
conexión al servidor X
which
máscara que selecciona subcomponentes a rellenar
device_spec
especificación del dispositivo, o XkbUseCoreKbd

DESCRIPCIÓN

Xkb proporciona dos funciones para obtener los componentes del mapa del teclado del servidor. La primera función, XkbGetMap, asigna una estructura XkbDescRec, recupera componentes del mapa del servidor y los almacena en la estructura XkbDescRec que acaba de asignar. La segunda función, XkbGetUpdatedMap, recupera componentes del mapa del servidor y los almacena en una estructura XkbDescRec que ha sido previamente asignada.

Para asignar una estructura XkbDescRec y rellenarla con el mapa de cliente y el mapa del servidor del teclado del servidor, use XkbGetMap. XkbGetMap es similar a XkbGetKeyboard, pero se usa solo para obtener la dirección de una estructura XkbDescRec que está rellena con componentes del mapa del teclado. Permite un control más fino sobre qué subestructuras de los componentes del mapa del teclado se van a rellenar. XkbGetKeyboard siempre devuelve componentes completamente rellenos, mientras que a XkbGetMap se le puede indicar que devuelva un componente parcialmente relleno.

La máscara which es una OR inclusiva a nivel de bits de las máscaras definidas en la Tabla 14.1. Solo aquellas porciones del mapa del servidor del teclado y los mapas de cliente del teclado que se especifican en which se asignan y rellenan.

Además de asignar y obtener el mapa del servidor y el mapa del cliente, XkbGetMap también establece los campos device_spec, min_key_code y max_key_code de la descripción del teclado.

XkbGetMap es síncrono; consulta al servidor la información deseada, espera una respuesta y luego devuelve. Si tiene éxito, XkbGetMap devuelve un puntero a la estructura XkbDescRec que asignó. Si no tiene éxito, XkbGetMap devuelve NULL. Cuando no tiene éxito, también se genera uno de los siguientes errores de protocolo: BadAlloc (no se pudo asignar la estructura XkbDescRec), BadValue (algunos bits de máscara en which no están definidos) o BadImplementation (no hay una versión compatible de la extensión Xkb disponible en el servidor). Para liberar los datos devueltos, use XkbFreeKeyboard.

Xkb también proporciona funciones de conveniencia para obtener definiciones de componentes parciales del servidor. Estas funciones se especifican en la columna "funciones de conveniencia" de la Tabla 1. Consulte las secciones enumeradas en la tabla para obtener más información sobre estas funciones.

Los tipos de teclas, los mapas de símbolos y las acciones están todos interrelacionados: los cambios en uno requieren cambios en los otros. Las funciones de conveniencia facilitan la edición de estos componentes y el manejo de las interdependencias.

ESTRUCTURAS

La descripción completa de un teclado Xkb se proporciona mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado de Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de teclas del servidor */
   XkbClientMapPtr    map;          /* mapa de teclas del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de pantalla X. El campo flags es privado de la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede ser devuelto por el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en XkbDescRec se muestran en la Tabla 2.

XkbGetMap(3)

NAME

XkbGetMap - Get keyboard mapping components

SYNOPSIS

#include <X11/extensions/Xkb.h>

XkbMapPtr XkbGetMap(Display *display,
                    XkbMapParts which,
                    XkbDescPtr xkb);

ARGUMENTS

● display: Conexión al servidor X.

● which: Componentes del mapa a recuperar.

● xkb: Descriptor del dispositivo Xkb.

DESCRIPTION

XkbGetMap recupera los componentes especificados por el argumento which del mapa del teclado asociado con la descripción del dispositivo Xkb xkb del servidor X especificado por display.

Los componentes del mapa disponibles son:

XkbKeyActionsMask
Recupera las acciones de las teclas.
XkbKeySymsMask
Recupera los símbolos de las teclas.
XkbModMapMask
Recupera el mapa de modificadores.
XkbCompatMapMask
Recupera el mapa de compatibilidad.
XkbGeometryMask
Recupera la geometría del teclado.
XkbAllMapParts
Recupera todas las partes del mapa.

La función devuelve un puntero a una estructura XkbMapPtr que contiene los componentes del mapa solicitados. Si se produce un error, devuelve NULL.

STRUCTURES

La estructura XkbMapPtr se define en <X11/extensions/Xkb.h> y contiene los siguientes campos:

typedef struct {
        XkbKeyActionBuffer actions;
        XkbKeySymsBuffer syms;
        XkbMods          modmap;
        XkbCompatMapPtr  compat;
        XkbGeometryPtr   geom;
    } XkbMapRec, *XkbMapPtr;
