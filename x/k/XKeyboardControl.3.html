XChangeKeyboardControl(3) FUNCIONES DE XLIB XChangeKeyboardControl(3)

NOMBRE

XChangeKeyboardControl, XGetKeyboardControl, XAutoRepeatOn, XAutoRepeatOff, XBell, XQueryKeymap, XKeyboardControl - manipular la configuración del teclado y la estructura de control del teclado

SINTAXIS

int XChangeKeyboardControl(Display *display, unsigned long value_mask, XKeyboardControl *values);

int XGetKeyboardControl(Display *display, XKeyboardState *values_return);

int XAutoRepeatOn(Display *display);

int XAutoRepeatOff(Display *display);

int XBell(Display *display, int percent);

int XQueryKeymap(Display *display, char keys_return[32]);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
keys_return
Devuelve un array de bytes que identifica qué teclas están presionadas. Cada bit representa una tecla del teclado.
percent
Especifica el volumen para la campana, que puede variar entre -100 y 100 inclusive.
value_mask
Especifica qué controles se van a cambiar. Esta máscara es la unión bitwise inclusiva de los bits de máscara de control válidos.
values
Especifica un valor para cada bit establecido en 1 en la máscara.
values_return
Devuelve los controles actuales del teclado en la estructura XKeyboardState especificada.

DESCRIPCIÓN

La función XChangeKeyboardControl controla las características del teclado definidas por la estructura XKeyboardControl. El argumento value_mask especifica qué valores se van a cambiar.

XChangeKeyboardControl puede generar errores BadMatch y BadValue.

La función XGetKeyboardControl devuelve los valores de control actuales para el teclado en la estructura XKeyboardState.

La función XAutoRepeatOn activa la repetición automática para el teclado en la pantalla especificada.

La función XAutoRepeatOff desactiva la repetición automática para el teclado en la pantalla especificada.

La función XBell hace sonar la campana del teclado en la pantalla especificada, si es posible. El volumen especificado es relativo al volumen base para el teclado. Si el valor del argumento percent no está en el rango de -100 a 100 inclusive, se produce un error BadValue. El volumen al que suena la campana cuando el argumento percent es no negativo es:

base - [(base * percent) / 100] + percent

El volumen al que suena la campana cuando el argumento percent es negativo es:

base + [(base * percent) / 100]

Para cambiar el volumen base de la campana, use XChangeKeyboardControl.

XBell puede generar un error BadValue.

La función XQueryKeymap devuelve un vector de bits para el estado lógico del teclado, donde cada bit establecido en 1 indica que la tecla correspondiente está actualmente presionada. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits para las teclas 8N a 8N + 7 con el bit menos significativo en el byte representando la tecla 8N.

Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente) puede ir a la zaga del estado físico si el procesamiento de eventos del dispositivo está congelado.

ESTRUCTURAS

La estructura XKeyboardControl contiene:

/* Bits de máscara para ChangeKeyboardControl */

#define KBKeyClickPercent (1L<<0)
#define KBBellPercent (1L<<1)
#define KBBellPitch (1L<<2)
#define KBBellDuration (1L<<3)
#define KBLed (1L<<4)
#define KBLedMode (1L<<5)
#define KBKey (1L<<6)
#define KBAutoRepeatMode (1L<<7) 
/* Valores */
typedef struct {
        int key_click_percent;
        int bell_percent;
        int bell_pitch;
        int bell_duration;
        int led;
        int led_mode;   /* LedModeOn, LedModeOff */
        int key;
        int auto_repeat_mode;   /* AutoRepeatModeOff, AutoRepeatModeOn,
                                AutoRepeatModeDefault */
} XKeyboardControl;

El miembro key_click_percent establece el volumen de los clics de tecla entre 0 (apagado) y 100 (alto) inclusive, si es posible. Una configuración de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

El miembro bell_percent establece el volumen base para la campana entre 0 (apagado) y 100 (alto) inclusive, si es posible. Una configuración de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_pitch establece el tono (especificado en Hz) de la campana, si es posible. Una configuración de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_duration establece la duración de la campana especificada en milisegundos, si es posible. Una configuración de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

Si se especifican tanto los miembros led_mode como led, se cambia el estado de ese LED, si es posible. El miembro led_mode se puede establecer en LedModeOn o LedModeOff. Si solo se especifica led_mode, se cambia el estado de todos los LED, si es posible. Se admiten como máximo 32 LED numerados a partir de uno. No se define ninguna interpretación estándar de los LED. Si se especifica led sin led_mode, se produce un error BadMatch.

Si se especifican tanto el modo auto_repeat_mode como la tecla, se cambia el auto_repeat_mode de esa tecla (según AutoRepeatModeOn, AutoRepeatModeOff o AutoRepeatModeDefault), si es posible. Si solo se especifica el auto_repeat_mode, se cambia el auto_repeat_mode global para todo el teclado, si es posible, y no afecta a la configuración por tecla. Si se especifica una tecla sin un auto_repeat_mode, se produce un error BadMatch. Cada tecla tiene un modo individual de si debe o no repetirse automáticamente y una configuración predeterminada para el modo. Además, existe un modo global de si la repetición automática debe estar habilitada o no y una configuración predeterminada para ese modo. Cuando el modo global es AutoRepeatModeOn, las teclas deben obedecer sus modos de repetición automática individuales. Cuando el modo global es AutoRepeatModeOff, ninguna tecla debe repetirse automáticamente. Una tecla que se repite automáticamente genera eventos KeyPress y KeyRelease alternos. Cuando una tecla se utiliza como modificador, es deseable que la tecla no se repita automáticamente, independientemente de su configuración de repetición automática.

La estructura XKeyboardState contiene:

typedef struct {
        int key_click_percent;
        int bell_percent;
        unsigned int bell_pitch, bell_duration;
        unsigned long led_mask;
        int global_auto_repeat;
        char auto_repeats[32];
} XKeyboardState;

Para los LED, el bit menos significativo de led_mask corresponde al LED uno, y cada bit establecido en 1 en led_mask indica un LED que está encendido. El miembro global_auto_repeat se puede establecer en AutoRepeatModeOn o AutoRepeatModeOff. El miembro auto_repeats es un vector de bits. Cada bit establecido en 1 indica que la repetición automática está habilitada para la tecla correspondiente. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits para las teclas 8N a 8N + 7 con el bit menos significativo en el byte representando la tecla 8N.

NAME

XKeyboardControl, XGetKeyboardControl, XSetKeyboardControl, XKeyboardState, XQueryKeymap - keyboard control

SYNTAX

typedef struct {
    int key_click_percent;
    int bell_percent;
    int bell_pitch;
    int bell_duration;
    int led_mode;
    int led_behavior;
    int global_auto_repeat;
    int [256] auto_repeat_mode;
} XKeyboardState;
Bool XGetKeyboardControl(Display *display, XKeyboardState *state_return);
int XSetKeyboardControl(Display *display, unsigned long which_fields, XKeyboardControl *values);
typedef struct {
    int key_click_percent;
    int bell_percent;
    int bell_pitch;
    int bell_duration;
    int led_mode;
    int led_behavior;
    int global_auto_repeat;
    int [256] auto_repeat_mode;
} XKeyboardControl;
Bool XQueryKeymap(Display *display, unsigned char key_map[32]);

ARGUMENTS

display
Specifies the connection to the X server.
state_return
Returns the current keyboard state.
which_fields
Specifies which controls to change.
values
Specifies the new values for the keyboard controls.
key_map
Returns the current keymap.

DESCRIPTION

The XGetKeyboardControl function retrieves the current keyboard state from the X server and returns it in state_return. The XKeyboardState structure contains information about the keyboard's auto-repeat settings, bell volume, key click volume, and LED settings.

The XSetKeyboardControl function sets keyboard controls. The which_fields argument specifies which fields in the values structure should be updated. The values structure contains the new values for the keyboard controls.

The XQueryKeymap function retrieves the current keymap from the X server and returns it in the key_map array. The key_map array is a 32-byte array where each bit corresponds to a keycode. If a bit is set, the corresponding key is currently pressed.

STRUCTURES

The XKeyboardState and XKeyboardControl structures are identical and contain the following members:

key_click_percent
Specifies the volume of the key click sound (0 to 100).
bell_percent
Specifies the volume of the bell sound (0 to 100).
bell_pitch
Specifies the pitch of the bell sound in Hz.
bell_duration
Specifies the duration of the bell sound in milliseconds.
led_mode
Specifies the mode of the LEDs (On, Off, or OnAccessibility).
led_behavior
Specifies the behavior of the LEDs when keys are pressed.
global_auto_repeat
Specifies whether auto-repeat is enabled globally (On or Off).
auto_repeat_mode
An array of 256 elements specifying the auto-repeat mode for each key (On or Off).

DIAGNOSTICS

The functions return False if an error occurs (e.g., the display is not open, or the server is unavailable). Otherwise, they return True.

The XSetKeyboardControl function returns BadValue if any of the specified values are out of range.

The XKeyboardControl structure is used to pass values to XSetKeyboardControl. The XKeyboardState structure is used to receive values from XGetKeyboardControl.

The which_fields argument is a bitmask that specifies which controls are being set. The following bits can be used:

XKB_KEY_CLICK_PERCENT
XKB_BELL_PERCENT
XKB_BELL_PITCH
XKB_BELL_DURATION
XKB_LED_MODE
XKB_LED_BEHAVIOR
XKB_GLOBAL_AUTO_REPEAT
XKB_AUTO_REPEAT_MODE

If a bit is set in which_fields, the corresponding field in the values structure is used to set the keyboard control. If a bit is not set, the corresponding field in the values structure is ignored.

The auto_repeat_mode array in XKeyboardState and XKeyboardControl is used to control the auto-repeat behavior of individual keys. Each element in the array corresponds to a keycode, and its value indicates whether auto-repeat is enabled or disabled for that key.

The XQueryKeymap function returns a 32-byte array where each bit corresponds to a keycode. If the bit is set, the key is pressed.

The XGetKeyboardControl function may fail if the X server cannot be reached or if there is an error in the display connection.

The XSetKeyboardControl function may fail if the server cannot be reached or if any of the specified values are out of range.

The XQueryKeymap function may fail if the server cannot be reached or if there is an error in the display connection.
