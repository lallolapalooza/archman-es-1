NOMBRE

XkbAllocGeomSectionDoodads - Asigna adornos específicos de una sección

SINOPSIS

Estado XkbAllocGeomSectionDoodads (XkbSectionPtr sección, int num_necesarios);

ARGUMENTOS

sección
sección para la cual se deben asignar los adornos
num_necesarios
número de adornos nuevos requeridos

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted completar los valores explícitamente en su código. Estas funciones de asignación incrementan sz_* pero nunca tocan num_* (a menos que haya un error de asignación, en cuyo caso restablecen tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomSectionDoodads asigna num_necesarios adornos y los agrega a la sección especificada. No se realiza ninguna inicialización de los adornos.

Para liberar los adornos de geometría, utilice XkbFreeGeomDoodads.

DIAGNÓSTICO

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango

VER TAMBIÉN

XkbFreeGeomDoodads(3)
