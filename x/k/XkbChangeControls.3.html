NOMBRE

XkbChangeControls - Proporciona un método flexible para actualizar los controles en un servidor para que coincidan con los de la descripción del teclado modificada

SINOPSIS

Bool XkbChangeControls (Display *dpy, XkbDescPtr xkb, XkbControlsChangesPtr changes);

ARGUMENTOS

dpy
conexión al servidor X
xkb
descripción del teclado con xkb->ctrls modificados
changes
qué partes de xkb->ctrls han cambiado

DESCRIPCIÓN

La estructura XkbControlsChangesRec permite a las aplicaciones realizar un seguimiento de las modificaciones en una estructura XkbControlsRec y, por lo tanto, reducir la cantidad de tráfico enviado al servidor. La misma estructura XkbControlsChangesRec se puede utilizar en varias modificaciones sucesivas de la misma estructura XkbControlsRec, y posteriormente se utiliza para que todos los cambios, y solo los cambios, se propaguen al servidor.

El campo changed_ctrls es una máscara que especifica qué conjuntos lógicos de datos en la estructura de controles se han modificado. En este contexto, modificado significa *establecido*, es decir, si un valor se establece al mismo valor que contenía anteriormente, aún se ha modificado y se marca como cambiado. Los valores válidos para changed_ctrls son cualquier combinación de las máscaras enumeradas en la Tabla 1 que tengan "ok" en la columna changed_ctrls. Establecer un bit implica que los campos de datos correspondientes de la columna "Campos de datos relevantes de XkbControlsRec" en la Tabla 1 se han modificado. El campo enabled_ctrls_changes especifica qué bits en el campo enabled_ctrls han cambiado. Si el número de grupos de teclado ha cambiado, el campo num_groups_changed se establece en True.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar los controles para su modificación y para habilitar y deshabilitar el control. Tenga en cuenta que se utiliza el mismo bit de máscara para especificar modificaciones generales en los parámetros utilizados para configurar el control (cuál), y para habilitar y deshabilitar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no se pueden habilitar ni deshabilitar.

NAME

XkbChangeControls - modify keyboard controls

SYNOPSIS

    Bool XkbChangeControls(Display *dpy,
                                XkbDescPtr xkb,
                                XkbControlsChangesPtr changes);

ARGUMENTS

dpy
Connector to the X server.
xkb-kb-desc-ptr
Keyboard description and controls to apply.
changes
Structure specifying which controls have changed.

DESCRIPTION

The XkbChangeControls function copies control information from the keyboard description specified by xkb to the X server connection specified by dpy. The changes argument specifies which particular controls have changed and should be copied.

In order for XkbChangeControls to work correctly, the xkb structure must contain a valid keyboard description that includes the controls you want to change.

If the changes argument is NULL, all controls are assumed to have changed, and the entire controls component is copied from the keyboard description to the server.

If changes is not NULL, then only those controls specified in the changes->changed_ctrls field are copied from the keyboard description to the server.

In addition, XkbChangeControls updates the specified controls, enabling or disabling them as indicated by the changes->enabled_ctrls_changes field.

The changes structure specifies the controls that have been modified. The changed_ctrls field is a bitmask that identifies which of the standard Xkb controls have changed.
The enabled_ctrls_changes field is also a bitmask that identifies which controls have had their enabled/disabled state changed.
The num_groups_changed field is a Boolean that is True if the number of keyboard groups has changed.

If you have an Xkb description with controls that have been modified and an XkbControlsChangesRec that describes the changes that have been made, the XkbChangeControls function provides a flexible method for updating the controls in a server to match those in the changed keyboard description.

XkbChangeControls copies any controls fields specified by changes from the keyboard description controls structure, xkb->ctrls, to the server specified by dpy.

STRUCTURES

The XkbControlsChangesRec structure is defined as follows:

    typedef struct _XkbControlsChanges {
        unsigned int  changed_ctrls;         /* bits indicating changed control data */
        unsigned int  enabled_ctrls_changes; /* bits indicating enabled/disabled controls */
        Bool          num_groups_changed;    /* True if number of keyboard groups changed */
    } XkbControlsChangesRec,*XkbControlsChangesPtr;
