XkbSetDetectableAutoRepeat(3)

Paquete: libx11

Licencias: MIT AND X11

XkbSet DetectableAutoRepeat(3) FUNCIONES DE XKB XkbSet DetectableAutoRepeat(3)

NOMBRE

XkbSet DetectableAutoRepeat - Establece DetectableAutoRepeat

SINOPSIS

Bool XkbSet DetectableAutoRepeat (Display *display, Bool detectable, Bool *supported_rtrn);

ARGUMENTOS

display
conexión al servidor X
detectable
True => establecer DetectableAutoRepeat
supported_rtrn
rellenado con True si DetectableAutoRepeat es compatible

DESCRIPCIÓN

La repetición automática es la generación de múltiples eventos de tecla por un teclado cuando el usuario presiona y mantiene una tecla. El hardware del teclado y el software del servidor X dependiente del dispositivo a menudo implementan la repetición automática generando múltiples eventos KeyPress sin un evento KeyRelease intermedio. El comportamiento estándar del servidor X es generar un evento KeyRelease por cada evento KeyPress. Si el hardware del teclado y el software dependiente del dispositivo del servidor X implementan la repetición automática generando múltiples eventos KeyPress, la parte independiente del servidor X del servidor X genera sintéticamente un evento KeyRelease después de cada evento KeyPress. Esto proporciona un comportamiento predecible para los clientes de X, pero no permite a esos clientes detectar el hecho de que una tecla se está repitiendo automáticamente.

Xkb permite a los clientes solicitar la repetición automática detectable. Si un cliente la solicita y el servidor es compatible con la repetición automática detectable, Xkb genera eventos KeyRelease solo cuando la tecla se suelta físicamente. Si la repetición automática detectable no es compatible o no se ha solicitado, el servidor sintetiza un evento KeyRelease por cada evento KeyPress repetido que genera.

DetectableAutoRepeat, a diferencia de otros controles, no está contenido en la estructura XkbControlsRec, ni se puede habilitar o deshabilitar a través del control EnabledControls. En su lugar, consulte y establezca DetectableAutoRepeat usando XkbGet DetectableAutoRepeat y XkbSet DetectableAutoRepeat.

DetectableAutoRepeat es una condición que se aplica a todos los dispositivos de teclado para la conexión de un cliente a un servidor X dado; no se puede configurar selectivamente para algunos dispositivos y no para otros. Por esta razón, ninguna de las funciones de la biblioteca Xkb que involucran a DetectableAutoRepeat involucra un especificador de dispositivo.

Esta solicitud afecta solo a la actividad del teclado del cliente solicitante; otros clientes aún ven el comportamiento esperado de repetición automática no detectable, a menos que hayan solicitado lo contrario.

XkbSet DetectableAutoRepeat envía una solicitud al servidor para establecer DetectableAutoRepeat activado para el cliente actual si detectable es True, y desactivado si detectable es False; luego espera una respuesta. Si supported_rtrn no es NULL, XkbSet DetectableAutoRepeat rellena supported_rtrn con True si el servidor es compatible con DetectableAutoRepeat, y False si no lo es. XkbSet DetectableAutoRepeat devuelve el estado actual de DetectableAutoRepeat para el cliente solicitante: True si DetectableAutoRepeat está establecido, y False en caso contrario.

VALORES DE RETORNO

True
La función XkbSet DetectableAutoRepeat devuelve True si DetectableAutoRepeat está establecido.
False
La función XkbSet DetectableAutoRepeat devuelve False si DetectableAutoRepeat no está establecido.
