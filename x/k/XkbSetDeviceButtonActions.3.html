XkbSetDeviceButtonActions(3) FUNCIONES XKB XkbSetDeviceButtonActions(3)

NOMBRE

XkbSetDeviceButtonActions - Cambiar solo las acciones de los botones para un dispositivo de extensión de entrada

SINOPSIS

Bool XkbSetDeviceButtonActions (Display *dpy, XkbDeviceInfoPtr device, unsigned int first_button, unsigned int num_buttons);

ARGUMENTOS

dpy
conexión al servidor X
device
estructura que define el dispositivo y las modificaciones
first_button
número del primer botón a actualizar, relativo a 0
num_buttons
número de botones a actualizar

DESCRIPCIÓN

XkbSetDeviceButtonActions asigna acciones a los botones del dispositivo especificado en device_info->device_spec. Las acciones se asignan a num_buttons botones comenzando desde first_button y se toman de las acciones especificadas en device_info->btn_acts.

Si el servidor no soporta la asignación de acciones Xkb a los botones de dispositivos de extensión, XkbSetDeviceButtonActions no tiene efecto y devuelve False. Si el dispositivo no tiene botones o si first_button o num_buttons especifican botones fuera del rango válido determinado por device_info->num_btns, la función no tiene efecto y devuelve False. De lo contrario, XkbSetDeviceButtonActions envía una solicitud al servidor para cambiar las acciones de los botones especificados y devuelve True.

Si la solicitud real enviada al servidor involucra números de botón ilegales, se genera un error de protocolo BadValue. Si se especifica un identificador de dispositivo inválido en device_info->device_spec, resulta un error de protocolo BadKeyboard. Si el dispositivo real especificado en device_info->device_spec no contiene botones y se realiza una solicitud que afecta a los botones, se genera un error de protocolo BadMatch.

DIAGNÓSTICOS

BadKeyboard
El dispositivo especificado no era un dispositivo core o de extensión de entrada válido
BadMatch
No había una versión compatible de Xkb disponible en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
BadValue
Un argumento está fuera de rango
