NOMBRE

XkbAddGeomRow - Añade una fila a una sección

SINOPSIS

XkbRowPtr XkbAddGeomRow (XkbSectionPtr section, int sz_keys);

ARGUMENTOS

section
sección a actualizar
sz_keys
número de claves a reservar

DESCRIPCIÓN

Xkb proporciona funciones para añadir un solo elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no cambian sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debes escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría del teclado incluye una lista de propiedades de geometría. Una propiedad de geometría asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar las propiedades de geometría como pistas, pero Xkb no las interpreta. Ninguna otra estructura de geometría hace referencia a propiedades de geometría.

Uno de los componentes de una sección de geometría de teclado son una o más filas de teclas. XkbAddGeomRow añade una fila a la section especificada. La fila recién creada contiene espacio para el número de teclas especificadas en sz_keys. Se asignan y se ponen a cero, pero por lo demás no están inicializadas. XkbAddGeomRow devuelve NULL si alguno de los parámetros está vacío o si no ha podido asignar espacio para la fila. Para asignar espacio para un número arbitrario de filas a una sección, usa la función XkbAllocGeomRows.

ESTRUCTURAS

typedef struct _XkbRow {
        short           top;
        short           left;
        unsigned short  num_keys;
        unsigned short  sz_keys;
        int             vertical;
        XkbKeyPtr       keys;
        XkbBoundsRec    bounds;
} XkbRowRec, *XkbRowPtr;
