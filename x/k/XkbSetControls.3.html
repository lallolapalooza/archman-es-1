XkbSetControls(3)

Paquete: libx11

Licencias: MIT AND X11

XkbSetControls(3) FUNCIONES DE XKB XkbSetControls(3)

NOMBRE

XkbSetControls - Copia los cambios al servidor X basándose en una estructura de controles modificada en una copia local de la descripción del teclado

SINOPSIS

Bool XkbSetControls (Display *display, unsigned long which, XkbDescPtr xkb);

ARGUMENTOS

display
conexión al servidor X
which
máscara de controles solicitados
xkb
descripción del teclado para la información de controles

DESCRIPCIÓN

Para cada bit establecido en el parámetro which, XkbSetControls envía los valores correspondientes del campo xkb->ctrls al servidor. Los valores válidos para which son cualquier combinación de las máscaras listadas en la Tabla 1 que tengan "ok" en la columna which.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar controles para modificación y para activar y desactivar el control. Tenga en cuenta que se utiliza el mismo bit de máscara para especificar modificaciones generales a los parámetros utilizados para configurar el control (which), y para activar y desactivar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no se pueden activar o desactivar.

Tabla 1 Bits de Máscara de Controles

XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)

XkbAudibleBellMask ok (1L<<9)

Si xkb->ctrls es NULL, el servidor no soporta una versión compatible de Xkb, o la extensión Xkb no se ha inicializado correctamente, XkbSetControls devuelve False. De lo contrario, envía la solicitud al servidor X y devuelve True.

Tenga en cuenta que los cambios en los atributos de los controles en la estructura XkbControlsRec solo son aparentes cuando el control asociado está habilitado, aunque los valores correspondientes todavía se actualizan en el servidor X. Por ejemplo, los campos repeat_delay y repeat_interval se ignoran a menos que el control RepeatKeys esté habilitado (es decir, el equivalente del servidor X de xkb->ctrls tiene XkbRepeatKeyMask establecido en enabled_ctrls). Es permisible modificar los atributos de un control en una llamada a XkbSetControls y habilitar el control en una llamada posterior. Ver XkbChangeEnabledControls para más información sobre cómo habilitar y deshabilitar controles.

Tenga en cuenta que el campo enabled_ctrls es en sí mismo un control - el control EnabledControls. Como tal, para establecer una configuración específica de controles booleanos habilitados y deshabilitados, debe establecer enabled_ctrls a los bits apropiados para habilitar solo los controles que desee y deshabilitar todos los demás, y luego especificar XkbControlsEnabledMask en una llamada a XkbSetControls.

Dado que esto es algo incómodo si todo lo que desea hacer es habilitar y deshabilitar controles, y no modificar ninguno de sus atributos, también se proporciona una función de conveniencia para este propósito, XkbChangeEnabledControls.

VALORES DE RETORNO

True
La función XkbSetControls devuelve True cuando envía la solicitud al servidor X.
False
La función XkbSetControls devuelve False cuando xkb->ctrls es NULL, el servidor no soporta una versión compatible de Xkb, o la extensión Xkb no se ha inicializado correctamente.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadMatch
No había disponible una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido por lo demás
