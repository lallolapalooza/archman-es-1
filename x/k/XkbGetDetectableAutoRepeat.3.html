NOMBRE

XkbGet DetectableAutoRepeat - Determina si el servidor soporta DetectableAutoRepeat

SINOPSIS

Bool XkbGet DetectableAutoRepeat (Display *display, Bool *supported_rtrn);

ARGUMENTOS

display
conexión al servidor X
supported_rtrn
relleno True siDetectableAutoRepeat es soportado

DESCRIPCIÓN

La repetición automática (auto-repeat) es la generación de múltiples eventos de tecla por un teclado cuando el usuario presiona una tecla y la mantiene presionada. El hardware del teclado y el software del servidor X dependiente del dispositivo a menudo implementan la repetición automática generando múltiples eventos KeyPress sin un evento KeyRelease intermedio. El comportamiento estándar del servidor X es generar un evento KeyRelease por cada evento KeyPress. Si el hardware del teclado y el software dependiente del dispositivo del servidor X implementan la repetición automática generando múltiples eventos KeyPress, la parte independiente del servidor X genera sintéticamente por defecto un evento KeyRelease después de cada evento KeyPress. Esto proporciona un comportamiento predecible para los clientes X, pero no permite a dichos clientes detectar el hecho de que una tecla se está repitiendo automáticamente.

Xkb permite a los clientes solicitar la repetición automática detectable. Si un cliente la solicita y el servidor la soporta, Xkb genera eventos KeyRelease solo cuando la tecla se suelta físicamente. Si DetectableAutoRepeat no es soportado o no ha sido solicitado, el servidor sintetiza un evento KeyRelease por cada evento KeyPress repetido que genera.

DetectableAutoRepeat, a diferencia de otros controles, no está contenido en la estructura XkbControlsRec, ni se puede habilitar o deshabilitar a través del control EnabledControls. En su lugar, consulta y establece DetectableAutoRepeat usando XkbGet DetectableAutoRepeat y XkbSet DetectableAutoRepeat.

DetectableAutoRepeat es una condición que se aplica a todos los dispositivos de teclado de la conexión de un cliente a un servidor X dado; no se puede establecer selectivamente para algunos dispositivos y no para otros. Por esta razón, ninguna de las funciones de la biblioteca Xkb que involucran DetectableAutoRepeat involucra un especificador de dispositivo.

XkbGet DetectableAutoRepeat consulta al servidor el estado actual de DetectableAutoRepeat y espera una respuesta. Si supported_rtrn no es NULL, rellena supported_rtrn con True si el servidor soporta DetectableAutoRepeat, y False en caso contrario. XkbGet DetectableAutoRepeat devuelve el estado actual de DetectableAutoRepeat para el cliente que realiza la solicitud: True si DetectableAutoRepeat está establecido, y False en caso contrario.

VALORES DE RETORNO

True
La función XkbGet DetectableAutoRepeat devuelve True si el servidor soporta DetectableAutoRepeat.
False
La función XkbGet DetectableAutoRepeat devuelve False si el servidor no soporta DetectableAutoRepeat.
