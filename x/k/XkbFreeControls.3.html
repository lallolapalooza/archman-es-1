XkbFreeControls(3) FUNCIONES XKB XkbFreeControls(3)

NOMBRE

XkbFreeControls - Libera la memoria utilizada por el miembro ctrls de una estructura XkbDescRec

SINOPSIS

void XkbFreeControls (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTOS

xkb
Descripción Xkb en la que liberar componentes de control
which
Máscara de componentes de ctrls a liberar
free_all
True => liberar todo + ctrls en sí

DESCRIPCIÓN

XkbFreeControls libera los componentes especificados del campo ctrls en la descripción del teclado xkb y establece los valores de los componentes de la estructura correspondientes a NULL o cero. La máscara which especifica los campos de ctrls a liberar y puede contener cualquiera de los componentes de control especificados en la Tabla 1.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar los controles para su modificación y para habilitar y deshabilitar el control. Tenga en cuenta que se utiliza el mismo bit de máscara para especificar modificaciones generales a los parámetros utilizados para configurar el control (which), y para habilitar y deshabilitar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no se pueden habilitar o deshabilitar.

Tabla 1 Bits de máscara de control
Bit de máscara which o habilitado Valor
changed_ctrls _ctrls
XkbRepeatKeysMask ok ok (1L<<0)
XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)
XkbIgnoreLockModsMask ok (1L<<29)
XkbPerKeyRepeatMask ok (1L<<30)
XkbControlsEnabledMask ok (1L<<31)
XkbAccessXOptionsMask ok ok (XkbStickyKeysMask |
XkbAccessXFeedbackMask)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Si free_all es True, XkbFreeControls libera cada componente de estructura no NULL en los controles, libera la estructura XkbControlsRec referenciada por el miembro ctrls de xkb, y establece ctrls a NULL.
