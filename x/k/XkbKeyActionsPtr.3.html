XkbKeyActionsPtr(3) FUNCIONES DE XKB XkbKeyActionsPtr(3)

NOMBRE

XkbKeyActionsPtr - Devuelve un puntero a la matriz bidimensional de acciones de tecla asociadas con la tecla correspondiente al código de tecla

SINOPSIS

XkbKeyActionPtr XkbKeyActionsPtr (XkbDescPtr xkb, KeyCode keycode);

ARGUMENTOS

xkb
Descripción Xkb de interés
keycode
Código de tecla de interés

DESCRIPCIÓN

Una acción de tecla define el efecto que tienen las pulsaciones y liberaciones de teclas en el estado interno del servidor. Por ejemplo, la acción de tecla esperada asociada con la pulsación de la tecla Shift es establecer el modificador Shift. Existe cero o una acción de tecla asociada con cada keysym enlazado a cada tecla.

Al igual que la lista completa de símbolos de tecla para la asignación del teclado se mantiene en el campo syms del mapa del cliente, la lista completa de acciones de tecla para la asignación del teclado se mantiene en la matriz acts del mapa del servidor. El tamaño total de acts se especifica por size_acts, y el número de entradas se especifica por num_acts.

La matriz key_acts, indexada por código de tecla, describe las acciones asociadas con una tecla. La matriz key_acts tiene min_key_code entradas sin usar al principio para permitir la indexación directa usando un código de tecla. Si una entrada de key_acts es cero, significa que la tecla no tiene ninguna acción asociada. Si una entrada no es cero, la entrada representa un índice en el campo acts del mapa del servidor, de forma similar a como el campo offset de una estructura KeySymMapRec es un índice en el campo syms del mapa del cliente.

La razón por la que el campo acts es una lista lineal de XkbActions es para reducir el consumo de memoria asociado con un mapa de teclado. Dado que Xkb permite que teclas individuales tengan múltiples niveles de shift y un número diferente de grupos por tecla, una única matriz bidimensional de KeySyms sería potencialmente muy grande y dispersa. En su lugar, Xkb proporciona una pequeña matriz bidimensional de XkbActions para cada tecla. Para almacenar todas estas matrices individuales, Xkb concatena cada matriz en el campo acts del mapa del servidor.

Las estructuras de acción de tecla consisten únicamente en campos de tipo char o unsigned char. Esto se hace para optimizar la transferencia de datos cuando el servidor envía bytes a través del cable. Si los campos son algo más que bytes, el servidor tiene que examinar todas las acciones e intercambiar cualquier campo no byte. Como consisten únicamente en bytes, simplemente puede copiarlos.

XkbKeyActionsPtr devuelve un puntero a la matriz bidimensional de acciones de tecla asociadas con la tecla correspondiente a keycode. Utilice XkbKeyActionsPtr solo si la tecla realmente tiene alguna acción asociada con ella, es decir, XkbKeyNumActions (xkb, keycode) devuelve algo mayor que cero.

ESTRUCTURAS

La estructura KeySymMapRec se define de la siguiente manera:

    #define XkbNumKbdGroups             4
    #define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
    typedef struct {                    /* map to keysyms for a single keycode */
        unsigned char       kt_index[XkbNumKbdGroups];  /* key type index for each group */
        unsigned char       group_info; /* # of groups and out of range group handling */
        unsigned char       width;      /* max # of shift levels for key */
        unsigned short      offset;     /* index to keysym table in syms array */
} XkbSymMapRec, *XkbSymMapPtr;
