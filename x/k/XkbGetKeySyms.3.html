XkbGetKeySyms(3) FUNCIONES XKB XkbGetKeySyms(3)

NOMBRE

XkbGetKeySyms - Obtener los símbolos para un subconjunto de las teclas en una descripción de teclado

SINOPSIS

Status XkbGetKeySyms (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
first
código de tecla de la primera tecla a obtener
num
número de códigos de tecla para los que se desean símbolos
xkb
descripción Xkb a ser actualizada

DESCRIPCIÓN

XkbGetKeySyms envía una solicitud al servidor para obtener el conjunto de símbolos vinculados a num teclas comenzando con la tecla cuyo código de tecla es first. Espera una respuesta y devuelve los símbolos en el campo map.syms de xkb. Si tiene éxito, XkbGetKeySyms devuelve Success. El parámetro xkb debe ser un puntero a una descripción de teclado Xkb válida.

Si el mapa del cliente en el parámetro xkb no se ha asignado, XkbGetKeySyms lo asigna e inicializa antes de obtener los símbolos.

Si no hay una versión compatible de Xkb disponible en el servidor o la extensión Xkb no se ha inicializado correctamente, XkbGetKeySyms devuelve BadAccess. Si num es menor que 1 o mayor que XkbMaxKeyCount, XkbGetKeySyms devuelve BadValue. Si ocurren errores de asignación, XkbGetKeySyms devuelve BadAlloc.

VALORES DE RETORNO

Success
La función XkbGetKeySyms devuelve Success si obtiene una respuesta a una solicitud al servidor para obtener el conjunto de símbolos vinculados a num teclas comenzando con la tecla cuyo código de tecla es first.

DIAGNÓSTICOS

BadAccess
La extensión Xkb no se ha inicializado correctamente
BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango
