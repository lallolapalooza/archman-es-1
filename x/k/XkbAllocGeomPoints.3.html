NOMBRE

XkbAllocGeomPoints - Asigna puntos en un contorno

SINOPSIS

Estado XkbAllocGeomPoints (XkbOutlinePtr contorno, int num_necesarios);

ARGUMENTOS

contorno
contorno para el cual se deben asignar puntos
num_necesarios
número de puntos nuevos requeridos

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el/los nuevo(s) elemento(s), y depende de usted completar los valores explícitamente en su código. Estas funciones de asignación aumentan sz_* pero nunca tocan num_* (a menos que haya un fallo de asignación, en cuyo caso reinician tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomPoints asigna espacio para num_necesarios puntos en el contorno especificado. Los puntos no se inicializan.

DIAGNÓSTICOS

BadAlloc
No se puede asignar almacenamiento
BadValue
Un argumento está fuera de rango
