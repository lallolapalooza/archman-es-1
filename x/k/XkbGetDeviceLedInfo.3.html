NOMBRE

XkbGetDeviceLedInfo - Consultar los nombres, mapas y estado de los indicadores asociados con una retroalimentación LED de un dispositivo de extensión de entrada

SINOPSIS

Status XkbGetDeviceLedInfo (Display *dpy, XkbDeviceInfoPtr device_info, unsigned int led_class, unsigned int led_id, unsigned int which);

ARGUMENTOS

dpy
conexión al servidor X
device_info
estructura a actualizar con los resultados
led_class
clase de retroalimentación LED asignada por la extensión de entrada
led_id
ID de retroalimentación LED asignada por la extensión de entrada
which
máscara que indica la información deseada

DESCRIPCIÓN

XkbGetDeviceLedInfo consulta al servidor la información LED deseada para la retroalimentación especificada por led_class y led_id para el dispositivo de extensión de entrada X indicado por device_spec->device_info y espera una respuesta. Si tiene éxito, XkbGetDeviceLedInfo rellena los campos relevantes de device_info según lo determinado por which con los resultados y devuelve Success. Los valores válidos para which son la OR inclusiva de cualquiera de XkbXI_IndicatorNamesMask, XkbXI_IndicatorMapsMask y XkbXI_IndicatorStateMask.

Los campos de device_info que se rellenan cuando esta solicitud tiene éxito son name, type, supported, y unsupported, y porciones de la estructura leds correspondientes a led_class y led_id según lo indicado por los bits establecidos en which. El vector device_info->leds se asigna si es necesario y se rellenan sz_leds y num_leds. Los campos led_class, led_id y phys_indicators de la entrada device_info->leds que corresponden a led_class y led_id siempre se rellenan.

Si which contiene XkbXI_IndicatorNamesMask, los campos names_present y names de la estructura device_info->leds correspondientes a led_class y led_id se actualizan; si which contiene XkbXI_IndicatorStateMask, el campo state correspondiente se actualiza; y si which contiene XkbXI_IndicatorMapsMask, los campos maps_present y maps se actualizan.

Si no está disponible una versión compatible de Xkb en el servidor o la extensión Xkb no se ha inicializado correctamente, XkbGetDeviceLedInfo devuelve BadAccess. Si ocurren errores de asignación, se devuelve un estado BadAlloc. Si el dispositivo no tiene indicadores, se devuelve un error BadMatch. Si ledClass o ledID tienen valores ilegales, se devuelve un error BadValue. Si tienen valores legales pero no especifican una retroalimentación que contenga LEDs y esté asociada con el dispositivo especificado, se devuelve un error BadMatch.

DIAGNÓSTICOS

BadAccess
La extensión Xkb no se ha inicializado correctamente
BadAlloc
No se pudo asignar almacenamiento
BadMatch
No se encontró una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
BadValue
Un argumento está fuera de rango
