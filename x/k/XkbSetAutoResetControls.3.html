XkbSetAutoResetControls(3) FUNCIONES XKB XkbSetAutoResetControls(3)

NOMBRE

XkbSetAutoResetControls - Cambia los valores actuales de los atributos de Control de reinicio automático

SINOPSIS

Bool XkbSetAutoResetControls (Display *dpy, unsigned int cambios, unsigned int *auto_ctrls, unsigned int *auto_values);

ARGUMENTOS

dpy
conexión al servidor X
cambios
controles cuyos valores de reinicio automático se van a cambiar
auto_ctrls
controles de los cambios que se reiniciarán automáticamente
auto_values
1 bit => reinicio automático activado

DESCRIPCIÓN

XkbSetAutoResetControls cambia el estado de reinicio automático y los valores de reinicio automático asociados para los controles seleccionados por cambios. Para cualquier control seleccionado por cambios, si el bit correspondiente está activado en auto_ctrls, el control se configura para reiniciarse automáticamente cuando el cliente finalice. Si el bit correspondiente en auto_values está activado, el control se activa cuando el cliente finalice; si es cero, el control se desactiva cuando el cliente finalice. Para cualquier control seleccionado por cambios, si el bit correspondiente no está activado en auto_ctrls, el control se configura para no reiniciarse cuando el cliente finalice.

Por ejemplo:

Para dejar los controles de reinicio automático para StickyKeys como están:
	ok = XkbSetAutoResetControls(dpy, 0, 0, 0);

Para cambiar los controles de reinicio automático para que StickyKeys no se vean afectados cuando el
cliente finalice:
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, 0, 0);

Para cambiar los controles de reinicio automático para que StickyKeys se desactiven cuando el
cliente finalice:
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, XkbStickyKeysMask, 0);

Para cambiar los controles de reinicio automático para que StickyKeys se activen cuando el
cliente finalice:
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, XkbStickyKeysMask,
XkbStickyKeysMask);
XkbSetAutoResetControls rellena auto_ctrls y auto_values con los controles de reinicio automático para este cliente en particular. Tenga en cuenta que todos los bits son válidos en los valores devueltos, no solo los seleccionados en la máscara de cambios.
