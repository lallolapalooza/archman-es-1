XkbGetKeyboard(3) FUNCIONES XKB XkbGetKeyboard(3)

NOMBRE

XkbGetKeyboard - Recupera uno o más componentes de la descripción de un dispositivo de teclado

SINOPSIS

XkbDescPtr XkbGetKeyboard (Display *display, unsigned int which, unsigned int device_spec);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo o XkbUseCoreKbd
bits_to_change
determina los eventos a seleccionar/deseleccionar
values_for_bits
1=>seleccionar, 0=>deseleccionar; para eventos en bits_to_change

DESCRIPCIÓN

XkbGetKeyboard asigna y devuelve un puntero a una descripción de teclado. Consulta al servidor para obtener los componentes especificados en el parámetro which para el dispositivo device_spec y copia los resultados a la XkbDescRec que asignó. Los campos restantes en la descripción del teclado se establecen en NULL. Las máscaras válidas para which son las listadas en la Tabla 1.

Tabla 1 Bits de Máscara para XkbDescRec
Bit de Máscara Campo XkbDescRec Valor
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Todos los Campos (1L<<7)

XkbGetKeyboard se utiliza para leer la descripción actual de uno o más componentes de un dispositivo de teclado. Llama a XkbGetKeyboardByName(3) de la siguiente manera:

XkbGetKeyboardByName(dpy, device_spec, NULL, which, which, False).

Si tiene éxito, XkbGetKeyboard devuelve un puntero a una estructura XkbDescRec recién asignada, que se describe en XkbGetKeyboardByName(3), y que debe liberarse con XkbFreeKeyboard(3). Si XkbGetKeyboard no tiene éxito, devuelve NULL.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
