XkbGetAutoResetControls(3) FUNCIONES XKB XkbGetAutoResetControls(3)

NOMBRE

XkbGetAutoResetControls - Obtiene los valores actuales de los controles de reinicio automático

SINOPSIS

Bool XkbGetAutoResetControls (Display *dpy, unsigned int *auto_ctrls, unsigned int *auto_values);

ARGUMENTOS

dpy
conexión al servidor X
auto_ctrls
especifica qué bits en auto_values son relevantes
auto_values
1 bit => el control correspondiente tiene el reinicio automático activado

DESCRIPCIÓN

Se pueden configurar los controles booleanos para que se activen o desactiven automáticamente cuando un programa finaliza. Esta capacidad se controla mediante dos máscaras mantenidas en el servidor X por cliente. No existe una estructura de datos Xkb del lado del cliente que corresponda a estas máscaras. Cada vez que el cliente finaliza por cualquier motivo, los controles booleanos especificados en la *máscara de reinicio automático* se establecen en el valor correspondiente de la *máscara de valores de reinicio automático*. Esto permite a los clientes "limpiar después de sí mismos" automáticamente, incluso si se terminan de forma anormal. Los bits utilizados en las máscaras corresponden a los bits de control de EnabledControls.

Por ejemplo, un cliente que reemplaza la campana del teclado con alguna otra señal audible podría querer desactivar el control AudibleBell para evitar que el servidor también genere un sonido y evitar la cacofonía. Si el cliente finalizara sin restablecer el control AudibleBell, el usuario se quedaría sin ninguna retroalimentación. Al establecer AudibleBell tanto en la máscara de reinicio automático como en los valores de reinicio automático, se garantiza que la campana audible se volverá a activar cuando el cliente finalice.

XkbGetAutoResetControls rellena auto_ctrls y auto_values con los atributos de control de reinicio automático para este cliente en particular. Devuelve True si tiene éxito y False en caso contrario.

VALORES DE RETORNO

True
La función XkbGetAutoResetControls devuelve True cuando rellena con éxito auto_ctrls y auto_values con los atributos de control de reinicio automático para este cliente en particular.
False
La función XkbGetAutoResetControls devuelve False cuando no rellena con éxito auto_ctrls y auto_values con los atributos de control de reinicio automático para este cliente en particular.
