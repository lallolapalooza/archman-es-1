NOMBRE

XkbLockGroup - Bloquea el grupo de keysym

SINOPSIS

Bool XkbLockGroup (Display *display, unsigned int device_spec, unsigned int group);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo o XkbUseCoreKbd
group
índice del grupo de keysym a bloquear

DESCRIPCIÓN

XkbLockGroup envía una solicitud al servidor para bloquear el group especificado y no espera una respuesta. Devuelve True si la solicitud se envió y False en caso contrario.

Consulte los índices de grupos de keysym con estas constantes simbólicas:

Tabla 1 Nombres de Grupos Simbólicos
Nombre Simbólico Valor
XkbGroup1Index 0
XkbGroup2Index 1
XkbGroup3Index 2
XkbGroup4Index 3

VALORES DE RETORNO

True
La función XkbLockGroup devuelve True cuando se envía una solicitud al servidor para bloquear el group especificado y no espera una respuesta.
False
La función XkbLockGroup devuelve False si la solicitud no se envió.
