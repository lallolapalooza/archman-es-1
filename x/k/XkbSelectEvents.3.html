XkbSelectEvents(3) FUNCIONES XKB XkbSelectEvents(3)

NOMBRE

XkbSelectEvents - Selecciona y/o deselecciona la entrega de uno o más eventos Xkb y los entrega bajo todas las condiciones

SINOPSIS

Bool XkbSelectEvents (Display *display, unsigned int device_spec, unsigned long int bits_to_change, unsigned long int values_for_bits);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo o XkbUseCoreKbd
bits_to_change
determina los eventos a seleccionar/deseleccionar
values_for_bits
1=>seleccionar, 0=>deseleccionar; para eventos en bits_to_change

DESCRIPCIÓN

Los eventos Xkb se seleccionan utilizando una máscara de eventos, de manera muy similar a como se seleccionan los eventos X principales. Sin embargo, a diferencia de la selección de eventos X principales, donde debe especificar el estado de selección (activado o desactivado) para todos los tipos de eventos posibles cada vez que desee cambiar los criterios de selección para cualquier evento, Xkb le permite restringir la especificación solo a los tipos de eventos que desea cambiar. Esto significa que no necesita recordar los valores de selección de eventos para todos los tipos posibles cada vez que desee cambiar uno de ellos.

Muchos tipos de eventos Xkb se generan en varias circunstancias diferentes. Al seleccionar recibir un evento Xkb, puede especificar si desea que se entregue en todas las circunstancias o solo para un subconjunto de las circunstancias posibles.

También puede deseleccionar un tipo de evento que fue seleccionado previamente, utilizando la misma granularidad.

Xkb proporciona dos funciones para seleccionar y deseleccionar la entrega de eventos Xkb. XkbSelectEvents le permite seleccionar o deseleccionar la entrega de más de un tipo de evento Xkb a la vez. Los eventos seleccionados utilizando XkbSelectEvents se entregan a su programa bajo todas las circunstancias que generan los eventos. Para restringir la entrega de un evento a un subconjunto de las condiciones bajo las cuales ocurre, use XkbSelectEventDetails. XkbSelectEventDetails solo le permite cambiar las condiciones de selección para un solo evento a la vez, pero proporciona un medio para ajustar finamente las condiciones bajo las cuales se entrega el evento.

Esta solicitud cambia la máscara de selección de eventos Xkb para el teclado especificado por device_spec.

Cada evento Xkb que se puede seleccionar está representado por un bit en las máscaras bits_to_change y values_for_bits. Solo los bits de selección de eventos especificados por el parámetro bits_to_change se ven afectados; cualquier bit no especificado se deja sin cambios. Para activar la selección de eventos para un evento, establezca el bit para el evento en el parámetro bits_to_change y establezca el bit correspondiente en el parámetro values_for_bits. Para desactivar la selección de eventos para un evento, establezca el bit para el evento en el parámetro bits_to_change y no establezca el bit correspondiente en el parámetro values_for_bits. Los valores válidos para ambos parámetros son un OR a nivel de bits inclusivo de las máscaras que se muestran en la Tabla 1. No hay una interfaz para devolver la máscara de selección de eventos actual de su cliente. Los clientes no pueden establecer las máscaras de selección de eventos de otros clientes.

El servidor X informa los eventos definidos por Xkb a su aplicación cliente solo si los ha solicitado a través de una llamada a XkbSelectEvents o XkbSelectEventDetails. Especifique los tipos de eventos que le interesan en una máscara.

La Tabla 1 enumera las constantes de máscara de eventos que se pueden especificar con la solicitud XkbSelectEvents y las circunstancias en las que se debe especificar la máscara.

Tabla 1 Constantes de Máscara de XkbSelectEvents
Máscara de Evento Valor Notificación Solicitada
XkbNewKeyboardNotifyMask (1L<<0) Cambio de geometría del teclado
XkbMapNotifyMask (1L<<1) Cambio de mapeo del teclado
XkbStateNotifyMask (1L<<2) Cambio de estado del teclado
XkbControlsNotifyMask (1L<<3) Cambio de control del teclado
XkbIndicatorStateNotifyMask (1L<<4) Cambio de estado del indicador del teclado
XkbIndicatorMapNotifyMask (1L<<5) Cambio de mapa del indicador del teclado
XkbNamesNotifyMask (1L<<6) Cambio de nombre del teclado
XkbCompatMapNotifyMask (1L<<7) Cambio de mapa de compatibilidad del teclado
XkbBellNotifyMask (1L<<8) Timbre
XkbActionMessageMask (1L<<9) Mensaje de acción
XkbAccessXNotifyMask (1L<<10) Funciones AccessX
XkbExtensionDeviceNotifyMask (1L<<11) Dispositivo de extensión
XkbAllEventsMask (0xFFF) Todos los eventos Xkb

Si un bit no está establecido en el parámetro bits_to_change, pero el bit correspondiente está establecido en el parámetro values_for_bits, se produce un error de protocolo BadMatch. Si se establece un bit indefinido en el parámetro bits_to_change o values_for_bits, se produce un error de protocolo BadValue.

Todos los bits de selección de eventos están inicialmente a cero para los clientes que utilizan la extensión Xkb. Una vez que establece algunos bits, permanecen establecidos para su cliente hasta que los borre mediante otra llamada a XkbSelectEvents.

XkbSelectEvents devuelve False si la extensión Xkb no se ha inicializado y True en caso contrario.

VALORES DE RETORNO

True
La función XkbSelectEvents devuelve True si la extensión Xkb se ha inicializado.
False
La función XkbSelectEvents devuelve False si la extensión Xkb no se ha inicializado.
