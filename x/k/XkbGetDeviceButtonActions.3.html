NOMBRE

XkbGetDeviceButtonActions - Consultar las acciones de los botones asociadas a un dispositivo de la Extensión de Entrada de X

SINOPSIS

Status XkbGetDeviceButtonActions (Display *dpy, XkbDeviceInfoPtr device_info, Bool all_buttons, unsigned int first_button, unsigned int num_buttons);

ARGUMENTOS

dpy
conexión al servidor X
device_info
estructura a actualizar con los resultados
all_buttons
Verdadero => obtener información para todos los botones
first_button
número del primer botón para el que se desea información
num_buttons
número de botones para los que se desea información

DESCRIPCIÓN

XkbGetDeviceButtonActions consulta al servidor la información deseada de los botones para el dispositivo indicado por el campo device_spec de device_info y espera una respuesta. Si tiene éxito, XkbGetDeviceButtonActions rellena las acciones de los botones (campo btn_acts de device_info) solo para los botones solicitados, actualiza los campos name, type, supported y unsupported, y devuelve Success.

all_buttons, first_button y num_buttons especifican los botones del dispositivo para los cuales se deben devolver las acciones. Establecer all_buttons a Verdadero solicita acciones para todos los botones del dispositivo; si all_buttons es Falso, first_button y num_buttons especifican un rango de botones para los cuales se solicitan acciones.

Si no está disponible una versión compatible de Xkb en el servidor o si la extensión Xkb no se ha inicializado correctamente, XkbGetDeviceButtonActions devuelve BadAccess. Si ocurren errores de asignación, se devuelve un estado BadAlloc. Si el dispositivo especificado (device_info->device_spec) es inválido, se devuelve un estado BadKeyboard. Si el dispositivo no tiene botones, se devuelve un estado BadMatch. Si first_button y num_buttons especifican botones ilegales, se devuelve un estado BadValue.

DIAGNÓSTICOS

BadAccess
La extensión Xkb no se ha inicializado correctamente
BadAlloc
No se pudo asignar almacenamiento
BadKeyboard
El dispositivo especificado no era un dispositivo válido del núcleo o de la extensión de entrada
BadMatch
No había una versión compatible de Xkb disponible en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
BadValue
Un argumento está fuera de rango
