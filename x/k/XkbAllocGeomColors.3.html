NOMBRE

XkbAllocGeomColors - Asigna colores de geometría

SINOPSIS

Status XkbAllocGeomColors (XkbGeometryPtr geom, int num_needed);

ARGUMENTOS

geom
geometría para la que se deben asignar los colores
num_needed
número de colores nuevos requeridos

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para los nuevos elementos y depende de usted rellenar explícitamente los valores en su código. Estas funciones de asignación aumentan sz_* pero nunca tocan num_* (a menos que haya un error de asignación, en cuyo caso restablecen sz_* y num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

XkbAllocGeomColors asigna espacio para num_needed colores y los añade a la geometría especificada geom. Un nombre de color es una cadena cuya interpretación no está especificada por Xkb. Todas las demás estructuras de datos de geometría se refieren a colores utilizando sus índices en esta lista global o punteros a colores en esta lista.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango
