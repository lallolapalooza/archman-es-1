XkbChangeMap(3)

Paquete: libx11

Licencias: MIT AND X11

XkbChangeMap(3) FUNCIONES XKB XkbChangeMap(3)

NOMBRE

XkbChangeMap - Actualiza solo componentes parciales de una descripción de teclado, modifica los campos apropiados en los componentes del servidor y del mapa de una copia local de la descripción del teclado

SINOPSIS

Bool XkbChangeMap (Display *dpy, XkbDescPtr xkb, XkbMapChangesPtr changes);

ARGUMENTOS

dpy
conexión al servidor X
xkb
descripción de la que se toman los nuevos valores
changes
identifica los componentes a actualizar

DESCRIPCIÓN

Para actualizar solo componentes parciales de una descripción de teclado, modifica los campos apropiados en los componentes del servidor y del mapa de una copia local de la descripción del teclado, y luego llama a XkbChangeMap con una estructura XkbMapChangesRec que indica qué componentes han cambiado.

XkbChangeMap copia cualquier componente especificado por la estructura changes desde la descripción del teclado, xkb, al servidor X especificado por dpy.

Si alguno de los componentes especificados por changes no está presente en el parámetro xkb, XkbChangeMap devuelve False. De lo contrario, envía una solicitud al servidor y devuelve True.

XkbChangeMap puede generar errores de protocolo BadAlloc, BadLength y BadValue.

VALORES DE RETORNO

True
La función XkbChangeMap devuelve True si los componentes especificados por changes están presentes en el parámetro xkb.
False
La función XkbChangeMap devuelve False si los componentes especificados por changes no están presentes en el parámetro xkb.

ESTRUCTURAS

Utiliza la estructura XkbMapChangesRec para identificar y rastrear modificaciones parciales en los componentes de mapeo y para reducir la cantidad de tráfico entre el servidor y los clientes.

typedef struct _XkbMapChanges {
    unsigned short   changed;            /* identifica componentes válidos en la estructura */
    KeyCode          min_key_code;       /* keycode de menor número para el dispositivo */
    KeyCode          max_key_code;       /* keycode de mayor número para el dispositivo */
    unsigned char    first_type;         /* índice del primer tipo de tecla modificado */
    unsigned char    num_types;          /* # de tipos modificados */
    KeyCode          first_key_sym;      /* primera tecla cuyo mapa de símbolos de tecla cambió */
    unsigned char    num_key_syms;       /* # de entradas de mapa de símbolos de tecla cambiadas */
    KeyCode          first_key_act;      /* primera tecla cuya entrada de acciones de tecla cambió */
    unsigned char    num_key_acts;       /* # de entradas de acciones de tecla cambiadas */
    KeyCode          first_key_behavior; /* primera tecla cuyas acciones cambiaron */
    unsigned char    num_key_behaviors;  /* # de acciones cambiadas */
    KeyCode          first_key_explicit; /* primera tecla cuya entrada explícita cambió */
    unsigned char    num_key_explicit;   /* # de entradas explícitas cambiadas */
    KeyCode          first_modmap_key;   /* primera tecla cuya entrada modmap cambió */
    unsigned char    num_modmap_keys;    /* # de entradas modmap cambiadas */
    KeyCode          first_vmodmap_key;  /* primera tecla cuyo vmodmap cambió */
    unsigned char    num_vmodmap_keys;   /* # de entradas vmodmap cambiadas */
    unsigned char    pad1;               /* reservado */
    unsigned short   vmods;              /* máscara que indica qué vmods cambiaron */
} XkbMapChangesRec,*XkbMapChangesPtr;

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadLength
La longitud de una solicitud es menor o mayor de lo requerido para contener mínimamente los argumentos
BadValue
Un argumento está fuera de rango
