XkbSetNamedDeviceIndicator(3)

Paquete: libx11

Licencias: MIT AND X11

XkbSetNamedIndicator(3) FUNCIONES XKB XkbSetNamedIndicator(3)

NOMBRE

XkbSetNamedIndicator - Nombra un indicador si aún no está nombrado; cambia el estado del indicador; establece el indicador a un estado especificado y establece el mapa del indicador para el indicador

SINOPSIS

Bool XkbSetNamedDeviceIndicator (Display *dpy, unsigned int device_spec, unsigned int led_class, unsigned int led_id, Atom name, Bool change_state, Bool state, Bool create_new, XkbIndicatorMapPtr map); Bool XkbSetNamedIndicator (Display *dpy, Atom name, Bool change_state, Bool state, Bool create_new, XkbIndicatorMapPtr map);

ARGUMENTOS

dpy
conexión al servidor X
device_spec
ID del dispositivo, o XkbUseCoreKbd
led_class
clase de retroalimentación, o XkbDfltXIClass
led_id
ID de retroalimentación, o XkbDfltXIId
name
nombre del indicador a cambiar
change_state
si se debe cambiar o no el estado del indicador
state
nuevo estado deseado para el indicador
create_new
si se debe crear un nuevo indicador con el nombre especificado cuando sea necesario
map
nuevo mapa para el indicador

DESCRIPCIÓN

Si una versión compatible de la extensión Xkb no está disponible en el servidor, XkbSetNamedDeviceIndicator devuelve False. De lo contrario, envía una solicitud al servidor X para cambiar el indicador especificado por name y devuelve True.

Si change_state es True, XkbSetNamedDeviceIndicator indica al servidor que cambie el estado del indicador nombrado al valor especificado por state. Si change_state es False, entonces state no se utiliza.

Si un indicador con el nombre especificado por name aún no existe, el parámetro create_new indica al servidor si debe crear un nuevo indicador nombrado. Si create_new es True, el servidor busca el primer indicador que no tiene nombre y le da el nombre especificado por name. Si el parámetro opcional, map, no es NULL, XkbSetNamedDeviceIndicator indica al servidor que cambie el mapa del indicador a los valores especificados en map.

Además, también puede generar eventos XkbIndicatorStateNotify, XkbIndicatorMapNotify y XkbNamesNotify.

XkbSetNamedIndicator es una función de conveniencia que llama a XkbSetNamedDeviceIndicator con un device_spec de XkbUseCoreKbd, una led_class de XkbDfltXIClass y un led_id de XkbDfltXIId. Devuelve el valor de retorno de XkbSetNamedDeviceIndicator.

VALORES DE RETORNO

True
Las funciones XkbSetNamedIndicator y XkbSetNamedDeviceIndicator devuelven True si una versión compatible de la extensión Xkb está disponible en el servidor.
False
Las funciones XkbSetNamedIndicator y XkbSetNamedDeviceIndicator devuelven False si una versión compatible de la extensión Xkb no está disponible en el servidor.

DIAGNÓSTICOS

BadAtom
Un nombre no es un Atom válido ni None
BadImplementation
Respuesta inválida del servidor
BadKeyboard
device_spec no especifica un dispositivo con indicadores.
BadMatch
led_id no es DfltXIId y no especifica una retroalimentación de la clase especificada por led_class en el dispositivo especificado por device_spec.
BadValue
led_class no especifica DfltXIClass, LedFeedbackClass o KbdFeedbackClass.

VER TAMBIÉN

XkbIndicatorMapNotify(3), XkbIndicatorStateNotify(3), XkbNamesNotify(3)
