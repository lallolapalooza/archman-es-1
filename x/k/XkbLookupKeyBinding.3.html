NOMBRE

XkbLookupKeyBinding - Encuentra la cadena enlazada a una tecla por XRebindKeySym

SINOPSIS

int XkbLookupKeyBinding (Display *dpy, KeySym sym, unsigned int state, char *buf, int nbytes, int *extra_rtrn);

ARGUMENTOS

dpy
conexión al servidor
sym
conexión al servidor
state
estado para el cual se buscará la cadena
buf
búfer en el que se escribirá la cadena devuelta
nbytes
tamaño del búfer en bytes
extra_rtrn
rellenado hacia atrás con el número de bytes de desbordamiento

DESCRIPCIÓN

XkbLookupKeyBinding es el equivalente de la función central XLookupString.

XRebindKeysym enlaza una cadena ASCII a un keysym especificado, de modo que la cadena y el keysym se devuelven cuando se presiona la tecla y se mantienen presionadas una lista especificada de modificadores. XkbLookupKeyBinding devuelve en buf la cadena asociada al keysym sym y al estado del modificador state. buf se termina con NULL a menos que haya un desbordamiento. Si la cadena devuelta es mayor que nbytes, se devuelve en extra_rtrn el número de bytes que no caben en el búfer. XkbTranslateKeySym devuelve el número de bytes que colocó en buf.

VER TAMBIÉN

XkbTranslateKeySym(3), XLookupString(3), XRebindKeysym(3)
