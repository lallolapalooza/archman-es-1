XkbAllocCompatMap(3) FUNCIONES XKB XkbAllocCompatMap(3)

NOMBRE

XkbAllocCompatMap - Asigna un nuevo mapa de compatibilidad si aún no dispones de uno

SINOPSIS

Status XkbAllocCompatMap (XkbDescPtr xkb, unsigned int which, unsigned int num_si);

ARGUMENTOS

xkb
descripción del teclado en la que se asignará el mapa de compatibilidad
which
máscara de componentes del mapa de compatibilidad a asignar
num_si
número de interpretaciones de símbolos a asignar

DESCRIPCIÓN

xkb especifica la descripción del teclado para la que se asignarán los mapas de compatibilidad. El mapa de compatibilidad es el campo compat en esta estructura.

which especifica los componentes del mapa de compatibilidad a asignar (ver XkbGetCompatMap). which es una OR inclusiva de los bits mostrados en la Tabla 1.

Tabla 1 Máscaras de Componentes del Mapa de Compatibilidad
Máscara Valor Afectando
XkbSymInterpMask (1<<0) Interpretaciones de símbolos
XkbGroupCompatMask (1<<1) Mapas de grupos
XkbAllCompatMask (0x3) Todos los componentes del mapa de compatibilidad

num_si especifica el número total de entradas a asignar en el vector de interpretaciones de símbolos (xkb.compat.sym_interpret).

XkbAllocCompatMap devuelve Success si tiene éxito, BadMatch si xkb es NULL, o BadAlloc si se encuentran errores al intentar asignar almacenamiento.

ESTRUCTURAS

    typedef struct {
        KeySym            sym;          /* keysym de interés o NULL */
        unsigned char     flags;        /* XkbSI_AutoRepeat, XkbSI_LockingKey */
        unsigned char     match;        /* especifica cómo se interpretan los mods */
        unsigned char     mods;         /* bits de modificadores, corresponden a ocho modificadores reales */
        unsigned char     virtual_mod;  /* 1 modificador a añadir al mapa de modificador virtual de la tecla */
        XkbAnyAction      act;          /* acción a enlazar a la posición del símbolo en la tecla */
    } XkbSymInterpretRec,*XkbSymInterpretPtr;

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadMatch
No se pudo encontrar una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera

VER TAMBIÉN

XkbGetCompatMap(3)

NOTAS

Tenga en cuenta que las interpretaciones de símbolos en un mapa de compatibilidad (el vector sym_interpret de las estructuras XkbSymInterpretRec) también se asignan utilizando esta misma función. Para garantizar que haya suficiente espacio en el vector de interpretaciones de símbolos para agregar entradas, use XkbAllocCompatMap especificando which como XkbSymInterpretMask y el número de interpretaciones de símbolos libres necesarias en num_si.
