XkbSetCompatMap(3) FUNCIONES XKB XkbSetCompatMap(3)

NOMBRE

XkbSetCompatMap - Modifica el mapa de compatibilidad del servidor

SINOPSIS

Bool XkbSetCompatMap (Display *display, unsigned int which, XkbDescPtr xkb, Bool update_actions);

ARGUMENTOS

display
conexión al servidor
which
máscara de componentes del mapa de compatibilidad a establecer
xkb
fuente para los componentes del mapa de compatibilidad
update_actions
True => aplicar al mapa de teclado del servidor

DESCRIPCIÓN

Para modificar el mapa de compatibilidad del servidor, primero modifique una copia local del mapa de compatibilidad Xkb, y luego llame a XkbSetCompatMap. Puede asignar un nuevo mapa de compatibilidad para este propósito usando XkbAllocCompatMap. También puede usar un mapa de compatibilidad de otro servidor, aunque necesita ajustar el campo device_spec en el XkbDescRec correspondientemente. Tenga en cuenta que las interpretaciones de símbolos en un mapa de compatibilidad ( sym_interpret, el vector de estructuras XkbSymInterpretRec) también se asignan usando esta misma función. XkbSetCompatMap copia la información del mapa de compatibilidad desde la descripción del teclado en xkb al servidor especificado en el mapa de compatibilidad del display para el dispositivo especificado por el campo device_spec de xkb. A menos que haya modificado específicamente este campo, es el dispositivo de teclado predeterminado. which especifica los componentes del mapa de compatibilidad a establecer, y es una OR inclusiva de los bits que se muestran en la Tabla 1.

Tabla 1 Máscaras de Componentes del Mapa de Compatibilidad
Máscara Valor Afectando
XkbSymInterpMask (1<<0) Interpretaciones de símbolos
XkbGroupCompatMask (1<<1) Mapas de grupos
XkbAllCompatMask (0x3) Todos los componentes del mapa de compatibilidad

Después de actualizar su mapa de compatibilidad para el dispositivo especificado, si update_actions es True, el servidor aplica el nuevo mapa de compatibilidad a todo su teclado para el dispositivo para generar un nuevo conjunto de semánticas de teclas, estado de compatibilidad y un nuevo mapa de teclado principal (core). Si update_actions es False, el nuevo mapa de compatibilidad no se utiliza para generar ninguna modificación en las semánticas, el estado o el mapa de teclado principal (core) del dispositivo actual. Una razón para no aplicar el mapa de compatibilidad inmediatamente podría ser si un servidor se estuviera configurando para que coincidiera con otro de forma fragmentada; el mapa no debería aplicarse hasta que todo se haya actualizado. Para forzar una actualización en un momento posterior, use XkbSetCompatMap especificando which como cero y update_actions como True. XkbSetCompatMap devuelve True si tiene éxito y False si falla. El servidor puede informar problemas que encuentre al procesar la solicitud posteriormente a través de errores de protocolo.

VALORES DE RETORNO

True
La función XkbSetCompatMap devuelve True si tiene éxito.
False
La función XkbSetCompatMap devuelve False si falla.

ESTRUCTURAS

La descripción completa de un teclado Xkb se da mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb.

typedef struct {
   struct _XDisplay  *display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado de Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de teclado del servidor */
   XkbClientMapPtr    map;          /* mapa de teclado del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;

El campo display apunta a una estructura de visualización X. El campo flags es privado de la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal (core). Los campos min_key_code y max_key_code especifican el keycode más bajo y más alto que puede devolver el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe manipularse de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en XkbDescRec se muestran en la Tabla 2.

Tabla 2 Bits de Máscara para XkbDescRec
Bit de Máscara Campo XkbDescRec Valor
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Todos los Campos (0x7f)

La estructura XkbSymInterpretRec especifica una interpretación de símbolos:

    typedef struct {
        KeySym        sym;         /* símbolo de interés o NULL */
        unsigned char flags;       /* XkbSI_AutoRepeat, XkbSI_LockingKey */
        unsigned char match;       /* especifica cómo se interpreta mods */
        unsigned char mods;        /* bits de modificadores, corresponden a ocho modificadores reales */
        unsigned char virtual_mod; /* 1 modificador a añadir al mapa de modificadores virtuales de la tecla */
        XkbAnyAction  act;         /* acción a enlazar a la posición del símbolo en la tecla */
    } XkbSymInterpretRec,*XkbSymInterpretPtr;
