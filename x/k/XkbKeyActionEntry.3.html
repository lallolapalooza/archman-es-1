XkbKeyActionEntry(3)

Paquete: libx11

Licencias: MIT AND X11

XkbKeyActionEntry(3) FUNCIONES DE XKB XkbKeyActionEntry(3)

NOMBRE

XkbKeyActionEntry - Devuelve un puntero a la acción de tecla correspondiente al grupo grp y nivel de desplazamiento lvl de la tabla bidimensional de acciones de teclas asociadas a la tecla correspondiente a keycode

SINOPSIS

XkbAction * XkbKeyActionEntry (XkbDescPtr xkb, KeyCode keycode, int shift, int grp);

ARGUMENTOS

xkb
Descripción Xkb de interés
keycode
Keycode de interés
shift
Nivel de desplazamiento dentro del grupo
grp
Índice de grupo de interés

DESCRIPCIÓN

Una acción de tecla define el efecto que las pulsaciones y liberaciones de teclas tienen sobre el estado interno del servidor. Por ejemplo, la acción de tecla esperada asociada con la pulsación de la tecla Shift es establecer el modificador Shift. Hay cero o una acción de tecla asociada con cada keysym enlazado a cada tecla.

Al igual que la lista completa de símbolos de tecla para la asignación del teclado se mantiene en el campo syms del mapa del cliente, la lista completa de acciones de tecla para la asignación del teclado se mantiene en el array acts del mapa del servidor. El tamaño total de acts se especifica por size_acts, y el número de entradas se especifica por num_acts.

El array key_acts, indexado por keycode, describe las acciones asociadas a una tecla. El array key_acts tiene min_key_code entradas no utilizadas al principio para permitir la indexación directa utilizando un keycode. Si una entrada de key_acts es cero, significa que la tecla no tiene ninguna acción asociada. Si una entrada no es cero, la entrada representa un índice en el campo acts del mapa del servidor, de forma similar a como el campo offset de una estructura KeySymMapRec es un índice en el campo syms del mapa del cliente.

La razón por la que el campo acts es una lista lineal de XkbActions es para reducir el consumo de memoria asociado a un keymap. Dado que Xkb permite que teclas individuales tengan múltiples niveles de desplazamiento y un número diferente de grupos por tecla, una única matriz bidimensional de KeySyms sería potencialmente muy grande y dispersa. En su lugar, Xkb proporciona una pequeña matriz bidimensional de XkbActions para cada tecla. Para almacenar todas estas matrices individuales, Xkb concatena cada matriz en el campo acts del mapa del servidor.

Las estructuras de acciones de teclas consisten únicamente en campos de tipo char o unsigned char. Esto se hace para optimizar la transferencia de datos cuando el servidor envía bytes a través de la red. Si los campos son algo más que bytes, el servidor tiene que examinar todas las acciones e intercambiar cualquier campo que no sea de bytes. Como consisten únicamente en bytes, simplemente puede copiarlos.

XkbKeyActionEntry devuelve la acción de tecla correspondiente al grupo grp y al nivel de desplazamiento lvl de la tabla bidimensional de acciones de teclas asociadas a la tecla correspondiente a keycode.

ESTRUCTURAS

La estructura KeySymMapRec se define de la siguiente manera:

    #define XkbNumKbdGroups             4
    #define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
    typedef struct {                    /* mapa a keysyms para un único keycode */
        unsigned char       kt_index[XkbNumKbdGroups];  /* índice de tipo de teclado para cada grupo */
        unsigned char       group_info; /* número de grupos y manejo de grupos fuera de rango */
        unsigned char       width;      /* número máximo de niveles de desplazamiento para la tecla */
        unsigned short      offset;     /* índice a la tabla de keysym en el array syms */
} XkbSymMapRec, *XkbSymMapPtr;
