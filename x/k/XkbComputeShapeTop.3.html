NOMBRE

XkbComputeShapeTop - Determina el cuadro delimitador de la superficie superior de una forma

SINOPSIS

Bool XkbComputeShapeTop (XkbShapePtr shape, XkbBoundsPtr bounds_rtrn);

ARGUMENTOS

shape
forma a examinar
bounds_rtrn
rellenado con el cuadro delimitador de la forma

DESCRIPCIÓN

Xkb proporciona una serie de funciones de conveniencia para ayudar a usar la geometría de un teclado. Estas incluyen funciones para devolver el cuadro delimitador de la superficie superior de una forma y para actualizar el cuadro delimitador de una fila o sección de forma.

Una forma se compone de un número de contornos. Cada contorno es un polígono formado por un número de puntos. El cuadro delimitador de una forma es un rectángulo que contiene todos los contornos de esa forma.

XkbComputeShapeTop devuelve un BoundsRec que contiene dos coordenadas x e y. Estas coordenadas describen las esquinas de un rectángulo que contiene el contorno que describe la superficie superior de la forma. La superficie superior se define como el contorno aproximado si el campo approx de shape no es NULL. Si approx es NULL, la superficie superior se define como el último contorno en el array de contornos de shape. XkbComputeShapeTop devuelve False si shape es NULL o si no hay contornos para la forma; de lo contrario, devuelve True.

ESTRUCTURAS

typedef struct _XkbBounds {
	short	x1,y1;	/* esquina superior izquierda del cuadro, en mm/10 */
	short	x2,y2;	/* esquina inferior derecha del cuadro, en mm/10 */
} XkbBoundsRec, *XkbBoundsPtr;
