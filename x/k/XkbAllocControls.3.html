XkbAllocControls(3) FUNCIONES DE XKB XkbAllocControls(3)

NOMBRE

XkbAllocControls - Asigna una estructura XkbControlsRec en XkbDescRec

SINOPSIS

Estado XkbAllocControls (XkbDescPtr xkb, unsigned int which);

ARGUMENTOS

xkb
Descripción Xkb en la que asignar el registro de controles
which
Máscara de componentes de controles a asignar

DESCRIPCIÓN

La necesidad de asignar una estructura XkbControlsRec rara vez surge; Xkb crea una cuando una aplicación llama a XkbGetControls o una función relacionada. Para aquellas situaciones en las que no hay una estructura XkbControlsRec asignada en XkbDescRec, asígnela llamando a XkbAllocControls.

XkbAllocControls asigna el campo ctrls del parámetro xkb, inicializa todos los campos a cero y devuelve Success. Si el campo ctrls no es NULL, XkbAllocControls simplemente devuelve Success. Si xkb es NULL, XkbAllocControls informa un error BadMatch. Si el campo ctrls no pudo ser asignado, informa un error BadAlloc.

La máscara which especifica los campos individuales de la estructura ctrls a asignar y puede contener cualquiera de las máscaras válidas definidas en la Tabla 1. (¿DEBERÍA DEJARSE ESTE COMENTARIO????) Dado que ninguno de los controles existentes actualmente tiene estructuras asociadas con ellos, which es actualmente de poco valor práctico en esta llamada.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar controles para modificación y para habilitar y deshabilitar el control. Tenga en cuenta que el mismo bit de máscara se utiliza para especificar modificaciones generales a los parámetros utilizados para configurar el control (which), y para habilitar y deshabilitar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no pueden ser habilitados o deshabilitados.

VALORES DE RETORNO

SUCCESS
asigna el campo ctrls del parámetro xkb, inicializa todos los campos a cero


el campo ctrls no es NULL

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadMatch
No se pudo encontrar una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
