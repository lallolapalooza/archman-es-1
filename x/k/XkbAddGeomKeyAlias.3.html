XkbAddGeomKeyAlias(3) FUNCIONES DE XKB XkbAddGeomKeyAlias(3)

NOMBRE

XkbAddGeomKeyAlias - Añade un alias de tecla a una descripción de geometría de teclado existente

SINOPSIS

XkbKeyAliasPtr XkbAddGeomKeyAlias (XkbGeometryPtr geom, _Xconst char *alias, _Xconst char *real);

ARGUMENTOS

geom
geometría a actualizar
alias
alias a añadir
real
nombre real al que se enlazará el nuevo alias

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no cambian sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debe escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades de geometría. Una propiedad de geometría asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar propiedades de geometría como pistas, pero no son interpretadas por Xkb. Ninguna otra estructura de geometría hace referencia a las propiedades de geometría.

XkbAddGeomKeyAlias añade un alias de tecla con el valor alias a la geometría geom, y lo asocia con la tecla cuyo nombre real es real. XkbAddGeomKeyAlias devuelve NULL si alguno de los parámetros está vacío o si no pudo asignar espacio para el alias. Para asignar espacio para un número arbitrario de alias, utilice la función XkbAllocGeomKeyAliases.

ESTRUCTURAS

    typedef struct {
        char            real[XkbKeyNameLength];   /* este nombre de tecla debe estar en el array de teclas */
        char            alias[XkbKeyNameLength];  /* nombre de tecla simbólico como alias para la tecla */
    } XkbKeyAliasRec,*XkbKeyAliasPtr;
