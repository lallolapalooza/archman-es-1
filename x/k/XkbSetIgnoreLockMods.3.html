XkbSetIgnoreLockMods(3) FUNCIONES XKB XkbSetIgnoreLockMods(3)

NOMBRE

XkbSetIgnoreLockMods - Establece los modificadores que, si están bloqueados, no deben ser reportados en eventos coincidentes a grabs pasivos

SINOPSIS

Bool XkbSetIgnoreLockMods (Display *display, unsigned int device_spec, unsigned int affect_real, unsigned int real_values, unsigned int affect_virtual, unsigned int virtual_values);

ARGUMENTOS

display
conexión con el servidor X
device_spec
especificador de dispositivo, o XkbUseCoreKbd
affect_real
máscara de modificadores reales afectados por esta llamada
real_values
valores para los modificadores reales afectados (1=>establecer, 0=>desestablecer)
affect_virtual
máscara de modificadores virtuales afectados por esta llamada
virtual_values
valores para los modificadores virtuales afectados (1=>establecer, 0=>desestablecer)

DESCRIPCIÓN

El protocolo central no proporciona una forma de excluir modificadores específicos de los cálculos de grabs, con el resultado de que los modificadores de bloqueo a veces tienen efectos secundarios imprevistos.

El control IgnoreLockMods especifica los modificadores que deben excluirse de los cálculos de grabs. Estos modificadores tampoco se reportan en ningún evento central, excepto en los eventos KeyPress y KeyRelease que no activan un grab pasivo y que no ocurren mientras un grab está activo.

Manipule el control IgnoreLockMods a través del campo ignore_lock en la estructura XkbControlsRec, luego use XkbSetControls y XkbGetControls para consultar y cambiar este control. Alternativamente, use XkbSetIgnoreLockMods.

XkbSetIgnoreLockMods envía una solicitud al servidor para cambiar el control IgnoreLockMods del servidor. affect_real y real_values son máscaras de bits de modificadores reales que indican qué modificadores reales se agregarán y eliminarán del control IgnoreLockMods del servidor. Los modificadores seleccionados por affect_real y real_values se agregan al control IgnoreLockMods del servidor; aquellos seleccionados por affect_real pero no por real_values se eliminan del control IgnoreLockMods del servidor. Los valores válidos para affect_real y real_values consisten en cualquier combinación de los ocho bits de modificadores centrales: ShiftMask, LockMask, ControlMask, Mod1Mask - Mod5Mask. affect_virtual y virtual_values son máscaras de bits de modificadores virtuales que indican qué modificadores virtuales se agregarán y eliminarán del control IgnoreLockMods del servidor. Los modificadores seleccionados por affect_virtual y virtual_values se agregan al control IgnoreLockMods del servidor; aquellos seleccionados por affect_virtual pero no por virtual_values se eliminan del control IgnoreLockMods del servidor. Consulte a continuación una discusión sobre las máscaras de modificadores virtuales a usar en affect_virtual y virtual_values. XkbSetIgnoreLockMods no espera una respuesta del servidor. Devuelve True si la solicitud se envió y False en caso contrario.

Los modificadores virtuales se nombran convirtiendo su nombre de cadena a un Atom X y almacenando el Atom en el array names.vmods en una estructura XkbDescRec. La posición de un nombre Atom en el array names.vmods define la posición del bit utilizada para representar el modificador virtual y también el índice utilizado al acceder a la información del modificador virtual en los arrays: el nombre en la i-ésima entrada (relativa a 0) de names.vmods es el i-ésimo modificador virtual, representado por la máscara (1<<i). En todo Xkb, varias funciones tienen un parámetro que es una máscara que representa opciones de modificadores virtuales. En cada caso, el i-ésimo bit (relativo a 0) de la máscara representa el i-ésimo modificador virtual.

Para establecer el nombre de un modificador virtual, use XkbSetNames, usando XkbVirtualModNamesMask en which y el nombre en el argumento xkb; para recuperar los nombres de los indicadores, use XkbGetNames.

ESTRUCTURAS

La descripción completa de un teclado Xkb se da mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb.

typedef struct {
    struct _XDisplay * display;      /* conexión al servidor X */
    unsigned short     flags;        /* privado para Xkb, no modificar */
    unsigned short     device_spec;  /* dispositivo de interés */
    KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
    KeyCode            max_key_code; /* keycode máximo para el dispositivo */
    XkbControlsPtr     ctrls;        /* controles */
    XkbServerMapPtr    server;       /* mapa de teclado del servidor */
    XkbClientMapPtr    map;          /* mapa de teclado del cliente */
    XkbIndicatorPtr    indicators;   /* mapa de indicadores */
    XkbNamesPtr        names;        /* nombres para todos los componentes */
    XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
    XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;

El campo display apunta a una estructura de pantalla X. El campo flags es privado de la biblioteca: modificar flags puede dar resultados impredecibles. El campo device_spec especifica el identificador del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado central. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede ser devuelto por el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en XkbDescRec se muestran en la Tabla 1.

XkbSetIgnoreLockMods(3)

Manual del Programador de Xkb

XkbSetIgnoreLockMods - Establece los modificadores de bloqueo ignorados para un cliente.

Sintaxis

void XkbSetIgnoreLockMods(Display *display,
                              unsigned int ignore_mods,
                              unsigned int all_mods);

Descripción

La función XkbSetIgnoreLockMods permite a una aplicación especificar qué modificadores de bloqueo (como Bloq Mayús, Bloq Num, Bloq Despl) deben ser ignorados por el servidor Xkb. Cuando un modificador de bloqueo está en la lista de ignorados, no afectará al estado de los modificadores de la tecla correspondiente hasta que el usuario presione explícitamente la tecla de modificador no bloqueado.

display es un puntero a la estructura Display que representa la conexión con el servidor X.

ignore_mods es una máscara de bits que especifica los modificadores de bloqueo que deben ser ignorados. Por ejemplo, XkbUseCoreBom (que define XkbLC_Lock) se puede usar para ignorar todos los modificadores de bloqueo.

all_mods es una máscara de bits que especifica todos los modificadores que se pueden ver afectados por la configuración de bloqueo. Normalmente se establece en XkbAllModifiers.

Ejemplo

#include <X11/Xlib.h>
#include <X11/X.h>
#include <X11/Xutil.h>
#include <X11/keysym.h>
#include <X11/Xos.h>
#include <X11/Xatom.h>
#include <X11/Xmd.h>
#include <X11/Xlib.h>
#include <X11/extensions/XKB.h>

int main() {
    Display *display;

    display = XOpenDisplay(NULL);
    if (!display) {
        fprintf(stderr, "No se pudo abrir la pantalla X.\n");
        return 1;
    }

    // Ignorar el modificador Bloq Mayús
    XkbSetIgnoreLockMods(display, XkbLC_Lock, XkbAllModifiers);

    XCloseDisplay(display);
    return 0;
}

Devoluciones

Esta función no devuelve ningún valor.
