XkbFreeClientMap(3)

Paquete: libx11

Licencias: MIT AND X11

XkbFreeClientMap(3) FUNCIONES DE XKB XkbFreeClientMap(3)

NOMBRE

XkbFreeClientMap - Liberar memoria usada por el miembro del mapa del cliente de una estructura XkbDescRec

SINOPSIS

void XkbFreeClientMap (XkbDescPtr xkb, unsigned int which, Bool free_all);

ARGUMENTOS

xkb
descripción del teclado que contiene el mapa del cliente a liberar
which
máscara que identifica los componentes del mapa a liberar
free_all
True => liberar todos los componentes del cliente y el mapa en sí

DESCRIPCIÓN

XkbFreeClientMap libera los componentes del mapa del cliente especificados por which en la estructura XkbDescRec especificada por el parámetro xkb y establece los valores de los componentes de la estructura correspondientes a NULL. El parámetro which especifica una combinación de las máscaras del mapa del cliente que se muestran en la Tabla 1.

Si free_all es True, se ignora which; XkbFreeClientMap libera cada componente de estructura no NULL en el mapa del cliente, libera la estructura XkbClientMapRec referenciada por el miembro map del parámetro xkb y establece el miembro map a NULL.

Tabla 1 Máscaras de XkbAllocClientMap
Máscara Efecto
XkbKeyTypesMask El campo type_count especifica el número de entradas a preasignar para el campo types del mapa del cliente. Si el campo type_count es menor que XkbNumRequiredTypes, devuelve BadValue.
XkbKeySymsMask Los campos min_key_code y max_key_code del parámetro xkb se utilizan para asignar los campos syms y key_sym_map del mapa del cliente. Los campos se asignan para contener el número máximo de entradas necesarias para max_key_code - min_key_code + 1 teclas.
XkbModifierMapMask Los campos min_key_code y max_key_code del parámetro xkb se utilizan para asignar el campo modmap del mapa del cliente. El campo se asigna para contener el número máximo de entradas necesarias para max_key_code - min_key_code + 1 teclas.

NOTA: Los campos min_key_code y max_key_code del parámetro xkb deben ser valores legales si las máscaras XkbKeySymsMask o XkbModifierMapMask están establecidas en el parámetro which. Si no son válidos, XkbAllocClientMap devuelve BadValue.

ESTRUCTURAS

La descripción completa de un teclado Xkb se da mediante una XkbDescRec. Las estructuras de componentes en XkbDescRec representan los componentes principales de Xkb.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado de Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de claves del servidor */
   XkbClientMapPtr    map;          /* mapa de claves del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de pantalla X. El campo flags es privado de la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede ser devuelto por el teclado.

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en XkbDescRec se muestran en la Tabla 2.

Tabla 2 Bits de máscara para XkbDescRec
Bit de máscara Campo XkbDescRec Valor
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Todos los campos (0x7f)

El campo map de la descripción completa del teclado Xkb es un puntero al mapa del cliente Xkb, que es de tipo XkbClientMapRec:

   typedef struct {                   /* Mapa del cliente */
      unsigned char     size_types;   /* # entradas ocupadas en types */
      unsigned char     num_types;    /* # entradas en types */
      XkbKeyTypePtr     types;        /* vector de tipos de clave usados por este mapakey */
      unsigned short    size_syms;    /* longitud del array syms */
      unsigned short    num_syms;     /* # entradas en syms */
      KeySym *          syms;         /* tablas lineales 2d de keysyms, 1 por clave */
      XkbSymMapPtr      key_sym_map;  /* 1 por keycode, mapea keycode a syms */
      unsigned char *   modmap;       /* 1 por keycode, mods reales enlazados a clave */
} XkbClientMapRec, *XkbClientMapPtr;
