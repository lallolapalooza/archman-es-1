NOMBRE

XkbFreeGeomShapes - Liberar formas de geometría

SINOPSIS

void XkbFreeGeomShapes (XkbGeometryPtr geom, int first, int count, Bool free_all);

ARGUMENTOS

geom
geometría en la cual se deben liberar las formas
first
primera forma a liberar
count
número de formas a liberar
free_all
True => se liberan todas las formas

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted llenar los valores explícitamente en su código. Estas funciones de asignación aumentan sz_* pero nunca tocan num_* (a menos que haya un error de asignación, en cuyo caso restablecen tanto sz_* como num_* a cero). Estas funciones devuelven Success si tienen éxito, BadAlloc si no pueden asignar espacio, o BadValue si un parámetro no es el esperado.

Si free_all es True, se liberan todas las formas de la geometría independientemente de los valores de first y count. De lo contrario, se liberan count formas, comenzando con la forma especificada por first.

VALORES DE RETORNO

Success
La función XkbFreeGeomShapes devuelve Success cuando no hay errores de asignación o de argumentos.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango
