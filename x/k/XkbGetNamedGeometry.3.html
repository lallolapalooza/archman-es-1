NOMBRE

XkbGetNamedGeometry - Carga una descripción de la geometría del teclado desde esta base de datos por nombre

SINOPSIS

Status XkbGetNamedGeometry (Display *dpy, XkbDescPtr xkb, Atom name);

ARGUMENTOS

dpy
conexión al servidor X
xkb
descripción del teclado en la que se debe cargar la geometría
name
nombre de la geometría a cargar

DESCRIPCIÓN

También es posible cargar una geometría de teclado por nombre. El servidor X mantiene una base de datos de componentes del teclado (ver más abajo).

XkbGetNamedGeometry puede devolver BadName si el nombre no se puede encontrar.

El servidor X mantiene una base de datos de componentes de teclado, identificados por el tipo de componente. La base de datos contiene toda la información necesaria para construir una descripción completa del teclado para un dispositivo particular, así como para ensamblar descripciones parciales. La Tabla 1 identifica los tipos de componentes y el tipo de información que contienen.

Tabla 1 Componentes de Teclado de la Base de Datos del Servidor
Componente Contenido Principal del Componente Puede contener también
Tipo
Mapa de Teclado Descripción completa del teclado. Normalmente se ensambla usando un componente completo de cada uno de los otros tipos.
Códigos de Tecla Nombre simbólico para cada tecla. Mínimo y máximo de códigos de tecla legales. Alias para algunas teclas. Nombres simbólicos para indicadores. Descripción de indicadores físicamente presentes.
Tipos Tipos de tecla Enlaces de modificadores reales y nombres simbólicos para algunos modificadores virtuales.
Compatibilidad Reglas utilizadas para asignar acciones a las teclas. Mapas para algunos indicadores. Enlaces de modificadores reales y nombres simbólicos para algunos modificadores virtuales.
Símbolos Mapeo de símbolos para las teclas del teclado. Mapeo de modificadores. Nombres simbólicos para grupos. Acciones y comportamientos explícitos para algunas teclas. Enlaces de modificadores reales y nombres simbólicos para algunos modificadores virtuales.
Geometría Diseño del teclado. Alias para algunas teclas; anula alias de componentes de códigos de tecla. Nombres simbólicos para algunos indicadores. Descripción de indicadores físicamente presentes.

Mientras que un mapa de teclado es una entrada de base de datos para una descripción completa del teclado, y por lo tanto lógicamente diferente de las entradas de la base de datos de componentes individuales, las reglas para procesar las entradas del mapa de teclado son idénticas a las de los componentes individuales. En la discusión que sigue, el término componente se utiliza para referirse a componentes individuales o a un mapa de teclado.

Puede haber múltiples entradas para cada uno de los tipos de componentes. Una entrada puede ser *completa* o *parcial*. Las entradas parciales describen solo una parte del componente del teclado correspondiente y están diseñadas para combinarse con otras entradas del mismo tipo para formar una entrada completa.

Por ejemplo, un mapa de símbolos parcial podría describir las diferencias entre un teclado ASCII común y algún diseño nacional. Tal mapa parcial no es útil por sí solo porque no incluye aquellos símbolos que son iguales en ambos diseños, ASCII y nacional (como las teclas de función). Por otro lado, este mapa parcial se puede usar para configurar *cualquier* teclado ASCII para usar un diseño nacional.

Cuando se construye una descripción de teclado, los componentes se procesan en el orden en que aparecen en la Tabla 1; las definiciones posteriores anulan las anteriores.
