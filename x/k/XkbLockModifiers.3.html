NOMBRE

XkbLockModifiers - Bloquea y desbloquea cualquiera de los ocho modificadores reales del teclado

SINOPSIS

Bool XkbLockModifiers (Display *display, unsigned int device_spec, unsigned int affect, unsigned int values);

ARGUMENTOS

display
conexión al servidor X
device_spec
ID del dispositivo, o XkbUseCoreKbd
affect
máscara de los modificadores reales cuyo estado de bloqueo se va a cambiar
values
1 => bloquear, 0 => desbloquear; solo para modificadores seleccionados por affect

DESCRIPCIÓN

XkbLockModifiers envía una solicitud al servidor para bloquear los modificadores reales seleccionados por affect y values y para desbloquear los modificadores reales seleccionados por affect, pero no seleccionados por values. XkbLockModifiers no espera una respuesta del servidor. Devuelve True si la solicitud se envió y False en caso contrario.

Las funciones de esta sección que cambian el uso de modificadores utilizan una máscara en el parámetro affect. Es una OR inclusiva a nivel de bits de las máscaras de modificadores legales:

Tabla 1 Máscaras de modificadores reales
Máscara
ShiftMask
LockMask
ControlMask
Mod1Mask
Mod2Mask
Mod3Mask
Mod4Mask
Mod5Mask

VALORES DE RETORNO

True
La función XkbLockModifiers devuelve True si se envía una solicitud al servidor para bloquear los modificadores reales seleccionados por affect y values y para desbloquear los modificadores reales seleccionados por affect, pero no seleccionados por values.
False
La función XkbLockModifiers devuelve False si la solicitud no se envió.
