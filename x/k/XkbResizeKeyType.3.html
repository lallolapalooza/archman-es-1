XkbResizeKeyType(3) FUNCIONES XKB XkbResizeKeyType(3)

NOMBRE

XkbResizeKeyType - Cambia el número de niveles en un tipo de tecla

SINOPSIS

Status XkbResizeKeyType (XkbDescPtr xkb, int type_ndx, int map_count, Bool want_preserve, int new_num_lvls);

ARGUMENTOS

xkb
descripción del teclado que contiene el mapa del cliente a actualizar
type_ndx
índice en xkb->map->types del tipo a cambiar
map_count
número total de entradas de mapa necesarias para el tipo
want_preserve
True => la lista de modificadores preservados es necesaria
new_num_lvls
nuevo número máximo de niveles para el tipo

DESCRIPCIÓN

XkbResizeKeyType cambia el tipo especificado por xkb->map->types[type_ndx], y reasigna los símbolos y acciones vinculados a todas las teclas que usan el tipo, si es necesario. XkbResizeKeyType actualiza solo la copia local de los tipos en xkb; para actualizar la copia del servidor para el dispositivo físico, usa XkbSetMap o XkbChangeMap después de llamar a XkbResizeKeyType.

El parámetro map_count especifica el número total de entradas de mapa necesarias para el tipo, y puede ser cero o mayor. Si map_count es cero, XkbResizeKeyType libera el mapa existente y las entradas preserve para el tipo si existen y las establece a NULL.

El parámetro want_preserve especifica si se debe crear una lista preserve para la tecla. Si want_preserve es True, la lista preserve con map_count entradas se asigna o se reasigna si ya existe. De lo contrario, si want_preserve es False, el campo preserve se libera si es necesario y se establece a NULL.

El parámetro new_num_lvls especifica el nuevo número máximo de niveles de desplazamiento para el tipo y se utiliza para calcular y redimensionar los símbolos y acciones vinculados a todas las teclas que usan el tipo.

Si type_ndx no especifica un tipo legal, new_num_lvls es menor que 1, o map_count es menor que cero, XkbResizeKeyType devuelve BadValue. Si XkbResizeKeyType encuentra algún problema con la asignación, devuelve BadAlloc. De lo contrario, devuelve Success.

VALORES DE RETORNO

Success
La función XkbResizeKeyType devuelve Success si type_ndx especifica un tipo legal, new_num_lvls es mayor que cero y map_count es positivo.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadValue
Un argumento está fuera de rango

VER TAMBIÉN

XkbChangeMap(3), XkbSetMap(3)
