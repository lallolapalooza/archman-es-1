XkbInitCanonicalKeyTypes(3)

Paquete: libx11

Licencias: MIT AND X11

XkbInitCanonicalKeyTypes(3) FUNCIONES XKB XkbInitCanonicalKeyTypes(3)

NOMBRE

XkbInitCanonicalKeyTypes - Establece las definiciones de los tipos de tecla canónicos en un mapa de cliente a sus valores predeterminados

SINOPSIS

Status XkbInitCanonicalKeyTypes (XkbDescPtr xkb, unsigned int which, int keypadVMod);

ARGUMENTOS

xkb
descripción del teclado que contiene el mapa de cliente a inicializar
which
máscara de tipos a inicializar
keypadVMod
índice del modificador virtual NumLock

DESCRIPCIÓN

XkbInitCanonicalKeyTypes inicializa los primeros XkbNumRequiredTypes tipos de tecla del teclado especificado por el parámetro xkb a sus valores predeterminados. El parámetro which especifica qué tipos de tecla canónicos inicializar y es una combinación OR inclusiva a nivel de bits de las siguientes máscaras: XkbOneLevelMask, XkbTwoLevelMask, XkbAlphabeticMask y XkbKeypadMask. Solo se inicializan los tipos canónicos especificados por la máscara which.

Si XkbKeypadMask está configurada en el parámetro which, XkbInitCanonicalKeyTypes busca el modificador virtual llamado NumLock para determinar qué modificador virtual usar al inicializar el tipo de tecla KEYPAD. Si el modificador virtual NumLock no existe, XkbInitCanonicalKeyTypes lo crea.

XkbInitCanonicalKeyTypes normalmente devuelve Success. Devuelve BadAccess si la extensión Xkb no se ha inicializado correctamente y BadAccess si el parámetro xkb no es válido.

VALORES DE RETORNO

Success
La función XkbInitCanonicalKeyTypes devuelve Success si la extensión Xkb se ha inicializado correctamente y el parámetro xkb es válido.

DIAGNÓSTICOS

BadAccess
La extensión Xkb no se ha inicializado correctamente
