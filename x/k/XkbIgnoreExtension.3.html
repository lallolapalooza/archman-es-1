XkbIgnoreExtension(3) FUNCIONES XKB XkbIgnoreExtension(3)

NOMBRE

XkbIgnoreExtension - Evita que las funciones de teclado principales de la biblioteca X utilicen la Extensión de Teclado X

SINOPSIS

Bool XkbIgnoreExtension (Bool *ignore);

ARGUMENTOS

ignore
True significa ignorar la extensión

DESCRIPCIÓN

Si un servidor soporta la extensión Xkb, la biblioteca X normalmente implementa las funciones de teclado preXkb utilizando la descripción y el estado del teclado Xkb. El estado del teclado Xkb del servidor puede diferir del estado del teclado preXkb. Esta diferencia no afecta a la mayoría de los clientes, pero hay excepciones. Para permitir que estos clientes funcionen correctamente, puede indicar a la extensión que no utilice la funcionalidad Xkb.

Llame a XkbIgnoreExtension para evitar que las funciones de teclado principales de la biblioteca X utilicen la Extensión de Teclado X. Debe llamar a XkbIgnoreExtension antes de abrir una conexión de servidor; Xkb no proporciona una forma de habilitar o deshabilitar el uso de la extensión una vez establecida la conexión.

XkbIgnoreExtension indica a la biblioteca X si debe utilizar la Extensión de Teclado X en cualquier conexión de pantalla X abierta posteriormente. Si ignore es True, la biblioteca no inicializa la extensión Xkb al abrir una nueva pantalla. Esto obliga al servidor X a utilizar el modo de compatibilidad y a comunicarse con el cliente utilizando solo solicitudes y eventos del protocolo principal. Si ignore es False, la biblioteca trata las llamadas posteriores a XOpenDisplay normalmente y utiliza las solicitudes, eventos y estado de la extensión Xkb. No utilice explícitamente Xkb en una conexión para la que esté deshabilitada. XkbIgnoreExtension devuelve False si no pudo aplicar la solicitud de ignorar.

VALORES DE RETORNO

True
XkbIgnoreExtension devuelve True si
False
La función XkbIgnoreExtension devuelve False si no pudo aplicar la solicitud de ignorar.
