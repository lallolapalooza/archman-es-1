XkbGetCompatMap(3) FUNCIONES DE XKB XkbGetCompatMap(3)

NOMBRE

XkbGetCompatMap - Obtener cualquier combinación de los componentes del mapa de compatibilidad actual del servidor

SINOPSIS

Status XkbGetCompatMap (Display *display, unsigned int which, XkbDescRec *xkb);

ARGUMENTOS

display
conexión al servidor
which
máscara de componentes del mapa de compatibilidad a obtener
xkb
descripción del teclado donde se colocan los resultados

DESCRIPCIÓN

Cuando otro cliente modifica el mapa de compatibilidad, se te notifica si has seleccionado los eventos XkbCompatMapNotify. XkbGetCompatMap es particularmente útil cuando recibes un evento de este tipo, ya que te permite actualizar la versión del mapa de compatibilidad de tu programa para que coincida con la versión modificada que ahora se encuentra en el servidor. Si tu programa está tratando con múltiples servidores y necesita configurarlos de manera similar, el mapa de compatibilidad actualizado puede utilizarse para reconfigurar otros servidores.

XkbGetCompatMap obtiene los componentes del mapa de compatibilidad especificados en which del servidor especificado por display y los coloca en la estructura compat de la descripción del teclado xkb. Los valores válidos para which son una combinación OR inclusiva de los valores que se muestran en la Tabla 1.

Tabla 1 Máscaras de Componentes del Mapa de Compatibilidad
Máscara Valor Afectando
XkbSymInterpMask (1<<0) Interpretaciones de símbolos
XkbGroupCompatMask (1<<1) Mapas de grupos
XkbAllCompatMask (0x3) Todos los componentes del mapa de compatibilidad

Si no se ha asignado ninguna estructura de mapa de compatibilidad en xkb al inicio, XkbGetCompatMap asignará una. Si ya existe una, su contenido se sobrescribirá con los resultados devueltos.

XkbGetCompatMap obtiene información del mapa de compatibilidad para el dispositivo especificado por el campo device_spec de xkb. A menos que hayas modificado específicamente este campo, es el dispositivo de teclado predeterminado. XkbGetCompatMap devuelve Success si tiene éxito, BadAlloc si no puede obtener el almacenamiento necesario para los valores de retorno o el espacio de trabajo, BadMatch si el campo dpy del argumento xkb no es NULL y no coincide con el argumento display, y BadLength bajo ciertas condiciones causadas por errores del servidor o de la implementación de Xkb.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadLength
La longitud de una solicitud es menor o mayor de lo requerido para contener mínimamente los argumentos
BadMatch
No se disponía de una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
