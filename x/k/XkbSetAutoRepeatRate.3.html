Paquete: libx11

Licencias: MIT AND X11

XkbSetAutoRepeatRate(3) FUNCIONES XKB XkbSetAutoRepeatRate(3)

NOMBRE

XkbSetAutoRepeatRate - Establece los atributos del control RepeatKeys para un dispositivo de teclado

SINOPSIS

Bool XkbSetAutoRepeatRate (Display *display, unsigned int device_spec, unsigned int timeout, unsigned int interval);

ARGUMENTOS

display
conexión al servidor X
device_spec
dispositivo a configurar, o XkbUseCoreKbd
timeout
retraso inicial, ms
interval
retraso entre repeticiones, ms

DESCRIPCIÓN

El protocolo principal solo permite controlar si el teclado completo o teclas individuales deben repetirse automáticamente cuando se mantienen presionadas. RepeatKeys es un control booleano que amplía esta capacidad al añadir control sobre el retraso hasta que una tecla comience a repetirse y la velocidad a la que se repite. RepeatKeys está acoplado al control de repetición automática principal: cuando RepeatKeys está habilitado o deshabilitado, la repetición automática principal se habilita o deshabilita y viceversa.

Las teclas de repetición automática se controlan mediante dos atributos. El primero, timeout, es el retraso después de la pulsación inicial de una tecla de repetición automática y el primer evento de repetición generado. El segundo, interval, es el retraso entre todos los eventos de repetición generados subsiguientes. Al igual que con todos los controles booleanos, la configuración de los atributos que determinan cómo funciona el control no habilita automáticamente el control en su conjunto.

XkbSetAutoRepeatRate envía una solicitud al servidor X para configurar los atributos del control AutoRepeat a los valores especificados en timeout e interval.

XkbSetAutoRepeatRate no espera una respuesta; normalmente devuelve True. Especificar un valor cero para timeout o interval provoca que el servidor genere un error de protocolo BadValue. Si no hay una versión compatible de la extensión Xkb disponible en el servidor, XkbSetAutoRepeatRate devuelve False.

VALORES DE RETORNO

True
La función XkbSetAutoRepeatRate devuelve True normalmente.
False
La función XkbSetAutoRepeatRate devuelve False si no hay una versión compatible de la extensión Xkb disponible en el servidor.

DIAGNÓSTICOS

BadValue
Un argumento está fuera de rango
