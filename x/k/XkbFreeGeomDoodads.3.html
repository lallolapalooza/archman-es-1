NOMBRE

XkbFreeGeomDoodads - Liberar elementos gráficos de geometría

SINOPSIS

void XkbFreeGeomDoodads (XkbDoodadPtr doodads, int count, Bool free_all);

ARGUMENTOS

doodads
elementos gráficos a liberar
count
número de elementos gráficos a liberar
free_all
Verdadero => se liberan todos los elementos gráficos

DESCRIPCIÓN

Xkb proporciona una serie de funciones para asignar y liberar subcomponentes de una geometría de teclado. Utilice estas funciones para crear o modificar geometrías de teclado. Tenga en cuenta que estas funciones simplemente asignan espacio para el(los) nuevo(s) elemento(s), y depende de usted completar los valores explícitamente en su código. Estas funciones de asignación aumentan sz_* pero nunca tocan num_* (a menos que haya un error de asignación, en cuyo caso restablecen tanto sz_* como num_* a cero). Estas funciones devuelven Éxito si tienen éxito, Error de Asignación si no pueden asignar espacio, o Valor Erróneo si un parámetro no es el esperado.

Si free_all es Verdadero, se liberan todos los elementos gráficos del arreglo, independientemente del valor de count. De lo contrario, se liberan count elementos gráficos.

VALORES DE RETORNO

Éxito
La función XkbFreeGeomDoodads devuelve Éxito si no hay errores de asignación.

DIAGNÓSTICOS

Error de Asignación
No se pudo asignar almacenamiento
Valor Erróneo
Un argumento está fuera de rango
