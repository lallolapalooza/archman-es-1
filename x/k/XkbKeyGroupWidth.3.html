NOMBRE

XkbKeyGroupWidth - Calcula el ancho del tipo asociado al grupo grp para la tecla que corresponde a keycode

SINOPSIS

int XkbKeyGroupWidth (XkbDescPtr xkb, KeyCode keycode, int grp);

ARGUMENTOS

xkb
Descripción Xkb de interés
keycode
keycode de interés
grp
grupo de interés

DESCRIPCIÓN

El ancho de la tecla y el número de grupos asociados a una tecla se utilizan para formar una pequeña matriz bidimensional de KeySyms para una tecla. Esta matriz puede tener tamaños diferentes para teclas distintas. La matriz para una única tecla se almacena como una lista lineal, en orden primero por filas. Las matrices para todas las teclas se almacenan en el campo syms del mapa del cliente. Hay una fila por cada grupo asociado a una tecla y una columna por cada nivel. El índice que corresponde a un grupo y nivel de desplazamiento dados se calcula como:

     idx = group_index * key_width + shift_level

El campo offset de la entrada key_sym_map para una tecla se utiliza para acceder al principio de la matriz.

XkbKeyGroupWidth calcula el ancho del tipo asociado al grupo grp para la tecla correspondiente a keycode.
