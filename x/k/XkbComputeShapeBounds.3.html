XkbComputeShapeBounds(3) FUNCIONES DE XKB XkbComputeShapeBounds(3)

NOMBRE

XkbComputeShapeBounds - Actualiza el cuadro delimitador de una forma

SINOPSIS

Bool XkbComputeShapeBounds (XkbShapePtr forma);

ARGUMENTOS

forma
forma a examinar

DESCRIPCIÓN

Xkb proporciona una serie de funciones de conveniencia para ayudar a usar la geometría de un teclado. Estas incluyen funciones para devolver el cuadro delimitador de la superficie superior de una forma y para actualizar el cuadro delimitador de una fila o sección de forma.

Una forma se compone de un número de contornos. Cada contorno es un polígono formado por un número de puntos. El cuadro delimitador de una forma es un rectángulo que contiene todos los contornos de esa forma.

Un ShapeRec contiene un BoundsRec que describe los límites de la forma. Si agregas o eliminas un contorno de una forma, el cuadro delimitador debe actualizarse.

XkbComputeShapeBounds actualiza el BoundsRec contenido en la forma examinando todos los contornos de la forma y estableciendo el BoundsRec a los valores mínimos de x e y, y máximos de x e y encontrados en esos contornos. XkbComputeShapeBounds devuelve False si forma es NULL o si no hay contornos para la forma; de lo contrario, devuelve True.

Si agrega o elimina una tecla de una fila, o si actualiza la forma de una de las teclas de esa fila, es posible que deba actualizar el cuadro delimitador de esa fila. Para actualizar el cuadro delimitador de una fila, use XkbComputeRowBounds.

ESTRUCTURAS

typedef struct _XkbShape {
    Atom           name;         /* nombre de la forma */
    unsigned short num_outlines; /* número de contornos para la forma */
    unsigned short sz_outlines;  /* tamaño del array de contornos */
    XkbOutlinePtr  outlines;     /* array de contornos para la forma */
    XkbOutlinePtr  approx;       /* puntero al array del contorno aproximado */
    XkbOutlinePtr  primary;      /* puntero al array del contorno primario */
    XkbBoundsRec   bounds;       /* cuadro delimitador para la forma; abarca todos los contornos */
} XkbShapeRec, *XkbShapePtr;
typedef struct _XkbBounds {
    short	x1,y1;	/* esquina superior izquierda de los límites, en mm/10 */
    short	x2,y2;	/* esquina inferior derecha de los límites, en mm/10 */
} XkbBoundsRec, *XkbBoundsPtr;
