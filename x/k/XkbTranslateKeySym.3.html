XkbTranslateKeySym(3) FUNCIONES XKB XkbTranslateKeySym(3)

NOMBRE

XkbTranslateKeySym - Encuentra la cadena y el símbolo asociados con un keysym para un estado de teclado dado

SINOPSIS

int XkbTranslateKeySym (Display *dpy, KeySym *sym_inout, unsigned int mods, char *buf, int nbytes, int *extra_rtrn);

ARGUMENTOS

dpy
conexión al servidor X
sym_inout
símbolo a traducir; resultado de la traducción
mods
modificadores a aplicar a sym_inout
buf
buffer en el que se escribe la cadena devuelta
nbytes
tamaño del buffer en bytes
extra_rtrn
número de bytes de desbordamiento

DESCRIPCIÓN

XkbTranslateKeySym aplica las transformaciones especificadas en mods al símbolo especificado por sym_inout. Devuelve en buf la cadena, si la hay, asociada con el keysym para la configuración regional actual. Si las transformaciones en mods cambian el keysym, sym_inout se actualiza en consecuencia. Si la cadena devuelta es más grande que nbytes, se devuelve en extra_rtrn el número de bytes que no caben en el buffer. XkbTranslateKeySym devuelve el número de bytes que colocó en buf.

VALORES DEVUELTOS

buf
Devuelve la cadena, si la hay, asociada con el keysym para la configuración regional actual.
