XkbGetNames(3) FUNCIONES XKB XkbGetNames(3)

NOMBRE

XkbGetNames - Obtener nombres simbólicos del servidor

SINOPSIS

Status XkbGetNames (Display *dpy, unsigned int which, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara de nombres o componentes de mapa a actualizar
xkb
descripción del teclado a actualizar

DESCRIPCIÓN

XkbGetNames recupera nombres simbólicos para los componentes de la extensión del teclado del servidor X. El parámetro which especifica los componentes de nombre a actualizar en el parámetro xkb, y es el OR inclusivo a nivel de bits de las máscaras de nombres válidas definidas en la Tabla 1.

Tabla 1 Máscaras de Nombres Simbólicos
Bit de Máscara Valor Teclado Campo
Componente
XkbKeycodesNameMask (1<<0) Xkb->names keycodes
XkbGeometryNameMask (1<<1) Xkb->names geometry
XkbSymbolsNameMask (1<<2) Xkb->names symbols
XkbPhysSymbolsNameMask (1<<3) Xkb->names phys_symbols
XkbTypesNameMask (1<<4) Xkb->names type
XkbCompatNameMask (1<<5) Xkb->names compat
XkbKeyTypeNamesMask (1<<6) Xkb->map type[*].name
XkbKTLevelNamesMask (1<<7) Xkb->map type[*].lvl_names[*]
XkbIndicatorNamesMask (1<<8) Xkb->names indicators[*]
XkbKeyNamesMask (1<<9) Xkb->names keys[*], num_keys
XkbKeyAliasesMask (1<<10) Xkb->names key_aliases[*], num_key_aliases
XkbVirtualModNamesMask (1<<11) Xkb->names vmods[*]
XkbGroupNamesMask (1<<12) Xkb->names groups[*]
XkbRGNamesMask (1<<13) Xkb->names radio_groups[*], num_rg
XkbComponentNamesMask (0x3f) Xkb->names keycodes,
geometry,
symbols,
physical symbols,
types, y
mapa de compatibilidad
XkbAllNamesMask (0x3fff) Xkb->names todos los componentes de nombre

Si el campo names de la descripción del teclado xkb es NULL, XkbGetNames asigna e inicializa el componente names de la descripción del teclado antes de obtener los valores especificados por which. Si el campo names de xkb no es NULL, XkbGetNames obtiene los valores especificados por which y los copia en la descripción del teclado Xkb.

Si el componente map del parámetro xkb es NULL, XkbGetNames no recupera los nombres de tipo o de nivel de cambio, incluso si XkbKeyTypeNamesMask o XkbKTLevelNamesMask están establecidos en which.

XkbGetNames puede devolver Success, o errores BadAlloc, BadLength, BadMatch y BadImplementation.

Para liberar los nombres simbólicos, use XkbFreeNames.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadImplementation
Respuesta inválida del servidor
BadLength
La longitud de una solicitud es más corta o más larga de lo necesario para contener mínimamente los argumentos
BadMatch
No había una versión compatible de Xkb disponible en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera

VER TAMBIÉN
