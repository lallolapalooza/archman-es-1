NOMBRE

XkbAddGeomShape - Añadir una forma a la geometría de un teclado

SINOPSIS

XkbShapePtr XkbAddGeomShape (XkbGeometryPtr geom, Atom name, int sz_outlines);

ARGUMENTOS

geom
geometría a actualizar
name
nombre de la nueva forma
sz_outlines
número de contornos a reservar

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no modifican sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debes escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades de geometría. Una propiedad de geometría asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar las propiedades de geometría como pistas, pero Xkb no las interpreta. Ninguna otra estructura de geometría hace referencia a las propiedades de geometría.

Una geometría contiene un número arbitrario de formas, cada una de las cuales está compuesta por un número arbitrario de contornos. XkbAddGeomShape añade una forma a una geometría geom asignando espacio para sz_outlines contornos para ella y dándole el nombre especificado por name. Si una forma con el nombre name ya existe en la geometría, se devuelve un puntero a la forma existente. XkbAddGeomShape devuelve NULL si alguno de los parámetros está vacío o si no pudo asignar espacio. Para asignar espacio para un número arbitrario de formas de geometría, usa XkbAllocGeomShapes.

ESTRUCTURAS

    typedef struct _XkbShape {
        Atom              name;           /* nombre de la forma */
        unsigned short    num_outlines;   /* número de contornos para la forma */
        unsigned short    sz_outlines;    /* tamaño del array de contornos */
        XkbOutlinePtr     outlines;       /* array de contornos para la forma */
        XkbOutlinePtr     approx;         /* puntero dentro del array al contorno de aproximación */
        XkbOutlinePtr     primary;        /* puntero dentro del array al contorno primario */
        XkbBoundsRec      bounds;         /* caja delimitadora para la forma; abarca todos los contornos */
    } XkbShapeRec, *XkbShapePtr;
