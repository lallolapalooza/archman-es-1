XkbGetKeyTypes(3) FUNCIONES XKB XkbGetKeyTypes(3)

NOMBRE

XkbGetKeyTypes - Obtiene la lista de tipos de teclas disponibles en el mapeo del teclado del servidor

SINOPSIS

Status XkbGetKeyTypes (Display *dpy, unsigned int first, unsigned int num, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
first
índice del primer tipo a obtener, 0 => 1er tipo
num
número de tipos de teclas a devolver
xkb
descripción del teclado que contiene el mapa del cliente a actualizar

DESCRIPCIÓN

XkbGetKeyTypes consulta al servidor los tipos deseados, espera una respuesta y devuelve los tipos deseados en xkb->map->types. Si tiene éxito, devuelve Success.

XkbGetKeyTypes devuelve BadAccess si la extensión Xkb no se ha inicializado correctamente y BadValue si la combinación de first y num da como resultado números fuera del rango válido.

NOTA: XkbGetKeyTypes se utiliza para obtener descripciones de los tipos de teclas en sí, no de los tipos de teclas enlazados a teclas individuales. Para obtener los tipos de teclas enlazados a una tecla individual, consulte el campo key_sym_map del mapa del cliente.

DIAGNÓSTICOS

BadAccess
La extensión Xkb no se ha inicializado correctamente
BadValue
Un argumento está fuera de rango

VER TAMBIÉN

XkbKeyKeyType(3), XkbKeyKeyTypeIndex(3)
