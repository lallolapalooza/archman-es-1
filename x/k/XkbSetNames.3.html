NOMBRE

XkbSetNames - Cambia los nombres simbólicos en el servidor

SINOPSIS

Bool XkbSetNames (Display *dpy, unsigned int which, unsigned int first_type, unsigned int num_types, XkbDescPtr xkb);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara de nombres o componentes del mapa a cambiar
first_type
primer tipo cuyo nombre se va a cambiar
num_types
número de tipos para los que se van a cambiar los nombres
xkb
descripción del teclado de donde se tomarán los nombres

DESCRIPCIÓN

Para cambiar los nombres simbólicos en el servidor, primero modifica una copia local de la descripción del teclado y luego usa XkbSetNames o, para ahorrar tráfico de red, usa una estructura XkbNameChangesRec y llama a XkbChangeNames para descargar los cambios al servidor. XkbSetNames y XkbChangeNames pueden generar errores BadAlloc, BadAtom, BadLength, BadMatch y BadImplementation.

Usa XkbSetNames para cambiar muchos nombres a la vez. Por cada bit establecido en which, XkbSetNames toma el valor correspondiente (o valores en el caso de arreglos) de la descripción del teclado xkb y lo envía al servidor.

Los argumentos first_type y num_types se usan solo si XkbKeyTypeNamesMask o XkbKTLevelNamesMask están establecidos en which y especifican un subconjunto de los tipos para los cuales se van a cambiar los nombres correspondientes. Si uno o ambos de estos bits de máscara están establecidos pero los tipos especificados son ilegales, XkbSetNames devuelve False y no actualiza ninguno de los nombres especificados en which. Los tipos especificados son ilegales si xkb no incluye un componente de mapa o si first_type y num_types especifican tipos que no están definidos en la descripción del teclado.

ESTRUCTURAS

XkbNameChangesRec permite a las aplicaciones identificar modificaciones pequeñas en los nombres simbólicos y reduce efectivamente la cantidad de tráfico enviado al servidor:

    typedef struct _XkbNameChanges {
        unsigned int   changed;          /* componentes de nombre que han cambiado */
        unsigned char  first_type;       /* primer tipo con un nuevo nombre */
        unsigned char  num_types;        /* número de tipos con nuevos nombres */
        unsigned char  first_lvl;        /* primer tipo de nivel con nuevos nombres */
        unsigned char  num_lvls;         /* número de tipos de tecla con nuevos nombres de nivel */
        unsigned char  num_aliases;      /* si los alias de tecla cambiaron, número total de alias de tecla */
        unsigned char  num_rg;           /* si los grupos de radio cambiaron, número total de grupos de radio */
        unsigned char  first_key;        /* primera tecla con un nuevo nombre */
        unsigned char  num_keys;         /* número de teclas con nuevos nombres */
        unsigned short changed_vmods;    /* máscara de modificadores virtuales para los cuales han cambiado los nombres */
        unsigned long  changed_indicators; /* máscara de indicadores para los cuales se cambiaron los nombres */
        unsigned char  changed_groups;     /* máscara de grupos para los cuales se cambiaron los nombres */
    } XkbNameChangesRec, *XkbNameChangesPtr

El campo changed especifica los componentes del nombre que han cambiado y es la unión a nivel de bits inclusiva de los bits de máscara de nombres válidos definidos en la Tabla 1. El resto de los campos de la estructura especifican los rangos que han cambiado para los diversos tipos de nombres simbólicos, como se muestra en la Tabla 2.

Xkb proporciona varias funciones que trabajan con nombres simbólicos. Cada una de estas funciones usa una máscara para especificar campos individuales de las estructuras descritas anteriormente. Estas máscaras y sus relaciones con los campos de una descripción del teclado se muestran en la Tabla 1.

XkbSetNames(3)

NAME

XkbSetNames - Query or modify the names associated with a keyboard map

SYNOPSIS

#include <X11/Xlib.h>
#include <X11/Xutil.h>
#include <X11/Xos.h>
#include <X11/extensions/XKB.h>

Bool XkbSetNames(
    Display *display,
    XkbDescPtr xkb,
    XkbNameTypeMask mask
);

ARGUMENTS

display
Determines the connection to the X server.
xkb
The keyboard description containing the names to be set.
mask
A mask specifying which names should be set.

DESCRIPTION

XkbSetNames sets the names associated with a keyboard description. The names specified in the xkb argument are copied to the server's keyboard description. The mask argument specifies which of the names should be set.

The mask is a bitwise OR of the following values:

XkbKeyNamesMask
Set the key names.
XkbнијаNamesMask
Set the group names.
XkbGeometryNamesMask
Set the geometry names.
XkbTypesNamesMask
Set the type names.
XkbCompatNamesMask
Set the compatibility names.
XkbSymbolsNamesMask
Set the symbols names.
XkbAllNamesMask
Set all names.

STRUCTURES

The XkbDescRec structure contains the following fields relevant to names:

key_names
A string containing the names of the keys.
group_names
A string containing the names of the groups.
geometry_names
A string containing the name of the geometry.
types_names
A string containing the names of the types.
compat_names
A string containing the names of the compatibility map.
symbols_names
A string containing the names of the symbols.

DIAGNOSTICS

If the display is not connected to an X server, XkbSetNames returns False.

If an invalid argument is provided, XkbSetNames may return False or cause a server error.

The following Xkb error codes are defined:

BadLength
The length of a request is shorter or longer than that required to minimally contain the arguments
BadMatch
A compatible version of Xkb was not available in the server or an argument has correct type and range, but is otherwise invalid
