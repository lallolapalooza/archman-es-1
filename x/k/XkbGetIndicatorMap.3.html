XkbGetIndicatorMap(3)

Paquete: libx11

Licencias: MIT AND X11

XkbGetIndicatorMap(3) FUNCIONES DE XKB XkbGetIndicatorMap(3)

NOMBRE

XkbGetIndicatorMap - Obtiene el mapa para uno o más indicadores, utilizando una máscara para especificar los indicadores

SINOPSIS

Status XkbGetIndicatorMap (Display *dpy, unsigned int which, XkbDescPtr desc);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara de indicadores para los que se deben devolver los mapas
desc
descripción del teclado a actualizar

DESCRIPCIÓN

Xkb permite a las aplicaciones obtener información sobre los indicadores mediante dos métodos diferentes. El primer método, similar a la implementación principal de X, utiliza una máscara para especificar los indicadores. El segundo método, más adecuado para aplicaciones preocupadas por la interoperabilidad, utiliza nombres de indicadores. La correspondencia entre el nombre del indicador y la posición del bit en las máscaras es la siguiente: uno de los parámetros devueltos por XkbGetNamedIndicators es un índice que es la posición del bit a usar en cualquier llamada de función que requiera una máscara de bits de indicadores, así como el índice del indicador en el array XkbIndicatorRec de mapas de indicadores.

XkbGetIndicatorMap obtiene los mapas del servidor solo para los indicadores especificados por la máscara which y copia los valores en la descripción del teclado especificada por desc. Si el campo indicators del parámetro desc es NULL, XkbGetIndicatorMap lo asigna e inicializa.

Para liberar los mapas de indicadores, usa XkbFreeIndicatorMaps.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadMatch
No se dispuso de una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otro modo
BadImplementation
Respuesta inválida del servidor

VER TAMBIÉN

XkbFreeIndicatorMaps(3), XkbGetNamedIndicators(3)
