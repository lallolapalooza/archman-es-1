XkbSAPtrDfltValue(3) FUNCIONES XKB XkbSAPtrDfltValue(3)

NOMBRE

XkbSAPtrDfltValue - Devuelve el campo valueXXX de act convertido a un entero con signo

SINOPSIS

int XkbSAPtrDfltValue (XkbAction act);

ARGUMENTOS

act
acción de la cual extraer el grupo

DESCRIPCIÓN

Las acciones asociadas con la estructura XkbPtrDfltAction cambian el atributo mk_dflt_btn del control MouseKeys.

Si el control MouseKeys no está habilitado, los eventos KeyPress y KeyRelease se tratan como si la acción fuera XkbSA_NoAction. De lo contrario, esta acción cambia el atributo mk_dflt_btn del control MouseKeys.

El campo type de la estructura XkbPtrDfltAction siempre debería ser XkbSA_SetPtrDflt.

El campo flags se compone del OR inclusivo a nivel de bits de los valores que se muestran en la Tabla 1 (actualmente solo hay un valor definido).

Tabla 1 Indicadores de Puntero Predeterminados
Indicador Significado
XkbSA_DfltBtnAbsolute Si está activado, el campo value representa un botón de puntero absoluto. De lo contrario, el campo value representa la cantidad a sumar al botón predeterminado actual.

El campo affect especifica qué cambios resultan de esta acción. El único valor válido para el campo affect es XkbSA_AffectDfltBtn.

El campo valueXXX es un carácter con signo que representa el nuevo valor del botón para el atributo mk_dflt_btn del control MouseKeys. Si XkbSA_DfltBtnAbsolute está activado en flags, valueXXX especifica el botón que se utilizará; de lo contrario, valueXXX especifica la cantidad a sumar al botón predeterminado actual. En cualquier caso, las opciones de botón ilegales se ajustan de nuevo al rango. Xkb proporciona macros para convertir entre los valores enteros y de carácter con signo en las estructuras XkbPtrDfltAction.

XkbSAPtrDfltValue devuelve el campo valueXXX de act convertido a un entero con signo.

ESTRUCTURAS

    typedef struct _XkbPtrDfltAction {
        unsigned char    type;      /* XkbSA_SetPtrDflt */
        unsigned char    flags;     /* controla el número de botón del puntero */
        unsigned char    affect;    /* XkbSA_AffectDfltBtn */
        char             valueXXX;  /* nuevo miembro del botón predeterminado */
    } XkbPtrDfltAction;
