XkbGetControlsChanges(3)

Paquete: libx11

Licencias: MIT AND X11

XkbGetControlsChanges(3) FUNCIONES XKB XkbGetControlsChanges(3)

NOMBRE

XkbGetControlsChanges - Actualiza una copia local de una descripción de teclado con los cambios previamente anotados por una o más llamadas a XkbNoteControlsChanges

SINOPSIS

XkbGetControlsChanges (Display *dpy, XkbDescPtr xkb, XkbNameChangesPtr changes);

ARGUMENTOS

dpy
conexión al servidor X
xkb
xkb->ctrls será actualizado
changes
indica qué partes de xkb->ctrls actualizar

DESCRIPCIÓN

Cada vez que un campo en la estructura de controles cambia en la descripción del teclado del servidor, el servidor envía un evento XkbControlsNotify a todos los clientes interesados. Para recibir eventos XkbControlsNotify bajo todas las condiciones posibles, use XkbSelectEvents y pase XkbControlsNotifyMask tanto en bits_to_change como en values_for_bits.

Para recibir eventos XkbControlsNotify solo bajo ciertas condiciones, use XkbSelectEventDetails usando XkbControlsNotify como event_type y especificando los cambios de estado deseados en bits_to_change y values_for_bits usando los bits de máscara de la Tabla 1.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar los controles a modificar y para habilitar y deshabilitar el control. Tenga en cuenta que el mismo bit de máscara se utiliza para especificar modificaciones generales a los parámetros utilizados para configurar el control (cuál), y para habilitar y deshabilitar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no se pueden habilitar o deshabilitar.

El campo changed_ctrls especifica los componentes de los controles que han cambiado y consiste en bits tomados de las máscaras definidas en la Tabla 10.7 con "ok" en la columna changed_ctrls.

Los controles actualmente habilitados en el servidor se informan en el campo enabled_ctrls. Si algún control se acaba de habilitar o deshabilitar (es decir, el contenido del campo enabled_ctrls cambió), se marcan en el campo enabled_ctrl_changes. Los bits válidos para estos campos son las máscaras enumeradas en la Tabla 10.7 con "ok" en la columna enabled_ctrls. El campo num_groups informa el número de grupos enlazados a la tecla que pertenecen al mayor número de grupos y se actualiza automáticamente cuando cambia el mapeo del teclado.

Si el cambio fue causado por una solicitud de un cliente, los campos keycode y event_type se establecen en cero y los campos req_major y req_minor identifican la solicitud. El valor de req_major es el mismo que el código de operación de extensión principal. De lo contrario, event_type se establece en el tipo de evento que causó el cambio (uno de KeyPress, KeyRelease, DeviceKeyPress, DeviceKeyRelease, ButtonPress o ButtonRelease), y req_major y req_minor no están definidos. Si event_type es KeyPress, KeyRelease, DeviceKeyPress o DeviceKeyRelease, el campo keycode se establece en la tecla que causó el cambio. Si event_type es ButtonPress o ButtonRelease, keycode contiene el número del botón.

Cuando un cliente recibe un evento XkbControlsNotify, puede anotar los cambios en una estructura de cambios usando XkbNoteControlsChanges.

XkbGetControlsChanges examina el parámetro changes, consulta al servidor la información necesaria y copia los resultados en la descripción del teclado xkb->ctrls. Si el campo ctrls de xkb es NULL, XkbGetControlsChanges lo asigna e inicializa. Para liberar el campo ctrls, use XkbFreeControls.

XkbGetControlsChanges devuelve Success si tiene éxito y puede generar errores BadAlloc, BadImplementation y BadMatch.

VALORES DE RETORNO

Success
La función XkbGetControlsChanges devuelve Success si la consulta al servidor fue exitosa.

ESTRUCTURAS

La estructura para el evento XkbControlsNotify se define de la siguiente manera:
typedef struct {
    int           type;          /* Código base de evento de extensión Xkb */
    unsigned long serial;        /* Número de serie del servidor X para el evento */
    Bool          send_event;    /* True => generado sintéticamente */
    Display *     display;       /* conexión del servidor donde se generó el evento */
    Time          time;          /* hora del servidor cuando se generó el evento */
    int           xkb_type;      /* XkbCompatMapNotify */
    int           device;        /* ID del dispositivo Xkb, no será XkbUseCoreKbd */
    unsigned int  changed_ctrls; /* bits que indican qué datos de controles han cambiado*/
    unsigned int  enabled_ctrls; /* controles actualmente habilitados en el servidor */
    unsigned int  enabled_ctrl_changes; /* bits que indican controles habilitados/deshabilitados */
    int           num_groups;    /* número actual de grupos de teclado */
    KeyCode       keycode;       /* != 0 => código de tecla de la tecla que causa el cambio */
    char          event_type;    /* Tipo de evento que causa el cambio */
    char          req_major;     /* código de evento principal del evento que causa el cambio */
    char          req_minor;     /* código de evento secundario del evento que causa el cambio */
} XkbControlsNotifyEvent;
