XkbSetDeviceInfo(3) FUNCIONES Xkb XkbSetDeviceInfo(3)

NOMBRE

XkbSetDeviceInfo - Modificar algunas o todas las características de un dispositivo de la Extensión de Entrada X

SINOPSIS

Bool XkbSetDeviceInfo (Display *dpy, unsigned int which, XkbDeviceInfoPtr device_info);

ARGUMENTOS

dpy
conexión al servidor X
which
máscara que indica las características a modificar
device_info
estructura que define el dispositivo y las modificaciones

DESCRIPCIÓN

Para cambiar las características de un dispositivo de la Extensión de Entrada X en el servidor, primero modifique una copia local de la estructura del dispositivo y luego use XkbSetDeviceInfo o, para ahorrar tráfico de red, use una estructura XkbDeviceChangesRec y llame a XkbChangeDeviceInfo para descargar los cambios al servidor.

XkbSetDeviceInfo envía una solicitud al servidor para modificar las características del dispositivo especificado en la estructura device_info. Las características particulares modificadas se identifican por los bits establecidos en which y toman sus valores de los campos relevantes de device_info (ver Tabla 1). XkbSetDeviceInfo devuelve True si la solicitud se envió con éxito al servidor. Si la implementación del servidor X no permite la interacción entre la extensión de entrada X y la Extensión Xkb, la función no hace nada y devuelve False.

El parámetro which especifica qué aspectos del dispositivo se cambiarán y es una máscara de bits compuesta por la OR inclusiva de uno o más de los siguientes bits: XkbXI_ButtonActionsMask, XkbXI_IndicatorNamesMask, XkbXI_IndicatorMapsMask. Si las características solicitadas para manipular en which son válidas para el dispositivo, pero el servidor no permite la asignación de una o más de ellas, esa parte particular de la solicitud se ignora.

Si el dispositivo especificado en device_info->device_spec no contiene botones y se realiza una solicitud que afecta a los botones, o el dispositivo no contiene indicadores y se realiza una solicitud que afecta a los indicadores, se produce un error de protocolo BadMatch.

Si el bit XkbXI_ButtonActionsMask está establecido en la máscara supported devuelta por XkbGetDeviceInfo, la extensión Xkb permite a las aplicaciones asignar acciones de teclas a botones en dispositivos de extensión de entrada distintos del dispositivo de teclado principal. Si XkbXI_ButtonActionsMask está establecido en which, las acciones para todos los botones especificados en device_info se establecen en las XkbActions especificadas en device_info->btn_acts. Si el número de botones solicitados para actualizar no es válido para el dispositivo, XkbSetDeviceInfo devuelve False y se produce un error de protocolo BadValue.

Si el bit XkbXI_IndicatorMaps y/o XkbXI_IndicatorNamesMask está establecido en la máscara supported devuelta por XkbGetDeviceInfo, la extensión Xkb permite a las aplicaciones asignar mapas y/o nombres a los indicadores de dispositivos de extensión no teclados. Si son compatibles, los mapas y/o nombres se pueden asignar a todos los indicadores de dispositivos de extensión, ya sea que formen parte de una retroalimentación de teclado o de una retroalimentación de indicador.

Si la bandera XkbXI_IndicatorMapsMask y/o XkbXI_IndicatorNamesMask está establecida en which, los mapas y/o nombres de indicadores para todos los dispositivos de indicador device_info->num_leds especificados en device_info->leds se establecen en los mapas y/o nombres especificados en device_info->leds. device_info->leds->led_class y led_id especifican la clase de extensión de entrada y el ID del dispositivo para cada dispositivo indicador a modificar; si tienen valores inválidos, se produce un error de protocolo BadValue y XkbSetDeviceInfo devuelve False. Si tienen valores legales pero no especifican una retroalimentación de clase de teclado o indicador para el dispositivo en cuestión, se produce un error BadMatch. Si alguno de los valores en device_info->leds->names no es un Atom válido o None, se produce un error de protocolo BadAtom.

VALORES DE RETORNO

True
La función XkbSetDeviceInfo devuelve True si la solicitud se envió con éxito al servidor.
False
La función XkbSetDeviceInfo devuelve False si la implementación del servidor X no permite la interacción entre la extensión de entrada X y la Extensión Xkb.

ESTRUCTURAS

Los cambios en un dispositivo de extensión Xkb pueden rastrearse escuchando los eventos XkbDeviceExtensionNotify y acumulando los cambios en una estructura XkbDeviceChangesRec. Los cambios anotados en la estructura pueden usarse posteriormente en operaciones para actualizar una configuración del servidor o una copia local de una configuración de dispositivo de extensión Xkb. La estructura de cambios se define de la siguiente manera:

typedef struct _XkbDeviceChanges {
    unsigned int    changed;    /* bits que indican qué ha cambiado */
    unsigned short  first_btn;  /* número del primer botón que cambió, si lo hubo */
    unsigned short  num_btns;   /* número de botones que han cambiado */
    XkbDeviceLedChangesRec leds;
} XkbDeviceChangesRec,*XkbDeviceChangesPtr;

DIAGNÓSTICOS

BadAtom
Un nombre no es un Atom válido ni None
BadMatch
No se encontró una versión compatible de Xkb en el servidor o un argumento tiene el tipo y rango correctos, pero es inválido de otra manera
BadValue
Un argumento es inválido

XkbSetDeviceInfo(3) — Arch Linux

NAME

XkbSetDeviceInfo — configure device controls

SYNOPSIS

#include <X11/Xlib.h>
#include <X11/extensions/Xkb.h>

Bool XkbSetDeviceInfo(
    Display *dpy,
    XkbDeviceInfo *info,
    unsigned int flags
);

ARGUMENTS

dpy
connection to X Server
info
specifies the device and its controls
flags
mask specifying which parts of info are valid and should be set

DESCRIPTION

XkbSetDeviceInfo configures the controls for a specified device. The info structure must contain a valid device ID. The flags parameter specifies which controls should be set.

Valid flags are:

XkbXnDeviceCtlControls
Set the controls specified in info->ctl.

RETURN VALUES

Returns True if the controls were set successfully, and False otherwise.

STRUCTURES

typedef struct { XkbDeviceInfoID id; XkbDeviceControlsRec ctl; /* ... other fields ... */ } XkbDeviceInfo;

The XkbDeviceInfo structure is used to pass device information, including controls, to XkbSetDeviceInfo.

id
The device ID.
ctl
A structure containing the device controls.
typedef struct { XkbControlTypePtr type; unsigned int num_types; XkbKTMapEntryPtr entry; unsigned int num_entries; XkbLedInfoPtr led_info; unsigned int num_leds; unsigned int group_names; unsigned int group_actions; Atom name; Atom type; unsigned int map_flags; unsigned int ptr_buttons; unsigned int bell_pitch; unsigned int bell_duration; XkbColorDescPtr color_bs; XkbColorDescPtr color_cs; unsigned int size_keyboard; unsigned int size_controls; unsigned int size_types; unsigned int size_map; unsigned int size_leds; XkbDeviceSpec device_spec; /* ... other fields ... */ } XkbDeviceControlsRec;

The XkbDeviceControlsRec structure contains the various controls associated with a device.

DIAGNOSTICS

If the specified device does not exist or if an invalid flag is provided, XkbSetDeviceInfo will return False.

An invalid value for a control may result in an error or an out of range error.
