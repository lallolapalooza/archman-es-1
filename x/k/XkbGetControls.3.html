XkbGetControls(3) FUNCIONES XKB XkbGetControls(3)

NOMBRE

XkbGetControls - Encuentra el estado actual de los controles del servidor Xkb

SINOPSIS

Status XkbGetControls (Display *display, unsigned long which, XkbDescPtr xkb);

ARGUMENTOS

display
conexión al servidor X
which
máscara de controles solicitados
xkb
descripción del teclado para la información de controles

DESCRIPCIÓN

XkbGetControls consulta al servidor la información de control solicitada, espera una respuesta y luego copia los valores del servidor para la información solicitada en la estructura ctrls del argumento xkb. Solo se copian los componentes especificados por el parámetro which. Los valores válidos para which son cualquier combinación de las máscaras listadas en la Tabla 1 que tengan "ok" en la columna which.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar controles para modificación y para activar y desactivar el control. Tenga en cuenta que el mismo bit de máscara se utiliza para especificar modificaciones generales a los parámetros usados para configurar el control (which), y para activar y desactivar el control (enabled_ctrls). Las anomalías en la Tabla 1 (ningún "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no pueden ser activados o desactivados.

Tabla 1 Bits de máscara de controles
Bit de máscara which o activado Valor
changed_ctrls _ctrls
XkbRepeatKeysMask ok ok (1L<<0)
XkbSlowKeysMask ok ok (1L<<1)
XkbBounceKeysMask ok ok (1L<<2)
XkbStickyKeysMask ok ok (1L<<3)
XkbMouseKeysMask ok ok (1L<<4)
XkbMouseKeysAccelMask ok ok (1L<<5)
XkbAccessXKeysMask ok ok (1L<<6)
XkbAccessXTimeoutMask ok ok (1L<<7)
XkbAccessXFeedbackMask ok ok (1L<<8)
XkbAudibleBellMask ok (1L<<9)
XkbOverlay1Mask ok (1L<<10)
XkbOverlay2Mask ok (1L<<11)
XkbIgnoreGroupLockMask ok (1L<<12)
XkbGroupsWrapMask ok (1L<<27)
XkbInternalModsMask ok (1L<<28)
XkbIgnoreLockModsMask ok (1L<<29)
XkbPerKeyRepeatMask ok (1L<<30)
XkbControlsEnabledMask ok (1L<<31)
XkbAccessXOptionsMask ok ok (XkbStickyKeysMask |
XkbAccessXFeedbackMask)
XkbAllBooleanCtrlsMask ok (0x00001FFF)
XkbAllControlsMask ok (0xF8001FFF)

Si xkb->ctrls es NULL, XkbGetControls lo asigna e inicializa antes de obtener los valores especificados por which. Si xkb->ctrls no es NULL, XkbGetControls modifica solo las partes de xkb->ctrls correspondientes a los valores especificados por which.

XkbGetControls devuelve Success si tiene éxito; de lo contrario, devuelve BadAlloc si no puede obtener suficiente almacenamiento, BadMatch si xkb es NULL o which está vacío, o BadImplementation.

Para liberar el miembro ctrls de una descripción de teclado, use XkbFreeControls.

El campo num_groups en la estructura ctrls se rellena siempre por XkbGetControls, independientemente de qué bits se seleccionen con which.

VALORES DE RETORNO

Success
La función XkbGetControls devuelve Success si tiene éxito.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
BadImplementation
Respuesta inválida del servidor
BadMatch
No se disponía de una versión compatible de Xkb en el servidor o un argumento tiene un tipo y rango correctos, pero es inválido de otra manera
