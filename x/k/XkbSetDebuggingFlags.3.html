Licencias: MIT AND X11

XkbSetDebuggingFlags(3) FUNCIONES DE XKB XkbSetDebuggingFlags(3)

NOMBRE

XkbSetDebuggingFlags - Cambia los valores de cualquiera de los controles de depuración

SINOPSIS

Bool XkbSetDebuggingFlags (Display *display, unsigned int mask, unsigned int flags, char *msg, unsigned int ctrls_mask, unsigned int ctrls, unsigned int *ret_flags, unsigned int *ret_ctrls);

ARGUMENTOS

display
conexión al servidor X
mask
máscara que selecciona las banderas de salida de depuración a cambiar
flags
valores para las banderas de salida de depuración seleccionadas por la máscara
msg
mensaje para imprimir ahora
ctrls_mask
máscara que selecciona los controles de depuración a cambiar
ctrls
valores para las banderas de control de depuración seleccionadas por ctrls_mask
ret_flags
estado resultante de todas las banderas de salida de depuración
ret_ctrls
estado resultante de todos los controles de depuración

DESCRIPCIÓN

Las ayudas de depuración están pensadas principalmente para ser utilizadas por los implementadores de Xkb y son opcionales en cualquier implementación.

Hay dos máscaras de bits que se pueden usar para controlar la depuración. Una máscara de bits controla la salida de información de depuración y la otra controla el comportamiento. Ambas máscaras de bits se inicializan a cero.

Para cambiar los valores de cualquiera de los controles de depuración, use XkbSetDebuggingFlags.

XkbSetDebuggingFlags modifica las banderas de salida de depuración según lo especificado por mask y flags, modifica las banderas de control de depuración según lo especificado por ctrls_mask y ctrls, imprime el mensaje msg, y rellena ret_flags y ret_ctrls con la salida de depuración resultante y las banderas de control de depuración.

Cuando los bits se establecen en las máscaras de salida de depuración, mask y flags, Xkb imprime información de depuración correspondiente a cada bit en los puntos apropiados durante su procesamiento. El dispositivo al que se escribe la salida depende de la implementación, pero normalmente es el mismo dispositivo al que se dirigen los mensajes de error del servidor X; por lo tanto, los bits que se pueden establecer en mask y flags son específicos de la implementación. Para activar una selección de salida de depuración, establezca el bit para la salida en el parámetro mask y establezca el bit correspondiente en el parámetro flags. Para desactivar la selección de eventos para un evento, establezca el bit para la salida en el parámetro mask y no establezca el bit correspondiente en el parámetro flags.

Cuando los bits se establecen en las máscaras de control de depuración, ctrls_mask y ctrls, Xkb modifica su comportamiento de acuerdo con cada bit de control. ctrls_mask y ctrls están relacionados de la misma manera que mask y flags. Los bits de control válidos se definen en la Tabla 1.

Tabla 1 Máscaras de Control de Depuración
Máscara de Control de Depuración Valor Significado
XkbDF_DisableLocks (1 << 0) Deshabilita acciones que bloquean modificadores

XkbSetDebuggingFlags devuelve True si tiene éxito y False en caso contrario. El único error de protocolo que puede generar es BadAlloc, si por alguna razón no puede asignar almacenamiento.

XkbSetDebuggingFlags está pensada para uso por parte de los desarrolladores y puede estar deshabilitada en servidores X de producción. Si está deshabilitada, XkbSetDebuggingFlags no tiene ningún efecto y no genera ningún error de protocolo.

El mensaje en msg se escribe inmediatamente. El dispositivo al que se escribe depende de la implementación, pero normalmente es el mismo dispositivo donde se dirigen los mensajes de error del servidor X.

VALORES DE RETORNO

True
La función XkbSetDebuggingFlags devuelve True cuando tiene éxito.
False
La función XkbSetDebuggingFlags devuelve False cuando no tiene éxito.

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
