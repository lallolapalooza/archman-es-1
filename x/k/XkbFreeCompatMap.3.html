XkbFreeCompatMap(3) FUNCIONES XKB XkbFreeCompatMap(3)

NOMBRE

XkbFreeCompatMap - Liberar un mapa de compatibilidad completo o porciones seleccionadas de uno

SINOPSIS

void XkbFreeCompatMap (XkbDescPtr xkb, unsigned int which, Bool free_map);

ARGUMENTOS

xkb
Descripción Xkb en la que liberar el mapa de compatibilidad
which
máscara de componentes del mapa de compatibilidad a liberar
free_map
True => liberar la estructura XkbCompatMap en sí

DESCRIPCIÓN

which especifica los componentes del mapa de compatibilidad a liberar (ver XkbGetCompatMap). which es una combinación OR inclusiva de los bits que se muestran en la Tabla 1.

Tabla 1 Máscaras de Componentes del Mapa de Compatibilidad
Máscara Valor Afecta
XkbSymInterpMask (1<<0) Interpretaciones de símbolos
XkbGroupCompatMask (1<<1) Mapas de grupos
XkbAllCompatMask (0x3) Todos los componentes del mapa de compatibilidad

free_map indica si la estructura XkbCompatMap en sí debe ser liberada. Si free_map es True, se ignora which, se liberan todos los componentes del mapa de compatibilidad no NULL, y el campo compat en el XkbDescRec referenciado por xkb se establece a NULL.

ESTRUCTURAS

    typedef struct _XkbCompatMapRec {
        XkbSymInterpretPtr    sym_interpret;            /* semántica de teclas basada en símbolos*/
        XkbModsRec            groups[XkbNumKbdGroups];  /* grupo => mapa de modificadores */
        unsigned short        num_si;                   /* # estructuras usadas en sym_interpret */
        unsigned short        size_si;                  /* # estructuras asignadas en sym_interpret */
    } XkbCompatMapRec, *XkbCompatMapPtr;

La descripción completa de un teclado Xkb se proporciona mediante una XkbDescRec. Las estructuras de componentes en la XkbDescRec representan los componentes principales de Xkb descritos en la Figura 1.1.

typedef struct {
   struct _XDisplay * display;      /* conexión al servidor X */
   unsigned short     flags;        /* privado de Xkb, no modificar */
   unsigned short     device_spec;  /* dispositivo de interés */
   KeyCode            min_key_code; /* keycode mínimo para el dispositivo */
   KeyCode            max_key_code; /* keycode máximo para el dispositivo */
   XkbControlsPtr     ctrls;        /* controles */
   XkbServerMapPtr    server;       /* mapa de teclas del servidor */
   XkbClientMapPtr    map;          /* mapa de teclas del cliente */
   XkbIndicatorPtr    indicators;   /* mapa de indicadores */
   XkbNamesPtr        names;        /* nombres para todos los componentes */
   XkbCompatMapPtr    compat;       /* mapa de compatibilidad */
   XkbGeometryPtr     geom;         /* geometría física del teclado */
} XkbDescRec, *XkbDescPtr;
El campo display apunta a una estructura de pantalla X. El campo flags es privado de la biblioteca: modificar flags puede producir resultados impredecibles. El campo device_spec especifica el identificador del dispositivo del dispositivo de entrada del teclado, o XkbUseCoreKeyboard, que especifica el dispositivo de teclado principal. Los campos min_key_code y max_key_code especifican el keycode menor y mayor que puede ser devuelto por el teclado. Los demás campos especifican componentes de estructura de la descripción del teclado y se describen en detalle en otras secciones de este documento. La Tabla 2 identifica las secciones subsiguientes de este documento que discuten los componentes individuales de la XkbDescRec.
Tabla 2 Referencias de Componentes de XkbDescRec
Campo XkbDescRec Para más información
ctrls Capítulo 10
server Capítulo 16
map Capítulo 15
indicators Capítulo 8
names Capítulo 18
compat Capítulo 17
geom Capítulo 13

Cada componente de estructura tiene un bit de máscara correspondiente que se utiliza en las llamadas a funciones para indicar que la estructura debe ser manipulada de alguna manera, como asignarla o liberarla. Estas máscaras y sus relaciones con los campos en la XkbDescRec se muestran en la Tabla 3.

Tabla 3 Bits de Máscara para XkbDescRec
Bit de Máscara Campo XkbDescRec Valor
XkbControlsMask ctrls (1L<<0)
XkbServerMapMask server (1L<<1)
XkbIClientMapMask map (1L<<2)
XkbIndicatorMapMask indicators (1L<<3)
XkbNamesMask names (1L<<4)
XkbCompatMapMask compat (1L<<5)
XkbGeometryMask geom (1L<<6)
XkbAllComponentsMask Todos los Campos (0x7f)
