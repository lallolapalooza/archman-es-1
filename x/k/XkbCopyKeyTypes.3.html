XkbCopyKeyTypes(3)

Paquete: libx11

Licencias: MIT AND X11

XkbCopyKeyTypes(3) FUNCIONES DE XKB XkbCopyKeyTypes(3)

NOMBRE

XkbCopyKeyTypes - Copia más de una estructura XkbKeyTypeRec

SINOPSIS

Status XkbCopyKeyTypes (XkbKeyTypePtr from, XkbKeyTypePtr into, int num_types);

ARGUMENTOS

from
puntero a array de XkbKeyTypeRecs para copiar
into
puntero a array de XkbKeyTypeRecs para modificar
num_types
número de tipos a copiar

DESCRIPCIÓN

XkbCopyKeyTypes copia num_types estructuras XkbKeyTypeRec del array especificado por from al array especificado por into. Está diseñado para copiar entre descripciones de teclado, en lugar de dentro de ellas, por lo que no comprueba solapamientos. Las mismas reglas que se aplican a los parámetros from e into en XkbCopyKeyType se aplican a cada entrada de los arrays from e into de XkbCopyKeyTypes. Si se produce algún error de asignación al copiar de from a into, XkbCopyKeyTypes devuelve BadAlloc. De lo contrario, XkbCopyKeyTypes copia de from a into y devuelve Success.

VALORES DE RETORNO

Success
La función XkbCopyKeyTypes devuelve Success cuando no hay errores de asignación.

ESTRUCTURAS

Los tipos de tecla se utilizan para determinar el nivel de cambio de una tecla dado el estado actual del teclado. El conjunto de todos los tipos de tecla posibles para la descripción del teclado Xkb se mantiene en el campo types del mapa del cliente, cuyo tamaño total se almacena en size_types, y cuyo número total de entradas válidas se almacena en num_types. Los tipos de tecla se definen utilizando la siguiente estructura:

typedef struct {                   /* Tipo de Tecla */
    XkbModsRec        mods;        /* modificadores usados para calcular el nivel de cambio */
    unsigned char     num_levels;  /* total # de niveles de cambio, no modificar directamente */
    unsigned char     map_count;   /* # de entradas en el mapa, preservar (si no es NULL) */
    XkbKTMapEntryPtr  map;         /* vector de modificadores para cada nivel de cambio */
    XkbModsPtr    preserve;    /* mods a preservar para la entrada de mapa correspondiente */
    Atom              name;        /* nombre del tipo de tecla */
    Atom *            level_names; /* array de nombres de cada nivel de cambio */
} XkbKeyTypeRec, *XkbKeyTypePtr;

DIAGNÓSTICOS

BadAlloc
No se pudo asignar almacenamiento
