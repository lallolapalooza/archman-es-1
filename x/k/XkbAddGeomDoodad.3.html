NOMBRE

XkbAddGeomDoodad - Añade un doodad a una sección de una geometría de teclado o a la geometría de nivel superior

SINOPSIS

XkbDoodadPtr XkbAddGeomDoodad (XkbGeometryPtr geom, XkbSectionPtr section, Atom name);

ARGUMENTOS

geom
geometría a la que se añade el doodad
section
sección, si la hay, a la que se añade el doodad
name
nombre del nuevo doodad

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único elemento nuevo a la geometría del teclado de nivel superior. En cada caso, los campos num_* de la estructura correspondiente se incrementan en 1. Estas funciones no modifican sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debe escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades de geometría. Una propiedad de geometría asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar las propiedades de geometría como pistas, pero Xkb no las interpreta. Ninguna otra estructura de geometría hace referencia a propiedades de geometría.

Un doodad describe algún aspecto visible del teclado que no es una tecla ni una sección. XkbAddGeomDoodad añade un doodad con el nombre especificado por name a la geometría geom si section es NULL o a la sección de la geometría especificada por section si section no es NULL. XkbAddGeomDoodad devuelve NULL si alguno de los parámetros está vacío o si no ha podido asignar espacio para el doodad. Si ya existe un doodad con el nombre name en el array de doodads para la geometría (si section es NULL) o la sección (si section no es NULL), se devuelve un puntero a ese doodad. Para asignar espacio para un número arbitrario de doodads a una sección, utilice la función XkbAllocGeomSectionDoodads. Para asignar espacio para un número arbitrario de doodads a una geometría de teclado, utilice la función XkbAllocGeomDoodads.

ESTRUCTURAS

    typedef union _XkbDoodad {
        XkbAnyDoodadRec            any;
        XkbShapeDoodadRec          shape;
        XkbTextDoodadRec           text;
        XkbIndicatorDoodadRec      indicator;
        XkbLogoDoodadRec           logo;
    } XkbDoodadRec, *XkbDoodadPtr;
