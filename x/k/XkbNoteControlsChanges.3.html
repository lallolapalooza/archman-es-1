XkbNoteControlsChanges(3)

Paquete: libx11

XkbNoteControlsChanges(3) FUNCIONES XKB XkbNoteControlsChanges(3)

NOMBRE

XkbNoteControlsChanges - Registra los cambios en una estructura de cambios cuando un cliente recibe un evento XkbControlsNotify

SINOPSIS

void XkbNoteControlsChanges(XkbControlsChangesPtr changes, XkbControlsNotifyEvent *new, unsigned int wanted);

ARGUMENTOS

changes
registra los cambios indicados por new
new
indica qué cosas han cambiado
wanted
indica qué partes de new registrar en changes

DESCRIPCIÓN

Cada vez que un campo en la estructura de controles cambia en la descripción del teclado del servidor, el servidor envía un evento XkbControlsNotify a todos los clientes interesados. Para recibir eventos XkbControlsNotify bajo todas las condiciones posibles, usa XkbSelectEvents y pasa XkbControlsNotifyMask tanto en bits_to_change como en values_for_bits.

Para recibir eventos XkbControlsNotify solo bajo ciertas condiciones, usa XkbSelectEventDetails usando XkbControlsNotify como event_type y especificando los cambios de estado deseados en bits_to_change y values_for_bits usando las máscaras de bits de la Tabla 1.

La Tabla 1 muestra los valores reales para los bits de máscara individuales utilizados para seleccionar controles para modificación y para habilitar y deshabilitar el control. Ten en cuenta que el mismo bit de máscara se utiliza para especificar modificaciones generales a los parámetros utilizados para configurar el control (which), y para habilitar y deshabilitar el control (enabled_ctrls). Las anomalías en la tabla (sin "ok" en la columna) son para controles que no tienen atributos configurables; y para controles que no son controles booleanos y, por lo tanto, no pueden ser habilitados o deshabilitados.

El campo changed_ctrls especifica los componentes de los controles que han cambiado y consiste en bits tomados de las máscaras definidas en la Tabla 1 con "ok" en la columna changed_ctrls.

Los controles actualmente habilitados en el servidor se informan en el campo enabled_ctrls. Si algunos controles acaban de ser habilitados o deshabilitados (es decir, el contenido del campo enabled_ctrls cambió), se marcan en el campo enabled_ctrl_changes. Los bits válidos para estos campos son las máscaras listadas en la Tabla 1 con "ok" en la columna enabled_ctrls. El campo num_groups informa el número de grupos enlazados a la tecla perteneciente al mayor número de grupos y se actualiza automáticamente cuando cambia el mapeo del teclado.

Si el cambio fue causado por una solicitud de un cliente, los campos keycode y event_type se establecen a cero y los campos req_major y req_minor identifican la solicitud. El valor de req_major es el mismo que el código de operación principal de la extensión. De lo contrario, event_type se establece al tipo de evento que causó el cambio (uno de KeyPress, KeyRelease, DeviceKeyPress, DeviceKeyRelease, ButtonPress o ButtonRelease), y req_major y req_minor no están definidos. Si event_type es KeyPress, KeyRelease, DeviceKeyPress o DeviceKeyRelease, el campo keycode se establece a la tecla que causó el cambio. Si event_type es ButtonPress o ButtonRelease, keycode contiene el número del botón.

Cuando un cliente recibe un evento XkbControlsNotify, puede registrar los cambios en una estructura de cambios usando XkbNoteControlsChanges.

El parámetro wanted es una OR inclusiva a nivel de bits de los bits tomados del conjunto de máscaras especificadas en la Tabla 1 con "ok" en la columna changed_ctrls. XkbNoteControlsChanges copia cualquier cambio reportado en new y especificado en wanted al registro de cambios especificado por old.

ESTRUCTURAS

La estructura para el evento XkbControlsNotify se define de la siguiente manera:
typedef struct {
    int           type;          /* Código base del evento de extensión Xkb */
    unsigned long serial;        /* Número de serie del servidor X para el evento */
    Bool          send_event;    /* True => generado sintéticamente */
    Display *     display;       /* conexión del servidor donde se generó el evento */
    Time          time;          /* tiempo del servidor cuando se generó el evento */
    int           xkb_type;      /* XkbCompatMapNotify */
    int           device;        /* ID del dispositivo Xkb, no será XkbUseCoreKbd */
    unsigned int  changed_ctrls; /* bits que indican qué datos de control han cambiado*/
    unsigned int  enabled_ctrls; /* controles actualmente habilitados en el servidor */
    unsigned int  enabled_ctrl_changes; /* bits que indican controles habilitados/deshabilitados */
    int           num_groups;    /* número actual de grupos de teclado */
    KeyCode       keycode;       /* != 0 => código de tecla de la tecla que causa el cambio */
    char          event_type;    /* Tipo de evento que causa el cambio */
    char          req_major;     /* código principal del evento que causa el cambio */
    char          req_minor;     /* código secundario del evento que causa el cambio */
} XkbControlsNotifyEvent;
