XkbAddGeomOutline(3) FUNCIONES XKB XkbAddGeomOutline(3)

NOMBRE

XkbAddGeomOutline - Añadir un contorno a una forma existente

SINOPSIS

XkbOutlinePtr XkbAddGeomOutline (XkbShapePtr shape, int sz_points);

ARGUMENTOS

shape
forma a actualizar
sz_points
número de puntos a reservar

DESCRIPCIÓN

Xkb proporciona funciones para añadir un único nuevo elemento a la geometría del teclado de nivel superior. En cada caso, los campos num_ * de la estructura correspondiente se incrementan en 1. Estas funciones no cambian sz_* a menos que no haya más espacio en el array. Algunas de estas funciones rellenan los valores de la estructura del elemento a partir de los argumentos. Para otras funciones, debes escribir explícitamente código para rellenar los elementos de la estructura.

La descripción de la geometría de nivel superior incluye una lista de propiedades de geometría. Una propiedad de geometría asocia una cadena arbitraria con un nombre igualmente arbitrario. Los programas que muestran imágenes de teclados pueden usar las propiedades de geometría como pistas, pero Xkb no las interpreta. Ninguna otra estructura de geometría hace referencia a propiedades de geometría.

Un contorno consta de un número arbitrario de puntos. XkbAddGeomOutline añade un contorno a la forma especificada reservando sz_points puntos para ella. El nuevo contorno se asigna y se pone a cero. XkbAddGeomOutline devuelve NULL si alguno de los parámetros está vacío o si no pudo asignar espacio. Para asignar espacio para un número arbitrario de contornos a una forma, usa XkbAllocGeomOutlines.

ESTRUCTURAS

    typedef struct _XkbOutline {
        unsigned short    num_points;      /* número de puntos en el contorno */
        unsigned short    sz_points;       /* tamaño del array de puntos */
        unsigned short    corner_radius;   /* dibuja esquinas como círculos con este radio */
        XkbPointPtr       points;          /* array de puntos que definen el contorno */
    } XkbOutlineRec, *XkbOutlinePtr;
