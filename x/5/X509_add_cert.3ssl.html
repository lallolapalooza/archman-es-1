X509_add_cert(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_ADD_CERT(3ssl) OpenSSL X509_ADD_CERT(3ssl)

NOMBRE

X509_add_cert, X509_add_certs - funciones de adición de lista de certificados X509

SINOPSIS

#include <openssl/x509.h>
int X509_add_cert(STACK_OF(X509) *sk, X509 *cert, int flags);
int X509_add_certs(STACK_OF(X509) *sk, STACK_OF(X509) *certs, int flags);

DESCRIPCIÓN

X509_add_cert() añade un certificado cert a la lista dada sk. Es un error que el argumento cert sea NULL.

X509_add_certs() añade una lista de certificados certs a la lista dada sk. El argumento certs puede ser NULL, lo que implica que no tiene efecto. No modifica la lista certs pero en caso de que se establezca el flag X509_ADD_FLAG_UP_REF (descrito a continuación) se incrementan los contadores de referencia de aquellos de sus miembros añadidos a sk.

Ambas funciones tienen un parámetro flags, que se utiliza para controlar los detalles de la operación.

El valor X509_ADD_FLAG_DEFAULT, que es igual a 0, significa que no hay semántica especial.

Si se establece X509_ADD_FLAG_UP_REF, se incrementan los contadores de referencia de aquellos certificados añadidos con éxito.

Si se establece X509_ADD_FLAG_PREPEND, los certificados se anteponen a sk. Por defecto, se añaden al final de sk. En ambos casos, se preserva el orden original de los certificados añadidos.

Si se establece X509_ADD_FLAG_NO_DUP, se ignoran los certificados que ya están contenidos en sk, lo que se determina usando X509_cmp(3).

Si se establece X509_ADD_FLAG_NO_SS, se ignoran los certificados que están marcados como autofirmados, lo que se determina usando X509_self_signed(3).

VALORES DE RETORNO

Ambas funciones devuelven 1 en caso de éxito y 0 en caso de fallo.

NOTAS

Si se utiliza X509_add_certs() con los flags X509_ADD_FLAG_NO_DUP o X509_ADD_FLAG_NO_SS, es aconsejable utilizar también X509_ADD_FLAG_UP_REF porque, de lo contrario, es probable que la propiedad de todos los miembros de la lista certs no se transfiera a la lista de certificados sk.

También se debe tener cuidado en caso de que el argumento certs sea igual a sk.

VER TAMBIÉN

X509_cmp(3) X509_self_signed(3)

HISTORIAL

Las funciones X509_add_cert() y X509_add_certs() se añadieron en OpenSSL 3.0.
