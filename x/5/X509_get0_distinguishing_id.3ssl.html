X509_get0_distinguishing_id(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_GET0_DISTINGUISHING_ID(3ssl) OpenSSL X509_GET0_DISTINGUISHING_ID(3ssl)

NOMBRE

X509_get0_distinguishing_id, X509_set0_distinguishing_id, X509_REQ_get0_distinguishing_id, X509_REQ_set0_distinguishing_id - obtener o establecer el ID distintivo para operaciones de certificado

SINOPSIS

#include <openssl/x509.h>
ASN1_OCTET_STRING *X509_get0_distinguishing_id(X509 *x);
void X509_set0_distinguishing_id(X509 *x, ASN1_OCTET_STRING *distid);
ASN1_OCTET_STRING *X509_REQ_get0_distinguishing_id(X509_REQ *x);
void X509_REQ_set0_distinguishing_id(X509_REQ *x, ASN1_OCTET_STRING *distid);

DESCRIPCIÓN

El ID distintivo se define en FIPS 196 de la siguiente manera:

Identificador distintivo
Información que distingue inequívocamente a una entidad en el proceso de autenticación.

El algoritmo de firma SM2 requiere un valor de ID distintivo al generar y verificar una firma, pero el ID distintivo también puede tener otros usos. En el contexto de SM2, el ID distintivo a menudo se denomina "ID SM2".

A efectos de verificar un certificado o una solicitud de certificación, se puede adjuntar un ID distintivo, de modo que funciones como X509_verify(3) o X509_REQ_verify(3) tengan fácil acceso a esa identidad para la verificación de la firma.

X509_get0_distinguishing_id() obtiene el valor del ID distintivo de un certificado x devolviendo un objeto ASN1_OCTET_STRING que no debe ser liberado por el llamante.

X509_set0_distinguishing_id() asigna distid al certificado x. La llamada a esta función transfiere la gestión de memoria del valor al objeto X509 y, por lo tanto, el valor que se ha pasado no debe ser liberado por el llamante después de que esta función haya sido llamada.

X509_REQ_get0_distinguishing_id() y X509_REQ_set0_distinguishing_id() tienen la misma funcionalidad que X509_get0_distinguishing_id() y X509_set0_distinguishing_id(), excepto que se ocupan de objetos X509_REQ en lugar de X509.

VALORES DE RETORNO

X509_set0_distinguishing_id() y X509_REQ_set0_distinguishing_id() no devuelven ningún valor.

VER TAMBIÉN

X509_verify(3), SM2(7)
