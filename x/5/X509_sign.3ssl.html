X509_sign(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_SIGN(3ssl) OpenSSL X509_SIGN(3ssl)

NOMBRE

X509_sign, X509_sign_ctx, X509_REQ_sign, X509_REQ_sign_ctx, X509_ACERT_sign, X509_ACERT_sign_ctx, X509_CRL_sign, X509_CRL_sign_ctx - firmar certificado, solicitud de certificado o firma de CRL

SINOPSIS

#include <openssl/x509.h>
int X509_sign(X509 *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_sign_ctx(X509 *x, EVP_MD_CTX *ctx);
int X509_REQ_sign(X509_REQ *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_REQ_sign_ctx(X509_REQ *x, EVP_MD_CTX *ctx);
int X509_CRL_sign(X509_CRL *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_CRL_sign_ctx(X509_CRL *x, EVP_MD_CTX *ctx);
#include <openssl/x509_acert.h>
int X509_ACERT_sign(X509_ACERT *x, EVP_PKEY *pkey, const EVP_MD *md);
int X509_ACERT_sign_ctx(X509_ACERT *x, EVP_MD_CTX *ctx);

DESCRIPCIÓN

X509_sign() firma el certificado x usando la clave privada pkey y el digestor de mensajes md y establece la firma en x. X509_sign_ctx() también firma el certificado x pero utiliza los parámetros contenidos en el contexto del digestor ctx. Si la información del certificado incluye extensiones X.509, estas dos funciones se aseguran de que el certificado porte la versión 3 de X.509.

X509_REQ_sign(), X509_REQ_sign_ctx(), X509_ACERT_sign(), X509_ACERT_sign_ctx(), X509_CRL_sign() y X509_CRL_sign_ctx() firman solicitudes de certificado y CRLs, respectivamente.

NOTAS

X509_sign_ctx() se utiliza cuando los parámetros por defecto para la clave pública y el digestor correspondientes no son adecuados. Se puede utilizar para firmar claves usando RSA-PSS, por ejemplo.

Por razones de eficiencia y para solucionar problemas de codificación ASN.1, la codificación de la parte firmada de un certificado, solicitud de certificado y CRL se almacena en caché internamente. Si la parte firmada de la estructura se modifica, la codificación no siempre se actualiza, lo que significa que a veces se utiliza una versión obsoleta. Esto normalmente no es un problema, ya que modificar la parte firmada invalidará la firma y el proceso de firma actualizará siempre la codificación.

VALORES DE RETORNO

Todas las funciones devuelven el tamaño de la firma en bytes en caso de éxito y cero en caso de fallo.

VER TAMBIÉN

ERR_get_error(3), X509_NAME_add_entry_by_txt(3), X509_new(3), X509_verify_cert(3), X509_verify(3), X509_REQ_verify_ex(3), X509_REQ_verify(3), X509_CRL_verify(3)

HISTORIA

Las funciones X509_sign(), X509_REQ_sign() y X509_CRL_sign() están disponibles en todas las versiones de OpenSSL.

Las funciones X509_sign_ctx(), X509_REQ_sign_ctx() y X509_CRL_sign_ctx() se añadieron en OpenSSL 1.0.1.

Las funciones X509_ACERT_sign() y X509_ACERT_sign_ctx() se añadieron en OpenSSL 3.4.
