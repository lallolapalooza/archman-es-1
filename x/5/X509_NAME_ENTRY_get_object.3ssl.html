X509_NAME_ENTRY_get_object(3ssl)

X509_NAME_ENTRY_GET_OBJECT(3ssl) OpenSSL X509_NAME_ENTRY_GET_OBJECT(3ssl)

NOMBRE

X509_NAME_ENTRY_get_object, X509_NAME_ENTRY_get_data, X509_NAME_ENTRY_set_object, X509_NAME_ENTRY_set_data, X509_NAME_ENTRY_create_by_txt, X509_NAME_ENTRY_create_by_NID, X509_NAME_ENTRY_create_by_OBJ - funciones de utilidad X509_NAME_ENTRY

SINOPSIS

#include <openssl/x509.h>
ASN1_OBJECT *X509_NAME_ENTRY_get_object(const X509_NAME_ENTRY *ne);
ASN1_STRING *X509_NAME_ENTRY_get_data(const X509_NAME_ENTRY *ne);
int X509_NAME_ENTRY_set_object(X509_NAME_ENTRY *ne, const ASN1_OBJECT *obj);
int X509_NAME_ENTRY_set_data(X509_NAME_ENTRY *ne, int type,
                             const unsigned char *bytes, int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_txt(X509_NAME_ENTRY **ne, const char *field,
                                               int type, const unsigned char *bytes,
                                               int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_NID(X509_NAME_ENTRY **ne, int nid,
                                               int type, const unsigned char *bytes,
                                               int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_OBJ(X509_NAME_ENTRY **ne,
                                               const ASN1_OBJECT *obj, int type,
                                               const unsigned char *bytes, int len);

DESCRIPCIÓN

X509_NAME_ENTRY_get_object() recupera el nombre del campo de ne en una estructura ASN1_OBJECT.

X509_NAME_ENTRY_get_data() recupera el valor del campo de ne en una estructura ASN1_STRING.

X509_NAME_ENTRY_set_object() establece el nombre del campo de ne a obj.

X509_NAME_ENTRY_set_data() establece el valor del campo de ne al tipo de cadena type y al valor determinado por bytes y len.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID() y X509_NAME_ENTRY_create_by_OBJ() crean y devuelven una estructura X509_NAME_ENTRY.

NOTAS

X509_NAME_ENTRY_get_object() y X509_NAME_ENTRY_get_data() se pueden usar para examinar una función X509_NAME_ENTRY como la devuelta por X509_NAME_get_entry(), por ejemplo.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_OBJ(), X509_NAME_ENTRY_create_by_NID() y X509_NAME_ENTRY_set_data() se usan raramente en la práctica porque las estructuras X509_NAME_ENTRY son casi siempre parte de estructuras X509_NAME y las funciones correspondientes de X509_NAME se usan típicamente para crear y añadir nuevas entradas en una sola operación.

Los argumentos de estas funciones admiten opciones similares a las de las funciones de X509_NAME con nombres similares, como X509_NAME_add_entry_by_txt(). Así, por ejemplo, type puede establecerse en MBSTRING_ASC, pero en el caso de X509_set_data(), el nombre del campo debe establecerse primero para que la información del campo relevante pueda ser buscada internamente.

VALORES DE RETORNO

X509_NAME_ENTRY_get_object() devuelve una estructura ASN1_OBJECT válida si está establecida o NULL si ocurrió un error.

X509_NAME_ENTRY_get_data() devuelve una estructura ASN1_STRING válida si está establecida o NULL si ocurrió un error.

X509_NAME_ENTRY_set_object() y X509_NAME_ENTRY_set_data() devuelven 1 en caso de éxito o 0 en caso de error.

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID() y X509_NAME_ENTRY_create_by_OBJ() devuelven una X509_NAME_ENTRY válida en caso de éxito o NULL si ocurrió un error.
