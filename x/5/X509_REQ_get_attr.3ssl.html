X509_REQ_get_attr(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_REQ_GET_ATTR(3ssl) OpenSSL X509_REQ_GET_ATTR(3ssl)

NOMBRE

X509_REQ_get_attr_count, X509_REQ_get_attr_by_NID, X509_REQ_get_attr_by_OBJ, X509_REQ_get_attr, X509_REQ_delete_attr, X509_REQ_add1_attr, X509_REQ_add1_attr_by_OBJ, X509_REQ_add1_attr_by_NID, X509_REQ_add1_attr_by_txt - Soporte X509_ATTRIBUTE para solicitudes de certificados firmados

SINOPSIS

#include <openssl/x509.h>
int X509_REQ_get_attr_count(const X509_REQ *req);
int X509_REQ_get_attr_by_NID(const X509_REQ *req, int nid, int lastpos);
int X509_REQ_get_attr_by_OBJ(const X509_REQ *req, const ASN1_OBJECT *obj,
                             int lastpos);
X509_ATTRIBUTE *X509_REQ_get_attr(const X509_REQ *req, int loc);
X509_ATTRIBUTE *X509_REQ_delete_attr(X509_REQ *req, int loc);
int X509_REQ_add1_attr(X509_REQ *req, X509_ATTRIBUTE *attr);
int X509_REQ_add1_attr_by_OBJ(X509_REQ *req,
                              const ASN1_OBJECT *obj, int type,
                              const unsigned char *bytes, int len);
int X509_REQ_add1_attr_by_NID(X509_REQ *req,
                              int nid, int type,
                              const unsigned char *bytes, int len);
int X509_REQ_add1_attr_by_txt(X509_REQ *req,
                              const char *attrname, int type,
                              const unsigned char *bytes, int len);

DESCRIPCIÓN

X509_REQ_get_attr_by_OBJ() encuentra la ubicación del primer objeto coincidente obj en la lista de atributos de req. La búsqueda comienza en la posición después de lastpos. Si el valor devuelto es positivo, se puede usar en la siguiente llamada a X509_REQ_get_attr_by_OBJ() como el valor de lastpos para iterar a través de los atributos restantes. lastpos se puede establecer en cualquier valor negativo en la primera llamada, para comenzar la búsqueda desde el inicio de la lista de atributos.

X509_REQ_get_attr_by_NID() es similar a X509_REQ_get_attr_by_OBJ(), excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de NID_*.

X509_REQ_get_attr() devuelve el objeto X509_ATTRIBUTE en el índice loc de la lista de atributos de req. loc debe estar en el rango de 0 a X509_REQ_get_attr_count() - 1.

X509_REQ_delete_attr() elimina el objeto X509_ATTRIBUTE en el índice loc de la lista de atributos de los objetos de req. Se produce un error si req es NULL.

X509_REQ_add1_attr() agrega una copia del X509_ATTRIBUTE pasado attr a la lista de atributos del objeto req. Se producirá un error si la lista de atributos es NULL o si el atributo ya existe.

X509_REQ_add1_attr_by_OBJ() crea un nuevo X509_ATTRIBUTE usando X509_ATTRIBUTE_set1_object() y X509_ATTRIBUTE_set1_data() para asignar un nuevo obj con el tipo type y los datos bytes de longitud len, y luego lo agrega a la lista de atributos del objeto req. req debe ser no NULL o se producirá un error. Si obj ya existe en la lista de atributos, se producirá un error.

X509_REQ_add1_attr_by_NID() es similar a X509_REQ_add1_attr_by_OBJ(), excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de NID_*.

X509_REQ_add1_attr_by_txt() es similar a X509_REQ_add1_attr_by_OBJ(), excepto que pasa un nombre attrname asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de nombres SN_*.

Consulte X509_ATTRIBUTE(3) para obtener información relacionada con los atributos.

VALORES DE RETORNO

X509_REQ_get_attr_count() devuelve el número de atributos en la lista de atributos del objeto req o -1 si la lista de atributos es NULL.

X509_REQ_get_attr_by_OBJ() devuelve -1 si la lista de atributos del objeto req está vacía O si obj no se encuentra, de lo contrario, devuelve la ubicación de obj en la lista de atributos.

X509_REQ_get_attr_by_NID() es similar a X509_REQ_get_attr_by_OBJ(), excepto que devuelve -2 si el nid no es conocido por OpenSSL.

X509_REQ_get_attr() devuelve un X509_ATTRIBUTE o NULL en caso de error.

X509_REQ_delete_attr() devuelve el X509_ATTRIBUTE eliminado o NULL si hay un error.

X509_REQ_add1_attr(), X509_REQ_add1_attr_by_OBJ(), X509_REQ_add1_attr_by_NID() y X509_REQ_add1_attr_by_txt() devuelven 1 en caso de éxito o 0 en caso de error.

NOTAS

Cualquier función que modifique los atributos (añada o elimine) establece internamente una bandera para indicar que la codificación ASN.1 ha sido modificada.
