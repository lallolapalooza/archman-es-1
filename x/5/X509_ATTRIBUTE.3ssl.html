DESCRIPCIÓN

Los objetos X509_ATTRIBUTE son utilizados por muchos estándares incluyendo X509, X509_REQ, PKCS12, PKCS8, PKCS7 y CMS.

El objeto X509_ATTRIBUTE se utiliza para representar el Atributo ASN.1 tal como se define en RFC 5280, es decir:

Attribute ::= SEQUENCE {
  type             AttributeType,
  values    SET OF AttributeValue }
AttributeType ::= OBJECT IDENTIFIER
AttributeValue ::= ANY -- DEFINED BY AttributeType

Por ejemplo, CMS define el atributo signing-time como:

id-signingTime OBJECT IDENTIFIER ::= { iso(1) member-body(2)
    us(840) rsadsi(113549) pkcs(1) pkcs9(9) 5 }
SigningTime ::= Time
Time ::= CHOICE {
  utcTime UTCTime,
  generalizedTime GeneralizedTime }

En OpenSSL, AttributeType se mapea a un objeto ASN1_OBJECT y AttributeValue se mapea a una lista de objetos ASN1_TYPE.

Las siguientes funciones se utilizan para objetos X509_ATTRIBUTE.

X509at_get_attr_by_OBJ() busca la ubicación del primer objeto coincidente obj en una lista de atributos sk. La búsqueda comienza en la posición después de lastpos. Si el valor devuelto es positivo, puede usarse en la siguiente llamada a X509at_get_attr_by_OBJ() como el valor de lastpos para iterar a través de los atributos restantes. lastpos puede establecerse en cualquier valor negativo en la primera llamada, para comenzar la búsqueda desde el principio de la lista.

X509at_get_attr_by_NID() es similar a X509at_get_attr_by_OBJ() excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de NID_*.

X509at_get_attr() devuelve el objeto X509_ATTRIBUTE en el índice loc de la lista de atributos x. loc debe estar en el rango de 0 a X509at_get_attr_count() - 1.

X509at_delete_attr() elimina el objeto X509_ATTRIBUTE en el índice loc de la lista de atributos x.

X509at_add1_attr() añade una copia del objeto X509_ATTRIBUTE pasado a la lista x. Tanto x como attr deben ser no nulos o ocurrirá un error. Si *x es NULL, se creará una nueva lista, de lo contrario se utilizará la lista pasada. Ocurrirá un error si ya existe un atributo (con el mismo tipo de atributo) en la lista de atributos.

X509at_add1_attr_by_OBJ() crea un nuevo X509_ATTRIBUTE utilizando X509_ATTRIBUTE_set1_object() y X509_ATTRIBUTE_set1_data() para asignar un nuevo obj con tipo type y datos bytes de longitud len y luego lo añade a la lista de atributos x. Tanto x como attr deben ser no nulos o ocurrirá un error. Si *x es NULL, se creará una nueva lista de atributos. Si obj ya existe en la lista de atributos, ocurrirá un error.

X509at_add1_attr_by_NID() es similar a X509at_add1_attr_by_OBJ() excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de NID_*.

X509at_add1_attr_by_txt() es similar a X509at_add1_attr_by_OBJ() excepto que pasa un nombre attrname asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de nombres SN_*.

X509_ATTRIBUTE_set1_object() asigna un ASN1_OBJECT obj al atributo attr. Si attr contenía un ASN1_OBJECT existente, se libera. Ocurre un error si attr o obj son NULL, o si el obj pasado no se puede duplicar.

X509_ATTRIBUTE_set1_data() añade un nuevo objeto ASN1_TYPE a la lista de atributos attr. Al nuevo objeto se le asigna una copia de los datos en data de tamaño len. Si attrtype tiene la bandera MBSTRING_FLAG establecida, se usa una búsqueda en tabla usando el NID de atributos de attr para establecer una ASN1_STRING usando ASN1_STRING_set_by_NID(), y los data pasados deben estar en el formato requerido para ese tipo de objeto o ocurrirá un error. Si len no es -1, internamente se usa ASN1_STRING_type_new() con el attrtype pasado. Si attrtype es 0, la llamada no hace nada excepto devolver 1.

X509_ATTRIBUTE_create() crea un nuevo X509_ATTRIBUTE usando el nid para establecer el OID del ASN1_OBJECT y el atrtype y value para establecer el ASN1_TYPE.

X509_ATTRIBUTE_create_by_OBJ() utiliza X509_ATTRIBUTE_set1_object() y X509_ATTRIBUTE_set1_data() para asignar un nuevo obj con tipo atrtype y datos data de longitud len. Si el atributo pasado attr O *attr es NULL, se devolverá un nuevo X509_ATTRIBUTE, de lo contrario se utilizará el X509_ATTRIBUTE pasado. Tenga en cuenta que el ASN1_OBJECT obj se añade a la lista existente de objetos de los atributos, lo que podría ser un problema si el ASN1_OBJECT de los atributos fuera diferente.

X509_ATTRIBUTE_create_by_NID() es similar a X509_ATTRIBUTE_create_by_OBJ() excepto que pasa el identificador numérico (NID) nid asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de NID_*.

X509_ATTRIBUTE_create_by_txt() es similar a X509_ATTRIBUTE_create_by_OBJ() excepto que pasa un nombre atrname asociado con el objeto. Ver <openssl/obj_mac.h> para una lista de nombres SN_*.

X509at_get0_data_by_OBJ() busca un atributo por su objeto obj y devuelve el valor de datos asociado con él. La búsqueda comienza en la posición después de lastpos. Si el valor devuelto es positivo, puede usarse en la siguiente llamada a X509at_get0_data_by_OBJ() como el valor de lastpos para iterar a través de los atributos restantes. lastpos puede establecerse en cualquier valor negativo en la primera llamada, para comenzar la búsqueda desde el principio de la lista. El parámetro type especifica el tipo ASN1 esperado para el valor del atributo, por ejemplo, V_ASN1_UTF8STRING.

X509_ATTRIBUTE_get0_data() devuelve los datos asociados con el índice idx del atributo attr. El parámetro type especifica el tipo ASN1 esperado para el valor del atributo. El resultado se copia en el buffer data. Si data es NULL, se asigna memoria para él y el llamador se hace responsable de liberarla.

X509_ATTRIBUTE_count() devuelve el número de valores de atributos contenidos en attr.

X509_ATTRIBUTE_get0_object() devuelve el objeto ASN1_OBJECT contenido en attr.

X509_ATTRIBUTE_get0_type() devuelve el tipo ASN1_TYPE contenido en el índice idx del atributo attr.

VALORES DE RETORNO

X509at_get_attr_count(), X509at_get_attr_by_NID() y X509at_get_attr_by_OBJ() devuelven el número de atributos o el índice del atributo buscado, o -1 en caso de error.

X509at_get_attr() devuelve un puntero a un objeto X509_ATTRIBUTE, o NULL si ocurre un error.

X509at_delete_attr() devuelve 1 en caso de éxito, o 0 si ocurre un error.

X509at_add1_attr(), X509at_add1_attr_by_OBJ(), X509at_add1_attr_by_NID() y X509at_add1_attr_by_txt() devuelven un puntero a la pila de atributos modificada, o NULL si ocurre un error.

X509at_get0_data_by_OBJ() devuelve un puntero a los datos del atributo o NULL si ocurre un error.

X509_ATTRIBUTE_create(), X509_ATTRIBUTE_create_by_NID(), X509_ATTRIBUTE_create_by_OBJ() y X509_ATTRIBUTE_create_by_txt() devuelven un puntero a un nuevo objeto X509_ATTRIBUTE o NULL si ocurre un error.

X509_ATTRIBUTE_set1_object() y X509_ATTRIBUTE_set1_data() devuelven 1 en caso de éxito, o 0 si ocurre un error.

X509_ATTRIBUTE_get0_data() devuelve un puntero a los datos del atributo, o NULL si ocurre un error.

X509_ATTRIBUTE_count() devuelve el número de valores de atributos.

X509_ATTRIBUTE_get0_object() devuelve un puntero al objeto ASN1_OBJECT.

X509_ATTRIBUTE_get0_type() devuelve un puntero al tipo ASN1_TYPE.

DESCRIPTION

An X509_ATTRIBUTE object represents a single X.509 attribute. Attributes are identified by an object identifier (OID) and contain one or more typed values. The type is determined by the ASN1 tag.

The functions described here allow manipulation of attribute lists (represented by STACK_OF(X509_ATTRIBUTE)) and individual X509_ATTRIBUTE objects.

X509_ATTRIBUTE_create(), X509_ATTRIBUTE_create_by_OBJ(), X509_ATTRIBUTE_create_by_NID() and X509_ATTRIBUTE_create_by_txt() create and return a new X509_ATTRIBUTE object. The nid parameter is the numeric identifier for the attribute's OID (if known). The obj parameter is the ASN1_OBJECT identifier itself. The type parameter is the ASN1 type tag for the value, for example V_ASN1_IA5STRING, V_ASN1_BMPSTRING, V_ASN1_UTF8STRING, etc. The data and len parameters specify the attribute value. The s parameter for X509_ATTRIBUTE_create_by_txt() is a null-terminated string from which the value is derived.

X509_ATTRIBUTE_set1_object() and X509_ATTRIBUTE_set1_data() are used to set the object identifier and value of an existing X509_ATTRIBUTE respectively. The existing contents are freed and replaced.

X509at_add1_attr(), X509at_add1_attr_by_OBJ(), X509at_add1_attr_by_NID() and X509at_add1_attr_by_txt() add a new attribute to the attribute list attr_list. If attr_list is NULL, a new list is created. The new attribute is created using the specified OID (or NID, or text string), type, data, and length.

X509at_find_attr() searches the attribute list attr_list for an attribute with the specified nid and returns it, or NULL if not found.

X509at_get_attr_count() returns the number of attributes in the list attr_list.

X509at_get_attr() returns the attribute at the specified location loc in the list attr_list.

X509at_get_attr_by_OBJ() and X509at_get_attr_by_NID() search the attribute list attr_list for an attribute matching the specified obj or nid. The search starts from index lastpos. If lastpos is -1, the search starts from the beginning of the list. The functions return the index of the found attribute, or -1 if not found. X509at_get_attr_by_NID() also returns -2 if the nid is not known to OpenSSL.

X509at_delete_attr() removes the attribute at the specified location loc from the list attr_list and returns it.

X509at_get0_data_by_OBJ() searches the attribute list x for an attribute matching the specified obj starting at index lastpos. It returns the data from the first ASN1_TYPE object within the found attribute. The type parameter is used to specify the expected type of the attribute value and is also used to return the actual type of the found attribute value. The value type can be set to V_ASN1_BOOLEAN or V_ASN1_NULL to indicate an error. The parameter lastpos is used to continue a search. If lastpos is less than -1 then an error will occur if there are multiple objects in the list x that match obj. If lastpos is less than -2 then an error will occur if there is more than one ASN1_TYPE object in the found attribute.

X509_ATTRIBUTE_count() returns the number of ASN1_TYPE objects within an attribute attr.

X509_ATTRIBUTE_get0_type() returns the ASN1_TYPE object at index idx within the attribute attr.

X509_ATTRIBUTE_get0_data() returns the data of an ASN1_TYPE object at index idx within the attribute attr. The atrtype parameter is used to specify the expected type of the attribute value. An error will occur if the attribute type atrtype does not match the type of the ASN1_TYPE object at index idx, or if atrtype is either V_ASN1_BOOLEAN or V_ASN1_NULL, or if the idx is out of range.

See <openssl/obj_mac.h> for a list of NIDs and <openssl/asn1.h> for a list of ASN1 types.

The functions named X509at_add1_attr... increment the reference count of the attribute being added, hence the '1' in the name. Similarly, the functions named X509at_get0_... return a pointer to data without incrementing the reference count, hence the '0' in the name. Users should be careful to manage the reference counts correctly.

X509at_get0_data_by_OBJ() is similar to X509at_get_attr_by_OBJ() except that it returns the data associated with the attribute, rather than the attribute itself. It is also similar to X509_ATTRIBUTE_get0_data() except that it searches for the attribute using an obj identifier.

RETURN VALUES

X509_ATTRIBUTE_create(), X509_ATTRIBUTE_create_by_OBJ(), X509_ATTRIBUTE_create_by_NID() and X509_ATTRIBUTE_create_by_txt() return a pointer to the newly created X509_ATTRIBUTE, or NULL on error.

X509_ATTRIBUTE_set1_object() and X509_ATTRIBUTE_set1_data() return 1 on success, or 0 on error.

X509_ATTRIBUTE_count() returns the number of ASN1_TYPE objects in the attribute, or -1 on error.

X509_ATTRIBUTE_get0_type() returns a pointer to the ASN1_TYPE object, or NULL on error.

X509_ATTRIBUTE_get0_data() returns a pointer to the attribute data, or NULL on error.

X509at_add1_attr(), X509at_add1_attr_by_OBJ(), X509at_add1_attr_by_NID() and X509at_add1_attr_by_txt() return a pointer to the updated attribute list, or NULL on error.

X509at_find_attr() returns a pointer to the found X509_ATTRIBUTE, or NULL if not found or on error.

X509at_get_attr_count() returns the number of attributes in the list, or -1 on error.

X509at_get_attr() returns a pointer to the X509_ATTRIBUTE at the specified location, or NULL on error.

X509at_get_attr_by_OBJ() and X509at_get_attr_by_NID() return the index of the found attribute, or -1 if not found. They return -2 if the nid is not known to OpenSSL in the case of X509at_get_attr_by_NID().

X509at_delete_attr() returns a pointer to the removed X509_ATTRIBUTE, or NULL on error.

X509at_get0_data_by_OBJ() returns a pointer to the attribute data, or NULL on error.
