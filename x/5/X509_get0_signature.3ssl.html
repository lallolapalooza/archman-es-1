X509_get0_signature(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_GET0_SIGNATURE(3ssl) OpenSSL X509_GET0_SIGNATURE(3ssl)

NOMBRE

X509_get0_signature, X509_REQ_set0_signature, X509_REQ_set1_signature_algo, X509_get_signature_nid, X509_get0_tbs_sigalg, X509_REQ_get0_signature, X509_REQ_get_signature_nid, X509_CRL_get0_signature, X509_CRL_get_signature_nid, X509_CRL_get0_tbs_sigalg, X509_get_signature_info, X509_SIG_INFO_get, X509_SIG_INFO_set, X509_ACERT_get0_signature, X509_ACERT_get0_info_sigalg, X509_ACERT_get_signature_nid - información de firma

SINOPSIS

 #include <openssl/x509.h>
 void X509_get0_signature(const ASN1_BIT_STRING **psig,
                          const X509_ALGOR **palg,
                          const X509 *x);
 void X509_REQ_set0_signature(X509_REQ *req, ASN1_BIT_STRING *psig);
 int X509_REQ_set1_signature_algo(X509_REQ *req, X509_ALGOR *palg);
 int X509_get_signature_nid(const X509 *x);
 const X509_ALGOR *X509_get0_tbs_sigalg(const X509 *x);
 void X509_REQ_get0_signature(const X509_REQ *crl,
                              const ASN1_BIT_STRING **psig,
                              const X509_ALGOR **palg);
 int X509_REQ_get_signature_nid(const X509_REQ *crl);
 const X509_ALGOR *X509_ACERT_get0_info_sigalg(const X509_ACERT *x);
 void X509_CRL_get0_signature(const X509_CRL *crl,
                              const ASN1_BIT_STRING **psig,
                              const X509_ALGOR **palg);
 int X509_CRL_get_signature_nid(const X509_CRL *crl);
 const X509_ALGOR *X509_CRL_get0_tbs_sigalg(const X509_crl *crl);
 int X509_get_signature_info(X509 *x, int *mdnid, int *pknid, int *secbits,
                             uint32_t *flags);
 int X509_SIG_INFO_get(const X509_SIG_INFO *siginf, int *mdnid, int *pknid,
                      int *secbits, uint32_t *flags);
 void X509_SIG_INFO_set(X509_SIG_INFO *siginf, int mdnid, int pknid,
                        int secbits, uint32_t flags);
 #include <openssl/x509_acert.h>
 void X509_ACERT_get0_signature(const X509_ACERT *x,
                                const ASN1_BIT_STRING **psig,
                                const X509_ALGOR **palg);
 int X509_ACERT_get_signature_nid(const X509_ACERT *x);
=head1 DESCRIPTION

X509_get0_signature() establece *psig a la firma de x y *palg al algoritmo de firma de x. Los valores devueltos son punteros internos que NO DEBEN ser liberados después de la llamada.

X509_set0_signature() y X509_REQ_set1_signature_algo() son los establecedores equivalentes para los dos valores de X509_get0_signature().

X509_get0_tbs_sigalg() y X509_CRL_get0_tbs_sigalg() devuelven el algoritmo de firma en la parte firmada del certificado o CRL.

X509_get_signature_nid() devuelve el NID correspondiente al algoritmo de firma de x.

X509_REQ_get0_signature(), X509_REQ_get_signature_nid() X509_CRL_get0_signature() y X509_CRL_get_signature_nid() realizan la misma función para solicitudes de certificado y CRLs.

X509_get_signature_info() recupera información sobre la firma del certificado x. El NID del digest de firma se escribe en *mdnid, el algoritmo de clave pública en *pknid, los bits de seguridad efectivos en *secbits y detalles de las banderas en *flags. Cualquiera de los parámetros puede establecerse a NULL si la información no se requiere.

X509_SIG_INFO_get() y X509_SIG_INFO_set() obtienen y establecen información sobre una firma en una estructura X509_SIG_INFO. Solo son utilizados por implementaciones de algoritmos que necesitan establecer información de firma personalizada: la mayoría de las aplicaciones nunca necesitarán llamarlos.

X509_ACERT_get0_signature(), X509_ACERT_get_signature_nid() y X509_ACERT_get0_info_sigalg() realizan la misma función para certificados de atributo.

NOTAS

Estas funciones proporcionan acceso de nivel inferior a las firmas en certificados donde una aplicación desea analizar o generar una firma en un formato para el cual X509_sign() y similares no son apropiados (por ejemplo, un formato no estándar o no soportado).

Los bits de seguridad devueltos por X509_get_signature_info() se refieren a información disponible de la firma del certificado (como el digest de firma). En algunos casos, la seguridad real de la firma es menor porque la clave de firma es menos segura: por ejemplo, un certificado firmado usando SHA-512 y una clave RSA de 1024 bits.

VALORES DE RETORNO

X509_get_signature_nid(), X509_REQ_get_signature_nid() y X509_CRL_get_signature_nid() devuelven un NID.

X509_get0_signature(), X509_REQ_get0_signature() y X509_CRL_get0_signature() no devuelven valores.

X509_get_signature_info() devuelve 1 si la información de firma devuelta es válida o 0 si la información no está disponible (por ejemplo, algoritmos desconocidos o parámetros mal formados).

X509_REQ_set1_signature_algo() devuelve 0 en caso de éxito; o 1 en caso de error (por ejemplo, puntero ALGO nulo). X509_REQ_set0_signature no devuelve un valor de error.

NOMBRE

X509_get0_signature, X509_get0_tbs, X509_get0_raw_data - obtener información de firma de un certificado X509

SINÓPSIS


#include <openssl/x509.h>

int X509_get0_signature(X509_ALGOR *alg, const ASN1_BIT_STRING **sig, const X509 *x);
int X509_get0_tbs(ASN1_STRING **ptbs, const X509 *x);
int X509_get0_raw_data(ASN1_STRING **praw_data, const X509 *x);

DESCRIPCIÓN

La función X509_get0_signature() recupera el algoritmo de firma y la firma del certificado x.

El campo alg debe ser un puntero a un X509_ALGOR que será llenado con el algoritmo de firma. El campo sig debe ser un puntero a un puntero ASN1_BIT_STRING que apuntará a la firma del certificado.

La función X509_get0_tbs() recupera los datos del certificado "To Be Signed" (TBS). Los datos TBS son la parte del certificado que se firma. El campo ptbs será llenado con un puntero a una ASN1_STRING que contiene los datos TBS.

La función X509_get0_raw_data() recupera los datos sin procesar del certificado. Esto incluye el encabezado, los datos TBS y la firma. El campo praw_data será llenado con un puntero a una ASN1_STRING que contiene los datos sin procesar.

VALORES DE RETORNO

X509_get0_signature(), X509_get0_tbs() y X509_get0_raw_data() devuelven 1 en caso de éxito y 0 en caso de error.

VER TAMBIÉN

X509(3ssl)

HISTORIA

Las funciones X509_get0_signature(), X509_get0_tbs() y X509_get0_raw_data() se añadieron en OpenSSL 1.1.0.
