X509V3_GET_D2I(3ssl) OpenSSL X509V3_GET_D2I(3ssl)

NOMBRE

X509V3_get_d2i, X509V3_add1_i2d, X509V3_EXT_d2i, X509V3_EXT_i2d, X509_get_ext_d2i, X509_add1_ext_i2d, X509_ACERT_get_ext_d2i, X509_ACERT_add1_ext_i2d, X509_CRL_get_ext_d2i, X509_CRL_add1_ext_i2d, X509_REVOKED_get_ext_d2i, X509_REVOKED_add1_ext_i2d, X509_get0_extensions, X509_ACERT_get0_extensions, X509_CRL_get0_extensions, X509_REVOKED_get0_extensions - funciones de decodificación y codificación de extensiones X509

SINOPSIS

#include <openssl/x509v3.h>
void *X509V3_get_d2i(const STACK_OF(X509_EXTENSION) *x, int nid, int *crit,
                     int *idx);
int X509V3_add1_i2d(STACK_OF(X509_EXTENSION) **x, int nid, void *value,
                    int crit, unsigned long flags);
void *X509V3_EXT_d2i(X509_EXTENSION *ext);
X509_EXTENSION *X509V3_EXT_i2d(int ext_nid, int crit, void *ext_struc);
void *X509_get_ext_d2i(const X509 *x, int nid, int *crit, int *idx);
int X509_add1_ext_i2d(X509 *x, int nid, void *value, int crit,
                      unsigned long flags);
void *X509_ACERT_get_ext_d2i(const X509_ACERT *x, int nid, int *crit, int *idx);
int X509_ACERT_add1_ext_i2d(X509_ACERT *x, int nid, void *value, int crit,
                            unsigned long flags);
void *X509_CRL_get_ext_d2i(const X509_CRL *crl, int nid, int *crit, int *idx);
int X509_CRL_add1_ext_i2d(X509_CRL *crl, int nid, void *value, int crit,
                          unsigned long flags);
void *X509_REVOKED_get_ext_d2i(const X509_REVOKED *r, int nid, int *crit, int *idx);
int X509_REVOKED_add1_ext_i2d(X509_REVOKED *r, int nid, void *value, int crit,
                              unsigned long flags);
const STACK_OF(X509_EXTENSION) *X509_get0_extensions(const X509 *x);
const STACK_OF(X509_EXTENSION) *X509_ACERT_get0_extensions(const X509 *x);
const STACK_OF(X509_EXTENSION) *X509_CRL_get0_extensions(const X509_CRL *crl);
const STACK_OF(X509_EXTENSION) *X509_REVOKED_get0_extensions(const X509_REVOKED *r);

DESCRIPCIÓN

X509V3_get_d2i() busca una extensión con el OID nid en las extensiones x y, si la encuentra, la decodifica. Si idx es NULL, entonces solo se permite una ocurrencia de una extensión, de lo contrario, se devuelve la primera extensión después del índice *idx y *idx se actualiza a la ubicación de la extensión. Si crit no es NULL, entonces *crit se establece en un valor de estado: -2 si la extensión ocurre múltiples veces (esto solo se devuelve si idx es NULL), -1 si la extensión no se pudo encontrar, 0 si la extensión se encuentra y no es crítica, y 1 si es crítica. Se devuelve un puntero a una estructura específica de la extensión o NULL.

X509V3_add1_i2d() agrega la extensión value a la PILA *x (asignando una nueva PILA si es necesario) utilizando el OID nid y la criticidad crit de acuerdo con flags.

X509V3_EXT_d2i() intenta decodificar los datos ASN.1 contenidos en la extensión ext y devuelve un puntero a una estructura específica de la extensión o NULL si la extensión no se pudo decodificar (sintaxis inválida o no admitida).

X509V3_EXT_i2d() codifica la estructura específica de la extensión ext_struc con el OID ext_nid y la criticidad crit.

X509_get_ext_d2i() y X509_add1_ext_i2d() operan en las extensiones del certificado x. Por lo demás, son idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_ACERT_get_ext_d2i() y X509_ACERT_add1_ext_i2d() operan en las extensiones de la estructura X509_ACERT x. Por lo demás, son idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_CRL_get_ext_d2i() y X509_CRL_add1_ext_i2d() operan en las extensiones de la CRL crl. Por lo demás, son idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_REVOKED_get_ext_d2i() y X509_REVOKED_add1_ext_i2d() operan en las extensiones de la estructura X509_REVOKED r (es decir, para extensiones de entrada de CRL). Por lo demás, son idénticas a X509V3_get_d2i() y X509V3_add1_i2d().

X509_get0_extensions(), X509_ACERT_get0_extensions(), X509_CRL_get0_extensions() y X509_REVOKED_get0_extensions() devuelven una PILA de todas las extensiones de un certificado, un certificado de atributo, una CRL o una entrada de CRL respectivamente.

NOTAS

En casi todos los casos, una extensión puede ocurrir como máximo una vez y múltiples ocurrencias son un error. Por lo tanto, el parámetro idx suele ser NULL.

El parámetro flags puede ser uno de los siguientes valores.

X509V3_ADD_DEFAULT agrega una nueva extensión solo si la extensión no existe. Se devuelve un error si la extensión existe.

X509V3_ADD_APPEND agrega una nueva extensión, ignorando si la extensión existe.

X509V3_ADD_REPLACE reemplaza una extensión existente. Si la extensión no existe, agrega una nueva extensión.

X509V3_ADD_REPLACE_EXISTING reemplaza una extensión existente. Si la extensión no existe, devuelve un error.

X509V3_ADD_KEEP_EXISTING agrega una nueva extensión solo si la extensión no existe. No se devuelve un error si la extensión existe.

X509V3_ADD_DELETE elimina y libera una extensión existente. Si la extensión no existe, devuelve un error. No se agrega ninguna extensión nueva.

Si X509V3_ADD_SILENT se combina bit a bit con flags: cualquier error devuelto no se agregará a la cola de errores.

La función X509V3_get_d2i() y sus variantes devolverán NULL si la extensión no se encuentra, ocurre múltiples veces o no se puede decodificar. Es posible determinar la razón exacta comprobando el valor de *crit. El puntero devuelto debe liberarse explícitamente.

La función X509V3_add1_i2d() y sus variantes asignan objetos X509_EXTENSION en la PILA *x dependiendo de flags. Los objetos X509_EXTENSION deben liberarse explícitamente usando X509_EXTENSION_free().

DESCRIPTION

These functions provide an API for accessing and manipulating X.509 certificate extensions. The extensions are encoded in ASN.1. The functions can convert between the ASN.1 encoding and native C structures.

The OpenSSL library defines a large number of standard extension types. These are identified by a numerical Object Identifier (OID) value. The NID (numeric identifier) is a convenient way to refer to these OIDs within the OpenSSL library.

A full list of supported NIDs can be found in the source code file crypto/x509v3/ext_list.c.

RETURN VALUES

X509V3_get_d2i(), its variants, and X509V3_EXT_d2i() return a pointer to an extension specific structure or NULL if an error occurs.

X509V3_add1_i2d() and its variants return 1 if the operation is successful and 0 if it fails due to a non-fatal error (extension not found, already exists, cannot be encoded) or -1 due to a fatal error such as a memory allocation failure.

X509V3_EXT_i2d() returns a pointer to an X509_EXTENSION structure or NULL if an error occurs.

X509_get0_extensions(), X509_CRL_get0_extensions() and X509_REVOKED_get0_extensions() return a stack of extensions. They return NULL if no extensions are present.
