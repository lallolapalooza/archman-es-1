X509_ACERT_print_ex(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_ACERT_PRINT_EX(3ssl) OpenSSL X509_ACERT_PRINT_EX(3ssl)

NOMBRE

X509_ACERT_PRINT_EX, X509_ACERT_PRINT - Rutinas de impresión de X509_ACERT

SINOPSIS

#include <openssl/x509_acert.h>
int X509_ACERT_print(BIO *bp, X509_ACERT *acert);
int X509_ACERT_print_ex(BIO *bp, X509_ACERT *acert, unsigned long nmflags,
                        unsigned long cflag);

DESCRIPCIÓN

X509_ACERT_print_ex() imprime una versión legible por humanos del certificado de atributo acert en el BIO bp.

Los siguientes datos contenidos en el certificado de atributo se imprimen en orden:

•
Los encabezados "Attribute certificate:" y "Data:" (X509_FLAG_NO_HEADER)

= elemento *

El número de versión del certificado de atributo según lo definido por el estándar, seguido entre paréntesis por el valor contenido en el campo de versión en notación hexadecimal. Si el número de versión no es un valor válido según la especificación, solo se imprime el valor bruto. Consulte X509_ACERT_get_version(3) para más detalles. (X509_FLAG_NO_VERSION)

= elemento *

El número de serie del certificado de atributo (X509_FLAG_NO_SERIAL)

= elemento *

La identidad del titular del certificado de atributo. Si el nombre del emisor del titular está presente, se imprime el primer GENERAL_NAME devuelto por X509_ACERT_get0_holder_entityName(). Si el baseCertificateId del titular está presente, se muestran el nombre del emisor (impreso con X509_NAME_print_ex) y el número de serie del certificado del titular. (X509_FLAG_NO_SUBJECT)

= elemento *

El nombre del emisor del certificado de atributo devuelto por X509_ACERT_get0_issuerName() e impreso usando X509_NAME_print_ex(). (X509_FLAG_NO_ISSUER)

= elemento *

El período de validez entre las fechas devueltas por X509_ACERT_get0_notBefore() y X509_ACERT_get0_notAfter(). Los valores se imprimen como tiempos generalizados usando ASN1_GENERALIZEDTIME_print(). (X509_FLAG_NO_VALIDITY)

= elemento *

La lista de atributos contenidos en el certificado de atributo. El tipo de atributo se imprime con i2a_ASN1_OBJECT(). Los atributos con valor de cadena se imprimen como datos de cadena brutos. Los valores codificados en ASN1 se imprimen con ASN1_parse_dump(). (X509_FLAG_NO_ATTRIBUTES)

= elemento *

Todas las extensiones X.509 contenidas en el certificado de atributo. (X509_FLAG_NO_EXTENSIONS)

= elemento *

La firma se imprime con X509_signature_print(). (X509_FLAG_NO_SIGDUMP)

Si cflag se especifica como X509_FLAG_COMPAT, se imprimirán todos los datos anteriores del certificado de atributo.

La bandera nmflags determina el formato utilizado para imprimir todos los campos impresos con X509_NAME_print_ex(). Consulte X509_NAME_print_ex(3) para más detalles.

X509_ACERT_print() es equivalente a llamar a X509_ACERT_print_ex() con nmflags y cflags establecidos en XN_FLAG_COMPAT y X509_FLAG_COMPAT respectivamente.

VALORES DE RETORNO

X509_ACERT_print_ex() X509_ACERT_print() devuelven 1 en caso de éxito y 0 en caso de fallo.

VER TAMBIÉN

X509_NAME_print_ex(3)

HISTORIAL

X509_ACERT_print() y X509_ACERT_print_ex() se añadieron en OpenSSL 3.4.
