DESCRIPCIÓN

X509_STORE_set_verify_cb() establece la función de devolución de llamada de verificación de xs a verify_cb, sobrescribiendo la anterior. La función de devolución de llamada asignada con esta función se convierte en un valor predeterminado para la que se puede asignar directamente a la X509_STORE_CTX correspondiente, consulte X509_STORE_CTX_set_verify_cb(3) para obtener más información.

X509_STORE_set_verify() establece la función final de verificación de la cadena para xs a verify. Su propósito es recorrer la cadena de certificados y verificar que todas las firmas sean válidas y que la hora actual esté dentro de los límites del primer y último tiempo de validez de cada certificado. Las funciones de verificación de cadena finales deben devolver 0 en caso de fallo y 1 en caso de éxito. Si no se proporciona ninguna función de verificación de cadena, se utilizará la función interna predeterminada en su lugar.

X509_STORE_CTX_get1_issuer() intenta encontrar un certificado del componente store de ctx cuyo nombre de sujeto coincida con el nombre del emisor de x y que sea aceptado por la función check_issued en ctx. En caso de éxito, asigna a *issuer la primera coincidencia que tenga un período de validez adecuado o, de lo contrario, tenga la fecha de expiración más reciente de todos los certificados coincidentes. Si la función devuelve 1, el llamante es responsable de liberar *issuer. Tenga en cuenta que esta búsqueda no admite retroceso.

X509_STORE_set_get_issuer() establece la función get_issuer que se utiliza para obtener el certificado emisor "mejor" candidato del certificado dado x. Cuando se encuentra dicho certificado, get_issuer debe incrementarlo y asignarlo a *issuer y luego devolver 1. De lo contrario, get_issuer debe devolver 0 si no se encuentra y -1 (o 0) en caso de fallo. Si X509_STORE_set_get_issuer() no se utiliza o get_issuer es NULL, entonces X509_STORE_CTX_get1_issuer() se utiliza como implementación predeterminada.

X509_STORE_set_check_issued() establece la función para verificar que un certificado dado x ha sido emitido por el certificado emisor issuer. Esta función debe devolver 0 en caso de fallo (entre otras cosas, si x no ha sido emitido por issuer) y 1 en caso de éxito. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_check_revocation() establece la función de verificación de revocación. Su propósito es recorrer la cadena final y verificar el estado de revocación de cada certificado. Debe devolver 0 en caso de fallo y 1 en caso de éxito. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_get_crl() establece la función para obtener la crl para un certificado dado x. Cuando se encuentra, la crl debe asignarse a *crl. Esta función debe devolver 0 en caso de fallo y 1 en caso de éxito. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_check_crl() establece la función para verificar la validez de la crl dada. Esta función debe devolver 0 en caso de fallo y 1 en caso de éxito. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_cert_crl() establece la función para verificar el estado de revocación del certificado dado x contra la crl dada. Esta función debe devolver 0 en caso de fallo y 1 en caso de éxito. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_check_policy() establece la función para verificar las políticas de todos los certificados en la cadena final. Esta función debe devolver 0 en caso de fallo y 1 en caso de éxito. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada.

X509_STORE_set_lookup_certs() establece la función para buscar certificados con el nombre de sujeto nm. Debe devolver una pila de certificados coincidentes o NULL si no se encuentra ninguno. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_lookup_crls() establece la función para buscar CRLs con el nombre de sujeto nm. Debe devolver una pila de CRLs coincidentes o NULL si no se encuentra ninguna. Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.

X509_STORE_set_cleanup() establece la función de limpieza para el contexto de verificación. Si no se proporciona ninguna función de limpieza, se utilizará la función interna predeterminada en su lugar.

Las funciones X509_STORE_get_*() devuelven la función correspondiente actualmente establecida para ctx.

Los alias X509_STORE_set_verify_cb_func(), X509_STORE_set_verify_func() y X509_STORE_set_lookup_crls_cb() son proporcionados para compatibilidad con versiones anteriores.

En caso de éxito, las funciones que establecen devuelven 1, y en caso de fallo devuelven 0. Las funciones que obtienen devuelven la función establecida actualmente.

El valor de retorno de las funciones de devolución de llamada varía. Consulte las descripciones individuales de las funciones para obtener más detalles.

DESCRIPTION

The functions described here are used to set and get various callback functions used by an X509_STORE object. These callbacks are invoked during the certificate verification process.

X509_STORE_set_verify_cb_func(), X509_STORE_set_verify_func() and X509_STORE_set_lookup_crls_cb() are macros for backward compatibility with older versions of OpenSSL. They are equivalent to X509_STORE_set_verify_cb(), X509_STORE_set_verify() and X509_STORE_set_lookup_crls respectively.

X509_STORE_set_verify_cb() sets the callback function used for verification. The function pointed to by cb is called when verifying a certificate chain.

X509_STORE_set_get_issuer() sets the callback function used to retrieve a certificate's issuer. This is used when building the certificate chain.

X509_STORE_set_check_issued() sets the callback function used to check if a certificate was issued by a given issuer.

X509_STORE_set_check_revocation() sets the callback function used to check if a certificate has been revoked.

X509_STORE_set_get_crl() sets the callback function used to retrieve a Certificate Revocation List (CRL) for a given issuer.

X509_STORE_set_check_crl() sets the callback function used to check the validity of a CRL.

X509_STORE_set_cert_crl() sets the callback function used to associate a CRL with a certificate.

X509_STORE_set_check_policy() sets the callback function used to check the certificate policies.

X509_STORE_set_lookup_certs() and X509_STORE_set_lookup_crls() set the functions to look up all the certs or all the CRLs that match the given name nm. These functions return NULL on failure and a pointer to a stack of certificates (X509) or to a stack of CRLs (X509_CRL) on success. If no function to get the issuer is provided, the internal default function will be used instead.

X509_STORE_set_cleanup() sets the final cleanup function, which is called when the context (X509_STORE_CTX) is being torn down. This function doesn't return any value. If no function to get the issuer is provided, the internal default function will be used instead.

X509_STORE_set_verify_cb_func(), X509_STORE_set_verify_func() and X509_STORE_set_lookup_crls_cb() are aliases for X509_STORE_set_verify_cb(), X509_STORE_set_verify() and X509_STORE_set_lookup_crls, available as macros for backward compatibility.

NOTES

All the callbacks from a X509_STORE are inherited by the corresponding X509_STORE_CTX structure when it is initialized. See X509_STORE_CTX_set_verify_cb(3) for further details.

BUGS

The macro version of this function was the only one available before OpenSSL 1.0.0.

RETURN VALUES

The X509_STORE_set_*() functions do not return a value.

The X509_STORE_get_*() functions return a pointer of the appropriate function type.

X509_STORE_CTX_get1_issuer() returns 1 if a suitable certificate is found, 0 if not found, -1 on other error.
