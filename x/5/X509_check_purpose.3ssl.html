X509_check_purpose(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_CHECK_PURPOSE(3ssl) OpenSSL X509_CHECK_PURPOSE(3ssl)

NOMBRE

X509_check_purpose, X509_PURPOSE_get_count, X509_PURPOSE_get_unused_id, X509_PURPOSE_get_by_sname, X509_PURPOSE_get_by_id, X509_PURPOSE_add, X509_PURPOSE_cleanup, X509_PURPOSE_get0, X509_PURPOSE_get_id, X509_PURPOSE_get0_name, X509_PURPOSE_get0_sname, X509_PURPOSE_get_trust, X509_PURPOSE_set - funciones relacionadas con la comprobación del propósito de un certificado

SINOPSIS

#include <openssl/x509v3.h>
int X509_check_purpose(X509 *x, int id, int ca);
int X509_PURPOSE_get_count(void);
int X509_PURPOSE_get_unused_id(OSSL_LIB_CTX *libctx);
int X509_PURPOSE_get_by_sname(const char *sname);
int X509_PURPOSE_get_by_id(int id);
int X509_PURPOSE_add(int id, int trust, int flags,
                     int (*ck) (const X509_PURPOSE *, const X509 *, int),
                     const char *name, const char *sname, void *arg);
void X509_PURPOSE_cleanup(void);
X509_PURPOSE *X509_PURPOSE_get0(int idx);
int X509_PURPOSE_get_id(const X509_PURPOSE *);
char *X509_PURPOSE_get0_name(const X509_PURPOSE *xp);
char *X509_PURPOSE_get0_sname(const X509_PURPOSE *xp);
int X509_PURPOSE_get_trust(const X509_PURPOSE *xp);
int X509_PURPOSE_set(int *p, int purpose);

DESCRIPCIÓN

X509_check_purpose() comprueba si el certificado x fue creado con el propósito representado por id. Si ca no es cero, entonces se comprueba el certificado x para determinar si es una CA posible con varios niveles de certeza que posiblemente se devuelvan. El certificado x debe ser un certificado completo; de lo contrario, la función devuelve un error.

A continuación se presentan los ID's potenciales que se pueden comprobar:

# define X509_PURPOSE_SSL_CLIENT        1
# define X509_PURPOSE_SSL_SERVER        2
# define X509_PURPOSE_NS_SSL_SERVER     3
# define X509_PURPOSE_SMIME_SIGN        4
# define X509_PURPOSE_SMIME_ENCRYPT     5
# define X509_PURPOSE_CRL_SIGN          6
# define X509_PURPOSE_ANY               7
# define X509_PURPOSE_OCSP_HELPER       8
# define X509_PURPOSE_TIMESTAMP_SIGN    9
# define X509_PURPOSE_CODE_SIGN        10

Las comprobaciones realizadas tienen en cuenta las extensiones X.509 keyUsage (uso de claves), extendedKeyUsage (uso extendido de claves) y basicConstraints (restricciones básicas).

X509_PURPOSE_get_count() devuelve el número de propósitos definidos actualmente.

X509_PURPOSE_get_unused_id() devuelve el ID de propósito más pequeño que aún no se ha utilizado, que está garantizado que sea único y mayor que X509_PURPOSE_MAX. El parámetro libctx debe usarse para proporcionar el contexto de la biblioteca. Actualmente se ignora ya que la tabla de mapeo de propósitos es global.

X509_PURPOSE_get_by_sname() devuelve el índice del propósito con el nombre corto dado o -1 si no se encuentra.

X509_PURPOSE_get_by_id() devuelve el índice del propósito con el ID dado o -1 si no se encuentra.

X509_PURPOSE_add() añade o modifica una entrada de propósito identificada por sname. A menos que el ID permanezca igual para una entrada existente, id debe ser nuevo, lo que se puede lograr utilizando el resultado de X509_PURPOSE_get_unused_id(). La función también establece en la entrada el ID de confianza trust, las flags dadas, el nombre (largo) del propósito name, el nombre corto sname, la función de comprobación de propósito ck de tipo int (*) (const X509_PURPOSE *, const X509 *, int) y sus datos de usuario arg que pueden recuperarse a través del puntero X509_PURPOSE.

X509_PURPOSE_cleanup() elimina todos los propósitos que no son predefinidos.

X509_PURPOSE_get0() devuelve un puntero X509_PURPOSE o NULL en caso de error.

X509_PURPOSE_get_id() devuelve el ID de la estructura X509_PURPOSE dada.

X509_PURPOSE_get0_name() devuelve el nombre (largo) de la X509_PURPOSE dada.

X509_PURPOSE_get0_sname() devuelve el nombre corto de la X509_PURPOSE dada.

X509_PURPOSE_get_trust() devuelve el ID de confianza de la X509_PURPOSE dada.

X509_PURPOSE_set() asigna el ID de purpose dado a la ubicación apuntada por p. Esto restablece a cualquier propósito si purpose es X509_PURPOSE_DEFAULT_ANY.

VALORES DE RETORNO

X509_check_purpose() devuelve los siguientes valores. Para comprobaciones que no son de CA

-1 se ha producido una condición de error
1 si el certificado se creó para realizar el propósito representado por id
0 si el certificado no se creó para realizar el propósito representado por id

Para comprobaciones de CA, los siguientes enteros podrían devolverse con los siguientes significados:

-1 se ha producido una condición de error
0 no es una CA o no tiene el propósito representado por id
1 es una CA.
2 Solo posible en versiones antiguas de openSSL cuando faltan las basicConstraints. Las versiones nuevas no devolverán este valor. Puede ser una CA
3 basicConstraints ausentes pero V1 autofirmado.
4 basicConstraints ausentes pero keyUsage presente y keyCertSign asegurado.
5 Flags de CA específicos de Netscape heredados presentes

X509_PURPOSE_get_count() devuelve el número de propósitos definidos actualmente.

X509_PURPOSE_get_unused_id() devuelve el ID de propósito más pequeño que aún no se ha utilizado.

X509_PURPOSE_get_by_sname() devuelve el índice del propósito con el nombre corto dado o -1 si no se encuentra.

X509_PURPOSE_get_by_id() devuelve el índice del propósito con el ID dado o -1 si no se encuentra.

int X509_PURPOSE_add() devuelve 1 en caso de éxito, 0 en caso de error.

X509_PURPOSE_cleanup() no devuelve nada.

X509_PURPOSE_get0() devuelve un puntero X509_PURPOSE o NULL en caso de error.

X509_PURPOSE_get_id() devuelve el ID de la estructura X509_PURPOSE dada.

X509_PURPOSE_get0_name() devuelve el nombre (largo) de la X509_PURPOSE dada.

X509_PURPOSE_get0_sname() devuelve el nombre corto de la X509_PURPOSE dada.

X509_PURPOSE_get_trust() devuelve el ID de confianza de la X509_PURPOSE dada.

X509_PURPOSE_set() devuelve 1 en caso de éxito, 0 en caso de error.

ERRORES

La implementación de X509_PURPOSE hasta ahora no es segura para hilos. Puede haber condiciones de carrera al recuperar información de propósito mientras se llama a X509_PURPOSE_add() o X509_PURPOSE_cleanup(void).

HISTORIAL

X509_PURPOSE_get_unused_id() se añadió en OpensSL 3.5.
