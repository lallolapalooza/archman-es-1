X509_digest(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_DIGEST(3ssl) OpenSSL X509_DIGEST(3ssl)

NOMBRE

X509_digest, X509_digest_sig, X509_CRL_digest, X509_pubkey_digest, X509_NAME_digest, X509_REQ_digest, PKCS7_ISSUER_AND_SERIAL_digest - obtener el resumen de varios objetos

SINOPSIS

#include <openssl/x509.h>
int X509_digest(const X509 *data, const EVP_MD *type, unsigned char *md,
                unsigned int *len);
ASN1_OCTET_STRING *X509_digest_sig(const X509 *cert,
                                   EVP_MD **md_used, int *md_is_fallback);
int X509_CRL_digest(const X509_CRL *data, const EVP_MD *type, unsigned char *md,
                    unsigned int *len);
int X509_pubkey_digest(const X509 *data, const EVP_MD *type,
                       unsigned char *md, unsigned int *len);
int X509_REQ_digest(const X509_REQ *data, const EVP_MD *type,
                    unsigned char *md, unsigned int *len);
int X509_NAME_digest(const X509_NAME *data, const EVP_MD *type,
                     unsigned char *md, unsigned int *len);
#include <openssl/pkcs7.h>
int PKCS7_ISSUER_AND_SERIAL_digest(PKCS7_ISSUER_AND_SERIAL *data,
                                   const EVP_MD *type, unsigned char *md,
                                   unsigned int *len);

DESCRIPCIÓN

X509_digest_sig() calcula un resumen del certificado dado cert utilizando el mismo algoritmo hash que en su firma, si el resumen es una parte integral del identificador del algoritmo de firma del certificado. De lo contrario, se determina un algoritmo hash de reserva: SHA512 si el algoritmo de firma es ED25519, SHAKE256 si es ED448, de lo contrario SHA256. Los parámetros de salida se asignan de la siguiente manera. A menos que md_used sea NULL, el algoritmo hash utilizado se proporciona en *md_used y debe ser liberado por el llamador (si no es NULL). A menos que md_is_fallback sea NULL, *md_is_fallback se establece en 1 si el algoritmo hash utilizado es una reserva, de lo contrario a 0.

X509_pubkey_digest() devuelve un resumen de la representación DER de la clave pública en el objeto X509 data especificado.

Todas las demás funciones descritas aquí devuelven un resumen de la representación DER de sus objetos data completos.

El parámetro type especifica el resumen a utilizar, como EVP_sha1(). El md es un puntero al búfer donde se copiará el resumen y se supone que es lo suficientemente grande; se sugiere la constante EVP_MAX_MD_SIZE. El parámetro len, si no es NULL, apunta a un lugar donde se almacenará el tamaño del resumen.

VALORES DE RETORNO

X509_digest_sig() devuelve un puntero ASN1_OCTET_STRING en caso de éxito, de lo contrario NULL.

Todas las demás funciones descritas aquí devuelven 1 para el éxito y 0 para el fallo.

VER TAMBIÉN

EVP_sha1(3)

HISTORIA

La función X509_digest_sig() se añadió en OpenSSL 3.0.
