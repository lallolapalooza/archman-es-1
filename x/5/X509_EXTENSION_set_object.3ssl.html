X509_EXTENSION_set_object(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_EXTENSION_SET_OBJECT(3ssl) OpenSSL X509_EXTENSION_SET_OBJECT(3ssl)

NOMBRE

X509_EXTENSION_set_object, X509_EXTENSION_set_critical, X509_EXTENSION_set_data, X509_EXTENSION_create_by_NID, X509_EXTENSION_create_by_OBJ, X509_EXTENSION_get_object, X509_EXTENSION_get_critical, X509_EXTENSION_get_data - funciones de utilidad para extensiones

SINOPSIS

int X509_EXTENSION_set_object(X509_EXTENSION *ex, const ASN1_OBJECT *obj);
int X509_EXTENSION_set_critical(X509_EXTENSION *ex, int crit);
int X509_EXTENSION_set_data(X509_EXTENSION *ex, ASN1_OCTET_STRING *data);
X509_EXTENSION *X509_EXTENSION_create_by_NID(X509_EXTENSION **ex,
                                             int nid, int crit,
                                             ASN1_OCTET_STRING *data);
X509_EXTENSION *X509_EXTENSION_create_by_OBJ(X509_EXTENSION **ex,
                                             const ASN1_OBJECT *obj, int crit,
                                             ASN1_OCTET_STRING *data);
ASN1_OBJECT *X509_EXTENSION_get_object(X509_EXTENSION *ex);
int X509_EXTENSION_get_critical(const X509_EXTENSION *ex);
ASN1_OCTET_STRING *X509_EXTENSION_get_data(X509_EXTENSION *ne);

DESCRIPCIÓN

X509_EXTENSION_set_object() establece el tipo de extensión de ex a obj. El puntero obj se duplica internamente, por lo que se debe liberar obj después de su uso.

X509_EXTENSION_set_critical() establece la criticidad de ex a crit. Si crit es cero, la extensión no es crítica, de lo contrario, es crítica.

X509_EXTENSION_set_data() establece los datos de la extensión ex a data. El puntero data se duplica internamente.

X509_EXTENSION_create_by_NID() crea una extensión de tipo nid, criticidad crit utilizando los datos data. La extensión creada se devuelve y se escribe en *ex, reutilizando o asignando una nueva extensión si es necesario, por lo que *ex debe ser NULL o una estructura X509_EXTENSION válida; no debe ser un puntero no inicializado.

X509_EXTENSION_create_by_OBJ() es idéntica a X509_EXTENSION_create_by_NID() excepto que crea una extensión usando obj en lugar de un NID.

X509_EXTENSION_get_object() devuelve el tipo de extensión de ex como un puntero ASN1_OBJECT. El puntero devuelto es un valor interno que no debe liberarse.

X509_EXTENSION_get_critical() devuelve la criticidad de la extensión ex; devuelve 1 para crítica y 0 para no crítica.

X509_EXTENSION_get_data() devuelve los datos de la extensión ex. El puntero devuelto es un valor interno que no debe liberarse.

NOTAS

Estas funciones manipulan el contenido de una extensión directamente. La mayoría de las aplicaciones querrán analizar o codificar y agregar una extensión; deberían usar las funciones de codificación y decodificación de extensiones en su lugar, como X509_add1_ext_i2d() y X509_get_ext_d2i().

Los datos asociados con una extensión son la codificación de la extensión en una estructura ASN1_OCTET_STRING.

VALORES DEVUELTOS

X509_EXTENSION_set_object(), X509_EXTENSION_set_critical() y X509_EXTENSION_set_data() devuelven 1 en caso de éxito y 0 en caso de fallo.

X509_EXTENSION_create_by_NID() y X509_EXTENSION_create_by_OBJ() devuelven un puntero X509_EXTENSION o NULL si ocurre un error.

X509_EXTENSION_get_object() devuelve un puntero ASN1_OBJECT.

X509_EXTENSION_get_critical() devuelve 0 para no crítica y 1 para crítica.

X509_EXTENSION_get_data() devuelve un puntero ASN1_OCTET_STRING.
