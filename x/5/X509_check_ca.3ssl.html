X509_check_ca(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_CHECK_CA(3ssl) OpenSSL X509_CHECK_CA(3ssl)

NOMBRE

X509_check_ca - comprobar si un certificado dado es un certificado CA

SINOPSIS

#include <openssl/x509v3.h>
int X509_check_ca(X509 *cert);

DESCRIPCIÓN

Esta función comprueba si un certificado dado es un certificado CA (puede ser utilizado para firmar otros certificados). El certificado debe ser un certificado completo, de lo contrario se devolverá un error.

VALORES DE RETORNO

La función devuelve 0 si no es un certificado CA, 1 si es un certificado CA X509v3 apropiado con la extensión basicConstraints CA:TRUE, 3 si es un certificado v1 X509 autofirmado, 4 si es un certificado con la extensión keyUsage con el bit keyCertSign establecido, pero sin basicConstraints, y 5 si tiene una extensión obsoleta Netscape Certificate Type que indica que es un certificado CA.

Esta función también devolverá 0 en caso de error.

De hecho, cualquier valor distinto de cero significa que este certificado podría haber sido utilizado para firmar otros certificados.

VER TAMBIÉN

X509_verify_cert(3), X509_check_issued(3), X509_check_purpose(3)
