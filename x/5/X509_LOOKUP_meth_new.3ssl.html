DESCRIPCIÓN

El tipo X509_LOOKUP_METHOD es una estructura utilizada para la implementación de nuevos tipos X509_LOOKUP. Proporciona un conjunto de funciones utilizadas por OpenSSL para la implementación de varias capacidades de búsqueda de X509 y X509_CRL. Una instancia de X509_LOOKUP_METHOD puede asociarse a muchas instanciaciones de la estructura X509_LOOKUP.

X509_LOOKUP_meth_new() crea una estructura X509_LOOKUP_METHOD nueva. Se le debe proporcionar una cadena legible por humanos que contenga una breve descripción del método de búsqueda.

X509_LOOKUP_meth_free() destruye una estructura X509_LOOKUP_METHOD. Si el argumento es NULL, no se hace nada.

X509_LOOKUP_get_new_item() y X509_LOOKUP_set_new_item() obtienen y establecen la función que se llama cuando se crea un objeto X509_LOOKUP con X509_LOOKUP_new(). Si un X509_LOOKUP_METHOD requiere datos específicos por X509_LOOKUP, la función new_item proporcionada debería asignar estos datos e invocar X509_LOOKUP_set_method_data(3).

X509_LOOKUP_get_free() y X509_LOOKUP_set_free() obtienen y establecen la función que se utiliza para liberar cualquier dato del método que fue asignado y establecido desde la función new_item.

X509_LOOKUP_meth_get_init() y X509_LOOKUP_meth_set_init() obtienen y establecen la función que se utiliza para inicializar los datos del método que se establecieron con X509_LOOKUP_set_method_data(3) como parte de la rutina new_item.

X509_LOOKUP_meth_get_shutdown() y X509_LOOKUP_meth_set_shutdown() obtienen y establecen la función que se utiliza para cerrar los datos del método cuyo estado fue previamente inicializado en la función init.

X509_LOOKUP_meth_get_ctrl() y X509_LOOKUP_meth_set_ctrl() obtienen y establecen una función para manejar comandos de control arbitrarios emitidos por X509_LOOKUP_ctrl(). La función de control recibe el X509_LOOKUP ctx, junto con los argumentos pasados por X509_LOOKUP_ctrl. cmd es un entero arbitrario que define alguna operación. argc es un puntero a un array de caracteres. argl es un entero. ret, si se establece, apunta a una ubicación donde se deben escribir los datos de retorno. Cómo se utilizan argc y argl depende completamente de la función de control.

X509_LOOKUP_set_get_by_subject(), X509_LOOKUP_set_get_by_issuer_serial(), X509_LOOKUP_set_get_by_fingerprint(), X509_LOOKUP_set_get_by_alias() establecen las funciones que se utilizan para recuperar un objeto X509 o X509_CRL por el sujeto, emisor, huella digital y alias del objeto respectivamente. Estas funciones reciben el contexto X509_LOOKUP, el tipo del X509_OBJECT que se solicita, parámetros relacionados con la búsqueda y un X509_OBJECT que recibirá el objeto solicitado.

Las implementaciones deben agregar los objetos que encuentren al objeto X509_STORE usando X509_STORE_add_cert() o X509_STORE_add_crl(). Esto incrementa su contador de referencias. Sin embargo, la función X509_STORE_CTX_get_by_subject(3) también incrementa el contador de referencias, lo que lleva a que se mantenga una referencia de más. Por lo tanto, las aplicaciones deben llamar adicionalmente a X509_free() o X509_CRL_free() para decrementar el contador de referencias nuevamente.

Las implementaciones también deben usar X509_OBJECT_set1_X509() o X509_OBJECT_set1_X509_CRL() para establecer el resultado. Tenga en cuenta que esto también incrementa el contador de referencias del resultado.

Cualquier dato del método que se creó como resultado de la función new_item establecida por X509_LOOKUP_meth_set_new_item() se puede acceder con X509_LOOKUP_get_method_data(3). El objeto X509_STORE que posee el X509_LOOKUP puede accederse con X509_LOOKUP_get_store(3). Las búsquedas exitosas deben devolver 1, y las búsquedas infructuosas deben devolver 0.

X509_LOOKUP_get_get_by_subject(), X509_LOOKUP_get_get_by_issuer_serial(), X509_LOOKUP_get_get_by_fingerprint(), X509_LOOKUP_get_get_by_alias() recuperan la función establecida por el configurador correspondiente.

VALORES DE RETORNO

Las funciones X509_LOOKUP_meth_set devuelven 1 en caso de éxito o 0 en caso de error.

NAME

X509_LOOKUP_meth_new, X509_LOOKUP_meth_free, X509_LOOKUP_meth_set_getter, X509_LOOKUP_meth_get_getter — create and manage X509 lookup methods

SYNOPSIS

#include <openssl/x509.h>

X509_LOOKUP_METHOD *X509_LOOKUP_meth_new(const char *name);
void X509_LOOKUP_meth_free(X509_LOOKUP_METHOD *meth);
int X509_LOOKUP_meth_set_getter(X509_LOOKUP_METHOD *meth,
    X509_LOOKUP_GETTER *getter);
X509_LOOKUP_GETTER *X509_LOOKUP_meth_get_getter(const X509_LOOKUP_METHOD *meth);

DESCRIPTION

The X509_LOOKUP_meth_new function creates a new X509 lookup method object. The name parameter is an optional name for the method.

The X509_LOOKUP_meth_free function frees the memory associated with the lookup method object meth.

The X509_LOOKUP_meth_set_getter function sets the getter function for the lookup method meth to be getter.

The X509_LOOKUP_meth_get_getter function returns the getter function pointer from the lookup method object meth.

RETURN VALUES

X509_LOOKUP_meth_new returns a pointer to the newly created X509_LOOKUP_METHOD object, or NULL if an error occurred.

X509_LOOKUP_meth_set_getter returns 1 on success and 0 on failure.

X509_LOOKUP_meth_get_getter returns the corresponding function pointer.

X509_STORE_CTX_get_by_subject(3), X509_STORE_new(3), SSL_CTX_set_cert_store(3)
