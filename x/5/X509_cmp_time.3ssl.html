X509_cmp_time(3ssl) OpenSSL X509_cmp_time(3ssl)

NOMBRE

X509_cmp_time, X509_cmp_current_time, X509_cmp_timeframe, X509_time_adj, X509_time_adj_ex, X509_gmtime_adj - Funciones de tiempo X509

SINOPSIS

int X509_cmp_time(const ASN1_TIME *asn1_time, time_t *in_tm);
int X509_cmp_current_time(const ASN1_TIME *asn1_time);
int X509_cmp_timeframe(const X509_VERIFY_PARAM *vpm,
                       const ASN1_TIME *start, const ASN1_TIME *end);
ASN1_TIME *X509_time_adj(ASN1_TIME *asn1_time, long offset_sec, time_t *in_tm);
ASN1_TIME *X509_time_adj_ex(ASN1_TIME *asn1_time, int offset_day, long
                            offset_sec, time_t *in_tm);
ASN1_TIME *X509_gmtime_adj(ASN1_TIME *asn1_time, long offset_sec);

DESCRIPCIÓN

X509_cmp_time() compara el ASN1_TIME en asn1_time con el tiempo en <in_tm>.

X509_cmp_current_time() compara el ASN1_TIME en asn1_time con el tiempo actual, expresado como time_t.

X509_cmp_timeframe() compara el período de tiempo dado con el tiempo de referencia incluido en los parámetros de verificación vpm si no son NULL y contienen X509_V_FLAG_USE_CHECK_TIME; de lo contrario, se utiliza el tiempo actual como tiempo de referencia.

X509_time_adj_ex() establece la estructura ASN1_TIME asn1_time al tiempo offset_day y offset_sec después de in_tm.

X509_time_adj() establece la estructura ASN1_TIME asn1_time al tiempo offset_sec después de in_tm. Este método solo puede manejar compensaciones de segundos hasta la capacidad de long, por lo que se debe preferir la API más nueva X509_time_adj_ex().

En ambos métodos, si asn1_time es NULL, se asigna y se devuelve una nueva estructura ASN1_TIME.

En todos los métodos, si in_tm es NULL, se utiliza el tiempo actual, expresado como time_t.

asn1_time debe cumplir el formato ASN1_TIME exigido por RFC 5280, es decir, su formato debe ser YYMMDDHHMMSSZ o YYYYMMDDHHMMSSZ.

X509_gmtime_adj() establece la estructura ASN1_TIME asn1_time al tiempo offset_sec después del tiempo actual. Es equivalente a llamar a X509_time_adj() con el último parámetro como NULL.

ERRORES

A diferencia de muchas funciones de comparación estándar, X509_cmp_time() y X509_cmp_current_time() devuelven 0 en caso de error.

VALORES DE RETORNO

X509_cmp_time() y X509_cmp_current_time() devuelven -1 si asn1_time es anterior o igual a in_tm (respectivamente, tiempo actual), y 1 en caso contrario. Estos métodos devuelven 0 en caso de error.

X509_cmp_timeframe() devuelve 0 si vpm no es NULL y los parámetros de verificación no contienen X509_V_FLAG_USE_CHECK_TIME, pero sí contienen X509_V_FLAG_NO_CHECK_TIME. De lo contrario, devuelve 1 si el tiempo de fin no es NULL y el tiempo de referencia (que se ha determinado como se indicó anteriormente) está pasado el tiempo de fin, -1 si el tiempo de inicio no es NULL y el tiempo de referencia es anterior, y 0 en caso contrario para indicar que el tiempo de referencia está dentro del rango (lo que implica que el tiempo de fin no es anterior al tiempo de inicio si ambos están presentes).

X509_time_adj(), X509_time_adj_ex() y X509_gmtime_adj() devuelven un puntero a la estructura ASN1_TIME actualizada y NULL en caso de error.

HISTORIAL

X509_cmp_timeframe() se añadió en OpenSSL 3.0.
