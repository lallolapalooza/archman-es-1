X509_get_version(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_GET_VERSION(3ssl) OpenSSL X509_GET_VERSION(3ssl)

NOMBRE

X509_get_version, X509_set_version, X509_REQ_get_version, X509_REQ_set_version, X509_ACERT_get_version, X509_ACERT_set_version, X509_CRL_get_version, X509_CRL_set_version - obtener o establecer la versión del certificado, solicitud de certificado o CRL

SINOPSIS

#include <openssl/x509.h>
long X509_get_version(const X509 *x);
int X509_set_version(X509 *x, long version);
long X509_REQ_get_version(const X509_REQ *req);
int X509_REQ_set_version(X509_REQ *x, long version);
long X509_CRL_get_version(const X509_CRL *crl);
int X509_CRL_set_version(X509_CRL *x, long version);
#include <openssl/x509_acert.h>
int X509_ACERT_set_version(X509_ACERT *x, long version);
long X509_ACERT_get_version(const X509_ACERT *x);

DESCRIPCIÓN

X509_get_version() devuelve el valor numérico del campo de versión del certificado x. Estos corresponden a las constantes X509_VERSION_1, X509_VERSION_2 y X509_VERSION_3. Nota: los valores de estas constantes están definidos por estándares (X.509 et al) para ser uno menos que la versión del certificado. Así, X509_VERSION_3 tiene el valor 2 y X509_VERSION_1 tiene el valor 0.

X509_set_version() establece el valor numérico del campo de versión del certificado x a version.

De manera similar, X509_REQ_get_version(), X509_REQ_set_version(), X509_ACERT_get_version(), X509_ACERT_set_version(), X509_CRL_get_version() y X509_CRL_set_version() obtienen y establecen el número de versión de solicitudes de certificados y CRLs. Usan las constantes X509_REQ_VERSION_1, X509_ACERT_VERSION_2, X509_CRL_VERSION_1 y X509_CRL_VERSION_2.

NOTAS

El campo de versión de certificados, solicitudes de certificados y CRLs tiene un valor PREDETERMINADO de v1(0), lo que significa que el campo debe omitirse para la versión 1. Esto es manejado transparentemente por estas funciones.

VALORES DEVUELTOS

X509_get_version(), X509_REQ_get_version() y X509_CRL_get_version() devuelven el valor numérico del campo de versión.

X509_set_version(), X509_REQ_set_version() y X509_CRL_set_version() devuelven 1 en caso de éxito y 0 en caso de fallo.

HISTORIAL

X509_get_version(), X509_REQ_get_version() y X509_CRL_get_version() son funciones en OpenSSL 1.1.0, en versiones anteriores eran macros.

X509_ACERT_get_version(), X509_ACERT_set_version() se añadieron en OpenSSL 3.4.
