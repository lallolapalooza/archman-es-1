X509_ACERT_add1_attr(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_ACERT_ADD1_ATTR(3ssl) OpenSSL X509_ACERT_ADD1_ATTR(3ssl)

NOMBRE

X509_ACERT_add1_attr, X509_ACERT_add1_attr_by_NID, X509_ACERT_add1_attr_by_OBJ, X509_ACERT_add1_attr_by_txt, X509_ACERT_delete_attr - Funciones de atributos de X509_ACERT

SINOPSIS

#include <openssl/x509_acert.h>
int X509_ACERT_add1_attr(X509_ACERT *x, X509_ATTRIBUTE *attr);
int X509_ACERT_add1_attr_by_NID(X509_ACERT *x, int nid, int type,
                                const void *bytes, int len);
int X509_ACERT_add1_attr_by_OBJ(X509_ACERT *x, const ASN1_OBJECT *obj,
                                int type, const void *bytes, int len);
int X509_ACERT_add1_attr_by_txt(X509_ACERT *x, const char *attrname, int type,
                                const unsigned char *bytes, int len);
X509_ATTRIBUTE *X509_ACERT_delete_attr(X509_ACERT *x, int loc);

DESCRIPCIÓN

X509_ACERT_add1_attr() añade un X509_ATTRIBUTE construido attr a la estructura X509_ACERT existente x.

X509_ACERT_add1_attr_by_NID() y X509_ACERT_add1_attr_by_OBJ() añaden un atributo de tipo nid o obj con un valor de tipo ASN1 type construido usando len bytes de bytes.

X509_ACERT_add1_attr_by_txt() añade un atributo de tipo attrname con un valor de tipo ASN1 type construido usando len bytes de bytes.

X509_ACERT_delete_attr() eliminará el atributo loc de x y devolverá un puntero a él o NULL si hay menos de loc atributos contenidos en x.

VALORES DE RETORNO

X509_ACERT_add1_attr(), X509_ACERT_add1_attr_by_NID(), y X509_ACERT_add1_attr_by_OBJ() devuelven 1 en caso de éxito y 0 en caso de error.

X509_ACERT_delete_attr() devuelve un puntero X509_ATTRIBUTE en caso de éxito o NULL en caso de error.

VER TAMBIÉN

X509_ACERT_get_attr_count(3)

HISTORIA

X509_ACERT_add1_attr(), X509_ACERT_add1_attr_by_NID(), X509_ACERT_add1_attr_by_OBJ(), X509_ACERT_add1_attr_by_txt() y X509_ACERT_delete_attr() se añadieron en OpenSSL 3.4.
