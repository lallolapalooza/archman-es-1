X509_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_NEW(3ssl) OpenSSL X509_NEW(3ssl)

NOMBRE

X509_new, X509_new_ex, X509_free, X509_up_ref, X509_chain_up_ref, OSSL_STACK_OF_X509_free - Funciones de asignación y desasignación ASN1 de certificados X509

SINOPSIS

#include <openssl/x509.h>
X509 *X509_new(void);
X509 *X509_new_ex(OSSL_LIB_CTX *libctx, const char *propq);
void X509_free(X509 *a);
int X509_up_ref(X509 *a);
STACK_OF(X509) *X509_chain_up_ref(STACK_OF(X509) *x);
void OSSL_STACK_OF_X509_free(STACK_OF(X509) *certs);

DESCRIPCIÓN

Las rutinas de asignación ASN1 X509 asignan y liberan una estructura X509, que representa un certificado X509.

X509_new_ex() asigna e inicializa una estructura X509 con un contexto de biblioteca de libctx, una consulta de propiedades de propq y un recuento de referencias de 1. Muchas funciones X509 como X509_check_purpose() y X509_verify() utilizan este contexto de biblioteca para seleccionar qué proveedores suministran los algoritmos obtenidos (SHA1 se utiliza internamente). Este objeto X509 creado se puede utilizar al cargar datos binarios con d2i_X509().

X509_new() es similar a X509_new_ex() pero establece el contexto de la biblioteca y la consulta de propiedades a NULL. Esto da como resultado que se utilice el contexto de biblioteca predeterminado (NULL) para cualquier operación X509 que requiera la obtención de algoritmos.

X509_free() decrementa el recuento de referencias de la estructura X509 a y la libera si el recuento de referencias es cero. Si el argumento es NULL, no se hace nada.

X509_up_ref() incrementa el recuento de referencias de a.

X509_chain_up_ref() aumenta el recuento de referencias de todos los certificados en la cadena x y devuelve una copia de la pila, o una pila vacía si a es NULL.

OSSL_STACK_OF_X509_free() desasigna la lista dada de punteros a certificados después de llamar a X509_free() en todos sus elementos. Si el argumento es NULL, no se hace nada.

NOTAS

La función X509_up_ref() es útil si una estructura de certificado está siendo utilizada por varias operaciones diferentes, cada una de las cuales la liberará después de su uso: esto evita la necesidad de duplicar toda la estructura del certificado.

La función X509_chain_up_ref() no solo aumenta el recuento de referencias de cada certificado. También devuelve una copia de la pila, utilizando sk_X509_dup(), pero sirve un propósito similar: la cadena devuelta persiste después de que la original haya sido liberada.

VALORES DE RETORNO

Si la asignación falla, X509_new() devuelve NULL y establece un código de error que puede obtenerse con ERR_get_error(3). De lo contrario, devuelve un puntero a la estructura recién asignada.

X509_up_ref() devuelve 1 para éxito y 0 para fallo.

X509_chain_up_ref() devuelve una copia de la pila o NULL si se produjo un error.

OSSL_STACK_OF_X509_free() no tiene valor de retorno.
