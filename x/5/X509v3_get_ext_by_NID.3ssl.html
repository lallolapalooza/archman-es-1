DESCRIPCIÓN

X509v3_get_ext_count() recupera el número de extensiones en x.

X509v3_get_ext() recupera la extensión loc de x. El índice loc puede tomar cualquier valor desde 0 hasta X509_get_ext_count(x) - 1. La extensión devuelta es un puntero interno que la aplicación NO DEBE liberar.

X509v3_get_ext_by_NID() y X509v3_get_ext_by_OBJ() buscan una extensión con nid u obj de la pila de extensiones x. La búsqueda comienza desde la extensión después de lastpos o desde el principio si lastpos es -1. Si se encuentra la extensión, se devuelve su índice, de lo contrario, se devuelve -1.

X509v3_get_ext_by_critical() es similar a X509v3_get_ext_by_NID() excepto que busca una extensión de criticidad crit. Un valor cero para crit busca una extensión no crítica. Un valor distinto de cero busca una extensión crítica.

X509v3_delete_ext() elimina la extensión con índice loc de x. La extensión eliminada se devuelve y debe ser liberada por el llamador. Si loc es un índice no válido, se devuelve NULL.

X509v3_add_ext() inserta la extensión ex en la pila *x en la posición loc. Si loc es -1, la nueva extensión se añade al final. Se asigna una nueva pila si *x es NULL. La extensión pasada ex se duplica, por lo que debe liberarse después de su uso.

X509v3_add_extensions() añade la lista de extensiones exts a la pila *target. La pila *target se devuelve sin cambios si exts es NULL o una lista vacía. De lo contrario, se asigna una nueva pila si *target es NULL. Una extensión que se va a añadir y que tiene el mismo OID que una preexistente reemplaza a esta anterior.

X509_get_ext_count(), X509_get_ext(), X509_get_ext_by_NID(), X509_get_ext_by_OBJ(), X509_get_ext_by_critical(), X509_delete_ext() y X509_add_ext() operan sobre las extensiones del certificado x. Por lo demás, son idénticas a las funciones X509v3.

X509_CRL_get_ext_count(), X509_CRL_get_ext(), X509_CRL_get_ext_by_NID(), X509_CRL_get_ext_by_OBJ(), X509_CRL_get_ext_by_critical(), X509_CRL_delete_ext() y X509_CRL_add_ext() operan sobre las extensiones de la CRL x. Por lo demás, son idénticas a las funciones X509v3.

X509_REVOKED_get_ext_count(), X509_REVOKED_get_ext(), X509_REVOKED_get_ext_by_NID(), X509_REVOKED_get_ext_by_OBJ(), X509_REVOKED_get_ext_by_critical(), X509_REVOKED_delete_ext() y X509_REVOKED_add_ext() operan sobre las extensiones de la entrada de CRL x. Por lo demás, son idénticas a las funciones X509v3.

NOTAS

Estas funciones se utilizan para examinar pilas de extensiones directamente. Las aplicaciones que deseen analizar o codificar y añadir una extensión deben utilizar las funciones de codificación y decodificación de extensiones en su lugar, como X509_add1_ext_i2d() y X509_get_ext_d2i().

Para X509v3_get_ext_by_NID(), X509v3_get_ext_by_OBJ(), X509v3_get_ext_by_critical() y sus variantes, un valor de retorno de índice cero no es un error ya que los índices de la pila de extensiones x comienzan desde cero. Estas funciones de búsqueda comienzan desde la extensión después del parámetro lastpos, por lo que inicialmente debe establecerse en -1. Si se establece en cero, la extensión inicial no se comprobará.

X509v3_delete_ext() y sus variantes son un poco contraintuitivas porque estas funciones no liberan la extensión que eliminan. Devuelven un objeto X509_EXTENSION que debe ser liberado explícitamente usando X509_EXTENSION_free().

VALORES DE RETORNO

X509v3_get_ext_count() devuelve el recuento de extensiones o 0 en caso de error.

X509v3_get_ext(), X509v3_delete_ext() y X509_delete_ext() devuelven una estructura X509_EXTENSION o NULL si ocurre un error.

X509v3_get_ext_by_OBJ() y X509v3_get_ext_by_critical() devuelven el índice de la extensión o -1 si ocurre un error.

X509v3_get_ext_by_NID() devuelve el índice de la extensión o valores negativos si ocurre un error.

X509v3_add_ext() devuelve una PILA de extensiones o NULL en caso de error.

X509v3_add_extensions() devuelve una PILA de extensiones o NULL en caso de error o si *target es NULL y exts es NULL o una lista vacía.

X509_add_ext() devuelve 1 en caso de éxito y 0 en caso de error.

    #include <openssl/x509v3.h>

    long X509v3_get_ext_by_OBJ(X509 *x, const ASN1_OBJECT *obj, long vtag, char *value);
    X509_EXTENSION *X509v3_get_ext(X509 *x, int loc);
    int X509v3_add_ext(X509 *x, X509_EXTENSION *ex, int loc);
    int X509v3_add_standard_extensions(X509 *x);
    int X509v3_get_ext_count(X509 *x);
    char *X509v3_text_vclass(const char *str, char *tag);
    ASN1_OBJECT *X509v3_get_object(const char **pp);
    int X509v3_add_IMPLICIT(STACK_OF(X509_EXTENSION) *sk, int tag, int xclass, int min, int max, char *value);
    int X509v3_add_LEN(STACK_OF(X509_EXTENSION) *sk, int tag, int xclass, int min, int max, char *value);

DESCRIPTION

These functions provide a mechanism for manipulating X.509 Version 3 extensions.

X.509 certificates can contain a number of optional extensions. These extensions are defined by RFC 5280 and later RFCs. The OpenSSL library provides functions to manipulate these extensions.

X509v3_get_ext_by_NID() and X509v3_get_ext_by_OBJ() search the extensions within the X.509 certificate x for one matching the specified NID (Numerical ID) or OBJECT identifier respectively. The vtag and value parameters are used to filter the extensions. If vtag is -1, any tag is accepted. If value is not NULL, only extensions with an ASN1 tag matching vtag and a value matching value are returned. The return value is the index of the extension in the certificate's extension list, or -1 if no match is found. If multiple extensions match, the index of the first match is returned.

X509v3_get_ext() retrieves the extension at the specified location loc from the certificate x.

X509v3_add_ext() adds the extension ex to the certificate x at the specified location loc. If loc is -1, the extension is added to the end of the list.

X509v3_add_standard_extensions() adds a set of standard extensions to the certificate x. The specific extensions added depend on the context and configuration.

X509v3_get_ext_count() returns the total number of extensions present in the certificate x.

X509v3_text_vclass() is a utility function for parsing text strings representing extension values. It parses the input string str and attempts to extract a tag and class. The tag parameter is used to store the extracted tag.

X509v3_get_object() is used to parse an ASN1 OBJECT identifier from a character pointer pp.

X509v3_add_IMPLICIT() and X509v3_add_LEN() are lower-level functions for adding extensions with specific implicit or length-encoded tags and classes to a stack of extensions sk.

NOTES

The behavior of X509v3_add_standard_extensions() can be influenced by configuration options and the type of certificate being generated.

RETURN VALUES

These functions return various values depending on their success or failure. A return value of -1 often indicates an error or no match found.
