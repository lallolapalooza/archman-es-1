X509_get_extension_flags(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_GET_EXTENSION_FLAGS(3ssl) OpenSSL X509_GET_EXTENSION_FLAGS(3ssl)

NOMBRE

X509_get0_subject_key_id, X509_get0_authority_key_id, X509_get0_authority_issuer, X509_get0_authority_serial, X509_get_pathlen, X509_get_extension_flags, X509_get_key_usage, X509_get_extended_key_usage, X509_set_proxy_flag, X509_set_proxy_pathlen, X509_get_proxy_pathlen - recuperar datos de extensión de certificado

SINOPSIS

#include <openssl/x509v3.h>
long X509_get_pathlen(X509 *x);
uint32_t X509_get_extension_flags(X509 *x);
uint32_t X509_get_key_usage(X509 *x);
uint32_t X509_get_extended_key_usage(X509 *x);
const ASN1_OCTET_STRING *X509_get0_subject_key_id(X509 *x);
const ASN1_OCTET_STRING *X509_get0_authority_key_id(X509 *x);
const GENERAL_NAMES *X509_get0_authority_issuer(X509 *x);
const ASN1_INTEGER *X509_get0_authority_serial(X509 *x);
void X509_set_proxy_flag(X509 *x);
void X509_set_proxy_pathlen(int l);
long X509_get_proxy_pathlen(X509 *x);

DESCRIPCIÓN

Estas funciones recuperan información relacionada con extensiones de certificado comúnmente utilizadas.

X509_get_pathlen() recupera la extensión de longitud de ruta de un certificado. Esta extensión se utiliza para limitar la longitud de una cadena de certificados que pueden ser emitidos desde esa AC.

X509_get_extension_flags() recupera información general sobre un certificado, devolverá uno o más de los siguientes flags combinados con OR.

EXFLAG_V1
El certificado es un certificado obsoleto versión 1.
EXFLAG_BCONS
El certificado contiene una extensión de restricciones básicas.
EXFLAG_CA
El certificado contiene restricciones básicas y afirma el flag de AC.
EXFLAG_PROXY
El certificado es un certificado proxy válido.
EXFLAG_SI
El certificado es autoemitido (es decir, los nombres del sujeto y del emisor coinciden).
EXFLAG_SS
Los nombres del sujeto y del emisor coinciden y los valores de las extensiones implican que está auto-firmado.
EXFLAG_FRESHEST
La extensión CRL más reciente está presente en el certificado.
EXFLAG_CRITICAL
El certificado contiene una extensión crítica no manejada.
EXFLAG_INVALID
Algunos valores de extensión del certificado son inválidos o inconsistentes. El certificado debe ser rechazado. Este bit también puede activarse después de un error de falta de memoria al procesar el objeto X509, por lo que puede no estar relacionado con el objeto ASN1 procesado en sí.
EXFLAG_NO_FINGERPRINT
Fallo al calcular el valor hash SHA1 interno del certificado o CRL. Esto puede deberse a un fallo de malloc o a que no se encontró ninguna implementación de SHA1.
EXFLAG_INVALID_POLICY
La extensión de certificado NID_certificate_policies es inválida o inconsistente. El certificado debe ser rechazado. Este bit también puede activarse después de un error de falta de memoria al procesar el objeto X509, por lo que puede no estar relacionado con el objeto ASN1 procesado en sí.
EXFLAG_KUSAGE
El certificado contiene una extensión de uso de clave. El valor puede ser recuperado usando X509_get_key_usage().
EXFLAG_XKUSAGE
El certificado contiene una extensión de uso de clave extendido. El valor puede ser recuperado usando X509_get_extended_key_usage().

X509_get_key_usage() devuelve el valor de la extensión de uso de clave. Si el uso de clave está presente, devolverá cero o más de los flags: KU_DIGITAL_SIGNATURE, KU_NON_REPUDIATION, KU_KEY_ENCIPHERMENT, KU_DATA_ENCIPHERMENT, KU_KEY_AGREEMENT, KU_KEY_CERT_SIGN, KU_CRL_SIGN, KU_ENCIPHER_ONLY o KU_DECIPHER_ONLY correspondientes a los bits de uso de clave individuales. Si el uso de clave está ausente, se devolverá UINT32_MAX.

X509_get_extended_key_usage() devuelve el valor de la extensión de uso de clave extendido. Si el uso de clave extendido está presente, devolverá cero o más de los flags: XKU_SSL_SERVER, XKU_SSL_CLIENT, XKU_SMIME, XKU_CODE_SIGN XKU_OCSP_SIGN, XKU_TIMESTAMP, XKU_DVCS o XKU_ANYEKU. Estos corresponden a los OID id-kp-serverAuth, id-kp-clientAuth, id-kp-emailProtection, id-kp-codeSigning, id-kp-OCSPSigning, id-kp-timeStamping, id-kp-dvcs y anyExtendedKeyUsage respectivamente. Adicionalmente, XKU_SGC se establece si están presentes los OID SGC de Netscape o Microsoft.

X509_get0_subject_key_id() devuelve un puntero interno al identificador de clave del sujeto de x como un ASN1_OCTET_STRING o NULL si la extensión no está presente o no se puede analizar.

X509_get0_authority_key_id() devuelve un puntero interno al identificador de clave de la autoridad de x como un ASN1_OCTET_STRING o NULL si la extensión no está presente o no se puede analizar.

X509_get0_authority_issuer() devuelve un puntero interno al emisor del certificado de la autoridad de x como una pila de estructuras GENERAL_NAME o NULL si la extensión no está presente o no se puede analizar.

X509_get0_authority_serial() devuelve un puntero interno al número de serie del certificado de la autoridad de x como un ASN1_INTEGER o NULL si la extensión no está presente o no se puede analizar.

X509_set_proxy_flag() marca el certificado con el flag EXFLAG_PROXY. Esto es para los usuarios que necesitan marcar certificados proxy no compatibles con RFC3820 como tales, ya que OpenSSL solo detecta los compatibles con RFC3820.

X509_set_proxy_pathlen() establece la longitud de ruta del certificado proxy para el certificado dado x. Esto es para los usuarios que necesitan marcar certificados proxy no compatibles con RFC3820 como tales, ya que OpenSSL solo detecta los compatibles con RFC3820.

X509_get_proxy_pathlen() devuelve la longitud de ruta del certificado proxy para el certificado dado x si es un certificado proxy.

NOTAS

El valor de los flags corresponde a valores de extensión que se almacenan en caché en la estructura X509. Si los flags devueltos no proporcionan información suficiente, una aplicación debería examinar los valores de extensión directamente, por ejemplo, utilizando X509_get_ext_d2i().

Si la extensión de uso de clave o de uso de clave extendido está ausente, típicamente el uso no está restringido. Por esta razón, X509_get_key_usage() y X509_get_extended_key_usage() devuelven UINT32_MAX cuando la extensión correspondiente está ausente. Las aplicaciones pueden verificar adicionalmente el valor de retorno de X509_get_extension_flags() y tomar la acción apropiada si una extensión está ausente.

Si X509_get0_subject_key_id() devuelve NULL, la extensión puede estar ausente o mal formada. Las aplicaciones pueden determinar la razón precisa usando X509_get_ext_d2i().

VALOR DE RETORNO

X509_get_pathlen() devuelve el valor de la longitud de ruta, o -1 si la extensión no está presente.

X509_get_extension_flags(), X509_get_key_usage() y X509_get_extended_key_usage() devuelven conjuntos de flags correspondientes a los valores de extensión del certificado.

X509_get0_subject_key_id() devuelve el identificador de clave del sujeto como un puntero a una estructura ASN1_OCTET_STRING o NULL si la extensión está ausente o si ocurrió un error durante el análisis.

X509_get_proxy_pathlen() devuelve el valor de la longitud de ruta si el certificado dado es uno proxy y tiene una longitud de ruta establecida, y -1 en caso contrario.
