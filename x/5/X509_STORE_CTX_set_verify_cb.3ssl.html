DESCRIPCIÓN

X509_STORE_CTX_set_verify_cb() establece la devolución de llamada de verificación de ctx a verify_cb, sobrescribiendo cualquier devolución de llamada existente.

La devolución de llamada de verificación se puede utilizar para personalizar el funcionamiento de la verificación de certificados, por ejemplo, ignorando condiciones de error o registrando errores con fines de depuración.

Sin embargo, una devolución de llamada de verificación no es esencial y el funcionamiento predeterminado suele ser suficiente.

El parámetro ok para la devolución de llamada indica el valor que la devolución de llamada debe devolver para mantener el comportamiento predeterminado. Si es cero, indica una condición de error. Si es 1, no ocurrió ningún error. Si se establece la marca X509_V_FLAG_NOTIFY_POLICY, entonces ok se establece en 2 para indicar que la comprobación de políticas ha finalizado.

El parámetro ctx para la devolución de llamada es la estructura X509_STORE_CTX que está realizando la operación de verificación. Una devolución de llamada puede examinar esta estructura y recibir información adicional sobre el error, por ejemplo, llamando a X509_STORE_CTX_get_current_cert(). Se pueden pasar datos de aplicación adicionales a la devolución de llamada a través del mecanismo ex_data.

X509_STORE_CTX_print_verify_cb() es una función de devolución de llamada de verificación que, cuando falla la verificación de un certificado, añade una entrada a la cola de errores con el código X509_R_CERTIFICATE_VERIFICATION_FAILED y con detalles diagnósticos, incluyendo los campos más relevantes del certificado de destino que falló al verificar y, si procede, de los certificados no confiables y confiables disponibles.

X509_STORE_CTX_get_verify_cb() devuelve el valor de la devolución de llamada actual para el ctx específico.

X509_STORE_CTX_get_get_issuer(), X509_STORE_CTX_get_check_issued(), X509_STORE_CTX_get_check_revocation(), X509_STORE_CTX_get_get_crl(), X509_STORE_CTX_get_check_crl(), X509_STORE_CTX_get_cert_crl(), X509_STORE_CTX_get_check_policy(), X509_STORE_CTX_get_lookup_certs(), X509_STORE_CTX_get_lookup_crls() y X509_STORE_CTX_get_cleanup() devuelven los punteros de función almacenados en caché de la X509_STORE correspondiente; consulte X509_STORE_set_verify(3) para más información.

X509_STORE_CTX_set_get_crl() establece la función para obtener la CRL de un certificado dado *x*. Cuando se encuentra, la CRL debe asignarse a *crl*. Esta función debe devolver 0 en caso de fallo y 1 en caso de éxito. *Si no se proporciona ninguna función para obtener el emisor, se utilizará la función interna predeterminada en su lugar.*

X509_STORE_CTX_set_current_reasons() se utiliza junto con X509_STORE_CTX_get_crl_fn. La devolución de llamada X509_STORE_CTX_get_crl_fn debe utilizar este método para establecer el motivo por el cual el certificado no es válido.

ADVERTENCIAS

En general, una devolución de llamada de verificación NO debe devolver 1 incondicionalmente en todas las circunstancias, ya que esto permitirá que la verificación tenga éxito sin importar el error. Esto elimina efectivamente toda la seguridad de la aplicación, ya que se aceptará cualquier certificado (incluidos los generados no confiables).

NOTAS

La devolución de llamada de verificación se puede establecer y heredar de la estructura padre que realiza la operación. En algunos casos (como la verificación S/MIME), la estructura X509_STORE_CTX se crea y se destruye internamente, y la única forma de establecer una devolución de llamada de verificación personalizada es heredándola de la X509_STORE asociada.

VALORES DE RETORNO

X509_STORE_CTX_set_verify_cb() no devuelve ningún valor.

EJEMPLOS

Operación de devolución de llamada predeterminada:

int verify_callback(int ok, X509_STORE_CTX *ctx) {
    return ok;
}

Ejemplo sencillo, supongamos que un certificado en la cadena ha expirado y deseamos continuar después de este error:

int verify_callback(int ok, X509_STORE_CTX *ctx) {
    /* Tolerar la expiración del certificado */
    if (X509_STORE_CTX_get_error(ctx) == X509_V_ERR_CERT_HAS_EXPIRED)
        return 1;
    /* De lo contrario, no anular */
    return ok;
}

Ejemplo más complejo, no deseamos continuar después de que cualquier certificado haya expirado, solo en un caso específico:

int verify_callback(int ok, X509_STORE_CTX *ctx)
{
    int err = X509_STORE_CTX_get_error(ctx);
    X509 *err_cert = X509_STORE_CTX_get_current_cert(ctx);
    if (err == X509_V_ERR_CERT_HAS_EXPIRED) {
        if (check_is_acceptable_expired_cert(err_cert)
            return 1;
    }
    return ok;
}

Devolución de llamada de registro con todas las funciones. En este caso, se supone que bio_err es un BIO de registro global; una alternativa sería almacenar un BIO en ctx usando ex_data.

int verify_callback(int ok, X509_STORE_CTX *ctx)
{
    X509 *err_cert;
    int err, depth;
    err_cert = X509_STORE_CTX_get_current_cert(ctx);
    err = X509_STORE_CTX_get_error(ctx);
    depth = X509_STORE_CTX_get_error_depth(ctx);
    BIO_printf(bio_err, "depth=%d ", depth);
    if (err_cert) {
        X509_NAME_print_ex(bio_err, X509_get_subject_name(err_cert),
                           0, XN_FLAG_ONELINE);
        BIO_puts(bio_err, "\n");
    }
    else
        BIO_puts(bio_err, "<no cert>\n");
    if (!ok)
        BIO_printf(bio_err, "verify error:num=%d:%s\n", err,
                   X509_verify_cert_error_string(err));
    switch (err) {
    case X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT:
        BIO_puts(bio_err, "issuer= ");
        X509_NAME_print_ex(bio_err, X509_get_issuer_name(err_cert),
                           0, XN_FLAG_ONELINE);
        BIO_puts(bio_err, "\n");
        break;
    case X509_V_ERR_CERT_NOT_YET_VALID:
    case X509_V_ERR_ERROR_IN_CERT_NOT_BEFORE_FIELD:
        BIO_printf(bio_err, "notBefore=");
        ASN1_TIME_print(bio_err, X509_get_notBefore(err_cert));
        BIO_printf(bio_err, "\n");
        break;
    case X509_V_ERR_CERT_HAS_EXPIRED:
    case X509_V_ERR_ERROR_IN_CERT_NOT_AFTER_FIELD:
        BIO_printf(bio_err, "notAfter=");
        ASN1_TIME_print(bio_err, X509_get_notAfter(err_cert));
        BIO_printf(bio_err, "\n");
        break;
    case X509_V_ERR_NO_EXPLICIT_POLICY:
        policies_print(bio_err, ctx);
        break;
    }
    if (err == X509_V_OK && ok == 2)
        /* print out policies */
    BIO_printf(bio_err, "verify return:%d\n", ok);
    return(ok);
}
