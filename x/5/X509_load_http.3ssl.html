X509_load_http(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_LOAD_HTTP(3ssl) OpenSSL X509_LOAD_HTTP(3ssl)

NOMBRE

X509_load_http, X509_http_nbio, X509_CRL_load_http, X509_CRL_http_nbio - funciones de carga de certificados y CRL

SINOPSIS

#include <openssl/x509.h>
X509 *X509_load_http(const char *url, BIO *bio, BIO *rbio, int timeout);
X509_CRL *X509_CRL_load_http(const char *url, BIO *bio, BIO *rbio, int timeout);

Las siguientes macros han sido deprecadas desde OpenSSL 3.0 y pueden ser ocultadas completamente definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

#define X509_http_nbio(rctx, pcert)
#define X509_CRL_http_nbio(rctx, pcrl)

DESCRIPCIÓN

X509_load_http() y X509_CRL_load_http() cargan un certificado o un CRL, respectivamente, en formato ASN.1 usando HTTP desde la url dada.

El tamaño máximo de la respuesta HTTP es de 100 kB para certificados y 32 MB para CRLs, y está codificado de forma fija en las funciones.

Si se proporciona bio y rbio es NULL, entonces este BIO se utiliza en lugar de uno interno para conectarse, escribir la solicitud y leer la respuesta. Si se proporcionan tanto bio como rbio (que pueden ser BIOs de memoria, por ejemplo) entonces no se intenta una conexión explícita, bio se usa para escribir la solicitud y rbio para leer la respuesta.

Si el parámetro timeout es > 0, esto indica el número máximo de segundos a esperar hasta que la transferencia se complete. Un valor de 0 permite esperar indefinidamente, mientras que un valor < 0 conduce inmediatamente a una condición de tiempo de espera agotado.

X509_http_nbio() y X509_CRL_http_nbio() son macros para compatibilidad retroactiva que tienen el mismo efecto que las funciones anteriores pero con tiempo de espera infinito y sin la posibilidad de especificar BIOs personalizados.

VALORES DE RETORNO

En caso de éxito, la función devuelve el valor cargado, de lo contrario NULL. Las condiciones de error incluyen tiempo de espera de conexión/transferencia, errores de análisis, etc.

VER TAMBIÉN

OSSL_HTTP_get(3)

HISTORIA

X509_load_http() y X509_CRL_load_http() se agregaron en OpenSSL 3.0. X509_http_nbio() y X509_CRL_http_nbio() fueron deprecadas en OpenSSL 3.0.
