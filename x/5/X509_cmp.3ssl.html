X509_cmp(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_cmp(3ssl) OpenSSL X509_cmp(3ssl)

NOMBRE

X509_cmp, X509_NAME_cmp, X509_issuer_and_serial_cmp, X509_issuer_name_cmp, X509_subject_name_cmp, X509_CRL_cmp, X509_CRL_match - comparar certificados X509 y valores relacionados

SINOPSIS

#include <openssl/x509.h>
int X509_cmp(const X509 *a, const X509 *b);
int X509_NAME_cmp(const X509_NAME *a, const X509_NAME *b);
int X509_issuer_and_serial_cmp(const X509 *a, const X509 *b);
int X509_issuer_name_cmp(const X509 *a, const X509 *b);
int X509_subject_name_cmp(const X509 *a, const X509 *b);
int X509_CRL_cmp(const X509_CRL *a, const X509_CRL *b);
int X509_CRL_match(const X509_CRL *a, const X509_CRL *b);

DESCRIPCIÓN

Este conjunto de funciones se utiliza para comparar objetos X509, incluyendo certificados X509, objetos CRL X509 y varios valores en un certificado X509.

La función X509_cmp() compara dos objetos X509 indicados por los parámetros a y b. La comparación se basa en el resultado de memcmp de los valores hash de dos objetos X509 y los valores de codificación canónica (DER).

La función X509_NAME_cmp() compara dos objetos X509_NAME indicados por los parámetros a y b, cualquiera de los cuales puede ser NULL. La comparación se basa en el resultado de memcmp de los valores de codificación canónica (DER) de los dos objetos utilizando i2d_X509_NAME(3). Este procedimiento se adhiere a las reglas de coincidencia para Nombres Distinguidos (DN) dadas en RFC 4517 sección 4.2.15 y RFC 5280 sección 7.1. En particular, el orden de los Nombres Distinguidos Relativos (RDN) es relevante. Por otro lado, si un RDN es multivaluado, es decir, contiene un conjunto de Afirmaciones de Valor de Atributo (AVA), sus miembros efectivamente no están ordenados.

La función X509_issuer_and_serial_cmp() compara el número de serie y los valores del emisor en los objetos X509 dados a y b.

Las funciones X509_issuer_name_cmp(), X509_subject_name_cmp() y X509_CRL_cmp() son en efecto envoltorios de la función X509_NAME_cmp(). Estas funciones comparan los nombres del emisor y los nombres del sujeto de los objetos, o los emisores de los objetos X509_CRL, respectivamente.

La función X509_CRL_match() compara dos objetos X509_CRL. A diferencia de la función X509_CRL_cmp(), esta función compara el contenido completo de la CRL en lugar de solo el nombre del emisor.

VALORES DE RETORNO

Las funciones de comparación X509 devuelven -1, 0 o 1 si el objeto a se encuentra menor que, coincide con, o es mayor que el objeto b, respectivamente.

X509_NAME_cmp(), X509_issuer_and_serial_cmp(), X509_issuer_name_cmp(), X509_subject_name_cmp(), X509_CRL_cmp() y X509_CRL_match() pueden devolver -2 para indicar un error.

NOTAS

Estas funciones utilizan de hecho memcmp subyacente de la biblioteca C para realizar la tarea de comparación. Los datos a comparar varían desde datos de codificación DER, valor hash o ASN1_STRING. El signo de la comparación puede usarse para ordenar los objetos, pero no tiene un significado especial en algunos casos.

X509_NAME_cmp() y sus envoltorios utilizan el valor -2 para indicar errores en algunas circunstancias, lo que podría causar confusión a las aplicaciones.

VER TAMBIÉN

i2d_X509_NAME(3), i2d_X509(3)
