X509_STORE_new(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_STORE_NEW(3ssl) OpenSSL X509_STORE_NEW(3ssl)

NOMBRE

X509_STORE_new, X509_STORE_up_ref, X509_STORE_free, X509_STORE_lock, X509_STORE_unlock - Funciones de asignación, liberación y bloqueo de X509_STORE

SINOPSIS

#include <openssl/x509_vfy.h>
X509_STORE *X509_STORE_new(void);
void X509_STORE_free(X509_STORE *xs);
int X509_STORE_lock(X509_STORE *xs);
int X509_STORE_unlock(X509_STORE *xs);
int X509_STORE_up_ref(X509_STORE *xs);

DESCRIPCIÓN

La función X509_STORE_new() devuelve un nuevo X509_STORE.

X509_STORE_up_ref() incrementa el contador de referencias asociado al objeto X509_STORE.

X509_STORE_lock() bloquea la tienda contra modificaciones por otros hilos, X509_STORE_unlock() la desbloquea.

X509_STORE_free() libera un único objeto X509_STORE. Si el argumento es NULL, no se hace nada.

VALORES DEVUELTOS

X509_STORE_new() devuelve un X509_STORE recién creado o NULL si la llamada falla.

X509_STORE_up_ref(), X509_STORE_lock() y X509_STORE_unlock() devuelven 1 para el éxito y 0 para el fallo.

X509_STORE_free() no devuelve valores.

VER TAMBIÉN

X509_STORE_set_verify_cb_func(3) X509_STORE_get0_param(3)

HISTORIA

Las funciones X509_STORE_up_ref(), X509_STORE_lock() y X509_STORE_unlock() se añadieron en OpenSSL 1.1.0.
