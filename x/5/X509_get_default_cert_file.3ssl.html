X509_get_default_cert_file(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_GET_DEFAULT_CERT_FILE(3ssl) OpenSSL X509_GET_DEFAULT_CERT_FILE(3ssl)

NOMBRE

X509_get_default_cert_file, X509_get_default_cert_file_env, X509_get_default_cert_dir, X509_get_default_cert_dir_env - recuperar ubicaciones predeterminadas para certificados CA de confianza

SINOPSIS

#include <openssl/x509.h>
const char *X509_get_default_cert_file(void);
const char *X509_get_default_cert_dir(void);
const char *X509_get_default_cert_file_env(void);
const char *X509_get_default_cert_dir_env(void);

DESCRIPCIÓN

La función X509_get_default_cert_file() devuelve la ruta predeterminada a un archivo que contiene certificados CA de confianza. OpenSSL utilizará esta ruta como ruta predeterminada cuando se le solicite cargar certificados CA de confianza desde un archivo y no se especifique otra ruta. Si el archivo existe, los certificados CA se cargarán desde el archivo.

La función X509_get_default_cert_dir() devuelve una lista predeterminada separada por delimitadores de rutas a directorios que contienen certificados CA de confianza nombrados en formato hash. OpenSSL utilizará esto como la lista predeterminada de rutas cuando se le solicite cargar certificados CA de confianza desde un directorio y no se especifique otra ruta. Si un directorio dado en la lista existe, OpenSSL intenta buscar certificados CA en este directorio calculando un nombre de archivo basado en un hash del nombre del sujeto del certificado.

X509_get_default_cert_file_env() devuelve un nombre de variable de entorno que se recomienda para especificar un valor no predeterminado a utilizar en lugar del valor devuelto por X509_get_default_cert_file(). El valor devuelto por esta última función no se ve afectado por estas variables de entorno; debe comprobar usted mismo esta variable de entorno, utilizando esta función para recuperar el nombre de variable de entorno correcto. Si no se establece una variable de entorno, se debe utilizar el valor devuelto por X509_get_default_cert_file().

X509_get_default_cert_dir_env() devuelve el nombre de la variable de entorno que se recomienda para especificar un valor no predeterminado a utilizar en lugar del valor devuelto por X509_get_default_cert_dir(). El valor especificado por esta variable de entorno también puede ser una URI de almacén (pero véase BUGS a continuación).

BUGS

Por defecto (por ejemplo, cuando se utiliza X509_STORE_set_default_paths(3)), el nombre de la variable de entorno devuelto por X509_get_default_cert_dir_env() se interpreta tanto como una lista de rutas separadas por delimitadores como una URI de almacén. Esto es ambiguo. Por ejemplo, especificar un valor de "file:///etc/certs" provocaría la instanciación del almacén "file" proporcionado como parte del proveedor predeterminado, pero también provocaría que una instancia de X509_LOOKUP_hash_dir(3) buscara certificados en el directorio "file" (relativo al directorio de trabajo actual) y en el directorio "///etc/certs". Esto se puede evitar no utilizando el mecanismo de variables de entorno y utilizando otros métodos para construir instancias X509_LOOKUP.

VALORES DE RETORNO

Estas funciones devuelven punteros a cadenas constantes con duración de almacenamiento estática.
