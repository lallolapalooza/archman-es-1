X509_ALGOR_dup(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_ALGOR_DUP(3ssl) OpenSSL X509_ALGOR_DUP(3ssl)

NOMBRE

X509_ALGOR_dup, X509_ALGOR_set0, X509_ALGOR_get0, X509_ALGOR_set_md, X509_ALGOR_cmp, X509_ALGOR_copy - funciones de AlgorithmIdentifier

SINOPSIS

#include <openssl/x509.h>
X509_ALGOR *X509_ALGOR_dup(X509_ALGOR *alg);
int X509_ALGOR_set0(X509_ALGOR *alg, ASN1_OBJECT *aobj, int ptype, void *pval);
void X509_ALGOR_get0(const ASN1_OBJECT **paobj, int *pptype,
                     const void **ppval, const X509_ALGOR *alg);
void X509_ALGOR_set_md(X509_ALGOR *alg, const EVP_MD *md);
int X509_ALGOR_cmp(const X509_ALGOR *a, const X509_ALGOR *b);
int X509_ALGOR_copy(X509_ALGOR *dest, const X509_ALGOR *src);

DESCRIPCIÓN

X509_ALGOR_dup() devuelve una copia de alg.

X509_ALGOR_set0() establece el OID del algoritmo de alg a aobj y el tipo de parámetro asociado a ptype con valor pval. Si ptype es V_ASN1_UNDEF el parámetro se omite, de lo contrario ptype y pval tienen el mismo significado que los parámetros type y value para ASN1_TYPE_set(). Todos los parámetros proporcionados se utilizan internamente, por lo que no deben liberarse después de que esta llamada tenga éxito; de lo contrario, la propiedad permanece con el llamador y alg permanece sin cambios.

X509_ALGOR_get0() es la inversa de X509_ALGOR_set0(): devuelve el OID del algoritmo en *paobj y el parámetro asociado en *pptype y *ppval del AlgorithmIdentifier alg.

X509_ALGOR_set_md() establece el AlgorithmIdentifier alg a los valores apropiados para el resumen de mensajes md.

X509_ALGOR_cmp() compara a y b y devuelve 0 si tienen codificaciones idénticas y un valor distinto de cero en caso contrario.

X509_ALGOR_copy() copia los valores de origen en las estructuras de destino; creando una duplicación de cada uno (y liberando cualquier cosa a la que apunte desde dentro de *dest).

VALORES DE RETORNO

X509_ALGOR_dup() devuelve una estructura X509_ALGOR válida o NULL si ocurrió un error.

X509_ALGOR_set0() y X509_ALGOR_copy() devuelven 1 en caso de éxito o 0 en caso de error.

X509_ALGOR_get0() y X509_ALGOR_set_md() no devuelven valores.

X509_ALGOR_cmp() devuelve 0 si los dos parámetros tienen codificaciones idénticas y un valor distinto de cero en caso contrario.

HISTORIA

X509_ALGOR_copy() se añadió en la versión 1.1.1e.
