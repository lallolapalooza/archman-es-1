X509_NAME_get_index_by_NID(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_NAME_GET_INDEX_BY_NID(3ssl) OpenSSL X509_NAME_GET_INDEX_BY_NID(3ssl)

NOMBRE

X509_NAME_get_index_by_NID, X509_NAME_get_index_by_OBJ, X509_NAME_get_entry, X509_NAME_entry_count, X509_NAME_get_text_by_NID, X509_NAME_get_text_by_OBJ - Funciones de búsqueda y enumeración de X509_NAME

SINOPSIS

#include <openssl/x509.h>
int X509_NAME_get_index_by_NID(const X509_NAME *name, int nid, int lastpos);
int X509_NAME_get_index_by_OBJ(const X509_NAME *name,
                               const ASN1_OBJECT *obj, int lastpos);
int X509_NAME_entry_count(const X509_NAME *name);
X509_NAME_ENTRY *X509_NAME_get_entry(const X509_NAME *name, int loc);
int X509_NAME_get_text_by_NID(const X509_NAME *name, int nid,
                              char *buf, int len);
int X509_NAME_get_text_by_OBJ(const X509_NAME *name, const ASN1_OBJECT *obj,
                              char *buf, int len);

DESCRIPCIÓN

Estas funciones permiten examinar una estructura X509_NAME. La estructura X509_NAME es la misma que el tipo Name definido en RFC 5280 (y en otros lugares) y utilizado por ejemplo en los nombres de sujeto y emisor de certificados.

X509_NAME_get_index_by_NID() y X509_NAME_get_index_by_OBJ() recuperan el siguiente índice que coincide con nid u obj después de lastpos. lastpos debe establecerse inicialmente en -1. Si no hay más entradas, se devuelve -1. Si nid es inválido (no corresponde a un OID válido), se devuelve -2.

X509_NAME_entry_count() devuelve el número total de entradas en name.

X509_NAME_get_entry() recupera la X509_NAME_ENTRY de name correspondiente al índice loc. Los valores aceptables para loc van de 0 a (X509_NAME_entry_count(name) - 1). El valor devuelto es un puntero interno que no debe liberarse.

X509_NAME_get_text_by_NID(), X509_NAME_get_text_by_OBJ() recuperan el "texto" de la primera entrada en name que coincide con nid u obj. Si no existe dicha entrada, se devuelve -1. Se escribirán como máximo len bytes y el texto escrito en buf se terminará con null. Se devuelve la longitud de la cadena de salida escrita, excluyendo el null final. Si buf es <NULL>, se devuelve la cantidad de espacio necesario en buf (excluyendo el null final).

NOTAS

X509_NAME_get_text_by_NID() y X509_NAME_get_text_by_OBJ() deben considerarse obsoletas porque tienen varias limitaciones que las hacen de uso mínimo en la práctica. Solo pueden encontrar la primera entrada coincidente y copiarán el contenido del campo literalmente: esto puede ser muy confuso si el objetivo es un tipo de cadena de varios caracteres como BMPString o UTF8String.

Para una solución más general, se deben usar X509_NAME_get_index_by_NID() o X509_NAME_get_index_by_OBJ() seguidas de X509_NAME_get_entry() en cualquier índice coincidente y luego las diversas funciones de utilidad de X509_NAME_ENTRY en el resultado.

La lista de todos los códigos relevantes **NID_*** y **OBJ_* codes** se puede encontrar en los archivos de cabecera del código fuente *<openssl/obj_mac.h>* y/o *<openssl/objects.h>*.

Las aplicaciones que podrían pasar NIDs no válidos a X509_NAME_get_index_by_NID() deberían verificar el valor de retorno de -2. Alternativamente, la validez del NID se puede determinar primero comprobando que OBJ_nid2obj(nid) no es NULL.

VALORES DE RETORNO

X509_NAME_get_index_by_NID() y X509_NAME_get_index_by_OBJ() devuelven el índice de la siguiente entrada coincidente o -1 si no se encuentra. X509_NAME_get_index_by_NID() también puede devolver -2 si el NID proporcionado no es válido.

X509_NAME_entry_count() devuelve el número total de entradas, y 0 en caso de error.

X509_NAME_get_entry() devuelve un puntero X509_NAME a la entrada solicitada o **NULL** si el índice es inválido.

EJEMPLOS

Procesar todas las entradas:

int i;
X509_NAME_ENTRY *e;
for (i = 0; i < X509_NAME_entry_count(nm); i++) {
    e = X509_NAME_get_entry(nm, i);
    /* Haz algo con e */
}

Procesar todas las entradas commonName:

int lastpos = -1;
X509_NAME_ENTRY *e;
for (;;) {
    lastpos = X509_NAME_get_index_by_NID(nm, NID_commonName, lastpos);
    if (lastpos == -1)
        break;
    e = X509_NAME_get_entry(nm, lastpos);
    /* Haz algo con e */
}
