X509_REQ_get_extensions(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_REQ_GET_EXTENSIONS(3ssl) OpenSSL X509_REQ_GET_EXTENSIONS(3ssl)

NOMBRE

X509_REQ_get_extensions, X509_REQ_add_extensions, X509_REQ_add_extensions_nid - maneja atributos de extensión X.509 de una CSR

SINOPSIS

#include <openssl/x509.h>
STACK_OF(X509_EXTENSION) *X509_REQ_get_extensions(const X509_REQ *req);
int X509_REQ_add_extensions(X509_REQ *req, const STACK_OF(X509_EXTENSION) *exts);
int X509_REQ_add_extensions_nid(X509_REQ *req,
                                const STACK_OF(X509_EXTENSION) *exts, int nid);

DESCRIPCIÓN

X509_REQ_get_extensions() devuelve la primera lista de extensiones X.509 encontradas en los atributos de req. La lista devuelta está vacía si no hay tales extensiones en req. El llamador es responsable de liberar la lista obtenida.

X509_REQ_add_extensions_nid() agrega a req una lista de extensiones X.509 exts, usando nid para identificar el atributo de extensiones. req no se modifica si exts es NULL o una lista vacía. Esta función puede ser llamada más de una vez en el mismo req y nid. En tal caso, las extensiones previas se aumentan, donde una extensión a agregar que tiene el mismo OID que una preexistente reemplaza a esta anterior.

X509_REQ_add_extensions() es como X509_REQ_add_extensions_nid() excepto que se usa el NID_ext_req predeterminado.

VALORES DE RETORNO

X509_REQ_get_extensions() devuelve un puntero a STACK_OF(X509_EXTENSION) o NULL en caso de error.

X509_REQ_add_extensions() y X509_REQ_add_extensions_nid() devuelven 1 en caso de éxito, 0 en caso de error.
