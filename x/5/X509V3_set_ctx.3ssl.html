X509V3_set_ctx(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509V3_SET_CTX(3ssl) OpenSSL X509V3_SET_CTX(3ssl)

NOMBRE

X509V3_set_ctx, X509V3_set_issuer_pkey - Utilidades de generación de extensiones X.509 v3

SINOPSIS

#include <openssl/x509v3.h>
void X509V3_set_ctx(X509V3_CTX *ctx, X509 *issuer, X509 *subject,
                    X509_REQ *req, X509_CRL *crl, int flags);
int X509V3_set_issuer_pkey(X509V3_CTX *ctx, EVP_PKEY *pkey);

DESCRIPCIÓN

X509V3_set_ctx() rellena los campos básicos de ctx de tipo X509V3_CTX, proporcionando detalles que pueden ser necesarios para las funciones que producen extensiones X509 v3. Estas pueden hacer uso de los campos del certificado subject, la solicitud de certificación req, o la lista de revocación de certificados crl. Como mucho uno de estos tres parámetros puede ser no NULL. Al construir el identificador de clave del sujeto calculando un valor hash de su clave pública, la clave pública se toma de subject o req. De manera similar, al construir nombres alternativos del sujeto a partir de cualquier dirección de correo electrónico contenida en un DN del sujeto, el DN del sujeto se toma de subject o req. Si se proporciona subject o crl, issuer debe apuntar a su emisor, por ejemplo, como referencia para generar la extensión del identificador de clave de autoridad. issuer puede tener el mismo valor de puntero que subject (lo que generalmente es una indicación de que el certificado subject es autoemitido o incluso autofirmado). En este caso, la fuente de respaldo para generar la extensión del identificador de clave de autoridad se tomará de cualquier valor proporcionado usando X509V3_set_issuer_pkey(). flags puede ser 0 o contener X509V3_CTX_TEST, lo que significa que solo se verificará la sintaxis de las definiciones de extensiones sin producir realmente ninguna extensión, o X509V3_CTX_REPLACE, lo que significa que cada extensión X.509v3 añadida como se define en alguna sección de configuración reemplazará cualquier extensión existente con el mismo OID.

X509V3_set_issuer_pkey() establece explícitamente la clave privada del emisor del certificado sujeto que se proporcionó en ctx. Esto debe hacerse en caso de que los argumentos issuer y subject de X509V3_set_ctx() tengan el mismo valor de puntero para proporcionar datos de respaldo para la extensión del identificador de clave de autoridad.

VALORES DE RETORNO

X509V3_set_issuer_pkey() devuelve 1 en caso de éxito y 0 en caso de error.

VER TAMBIÉN

X509_add_ext(3)

HISTORIA

X509V3_set_issuer_pkey() se añadió en OpenSSL 3.0.

CTX_TEST fue obsoleto en OpenSSL 3.0; use X509V3_CTX_TEST en su lugar.
