X509_CRL_get0_by_serial(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_CRL_GET0_BY_SERIAL(3ssl) OpenSSL X509_CRL_GET0_BY_SERIAL(3ssl)

NOMBRE

X509_CRL_get0_by_serial, X509_CRL_get0_by_cert, X509_CRL_get_REVOKED, X509_REVOKED_get0_serialNumber, X509_REVOKED_get0_revocationDate, X509_REVOKED_set_serialNumber, X509_REVOKED_set_revocationDate, X509_CRL_add0_revoked, X509_CRL_sort - Funciones de utilidad de entradas revocadas de CRL

SINOPSIS

#include <openssl/x509.h>
int X509_CRL_get0_by_serial(X509_CRL *crl,
                            X509_REVOKED **ret, const ASN1_INTEGER *serial);
int X509_CRL_get0_by_cert(X509_CRL *crl, X509_REVOKED **ret, X509 *x);
STACK_OF(X509_REVOKED) *X509_CRL_get_REVOKED(X509_CRL *crl);
const ASN1_INTEGER *X509_REVOKED_get0_serialNumber(const X509_REVOKED *r);
const ASN1_TIME *X509_REVOKED_get0_revocationDate(const X509_REVOKED *r);
int X509_REVOKED_set_serialNumber(X509_REVOKED *r, ASN1_INTEGER *serial);
int X509_REVOKED_set_revocationDate(X509_REVOKED *r, ASN1_TIME *tm);
int X509_CRL_add0_revoked(X509_CRL *crl, X509_REVOKED *rev);
int X509_CRL_sort(X509_CRL *crl);

DESCRIPCIÓN

X509_CRL_get0_by_serial() intenta encontrar una entrada revocada en crl para el número de serie serial. Si tiene éxito, establece *ret al puntero interno de la entrada coincidente. Como resultado, *ret NO DEBE liberarse después de la llamada.

X509_CRL_get0_by_cert() es similar a X509_get0_by_serial(), excepto que busca una entrada revocada usando el número de serie del certificado x.

X509_CRL_get_REVOKED() devuelve un puntero interno a una STACK de todas las entradas revocadas para crl.

X509_REVOKED_get0_serialNumber() devuelve un puntero interno al número de serie de r.

X509_REVOKED_get0_revocationDate() devuelve un puntero interno a la fecha de revocación de r.

X509_REVOKED_set_serialNumber() establece el número de serie de r a serial. El puntero serial proporcionado no se utiliza internamente, por lo que debe liberarse después de su uso.

X509_REVOKED_set_revocationDate() establece la fecha de revocación de r a tm. El puntero tm proporcionado no se utiliza internamente, por lo que debe liberarse después de su uso.

X509_CRL_add0_revoked() añade la entrada revocada rev a la CRL crl. El puntero rev se utiliza internamente, por lo que NO DEBE liberarse después de la llamada: se libera cuando se libera la CRL padre.

X509_CRL_sort() ordena las entradas revocadas de crl en orden ascendente de número de serie.

NOTAS

Las aplicaciones pueden determinar el número de entradas revocadas devueltas por X509_CRL_get_REVOKED() usando sk_X509_REVOKED_num() y examinar cada una en orden usando sk_X509_REVOKED_value().

VALORES DE RETORNO

X509_CRL_get0_by_serial() y X509_CRL_get0_by_cert() devuelven 0 por fallo, 1 en caso de éxito, excepto si la entrada revocada tiene la razón "removeFromCRL" (8), en cuyo caso se devuelve 2.

X509_CRL_get_REVOKED() devuelve una STACK de entradas revocadas.

X509_REVOKED_get0_serialNumber() devuelve una estructura ASN1_INTEGER.

X509_REVOKED_get0_revocationDate() devuelve una estructura ASN1_TIME.

X509_REVOKED_set_serialNumber(), X509_REVOKED_set_revocationDate(), X509_CRL_add0_revoked() y X509_CRL_sort() devuelven 1 por éxito y 0 por fallo.
