X509_ACERT_get_attr(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_ACERT_GET_ATTR(3ssl) OpenSSL X509_ACERT_GET_ATTR(3ssl)

NOMBRE

X509_ACERT_get_attr, X509_ACERT_get_attr_by_NID, X509_ACERT_get_attr_by_OBJ, X509_ACERT_get_attr_count - Recuperar atributos de una estructura X509_ACERT

SINOPSIS

#include <openssl/x509_acert.h>
X509_ATTRIBUTE *X509_ACERT_get_attr(const X509_ACERT *x, int loc);
int X509_ACERT_get_attr_by_NID(const X509_ACERT *x, int nid, int lastpos);
int X509_ACERT_get_attr_by_OBJ(const X509_ACERT *x, const ASN1_OBJECT *obj,
                               int lastpos);
int X509_ACERT_get_attr_count(const X509_ACERT *x);

DESCRIPCIÓN

X509_ACERT_get0_attr() recupera el atributo X509_ATTRIBUTE en la posición loc de un X509_ACERT x. X509_ACERT_get_attr_count() devuelve el número total de atributos en el X509_ACERT.

X509_ACERT_get_attr_by_NID() y X509_ACERT_get_attr_by_OBJ() recuperan la siguiente ubicación de atributo que coincide con nid u obj después de lastpos. lastpos debe inicializarse en -1. Si no hay más entradas, se devuelve -1. Si nid es inválido (no corresponde a un OID válido), se devuelve -2.

VALORES DE RETORNO

X509_ACERT_get0_attr() devuelve un X509_ATTRIBUTE de un certificado de atributo, o NULL si no se encuentra el atributo especificado.

X509_ACERT_get_attr_by_NID() y X509_ACERT_get_attr_by_OBJ() devuelven la ubicación del siguiente atributo solicitado o -1 si no se encuentra. X509_ACERT_get_attr_by_NID() también puede devolver -2 si el NID proporcionado es inválido.

X509_ACERT_get_attr_count() devuelve el número de atributos en el certificado de atributo dado.

HISTORIA

X509_ACERT_get0_attr(), X509_ACERT_get_attr_by_NID(), X509_ACERT_get_attr_by_OBJ() y X509_ACERT_get_attr_count() se añadieron en OpenSSL 3.4.
