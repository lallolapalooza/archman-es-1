X509_STORE_CTX_get_error(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_STORE_CTX_GET_ERROR(3ssl) OpenSSL X509_STORE_CTX_GET_ERROR(3ssl)

NOMBRE

X509_STORE_CTX_get_error, X509_STORE_CTX_set_error, X509_STORE_CTX_get_error_depth, X509_STORE_CTX_set_error_depth, X509_STORE_CTX_get_current_cert, X509_STORE_CTX_set_current_cert, X509_STORE_CTX_get0_cert, X509_STORE_CTX_get1_chain, X509_verify_cert_error_string - obtener o establecer información de estado de verificación de certificado

SINOPSIS

#include <openssl/x509.h>
int   X509_STORE_CTX_get_error(const X509_STORE_CTX *ctx);
void  X509_STORE_CTX_set_error(X509_STORE_CTX *ctx, int s);
int   X509_STORE_CTX_get_error_depth(const X509_STORE_CTX *ctx);
void  X509_STORE_CTX_set_error_depth(X509_STORE_CTX *ctx, int depth);
X509 *X509_STORE_CTX_get_current_cert(const X509_STORE_CTX *ctx);
void  X509_STORE_CTX_set_current_cert(X509_STORE_CTX *ctx, X509 *x);
X509 *X509_STORE_CTX_get0_cert(const X509_STORE_CTX *ctx);
STACK_OF(X509) *X509_STORE_CTX_get1_chain(const X509_STORE_CTX *ctx);
const char *X509_verify_cert_error_string(long n);

DESCRIPCIÓN

Estas funciones suelen llamarse después de que la verificación del certificado o de la cadena mediante X509_verify_cert(3) o X509_STORE_CTX_verify(3) haya indicado un error o en una función de devolución de llamada de verificación para determinar la naturaleza de un error.

X509_STORE_CTX_get_error() devuelve el código de error de ctx. ctx NO DEBE ser NULL. Consulte la sección "CÓDIGOS DE ERROR" para obtener una descripción completa de todos los códigos de error. Puede devolver un código != X509_V_OK incluso si X509_verify_cert() no indicó un error, probablemente porque una función de devolución de llamada de verificación ha omitido el error.

X509_STORE_CTX_set_error() establece el código de error de ctx a s. Por ejemplo, podría usarse en una función de devolución de llamada de verificación para establecer un error basándose en comprobaciones adicionales. ctx NO DEBE ser NULL.

X509_STORE_CTX_get_error_depth() devuelve la profundidad del error. Es un entero no negativo que representa dónde ocurrió el error en la cadena de certificados. Si es cero, ocurrió en el certificado de entidad final, uno si es el certificado que firmó el certificado de entidad final y así sucesivamente. ctx NO DEBE ser NULL.

X509_STORE_CTX_set_error_depth() establece la profundidad del error. Esto se puede usar en combinación con X509_STORE_CTX_set_error() para establecer la profundidad a la que se detectó una condición de error.

X509_STORE_CTX_get_current_cert() devuelve el certificado actual en ctx. Si ocurrió un error, el certificado actual será el que esté más estrechamente relacionado con el error, o posiblemente NULL si ningún certificado es relevante.

X509_STORE_CTX_set_current_cert() establece el certificado x en ctx que causó el error. Este valor no pretende permanecer válido durante mucho tiempo y sigue siendo propiedad del llamador. Puede ser examinado por una función de devolución de llamada de verificación invocada para manejar cada error encontrado durante la verificación de la cadena y ya no se requiere después de que dicha función de devolución de llamada regrese. Si una función de devolución de llamada desea guardar el certificado para su uso después de que regrese, necesita incrementar su contador de referencias a través de X509_up_ref(3). Una vez que un certificado *guardado* de este tipo ya no se necesite, se puede liberar con X509_free(3).

X509_STORE_CTX_get0_cert() recupera un puntero interno al certificado que está siendo verificado por ctx. Puede ser NULL si se está verificando una clave pública en bruto.

X509_STORE_CTX_get1_chain() devuelve una cadena de validación completa si una verificación anterior es exitosa. De lo contrario, la cadena devuelta puede ser incompleta o inválida. La cadena devuelta persiste después de que se libera la estructura ctx. Cuando ya no sea necesaria, debe liberarse usando:

OSSL_STACK_OF_X509_free(chain);

X509_verify_cert_error_string() devuelve una cadena de error legible por humanos para el error de verificación n.

VALORES DE RETORNO

X509_STORE_CTX_get_error() devuelve X509_V_OK o un código de error.

X509_STORE_CTX_get_error_depth() devuelve una profundidad de error no negativa.

X509_STORE_CTX_get_current_cert() devuelve el certificado que causó el error o NULL si ningún certificado es relevante para el error.

X509_verify_cert_error_string() devuelve una cadena de error legible por humanos para el error de verificación n.

CÓDIGOS DE ERROR

A continuación se muestra una lista de códigos de error y mensajes. Algunos de los códigos de error están definidos pero actualmente nunca se devuelven: estos se describen como "no utilizados".

X509_V_OK: ok
La operación fue exitosa.
X509_V_ERR_UNSPECIFIED: error de verificación de certificado no especificado
Error no especificado; no debería ocurrir.
X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT: no se pudo obtener el certificado del emisor
No se pudo encontrar el certificado del emisor de un certificado buscado localmente. Esto normalmente significa que la lista de certificados de confianza no está completa. Para permitir que cualquier certificado (no solo uno autofirmado) en el almacén de confianza termine la cadena, se puede establecer la bandera X509_V_FLAG_PARTIAL_CHAIN.
X509_V_ERR_UNABLE_TO_GET_CRL: no se pudo obtener el CRL del certificado
No se pudo encontrar el CRL de un certificado.
X509_V_ERR_UNABLE_TO_DECRYPT_CERT_SIGNATURE: no se pudo descifrar la firma del certificado
No se pudo descifrar la firma del certificado. Esto significa que el valor de la firma real no se pudo determinar en lugar de no coincidir con el valor esperado; esto solo tiene sentido para claves RSA.
X509_V_ERR_UNABLE_TO_DECRYPT_CRL_SIGNATURE: no se pudo descifrar la firma del CRL
No se pudo descifrar la firma del CRL: esto significa que el valor de la firma real no se pudo determinar en lugar de no coincidir con el valor esperado. No utilizado.
X509_V_ERR_UNABLE_TO_DECODE_ISSUER_PUBLIC_KEY: no se pudo decodificar la clave pública del emisor
No se pudo leer la clave pública en el campo "SubjectPublicKeyInfo" del certificado.
X509_V_ERR_CERT_SIGNATURE_FAILURE: fallo en la firma del certificado
La firma del certificado es inválida.
X509_V_ERR_CRL_SIGNATURE_FAILURE: fallo en la firma del CRL
La firma del CRL es inválida.
X509_V_ERR_CERT_NOT_YET_VALID: el certificado aún no es válido
El certificado aún no es válido: la fecha "notBefore" es posterior a la hora actual.
X509_V_ERR_CERT_HAS_EXPIRED: el certificado ha expirado
El certificado ha expirado: es decir, la fecha "notAfter" es anterior a la hora actual.
X509_V_ERR_CRL_NOT_YET_VALID: el CRL aún no es válido
El CRL aún no es válido.
X509_V_ERR_CRL_HAS_EXPIRED: el CRL ha expirado
El CRL ha expirado.
X509_V_ERR_ERROR_IN_CERT_NOT_BEFORE_FIELD: error de formato en el campo notBefore del certificado
El campo "notBefore" del certificado contiene una hora inválida.
X509_V_ERR_ERROR_IN_CERT_NOT_AFTER_FIELD: error de formato en el campo notAfter del certificado
El campo "notAfter" del certificado contiene una fecha/hora inválida.
X509_V_ERR_ERROR_IN_CRL_LAST_UPDATE_FIELD: error de formato en el campo lastUpdate de la CRL
El campo lastUpdate de la CRL contiene una fecha/hora inválida.
X509_V_ERR_ERROR_IN_CRL_NEXT_UPDATE_FIELD: error de formato en el campo nextUpdate de la CRL
El campo "nextUpdate" de la CRL contiene una fecha/hora inválida.
X509_V_ERR_OUT_OF_MEM: memoria agotada
Se produjo un error al intentar asignar memoria.
X509_V_ERR_DEPTH_ZERO_SELF_SIGNED_CERT: certificado autofirmado
El certificado proporcionado está autofirmado y no se puede encontrar el mismo certificado en la lista de certificados de confianza.
X509_V_ERR_SELF_SIGNED_CERT_IN_CHAIN: certificado autofirmado en la cadena de certificados
La cadena de certificados se pudo construir utilizando los certificados no confiables, pero no se pudo encontrar ninguna autoridad raíz adecuada (que típicamente es un certificado raíz autofirmado) en el almacén de confianza.
X509_V_ERR_UNABLE_TO_GET_ISSUER_CERT_LOCALLY: no se puede obtener el certificado del emisor local
No se pudo encontrar el certificado del emisor: esto ocurre si el certificado del emisor de un certificado no confiable no se encuentra.
X509_V_ERR_UNABLE_TO_VERIFY_LEAF_SIGNATURE: no se puede verificar el primer certificado
No se pudieron verificar las firmas porque la cadena contiene solo un certificado y no está autofirmado, y la bandera X509_V_FLAG_PARTIAL_CHAIN no está establecida.
X509_V_ERR_CERT_CHAIN_TOO_LONG: cadena de certificados demasiado larga
La longitud de la cadena de certificados es mayor que la profundidad máxima proporcionada.
X509_V_ERR_CERT_REVOKED: certificado revocado
El certificado ha sido revocado.
X509_V_ERR_NO_ISSUER_PUBLIC_KEY: el certificado del emisor no tiene clave pública
El certificado del emisor no tiene una clave pública.
X509_V_ERR_PATH_LENGTH_EXCEEDED: se excedió la restricción de longitud de ruta
Se excedió el parámetro de longitud de ruta de las restricciones básicas (basicConstraints).
X509_V_ERR_INVALID_PURPOSE: propósito de certificado inadecuado
El certificado de destino no se puede utilizar para el propósito especificado.
X509_V_ERR_CERT_UNTRUSTED: certificado no confiable
La CA raíz no está marcada como confiable para el propósito especificado.
X509_V_ERR_CERT_REJECTED: certificado rechazado
La CA raíz está marcada para rechazar el propósito especificado.
X509_V_ERR_SUBJECT_ISSUER_MISMATCH: incompatibilidad entre sujeto y emisor
El certificado del emisor candidato actual fue rechazado porque su nombre de sujeto no coincidía con el nombre del emisor del certificado actual.
X509_V_ERR_AKID_SKID_MISMATCH: incompatibilidad entre el identificador de clave de autoridad y el identificador de clave de sujeto
El certificado del emisor candidato actual fue rechazado porque su identificador de clave de sujeto estaba presente y no coincidía con el identificador de clave de autoridad del certificado actual.
X509_V_ERR_AKID_ISSUER_SERIAL_MISMATCH: incompatibilidad entre el número de serie del emisor y el identificador de clave de autoridad
El certificado del emisor candidato actual fue rechazado porque su nombre y número de serie del emisor estaban presentes y no coincidían con el identificador de clave de autoridad del certificado actual.
X509_V_ERR_KEYUSAGE_NO_CERTSIGN: el uso de claves no incluye la firma de certificados
El certificado del emisor candidato actual fue rechazado porque su extensión "keyUsage" no permite la firma de certificados.
X509_V_ERR_UNABLE_TO_GET_CRL_ISSUER: no se puede obtener el certificado del emisor de la CRL
No se pudo obtener el certificado del emisor de la CRL.
X509_V_ERR_UNHANDLED_CRITICAL_EXTENSION: extensión crítica no manejada
Extensión crítica no manejada.
X509_V_ERR_KEYUSAGE_NO_CRL_SIGN: el uso de claves no incluye la firma de CRL
El uso de claves no incluye la firma de CRL.
X509_V_ERR_UNHANDLED_CRITICAL_CRL_EXTENSION: extensión CRL crítica no manejada
Extensión CRL crítica no manejada.
X509_V_ERR_INVALID_NON_CA: certificado no CA inválido (tiene marcas de CA)
El certificado no CA inválido tiene marcas de CA.
X509_V_ERR_PROXY_PATH_LENGTH_EXCEEDED: se excedió la restricción de longitud de ruta de proxy
Se excedió la restricción de longitud de ruta de proxy.
X509_V_ERR_KEYUSAGE_NO_DIGITAL_SIGNATURE: el uso de claves no incluye la firma digital
El uso de claves no incluye la firma digital y, por lo tanto, no puede firmar certificados.
X509_V_ERR_PROXY_CERTIFICATES_NOT_ALLOWED: no se permiten certificados proxy, establezca la bandera apropiada
No se permiten certificados proxy a menos que esté establecida la bandera X509_V_FLAG_ALLOW_PROXY_CERTS.
X509_V_ERR_INVALID_EXTENSION: extensión de certificado inválida o inconsistente
Una extensión de certificado tenía un valor inválido (por ejemplo, una codificación incorrecta) o algún valor inconsistente con otras extensiones.
X509_V_ERR_INVALID_POLICY_EXTENSION: extensión de política de certificado inválida o inconsistente
Una extensión de políticas de certificado tenía un valor inválido (por ejemplo, una codificación incorrecta) o algún valor inconsistente con otras extensiones. Este error solo ocurre si el procesamiento de políticas está habilitado.
X509_V_ERR_NO_EXPLICIT_POLICY: sin política explícita
Las banderas de verificación se establecieron para requerir una política explícita, pero ninguna estaba presente.
X509_V_ERR_DIFFERENT_CRL_SCOPE: alcance de CRL diferente
Las únicas CRLs que se pudieron encontrar no coincidían con el alcance del certificado.
X509_V_ERR_UNSUPPORTED_EXTENSION_FEATURE: característica de extensión no compatible
Alguna característica de una extensión de certificado no es compatible. No utilizada.
X509_V_ERR_UNNESTED_RESOURCE: recurso RFC 3779 no es subconjunto de los recursos del padre
Ver RFC 3779 para más detalles.
X509_V_ERR_PERMITTED_VIOLATION: violación de subárbol permitido
Se produjo una violación de las restricciones de nombres en los subárboles permitidos.
X509_V_ERR_EXCLUDED_VIOLATION: violación de subárbol excluido
Se produjo una violación de las restricciones de nombres en los subárboles excluidos.
X509_V_ERR_SUBTREE_MINMAX: mínimo y máximo de restricciones de nombres no compatibles
Una extensión de restricciones de nombres de certificado incluía un campo mínimo o máximo: esto no es compatible.
X509_V_ERR_APPLICATION_VERIFICATION: fallo de verificación de la aplicación
Un error específico de la aplicación. Esto nunca se devolverá a menos que sea establecido explícitamente por una función de devolución de llamada de la aplicación.
X509_V_ERR_UNSUPPORTED_CONSTRAINT_TYPE: tipo de restricción de nombres no compatible
Se encontró un tipo de restricción de nombres no compatible. OpenSSL actualmente solo admite tipos de nombre de directorio, nombre DNS, correo electrónico y URI.
X509_V_ERR_UNSUPPORTED_CONSTRAINT_SYNTAX: sintaxis de restricción de nombres no compatible o inválida
El formato de la restricción de nombres no se reconoce: por ejemplo, un formato de dirección de correo electrónico de una forma no mencionada en RFC3280. Esto podría ser causado por una extensión corrupta o alguna característica nueva no compatible actualmente.
