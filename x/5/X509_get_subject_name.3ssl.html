X509_get_subject_name(3ssl)

Paquete: openssl

Licencias: Apache-2.0

X509_GET_SUBJECT_NAME(3ssl) OpenSSL X509_GET_SUBJECT_NAME(3ssl)

NOMBRE

X509_NAME_hash_ex, X509_NAME_hash, X509_get_subject_name, X509_set_subject_name, X509_subject_name_hash, X509_get_issuer_name, X509_set_issuer_name, X509_issuer_name_hash, X509_REQ_get_subject_name, X509_REQ_set_subject_name, X509_ACERT_get0_issuerName, X509_ACERT_set1_issuerName, X509_CRL_get_issuer, X509_CRL_set_issuer_name - obtener hashes X509_NAME o obtener y establecer nombres de emisor o asunto

SINOPSIS

#include <openssl/x509.h>
unsigned long X509_NAME_hash_ex(const X509_NAME *x, OSSL_LIB_CTX *libctx,
                                const char *propq, int *ok);
X509_NAME *X509_get_subject_name(const X509 *x);
int X509_set_subject_name(X509 *x, const X509_NAME *name);
unsigned long X509_subject_name_hash(X509 *x);
X509_NAME *X509_get_issuer_name(const X509 *x);
int X509_set_issuer_name(X509 *x, const X509_NAME *name);
unsigned long X509_issuer_name_hash(X509 *x);
X509_NAME *X509_REQ_get_subject_name(const X509_REQ *req);
int X509_REQ_set_subject_name(X509_REQ *req, const X509_NAME *name);
X509_NAME *X509_CRL_get_issuer(const X509_CRL *crl);
int X509_CRL_set_issuer_name(X509_CRL *x, const X509_NAME *name);
#include <openssl/x509_acert.h>
X509_NAME *X509_ACERT_get0_issuerName(const X509_ACERT *x);
int X509_ACERT_set1_issuerName(X509_ACERT *x, const X509_NAME *name);

El siguiente macro ha sido obsoleto desde OpenSSL 3.0, y puede ser ocultado por completo definiendo OPENSSL_API_COMPAT con un valor de versión adecuado, ver openssl_user_macros(7):

#define X509_NAME_hash(x) X509_NAME_hash_ex(x, NULL, NULL, NULL)

DESCRIPCIÓN

X509_NAME_hash_ex() devuelve un valor hash del nombre x o 0 en caso de fallo, utilizando cualquier contexto de biblioteca libctx y consulta de propiedad propq proporcionada. El argumento de resultado ok puede ser NULL o, de lo contrario, se utiliza para devolver 1 en caso de éxito y 0 en caso de fallo. El fallo puede ocurrir por error de asignación de memoria o si no hay una implementación SHA1 disponible.

X509_NAME_hash() devuelve un valor hash del nombre x o 0 en caso de fallo, utilizando el contexto de biblioteca predeterminado y la consulta de propiedad predeterminada.

X509_get_subject_name() devuelve el nombre del asunto del certificado x. El valor devuelto es un puntero interno que NO DEBE liberarse. x NO DEBE ser NULL.

X509_set_subject_name() establece el nombre del emisor del certificado x a name. El parámetro name se copia internamente y debe liberarse cuando ya no sea necesario.

X509_subject_name_hash() devuelve un valor hash del nombre del asunto del certificado x.

X509_get_issuer_name(), X509_set_issuer_name() y X509_issuer_name_hash() son idénticas a X509_get_subject_name(), X509_set_subject_name() y X509_subject_name_hash() excepto que se relacionan con el nombre del emisor de x.

De manera similar, X509_REQ_get_subject_name(), X509_REQ_set_subject_name(), X509_ACERT_get0_issuerName(), X509_ACERT_set1_issuerName(), X509_CRL_get_issuer() y X509_CRL_set_issuer_name() obtienen o establecen los nombres de asunto o emisor de las solicitudes de certificado o CRLs respectivamente.

Dado que los certificados de atributos no tienen un nombre de asunto, solo se puede establecer el nombre del emisor. Para obtener detalles sobre cómo establecer las identidades del titular de X509_ACERT, consulte X509_ACERT_set0_holder_entityName(3).

VALORES DE RETORNO

X509_get_subject_name(), X509_get_issuer_name(), X509_REQ_get_subject_name(), X509_ACERT_get0_issuerName() y X509_CRL_get_issuer() devuelven un puntero X509_NAME.

X509_NAME_hash_ex(), X509_NAME_hash(), X509_subject_name_hash() y X509_issuer_name_hash() devuelven los primeros cuatro bytes del valor hash SHA1, convertidos a unsigned long en orden little-endian, o 0 en caso de fallo.

X509_set_subject_name(), X509_set_issuer_name(), X509_REQ_set_subject_name(), X509_ACERT_get0_issuerName() y X509_CRL_set_issuer_name() devuelven 1 en caso de éxito y 0 en caso de fallo.

ERRORES

En caso de que X509_NAME_hash(), X509_subject_name_hash() o X509_issuer_name_hash() devuelvan 0, no está claro si este es el valor hash real o se debe a un fallo. Es mejor usar X509_NAME_hash_ex() en su lugar.

HISTORIA

X509_REQ_get_subject_name() es una función en OpenSSL 1.1.0 y un macro en versiones anteriores.

X509_CRL_get_issuer() es una función en OpenSSL 1.1.0. Fue agregada previamente en OpenSSL 1.0.0 como un macro.

X509_NAME_hash() se convirtió en un macro y se declaró obsoleto en OpenSSL 3.0.

X509_ACERT_get0_issuerName(), X509_ACERT_set1_issuerName() se agregaron en OpenSSL 3.4.
