XtSetSensitive(3) FUNCIONES XT XtSetSensitive(3)

NOMBRE

XtSetSensitive, XtIsSensitive - establece y comprueba el estado de sensibilidad de un widget

SINTAXIS

#include <X11/Intrinsic.h>

void XtSetSensitive(Widget w, Boolean sensitive);

Boolean XtIsSensitive(Widget w);

ARGUMENTOS

sensible
Especifica un valor booleano que indica si el widget debe recibir eventos de teclado y puntero.
w
Especifica el widget.

DESCRIPCIÓN

La función XtSetSensitive primero llama a XtSetValues en el widget actual con una lista de argumentos que especifica que el campo sensitive debe cambiar al nuevo valor. Luego, propaga recursivamente el nuevo valor hacia abajo en el árbol de hijos gestionados llamando a XtSetValues en cada hijo para establecer ancestor_sensitive al nuevo valor si los nuevos valores para sensitive y ancestor_sensitive del hijo no son los mismos.

XtSetSensitive llama a XtSetValues para cambiar sensitive y ancestor_sensitive. Por lo tanto, cuando uno de estos cambia, el procedimiento set_values del widget debe realizar las acciones de visualización necesarias (por ejemplo, poner en gris o moteado el widget).

XtSetSensitive mantiene el invariante de que si el padre tiene sensitive o ancestor_sensitive en False, entonces todos los hijos tienen ancestor_sensitive en False.

La función XtIsSensitive devuelve True o False para indicar si se están enviando eventos de entrada del usuario. Si tanto core.sensitive como core.ancestor_sensitive son True, XtIsSensitive devuelve True; de lo contrario, devuelve False.
