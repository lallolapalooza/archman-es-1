XtSetValues(3) FUNCIONES XT XtSetValues(3)

NOMBRE

XtSetValues, XtVaSetValues, XtSetSubvalues, XtVaSetSubvalues, XtGetValues, XtVaGetValues, XtGetSubvalues, XtVaGetSubvalues - obtener y establecer recursos de widgets

SINTAXIS

#include <X11/Intrinsic.h>

void XtSetValues(Widget w, ArgList args, Cardinal num_args);

void XtVaSetValues(Widget w, ...);

void XtSetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaSetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ...);

void XtGetValues(Widget w, ArgList args, Cardinal num_args);

void XtVaGetValues(Widget w, ...);

void XtGetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaGetSubvalues(XtPointer base, XtResourceList resources, Cardinal num_resources, ...);

ARGUMENTOS

args
Especifica la lista de argumentos de pares nombre/dirección que contienen el nombre del recurso y ya sea la dirección en la que se almacenará el valor del recurso o sus nuevos valores.
base
Especifica la dirección base de la estructura de datos de subparte donde se deben recuperar o escribir los recursos.
num_args
Especifica el número de argumentos en la lista de argumentos.
resources
Especifica la lista o valores de recursos no widget.
num_resources
Especifica el número de recursos en la lista de recursos.
w
Especifica el widget.
...
Especifica la lista variable de argumentos de pares nombre/dirección que contienen el nombre del recurso y ya sea la dirección en la que se almacenará el valor del recurso o sus nuevos valores.

DESCRIPCIÓN

La función XtSetValues comienza con los recursos especificados para los campos del widget Core y avanza por la cadena de subclases hasta el widget. En cada etapa, escribe el nuevo valor (si se especifica en uno de los argumentos) o el valor existente (si no se especifica ningún valor nuevo) en un nuevo registro de datos de widget. XtSetValues luego llama a los procedimientos set_values para el widget en orden de superclase a subclase. Si el widget tiene algún campo set_values_hook no NULL, estos se llaman inmediatamente después del procedimiento set_values correspondiente. Este procedimiento permite a las subclases establecer datos no widget para XtSetValues.

Si el padre del widget es una subclase de constraintWidgetClass, XtSetValues también actualiza las restricciones del widget. Comienza con los recursos de restricción especificados para constraintWidgetClass y avanza por la cadena de subclases hasta la clase padre. En cada etapa, escribe el nuevo valor o el valor existente en un nuevo registro de restricción. Luego llama a los procedimientos set_values de restricción desde constraintWidgetClass hasta la clase padre. Los procedimientos set_values de restricción se llaman con argumentos de widget, como para todos los procedimientos set_values, no solo los argumentos del registro de restricción, para que puedan hacer ajustes a los valores deseados basándose en información completa sobre el widget.

XtSetValues determina si se necesita una solicitud de geometría comparando el widget actual con el nuevo widget. Si se requieren cambios de geometría, realiza la solicitud y el administrador de geometría devuelve XtGeometryYes, XtGeometryAlmost o XtGeometryNo. Si es XtGeometryYes, XtSetValues llama al procedimiento resize del widget. Si es XtGeometryNo, XtSetValues restablece los campos de geometría a sus valores originales. Si es XtGeometryAlmost, XtSetValues llama al procedimiento set_values_almost, que determina qué se debe hacer y escribe nuevos valores para los campos de geometría en el nuevo widget. XtSetValues luego repite este proceso, decidiendo una vez más si se debe llamar al administrador de geometría.

Finalmente, si alguno de los procedimientos set_values devolvió True, XtSetValues hace que se invoque el procedimiento expose del widget llamando a la función Xlib XClearArea en la ventana del widget.

La función XtSetSubvalues almacena recursos en la estructura identificada por base.

La función XtGetValues comienza con los recursos especificados para los campos del widget Core y avanza por la cadena de subclases hasta el widget. El campo de valor de una lista de argumentos pasada debe contener la dirección en la que se almacenará el valor del recurso correspondiente. Es responsabilidad del llamante asignar y liberar este almacenamiento de acuerdo con el tamaño del tipo de representación del recurso utilizado dentro del widget.

Si el padre del widget es una subclase de constraintWidgetClass, XtGetValues luego obtiene los valores de cualquier recurso de restricción solicitado. Comienza con los recursos de restricción especificados para constraintWidgetClass y avanza por la cadena de subclases hasta los recursos de restricción del padre. Si la lista de argumentos contiene un nombre de recurso que no se encuentra en ninguna de las listas de recursos buscadas, el valor en la dirección correspondiente no se modifica. Finalmente, si los procedimientos get_values_hook no son NULL, se llaman en orden de superclase a subclase después de que todos los valores de recursos hayan sido recuperados por XtGetValues. Esto permite a una subclase proporcionar datos de recursos no widget a XtGetValues.

La función XtGetSubvalues obtiene valores de recursos de la estructura identificada por base.
