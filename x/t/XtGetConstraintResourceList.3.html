XtGetConstraintResourceList(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetResourceList(3) FUNCIONES XT XtGetResourceList(3)

NOMBRE

XtGetResourceList, XtGetConstraintResourceList - obtener lista de recursos

SINTAXIS

#include <X11/Intrinsic.h>

void XtGetResourceList(WidgetClass class, XtResourceList *resources_return, Cardinal *num_resources_return);

void XtGetConstraintResourceList(WidgetClass class, XtResourceList *resources_return, Cardinal *num_resources_return);

ARGUMENTOS

num_resources_return
Especifica un puntero a dónde almacenar el número de entradas en la lista de recursos.
resources_return
Especifica un puntero a dónde almacenar la lista de recursos devuelta. El llamador debe liberar este almacenamiento usando XtFree cuando termine con él.
widget_class
Especifica la clase de widget para la que desea la lista.

DESCRIPCIÓN

Si XtGetResourceList se llama antes de que la clase del widget se inicialice (es decir, antes de que se haya creado el primer widget de esa clase), XtGetResourceList devuelve la lista de recursos tal como se especifica en el registro de la clase del widget. Si se llama después de que la clase del widget se haya inicializado, XtGetResourceList devuelve una lista de recursos combinada que contiene los recursos de todas las superclases. La lista devuelta por XtGetResourceList debe liberarse usando XtFree cuando ya no sea necesaria.

Si XtGetConstraintResourceList se llama antes de que la clase del widget se inicialice (es decir, antes de que se haya creado el primer widget de esa clase), XtGetConstraintResourceList devuelve la lista de recursos tal como se especifica en el registro de la parte de Constraint de la clase del widget. Si se llama después de que la clase del widget se haya inicializado, XtGetConstraintResourceList devuelve una lista de recursos combinada que contiene los recursos de Constraint de todas las superclases. Si la clase especificada no es una subclase de constraintWidgetClass, *resources_return se establece en NULL y *num_resources_return se establece en cero. La lista devuelta por XtGetConstraintResourceList debe liberarse usando XtFree cuando ya no sea necesaria.
