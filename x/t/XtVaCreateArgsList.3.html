XtVaCreateArgsList(3) FUNCIONES XT XtVaCreateArgsList(3)

NOMBRE

XtVaCreateArgsList - asigna dinámicamente una lista de argumentos variables

SINTAXIS

#include <X11/Intrinsic.h>

XtVarArgsList XtVaCreateArgsList(XtPointer unused, ...);

ARGUMENTOS

unused
Debe especificarse como NULL.
...
Especifica una lista de parámetros variables de pares nombre-valor de recursos.

DESCRIPCIÓN

La función XtVaCreateArgsList asigna memoria y copia sus argumentos en un único puntero de lista, que puede ser utilizado con XtVaNestedList. El final de ambas listas se identifica por una entrada de nombre que contiene NULL. Cualquier entrada de tipo XtVaTypedArg se copia tal como se especifica sin aplicar conversiones. Los datos pasados por referencia (incluyendo Strings) no se copian, solo los propios punteros; el llamante debe asegurarse de que los datos permanezcan válidos durante la vida útil de la lista de argumentos variables creada. La lista debe liberarse usando XtFree cuando ya no se necesite.
