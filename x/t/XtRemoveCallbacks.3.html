XtRemoveCallbacks(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAddCallback(3) FUNCIONES XT XtAddCallback(3)

NOMBRE

XtAddCallback, XtAddCallbacks, XtRemoveCallback, XtRemoveCallbacks, XtRemoveAllCallbacks - agregar y eliminar procedimientos de devolución de llamada

SINTAXIS

#include <X11/Intrinsic.h>

void XtAddCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtAddCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtRemoveCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveAllCallbacks(Widget w, const char *callback_name);

ARGUMENTOS

callback
Especifica el procedimiento de devolución de llamada.
callbacks
Especifica la lista terminada en nulo de procedimientos de devolución de llamada y los datos del cliente correspondientes.
callback_name
Especifica la lista de devoluciones de llamada a la que se va a agregar o eliminar el procedimiento.
client_data
Especifica el argumento que se pasará al procedimiento especificado cuando sea invocado por XtCallbacks o NULL, o los datos del cliente para comparar en los procedimientos de devolución de llamada registrados.
w
Especifica el widget.

DESCRIPCIÓN

La función XtAddCallback agrega el procedimiento de devolución de llamada especificado a la lista de devoluciones de llamada del widget especificado.

La función XtAddCallbacks agrega la lista especificada de devoluciones de llamada a la lista de devoluciones de llamada del widget especificado.

La función XtRemoveCallback elimina una devolución de llamada solo si coinciden tanto el procedimiento como los datos del cliente.

La función XtRemoveCallbacks elimina los procedimientos de devolución de llamada especificados de la lista de devoluciones de llamada del widget especificado.

La función XtRemoveAllCallbacks elimina todos los procedimientos de devolución de llamada de la lista de devoluciones de llamada del widget especificado.
