XtErrorMsg(3) FUNCIONES DE COMPATIBILIDAD XT XtErrorMsg(3)

NOMBRE

XtErrorMsg, XtSetErrorMsgHandler, XtWarningMsg, XtSetWarningMsgHandler - manejadores de errores de alto nivel

SINTAXIS

#include <X11/Intrinsic.h>

_X_NORETURN void XtErrorMsg(const char *name, const char *type, const char *class, const char *defaultMsg, String *params, Cardinal *num_params);

void XtSetErrorMsgHandler(_X_NORETURN XtErrorMsgHandler msg_handler);

void XtSetWarningMsgHandler(XtErrorMsgHandler msg_handler);

void XtWarningMsg(const char *name, const char *type, const char *class, const char *defaultMsg, String *params, Cardinal *num_params);

ARGUMENTOS

class
Especifica la clase de recurso del mensaje de error.
default
Especifica el mensaje predeterminado a utilizar.
name
Especifica el tipo general de error.
type
Especifica el nombre detallado del error.
msg_handler
Especifica el nuevo procedimiento de error fatal, que no debe devolver, o el procedimiento de error no fatal, que normalmente devuelve.
num_params
Especifica el número de valores en la lista de parámetros.
params
Especifica un puntero a una lista de valores que se almacenarán en el mensaje.

DESCRIPCIÓN

La función XtErrorMsg ha sido sustituida por XtAppErrorMsg.

La función XtSetErrorMsgHandler ha sido sustituida por XtAppSetErrorMsgHandler.

La función XtSetWarningMsgHandler ha sido sustituida por XtAppSetWarningMsgHandler.

La función XtWarningMsg ha sido sustituida por XtAppWarningMsg.
