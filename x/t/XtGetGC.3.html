XtGetGC(3) FUNCIONES XT XtGetGC(3)

NOMBRE

XtGetGC, XtReleaseGC - obtener y destruir un GC compartible

SINTAXIS

#include <X11/Intrinsic.h>

GC XtGetGC(Widget w, XtGCMask value_mask, XGCValues *values);

void XtReleaseGC(Widget w, GC gc);

ARGUMENTOS

gc
Especifica el GC a ser desasignado.
values
Especifica los valores reales para este GC.
value_mask
Especifica qué campos de los valores se especifican.
w
Especifica el widget.

DESCRIPCIÓN

La función XtGetGC devuelve un GC compartible y de solo lectura. Los parámetros de esta función son los mismos que los de XCreateGC, excepto que se pasa un widget en lugar de una pantalla. XtGetGC solo comparte GCs en los que todos los valores del GC devuelto por XCreateGC son iguales. En particular, no utiliza el value_mask proporcionado para determinar qué campos del GC considera relevantes un widget. El value_mask solo se utiliza para indicar al servidor qué campos deben ser completados con datos del widget y cuáles debe completar con valores predeterminados. Para más información sobre value_mask y values, consulte XCreateGC en la *Xlib - Interfaz del lenguaje C X*.

La función XtReleaseGC desasigna el GC compartido especificado.
