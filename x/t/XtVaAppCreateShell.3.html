XtAppCreateShell(3) FUNCIONES XT XtAppCreateShell(3)

NOMBRE

XtAppCreateShell, XtVaAppCreateShell - crear instancia de widget de nivel superior

SINTAXIS

#include <X11/Intrinsic.h>

Widget XtAppCreateShell(const char *nombre_aplicacion, const char *clase_aplicacion, WidgetClass clase_widget, Display *display, ArgList args, Cardinal num_args);

Widget XtVaAppCreateShell(const char * nombre_aplicacion, const char * clase_aplicacion, WidgetClass clase_widget, Display *display, ...);

ARGUMENTOS

nombre_aplicacion
Especifica el nombre de la instancia de la aplicación.
clase_aplicacion
Especifica el nombre de la clase de esta aplicación, que normalmente es el nombre genérico para todas las instancias de esta aplicación.
clase_widget
Especifica la clase de widget que debe ser el widget de nivel superior de la aplicación.
display
Especifica la pantalla de la que se obtendrán los recursos.
args
Especifica la lista de argumentos de la que se obtendrán los recursos.
num_args
Especifica el número de argumentos en la lista de argumentos.
...
Especifica la lista de argumentos variables de la que se obtendrán los recursos.

DESCRIPCIÓN

La función XtAppCreateShell guarda el nombre de aplicación y la clase de aplicación especificados para calificar todos los especificadores de recursos de widget. El nombre de aplicación y la clase de aplicación se usan como los componentes más a la izquierda en todos los nombres de recursos de widget para esta aplicación. XtAppCreateShell debe usarse para crear una nueva aplicación lógica dentro de un programa o para crear un shell en otra pantalla. En el primer caso, permite la especificación de una nueva raíz en la jerarquía de recursos. En el segundo caso, utiliza la base de datos de recursos asociada con la otra pantalla.

Tenga en cuenta que el widget devuelto por XtAppCreateShell tiene la propiedad WM_COMMAND establecida para los gestores de sesión (consulte el Capítulo 4).
