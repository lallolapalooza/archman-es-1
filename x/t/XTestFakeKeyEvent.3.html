DESCRIPCIÓN

Esta extensión es un conjunto mínimo de extensiones de cliente y servidor requerido para probar completamente el servidor X11 sin intervención del usuario. Esta extensión no está destinada a soportar la grabación y reproducción general de acciones del usuario.

Las funciones proporcionadas por esta extensión se dividen en dos grupos:

Operaciones de Cliente

Estas rutinas manipulan el comportamiento oculto del lado del cliente. La implementación real dependerá de los detalles de la unión de lenguajes y del grado de almacenamiento en búfer de solicitudes, caché de GContext, etc., que se proporcione. En la unión C, se proporcionan rutinas para acceder a los detalles internos de dos estructuras de datos opacas — GCs y Visuals — y para descartar cualquier solicitud pendiente en el búfer de salida de una conexión. Se espera que los detalles exactos difieran para otras uniones de lenguajes.

Solicitudes de Servidor

La primera de estas solicitudes es similar a la proporcionada en la mayoría de las extensiones: permite a un cliente especificar un número de versión principal y secundaria al servidor, y al servidor responder con las versiones principal y secundaria propias. Las dos solicitudes restantes permiten lo siguiente:
•Acceso a un recurso de servidor, de lo contrario de solo escritura: el cursor asociado con una ventana dada
•Quizás lo más importante, síntesis limitada de eventos del dispositivo de entrada, casi como si un usuario cooperativo hubiera movido el dispositivo señalador o presionado una tecla o botón.

Todas las funciones y procedimientos de la extensión XTEST, y todas las constantes y macros manifiestas, comenzarán con la cadena XTest. Todas las operaciones se clasifican como servidor/cliente (Servidor) o solo cliente (Cliente).

XTestQueryExtension devuelve True si la pantalla especificada admite la extensión XTEST, de lo contrario, False. Si la extensión es compatible, *event_base se establecerá en el número de evento para el primer evento de esta extensión y *error_base se establecerá en el número de error para el primer error de esta extensión. Dado que no se definen errores ni eventos para esta versión de la extensión, los valores devueltos aquí no están definidos (ni son útiles). Si la extensión es compatible, *major_version y *minor_version se establecen en los números de versión principal y secundaria de la extensión compatibles con la pantalla. De lo contrario, ninguno de los argumentos se establece.

Si la extensión es compatible, XTestCompareCursorWithWindow realiza una comparación del cursor cuyo ID se especifica mediante cursor (que puede ser None) con el cursor de la ventana especificada por window, devolviendo True si son iguales y False en caso contrario. Si la extensión no es compatible, la solicitud se ignora y se devuelve cero.

Si la extensión es compatible, XTestCompareCurrentCursorWithWindow realiza una comparación del cursor actual con el cursor de la ventana especificada, devolviendo True si son iguales y False en caso contrario. Si la extensión no es compatible, la solicitud se ignora y se devuelve cero.

Si la extensión es compatible, XTestFakeKeyEvent solicita al servidor que simule una KeyPress (si is_press es True) o una KeyRelease (si is_press es False) de la tecla con el keycode especificado; de lo contrario, la solicitud se ignora.

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido delay milisegundos después de recibir la solicitud (si delay es CurrentTime, se interpreta como que no hay retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y se haya completado el procesamiento posterior del evento simulado.

Si la extensión es compatible, XTestFakeButtonEvent solicita al servidor que simule una ButtonPress (si is_press es True) o una ButtonRelease (si is_press es False) del botón lógico numerado por el botón especificado; de lo contrario, la solicitud se ignora.

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido delay milisegundos después de recibir la solicitud (si delay es CurrentTime, se interpreta como que no hay retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y se haya completado el procesamiento posterior del evento simulado.

Si la extensión es compatible, XTestFakeMotionEvent solicita al servidor que simule un movimiento del puntero a la posición especificada (x, y) en la ventana raíz de screen_number; de lo contrario, la solicitud se ignora. Si screen_number es -1, se utiliza la pantalla actual (en la que se encuentra el puntero).

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido delay milisegundos después de recibir la solicitud (si delay es CurrentTime, se interpreta como que no hay retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y se haya completado el procesamiento posterior del evento simulado.

Si la extensión es compatible, XTestFakeRelativeMotionEvent solicita al servidor que simule un movimiento del puntero por los desplazamientos especificados (x, y) en relación con la posición actual del puntero en screen_number; de lo contrario, la solicitud se ignora. Si screen_number es -1, se utiliza la pantalla actual (en la que se encuentra el puntero).

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido delay milisegundos después de recibir la solicitud (si delay es CurrentTime, se interpreta como que no hay retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y se haya completado el procesamiento posterior del evento simulado.

Si impervious es True, entonces el cliente que se ejecuta se vuelve impermeable a las capturas del servidor. Si impervious es False, entonces el cliente que se ejecuta vuelve al estado normal de ser susceptible a las capturas del servidor.

XTestSetGContextOfGC establece el GContext dentro del tipo de dato opaco al que hace referencia gc para que sea el especificado por gid.

XTestSetVisualIDOfVisual establece el VisualID dentro del tipo de dato opaco al que hace referencia visual para que sea el especificado por visualid.

XTestDiscard descarta cualquier solicitud dentro del búfer de salida para la pantalla especificada. Devuelve True si se descartó alguna solicitud; de lo contrario, devuelve False.

>

VALORES DE RETORNO

Todas las rutinas que tengan un tipo de retorno Status devolverán un valor distinto de cero para el éxito y cero para el fallo. Incluso si la extensión XTEST es compatible, el servidor puede retirar dichas facilidades de forma arbitraria; en cuyo caso, posteriormente devolverán cero.
