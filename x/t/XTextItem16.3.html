XTextItem16(3)

Paquete: libx11

Licencias: MIT AND X11

XDrawText(3) FUNCIONES DE XLIB XDrawText(3)

NOMBRE

XDrawText, XDrawText16, XTextItem, XTextItem16 - dibujar texto politexto y estructuras de dibujo de texto

SINTAXIS

int XDrawText(Display *display, Drawable d, GC gc, int x, int y, XTextItem *items, int nitems);

int XDrawText16(Display *display, Drawable d, GC gc, int x, int y, XTextItem16 *items, int nitems);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
items
Especifica un array de ítems de texto.
nitems
Especifica el número de ítems de texto en el array.
x

y
Especifican las coordenadas x e y, que son relativas al origen del drawable especificado y definen el origen del primer carácter.

DESCRIPCIÓN

La función XDrawText16 es similar a XDrawText excepto que utiliza caracteres de 2 bytes o de 16 bits. Ambas funciones permiten un espaciado complejo y cambios de fuente entre cadenas contadas.

Cada ítem de texto se procesa en orden. Un miembro font distinto de None en un ítem provoca que la fuente se almacene en el GC y se utilice para texto subsiguiente. Un delta de elemento de texto especifica un cambio adicional en la posición a lo largo del eje x antes de que se dibuje la cadena. El delta siempre se suma al origen del carácter y no depende de ninguna característica de la fuente. Cada imagen de carácter, según lo definido por la fuente en el GC, se trata como una máscara adicional para una operación de relleno en el drawable. El drawable se modifica solo donde el carácter de la fuente tiene un bit establecido en 1. Si un ítem de texto genera un error BadFont, los ítems de texto anteriores pueden haber sido dibujados.

Para fuentes definidas con indexación lineal en lugar de indexación matricial de 2 bytes, cada estructura XChar2b se interpreta como un número de 16 bits con byte1 como el byte más significativo.

Ambas funciones utilizan estos componentes del GC: function, plane-mask, fill-style, font, subwindow-mode, clip-x-origin, clip-y-origin y clip-mask. También utilizan estos componentes dependientes del modo del GC: foreground, background, tile, stipple, tile-stipple-x-origin y tile-stipple-y-origin.

XDrawText y XDrawText16 pueden generar errores BadDrawable, BadFont, BadGC y BadMatch.

ESTRUCTURAS

Las estructuras XTextItem y XTextItem16 contienen:

typedef struct {
        char *chars;    /* puntero a la cadena */
        int nchars;     /* número de caracteres */
        int delta;      /* delta entre cadenas */
        Font font;      /* Fuente en la que imprimir, None no cambia */
} XTextItem;
typedef struct {
        XChar2b *chars; /* puntero a caracteres de dos bytes */
        int nchars;     /* número de caracteres */
        int delta;      /* delta entre cadenas */
        Font font;      /* fuente en la que imprimir, None no cambia */
} XTextItem16;

Si el miembro font no es None, la fuente se cambia antes de imprimir y también se almacena en el GC. Si se generó un error durante el dibujo del texto, los ítems anteriores pueden haber sido dibujados. La línea base de los caracteres se dibuja comenzando en las coordenadas x e y que se pasan a las funciones de dibujo de texto.

Por ejemplo, considere el rectángulo de fondo dibujado por XDrawImageString. Si desea que la esquina superior izquierda del rectángulo de fondo esté en la coordenada de píxel (x,y), pase (x,y + ascent) como las coordenadas de origen de la línea base a las funciones de texto. El ascent es el ascent de la fuente, según lo dado en la estructura XFontStruct. Si desea que la esquina inferior izquierda del rectángulo de fondo esté en la coordenada de píxel (x,y), pase (x,y - descent + 1) como las coordenadas de origen de la línea base a las funciones de texto. El descent es el descent de la fuente, según lo dado en la estructura XFontStruct.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadFont
Un valor para un argumento Font o GContext no nombra una Fuente definida.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana InputOnly como Drawable.
