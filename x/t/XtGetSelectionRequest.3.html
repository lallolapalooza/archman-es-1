NOMBRE

XtGetSelectionRequest - recupera el evento que activó el XtConvertSelectionProc

SINTAXIS

#include <X11/Intrinsic.h>

XSelectionRequestEvent* XtGetSelectionRequest(Widget w, Atom selection, XtRequestId request_id);

ARGUMENTOS

w
Especifica el widget.
selection
Especifica la selección que se está procesando.
request_id
Especifica el id del solicitante en caso de transferencias incrementales, o NULL en caso de transferencias atómicas.

DESCRIPCIÓN

XtGetSelectionRequest solo puede ser llamado desde dentro de un procedimiento XtConvertSelectionProc y devuelve un puntero al evento SelectionRequest que provocó la invocación del procedimiento de conversión. Request_id especifica un id único para la solicitud individual en el caso de que haya varias transferencias incrementales pendientes. Para transferencias atómicas, request_id debe especificarse como NULL. Si no se está procesando ningún evento SelectionRequest para el widget, selection e request_id especificados, XtGetSelectionRequest devuelve NULL.
