XtSetKeyTranslator(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtSetKeyTranslator(3) FUNCIONES XT XtSetKeyTranslator(3)

NOMBRE

XtSetKeyTranslator, XtTranslateKeycode, XtRegisterCaseConverter, XtConvertCase - convertir KeySym a KeyCodes

SINTAXIS

#include <X11/Intrinsic.h>

void XtSetKeyTranslator(Display *display, XtKeyProc proc);

void XtTranslateKeycode(Display *display, KeyCode keycode, Modifiers modifiers, Modifiers *modifiers_return, KeySym *keysym_return);

void XtRegisterCaseConverter(Display *display, XtCaseProc proc, KeySym start, KeySym stop);

void XtConvertCase(Display *display, KeySym keysym, KeySym *lower_return, KeySym *upper_return);

ARGUMENTOS

display
Especifica la pantalla.
keycode
Especifica el KeyCode a traducir.
keysym
Especifica el KeySym a convertir.
keysym_return
Devuelve el KeySym resultante.
lower_return
Devuelve el equivalente en minúsculas del KeySym.
upper_return
Devuelve el equivalente en mayúsculas del KeySym.
modifiers
Especifica los modificadores del KeyCode.
modifiers_return
Devuelve una máscara que indica los modificadores realmente utilizados para generar el KeySym.
proc
Especifica el procedimiento que realizará las traducciones o conversiones de teclas.
start
Especifica el primer KeySym para el cual este conversor es válido.
stop
Especifica el último KeySym para el cual este conversor es válido.

DESCRIPCIÓN

La función XtSetKeyTranslator establece el procedimiento especificado como el traductor de teclas actual. El traductor predeterminado es XtTranslateKey, un XtKeyProc que utiliza los modificadores Shift y Lock con las interpretaciones definidas por el protocolo principal. Se proporciona para que los nuevos traductores puedan llamarlo para obtener traducciones predeterminadas de KeyCode a KeySym y para que el traductor predeterminado pueda ser reinstalado.

La función XtTranslateKeycode pasa los argumentos especificados directamente al traductor de KeyCode a KeySym registrado actualmente.

La función XtRegisterCaseConverter registra el conversor de mayúsculas/minúsculas especificado. Los argumentos start y stop proporcionan el rango inclusivo de KeySyms para los cuales se llamará este conversor. El nuevo conversor anula cualquier conversor anterior para KeySyms en ese rango. No existe una interfaz para eliminar conversores; es necesario registrar un conversor de identidad. Cuando se registra un nuevo conversor, las Intrínsecas actualizan el estado del teclado si es necesario. El conversor predeterminado entiende la conversión de mayúsculas/minúsculas para todos los KeySyms definidos en el protocolo principal.

La función XtConvertCase llama al conversor apropiado y devuelve los resultados. Un XtKeyProc suministrado por el usuario puede necesitar utilizar esta función.
