XTextWidth(3) FUNCIONES DE XLIB XTextWidth(3)

NOMBRE

XTextWidth, XTextWidth16 - calcular el ancho del texto

SINTAXIS

int XTextWidth(XFontStruct *font_struct, const char *string, int count);

int XTextWidth16(XFontStruct *font_struct, const XChar2b *string, int count);

ARGUMENTOS

count
Especifica el recuento de caracteres en la cadena dada.
font_struct
Especifica la fuente utilizada para el cálculo del ancho.
string
Especifica la cadena de caracteres.

DESCRIPCIÓN

Las funciones XTextWidth y XTextWidth16 devuelven el ancho de las cadenas de caracteres de 8 bits o 2 bytes especificadas.
