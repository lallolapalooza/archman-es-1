XtFindFile(3) FUNCIONES XT XtFindFile(3)

NOMBRE

XtFindFile - busca un archivo usando sustituciones en la lista de rutas

SINTAXIS

#include <X11/Intrinsic.h>

char * XtFindFile(const char *ruta, Substitution sustituciones, Cardinal num_sustituciones, XtFilePredicate predicado);

ARGUMENTOS

ruta
Especifica una cadena de nombres de archivo potenciales, incluyendo caracteres de sustitución.
sustituciones
Especifica una lista de sustituciones a realizar en una ruta.
num_sustituciones
Especifica el número de sustituciones pasadas.
predicado
Especifica un procedimiento a llamar para juzgar un nombre de archivo potencial, o NULL.

DESCRIPCIÓN

El parámetro ruta especifica una cadena que consiste en una serie de nombres de archivo potenciales delimitados por dos puntos. Dentro de cada nombre, el carácter de porcentaje especifica una sustitución de cadena seleccionada por el carácter siguiente. La secuencia de caracteres “%:” especifica un dos puntos incrustado que no es un delimitador; la secuencia se reemplaza por un solo dos puntos. La secuencia de caracteres “%%” especifica un carácter de porcentaje que no introduce una sustitución; la secuencia se reemplaza por un solo carácter de porcentaje. Si un carácter de porcentaje es seguido por cualquier otro carácter, XtFindFile busca en las sustituciones especificadas ese carácter en el campo coincidencia y, si lo encuentra, reemplaza el carácter de porcentaje y el carácter de coincidencia con la cadena en el campo sustitución correspondiente. Una entrada de campo de sustitución NULL es equivalente a un puntero a una cadena vacía. Si el sistema operativo no interpreta múltiples separadores de nombres incrustados en la ruta (es decir, “/” en POSIX) de la misma manera que un solo separador, XtFindFile colapsará múltiples separadores en uno solo después de realizar todas las sustituciones de cadenas. Excepto por el colapso de separadores incrustados, el contenido de las sustituciones de cadenas no es interpretado por XtFindFile y, por lo tanto, puede contener cualquier carácter dependiente del sistema operativo, incluyendo separadores de nombres adicionales. Cada cadena resultante se pasa al procedimiento de predicado hasta que se encuentra una cadena para la cual el procedimiento devuelve True; esta cadena es el valor de retorno para XtFindFile. Si ninguna cadena produce un retorno True del predicado, XtFindFile devuelve NULL.

Si el parámetro predicado es NULL, se utilizará un procedimiento interno que comprueba si el archivo existe, es legible y no es un directorio.

Es responsabilidad del llamador liberar la cadena devuelta usando XtFree cuando ya no sea necesaria.
