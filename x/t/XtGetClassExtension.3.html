XtGetClassExtension(3) FUNCIONES XT XtGetClassExtension(3)

NOMBRE

XtGetClassExtension - localizar un registro de extensión de clase

SINTAXIS

#include <X11/Intrinsic.h>

XtPointer XtGetClassExtension(WidgetClass object_class, Cardinal byte_offset, XrmQuark type, long version, Cardinal record_size);

ARGUMENTOS

object_class
Especifica la clase de widget que contiene la lista de extensiones a buscar.
byte_offset
Especifica el desplazamiento en bytes desde la base de la clase de widget del campo de extensión a buscar.
type
Especifica el nombre de la extensión de clase a localizar.
version
Especifica la versión mínima aceptable de la extensión de clase requerida para una coincidencia.
record_size
Especifica la longitud mínima aceptable del registro de extensión de clase requerida para una coincidencia, o 0.

DESCRIPCION

La lista de registros de extensión en el desplazamiento especificado en la widget_class especificada se buscará para una coincidencia con el type especificado, una versión mayor o igual a la version especificada, y un tamaño de registro mayor o igual al record_size especificado si este es distinto de cero. XtGetClassExtension devuelve un puntero a un registro de extensión correspondiente o NULL si no se encuentra ninguna coincidencia. El registro de extensión devuelto es propiedad de la clase de widget y no debe ser modificado ni liberado por el llamador, excepto posiblemente para ser modificado por el propietario de la clase de widget.
