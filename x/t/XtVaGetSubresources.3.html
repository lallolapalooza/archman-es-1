XtVaGetSubresources(3)

XtGetSubresources(3) FUNCIONES XT XtGetSubresources(3)

NOMBRE

XtGetSubresources, XtVaGetSubresources - obtener subrecursos

SINTAXIS

#include <X11/Intrinsic.h>

void XtGetSubresources(Widget w, XtPointer base, const char *name, const char * class, XtResourceList resources, Cardinal num_resources, ArgList args, Cardinal num_args);

void XtVaGetSubresources(Widget w, XtPointer base, const char *name, const char *class, XtResourceList resources, Cardinal num_resources, ...);

ARGUMENTOS

args
Especifica la lista de argumentos para anular los recursos obtenidos de la base de datos de recursos.
base
Especifica la dirección base de la estructura de datos de la subparte donde se escribirán los recursos.
class
Especifica la clase de la subparte.
name
Especifica el nombre de la subparte.
num_args
Especifica el número de argumentos en la lista de argumentos.
num_resources
Especifica el número de recursos en la lista de recursos.
resources
Especifica la lista de recursos para la subparte.
w
Especifica el widget que desea recursos para una subparte o que identifica la base de datos de recursos a buscar.
...
Especifica los argumentos variables para anular los recursos obtenidos de la base de datos de recursos.

DESCRIPCIÓN

La función XtGetSubresources construye una lista de nombre/clase a partir del nombre/clase de la aplicación, el nombre/clases de todos sus ancestros y el propio widget. Luego, añade a esta lista el par nombre/clase proporcionado. Los recursos se obtienen de la lista de argumentos, la base de datos de recursos o los valores predeterminados de la lista de recursos. Luego, se copian en el registro de la subparte. Si args es NULL, num_args debe ser cero. Sin embargo, si num_args es cero, la lista de argumentos no se referencia.
