XtDisplayInitialize(3) FUNCIONES XT XtDisplayInitialize(3)

NOMBRE

XtDisplayInitialize, XtOpenDisplay, XtDatabase, XtScreenDatabase, XtCloseDisplay - inicializa, abre o cierra una pantalla

SINTAXIS

#include <X11/Intrinsic.h>

void XtDisplayInitialize(XtAppContext app_context, Display *display, const char *application_name, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc, char **argv);

Display *XtOpenDisplay(XtAppContext app_context, const char *display_string, const char *application_name, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc, char **argv);

void XtCloseDisplay(Display *display);

XrmDatabase XtDatabase(Display *display);

XrmDatabase XtScreenDatabase(Screen* screen);

ARGUMENTOS

argc
Especifica un puntero al número de parámetros de la línea de comandos.
argv
Especifica los parámetros de la línea de comandos.
app_context
Especifica el contexto de la aplicación.
application_class
Especifica el nombre de clase de esta aplicación, que normalmente es el nombre genérico para todas las instancias de esta aplicación.
application_name
Especifica el nombre de la instancia de la aplicación.
display
Especifica la pantalla. Tenga en cuenta que una pantalla puede estar en como máximo un contexto de aplicación.
num_options
Especifica el número de entradas en la lista de opciones.
options
Especifica cómo analizar la línea de comandos para recursos específicos de la aplicación. El argumento options se pasa como parámetro a XrmParseCommand. Para más información, consulte Xlib - C Language X Interface.
screen
Especifica la pantalla cuya base de datos de recursos se va a devolver.

DESCRIPCIÓN

La función XtDisplayInitialize construye la base de datos de recursos, llama a la función XrmParseCommand de Xlib para analizar la línea de comandos y realiza otras inicializaciones por pantalla. Después de llamar a XrmParseCommand, argc y argv contienen solo aquellos parámetros que no estaban en la tabla de opciones estándar o en la tabla especificada por el argumento options. Si el argc modificado no es cero, la mayoría de las aplicaciones simplemente imprimen el argv modificado junto con un mensaje que enumera las opciones permitidas. En sistemas basados en UNIX, el nombre de la aplicación suele ser el componente final de argv[0]. Si el recurso synchronize es True para la aplicación especificada, XtDisplayInitialize llama a la función XSynchronize de Xlib para poner Xlib en modo síncrono para esta conexión de pantalla. Si el recurso reverseVideo es True, los Intrínsecos intercambian XtDefaultForeground y XtDefaultBackground para los widgets creados en esta pantalla. (Ver Sección 9.6.1).

La función XtOpenDisplay llama a XOpenDisplay con el nombre de pantalla especificado. Si display_string es NULL, XtOpenDisplay utiliza el valor actual de la opción -display especificada en argv y, si no se especifica ninguna pantalla en argv, utiliza la pantalla predeterminada del usuario (en sistemas basados en UNIX, este es el valor de la variable de entorno DISPLAY).

Si esto tiene éxito, llama a XtDisplayInitialize y le pasa la pantalla abierta y el valor de la opción -name especificada en argv como nombre de la aplicación. Si no se especifica ninguna opción de nombre, utiliza el nombre de aplicación pasado a XtOpenDisplay. Si el nombre de aplicación es NULL, utiliza el último componente de argv[0]. XtOpenDisplay devuelve la pantalla recién abierta o NULL si falló.

XtOpenDisplay se proporciona como una conveniencia para el programador de aplicaciones.

La función XtCloseDisplay cierra la pantalla especificada tan pronto como sea seguro hacerlo. Si se llama desde dentro de una distribución de eventos (por ejemplo, un procedimiento de devolución de llamada), XtCloseDisplay no cierra la pantalla hasta que se completa la distribución. Tenga en cuenta que las aplicaciones solo necesitan llamar a XtCloseDisplay si van a continuar ejecutándose después de cerrar la pantalla; de lo contrario, deberían llamar a XtDestroyApplicationContext o simplemente salir.

La función XtDatabase devuelve la base de datos de recursos completamente fusionada que fue construida por XtDisplayInitialize asociada con la pantalla que se pasó. Si esta pantalla no ha sido inicializada por XtDisplayInitialize, los resultados no están definidos.

La función XtScreenDatabase devuelve la base de datos de recursos completamente fusionada asociada con la pantalla especificada. Si la screen no pertenece a una Display inicializada por XtDisplayInitialize, los resultados no están definidos.
