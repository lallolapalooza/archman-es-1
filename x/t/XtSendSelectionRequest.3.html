XtCreateSelectionRequest(3) FUNCIONES XT XtCreateSelectionRequest(3)

NOMBRE

XtCreateSelectionRequest, XtSendSelectionRequest, XtCancelSelectionRequest - agrupa múltiples solicitudes de conversión de selección en una única solicitud usando el objetivo MULTIPLE

SINTAXIS

#include <X11/Intrinsic.h>

void XtCreateSelectionRequest(Widget requestor, Atom selection);

void XtSendSelectionRequest(Widget requestor, Atom selection, Time time);

void XtCancelSelectionRequest(Widget requestor, Atom selection);

ARGUMENTOS

requestor
Especifica el widget que realiza la solicitud. Debe ser de la clase Core o una subclase de ella.
selection
Especifica la selección deseada en particular.
time
Especifica la marca de tiempo que se utilizará al realizar la solicitud.

DESCRIPCIÓN

Cuando se llama a XtCreateSelectionRequest, las llamadas posteriores a XtGetSelectionValue y XtGetSelectionValueIncremental con el solicitante y la selección especificados en XtCreateSelectionRequest se agruparán en una única solicitud de conversión de selección con múltiples objetivos. La solicitud se inicia realmente llamando a XtSendSelectionRequest.

Cuando se llama a XtSendSelectionRequest con un valor de requestor y selection que coinciden con una llamada anterior a XtCreateSelectionRequest, se envía realmente una solicitud de conversión de selección al propietario de la selección. Si se pone en cola una solicitud de un solo objetivo, se realiza esa solicitud. Si se ponen en cola múltiples objetivos, se agrupan en una única solicitud con el objetivo MULTIPLE utilizando la marca de tiempo especificada. A medida que se realizan las conversiones, se invocan sucesivamente las devoluciones de llamada asociadas a cada XtGetSelectionValue y XtGetSelectionValueIncremental.

Las aplicaciones multihilo deben bloquear el contexto de la aplicación antes de llamar a XtCreateSelectionRequest y liberar el bloqueo después de llamar a XtSendSelectionRequest para garantizar que el hilo que ensambla la solicitud esté seguro contra interferencias de otro hilo que ensamble una solicitud diferente que nombre el mismo widget y selección.

Cuando se llama a XtCancelSelectionRequest, se limpian todas las solicitudes puestas en cola desde la última llamada a XtCreateSelectionRequest. Las llamadas posteriores a XtGetSelectionValue, XtGetSelectionValues, XtGetSelectionValueIncremental y XtGetSelectionValuesIncremental no se pospondrán.
