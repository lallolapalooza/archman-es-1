XTextPropertyToStringList(3)

Paquete: libx11

Licencias: MIT AND X11

XStringListToTextProperty(3) FUNCIONES DE XLIB XStringListToTextProperty(3)

NOMBRE

XStringListToTextProperty, XTextPropertyToStringList, XFreeStringList, XTextProperty - convertir listas de cadenas y estructura de propiedad de texto

SINTAXIS

Status XStringListToTextProperty(char **list, int count, XTextProperty *text_prop_return);

Status XTextPropertyToStringList(XTextProperty *text_prop, char ***list_return, int *count_return);

void XFreeStringList(char **list);

ARGUMENTOS

count
Especifica el número de cadenas.
count_return
Devuelve el número de cadenas.
list
Especifica la lista de cadenas a liberar.
list
Especifica una lista de cadenas de caracteres terminadas en nulo.
list_return
Devuelve una lista de cadenas de caracteres terminadas en nulo.
text_prop
Especifica la estructura XTextProperty a utilizar.
text_prop_return
Devuelve la estructura XTextProperty.

DESCRIPCIÓN

La función XStringListToTextProperty establece la XTextProperty especificada para que sea de tipo STRING (formato 8) con un valor que representa la concatenación de la lista especificada de cadenas de caracteres separadas por nulos. Un byte nulo adicional (que no está incluido en el miembro nitems) se almacena al final del campo de valor de text_prop_return. Se asume (sin verificación) que las cadenas están en la codificación STRING. Si no hay suficiente memoria disponible para la nueva cadena de valor, XStringListToTextProperty no establece ningún campo en la estructura XTextProperty y devuelve un estado cero. De lo contrario, devuelve un estado distinto de cero. Para liberar el almacenamiento del campo de valor, use XFree.

La función XTextPropertyToStringList devuelve una lista de cadenas que representa los elementos separados por nulos de la estructura XTextProperty especificada. Los datos en text_prop deben ser de tipo STRING y formato 8. Múltiples elementos de la propiedad (por ejemplo, las cadenas en una selección de texto disjoin) están separados por NULL (codificación 0). El contenido de la propiedad no está terminado en nulo. Si no hay suficiente memoria disponible para la lista y sus elementos, XTextPropertyToStringList no establece ningún valor de retorno y devuelve un estado cero. De lo contrario, devuelve un estado distinto de cero. Para liberar el almacenamiento de la lista y su contenido, use XFreeStringList.

La función XFreeStringList libera la memoria asignada por XmbTextPropertyToTextList, Xutf8TextPropertyToTextList y XTextPropertyToStringList, y la lista de caracteres faltantes asignada por XCreateFontSet.

ESTRUCTURAS

La estructura XTextProperty contiene:

typedef struct {
        unsigned char *value;   /* datos de la propiedad */
        Atom encoding;  /* tipo de propiedad */
        int format;     /* 8, 16 o 32 */
        unsigned long nitems;   /* número de elementos en value */
} XTextProperty;
