XtKeysymToKeycodeList(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetKeysymTable(3) FUNCIONES XT XtGetKeysymTable(3)

NOMBRE

XtGetKeysymTable, XtKeysymToKeycodeList - consultar símbolos de tecla y códigos de tecla

SINTAXIS

#include <X11/Intrinsic.h>

KeySym* XtGetKeysymTable(Display* display, KeyCode* min_keycode_return, int *keysyms_per_keycode_return);

void XtKeysymToKeycodeList(Display* display, KeySym keysym, KeyCode** keycodes_return, Cardinal* keycount_return);

ARGUMENTOS

display
Especifica la pantalla cuya tabla se requiere.
min_keycode_return
Devuelve el KeyCode mínimo válido para la pantalla.
keysyms_per_keycode_return
Devuelve el número de KeySyms almacenados para cada KeyCode.
keysym
Especifica el KeySym que se va a buscar.
keycodes_return
Devuelve una lista de KeyCodes que tienen keysym asociado a ellos, o NULL si keycount_return es 0.
keycount_return
Devuelve el número de KeyCodes en la lista de códigos de tecla.

DESCRIPCIÓN

XtGetKeysymTable devuelve un puntero a la copia de los Intrinsics de la tabla KeyCode-a-KeySym del servidor. Esta tabla no debe ser modificada.

El procedimiento XtKeysymToKeycodeList devuelve todos los KeyCodes que tienen keysym en su entrada para la tabla de mapeo del teclado asociada con display. El llamante debe liberar el almacenamiento apuntado por keycodes_return usando XtFree cuando ya no sea útil.
