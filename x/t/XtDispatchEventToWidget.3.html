XtInsertEventTypeHandler(3) FUNCIONES XT XtInsertEventTypeHandler(3)

NOMBRE

XtInsertEventTypeHandler, XtRemoveEventTypeHandler, XtRegisterExtensionSelector, XtSetEventDispatcher, XtDispatchEventToWidget - manejo de eventos de extensión

SINTAXIS

#include <X11/Intrinsic.h>

void XtInsertEventTypeHandler(Widget widget, int event_type, XtPointer select_data, XtEventHandler proc, XtPointer client_data, XtListPosition position);

void XtRemoveEventTypeHandler(Widget widget, int event_type, XtPointer select_data, XtEventHandler proc, XtPointer client_data);

void XtRegisterExtensionSelector(Display* display, int min_event_type, int max_event_type, XtExtensionSelectProc proc, XtPointer client_data);

XtEventDispatchProc XtSetEventDispatcher(Display* display, int event_type, XtEventDispatchProc proc);

Boolean XtDispatchEventToWidget(Widget widget, XEvent* event);

ARGUMENTOS

widget
Especifica el widget para este manejador de eventos. Debe ser de la clase Core o de cualquier subclase de la misma.
event_type
Especifica el tipo de evento.
select_data
Especifica datos utilizados para seleccionar o deseleccionar eventos del servidor.
proc
Especifica el procedimiento.
client_data
Especifica datos adicionales que se pasarán al manejador de eventos.
position
Especifica cuándo se debe llamar al manejador de eventos en relación con otros manejadores registrados previamente.
display
Especifica la pantalla.
min_event_type, max_event_type
Especifica el rango de tipos de eventos para esta extensión.
event
Especifica un puntero al evento que se va a distribuir.

DESCRIPCIÓN

La función XtInsertEventTypeHandler registra un procedimiento con el mecanismo de distribución que se llamará cuando un evento que coincida con el event_type especificado se distribuya al widget especificado.

Si event_type es uno de los eventos del protocolo X central, select_data debe ser un puntero a un valor de tipo EventMask, que indica la máscara de eventos que se utilizará para seleccionar el evento deseado. Esta máscara de eventos se incluirá en el valor devuelto por XtBuildEventMask. Si el widget está realizado, XtInsertEventTypeHandler llama a XSelectInput si es necesario. Especificar NULL para select_data es equivalente a especificar un puntero a una máscara de eventos que contiene 0. Esto es similar a la función XtInsertRawEventHandler.

Si event_type especifica un tipo de evento de extensión, la semántica de los datos apuntados por select_data la define el selector de extensión registrado para el tipo de evento especificado.

En ambos casos, los Intrinsics no están obligados a copiar los datos apuntados por select_data, por lo que el llamador debe asegurarse de que permanezcan válidos mientras el manejador de eventos permanezca registrado con este valor de select_data.

El argumento position permite al cliente controlar el orden de invocación de los manejadores de eventos registrados para el mismo tipo de evento. Si al cliente no le importa el orden, normalmente debería especificar XtListTail, que registra este manejador de eventos después de cualquier manejador registrado previamente para este tipo de evento.

La función XtRemoveEventTypeHandler anula el registro de un manejador de eventos registrado con XtInsertEventTypeHandler para el tipo de evento especificado. La solicitud se ignora si client_data no coincide con el valor dado cuando se registró el manejador.

Si event_type especifica uno de los eventos del protocolo X central, select_data debe ser un puntero a un valor de tipo EventMask, que indica la máscara que se utilizará para deseleccionar el evento apropiado. Si el widget está realizado, XtRemoveEventTypeHandler llama a XSelectInput si es necesario. Especificar NULL para select_data es equivalente a especificar un puntero a una máscara de eventos que contiene 0. Esto es similar a la función XtRemoveRawEventHandler.

Si event_type especifica un tipo de evento de extensión, la semántica de los datos apuntados por select_data la define el selector de extensión registrado para el tipo de evento especificado.

La función XtRegisterExtensionSelector registra un procedimiento para organizar la entrega de eventos de extensión a los widgets.

Si min_event_type y max_event_type coinciden con los parámetros de una llamada anterior a XtRegisterExtensionSelector para la misma pantalla, el proc y client_data reemplazan los valores registrados previamente. Si el rango especificado por min_event_type y max_event_type se superpone de alguna otra manera con el rango de los parámetros de una llamada anterior para la misma pantalla, se produce un error.

La función XtSetEventDispatcher registra el procedimiento de distribución de eventos especificado por proc para eventos con el tipo event_type. Se devuelve el distribuidor registrado previamente (o el distribuidor predeterminado si no había un distribuidor registrado previamente).

Si proc es NULL, se restaura el procedimiento predeterminado para el tipo especificado.

En el futuro, cuando se llame a XtDispatchEvent con un evento de event_type, se invocará el proc especificado (o el distribuidor predeterminado) para determinar un widget en el que distribuir el evento.

La función XtDispatchEventToWidget escanea la lista de manejadores de eventos registrados para el widget especificado y llama a cada manejador que se haya registrado para el tipo de evento especificado, sujeto al valor continue_to_dispatch devuelto por cada manejador. Los Intrinsics se comportan como si los manejadores de eventos se hubieran registrado en la cabeza de la lista para los eventos Expose, NoExpose, GraphicsExpose y VisibilityNotify para invocar el procedimiento de exposición del widget de acuerdo con las reglas de compresión de exposición y para actualizar el campo visible del widget si visible_interest es True. Estos manejadores de eventos internos nunca establecen continue_to_dispatch en False.

XtDispatchEventToWidget devuelve True si se llamó a algún manejador de eventos y False en caso contrario.

ToWidget(3)

ToWidget - convierte un archivo de configuración de Xcursor a un formato binario.

NOMBRE

ToWidget - convierte un archivo de configuración de Xcursor a un formato binario.

SINOPSIS

ToWidget [-o archivo] [-b] [archivo ...]

DESCRIPCIÓN

ToWidget es una utilidad para convertir archivos de configuración de Xcursor a un formato binario que puede ser utilizado por el tema del cursor.

OPCIONES

-o archivo
Especifica el archivo de salida. Si no se especifica, la salida se redirige a stdout.
-b
Convierte los archivos a formato binario.

EJEMPLO

Para convertir un archivo de configuración mycursor.xcursor a un archivo binario llamado mycursor.bin, use:

$ ToWidget -o mycursor.bin mycursor.xcursor
