XtOffsetOf(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtOffset(3) FUNCIONES XT XtOffset(3)

NOMBRE

XtOffset, XtOffsetOf, XtNumber - determinar el desplazamiento en bytes o el número de elementos de un array

SINTAXIS

#include <X11/Intrinsic.h>

Cardinal XtOffset(Type tipo_puntero, Field nombre_campo);

Cardinal XtOffsetOf(Type tipo_estructura, Field nombre_campo);

Cardinal XtNumber(ArrayVariable array);

ARGUMENTOS

array
Especifica un array de tamaño fijo.
nombre_campo
Especifica el nombre del campo para el cual calcular el desplazamiento en bytes.
tipo_puntero
Especifica un tipo declarado como puntero a la estructura.
tipo_estructura
Especifica un tipo declarado como una estructura.

DESCRIPCIÓN

La macro XtOffset se usa generalmente para determinar el desplazamiento de varios campos de recursos desde el principio de un widget y se puede usar en tiempo de compilación en inicializaciones estáticas.

La macro XtOffsetOf se expande a una expresión constante que da el desplazamiento en bytes al miembro de estructura especificado desde el principio de la estructura. Normalmente se utiliza para inicializar estáticamente listas de recursos y es más portable que XtOffset, que cumple la misma función.

La macro XtNumber devuelve el número de elementos en las listas de argumentos, listas de recursos y otros arrays contados especificados.
