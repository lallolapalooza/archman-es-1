XtAppAddSignal(3) FUNCIONES DE XT XtAppAddSignal(3)

NOMBRE

XtAppAddSignal, XtRemoveSignal, XtNoticeSignal - registrar y eliminar una fuente de señal

SINTAXIS

#include <X11/Intrinsic.h>

XtSignalId XtAppAddSignal(XtAppContext app_context, XtSignalCallbackProc proc, XtPointer client_data);

void XtRemoveSignal(XtSignalId id);

void XtNoticeSignal(XtSignalId id);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
client_data
Especifica el argumento que se pasará al procedimiento especificado cuando se haya activado una señal.
id
Especifica el ID devuelto por la llamada correspondiente a XtAppAddSignal.
proc
Especifica el procedimiento que se llamará cuando se haya activado la señal.

DESCRIPCIÓN

La función XtAppAddSignal inicia un mecanismo para manejar señales dentro del contexto de Intrinsics. Antes de establecer un manejador de señales dependiente del sistema operativo, la aplicación puede llamar a XtAppAddSignal y almacenar el id devuelto en un lugar accesible para el manejador de señales.

Al recibir una señal del sistema operativo, la aplicación puede llamar a XtNoticeSignal pasando el id devuelto por la llamada a XtAppAddSignal.

XtNoticeSignal es la única función de Intrinsics que puede llamarse de forma segura desde un manejador de señales. Si XtNoticeSignal se llama varias veces antes de que Intrinsics pueda invocar la devolución de llamada registrada, la devolución de llamada solo se invoca una vez. Lógicamente, Intrinsics mantiene un indicador "pendiente" para cada devolución de llamada registrada. Este indicador es inicialmente False y se establece en True por XtNoticeSignal; Intrinsics invoca la devolución de llamada siempre que el indicador es True, y el indicador se establece en False justo antes de que se invoque la devolución de llamada.

La función XtRemoveSignal se llama para eliminar el manejador de señales de Intrinsics especificado. El cliente debe deshabilitar la fuente de la señal antes de llamar a XtRemoveSignal.
