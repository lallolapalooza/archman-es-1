XtUninstallTranslations(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtParseTranslationTable(3) FUNCIONES XT XtParseTranslationTable(3)

NOMBRE

XtParseTranslationTable, XtAugmentTranslations, XtOverrideTranslations, XtUninstallTranslations - gestionar tablas de traducción

SINTAXIS

#include <X11/Intrinsic.h>

XtTranslations XtParseTranslationTable(const char *table);

void XtAugmentTranslations(Widget w, XtTranslations translations);

void XtOverrideTranslations(Widget w, XtTranslations translations);

void XtUninstallTranslations(Widget w);

ARGUMENTOS

table
Especifica la tabla de traducción a compilar.
translations
Especifica la tabla de traducción compilada para fusionar (no debe ser NULL).
w
Especifica el widget en el que se fusionarán o eliminarán las nuevas traducciones.

DESCRIPCIÓN

La función XtParseTranslationTable compila la tabla de traducción en la representación interna opaca de tipo XtTranslations. Tenga en cuenta que si se requiere una tabla de traducción vacía para cualquier propósito, se puede obtener llamando a XtParseTranslationTable y pasando una cadena vacía.

La función XtAugmentTranslations fusiona de forma no destructiva las nuevas traducciones en las traducciones existentes del widget. Si las nuevas traducciones contienen un evento o una secuencia de eventos que ya existen en las traducciones del widget, la nueva traducción se ignora.

La función XtOverrideTranslations fusiona de forma destructiva las nuevas traducciones en las traducciones existentes del widget. Si las nuevas traducciones contienen un evento o una secuencia de eventos que ya existen en las traducciones del widget, la nueva traducción se fusiona y anula la traducción del widget.

Para reemplazar completamente las traducciones de un widget, utilice XtSetValues en el recurso XtNtranslations y especifique una tabla de traducción compilada como valor.

La función XtUninstallTranslations hace que se elimine toda la tabla de traducción del widget.
