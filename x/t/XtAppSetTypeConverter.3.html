XtAppSetTypeConverter(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppSetTypeConverter(3) FUNCIONES XT XtAppSetTypeConverter(3)

NOMBRE

XtAppSetTypeConverter, XtSetTypeConverter - registrar convertidor de recursos

SINTAXIS

#include <X11/Intrinsic.h>

void XtAppSetTypeConverter(XtAppContext app_context, const char *from_type, const char * to_type, XtTypeConverter converter, XtConvertArgList convert_args, Cardinal num_args, XtCacheType cache_type, XtDestructor destructor);

void XtSetTypeConverter(const char *from_type, const char *to_type, XtTypeConverter converter, XtConvertArgList convert_args, Cardinal num_args, XtCacheType cache_type, XtDestructor destructor);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
converter
Especifica el procedimiento de conversión de tipos.
convert_args
Especifica cómo calcular los argumentos adicionales para el convertidor o NULL.
from_type
Especifica el tipo de origen.
num_args
Especifica el número de argumentos adicionales para el convertidor o cero.
to_type
Especifica el tipo de destino.
cache_type
Especifica si los recursos producidos por este convertidor son compartibles o específicos de la pantalla y cuándo deben liberarse.
destructor
Especifica un procedimiento de destrucción para los recursos producidos por esta conversión, o NULL si no se requiere ninguna acción adicional para desasignar los recursos producidos por el convertidor.

DESCRIPCIÓN

XtSetTypeConverter registra el convertidor de tipos y el destructor especificados en todos los contextos de aplicación creados por el proceso que llama, incluidos los contextos de aplicación futuros que puedan crearse. XtAppSetTypeConverter registra el convertidor de tipos especificado en el único contexto de aplicación especificado. Si se especifican los mismos from_type y to_type en varias llamadas a cualquiera de las funciones, la más reciente anula las anteriores.
