XtGetSelectionParameters(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetSelectionParameters(3) FUNCIONES XT XtGetSelectionParameters(3)

NOMBRE

XtGetSelectionParameters - recupera los parámetros de selección para una solicitud de selección con un único destino

SINTAXIS

#include <X11/Intrinsic.h>

void XtGetSelectionParameters(Widget owner, Atom selection, XtRequestId request_id, Atom *type_return, XtPointer *value_return, unsigned long *length_return, int *format_return);

ARGUMENTOS

owner
Especifica el widget que posee la selección especificada.
selection
Especifica la selección que se está procesando.
request_id
Especifica el id del solicitante en el caso de selecciones incrementales, o NULL en el caso de transferencias atómicas.
type_return
Especifica un puntero a un átomo en el que se almacenará el tipo de propiedad de los parámetros.
value_return
Especifica un puntero en el que se almacenará un puntero a los parámetros. Se almacenará NULL si no hay parámetros que acompañen a la solicitud.
length_return
Especifica un puntero en el que se almacenará el número de elementos de datos en value_return del tamaño indicado por format_return.
format_return
Especifica un puntero en el que se almacenará el tamaño en bits de los datos de los parámetros en los elementos de value_return.

DESCRIPCIÓN

XtGetSelectionParameters solo puede ser llamada desde dentro de un XtConvertSelectionProc o desde dentro de la última llamada a un XtConvertSelectionIncrProc con un nuevo request_id.
