XtAddCallback(3) FUNCIONES XT XtAddCallback(3)

NOMBRE

XtAddCallback, XtAddCallbacks, XtRemoveCallback, XtRemoveCallbacks, XtRemoveAllCallbacks - añadir y eliminar procedimientos de llamada

SINTAXIS

#include <X11/Intrinsic.h>

void XtAddCallback(Widget w, const char *nombre_llamada, XtCallbackProc llamada, XtPointer datos_cliente);

void XtAddCallbacks(Widget w, const char *nombre_llamada, XtCallbackList llamadas);

void XtRemoveCallback(Widget w, const char *nombre_llamada, XtCallbackProc llamada, XtPointer datos_cliente);

void XtRemoveCallbacks(Widget w, const char *nombre_llamada, XtCallbackList llamadas);

void XtRemoveAllCallbacks(Widget w, const char *nombre_llamada);

ARGUMENTOS

llamada
Especifica el procedimiento de llamada.
llamadas
Especifica la lista terminada en nulo de procedimientos de llamada y los datos de cliente correspondientes.
nombre_llamada
Especifica la lista de llamadas a la que se va a añadir o de la que se va a eliminar el procedimiento.
datos_cliente
Especifica el argumento que se pasará al procedimiento especificado cuando sea invocado por XtCallbacks o NULL, o los datos del cliente que coincidan con los procedimientos de llamada registrados.
w
Especifica el widget.

DESCRIPCIÓN

La función XtAddCallback añade el procedimiento de llamada especificado a la lista de llamadas del widget especificado.

La función XtAddCallbacks añade la lista de llamadas especificada a la lista de llamadas del widget especificado.

La función XtRemoveCallback elimina una llamada solo si tanto el procedimiento como los datos del cliente coinciden.

La función XtRemoveCallbacks elimina los procedimientos de llamada especificados de la lista de llamadas del widget especificado.

La función XtRemoveAllCallbacks elimina todos los procedimientos de llamada de la lista de llamadas del widget especificado.
