XtMalloc(3) FUNCIONES XT XtMalloc(3)

NOMBRE

XtMalloc, XtCalloc, XtRealloc, XtReallocArray, XtFree, XtNew, XtNewString - funciones de gestión de memoria

SINTAXIS

#include <X11/Intrinsic.h>

char *XtMalloc(Cardinal tamaño);

char *XtCalloc(Cardinal num, Cardinal tamaño);

char *XtRealloc(char *ptr, Cardinal tamaño);

void *XtReallocArray(void *ptr, Cardinal num, Cardinal tamaño);

void XtFree(char *ptr);

tipo *XtNew(tipo);

String XtNewString(String cadena);

Cardinal XtAsprintf(char **nueva_cadena, const char *formato, ...);

ARGUMENTOS

num
Especifica el número de elementos del array.
ptr
Especifica un puntero al almacenamiento antiguo o al bloque de almacenamiento que se va a liberar.
tamaño
Especifica el tamaño de un elemento del array (en bytes) o el número de bytes deseados.
cadena
Especifica una cadena declarada previamente.
tipo
Especifica un tipo de dato declarado previamente.
nueva_cadena
Especifica un puntero para escribir una cadena recién asignada.
formato
Especifica una cadena de formato según lo definido por sprintf(3c)

DESCRIPCIÓN

XtMalloc devuelve un puntero a un bloque de almacenamiento de al menos el tamaño especificado en bytes. Si no hay suficiente memoria para asignar el nuevo bloque, XtMalloc llama a XtErrorMsg.

La función XtCalloc asigna espacio para el número especificado de elementos de array del tamaño especificado e inicializa el espacio a cero. Si no hay suficiente memoria para asignar el nuevo bloque, XtCalloc llama a XtErrorMsg.

Las funciones XtRealloc y XtReallocArray cambian el tamaño de un bloque de almacenamiento (posiblemente moviéndolo). Luego, copian el contenido antiguo (o tanto como quepa) en el nuevo bloque y liberan el bloque antiguo. Si no hay suficiente memoria para asignar el nuevo bloque, o los cálculos para el tamaño del nuevo bloque causarían un desbordamiento entero, estas funciones llaman a XtErrorMsg. Si ptr es NULL, estas funciones asignan el nuevo almacenamiento sin copiar el contenido antiguo; es decir, simplemente llaman a XtMalloc.

La función XtFree devuelve almacenamiento y permite que se reutilice. Si ptr es NULL, XtFree regresa inmediatamente.

XtNew devuelve un puntero al almacenamiento asignado. Si no hay suficiente memoria para asignar el nuevo bloque, XtNew llama a XtErrorMsg. XtNew es una macro de conveniencia que llama a XtMalloc con los siguientes argumentos especificados:

((type *) XtMalloc((unsigned) sizeof(type))

XtNewString devuelve un puntero a una nueva cadena que es un duplicado de cadena. Si no hay suficiente memoria para asignar el nuevo bloque, o el argumento es NULL, XtNewString devuelve NULL. La memoria se puede liberar con XtFree.

La función XtAsprintf asigna espacio para una cadena lo suficientemente grande como para contener la cadena especificada por el patrón de formato de sprintf(3c) cuando se usa con los argumentos restantes, y la llena con los resultados formateados. La dirección de la cadena asignada se coloca en el puntero pasado como ret. Se devuelve la longitud de la cadena (sin incluir el byte nulo de terminación). Si no hay suficiente memoria para asignar el nuevo bloque, XtAsprintf llama a XtErrorMsg.
