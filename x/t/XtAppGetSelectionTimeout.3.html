XtAppGetSelectionTimeout(3) FUNCIONES XT XtAppGetSelectionTimeout(3)

NOMBRE

XtAppGetSelectionTimeout, XtAppSetSelectionTimeout - establecer y obtener valores de tiempo de espera de selección

SINTAXIS

#include <X11/Intrinsic.h>

unsigned long XtAppGetSelectionTimeout(XtAppContext app_context);

void XtAppSetSelectionTimeout(XtAppContext app_context, unsigned long timeout);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
timeout
Especifica el tiempo de espera de selección en milisegundos.

DESCRIPCIÓN

La función XtAppGetSelectionTimeout devuelve el valor actual del tiempo de espera de selección, en milisegundos. El tiempo de espera de selección es el tiempo dentro del cual las dos aplicaciones que se comunican deben responderse mutuamente. El valor inicial del tiempo de espera se establece mediante el recurso de aplicación selectionTimeout o, si no se especifica selectionTimeout, el valor predeterminado es de cinco segundos.

La función XtAppSetSelectionTimeout establece el mecanismo de tiempo de espera de selección de los Intrinsics. Tenga en cuenta que la mayoría de las aplicaciones no deberían establecer el tiempo de espera de selección.
