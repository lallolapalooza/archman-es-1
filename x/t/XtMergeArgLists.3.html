XtMergeArgLists(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtSetArg(3) FUNCIONES XT XtSetArg(3)

NOMBRE

XtSetArg, XtMergeArgLists - establecer y fusionar listas de argumentos

SINTAXIS

#include <X11/Intrinsic.h>

int XtSetArg(Arg arg, String name, XtArgVal value);

ArgList XtMergeArgLists(ArgList args1, Cardinal num_args1, ArgList args2, Cardinal num_args2);

ARGUMENTOS

arg
Especifica el par nombre-valor a establecer.
args1
Especifica la primera ArgList.
args2
Especifica la segunda ArgList.
num_args1
Especifica el número de argumentos en la primera lista de argumentos.
num_args2
Especifica el número de argumentos en la segunda lista de argumentos.
name
Especifica el nombre del recurso.
value
Especifica el valor del recurso si cabe en un XtArgVal o la dirección.

DESCRIPCIÓN

La función XtSetArg se utiliza normalmente de una manera muy estilizada para minimizar la probabilidad de cometer un error; por ejemplo:

Arg args[20];
int n;
n = 0;
XtSetArg(args[n], XtNheight, 100);      n++;
XtSetArg(args[n], XtNwidth, 200);       n++;
XtSetValues(widget, args, n);

Alternativamente, una aplicación puede declarar estáticamente la lista de argumentos y usar XtNumber:

static Args args[] = {
        {XtNheight, (XtArgVal) 100},
        {XtNwidth, (XtArgVal) 200},
};
XtSetValues(Widget, args, XtNumber(args));

Tenga en cuenta que no debe usar el postincremento o postdecremento dentro del primer argumento de XtSetArg. XtSetArg puede ser implementada como una macro que desreferencia el primer argumento dos veces.

La función XtMergeArgLists asigna suficiente espacio para almacenar las estructuras ArgList combinadas y las copia en él. Tenga en cuenta que no comprueba si hay entradas duplicadas. Cuando ya no se necesita, libere el espacio devuelto usando XtFree.
