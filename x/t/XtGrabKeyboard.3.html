XtGrabKeyboard(3)

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGrabKey(3) FUNCIONES XT XtGrabKey(3)

NOMBRE

XtGrabKey, XtUngrabKey, XtGrabKeyboard, XtUngrabKeyboard, XtGrabButton, XtUngrabButton, XtGrabPointer, XtUngrabPointer - gestionar agarres (grabs)

SINTAXIS

#include <X11/Intrinsic.h>

void XtGrabKey(Widget widget, KeyCode keycode, Modifiers modifiers, Boolean owner_events, int pointer_mode, int keyboard_mode);

void XtUngrabKey(Widget widget, KeyCode keycode, Modifiers modifiers);

int XtGrabKeyboard(Widget widget, Boolean owner_events, int pointer_mode, int keyboard_mode, Time time);

void XtUngrabKeyboard(Widget widget, Time time);

void XtGrabButton(Widget widget, int button, Modifiers modifiers, Boolean owner_events, unsigned int event_mask, int pointer_mode, int keyboard_mode, Window confine_to, Cursor cursor);

void XtUngrabButton(Widget widget, unsigned button, Modifiers modifiers);

int XtGrabPointer(Widget widget, Boolean owner_events, unsigned int event_mask, int pointer_mode, int keyboard_mode, Window confine_to, Cursor cursor, Time time);

void XtUngrabPointer(Widget widget, Time time);

ARGUMENTOS

widget
Especifica el widget en cuya ventana se producirá el agarre. Debe ser de la clase Core o una subclase de la misma.
keycode

modifiers

owner_events

pointer_mode

keyboard_mode

time

button

confine_to

cursor
Especifica argumentos para la llamada asociada a la función Xlib.

DESCRIPCIÓN

XtGrabKey llama a XGrabKey especificando la ventana del widget como la ventana de agarre si el widget está realizado. Los argumentos restantes son exactamente los de XGrabKey. Si el widget no está realizado, o se deja de realizar posteriormente, la llamada a XGrabKey se realizará (de nuevo) cuando el widget se realice y su ventana se mapee. En el futuro, si se llama a XtDispatchEvent con un evento KeyPress que coincida con el keycode y modificadores especificados (que pueden ser AnyKey o AnyModifier, respectivamente) para la ventana del widget, los Intrinsics llamarán a XtUngrabKeyboard con la marca de tiempo del evento KeyPress si se cumple alguna de las siguientes condiciones:

  • Existe una cascada modal y el widget no está en el subconjunto activo de la cascada y el teclado no fue previamente agarrado, o
  • XFilterEvent devuelve True.

XtUngrabKey llama a XUngrabKey especificando la ventana del widget como la ventana de liberación de agarre si el widget está realizado. Los argumentos restantes son exactamente los de XUngrabKey. Si el widget no está realizado, XtUngrabKey elimina una solicitud diferida de XtGrabKey, si la hay, para el widget, keycode y modificadores especificados.

Si el widget especificado está realizado, XtGrabKeyboard llama a XGrabKeyboard especificando la ventana del widget como la ventana de agarre. Los argumentos restantes y el valor de retorno son exactamente los de XGrabKeyboard. Si el widget no está realizado, XtGrabKeyboard devuelve inmediatamente GrabNotViewable. Ninguna liberación posterior de agarre está implícita por XtGrabKeyboard.

XtUngrabKeyboard llama a XUngrabKeyboard con la marca de tiempo especificada.

XtGrabButton llama a XGrabButton especificando la ventana del widget como la ventana de agarre si el widget está realizado. Los argumentos restantes son exactamente los de XGrabButton. Si el widget no está realizado, o se deja de realizar posteriormente, la llamada a XGrabButton se realizará (de nuevo) cuando el widget se realice y su ventana se mapee. En el futuro, si se llama a XtDispatchEvent con un evento ButtonPress que coincida con el botón y modificadores especificados (que pueden ser AnyButton o AnyModifier, respectivamente) para la ventana del widget, los Intrinsics llamarán a XtUngrabPointer con la marca de tiempo del evento ButtonPress si se cumple alguna de las siguientes condiciones:

  • Existe una cascada modal y el widget no está en el subconjunto activo de la cascada y el puntero no fue previamente agarrado, o
  • XFilterEvent devuelve True.

XtUngrabButton llama a XUngrabButton especificando la ventana del widget como la ventana de liberación de agarre si el widget está realizado. Los argumentos restantes son exactamente los de XUngrabButton. Si el widget no está realizado, XtUngrabButton elimina una solicitud diferida de XtGrabButton, si la hay, para el widget, botón y modificadores especificados.

XtGrabPointer llama a XGrabPointer especificando la ventana del widget como la ventana de agarre. Los argumentos restantes y el valor de retorno son exactamente los de XGrabPointer. Si el widget no está realizado, XtGrabPointer devuelve inmediatamente GrabNotViewable. Ninguna liberación posterior de agarre está implícita por XtGrabPointer.

XtUngrabPointer llama a XUngrabPointer con la marca de tiempo especificada.
