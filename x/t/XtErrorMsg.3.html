Paquete: libxt

XtErrorMsg(3) Funciones de compatibilidad XT XtErrorMsg(3)

NOMBRE

XtErrorMsg, XtSetErrorMsgHandler, XtWarningMsg, XtSetWarningMsgHandler - manejadores de errores de alto nivel

SINTAXIS

#include <X11/Intrinsic.h>

_X_NORETURN void XtErrorMsg(const char *nombre, const char *tipo, const char *clase, const char *mensajeDefault, String *parametros, Cardinal *num_parametros);

void XtSetErrorMsgHandler(_X_NORETURN XtErrorMsgHandler manejador_msg);

void XtSetWarningMsgHandler(XtErrorMsgHandler manejador_msg);

void XtWarningMsg(const char *nombre, const char *tipo, const char *clase, const char *mensajeDefault, String *parametros, Cardinal *num_parametros);

ARGUMENTOS

clase
Especifica la clase de recurso del mensaje de error.
mensajeDefault
Especifica el mensaje predeterminado a usar.
nombre
Especifica el tipo general de error.
tipo
Especifica el nombre detallado del error.
manejador_msg
Especifica el nuevo procedimiento de error fatal, que no debe devolver, o el procedimiento de error no fatal, que normalmente devuelve.
num_parametros
Especifica el número de valores en la lista de parámetros.
parametros
Especifica un puntero a una lista de valores que se almacenarán en el mensaje.

DESCRIPCIÓN

La función XtErrorMsg ha sido reemplazada por XtAppErrorMsg.

La función XtSetErrorMsgHandler ha sido reemplazada por XtAppSetErrorMsgHandler.

La función XtSetWarningMsgHandler ha sido reemplazada por XtAppSetWarningMsgHandler.

La función XtWarningMsg ha sido reemplazada por XtAppWarningMsg
