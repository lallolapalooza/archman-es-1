XtAppGetErrorDatabaseText(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppGetErrorDatabase(3) FUNCIONES XT XtAppGetErrorDatabase(3)

NOMBRE

XtAppGetErrorDatabase, XtAppGetErrorDatabaseText - obtener la base de datos de errores

SINTAXIS

#include <X11/Intrinsic.h>

XrmDatabase *XtAppGetErrorDatabase(XtAppContext app_context);

void XtAppGetErrorDatabaseText(XtAppContext app_context, const char *name, const char *type, const char *class, const char *defaultMsg, char *buffer_return, int nbytes, XrmDatabase database);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
buffer_return
Especifica el búfer en el que se va a devolver el mensaje de error.
class
Especifica la clase de recurso del mensaje de error.
database
Especifica el nombre de la base de datos alternativa que se va a utilizar o NULL si se va a utilizar la base de datos de la aplicación.
defaultMsg
Especifica el mensaje predeterminado a utilizar.
name

type
Especifica el nombre y el tipo que se concatenan para formar el nombre del recurso del mensaje de error.
nbytes
Especifica el tamaño del búfer en bytes.

DESCRIPCIÓN

La función XtAppGetErrorDatabase devuelve la dirección de la base de datos de errores. Las Intrínsec hacen una vinculación perezosa de la base de datos de errores y no fusionan el archivo de la base de datos hasta la primera llamada a XtAppGetErrorDatbaseText.

La función XtAppGetErrorDatabaseText devuelve el mensaje apropiado de la base de datos de errores o devuelve el mensaje predeterminado especificado si no se encuentra ninguno en la base de datos de errores.
