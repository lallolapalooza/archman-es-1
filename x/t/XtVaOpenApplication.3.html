XtOpenApplication(3) FUNCIONES XT XtOpenApplication(3)

NOMBRE

XtOpenApplication, XtVaOpenApplication - inicializar, abrir o cerrar una pantalla

SINTAXIS

#include <X11/Intrinsic.h>

Widget XtOpenApplication(XtAppContext *app_context_return, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, WidgetClass widget_class, ArgList args, Cardinal num_args);

Widget XtVaOpenApplication(XtAppContext *app_context_return, const char *application_class, XrmOptionDescRec *options, Cardinal num_options, int *argc_in_out, char **argv_in_out, String *fallback_resources, WidgetClass widget_class, ...);

ARGUMENTOS

app_context_return
Especifica el contexto de la aplicación.
application_class
Especifica el nombre de clase de esta aplicación, que usualmente es el nombre genérico para todas las instancias de esta aplicación.
options
Especifica cómo analizar la línea de comandos para cualquier recurso específico de la aplicación. El argumento de opciones se pasa como parámetro a XrmParseCommand. Para más información, ver Xlib - Interfaz del Lenguaje C de X.
num_options
Especifica el número de entradas en la lista de opciones.
argc_in_out
Especifica un puntero al número de parámetros de la línea de comandos.
argv_in_out
Especifica los parámetros de la línea de comandos.
fallback_resources
Especifica valores de recursos a ser usados si el archivo de recursos de la clase de la aplicación no puede ser abierto o leído, o NULL.
widget_class
Especifica la clase del widget a ser creado.
args
Especifica la lista de argumentos para sobrescribir cualquier otra especificación de recurso para el widget de shell creado.
num_args
Especifica el número de entradas en la lista de argumentos.
...
Especifica la lista de argumentos variables para sobrescribir cualquier otra especificación de recurso para el widget de shell creado.

DESCRIPCIÓN

La función XtOpenApplication llama a XtToolkitInitialize seguido por XtCreateApplicationContext, luego llama a XtOpenDisplay con display_string NULL y application_name NULL, y finalmente llama a XtAppCreateShell con application_name NULL, la widget_class especificada, y los args y num_args especificados, y devuelve el shell creado. El argc y argv modificados devueltos por XtDisplayInitialize se devuelven en argc_in_out y argv_in_out. Si app_context_return no es NULL, el contexto de aplicación creado también se devuelve. Si la pantalla especificada por la línea de comandos no puede ser abierta, se emite un mensaje de error y XtOpenApplication termina la aplicación. Si fallback_resources no es NULL, XtAppSetFallbackResources es llamado con el valor antes de llamar a XtOpenDisplay.

XtAppInitialize y XtVaAppInitialize han sido reemplazados por XtOpenApplication y XtVaOpenApplication respectivamente.
