XtUnmapWidget(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtMapWidget(3) FUNCIONES XT XtMapWidget(3)

NOMBRE

XtMapWidget, XtSetMappedWhenManaged, XtUnmapWidget - mapear y desmapear widgets

SINTAXIS

#include <X11/Intrinsic.h>

void XtMapWidget(Widget w);

void XtSetMappedWhenManaged(Widget w, Boolean map_when_managed);

void XtUnmapWidget(Widget w);

ARGUMENTOS

map_when_managed
Especifica un valor booleano que indica el nuevo valor del campo map_when_managed.
w
Especifica el widget.

DESCRIPCIÓN

Si el widget está realizado y gestionado y si el nuevo valor de map_when_managed es True, XtSetMappedWhenManaged mapea la ventana. Si el widget está realizado y gestionado y si el nuevo valor de map_when_managed es False, desmapea la ventana. XtSetMappedWhenManaged es una función de conveniencia que es equivalente (pero ligeramente más rápida que) llamar a XtSetValues y establecer el nuevo valor para el recurso mappedWhenManaged. Como alternativa a usar XtSetMappedWhenManaged para controlar el mapeo, un cliente puede establecer mapped_when_managed a False y usar XtMapWidget y XtUnmapWidget explícitamente.
