XtAppSetFallbackResources(3) FUNCIONES XT XtAppSetFallbackResources(3)

NOMBRE

XtAppSetFallbackResources - establecer recursos de reserva

SINTAXIS

#include <X11/Intrinsic.h>

void XtAppSetFallbackResources(XtAppContext app_context, String* specification_list);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
specification_list
Especifica una lista terminada en NULL de especificaciones de recursos para precargar la base de datos, o NULL.

DESCRIPCIÓN

Cada entrada en specification_list apunta a una cadena en el formato XrmPutLineResource. después de una llamada a XtAppSetFallbackResources, cuando se está creando una base de datos de recursos para una pantalla particular y las Intrínsecas no pueden encontrar o leer un archivo de recursos de clase específico de la aplicación, y si specification_list no es NULL, la especificación de recursos en specification_list se fusionará en la base de datos de recursos de la pantalla en lugar del archivo de recursos de clase específico de la aplicación. XtAppSetFallbackResources no está obligado a copiar specification_list; el llamante debe asegurarse de que el contenido de la lista y las cadenas a las que apunta la lista permanezcan válidas hasta que todas las pantallas se inicialicen o hasta que se vuelva a llamar a XtAppSetFallbackResources. El valor NULL para specification_list elimina cualquier especificación de recursos de reserva anterior para el contexto de la aplicación. El uso previsto para los recursos de reserva es proporcionar un número mínimo de recursos que harán que la aplicación sea utilizable (o al menos que termine con mensajes de diagnóstico útiles) cuando exista algún problema para encontrar y cargar el archivo de valores predeterminados de la aplicación.
