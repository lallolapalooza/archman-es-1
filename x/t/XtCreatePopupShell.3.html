XtCreatePopupShell(3) FUNCIONES XT XtCreatePopupShell(3)

NOMBRE

XtCreatePopupShell, XtVaCreatePopupShell - crear un shell emergente

SINTAXIS

#include <X11/Intrinsic.h>

Widget XtCreatePopupShell(const char *nombre, WidgetClass clase_widget, Widget padre, ArgList args, Cardinal num_args);

Widget XtVaCreatePopupShell(const char *nombre, WidgetClass clase_widget, Widget padre, ...);

ARGUMENTOS

args
Especifica la lista de argumentos para sobrescribir los valores predeterminados de los recursos.
nombre
Especifica el nombre de texto para el widget de shell creado.
num_args
Especifica el número de argumentos en la lista de argumentos.
padre
Especifica el widget padre.
clase_widget
Especifica el puntero de clase del widget para el widget de shell creado.
...
Especifica la lista de argumentos variables para sobrescribir los valores predeterminados de los recursos.

DESCRIPCIÓN

La función XtCreatePopupShell asegura que la clase especificada sea una subclase de Shell y, en lugar de usar insert_child para adjuntar el widget a la lista de hijos del padre, adjunta el shell directamente a la lista de emergentes del padre.

Un emergente activado por resorte invocado desde una tabla de traducción ya debe existir en el momento en que se invoca la traducción, por lo que el gestor de traducciones puede encontrar el shell por nombre. Los emergentes invocados de otras maneras se pueden crear "sobre la marcha" cuando el emergente sea realmente necesario. Esta creación retrasada del shell es particularmente útil cuando se activan emergentes en número indeterminado. Puede comprobar si existe un shell apropiado no utilizado (es decir, no activado actualmente) y crear un nuevo shell si es necesario.
