XtAddEventHandler(3) FUNCIONES DE XT XtAddEventHandler(3)

NOMBRE

XtAddEventHandler, XtAddRawEventHandler, XtRemoveEventHandler, XtRemoveRawEventHandler, XtInsertEventHandler, XtInsertRawEventHandler - añadir y eliminar manejadores de eventos

SINTAXIS

#include <X11/Intrinsic.h>

void XtAddEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtAddRawEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtRemoveEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtRemoveRawEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data);

void XtInsertEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data, XtListPosition position);

void XtInsertRawEventHandler(Widget w, EventMask event_mask, Boolean nonmaskable, XtEventHandler proc, XtPointer client_data, XtListPosition position);

typedef enum { XtListHead, XtListTail } XtListPosition;

ARGUMENTOS

client_data
Especifica datos adicionales que se pasarán al manejador de eventos del cliente.
event_mask
Especifica la máscara de eventos para la cual se llamará o anulará el registro de este procedimiento.
nonmaskable
Especifica un valor booleano que indica si este procedimiento debe ser llamado o eliminado en los eventos no enmascarables ( GraphicsExpose, NoExpose, SelectionClear, SelectionRequest, SelectionNotify, ClientMessage y MappingNotify).
proc
Especifica el procedimiento que se va a añadir o eliminar.
w
Especifica el widget para el que se está registrando este manejador de eventos.
position
Especifica cuándo se llamará al manejador de eventos en relación con otros manejadores registrados previamente.

DESCRIPCIÓN

La función XtAddEventHandler registra un procedimiento con el mecanismo de distribución que se llamará cuando ocurra un evento que coincida con la máscara en el widget especificado. Si el procedimiento ya está registrado con los mismos datos del cliente, la máscara especificada se combinará con la máscara existente. Si el widget está realizado, XtAddEventHandler llama a XSelectInput, si es necesario.

La función XtAddRawEventHandler es similar a XtAddEventHandler, excepto que no afecta a la máscara del widget y nunca provoca una llamada a XSelectInput para sus eventos. Tenga en cuenta que el widget puede tener ya configurados esos bits de máscara debido a otros manejadores de eventos no directos registrados en él.

La función XtRemoveRawEventHandler detiene el que el procedimiento especificado reciba los eventos especificados. Como el procedimiento es un manejador de eventos directo, esto no afecta a la máscara del widget y nunca provoca una llamada a XSelectInput.

XtInsertEventHandler es idéntico a XtAddEventHandler con el argumento adicional position. Si position es XtListHead, el manejador de eventos se registra para ser llamado antes que cualquier otro manejador de eventos previamente registrado para el mismo widget. Si position es XtListTail, el manejador de eventos se registra para ser llamado después de cualquier manejador de eventos previamente registrado. Si el procedimiento ya está registrado con el mismo valor de client_data, la máscara especificada aumenta la máscara existente y el procedimiento se reposiciona en la lista.

XtInsertRawEventHandler es similar a XtInsertEventHandler, excepto que no modifica la máscara de eventos del widget y nunca provoca una llamada a XSelectInput para los eventos especificados. Si el procedimiento ya está registrado con el mismo valor de client_data, la máscara especificada aumenta la máscara existente y el procedimiento se reposiciona en la lista.
