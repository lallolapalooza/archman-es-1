DESCRIPCIÓN

Esta extensión es un conjunto mínimo de extensiones de cliente y servidor requeridas para probar completamente el servidor X11 sin intervención del usuario. Esta extensión no está destinada a soportar el registro y la reproducción general de acciones del usuario.

Las funciones proporcionadas por esta extensión se dividen en dos grupos:

Operaciones de Cliente

Estas rutinas manipulan el comportamiento del lado del cliente, de otro modo oculto. La implementación real dependerá de los detalles del enlace de idioma específico y del grado de almacenamiento en búfer de solicitudes, caché de GContext, etc., que se proporcione. En el enlace C, se proporcionan rutinas para acceder a los detalles internos de dos estructuras de datos opacas — GCs y Visuals — y para descartar cualquier solicitud pendiente dentro del búfer de salida de una conexión. Se puede esperar que los detalles exactos difieran para otros enlaces de idioma.

Solicitudes del Servidor

La primera de estas solicitudes es similar a la proporcionada en la mayoría de las extensiones: permite a un cliente especificar un número de versión principal y secundaria al servidor, y al servidor responder con las versiones principal y secundaria propias. Las dos solicitudes restantes permiten lo siguiente:
•Acceso a un recurso del servidor, de otro modo de *solo escritura*: el cursor asociado con una ventana dada
•Quizás lo más importante, la síntesis limitada de eventos de dispositivos de entrada, casi como si un usuario cooperativo hubiera movido el dispositivo señalador o presionado una tecla o botón.

Todas las funciones y procedimientos de la extensión XTEST, y todas las constantes y macros manifiestas, comenzarán con la cadena *XTest*. Todas las operaciones se clasifican como servidor/cliente (Servidor) o solo cliente (Cliente).

XTestQueryExtension devuelve True si el display especificado soporta la extensión XTEST, de lo contrario False. Si la extensión es soportada, *event_base se establecería en el número de evento para el primer evento de esta extensión y *error_base se establecería en el número de error para el primer error de esta extensión. Como no se definen errores ni eventos para esta versión de la extensión, los valores devueltos aquí no están definidos (ni son útiles). Si la extensión es soportada, *major_version y *minor_version se establecen en los números de versión principal y secundaria de la extensión soportada por el display. De lo contrario, ninguno de los argumentos se establece.

Si la extensión es soportada, XTestCompareCursorWithWindow realiza una comparación del cursor cuyo ID es especificado por cursor (que puede ser None) con el cursor de la ventana especificada por window, devolviendo True si son iguales y False en caso contrario. Si la extensión no es soportada, entonces la solicitud se ignora y se devuelve cero.

Si la extensión es soportada, XTestCompareCurrentCursorWithWindow realiza una comparación del cursor actual con el cursor de la ventana especificada, devolviendo True si son iguales y False en caso contrario. Si la extensión no es soportada, entonces la solicitud se ignora y se devuelve cero.

Si la extensión es soportada, XTestFakeKeyEvent solicita al servidor que simule una KeyPress (si is_press es True) o una KeyRelease (si is_press es False) de la tecla con el keycode especificado; de lo contrario, la solicitud se ignora.

Si la extensión es soportada, el evento simulado no se procesará hasta que transcurran delay milisegundos después de recibir la solicitud (si delay es CurrentTime, esto se interpreta como ningún retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y el procesamiento posterior del evento simulado se haya completado.

Si la extensión es soportada, XTestFakeButtonEvent solicita al servidor que simule una ButtonPress (si is_press es True) o una ButtonRelease (si is_press es False) del botón lógico numerado por el botón especificado; de lo contrario, la solicitud se ignora.

Si la extensión es soportada, el evento simulado no se procesará hasta que transcurran delay milisegundos después de recibir la solicitud (si delay es CurrentTime, esto se interpreta como ningún retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y el procesamiento posterior del evento simulado se haya completado.

Si la extensión es soportada, XTestFakeMotionEvent solicita al servidor que simule un movimiento del puntero a la posición especificada (x, y) en la ventana raíz de screen_number; de lo contrario, la solicitud se ignora. Si screen_number es -1, se usa la pantalla actual (en la que se encuentra el puntero).

Si la extensión es soportada, el evento simulado no se procesará hasta que transcurran delay milisegundos después de recibir la solicitud (si delay es CurrentTime, esto se interpreta como ningún retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y el procesamiento posterior del evento simulado se haya completado.

Si la extensión es soportada, XTestFakeRelativeMotionEvent solicita al servidor que simule un movimiento del puntero por los desfases especificados (x, y) en relación con la posición actual del puntero en screen_number; de lo contrario, la solicitud se ignora. Si screen_number es -1, se usa la pantalla actual (en la que se encuentra el puntero).

Si la extensión es soportada, el evento simulado no se procesará hasta que transcurran delay milisegundos después de recibir la solicitud (si delay es CurrentTime, esto se interpreta como ningún retraso). Ninguna otra solicitud de este cliente se procesará hasta que este retraso, si lo hay, haya expirado y el procesamiento posterior del evento simulado se haya completado.

Si impervious es True, entonces el cliente en ejecución se vuelve impermeable a las capturas del servidor. Si impervious es False, entonces el cliente en ejecución vuelve al estado normal de ser susceptible a las capturas del servidor.

XTestSetGContextOfGC establece el GContext dentro del tipo de dato opaco referenciado por gc al especificado por gid.

XTestSetVisualIDOfVisual establece el VisualID dentro del tipo de dato opaco referenciado por visual al especificado por visualid.

XTestDiscard descarta cualquier solicitud dentro del búfer de salida para el display especificado. Devuelve True si se descartó alguna solicitud; de lo contrario, devuelve False.

VALORES DE RETORNO

Todas las rutinas que tengan el tipo de retorno Status devolverán un valor distinto de cero para el éxito y cero para el fallo. Incluso si la extensión XTEST es compatible, el servidor puede retirar tales instalaciones de forma arbitraria; en cuyo caso, posteriormente devolverán cero.
