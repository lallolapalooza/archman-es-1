XtAppSetErrorHandler(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAppError(3) FUNCIONES XT XtAppError(3)

NOMBRE

XtAppError, XtAppSetErrorHandler, XtAppSetWarningHandler, XtAppWarning - manejadores de errores de bajo nivel

SINTAXIS

#include <X11/Intrinsic.h>

_X_NORETURN void XtAppError(XtAppContext app_context, const char *message);

XtErrorHandler XtAppSetErrorHandler(XtAppContext app_context, _X_NORETURN XtErrorHandler handler);

XtErrorHandler XtAppSetWarningHandler(XtAppContext app_context, XtErrorHandler handler);

void XtAppWarning(XtAppContext app_context, const char *message);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
message
Especifica el mensaje de error no fatal que debe ser reportado.
handler
Especifica el nuevo procedimiento de error fatal, que no debería retornar, o el procedimiento de error no fatal, que usualmente retorna.
message
Especifica el mensaje que debe ser reportado.

DESCRIPCIÓN

La función XtAppError llama al procedimiento de error instalado y le pasa el mensaje especificado.

La función XtAppSetErrorHandler registra el procedimiento especificado, que es llamado cuando ocurre una condición de error fatal.

La función XtAppSetWarningHandler registra el procedimiento especificado, que es llamado cuando ocurre una condición de error no fatal.

La función XtAppWarning llama al procedimiento de error no fatal instalado y le pasa el mensaje especificado.

VER TAMBIÉN

XtAppGetErrorDatabase(3), XtAppErrorMsg(3)
