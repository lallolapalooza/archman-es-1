XtLastEventProcessed(3) FUNCIONES XT XtLastEventProcessed(3)

NOMBRE

XtLastEventProcessed, XtLastTimestampProcessed - último evento, última marca de tiempo procesada

SINTAXIS

#include <X11/Intrinsic.h>

XEvent* XtLastEventProcessed(Display* display);

Time XtLastTimestampProcessed(Display* display);

ARGUMENTOS

display
Especifica la conexión de pantalla abierta.

DESCRIPCIÓN

XtLastEventProcessed devuelve el último evento pasado a XtDispatchEvent para la pantalla especificada y NULL si no ha habido ningún evento. El cliente no debe modificar el contenido del evento devuelto.

XtLastTimestampProcessed devuelve la marca de tiempo del último evento KeyPress, KeyRelease, ButtonPress, ButtonRelease, MotionNotify, EnterNotify, LeaveNotify, PropertyNotify, o SelectionClear que se haya pasado a XtDispatchEvent para la pantalla especificada y cero si no ha habido dicho evento.
