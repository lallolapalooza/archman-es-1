XtNameToWidget(3) FUNCIONES XT XtNameToWidget(3)

NOMBRE

XtNameToWidget, XtWindowToWidget - traducción de cadenas a widgets o de widgets a ventanas

SINTAXIS

#include <X11/Intrinsic.h>

Widget XtNameToWidget(Widget referencia, const char *nombres);

Widget XtWindowToWidget(Display *display, Window ventana);

ARGUMENTOS

display
Especifica la pantalla en la que está definida la ventana.
nombres
Especifica el nombre completamente cualificado del widget deseado.
referencia
Especifica el widget desde el cual se debe iniciar la búsqueda.
ventana
Especifica la ventana para la que deseas el widget.

DESCRIPCIÓN

La función XtNameToWidget busca un widget cuyo nombre sea el primer componente de los nombres especificados y que sea un hijo emergente de referencia (o un hijo normal si referencia es una subclase de compositeWidgetClass). Luego, utiliza ese widget como la nueva referencia y repite la búsqueda después de eliminar el primer componente de los nombres especificados. Si no puede encontrar el widget especificado, XtNameToWidget devuelve NULL.

Tenga en cuenta que el argumento nombres contiene el nombre de un widget con respecto al widget de referencia especificado y puede contener más de un nombre de widget (separados por puntos) para widgets que no son hijos directos del widget de referencia especificado.

Si más de un hijo de la referencia coincide con el nombre, XtNameToWidget puede devolver cualquiera de los hijos. Las Intrínsecas no requieren que todos los hijos de un widget tengan nombres únicos. Si los nombres especificados contienen más de un componente y si más de un hijo coincide con el primer componente, XtNameToWidget puede devolver NULL si la rama única que sigue no contiene el widget nombrado. Es decir, XtNameToWidget no retrocede y sigue otras ramas coincidentes del árbol de widgets.

La función XtWindowToWidget traduce la ventana y el puntero de pantalla especificados al widget de instancia apropiado.
