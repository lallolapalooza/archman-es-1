XtUnrealizeWidget(3) FUNCIONES DE XT XtUnrealizeWidget(3)

NOMBRE

XtRealizeWidget, XtIsRealized, XtUnrealizeWidget - realizar y desrealizar widgets

SINTAXIS

#include <X11/Intrinsic.h>

void XtRealizeWidget(Widget w);

Boolean XtIsRealized(Widget w);

void XtUnrealizeWidget(Widget w);

ARGUMENTOS

w
Especifica el widget.

DESCRIPCIÓN

Si el widget ya está realizado, XtRealizeWidget simplemente devuelve. De lo contrario, realiza lo siguiente:

  • Vincula todos los nombres de acción en la tabla de traducción del widget a procedimientos (ver Sección 10.1.2).
  • Realiza una recorrido postorden del árbol de widgets con raíz en el widget especificado y llama al procedimiento change_managed de cada widget compuesto que tenga uno o más hijos gestionados.
  • Construye una estructura XSetWindowAttributes completada con información derivada de los campos del widget Core y llama al procedimiento realize para el widget, que agrega los atributos específicos del widget y crea la ventana X.
  • Si el widget no es una subclase de compositeWidgetClass, XtRealizeWidget devuelve; de lo contrario, continúa y realiza lo siguiente:
  • Desciende recursivamente a cada uno de los hijos gestionados del widget y llama a los procedimientos realize. Los widgets primitivos que instancian hijos son responsables de realizar esos hijos ellos mismos.
  • Mapea todas las ventanas de hijos gestionados que tienen mapped_when_managed en True. (Si un widget está gestionado pero mapped_when_managed es False, al widget se le asigna espacio visual pero no se muestra. A algunas personas parece gustarles esto para indicar ciertos estados).

Si el widget es un widget shell de nivel superior (es decir, no tiene padre), y mapped_when_managed es True, XtRealizeWidget mapea la ventana del widget.

La función XtIsRealized devuelve True si el widget se ha realizado, es decir, si el widget tiene un ID de ventana X distinto de cero.

Algunos procedimientos de widget (por ejemplo, set_values) podrían desear operar de manera diferente después de que el widget se haya realizado.

La función XtUnrealizeWidget destruye las ventanas de un widget existente y todos sus hijos (recursivamente hacia abajo en el árbol de widgets). Para recrear las ventanas en un momento posterior, llame a XtRealizeWidget nuevamente. Si el widget estaba gestionado, se desgestionará automáticamente antes de que se libere su ventana.
