XtGetSelectionValueIncremental(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtGetSelectionValueIncremental(3) FUNCIONES XT XtGetSelectionValueIncremental(3)

NOMBRE

XtGetSelectionValueIncremental, XtGetSelectionValuesIncremental - obtener valores de selección

SINTAXIS

#include <X11/Intrinsic.h>

void XtGetSelectionValueIncremental(Widget w, Atom selection, Atom target, XtSelectionCallbackProc callback, XtPointer client_data, Time time);

void XtGetSelectionValuesIncremental(Widget w, Atom selection, Atom *targets, int count, XtSelectionCallbackProc callback, XtPointer *client_data, Time time);

ARGUMENTOS

callback
Especifica el procedimiento de devolución de llamada que se llamará cuando se haya obtenido el valor de la selección.
client_data
Especifica el argumento que se pasará al procedimiento especificado cuando se llame.
client_data
Especifica los datos del cliente (uno para cada tipo de destino) que se pasan al procedimiento de devolución de llamada cuando se llama para ese destino.
count
Especifica la longitud de las listas de destinos y datos del cliente.
selection
Especifica la selección particular deseada (es decir, primaria o secundaria).
target
Especifica el tipo de información que se necesita sobre la selección.
target
Especifica los tipos de información que se necesitan sobre la selección.
time
Especifica la marca de tiempo que indica cuándo se desea el valor de la selección.
w
Especifica el widget que está realizando la solicitud.

DESCRIPCIÓN

La función XtGetSelectionValueIncremental es similar a XtGetSelectionValue, excepto que el procedimiento selection_callback se llamará repetidamente al entregar varios segmentos del valor de selección. El final del valor de selección se indica cuando se llama a selection_callback con un valor no NULL de longitud cero, que aún debe ser liberado por el cliente. Si la transferencia de la selección se aborta en medio de una transferencia (por ejemplo, debido a un tiempo de espera), se llamará al procedimiento selection_callback con un valor de tipo igual a la constante simbólica XT_CONVERT_FAIL para que el solicitante pueda desechar el valor de selección parcial que ha recopilado hasta ese momento. Al recibir XT_CONVERT_FAIL, el cliente solicitante debe determinar por sí mismo si una transferencia completada parcialmente es significativa o no.

La función XtGetSelectionValuesIncremental es similar a XtGetSelectionValueIncremental, excepto que toma una lista de tipos de destino y una lista de datos del cliente y obtiene el valor actual de la selección convertido a cada uno de los destinos. El efecto es como si cada destino se especificara en una llamada separada a XtGetSelectionValueIncremental. Se llama a la devolución de llamada una vez con los datos del cliente correspondientes para cada destino. XtGetSelectionValuesIncremental garantiza que todas las conversiones utilizarán el mismo valor de selección, ya que la propiedad de la selección no puede cambiar en medio de la lista, como ocurriría al llamar repetidamente a XtGetSelectionValueIncremental.
