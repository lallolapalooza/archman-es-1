XtResolvePathname(3) FUNCIONES DE XT XtResolvePathname(3)

NOMBRE

XtResolvePathname - busca un archivo usando sustituciones estándar

SINTAXIS

#include <X11/Intrinsic.h>

char * XtResolvePathname(Display *display, const char *type, const char *filename, const char *suffix, const char *path, Substitution substitutions, Cardinal num_substitutions, XtFilePredicate predicate);

ARGUMENTOS

display
Especifica la pantalla a usar para encontrar el idioma para las sustituciones de idioma.
type

filename

suffix
Especifica valores para sustituir en la ruta.
path
Especifica la lista de especificaciones de archivo, o NULL.
substitutions
Especifica una lista de sustituciones adicionales a realizar en la ruta, o NULL.
num_substitutions
Especifica el número de entradas en substitutions.
predicate
Especifica un procedimiento llamado para juzgar cada nombre de archivo potencial, o NULL.

DESCRIPCIÓN

Las sustituciones especificadas por XtResolvePathname se determinan a partir del valor de la cadena de idioma recuperada por XtDisplayInitialize para la pantalla especificada. Para establecer el idioma para todas las aplicaciones, especifique “*xnlLanguage: lang” en la base de datos de recursos. El formato y el contenido de la cadena de idioma dependen de la implementación. Una sintaxis sugerida es componer la cadena de idioma de tres partes: una parte de “idioma”, una parte de “territorio” y una parte de “codeset”. La manera en que se realiza esta composición depende de la implementación y las Intrinsics no hacen ninguna interpretación de las partes más que usarlas en sustituciones como se describe a continuación.

XtResolvePathname llama a XtFindFile con las siguientes sustituciones además de las pasadas por el llamador y devuelve el valor devuelto por XtFindFile:

%N
El valor del parámetro filename, o el nombre de clase de la aplicación si filename es NULL.
%T
El valor del parámetro type.
%S
El valor del parámetro suffix.
%L
La cadena de idioma asociada con la pantalla especificada.
%l
La parte del idioma de la cadena de idioma de la pantalla.
%t
La parte del territorio de la cadena de idioma de la pantalla.
%c
La parte del codeset de la cadena de idioma de la pantalla.
%C
La cadena de personalización recuperada de la base de datos de recursos asociada con display.
%D
El valor de la ruta predeterminada específica de la implementación.

Si se pasa una ruta a XtResolvePathname, se pasará a XtFindFile. Si el argumento path es NULL, el valor de la variable de entorno XFILESEARCHPATH se pasará a XtFindFile. Si XFILESEARCHPATH no está definido, se utilizará una ruta predeterminada específica de la implementación que contiene al menos 6 entradas. Estas entradas deben contener las siguientes sustituciones:

1.	%C, %N, %S, %T, %L	o	%C, %N, %S, %T, %l, %t, %c
2.	%C, %N, %S, %T, %l
3.	%C, %N, %S, %T
4.	%N, %S, %T, %L	o	%N, %S, %T, %l, %t, %c
5.	%N, %S, %T, %l
6.	%N, %S, %T

El orden de estas seis entradas dentro de la ruta debe ser el dado anteriormente. El orden y uso de las sustituciones dentro de una entrada dada dependen de la implementación. Si la ruta comienza con dos puntos, se le precederá %N%S. Si la ruta incluye dos dos puntos adyacentes, se insertará %N%S entre ellos.

El parámetro type está destinado a ser una categoría de archivos, que generalmente se traduce en un directorio en el nombre de la ruta. Los valores posibles podrían incluir “app-defaults”, “help” y “bitmap”.

El parámetro suffix está destinado a agregarse al nombre del archivo. Los valores posibles podrían incluir “.txt”, “.dat” y “.bm”.

Un valor sugerido para la ruta predeterminada en sistemas basados en POSIX es

/usr/lib/X11/%L/%T/%N%C%S:/usr/lib/X11/%l/%T/%N%C%S:\
/usr/lib/X11/%T/%N%C%S:/usr/lib/X11/%L/%T/%N%S:\
/usr/lib/X11/%l/%T/%N%S:/usr/lib/X11/%T/%N%S

Usando este ejemplo, si el usuario ha especificado un idioma, se utilizará como un subdirectorio de /usr/lib/X11 que se buscará para otros archivos. Si el archivo deseado no se encuentra allí, la búsqueda se intentará nuevamente usando solo la parte del idioma de la especificación. Si el archivo no está allí, se buscará en /usr/lib/X11. El parámetro type se usa como un subdirectorio del directorio de idioma o de /usr/lib/X11, y suffix se agrega al nombre del archivo.

La sustitución %D permite la adición de elementos de ruta a la ruta predeterminada específica de la implementación, típicamente para permitir que se busquen directorios adicionales sin evitar que se encuentren recursos en los directorios del sistema. Por ejemplo, un usuario que instala archivos de recursos en un directorio llamado “ourdir” podría establecer XFILESEARCHPATH a

%D:ourdir/%T/%N%C:ourdir/%T/%N

La cadena de personalización se obtiene consultando la base de datos de recursos actualmente asociada con la pantalla (la base de datos devuelta por XrmGetDatabase) para el recurso application_name.customization, clase application_class.Customization donde application_name y application_class son los valores devueltos por XtGetApplicationNameAndClass. Si no se especifica ningún valor en la base de datos, se utiliza la cadena vacía.

Es responsabilidad del llamador liberar la cadena devuelta usando XtFree cuando ya no sea necesaria.
