XtSetMultiClickTime(3) FUNCIONES XT XtSetMultiClickTime(3)

NOMBRE

XtSetMultiClickTime, XtGetMultiClickTime - establecer y obtener tiempos de múltiples clics

SINTAXIS

#include <X11/Intrinsic.h>

void XtSetMultiClickTime(Display* display, int time);

int XtGetMultiClickTime(Display* display);

ARGUMENTOS

display
Especifica la conexión de pantalla.
time
Especifica el tiempo de múltiples clics en milisegundos.

DESCRIPCIÓN

XtSetMultiClickTime establece el intervalo de tiempo utilizado por el gestor de traducciones para determinar cuándo se interpretan múltiples eventos como un evento repetido.

XtGetMultiClickTime devuelve el tiempo en milisegundos que el gestor de traducciones utiliza para determinar si múltiples eventos deben ser interpretados como un evento repetido a efectos de coincidencia de una entrada de traducción que contenga un recuento de repetición.
