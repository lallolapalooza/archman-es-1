XtConvertAndStore(3) FUNCIONES XT XtConvertAndStore(3)

NOMBRE

XtConvertAndStore, XtCallConverter - invocar conversores de recursos

SINTAXIS

#include <X11/Intrinsic.h>

Boolean XtConvertAndStore(Widget widget, const char *from_type, XrmValuePtr from, const char *to_type, XrmValuePtr to_in_out);

Boolean XtCallConverter(Display* dpy, XtTypeConverter converter, XrmValuePtr args, Cardinal num_args, XrmValuePtr from, XrmValuePtr to_in_out, XtCacheRef* cache_ref_return);

ARGUMENTOS

args
Especifica la lista de argumentos que contiene los argumentos adicionales necesarios para realizar la conversión, o NULL.
converter
Especifica el procedimiento de conversión que se va a llamar.
from
Especifica el valor a convertir.
from_type
Especifica el tipo de origen.
num_args
Especifica el número de argumentos adicionales (a menudo cero).
to_type
Especifica el tipo de destino.
to_in_out
Devuelve el valor convertido.
widget
Especifica el widget a utilizar para argumentos adicionales, si los hay, y la lista de callbacks de destrucción.
dpy
Especifica la pantalla con la que se debe asociar la conversión.

DESCRIPCIÓN

La función XtConvertAndStore busca el conversor de tipo registrado para convertir from_type a to_type, calcula los argumentos adicionales necesarios y luego llama a XtCallConverter. (o XtDirectConvert si se registró un conversor de estilo antiguo con XtAddConverter o XtAppAddConverter) con los argumentos from y to_in_out.

La función XtCallConverter busca el conversor de tipo especificado en el contexto de la aplicación asociado a la pantalla y, si el conversor no fue registrado o se registró con el tipo de caché XtCacheAll o XtCacheByDisplay, busca en la caché de conversión para ver si este procedimiento de conversión se ha llamado con los argumentos de conversión especificados. Si es así, verifica el estado de éxito de la llamada anterior y, si la conversión falló, XtCallConverter devuelve False inmediatamente; de lo contrario, verifica el tamaño especificado en el argumento to y, si es mayor o igual al tamaño almacenado en la caché, copia la información almacenada en la caché en la ubicación especificada por to->addr, almacena el tamaño de la caché en to->size y devuelve True. Si el tamaño especificado en el argumento to es menor que el tamaño almacenado en la caché, XtCallConverter copia el tamaño de la caché en to->size y devuelve False. Si el conversor se registró con el tipo de caché XtCacheNone o no se encontró ningún valor en la caché de conversión, XtCallConverter llama al conversor y, si no se registró con el tipo de caché XtCacheNone, introduce el resultado en la caché. Luego, XtCallConverter devuelve lo que el conversor devolvió.

El campo cache_ref_return especifica un almacenamiento asignado por el llamador donde se almacenará un valor opaco. Si el conversor de tipo se ha registrado con el modificador XtCacheRefCount y si el valor devuelto en cache_ref_return no es NULL, la llamada debe almacenar el valor de cache_ref_return para decrementar el contador de referencias cuando el valor convertido ya no sea necesario. El argumento cache_ref_return debe ser NULL si el llamador no está dispuesto o no puede almacenar el valor.
