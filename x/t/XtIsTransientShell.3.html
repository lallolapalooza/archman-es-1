NOMBRE

ARGUMENTOS

w
Especifica el widget.
widget_class
Especifica la clase del widget.
message
Especifica el mensaje que se va a usar.

DESCRIPCIÓN

La función XtClass devuelve un puntero a la estructura de clase del widget.

La función XtSuperclass devuelve un puntero a la estructura de clase superclase del widget.

La función XtIsSubclass devuelve True si la clase del widget especificado es igual o es una subclase de la clase especificada. La clase del widget puede ser cualquier número de subclases hacia abajo en la cadena y no necesita ser una subclase inmediata de la clase especificada. Los widgets compuestos que necesitan restringir la clase de los elementos que contienen pueden usar XtIsSubclass para averiguar si un widget pertenece a la clase deseada de objetos.

La macro XtCheckSubclass determina si la clase del widget especificado es igual o es una subclase de la clase de widget especificada. El widget puede ser cualquier número de subclases hacia abajo en la cadena y no necesita ser una subclase inmediata de la clase de widget especificada. Si el widget especificado no es una subclase, XtCheckSubclass construye un mensaje de error a partir del mensaje proporcionado, la clase real del widget y la clase esperada, y llama a XtErrorMsg. XtCheckSubclass debe usarse en el punto de entrada de las rutinas exportadas para garantizar que el cliente haya pasado una clase de widget válida para la operación exportada.

XtCheckSubclass solo se ejecuta cuando el widget ha sido compilado con el símbolo del compilador DEBUG definido; de lo contrario, se define como una cadena vacía y no genera código.

Para probar si un widget dado pertenece a una subclase de una clase definida por Intrinsics, Intrinsics define macros o funciones equivalentes a XtIsSubclass para cada una de las clases integradas. Estos procedimientos son XtIsObject, XtIsRectObj, XtIsWidget, XtIsComposite, XtIsConstraint, XtIsShell, XtIsOverrideShell, XtIsWMShell, XtIsVendorShell, XtIsTransientShell, XtIsTopLevelShell, XtIsApplicationShell y XtIsSessionShell.
