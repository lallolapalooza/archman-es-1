XtSetSelectionParameters(3)

XtSetSelectionParameters(3) FUNCIONES XT XtSetSelectionParameters(3)

NOMBRE

XtSetSelectionParameters - especificar parámetros de destino para una solicitud de selección con un único destino

SINTAXIS

#include <X11/Intrinsic.h>

void XtSetSelectionParameters(Widget requestor, Atom selection, Atom type, XtPointer value, unsigned long length, int format);

ARGUMENTOS

requestor
Especifica el widget que realiza la solicitud. Debe ser de la clase Core o cualquier subclase de la misma.
selection
Especifica el átomo que nombra la selección.
type
Especifica el tipo de la propiedad en la que se pasarán los parámetros.
value
Especifica un puntero a los parámetros.
length
Especifica el número de elementos que contienen datos en value, cada elemento de un tamaño indicado por format.
format
Especifica el tamaño en bits de los datos en los elementos de value.

DESCRIPCIÓN

Los parámetros especificados se copiarán y almacenarán en una nueva propiedad del tipo y formato especificados en la ventana del solicitante. Para iniciar una solicitud de selección con un destino y estos parámetros, una llamada posterior a XtGetSelectionValue o a XtGetSelectionValueIncremental especificando el mismo widget solicitante y átomo de selección generará una solicitud ConvertSelection que hará referencia a la propiedad que contiene los parámetros. Si XtSetSelectionParameters se llama más de una vez con el mismo widget y selección sin una llamada para especificar una solicitud, los parámetros especificados más recientemente se utilizan en la solicitud posterior.

Los valores posibles de format pueden ser 8, 16 o 32. Si el format es 8, se asume que los elementos de value son sizeof(char); si es 16, sizeof(short); si es 32, sizeof(long).

Para generar una solicitud de destino MULTIPLE con parámetros para cualquiera de los destinos múltiples de la solicitud de selección, preceda llamadas individuales a XtGetSelectionValue y XtGetSelectionValueIncremental con llamadas individuales correspondientes a XtSetSelectionParameters, y encierre todas estas dentro de XtCreateSelectionRequest y XtSendSelectionRequest. XtGetSelectionValues y XtGetSelectionValuesIncremental no se pueden usar para realizar solicitudes de selección con destinos parametrizados.
