XtPopup(3) FUNCIONES XT XtPopup(3)

NOMBRE

XtPopup, XtPopupSpringLoaded, XtCallbackNone, XtCallbackNonexclusive, XtCallbackExclusive - mostrar una ventana emergente

SINTAXIS

#include <X11/Intrinsic.h>

void XtPopup(Widget popup_shell, XtGrabKind grab_kind);

void XtPopupSpringLoaded(Widget popup_shell);

void XtCallbackNone(Widget w, XtPointer client_data, XtPointer call_data);

void XtCallbackNonexclusive(Widget w, XtPointer client_data, XtPointer call_data);

void XtCallbackExclusive(Widget w, XtPointer client_data, XtPointer call_data);

ACCIONES

void XtMenuPopup(String shell_name);

ARGUMENTOS

call_data
Especifica los datos de la llamada de retorno, que no son utilizados por este procedimiento.
client_data
Especifica el shell emergente.
grab_kind
Especifica la forma en que se deben restringir los eventos del usuario.
popup_shell
Especifica el shell del widget.
w
Especifica el widget.

DESCRIPCIÓN

La función XtPopup realiza lo siguiente:

  • Llama a XtCheckSubclass para asegurar que popup_shell es una subclase de Shell.
  • Genera un error si el campo popped_up del shell ya es True.
  • Llama a los procedimientos de devolución de llamada de la lista popup_callback del shell.
  • Establece el campo popped_up del shell a True, el campo spring_loaded del shell a False, y el campo grab_kind del shell a partir de grab_kind.
  • Si el campo create_popup_child del shell no es NULL, XtPopup lo llama con popup_shell como parámetro.
  • Si grab_kind es XtGrabNonexclusive o XtGrabExclusive, llama a:
XtAddGrab(popup_shell, (grab_kind == XtGrabExclusive), False)
  • Llama a XtRealizeWidget con popup_shell especificado.
  • Llama a XMapWindow con popup_shell especificado.

La función XtPopupSpringLoaded realiza exactamente lo mismo que XtPopup excepto que establece el campo spring_loaded del shell a True y siempre llama a XtAddGrab con exclusive True y spring_loaded True.

Las funciones XtCallbackNone, XtCallbackNonexclusive y XtCallbackExclusive llaman a XtPopup con el shell especificado por el argumento de datos del cliente y grab_kind establecido como indica el nombre. XtCallbackNone, XtCallbackNonexclusive y XtCallbackExclusive especifican XtGrabNone, XtGrabNonexclusive y XtGrabExclusive, respectivamente. Cada función establece luego el widget que ejecutó la lista de devoluciones de llamada para que sea no sensible usando XtSetSensitive. El uso de estas funciones en las devoluciones de llamada no es obligatorio. En particular, una aplicación debe proporcionar código personalizado para devoluciones de llamada que crean shells emergentes dinámicamente o que deben hacer más que desensibilizar el botón.

XtMenuPopup es conocido por el gestor de traducciones, que debe realizar acciones especiales para ventanas emergentes de carga elástica. Las llamadas a XtMenuPopup en una especificación de traducción se mapean en llamadas a un procedimiento de acción no exportado, y el gestor de traducciones rellena los parámetros basándose en el evento especificado en el lado izquierdo de una traducción.

Si se invoca XtMenuPopup en ButtonPress (posiblemente con modificadores), el gestor de traducciones muestra el shell con grab_kind establecido a XtGrabExclusive y spring_loaded establecido a True. Si se invoca XtMenuPopup en EnterWindow (posiblemente con modificadores), el gestor de traducciones muestra el shell con grab_kind establecido a XtGrabNonexclusive y spring_loaded establecido a False. De lo contrario, el gestor de traducciones genera un error. Cuando se muestra el widget, ocurren las siguientes acciones:

  • Llama a XtCheckSubclass para asegurar que popup_shell es una subclase de Shell.
  • Genera un error si el campo popped_up del shell ya es True.
  • Llama a los procedimientos de devolución de llamada de la lista popup_callback del shell.
  • Establece el campo popped_up del shell a True y los campos grab_kind y spring_loaded del shell de manera apropiada.
  • Si el campo create_popup_child del shell no es NULL, se llama con popup_shell como parámetro.
  • Llama a:
XtAddGrab(popup_shell, (grab_kind == XtGrabExclusive), spring_loaded)
  • Llama a XtRealizeWidget con popup_shell especificado.
  • Llama a XMapWindow con popup_shell especificado.

(Nota: estas acciones son las mismas que las de XtPopup.) XtMenuPopup intenta encontrar el shell buscando en el árbol de widgets comenzando desde el padre del widget en el que se invoca. Si encuentra un shell con el nombre especificado en los hijos emergentes de ese padre, muestra el shell con los parámetros apropiados. De lo contrario, sube por la cadena de padres según sea necesario. Si XtMenuPopup llega al widget de la aplicación y no puede encontrar un shell coincidente, genera un error.
