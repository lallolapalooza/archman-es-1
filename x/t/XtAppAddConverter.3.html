Paquete: libxt

XtAppAddConverter(3) FUNCIONES DE COMPATIBILIDAD XT XtAppAddConverter(3)

NOMBRE

XtAppAddConverter, XtAddConverter - registrar convertidor de recursos

SINTAXIS

#include <X11/Intrinsic.h>

void XtAppAddConverter(XtAppContext app_context, const char *from_type, const char *to_type, XtConverter converter, XtConvertArgList convert_args, Cardinal num_args);

void XtAddConverter(const char *from_type, const char *to_type, XtConverter converter, XtConvertArgList convert_args, Cardinal num_args);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
converter
Especifica el procedimiento convertidor de tipo.
convert_args
Especifica cómo calcular los argumentos adicionales para el convertidor o NULL.
from_type
Especifica el tipo de origen.
num_args
Especifica el número de argumentos adicionales para el convertidor o cero.
to_type
Especifica el tipo de destino.

DESCRIPCIÓN

XtAppAddConverter es equivalente en función a XtAppSetTypeConverter con cache_type igual a XtCacheAll para convertidores de tipo de formato antiguo. Ha sido sustituido por XtAppSetTypeConverter.

XtAddConverter es equivalente en función a XtSetTypeConverter con cache_type igual a XtCacheAll para convertidores de tipo de formato antiguo. Ha sido sustituido por XtSetTypeConverter.
