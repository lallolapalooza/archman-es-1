XtOffset(3) FUNCIONES XT XtOffset(3)

NOMBRE

XtOffset, XtOffsetOf, XtNumber - determinar el desplazamiento en bytes o el número de elementos de un array

SINTAXIS

#include <X11/Intrinsic.h>

Cardinal XtOffset(Type tipo_puntero, Field nombre_campo);

Cardinal XtOffsetOf(Type tipo_estructura, Field nombre_campo);

Cardinal XtNumber(VariableArray array);

ARGUMENTOS

array
Especifica un array de tamaño fijo.
nombre_campo
Especifica el nombre del campo para el cual calcular el desplazamiento en bytes.
tipo_puntero
Especifica un tipo declarado como puntero a la estructura.
tipo_estructura
Especifica un tipo declarado como estructura.

DESCRIPCIÓN

La macro XtOffset se utiliza habitualmente para determinar el desplazamiento de diversos campos de recursos desde el principio de un widget y puede usarse en tiempo de compilación en inicializaciones estáticas.

La macro XtOffsetOf se expande a una expresión constante que proporciona el desplazamiento en bytes hasta el miembro de estructura especificado desde el principio de la estructura. Se utiliza normalmente para inicializar estáticamente listas de recursos y es más portable que XtOffset, que cumple la misma función.

La macro XtNumber devuelve el número de elementos en las listas de argumentos, listas de recursos y otros arrays contados especificados.
