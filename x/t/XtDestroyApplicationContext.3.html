XtCreateApplicationContext(3) FUNCIONES XT XtCreateApplicationContext(3)

NOMBRE

XtCreateApplicationContext, XtDestroyApplicationContext, XtWidgetToApplicationContext, XtToolkitInitialize - crear, destruir y obtener un contexto de aplicación

SINTAXIS

#include <X11/Intrinsic.h>

XtAppContext XtCreateApplicationContext(void);

void XtDestroyApplicationContext(XtAppContext app_context);

XtAppContext XtWidgetToApplicationContext(Widget w);

void XtToolkitInitialize(void);

ARGUMENTOS

app_context
Especifica el contexto de la aplicación.
w
Especifica el widget del que se desea obtener el contexto de la aplicación.

DESCRIPCIÓN

La función XtCreateApplicationContext devuelve un contexto de aplicación, que es un tipo opaco. Cada aplicación debe tener al menos un contexto de aplicación.

La función XtDestroyApplicationContext destruye el contexto de aplicación especificado tan pronto como sea seguro hacerlo. Si se llama desde dentro de una distribución de eventos (por ejemplo, un procedimiento de retrollamada), XtDestroyApplicationContext no destruye el contexto de aplicación hasta que la distribución se completa.

La función XtWidgetToApplicationContext devuelve el contexto de aplicación para el widget especificado.

La función XtToolkitInitialize inicializa los componentes internos de Intrinsics. Si XtToolkitInitialize se llamó previamente, retorna inmediatamente.
