XtAddCallbacks(3)

Paquete: libxt

Licencias: MIT, HPND-sell-variant, SMLNJ, MIT-open-group, X11

XtAddCallback(3) FUNCIONES XT XtAddCallback(3)

NOMBRE

XtAddCallback, XtAddCallbacks, XtRemoveCallback, XtRemoveCallbacks, XtRemoveAllCallbacks - añadir y eliminar procedimientos de callback

SINTAXIS

#include <X11/Intrinsic.h>

void XtAddCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtAddCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveCallback(Widget w, const char *callback_name, XtCallbackProc callback, XtPointer client_data);

void XtRemoveCallbacks(Widget w, const char *callback_name, XtCallbackList callbacks);

void XtRemoveAllCallbacks(Widget w, const char *callback_name);

ARGUMENTOS

callback
Especifica el procedimiento de callback.
callbacks
Especifica la lista terminada en nulo de procedimientos de callback y los datos del cliente correspondientes.
callback_name
Especifica la lista de callbacks a la que se va a añadir o de la que se va a eliminar el procedimiento.
client_data
Especifica el argumento que se pasará al procedimiento especificado cuando sea invocado por XtCallbacks o NULL, o los datos del cliente para hacer coincidir los procedimientos de callback registrados.
w
Especifica el widget.

DESCRIPCIÓN

La función XtAddCallback añade el procedimiento de callback especificado a la lista de callbacks del widget especificado.

La función XtAddCallbacks añade la lista de callbacks especificada a la lista de callbacks del widget especificado.

La función XtRemoveCallback elimina un callback solo si coinciden tanto el procedimiento como los datos del cliente.

La función XtRemoveCallbacks elimina los procedimientos de callback especificados de la lista de callbacks del widget especificado.

La función XtRemoveAllCallbacks elimina todos los procedimientos de callback de la lista de callbacks del widget especificado.
