DESCRIPCIÓN

Esta extensión es un conjunto mínimo de extensiones de cliente y servidor requerido para probar completamente el servidor X11 sin intervención del usuario. Esta extensión no está diseñada para soportar la grabación y reproducción general de acciones del usuario.

Las funciones proporcionadas por esta extensión se dividen en dos grupos:

Operaciones de Cliente

Estas rutinas manipulan el comportamiento del lado del cliente, de lo contrario oculto. La implementación real dependerá de los detalles del binding de lenguaje específico y del grado de almacenamiento en búfer de solicitudes, caché de GContext, etc., que se proporcione. En el binding de C, se proporcionan rutinas para acceder a los detalles internos de dos estructuras de datos opacas — GCs y Visuals — y para descartar cualquier solicitud pendiente dentro del búfer de salida de una conexión. Se puede esperar que los detalles exactos difieran para otros bindings de lenguaje.

Solicitudes del Servidor

La primera de estas solicitudes es similar a la que se proporciona en la mayoría de las extensiones: permite a un cliente especificar un número de versión mayor y menor al servidor, y que el servidor responda con las versiones mayor y menor de sí mismo. Las dos solicitudes restantes permiten lo siguiente:
•Acceso a un recurso de servidor, de lo contrario, de sólo escritura: el cursor asociado con una ventana dada
•Quizás lo más importante, la síntesis limitada de eventos de dispositivos de entrada, casi como si un usuario cooperativo hubiera movido el dispositivo señalador o presionado una tecla o botón.

Todas las funciones y procedimientos de la extensión XTEST, y todos los constantes y macros manifiestos, comenzarán con la cadena XTest. Todas las operaciones se clasifican como servidor/cliente (Server) o solo cliente (Client).

XTestQueryExtension devuelve True si la pantalla especificada admite la extensión XTEST, de lo contrario False. Si la extensión es compatible, *event_base se establecería en el número de evento para el primer evento de esta extensión y *error_base se establecería en el número de error para el primer error de esta extensión. Como no se definen errores ni eventos para esta versión de la extensión, los valores devueltos aquí no están definidos (ni son útiles). Si la extensión es compatible, *major_version y *minor_version se establecen en los números de versión mayor y menor de la extensión admitida por la pantalla. De lo contrario, ninguno de los argumentos se establece.

Si la extensión es compatible, XTestCompareCursorWithWindow realiza una comparación del cursor cuyo ID se especifica mediante cursor (que puede ser None) con el cursor de la ventana especificada mediante window, devolviendo True si son iguales y False en caso contrario. Si la extensión no es compatible, la solicitud se ignora y se devuelve cero.

Si la extensión es compatible, XTestCompareCurrentCursorWithWindow realiza una comparación del cursor actual con el cursor de la ventana especificada, devolviendo True si son iguales y False en caso contrario. Si la extensión no es compatible, la solicitud se ignora y se devuelve cero.

Si la extensión es compatible, XTestFakeKeyEvent solicita al servidor que simule una KeyPress (si is_press es True) o una KeyRelease (si is_press es False) de la tecla con el keycode especificado; de lo contrario, la solicitud se ignora.

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido `delay` milisegundos después de recibir la solicitud (si `delay` es CurrentTime, esto se interpreta como ninguna demora). Ninguna otra solicitud de este cliente se procesará hasta que esta demora, si la hay, haya expirado y se haya completado el procesamiento subsiguiente del evento simulado.

Si la extensión es compatible, XTestFakeButtonEvent solicita al servidor que simule una ButtonPress (si is_press es True) o una ButtonRelease (si is_press es False) del botón lógico numerado por el botón especificado; de lo contrario, la solicitud se ignora.

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido `delay` milisegundos después de recibir la solicitud (si `delay` es CurrentTime, esto se interpreta como ninguna demora). Ninguna otra solicitud de este cliente se procesará hasta que esta demora, si la hay, haya expirado y se haya completado el procesamiento subsiguiente del evento simulado.

Si la extensión es compatible, XTestFakeMotionEvent solicita al servidor que simule un movimiento del puntero a la posición especificada (x, y) en la ventana raíz de screen_number; de lo contrario, la solicitud se ignora. Si screen_number es -1, se utiliza la pantalla actual (en la que se encuentra el puntero).

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido `delay` milisegundos después de recibir la solicitud (si `delay` es CurrentTime, esto se interpreta como ninguna demora). Ninguna otra solicitud de este cliente se procesará hasta que esta demora, si la hay, haya expirado y se haya completado el procesamiento subsiguiente del evento simulado.

Si la extensión es compatible, XTestFakeRelativeMotionEvent solicita al servidor que simule un movimiento del puntero en las cantidades especificadas (x, y) relativas a la posición actual del puntero en screen_number; de lo contrario, la solicitud se ignora. Si screen_number es -1, se utiliza la pantalla actual (en la que se encuentra el puntero).

Si la extensión es compatible, el evento simulado no se procesará hasta que hayan transcurrido `delay` milisegundos después de recibir la solicitud (si `delay` es CurrentTime, esto se interpreta como ninguna demora). Ninguna otra solicitud de este cliente se procesará hasta que esta demora, si la hay, haya expirado y se haya completado el procesamiento subsiguiente del evento simulado.

Si impervious es True, entonces el cliente en ejecución se vuelve impermeable a los grabs del servidor. Si impervious es False, entonces el cliente en ejecución vuelve al estado normal de ser susceptible a los grabs del servidor.

XTestSetGContextOfGC establece el GContext dentro del tipo de dato opaco referenciado por gc para que sea el especificado por gid.

XTestSetVisualIDOfVisual establece el VisualID dentro del tipo de dato opaco referenciado por visual para que sea el especificado por visualid.

XTestDiscard descarta cualquier solicitud dentro del búfer de salida para la pantalla especificada. Devuelve True si se descartó alguna solicitud; de lo contrario, devuelve False.

VALORES DE RETORNO

Todas las rutinas que tengan el tipo de retorno Status devolverán un valor distinto de cero para el éxito y cero para el fracaso. Incluso si la extensión XTEST es compatible, el servidor puede retirar tales facilidades de forma arbitraria; en cuyo caso, posteriormente devolverán cero.
