XtCreateApplicationShell(3) Funciones de compatibilidad de XT XtCreateApplicationShell(3)

NOMBRE

XtCreateApplicationShell - crear instancia de widget de nivel superior

SINTAXIS

#include <X11/Intrinsic.h>

Widget XtCreateApplicationShell(const char *name, WidgetClass widget_class, ArgList args, Cardinal num_args);

ARGUMENTOS

name
Especifica el nombre del shell.
args
Especifica la lista de argumentos para anular cualquier otra especificación de recursos.
num_args
Especifica el número de argumentos en la lista de argumentos.

DESCRIPCIÓN

El procedimiento XtCreateApplicationShell llama a XtAppCreateShell con application NULL, la clase de aplicación pasada a XtInitialize y el contexto de aplicación predeterminado creado por XtInitialize. Esta rutina ha sido reemplazada por XtAppCreateShell.
