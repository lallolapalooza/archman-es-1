XQueryTree(3) XLIB FUNCTIONS XQueryTree(3)

NOMBRE

XQueryTree - consultar información del árbol de ventanas

SINTAXIS

Status XQueryTree(Display *display, Window w, Window *root_return, Window *parent_return, Window **children_return, unsigned int *nchildren_return);

ARGUMENTOS

children_return
Devuelve la lista de hijos.
display
Especifica la conexión con el servidor X.
nchildren_return
Devuelve el número de hijos.
parent_return
Devuelve la ventana padre.
root_return
Devuelve la ventana raíz.
w
Especifica la ventana de la que se desean obtener la lista de hijos, la raíz, el padre y el número de hijos.

DESCRIPCIÓN

La función XQueryTree devuelve el ID raíz, el ID de la ventana padre, un puntero a la lista de ventanas hijas (NULL si no hay hijos) y el número de hijos en la lista para la ventana especificada. Los hijos se listan en orden de apilamiento actual, desde el más bajo (primero) hasta el más alto (último). XQueryTree devuelve cero si falla y un valor distinto de cero si tiene éxito. Para liberar una lista de hijos no NULL cuando ya no se necesita, use XFree.

XQueryTree puede generar un error BadWindow.

ERRORES

BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.

VER TAMBIÉN

XFree(3), XGetWindowAttributes(3), XQueryPointer(3)
