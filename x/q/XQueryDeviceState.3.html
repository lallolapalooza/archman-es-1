XQUERYDEVICESTATE(3)   XQUERYDEVICESTATE(3)

NOMBRE

XQueryDeviceState - consultar el estado de un dispositivo de entrada de extensión.

SINOPSIS

#include <X11/extensions/XInput.h>
XDeviceState* XQueryDeviceState( Display *display,
                                 XDevice *device);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyo estado se va a consultar.

DESCRIPCIÓN

La solicitud XQueryDeviceState consulta el estado de un dispositivo de entrada.
El estado actual de las teclas y botones (presionados o sueltos), y los
valuadores (valor actual) en el dispositivo es reportado por esta solicitud.
Cada tecla o botón se representa por un bit en la estructura XDeviceState que
se devuelve. Los valuadores en el dispositivo reportan 0 si están reportando
información relativa, y el valor actual si están reportando información
absoluta.
XQueryDeviceState puede generar un error BadDevice.
Estructuras:
La estructura XDeviceState contiene:
typedef struct {
    XID device_id;
    int num_classes;
    XInputClass *data;
} XDeviceState;
La estructura XValuatorState contiene:
typedef struct {
    unsigned char class;
    unsigned char length;
    unsigned char num_valuators;
    unsigned char mode;
    int *valuators;
} XValuatorState;
La estructura XKeyState contiene:
typedef struct {
    unsigned char class;
    unsigned char length;
    short     num_keys;
    char keys[32];
} XKeyState;
La estructura XButtonState contiene:
typedef struct {
    unsigned char class;
    unsigned char length;
    short     num_buttons;
    char buttons[32];
} XButtonState;

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si algún otro
       cliente ha hecho que el dispositivo especificado sea el dispositivo
       de teclado X o el dispositivo puntero X a través de las solicitudes
       XChangeKeyboardDevice o XChangePointerDevice.
