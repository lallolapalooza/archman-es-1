XQueryBestCursor(3)

Paquete: libx11

Licencias: MIT AND X11

XRecolorCursor(3) FUNCIONES DE XLIB XRecolorCursor(3)

NOMBRE

XRecolorCursor, XFreeCursor, XQueryBestCursor - manipular cursores

SINTAXIS

int XRecolorCursor(Display *display, Cursor cursor, XColor *foreground_color, XColor *background_color);

int XFreeCursor(Display *display, Cursor cursor);

Status XQueryBestCursor(Display *display, Drawable d, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

ARGUMENTOS

background_color
Especifica los valores RGB para el fondo de la fuente.
cursor
Especifica el cursor.
d
Especifica el dibujable, que indica la pantalla.
display
Especifica la conexión con el servidor X.
foreground_color
Especifica los valores RGB para el primer plano de la fuente.
width

height
Especifican el ancho y alto del cursor para el cual se desea información de tamaño.
width_return

height_return
Devuelven el mejor ancho y alto más cercanos a los especificados.

DESCRIPCION

La función XRecolorCursor cambia el color del cursor especificado y, si el cursor se está mostrando en una pantalla, el cambio es visible inmediatamente. Los miembros de píxeles de las estructuras XColor se ignoran; solo se utilizan los valores RGB.

XRecolorCursor puede generar un error BadCursor.

La función XFreeCursor elimina la asociación entre el ID del recurso del cursor y el cursor especificado. El almacenamiento del cursor se libera cuando ningún otro recurso lo referencia. El ID del cursor especificado no debe volver a ser referenciado.

XFreeCursor puede generar un error BadCursor.

Algunas pantallas permiten cursores más grandes que otras. La función XQueryBestCursor proporciona una forma de averiguar qué tamaños de cursores son realmente posibles en la pantalla. Devuelve el tamaño más grande que se puede mostrar. Las aplicaciones deben estar preparadas para usar cursores más pequeños en pantallas que no puedan admitir los grandes.

XQueryBestCursor puede generar un error BadDrawable.

DIAGNÓSTICOS

BadCursor
Un valor para un argumento Cursor no nombra un Cursor definido.
BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
