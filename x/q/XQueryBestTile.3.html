XQueryBestSize(3) FUNCIONES DE XLIB XQueryBestSize(3)

NOMBRE

XQueryBestSize, XQueryBestTile, XQueryBestStipple - determinar tamaños eficientes

SINTAXIS

Status XQueryBestSize(Display *display, int class, Drawable which_screen, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

Status XQueryBestTile(Display *display, Drawable which_screen, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

Status XQueryBestStipple(Display *display, Drawable which_screen, unsigned int width, unsigned int height, unsigned int *width_return, unsigned int *height_return);

ARGUMENTOS

class
Especifica la clase de interés. Puede pasar TileShape, CursorShape o StippleShape.
display
Especifica la conexión con el servidor X.
width

height
Especifique el ancho y el alto.
which_screen
Especifica cualquier drawable en la pantalla.
width_return

height_return
Devuelve el ancho y el alto del objeto mejor soportado por el hardware de la pantalla.

DESCRIPCIÓN

La función XQueryBestSize devuelve el tamaño mejor o más cercano al tamaño especificado. Para CursorShape, este es el tamaño más grande que se puede mostrar completamente en la pantalla especificada por which_screen. Para TileShape, este es el tamaño que se puede teselar más rápido. Para StippleShape, este es el tamaño que se puede difuminar más rápido. Para CursorShape, el drawable indica la pantalla deseada. Para TileShape y StippleShape, el drawable indica la pantalla y posiblemente la clase y profundidad de la ventana. Una ventana InputOnly no se puede utilizar como drawable para TileShape o StippleShape, o se produce un error BadMatch.

XQueryBestSize puede generar errores BadDrawable, BadMatch y BadValue.

La función XQueryBestTile devuelve el tamaño mejor o más cercano, es decir, el tamaño que se puede teselar más rápido en la pantalla especificada por which_screen. El drawable indica la pantalla y posiblemente la clase y profundidad de la ventana. Si se utiliza una ventana InputOnly como drawable, se produce un error BadMatch.

XQueryBestTile puede generar errores BadDrawable y BadMatch.

La función XQueryBestStipple devuelve el tamaño mejor o más cercano, es decir, el tamaño que se puede difuminar más rápido en la pantalla especificada por which_screen. El drawable indica la pantalla y posiblemente la clase y profundidad de la ventana. Si se utiliza una ventana InputOnly como drawable, se produce un error BadMatch.

XQueryBestStipple puede generar errores BadDrawable y BadMatch.

DIAGNÓSTICOS

BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Píxel definido.
BadMatch
Los valores no existen para una ventana InputOnly.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta todo el rango definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
