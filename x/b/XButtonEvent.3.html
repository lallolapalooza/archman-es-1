XButtonEvent(3)

Paquete: libx11

Licencias: MIT AND X11

XButtonEvent(3) FUNCIONES XLIB XButtonEvent(3)

NOMBRE

XButtonEvent, XKeyEvent, XMotionEvent - Estructuras de eventos KeyPress, KeyRelease, ButtonPress, ButtonRelease y MotionNotify

ESTRUCTURAS

Las estructuras para los eventos KeyPress, KeyRelease, ButtonPress, ButtonRelease y MotionNotify contienen:

typedef struct {
        int type;       /* ButtonPress o ButtonRelease */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window window;  /* ventana de "evento" con respecto a la que se informa */
        Window root;    /* ventana raíz en la que ocurrió el evento */
        Window subwindow;       /* ventana hija */
        Time time;      /* milisegundos */
        int x, y;       /* coordenadas x, y del puntero en la ventana de evento */
        int x_root, y_root;     /* coordenadas relativas a la raíz */
        unsigned int state;     /* máscara de tecla o botón */
        unsigned int button;    /* detalle */
        Bool same_screen;       /* indicador same_screen */
} XButtonEvent;
typedef XButtonEvent XButtonPressedEvent;
typedef XButtonEvent XButtonReleasedEvent;
typedef struct {
        int type;       /* KeyPress o KeyRelease */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window window;  /* ventana de "evento" con respecto a la que se informa */
        Window root;    /* ventana raíz en la que ocurrió el evento */
        Window subwindow;       /* ventana hija */
        Time time;      /* milisegundos */
        int x, y;       /* coordenadas x, y del puntero en la ventana de evento */
        int x_root, y_root;     /* coordenadas relativas a la raíz */
        unsigned int state;     /* máscara de tecla o botón */
        unsigned int keycode;   /* detalle */
        Bool same_screen;       /* indicador same_screen */
} XKeyEvent;
typedef XKeyEvent XKeyPressedEvent;
typedef XKeyEvent XKeyReleasedEvent;
typedef struct {
        int type;       /* MotionNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del que se leyó el evento */
        Window window;  /* ventana de "evento" con respecto a la que se informa */
        Window root;    /* ventana raíz en la que ocurrió el evento */

} XMotionEvent;

Cuando recibes estos eventos, los miembros de su estructura se configuran de la siguiente manera.

El miembro type se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido en GraphicsExpose. El miembro display se establece en un puntero a la pantalla de la que se leyó el evento. El miembro send_event se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero ampliado desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece en la ventana que es más útil para los despachadores de toolkit.

Estas estructuras tienen los siguientes miembros comunes: window, root, subwindow, time, x, y, x_root, y_root, state y same_screen. El miembro window se establece en la ventana en la que se generó el evento y se denomina ventana de evento. Siempre que se cumplan las condiciones discutidas previamente, esta es la ventana utilizada por el servidor X para informar el evento. El miembro root se establece en la ventana raíz de la ventana de origen. Los miembros x_root y y_root se establecen en las coordenadas del puntero relativas al origen de la ventana raíz en el momento del evento.

El miembro same_screen se establece para indicar si la ventana de evento está en la misma pantalla que la ventana raíz y puede ser True o False. Si es True, las ventanas de evento y raíz están en la misma pantalla. Si es False, las ventanas de evento y raíz no están en la misma pantalla.

Si la ventana de origen es inferior a la ventana de evento, el miembro subwindow de la estructura se establece en la ventana hija de la ventana de evento que es la ventana de origen o la ventana hija de la ventana de evento que es un ancestro de la ventana de origen. De lo contrario, el servidor X establece el miembro subwindow en None. El miembro time se establece en la hora en que se generó el evento y se expresa en milisegundos.

Si la ventana de evento está en la misma pantalla que la ventana raíz, los miembros x y y se establecen en las coordenadas relativas al origen de la ventana de evento. De lo contrario, estos miembros se establecen en cero.

El miembro state se establece para indicar el estado lógico de los botones del puntero y las teclas modificadoras justo antes del evento, que es la operación OR inclusiva a nivel de bits de una o más de las máscaras de botones o teclas modificadoras: Button1Mask, Button2Mask, Button3Mask, Button4Mask, Button5Mask, ShiftMask, LockMask, ControlMask, Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask y Mod5Mask.

Cada una de estas estructuras también tiene un miembro que indica el detalle. Para las estructuras XKeyPressedEvent y XKeyReleasedEvent, este miembro se llama keycode. Se establece en un número que representa una tecla física en el teclado. El keycode es una representación arbitraria para cualquier tecla del teclado (ver secciones 12.7 y 16.1).

Para las estructuras XButtonPressedEvent y XButtonReleasedEvent, este miembro se llama button. Representa el botón del puntero que cambió de estado y puede ser el valor Button1, Button2, Button3, Button4 o Button5. Para la estructura XPointerMovedEvent, este miembro se llama is_hint. Puede establecerse en NotifyNormal o NotifyHint.
