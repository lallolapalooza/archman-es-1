XChangeKeyboardControl(3) FUNCIONES XLIB XChangeKeyboardControl(3)

NOMBRE

XChangeKeyboardControl, XGetKeyboardControl, XAutoRepeatOn, XAutoRepeatOff, XBell, XQueryKeymap, XKeyboardControl - manipular la configuración del teclado y la estructura de control del teclado

SINTAXIS

int XChangeKeyboardControl(Display *display, unsigned long value_mask, XKeyboardControl *values);

int XGetKeyboardControl(Display *display, XKeyboardState *values_return);

int XAutoRepeatOn(Display *display);

int XAutoRepeatOff(Display *display);

int XBell(Display *display, int percent);

int XQueryKeymap(Display *display, char keys_return[32]);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
keys_return
Devuelve una matriz de bytes que identifica qué teclas están presionadas. Cada bit representa una tecla del teclado.
percent
Especifica el volumen de la campana, que puede variar entre -100 y 100 inclusive.
value_mask
Especifica qué controles cambiar. Esta máscara es la OR inclusiva a nivel de bits de los bits de máscara de control válidos.
values
Especifica un valor para cada bit establecido en 1 en la máscara.
values_return
Devuelve los valores de control actuales del teclado en la estructura XKeyboardState especificada.

DESCRIPCION

La función XChangeKeyboardControl controla las características del teclado definidas por la estructura XKeyboardControl. El argumento value_mask especifica qué valores se van a cambiar.

XChangeKeyboardControl puede generar errores BadMatch y BadValue.

La función XGetKeyboardControl devuelve los valores de control actuales del teclado en la estructura XKeyboardState.

La función XAutoRepeatOn activa la repetición automática para el teclado en la pantalla especificada.

La función XAutoRepeatOff desactiva la repetición automática para el teclado en la pantalla especificada.

La función XBell hace sonar la campana del teclado en la pantalla especificada, si es posible. El volumen especificado es relativo al volumen base del teclado. Si el valor del argumento percent no está en el rango -100 a 100 inclusive, se produce un error BadValue. El volumen al que suena la campana cuando el argumento percent es no negativo es:

base - [(base * percent) / 100] + percent

El volumen al que suena la campana cuando el argumento percent es negativo es:

base + [(base * percent) / 100]

Para cambiar el volumen base de la campana, utilice XChangeKeyboardControl.

XBell puede generar un error BadValue.

La función XQueryKeymap devuelve un vector de bits para el estado lógico del teclado, donde cada bit establecido en 1 indica que la tecla correspondiente está actualmente presionada. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits para las teclas 8N a 8N + 7 con el bit menos significativo del byte representando la tecla 8N.

Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente) puede retrasarse respecto al estado físico si el procesamiento de eventos del dispositivo está congelado.

ESTRUCTURAS

La estructura XKeyboardControl contiene:

/* Bits de máscara para ChangeKeyboardControl */

#define KBKeyClickPercent (1L<<0)
#define KBBellPercent (1L<<1)
#define KBBellPitch (1L<<2)
#define KBBellDuration (1L<<3)
#define KBLed (1L<<4)
#define KBLedMode (1L<<5)
#define KBKey (1L<<6)
#define KBAutoRepeatMode (1L<<7) 
/* Valores */
typedef struct {
        int key_click_percent;
        int bell_percent;
        int bell_pitch;
        int bell_duration;
        int led;
        int led_mode;   /* LedModeOn, LedModeOff */
        int key;
        int auto_repeat_mode;   /* AutoRepeatModeOff, AutoRepeatModeOn,
                                AutoRepeatModeDefault */
} XKeyboardControl;

El miembro key_click_percent establece el volumen de los clics de tecla entre 0 (apagado) y 100 (alto) inclusive, si es posible. Un valor de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

El miembro bell_percent establece el volumen base de la campana entre 0 (apagado) y 100 (alto) inclusive, si es posible. Un valor de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_pitch establece el tono (especificado en Hz) de la campana, si es posible. Un valor de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_duration establece la duración de la campana especificada en milisegundos, si es posible. Un valor de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

Si se especifican los miembros led_mode y led, se cambia el estado de ese LED, si es posible. El miembro led_mode se puede establecer en LedModeOn o LedModeOff. Si solo se especifica led_mode, se cambia el estado de todos los LEDs, si es posible. Se soportan como máximo 32 LEDs numerados a partir de uno. No se define una interpretación estándar de los LEDs. Si se especifica led sin led_mode, se produce un error BadMatch.

Si se especifican los miembros auto_repeat_mode y key, se cambia el auto_repeat_mode de esa tecla (según AutoRepeatModeOn, AutoRepeatModeOff o AutoRepeatModeDefault), si es posible. Si solo se especifica auto_repeat_mode, se cambia el auto_repeat_mode global para todo el teclado, si es posible, y no afecta a la configuración por tecla. Si se especifica una tecla sin un auto_repeat_mode, se produce un error BadMatch. Cada tecla tiene un modo individual para saber si debe repetirse automáticamente o no, y una configuración predeterminada para el modo. Además, existe un modo global para saber si la repetición automática debe estar activada o no, y una configuración predeterminada para ese modo. Cuando el modo global es AutoRepeatModeOn, las teclas deben obedecer sus modos de repetición automática individuales. Cuando el modo global es AutoRepeatModeOff, ninguna tecla debe repetirse automáticamente. Una tecla que se repite automáticamente genera eventos alternos de KeyPress y KeyRelease. Cuando una tecla se utiliza como modificador, es deseable que la tecla no se repita automáticamente, independientemente de su configuración de repetición automática.

La estructura XKeyboardState contiene:

typedef struct {
        int key_click_percent;
        int bell_percent;
        unsigned int bell_pitch, bell_duration;
        unsigned long led_mask;
        int global_auto_repeat;
        char auto_repeats[32];
} XKeyboardState;

Para los LEDs, el bit menos significativo de led_mask corresponde al LED uno, y cada bit establecido en 1 en led_mask indica un LED que está encendido. El miembro global_auto_repeat puede establecerse en AutoRepeatModeOn o AutoRepeatModeOff. El miembro auto_repeats es un vector de bits. Cada bit establecido en 1 indica que la repetición automática está habilitada para la tecla correspondiente. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits para las teclas 8N a 8N + 7 con el bit menos significativo del byte representando la tecla 8N.

XBell(3) - Arch Linux MAN pages

NAME

XBell, XBellKeyboard, XChangeKeyboardControl, XGetKeyboardControl, XKeyboardControl - emit a keyboard bell or set/get keyboard controls

SYNTAX

      XBell(3)
      XBellKeyboard(3)
      XChangeKeyboardControl(3)
      XGetKeyboardControl(3)
      XKeyboardControl(3)

ARGUMENTS

display
Specifies the connection to the X server.
bell_advice
Specifies the bell pitch.

If the bell is disabled, this value has no effect. If the bell is enabled, the pitch is set according to this value. The exact pitch is determined by the server.

bell_percent
Specifies the bell volume.

If the bell is disabled, this value has no effect. If the bell is enabled, the volume is set according to this value. The volume is specified as a percentage of the maximum volume. The exact volume is determined by the server.

bell_pitch
Specifies the bell pitch in Hz.

If the bell is disabled, this value has no effect. If the bell is enabled, the pitch is set according to this value. The exact pitch is determined by the server.

bell_duration
Specifies the bell duration in milliseconds.

If the bell is disabled, this value has no effect. If the bell is enabled, the duration is set according to this value. The exact duration is determined by the server.

led_mode
Specifies the LED mode. Must be On or Off.
global_auto_repeat
Specifies the global auto-repeat mode. Must be On or Off.
auto_repeat
Specifies the auto-repeat mode for a specific key. If On, the key will repeat when held down. If Off, it will not. The key is specified by its keycode.
repeat
Controls the auto-repeat behavior for individual keys.
led
Specifies the LED to control. LEDs are numbered 0 and up.
control
Specifies the keyboard control to modify.
value
Specifies the new value for the keyboard control.
values_return
Returns the current values of the keyboard controls.

DESCRIPTION

The XBell function emits a keyboard bell. The bell_advice parameter controls the pitch of the bell, and the bell_percent parameter controls the volume. The actual pitch and volume are determined by the server.

The XBellKeyboard function emits a keyboard bell for a specific keyboard device. The bell_pitch and bell_duration parameters control the pitch and duration of the bell, respectively.

The XChangeKeyboardControl function allows you to modify various keyboard settings. You can control the bell, LEDs, and auto-repeat behavior. The control parameter specifies which control to modify, and the value parameter specifies the new value for that control. The XKeyboardControl structure is used to pass multiple control values at once.

The XGetKeyboardControl function retrieves the current keyboard settings and stores them in the values_return structure.

STRUCTURES

The XKeyboardControl structure contains the following members:

typedef struct {
    int         key_click_volume;
    int         bell_volume;
    int         bell_pitch;
    int         bell_duration;
    int         led_mode;
    int         global_auto_repeat;
    int         auto_repeat[32];
    int         led[32];
} XKeyboardControl;

DIAGNOSTICS

On failure, XBell, XBellKeyboard, XChangeKeyboardControl, and XGetKeyboardControl raise a BadValue error if a specified value is out of range.
