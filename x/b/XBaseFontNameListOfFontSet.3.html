XFontsOfFontSet(3) FUNCIONES XLIB XFontsOfFontSet(3)

NOMBRE

XFontsOfFontSet, XBaseFontNameListOfFontSet, XLocaleOfFontSet, XContextDependentDrawing, XContextualDrawing, XDirectionalDependentDrawing - obtener información de conjuntos de fuentes

SINTAXIS

int XFontsOfFontSet(XFontSet font_set, XFontStruct ***font_struct_list_return, char ***font_name_list_return);

char *XBaseFontNameListOfFontSet(XFontSet font_set);

char *XLocaleOfFontSet(XFontSet font_set);

Bool XContextDependentDrawing(XFontSet font_set);

Bool XContextualDrawing(XFontSet font_set);

Bool XDirectionalDependentDrawing(XFontSet font_set);

ARGUMENTOS

font_set
Especifica el conjunto de fuentes.
font_name_list_return
Devuelve la lista de nombres de fuentes.
font_struct_list_return
Devuelve la lista de estructuras de fuentes.

DESCRIPCIÓN

La función XFontsOfFontSet devuelve una lista de una o más estructuras XFontStruct y nombres de fuentes para las fuentes utilizadas por las capas Xmb y Xwc para el conjunto de fuentes dado. Se devuelve una lista de punteros a las estructuras XFontStruct a font_struct_list_return. Se devuelve una lista de punteros a cadenas de nombres de fuentes nulas y completamente especificadas en la configuración regional del conjunto de fuentes a font_name_list_return. El orden de font_name_list corresponde al orden de font_struct_list. El número de estructuras XFontStruct y nombres de fuentes se devuelve como el valor de la función.

Dado que no se garantiza que un carácter dado se represente utilizando un solo glifo de fuente, no hay disposición para mapear un carácter o una cadena predeterminada a las propiedades de la fuente, el ID de la fuente o la pista de dirección de la fuente para el carácter. El cliente puede acceder a la lista XFontStruct para obtener estos valores para todas las fuentes en uso actualmente.

Xlib no garantiza que las fuentes se carguen desde el servidor al crear un XFontSet. Xlib puede optar por almacenar en caché los datos de las fuentes, cargándolos solo cuando sea necesario para dibujar texto o calcular las dimensiones del texto. Por lo tanto, la existencia de las métricas per_char en las estructuras XFontStruct en el XFontStructSet no está definida. Además, tenga en cuenta que todas las propiedades de las estructuras XFontStruct están en la codificación STRING.

Las listas de XFontStruct y nombres de fuentes son propiedad de Xlib y no deben ser modificadas ni liberadas por el cliente. Serán liberadas por una llamada a XFreeFontSet con el XFontSet asociado. Hasta que sean liberadas, sus contenidos no serán modificados por Xlib.

La función XBaseFontNameListOfFontSet devuelve la lista original de nombres base de fuentes proporcionada por el cliente cuando se creó el XFontSet. Se devuelve una cadena terminada en nulo que contiene una lista de nombres de fuentes separados por comas como valor de la función. Puede aparecer espacio en blanco inmediatamente a cada lado de las comas separadoras.

Si XCreateFontSet obtuvo un nombre XLFD de las propiedades de la fuente especificadas por un nombre base no XLFD, la función XBaseFontNameListOfFontSet devolverá el nombre XLFD en lugar del nombre base no XLFD.

La lista de nombres base de fuentes es propiedad de Xlib y no debe ser modificada ni liberada por el cliente. Será liberada por una llamada a XFreeFontSet con el XFontSet asociado. Hasta que sea liberada, su contenido no será modificado por Xlib.

La función XLocaleOfFontSet devuelve el nombre de la configuración regional vinculada al XFontSet especificado, como una cadena terminada en nulo.

La cadena de nombre de configuración regional devuelta es propiedad de Xlib y no debe ser modificada ni liberada por el cliente. Puede ser liberada por una llamada a XFreeFontSet con el XFontSet asociado. Hasta que sea liberada, no será modificada por Xlib.

La función XContextDependentDrawing devuelve True si las funciones de dibujo implementan direccionalidad implícita de texto o si el texto dibujado con font_set podría incluir dibujo dependiente del contexto; de lo contrario, devuelve False.

La función XContextualDrawing devuelve True si el texto dibujado con el conjunto de fuentes podría incluir dibujo dependiente del contexto; de lo contrario, devuelve False.

La función XDirectionalDependentDrawing devuelve True si las funciones de dibujo implementan direccionalidad implícita de texto; de lo contrario, devuelve False.
