TIPOS DE DATOS

Rotaciones/Reflexiones

Puede ser cualquiera de:

#define RR_Rotate_0             1
#define RR_Rotate_90            2
#define RR_Rotate_180           4
#define RR_Rotate_270           8
/∗ nuevo en el protocolo 1.0, para permitir la reflexión de la pantalla */
/∗ la reflexión se aplica después de la rotación */
#define RR_Reflect_X            16
#define RR_Reflect_Y            32
typedef struct {
    int	width, height;
    int	mwidth, mheight;
} XRRScreenSize;
typedef struct {
    int type;				/∗ base del evento */
    unsigned long serial;	/∗ # de la última solicitud procesada por el servidor */
    Bool send_event;		/∗ verdadero si esto provino de una solicitud SendEvent */
    Display *display;		/∗ Display del cual se leyó el evento */
    Window window;			/∗ ventana que seleccionó este evento */
    Window root;			/∗ Ventana raíz para la pantalla cambiada */
    Time timestamp;			/∗ cuándo ocurrió el cambio de pantalla */
    Time config_timestamp;	/∗ cuándo fue el último cambio de configuración */
    SizeID size_index;
    SubpixelOrder subpixel_order;
    Rotation rotation;
    int width;
    int height;
    int mwidth;
    int mheight;
} XRRScreenChangeNotifyEvent;
La estructura XRRScreenSize contiene un tamaño raíz posible en píxeles y en milímetros.

Un XRRScreenChangeNotifyEvent se envía a un cliente que ha solicitado notificación cada vez que la configuración de la pantalla cambia. Un cliente puede realizar esta solicitud llamando a XRRSelectInput, pasando la pantalla, la ventana raíz y la máscara RRScreenChangeNotifyMask.

XRRScreenConfiguration es un tipo de dato opaco que contiene la información de configuración de una pantalla.

Marcas de tiempo

Se incluyen marcas de tiempo y se deben usar para asegurar que el cliente esté al día: la pantalla puede cambiar propiedades sobre la marcha y esto asegura que su conocimiento de la configuración esté actualizado. Esto es para ayudar con problemas cuando las pantallas pueden ser conectables en caliente en el futuro.

DESCRIPCIÓN

Xrandr es una biblioteca simple diseñada para interactuar con la Extensión de Redimensionamiento y Rotación de X. Esto permite a los clientes cambiar el tamaño y la rotación de la ventana raíz de una pantalla, junto con la capacidad de reflejar la pantalla sobre cualquier eje (si es compatible con la implementación). La rotación y la reflexión pueden ser implementadas por software y pueden resultar en un rendimiento más lento si la rotación y la reflexión se implementan de esta manera (como lo son todas las implementaciones en octubre de 2002).

La biblioteca Xrandr realiza un almacenamiento en caché mínimo para evitar viajes de ida y vuelta y proporcionar a los clientes información de uso frecuente. Consulte "The X Resize and Rotate Extension" para una descripción detallada; tenga en cuenta también que el cambio de profundidad, como se describe en el documento, no está implementado y puede (o no) ser implementado alguna vez, ya que la memoria de visualización está creciendo rápidamente y los kits de herramientas ya están comenzando a admitir la migración, mitigando la necesidad de cambiar de profundidad. Si se implementa en el futuro, esperamos hacerlo a través de una extensión compatible hacia arriba de la biblioteca/protocolo actual; la funcionalidad descrita aquí debería seguir funcionando.

La rotación y la reflexión y cómo interactúan pueden ser confusas. En Randr, el sistema de coordenadas se rota en sentido antihorario con respecto a la orientación normal. La reflexión es a lo largo del sistema de coordenadas del sistema de ventanas, no los ejes X e Y físicos de la pantalla, por lo que la rotación y la reflexión no interactúan. La otra forma de considerar la reflexión es tratarla como se especifica en la orientación "normal", antes de la rotación.

El evento XRRScreenChangeNotify se envía a los clientes que solicitan ser informados cada vez que cambian las configuraciones de la ventana raíz. Los cambios de configuración pueden incluir resolución, tamaño físico, orden de subpíxeles (ver XRender(3)) y rotación. Tenga en cuenta que los cambios en cualquiera o en todos estos pueden ocurrir debido a eventos externos (control del usuario en el servidor X, conexión/desconexión de un monitor/panel plano diferente) y no son solo el resultado de una solicitud de protocolo/biblioteca al servidor X.

Además, para eliminar una posible condición de carrera, este evento puede generarse inmediatamente al seleccionar la notificación si la pantalla ha cambiado desde que el cliente de Xrandr se conectó al servidor X, para permitir un cambio de resolución de pantalla confiable cuando un usuario puede iniciar sesión y cambiar la configuración mientras uno o varios clientes se están iniciando.

Notificación de Xlib

Los clientes deben volver a llamar a Xlib usando XRRUpdateConfiguration cuando se generan eventos de notificación de cambio de configuración de pantalla (o ocurren cambios de configuración de la ventana raíz, para actualizar la vista de Xlib de la resolución, tamaño, rotación, reflexión u orden de subpíxeles. En general, los kits de herramientas realizarán esta operación en nombre de las aplicaciones; no queríamos cambiar los datos de la estructura de visualización a espaldas de los kits de herramientas, ya que en clientes multihilo, podrían ocurrir varias condiciones de carrera. Los kits de herramientas deberían proporcionar a los clientes algún mecanismo para la notificación de cambios de pantalla, por supuesto.

FUNCIONES

XRRQueryExtension Verifica si la extensión X RandR está disponible en el servidor. Si lo está, devuelve True y establece event_base_return y error_base_return para indicar los números de base de eventos y errores para la extensión. Si no está disponible, devuelve False.

XRRQueryVersion Consulta la versión del protocolo X RandR que implementa el servidor. Establece major_version_return y minor_version_return con los números de versión mayor y menor, respectivamente. Devuelve Status.

XRRGetScreenInfo Obtiene la información de configuración actual para una pantalla dada. Devuelve un puntero a una estructura XRRScreenConfiguration, que contiene información sobre los tamaños, rotaciones y tasas de refresco disponibles. Es responsabilidad del llamador liberar esta estructura usando XRRFreeScreenConfigInfo.

XRRFreeScreenConfigInfo Libera la memoria asignada por XRRGetScreenInfo.

XRRSetScreenConfig Establece la configuración de la pantalla, incluyendo el índice del tamaño, la rotación y la marca de tiempo. Devuelve Status.

XRRSetScreenConfigAndRate Establece la configuración de la pantalla, incluyendo el índice del tamaño, la rotación, la tasa de refresco y la marca de tiempo. Devuelve Status.

XRRConfigRotations Devuelve las rotaciones posibles para la configuración de pantalla dada. El valor de rotación actual se devuelve en current_rotation.

XRRConfigTimes Devuelve las marcas de tiempo asociadas con la configuración de pantalla. La marca de tiempo de configuración actual se devuelve en config_timestamp.

XRRConfigSizes Devuelve una matriz de las configuraciones de tamaño admitidas para la pantalla dada. El número de tamaños en la matriz se devuelve en nsizes.

XRRConfigRates Devuelve una matriz de las tasas de refresco admitidas para un tamaño de pantalla específico. El número de tasas en la matriz se devuelve en nrates.

XRRConfigCurrentConfiguration Devuelve el índice de configuración actual y la rotación actual de la pantalla. La rotación actual se devuelve en rotation.

XRRConfigCurrentRate Devuelve la tasa de refresco actual de la pantalla.

XRRRootToScreen Mapea una ventana raíz a un número de pantalla.

XRRSelectInput Permite que un cliente reciba eventos RRScreenChangeNotify. El argumento mask debe incluir RRScreenChangeNotifyMask para recibir estos eventos.

XRRUpdateConfiguration Debe ser llamado por el cliente cuando recibe un evento RRScreenChangeNotify o ConfigureNotify en la ventana raíz. Actualiza la información de configuración interna de Xlib. Devuelve 1 si el evento fue procesado, 0 en caso contrario.

XRRRotations Devuelve las rotaciones posibles para la pantalla especificada. La rotación actual se almacena en current_rotation. Esta es una versión que no requiere la estructura de configuración.

XRRSizes Devuelve una matriz de las configuraciones de tamaño admitidas para la pantalla especificada. El número de tamaños se almacena en nsizes. Esta es una versión que no requiere la estructura de configuración.

XRRRates Devuelve una matriz de las tasas de refresco admitidas para un tamaño de pantalla específico en la pantalla especificada. El número de tasas se almacena en nrates. Esta es una versión que no requiere la estructura de configuración.

XRRTimes Devuelve las marcas de tiempo asociadas con la configuración de la pantalla especificada. La marca de tiempo de configuración actual se almacena en config_timestamp. Esta es una versión que no requiere la estructura de configuración.

Hay dos clases de interfaces: aquellas que se pueden llamar de forma segura incluso si RandR no está implementado en una pantalla (para que los modismos comunes no dependan del soporte del servidor), y aquellas que devolverán errores si la extensión no está presente.

XRRRotations devuelve tanto el conjunto de rotaciones/reflexiones posibles admitidas (como una máscara de bits) como el valor de la función, junto con la rotación/reflexión actual de la pantalla.

XRRSizes devuelve el tamaño y un puntero a los tamaños actuales admitidos por la pantalla especificada. El primer tamaño especificado es el tamaño predeterminado del servidor. Si RandR no es compatible, devuelve 0 para el número de tamaños.

XRRRates devuelve un puntero a las tasas admitidas por el tamaño especificado. Si RandR no es compatible, devuelve 0 para el número de tasas.

XRRTimes devuelve la hora informada por última vez por el servidor junto con la marca de tiempo del último cambio de configuración. Si la configuración ha cambiado desde que el cliente actualizó por última vez su vista de la hora del servidor, las solicitudes para cambiar la configuración fallarán hasta que el cliente tenga una marca de tiempo actualizada.

XRRRootToScreen devuelve el número de pantalla dado una ventana raíz (por ejemplo, de un XRRScreenChangeNotifyEvent).

El resto de las funciones fallarán si se aplican a pantallas que no implementan la extensión RandR. XRRSetScreenConfig establece el tamaño de la pantalla y la rotación y reflexión a los valores deseados en la pantalla especificada por draw, o devuelve un error BadValue. size_index especifica qué configuración de tamaño se utilizará, rotation especifica qué rotación o reflexión se utilizará (o se devuelve un error BadValue). La timestamp es utilizada por el servidor para asegurarse de que el cliente tiene información de configuración actualizada. El estado se devuelve para indicar éxito o fracaso; un cliente debe actualizar su información de configuración si falla y volver a intentar la llamada (llamando a XRRGetScreenInfo).

XRRSetScreenConfigAndRate es como XRRSetScreenConfig pero también establece la frecuencia de actualización. Si la tasa especificada no es compatible, se devuelve un error BadValue.

XRRConfigRotations, XRRConfigSizes, XRRConfigCurrentConfiguration, XRRConfigTimes, XRRConfigRates, y XRRConfigCurrentRate se utilizan para obtener información de configuración específica de una configuración de pantalla.

XRRGetScreenInfo devuelve una configuración de pantalla para uso posterior; la información es privada de la biblioteca. Llame a XRRFreeScreenConfigInfo para liberar esta información cuando haya terminado con ella. Fuerza un viaje de ida y vuelta al servidor.

Otras funciones incluyen: XRRQueryExtension que devuelve los códigos base de eventos y errores, XRRQueryVersion, que devuelve la versión actual de la extensión (esta información está en caché por la biblioteca).

RESTRICCIONES

Xrandr seguirá siendo compatible con versiones anteriores después del lanzamiento actual 1.0.
