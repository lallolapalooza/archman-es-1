XReadBitmapFileData(3)

Paquete: libx11

Licencias: MIT AND X11

XReadBitmapFile(3) FUNCIONES DE XLIB XReadBitmapFile(3)

NOMBRE

XReadBitmapFile, XReadBitmapFileData, XWriteBitmapFile, XCreatePixmapFromBitmapData, XCreateBitmapFromData - manipular mapas de bits

SINTAXIS

int XReadBitmapFile(Display *display, Drawable d, _Xconst char *filename, unsigned int *width_return, unsigned int *height_return, Pixmap *bitmap_return, int *x_hot_return, int *y_hot_return);

int XReadBitmapFileData(_Xconst char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

int XWriteBitmapFile(Display *display, _Xconst char *filename, Pixmap bitmap, unsigned int width, unsigned int height, int x_hot, int y_hot);

Pixmap XCreatePixmapFromBitmapData(Display *display, Drawable d, char *data, unsigned int width, unsigned int height, unsigned long fg, unsigned long bg, unsigned int depth);

Pixmap XCreateBitmapFromData(Display *display, Drawable d, _Xconst char *data, unsigned int width, unsigned int height);

ARGUMENTOS

bitmap
Especifica el mapa de bits.
bitmap_return
Devuelve el mapa de bits que se crea.
d
Especifica el drawable que indica la pantalla.
data
Especifica los datos en formato de mapa de bits.
data
Especifica la ubicación de los datos del mapa de bits.
data_return
Devuelve los datos del mapa de bits.
depth
Especifica la profundidad del pixmap.
display
Especifica la conexión con el servidor X.
fg

bg
Especifican los valores de píxel de primer plano y fondo a usar.
filename
Especifica el nombre del archivo a usar. El formato del nombre de archivo depende del sistema operativo.
width

height
Especifican el ancho y alto.
width_return

height_return
Devuelven los valores de ancho y alto del archivo de mapa de bits leído.
x_hot

y_hot
Especifican dónde colocar las coordenadas del punto de acceso (o -1,-1 si no hay ninguna) en el archivo.
x_hot_return

y_hot_return
Devuelven las coordenadas del punto de acceso.

DESCRIPCIÓN

La función XReadBitmapFile lee un archivo que contiene un mapa de bits. El archivo se analiza en la codificación de la configuración regional actual. La capacidad de leer algo que no sea el formato estándar depende de la implementación. Si el archivo no se puede abrir, XReadBitmapFile devuelve BitmapOpenFailed. Si el archivo se puede abrir pero no contiene datos de mapa de bits válidos, devuelve BitmapFileInvalid. Si no se asigna suficiente memoria de trabajo, devuelve BitmapNoMemory. Si el archivo es legible y válido, devuelve BitmapSuccess.

XReadBitmapFile devuelve el alto y el ancho del mapa de bits, tal como se leen del archivo, a width_return y height_return. Luego crea un pixmap del tamaño apropiado, lee los datos del mapa de bits del archivo en el pixmap y asigna el pixmap a la variable bitmap del llamador. El llamador debe liberar el pixmap usando XFreePixmap cuando haya terminado. Si name_x_hot y name_y_hot existen, XReadBitmapFile los devuelve a x_hot_return y y_hot_return; de lo contrario, devuelve -1,-1.

XReadBitmapFile puede generar errores BadAlloc y BadDrawable.

La función XReadBitmapFileData lee un archivo que contiene un mapa de bits, de la misma manera que XReadBitmapFile, pero devuelve los datos directamente en lugar de crear un pixmap en el servidor. Los datos del mapa de bits se devuelven en data_return; el cliente debe liberar este almacenamiento cuando haya terminado llamando a XFree. El estado y otros valores de retorno son los mismos que para XReadBitmapFile.

La función XWriteBitmapFile escribe un mapa de bits en un archivo en el formato X versión 11. El nombre utilizado en el archivo de salida se deriva del nombre del archivo eliminando el prefijo del directorio. El archivo se escribe en la codificación de la configuración regional actual. Si el archivo no se puede abrir para escritura, devuelve BitmapOpenFailed. Si se asigna memoria insuficiente, XWriteBitmapFile devuelve BitmapNoMemory; de lo contrario, si no hay errores, devuelve BitmapSuccess. Si x_hot y y_hot no son -1, -1, XWriteBitmapFile los escribe como las coordenadas del punto de acceso para el mapa de bits.

XWriteBitmapFile puede generar errores BadDrawable y BadMatch.

La función XCreatePixmapFromBitmapData crea un pixmap de la profundidad dada y luego realiza un XPutImage con formato de mapa de bits de los datos en él. La profundidad debe ser compatible con la pantalla del drawable especificado, o se produce un error BadMatch.

XCreatePixmapFromBitmapData puede generar errores BadAlloc y BadMatch.

La función XCreateBitmapFromData le permite incluir en su programa C (usando #include) un archivo de mapa de bits que fue escrito por XWriteBitmapFile (solo formato X versión 11) sin leer el archivo de mapa de bits. El siguiente ejemplo crea un mapa de bits gris:

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

Si se asignó almacenamiento de trabajo insuficiente, XCreateBitmapFromData devuelve None. Es su responsabilidad liberar el mapa de bits usando XFreePixmap cuando haya terminado.

XCreateBitmapFromData puede generar un error BadAlloc.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadMatch
Se utiliza una ventana InputOnly como Drawable.

VER TAMBIÉN

XCreatePixmap(3), XPutImage(3)

XReadBitmapFileData(3)

NOMBRE

XReadBitmapFileData - lee datos de un archivo de mapa de bits

SINTAXIS

int XReadBitmapFileData(Display *display, const char *filename, unsigned int *width_return, unsigned int *height_return, unsigned char **data_return, int *x_hot_return, int *y_hot_return);

ARGUMENTOS

display

Especifica la conexión al servidor X.

filename

Especifica el nombre del archivo que contiene los datos del mapa de bits.

width_return

Devuelve el ancho del mapa de bits.

height_return

Devuelve la altura del mapa de bits.

data_return

Devuelve un puntero a los datos del mapa de bits. La memoria debe ser liberada por el llamante usando XFree().

x_hot_return

Devuelve la coordenada x del punto de acceso del mapa de bits.

y_hot_return

Devuelve la coordenada y del punto de acceso del mapa de bits.

DESCRIPCIÓN

La función XReadBitmapFileData() lee datos de un archivo de mapa de bits especificado por filename. Los datos del mapa de bits se leen en la memoria y se devuelve un puntero a ellos en data_return. También se devuelven el ancho, la altura y las coordenadas del punto de acceso del mapa de bits.

El archivo de mapa de bits debe estar en el formato X BitMap. El archivo puede contener información sobre el punto de acceso (hot-spot), que se devuelve en x_hot_return y y_hot_return. Si el archivo no contiene información de punto de acceso, se establecerán los valores de x_hot_return y y_hot_return en -1.

La memoria asignada para data_return debe ser liberada por el llamante usando XFree().

DIAGNÓSTICOS

XReadBitmapFileData() devuelve 0 si se produce un error, como no poder abrir el archivo o no poder leer los datos del mapa de bits. De lo contrario, devuelve un valor distinto de cero.

VER TAMBIÉN

XCreateBitmapFromData(3), XReadBitmapFile(3), XFree(3)
