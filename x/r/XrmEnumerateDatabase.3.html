XrmEnumerateDatabase(3)

Paquete: libx11

Licencias: MIT AND X11

XrmEnumerateDatabase(3) FUNCIONES DE XLIB XrmEnumerateDatabase(3)

NOMBRE

XrmEnumerateDatabase - enumerar entradas de la base de datos de recursos

SINTAXIS

#include <X11/Xresource.h>

#define XrmEnumAllLevels 0
#define XrmEnumOneLevel 1

Bool XrmEnumerateDatabase(XrmDatabase database, XrmNameList name_prefix, XrmClassList class_prefix, int mode, Bool (*proc)(), XPointer arg);

ARGUMENTOS

database
Especifica la base de datos de recursos.
name_prefix
Especifica el prefijo del nombre del recurso.
class_prefix
Especifica el prefijo de la clase del recurso.
mode
Especifica el número de niveles a enumerar.
proc
Especifica el procedimiento que se llamará para cada entrada coincidente.
arg
Especifica el argumento proporcionado por el usuario que se pasará al procedimiento.

DESCRIPCIÓN

La función XrmEnumerateDatabase llama al procedimiento especificado para cada recurso en la base de datos que coincidiría con alguna completación del prefijo de nombre/clase de recurso dado. El orden en el que se encuentran los recursos depende de la implementación. Si el modo es XrmEnumOneLevel, un recurso debe coincidir con el prefijo de nombre/clase dado con solo un nombre y una clase añadidos. Si el modo es XrmEnumAllLevels, el recurso debe coincidir con el prefijo de nombre/clase dado con uno o más nombres y clases añadidos. Si el procedimiento devuelve True, la enumeración termina y la función devuelve True. Si el procedimiento siempre devuelve False, se enumeran todos los recursos coincidentes y la función devuelve False.

El procedimiento se llama con los siguientes argumentos:

(*proc)(database, bindings, quarks, type, value, arg)
        XrmDatabase *database;
        XrmBindingList bindings;
        XrmQuarkList quarks;
        XrmRepresentation *type;
        XrmValue *value;
        XPointer arg;

Las listas de enlaces y quarks terminan con NULLQUARK. Tenga en cuenta que se pasan punteros a la base de datos y al tipo, pero estos valores no deben modificarse.

El procedimiento no debe modificar la base de datos. Si Xlib se ha inicializado para hilos, el procedimiento se llama con la base de datos bloqueada y el resultado de una llamada por parte del procedimiento a cualquier función Xlib que utilice la misma base de datos no está definido.
