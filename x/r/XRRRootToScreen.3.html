La estructura XRRScreenSize contiene un tamaño de raíz posible en píxeles y en milímetros.

Un XRRScreenChangeNotifyEvent se envía a un cliente que ha solicitado notificación cada vez que se cambia la configuración de pantalla. Un cliente puede realizar esta solicitud llamando a XRRSelectInput, pasando la pantalla, la ventana raíz y la máscara RRScreenChangeNotifyMask.

XRRScreenConfiguration es un tipo de datos opaco que contiene la información de configuración de una pantalla.

Marcas de tiempo

Se incluyen marcas de tiempo y deben usarse para garantizar que el cliente esté al día: la pantalla puede cambiar propiedades sobre la marcha y esto asegura que su conocimiento de la configuración esté actualizado. Esto es para ayudar con problemas cuando las pantallas pueden ser conectables en caliente en el futuro.

DESCRIPCIÓN

Xrandr es una biblioteca simple diseñada para interactuar con la Extensión X Resize and Rotate (Redimensionar y Rotar). Esto permite a los clientes cambiar el tamaño y la rotación de la ventana raíz de una pantalla, junto con la capacidad de reflejar la pantalla sobre cualquier eje (si es soportado por la implementación). La rotación y el reflejo pueden ser implementados por software y pueden resultar en un rendimiento más lento si la rotación y el reflejo se implementan de esta manera (como lo son todas las implementaciones en octubre de 2002).

La biblioteca Xrandr realiza un almacenamiento en caché mínimo para evitar viajes de ida y vuelta y proporcionar a los clientes información de uso frecuente. Consulte "The X Resize and Rotate Extension" para obtener una descripción detallada; también tenga en cuenta que el cambio de profundidad, como se describe en el documento, no está implementado y puede (o no) ser implementado, ya que la memoria de pantalla está creciendo rápidamente y las herramientas ya están empezando a soportar la migración, mitigando la necesidad de cambio de profundidad. Si se implementa en el futuro, esperamos hacerlo a través de una extensión compatible hacia arriba de la biblioteca/ protocolo actual; la funcionalidad descrita aquí debería seguir funcionando.

La rotación y el reflejo y cómo interactúan pueden ser confusos. En Randr, el sistema de coordenadas se rota en sentido antihorario con respecto a la orientación normal. El reflejo es a lo largo del sistema de coordenadas del sistema de ventanas, no los ejes X e Y físicos de la pantalla, de modo que la rotación y el reflejo no interactúen. La otra forma de considerar el reflejo es tratarlo como se especifica en la orientación "normal", antes de la rotación.

El evento XRRScreenChangeNotify se envía a los clientes que solicitan ser informados cada vez que cambian las configuraciones de la ventana raíz. Los cambios de configuración pueden incluir resolución, tamaño físico, orden de subpíxeles (ver XRender(3)) y rotación. Tenga en cuenta que los cambios en cualquiera o todos estos pueden ocurrir debido a eventos externos (control del usuario en el servidor X, conexión de un monitor/panel plano diferente) y no son solo el resultado de una solicitud de protocolo/ biblioteca al servidor X.

Además, para eliminar una posible condición de carrera, este evento puede generarse inmediatamente al seleccionar la notificación si la pantalla ha cambiado desde que el cliente de Xrandr se conectó al servidor X, para permitir un cambio de resolución de pantalla confiable cuando un usuario puede iniciar sesión y cambiar la configuración mientras uno o varios clientes están iniciando.

Notificación de Xlib

Los clientes deben llamar de nuevo a Xlib usando XRRUpdateConfiguration cuando se generan eventos de notificación de cambio de configuración de pantalla (o ocurren cambios de configuración de la ventana raíz, para actualizar la vista de Xlib de la resolución, tamaño, rotación, reflejo u orden de subpíxeles. Generalmente, las herramientas realizarán esta operación en nombre de las aplicaciones; no queríamos cambiar los datos de la estructura de visualización detrás de las herramientas, ya que en clientes multihilo, podrían ocurrir varias condiciones de carrera. Las herramientas deberían proporcionar a los clientes algún mecanismo para notificar el cambio de pantalla, por supuesto.

FUNCIONES

XRRQueryExtension:

Verifica si la extensión Xrandr está disponible en el servidor X y recupera las bases de eventos y errores.

XRRQueryVersion:

Consulta la versión del protocolo Xrandr implementado por el servidor.

XRRGetScreenInfo:

Obtiene la configuración de pantalla actual, incluyendo tamaños, rotaciones y frecuencias de actualización disponibles.

XRRFreeScreenConfigInfo:

Libera la memoria utilizada por la estructura XRRScreenConfiguration.

XRRSetScreenConfig:

Establece la configuración de pantalla, tamaño y rotación.

XRRSetScreenConfigAndRate:

Establece la configuración de pantalla, tamaño, rotación y frecuencia de actualización.

XRRConfigRotations:

Devuelve las rotaciones posibles y la rotación actual para una configuración de pantalla dada.

XRRConfigTimes:

Devuelve las marcas de tiempo de configuración para una configuración de pantalla dada.

XRRConfigSizes:

Devuelve los tamaños disponibles para una configuración de pantalla dada.

XRRConfigRates:

Devuelve las frecuencias de actualización disponibles para un tamaño dado en una configuración de pantalla.

XRRConfigCurrentConfiguration:

Devuelve el tamaño actual y la rotación de una configuración de pantalla dada.

XRRConfigCurrentRate:

Devuelve la frecuencia de actualización actual para una configuración de pantalla dada.

XRRRootToScreen:

Devuelve el número de pantalla asociado con una ventana raíz dada.

XRRSelectInput:

Selecciona qué eventos de Xrandr se deben enviar a una ventana específica.

XRRUpdateConfiguration:

Procesa los eventos de cambio de configuración de pantalla y actualiza la información interna de Xlib.

XRRRotations:

Devuelve las rotaciones posibles y la rotación actual para una pantalla específica (sin usar la estructura XRRScreenConfiguration).

XRRSizes:

Devuelve los tamaños disponibles para una pantalla específica (sin usar la estructura XRRScreenConfiguration).

XRRRates:

Devuelve las frecuencias de actualización disponibles para un tamaño dado en una pantalla específica (sin usar la estructura XRRScreenConfiguration).

XRRTimes:

Devuelve las marcas de tiempo de configuración para una pantalla específica (sin usar la estructura XRRScreenConfiguration).

NAME

XRRRootToScreen - obtener el número de pantalla a partir de una ventana raíz.

SYNTAX

   int XRRRootToScreen(Display *display, Window root);

ARGUMENTS

display
Especifica la conexión con el servidor X.
root
La ventana raíz para la cual se desea obtener el número de pantalla.

DATATYPES

Puede consultar la sección DESCRIPTION para más detalles.

DESCRIPTION

Hay dos clases de interfaces: aquellas que pueden llamarse de forma segura incluso si RandR no está implementado en una pantalla (para que los modismos comunes no dependan del soporte del servidor), y aquellas que devolverán errores si la extensión no está presente.

XRRRotations devuelve tanto el conjunto de rotaciones/reflexiones posibles compatibles (como una máscara de bits) como el valor de la función, junto con la rotación/reflexión actual de la pantalla.

XRRSizes devuelve el tamaño y un puntero a los tamaños actuales soportados por la pantalla especificada. El primer tamaño especificado es el tamaño predeterminado del servidor. Si RandR no es compatible, devuelve 0 para el número de tamaños.

XRRRates devuelve un puntero a las frecuencias compatibles con el tamaño especificado. Si RandR no es compatible, devuelve 0 para el número de frecuencias.

XRRTimes devuelve la hora reportada por última vez por el servidor junto con la marca de tiempo en la que la última configuración cambió. Si la configuración ha cambiado desde que el cliente actualizó por última vez su visión de la hora del servidor, las solicitudes para cambiar la configuración fallarán hasta que el cliente tenga una marca de tiempo actualizada.

XRRRootToScreen devuelve el número de pantalla dado una ventana raíz (por ejemplo, de un evento XRRScreenChangeNotifyEvent).

El resto de las funciones fallarán si se aplican a pantallas que no implementan la extensión RandR. XRRSetScreenConfig establece el tamaño de la pantalla y la rotación y reflexión a los valores deseados en la pantalla especificada por draw, o devuelve un error BadValue. size_index especifica qué configuración de tamaño se utilizará, rotation especifica qué rotación o reflexión se utilizará (o se devuelve un error BadValue). La timestamp es utilizada por el servidor para asegurarse de que el cliente tiene información de configuración actualizada. Se devuelve un estado para indicar éxito o fracaso; un cliente debe actualizar su información de configuración si falla y volver a intentar la llamada (llamando a XRRGetScreenInfo).

XRRSetScreenConfigAndRate es como XRRSetScreenConfig pero también establece la frecuencia de actualización. Si la frecuencia especificada no es compatible, se devuelve un error BadValue.

XRRConfigRotations, XRRConfigSizes, XRRConfigCurrentConfiguration, XRRConfigTimes, XRRConfigRates, y XRRConfigCurrentRate se utilizan para obtener información de configuración específica de una configuración de pantalla.

XRRGetScreenInfo devuelve una configuración de pantalla para su uso posterior; la información es privada de la biblioteca. Llame a XRRFreeScreenConfigInfo para liberar esta información cuando haya terminado con ella. Fuerza un viaje de ida y vuelta al servidor.

Otras funciones incluyen: XRRQueryExtension que devuelve las bases de código de eventos y errores, XRRQueryVersion, que devuelve la versión actual de la extensión (esta información es almacenada en caché por la biblioteca).

RESTRICTIONS

Xrandr seguirá siendo compatible hacia atrás después del lanzamiento actual 1.0.
