XrmQPutResource(3)

Paquete: libx11

Licencias: MIT AND X11

XrmPutResource(3) FUNCIONES DE XLIB XrmPutResource(3)

NOMBRE

XrmPutResource, XrmQPutResource, XrmPutStringResource, XrmQPutStringResource, XrmPutLineResource - almacenar recursos de la base de datos

SINTAXIS

#include <X11/Xresource.h>

void XrmPutResource(XrmDatabase *database, char *specifier, char *type, XrmValue *value);

void XrmQPutResource(XrmDatabase *database, XrmBindingList bindings, XrmQuarkList quarks, XrmRepresentation type, XrmValue *value);

void XrmPutStringResource(XrmDatabase *database, _Xconst char *specifier, _Xconst char *value);

void XrmQPutStringResource(XrmDatabase *database, XrmBindingList bindings, XrmQuarkList quarks, _Xconst char *value);

void XrmPutLineResource(XrmDatabase *database, _Xconst char *line);

ARGUMENTOS

bindings
Especifica una lista de enlaces.
database
Especifica la base de datos de recursos.
line
Especifica el nombre del recurso y el par de valores como una sola cadena.
quarks
Especifica el nombre completo o parcial o la lista de clases del recurso.
specifier
Especifica una especificación completa o parcial del recurso.
type
Especifica el tipo del recurso.
value
Especifica el valor del recurso, que se especifica como una cadena.

DESCRIPCIÓN

Si database contiene NULL, XrmPutResource crea una nueva base de datos y devuelve un puntero a ella. XrmPutResource es una función de conveniencia que llama a XrmStringToBindingQuarkList seguido de:

XrmQPutResource(database, bindings, quarks, XrmStringToQuark(type), value)

Si el especificador y el tipo no están en la codificación de caracteres portátil del host, el resultado depende de la implementación. El valor se almacena en la base de datos sin modificaciones.

Si database contiene NULL, XrmQPutResource crea una nueva base de datos y devuelve un puntero a ella. Si una entrada de recurso con los mismos enlaces y quarks ya existe en la base de datos, el tipo y valor anteriores son reemplazados por el nuevo tipo y valor especificados. El valor se almacena en la base de datos sin modificaciones.

Si database contiene NULL, XrmPutStringResource crea una nueva base de datos y devuelve un puntero a ella. XrmPutStringResource añade un recurso con el valor especificado a la base de datos especificada. XrmPutStringResource es una función de conveniencia que primero llama a XrmStringToBindingQuarkList sobre el especificador y luego llama a XrmQPutResource, utilizando un tipo de representación “String”. Si el especificador no está en la codificación de caracteres portátil del host, el resultado depende de la implementación. El valor se almacena en la base de datos sin modificaciones.

Si database contiene NULL, XrmQPutStringResource crea una nueva base de datos y devuelve un puntero a ella. XrmQPutStringResource es una rutina de conveniencia que construye un XrmValue para la cadena de valor (llamando a strlen para calcular el tamaño) y luego llama a XrmQPutResource, utilizando un tipo de representación “String”. El valor se almacena en la base de datos sin modificaciones.

Si database contiene NULL, XrmPutLineResource crea una nueva base de datos y devuelve un puntero a ella. XrmPutLineResource añade una única entrada de recurso a la base de datos especificada. La línea debe estar en el formato válido ResourceLine (ver sección 15.1) terminada por un carácter de nueva línea o nulo; la base de datos resultante del uso de una cadena con sintaxis incorrecta depende de la implementación. La cadena se analiza en la configuración regional de la base de datos. Si el ResourceName no está en la codificación de caracteres portátil del host, el resultado depende de la implementación. Tenga en cuenta que las líneas de comentario no se almacenan.
