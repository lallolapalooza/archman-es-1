XResetScreenSaver(3)

Paquete: libx11

Licencias: MIT AND X11

XSetScreenSaver(3) FUNCIONES DE XLIB XSetScreenSaver(3)

NOMBRE

XSetScreenSaver, XForceScreenSaver, XActivateScreenSaver, XResetScreenSaver, XGetScreenSaver - manipular el salvapantallas

SINTAXIS

int XSetScreenSaver(Display *display, int timeout, int interval, int prefer_blanking, int allow_exposures);

int XForceScreenSaver(Display *display, int mode);

int XActivateScreenSaver(Display *display);

int XResetScreenSaver(Display *display);

int XGetScreenSaver(Display *display, int *timeout_return, int *interval_return, int *prefer_blanking_return, int *allow_exposures_return);

ARGUMENTOS

allow_exposures
Especifica los valores de control del salvapantallas. Puedes pasar DontAllowExposures, AllowExposures o DefaultExposures.
allow_exposures_return
Devuelve el valor actual de control del salvapantallas (DontAllowExposures, AllowExposures o DefaultExposures).
display
Especifica la conexión con el servidor X.
interval
Especifica el intervalo, en segundos, entre alteraciones del salvapantallas.
interval_return
Devuelve el intervalo entre invocaciones del salvapantallas.
mode
Especifica el modo que se va a aplicar. Puedes pasar ScreenSaverActive o ScreenSaverReset.
prefer_blanking
Especifica cómo habilitar el oscurecimiento de pantalla. Puedes pasar DontPreferBlanking, PreferBlanking o DefaultBlanking.
prefer_blanking_return
Devuelve la preferencia actual de oscurecimiento de pantalla (DontPreferBlanking, PreferBlanking o DefaultBlanking).
timeout
Especifica el tiempo de espera, en segundos, hasta que se active el salvapantallas.
timeout_return
Devuelve el tiempo de espera, en segundos, hasta que se active el salvapantallas.

DESCRIPCIÓN

El tiempo de espera y el intervalo se especifican en segundos. Un tiempo de espera de 0 desactiva el salvapantallas (pero no desactiva un salvapantallas activado), y un tiempo de espera de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. Si el valor del tiempo de espera no es cero, XSetScreenSaver habilita el salvapantallas. Un intervalo de 0 deshabilita el movimiento de patrones aleatorios. Ambos valores están limitados a un rango de entero con signo de 16 bits por el protocolo de red, a pesar del prototipo C. Si no se genera ninguna entrada de los dispositivos (teclado, ratón, etc.) durante el número especificado de segundos de tiempo de espera una vez que se habilita el salvapantallas, este se activa.

Para cada pantalla, si se prefiere el oscurecimiento y el hardware soporta el oscurecimiento de video, la pantalla simplemente se oscurece. De lo contrario, si se permiten las exposiciones o la pantalla puede regenerarse sin enviar eventos Expose a los clientes, la pantalla se rellena con el mosaico de fondo de la ventana raíz con el origen reubicado aleatoriamente cada intervalo de segundos. De lo contrario, los estados de la pantalla no cambian y el salvapantallas no se activa. El salvapantallas se desactiva y todos los estados de la pantalla se restauran en la siguiente entrada de teclado o puntero o en la siguiente llamada a XForceScreenSaver con el modo ScreenSaverReset.

Si el método del salvapantallas específico del servidor admite cambios periódicos, el argumento interval sirve como una indicación de la duración del período de cambio, y cero indica que no se debe realizar ningún cambio periódico. Ejemplos de formas de cambiar la pantalla incluyen mezclar el mapa de colores periódicamente, mover una imagen de icono por la pantalla periódicamente o rellenar la pantalla con el mosaico de fondo de la ventana raíz, con el origen reubicado aleatoriamente periódicamente.

XSetScreenSaver puede generar un error BadValue.

Si el modo especificado es ScreenSaverActive y el salvapantallas está actualmente desactivado, XForceScreenSaver activa el salvapantallas incluso si se había deshabilitado con un tiempo de espera de cero. Si el modo especificado es ScreenSaverReset y el salvapantallas está actualmente habilitado, XForceScreenSaver desactiva el salvapantallas si estaba activado y el temporizador de activación se restablece a su estado inicial (como si se hubieran recibido entradas del dispositivo).

XForceScreenSaver puede generar un error BadValue.

La función XActivateScreenSaver activa el salvapantallas.

La función XResetScreenSaver restablece el salvapantallas.

La función XGetScreenSaver obtiene los valores actuales del salvapantallas.

DIAGNÓSTICOS

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
