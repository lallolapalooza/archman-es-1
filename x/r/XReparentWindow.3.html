XReparentWindow(3) FUNCIONES DE XLIB XReparentWindow(3)

NOMBRE

XReparentWindow - cambiar la ventana principal de las ventanas

SINTAXIS

int XReparentWindow(Display *display, Window w, Window parent, int x, int y);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
parent
Especifica la ventana principal.
w
Especifica la ventana.
x

y
Especifica las coordenadas x e y de la posición en la nueva ventana principal.

DESCRIPCIÓN

Si la ventana especificada está visible (mapped), XReparentWindow realiza automáticamente una solicitud UnmapWindow sobre ella, la elimina de su posición actual en la jerarquía y la inserta como hija de la ventana principal especificada. La ventana se coloca en el orden de apilamiento sobre las ventanas hermanas.

Después de cambiar la ventana principal especificada, XReparentWindow hace que el servidor X genere un evento ReparentNotify. El miembro override_redirect devuelto en este evento se establece en el atributo correspondiente de la ventana. Los clientes del gestor de ventanas normalmente deberían ignorar esta ventana si este miembro está establecido a True. Finalmente, si la ventana especificada estaba originalmente visible, el servidor X realiza automáticamente una solicitud MapWindow sobre ella.

El servidor X realiza el procesamiento normal de exposición en las ventanas previamente ocultas. El servidor X podría no generar eventos Expose para las regiones de la solicitud inicial UnmapWindow que queden inmediatamente ocultas por la solicitud final MapWindow. Se produce un error BadMatch si:

  • La nueva ventana principal no está en la misma pantalla que la antigua ventana principal.
  • La nueva ventana principal es la ventana especificada o una inferior de la ventana especificada.
  • El nuevo padre es InputOnly y la ventana no lo es.
  • La ventana especificada tiene un fondo ParentRelative y la nueva ventana principal no tiene la misma profundidad que la ventana especificada.

XReparentWindow puede generar errores BadMatch y BadWindow.

DIAGNÓSTICOS

BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
