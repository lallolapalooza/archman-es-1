NOMBRE

XrmUniqueQuark, XrmStringToQuark, XrmPermStringToQuark, XrmQuarkToString, XrmStringToQuarkList, XrmStringToBindingQuarkList - manipular quarks de recursos

SINOPSIS

#include <X11/Xresource.h>

XrmQuark XrmUniqueQuark(void);

#define XrmStringToName(string) XrmStringToQuark(string)
#define XrmStringToClass(string) XrmStringToQuark(string)
#define XrmStringToRepresentation(string) XrmStringToQuark(string)

XrmQuark XrmStringToQuark(char *string);

XrmQuark XrmPermStringToQuark(_Xconst char *string);

#define XrmStringToName(string) XrmStringToQuark(string)
#define XrmStringToClass(string) XrmStringToQuark(string)
#define XrmStringToRepresentation(string) XrmStringToQuark(string)

XrmQuark XrmStringToQuark(char *string);

XrmQuark XrmPermStringToQuark(_Xconst char *string);

#define XrmNameToString(name) XrmQuarkToString(name)
#define XrmClassToString(class) XrmQuarkToString(class)
#define XrmRepresentationToString(type) XrmQuarkToString(type)

char *XrmQuarkToString(XrmQuark quark);

#define XrmStringToNameList(str, name) XrmStringToQuarkList((str), (name))
#define XrmStringToClassList(str,class) XrmStringToQuarkList((str), (class))

void XrmStringToQuarkList(char *string, XrmQuarkList quarks_return);

void XrmStringToBindingQuarkList(_Xconst char *string, XrmBindingList bindings_return, XrmQuarkList quarks_return);

ARGUMENTOS

bindings_return
Devuelve la lista de enlaces.
quark
Especifica el quark para el que se desea la cadena equivalente.
quarks_return
Devuelve la lista de quarks.
string
Especifica la cadena para la que se va a asignar un quark o una lista de quarks.

DESCRIPCIÓN

La función XrmUniqueQuark asigna un quark que se garantiza que no representa ninguna cadena conocida por el gestor de recursos.

Estas funciones se pueden utilizar para convertir de cadena a representación de quark. Si la cadena no está en la Codificación de Caracteres Portátil del Host, la conversión depende de la implementación. La cadena argumento para XrmStringToQuark no necesita ser almacenamiento permanentemente asignado. XrmPermStringToQuark es igual que XrmStringToQuark, excepto que a Xlib se le permite asumir que la cadena argumento está permanentemente asignada y, por lo tanto, que puede utilizarse como el valor que será devuelto por XrmQuarkToString.

Para cualquier quark dado, si XrmStringToQuark devuelve un valor no NULL, todas las llamadas futuras devolverán el mismo valor (dirección idéntica).

Estas funciones se pueden utilizar para convertir de representación de quark a cadena. La cadena apuntada por el valor devuelto no debe ser modificada ni liberada. La cadena devuelta es byte por byte igual a la cadena original pasada a una de las rutinas de cadena a quark. Si no existe ninguna cadena para ese quark, XrmQuarkToString devuelve NULL. Para cualquier quark dado, si XrmQuarkToString devuelve un valor no NULL, todas las llamadas futuras devolverán el mismo valor (dirección idéntica).

Estas funciones se pueden utilizar para convertir de cadena a representación de quark. Si la cadena no está en la Codificación de Caracteres Portátil del Host, la conversión depende de la implementación. La cadena argumento para XrmStringToQuark no necesita ser almacenamiento permanentemente asignado. La función XrmStringToQuarkList convierte la cadena terminada en nulo (generalmente un nombre completamente calificado) en una lista de quarks. El llamante debe asignar suficiente espacio para la lista de quarks antes de llamar a XrmStringToQuarkList. Tenga en cuenta que la cadena debe estar en el formato válido de Nombre de Recurso (ver sección 15.1). Si la cadena no está en la Codificación de Caracteres Portátil del Host, la conversión depende de la implementación.

Una lista de enlaces es una lista de tipo XrmBindingList e indica si los componentes de las listas de nombres o clases están enlazados estrictamente o de forma laxa (es decir, si se especifica el uso de comodines para componentes intermedios).

typedef enum {XrmBindTightly, XrmBindLoosely} XrmBinding, *XrmBindingList;

XrmBindTightly indica que un punto separa los componentes, y XrmBindLoosely indica que un asterisco separa los componentes.

La función XrmStringToBindingQuarkList convierte la cadena especificada en una lista de enlaces y una lista de quarks. El llamante debe asignar suficiente espacio para la lista de quarks y la lista de enlaces antes de llamar a XrmStringToBindingQuarkList. Si la cadena no está en la Codificación de Caracteres Portátil del Host, la conversión depende de la implementación. Los nombres de componentes en la lista están separados por un punto o un carácter asterisco. Si la cadena no comienza con un punto o un asterisco, se asume un punto. Por ejemplo, “*a.b*c” se convierte en:

quarks a b c
enlaces laxo estricto laxo
