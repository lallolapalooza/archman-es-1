XrmOptionKind(3)

Paquete: libx11

Licencias: MIT AND X11

XrmInitialize(3) FUNCIONES DE XLIB XrmInitialize(3)

NOMBRE

XrmInitialize, XrmParseCommand, XrmValue, XrmOptionKind, XrmOptionDescRec - inicializar el gestor de recursos, las estructuras del gestor de recursos y analizar la línea de comandos

SINTAXIS

#include <X11/Xresource.h>

void XrmInitialize(void);

void XrmParseCommand(XrmDatabase *database, XrmOptionDescList table, int table_count, _Xconst char *name, int *argc_in_out, char **argv_in_out);

ARGUMENTOS

argc_in_out
Especifica el número de argumentos y devuelve el número de argumentos restantes.
argv_in_out
Especifica los argumentos de la línea de comandos y devuelve los argumentos restantes.
database
Especifica la base de datos de recursos.
name
Especifica el nombre de la aplicación.
table
Especifica la tabla de argumentos de la línea de comandos que se va a analizar.
table_count
Especifica el número de entradas en la tabla.

DESCRIPCIÓN

La función XrmInitialize inicializa el gestor de recursos. Debe llamarse antes de utilizar cualquier otra función de Xrm.

La función XrmParseCommand analiza un par (argc, argv) según la tabla de opciones especificada, carga las opciones reconocidas en la base de datos especificada con el tipo "String" y modifica el par (argc, argv) para eliminar todas las opciones reconocidas. Si la base de datos contiene NULL, XrmParseCommand crea una nueva base de datos y devuelve un puntero a ella. De lo contrario, se añaden entradas a la base de datos especificada. Si se crea una base de datos, se crea en la configuración regional actual.

La tabla especificada se utiliza para analizar la línea de comandos. Las opciones reconocidas en la tabla se eliminan de argv y se añaden entradas a la base de datos de recursos especificada en el orden en que aparecen en argv. Las entradas de la tabla contienen información sobre la cadena de la opción, el nombre de la opción, el estilo de la opción y un valor a proporcionar si el tipo de opción es XrmoptionNoArg. Los nombres de las opciones se comparan byte por byte con los argumentos de argv, independientemente de la configuración regional. Los valores de recursos proporcionados en la tabla se almacenan en la base de datos de recursos sin modificación. Todas las entradas de la base de datos de recursos se crean utilizando una representación de tipo "String". El argumento argc especifica el número de argumentos en argv y se establece al regresar al número restante de argumentos que no fueron analizados. El argumento name debería ser el nombre de su aplicación para su uso en la construcción de la entrada de la base de datos. El argumento name se antepone al resourceName en la tabla de opciones antes de almacenar una entrada en la base de datos. El argumento name se trata como un único componente, incluso si tiene puntos incrustados. No se inserta ningún carácter de separación (enlace), por lo que la tabla debe contener un punto (.) o un asterisco (*) como primer carácter en cada entrada resourceName. Para especificar un nombre de recurso más completamente calificado, la entrada resourceName puede contener múltiples componentes. Si el argumento name y los resourceNames no están en la codificación de caracteres portátil del host, el resultado es dependiente de la implementación.

ESTRUCTURAS

Las estructuras XrmValue, XrmOptionKind y XrmOptionDescRec contienen:

typedef struct {
        unsigned int size;
        XPointer addr;
} XrmValue, *XrmValuePtr;
typedef enum {
        XrmoptionNoArg, /* El valor se especifica en XrmOptionDescRec.value */
        XrmoptionIsArg, /* El valor es la propia cadena de la opción */
        XrmoptionStickyArg,     /* El valor son los caracteres inmediatamente posteriores a la opción */
        XrmoptionSepArg,        /* El valor es el siguiente argumento en argv */
        XrmoptionResArg,        /* Recurso y valor en el siguiente argumento en argv */
        XrmoptionSkipArg,       /* Ignorar esta opción y el siguiente argumento en argv */
        XrmoptionSkipLine,      /* Ignorar esta opción y el resto de argv */
        XrmoptionSkipNArgs      /* Ignorar esta opción y los siguientes
                   argumentos XrmOptionDescRec.value en argv */
} XrmOptionKind;
typedef struct {
        char *option;   /* Cadena de especificación de opción en argv                    */
        char *specifier;        /* Nombre de enlace y recurso (sin el nombre de la aplicación)    */
        XrmOptionKind argKind;  /* Qué estilo de opción es            */
        XPointer value; /* Valor a proporcionar si XrmoptionNoArg o
                   XrmoptionSkipNArgs   */
} XrmOptionDescRec, *XrmOptionDescList;
