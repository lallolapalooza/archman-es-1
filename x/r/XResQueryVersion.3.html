XResQueryVersion(3)

Paquete: libxres

Licencias: X11

XRes(3) X Version 11 XRes(3)

NOMBRE

XRes - Biblioteca cliente de la extensión X-Resource

SINOPSIS

#include <X11/extensions/XRes.h>

typedef struct {
	XID	resource_base;
	XID	resource_mask;
} XResClient;

typedef struct {
	Atom	resource_type;
	unsigned int	count;
} XResType;
Bool XResQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XResQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
Status XResQueryClients(Display *dpy,
    int *num_clients, XResClient **clients);
Status XResQueryClientResources(Display *dpy, XID xid,
    int *num_types, XResType **types);
Status XResQueryClientPixmapBytes(Display *dpy, XID xid,
    unsigned long *bytes);

DESCRIPCIÓN

La X-Resource es una extensión que permite a un cliente consultar al servidor X sobre su uso de varios recursos. No debe confundirse con las funciones de acceso a la base de datos de recursos X.

XResQueryExtension devuelve True si la extensión XRes está disponible en la pantalla dada. Un cliente debe llamar a XResQueryExtension antes de llamar a cualquier otra función de XRes para negociar una versión de protocolo compatible; de lo contrario, el cliente obtendrá un comportamiento indefinido (XRes puede funcionar o no).

XResQueryVersion devuelve True si la solicitud tuvo éxito; los valores de las versiones de protocolo principal y secundaria admitidas por el servidor se devuelven en major_version_return y minor_version_return.

XResQueryClients llena una lista de clientes de la pantalla dada. Para cada cliente, devuelve en la estructura XResClient una máscara y un valor base de los recursos utilizados por estos clientes. Devuelve True si tiene éxito o False si falla.

XResQueryClientResources llena una lista de estructuras XResType, indicando para cada tipo de recurso asignado por el cliente su nombre (como un Atom) y el número de recursos de este tipo asignados. Devuelve True si tiene éxito o False si falla.

XResQueryClientPixmapBytes proporciona, para los recursos del tipo PIXMAP, el número total de bytes asignados en el servidor X por el cliente dado. Devuelve True si tiene éxito o False si falla.

ERRORES

XResQueryClientResources y XResQueryClientPixmapBytes devolverán BadValue si se les pasa un identificador de cliente ilegal.
