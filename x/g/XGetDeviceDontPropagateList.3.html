XGetDeviceDontPropagateList(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XCHANGEDEVICEDONTPRO(3)   XCHANGEDEVICEDONTPRO(3)

NOMBRE

XChangeDeviceDontPropagateList, XGetDeviceDontPropagateList - consultar o cambiar la lista de no propagación para dispositivos de extensión

SINOPSIS

#include <X11/extensions/XInput.h>
int XChangeDeviceDontPropagateList( Display *display,
                                    Window window,
                                    int count,
                                    XEventClass *event_list,
                                    int mode);
XEventClass* XGetDeviceDontPropagateList( Display *display,
                                          Window window,
                                          int *count);
display
       Especifica la conexión al servidor X.
window
       Especifica la ventana cuya lista de no propagación se va a
       consultar o modificar.
event_list
       Especifica un puntero a una lista de clases de eventos.
mode
       Especifica el modo. Puede pasar AddToList o
       DeleteFromList.
count
       Especifica el número de clases de eventos en la lista.

DESCRIPCIÓN

La solicitud XChangeDeviceDontPropagateList modifica la lista de
eventos que no deben propagarse a los ancestros de la ventana de
evento. Esta solicitud permite añadir o eliminar eventos de
extensión de esa lista. Por defecto, todos los eventos se propagan
a las ventanas ancestro. Una vez modificada, la lista permanece
modificada durante la vida útil de la ventana. Los eventos no se
eliminan de la lista porque el cliente que los añadió haya
terminado.
La supresión de la propagación de eventos no está permitida para
todos los eventos de extensión de entrada. Si una clase de evento
especificada es una que no se puede suprimir, se producirá un error
BadClass. Los eventos que se pueden suprimir incluyen DeviceKeyPress,
DeviceKeyRelease, DeviceButtonPress, DeviceButtonRelease,
DeviceMotionNotify, ProximityIn y ProximityOut.
XChangeDeviceDontPropagateList puede generar un error BadDevice,
BadClass o BadValue.
La solicitud XGetDeviceDontPropagateList consulta la lista de
eventos que no deben propagarse a los ancestros de la ventana de
evento.
XGetDeviceDontPropagateList puede generar un error BadClass o
BadWindow.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo
       especificado no existe o no ha sido abierto por este cliente
       a través de XOpenInputDevice. Este error también puede
       ocurrir si algún otro cliente ha provocado que el dispositivo
       especificado se convierta en el dispositivo de teclado X o
       puntero X a través de las solicitudes
       XChangeKeyboardDevice o XChangePointerDevice.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un
       rango específico para un argumento, se acepta el rango
       completo definido por el tipo del argumento. Cualquier
       argumento definido como un conjunto de alternativas puede
       generar este error.
BadWindow
       Se especificó un ID de ventana no válido.
BadClass
       Se especificó una clase de evento no válida.
