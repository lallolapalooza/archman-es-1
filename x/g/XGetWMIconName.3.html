Paquete: libx11

XSetWMIconName(3) FUNCIONES DE XLIB XSetWMIconName(3)

NOMBRE

XSetWMIconName, XGetWMIconName, XSetIconName, XGetIconName - establecer o leer la propiedad WM_ICON_NAME de una ventana

SINTAXIS

void XSetWMIconName(Display *display, Window w, XTextProperty *text_prop);

Status XGetWMIconName(Display *display, Window w, XTextProperty *text_prop_return);

int XSetIconName(Display *display, Window w, _Xconst char *icon_name);

Status XGetIconName(Display *display, Window w, char **icon_name_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
icon_name
Especifica el nombre del icono, que debe ser una cadena terminada en nulo.
icon_name_return
Devuelve el nombre del icono de la ventana, que es una cadena terminada en nulo.
text_prop
Especifica la estructura XTextProperty a utilizar.
text_prop_return
Devuelve la estructura XTextProperty.
w
Especifica la ventana.

DESCRIPCIÓN

La función de conveniencia XSetWMIconName llama a XSetTextProperty para establecer la propiedad WM_ICON_NAME.

La función de conveniencia XGetWMIconName llama a XGetTextProperty para obtener la propiedad WM_ICON_NAME. Devuelve un estado distinto de cero en caso de éxito; de lo contrario, devuelve un estado cero.

La función XSetIconName establece el nombre que se mostrará en el icono de una ventana.

XSetIconName puede generar errores BadAlloc y BadWindow.

La función XGetIconName devuelve el nombre que se mostrará en el icono de la ventana especificada. Si tiene éxito, devuelve un estado distinto de cero; de lo contrario, si no se ha establecido ningún nombre de icono para la ventana, devuelve cero. Si nunca asignó un nombre a la ventana, XGetIconName establece icon_name_return a NULL. Si los datos devueltos por el servidor están en la codificación de caracteres portátil Latin, la cadena devuelta está en la codificación de caracteres portátil del host. De lo contrario, el resultado depende de la implementación. Cuando haya terminado con él, un cliente debe liberar la cadena del nombre del icono usando XFree.

XGetIconName puede generar un error BadWindow.

PROPIEDADES

WM_ICON_NAME
El nombre que se utilizará en un icono.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
