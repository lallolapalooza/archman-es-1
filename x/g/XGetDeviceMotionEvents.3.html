XGetDeviceMotionEvents(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGETDEVICEMOTIONEVEN(3)   XGETDEVICEMOTIONEVEN(3)

NOMBRE

XGetDeviceMotionEvents, XDeviceTimeCoord - obtener historial de movimiento del dispositivo

SINOPSIS

#include <X11/extensions/XInput.h>
XDeviceTimeCoord *XGetDeviceMotionEvents( Display *display,
                                          XDevice *device,
                                          Time start,
                                          Time stop,
                                          int *nevents_return,
                                          int *mode_return,
                                          int *axis_count_return);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyo historial de movimiento se
       va a consultar.
start, stop
       Especifican el intervalo de tiempo en el que se devuelven
       los eventos del búfer de historial de movimiento. Puede
       pasar una marca de tiempo o CurrentTime.
nevents_return
       Devuelve el número de eventos del búfer de historial de
       movimiento.
mode_return
       Devuelve el modo del dispositivo (Absoluto o Relativo).
axis_count_return
       Devuelve el recuento de ejes que se están reportando.

DESCRIPCIÓN

El servidor puede retener el historial reciente del movimiento del
dispositivo y hacerlo con una granularidad más fina que la
reportada por los eventos DeviceMotionNotify. La solicitud
XGetDeviceMotionEvents hace que este historial esté disponible.
La solicitud XGetDeviceMotionEvents devuelve todos los eventos en el
búfer de historial de movimiento que caen entre los tiempos de
inicio y fin especificados, ambos inclusive. Si el tiempo de
inicio es posterior al tiempo de fin o si el tiempo de inicio
está en el futuro, no se devuelven eventos. Si el tiempo de fin
está en el futuro, es equivalente a especificar CurrentTime.
El modo indica si el dispositivo está reportando datos de
posición absoluta (mode = Absolute) o datos de movimiento
relativo (mode = Relative). Algunos dispositivos permiten que su
modo se cambie mediante la solicitud XSetDeviceMode. Estas
constantes están definidas en el archivo XI.h. El axis_count
devuelve el número de ejes o valoradores que está reportando el
dispositivo.
XGetDeviceMotionEvents puede generar un error BadDevice o
BadMatch.

Estructuras

La estructura XDeviceTimeCoord contiene:
typedef struct {
    Time time;
    int *data;
} XDeviceTimeCoord;
El miembro time se establece a la hora, en milisegundos. El
miembro data es un puntero a una matriz de enteros. Estos
enteros se establecen a los valores de cada valorador o eje
reportado por el dispositivo. Hay un elemento en la matriz por
cada eje de movimiento reportado por el dispositivo. El valor
de los elementos de la matriz depende del modo del dispositivo.
Si el modo es Absoluto, los valores son los valores brutos
generados por el dispositivo. Estos pueden ser escalados por
programas cliente utilizando los valores máximos que el
dispositivo puede generar. El valor máximo para cada eje del
dispositivo se reporta en el campo max_val de la XAxisInfo
devuelta por la solicitud XListInputDevices. Si el modo es
Relativo, los valores de los datos son los valores relativos
generados por el dispositivo.
Debe usar XFreeDeviceMotionEvents para liberar los datos
devueltos por esta solicitud.
Errores devueltos por esta solicitud: BadDevice, BadMatch.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo
       especificado no existe o no ha sido abierto por este
       cliente a través de XOpenInputDevice. Este error también
       puede ocurrir si el dispositivo especificado es el teclado
       o el dispositivo de puntero X.
BadMatch
       Este error puede ocurrir si se realiza una solicitud
       XGetDeviceMotionEvents especificando un dispositivo que no
       tiene valoradores y no reporta ejes de movimiento.
