XLoadFont(3) FUNCIONES DE XLIB XLoadFont(3)

NOMBRE

XLoadFont, XQueryFont, XLoadQueryFont, XFreeFont, XGetFontProperty, XUnloadFont, XCharStruct, XFontProp, XChar2b, XFontStruct - cargar o descargar fuentes y estructuras de métricas de fuentes

SINTAXIS

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

ARGUMENTOS

atom
Especifica el átomo para el nombre de la propiedad que desea obtener.
display
Especifica la conexión con el servidor X.
font
Especifica la fuente.
font_ID
Especifica el ID de la fuente o el ID del GContext.
font_struct
Especifica el almacenamiento asociado con la fuente.
gc
Especifica el GC.
name
Especifica el nombre de la fuente, que es una cadena terminada en nulo.
value_return
Devuelve el valor de la propiedad de la fuente.

DESCRIPCIÓN

La función XLoadFont carga la fuente especificada y devuelve su ID de fuente asociado. Si el nombre de la fuente no está en la codificación de caracteres portátil del host (Host Portable Character Encoding), el resultado es dependiente de la implementación. El uso de mayúsculas o minúsculas no importa. Cuando los caracteres “?” y “” se utilizan en un nombre de fuente, se realiza una coincidencia de patrones y se utiliza cualquier fuente coincidente. En el patrón, el carácter “?” coincidirá con cualquier carácter individual, y el carácter “” coincidirá con cualquier número de caracteres. Un formato estructurado para los nombres de fuentes se especifica en las convenciones de descripción de fuentes lógicas X del estándar del Consorcio X (X Logical Font Description Conventions). Si XLoadFont no tuvo éxito al cargar la fuente especificada, se produce un error BadName. Las fuentes no están asociadas con una pantalla particular y pueden almacenarse como un componente de cualquier GC. Cuando la fuente ya no sea necesaria, llame a XUnloadFont.

XLoadFont puede generar errores BadAlloc y BadName.

La función XQueryFont devuelve un puntero a la estructura XFontStruct, que contiene información asociada con la fuente. Puede consultar una fuente o la fuente almacenada en un GC. El ID de fuente almacenado en la estructura XFontStruct será el ID del GContext, y deberá tener cuidado al usar este ID en otras funciones (consulte XGContextFromGC). Si la fuente no existe, XQueryFont devuelve NULL. Para liberar estos datos, use XFreeFontInfo.

XLoadQueryFont puede generar un error BadAlloc.

La función XLoadQueryFont proporciona la forma más común de acceder a una fuente. XLoadQueryFont abre (carga) la fuente especificada y devuelve un puntero a la estructura XFontStruct apropiada. Si el nombre de la fuente no está en la codificación de caracteres portátil del host, el resultado es dependiente de la implementación. Si la fuente no existe, XLoadQueryFont devuelve NULL.

La función XFreeFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada, y libera la estructura XFontStruct. La fuente en sí se liberará cuando ningún otro recurso la referencie. Los datos y la fuente no deben volver a ser referenciados.

XFreeFont puede generar un error BadFont.

Dado el átomo para esa propiedad, la función XGetFontProperty devuelve el valor de la propiedad de fuente especificada. XGetFontProperty también devuelve False si la propiedad no estaba definida o True si estaba definida. Un conjunto de átomos predefinidos existe para las propiedades de fuentes, que se pueden encontrar en X11/Xatom.h. Este conjunto contiene las propiedades estándar asociadas con una fuente. Aunque no está garantizado, es probable que las propiedades de fuente predefinidas estén presentes.

La función XUnloadFont elimina la asociación entre el ID del recurso de fuente y la fuente especificada. La fuente en sí se liberará cuando ningún otro recurso la referencie. La fuente no debe volver a ser referenciada.

XUnloadFont puede generar un error BadFont.

ESTRUCTURAS

La estructura XFontStruct contiene toda la información de la fuente y consta de la información específica de la fuente, así como de un puntero a una matriz de estructuras XCharStruct para los caracteres contenidos en la fuente. Las estructuras XFontStruct, XFontProp y XCharStruct contienen:

typedef struct {
	short lbearing;	/* origen al borde izquierdo del raster */
	short rbearing;	/* origen al borde derecho del raster */
	short width;	/* avance al origen del siguiente carácter */
	short ascent;	/* línea base a borde superior del raster */
	short descent;	/* línea base a borde inferior del raster */
	unsigned short attributes;	/* flags por carácter (no predefinidos) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* los caracteres normales de 16 bits son de dos bytes */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* gancho para que la extensión cuelgue datos */
	Font fid;	/* ID de fuente para esta fuente */
	unsigned direction;	/* pista sobre la dirección en la que se pinta la fuente */
	unsigned min_char_or_byte2;	/* primer carácter */
	unsigned max_char_or_byte2;	/* último carácter */
	unsigned min_byte1;	/* primera fila que existe */
	unsigned max_byte1;	/* última fila que existe */
	Bool all_chars_exist;	/* flag si todos los caracteres tienen tamaño distinto de cero */
	unsigned default_char;	/* carácter para imprimir para caracteres indefinidos */
	int n_properties;	/* cuántas propiedades hay */
	XFontProp *properties;	/* puntero a matriz de propiedades adicionales */
	XCharStruct min_bounds;	/* límites mínimos de todos los caracteres existentes */
	XCharStruct max_bounds;	/* límites máximos de todos los caracteres existentes */
	XCharStruct *per_char;	/* información de first_char a last_char */
	int ascent;	/* extensión lógica por encima de la línea base para espaciado */
	int descent;	/* descenso lógico por debajo de la línea base para espaciado */
} XFontStruct;

X soporta operaciones de texto de un solo byte/carácter, matriz de dos bytes/carácter y de 16 bits por carácter. Tenga en cuenta que cualquiera de estas formas puede usarse con una fuente, pero una solicitud de texto de un solo byte/carácter solo puede especificar un solo byte (es decir, la primera fila de una fuente de 2 bytes). Debe considerar las fuentes de 2 bytes como una matriz bidimensional de caracteres definidos: byte1 especifica el rango de filas definidas y byte2 define el rango de columnas definidas de la fuente. Las fuentes de un solo byte/carácter tienen una fila definida, y el rango de byte2 especificado en la estructura define un rango de caracteres.

El cuadro delimitador de un carácter se define mediante la XCharStruct de ese carácter. Cuando faltan caracteres en una fuente, se utiliza el default_char. Cuando las fuentes tienen todos los caracteres del mismo tamaño, solo se utilizan las informaciónes en los límites mínimo y máximo de XFontStruct.

Los miembros de XFontStruct tienen las siguientes semánticas:

  • El miembro direction puede ser FontLeftToRight o FontRightToLeft. Es solo una pista sobre si la mayoría de los elementos XCharStruct tienen una métrica de ancho de carácter positiva (FontLeftToRight) o negativa (FontRightToLeft). El protocolo central no define soporte para texto vertical.
  • Si los miembros min_byte1 y max_byte1 son ambos cero, min_char_or_byte2 especifica el índice lineal de carácter correspondiente al primer elemento de la matriz per_char, y max_char_or_byte2 especifica el índice lineal de carácter del último elemento.
Si min_byte1 o max_byte1 son distintos de cero, tanto min_char_or_byte2 como max_char_or_byte2 son menores que 256, y los valores del índice de carácter de 2 bytes correspondientes al elemento N de la matriz per_char (contando desde 0) son:
byte1 = N/D + min_byte1
byte2 = N\D + min_char_or_byte2
donde: 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = división entera
        \
y N\D representa el resto de la división.

Para calcular el índice lineal N para un índice de carácter de 2 bytes dado, utilice:

N = (byte1 - min_byte1) * D + (byte2 - min_char_or_byte2)
donde D es el mismo que se definió anteriormente.

\ = módulo de enteros
  • Si el puntero per_char es NULL, todas las glifos entre los índices del primer y último carácter inclusive tienen la misma información, según lo dado por min_bounds y max_bounds.
  • Si all_chars_exist es Verdadero, todos los caracteres en el array per_char tienen cuadros delimitadores distintos de cero.
  • El miembro default_char especifica el carácter que se usará cuando se imprima un carácter no definido o inexistente. El default_char es un carácter de 16 bits (no un carácter de 2 bytes). Para una fuente que usa el formato de matriz de 2 bytes, el default_char tiene byte1 en el byte más significativo y byte2 en el byte menos significativo. Si el default_char especifica en sí mismo un carácter no definido o inexistente, no se realiza ninguna impresión para un carácter no definido o inexistente.
  • Los miembros min_bounds y max_bounds contienen los valores más extremos de cada componente XCharStruct individual sobre todos los elementos de este array (e ignoran los caracteres inexistentes). El cuadro delimitador de la fuente (el rectángulo más pequeño que encierra la forma obtenida al superponer todos los caracteres en el mismo origen [x,y]) tiene su coordenada superior izquierda en: 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
Su ancho es: 
max_bounds.rbearing - min_bounds.lbearing
Su altura es: 
max_bounds.ascent + max_bounds.descent
  • El miembro ascent es la extensión lógica de la fuente por encima de la línea base que se utiliza para determinar el espaciado entre líneas. Los caracteres específicos pueden extenderse más allá de esto.
  • El miembro descent es la extensión lógica de la fuente en o por debajo de la línea base que se utiliza para determinar el espaciado entre líneas. Los caracteres específicos pueden extenderse más allá de esto.
  • Si la línea base está en la coordenada Y y, la extensión lógica de la fuente es inclusiva entre los valores de la coordenada Y (y - font.ascent) y (y + font.descent - 1). Típicamente, el espaciado mínimo entre líneas de texto se da por ascent + descent.

Para un origen de carácter en [x,y], el cuadro delimitador de un carácter (es decir, el rectángulo más pequeño que encierra la forma del carácter) descrito en términos de componentes XCharStruct es un rectángulo con su esquina superior izquierda en:

[x + lbearing, y - ascent]

Su ancho es:

rbearing - lbearing

Su altura es:

ascent + descent

El origen para el siguiente carácter se define como:

[x + width, y]

El miembro lbearing define la extensión del borde izquierdo de la tinta del carácter desde el origen. El miembro rbearing define la extensión del borde derecho de la tinta del carácter desde el origen. El miembro ascent define la extensión del borde superior de la tinta del carácter desde el origen. El miembro descent define la extensión del borde inferior de la tinta del carácter desde el origen. El miembro width define el ancho lógico del carácter.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o memoria del servidor solicitado.
BadFont
Un valor para un argumento de Fuente o GContext no nombra una Fuente definida.
BadName
No existe una fuente o color del nombre especificado.
