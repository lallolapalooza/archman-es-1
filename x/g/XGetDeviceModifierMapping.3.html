XGetDeviceModifierMapping(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGETDEVICEMODIFIERMA(3)   XGETDEVICEMODIFIERMA(3)

NOMBRE

XSetDeviceModifierMapping, XGetDeviceModifierMapping - consultar o cambiar las asignaciones de modificadores de dispositivos

SINOPSIS

#include <X11/extensions/XInput.h>
int XSetDeviceModifierMapping( Display *display,
                               XDevice *device,
                               XModifierKeymap *modmap);
XModifierKeymap *XGetDeviceModifierMapping( Display *display,
                                            XDevice *device);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyas asignaciones de modificadores se van a
       consultar o modificar.
modmap
       Especifica un puntero a la estructura XModifierKeymap.

DESCRIPCIÓN

La solicitud XSetDeviceModifierMapping especifica los códigos de tecla (si los hay)
que se utilizarán como modificadores para el dispositivo especificado. Si tiene
éxito, el servidor X genera un evento DeviceMappingNotify y XSetDeviceModifierMapping
devuelve MappingSuccess. X permite como máximo ocho teclas modificadoras.
Si se especifican más de ocho en la estructura XModifierKeymap, se produce un
error BadLength.
El miembro modifiermap de la estructura XModifierKeymap contiene ocho conjuntos
de max_keypermod códigos de tecla, uno para cada modificador en el orden Shift,
Lock, Control, Mod1, Mod2, Mod3, Mod4 y Mod5. Solo los códigos de tecla distintos
de cero tienen significado en cada conjunto, y los códigos de tecla cero se
ignoran. Además, todos los códigos de tecla distintos de cero deben estar en el
rango especificado por min_keycode y max_keycode devueltos por XListInputDevices,
o se producirá un error BadValue. Ningún código de tecla puede aparecer dos veces
en todo el mapa, o se producirá un error BadValue.
Un servidor X puede imponer restricciones sobre cómo se pueden cambiar los
modificadores, por ejemplo, si ciertas teclas no generan transiciones de subida
en hardware, si la repetición automática no se puede deshabilitar en ciertas
teclas o si no se admiten varios modificadores de teclas. Si se viola alguna
restricción de este tipo, la respuesta de estado es MappingFailed y ninguno de
los modificadores se cambia. Si los nuevos códigos de tecla especificados para
un modificador difieren de los definidos actualmente y alguna de las teclas
(actuales o nuevas) para ese modificador está en el estado lógicamente presionado,
XSetDeviceModifierMapping devuelve MappingBusy y ninguno de los modificadores
se cambia.
XSetDeviceModifierMapping puede generar errores BadLength, BadDevice, BadMatch,
BadAlloc y BadValue.
La solicitud XGetDeviceModifierMapping devuelve un puntero a una estructura
XModifierKeymap recién creada que contiene las teclas que se utilizan como
modificadores. La estructura debe liberarse después de su uso llamando a
XFreeModifierMapping. Si solo aparecen valores cero en el conjunto para algún
modificador, ese modificador se deshabilita.
XGetDeviceModifierMapping puede generar errores BadDevice y BadMatch.

Estructuras

La estructura XModifierKeymap contiene:
typedef struct {
int max_keypermod;
KeyCode *modifiermap;
} XModifierKeymap;

DIAGNÓSTICOS

BadLength
       Se especificaron más de ocho teclas en la estructura
       XModifierKeymap.
BadAlloc
       El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadDevice
       Se especificó un dispositivo no válido. El dispositivo
       especificado no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si el
       dispositivo especificado es el teclado X o el dispositivo puntero X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud
       XGetDeviceModifierMapping o XChangeDeviceModifierMapping especificando
       un dispositivo que no tiene teclas.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un rango para un
       argumento, se acepta el rango completo definido por el tipo del
       argumento. Cualquier argumento definido como un conjunto de alternativas
       puede generar este error.
