XSetCommand(3) FUNCIONES DE XLIB XSetCommand(3)

NOMBRE

XSetCommand, XGetCommand - establecer o leer la propiedad WM_COMMAND de una ventana

SINTAXIS

int XSetCommand(Display *display, Window w, char **argv, int argc);

Status XGetCommand(Display *display, Window w, char ***argv_return, int *argc_return);

ARGUMENTOS

argc
Especifica el número de argumentos.
argc_return
Devuelve el número de argumentos devueltos.
argv
Especifica la lista de argumentos de la aplicación.
argv_return
Devuelve la lista de argumentos de la aplicación.
display
Especifica la conexión con el servidor X.
w
Especifica la ventana.

DESCRIPCIÓN

La función XSetCommand establece el comando y los argumentos utilizados para invocar la aplicación. (Típicamente, argv es la matriz argv de su programa principal.) Si las cadenas no están en la codificación de caracteres portátil del host, el resultado depende de la implementación.

XSetCommand puede generar errores BadAlloc y BadWindow.

La función XGetCommand lee la propiedad WM_COMMAND de la ventana especificada y devuelve una lista de cadenas. Si la propiedad WM_COMMAND existe, es de tipo STRING y formato 8. Si se puede asignar memoria suficiente para contener la lista de cadenas, XGetCommand rellena los argumentos argv_return y argc_return y devuelve un estado distinto de cero. En caso contrario, o si se encuentra algún otro error, devuelve un estado cero. Si los datos devueltos por el servidor están en la codificación de caracteres portátil latina, entonces las cadenas devueltas están en la codificación de caracteres portátil del host. En caso contrario, el resultado depende de la implementación. Para liberar la memoria asignada a la lista de cadenas, use XFreeStringList.

PROPIEDADES

WM_COMMAND
El comando y los argumentos, separados por nulos, utilizados para invocar la aplicación.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
