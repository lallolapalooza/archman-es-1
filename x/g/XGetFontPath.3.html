XSetFontPath(3) FUNCIONES XLIB XSetFontPath(3)

NOMBRE

XSetFontPath, XGetFontPath, XFreeFontPath - establecer, obtener o liberar la ruta de búsqueda de fuentes

SINTAXIS

int XSetFontPath(Display *display, char **directories, int ndirs);

char **XGetFontPath(Display *display, int *npaths_return);

int XFreeFontPath(char **list);

ARGUMENTOS

directories
Especifica la ruta del directorio utilizada para buscar una fuente. Establecer la ruta a la lista vacía restaura la ruta predeterminada definida para el servidor X.
display
Especifica la conexión al servidor X.
list
Especifica el array de cadenas que deseas liberar.
ndirs
Especifica el número de directorios en la ruta.
npaths_return
Devuelve el número de cadenas en el array de rutas de fuentes.

DESCRIPCIÓN

La función XSetFontPath define la ruta de búsqueda de directorios para la búsqueda de fuentes. Existe una sola ruta de búsqueda por servidor X, no una por cliente. La codificación e interpretación de las cadenas dependen de la implementación, pero típicamente especifican directorios o servidores de fuentes que se buscarán en el orden que se enumeran. Se permite que un servidor X almacene en caché información de fuentes internamente; por ejemplo, podría almacenar en caché una fuente completa de un archivo y no comprobar en aperturas posteriores de esa fuente para ver si el archivo de fuente subyacente ha cambiado. Sin embargo, cuando se cambia la ruta de fuentes, se garantiza que el servidor X vaciará toda la información almacenada en caché sobre fuentes para las que actualmente no hay IDs de recursos explícitos asignados. El significado de un error de esta solicitud depende de la implementación.

XSetFontPath puede generar un error BadValue.

La función XGetFontPath asigna y devuelve un array de cadenas que contiene la ruta de búsqueda. El contenido de estas cadenas depende de la implementación y no está destinado a ser interpretado por aplicaciones cliente. Cuando ya no sea necesario, los datos de la ruta de fuentes deben liberarse utilizando XFreeFontPath.

La función XFreeFontPath libera los datos asignados por XGetFontPath.

DIAGNÓSTICOS

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta todo el rango definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
