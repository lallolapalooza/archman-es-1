Paquete: libx11

Licencias: MIT AND X11

XSetWMProtocols(3) FUNCIONES DE XLIB XSetWMProtocols(3)

NOMBRE

XSetWMProtocols, XGetWMProtocols - establece o lee la propiedad WM_PROTOCOLS de una ventana

SINTAXIS

Status XSetWMProtocols(Display *display, Window w, Atom *protocols, int count);

Status XGetWMProtocols(Display *display, Window w, Atom **protocols_return, int *count_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
count
Especifica el número de protocolos en la lista.
count_return
Devuelve el número de protocolos en la lista.
protocols
Especifica la lista de protocolos.
protocols_return
Devuelve la lista de protocolos.

DESCRIPCIÓN

La función XSetWMProtocols reemplaza la propiedad WM_PROTOCOLS en la ventana especificada con la lista de átomos especificados por el argumento protocols. Si la propiedad no existe, XSetWMProtocols establece la propiedad WM_PROTOCOLS en la ventana especificada con la lista de átomos especificados por el argumento protocols. La propiedad se almacena con un tipo ATOM y un formato de 32. Si no puede internar el átomo WM_PROTOCOLS, XSetWMProtocols devuelve un estado cero. De lo contrario, devuelve un estado distinto de cero.

XSetWMProtocols puede generar errores BadAlloc y BadWindow.

La función XGetWMProtocols devuelve la lista de átomos almacenados en la propiedad WM_PROTOCOLS en la ventana especificada. Estos átomos describen los protocolos del gestor de ventanas en los que el propietario de esta ventana está dispuesto a participar. Si la propiedad existe, es de tipo ATOM, es de formato 32 y el átomo WM_PROTOCOLS se puede internar, XGetWMProtocols establece el argumento protocols_return a una lista de átomos, establece el argumento count_return al número de elementos de la lista y devuelve un estado distinto de cero. De lo contrario, no establece ninguno de los argumentos de retorno y devuelve un estado cero. Para liberar la lista de átomos, use XFree.

XGetWMProtocols puede generar un error BadWindow.

PROPIEDADES

WM_PROTOCOLS
Lista de átomos que identifican los protocolos de comunicación entre el cliente y el gestor de ventanas en los que el cliente está dispuesto a participar.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
