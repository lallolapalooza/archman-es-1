XGETEXTENSIONVERSION(3)   XGETEXTENSIONVERSION(3)

NOMBRE

XGetExtensionVersion - consultar la versión de la extensión de entrada.

SINOPSIS

#include <X11/extensions/XInput.h>
XExtensionVersion *XGetExtensionVersion( Display *display,
                                         char *name);
display
       Especifica la conexión con el servidor X.
name
       Especifica la extensión a consultar. El nombre de la
       extensión de entrada se define en el archivo de cabecera XI.h.

DESCRIPCIÓN

La solicitud XGetExtensionVersion está obsoleta y no debe
utilizarse en aplicaciones XI2. Los clientes que emitan una
solicitud XGetExtensionVersion no podrán utilizar las funciones XI2.
La solicitud XGetExtensionVersion consulta la versión de la extensión de entrada
y devuelve una estructura XExtensionVersion. Esta estructura
contiene un número major_version y minor_version que pueden compararse
con constantes definidas en XI.h. El soporte para solicitudes de protocolo
adicionales añadidas a la extensión de entrada después de su lanzamiento
inicial se indica mediante un número de versión que corresponde a las
solicitudes añadidas. Cada versión contiene todas las solicitudes de protocolo
contenidas en versiones anteriores.
Deberías usar XFree para liberar la estructura XExtensionVersion.

ESTRUCTURAS

Esta solicitud devuelve una estructura XExtensionVersion.
typedef struct {
    int present;
    short major_version;
    short minor_version;
} XExtensionVersion;
