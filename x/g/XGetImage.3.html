XPutImage(3) FUNCIONES XLIB XPutImage(3)

NOMBRE

XPutImage, XGetImage, XGetSubImage - transferir imágenes

SINTAXIS

int XPutImage(Display *display, Drawable d, GC gc, XImage *image, int src_x, int src_y, int dest_x, int dest_y, unsigned int width, unsigned int height);

XImage *XGetImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format);

XImage *XGetSubImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format, XImage *dest_image, int dest_x, dest_y);

ARGUMENTOS

d
Especifica el drawable.
dest_image
Especifica la imagen de destino.
dest_x

dest_y
Especifican las coordenadas x e y, que son relativas al origen del drawable y son las coordenadas de la subimagen o que son relativas al origen del rectángulo de destino, especifican su esquina superior izquierda, y determinan dónde se coloca la subimagen en la imagen de destino.
display
Especifica la conexión con el servidor X.
format
Especifica el formato para la imagen. Puedes pasar XYPixmap o ZPixmap.
gc
Especifica el GC.
image
Especifica la imagen que deseas combinar con el rectángulo.
plane_mask
Especifica la máscara de planos.
src_x
Especifica el desplazamiento en X desde el borde izquierdo de la imagen definida por la estructura XImage.
src_y
Especifica el desplazamiento en Y desde el borde superior de la imagen definida por la estructura XImage.
width

height
Especifican el ancho y el alto de la subimagen, que definen las dimensiones del rectángulo.
x

y
Especifican las coordenadas x e y, que son relativas al origen del drawable y definen la esquina superior izquierda del rectángulo.

DESCRIPCIÓN

La función XPutImage combina una imagen con un rectángulo del drawable especificado. La sección de la imagen definida por los argumentos src_x, src_y, width y height se dibuja en la parte especificada del drawable. Si se usa el formato XYBitmap, la profundidad de la imagen debe ser uno, o se producirá un error BadMatch. El píxel de primer plano en el GC define la fuente para los bits uno en la imagen, y el píxel de fondo define la fuente para los bits cero. Para XYPixmap y ZPixmap, la profundidad de la imagen debe coincidir con la profundidad del drawable, o se producirá un error BadMatch.

Si las características de la imagen (por ejemplo, byte_order y bitmap_unit) difieren de lo que requiere el servidor, XPutImage realiza automáticamente las conversiones apropiadas.

Esta función utiliza estos componentes del GC: function, plane-mask, subwindow-mode, clip-x-origin, clip-y-origin y clip-mask. También utiliza estos componentes dependientes del modo del GC: foreground y background.

XPutImage puede generar errores BadDrawable, BadGC, BadMatch y BadValue.

La función XGetImage devuelve un puntero a una estructura XImage. Esta estructura te proporciona el contenido del rectángulo especificado del drawable en el formato que especifiques. Si el argumento format es XYPixmap, la imagen contiene solo los planos de bits que pasaste al argumento plane_mask. Si el argumento plane_mask solo solicita un subconjunto de los planos de la pantalla, la profundidad de la imagen devuelta será el número de planos solicitados. Si el argumento format es ZPixmap, XGetImage devuelve como cero los bits en todos los planos no especificados en el argumento plane_mask. La función no realiza ninguna verificación de rango en los valores de plane_mask e ignora los bits extraños.

XGetImage devuelve la profundidad de la imagen al miembro depth de la estructura XImage. La profundidad de la imagen es como se especificó cuando se creó el drawable, excepto cuando se obtiene un subconjunto de los planos en formato XYPixmap, cuando la profundidad es dada por el número de bits establecidos a 1 en plane_mask.

Si el drawable es un pixmap, el rectángulo dado debe estar completamente contenido dentro del pixmap, o se producirá un error BadMatch. Si el drawable es una ventana, la ventana debe ser visible, y debe darse el caso de que si no hubiera inferiores ni ventanas superpuestas, el rectángulo especificado de la ventana sería completamente visible en la pantalla y estaría completamente contenido dentro de los bordes exteriores de la ventana, o se producirá un error BadMatch. Ten en cuenta que las bordes de la ventana pueden ser incluidos y leídos con esta solicitud. Si la ventana tiene backing-store, se devuelven los contenidos del backing-store para las regiones de la ventana que están oscurecidas por ventanas no inferiores. Si la ventana no tiene backing-store, los contenidos devueltos de dichas regiones oscurecidas no están definidos. Los contenidos devueltos de regiones visibles de inferiores de una profundidad diferente a la profundidad de la ventana especificada tampoco están definidos. La imagen del cursor del puntero no se incluye en los contenidos devueltos. Si ocurre un problema, XGetImage devuelve NULL.

XGetImage puede generar errores BadDrawable, BadMatch y BadValue.

La función XGetSubImage actualiza dest_image con la subimagen especificada de la misma manera que XGetImage. Si el argumento format es XYPixmap, la imagen contiene solo los planos de bits que pasaste al argumento plane_mask. Si el argumento format es ZPixmap, XGetSubImage devuelve como cero los bits en todos los planos no especificados en el argumento plane_mask. La función no realiza ninguna verificación de rango en los valores de plane_mask e ignora los bits extraños. Como una conveniencia, XGetSubImage devuelve un puntero a la misma estructura XImage especificada por dest_image.

La profundidad de la estructura XImage de destino debe ser la misma que la del drawable. Si la subimagen especificada no cabe en la ubicación especificada en la imagen de destino, los bordes derecho e inferior se recortan. Si el drawable es un pixmap, el rectángulo dado debe estar completamente contenido dentro del pixmap, o se producirá un error BadMatch. Si el drawable es una ventana, la ventana debe ser visible, y debe darse el caso de que si no hubiera inferiores ni ventanas superpuestas, el rectángulo especificado de la ventana sería completamente visible en la pantalla y estaría completamente contenido dentro de los bordes exteriores de la ventana, o se producirá un error BadMatch. Si la ventana tiene backing-store, los contenidos del backing-store se devuelven para las regiones de la ventana que están oscurecidas por ventanas no inferiores. Si la ventana no tiene backing-store, los contenidos devueltos de dichas regiones oscurecidas no están definidos. Los contenidos devueltos de regiones visibles de inferiores de una profundidad diferente a la profundidad de la ventana especificada tampoco están definidos. Si ocurre un problema, XGetSubImage devuelve NULL.

XGetSubImage puede generar errores BadDrawable, BadGC, BadMatch y BadValue.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definido.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana de tipo InputOnly como Drawable.
BadMatch
Algún argumento o par de arg

XGetImage(3) - Arch Linux Man Pages

NAME

XGetImage, XGetPixel, XPutImage, XDestroyImage, XSubImage, XAddPixel - image functions

SYNOPSIS

#include <Xlib.h>

XImage *XGetImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, long plane_mask, int format);

unsigned long XGetPixel(XImage *image, int x, int y);

int XPutImage(Display *display, Drawable d, GC gc, XImage *image, int x, int y, int dst_x, int dst_y, unsigned int width, unsigned int height);

int XDestroyImage(XImage *image);

XImage *XSubImage(XImage *image, int x, int y, unsigned int width, unsigned int height);

int XAddPixel(XImage *image, long add);

ARGUMENTS

All functions in this section require a connection to the X server maintained by Display *display.

Drawable d: Specifies the drawable from which the image is obtained or to which the image is written.

GC gc: Specifies the graphics context for XPutImage.

int x, int y: Define the coordinates of the upper-left corner of the image.

unsigned int width, unsigned int height: Define the width and height of the image.

long plane_mask: Specifies which planes of the destination drawable are to be read. A value of 0 means all planes.

int format: Specifies the format of the image data. This can be XYPixmap or ZPixmap.

XImage *image: Pointer to the X image structure.

long add: Value to be added to each pixel's value (used in XAddPixel).

int dst_x, int dst_y: Define the coordinates where the image is to be written on the destination drawable.

DESCRIPTION

XGetImage reads a rectangular region of pixels from a drawable and returns a pointer to an XImage structure. The image data is returned in the specified format. XYPixmap means that the data is stored plane by plane, while ZPixmap means that the data is stored pixel by pixel.

XGetPixel returns the value of the pixel at the specified coordinates within the XImage structure. The coordinates are relative to the XImage structure's origin.

XPutImage writes a rectangular region of pixels from an XImage structure to a drawable. The data is written using the specified GC. The destination coordinates are given by dst_x and dst_y.

XDestroyImage destroys the specified XImage structure and frees all associated memory. Note that this function does not destroy the image data if it was obtained using XGetImage directly from the server, as the server manages that memory.

XSubImage creates a new XImage structure that is a sub-region of the given XImage. The new image structure shares the same data buffer as the original image, but its offset and dimensions are adjusted.

XAddPixel adds a value to each pixel in the XImage structure. This can be used to change the color values of an image.

DIAGNOSTICS

BadDrawable
A value for a Drawable argument does not exist.
BadGC
A value for a GC argument does not exist.
BadMatch
This error can occur if the format of the image is incompatible with the drawable.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.
