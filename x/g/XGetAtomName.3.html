XInternAtom(3) FUNCIONES DE XLIB XInternAtom(3)

NOMBRE

XInternAtom, XInternAtoms, XGetAtomName, XGetAtomNames - crear o devolver nombres de átomos

SINTAXIS

Atom XInternAtom(Display *display, _Xconst char *atom_name, Bool only_if_exists);

Status XInternAtoms(Display *display, char **names, int count, Bool only_if_exists, Atom *atoms_return);

char *XGetAtomName(Display *display, Atom atom);

Status XGetAtomNames(Display *display, Atom *atoms, int count, char **names_return);

ARGUMENTOS

atom
Especifica el átomo para el nombre de propiedad que desea devolver.
atoms
Especifica el array de átomos.
atom_name
Especifica el nombre asociado con el átomo que desea devolver.
atoms_return
Devuelve los átomos.
count
Especifica el número de nombres de átomos en el array.
display
Especifica la conexión con el servidor X.
names
Especifica el array de nombres de átomos.
names_return
Devuelve los nombres de átomos.
only_if_exists
Especifica un valor booleano que indica si el átomo debe ser creado.

DESCRIPCION

La función XInternAtom devuelve el identificador del átomo asociado con la cadena atom_name especificada. Si only_if_exists es False, el átomo se crea si no existe. Por lo tanto, XInternAtom puede devolver None. Si el nombre del átomo no está en la Codificación de Caracteres Portátil del Host, el resultado depende de la implementación. Mayúsculas y minúsculas importan; las cadenas “cosa”, “Cosa”, y “coSa” designan átomos diferentes. El átomo permanecerá definido incluso después de que la conexión del cliente se cierre. Se volverá indefinido solo cuando se cierre la última conexión con el servidor X.

XInternAtom puede generar errores BadAlloc y BadValue.

La función XInternAtoms devuelve los identificadores de átomos asociados con los nombres especificados. Los átomos se almacenan en el array atoms_return proporcionado por el llamador. Llamar a esta función es equivalente a llamar a XInternAtom para cada uno de los nombres en turno con el valor especificado de only_if_exists, pero esta función minimiza el número de intercambios de protocolo de ida y vuelta entre el cliente y el servidor X.

Esta función devuelve un estado distinto de cero si se devuelven átomos para todos los nombres; de lo contrario, devuelve cero.

XInternAtoms puede generar errores BadAlloc y BadValue.

La función XGetAtomName devuelve el nombre asociado con el átomo especificado. Si los datos devueltos por el servidor están en la Codificación de Caracteres Portátil Latina, entonces la cadena devuelta está en la Codificación de Caracteres Portátil del Host. De lo contrario, el resultado depende de la implementación. Para liberar la cadena resultante, llame a XFree.

XGetAtomName puede generar un error BadAtom.

La función XGetAtomNames devuelve los nombres asociados con los átomos especificados. Los nombres se almacenan en el array names_return proporcionado por el llamador. Llamar a esta función es equivalente a llamar a XGetAtomName para cada uno de los átomos en turno, pero esta función minimiza el número de intercambios de protocolo de ida y vuelta entre el cliente y el servidor X.

Esta función devuelve un estado distinto de cero si se devuelven nombres para todos los átomos; de lo contrario, devuelve cero.

XGetAtomNames puede generar un error BadAtom.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadAtom
Un valor para un argumento Atom no nombra un Átomo definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
