XGrabDeviceButton(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGRABDEVICEBUTTON(3)   XGRABDEVICEBUTTON(3)

NOMBRE

XGrabDeviceButton, XUngrabDeviceButton - capturar/liberar botones del dispositivo de extensión

SINOPSIS

#include <X11/extensions/XInput.h>
int XGrabDeviceButton( Display *display,
                       XDevice *device,
                       unsigned int button,
                       unsigned int modifiers,
                       XDevice* modifier_device,
                       Window grab_window,
                       Bool owner_events,
                       unsigned int event_count,
                       XEventClass *event_list,
                       int this_device_mode,
                       int other_devices_mode);
int XUngrabDeviceButton( Display *display,
                         XDevice *device,
                         unsigned int button,
                         unsigned int modifiers,
                         XDevice* modifier_device,
                         Window grab_window);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo que se va a capturar o liberar
button
       Especifica el botón del dispositivo que se va a capturar o
       liberar o AnyButton.
modifiers
       Especifica el conjunto de máscaras de teclado o AnyModifier. La máscara es
       la inclusión bit a bit de los bits de máscara de teclado válidos.
       Los bits válidos son: ShiftMask, LockMask, ControlMask,
       Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask, Mod5Mask.
modifier_device
       especifica el dispositivo cuyos modificadores se van a utilizar. Si
       el modifier_device especificado es NULL, se utilizará el teclado X
       como modifier_device.
grab_window
       Especifica la ventana de captura.
owner_events
       Especifica un valor booleano que indica si los eventos del dispositivo
       se van a notificar como de costumbre o se van a notificar con respecto a
       la ventana de captura si se seleccionan en la lista de eventos.
event_count
       Especifica el número de clases de eventos en la lista de eventos.
event_list
       Especifica qué eventos se notifican al cliente.
this_device_mode
       Especifica un procesamiento adicional de los eventos de este
       dispositivo. Puede pasar GrabModeSync o GrabModeAsync.
other_devices_mode
       Especifica un procesamiento adicional de los eventos de todos los demás
       dispositivos. Puede pasar GrabModeSync o GrabModeAsync.

DESCRIPCIÓN

La solicitud XGrabDeviceButton establece una captura pasiva. En
el futuro, el dispositivo se captura activamente (como para XGrabDevice,
la última hora de captura se establece en la hora en que se presionó el botón (tal como se transmitió en el evento DeviceButtonPress), y
el evento DeviceButtonPress se notifica si se cumplen todas las siguientes condiciones:
  * El dispositivo no está capturado, y el botón especificado está
    presionado lógicamente cuando las teclas modificadoras especificadas están
    presionadas lógicamente en el dispositivo modificador especificado y ningún
    otro botón o tecla modificadora está presionado lógicamente.
  * O bien la ventana de captura es un antecesor de (o es) la ventana de foco
    O bien la ventana de captura es un descendiente de la ventana de foco
    y contiene el dispositivo.
  * Una captura pasiva en la misma combinación de botón/modificador no
    existe en ningún antecesor de grab_window.
La interpretación de los argumentos restantes es la misma que para
XGrabDevice. La captura activa se termina automáticamente cuando
el estado lógico del dispositivo tiene todos los botones liberados
(independientemente del estado lógico de las teclas modificadoras).
Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente)
puede rezagarse con respecto al estado físico si el procesamiento de eventos del dispositivo
está congelado.
Esta solicitud anula todas las capturas anteriores por el mismo cliente en
las mismas combinaciones de botón/modificador en la misma ventana. Un modificador de AnyModifier
es equivalente a emitir la solicitud de captura para todas las combinaciones de modificadores posibles (incluida la combinación de ningún modificador). No es necesario que todos los modificadores especificados tengan actualmente códigos de tecla asignados. Un botón de AnyButton es equivalente a emitir la solicitud para todos los botones posibles. De lo contrario, no es necesario que el botón especificado esté asignado actualmente a un botón físico.
Un modifier_device de NULL indica que el teclado X se utilizará como el
modifier_device.
Si algún otro cliente ha emitido previamente un XGrabDeviceButton con
la misma combinación de botón/modificador en la misma ventana, se produce un error
BadAccess. Al usar AnyModifier o AnyButton,
la solicitud falla por completo y se produce un error BadAccess (no se establecen capturas)
si existe una captura conflictiva para alguna combinación. XGrabDeviceButton no tiene ningún efecto sobre una captura activa.
XGrabDeviceButton puede generar errores BadClass, BadDevice, BadMatch,
BadValue y BadWindow.
La solicitud XUngrabDeviceButton libera la captura pasiva para una
combinación de botón/modificador en la ventana especificada si fue capturada
por este cliente. Un modificador de AnyModifier es equivalente a
emitir la solicitud de liberación para todas las combinaciones de modificadores posibles,
incluida la combinación de ningún modificador. Un botón de AnyButton es
equivalente a emitir la solicitud para todos los botones posibles.
XUngrabDeviceButton no tiene ningún efecto sobre una captura activa.
Un modifier_device de NULL indica que el teclado X debe
utilizarse como el modifier_device.
XUngrabDeviceButton puede generar errores BadDevice, BadMatch, BadValue
y BadWindow.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si el
       dispositivo especificado es el teclado X o el dispositivo puntero X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud XGrabDeviceButton
       especificando un dispositivo que no tiene botones, o
       especificando un dispositivo modificador que no tiene teclas.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un rango para un
       argumento, se acepta el rango completo definido por el tipo del
       argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
       Un valor para un argumento de Ventana no nombra una Ventana
       definida.
