XGETFEEDBACKCONTROL(3)   XGETFEEDBACKCONTROL(3)

NOMBRE

XGetFeedbackControl, XChangeFeedbackControl - consultar y cambiar retroalimentaciones de dispositivos de entrada

SINOPSIS

#include <X11/extensions/XInput.h>
XFeedbackState *XGetFeedbackControl( Display *display,
                                     XDevice *device,
                                     int *num_feedbacks);
int XChangeFeedbackControl( Display *display,
                            XDevice *device,
                            Mask mask,
                            XFeedbackControl *control);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyas retroalimentaciones se consultarán
       o modificarán.
num_feedbacks
       Especifica una dirección en la que se devolverá el número de retroalimentaciones
       soportadas por el dispositivo.
mask
       Especifica una máscara específica para cada tipo de retroalimentación que
       describe cómo se modificará la retroalimentación.
control
       Especifica la dirección de una estructura XFeedbackControl
       que contiene los nuevos valores para la retroalimentación.

DESCRIPCIÓN

Estas peticiones se proporcionan para manipular aquellos dispositivos de entrada
que soportan retroalimentaciones. Se generará un error BadMatch si
el dispositivo solicitado no soporta retroalimentaciones. Si un dispositivo dado
soporta retroalimentaciones o no, puede determinarse examinando la
información devuelta por la petición XOpenDevice.
Para aquellos dispositivos que soportan retroalimentaciones, XOpenDevice devolverá
una estructura XInputClassInfo con el campo input_class igual a la constante
FeedbackClass (definida en el archivo XI.h).
La petición XGetFeedbackControl devuelve un puntero a una lista de
estructuras XFeedbackState. Cada elemento de esta lista describe una
de las retroalimentaciones soportadas por el dispositivo. Los elementos son
de longitud variable, por lo que cada uno contiene su longitud para permitir la
travesía al siguiente elemento de la lista.
Las clases de retroalimentación que están definidas actualmente son:
KbdFeedbackClass, PtrFeedbackClass, StringFeedbackClass,
IntegerFeedbackClass, LedFeedbackClass, y BellFeedbackClass.
Estas constantes están definidas en el archivo XI.h. Un dispositivo de entrada
puede soportar cero o más clases de retroalimentación, y puede soportar
múltiples retroalimentaciones de la misma clase. Cada retroalimentación contiene un
identificador de clase y un id que es único dentro de esa clase para
ese dispositivo de entrada. El id se utiliza para identificar la retroalimentación al
realizar una petición XChangeFeedbackControl.
XGetFeedbackControl puede generar un error BadDevice o BadMatch.
La petición XChangeFeedbackControl modifica los valores de una
retroalimentación en el dispositivo especificado. La retroalimentación se identifica
por el campo id de la estructura XFeedbackControl que se pasa con la
petición. Los campos de la retroalimentación que se van a modificar se
identifican por los bits de la máscara que se pasa con la
petición.
XChangeFeedbackControl puede generar un error BadDevice, BadMatch o
BadValue.

Estructuras

Cada clase de retroalimentación se describe mediante una estructura específica para
esa clase. Estas estructuras se definen en el archivo XInput.h.
XFeedbackState y XFeedbackControl son estructuras genéricas que
contienen tres campos que están al principio de cada clase de retroalimentación:
typedef struct {
    XID class;
    int length;
    XID id;
} XFeedbackState, XFeedbackControl;
La estructura XKbdFeedbackState define los atributos que se
devuelven para retroalimentaciones equivalentes a las del teclado X.
typedef struct {
    XID class;
    int length;
    XID id;
    int click;
    int percent;
    int pitch;
    int duration;
    int led_mask;
    int global_auto_repeat;
    char auto_repeats[32];
} XKbdFeedbackState;
La estructura XPtrFeedbackState define los atributos que se
devuelven para retroalimentaciones equivalentes a las del puntero X.
typedef struct {
    XID class;
    int length;
    XID id;
    int accelNum;
    int accelDenom;
    int threshold;
} XPtrFeedbackState;
La estructura XIntegerFeedbackState define los atributos que se
devuelven para retroalimentaciones enteras.
typedef struct {
    XID class;
    int length;
    XID id;
    int resolution;
    int minVal;
    int maxVal;
} XIntegerFeedbackState;
La estructura XStringFeedbackState define los atributos que se
devuelven para retroalimentaciones de cadena.
typedef struct {
    XID class;
    int length;
    XID id;
    int max_symbols;
    int num_syms_supported;
    KeySym *syms_supported;
} XStringFeedbackState;
La estructura XBellFeedbackState define los atributos que se
devuelven para retroalimentaciones de timbre.
typedef struct {
    XID class;
    int length;
    XID id;
    int percent;
    int pitch;
    int duration;
} XBellFeedbackState;
La estructura XLedFeedbackState define los atributos que se
devuelven para retroalimentaciones LED.
typedef struct {
    XID class;
    int length;
    XID id;
    int led_values;
} XLedFeedbackState;
La estructura XPrtFeedbackControl define los atributos que se
pueden controlar para las retroalimentaciones del puntero.
typedef struct {
    XID class;
    int length;
    XID id;
    int accelNum;
    int accelDenom;
    int threshold;
} XPtrFeedbackControl;
La estructura XKbdFeedbackControl define los atributos que se
pueden controlar para las retroalimentaciones del teclado.
typedef struct {
    XID class;
    int length;
    XID id;
    int click;
    int percent;
    int pitch;
    int duration;
    int led_mask;
    int led_value;
    int key;
    int auto_repeat_mode;
} XKbdFeedbackControl;
La estructura XStringFeedbackControl define los atributos
que se pueden controlar para las retroalimentaciones de cadena.
typedef struct {
    XID class;
    int length;
    XID id;
    int num_keysyms;
    KeySym  *syms_to_display;
} XStringFeedbackControl;
La estructura XIntegerFeedbackControl define los atributos
que se pueden controlar para las retroalimentaciones enteras.
typedef struct {
    XID class;
    int length;
    XID id;
    int int_to_display;
} XIntegerFeedbackControl;
La estructura XBellFeedbackControl define los atributos que
se pueden controlar para las retroalimentaciones de timbre.
typedef struct {
    XID     class;
    int     length;
    XID     id;
    int     percent;
    int     pitch;
    int     duration;
} XBellFeedbackControl;
La estructura XLedFeedbackControl define los atributos que

    XID     class;
    int     length;
    XID     id;
    int     led_mask;
    int     led_values;

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo
       especificado no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si algún
       otro cliente ha causado que el dispositivo especificado sea
       el dispositivo de teclado X o puntero X a través de las
       peticiones XChangeKeyboardDevice o XChangePointerDevice.
BadMatch
       Este error puede ocurrir si se realizó una petición XGetFeedbackControl
       especificando un dispositivo que no tiene retroalimentaciones, o
       si se realizó una petición XChangeFeedbackControl con una
       estructura XFeedbackControl que contiene un tipo de retroalimentación
       inválido. También puede ocurrir si se especifica una combinación
       inválida de bits de máscara (DvKey pero no
       DvAutoRepeatMode para retroalimentaciones de teclado), o si se especifica
       una KeySym inválida para una retroalimentación de cadena.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la petición XChangeFeedbackControl. A menos que se especifique
       un rango específico para un argumento, se acepta el rango completo
       definido por el tipo del argumento. Cualquier
       argumento definido como un conjunto de alternativas puede generar
       este error.

NAME

XGetFeedbackControl, XSetFeedbackControl, XGetFeedbackArray, XSetFeedbackArray, XChangeFeedbackControl — obtener y establecer controles de retroalimentación de dispositivos de entrada

SINOPSIS

En <X11/extensions/XInput.h>

Bool XGetFeedbackControl(
    Display *display,
    XID       resource_id,
    int       *num_feedback,
    XFeedbackState **feedback_list_ret
);

Status XSetFeedbackControl(
    Display *display,
    XID       resource_id,
    int       num_feedback,
    XFeedbackControl **feedback_controls
);

Bool XGetFeedbackArray(
    Display *display,
    XID       resource_id,
    int       *num_feedback,
    XFeedbackState **feedback_list_ret
);

Status XSetFeedbackArray(
    Display *display,
    XID       resource_id,
    int       num_feedback,
    XFeedbackControl **feedback_controls
);

Status XChangeFeedbackControl(
    Display *display,
    XID       resource_id,
    Atom      control,
    int       num_feedback,
    XFeedbackControl **feedback_controls
);

DESCRIPCIÓN

La extensión de entrada X (XInput) proporciona una interfaz para controlar y obtener información sobre dispositivos de entrada. Los dispositivos de entrada pueden tener mecanismos de retroalimentación, como retumbar, vibrar, emitir pitidos, etc. La extensión XInput proporciona funciones para obtener y establecer el estado y los controles de estos mecanismos de retroalimentación.

XGetFeedbackControl y XGetFeedbackArray recuperan el estado actual de todos los mecanismos de retroalimentación asociados con un recurso dado (normalmente un dispositivo de entrada). El parámetro resource_id especifica el recurso de interés. El parámetro num_feedback se establece en el número de elementos de retroalimentación devueltos y feedback_list_ret apunta a una lista de estructuras XFeedbackState. Cada estructura XFeedbackState contiene información sobre un mecanismo de retroalimentación específico, incluido su tipo, identificador y estado actual.

XSetFeedbackControl y XSetFeedbackArray establecen los controles de los mecanismos de retroalimentación asociados con un recurso dado. El parámetro resource_id especifica el recurso de interés. Los parámetros num_feedback y feedback_controls especifican la matriz de estructuras XFeedbackControl que contienen los nuevos valores de control deseados. Cada estructura XFeedbackControl contiene el tipo de retroalimentación, el identificador y los valores de control que se van a establecer.

XChangeFeedbackControl es una forma más general de modificar los controles de retroalimentación. Permite especificar un único control de retroalimentación que se va a modificar (control) junto con los nuevos valores. Los parámetros num_feedback y feedback_controls se utilizan de manera similar a XSetFeedbackControl.

Las estructuras XFeedbackState y XFeedbackControl se definen en el encabezado <X11/extensions/XInput.h> y contienen campos como:

  • type: el tipo de mecanismo de retroalimentación.
  • id: el identificador único del mecanismo de retroalimentación.
  • class_id: la clase del mecanismo de retroalimentación.
  • max_value: el valor máximo que puede tener este control.
  • min_value: el valor mínimo que puede tener este control.
  • value: el valor actual del control (en XFeedbackState).
  • led_class, bl_state, bl_inc, bl_color, etc.: campos específicos de cada tipo de retroalimentación.

Para usar estas funciones, primero debe inicializar la extensión XInput usando XSelectExtensionEvent y verificar la disponibilidad de la extensión. Después de usar las funciones de retroalimentación, debe liberar la memoria asignada para las listas de retroalimentación usando XFree.

DIAGNÓSTICOS

Estas funciones pueden devolver False (para las funciones XGet...) o BadValue, BadIdChoice, BadImplementation, etc. (para las funciones XSet... y XChange...) en caso de error. Se debe verificar el valor de retorno para detectar errores. Los errores del servidor X se pueden obtener usando XErrors.
