Paquete: libxi

XGETDEVICECONTROL(3)   XGETDEVICECONTROL(3)

NOMBRE

XGetDeviceControl, XChangeDeviceControl - consultar y cambiar controles de dispositivos de entrada

SINOPSIS

#include <X11/extensions/XInput.h>
XDeviceControl *XGetDeviceControl( Display *display,
                                   XDevice *device,
                                   int *controlType);
int XChangeDeviceControl( Display *display,
                          XDevice *device,
                          int controlType,
                          XDeviceControl *control);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyos controles se van a interrogar
       o modificar.
controlType
       Especifica el tipo de control a interrogar o cambiar.
control
       Especifica la dirección de una estructura XDeviceControl
       que contiene los nuevos valores para el Dispositivo.

DESCRIPCIÓN

Estas solicitudes se proporcionan para manipular aquellos dispositivos de entrada
que admiten controles de dispositivos. Se generará un error BadMatch si
el dispositivo solicitado no admite ningún control de dispositivo.
Los tipos de control de dispositivo válidos que se pueden utilizar con estas
solicitudes incluyen los siguientes:
DEVICE_RESOLUTION: Consulta o cambia la resolución de los
valuadores en los dispositivos de entrada.
La solicitud XGetDeviceControl devuelve un puntero a una estructura
XDeviceControl.
XGetDeviceControl puede generar un error BadDevice o BadMatch.
La solicitud XChangeDeviceControl modifica los valores de un
control en el dispositivo especificado. El control se identifica por
el campo id de la estructura XDeviceControl que se pasa con la
solicitud.
XChangeDeviceControl puede generar un error BadDevice, BadMatch o
BadValue.

ESTRUCTURAS

Cada control se describe mediante una estructura específica para ese control.
Estas estructuras se definen en el archivo XInput.h.
XDeviceControl es una estructura genérica que contiene dos campos
que están al principio de cada clase de control:
typedef struct {
    XID class;
    int length;
} XDeviceControl;
La estructura XDeviceResolutionState define la información
que se devuelve para la resolución del dispositivo para dispositivos con
valuadores.
typedef struct {
    XID control;
    int length;
    int num_valuators;
    int* resolutions;
    int* min_resolutions;
    int* max_resolutions;
} XDeviceResolutionState;
La estructura XDeviceResolutionControl define los atributos
que se pueden controlar para los dispositivos de teclado.
typedef struct {
    XID control;
    int length;
    int first_valuator;
    int num_valuators;
    int* resolutions;
} XDeviceResolutionControl;

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo
       especificado no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si algún
       otro cliente ha hecho que el dispositivo especificado sea
       el dispositivo X keyboard o X pointer a través de las
       solicitudes XChangeKeyboardDevice o XChangePointerDevice.
BadMatch
       Este error puede ocurrir si se realizó una solicitud XGetDeviceControl
       especificando un dispositivo que no tiene controles o una
       solicitud XChangeDeviceControl con una
       estructura XDeviceControl que contiene un tipo de Dispositivo no válido.
       También puede ocurrir si se especifica una combinación inválida de
       bits de máscara ( DvKey pero sin DvAutoRepeatMode
       para Dispositivos de teclado), o si se especifica un KeySym inválido
       para un Dispositivo de cadena.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud XChangeDeviceControl. A menos que se
       especifique un rango específico para un argumento, se acepta el rango completo
       definido por el tipo del argumento. Cualquier argumento definido como un conjunto de
       alternativas puede generar este error.
