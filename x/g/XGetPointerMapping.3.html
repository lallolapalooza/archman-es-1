XGetPointerMapping(3)

Paquete: libx11

Licencias: MIT AND X11

XSetPointerMapping(3) FUNCIONES DE XLIB XSetPointerMapping(3)

NOMBRE

XSetPointerMapping, XGetPointerMapping - manipular la configuración del puntero

SINTAXIS

int XSetPointerMapping(Display *display, const unsigned char map[], int nmap);

int XGetPointerMapping(Display *display, unsigned char map_return[], int nmap);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
map
Especifica la lista de mapeo.
map_return
Devuelve la lista de mapeo.
nmap
Especifica el número de elementos en la lista de mapeo.

DESCRIPCIÓN

La función XSetPointerMapping establece el mapeo del puntero. Si tiene éxito, el servidor X genera un evento MappingNotify y XSetPointerMapping devuelve MappingSuccess. El elemento map[i] define el número lógico del botón para el botón físico i+1. La longitud de la lista debe ser la misma que devolvería XGetPointerMapping, o se producirá un error BadValue. Un elemento cero deshabilita un botón, y los elementos no están restringidos en valor por el número de botones físicos. Sin embargo, no puede haber dos elementos con el mismo valor distinto de cero, o se producirá un error BadValue. Si alguno de los botones que se van a modificar está lógicamente en estado de pulsado, XSetPointerMapping devuelve MappingBusy y el mapeo no se modifica.

XSetPointerMapping puede generar un error BadValue.

La función XGetPointerMapping devuelve el mapeo actual del puntero. Los botones del puntero se numeran a partir de uno. XGetPointerMapping devuelve el número de botones físicos que hay realmente en el puntero. El mapeo nominal para un puntero es map[i]=i+1. El argumento nmap especifica la longitud del array donde se devuelve el mapeo del puntero, y solo se devuelven los primeros nmap elementos en map_return.

DIAGNÓSTICOS

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
