XGrabButton(3)

Paquete: libx11

Licencias: MIT AND X11

XGrabButton(3) FUNCIONES DE XLIB XGrabButton(3)

NOMBRE

XGrabButton, XUngrabButton - capturar botones del puntero

SINTAXIS

int XGrabButton(Display *display, unsigned int button, unsigned int modifiers, Window grab_window, Bool owner_events, unsigned int event_mask, int pointer_mode, keyboard_mode, Window confine_to, Cursor cursor);

int XUngrabButton(Display *display, unsigned int button, unsigned int modifiers, Window grab_window);

ARGUMENTOS

button
Especifica el botón del puntero que se va a capturar o liberar o AnyButton.
confine_to
Especifica la ventana en la que confinar el puntero o None.
cursor
Especifica el cursor que se va a mostrar o None.
display
Especifica la conexión con el servidor X.
event_mask
Especifica qué eventos del puntero se informan al cliente. La máscara es el OR inclusivo a nivel de bits de los bits de máscara de evento del puntero válidos.
grab_window
Especifica la ventana de captura.
keyboard_mode
Especifica el procesamiento adicional de los eventos del teclado. Puedes pasar GrabModeSync o GrabModeAsync.
modifiers
Especifica el conjunto de máscaras de teclas o AnyModifier. La máscara es el OR inclusivo a nivel de bits de los bits de máscara de tecla válidos.
owner_events
Especifica un valor booleano que indica si los eventos del puntero se informan como de costumbre o se informan con respecto a la ventana de captura si se seleccionan mediante la máscara de eventos.
pointer_mode
Especifica el procesamiento adicional de los eventos del puntero. Puedes pasar GrabModeSync o GrabModeAsync.

DESCRIPCIÓN

La función XGrabButton establece una captura pasiva. En el futuro, el puntero se captura activamente (como para XGrabPointer), la hora de la última captura del puntero se establece en la hora en que se presionó el botón (tal como se transmite en el evento ButtonPress), y el evento ButtonPress se informa si se cumplen todas las siguientes condiciones:

  • El puntero no está capturado, y el botón especificado se presiona lógicamente cuando las teclas modificadoras especificadas están lógicamente pulsadas, y ningún otro botón o tecla modificadora está lógicamente pulsada.
  • La grab_window contiene el puntero.
  • La ventana confine_to (si existe) es visible.
  • No existe una captura pasiva en el mismo botón/combinación de teclas en ningún antecesor de grab_window.

La interpretación de los argumentos restantes es como para XGrabPointer. La captura activa se termina automáticamente cuando el estado lógico del puntero tiene todos los botones liberados (independientemente del estado de las teclas modificadoras lógicas), momento en el cual se informa un evento ButtonRelease a la ventana que captura.

Ten en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente) puede ir por detrás del estado físico si el procesamiento de eventos del dispositivo está congelado.

Esta solicitud anula todas las capturas previas del mismo cliente en los mismos botones/combinaciones de teclas en la misma ventana. Un modificador de AnyModifier es equivalente a emitir la solicitud de captura para todas las combinaciones de modificadores posibles (incluida la combinación de ningún modificador). No es necesario que todos los modificadores especificados tengan KeyCodes asignados actualmente. Un botón de AnyButton es equivalente a emitir la solicitud para todos los botones posibles. De lo contrario, no es necesario que el botón especificado esté actualmente asignado a un botón físico.

Si algún otro cliente ya ha emitido un XGrabButton con el mismo botón/combinación de teclas en la misma ventana, se produce un error BadAccess. Al usar AnyModifier o AnyButton, la solicitud falla por completo y se produce un error BadAccess (no se establecen capturas) si hay una captura conflictiva para alguna combinación. XGrabButton no tiene ningún efecto en una captura activa.

XGrabButton puede generar errores BadCursor, BadValue y BadWindow.

La función XUngrabButton libera el botón/combinación de teclas pasiva en la ventana especificada si fue capturada por este cliente. Un modificador de AnyModifier es equivalente a emitir la solicitud de liberación de captura para todas las combinaciones de modificadores posibles, incluida la combinación de ningún modificador. Un botón de AnyButton es equivalente a emitir la solicitud para todos los botones posibles. XUngrabButton no tiene ningún efecto en una captura activa.

XUngrabButton puede generar errores BadValue y BadWindow.

DIAGNÓSTICOS

BadCursor
Un valor para un argumento Cursor no nombra un Cursor definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
