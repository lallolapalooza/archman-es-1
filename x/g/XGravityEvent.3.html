XGravityEvent(3) FUNCIONES XLIB XGravityEvent(3)

NOMBRE

XGravityEvent - estructura del evento GravityNotify

ESTRUCTURAS

La estructura para los eventos GravityNotify contiene:

typedef struct {
        int type;       /* GravityNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* true si esto provino de una solicitud SendEvent */
        Display *display;       /* Display del cual se leyó el evento */
        Window event;
        Window window;
        int x, y;
} XGravityEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro `type` se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro `type` establecido en GraphicsExpose. El miembro `display` se establece en un puntero a la pantalla en la que se leyó el evento. El miembro `send_event` se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro `serial` se establece a partir del número de serie informado en el protocolo, pero expandido desde los 16 bits menos significativos a un valor completo de 32 bits. El miembro `window` se establece en la ventana que es más útil para los despachadores de herramientas (toolkits).

El miembro `event` se establece ya sea en la ventana que se movió o en su padre, dependiendo de si se seleccionó StructureNotify o SubstructureNotify. El miembro `window` se establece en la ventana hija que se movió. Los miembros `x` e `y` se establecen en las coordenadas relativas al origen de la nueva ventana padre e indican la posición de la esquina exterior superior izquierda de la ventana.
