XGetEventData(3)

Paquete: libx11

Licencias: MIT AND X11

XGetEventData(3) FUNCIONES DE XLIB XGetEventData(3)

NOMBRE

XGetEventData, XFreeEventData, XGenericEventCookie - recuperar y liberar datos adicionales de eventos a través de cookies.

SINTAXIS

Bool XGetEventData(Display *display, XGenericEventCookie *cookie);

void XFreeEventData(Display *display, XGenericEventCookie *cookie);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
cookie
Especifica la cookie para liberar o recuperar los datos.

ESTRUCTURAS

typedef struct {
        int type;
        unsigned long serial;
        Bool send_event;
        Display *display;
        int extension;
        int evtype;
        unsigned int cookie;
        void *data;
} XGenericEventCookie;

DESCRIPCIÓN

Algunos XGenericEvents de extensión requieren memoria adicional para almacenar información. Para estos eventos, la biblioteca devuelve una XGenericEventCookie con un token ('cookie') único para este evento. El puntero de datos de XGenericEventCookie no está definido hasta que se llama a XGetEventData.

La función XGetEventData recupera estos datos extra para la cookie dada. No se requiere una comunicación de ida y vuelta al servidor. Si la cookie no es válida o el evento no es un evento manejado por los manejadores de cookies, se devuelve False. Si XGetEventData devuelve True, el puntero de datos de la cookie apunta a la memoria que contiene la información del evento. El cliente debe llamar a XFreeEventData para liberar esta memoria. XGetEventData devuelve False para múltiples llamadas para la misma cookie de evento.

La función XFreeEventData libera los datos asociados con una cookie. El cliente debe llamar a XFreeEventData para cada cookie reclamada con XGetEventData.

CÓDIGO DE EJEMPLO

XEvent event;
XGenericEventCookie *cookie = &ev;
XNextEvent(display, &event);
if (XGetEventData(display, cookie)) {
    handle_cookie_event(cookie->data);
} else
    handle_event(&event);
}
XFreeEventData(display, cookie);

NOTAS

Una cookie se define como no reclamada si ha sido devuelta al cliente a través de XNextEvent pero sus datos no han sido recuperados a través de XGetEventData. Las llamadas posteriores a XNextEvent pueden liberar la memoria asociada con cookies no reclamadas. Los clientes X multihilo deben asegurarse de que se llama a XGetEventData antes de la siguiente llamada a XNextEvent.
