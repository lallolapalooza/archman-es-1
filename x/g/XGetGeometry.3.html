XGetGeometry(3)

Paquete: libx11

Licencias: MIT AND X11

XGetWindowAttributes(3) FUNCIONES DE XLIB XGetWindowAttributes(3)

NOMBRE

XGetWindowAttributes, XGetGeometry, XWindowAttributes - obtener atributos o geometría de ventana actuales y estructura de atributos de ventana actuales

SINTAXIS

Status XGetWindowAttributes(Display *display, Window w, XWindowAttributes *window_attributes_return);

Status XGetGeometry(Display *display, Drawable d, Window *root_return, int *x_return, int *y_return, unsigned int *width_return, unsigned int *height_return, unsigned int *border_width_return, unsigned int *depth_return);

ARGUMENTOS

border_width_return
Devuelve el ancho del borde en píxeles.
d
Especifica el drawable, que puede ser una ventana o un pixmap.
depth_return
Devuelve la profundidad del drawable (bits por píxel del objeto).
display
Especifica la conexión con el servidor X.
root_return
Devuelve la ventana raíz.
w
Especifica la ventana cuyos atributos actuales desea obtener.
width_return

height_return
Devuelven las dimensiones del drawable (ancho y alto).
window_attributes_return
Devuelve los atributos de la ventana especificada en la estructura XWindowAttributes.
x_return

y_return
Devuelven las coordenadas x e y que definen la ubicación del drawable. Para una ventana, estas coordenadas especifican la esquina exterior superior izquierda relativa al origen de su padre. Para los pixmaps, estas coordenadas son siempre cero.

DESCRIPCIÓN

La función XGetWindowAttributes devuelve los atributos actuales de la ventana especificada en una estructura XWindowAttributes. Devuelve un estado distinto de cero en caso de éxito; de lo contrario, devuelve un estado cero.

XGetWindowAttributes puede generar errores BadDrawable y BadWindow.

La función XGetGeometry devuelve la ventana raíz y la geometría actual del drawable. La geometría del drawable incluye las coordenadas x e y, el ancho y alto, el ancho del borde y la profundidad. Estos se describen en la lista de argumentos. Es legal pasar a esta función una ventana cuya clase sea InputOnly. Devuelve un estado distinto de cero en caso de éxito; de lo contrario, devuelve un estado cero.

ESTRUCTURAS

La estructura XWindowAttributes contiene:

typedef struct {
        int x, y;       /* ubicación de la ventana */
        int width, height;      /* ancho y alto de la ventana */
        int border_width;       /* ancho del borde de la ventana */
        int depth;      /* profundidad de la ventana */
        Visual *visual; /* la estructura visual asociada */
        Window root;    /* raíz de la pantalla que contiene la ventana */
        int class;      /* InputOutput, InputOnly */
        int bit_gravity;        /* uno de los valores de bit gravity */
        int win_gravity;        /* uno de los valores de window gravity */
        int backing_store;      /* NotUseful, WhenMapped, Always */
        unsigned long backing_planes;   /* planos que se conservarán si es posible */
        unsigned long backing_pixel;    /* valor a utilizar al restaurar planos */
        Bool save_under;        /* booleano, ¿se deben guardar los bits inferiores? */
        Colormap colormap;      /* mapa de colores a asociar con la ventana */
        Bool map_installed;     /* booleano, ¿está el mapa de colores actualmente instalado?*/
        int map_state;  /* IsUnmapped, IsUnviewable, IsViewable */
        long all_event_masks;   /* conjunto de eventos que interesan a todos */
        long your_event_mask;   /* mi máscara de eventos */
        long do_not_propagate_mask;     /* conjunto de eventos que no deben propagarse */
        Bool override_redirect; /* valor booleano para override-redirect */
        Screen *screen; /* puntero de retroceso a la pantalla correcta */
} XWindowAttributes;

Los miembros x e y se establecen en la esquina exterior superior izquierda relativa al origen de la ventana padre. Los miembros width y height se establecen en el tamaño interior de la ventana, sin incluir el borde. El miembro border_width se establece en el ancho del borde de la ventana en píxeles. El miembro depth se establece en la profundidad de la ventana (es decir, bits por píxel del objeto). El miembro visual es un puntero a la estructura Visual de la pantalla. El miembro root se establece en la ventana raíz de la pantalla que contiene la ventana. El miembro class se establece en la clase de la ventana y puede ser InputOutput o InputOnly.

El miembro bit_gravity se establece en la gravedad de bits de la ventana y puede ser uno de los siguientes:

ForgetGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

El miembro win_gravity se establece en la gravedad de ventana de la ventana y puede ser uno de los siguientes:

UnmapGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

Para obtener información adicional sobre la gravedad, consulte la sección 3.3.

El miembro backing_store se establece para indicar cómo el servidor X debe mantener el contenido de una ventana y puede ser WhenMapped, Always o NotUseful. El miembro backing_planes se establece para indicar (con bits puestos a 1) qué planos de bits de la ventana contienen datos dinámicos que deben conservarse en los backing_stores y durante los save_unders. El miembro backing_pixel se establece para indicar qué valores se utilizarán para los planos no establecidos en backing_planes.

El miembro save_under se establece en True o False. El miembro colormap se establece en el mapa de colores de la ventana especificada y puede ser un ID de mapa de colores o None. El miembro map_installed se establece para indicar si el mapa de colores está actualmente instalado y puede ser True o False. El miembro map_state se establece para indicar el estado de la ventana y puede ser IsUnmapped, IsUnviewable o IsViewable. IsUnviewable se utiliza si la ventana está mapeada pero algún antepasado no está mapeado.

El miembro all_event_masks se establece en el OR inclusivo a nivel de bits de todas las máscaras de eventos seleccionadas en la ventana por todos los clientes. El miembro your_event_mask se establece en el OR inclusivo a nivel de bits de todas las máscaras de eventos seleccionadas por el cliente que consulta. El miembro do_not_propagate_mask se establece en el OR inclusivo a nivel de bits del conjunto de eventos que no deben propagarse.

El miembro override_redirect se establece para indicar si esta ventana anula las instalaciones de control de estructura y puede ser True o False. Los clientes del gestor de ventanas deben ignorar la ventana si este miembro es True.

El miembro screen se establece en un puntero de pantalla que le proporciona un puntero de retroceso a la pantalla correcta. Esto facilita la obtención de la información de la pantalla sin tener que recorrer los campos de la ventana raíz para ver qué campo coincide.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.

XGetGeometry(3) — Mandoc

XGetGeometry

X Protocol Requests and Functions

SYNOPSIS

#include <X11/Xutil.h>

int XGetGeometry(
    Display *display,
    Drawable d,
    Window *root_return,
    int *width_return,
    int *height_return,
    int *depth_return,
    int *border_return
);

ARGUMENTS

display
Specifies the connection to the X server.
d
Specifies the drawable (window or pixmap).
root_return
Returns the root window ID of the drawable.
width_return
Returns the width of the drawable.
height_return
Returns the height of the drawable.
depth_return
Returns the depth of the drawable.
border_return
Returns the border width of the drawable.

DESCRIPTION

The XGetGeometry function retrieves the geometry of the specified drawable. The geometry includes the root window ID, width, height, depth, and border width.

STRUCTURES

None.

DIAGNOSTICS

None.
