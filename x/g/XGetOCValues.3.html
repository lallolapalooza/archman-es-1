XCreateOC(3) FUNCIONES DE XLIB XCreateOC(3)

NOMBRE

XCreateOC, XDestroyOC, XSetOCValues, XGetOCValues, XOMOfOC - crear contextos de salida

SINTAXIS

XOC XCreateOC(XOM om, ...);

void XDestroyOC(XOC oc);

char * XSetOCValues(XOC oc, ...);

char * XGetOCValues(XOC oc, ...);

XOM XOMOfOC(XOC oc);

ARGUMENTOS

oc
Especifica el contexto de salida.
om
Especifica el método de salida.
...
Especifica la lista de argumentos de longitud variable para establecer o obtener valores de XOC.

DESCRIPCIÓN

La función XCreateOC crea un contexto de salida dentro del método de salida especificado.

El argumento de nombres de fuentes base es obligatorio en el momento de la creación, y el contexto de salida no se creará a menos que se proporcione. Todos los demás valores del contexto de salida se pueden establecer más tarde.

XCreateOC devuelve NULL si no se pudo crear ningún contexto de salida. NULL se puede devolver por cualquiera de las siguientes razones:

  • No se estableció un argumento obligatorio.
  • Se estableció un argumento de solo lectura.
  • No se reconoce un nombre de argumento.
  • El método de salida encontró un error dependiente de la implementación del método de salida.

La función XDestroyOC destruye el contexto de salida especificado.

La función XSetOCValues devuelve NULL si no ocurrió ningún error; de lo contrario, devuelve el nombre del primer argumento que no se pudo establecer. Un argumento podría no establecerse por cualquiera de las siguientes razones:

  • El argumento es de solo lectura.
  • No se reconoce el nombre del argumento.
  • Ocurre un error dependiente de la implementación.

Cada valor a establecer debe ser un dato apropiado, que coincida con el tipo de datos impuesto por la semántica del argumento.

La función XGetOCValues devuelve NULL si no ocurrió ningún error; de lo contrario, devuelve el nombre del primer argumento que no se pudo obtener. Un argumento podría no obtenerse por cualquiera de las siguientes razones:

  • No se reconoce el nombre del argumento.
  • Ocurre un error dependiente de la implementación.

Cada valor de argumento que sigue a un nombre debe apuntar a una ubicación donde se almacenará el valor.

La función XOMOfOC devuelve el método de salida asociado con el contexto de salida especificado.
