XGetWMName(3)

Paquete: libx11

Licencias: MIT AND X11

XSetWMName(3) FUNCIONES DE XLIB XSetWMName(3)

NOMBRE

XSetWMName, XGetWMName, XStoreName, XFetchName - establecer o leer la propiedad WM_NAME de una ventana

SINTAXIS

void XSetWMName(Display *display, Window w, XTextProperty *text_prop);

Status XGetWMName(Display *display, Window w, XTextProperty *text_prop_return);

int XStoreName(Display *display, Window w, _Xconst char *window_name);

Status XFetchName(Display *display, Window w, char **window_name_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
text_prop
Especifica la estructura XTextProperty que se va a utilizar.
text_prop_return
Devuelve la estructura XTextProperty.
w
Especifica la ventana.
window_name
Especifica el nombre de la ventana, que debe ser una cadena terminada en nulo.
window_name_return
Devuelve el nombre de la ventana, que es una cadena terminada en nulo.

DESCRIPCIÓN

La función de conveniencia XSetWMName llama a XSetTextProperty para establecer la propiedad WM_NAME.

La función de conveniencia XGetWMName llama a XGetTextProperty para obtener la propiedad WM_NAME. Devuelve un estado distinto de cero en caso de éxito; de lo contrario, devuelve un estado cero.

La función XStoreName asigna el nombre pasado a window_name a la ventana especificada. Un gestor de ventanas puede mostrar el nombre de la ventana en algún lugar prominente, como la barra de título, para permitir a los usuarios identificar las ventanas fácilmente. Algunos gestores de ventanas pueden mostrar el nombre de una ventana en el icono de la ventana, aunque se les anima a usar el nombre del icono de la ventana si la aplicación proporciona uno. Si la cadena no está en la Codificación de Caracteres Portátil Host, el resultado es dependiente de la implementación.

XStoreName puede generar errores BadAlloc y BadWindow.

La función XFetchName devuelve el nombre de la ventana especificada. Si tiene éxito, devuelve un estado distinto de cero; de lo contrario, no se ha establecido ningún nombre para la ventana y devuelve cero. Si la propiedad WM_NAME no se ha establecido para esta ventana, XFetchName establece window_name_return a NULL. Si los datos devueltos por el servidor están en la Codificación de Caracteres Portátil Latin, la cadena devuelta está en la Codificación de Caracteres Portátil Host. De lo contrario, el resultado es dependiente de la implementación. Cuando termine con él, un cliente debe liberar la cadena del nombre de la ventana usando XFree.

XFetchName puede generar un error BadWindow.

PROPIEDADES

WM_NAME
El nombre de la aplicación.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
