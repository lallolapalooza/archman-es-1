XGetWMHints(3)

Paquete: libx11

Licencias: MIT AND X11

XAllocWMHints(3) FUNCIONES DE XLIB XAllocWMHints(3)

NOMBRE

XAllocWMHints, XSetWMHints, XGetWMHints, XWMHints - asigna una estructura de sugerencias del gestor de ventanas y establece o lee la propiedad WM_HINTS de una ventana

SINTAXIS

XWMHints *XAllocWMHints(void);

int XSetWMHints(Display *display, Window w, XWMHints *wmhints);

XWMHints *XGetWMHints(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.
wmhints
Especifica la estructura XWMHints a utilizar.

DESCRIPCIÓN

La función XAllocWMHints asigna y devuelve un puntero a una estructura XWMHints. Tenga en cuenta que todos los campos de la estructura XWMHints se inicializan a cero. Si no hay suficiente memoria disponible, XAllocWMHints devuelve NULL. Para liberar la memoria asignada a esta estructura, utilice XFree.

La función XSetWMHints establece las sugerencias del gestor de ventanas que incluyen información y ubicación del icono, el estado inicial de la ventana y si la aplicación depende del gestor de ventanas para recibir entrada de teclado.

XSetWMHints puede generar errores BadAlloc y BadWindow.

La función XGetWMHints lee las sugerencias del gestor de ventanas y devuelve NULL si no se estableció ninguna propiedad WM_HINTS en la ventana, o devuelve un puntero a una estructura XWMHints si tiene éxito. Cuando termine con los datos, libere el espacio utilizado llamando a XFree.

XGetWMHints puede generar un error BadWindow.

PROPIEDADES

WM_HINTS
Sugerencias adicionales establecidas por el cliente para uso del gestor de ventanas. El tipo C de esta propiedad es XWMHints.

ESTRUCTURAS

La estructura XWMHints contiene:

/* bits de máscara de sugerencias del gestor de ventanas */

#define InputHint (1L << 0)
#define StateHint (1L << 1)
#define IconPixmapHint (1L << 2)
#define IconWindowHint (1L << 3)
#define IconPositionHint (1L << 4)
#define IconMaskHint (1L << 5)
#define WindowGroupHint (1L << 6)
#define XUrgencyHint (1L << 8)
#define AllHints (InputHint| StateHint| IconPixmapHint| IconWindowHint| IconPositionHint| IconMaskHint| WindowGroupHint) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        Bool input;     /* ¿depende esta aplicación del gestor de ventanas para
                        recibir entrada de teclado? */
        int initial_state;      /* ver abajo */
        Pixmap icon_pixmap;     /* pixmap a usar como icono */
        Window icon_window;     /* ventana a usar como icono */
        int icon_x, icon_y;     /* posición inicial del icono */
        Pixmap icon_mask;       /* pixmap a usar como máscara para icon_pixmap */
        XID window_group;       /* id del grupo de ventanas relacionadas */
        /* esta estructura puede ser extendida en el futuro */
} XWMHints;

El miembro input se utiliza para comunicar al gestor de ventanas el modelo de foco de entrada utilizado por la aplicación. Las aplicaciones que esperan entrada pero nunca establecen explícitamente el foco en ninguna de sus subventanas (es decir, utilizan el modelo de gestión de foco "push"), como las aplicaciones de estilo X Versión 10 que utilizan foco basado en "real-estate", deben establecer este miembro a True. Del mismo modo, las aplicaciones que establecen el foco de entrada en sus subventanas solo cuando el gestor de ventanas se lo da a su ventana de nivel superior también deben establecer este miembro a True. Las aplicaciones que gestionan su propio foco de entrada estableciendo explícitamente el foco en una de sus subventanas siempre que desean entrada de teclado (es decir, utilizan el modelo de foco "pull") deben establecer este miembro a False. Las aplicaciones que nunca esperan entrada de teclado también deben establecer este miembro a False.

Los gestores de ventanas de modelo "pull" deben hacer posible que las aplicaciones de modelo "push" obtengan entrada estableciendo el foco de entrada en las ventanas de nivel superior de las aplicaciones cuyo miembro input es True. Los gestores de ventanas de modelo "push" deben asegurarse de que las aplicaciones de modelo "pull" no los rompan restableciendo el foco de entrada a PointerRoot cuando sea apropiado (por ejemplo, cada vez que una aplicación cuyo miembro input es False establece el foco de entrada en una de sus subventanas).

Las definiciones para el indicador initial_state son:

#define WithdrawnState 0
#define NormalState 1 /* la mayoría de las aplicaciones comienzan así */
#define IconicState 3 /* la aplicación quiere empezar como un icono */
La máscara icon_mask especifica qué píxeles del icon_pixmap se deben usar como icono. Esto permite iconos no rectangulares. Tanto icon_pixmap como icon_mask deben ser bitmaps. La ventana icon_window permite a una aplicación proporcionar una ventana para ser utilizada como icono para los gestores de ventanas que admiten dicho uso. El window_group le permite especificar que esta ventana pertenece a un grupo de otras ventanas. Por ejemplo, si una sola aplicación manipula múltiples ventanas de nivel superior, esto le permite proporcionar suficiente información para que un gestor de ventanas pueda minimizar (iconify) todas las ventanas en lugar de solo una.

El indicador UrgencyHint, si se establece en el campo flags, indica que el cliente considera que el contenido de la ventana es urgente y requiere la respuesta oportuna del usuario. El gestor de ventanas hará un esfuerzo por llamar la atención del usuario sobre esta ventana mientras este indicador esté establecido. El cliente debe proporcionar algún medio por el cual el usuario pueda hacer que el indicador de urgencia se borre (ya sea mitigando la condición que hizo que la ventana fuera urgente o simplemente apagando la alarma) o que la ventana sea retirada.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.

XGetWMHints(3)

NAME

XGetWMHints - obtiene los datos de sugerencias de ventana del gestor de ventanas

SYNTAX

XSetWMHints(Display *display, Window w, XWMHints *hints)

XGetWMHints(Display *display, Window w, XWMHints *hints)

ARGUMENTS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.
hints
Devuelve las sugerencias de ventana. La estructura XWMHints se define en <X11/Xatom.h>.

DESCRIPTION

La función XGetWMHints recupera los datos de sugerencias de ventana para la ventana especificada por w y los almacena en la estructura hints.

La estructura XWMHints contiene información que las aplicaciones pueden utilizar para comunicarse con el gestor de ventanas sobre las preferencias y el comportamiento de la ventana. Por ejemplo, puede especificar el tamaño mínimo y máximo de la ventana, si la ventana es redimensionable, y si la ventana es una ventana de aplicación principal o una ventana secundaria.

La función XSetWMHints establece los datos de sugerencias de ventana para la ventana especificada por w utilizando la información de la estructura hints.

PROPERTIES

Las sugerencias de ventana se almacenan en la propiedad WM_HINTS de la ventana.

STRUCTURES

La estructura XWMHints tiene la siguiente definición:

typedef struct {
    long flags;
    int x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int width_inc, height_inc;
    int base_width, base_height;
    int min_aspect, max_aspect;
} XWMHints;
flags
Un campo de bits que indica qué campos de la estructura son válidos.
x, y
La posición preferida de la ventana.
width, height
El tamaño preferido de la ventana.
min_width, min_height
El tamaño mínimo de la ventana.
max_width, max_height
El tamaño máximo de la ventana.
width_inc, height_inc
El incremento del tamaño de la ventana (por ejemplo, para aplicaciones que utilizan rejillas).
base_width, base_height
El tamaño base de la ventana (utilizado junto con los incrementos).
min_aspect, max_aspect
Las relaciones de aspecto mínimas y máximas permitidas para la ventana.

DIAGNOSTICS

En caso de error, XGetWMHints y XSetWMHints devuelven NULL.
