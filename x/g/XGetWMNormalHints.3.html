Paquete: libx11

XAllocSizeHints(3) FUNCIONES DE XLIB XAllocSizeHints(3)

NOMBRE

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - asignar estructura de sugerencias de tamaño y establecer o leer la propiedad WM_NORMAL_HINTS de una ventana

SINTAXIS

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
hints
Especifica las sugerencias de tamaño para la ventana en su estado normal.
hints
Especifica la estructura XSizeHints a utilizar.
hints_return
Devuelve las sugerencias de tamaño para la ventana en su estado normal.
property
Especifica el nombre de la propiedad.
supplied_return
Devuelve las sugerencias que fueron proporcionadas por el usuario.
w
Especifica la ventana.

DESCRIPCIÓN

La función XAllocSizeHints asigna y devuelve un puntero a una estructura XSizeHints. Tenga en cuenta que todos los campos de la estructura XSizeHints se inicializan a cero. Si no hay suficiente memoria disponible, XAllocSizeHints devuelve NULL. Para liberar la memoria asignada a esta estructura, utilice XFree.

La función XSetWMNormalHints reemplaza las sugerencias de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. Si la propiedad no existe previamente, XSetWMNormalHints establece las sugerencias de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. La propiedad se almacena con un tipo de WM_SIZE_HINTS y un formato de 32.

XSetWMNormalHints puede generar errores BadAlloc y BadWindow.

La función XGetWMNormalHints devuelve las sugerencias de tamaño almacenadas en la propiedad WM_NORMAL_HINTS en la ventana especificada. Si la propiedad es de tipo WM_SIZE_HINTS, es de formato 32 y es lo suficientemente larga como para contener una estructura de sugerencias de tamaño antigua (pre-ICCCM) o nueva, XGetWMNormalHints establece los diversos campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos), y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero.

Si XGetWMNormalHints se ejecuta correctamente y se lee una propiedad de sugerencias de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente larga como para contener también los campos de tamaño base y gravedad de ventana, el argumento supplied_return contendrá también los siguientes bits:

PBaseSize|PWinGravity

XGetWMNormalHints puede generar un error PN BadWindow.

La función XSetWMSizeHints reemplaza las sugerencias de tamaño para la propiedad especificada en la ventana nombrada. Si la propiedad especificada no existe previamente, XSetWMSizeHints establece las sugerencias de tamaño para la propiedad especificada en la ventana nombrada. La propiedad se almacena con un tipo de WM_SIZE_HINTS y un formato de 32. Para establecer las sugerencias de tamaño normales de una ventana, puede utilizar la función XSetWMNormalHints.

XSetWMSizeHints puede generar errores BadAlloc, BadAtom y BadWindow.

La función XGetWMSizeHints devuelve las sugerencias de tamaño almacenadas en la propiedad especificada en la ventana nombrada. Si la propiedad es de tipo WM_SIZE_HINTS, es de formato 32 y es lo suficientemente larga como para contener una estructura de sugerencias de tamaño antigua (pre-ICCCM) o nueva, XGetWMSizeHints establece los diversos campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos), y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero. Para obtener las sugerencias de tamaño normales de una ventana, puede utilizar la función XGetWMNormalHints.

Si XGetWMSizeHints se ejecuta correctamente y se lee una propiedad de sugerencias de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente larga como para contener también los campos de tamaño base y gravedad de ventana, el argumento supplied_return contendrá también los siguientes bits:

PBaseSize|PWinGravity

XGetWMSizeHints puede generar errores BadAtom y BadWindow.

PROPIEDADES

WM_NORMAL_HINTS
Sugerencias de tamaño para una ventana en su estado normal. El tipo C de esta propiedad es XSizeHints.

ESTRUCTURAS

La estructura XSizeHints contiene:

/* Bits de máscara de sugerencias de tamaño */

#define USPosition (1L << 0) /* usuario especificó x, y */
#define USSize (1L << 1) /* usuario especificó ancho, alto */
#define PPosition (1L << 2) /* programa especificó posición */
#define PSize (1L << 3) /* programa especificó tamaño */
#define PMinSize (1L << 4) /* programa especificó tamaño mínimo */
#define PMaxSize (1L << 5) /* programa especificó tamaño máximo */
#define PResizeInc (1L << 6) /* programa especificó incrementos de redimensionamiento */
#define PAspect (1L << 7) /* programa especificó relaciones de aspecto mínimas y máximas */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        int x, y;       /* Obsoleto */
        int width, height;      /* Obsoleto */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* numerador */
               int y;   /* denominador */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* esta estructura puede ser extendida en el futuro */
} XSizeHints;

Los miembros x, y, width y height ahora son obsoletos y se dejan únicamente por motivos de compatibilidad. Los miembros min_width y min_height especifican el tamaño mínimo de ventana que aún permite que la aplicación sea útil. Los miembros max_width y max_height especifican el tamaño máximo de ventana. Los miembros width_inc y height_inc definen una progresión aritmética de tamaños (mínimo a máximo) en los que la ventana prefiere redimensionarse. Los miembros min_aspect y max_aspect se expresan como proporciones de x e y, y permiten a una aplicación especificar el rango de relaciones de aspecto que prefiere. Los miembros base_width y base_height definen el tamaño deseado de la ventana. El gestor de ventanas interpretará la posición de la ventana y el ancho de su borde para posicionar el punto del rectángulo exterior de la ventana general especificado por el miembro win_gravity. XGetWMNormalHints(3)

XGetWMNormalHints(3) libX11 1.8.12

NAME

XGetWMNormalHints, XSetWMNormalHints - retrieve or set window manager normal hints

SYNOPSIS

#include <X11/Xutil.h>

XWMHints *
XGetWMNormalHints(Display *display, Window w,
    XWMHints **normal_hints_ret, Status *status_ret);
int
XSetWMNormalHints(Display *display, Window w,
    XWMHints *normal_hints);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
normal_hints_ret
A pointer to a pointer to a XWMHints structure. On return, this argument is set to point to the retrieved hints.
status_ret
A pointer to a status value. On return, it is set to 0 if an error occurred or 1 if the hints were retrieved successfully. For XSetWMNormalHints, the return value is 0 if an error occurred or nonzero if the hints were set successfully.
normal_hints
Specifies the XWMHints structure containing the normal hints to be set.

DESCRIPTION

The function XGetWMNormalHints retrieves the WMHints property for the specified window.

The function XSetWMNormalHints sets the WMHints property for the specified window.

The hints are stored in the XWMHints structure, which is defined in <X11/Xutil.h> as:

typedef struct {
    long       flags;
    XIconSize  *icon_size;
    Bool       title_text_specified;
    char       *title;
    char       *icon_name;
    int        input;
    int        initial_state;
    Pixmap     icon_pixmap;
    int        icon_x;
    int        icon_y;
    Pixmap     icon_mask;
    Window     parent;
    XPointer   user_data;
} XWMHints;

The XWMHints structure contains the following fields:

flags
A bitmask that indicates which fields in the structure are set. The following bits are defined:

InputHint

The input field is valid.

StateHint

The initial_state field is valid.

IconPixmapHint

The icon_pixmap, icon_x, and icon_y fields are valid.

IconWindowHint

The icon_pixmap, icon_x, and icon_y fields are valid. The window manager should
      use the specified pixmap as the icon window.

IconMaskHint

The icon_mask field is valid.

WindowGroupHint

The parent field is valid. This field specifies the ID of the parent window
      for the window group.

XUrgencyHint

The input field is set to 1, indicating that the window requires the user's
      urgent attention.
icon_size
A pointer to an XIconSize structure that specifies the minimum and maximum icon sizes the window prefers. This field is only used when setting the hints.
title_text_specified
A boolean value that indicates whether the title text has been specified. This field is obsolete and should not be used.
title
A pointer to the null-terminated string that is the window's title.
icon_name
A pointer to the null-terminated string that is the window's icon name.
input
A boolean value that indicates whether the window should receive keyboard input. 1 means it should receive input, 0 means it should not.
initial_state
Specifies the initial state of the window. It can be one of NormalState, ZoomState, or DontCareState.
icon_pixmap
The pixmap to be used for the window's icon.
icon_x
The x-coordinate for the icon's position.
icon_y
The y-coordinate for the icon's position.
icon_mask
The pixmap to be used as a mask for the icon.
parent
The window ID of the parent window for the window group.
user_data
A pointer to user-defined data. This field is not used by the window manager.

When setting the WMHints property, the application should allocate the XWMHints structure and fill in the appropriate fields. The application is responsible for freeing the memory allocated for the structure using XFree.

When retrieving the WMHints property, the application should allocate a pointer to a XWMHints structure using XFree.

PROPERTIES

WMHints

STRUCTURES

XWMHints

XIconSize

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadWindow
A value for a Window argument does not name a defined Window.
