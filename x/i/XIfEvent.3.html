XIfEvent(3) FUNCIONES XLIB XIfEvent(3)

NOMBRE

XIfEvent, XCheckIfEvent, XPeekIfEvent - comprobar la cola de eventos con un procedimiento predicado

SINTAXIS

int XIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

Bool XCheckIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

int XPeekIfEvent(Display *display, XEvent *event_return, Bool (*predicate)(), XPointer arg);

ARGUMENTOS

arg
Especifica el argumento proporcionado por el usuario que se pasará al procedimiento predicado.
display
Especifica la conexión con el servidor X.
event_return
Devuelve una copia o la estructura asociada del evento coincidente.
predicate
Especifica el procedimiento que se llamará para determinar si el próximo evento en la cola coincide con lo que desea.

DESCRIPCIÓN

La función XIfEvent se completa solo cuando el procedimiento predicado especificado devuelve True para un evento, lo que indica que un evento en la cola coincide. XIfEvent vacía el búfer de salida si se bloquea esperando eventos adicionales. XIfEvent elimina el evento coincidente de la cola y copia la estructura en la estructura XEvent proporcionada por el cliente.

Cuando el procedimiento predicado encuentra una coincidencia, XCheckIfEvent copia el evento coincidente en la estructura XEvent proporcionada por el cliente y devuelve True. (Este evento se elimina de la cola). Si el procedimiento predicado no encuentra ninguna coincidencia, XCheckIfEvent devuelve False y el búfer de salida se habrá vaciado. Todos los eventos anteriores almacenados en la cola no se descartan.

La función XPeekIfEvent solo devuelve cuando el procedimiento predicado especificado devuelve True para un evento. Después de que el procedimiento predicado encuentra una coincidencia, XPeekIfEvent copia el evento coincidente en la estructura XEvent proporcionada por el cliente sin eliminar el evento de la cola. XPeekIfEvent vacía el búfer de salida si se bloquea esperando eventos adicionales.

Cada una de estas funciones requiere que proporcione un procedimiento predicado que determine si un evento coincide con lo que desea. Su procedimiento predicado debe decidir si el evento es útil sin llamar a ninguna función de Xlib. Si el predicado causa directa o indirectamente que el estado de la cola de eventos cambie, el resultado no está definido. Si Xlib se ha inicializado para hilos, el predicado se llama con el display bloqueado y el resultado de una llamada del predicado a cualquier función de Xlib que bloquee el display no está definido a menos que el llamante haya llamado primero a XLockDisplay.

El procedimiento predicado y sus argumentos asociados son:

Bool (*predicate)(Display *display, XEvent *event, XPointer arg)

display
Especifica la conexión con el servidor X.
event
Especifica la estructura XEvent.
arg
Especifica el argumento pasado desde la función XIfEvent, XCheckIfEvent o XPeekIfEvent.

El procedimiento predicado se llama una vez por cada evento en la cola hasta que encuentra una coincidencia. Después de encontrar una coincidencia, el procedimiento predicado debe devolver True. Si no encontró ninguna coincidencia, debe devolver False.

Tenga en cuenta que el procedimiento predicado se llama con el display bloqueado, y por lo tanto no se le permite llamar a ninguna función que vuelva a tomar el bloqueo del display.
