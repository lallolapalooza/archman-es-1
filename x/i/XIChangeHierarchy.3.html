NOMBRE

XIChangeHierarchy - cambia la jerarquía de dispositivos.

SINOPSIS

#include <X11/extensions/XInput2.h>
Status XIChangeHierarchy( Display *display,
                          XIAnyHierarchyChangeInfo *changes,
                          int num_changes);
display
       Especifica la conexión con el servidor X.
num_changes
       Especifica el número de elementos en changes.
changes
       Especifica los cambios a realizar.

DESCRIPCIÓN

XIChangeHierarchy modifica la jerarquía de dispositivos creando o
eliminando dispositivos maestros o cambiando la adjunción de dispositivos esclavos. Si num_changes no es cero, changes es un array de
estructuras XIAnyHierarchyChangeInfo. Si num_changes es igual o menor que
cero, XIChangeHierarchy no hace nada.
XIChangeHierarchy procesa los cambios en orden, efectivos
inmediatamente. Si ocurre un error, el procesamiento se aborta y el
error se reporta al cliente. Los cambios ya realizados permanecen
efectivos.
La lista de cambios es cualquier combinación de
XIAnyHierarchyChangeInfo. El tipo de un cambio de jerarquía puede ser
XIAddMaster, XIRemoveMaster, XIAttachSlave o XIDetachSlave.
typedef union {
    int type;
    XIAddMasterInfo add;
    XIRemoveMasterInfo remove;
    XIAttachSlave attach;
    XIDetachSlave detach;
} XIAnyHierarchyChangeInfo;
typedef struct {
    int type; /* XIAddMaster */
    char* name;
    Bool send_core;
    Bool enable;
} XIAddMasterInfo;
typedef struct {
    int type; /* XIRemoveMaster */
    int deviceid;
    int return_mode;
    int return_pointer;
    int return_keyboard;
} XIRemoveMasterInfo;
typedef struct {
    int type; /* XIAttachSlave */
    int deviceid;
    int new_master;
} XIAttachSlaveInfo;
typedef struct {
    int type; /* XIDetachSlave */
    int deviceid;
} XIDetachSlaveInfo;
XIAddMasterInfo crea un nuevo puntero maestro y un nuevo
teclado maestro etiquetados como "name pointer" y "name keyboard"
respectivamente. Si sendCore es True, los dispositivos enviarán eventos principales. Si enable es True, el dispositivo se habilita inmediatamente.
XIAddMasterInfo puede generar un error BadValue.
XIRemoveMasterInfo elimina el dispositivo y su dispositivo maestro emparejado.
Si returnMode es XIAttachToMaster, todos los punteros adjuntos al
dispositivo o a su dispositivo maestro emparejado se adjuntarán a
returnPointer. De manera similar, todos los teclados se adjuntarán a
returnKeyboard. Si returnMode es XIFloating, todos los dispositivos adjuntos se establecerán como flotantes.
XIRemoveMasterInfo puede generar un error BadValue y BadDevice.
XIAttachSlaveInfo adjunta el dispositivo a new_master. Si el dispositivo
está actualmente adjunto a un dispositivo maestro, se desadjunta del
dispositivo maestro y se adjunta al nuevo dispositivo maestro.
XIAttachSlaveInfo puede generar un error BadDevice.
XIDetachSlaveInfo desadjunta el dispositivo del dispositivo maestro actual
y lo establece como flotante. Si el dispositivo ya está flotante, no se
realizan cambios.
XIDetachSlaveInfo puede generar un error BadDevice.
XIChangeHierarchy genera un XIHierarchyEvent si alguna
modificación fue exitosa.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe o no es apropiado para el tipo de cambio.
BadValue
       Algún valor numérico cae fuera del rango permitido.
