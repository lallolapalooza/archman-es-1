XIconifyWindow(3)

Paquete: libx11

Licencias: MIT AND X11

XIconifyWindow(3) FUNCIONES DE XLIB XIconifyWindow(3)

NOMBRE

XIconifyWindow, XWithdrawWindow, XReconfigureWMWindow - manipular ventanas de nivel superior

SINTAXIS

Status XIconifyWindow(Display *display, Window w, int screen_number);

Status XWithdrawWindow(Display *display, Window w, int screen_number);

Status XReconfigureWMWindow(Display *display, Window w, int screen_number, unsigned int value_mask, XWindowChanges *values);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
screen_number
Especifica el número de pantalla apropiado en el servidor anfitrión.
value_mask
Especifica qué valores se establecerán utilizando la información de la estructura de valores. Esta máscara es la operación OR inclusiva a nivel de bits de los bits de valores válidos de configuración de ventana.
values
Especifica la estructura XWindowChanges.
w
Especifica la ventana.

DESCRIPCION

La función XIconifyWindow envía un evento ClientMessage WM_CHANGE_STATE con un formato de 32 y un primer elemento de datos de IconicState (como se describe en la sección 4.1.4 del Inter-Client Communication Conventions Manual) y una ventana de w a la ventana raíz de la pantalla especificada con una máscara de evento establecida en SubstructureNotifyMask| SubstructureRedirectMask. Los gestores de ventanas pueden optar por recibir este mensaje y, si la ventana está en su estado normal, pueden tratarlo como una solicitud para cambiar el estado de la ventana de normal a icónico. Si la propiedad WM_CHANGE_STATE no se puede internar, XIconifyWindow no envía un mensaje y devuelve un estado cero. Devuelve un estado distinto de cero si el mensaje del cliente se envía correctamente; de lo contrario, devuelve un estado cero.

La función XWithdrawWindow desmapea la ventana especificada y envía un evento sintético UnmapNotify a la ventana raíz de la pantalla especificada. Los gestores de ventanas pueden optar por recibir este mensaje y pueden tratarlo como una solicitud para cambiar el estado de la ventana a retirado. Cuando una ventana está en estado retirado, ni su representación normal ni su representación icónica son visibles. Devuelve un estado distinto de cero si el evento UnmapNotify se envía correctamente; de lo contrario, devuelve un estado cero.

XWithdrawWindow puede generar un error BadWindow.

La función XReconfigureWMWindow emite una solicitud ConfigureWindow en la ventana de nivel superior especificada. Si el modo de apilamiento se cambia y la solicitud falla con un error BadMatch, el error es capturado por Xlib y se envía un evento sintético ConfigureRequestEvent que contiene los mismos parámetros de configuración a la raíz de la ventana especificada. Los gestores de ventanas pueden optar por recibir este evento y tratarlo como una solicitud para reconfigurar la ventana indicada. Devuelve un estado distinto de cero si la solicitud o el evento se envían correctamente; de lo contrario, devuelve un estado cero.

XReconfigureWMWindow puede generar errores BadValue y BadWindow.

DIAGNÓSTICOS

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
