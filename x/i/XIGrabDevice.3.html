XIGRABDEVICE(3)   XIGRABDEVICE(3)

NOMBRE

XIGrabDevice, XIUngrabDevice - capturar o liberar el dispositivo.

SINOPSIS

#include <X11/extensions/XInput2.h>
Status XIGrabDevice( Display *display,
                     int deviceid,
                     Window grab_window,
                     Time time,
                     Cursor cursor,
                     int grab_mode,
                     int paired_device_mode,
                     Bool owner_events,
                     XIEventMask *mask);
Status XIUngrabDevice( Display *display,
                       int deviceid,
                       Time time);
cursor
       Especifica la imagen del cursor a mostrar durante la
       captura.
display
       Especifica la conexión con el servidor X.
deviceid
       Especifica el dispositivo que debe ser capturado o
       liberado.
grab_mode, paired_device_mode
       El modo de captura para este dispositivo y (si es aplicable)
       el dispositivo emparejado.
grab_window
       La ventana de captura.
mask
       Máscara de eventos.
owner_events
       True si los eventos se deben reportar normalmente.
time
       Una marca de tiempo válida o CurrentTime.

DESCRIPCIÓN

XIGrabDevice captura activamente el control del dispositivo. Los eventos
posteriores del dispositivo se informan solo al cliente que captura.
XIGrabDevice anula cualquier captura de dispositivo activa por este cliente.
Si el dispositivo es un dispositivo esclavo conectado, el dispositivo se
desconecta automáticamente del dispositivo maestro y se vuelve a conectar
al mismo dispositivo maestro cuando el cliente libera la captura del
dispositivo. Si el dispositivo maestro se elimina mientras el dispositivo
está flotando como resultado de una captura, el dispositivo permanece
flotando una vez que la captura se desactiva.
Si owner_events es False, todos los eventos de dispositivo generados se
informan con respecto a grab_window si se seleccionan. Si
owner_events es True y si un evento de dispositivo generado se
informaría normalmente a este cliente, se informa normalmente;
de lo contrario, el evento se informa con respecto a
grab_window, y solo se informa si se especifica en la máscara de
eventos.
Si el argumento grab_mode es XIGrabModeAsync, el procesamiento de eventos
del dispositivo continúa como de costumbre. Si el dispositivo está
actualmente congelado por este cliente, se reanuda el procesamiento de los
eventos del dispositivo. Si el argumento grab_mode es XIGrabModeSync, el
estado del dispositivo (tal como lo ven las aplicaciones cliente) parece
congelarse, y el servidor X no genera más eventos de dispositivo hasta que
el cliente que captura emite una llamada XIAllowEvents de liberación o hasta
que se libera la captura del dispositivo. Los cambios reales del dispositivo
no se pierden mientras el dispositivo está congelado; simplemente se
ponen en cola en el servidor para su procesamiento posterior.
Si paired_device_mode es XIGrabModeAsync, el procesamiento de eventos del
dispositivo maestro emparejado no se ve afectado por la activación de la
captura. Si paired_device_mode es XIGrabModeSync, el estado del dispositivo
maestro emparejado (tal como lo ven las aplicaciones cliente) parece
congelarse, y el servidor X no genera más eventos de este dispositivo hasta
que el cliente que captura emita una llamada XIAllowEvents de liberación o
hasta que se libere la captura del dispositivo. Los eventos reales no se
pierden mientras los dispositivos están congelados; simplemente se ponen
en cola en el servidor para su procesamiento posterior. Si el dispositivo es
un dispositivo esclavo, paired_device_mode se ignora.
Si el dispositivo está activamente capturado por otro cliente,
XIGrabDevice falla y devuelve AlreadyGrabbed. Si grab_window no es visible,
falla y devuelve GrabNotViewable. Si el dispositivo está congelado por una
captura activa de otro cliente, falla y devuelve GrabFrozen. Si la marca de
tiempo especificada es anterior a la última marca de tiempo de captura de
dispositivo o posterior a la hora actual del servidor X, falla y devuelve
GrabInvalidTime. De lo contrario, la última marca de tiempo de captura de
dispositivo se establece en la marca de tiempo especificada. CurrentTime
se reemplaza por la hora actual del servidor X.
Si cursor no es None, este cursor se muestra hasta que el cliente llama a
XIUngrabDevice.
XIGrabDevice puede generar errores BadDevice, BadValue y BadWindow.
La solicitud XIUngrabDevice libera el dispositivo y cualquier evento en cola
si este cliente lo tiene activamente capturado desde XIGrabDevice o
XIGrabKey o XIGrabButton. Si otros dispositivos están congelados por la
captura, XUngrabDevice los descongela. XUngrabDevice no libera el
dispositivo y los eventos en cola si la marca de tiempo especificada es
anterior a la marca de tiempo de captura de dispositivo más reciente o es
posterior a la hora actual del servidor X. El servidor X realiza
automáticamente una solicitud XIUngrabDevice si la ventana de eventos para
una captura de dispositivo activa no se vuelve visible.
XIUngrabDevice puede generar un error BadDevice.

DIAGNÓSTICOS

BadValue
       Un valor está fuera del rango permitido.
BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe o no es apropiado para el tipo de cambio.
BadMatch
       La ventana no es visible.
BadWindow
       Un valor para un argumento de Ventana no nombra una
       Ventana definida.

ERRORES

Los encabezados del protocolo para XI 2.0 no proporcionaron
XIGrabModeAsync o XIGrabModeSync. Use GrabModeSync y
GrabModeAsync respectivamente en su lugar.
