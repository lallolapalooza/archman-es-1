NOMBRE

XIQueryPointer - obtener las coordenadas del puntero del dispositivo.

SINOPSIS

#include <X11/extensions/XInput2.h>
Bool XIQueryPointer( Display *display,
                     int deviceid,
                     Window win,
                     Window *root_return,
                     Window *child_return,
                     double *root_x_return,
                     double *root_y_return,
                     double *win_x_return,
                     double *win_y_return,
                     XIButtonState *buttons_return,
                     XIModifierState *modifiers_return,
                     XIGroupState *group_return);
buttons_return
       Devuelve el estado actual de los botones.
child_return
       Devuelve la ventana hija en la que se encuentra el puntero,
       si la hay.
deviceid
       Especifica el dispositivo a consultar.
display
       Especifica la conexión con el servidor X.
group_return
       Devuelve el estado actual del grupo.
modifiers_return
       Devuelve el estado actual de las teclas modificadoras.
root_return
       Devuelve la ventana raíz en la que se encuentra el puntero.
root_x_return, root_y_return
       Devuelven las coordenadas del puntero relativas al origen
       de la ventana raíz.
win
       Especifica la ventana.
win_x_return, win_y_return
       Devuelven las coordenadas del puntero relativas a la ventana
       especificada.

DESCRIPCIÓN

La función XIQueryPointer devuelve la ventana raíz en la que se
encuentra lógicamente el puntero del dispositivo y las coordenadas
del puntero relativas al origen de la ventana raíz. Si XIQueryPointer
devuelve False, el puntero no está en la misma pantalla que la
ventana especificada, y XIQueryPointer devuelve None a
child_return y cero a win_x_return y win_y_return. Si
XIQueryPointer devuelve True, las coordenadas del puntero devueltas
a win_x_return y win_y_return son relativas al origen de la ventana
especificada. En este caso, XIQueryPointer devuelve la ventana hija
que contiene el puntero, si la hay, o None a child_return.
XIQueryPointer devuelve el estado lógico actual de los botones
buttons_return. El teclado emparejado con el puntero maestro se
selecciona para obtener los datos de modifiers_return y
group_return.
El campo mask en buttons_return se asigna dinámicamente y debe
ser liberado por el llamante.
XIQueryPointer es idéntica a XQueryPointer pero especifica el
dispositivo explícitamente.
XIQueryPointer puede generar un error BadDevice y un error
BadWindow.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe o no es un dispositivo puntero.
BadWindow
       Un valor para un argumento Window no nombra una ventana
       definida.
