XIICHANGEPROPERTY(3)   XIICHANGEPROPERTY(3)

NOMBRE

XIChangeProperty, XIGetProperty, XIDeleteProperty - cambiar, recuperar o eliminar una propiedad de un dispositivo.

SINOPSIS

#include <X11/extensions/XInput2.h>
void XIChangeProperty( Display* dpy,
                       int deviceid,
                       Atom property,
                       Atom type,
                       int format,
                       int mode,
                       unsigned char *data,
                       int num_items)
void XIDeleteProperty( Display *dpy,
                       int deviceid,
                       Atom property)
Status XIGetProperty( Display *dpy,
                      int deviceid,
                      Atom property,
                      long offset,
                      long length,
                      Bool delete_property,
                      Atom type,
                      Atom *type_return,
                      int *format_return,
                      unsigned long *num_items_return,
                      unsigned long *bytes_after_return,
                      unsigned char **data)
bytes_after_return
       Devuelve el número de bytes restantes por leer en la propiedad
       si se realizó una lectura parcial.
data
       Especifica los datos de la propiedad.
display
       Especifica la conexión con el servidor X.
delete_property
       Especifica un valor booleano que determina si la propiedad
       debe ser eliminada.
deviceid
       El dispositivo para listar las propiedades.
format
       Especifica si los datos deben ser vistos como una lista de
       cantidades de 8, 16 o 32 bits. Los valores posibles son 8,
       16 y 32. Esta información permite al servidor X realizar correctamente
       las operaciones de intercambio de bytes según sea necesario. Si el
       formato es de 16 o 32 bits, debe convertir explícitamente su
       puntero de datos a (unsigned char *) en la llamada a
       XIChangeProperty.
format_return
       Devuelve el formato real de la propiedad.
length
       Especifica la longitud en múltiplos de 32 bits de los datos a recuperar.
offset
       Especifica el desplazamiento en la propiedad especificada (en cantidades
       de 32 bits) desde donde se deben recuperar los datos.
mode
       Uno de XIPropModeAppend, XIPropModePrepend o XIPropModeReplace.
num_items
       Número de elementos en data en el formato especificado.
nitems_return
       Devuelve el número real de elementos de 8, 16 o 32 bits
       almacenados en data.
property
       Especifica el nombre de la propiedad.
type
       Especifica el tipo de la propiedad. El servidor X no
       interpreta el tipo, sino que simplemente lo devuelve a una aplicación
       que posteriormente llama a XIGetProperty.
type_return
       Devuelve el identificador del átomo que define el tipo real de
       la propiedad.

DESCRIPCIÓN

La función XIGetProperty devuelve el tipo real de la propiedad; el formato real de la propiedad; el número de elementos de 8, 16 o 32 bits transferidos; el número de bytes restantes por leer en la propiedad; y un puntero a los datos realmente devueltos. XIGetProperty establece los argumentos de retorno de la siguiente manera:

•Si la propiedad especificada no existe para el dispositivo especificado, XIGetProperty devuelve None a actual_type_return y el valor cero a actual_format_return y bytes_after_return. El argumento nitems_return está vacío. En este caso, el argumento delete se ignora.
•Si la propiedad especificada existe pero su tipo no coincide con el tipo especificado, XIGetProperty devuelve el tipo real de la propiedad a actual_type_return, el formato real de la propiedad (nunca cero) a actual_format_return, y la longitud de la propiedad en bytes (incluso si actual_format_return es 16 o 32) a bytes_after_return. También ignora el argumento delete. El argumento nitems_return está vacío.
•Si la propiedad especificada existe y usted asigna XIAnyPropertyType al argumento req_type o si el tipo especificado coincide con el tipo real de la propiedad, XIGetProperty devuelve el tipo real de la propiedad a actual_type_return y el formato real de la propiedad (nunca cero) a actual_format_return. También devuelve un valor a bytes_after_return y nitems_return, definiendo los siguientes valores: 
N = longitud de la propiedad almacenada en bytes
I = 4 * offset
T = N - I
L = MINIMO(T, 4 * length)
A = N - (I + L)

El valor devuelto comienza en el índice de byte I en la propiedad (indexando desde cero), y su longitud en bytes es L. Si el valor de long_offset hace que L sea negativo, se produce un error BadValue.

El valor de bytes_after_return es A, que indica el número de bytes no leídos al final de la propiedad almacenada.

Si el formato devuelto es 8, los datos devueltos se representan como una matriz de caracteres. Si el formato devuelto es 16, los datos devueltos se representan como una matriz de uint16_t y deben ser convertidos a ese tipo para obtener los elementos. Si el formato devuelto es 32, los datos devueltos se representan como una matriz de uint32_t y deben ser convertidos a ese tipo para obtener los elementos.

XIGetProperty siempre asigna un byte adicional en prop_return (incluso si la propiedad tiene longitud cero) y lo establece a cero para que las propiedades simples que consisten en caracteres no tengan que ser copiadas a otra cadena antes de su uso.

Si delete es True y bytes_after_return es cero, XIGetProperty elimina la propiedad de la ventana y genera un evento XIPropertyNotify en la ventana.

La función devuelve Success si se ejecuta correctamente. Para liberar los datos resultantes, use XFree.

XIGetProperty puede generar errores BadAtom, BadValue y BadWindow.

La función XIChangeProperty modifica la propiedad para el dispositivo especificado y hace que el servidor X genere un evento XIPropertyNotify para ese dispositivo. XIChangeProperty realiza lo siguiente:

•Si mode es XIPropModeReplace, XIChangeProperty descarta el valor anterior de la propiedad y almacena los nuevos datos.
•Si mode es XIPropModePrepend o XIPropModeAppend, XIChangeProperty inserta los datos especificados antes del inicio de los datos existentes o al final de los datos existentes, respectivamente. El tipo y el formato deben coincidir con el valor existente de la propiedad, de lo contrario, se produce un error BadMatch. Si la propiedad no está definida, se trata como definida con el tipo y formato correctos con datos de longitud cero.

Si el formato especificado es 8, los datos de la propiedad deben ser una matriz de caracteres. Si el formato especificado es 16, los datos de la propiedad deben ser una matriz de uint16_t. Si el formato especificado es 32, los datos de la propiedad deben ser una matriz de uint32_t.

La vida útil de una propiedad no está ligada al cliente que la almacena. Las propiedades permanecen hasta que se eliminan explícitamente, hasta que se elimina el dispositivo, o hasta que el servidor se reinicia. El tamaño máximo de una propiedad depende del servidor y puede variar dinámicamente según la cantidad de memoria que tenga disponible el servidor. (Si no hay suficiente espacio, se produce un error BadAlloc).

XIChangeProperty puede generar errores BadAlloc, BadAtom, BadMatch, BadValue y BadDevice.

La función XIDeleteProperty elimina la propiedad especificada solo si la propiedad estaba definida en el dispositivo especificado y hace que el servidor X genere un evento XIPropertyNotify para el dispositivo, a menos que la propiedad no exista.

XIDeleteProperty puede generar errores BadAtom y BadDevice.

DIAGNÓSTICOS

BadAlloc El servidor no pudo asignar el recurso solicitado o memoria del servidor.

BadAtom Un valor para un argumento Atom no nombra un Átomo definido.

BadValue Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.

BadDevice Se especificó un dispositivo inválido. El dispositivo no existe.

BadAtom Se especificó una propiedad inválida. La propiedad no existe.

ERRORES

Las cabeceras del protocolo para XI 2.0 no proporcionaron
XIAnyPropertyType, XIPropModeReplace, XIPropModePrepend o
XIPropModeAppend. Use AnyPropertyType, PropModeReplace,
PropModePrepend y PropModeAppend en su lugar, respectivamente.

NOMBRE

XIChangeProperty, XIPropertyNotification - cambiar y notificar propiedades de XI

SINOPSIS

    #include <X11/extensions/XI.h>
    #include <X11/extensions/XInput.h>

    int XIChangeProperty(
        Display *display,
        XID window,
        Atom property,
        Atom type,
        int format,
        int mode,
        const unsigned char *data,
        int nelements
    );

    void XIPropertyNotification(
        Display *display,
        XID window,
        Atom property,
        Bool enable
    );

DESCRIPCIÓN

La función XIChangeProperty cambia el valor de la propiedad especificada para la ventana especificada. Las propiedades son pares clave-valor que se almacenan con las ventanas. Los usos comunes de las propiedades incluyen almacenar el título de la ventana, la información del cliente y otra información que el servidor X y sus clientes puedan necesitar intercambiar.

El argumento display es el manejador de conexión X.

El argumento window es el identificador de la ventana cuya propiedad se va a cambiar.

El argumento property es el átomo que identifica la propiedad que se va a cambiar. Los átomos son identificadores únicos para cadenas de texto. Puedes obtener un átomo usando la función XInternAtom.

El argumento type es el átomo que especifica el tipo de datos de la propiedad. Los tipos comunes incluyen XA_STRING, XA_INTEGER, etc.

El argumento format especifica el formato de los datos de la propiedad. Los valores posibles son 8, 16 o 32.

El argumento mode especifica cómo se deben cambiar los datos de la propiedad. Los valores posibles son PropModeReplace, PropModePrepend y PropModeAppend. PropModeReplace reemplaza el valor existente de la propiedad con los nuevos datos. PropModePrepend antepone los nuevos datos al valor existente de la propiedad. PropModeAppend añade los nuevos datos al final del valor existente de la propiedad.

El argumento data es un puntero a los datos de la propiedad que se van a escribir.

El argumento nelements es el número de elementos de datos en el búfer data.

La función XIPropertyNotification habilita o deshabilita las notificaciones de cambios de propiedad para la ventana y propiedad especificadas. Si enable es True, se enviará un evento PropertyNotify cuando la propiedad cambie. Si enable es False, no se enviarán eventos.

DIAGNÓSTICOS

XIChangeProperty devolverá BadAtom si la propiedad o el tipo especificados no son átomos válidos. Devolverá BadValue si el formato o el modo no son válidos. Devolverá BadWindow si la ventana especificada no es válida.

ERRORES

No se conocen errores en este momento.
