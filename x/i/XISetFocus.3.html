XISetFocus(3)   XISetFocus(3)

NOMBRE

XISetFocus, XIGetFocus - establecer u obtener el foco del dispositivo.

SINOSIS

#include <X11/extensions/XInput2.h>
Status XISetFocus( Display *display,
                   int deviceid,
                   Window focus,
                   Time time);
Status XIGetFocus( Display *display,
                   Window *focus_return);
display
       Especifica la conexión con el servidor X.
deviceid
       Especifica el dispositivo cuyo foco se va a consultar o
       cambiar.
focus
       La nueva ventana de foco.
focus_return
       Devuelve la ventana de foco actual.
time
       Una marca de tiempo válida o CurrentTime.

DESCRIPCIÓN

XISetFocus cambia el foco del dispositivo especificado y su
hora de último cambio de foco. No tiene ningún efecto si la hora
especificada es anterior a la hora actual de último cambio de foco
o es posterior a la hora actual del servidor X. De lo contrario, la
hora de último cambio de foco se establece en la hora especificada.
CurrentTime se reemplaza por la hora actual del servidor X).
XISetFocus hace que el servidor X genere eventos de foco
principales, XI y XI2.
Si la ventana de foco es None, todos los eventos de teclado de este
dispositivo se descartan hasta que se establezca una nueva ventana de
foco. De lo contrario, si foco es una ventana, se convierte en la
ventana de foco del dispositivo. Si un evento de dispositivo generado
normalmente se informaría a esta ventana o a uno de sus inferiores, el
evento se informa como de costumbre. De lo contrario, el evento se
informa en relación con la ventana de foco.
La ventana de foco especificada debe ser visible en el momento en que
se llama a XISetFocus, o se produce un error BadMatch. Si la ventana
de foco posteriormente deja de ser visible, el foco revierte al
padre (o al ancestro visible más cercano. Cuando el foco revierte, el
servidor X genera eventos de foco principales, XI y XI2, pero la hora
del último cambio de foco no se ve afectada.
Intentar establecer el foco en un dispositivo puntero maestro o un
dispositivo esclavo adjunto dará como resultado un error BadDevice.
XISetFocus puede generar errores BadDevice, BadMatch, BadValue y
BadWindow.

DIAGNÓSTICOS

BadValue
       Un valor está fuera del rango permitido.
BadDevice
       Se especificó un dispositivo no válido. El dispositivo no
       existe o no es apropiado para el tipo de cambio.
BadMatch
       La ventana no es visible.
BadWindow
       Un valor para un argumento Window no nombra una Window
       definida.
