display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo que se va a capturar o liberar
button
       Especifica el botón del dispositivo que se va a capturar o
       liberar o XIAnyButton.
keycode
       Especifica el código de tecla que se va a capturar o liberar
       o XIAnyKeycode.
num_modifiers
       Número de elementos en modifiers o modifiers_inout.
modifiers
       Especifica el conjunto de modificadores fijados y base o
       XIAnyModifier para liberar. El tipo de dato es para
       consistencia con la solicitud de captura respectiva y el
       código de estado de la estructura XIGrabModifiers se ignora.
modifiers_inout
       Especifica el conjunto de modificadores fijados y base o
       XIAnyModifier para capturar. Devuelve los modificadores que no se
       pudieron capturar y su código de error.
grab_window
       Especifica la ventana de captura.
owner_events
       Especifica un valor booleano que indica si los eventos
       deben ser reportados como de costumbre o reportados con
       respecto a la ventana de captura.
mask
       Especifica la máscara de eventos.
grab_mode
       Especifica el procesamiento adicional de eventos de este
       dispositivo. Puedes pasar XIGrabModeSync o XIGrabModeAsync.
paired_device_mode
       Especifica el procesamiento adicional de eventos del dispositivo
       maestro emparejado. Puedes pasar XIGrabModeSync o
       XIGrabModeAsync. Si deviceid especifica un dispositivo esclavo
       flotante, este parámetro se ignora.

DESCRIPCIÓN

XIGrabButton, XIGrabKeycode, XIGrabTouchBegin, XIGrabPinchGestureBegin,
XIGrabSwipeTouchBegin establecen una captura pasiva.
El dispositivo modificador para una captura de botón es el dispositivo
maestro emparejado si deviceid especifica un puntero maestro. De lo
contrario, el dispositivo modificador es el dispositivo especificado
con deviceid. En el futuro, el dispositivo es capturado activamente
(como para XIGrabDevice, la última hora de captura se establece en
el momento en que se presionó el botón o la tecla y el evento
XI_ButtonPress o XI_KeyPress se informa si se cumplen todas las
siguientes condiciones:
  * El dispositivo no está capturado, y el botón o tecla especificado
    se presiona lógicamente, ocurre un toque o un evento de gesto
    cuando las teclas modificadoras especificadas están lógicamente
    presionadas en el dispositivo modificador y ningún otro botón o tecla
    modificadora está lógicamente presionado.
  * O bien, la ventana de captura es un antecesor de (o es) la ventana
    de foco, O bien, la ventana de captura es un descendiente de la
    ventana de foco y contiene el dispositivo.
  * No existe una captura pasiva en el mismo botón/combinación
    modificadora en ningún antecesor de grab_window.
La interpretación de los argumentos restantes es la misma que para
XIGrabDevice. La captura activa se termina automáticamente cuando
el estado lógico del dispositivo tiene todos los botones o teclas
liberados (independientemente del estado lógico de las teclas
modificadoras).
Si el dispositivo es un dispositivo esclavo adjunto, el dispositivo se
desconecta automáticamente del dispositivo maestro cuando la captura
se activa y se vuelve a conectar al mismo dispositivo maestro cuando
la captura se desactiva. Si se elimina el dispositivo maestro mientras
el dispositivo está flotando como resultado de una captura, el
dispositivo permanece flotando una vez que la captura se desactiva.
Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven
las aplicaciones cliente) puede ir a la zaga del estado físico si el
procesamiento de eventos del dispositivo está congelado.
Esta solicitud anula todas las capturas anteriores del mismo cliente
en las mismas combinaciones de botón/modificador o tecla/modificador en
la misma ventana. Un modificador de XIAnyModifier es equivalente a
emitir la solicitud de captura para todas las combinaciones de
modificadores posibles (incluida la combinación de ningún
modificador). No es necesario que todos los modificadores especificados
tengan códigos de tecla asignados actualmente. Un botón de XIAnyButton
es equivalente a emitir la solicitud para todos los botones posibles.
De lo contrario, no es necesario que el botón especificado esté
actualmente asignado a un botón físico.
Si algún otro cliente ya ha emitido un XIGrabButton o
XIGrabKeycode con la misma combinación de botón/modificador o
tecla/modificador en la misma ventana, se produce un error
BadAccess. Al usar XIAnyModifier o XIAnyButton, la solicitud
falla por completo y se produce un error XIBadAccess
(no se establecen capturas) si hay una captura conflictiva para
cualquier combinación. XIGrabButton y XIGrabKeycode no tienen
efecto sobre una captura activa.
En caso de éxito, XIGrabButton, XIGrabKeycode, XIGrabTouchBegin,
XIGrabPinchGestureBegin y XIGrabSwipeGestureBegin devuelven 0;
Si una o más combinaciones de modificadores no pudieron ser
capturadas, XIGrabButton, XIGrabKeycode, XIGrabTouchBegin,
XIGrabPinchGestureBegin y XIGrabSwipeGestureBegin devuelven el número de
combinaciones fallidas y modifiers_inout contiene las combinaciones
fallidas y sus respectivos códigos de error.
XIGrabButton, XIGrabKeycode, XIGrabTouchBegin, XIGrabPinchGestureBegin
y XIGrabSwipeGestureBegin pueden generar errores BadClass,
BadDevice, BadMatch, BadValue y BadWindow.
XIUngrabButton, XIUngrabKeycode, XIUngrabTouchBegin, XIUngrabPinchGestureBegin
y XIUngrabSwipeGestureBegin liberan la
captura pasiva para una combinación de botón/modificador, tecla/modificador
o toque/modificador en la ventana especificada si fue capturada por
este cliente. Un modificador de XIAnyModifier es equivalente a
emitir la solicitud de liberación para todas las combinaciones de
modificadores posibles, incluida la combinación de ningún
modificador. Un botón de XIAnyButton es equivalente a emitir la
solicitud para todos los botones posibles.
XIUngrabButton y XIUngrabKeycode no tienen efecto sobre una
captura activa.

XIGrabTouchBegin(3)

NAME

XIGrabTouchBegin, XIUngrabTouchBegin - grab a touch device, or ungrab a touch device

SYNOPSIS

        #include <X11/extensions/XInput.h>

        int XIGrabButton ( Display *display ,
                           int button ,
                           int grab_window ,
                           unsigned int event_mask ,
                           int pointer_mode ,
                           int keyboard_mode ,
                           Window grab_window ,
                           const String *owner_events ,
                           Time *time_of_grab ,
                           int *modifiers_inout )

        int XIGrabKeycode ( Display *display ,
                            int keycode ,
                            int grab_window ,
                            unsigned int event_mask ,
                            int pointer_mode ,
                            int keyboard_mode ,

        int XIGrabTouchBegin ( Display *display ,
                               int grab_window ,
                               unsigned int event_mask ,
                               int pointer_mode ,
                               int keyboard_mode ,

                               Time *time_of_grab ,
                               int *modifiers_inout )

        int XIGrabPinchGestureBegin ( Display *display ,
                                      int grab_window ,
                                      unsigned int event_mask ,
                                      int pointer_mode ,
                                      int keyboard_mode ,
                                      Window grab_window ,
                                      const String *owner_events ,
                                      Time *time_of_grab ,
                                      int *modifiers_inout )

        int XIGrabSwipeGestureBegin ( Display *display ,
                                      int grab_window ,
                                      unsigned int event_mask ,
                                      int pointer_mode ,
                                      int keyboard_mode ,
                                      Window grab_window ,
                                      const String *owner_events ,
                                      Time *time_of_grab ,
                                      int *modifiers_inout )

        int XIUngrabButton ( Display *display ,
                             int button ,
                             Window grab_window ,
                             const String *owner_events )

        int XIUngrabKeycode ( Display *display ,
                              int keycode ,
                              Window grab_window ,
                              const String *owner_events )

        int XIUngrabTouchBegin ( Display *display ,
                                 Window grab_window ,
                                 const String *owner_events )

        int XIUngrabPinchGestureBegin ( Display *display ,
                                        Window grab_window ,
                                        const String *owner_events )

        int XIUngrabSwipeGestureBegin ( Display *display ,
                                        Window grab_window ,
                                        const String *owner_events )

DESCRIPTION

These functions establish or terminate a passive grab on a device. A passive
grab is one where the server waits for a specific device event to occur
before activating the grab. For example, a passive grab on button 1 of pointer
device 0 might be activated when button 1 of pointer device 0 is pressed.
The grab is then active until the button is released.

The following arguments are common to all these functions:

display:
       Specifies the connection to the X server.

grab_window:
       Specifies the window in which the grab is to occur. All events that
       are being grabbed will be reported to this window.

event_mask:
       Specifies the events that are to be grabbed. This mask is composed
       of valid XI events.

pointer_mode:
       Specifies the mode in which the pointer is to be grabbed. This may
       be GrabModeSync or GrabModeAsync.

keyboard_mode:
       Specifies the mode in which the keyboard is to be grabbed. This may
       be GrabModeSync or GrabModeAsync.

owner_events:
       Specifies whether events that would normally be reported to the owner
       of the grab are reported to the client that made the grab request.
       If owner_events is True, events are reported to the client.
       If owner_events is False, events are reported to the window.

time_of_grab:
       Specifies the time at which the grab is to occur. You can use the
       CurrentTime symbol for the current server time.

modifiers_inout:
       Specifies the modifiers that are to be grabbed. This is a bitmask
       that is composed of valid XI modifiers.

The XIGrabButton, XIUngrabButton, XIUngrabKeycode, XIUngrabTouchBegin,
XIUngrabPinchGestureBegin and XIUngrabSwipeGestureBegin functions differ
in what they grab:

XIGrabButton:
       Grabs the specified button on the specified device.

XIUngrabButton:
       Ungrabs the specified button on the specified device.

XIUngrabKeycode:
       Grabs the specified keycode on the specified device.

XIUngrabKeycode:
       Ungrabs the specified keycode on the specified device.

XIUngrabTouchBegin:
       Grabs the beginning of a touch sequence on the specified device.

XIUngrabTouchBegin:
       Ungrabs the beginning of a touch sequence on the specified device.

XIUngrabPinchGestureBegin:
       Grabs the beginning of a pinch gesture on the specified device.

XIUngrabPinchGestureBegin:
       Ungrabs the beginning of a pinch gesture on the specified device.

XIUngrabSwipeGestureBegin:
       Grabs the beginning of a swipe gesture on the specified device.

XIUngrabSwipeGestureBegin:
       Ungrabs the beginning of a swipe gesture on the specified device.

Note thatXIUngrabButton, XIUngrabKeycode, XIUngrabTouchBegin,
XIUngrabPinchGestureBegin and XIUngrabSwipeGestureBegin can generate
BadDevice, BadMatch, BadValue and BadWindow errors.

RETURN VALUE

XIGrabButton, XIGrabKeycode, XIGrabTouchBegin and
XIGrabPinchGestureBegin and XIGrabSwipeGestureBegin return the number of
modifier combination that could not establish a passive grab. The
modifiers are returned in modifiers_inout, along with the respective
error for this modifier combination. If XIGrabButton, XIGrabKeycode
or XIGrabTouchBegin return zero, passive grabs with all requested
modifier combinations were established successfully.

DIAGNOSTICS

BadDevice
       An invalid deviceid was specified.
BadMatch
       This error may occur if XIGrabButton specified a device
       that has no buttons, or XIGrabKeycode specified a device
       that has no keys,
       or XIGrabTouchBegin specified a device that is not touch-capable,
       or XIGrabPinchGestureBegin specified a device that is not gesture-capable,
       or XIGrabSwipeGestureBegin specified a device that is not gesture-capable.
BadValue
       Some numeric value falls outside the range of values
       accepted by the request. Unless a specific range is
       specified for an argument, the full range defined by the
       argument's type is accepted. Any argument defined as a
       set of alternatives can generate this error.
BadWindow
       A value for a Window argument does not name a defined
       Window.

BUGS

The protocol headers for XI 2.0 did not provide
XIGrabModeAsync or XIGrabModeSync. Use GrabModeSync and
GrabModeAsync instead, respectively.
