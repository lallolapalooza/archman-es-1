NOMBRE

XIGrabEnter, XIUngrabEnter, XIGrabFocusIn, XIUngrabFocusIn - capturar/liberar eventos de entrada o foco.

SINOPSIS

#include <X11/extensions/XInput.h>
int XIGrabEnter( Display *display,
                 int deviceid,
                 Window grab_window,
                 Cursor cursor,
                 int grab_mode,
                 int paired_device_mode,
                 Bool owner_events,
                 XIEventMask *mask,
                 int num_modifiers,
                 XIGrabModifiers *modifiers_inout);
int XIUngrabEnter( Display *display,
                   int deviceid,
                   Window grab_window
                   int num_modifiers,
                   XIGrabModifiers *modifiers);
int XIGrabFocusIn ( Display *display,
                    int deviceid,
                    Window grab_window
                    int grab_mode,
                    int paired_device_mode,
                    Bool owner_events,
                    XIEventMask *mask,
                    int num_modifiers,
                    XIGrabModifiers *modifiers_inout);
int XIUngrabFocusIn( Display *display,
                     int deviceid,
                     Window grab_window
                     int num_modifiers,
                     XIGrabModifiers *modifiers);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo que se va a capturar o liberar
num_modifiers
       Número de elementos en modifiers o modifiers_inout.
modifiers
       Especifica el conjunto de modificadores latcheados y base o
       XIAnyModifier para liberar. El tipo de dato es para
       consistencia con la solicitud de captura respectiva y el
       código de estado de la estructura XIGrabModifiers se ignora.
modifiers_inout
       Especifica el conjunto de modificadores latcheados y base o
       XIAnyModifier para capturar. Devuelve los modificadores que no
       pudieron ser capturados y su código de estado.
grab_window
       Especifica la ventana de captura.
owner_events
       Especifica un valor booleano que indica si los eventos
       deben reportarse como de costumbre o reportarse con respecto a
       la ventana de captura.
mask
       Especifica la máscara de eventos.
grab_mode
       Especifica el procesamiento adicional de eventos de este dispositivo.
       Puede pasar XIGrabModeSync o XIGrabModeAsync.
paired_device_mode
       Especifica el procesamiento adicional de eventos del dispositivo maestro emparejado.
       Puede pasar XIGrabModeSync o XIGrabModeAsync. Si deviceid especifica un dispositivo esclavo flotante, este parámetro se ignora.

DESCRIPCIÓN

XIGrabEnter y XIGrabFocusIn establecen una captura pasiva. El
dispositivo modificador para una captura de entrada es el dispositivo
maestro emparejado si deviceid especifica un puntero maestro. De lo
contrario, el dispositivo modificador es el dispositivo especificado con
deviceid.
Para XIGrabEnter y XIGrabFocusIn, en el futuro, el dispositivo se
captura activamente (como para XIGrabDevice, el tiempo de la última
captura se establece en el momento en que el puntero/foco entró en la
ventana) si el dispositivo no está capturado y el puntero ha entrado
en grab_window o el foco se ha establecido en grab_window cuando las
teclas modificadoras especificadas están lógicamente pulsadas en el
dispositivo modificador y ningún otro botón o tecla modificadora está
lógicamente pulsada.
La interpretación de los argumentos restantes es la misma que para
XIGrabDevice. La captura activa se termina automáticamente cuando
el puntero sale de la ventana o el foco se establece en una ventana
diferente (independientemente del estado lógico de las teclas
modificadoras).
Si el dispositivo es un dispositivo esclavo adjunto, el dispositivo
se desvincula automáticamente del dispositivo maestro cuando la captura
se activa y se vuelve a vincular al mismo dispositivo maestro cuando
la captura se desactiva. Si el dispositivo maestro se elimina mientras
el dispositivo está flotando como resultado de una captura, el
dispositivo permanece flotando una vez que la captura se desactiva.
Tenga en cuenta que el estado lógico de un dispositivo (visto por
las aplicaciones cliente) puede tener un retraso con respecto al
estado físico si el procesamiento de eventos del dispositivo está
congelado.
Esta solicitud anula todas las capturas anteriores por el mismo
cliente del mismo tipo y combinaciones de modificadores en la misma
ventana. Un modificador de XIAnyModifier es equivalente a emitir
la solicitud de captura para todas las combinaciones de modificadores
posibles (incluida la combinación de ningún modificador). No es
necesario que todos los modificadores especificados tengan KeyCodes
asignados actualmente.
Si algún otro cliente ya ha emitido un XIGrabEnter o XIGrabFocusIn
en la misma ventana, se produce un error BadAccess. Al usar
XIAnyModifier, la solicitud falla por completo y se produce un error
XIBadAccess (no se establecen capturas) si hay una captura conflictiva
para cualquier combinación. XIGrabEnter y XIGrabFocusIn no tienen
efecto sobre una captura activa.
En caso de éxito, XIGrabEnter y XIGrabFocusIn devuelven 0;
Si una o más combinaciones de modificadores no pudieron ser
capturadas, XIGrabEnter y XIGrabFocusIn devuelven el número de
combinaciones fallidas y modifiers_inout contiene las combinaciones
fallidas y sus respectivos códigos de estado.
XIGrabEnter y XIGrabFocusIn pueden generar errores BadDevice,
BadMatch, BadValue y BadWindow.
XIUngrabEnter y XIUngrabFocusIn liberan la captura pasiva en
la ventana especificada si fue capturada por este cliente. Un
modificador de XIAnyModifier es equivalente a emitir la solicitud
de liberación para todas las combinaciones de modificadores posibles,
incluida la combinación de ningún modificador. XIUngrabEnter y
XIUngrabFocusIn no tienen efecto sobre una captura activa.
XIUngrabEnter y XIUngrabFocusIn pueden generar errores BadDevice,
BadMatch, BadValue y BadWindow.

VALOR DE RETORNO

XIGrabEnter y XIGrabFocusIn devuelven el número de combinaciones de
modificadores que no pudieron establecer una captura pasiva. Los
modificadores se devuelven en modifiers_inout, junto con el error
respectivo para esta combinación de modificadores. Si XIGrabEnter o
XIGrabFocusIn devuelven cero, las capturas pasivas con todas las
combinaciones de modificadores solicitadas se establecieron
exitosamente.

DIAGNÓSTICOS

BadDevice
       Se especificó un deviceid no válido.
BadMatch
       Este error puede ocurrir si XIGrabEnter especificó un dispositivo
       que no tiene valuadores, o XIGrabFocusIn especificó un dispositivo
       que no tiene teclas.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un rango
       particular para un argumento, se acepta el rango completo definido por
       el tipo del argumento. Cualquier argumento definido como un
       conjunto de alternativas puede generar este error.
BadWindow
       Un valor para un argumento Window no nombra una Ventana definida.

ERRORES CONOCIDOS

Las cabeceras del protocolo para XI 2.0 no proporcionaron
XIGrabModeAsync o XIGrabModeSync. Use GrabModeSync y
GrabModeAsync respectivamente.

NAME

XIGrabEnter - Enter a grab

SYNTAX

XIGrabEnter(display, grab)

ARGUMENTS

display

The X Display structure for the connection.

grab

The grab structure to enter.

DESCRIPTION

The XIGrabEnter function enters the specified grab. This means that the grab becomes active and will start intercepting events. The grab must have been previously created using XIGrabInit.

This function is typically called after all necessary setup for the grab has been completed, and the application is ready to start handling the grabbed events.

When a grab is entered, the X server will redirect all input events that match the conditions specified in the grab structure to the client that owns the grab. This is commonly used for implementing features like drag-and-drop, modal dialogs, or custom input handling.

RETURN VALUE

This function does not return a value.

SEE ALSO

XIGrabInit, XIGrabFree, XIGrabEvent
