XINERAMA(3) Manual de funciones de biblioteca XINERAMA(3)

NOMBRE

Xinerama - API para la extensión Xinerama del Protocolo X11

SINOPSIS

#include <X11/extensions/Xinerama.h>

Bool XineramaQueryExtension (Display *dpy,
	int *event_base_return, int *error_base_return);

Status XineramaQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

Bool XineramaIsActive (Display *dpy);

XineramaScreenInfo * XineramaQueryScreens (Display *dpy,
	int *number);

ARGUMENTOS

display
Especifica la conexión al servidor X.
event_base_return
Especifica la ubicación de retorno para el código de evento base asignado
error_base_return
Especifica la ubicación de retorno para el código de error base asignado
major_version_return
Devuelve la versión principal compatible con el servidor
minor_version_return
Devuelve la versión menor compatible con el servidor
number
Devuelve el número de entradas en la matriz XineramaScreenInfo devuelta.

DESCRIPCIÓN

Xinerama es una biblioteca simple diseñada para interactuar con la Extensión Xinerama para recuperar información sobre dispositivos de salida físicos que pueden combinarse en una única pantalla X lógica.

FUNCIONES

XineramaQueryExtension()

La función XineramaQueryExtension consulta al Xserver para determinar la disponibilidad de la Extensión Xinerama. Si la extensión está disponible, el valor de retorno es True, y event_base_return y error_base_return se establecen en el número de evento base y el número de error base para la extensión, respectivamente. De lo contrario, el valor de retorno es False, y los valores de event_base_return y error_base_return no están definidos.

XineramaQueryVersion()

La función XineramaQueryVersion devuelve la versión de la extensión Xinerama implementada por el Xserver. La versión se devuelve en major_version_return y minor_version_return. La versión principal se incrementará para cambios incompatibles con el protocolo, y la versión menor se incrementará para cambios pequeños y compatibles hacia atrás.

Si la biblioteca Xinerama es compatible con la versión devuelta por el servidor, devuelve un valor distinto de cero. Si el servidor no admite la extensión XINERAMA, o si hubo un error durante las comunicaciones con el servidor, o si las versiones del protocolo del servidor y la biblioteca son incompatibles, devuelve cero.

XineramaIsActive()

La función XineramaIsActive devuelve un operador booleano utilizado para determinar si Xinerama está activado en la pantalla. Devuelve True para activo y False para inactivo.

XineramaQueryScreens()

La función XineramaQueryScreens() devuelve información sobre cada dispositivo de salida individual dentro de la Pantalla Xinerama. El entero al que apunta el argumento number se actualiza al número de dispositivos de salida listados en la matriz devuelta de estructuras XineramaScreenInfo. XineramaQueryScreens() devuelve NULL y establece number a 0 si Xinerama no está activo.

El puntero devuelto debe liberarse con XFree(3) cuando ya no se necesite.

NOTA

La API original proporcionada para interactuar con la extensión XINERAMA utilizaba nombres de función que comenzaban con XPanoramiX. Esa API está ahora obsoleta y esta API debe usarse en su lugar en software nuevo.
