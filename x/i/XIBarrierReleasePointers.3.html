XIBARRIERRELEASEPOIN(3)   XIBARRIERRELEASEPOIN(3)

NOMBRE

XIBarrierReleasePointer, XIBarrierReleasePointers - permite el movimiento del puntero a través de una barrera de puntero

SINOPSIS

#include <X11/extensions/XInput2.h>
int XIBarrierReleasePointer( Display *display,
                             int deviceid,
                             PointerBarrier barrier,
                             BarrierEventID eventid);
int XIBarrierReleasePointers( Display *display,
                              XIBarrierReleasePointerInfo *barriers,
                              int num_barriers);
display
       Especifica la conexión con el servidor X.
deviceid
       Especifica el dispositivo al que se le permite moverse a través de la barrera.
barrier
       Especifica la barrera.
eventid
       Especifica el ID de evento único para esta secuencia de eventos de barrera.
barriers
       Lista de tripletas de deviceid, barrier, eventid.
num_barriers
       Número de elementos en barriers.

DESCRIPCIÓN

Si un puntero está restringido por una barrera de puntero, libera el puntero
de la barrera y permite que cruce la barrera con el siguiente movimiento.
Si el puntero se aleja de la barrera, esta solicitud no hace nada.
Esta solicitud solo libera el puntero para la secuencia de eventos de barrera
dada. Si el puntero se aleja o atraviesa la barrera, se genera un evento
XI_BarrierLeave. Los movimientos futuros del puntero restringidos por esta barrera
asignarán un nuevo eventid y requerirán una nueva solicitud
XIBarrierReleasePointer.
Si el puntero no está actualmente bloqueado por la barrera o la secuencia de
eventos de barrera ha finalizado, esta solicitud no hace nada.
XIBarrierReleasePointer y XIBarrierReleasePointers pueden generar un
error BadDevice o BadValue.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo no
       existe o no es un dispositivo puntero maestro.
BadValue
       Un valor para un argumento PointerBarrier no nombra una barrera de puntero
       definida.
