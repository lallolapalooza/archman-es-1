Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XISELECTEVENTS(3)   XISELECTEVENTS(3)

NOMBRE

XISelectEvents, XIGetSelectedEvents - seleccionar o obtener eventos XI2 seleccionados en la ventana.

SINOPSIS

#include <X11/extensions/XInput2.h>
Status XISelectEvents( Display *display,
                       Window win,
                       XIEventMask *masks,
                       int num_masks);
display
       Especifica la conexión con el servidor X.
masks
       Máscara de eventos del dispositivo.
num_masks
       Número de máscaras en masks.
win
       Especifica la ventana.
XIEventMask *XIGetSelectedEvents( Display *display,
                                  Window win,
                                  int *num_masks_return);
display
       Especifica la conexión con el servidor X.
num_masks_return
       Número de máscaras en el valor de retorno.
win
       Especifica la ventana.

DESCRIPCIÓN

Los eventos XI2 deben ser seleccionados usando XISelectEvents.
XISelectEvents establece la máscara de eventos para este cliente en win.
Los eventos posteriores solo se informan a este cliente si el tipo de evento
coincide con la máscara de eventos seleccionada. Las máscaras anulan la
máscara de eventos seleccionada previamente para el dispositivo dado.
Si deviceid es un dispositivo válido, la máscara de eventos se selecciona solo
para este dispositivo. Si deviceid es XIAllDevices o
XIAllMasterDevices, la máscara de eventos se selecciona para todos los
dispositivos o todos los dispositivos maestros, respectivamente. La máscara de
eventos efectiva es la OR a nivel de bits de XIAllDevices, XIAllMasterDevices y
la máscara de eventos del dispositivo respectivo.
typedef struct {
    int deviceid;
    int mask_len;
    unsigned char* mask;
} XIEventMask;
mask_len especifica la longitud de mask en bytes. mask es una
máscara binaria en la forma de (1 << event type). deviceid debe ser
un dispositivo o XIAllDevices o XIAllMasterDevices. Un cliente puede enviar
varias máscaras con el mismo deviceid en una solicitud, pero solo la última
máscara será efectiva.
XISelectEvents puede generar un error BadValue, BadDevice y BadWindow.
XIGetSelectedEvents devuelve los eventos seleccionados por este cliente en la
ventana dada. Si no se seleccionaron eventos en esta ventana, XIGetSelectedEvents
devuelve NULL y num_masks_return se establece en 0. Si ocurre un error interno,
XIGetSelectedEvents devuelve NULL y num_masks_return se establece en -1.
De lo contrario, XIGetSelectedEvent devuelve las máscaras de eventos
seleccionadas para todos los dispositivos, incluidas las máscaras para
XIAllDevices y XIAllMasterDevices.
El llamador debe liberar los datos devueltos usando XFree().

DIAGNÓSTICOS

BadValue
       Un valor está fuera del rango permitido.
BadWindow
       Un valor para un argumento Window no nombra una ventana
       definida.
BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe.
