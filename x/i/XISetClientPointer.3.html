XISETCLIENTPOINTER(3)   XISETCLIENTPOINTER(3)

NOMBRE

XISetClientPointer, XIGetClientPointer - establecer u obtener el dispositivo ClientPointer.

SINOPSIS

#include <X11/extensions/XInput2.h>
XISetClientPointer( Display *display,
                    Window win,
                    int deviceid);
Bool XIGetClientPointer( Display *display,
                         Window win,
                         int *device);
display
       Especifica la conexión con el servidor X.
win
       Especifica una ventana perteneciente al cliente. Puede ser None.
deviceid
       Especifica el dispositivo ClientPointer.

DESCRIPCIÓN

El ClientPointer es el dispositivo que se percibe como el
puntero principal para las solicitudes y respuestas del protocolo no-XI. Cada
vez que un mensaje de protocolo necesita datos dependientes del dispositivo y el
dispositivo no se proporciona explícitamente, se utiliza el dispositivo ClientPointer
para obtener los datos. Por ejemplo, una solicitud XQueryPointer
devolverá las coordenadas del ClientPointer.
La solicitud XISetClientPointer establece el dispositivo ClientPointer para
el cliente que posee la ventana dada. Si win es None, el
ClientPointer del cliente solicitante se establece en el dispositivo
especificado con deviceid. Solo los dispositivos de puntero maestros pueden ser
establecidos como ClientPointer.
XISetClientPointer puede generar un error BadDevice y un error BadWindow.
La solicitud XIGetClientPointer devuelve el ID del dispositivo ClientPointer
para el cliente que posee la ventana dada. Si win es None, se devuelve el
ClientPointer del cliente solicitante.
win puede ser un ID de cliente en lugar de una ventana.
XIGetClientPointer puede generar un error BadWindow.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo no
       existe o no es un dispositivo de puntero maestro.
BadWindow
       Un valor para un argumento de Ventana no nombra una ventana
       definida.
