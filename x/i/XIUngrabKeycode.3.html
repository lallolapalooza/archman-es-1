display
       Especifica la conexión con el servidor X.
deviceid
       Especifica el dispositivo que se va a capturar o liberar
button
       Especifica el botón del dispositivo que se va a capturar o
       liberar o XIAnyButton.
keycode
       Especifica el código de tecla que se va a capturar o liberar
       o XIAnyKeycode.
num_modifiers
       Número de elementos en modifiers o modifiers_inout.
modifiers
       Especifica el conjunto de modificadores enclavados y base o
       XIAnyModifier para liberar. El tipo de dato es para consistencia con la
       solicitud de captura respectiva y se ignora el código de estado de la
       struct XIGrabModifiers.
modifiers_inout
       Especifica el conjunto de modificadores enclavados y base o
       XIAnyModifier para capturar. Devuelve los modificadores que no se pudieron
       capturar y su código de error.
grab_window
       Especifica la ventana de captura.
owner_events
       Especifica un valor booleano que indica si los eventos
       se van a informar como de costumbre o se van a informar con respecto a la
       ventana de captura.
mask
       Especifica la máscara de eventos.
grab_mode
       Especifica el procesamiento adicional de eventos de este dispositivo.
       Se puede pasar XIGrabModeSync o XIGrabModeAsync.
paired_device_mode
       Especifica el procesamiento adicional de eventos del dispositivo maestro emparejado.
       Se puede pasar XIGrabModeSync o XIGrabModeAsync. Si deviceid especifica un dispositivo esclavo flotante, este parámetro se ignora.

DESCRIPCIÓN

XIGrabButton, XIGrabKeycode, XIGrabTouchBegin, XIGrabPinchGestureBegin,
XIGrabSwipeTouchBegin establecen una captura pasiva.
El dispositivo modificador para una captura de botón es el dispositivo maestro emparejado
si deviceid especifica un puntero maestro. De lo contrario, el dispositivo modificador
es el dispositivo especificado con deviceid. En el futuro,
el dispositivo se captura activamente (como para XIGrabDevice, la
última hora de captura se establece en la hora en que se
presionó el botón o el código de tecla y el evento XI_ButtonPress o XI_KeyPress se
informa si se cumplen todas las siguientes condiciones:
  * El dispositivo no está capturado, y el botón o
    código de tecla especificado está lógicamente presionado, ocurre un evento táctil o de gesto
    cuando las teclas modificadoras especificadas están lógicamente pulsadas en el dispositivo modificador
    y ningún otro botón o tecla modificadora está lógicamente pulsado.
  * La ventana de captura es un ancestro de (o es) la ventana de foco, O
    la ventana de captura es un descendiente de la ventana de foco y contiene el dispositivo.
  * No existe una captura pasiva en el mismo botón/modificador en ningún ancestro de grab_window.
La interpretación de los argumentos restantes es como para
XIGrabDevice. La captura activa se termina automáticamente cuando
el estado lógico del dispositivo tiene todos los botones o teclas
liberados (independientemente del estado lógico de las teclas modificadoras).
Si el dispositivo es un dispositivo esclavo adjunto, el dispositivo se
desconecta automáticamente del dispositivo maestro cuando se activa la captura
y se vuelve a conectar al mismo dispositivo maestro cuando se desactiva la captura.
Si el dispositivo maestro se elimina mientras el dispositivo está flotando como resultado de una captura, el dispositivo permanece flotando una vez que la captura se desactiva.
Tenga en cuenta que el estado lógico de un dispositivo (visto por las aplicaciones cliente) puede retrasarse respecto al estado físico si el procesamiento de eventos del dispositivo está congelado.
Esta solicitud anula todas las capturas anteriores del mismo cliente en las
mismas combinaciones de botón/modificador o código de tecla/modificador en la
misma ventana. Un modificador de XIAnyModifier es equivalente a emitir la solicitud de captura para todas las combinaciones de modificadores posibles (incluida la combinación de ningún modificador). No es necesario que todos los modificadores especificados tengan códigos de tecla asignados actualmente.
Un botón de XIAnyButton es equivalente a emitir la solicitud para todos los botones posibles. De lo contrario, no es necesario que el botón especificado esté actualmente asignado a un botón físico.
Si algún otro cliente ya ha emitido una XIGrabButton o
XIGrabKeycode con la misma combinación de botón/modificador o código de tecla/modificador
en la misma ventana, se produce un error BadAccess. Cuando
se utiliza XIAnyModifier o XIAnyButton , la solicitud falla
completamente y se produce un error XIBadAccess (no se establece ninguna captura)
si existe una captura en conflicto para alguna
combinación. XIGrabButton y XIGrabKeycode no tienen efecto sobre una
captura activa.
En caso de éxito, XIGrabButton, XIGrabKeycode, XIGrabTouchBegin,
XIGrabPinchGestureBegin y XIGrabSwipeGestureBegin devuelven 0;
Si una o más combinaciones de modificadores no se pudieron capturar,
XIGrabButton, XIGrabKeycode, XIGrabTouchBegin, XIGrabPinchGestureBegin
y XIGrabSwipeGestureBegin devuelven el número de
combinaciones fallidas y modifiers_inout contiene las combinaciones fallidas
y sus respectivos códigos de error.
XIGrabButton, XIGrabKeycode, XIGrabTouchBegin, XIGrabPinchGestureBegin
y XIGrabSwipeGestureBegin pueden generar errores BadClass,
BadDevice, BadMatch, BadValue y BadWindow.
XIUngrabButton, XIUngrabKeycode, XIUngrabTouchBegin, XIUngrabPinchGestureBegin
y XIUngrabSwipeGestureBegin liberan la
captura pasiva para una combinación de botón/modificador, código de tecla/modificador o táctil/modificador
en la ventana especificada si fue capturada por este cliente. Un
modificador de XIAnyModifier es equivalente a emitir la solicitud de liberación para todas las combinaciones de modificadores posibles, incluida la
combinación de ningún modificador. Un botón de XIAnyButton es
equivalente a emitir la solicitud para todos los botones posibles.
XIUngrabButton y XIUngrabKeycode no tienen efecto sobre una captura activa.

NAME

XIUngrabKeycode, XIUngrabButton, XIUngrabPinchGestureBegin, XIUngrabSwipeGestureBegin - liberar teclas, botones o gestos de entrada.

SYNOPSIS

#include <X11/extensions/XInput.h>

int XIUngrabKeycode(Display *display,
                    int deviceid,
                    int count,
                    XIRegion region,
                    int mode);
int XIUngrabButton(Display *display,
                   int deviceid,
                   int button,
                   XIRegion region,
                   int mode);
int XIUngrabPinchGestureBegin(Display *display,
                              int deviceid,
                              XIRegion region,
                              int mode);
int XIUngrabSwipeGestureBegin(Display *display,
                              int deviceid,
                              XIRegion region,
                              int mode);

DESCRIPTION

Estas funciones liberan los grabados de teclas, botones o gestos de entrada
en el dispositivo especificado por deviceid.
Las funciones XIUngrabKeycode, XIUngrabButton,
XIUngrabPinchGestureBegin y XIUngrabSwipeGestureBegin
pueden generar los errores BadDevice, BadMatch, BadValue y BadWindow.

VALOR DE RETORNO

XIGrabButton, XIGrabKeycode, XIUngrabKeycode, XIUngrabButton, XIUngrabPinchGestureBegin
y XIUngrabSwipeGestureBegin devuelven el número de combinaciones de modificadores
que no pudieron establecer un grab pasivo. Los modificadores se devuelven en
modifiers_inout, junto con el error respectivo para esta combinación de modificadores.
Si XIGrabButton, XIGrabKeycode o XIGrabTouchBegin devuelven cero, los grabs pasivos
con todas las combinaciones de modificadores solicitadas se establecieron
correctamente.

DIAGNÓSTICOS

BadDevice
       Se especificó un deviceid inválido.

BadMatch
       Este error puede ocurrir si XIGrabButton especificó un dispositivo
       que no tiene botones, o XIGrabKeycode especificó un dispositivo
       que no tiene teclas,
       o XIUngrabTouchBegin especificó un dispositivo que no es táctil,
       o XIUngrabPinchGestureBegin especificó un dispositivo que no es capaz de gestos,
       o XIUngrabSwipeGestureBegin especificó un dispositivo que no es capaz de gestos.

BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un rango
       específico para un argumento, se acepta el rango completo definido por
       el tipo del argumento. Cualquier argumento definido como un
       conjunto de alternativas puede generar este error.

BadWindow
       Un valor para un argumento Window no nombra una Window definida.

BUGS

Las cabeceras del protocolo para XI 2.0 no proporcionaron
XIGrabModeAsync o XIGrabModeSync. Utilice GrabModeSync y
GrabModeAsync en su lugar, respectivamente.
