XIQUERYVERSION(3)   XIQUERYVERSION(3)

NOMBRE

XIQueryVersion - anuncia y consulta la versión soportada de XI2.

SINOPSIS

#include <X11/extensions/XInput2.h>
Status XIQueryVersion( Display *display,
                       int *major_version_inout,
                       int *minor_version_inout);
display
       Especifica la conexión con el servidor X.
major_version_inout
       Especifica la versión XI2 soportada por el cliente, y
       devuelve la versión soportada por el servidor.
minor_version_inout
       Especifica la versión XI2 soportada por el cliente, y
       devuelve la versión soportada por el servidor.

DESCRIPCIÓN

XIQueryVersion anuncia la versión XI2 soportada por el cliente al
servidor y devuelve la versión X Input soportada por el servidor. Los
clientes deben usar XIQueryVersion en lugar de XGetExtensionVersion
si utilizan llamadas XI2. El servidor puede tratar a un cliente de
manera diferente dependiendo de la versión soportada anunciada por el
cliente.
La versión major_version_inout debe ser 2 o superior, de lo contrario se
produce un error BadValue.
Si el servidor no soporta XI2, XIQueryVersion devuelve BadRequest
al cliente. De lo contrario, XIQueryVersion devuelve Success. En ambos
casos, major_version_inout y minor_version_inout se establecen a la
versión soportada por el servidor.
Si el cliente ha llamado previamente a XIQueryVersion, el resultado
depende de la versión solicitada previamente y la versión solicitada
actualmente.
Si alguna de las versiones solicitadas anteriormente o actualmente es
menor que 2.2, o si los números de versión principal solicitados no
coinciden, entonces las llamadas consecutivas a XIQueryVersion por el
mismo cliente siempre devuelven la primera versión principal.minor devuelta.
Si el cliente solicita una versión inferior a la primera versión
principal.minor devuelta en una llamada posterior, se produce un error
BadValue.
Si todas las versiones solicitadas son 2.2 o superiores, entonces las
llamadas consecutivas a XIQueryVersion por el mismo cliente con la
misma versión principal devolverán la versión solicitada, pero el
servidor operará de acuerdo con el número de versión más alto
solicitado o la versión más alta soportada, el que sea menor.
XIQueryVersion puede generar un error BadValue.

EJEMPLOS

int rc;
int major = 2;
int minor = 0;
rc = XIQueryVersion(dpy, &major, &minor);
if (rc == Success)
    printf("Soportado XI2. (%d.%d)\n", major, minor);
else if (rc == BadRequest)
    printf("Sin soporte XI2. (solo %d.%d)\n", major, minor);
else
    printf("Error interno\n");

DIAGNÓSTICOS

BadValue
       Un valor está fuera del rango permitido.
