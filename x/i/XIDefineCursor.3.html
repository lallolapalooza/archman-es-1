XIDEFINECURSOR(3)   XIDEFINECURSOR(3)

NOMBRE

XIDefineCursor, XIUndefineCursor - definir cursores de dispositivo.

SINOPSIS

#include <X11/extensions/XInput2.h>
int XIDefineCursor( Display *display,
                    int deviceid,
                    Window win,
                    Cursor cursor);
int XIUndefineCursor( Display *display,
                      int deviceid,
                      Window win);
cursor
       Especifica el cursor que se va a mostrar o None.
deviceid
       Especifica el dispositivo cuyo cursor va a cambiar.
display
       Especifica la conexión con el servidor X.
win
       Especifica la ventana.

DESCRIPCIÓN

Si se establece un cursor, se utilizará cuando el puntero del dispositivo esté
en la ventana. Si el cursor es None, es equivalente a XIUndefineCursor.
El deviceid debe ser un dispositivo de puntero maestro o se devolverá un error
BadDevice.
XIDefineCursor puede generar BadDevice, BadCursor y BadWindow.
La función XIUndefineCursor deshace el efecto de una llamada anterior a
XIDefineCursor para esta ventana. Cuando el puntero esté en la ventana, ahora
se utilizará el cursor por defecto de la ventana. Si no se define ningún cursor
por defecto, se utilizará el cursor del padre para este dispositivo (si está
definido) o se utilizará el cursor por defecto del padre.
XIDefineCursor y XIUndefineCursor son idénticos a XDefineCursor y
XUndefineCursor pero especifican el dispositivo explícitamente.
XIUndefineCursor puede generar un error BadDevice y BadWindow.

DIAGNÓSTICOS

BadCursor
       Un valor para un argumento de cursor no designa un cursor definido.
BadDevice
       Se especificó un dispositivo inválido. El dispositivo no existe o no es un
       dispositivo de puntero.
BadWindow
       Un valor para un argumento Window no designa una ventana definida.
