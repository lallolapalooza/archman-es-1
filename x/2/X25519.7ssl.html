NOMBRE

X25519, X448 - Soporte EVP_PKEY X25519 y X448

DESCRIPCIÓN

La implementación EVP_PKEY X25519 y X448 soporta la generación de claves y la derivación de claves utilizando X25519 y X448. Tiene formatos de clave privada y pública asociados compatibles con RFC 8410.

No se pueden establecer parámetros adicionales durante la generación de claves.

La clave pública del par debe establecerse usando EVP_PKEY_derive_set_peer() al realizar la derivación de claves.

NOTAS

Se puede obtener un contexto para el algoritmo X25519 llamando a:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_X25519, NULL);

Para el algoritmo X448 se puede obtener un contexto llamando a:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_X448, NULL);

Las claves privadas X25519 o X448 se pueden establecer directamente usando EVP_PKEY_new_raw_private_key(3) o cargarse desde un archivo de clave privada PKCS#8 usando PEM_read_bio_PrivateKey(3) (o una función similar). También se pueden generar claves completamente nuevas (ver el ejemplo a continuación). Establecer una clave privada también establece la clave pública asociada.

Las claves públicas X25519 o X448 se pueden establecer directamente usando EVP_PKEY_new_raw_public_key(3) o cargarse desde una estructura SubjectPublicKeyInfo en un archivo PEM usando PEM_read_bio_PUBKEY(3) (o una función similar).

EJEMPLOS

Este ejemplo genera una clave privada X25519 y la escribe en la salida estándar en formato PEM:

#include <openssl/evp.h>
#include <openssl/pem.h>
...
EVP_PKEY *pkey = NULL;
EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_X25519, NULL);
EVP_PKEY_keygen_init(pctx);
EVP_PKEY_keygen(pctx, &pkey);
EVP_PKEY_CTX_free(pctx);
PEM_write_PrivateKey(stdout, pkey, NULL, NULL, 0, NULL, NULL);

El ejemplo de derivación de claves en EVP_PKEY_derive(3) puede usarse con X25519 y X448.

VER TAMBIÉN

EVP_PKEY_CTX_new(3), EVP_PKEY_keygen(3), EVP_PKEY_derive(3), EVP_PKEY_derive_set_peer(3)
