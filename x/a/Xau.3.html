Xau(3) Manual de funciones de biblioteca Xau(3)

NOMBRE

Biblioteca Xau: XauFileName, XauReadAuth, XauLockAuth, XauUnlockAuth, XauWriteAuth, XauDisposeAuth, XauGetAuthByAddr, XauGetBestAuthByAddr - Rutinas de la base de datos de autorización X

SINOPSIS

#include <X11/Xauth.h>
typedef struct xauth {
        unsigned short  family;
        unsigned short  address_length;
        char    *address;
        unsigned short  number_length;
        char    *number;
        unsigned short  name_length;
        char    *name;
        unsigned short  data_length;
        char    *data;
} Xauth;
char *XauFileName (void);
Xauth *XauReadAuth (FILE *auth_file);
int XauWriteAuth (FILE *auth_file, Xauth *auth);
Xauth *XauGetAuthByAddr (unsigned short family, unsigned short
address_length, const char *address, unsigned short
number_length, const char *number, unsigned short
name_length, const char *name);
Xauth *XauGetBestAuthByAddr (unsigned short family, unsigned short
address_length, const char *address, unsigned short
number_length, const char *number, int types_length,
char **types, const int *type_lengths);
int XauLockAuth (const char *file_name, int retries, int
timeout, long dead);
int XauUnlockAuth (const char *file_name);
int XauDisposeAuth (Xauth *auth);

DESCRIPCIÓN

XauFileName genera el nombre del archivo de autorización predeterminado comprobando primero la variable de entorno XAUTHORITY si está configurada, de lo contrario, devuelve $HOME/.Xauthority. Este nombre se asigna estáticamente y no debe liberarse.

XauReadAuth lee la siguiente entrada de auth_file. La entrada **no** se asigna estáticamente y debe liberarse llamando a XauDisposeAuth.

XauWriteAuth escribe una entrada de autorización en auth_file. Devuelve 1 si tiene éxito, 0 si falla.

XauGetAuthByAddr busca una entrada que coincida con el par de dirección de red/número de pantalla proporcionado. La entrada **no** se asigna estáticamente y debe liberarse llamando a XauDisposeAuth.

XauGetBestAuthByAddr es similar a XauGetAuthByAddr, excepto que se especifica una lista de métodos de autenticación aceptables. Xau elegirá la entrada del archivo que coincida con la entrada más temprana en esta lista (por ejemplo, el método de autenticación más seguro). El argumento types es una matriz de cadenas, una cadena para cada método de autenticación. types_length especifica cuántos elementos hay en la matriz types. types_lengths es una matriz de enteros que representa la longitud de cada cadena.

XauLockAuth realiza el trabajo necesario para actualizar sincrónicamente un archivo de autorización. Primero crea dos nombres de archivo, uno con ``-c'' añadido a file_name, el otro con ``-l'' añadido. Si el archivo ``-c'' ya existe y tiene más de dead segundos de antigüedad, XauLockAuth lo elimina a él y al archivo ``-l'' asociado. Para evitar posibles problemas de sincronización con NFS, un valor de dead de cero fuerza la eliminación de los archivos. XauLockAuth realiza retries intentos para crear y enlazar los nombres de archivo, pausando timeout segundos entre cada intento. XauLockAuth devuelve una colección de valores dependiendo de los resultados:

LOCK_ERROR
Ocurrió un error del sistema, ya sea un nombre de archivo demasiado largo o un fallo inesperado de una llamada al sistema. errno puede ser útil.
LOCK_TIMEOUT
Fallaron retries intentos
LOCK_SUCCESS
El bloqueo tuvo éxito.

XauUnlockAuth deshace el trabajo de XauLockAuth eliminando los nombres de archivo ``-c'' y ``-l''.

XauDisposeAuth libera el almacenamiento asignado para mantener una entrada de autorización.
