XAllocSizeHints(3) FUNCIONES DE XLIB XAllocSizeHints(3)

NOMBRE

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - asignar estructura de sugerencias de tamaño y establecer o leer la propiedad WM_NORMAL_HINTS de una ventana

SINTAXIS

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
hints
Especifica las sugerencias de tamaño para la ventana en su estado normal.
hints
Especifica la estructura XSizeHints a utilizar.
hints_return
Devuelve las sugerencias de tamaño para la ventana en su estado normal.
property
Especifica el nombre de la propiedad.
supplied_return
Devuelve las sugerencias proporcionadas por el usuario.
w
Especifica la ventana.

DESCRIPCIÓN

La función XAllocSizeHints asigna y devuelve un puntero a una estructura XSizeHints. Tenga en cuenta que todos los campos de la estructura XSizeHints se inicializan a cero. Si no hay memoria suficiente disponible, XAllocSizeHints devuelve NULL. Para liberar la memoria asignada a esta estructura, utilice XFree.

La función XSetWMNormalHints reemplaza las sugerencias de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. Si la propiedad no existe, XSetWMNormalHints establece las sugerencias de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. La propiedad se almacena con un tipo de WM_SIZE_HINTS y un formato de 32.

XSetWMNormalHints puede generar errores BadAlloc y BadWindow.

La función XGetWMNormalHints devuelve las sugerencias de tamaño almacenadas en la propiedad WM_NORMAL_HINTS de la ventana especificada. Si la propiedad es de tipo WM_SIZE_HINTS, de formato 32, y es lo suficientemente larga como para contener una estructura de sugerencias de tamaño antigua (pre-ICCCM) o nueva, XGetWMNormalHints establece los diversos campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos), y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero.

Si XGetWMNormalHints devuelve con éxito y se lee una propiedad de sugerencias de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente larga como para contener también el tamaño base y los campos de gravedad de la ventana, el argumento supplied_return también contendrá los siguientes bits:

PBaseSize|PWinGravity

XGetWMNormalHints puede generar un error PN BadWindow.

La función XSetWMSizeHints reemplaza las sugerencias de tamaño para la propiedad especificada en la ventana nombrada. Si la propiedad especificada no existe, XSetWMSizeHints establece las sugerencias de tamaño para la propiedad especificada en la ventana nombrada. La propiedad se almacena con un tipo de WM_SIZE_HINTS y un formato de 32. Para establecer las sugerencias de tamaño normales de una ventana, puede utilizar la función XSetWMNormalHints.

XSetWMSizeHints puede generar errores BadAlloc, BadAtom y BadWindow.

La función XGetWMSizeHints devuelve las sugerencias de tamaño almacenadas en la propiedad especificada en la ventana nombrada. Si la propiedad es de tipo WM_SIZE_HINTS, de formato 32, y es lo suficientemente larga como para contener una estructura de sugerencias de tamaño antigua (pre-ICCCM) o nueva, XGetWMSizeHints establece los diversos campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos), y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero. Para obtener las sugerencias de tamaño normales de una ventana, puede utilizar la función XGetWMNormalHints.

Si XGetWMSizeHints devuelve con éxito y se lee una propiedad de sugerencias de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente larga como para contener también el tamaño base y los campos de gravedad de la ventana, el argumento supplied_return también contendrá los siguientes bits:

PBaseSize|PWinGravity

XGetWMSizeHints puede generar errores BadAtom y BadWindow.

PROPIEDADES

WM_NORMAL_HINTS
Sugerencias de tamaño para una ventana en su estado normal. El tipo C de esta propiedad es XSizeHints.

ESTRUCTURAS

La estructura XSizeHints contiene:

/* Bits de máscara de sugerencias de tamaño */

#define USPosition (1L << 0) /* usuario especificó x, y */
#define USSize (1L << 1) /* usuario especificó ancho, alto */
#define PPosition (1L << 2) /* programa especificó posición */
#define PSize (1L << 3) /* programa especificó tamaño */
#define PMinSize (1L << 4) /* programa especificó tamaño mínimo */
#define PMaxSize (1L << 5) /* programa especificó tamaño máximo */
#define PResizeInc (1L << 6) /* programa especificó incrementos de redimensionamiento */
#define PAspect (1L << 7) /* programa especificó relaciones de aspecto mínimas y máximas */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        int x, y;       /* Obsoleto */
        int width, height;      /* Obsoleto */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* numerador */
               int y;   /* denominador */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* esta estructura puede ser extendida en el futuro */
} XSizeHints;

Los miembros x, y, width y height ahora son obsoletos y se dejan únicamente por razones de compatibilidad. Los miembros min_width y min_height especifican el tamaño mínimo de ventana que aún permite que la aplicación sea útil. Los miembros max_width y max_height especifican el tamaño máximo de ventana. Los miembros width_inc y height_inc definen una progresión aritmética de tamaños (mínimo a máximo) en la que la ventana prefiere redimensionarse. Los miembros min_aspect y max_aspect se expresan como relaciones de x e y, y permiten a una aplicación especificar el rango de relaciones de aspecto que prefiere. Los miembros base_width y base_height definen el tamaño deseado de la ventana. El administrador de ventanas interpretaría la posición de la ventana y el ancho de su borde para colocar el punto del rectángulo exterior de la ventana general especificada por el miembro win_gravity. El rectángulo exterior de la ventana incluye cualquier borde o decoración proporcionada por el administrador de ventanas. XAllocSizeHints(3)

NAME

XAllocSizeHints, XFreeSizeHints - obtain and free XSizeHints structure

SYNTAX

#include <Xlib.h>
XSizeHints *XAllocSizeHints(void);
void XFreeSizeHints(XSizeHints *hints);

ARGUMENTS

--
hints Specifies the XSizeHints structure to be freed.

DESCRIPTION

The XAllocSizeHints function allocates and returns a pointer to an XSizeHints structure. This structure is used to specify size and positioning information for a window. The fields of the structure are initialized to zero. The caller is responsible for freeing this structure when it is no longer needed using XFree().

The XFreeSizeHints function frees the specified hints structure.

It is generally recommended to use XSetNormalHints(3) instead of allocating and manipulating XSizeHints structures directly. However, this function is provided for compatibility with older clients or for specific use cases.

PROPERTIES

The XSizeHints structure contains the following members:

long flags
Indicates which of the other XSizeHints fields are set.
int x, y
The desired x and y coordinates of the upper-left corner of the window.
int width, height
The desired width and height of the window in pixels.
int min_width, min_height
The minimum width and height the window can have.
int max_width, max_height
The maximum width and height the window can have.
int width_inc, height_inc
The increments for width and height. The window width must be min_width + i*width_inc for some non-negative integer i, and similarly for height.
struct {
int num;
int den;
} min_aspect, max_aspect;
The minimum and maximum aspect ratio for the window. The aspect ratio is defined as width/height. These fields are specified as numerator and denominator.

The flags field can be set to a bitwise OR of the following constants:

PPosition
The x and y fields are specified.
PSize
The width and height fields are specified.
PMinSize
The min_width and min_height fields are specified.
PMaxSize
The max_width and max_height fields are specified.
PResizeInc
The width_inc and height_inc fields are specified.
PAspect
The min_aspect and max_aspect fields are specified.

STRUCTURES

The XSizeHints structure is defined as follows:

typedef struct {
  long    flags;
  int     x, y;
  int     width, height;
  int     min_width, min_height;
  int     max_width, max_height;
  int     width_inc, height_inc;
  struct {
    int num;
    int den;
  } min_aspect, max_aspect;
} XSizeHints;

Note that use of the PAllHints macro is highly discouraged.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadWindow
A value for a Window argument does not name a defined Window.
