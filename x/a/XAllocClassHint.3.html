XAllocClassHint(3)

Paquete: libx11

Licencias: MIT AND X11

XAllocClassHint(3) FUNCIONES DE XLIB XAllocClassHint(3)

NOMBRE

XAllocClassHint, XSetClassHint, XGetClassHint, XClassHint - asigna una estructura de sugerencias de clase y establece o lee la propiedad WM_CLASS de una ventana

SINTAXIS

XClassHint *XAllocClassHint(void);

XSetClassHint(Display *display, Window w, XClassHint *class_hints);

Status XGetClassHint(Display *display, Window w, XClassHint *class_hints_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
class_hints
Especifica la estructura XClassHint que se va a utilizar.
class_hints_return
Devuelve la estructura XClassHint.
w
Especifica la ventana.

DESCRIPCIÓN

La función XAllocClassHint asigna y devuelve un puntero a una estructura XClassHint. Tenga en cuenta que los campos de puntero en la estructura XClassHint se inicializan a NULL. Si no hay suficiente memoria disponible, XAllocClassHint devuelve NULL. Para liberar la memoria asignada a esta estructura, utilice XFree.

La función XSetClassHint establece la sugerencia de clase para la ventana especificada. Si las cadenas no están en la Codificación de Caracteres Portátil de Host, el resultado depende de la implementación.

XSetClassHint puede generar errores BadAlloc y BadWindow.

La función XGetClassHint devuelve la sugerencia de clase de la ventana especificada a los miembros de la estructura proporcionada. Si los datos devueltos por el servidor están en la Codificación de Caracteres Portátil Latina, entonces las cadenas devueltas están en la Codificación de Caracteres Portátil de Host. De lo contrario, el resultado depende de la implementación. Devuelve un estado distinto de cero en caso de éxito; de lo contrario, devuelve un estado cero. Para liberar res_name y res_class cuando haya terminado con las cadenas, utilice XFree en cada una individualmente.

XGetClassHint puede generar un error BadWindow.

PROPIEDADES

WM_CLASS
Establecida por los programas de aplicación para permitir que los gestores de ventanas y de sesiones obtengan los recursos de la aplicación de la base de datos de recursos.

ESTRUCTURAS

La estructura XClassHint contiene:

typedef struct {
        char *res_name;
        char *res_class;
} XClassHint;
El miembro res_name contiene el nombre de la aplicación,
y el miembro res_class contiene la clase de la aplicación.
Tenga en cuenta que el nombre establecido en esta propiedad puede diferir del nombre
establecido como WM_NAME.
Es decir, WM_NAME especifica lo que se debe mostrar en la barra de título y,
por lo tanto, puede contener información temporal (por ejemplo, el nombre de
un archivo actualmente en el búfer de un editor).
Por otro lado,
el nombre especificado como parte de WM_CLASS es el nombre formal de la aplicación
que debe utilizarse al recuperar los recursos de la aplicación de la
base de datos de recursos.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
