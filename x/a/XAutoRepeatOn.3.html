XChangeKeyboardControl(3) FUNCIONES DE XLIB XChangeKeyboardControl(3)

NOMBRE

XChangeKeyboardControl, XGetKeyboardControl, XAutoRepeatOn, XAutoRepeatOff, XBell, XQueryKeymap, XKeyboardControl - manipular la configuración del teclado y la estructura de control del teclado

SINTAXIS

int XChangeKeyboardControl(Display *display, unsigned long value_mask, XKeyboardControl *values);

int XGetKeyboardControl(Display *display, XKeyboardState *values_return);

int XAutoRepeatOn(Display *display);

int XAutoRepeatOff(Display *display);

int XBell(Display *display, int percent);

int XQueryKeymap(Display *display, char keys_return[32]);

ARGUMENTOS

display
Especifica la conexión al servidor X.
keys_return
Devuelve un array de bytes que identifica qué teclas están pulsadas. Cada bit representa una tecla del teclado.
percent
Especifica el volumen para la campana, que puede variar entre -100 y 100 inclusive.
value_mask
Especifica qué controles cambiar. Esta máscara es la OR inclusiva a nivel de bits de los bits de máscara de control válidos.
values
Especifica un valor por cada bit establecido a 1 en la máscara.
values_return
Devuelve los controles actuales del teclado en la estructura XKeyboardState especificada.

DESCRIPCIÓN

La función XChangeKeyboardControl controla las características del teclado definidas por la estructura XKeyboardControl. El argumento value_mask especifica qué valores se van a cambiar.

XChangeKeyboardControl puede generar errores BadMatch y BadValue.

La función XGetKeyboardControl devuelve los valores de control actuales del teclado a la estructura XKeyboardState.

La función XAutoRepeatOn activa la repetición automática del teclado en la pantalla especificada.

La función XAutoRepeatOff desactiva la repetición automática del teclado en la pantalla especificada.

La función XBell hace sonar la campana del teclado en la pantalla especificada, si es posible. El volumen especificado es relativo al volumen base del teclado. Si el valor del argumento percent no está en el rango de -100 a 100 inclusive, se produce un error BadValue. El volumen al que suena la campana cuando el argumento percent es no negativo es:

base - [(base * percent) / 100] + percent

El volumen al que suena la campana cuando el argumento percent es negativo es:

base + [(base * percent) / 100]

Para cambiar el volumen base de la campana, utilice XChangeKeyboardControl.

XBell puede generar un error BadValue.

La función XQueryKeymap devuelve un vector de bits para el estado lógico del teclado, donde cada bit establecido a 1 indica que la tecla correspondiente está pulsada actualmente. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits de las teclas 8N a 8N + 7, con el bit menos significativo del byte representando la tecla 8N.

Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente) puede retrasarse respecto al estado físico si el procesamiento de eventos del dispositivo está congelado.

ESTRUCTURAS

La estructura XKeyboardControl contiene:

/* Bits de máscara para ChangeKeyboardControl */

#define KBKeyClickPercent (1L<<0)
#define KBBellPercent (1L<<1)
#define KBBellPitch (1L<<2)
#define KBBellDuration (1L<<3)
#define KBLed (1L<<4)
#define KBLedMode (1L<<5)
#define KBKey (1L<<6)
#define KBAutoRepeatMode (1L<<7) 
/* Valores */
typedef struct {
        int key_click_percent;
        int bell_percent;
        int bell_pitch;
        int bell_duration;
        int led;
        int led_mode;   /* LedModeOn, LedModeOff */
        int key;
        int auto_repeat_mode;   /* AutoRepeatModeOff, AutoRepeatModeOn,
                                AutoRepeatModeDefault */
} XKeyboardControl;

El miembro key_click_percent establece el volumen de los clics de tecla entre 0 (apagado) y 100 (alto) inclusive, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

El miembro bell_percent establece el volumen base para la campana entre 0 (apagado) y 100 (alto) inclusive, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_pitch establece el tono (especificado en Hz) de la campana, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue. El miembro bell_duration establece la duración de la campana especificada en milisegundos, si es posible. Un ajuste de -1 restaura el valor predeterminado. Otros valores negativos generan un error BadValue.

Si se especifican tanto los miembros led_mode como led, se cambia el estado de ese LED, si es posible. El miembro led_mode se puede establecer en LedModeOn o LedModeOff. Si solo se especifica led_mode, se cambia el estado de todos los LEDs, si es posible. Se soportan hasta 32 LEDs numerados a partir de uno. No se define ninguna interpretación estándar de los LEDs. Si se especifica led sin led_mode, se produce un error BadMatch.

Si se especifican tanto el modo de repetición como la tecla, se cambia el modo de repetición de esa tecla (según AutoRepeatModeOn, AutoRepeatModeOff o AutoRepeatModeDefault), si es posible. Si solo se especifica el modo de repetición, se cambia el modo global de repetición automática para todo el teclado, si es posible, y no afecta a la configuración por tecla. Si se especifica una tecla sin modo de repetición, se produce un error BadMatch. Cada tecla tiene un modo individual de si debe repetirse o no y una configuración predeterminada para el modo. Además, hay un modo global de si la repetición automática debe estar activada o no y una configuración predeterminada para ese modo. Cuando el modo global es AutoRepeatModeOn, las teclas deben obedecer sus modos individuales de repetición automática. Cuando el modo global es AutoRepeatModeOff, ninguna tecla debe repetirse. Una tecla de repetición automática genera eventos alternos de KeyPress y KeyRelease. Cuando una tecla se utiliza como modificador, es deseable que la tecla no se repita, independientemente de su configuración de repetición automática.

La estructura XKeyboardState contiene:

typedef struct {
        int key_click_percent;
        int bell_percent;
        unsigned int bell_pitch, bell_duration;
        unsigned long led_mask;
        int global_auto_repeat;
        char auto_repeats[32];
} XKeyboardState;

Para los LEDs, el bit menos significativo de led_mask corresponde al LED uno, y cada bit establecido a 1 en led_mask indica un LED que está encendido. El miembro global_auto_repeat se puede establecer en AutoRepeatModeOn o AutoRepeatModeOff. El miembro auto_repeats es un vector de bits. Cada bit establecido a 1 indica que la repetición automática está habilitada para la tecla correspondiente. El vector se representa como 32 bytes. El byte N (a partir de 0) contiene los bits de las teclas 8N a 8N + 7, con el bit menos significativo del byte representando la tecla 8N.

DIAGNÓSTICOS

BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos, pero falla al coincidir de alguna otra manera requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas
