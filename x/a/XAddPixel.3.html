XCreateImage(3) FUNCIONES DE XLIB XCreateImage(3)

NOMBRE

XInitImage, XCreateImage, XGetPixel, XPutPixel, XSubImage, XAddPixel, XDestroyImage - utilidades de imágenes

SINTAXIS

Status XInitImage(XImage *image);

XImage *XCreateImage(Display *display, Visual *visual, unsigned int depth, int format, int offset, char *data, unsigned int width, unsigned int height, int bitmap_pad, int bytes_per_line);

unsigned long XGetPixel(XImage *ximage, int x, int y);

int XPutPixel(XImage *ximage, int x, int y, unsigned long pixel);

XImage *XSubImage(XImage *ximage, int x, int y, unsigned int subimage_width, unsigned int subimage_height);

int XAddPixel(XImage *ximage, long value);

int XDestroyImage(XImage *ximage);

ARGUMENTOS

bitmap_pad
Especifica el cuanto de una línea de escaneo (8, 16 o 32). En otras palabras, el inicio de una línea de escaneo está separado en la memoria del cliente del inicio de la siguiente línea de escaneo por un múltiplo entero de esta cantidad de bits.
bytes_per_line
Especifica el número de bytes en la imagen del cliente entre el inicio de una línea de escaneo y el inicio de la siguiente.
data
Especifica los datos de la imagen.
depth
Especifica la profundidad de la imagen.
display
Especifica la conexión con el servidor X.
format
Especifica el formato para la imagen. Puedes pasar XYBitmap, XYPixmap, o ZPixmap.
height
Especifica la altura de la imagen, en píxeles.
offset
Especifica el número de píxeles a ignorar al principio de la línea de escaneo.
pixel
Especifica el nuevo valor de píxel.
subimage_height
Especifica la altura de la nueva subimagen, en píxeles.
subimage_width
Especifica el ancho de la nueva subimagen, en píxeles.
value
Especifica el valor constante que se va a sumar.
visual
Especifica la estructura Visual.
width
Especifica el ancho de la imagen, en píxeles.
ximage
Especifica la imagen.
x

y
Especifica las coordenadas x e y.

DESCRIPCIÓN

La función XInitImage inicializa las rutinas internas de manipulación de imágenes de una estructura de imagen, basándose en los valores de los diversos miembros de la estructura. Todos los campos, aparte de las rutinas de manipulación, deben estar ya inicializados. Si el miembro bytes_per_line es cero, XInitImage asumirá que los datos de la imagen son contiguos en memoria y establecerá el miembro bytes_per_line a un valor apropiado basado en los otros miembros; de lo contrario, el valor de bytes_per_line no se cambia. Todas las rutinas de manipulación se inicializan a funciones que otras funciones de manipulación de imágenes de Xlib necesitan para operar sobre el tipo de imagen especificado por el resto de la estructura.

Esta función debe llamarse para cualquier imagen construida por el cliente antes de pasarla a cualquier otra función de Xlib. Las estructuras de imagen creadas o devueltas por Xlib no necesitan ser inicializadas de esta manera.

Esta función devuelve un estado distinto de cero si la inicialización de la estructura es exitosa. Devuelve cero si detectó algún error o inconsistencia en la estructura, en cuyo caso la imagen no se modifica.

La función XCreateImage asigna la memoria necesaria para una estructura XImage para la pantalla especificada, pero no asigna espacio para la imagen en sí. En su lugar, inicializa el orden de bytes, el orden de bits y los valores de unidad de mapa de bits de la estructura a partir de la pantalla y devuelve un puntero a la estructura XImage. Las máscaras de rojo, verde y azul se definen solo para imágenes de formato Z y se derivan de la estructura Visual pasada. Otros valores también se pasan. El offset permite la visualización rápida de la imagen sin requerir que cada línea de escaneo se posicione correctamente. Si se pasa un valor cero en bytes_per_line, Xlib asume que las líneas de escaneo son contiguas en memoria y calcula el valor de bytes_per_line por sí mismo.

Tenga en cuenta que cuando la imagen se crea utilizando XCreateImage, XGetImage o XSubImage, el procedimiento de destrucción que llama la función XDestroyImage libera tanto la estructura de la imagen como los datos a los que apunta la estructura de la imagen.

Las funciones básicas utilizadas para obtener un píxel, establecer un píxel, crear una subimagen y agregar un valor constante a una imagen se definen en el objeto de imagen. Las funciones de esta sección son en realidad invocaciones de macros de las funciones del objeto de imagen y están definidas en X11/Xutil.h.

La función XGetPixel devuelve el píxel especificado de la imagen nombrada. El valor del píxel se devuelve en formato normalizado (es decir, el byte menos significativo del long es el byte menos significativo del píxel). La imagen debe contener las coordenadas x e y.

La función XPutPixel sobrescribe el píxel en la imagen nombrada con el valor de píxel especificado. El valor del píxel de entrada debe estar en formato normalizado (es decir, el byte menos significativo del long es el byte menos significativo del píxel). La imagen debe contener las coordenadas x e y.

La función XSubImage crea una nueva imagen que es una subsección de una existente. Asigna la memoria necesaria para la nueva estructura XImage y devuelve un puntero a la nueva imagen. Los datos se copian de la imagen de origen, y la imagen debe contener el rectángulo definido por x, y, subimage_width y subimage_height.

La función XAddPixel agrega un valor constante a cada píxel de una imagen. Es útil cuando se tiene un valor de píxel base de la asignación de recursos de color y se necesita manipular la imagen a esa forma.

La función XDestroyImage desasigna la memoria asociada con la estructura XImage.
