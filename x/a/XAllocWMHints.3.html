XAllocWMHints(3)

Paquete: libx11

Licencias: MIT AND X11

XAllocWMHints(3) FUNCIONES DE XLIB XAllocWMHints(3)

NOMBRE

XAllocWMHints, XSetWMHints, XGetWMHints, XWMHints - asignar estructura de sugerencias del gestor de ventanas y establecer o leer la propiedad WM_HINTS de una ventana

SINTAXIS

XWMHints *XAllocWMHints(void);

int XSetWMHints(Display *display, Window w, XWMHints *wmhints);

XWMHints *XGetWMHints(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.
wmhints
Especifica la estructura XWMHints a utilizar.

DESCRIPCIÓN

La función XAllocWMHints asigna y devuelve un puntero a una estructura XWMHints. Ten en cuenta que todos los campos de la estructura XWMHints se inicializan a cero. Si no hay suficiente memoria disponible, XAllocWMHints devuelve NULL. Para liberar la memoria asignada a esta estructura, usa XFree.

La función XSetWMHints establece las sugerencias del gestor de ventanas, que incluyen información y ubicación del icono, el estado inicial de la ventana y si la aplicación depende del gestor de ventanas para recibir la entrada del teclado.

XSetWMHints puede generar errores BadAlloc y BadWindow.

La función XGetWMHints lee las sugerencias del gestor de ventanas y devuelve NULL si no se estableció ninguna propiedad WM_HINTS en la ventana o devuelve un puntero a una estructura XWMHints si tiene éxito. Cuando hayas terminado con los datos, libera el espacio utilizado llamando a XFree.

XGetWMHints puede generar un error BadWindow.

PROPIEDADES

WM_HINTS
Sugerencias adicionales establecidas por el cliente para uso del gestor de ventanas. El tipo C de esta propiedad es XWMHints.

ESTRUCTURAS

La estructura XWMHints contiene:

/* Bits de máscara de sugerencias del gestor de ventanas */

#define InputHint (1L << 0)
#define StateHint (1L << 1)
#define IconPixmapHint (1L << 2)
#define IconWindowHint (1L << 3)
#define IconPositionHint (1L << 4)
#define IconMaskHint (1L << 5)
#define WindowGroupHint (1L << 6)
#define XUrgencyHint (1L << 8)
#define AllHints (InputHint| StateHint| IconPixmapHint| IconWindowHint| IconPositionHint| IconMaskHint| WindowGroupHint) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        Bool input;     /* ¿depende esta aplicación del gestor de ventanas para
                        recibir la entrada del teclado? */
        int initial_state;      /* véase más abajo */
        Pixmap icon_pixmap;     /* pixmap a usar como icono */
        Window icon_window;     /* ventana a usar como icono */
        int icon_x, icon_y;     /* posición inicial del icono */
        Pixmap icon_mask;       /* pixmap a usar como máscara para icon_pixmap */
        XID window_group;       /* id del grupo de ventanas relacionado */
        /* esta estructura puede ser extendida en el futuro */
} XWMHints;

El miembro input se utiliza para comunicar al gestor de ventanas el modelo de enfoque de entrada utilizado por la aplicación. Las aplicaciones que esperan entrada pero nunca establecen explícitamente el enfoque en ninguna de sus subventanas (es decir, usan el modelo de gestión de enfoque de "push"), como las aplicaciones estilo X versión 10 que usan enfoque impulsado por el espacio real, deben establecer este miembro a True. De manera similar, las aplicaciones que establecen el enfoque de entrada en sus subventanas solo cuando un gestor de ventanas se lo da a su ventana de nivel superior también deben establecer este miembro a True. Las aplicaciones que gestionan su propio enfoque de entrada estableciendo explícitamente el enfoque en una de sus subventanas cada vez que desean entrada de teclado (es decir, usan el modelo de enfoque de "pull") deben establecer este miembro a False. Las aplicaciones que nunca esperan ninguna entrada de teclado también deben establecer este miembro a False.

Los gestores de ventanas de modelo "pull" deben hacer posible que las aplicaciones de modelo "push" obtengan entrada estableciendo el enfoque de entrada en las ventanas de nivel superior de las aplicaciones cuyo miembro input es True. Los gestores de ventanas de modelo "push" deben asegurarse de que las aplicaciones de modelo "pull" no los rompan restableciendo el enfoque de entrada a PointerRoot cuando sea apropiado (por ejemplo, siempre que una aplicación cuyo miembro input sea False establezca el enfoque de entrada en una de sus subventanas).

Las definiciones para el indicador initial_state son:

#define WithdrawnState 0
#define NormalState 1 /* la mayoría de las aplicaciones comienzan así */
#define IconicState 3 /* la aplicación quiere empezar como un icono */
El icon_mask especifica qué píxeles del icon_pixmap deben usarse como icono. Esto permite iconos no rectangulares. Tanto icon_pixmap como icon_mask deben ser mapas de bits. icon_window permite a una aplicación proporcionar una ventana para que sea utilizada como icono por los gestores de ventanas que soportan dicho uso. window_group te permite especificar que esta ventana pertenece a un grupo de otras ventanas. Por ejemplo, si una única aplicación manipula múltiples ventanas de nivel superior, esto te permite proporcionar suficiente información para que un gestor de ventanas pueda convertir en icono todas las ventanas en lugar de solo una.

El indicador UrgencyHint, si está establecido en el campo flags, indica que el cliente considera que el contenido de la ventana es urgente, requiriendo la respuesta oportuna del usuario. El gestor de ventanas hará un esfuerzo por llamar la atención del usuario hacia esta ventana mientras este indicador esté activo. El cliente debe proporcionar algún medio por el cual el usuario pueda hacer que se borre el indicador de urgencia (ya sea mitigando la condición que hizo que la ventana fuera urgente o simplemente apagando la alarma) o que la ventana sea retirada.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.

XAllocWMHints(3)

NAME

XAllocWMHints - asigna y obtiene sugerencias de ventana de administración de ventanas

SYNTAX

#include <Xlib.h>

XWMHints *XAllocWMHints(void);

Status XSetWMHints(Display *display, Window w, XWMHints *hints);

XWMHints *XGetWMHints(Display *display, Window w);

void XFreeWMHints(XWMHints *hints);

ARGUMENTS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.
hints
Especifica las sugerencias de ventana de administración de ventanas.

DESCRIPTION

La función XAllocWMHints asigna memoria para una estructura XWMHints y la devuelve. Si la asignación de memoria falla, devuelve NULL.

La función XSetWMHints establece las sugerencias de ventana de administración de ventanas para la ventana especificada. Las sugerencias se pasan en la estructura XWMHints. El campo flags de la estructura XWMHints especifica qué sugerencias están establecidas.

La función XGetWMHints obtiene las sugerencias de ventana de administración de ventanas para la ventana especificada. Las sugerencias se devuelven en una estructura XWMHints asignada por la función. El llamante es responsable de liberar la memoria asignada para la estructura XWMHints utilizando XFreeWMHints.

La función XFreeWMHints libera la memoria asignada para la estructura XWMHints.

PROPERTIES

Las sugerencias de ventana de administración de ventanas se almacenan en la propiedad _NET_WM_HINTS (_OB_WM_HINTS para la compatibilidad con versiones anteriores).

STRUCTURES

La estructura XWMHints se define de la siguiente manera:

typedef struct {
    long            flags;
    int             initial_state;
    Pixmap          icon;
    int             icon_x, icon_y;
    int             icon_width, icon_height;
    Pixmap          icon_mask;
    XID             wmgr_hints_color;
    Atom            input_group;
} XWMHints;
  • flags: Un campo de bits que indica qué campos de la estructura son válidos.
  • initial_state: Especifica el estado inicial de la ventana (e.g., NormalState, IconicState, ZoomState).
  • icon: Un Pixmap para el icono de la ventana.
  • icon_x, icon_y: Las coordenadas X e Y del icono en la pantalla.
  • icon_width, icon_height: El ancho y alto del icono en píxeles.
  • icon_mask: Una máscara para el icono.
  • wmgr_hints_color: Sugerencias de color para el administrador de ventanas (obsoleto).
  • input_group: Un identificador de grupo de entrada para la ventana.

DIAGNOSTICS

En caso de error, XSetWMHints devuelve 0. XAllocWMHints y XGetWMHints devuelven NULL en caso de error.
