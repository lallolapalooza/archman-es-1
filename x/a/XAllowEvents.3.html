XAllowEvents(3) FUNCIONES DE XLIB XAllowEvents(3)

NOMBRE

XAllowEvents - libera eventos en cola

SINTAXIS

int XAllowEvents(Display *display, int event_mode, Time time);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
event_mode
Especifica el modo de evento. Puedes pasar AsyncPointer, SyncPointer, AsyncKeyboard, SyncKeyboard, ReplayPointer, ReplayKeyboard, AsyncBoth o SyncBoth.
time
Especifica el tiempo. Puedes pasar una marca de tiempo o CurrentTime.

DESCRIPCIÓN

La función XAllowEvents libera algunos eventos en cola si el cliente ha causado que un dispositivo se congele. No tiene efecto si el tiempo especificado es anterior al último tiempo de captura de la captura activa más reciente para el cliente o si el tiempo especificado es posterior al tiempo actual del servidor X.

XAllowEvents puede generar un error BadValue.

DIAGNÓSTICOS

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
