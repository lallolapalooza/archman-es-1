XSetICValues(3)

Paquete: libx11

Licencias: MIT AND X11

XSetICValues(3) FUNCIONES XLIB XSetICValues(3)

NOMBRE

XSetICValues, XGetICValues - establecer y obtener valores de XIC

SINTAXIS

char * XSetICValues(XIC ic, ...);

char * XGetICValues(XIC ic, ...);

ARGUMENTOS

ic
Especifica el contexto de entrada.
...
Especifica la lista de argumentos de longitud variable para establecer o obtener valores de XIC.

DESCRIPCIÓN

La función XSetICValues devuelve NULL si no ocurrió ningún error; de lo contrario, devuelve el nombre del primer argumento que no se pudo establecer. Un argumento podría no establecerse por cualquiera de las siguientes razones:

  • El argumento es de solo lectura (por ejemplo, XNFilterEvents).
  • El nombre del argumento no se reconoce.
  • Ocurre un error dependiente de la implementación.

Cada valor a establecer debe ser un dato apropiado, que coincida con el tipo de dato impuesto por la semántica del argumento.

XSetICValues puede generar errores BadAtom, BadColor, BadCursor, BadPixmap y BadWindow.

La función XGetICValues devuelve NULL si no ocurrió ningún error; de lo contrario, devuelve el nombre del primer argumento que no se pudo obtener. Un argumento no se pudo obtener por cualquiera de las siguientes razones:

  • El nombre del argumento no se reconoce.
  • El método de entrada encontró un error dependiente de la implementación.

Cada argumento de valor de atributo de IC (siguiendo un nombre) debe apuntar a una ubicación donde se almacenará el valor del IC. Es decir, si el valor del IC es de tipo T, el argumento debe ser de tipo T*. Si T es en sí mismo un tipo puntero, entonces XGetICValues asigna memoria para almacenar los datos reales, y el cliente es responsable de liberar estos datos llamando a XFree con el puntero devuelto. La excepción a esta regla es para un valor de IC de tipo XNVaNestedList (para atributos preedit y status). En este caso, el argumento también debe ser de tipo XVaNestedList. Entonces, la regla de cambiar el tipo T a T* y liberar los datos asignados se aplica a cada elemento de la lista anidada.

DIAGNÓSTICOS

BadAtom
Un valor para un argumento Atom no nombra un Atom definido.
BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadCursor
Un valor para un argumento Cursor no nombra un Cursor definido.
BadPixmap
Un valor para un argumento Pixmap no nombra un Pixmap definido.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
