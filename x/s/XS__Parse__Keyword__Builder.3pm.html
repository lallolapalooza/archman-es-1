XS::Parse::Keyword::Builder(3pm) Documentación de Perl contribuida por el usuario XS::Parse::Keyword::Builder(3pm)

NOMBRE

"XS::Parse::Keyword::Builder" - soporte en tiempo de compilación para "XS::Parse::Keyword"

SINOPSIS

En Build.PL:

use XS::Parse::Keyword::Builder;
my $build = Module::Build->new(
   ...,
   configure_requires => {
      ...
      'XS::Parse::Keyword::Builder' => 0,
   }
);
XS::Parse::Keyword::Builder->extend_module_build( $build );
...

DESCRIPCIÓN

Este módulo proporciona una ayuda en tiempo de compilación para asistir a autores de módulos XS que utilizan XS::Parse::Keyword. Prepara una distribución basada en Module::Build para poder utilizar "XS::Parse::Keyword".

FUNCIONES

write_XSParseKeyword_h

XS::Parse::Keyword::Builder->write_XSParseKeyword_h;

Este método ya no hace nada desde la versión 0.43.

extra_compiler_flags

@flags = XS::Parse::Keyword::Builder->extra_compiler_flags;

Devuelve una lista de banderas adicionales que los scripts de compilación deberían añadir a la invocación del compilador. Esto permite que el compilador C encuentre el archivo XSParseKeyword.h.

extend_module_build

XS::Parse::Keyword::Builder->extend_module_build( $build );

Un método abreviado conveniente para realizar todas las tareas necesarias para que una distribución basada en Module::Build utilice la ayuda.
