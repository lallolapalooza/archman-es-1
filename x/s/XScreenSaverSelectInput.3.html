NOMBRE

XScreenSaver - biblioteca cliente de extensión del salvapantallas de X11

SINOPSIS

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* ventana del salvapantallas */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* milisegundos */
    unsigned long idle;           /* milisegundos */
    unsigned long eventMask;      /* eventos */
} XScreenSaverInfo;

typedef struct {
    int type;               /* de evento */
    unsigned long serial;   /* # de la última solicitud procesada por el servidor */
    Bool send_event;        /* verdadero si esto provino de una solicitud SendEvent */
    Display *display;       /* Display desde el cual se leyó el evento */
    Window window;          /* ventana del salvapantallas */
    Window root;            /* ventana raíz de la pantalla del evento */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* extensiones de la nueva región */
    Time time;              /* marca de tiempo del evento */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPCIÓN

El Sistema de Ventanas X proporciona soporte para cambiar la imagen en la pantalla después de un período de inactividad configurable por el usuario para evitar quemar los fósforos del tubo de rayos catódicos. Sin embargo, no se proporcionan interfaces para que el usuario controle la imagen que se dibuja. Esta extensión permite a un cliente de ``salvapantallas'' externo detectar cuándo se va a mostrar la imagen alternativa y proporcionar los gráficos.

Las implementaciones actuales del servidor X típicamente proporcionan al menos una forma de imagen de ``salvapantallas''. Históricamente, esto ha sido una copia del logo de X dibujado sobre el patrón de fondo de la raíz. Sin embargo, muchos usuarios han solicitado un mecanismo que les permita escribir programas de salvapantallas que proporcionen capacidades similares a las proporcionadas por otros sistemas de ventanas. En particular, dichos usuarios a menudo desean poder mostrar logotipos corporativos, instrucciones sobre cómo reactivar la pantalla y utilidades de bloqueo automático de pantalla. Esta extensión proporciona un medio para escribir dichos clientes.

Supuestos

Esta extensión exporta la noción de una ventana de salvapantallas especial que se mapea por encima de todas las demás ventanas en una pantalla. Esta ventana tiene el atributo override-redirect establecido para que no esté sujeta a manipulación por el gestor de ventanas. Además, el identificador X de la ventana nunca se devuelve mediante solicitudes QueryTree en la ventana raíz, por lo que típicamente no es visible para otros clientes.

XScreenSaverQueryExtension devuelve True si la extensión XScreenSaver está disponible en la pantalla dada. Un cliente debe llamar a XScreenSaverQueryExtension antes de llamar a cualquier otra función de XScreenSaver para negociar una versión de protocolo compatible; de lo contrario, el cliente obtendrá un comportamiento indefinido (XScreenSaver puede funcionar o no).

Si la extensión es compatible, el número de evento para los eventos ScreenSaverNotify se devuelve en el valor apuntado por event_base. Dado que esta extensión no define errores adicionales, los resultados de error_base no están definidos.

XScreenSaverQueryVersion devuelve True si la solicitud tuvo éxito; los valores de las versiones principales y secundarias del protocolo compatibles con el servidor se devuelven en major_version_return y minor_version_return.

XScreenSaverAllocInfo asigna y devuelve una estructura XScreenSaverInfo para su uso en llamadas a XScreenSaverQueryInfo. Todos los campos de la estructura se inicializan a cero. Si no hay suficiente memoria disponible, se devuelve NULL. Los resultados de esta rutina se pueden liberar usando XFree.

XScreenSaverQueryInfo devuelve información sobre el estado actual del servidor de pantalla en saver_info y se devuelve un valor distinto de cero. Si la extensión no es compatible, saver_info no se modifica y se devuelve 0.

El campo state especifica si el salvapantallas está actualmente activo y cómo se debe interpretar el valor til-or-since:

Off
La pantalla no se está guardando actualmente; til-or-since especifica el número de milisegundos hasta que se espera que el salvapantallas se active.
On
La pantalla se está guardando actualmente; til-or-since especifica el número de milisegundos desde que se activó el salvapantallas.
Disabled
El salvapantallas está actualmente deshabilitado; til-or-since es cero.

El campo kind especifica el mecanismo que se está utilizando actualmente o que se habría utilizado si la pantalla se estuviera guardando:

Blanked
Se deshabilitó la señal de video del monitor de pantalla.
Internal
Se mostró una imagen de salvapantallas integrada, dependiente del servidor; o ningún cliente había establecido los atributos de la ventana del salvapantallas o otro cliente tenía el servidor capturado cuando se activó el salvapantallas.
External
La ventana del salvapantallas se mapeó con atributos establecidos por un cliente utilizando la solicitud ScreenSaverSetAttributes.

El campo idle especifica el número de milisegundos desde la última entrada recibida del usuario en cualquiera de los dispositivos de entrada.
El campo event-mask especifica cuáles, si los hay, eventos del salvapantallas ha solicitado este cliente usando ScreenSaverSelectInput.

XScreenSaverSelectInput solicita que se generen eventos relacionados con el salvapantallas para este cliente. Si no hay bits establecidos en event-mask, entonces no se generarán eventos. De lo contrario, se puede establecer cualquier combinación de los siguientes bits:

ScreenSaverNotify
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que el salvapantallas se activa o desactiva.
ScreenSaverCycle
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que pasa el intervalo de ciclo del salvapantallas.

XScreenSaverSetAttributes establece los atributos que se utilizarán la próxima vez que se active el salvapantallas externo. Si otro cliente tiene actualmente los atributos establecidos, se genera un error BadAccess y la solicitud se ignora.
De lo contrario, los atributos especificados se verifican como si se hubieran utilizado en una solicitud CreateWindow central cuyo padre es la raíz. El campo override-redirect se ignora ya que se establece implícitamente en True. Si los atributos de la ventana dan como resultado un error según las reglas para CreateWindow, la solicitud se ignora.
De lo contrario, los atributos se almacenan y entrarán en vigor en la próxima activación que ocurra cuando el servidor no esté capturado por otro cliente. Cualquier recurso especificado para los atributos background-pixmap o cursor puede ser liberado inmediatamente. T

XScreenSaverSelectInput(3)

NAME

XScreenSaverSelectInput, XScreenSaverSetAttributes, XScreenSaverUnsetAttributes, XScreenSaverRegister, XScreenSaverUnregister, XScreenSaverGetRegistered, XScreenSaverSuspend - client functions for the X Screen Saver Extension

SYNOPSIS

#include <X11/Xlib.h>
#include <X11/extensions/scrnsaver.h>

Bool XScreenSaverQueryExtension(Display *dpy, int *event_basep, int *error_basep);

Bool XScreenSaverAllocColor(Display *dpy, Colormap cmap, XColor *def_in, XColor *def_out);

int XScreenSaverQueryVersion(Display *dpy, int *major_versionp, int *minor_versionp);

Bool XScreenSaverQueryInfo(Display *dpy, Drawable d, XScreenSaverInfo *info);

void XScreenSaverSelectInput(Display *dpy, Drawable d, unsigned long mask);

void XScreenSaverSetAttributes(Display *dpy, Drawable d, int x_offset, int y_offset,
    double tilt_x, double tilt_y, double color_range,
    int ncolors, XColor *colors,
    Visual *visual, Colormap colormap, unsigned long event_mask);

void XScreenSaverUnsetAttributes(Display *dpy, Drawable d);

int XScreenSaverRegister(Display *dpy, Screen *screen, Window w, int type);

int XScreenSaverUnregister(Display *dpy, Screen *screen);

int XScreenSaverGetRegistered(Display *dpy, Screen *screen, Window *w, int *type);

Bool XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPTION

The X Screen Saver Extension provides a mechanism for applications to interact with the X server's screen saver functionality. This extension is distinct from the screensaver itself, and simply provides an interface for applications to control and query the screensaver's behavior.

XScreenSaverQueryExtension checks if the screen saver extension is available on the specified display. If it is available, it returns True and sets the integers pointed to by event_basep and error_basep to the extension's event and error base codes, respectively. Otherwise, it returns False.

XScreenSaverAllocColor is similar to XAllocColor(3), but uses the screen saver's colormap, if available. It returns False if the colormap cannot be allocated.

XScreenSaverQueryVersion queries the X Screen Saver Extension version supported by the server. If the extension is present, it returns True and sets the integers pointed to by major_versionp and minor_versionp to the major and minor version numbers, respectively. Otherwise, it returns False.

XScreenSaverQueryInfo queries the current screen saver settings for the specified Drawable (usually the root window). The information is returned in the XScreenSaverInfo structure pointed to by info.

typedef struct {
    int           event_gcd;    /* greatest common divisor of event intervals */
    int           event_count;  /* number of events since last reset */
    int           prefer_blanking;/* true if screen blanking is preferred */
    int           allow_exposures;/* true if screen exposures are allowed */
    int           min_delay;    /* minimum delay between screen saving */
    int           max_delay;    /* maximum delay between screen saving */
    int           nsaver_windows;/* number of saver windows */
    unsigned long root;         /* root window ID */
    int           period;       /* number of seconds between saver window exposures */
    int           gccolor;      /* true if colormaps are used */
    unsigned long til_x;        /* tilt_x, scaled by event_gcd */
    unsigned long til_y;        /* tilt_y, scaled by event_gcd */
    unsigned long col_range;    /* color range, scaled by event_gcd */
} XScreenSaverInfo;

event_gcd and event_count can be used to detect user activity. prefer_blanking and allow_exposures indicate the server's current screen saver preferences. min_delay and max_delay specify the range of allowable delay times between screen saving. nsaver_windows indicates the number of screen saver windows currently mapped. root is the ID of the root window for which the information is being queried. period is the number of seconds between screen saver window exposures. gccolor indicates whether the screen saver uses colormaps. til_x, til_y, and col_range provide information about motion and color for screen savers that use these features.

XScreenSaverSelectInput selects which screen saver events the specified Drawable should receive. The event-mask argument is a bitmask that specifies the events to be selected. Valid event mask bits are ScreenSaverNotifyMask.

XScreenSaverSetAttributes sets the attributes for the screen saver window associated with the specified Drawable. The x_offset and y_offset arguments specify the offset of the screen saver window within the root window. The tilt_x and tilt_y arguments specify the tilt of the screen saver. The color_range argument specifies the color range. The ncolors and colors arguments specify an array of colors to be used by the screen saver. The visual and colormap arguments specify the visual and colormap to be used for the screen saver window. The event_mask argument specifies the events that the screen saver window should receive.

Note that the server is free to copy the background-pixmap or cursor resources or to use them in place; therefore, the effect of changing the contents of those resources is undefined. If the specified colormap no longer exists when the screen saver activates, the parent's colormap is used instead. If no errors are generated by this request, any previous screen saver window attributes set by this client are released.

When the screen saver next activates and the server is not grabbed by another client, the screen saver window is created, if necessary, and set to the specified attributes and events are generated as usual. The colormap associated with the screen saver window is installed. Finally, the screen saver window is mapped.

The window remains mapped and at the top of the stacking order until the screen saver is deactivated in response to activity on any of the user input devices, a ForceScreenSaver request with a value of Reset, or any request that would cause the window to be unmapped.

If the screen saver activates while the server is grabbed by another client, the internal saver mechanism is used. The ForceScreenSaver request may be used with a value of Active to deactivate the internal saver and activate the external saver.

If the screen saver client's connection to the server is broken while the screen saver is activated and the client's close down mode has not been RetainPermanent or RetainTemporary, the current screen saver is deactivated and the internal screen saver is immediately activated.

When the screen saver deactivates, the screen saver window's colormap is uninstalled and the window is unmapped (except as described below). The screen saver XID is disassociated with the window and the server may, but is not required to, destroy the window along with any children.

When the screen saver is being deactivated and then immediately reactivated (such as when switching screen savers), the server may leave the screen saver window mapped (typically to avoid generating exposures).

XScreenSaverUnsetAttributes instructs the server to discard any previous screen saver window attributes set by this client.

XScreenSaverRegister stores the given XID in the _SCREEN_SAVER_ID property (of the given type) on the root window of the specified screen. It returns zero if an error is encountered and the property is not changed, otherwise it returns non-zero.

XScreenSaverUnregister removes any _SCREEN_SAVER_ID from the root window of the specified screen. It returns zero if an error is encountered and the property is changed, otherwise it returns non-zero.

XScreenSaverGetRegistered returns the XID and type stored in the _SCREEN_SAVER_ID property on the root window of the specified screen. It returns zero if an error is encountered or if the property does not exist or is not of the correct format; otherwise it returns non-zero.

XScreenSaverSuspend temporarily suspends the screensaver and DPMS timer if suspend is 'True', and restarts the timer if suspend is 'False'.
This function should be used by applications that don't want the screensaver or DPMS to become activated while they're for example in the process of playing a media sequence, or are otherwise continuously presenting visual information to the user while in a non-interactive state. This function is not intended to be called by an external screensaver application.
If XScreenSaverSuspend is called multiple times with suspend set to 'True', it must be called an equal number of times with suspend set to 'False' in order for the screensaver timer to be restarted. This request has no affect if a client tries to resume the screensaver without first having suspended it. XScreenSaverSuspend can thus not be used by one client to resume the screensaver if it's been suspended by another client.
If a client that has suspended the screensaver becomes disconnected from the X server, the screensaver timer will automatically be restarted, unless it's still suspended by another client. Suspending the screensaver timer doesn't prevent the screensaver from being forcibly activated with the ForceScreenSaver request, or a DPMS mode from being set with the DPMSForceLevel request.
XScreenSaverSuspend also doesn't deactivate the screensaver or DPMS if either is active at the time the request to suspend them is received by the X server. But once they've been deactivated, they won't automatically be activated again, until the client has canceled the suspension.

ERRORS

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes, and XScreenSaverUnsetAttributes will generate a BadDrawable error if drawable is not a valid drawable identifier. If any undefined bits are set in event-mask, a BadValue error is generated by XScreenSaverSelectInput.

AVAILABILITY

XScreenSaverSuspend is available in version 1.1 and later versions of the X Screen Saver Extension. Version 1.1 was first released with X11R7.1.
