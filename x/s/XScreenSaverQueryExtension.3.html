XScreenSaver(3) X Version 11 XScreenSaver(3)

NOMBRE

XScreenSaver - Biblioteca cliente de extensión de salvapantallas de X11

SINOPSIS

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* ventana del salvapantallas */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* milisegundos */
    unsigned long idle;           /* milisegundos */
    unsigned long eventMask;      /* eventos */
} XScreenSaverInfo;

typedef struct {
    int type;               /* de evento */
    unsigned long serial;   /* # de la última petición procesada por el servidor */
    Bool send_event;        /* true si esto vino de una petición SendEvent */
    Display *display;       /* Display desde el que se leyó el evento */
    Window window;          /* ventana del salvapantallas */
    Window root;            /* ventana raíz del área del evento */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* extensiones de la nueva región */
    Time time;              /* marca de tiempo del evento */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPCIÓN

El Sistema de Ventanas X proporciona soporte para cambiar la imagen en la pantalla después de un período de inactividad configurable por el usuario, para evitar quemar los fósforos del tubo de rayos catódicos. Sin embargo, no se proporcionan interfaces para que el usuario controle la imagen que se dibuja. Esta extensión permite a un cliente externo de "salvapantallas" detectar cuándo se va a mostrar la imagen alternativa y proporcionar los gráficos.

Las implementaciones actuales del servidor X suelen proporcionar al menos una forma de imagen de "salvapantallas". Históricamente, ha sido una copia del logo de X dibujada contra el patrón de fondo de la raíz. Sin embargo, muchos usuarios han solicitado un mecanismo que les permita escribir programas de salvapantallas que proporcionen capacidades similares a las ofrecidas por otros sistemas de ventanas. En particular, dichos usuarios suelen desear poder mostrar logotipos corporativos, instrucciones sobre cómo reactivar la pantalla y utilidades automáticas de bloqueo de pantalla. Esta extensión proporciona un medio para escribir dichos clientes.

Supuestos

Esta extensión exporta la noción de una ventana especial de salvapantallas que se mapea sobre todas las demás ventanas en una pantalla. Esta ventana tiene el atributo override-redirect establecido para que no esté sujeta a manipulación por el gestor de ventanas. Además, el identificador X de la ventana nunca es devuelto por las peticiones QueryTree sobre la ventana raíz, por lo que típicamente no es visible para otros clientes.

XScreenSaverQueryExtension devuelve True si la extensión XScreenSaver está disponible en la pantalla dada. Un cliente debe llamar a XScreenSaverQueryExtension antes de llamar a cualquier otra función de XScreenSaver para negociar una versión de protocolo compatible; de lo contrario, el cliente obtendrá un comportamiento indefinido (XScreenSaver puede funcionar o no).

Si la extensión es compatible, se devuelve el número de evento para los eventos ScreenSaverNotify en el valor apuntado por event_base. Dado que esta extensión no define errores adicionales, los resultados de error_base no están definidos.

XScreenSaverQueryVersion devuelve True si la petición tuvo éxito; los valores de las versiones principales y secundarias del protocolo soportadas por el servidor se devuelven en major_version_return y minor_version_return.

XScreenSaverAllocInfo asigna y devuelve una estructura XScreenSaverInfo para su uso en llamadas a XScreenSaverQueryInfo. Todos los campos de la estructura se inicializan a cero. Si no hay suficiente memoria disponible, se devuelve NULL. Los resultados de esta rutina se pueden liberar usando XFree.

XScreenSaverQueryInfo devuelve información sobre el estado actual del servidor de pantalla en saver_info y se devuelve un valor distinto de cero. Si la extensión no es compatible, saver_info no se modifica y se devuelve 0.

El campo state especifica si el salvapantallas está actualmente activo y cómo debe interpretarse el valor til-or-since:

Off
La pantalla no se está guardando actualmente; til-or-since especifica el número de milisegundos hasta que se espera que el salvapantallas se active.
On
La pantalla se está guardando actualmente; til-or-since especifica el número de milisegundos desde que se activó el salvapantallas.
Disabled
El salvapantallas está actualmente deshabilitado; til-or-since es cero.

El campo kind especifica el mecanismo que se está utilizando actualmente o que se habría utilizado de haberse estado guardando la pantalla:

Blanked
Se desactivó la señal de video del monitor de pantalla.
Internal
Se mostró una imagen de salvapantallas incorporada, dependiente del servidor; o ningún cliente había configurado los atributos de la ventana del salvapantallas, o un cliente diferente tenía el servidor capturado cuando se activó el salvapantallas.
External
La ventana del salvapantallas se mapeó con atributos establecidos por un cliente usando la petición ScreenSaverSetAttributes.

El campo idle especifica el número de milisegundos desde la última entrada recibida del usuario en cualquiera de los dispositivos de entrada.
El campo event-mask especifica cuáles, si alguno, de los eventos del salvapantallas ha solicitado este cliente usando ScreenSaverSelectInput.

XScreenSaverSelectInput solicita que se generen eventos relacionados con el salvapantallas para este cliente. Si no hay bits establecidos en event-mask, entonces no se generarán eventos. De lo contrario, se puede establecer cualquier combinación de los siguientes bits:

ScreenSaverNotify
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que el salvapantallas se activa o desactiva.
ScreenSaverCycle
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que pasa el intervalo de ciclo del salvapantallas.

XScreenSaverSetAttributes establece los atributos que se utilizarán la próxima vez que se active el salvapantallas externo. Si otro cliente tiene actualmente los atributos establecidos, se genera un error BadAccess y la petición se ignora.
De lo contrario, los atributos de ventana especificados se comprueban como si se hubieran utilizado en una petición core CreateWindow cuyo padre es la raíz. El campo override-redirect se ignora ya que se establece implícitamente en True. Si los atributos de la ventana dan como resultado un error según las reglas para CreateWindow, la petición se ignora.
De lo contrario, los atributos se almacenan y entrarán en vigor en la próxima activación que ocurra cuando el servidor no esté capturado por otro cliente. Cualquier recurso especificado para los atributos background-pixmap o cursor puede liberarse inmediatamente.

SINOPSIS

#include <X11/extensions/scrnsaver.h>

Bool XScreenSaverQueryExtension(Display *dpy, int *event_basep, int *error_basep);
int XScreenSaverQueryVersion(Display *dpy, int *client_major_versionp, int *client_minor_versionp);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Bool XScreenSaverSetAttributes(Display *dpy, Drawable drawable, unsigned long valuemask, XScreenSaverSetWindowAttributes *attributes);
Bool XScreenSaverGetAttributes(Display *dpy, Drawable drawable, XScreenSaverInfo *info);
Bool XScreenSaverSelectInput(Display *dpy, Drawable drawable, unsigned long mask);
Bool XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
Bool XScreenSaverRegister(Display *dpy, Screen *screen, XID xid, int type);
Bool XScreenSaverUnregister(Display *dpy, Screen *screen);
Bool XScreenSaverGetRegistered(Display *dpy, Screen *screen, XID *xid_return, int *type_return);
Bool XScreenSaverSuspend(Display *dpy, Bool suspend);
int XScreenSaverForce(Display *dpy, int mode);

DESCRIPCIÓN

La extensión X Screen Saver proporciona un mecanismo para que las aplicaciones de salvapantallas interactúen con el servidor X. Permite que las aplicaciones consulten el estado del salvapantallas, establezcan atributos y generen eventos.

XScreenSaverQueryExtension consulta si la extensión Screen Saver está disponible en el servidor X. Si está disponible, devuelve True y rellena los argumentos event_basep y error_basep con los números base de eventos y errores para la extensión, respectivamente. De lo contrario, devuelve False.

XScreenSaverQueryVersion consulta la versión de la extensión Screen Saver que soporta el servidor. Devuelve el número de versión principal mayor del servidor y rellena los argumentos client_major_versionp y client_minor_versionp con las versiones principales y secundarias solicitadas por el cliente, respectivamente. Debe ser la primera llamada de extensión que realice un cliente.

XScreenSaverAllocInfo asigna y devuelve un puntero a una estructura XScreenSaverInfo. Esta estructura se utiliza para almacenar información sobre el estado del salvapantallas y se utiliza con otras funciones de la extensión.

XScreenSaverSetAttributes establece los atributos de la ventana del salvapantallas. El argumento drawable especifica la ventana que se utilizará como ventana del salvapantallas. El argumento valuemask especifica qué atributos se están estableciendo, y puede ser una combinación de CWBackPixmap, CWBackPixel, CWBorderPixel, CWColormap, CWEventMask, CWSaveUnder, CWCursor. El argumento attributes es un puntero a una estructura XScreenSaverSetWindowAttributes que contiene los nuevos valores de los atributos. Si se genera un error, esta función devuelve False, de lo contrario devuelve True.

XScreenSaverGetAttributes rellena la estructura XScreenSaverInfo especificada con la información actual del salvapantallas para el drawable dado. Devuelve False si se produce un error, de lo contrario devuelve True.

XScreenSaverSelectInput especifica qué eventos de salvapantallas debe recibir el cliente. El argumento mask es una combinación de los siguientes valores: ScreenSaverNotifyMask. Devuelve False si se produce un error, de lo contrario devuelve True.

XScreenSaverUnsetAttributes instruye al servidor para que descarte cualquier atributo de ventana de salvapantallas previamente establecido por este cliente.

XScreenSaverRegister almacena el XID dado en la propiedad _SCREEN_SAVER_ID (del type dado) en la ventana raíz de la screen especificada. Devuelve cero si se encuentra un error y la propiedad no se cambia, de lo contrario devuelve un valor distinto de cero.

XScreenSaverUnregister elimina cualquier _SCREEN_SAVER_ID de la ventana raíz de la screen especificada. Devuelve cero si se encuentra un error y la propiedad se cambia, de lo contrario devuelve un valor distinto de cero.

XScreenSaverGetRegistered devuelve el XID y el type almacenados en la propiedad _SCREEN_SAVER_ID en la ventana raíz de la screen especificada. Devuelve cero si se encuentra un error o si la propiedad no existe o no tiene el formato correcto; de lo contrario, devuelve un valor distinto de cero.

XScreenSaverSuspend suspende temporalmente el temporizador del salvapantallas y DPMS si suspend es 'True', y reinicia el temporizador si suspend es 'False'.
Esta función debe ser utilizada por aplicaciones que no quieren que el salvapantallas o DPMS se activen mientras, por ejemplo, están reproduciendo una secuencia multimedia, o están presentando continuamente información visual al usuario mientras están en un estado no interactivo. Esta función no está pensada para ser llamada por una aplicación de salvapantallas externa.
Si XScreenSaverSuspend se llama varias veces con suspend establecido en 'True', debe llamarse un número igual de veces con suspend establecido en 'False' para que el temporizador del salvapantallas se reinicie. Esta solicitud no tiene ningún efecto si un cliente intenta reanudar el salvapantallas sin haberlo suspendido primero. Por lo tanto, XScreenSaverSuspend no puede ser utilizado por un cliente para reanudar el salvapantallas si ha sido suspendido por otro cliente.
Si un cliente que ha suspendido el salvapantallas se desconecta del servidor X, el temporizador del salvapantallas se reiniciará automáticamente, a menos que todavía esté suspendido por otro cliente. Suspender el temporizador del salvapantallas no evita que el salvapantallas se active forzosamente con la solicitud ForceScreenSaver, o que se establezca un modo DPMS con la solicitud DPMSForceLevel.
XScreenSaverSuspend tampoco desactiva el salvapantallas o DPMS si alguno de ellos está activo en el momento en que el servidor X recibe la solicitud para suspenderlos. Pero una vez que se han desactivado, no se activarán automáticamente de nuevo, hasta que el cliente haya cancelado la suspensión.

Cuando el salvapantallas se activa, si el servidor no está siendo capturado por otro cliente, la ventana del salvapantallas se crea, si es necesario, y se le aplican los atributos y eventos especificados. Se instala el mapa de colores asociado a la ventana del salvapantallas. Finalmente, la ventana del salvapantallas se mapea.

La ventana permanece mapeada y en la parte superior del orden de apilamiento hasta que el salvapantallas se desactiva en respuesta a la actividad en cualquiera de los dispositivos de entrada del usuario, una solicitud ForceScreenSaver con un valor de Reset, o cualquier solicitud que provoque que la ventana se desmapee.

Si el salvapantallas se activa mientras el servidor está siendo capturado por otro cliente, se utiliza el mecanismo interno del salvapantallas. La solicitud ForceScreenSaver puede utilizarse con un valor de Active para desactivar el salvapantallas interno y activar el salvapantallas externo.

Si la conexión del cliente del salvapantallas con el servidor se interrumpe mientras el salvapantallas está activado y el modo de cierre del cliente no ha sido RetainPermanent o RetainTemporary, el salvapantallas actual se desactiva y el salvapantallas interno se activa inmediatamente.

Cuando el salvapantallas se desactiva, el mapa de colores de la ventana del salvapantallas se desinstala y la ventana se desmapea (excepto como se describe a continuación). El XID del salvapantallas se disocia de la ventana y el servidor puede, pero no está obligado a, destruir la ventana junto con cualquier hijo.

Cuando el salvapantallas se está desactivando y luego se reactiva inmediatamente (como al cambiar de salvapantallas), el servidor puede dejar la ventana del salvapantallas mapeada (típicamente para evitar generar exposiciones).

ERRORES

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes y XScreenSaverUnsetAttributes generarán un error BadDrawable si drawable no es un identificador de drawable válido. Si se establecen bits indefinidos en event-mask, se genera un error BadValue por XScreenSaverSelectInput.

DISPONIBILIDAD

XScreenSaverSuspend está disponible en la versión 1.1 y posteriores de la extensión X Screen Saver. La versión 1.1 se lanzó por primera vez con X11R7.1.
