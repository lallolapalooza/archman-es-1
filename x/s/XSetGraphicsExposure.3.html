XSetGraphicsExposure(3)

Paquete: libx11

Licencias: MIT AND X11

XSetArcMode(3) FUNCIONES DE XLIB XSetArcMode(3)

NOMBRE

XSetArcMode, XSetSubwindowMode, XSetGraphicsExposure - rutinas de conveniencia de GC

SINTAXIS

int XSetArcMode(Display *display, GC gc, int arc_mode);

int XSetSubwindowMode(Display *display, GC gc, int subwindow_mode);

int XSetGraphicsExposures(Display *display, GC gc, Bool graphics_exposures);

ARGUMENTOS

arc_mode
Especifica el modo de arco. Puede pasar ArcChord o ArcPieSlice.
display
Especifica la conexión con el servidor X.
gc
Especifica el GC.
graphics_exposures
Especifica un valor booleano que indica si desea que se informen los eventos GraphicsExpose y NoExpose al llamar a XCopyArea y XCopyPlane con este GC.
subwindow_mode
Especifica el modo de subventana. Puede pasar ClipByChildren o IncludeInferiors.

DESCRIPCIÓN

La función XSetArcMode establece el modo de arco en el GC especificado.

XSetArcMode puede generar errores BadAlloc, BadGC y BadValue.

La función XSetSubwindowMode establece el modo de subventana en el GC especificado.

XSetSubwindowMode puede generar errores BadAlloc, BadGC y BadValue.

La función XSetGraphicsExposures establece el indicador graphics-exposures en el GC especificado.

XSetGraphicsExposures puede generar errores BadAlloc, BadGC y BadValue.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
