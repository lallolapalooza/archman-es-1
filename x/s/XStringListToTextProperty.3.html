XStringListToTextProperty(3)

Paquete: libx11

Licencias: MIT AND X11

XStringListToTextProperty(3) FUNCIONES DE XLIB XStringListToTextProperty(3)

NOMBRE

XStringListToTextProperty, XTextPropertyToStringList, XFreeStringList, XTextProperty - convertir listas de cadenas y estructura de propiedad de texto

SINTAXIS

Status XStringListToTextProperty(char **lista, int cuenta, XTextProperty *propiedad_texto_retorno);

Status XTextPropertyToStringList(XTextProperty *propiedad_texto, char ***lista_retorno, int *cuenta_retorno);

void XFreeStringList(char **lista);

ARGUMENTOS

cuenta
Especifica el número de cadenas.
cuenta_retorno
Devuelve el número de cadenas.
lista
Especifica la lista de cadenas a liberar.
lista
Especifica una lista de cadenas de caracteres terminadas en nulo.
lista_retorno
Devuelve una lista de cadenas de caracteres terminadas en nulo.
propiedad_texto
Especifica la estructura XTextProperty a utilizar.
propiedad_texto_retorno
Devuelve la estructura XTextProperty.

DESCRIPCIÓN

La función XStringListToTextProperty establece la XTextProperty especificada para que sea de tipo STRING (formato 8) con un valor que representa la concatenación de la lista especificada de cadenas de caracteres separadas por nulos. Se almacena un byte nulo adicional (que no está incluido en el miembro nitems) al final del campo de valor de propiedad_texto_retorno. Se asume (sin verificación) que las cadenas están en la codificación STRING. Si no hay memoria suficiente para la nueva cadena de valor, XStringListToTextProperty no establece ningún campo en la estructura XTextProperty y devuelve un estado cero. De lo contrario, devuelve un estado distinto de cero. Para liberar el almacenamiento del campo de valor, use XFree.

La función XTextPropertyToStringList devuelve una lista de cadenas que representa los elementos separados por nulos de la estructura XTextProperty especificada. Los datos en propiedad_texto deben ser de tipo STRING y formato 8. Múltiples elementos de la propiedad (por ejemplo, las cadenas en una selección de texto disjunta) están separados por NULL (codificación 0). El contenido de la propiedad no está terminado en nulo. Si no hay memoria suficiente para la lista y sus elementos, XTextPropertyToStringList no establece ningún valor de retorno y devuelve un estado cero. De lo contrario, devuelve un estado distinto de cero. Para liberar el almacenamiento de la lista y su contenido, use XFreeStringList.

La función XFreeStringList libera la memoria asignada por XmbTextPropertyToTextList, Xutf8TextPropertyToTextList y XTextPropertyToStringList, y la lista de conjuntos de caracteres faltantes asignada por XCreateFontSet.

ESTRUCTURAS

La estructura XTextProperty contiene:

typedef struct {
        unsigned char *valor;   /* datos de la propiedad */
        Atom codificacion;  /* tipo de propiedad */
        int formato;     /* 8, 16 o 32 */
        unsigned long nitems;   /* número de elementos en valor */
} XTextProperty;
