XSetTextProperty(3)

Paquete: libx11

Licencias: MIT AND X11

XSetTextProperty(3) FUNCIONES XLIB XSetTextProperty(3)

NOMBRE

XSetTextProperty, XGetTextProperty - establecer y leer propiedades de texto

SINTAXIS

void XSetTextProperty(Display *display, Window w, XTextProperty *text_prop, Atom property);

Status XGetTextProperty(Display *display, Window w, XTextProperty *text_prop_return, Atom property);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
property
Especifica el nombre de la propiedad.
text_prop
Especifica la estructura XTextProperty a ser utilizada.
text_prop_return
Devuelve la estructura XTextProperty.

DESCRIPCIÓN

La función XSetTextProperty reemplaza la propiedad especificada existente para la ventana nombrada con los datos, tipo, formato y número de elementos determinados por el campo de valor, el campo de codificación, el campo de formato y el campo nitems, respectivamente, de la estructura XTextProperty especificada. Si la propiedad no existe ya, XSetTextProperty la establece para la ventana especificada.

XSetTextProperty puede generar errores BadAlloc, BadAtom, BadValue y BadWindow.

La función XGetTextProperty lee la propiedad especificada de la ventana y almacena los datos en la estructura XTextProperty devuelta. Almacena los datos en el campo de valor, el tipo de datos en el campo de codificación, el formato de los datos en el campo de formato y el número de elementos de datos en el campo nitems. Se almacena un byte extra que contiene un nulo (que no está incluido en el miembro nitems) al final del campo de valor de text_prop_return. La interpretación particular de la codificación y los datos de la propiedad como texto se deja a la aplicación que llama. Si la propiedad especificada no existe en la ventana, XGetTextProperty establece el campo de valor a NULL, el campo de codificación a None, el campo de formato a cero y el campo nitems a cero.

Si pudo leer y almacenar los datos en la estructura XTextProperty, XGetTextProperty devuelve un estado distinto de cero; de lo contrario, devuelve un estado cero.

XGetTextProperty puede generar errores BadAtom y BadWindow.

PROPIEDADES

WM_CLIENT_MACHINE
El nombre de cadena de la máquina en la que se está ejecutando la aplicación cliente.
WM_COMMAND
El comando y los argumentos, separados por nulos, utilizados para invocar la aplicación.
WM_ICON_NAME
El nombre que se utilizará en un icono.
WM_NAME
El nombre de la aplicación.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadAtom
Un valor para un argumento de tipo Atom no nombra un Atom definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento de tipo Window no nombra una Window definida.
