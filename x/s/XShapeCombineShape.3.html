ESTRUCTURAS

typedef struct {
    int type;	/* tipo de evento */
    unsigned long serial;	/* # de la última petición procesada por el servidor */
    Bool send_event;	/* verdadero si esto provino de una petición SendEvent */
    Display *display;	/* Display desde el cual se leyó el evento */
    Window window;	/* ventana del evento */
    int kind;	/* ShapeBounding o ShapeClip */
    int x, y;	/* extensiones de la nueva región */
    unsigned width, height;
    Time time;	/* marca de tiempo del servidor cuando la región cambió */
    Bool shaped;	/* verdadero si la región existe */
} XShapeEvent;

DESCRIPCIÓN

La Extensión de Forma de Ventana No Rectangular X11 añade ventanas no rectangulares al Sistema de Ventanas X.
