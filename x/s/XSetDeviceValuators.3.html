XSETDEVICEVALUATORS(3)   XSETDEVICEVALUATORS(3)

NOMBRE

XSetDeviceValuators - inicializa los valuators de un dispositivo de entrada de extensión

SINOPSIS

#include <X11/extensions/XInput.h>
XSetDeviceValuators( Display *display,
                     XDevice *device,
                     int *valuators,
                     int first_valuator,
                     int num_valuators);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyos valuators se van a
       inicializar.
valuators
       Especifica un puntero a una matriz de valores enteros que se utilizarán para inicializar los valuators del dispositivo.
first_valuator
       Especifica el primer valuator que se establecerá. Los valuators se numeran a partir de cero.
num_valuators
       Especifica el número de valuators que se establecerán.

DESCRIPCIÓN

La solicitud XSetDeviceValuators establece los valores actuales de los
valuators de un dispositivo de entrada. Los valuators en el rango
first_valuator hasta (first_valuator + num_valuators) se establecen con los
valores especificados. Los valuators se numeran a partir de 0.
No todos los dispositivos de entrada admiten la inicialización de los valores de los valuators. Si esta solicitud se realiza a un dispositivo que no admite la inicialización de valuators, se producirá un error BadMatch.
Si la solicitud tiene éxito, se devolverá un estado Success. Si
otro cliente tiene el dispositivo capturado, se devolverá un estado
AlreadyGrabbed.
XSetDeviceValuators puede generar un error BadLength, BadDevice,
BadMatch o BadValue.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice.
BadMatch
       Este error puede ocurrir si se realiza una solicitud XSetDeviceValuators
       especificando un dispositivo que no tiene valuators y
       no informa de ejes de movimiento, o si dicha solicitud se realiza
       especificando un dispositivo que no admite la inicialización de valuators.
BadValue
       Se especificaron valores inválidos para first_valuator o num_valuators.
