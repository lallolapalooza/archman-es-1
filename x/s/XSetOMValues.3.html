XOpenOM(3) FUNCIONES DE XLIB XOpenOM(3)

NOMBRE

XOpenOM, XCloseOM, XSetOMValues, XGetOMValues, XDisplayOfOM, XLocaleOfOM - abrir métodos de salida

SINTAXIS

XOM XOpenOM(Display *display, XrmDatabase db, char *res_name, char *res_class);

Status XCloseOM(XOM om);

char *XSetOMValues(XOM om, ...);

char *XGetOMValues(XOM om, ...);

Display *XDisplayOfOM(XOM om);

char *XLocaleOfOM(XOM om);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
db
Especifica un puntero a la base de datos de recursos.
res_name
Especifica el nombre completo del recurso de la aplicación.
res_class
Especifica el nombre completo de la clase de la aplicación.
om
Especifica el método de salida.
...
Especifica la lista de argumentos de longitud variable para establecer o obtener valores de XOM.

DESCRIPCIÓN

La función XOpenOM abre un método de salida que coincide con la especificación de localización y modificadores actual. La localización y los modificadores actuales se vinculan al método de salida cuando se llama a XOpenOM. La localización asociada a un método de salida no se puede cambiar.

El método de salida específico al que se dirigirá esta llamada se identifica en función de la localización y los modificadores actuales. XOpenOM identificará un método de salida predeterminado que corresponde a la localización actual. Ese valor predeterminado se puede modificar usando XSetLocaleModifiers para establecer el modificador del método de salida.

El argumento db es la base de datos de recursos que será utilizada por el método de salida para buscar recursos que son privados para el método de salida. No está previsto que esta base de datos se utilice para buscar valores que se puedan establecer como valores OC en un contexto de salida. Si db es NULL, no se pasa ninguna base de datos al método de salida.

Los argumentos res_name y res_class especifican el nombre y la clase del recurso de la aplicación. Están pensados para ser utilizados como prefijos por el método de salida al buscar recursos que son comunes a todos los contextos de salida que se puedan crear para este método de salida. Los caracteres utilizados para los nombres y clases de recursos deben estar en el Conjunto de Caracteres Portátiles de X. Los recursos buscados no se especifican completamente si res_name o res_class es NULL.

No se asume que los argumentos res_name y res_class existan más allá de la llamada a XOpenOM. Se asume que la base de datos de recursos especificada existe durante la vida útil del método de salida.

XOpenOM devuelve NULL si no se pudo abrir ningún método de salida.

La función XCloseOM cierra el método de salida especificado.

La función XSetOMValues presenta una interfaz de programación de lista de argumentos variables para establecer propiedades o características del método de salida especificado. Esta función devuelve NULL si tiene éxito; de lo contrario, devuelve el nombre del primer argumento que no se pudo establecer. Xlib no intenta establecer argumentos de la lista suministrada que siguen al argumento fallido; todos los argumentos de la lista precedentes al argumento fallido se han establecido correctamente.

Actualmente no hay argumentos estándar definidos por Xlib.

La función XGetOMValues presenta una interfaz de programación de lista de argumentos variables para consultar propiedades o características del método de salida especificado. Esta función devuelve NULL si tiene éxito; de lo contrario, devuelve el nombre del primer argumento que no se pudo obtener.

La función XDisplayOfOM devuelve la pantalla asociada con el método de salida especificado.

La función XLocaleOfOM devuelve la localización asociada con el método de salida especificado.
