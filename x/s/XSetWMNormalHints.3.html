Paquete: libx11

Licencias: MIT AND X11

XAllocSizeHints(3) FUNCIONES DE XLIB XAllocSizeHints(3)

NOMBRE

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - asignar estructura de pistas de tamaño y establecer o leer la propiedad WM_NORMAL_HINTS de una ventana

SINTAXIS

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
hints
Especifica las pistas de tamaño para la ventana en su estado normal.
hints
Especifica la estructura XSizeHints que se utilizará.
hints_return
Devuelve las pistas de tamaño para la ventana en su estado normal.
property
Especifica el nombre de la propiedad.
supplied_return
Devuelve las pistas que fueron proporcionadas por el usuario.
w
Especifica la ventana.

DESCRIPCIÓN

La función XAllocSizeHints asigna y devuelve un puntero a una estructura XSizeHints. Tenga en cuenta que todos los campos de la estructura XSizeHints se establecen inicialmente a cero. Si no hay suficiente memoria disponible, XAllocSizeHints devuelve NULL. Para liberar la memoria asignada a esta estructura, use XFree.

La función XSetWMNormalHints reemplaza las pistas de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. Si la propiedad aún no existe, XSetWMNormalHints establece las pistas de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. La propiedad se almacena con un tipo WM_SIZE_HINTS y un formato de 32.

XSetWMNormalHints puede generar errores BadAlloc y BadWindow.

La función XGetWMNormalHints devuelve las pistas de tamaño almacenadas en la propiedad WM_NORMAL_HINTS de la ventana especificada. Si la propiedad es de tipo WM_SIZE_HINTS, tiene formato 32 y es lo suficientemente larga como para contener una estructura de pistas de tamaño antigua (pre-ICCCM) o nueva, XGetWMNormalHints establece varios campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos) y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero.

Si XGetWMNormalHints devuelve correctamente y se lee una propiedad de pistas de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente grande como para contener también los campos de tamaño base y gravedad de ventana, el argumento supplied_return también contendrá los siguientes bits:

PBaseSize|PWinGravity

XGetWMNormalHints puede generar un error PN BadWindow.

La función XSetWMSizeHints reemplaza las pistas de tamaño para la propiedad especificada en la ventana nombrada. Si la propiedad especificada aún no existe, XSetWMSizeHints establece las pistas de tamaño para la propiedad especificada en la ventana nombrada. La propiedad se almacena con un tipo WM_SIZE_HINTS y un formato de 32. Para establecer las pistas de tamaño normales de una ventana, puede usar la función XSetWMNormalHints.

XSetWMSizeHints puede generar errores BadAlloc, BadAtom y BadWindow.

La función XGetWMSizeHints devuelve las pistas de tamaño almacenadas en la propiedad especificada en la ventana nombrada. Si la propiedad es de tipo WM_SIZE_HINTS, tiene formato 32 y es lo suficientemente larga como para contener una estructura de pistas de tamaño antigua (pre-ICCCM) o nueva, XGetWMSizeHints establece varios campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos) y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero. Para obtener las pistas de tamaño normales de una ventana, puede usar la función XGetWMNormalHints.

Si XGetWMSizeHints devuelve correctamente y se lee una propiedad de pistas de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente grande como para contener también los campos de tamaño base y gravedad de ventana, el argumento supplied_return también contendrá los siguientes bits:

PBaseSize|PWinGravity

XGetWMSizeHints puede generar errores BadAtom y BadWindow.

PROPIEDADES

WM_NORMAL_HINTS
Pistas de tamaño para una ventana en su estado normal. El tipo C de esta propiedad es XSizeHints.

ESTRUCTURAS

La estructura XSizeHints contiene:

/* Bits de máscara de pistas de tamaño */

#define USPosition (1L << 0) /* usuario especificó x, y */
#define USSize (1L << 1) /* usuario especificó ancho, alto */
#define PPosition (1L << 2) /* programa especificó posición */
#define PSize (1L << 3) /* programa especificó tamaño */
#define PMinSize (1L << 4) /* programa especificó tamaño mínimo */
#define PMaxSize (1L << 5) /* programa especificó tamaño máximo */
#define PResizeInc (1L << 6) /* programa especificó incrementos de redimensionamiento */
#define PAspect (1L << 7) /* programa especificó relaciones de aspecto mínimas y máximas */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        int x, y;       /* Obsoleto */
        int width, height;      /* Obsoleto */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* numerador */
               int y;   /* denominador */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* esta estructura puede ser extendida en el futuro */
} XSizeHints;

Los miembros x, y, width y height ahora son obsoletos y se dejan exclusivamente por motivos de compatibilidad. Los miembros min_width y min_height especifican el tamaño mínimo de ventana que aún permite que la aplicación sea útil. Los miembros max_width y max_height especifican el tamaño máximo de ventana. Los miembros width_inc y height_inc definen una progresión aritmética de tamaños (mínimo a máximo) en los que la ventana prefiere ser redimensionada. Los miembros min_aspect y max_aspect se expresan como relaciones de x e y, y permiten a una aplicación especificar el rango de relaciones de aspecto que prefiere. Los miembros base_width y base_height definen el tamaño deseado de la ventana. El gestor de ventanas interpretará la posición de la ventana y el ancho de su borde para posicionar el punto del rectángulo exterior de la ventana general especificada por el miembro win_gravity. XSetWMNormalHints(3) - Arch Linux Man Pages

NAME

XSetWMNormalHints - establecer las sugerencias de tamaño y posiciones normales de una ventana para el administrador de ventanas

SYNTAX

void XSetWMNormalHints(Display *display, Window w, XWMHints *hints);

ARGUMENTS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana a la que se le van a establecer las sugerencias.
hints
Especifica las sugerencias de ventana normales a establecer. Si es un puntero nulo, se eliminan las sugerencias de ventana normales asociadas con la ventana.

DESCRIPTION

La función XSetWMNormalHints establece las sugerencias de ventana normales para la ventana especificada. Las sugerencias de ventana normales se utilizan para comunicar información sobre las dimensiones deseadas y la posición de la ventana al administrador de ventanas.

La estructura XWMHints se define como:

typedef struct {
    int flags;
    int x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int width_inc, height_inc;
    Time time;
    Window parent;
    long input;
} XWMHints;

Los indicadores relevantes para XSetWMNormalHints son:

  • PPosition: La posición de la ventana (x, y) es significativa.
  • PSize: El tamaño de la ventana (width, height) es significativo.
  • PMinSize: El tamaño mínimo de la ventana (min_width, min_height) es significativo.
  • PMaxSize: El tamaño máximo de la ventana (max_width, max_height) es significativo.
  • PResizeInc: Los incrementos de tamaño de la ventana (width_inc, height_inc) son significativos.
  • PAspect: La relación de aspecto de la ventana (definida por min_aspect y max_aspect, que no se muestran en la estructura anterior pero se especifican en la documentación de Xlib) es significativa.

Si el argumento hints es un puntero nulo, se eliminan todas las sugerencias de ventana normales asociadas con la ventana especificada.

El administrador de ventanas utiliza estas sugerencias para determinar la mejor manera de colocar y cambiar el tamaño de la ventana. Por ejemplo, si se establece PMinSize, el administrador de ventanas se asegurará de que la ventana no se reduzca por debajo de esas dimensiones.

Para obtener más información sobre los campos de la estructura XWMHints y los indicadores, consulte la documentación de XAllocWMHints.

PROPERTIES

Esta función establece la propiedad WM_NORMAL_HINTS en la ventana.

STRUCTURES

La estructura XWMHints es una de las estructuras de sugerencias de ventana utilizadas en X Window System. Contiene varios campos que describen las características deseadas de una ventana, como su tamaño, posición, y si se puede cambiar su tamaño o no.

Los indicadores definen qué campos de la estructura XWMHints son válidos y deben ser tenidos en cuenta por el administrador de ventanas. Por ejemplo, si el indicador PPosition está establecido, el administrador de ventanas considerará los valores de x e y al colocar la ventana. Si no está establecido, el administrador de ventanas puede elegir la posición libremente.

El campo parent en la estructura XWMHints no se utiliza con XSetWMNormalHints. Se utiliza con XSetWMHints para indicar la ventana padre deseada en caso de que la ventana se esté utilizando como una ventana de cliente para un administrador de ventanas y se le pidan sugerencias de colocación relativas al borde de la ventana padre.

Tenga en cuenta que el uso de la macro PAllHints está muy desaconsejado.

DIAGNOSTICS

BadAlloc
El servidor no pudo asignar el recurso o memoria del servidor solicitados.
BadAtom
Un valor para un argumento Atom no nombra un Atom definido.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
