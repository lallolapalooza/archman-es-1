XDrawLine(3) FUNCIONES XLIB XDrawLine(3)

NOMBRE

XDrawLine, XDrawLines, XDrawSegments, XSegment - dibuja líneas, polígonos y estructuras de línea

SINTAXIS

int XDrawLine(Display *display, Drawable d, GC gc, int x1, int y1, int x2, int y2);

int XDrawLines(Display *display, Drawable d, GC gc, XPoint *points, int npoints, int mode);

int XDrawSegments(Display *display, Drawable d, GC gc, XSegment *segments, int nsegments);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
gc
Especifica la GC.
mode
Especifica el modo de coordenadas. Puedes pasar CoordModeOrigin o CoordModePrevious.
npoints
Especifica el número de puntos en el array.
nsegments
Especifica el número de segmentos en el array.
points
Especifica un array de puntos.
segments
Especifica un array de segmentos.
x1

y1

x2

y2
Especifican los puntos (x1, y1) y (x2, y2) a conectar.

DESCRIPCIÓN

La función XDrawLine utiliza los componentes de la GC especificada para dibujar una línea entre el conjunto especificado de puntos (x1, y1) y (x2, y2). No realiza uniones en puntos finales coincidentes. Para cualquier línea dada, XDrawLine no dibuja un píxel más de una vez. Si las líneas se cruzan, los píxeles que se cruzan se dibujan varias veces.

La función XDrawLines utiliza los componentes de la GC especificada para dibujar npoints-1 líneas entre cada par de puntos (point[i], point[i+1]) en el array de estructuras XPoint. Dibuja las líneas en el orden en que aparecen en el array. Las líneas se unen correctamente en todos los puntos intermedios, y si el primer y último punto coinciden, las líneas primera y última también se unen correctamente. Para cualquier línea dada, XDrawLines no dibuja un píxel más de una vez. Si las líneas finas (de ancho cero) se cruzan, los píxeles que se cruzan se dibujan varias veces. Si las líneas anchas se cruzan, los píxeles que se cruzan se dibujan solo una vez, como si toda la solicitud de protocolo PolyLine fuera una forma única y rellena. CoordModeOrigin trata todas las coordenadas como relativas al origen, y CoordModePrevious trata todas las coordenadas después de la primera como relativas al punto anterior.

La función XDrawSegments dibuja múltiples líneas desconectadas. Para cada segmento, XDrawSegments dibuja una línea entre (x1, y1) y (x2, y2). Dibuja las líneas en el orden en que aparecen en el array de estructuras XSegment y no realiza uniones en puntos finales coincidentes. Para cualquier línea dada, XDrawSegments no dibuja un píxel más de una vez. Si las líneas se cruzan, los píxeles que se cruzan se dibujan varias veces.

Las tres funciones utilizan estos componentes de la GC: function, plane-mask, line-width, line-style, cap-style, fill-style, subwindow-mode, clip-x-origin, clip-y-origin y clip-mask. La función XDrawLines también utiliza el componente join-style de la GC. Las tres funciones también utilizan estos componentes dependientes del modo de la GC: foreground, background, tile, stipple, tile-stipple-x-origin, tile-stipple-y-origin, dash-offset y dash-list.

XDrawLine, XDrawLines y XDrawSegments pueden generar errores BadDrawable, BadGC y BadMatch. XDrawLines también puede generar un error BadValue.

ESTRUCTURAS

La estructura XSegment contiene:

typedef struct {
        short x1, y1, x2, y2;
} XSegment;

Todos los miembros x e y son enteros con signo. Los miembros width y height son enteros sin signo de 16 bits. Debes tener cuidado de no generar coordenadas y tamaños fuera de los rangos de 16 bits, ya que el protocolo solo tiene campos de 16 bits para estos valores.

DIAGNÓSTICOS

BadDrawable
Un valor para un argumento Drawable no nombra una Ventana o Pixmap definida.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos, pero falla al coincidir de alguna otra manera requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
