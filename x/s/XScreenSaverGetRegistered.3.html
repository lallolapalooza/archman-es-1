NOMBRE

XScreenSaver - biblioteca cliente de la extensión del salvapantallas de X11

SINOPSIS

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* ventana del salvapantallas */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* milisegundos */
    unsigned long idle;           /* milisegundos */
    unsigned long eventMask;      /* eventos */
} XScreenSaverInfo;

typedef struct {
    int type;               /* de evento */
    unsigned long serial;   /* # de la última solicitud procesada por el servidor */
    Bool send_event;        /* verdadero si esto provino de una solicitud SendEvent */
    Display *display;       /* Pantalla desde la que se leyó el evento */
    Window window;          /* ventana del salvapantallas */
    Window root;            /* ventana raíz de la pantalla del evento */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* extensiones de la nueva región */
    Time time;              /* marca de tiempo del evento */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPCIÓN

El Sistema de Ventanas X proporciona soporte para cambiar la imagen en la pantalla de un monitor después de un período de inactividad establecido por el usuario para evitar quemar los fósforos del tubo de rayos catódicos. Sin embargo, no se proporcionan interfaces para que el usuario controle la imagen que se dibuja. Esta extensión permite que un cliente externo de ``salvapantallas'' detecte cuándo se va a mostrar la imagen alternativa y proporcione los gráficos.

Las implementaciones actuales del servidor X típicamente proporcionan al menos una forma de imagen de ``salvapantallas''. Históricamente, esta ha sido una copia del logo de X dibujada contra el patrón de fondo de la raíz. Sin embargo, muchos usuarios han pedido el mecanismo que les permita escribir programas de salvapantallas que proporcionen capacidades similares a las proporcionadas por otros sistemas de ventanas. En particular, dichos usuarios a menudo desean poder mostrar logos corporativos, instrucciones sobre cómo reactivar la pantalla y utilidades de bloqueo de pantalla automático. Esta extensión proporciona un medio para escribir tales clientes.

Supuestos

Esta extensión exporta la noción de una ventana especial de salvapantallas que se mapea por encima de todas las demás ventanas en una pantalla. Esta ventana tiene el atributo override-redirect establecido para que no esté sujeta a manipulación por el gestor de ventanas. Además, el identificador X de la ventana nunca es devuelto por solicitudes QueryTree en la ventana raíz, por lo que típicamente no es visible para otros clientes.

XScreenSaverQueryExtension devuelve True si la extensión XScreenSaver está disponible en la pantalla dada. Un cliente debe llamar a XScreenSaverQueryExtension antes de llamar a cualquier otra función de XScreenSaver para negociar una versión de protocolo compatible; de lo contrario, el cliente obtendrá un comportamiento indefinido (XScreenSaver puede funcionar o no).

Si la extensión es compatible, el número de evento para eventos ScreenSaverNotify se devuelve en el valor apuntado por event_base. Dado que esta extensión no define errores adicionales, los resultados de error_base no están definidos.

XScreenSaverQueryVersion devuelve True si la solicitud tuvo éxito; los valores de las versiones de protocolo principal y secundaria compatibles con el servidor se devuelven en major_version_return y minor_version_return.

XScreenSaverAllocInfo asigna y devuelve una estructura XScreenSaverInfo para usar en llamadas a XScreenSaverQueryInfo. Todos los campos de la estructura se inicializan a cero. Si no hay suficiente memoria disponible, se devuelve NULL. Los resultados de esta rutina se pueden liberar usando XFree.

XScreenSaverQueryInfo devuelve información sobre el estado actual del servidor de pantalla en saver_info y se devuelve un valor distinto de cero. Si la extensión no es compatible, saver_info no se modifica y se devuelve 0.

El campo state especifica si el salvapantallas está actualmente activo o no y cómo se debe interpretar el valor til-or-since:

Off
La pantalla no se está salvando actualmente; til-or-since especifica el número de milisegundos hasta que se espera que el salvapantallas se active.
On
La pantalla se está salvando actualmente; til-or-since especifica el número de milisegundos desde que se activó el salvapantallas.
Disabled
El salvapantallas está actualmente deshabilitado; til-or-since es cero.

El campo kind especifica el mecanismo que se está utilizando actualmente o que se habría utilizado si la pantalla se estuviera salvando:

Blanked
Se deshabilitó la señal de video del monitor de pantalla.
Internal
Se mostró una imagen de salvapantallas incorporada y dependiente del servidor; o bien ningún cliente había establecido los atributos de la ventana del salvapantallas o bien otro cliente tenía el servidor capturado cuando se activó el salvapantallas.
External
La ventana del salvapantallas se mapeó con atributos establecidos por un cliente usando la solicitud ScreenSaverSetAttributes.

El campo idle especifica el número de milisegundos desde la última entrada recibida del usuario en cualquiera de los dispositivos de entrada.
El campo event-mask especifica cuáles, si los hay, eventos del salvapantallas este cliente ha solicitado usando ScreenSaverSelectInput.

XScreenSaverSelectInput solicita que se generen eventos relacionados con el salvapantallas para este cliente. Si no hay bits establecidos en event-mask, no se generarán eventos. De lo contrario, se pueden establecer cualquier combinación de los siguientes bits:

ScreenSaverNotify
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que el salvapantallas se activa o desactiva.
ScreenSaverCycle
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que pasa el intervalo de ciclo del salvapantallas.

XScreenSaverSetAttributes establece los atributos a ser utilizados la próxima vez que se active el salvapantallas externo. Si otro cliente tiene actualmente los atributos establecidos, se genera un error BadAccess y la solicitud se ignora.
De lo contrario, los atributos especificados se verifican como si se hubieran utilizado en una solicitud CreateWindow principal cuyo padre es la raíz. El campo override-redirect se ignora ya que se establece implícitamente en True. Si los atributos de la ventana resultan en un error de acuerdo con las reglas para CreateWindow, la solicitud se ignora.
De lo contrario, los atributos se almacenan y entrarán en vigor en la próxima activación que ocurra cuando el servidor no esté capturado por otro cliente. Cualquier recurso especificado para los atributos background-pixmap o cursor puede liberarse inmediatamente.

DESCRIPCIÓN

El servidor es libre de copiar los recursos background-pixmap o cursor o de usarlos en su lugar; por lo tanto, el efecto de cambiar el contenido de esos recursos no está definido. Si el colormap especificado ya no existe cuando se activa el salvapantallas, se utiliza el colormap del padre. Si no se generan errores en esta solicitud, se liberan los atributos anteriores de la ventana del salvapantallas establecidos por este cliente.


Cuando el salvapantallas se active la próxima vez y el servidor no esté capturado por otro cliente, la ventana del salvapantallas se creará, si es necesario, y se establecerá con los atributos especificados, y se generarán eventos como de costumbre. Se instalará el colormap asociado con la ventana del salvapantallas. Finalmente, la ventana del salvapantallas se mapeará.


La ventana permanecerá mapeada y en la parte superior del orden de apilamiento hasta que el salvapantallas se desactive en respuesta a actividad en cualquiera de los dispositivos de entrada del usuario, una solicitud ForceScreenSaver con un valor de Reset, o cualquier solicitud que cause que la ventana se desmapee.


Si el salvapantallas se activa mientras el servidor está capturado por otro cliente, se utilizará el mecanismo de salvado interno. La solicitud ForceScreenSaver puede usarse con un valor de Active para desactivar el salvado interno y activar el salvado externo.


Si la conexión del cliente del salvapantallas con el servidor se interrumpe mientras el salvapantallas está activado y el modo de cierre del cliente no ha sido RetainPermanent o RetainTemporary, el salvapantallas actual se desactivará y el salvapantallas interno se activará inmediatamente.


Cuando el salvapantallas se desactiva, el colormap de la ventana del salvapantallas se desinstala y la ventana se desmapea (excepto como se describe a continuación). El XID del salvapantallas se disocia de la ventana y el servidor puede, pero no está obligado a, destruir la ventana junto con cualquier hijo.


Cuando el salvapantallas se está desactivando y luego se reactiva inmediatamente (como al cambiar de salvapantallas), el servidor puede dejar la ventana del salvapantallas mapeada (típicamente para evitar generar exposiciones).

XScreenSaverUnsetAttributes instruye al servidor a descartar cualquier atributo previo de la ventana del salvapantallas establecido por este cliente.

XScreenSaverRegister almacena el XID dado en la propiedad _SCREEN_SAVER_ID (del type dado) en la ventana raíz de la screen especificada. Devuelve cero si se encuentra un error y la propiedad no se cambia, de lo contrario, devuelve un valor distinto de cero.

XScreenSaverUnregister elimina cualquier _SCREEN_SAVER_ID de la ventana raíz de la screen especificada. Devuelve cero si se encuentra un error y la propiedad se cambia, de lo contrario, devuelve un valor distinto de cero.

XScreenSaverGetRegistered devuelve el XID y el type almacenados en la propiedad _SCREEN_SAVER_ID en la ventana raíz de la screen especificada. Devuelve cero si se encuentra un error o si la propiedad no existe o no tiene el formato correcto; de lo contrario, devuelve un valor distinto de cero.

XScreenSaverSuspend suspende temporalmente el salvapantallas y el temporizador DPMS si suspend es 'True', y reinicia el temporizador si suspend es 'False'.
Esta función debe ser utilizada por aplicaciones que no desean que el salvapantallas o DPMS se activen mientras están, por ejemplo, en proceso de reproducir una secuencia multimedia, o que de otra manera presentan información visual continua al usuario mientras están en un estado no interactivo. Esta función no está destinada a ser llamada por una aplicación de salvapantallas externa.
Si XScreenSaverSuspend se llama varias veces con suspend establecido en 'True', debe llamarse un número igual de veces con suspend establecido en 'False' para que el temporizador del salvapantallas se reinicie. Esta solicitud no tiene efecto si un cliente intenta reanudar el salvapantallas sin haberlo suspendido previamente. Por lo tanto, XScreenSaverSuspend no puede ser utilizado por un cliente para reanudar el salvapantallas si ha sido suspendido por otro cliente.
Si un cliente que ha suspendido el salvapantallas se desconecta del servidor X, el temporizador del salvapantallas se reiniciará automáticamente, a menos que todavía esté suspendido por otro cliente. Suspender el temporizador del salvapantallas no evita que el salvapantallas se active forzosamente con la solicitud ForceScreenSaver, o que se establezca un modo DPMS con la solicitud DPMSForceLevel.
XScreenSaverSuspend tampoco desactiva el salvapantallas o DPMS si alguno de ellos está activo en el momento en que el servidor X recibe la solicitud para suspenderlos. Pero una vez que se han desactivado, no se activarán automáticamente de nuevo, hasta que el cliente haya cancelado la suspensión.

ERRORES

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes y XScreenSaverUnsetAttributes generarán un error BadDrawable si drawable no es un identificador de dibujo válido. Si se establecen bits indefinidos en event-mask, XScreenSaverSelectInput generará un error BadValue.

DISPONIBILIDAD

XScreenSaverSuspend está disponible en la versión 1.1 y posteriores de la Extensión de Salvapantallas de X. La versión 1.1 se lanzó por primera vez con X11R7.1.
