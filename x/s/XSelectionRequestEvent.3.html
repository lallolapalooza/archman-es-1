XSelectionRequestEvent(3) FUNCIONES DE XLIB XSelectionRequestEvent(3)

NOMBRE

XSelectionRequestEvent - estructura del evento SelectionRequest

ESTRUCTURAS

La estructura para los eventos SelectionRequest contiene:

typedef struct {
        int type;       /* SelectionRequest */
        unsigned long serial;   /* # de la última petición procesada por el servidor */
        Bool send_event;        /* true si esto provino de una petición SendEvent */
        Display *display;       /* Display desde el cual se leyó el evento */
        Window owner;
        Window requestor;
        Atom selection;
        Atom target;
        Atom property;
        Time time;
} XSelectionRequestEvent;

Cuando recibes este evento, los miembros de la estructura se configuran de la siguiente manera.

El miembro type se establece al nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro type establecido a GraphicsExpose. El miembro display se establece a un puntero al display en el que se leyó el evento. El miembro send_event se establece a True si el evento provino de una petición de protocolo SendEvent. El miembro serial se establece a partir del número de serie informado en el protocolo, pero ampliado de los 16 bits menos significativos a un valor completo de 32 bits. El miembro window se establece a la ventana que es más útil para los despachadores de toolkits.

El miembro owner se establece a la ventana que fue especificada por el propietario actual en su llamada XSetSelectionOwner. El miembro requestor se establece a la ventana que solicita la selección. El miembro selection se establece al átomo que nombra la selección. Por ejemplo, PRIMARY se usa para indicar la selección primaria. El miembro target se establece al átomo que indica el tipo en el que se desea la selección. El miembro property puede ser un nombre de propiedad o None. El miembro time se establece a la marca de tiempo o al valor CurrentTime de la petición ConvertSelection.
