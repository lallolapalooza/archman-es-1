XSetTSOrigin(3)

Paquete: libx11

Licencias: MIT AND X11

XSetTile(3) FUNCIONES DE XLIB XSetTile(3)

NOMBRE

XSetTile, XSetStipple, XSetTSOrigin - rutinas de conveniencia para GC

SINTAXIS

int XSetTile(Display *display, GC gc, Pixmap tile);

int XSetStipple(Display *display, GC gc, Pixmap stipple);

int XSetTSOrigin(Display *display, GC gc, int ts_x_origin, int ts_y_origin);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
gc
Especifica la GC.
stipple
Especifica el patrón de relleno que deseas establecer para la GC especificada.
tile
Especifica el mosaico de relleno que deseas establecer para la GC especificada.
ts_x_origin

ts_y_origin
Especifica las coordenadas x e y del origen del mosaico y del patrón de relleno.

DESCRIPCIÓN

La función XSetTile establece el mosaico de relleno en la GC especificada. El mosaico y la GC deben tener la misma profundidad, o se producirá un error BadMatch.

XSetTile puede generar errores BadAlloc, BadGC, BadMatch y BadPixmap.

La función XSetStipple establece el patrón de relleno en la GC especificada. El patrón de relleno debe tener una profundidad de uno, o se producirá un error BadMatch.

XSetStipple puede generar errores BadAlloc, BadGC, BadMatch y BadPixmap.

La función XSetTSOrigin establece el origen del mosaico/patrón de relleno en la GC especificada. Cuando las solicitudes gráficas requieren relleno con mosaico o patrón, el origen del padre se interpretará en relación con cualquier drawable de destino que se especifique en la solicitud gráfica.

XSetTSOrigin puede generar errores BadAlloc y BadGC.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadGC
Un valor de argumento de GContext no nombra un GContext definido.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero no coincide de alguna otra manera requerida por la solicitud.
BadPixmap
Un valor de argumento de Pixmap no nombra un Pixmap definido.
