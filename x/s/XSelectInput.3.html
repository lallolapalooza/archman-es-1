XSelectInput(3) FUNCIONES DE XLIB XSelectInput(3)

NOMBRE

XSelectInput - seleccionar eventos de entrada

SINTAXIS

int XSelectInput(Display *display, Window w, long event_mask);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
event_mask
Especifica la máscara de eventos.
w
Especifica la ventana de la que te interesan los eventos.

DESCRIPCIÓN

La función XSelectInput solicita que el servidor X informe de los eventos asociados con la máscara de eventos especificada. Inicialmente, X no informará de ninguno de estos eventos. Los eventos se informan en relación con una ventana. Si una ventana no está interesada en un evento del dispositivo, normalmente se propagará al antepasado más cercano que esté interesado, a menos que la máscara do_not_propagate lo prohíba.

Establecer el atributo de máscara de eventos de una ventana anula cualquier llamada anterior para la misma ventana pero no para otros clientes. Múltiples clientes pueden seleccionar eventos para los mismos eventos en la misma ventana con las siguientes restricciones:

  • Múltiples clientes pueden seleccionar eventos en la misma ventana porque sus máscaras de eventos son disjuntas. Cuando el servidor X genera un evento, lo informa a todos los clientes interesados.
  • Solo un cliente a la vez puede seleccionar eventos CirculateRequest, ConfigureRequest o MapRequest, que están asociados con la máscara de eventos SubstructureRedirectMask.
  • Solo un cliente a la vez puede seleccionar un evento ResizeRequest, que está asociado con la máscara de eventos ResizeRedirectMask.
  • Solo un cliente a la vez puede seleccionar un evento ButtonPress, que está asociado con la máscara de eventos ButtonPressMask.

El servidor informa del evento a todos los clientes interesados.

XSelectInput puede generar un error BadWindow.

DIAGNÓSTICOS

BadWindow
Un valor para un argumento Window no nombra una Ventana definida.
