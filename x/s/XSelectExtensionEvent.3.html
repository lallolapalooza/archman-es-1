XSELECTEXTENSIONEVEN(3)   XSELECTEXTENSIONEVEN(3)

NOMBRE

XSelectExtensionEvent, XGetSelectedExtensionEvents - seleccionar eventos de extensión, obtener la lista de eventos de extensión actualmente seleccionados

SINOPSIS

#include <X11/extensions/XInput.h>
XSelectExtensionEvent( Display *display,
                       Window w,
                       XEventClass *event_list,
                       int event_count);
XGetSelectedExtensionEvents( Display *display,
                             Window w,
                             int *this_client_event_count_return,
                             XEventClass **this_client_event_list_return,
                             int *all_clients_event_count_return,
                             XEventClass **all_clients_event_list_return);
display
       Especifica la conexión con el servidor X.
w
       Especifica la ventana sobre la que te interesan los eventos.
event_list
       Especifica la lista de clases de eventos que describen los
       eventos que te interesan.
event_count
       Especifica el número de clases de eventos en la lista de eventos.
this_client_event_count_return
       Devuelve el número de clases de eventos seleccionadas por este
       cliente.
this_client_event_list_return
       Devuelve un puntero a la lista de clases de eventos seleccionadas
       por este cliente.
all_clients_event_count_return
       Devuelve el número de clases de eventos seleccionadas por todos
       los clientes.
all_clients_event_list_return
       Devuelve un puntero a la lista de clases de eventos seleccionadas
       por todos los clientes.

DESCRIPCIÓN

La solicitud XSelectExtensionEvent hace que el servidor X informe de
los eventos asociados con la lista especificada de clases de eventos.
Inicialmente, X no informará de ninguno de estos eventos. Los eventos
se informan en relación con una ventana. Si una ventana no está interesada
en un evento del dispositivo, generalmente se propaga a su ancestro más
cercano que sí esté interesado, a menos que la máscara do_not_propagate lo
prohíba.
Múltiples clientes pueden seleccionar los mismos eventos en la misma
ventana con las siguientes restricciones:
  * Múltiples clientes pueden seleccionar eventos en la misma ventana
    porque sus máscaras de eventos son disjuntas. Cuando el servidor X
    genera un evento, lo informa a todos los clientes interesados.
  * Solo un cliente a la vez puede seleccionar un evento
    DeviceButtonPress con captura pasiva automática habilitada, que está
    asociado con la clase de evento DeviceButtonPressGrab. Para recibir
    eventos DeviceButtonPress sin captura pasiva automática, utiliza la
    clase de evento DeviceButtonPress pero no especifiques la clase de
    evento DeviceButtonPressGrab.
El servidor informa el evento a todos los clientes interesados.
La información contenida en la estructura XDevice devuelta por
XOpenDevice es utilizada por macros para obtener las clases de eventos
que los clientes utilizan en las solicitudes XSelectExtensionEvent. Las
macros definidas actualmente incluyen DeviceKeyPress, DeviceKeyRelease,
DeviceButtonPress, DeviceButtonRelease, DeviceMotionNotify,
DeviceFocusIn, DeviceFocusOut, ProximityIn, ProximityOut,
DeviceStateNotify, DeviceMappingNotify, ChangeDeviceNotify,
DevicePointerMotionHint, DeviceButton1Motion,
DeviceButton2Motion, DeviceButton3Motion, DeviceButton4Motion,
DeviceButton5Motion, DeviceButtonMotion, DeviceOwnerGrabButton,
DeviceButtonPressGrab y NoExtensionEvent.
Para obtener la clase de evento adecuada para un dispositivo particular,
se invoca una de las macros anteriores utilizando la estructura XDevice
para ese dispositivo. Por ejemplo,
             DeviceKeyPress (*device, type, eventclass);
devuelve el tipo de evento DeviceKeyPress y la clase de evento para
seleccionar eventos DeviceKeyPress de este dispositivo.
XSelectExtensionEvent puede generar un error BadWindow o BadClass.
La solicitud XGetSelectedExtensionEvents informa los eventos de extensión
seleccionados por este cliente y por todos los clientes para la ventana
especificada. Esta solicitud devuelve punteros a dos matrices XEventClass.
Una enumera los eventos de extensión de entrada seleccionados por este
cliente de la ventana especificada. La otra enumera las clases de eventos
seleccionadas por todos los clientes de la ventana especificada. Debes usar
XFree para liberar estas dos matrices.
XGetSelectedExtensionEvents puede generar un error BadWindow.

DIAGNÓSTICOS

BadWindow
       Un valor para un argumento Window no nombra una ventana definida.
BadClass
       Un valor para una XEventClass es inválido.
