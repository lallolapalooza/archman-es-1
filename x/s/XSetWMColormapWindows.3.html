XSetWMColormapWindows(3)

Paquete: libx11

Licencias: MIT AND X11

XSetWMColormapWindows(3) FUNCIONES XLIB XSetWMColormapWindows(3)

NOMBRE

XSetWMColormapWindows, XGetWMColormapWindows - establecer o leer la propiedad WM_COLORMAP_WINDOWS de una ventana

SINTAXIS

Status XSetWMColormapWindows(Display *display, Window w, Window *colormap_windows, int count);

Status XGetWMColormapWindows(Display *display, Window w, Window **colormap_windows_return, int *count_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
colormap_windows
Especifica la lista de ventanas.
colormap_windows_return
Devuelve la lista de ventanas.
count
Especifica el número de ventanas en la lista.
count_return
Devuelve el número de ventanas en la lista.
w
Especifica la ventana.

DESCRIPCIÓN

La función XSetWMColormapWindows reemplaza la propiedad WM_COLORMAP_WINDOWS en la ventana especificada con la lista de ventanas especificada por el argumento colormap_windows. Si la propiedad no existe aún, XSetWMColormapWindows establece la propiedad WM_COLORMAP_WINDOWS en la ventana especificada a la lista de ventanas especificada por el argumento colormap_windows. La propiedad se almacena con un tipo de WINDOW y un formato de 32. Si no puede internar el átomo WM_COLORMAP_WINDOWS, XSetWMColormapWindows devuelve un estado cero. De lo contrario, devuelve un estado distinto de cero.

XSetWMColormapWindows puede generar errores BadAlloc y BadWindow.

La función XGetWMColormapWindows devuelve la lista de identificadores de ventana almacenados en la propiedad WM_COLORMAP_WINDOWS en la ventana especificada. Estos identificadores indican los mapas de color que el gestor de ventanas podría necesitar instalar para esta ventana. Si la propiedad existe, es de tipo WINDOW, es de formato 32, y el átomo WM_COLORMAP_WINDOWS puede ser internado, XGetWMColormapWindows establece el argumento windows_return a una lista de identificadores de ventana, establece el argumento count_return al número de elementos en la lista y devuelve un estado distinto de cero. De lo contrario, no establece ninguno de los argumentos de retorno y devuelve un estado cero. Para liberar la lista de identificadores de ventana, usa XFree.

XGetWMColormapWindows puede generar un error BadWindow.

PROPIEDADES

WM_COLORMAP_WINDOWS
La lista de IDs de ventana que pueden necesitar un mapa de color diferente al de su ventana de nivel superior.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
