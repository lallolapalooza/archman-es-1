XSynchronize(3) FUNCIONES DE XLIB XSynchronize(3)

NOMBRE

XSynchronize, XSetAfterFunction - habilita o deshabilita la sincronización

SINTAXIS

int (*XSynchronize(Display *display, Bool onoff))();

int (*XSetAfterFunction(Display *display, int (*procedure)()))();

ARGUMENTOS

display
Especifica la conexión con el servidor X.
procedure
Especifica el procedimiento a llamar.
onoff
Especifica un valor booleano que indica si se debe habilitar o deshabilitar la sincronización.

DESCRIPCIÓN

La función XSynchronize devuelve la función anterior. Si onoff es True, XSynchronize activa el comportamiento síncrono. Si onoff es False, XSynchronize desactiva el comportamiento síncrono.

El procedimiento especificado se llama solo con un puntero de visualización. XSetAfterFunction devuelve la función anterior.
