XSetWMClientMachine(3) FUNCIONES XLIB XSetWMClientMachine(3)

NOMBRE

XSetWMClientMachine, XGetWMClientMachine - establecer o leer la propiedad WM_CLIENT_MACHINE de una ventana

SINTAXIS

void XSetWMClientMachine(Display *display, Window w, XTextProperty *text_prop);

Status XGetWMClientMachine(Display *display, Window w, XTextProperty *text_prop_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
text_prop
Especifica la estructura XTextProperty a utilizar.
text_prop_return
Devuelve la estructura XTextProperty.
w
Especifica la ventana.

DESCRIPCIÓN

La función de conveniencia XSetWMClientMachine llama a XSetTextProperty para establecer la propiedad WM_CLIENT_MACHINE.

La función de conveniencia XGetWMClientMachine realiza una XGetTextProperty en la propiedad WM_CLIENT_MACHINE. Devuelve un estado distinto de cero si tiene éxito; de lo contrario, devuelve un estado cero.

PROPIEDADES

WM_CLIENT_MACHINE
El nombre de cadena de la máquina en la que se está ejecutando la aplicación cliente.
