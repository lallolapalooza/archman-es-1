XSetDashes(3)

Paquete: libx11

Licencias: MIT AND X11

XSetLineAttributes(3) FUNCIONES DE XLIB XSetLineAttributes(3)

NOMBRE

XSetLineAttributes, XSetDashes - rutinas de conveniencia de GC

SINTAXIS

int XSetLineAttributes(Display *display, GC gc, unsigned int line_width, int line_style, int cap_style, int join_style);

int XSetDashes(Display *display, GC gc, int dash_offset, _Xconst char dash_list[], int n);

ARGUMENTOS

cap_style
Especifica el estilo de línea y el estilo de terminación que desea establecer para la GC especificada. Puede pasar CapNotLast, CapButt, CapRound o CapProjecting.
dash_list
Especifica la lista de guiones para el estilo de línea con guiones que desea establecer para la GC especificada.
dash_offset
Especifica la fase del patrón para el estilo de línea con guiones que desea establecer para la GC especificada.
display
Especifica la conexión con el servidor X.
gc
Especifica la GC.
join_style
Especifica el estilo de unión de línea que desea establecer para la GC especificada. Puede pasar JoinMiter, JoinRound o JoinBevel.
line_style
Especifica el estilo de línea que desea establecer para la GC especificada. Puede pasar LineSolid, LineOnOffDash o LineDoubleDash.
line_width
Especifica el ancho de línea que desea establecer para la GC especificada.
n
Especifica el número de elementos en dash_list.

DESCRIPCIÓN

La función XSetLineAttributes establece los componentes de dibujo de línea en la GC especificada.

XSetLineAttributes puede generar errores BadAlloc, BadGC y BadValue.

La función XSetDashes establece los atributos dash-offset y dash-list para estilos de línea con guiones en la GC especificada. Debe haber al menos un elemento en la dash_list especificada, o se producirá un error BadValue. Los elementos iniciales y alternos (segundo, cuarto, etc.) de la dash_list son los guiones pares, y los otros son los guiones impares. Cada elemento especifica una longitud de guion en píxeles. Todos los elementos deben ser distintos de cero, o se producirá un error BadValue. Especificar una lista de longitud impar es equivalente a especificar la misma lista concatenada consigo misma para producir una lista de longitud par.

El dash-offset define la fase del patrón, especificando cuántos píxeles dentro de la lista de guiones debe comenzar realmente el patrón en cualquier solicitud gráfica individual. Los guiones son continuos a través de los elementos de la ruta combinados con un estilo de unión, pero se reinician al dash-offset entre cada secuencia de líneas unidas.

La unidad de medida para los guiones es la misma que para el sistema de coordenadas ordinario. Idealmente, la longitud de un guion se mide a lo largo de la pendiente de la línea, pero las implementaciones solo están obligadas a que coincida con este ideal para líneas horizontales y verticales. A falta de la semántica ideal, se sugiere que la longitud se mida a lo largo del eje principal de la línea. El eje principal se define como el eje x para las líneas dibujadas en un ángulo de entre -45 y +45 grados o entre 135 y 225 grados con respecto al eje x. Para todas las demás líneas, el eje principal es el eje y.

XSetDashes puede generar errores BadAlloc, BadGC y BadValue.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
