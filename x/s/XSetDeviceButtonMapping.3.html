XSetDeviceButtonMapping(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XSETDEVICEBUTTONMAPP(3)   XSETDEVICEBUTTONMAPP(3)

NOMBRE

XSetDeviceButtonMapping, XGetDeviceButtonMapping - consultar o cambiar los mapeos de botones del dispositivo

SINOPSIS

#include <X11/extensions/XInput.h>
int XSetDeviceButtonMapping( Display *display,
                             XDevice *device,
                             unsigned char map[],
                             int nmap);
int XGetDeviceButtonMapping( Display *display,
                             XDevice *device,
                             unsigned char map_return[],
                             int nmap);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo cuyo mapeo de botones se va a
       consultar o cambiar.
map
       Especifica la lista de mapeo.
map_return
       Devuelve la lista de mapeo.
nmap
       Especifica el número de elementos en la lista de mapeo.

DESCRIPCIÓN

La solicitud XSetDeviceButtonMapping establece el mapeo del
dispositivo especificado. Si tiene éxito, el servidor X genera un
evento DeviceMappingNotify y XSetDeviceButtonMapping devuelve
MappingSuccess. El elemento map[i] define el número de botón
lógico para el botón físico i+1. La longitud de la lista debe ser
la misma que devolvería XGetDeviceButtonMapping, o se producirá
un error BadValue. Un elemento cero deshabilita un botón, y los
elementos no están restringidos en valor por el número de
botones físicos. Sin embargo, no puede haber dos elementos con
el mismo valor distinto de cero, o se producirá un error
BadValue. Si alguno de los botones que se van a modificar está
lógicamente en estado presionado,
XSetDeviceButtonMapping devuelve MappingBusy y el mapeo no se
cambia.
XSetDeviceButtonMapping puede generar errores BadDevice,
BadMatch y BadValue.
La solicitud XGetDeviceButtonMapping devuelve el mapeo actual
del dispositivo especificado. Los botones se numeran a partir
de uno. XGetDeviceButtonMapping devuelve el número de botones
físicos realmente presentes en el dispositivo. El mapeo nominal
para un dispositivo es map[i]=i+1. El argumento nmap especifica
la longitud del array donde se devuelve el mapeo del
dispositivo, y solo se devuelven los primeros nmap elementos en
map_return.
XGetDeviceButtonMapping puede generar errores BadDevice o
BadMatch.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo
       especificado no existe o no ha sido abierto por este
       cliente a través de XOpenInputDevice. Este error también
       puede ocurrir si el dispositivo especificado es el teclado
       X o el dispositivo puntero X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud
       XGetDeviceButtonMapping o XSetDeviceButtonMapping
       especificando un dispositivo que no tiene botones.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un
       rango específico para un argumento, se acepta el rango
       completo definido por el tipo del argumento. Cualquier
       argumento definido como un conjunto de alternativas puede
       generar este error.
