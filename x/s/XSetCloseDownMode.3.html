XSetCloseDownMode(3)

Paquete: libx11

Licencias: MIT AND X11

XSetCloseDownMode(3) FUNCIONES DE XLIB XSetCloseDownMode(3)

NOMBRE

XSetCloseDownMode, XKillClient - controlar clientes

SINTAXIS

int XSetCloseDownMode(Display *display, int close_mode);

int XKillClient(Display *display, XID resource);

ARGUMENTOS

close_mode
Especifica el modo de cierre de cliente. Puede pasar DestroyAll, RetainPermanent o RetainTemporary.
display
Especifica la conexión con el servidor X.
resource
Especifica cualquier recurso asociado con el cliente que desee destruir o AllTemporary.

DESCRIPCIÓN

XSetCloseDownMode define qué sucederá con los recursos del cliente al cerrar la conexión. Una conexión comienza en modo DestroyAll. Para obtener información sobre lo que sucede con los recursos del cliente cuando el argumento close_mode es RetainPermanent o RetainTemporary, consulte la sección 2.6.

XSetCloseDownMode puede generar un error BadValue.

La función XKillClient fuerza el cierre del cliente que creó el recurso si se especifica un recurso válido. Si el cliente ya ha terminado en modo RetainPermanent o RetainTemporary, todos los recursos del cliente se destruyen. Si se especifica AllTemporary, los recursos de todos los clientes que han terminado en RetainTemporary se destruyen (consulte la sección 2.5). Esto permite la implementación de instalaciones del administrador de ventanas que ayudan a la depuración. Un cliente puede establecer su modo de cierre en RetainTemporary. Si el cliente falla entonces, sus ventanas no se destruirían. El programador puede entonces inspeccionar el árbol de ventanas de la aplicación y utilizar el administrador de ventanas para destruir las ventanas zombis.

XKillClient puede generar un error BadValue.

DIAGNÓSTICO

BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
