XChangeKeyboardMapping(3) FUNCIONES DE XLIB XChangeKeyboardMapping(3)

NOMBRE

XChangeKeyboardMapping, XGetKeyboardMapping, XDisplayKeycodes, XSetModifierMapping, XGetModifierMapping, XNewModifiermap, XInsertModifiermapEntry, XDeleteModifiermapEntry, XFreeModifiermap, XModifierKeymap - manipular la codificación del teclado y la estructura de codificación del teclado

SINTAXIS

int XChangeKeyboardMapping(Display *display, KeyCode first_keycode, int keysyms_per_keycode, KeySym *keysyms, int num_codes);

KeySym *XGetKeyboardMapping(Display *display, KeyCode first_keycode, int keycode_count, int *keysyms_per_keycode_return);

int XDisplayKeycodes(Display *display, int *min_keycodes_return, int *max_keycodes_return);

int XSetModifierMapping(Display *display, XModifierKeymap *modmap);

XModifierKeymap *XGetModifierMapping(Display *display);

XModifierKeymap *XNewModifiermap(int max_keys_per_mod);

XModifierKeymap *XInsertModifiermapEntry(XModifierKeymap *modmap, KeyCode keycode_entry, int modifier);

XModifierKeymap *XDeleteModifiermapEntry(XModifierKeymap *modmap, KeyCode keycode_entry, int modifier);

int XFreeModifiermap(XModifierKeymap *modmap);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
first_keycode
Especifica el primer KeyCode que se va a cambiar o devolver.
keycode_count
Especifica el número de KeyCodes que se van a devolver.
keycode_entry
Especifica el KeyCode.
keysyms
Especifica una matriz de KeySyms.
keysyms_per_keycode
Especifica el número de KeySyms por KeyCode.
keysyms_per_keycode_return
Devuelve el número de KeySyms por KeyCode.
max_keys_per_mod
Especifica el número de entradas de KeyCode preasignadas a los modificadores en el mapa.
max_keycodes_return
Devuelve el número máximo de KeyCodes.
min_keycodes_return
Devuelve el número mínimo de KeyCodes.
modifier
Especifica el modificador.
modmap
Especifica la estructura XModifierKeymap.
num_codes
Especifica el número de KeyCodes que se van a cambiar.

DESCRIPCIÓN

La función XChangeKeyboardMapping define los símbolos para el número especificado de KeyCodes comenzando con first_keycode. Los símbolos para KeyCodes fuera de este rango permanecen sin cambios. El número de elementos en keysyms debe ser:

num_codes * keysyms_per_keycode

El first_keycode especificado debe ser mayor o igual que min_keycode devuelto por XDisplayKeycodes, o se produce un error BadValue. Además, la siguiente expresión debe ser menor o igual que max_keycode devuelto por XDisplayKeycodes, o se produce un error BadValue:

first_keycode + num_codes - 1

El símbolo N (contando desde cero) para el KeyCode K tiene el siguiente índice en keysyms (contando desde cero):

(K - first_keycode) * keysyms_per_keycode + N

El keysyms_per_keycode especificado puede ser elegido arbitrariamente por el cliente para que sea lo suficientemente grande como para contener todos los símbolos deseados. Se debe usar un valor de KeySym especial de NoSymbol para rellenar los elementos no utilizados para KeyCodes individuales. Es legal que NoSymbol aparezca en posiciones no finales de la lista efectiva para un KeyCode. XChangeKeyboardMapping genera un evento MappingNotify.

No hay ningún requisito de que el servidor X interprete este mapeo. Simplemente se almacena para que los clientes lo lean y escriban.

XChangeKeyboardMapping puede generar errores BadAlloc y BadValue.

La función XGetKeyboardMapping devuelve los símbolos para el número especificado de KeyCodes comenzando con first_keycode. El valor especificado en first_keycode debe ser mayor o igual que min_keycode tal como lo devuelve XDisplayKeycodes, o se producirá un error BadValue. Además, la siguiente expresión debe ser menor o igual que max_keycode tal como lo devuelve XDisplayKeycodes:

first_keycode + keycode_count - 1

Si esto no es así, se producirá un error BadValue. El número de elementos en la lista KeySyms es:

keycode_count * keysyms_per_keycode_return

El símbolo N (contando desde cero) para el KeyCode K tiene el siguiente índice en la lista (contando desde cero):

(K - first_code) * keysyms_per_code_return + N

El servidor X elige arbitrariamente que el valor keysyms_per_keycode_return sea lo suficientemente grande como para informar todos los símbolos solicitados. Se utiliza un valor especial de KeySym NoSymbol para rellenar los elementos no utilizados para KeyCodes individuales. Para liberar el almacenamiento devuelto por XGetKeyboardMapping, use XFree.

XGetKeyboardMapping puede generar un error BadValue.

La función XDisplayKeycodes devuelve los min-keycodes y max-keycodes admitidos por la pantalla especificada. El número mínimo de KeyCodes devueltos nunca es inferior a 8, y el número máximo de KeyCodes devueltos nunca es superior a 255. No se requiere que todos los KeyCodes en este rango tengan teclas correspondientes.

La función XSetModifierMapping especifica los KeyCodes de las teclas (si las hay) que se utilizarán como modificadores. Si tiene éxito, el servidor X genera un evento MappingNotify y XSetModifierMapping devuelve MappingSuccess. X permite como máximo 8 teclas modificadoras. Si se especifican más de 8 en la estructura XModifierKeymap, se produce un error BadLength.

El miembro modifiermap de la estructura XModifierKeymap contiene 8 conjuntos de KeyCodes max_keypermod, uno para cada modificador en el orden Shift, Lock, Control, Mod1, Mod2, Mod3, Mod4 y Mod5. Solo los KeyCodes distintos de cero tienen significado en cada conjunto, y los KeyCodes cero se ignoran. Además, todos los KeyCodes distintos de cero deben estar en el rango especificado por min_keycode y max_keycode en la estructura Display, o se producirá un error BadValue.

Un servidor X puede imponer restricciones sobre cómo se pueden cambiar los modificadores, por ejemplo, si ciertas teclas no generan transiciones de subida en hardware, si la repetición automática no se puede desactivar en ciertas teclas, o si no se admiten múltiples teclas modificadoras. Si se viola alguna de estas restricciones, la respuesta de estado es MappingFailed y ninguno de los modificadores se cambia. Si los nuevos KeyCodes especificados para un modificador difieren de los actualmente definidos y alguna tecla (actual o nueva) para ese modificador está en el estado lógicamente presionado, XSetModifierMapping devuelve MappingBusy y ninguno de los modificadores se cambia.

XSetModifierMapping puede generar errores BadAlloc y BadValue.

La función XGetModifierMapping devuelve un puntero a una estructura XModifierKeymap recién creada que contiene las teclas que se utilizan como modificadores. La estructura debe liberarse después de su uso llamando a XFreeModifiermap. Si solo aparecen valores cero en el conjunto de algún modificador, ese modificador se deshabilita.

La función XNewModifiermap devuelve un puntero a una estructura XModifierKeymap para uso posterior.

La función XInsertModifiermapEntry agrega el KeyCode especificado al conjunto que controla el modificador especificado y devuelve la estructura XModifierKeymap resultante (ampliada según sea necesario).

La función XDeleteModifiermapEntry elimina el KeyCode especificado del conjunto que controla el modificador especificado y devuelve un puntero a la estructura XModifierKeymap resultante.

La función XFreeModifiermap

NAME

XSetModifierMapping, XGetModifierMapping, XFreeModifiermap - establecer o recuperar el mapeo de modificadores del teclado

SYNOPSIS 

#include <X11/Xlib.h>

XModifierMapping *XSetModifierMapping(Display *display, XModifierMapping *modmap);
XModifierMapping *XGetModifierMapping(Display *display);
int XFreeModifiermap(XModifierMapping *modmap);

ARGUMENTS

display
Especifica la conexión con el servidor X.
modmap
Especifica el mapa de modificadores a establecer. Puede ser NULL.

DESCRIPTION

La función XSetModifierMapping establece el mapeo de modificadores del teclado para el servidor X especificado. Los mapas de modificadores definen qué teclas del teclado se deben tratar como modificadores (por ejemplo, Shift, Control, Alt, Super).

Cuando se llama a XSetModifierMapping, el servidor X valida el mapa de modificadores proporcionado.

  • Cada modificador (Shift, Lock, Control, Mod1 a Mod5) puede estar asociado con una o más teclas.
  • Debe haber exactamente un conjunto de teclas para el modificador Shift.
  • Debe haber exactamente un conjunto de teclas para el modificador Caps Lock.
  • Debe haber exactamente un conjunto de teclas para el modificador Control.
  • Los modificadores Mod1 a Mod5 pueden estar asociados con cero o más teclas.
  • Las teclas especificadas deben ser teclas de modificador válidas o deben ser teclas normales y no modificadores.
  • No se pueden usar las mismas teclas para diferentes modificadores.

Si el mapa de modificadores es válido, XSetModifierMapping lo establece y devuelve el mapa de modificadores anterior. Si el mapa de modificadores no es válido, XSetModifierMapping devuelve NULL.

La función XGetModifierMapping recupera el mapa de modificadores actual del servidor X especificado. Devuelve un puntero a una estructura XModifierMapping que contiene el mapa. El cliente es responsable de liberar esta estructura cuando ya no sea necesaria.

La función XFreeModifiermap libera la memoria asignada a la estructura XModifierKeymap especificada.

STRUCTURES

La estructura XModifierKeymap contiene:

typedef struct {
        int max_keypermod;      /* This server's max number of keys per modifier */
        KeyCode *modifiermap;   /* An 8 by max_keypermod array of the modifiers */
} XModifierKeymap;

DIAGNOSTICS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
