XSETDEVICEMODE(3)   XSETDEVICEMODE(3)

NOMBRE

XSetDeviceMode - cambia el modo de un dispositivo

SINOPSIS

#include <X11/extensions/XInput.h>
XSetDeviceMode( Display *display,
                XDevice *device,
                int mode);
display
       Especifica la conexión al servidor X.
device
       Especifica el dispositivo cuyo modo se va a cambiar.
mode
       Especifica el modo. Puede pasar Absolute o Relative.

DESCRIPCIÓN

La solicitud XSetDeviceMode cambia el modo de un dispositivo de entrada
que es capaz de informar información posicional absoluta o información de
movimiento relativo. No todos los dispositivos de entrada son capaces de
informar datos de movimiento, y no todos son capaces de cambiar los modos
de Absoluto a Relativo.
XSetDeviceMode puede generar un error BadDevice o BadMode.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si algún otro
       cliente ha provocado que el dispositivo especificado se convierta
       en el dispositivo de teclado X o puntero X a través de las
       solicitudes XChangeKeyboardDevice o XChangePointerDevice.
BadMatch
       Este error puede ocurrir si se realiza una solicitud XSetDeviceMode
       especificando un dispositivo que no tiene valores y no informa
       ningún eje de movimiento.
BadMode
       Se especificó un modo inválido. Este error también se devolverá si
       el dispositivo especificado no es capaz de soportar la solicitud
       XSetDeviceMode.
