NAME

XScreenSaver - Librería cliente de extensión del salvapantallas de X11

SYNOPSIS

#include <X11/extensions/scrnsaver.h>

typedef struct {
    Window window;                /* ventana del salvapantallas */
    int state;                    /* ScreenSaver{Off,On,Disabled} */
    int kind;                     /* ScreenSaver{Blanked,Internal,External} */
    unsigned long til_or_since;   /* milisegundos */
    unsigned long idle;           /* milisegundos */
    unsigned long eventMask;      /* eventos */
} XScreenSaverInfo;

typedef struct {
    int type;               /* del evento */
    unsigned long serial;   /* # de la última petición procesada por el servidor */
    Bool send_event;        /* verdadero si esto vino de una petición SendEvent */
    Display *display;       /* Display del cual se leyó el evento */
    Window window;          /* ventana del salvapantallas */
    Window root;            /* ventana raíz de la pantalla del evento */
    int state;              /* ScreenSaver{Off,On,Cycle} */
    int kind;               /* ScreenSaver{Blanked,Internal,External} */
    Bool forced;            /* extensiones de la nueva región */
    Time time;              /* marca de tiempo del evento */
} XScreenSaverNotifyEvent;
Bool XScreenSaverQueryExtension(Display *dpy,
    int *event_base_return, int *error_base_return);
Status XScreenSaverQueryVersion(Display *dpy,
    int *major_version_return, int *minor_version_return);
XScreenSaverInfo *XScreenSaverAllocInfo(void);
Status XScreenSaverQueryInfo(Display *dpy, Drawable drawable,
    XScreenSaverInfo *saver_info);
void XScreenSaverSelectInput(Display *dpy, Drawable drawable,
    unsigned long mask);
void XScreenSaverSetAttributes(Display *dpy, Drawable drawable,
    int x, int y, unsigned int width, unsigned int height,
    unsigned int border_width, int depth, unsigned int class,
    Visual *visual, unsigned long valuemask,
    XSetWindowAttributes *attributes);
void XScreenSaverUnsetAttributes(Display *dpy, Drawable drawable);
void XScreenSaverRegister(Display *dpy, int screen, XID xid, Atom type);
Status XScreenSaverUnregister(Display *dpy, int screen);
Status XScreenSaverGetRegistered(Display *dpy, int screen,
    XID *xid, Atom *type);
void XScreenSaverSuspend(Display *dpy, Bool suspend);

DESCRIPTION

El sistema de ventanas X proporciona soporte para cambiar la imagen en la pantalla después de un período de inactividad configurable por el usuario para evitar quemar los fósforos del tubo de rayos catódicos. Sin embargo, no se proporcionan interfaces para que el usuario controle la imagen que se dibuja. Esta extensión permite a un cliente externo de ``salvapantallas'' detectar cuándo se va a mostrar la imagen alternativa y proporcionar los gráficos.

Las implementaciones actuales del servidor X típicamente proporcionan al menos una forma de imagen de ``salvapantallas''. Históricamente, esto ha sido una copia del logo de X dibujada contra el patrón de fondo de la raíz. Sin embargo, muchos usuarios han solicitado un mecanismo que les permita escribir programas de salvapantallas que proporcionen capacidades similares a las ofrecidas por otros sistemas de ventanas. En particular, tales usuarios a menudo desean poder mostrar logotipos corporativos, instrucciones sobre cómo reactivar la pantalla y utilidades de bloqueo automático de pantalla. Esta extensión proporciona un medio para escribir dichos clientes.

Supuestos

Esta extensión exporta la noción de una ventana especial de salvapantallas que se mapea sobre todas las demás ventanas en una pantalla. Esta ventana tiene el atributo override-redirect establecido para que no esté sujeta a manipulación por el gestor de ventanas. Además, el identificador X de la ventana nunca se devuelve mediante peticiones QueryTree en la ventana raíz, por lo que típicamente no es visible para otros clientes.

XScreenSaverQueryExtension devuelve True si la extensión XScreenSaver está disponible en la pantalla dada. Un cliente debe llamar a XScreenSaverQueryExtension antes de llamar a cualquier otra función de XScreenSaver para negociar una versión de protocolo compatible; de lo contrario, el cliente obtendrá un comportamiento indefinido (XScreenSaver puede o no funcionar).

Si la extensión es compatible, el número de evento para los eventos ScreenSaverNotify se devuelve en el valor apuntado por event_base. Dado que esta extensión no define errores adicionales, los resultados de error_base no están definidos.

XScreenSaverQueryVersion devuelve True si la petición tuvo éxito; los valores de las versiones de protocolo mayor y menor compatibles con el servidor se devuelven en major_version_return y minor_version_return.

XScreenSaverAllocInfo asigna y devuelve una estructura XScreenSaverInfo para usar en llamadas a XScreenSaverQueryInfo. Todos los campos de la estructura se inicializan a cero. Si no hay suficiente memoria disponible, se devuelve NULL. Los resultados de esta rutina se pueden liberar usando XFree.

XScreenSaverQueryInfo devuelve información sobre el estado actual del servidor de pantalla en saver_info y se devuelve un valor distinto de cero. Si la extensión no es compatible, saver_info no se modifica y se devuelve 0.

El campo state especifica si el salvapantallas está actualmente activo o no y cómo debe interpretarse el valor til-or-since:

Off
La pantalla no se está salvando actualmente; til-or-since especifica el número de milisegundos hasta que se espera que se active el salvapantallas.
On
La pantalla se está salvando actualmente; til-or-since especifica el número de milisegundos desde que se activó el salvapantallas.
Disabled
El salvapantallas está actualmente deshabilitado; til-or-since es cero.

El campo kind especifica el mecanismo que se está utilizando actualmente o que se habría utilizado si la pantalla se estuviera salvando:

Blanked
La señal de video al monitor de pantalla se deshabilitó.
Internal
Se mostró una imagen de salvapantallas integrada, dependiente del servidor; o bien ningún cliente había configurado los atributos de la ventana del salvapantallas o bien otro cliente tenía el servidor capturado cuando se activó el salvapantallas.
External
La ventana del salvapantallas se mapeó con atributos configurados por un cliente usando la petición ScreenSaverSetAttributes.

El campo idle especifica el número de milisegundos desde la última entrada recibida del usuario en cualquiera de los dispositivos de entrada.
El campo event-mask especifica cuáles, si los hay, eventos del salvapantallas ha solicitado este cliente usando ScreenSaverSelectInput.

XScreenSaverSelectInput solicita que se generen eventos relacionados con el salvapantallas para este cliente. Si no hay bits establecidos en event-mask, no se generarán eventos. De lo contrario, se puede establecer cualquier combinación de los siguientes bits:

ScreenSaverNotify
Si este bit está establecido, se generan eventos ScreenSaverNotify siempre que el salvapantallas se active o desactive.
ScreenSaverCycle
Si este bit está establecido, se generan eventos ScreenSaverNotify cada vez que pasa el intervalo de ciclo del salvapantallas.

XScreenSaverSetAttributes establece los atributos que se utilizarán la próxima vez que se active el salvapantallas externo. Si otro cliente tiene actualmente los atributos establecidos, se genera un error BadAccess y se ignora la petición.
De lo contrario, se comprueban los atributos de la ventana como si se hubieran utilizado en una petición CreateWindow principal cuyo padre es la raíz. El campo override-redirect se ignora ya que se establece implícitamente en True. Si los atributos de la ventana resultan en un error de acuerdo con las reglas para CreateWindow, se ignora la petición.
De lo contrario, se almacenan los atributos y entrarán en vigor en la próxima activación que ocurra cuando el servidor no esté capturado por otro cliente. Cualquier recurso especificado para los atributos background-pixmap o cursor puede liberarse inmediatamente.

NAME

XScreenSaverQueryVersion — query the screen saver extension version

SYNOPSIS

#include <X11/Xlib.h>
#include <X11/extensions/scrnsaver.h>

Bool XScreenSaverQueryVersion(
    Display *dpy,
    int *major_version_return,
    int *minor_version_return
);

DESCRIPTION

The screen saver extension provides a mechanism for implementing screen savers. The screen saver extension is described in the file extensions/scrnsaver.h.

XScreenSaverQueryVersion returns the version of the screen saver extension implemented by the server.

It returns True if the screen saver extension is supported by the server, and fills in major_version_return and minor_version_return with the version numbers. It returns False if the screen saver extension is not supported by the server.

The screen saver extension provides the following functions:

XScreenSaverAllocInfo allocates memory for a XScreenSaverInfo structure and returns a pointer to it. The structure will be filled in by XScreenSaverQueryInfo.

XScreenSaverQueryInfo fills in the specified XScreenSaverInfo structure with information about the current screen saver settings for the specified screen.

XScreenSaverSetAttributes is used to set the attributes for the screen saver window. The screen saver server may choose to copy the resources or use them in place. Thus the effect of changing the contents of the background-pixmap or cursor resources is undefined. If the specified colormap no longer exists when the screen saver activates, the parent's colormap is used instead. If no errors are generated by this request, any previous screen saver window attributes set by this client are released.

When the screen saver next activates and the server is not grabbed by another client, the screen saver window is created, if necessary, and set to the specified attributes and events are generated as usual. The colormap associated with the screen saver window is installed. Finally, the screen saver window is mapped.

The window remains mapped and at the top of the stacking order until the screen saver is deactivated in response to activity on any of the user input devices, a ForceScreenSaver request with a value of Reset, or any request that would cause the window to be unmapped.

If the screen saver activates while the server is grabbed by another client, the internal saver mechanism is used. The ForceScreenSaver request may be used with a value of Active to deactivate the internal saver and activate the external saver.

If the screen saver client's connection to the server is broken while the screen saver is activated and the client's close down mode has not been RetainPermanent or RetainTemporary, the current screen saver is deactivated and the internal screen saver is immediately activated.

When the screen saver deactivates, the screen saver window's colormap is uninstalled and the window is unmapped (except as described below). The screen saver XID is disassociated with the window and the server may, but is not required to, destroy the window along with any children.

When the screen saver is being deactivated and then immediately reactivated (such as when switching screen savers), the server may leave the screen saver window mapped (typically to avoid generating exposures).

XScreenSaverUnsetAttributes instructs the server to discard any previous screen saver window attributes set by this client.

XScreenSaverRegister stores the given XID in the _SCREEN_SAVER_ID property (of the given type) on the root window of the specified screen. It returns zero if an error is encountered and the property is not changed, otherwise it returns non-zero.

XScreenSaverUnregister removes any _SCREEN_SAVER_ID from the root window of the specified screen. It returns zero if an error is encountered and the property is changed, otherwise it returns non-zero.

XScreenSaverGetRegistered returns the XID and type stored in the _SCREEN_SAVER_ID property on the root window of the specified screen. It returns zero if an error is encountered or if the property does not exist or is not of the correct format; otherwise it returns non-zero.

XScreenSaverSuspend temporarily suspends the screensaver and DPMS timer if suspend is 'True', and restarts the timer if suspend is 'False'.
This function should be used by applications that don't want the screensaver or DPMS to become activated while they're for example in the process of playing a media sequence, or are otherwise continuously presenting visual information to the user while in a non-interactive state. This function is not intended to be called by an external screensaver application.
If XScreenSaverSuspend is called multiple times with suspend set to 'True', it must be called an equal number of times with suspend set to 'False' in order for the screensaver timer to be restarted. This request has no affect if a client tries to resume the screensaver without first having suspended it. XScreenSaverSuspend can thus not be used by one client to resume the screensaver if it's been suspended by another client.
If a client that has suspended the screensaver becomes disconnected from the X server, the screensaver timer will automatically be restarted, unless it's still suspended by another client. Suspending the screensaver timer doesn't prevent the screensaver from being forcibly activated with the ForceScreenSaver request, or a DPMS mode from being set with the DPMSForceLevel request.
XScreenSaverSuspend also doesn't deactivate the screensaver or DPMS if either is active at the time the request to suspend them is received by the X server. But once they've been deactivated, they won't automatically be activated again, until the client has canceled the suspension.

ERRORS

XScreenSaverSelectInput, XScreenSaverQueryInfo, XScreenSaverSetAttributes, and XScreenSaverUnsetAttributes will generate a BadDrawable error if drawable is not a valid drawable identifier. If any undefined bits are set in event-mask, a BadValue error is generated by XScreenSaverSelectInput.

AVAILABILITY

XScreenSaverSuspend is available in version 1.1 and later versions of the X Screen Saver Extension. Version 1.1 was first released with X11R7.1.
