XS::Parse::Infix::Builder(3pm) Documentación de Perl contribuida por el usuario XS::Parse::Infix::Builder(3pm)

NOMBRE

"XS::Parse::Infix::Builder" - soporte en tiempo de compilación para "XS::Parse::Infix"

SINOPSIS

En Build.PL:

use XS::Parse::Infix::Builder;
my $build = Module::Build->new(
   ...,
   configure_requires => {
      ...
      'XS::Parse::Infix::Builder' => 0,
   }
);
XS::Parse::Infix::Builder->extend_module_build( $build );
...

DESCRIPCIÓN

Este módulo proporciona una ayuda en tiempo de compilación para asistir a los autores de módulos XS que utilizan XS::Parse::Infix. Prepara una distribución basada en Module::Build para poder hacer uso de "XS::Parse::Infix".

FUNCIONES

write_XSParseInfix_h

XS::Parse::Infix::Builder->write_XSParseInfix_h;

Este método ya no realiza ninguna acción desde la versión 0.43.

extra_compiler_flags

@flags = XS::Parse::Infix::Builder->extra_compiler_flags;

Devuelve una lista de banderas adicionales que los scripts de compilación deben añadir a la invocación del compilador. Esto permite al compilador C encontrar el archivo XSParseInfix.h.

extend_module_build

XS::Parse::Infix::Builder->extend_module_build( $build );

Un atajo conveniente para realizar todas las tareas necesarias para que una distribución basada en Module::Build utilice la ayuda.
