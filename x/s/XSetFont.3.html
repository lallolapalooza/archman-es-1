XSetFont(3) FUNCIONES DE XLIB XSetFont(3)

NOMBRE

XSetFont - rutinas de conveniencia para GC

SINTAXIS

int XSetFont(Display *display, GC gc, Font font);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
font
Especifica la fuente.
gc
Especifica el GC.

DESCRIPCIÓN

La función XSetFont establece la fuente actual en el GC especificado.

XSetFont puede generar errores BadAlloc, BadFont y BadGC.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadFont
Un valor para un argumento de Font o GContext no nombra una Font definida.
BadGC
Un valor para un argumento de GContext no nombra un GContext definido.
