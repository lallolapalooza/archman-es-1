XSetState(3)

Paquete: libx11

Licencias: MIT AND X11

XSetState(3) FUNCIONES DE XLIB XSetState(3)

NOMBRE

XSetState, XSetFunction, XSetPlaneMask, XSetForeground, XSetBackground - rutinas de conveniencia de GC

SINTAXIS

int XSetState(Display *display, GC gc, unsigned long foreground, unsigned long background, int function, unsigned long plane_mask);

int XSetFunction(Display *display, GC gc, int function);

int XSetPlaneMask(Display *display, GC gc, unsigned long plane_mask);

int XSetForeground(Display *display, GC gc, unsigned long foreground);

int XSetBackground(Display *display, GC gc, unsigned long background);

ARGUMENTOS

background
Especifica el fondo que desea establecer para el GC especificado.
display
Especifica la conexión con el servidor X.
foreground
Especifica el primer plano que desea establecer para el GC especificado.
function
Especifica la función que desea establecer para el GC especificado.
gc
Especifica el GC.
plane_mask
Especifica la máscara de planos.

DESCRIPCIÓN

La función XSetState establece los componentes de primer plano, fondo, máscara de planos y función para el GC especificado.

XSetState puede generar errores BadAlloc, BadGC y BadValue.

XSetFunction establece un valor especificado en el GC especificado.

XSetFunction puede generar errores BadAlloc, BadGC y BadValue.

La función XSetPlaneMask establece la máscara de planos en el GC especificado.

XSetPlaneMask puede generar errores BadAlloc y BadGC.

La función XSetForeground establece el primer plano en el GC especificado.

XSetForeground puede generar errores BadAlloc y BadGC.

La función XSetBackground establece el fondo en el GC especificado.

XSetBackground puede generar errores BadAlloc y BadGC.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta todo el rango definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
