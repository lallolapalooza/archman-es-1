XSetWindowBorderWidth(3)

Paquete: libx11

Licencias: MIT AND X11

XConfigureWindow(3) FUNCIONES DE XLIB XConfigureWindow(3)

NOMBRE

XConfigureWindow, XMoveWindow, XResizeWindow, XMoveResizeWindow, XSetWindowBorderWidth, XWindowChanges - configurar ventanas y estructura de cambios de ventana

SINTAXIS

int XConfigureWindow(Display *display, Window w, unsigned value_mask, XWindowChanges *changes);

int XMoveWindow(Display *display, Window w, int x, y);

int XResizeWindow(Display *display, Window w, unsigned width, unsigned height);

int XMoveResizeWindow(Display *display, Window w, int x, int y, unsigned width, unsigned height);

int XSetWindowBorderWidth(Display *display, Window w, unsigned width);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
value_mask
Especifica qué valores se establecerán utilizando la información de la estructura de valores. Esta máscara es el OR inclusivo a nivel de bits de los bits de valores válidos para configurar la ventana.
values
Especifica la estructura XWindowChanges.
w
Especifica la ventana que se reconfigurará, moverá o redimensionará.
width
Especifica el ancho del borde de la ventana.
width

height
Especifican el ancho y el alto, que son las dimensiones interiores de la ventana.
x

y
Especifican las coordenadas x e y, que definen la nueva ubicación del píxel superior izquierdo del borde de la ventana o la ventana misma si no tiene borde, o definen la nueva posición de la ventana en relación con su padre.

DESCRIPCIÓN

La función XConfigureWindow utiliza los valores especificados en la estructura XWindowChanges para reconfigurar el tamaño, la posición, el borde y el orden de apilamiento de una ventana. Los valores no especificados se toman de la geometría existente de la ventana.

Si se especifica un hermano sin un modo de apilamiento (stack_mode) o si la ventana no es realmente un hermano, se produce un error BadMatch. Tenga en cuenta que los cálculos para BottomIf, TopIf y Opposite se realizan con respecto a la geometría final de la ventana (según lo controlado por los otros argumentos pasados a XConfigureWindow), no a su geometría inicial. Cualquier contenido de respaldo de la ventana, sus inferiores y otras ventanas recién visibles se descartan o se modifican para reflejar el contenido actual de la pantalla (dependiendo de la implementación).

XConfigureWindow puede generar errores BadMatch, BadValue y BadWindow.

La función XMoveWindow mueve la ventana especificada a las coordenadas x e y especificadas, pero no cambia el tamaño de la ventana, no la eleva ni cambia su estado de mapeo. Mover una ventana mapeada puede o no perder el contenido de la ventana dependiendo de si está oscurecida por elementos no hijos y si no existe un almacenamiento de respaldo. Si se pierden los contenidos de la ventana, el servidor X genera eventos Expose. Mover una ventana mapeada genera eventos Expose en cualquier ventana previamente oscurecida.

Si la bandera override-redirect de la ventana es False y algún otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún procesamiento adicional. De lo contrario, la ventana se mueve.

XMoveWindow puede generar un error BadWindow.

La función XResizeWindow cambia las dimensiones interiores de la ventana especificada, sin incluir sus bordes. Esta función no cambia la coordenada superior izquierda ni el origen de la ventana, ni la reorganiza. Cambiar el tamaño de una ventana mapeada puede perder su contenido y generar eventos Expose. Si una ventana mapeada se hace más pequeña, cambiar su tamaño genera eventos Expose en las ventanas que la ventana mapeada previamente oscurecía.

Si la bandera override-redirect de la ventana es False y algún otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún procesamiento adicional. Si el ancho o el alto son cero, se produce un error BadValue.

XResizeWindow puede generar errores BadValue y BadWindow.

La función XMoveResizeWindow cambia el tamaño y la ubicación de la ventana especificada sin elevarla. Mover y redimensionar una ventana mapeada puede generar un evento Expose en la ventana. Dependiendo de los nuevos parámetros de tamaño y ubicación, mover y redimensionar una ventana puede generar eventos Expose en las ventanas que la ventana previamente oscurecía.

Si la bandera override-redirect de la ventana es False y algún otro cliente ha seleccionado SubstructureRedirectMask en el padre, el servidor X genera un evento ConfigureRequest y no se realiza ningún procesamiento adicional. De lo contrario, se cambian el tamaño y la ubicación de la ventana.

XMoveResizeWindow puede generar errores BadValue y BadWindow.

La función XSetWindowBorderWidth establece el ancho del borde de la ventana especificada al ancho especificado.

XSetWindowBorderWidth puede generar un error BadWindow.

ESTRUCTURAS

La estructura XWindowChanges contiene:

// Bits de máscara de valor para configurar la ventana

#define CWX (1<<0)
#define CWY (1<<1)
#define CWWidth (1<<2)
#define CWHeight (1<<3)
#define CWBorderWidth (1<<4)
#define CWSibling (1<<5)
#define CWStackMode (1<<6) 
/* Valores */
typedef struct {
        int x, y;
        int width, height;
        int border_width;
        Window sibling;
        int stack_mode;
} XWindowChanges;

Los miembros x e y se utilizan para establecer las coordenadas x e y de la ventana, que son relativas al origen del padre e indican la posición de la esquina exterior superior izquierda de la ventana. Los miembros width y height se utilizan para establecer el tamaño interior de la ventana, sin incluir el borde, y deben ser distintos de cero, o se producirá un error BadValue. Los intentos de configurar una ventana raíz no tienen efecto.

El miembro border_width se utiliza para establecer el ancho del borde en píxeles. Tenga en cuenta que establecer solo el ancho del borde deja la esquina superior izquierda de la ventana en una posición fija pero mueve la posición absoluta del origen de la ventana. Si intenta establecer el atributo border_width de una ventana InputOnly como distinto de cero, se producirá un error BadMatch.

El miembro sibling se utiliza para establecer la ventana hermana para las operaciones de apilamiento. El miembro stack_mode se utiliza para establecer cómo se va a reorganizar la ventana y se puede establecer en Above, Below, TopIf, BottomIf u Opposite.

DIAGNÓSTICOS

BadMatch
Se utiliza una ventana InputOnly como Drawable.
BadMatch
Algún argumento o par de argumentos tiene el tipo y rango correctos pero falla de alguna otra manera requerida por la solicitud.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
