XSetFillRule(3)

Paquete: libx11

Licencias: MIT AND X11

XSetFillStyle(3) FUNCIONES DE XLIB XSetFillStyle(3)

NOMBRE

XSetFillStyle, XSetFillRule - Rutinas de conveniencia para GC

SINTAXIS

int XSetFillStyle(Display *display, GC gc, int fill_style);

int XSetFillRule(Display *display, GC gc, int fill_rule);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
fill_rule
Especifica la regla de relleno que desea establecer para la GC especificada. Puede pasar EvenOddRule o WindingRule.
fill_style
Especifica el estilo de relleno que desea establecer para la GC especificada. Puede pasar FillSolid, FillTiled, FillStippled o FillOpaqueStippled.
gc
Especifica la GC.

DESCRIPCIÓN

La función XSetFillStyle establece el estilo de relleno en la GC especificada.

XSetFillStyle puede generar errores BadAlloc, BadGC y BadValue.

La función XSetFillRule establece la regla de relleno en la GC especificada.

XSetFillRule puede generar errores BadAlloc, BadGC y BadValue.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o la memoria del servidor.
BadGC
Un valor para un argumento GContext no nombra un GContext definido.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
