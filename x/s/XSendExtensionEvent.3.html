NOMBRE

XSendExtensionEvent - envía eventos de extensión de entrada a un cliente

SINOPSIS

#include <X11/extensions/XInput.h>
Status XSendExtensionEvent( Display *display,
                            XDevice *device,
                            Window destination,
                            Bool propagate,
                            int event_count,
                            XEventClass *event_list,
                            XEvent *event_send);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo desde el cual se enviarán los eventos.
destination
       Especifica la ventana a la que se enviará el evento. Puedes
       pasar el ID de la ventana, PointerWindow o InputFocus.
propagate
       Especifica un valor booleano que es True o False.
event_count
       Especifica el número de XEventClass en event_list.
event_list
       Especifica la lista de selecciones de eventos a usar.
event_send
       Especifica un puntero al evento que se enviará.

DESCRIPCIÓN

La solicitud XSendExtensionEvent identifica la ventana de
destino, determina qué clientes recibirán los eventos especificados
e ignora cualquier grabador activo. Esta solicitud requiere que
pases una lista de clases de eventos. Para una discusión sobre
los nombres válidos de las clases de eventos, consulta
XOpenDevice(3). Esta solicitud utiliza el argumento w para
identificar la ventana de destino de la siguiente manera:
  * Si w es PointerWindow, la ventana de destino es la ventana
    que contiene el puntero.
  * Si w es InputFocus y si la ventana de foco contiene el
    puntero, la ventana de destino es la ventana que contiene el
    puntero; de lo contrario, la ventana de destino es la ventana
    de foco.
Para determinar qué clientes deben recibir los eventos especificados,
XSendExtensionEvent utiliza el argumento propagate de la
siguiente manera:
  * Si event_list es el conjunto vacío, el evento se envía al
    cliente que creó la ventana de destino. Si ese cliente ya no
    existe, no se envía ningún evento.
  * Si propagate es False, el evento se envía a cada cliente que
    seleccione en destination cualquiera de los tipos de evento
    especificados por el array event_list.
  * Si propagate es True y ningún cliente ha seleccionado en
    destination ninguno de los eventos especificados por el array
    event_list, el destino se reemplaza con el ancestro más cercano
    de destination para el cual algún cliente ha seleccionado un
    tipo especificado por el array de eventos y para el cual
    ninguna ventana intermedia tiene ese tipo en su máscara
    do-not-propagate-mask. Si no existe tal ventana o si la ventana
    es un ancestro de la ventana de foco y se especificó
    InputFocus originalmente como destino, el evento no se envía
    a ningún cliente. De lo contrario, el evento se informa a cada
    cliente que selecciona en el destino final cualquiera de los
    eventos especificados en el array event_list.
El evento en la estructura XEvent debe ser uno de los eventos
definidos por la extensión de entrada (o se producirá un error
BadValue), de modo que el servidor X pueda intercambiar correctamente
los bytes del contenido según sea necesario. El contenido del evento
se mantiene sin alterar y sin verificar por el servidor X, excepto
por forzar send_event a True en el evento reenviado y por establecer
correctamente el número de serie en el evento.
XSendExtensionEvent devuelve cero si la conversión al formato de
protocolo de cable falló y devuelve un valor distinto de cero
en caso contrario. XSendExtensionEvent puede generar errores
BadClass, BadDevice, BadValue y BadWindow.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si el
       dispositivo especificado es el teclado X o el dispositivo
       puntero X.
BadValue
       Un valor numérico cae fuera del rango de valores aceptados
       por la solicitud. A menos que se especifique un rango
       específico para un argumento, se acepta todo el rango
       definido por el tipo del argumento. Cualquier argumento
       definido como un conjunto de alternativas puede generar este
       error.
BadWindow
       Un valor para un argumento de Ventana no nombra una ventana
       definida.
