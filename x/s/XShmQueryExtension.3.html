DESCRIPCIÓN

XShmQueryExtension comprueba si las extensiones de memoria compartida están disponibles para la pantalla especificada.

XShmQueryVersion devuelve los números de versión de la implementación de la extensión. Los pixmaps de memoria compartida son soportados si el argumento pixmaps devuelve true.

XShmAttach indica al servidor que se adjunte a tu segmento de memoria compartida. Si todo va bien, obtendrás un estado distinto de cero, atrás y tu XImage estará lista para usar.

XShmDetach indica al servidor que se desvincule de tu segmento de memoria compartida.

XShmPutImage combina una imagen en memoria con una forma del drawable especificado. Si se usa el formato XYBitmap, la profundidad debe ser uno, o resultará un error ``BadMatch''. El píxel de primer plano en el GC define la fuente para los unos de la imagen, y el píxel de fondo define la fuente para los ceros. Para XYPixmap y ZPixmap, la profundidad debe coincidir con la profundidad del drawable, o resultará un error ``BadMatch''.

XShmGetImage lee datos de imagen en un XImage de memoria compartida donde display es la pantalla de interés, drawable es el drawable fuente, image es el XImage de destino, x e y son desplazamientos dentro del drawable, y plane_mask define qué planos se leerán.

XShmCreateImage asigna la memoria necesaria para una estructura XImage para la pantalla especificada, pero no asigna espacio para la imagen en sí.

XShmPixmapFormat obtiene el formato para el servidor. Si tu aplicación puede manejar el formato de datos de pixmap del servidor, se creará un segmento de memoria compartida y una estructura shminfo.

XShmCreatePixmap apunta a un pixmap que puedes manipular de todas las formas habituales, con la ventaja añadida de poder editar su contenido directamente a través del segmento de memoria compartida.

XShmGetEventBase obtiene el valor del evento de finalización.
