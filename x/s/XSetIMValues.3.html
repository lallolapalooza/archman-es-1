NOMBRE

XOpenIM, XCloseIM, XSetIMValues, XGetIMValues, XDisplayOfIM, XLocaleOfIM, XRegisterIMInstantiateCallback, XUnregisterIMInstantiateCallback - abrir, cerrar y obtener información del método de entrada

SINTAXIS

XIM XOpenIM(Display *display, XrmDatabase db, char *res_name, char *res_class);

Status XCloseIM(XIM im);

char *XSetIMValues(XIM im, ...);

char *XGetIMValues(XIM im, ...);

Display *XDisplayOfIM(XIM im);

char *XLocaleOfIM(XIM im);

Bool XRegisterIMInstantiateCallback(Display *display, XrmDatabase db, char *res_name, char *res_class, XIDProc callback, XPointer client_data);

Bool XUnregisterIMInstantiateCallback(Display *display, XrmDatabase db, char *res_name, char *res_class, XIDProc callback, XPointer client_data);

ARGUMENTOS

callback
Especifica un puntero a la función de llamada de método de entrada.
client_data
Especifica los datos adicionales del cliente.
db
Especifica un puntero a la base de datos de recursos.
display
Especifica la conexión con el servidor X.
im
Especifica el método de entrada.
res_class
Especifica el nombre completo de la clase de la aplicación.
res_name
Especifica el nombre completo del recurso de la aplicación.
...
Especifica la lista de argumentos de longitud variable para establecer u obtener valores de XIM.

DESCRIPCIÓN

La función XOpenIM abre un método de entrada, coincidiendo con la configuración de local y modificadores actual. El local y los modificadores actuales están vinculados al método de entrada en el momento de la apertura. El local asociado con un método de entrada no puede modificarse dinámicamente. Esto implica que las cadenas devueltas por XmbLookupString o XwcLookupString, para cualquier contexto de entrada afiliado a un método de entrada dado, se codificarán en el local actual en el momento en que se abrió el método de entrada.

El método de entrada específico al que se dirigirá esta llamada se identifica en función del local actual. XOpenIM identificará un método de entrada predeterminado correspondiente al local actual. Ese predeterminado puede modificarse usando XSetLocaleModifiers para el modificador del método de entrada.

El argumento db es la base de datos de recursos que será utilizada por el método de entrada para buscar recursos que son privados para el método de entrada. No se pretende que esta base de datos se utilice para buscar valores que puedan establecerse como valores de IC en un contexto de entrada. Si db es NULL, no se pasa ninguna base de datos al método de entrada.

Los argumentos res_name y res_class especifican el nombre y la clase del recurso de la aplicación. Están destinados a ser utilizados como prefijos por el método de entrada al buscar recursos que son comunes a todos los contextos de entrada que puedan crearse para este método de entrada. Los caracteres utilizados para nombres y clases de recursos deben estar en el Conjunto de Caracteres Portátiles de X. Los recursos buscados no se especifican completamente si res_name o res_class es NULL.

No se asume que los argumentos res_name y res_class existan más allá de la llamada a XOpenIM. Se asume que la base de datos de recursos especificada existe durante la vida útil del método de entrada.

XOpenIM devuelve NULL si no se pudo abrir ningún método de entrada.

La función XCloseIM cierra el método de entrada especificado y libera la memoria apuntada por el argumento im.

La función XSetIMValues presenta una interfaz de programación de lista de argumentos variables para establecer atributos del método de entrada especificado. Devuelve NULL si tiene éxito; de lo contrario, devuelve el nombre del primer argumento que no se pudo establecer. Xlib no intenta establecer argumentos de la lista suministrada que siguen al argumento fallido; todos los argumentos de la lista anteriores al argumento fallido se han establecido correctamente.

La función XGetIMValues presenta una interfaz de programación de lista de argumentos variables para consultar propiedades o características del método de entrada especificado. Esta función devuelve NULL si tiene éxito; de lo contrario, devuelve el nombre del primer argumento que no se pudo obtener.

Cada argumento de valor XIM (después de un nombre) debe apuntar a una ubicación donde se almacenará el valor XIM. Es decir, si el valor XIM es de tipo T, el argumento debe ser de tipo T*. Si T es en sí mismo un tipo puntero, entonces XGetIMValues asigna memoria para almacenar los datos reales, y el cliente es responsable de liberar estos datos llamando a XFree con el puntero devuelto.

La función XDisplayOfIM devuelve la pantalla asociada con el método de entrada especificado.

La función XLocaleOfIM devuelve el local asociado con el método de entrada especificado.

La función XRegisterIMInstantiateCallback registra una función de llamada que se invocará cada vez que un nuevo método de entrada esté disponible para la pantalla especificada que coincida con el local y los modificadores actuales.

La función devuelve True si tiene éxito; de lo contrario, devuelve False.

La función XUnregisterIMInstantiateCallback elimina una función de llamada de instanciación de método de entrada registrada previamente. La función devuelve True si tiene éxito; de lo contrario, devuelve False.
