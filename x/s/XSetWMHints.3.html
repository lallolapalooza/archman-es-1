XSetWMHints(3)

Paquete: libx11

Licencias: MIT AND X11

XAllocWMHints(3) FUNCIONES DE XLIB XAllocWMHints(3)

NOMBRE

XAllocWMHints, XSetWMHints, XGetWMHints, XWMHints - asigna estructura de sugerencias del gestor de ventanas y establece o lee la propiedad WM_HINTS de una ventana

SINTAXIS

XWMHints *XAllocWMHints(void);

int XSetWMHints(Display *display, Window w, XWMHints *wmhints);

XWMHints *XGetWMHints(Display *display, Window w);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
w
Especifica la ventana.
wmhints
Especifica la estructura XWMHints a utilizar.

DESCRIPCIÓN

La función XAllocWMHints asigna y devuelve un puntero a una estructura XWMHints. Tenga en cuenta que todos los campos de la estructura XWMHints se establecen inicialmente a cero. Si no hay suficiente memoria disponible, XAllocWMHints devuelve NULL. Para liberar la memoria asignada a esta estructura, use XFree.

La función XSetWMHints establece las sugerencias del gestor de ventanas que incluyen información y ubicación de iconos, el estado inicial de la ventana y si la aplicación depende del gestor de ventanas para obtener entrada del teclado.

XSetWMHints puede generar errores BadAlloc y BadWindow.

La función XGetWMHints lee las sugerencias del gestor de ventanas y devuelve NULL si no se estableció ninguna propiedad WM_HINTS en la ventana o devuelve un puntero a una estructura XWMHints si tiene éxito. Cuando haya terminado con los datos, libere el espacio utilizado para ello llamando a XFree.

XGetWMHints puede generar un error BadWindow.

PROPIEDADES

WM_HINTS
Sugerencias adicionales establecidas por el cliente para uso del gestor de ventanas. El tipo C de esta propiedad es XWMHints.

ESTRUCTURAS

La estructura XWMHints contiene:

/* bits de máscara de sugerencias del gestor de ventanas */

#define InputHint (1L << 0)
#define StateHint (1L << 1)
#define IconPixmapHint (1L << 2)
#define IconWindowHint (1L << 3)
#define IconPositionHint (1L << 4)
#define IconMaskHint (1L << 5)
#define WindowGroupHint (1L << 6)
#define XUrgencyHint (1L << 8)
#define AllHints (InputHint| StateHint| IconPixmapHint| IconWindowHint| IconPositionHint| IconMaskHint| WindowGroupHint) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        Bool input;     /* ¿depende esta aplicación del gestor de ventanas para
                        obtener entrada del teclado? */
        int initial_state;      /* ver abajo */
        Pixmap icon_pixmap;     /* pixmap a usar como icono */
        Window icon_window;     /* ventana a usar como icono */
        int icon_x, icon_y;     /* posición inicial del icono */
        Pixmap icon_mask;       /* pixmap a usar como máscara para icon_pixmap */
        XID window_group;       /* id del grupo de ventanas relacionado */
        /* esta estructura puede ser extendida en el futuro */
} XWMHints;

El miembro input se utiliza para comunicar al gestor de ventanas el modelo de entrada de foco utilizado por la aplicación. Las aplicaciones que esperan entrada pero nunca establecen explícitamente el foco en ninguna de sus subventanas (es decir, utilizan el modelo de gestión de foco por empuje), como las aplicaciones estilo X Versión 10 que utilizan foco impulsado por el espacio de bienes, deben establecer este miembro a True. De manera similar, las aplicaciones que establecen el foco de entrada en sus subventanas solo cuando un gestor de ventanas se lo otorga a su ventana de nivel superior también deberían establecer este miembro a True. Las aplicaciones que gestionan su propio foco de entrada estableciendo explícitamente el foco en una de sus subventanas siempre que desean entrada del teclado (es decir, utilizan el modelo de gestión de foco por extracción) deberían establecer este miembro a False. Las aplicaciones que nunca esperan ninguna entrada del teclado también deberían establecer este miembro a False.

Los gestores de ventanas de modelo de extracción deberían hacer posible que las aplicaciones de modelo de empuje obtengan entrada estableciendo el foco de entrada en las ventanas de nivel superior de las aplicaciones cuya miembro input sea True. Los gestores de ventanas de modelo de empuje deberían asegurarse de que las aplicaciones de modelo de extracción no los rompan restableciendo el foco de entrada a PointerRoot cuando sea apropiado (por ejemplo, cada vez que una aplicación cuyo miembro input sea False establezca el foco de entrada en una de sus subventanas).

Las definiciones para el indicador initial_state son:

#define WithdrawnState 0
#define NormalState 1 /* la mayoría de las aplicaciones comienzan así */
#define IconicState 3 /* la aplicación quiere empezar como un icono */
La máscara icon_mask especifica qué píxeles del icon_pixmap deben usarse como icono. Esto permite iconos no rectangulares. Tanto icon_pixmap como icon_mask deben ser bitmaps. La ventana icon_window permite a una aplicación proporcionar una ventana para usar como icono para los gestores de ventanas que admiten dicho uso. La ventana window_group le permite especificar que esta ventana pertenece a un grupo de otras ventanas. Por ejemplo, si una única aplicación manipula varias ventanas de nivel superior, esto le permite proporcionar suficiente información para que un gestor de ventanas pueda iconificar todas las ventanas en lugar de solo una.

El indicador UrgencyHint, si se establece en el campo flags, indica que el cliente considera que el contenido de la ventana es urgente, requiriendo la respuesta oportuna del usuario. El gestor de ventanas hará algún esfuerzo para llamar la atención del usuario hacia esta ventana mientras este indicador esté activado. El cliente debe proporcionar algún medio por el cual el usuario pueda hacer que se borre el indicador de urgencia (ya sea mitigando la condición que hizo que la ventana fuera urgente o simplemente apagando la alarma) o que la ventana sea retirada.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadWindow
Un valor para un argumento Window no nombra una Ventana definida.
