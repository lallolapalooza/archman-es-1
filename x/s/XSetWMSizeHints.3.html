XAllocSizeHints(3) FUNCIONES DE XLIB XAllocSizeHints(3)

NOMBRE

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - asignar estructura de indicaciones de tamaño y establecer o leer la propiedad WM_NORMAL_HINTS de una ventana

SINTAXIS

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
hints
Especifica las indicaciones de tamaño para la ventana en su estado normal.
hints
Especifica la estructura XSizeHints a utilizar.
hints_return
Devuelve las indicaciones de tamaño para la ventana en su estado normal.
property
Especifica el nombre de la propiedad.
supplied_return
Devuelve las indicaciones que fueron proporcionadas por el usuario.
w
Especifica la ventana.

DESCRIPCIÓN

La función XAllocSizeHints asigna y devuelve un puntero a una estructura XSizeHints. Tenga en cuenta que todos los campos de la estructura XSizeHints se establecen inicialmente a cero. Si no hay suficiente memoria disponible, XAllocSizeHints devuelve NULL. Para liberar la memoria asignada a esta estructura, utilice XFree.

La función XSetWMNormalHints reemplaza las indicaciones de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. Si la propiedad no existe, XSetWMNormalHints establece las indicaciones de tamaño para la propiedad WM_NORMAL_HINTS en la ventana especificada. La propiedad se almacena con un tipo WM_SIZE_HINTS y un formato de 32.

XSetWMNormalHints puede generar errores BadAlloc y BadWindow.

La función XGetWMNormalHints devuelve las indicaciones de tamaño almacenadas en la propiedad WM_NORMAL_HINTS en la ventana especificada. Si la propiedad es de tipo WM_SIZE_HINTS, tiene formato 32 y es lo suficientemente larga como para contener una estructura de indicaciones de tamaño antigua (pre-ICCCM) o nueva, XGetWMNormalHints establece los diversos campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos) y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero.

Si XGetWMNormalHints se ejecuta correctamente y se lee una propiedad de indicaciones de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente larga como para contener también el tamaño base y los campos de gravedad de la ventana, el argumento supplied_return contendrá también los siguientes bits:

PBaseSize|PWinGravity

XGetWMNormalHints puede generar un error PN BadWindow.

La función XSetWMSizeHints reemplaza las indicaciones de tamaño para la propiedad especificada en la ventana nombrada. Si la propiedad especificada no existe, XSetWMSizeHints establece las indicaciones de tamaño para la propiedad especificada en la ventana nombrada. La propiedad se almacena con un tipo WM_SIZE_HINTS y un formato de 32. Para establecer las indicaciones de tamaño normales de una ventana, puede utilizar la función XSetWMNormalHints.

XSetWMSizeHints puede generar errores BadAlloc, BadAtom y BadWindow.

La función XGetWMSizeHints devuelve las indicaciones de tamaño almacenadas en la propiedad especificada en la ventana nombrada. Si la propiedad es de tipo WM_SIZE_HINTS, tiene formato 32 y es lo suficientemente larga como para contener una estructura de indicaciones de tamaño antigua (pre-ICCCM) o nueva, XGetWMSizeHints establece los diversos campos de la estructura XSizeHints, establece el argumento supplied_return a la lista de campos que fueron proporcionados por el usuario (independientemente de si contenían valores definidos) y devuelve un estado distinto de cero. De lo contrario, devuelve un estado cero. Para obtener las indicaciones de tamaño normales de una ventana, puede utilizar la función XGetWMNormalHints.

Si XGetWMSizeHints se ejecuta correctamente y se lee una propiedad de indicaciones de tamaño pre-ICCCM, el argumento supplied_return contendrá los siguientes bits:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

Si la propiedad es lo suficientemente larga como para contener también el tamaño base y los campos de gravedad de la ventana, el argumento supplied_return contendrá también los siguientes bits:

PBaseSize|PWinGravity

XGetWMSizeHints puede generar errores BadAtom y BadWindow.

PROPIEDADES

WM_NORMAL_HINTS
Indicaciones de tamaño para una ventana en su estado normal. El tipo C de esta propiedad es XSizeHints.

ESTRUCTURAS

La estructura XSizeHints contiene:

/* Bits de máscara de indicaciones de tamaño */

#define USPosition (1L << 0) /* usuario especificó x, y */
#define USSize (1L << 1) /* usuario especificó ancho, alto */
#define PPosition (1L << 2) /* programa especificó posición */
#define PSize (1L << 3) /* programa especificó tamaño */
#define PMinSize (1L << 4) /* programa especificó tamaño mínimo */
#define PMaxSize (1L << 5) /* programa especificó tamaño máximo */
#define PResizeInc (1L << 6) /* programa especificó incrementos de redimensionamiento */
#define PAspect (1L << 7) /* programa especificó relaciones de aspecto mínimas y máximas */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* Valores */
typedef struct {
        long flags;     /* marca qué campos en esta estructura están definidos */
        int x, y;       /* Obsoleto */
        int width, height;      /* Obsoleto */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* numerador */
               int y;   /* denominador */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* esta estructura puede ser extendida en el futuro */
} XSizeHints;

Los miembros x, y, width y height ahora son obsoletos y se dejan únicamente por motivos de compatibilidad. Los miembros min_width y min_height especifican el tamaño mínimo de la ventana que aún permite que la aplicación sea útil. Los miembros max_width y max_height especifican el tamaño máximo de la ventana. Los miembros width_inc y height_inc definen una progresión aritmética de tamaños (mínimo a máximo) en los que la ventana prefiere redimensionarse. Los miembros min_aspect y max_aspect se expresan como relaciones de x e y, y permiten a una aplicación especificar el rango de relaciones de aspecto que prefiere. Los miembros base_width y base_height definen el tamaño deseado de la ventana. El gestor de ventanas interpretará la posición de la ventana y el ancho de su borde para posicionar el punto del rectángulo exterior de la ventana general especificada por el miembro win_gravity. El rectángulo exterior de la ventana incluye cualquier borde o decoración proporcionado por el gestor de ventanas. XSetWMSizeHints(3) — Linux manual pages

NAME

XSetWMSizeHints — set window manager size hints

SYNTAX

    #include <X11/Xutil.h>

    Status XSetWMSizeHints(
        Display *display,
        Window w,
        XWMSizeHints *hints
    );

ARGUMENTS

display Specifies the connection to the X server.

w Specifies the window.

hints Specifies the size hints structure to be set.

DESCRIPTION

The XSetWMSizeHints function sets the X WMHints structure for the specified window. The window manager uses the information in the X WMHints structure to interact with the application.

The XWMSizeHints structure is defined in <X11/Xutil.h> as:

    typedef struct {
        long flags;
        int x, y;
        int width, height;
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        /* PMinStride, PMaxStride, PAspect, PBaseWidth, PBaseHeight */
        int min_aspect, max_aspect;
    } XWMSizeHints;

The fields in the XWMSizeHints structure are interpreted as follows:

flags
Specifies which of the other fields in the structure are set to meaningful values. The following flags are defined:
PPosition
The x, y fields are set.
PSize
The width, height fields are set.
PMinSize
The min_width, min_height fields are set.
PMaxSize
The max_width, max_height fields are set.
PResizeInc
The width_inc, height_inc fields are set.
PAspect
The min_aspect, max_aspect fields are set. The aspect ratio is specified as a pair of integers representing the numerator and denominator. For example, a value of 2,1 means the aspect ratio is 2:1. A value of 1,2 means the aspect ratio is 1:2. The aspect ratio is calculated as (width*max_aspect) / (height*min_aspect). The range is defined as min_aspect/max_aspect <= width/height <= max_aspect/min_aspect. The value is encoded as (min_aspect << 16) + max_aspect.
PBaseWidth
The PBaseWidth and PBaseHeight flags are used for applications that want to define a base size for their windows, and then additional increments. The PBaseWidth, PBaseHeight, PResizeInc, min_width, min_height, max_width, and max_height attributes are related. The PBaseWidth and PBaseHeight attributes specify the base dimensions. The width and height of the window must be greater than or equal to the base dimensions. The PResizeInc attribute specifies the increments by which the window can be resized. The width and height must be equal to the base dimension plus some multiple of the increment. The maximum and minimum width and height must also conform to this constraint. This means that width = base_width + k*width_inc and height = base_height + l*height_inc, where k and l are integers. The PBaseWidth and PBaseHeight flags should be set if the base_width, base_height, width_inc, and height_inc fields are valid.
PWinGravity
The win_gravity field is set. This specifies the gravity for the window's position, relative to the parent window's border. If PWinGravity is set, win_gravity should be set to either NorthWestGravity, NorthGravity, NorthEastGravity, WestGravity, CenterGravity, EastGravity, SouthWestGravity, SouthGravity, or SouthEastGravity. If PWinGravity is not set, the window's gravity is set to the default, which is NorthWestGravity.
x, y
The preferred position of the window. If PPosition is set in the flags field, the window manager will try to place the window at these coordinates.
width, height
The preferred size of the window. If PSize is set in the flags field, the window manager will try to make the window this size.
min_width, min_height
The minimum size of the window. If PMinSize is set in the flags field, the window manager will not allow the user to resize the window to be smaller than these dimensions.
max_width, max_height
The maximum size of the window. If PMaxSize is set in the flags field, the window manager will not allow the user to resize the window to be larger than these dimensions.
width_inc, height_inc
The increments for resizing the window. If PResizeInc is set in the flags field, the window manager will only allow the user to resize the window in increments of these values. For example, if width_inc is 2, the width can only be changed by multiples of 2.
min_aspect, max_aspect
The minimum and maximum aspect ratios for the window. If PAspect is set in the flags field, the window manager will attempt to maintain the aspect ratio within the specified range.
win_gravity
The gravity of the window. If PWinGravity is set, this field specifies the gravity for the window's position on the parent window's border.

Use XSetNormalHints(3) to set the size hints for a window.

Note that use of the PAllHints macro is highly discouraged.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadAtom
A value for an Atom argument does not name a defined Atom.
BadWindow
A value for a Window argument does not name a defined Window.
