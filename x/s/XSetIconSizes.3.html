XSetIconSizes(3)

Paquete: libx11

Licencias: MIT AND X11

XAllocIconSize(3) FUNCIONES XLIB XAllocIconSize(3)

NOMBRE

XAllocIconSize, XSetIconSizes, XGetIconSizes, XIconSize - asigna una estructura de tamaño de icono y establece o lee la propiedad WM_ICON_SIZES de una ventana

SINTAXIS

XIconSize *XAllocIconSize(void);

int XSetIconSizes(Display *display, Window w, XIconSize *size_list, int count);

Status XGetIconSizes(Display *display, Window w, XIconSize **size_list_return, int *count_return);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
count
Especifica el número de elementos en la lista de tamaños.
count_return
Devuelve el número de elementos en la lista de tamaños.
size_list
Especifica la lista de tamaños.
size_list_return
Devuelve la lista de tamaños.
w
Especifica la ventana.

DESCRIPCIÓN

La función XAllocIconSize asigna y devuelve un puntero a una estructura XIconSize. Ten en cuenta que todos los campos de la estructura XIconSize se inicializan a cero. Si no hay suficiente memoria disponible, XAllocIconSize devuelve NULL. Para liberar la memoria asignada a esta estructura, usa XFree.

La función XSetIconSizes solo la usan los gestores de ventanas para establecer los tamaños de icono admitidos.

XSetIconSizes puede generar errores BadAlloc y BadWindow.

La función XGetIconSizes devuelve cero si un gestor de ventanas no ha establecido tamaños de icono; de lo contrario, devuelve un valor distinto de cero. Una aplicación que quiera saber qué tamaños de icono serían más apreciados por el gestor de ventanas bajo el cual se está ejecutando debería llamar a XGetIconSizes. La aplicación debería entonces usar XSetWMHints para proporcionar al gestor de ventanas un pixmap o ventana de icono en uno de los tamaños admitidos. Para liberar los datos asignados en size_list_return, usa XFree.

XGetIconSizes puede generar un error BadWindow.

PROPIEDADES

WM_ICON_SIZES
El gestor de ventanas puede establecer esta propiedad en la ventana raíz para especificar los tamaños de icono que admite. El tipo C de esta propiedad es XIconSize.

ESTRUCTURAS

La estructura XIconSize contiene:

typedef struct {
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
} XIconSize;

Los miembros width_inc y height_inc definen una progresión aritmética de tamaños (de mínimo a máximo) que representan los tamaños de icono admitidos.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso solicitado o memoria del servidor.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
