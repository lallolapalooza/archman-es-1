XUnmapEvent(3) FUNCIONES DE XLIB XUnmapEvent(3)

NOMBRE

XUnmapEvent - estructura del evento UnmapNotify

ESTRUCTURAS

La estructura para los eventos UnmapNotify contiene:

typedef struct {
        int type;       /* UnmapNotify */
        unsigned long serial;   /* # de la última solicitud procesada por el servidor */
        Bool send_event;        /* verdadero si esto provino de una solicitud SendEvent */
        Display *display;       /* Display desde el cual se leyó el evento */
        Window event;
        Window window;
        Bool from_configure;
} XUnmapEvent;

Cuando recibes este evento, los miembros de la estructura se establecen de la siguiente manera.

El miembro `type` se establece en el nombre de la constante del tipo de evento que lo identifica de forma única. Por ejemplo, cuando el servidor X informa un evento GraphicsExpose a una aplicación cliente, envía una estructura XGraphicsExposeEvent con el miembro `type` establecido en GraphicsExpose. El miembro `display` se establece en un puntero al display desde el cual se leyó el evento. El miembro `send_event` se establece en True si el evento provino de una solicitud de protocolo SendEvent. El miembro `serial` se establece a partir del número de serie informado en el protocolo, pero expandido de los 16 bits menos significativos a un valor completo de 32 bits. El miembro `event` se establece en la ventana que es más útil para los despachadores del toolkit.

El miembro `event` se establece ya sea en la ventana desmapeada o en su padre, dependiendo de si se seleccionó StructureNotify o SubstructureNotify. Esta es la ventana que utiliza el servidor X para informar el evento. El miembro `window` se establece en la ventana que fue desmapeada. El miembro `from_configure` se establece en True si el evento se generó como resultado de un redimensionamiento del padre de la ventana cuando la ventana en sí tenía una `win_gravity` de UnmapGravity.
