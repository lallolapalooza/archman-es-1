Paquete: libx11

XGrabKey(3) FUNCIONES XLIB XGrabKey(3)

NOMBRE

XGrabKey, XUngrabKey - capturar teclas del teclado

SINTAXIS

int XGrabKey(Display *display, int keycode, unsigned int modifiers, Window grab_window, Bool owner_events, int pointer_mode, int keyboard_mode);

int XUngrabKey(Display *display, int keycode, unsigned int modifiers, Window grab_window);

ARGUMENTOS

display
Especifica la conexión con el servidor X.
grab_window
Especifica la ventana de captura.
keyboard_mode
Especifica el procesamiento adicional de los eventos del teclado. Puede pasar GrabModeSync o GrabModeAsync.
keycode
Especifica el KeyCode o AnyKey.
modifiers
Especifica el conjunto de máscaras de teclas o AnyModifier. La máscara es el OR inclusivo a nivel de bits de los bits de máscara de teclas válidos.
owner_events
Especifica un valor booleano que indica si los eventos del teclado se informarán como de costumbre.
pointer_mode
Especifica el procesamiento adicional de los eventos del puntero. Puede pasar GrabModeSync o GrabModeAsync.

DESCRIPCIÓN

La función XGrabKey establece una captura pasiva del teclado. En el futuro, el teclado se captura activamente (como para XGrabKeyboard), el tiempo de la última captura de teclado se establece en el momento en que se presionó la tecla (tal como se transmite en el evento KeyPress), y el evento KeyPress se informa si se cumplen todas las siguientes condiciones:

  • El teclado no está capturado y la tecla especificada (que puede ser una tecla modificadora) está presionada lógicamente cuando las teclas modificadoras especificadas están lógicamente abajo, y ninguna otra tecla modificadora está lógicamente abajo.
  • Ya sea que grab_window sea un antecesor (o sea) la ventana de enfoque, o grab_window sea un descendiente de la ventana de enfoque y contenga el puntero.
  • Una captura pasiva en la misma combinación de teclas no existe en ningún antecesor de grab_window.

La interpretación de los argumentos restantes es como para XGrabKeyboard. La captura activa se termina automáticamente cuando el estado lógico del teclado tiene la tecla especificada liberada (independiente del estado lógico de las teclas modificadoras), momento en el cual se informa un evento KeyRelease a la ventana que realiza la captura.

Tenga en cuenta que el estado lógico de un dispositivo (tal como lo ven las aplicaciones cliente) puede rezagarse respecto al estado físico si el procesamiento de eventos del dispositivo está congelado.

Un argumento de modificadores de AnyModifier es equivalente a emitir la solicitud para todas las combinaciones de modificadores posibles (incluida la combinación de ningún modificador). No es necesario que todos los modificadores especificados tengan KeyCodes asignados actualmente. Un argumento keycode de AnyKey es equivalente a emitir la solicitud para todos los KeyCodes posibles. De lo contrario, el keycode especificado debe estar en el rango especificado por min_keycode y max_keycode en la configuración de la conexión, o se produce un error BadValue.

Si algún otro cliente ha emitido un XGrabKey con la misma combinación de teclas en la misma ventana, se produce un error BadAccess. Al usar AnyModifier o AnyKey, la solicitud falla por completo, y se produce un error BadAccess (no se establece ninguna captura) si hay una captura conflictiva para alguna combinación.

XGrabKey puede generar errores BadAccess, BadValue y BadWindow.

La función XUngrabKey libera la combinación de teclas en la ventana especificada si fue capturada por este cliente. No tiene ningún efecto sobre una captura activa. Un modificador de AnyModifier es equivalente a emitir la solicitud para todas las combinaciones de modificadores posibles (incluida la combinación de ningún modificador). Un argumento keycode de AnyKey es equivalente a emitir la solicitud para todos los códigos de tecla posibles.

XUngrabKey puede generar errores BadValue y BadWindow.

DIAGNÓSTICOS

BadAccess
Un cliente intentó capturar una combinación de teclas/botones ya capturada por otro cliente.
BadValue
Algún valor numérico cae fuera del rango de valores aceptados por la solicitud. A menos que se especifique un rango específico para un argumento, se acepta el rango completo definido por el tipo del argumento. Cualquier argumento definido como un conjunto de alternativas puede generar este error.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
