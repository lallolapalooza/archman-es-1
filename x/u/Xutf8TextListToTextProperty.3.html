XmbTextListToTextProperty(3) FUNCIONES DE XLIB XmbTextListToTextProperty(3)

NOMBRE

XmbTextListToTextProperty, XwcTextListToTextProperty, Xutf8TextListToTextProperty, XmbTextPropertyToTextList, XwcTextPropertyToTextList, Xutf8TextPropertyToTextList, XwcFreeStringList, XDefaultString - convertir listas de texto y estructuras de propiedad de texto

SINTAXIS

int XmbTextListToTextProperty(Display *display, char **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int XwcTextListToTextProperty(Display *display, wchar_t **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int Xutf8TextListToTextProperty(Display *display, char **list, int count, XICCEncodingStyle style, XTextProperty *text_prop_return);

int XmbTextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, char ***list_return, int *count_return);

int XwcTextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, wchar_t ***list_return, int *count_return);

int Xutf8TextPropertyToTextList(Display *display, _Xconst XTextProperty *text_prop, char ***list_return, int *count_return);

void XwcFreeStringList(wchar_t **list);

char *XDefaultString(void)

ARGUMENTOS

display
Especifica la conexión con el servidor X.
list
Especifica una lista de cadenas de caracteres terminadas en nulo.
count
Especifica el número de cadenas especificadas.
style
Especifica la forma en que se codifica la propiedad.
text_prop_return
Devuelve la estructura XTextProperty.
text_prop
Especifica la estructura XTextProperty a utilizar.
list_return
Devuelve una lista de cadenas de caracteres terminadas en nulo.
count_return
Devuelve el número de cadenas.
list
Especifica la lista de cadenas a liberar.

DESCRIPCIÓN

Las funciones XmbTextListToTextProperty, XwcTextListToTextProperty y Xutf8TextListToTextProperty establecen el valor XTextProperty especificado a un conjunto de elementos separados por nulos que representan la concatenación de la lista especificada de cadenas de texto terminadas en nulo. Las cadenas de texto de entrada deben proporcionarse en la codificación de la configuración regional actual (para XmbTextListToTextProperty y XwcTextListToTextProperty), o en codificación UTF-8 (para Xutf8TextListToTextProperty).

Las funciones establecen el campo de codificación de text_prop_return a un Atom para el servidor especificado que nombra la codificación determinada por el estilo especificado y convierten la lista de texto especificada a esta codificación para su almacenamiento en el campo de valor de text_prop_return. Si se especifica el estilo XStringStyle o XCompoundTextStyle, esta codificación es “STRING” o “COMPOUND_TEXT”, respectivamente. Si se especifica el estilo XUTF8StringStyle, esta codificación es “UTF8_STRING”. (Esta es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.) Si se especifica el estilo XTextStyle, esta codificación es la codificación de la configuración regional actual. Si se especifica el estilo XStdICCTextStyle, esta codificación es “STRING” si el texto es completamente convertible a STRING, de lo contrario “COMPOUND_TEXT”. Un byte nulo de terminación final se almacena al final del campo de valor de text_prop_return pero no se incluye en el miembro nitems.

Si no hay suficiente memoria disponible para la nueva cadena de valor, las funciones devuelven XNoMemory. Si la configuración regional actual no es compatible, las funciones devuelven XLocaleNotSupported. En ambos casos de error, las funciones no establecen text_prop_return.

Para determinar si las funciones garantizan no devolver XLocaleNotSupported, utilice XSupportsLocale.

Si el texto proporcionado no es completamente convertible a la codificación especificada, las funciones devuelven el número de caracteres inconvertibles. Cada carácter inconvertible se convierte a una cadena por definición de implementación y específica de la codificación. De lo contrario, las funciones devuelven Success. Tenga en cuenta que la convertibilidad completa a todos los estilos, excepto XStringStyle, está garantizada.

Para liberar el almacenamiento del campo de valor, utilice XFree.

Las funciones XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven una lista de cadenas de texto que representan los elementos separados por nulos de la estructura XTextProperty especificada. Las cadenas devueltas se codifican utilizando la codificación de la configuración regional actual (para XmbTextPropertyToTextList y XwcTextPropertyToTextList) o en UTF-8 (para Xutf8TextPropertyToTextList). Los datos en text_prop deben ser de formato 8.

Múltiples elementos de la propiedad (por ejemplo, las cadenas en una selección de texto disjunta) se separan por un byte nulo. Los contenidos de la propiedad no requieren ser terminados en nulo; cualquier nulo de terminación no debe incluirse en text_prop.nitems.

Si no hay suficiente memoria disponible para la lista y sus elementos, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven XNoMemory. Si la configuración regional actual no es compatible, las funciones devuelven XLocaleNotSupported. De lo contrario, si el campo de codificación de text_prop no es convertible a la codificación de la configuración regional actual, las funciones devuelven XConverterNotFound. Para las configuraciones regionales compatibles, la existencia de un convertidor desde COMPOUND_TEXT, STRING, UTF8_STRING o la codificación de la configuración regional actual está garantizada si XSupportsLocale devuelve True para la configuración regional actual (pero el texto real puede contener caracteres inconvertibles). La conversión de otras codificaciones depende de la implementación. En todos estos casos de error, las funciones no establecen ningún valor de retorno.

De lo contrario, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven la lista de cadenas de texto terminadas en nulo a list_return y el número de cadenas de texto a count_return.

Si el campo de valor de text_prop no es completamente convertible a la codificación de la configuración regional actual, las funciones devuelven el número de caracteres inconvertibles. Cada carácter inconvertible se convierte a una cadena en la configuración regional actual que es específica de la configuración regional actual. Para obtener el valor de esta cadena, utilice XDefaultString. De lo contrario, XmbTextPropertyToTextList, XwcTextPropertyToTextList y Xutf8TextPropertyToTextList devuelven Success.

Para liberar el almacenamiento de la lista y su contenido devuelto por XmbTextPropertyToTextList o Xutf8TextPropertyToTextList, utilice XFreeStringList. Para liberar el almacenamiento de la lista y su contenido devuelto por XwcTextPropertyToTextList, utilice XwcFreeStringList.

La función XwcFreeStringList libera la memoria asignada por XwcTextPropertyToTextList.

La función XDefaultString devuelve la cadena predeterminada utilizada por Xlib para la conversión de texto (por ejemplo, en XmbTextPropertyToTextList). La cadena predeterminada es la cadena en la configuración regional actual que se produce cuando se encuentra un carácter inconvertible durante la conversión de texto. Si la cadena devuelta por XDefaultString es la cadena vacía (""), no se produce ningún carácter en el texto convertido. XDefaultString no devuelve NULL.

La cadena devuelta por XDefaultString es independiente de la cadena predeterminada para el dibujo de texto; consulte XCreateFontSet para obtener la cadena predeterminada de un XFontSet.

El comportamiento cuando se proporciona un punto de código inválido a cualquier función de Xlib no está definido.

La cadena devuelta está terminada en nulo. Es propiedad de Xlib y no debe ser modificada ni liberada por el cliente. Puede ser liberada después de que cambie la configuración regional actual. Hasta que se libere, Xlib no la modificará.

ESTRUCTURAS

La estructura XTextProperty contiene:

typedef struct {
        unsigned char *value;   /* datos de la propiedad */
        Atom encoding;  /* tipo de propiedad */
        int format;     /* 8, 16, o 32 */
        unsigned long nitems;   /* número de elementos en value */
} XTextProperty;

La estructura XICCEncodingStyle contiene:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* texto en la codificación del propietario (localidad actual) */
        XStdICCTextStyle,       /* STRING, de lo contrario COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;
