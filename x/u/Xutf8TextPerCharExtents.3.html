XmbTextPerCharExtents(3) FUNCIONES DE XLIB XmbTextPerCharExtents(3)

NOMBRE

XmbTextPerCharExtents, XwcTextPerCharExtents, Xutf8TextPerCharExtents - obtener información por carácter para una cadena de texto

SINTAXIS

Status XmbTextPerCharExtents(XFontSet font_set, _Xconst char *string, int num_bytes, XRectangle *ink_array_return, XRectangle *logical_array_return, int array_size, int *num_chars_return, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

Status XwcTextPerCharExtents(XFontSet font_set, _Xconst wchar_t *string, int num_wchars, XRectangle *ink_array_return, XRectangle *logical_array_return, int array_size, int *num_chars_return, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

Status Xutf8TextPerCharExtents(XFontSet font_set, _Xconst char *string, int num_bytes, XRectangle *ink_array_return, XRectangle *logical_array_return, int array_size, int *num_chars_return, XRectangle *overall_ink_return, XRectangle *overall_logical_return);

ARGUMENTOS

array_size
Especifica el tamaño de ink_array_return y logical_array_return. El llamador debe pasar arreglos de este tamaño.
font_set
Especifica el conjunto de fuentes.
ink_array_return
Devuelve las dimensiones de tinta para cada carácter.
logical_array_return
Devuelve las dimensiones lógicas para cada carácter.
num_bytes
Especifica el número de bytes en el argumento string.
num_chars_return
Devuelve el número de caracteres en el argumento string.
num_wchars
Especifica el número de caracteres en el argumento string.
overall_ink_return
Devuelve las extinciones de tinta generales de toda la cadena.
overall_logical_return
Devuelve las extinciones lógicas generales de toda la cadena.
string
Especifica la cadena de caracteres.

DESCRIPCIÓN

Las funciones XmbTextPerCharExtents, XwcTextPerCharExtents y Xutf8TextPerCharExtents devuelven las dimensiones de texto de cada carácter de la cadena de texto especificada, utilizando las fuentes cargadas para el conjunto de fuentes especificado. Cada elemento sucesivo de ink_array_return y logical_array_return se establece en las métricas dibujadas del carácter sucesivo, en relación con el origen de dibujo de la cadena y un rectángulo para cada carácter en la cadena de texto proporcionada. El número de elementos de ink_array_return y logical_array_return que han sido establecidos se devuelve a num_chars_return.

Cada elemento de ink_array_return se establece en el cuadro delimitador del color de primer plano dibujado del carácter correspondiente. Cada elemento de logical_array_return se establece en el cuadro delimitador que proporciona un espaciado mínimo con otras características gráficas para el carácter correspondiente. Otras características gráficas no deben intersecar ninguno de los rectángulos de logical_array_return.

Tenga en cuenta que un XRectangle representa las dimensiones de dibujo efectivas del carácter, independientemente del número de glifos de fuente que se utilicen para dibujar el carácter o la dirección en la que se dibuja el carácter. Si varios caracteres se mapean a un solo glifo de carácter, las dimensiones de todos los XRectangles de esos caracteres son las mismas.

Cuando el XFontSet tiene conjuntos de caracteres faltantes, las métricas para cada carácter no disponible se toman de la cadena predeterminada devuelta por XCreateFontSet para que las métricas representen el texto tal como se dibujará realmente. El comportamiento para un punto de código inválido no está definido.

Si array_size es demasiado pequeño para el número de caracteres en el texto proporcionado, las funciones devuelven cero y num_chars_return se establece en el número de rectángulos requeridos. De lo contrario, las funciones devuelven un valor distinto de cero.

Si el argumento overall_ink_return u overall_logical_return no es NULL, XmbTextPerCharExtents, XwcTextPerCharExtents y Xutf8TextPerCharExtents devuelven la extensión máxima de las métricas de la cadena a overall_ink_return u overall_logical_return, tal como lo devuelven XmbTextExtents, XwcTextExtents o Xutf8TextExtents.

La función Xutf8TextPerCharExtents es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia está indicada por la macro X_HAVE_UTF8_STRING.
