XUngrabDevice(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGRABDEVICE(3)   XGRABDEVICE(3)

NOMBRE

XGrabDevice, XUngrabDevice - capturar/liberar el dispositivo de extensión especificado

SINOPSIS

#include <X11/extensions/XInput.h>
int XGrabDevice( Display *display,
                 XDevice* device,
                 Window grab_window,
                 Bool owner_events,
                 int event_count,
                 XEventClass *event_list,
                 int this_device_mode,
                 int other_devices_mode,
                 Time time);
int XUngrabDevice( Display *display,
                   XDevice *device,
                   Time time);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo a capturar o liberar.
grab_window
       Especifica el id de una ventana a asociar con el
       dispositivo.
owner_events
       Especifica un valor booleano que indica si los
       eventos del dispositivo se informarán como de costumbre o
       se informarán con respecto a la ventana de captura si son
       seleccionados por la lista de eventos.
event_count
       Especifica el número de elementos en el array event_list.
event_list
       Especifica un puntero a una lista de clases de eventos que
       indica qué eventos desea recibir el cliente.
       Estas clases de eventos deben haberse obtenido especificando
       el dispositivo que se está capturando.
this_device_mode
       Especifica el procesamiento adicional de eventos de este
       dispositivo. Puede pasar GrabModeSync o GrabModeAsync.
other_devices_mode
       Especifica el procesamiento adicional de eventos de otros
       dispositivos. Puede pasar GrabModeSync o GrabModeAsync.
time
       Especifica el tiempo. Puede pasar una marca de tiempo o
       CurrentTime.

DESCRIPCIÓN

La solicitud XGrabDevice captura activamente el control del dispositivo
y genera eventos DeviceFocusIn y DeviceFocusOut. Los eventos de dispositivo posteriores se informan solo al
cliente que captura. XGrabDevice anula cualquier captura de dispositivo activa por este
cliente. event_list es un puntero a una lista de clases de eventos.
Esta lista indica qué eventos desea recibir el cliente mientras la captura está activa. Si owner_events es False, todos
los eventos de dispositivo generados se informan con respecto a
grab_window si están seleccionados. Si owner_events es True y si un
evento de dispositivo generado se informaría normalmente a este
cliente, se informa normalmente; de lo contrario, el evento se informa con respecto a
grab_window, y solo se informa si se especifica en
event_list.
Si el argumento this_device_mode es GrabModeAsync, el procesamiento de eventos del dispositivo
continúa como de costumbre. Si el dispositivo está actualmente
congelado por este cliente, el procesamiento de eventos del dispositivo se reanuda. Si
el argumento this_device_mode es GrabModeSync, el estado del dispositivo (tal como lo ven las aplicaciones cliente) parece congelarse,
y el servidor X no genera más eventos de dispositivo hasta que el
cliente que captura emita una llamada de liberación XAllowDeviceEvents
o hasta que se libere la captura del dispositivo. Los cambios reales del dispositivo no se pierden mientras el dispositivo está congelado; simplemente se ponen en cola en el servidor para su procesamiento posterior.
Si other_devices_mode es GrabModeAsync, el procesamiento de eventos de otros
dispositivos no se ve afectado por la activación de la captura. Si
other_devices_mode es GrabModeSync, el estado de todos los dispositivos excepto el dispositivo capturado (tal como lo ven las aplicaciones cliente) parece congelarse,
y el servidor X no genera más eventos de esos
dispositivos hasta que el cliente que captura emita una llamada de liberación XAllowDeviceEvents
o hasta que se libere la captura del dispositivo. Los eventos reales no se pierden mientras los dispositivos están congelados; simplemente se ponen en cola en el servidor para su procesamiento posterior.
Si el dispositivo está activamente capturado por algún otro cliente,
XGrabDevice falla y devuelve AlreadyGrabbed. Si grab_window no es visible, falla y devuelve GrabNotViewable. Si el
dispositivo está congelado por una captura activa de otro cliente, falla y
devuelve GrabFrozen. Si el tiempo especificado es anterior a
la última hora de captura del dispositivo o posterior a la hora actual del servidor X, falla y devuelve GrabInvalidTime. De lo contrario, la
última hora de captura del dispositivo se establece en la hora
especificada (CurrentTime se reemplaza por la hora actual del servidor X).
Si un cliente cierra un dispositivo capturado mientras una captura activa por ese cliente está en vigor, la captura activa se libera. Si
el dispositivo está congelado solo por una captura activa del cliente solicitante, se descongela.
XGrabDevice puede generar errores BadClass, BadDevice, BadValue y
BadWindow.
La solicitud XUngrabDevice libera el dispositivo y cualquier evento en cola si este cliente lo tiene activamente capturado desde XGrabDevice o XGrabDeviceKey. Si otros dispositivos están congelados por la captura, XUngrabDevice los descongela. XUngrabDevice no libera el dispositivo ni ningún evento en cola si la hora especificada es anterior a la última hora de captura del dispositivo o es posterior a la hora actual del servidor X. También genera eventos DeviceFocusIn y DeviceFocusOut. El servidor X realiza automáticamente una solicitud UngrabDevice si la ventana de eventos para una captura de dispositivo activa no se vuelve visible.
XUngrabDevice puede generar un error BadDevice.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo inválido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si el
       dispositivo especificado es el teclado X o el dispositivo puntero X.
BadValue
       Algún valor numérico cae fuera del rango de valores
       aceptados por la solicitud. A menos que se especifique un rango específico
       para un argumento, se acepta el rango completo definido por el
       tipo del argumento. Cualquier argumento definido como un conjunto
       de alternativas puede generar este error.
BadWindow
       Un valor para un argumento Window no nombra una
       Ventana definida.
