XInstallColormap(3) FUNCIONES XLIB XInstallColormap(3)

NOMBRE

XInstallColormap, XUninstallColormap, XListInstalledColormaps - controlar mapas de color

SINTAXIS

int XInstallColormap(Display *display, Colormap colormap);

int XUninstallColormap(Display *display, Colormap colormap);

Colormap *XListInstalledColormaps(Display *display, Window w, int *num_return);

ARGUMENTOS

colormap
Especifica el mapa de color.
display
Especifica la conexión con el servidor X.
num_return
Devuelve el número de mapas de color actualmente instalados.
w
Especifica la ventana que determina la pantalla.

DESCRIPCIÓN

La función XInstallColormap instala el mapa de color especificado para su pantalla asociada. Todas las ventanas asociadas con este mapa de color se muestran inmediatamente con colores verdaderos. Asociaste las ventanas con este mapa de color cuando las creaste llamando a XCreateWindow, XCreateSimpleWindow, XChangeWindowAttributes, o XSetWindowColormap.

Si el mapa de color especificado no es ya un mapa de color instalado, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de color. Además, para cada otro mapa de color que se instala como resultado de una llamada a XInstallColormap, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de color.

XInstallColormap puede generar un error BadColor.

La función XUninstallColormap elimina el mapa de color especificado de la lista requerida para su pantalla. Como resultado, el mapa de color especificado puede ser desinstalado, y el servidor X puede instalar o desinstalar implícitamente mapas de color adicionales. Qué mapas de color se instalan o desinstalan depende del servidor, excepto que la lista requerida debe permanecer instalada.

Si el mapa de color especificado se desinstala, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de color. Además, para cada otro mapa de color que se instala o desinstala como resultado de una llamada a XUninstallColormap, el servidor X genera un evento ColormapNotify en cada ventana que tiene ese mapa de color.

XUninstallColormap puede generar un error BadColor.

La función XListInstalledColormaps devuelve una lista de los mapas de color actualmente instalados para la pantalla de la ventana especificada. El orden de los mapas de color en la lista no es significativo y no hay indicación explícita de la lista requerida. Cuando la lista asignada ya no es necesaria, libérala usando XFree.

XListInstalledColormaps puede generar un error BadWindow.

DIAGNÓSTICOS

BadColor
Un valor para un argumento Colormap no nombra un Colormap definido.
BadWindow
Un valor para un argumento Window no nombra una Window definida.
