XUnlockDisplay(3)

Paquete: libx11

Licencias: MIT AND X11

XInitThreads(3) FUNCIONES DE XLIB XInitThreads(3)

NOMBRE

XInitThreads, XLockDisplay, XUnlockDisplay - soporte para multihilo

SINTAXIS

Status XInitThreads(void);

Status XFreeThreads(void);

void XLockDisplay(Display *display);

void XUnlockDisplay(Display *display);

ARGUMENTOS

display
Especifica la conexión con el servidor X.

DESCRIPCIÓN

La función XInitThreads inicializa el soporte de Xlib para hilos concurrentes. Esta función debe ser la primera función de Xlib que llame un programa multihilo, y debe completarse antes de que se realice cualquier otra llamada a Xlib. Esta función devuelve un estado distinto de cero si la inicialización fue exitosa; de lo contrario, devuelve cero. En sistemas que no soportan hilos, esta función siempre devuelve cero.

Solo es necesario llamar a esta función si varios hilos podrían usar Xlib de forma concurrente. Si todas las llamadas a funciones de Xlib están protegidas por algún otro mecanismo de acceso (por ejemplo, un bloqueo de exclusión mutua en un toolkit o a través de programación explícita del cliente), no se requiere la inicialización de hilos de Xlib. Se recomienda que los programas de un solo hilo no llamen a esta función.

La función XFreeThreads libera la memoria asignada por XInitThreads.

La función XLockDisplay bloquea a todos los demás hilos para que no utilicen la pantalla especificada. Otros hilos que intenten usar la pantalla se bloquearán hasta que la pantalla sea desbloqueada por este hilo. Las llamadas anidadas a XLockDisplay funcionan correctamente; la pantalla no se desbloqueará realmente hasta que XUnlockDisplay se haya llamado el mismo número de veces que XLockDisplay. Esta función no tiene efecto a menos que Xlib se haya inicializado correctamente para hilos usando XInitThreads.

La función XUnlockDisplay permite que otros hilos vuelvan a utilizar la pantalla especificada. Se permite que continúen los hilos que se han bloqueado en la pantalla. El bloqueo anidado funciona correctamente; si se ha llamado a XLockDisplay varias veces por un hilo, entonces XUnlockDisplay debe llamarse un número igual de veces antes de que la pantalla se desbloquee realmente. Esta función no tiene efecto a menos que Xlib se haya inicializado correctamente para hilos usando XInitThreads.
