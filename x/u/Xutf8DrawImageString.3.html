Xutf8DrawImageString(3)

Paquete: libx11

XmbDrawImageString(3) FUNCIONES DE XLIB XmbDrawImageString(3)

NOMBRE

XmbDrawImageString, XwcDrawImageString, Xutf8DrawImageString - dibujar texto de imagen usando un único conjunto de fuentes

SINTAXIS

void XmbDrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst char *string, int num_bytes);

void XwcDrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst wchar_t *string, int num_wchars);

void Xutf8DrawImageString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, _Xconst char *string, int num_bytes);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
font_set
Especifica el conjunto de fuentes.
gc
Especifica el GC.
num_bytes
Especifica el número de bytes en el argumento string.
num_wchars
Especifica el número de caracteres en el argumento string.
string
Especifica la cadena de caracteres.
x

y
Especifican las coordenadas x e y.

DESCRIPCIÓN

Las funciones XmbDrawImageString, XwcDrawImageString y Xutf8DrawImageString rellenan un rectángulo de destino con el píxel de fondo definido en el GC y luego pintan el texto con el píxel de primer plano. El rectángulo rellenado es el rectángulo devuelto por XmbTextExtents, XwcTextExtents o Xutf8TextExtents para el mismo texto y XFontSet.

Cuando el XFontSet tiene conjuntos de caracteres faltantes, cada carácter no disponible se dibuja con la cadena predeterminada devuelta por XCreateFontSet. El comportamiento para un punto de código no válido no está definido.

La función Xutf8TextExtents es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia está indicada por la macro X_HAVE_UTF8_STRING.
