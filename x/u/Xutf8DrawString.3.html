Xutf8DrawString(3)

Paquete: libx11

XmbDrawString(3) FUNCIONES DE XLIB XmbDrawString(3)

NOMBRE

XmbDrawString, XwcDrawString, Xutf8DrawString - dibujar texto usando un único conjunto de fuentes

SINTAXIS

void XmbDrawString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, const char *string, int num_bytes);

void XwcDrawString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, const wchar_t *string, int num_wchars);

void Xutf8DrawString(Display *display, Drawable d, XFontSet font_set, GC gc, int x, int y, const char *string, int num_bytes);

ARGUMENTOS

d
Especifica el drawable.
display
Especifica la conexión con el servidor X.
font_set
Especifica el conjunto de fuentes.
gc
Especifica el GC.
num_bytes
Especifica el número de bytes en el argumento string.
num_wchars
Especifica el número de caracteres en el argumento string.
string
Especifica la cadena de caracteres.
x

y
Especifica las coordenadas x e y.

DESCRIPCIÓN

Las funciones XmbDrawString, XwcDrawString y Xutf8DrawString dibujan el texto especificado con el píxel de primer plano. Cuando el XFontSet tiene conjuntos de caracteres faltantes, cada carácter no disponible se dibuja con la cadena predeterminada devuelta por XCreateFontSet. El comportamiento para un punto de código no válido no está definido.

La función Xutf8DrawString es una extensión introducida por The XFree86 Project, Inc., en su versión 4.0.2. Su presencia se indica mediante la macro X_HAVE_UTF8_STRING.
