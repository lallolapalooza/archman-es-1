XUndefineCursor(3)

Paquete: libx11

Licencias: MIT AND X11

XDefineCursor(3) FUNCIONES DE XLIB XDefineCursor(3)

NOMBRE

XDefineCursor, XUndefineCursor - definir cursores

SINTAXIS

int XDefineCursor(Display *display, Window w, Cursor cursor);

int XUndefineCursor(Display *display, Window w);

ARGUMENTOS

cursor
Especifica el cursor que se va a mostrar o None.
display
Especifica la conexión con el servidor X.
w
Especifica la ventana.

DESCRIPCIÓN

Si se establece un cursor, se utilizará cuando el puntero esté en la ventana. Si el cursor es None, es equivalente a XUndefineCursor.

XDefineCursor puede generar errores BadCursor y BadWindow.

La función XUndefineCursor deshace el efecto de un XDefineCursor anterior para esta ventana. Cuando el puntero esté en la ventana, se utilizará el cursor del padre. En la ventana raíz, se restaurará el cursor predeterminado.

XUndefineCursor puede generar un error BadWindow.

DIAGNÓSTICOS

BadAlloc
El servidor no pudo asignar el recurso o la memoria del servidor solicitados.
BadCursor
Un valor para un argumento de Cursor no nombra un Cursor definido.
BadWindow
Un valor para un argumento de Ventana no nombra una Ventana definida.
