XUngrabDeviceKey(3)

Paquete: libxi

Licencias: MIT-open-group, SMLNJ, MIT

XGRABDEVICEKEY(3)   XGRABDEVICEKEY(3)

NOMBRE

XGrabDeviceKey, XUngrabDeviceKey - Capturar/Liberar Teclas de Dispositivos de Extensión

SINOPSIS

#include <X11/extensions/XInput.h>
int XGrabDeviceKey( Display *display,
                    XDevice *device,
                    unsigned int key,
                    unsigned int modifiers,
                    XDevice *modifier_device,
                    Window grab_window,
                    Bool owner_events,
                    unsigned int event_count,
                    XEventClass *event_list,
                    int this_device_mode,
                    int other_devices_mode);
int XUngrabDeviceKey( Display *display,
                      XDevice *device,
                      unsigned int key,
                      unsigned int modifiers,
                      XDevice *modifier_device,
                      Window grab_window);
display
       Especifica la conexión con el servidor X.
device
       Especifica el dispositivo que se va a capturar o liberar.
Key
       Especifica la Tecla del dispositivo que se va a capturar o liberar
       o AnyKey.
modifiers
       Especifica el conjunto de máscaras de teclas o AnyModifier. La máscara
       es el OR inclusivo a nivel de bits de los bits válidos de la máscara
       de teclas. Los bits válidos son: ShiftMask, LockMask, ControlMask,
       Mod1Mask, Mod2Mask, Mod3Mask, Mod4Mask, Mod5Mask.
modifier_device
       Especifica el dispositivo cuyos modificadores se van a utilizar. Si
       se especifica un modifier_device de NULL, el teclado X se utilizará
       como el modifier_device.
grab_window
       Especifica la ventana de captura.
owner_events
       Especifica un valor booleano que indica si los eventos del dispositivo
       se informarán como de costumbre o se informarán con respecto a la
       ventana de captura si se seleccionan en la lista de eventos.
event_count
       Especifica el número de clases de eventos en la lista de eventos.
event_list
       Especifica qué eventos del dispositivo se informan al cliente.
this_device_mode
       Especifica el procesamiento adicional de eventos de este
       dispositivo. Puede pasar GrabModeSync o GrabModeAsync.
other_devices_mode
       Especifica el procesamiento adicional de eventos de otros
       dispositivos. Puede pasar GrabModeSync o GrabModeAsync.

DESCRIPCIÓN

La solicitud XGrabDeviceKey establece una captura pasiva. En el futuro,
el dispositivo se captura activamente (como para XGrabDevice, la hora
de la última captura de dispositivo se establece en la hora en que se
presionó la Tecla (según se transmite en el evento DeviceKeyPress), y
el evento DeviceKeyPress se informa si todas las siguientes
condiciones son verdaderas:
  * El dispositivo no está capturado, y la tecla especificada se
    presiona lógicamente cuando las teclas modificadoras especificadas
    están lógicamente abajo, y ninguna otra tecla o tecla modificadora
    está lógicamente abajo.
  * La grab_window es un ancestro (o es) la ventana de foco O
    la grab_window es un descendiente de la ventana de foco y
    contiene el dispositivo.
  * La confine_to window (si existe) es visible.
  * No existe una captura pasiva en la misma combinación de tecla/modificador
    en ningún ancestro de grab_window.
La interpretación de los argumentos restantes es como para
XGrabDevice. La captura activa se termina automáticamente cuando
el estado lógico del dispositivo tiene la tecla especificada liberada.
Tenga en cuenta que el estado lógico de un dispositivo (tal como se ve a
través del protocolo X) puede retrasarse respecto al estado físico si
el procesamiento de eventos del dispositivo está congelado.
Si la clave no es AnyKey, debe estar en el rango especificado por
min_keycode y max_keycode devueltos por la solicitud
XListInputDevices. De lo contrario, se produce un error BadValue.
Esta solicitud anula todas las capturas anteriores por el mismo cliente
en las mismas combinaciones de Tecla/modificador en la misma ventana.
Un modificador de AnyModifier es equivalente a emitir la solicitud de
captura para todas las combinaciones de modificadores posibles (incluida
la combinación de ningún modificador). No es necesario que todos los
modificadores especificados tengan actualmente KeyCodes asignados. Una
tecla de AnyKey es equivalente a emitir la solicitud para todas las
Teclas posibles. De lo contrario, no es necesario que la tecla especificada
esté actualmente asignada a una Tecla física.
Si se especifica un modifier_device de NULL, el teclado X se utilizará
como el modifier_device.
Si algún otro cliente ya ha emitido un XGrabDeviceKey con la misma
combinación de Tecla/modificador en la misma ventana, se produce un error
BadAccess. Al usar AnyModifier o AnyKey, la solicitud falla por completo,
y se produce un error BadAccess (no se establecen capturas) si hay una
captura en conflicto para alguna combinación. XGrabDeviceKey no tiene
efecto en una captura activa.
XGrabDeviceKey puede generar errores BadAccess, BadClass, BadDevice,
BadMatch, BadValue y BadWindow. Devuelve Success si la solicitud se
completa correctamente.
La solicitud XUngrabDeviceKey libera la captura pasiva para una
combinación de tecla/modificador en la ventana especificada si fue
capturada por este cliente. Un modificador de AnyModifier es equivalente
a emitir la solicitud de liberación para todas las combinaciones de
modificadores posibles, incluida la combinación de ningún modificador.
Una Tecla de AnyKey es equivalente a emitir la solicitud para todas las
Teclas posibles. XUngrabDeviceKey no tiene efecto en una captura activa.
Si se especifica un modifier_device de NULL, el teclado X se utilizará
como el modifier_device.
XUngrabDeviceKey puede generar errores BadDevice, BadMatch, BadValue y
BadWindow.

DIAGNÓSTICOS

BadDevice
       Se especificó un dispositivo no válido. El dispositivo especificado
       no existe o no ha sido abierto por este cliente a través de
       XOpenInputDevice. Este error también puede ocurrir si el
       dispositivo especificado es el teclado X o el dispositivo de puntero
       X.
BadMatch
       Este error puede ocurrir si se realizó una solicitud XGrabDeviceKey
       especificando un dispositivo que no tiene teclas, o un dispositivo
       modificador que no tiene teclas.
BadValue
       Algún valor numérico cae fuera del rango de valores aceptados por
       la solicitud. A menos que se especifique un rango para un argumento,
       se acepta el rango completo definido por el tipo del argumento.
       Cualquier argumento definido como un conjunto de alternativas puede
       generar este error.
BadWindow
       Un valor para un argumento Window no nombra una Window definida.
