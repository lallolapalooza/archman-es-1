Paquete: glib-perl

Glib::Param::GType(3) Documentación aportada por el usuario de Perl Glib::Param::GType(3)

NOMBRE

Glib::Param::GType - Envoltura para parámetros de tipo en GLib

JERARQUÍA

Glib::ParamSpec
+----Glib::Param::GType

DESCRIPCIÓN

Este objeto describe un parámetro que contiene el nombre de una clase conocida por el sistema de tipos de GLib. El nombre de la clase se considera el ancestro común para los valores válidos. Para crear un parámetro que permita cualquier nombre de tipo, especifique "undef" para el nombre del paquete. Sin embargo, tenga cuidado, aunque decimos "cualquier nombre de tipo", esto se refiere en realidad a cualquier tipo registrado en Glib; los paquetes Perl normales no funcionarán.

MÉTODOS

cadena o indefinido = $pspec_gtype->get_is_a_type

Si es "undef", entonces se permite cualquier clase.

Desde: glib 2.10

VER TAMBIÉN

Glib, Glib::ParamSpec
