NOMBRE

Graphics::ColorNames::SVG - Nombres de colores SVG y valores RGB equivalentes

SINOPSIS

require Graphics::ColorNames::SVG;
$NameTable = Graphics::ColorNames::SVG->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPCIÓN

Este módulo define nombres de colores y sus valores RGB asociados de la Especificación SVG 1.2.

Actualmente es un alias de Graphic::ColorNames::WWW. Esto puede cambiar en el futuro. Se recomienda usar el módulo WWW, que siempre implementará un superconjunto de este módulo.

Consulte la documentación de Graphics::ColorNames para obtener información sobre cómo usar este módulo.

VER TAMBIÉN

Graphics::ColorNames::WWW, Especificación de Gráficos Vectoriales Escalables (SVG) 1.1, Sección 4.2 (http://www.w3.org/TR/SVG/types.html#ColorKeywords)
