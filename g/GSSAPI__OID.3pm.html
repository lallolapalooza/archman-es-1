GSSAPI__OID(3pm)

Paquete: perl-gssapi

Licencias: GPL, PerlArtistic

GSSAPI::OID(3) Documentación de Perl contribuida por el usuario GSSAPI::OID(3)

NOMBRE

GSSAPI::OID - métodos para manejar OIDs de GSSAPI y algunos OIDs constantes

SINOPSIS

use GSSAPI;
#$oid = GSSAPI::OID->new;             # rara vez necesario o deseado
$status = GSSAPI::OID->from_str($oid, "{ 1 2 840 113554 1 2 1 1 }");
#
# solo soportado en MIT Kerberos
#
$status = $oid->to_str($str);
#
# solo soportado en MIT Kerberos
#
$status = $oid->inquire_names($oidset);
# OIDs constantes proporcionados:
$oid = gss_nt_user_name;
$oid = gss_nt_machine_uid_name;
$oid = gss_nt_string_uid_name;
$oid = gss_nt_service_name;
$oid = gss_nt_exported_name;
$oid = gss_nt_service_name_v2;
$oid = gss_nt_krb5_name;
$oid = gss_nt_krb5_principal;
$oid = gss_mech_krb5;
$oid = gss_mech_krb5_old;
$oid = gss_mech_krb5_v2;
$oid = gss_mech_spnego;
# si tu implementación de GSSAPI soporta
# SPNEGO (Heimdal 0.7 por ejemplo
# puedes usar el tipo de mecanismo OID::gss_mech_spnego.
#
# use GSSAPI::indicate_mechs( $oidset );
# para obtener los tipos de mecanismo que tu implementación soporta
$oid = gss_nt_hostbased_service; # GSS_C_NT_HOSTBASED_SERVICE

DESCRIPCIÓN

"GSSAPI::OID" los objetos se utilizan como identificadores/constantes únicos para 'mecanismos' — el protocolo y versión particulares que se están utilizando — y para las codificaciones utilizadas para representar nombres. En muchos casos, puedes solicitar el mecanismo o codificación predeterminados para la implementación usando GSS_C_NO_OID. Consulta la descripción de la rutina en rfc2743 si no estás seguro.
