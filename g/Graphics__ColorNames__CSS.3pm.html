NOMBRE

Graphics::ColorNames::CSS - Nombres de colores CSS y valores RGB equivalentes

SINOPSIS

require Graphics::ColorNames::CSS;
$NameTable = Graphics::ColorNames::CSS->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPCIÓN

Este módulo define nombres de colores y sus valores RGB asociados de la Propuesta de trabajo del Módulo de Color CSS Nivel 3 del W3C del 21-07-2008.

Actualmente es un alias de Graphic::ColorNames::WWW. Esto puede cambiar en el futuro. Se recomienda usar el módulo WWW, que siempre implementará un superconjunto de este módulo.

Consulte la documentación de Graphics::ColorNames para obtener información sobre cómo usar este módulo.

VER TAMBIÉN

Graphics::ColorNames::WWW, Módulo de Color CSS Nivel 3 (http://w3.org/TR/CSS3-color)
