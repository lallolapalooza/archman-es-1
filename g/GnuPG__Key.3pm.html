GnuPG::Key(3) Documentación de Perl contribuida por el usuario GnuPG::Key(3)

NOMBRE

GnuPG::Key - Objeto de clave GnuPG

SINOPSIS

# asume un objeto GnuPG::Interface en $gnupg
my @claves = $gnupg->obtener_claves_publicas( 'ftobin' );
# ahora los objetos GnuPG::PublicKey están en @claves

DESCRIPCIÓN

Los objetos GnuPG::Key generalmente no se instancian por sí solos, sino que se utilizan como superclase de los objetos GnuPG::PublicKey, GnuPG::SecretKey o GnuPG::SubKey.

MÉTODOS DE OBJETO

Métodos de inicialización

new( %argumentos_inicialización )
Este método crea un nuevo objeto. Los argumentos opcionales son la inicialización de los miembros de datos.
hash_init( %args ).
short_hex_id
Esto devuelve el ID hexadecimal corto de 8 caracteres, de uso común, de la clave.
compare( $otro, $profundo )
Devuelve distinto de cero solo cuando esta Clave es idéntica a la otra GnuPG::Key. Si $profundo está presente y es distinto de cero, las firmas asociadas, revocaciones y revocadores de la clave también se compararán.

MIEMBROS DE DATOS DEL OBJETO

length
Número de bits en la clave.
algo_num
El número del algoritmo para el cual se utiliza la Clave.
usage_flags
Las banderas de Uso de Clave asociadas con esta clave, representadas como una cadena de letras minúsculas. Los valores posibles incluyen: (a) autenticar, (c) certificar, (e) cifrar y (s) firmar.

Una clave puede tener cualquier combinación de ellas en cualquier orden. Además de estas letras, la clave principal tiene versiones en mayúsculas de las letras para denotar las capacidades _utilizables_ de toda la clave, y una letra potencial 'D' para indicar una clave deshabilitada.

Consulte "capacidades de clave" DETALLES en las fuentes de GnuPG para más detalles.

hex_data
Los datos de la clave. ADVERTENCIA: esto parece que nunca se ha instanciado y siempre debería ser undef.
pubkey_data
Una lista de objetos Math::BigInt que corresponden al material de clave pública para la clave dada. Este miembro está vacío en claves secretas en GnuPG 1.4. Está poblado en claves secretas en GnuPG >= 2.2.0.

Para claves DSA, los valores son: primo (p), orden del grupo (q), generador del grupo (g), y

Para claves RSA, los valores son: módulo (n), exponente (e)

Para claves El Gamal, los valores son: primo (p), generador del grupo (g), y

Para más detalles, véase: http://tools.ietf.org/html/rfc4880#page-42

hex_id
El ID hexadecimal largo de la clave. Esta no es la huella digital ni el ID hexadecimal corto, que son 8 caracteres hexadecimales.
creation_date_string
expiration_date_string
Fecha formateada de creación y expiración de la clave. Si la clave no tiene expiración, expiration_date_string devolverá undef.
creation_date
expiration_date
Fecha de creación y expiración de la clave, almacenada como el número de segundos desde la medianoche de 1970-01-01 UTC. Si la clave no tiene expiración, expiration_date devolverá undef.
fingerprint
Un objeto GnuPG::Fingerprint.
signatures
Una lista de objetos GnuPG::Signature que encarnan las firmas de esta clave. Para sub-claves, las firmas son generalmente firmas de enlace de sub-clave. Para claves primarias, las firmas son declaraciones sobre la clave misma.
revocations
Una lista de revocaciones asociadas con esta clave, almacenadas como objetos GnuPG::Signature (ya que las revocaciones también son un tipo de certificación). Tenga en cuenta que la revocación de una clave primaria tiene un significado semántico diferente al de una revocación asociada con una sub-clave.
revokers
Una lista de objetos GnuPG::Revoker asociados con esta clave, que indican otras claves que tienen permiso para revocar certificaciones hechas por esta clave.

VER TAMBIÉN
