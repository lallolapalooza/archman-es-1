NOMBRE

Glib::Flags - métodos y operadores sobrecargados para flags

JERARQUÍA

Glib::Flags

DESCRIPCIÓN

Glib mapea los valores de flags y enumeraciones a las cadenas de alias proporcionadas por las bibliotecas C subyacentes. Representar flags de esta manera en Perl es un problema interesante, que Glib resuelve mediante algunos operadores sobrecargados geniales.

Las funciones descritas aquí realizan el trabajo de esos operadores sobrecargados. Consulte la descripción de los operadores de flags en la sección "Esto es ahora eso" de Glib para obtener más información.

MÉTODOS

escalar = $clase->new ($a)

•
$a (escalar)

Crea un nuevo objeto de flags con los bits dados. Esto es para uso desde una subclase, no es posible crear un objeto "Glib::Flags" como tal. Por ejemplo,

my $f1 = Glib::ParamFlags->new ('readable');
my $f2 = Glib::ParamFlags->new (['readable','writable']);

Un objeto como este puede ser usado con los operadores sobrecargados.

escalar = $a->all ($b, $swap)

  • $b (escalar)
  • $swap (escalar)

aref = $f->as_arrayref

Devuelve los bits de $f como una referencia a un array de cadenas, como ['flagbit1','flagbit2']. Esta es la función sobrecargada para "@{}", es decir, la arrayización de $f. También puedes llamarla directamente como un método.

Ten en cuenta que @$f devuelve los bits como una lista, pero as_arrayref devuelve un arrayref. Si lo que quieres es un arrayref, entonces el estilo de método somefunc()->as_arrayref puede ser más legible que [@{somefunc()}].

booleano = $f->bool

Devuelve 1 si hay algún bit activado en $f, o 0 si no hay ninguno activado. Esta es la sobrecarga para $f en contexto booleano (como "if", etc.). También puedes llamarlo como método para obtener directamente un valor verdadero/falso.
