GnuPG::PrimaryKey(3) Documentación de Perl contribuida por el usuario GnuPG::PrimaryKey(3)

NOMBRE

GnuPG::PrimaryKey - Objetos de clave primaria de GnuPG

SINOPSIS

# asume un objeto GnuPG::Interface en $gnupg
my @claves = $gnupg->get_public_keys( 'ftobin' );
# o
my @claves = $gnupg->get_secret_keys( 'ftobin' );
# ahora los objetos GnuPG::PrimaryKey están en @claves

DESCRIPCIÓN

Los objetos GnuPG::PrimaryKey se instancian generalmente como objetos GnuPG::PublicKey o GnuPG::SecretKey a través de varios métodos de GnuPG::Interface. Representan varios aspectos de una clave primaria de GnuPG.

Este paquete hereda miembros de datos y métodos de objeto de GnuPG::Key, que no se describe aquí, sino en GnuPG::Key.

MIEMBROS DE DATOS DEL OBJETO

user_ids
Una lista de objetos GnuPG::UserId asociados con esta clave.
user_attributes
Una lista de objetos GnuPG::UserAttribute asociados con esta clave.
subkeys
Una lista de objetos GnuPG::SubKey asociados con esta clave.
local_id
ADVERTENCIA: NO USAR. Esto solía significar el ID local de GnuPG para la clave, pero las versiones modernas de GnuPG no lo producen. Espere que sea la cadena vacía o undef.
owner_trust
El valor escalar que GnuPG reporta como confianza del propietario para esta clave. Consulte el archivo DETAILS de GnuPG para obtener más información.

VER TAMBIÉN

GnuPG::Key, GnuPG::UserId, GnuPG::SubKey,
