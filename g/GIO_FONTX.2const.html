KDGKBMODE
Obtiene el modo actual del teclado. argp apunta a un long que se establece a uno de estos:
K_RAW 0x00 /* Modo crudo (scancode) */
K_XLATE 0x01 /* Traduce keycodes usando el mapa de teclas */
K_MEDIUMRAW 0x02 /* Modo crudo medio (scancode) */
K_UNICODE 0x03 /* Modo Unicode */
K_OFF 0x04 /* Modo deshabilitado (desde Linux 2.6.39) */
KDSKBMODE
Establece el modo actual del teclado. argp es un long igual a uno de los valores mostrados para KDGKBMODE.
KDGKBMETA
Obtiene el modo de manejo de la tecla meta. argp apunta a un long que se establece a uno de estos:
K_METABIT 0x03 establece el bit de orden alto
K_ESCPREFIX 0x04 prefijo de escape
KDSKBMETA
Establece el modo de manejo de la tecla meta. argp es un long igual a uno de los valores mostrados arriba para KDGKBMETA.
KDGKBENT
Obtiene una entrada en la tabla de traducción de teclas (keycode a código de acción). argp apunta a un

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

con los dos primeros miembros rellenados: kb_table selecciona la tabla de teclas (0 <= kb_table < MAX_NR_KEYMAPS), y kb_index es el keycode (0 <= kb_index < NR_KEYS). kb_value se establece al código de acción correspondiente, o K_HOLE si no existe tal tecla, o K_NOSUCHMAP si kb_table es inválido.
KDSKBENT
Establece una entrada en la tabla de traducción. argp apunta a un struct kbentry.
KDGKBSENT
Obtiene una cadena de tecla de función. argp apunta a un

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string se establece a la cadena (terminada en nulo) correspondiente a la acción de la tecla de función número kb_func.
KDSKBSENT
Establece una entrada de cadena de tecla de función. argp apunta a un struct kbsentry.
KDGKBDIACR
Lee la tabla de acentos del núcleo. argp apunta a un

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

donde kb_cnt es el número de entradas en el array, cada una de las cuales es un

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lee una entrada de la tabla de keycodes del núcleo (scancode a keycode). argp apunta a un

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode se establece para corresponder al scancodedado. (Solo 89 <= scancode <= 255. Para 1 <= scancode <= 88, keycode==scancode.) (Desde Linux 1.1.63.)
KDSETKEYCODE
Escribe una entrada de la tabla de keycodes del núcleo. argp apunta a un struct kbkeycode. (Desde Linux 1.1.63.)
KDSIGACCEPT
El proceso que llama indica su disposición a aceptar la señal argp cuando se genera al presionar una combinación de teclas apropiada. (1 <= argp <= NSIG). (Véase spawn_console() en linux/drivers/char/keyboard.c.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique). En caso de fallo, se devuelve -1, y errno se establece para indicar el error.

ERRORES

EINVAL
argp es inválido.
