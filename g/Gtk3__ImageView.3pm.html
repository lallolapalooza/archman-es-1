NOMBRE

Gtk3::ImageView - Visor de imágenes para Gtk3

VERSIÓN

9

SINOPSIS

use Gtk3::ImageView;
Gtk3->init;
$window = Gtk3::Window->new();
$view = Gtk3::ImageView->new;
$view->set_pixbuf($pixbuf, TRUE);
$window->add($view);
$window->show_all;

DESCRIPCIÓN

El widget Gtk3::ImageView permite al usuario hacer zoom, desplazarse y seleccionar la imagen especificada, y proporciona puntos de conexión para permitir la creación y el uso de herramientas adicionales, por ejemplo, un pincel.

Gtk3::ImageView es un port a Gtk3 de Gtk2::ImageView.

Para discutir Gtk3::ImageView o gtk3-perl, hacer preguntas y criticar/elogiar a los autores, únete a gtk-perl-list@gnome.org en lists.gnome.org.

SUBRUTINAS/MÉTODOS

$view->set_pixbuf( $pixbuf, $zoom_to_fit )

Define la imagen a visualizar. El parámetro opcional zoom_to_fit especifica si se debe hacer zoom para ajustar la imagen o no.

$view->get_pixbuf

Devuelve la imagen que se está visualizando actualmente.

$view->get_pixbuf_size

Devuelve un hash que contiene el tamaño de la imagen actual en las claves de ancho y alto.

$view->set_zoom($zoom)

Especifica el nivel de zoom.

$view->get_zoom

Devuelve el nivel de zoom actual.

$view->set_zoom_to_fit($zoom_to_fit, $limit)

Especifica si se debe hacer zoom para ajustar o no. Si se define limit, dicho zoom automático no hará más zoom que eso. Si limit no está definido, se usará el límite establecido previamente, inicialmente no tiene límite.

$view->zoom_to_box( $box, $additional_factor )

Especifica un cuadro al que hacer zoom, incluyendo un factor de zoom adicional.

$view->zoom_to_selection($context_factor)

Hace zoom a la selección actual, más un factor de zoom adicional. Atajo para

$view->zoom_to_box( $view->get_selection, $context_factor );

$view->get_zoom_to_fit

Devuelve si la vista está actualmente ajustada al tamaño o no.

$view->zoom_in

Aumenta el zoom actual por "zoom-step" veces (por defecto es 2).

$view->zoom_out

Disminuye el zoom actual por "zoom-step" veces (por defecto es 2).

$view->zoom_to_fit

Atajo para

$view->set_zoom_to_fit(TRUE);

$view->set_fitting( $value )

Atajo para

$view->set_zoom_to_fit($value, 1);

lo que significa que no estirará una imagen pequeña a una ventana grande. Proporcionado (a pesar del nombre ambiguo) para compatibilidad con Gtk2::ImageView.

$view->set_offset( $x, $y )

Establece el desplazamiento de la vista actual (es decir, la posición de desplazamiento).

$view->set_offset

Devuelve el desplazamiento de la vista actual (es decir, la posición de desplazamiento).

$view->get_viewport

Devuelve un hash que contiene la posición y el tamaño de la vista actual.

$view->set_tool

Establece la herramienta actual (es decir, el modo): un objeto de una subclase de "Gtk3::ImageView::Tool".

Aquí hay algunas subclases conocidas:

  • "Gtk3::ImageView::Tool::Dragger" permite arrastrar la imagen cuando está ampliada.
  • "Gtk3::ImageView::Tool::Selector" permite al usuario seleccionar un área rectangular de la imagen.
  • "Gtk3::ImageView::Tool::SelectorDragger" selecciona o arrastra con diferentes botones del ratón.

No confíes demasiado en cómo interactúa actualmente Tool con ImageView.

$view->get_tool

Devuelve la herramienta actual (es decir, el modo).

$view->set_selection($selection)

Establece la selección actual como un hash de posición y tamaño.

$view->get_selection

Devuelve la selección actual como un hash de posición y tamaño.

$view->set_resolution_ratio($ratio)

Establece la relación de las resoluciones en las direcciones x e y, permitiendo que las imágenes con píxeles no cuadrados se muestren correctamente.

$view->get_resolution_ratio

Devuelve la relación de resolución actual.

$view->set_interpolation

El método de interpolación a usar, del tipo "cairo_filter_t" https://www.cairographics.org/manual/cairo-cairo-pattern-t.html#cairo-filter-t. Los valores posibles son cadenas en minúsculas como "nearest". Para usar una interpolación diferente dependiendo del zoom, configúrala en la señal "zoom-changed".

$view->get_interpolation

Devuelve el método de interpolación actual.

INCOMPATIBILIDADES

Portando desde Gtk2::ImageView

  • set_from_pixbuf() fue renombrado a set_pixbuf() y ahora su segundo argumento significa zoom_to_fit() en lugar de set_fitting().
  • set_fitting(TRUE) solía ser el valor por defecto, ahora debes llamarlo explícitamente si quieres ese comportamiento. Sin embargo, una vez llamado, las nuevas llamadas a set_from_pixbuf() no restablecerán

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

para ello, ver set_zoom_to_fit() para más detalles.
  • El arrastrar y soltar ahora se puede activar suscribiéndose a la señal "dnd-start" y llamando a "$view->drag_begin_with_coordinates()" desde el manejador. drag_source_set() no funcionará.
  • "Gtk2::ImageView::ScrollWin" el reemplazo aún no está implementado.
  • set_transp() ahora está disponible a través de CSS https://developer.gnome.org/gtk3/stable/chap-css-overview.html en su lugar, por ejemplo, a través de 
    .imageview.transparent {
    background-image: url('checkers.svg');
}
  • set_interpolation() ahora acepta "cairo_filter_t" https://www.cairographics.org/manual/cairo-cairo-pattern-t.html#cairo-filter-t en lugar de "GdkInterpType" https://developer.gnome.org/gdk-pixbuf/stable/gdk-pixbuf-Scaling.html#GdkInterpType.
