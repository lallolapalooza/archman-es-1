DESCRIPCIÓ

N

GD::Simple es una subclase de la biblioteca GD que acorta muchas de las llamadas largas a los métodos de GD almacenando información sobre el color, tamaño y posición del lápiz en el propio objeto GD. También añade un pequeño número de llamadas de estilo "gráficos de tortuga" para quienes prefieren trabajar en coordenadas polares. Además, la biblioteca permite usar nombres simbólicos para los colores, como "chartreuse", y gestionará los colores por

ti.

Método

s

GD::Simple introduce un número de nuevos métodos, algunos de los cuales tienen el mismo nombre que los métodos de GD::Image y, por lo tanto, cambian su comportamiento. Además de estos nuevos métodos, los objetos GD::Simple admiten todos los métodos de GD::Image. Si haces una llamada a un método que GD::Simple no admite directamente, remite la solicitud al objeto GD::Image subyacente. Así se puede cargar una imagen JPEG en GD::Simple y declararla como TrueColor usando esta llamada, que se hereda efectivamente de GD::

Image: 
my $img = GD::Simple->newFromJpeg('./myimage.jpg',1)

GD::Simple(3pm)

NAME

GD::Simple - A simpler interface to the GD graphics library

SYNOPSIS

    use GD::Simple;
    my $img = GD::Simple->new(400,200);
    $img->bgcolor('lightblue');
    $img->fgcolor('darkblue');
    $img->string(20,30,'Hello World!');
    $img->line(0,0,400,200);
    print $img->png;

DESCRIPTION

This module provides a simpler, more object-oriented interface to the GD graphics library than the standard GD.pm module. It handles the creation and destruction of the GD::Image object implicitly. It also provides convenience methods for common operations.

All methods that draw on the image are automatically translated to the internal GD::Image object. This object is created with either GD::Simple->new() or GD::Simple->newWith(width, height) and destroyed automatically when the object goes out of scope.

$img->polyline($poly)
Este método dibuja polígonos sin cerrar los vértices primero y último (similar a GD::Image->unclosedPolygon()). Utiliza el color de primer plano para dibujar la línea.
$img->string($string)
Este método dibuja la cadena indicada comenzando en la posición actual del cursor. El cursor se mueve al final de la cadena dibujada. Dependiendo de la fuente seleccionada con el método font(), se usará una fuente GD de mapa de bits o una fuente TrueType. Se consultará el ángulo del cursor al dibujar el texto. Para fuentes TrueType, se acepta cualquier ángulo. Para fuentes GD de mapa de bits, el ángulo puede ser 0 (dibujar horizontalmente) o -90 (dibujar hacia arriba).

Para mantener la consistencia entre el comportamiento de las fuentes TrueType y GD, la cadena siempre se dibuja de manera que la posición actual del cursor corresponda a la parte inferior izquierda del primer carácter del texto. Esto es diferente del comportamiento de GD, en el cual el primer carácter de las fuentes de mapa de bits cuelga de la posición del cursor.

Este método devuelve un polígono que indica el cuadro delimitador del texto renderizado. Si ocurrió un error (como una especificación de fuente inválida), devuelve undef y un mensaje de error en $@.

$metrics = $img->fontMetrics
($metrics,$width,$height) = GD::Simple->fontMetrics($font,$fontsize,$string)
Este método devuelve información sobre la fuente actual, más comúnmente una fuente TrueType. Se puede invocar como un método de instancia (en un objeto GD::Simple previamente creado) o como un método de clase (en la clase 'GD::Simple').

Cuando se llama como un método de instancia, fontMetrics() no toma argumentos y devuelve una referencia de hash única que contiene las métricas que describen la fuente y el tamaño actualmente seleccionados. La referencia de hash contiene la siguiente información:

xheight      la altura base de la fuente desde la parte inferior hasta la superior
             de una 'm' en minúscula
ascent       la longitud del tallo superior de la 'd' en minúscula
descent      la longitud del tallo inferior de la 'j' en minúscula
lineheight   la distancia desde la parte inferior de la 'j' hasta la superior
             de la 'd'
leading      la distancia entre dos líneas adyacentes

Esta descripción y código se modificaron con la versión 2.75.

($delta_x,$delta_y)= $img->stringBounds($string)
Este método indica los desplazamientos X e Y (que pueden ser negativos) que ocurrirán cuando la cadena dada se dibuje utilizando la fuente, el tamaño de fuente y el ángulo actuales. Cuando la cadena se dibuja horizontalmente, indica el ancho y la altura del cuadro delimitador de la cadena.
$delta_x = $img->stringWidth($string)
Este método indica el ancho de la cadena dada la fuente, el tamaño de fuente y el ángulo actuales. Es lo mismo que ($img->stringBounds($string))[0]
($x,$y) = $img->curPos
Devuelve la posición actual del cursor. Establezca la posición actual usando moveTo().
$font = $img->font([$newfont] [,$newsize])
Obtiene o establece la fuente actual. Las fuentes pueden ser objetos GD::Font, rutas de archivos de fuentes TrueType o patrones de fuentes de fontconfig como "Times:italic" (ver fontconfig). Esta última función requiere que tenga la biblioteca fontconfig instalada y esté utilizando la versión 2.0.33 o superior de libgd.

Como atajo, puede pasar dos argumentos para establecer la fuente y el tamaño de fuente simultáneamente. El tamaño de fuente solo es válido al dibujar con fuentes TrueType.

$size = $img->fontsize([$newfontsize])
Obtiene o establece el tamaño de fuente actual. Esto solo es válido para fuentes TrueType.
$size = $img->penSize([$newpensize])
Obtiene o establece el ancho del lápiz actual para su uso durante las operaciones de dibujo de líneas.
$angle = $img->angle([$newangle])
Establece el ángulo actual para usarlo al llamar a line() o move() con un solo argumento.

Aquí hay un ejemplo de uso de turn() y angle() juntos para dibujar un octágono. La primera línea dibujada es el borde superior derecho inclinado hacia abajo. La última línea dibujada es la parte superior horizontal del octágono.

$img->moveTo(200,50);
$img->angle(0);
$img->turn(360/8);
for (1..8) { $img->line(50) }
$angle = $img->turn([$newangle])
Obtiene o establece el ángulo actual para girar antes de dibujar líneas. Este valor solo se utiliza al llamar a line() o move() con un solo argumento. El ángulo de giro se aplicará a cada llamada a line() o move() justo antes de que ocurra el dibujo real.

Los ángulos están en grados. Los valores positivos giran el ángulo en sentido horario.

$color = $img->fgcolor([$newcolor])
Obtiene o establece el color de primer plano del lápiz. El color actual del lápiz se puede establecer (1) usando un triple (r,g,b); (2) usando un color previamente asignado de la paleta GD; o (3) usando un nombre de color simbólico como "chartreuse". La lista de nombres de colores se puede obtener usando color_names(). El nombre de color especial 'transparent' creará un color completamente transparente.
$color = $img->bgcolor([$newcolor])
Obtiene o establece el color de fondo del lápiz. El color actual del lápiz se puede establecer (1) usando un triple (r,g,b); (2) usando un color previamente asignado de la paleta GD; o (3) usando un nombre de color simbólico como "chartreuse". La lista de nombres de colores se puede obtener usando color_names(). El nombre de color especial 'transparent' creará un color completamente transparente.
$index = $img->translate_color(@args)
Traduce un color a un índice de paleta GD o TrueColor. Puede pasar un triple (r,g,b) o un nombre de color simbólico. Si pasa un índice previamente asignado, el método lo devolverá sin cambios.
$index = $img->alphaColor(@args,$alpha)
Crea un color alfa. Puede pasar un triple (r,g,b) o un nombre de color simbólico, seguido de un entero que indica su opacidad. El valor de opacidad varía de 0 (totalmente opaco) a 127 (totalmente transparente).
@names = GD::Simple->color_names
$translate_table = GD::Simple->color_names
Cuando se llama en un contexto de lista, color_names() devuelve la lista de nombres de colores simbólicos reconocidos por este módulo. Cuando se llama en un contexto escalar, el método devuelve una referencia de hash en la que las claves son los nombres de los colores y los valores son referencias de arreglos que contienen triples [r,g,b].
$gd = $img->gd
Devuelve el objeto GD::Image interno. Por lo general, no necesitará llamar a esto, ya que todos los métodos GD se refieren automáticamente a este objeto.
($red,$green,$blue) = GD::Simple->HSVtoRGB($hue,$saturation,$value)
Convierte un color de Tono/Saturación/Valor (HSV) a un triple RGB. El tono, la saturación y el valor son enteros de 0 a 255.
($hue,$saturation,$value) = GD::Simple->RGBtoHSV($red,$green,$blue)
Convierte un valor de Rojo/Verde/Azul (RGB) a un triple de Tono/Saturación/Valor (HSV). El tono, la saturación y el valor son enteros de 0 a 255.

COLORES

Este script creará una imagen que muestra todos los colores simbólicos.

#!/usr/bin/perl
use strict;
use GD::Simple;
my @color_names = GD::Simple->color_names;
my $cols = int(sqrt(@color_names));
my $rows = int(@color_names/$cols)+1;
my $cell_width    = 100;
my $cell_height   = 50;
my $legend_height = 16;
my $width       = $cols * $cell_width;
my $height      = $rows * $cell_height;
my $img = GD::Simple->new($width,$height);
$img->font(gdSmallFont);
for (my $c=0; $c<$cols; $c++) {
  for (my $r=0; $r<$rows; $r++) {
    my $color = $color_names[$c*$rows + $r] or next;
    my @topleft  = ($c*$cell_width,$r*$cell_height);
    my @botright = ($topleft[0]+$cell_width,$topleft[1]+$cell_height-$legend_height);
    $img->bgcolor($color);
    $img->fgcolor($color);
    $img->rectangle(@topleft,@botright);
    $img->moveTo($topleft[0]+2,$botright[1]+$legend_height-2);
    $img->fgcolor('black');
    $img->string($color);
  }
}
print $img->png;
