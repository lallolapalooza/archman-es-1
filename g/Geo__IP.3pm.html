DESCRIPCIÓ

N

Este módulo utiliza la base de datos basada en archivos GeoIP Legacy. Esta base de datos simplemente contiene bloques IP como claves y países como valores. Esta base de datos debería ser más completa y precisa que las búsquedas DNS

inversas.

Este módulo se puede utilizar para seleccionar automáticamente el espejo geográficamente más cerc

ano, para analizar los registros de su servidor web y determinar los países de sus visitantes, par
a la detección de fraude con tarjetas de crédito y para los controles de exportación de software.

USO DE LA GEOLOCALIZACIÓN

IP

La geolocalización IP es inherentemente imprecisa. Las ubicaciones a menudo están cerca

del centro de la población. Cualquier ubicación proporcionada por una base de datos GeoIP o
servicio web no debe utilizarse para identificar una dirección o hogar en particular.

CLASE
$gi = Geo::IP->new( $flags
);
Construye un nuevo objeto Geo::IP con la base de datos predeterminada ubicada dentro de su datadir del sistema, típicamente /usr/local/share/GeoIP/GeoIP.dat.

Los indicadores se pueden establecer en GEOIP_STANDARD, o para un rendimiento más rápido (a costa de usar más memoria), GEOIP_MEMORY_CACHE. Cuando usa la caché de memoria, puede forzar una recarga si el archivo se actualiza estableciendo GEOIP_CHECK_CACHE. GEOIP_INDEX_CACHE almacena en caché la parte de índice de la base de datos más frecuentemente accedida, lo que resulta en búsquedas más rápidas que GEOIP_STANDARD, pero con menos uso de memoria que GEOIP_MEMORY_CACHE - útil para bases de datos más grandes como GeoIP Legacy Organization y GeoIP City. Tenga en cuenta, para las bases de datos de País, Región y Netspeed de GeoIP, GEOIP_INDEX_CACHE es equivalente a

GEOIP_MEMORY_CACHE.

Antes de la versión 1.6.3 de geoip-api, la API C filtraba mensajes de diagnóstico en stderr incondicionalmente. Desde Geo::IP v1.44 en adelante, el indicador que silencia este comportamiento (GEOIP_SILENCE) se añade implícitamente a los indicadores pasados en new(), open(), y open_typ

e().

Para combinar indicadores, use el operador OR a nivel de bits, |. Por ejemplo, para almacenar la base de datos en memoria, pero comprobar si hay un archivo GeoIP.dat actualizado, use: Geo::IP->new( GEOIP_MEMORY_CACHE | GEOIP_CHECK_CACHE
