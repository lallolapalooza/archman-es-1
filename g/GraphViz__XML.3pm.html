GraphViz__XML(3pm)

Paquete: perl-graphviz

Licencias: GPL, PerlArtistic

GraphViz::XML(3) Documentación de Perl contribuida por el usuario GraphViz::XML(3)

NOMBRE

GraphViz::XML - Visualiza XML como un árbol

SINOPSIS

use GraphViz::XML;
my $graph = GraphViz::XML->new($xml);
print $g->as_png;

DESCRIPCIÓN

Este módulo facilita la visualización de XML como un árbol. El XML es difícil de comprender para los humanos, especialmente si el XML es generado por computadora. Este módulo tiene como objetivo visualizar el XML como un grafo para que la estructura del XML sea clara y ayude a comprender el XML.

Los elementos XML se representan como nodos romboidales, con enlaces a los elementos dentro de ellos. Los datos de caracteres se representan en nodos redondos.

Tenga en cuenta que el módulo XML::Twig debe estar instalado.

MÉTODOS

new

Este es el constructor. Toma un argumento obligatorio, que es el XML a visualizar. Se devuelve un objeto GraphViz.

my $graph = GraphViz::XML->new($xml);

as_*

El XML se puede visualizar en varios formatos gráficos diferentes. Los métodos incluyen as_ps, as_hpgl, as_pcl, as_mif, as_pic, as_gd, as_gd2, as_gif, as_jpeg, as_png, as_wbmp, as_ismap, as_imap, as_vrml, as_vtx, as_mp, as_fig, as_svg. Consulte la documentación de GraphViz para obtener más información. Los dos métodos más comunes son:

# Imprimir un archivo en formato PNG
print $g->as_png;
# Imprimir un archivo en formato PostScript
print $g->as_ps;

ERRORES

GraphViz tiende a reordenar los nodos. Espero encontrar una solución pronto (posiblemente con puertos).
