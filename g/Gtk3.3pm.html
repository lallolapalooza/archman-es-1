RESUME

N

Enlaces de Perl para la serie 3.x del conjunto de herramientas gtk+. Este módulo le permite escribir inte

rfaces gráficas de usuario de una manera orientada a objetos y al estilo de Perl, liberándolo de la conv
ersión de tipos y la gestión de memoria en C, pero manteniéndose muy fiel al espíritu de la API original.

DESCRIPCIÓ

N

El módulo "Gtk3" permite a un desarrollador de Perl usar la biblioteca de interfaz gráfica de usuario gtk+. Obtenga más información sobre gtk+ en http://www.gt

k.org.

El manual de referencia de gtk+ también es un compañero útil al escribir programas "Gtk3" en Perl: http://developer.gnome.org/gtk3/stable/. Los enlaces de Perl siguen muy de cerca la API de C, y la documentación de referencia de C debe considerarse la fuente canónica. Los principios subyacentes al mapeo de C a Perl se explican en la documentación de Glib::Object::Introspection, sobre la cual "Gtk3" está

basada.

Glib::Object::Introspection también incluye el programa "perli11ndoc", que muestra la documentación de referencia de la API de todas las bibliotecas instaladas, organizada de acuerdo con estos

principios.
