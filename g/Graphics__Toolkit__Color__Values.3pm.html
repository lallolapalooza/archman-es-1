Graphics::Toolkit::Color::Values(3) Documentación aportada por el usuario Graphics::Toolkit::Color::Values(3)

NOMBRE

Graphics::Toolkit::Color::Value - métodos de alto nivel relacionados con un solo color

SINOPSIS

Objeto de solo lectura que contiene los valores de un color. Proporciona métodos para obtener los valores de vuelta en diferentes formatos, para medir la diferencia con otros colores o para crear objetos de valores de colores relacionados.

use Graphics::Toolkit::Color::Value;
my $blue = Graphics::Toolkit::Color::Value->new( 'hsl(220,50,60)' );
my @rgb = $blue->get();
my $purple = $blue->set({red => 220});

DESCRIPCIÓN

El objeto que contiene los valores normalizados de la definición original del color (argumento del getter) y la terna RGB normalizada, si el color no fue definido en valores RGB. De esta manera evitamos en la medida de lo posible los errores de conversión y de redondeo.

Este paquete es una capa de mediación entre Graphics::Toolkit::Color::Space::Hub abajo, donde solo se trata de hacer cálculos numéricos con vectores de valores, y la API de usuario arriba en Graphics::Toolkit::Color, donde se trata principalmente de producir conjuntos de colores y manejar los argumentos. Este módulo no está destinado a ser usado como una API pública ya que tiene mucho menos confort que Graphics::Toolkit::Color.

MÉTODOS

new

El constructor toma solo un argumento requerido, un escalar que define completamente y numéricamente un color. Dentro de las definiciones de color, los nombres de los espacios de color no distinguen entre mayúsculas y minúsculas. Algunos formatos posibles son

[ 1, 2, 3 ]                  # Terna RGB
[ HSL => 220, 100, 3 ]       # Vector HSL con nombre
{ h => 220, s =>100, l => 3} # Hash de caracteres
{ cyan => 1, magenta => 0.5, yellow => 0} # Hash
'hwb: 20, 60, 30'            # Cadena
'hwb(20,60,30)'              # css_string
'#2211FF'                    # Cadena hexadecimal rgb

get

Método getter universal - casi la función inversa a new: puede devolver los valores del color en todos los espacios de color soportados (primer argumento) (ver: "COLOR-SPACES" en Graphics::Toolkit::Color::Space::Hub) y todos los formatos mencionados arriba (segundo argumento). Adicionalmente, un tercer argumento puede convertir los valores numéricos en diferentes rangos. El espacio de nombres por defecto es RGB, el formato por defecto es una lista y cada espacio de color tiene su rango por defecto.

my @rgb = $val_object->get();
my @cmyk = $val_object->get('CMYK', 'list', 255);
my $YIQ = $val_object->get('YIQ', 'string');

set

Construye un nuevo "Graphics::Toolkit::Color::Value" objeto cambiando absolutamente algunos valores del objeto actual y manteniendo otros. (add cambia algunos valores relativamente.) El único y requerido argumento es una HASH referencia que tiene claves que coinciden solo con uno de los espacios de color soportados (ver: "COLOR-SPACES" en Graphics::Toolkit::Color::Space::Hub). Los valores fuera de los límites definidos serán limitados a un valor aceptable (o rotados en el caso de dimensiones circulares).

my $more_blend_color = $val_object->set( {saturation => 40} );
my $bright_color = $val_object->set( {saturation => 2240} ); #la saturación será 100

add

Este método también toma una referencia HASH como entrada y también produce un objeto de color relacionado como el anterior set. La única diferencia es: los valores del hash se añadirán a los actuales. Si salen de los límites definidos, serán limitados (o rotados en el caso de dimensiones circulares).

my $darker_color = $val_object->set( {lightness => -10} );

blend

Crea un objeto de valor de color mezclando dos colores. El primer y único argumento requerido es el segundo objeto de valor de color. El segundo argumento es la proporción de mezcla. Cero resultaría en el color original y uno en el segundo color. El valor por defecto es 0.5 (mezcla 1:1). Los valores fuera del rango 0..1 son posibles y los valores serán limitados si dejan los límites definidos del espacio de color requerido.

El tercer argumento opcional es el nombre del espacio de color en el que la mezcla será calculada - por defecto es 'HSL'.

my $green = Graphics::Toolkit::Color::Values->new( '#00ff00' );
my $cyan = $blue->blend( $green, 0.6, 'YIQ' );

distance

Calcula un número real que designa la distancia (euclidiana) entre dos puntos en un espacio de color (también conocidos como colores).

El primer y único argumento requerido es el segundo color como un Graphics::Toolkit::Color::Value objeto. El segundo y opcional argumento es el nombre del espacio de color, donde la distancia es calculada (por defecto es 'HSL'). El tercer argumento es la métrica, que actualmente es solo el subconjunto de dimensiones en el espacio elegido que debe ser observado. Uno puede también mencionar el nombre abreviado de una dimensión varias veces para aumentar su peso en el cálculo. El cuarto argumento opcional son los rangos numéricos de las dimensiones. Si no se dan ninguno, el método solo usa valores normalizados (rango: 0..1).

my $blue = Graphics::Toolkit::Color::Values->new( '#0000ff' );
my $green = Graphics::Toolkit::Color::Values->new( '#00ff00' );
my $d = $blue->distance( $green, 'HSV', 's', 255); # 0 : ambas tienen la misma saturación
