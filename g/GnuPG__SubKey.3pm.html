GnuPG::SubKey(3) Documentación de Perl contribuida por el usuario GnuPG::SubKey(3)

NOMBRE

GnuPG::SubKey - Objetos de Subclave GnuPG

SINOPSIS

# asume un objeto GnuPG::PublicKey en $key
my @subkeys = $key->subkeys();
# ahora los objetos GnuPG::SubKey están en @subkeys

DESCRIPCIÓN

Los objetos GnuPG::SubKey generalmente se instancian a través de varios métodos de GnuPG::Interface. Encarnan varios aspectos de una subclave GnuPG.

Este paquete hereda miembros de datos y métodos de objeto de GnuPG::Key, que no se describen aquí, sino en GnuPG::Key.

MIEMBROS DE DATOS DEL OBJETO

validez
Un escalar que contiene el valor que GnuPG informa para la confianza de autenticidad (también conocida como) validez de una clave. Ver el archivo DETAILS de GnuPG para más detalles.
id_local
El id local de GnuPG para la clave.
confianza_propietario
El valor escalar que GnuPG informa como confianza_propietario para esta clave. Ver el archivo DETAILS de GnuPG para más detalles.
firma
* OBSOLETO*

Un objeto GnuPG::Signature que contiene la representación de la firma en esta clave. Por favor, use firmas (ver GnuPG::Key) en lugar de firma. Usando firma, obtendrá una firma arbitraria del conjunto de firmas disponibles.

VER TAMBIÉN

GnuPG::Key, GnuPG::Signature,
