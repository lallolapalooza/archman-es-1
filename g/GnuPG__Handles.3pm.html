GnuPG::Handles(3) Documentación de Perl aportada por el usuario GnuPG::Handles(3)

NOMBRE

GnuPG::Handles - Paquete de identificadores GnuPG

SINOPSIS

use IO::Handle;
my ( $stdin, $stdout, $stderr,
     $status_fh, $logger_fh, $passphrase_fh,
   )
  = ( IO::Handle->new(), IO::Handle->new(), IO::Handle->new(),
      IO::Handle->new(), IO::Handle->new(), IO::Handle->new(),
    );
my $handles = GnuPG::Handles->new
  ( stdin      => $stdin,
    stdout     => $stdout,
    stderr     => $stderr,
    status     => $status_fh,
    logger     => $logger_fh,
    passphrase => $passphrase_fh,
  );

DESCRIPCIÓN

Los objetos GnuPG::Handles generalmente se instancian para ser utilizados junto con los métodos de los objetos de la clase GnuPG::Interface. Los objetos GnuPG::Handles representan una colección de identificadores que se utilizan para comunicarse con GnuPG.

Métodos de inicialización

new( %argumentos_de_inicialización )

MIEMBROS DE DATOS DE OBJETO

stdin
Este identificador está conectado a la entrada estándar de un proceso GnuPG.
stdout
Este identificador está conectado a la salida estándar de un proceso GnuPG.
stderr
Este identificador está conectado al error estándar de un proceso GnuPG.
status
Este identificador está conectado al identificador de salida de estado de un proceso GnuPG.
logger
Este identificador está conectado al identificador de salida del registrador de un proceso GnuPG.
passphrase
Este identificador está conectado al identificador de entrada de contraseña de un proceso GnuPG.
command
Este identificador está conectado al identificador de entrada de comandos de un proceso GnuPG.
options
Este es un hash de hashes de configuración relacionados con los identificadores de este objeto. El hash de nivel superior está indexado por los nombres del identificador al que se aplica la configuración, mientras que el interior está indexado por la configuración que se está referenciando. Por ejemplo, para establecer la configuración "direct" en verdadero para el identificador de archivo "stdin", el siguiente código lo hará: 
# asumiendo que $handles es un objeto
# GnuPG::Handles ya creado, esto establece todas las
# configuraciones para el identificador de archivo stdin de golpe,
# limpiando todas las demás
$handles->options( 'stdin', { direct => 1 } );
# esto es útil para hacer solo un cambio
# al conjunto de configuraciones para un identificador
$handles->options( 'stdin' )->{direct} = 1;
# y para obtener la configuración...
$setting = $handles->options( 'stdin' )->{direct};
# y para limpiar las configuraciones para stdin
$handles->options( 'stdin', {} );

Las configuraciones actualmente en uso son las siguientes:

direct
Si la configuración "direct" es verdadera para un identificador, el proceso GnuPG generado accederá directamente al identificador. Esto es útil para que el proceso GnuPG lea o escriba directamente desde o hacia un archivo ya abierto.
