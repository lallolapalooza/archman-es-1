Geo::IP::Record(3) Documentación de Perl contribuida por el usuario Geo::IP::Record(3)

NOMBRE

Geo::IP::Record - Contiene información de ciudad para GeoIP Legacy City Edition

SINOPSIS

use Geo::IP;
my $gi = Geo::IP->open("/usr/local/share/GeoIP/GeoIPCity.dat", GEOIP_STANDARD);
my $record = $gi->record_by_addr('24.24.24.24');
print $record->country_code,
  $record->country_code3,
  $record->country_name,
  $record->region,
  $record->region_name,
  $record->city,
  $record->postal_code,
  $record->latitude,
  $record->longitude,
  $record->time_zone,
  $record->area_code,
  $record->continent_code,
  $record->metro_code;

DESCRIPCIÓN

Geo::IP::Record representa objetos que contienen información de ubicación devuelta por la base de datos GeoIP Legacy City. Funciona tanto con las bases de datos comerciales GeoIP Legacy City como con las gratuitas GeoLite Legacy City.

MÉTODOS DE OBJETO

$code = $record->country_code;
Devuelve el código de país ISO 3166 del objeto de ubicación.
$code3 = $record->country_code3;
Devuelve el código de país de 3 letras ISO 3166 del objeto de ubicación.
$name = $record->country_name;
Devuelve el nombre del país del objeto de ubicación.
$region = $record->region;
Devuelve el código de región del objeto de ubicación.
$region = $record->region_name;
Devuelve el nombre de la región del objeto de ubicación.
$city = $record->city;
Devuelve la ciudad del objeto de ubicación.
$postal_code = $record->postal_code;
Devuelve el código postal del objeto de ubicación.
$lat = $record->latitude;
Devuelve la latitud aproximada de la ubicación asociada a la dirección IP. Este valor no es preciso y no debe utilizarse para identificar una dirección o hogar en particular.
$lon = $record->longitude;
Devuelve la longitud aproximada de la ubicación asociada a la dirección IP. Este valor no es preciso y no debe utilizarse para identificar una dirección o hogar en particular.
$time_zone = $record->time_zone;
Devuelve la zona horaria del objeto de ubicación.
$area_code = $record->area_code;
Devuelve el código de área del objeto de ubicación (solo para ubicaciones dentro de EE. UU. a nivel de ciudad)
$metro_code = $record->metro_code;
Devuelve el código de metropolitano del objeto de ubicación (solo para ubicaciones dentro de EE. UU. a nivel de ciudad)
$continent_code = $record->continent_code;
Devuelve el código de continente del objeto de ubicación.
Los códigos de continente posibles son AF, AS, EU, NA, OC, SA para África, Asia, Europa, América del Norte, Oceanía y América del Sur.
