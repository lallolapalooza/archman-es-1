NOMBRE

GeoIP.conf - Archivo de configuración para geoipupdate

SINOPSIS

Este archivo te permite configurar tu programa geoipupdate para descargar bases de datos GeoIP2 y GeoLite2.

DESCRIPCIÓN

El archivo consiste en una configuración por línea. Las líneas que comienzan con # son comentarios y no serán procesadas. Todas las palabras clave de configuración distinguen entre mayúsculas y minúsculas.

Configuraciones requeridas:

AccountID
Tu ID de cuenta de MaxMind. Anteriormente conocido como UserId. Esto puede ser anulado en tiempo de ejecución por las variables de entorno GEOIPUPDATE_ACCOUNT_ID o GEOIPUPDATE_ACCOUNT_ID_FILE.
LicenseKey
Tu clave de licencia de MaxMind sensible a mayúsculas y minúsculas. Esto puede ser anulado en tiempo de ejecución por las variables de entorno GEOIPUPDATE_LICENSE_KEY o GEOIPUPDATE_LICENSE_KEY_FILE.
EditionIDs
Lista de IDs de edición de base de datos separados por espacios. Los IDs de edición pueden consistir en letras, dígitos y guiones. Por ejemplo, GeoIP2-City descargaría la base de datos GeoIP2 City (GeoIP2-City). Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_EDITION_IDS. Nota: anteriormente se llamaba ProductIds.

Configuraciones opcionales:

DatabaseDirectory
El directorio donde se almacenarán los archivos de base de datos. Si no se establece, el valor predeterminado es /var/lib/GeoIP. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_DB_DIR o el argumento de línea de comandos -d.
Host
El nombre del host del servidor a utilizar. El valor predeterminado es https://updates.maxmind.com. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_HOST.
Proxy
El nombre de host o dirección IP del proxy. Opcionalmente, puedes especificar un número de puerto, por ejemplo, 127.0.0.1:8888. Si no se especifica ningún número de puerto, se utilizará 1080. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_PROXY.
ProxyUserPassword
El nombre de usuario y la contraseña del proxy, separados por dos puntos. Por ejemplo, usuario:contraseña. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_PROXY_USER_PASSWORD.
PreserveFileTimes
Si se deben conservar las horas de modificación de los archivos descargados del servidor. Esta opción es 0 o 1. El valor predeterminado es 0. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_PRESERVE_FILE_TIMES.
LockFile
El archivo de bloqueo a utilizar. Esto garantiza que solo un proceso geoipupdate pueda ejecutarse a la vez. Nota: una vez creado, este archivo de bloqueo no se elimina del sistema de archivos. El valor predeterminado es .geoipupdate.lock bajo el DatabaseDirectory. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_LOCK_FILE.
RetryFor
El tiempo de reintento cuando se encuentran errores durante las transacciones HTTP. Se puede especificar como un número decimal (posiblemente fraccionario) seguido de un sufijo de unidad. Las unidades de tiempo válidas son ns, us (o µs), ms, s, m, h. El valor predeterminado es 5m (5 minutos). Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_RETRY_FOR.
Parallelism
El número máximo de descargas de bases de datos en paralelo. El valor predeterminado es 1, lo que significa que las bases de datos se descargarán secuencialmente. Esto puede ser anulado en tiempo de ejecución por la variable de entorno GEOIPUPDATE_PARALLELISM o el argumento de línea de comandos --parallelism.

Configuraciones obsoletas:

Las siguientes están obsoletas y se ignorarán si están presentes:

Protocol

SkipPeerVerification

SkipHostnameVerification
