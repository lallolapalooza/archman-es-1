Glib::Utils(3) Documentación de Perl aportada por el usuario Glib::Utils(3)

NOMBRE

Glib::Utils - Funciones utilitarias diversas

SINOPSIS

use Glib;
Glib::set_application_name (Glib::get_real_name."'s Cool Program");
print "app name is ".Glib::get_application_name()."\n";

DESCRIPCIÓN

Aquí hay algunas utilidades diversas útiles. GLib es una biblioteca de portabilidad, que proporciona funciones utilitarias portables para programas en C. Como tal, la mayoría de estas funciones parecen violar el principio de enlace de Glib de no duplicar funcionalidad que Perl ya proporciona, pero hay una distinción para cada una, se lo juro. Las funciones para tratar con información de usuario se proporcionan en todas las plataformas soportadas por GLib, no solo donde POSIX (que proporciona información similar) está disponible, e incluso funcionan en plataformas donde %ENV puede no incluir la información esperada. Además, el "nombre de aplicación" al que se refiere (set|get)_application_name es un nombre legible para humanos, distinto del nombre real del programa proporcionado por el propio Perl $0.

MÉTODOS

string = Glib::get_application_name

Obtiene el nombre de aplicación legible para humanos establecido por "set_application_name".

Desde: glib 2.2

Glib::set_application_name ($application_name)

•
$application_name (string)

Establece el nombre de aplicación legible para humanos.

Desde: glib 2.2

string = Glib::get_home_dir

Encuentra el directorio personal del usuario actual, por medios dependientes del sistema/apropiados.

list = Glib::get_language_names

Calcula una lista de nombres de configuración regional aplicables, que pueden usarse para construir nombres de archivo o rutas de búsqueda dependientes de la configuración regional. La lista devuelta está ordenada de la más deseable a la menos deseable y siempre contiene la configuración regional predeterminada "C".

Desde: glib 2.6

string = Glib::get_prgname

Glib::set_prgname ($prgname)

•
$prgname (string)

string = Glib::get_real_name

Obtiene el nombre real del usuario actual.

string = Glib::strerror ($err)

•
$err (integer)

Devuelve una cadena que describe el valor de errno dado, como "No such file or directory" para ENOENT. Esto se traduce al idioma preferido del usuario y es una cadena utf8 de caracteres anchos (a diferencia de una cadena $! (perlvar) o POSIX::strerror (POSIX) que son bytes del codeset de la configuración regional).

string = Glib::strsignal ($signum)

•
$signum (integer)

Devuelve una cadena que describe el número de señal dado, como "Segmentation violation" para SIGSEGV. Esto se traduce al idioma preferido del usuario y es una cadena utf8 de caracteres anchos.

list = Glib::get_system_config_dirs

Devuelve una lista ordenada de directorios base en los que acceder a información de configuración de todo el sistema.

Desde: glib 2.6

list = Glib::get_system_data_dirs

Devuelve una lista ordenada de directorios base en los que acceder a datos de aplicación de todo el sistema.

Desde: glib 2.6

string = Glib::get_tmp_dir

Obtiene el directorio temporal apropiado para el sistema actual. Consulte la documentación de GLib para obtener información sobre cómo funciona.

string = Glib::get_user_cache_dir

Obtiene el directorio base en el que almacenar datos no esenciales, en caché específicos de un usuario particular.

Desde: glib 2.6

string = Glib::get_user_config_dir

Obtiene el directorio base en el que almacenar información de configuración de aplicación específica del usuario, como preferencias y ajustes del usuario.

Desde: glib 2.6

string = Glib::get_user_data_dir

Obtiene el directorio base para datos de aplicación como iconos que está personalizado para un usuario particular.

Desde: glib 2.6

string = Glib::get_user_name

Obtiene el nombre del usuario actual por los medios dependientes del sistema que sean necesarios.

string = Glib::get_user_special_dir ($directory)

•
$directory (Glib::UserDirectory)

Devuelve la ruta completa de un directorio especial usando su id lógico.

Desde: glib 2.14
