Getopt::Long::Parser(3perl) Guía de referencia para programadores de Perl Getopt::Long::Parser(3perl)

NOMBRE

Getopt::Long::Parser - Interfaz orientada a objetos para Getopt::Long

SINOPSIS

use Getopt::Long::Parser;
my $p = Getopt::Long::Parser->new;
$p->configure( %options );
if ( $p->getoptions( @options ) ) { ... }
if ( $p->getoptionsfromarray( \@array, @options ) ) { ... }

Las opciones de configuración se pueden pasar al constructor:

my $p = Getopt::Long::Parser->new( config => [ %options ] );

DESCRIPCIÓN

"Getopt::Long::Parser" es una interfaz orientada a objetos para Getopt::Long. Consulte su documentación para obtener información sobre la configuración y el uso.

Tenga en cuenta que "Getopt::Long" y "Getopt::Long::Parser" no son orientadas a objetos. "Getopt::Long::Parser" emula una interfaz orientada a objetos, lo que debería estar bien para la mayoría de los propósitos.

CONSTRUCTOR

my $p = Getopt::Long::Parser->new( %options );

El constructor toma un hash opcional con parámetros.

config
Una referencia a un array con configuraciones. Consulte "Configuring Getopt::Long" en Getopt::Long para conocer todas las configuraciones posibles.

MÉTODOS

En los ejemplos, se asume que $p es el resultado de una llamada al constructor.

configure

$p->configure( %settings );

Actualiza la configuración actual. Consulte "Configuring Getopt::Long" en Getopt::Long para conocer todas las configuraciones posibles.

getoptionsfromarray

my $res = $p->getoptionsfromarray( $aref, @opts );

getoptions

my $res = $p->getoptions( @opts );

Lo mismo que "getoptionsfromarray( \@ARGV, @opts )".
