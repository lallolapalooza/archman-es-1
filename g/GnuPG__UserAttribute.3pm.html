GnuPG::UserAttribute(3) Documentación de Perl aportada por el usuario GnuPG::UserAttribute(3)

NOMBRE

GnuPG::UserAttribute - Objetos de Atributo de Usuario de GnuPG

SINOPSIS

# asume un objeto GnuPG::PublicKey en $publickey
my $jpgs_size = $publickey->user_attributes->[0]->subpacket_total_size();

DESCRIPCIÓN

Los objetos GnuPG::UserAttribute generalmente no se instancian por sí solos, sino como parte de objetos GnuPG::PublicKey o GnuPG::SecretKey.

MÉTODOS DEL OBJETO

nuevo( %argumentos_inicialización )
Este método crea un nuevo objeto. Los argumentos opcionales son la inicialización de los miembros de datos;

MIEMBROS DE DATOS DEL OBJETO

validez
Un escalar que contiene el valor que GnuPG informa para la validez calculada de la vinculación entre este paquete de Atributo de Usuario y su clave primaria asociada. Consulte el archivo DETAILS de GnuPG para obtener más detalles.
conteo_subpaquetes
Un escalar que contiene el número de subpaquetes de atributos. Este suele ser 1, ya que la mayoría de los UAT que se ven en la práctica contienen una sola imagen en formato JPEG.
tamaño_total_subpaquetes
Un escalar que contiene el recuento total de bytes de todos los subpaquetes de atributos.
firmas
Una lista de objetos GnuPG::Signature que representan las firmas en este atributo de usuario.
revocaciones
Una lista de revocaciones asociadas con este Atributo de Usuario, almacenadas como objetos GnuPG::Signature (ya que las revocaciones son un tipo de certificación también).

ERRORES

Aún no se proporciona información útil sobre los atributos incrustados. Sería bueno poder acceder al material JPEG sin procesar.
