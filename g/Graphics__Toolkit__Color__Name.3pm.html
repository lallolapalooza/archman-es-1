Graphics::Toolkit::Color::Name(3) Documentación de Perl aportada por el usuario Graphics::Toolkit::Color::Name(3)

NOMBRE

Graphics::Toolkit::Color::Name - acceder a los valores de las constantes de color

SINOPSIS

use Graphics::Toolkit::Color::Name qw/:all/;
my @names = Graphics::Toolkit::Color::Name::all();
my @rgb  = rgb_from_name('darkblue');
my @hsl  = hsl_from_name('darkblue');
Graphics::Toolkit::Color::Value::add_rgb('lucky', [0, 100, 50]);

DESCRIPCIÓN

Valores RGB y HSL de colores con nombre de los estándares X11, HTML(CSS), SVG y del informe Pantone. Permite también búsqueda cercana, búsqueda inversa y almacenamiento (no permanente) de nombres adicionales. Un color puede tener múltiples nombres. Se pueden almacenar colores propios (no permanentemente) para su posterior referencia por nombre. Para esto, se debe elegir un nombre que no esté ya en uso. El color correspondiente puede definirse mediante un trío RGB o HSL.

No se importa ningún símbolo por defecto. Los símbolos de subrutina: "rgb_from_name", "hsl_from_name", "name_from_rgb", "name_from_hsl" pueden importarse individualmente o mediante:

use Graphics::Toolkit::Color::Name qw/:all/;

RUTINAS

rgb_from_name

Valor de Rojo, Verde y Azul del color con nombre. Estos valores son enteros en 0 .. 255.

my @rgb = Graphics::Toolkit::Color::Name::rgb_from_name('darkblue');
@rgb = Graphics::Toolkit::Color::Name::rgb_from_name('dark_blue'); # mismo resultado
@rgb = Graphics::Toolkit::Color::Name::rgb_from_name('DarkBlue');  # sigue siendo el mismo

hsl_from_name

Tono, saturación y luminosidad del color con nombre. Estos son enteros entre 0 .. 359 (tono) o 100 (saturación y luminosidad). Un tono de 360 y 0 (grados en un sistema de coordenadas cilíndrico) se considera el mismo, este módulo solo trata con el último.

my @hsl = Graphics::Toolkit::Color::Name::hsl_from_name('darkblue');

name_from_rgb

Devuelve el nombre del color con el trío de valores rgb dados. Devuelve una cadena vacía si el color no está almacenado. Cuando varios nombres definen el color dado, se seleccionará el nombre más corto en contexto escalar. En contexto de matriz se dan todos los nombres.

say Graphics::Toolkit::Color::Name::name_from_rgb( 15, 10, 121 );  # 'darkblue'
say Graphics::Toolkit::Color::Name::name_from_rgb([15, 10, 121]);  # también funciona

name_from_hsl

Devuelve el nombre del color con el trío de valores hsl dados. Devuelve una cadena vacía si el color no está almacenado. Cuando varios nombres definen el color dado, se seleccionará el nombre más corto en contexto escalar. En contexto de matriz se dan todos los nombres.

say scalar Graphics::Toolkit::Color::Name::name_from_hsl( 0, 100, 50 );  # 'red'
scalar Graphics::Toolkit::Color::Name::name_from_hsl([0, 100, 50]);  # también funciona
say for Graphics::Toolkit::Color::Name::name_from_hsl( 0, 100, 50 ); # 'red', 'red1'

names_in_hsl_range

Nombres de color en el vecindario seleccionado del espacio de color hsl, que se ven similares. Requiere dos argumentos. El primero es una matriz que contiene tres valores (tono, saturación y luminosidad), que definen el centro del vecindario (área buscada).

El segundo argumento puede ser un número o nuevamente una matriz con tres valores (h, s y l). Si es solo un número, será el radio r de una esfera, que define el vecindario. De todos los colores dentro de esa esfera, que estén a una distancia igual o menor que r del centro, se devolverá un nombre.

Si el segundo argumento es una matriz, debe contener la tolerancia (distancia permitida) en las direcciones h, s y l. Tenga en cuenta que la dimensión h es circular: la distancia de 355 a 0 es 5. Las dimensiones s y l son lineales, por lo que un valor central de 90 y una tolerancia de 15 resultarán en una búsqueda en el rango 75 .. 100.

Los resultados contienen solo un nombre por color (el más corto).

# todos los colores rojizos brillantes
my @names = Graphics::Toolkit::Color::Name::names_in_hsl_range([0, 90, 50], 5);
# se aproxima a:
my @names = Graphics::Toolkit::Color::Name::names_in_hsl_range([0, 90, 50],[ 3, 3, 3]);

all

Una lista ordenada de todos los nombres de color almacenados.

taken

Un pseudo booleano perl que indica si el nombre de color (primer y único argumento requerido) ya está en uso.

add_rgb

Agrega un color al almacén con un nombre no tomado (no usado ya). Los argumentos son nombre, valor de rojo, verde y azul (entero < 256, ver rgb).

Graphics::Toolkit::Color::Name::add_rgb('nightblue',  15, 10, 121 );
Graphics::Toolkit::Color::Name::add_rgb('nightblue', [15, 10, 121]);

add_hsl

Agrega un color al almacén con un nombre no tomado (no usado ya). Los argumentos son nombre, valor de tono, saturación y luminosidad (ver hsl).

Graphics::Toolkit::Color::Name::add_rgb('lucky',  0, 100, 50 );
Graphics::Toolkit::Color::Name::add_rgb('lucky', [0, 100, 50]);
