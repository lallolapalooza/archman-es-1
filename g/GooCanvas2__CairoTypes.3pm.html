GooCanvas2::CairoTypes(3) Documentación de Perl contribuida por el usuario GooCanvas2::CairoTypes(3)

NOMBRE

GooCanvas2::CairoTypes - Puente entre GooCanvas2 y tipos Cairo

SINOPSIS

use GooCanvas2;
use GooCanvas2::CairoTypes;
my $pattern = Cairo::SolidPattern->create_rgba(0, 0, 0, 0);
my $rect = GooCanvas2::CanvasRect->new(
        ...,
        'fill-pattern' => $pattern,  # falla sin CairoTypes, solo funciona con
);
# A veces (pero no siempre, no tengo ni idea de por qué) esto falla:
$rect->get('fill-pattern')->set_filter('linear);
# Aquí está la solución:
GooCanvas2::CairoTypes::cairoize_pattern($rect->get('fill-pattern'))
        ->set_filter('linear);

DESCRIPCIÓN

Existe un problema en la interacción entre GooCanvas, GObject Introspection, Cairo y sus enlaces de Perl, que hace que cierta funcionalidad sea inutilizable desde el lado de Perl. Esto se describe mejor aquí https://stackoverflow.com/questions/64625955/cairosolidpattern-is-not-of-type-goocanvas2cairopattern, y hubo un intento https://gitlab.gnome.org/GNOME/goocanvas/-/merge_requests/9 para solucionarlo upstream. Hasta que se solucione, esto puede servir como una solución provisional.

Actualmente, este módulo solo "arregla" la interop. de "Cairo::Pattern/GooCanvas2::CairoPattern". Para ciertas llamadas, simplemente funciona si este módulo se incluyó; para otras llamadas, necesitas convertir explícitamente el tipo.

Si tienes alguna idea de cómo arreglar esos casos para que no requieran tal llamada, o necesitas unir más tipos, las pull requests https://github.com/DarthGandalf/GooCanvas2-CairoTypes son bienvenidas.
