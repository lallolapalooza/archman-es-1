NOMBRE

Glib::BookmarkFile - Analizador de archivos de marcadores

SINOPSIS

use Glib;
$date .= $_ while (<DATA>);
$b = Glib::BookmarkFile->new;
$b->load_from_data($data);
$uri = 'file:///some/path/to/a/file.txt';
if ($b->has_item($uri)) {
      $title = $b->get_title($uri);
      $desc  = $b->get_description($uri);
      print "Marcador para `$uri' ($title):\n";
      print "  $desc\n";
}
0;

DESCRIPCIÓN

Glib::BookmarkFile permite analizar, editar o crear archivos que contienen listas de marcadores de recursos apuntados por URIs, con algunos metadatos asociados, siguiendo la Especificación de Marcadores de Escritorio. La función de archivos recientes dentro de GTK+ utiliza este tipo de archivos para almacenar la lista de archivos utilizados recientemente.

La sintaxis de los archivos de marcadores se describe en detalle en la Especificación de Marcadores de Escritorio; aquí hay un resumen rápido: los archivos de marcadores utilizan una subclase del formato de documento XBEL (XML Bookmark Exchange Language), definiendo metadatos como el tipo MIME del recurso al que apunta un marcador, la lista de aplicaciones que han registrado la misma URI y la visibilidad del marcador.

MÉTODOS

marcador_archivo = Glib::BookmarkFile->new

$marcador_archivo->add_application ($uri, $nombre, $exec)

  • $uri (cadena)
  • $nombre (cadena o undef)
  • $exec (cadena o undef)

Añade la aplicación con $nombre y $exec a la lista de aplicaciones que han registrado un marcador para $uri en $marcador_archivo.

Cada marcador dentro de un "Glib::BookmarkFile" debe tener al menos una aplicación registrada. Cada aplicación debe proporcionar un nombre, una línea de comandos útil para lanzar el marcador, el número de veces que el marcador ha sido registrado por la aplicación y la última vez que la aplicación registró este marcador.

Si $nombre es undef, el nombre de la aplicación será el mismo que devuelve Glib::get_application_name(); si $exec es undef, la línea de comandos será una composición del nombre del programa, tal como lo devuelve Glib::get_prgname(), y el modificador "%u", que se expandirá a la URI del marcador.

Esta función se encargará automáticamente de actualizar el contador de registros y la marca de tiempo en caso de que una aplicación con el mismo $nombre ya hubiera registrado un marcador para $uri dentro del archivo de marcadores. Si no se encuentra ningún marcador para $uri, se creará uno.

$marcador_archivo->add_group ($uri, $grupo)

  • $uri (cadena)
  • $grupo (cadena)

Añade $grupo a la lista de grupos a los que pertenece el marcador para $uri. Si no se encuentra ningún marcador para $uri, se creará uno.

($exec, $count, $stamp) = $marcador_archivo->get_app_info ($uri, $nombre)

  • $uri (cadena)
  • $nombre (cadena)

Obtiene la información de registro de $nombre para el marcador de $uri. Véase Glib::BookmarkFile::set_app_info() para más información sobre los datos devueltos.

Puede fallar con un Glib::Error en $@ en caso de error.

$marcador_archivo->set_app_info ($uri, $nombre, $exec, $count, $stamp)

  • $uri (cadena)
  • $nombre (cadena)
  • $exec (cadena)
  • $count (entero)
  • $stamp (marca de tiempo_unix)

Establece los metadatos de la aplicación $nombre dentro de la lista de aplicaciones que han registrado un marcador para $uri en $marcador_archivo.

Raramente deberías usar este método; usa Glib::BookmarkFile::add_application() y Glib::BookmarkFile::remove_application() en su lugar.

$nombre puede ser cualquier cadena codificada en UTF-8 utilizada para identificar una aplicación. $exec puede tener uno de estos dos modificadores: "%f", que se expandirá como el nombre del archivo local obtenido de la URI del marcador; "%u", que se expandirá como la URI del marcador. La expansión se realiza automáticamente al recuperar la línea de comandos almacenada usando el método Glib::BookmarkFile::get_app_info(). $count es el número de veces que la aplicación ha registrado el marcador; si es < 0, el número de registro actual se incrementará en uno, si es 0, la aplicación con $nombre se eliminará de la lista de aplicaciones registradas. $stamp es la hora Unix del último registro, tal como la devuelve time(); si es -1, se usará la hora actual.

Si intentas eliminar una aplicación estableciendo su número de registro a cero, y no se encuentra ningún marcador para $uri, se devuelve %FALSE y se dispara una excepción.

Puede fallar con un Glib::Error en $@ en caso de error.

METADATOS ESPECÍFICOS DEL FORMATO

El formato XBEL permite añadir información adicional a los marcadores utilizando el atributo owner. El estándar de marcadores de escritorio define varios espacios de nombres de metadatos, como http://www.freedesktop.org/standards/desktop-bookmarks para la información de aplicaciones y tipos MIME, y http://www.freedesktop.org/standards/shared-mime-info para información relacionada con MIME.

Estos metadatos se pueden acceder y manipular utilizando los métodos del objeto Glib::BookmarkFile:
