SINOPSI

S 
#!/usr/bin/perl -w
use strict;
use warnings;
use Gtk3 -init;
use GooCanvas2;

my $window = Gtk3::Window->new();
$window->set_default_size(640, 600);
$window->signal_connect('destroy' => sub {Gtk3->main_quit()});
my $scrolled_win = Gtk3::ScrolledWindow->new();
$scrolled_win->set_shadow_type('in');
my $canvas = GooCanvas2::Canvas->new();
$canvas->set_size_request(600,450);
$canvas->set_bounds(0,0,1000,1000);
$scrolled_win->add($canvas);
my $root = $canvas->get_root_item();
# Añadir algunos elementos simples
my $rect_item = GooCanvas2::CanvasRect->new('parent' => $root,
                                        'x' => 100,
                                        'y' => 100,
                                        'width' => 300,
                                        'height' => 300,
                                        'line_width' => 10.0,
                                        'radius-x' => 20.0,
                                        'radius-y' => 10.0,
                                        'stroke-color' => 'yellow',
                                        'fill-color' => 'red');
my $text_item = GooCanvas2::CanvasText->new('parent' => $root,
                                        'text' => 'Hello World',
                                        'x' => 300, 'y' => 300, 
                                        'width' => -1,
                                        'anchor' => 'center',
                                        'font' => 'Sans 24');
$text_item->rotate(45, 300, 300);
# Conectar un manejador de señal para el elemento rectángulo.
$rect_item->signal_connect('button_press_event' => \&on_rect_button_press);
$window->add($scrolled_win);
$window->show_all;
# Pasar el control al bucle de eventos principal de Gtk3
Gtk3->main();
# Esto maneja las pulsaciones de botón en las vistas de elementos. 
#Simplemente mostramos un mensaje en la consola
sub on_rect_button_press {
        my ($item, $target, $event) = @_;
        print "rect item received button press event \n";
        return 1;
}

DESCRIPCIÓ

N

GooCanvas2 es un nuevo widget de lienzo para usar con Gtk3 que utiliza la biblioteca Cairo 2d para dibujar. Esta es una implementación simple y básica de este maravilloso widget de

lienzo.

Para más información, consulta https://wiki.gnome.org/action/show/Projects/GooCanva

s

Para instrucciones sobre cómo usar GooCanvas2, por favor, estudia la referencia de la API en https://developer.gnome.org/goocanvas/unstable/ por ahora. Una documentación específica de Perl quizás venga en versiones posteriores. Pero aplicar la documentación en C no debería ser un

problema.
