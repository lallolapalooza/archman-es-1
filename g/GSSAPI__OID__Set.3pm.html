GSSAPI::OID::Set(3) Documentación de Perl contribuida por el usuario GSSAPI::OID::Set(3)

NOMBRE

GSSAPI::OID::Set - métodos para manejar conjuntos de OIDs GSSAPI y algunos conjuntos de OIDs constantes.

SINOPSIS

use GSSAPI;
$oidset = GSSAPI::OID::Set->new;
$status = $oidset->insert($oid);
$status = $oidset->contains($oid, $isthere);
if ($status && $isthere) {
  # bla bla bla
}

DESCRIPCIÓN

"GSSAPI::OID::Set" los objetos son conjuntos simples de GSSAPI:OIDs (obviamente).

INCONVENIENTES

No hay forma de listar los OIDs en un conjunto; solo puedes verificar si uno en particular está presente. Esto es realmente un error en la API de C, por lo que cualquier solución sería específica de la implementación.
