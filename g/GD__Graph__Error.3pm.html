Esta clase es una clase padre para todas las clases de GD::Graph, incluyendo GD::Graph::Data, y ofrece manejo de errores y advertencias y algo de control de

PÚBLICOS

Estos métodos pueden ser utilizados por los usuarios de cualquiera de las subclases de GD::Graph::Error para acceder a los errores de los objetos o

clases.

$object->error() O Class->error(

)

Devuelve una lista de todos los errores que el objeto actual ha acumulado. En contexto escalar, devuelve el último error. Si se llama como un método de clase, funciona a nivel de clase. Esto es útil cuando un constructor falla, por

ejemplo: 
my $data = GD::Graph::Data->new()    
    or die GD::Graph::Data->error;
$data->read(file => '/foo/bar.data') 
    or die $data->
error;

o si realmente solo te interesa el último

error: 
$data->read(file => '/foo/bar.data') 
    or die scalar $data->
error;

Esta implementación no limpia la lista de errores, así que si no mueres con los errores, necesitarás asegurarte de nunca pedir nada más que el último error (ponlo en contexto escalar) o de llamar a clear_error() de vez en

cuando.

Los errores son más verbosos sobre dónde se originaron si la variable $GD::Graph::Error::Debug está establecida en un valor verdadero, y aún más verbosos si este valor es mayor que

5.

Si $Debug es mayor que 3, ambos devolverán siempre la lista completa de errores y advertencias (aunque el significado de "has_warning" y "has_error"

no ca
mbia).

(

$object->has_warning() O Class->has_warning(

)

Devuelve verdadero si hay errores (advertencias) pendientes para el objeto (o clase). Para ser más preciso, devuelve una lista de errores en contexto de lista, y el número de errores en contexto

escalar.

Esto te permite comprobar errores y advertencias después de un gran número de operaciones que cada una podría

fallar: 
$data->read(file => '/foo/bar.data') or die $data->error;
while (my @foo = $sth->fetchrow_array)
{
    $data->add_point(@foo);
}
$data->set_x(12, 'Foo');
$data->has_warning and warn $data->warning;
$data->has_error   and die  $data->
error;

La razón para llamar a esto, en lugar de simplemente llamar a error() o warning() y mirar su valor de retorno, es que este método es mucho más eficiente y

rápido.

Si quieres contar cualquier cosa como mala, simplemente establece $ErrorLevel a 0, después de lo cual solo necesitas llamar a "has_error

PROTEGIDOS

Estos métodos solo deben ser llamados desde dentro de esta clase y sus

subclases.

$object->_set_error(arg) o Class->_set_error(ar

g
)

$object->_set_warning(arg) o Class->_set_warning(arg

)

Las subclases llaman a esto para establecer un error. El argumento puede ser una referencia a un array, cuyo primer elemento debería ser el nivel de error, y el segundo elemento el mensaje del error. Alternativamente, puede ser simplemente el mensaje, en cuyo caso el nivel de error se asumirá que es $ErrorLevel

.

Si el nivel de error es >= $CriticalLevel el programa morirá, usando Carp::croak para mostrar el mensaje actual, así como todos los demás mensajes de error

pendientes.

En la implementación actual estos son casi idénticos cuando se llaman con un argumento escalar, excepto

que el nivel de error predeterminado es diferente. Cuando se llaman con una referencia a array, son idént
icos en función. Esto puede cambiar en el futuro. Están aquí principalmente para la claridad del código.

VARIABLE

S

$GD::Graph::Error::

Debug

Cuanto más alto sea este valor, más verbosos serán los mensajes de error. En el momento, cualquier valor verdadero hará que se incluya el número de l

ínea y el archivo fuente del llamador en la parte superior de la pila, un valor mayor que 2 incluirá la severidad del error, y un valor mayor que
5 también incluirá el número de línea y el paquete del llamador directo (es decir, el lugar donde se generó el mensaje de error). Predeterminado: 0.

$GD::Graph::Error::

ErrorLevel

Los niveles de error por debajo de este valor se contarán como advertencias, y los niveles de error por encima (e incluyendo) hasta $CriticalLevel se contarán como errores. Este es también el nivel de error predeterminado para el método _set_error(). Este valor debería ser 0 o mayor, y menor que $CriticalLevel. P

redetermi
nado: 5.

CriticalLevel

este nivel hará inmediatamente que el
programa muera con el mensaje especificado
, usando Carp::croak. Predeterminado: 10.
