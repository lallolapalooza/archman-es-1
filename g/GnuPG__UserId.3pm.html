GnuPG::UserId(3) Documentación de Perl aportada por el usuario GnuPG::UserId(3)

NOMBRE

GnuPG::UserId - Objetos de ID de usuario de GnuPG

SINOPSIS

# asume un objeto GnuPG::PublicKey en $publickey
my $user_id = $publickey->user_ids_ref->[0]->as_string;

DESCRIPCIÓN

Los objetos GnuPG::UserId generalmente no se instancian por sí solos, sino como parte de los objetos GnuPG::PublicKey o GnuPG::SecretKey.

MÉTODOS DE OBJETO

new( %argumentos_de_inicialización )
Este método crea un nuevo objeto. Los argumentos opcionales son la inicialización de los miembros de datos;
compare( $otro, $profundo )
Devuelve distinto de cero solo cuando este ID de usuario es idéntico al otro GnuPG::UserID. Si $profundo está presente y es distinto de cero, también se compararán las firmas y revocaciones del ID de usuario.

MIEMBROS DE DATOS DEL OBJETO

as_string
Una cadena del ID de usuario.
validity
Un escalar que contiene el valor que GnuPG informa para la confianza de autenticidad (también conocido como) validez de una clave. Ver el archivo DETAILS de GnuPG para más detalles.
signatures
Una lista de objetos GnuPG::Signature que representan las firmas en este ID de usuario.
revocations
Una lista de revocaciones asociadas con este ID de usuario, almacenadas como objetos GnuPG::Signature (ya que las revocaciones también son un tipo de certificación).
