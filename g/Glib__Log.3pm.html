Glib::Log::default_handler ($log_domain, $log_level, $message, ...)

  • $log_domain (cadena)
  • $log_level (escalar)
  • $message (cadena)
  • ... (lista) posible argumento "userdata" ignorado

Los argumentos son los mismos que los que toma la función para set_handler o set_default_handler.

prev_log_func = Glib::Log->set_default_handler ($log_func, $user_data)

  • $log_func (subrutina) función manejadora o undef
  • $user_data (escalar)

Instala log_func como el manejador de registro predeterminado. log_func se llama para cualquier cosa que no tenga de otro modo un manejador (ya sea Glib::Log->set_handler, o el gperl_handle_logs_for de Glib::xsapi),

&$log_func ($log_domain, $log_levels, $message, $user_data)

donde $log_domain es una cadena, y $log_levels es un Glib::LogLevelFlags del nivel y los indicadores que se están reportando.

Si log_func es \&Glib::Log::default_handler o undef, entonces se establece el manejador predeterminado de Glib.

El valor de retorno de "set_default_handler" es el manejador anterior. Este es \&Glib::Log::default_handler para el predeterminado de Glib, de lo contrario una función Perl instalada previamente. Si el manejador es alguna otra función no Perl, entonces actualmente el retorno es undef, pero quizás eso cambiará a algo envuelto, excepto que sin el userdata asociado hay muy poco que se podría hacer con él (no podría reinstalarse más tarde sin su userdata).

Desde: glib 2.6

escalar = Glib::Log->set_fatal_mask ($log_domain, $fatal_mask)

  • $log_domain (cadena)
  • $fatal_mask (escalar)

entero = Glib::Log->set_handler ($log_domain, $log_levels, $log_func, $user_data=undef)

  • $log_domain (cadena o undef) nombre del dominio para manejar con esta devolución de llamada.
  • $log_levels (Glib::LogLevelFlags) niveles de registro para manejar con esta devolución de llamada
  • $log_func (subrutina) función manejadora
  • $user_data (escalar)

$log_func se llamará como

&$log_func ($log_domain, $log_levels, $message, $user_data);

donde $log_domain es el nombre solicitado y $log_levels es un Glib::LogLevelFlags del nivel y los indicadores que se están reportando.
