Graphics::ColorNames::WWW(3) Documentación Perl aportada por el usuario Graphics::ColorNames::WWW(3)

NOMBRE

Graphics::ColorNames::WWW - Nombres de colores WWW y valores RGB equivalentes

SINOPSIS

require Graphics::ColorNames::WWW;
$NameTable = Graphics::ColorNames::WWW->NamesRgbTable();
$RgbBlack  = $NameTable->{black};

DESCRIPCIÓN

Este módulo define nombres de colores y sus valores RGB asociados de varias especificaciones WWW, como SVG o CSS, así como implementaciones comunes de navegadores.

Consulte la documentación de Graphics::ColorNames para obtener información sobre cómo usar este módulo.

Actualmente, SVG y CSS definen las mismas palabras clave de color e incluyen todas las palabras clave de color admitidas por los navegadores web comunes. Por lo tanto, los módulos Graphics::ColorNames::WWW, Graphics::ColorNames::SVG y Graphics::ColorNames::CSS se comportan de maneras idénticas.

Esto puede cambiar si las especificaciones divergen; entonces, este módulo se convertirá en un superconjunto de todas las palabras clave de color definidas por las especificaciones de W3C.

Se recomienda utilizar este módulo a menos que requiera una compatibilidad exacta con las especificaciones CSS y SVG o con navegadores específicos.

NOTA

Según se informa, "fuchsia" se escribió mal como "fuscia" en una especificación HTML no identificada. También parece ser un error tipográfico común, por lo que se reconocen ambos nombres.

LIMITACIONES

La palabra clave "transparent" no es compatible. Actualmente, Graphics::ColorNames no permite valores RGBA.

Además, las palabras clave de color del sistema no se asignan a un valor RGB fijo y, por lo tanto, no son compatibles: "ActiveBorder", "ActiveCaption", "AppWorkspace", "Background", "ButtonFace", "ButtonHighlight", "ButtonShadow", "ButtonText", "CaptionText", "GrayText", "Highlight", "HighlightText", "InactiveBorder", "InactiveCaption", "InactiveCaptionText", "InfoBackground", "InfoText", "Menu", "MenuText", "Scrollbar", "ThreeDDarkShadow", "ThreeDFace", "ThreeDHighlight", "ThreeDLightShadow", "ThreeDShadow", "Window", "WindowFrame", "WindowText" (estas están obsoletas en CSS3)

VER TAMBIÉN

Graphics::ColorNames::HTML, Graphics::ColorNames::CSS, Graphics::ColorNames::SVG
