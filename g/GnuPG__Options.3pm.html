Estas opciones se correlacionan directamente con muchas opciones de GnuPG. Para aquellas que son booleanas en GnuPG, simplemente se pasa ese argumento. Para aquellas que están asociadas con un escalar, ese escalar se pasa como un argumento apropiado. Para aquellas que se pueden especificar más de una vez, como recipients, se consideran listas y se pasan en consecuencia. Cada uno es indefinido o falso al

principio.

Opciones

meta

Las opciones meta son aquellas que no se correlacionan directamente con ninguna opción en GnuPG, sino que generalmente son un conjunto de opciones utilizadas para lograr un objetivo específico, como obtener compatibilidad con PGP 5. Los argumentos reales que cada una de estas refleja pueden cambiar con el tiempo. Cada una es falsa por defecto a menos que se especifique lo

contrario.

Estas opciones se están diseñando para proporcionar una abstracción no específica de GnuPG, para ayudar a crear compatibilidad con un posible módulo PGP::

Interface.

Para ayudar a evitar confusiones, los métodos que toman una forma de una clave como objeto deberán ir precedidos por _id(s) si solo toman un id; de lo contrario, se asume que se requiere un objeto de tipo GnuPG::

Key.
