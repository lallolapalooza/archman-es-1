PAQUETES (BUNDLES) Un paquete (bundle) es una colección de recursos que forman un paquete discreto para su us

o. Actualmente hay tres tipos de paquetes: a
plicaciones, frameworks y paquetes cargables.

Un paquete cargable es un tipo de plugin. Hay dos tipos de paquetes cargables, a saber, plugins y paletas. Al plugin normalmente se le llama bundle, lo que puede resultar un poco confuso. Un plugin es un bundle que puede ser cargado por una aplicación para proporcionar funcionalidad adicional,

mientras que una paleta es un plugin para

GORM , el constructor de interfaces. Una paleta se usa para extender GORM con objetos de interfaz de usuario personalizados. Las paletas tienen la extensión .palette . EL ESPACIO DE
