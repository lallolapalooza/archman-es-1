NOMBRE

GD::Graph::Data - Encapsulación de conjuntos de datos para GD::Graph

SINOPSIS

use GD::Graph::Data;

DESCRIPCIÓN

Este módulo encapsula la estructura de datos que necesita GD::Graph y sus compañeros. Un objeto de esta clase contiene una lista de valores X y varias listas de valores Y correspondientes. Esto solo tiene sentido realmente si los valores Y son numéricos, pero básicamente puedes almacenar cualquier cosa. Los valores indefinidos tienen un significado especial para GD::Graph, por lo que se tratan con cuidado cuando se almacenan.

Muchos de los métodos de este módulo están destinados al uso interno por GD::Graph y el propio módulo, y probablemente no te serán útiles. Muchos ni siquiera parecerán útiles para ti...

EJEMPLOS

use GD::Graph::Data;
use GD::Graph::bars;
my $data = GD::Graph::Data->new();
$data->read(file => '/data/sales.dat', delimiter => ',');
$data = $data->copy(wanted => [2, 4, 5]);
# Añadir las cifras más recientes de la base de datos
use DBI;
# Hacer operaciones con DBI, como conectarse a la base de datos,
# preparar y ejecutar sentencias
while (@row = $sth->fetchrow_array)
{
    $data->add_point(@row);
}
my $chart = GD::Graph::bars->new();
my $gd = $chart->plot($data);

o para cambios rápidos en código heredado

# El código heredado construye una matriz así
@data = ( [qw(Jan Feb Mar)], [1, 2, 3], [5, 4, 3], [6, 3, 7] );
# Y necesitamos rápidamente hacer algunas manipulaciones sobre eso
my $data = GD::Graph::Data->new();
$data->copy_from(\@data);
# Y ahora hacer todo lo nuevo que se quiere.
while (@foo = bar_baz())
{
    $data->add_point(@foo);
}

MÉTODOS

$data = GD::Graph::Data->new()

Crea un nuevo objeto GD::Graph::Data.

$data->set_x($np, $value);

Establece el valor X del punto $np a $value. Los puntos se numeran empezando por 0. Probablemente nunca necesitarás esto. Devuelve undef en caso de fallo.

$data->get_x($np)

Obtiene el valor X del punto $np. Ver "set_x".

$data->set_y($nd, $np, $value);

Establece el valor Y del punto $np en el conjunto de datos $nd a $value. Los puntos se numeran empezando por 0, los conjuntos de datos se numeran empezando por 1. Probablemente nunca necesitarás esto. Devuelve undef en caso de fallo.

$data->get_y($nd, $np)

Obtiene el valor Y del punto $np en el conjunto de datos $nd. Ver "set_y". Esto devolverá undef en caso de error, pero el hecho de que devuelva undef no significa que haya habido un error (ya que se pueden almacenar valores indefinidos y, por tanto, devolverlos).

$data->get_y_cumulative($nd, $np)

Obtiene el valor acumulado del punto $np en el conjunto de datos<$nd>. El valor acumulado se obtiene sumando todos los valores de los puntos $np en los conjuntos de datos del 1 al $nd.

$data->get_min_max_x

Devuelve una lista con el valor x mínimo y máximo, o la lista vacía en caso de fallo.

$data->get_min_max_y($nd)

Devuelve una lista con el valor y mínimo y máximo en el conjunto de datos $nd o la lista vacía en caso de fallo.

$data->get_min_max_y_all()

Devuelve una lista con el valor y mínimo y máximo en todos los conjuntos de datos, o la lista vacía en caso de fallo.

$data->add_point($X, $Y1, $Y2 ...)

Añade un punto al conjunto de datos. La base para la adición es el número actual de valores X. Esto significa que si tienes un conjunto de datos con el contenido

(X1,  X2)
(Y11, Y12)
(Y21)
(Y31, Y32, Y33, Y34)

un $data->add_point(Xx, Y1x, Y2x, Y3x, Y4x) resultará en

(X1,    X2,    Xx )
(Y11,   Y12,   Y1x)
(Y21,   undef, Y2x)
(Y31,   Y32,   Y3x,  Y34)
(undef, undef, Y4x)

En otras palabras: ten cuidado con cómo usas esto. Siempre que te asegures de que todos los conjuntos de datos tengan la misma longitud, este método es seguro de usar.

$data->num_sets()

Devuelve el número de conjuntos de datos.

$data->num_points()

En contexto de lista, devuelve una lista cuyo primer elemento es el número de valores X, y los elementos siguientes el número de valores Y respectivos para cada conjunto de datos. En contexto escalar devuelve el número de puntos que tienen un valor X establecido, es decir, el número de conjuntos de datos que resultarían de una llamada a "make_strict".

$data->x_values()

Devuelve una lista de todos los valores X.

$data->y_values($nd)

Devuelve una lista de los valores Y para el conjunto de datos $nd. Los conjuntos de datos se numeran desde 1. Devuelve la lista vacía si $nd está fuera de rango, o si el conjunto de datos en $nd está vacío.

$data->reset() O GD::Graph::Data->reset()

Como método de objeto: Restablece el contenedor de datos, se deshace de todos los datos y mensajes de error. Como método de clase: se deshace de los mensajes de error acumulados y de otros posibles residuos.

$data->make_strict()

Hace que todas las listas de conjuntos de datos tengan la misma longitud que la lista X, truncando los conjuntos de datos que sean demasiado largos y rellenando los conjuntos de datos que sean demasiado cortos con valores undef. Siempre devuelve un valor verdadero.

$data->cumulate(preserve_undef => boolean)

El parámetro cumulate resumirá los conjuntos de valores Y de la siguiente manera: la primera lista de valores Y permanecerá sin cambios, la segunda contendrá una suma de la primera y la segunda, la tercera contendrá la suma de la primera, segunda y tercera, y así sucesivamente. Devuelve undef en caso de fallo.

si el argumento preserve_undef se establece en un valor verdadero, entonces la suma de valores exclusivamente indefinidos se conservará como un valor indefinido. Si no está presente o es un valor falso, undef se tratará como cero. Ten en cuenta que esto aún dejará sin cambios los valores indefinidos en el primer conjunto de datos.

Nota: Cualquier valor Y definido no numérico se tratará como 0, pero realmente no deberías usar esto para almacenar ese tipo de datos Y.

$data->wanted(indexes)

Elimina todos los conjuntos de datos excepto los de la lista de argumentos. También reordenará los conjuntos de datos en el orden dado. Devuelve undef en caso de fallo.

Para eliminar todos los conjuntos de datos excepto el primero, el sexto y el segundo, en ese orden:

$data->wanted(1, 6, 2) or die $data->error;

$data->reverse

Invierte el orden de los conjuntos de datos.

$data->copy_from($data_ref)

Copia una estructura de datos de GD::Graph de estilo 'antiguo' u otro objeto GD::Graph::Data en este objeto. Esto eliminará los datos actuales. Devuelve undef en caso de fallo.

$data->copy()

Devuelve una copia del objeto, o undef en caso de fallo.

$data->read(argumentos)

Lee un conjunto de datos de un archivo. Esto eliminará los datos actuales. Devuelve undef en caso de fallo. Este método utiliza el módulo estándar Text::ParseWords para analizar las líneas. Si por alguna razón extraña no lo tiene, no utilice este método, o su programa morirá.

Formato del archivo de datos: El formato de archivo de datos predeterminado son datos separados por tabulaciones (lo cual se puede cambiar con el argumento delimiter). Las líneas de comentario son cualquier línea que comience con un #. En el siguiente ejemplo he reemplazado los tabuladores literales con <tab> por claridad

# Este es un comentario, y será ignorado
Ene<tab>12<tab>24
Feb<tab>13<tab>37
# Marzo falta
Mar<tab><tab>
Abr<tab>9<tab>18

Los argumentos válidos son:

file, obligatorio. El nombre del archivo del cual leer, o una referencia a un manejador de archivo o glob.

$data->read(file => '/data/foo.dat') or die $data->error;
$data->read(file => \*DATA) or die $data->error;
$data->read(file => $file_handle) or die $data->error;

no_comment, opcional. Proporcione un valor verdadero si no desea que se omitan las líneas que comienzan con #.

$data->read(file => '/data/foo.dat', no_comment => 1);

delimiter, opcional. Una expresión regular que se convertirá en el delimitador en lugar de un solo tabulador.

$data->read(file => '/data/foo.dat', delimiter => '\s+');
$data->read(file => '/data/foo.dat', delimiter => qr/\s+/);

$data->error() O GD::Graph::Data->error()

Devuelve una lista de todos los errores que el objeto actual ha acumulado. En contexto escalar, devuelve el último error. Si se llama como un método de clase, funciona a nivel de clase.

Este método es heredado, consulte GD::Graph::Error para más información.

$data->has_error() O GD::Graph::Data->has_error()

Devuelve true si el objeto (o la clase) tiene errores pendientes, false si no. En algunos casos (vea "copy") esta es la mejor manera de comprobar errores.

Este método es heredado, consulte GD::Graph::Error para más información.

NOTAS

Como con todos los módulos para Perl: Por favor, limite el uso a la interfaz. Si intenta manipular demasiado el conocimiento de los internos de este módulo, podría quemarse. Puedo cambiarlos en cualquier momento. Específicamente, yo probablemente no mantendré siempre esto implementado como una referencia de arreglo.
