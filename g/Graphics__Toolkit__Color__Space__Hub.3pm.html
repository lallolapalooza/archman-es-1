NOMBRE

Graphics::Toolkit::Color::Space::Hub - convierte, formatea y mide valores de color

SINOPSIS

Centro de distribución para todas las matemáticas relacionadas con valores de color. Puede manejar vectores de todos los espacios mencionados en el siguiente párrafo y también se traduce desde y hacia diferentes formatos como RGB hexadecimal ('#AABBCC').

use Graphics::Toolkit::Color::Space::Hub;
my $true = Graphics::Toolkit::Color::Space::Hub::is_space( 'HSL' );
my $HSL = Graphics::Toolkit::Color::Space::Hub::get_space( 'HSL');
my $RGB = Graphics::Toolkit::Color::Space::Hub::base_space();
Graphics::Toolkit::Color::Space::Hub::space_names();     # todos los nombres de espacio
$HSL->normalize([240,100, 0]);         # 2/3, 1, 0
$HSL->convert([240, 100, 0], 'RGB');   #   0, 0, 1
$HSL->deconvert([0, 0, 1], 'RGB');     # 2/3, 1, 0
$RGB->denormalize([0, 0, 1]);          #   0, 0, 255
$RGB->format([0, 0, 255], 'hex');      #   '#0000ff'
my ($values, $space_name) = Graphics::Toolkit::Color::Space::Hub::deformat( '#0000ff' );
# [0, 0, 255] , 'RGB'

DESCRIPCIÓN

Este módulo está pensado para ser utilizado por Graphics::Toolkit::Color y no directamente, por lo tanto, no exporta ningún símbolo y tiene una API mucho menos inteligente (DWIM) que el módulo principal.

ESPACIOS DE COLOR

Los nombres de los espacios de color se pueden escribir en cualquier combinación de mayúsculas y minúsculas.

RGB

tiene tres valores enteros: rojo (0 .. 255), verde (0 .. 255) y azul (0 .. 255). Todos escalan desde no (0) hasta muchísimo (255) de luz de ese color, de modo que (0,0,0) es negro, (255,255,255) es blanco y (0,0,255) es azul.

CMY

es el inverso de RGB pero con el rango: 0 .. 1. cian es el valor inverso de rojo, magenta es verde inverso y amarillo es inverso de azul. Inverso significa que cuando un color tiene el valor máximo de rojo, debe tener el valor mínimo de cian.

CMYK

es una extensión de CMY con un cuarto valor llamado clave (también 0 .. 1), que es básicamente la cantidad de negro mezclado en el color CMY.

HSL

tiene tres valores enteros: tono (0 .. 359), saturación (0 .. 100) y luminosidad (0 .. 100). El tono representa un color en un arcoíris: 0 = rojo, 15 se aproxima a naranja, 60 - amarillo, 120 - verde, 180 - cian, 240 - azul, 270 - violeta, 300 - magenta, 330 - rosa. 0 y 360 apuntan a la misma coordenada. Este módulo solo emite 0, incluso si acepta 360 como entrada. La saturación varía de 0 = gris a 100 = color más claro definido por el tono. La luminosidad varía de 0 = negro a 50 (tono o gris) a 100 = blanco.

HSV

Similar a HSL tenemos tono y saturación, pero el tercer valor se llama valor. En HSL, el color blanco siempre se consigue cuando la luminosidad = 100. En HSV, además, la saturación debe ser cero para obtener blanco. Cuando en HSV el valor es 100 y la saturación también es 100, entonces tenemos el color más brillante y puro del que sea que establezca el tono.

HSB

Es un alias para HSV, solo que el valor se renombra como brillo.

HWB

Un HSV invertido, donde los colores puros están dentro del cilindro. Todavía tiene la dimensión circular del tono, como se describe en "HSL". Las otras dos dimensiones lineales (también 0 .. 100 [por ciento]) son blancura y negritud, que describen cuánta blancura o negrura se mezcla. Si ambas son cero, entonces tenemos un color puro. Una blancura del 100 siempre lleva a blanco puro y una negritud del 100 siempre lleva a negro puro.

YIQ

Tiene las dimensiones lineales luminancia (una especie de brillo, rango 0..1), en fase (cian - naranja - equilibrio, rango -0.5959 .. 0.5959) y cuadratura (magenta - verde - equilibrio, rango: -0.5227 .. 0.5227).

FORMATOS

Estos formatos están disponibles en todos los espacios de color.

cadena

'RGB: 10, 20, 30'

cadena_css

'rgb(10, 20, 30)'

arreglo

[RGB, 10, 20, 30]

hash

{ red => 10, green => 20, blue => 30 }

hash_caracter

{ r => 10, g => 20, b => 30 }

RUTINAS

Este paquete proporciona dos conjuntos de rutinas. El primero es solo una búsqueda de los objetos de espacio de color disponibles. El segundo conjunto consta de tres pares de rutinas sobre operaciones esenciales de valores numéricos y su inversión. El proceso completo para la traducción de valores de color es:

1. deformat (a una lista de valores)
2. normalize (a rango 0..1)
3. convert/deconvert (al espacio de color de destino)
4. denormalize (al rango de destino)
5. format (al formato de destino)

space_names

Devuelve una lista de valores de cadena, que son los nombres de todos los espacios de color disponibles. Ver "ESPACIOS DE COLOR".

is_space

Necesita un argumento, que se supone que es un nombre de espacio de color. Si lo es, el resultado es 1, de lo contrario 0 (pseudo booleano perlense).

get_space

Necesita un argumento, que se supone que es un nombre de espacio de color. Si lo es, el resultado es el objeto de espacio de color correspondiente, de lo contrario, undef.

base_space

Devuelve el objeto de espacio de color del espacio de nombres (actualmente) RGB. Este espacio de nombres es especial ya que todos los objetos de espacio de color proporcionan convertidores desde y hacia RGB, pero RGB en sí mismo no tiene convertidor.

normalize

Normal en un sentido matemático significa que el rango de valores aceptables está entre cero y uno. La normalización significa, por lo tanto, alterar los valores de los números para que encajen en ese rango. Por ejemplo, los valores RGB estándar son enteros entre cero y 255. Normalizarlos esencialmente significa dividirlos por 255.

my @rgb = Graphics::Toolkit::Color::Space::Hub::normalize( [0,10,255], 'RGB' );

Tiene un argumento obligatorio y dos opcionales. El primero es una referencia ARRAY con el vector o valores de un color. El segundo argumento es el nombre de un espacio de color. Esto es necesario en la mayoría de los casos, ya que todos los espacios de color conocen sus rangos de valores estándar (siendo, por ejemplo, 3 x 0 .. 255 para RGB). Si desea normalizar desde rangos especiales como RGB16, debe usar el tercer argumento, que debe ser una definición de rango de valores válida.

my @rgb = Graphics::Toolkit::Color::Space::Hub::normalize( [0, 1000, 34000], 'RGB', 2**16 );
# que es lo mismo que:
my @rgb = Graphics::Toolkit::Color::Space::Hub::normalize( [0, 1000, 34000], 'RGB', [[0,65536].[0,65536].[0,65536]] );

denormalize

Función inversa de normalize, que toma los mismos argumentos. Si el resultado tiene que ser un entero (máximo de rango mayor que 1), se redondeará.

my @rgb = Graphics::Toolkit::Color::Space::Hub::denormalize( [0,0.1,1], 'RGB' );
my @rgb = Graphics::Toolkit::Color::Space::Hub::denormalize( [0,0.1,1], 'RGB', 2**16 );

convert

Convierte un va

lue vector (primer argumento) del espacio base (RGB) a cualquier espacio mencionado (segundo argumento - ver "COLOR-SPACES"). Los valores deben estar normalizados (dentro de 0..1). Si están fuera del rango aceptable, serán recortados, de modo que el resultado también será normal.

# convertir de RGB a HSL
my @hsl = Graphics::Toolkit::Color::Space::Hub::convert( [0.1, 0.5, .7], 'HSL' );

deconvert

Convierte una tupla de valores (vector - primer argumento) de cualquier espacio de color (segundo argumento) en el espacio base (RGB).

# convertir de HSL a RGB
my @rgb = Graphics::Toolkit::Color::Space::Hub::deconvert( [0.9, 0.5, 0.5], 'HSL' );

format

Pone una lista de valores (dentro de una referencia ARRAY - primer argumento) de cualquier espacio de color soportado (segundo argumento) en otro formato de datos (tercer argumento, ver /FORMATS).

my $hex = Graphics::Toolkit::Color::Space::Hub::format( [255, 0, 10], 'hex' );       # 'ff00a0'
my $string = Graphics::Toolkit::Color::Space::Hub::format( [255, 0, 10], 'string' ); # 'RGB: 255, 0, 10'

deformat

Función inversa de format, pero también adivina el espacio de color. Por eso solo toma un argumento, un escalar que puede ser una cadena, una referencia ARRAY o una referencia HASH. El resultado serán dos valores. El primero es un ARRAY con todos los valores sin alterar, sin recortar y sin normalizar. El segundo es el nombre del espacio de color reconocido.

my ($values, $space) =  Graphics::Toolkit::Color::Space::Hub::deformat( 'ff00a0' );
# [255, 10 , 0], 'RGB'
($values, $space) =  Graphics::Toolkit::Color::Space::Hub::deformat( [255, 10 , 0] ); # mismo resultado

partial_hash_deformat

Este es un caso especial deformat para el formato hash y char_hash (ver /FORMATS). Puede tolerar valores faltantes. El resultado también será un hash
