DESCRIPCIÓ

N

Los programas basados en eventos necesitan algún tipo de bucle que vigile los eventos y lance las acciones apropiadas. Glib::MainLoop proporciona esta

funcionalidad.

Los bucles principales tienen contexto, proporcionado por el objeto MainContext. En su mayor parte, puedes usar el contexto predeterminado (ver "default"), pero si quieres crear un subcontexto para un bucle anidado que no tenga las mismas fuentes de eventos, etc, puedes

hacerlo.

Las fuentes de eventos, adjuntadas a los contextos principales, vigilan la ocurrencia de eventos y lanzan acciones apropiadas. Glib proporciona algunas fuentes de eventos listas para usar, como Glib::Timeout, Glib::Idle y la vigilancia de E/S ("Glib::IO->add_

watch").

Internamente, Gtk+ añade fuentes de eventos para GdkEvents para despachar eventos a tus widgets. De hecho, Gtk2 proporciona una abstracción de Glib::MainLoop (ver "Gtk2->main" y sus amigos), por lo que rara vez tendrás la necesidad de usar Glib::MainLoop

directamente.

Nota: A partir de la versión 1.080, el módulo Glib usa una fuente de eventos personalizada para asegurar que

el manejo seguro de señales de perl y el bucle de eventos de sondeo de glib funcionen bien juntos. Ya no es n
ecesario instalar un tiempo de espera para asegurar que las señales asíncronas se manejen de manera oportuna.

CONSTANTE

S

"SOURCE_REMOVE" y "SOURCE_CONTINUE" están diseñadas para usarse como los valores de retorno de las funciones de fuentes de tiempo de espera, ociosas y de vigilancia de E/S. Devuelven true para mantenerse en ejecución o false para eliminarse a sí mismas. Estas constantes pueden ayudarte a hacerlo de la manera

correcta. 
Glib::SOURCE_CONTINUE
# true Glib::SOURC
E_REMOVE # false
