optiongroup = Glib::OptionGroup->new (clave => valor, ...

)

Crea un nuevo grupo de opciones a partir de los pares clave-valor proporcionados. Las claves válidas son name, description, help_description y entries. Las tres primeras especifican cadenas, mientras que la última, entries, especifica una referencia a un array de entradas de opción.

Ejemplo: 
my $group = Glib::OptionGroup->new (
              name => 'urgs',
              description => 'Urgs Urgs Urgs',
              help_description => 'Help with Urgs',
              entries => \@entries)
;

Una entrada de opción es una referencia a un hash como

esta: 
{ long_name => 'verbose',
  short_name => 'v',
  flags => [qw/reverse hidden in-main/],
  arg_type => 'none',
  arg_value => \$verbose,
  description => 'verbose desc.',
  arg_description => 'verbose arg desc.'
}

De todas esas claves, solo long_name, arg_type y arg_value son obligatorias. Así que esta también es una entrada de opción

válida: 
{ long_name => 'package-names',
  arg_type => 'string-array',
  arg_value => \$package_names
}

Por conveniencia, las entradas de opción también pueden especificarse como referencias a arrays que contienen long_name, short_name, arg_type y

arg_value: 
[ 'filenames', 'f', 'filename-array', \$filenames
]

Si no quieres que una opción tenga un nombre corto, especifica undef para

él: 
[ 'filenames', und
ef, 'filename-arr
ay', \$filenames ]
