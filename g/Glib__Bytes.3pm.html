NOMBRE

Glib::Bytes - Envoltorios para objetos de bytes en GLib

JERARQUÍA

Glib::Boxed
+----Glib::Bytes

DESCRIPCIÓN

Además de la API de bajo nivel documentada a continuación, Glib también proporciona sobrecargas de stringificación para que puedas tratar cualquier objeto de "Glib::Bytes" como una cadena normal de Perl.
