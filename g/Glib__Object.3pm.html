NOMBRE

Glib::Object - Enlaces para GObject

DESCRIPCIÓN

GObject es la clase base de objetos proporcionada por la biblioteca gobject. Proporciona propiedades de objeto con un sistema de notificación y señales que se pueden emitir.

Glib::Object es la clase de objeto Perl correspondiente. Los Glib::Objects están representados por referencias a hash bendecidas, con una conexión mágica al objeto C subyacente.

get y set

Algunas subclases de "Glib::Object" anulan "get" y "set" con métodos más útiles para la subclase, por ejemplo, "Gtk2::TreeModel" obtiene y establece el contenido de las filas.

Esto se hace generalmente cuando la subclase no tiene propiedades de objeto. Cualquier propiedad de objeto que tenga, o que tenga una subclase posterior, siempre se puede acceder con "get_property" y "set_property" (junto con "find_property" y "list_properties" para consultarlas).

El código genérico para cualquier subclase de objeto puede usar los nombres "get_property" y "set_property" para asegurarse de obtener las propiedades del objeto como tales.

MÉTODOS

objeto = $clase->new (...)

•
... (lista) pares clave/valor, valores de propiedad a establecer en la creación

Instancia un Glib::Object de tipo $clase. Cualquier par clave/valor en ... se utiliza para establecer propiedades en el nuevo objeto; véase "set". Esto está diseñado para ser heredado por subclases derivadas de Perl (ver Glib::Object::Subclass), pero en realidad puede usarlo para crear cualquier tipo derivado de GObject.

escalar = Glib::Object->new_from_pointer ($puntero, $sininc=FALSE)

  • $puntero (sin signo) un valor de puntero C como un entero.
  • $sininc (booleano) si es verdadero, no aumente el recuento de referencias del GObject al crear el envoltorio de Perl. esto típicamente significa que cuando el envoltorio de Perl poseerá el objeto. en general, no querrá hacer eso, por lo que el valor predeterminado es falso.

Crea una referencia Glib::Object de Perl para el objeto C al que apunta $puntero. Debería necesitar esto *muy* raramente; está destinado a admitir objetos extranjeros.

NOTA: la conversión de entero arbitrario a GObject puede resultar en un volcado de núcleo sin advertencia, porque la macro de verificación de tipo G_OBJECT() intenta desreferenciar el puntero para encontrar una estructura GTypeClass, y no hay una forma portátil de validar el puntero.

sin signo = $objeto->get_data ($clave)

•
$clave (cadena)

Recupera el entero almacenado bajo la clave de datos del objeto $clave. Estos valores no tienen tipos; las conversiones de tipo deben hacerse manualmente. Ver "set_data".

$objeto->set_data ($clave, $datos)

  • $clave (cadena)
  • $datos (escalar)

GObject proporciona un mecanismo de datos arbitrario que asigna enteros sin signo a nombres de clave. La funcionalidad se superpone con el hash utilizado como instancia del objeto Perl, por lo que recomendamos encarecidamente que utilice claves de hash para almacenar sus datos. Los valores de datos de GObject no pueden almacenar información de tipo, por lo que no son seguros para nada más que valores enteros, y realmente solo debe usar este método si sabe lo que está haciendo.

pspec o undef = $objeto_o_nombre_clase->find_property ($nombre)

•
$nombre (cadena)

Encuentra la definición de la propiedad del objeto $nombre para $objeto_o_nombre_clase. Devuelve "undef" si no existe tal propiedad. Para los datos devueltos, ver Glib::Object::list_properties.

$objeto->freeze_notify

Detiene la emisión de señales de "notify" en $objeto. Las señales se ponen en cola hasta que se llama a "thaw_notify" en $objeto.

$objeto->get (...)

•
... (lista) lista de nombres de propiedades

Alias de "get_property" (ver "get y set" arriba).

$objeto->set (clave => $valor, ...)

•
... (lista) pares clave/valor

Alias de "set_property" (ver "get y set" arriba).

lista = $objeto_o_nombre_clase->list_properties

Enumera todas las propiedades del objeto para $objeto_o_nombre_clase; las devuelve como una lista de hashes, que contiene estas claves:

nombre
El nombre de la propiedad
tipo
El tipo de la propiedad
tipo_propietario
El tipo que posee la propiedad
descripción
La descripción de la propiedad
banderas
Las Glib::ParamFlags de la propiedad

$objeto->notify ($nombre_propiedad)

•
$nombre_propiedad (cadena)

Emite una señal de "notify" para la propiedad $propiedad en $objeto.

puntero_g = $objeto->get_pointer

Complemento de "new_from_pointer".

$objeto->get_property (...)

Recupera y devuelve los valores de las propiedades del objeto nombradas en ....

$objeto->set_property (clave => $valor, ...)

Establece las propiedades del objeto.

unsigned = $objeto_o_nombre_clase->signal_add_emission_hook ($señal_detallada, $func_gancho, $datos_gancho=undef)

  • $señal_detallada (cadena) del formato name::detail, o solo name para enlazar con todas las señales del nombre dado.
  • $func_gancho (subrutina de Perl)
  • $datos_gancho (escalar) opcional para pasar a la subrutina del gancho.

Este es un gancho para la emisión de señales GObject. Cuando una señal que coincide con $señal_detallada está a punto de ser emitida, se llama a $func_gancho. Si el gancho devuelve verdadero, la señal se emitirá. Si el gancho devuelve falso, la señal se bloqueará y no se emitirá.

El gancho recibe los siguientes argumentos:

•
El objeto que emite la señal
•
El nombre detallado de la señal
•
Una lista de argumentos de señal
•
$datos_gancho

Si el gancho devuelve verdadero, la señal se emitirá. Si el gancho devuelve falso, la señal se bloqueará.

Hay que tener cuidado con la llamada a signal_emit() o signal_emit_stop() dentro del gancho, ya que podría provocar un bucle infinito si el gancho es para la misma señal que se está intentando emitir/detener.

booleano = $object->thaw_notify

Reanuda la emisión de señales de "notify" en $object. Si ha habido llamadas pendientes a "freeze_notify", las señales solo se emitirán cuando el número de llamadas a "thaw_notify" coincida con el número de llamadas a "freeze_notify".

Devuelve verdadero si las señales se emitirán inmediatamente, falso si están todavía congeladas.
