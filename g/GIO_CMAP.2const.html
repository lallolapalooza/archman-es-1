ioctl_kd(2) Manual de llamadas al sistema ioctl_kd(2)

NOMBRE

ioctl_kd - ioctls para terminal de consola y consolas virtuales

SINOPSIS

#include <linux/kd.h>  /* Definición de las constantes de operación */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones ioctl(2) específicas de Linux son soportadas para terminales de consola y consolas virtuales.

KDGETLED
Obtener el estado de los LEDs. argp apunta a un char. Los tres bits inferiores de *argp se establecen al estado de los LEDs, como sigue:
LED_CAP 0x04 led de Bloq Mayús
LED_NUM 0x02 led de Bloq Num
LED_SCR 0x01 led de Bloq Despl
KDSETLED
Establecer los LEDs. Los LEDs se configuran para corresponder a los tres bits inferiores del entero sin signo en argp. Sin embargo, si se establece un bit de orden superior, los LEDs vuelven a la normalidad: mostrando el estado de las funciones del teclado de Bloq Mayús, Bloq Num y Bloq Despl.

Antes de Linux 1.1.54, los LEDs solo reflejaban el estado de las banderas correspondientes del teclado, y KDGETLED/KDSETLED también modificaban las banderas del teclado. Desde Linux 1.1.54, los LEDs pueden mostrar información arbitraria, pero por defecto muestran las banderas del teclado. Los dos siguientes ioctls se utilizan para acceder a las banderas del teclado.

KDGKBLED
Obtener las banderas del teclado Bloq Mayús, Bloq Num, Bloq Despl (no las luces). argp apunta a un char que se establece al estado de la bandera. Los tres bits de orden inferior (máscara 0x7) obtienen el estado actual de la bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) obtienen el estado predeterminado de la bandera. (Desde Linux 1.1.54.)
KDSKBLED
Establecer las banderas del teclado Bloq Mayús, Bloq Num, Bloq Despl (no las luces). argp es un entero sin signo que tiene el estado de bandera deseado. Los tres bits de orden inferior (máscara 0x7) tienen el estado de bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) tienen el estado predeterminado de bandera. (Desde Linux 1.1.54.)
KDGKBTYPE
Obtener el tipo de teclado. Esto devuelve el valor KB_101, definido como 0x02.
KDADDIO
Añadir puerto de E/S como válido. Equivalente a ioperm(arg,1,1).
KDDELIO
Eliminar puerto de E/S como válido. Equivalente a ioperm(arg,1,0).
KDENABIO
Habilitar E/S a la placa de vídeo. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Deshabilitar E/S a la placa de vídeo. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Establecer modo texto/gráficos. argp es un entero sin signo que contiene uno de:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtener modo texto/gráficos. argp apunta a un int que se establece a uno de los valores mostrados arriba para KDSETMODE.
KDMKTONE
Generar tono de longitud especificada. Los 16 bits inferiores del entero sin signo en argp especifican el período en ciclos de reloj, y los 16 bits superiores dan la duración en mseg. Si la duración es cero, el sonido se apaga. El control regresa inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especificaría el pitido normalmente asociado con un ctrl-G. (Por lo tanto, desde Linux 0.99pl1; roto en Linux 2.1.49-50.)
KIOCSOUND
Iniciar o detener la generación de sonido. Los 16 bits inferiores de argp especifican el período en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En ambos casos, el control regresa inmediatamente.
GIO_CMAP
Obtener el mapa de colores predeterminado actual del kernel. argp apunta a un array de 48 bytes. (Desde Linux 1.3.3.)
PIO_CMAP
Cambiar el mapa de colores predeterminado en modo texto. argp apunta a un array de 48 bytes que contiene, en orden, los valores Rojo, Verde y Azul para los 16 colores de pantalla disponibles: 0 es apagado, y 255 es intensidad completa. Los colores predeterminados son, en orden: negro, rojo oscuro, verde oscuro, marrón, azul oscuro, púrpura oscuro, cian oscuro, gris claro, gris oscuro, rojo brillante, verde brillante, amarillo, azul brillante, púrpura brillante, cian brillante y blanco. (Desde Linux 1.3.3.)
GIO_FONT
Obtiene la fuente de pantalla de 256 caracteres en forma expandida. argp apunta a un array de 8192 bytes. Falla con código de error EINVAL si la fuente cargada actualmente es una fuente de 512 caracteres, o si la consola no está en modo de texto.
GIO_FONTX
Obtiene la fuente de pantalla y la información asociada. argp apunta a una struct consolefontdesc (ver PIO_FONTX). Al llamar, el campo charcount debe establecerse al número máximo de caracteres que cabrían en el buffer apuntado por chardata. Al regresar, charcount y charheight se llenan con los datos respectivos para la fuente cargada actualmente, y el array chardata contiene los datos de la fuente si el valor inicial de charcount indicó que había suficiente espacio; de lo contrario, el buffer no se modifica y errno se establece a ENOMEM. (Desde Linux 1.3.1.)
PIO_FONT
Establece la fuente de pantalla de 256 caracteres. Carga la fuente en el generador de caracteres EGA/VGA. argp apunta a un mapa de 8192 bytes, con 32 bytes por carácter. Solo los primeros N de ellos se usan para una fuente de 8xN (0 < N <= 32). Esta llamada también invalida el mapeo Unicode.
PIO_FONTX
Establece la fuente de pantalla y la información de renderizado asociada. argp apunta a un

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en la fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de escaneo por
                                  carácter (1-32) */
    char          *chardata;   /* datos de la fuente en
                                  forma expandida */
};

Si es necesario, la pantalla se redimensionará adecuadamente, y se enviará SIGWINCH a los procesos apropiados. Esta llamada también invalida el mapeo Unicode. (Desde Linux 1.3.1.)
PIO_FONTRESET
Restablece la fuente de pantalla, el tamaño y el mapeo Unicode a los valores predeterminados al arrancar. argp no se utiliza, pero debe establecerse a NULL para garantizar la compatibilidad con futuras versiones de Linux. (Desde Linux 1.3.28.)
GIO_SCRNMAP
Obtener el mapa de pantalla del kernel. argp apunta a un área de tamaño E_TABSZ, que se carga con las posiciones de fuente utilizadas para mostrar cada carácter. Es probable que esta llamada devuelva información inútil si la fuente cargada actualmente tiene más de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapa de pantalla Unicode completo del kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), que se carga con los Unicodes que representa cada carácter. Un conjunto especial de Unicodes, a partir de U+F000, se utiliza para representar mapeos de "directo a fuente". (Desde Linux 1.3.1.)
PIO_SCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a símbolos de pantalla de consola. argp apunta a un área de tamaño E_TABSZ.
PIO_UNISCRNM
AP
Carga la tabla "definible por el usuario" (cuarta) en el kernel, la cual mapea bytes a Unicode, los cuales son luego traducidos a símbolos de pantalla de acuerdo con el mapa Unicode-a-fuente actualmente cargado. Se pueden usar Unicodes especiales que comienzan en U+F000 para mapear directamente a los símbolos de la fuente. (Desde Linux 1.3.
1.)
