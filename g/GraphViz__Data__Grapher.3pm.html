NOMBRE

GraphViz::Data::Grapher - Visualiza estructuras de datos como un grafo

SINOPSIS

use GraphViz::Data::Grapher;
my $graph = GraphViz::Data::Grapher->new($structure);
print $graph->as_png;

DESCRIPCIÓN

Este módulo facilita la visualización de estructuras de datos de Perl. Las estructuras de datos pueden crecer bastante y puede ser difícil entender cómo encaja la estructura.

Data::Dumper puede ayudar representando la estructura como una jerarquía de texto, pero GraphViz::Data::Grapher va un paso más allá y visualiza la estructura dibujando un grafo que representa la estructura de datos.

Los arrays se representan mediante registros. Los escalares se representan a sí mismos. Las referencias a arrays se representan mediante un símbolo '@', que está enlazado al array. Las referencias a hashes se representan mediante un símbolo '%', que está enlazado a un array de claves, cada una de las cuales enlaza a su valor. Las referencias a objetos se representan mediante 'Object', que luego enlaza al tipo del objeto. Undef se representa mediante 'undef'.

MÉTODOS

new

Este es el constructor. Toma una lista, que es la estructura de datos a visualizar. Se devuelve un objeto GraphViz.

my $graph = GraphViz::Data::Grapher->new([3, 4, 5], "Hola");

as_*

La estructura de datos puede visualizarse en varios formatos gráficos. Los métodos incluyen as_ps, as_hpgl, as_pcl, as_mif, as_pic, as_gd, as_gd2, as_gif, as_jpeg, as_png, as_wbmp, as_ismap, as_imap, as_vrml, as_vtx, as_mp, as_fig, as_svg. Consulte la documentación de GraphViz para obtener más información. Los dos métodos más comunes son:

# Imprime un archivo en formato PNG
print $graph->as_png;
# Imprime un archivo en formato PostScript
print $graph->as_ps;
