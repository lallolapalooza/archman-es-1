NOMBRE

GraphicsMagick++-config - obtener información sobre la versión instalada de Magick++

SINOPSIS

GraphicsMagick++-config [--cppflags] [--cxxflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPCIÓN

GraphicsMagick++-config imprime las opciones del compilador y del enlazador necesarias para compilar y enlazar programas que utilizan la Interfaz de Programación de Aplicaciones (API) C++ de GraphicsMagick (conocida como Magick++).

EJEMPLOS

Para imprimir la versión de la distribución instalada de Magick++, utiliza:

  GraphicsMagick++-config --version

Para compilar un programa que llama a la Interfaz de Programación de Aplicaciones C++ de GraphicsMagick, utiliza:

  c++ `GraphicsMagick++-config --cxxflags --cppflags --ldflags --libs` programa.cpp

OPCIONES

--cppflags
Imprime las opciones del preprocesador necesarias para encontrar los archivos de inclusión C y C++ de GraphicsMagick y las definiciones para asegurar que las estructuras de datos de GraphicsMagick coinciden entre tu programa y las bibliotecas instaladas.
--cxxflags
Imprime las opciones del compilador que se utilizaron para compilar libMagick++.
--exec-prefix
Imprime el directorio bajo el cual se instalan los binarios y ejecutables específicos del objetivo.
--ldflags
Imprime las opciones del enlazador necesarias para enlazar con la biblioteca libMagick++.
--libs
Imprime las opciones del enlazador necesarias para enlazar un programa con libMagick++.
--prefix
Imprime el directorio bajo el cual se instala el paquete.
--version
Imprime la versión de la distribución de GraphicsMagick en la salida estándar.
