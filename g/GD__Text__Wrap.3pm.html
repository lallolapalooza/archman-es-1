NOMBRE

GD::Text::Wrap - Ajustar cadenas de texto en cajas

SINOPSIS

use GD;
use GD::Text::Wrap;
my $gd = GD::Image->new(800,600);
# asignar colores, hacer otras cosas.

my $text = <<EOSTR;
Lorem ipsum dolor sit amet, consectetuer adipiscing elit, 
sed diam nonummy nibh euismod tincidunt ut laoreet dolore 
magna aliquam erat volutpat.
EOSTR

my $wrapbox = GDTextWrap->new( $gd,
    line_space  => 4,
    color       => $black,
    text        => $text,
);
$wrapbox->set_font(gdMediumBoldFont);
$wrapbox->set_font('arial', 12);
$wrapbox->set(align => 'left', width => 120);
$wrapbox->draw(10,140);
$gd->rectangle($wrap_box->get_bounds(10,140), $color);

DESCRIPCIÓN

GD::Text::Wrap proporciona un objeto que dibuja un párrafo formateado de texto en una caja sobre un lienzo GD::Image, utilizando una fuente GD integrada o una fuente TrueType.

MÉTODOS

Esta clase no hereda directamente de GD::Text, sino que delega la mayor parte de su trabajo a ella (de hecho, a un objeto GD::Text::Align. Eso significa que la mayoría de los métodos de GD::Text::Align están disponibles para esta clase, específicamente "set_font" y "font_path". Otros métodos y métodos con una interfaz diferente se describen aquí:

GD::Text::Wrap->new( $objeto_gd, atributo => valor, ... )

Crea un nuevo objeto. El primer argumento para new tiene que ser un objeto GD::Image válido. Los otros argumentos se pasarán al método set() para la inicialización de los atributos.

$wrapbox->set( atributo => valor, ... )

Establece el valor de un atributo. Los atributos válidos son:

ancho
El ancho de la caja en la que dibujar el texto. Si no se especifica, por defecto será el ancho del objeto GD::Image.
espacio_linea
El número de píxeles entre líneas. Por defecto es 2.
espacio_parrafo, espacio_párrafo
El número de píxeles extra entre párrafos, además del espacio entre líneas. Por defecto es 0.
color, color
Sinónimos. El color a utilizar al dibujar la fuente. Se inicializará con el último color de la paleta del objeto GD.
alineacion, alineación
Sinónimos. Uno de 'justificado' (el valor por defecto), 'izquierda', 'derecha' o 'centrado'.
texto
El texto a dibujar. Este es el único atributo que debes establecer absolutamente.
conservar_nl
Si se establece a un valor verdadero, los saltos de línea en el texto causarán un salto de línea. Ten en cuenta que las líneas seguirán estando justificadas. Si solo aparece una palabra en la línea, podría quedar mal. Por defecto es 0.

Al igual que con los métodos, los atributos desconocidos para esta clase se delegan a la clase GD::Text::Align.

$wrapbox->get( atributo );

Obtiene el valor actual de un atributo. Todos los atributos mencionados bajo el método set() pueden ser recuperados.

$wrapbox->get_bounds()

Devuelve el cuadro delimitador de la caja que se dibujará con la configuración de atributos actual como una lista. Los valores devueltos son las coordenadas de la esquina superior izquierda y la inferior derecha.

($izquierda, $arriba, $derecha, $abajo) = $wrapbox->get_bounds();

Devuelve una lista vacía en caso de error.

NOTA: La lista devuelta por este método puede cambiar en una futura implementación que permita cajas anguladas.

$wrapbox->draw(x, y)

Dibuja la caja, con (x,y) como la esquina superior derecha. Devuelve los mismos valores que el método getbounds().

NOTA: La lista devuelta por este método puede cambiar en una futura implementación que permita cajas anguladas.

NOTAS

Como con todos los Módulos para Perl: Por favor, utilicen la interfaz. Si intentan manipular demasiado con el conocimiento interno de este módulo, podrían salir perjudicados. Puedo cambiarlos en cualquier momento.

Solo se pueden usar fuentes TrueType con versiones de GD > 1.20, y entonces solo si se compilaron con soporte para ello. Si intentan hacerlo de todos modos, obtendrán errores.

Aunque este módulo vive en el espacio de nombres GD::Text, no es un GD::Text. Sin embargo, delega mucha de su funcionalidad a un objeto contenido que lo es (GD::Text::Align).
