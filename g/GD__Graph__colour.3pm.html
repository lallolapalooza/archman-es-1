NOMBRE

GD::Graph::colour - Rutinas de manipulación de color para usar con GD::Graph

SINOPSIS

use GD::Graph::colour qw(:colours :lists :files :convert);

DESCRIPCIÓN

El paquete GD::Graph::colour proporciona algunas rutinas para trabajar con colores. La funcionalidad de este paquete se define principalmente por lo que se necesita, ahora y históricamente, por los módulos GD::Graph.

FUNCIONES

lista_de_colores( numero de colores )

Devuelve una lista de numero de colores nombres de color conocidos por el paquete. Exportado con la etiqueta :lists.

lista_de_colores_ordenada( numero de colores )

Devuelve una lista de numero de colores nombres de color conocidos por el paquete, ordenados por luminancia o matiz. NB. En este momento siempre se ordena por luminancia. Se añadirá una opción en una etapa posterior para decidir el método de ordenación en tiempo de ejecución. Exportado con la etiqueta :lists.

rgb( nombre del color )

Devuelve una lista de los valores RGB del nombre del color. Si el nombre del color es una cadena de la forma aceptable para la subrutina hex2rgb, entonces el color se añadirá dinámicamente a la lista. Exportado con la etiqueta :colours.

matiz( R,G,B )

Devuelve el matiz del color con los valores RGB especificados. Exportado con la etiqueta :colours.

luminancia( R,G,B )

Devuelve la luminancia del color con los valores RGB especificados. Exportado con la etiqueta :colours.

agregar_color(nombrecolor => [$r, $g, $b]) o agregar_color('#7fe310')

Autoexplicativo. Exportado con la etiqueta :colours.

rgb2hex($rojo, $verde, $azul)

hex2rgb('#7fe310')

Estas funciones traducen una lista de valores RGB a una cadena hexadecimal, tal como se usa comúnmente en HTML y en la API de Image::Magick, y viceversa. Exportado con la etiqueta :convert.

leer_rgb( nombre de archivo )

Lee colores de un archivo rgb tal como lo usa el sistema X11.

Hacer algo como:

use GD::Graph::bars;
use GD::Graph::colour;
GD::Graph::colour::leer_rgb("rgb.txt") or die "no se pueden leer los colores";

Permitirá utilizar cualquier color definido en rgb.txt en su gráfico. Exportado con la etiqueta :files.

NOMBRES DE COLORES PREDEFINIDOS

blanco, lgris, gris, ngris, negro, lazul, azul, nazul, dorado, lamarillo, amarillo, namarillo, verdecl, verde, nverde, rclaro, rojo, nrojo, pclar, morado, nmorado, narnja, naranja, rosa, nrosa, marino, cyan, marroncl, marronn.
