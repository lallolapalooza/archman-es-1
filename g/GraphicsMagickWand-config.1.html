NOMBRE

GraphicsMagickWand-config - obtener información sobre la versión instalada de GraphicsMagick

SINOPSIS

GraphicsMagickWand-config [--cflags] [--cppflags] [--exec-prefix] [--ldflags] [--libs] [--prefix] [--version]

DESCRIPCIÓN

GraphicsMagickWand-config imprime las banderas del compilador y del enlazador requeridas para compilar y enlazar programas que usan la interfaz de programación de aplicaciones GraphicsMagick Wand.

EJEMPLOS

Para imprimir la versión de la distribución instalada de GraphicsMagick, use:

  GraphicsMagickWand-config --version

Para compilar un programa que llama a la interfaz de programación de aplicaciones GraphicsMagick Wand, use:

  cc `GraphicsMagickWand-config --cflags --cppflags --ldflags --libs` programa.c

OPCIONES

--cflags
Imprime las banderas del compilador que se usaron para compilar libGraphicsMagick.
--cppflags
Imprime las banderas del preprocesador que son necesarias para encontrar los archivos de inclusión C de GraphicsMagick y las definiciones para asegurar que las estructuras de datos de GraphicsMagick coincidan entre su programa y las bibliotecas instaladas.
--exec-prefix
Imprime el directorio bajo el cual se instalan los binarios y ejecutables específicos del destino.
--ldflags
Imprime las banderas del enlazador que son necesarias para enlazar con la biblioteca GraphicsMagickWand.
--libs
Imprime las banderas del enlazador que son necesarias para enlazar un programa con libMagick.
--version
Imprime la versión de la distribución de GraphicsMagick a la salida estándar.
