Gtk3::SimpleList(3) Documentación de Perl aportada por el usuario Gtk3::SimpleList(3)

NOMBRE

Gtk3::SimpleList - Una interfaz simple para el complejo widget de lista MVC de Gtk3

SINOPSIS

use Glib qw(TRUE FALSE);
use Gtk3 '-init';
use Gtk3::SimpleList;
my $slist = Gtk3::SimpleList->new (
              'Campo de texto'    => 'text',
              'Campo de marcado'  => 'markup',
              'Campo entero'      => 'int',
              'Campo doble'       => 'double',
              'Campo booleano'    => 'bool',
              'Campo escalar'     => 'scalar',
              'Campo pixbuf'      => 'pixbuf',
            );
@{$slist->{data}} = (
        [ 'texto', 1, 1.1,  TRUE, $var, $pixbuf ],
        [ 'texto', 2, 2.2, FALSE, $var, $pixbuf ],
);
# (casi) todo lo que puedes hacer con un array puedes hacerlo con
# $slist->{data} que es una referencia a un array vinculado al modelo de lista
push @{$slist->{data}}, [ 'texto', 3, 3.3, TRUE, $var, $pixbuf ];
# manipular selecciones
$slist->get_selection->set_mode ('multiple');
$slist->get_selection->unselect_all;
$slist->select (1, 3, 5..9); # seleccionar filas por índice
$slist->unselect (3, 8); # deseleccionar filas por índice
@sel = $slist->get_selected_indices;
# forma sencilla de hacer editables las columnas de texto
$slist->set_column_editable ($col_num, TRUE);
# Gtk3::SimpleList hereda de Gtk3::TreeView, por lo que todos los métodos
# de un treeview están disponibles.
$slist->set_rules_hint (TRUE);
$slist->signal_connect (row_activated => sub {
        my ($sl, $path, $column) = @_;
        my $row_ref = $sl->get_row_data_from_path ($path);
        # $row_ref es ahora una referencia a un array con los datos de la fila doblemente pulsada.
    });
# convertir un TreeView existente en un SimpleList; útil para
# interfaces generadas con Glade.
$simplelist = Gtk3::SimpleList->new_from_treeview (
                  $glade->get_widget ('treeview'),
                  'Campo de texto'    => 'text',
                  'Campo entero'      => 'int',
                  'Campo doble'       => 'double',
               );

RESUMEN

SimpleList es una interfaz simple para la poderosa pero compleja combinación de Gtk3::TreeView y Gtk3::ListStore, que implementa arrays vinculados para hacer las cosas simples y fáciles.

DESCRIPCIÓN

Gtk3 tiene un sistema MVC (Modelo, Vista, Controlador) poderoso pero complejo utilizado para implementar widgets de listas y árboles. Gtk3::SimpleList automatiza la configuración compleja y le permite tratar el modelo de lista como una estructura más natural de listas de listas.

Después de crear un nuevo objeto Gtk3::SimpleList con las columnas deseadas, puede establecer los datos de la lista con una simple asignación de array de Perl. Las filas pueden añadirse o eliminarse con todas las operaciones normales de array. Puede tratar el "data" miembro del objeto de lista simplelist como una referencia a un array, y manipular los datos de la lista con los operadores normales de array de Perl.

También se ha implementado un mecanismo que permite que las columnas sean escalares de Perl. El escalar se convierte en texto a través de los mecanismos normales de Perl y luego se muestra en la lista. Este mismo mecanismo puede ampliarse definiendo nuevos tipos de columna arbitrarios antes de llamar a la función new.

MÉTODOS

$slist = Gtk3::SimpleList->new ($cname, $ctype, ...)
  • $cname (cadena)
  • $ctype (cadena)

Crea un nuevo objeto Gtk3::SimpleList con las columnas especificadas. El parámetro "cname" es el nombre de la columna, lo que se mostrará en los encabezados de la lista si están activados. El parámetro ctype es el tipo de columna, uno de:

text    cadenas de texto normales
markup  cadenas de marcado pango
int     valores enteros
double  valores de punto flotante de doble precisión
bool    valores booleanos, mostrados como casillas de verificación conmutable
scalar  un escalar de Perl, mostrado como una cadena de texto por defecto
pixbuf  un Gtk3::Gdk::Pixbuf

o el nombre de un tipo personalizado que añada con "add_column_type". Estos deben proporcionarse en pares según las columnas deseadas para su lista.

$slist = Gtk3::SimpleList->new_from_treeview ($treeview, $cname, $ctype, ...)
  • $treeview (Gtk3::TreeView)
  • $cname (cadena)
  • $ctype (cadena)

Como "Gtk3::SimpleList->new()", pero convierte un Gtk3::TreeView existente en un Gtk3::SimpleList. Esto está destinado principalmente para su uso con herramientas como Glade, donde el widget es creado por usted. Esto creará y adjuntará un nuevo modelo y eliminará cualquier columna existente de treeview. Devuelve treeview, re-bendecido como un Gtk3::SimpleList.

$slist->set_data_array ($arrayref)
•
$arrayref (referencia a array)

Establece los datos en la lista a la referencia de array $arrayref. Esto es completamente equivalente a @{$list->{data}} = @{$arrayref} y está aquí solo por conveniencia y para aquellos programadores que no les gusta hacer type-casting y tienen datos estáticos, establecidos una sola vez.

@indices = $slist->get_selected_indices
Devuelve los índices de las filas seleccionadas en el ListStore.
$slist->get_row_data_from_path ($path)
•
$path (Gtk3::TreePath) la ruta de la fila deseada

Devuelve una referencia a un array con los datos de la fila indicada por $path.

$slist->select ($index, ...);
$slist->unselect ($index, ...);
•
$index (entero)

Selecciona o deselecciona filas en la lista por índice. Si la lista está configurada para selección múltiple, todos los índices en la lista serán establecidos/eliminados; de lo contrario, solo se usa el primero. Si la lista está configurada para sin selección, entonces no ocurre nada.

Para establecer el modo de selección, o para seleccionar todas o ninguna de las filas, use las cosas normales de TreeView/TreeSelection, por ejemplo $slist->get_selection y los métodos de TreeSelection "get_mode", "set_mode", "select_all", y "unselect_all".

$slist->set_column_editable ($index, $editable)
  • $index (entero)
  • $editable (booleano)
booleano = $slist->get_column_editable ($index)
•
$index (entero)

Esta es una interfaz muy simple para las celdas de texto editables de Gtk3::TreeView. Todas las columnas que usan el atributo "text" (básicamente, cualquier columna de texto o número, ver "add_column_type") tienen automáticamente callbacks instalados para actualizar los datos cuando se editan las celdas. Con "set_column_editable", puede habilitar la edición en el lugar.

"get_column_editable" le dice si la columna index es actualmente editable.

Gtk3::SimpleList->add_column_type ($type_name, ...)
$type_name (cadena)

Añade un nuevo tipo de columna a la lista de tipos posibles. Inicialmente seis se definen los tipos: text, int, double, bool, scalar y pixbuf. El tipo de columna bool utiliza un renderizador de celdas de conmutación (toggle), el pixbuf utiliza un renderizador de celdas de pixbuf, y el resto utilizan renderizadores de celdas de texto. En el proceso de añadir un nuevo tipo de columna puede usar cualquier renderizador de celdas que desee.

El primer parámetro es el nombre del tipo de columna, la lista de seis son ejemplos. No hay restricciones en los nombres e incluso puede sobrescribir los existentes si así lo desea. Los parámetros restantes son la definición del tipo que consiste en pares clave-valor. Hay tres requeridos: type, renderer y attr. La clave type determina qué tipo de dato real será almacenado en la representación subyacente del modelo; este es un nombre de paquete, p. ej. Glib::String, Glib::Int, Glib::Boolean, pero en general si quiere una estructura de datos Perl arbitraria, querrá usar 'Glib::Scalar'. La clave renderer debe contener el nombre de la clase del renderizador de celdas a crear para este tipo de columna; puede ser cualquiera de Gtk3::CellRendererText, Gtk3::CellRendererToggle, Gtk3::CellRendererPixbuf, u otro, posiblemente personalizado, clase de renderizador de celdas. La clave attr es mágica; puede ser una cadena, en cuyo caso especifica el atributo que será establecido desde la columna especificada (p. ej. 'text' para un renderizador de texto, 'active' para un renderizador de conmutación, etc.), o puede ser una referencia a una subrutina que será llamada cada vez que el renderizador necesite dibujar los datos.

Esta función, descrita como una GtkTreeCellDataFunc en la referencia de la API, recibirá 5 parámetros: $treecol, $cell, $model, $iter, $col_num (cuando SimpleList conecta la función, establece el número de columna a pasar como datos de usuario). El valor de datos para la celda particular en cuestión está disponible a través de $model->get ($iter, $col_num); luego puede hacer lo que sea que tenga que hacer para renderizar la celda de la manera que desee. Aquí hay algunos ejemplos:

# solo muestra el valor en un escalar como
# Perl lo convertiría a una cadena
Gtk3::SimpleList->add_column_type( 'a_scalar',
        type     => 'Glib::Scalar',
        renderer => 'Gtk3::CellRendererText',
        attr     => sub {
             my ($treecol, $cell, $model, $iter, $col_num) = @_;
             my $info = $model->get ($iter, $col_num);
             $cell->set (text => $info);
        }
   );
# suma los valores en una referencia de arreglo y muestra
# eso en un renderizador de texto
Gtk3::SimpleList->add_column_type( 'sum_of_array',
        type     => 'Glib::Scalar',
        renderer => 'Gtk3::CellRendererText',
        attr     => sub {
             my ($treecol, $cell, $model, $iter, $col_num) = @_;
             my $sum = 0;
             my $info = $model->get ($iter, $col_num);
             foreach (@$info)
             {
                 $sum += $_;
             }
             $cell->set (text => $sum);
        }
   );

MODIFICANDO LOS DATOS DE LA LISTA

Después de crear un nuevo objeto Gtk3::SimpleList habrá un miembro llamado "data" que es un arreglo vinculado (tied). Esto significa que los datos pueden ser tratados como un arreglo, pero en realidad los datos residen en otra cosa. No hay necesidad de entender los detalles de esto, solo significa que pone datos, saca datos y los modifica igual que cualquier otro arreglo. Esto incluye usar operaciones de arreglo como push, pop, unshift y shift. Para aquellos de ustedes muy familiarizados con perl esta sección resultará redundante, pero por si acaso:

Añadiendo y eliminando filas:

  # añade una fila al final de la lista
  push @{$slist->{data}}, [col1_data, col2_data, ..., coln_data];
  # extrae una fila del final de la lista
  $rowref = pop @{$slist->{data}};
  # añade una fila al principio de la lista
  unshift @{$slist->{data}}, [col1_data, col2_data, ..., coln_data];
  # extrae una fila del principio de la lista
  $rowref = shift @{$slist->{data}};
  # elimina la fila en el índice $n, indexado desde 0
  splice @{ $slist->{data} }, $n, 1;
  # establece la lista entera para que sea los datos en un arreglo
  @{$slist->{data}} = ( [row1, ...], [row2, ...], [row3, ...] );
Obteniendo los datos en la lista:

  # obtiene una referencia de arreglo a la fila n entera
  $rowref = $slist->{data}[n];
  # obtiene el escalar en la columna m de la fila n, indexado desde 0
  $val = $slist->{data}[n][m];
  # establece una referencia de arreglo a la fila n entera
  $slist->{data}[n] = [col1_data, col2_data, ..., coln_data];
  # obtiene el escalar en la columna m de la fila n, indexado desde 0
  $slist->{data}[n][m] = $rowm_coln_value;
