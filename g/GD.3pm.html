DESCRIPCIÓ

N

GD.pm es una interfaz de Perl para la biblioteca de gráficos gd de Thomas Boutell (versión 2.01 o superior; ver más abajo). GD le permite crear dibujos en color utilizando un gran número de primitivas gráficas, y emitir los dibujos como archivos

PNG.

GD define las siguientes cuatro

clases:
"GD::
Image"
Una clase de imagen, que contiene los datos de la imagen y acepta llamadas a métodos de primitivas
gráficas.
"GD::
Font"
Una clase de fuente, que contiene información estática de la fuente y se utiliza para el renderizado de
texto.
"GD::
Polygon"
Un objeto polígono simple, utilizado para almacenar listas de vértices antes de renderizar un polígono en una
imagen.
"GD::
Simple"
Una clase "simple" que simplifica la API de GD::Image y luego añade un conjunto de métodos de dibujo orientados a objetos utilizando
gráficos de tortuga, manejo simplificado de fuentes, capacidad para trabajar en coordenadas polares, espacios de color HSV y
nombres de color legibles por humanos como "lightblue". Por favor, consulte GD::Simple para una descripción de estos métodos.

Un ejemplo

sencillo: 
#!/usr/bin/perl
use GD;
# crear una nueva imagen
$im = GD::Image->new(100,100);
# asignar algunos colores
$white = $im->colorAllocate(255,255,255);
$black = $im->colorAllocate(0,0,0);       
$red = $im->colorAllocate(255,0,0);      
$blue = $im->colorAllocate(0,0,255);
# hacer que el fondo sea transparente e interlazado
$im->transparent($white);
$im->interlaced('true');
# Poner un marco negro alrededor de la imagen
$im->rectangle(0,0,99,99,$black);
# Dibujar un óvalo azul
$im->arc(50,50,95,75,0,360,$blue);
# Y rellenarlo con rojo
$im->fill(50,50,$red);
# asegurarnos de que estamos escribiendo en un flujo binario
binmode STDOUT;
# Convertir la imagen a PNG e imprimirla en la salida estándar
print $im->
png;

Notas

:
1. Para crear una nueva imagen vacía, envíe un mensaje new() a GD::Image, pasándole el ancho y el alto de la imagen que desea crear. Se devolverá un objeto de imagen. Otros métodos de clase le permiten inicializar una imagen a partir de archivos de imagen JPG, PNG, GD, GD2, XBM u otros soportados
preexistentes.
2. A continuación, normalmente añadirá colores a la tabla de colores de la imagen. Los colores se añaden utilizando una llamada al método colorAllocate(). Los tres parámetros en cada llamada son las tripletas rojo, verde y azul (rgb) para el color deseado. El método devuelve el índice de ese color en la tabla de colores de la imagen. Debería almacenar estos índices para su uso
posterior.
3. ¡Ahora puede dibujar! Las diversas primitivas gráficas se describen más abajo. En este ejemplo, hacemos algo de dibujo de texto, creamos un óvalo, y creamos y dibujamos un
polígono.
4. Los polígonos se crean con un mensaje new() a GD::Polygon. Puede añadir puntos al polígono devuelto uno a uno utilizando el método addPt(). El polígono puede entonces pasarse a una imagen para su
renderizado.
5. Cuando termine de dibujar, puede convertir la imagen al formato PNG enviándole un mensaje png() (o cualquier otro formato de imagen soportado). Devolverá un valor escalar (potencialmente grande) que contiene los datos binarios de la imagen. Normalmente la imprimirá en este punto o la escribirá en un archivo. Para asegurar la portabilidad en plataformas que diferencian entre archivos de texto y binarios, asegúrese de llamar a binmode() en el archivo en el que está escribiendo la
imagen.

Control de Color

Estos métodos le permiten controlar y manipular la tabla de colores de GD::Image para imágenes de paleta, no de color real.

$index = $image->colorAllocate(red,green,blue)
Esto asigna un color con los componentes rojo, verde y azul especificados y devuelve su índice en la tabla de colores, si se especifica. El primer color asignado de esta manera se convierte en el color de fondo de la imagen. (255,255,255) es blanco (todos los píxeles encendidos). (0,0,0) es negro (todos los píxeles apagados). (255,0,0) es rojo completamente saturado. (127,127,127) es gris al 50%. Puede encontrar muchos ejemplos en /usr/X11/lib/X11/rgb.txt.

Si no se asignan colores, esta función devuelve -1.

Ejemplo:

$black = $myImage->colorAllocate(0,0,0); # color de fondo
$white = $myImage->colorAllocate(255,255,255);
$peachpuff = $myImage->colorAllocate(255,218,185);
$index = $image->colorAllocateAlpha(reg,green,blue,alpha)
Esto asigna un color con los componentes rojo, verde y azul especificados, más el canal alfa especificado. El valor alfa puede variar de 0 (opaco) a 127 (transparente). La función "alphaBlending" cambia la forma en que este canal alfa afecta la imagen resultante.
$image->colorDeallocate(colorIndex)
Esto marca el color en el índice especificado como listo para ser reasignado. La próxima vez que se use colorAllocate, esta entrada será reemplazada. Puede llamar a este método varias veces para desasignar varios colores. No hay resultado de esta llamada.

Ejemplo:

Canales alfa

Los métodos de canal alfa te permiten controlar la forma en que los dibujos se procesan según el canal alfa. Cuando la imagen a color verdadero está activada, los colores se codifican como cuatro bytes, en los que los tres últimos bytes son los valores de color RGB y el primer byte es el canal alfa. Por lo tanto, la representación hexadecimal de un color RGB no transparente será: C=0x00(rr)(bb)(bb)

Cuando la mezcla alfa está activada, puedes usar el primer byte del color para controlar la transparencia, lo que significa que un rectángulo pintado con el color 0x00(rr)(bb)(bb) será opaco, y otro pintado con 0x7f(rr)(gg)(bb) será transparente. El valor Alfa debe ser >= 0 y <= 0x7f.

$image->alphaBlending($integer)
El método alphaBlending() permite dos modos diferentes de dibujo en imágenes a color verdadero. En modo de mezcla, que está activado por defecto (libgd 2.0.2 y superior), el componente del canal alfa del color suministrado a todas las funciones de dibujo, como "setPixel", determina cuánto del color subyacente se permitirá que brille a través. Como resultado, GD mezcla automáticamente el color existente en ese punto con el color de dibujo y almacena el resultado en la imagen. El píxel resultante es opaco. En modo sin mezcla, el color de dibujo se copia literalmente con su información de canal alfa, reemplazando el píxel de destino. El modo de mezcla no está disponible cuando se dibuja en imágenes de paleta.

Pasa un valor de 1 para el modo de mezcla y 0 para el modo sin mezcla.

$image->saveAlpha($saveAlpha)
Por defecto, GD (libgd 2.0.2 y superior) no intenta guardar información completa del canal alfa (a diferencia de la transparencia de un solo color) al guardar imágenes PNG. (PNG es actualmente el único formato de salida admitido por gd que puede acomodar información del canal alfa). Esto ahorra espacio en el archivo de salida. Si deseas crear una imagen con información del canal alfa para usarla con herramientas que la soporten, llama a saveAlpha(1) para activar el guardado de dicha información, y llama a alphaBlending(0) para desactivar la mezcla alfa dentro de la biblioteca para que la información del canal alfa se almacene realmente en la imagen en lugar de componerse inmediatamente en el momento en que se invocan las funciones de dibujo.
