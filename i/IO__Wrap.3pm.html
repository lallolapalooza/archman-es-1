IO::Wrap(3) Documentación aportada por el usuario de Perl IO::Wrap(3)

NOMBRE

IO::Wrap - Envuelve manejadores de archivo brutos en la interfaz IO::Handle

SINOPSIS

use strict;
use warnings;
use IO::Wrap;
# este es un caso de uso bastante sin sentido ya que IO::Handle ya hace esto.
my $wrap_fh = IO::Wrap->new(\*STDIN);
my $line = $wrap_fh->getline();
# Haz cosas con cualquier tipo de manejador de archivo (incluyendo un globref desnudo), o
# cualquier tipo de objeto bendecido que responda a un mensaje print().
# ¿ya tienes un globref? ¿un FileHandle? ¿un nombre de manejador de archivo escalar?
$wrap_fh = IO::Wrap->new($some_unknown_thing);
# ¡En este punto, sabemos que tenemos un objeto similar a IO::Handle! ¡YAY!
$wrap_fh->print("¡Hola!");

También puedes hacer esto usando una función de envoltorio de conveniencia

use strict;
use warnings;
use IO::Wrap qw(wraphandle);
# este es un caso de uso bastante sin sentido ya que IO::Handle ya hace esto.
my $wrap_fh = wraphandle(\*STDIN);
my $line = $wrap_fh->getline();
# Haz cosas con cualquier tipo de manejador de archivo (incluyendo un globref desnudo), o
# cualquier tipo de objeto bendecido que responda a un mensaje print().
# ¿ya tienes un globref? ¿un FileHandle? ¿un nombre de manejador de archivo escalar?
$wrap_fh = wraphandle($some_unknown_thing);
# ¡En este punto, sabemos que tenemos un objeto similar a IO::Handle! ¡YAY!
$wrap_fh->print("¡Hola!");

DESCRIPCIÓN

Supongamos que quieres escribir código que realiza E/S, pero no quieres obligar al llamador a proporcionarte un objeto FileHandle o IO::Handle. Quieres que puedan decir:

do_stuff(\*STDOUT);
do_stuff('STDERR');
do_stuff($some_FileHandle_object);
do_stuff($some_IO_Handle_object);

E incluso:

do_stuff($any_object_with_a_print_method);

Claro, una forma de hacerlo es obligar al llamador a usar tiehandle(). Pero eso le carga la responsabilidad. Otra forma de hacerlo es usar IO::Wrap.

Claramente, al envolver un manejador de archivo externo bruto (como "\*STDOUT"), no quise cerrar el descriptor de archivo cuando el objeto envoltorio sea destruido; ¡el usuario podría no apreciar eso! Por lo tanto, no hay un método "DESTROY" en esta clase.

Sin embargo, al envolver un objeto FileHandle, creo que Perl invocará el "FileHandle::DESTROY" cuando la última referencia desaparezca, por lo que en ese caso, el manejador de archivo se cerrará si el FileHandle envuelto era realmente la última referencia a él.

FUNCIONES

IO::Wrap pone a disposición las siguientes funciones.

wraphandle

# envuelve un glob de manejador de archivo
my $fh = wraphandle(\*STDIN);
# envuelve un glob de manejador de archivo bruto por nombre
$fh = wraphandle('STDIN');
# envuelve un manejador en un objeto
$fh = wraphandle('Class::HANDLE');
# envuelve un objeto FileHandle bendecido
use FileHandle;
my $fho = FileHandle->new("/tmp/foo.txt", "r");
$fh = wraphandle($fho);
# envuelve cualquier otro objeto bendecido que comparta la interfaz de IO::Handle
$fh = wraphandle($some_object);

Esta función es simplemente un envoltorio para el método constructor "new" en IO::Wrap.

MÉTODOS

IO::Wrap implementa los siguientes métodos.

close

$fh->close();

El método "close" intentará cerrar el descriptor de archivo del sistema. Para una descripción más completa, lee "close" en perlfunc.

fileno

my $int = $fh->fileno();

El método "fileno" devuelve el descriptor de archivo para el manejador de archivo envuelto. Vea "fileno" en perlfunc para más información.

getline

my $data = $fh->getline();

El método "getline" imita la función del mismo nombre en IO::Handle. Es como llamar a "my $data = <$fh>;" pero solo en contexto escalar.

getlines

my @data = $fh->getlines();

El método "getlines" imita la función del mismo nombre en IO::Handle. Es como llamar a "my @data = <$fh>;" pero solo en contexto de lista. Llamar a este método en contexto escalar resultará en un error.

new

# envuelve un glob de manejador de archivo
my $fh = IO::Wrap->new(\*STDIN);
# envuelve un glob de manejador de archivo bruto por nombre
$fh = IO::Wrap->new('STDIN');
# envuelve un manejador en un objeto
$fh = IO::Wrap->new('Class::HANDLE');
# envuelve un objeto FileHandle bendecido
use FileHandle;
my $fho = FileHandle->new("/tmp/foo.txt", "r");
$fh = IO::Wrap->new($fho);
# envuelve cualquier otro objeto bendecido que comparta la interfaz de IO::Handle
$fh = IO::Wrap->new($some_object);

El método constructor "new" toma un solo argumento y decide envolverlo o no basándose en lo que parece ser.

Se puede envolver un nombre de manejador de archivo bruto, como "STDOUT" o "Class::HANDLE", devolviendo una instancia de objeto IO::Wrap.

También se puede envolver un glob de manejador de archivo bruto, como "\*STDOUT", devolviendo una instancia de objeto IO::Wrawp.

También se puede envolver un objeto FileHandle bendecido. Este es un caso especial en el que solo se devolverá una instancia de objeto IO::Wrap en el caso de que su objeto FileHandle no admita el método "read".

Además, se puede pasar cualquier otro tipo de objeto bendecido que cumpla con la interfaz IO::Handle. En este caso, simplemente se devuelve ese objeto.

En otras palabras, solo lo envolvemos en un objeto IO::Wrap cuando lo que has proporcionado ya no cumple con la interfaz IO::Handle.

Si obtienes un objeto IO::Wrap, obedecerá un subconjunto básico de la interfaz "IO::". Lo hará con métodos de objeto, no con operadores.

ADVERTENCIAS

Este módulo no le permite envolver nombres de manejadores de archivo que se dan como cadenas que carecen del paquete en el que se abrieron. Es decir, si un usuario abre FOO en el paquete Foo, debe pasarlo a usted como "\*FOO" o como "Foo::FOO". Sin embargo, "STDIN" y similares funcionarán perfectamente.

print

$fh->print("Alguna cadena");
$fh->print("más", " de una", " cadena");

El método "print" intentará imprimir una cadena o una lista de cadenas en el manejador de archivo. Para una descripción más completa, lee "print" en perlfunc.

read

my $buffer;
# intenta leer 30 caracteres en el búfer comenzando desde la
# posición actual del cursor.
my $num_chars_read = $fh->read($buffer, 30);

El método read intenta leer un número de caracteres, comenzando en la posición actual del cursor del manejador de archivo. Devuelve el número de caracteres realmente leídos. Vea "read" en perlfunc para más información.

seek

use Fcntl qw(:seek); # importa las constantes SEEK_CUR, SEEK_SET, SEEK_END
# busca la posición en bytes
$fh->seek(0, SEEK_SET);
# busca la posición en bytes desde la posición actual
$fh->seek(22, SEEK_CUR);
# busca al final del archivo más bytes
$fh->seek(0, SEEK_END);

El método "seek" intentará establecer el cursor a una posición dada en bytes para el manejador de archivo envuelto. Vea "seek" en perlfunc para más información.

tell

my $bytes = $fh->tell();

El método "tell" intentará devolver la posición actual del cursor en bytes para el manejador de archivo envuelto. Vea "tell" en perlfunc para más información.

IO::Wrap(3pm)

NAME

IO::Wrap - A Wrapper for IO::Handle

SYNOPSIS

  use IO::Wrap;

  my $handle = new IO::Wrap \*STDIN;

  # ... do IO operations on $handle ...

  # get the underlying handle
  my $real_handle = $handle->rewind();

DESCRIPTION

This module provides a wrapper around the standard IO::Handle objects. It allows you to wrap existing filehandles, sockets, or other IO objects and apply additional functionality to them. The main purpose is to provide a consistent interface to various IO types and to allow you to manipulate them as if they were standard filehandles.

FUNCTIONS

There are no specific functions exported by this module. You create instances of IO::Wrap objects using the constructor.

METHODS

new IO::Wrap( $handle )
Constructs a new IO::Wrap object. The $handle argument should be a valid IO::Handle object or a glob reference.
rewind()
Returns the underlying IO::Handle object. This method is useful if you need to access the original handle's methods directly.
$handle->print(@args)
$handle->printf(@args)
$handle->say(@args)
$handle->read(@args)
$handle->sysread(@args)
$handle->syswrite(@args)
$handle->write(@args)
$handle->eof()
$handle->eof( \$var )
$handle->seek( \$pos, \$whence )
$handle->tell()
$handle->fileno()
$handle->open( \$mode )
$handle->close()
$handle->opened()
$handle->error()
$handle->clearerr()
$handle->flush()
$handle->autoflush( [ $bool ] )
$handle->blocking( [ $mode ] )
$handle->input_line_number( [ $n ] )
$handle->getline()
$handle->getc()
$handle->read_line()
$handle->read_chars( $n )
$handle->ungetc( $char )
$handle->binmode( [ $layer ] )
These methods are inherited from IO::Handle and are passed directly to the underlying handle.
