IO::HTML(3) Documentación de Perl aportada por el usuario IO::HTML(3)

NOMBRE

IO::HTML - Abrir un archivo HTML con detección automática de codificación

VERSIÓN

Este documento describe la versión 1.004 de IO::HTML, publicada el 26 de septiembre de 2020.

SINOPSIS

use IO::HTML;                 # exporta html_file por defecto
use HTML::TreeBuilder;
my $tree = HTML::TreeBuilder->new_from_file(
             html_file('foo.html')
           );
# Interfaz alternativa:
open(my $in, '<:raw', 'bar.html');
my $encoding = IO::HTML::sniff_encoding($in, 'bar.html');

DESCRIPCIÓN

IO::HTML proporciona una forma fácil de abrir un archivo que contiene HTML, determinando automáticamente su codificación. Utiliza el algoritmo de detección de codificación HTML5 especificado en la sección 8.2.2.2 del borrador estándar.

El algoritmo implementado aquí es:

1.
Si el archivo comienza con un marcador de orden de bytes (BOM) que indica UTF-16LE, UTF-16BE o UTF-8, entonces esa es la codificación.
2.
Si los primeros $bytes_to_check bytes del archivo contienen una etiqueta "<meta>" que indica el conjunto de caracteres (charset), y Encode reconoce el nombre de la codificación especificada, entonces esa es la codificación. (Esta parte del algoritmo es implementada por "find_charset_in").

La etiqueta "<meta>" puede tener uno de los siguientes formatos:

<meta charset="...">
<meta http-equiv="Content-Type" content="...charset=...">

La búsqueda no distingue entre mayúsculas y minúsculas, y el orden de los atributos dentro de la etiqueta es irrelevante. Cualquier atributo adicional de la etiqueta se ignora. La primera etiqueta coincidente con una codificación reconocida finaliza la búsqueda.

3.
Si los primeros $bytes_to_check bytes del archivo son UTF-8 válido (con al menos 1 carácter no ASCII), entonces la codificación es UTF-8.
4.
Si todo lo anterior falla, se utiliza la codificación de caracteres por defecto. El estándar HTML5 sugiere que la codificación por defecto debe depender de la configuración regional (locale), pero actualmente siempre es "cp1252" a menos que establezcas $IO::HTML::default_encoding a un valor diferente. Nota: "sniff_encoding" no aplica este paso; solo "html_file" lo hace.

SUBRUTINAS

html_file

$manejador_archivo = html_file($nombre_archivo, \%opciones);

Esta función (exportada por defecto) es el punto de entrada principal. Abre el archivo especificado por $nombre_archivo para lectura, utiliza "sniff_encoding" para encontrar una capa de codificación adecuada y la aplica. También aplica la capa ":crlf". Si el archivo comienza con un BOM, el manejador de archivo se posiciona justo después del BOM.

El segundo argumento opcional es un hashref que contiene opciones. Las claves posibles se describen en "find_charset_in".

Si "sniff_encoding" no puede determinar la codificación, usa por defecto $IO::HTML::default_encoding, que se establece a "cp1252" (también conocido como Windows-1252) por defecto. Según el estándar, la codificación por defecto debería depender de la configuración regional, pero eso no está implementado actualmente.

Muere (die) si el archivo no puede ser abierto, o si "sniff_encoding" no puede determinar la codificación y $IO::HTML::default_encoding se ha establecido a "undef".

html_file_and_encoding

($manejador_archivo, $codificación, $bom)
  = html_file_and_encoding($nombre_archivo, \%opciones);

Esta función (exportada solo bajo petición) es igual que "html_file", pero devuelve más información. Además del manejador de archivo, devuelve el nombre de la codificación utilizada y un indicador booleano que indica si se encontró un marcador de orden de bytes (si $bom es verdadero, el archivo comenzó con un BOM). Esto puede ser útil si quieres escribir el archivo de nuevo (especialmente en conjunto con la función "html_outfile").

El segundo argumento opcional es un hashref que contiene opciones. Las claves posibles se describen en "find_charset_in".

Muere (die) si el archivo no puede ser abierto, o si "sniff_encoding" no puede determinar la codificación y $IO::HTML::default_encoding se ha establecido a "undef".

El resultado de llamar a "html_file_and_encoding" en contexto escalar es indefinido (en el sentido C, no hay garantía de lo que obtendrás).

html_outfile

$manejador_archivo = html_outfile($nombre_archivo, $codificación, $bom);

Esta función (exportada solo bajo petición) abre $nombre_archivo para salida usando $codificación, y escribe un BOM en él si $bom es verdadero. Si $codificación es "undef", usa por defecto $IO::HTML::default_encoding. $codificación puede ser un nombre de codificación o un objeto Encode::Encoding.

Muere (die) si el archivo no puede ser abierto, o si tanto $codificación como $IO::HTML::default_encoding son "undef".

sniff_encoding

($codificación, $bom) = sniff_encoding($manejador_archivo, $nombre_archivo, \%opciones);

Esta función (exportada solo bajo petición) ejecuta el algoritmo de detección de codificación HTML5 en $manejador_archivo (que debe ser buscable y debería haber sido abierto en modo ":raw"). $nombre_archivo solo se usa para mensajes de error (si hay un problema al usar el manejador de archivo) y tiene un valor por defecto de "file" si se omite. El tercer argumento opcional es un hashref que contiene opciones. Las claves posibles se describen en "find_charset_in".

Devuelve el nombre canónico de Perl para la codificación, que no es necesariamente el mismo que el nombre del charset MIME o IANA. Devuelve "undef" si la codificación no puede ser determinada. $bom es verdadero si el archivo comenzó con un marcador de orden de bytes. En contexto escalar, solo devuelve $codificación.

La posición del manejador de archivo se restaura a su posición original (normalmente el principio del archivo) a menos que $bom sea verdadero. En ese caso, la posición está inmediatamente después del BOM.

Consejo: Si quieres ejecutar "sniff_encoding" en un archivo que ya has cargado en una cadena, abre un archivo en memoria sobre la cadena y pasa ese manejador:

($codificación, $bom) = do {
  open(my $fh, '<', \$string);  sniff_encoding($fh)
};

(Esto solo tiene sentido si $string contiene bytes, no caracteres.)

find_charset_in

$codificación = find_charset_in($cadena_que_contiene_HTML, \%opciones);

Esta función (exportada solo bajo petición) busca información de conjunto de caracteres en una etiqueta "<meta>" en un documento HTML posiblemente incompleto usando el algoritmo de "dos pasos" especificado por HTML5. No busca un BOM. La etiqueta "<meta>" debe comenzar dentro de los primeros $IO::HTML::bytes_to_check bytes de la cadena.

Devuelve el nombre canónico de Perl para la codificación, que no es necesariamente el mismo que el nombre del charset MIME o IANA. Devuelve "undef" si no se especifica ningún conjunto de caracteres o si el conjunto de caracteres especificado no es reconocido por el módulo Encode.

El segundo argumento opcional es un hashref que contiene opciones. Las siguientes claves son reconocidas:

"encoding"

EXPORTS

Por defecto, solo se exporta "html_file". Otras funciones pueden ser exportadas bajo petición.

Para personas que prefieren no exportar funciones, todas las funciones que comienzan con "html_" tienen un alias sin ese prefijo (por ejemplo, puedes llamar a IO::HTML::file(...) en lugar de IO::HTML::html_file(...). Estos alias no son exportables.

Las siguientes etiquetas de exportación están disponibles:

":all"
Todas las funciones exportables.
":rw"
"html_file", "html_file_and_encoding", "html_outfile".

VER TAMBIÉN

La especificación HTML5, sección 8.2.2.2 Determinación de la codificación de caracteres: http://www.w3.org/TR/html5/syntax.html#determining-the-character-encoding

DIAGNÓSTICOS

"No se pudo leer %s: %s"
El archivo especificado no se pudo leer por el motivo especificado por $!.
"No se pudo buscar %s: %s"
El archivo especificado no se pudo rebobinar por el motivo especificado por $!.
"Fallo al abrir %s: %s"
El archivo especificado no se pudo abrir para lectura por el motivo especificado por $!.
"No se especificó codificación por defecto"
El algoritmo "sniff_encoding" no encontró una codificación para usar, y configuraste $IO::HTML::default_encoding a "undef".

CONFIGURACIÓN Y ENTORNO

Hay dos variables globales que afectan a IO::HTML. Si necesitas cambiarlas, deberías hacerlo usando "local" si es posible:

my $file = do {
  # Este archivo puede definir el charset más tarde en la cabecera
  local $IO::HTML::bytes_to_check = 4096;
  html_file(...);
};
$bytes_to_check
Este es el número de bytes que "sniff_encoding" leerá del stream. También es el número de bytes que "find_charset_in" buscará en una etiqueta "<meta>" que contenga información del charset. Debe ser un entero positivo.

La especificación HTML 5 recomienda usar el valor por defecto de 1024, pero algunas páginas no siguen la especificación.

$default_encoding
Esta es la codificación que "html_file" y "html_file_and_encoding" usarán si "sniff_encoding" no puede detectar ninguna codificación. El valor por defecto es "cp1252" (también conocido como Windows-1252).

Configurarlo a "undef" hará que las subrutinas de archivo fallen si "sniff_encoding" no logra determinar la codificación. (El propio "sniff_encoding" no usa $default_encoding).

DEPENDENCIAS

IO::HTML no tiene dependencias no esenciales para Perl 5.8.7+. Con versiones anteriores de Perl 5.8, necesitas actualizar Encode a la versión 2.10 como mínimo, y podrías necesitar actualizar Exporter a la versión 5.57 como mínimo.
