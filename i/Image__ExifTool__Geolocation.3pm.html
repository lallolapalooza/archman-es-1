Image::ExifTool::Geolocation(3) Documentación de Perl contribuida por el usuario Image::ExifTool::Geolocation(3)

NOMBRE

Image::ExifTool::Geolocation - Determinar geolocalización desde GPS y viceversa

SINOPSIS

Buscar información de geolocalización (ciudad, región, subregión, país, etc.) basada en coordenadas GPS de entrada, o determinar coordenadas GPS basada en el nombre de la ciudad, etc.

DESCRIPCIÓN

Este módulo contiene el código para convertir coordenadas GPS a ciudad, región, subregión, país, zona horaria, etc. Utiliza una base de datos derivada de geonames.org, modificada para reducir el tamaño tanto como sea posible.

MÉTODOS

ReadDatabase

Cargar la base de datos de geolocalización desde un archivo. Este método se llama automáticamente cuando se carga este módulo. Por defecto, la base de datos se carga desde "Geolocation.dat" en el mismo directorio que este módulo, pero se puede usar un directorio diferente estableciendo $Image::ExifTool::Geolocation::geoDir antes de cargar este módulo. Establecer esto a una cadena vacía evita cargar cualquier base de datos. Se genera una advertencia si el archivo no se puede leer.

Image::ExifTool::Geolocation::ReadDatabase($filename);
Entradas:
0) Nombre del archivo de la base de datos
Valor de retorno:
Verdadero en caso de éxito.

ReadAltNames

Cargar la base de datos de nombres alternativos. Antes de llamar a este método, se puede establecer la variable del paquete $altDir, de lo contrario, AltNames.dat se carga desde el mismo directorio que Geolocation.dat. Este método es llamado automáticamente por "Geolocate" si se usa la opción GeolocAltNames y se proporciona un nombre de ciudad de entrada.

Image::ExifTool::Geolocation::ReadAltNames();
Entradas:
(ninguna)
Valor de retorno:
Verdadero en caso de éxito. Puede ser llamado repetidamente, pero AltNames.dat solo se carga en la primera llamada.

SortDatabase

Ordenar la base de datos en el orden especificado.

Image::ExifTool::Geolocation::SortDatabase('City');
Entradas:
0) Orden de clasificación: 'Latitude', 'City' o 'Country'
Valor de retorno:
1 en caso de éxito, 0 en caso de fallo (orden de clasificación especificado incorrectamente).

AddEntry

Añadir entrada a la base de datos de geolocalización.

Image::ExifTool::Geolocation::AddEntry($city, $region,
    $subregion, $countryCode, $country, $timezone,
    $featureCode, $population, $lat, $lon, $altNames);
Entradas:
0) Nombre de la ciudad (UTF8)

1) Nombre de la región, estado o provincia (UTF8), o cadena vacía si se desconoce

2) Nombre de la subregión (UTF8), o cadena vacía si se desconoce

3) Código de país ISO 3166 de 2 caracteres

4) Nombre del país (UTF8), o cadena vacía para usar la definición existente. Si se proporciona el nombre del país para un código de país que ya existe en la base de datos, la entrada de la base de datos se actualiza con el nuevo nombre del país.

5) Identificador de zona horaria (ej. "America/New_York")

6) Código de característica (ej. "PPL"), o vacío si se desconoce

7) Población de la ciudad

8) Latitud GPS (grados flotantes con signo)

9) Longitud GPS

10) Lista opcional separada por comas de nombres alternativos para la ciudad

Valor de retorno:
1 en caso de éxito, de lo contrario, envía un mensaje de advertencia a stderr

GetEntry

Obtener entrada de la base de datos de geolocalización.

my @vals = Image::ExifTool::Geolocation::GetEntry($num,$lang,$sort);
Entradas:
0) Número de entrada en la base de datos, o índice en la base de datos clasificada

1) Código de idioma opcional

2) Indicador opcional para tratar el primer argumento como un índice en la base de datos clasificada

Valores de retorno del elemento:

0) Nombre de la ciudad, o undef si la entrada no existía

1) Nombre de la región, o "" si no hay región

2) Nombre de la subregión, o "" si no hay subregión

3) Código de país

4) Nombre del país

5) Zona horaria

6) Código de característica

7) Población de la ciudad

8) Latitud GPS

9) Longitud GPS

10) Tipo de característica, o undef

GetAltNames

Obtener nombres alternativos para la ciudad especificada.

my $str = Image::ExifTool::Geolocation::GetAltNames($num,$sort);
Entradas:
0) Número de entrada en la base de datos o índice en la base de datos clasificada

1) Indicador opcional para tratar el primer argumento como un índice en la base de datos clasificada

Valor de retorno:
Cadena separada por comas de nombres alternativos para esta ciudad.
Notas:
"ReadAltNames" debe ser llamado antes de llamar a esta rutina.

Geolocate

Devolver información de geolocalización para coordenadas GPS o nombre de ciudad especificados.

my @rtnInfo = Image::ExifTool::Geolocation::Geolocate($arg,$opts);
Entradas:
0) Argumento de entrada ("lat,lon", "ciudad", "ciudad,país", "ciudad,región,país", etc.). Al especificar una ciudad, el nombre de la ciudad debe ir primero, seguido de cero o más de los siguientes en cualquier orden, separados por comas: nombre de la región, nombre de la subregión, código de país y/o nombre del país. También se permiten expresiones regulares en formato "/expr/", opcionalmente prefijadas por "ci", "re", "sr", "cc" o "co" para coincidir específicamente con el nombre de la Ciudad, Región, Subregión, Código de País o País. Se pueden añadir dos controles especiales a la lista de argumentos: 
'both'   - Cuando la entrada de búsqueda incluye tanto el nombre como las coordenadas GPS, úselos
           ambos para determinar la ciudad más cercana que coincida con el(los) nombre(s) especificado(s)
           en lugar de usar solo el GPS.
'num=##' - Cuando la búsqueda incluye coordenadas GPS, o cuando una sola
           ciudad coincide por nombre, devuelve las ## ciudades más cercanas en lugar
           de solo la más cercana o la nombrada. Las ciudades devueltas están en
           orden de la más cercana a la más lejana.

Consulte https://exiftool.org/geolocation.html#Read para más detalles.

1) Referencia opcional a un hash de opciones:

GeolocMinPop   - Población mínima de ciudades a considerar en la búsqueda.
                 Por defecto 0.
GeolocMaxDist  - Distancia máxima (km) para buscar ciudades cuando se
                 utiliza una posición GPS de entrada.  Por defecto infinito.
GeolocMulti    - Indicador para devolver múltiples ciudades si hay más de
                 una coincidencia.  Se utiliza en el caso donde no se
                 proporcionan coordenadas GPS de entrada.  Por defecto 0.
GeolocFeature  - Lista separada por comas de códigos de característica a incluir en
                 la búsqueda, o excluir si la lista comienza con un guion (-).
                 Por defecto undef.
GeolocAltNames - Indicador para buscar en la base de datos de nombres alternativos si está disponible
                 para el nombre de ciudad coincidente (ver BASES DE DATOS ALTERNATIVAS abajo).
                 Por defecto undef.
Valores de retorno:
0) Referencia a una lista de números de entrada de la base de datos para las ciudades coincidentes, o undef si no se encontraron coincidencias.

1) Referencia a una lista de pares distancia/rumbo para cada ciudad coincidente, o undef si la búsqueda no proporcionó coordenadas GPS.

>

BASES DE DATOS

ALTERNATIVAS

Se puede especificar una versión diferente de la base de datos de ciudades estableciendo el paquete $geoDir antes de cargar este módulo. Este directorio debe contener el archivo Geolocation.dat y, opcionalmente, un directorio GeoLang para las traducciones de idioma. La variable $geoDir se puede establecer en una cadena vacía para deshabilitar la carga de una base de

datos.

Al buscar una ciudad por nombre, se comprueba AltNames.dat para proporcionar posibilidades adicionales de coincidencia si la opción GeolocAltNames está activada y existe una base de datos AltNames.dat. El paquete $altDir se puede establecer para especificar un directorio diferente para AltNames.dat; de lo contrario, se asume el directorio d

e Geolocation.dat. Las entradas en AltNames.dat deben coincidir
con las de la versión actualmente cargada de Geolocation.dat.

AÑADIR ENTRADAS DE BASE DE DATOS DEFINIDAS POR EL

USUARIO

Se pueden crear entradas definidas por el usuario definiéndolas mediante la siguiente técnica antes de que se cargue el módulo

Geolocation. 
@Image::ExifTool::UserDefined::Geolocation = (
    # ciudad, región, subregión, código de país, país, zona horaria,
    ['Sinemorets','burgas','Obshtina Tsarevo','BG','','Europe/Sofia',
    # código de característica, población, lat, lon
     'PPL',400,42.06115,27.97833],
)
;

De manera similar, se pueden definir traducciones de idioma definidas por el usuario, y estas anularán cualquier traducción existente. También se pueden especificar traducciones para el idioma predeterminado 'en'. Consulte https://exiftool.org/geolocation.html#

Custom para obtener
más información.

USAR UNA BASE DE DATOS

PERSONALIZADA

Este ejemplo muestra cómo usar una base de datos personalizada. En este ejemplo, el archivo de base de datos de entrada es un archivo de texto separado por comas con columnas correspondientes a los argumentos de entrada del método

AddEntry. 
$Image::ExifTool::Geolocation::geoDir = '';
require Image::Exif
Tool::Geolocation; open DFILE, "< $filename"; Image::ExifTool:
:Geolocation::AddEntry(split /,/) foreach <DFILE>; close DFILE;
