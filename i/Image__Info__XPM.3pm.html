NOMBRE

Image::Info::XPM - Soporte XPM para Image::Info

SINOPSIS

use Image::Info qw(image_info dim);
my $info = image_info("image.xpm");
if (my $error = $info->{error}) {
    die "No se puede analizar la información de la imagen: $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

DESCRIPCIÓN

Este módulo proporciona los nombres de claves estándar excepto Compression, Gamma, Interlace, LastModificationTime, así como:

ColorPalette
Referencia a un array de todos los colores utilizados. Esta clave solo está presente si "image_info" se invoca como "image_info($file, ColorPalette>=1)".
ColorTableSize
El número de colores que utiliza la imagen.
HotSpotX
La coordenada x del punto de acceso de la imagen. Se establece en -1 si no hay punto de acceso.
HotSpotY
La coordenada y del punto de acceso de la imagen. Se establece en -1 si no hay punto de acceso.
L1D_Histogram
Referencia a un array que representa un histograma de luminancia unidimensional. Esta clave solo está presente si "image_info" se invoca como "image_info($file, L1D_Histogram=>1)". El rango es de 0 a 255, sin embargo se utiliza la auto-vivificación, por lo que un campo nulo también es 0, y el array puede no contener realmente 255 campos.
XPM_CharactersPerPixel
Típicamente es 1 o 2. Ver Image::Xpm.
XPM_Extension-.*
Extensiones XPM (la más común es XPMEXT) si están presentes.

MÉTODOS

process_file()

$info->process_file($source, $options);

Procesa un archivo y establece los campos de información encontrados en el objeto $info.

ARCHIVOS

Este módulo requiere Image::Xpm

$Image::Info::XPM::RGBLIB se establece en /usr/X11R6/lib/X11/rgb.txt o una ruta equivalente (ver la función "_get_rgb_txt" para la lista completa) por defecto, esto se utiliza para resolver nombres de color textuales a sus contrapartes RGB.

VER TAMBIÉN

Image::Info, Image::Xpm

NOTAS

Para más información sobre XPM ver <ftp://ftp.x.org/contrib/libraries/xpm-README.html>

ADVERTENCIAS

Aunque el módulo intenta ser lo más robusto posible, puede que no reconozca XPMs más antiguos (Versiones 1-3). Si este es el caso, intente insertar /* XPM */ como la primera línea.
