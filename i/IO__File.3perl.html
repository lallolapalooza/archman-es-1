IO::File(3perl) Guía de Referencia del Programador de Perl IO::File(3perl)

NOMBRE

IO::File - proporcionar métodos de objeto para manejadores de archivo

SINOPSIS

use IO::File;
my $fh = IO::File->new();
if ($fh->open("< file")) {
    print <$fh>;
    $fh->close;
}
my $fh = IO::File->new("> file");
if (defined $fh) {
    print $fh "bar\n";
    $fh->close;
}
my $fh = IO::File->new("file", "r");
if (defined $fh) {
    print <$fh>;
    undef $fh;       # cierra el archivo automáticamente
}
my $fh = IO::File->new("file", O_WRONLY|O_APPEND);
if (defined $fh) {
    print $fh "corge\n";
    my $pos = $fh->getpos;
    $fh->setpos($pos);
    undef $fh;       # cierra el archivo automáticamente
}
autoflush STDOUT 1;

DESCRIPCIÓN

"IO::File" hereda de "IO::Handle" y "IO::Seekable". Extiende estas clases con métodos específicos para manejadores de archivo.

CONSTRUCTOR

new ( NOMBRE_ARCHIVO [, MODO [, PERMISOS ]] )
Crea un "IO::File". Si recibe algún parámetro, estos se pasan al método "open"; si la apertura falla, el objeto se destruye. De lo contrario, se devuelve al llamador.
new_tmpfile
Crea un "IO::File" abierto para lectura/escritura en un archivo temporal recién creado. En sistemas donde esto es posible, el archivo temporal es anónimo (es decir, se elimina después de la creación, pero se mantiene abierto). Si el archivo temporal no se puede crear o abrir, el objeto "IO::File" se destruye. De lo contrario, se devuelve al llamador.

MÉTODOS

open( NOMBRE_ARCHIVO [, MODO [, PERMISOS ]] )
open( NOMBRE_ARCHIVO, CAPAS_IO )
"open" acepta uno, dos o tres parámetros. Con un parámetro, es solo una interfaz para la función integrada "open". Con dos o tres parámetros, el primer parámetro es un nombre de archivo que puede incluir espacios en blanco u otros caracteres especiales, y el segundo parámetro es el modo de apertura, opcionalmente seguido por un valor de permisos de archivo.

Si "IO::File::open" recibe una cadena de modo Perl (">", "+<", etc.) o una cadena de modo fopen() ANSI C ("w", "r+", etc.), utiliza el operador básico de "open" de Perl (pero protege cualquier carácter especial).

Si "IO::File::open" recibe un modo numérico, pasa ese modo y el valor de permisos opcional al operador "sysopen" de Perl. Los permisos tienen un valor predeterminado de 0666.

Si "IO::File::open" recibe un modo que incluye el carácter ":", pasa los tres argumentos al operador "open" de tres argumentos.

Por conveniencia, "IO::File" exporta las constantes O_XXX del módulo Fcntl, si este módulo está disponible.

NOTA

Algunos sistemas operativos pueden realizar IO::File::new() o IO::File::open() en un directorio sin errores. Este comportamiento no es portable y no se sugiere su uso. Se recomiendan en su lugar opendir() y readdir() o "IO::Dir".
