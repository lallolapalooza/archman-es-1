NOMBRE

Image::ExifTool::CaptureOne - Lee archivos Capture One EIP y COS

SINOPSIS

Este módulo es utilizado por Image::ExifTool

DESCRIPCIÓN

Este módulo contiene las definiciones necesarias para que Image::ExifTool extraiga información meta de los archivos Capture One EIP (Enhanced Image Package) y COS (Capture One Settings).

NOTAS

El formato EIP es un archivo ZIP que contiene una imagen (IIQ o TIFF) y algunos archivos de configuración (COS).
