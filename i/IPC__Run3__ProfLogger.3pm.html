IPC::Run3::ProfLogger(3) Documentación de Perl aportada por el usuario IPC::Run3::ProfLogger(3)

NOMBRE

IPC::Run3::ProfLogger - escribe datos de perfilado en un archivo de registro

SINOPSIS

use IPC::Run3::ProfLogger;
my $logger = IPC::Run3::ProfLogger->new;  ## escribe en "run3.out"
my $logger = IPC::Run3::ProfLogger->new( Destination => $fn );
$logger->app_call( \@cmd, $time );
$logger->run_exit( \@cmd1, @times1 );
$logger->run_exit( \@cmd1, @times1 );
$logger->app_exit( $time );

DESCRIPCIÓN

Usado por IPC::Run3 para escribir un archivo de registro de perfilado. No genera informes ni mantiene estadísticas; está destinado a tener una sobrecarga mínima.

Su API es compatible con un pequeño subconjunto de las otras clases de perfilado de IPC::Run.

MÉTODOS

"IPC::Run3::ProfLogger->new( ... )"

"$logger->run_exit( ... )"

"$logger->app_exit( $arg )"

"$logger->app_call( $t, @args)"
