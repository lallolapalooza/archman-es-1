IO::Stringy(3) Documentación de Perl aportada por el usuario IO::Stringy(3)

NOMBRE

IO-stringy - E/S en objetos en memoria como cadenas y arrays

SINOPSIS

use strict;
use warnings;
use IO::AtomicFile; # Escribir un archivo que se actualiza atómicamente
use IO::InnerFile; # definir un archivo dentro de otro archivo
use IO::Lines; # Handle de E/S para leer/escribir a un array de líneas
use IO::Scalar; # Handle de E/S para leer/escribir a una cadena
use IO::ScalarArray; # Handle de E/S para leer/escribir a un array de escalares
use IO::Wrap; # Envolver handles antiguos (estilo C) en una interfaz OO estándar
use IO::WrapTie; # Ligar tus handles y retener la interfaz OO completa
# ...

DESCRIPCIÓN

Este toolkit proporciona principalmente módulos para realizar E/S (Entrada/Salida) tanto tradicional como orientada a objetos en cosas que *no* son filehandles normales; en particular, IO::Scalar, IO::ScalarArray e IO::Lines.

En el frente más tradicional de IO::Handle, tenemos IO::AtomicFile que puede ser utilizado para crear sin problemas archivos que se actualizan atmicamente.

Y en el rincón de "esto podría ser útil", tenemos IO::Wrap, cuya función exportada wraphandle() envolverá cualquier cosa que no sea un objeto referenciado en un envoltorio similar a IO::Handle... para que puedas simplemente usar la sintaxis OO y dejar de preocuparte por si el llamador de tu función te pasó una cadena, un globref o un FileHandle.
