Image::ExifTool::TagInfoXML(3) Documentación de Perl contribuida por el usuario Image::ExifTool::TagInfoXML(3)

NOMBRE

Image::ExifTool::TagInfoXML - Leer/escribir base de datos XML de información de etiquetas

DESCRIPCIÓN

Este módulo se utiliza para generar una base de datos XML a partir de toda la información de etiquetas de ExifTool. La base de datos XML puede ser editada y utilizada para regenerar los módulos de idioma (Image::ExifTool::Lang::*).

MÉTODOS

Escribir

Imprime la base de datos completa de información de etiquetas en formato XML.

# guarda la lista de todas las etiquetas
$exito = Image::ExifTool::TagInfoXML::Write('dst.xml');
# lista todas las etiquetas IPTC en la consola, incluyendo Flags
Image::ExifTool::TagInfoXML::Write(undef, 'IPTC', Flags => 1);
# escribe todas las etiquetas de cámara EXIF en un archivo
Image::ExifTool::TagInfoXML::Write($archivo_salida, 'exif:camera');
Entradas:
0) [opcional] Nombre del archivo de salida, o undef para salida en consola. El archivo de salida se sobrescribirá si ya existe.

1) [opcional] Cadena de nombres de grupo separados por dos puntos para especificar el grupo a imprimir. Un IFD específico no puede ser dado como grupo, ya que las etiquetas EXIF pueden ser escritas en cualquier IFD. Guarda todos los grupos si no se especifica.

2) [opcional] Hash de valores de opciones:

Flags   - Establecer para generar el atributo 'flags'
NoDesc  - Establecer para suprimir la salida de descripciones
Lang    - Seleccionar un solo idioma para la salida
Valor de retorno:
Verdadero en caso de éxito.
Ejemplo de salida XML:
<?xml version='1.0' encoding='UTF-8'?>
<taginfo>
<table name='XMP::dc' g0='XMP' g1='XMP-dc' g2='Other'>
 <desc lang='en'>XMP Dublin Core</desc>
 <tag id='title' name='Title' type='lang-alt' writable='true' g2='Image'>
  <desc lang='en'>Title</desc>
  <desc lang='de'>Titel</desc>
  <desc lang='fr'>Titre</desc>
 </tag>
 ...
</table>
</taginfo>

Los Flags (si se seleccionan y están disponibles) se formatean como una lista separada por comas de los siguientes valores posibles: Avoid, Binary, List, Mandatory, Permanent, Protected, Unknown y Unsafe. Consulte la documentación de los nombres de etiquetas y lib/Image::ExifTool/README para obtener una descripción de estos flags. Para las etiquetas XMP List, el tipo de lista (Alt, Bag o Seq) también se genera como un flag si es aplicable.

BuildLangModules

Construye todos los módulos Lang de Image::ExifTool desde un archivo de base de datos XML.

Image::ExifTool::TagInfoXML::BuildLangModules('src.xml');
Entradas:
0) Nombre del archivo XML

1) Flags de actualización:

0x01 = preservar los números de versión
0x02 = actualizar todos los módulos, incluso si no cambiaron
0x04 = actualizar desde cero, ignorando las definiciones existentes
0x08 = anular descripciones y valores existentes diferentes
Valor de retorno:
Número de módulos actualizados, o negativo en caso de error.
