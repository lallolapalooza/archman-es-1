ImageMagick(1) Manual de Comandos Generales ImageMagick(1)

NOMBRE

ImageMagick - un conjunto de software libre para la creación, modificación y visualización de imágenes de mapa de bits.

SINOPSIS

magick [opciones|archivo-de-entrada]... archivo-de-salida magick-script archivo-script [argumentos-script]...

DESCRIPCIÓN

Utilice ImageMagick® para crear, editar, componer o convertir imágenes de mapa de bits. Puede leer y escribir imágenes en una variedad de formatos (más de 200) incluyendo PNG, JPEG, GIF, HEIC, TIFF, DPX, EXR, WebP, Postscript, PDF y SVG. Utilice ImageMagick para redimensionar, voltear, reflejar, rotar, distorsionar, inclinar y transformar imágenes, ajustar los colores de la imagen, aplicar varios efectos especiales o dibujar texto, líneas, polígonos, elipses y curvas de Bézier.

La funcionalidad de ImageMagick se utiliza normalmente desde la línea de comandos. También se puede acceder desde programas escritos en su lenguaje favorito utilizando la interfaz correspondiente: G2F (Ada), MagickCore (C), MagickWand (C), ChMagick (Ch), ImageMagickObject (COM+), Magick++ (C++), JMagick (Java), JuliaIO (Julia), L-Magick (Lisp), Lua (LuaJIT), NMagick (Neko/haXe), Magick.NET (.NET), PascalMagick (Pascal), ALImageMagick (Delphi), PerlMagick (Perl), MagickWand para PHP (PHP), IMagick (PHP), PythonMagick (Python), magick (R), RMagick (Ruby) o TclMagick (Tcl/TK). Con una interfaz de lenguaje, utilice ImageMagick para modificar o crear imágenes dinámicamente y de forma automática.

ImageMagick utiliza múltiples hilos de cálculo para aumentar el rendimiento. Puede leer, procesar o escribir imágenes de mega-, giga- o tera-píxeles.

ImageMagick es software libre distribuido como una distribución binaria lista para usar, o como código fuente que puede usar, copiar, modificar y distribuir tanto en aplicaciones abiertas como propietarias. Se distribuye bajo una licencia Apache 2.0 derivada.

El proceso de desarrollo de ImageMagick garantiza una API y ABI estables. Antes de cada versión de ImageMagick, realizamos una evaluación de seguridad exhaustiva que incluye detección de errores de memoria, carreras de datos en hilos y fuzzing continuo para ayudar a prevenir vulnerabilidades de seguridad.

La versión actual es ImageMagick 7.0.8-11. Funciona en Linux, Windows, macOS, iOS, Android OS y otros. Continuamos manteniendo la versión heredada de ImageMagick, la versión 6, en https://legacy.imagemagick.org.

El sitio web oficial de ImageMagick es https://imagemagick.org. El repositorio de código fuente oficial es https://github.com/ImageMagick. Mantenemos un espejo del código fuente en https://gitlab.com/ImageMagick.

ImageMagick es un conjunto de utilidades de línea de comandos para manipular imágenes. Puede que haya editado imágenes en algún momento utilizando programas como GIMP o Photoshop, que exponen su funcionalidad principalmente a través de una interfaz gráfica de usuario. Sin embargo, un programa GUI no es siempre la herramienta adecuada. Suponga que desea procesar una imagen dinámicamente desde un script web, o que desea aplicar las mismas operaciones a muchas imágenes, o repetir una operación específica en diferentes momentos a la misma o diferente imagen. Para estos tipos de operaciones, una utilidad de línea de comandos es más adecuada.

El resto de esta página del manual es una lista de las utilidades de línea de comandos disponibles y sus descripciones breves. Para obtener más documentación sobre un comando en particular y sus opciones, consulte la página del manual correspondiente. Si solo está familiarizándose con ImageMagick, comience por la parte superior de esa lista, el programa magick(1), y continúe hacia abajo. Además, asegúrese de consultar el tutorial de Anthony Thyssen sobre cómo usar las utilidades de ImageMagick para convertir, componer o editar imágenes desde la línea de comandos.

magick
Lee imágenes en memoria, realiza operaciones sobre esas imágenes y las escribe en el mismo u otro formato de archivo de imagen. La opción "-script" se puede utilizar para cambiar del procesamiento de opciones de línea de comandos a la lectura de opciones desde un archivo o tubería.
magick-script
Este comando es similar a magick(1) pero con una opción "-script" implícita. Es útil en scripts especiales "#!/usr/bin/env magick-script" que buscan el comando magick-script(1) en cualquier lugar de la PATH del usuario, en lugar de en una ubicación de comando codificada.
convert
Disponible para compatibilidad retroactiva con la versión 6 de ImageMagick, convert(1). Esencialmente, es solo un alias para una forma restrictiva del comando magick(1), que debería usarse en su lugar.
mogrify
Redimensiona una imagen, la difumina, la recorta, la limpia de puntos, la convierte en mapa de bits, dibuja sobre ella, la voltea, la une, la re-muestrea y mucho más. Este comando sobrescribe el archivo de imagen original, mientras que convert(1) escribe en un archivo de imagen diferente.
identify
Describe el formato y las características de uno o más archivos de imagen.
composite
Superpone una imagen sobre otra.
montage
Crea una imagen compuesta combinando varias imágenes separadas. Las imágenes se colocan en mosaico en la imagen compuesta, opcionalmente adornadas con un borde, marco, nombre de imagen y más.
compare
Anota matemática y visualmente la diferencia entre una imagen y su reconstrucción.
stream
Transmite uno o más componentes de píxeles de la imagen o una porción de la imagen a su elección de formatos de almacenamiento. Escribe los componentes de píxeles a medida que se leen de la imagen de entrada, fila por fila, lo que hace que stream(1) sea deseable al trabajar con imágenes grandes, o cuando se requieren componentes de píxeles sin procesar.
display
Muestra una imagen o secuencia de imágenes en cualquier servidor X.
animate
Anima una secuencia de imágenes en cualquier servidor X.
import
Guarda cualquier ventana visible en cualquier servidor X y la exporta como un archivo de imagen. Puede capturar una sola ventana, toda la pantalla o cualquier porción rectangular de la misma.
conjure
Interpreta y ejecuta scripts escritos en el Lenguaje de Scripting de Magick (MSL).

Para más información sobre ImageMagick, apunte su navegador a file:///usr/share/doc/ImageMagick-7/index.html o https://imagemagick.org/.
