DESCRIPCIÓ

N

Este módulo proporciona una interfaz Perl que permite escribir datos comprimidos en archivos o búferes como se define en RFC

1951.

Tenga en cuenta que los datos RFC 1951 no son una buena opción de formato de compresión para usar de forma aislada, especialmente si desea la detección

automática.

Para leer archivos/búferes RFC 195

1, consulte el módulo complementar
io IO::Uncompress::RawInflate.

Interfaz

Funcional

Se proporciona una función de nivel superior, "rawdeflate", para realizar una compresión "de un solo disparo" entre búferes y/o archivos. Para un control más fino sobre el proceso de compresión, consulte la sección "Interfaz

OO". 
use IO::Compress::RawDeflate qw(rawdeflate $RawDeflateError) ;

    or die "rawdeflate failed: $RawDeflateError\n"
;
