IPC::Run::Win32Process(3) Documentación Perl contribuida por el usuario IPC::Run::Win32Process(3)

NOMBRE

IPC::Run::Win32Process -- entrega líneas de comandos no estándar a través de IPC::Run.

SINOPSIS

use File::Spec ();
use IPC::Run qw(run);
use IPC::Run::Win32Process ();
use Win32 ();
$find_exe = File::Spec->catfile(Win32::GetFolderPath(Win32::CSIDL_SYSTEM),
                                'find.exe');
run(IPC::Run::Win32Process->new($ENV{COMSPEC}, q{cmd.exe /c echo ""}),
    '|', IPC::Run::Win32Process->new($find_exe, q{find_exe """"""}),
    '>', \$out);

DESCRIPCIÓN

Esta clase facilita la ejecución de programas de Windows que no utilizan las reglas estándar de análisis de línea de comandos https://docs.microsoft.com/en-us/cpp/cpp/main-function-command-line-args#parsing-c-command-line-arguments. Los programas notables que tienen reglas no estándar incluyen cmd.exe, cscript.exe y programas Cygwin llamados desde programas que no son Cygwin. IPC::Run utilizará las dos cadenas, textualmente, como los argumentos lpApplicationName y lpCommandLine de CreateProcessA(). Esto proporciona un control sin filtrar sobre la línea de comandos del proceso hijo.
