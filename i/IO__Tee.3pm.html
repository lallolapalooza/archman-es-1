IO::Tee(3) Documentación de Perl aportada por el usuario IO::Tee(3)

NOMBRE

IO::Tee - Multiplexa la salida a múltiples manejadores de salida

SINOPSIS

use IO::Tee;
$tee = IO::Tee->new($handle1, $handle2);
print $tee "foo", "bar";
my $input = <$tee>;

DESCRIPCIÓN

Los objetos "IO::Tee" se pueden utilizar para multiplexar la entrada y la salida de dos maneras diferentes. La primera manera es multiplexar la salida a cero o más manejadores de salida. El "IO::Tee" constructor, dado una lista de manejadores de salida, devuelve un manejador vinculado al que se puede escribir. Cuando se escribe en él (usando print o printf), el "IO::Tee" objeto multiplexa la salida a la lista de manejadores pasados originalmente al constructor. Como atajo, también puedes pasar directamente una cadena o una referencia de array al constructor, en cuyo caso "IO::File::new" se llama por ti con el argumento o argumentos especificados.

La segunda manera es multiplexar la entrada de un manejador de entrada a cero o más manejadores de salida a medida que se lee. El "IO::Tee" constructor, dado un manejador de entrada seguido de una lista de manejadores de salida, devuelve un manejador vinculado del que se puede leer y también escribir. Cuando se escribe en él, el "IO::Tee" objeto multiplexa la salida a todos los manejadores pasados al constructor, como se describe en el párrafo anterior. Cuando se lee de él, el "IO::Tee" objeto lee del manejador de entrada dado como el primer argumento al "IO::Tee" constructor, luego escribe cualquier dato leído en los manejadores de salida dados como los argumentos restantes al constructor.

La "IO::Tee" clase soporta ciertos "IO::Handle" y "IO::File" métodos relacionados con la entrada y la salida. En particular, los siguientes métodos se iterarán a sí mismos sobre todos los manejadores asociados con el "IO::Tee" objeto, y devuelven TRUE indicando éxito si y solo si todos los manejadores asociados devolvieron TRUE indicando éxito:

close
truncate
write
syswrite
format_write
formline
fcntl
ioctl
flush
clearerr
seek

Los siguientes métodos realizan multiplexación de entrada como se describe arriba:

read
sysread
readline
getc
gets
eof
getline
getlines

Los siguientes métodos se pueden usar para establecer (pero no recuperar) los valores actuales de las variables de estado relacionadas con la salida en todos los manejadores asociados:

autoflush
output_field_separator
output_record_separator
format_page_number
format_lines_per_page
format_lines_left
format_name
format_top_name
format_line_break_characters
format_formfeed

Los siguientes métodos se pasan directamente al manejador de entrada dado como el primer argumento al "IO::Tee" constructor:

input_record_separator
input_line_number

Ten en cuenta que el valor de retorno de los métodos de multiplexación de entrada (como "print") es siempre el valor de retorno de la acción de entrada, no el valor de retorno de las acciones de salida posteriores. En particular, no se indica ningún error por el valor de retorno si la acción de entrada en sí tiene éxito pero la multiplexación de salida posterior falla.

EJEMPLO

use IO::Tee;
use IO::File;
my $tee = new IO::Tee(\*STDOUT,
    new IO::File(">tt1.out"), ">tt2.out");
print join(' ', $tee->handles), "\n";
for (1..10) { print $tee $_, "\n" }
for (1..10) { $tee->print($_, "\n") }
$tee->flush;
$tee = new IO::Tee('</etc/passwd', \*STDOUT);
my @lines = <$tee>;
print scalar(@lines);
