N

Este módulo proporciona una interfaz de Perl que permite la lectura de archivos/búferes que se ajustan a la RFC

1951.

Para escribir archivos/búferes RF

C 1951, consulte el módulo compañ

Se proporciona una función de nivel superior, "rawinflate", para realizar una descompresión "de una sola vez" entre búferes y/o archivos. Para un control más fino sobre el proceso de descompresión, consulte la sección "Interfaz

OO".
