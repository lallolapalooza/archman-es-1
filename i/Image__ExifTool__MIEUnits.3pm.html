NOMBRE

Image::ExifTool::MIEUnits - Documentación de las unidades MIE

DESCRIPCIÓN

El formato MIE permite especificar unidades de medida entre corchetes al final del nombre de una etiqueta MIE (por ejemplo, "Volume(m3)"). Este documento describe las abreviaturas estándar de las unidades MIE.

SINTAXIS

La cadena de unidades puede contener cualquier carácter ASCII en el rango 0x21 ('!') a 0x7d ('}'), excepto los caracteres de corchete (0x28 y 0x29). Se permite una cadena vacía, que indica un valor adimensional. Deben usarse las unidades estándar siempre que sea posible. En las unidades estándar, un subrayado ('_') se usa para indicar un subíndice, y múltiples palabras pueden separarse con un guion ('-').

Los exponentes deben ser positivos y no requieren separador (por ejemplo, "m2" para metros cuadrados). Se pueden añadir prefijos a las unidades estándar (por ejemplo, "cm") excepto cuando el nombre resultante entre en conflicto con otra unidad estándar.

La multiplicación se indica con '.', y la división con '/'. Las unidades recíprocas (es decir, el inverso multiplicativo) se obtienen mediante división en lugar del uso de exponentes negativos (por ejemplo, "/in", no "in-1"). En las unidades MIE, la multiplicación tiene precedencia sobre la división, por lo que todo lo que esté a la derecha de un '/' está en el denominador. (Véase "EJEMPLOS" para algunos ejemplos.)

A continuación se muestra una tabla que resume los caracteres especiales utilizados en las cadenas de unidades MIE.

.           multiplicación
/           división (usada para exponentes negativos)
-           separador de palabras
_           subíndice
{}          anotación
[]          usado para evitar conflictos de nombres si es necesario
0-9         potenciación
