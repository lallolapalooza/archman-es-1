IPC::Run3::ProfReporter(3) Documentación de Perl contribuida por el usuario IPC::Run3::ProfReporter(3)

NOMBRE

IPC::Run3::ProfReporter - clase base para el manejo de datos de perfilado

SINOPSIS

DESCRIPCIÓN

Ver IPC::Run3::ProfPP y para una subclase de ejemplo.

Esta clase solo registra y acumula tiempos; las subclases utilizan métodos como "handle_app_call", "handle_run_exit" y "handle_app_exit" para emitir informes sobre ello. Los métodos por defecto para estos manejadores son no-ops (no hacen nada).

Si se ejecuta desde la línea de comandos, se creará un reporter y se ejecutará en cada archivo de registro dado como parámetro de línea de comandos o en run3.out si no se proporciona ninguno.

Esto permite ejecutar informes como:

perl -MIPC::Run3::ProfPP -e1
perl -MIPC::Run3::ProfPP -e1 foo.out bar.out

Use "-" para leer desde STDIN (el formato del archivo de registro está pensado para ser moderadamente legible con `grep`):

grep "^cvs " run3.out perl -MIPC::Run3::ProfPP -e1 -

Use --app para mostrar solo estadísticas a nivel de aplicación (es decir, no emitir una sección de informe para cada comando ejecutado).

MÉTODOS

"IPC::Run3::ProfReporter->new"
Devuelve un nuevo objeto de informe de perfil.
"$reporter->handle_app_call( ... )"
"$reporter->handle_app_exit( ... )"
"$reporter->handle_run_exit( ... )"
Estos métodos son llamados por los eventos manejados (ver abajo).
"$reporter->app_call(\@cmd, $time)"
"$reporter->app_exit($time)"
"$reporter->run_exit(@times)"
$self->app_call( $time );
my $time = $self->get_app_call_time;

Establece el tiempo (en segundos de punto flotante) en el que la aplicación, run3(), o system() fue llamada o finalizó. Si no se pasa ningún parámetro de tiempo, utiliza la rutina de tiempo de IPC::Run3.

Use get_...() para recuperar estos valores (y también los valores _accum. Este es un método separado para acelerar un poco el tiempo de ejecución de los setters.

"$reporter->get_run_count()"
"$reporter->get_app_call_time()"
"$reporter->get_app_exit_time()"
"$reporter->get_app_cmd()"
"$reporter->get_app_time()"
"$reporter->get_app_cumulative_time()"
"$reporter->get_run_call_time()"
"$reporter->get_run_exit_time()"
"$reporter->get_run_time()"
"$reporter->get_run_cumulative_time()"
"$reporter->get_sys_call_time()"
"$reporter->get_sys_exit_time()"
"$reporter->get_sys_time()"
"$reporter->get_sys_cumulative_time()"
"$reporter->get_run_cmd()"
