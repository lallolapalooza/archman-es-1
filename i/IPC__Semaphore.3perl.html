NOMBRE

IPC::Semaphore - Clase de objeto IPC de semáforos SysV

SINOPSIS

use IPC::SysV qw(IPC_PRIVATE S_IRUSR S_IWUSR IPC_CREAT);
use IPC::Semaphore;
$sem = IPC::Semaphore->new(IPC_PRIVATE, 10, S_IRUSR | S_IWUSR | IPC_CREAT);
$sem->setall( (0) x 10);
@sem = $sem->getall;
$ncnt = $sem->getncnt;
$zcnt = $sem->getzcnt;
$ds = $sem->stat;
$sem->remove;

DESCRIPCIÓN

Una clase que proporciona una interfaz orientada a objetos para los semáforos IPC de SysV.

MÉTODOS

new ( KEY , NSEMS , FLAGS )
Crea un nuevo conjunto de semáforos asociado a "KEY". "NSEMS" es el número de semáforos en el conjunto. Se crea un nuevo conjunto si
  • "KEY" es igual a "IPC_PRIVATE"
  • "KEY" no tiene ya asociado un identificador de semáforo, y "FLAGS & IPC_CREAT" es verdadero.

Al crear un nuevo conjunto de semáforos, "FLAGS" se utiliza para establecer los permisos. Tenga cuidado de no establecer ninguna bandera que la implementación IPC de Sys V no permita: en algunos sistemas, establecer bits de ejecución hace que las operaciones fallen.

getall
Devuelve los valores del conjunto de semáforos como una matriz.
getncnt ( SEM )
Devuelve el número de procesos que esperan a que el semáforo "SEM" sea mayor que su valor actual.
getpid ( SEM )
Devuelve el ID del proceso del último proceso que realizó una operación en el semáforo "SEM".
getval ( SEM )
Devuelve el valor actual del semáforo "SEM".
getzcnt ( SEM )
Devuelve el número de procesos que esperan a que el semáforo "SEM" sea cero.
id
Devuelve el identificador del sistema para el conjunto de semáforos.
op ( OPLIST )
"OPLIST" es una lista de operaciones para pasar a "semop". "OPLIST" es una concatenación de listas más pequeñas, cada una de las cuales tiene tres valores. El primero es el número de semáforo, el segundo es la operación y el último es un valor de bandera. Consulte semop(2) para obtener más detalles. Por ejemplo: 
$sem->op(
    0, -1, IPC_NOWAIT,
    1,  1, IPC_NOWAIT
);
remove
Elimina y destruye el conjunto de semáforos del sistema.
set ( STAT )
set ( NAME => VALUE [, NAME => VALUE ...] )
"set" establecerá los siguientes valores de la estructura "stat" asociada al conjunto de semáforos. 
uid
gid
mode (solo los bits de permiso)

"set" acepta ya sea un objeto de estadísticas, como el devuelto por el método "stat", o una lista de pares nombre-valor.

setall ( VALUES )
Establece todos los valores del conjunto de semáforos a los proporcionados en la lista "VALUES". "VALUES" debe contener el número correcto de valores.
setval ( N , VALUE )
Establece el valor "N" del conjunto de semáforos a "VALUE".
stat
Devuelve un objeto de tipo "IPC::Semaphore::stat", que es una sub-clase de "Class::Struct". Proporciona los siguientes campos. Para una descripción de estos campos, consulte la documentación de su sistema. 
uid
gid
cuid
cgid
mode
ctime
otime
nsems

VER TAMBIÉN

IPC::SysV, Class::Struct, semget(2), semctl(2), semop(2)
