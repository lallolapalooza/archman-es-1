NOMBRE

Image::ExifTool::Photoshop - Lee/escribe información meta de Photoshop IRB

SINOPSIS

Este módulo es cargado automáticamente por Image::ExifTool cuando se requiere.

DESCRIPCIÓN

Photoshop escribe su propio formato de información meta llamado recurso de Photoshop IRB, que se encuentra en el registro APP13 de los archivos JPEG. Este módulo contiene las definiciones para leer esta información.

NOTAS

Los bloques de Photoshop IRB pueden tener un nombre de recurso asociado. Estos nombres suelen ser solo una cadena vacía, pero si no están vacíos, se muestran en la salida de nivel de detalle 2 (o superior). Se puede establecer una bandera especial "SetResourceName" a '1' en el hash de información de etiquetas para hacer que el nombre del recurso se añada al valor cuando se extraiga. Si se hace esto, el valor devuelto tiene el formato "VALOR/#NOMBRE# /". Al escribir, la rutina de escritura busca esta sintaxis (si "SetResourceName" está definido) y utiliza el nombre incrustado para establecer el nombre del nuevo recurso. Esto permite que los nombres de los recursos se conserven al copiar información de Photoshop a través de etiquetas definidas por el usuario.
