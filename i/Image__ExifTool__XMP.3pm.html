NOMBRE

Image::ExifTool::XMP - Leer información de metadatos XMP

SINOPSIS

Este módulo es cargado automáticamente por Image::ExifTool cuando se requiere.

DESCRIPCIÓN

XMP son las siglas de Extensible Metadata Platform. Es un formato basado en XML que Adobe desarrolló para incrustar información de metadatos en archivos de imagen. Este módulo contiene las definiciones necesarias para que Image::ExifTool lea información XMP.
