IO::Zlib(3perl) Guía de referencia para programadores de Perl IO::Zlib(3perl)

NOMBRE

IO::Zlib - Interfaz de estilo IO:: para Compress::Zlib

SINOPSIS

Con cualquier versión de Perl 5 puedes usar la interfaz OO básica:

use IO::Zlib;
$fh = new IO::Zlib;
if ($fh->open("file.gz", "rb")) {
    print <$fh>;
    $fh->close;
}
$fh = IO::Zlib->new("file.gz", "wb9");
if (defined $fh) {
    print $fh "bar\n";
    $fh->close;
}
$fh = IO::Zlib->new("file.gz", "rb");
if (defined $fh) {
    print <$fh>;
    undef $fh;       # cierra automáticamente el archivo
}

Con Perl 5.004 también puedes usar la interfaz TIEHANDLE para acceder a archivos comprimidos igual que archivos ordinarios:

use IO::Zlib;
tie *FILE, 'IO::Zlib', "file.gz", "wb";
print FILE "line 1\nline2\n";
tie *FILE, 'IO::Zlib', "file.gz", "rb";
while (<FILE>) { print "LINE: ", $_ };

DESCRIPCIÓN

"IO::Zlib" proporciona una interfaz de estilo IO:: a Compress::Zlib y por lo tanto a archivos comprimidos con gzip/zlib. Proporciona muchos de los mismos métodos que la interfaz IO::Handle.

A partir de la versión 1.02 de IO::Zlib, IO::Zlib también puede usar un comando gzip externo. El comportamiento por defecto es intentar usar un externo gzip si no se puede cargar ningún "Compress::Zlib" , a menos que se deshabilite explícitamente mediante

use IO::Zlib qw(:gzip_external 0);

Si se habilita explícitamente mediante

use IO::Zlib qw(:gzip_external 1);

entonces el gzip externo se usa en lugar de "Compress::Zlib".

CONSTRUCTOR

new ( [ARGS] )
Crea un objeto "IO::Zlib" . Si recibe algún parámetro, este se pasa al método "open"; si la apertura falla, el objeto se destruye. De lo contrario, se devuelve al llamador.

MÉTODOS DEL OBJETO

open ( FILENAME, MODE )
"open" toma dos argumentos. El primero es el nombre del archivo a abrir y el segundo es el modo de apertura. El modo puede ser cualquier cosa aceptable para Compress::Zlib y por extensión cualquier cosa aceptable para zlib (eso básicamente significa cadenas de modo al estilo POSIX fopen() más un número opcional para indicar el nivel de compresión).
opened
Devuelve true si el objeto actualmente se refiere a un archivo abierto.
close
Cierra el archivo asociado con el objeto y desasocia el archivo del manejador. Se hace automáticamente al destruir.
getc
Devuelve el siguiente carácter del archivo, o undef si no quedan más.
getline
Devuelve la siguiente línea del archivo, o undef al final de la cadena. Se puede llamar con seguridad en un contexto de arreglo. Actualmente ignora $/ ($INPUT_RECORD_SEPARATOR o $RS cuando se usa English) y trata las líneas como delimitadas por "\n".
getlines
Obtiene todas las líneas restantes del archivo. Hará croak() si se llama accidentalmente en un contexto escalar.
print ( ARGS... )
Imprime ARGS en el archivo.
read ( BUF, NBYTES, [OFFSET] )
Lee algunos bytes del archivo. Devuelve el número de bytes realmente leídos, 0 al final del archivo, undef en caso de error.
eof
Devuelve true si el manejador está actualmente posicionado al final del archivo.
seek ( OFFSET, WHENCE )
Busca una posición dada en el flujo. Aún no soportado.
tell
Devuelve la posición actual en el flujo, como un desplazamiento numérico. Aún no soportado.
setpos ( POS )
Establece la posición actual, usando el valor opaco devuelto por getpos(). Aún no soportado.
getpos ( POS )
Devuelve la posición actual en la cadena, como un objeto opaco. Aún no soportado.

USAR EL GZIP EXTERNO

Si se usa el gzip externo, se usan los siguientes "open":

open(FH, "gzip -dc $filename |")  # para aperturas de lectura
open(FH, " | gzip > $filename")   # para aperturas de escritura

Puedes modificar los 'comandos' por ejemplo para fijar una ruta absoluta mediante

use IO::Zlib ':gzip_read_open'  => '/some/where/gunzip -c %s |';
use IO::Zlib ':gzip_write_open' => '| /some/where/gzip.exe > %s';

El %s se expande para ser el nombre del archivo (se usa"sprintf" , así que ten cuidado de escapar cualquier otro signo "%" ). Los 'comandos' se verifican por coherencia: deben contener el %s, y la apertura de lectura debe terminar con el signo de tubería, y la apertura de escritura debe comenzar con el signo de tubería.

MÉTODOS DE CLASE

has_Compress_Zlib
Devuelve true si "Compress::Zlib" está disponible. Ten en cuenta que esto no significa que "Compress::Zlib" se esté usando: ver "gzip_external" y gzip_used.
gzip_external
Indefinido si un gzip externo puede usarse si "Compress::Zlib" no está disponible (ver "has_Compress_Zlib"), true si un gzip externo se usa explícitamente, false si un gzip externo no debe usarse. Ver "gzip_used".
gzip_used
True si se está usando un gzip externo, false si no.
gzip_read_open
Devuelve el 'comando' que se está usando para abrir un archivo para lectura usando un externo gzip.
gzip_write_open
Devuelve el 'comando' que se está usando para abrir un archivo para escritura usando un externo gzip.

DIAGNÓSTICOS

IO::Zlib::getlines: must be called in list context
Si quieres leer líneas, debes leer en contexto de lista.
IO::Zlib::gzopen_external: mode '...' is illegal
Usa solo los modos 'rb' o 'wb' o /wb[1-9]/.
IO::Zlib::import: '...' is illegal
Los símbolos de importación conocidos son ":gzip_external", ":gzip_read_open", y ":gzip_write_open". Cualquier otra cosa no se reconoce.
IO::Zlib::import: ':gzip_external' requires an argument
El ":gzip_external" requiere un argumento booleano.
IO::Zlib::import: 'gzip_read_open' requires an argument
El ":gzip_external" requiere un argumento de cadena.
IO::Zlib::import: 'gzip_read' '...' is illegal
El ":gzip_read_open" el argumento debe terminar con el signo de tubería (|) y tener el %s para el nombre del archivo. Ver "USAR EL GZIP EXTERNO"t;.
IO::Zlib::import: 'gzip_write_open' requiere un argumento
El ":gzip_external" requiere un argumento de cadena de texto.
IO::Zlib::import: 'gzip_write_open' '...' es ilegal
El argumento ":gzip_write_open" debe comenzar con el signo de barra vertical (|) y tener el %s para el nombre de archivo. Una redirección de salida (>) también suele ser una buena idea, dependiendo de la sintaxis del shell de su sistema operativo. Vea "USING THE EXTERNAL GZIP".
IO::Zlib::import: no hay Compress::Zlib ni gzip externo
Dado que no pudimos cargar "Compress::Zlib" y que el uso de
un gzip externo estaba deshabilitado, IO::Zlib no tiene muchas posibilidades de funcionar.
IO::Zlib::open: necesita un nombre de archivo
Sin nombre de archivo, no hay apertura.
IO::Zlib::READ: se debe especificar NBYTES
Debemos saber cuánto leer.
IO::Zlib::WRITE: LENGTH demasiado largo
El LENGTH debe ser menor o igual que el tamaño del búfer.
