Canales de entrada.

Este módulo proporciona funciones para trabajar con canales de entrada.

Ver In_channel.examples abajo.

Modos de apertura para In_channel.open_gen .

val stdin : t

La entrada estándar para el proceso.

val open_bin : string -> t

Abrir el archivo con nombre para lectura y devolver un nuevo canal de entrada en ese archivo, posicionado al principio del archivo.

val open_text : string -> t

Igual que In_channel.open_bin , pero el archivo se abre en modo texto, de modo que la traducción de saltos de línea ocurre durante las lecturas. En sistemas operativos que no distinguen entre modo texto y modo binario, esta función se comporta como In_channel.open_bin .

val open_gen : open_flag list -> int -> string -> t

open_gen mode perm filename abre el archivo con nombre para lectura, como se describe arriba. Los argumentos adicionales mode y perm especifican el modo de apertura y los permisos del archivo. In_channel.open_text e In_channel.open_bin son casos especiales de esta función.

val with_open_bin : string -> (t -> 'a) -> 'a

with_open_bin fn f abre un canal ic en el archivo fn y devuelve f
ic . Después de que f retorna, ya sea con un valor o lanzando una excepción, se garantiza que ic se cerrará.

val with_open_text : string -> (t -> 'a) -> 'a

Similar a In_channel.with_open_bin , pero el canal se abre en modo texto (ver In_channel.open_text ).

val with_open_gen : open_flag list -> int -> string -> (t -> 'a) -> 'a

Similar a In_channel.with_open_bin , pero puede especificar el modo de apertura y el permiso del archivo, en caso de que el archivo deba ser creado (ver In_channel.open_gen ).

val close : t -> unit

Cierra el canal dado. Las funciones de entrada lanzan una excepción Sys_error cuando se aplican a un canal de entrada cerrado, excepto In_channel.close , que no hace nada cuando se aplica a un canal ya cerrado.

val close_noerr : t -> unit

Igual que In_channel.close , pero ignora todos los errores.

Entrada

val input_char : t -> char option

Lee un carácter del canal de entrada dado. Devuelve None si no hay más caracteres para leer.

val input_byte : t -> int option

Igual que In_channel.input_char , pero devuelve el entero de 8 bits que representa el carácter. Devuelve None si se alcanzó el final del archivo.

val input_line : t -> string option

input_line ic lee caracteres de ic hasta que se alcanza un salto de línea o el final del archivo. Devuelve la cadena de todos los caracteres leídos, sin el salto de línea (si lo hubiera). Devuelve None si se alcanzó el final del archivo. En particular, este será el caso si la última línea de entrada está vacía.

Un salto de línea es el carácter \n a menos que el archivo esté abierto en modo texto y Sys.win32 sea true en cuyo caso es la secuencia de caracteres \r\n .

val really_input_string : t -> int -> string option

really_input_string ic len lee len caracteres del canal ic y los devuelve en una nueva cadena. Devuelve None si se alcanzó el final del archivo antes de que se leyeran len caracteres.

Si el mismo canal es leído concurrentemente por múltiples hilos, la cadena devuelta no garantiza contener caracteres contiguos de la entrada.

val input_all : t -> string

input_all ic lee todos los datos restantes de ic .

Si el mismo canal es leído concurrentemente por múltiples hilos, la cadena devuelta no garantiza contener caracteres contiguos de la entrada.

val input_lines : t -> string list

input_lines ic lee líneas usando In_channel.input_line hasta que se alcanza el final del archivo. Devuelve la lista de todas las líneas leídas, en el orden en que fueron leídas. Los caracteres de salto de línea que terminan las líneas no se incluyen en las cadenas devueltas. Las líneas vacías producen cadenas vacías.

Desde 5.1

Entrada avanzada

val input : t -> bytes -> int -> int -> int

input ic buf pos len lee hasta len caracteres del canal ic , almacenándolos en la secuencia de bytes buf , comenzando en el número de carácter pos . Devuelve el número real de caracteres leídos, entre 0 y len (inclusive). Un valor de retorno de 0 significa que se alcanzó el final del archivo.

Use In_channel.really_input para leer exactamente len caracteres.

Lanza Invalid_argument si pos y len no designan un rango válido de buf .

val input_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> int

Igual que In_channel.input , pero lee los datos en un bigarray.

Desde 5.2

val really_input : t -> bytes -> int -> int -> unit option

really_input ic buf pos len lee len caracteres del canal ic , almacenándolos en la secuencia de bytes buf , comenzando en el número de carácter pos .

Devuelve None si se alcanzó el final del archivo antes de que se leyeran len caracteres.

Lanza Invalid_argument si pos y len no designan un rango válido de buf .

val really_input_bigarray : t -> ('a, Bigarray.int8_unsigned_elt, Bigarray.c_layout) Bigarray.Array1.t -> int -> int -> unit option

Igual que In_channel.really_input , pero lee los datos en un bigarray.

Desde 5.2

val fold_lines : ('acc -> string -> 'acc) -> 'acc -> t -> 'acc

fold_lines f init ic lee líneas de ic usando In_channel.input_line hasta que se alcanza el final del archivo, y pasa sucesivamente cada línea a la función f en el estilo de un fold. Más precisamente, si se leen las líneas l1, ..., lN , fold_lines f init ic calcula f (... (f (f init l1) l2) ...) lN . Si f no tiene efectos secundarios, esto es equivalente a List.fold_left f init (In_channel.input_lines ic) , pero es más eficiente ya que no construye la lista de todas las líneas leídas.

Búsqueda

val seek : t -> int64 -> unit

seek chan pos establece la posición de lectura actual a pos para el canal chan . Esto solo funciona para archivos regulares. En archivos de otros tipos, el comportamiento no está especificado.

val pos : t -> int64

Devuelve la posición de lectura actual para el canal dado. Para archivos abiertos en modo texto en Windows, la posición devuelta es aproximada (debido a la conversión de fin de línea); en particular, guardar la posición actual con In_channel.pos , y luego volver a esta posición usando In_channel.seek no funcionará. val length : t ->

int64

Devuelve el tamaño (número de caracteres) del archivo regular en el que está abierto el canal dado. Si el canal está abierto en un archivo que no es un archivo regular, el resultado no tiene significado. El tamaño devuelto no tiene en cuenta las traducciones de fin de línea que pueden realizarse al leer de un canal abierto en modo

texto.

val set_binary_mode : t -> bool ->

unit

set_binary_mode ic true establece el canal ic en modo binario: no se producen traducciones durante la

entrada.

set_binary_mode ic false establece el canal ic en modo texto: dependiendo del sistema operativo, pueden producirse algunas traducciones durante la entrada. Por ejemplo, en Windows, los finales de línea se traducirán de \r\n a \n

.

Esta función no tiene efecto en los sistemas operativos que no distinguen entre modo texto y modo

binario.

val is_binary_mode : t ->

bool

is_binary_mode ic devuelve si el canal ic está en modo binario (ver In_channel.set_binary_mode )

.
