Image::ExifTool::RIFF(3) Documentación de Perl contribuida por el usuario Image::ExifTool::RIFF(3)

NOMBRE

Image::ExifTool::RIFF - Lee información meta de RIFF/AVI/WAV

SINOPSIS

Este módulo es utilizado por Image::ExifTool

DESCRIPCIÓN

Este módulo contiene las rutinas requeridas por Image::ExifTool para extraer información de archivos basados en RIFF (Resource Interchange File Format), incluyendo videos AVI, archivos de audio WAV e imágenes WEBP.
