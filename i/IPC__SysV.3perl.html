IPC::SysV(3perl) Guía de referencia del programador de Perl IPC::SysV(3perl)

NOMBRE

IPC::SysV - Constantes y llamadas del sistema IPC de System V

SINOPSIS

use IPC::SysV qw(IPC_STAT IPC_PRIVATE);

DESCRIPCIÓN

"IPC::SysV" define y exporta condicionalmente todas las constantes definidas en los archivos de cabecera de tu sistema que son necesarias para las llamadas IPC de SysV. Las comunes incluyen:

IPC_CREAT IPC_EXCL IPC_NOWAIT IPC_PRIVATE IPC_RMID IPC_SET IPC_STAT
GETVAL SETVAL GETPID GETNCNT GETZCNT GETALL SETALL
SEM_A SEM_R SEM_UNDO
SHM_RDONLY SHM_RND SHMLBA

y las auxiliares

S_IRUSR S_IWUSR S_IRWXU
S_IRGRP S_IWGRP S_IRWXG
S_IROTH S_IWOTH S_IRWXO

pero tu sistema podría tener más.

ftok( RUTA )
ftok( RUTA, ID )
Devuelve una clave basada en RUTA e ID, que puede ser usada como clave para "msgget", "semget" y "shmget". Ver ftok(3).

Si se omite ID, toma el valor predeterminado de 1. Si se proporciona un carácter único para ID, se usa el valor numérico de ese carácter.

shmat( ID, DIRECCIÓN, FLAG )
Adjunta el segmento de memoria compartida identificado por ID al espacio de direcciones del proceso que llama. Ver shmat(2).

DIRECCIÓN debe ser "undef" a menos que realmente sepas lo que estás haciendo.

shmdt( DIRECCIÓN )
Desadjunta el segmento de memoria compartida ubicado en la dirección especificada por DIRECCIÓN del espacio de direcciones del proceso que llama. Ver shmdt(2).
memread( DIRECCIÓN, VAR, POSICIÓN, TAMAÑO )
Lee TAMAÑO bytes de un segmento de memoria en DIRECCIÓN comenzando en la posición POSICIÓN. VAR debe ser una variable que contendrá los datos leídos. Devuelve verdadero si tiene éxito, o falso si hay un error. memread() mancha la variable.
memwrite( DIRECCIÓN, CADENA, POSICIÓN, TAMAÑO )
Escribe TAMAÑO bytes de CADENA en un segmento de memoria en DIRECCIÓN comenzando en la posición POSICIÓN. Si CADENA es demasiado larga, solo se usan TAMAÑO bytes; si CADENA es demasiado corta, se escriben nulos para completar TAMAÑO bytes. Devuelve verdadero si tiene éxito, o falso si hay un error.

VER TAMBIÉN

IPC::Msg, IPC::Semaphore, IPC::SharedMem, ftok(3), shmat(2), shmdt(2)
