NOMBRE

IO::Pager::Page - Emula IO::Page, canaliza STDOUT a un paginador si STDOUT es un TTY

SINOPSIS

Canaliza STDOUT a un paginador si STDOUT es un TTY

DESCRIPCIÓN

IO::Pager fue diseñado para decidir programáticamente si dirigir el manejador de archivos STDOUT a una tubería a un paginador especificado en la variable de entorno PAGER o a una lista estándar de paginadores.

USO

BEGIN {
  use IO::Pager::Page;
  # usa I::P::P primero, por si acaso otro módulo envía salida a STDOUT
}
print<<HEREDOC;
...
Mucha texto después
HEREDOC

Si deseas evitar la posibilidad de un error de Tubería Rota resultante de que el usuario salga prematuramente del paginador, carga IO::Pager::Page de la siguiente manera:

use IO::Pager::Page hush=>1;

VER TAMBIÉN

IO::Page, IO::Pager, IO::Pager::Unbuffered, IO::Pager::Buffered
