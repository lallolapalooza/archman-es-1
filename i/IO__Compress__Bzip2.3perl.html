IO::Compress::Bzip2 - Escribir archivos/búferes bzip2

DESCRIPCIÓN

Este módulo proporciona una interfaz de Perl que permite escribir datos comprimidos con bzip2 en archivos o búferes.

Para leer archivos/búferes bzip2, consulte el módulo complementario IO::Uncompress::Bunzip2.

Interfaz Funcional

Se proporciona una función de nivel superior, "bzip2", para realizar una compresión "de un solo disparo" entre búferes y/o archivos. Para un control más detallado sobre el proceso de compresión, consulte la sección "Interfaz OO".

use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
bzip2 $input_filename_or_reference => $output_filename_or_reference [,OPTS]
    or die "bzip2 failed: $Bzip2Error\n";

La interfaz funcional necesita Perl 5.005 o superior.

bzip2 $input_filename_or_reference => $output_filename_or_reference [, OPTS]

"bzip2" espera al menos dos parámetros, $input_filename_or_reference y $output_filename_or_reference y cero o más parámetros opcionales (véase "Parámetros Opcionales")

El $input_filename_or_reference parámetro

El parámetro, $input_filename_or_reference, se utiliza para definir la fuente de los datos sin comprimir.

Puede tomar una de las siguientes formas:

Un nombre de archivo
Si el $input_filename_or_reference parámetro es un escalar simple, se asume que es un nombre de archivo. Este archivo se abrirá para lectura y los datos de entrada se leerán de él.
Un manejador de archivo
Si el $input_filename_or_reference parámetro es un manejador de archivo, los datos de entrada se leerán de él. La cadena '-' puede usarse como alias para la entrada estándar.
Una referencia a escalar
Si $input_filename_or_reference es una referencia a escalar, los datos de entrada se leerán de $$input_filename_or_reference.
Una referencia a arreglo
Si $input_filename_or_reference es una referencia a arreglo, cada elemento del arreglo debe ser un nombre de archivo.

Los datos de entrada se leerán de cada archivo a su vez.

Se recorrerá el arreglo completo para asegurarse de que solo contiene nombres de archivo válidos antes de comprimir ningún dato.

Una cadena de FileGlob de entrada string
Si $input_filename_or_reference es una cadena delimitada por los caracteres "<" y ">" "bzip2" asumirá que es una cadena de fileglob de entrada. La entrada es la lista de archivos que coinciden con el fileglob.

Consulte File::GlobMapper para más detalles.

Si el $input_filename_or_reference parámetro es de cualquier otro tipo, "undef" será devuelto.

El $output_filename_or_reference parámetro

El parámetro $output_filename_or_reference se utiliza para controlar el destino de los datos comprimidos. Este parámetro puede tomar una de estas formas.

Un nombre de archivo
Si el $output_filename_or_reference parámetro es un escalar simple, se asume que es un nombre de archivo. Este archivo se abrirá para escritura y los datos comprimidos se escribirán en él.
Un manejador de archivo
Si el $output_filename_or_reference parámetro es un manejador de archivo, los datos comprimidos se escribirán en él. La cadena '-' puede usarse como alias para la salida estándar.
Una referencia a escalar
Si $output_filename_or_reference es una referencia a escalar, los datos comprimidos se almacenarán en $$output_filename_or_reference.
Una Referencia a Arreglo
Si $output_filename_or_reference es una referencia a arreglo, los datos comprimidos se añadirán al final del arreglo.
Un FileGlob de Salida
Si $output_filename_or_reference es una cadena delimitada por los caracteres "<" y ">" "bzip2" asumirá que es una cadena de fileglob de salida. La salida es la lista de archivos que coinciden con el fileglob.

Cuando $output_filename_or_reference es una cadena de fileglob, $input_filename_or_reference también debe ser una cadena de fileglob. Cualquier otra cosa es un error.

Consulte File::GlobMapper para más detalles.

Si el $output_filename_or_reference parámetro es de cualquier otro tipo, "undef" será devuelto.

Notas

Cuando $input_filename_or_reference se mapea a múltiples archivos/búferes y $output_filename_or_reference es un único archivo/búfer, los archivos/búferes de entrada se almacenarán en $output_filename_or_reference como una serie concatenada de flujos de datos comprimidos.

Parámetros Opcionales

Los parámetros opcionales para la función de un solo disparo "bzip2" son (en su mayoría) idénticos a los utilizados con la interfaz OO definida en la sección "Opciones del Constructor". Las excepciones se enumeran a continuación

"AutoClose => 0|1"
Esta opción se aplica a cualquier flujo de datos de entrada o salida a "bzip2" que sean manejadores de archivo.

Si se especifica "AutoClose" , y el valor es verdadero, resultará en que todos los manejadores de archivo de entrada y/o salida se cierren una vez que "bzip2" haya completado.

Este parámetro tiene como valor predeterminado 0.

"BinModeIn => 0|1"
Esta opción ahora no tiene efecto. Todos los archivos se leerán en modo binario.
"Append => 0|1"
El comportamiento de esta opción depende del tipo de flujo de datos de salida.
  • Un Búfer

    Si "Append" está habilitado, todos los datos comprimidos se añadirán al final del búfer de salida. De lo contrario, el búfer de salida se borrará antes de que se escriba en él cualquier dato comprimido.

  • Un Nombre de Archivo

    Si "Append" está habilitado, el archivo se abrirá en modo de añadir. De lo contrario, el contenido del archivo, si lo hay, se truncará antes de que se escriba en él cualquier dato comprimido.

  • Un Manejador de Archivo

    Si "Append" está habilitado, el manejador de archivo se posicionará al final del archivo mediante una llamada a "seek" antes de que se escriba cualquier dato comprimidos escrito en él. De lo contrario, el puntero del archivo no se moverá.

Cuando "Append" está especificado, y establecido en true, hará que añada todos los datos comprimidos al flujo de datos de salida.

Por lo tanto, cuando la salida es un manejador de archivo (filehandle), realizará una búsqueda (seek) al final del archivo (eof) antes de escribir cualquier dato comprimido. Si la salida es un nombre de archivo, se abrirá para añadir (append). Si la salida es un buffer, todos los datos comprimidos se añadirán al buffer existente.

A la inversa, cuando "Append" no está especificado, o está presente y se establece en false, funcionará de la siguiente manera.

Cuando la salida es un nombre de archivo, truncará el contenido de el archivo antes de escribir cualquier dato comprimido. Si la salida es un manejador de archivo (filehandle), su posición no se cambiará. Si la salida es un buffer, se borrará antes de que se emita cualquier dato comprimido.

Por defecto es 0.

Oneshot Ejemplos

Aquí hay algunos ejemplos que muestran las capacidades del módulo.

Streaming

Este ejemplo de línea de comando muy simple demuestra las capacidades de streaming del módulo. El código lee datos de STDIN, los comprime, y escribe los datos comprimidos en STDOUT.

$ echo hello world | perl -MIO::Compress::Bzip2=bzip2 -e 'bzip2 \*STDIN => \*STDOUT' >output.bz2

El nombre de archivo especial "-" se puede usar como sustituto para tanto "\*STDIN" como "\*STDOUT", por lo que lo anterior se puede reescribir como

$ echo hello world | perl -MIO::Compress::Bzip2=bzip2 -e 'bzip2 "-" => "-"' >output.bz2

Comprimiendo un archivo del sistema de archivos

Para leer el contenido del archivo "file1.txt" y escribir los datos comprimidos en el archivo "file1.txt.bz2".

use strict ;
use warnings ;
use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
my $input = "file1.txt";
bzip2 $input => "$input.bz2"
    or die "bzip2 failed: $Bzip2Error\n";

Leyendo de un manejador de archivo (filehandle) y escribiendo en un buffer en memoria

Para leer de un manejador de archivo (filehandle) de Perl existente, $input, y escribir los datos comprimidos en un buffer, $buffer.

use strict ;
use warnings ;
use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
use IO::File ;
my $input = IO::File->new( "<file1.txt" )
    or die "Cannot open 'file1.txt': $!\n" ;
my $buffer ;
bzip2 $input => \$buffer
    or die "bzip2 failed: $Bzip2Error\n";

Comprimiendo múltiples archivos

Para comprimir todos los archivos en el directorio "/my/home" que coincidan con "*.txt" y almacenar los datos comprimidos en el mismo directorio

use strict ;
use warnings ;
use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
bzip2 '</my/home/*.txt>' => '<*.bz2>'
    or die "bzip2 failed: $Bzip2Error\n";

y si quieres comprimir cada archivo uno a la vez, esto hará el truco

use strict ;
use warnings ;
use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
for my $input ( glob "/my/home/*.txt" )
{
    my $output = "$input.bz2" ;
    bzip2 $input => $output
        or die "Error compressing '$input': $Bzip2Error\n";
}

OO Interfaz

Constructor

El formato del constructor para "IO::Compress::Bzip2" se muestra a continuación

my $z = IO::Compress::Bzip2->new( $output [,OPTS] )
    or die "IO::Compress::Bzip2 failed: $Bzip2Error\n";

El constructor toma un parámetro obligatorio, $output, definido a continuación y cero o más "OPTS", definidos en "Constructor Options".

Devuelve un "IO::Compress::Bzip2" objeto en caso de éxito y "undef" en caso de fallo. La variable $Bzip2Error contendrá un mensaje de error en caso de fallo.

Si estás ejecutando Perl 5.005 o superior, el objeto, $z, devuelto por IO::Compress::Bzip2 se puede usar exactamente como un manejador de archivo (filehandle) de IO::File. Esto significa que todas las operaciones normales de archivo de salida se pueden realizar con $z. Por ejemplo, para escribir en un archivo/buffer comprimido puedes usar cualquiera de estas formas

$z->print("hello world\n");
print $z "hello world\n";

A continuación hay un ejemplo simple de uso de la interfaz OO para crear un archivo de salida "myfile.bz2" y escribir algunos datos en él.

my $filename = "myfile.bz2";
my $z = IO::Compress::Bzip2->new($filename)
    or die "IO::Compress::Bzip2 failed: $Bzip2Error\n";
$z->print("abcde");
$z->close();

Ver "Examples" para más información.

El parámetro obligatorio $output se usa para controlar el destino de los datos comprimidos. Este parámetro puede tomar una de estas formas.

Un nombre de archivo
Si el $output parámetro es un escalar simple, se asume que es un nombre de archivo. Este archivo se abrirá para escribir y los datos comprimidos se escribirán en él.
Un manejador de archivo (filehandle)
Si el $output parámetro es un manejador de archivo (filehandle), los datos comprimidos se escribirán en él. La cadena '-' se puede usar como un alias para la salida estándar.
Una referencia a escalar
Si $output es una referencia a escalar, los datos comprimidos se almacenarán en $$output.

Si el $output parámetro es de cualquier otro tipo, "IO::Compress::Bzip2"::new devolverá undef.

Constructor Opciones

"OPTS" es cualquier combinación de cero o más de las siguientes opciones:

"AutoClose => 0|1"
Esta opción solo es válida cuando el $output parámetro es un manejador de archivo (filehandle). Si se especifica, y el valor es true, resultará en que $output se cierre una vez que se llame al método "close" o el objeto "IO::Compress::Bzip2" sea destruido.

Este parámetro por defecto es 0.

"Append => 0|1"
Abre $output en modo de añadido (append).

El comportamiento de esta opción depende del tipo de $output.

  • Un Buffer

    Si $output es un buffer y "Append" está habilitado, todos los datos comprimidos se añadirán al final de $output. De lo contrario, $output se borrará antes de que se escriban datos en él.

  • Un Nombre de Archivo

    Si $output es un nombre de archivo y "Append" está habilitado, el archivo se abrirá en modo de añadido (append). De lo contrario, el contenido del archivo, si lo hay, se truncará antes de que se escriban datos comprimidos en él.

  • Un Manejador de Archivo (Filehandle)

    Si $output es un manejador de archivo (filehandle), el puntero del archivo se posicionará al final del archivo mediante una llamada a "seek" antes de que se escriban datos comprimidos en él. De lo contrario, el puntero del archivo no se moverá.

Este parámetro por defecto es 0.

"BlockSize100K => number"
Especifica el número de bloques de 100K que bzip2 usa durante la compresión.

Los valores válidos van de 1 a 9, donde 9 es la mejor compresión.

El valor por defecto es 1.

"WorkFactor => number"
Especifica cuánto esfuerzo debe hacer bzip2 antes de recurrir a un algoritmo de compresión de respaldo más lento.

Los valores válidos van de 0 a 250, donde 0 significa usar el valor por defecto 30.

El valor por defecto es 0.

"Strict => 0|1"
Esta es una opción de marcador de posición.

Ejemplos

Streaming

Este ejemplo de línea de comando muy simple demuestra las capacidades de streaming del módulo. El código lee datos de STDIN o de todos los archivos dados en la línea de comandos, los comprime, y escribe los datos comprimidos en STDOUT.

use strict ;
use warnings ;
use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
my $z = IO::Compress::Bzip2->new("-", Stream => 1)
    or die "IO::Compress::Bzip2 failed: $Bzip2Error\n";
while (<>) {
    $z->print("abcde");
}
$z->close();

Nota el uso de "-" para significar "STDOUT". Alternativamente puedes usar "\*STDOUT".

Comprimiendo un archivo del sistema de archivos

Para leer el contenido del archivo "file1.txt" y escribir los datos comprimidos en el archivo "file1.txt.bz2" hay algunas opciones

Comienza creando el objeto de compresión y abriendo el archivo de entrada

use strict ;
use warnings ;
use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;
my $input = "file1.txt";
my $z = IO::Compress::Bzip2->new("file1.txt.bz2")
    or die "IO::Compress::Bzip2 failed: $Bzip2Error\n";
# open the input file
open my $fh, "<", "file1.txt"
    or die "Cannot open file1.txt: $!\n";
# loop through the input file & write to the compressed file
while (<$fh>) {
    $z->print($_);
}
# not forgetting to close the compressed file
$z->close();

NAME

IO::Compress::Bzip2 - Compresses and uncompresses files or buffers using the Bzip2 compression algorithm

SYNOPSIS

use IO::Compress::Bzip2 qw(:all) ;

# Functional interface
my $status = bzip2 $input_file, $output_file ;
my $status = bzip2 $input_file => $output_file ;
my $status = bzip2 \$input_data => \$output_data ;
my $status = bzip2 $input_handle => $output_handle ;

# OO interface
my $z = IO::Compress::Bzip2->new($output_file, { Binary => 1 }) ;
$z->open($output_file, "w") ;
$z->print("some data\n") ;
$z->syswrite("more data") ;
my $bytes_written = $z->write($buffer) ;
my $status = $z->close() ;

DESCRIPTION

This module provides a Perl interface to the bzip2 compression algorithm. It can be used to compress and uncompress data from files, filehandles or scalars.

It is part of the IO::Compress bundle.

There are two ways to use this module:

Functional Interface

The simplest way to use IO::Compress::Bzip2 is via the bzip2 function.

It takes a minimum of 2 arguments, an input source and an output destination.

The input source can be a filename or a scalar containing the data to be compressed. The output destination can be a filename, a scalar (to store the compressed data), or a filehandle.

The function returns true on success and false on failure. When an error occurs, the global variable $Bzip2Error will contain a string describing the error.

The function also accepts an optional hash reference containing any of the supported constructor options.

Example:

use IO::Compress::Bzip2 qw(bzip2 $Bzip2Error) ;

# Compress a file
my $status = bzip2 $input_file, $output_file ;
unless ($status) {
    die "Failed to compress '$input_file': $Bzip2Error\n" ;
}

# Compress a file, writing compressed data to a scalar
my $compressed_data ;
my $status = bzip2 $input_file, \$compressed_data ;
die "Failed to compress file: $Bzip2Error\n" unless $status ;

# Compress data in a scalar
my $uncompressed_data = "some data" ;
my $compressed_data ;
my $status = bzip2 \$uncompressed_data, \$compressed_data ;
die "Failed to compress scalar: $Bzip2Error\n" unless $status ;

# Compress a filehandle
open my $in_fh, "<", $input_file or die "Could not open $input_file: $!" ;
open my $out_fh, ">", $output_file or die "Could not open $output_file: $!" ;
my $status = bzip2 $in_fh, $out_fh ;
close $in_fh ;
close $out_fh ;
die "Failed to compress filehandle: $Bzip2Error\n" unless $status ;

OO Interface

The OO interface provides finer control over the compression process. You create an object, open a destination, write data to it and then close it.

Example:

use IO::Compress::Bzip2 ;

# Open a file for writing compressed data
my $z = IO::Compress::Bzip2->new($output_file, { Binary => 1 }) ;
# Or open a filehandle
# my $z = IO::Compress::Bzip2->new(\*STDOUT, { Binary => 1 }) ;
# Or open a scalar
# my $z = IO::Compress::Bzip2->new(\$compressed_data, { Binary => 1 }) ;

# Check if the object was created successfully
unless ($z) {
    die "Failed to create IO::Compress::Bzip2 object: $Bzip2Error\n" ;
}

# Write data
$z->print("some data\n") ;
$z->write("more data") ;
$z->syswrite("even more data") ;

# Close the compressed file/buffer
my $status = $z->close() ;
unless ($status) {
    die "Failed to close compressed file: $Bzip2Error\n" ;
}

Methods

new

my $z = IO::Compress::Bzip2->new($target) ;
my $z = IO::Compress::Bzip2->new($target, OPTS) ;

Creates a new IO::Compress::Bzip2 object. $target can be a filename, a filehandle or a scalar reference. OPTS is an optional hash reference containing constructor options.

Returns the new object on success, or undef on failure.

See the "Constructor Options" section for more details.

open

$z->open($filename)
$z->open($filename, $mode)

Opens a file for writing compressed data.

Returns true on success, otherwise false.

print

$z->print(LIST)

Performs the same function as the built-in "print" function.

Returns true if successful.

printf

Usage is

$z->printf($format, $data)
printf $z $format, $data

Compresses and outputs the contents of the $data parameter.

Returns true if successful.

syswrite

Usage is

$z->syswrite $data
$z->syswrite $data, $length
$z->syswrite $data, $length, $offset

Compresses and outputs the contents of the $data parameter.

Returns the number of uncompressed bytes written, or "undef" if unsuccessful.

write

Usage is

$z->write $data
$z->write $data, $length
$z->write $data, $length, $offset

Compresses and outputs the contents of the $data parameter.

Returns the number of uncompressed bytes written, or "undef" if unsuccessful.

flush

Usage is

$z->flush;

Flushes any pending compressed data to the output file/buffer.

Returns true on success.

tell

Usage is

$z->tell()
tell $z

Returns the uncompressed file offset.

eof

Usage is

$z->eof();
eof($z);

Returns true if the "close" method has been called.

seek

$z->seek($position, $whence);
seek($z, $position, $whence);

Provides a sub-set of the "seek" functionality, with the restriction that it is only legal to seek forward in the output file/buffer. It is a fatal error to attempt to seek backward.

Empty parts of the file/buffer will have NULL (0x00) bytes written to them.

The $whence parameter takes one the usual values, namely SEEK_SET, SEEK_CUR or SEEK_END.

Returns 1 on success, 0 on failure.

binmode

Usage is

$z->binmode
binmode $z ;

This is a noop provided for completeness.

opened

$z->opened()

Returns true if the object currently refers to a opened file/buffer.

autoflush

my $prev = $z->autoflush()
my $prev = $z->autoflush(EXPR)

If the $z object is associated with a file or a filehandle, this method returns the current autoflush setting for the underlying filehandle. If "EXPR" is present, and is non-zero, it will enable flushing after every write/print operation.

If $z is associated with a buffer, this method has no effect and always returns "undef".

Note that the special variable $| cannot be used to set or retrieve the autoflush setting.

input_line_number

$z->input_line_number()
$z->input_line_number(EXPR)

This method always returns "undef" when compressing.

fileno

$z->fileno()
fileno($z)

If the $z object is associated with a file or a filehandle, "fileno" will return the underlying file descriptor. Once the "close" method is called "fileno" will return "undef".

If the $z object is associated with a buffer, this method will return "undef".

close

$z->close() ;
close $z ;

Flushes any pending compressed data and then closes the output file/buffer.

For most versions of Perl this method will be automatically invoked if the IO::Compress::Bzip2 object is destroyed (either explicitly or by the variable with the reference to the object going out of scope). The exceptions are Perl versions 5.005 through 5.00504 and 5.8.0. In these cases, the "close" method will be called automatically, but not until global destruction of all live objects when the program is terminating.

Therefore, if you want your scripts to be able to run on all versions of Perl, you should call "close" explicitly and not rely on automatic closing.

Returns true on success, otherwise 0.

If the "AutoClose" option has been enabled when the IO::Compress::Bzip2 object was created, and the object is associated with a file, the underlying file will also be closed.

newStream([OPTS])

Usage is

$z->newStream( [OPTS] )

Closes the current compressed data stream and starts a new one.

OPTS consists of any of the options that are available when creating the $z object.

See the "Constructor Options" section for more details.
