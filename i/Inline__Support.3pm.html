NOMBRE

Inline-Support - Información de soporte para Inline.pm y módulos relacionados.

DESCRIPCIÓN

Este documento contiene toda la información de soporte más reciente para "Inline.pm" y los Módulos de Soporte de Lenguaje en Línea (ILSM) reconocidos disponibles en CPAN.

IDIOMAS SOPORTADOS

El idioma más importante que soporta Inline es "C". Esto se debe a que el propio Perl está escrito en "C". Al dar a sus scripts de Perl acceso a "C", en efecto les da acceso a todos los gloriosos detalles internos de Perl. (Cuidado, escritor :-)

Hasta la fecha, Inline también soporta:

  • C++
  • Java
  • Python
  • Tcl
  • Assembly
  • CPR
  • ¡E incluso Inline::Foo! :)

Los proyectos que más me gustaría ver ocurrir en el año 2001 son:

  • Fortran
  • Ruby
  • Lisp
  • Guile
  • Bash
  • Perl4

PLATAFORMAS SOPORTADAS

"Inline::C" debería funcionar en cualquier lugar donde se puedan instalar módulos de extensión de CPAN (aquellos que usan XS), utilizando el formato de instalación típico de:

perl Makefile.PL
make
make test
make install

Se ha probado en muchas variantes de Unix y Windows.

NOTA: "Inline::C" requiere Perl 5.005 o superior porque "Parse::RecDescent" lo requiere. (Algo que ver con el operador "qr")

Inline ha sido probado con éxito en un momento u otro en las siguientes plataformas:

  • Linux
  • Solaris
  • SunOS
  • HPUX
  • AIX
  • FreeBSD
  • OpenBSD
  • BeOS
  • OS X
  • WinNT
  • Win2K
  • WinME
  • Win98
  • Cygwin

Las pruebas en Microsoft merecen una explicación adicional. Utilicé las siguientes:

  • Windows NT 4.0 (service pack 6)
  • Perl 5.005_03 (ActiveState build 522)
  • MS Visual C++ 6.0
  • La utilidad make "nmake" (distribuida con Visual C++)

"Inline::C" extrae toda su configuración base (incluyendo qué utilidad "make" usar) de "Config.pm". Dado que su versión de MSWin32 de Perl probablemente provino de ActiveState (como una distribución binaria), "Config.pm" indicará que "nmake" es la utilidad "make" del sistema. Esto se debe a que ActiveState utiliza Visual C++ para compilar Perl.

Para instalar "Inline.pm" (o cualquier otro módulo CPAN) en MSWin32 con Visual C++, use estos comandos:

perl Makefile.PL
nmake
nmake test
nmake install

Inline también se ha hecho funcionar con Mingw32/gcc en todas las plataformas de Windows. Este es un compilador gratuito para Windows. También debe usar un perl compilado con ese compilador.

La prueba "Cygwin" se realizó en una máquina Windows 98 utilizando el software de capa de portabilidad Unix/Win32 Cygwin de Cygnus. El binario "perl" en esta máquina también fue compilado usando el conjunto de herramientas Cygwin ("gcc"). Este software está disponible gratuitamente en http://sources.redhat.com/cygwin/

Si logra que Inline funcione en una nueva plataforma, envíeme un correo electrónico. Si no funciona, también hágamelo saber y veré qué se puede hacer.
