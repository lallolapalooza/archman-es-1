Este módulo proporciona una interfaz de Perl que permite la lectura de archivos/búferes que se ajustan al RFC

1952.

Para escribir archivos/búferes RF

OO".

En estos casos, el método "close" se llamará automáticamente, pero no hasta la destrucción global de todos los objetos vivos cuando el programa esté

terminando.

Por lo tanto, si desea que sus scripts puedan ejecutarse en todas las versiones de Perl, debe llamar a "close" explícitamente y no depender del cierre

automático.

trailingDat

a

El uso

my $data = $z->trailingData()
;

Devuelve los datos, si los hay, que están presentes inmediatamente después del flujo de datos comprimidos una vez que la descompresión está completa. Solo tiene sentido llamar a este método una vez que se ha encontrado el final del flujo de datos

comprimidos.

Esta opción se puede usar cuando hay información útil inmediatamente después del flujo de datos comprimidos, y no conoce la longitud del flujo de datos

comprimidos.

Si la entrada es un búfer, "trailingData" devolverá todo desde el final del flujo de datos comprimido hasta el final del

búfer.

Si la entrada es un identificador de archivo, "trailingData" devolverá los datos que quedan en el búfer de entrada del identificador de archivo una vez que se ha alcanzado el final del flujo de datos comprimido. Luego puedes usar el identificador de archivo para leer el resto del archivo de

entrada.

No te molestes en usar "trailingData" si la entrada es un nombre de

archivo.

Si conoces la longitud del flujo de datos comprimido antes de empezar a descomprimir, puedes evitar tener que usar "trailingData" estableciendo la opción "InputLength"
