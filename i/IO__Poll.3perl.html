IO::Poll(3perl) Guía de referencia del programador de Perl IO::Poll(3perl)

NOMBRE

IO::Poll - Interfaz de objeto para la llamada poll del sistema

SINOPSIS

use IO::Poll qw(POLLRDNORM POLLWRNORM POLLIN POLLHUP);
$poll = IO::Poll->new();
$poll->mask($input_handle => POLLIN);
$poll->mask($output_handle => POLLOUT);
$poll->poll($timeout);
$ev = $poll->events($input);

DESCRIPCIÓN

IO::Poll es una interfaz simple a la rutina poll a nivel de sistema.

MÉTODOS

mask ( IO [, EVENT_MASK ] )
Si se proporciona EVENT_MASK, entonces, si EVENT_MASK es distinto de cero, IO se añade a la lista de descriptores de archivo y la próxima llamada a poll comprobará cualquier evento especificado en EVENT_MASK. Si EVENT_MASK es cero, entonces IO se eliminará de la lista de descriptores de archivo.

Si no se proporciona EVENT_MASK, el valor de retorno será el valor de la máscara de eventos actual para IO.

poll ( [ TIMEOUT ] )
Llama a la rutina poll a nivel de sistema. Si no se especifica TIMEOUT, la llamada se bloqueará. Devuelve el número de manejadores que tuvieron eventos, o -1 en caso de error.
events ( IO )
Devuelve la máscara de eventos que representa los eventos que ocurrieron en IO durante la última llamada a "poll".
remove ( IO )
Elimina IO de la lista de descriptores de archivo para el próximo poll.
handles( [ EVENT_MASK ] )
Devuelve una lista de manejadores. Si no se proporciona EVENT_MASK, se devolverá una lista de todos los manejadores conocidos. Si se proporciona EVENT_MASK, se devolverá una lista de manejadores para los cuales ocurrieron uno de los eventos especificados por EVENT_MASK durante la última llamada a "poll".

VER TAMBIÉN

poll(2), IO::Handle, IO::Select
