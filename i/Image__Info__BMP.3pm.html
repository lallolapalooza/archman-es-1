Image::Info::BMP(3) Documentación de Perl contribuida por el usuario Image::Info::BMP(3)

NOMBRE

Image::Info::BMP - Soporte para Windows Device Independent Bitmap para Image::Info

SINOPSIS

use Image::Info qw(image_info dim);
my $info = image_info("imagen.bmp");
if (my $error = $info->{error}) {
    die "No se puede analizar la información de la imagen: $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

DESCRIPCIÓN

Este módulo suministra los nombres de clave estándar excepto Gamma, Interlace, LastModificationTime, así como:

BMP_ColorsImportant
Especifica el número de índices de color que son necesarios para mostrar el mapa de bits. Si este valor es cero, se requieren todos los colores.
BMP_Origin
Si es verdadero, el mapa de bits es un DIB ascendente y su origen es la esquina inferior izquierda. De lo contrario, el mapa de bits es un DIB descendente y su origen es la esquina superior izquierda.
ColorPalette
Referencia a una matriz de todos los colores utilizados. Esta clave solo está presente si "image_info" se invoca como "image_info($file, ColorPalette=>1)".
ColorTableSize
El número de colores que utiliza la imagen. Si es 0, entonces es una imagen de color verdadero. El número de colores *disponibles* es 2 ^ BitsPerSample.

MÉTODOS

process_file()

$info->process_file($source, $options);

Procesa un archivo y establece los campos de información encontrados en el objeto $info.

DIAGNÓSTICOS

Desajuste de tamaño
La imagen puede ser correcta, pero el tamaño del archivo no coincide con el valor almacenado internamente.

ERRORES

La implementación actual solo funciona en arquitecturas little-endian. Por consiguiente, es posible que se informen datos erróneos sobre la compresión (incluidos file_ext y file_mime_type).
