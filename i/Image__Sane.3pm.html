Image::Sane(3) Documentación de Perl aportada por el usuario Image::Sane(3)

NOMBRE

Image::Sane - Extensión de Perl para el Proyecto SANE (Scanner Access Now Easy)

VERSIÓN

5

SINOPSIS

use Image::Sane;
my @devices = Image::Sane->get_devices;
my $device = Image::Sane::Device->open($devices[0]->{name});
my $param = $device->get_parameters;
$device->write_pnm_header($fh, $param);
my ($data, $len) = $device->read ($param->{bytes_per_line});
print $fh $data;

DESCRIPCIÓN

Estos enlaces de Perl para el Proyecto SANE (Scanner Access Now Easy) le permiten acceder a escáneres compatibles con SANE de una manera orientada a objetos y propia de Perl, liberándolo de la conversión de tipos y la gestión de memoria en C, permaneciendo muy cercano en espíritu a la API original.

Obtenga más información sobre SANE en http://www.sane-project.org.

SUBRUTINAS/MÉTODOS

Image::Sane->get_version

Devuelve una matriz con las versiones SANE_VERSION_(MAJOR|MINOR|BUILD):

join('.', Image::Sane->get_version)

Image::Sane->get_version_scalar

Devuelve un escalar con las versiones SANE_VERSION_(MAJOR|MINOR|BUILD) combinadas según la numeración de versiones de Perl, es decir, sane 1.0.19 da 1.000019. Esto permite comparaciones simples de versiones.

Image::Sane->get_devices

Esta función se puede utilizar para consultar la lista de dispositivos disponibles. Si la función se ejecuta correctamente, devuelve una matriz de referencias a hashes con los dispositivos encontrados. La lista devuelta está garantizada para permanecer válida hasta que (a) se realice otra llamada a esta función o (b) se realice una llamada a sane_exit() . Esta función se puede llamar repetidamente para detectar cuándo hay nuevos dispositivos disponibles.

Si el argumento local_only es verdadero, solo se devuelven dispositivos locales (dispositivos directamente conectados a la máquina en la que se ejecuta SANE). Si es falso, la lista de dispositivos incluye todos los dispositivos remotos a los que la biblioteca SANE tiene acceso.

try {
    @devices = Image::Sane->get_devices;
    print "Name: $devices[0]->{name}\n";
    print "Vendor: $devices[0]->{vendor}\n";
    print "Model: $devices[0]->{model}\n";
    print "Type: $devices[0]->{type}\n";
}
catch {
    print "Error getting devices:", $_->error, "\n";
};

Image::Sane::Device->open

Esta función se utiliza para establecer una conexión con un dispositivo en particular. El nombre del dispositivo que se va a abrir se pasa en el argumento name. Si la llamada se completa correctamente, se devuelve un objeto Image::Sane::Device. Como caso especial, especificar una cadena de longitud cero como dispositivo solicita abrir el primer dispositivo disponible (si existe tal dispositivo).

my $device = Image::Sane::Device->open($device_name);

Image::Sane::Device->get_option_descriptor

Esta función se utiliza para acceder a los descriptores de opciones. La función devuelve una referencia a un hash con el descriptor de la opción para el número de opción n del objeto Image::Sane::Device. Se garantiza que el número de opción 0 es una opción válida. Su valor es un entero que especifica el número de opciones disponibles para el objeto Image::Sane::Device (el recuento incluye la opción 0). Si n no es un índice de opción válido, la función aborta.

try {
    $option = $device->get_option_descriptor($n);
    print "Name: $option->{name}\n";
    print "Name: $option->{title}\n";
    print "Name: $option->{desc}\n";
    print "Name: $option->{type}\n";
    print "Name: $option->{unit}\n";
    print "Name: $option->{cap}\n";
    print "Name: $option->{max_values}\n";
    print "Name: $option->{constraint_type}\n";
}
catch {
    print "Error getting option descriptor:", $_->error, "\n";
};

El contenido de las claves del hash "name", "title", "desc", "type", "unit", "cap" y "constraint_type" es según la descripción de la API de C (http://www.sane-project.org/html). Hay una clave de restricción adicional que contiene o bien una matriz con los valores posibles de la opción, o un hash con las claves "max", "min" y "quant".

La clave max_values reemplazó a la clave size en la API de C, y contiene el número máximo de valores que la opción puede contener.

Image::Sane::Device->get_option

Devuelve el valor actual de la opción seleccionada.

try {
    $value = $device->get_option($n);
    print "value: $value\n";
}
catch {
    print "Error getting option:", $_->error, "\n";
};

Para $option->{max_values} > 1, $value es una referencia a una matriz.

Image::Sane::Device->set_auto

Ordena al dispositivo seleccionado que seleccione automáticamente un valor apropiado. Este modo permanece activo hasta que se anule con una solicitud explícita set_option.

$device->set_auto($n);

Image::Sane::Device->set_option

Establece la opción seleccionada, devolviendo indicadores en $info, que están descritos en la API de C (http://www.sane-project.org/html).

$orig = $device->get_option($n);
$info = $device->set_option($n, $value);
if ($info & SANE_INFO_INEXACT) {
 $value = $device->get_option($n);
 print "rounded value of $opt->{name} from $orig to $value\n";
}

Para $option->{max_values} > 1, $value puede ser una referencia a una matriz.

Image::Sane::Device->get_parameters

Esta función se utiliza para obtener los parámetros de escaneo actuales. Se garantiza que los parámetros devueltos son precisos entre el momento en que se ha iniciado un escaneo (se ha llamado a Image::Sane::Device->start() ) y la finalización de esa solicitud. Fuera de esa ventana, los valores devueltos son estimaciones de mejor esfuerzo de lo que serán los parámetros cuando se invoque Image::Sane::Device->start() . Llamar a esta función antes de que un escaneo haya comenzado realmente permite, por ejemplo, obtener una estimación de cuán grande será la imagen escaneada.

try {
    $param = $device->get_parameters;
    print "format $param->{format}\n";
    print "last_frame $param->{last_frame}\n";
    print "bytes_per_line $param->{bytes_per_line}\n";
    print "pixels_per_line $param->{pixels_per_line}\n";
    print "lines $param->{lines}\n";
    print "depth $param->{depth}\n";
}
catch {
    print "Error getting parameters:", $_->error, "\n";
};

Por favor, consulte la documentación de C (http://www.sane-project.org/html) para obtener detalles sobre los valores anteriores.

Image::Sane::Device->start

Esta función inicia la adquisición de una imagen desde el dispositivo especificado.

$device->start;

Image::Sane::Device->read

Esta función se utiliza para leer datos de imagen desde el dispositivo especificado. El número de bytes devueltos en $buf se almacena en $len. Un backend debe establecer esto en cero cuando se lanza un error. Si la llamada tiene éxito, el número de bytes devueltos puede estar en cualquier lugar del rango de 0 a $maxlen bytes.

$param = $device->get_parameters;
$maxlen = $param->{bytes_per_line};
($buf, $len) = $test->read ($maxlen);

Si se llama a esta función cuando no hay datos disponibles, pueden ocurrir dos cosas, dependiendo del modo de E/S que esté activo para el dispositivo.

1. Si el dispositivo está en modo de E/S bloqueante (el modo predeterminado), la llamada se bloquea hasta que al menos un byte de datos esté disponible (o hasta que ocurra algún error).
2. Si el dispositivo está en modo de E/S no bloqueante, la llamada retorna inmediatamente con $len establecido en cero.

El modo de E/S del dispositivo se puede establecer mediante una llamada a Image::Sane::Device->set_io_mode().

Image::Sane::Device->cancel

Esta función se usa para cancelar inmediatamente o lo más rápido posible la operación actualmente pendiente del dispositivo.

$device->cancel;

Esta función se puede llamar en cualquier momento (siempre que $device sea válido), pero generalmente solo afecta a operaciones de larga duración (como la adquisición de imágenes). Es seguro llamar a esta función de forma asíncrona (por ejemplo, desde dentro de un manejador de señales). Es importante señalar que la finalización de esta operación no implica que la operación actualmente pendiente haya sido cancelada. Solo garantiza que la cancelación se ha iniciado. La cancelación se completa solo cuando la llamada cancelada lanza una excepción (típicamente con un valor de estado de SANE_STATUS_CANCELLED). Dado que la API de SANE no requiere que ninguna otra operación sea reentrante, esto implica que un frontend no debe llamar a ninguna otra operación hasta que la operación cancelada haya retornado.

Image::Sane::Device->set_io_mode

Esta función se usa para establecer el modo de E/S del dispositivo. El modo de E/S puede ser bloqueante o no bloqueante. Si el argumento $bool es SANE_TRUE, el modo se establece en modo no bloqueante, de lo contrario se establece en modo bloqueante. Esta función solo se puede llamar después de que se haya realizado una llamada a Image::Sane::Device->start() .

$device->set_io_mode ($bool);

De forma predeterminada, los manejadores recién abiertos operan en modo bloqueante. Un backend puede optar por no soportar el modo de E/S no bloqueante. En tal caso, la llamada lanza una excepción con el valor de estado SANE_STATUS_UNSUPPORTED. El E/S bloqueante debe ser soportado por todos los backends, por lo que llamar a esta función con SANE_FALSE está garantizado que se complete exitosamente.

Image::Sane::Device->get_select_fd

Esta función se usa para obtener un descriptor de archivo (específico de la plataforma) para el dispositivo que es legible si y solo si hay datos de imagen disponibles (es decir, cuando una llamada a Image::Sane::Device->read() retornará al menos un byte de datos).

$fd = $device->get_select_fd;

Esta función solo se puede llamar después de que se haya realizado una llamada a Image::Sane::Device->start() y se garantiza que el descriptor de archivo retornado permanecerá válido durante la duración de la adquisición de la imagen actual (es decir, hasta que Image::Sane::Device->cancel() o Image::Sane::Device->start() se llame nuevamente o hasta que Image::Sane::Device->read() lance una excepción con estado SANE_STATUS_EOF). De hecho, un backend debe garantizar cerrar el descriptor de archivo de selección retornado en el punto en el que la siguiente llamada a Image::Sane::Device->read() lanzaría una excepción con SANE_STATUS_EOF. Esto es necesario para asegurar que la aplicación pueda detectar cuándo ocurre esta condición sin tener que llamar realmente a Image::Sane::Device->read().

Un backend puede optar por no soportar esta operación. En tal caso, la función lanza una excepción con el código de estado SANE_STATUS_UNSUPPORTED.

Tenga en cuenta que la única operación soportada por el descriptor de archivo retornado es una prueba dependiente del sistema operativo anfitrión de si el descriptor de archivo es legible (por ejemplo, esta prueba se puede implementar usando select() o poll() bajo UNIX). Si se realiza cualquier otra operación en el descriptor de archivo, el comportamiento del backend se vuelve impredecible. Una vez que el descriptor de archivo señala el estado ``legible'', permanecerá en ese estado hasta que se realice una llamada a sane_read() . Dado que muchos dispositivos de entrada son muy lentos, se fomenta fuertemente el soporte para esta operación, ya que permite a una aplicación hacer otro trabajo mientras la adquisición de imágenes está en progreso.

Image::Sane::Device->write_pnm_header

Esta función es una función auxiliar de Perl puro para escribir un encabezado PNM. Obtendrá la configuración de imagen actual usando Image::Sane::Device->get_parameters, si no se proporcionan ya, por ejemplo:

$device->write_pnm_header($fh);

o

$parm = $device->get_parameters;
$device->write_pnm_header ($fh, $parm->{format}, 
                                $parm->{pixels_per_line},
                                $parm->{lines}, $parm->{depth});

DIAGNÓSTICO

Si la biblioteca SANE subyacente retorna un valor de estado diferente a SANE_STATUS_GOOD, se lanza una excepción. Por lo tanto, se sugiere que estas se capturen usando el módulo Try::Tiny. $_->status y $_->error se pueden usar dentro de la cláusula catch{} para dar el código de estado y su cadena equivalente.

CONFIGURACIÓN Y ENTORNO

Este módulo no requiere ninguna configuración o entorno especial, más allá de lo necesario para Perl y SANE.

DEPENDENCIAS

Obviamente, se requiere la biblioteca SANE, junto con los backends para los escáneres a usar.
Exception::Class se usa para lanzar excepciones. Se sugiere que estas se capturen con Try::Tiny.

INCOMPATIBILIDADES

Ninguna conocida.

ERRORES Y LIMITACIONES

Ninguna conocida.

VER TAMBIÉN

La Referencia Estándar de SANE http://www.sane-project.org/html es un útil compañero. Los enlaces de Perl siguen la API de C muy de cerca, y la documentación de referencia de C debe considerarse la fuente canónica.
