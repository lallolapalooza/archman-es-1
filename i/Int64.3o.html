Módulo Int64
: sig end

Enteros de 64 bits.

Este módulo proporciona operaciones sobre el tipo int64 de enteros con signo de 64 bits. A diferencia del tipo incorporado int , el tipo int64 está garantizado para tener exactamente 64 bits de ancho en todas las plataformas. Todas las operaciones aritméticas sobre int64 se realizan módulo 2^64

Aviso de rendimiento: los valores de tipo int64 ocupan más espacio de memoria que los valores de tipo int , y las operaciones aritméticas sobre int64 son generalmente más lentas que aquellas sobre int . Utilice int64 solo cuando la aplicación requiera aritmética exacta de 64 bits.

Los literales para enteros de 64 bits se sufijan con L:

      let zero: int64 = 0L
      let one: int64 = 1L
      let m_one: int64 = -1L

val rem : int64 -> int64 -> int64

Resto entero. Si y no es cero, el resultado de Int64.rem x y satisface la siguiente propiedad: x = Int64.add (Int64.mul (Int64.div x y) y) (Int64.rem x y) . Si y = 0 , Int64.rem x y lanza Division_by_zero .

val shift_left : int64 -> int -> int64

Int64.shift_left x y desplaza x hacia la izquierda en y bits. El resultado es indeterminado si y < 0 o y >= 64 .

val shift_right : int64 -> int -> int64

Int64.shift_right x y desplaza x hacia la derecha en y bits. Este es un desplazamiento aritmético: el bit de signo de x se replica e inserta en los bits vacantes. El resultado es indeterminado si y < 0 o y >= 64 .

val shift_right_logical : int64 -> int -> int64

Int64.shift_right_logical x y desplaza x hacia la derecha en y bits. Este es un desplazamiento lógico: se insertan ceros en los bits vacantes independientemente del signo de x . El resultado es indeterminado si y < 0 o y >= 64 .

val of_int : int -> int64

Convierte el entero dado (tipo int ) a un entero de 64 bits (tipo int64 ).

val to_int : int64 -> int

Convierte el entero de 64 bits dado (tipo int64 ) a un entero (tipo int ). En plataformas de 64 bits, el entero de 64 bits se toma módulo 2^63, es decir, el bit de orden superior se pierde durante la conversión. En plataformas de 32 bits, el entero de 64 bits se toma módulo 2^31, es decir, los 33 bits superiores se pierden durante la conversión.

val unsigned_to_int : int64 -> int option

Igual que Int64.to_int , pero interpreta el argumento como un entero sin signo. Devuelve None si el valor sin signo del argumento no cabe en un int .

val of_float : float -> int64

Convierte el número de punto flotante dado a un entero de 64 bits, descartando la parte fraccionaria (truncando hacia 0). Si el número de punto flotante truncado está fuera del rango [ Int64.min_int , Int64.max_int ], no se lanza ninguna excepción, y se devuelve un entero indeterminado, dependiente de la plataforma.

val to_float : int64 -> float

Convierte el entero de 64 bits dado a un número de punto flotante.

val of_int32 : int32 -> int64

Convierte el entero de 32 bits dado (tipo int32 ) a un entero de 64 bits (tipo int64 ).

val to_int32 : int64 -> int32

Convierte el entero de 64 bits dado (tipo int64 ) a un entero de 32 bits (tipo int32 ). El entero de 64 bits se toma módulo 2^32, es decir, los 32 bits superiores se pierden durante la conversión.

val of_nativeint : nativeint -> int64

Convierte el entero nativo dado (tipo nativeint ) a un entero de 64 bits (tipo int64 ).

val to_nativeint : int64 -> nativeint

Convierte el entero de 64 bits dado (tipo int64 ) a un entero nativo. En plataformas de 32 bits, el entero de 64 bits se toma módulo 2^32. En plataformas de 64 bits, la conversión es exacta.

val of_string : string -> int64

Convierte la cadena dada a un entero de 64 bits. La cadena se lee en decimal (por defecto, o si la cadena comienza con 0u ) o en hexadecimal, octal o binario si la cadena comienza con 0x , 0o o 0b respectivamente.

El prefijo 0u lee la entrada como un entero sin signo en el rango [0, 2*Int64.max_int+1] . Si la entrada excede Int64.max_int se convierte al entero con signo Int64.min_int + input - Int64.max_int - 1 .

El carácter _ (guion bajo) puede aparecer en cualquier lugar de la cadena y se ignora.

Lanza Failure si la cadena dada no es una representación válida de un entero, o si el entero representado excede el rango de enteros representables en el tipo int64 .

val of_string_opt : string -> int64 option

Igual que of_string , pero devuelve None en lugar de lanzar una excepción.

val bits_of_float : float -> int64

Devuelve la representación interna del float dado según la distribución de bits del 'formato doble' de punto flotante IEEE 754. El bit 63 del resultado representa el signo del float; los bits 62 a 52 representan el exponente (con sesgo); los bits 51 a 0 representan la mantisa.

val float_of_bits : int64 -> float

Devuelve el número de punto flotante cuya representación interna, según la distribución de bits del 'formato doble' de punto flotante IEEE 754, es el int64 dado.
