IO::Socket::INET(3perl) Guía de Referencia del Programador de Perl IO::Socket::INET(3perl)

NOMBRE

"IO::Socket::INET" - Interfaz de objetos para sockets del dominio AF_INET

SINOPSIS

use IO::Socket::INET;

DESCRIPCIÓN

"IO::Socket::INET" proporciona una interfaz de objetos para crear y utilizar sockets en el dominio AF_INET. Se basa en la interfaz IO::Socket y hereda todos los métodos definidos por IO::Socket.

CONSTRUCTOR

new ( [ARGUMENTOS] )
Crea un objeto "IO::Socket::INET", que es una referencia a un símbolo recién creado (ver el paquete Symbol). "new" opcionalmente toma argumentos, estos argumentos están en pares clave-valor.

Además de los pares clave-valor aceptados por IO::Socket, "IO::Socket::INET" proporciona:

PeerAddr    Dirección remota del host          <nombrehost>[:<puerto>]
PeerHost    Sinónimo de PeerAddr
PeerPort    Puerto o servicio remoto       <servicio>[(<no>)] | <no>
LocalAddr   Dirección de enlace local del host      nombrehost[:puerto]
LocalHost   Sinónimo de LocalAddr
LocalPort   Puerto de enlace local del host         <servicio>[(<no>)] | <no>
Proto       Nombre del protocolo (o número)    "tcp" | "udp" | ...
Type        Tipo de socket              SOCK_STREAM | SOCK_DGRAM | ...
Listen      Tamaño de la cola para listen
ReuseAddr   Establecer SO_REUSEADDR antes de enlazar
Reuse       Establecer SO_REUSEADDR antes de enlazar (obsoleto,
                                             preferir ReuseAddr)
ReusePort   Establecer SO_REUSEPORT antes de enlazar
Broadcast   Establecer SO_BROADCAST antes de enlazar
Timeout     Valor de tiempo de espera para varias operaciones
MultiHomed  Intentar todas las direcciones para hosts multi-homed
Blocking    Determinar si la conexión estará en modo de bloqueo

Si "Listen" está definido, entonces se crea un socket de escucha, de lo contrario, si el tipo de socket, que se deriva del protocolo, es SOCK_STREAM, se llama a connect(). Si se proporciona el argumento "Listen", pero es falso, el tamaño de la cola se establecerá en 5.

Aunque no es ilegal, el uso de "MultiHomed" en un socket que está en modo no bloqueante tiene poca utilidad. Esto se debe a que la primera conexión nunca fallará con un tiempo de espera agotado, ya que la llamada a connect no se bloqueará.

La "PeerAddr" puede ser un nombre de host o la dirección IP en formato "xx.xx.xx.xx". El "PeerPort" puede ser un número o un nombre de servicio simbólico. El nombre del servicio puede ir seguido de un número entre paréntesis que se utiliza si el servicio no es conocido por el sistema. La especificación "PeerPort" también puede incrustarse en "PeerAddr" precediéndolo con un ":".

Si no se proporciona "Proto" y se especifica un puerto simbólico "PeerPort", el constructor intentará derivar "Proto" del nombre del servicio. Como último recurso, se asume "Proto" "tcp". El parámetro "Type" se deducirá de "Proto" si no se especifica.

Si el constructor solo recibe un argumento, se asume que es una especificación de "PeerAddr".

Si "Blocking" se establece en 0, la conexión estará en modo no bloqueante. Si no se especifica, por defecto es 1 (modo de bloqueo).

Ejemplos:

$sock = IO::Socket::INET->new(PeerAddr => 'www.perl.org',
                              PeerPort => 'http(80)',
                              Proto    => 'tcp');
$sock = IO::Socket::INET->new(PeerAddr => 'localhost:smtp(25)');
$sock = IO::Socket::INET->new(Listen    => 5,
                              LocalAddr => 'localhost',
                              LocalPort => 9000,
                              Proto     => 'tcp');
$sock = IO::Socket::INET->new('127.0.0.1:25');
$sock = IO::Socket::INET->new(
                        PeerPort  => 9999,
                        PeerAddr  => inet_ntoa(INADDR_BROADCAST),
                        Proto     => 'udp',
                        LocalAddr => 'localhost',
                        Broadcast => 1 )
                    or die "No se pudo enlazar: $IO::Socket::errstr\n";

Si el constructor falla, devolverá "undef" y establecerá la variable de paquete $IO::Socket::errstr para contener un mensaje de error.

$sock = IO::Socket::INET->new(...)
    or die "No se puede crear el socket - $IO::Socket::errstr\n";

Por razones de compatibilidad, el mensaje de error también se establece en la variable global $@, y es posible que encuentres código antiguo que busque aquí en su lugar.

$sock = IO::Socket::INET->new(...)
    or die "No se puede crear el socket - $@\n";

MÉTODOS

sockaddr ()
Devuelve la parte de la dirección de la estructura sockaddr para el socket.
sockport ()
Devuelve el número de puerto que está utilizando el socket en el host local.
sockhost ()
Devuelve la parte de la dirección de la estructura sockaddr para el socket en formato de texto xx.xx.xx.xx.
peeraddr ()
Devuelve la parte de la dirección de la estructura sockaddr para el socket en el host remoto.
peerport ()
Devuelve el número de puerto para el socket en el host remoto.
peerhost ()
Devuelve la parte de la dirección de la estructura sockaddr para el socket en el host remoto en formato de texto xx.xx.xx.xx.
