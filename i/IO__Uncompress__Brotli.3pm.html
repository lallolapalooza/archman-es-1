IO::Uncompress::Brotli(3) Documentación de Perl aportada por el usuario IO::Uncompress::Brotli(3)

NOMBRE

IO::Uncompress::Brotli - Lee búferes/flujos Brotli

SINOPSIS

use IO::Uncompress::Brotli;
# descomprime un búfer (produciendo como máximo 10MB)
my $decoded = unbro $encoded, 10_000_000;
# descomprime un flujo
my $bro = IO::Uncompress::Brotli->create;
while(have_input()) {
   my $block = get_input_block();
   my $decoded_block = $bro->decompress($block);
   handle_output_block($decoded_block);
}

DESCRIPCIÓN

IO::Uncompress::Brotli es un módulo que descomprime búferes y flujos Brotli. A pesar de su nombre, no es una subclase de IO::Uncompress::Base y no implementa su interfaz. Esto se rectificará en una futura versión.

Interfaz de una sola llamada

Si tiene todo el búfer en un escalar de Perl, utilice la función unbro.

unbro($input, $maximum_decoded_size)
Toma un búfer comprimido completo como entrada y devuelve los datos descomprimidos. Asigna un búfer de tamaño $maximum_decoded_size para almacenar los datos descomprimidos; si no es suficiente (o hay otro error), esta función fallará.

A partir de la versión 0.004_002, el argumento $maximum_decoded_size es opcional. Si no se proporciona, unbro utiliza la interfaz de flujo descrita en la siguiente sección para descomprimir el búfer en bloques de un megabyte. Los bloques descomprimidos se concatenan y se devuelven.

Se exporta por defecto.

Interfaz de flujo

Si desea procesar los datos en bloques, utilice la interfaz orientada a objetos. Los métodos disponibles son:

IO::Uncompress::Brotli->create
Devuelve una instancia de IO::Uncompress::Brotli. Tenga en cuenta que una única instancia no se puede utilizar para descomprimir varios flujos.
$bro->decompress($block)
Toma un bloque de datos comprimidos y devuelve un bloque de datos sin comprimir. Fallará en caso de error.
