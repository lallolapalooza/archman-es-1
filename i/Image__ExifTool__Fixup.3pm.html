NOMBRE

Image::ExifTool::Fixup - Utilidad para manejar correcciones de punteros

SINOPSIS

use Image::ExifTool::Fixup;
$fixup = Image::ExifTool::Fixup->new;
# añade una nueva corrección a un puntero en el offset especificado en los datos
$fixup->AddFixup($offset);
# añade un nuevo objeto Fixup al árbol
$fixup->AddFixup($subFixup);
$fixup->{Start} += $shift1;   # desplaza offsets y valores de punteros
$fixup->{Shift} += $shift2;   # desplaza solo valores de punteros
# aplica recursivamente correcciones a los datos especificados
$fixup->ApplyFixups(\$data);
$fixup->Dump();               # muestra información de depuración
$fixup->IsEmpty();            # devuelve verdadero si no hay offsets que corregir

DESCRIPCIÓN

Este módulo contiene el código para llevar un registro de los punteros en memoria y para desplazar estos punteros según sea necesario. Es utilizado por ExifTool para mantener los punteros en los directorios de archivos de imagen (IFD's).

NOTAS

Lleva un registro de punteros con diferente orden de bytes y se basa en Image::ExifTool::GetByteOrder() para determinar el orden de bytes actual al añadir nuevos punteros a una corrección.

Mantiene una lista jerárquica de correcciones para que toda la jerarquía pueda ser desplazada por un simple desplazamiento en la base. La jerarquía se colapsa a una lista lineal cuando se llama a ApplyFixups().
