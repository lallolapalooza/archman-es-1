IO::Socket::SSL::PublicSuffix(3) Documentación de Perl aportada por el usuario IO::Socket::SSL::PublicSuffix(3)

NOMBRE

IO::Socket::SSL::PublicSuffix - proporciona acceso a la lista de Mozilla de nombres de TLD efectivos

SINOPSIS

   # usar el predeterminado incorporado
   use IO::Socket::SSL::PublicSuffix;
   $ps = IO::Socket::SSL::PublicSuffix->default;
   # cargar desde una cadena
   $ps = IO::Socket::SSL::PublicSuffix->from_string("*.uk\n*");
   # cargar desde un archivo o manejador de archivo
   $ps = IO::Socket::SSL::PublicSuffix->from_file($nombre_archivo);
   $ps = IO::Socket::SSL::PublicSuffix->from_file(\*STDIN);
   # --- cadena de entrada -> cadena de salida
   # $resto -> whatever.host
   # $tld  -> co.uk
   my ($resto,$tld) = $ps->public_suffix('whatever.host.co.uk');
   my $tld = $ps->public_suffix('whatever.host.co.uk');
   # $dominio_raiz -> host.co.uk
   my $dominio_raiz = $ps->public_suffix('whatever.host.co.uk', 1);
   # --- array de entrada -> array de salida
   # $resto -> [qw(whatever host)]
   # $tld  -> [qw(co uk)]
   my ($resto,$tld) = $ps->public_suffix([qw(whatever host co uk)]);

DESCRIPCIÓN

Este módulo utiliza la lista de nombres de dominio de nivel superior efectivos del proyecto mozilla para determinar el dominio de nivel superior público de un nombre de host dado.

Método

clase->default(%args)
Devuelve un objeto con el predeterminado incorporado. Se puede especificar "min_suffix" en %args para especificar el sufijo mínimo, el valor predeterminado es 1.
clase->from_string(cadena,%args)
Devuelve un objeto con la configuración de una cadena. Consulte el método "default" para %args.
clase->from_file( nombre_archivo | manejador_archivo, %args )
Devuelve un objeto con la configuración de un archivo o manejador de archivo. Consulte el método "default" para %args.
$self->public_suffix( $host|\@host, [ $add ] )
En contexto de array, la función devuelve la parte no-TLD y la parte TLD del nombre de host dado, en contexto escalar solo la parte TLD. Añade $add partes de la parte no-TLD a la TLD, por ejemplo, con "$add=1" devolverá el dominio raíz.

Si no hubo coincidencias explícitas contra la configuración del sufijo público, recurrirá a un sufijo de longitud 1.

La función acepta una cadena o una referencia a un array (por ejemplo, host dividido por "."). En el primer caso devolverá cadenas, en el último caso referencias a arrays.

Los nombres de host o etiquetas internacionales pueden estar en ASCII (forma IDNA comenzando con "xn--") o unicode. En este último caso, debe estar disponible una biblioteca de manejo de IDNA. Se prefiere URI, pero Net::IDN::Encode, Net::LibIDN todavía son compatibles.

($self|clase)->can_idn
Devuelve verdadero si el soporte IDN está disponible.

VER TAMBIÉN

Domain::PublicSuffix, Mozilla::PublicSuffix

ERRORES

P: ¿Por qué otro módulo más, si ya tenemos L<Domain::PublicSuffix> y
   L<Mozilla::PublicSuffix>?
R: Porque los datos del sufijo público cambian con más frecuencia que estos
   módulos, IO::Socket::SSL necesita esta lista y es más fácil mantenerla
   actualizada de esta manera.
