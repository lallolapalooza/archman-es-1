FUNCIONE

S

Las siguientes funciones se exportarán bajo

demanda.

capture(

) 
capture \&subroutine, \$stdout,
\$stderr;

Captura todo lo que se imprime en "STDOUT" y "STDERR" durante la ejecución de &subroutine. $stdout y $stderr son escalares opcionales que contendrán "STDOUT" y "STDERR" respectivamente

.

capture() usa un prototipo de código, por lo que el primer argumento puede especificarse directamente entre corchetes si se

desea. 
# abreviatura con prototipo
capture C< print __PACKAGE__ > \$stdout,
\$stderr;

Devuelve el(los) valor(es) de retorno de &subroutine. La subrutina se llama en el mismo contexto en que se llamó a capture(), por

ejemplo: 
@rv = capture C< wantarray > ; # devuelve true
$rv = capture C< wantarray > ; # devuelve definido, pero no true
capture C< wantarray >;       # vacío, devuelve
undef

capture() es capaz de capturar la salida de subprocesos y código C, lo que los métodos tradicionales de tie() de captura de salida no pueden

hacer.

Nota: capture() solo capturará la salida que haya sido escrita o vaciada (flush) al manejador de

archivos.

Si las dos referencias a escalares apuntan al mismo escalar, entonces "STDERR" se fusionará con "STDOUT" antes de capturar y el escalar contendrá la salida combinada de

ambos. 
capture \&subroutine, \$combined,
\$combined;

Normalmente, capture() usa archivos anónimos y temporales para capturar la salida. Si se desea, se pueden proporcionar nombres de archivo específicos como opciones

adicionales. 
capture \&subroutine, \$stdout, \$stderr, $out_file,
$err_file;

Los archivos proporcionados serán sobrescritos, reemplazando cualquier dato anterior, pero persistirán después de la llamada a capture() para su inspección u otra

manipulación.

De forma predeterminada, cuando no se proporcionan referencias para retener STDOUT o STDERR, la salida se captura y se descarta silenciosamente

. 
# Capturar STDOUT, descartar STDERR
capture \&subroutine, \$stdout;
# Descartar STDOUT, capturar STDERR
capture \&subroutine, undef,
\$stderr;

Sin embargo, incluso cuando se usa "undef", la salida puede capturarse en archivos

específicos. 
# Capturar STDOUT en un archivo específico, descartar STDERR
capture \&subroutine, \$stdout, undef, $outfile;
# Descartar STDOUT, capturar STDERR en un archivo específico
capture \&subroutine, undef, \$stderr, undef, $err_file;
# Descartar ambos, capturar la salida fusionada en un archivo específico
capture \&subroutine, undef, undef,
$mergedfile;

Es un error fatal fusionar STDOUT y STDERR y solicitar archivos específicos y separados para la

captura. 
# ERROR:
capture \&subroutine, \$stdout, \$stdout, $out_file, $err_file;
capture \&subroutine, undef, undef, $out_file,
$err_file;

Si STDOUT o STDERR deben pasar a la terminal en lugar de capturarse, proporcione una referencia a undef -- "\undef" -- en lugar de una variable de

captura. 
# Capturar STDOUT, mostrar STDERR
capture \&subro
utine, \$stdout, \undef; # Mostrar STDOUT, captur
ar STDERR capture \&subroutine, \undef, \$stderr;

capture_exec(

) 
($stdout, $stderr, $success, $exit_code) = capture_exec(@args)
;

Captura y devuelve la salida de system(@args). En contexto escalar, capture_exec() devolverá lo que se imprimió en "STDOUT". En contexto de lista, devuelve lo que se imprimió en "STDOUT" y "STDERR", así como un indicador de éxito y el valor de

salida. 
$stdout = capture_exec('perl', '-e', 'print "hello world"');
($stdout, $stderr, $success, $exit_code) =
    capture_exec('perl', '-e', 'warn "Test"')
;

"capture_exec" pasa sus argumentos a system() y en MSWin32 protegerá los argumentos con comillas de shell si es necesario. Esto lo convierte en una alternativa práctica y ligeramente más portable a las comillas invertidas, la apertura con open() con tubería y "IPC::Ope

n3".

El indicador $success devuelto será verdadero si el comando se ejecutó correctamente y falso si no lo hizo (si el comando no pudo ejecutarse o si se ejecutó y devolvió un valor de salida distinto de cero). En caso de fallo, el valor de salida sin procesar de la llamada a system() está disponible tanto en el $exit_code devuelto como en la variable $?

. 
($stdout, $stderr, $success, $exit_code) =
    capture_exec('perl', '-e', 'warn "Test" and exit 1');
if ( ! $success ) {
    print "The exit code was " . ($exit_code >> 8) . "\n";
}
