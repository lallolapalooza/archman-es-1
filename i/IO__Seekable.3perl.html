IO::Seekable(3perl) Guía del programador de Perl IO::Seekable(3perl)

NOMBRE

IO::Seekable - proporciona métodos de búsqueda para objetos de E/S

SINOPSIS

use IO::Seekable;
package IO::Something;
@ISA = qw(IO::Seekable);

DESCRIPCIÓN

"IO::Seekable" no tiene un constructor propio, ya que está diseñado para ser heredado por otros objetos basados en "IO::Handle". Proporciona métodos que permiten buscar en los descriptores de archivo.

$io->getpos
Devuelve un valor opaco que representa la posición actual del IO::File, o "undef" si no es posible (por ejemplo, un flujo no buscable como una terminal, tubería o socket). Si la función fgetpos() está disponible en tu biblioteca C, se utiliza para implementar getpos; de lo contrario, perl emula getpos utilizando la función ftell() de C.
$io->setpos
Utiliza el valor de una llamada getpos anterior para regresar a una posición visitada previamente. Devuelve "0 pero verdadero" en caso de éxito, "undef" en caso de fallo.

Consulta perlfunc para obtener descripciones completas de cada uno de los siguientes métodos admitidos de "IO::Seekable", que son simplemente interfaces para las funciones incorporadas correspondientes:

$io->seek ( POS, WHENCE )
Busca el IO::File en la posición POS, relativa a WHENCE:
WHENCE=0 (SEEK_SET)
POS es la posición absoluta. (Busca relativo al inicio del archivo)
WHENCE=1 (SEEK_CUR)
POS es un desplazamiento desde la posición actual. (Busca relativo a la actual)
WHENCE=2 (SEEK_END)
POS es un desplazamiento desde el final del archivo. (Busca relativo al final)

Las constantes SEEK_* se pueden importar del módulo "Fcntl" si no deseas usar los números 0 1 o 2 en tu código.

Devuelve 1 en caso de éxito, 0 en caso contrario.

$io->sysseek( POS, WHENCE )
Similar a $io->seek, pero establece la posición del IO::File utilizando directamente la llamada al sistema lseek(2), por lo que confundirá la mayoría de los operadores de E/S de perl, excepto sysread y syswrite (ver perlfunc para detalles completos).

Devuelve la nueva posición, o "undef" en caso de fallo. Una posición de cero se devuelve como la cadena "0 pero verdadero"

$io->tell
Devuelve la posición actual del IO::File, o -1 en caso de error.
