NOMBRE

Image::ExifTool::Import - Importar archivos de base de datos CSV y JSON

SINOPSIS

use Image::ExifTool::Import qw(ReadCSV ReadJSON);
$err = ReadCSV($archivo_csv, \%base_de_datos);
$err = ReadJSON($archivo_json, \%base_de_datos);

DESCRIPCIÓN

Este módulo contiene rutinas para importar información de etiquetas desde archivos de base de datos CSV (Valor Separado por Comas) y JSON (Notación de Objeto de JavaScript).

EXPORTACIONES

No exporta nada por defecto, pero ReadCSV y ReadJSON pueden ser exportados.

MÉTODOS

ReadCSV / ReadJSON

Lee un archivo CSV o JSON en una base de datos hash.

Entradas:
0) Nombre del archivo CSV o referencia al archivo.

1) Referencia hash para el objeto de base de datos.

2) Cadena opcional utilizada para representar un valor de etiqueta indefinido (faltante). (Se utiliza para eliminar etiquetas.)

3) Para ReadCSV, esto proporciona el delimitador para las entradas CSV, con un valor predeterminado de ",". Para ReadJSON, este es el conjunto de caracteres para convertir secuencias de escape Unicode en cadenas, con un valor predeterminado de "UTF8". Consulte la opción Charset de ExifTool para obtener una lista de conjuntos de caracteres válidos.

Valor de Retorno:
Estas funciones devuelven una cadena de error, o undef en caso de éxito y poblan el hash de la base de datos con entradas del archivo CSV o JSON. Las entradas se indexan basándose en la columna SourceFile de la información CSV o JSON, y se almacenan como búsquedas hash de nombre/valor de etiqueta para cada SourceFile. El orden de las claves (orden de las columnas CSV o orden en un objeto JSON) se almacena como una referencia ARRAY en un elemento especial "_ordered_keys_" de este hash.
