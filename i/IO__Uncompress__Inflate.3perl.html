DESCRIPCIÓN

Este módulo proporciona una interfaz de Perl que permite la lectura de archivos/buffers que se ajustan al RFC 1950.

Para escribir archivos/buffers RFC 1950, consulta el módulo complementario IO::Compress::Deflate.

Interfaz Funcional

Se proporciona una función de nivel superior, "inflate", para realizar la descompresión "de un solo golpe" entre buffers y/o archivos. Para un control más fino sobre el proceso de descompresión, consulta la sección "Interfaz OO".

use IO::Uncompress::Inflate qw(inflate $InflateError) ;
inflate $input_filename_or_reference => $output_filename_or_reference [,OPTS]
    or die "La descompresión falló: $InflateError\n";

La interfaz funcional requiere Perl5.005 o superior.

inflate $nombre_de_archivo_o_referencia_de_entrada => $nombre_de_archivo_o_referencia_de_salida [, OPTS]

"inflate" espera al menos dos parámetros, $nombre_de_archivo_o_referencia_de_entrada y $nombre_de_archivo_o_referencia_de_salida y cero o más parámetros opcionales (ver "Parámetros Opcionales")

El parámetro $nombre_de_archivo_o_referencia_de_entrada

El parámetro, $nombre_de_archivo_o_referencia_de_entrada, se utiliza para definir la fuente de los datos comprimidos.

Puede tomar una de las siguientes formas:

Un nombre de archivo
Si el parámetro $nombre_de_archivo_o_referencia_de_entrada es un escalar simple, se asume que es un nombre de archivo. Este archivo se abrirá para lectura y los datos de entrada se leerán de él.
Un manejador de archivo
Si el parámetro $nombre_de_archivo_o_referencia_de_entrada es un manejador de archivo, los datos de entrada se leerán de él. La cadena '-' se puede usar como alias para la entrada estándar.
Una referencia escalar
Si $nombre_de_archivo_o_referencia_de_entrada es una referencia escalar, los datos de entrada se leerán de $$nombre_de_archivo_o_referencia_de_entrada.
Una referencia de array
Si $nombre_de_archivo_o_referencia_de_entrada es una referencia de array, cada elemento del array debe ser un nombre de archivo.

Los datos de entrada se leerán de cada archivo en orden.

Se recorrerá todo el array para asegurar que solo contenga nombres de archivo válidos antes de descomprimir cualquier dato.

Una cadena FileGlob de entrada
Si $nombre_de_archivo_o_referencia_de_entrada es una cadena delimitada por los caracteres "<" y ">" "inflate" asumirá que es una cadena fileglob de entrada. La entrada es la lista de archivos que coinciden con el fileglob.

Consulta File::GlobMapper para más detalles.

Si el parámetro $nombre_de_archivo_o_referencia_de_entrada es de otro tipo, se devolverá "undef".

El parámetro $nombre_de_archivo_o_referencia_de_salida

El parámetro $nombre_de_archivo_o_referencia_de_salida se utiliza para controlar el destino de los datos descomprimidos. Este parámetro puede tomar una de estas formas.

Un nombre de archivo
Si el parámetro $nombre_de_archivo_o_referencia_de_salida es un escalar simple, se asume que es un nombre de archivo. Este archivo se abrirá para escritura y los datos descomprimidos se escribirán en él.
Un manejador de archivo
Si el parámetro $nombre_de_archivo_o_referencia_de_salida es un manejador de archivo, los datos descomprimidos se escribirán en él. La cadena '-' se puede usar como alias para la salida estándar.
Una referencia escalar
Si $nombre_de_archivo_o_referencia_de_salida es una referencia escalar, los datos descomprimidos se almacenarán en $$nombre_de_archivo_o_referencia_de_salida.
Una Referencia de Array
Si $nombre_de_archivo_o_referencia_de_salida es una referencia de array, los datos descomprimidos se añadirán al final del array.
Un FileGlob de salida
Si $nombre_de_archivo_o_referencia_de_salida es una cadena delimitada por los caracteres "<" y ">" "inflate" asumirá que es una cadena fileglob de salida. La salida es la lista de archivos que coinciden con el fileglob.

Cuando $nombre_de_archivo_o_referencia_de_salida es una cadena fileglob, $nombre_de_archivo_o_referencia_de_entrada también debe ser una cadena fileglob. Cualquier otra cosa es un error.

Consulta File::GlobMapper para más detalles.

Si el parámetro $nombre_de_archivo_o_referencia_de_salida es de otro tipo, se devolverá "undef".

Notas

Cuando $nombre_de_archivo_o_referencia_de_entrada se mapea a múltiples archivos/buffers comprimidos y $nombre_de_archivo_o_referencia_de_salida es un único archivo/buffer, después de la descompresión $nombre_de_archivo_o_referencia_de_salida contendrá una concatenación de todos los datos descomprimidos de cada uno de los archivos/buffers de entrada.

Parámetros Opcionales

Los parámetros opcionales para la función de un solo golpe "inflate" son (en su mayor parte) idénticos a los utilizados con la interfaz OO definida en la sección "Opciones del Constructor". Las excepciones se enumeran a continuación

"AutoClose => 0|1"
Esta opción se aplica a cualquier flujo de datos de entrada o salida para "inflate" que sean manejadores de archivo.

Si se especifica "AutoClose" y el valor es verdadero, todos los manejadores de archivo de entrada y/o salida se cerrarán una vez que "inflate" haya completado.

Este parámetro tiene un valor predeterminado de 0.

"BinModeOut => 0|1"
Esta opción ahora es un no-operativo. Todos los archivos se escribirán en modo binario.
"Append => 0|1"
El comportamiento de esta opción depende del tipo de flujo de datos de salida.
  • Un Buffer

    Si "Append" está habilitado, todos los datos descomprimidos se añadirán al final del buffer de salida. De lo contrario, el buffer de salida se borrará antes de que se escriban datos descomprimidos en él.

    Si "Append" está habilitado, el archivo se abrirá en modo de adición. De lo contrario, el contenido del archivo, si lo hay, se truncará antes de que cualquier dato descomprimido.
