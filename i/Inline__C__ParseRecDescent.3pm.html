NOMBRE

Inline::C::ParseRecDescent - El Analizador Clásico de Inline::C

SINOPSIS

use Inline C => DATA =>
           USING => ParseRecDescent;

DESCRIPCIÓN

Este módulo es el analizador original de Inline::C basado en Parse::RecDescent. Anteriormente estaba empaquetado como Inline::C::grammar.

Prueba Inline::C::ParseRegExp para una alternativa.
