Image::Info::WBMP(3) Documentación de Perl contribuida por el usuario Image::Info::WBMP(3)

NOMBRE

Image::Info::WBMP - Soporte WBMP para Image::Info

SINOPSIS

use Image::Info qw(dim);
use Image::Info::WBMP qw(wbmp_image_info);
my $info = wbmp_image_info("image.xpm");
if (my $error = $info->{error}) {
    die "No se pueden analizar los datos de la imagen: $error\n";
}
my($w, $h) = dim($info);

DESCRIPCIÓN

wbmp es un formato de archivo sin "magia", por lo que usar "image_info" o "image_type" de Image::Info no funciona aquí. En su lugar, el usuario debe determinar el tipo de archivo por sí mismo, por ejemplo, basándose en la extensión del archivo o el tipo MIME, y usar la función "wbmp_image_info" en su lugar. El valor devuelto se parece al de "image_info" de Image::Info y puede ser utilizado en una llamada a la función "dim".
