NOMBRE

I18N::Collate - compara datos escalares de 8 bits según la configuración regional actual

SINOPSIS

use I18N::Collate;
setlocale(LC_COLLATE, 'locale-de-tu-eleccion');
$s1 = I18N::Collate->new("datos_escalares_1");
$s2 = I18N::Collate->new("datos_escalares_2");

DESCRIPCION

***

la interfaz I18N::Collate para comparar datos escalares de 8 bits
según la configuración regional actual
      HA SIDO DECLARADA OBSOLETA
Es decir, no la utilices más para ninguna aplicación nueva
y migra las aplicaciones antiguas de ella porque su
funcionalidad fue integrada en el lenguaje Perl central en

Consulta la página del manual perllocale para obtener más información.

Este módulo te proporciona objetos que ordenarán según tu juego de caracteres nacional, siempre que la función setlocale() de POSIX sea compatible en tu sistema.

Puedes comparar $s1 y $s2 arriba con

$s1 le $s2

para extraer los datos en sí, necesitarás una desreferenciación: $$s1

Este módulo utiliza POSIX::setlocale(). La conversión básica de ordenación se realiza mediante strxfrm(), que termina en caracteres NUL, siendo una rutina C decente. collate_xfrm() maneja caracteres NUL incrustados de forma elegante.

Las configuraciones regionales disponibles dependen de tu sistema operativo; prueba si "locale -a" las muestra o consulta las páginas del manual para "locale" o "nlsinfo" o el enfoque directo "ls /usr/lib/nls/loc" o "ls /usr/lib/nls" o "ls /usr/lib/locale". No todas las configuraciones regionales que tu proveedor soporta están necesariamente instaladas: consulta la documentación de tu sistema operativo y posiblemente la administración de tu sistema local. Los nombres de las configuraciones regionales probablemente sean algo como "xx_XX.(ISO)?8859-N" o "xx_XX.(ISO)?8859N", por ejemplo "fr_CH.ISO8859-1" es la variante suiza (CH) del francés (fr), ISO Latin (8859) 1 (-1) que es el juego de caracteres de Europa Occidental.
