NOMBRE

Image::ExifTool::BuildTagLookup - Construye tablas de búsqueda de etiquetas de ExifTool

DESCRIPCIÓN

Este módulo se utiliza para generar las tablas de búsqueda de etiquetas en Image::ExifTool::TagLookup.pm y la documentación de nombres de etiquetas en Image::ExifTool::TagNames.pod, así como la documentación de nombres de etiquetas HTML. Se utiliza antes de cada nueva versión de ExifTool para actualizar las tablas de búsqueda y la documentación, pero no se utiliza de otra manera. También realiza algunas validaciones y comprobaciones de coherencia en las tablas de etiquetas.

SINOPSIS

use Image::ExifTool::BuildTagLookup;
$builder = Image::ExifTool::BuildTagLookup->new;
# actualizar Image::ExifTool::TagLookup
$ok = $builder->WriteTagLookup('lib/Image/ExifTool/TagLookup.pm');
# actualizar la documentación de nombres de etiquetas
$ok = $builder->WriteTagNames('lib/Image/ExifTool/TagNames.pod','html');
# imprimir algunas estadísticas
my $count = $$builder{COUNT};
foreach (sort keys %$count) {
    printf "%5d %s\n", $$count{$_}, $_;
}

VARIABLES MIEMBRO

PRESERVE_DATE
Bandera para preservar la fecha de "Última revisión" en los archivos HTML. Se establece antes de llamar a WriteTagNames().
COUNT
Referencia a un hash que contiene estadísticas de conteo. Las claves son las descripciones y los valores son los recuentos numéricos. Válido después de que se crea el objeto BuildTagLookup, pero se agregan estadísticas adicionales mediante WriteTagNames().
WRITE_PSEUDO
Lista devuelta de etiquetas pseudo escribibles.
