NOMBRE

I18N::LangTags::List -- etiquetas y nombres para lenguas humanas

SINOPSIS

use I18N::LangTags::List;
print "Parlez-vous... ", join(', ',
    I18N::LangTags::List::name('elx') || 'unknown_language',
    I18N::LangTags::List::name('ar-Kw') || 'unknown_language',
    I18N::LangTags::List::name('en') || 'unknown_language',
    I18N::LangTags::List::name('en-CA') || 'unknown_language',
  ), "?\n";

imprime:

Parlez-vous... Elamite, Kuwait Arabic, English, Canadian English?

DESCRIPCIÓN

Este módulo proporciona una función I18N::LangTags::List::name( etiqueta_idioma ) que toma una etiqueta de idioma (ver I18N::LangTags) y devuelve el mejor intento de un nombre en inglés para ella, o undef si no puede entender la etiqueta.

La función I18N::LangTags::List::name(...) no se exporta.

Este módulo también proporciona una función I18N::LangTags::List::is_decent( etiqueta_idioma ) que devuelve verdadero si y solo si la etiqueta de idioma es sintácticamente válida y es para uso general (como "fr" o "fr-ca", abajo). Es decir, devuelve falso para etiquetas que son sintácticamente inválidas y para etiquetas, como "aus", que están entre corchetes abajo. Esta función no se exporta.

El mapa de etiquetas a nombres que utiliza es accesible como %I18N::LangTags::List::Name, y es el mismo que la lista que sigue en esta documentación, que debería serle útil incluso si no usa este módulo.

SOBRE ETIQUETAS DE IDIOMAS

Las etiquetas de idioma de Internet, como se definen en RFC 3066, son un formalismo para denotar lenguas humanas. Los códigos de idioma ISO 639-1 de dos letras son bien conocidos (como "en" para inglés), al igual que sus formas cuando se califican con un código de país ("en-US"). Menos conocidos son los códigos arbitrarios de longitud no ISO (como "i-mingo"), y los recientemente (en 2001) introducidos códigos ISO-639-2 de tres letras.

Recuerde estos hechos importantes:

  • Las etiquetas de idioma no son identificadores de configuración regional (locale). Un identificador de configuración regional se escribe con un "_" en lugar de un "-", (casi?) siempre coincide con "m/^\w\w_\w\w\b/", y significa algo diferente a una etiqueta de idioma. Una etiqueta de idioma denota un idioma. Un identificador de configuración regional denota un idioma tal como se usa en un lugar particular, en combinación con información específica de la ubicación no lingüística tal como la moneda que se usa allí. Las configuraciones regionales también a menudo denotan información del conjunto de caracteres, como en "en_US.ISO8859-1".
  • Las etiquetas de idioma no son para lenguajes de programación.
  • "Dialecto" no es un término útil, ya que no existe un criterio objetivo para establecer cuándo dos formas de lenguaje son dialectos entre sí, o son idiomas separados.
  • Las etiquetas de idioma no distinguen entre mayúsculas y minúsculas. en-US, en-us, En-Us, etc., son todas la misma etiqueta, y denotan el mismo idioma.
  • No todas las etiquetas de idioma se refieren realmente a un solo idioma. Algunas etiquetas de idioma se refieren a condiciones: i-default (texto de mensajes del sistema en inglés más quizás otros idiomas), und (idioma no determinado). Otras (notablemente muchos de los códigos de tres letras) son etiquetas bibliográficas que clasifican grupos enteros de lenguas, como con cus "Cushitic (Otro)" (es decir, un idioma que ha sido clasificado como cushita, pero que no tiene un código más específico) o el aún menos coherente lingüísticamente sai para "Indígena Sudamericano (Otro)". Aunque útiles en bibliografía, DICHAS ETIQUETAS NO SON PARA USO GENERAL. Para más orientación, envíeme un correo electrónico.
  • Las etiquetas de idioma no son códigos de país. De hecho, a menudo son códigos distintos, como con la etiqueta de idioma ja para japonés, y el código de país ISO 3166 ".jp" para Japón.
