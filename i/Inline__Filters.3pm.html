Inline::Filters - Filtros

de código fuente comunes
para los Módulos Inline.

DESCRIPCIÓ

N

"Inline::Filters" proporciona filtros de código fuente comunes a los Módulos de Lenguaje Inline. A

menos que seas un desarrollador de módulos Inli
ne, puedes simplemente leer la siguiente sección.

Filtros

Soportados

Esta sección describe cada filtro en Inline::

Filters.

Strip_PO

D

Elimina el POD incrustado de un bloque de código en cualquier lenguaje. Esto está implementado como una expresión

regular: 
$code =~ s/^=\w+[^\n]*\n\n(.*?)(^=cut\n\n|\Z)
//gsm;

Eso significa que si tienes un lenguaje que contiene una sintaxis similar a POD, será eliminado por este filtro (es decir, no uses este filtro con dicho lenguaje). Este filtro es útil para hacer que código como este

compile: 
use Inline C => <<'END', FILTERS => 'Strip_POD'
; =head1 add Devuelve la suma de dos enteros. =
cut int add(int x, int y) { return x + y; } END

Strip

Comments

Elimina los comentarios de un bloque de código en el lenguaje que estés usando. El eliminador de comentarios es seguro con cadenas (strings) -- es decir, no eliminará comentarios incrustados en

cadenas.

La característica es útil porque tanto la gramática de C como la de C++ no pueden manejar comentarios en puntos arbitrarios del código fuente; hacerlo inflaría la gramática. En su lugar, el código como este debería tener sus comentarios eliminados antes del

análisis: 
use Inline C => <<'END', FILTERS => 'Strip_Comments';
int md5_block(char *block,   /* el bloque sobre el que operar */
              long length,   /* el número de bytes */
              char **result) /* la suma resultante de 128 bits */
{
     /* algún código aquí */
}
END

Strip_Comments está disponible para los siguientes

lenguajes:
Strip_C_Comme
nts
Strip_CPP_Comme
nts
Strip_Python_Comme
nts
Strip_TCL_Comme
nts
Java a través de Strip_CPP_Comme
nts

Los filtros de Python y Java están disponibles solo por conveniencia. Hay poca neces

idad de ellos, ya que Inline::Python y Inline::Java usan los compiladores oficiales
del lenguaje para analizar el código, y estos compiladores conocen los comentarios.

Preproces

s

Ahora disponible para todos los lenguajes. Usa el preprocesador de C ($Config{cpprun}) para preprocesar un bloque de código. Esto es útil si quieres expandir macros y código condicional antes del análisis. Por

ejemplo: 
use Inline CPP => <<'END', FILTERS => 'Preprocess';
class Foo
#ifdef FOO_INHERITS_BAR
   : public Bar
#endif
{
};
END

El código mostrado anteriormente no se analizará correctamente sin el filtro Preprocess, ya que la gramática de Inline::CPP no puede entender las directivas del

preprocesador.

Argumento

CPPFLAGS

También está disponible el argumento CPPFLAGS, para especificar directivas del preprocesador de

C. 
use Inline C => <<'END' => CPPFLAGS => ' -DPREPROCESSOR_DEFINE' => FILTERS => 'Preprocess';
#ifdef PREPROCESSOR_DEFINE
int foo() { return 4321; }
#else
int foo() { return -1; }
#endif
END

El código mostrado anteriormente devolverá 4321 cuando foo() sea

llamado.

Argumento CLEAN_AFTER_BUIL

D

Por defecto, el filtro Preprocess elimina todos los archivos Filters*.c que crea. Si estableces la bandera CLEAN_AFTER_BUILD a falso, entonces los archivos "Filters*.c" no serán eliminados; esto es necesario cuando se usa "gdb" para depurar programas de Inline::C e Inline::CPP que utilizan el filtro

Preprocess.

Si no estableces la bandera CLEAN_AFTER_BUILD a falso, probablemente terminarás con un error de "No such file or directory" en

gdb: 
use Inline C => <<'END' => FILTERS => 'Preprocess';
// tu código aquí
END

$ gdb /usr/bin/perl (gdb) run ./my_script.pl arg0 arg1 ... Thread 1 "perl" received signal SIGSEGV, Segmentation fault. MyPackage::my_method (this=this@entry=0x1234567, my_arg=my_arg@entry=23)
at /.../_Inline/build/eval_XXX_YYYY/FiltersZZZZ.c:42 42 /.../_Inline/build/eval_XXX_YYYY/FiltersZZZZ.c: No such file or

directory.

Si estableces la bandera CLEAN_AFTER_BUILD a falso, deberías ver el código C o C++ ofensivo real en

gdb: 
use Inline C => <<'END' => CLEAN_AFTER_BUILD => 0 => FILTERS => 'Preprocess';
// tu código aquí
END

$ gdb /usr/bin/perl (gdb) run ./my_script.pl arg0 arg1 ... Thread 1 "perl" received signal SIGSEGV, Segmentation fault. MyPackage::my_method (this=this@entry=0x1234567, my_arg=my_arg@entry=23)

DETALLE

S

Filtros

Incorporados

Los filtros de código fuente incorporados están implementados como una referencia bendecida a un hash que contiene dos elementos: 'filter' es el nombre del filtro, y 'coderef' es una referencia de código al filtro apropiado. El objeto tiene un método filter(), el cual debe ser llamado con el objeto ILSM como primer parámetro, y el

código fuente como segundo parámetro. Los f
iltros siempre devuelven el código filtrado.

Filtros Proporcionados por el

Usuario

A partir de Inline 0.42, puedes proporcionar tus propios filtros a Inline pasando una referencia de código a la opción FILTERS,

así: 
sub my_filter { };
use Inline C => DATA => FILTERS => [\&my_filter]
;

A la subrutina del filtro se le pasa un argumento: el código sin filtrar. Debe devolver el código filtrado como su único valor de retorno. Si algo sale mal y necesitas informar al usuario, simplemente usa

croak.

Nota: en algunas circunstancias, tú debes poner tu subrutina de filtro arriba de la declaración "use Inline". Cuando es posible, Inline compila tu código en tiempo de compilación, lo que significa que la subrutina debe estar definida. Si estás leyend

o código del manejador de archivos 'DATA', puedes poner el filtro en cualquier lug
ar de tu script, ya que Inline retrasa la compilación hasta el tiempo de ejecución.

Aplicando

Filtros

"Inline" proporciona un método filter() el cual aplica los filtros solicitados uno tras otro sobre el código fuente. Todos los ILSM deberían guardar el resultado de $o->filter() y considerarlo el código fuente. Si no se han solicitado

filtros, esto simplemente devuel
ve el código fuente sin filtrar.

ERRORES O

OMISIONES

Puedes pasar referencias de subrutina arbitrarias como filtros. Sin embargo, si te encuentras usando un filtro regularmente y te gustaría verlo incluido en Inline::Filters, por favor presenta un reporte de

error.

Si deseas reportar un error, por favor consulta Inline para obtener instrucciones sobre cómo presentar un reporte de

error.
