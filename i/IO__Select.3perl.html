DESCRIPCIÓ

N

El paquete "IO::Select" implementa un enfoque orientado a objetos para la llamada a la función "select" del sistema. Permite al usuario ver qué manejadores de E/S (ver IO:

:Handle) están listos para leer, escrib
ir o tienen una excepción pendiente.

add ( MANEJADORES
)
Añade la lista de manejadores al objeto "IO::Select". Son estos valores los que se devolverán cuando ocurra un evento. "IO::Select" guarda estos valores en una caché indexada por el "fileno" del manejador, por lo que si se especifica más de un manejador con el mismo "fileno", solo se guardará en la caché el último.

Cada manejador puede ser un objeto "IO::Handle", un entero o una referencia a un array donde el primer elemento sea un "IO::Handle"

o un e
ntero.

)
Elimina todos los manejadores dados del objeto. Este método también funciona por el "fileno" de los manejadores. Por lo tanto, no es necesario pasar los manejadores exactos que se añadieron, sino solo manejadores que tengan un "fileno"
equivalente.

contrario.

can_read ( [ TIEMPO_LÍMITE ]
)
Devuelve un array de manejadores que están listos para la lectura. "TIEMPO_LÍMITE" es la cantidad máxima de tiempo a esperar antes de devolver una lista vacía (con $! sin cambios), en segundos, posiblemente fraccionario. Si "TIEMPO_LÍMITE" no se proporciona y hay manejadores registrados, la llamada se bloqueará indefinidamente. En caso de error, se devuelve una lista vacía, con $! establecido para indicar el error. Para distinguir entre un tiempo de espera agotado y un error, establezca $! a cero antes de llamar a este método, y compruébelo después de que se devuelva una lista
vacía.

select ( LECTURA, ESCRITURA, EXCEPCIÓN [, TIEMPO_LÍMITE
] )
"select" es un método estático, es decir, se llama con el nombre del paquete como "new". "LECTURA", "ESCRITURA" y "EXCEPCIÓN" son o bien "undef" u objetos "IO::Select". "TIEMPO_LÍMITE" es opcional y tiene el mismo efecto que en la llamada select principal.

Si al menos un manejador está listo para el tipo de operación especificado, el resultado será un array de 3 elementos, cada uno una referencia a un array que contendrá los manejadores que están listos para leer, escribir y tienen excepciones, respectivamente. En caso de agotarse el tiempo de espera, se devuelve una lista vacía, con $! sin cambios. En caso de error, se devuelve una lista vacía, con $! establecido para indicar el error. EJEMPL

O

Aquí hay un breve ejemplo que muestra cómo se podría usar "IO::Select" para escribir un servidor que se comunica con varios sockets mientras también escucha más conexiones en un socket de

escucha. 
use IO::Select;
use IO::Socket;
my $lsn = IO::Socket::INET->new(Listen => 1, LocalPort => 8080);
my $sel = IO::Select->new( $lsn );
while(my @ready = $sel->can_read) {
    foreach my $fh (@ready) {
        if($fh == $lsn) {
            # Create a new socket
            my $new = $lsn->accept;
            $sel->add($new);
        }
        else {
            # Process socket
            # Maybe we have finished with the socket
            $sel->remove($fh);
            $fh->close;
        }
    }
}
