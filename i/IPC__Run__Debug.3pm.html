Paquete: perl-ipc-run

Licencias: GPL, PerlArtistic

IPC::Run::Debug(3) Documentación de Perl aportada por el usuario IPC::Run::Debug(3)

NOMBRE

IPC::Run::Debug - rutinas de depuración para IPC::Run

SINOPSIS

##
## Uso de variables de entorno
##
## Para forzar la desactivación de la depuración y ahorrar un poco de CPU y memoria
## optimizando en tiempo de compilación todo el código de depuración en IPC::Run
## (las opciones debug => ...) de IPC::Run serán ignoradas.
export IPCRUNDEBUG=none
## Para forzar la activación de la depuración (los niveles son de 0 a 10)
export IPCRUNDEBUG=basic
## Dejar sin definir o establecer a "" para compilar el soporte de depuración y
## permitir el control en tiempo de ejecución utilizando la opción debug.

DESCRIPCIÓN

Controla la depuración de IPC::Run. Los niveles de depuración ahora se establecen usando palabras, pero los números mostrados todavía se admiten por compatibilidad con versiones anteriores:

0  none         desactivado (especial, ver abajo)
1  basic        lo que se está ejecutando
2  data         lo que se está enviando/recibiendo
3  details      lo que está sucediendo con más detalle
4  gory         demasiado detalle para la mayoría de los usos
10 all          usa esto al enviar informes de errores
   noopts       optimizaciones prohibidas debido a STDIN heredado

El nivel "none" es especial cuando la variable de entorno IPCRUNDEBUG se establece en este valor la primera vez que se carga IPC::Run::Debug: evita que el código de depuración se compile en los módulos restantes de IPC::Run, ahorrando un poco de cpu.

Para hacer esto en un script, aquí hay una forma que permite que sea anulado:

BEGIN {
   unless ( defined $ENV{IPCRUNDEBUG} ) {
      eval 'local $ENV{IPCRUNDEBUG} = "none"; require IPC::Run::Debug"'
         or die $@;
   }
}

Esto debería forzar que IPC::Run no sea depurable a menos que alguien establezca la bandera IPCRUNDEBUG; modifica esta fórmula para buscar en @ARGV si es necesario:

BEGIN {
   unless ( grep /^--debug/, @ARGV ) {
      eval 'local $ENV{IPCRUNDEBUG} = "none"; require IPC::Run::Debug"'
      or die $@;
}

Ambos son no probados.
