IO::Pager::Unbuffered(3) Documentación de Perl aportada por el usuario IO::Pager::Unbuffered(3)

NOMBRE

IO::Pager::Unbuffered - Envía la salida a PAGER si el destino es una TTY

SINOPSIS

use IO::Pager::Unbuffered;
{
  local $STDOUT = IO::Pager::Unbuffered::open *STDOUT;
  print <<"  HEREDOC" ;
  ...
  Un montón de texto más tarde
  HEREDOC
}
{
  # También puedes usar manejadores de archivos escalares...
  my $token = IO::Pager::Unbuffered::open($FH) or warn($!);
  print $FH "Nada de globs ni barewords para nosotros, ¡gracias!\n" while 1;
}
{
  # ...o una interfaz de objetos
  my $token = new IO::Pager::Unbuffered;
  $token->print("Brillante OO...\n") while 1;
}

DESCRIPCIÓN

Las subclases de IO::Pager están diseñadas para decidir programáticamente si se debe o no enviar la salida de un manejador de archivos a un programa especificado en PAGER; determinado y establecido por IO::Pager en tiempo de ejecución si aún no está definido.

Ver IO::Pager para detalles de los métodos.

MÉTODOS

Todos los métodos se heredan de IO::Pager; excepto la instanciación.

SALVEDADES

Probablemente quieras hacer algo con SIGPIPE, por ejemplo:

eval {
  local $SIG{PIPE} = sub { die };
  local $STDOUT = IO::Pager::open(*STDOUT);
  while (1) {
    # Haz algo
  }
}
# Haz otra cosa
