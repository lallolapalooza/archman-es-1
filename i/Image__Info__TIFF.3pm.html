Image::Info::TIFF(3) Documentación de Perl contribuida por el usuario Image::Info::TIFF(3)

NOMBRE

Image::Info::TIFF - Soporte TIFF para Image::Info

SINOPSIS

use Image::Info qw(image_info dim);
my $info = image_info("image.tif");
if (my $error = $info->{error}) {
    die "No se pueden analizar la información de la imagen: $error\n";
}
print $info->{BitPerSample};
my($w, $h) = dim($info);

DESCRIPCIÓN

Este módulo añade soporte TIFF para Image::Info.

MÉTODOS

process_file()

$info->process_file($source, $options);

Procesa un archivo y establece los campos de información encontrados en el objeto $info.
