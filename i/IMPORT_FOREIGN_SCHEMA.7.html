NOMBRE

IMPORT_FOREIGN_SCHEMA - importar definiciones de tablas desde un servidor externo

SINTAXIS

IMPORT FOREIGN SCHEMA esquema_remoto
    [ { LIMIT TO | EXCEPT } ( nombre_tabla [, ...] ) ]
    FROM SERVER nombre_servidor
    INTO esquema_local
    [ OPTIONS ( opcion 'valor' [, ... ] ) ]

DESCRIPCIÓN

IMPORT FOREIGN SCHEMA crea tablas externas que representan tablas existentes en un servidor externo. Las nuevas tablas externas serán propiedad del usuario que ejecuta el comando y se crearán con las definiciones de columna y opciones correctas para que coincidan con las tablas remotas.

Por defecto, se importan todas las tablas y vistas existentes en un esquema particular en el servidor externo. Opcionalmente, la lista de tablas puede limitarse a un subconjunto especificado, o se pueden excluir tablas específicas. Todas las nuevas tablas externas se crean en el esquema de destino, que ya debe existir.

Para usar IMPORT FOREIGN SCHEMA, el usuario debe tener el privilegio USAGE en el servidor externo, así como el privilegio CREATE en el esquema de destino.

PARÁMETROS

esquema_remoto

El esquema remoto desde el cual importar. El significado específico de un esquema remoto depende del wrapper de datos externos en uso.

LIMIT TO ( nombre_tabla [, ...] )

Importar solo tablas externas que coincidan con uno de los nombres de tabla dados. Se ignorarán otras tablas existentes en el esquema externo.

EXCEPT ( nombre_tabla [, ...] )

Excluir tablas externas especificadas de la importación. Todas las tablas existentes en el esquema externo se importarán excepto las listadas aquí.

nombre_servidor

El servidor externo desde el cual importar.

esquema_local

El esquema en el cual se crearán las tablas externas importadas.

OPTIONS ( opcion 'valor' [, ...] )

Opciones que se utilizarán durante la importación. Los nombres y valores de opción permitidos son específicos de cada wrapper de datos externos.

EJEMPLOS

Importar definiciones de tablas desde el esquema remoto foreign_films en el servidor film_server, creando las tablas externas en el esquema local films:

IMPORT FOREIGN SCHEMA foreign_films
    FROM SERVER film_server INTO films;

Como anteriormente, pero importar solo las dos tablas actors y directors (si existen):

IMPORT FOREIGN SCHEMA foreign_films LIMIT TO (actors, directors)
    FROM SERVER film_server INTO films;

COMPATIBILIDAD

El comando IMPORT FOREIGN SCHEMA se ajusta al estándar SQL, excepto que la cláusula OPTIONS es una extensión de PostgreSQL.
