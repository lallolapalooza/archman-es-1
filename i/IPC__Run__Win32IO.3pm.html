IPC::Run::Win32IO(3) Documentación de Perl aportada por el usuario IPC::Run::Win32IO(3)

NOMBRE

IPC::Run::Win32IO - rutinas auxiliares para IPC::Run en plataformas Win32.

SINOPSIS

use IPC::Run::Win32IO;   # Exporta todo por defecto

DESCRIPCIÓN

IPC::Run necesita usar sockets para redirigir la E/S de subprocesos para que el bucle select() funcione en Win32. Esto parece funcionar solo en WinNT y Win2K en este momento, no estoy seguro de si alguna vez funcionará en Win95 o Win98. Si tienes experiencia en esta área, por favor contáctame en barries@slaysys.com, ¡gracias!.

DESCRIPCIÓN

Una clase de E/S especializada utilizada en Win32.

SUBRUTINAS

poll
Versión de Windows de IPC::Run::IP::poll.
