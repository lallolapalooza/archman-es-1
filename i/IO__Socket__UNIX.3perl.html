IO::Socket::UNIX(3perl) Guía del programador de Perl IO::Socket::UNIX(3perl)

NOMBRE

IO::Socket::UNIX - Interfaz de objeto para sockets de dominio AF_UNIX

SINOPSIS

use IO::Socket::UNIX;
my $SOCK_PATH = "$ENV{HOME}/unix-domain-socket-test.sock";
# Servidor:
my $server = IO::Socket::UNIX->new(
    Type => SOCK_STREAM(),
    Local => $SOCK_PATH,
    Listen => 1,
);
my $count = 1;
while (my $conn = $server->accept()) {
    $conn->print("Hola " . ($count++) . "\n");
}
# Cliente:
my $client = IO::Socket::UNIX->new(
    Type => SOCK_STREAM(),
    Peer => $SOCK_PATH,
);
# Ahora lee y escribe desde $client

DESCRIPCIÓN

"IO::Socket::UNIX" proporciona una interfaz de objeto para crear y usar sockets en el dominio AF_UNIX. Está construido sobre la interfaz IO::Socket y hereda todos los métodos definidos por IO::Socket.

CONSTRUCTOR

new ( [ARGUMENTOS] )
Crea un objeto "IO::Socket::UNIX", que es una referencia a un símbolo recién creado (ver el paquete Symbol). "new" opcionalmente acepta argumentos, estos argumentos están en pares clave-valor.

Además de los pares clave-valor aceptados por IO::Socket, "IO::Socket::UNIX" proporciona.

Type        Tipo de socket (ej. SOCK_STREAM o SOCK_DGRAM)
Local       Ruta al fifo local
Peer        Ruta al fifo del par
Listen      Tamaño de cola para escuchar

Si al constructor solo se le pasa un único argumento, se asume que es una especificación de "Peer".

Si se proporciona el argumento "Listen", pero es falso, el tamaño de la cola se establecerá en 5.

Si el constructor falla, devolverá "undef" y establecerá la variable de paquete $IO::Socket::errstr para contener un mensaje de error.

$sock = IO::Socket::UNIX->new(...)
    or die "No se puede crear el socket - $IO::Socket::errstr\n";

Por razones de compatibilidad, el mensaje de error también se establece en la variable global $@, y es posible que encuentres código antiguo que mire aquí en su lugar.

$sock = IO::Socket::UNIX->new(...)
    or die "No se puede crear el socket - $@\n";

MÉTODOS

hostpath()
Devuelve la ruta al fifo en el extremo local.
peerpath()
Devuelve la ruta al fifo en el extremo del par.
