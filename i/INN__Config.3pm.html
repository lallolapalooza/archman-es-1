INN::Config(3pm) Documentación de InterNetNews INN::Config(3pm)

NOMBRE

INN::Config - Exporta todas las variables que un script Perl de INN podría necesitar

DESCRIPCIÓN

Este módulo Perl configura todas y cada una de las variables que un script Perl de INN podría necesitar. Más concretamente, permite usar las variables de inn.conf: todas ellas son proporcionadas por innconfval, así como la versión de INN (en la variable $INN::Config::VERSION para su forma de número corto, y en $INN::Config::version para su forma completa). También se proporcionan otras variables útiles (directorios, archivos, programas, máscaras, parámetros). La lista completa se puede obtener con el siguiente script que las imprime:

use lib '<pathnews>/lib/perl';
use INN::Config;
use Data::Dumper;
my ($varname, $value);
foreach my $var (@INN::Config::EXPORT_OK) {
    if ($var =~ /^\$(.*)$/) {
        $varname = "INN::Config::$1";
        $value = Dumper($$varname);
        $value =~ s/^\$VAR1 = //;
        print "\$$varname = $value";
    } elsif ($var =~ /^\@(.*)$/) {
        $varname = "INN::Config::$1";
        $value = Dumper(\@$varname);
        $value =~ s/^\$VAR1 = //;
        print "\@$varname = $value";
    }
}

Se cargará un script Perl local llamado innshellvars.pl.local en pathetc, si está presente y es ejecutable, al final de la ejecución de este módulo. Un uso típico es añadir o sobrescribir variables.

Solo tienes que declarar el módulo al principio de los mismos:

use lib '<pathnews>/lib/perl';
use INN::Config;

Luego, puedes, por ejemplo, usar:

print $INN::Config::localmaxartsize;

para imprimir el valor de localmaxartsize tal como está configurado en inn.conf.

También puedes especificar una versión al importar el módulo. Si escribes:

use INN::Config 2.5.0;

solo las versiones de INN superiores a 2.5.0 podrán ejecutar el script Perl.

También es posible importar las variables directamente en tu espacio de nombres si especificas lo que quieres importar:

use INN::Config qw($localmaxartsize $pathbin);

Ten en cuenta que también se proporciona un innshellvars.pl heredado en pathnews/lib por razones de compatibilidad con scripts Perl antiguos no distribuidos con INN. Fue utilizado por versiones de INN anteriores a la 2.5.0. Sin embargo, los scripts correspondientes para Shell y Tcl todavía están en uso: innshellvars y innshellvars.tcl. Ofrecen las mismas capacidades que este módulo.

HISTORIA

innshellvars.pl fue escrito por James Brister <brister@vix.com> para InterNetNews en 1996. Fue convertido al módulo Perl INN::Config por Julien Elie en 2007.

VER TAMBIÉN

inn.conf(5), innconfval(1), perl(1).
