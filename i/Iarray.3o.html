Módulo Iarray
: sig end

Operaciones sobre arrays inmutables. Este módulo refleja la API de Array, pero omite las funciones que asumen mutabilidad; además de las funciones evidentemente mutables, omite copy junto con las funciones make, create_float y make_matrix que producen arrays completamente constantes. La excepción son las funciones de ordenación, que tienen una API de copia para reemplazar la in-situ.

type 'a t = 'a iarray

Un alias para el tipo de arrays inmutables.

val length : 'a iarray -> int

Devuelve la longitud (número de elementos) del array inmutable dado.

val get : 'a iarray -> int -> 'a

get a n devuelve el elemento número n del array inmutable a. El primer elemento tiene el número 0. El último elemento tiene el número length a - 1.

Raises Invalid_argument si n está fuera del rango 0 a (length a - 1).

val init : int -> (int -> 'a) -> 'a iarray

init n f devuelve un nuevo array inmutable de longitud n, con el elemento número i inicializado al resultado de f i. En otras palabras, init n f tabula los resultados de f aplicados a los enteros 0 a n-1.

Raises Invalid_argument si n < 0 o n > Sys.max_array_length. Si el tipo de retorno de f es float, entonces el tamaño máximo es solo Sys.max_array_length / 2.

val append : 'a iarray -> 'a iarray -> 'a iarray

append v1 v2 devuelve un nuevo array inmutable que contiene la concatenación de los arrays inmutables v1 y v2.

Raises Invalid_argument si length v1 + length v2 > Sys.max_array_length.

val concat : 'a iarray list -> 'a iarray

Igual que Iarray.append, pero concatena una lista de arrays inmutables.

val sub : 'a iarray -> pos:int -> len:int -> 'a iarray

sub a ~pos ~len devuelve un nuevo array inmutable de longitud len, que contiene los elementos del número pos al pos + len - 1 del array inmutable a. Esto crea una copia de la porción seleccionada del array inmutable.

Raises Invalid_argument si pos y len no designan un sub-array válido de a; es decir, si pos < 0, o len < 0, o pos + len > length a.

val to_list : 'a iarray -> 'a list

to_list a devuelve la lista de todos los elementos de a.

val of_list : 'a list -> 'a iarray

of_list l devuelve un nuevo array inmutable que contiene los elementos de l.

Raises Invalid_argument si la longitud de l es mayor que Sys.max_array_length.

Conversión a y desde arrays mutables

val to_array : 'a iarray -> 'a array

to_array a devuelve una copia mutable del array inmutable a; es decir, un nuevo array (mutable) que contiene los mismos elementos que a.

val of_array : 'a array -> 'a iarray

of_array ma devuelve una copia inmutable del array mutable ma; es decir, un nuevo array inmutable que contiene los mismos elementos que ma.

Comparación

val equal : ('a -> 'a -> bool) -> 'a iarray -> 'a iarray -> bool

eq [|a1; ...; an|] [|b1; ..; bm|] es verdadero cuando los dos arrays inmutables de entrada tienen la misma longitud, y para cada par de elementos ai, bi en la misma posición se cumple que eq ai bi.

val compare : ('a -> 'a -> int) -> 'a iarray -> 'a iarray -> int

Dado que la función cmp define un preorden en los elementos, compare cmp a b compara primero a y b por su longitud, y luego, si son iguales, por sus elementos según el preorden lexicográfico.

Para más detalles sobre las funciones de comparación, véase Iarray.sort.

Iteradores

val iter : ('a -> unit) -> 'a iarray -> unit

iter f a aplica la función f sucesivamente a todos los elementos de a. Es equivalente a f (get a 0); f (get a 1); ...; f (get a (length a - 1)); ().

val iteri : (int -> 'a -> unit) -> 'a iarray -> unit

Igual que Iarray.iter, pero la función se aplica al índice del elemento como primer argumento, y al elemento mismo como segundo argumento.

val map : ('a -> 'b) -> 'a iarray -> 'b iarray

map f a aplica la función f a todos los elementos de a, y construye un array inmutable con los resultados devueltos por f: [| f (get a 0); f (get a 1); ...; f (get a (length a - 1)) |].

val mapi : (int -> 'a -> 'b) -> 'a iarray -> 'b iarray

Igual que Iarray.map, pero la función se aplica al índice del elemento como primer argumento, y al elemento mismo como segundo argumento.

val fold_left : ('a -> 'b -> 'a) -> 'a -> 'b iarray -> 'a

fold_left f init a calcula f (... (f (f init (get a 0)) (get a 1)) ...) (get a n-1), donde n es la longitud del array inmutable a.

val fold_left_map : ('a -> 'b -> 'a * 'c) -> 'a -> 'b iarray -> 'a * 'c iarray

fold_left_map es una combinación de Iarray.fold_left y Iarray.map que pasa un acumulador a través de las llamadas a f.

val fold_right : ('b -> 'a -> 'a) -> 'b iarray -> 'a -> 'a

fold_right f a init calcula f (get a 0) (f (get a 1) ( ... (f (get a (n-1)) init) ...)), donde n es la longitud del array inmutable a.

Iteradores sobre dos arrays

val iter2 : ('a -> 'b -> unit) -> 'a iarray -> 'b iarray -> unit

iter2 f a b aplica la función f a todos los elementos de a y b.

Raises Invalid_argument si los arrays inmutables no tienen el mismo tamaño.

val map2 : ('a -> 'b -> 'c) -> 'a iarray -> 'b iarray -> 'c iarray

map2 f a b aplica la función f a todos los elementos de a y b, y construye un array inmutable con los resultados devueltos por f: [| f (get a 0) (get b 0);
...;
f (get a (length a - 1)) (get b (length b - 1))|] .

Raises Invalid_argument si los arrays inmutables no tienen el mismo tamaño.

Escaneo de arrays

val for_all : ('a -> bool) -> 'a iarray -> bool

for_all f [|a1; ...; an|] comprueba si todos los elementos del array inmutable satisfacen el predicado f. Es decir, devuelve (f a1) && (f a2) && ... && (f an).

val exists : ('a -> bool) -> 'a iarray -> bool

exists f [|a1; ...; an|] comprueba si al menos un elemento del array inmutable satisface el predicado f. Es decir, devuelve (f a1) || (f a2) || ... || (f an).

val for_all2 : ('a -> 'b -> bool) -> 'a iarray -> 'b iarray -> bool

Igual que Iarray.for_all, pero para un predicado de dos argumentos.

Raises Invalid_argument si los dos arrays inmutables tienen longitudes diferentes.

val exists2 : ('a -> 'b -> bool) -> 'a iarray -> 'b iarray -> bool

Igual que Iarray.exists, pero para un predicado de dos argumentos.

val mem : 'a -> 'a iarray -> bool

mem a set es verdadero si y solo si a es estructuralmente igual a un elemento de l (es decir, existe un x en l] tal que compare a x = 0 ).

val memq : 'a -> 'a iarray -> bool

Igual que Iarray.mem , pero usa igualdad física en lugar de igualdad estructural para comparar los elementos del array.

val find_opt : ('a -> bool) -> 'a iarray -> 'a option

find_opt f a devuelve el primer elemento del array inmutable a que satisface el predicado f , o None si no hay ningún valor que satisfaga f en el array a .

val find_index : ('a -> bool) -> 'a iarray -> int option

find_index f a devuelve Some i , donde i es el índice del primer elemento del array a que satisface f x , si existe tal elemento.

Devuelve None si no existe tal elemento.

val find_map : ('a -> 'b option) -> 'a iarray -> 'b option

find_map f a aplica f a los elementos de a en orden, y devuelve el primer resultado de la forma Some v , o None si no existe ninguno.

val find_mapi : (int -> 'a -> 'b option) -> 'a iarray -> 'b option

Igual que find_map , pero el predicado se aplica al índice del elemento como primer argumento (contando desde 0), y al propio elemento como segundo argumento.

Arrays de pares

val split : ('a * 'b) iarray -> 'a iarray * 'b iarray

split [|(a1,b1); ...; (an,bn)|] es ([|a1; ...; an|], [|b1; ...; bn|]) .

val combine : 'a iarray -> 'b iarray -> ('a * 'b) iarray

combine [|a1; ...; an|] [|b1; ...; bn|] es [|(a1,b1); ...; (an,bn)|] . Lanza Invalid_argument si los dos arrays inmutables tienen longitudes diferentes.

Ordenación

val sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Ordena un array inmutable en orden creciente según una función de comparación. La función de comparación debe devolver 0 si sus argumentos son iguales, un entero positivo si el primero es mayor, y un entero negativo si el primero es menor (ver más abajo para una especificación completa). Por ejemplo, compare es una función de comparación adecuada. El resultado de llamar a sort es un array inmutable nuevo que contiene los mismos elementos que el original ordenados en orden creciente. Aparte de este array nuevo, sort garantiza ejecutarse en espacio de heap constante y (como máximo) espacio de pila logarítmico.

La implementación actual usa Heap Sort. Se ejecuta en espacio de pila constante.

Especificación de la función de comparación: Sea a el array inmutable y cmp la función de comparación. Lo siguiente debe ser cierto para todos x , y , z en a :

- cmp x y > 0 si y solo si cmp y x < 0

- si cmp x y >= 0 y cmp y z >= 0 entonces cmp x z >= 0

El resultado de sort , al que llamaremos a' , contiene los mismos elementos que a , reordenados de tal manera que para todos i y j índices válidos de a (o equivalentemente, de a' ):

- cmp (get a' i) (get a' j) >= 0 si y solo si i >= j

val stable_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Igual que Iarray.sort , pero el algoritmo de ordenación es estable (es decir, los elementos que comparan igual se mantienen en su orden original) y no garantiza ejecutarse en espacio de heap constante.

La implementación actual usa Merge Sort. Usa un array temporal de longitud n/2 , donde n es la longitud del array inmutable. Generalmente es más rápido que la implementación actual de Iarray.sort .

val fast_sort : ('a -> 'a -> int) -> 'a iarray -> 'a iarray

Igual que Iarray.sort o Iarray.stable_sort , la que sea más rápida en entradas típicas.
