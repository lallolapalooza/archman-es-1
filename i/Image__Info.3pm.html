Image::Info(3) Documentación de Perl aportada por el usuario Image::Info(3)

NOMBRE

Image::Info - Extrae metadatos de archivos de imagen

SINOPSIS

use Image::Info qw(image_info dim);
my $info = image_info("imagen.jpg");
if (my $error = $info->{error}) {
    die "No se puede analizar la información de la imagen: $error\n";
}
my $color = $info->{color_type};

my $type = image_type("imagen.jpg");
if (my $error = $type->{error}) {
    die "No se puede determinar el tipo de archivo: $error\n";
}
die "¡No se permiten archivos gif!" if $type->{file_type} eq 'GIF';

my($w, $h) = dim($info);

DESCRIPCIÓN

Este módulo proporciona funciones para extraer varios tipos de metadatos de archivos de imagen.

EXPORTA

No exporta nada por defecto, pero puede exportar los siguientes métodos si se solicitan:

image_info
image_type
dim
html_dim
determine_file_type

MÉTODOS

Las siguientes funciones son proporcionadas por el módulo "Image::Info":

image_info( $archivo )
image_info( \$datos_imagen )
image_info( $archivo, clave => valor,... )
Esta función toma el nombre de un archivo o un puntero de archivo como argumento y devolverá uno o más hashes (en realidad, referencias a hashes) que describen las imágenes dentro del archivo. Si solo hay una imagen en el archivo, se devuelve solo un hash. En contexto escalar, solo se devuelve el hash de la primera imagen.

En caso de error, se devolverá un hash que contiene la clave "error". El valor correspondiente será un mensaje de error apropiado.

Si se pasa una referencia a un escalar como argumento a esta función, se asume que ese escalar contiene directamente los datos brutos de la imagen.

La función image_info() también toma argumentos opcionales de estilo clave/valor que pueden influir en la información que se devuelve.

image_type( $archivo )
image_type( \$datos_imagen )
Devuelve un hash con una sola clave, "file_type". El valor será el tipo de archivo. En caso de error, establece las dos claves "error" y "Errno".

Esta función es una alternativa drásticamente más rápida a la función image_info para situaciones en las que solo necesita encontrar el tipo de imagen.

Utiliza solo la detección interna del tipo de archivo para hacer esto, y por lo tanto no necesita cargar ninguno de los módulos controladores específicos del tipo de imagen, y no accede a todo el archivo. Tampoco necesita acceso a los primeros 11 bytes del archivo.

Para mantener cierto nivel de compatibilidad con image_info, image_type devuelve en el mismo formato, con el mismo estilo de mensaje de error. Es decir, devuelve una referencia a un HASH, con la clave "$type->{error}" establecida si hubo un error.

En caso de éxito, la referencia HASH contendrá la única clave "file_type", que representa el tipo de archivo, expresado como el código de tipo utilizado para los diversos controladores ('GIF', 'JPEG', 'TIFF' y así sucesivamente).

Si hay varias imágenes dentro del archivo, se ignorarán, ya que esta función solo proporciona el tipo del archivo general, no de las diversas imágenes dentro de él. Esta función no devolverá varios hashes si el archivo contiene varias imágenes.

Por supuesto, en todos (o al menos efectivamente en todos) los casos el tipo de las imágenes dentro del archivo será el mismo que el del archivo en sí.

dim( $hash_info )
Toma un hash devuelto por image_info() y devuelve las dimensiones ($ancho, $alto) de la imagen. En contexto escalar, devuelve las dimensiones como una cadena.
html_dim( $hash_info )
Devuelve las dimensiones como una cadena adecuada para incrustar directamente en etiquetas <img> de HTML o SVG. Por ejemplo: 
print "<img src="..." @{[html_dim($info)]}>\n";
determine_file_format( $datos_archivo )
Determina el formato del archivo a partir de los datos del archivo proporcionados (un escalar normal de Perl que contiene los primeros bytes del archivo), y devuelve undef para un formato de archivo desconocido, o una cadena que describe el formato, como "BMP" o "JPEG".

Descripciones de imagen

La función image_info() devuelve metadatos sobre cada imagen en forma de referencia a un hash. Las claves de hash utilizadas se basan en la mayoría de los casos en los nombres de los elementos TIFF. Todas las claves en minúsculas son obligatorias para todos los formatos de archivo y siempre estarán presentes a menos que ocurra un error (en cuyo caso estará presente la clave "error"). Las claves en mayúsculas y minúsculas solo estarán presentes cuando el elemento de información correspondiente esté disponible en la imagen.

Los siguientes nombres de clave son comunes para cualquier formato de imagen:

file_media_type
Este es el tipo MIME apropiado para el formato de archivo dado. El valor correspondiente es una cadena como: "image/png" o "image/jpeg".
file_ext
Esta es la extensión de nombre de archivo sugerida para un archivo del formato de archivo dado. El valor es una cadena de 3 letras en minúsculas como "png", "jpg".
width
Este es el número de píxeles horizontalmente en la imagen.
height
Este es el número de píxeles verticalmente en la imagen. (TIFF usa el nombre ImageLength para este campo.)
color_type
El valor es una cadena corta que describe qué tipo de valores codifican los píxeles. El valor puede ser uno de los siguientes: 
Gray
GrayA
RGB
RGBA
CMYK
YCbCr
CIELab

Estos nombres también pueden ir precedidos por "Indexed-" si la imagen está compuesta por índices de una paleta. De estos, es probable que ocurra solo "Indexed-RGB".

Es similar al campo TIFF "PhotometricInterpretation", pero se encontró que este nombre era demasiado largo, por lo que usamos el término inspirado en PNG en su lugar.

resolution
El valor de este campo normalmente da el tamaño físico de la imagen en la pantalla o en el papel. Cuando falta el especificador de unidad, este campo denota la cuadratura de los píxeles en la imagen.

La sintaxis de este campo es:

<res> <unidad>
<xres> "/" <yres> <unidad>
<xres> "/" <yres>

Los campos <res>, <xres> y <yres> son números. La <unidad> es una cadena como "dpi", "dpm" o "dpcm" (que denota "puntos por pulgada/cm/metro").

SamplesPerPixel
Esto indica cuántos canales hay en la imagen. Para algunos formatos de imagen, este número puede ser mayor que el número implícito por "color_type".
BitsPerSample
Esto indica cuántos bits se utilizan para codificar cada una de las muestras. El valor es una referencia a un array que contiene números. El número de elementos en el array debe ser el mismo que "SamplesPerPixel".
Comment
Comentarios textuales encontrados en el archivo. El valor es una referencia a un array si se encuentran varios comentarios.
Int

NAME

Image::Info - retrieve image information.

SYNOPSIS

 use Image::Info qw(image_info);

 my $info = image_info('image.png');
 print "Image Type: ", $info->{type}, "\n";
 print "Dimensions: ", $info->{width}, "x", $info->{height}, "\n";

 my @all_info = image_info('animated.gif');

DESCRIPTION

This module attempts to return image format information without reading the whole image data. This is done by reading the image file header and some associated chunks.

The image_info() function returns a hash reference with image information. If the image file contains multiple images (like in animated GIFs or TIFFs), and image_info() is called in list context, it will return a list of hash references, one for each image.

The information returned depends on the image format, but the following keys are usually available:

type
The image format (e.g. 'png', 'jpeg', 'gif').
width
The image width in pixels.
height
The image height in pixels.
depth
The number of bits per pixel.
mime_type
The MIME type of the image (e.g. 'image/png').
file_size
The size of the file in bytes.

Image descriptions

The following image specific keys may be returned:

Interlace
If the image is interlaced, then this tells which interlace method is used.
Compression
This tells you which compression algorithm is used.
Gamma
A number.
LastModificationTime
A ISO date string

Supported Image Formats

The following image file formats are supported:

AVIF
Supports the basic standard info key names.
BMP
This module supports the Microsoft Device Independent Bitmap format (BMP, DIB, RLE).

For more information see Image::Info::BMP.

GIF
Both GIF87a and GIF89a are supported and the version number is found as "GIF_Version" for the first image. GIF files can contain multiple images, and information for all images will be returned if image_info() is called in list context. The Netscape-2.0 extension to loop animation sequences is represented by the "GIF_Loop" key for the first image. The value is either "forever" or a number indicating loop count.
ICO
This module supports the Microsoft Windows Icon Resource format (.ico).
JPEG
For JPEG files we extract information both from "JFIF" and "Exif" application chunks.

"Exif" is the file format written by most digital cameras. This encode things like timestamp, camera model, focal length, exposure time, aperture, flash usage, GPS position, etc.

The "Exif" spec can be found at: http://www.exif.org/specifications.html.

The "color_type" element may have the following values: "Gray", "YCbCr", and "CMYK". Note that detecting "RGB" and "YCCK" currently does not work, but will hopefully in future.

PNG
Information from IHDR, PLTE, gAMA, pHYs, tEXt, tIME chunks are extracted. The sequence of chunks are also given by the "PNG_Chunks" key.
PBM/PGM/PPM
All information available is extracted.
SVG
Provides a plethora of attributes and metadata of an SVG vector graphic.
TIFF
The "TIFF" spec can be found at: http://partners.adobe.com/public/developer/tiff/

The EXIF spec can be found at: http://www.exif.org/specifications.html

WBMP
wbmp files have no magic, so cannot be used with the normal Image::Info functions. See Image::Info::WBMP for more information.
WEBP
VP8 (lossy), VP8L (lossless) and VP8X (extended) files are supported. Sets the key "Animation" to true if the file is an animation. Otherwise sets the key "Compression" to either "VP8" or "Lossless".
XBM
See Image::Info::XBM for details.
XPM
See Image::Info::XPM for details.

CAVEATS

While this module is fine for parsing basic image information like image type, dimensions and color depth, it is probably not good enough for parsing out more advanced information like EXIF data. If you want an up-to-date and tested EXIF parsing library, please use Image::ExifTool.
