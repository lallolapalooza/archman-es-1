IsCursorKey(3) FUNCIONES DE XLIB IsCursorKey(3)

NOMBRE

IsCursorKey, IsFunctionKey, IsKeypadKey, IsMiscFunctionKey, IsModifierKey, IsPFKey, IsPrivateKeypadKey - macros de clasificación de KeySym

SINTAXIS

int IsCursorKey(KeySym keysym);

int IsFunctionKey(KeySym keysym);

int IsKeypadKey(KeySym keysym);

int IsMiscFunctionKey(KeySym keysym);

int IsModifierKey(KeySym keysym);

int IsPFKey(KeySym keysym);

int IsPrivateKeypadKey(KeySym keysym);

ARGUMENTOS

keysym
Especifica el KeySym que se va a probar.

DESCRIPCIÓN

El macro IsCursorKey devuelve True si el KeySym especificado es una tecla de cursor.

El macro IsFunctionKey devuelve True si el KeySym es una tecla de función.

El macro IsKeypadKey devuelve True si el KeySym especificado es una tecla del teclado numérico.

El macro IsMiscFunctionKey devuelve True si el KeySym especificado es una tecla de función miscelánea.

El macro IsModifierKey devuelve True si el KeySym especificado es una tecla modificadora.

El macro IsPFKey devuelve True si el KeySym especificado es una tecla PF.

El macro IsPrivateKeypadKey devuelve True si el KeySym especificado es una tecla del teclado numérico privada del proveedor.
