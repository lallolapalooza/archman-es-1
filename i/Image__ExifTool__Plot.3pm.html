NOMBRE

Image::ExifTool::Plot - Graficar valores de etiquetas en formato SVG

DESCRIPCIÓN

Genera gráficos en formato SVG basados en la información de etiquetas de ExifTool.

MÉTODOS

new

Crea un nuevo objeto Plot.

$plot = Image::ExifTool::Plot->new;

Settings

Cambia la configuración del gráfico.

Entradas:
0) Referencia al objeto Plot

1) Cadena de opciones separadas por comas

Opciones:
"Type=Line"           - tipo de gráfico (Line, Scatter o Histogram)
"Style=Line"          - estilo de datos (Line, Marker y/o Fill)
"NBins=20"            - número de divisiones para gráfico de histograma
"Size=800 600"        - ancho,alto de la imagen de salida
"Margin=60 15 15 30"  - márgenes izquierdo,superior,derecho,inferior alrededor del área del gráfico
"Legend=0 0"          - desplazamiento x,y para mover la leyenda del gráfico
"TxtPad=10 10"        - relleno entre texto y escala x,y
"LineSpacing=20"      - espaciado entre líneas de texto
"Stroke=1"            - ancho de trazo del gráfico y factor de escala del tamaño del marcador
Title, XLabel, YLabel - título del gráfico y etiquetas de los ejes x/y (sin valor predeterminado)
XMin, XMax            - mínimo/máximo del eje x (escalado automático si no se establece)
YMin, YMax            - mínimo/máximo del eje y
Multi                 - número de columnas al dibujar múltiples gráficos,
                        seguido opcionalmente por el número de conjuntos de datos para cada
                        gráfico (1 por defecto) usando cualquier separador
Split                 - indicador para dividir cadenas de números en listas
                        (> 1 para dividir en listas de N elementos)
"Grid=darkgray"       - color de la cuadrícula
"Text=black"          - color del texto y borde del gráfico
"Bkg="                - color de fondo (el valor predeterminado es transparente)
"Cols=red green blue black orange gray fuchsia brown turquoise gold"
                      - colores para los datos del gráfico
"Marks=circle square triangle diamond star plus pentagon left down right"
                      - nombres de formas de marcador para cada conjunto de datos

AddPoints

Añade puntos para ser graficados.

Entradas:
0) Referencia al objeto Plot

1) Referencia al hash de información de etiquetas de ExifTool

2) Lista de claves de etiquetas para graficar

Draw

Dibuja el gráfico SVG en el archivo de salida especificado.

Entradas:
0) Referencia al objeto Plot

1) Referencia al archivo de salida

Notas:
Al regresar, los miembros Plot Error y Warn contienen cadenas de error o advertencia si hubo algún problema. Si se establece un Error, entonces el SVG de salida no es válido.
