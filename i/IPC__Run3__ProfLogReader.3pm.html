IPC::Run3::ProfLogReader(3) Documentación de Perl contribuida por el usuario IPC::Run3::ProfLogReader(3)

NOMBRE

IPC::Run3::ProfLogReader - lee y procesa un archivo ProfLogger

SINOPSIS

use IPC::Run3::ProfLogReader;
my $reader = IPC::Run3::ProfLogReader->new; ## usa "run3.out"
my $reader = IPC::Run3::ProfLogReader->new( Source => $fn );
my $profiler = IPC::Run3::ProfPP;   ## Por ejemplo
my $reader   = IPC::Run3::ProfLogReader->new( ..., Handler => $p );
$reader->read;
$eaderr->read_all;

DESCRIPCIÓN

Lee un archivo de registro. Usa el nombre de archivo "-" para leer desde STDIN.

MÉTODOS

"IPC::Run3::ProfLogReader->new( ... )"

"$reader->set_handler( $handler )"

"$reader->get_handler()"

"$reader->read()"

"$reader->read_all()"

Este método lee hasta que no queda nada por leer y luego devuelve verdadero.
