IPC::Msg(3perl) Guía de referencia del programador de Perl IPC::Msg(3perl)

NOMBRE

IPC::Msg - Clase de objeto IPC de mensajes SysV

SINOPSIS

use IPC::SysV qw(IPC_PRIVATE S_IRUSR S_IWUSR);
use IPC::Msg;
$msg = IPC::Msg->new(IPC_PRIVATE, S_IRUSR | S_IWUSR);
$msg->snd($msgtype, $msgdata);
$msg->rcv($buf, 256);
$ds = $msg->stat;
$msg->remove;

DESCRIPCIÓN

Una clase que proporciona una interfaz orientada a objetos para las colas de mensajes IPC de SysV.

MÉTODOS

new ( CLAVE , BANDERAS )
Crea una nueva cola de mensajes asociada con "CLAVE". Se crea una nueva cola si
  • "CLAVE" es igual a "IPC_PRIVATE"
  • "CLAVE" no tiene ya asociada una cola de mensajes, y "BANDERAS & IPC_CREAT" es verdadero.

Al crear una nueva cola de mensajes, "BANDERAS" se utiliza para establecer los permisos. Tenga cuidado de no establecer ninguna bandera que la implementación de IPC de Sys V no permita: en algunos sistemas, establecer bits de ejecución hace que las operaciones fallen.

id
Devuelve el identificador del sistema de la cola de mensajes.
rcv ( BUFFER, LONGITUD [, TIPO [, BANDERAS ]] )
Lee un mensaje de la cola. Devuelve el tipo del mensaje leído. Véase msgrcv(2). El BUFFER se marca como contaminado (tainted).
remove
Elimina y destruye la cola de mensajes del sistema.
set ( ESTADO )
set ( NOMBRE => VALOR [, NOMBRE => VALOR ...] )
"set" establecerá los siguientes valores de la estructura de "estado" asociada a la cola de mensajes. 
uid
gid
mode (sólo los bits de permisos)
qbytes

"set" acepta ya sea un objeto de estado, como el devuelto por el método "stat", o una lista de pares de nombre-valor.

snd ( TIPO, MENSAJE [, BANDERAS ] )
Coloca un mensaje en la cola con los datos de "MENSAJE" y con tipo "TIPO". Véase msgsnd(2).
stat
Devuelve un objeto de tipo "IPC::Msg::stat" que es una subclase de "Class::Struct". Proporciona los siguientes campos. Para una descripción de estos campos, consulte la documentación de su sistema. 
uid
gid
cuid
cgid
mode
qnum
qbytes
lspid
lrpid
stime
rtime
ctime

VER TAMBIÉN

IPC::SysV, Class::Struct
