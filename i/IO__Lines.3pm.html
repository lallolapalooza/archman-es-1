IO::Lines(3) Documentación de Perl aportada por el usuario IO::Lines(3)

NOMBRE

IO::Lines - Interfaz IO:: para leer/escribir un array de líneas

SINOPSIS

use IO::Lines;
### Ver IO::ScalarArray para detalles

DESCRIPCIÓN

Esta clase implementa objetos que se comportan como objetos FileHandle (o IO::Handle), excepto que puedes usarlos para escribir (o leer) desde un array de líneas. Capaz de "tiehandle" también.

Esta es una subclase de IO::ScalarArray en la que el array subyacente tiene sus datos almacenados en un formato orientado a líneas: es decir, cada elemento termina en un "\n", con la posible excepción del elemento final. Esto hace que getline() sea *mucho* más eficiente; si planeas hacer lectura/impresión orientada a líneas, querrás esta clase.

El método print() aplicará esta regla, por lo que puedes imprimir datos arbitrarios al array de líneas: dividirá los datos en saltos de línea apropiadamente.

Ver IO::ScalarArray para uso completo y advertencias.
