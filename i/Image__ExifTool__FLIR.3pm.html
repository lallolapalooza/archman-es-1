NOMBRE

Image::ExifTool::FLIR - Lee metadatos de FLIR

SINOPSIS

Este módulo es cargado automáticamente por Image::ExifTool cuando se requiere.

DESCRIPCIÓN

Este módulo contiene las definiciones para leer metadatos de archivos de imagen térmica de FLIR Systems Inc. (formato FFF, FPF y JPEG).
