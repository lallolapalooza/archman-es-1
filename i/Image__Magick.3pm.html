Image__Magick(3pm)

Paquete: imagemagick

Licencias: custom

Magick(3) Documentación de Perl contribuida por el usuario Magick(3)

NOMBRE

Image::Magick - interfaz orientada a objetos de Perl para ImageMagick con quantum por defecto (Q16HDRI). Úselo para leer, manipular o escribir una imagen o una secuencia de imágenes dentro de un script de Perl.

SINOPSIS

use Image::Magick;
$p = new Image::Magick;
$p->Read("archivo_imagen");
$p->Set(atributo => valor, ...)
($a, ...) = $p->Get("atributo", ...)
$p->rutina(parametro => valor, ...)
$p->Mogrify("Rutina", parametro => valor, ...)
$p->Write("nombre_archivo");

DESCRIPCIÓN

Esta extensión de Perl permite la lectura, manipulación y escritura de una gran cantidad de formatos de archivo de imagen utilizando la biblioteca ImageMagick. Originalmente se desarrolló para ser utilizada por scripts CGI para páginas web.

Se ha creado una página web para esta extensión. Consulte:
