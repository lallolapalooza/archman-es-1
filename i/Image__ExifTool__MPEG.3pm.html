Image::ExifTool::MPEG(3) Documentación de Perl aportada por el usuario Image::ExifTool::MPEG(3)

NOMBRE

Image::ExifTool::MPEG - Lee información de metadatos de archivos MPEG-1 y MPEG-2

SINOPSIS

Este módulo es utilizado por Image::ExifTool

DESCRIPCIÓN

Este módulo contiene definiciones necesarias para que Image::ExifTool lea archivos de audio/vídeo MPEG-1 y MPEG-2.

NOTAS

Dado que ISO cobra dinero por la especificación oficial de MPEG, este módulo se basa en fuentes no oficiales que pueden ser incompletas, inexactas o desactualizadas.
