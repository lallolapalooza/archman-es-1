NOMBRE

Image::ExifTool::TNEF - Leer información meta de TNEF

SINOPSIS

Este módulo es utilizado por Image::ExifTool

DESCRIPCIÓN

Este módulo contiene las definiciones necesarias para que Image::ExifTool lea archivos TNEF (Transport Neutral Encapsulation Format).
