NOMBRE

I18N::LangTags::Detect - detectar las preferencias de idioma del usuario

SINOPSIS

use I18N::LangTags::Detect;
my @user_wants = I18N::LangTags::Detect::detect();

DESCRIPCIÓN

Es un problema común querer detectar en qué idioma(s) preferiría el usuario la salida.

FUNCIONES

Este módulo define una función pública, I18N::LangTags::Detect::detect(). Esta función no se exporta (ni siquiera es exportable) y no toma parámetros.

En contexto escalar, la función devuelve la etiqueta de idioma más preferida (o undef si no se vio ninguna preferencia).

En contexto de lista (que es lo que generalmente querrá), la función devuelve una lista (posiblemente vacía) de etiquetas de idioma que representan (primero la mejor) los idiomas en los que el usuario aparentemente aceptaría la salida. Probablemente querrá pasar la salida de esto a través de I18N::LangTags::implicate_supers_tightly(...) o I18N::LangTags::implicate_supers(...), así:

my @languages =
  I18N::LangTags::implicate_supers_tightly(
    I18N::LangTags::Detect::detect()
  );

ENTORNO

Este módulo examina varias variables de entorno: REQUEST_METHOD, HTTP_ACCEPT_LANGUAGE, LANGUAGE, LC_ALL, LC_MESSAGES y LANG.

También utilizará el módulo Win32::Locale, si está instalado y IGNORE_WIN32_LOCALE no está establecido a un valor verdadero en el entorno.

VER TAMBIÉN

I18N::LangTags, Win32::Locale, Locale::Maketext.

(El código principal de este módulo comenzó como una rutina en Locale::Maketext; pero lo moví aquí una vez que me di cuenta de que era más útil en general.)
