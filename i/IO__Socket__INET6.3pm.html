NAME

IO::Socket::INET6 - [¡DEPRECADO!!] Interfaz de objetos para sockets de dominio AF_INET/AF_INET6

SYNOPSIS

use IO::Socket::INET6;

WARNING

¡ADVERTENCIA!! IO-Socket-INET6 está deprecado.

IO-Socket-INET6 ha sido reemplazado por IO::Socket::IP de Paul Evans. Por favor, convierta el código antiguo de IO-Socket-INET6 a IO::Socket-IP.

DESCRIPTION

"IO::Socket::INET6" proporciona una interfaz de objetos para crear y usar sockets en los dominios AF_INET o AF_INET6. Se construye sobre la interfaz IO::Socket y hereda todos los métodos definidos por IO::Socket.

CONSTRUCTOR

new ( [ARGS] )
Crea un objeto "IO::Socket::INET6", que es una referencia a un símbolo recién creado (véase el paquete "Symbol"). "new" puede tomar opcionalmente argumentos, estos argumentos se presentan en pares clave-valor.

Además de los pares clave-valor aceptados por IO::Socket, "IO::Socket::INET6" proporciona.

Domain      Familia de direcciones               AF_INET | AF_INET6 | AF_UNSPEC (por defecto)
PeerAddr    Dirección del host remoto          <hostname>[:<port>]
PeerHost    Sinónimo de PeerAddr
PeerPort    Puerto remoto o servicio          <service>[(<no>)] | <no>
PeerFlow    Información de flujo remoto
PeerScope   Alcance de la dirección remota
LocalAddr   Dirección de enlace local del host hostname[:port]
LocalHost   Sinónimo de LocalAddr
LocalPort   Puerto de enlace local del host         <service>[(<no>)] | <no>
LocalFlow   Información de flujo del host local
LocalScope  Alcance de la dirección del host local
Proto       Nombre (o número) del protocolo    "tcp" | "udp" | ...
Type        Tipo de socket                  SOCK_STREAM | SOCK_DGRAM | ...
Listen      Tamaño de cola para escuchar
ReuseAddr   Establecer SO_REUSEADDR antes de enlazar
Reuse       Establecer SO_REUSEADDR antes de enlazar (deprecado, prefiera ReuseAddr)
ReusePort   Establecer SO_REUSEPORT antes de enlazar
Broadcast   Establecer SO_BROADCAST antes de enlazar
Timeout     Valor de tiempo de espera para varias operaciones
MultiHomed  Intentar todas las direcciones para hosts multi-enlazados
Blocking    Determinar si la conexión será en modo no bloqueante

Si "Listen" está definido, se crea un socket de escucha; de lo contrario, si el tipo de socket, que se deriva del protocolo, es SOCK_STREAM, se llama connect().

Aunque no es ilegal, el uso de "MultiHomed" en un socket que está en modo no bloqueante es de poca utilidad. Esto se debe a que la primera conexión nunca fallará con un tiempo de espera, ya que la llamada de conexión no bloqueará.

El "PeerAddr" puede ser un nombre de host, la dirección IPv6 en la forma "2001:800:40:2a05::10" , o la dirección IPv4 en la forma "213.34.234.245". El "PeerPort" puede ser un número o un nombre de servicio simbólico. El nombre de servicio puede seguirse de un número en paréntesis que se usa si el sistema no conoce el servicio. La especificación de "PeerPort" también puede estar incrustada en el "PeerAddr" al precederla con un ":" y cerrar la dirección IPv6 en paréntesis "[]" si es necesario: "124.678.12.34:23","[2a05:345f::10]:23","any.server.com:23".

Si "Domain" no se proporciona, se asume AF_UNSPEC, es decir, tanto AF_INET como AF_INET6 se considerarán al resolver nombres DNS. AF_INET6 tiene prioridad. Si sospecha que hay problemas para alcanzar al par (el servicio no está disponible vía AF_INET6 pero sí AF_INET), puede intentar Multihomed (intentar cualquier dirección/familia hasta alcanzar) o especificar su dirección "family" (AF_INET, AF_INET6).

Si "Proto" no se proporciona y especifica un puerto simbólico "PeerPort", entonces el constructor intentará derivar "Proto" del nombre del servicio. Como último recurso se asume "Proto" "tcp". El parámetro "Type" se deducirá de "Proto" si no se especifica.

Si el constructor solo recibe un argumento, se asume que es una especificación "PeerAddr".

Si "Blocking" se establece en 0, la conexión estará en modo no bloqueante. Si no se especifica, por defecto es 1 (modo bloqueante).

Ejemplos:

$sock = IO::Socket::INET6->new(PeerAddr => 'www.perl.org',
                              PeerPort => 'http(80)',
                              Proto    => 'tcp');

Suponga que no tiene conectividad IPv6 o www.perl.org no tiene el servicio http en IPv6. Entonces,

(Intentar todas las direcciones/familias hasta alcanzar)

$sock = IO::Socket::INET6->new(PeerAddr => 'www.perl.org',
                              PeerPort => 'http(80)',
                              Multihomed => 1 ,
                              Proto    => 'tcp');

(Concretar al protocolo IPv4)

  $sock = IO::Socket::INET6->new(PeerAddr => 'www.perl.org',
                                PeerPort => 'http(80)',
                                Domain => AF_INET ,
                                Proto    => 'tcp');
  $sock = IO::Socket::INET6->new(PeerAddr => 'localhost:smtp(25)');
  $sock = IO::Socket::INET6->new(Listen    => 5,
                                LocalAddr => 'localhost',
                                LocalPort => 9000,
                                Proto     => 'tcp');
  $sock = IO::Socket::INET6->new('[::1]:25');
  $sock = IO::Socket::INET6->new(PeerPort  => 9999,
                                PeerAddr  => Socket6::inet_ntop(AF_INET6,in6addr_broadcast),
                                Proto     => udp,
                                LocalAddr => 'localhost',
                                Broadcast => 1 )
                            or die "Can't bind : $@\n";

A partir de la VERSIÓN 1.18, todos los objetos IO::Socket tienen el autoflush activado por defecto. Esto no era el caso en las versiones anteriores.
