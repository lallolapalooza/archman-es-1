INFINITY(3) Manual de funciones de biblioteca INFINITY(3)

NOMBRE

INFINITY, NAN, HUGE_VAL, HUGE_VALF, HUGE_VALL - constantes de punto flotante

BIBLIOTECA

Biblioteca matemática (libm)

SINOPSIS

#define _ISOC99_SOURCE      /* véase feature_test_macros(7) */
#include <math.h>
INFINITY
NAN
HUGE_VAL
HUGE_VALF
HUGE_VALL

DESCRIPCIÓN

La macro INFINITY se expande a una constante de tipo float que representa el infinito positivo.

La macro NAN se expande a una constante de tipo float que representa un NaN silencioso (cuando está soportado). Un NaN silencioso es un NaN ("not-a-number") que no genera excepciones cuando se utiliza en aritmética. Lo opuesto es un NaN señalizador. Véase IEC 60559:1989.

Las macros HUGE_VAL, HUGE_VALF, HUGE_VALL se expanden a constantes de los tipos double, float y long double, respectivamente, que representan un valor positivo grande, posiblemente infinito positivo.

ESTÁNDARES

C11.

HISTORIA

C99.

En un sistema glibc, la macro HUGE_VAL siempre está disponible. La disponibilidad de la macro NAN se puede probar usando #ifdef NAN, y de forma similar para INFINITY, HUGE_VALF, HUGE_VALL. Serán definidas por <math.h> si se define _ISOC99_SOURCE o _GNU_SOURCE, o si __STDC_VERSION__ está definido y tiene un valor no menor que 199901L.

VéASE TAMBIÉN

fpclassify(3), math_error(7)
