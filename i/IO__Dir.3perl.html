IO::Dir(3perl) Guía de referencia del programador de Perl IO::Dir(3perl)

NOMBRE

IO::Dir - proporcionar métodos de objeto para manejadores de directorios

SINOPSIS

use IO::Dir;
my $d = IO::Dir->new(".");
if (defined $d) {
    while (defined($_ = $d->read)) { something($_); }
    $d->rewind;
    while (defined($_ = $d->read)) { something_else($_); }
    undef $d;
}
tie my %dir, 'IO::Dir', ".";
foreach (keys %dir) {
    print $_, " " , $dir{$_}->size,"\n";
}

DESCRIPCIÓN

El paquete "IO::Dir" proporciona dos interfaces a las rutinas de lectura de directorios de Perl.

La primera interfaz es un enfoque orientado a objetos. "IO::Dir" proporciona un constructor de objetos y métodos, que son solo envolturas alrededor de las rutinas de lectura de directorios integradas de Perl.

new ( [ NOMBRE_DIR ] )
"new" es el constructor para objetos "IO::Dir". Acepta un argumento opcional que, si se proporciona, "new" pasará a "open"

Los siguientes métodos son envolturas para las funciones relacionadas con directorios integradas en Perl (se ha eliminado el sufijo 'dir' de los nombres). Consulte perlfunc para obtener detalles sobre estas funciones.

open ( NOMBRE_DIR )
read ()
seek ( POS )
tell ()
rewind ()
close ()

"IO::Dir" también proporciona una interfaz para leer directorios a través de un hash enlazado (tied hash). El hash enlazado extiende la interfaz más allá de las simples rutinas de lectura de directorios mediante el uso de "lstat", del paquete "File::stat", "unlink", "rmdir" y "utime".

tie %hash, 'IO::Dir', NOMBRE_DIR [, OPCIONES ]

Las claves del hash serán los nombres de las entradas en el directorio. Leer un valor del hash será el resultado de llamar a "File::stat::lstat". Eliminar un elemento del hash eliminará el archivo o subdirectorio correspondiente, siempre que "DIR_UNLINK" se incluya en "OPCIONES".

Asignar a una entrada en el hash provocará la modificación de las marcas de tiempo del archivo. Si el archivo no existe, se creará. Asignar un único entero a un elemento del hash provocará que tanto el tiempo de acceso como el de modificación se cambien a ese valor. Alternativamente, se puede pasar una referencia a un array de dos valores. El primer elemento del array se utilizará para establecer el tiempo de acceso y el segundo elemento se utilizará para establecer el tiempo de modificación.
