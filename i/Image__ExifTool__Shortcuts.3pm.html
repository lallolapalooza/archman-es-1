Image::ExifTool::Shortcuts(3) Documentación de Perl contribuida por el usuario Image::ExifTool::Shortcuts(3)

NOMBRE

Image::ExifTool::Shortcuts - Etiquetas de atajos de ExifTool

SINOPSIS

Este módulo es requerido por Image::ExifTool.

DESCRIPCIÓN

Este módulo contiene definiciones para atajos de nombres de etiquetas utilizados por Image::ExifTool. Puedes personalizar este archivo para añadir tus propios atajos.

Los usuarios individuales también pueden añadir sus propios atajos al archivo .ExifTool_config en su directorio de inicio (o el directorio especificado por la variable de entorno EXIFTOOL_HOME). Los atajos se definen en una tabla hash llamada %Image::ExifTool::UserDefined::Shortcuts. Las claves de la tabla hash son los nombres de los atajos, y los elementos son nombres de etiquetas o referencias a listas de nombres de etiquetas.

Un ejemplo de definición de atajo en .ExifTool_config:

%Image::ExifTool::UserDefined::Shortcuts = (
    MiAtajo => ['createdate','exif:exposuretime','aperture'],
    MiAlias => 'FocalLengthIn35mmFormat',
);

En este ejemplo, MiAtajo es un atajo para las etiquetas CreateDate, EXIF:ExposureTime y Aperture, y MiAlias es un atajo para FocalLengthIn35mmFormat.

Los nombres de las etiquetas de destino pueden contener un prefijo de nombre de grupo opcional. Un nombre de grupo aplicado al atajo se ignorará para cualquier etiqueta de destino con un prefijo de nombre de grupo.
