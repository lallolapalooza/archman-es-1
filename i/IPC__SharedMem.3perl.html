IPC::SharedMem(3perl) Guía de Referencia del Programador de Perl IPC::SharedMem(3perl)

NOMBRE

IPC::SharedMem - Clase de objeto de memoria compartida IPC SysV

SINOPSIS

use IPC::SysV qw(IPC_PRIVATE S_IRUSR S_IWUSR);
use IPC::SharedMem;
$shm = IPC::SharedMem->new(IPC_PRIVATE, 8, S_IRWXU);
$shm->write(pack("S", 4711), 2, 2);
$data = $shm->read(0, 2);
$ds = $shm->stat;
$shm->remove;

DESCRIPCIÓN

Una clase que proporciona una interfaz orientada a objetos a la memoria compartida IPC de SysV.

MÉTODOS

new ( CLAVE, TAMAÑO, INDICADORES )
Crea un nuevo segmento de memoria compartida de TAMAÑO bytes asociado con CLAVE. Se crea un nuevo segmento si
  • CLAVE es igual a IPC_PRIVATE
  • CLAVE no tiene ya un segmento de memoria compartida asociado, y "INDICADORES & IPC_CREAT" es verdadero.

Al crear un nuevo segmento de memoria compartida, INDICADORES se utiliza para establecer los permisos. Tenga cuidado de no establecer ningún indicador que la implementación IPC de Sys V no permita: en algunos sistemas, establecer los bits de ejecución hace que las operaciones fallen.

id
Devuelve el identificador de memoria compartida.
leer ( POS, TAMAÑO )
Lee TAMAÑO bytes del segmento de memoria compartida en POS. Devuelve la cadena leída, o undef si hubo un error. El valor de retorno se convierte en 'tainted'. Ver shmread.
escribir ( CADENA, POS, TAMAÑO )
Escribe TAMAÑO bytes en el segmento de memoria compartida en POS. Devuelve verdadero si tiene éxito, o falso si hay un error. Ver shmwrite.
eliminar
Elimina el segmento de memoria compartida del sistema o lo marca como eliminado siempre que cualquier proceso todavía esté conectado a él.
esta_eliminado
Devuelve verdadero si el segmento de memoria compartida ha sido eliminado o marcado para su eliminación.
estadistica
Devuelve un objeto de tipo IPC::SharedMem::stat, que es una subclase de Class::Struct. Proporciona los siguientes campos. Para una descripción de estos campos, consulte la documentación del sistema. 
uid
gid
cuid
cgid
mode
segsz
lpid
cpid
nattch
atime
dtime
ctime
adjuntar ( [INDICADOR] )
Se conecta permanentemente al segmento de memoria compartida. Cuando un objeto IPC::SharedMem está conectado, utilizará memread y memwrite en lugar de shmread y shmwrite para acceder al segmento de memoria compartida. Devuelve verdadero si tiene éxito, o falso en caso de error. Ver shmat(2).
desadjuntar
Se desconecta del segmento de memoria compartida al que se había conectado previamente. Devuelve verdadero si tiene éxito, o falso en caso de error. Ver shmdt(2).
direccion
Devuelve la dirección de la memoria compartida a la que se ha conectado en un formato adecuado para su uso con pack('P'). Devuelve undef si la memoria compartida no se ha conectado.
