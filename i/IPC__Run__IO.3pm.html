IPC::Run::IO(3) Documentación de Perl aportada por el usuario IPC::Run::IO(3)

NOMBRE

IPC::Run::IO -- Canales de E/S para IPC::Run.

SINÓPSIS

¡AÚN NO IMPLEMENTADO EN Win32! Win32 no permite select() en descriptores de archivo normales; IPC::RUN::IO necesita usar IPC::Run::Win32Helper para hacer esto.

use IPC::Run qw( io );
## El sentido de '>' y '<' es opuesto al de perl's open(),
## pero concuerda con IPC::Run.
$io = io( "nombre_archivo", '>',  \$recibido );
$io = io( "nombre_archivo", 'r',  \$recibido );
## Añadir a $recibido:
$io = io( "nombre_archivo", '>>', \$recibido );
$io = io( "nombre_archivo", 'ra', \$recibido );
$io = io( "nombre_archivo", '<',  \$enviado );
$io = io( "nombre_archivo", 'w',  \$enviado );
$io = io( "nombre_archivo", '<<', \$enviado );
$io = io( "nombre_archivo", 'wa', \$enviado );
## Handles / objetos de E/S que el llamador abre:
$io = io( \*HANDLE,   '<',  \$enviado );
$f = IO::Handle->new( ... ); # Cualquier subclase de IO::Handle
$io = io( $f, '<', \$enviado );
require IPC::Run::IO;
$io = IPC::Run::IO->new( ... );
## Luego run(), harness(), o start():
run $io, ...;
## Por supuesto, puedes usar io() o IPC::Run::IO->new() como
## argumento para run(), harness, o start():
run io( ... );

DESCRIPCIÓN

Esta clase y módulo permite que los manejadores de archivo y nombres de archivo sean aprovechados para E/S cuando se usa IPC::Run, independientemente de cualquier otra cosa que IPC::Run esté haciendo (excepto que los errores y excepciones pueden afectar a todas las cosas que IPC::Run está haciendo).

filename
Obtiene/establece el nombre del archivo. Devuelve el valor después del cambio de nombre, si lo hay.
init
Realiza la inicialización necesaria antes de que esto pueda ejecutarse. Esto incluye **open()**ing el archivo, si es necesario, y limpiar el escalar de destino si es necesario.
open
Si se pasó un nombre de archivo, lo abre. Determina si el manejador está abierto a través de **fileno()**. Lanza una excepción en caso de error.
open_pipe
Si este es un objeto de redirección de E/S, abre la tubería de manera independiente de la plataforma.
close
Cierra el manejador. Lanza una excepción en caso de fallo.
fileno
Devuelve el fileno del manejador. Lanza una excepción en caso de fallo.
mode
Devuelve el operador en términos de 'r', 'w' y 'a'. Hay un estado 'ra', a diferencia de **open()** de Perl, que indica que los datos leídos del manejador o archivo se añadirán a la salida si la salida es un escalar. Esto solo es significativo si la salida es un escalar, no tiene efecto si la salida es una subrutina.

Los operadores de redirección pueden ser un poco confusos, así que aquí hay una tabla de referencia:

>      r      Leer desde el manejador de entrada al proceso
<      w      Escribir desde el proceso de salida al manejador
>>     ra     Leer desde el manejador de entrada al proceso, añadiéndolo a
              los datos existentes si el destino es un escalar.
<<     wa     Escribir desde el proceso de salida al manejador, añadiendo a
              los datos existentes si IPC::Run::IO abrió un archivo con nombre.
op
Devuelve la operación: '<', '>', '<<', '>>'. Consulte "mode" si desea escribir esto como 'r', 'w', etc.
binmode
Establece/obtiene si esta tubería está en modo binario o no. No tiene efecto en sistemas que no sean Win32, por supuesto, y en Win32, no tiene efecto después de que el harness sea **start()**ed.
dir
Devuelve el primer carácter de $self->op. Este es '<' o '>'.
