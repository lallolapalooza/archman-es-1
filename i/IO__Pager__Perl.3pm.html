NOMBRE

IO::Pager::Perl - Paginador de texto pantalla por pantalla, como more o less

SINOPSIS

use Term:ReadKey; # Opcional, pero recomendado
use IO::Pager::Perl;
my $t = IO::Pager::Perl->new( rows => 25, cols => 80 );
$t->add_text( $texto );
$t->more();

DESCRIPCIÓN

Este es un módulo para paginar texto pantalla por pantalla. Soporta las características que esperas con los atajos que esperas.

IO::Pager::Perl es un fork mejorado de Term::Pager.

USO

Crear el Paginador

$t = IO::Pager::Perl->new( opcion => valor, ... );

Si no se especifican opciones, se usarán valores predeterminados sensatos. Las siguientes opciones son reconocidas y se muestran con su valor predeterminado:

filas =>25?
El número de filas en tu terminal. La terminal se consulta directamente con Term::ReadKey si está cargado o con "stty" o "tput", y si estos fallan, se usa 25 por defecto.
columnas =>80?
El número de columnas en tu terminal. La terminal se consulta directamente con Term::ReadKey si está cargado o con "stty" o "tput", y si estos fallan, se usa 80 por defecto.
velocidad =>38400?
La velocidad (tasa de baudios) de tu terminal. La terminal se consulta directamente con Term::ReadKey si está cargado o con "stty", y si estos fallan, se usa un valor sensato por defecto.
eof =>0
Salir al final del archivo.
plegar =>1
Plegar líneas largas con Text::Wrap.
numLinea =>0
Si es verdadero, se añade numeración de líneas a la salida.
pausa =>0
Si está definido, el paginador se detendrá cuando se encuentre esta secuencia de caracteres en el texto de entrada. Se establece en ^L, es decir, "\cL", para imitar el comportamiento tradicional de "1" en more.
crudo =>0
Pasa los caracteres de control de la entrada sin adulterar a la terminal. Por defecto, los caracteres distintos de tabulación y nueva línea se convertirán a notación de careto, por ejemplo, ^@ para nulo o ^L para salto de página.
barraProgreso =>0
--barra_progreso
Mostrar una barra de progreso interactiva en la columna más a la derecha.
comprimir =>0
Colapsar múltiples líneas en blanco en una.
columna_estado =>0
Añadir una columna con marcadores que indican qué fila coincide con una expresión de búsqueda.
campanaVisual =>0
Parpadear la pantalla al hacer sonar la campana.

Accesores

Hay accesores para todas las propiedades anteriores, sin embargo, los de filas, columnas, velocidad, plegar y comprimir son de solo lectura.

# ¿Está configurada la campana visual?
$t->visualBell();
# Habilitar numeración de líneas
$t->lineNo(1);

Añadir Texto

Necesitarás algún texto para paginar. Puedes especificar el texto como parámetro al constructor:

texto => $texto

O añadir texto más tarde:

$t->add_text( $texto );

Si deseas añadir texto continuamente al paginador, debes configurar tu propio bucle de eventos e indicar a "more" que libere el control, por ejemplo:

eval{
    while( $t->more(RT=>.05) ){
      ...
      $t->add_text("Más texto para paginar");
    }
};

El bloque eval captura la excepción lanzada al finalizar el paginador para que tu propio programa pueda continuar. El parámetro RT indica que deseas proporcionar contenido en tiempo real. Este valor también se pasa a "ReadKey" en Term::ReadKey como el tiempo máximo de bloqueo por pulsación de tecla y debe estar entre 0 y 1, con valores más grandes intercambiando una mayor capacidad de respuesta de la interfaz por pequeños retrasos en la salida. También se puede usar un valor de -1 para solicitar sondeos no bloqueantes, pero es probable que no se comporte como esperas.

NOTA: Si Term::ReadKey no está cargado pero RT es verdadero, las actualizaciones de pantalla solo ocurrirán al pulsar una tecla.

Callback

También puedes pasar una referencia de código al atributo texto del constructor, que se llamará al llegar al "final del archivo"; en consecuencia, no es posible establecer la bandera eof para salir al final del archivo si lo haces.

$t->new( text=>sub{ } ); # eof=>0 está implícito

Alternativamente, puedes proporcionar una referencia a un array de dos elementos. El primero es un fragmento inicial de texto para cargar, y el segundo es el callback.

# Fibonacci
my($m, $n)=(1,1);
$t->new( text=> ["1\n", sub{ ($m,$n)=($n,$m+$n); return "$n\n"} ] );

Interfaz de Usuario

Hay varios marcadores especiales (marcas) que se pueden usar en la navegación.

^ Principio del archivo
$ Fin del archivo
' Ubicación anterior
" Listar marcas creadas por el usuario

"add_text" creará automáticamente marcas numéricas especiales cuando encuentre una secuencia de caracteres especial, permitiendo al usuario saltar a puntos predeterminados en el búfer. Las secuencias que coinciden con la siguiente expresión regular

/\cF\c]\cL\cE \[(\d+)\// # por ejemplo, ^F^]^L^E [3/4]

tendrán marcas que coinciden con $1 creadas que apuntan a la línea del búfer donde ocurre la secuencia.

I18N

El "dialog" método puede ser particularmente útil al mejorar el paginador. Acepta una cadena para mostrar y un tiempo de espera opcional para dormir antes de que el diálogo se borre. Si el tiempo de espera falta o es 0, el diálogo permanece hasta que se presiona una tecla.

my $t = IO::Pager::Perl->new();
$t->add_text("Text to display");
$t->add_func('!'=>\&boo);
$t->more();
sub boo{ my $self = shift; $self->dialog("BOO!", 1); }

Si añade funcionalidad adicional a su paginador, probablemente querrá cambiar el contenido del diálogo de ayuda o posiblemente la línea de estado. Use el "I18N" método para reemplazar el texto predeterminado o guardar texto para su propia interfaz.

#Get the default help text
my $help = $t->I18N('help');
#Minimal status line
$t->I18N('minihelp', "<h> help");

Los elementos de texto actuales disponibles para personalizar son:

404        - diálogo de texto de búsqueda no encontrado
continue   - texto para mostrar en la parte inferior del diálogo de ayuda
help       - texto del diálogo de ayuda, una lista de teclas y sus funciones
minihelp   - instrucciones básicas mostradas en la parte inferior de la pantalla
status     - mensaje breve para incluir en la línea de estado
top        - indicador de inicio de archivo
bottom     - indicador de fin de archivo
searchwrap - mensaje de que el paginador está a punto de buscar más coincidencias

prompt está destinado para compartir mensajes cortos que no merecen un diálogo, por ejemplo; al depurar. Necesitará llamar al "status" método después de establecerlo para refrescar la línea de estado de la pantalla, luego vaciar prompt y llamar a "status" de nuevo para borrar el mensaje.

Escalabilidad

El texto de ayuda se dividirá en dos horizontalmente en un carácter nulo si el texto es más ancho que la pantalla, y se mostrará en dos diálogos secuenciales.

De manera similar, el texto de estado se recortará en un carácter nulo para pantallas estrechas.

ADVERTENCIAS

UN*X

Este módulo actualmente solo funciona en un entorno tipo UN*X.

Rendimiento

Por simplicidad, la implementación actual carga el mensaje completo a ver de una vez; por lo tanto no requiere una distinción entre contenido canalizado y archivos. Esto puede requerir memoria significativa para archivos grandes.

Termcap

Este módulo usa Termcap, que ha sido obsoleto por el Open Group, y puede no ser soportado por su sistema operativo por mucho más tiempo.

Si la entrada termcap para su terminal antigua y especializada es incorrecta o incompleta, este módulo puede llenar su pantalla con texto ininteligible, o volver a un modo sin características.

Eventualmente, el soporte para Terminfo también puede ser añadido.

Señales

IO::Pager::Perl establece un manejador de señal global para SIGWINCH, esta es la única manera en que puede detectar y acomodar efectivamente cambios en el tamaño del terminal. Si también necesita notificación de esta señal, el manejador activará cualquier callback asignado al WINCH atributo del "new" método.

WINCH no está disponible en Windows. Necesitará refrescar manualmente su pantalla ^L si redimensiona el terminal en Windows para limpiar el texto, sin embargo, esto no cambiará el tamaño del paginador en sí.
