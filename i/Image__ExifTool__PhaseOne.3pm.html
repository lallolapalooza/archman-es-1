NOMBRE

Image::ExifTool::PhaseOne - etiquetas de notas del fabricante Phase One

SINOPSIS

Este módulo es cargado automáticamente por Image::ExifTool cuando es requerido.

DESCRIPCIÓN

Este módulo contiene las definiciones requeridas por Image::ExifTool para decodificar las notas del fabricante Phase One.
