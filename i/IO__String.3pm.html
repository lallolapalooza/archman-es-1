NOMBRE

IO::String - Emula la interfaz de archivo para cadenas en memoria

SINOPSIS

use IO::String;
$io = IO::String->new;
$io = IO::String->new($var);
tie *IO, 'IO::String';
# leer datos
<$io>;
$io->getline;
read($io, $buf, 100);
# escribir datos
print $io "cadena\n";
$io->print(@data);
syswrite($io, $buf, 100);
select $io;
printf "Texto: %s\n", $str;

DESCRIPCIÓN

El módulo "IO::String" proporciona la interfaz "IO::File" para cadenas en memoria. Un objeto "IO::String" puede adjuntarse a una cadena y permite utilizar las operaciones de archivo normales para leer o escribir datos, así como para buscar en diferentes ubicaciones de la cadena. Esto es útil cuando se desea utilizar un módulo de biblioteca que solo proporciona una interfaz a manejadores de archivo sobre datos que se tienen en una variable de cadena.

Tenga en cuenta que perl-5.8 y versiones posteriores tienen soporte integrado para archivos "en memoria", que se configuran pasando una referencia en lugar de un nombre de archivo a la llamada open(). La razón para usar este módulo es que lo hace compatible con versiones anteriores de Perl.

El módulo "IO::String" proporciona una interfaz compatible con "IO::File" tal como se distribuye con IO-1.20, pero los siguientes métodos no están disponibles: new_from_fd, fdopen, format_write, format_page_number, format_lines_per_page, format_lines_left, format_name, format_top_name.

Los siguientes métodos son específicos de la clase "IO::String":

$io = IO::String->new
$io = IO::String->new( $cadena )
El constructor devuelve un objeto "IO::String" recién creado. Acepta un argumento opcional, que es la cadena de la que leer o en la que escribir. Si no se proporciona ningún argumento $cadena, se asigna un búfer interno (inicialmente vacío).

El objeto "IO::String" devuelto está enlazado a sí mismo. Esto significa que también puede utilizar la mayoría de las funciones integradas de E/S de Perl en él: readline, <>, getc, print, printf, syswrite, sysread, close.

$io->open
$io->open( $cadena )
Adjunta un objeto IO::String existente a otra $cadena, o asigna un nuevo búfer interno (si no se proporciona ningún argumento). La posición se restablece a 0.
$io->string_ref
Devuelve una referencia a la cadena que está adjunta al objeto "IO::String". Es más útil cuando se deja que "IO::String" cree un búfer interno en el que escribir.
$io->pad
$io->pad( $caracter )
Especifica el relleno que se utilizará si la cadena se extiende mediante los métodos seek() o truncate(). Es un solo carácter y por defecto es "\0".
$io->pos
$io->pos( $nuevapos )
Una interfaz más para leer y establecer la posición actual de lectura /escritura dentro de la cadena (los métodos normales getpos/setpos/tell/seek también están disponibles). El método pos() siempre devuelve la posición anterior y, si se le pasa un argumento, establece la nueva posición.

Existe (deliberadamente) una diferencia entre los métodos setpos() y seek() en que seek() extiende la cadena (con el relleno especificado) si se va a una ubicación más allá del final, mientras que setpos() simplemente vuelve al final. Si se utiliza truncate() para extender la cadena, funciona como seek().

ERRORES

En las versiones de Perl anteriores a la 5.6, la interfaz TIEHANDLE era incompleta. Si utiliza una versión de Perl de este tipo, seek(), tell(), eof(), fileno(), binmode() no harán nada en un manejador "IO::String". Consulte perltie para obtener más detalles.

VER TAMBIÉN

IO::File, IO::Stringy, "open" in perlfunc
