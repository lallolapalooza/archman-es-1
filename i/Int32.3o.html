Enteros de 32

bits.

Este módulo proporciona operaciones sobre el tipo int32 de enteros con signo de 32 bits. A diferencia del tipo incorporado int, se garantiza que el tipo int32 tenga exactamente 32 bits de ancho en todas las plataformas. Todas las operaciones aritméticas sobre int32 se realizan módulo

2^32.

Aviso de rendimiento: los valores de tipo int32 ocupan más espacio de memoria que los valores de tipo int, y las operaciones aritméticas sobre int32 son generalmente más lentas que las de int. Utilice int32 solo cuando la aplicación requiera aritmética exacta de 32

bits.

Los literales para enteros de 32 bits se sufijan con

l: 
      let zero: int32 = 0l
      let one: int32 = 1l
      let m_one: int32 =
-1l

val shift_left : int32 -> int ->

int32

Int32.shift_left x y desplaza x a la izquierda en y bits. El resultado es indeterminado si y < 0 o y >=

32.

val shift_right : int32 -> int ->

int32

Int32.shift_right x y desplaza x a la derecha en y bits. Este es un desplazamiento aritmético: el bit de signo de x se replica e inserta en los bits vacantes. El resultado es indeterminado si y < 0 o y >=

32.

val shift_right_logical : int32 -> int ->

int32

Int32.shift_right_logical x y desplaza x a la derecha en y bits. Este es un desplazamiento lógico: se insertan ceros en los bits vacantes independientemente del signo de x. El resultado es indeterminado si y < 0 o y >=

32.

val of_int : int ->

int32

Convierte el entero dado (tipo int) en un entero de 32 bits (tipo int32). En plataformas de 64 bits, el argumento se toma módulo

2^32.

val to_int : int32 ->

int

Convierte el entero de 32 bits dado (tipo int32) en un entero (tipo int). En plataformas de 32 bits, el entero de 32 bits se toma módulo 2^31, es decir, se pierde el bit de orden superior durante la conversión. En plataformas de 64 bits, la conversión es

exacta.

val of_float : float ->

int32

Convierte el número de punto flotante dado en un entero de 32 bits, descartando la parte fraccionaria (truncando hacia 0). Si el número de punto flotante truncado está fuera del rango [ Int32.min_int, Int32.max_int], no se lanza ninguna excepción y se devuelve un entero indeterminado, dependiente de la

plataforma.

val to_float : int32 ->

float

Convierte el entero de 32 bits dado en un número de punto

flotante.

val of_string : string ->

int32

Convierte la cadena dada en un entero de 32 bits. La cadena se lee en decimal (por defecto, o si la cadena comienza con 0u) o en hexadecimal, octal o binario si la cadena comienza con 0x, 0o o 0b respectivamente

.

El prefijo 0u lee la entrada como un entero sin signo en el rango [0, 2*Int32.max_int+1]. Si la entrada excede Int32.max_int, se convierte en el entero con signo Int32.min_int + entrada - Int32.max_int -

1.

El carácter _ (guion bajo) puede aparecer en cualquier lugar de la cadena y se

ignora.

Lanza Failure si la cadena dada no es una representación válida de un entero, o si el entero representado excede el rango de enteros representables en el tipo int32

.

val of_string_opt : string -> int32

option

val bits_of_float : float ->

int32

Devuelve la representación interna del float dado según la distribución de bits del 'formato simple' de punto flotante IEEE 754. El bit 31 del resultado representa el signo del float; los bits 30 a 23 representan el exponente (sesgado); los bits 22 a 0 representan la

mantisa.
