NOMBRE

INN::Utils::Shlock - Envoltorio alrededor del programa shlock

DESCRIPCIÓN

Este módulo Perl envuelve el programa shlock(8) para que pueda ser utilizado fácilmente. Llamar a shlock es más portable que usar flock(2) y su función Perl correspondiente porque esta función no funciona como se espera en todos los sistemas existentes.

Ver la documentación de shlock(8) para más información.

Usar INN::Utils::Shlock es directo:

use lib '<pathnews>/lib/perl';
use INN::Utils::Shlock;
my $lockfile = "myprogram.LOCK";
# Adquirir un bloqueo.
INN::Utils::Shlock::lock($lockfile);
# Hacer lo que quieras. El bloqueo previene accesos concurrentes.
# Desbloquear.
INN::Utils::Shlock::unlock($lockfile);

Estas dos funciones retornan 1 si tienen éxito, 0 si fallan. Por ejemplo, el éxito del (des)bloqueo puede ser verificado como:

INN::Utils::Shlock::lock($lockfile)
    or die "no se puede crear el archivo de bloqueo";

o:

if (! INN::Utils::Shlock::lock($lockfile, 4)) {
    die "rendirse después de 4 intentos para crear el archivo de bloqueo";
}

En lugar de llamar a "unlock(lockfile)", se puede llamar a la función "releaselocks()". Elimina cualquier bloqueo sobrante, lo cual es útil cuando se usan varios bloqueos diferentes. Otro uso posible es llamarla en un bloque de código END:

END {
    # En caso de que salgamos, mientras mantenemos un bloqueo.
    INN::Utils::Shlock::releaselocks();
}

INTERFAZ

lock(lockfile)
Intenta crear un archivo de bloqueo llamado lockfile.

Esta función retorna 1 si tiene éxito, 0 si falla.

lock(lockfile, intentos)
Intenta crear un archivo de bloqueo llamado lockfile. Si falla, los intentos de bloqueo se repiten una vez cada 2 segundos durante un máximo de intentos veces (incluyendo el primer intento fallido).

Esta función retorna 1 si tiene éxito, 0 si falla.

lock(lockfile, intentos, retraso)
Intenta crear un archivo de bloqueo llamado lockfile. Si falla, los intentos de bloqueo se repiten una vez cada retraso segundos durante un máximo de intentos veces (incluyendo el primer intento fallido).

Nota: "lock(lockfile)" es equivalente a "lock(lockfile, 1, 2)".

Esta función retorna 1 si tiene éxito, 0 si falla.

releaselocks()
Elimina todos los archivos de bloqueo creados previamente llamando a la función "lock(lockfile)".

Esta función retorna el número de archivos de bloqueo eliminados.

unlock(lockfile)
Elimina el archivo llamado lockfile.

Esta función retorna 1 si tiene éxito, 0 si falla.
