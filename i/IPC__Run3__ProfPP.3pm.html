NOMBRE

IPC::Run3::ProfPP - Genera informes a partir de datos de perfilado de IPC::Run3

SINOPSIS

DESCRIPCIÓN

Utilizado por IPC::Run3 y/o run3profpp para imprimir informes de perfilado para lectores humanos. Utilice otras clases para extraer datos de otras maneras.

Los métodos de salida son de texto plano, anule estos (consulte el código fuente por ahora) para proporcionar otros formatos.

Esta clase genera informes sobre cada llamada a run3_exit() y app_exit().

MÉTODOS

"IPC::Run3::ProfPP->new()"

Devuelve un nuevo objeto de informes de perfilado.

"$profpp->handle_app_call()"

"$profpp->handle_app_exit()"

"$profpp->handle_run_exit()"
