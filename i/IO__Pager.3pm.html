IO::Pager - Selecciona un paginad

or (posiblemente basado en perl)
y le envía texto si es un TTY

SINOPSI

S 
# Selecciona un paginador apropiado y establece la variable de entorno PAGER
use IO::Pager;
# TIMTOWTDI Orientado a objetos
{
  # open()                           # Usa todos los valores por defecto.
  my $object = new IO::Pager;
  # open FILEHANDLE                  # Unbuffered es la subclase por defecto
  my $object = new IO::Pager *STDOUT;
  # open FILEHANDLE,EXPR             # Especifica la subclase
  my $object = new IO::Pager *STDOUT,  'Unbuffered';
  # Instanciación directa de subclase    # FH es opcional
  use IO::Pager::Unbuffered;
  my $object = new IO::Pager::Unbuffered  *STDOUT;
  $object->print("OO brillante...\n") while 1;
  print "Algún otro texto enviado a STODUT, quizás desde una rutina externa."
  # $object sale del ámbito y el manejador de archivo se cierra automáticamente
}
# TIMTOWTDI Procedimental
{
  # open FILEHANDLE                    # Unbuffered es la subclase por defecto
  my $token = IO::Pager::open *STDOUT;
  # open FILEHANDLE,EXPR               # Especifica la subclase
  my $token = IO::Pager::open *STDOUT,  'Unbuffered';
  # open FILEHANDLE,MODE,EXPR          # En lugar de un binmode() separado
  my $token = IO::Pager::open *STDOUT, '|-:utf8', 'Unbuffered';
  print <<"  HEREDOC" ;
  ...
  Un montón de texto más tarde
  HEREDOC
  # $token sale del ámbito y el manejador de archivo se cierra automáticamente
}
{
  # También puedes usar manejadores de archivo escalares...
  my $token = IO::Pager::open(my $FH) or warn($!); XXX
  print $FH "¡Sin globs ni palabras desnudas para nosotros, gracias!\n" while 1;
}

DESCRIPCIÓ

N

IO::Pager puede usarse para localizar un paginador disponible y establecer la variable de entorno PAGER (ver "NOTAS"). También es una fábrica para crear objetos de E/S como IO::Pager::Buffered y IO::Pager::

Unbuffered.

Las subclases de IO::Pager están diseñadas para decidir programáticamente si canalizar o no la salida de un manejador de archivo a un programa especificado en PAGER. Las subclases pueden implementar solo los métodos de manejo de E/S deseados e heredar el resto de los descritos a continuac

ión de IO::Pager. Para cualquier otra cosa, YMMV. Ver la subclas
e apropiada para los detalles específicos de la implementación.

:LOG([>>ARCHIVO]

)

IO::Pager implementa una pseudo-capa de E/S para capturar la salida y enviarla a un archivo, similar a tee(1). Aunque está limitado a un archivo, esta característica es perl puro y no añade

dependencias.

Puedes indicar en qué archivo almacenar entre paréntesis, de lo contrario el valor por defecto es "$$.log". También puedes usar un indicador implícito (sin indicador) o explícito (>) para sobrescribir un archivo existente, o uno explícito (>>) para añadir a un archivo de registro. Por

ejemplo: 
binmode(*STDOUT, ':LOG(clobber.log)');
...
$STDOUT->binmode(':LOG(>>noclobber.log)')
;

eof( FILEHANDLE

)

Se usa en el idiomatismo de eval-hasta-eof descrito a continuación, IO::Pager manejará tuberías rotas de hijos fallecidos por ti de una de dos maneras. Si $ENV{IP_EOF} es falso, entonces el flujo del programa saldrá del bucle en SIGPIPE, este es el comportamiento por defecto. Si la variable es verdadera, entonces el programa continúa ejecutándose con la salida para el manejador de archivo paginado previamente dirigida al flujo STDOUT; con más precisión, el manejador de archivo se reabre al descriptor de archivo
