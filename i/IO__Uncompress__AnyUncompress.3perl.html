Devuelve los datos, si los hay, que están presentes inmediatamente después del flujo de datos comprimidos una vez que la descompresión está completa. Solo tiene sentido llamar a este método una vez que el final del flujo de datos comprimidos hayan

encontrado.

Esta opción se puede utilizar cuando hay información útil inmediatamente después del flujo de datos comprimido, y no se conoce la longitud del flujo de datos

comprimido.

Si la entrada es un búfer, "trailingData" devolverá todo desde el final del flujo de datos comprimido hasta el final del

búfer.

Si la entrada es un manejador de archivo, "trailingData" devolverá los datos que quedan en el búfer de entrada del manejador de archivo una vez que se ha alcanzado el final del flujo de datos comprimido. Luego puede usar el manejador de archivo para leer el resto del archivo de

entrada.

No se moleste en usar "trailingData" si la entrada es un nombre de

archivo.
