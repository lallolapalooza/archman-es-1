Descripción detallada

El Widget Contador.

Un Contador consta de una etiqueta que muestra un número y uno o más (hasta tres) botones a cada lado de la etiqueta que se pueden usar para incrementar o decrementar el valor del contador.

Un contador tiene un rango desde un valor mínimo a un valor máximo y un tamaño de paso. Cuando la propiedad de envoltorio está activada, el contador es circular.

El número de pasos con los que un botón incrementa o decrementa el valor se puede especificar usando setIncSteps(). El número de botones se puede cambiar con setNumButtons().

Ejemplo:

#include <qwt_counter.h>
  QwtCounter *counter = new QwtCounter(parent);
  counter->setRange(0.0, 100.0);                  // De 0.0 a 100
  counter->setSingleStep( 1.0 );                  // Tamaño de paso 1.0
  counter->setNumButtons(2);                      // Dos botones cada lado
  counter->setIncSteps(QwtCounter::Button1, 1);   // El botón 1 incrementa 1 paso
  counter->setIncSteps(QwtCounter::Button2, 20);  // El botón 2 incrementa 20 pasos
  connect(counter, SIGNAL(valueChanged(double)), myClass, SLOT(newValue(double)));

QwtCounter::QwtCounter (QWidget * parent = NULL) [explicit]

El contador se inicializa con un rango de [0.0, 1.0] con 0.01 como tamaño de paso único. El valor es inválido.

El número predeterminado de botones es 2. Los incrementos predeterminados son:

  • Botón 1: 1 paso
  • Botón 2: 10 pasos
  • Botón 3: 100 pasos

DESCRIPCIÓN DETALLADA

Un componente de control numérico.

El QwtCounter es un control numérico, que puede ser controlado con las teclas de flecha, el ratón (con la rueda del ratón) y el teclado.

Un QwtCounter tiene un valor que se puede observar (ver QwtAbstractSlider). El rango del valor se puede ajustar entre minVal y maxVal. minVal y maxVal pueden ser ajustados por setRange().

El paso único se puede ajustar por setSingleStep(). El valor predeterminado es 1.0.

Si el wrapping está activado (ver setWrapping()), el QwtCounter se comportará como un contador cíclico. Por ejemplo, si el valor máximo es 100 y el usuario incrementa el valor 100, el valor se convierte en 0.
