Descripción detallada

Una clase para dibujar marcadores.

Un marcador puede ser un símbolo, una etiqueta o una combinación de ellos, que se puede dibujar alrededor de un punto central dentro de un rectángulo delimitador.

La función miembro setSymbol() asigna un símbolo al marcador. El símbolo se dibuja en el punto especificado.

Con setLabel(), se puede asignar una etiqueta al marcador. La función miembro setLabelAlignment() especifica dónde se dibuja la etiqueta. Todas las constantes Align* en Qt::AlignmentFlags (ver la documentación de Qt) son válidas. La alineación se refiere al punto central del marcador, lo que significa, por ejemplo, que la etiqueta se pintaría arriba a la izquierda del punto central si la alineación se estableciera en AlignLeft|AlignTop.

Descripción Detallada

Esta clase proporciona un marcador polar para añadir información o símbolos a un gráfico polar.

Los marcadores polares son elementos polares que se utilizan para indicar puntos específicos en un gráfico polar. Son útiles para resaltar datos importantes, mostrar valores anómalos o simplemente para añadir anotaciones visuales.

La clase QwtPolarMarker hereda de QwtPolarItem y proporciona funcionalidades para establecer la posición del marcador (por acimut y radio), el símbolo a mostrar y otras propiedades visuales.

La posición de un marcador se define mediante un ángulo de acimut (en grados) y un radio. El símbolo utilizado para representar el marcador puede ser cualquier instancia de la clase QwtSymbol, lo que permite una gran flexibilidad en la personalización visual.

Además de la posición y el símbolo, QwtPolarMarker permite controlar la visibilidad, el nivel de apilamiento (z-order) y el recorte del marcador.

Se pueden añadir múltiples marcadores a un gráfico polar para representar diferentes puntos de datos o para fines de anotación. La clase QwtPolarPlot gestiona la adición y visualización de estos marcadores.
