Descripción Detallada

QwtPlotIntervalCurve representa una serie de muestras, donde cada valor está asociado a un intervalo ( $[y1,y2] = f(x)$ ).

La representación depende del style() y de un symbol() opcional que se muestra para cada intervalo. QwtPlotIntervalCurve podría usarse para mostrar barras de error o el área entre 2 curvas.

Detailed Description

An interval curve is a curve which displays intervals for each data point. The intervals can be displayed as horizontal, vertical or rectangular spans.

The intervals are defined by QwtPlotIntervalCurve::setData. For each data point (x, y) a second y-value (y_interval) can be specified. The interval span is then calculated from y - y_interval to y + y_interval.

The orientation of the intervals can be controlled by QwtPlotIntervalCurve::setOrientation.

The appearance of the intervals can be controlled by QwtPlotIntervalCurve::setSymbol.

The default plot item is a horizontal interval curve with QwtPlotIntervalCurve::CurveStyle set to QwtPlotIntervalCurve::SolidLine.
