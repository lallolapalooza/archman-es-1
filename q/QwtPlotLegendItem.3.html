Descripción Detallada

Una clase que dibuja una leyenda dentro del lienzo del gráfico.

QwtPlotLegendItem se puede utilizar para dibujar dentro del lienzo del gráfico. Se puede usar junto con un QwtLegend o en su lugar para tener más espacio para el lienzo del gráfico.

A diferencia de QwtLegend, el elemento de leyenda no es interactivo. Para identificar clics del ratón en un elemento de leyenda, se debe instalar un filtro de eventos que capture los eventos del ratón en el lienzo del gráfico. Las geometrías de los elementos de la leyenda están disponibles usando legendGeometries().

El elemento de leyenda se alinea al lienzo del gráfico según sus indicadores de alineación (alignment). Puede tener un fondo para toda la leyenda (generalmente semitransparente) o para cada elemento de la leyenda.

Nota

Un QwtLegend externo con un fondo transparente encima del lienzo del gráfico podría ser otra opción con un efecto similar.

Detailed Description

Plot legend item class.

This class is the base class for legend items representing plot items. A legend item is responsible to visualize the content of a legend entry.

A legend item is a composite of multiple items:

  • A symbol (optional)
  • A text label (optional)

The symbol can be a legend marker (like a curve color bar or a marker symbol) or the legend item itself can draw its own representation of the plot item. The latter is the default behavior.

The appearance of the legend item can be controlled by setting

pens, brushes, fonts and spacing parameters.
