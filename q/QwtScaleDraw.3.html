Descripción detallada

Una clase para dibujar escalas.

QwtScaleDraw se puede usar para dibujar escalas lineales o logarítmicas. Una escala tiene una posición, una alineación y una longitud, que se pueden especificar. Las etiquetas se pueden rotar y alinear a las marcas usando setLabelRotation() y setLabelAlignment().

Después de que una división de escala se haya especificado como un objeto QwtScaleDiv usando QwtAbstractScaleDraw::setScaleDiv(const QwtScaleDiv &s), la escala se puede dibujar con la función miembro QwtAbstractScaleDraw::draw().

Detailed Description

Abstract base class for scale drawings. This class abstracts the details of drawing scales from the scale itsself. Scales are not drawn directly by the scale widget, but by a scale draw object. This way, different kinds of scales (e.g. linear, logarithmic, circular) can be drawn using the same scale widget.

The scale draw object calculates the positions of the ticks and labels and delegates the actual drawing to the paint device.

The abstract interface is defined by the virtual functions in QwtAbstractScaleDraw. QwtScaleDraw adds functions to control the alignment and spacing of the scale.

The default implementation of QwtAbstractScaleDraw::label() renders the label text with its own flags and rotation, which are controllable by setLabelAlignment() and setLabelRotation().

The abstract member function QwtAbstractScaleDraw::draw() is implemented by iterating over all ticks and labels and calling the virtual functions processTick() and label().

The length of the scale's backbone is controlled by setLength().

The position of the scale's backbone is controlled by setPos().

The orientation of the scale is determined by the alignment. BottomScale and TopScale mean horizontal scales, while LeftScale and RightScale mean vertical scales.

void QwtScaleDraw::setLabelAlignment (Qt::Alignment alignment)

Change the label flags. Labels are aligned to the point tick length + spacing away from the backbone.

The alignment is relative to the orientation of the label text. In case of an flags of 0 the label will be aligned depending on the orientation of the scale:

QwtScaleDraw::TopScale: Qt::AlignHCenter | Qt::AlignTop
QwtScaleDraw::BottomScale: Qt::AlignHCenter | Qt::AlignBottom
QwtScaleDraw::LeftScale: Qt::AlignLeft | Qt::AlignVCenter
QwtScaleDraw::RightScale: Qt::AlignRight | Qt::AlignVCenter
Changing the alignment is often necessary for rotated labels.

Parameters

alignment Or'd Qt::AlignmentFlags see <qnamespace.h>

See also

setLabelRotation(), labelRotation(), labelAlignment()

Warning

The various alignments might be confusing. The alignment of the label is not the alignment of the scale and is not the alignment of the flags ( QwtText::flags() ) returned from QwtAbstractScaleDraw::label().
