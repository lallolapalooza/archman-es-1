Descripción detallada

template<typename T>

class QwtSeriesData< T >" Interfaz abstracta para iterar sobre muestras.

Qwt ofrece varias implementaciones de la API de QwtSeriesData, pero en situaciones donde los datos de un formato específico de la aplicación necesitan ser mostrados, sin tener que copiarlos, se recomienda implementar un acceso de datos individual.

Una subclase de QwtSeriesData<QPointF> debe implementar:

  • size()
    Debería devolver el número de puntos de datos.
  • sample()
    Debería devolver los valores x e y de la muestra en una posición específica como un objeto QPointF.
  • boundingRect()
    Debería devolver el rectángulo delimitador de la serie de datos. Se utiliza para la autoescala y puede ayudar a ciertos algoritmos para mostrar los datos. Puedes usar qwtBoundingRect() para una implementación, pero a menudo es posible implementar un algoritmo más eficiente dependiendo de las características de la serie. El miembro cachedBoundingRect está destinado a almacenar en caché el rectángulo calculado.

template<typename T > virtual QRectF QwtSeriesData< T >::boundingRect () const [pure virtual]

Calcula el rectángulo delimitador de todas las muestras

El rectángulo delimitador es necesario para la autoescala y puede utilizarse para varias optimizaciones de pintura.

qwtBoundingRect(...) ofrece implementaciones lentas que iteran sobre las muestras. Para conjuntos grandes, se recomienda implementar algo más rápido, por ejemplo, almacenando en caché el rectángulo delimitador.

Establece el 'rectángulo de interés'

QwtPlotSeriesItem define el área actual del lienzo del gráfico como 'rectángulo de interés' ( QwtPlotSeriesItem::updateScaleDiv() ). Puede usarse para implementar diferentes niveles de detalle.

La implementación predeterminada no hace nada.
