Descripción detallada

Un elemento de gráfico que muestra una etiqueta de texto.

QwtPlotTextLabel muestra una etiqueta de texto alineada al lienzo del gráfico.

A diferencia de QwtPlotMarker, la posición de la etiqueta no está relacionada con las coordenadas del gráfico.

Dado que dibujar texto es una operación costosa, la etiqueta se almacena en caché en un pixmap para acelerar los replots.

Ejemplo

El siguiente código muestra cómo añadir un título. 
QwtText titulo( "Título del gráfico" );
titulo.setRenderFlags( Qt::AlignHCenter | Qt::AlignTop );
QFont fuente;
fuente.setBold( true );
titulo.setFont( fuente );
QwtPlotTextLabel *tituloItem = new QwtPlotTextLabel();
tituloItem->setText( titulo );
tituloItem->attach( plot );
