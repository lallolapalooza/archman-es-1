Descripción Detallada

Clase base abstracta para elementos de gráfico de barras.

A diferencia de casi todos los demás elementos del gráfico, los gráficos de barras no se pueden mostrar dentro de su rectángulo delimitador y necesitan una API especial sobre cómo calcular el ancho de las barras y cómo afectan la disposición del gráfico adjunto.

void QwtPlotAbstractBarChart::getCanvasMarginHint (const QwtScaleMap & xMap, const QwtScaleMap & yMap, const QRectF & canvasRect, double & left, double & top, double & right, double & bottom) const [override], [virtual]

Calcula una pista para el margen del lienzo. Los gráficos de barras necesitan reservar espacio para mostrar las barras de la primera y última muestra. La pista se calcula a partir de layoutHint() dependiendo de layoutPolicy().

Los márgenes están en coordenadas del dispositivo de destino (píxeles en pantalla)

Parámetros

xMap Mapea valores x a coordenadas de píxeles.
yMap Mapea valores y a coordenadas de píxeles.
canvasRect Rectángulo de contenido del lienzo en coordenadas del pintor
left Devuelve el margen izquierdo
top Devuelve el margen superior
right Devuelve el margen derecho
bottom Devuelve el margen inferior

Retorna

Margen

void QwtPlotAbstractBarChart::setBaseline (double value)

Establece la línea de base. La línea de base es el origen para el gráfico. Cada barra se dibuja desde la línea de base en la dirección del valor de la muestra. En el caso de una orientation() horizontal, la línea de base se interpreta como un valor en el eje X, de lo contrario, como un valor en el eje Y.

El valor predeterminado para la línea de base es 0.

Parámetros

value Valor para la línea de base
