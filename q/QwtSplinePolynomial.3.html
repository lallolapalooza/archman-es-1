Descripción detallada

Un polinomio cúbico sin término constante.

QwtSplinePolynomial es un polinomio de 3er grado de la forma: y = c3 * x³ + c2 * x² + c1 * x;

QwtSplinePolynomial se usa generalmente en combinación con la interpolación de polígonos, donde no es necesario almacenar un término constante ( c0 ), ya que la traslación se conoce a partir de los puntos del polígono correspondientes.

NAME

QwtSplinePolynomial — polynomial spline class.

SYNOPSIS

#include <qwt_spline_polynomial.h>

class QwtSplinePolynomial : public QwtSpline
{
public:
    QwtSplinePolynomial( int order = 3 );
    ~QwtSplinePolynomial();

    virtual void setPoints( const QVector<QPointF>& ) const;
    virtual void setPoints( const QVector<double>&, const QVector<double>& ) const;

    double slopeAt( double x ) const;
    double valueAt( double x ) const;

};

Detailed Description

A polynomial spline is a piecewise polynomial function. For a cubic spline (the default), it is composed of cubic polynomials.

The value and slope of the spline can be calculated at any point within the range of the control points.
