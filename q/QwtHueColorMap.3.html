Descripción detallada

QwtHueColorMap varía el valor de tono en el modelo HSV de colores.

QwtHueColorMap puede usarse para establecer una mapa de color fácilmente, que se repite ciclicamente por todas las colores. Cada ciclo tiene 360 pasos diferentes.

Los valores para value y saturation están en el rango de 0 a 255 y no dependen del valor de datos a ser mapado.

void QwtHueColorMap::setHueInterval (int hue1, int hue2)

Establece el intervalo de la coordenada de tono

hue1 y hue2 deben ser números positivos y pueden ser > 360 para definir ciclos. Por ejemplo, 420 a 240 define un mapa de amarillo/rojo/magenta/azul.

Parámetros

hue1 Coordenada de tono inicial
hue2 Coordenada de tono final
