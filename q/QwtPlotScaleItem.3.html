Descripción detallada

Una clase que dibuja una escala dentro del lienzo del gráfico.

QwtPlotScaleItem se puede usar para dibujar un eje dentro del lienzo del gráfico. Puede sincronizarse con uno de los ejes del gráfico, pero también puede mostrar sus propias marcas y etiquetas.

Está permitido sincronizar el elemento de escala con un eje deshabilitado. En gráficos con elementos de escala verticales y horizontales, podría ser necesario eliminar las marcas en las intersecciones, sobrecargando updateScaleDiv().

La escala puede estar en una posición específica (por ejemplo, 0.0) o puede alinearse a un borde del lienzo.

Ejemplo

El siguiente ejemplo muestra cómo reemplazar el eje izquierdo con un elemento de escala en la posición x 0.0. 
QwtPlotScaleItem *scaleItem = new QwtPlotScaleItem( QwtScaleDraw::RightScale, 0.0 );
scaleItem->setFont( plot->axisWidget( QwtAxis::YLeft )->font() );
scaleItem->attach(plot);
plot->setAxisVisible( QwtAxis::YLeft, false );

    Detailed Description

    A scale item is a plot item that displays a scale. The scale can be attached to one of the axes or be positioned independently. The appearance of the scale is controlled by a QwtScaleDraw object.

    The scale can be aligned to the canvas border by setBorderDistance(). Otherwise it is positioned using setPosition().

    In most cases the scale division is automatically managed by the plot. The scale division can be synchronized to the corresponding axis by calling setScaleDivFromAxis() (default). Otherwise the scale division has to be set manually using setScaleDiv().

    void QwtPlotScaleItem::setAlignment (int alignment)

    Sets the alignment of the scale.

    The alignment specifies the position of the scale and its ticks relative to the scale line.

    Possible values for the alignment are:

    • QwtScaleDraw::BottomScale: horizontal, ticks below
    • QwtScaleDraw::TopScale: horizontal, ticks above
    • QwtScaleDraw::LeftScale: vertical, ticks left
    • QwtScaleDraw::RightScale: vertical, ticks right

    For horizontal scales the position corresponds to QwtPlotItem::yAxis(), otherwise to QwtPlotItem::xAxis().

    void QwtPlotScaleItem::setBorderDistance (int distance)

    Align the scale to the canvas. If distance is >= 0 the scale will be aligned to a border of the contents rectangle of the canvas. If alignment() is QwtScaleDraw::LeftScale, the scale will be aligned to the right border, if it is QwtScaleDraw::TopScale it will be aligned to the bottom (and vice versa),

    If distance is < 0 the scale will be at the position().

    Parameters

    distance Number of pixels between the canvas border and the backbone of the scale.
