QMCSOURCE(3) Manual de funciones de biblioteca QMCSOURCE(3)

NOMBRE

QmcSource - gestiona contextos creados por todos los grupos

SINOPSIS EN C++

#include <QmcSource.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

La clase QmcSource mantiene una lista única de todas las fuentes de métricas en uso para minimizar la creación de nuevos contextos (ver pmNewContext(3)) cuando el contexto podría haberse duplicado (ver pmDupContext(3)). Esto también reduce la duplicación de descripciones de cada fuente.

En general, los usuarios de QMC solo necesitarán acceder a los métodos de QmcSource para obtener descripciones de fuentes para un objeto QmcContext(3). Toda la creación de contextos por parte del usuario debe ser manejada a través de QmcGroup(3).

DESTRUCTOR

~QmcSource();
Destructor.

CONSTRUCTORES

static QmcSource* getSource(int type, const char* source,
bool matchHosts)

Este método devolverá un objeto QmcSource que representa un contexto de type para source. El objeto QmcSource puede ser un objeto nuevo si la source no ha sido solicitada previamente. La gestión de memoria de los objetos QmcSource es manejada por QmcSource. Si todos los QmcContext(3) hacia el QmcSource han sido eliminados, el objeto QmcSource también será eliminado.

El indicador matchHosts controla el algoritmo que se usa para emparejar hosts con archivos. Si matchHosts es igual a false, este método no intentará emparejar un contexto de host con un contexto de fuente existente. Siempre se devolverá un objeto QmcSource en este caso, aunque el método QmcSource::status puede indicar que un contexto para source falló.

Si matchHosts es igual a true, los contextos de host se emparejarán con una fuente de archivo predefinida recopilada de esa source. Si no se han especificado previamente fuentes de archivo para la source, getSource devolverá un puntero NULL.

DIAGNÓSTICOS

Los mensajes de error se generan usando pmprintf(3) pero no se vacían. Es responsabilidad del usuario llamar a pmflush(3) para mostrar cualquier mensaje.

Se pueden activar diagnósticos adicionales agregando la opción pmc a la especificación de depuración global, como se describe en pmSetDebug(3).

VER TAMBIÉN

PMAPI(3), QMC(3), QmcContext(3), QmcGroup(3), pmDupContext(3), pmflush(3), pmNewContext(3) y pmprintf(3).
