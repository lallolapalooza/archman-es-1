Descripción Detallada

Un dispositivo de dibujo para gráficos escalables.

QwtGraphic es la representación de un gráfico adaptado para ser escalable. Al igual que QPicture, se inicializará mediante operaciones de QPainter y podrá reproducirse posteriormente en cualquier dispositivo de dibujo de destino.

Mientras que las representaciones de imagen habituales QImage y QPixmap no son escalables, Qt ofrece dos dispositivos de dibujo que podrían ser candidatos para representar un gráfico vectorial:

  • QPicture
    Desafortunadamente, QPicture fue olvidada cuando Qt4 introdujo motores de renderizado basados en punto flotante. Su API todavía usa enteros, lo que la hace inutilizable para un escalado adecuado.
  • QSvgRenderer/QSvgGenerator
    Desafortunadamente, QSvgRenderer oculta demasiada información sobre sus nodos en APIs internas que son necesarias para cálculos de diseño adecuados. Además, hereda de QObject y no se puede copiar como QImage/QPixmap.

QwtGraphic mapea todos los primitivos de dibujo escalables a un QPainterPath y los almacena junto con los cambios de estado del pintor (pluma, pincel, transformación...) en una lista de QwtPaintCommands. Para ser un QPaintDevice completo, también almacena pixmaps o imágenes, lo cual va un poco en contra de la idea de la clase, ya que estos objetos no se pueden escalar sin pérdida de calidad.

El principal problema al escalar un objeto QwtGraphic son las plumas utilizadas para dibujar los contornos de los paths del pintor. Mientras que las plumas no cosméticas ( QPen::isCosmetic() ) se escalan con la misma proporción que el path, las plumas cosméticas tienen un ancho fijo. Un gráfico puede tener paths con plumas diferentes: cosméticas y no cosméticas.

QwtGraphic almacena en caché 2 rectángulos diferentes:

  • rectángulo de puntos de control
    El rectángulo de puntos de control es el rectángulo delimitador de todos los rectángulos de puntos de control de los paths del pintor, o el rectángulo de destino de los pixmaps/imágenes.
  • rectángulo delimitador
    El rectángulo delimitador extiende el rectángulo de puntos de control con lo necesario para dibujar el contorno con una pluma no escalada.

Dado que el desplazamiento para dibujar el contorno depende de la forma del path del pintor (la punta de un triángulo es diferente que el lado plano), escalar con una relación de aspecto fija siempre necesita ser calculado a partir del rectángulo de puntos de control.

RenderPensUnscaled
Al renderizar un QwtGraphic, se establece internamente en render() un escalado específico entre controlPointRect() y las coordenadas del rectángulo de destino.

Cuando RenderPensUnscaled está activado, este escalado específico se aplica solo a los puntos de control, pero no a

las plumas. Todas las demás transformaciones de pintor (configuradas por el código de la aplicación) deberían funcionar como de costumbre.

Detailed Description

This class represents a graphic that can be painted into a QPainter. The graphic can be an object of type Image, Pixmap, Printer or Document.

The graphic itself is a QwtPaintDevice and can be used whenever a paint device is needed.

In opposition to a QwtPlotPrintFilter the QwtGraphic is not meant to be a tool for adapting plot properties for printouts, but for collecting graphic elements that are supposed to be printed.

When a QwtGraphic is printed, its attributes like resolution and bounding-rectangle are taken into account.

The default size of the graphic is initialized by the constructor argument. When the size needs to be adjusted to a new dimension, the method widthForHeight or heightForWidth is used.

The transformation attributes like translation, scaling and rotation can be controlled with translate, scale, setMatrix.
