Descripción detallada

Un lienzo alternativo para un QwtPlot derivado de QGLWidget.

QwtPlotGLCanvas implementa lo más básico para actuar como lienzo dentro de un widget QwtPlot. Podría extenderse a una alternativa con todas las funciones de QwtPlotCanvas en una futura versión de Qwt.

Aunque QwtPlotGLCanvas no deriva de QFrame, imita su API. Al usar hojas de estilo, soporta el modelo de caja, además de fondos con bordes redondeados.

Desde Qt 5.4 está disponible QOpenGLWidget, que es utilizado por QwtPlotOpenGLCanvas.

Ver también

QwtPlot::setCanvas(), QwtPlotCanvas, QwtPlotOpenGLCanvas

Nota

Con Qt4, puede que desees usar el motor de pintura QPaintEngine::OpenGL (ver QGL::setPreferredPaintEngine() ). En un sistema de pruebas Linux, QPaintEngine::OpenGL2 muestra problemas muy básicos como geometrías desplazadas.

Otra forma de obtener gráficos acelerados por hardware es usar un búfer fuera de pantalla OpenGL ( QwtPlotCanvas::OpenGLBuffer ) con QwtPlotCanvas. El rendimiento es peor que renderizar directamente a un QGLWidget, pero generalmente está mejor integrado en una aplicación de escritorio.

QwtPlotGLCanvas(3)

QwtPlotGLCanvas — Un lienzo para QwtPlot que usa OpenGL.

Sinopsis

#include <qwt_plot_gl_canvas.h>
class QwtPlotGLCanvas : public QwtPlotCanvas

Descripción

Este class extiende QwtPlotCanvas para poder renderizar el contenido de QwtPlot usando OpenGL.

El uso de OpenGL puede mejorar significativamente el rendimiento de renderizado, especialmente para gráficos complejos o cuando se actualizan con frecuencia.

Para usar QwtPlotGLCanvas, simplemente crea una instancia de él en lugar de QwtPlotCanvas al crear tu gráfico QwtPlot.

Instalación

Asegúrate de tener instalada la biblioteca Qwt y sus dependencias de desarrollo, incluido OpenGL. Puedes instalarla usando el gestor de paquetes de Arch Linux:

sudo pacman -S qwt

Uso

Aquí tienes un ejemplo básico de cómo usar QwtPlotGLCanvas:

#include <qwt_plot.h>
#include <qwt_plot_gl_canvas.h>
#include <qwt_plot_curve.h>
#include <qwt_point_data.h>

int main(int argc, char **argv) {
    QApplication app(argc, argv);

    QwtPlot plot;

    // Usar QwtPlotGLCanvas en lugar de QwtPlotCanvas
    plot.setCanvas(new QwtPlotGLCanvas()); 

    // ... (código para agregar curvas, ejes, etc. a QwtPlot) ...

    QwtPlotCurve *curve = new QwtPlotCurve();
    curve->setTitle("Datos de Ejemplo");
    curve->setPen(Qt::blue, 2);
    curve->attach(&plot);

    QVector<QPointF> data;
    data << QPointF(1.0, 1.0) << QPointF(2.0, 3.0) << QPointF(3.0, 2.0) << QPointF(4.0, 4.0);
    curve->setSamples(data);

    plot.replot();
    plot.show();

    return app.exec();
}

Notas

  • La compilación y ejecución de aplicaciones que usan OpenGL pueden requerir la instalación de paquetes de desarrollo de OpenGL (por ejemplo, mesa-libgl en Arch Linux).
  • El rendimiento mejorado de OpenGL puede depender de la complejidad del gráfico y de la potencia de la GPU.
  • Puede ser necesario configurar atributos de formato de OpenGL (por ejemplo, doble búfer, profundidad) si se encuentran problemas de renderizado.
