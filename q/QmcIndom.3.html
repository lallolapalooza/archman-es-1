QMCINDOM(3) Manual de funciones de biblioteca QMCINDOM(3)

NOMBRE

QmcIndom - contenedor para la descripción de un dominio de instancias

SINOPSIS EN C++

#include <QmcIndom.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

Un objeto QmcIndom representa un dominio de instancias de PMAPI(3). Esto incluye una descripción de todas las instancias en el dominio de instancias.

Una QmcInstance es una estructura utilizada para describir cada instancia en el dominio de instancias. Esto incluye:


- identificador interno. Si es menor que cero, la instancia se trata como una entrada NULA en la tabla de instancias.

- nombre externo

- contador de referencias, es decir, el número de objetos QmcMetric que hacen referencia a esta instancia.

- la posición probable de la instancia en el pmResult de un pmFetch(3). Esto también se utiliza para indicar la posición de la siguiente instancia NULA en la tabla de instancias, si esta entrada también es NULA.

- una bandera que indica si la instancia estaba en el último pmGetInDom(3).

El objeto QmcIndom tiene una lista de estructuras QmcInstance, y varias banderas y contadores para admitir dominios de instancias dinámicos donde las instancias pueden ir y venir con cada búsqueda y generación eficiente de perfiles.

CONSTRUCTORES

QmcIndom::QmcIndom(int type, QmcDesc &desc);
Llama a pmGetInDom(3) y pmGetInDomArchive(3) para contextos de host y archivo para obtener la lista completa de instancias para el dominio de instancias de tipo type e identificado en desc.

DOMINIOS DE INSTANCIAS DINÁMICOS

El soporte de dominios de instancias dinámicos para contextos en vivo es complejo, ya que muchas métricas pueden hacer referencia a cualquiera de las instancias en el dominio. Por lo tanto, la lista de instancias puede ser dispersa, ya que se debe mantener la posición de las instancias en la lista.

Cuando se actualiza el dominio de instancias, las instancias pueden eliminarse de la lista si no están en la nueva lista de instancias (tal como la devuelve pmGetInDom(3)) y no están referenciadas por ninguna métrica. Cada instancia en la nueva lista se compara con la lista antigua para determinar qué instancias siguen activas, y las nuevas instancias deben agregarse. Una instancia se considera la misma si tanto el identificador interno como el externo son los mismos. Las nuevas instancias se insertan primero en las posiciones de las instancias eliminadas antes de agregarse al final de la lista.

Este algoritmo es costoso (potencialmente O(N^2)).

bool changed() const;
Devuelve true si el dominio de instancias pudo haber cambiado en la última búsqueda.
void newFetch();
Restablece las banderas que podrían haber indicado que el dominio de instancias había cambiado. Esto es llamado por QmcContext::fetch.
void hasChanged();
Establece las banderas para indicar que el dominio de instancias pudo haber cambiado. Esto es llamado por QmcMetric::extractValues.
int update();
Actualiza el dominio de instancias como se describió anteriormente. En llamadas subsiguientes, antes de la próxima búsqueda, este método eliminará cualquier instancia que ya no esté referenciada sin actualizar la lista de instancias con una llamada a pmGetInDom(3).
uint_t numInsts() const;
Devuelve el número de instancias que no son NULAS.
uint_t numActiveInsts() const;
Devuelve el número de instancias que están activas según la última llamada a QmcIndom::update.
uint_t listLen() const;
Devuelve la longitud de la lista de instancias, incluidas las instancias NULAS.

PERFILES

El algoritmo para determinar el perfil más compacto utiliza el número de instancias (_instances.length()), el número de instancias referenciadas (_count), el número de instancias activas (_numActive) y el número de instancias activas referenciadas (_numActiveRef).


if (todas las instancias activas están referenciadas
    o no hay instancias activas)
        solicitar todas las instancias implícitamente
else if (el número de instancias referenciadas
         es menor que el número de instancias activas
         que no están referenciadas)
        eliminar todas las instancias del perfil
        agregar todas las instancias referenciadas
else
        agregar todas las instancias al perfil
        eliminar todas las instancias que no están referenciadas
bool diffProfile() const;
Devuelve true si el perfil ha cambiado potencialmente desde la última llamada a QmcIndom::genProfile.
int genProfile();
Genera un nuevo perfil para el dominio de instancias. Se devuelve un código de error de PMAPI(3) si la generación del perfil falló.

DIAGNÓSTICOS

Los mensajes de error se generan utilizando pmprintf(3) pero no se vacían. Es responsabilidad del usuario llamar a pmflush(3) para mostrar cualquier mensaje.

Se pueden activar diagnósticos adicionales agregando las opciones pmc y/o indom a la especificación de depuración global, como se describe en pmSetDebug(3).

ERRORES

Los usuarios no tienen control sobre el algoritmo utilizado para generar el perfil. En el caso de las métricas proc, se podría generar un perfil implícito si se requieren todas las instancias de proceso, aunque esto resultará en que no se devuelvan valores en la búsqueda.
