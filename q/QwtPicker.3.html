Descripción detallada

QwtPicker proporciona selecciones en un widget.

QwtPicker filtra todos los eventos de entrada, salida, ratón y teclado de un widget y los traduce en un array de puntos seleccionados.

La forma en que se recopilan los puntos depende del tipo de máquina de estados que está conectada al selector. Qwt ofrece un par de máquinas de estados predefinidas para seleccionar:

  • Nada
    QwtPickerTrackerMachine
  • Puntos individuales
    QwtPickerClickPointMachine, QwtPickerDragPointMachine
  • Rectángulos
    QwtPickerClickRectMachine, QwtPickerDragRectMachine
  • Polígonos
    QwtPickerPolygonMachine

Si bien estas máquinas de estados cubren las formas más comunes de recopilar puntos, también es posible implementar máquinas individuales.

QwtPicker traduce los puntos seleccionados en una selección utilizando el método adjustedPoints(). adjustedPoints() está destinado a ser reimplementado para corregir la selección según los requisitos específicos de la aplicación. (Por ejemplo, cuando una aplicación solo acepta rectángulos con una relación de aspecto fija).

Opcionalmente, QwtPicker admite el proceso de recopilación de puntos mediante una banda elástica y un rastreador que muestra un texto para la posición actual del ratón.

Ejemplo

#include <qwt_picker.h>
#include <qwt_picker_machine.h>
   QwtPicker *picker = new QwtPicker(widget);
   picker->setStateMachine(new QwtPickerDragRectMachine);
   picker->setTrackerMode(QwtPicker::ActiveOnly);
   picker->setRubberBand(QwtPicker::RectRubberBand);

La máquina de estados activa los siguientes comandos:

  • begin()
    Activa/Inicializa la selección.
  • append()
    Añade un nuevo punto
  • move()
    Cambia la posición del último punto.
  • remove()
    Elimina el último punto.
  • end()
    Termina la selección y llama a accept para validar los puntos seleccionados.

El selector está activo (isActive()), entre begin() y end(). En estado activo, se muestra la banda elástica y el rastreador es visible en caso de que trackerMode sea ActiveOnly o AlwaysOn.

El cursor se puede mover usando las teclas de flecha. Todas las selecciones se pueden abortar usando la tecla de abortar. (QwtEventPattern::KeyPatternCode)

Advertencia

En caso de QWidget::NoFocus, la política de enfoque del widget observado se establece en QWidget::WheelFocus y el seguimiento del ratón se manipulará mientras el selector esté activo, o si trackerMode() es AlwayOn.

QPolygon QwtPicker::adjustedPoints (const QPolygon & points) const [protected], [virtual]

Mappe les pickedPoints() en une selection(). adjustedPoints() mappe les points, qui ont été collectés sur le parentWidget(), dans une selection(). L'implémentation par défaut retourne simplement les points sans modification.

La raison pour laquelle une selection() diffère des points sélectionnés dépend des exigences de l'application. Par exemple :

  • Une sélection rectangulaire pourrait avoir uniquement un rapport d'aspect spécifique.
  • Une sélection pourrait n'accepter que des polygones non intersectants.
  • ...

L'exemple ci-dessous concerne une sélection rectangulaire, où le premier point est le centre du rectangle sélectionné.

Exemple

QPolygon MyPicker::adjustedPoints( const QPolygon &points ) const
{
    QPolygon adjusted;
    if ( points.size() == 2 )
    {
        const int width = qAbs( points[1].x() - points[0].x() );
        const int height = qAbs( points[1].y() - points[0].y() );
        QRect rect( 0, 0, 2 * width, 2 * height );
        rect.moveCenter( points[0] );
        adjusted += rect.topLeft();
        adjusted += rect.bottomRight();
    }
    return adjusted;
}

Paramètres

points Points sélectionnés

Retourne

Points sélectionnés sans modification
