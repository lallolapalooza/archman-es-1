Descripción Detallada

Parametrización de curvas utilizada para una interpolación spline.

La parametrización es el proceso de encontrar un valor de parámetro para cada punto de la curva, usualmente relacionado con alguna cantidad física (distancia, tiempo...).

A menudo, acumular la longitud de la curva es la forma prevista de parametrización, pero como la curva interpolada no se conoce de antemano, se necesita usar una aproximación.

Los valores se calculan acumulando incrementos, que son proporcionados por QwtSplineParametrization. Como los parámetros de la curva deben ser monótonamente crecientes, cada incremento debe ser positivo.

  • t[0] = 0;
  • t[i] = t[i-1] + valorIncremento( punto[i-1], p[i] );

QwtSplineParametrization proporciona los tipos de parametrizaciones más comunes y ofrece una interfaz para insertar implementaciones personalizadas.

Nota

Los tipos de parametrización más relevantes intentan proporcionar una aproximación de la longitud de la curva.

Detailed Description

This class is a namespace for several static member functions, that calculate the increments of the parameter values for a spline, depending on different parametrization schemes.

The parameter value is an abstract value, that is not related to any specific coordinate system. It is only used to describe the position on a spline curve. Usually it is in the range [0, 1] or [0, N] where N is the number of points.

The different value increments are:

  • ParameterUniform: The parameter value is increased by 1 for each segment.
  • ParameterX: The parameter value is the difference between the x-coordinates of the end points of the segment.
  • ParameterY: The parameter value is the difference between the y-coordinates of the end points of the segment.
  • ParameterChordal: The parameter value is the length of the chordal segment (euclidean distance).
  • ParameterCentripetal: The parameter value is the square root of the chordal segment length. This scheme is often preferred for cubic splines, because it results in better shape properties.
  • ParameterManhattan: The parameter value is the sum of the absolute differences in x and y coordinates (L1 distance).

F.I. The calculation of the parameter values for a spline curve can be done by calling QwtSpline::calcParametrization.
