Módulo Queue
: sig end

Colas de tipo first-in, first-out (FIFO).

Este módulo implementa colas (FIFO), con modificación in-place. Ver Queue.examples abajo.

Alert unsynchronized_access. Los accesos no sincronizados a las colas son un error de programación.

Accesos no sincronizados

Los accesos no sincronizados a una cola pueden llevar a un estado inválido de la cola. Por lo tanto, los accesos concurrentes a las colas deben ser sincronizados (por ejemplo, con un Mutex.t ).

type !'a t

El tipo de colas que contienen elementos de tipo 'a .

exception Empty

Lanzada cuando Queue.take o Queue.peek se aplica a una cola vacía.

val create : unit -> 'a t

Devuelve una nueva cola, inicialmente vacía.

val add : 'a -> 'a t -> unit

add x q añade el elemento x al final de la cola q .

val push : 'a -> 'a t -> unit

push es un sinónimo de add .

val take : 'a t -> 'a

take q elimina y devuelve el primer elemento de la cola q , o lanza Queue.Empty si la cola está vacía.

val take_opt : 'a t -> 'a option

take_opt q elimina y devuelve el primer elemento de la cola q , o devuelve None si la cola está vacía.

Desde 4.08

val pop : 'a t -> 'a

pop es un sinónimo de take .

val peek : 'a t -> 'a

peek q devuelve el primer elemento de la cola q , sin eliminarlo de la cola, o lanza Queue.Empty si la cola está vacía.

val peek_opt : 'a t -> 'a option

peek_opt q devuelve el primer elemento de la cola q , sin eliminarlo de la cola, o devuelve None si la cola está vacía.

Desde 4.08

val top : 'a t -> 'a

top es un sinónimo de peek .

val drop : 'a t -> unit

drop q elimina el primer elemento de la cola q , o lanza Queue.Empty si la cola está vacía.

Desde 5.3

val clear : 'a t -> unit

Descarta todos los elementos de una cola.

val copy : 'a t -> 'a t

Devuelve una copia de la cola dada.

val is_empty : 'a t -> bool

Devuelve true si la cola dada está vacía, false en caso contrario.

val length : 'a t -> int

Devuelve el número de elementos en una cola.

val iter : ('a -> unit) -> 'a t -> unit

iter f q aplica f en turno a todos los elementos de q , desde el menos reciente al más reciente. La cola en sí misma no cambia.

val fold : ('acc -> 'a -> 'acc) -> 'acc -> 'a t -> 'acc

fold f accu q es equivalente a List.fold_left f accu l , donde l es la lista de los elementos de q . La cola permanece sin cambios.

val transfer : 'a t -> 'a t -> unit

transfer q1 q2 añade todos los elementos de q1 al final de la cola q2 , y luego vacía q1 . Es equivalente a la secuencia iter (fun x -> add x q2) q1; clear q1 , pero se ejecuta en tiempo constante.

Iteradores

val to_seq : 'a t -> 'a Seq.t

Itera sobre la cola, en orden de adelante hacia atrás. El comportamiento no está especificado si la cola se modifica durante la iteración.

val add_seq : 'a t -> 'a Seq.t -> unit

Un ejemplo básico:

    val q : '_weak1 Queue.t = <abstr>
    # Queue.push 1 q; Queue.push 2 q; Queue.push 3 q
    - : unit = ()
    # Queue.length q
    - : int = 3
    # Queue.pop q

Búsqueda a través de un Grafo

Para un ejemplo más elaborado, un uso algorítmico clásico de las colas es implementar una búsqueda en anchura (BFS) a través de un grafo.

     type graph = {
       edges: (int, int list) Hashtbl.t
     }
    (* Busca en el grafo [g] usando BFS, comenzando desde el nodo [start].
       Devuelve el primer nodo que satisface [p], o [None] si ningún nodo
       alcanzable desde [start] satisface [p].
    *)
    let search_for ~(g:graph) ~(start:int) (p:int -> bool) : int option =
      let to_explore = Queue.create() in
      let explored = Hashtbl.create 16 in
      Queue.push start to_explore;
      let rec loop () =
        if Queue.is_empty to_explore then None
        else
          (* nodo a explorar *)
          let node = Queue.pop to_explore in
          explore_node node
      and explore_node node =
        if not (Hashtbl.mem explored node) then (
          if p node then Some node (* encontrado *)
          else (
            Hashtbl.add explored node ();
            let children =
              Hashtbl.find_opt g.edges node
              |> Option.value ~default:[]
            in
            List.iter (fun child -> Queue.push child to_explore) children;
            loop()
          )
        ) else loop()
      in
      loop()
    (* un grafo de ejemplo *)
    let my_graph: graph =
      let edges =
        List.to_seq [
          1, [2;3];
          2, [10; 11];
          3, [4;5];
          5, [100];
          11, [0; 20];
        ]
        |> Hashtbl.of_seq
      in {edges}
    # search_for ~g:my_graph ~start:1 (fun x -> x = 30)
    - : int option = None
    # search_for ~g:my_graph ~start:1 (fun x -> x >= 15)
    - : int option = Some 20
    # search_for ~g:my_graph ~start:1 (fun x -> x >= 50)
    - : int option = Some 100
