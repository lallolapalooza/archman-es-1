Detailed Description

This class is a tool to render a QwtPlot widget to different output devices like QPrinter, QImage, QPixmap etc. In comparison to the QwtPlot::print function the renderer offers more sophisticated control over the output.

The rendering process can be configured by setting flags. These flags control if certain plot elements (like the legend, the axes, or the title) should be rendered or not.

The rendering can be scaled precisely by passing a page size and printer mode to renderDocument().

The layout flags control the layout of the plot. The options are:

LayoutFlag

DoNotClipCanvas
By default the plot canvas is clipped to its bounding rectangle. This flag disables clipping. This might be useful if the canvas contains plot items that should extend beyond the canvas borders.
DoNotAlignFrames
By default the frames around the axes are aligned to the outer border of the plot widget. This flag disables this alignment.

The discard flags control the removal of plot elements. The options are:

DiscardFlag

DiscardLegend
Render the plot without its legend.
DiscardTitle
Render the plot without its title.
DiscardCanvasBackground
Render the plot without the canvas background.
DiscardFrameAttributes
Render the plot without the frame around the plot canvas.
DiscardAxisBackground
Render the plot without the background of the axes.
DiscardAxisScaleMaxMajor
Render the plot without the major scale marks of the axes.
DiscardAxisScaleMinMajor
Render the plot without the minor scale marks of the axes.
DiscardAxisTitle
Render the plot without the titles of the axes.
DiscardAxisScale
Render the plot without the scales of the axes.
DiscardAllFrameAttributes
Render the plot without any frame attributes (equivalent to DiscardFrameAttributes | DiscardAxisBackground).
