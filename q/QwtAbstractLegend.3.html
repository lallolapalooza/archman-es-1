DESCRIPCIÓN DETALLADA

Clase base abstracta para widgets de leyenda.

Las leyendas, que necesitan estar bajo el control del sistema de disposición de QwtPlot, deben derivarse de QwtAbstractLegend.

Nota

Otros tipos de leyendas se pueden implementar conectándose a la señal QwtPlot::legendDataChanged(). Pero como estas leyendas son desconocidas para el sistema de disposición del gráfico, el código de disposición (en pantalla y para QwtPlotRenderer) debe organizarse en el código de la aplicación.
