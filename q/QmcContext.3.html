NOMBRE

QmcContext - contenedor para un contexto PMAPI y sus métricas

SINOPSIS EN C++

#include <QmcContext.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

Un objeto QmcContext es un contenedor para un único contexto PMAPI(3). El objeto mantiene una lista de todos los descriptores de métricas (QmcDesc), dominios de instancias (QmcIndom) y métricas (QmcMetric) que utilizan el contexto para minimizar la duplicación de estos objetos.

CONSTRUCTORES

Un objeto QmcContext debe construirse a través de la interfaz QmcGroup::use.

BÚSQUEDA DE DESCRIPTORES

Los descriptores de métricas y dominios de instancias son cacheados por el objeto QmcContext para reducir objetos QmcDesc y QmcIndom duplicados y las llamadas a PMAPI(3) necesarias para crearlos. También se mantiene el mapeo de nombres de métricas a pmIDs para evitar llamadas a pmLookupName(3).

int lookupDesc(const char *name, pmID& id);
Busca la métrica name en la lista de nombres y establece id al pmID conocido. Si no se encuentra, usa pmLookupName(3) para obtener el mapeo. Si esta llamada falla, se devolverá el código de error de PMAPI(3).
int lookupDesc(const char *name, uint_t& desc, uint_t& indom);
Encuentra el índice desc e indom para el objeto QmcDesc y el objeto QmcIndom para la métrica name. Los índices pueden ser utilizados luego con QmcContext::desc y QmcContext::indom para obtener referencias a los objetos reales. Los métodos devolverán un código de error de PMAPI(3) si el descriptor de métrica o el dominio de instancia no pudieron ser obtenidos.
int lookupDesc(pmID pmid, uint_t& desc, uint_t& indom);
Encuentra el índice desc e indom para el objeto QmcDesc y el objeto QmcIndom para la métrica pmid. Los índices pueden ser utilizados luego con QmcContext::desc y QmcContext::indom para obtener referencias a los objetos reales. Los métodos devolverán un código de error de PMAPI(3) si el descriptor de métrica o el dominio de instancia no pudieron ser obtenidos.

DIAGNÓSTICOS

Los mensajes de error se generan usando pmprintf(3) pero no se vacían. Es responsabilidad del usuario llamar a pmflush(3) para mostrar cualquier mensaje.

Diagnósticos adicionales pueden ser activados añadiendo las opciones pmc y/o optfetch a la especificación de depuración global, como se describe en pmSetDebug(3).

VER TAMBIÉN

PMAPI(3), QMC(3), QmcDesc(3), QmcGroup(3), QmcIndom(3), QmcMetric(3), pmflush(3), pmLookupName(3) y pmprintf(3).
