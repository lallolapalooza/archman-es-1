Descripción detallada

Clase base para interpolaciones de splines que proporcionan una continuidad paramétrica de segundo orden (C2) entre curvas adyacentes.

Todas las interpolaciones con continuidad C2 se basan en reglas para encontrar la segunda derivada en algunos puntos de control.

En el caso de splines no paramétricas, esos puntos son los puntos de la curva, mientras que para splines paramétricas, el cálculo se realiza dos veces usando un valor de parámetro t.

Enumerador

CubicRunout
La segunda derivada en el punto final está relacionada con las segundas derivadas en los 2 vecinos: cv[0] := 2.0 * cv[1] - cv[2].

Nota

boundaryValue() se ignora
NotAKnot
La tercera derivada en el punto final coincide con la tercera derivada en sus vecinos. O en otras palabras: el primer/último segmento de curva extiende el polinomio de su polinomio vecino.

QVector< double > QwtSplineC2::curvatures (const QPolygonF & points) const [override], [virtual]

Calculate the second derivates of f at the control points.

The base class implementation finds the interpolating polynomials for a non parametric spline. C2 spline interpolations are based on finding values for the second derivates of f at the control points. The interpolating polynomials can be calculated from the the second derivates using QwtSplinePolynomial::fromCurvatures.

The default implementation is a 2 pass calculation. In derived classes it might be overloaded by a one pass implementation.

Parameters

points Control points

Returns

Interpolating polynomials

Note

The x coordinates need to be increasing or decreasing
