Descripción detallada

Clase base para motores de escala.

Un motor de escala intenta encontrar rangos y tamaños de paso 'razonables' para las escalas.

El diseño de la escala se puede variar con setAttribute().

Qwt ofrece implementaciones para escalas logarítmicas y lineales.

Enumerador

NoAttribute
Sin atributos.
IncludeReference
Construye una escala que incluye el valor reference().
Symmetric
Construye una escala simétrica al valor reference().
Floating
Se supone que los extremos de la escala son iguales a los valores más externos incluidos más los márgenes especificados (ver setMargins()). Si este atributo *no* está configurado, los extremos de la escala serán múltiplos enteros del tamaño del paso.
Inverted
Invierte la escala (la pone al revés).

    NOMBRE

    QwtScaleEngine - Motor de escala para QwtPlot

    SINOPSIS

    #include <qwt_scale_engine.h>

    Clase base para motores de escala. Qwt ofrece varias implementaciones:

    • QwtLinearScaleEngine
    • QwtLog10ScaleEngine
    • QwtSymLogScaleEngine

    DESCRIPCIÓN

    Esta clase es la base para la representación de ejes de Qwt. Define la interfaz para el cálculo de las divisiones y etiquetas de un eje. Qwt proporciona varias implementaciones para diferentes tipos de escalas: lineales, logarítmicas (base 10) y simétricas logarítmicas. Las implementaciones de motores de escala para tipos de datos que no son `double` deben derivarse de esta clase.
