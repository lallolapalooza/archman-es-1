Descripción Detallada

Un widget de gráficos 2D.

QwtPlot es un widget para graficar gráficos bidimensionales. Se puede mostrar un número ilimitado de elementos de gráfico en su lienzo. Los elementos del gráfico pueden ser curvas (QwtPlotCurve), marcadores (QwtPlotMarker), la cuadrícula (QwtPlotGrid), o cualquier otra cosa derivada de QwtPlotItem. Un gráfico puede tener hasta cuatro ejes, con cada elemento del gráfico adjunto a un eje x y un eje y. Las escalas en los ejes se pueden establecer explícitamente (QwtScaleDiv), o se calculan a partir de los elementos del gráfico, utilizando algoritmos (QwtScaleEngine) que se pueden configurar por separado para cada eje.

El ejemplo simpleplot es un buen punto de partida para ver cómo configurar un widget de gráfico.

Ejemplo

El siguiente ejemplo muestra (esquemáticamente) la forma más sencilla de usar QwtPlot. Por defecto, solo los ejes izquierdo y inferior son visibles y sus escalas se calculan automáticamente. 
#include <qwt_plot.h>
#include <qwt_plot_curve.h>
     QwtPlot *myPlot = new QwtPlot( "Dos Curvas", parent );
     // añadir curvas
     QwtPlotCurve *curve1 = new QwtPlotCurve( "Curva 1" );
     QwtPlotCurve *curve2 = new QwtPlotCurve( "Curva 2" );
     // conectar o copiar los datos a las curvas
     curve1->setData( ... );
     curve2->setData( ... );
     curve1->attach( myPlot );
     curve2->attach( myPlot );
     // finalmente, actualizar el gráfico
     myPlot->replot();

void QwtPlot::setAutoReplot (bool tf = true)

Configura o restablece la opción autoReplot. Si la opción autoReplot está configurada, el gráfico se actualizará implícitamente manipulando funciones miembro. Dado que esto puede consumir mucho tiempo, se recomienda dejar esta opción desactivada y llamar a replot() explícitamente si es necesario.

La opción autoReplot está configurada en false por defecto, lo que significa que el usuario debe llamar a replot() para que los cambios sean visibles.

Parámetros

tf true o false. Por defecto es true.
