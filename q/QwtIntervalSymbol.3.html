Documentación de Enumeración de Miembros

enum QwtIntervalSymbol::Style

Estilo del símbolo.

Enumerador

NoSymbol
Sin estilo. El símbolo no se puede dibujar.
Bar
El símbolo muestra una línea con remates al principio/final. El tamaño de los remates depende del width() del símbolo.
Box
El símbolo muestra un rectángulo simple usando pen() y brush(). El tamaño del rectángulo depende del intervalo transladado y del width().
UserSymbol
Los estilos >= UserSymbol están reservados para clases derivadas de QwtIntervalSymbol que sobreescriben draw() con tipos de símbolos adicionales específicos de la aplicación.

NAME

QwtIntervalSymbol - symbol for intervals

SYNOPSIS

#include <qwt_interval_symbol.h>

#include <qwt_symbol.h>

enum Style {
    NoSymbol,
    UserSymbol
};
class QwtIntervalSymbol : public QwtSymbol {
public:
    QwtIntervalSymbol( Style style = NoSymbol );
    QwtIntervalSymbol( const QwtSymbol &symbol, Style style = UserSymbol );
    ~QwtIntervalSymbol();
    void setWidth( int width );
    int width() const;
    Style style() const;
    virtual void draw( QPainter *painter, const QPointF &center, double radius ) const;
    virtual void draw( QPainter *painter, const QRectF &rect ) const;
    virtual void draw( QPainter *painter, const QwtInterval &interval, const QPointF &pos, double size ) const;
};

Detailed Description

A symbol representing an interval. The symbol can be drawn using a preset style (e.g. NoSymbol) or using a separate QwtSymbol, that is drawn within the interval.
