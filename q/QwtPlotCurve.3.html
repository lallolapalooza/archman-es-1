Descripción Detallada

Un elemento de gráfico, que representa una serie de puntos.

Una curva es la representación de una serie de puntos en el plano x-y. Soporta diferentes estilos de visualización, interpolación (por ejemplo, spline) y símbolos.

Uso

a) Asignar propiedades de la curva
Cuando se crea una curva, se configura para dibujar líneas sólidas negras en el estilo QwtPlotCurve::Lines y sin símbolos. Puede cambiar esto llamando a setPen(), setStyle() y setSymbol().
b) Conectar/Asignar datos.
QwtPlotCurve obtiene sus puntos usando un objeto QwtSeriesData que ofrece un puente al almacenamiento real de los puntos (como QAbstractItemModel). Existen varias clases de conveniencia derivadas de QwtSeriesData, que también almacenan los puntos internamente (como QStandardItemModel). QwtPlotCurve también ofrece un par de variaciones de setSamples(), que crean internamente objetos QwtSeriesData a partir de arrays.
c) Adjuntar la curva a un gráfico
Ver QwtPlotItem::attach()

Atributo para dibujar la curva

Enumerator

Inverted
Solo para QwtPlotCurve::Steps. Dibuja una función escalonada de derecha a izquierda.
Fitted
Solo en combinación con QwtPlotCurve::Lines. Un QwtCurveFitter intenta interpolar/suavizar la curva antes de que se dibuje.

Nota

El ajuste de curvas requiere memoria temporal para calcular coeficientes y puntos adicionales. Si el dibujo en modo QwtPlotCurve::Fitted es lento, podría ser mejor ajustar los puntos antes de pasarlos a QwtPlotCurve.

enum QwtPlotCurve::CurveStyle

Estilos de curva.

Ver también

setStyle(), style()

Enumerator

NoCurve
No dibujar una curva. Nota: Esto no afecta a los símbolos.
Lines
Conectar los puntos con líneas rectas. Las líneas pueden ser interpoladas dependiendo del atributo 'Fitted'. El ajuste de curvas se puede configurar usando setCurveFitter().
Sticks
Dibujar barras verticales u horizontales (dependiendo de la orientation()) desde una línea base definida por setBaseline().
Steps
Conectar los puntos con una función escalonada. La función escalonada se dibuja de izquierda a derecha o viceversa, dependiendo del atributo QwtPlotCurve::Inverted.
Dots
Dibujar puntos en las ubicaciones de los puntos de datos. Nota: Esto es diferente de una línea punteada (ver setPen()) y más rápido que una curva en el estilo QwtPlotCurve::NoStyle y un símbolo que dibuja un punto.
UserCurve
Los estilos >= QwtPlotCurve::UserCurve están reservados para clases derivadas de QwtPlotCurve que sobreescriben drawCurve() con tipos de curva adicionales específicos de la aplicación.

enum QwtPlotCurve::PaintAttribute

Atributos para modificar el algoritmo de dibujo. La configuración predeterminada habilita ClipPolygons | FilterPoints

Ver también

setPaintAttribute(), testPaintAttribute()

Enumerator

ClipPolygons
Recortar polígonos antes de dibujarlos. En situaciones donde los puntos están muy fuera del área visible (por ejemplo, al hacer zoom profundo), esto podría ser una mejora sustancial en el rendimiento del dibujo.
FilterPoints
Intenta reducir los datos que deben dibujarse, descartando duplicados o dibujos fuera del área visible. Podría tener un impacto notable en curvas con muchos puntos cercanos. Solo se implementan algunos algoritmos de filtrado muy básicos.
MinimizeMemory
Minimizar el uso de memoria que se necesita temporalmente para los puntos traducidos antes de que se dibujen. Esto podría ralentizar el rendimiento del dibujo.
ImageBuffer
Renderizar los puntos a una imagen temporal y dibujar la imagen. Esta es una optimización muy especial para el estilo Dots cuando hay una gran cantidad de puntos. Con un número razonable de puntos, QPainter::drawPoints() será más rápido.
FilterPointsAggressive
Filtrado de puntos más agresivo, intentando filtrar puntos intermedios, aceptando diferencias visuales menores.

Solo tiene efecto al dibujar la curva en un dispositivo de dibujo en coordenadas enteras (por ejemplo, todos los widgets en pantalla) utilizando el hecho de que los puntos consecutivos a menudo se mapean a la misma coordenada x o y. Cada bloque de muestras mapeadas a la misma coordenada puede reducirse a 4 puntos (primero, mínimo, máximo, último).

En el peor de los casos, el polígono a renderizar tendrá 4 veces el ancho del lienzo del gráfico.

El algoritmo es muy rápido y efectivo para grandes conjuntos de datos, y puede usarse dentro de un ciclo de replotear.

Nota

Implementado solo para QwtPlotCurve::Lines.

Como este algoritmo reemplaza muchas líneas pequeñas por una larga, un error desagradable del motor de pintura rasterizada (Qt 4.8, Qt 5.1 - 5.3) se vuelve más dominante. Para estas versiones, el error puede evitarse habilitando el modo QwtPainter::polylineSplitting().

Description

The class that represents a curve item in the plot.

A curve is a QwtPlotSeriesItem which displays a set of y-values relative to a set of x-values. All x- and y-values need to be sorted according to the Qwt documentation.

The curve can be displayed in different styles (see QwtPlotCurve::CurveStyle) and can have symbols for its points (see QwtSymbol).

If the curve attribute `Fitted` is enabled the curve will be fitted by a QwtCurveFitter before it is painted.

The curve can be connected to the mouse events, that are related to the closest point on the curve. If you want to find the closest point use closestPoint().

See also

QwtPlotSeriesItem::setData(), setSymbol(), setStyle(), setCurveFitter(), setCurveAttribute().

void QwtPlotCurve::setBaseline (double value)

Establece el valor de la línea base. La línea base es necesaria para rellenar la curva con un pincel o con el estilo de dibujo Sticks.

La interpretación de la línea base depende de la orientación(). Con Qt::Vertical, la línea base se interpreta como una línea horizontal en y = baseline(), con Qt::Horizontal, se interpreta como una línea vertical en x = baseline().

El valor predeterminado es 0.0.

void QwtPlotCurve::setBrush (const QBrush & brush)

Asigna un pincel. En caso de brush.style() != QBrush::NoBrush y style() != QwtPlotCurve::Sticks, el área entre la curva y la línea base se rellenará.

En caso de !brush.color().isValid() el área se rellenará con el color del lápiz. El algoritmo de relleno simplemente conecta el primer y el último punto de la curva a la línea base. Por lo tanto, los datos de la curva deben estar ordenados (ascendente o descendente).

void QwtPlotCurve::setCurveFitter (QwtCurveFitter * curveFitter)

Asigna un ajustador de curvas.

El ajustador de curvas "suaviza" los puntos de la curva, cuando se establece el atributo CurveAttribute Fitted. setCurveFitter(NULL) también deshabilita el ajuste de curvas.

El ajustador de curvas opera sobre los puntos traducidos (es decir, coordenadas del widget) para ser funcional en escalas logarítmicas. Obviamente, esto es menos eficiente para algoritmos de ajuste que reducen el número de puntos.

Para situaciones en las que el ajuste de curvas se utiliza para mejorar el rendimiento de la pintura de grandes series de puntos, puede ser mejor ejecutar el ajustador una vez en los puntos de la curva y almacenar en caché el resultado en el objeto QwtSeriesData.

Parámetros

curveFitter() Ajustador de curvas
