Descripción Detallada

El Widget de Termómetro.

QwtThermo es un widget que muestra un valor dentro de un intervalo. Soporta:

  • una disposición horizontal o vertical;
  • un rango;
  • una escala;
  • un nivel de alarma.

Los colores de relleno pueden ser calculados a partir de un mapa de colores opcional. Si no se ha asignado un mapa de colores, QwtThermo utiliza los siguientes colores/pinceles de la paleta del widget:

  • QPalette::Base Fondo de la tubería
  • QPalette::ButtonText Pincel de relleno por debajo del nivel de alarma
  • QPalette::Highlight Pincel de relleno para los valores por encima del nivel de alarma
  • QPalette::WindowText Para el eje de la escala
  • QPalette::Text Para las etiquetas de la escala

Detailed Description

A thermometer widget, that visualizes a value within a given range.

The thermometer is composed of a pipe, that is filled according to the current value. The pipe is decorated with a scale.

The fill color can be assigned by a QwtColorMap. When no color map is assigned, the fill color is determined by the QPalette::ButtonText color of the widget.

The alarm threshold can be indicated by a color change of the border.

The origin of the scale can be customized by setOrigin(). The default origin is 0.0.

The scale can be positioned on different sides of the pipe using setScalePosition().

The orientation (horizontal or vertical) can be changed during runtime using setOrientation().

See also

QwtColorMap, QwtScaleWidget, QwtScaleDraw.
