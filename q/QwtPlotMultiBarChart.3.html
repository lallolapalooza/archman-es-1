Descripción Detallada

QwtPlotMultiBarChart muestra una serie de muestras que consisten cada una en un conjunto de valores.

Cada valor se muestra como una barra, y las barras de cada conjunto pueden organizarse lado a lado o apilarse.

Cada barra de un conjunto se renderiza con un QwtColumnSymbol, que se establece mediante setSymbol(). Las barras de diferentes conjuntos usan los mismos símbolos. Se pueden obtener excepciones mediante la sobrescritura de specialSymbol() o drawBar().

Dependiendo de la orientation() de la barra, las barras se muestran horizontalmente o verticalmente. Las barras cubren el intervalo entre la baseline() y el valor.

En contraste con la mayoría de otros elementos de gráficos, QwtPlotMultiBarChart devuelve más de una entrada en la leyenda - una por cada símbolo.

Detailed Description

Multi bar chart widget. This widget displays a number of bar charts in parallel.

The bars are organized in sets, where each set corresponds to a y-data set. All bars of a set are drawn with the same symbol and color.

The bars are rendered horizontally or vertically depending on the style().

The bars are aligned to the baseline. The distance between the bars of different sets is configurable with setSpacing().

The width of the bars can be configured by setBarWidth().

The bar symbols can be configured individually for each y-data index using setSymbol().

If the default symbol should be overridden for special values, the specialSymbol() virtual function can be overloaded.

Supported chart styles. The style can be used to customize the appearance of the bars.

When clipping is enabled, bars that are partially or fully outside the visible plot area are not rendered.

const QwtColumnSymbol * QwtPlotMultiBarChart::specialSymbol (int sampleIndex, int valueIndex) const [virtual]

Create a symbol for special values. Usually the symbols for displaying a bar are set by setSymbols() and common for all sets. By overloading specialSymbol() it is possible to create a temporary symbol() for displaying a special value.

The symbol has to be created by new each time specialSymbol() is called. As soon as the symbol is painted this symbol gets deleted.

When no symbol ( NULL ) is returned, the value will be displayed with the standard symbol that is used for all symbols with the same valueIndex.

Parameters

sampleIndex Index of the sample
valueIndex Index of the value in the set

Returns

NULL, meaning that the value is not special
