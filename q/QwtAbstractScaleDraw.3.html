Descripción detallada

Una clase base abstracta para dibujar escalas.

QwtAbstractScaleDraw se puede utilizar para dibujar escalas lineales o logarítmicas.

Después de que una división de escala se especifica como un objeto QwtScaleDiv usando setScaleDiv(), la escala se puede dibujar con la función miembro draw().
