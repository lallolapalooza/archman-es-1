Descripción detallada

Un elemento de gráfico que muestra una zona.

Una zona horizontal resalta un intervalo del eje y, una zona vertical un intervalo del eje x, y no tiene límites en la dirección opuesta. Se rellena con una brocha y sus líneas de borde se muestran opcionalmente con un bolígrafo.

Nota

Para mostrar un área delimitada por coordenadas x e y, utilice QwtPlotShapeItem

NAME

QwtPlotZoneItem - Abstract base class for zone items

SYNOPSIS

#include <qwt_plot_zoneitem.h>

class QwtPlotZoneItem : public QwtPlotItem
{
  public:
    Q_OBJECT

    enum Zone
    {
        Left,
        Right,
        Bottom,
        Top
    };

    explicit QwtPlotZoneItem( const QVariant &title = QVariant() );
    explicit QwtPlotZoneItem( const QString &title );
    virtual ~QwtPlotZoneItem();

    void setInterval( Qt::Orientation, double min, double max );
    void setInterval( Qt::Orientation, QwtDoubleInterval interval );
    QwtDoubleInterval interval( Qt::Orientation ) const;

    void setOrientation( Qt::Orientation orientation );
    Qt::Orientation orientation() const;

    void setPen( QColor color, qreal width = 0.0, Qt::PenStyle style = Qt::SolidLine );
    void setPen( QPen pen );
    QPen pen() const;

    void setBrush( QColor color );
    void setBrush( QBrush brush );
    QBrush brush() const;

    void setZ( double z );
    double z() const;

    virtual QRectF boundingRect() const;
    virtual void draw( QPainter *, const QPalette &, const QRectF & );

  protected:
    virtual void drawZone( QPainter *, const QwtScaleMap &xMap, const QwtScaleMap &yMap, const QRectF & );
    virtual void updateScaleDiv( const QwtScaleDiv &xs, const QwtScaleDiv &ys );

  private:
    class PrivateData;
    PrivateData *m_data;
};

Detailed Description

This class is an abstract base class for plot items, that visualize a zone, a rectangle or a line segment within the plot area. The zone can be oriented horizontally or vertically. In the case of a horizontal zone, it highlights an interval on the y-axis and is unbounded in the x-direction. A vertical zone highlights an interval on the x-axis and is unbounded in the y-direction.

The visual representation is controlled by a pen and a brush. The pen is used to draw the border lines of the zone, and the brush fills the zone.

The zone itself is defined by an interval along one of the plot axes. This interval can be set using the setInterval() methods.

The orientation can be changed using setOrientation().

The abstract method drawZone() is intended to be overloaded by derived classes to implement the drawing of the specific zone shape.
