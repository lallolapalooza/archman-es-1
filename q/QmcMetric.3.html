QMCMETRIC(3) Manual de funciones de biblioteca QMCMETRIC(3)

NOMBRE

QmcMetric - contenedor para una métrica y todos sus valores

SINOPSIS EN C++

#include <pcp/pmc/Metric.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

Un objeto QmcMetric es un contenedor para una métrica individual y todos sus valores.

La estructura QmcMetricValue se utiliza para almacenar el índice de la instancia, los valores y los errores de cada instancia. En el caso de una métrica singular, se utiliza un único objeto QmcMetricValue.

Un objeto QmcMetric consta de una lista de objetos QmcMetricValue, índices para los descriptores del QmcGroup y QmcContext de la métrica, y flags para indicar si las instancias son explícitas o implícitas, y si solo se requieren métricas activas después de llamar a QmcMetric::updateIndom.

CONSTRUCTORES

Las métricas deben construirse a través de los métodos QmcGroup::addMetric, ya que esto garantizará que las referencias al contexto, descriptor y dominio de instancia de la métrica se inicialicen correctamente.

INSTANCIAS

Para métricas con un dominio de instancia, es posible agregar y eliminar cualquier instancia, y también actualizar la lista de instancias para reflejar los cambios en un dominio de instancia dinámico.

bool updateIndom();
Actualiza la métrica para incluir nuevas instancias. Este método llamará primero a QmcContext::update para actualizar el dominio de instancia. Si el flag active está establecido en la llamada a QmcGroup::addMetric, la métrica solo exportará las instancias listadas en el dominio; de lo contrario, la métrica exportará todas las instancias listadas en el dominio.

El orden de las instancias puede cambiar como resultado de esta llamada. Las instancias que ya existían conservarán sus valores y errores actuales y anteriores, incluso si están en un orden diferente.

int addInst(QString const& name);
Agrega la instancia name a la métrica. Si la instancia no existe en el dominio de instancia, se devolverá un error de PMAPI(3). Este método ignora el valor del flag active establecido en el constructor de QmcMetric.
void removeInst(uint_t index);
Elimina la instancia en la posición index de la métrica.

DIAGNÓSTICOS

Los mensajes de error se generan usando pmprintf(3) pero no se vacían. Es responsabilidad del usuario llamar a pmflush(3) para mostrar cualquier mensaje.

Se pueden activar diagnósticos adicionales agregando la opción pmc a la especificación de depuración global, como se describe en pmSetDebug(3).

VER TAMBIÉN

PMAPI(3), QMC(3), QmcContext(3), QmcGroup(3), pmflush(3) y pmprintf(3).
