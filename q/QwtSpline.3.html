Descripción Detallada

Clase base para todas las splines.

Una spline es una curva representada por una secuencia de polinomios. La aproximación por splines es el proceso de encontrar polinomios para un conjunto dado de puntos. Cuando el algoritmo preserva los puntos iniciales, se llama interpolador.

Las splines se pueden clasificar según las condiciones de los polinomios que se cumplen en los puntos de inicio/final de las piezas:

•
Continuidad Geométrica
•
G0: los polinomios están unidos
•
G1: las primeras derivadas son proporcionales en el punto de unión. La tangente de la curva tiene la misma dirección, pero no necesariamente la misma magnitud. Es decir, C1'(1) = (a,b,c) y C2'(0) = (k*a, k*b, k*c).
•
G2: las primeras y segundas derivadas son proporcionales en el punto de unión
•
Continuidad Paramétrica
•
C0: las curvas están unidas
•
C1: las primeras derivadas son iguales
•
C2: las primeras y segundas derivadas son iguales

La continuidad geométrica requiere que la geometría sea continua, mientras que la continuidad paramétrica requiere que la parametrización subyacente también sea continua. La continuidad paramétrica de orden n implica continuidad geométrica de orden n, pero no viceversa.

QwtSpline es la clase base para aproximaciones de splines de cualquier continuidad.

DESCRIPTION

This is an abstract base class for spline interpolation algorithms. Qwt offers several derived classes for different spline types.

The spline interpolation approximates a set of control points P = { p0, p1, ..., pn } by a sequence of polynomials.

Each polynomial can be calculated from a local subset of the control points. The way how this is done is defined by the specific spline class.

locality

uint   QwtSpline::locality () const [virtual]

The locality of an spline interpolation identifies how many adjacent polynomials are affected, when changing the position of one point.

A locality of 'n' means, that changing the coordinates of a point has an effect on 'n' leading and 'n' following polynomials. Those polynomials can be calculated from a local subpolygon.

A value of 0 means, that the interpolation is not local and any modification of the polygon requires to recalculate all polynomials ( f.e cubic splines ).

Returns

Order of locality

Reimplemented in QwtSplinePleasing, QwtSplineLocal, QwtSplineCubic, and QwtSplineBasis.

Detailed Description

The Qwt Spline classes offer curve fitting algorithms.

The base class QwtSpline is an abstract base class, that offers an interface to the spline algorithms.

The class QwtSplineParameterization can be used to calculate equidistant points on a curve.

The derived classes implement specific spline algorithms:

  • QwtCubicSpline: Cubic spline interpolation.
  • QwtLinearSpline: Linear interpolation.

Qwt provides a widget QwtSplinePlot that is able to display splines.
