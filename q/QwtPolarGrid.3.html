Descripción Detallada

Un elemento que dibuja escalas y líneas de cuadrícula en un gráfico polar.

La clase QwtPolarGrid se puede utilizar para dibujar una cuadrícula de coordenadas. Una cuadrícula de coordenadas consta de líneas de cuadrícula principales y secundarias. Las ubicaciones de las líneas de cuadrícula se determinan por las divisiones de escala de azimut y radiales.

QwtPolarGrid también es responsable de dibujar el eje que representa las escalas. Es posible mostrar 4 ejes radiales y un eje de azimut.

Cada vez que cambian las divisiones de escala del widget del gráfico, la cuadrícula se sincroniza mediante updateScaleDiv().

Enumerador

SmartOriginLabel
Intenta evitar situaciones en las que la etiqueta del origen se pinte sobre otro eje.
HideMaxRadiusLabel
A menudo, la marca de graduación más externa de la escala radial está cerca del borde del lienzo. Con HideMaxRadiusLabel habilitado, no se pinta.
ClipAxisBackground
Las etiquetas de las marcas de graduación de las escalas radiales pueden ser difíciles de leer cuando se pintan encima de las líneas de cuadrícula radiales (o encima de una curva/espectrograma). Cuando ClipAxisBackground está activado, el rectángulo delimitador de cada etiqueta se añade a la región de recorte.
SmartScaleDraw
No pinta la línea base de los ejes radiales, cuando están muy cerca de una línea de la cuadrícula de azimut.
ClipGridLines
Todas las líneas de cuadrícula se recortan contra el área del gráfico antes de pintarse. Cuando el gráfico se amplía, esto tendrá un impacto significativo en el rendimiento del código de pintura.

NAME

QwtPolarGrid - Grid item for polar plots

Detailed Description

This class represents a grid item for polar plots. It draws lines for the azimuth and radial scales.

The grid can be configured to draw scales with regular intervals or to adopt the scale divisions from the plot.

When updateGridAttributes is called the grid attributes are updated according to the current state of the canvas. If AutoScaling is enabled the radial scale is calculated from the interval, otherwise the scales are adopted to the plot scales.
