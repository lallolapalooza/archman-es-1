Detailed Description

This class displays a curve represented by samples of QwtPoint3D.

The value of the z-component of the samples is mapped to a color using a QwtColorMap.

The curve is not drawn polygonally, but by using the color map. The color of each point (x,y) is determined by the z value. This is useful for displaying the intensity distribution of a 3D object.

The setPaintAttribute() attribute PaintAttribute::RenderOutlines can be used to draw the polygon outlines.
