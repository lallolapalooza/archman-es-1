Descripción detallada

QwtColorMap se utiliza para mapear valores a colores.

Para mostrar datos 3D en un plano 2D, la tercera dimensión a menudo se muestra usando colores, como por ejemplo en un espectrograma.

Cada mapa de colores está optimizado para devolver colores para solo uno de los siguientes formatos de imagen:

  • QImage::Format_Indexed8
  • QImage::Format_ARGB32

NAME

QwtColorMap — Abstract base class for color maps

SYNOPSIS

#include <qwt_color_map.h>

class QwtColorMap
{
public:
    enum Format {
        RGB,
        Alpha    // Not used
    };

    explicit QwtColorMap(Format format = RGB);
    virtual ~QwtColorMap();

    void setColorInterval(double min, double max);
    void setMinColorValue(double value);
    void setMaxColorValue(double value);

    double minColorValue() const;
    double maxColorValue() const;

    virtual QColor color(const double value) const = 0;
    Format format() const;

protected:
    double transform(double value) const;

private:
    double m_minValue;
    double m_maxValue;
    int m_format;
};

Detailed Description

This class is an abstract base class for color maps. A color map is a mapping from a value into a color. The value can be anything from any interval, but the color map itself is only interested in values between 0.0 and 1.0. Values outside of this interval are not allowed. Values are transformed linearly into the range [0, 1] before they are used.

The mapping from the value range [min, max] to [0, 1] is done by the transform() function. The default implementation is:

value = (value - m_minValue) / (m_maxValue - m_minValue);

If minColorValue() and maxColorValue() are used, the range [min, max] is mapped to [0, 1].

The abstract method color() has to be implemented by a derived class. This method is the actual mapping from a value into the range [0, 1] to a QColor.
