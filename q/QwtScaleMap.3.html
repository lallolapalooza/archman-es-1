Detailed Description

A scale map converts values from a scale into coordinates on a paint device and vice versa. The scale is defined by a scale interval and the paint device by a paint interval.

The mapping can be linear or logarithmic (or any other transformation derived from QwtTransform).

It is assumed that the scale and paint intervals are valid and have finite, non-zero lengths.

The maps can be used to transform coordinates between different coordinate systems. For example, in a plot using multiple axes, each axis has its own scale map.

In the case of multiple axes, the transformation of points and rectangles requires the corresponding x and y scale maps.
