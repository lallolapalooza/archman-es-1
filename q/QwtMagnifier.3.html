QwtMagnifier proporciona zoom, magnificando en pasos.

Usando QwtMagnifier se puede hacer zoom in/out en un gráfico en pasos usando teclas, la rueda del ratón o moviendo un botón del ratón en dirección vertical.

void QwtMagnifier::setWheelFactor (double factor)

Cambiar el factor de la rueda. El factor de la rueda define la relación entre el rango actual en el widget padre y el rango ampliado para cada paso de la rueda.

Utiliza valores > 1 para la magnificación (por ejemplo, 2.0) y valores < 1 para escalar hacia abajo (por ejemplo, 1/2.0 = 0.5). Puedes usar esta función para invertir la dirección de la rueda.

El valor predeterminado es 0.9.

Parámetros

factor Factor de la rueda

NAME

QwtMagnifier - Magnifier widget for plot items

SYNOPSIS

#include <qwt_magnifier.h>
class QwtMagnifier : public QObject

Detailed Description

Magnifier widget for plot items.

A magnifier can be installed on a plot axis. It observes mouse events and zooms the axis accordingly. See the Magnifier example.

The default mouse bindings can be overridden by installing your own mouse event filter.

The magnifier can be enabled/disabled using enable() or setEnabled().
