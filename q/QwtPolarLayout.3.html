Descripción Detallada

Clase de diseño para QwtPolarPlot.

Organiza la geometría para los diferentes componentes de QwtPolarPlot. Es utilizada por el widget QwtPolar para organizar sus widgets internos o por QwtPolarRnderer para renderizar su contenido a un QPaintDevice como un QPrinter, QPixmap/QImage o QSvgRenderer.

Detailed Description

Layout for polar plots. The layout calculates the geometries of the title, canvas, axes and legend.

The size of the legend can be controlled by setLegendRatio().

void QwtPolarLayout::setLegendPosition (QwtPolarPlot::LegendPosition pos, double ratio)

Specify the position of the legend.

Parameters

pos The legend's position.
ratio Ratio between legend and the bounding rect of title, canvas and axes. The legend will be shrunk if it would need more space than the given ratio. The ratio is limited to ]0.0 .. 1.0]. In case of <= 0.0 it will be reset to the default ratio. The default vertical/horizontal ratio is 0.33/0.5.
