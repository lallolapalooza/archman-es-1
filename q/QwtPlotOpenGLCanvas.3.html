Descripción Detallada

Un lienzo alternativo para un QwtPlot derivado de QOpenGLWidget.

Aunque QwtPlotOpenGLCanvas no deriva de QFrame, imita su API. Al usar hojas de estilo, soporta el modelo de caja - además de fondos con bordes redondeados.

Ver también

QwtPlot::setCanvas(), QwtPlotCanvas, QwtPlotCanvas::OpenGLBuffer

Nota

Otra forma de obtener gráficos acelerados por hardware es usar un búfer fuera de pantalla OpenGL ( QwtPlotCanvas::OpenGLBuffer ) con QwtPlotCanvas. El rendimiento es peor que renderizar directamente en un QOpenGLWidget, pero generalmente está mejor integrado en una aplicación de escritorio.
