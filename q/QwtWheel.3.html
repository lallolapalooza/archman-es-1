Descripción detallada

El widget de rueda.

El widget de rueda puede usarse para cambiar valores en un rango muy grande en pasos muy pequeños. Usando el miembro setMass(), puede configurarse como una rueda de elevación.

El rango por defecto de la rueda es [0.0, 100.0]

void QwtWheel::keyPressEvent (QKeyEvent * event) [override], [protected], [virtual]

Maneja eventos del teclado

  • Qt::Key_Home
    Pasa a minimum()
  • Qt::Key_End
    Pasa a maximum()
  • Qt::Key_Up
    En caso de una rueda horizontal o vertical no invertida, el valor se incrementa en el tamaño del paso. Para una rueda vertical invertida, el valor se decrementa en el tamaño del paso.
  • Qt::Key_Down
    En caso de una rueda horizontal o vertical no invertida, el valor se decrementa en el tamaño del paso. Para una rueda vertical invertida, el valor se incrementa en el tamaño del paso.
  • Qt::Key_PageUp
    El valor se incrementa en pageStepSize() * singleStepSize().
  • Qt::Key_PageDown
    El valor se decrementa en pageStepSize() * singleStepSize().

Parámetros

event Evento del teclado

void QwtWheel::setMass (double mass) [slot]

Set the slider's mass for flywheel effect. If the slider's mass is greater then 0, it will continue to move after the mouse button has been released. Its speed decreases with time at a rate depending on the slider's mass. A large mass means that it will continue to move for a long time.

Derived widgets may overload this function to make it public.

void QwtWheel::setTotalAngle (double angle) [slot]

Set the total angle which the wheel can be turned. One full turn of the wheel corresponds to an angle of 360 degrees. A total angle of n*360 degrees means that the wheel has to be turned n times around its axis to get from the minimum value to the maximum value.

The default setting of the total angle is 360 degrees.

Parameters

angle total angle in degrees
