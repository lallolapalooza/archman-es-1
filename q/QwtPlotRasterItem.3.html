Descripción Detallada

Una clase que muestra datos ráster.

Los datos ráster son una cuadrícula de valores de píxeles que se pueden representar como una QImage. Se utiliza para muchos tipos de información como espectrogramas, cartogramas, mapas geográficos...

A menudo, un gráfico tiene varios tipos de datos ráster organizados en capas. (por ejemplo, un mapa geográfico con estadísticas meteorológicas). Usando setAlpha(), los elementos ráster se pueden apilar fácilmente.

QwtPlotRasterItem solo está implementado para imágenes de los siguientes formatos: QImage::Format_Indexed8, QImage::Format_ARGB32.

enum QwtPlotRasterItem::CachePolicy

Política de caché. La política predeterminada es NoCache.

Enumerador

NoCache
renderImage() se llama cada vez que el elemento necesita ser repintado.
PaintCache
renderImage() se llama siempre que la caché de imágenes no sea válida, o las escalas, o el tamaño del lienzo hayan cambiado.

Este tipo de caché es útil para mejorar el rendimiento de las operaciones de ocultar/mostrar o las manipulaciones del valor alfa. Todas las demás situaciones son manejadas por el almacenamiento en búfer del lienzo.

NAME

QwtPlotRasterItem - plot item, that displays raster data

SYNOPSIS

#include <qwt_plot_rasteritem.h>

Inherits QwtPlotSpectrogram.

class QwtPlotRasterItem: public QwtPlotSeriesItem
{
public:
    enum CachePolicy
    {
        NoCache,
        PaintCache
    };

    enum PaintAttribute
    {
        ImageMode,
        RenderAntialiased
    };

    Q_DECLARE_FLAGS( PaintAttributes, PaintAttribute )

    explicit QwtPlotRasterItem( const QwtText &title = QwtText() );
    virtual ~QwtPlotRasterItem();

    void setAlpha( int alpha );
    int alpha() const;

    void setCachePolicy( CachePolicy policy );
    CachePolicy cachePolicy() const;

    void invalidateCache();

    void setPaintAttribute( PaintAttribute attribute, bool on = true );
    bool testPaintAttribute( PaintAttribute attribute ) const;
    PaintAttributes paintAttributes() const;

    virtual QRectF pixelHint( const QRectF &area ) const;

    virtual QwtInterval interval( Qt::Axis axis ) const;

protected:
    virtual QImage renderImage( const QwtScaleMap &xMap,
        const QwtScaleMap &yMap, const QRectF &area, const QSize
        &imageSize ) const = 0;

    void renderScaleMap( QPainter *painter, const QwtScaleMap &xMap,
        const QwtScaleMap &yMap, const QRectF &area, QSize imageSize,
        double pixelSize ) const;

};

Detailed Description

This class is a base class for plot items, that display raster data. Raster data is represented by a matrix of values, that are mapped to colors according to a color map.

A QwtPlotRasterItem uses a color map ( see QwtColorMap ) to convert the raster values into colors. The raster data itself has to be supplied by derived classes.

The plot item can be configured by it's cache policy and paint attributes.

QRectF QwtPlotRasterItem::pixelHint (const QRectF & area) const [virtual]

Pixel hint. The geometry of a pixel is used to calculated the resolution and alignment of the rendered image.

Width and height of the hint need to be the horizontal and vertical distances between 2 neighbored points. The center of the hint has to be the position of any point ( it doesn't matter which one ).

Limiting the resolution of the image might significantly improve the performance and heavily reduce the amount of memory when rendering a QImage from the raster data.

The default implementation returns an empty rectangle (QRectF()), meaning, that the image will be rendered in target device ( f.e screen ) resolution.

Parameters

area In most implementations the resolution of the data doesn't depend on the requested area.

Returns

Bounding rectangle of a pixel

void QwtPlotRasterItem::setAlpha (int alpha)

Set an alpha value for the raster data. Often a plot has several types of raster data organized in layers. ( f.e a geographical map, with weather statistics ). Using setAlpha() raster items can be stacked easily.

The alpha value is a value [0, 255] to control the transparency of the image. 0 represents a fully transparent color, while 255 represents a fully opaque color.

Parameters

alpha Alpha value
  • alpha >= 0
    All alpha values of the pixels returned by renderImage() will be set to alpha, beside those with an alpha value of 0 (invalid pixels).
  • alpha < 0 The alpha values returned by renderImage() are not changed.

The default alpha value is -1.
