Descripción detallada

Un diccionario para elementos de gráfico.

QwtPlotDict organiza los elementos de gráfico en orden z ascendente. Si autoDelete() está habilitado, todos los elementos adjuntos serán eliminados en el destructor del diccionario. QwtPlotDict se puede usar para acceder a todos los elementos QwtPlotItem, o a todos los elementos de un tipo específico, que se encuentran actualmente en el gráfico.

Una QwtPlotItemList de todos los elementos de gráfico adjuntos. Use precaución al iterar sobre estas listas, ya que eliminar/desvincular un elemento invalidará el iterador. En su lugar, puede colocar punteros a objetos que se eliminarán en una lista de eliminación y recorrer esa lista más tarde.
