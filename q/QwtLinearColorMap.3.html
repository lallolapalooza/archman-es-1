Descripción detallada

QwtLinearColorMap crea un mapa de colores a partir de puntos de color.

Un punto de color es un color en una posición específica. El rango válido para las posiciones es [0.0, 1.0]. Al mapear un valor a un color, este se traduce a este intervalo según mode().

Descripción Detallada

Establecer el rango de colores

Añadir puntos de referencia en 0.0 y 1.0.

Establecer el modo del mapa de colores. FixedColors significa que el color se calcula a partir del siguiente punto de referencia de color inferior. ScaledColors significa que el color se calcula interpolando los colores de los puntos de referencia adyacentes.
