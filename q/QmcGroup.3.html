QMCGROUP(3) Manual de funciones de biblioteca QMCGROUP(3)

NOMBRE

QmcGroup - contenedor que representa un único grupo de recuperación de métricas de múltiples fuentes

SINOPSIS EN C++

#include <QmcGroup.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

Un objeto QmcGroup es un contenedor para contextos y métricas que deben recuperarse al mismo tiempo. La clase administra los objetos QmcContext(3), las zonas horarias y los límites para cada contexto creado con QmcGroup::use y QmcGroup::addMetric.

CONSTRUCTORES & DESTRUCTOR

~QmcGroup();
Destructor que destruye todas las métricas y contextos creados por este grupo.
QmcGroup(bool restrictArchives = false);
Construye un nuevo grupo de recuperación. restrictArchives restringirá la creación de múltiples contextos de archivo creados desde el mismo host.

CONTEXTOS

El contexto predeterminado del grupo se define como el primer contexto creado con QmcGroup::use antes de la primera llamada a QmcGroup::addMetric. Si no se crea ningún contexto antes de agregar la primera métrica, se utiliza el host local como contexto predeterminado. Por lo tanto, si alguna especificación de métrica contiene fuentes de archivo, se debe haber creado una fuente de archivo con QmcGroup::use para evitar un error al mezclar tipos de contexto.

uint_t numContexts() const;
El número de contextos válidos creados en este grupo.
QmcContext const& context(uint_t index) const
Devuelve un manejador a un contexto.
QmcContext& context(uint_t index);
Devuelve un manejador modificable a un contexto.
int mode() const;
Devuelve el tipo de contexto, ya sea PM_CONTEXT_LOCAL, PM_CONTEXT_HOST o PM_CONTEXT_ARCHIVE.
QmcContext* which() const;
Devuelve un manejador al contexto actual de este grupo. Esto no llama a pmUseContext(3), por lo que puede que no sea el contexto PMAPI(3) actual.
uint_t contextIndex() const
El índice del contexto del grupo actual.
int use(int type, char const* source);
Utiliza el contexto de type de source. Si ya existe un contexto para esta source en este grupo, ese contexto se convertirá en el contexto PMAPI(3) actual. De lo contrario, se creará un nuevo contexto. El resultado es el manejador del contexto PMAPI(3) para el QmcGroup::context o un código de error PMAPI(3) si el contexto falló.
bool defaultDefined() const;
Devuelve true si se ha determinado un contexto predeterminado.
int useDefault();
Utiliza el contexto predeterminado. Si no se ha creado un contexto predeterminado, se intentará utilizar el contexto del host local. Un resultado menor que cero indica que el método falló con el error PMAPI(3) codificado en el resultado.
void createLocalContext();
Crea y utiliza un contexto para el host local. Un resultado menor que cero indica que el método falló con el error PMAPI(3) codificado en el resultado.

MÉTRICAS

Estos métodos addMetric deben usarse para crear nuevas métricas, ya que los constructores de QmcMetric son privados. Estos métodos siempre devolverán un puntero a un objeto QmcMetric, sin embargo, se debe verificar el campo QmcMetric::status() para asegurar que la métrica sea válida.

QmcMetric* addMetric(char const* str, double theScale = 0.0,
bool active = false);

Agrega la métrica str al grupo, con un factor de escala de scale. Si active está configurado, la métrica utilizará solo instancias activas (ver QmcMetric(3)).

QmcMetric* addMetric(pmMetricSpec* theMetric, double theScale
= 0.0, bool active);

Agrega la métrica theMetric al grupo, con un factor de escala de scale. Si active está configurado, la métrica utilizará solo instancias activas (ver QmcMetric(3)).

int fetch(bool update = true);
Recupera todas las métricas en todos los contextos de este grupo. Si update es igual a true, todas las métricas de contador se convertirán automáticamente en tasas (ver QmcMetric(3)).
int setArchiveMode(int mode, const struct timeval *when,
int interval);

Establece el modo y la hora para acceder a todos los contextos de archivo en este grupo. Ver pmSetMode(3) para más detalles.

ZONAS HORARIAS

Estos métodos ayudan en la gestión de múltiples zonas horarias y contribuyen al control de la zona horaria actual.

enum TimeZoneFlag { localTZ, userTZ, groupTZ, unknownTZ };
Enumeración utilizada para describir el origen de la zona horaria predeterminada. localTZ, userTZ y groupTZ indican que la zona horaria se estableció con QmcGroup::useLocalTZ, QmcGroup::useTZ(QString const&) y QmcGroup::useTZ() respectivamente. unknownTZ indica que no se ha establecido una zona horaria. userTZ indica que la zona horaria fue
int useTZ();
Utiliza la zona horaria del contexto del grupo actual como la predeterminada.
int useTZ(const QString &tz);
Agrega y utiliza tz como la zona horaria predeterminada de este grupo.
int useLocalTZ();
Utiliza la zona horaria del host local como la predeterminada para este grupo.
void defaultTZ(QString &label, QString &tz);
Devuelve la cadena de label y tz de la zona horaria predeterminada de este grupo.
TimeZoneFlag defaultTZ() const
Devuelve el origen de la zona horaria predeterminada.
int useDefaultTZ();
Establece la zona horaria a ser la zona horaria predeterminada según se definió en una llamada anterior a QmcGroup::useTZ o QmcGroup::useLocalTZ.
struct timeval const& logStart() const;
Devuelve la hora de inicio más temprana de cualquier archivo en este grupo. Asume que se ha llamado a QmcGroup::updateBounds.
struct timeval const& logEnd() const;
Devuelve la hora de finalización más tardía de cualquier archivo en este grupo. Asume que se ha llamado a QmcGroup::updateBounds.
void updateBounds();
Determina las horas de inicio más temprana y de finalización más tardía de todos los archivos en este grupo.

DEPURACIÓN

void dump(ostream &os);
Vuelca la información del estado sobre este grupo a os.

DIAGNÓSTICOS

Los mensajes de error

QmcGroup(3)

NAME

QmcGroup - C++ API for Performance Metrics Domain Manager (PMDM) group objects

C++ SYNOPSIS

#include <pcp/qmc.h>

QmcGroup(const char *name);
~QmcGroup();

QmcStatus addContext(QmcContext *ctx);
QmcStatus addMetric(QmcMetric *metric);
QmcStatus addMetric(QmcMetric *metric, const char *instance);
QmcStatus removeContext(QmcContext *ctx);
QmcStatus removeMetric(QmcMetric *metric);
QmcStatus removeMetric(QmcMetric *metric, const char *instance);
QmcStatus removeMetric(QmcMetric *metric, QmcInstance *instance);

QmcContext *getContext(int index) const;
QmcMetric *getMetric(int index) const;
QmcMetric *getMetric(const char *name) const;

int numContexts() const;
int numMetrics() const;
const char *name() const;

DESCRIPTION

The QmcGroup class provides an abstraction for a collection of metrics and contexts that are typically associated with a specific Performance Metrics Domain Manager (PMDM).

The primary purpose of a QmcGroup is to allow the user to manage and query a set of related metrics and their associated contexts efficiently.

CONSTRUCTORS & DESTRUCTOR

QmcGroup(const char *name);

The constructor initializes a new QmcGroup object. The name parameter specifies the name of the group, which is typically the name of the PMDM it represents.

~QmcGroup();

The destructor releases all resources associated with the QmcGroup object, including any contexts and metrics that were added to it.

CONTEXTS

QmcStatus addContext(QmcContext *ctx);

Adds a QmcContext object to the group.

QmcStatus removeContext(QmcContext *ctx);

Removes a QmcContext object from the group.

QmcContext *getContext(int index) const;

Returns a pointer to the QmcContext object at the specified index within the group.

int numContexts() const;

Returns the number of contexts currently associated with the group.

METRICS

QmcStatus addMetric(QmcMetric *metric);

Adds a QmcMetric object to the group without specifying an instance.

QmcStatus addMetric(QmcMetric *metric, const char *instance);

Adds a specific instance of a QmcMetric object to the group.

QmcStatus removeMetric(QmcMetric *metric);

Removes a QmcMetric object (and all its instances) from the group.

QmcStatus removeMetric(QmcMetric *metric, const char *instance);

Removes a specific instance of a QmcMetric object from the group.

QmcStatus removeMetric(QmcMetric *metric, QmcInstance *instance);

Removes a specific QmcInstance object from the group.

QmcMetric *getMetric(int index) const;

Returns a pointer to the QmcMetric object at the specified index within the group.

QmcMetric *getMetric(const char *name) const;

Returns a pointer to the QmcMetric object with the specified name within the group.

int numMetrics() const;

Returns the number of metrics currently associated with the group.

TIMEZONES

The QmcGroup class does not directly manage timezones. Timezone information is typically handled at the QmcContext level or through the global Performance Co-Pilot (PCP) configuration.

DEBUGGING

Debugging output for QmcGroup operations can be enabled by setting the appropriate debugging flags using the pmSetDebug(3) function. Specifically, adding the option qmc to the global debugging specification will enable debugging messages for this class.

DIAGNOSTICS

Diagnostic messages generated by QmcGroup methods are buffered and are not immediately output. The user is responsible for calling pmflush(3) to ensure that any buffered messages are displayed.

Additional diagnostics may be activated by adding the option pmc to the global debugging specification, as described in pmSetDebug(3).

SEE ALSO

PMAPI(3), QMC(3), QmcContext(3), QmcMetric(3), pmflush(3), pmprintf(3) and pmSetMode(3).

```html QmcGroup(3)

NOMBRE

QmcGroup - API C++ para objetos de grupo del Gestor de Dominios de Métricas de Rendimiento (PMDM)

SINOPSIS EN C++

#include <pcp/qmc.h>

QmcGroup(const char *name);
~QmcGroup();

QmcStatus addContext(QmcContext *ctx);
QmcStatus addMetric(QmcMetric *metric);
QmcStatus addMetric(QmcMetric *metric, const char *instance);
QmcStatus removeContext(QmcContext *ctx);
QmcStatus removeMetric(QmcMetric *metric);
QmcStatus removeMetric(QmcMetric *metric, const char *instance);
QmcStatus removeMetric(QmcMetric *metric, QmcInstance *instance);

QmcContext *getContext(int index) const;
QmcMetric *getMetric(int index) const;
QmcMetric *getMetric(const char *name) const;

int numContexts() const;
int numMetrics() const;
const char *name() const;

DESCRIPCIÓN

La clase QmcGroup proporciona una abstracción para una colección de métricas y contextos que normalmente se asocian con un Gestor de Dominios de Métricas (PMDM) específico.

El propósito principal de un QmcGroup es permitir al usuario gestionar y consultar un conjunto de métricas relacionadas y sus contextos asociados de manera eficiente.

CONSTRUCTORES Y DESTRUCTOR

QmcGroup(const char *name);

El constructor inicializa un nuevo objeto QmcGroup. El parámetro name especifica el nombre del grupo, que normalmente es el nombre del PMDM que representa.

~QmcGroup();

El destructor libera todos los recursos asociados con el objeto QmcGroup, incluidos todos los contextos y métricas que se añadieron a él.

CONTEXTOS

QmcStatus addContext(QmcContext *ctx);

Añade un objeto QmcContext al grupo.

QmcStatus removeContext(QmcContext *ctx);

Elimina un objeto QmcContext del grupo.

QmcContext *getContext(int index) const;

Devuelve un puntero al objeto QmcContext en el índice especificado dentro del grupo.

int numContexts() const;

Devuelve el número de contextos asociados actualmente al grupo.

MÉTRICAS

QmcStatus addMetric(QmcMetric *metric);

Añade un objeto QmcMetric al grupo sin especificar una instancia.

QmcStatus addMetric(QmcMetric *metric, const char *instance);

Añade una instancia específica de un objeto QmcMetric al grupo.

QmcStatus removeMetric(QmcMetric *metric);

Elimina un objeto QmcMetric (y todas sus instancias) del grupo.

QmcStatus removeMetric(QmcMetric *metric, const char *instance);

Elimina una instancia específica de un objeto QmcMetric del grupo.

QmcStatus removeMetric(QmcMetric *metric, QmcInstance *instance);

Elimina un objeto QmcInstance específico del grupo.

QmcMetric *getMetric(int index) const;

Devuelve un puntero al objeto QmcMetric en el índice especificado dentro del grupo.

QmcMetric *getMetric(const char *name) const;

Devuelve un puntero al objeto QmcMetric con el nombre especificado dentro del grupo.

int numMetrics() const;

Devuelve el número de métricas asociadas actualmente al grupo.

ZONAS HORARIAS

La clase QmcGroup no gestiona directamente las zonas horarias. La información de la zona horaria se maneja típicamente a nivel de QmcContext o a través de la configuración global de Performance Co-Pilot (PCP).

DEPURACIÓN

La salida de depuración para las operaciones de QmcGroup se puede habilitar estableciendo las banderas de depuración apropiadas utilizando la función pmSetDebug(3). Específicamente, añadir la opción qmc a la especificación de depuración global habilitará los mensajes de depuración para esta clase.

DIAGNÓSTICOS

Los mensajes de diagnóstico generados por los métodos de QmcGroup se almacenan en búfer y no se muestran inmediatamente. El usuario es responsable de llamar a pmflush(3) para asegurarse de que se muestran todos los mensajes en búfer.

Es posible activar diagnósticos adicionales añadiendo la opción pmc a la especificación de depuración global, como se describe en pmSetDebug(3).

VER TAMBIÉN

PMAPI(3), QMC(3), QmcContext(3), QmcMetric(3), pmflush(3), pmprintf(3) y pmSetMode(3).
