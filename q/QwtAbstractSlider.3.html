Descripción detallada

Una clase base abstracta para widgets deslizantes con una escala.

Un widget deslizante muestra un valor de acuerdo con una escala. La clase está diseñada como una superclase común para widgets como QwtKnob, QwtDial y QwtSlider.

Cuando el deslizador no está en modo de solo lectura (readOnly()), su valor puede modificarse mediante entradas de teclado, ratón y rueda.

El rango del deslizador se divide en un número de pasos de los cuales dependen los incrementos de valor según las entradas del usuario. Solo para escalas lineales, el número de pasos corresponde a un tamaño de paso fijo.

Maneja los eventos de teclado

QwtAbstractSlider maneja las siguientes teclas:

  • Qt::Key_Left
    Suma/Resta singleSteps() en la dirección a lowerBound();
  • Qt::Key_Right
    Suma/Resta singleSteps() en la dirección a upperBound();
  • Qt::Key_Down
    Resta singleSteps(), cuando invertedControls() es falso
  • Qt::Key_Up
    Suma singleSteps(), cuando invertedControls() es falso
  • Qt::Key_PageDown
    Resta pageSteps(), cuando invertedControls() es falso
  • Qt::Key_PageUp
    Suma pageSteps(), cuando invertedControls() es falso
  • Qt::Key_Home
    Establece el valor al minimum()
  • Qt::Key_End
    Establece el valor al maximum()

void QwtAbstractSlider::setInvertedControls (bool on)

Invierte los eventos de la rueda y del teclado

Normalmente, al girar la rueda del ratón hacia "arriba" y usar teclas como AvPág, el valor del deslizador aumenta hacia su máximo. Cuando invertedControls() está habilitado, el valor se desplaza hacia su mínimo.

Invertir los controles puede ser útil, por ejemplo, para un deslizador vertical con una escala invertida (disminuyendo de arriba a abajo).

SYNOPSIS

QwtAbstractSlider

Detailed Description

Abstract base class for sliders.

The slider is a concept for a widget that allows to edit a continuous value by moving a slider within a valid range.

The value is always in the range [minimum, maximum].

The steps are defined by setTotalSteps(). For a value change of 1.0 the slider has to be moved by singleSteps() steps.

For example: setRange(0, 100), setSingleSteps(10) and setPageSteps(20). The slider has 100 steps in total. Moving the slider by one single step changes the value by 1.0 (100 / 10 = 10).

Moving the slider by one page step changes the value by 2.0 (100 / 20 = 5).

void QwtAbstractSlider::wheelEvent (QWheelEvent * event) [override], [protected], [virtual]

Wheel Event handler

In/decreases the value by s number of steps. The direction depends on the invertedControls() property.

When the control or shift modifier is pressed the wheel delta ( divided by 120 ) is mapped to an increment according to pageSteps(). Otherwise it is mapped to singleSteps().
