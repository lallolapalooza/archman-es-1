Descripción detallada

Un elemento de gráfico que muestra datos en formato Scalable Vector Graphics (SVG).

Las imágenes SVG se usan a menudo para mostrar mapas.

QwtPlotSvgItem es solo una pequeña clase envoltorio de conveniencia para QwtPlotGraphicItem, que crea un QwtGraphic a partir de datos SVG.
