QMC(3) Manual de funciones de biblioteca QMC(3)

NOMBRE

QMC - biblioteca para gestionar grupos de métricas de Performance Co-Pilot

SINOPSIS DE C++

#include <qmc.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

La biblioteca de clases Qt-based Performance Metrics Class (QMC) es una colección de clases C++ para gestionar un gran conjunto de métricas de rendimiento de diversas fuentes. Esta biblioteca está construida sobre PMAPI(3).

DIAGNÓSTICOS

Los mensajes de error se generan utilizando pmprintf(3) pero no se vacían. Es responsabilidad del usuario llamar a pmflush(3) para enviar cualquier mensaje.

Diagnósticos adicionales pueden ser activados añadiendo la opción pmc a la especificación de depuración global, como se describe en pmSetDebug(3).

VER TAMBIÉN

PMAPI(3), QmcContext(3), QmcDesc(3), QmcGroup(3), QmcIndom(3), QmcMetric(3), QmcSource(3), pmflush(3) y pmprintf(3).
