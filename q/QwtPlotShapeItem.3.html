Descripción Detallada

Un elemento de gráfico, que muestra cualquier forma gráfica, que puede definirse mediante un QPainterPath.

Un QPainterPath es una forma compuesta por regiones que se intersecan y unen, rectángulos, elipses o áreas irregulares definidas por líneas y curvas. QwtPlotShapeItem muestra una forma con un bolígrafo y una brocha.

QwtPlotShapeItem ofrece un par de optimizaciones como recorte o eliminación. Estos algoritmos necesitan convertir el camino del pintor en polígonos que podrían ser menos eficientes para caminos construidos a partir de curvas y elipses.

Formas más complejas, que no se pueden expresar mediante un QPainterPath, se pueden mostrar utilizando QwtPlotGraphicItem.

Enumerador

ClipPolygons
Recortar polígonos antes de dibujarlos. En situaciones en las que los puntos están muy lejos del área visible (por ejemplo, al hacer zoom profundo), esto podría ser una mejora sustancial en el rendimiento del dibujo.

Pero el recorte de polígonos convertirá el camino del pintor en polígonos, lo que podría tener un impacto negativo en el rendimiento de los caminos compuestos por curvas o elipses.

Detailed Description

Plot item that displays a shape.

The shape is represented by a QPainterPath object. The shape can be set by using setShape() or by constructing it from a QPolygon or a QRect.

The shape can be outlined with a QPen and filled with a QBrush.

The outline/fill can be enabled/disabled individually by setting the pen/brush to a Qt::NoPen / Qt::NoBrush.

For performance reasons the shape might be simplified using a weeding optimization ( see setRenderTolerance() ).

void QwtPlotShapeItem::setRenderTolerance (double tolerance)

Set the tolerance for the weeding optimization. After translating the shape into target device coordinates ( usually widget geometries ) the painter path can be simplified by a point weeding algorithm ( Douglas-Peucker ).

For shapes built from curves and ellipses, weeding might have the opposite effect because they have to be expanded to polygons.

Parameters

tolerance Accepted error when reducing the number of points. A value <= 0.0 disables weeding.

renderTolerance(), QwtWeedingCurveFitter
