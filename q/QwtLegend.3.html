Descripción Detallada

El widget de leyenda.

El widget QwtLegend es una disposición tabular de elementos de leyenda. Los elementos de leyenda pueden ser cualquier tipo de widget, pero en general serán QwtLegendLabel.

QwtLegend

Clase de leyenda de Qwt

La clase QwtLegend es una clase que se puede personalizar para mostrar elementos de leyenda. La apariencia de los elementos se puede modificar sobrescribiendo el método QwtLegendItem::createWidget. La pila de elementos se puede configurar con setItemMode.

Descendencia

QwtLegend es una subclase de QFrame y una clase base para QwtPlotLegend.
