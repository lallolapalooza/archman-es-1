Descripción Detallada

La clase QwtDial proporciona un control de rango redondeado.

QwtDial está pensada como clase base para widgets de dial como velocímetros, compases, relojes...

Un dial contiene una escala y una aguja que indica el valor actual del dial. Dependiendo del Modo, uno de ellos está fijo y el otro está girando. Si no está en modo de solo lectura (isReadOnly()), el dial se puede girar arrastrando el ratón o usando la entrada del teclado (ver QwtAbstractSlider::keyPressEvent()). Un dial puede ser envolvente, lo que significa que una rotación por debajo/por encima de un límite continúa en el otro límite (por ejemplo, una brújula). La escala puede cubrir cualquier arco del dial, sus valores están relacionados con el origen() del dial.

A menudo, los dials deben actualizarse muy frecuentemente de acuerdo con los valores de dispositivos externos. Para estas altas tasas de actualización, QwtDial almacena en caché tanto como sea posible. Para las clases derivadas, puede ser necesario borrar estas cachés manualmente según los cambios de atributos usando invalidateCache().

Ver también

QwtCompass, QwtAnalogClock, QwtDialNeedle

Nota

Los ejemplos de controles y dials muestran diferentes tipos de dials.

QDial es más similar a QwtKnob que a QwtDial.

Detailed Description

A dial is a circular slider. It can be used to set or display a value within a certain range.

The value is represented by a needle. The range of the dial is represented by a scale. The scale can be restricted to a certain arc.

A QwtDialNeedle object is used to represent the value. A QwtRoundScaleDraw object is used to draw the scale.

The mode of the dial can be changed using setMode(). In the default mode QwtDial::RotateNeedle the needle rotates around the origin to indicate the value. In mode QwtDial::RotateScale the needle always points to the origin and the scale rotates.

The geometry of the scale can be changed by overriding scaleInnerRect().

Member Enumeration Documentation

Mode

Modes of the dial.

RotateNeedle
The needle rotates around the center of the dial.
RotateScale
The scale rotates around the center of the dial. The needle always points to the origin. The origin is typically at the lowest value of the scale.
