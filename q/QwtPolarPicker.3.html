Detailed Description

This class implements a picker for polar plots. It inherits the basic functionality of QwtPicker and adjusts it to the polar coordinate system.

The picker operates on a QwtPolarCanvas, which manages the transformation between pixel coordinates and the polar coordinate system (QwtPointPolar).

The picker can be configured by the selection type flags (see QwtPicker::SelectionFlags). A selection can be a single point, a rectangle, or a polygon.

The picked points are reported using the signals selected(). While the mouse is moved moved() is emitted.

The transformation between pixel coordinates and the polar coordinate system is done by the QwtPolarCanvas associated with the picker.

trackerTextPolar

virtual QwtText trackerTextPolar (const QwtPointPolar & pos) const [protected], [virtual]

Translate a position into a position string. In case of HLineRubberBand the label is the value of the y position, in case of VLineRubberBand the value of the x position. Otherwise the label contains x and y position separated by a ',' .

The format for the double to string conversion is '%.4f'.
