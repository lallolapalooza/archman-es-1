Descripción detallada

Implementación del algoritmo de de Casteljau para interpolar curvas de Bézier.

El criterio de planitud para terminar la subdivisión se basa en 'Piecewise Linear Approximation of Bézier Curves' de Roger Willcocks ( http://www.rops.org )

Este artículo explica las matemáticas subyacentes de una manera muy agradable: https://jeremykun.com/2013/05/11/bezier-curves-and-picasso

void QwtBezier::appendToPolygon (const QPointF & p1, const QPointF & cp1, const QPointF & cp2, const QPointF & p2, QPolygonF & polygon) const

Interpola una curva de Bézier con un polígono. appendToPolygon() está adaptada para acumular puntos de una secuencia de curvas de Bézier, como las que se crean mediante interpolación de splines.

Parámetros

p1 Punto de inicio
cp1 Primer punto de control
cp2 Segundo punto de control
p2 Punto final
polygon Polígono, al que se añaden los puntos interpolados

Nota

Si el último punto del polígono entrante coincide con p1, no se insertará por segunda vez.

void QwtBezier::setTolerance (double tolerance)

Establece la tolerancia.

La tolerancia es una medida de la planitud de una curva. Una curva con una planitud inferior a la tolerancia se considera plana y finaliza el algoritmo de subdivisión.

Al interpolar una curva de Bézier para renderizarla como una secuencia de líneas a algún tipo de raster (por ejemplo, a la pantalla), un valor de 0.5 del tamaño del píxel es un buen valor para la tolerancia.

Parámetros

tolerance Criterio de terminación para la subdivisión
