Descripción detallada

Un motor de escala para escalas logarítmicas.

El tamaño del paso se mide en décadas y el tamaño del paso principal se ajustará para encajar en el patrón $re n es un número natural incluyendo el cero.

Advertencia

el tamaño del paso, así como los márgenes, se miden en décadas.

Descripción detallada

El motor de escala logarítmica para QwtPlot.

Este motor puede ser usado para la representación de datos con una escala logarítmica. El motor se encarga de la conversión de valores de datos a posiciones en el eje y viceversa.

Para la representación de valores con base 10, se puede usar QwtLog10ScaleEngine.

El constructor recibe el rango del eje y una tolerancia para el redondeo de los ticks.
