Descripción detallada

Una clase que dibuja una cuadrícula de coordenadas.

La clase QwtPlotGrid se puede utilizar para dibujar una cuadrícula de coordenadas. Una cuadrícula de coordenadas consta de líneas de cuadrícula verticales y horizontales principales y secundarias. Las ubicaciones de las líneas de cuadrícula se determinan por las divisiones de escala X e Y que se pueden asignar con setXDiv() y setYDiv(). El miembro draw() dibuja la cuadrícula dentro de un rectángulo delimitador.

NAME

QwtPlotGrid - grid item for Qwt plots

SYNOPSIS

#include <qwt_plot_grid.h>

QwtPlotGrid : public QwtPlotItem

public:
    enum TickType {
        MajorTick,
        MinorTick
    };

    explicit QwtPlotGrid(const QwtScaleDiv & = QwtScaleDiv());
    virtual ~QwtPlotGrid();
    virtual void draw(QPainter *painter, const QwtScaleMap &xMap, const QwtScaleMap &yMap, const QRect &clipRect) override;
    void enableX(bool enable = true);
    void enableXMin(bool enable = true);
    void enableY(bool enable = true);
    void enableYMin(bool enable = true);
    bool xEnabled() const;
    bool xMinEnabled() const;
    bool yEnabled() const;
    bool yMinEnabled() const;
    void setXDiv(const QwtScaleDiv &scaleDiv);
    void setYDiv(const QwtScaleDiv &scaleDiv);
    const QwtScaleDiv & xScaleDiv() const;
    const QwtScaleDiv & yScaleDiv() const;
    void setMajorPen(const QColor &color, qreal width = 0.0, Qt::PenStyle style = Qt::SolidLine);
    void setMajorPen(const QPen &pen);
    const QPen & majorPen() const;
    void setMinorPen(const QColor &color, qreal width = 0.0, Qt::PenStyle style = Qt::SolidLine);
    void setMinorPen(const QPen &pen);
    const QPen & minorPen() const;
    void setPen(const QColor &color, qreal width = 0.0, Qt::PenStyle style = Qt::SolidLine);
    void setPen(const QPen &pen);

protected:
    virtual void draw_sheet(QPainter *painter, const QwtScaleMap &xMap, const QwtScaleMap &yMap, const QRect &clipRect);
    virtual void draw_lines(QPainter *painter, const QwtScaleMap &xMap, const QwtScaleMap &yMap, const QRect &clipRect);
};

Detailed Description

A grid item for QwtPlot. A grid can be configured to draw lines for major and/or minor ticks. The alignment of the lines can be controlled independently for the x and y axes.

The default grid draws major ticks for both axes.

The properties of the grid lines can be configured using setMajorPen() and setMinorPen().

If a plot has no explicit scale divisions ( QwtPlot::setAxisScaleDiv ) for an axis, the grid item will try to determine its own. This is done by observing the plot's axes. When the plot's axes change their scale divisions (e.g. during autoscaling) the grid item's updateScaleDiv() is called.

The draw_sheet() and draw_lines() can be overloaded to customize the appearance of the grid.
