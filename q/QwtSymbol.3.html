enum QwtSymbol::CachePolicy

Dependiendo del motor de renderizado y la complejidad de la forma del símbolo, puede ser más rápido renderizar el símbolo a un pixmap y pintar este pixmap.

Por ejemplo, el motor de pintura ráster es un renderizador de software puro donde en modo caché una operación de dibujo generalmente termina en una operación ráster con el área de respaldo, que suele ser más rápida que los algoritmos para renderizar polígonos. Pero se puede esperar lo contrario para las canalizaciones gráficas que pueden aprovechar la aceleración por hardware.

La configuración predeterminada es AutoCache.

Ver también

setCachePolicy(), cachePolicy()

Nota

La política no tiene efecto cuando el símbolo se pinta en un formato de gráficos vectoriales (PDF, SVG).

Advertencia

Desde Qt 4.8, el backend predeterminado en X11 es ráster.

void QwtSymbol::setPath (const QPainterPath & path)

Establecer una ruta de pintor como símbolo. El símbolo está representado por una ruta de pintor, donde el origen ( 0, 0 ) del sistema de coordenadas de la ruta se mapea a la posición del símbolo.

Cuando el símbolo tiene un tamaño válido, la ruta del pintor se escala para que encaje en el tamaño. De lo contrario, el tamaño del símbolo depende del rectángulo delimitador de la ruta.

Ejemplo

El siguiente código define un símbolo que dibuja una flecha:
#include <qwt_symbol.h>
     QwtSymbol *symbol = new QwtSymbol();
     QPen pen( Qt::black, 2 );
     pen.setJoinStyle( Qt::MiterJoin );
     symbol->setPen( pen );
     symbol->setBrush( Qt::red );
     QPainterPath path;
     path.moveTo( 0, 8 );
     path.lineTo( 0, 5 );
     path.lineTo( -3, 5 );
     path.lineTo( 0, 0 );
     path.lineTo( 3, 5 );
     path.lineTo( 0, 5 );
     QTransform transform;
     transform.rotate( -30.0 );
     path = transform.map( path );
     symbol->setPath( path );
     symbol->setPinPoint( QPointF( 0.0, 0.0 ) );
     setSize( 10, 14 );

Parámetros

path Ruta de pintor

Nota

El estilo se establece implícitamente en QwtSymbol::Path.

Descripción Detallada

Esta clase representa el símbolo gráfico que se utiliza para marcar puntos de datos individuales en un gráfico.

El usuario puede elegir entre varios estilos predefinidos (círculo, cuadrado, triángulo, etc.) o puede definir un estilo personalizado. Los símbolos también se pueden personalizar con un tamaño, un color de borde (pen) y un color de relleno (brush).

La clase proporciona una interfaz para dibujar el símbolo en una posición dada en el lienzo del gráfico.

Documentación de Enumeración de Miembros

Style

Define los diferentes estilos de símbolos disponibles:

  • NoSymbol: Ningún símbolo se dibuja.
  • Ellipse: Un círculo o elipse.
  • Rect: Un cuadrado o rectángulo.
  • Diamond: Un diamante.
  • UpTriangle: Un triángulo apuntando hacia arriba.
  • DownTriangle: Un triángulo apuntando hacia abajo.
  • LeftTriangle: Un triángulo apuntando hacia la izquierda.
  • RightTriangle: Un triángulo apuntando hacia la derecha.
  • Cross: Una cruz (+)
  • XCross: Una cruz en forma de X.
  • HLine: Una línea horizontal.
  • VLine: Una línea vertical.
