Descripción Detallada

Una clase que representa un texto.

Un QwtText es un texto que incluye un conjunto de atributos sobre cómo renderizarlo.

  • Formato
    Un texto puede incluir secuencias de control (por ejemplo, etiquetas) que describen cómo renderizarlo. Cada formato (por ejemplo, MathML, TeX, Qt Rich Text) tiene su propio conjunto de secuencias de control, que pueden ser manejadas por un QwtTextEngine especial para ese formato.
  • Fondo
    Un texto puede tener un fondo, definido por un QPen y QBrush para mejorar su visibilidad. Las esquinas del fondo pueden ser redondeadas.
  • Fuente
    Un texto puede tener una fuente individual.
  • Color
    Un texto puede tener un color individual.
  • Banderas de Renderizado
    Banderas de Qt::AlignmentFlag y Qt::TextFlag usadas como en QPainter::drawText().

enum QwtText::TextFormat

Formato de texto. El formato de texto define el QwtTextEngine que se utiliza para renderizar el texto.

Ver también

QwtTextEngine, setTextEngine()

Enumerador

AutoText
El formato de texto se determina usando QwtTextEngine::mightRender() para todos los motores de texto disponibles en orden creciente > PlainText. Si ninguno de los motores de texto puede renderizar el texto, se renderiza como QwtText::PlainText.
PlainText
Dibuja el texto tal como está, utilizando un QwtPlainTextEngine.
RichText
Utiliza el framework Scribe (Qt Rich Text) para renderizar el texto.
MathMLText
Utiliza un motor de renderizado MathML (http://en.wikipedia.org/wiki/MathML) para mostrar el texto. En versiones anteriores de Qwt, se incluía un motor así; desde Qwt 6.2 se encuentra aquí: https://github.com/uwerat/qwt-mml-dev

Para habilitar el soporte de MathML, se debe agregar el siguiente código a la aplicación:

QwtText::setTextEngine( QwtText::MathMLText, new QwtMathMLTextEngine() );
TeXText
Utiliza un motor de renderizado TeX (http://en.wikipedia.org/wiki/TeX) para mostrar el texto. Este motor no está incluido en Qwt.
OtherFormat
Formato de texto desconocido.

Enumerations

QwtText::TextFormat

The type of a text document. The formats >= OtherFormat are not used by Qwt. They are reserved for the user, to be used with setTextEngine().

AutoText
Try to auto detect the text format. If the text starts with "@:" it is interpreted as RichText. Otherwise it is interpreted as plain text.
PlainText
The text is interpreted as plain text.
RichText
The text is interpreted as Rich Text ( html subset ). A render engine is needed to display RichText. QwtText::draw() will try to use the render_engine to display the text ( not implemented yet ).
OtherFormat
The number of text formats can be extended using setTextEngine. Formats >= QwtText::OtherFormat are not used by Qwt.

Detailed Description

This class represents a text, that can be rendered in different formats ( plain text, HTML, Rich Text).

The actual rendering is done by pluggable text engines (see QwtTextEngine). The default engine is QwtPlainTextEngine.

The format of the text can be set using setTextFormat(). If the format is AutoText, the actual format is detected automatically.

The text and its font/color can be copied from another QwtText object.

Note:

The copy constructor and assignment operator are automatically generated and perform a deep copy.

The text can be rendered using draw(). The layout and paint attributes can be controlled by setLayoutAttribute() and setPaintAttribute().

See also:

QwtTextEngine.
