bool QwtPolarRenderer::exportTo (QwtPolarPlot * plot, const QString & documentName, const QSizeF & sizeMM = QSizeF( 200, 200 ), int resolution = 85)

Ejecuta un diálogo de archivo y renderiza el gráfico al archivo seleccionado. El documento se renderizará a 85 ppp para un tamaño de 30x30 cm.

Parámetros

plot Widget del gráfico
documentName Nombre del documento por defecto
sizeMM Tamaño del documento en milímetros.

void QwtPolarRenderer::renderDocument (QwtPolarPlot * plot, const QString & fileName, const QString & format, const QSizeF & sizeMM, int resolution = 85)

Renderiza un gráfico a un archivo.

Los formatos soportados son:

  • pdf
  • ps
  • svg
  • todos los formatos de imagen soportados por Qt, ver QImageWriter::supportedImageFormats()
