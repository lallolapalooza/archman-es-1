NAME

QwtInterval - Interval class

SYNOPSIS

#include <qwt_interval.h>

class QwtInterval
{
public:
    enum IntervalType {
        Axis,
        UserTime
    };

    QwtInterval();
    QwtInterval( double value, IntervalType type = Axis );
    QwtInterval( double minValue, double maxValue, IntervalType type = Axis );
    QwtInterval( const QwtValueList& values, IntervalType type = Axis );

    bool isValid() const;
    double minValue() const;
    double maxValue() const;
    IntervalType intervalType() const;

    void setMinValue( double value );
    void setMaxValue( double value );
    void setIntervalType( IntervalType type );

    bool covers( double value ) const;
    bool intersects( const QwtInterval& ) const;
    void unite( const QwtInterval& );
    void setBorderFlags( int flags );
    int borderFlags() const;

    QwtInterval symmetrize( double value ) const;
    double width() const;
    long double widthL() const;

};

Detailed Description

An interval is a range between a minimum and maximum value. The interval can be inclusive or exclusive of its limits.

The interval has a type, which is important for the alignment of axis intervals.

The interval can be checked for validity. An invalid interval is represented by the interval [ +inf, -inf ]. This is the default state of an uninitialized interval.

The interval can be bounded by a list of values. In this case the minimum value of the interval will be the minimum of the values, and the maximum value will be the maximum of the values.

The interval provides functions for checking if a value is covered by the interval (covers()), if two intervals intersect (intersects()) and for the union of two intervals (unite()).

The border flags indicate whether the interval borders are included or excluded. The flags can be a combination of Border flags.

symmetrize() adjusts the interval so that the given value becomes the center of the interval.

width() and widthL() return the width of the interval. For invalid intervals the width is 0.0.
