Descripción detallada

Una clase para dibujar escalas circulares.

QwtRoundScaleDraw se puede usar para dibujar escalas circulares. El segmento del círculo se puede ajustar con setAngleRange(). La geometría de la escala se puede especificar con moveCenter() y setRadius().

Después de que una división de escala se haya especificado como un objeto QwtScaleDiv usando QwtAbstractScaleDraw::setScaleDiv(const QwtScaleDiv &s), la escala se puede dibujar con la función miembro QwtAbstractScaleDraw::draw().

double QwtRoundScaleDraw::extent (const QFont & font) const [override], [virtual]

Calcula la extensión de la escala

La extensión es la distancia desde la línea base hasta el píxel más externo del dibujo de la escala. radius() + extent() es un límite superior para el radio del círculo delimitador.

void QwtRoundScaleDraw::setAngleRange (double angle1, double angle2)

Ajusta el segmento del círculo base para escalas circulares. La línea base se dibujará desde min(angle1,angle2) hasta max(angle1, angle2). La configuración predeterminada es [ -135, 135 ]. Un ángulo de 0 grados corresponde a la posición de las 12 en punto, y los ángulos positivos cuentan en sentido horario.

Parámetros

angle1
angle2 límites del intervalo de ángulos en grados.

Advertencia

  • El rango de ángulos se limita a [-360, 360] grados. Los ángulos que excedan este rango se recortarán.
