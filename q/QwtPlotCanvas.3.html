Enumerator

BackingStore
Pinta con doble buffer reutilizando el contenido del buffer de pixmap cuando sea posible. Usar un buffer de respaldo puede mejorar significativamente el rendimiento cuando se trabaja con superposiciones de widgets (como bandas de goma). Deshabilitar la caché puede mejorar el rendimiento para pinturas incrementales (usando QwtPlotDirectPainter).

Ver también

backingStore(), invalidateBackingStore()
Opaque
Intenta llenar completamente el rectángulo de contenido del lienzo del gráfico. Cuando se usan fondos con estilo, Qt asume que el lienzo no llena completamente su área (por ejemplo, debido a bordes redondeados) y llena el área debajo del lienzo. Cuando esto se hace con gradientes, puede resultar en un cuello de botella de rendimiento serio, dependiendo del tamaño.

Cuando el atributo Opaque está habilitado, el lienzo intenta identificar los huecos con algunas heurísticas y llenar solo esos.

Advertencia

No funcionará para fondos semitransparentes
HackStyledBackground
Intenta mejorar la pintura de fondos con estilo. QwtPlotCanvas soporta los atributos del modelo de caja para personalizar el diseño con hojas de estilo. Desafortunadamente, el diseño de las hojas de estilo de Qt no tiene un concepto sobre cómo manejar fondos con esquinas redondeadas, aparte del relleno.

Cuando HackStyledBackground está habilitado, el lienzo del gráfico intenta separar el fondo del borde del fondo mediante ingeniería inversa para pintar el fondo antes y el borde después de los elementos del gráfico. En este orden, el borde se suaviza perfectamente y se pueden evitar algunos artefactos de píxeles en las esquinas.

ImmediatePaint
Cuando se establece ImmediatePaint, replot() llama a repaint() en lugar de update().

Detailed Description

A canvas widget for the plot.

The canvas is the area where the plot items are rendered. It can be a plain widget or have a border, a frame and a background.

The canvas is an abstract base class and needs to be subclassed. QwtPlotDirectPainter is a concrete implementation for direct painting.

Member Enumeration Documentation

◆ PaintAttribute

enum

Paint attributes.

BackingStore

When enabled the canvas uses a pixmap for double buffering.

This might be useful if the canvas content is complex and needs to be redrawn often.

MinimizeMode

When enabled the canvas tries to minimize the area that needs to be repainted.

This is an optimization that might be useful for plots with dynamic data.
