Descripción detallada

Un ajustador de curvas que implementa el algoritmo de Douglas y Peucker.

El propósito del algoritmo de Douglas y Peucker es, dada una 'curva' compuesta por segmentos de línea, encontrar una curva que no sea demasiado diferente pero que tenga menos puntos. El algoritmo define 'demasiado diferente' basándose en la distancia máxima (tolerancia) entre la curva original y la curva suavizada.

El tiempo de ejecución del algoritmo aumenta de forma no lineal (peor caso O( n*n )) y puede ser muy lento para polígonos enormes. Para evitar problemas de rendimiento, puede ser útil dividir el polígono ( setChunkSize() ) y ejecutar el algoritmo para estas partes más pequeñas. La desventaja de no tener interpolación en los bordes es irrelevante para la mayoría de los casos de uso.

La curva suavizada consiste en un subconjunto de los puntos que definieron la curva original.

A diferencia de QwtSplineCurveFitter, el algoritmo de Douglas y Peucker reduce el número de puntos. Ajustando el parámetro de tolerancia según las escalas del eje, QwtSplineCurveFitter se puede utilizar para implementar diferentes niveles de detalle para acelerar el dibujo de curvas con muchos puntos.
