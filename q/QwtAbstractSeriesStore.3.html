Descripción detallada

Puente entre QwtSeriesStore y QwtPlotSeriesItem.

QwtAbstractSeriesStore es solo una interfaz abstracta para hacer posible aislar los métodos basados en plantillas ( QwtSeriesStore ) de los métodos regulares ( QwtPlotSeriesItem ) para permitir heredar de QwtPlotSeriesItem sin ningún problema con las plantillas.
