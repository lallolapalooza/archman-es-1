QwtPlotRescaler se encarga de las relaciones de aspecto fijas para las escalas de los gráficos.

QwtPlotRescaler ajusta automáticamente los ejes de un QwtPlot según relaciones de aspecto fijas.

enum QwtPlotRescaler::RescalePolicy

La política de redimensionamiento define cómo redimensionar el eje de referencia y los ejes dependientes.

Ver también

ExpandingDirection, setIntervalHint()

Enumerador

Fixed
El intervalo del eje de referencia permanece sin cambios cuando la geometría del lienzo cambia. Todos los demás ejes se ajustarán de acuerdo con su relación de aspecto.
Expanding
El intervalo del eje de referencia se encogerá/expandirá cuando la geometría del lienzo cambie. Todos los demás ejes se ajustarán de acuerdo con su relación de aspecto.

El intervalo representado por un píxel es fijo.

Fitting
Los intervalos de los ejes se calculan de manera que todos los ejes incluyan su sugerencia de intervalo.

NAME

QwtPlotRescaler - plot rescaler class

SYNOPSIS

#include <qwt_plot_rescaler.h>

Inherits QObject.

class QwtPlotRescaler : public QObject
{
  Q_OBJECT
public:
  explicit QwtPlotRescaler(QObject *parent = nullptr);
  virtual ~QwtPlotRescaler();
  void setAxis(QwtAxis::AxisPositions axis);
  QwtAxis::AxisPositions axis() const;
  void setReferenceAxis(QwtAxis::AxisPositions axis);
  QwtAxis::AxisPositions referenceAxis() const;
  void setScaleMode(ScaleMode mode);
  ScaleMode scaleMode() const;
  void setAspect ratio(double ratio);
  double aspectRatio() const;
  void setRescalePolicy(RescalerPolicy policy);
  RescalerPolicy rescalePolicy() const;
  void setEnabled(bool enable);
  bool isEnabled() const;
  void setZoomer(QwtPlotZoomer *zoomer);
  QwtPlotZoomer *zoomer() const;
  void setPanner(QwtPlotPanner *panner);
  QwtPlotPanner *panner() const;
  void setWheelTimeout(int timeout);
  int wheelTimeout() const;
protected:
  virtual void rescale(const QwtInterval &reference, QwtAxis::AxisPositions axisId);
  virtual void updateScales(QwtInterval intervals[QwtAxis::AxisPositions]) const;
private:
  void doRescale(bool updateItems);
};

Detailed Description

This class can be used to automatically rescale the axes of a QwtPlot widget.

The rescaler can be enabled/disabled using setEnabled(). When enabled, it observes mouse events (wheel, press, release) on a QwtPlotZoomer or QwtPlotPanner associated with the plot. The rescale operation itself is triggered when the user finishes zooming or panning.

The behavior of the rescaling is controlled by setScaleMode() and setRescalePolicy().

The rescaling is done relative to a reference axis. The axis and the reference axis can be set using setAxis() and setReferenceAxis().

The relation between the ranges of the axis and the reference axis is controlled by setAspectRatio(). This is useful to keep the aspect ratio of the plot items.

The actual rescaling happens in rescale() and updateScales(). They can be overridden to implement custom rescaling logic.

The default implementation of rescale() uses setRescalePolicy() and setScaleMode() to calculate the new scale intervals. They are then applied to the plot axes by calling QwtPlot::setAxisScale().

The default implementation of updateScales() calls QwtPlot::setAxisScale() for all axes.
