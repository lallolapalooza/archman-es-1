Detailed Description

Linear scale engine. This class is used to calculate the major and minor ticks of a linear scale. It can be used to build scales with arbitrary intervals and step sizes.

The engine calculates the tick positions based on the given lower and upper bounds of the scale, and an optional step size. If no step size is provided, the engine will calculate a suitable step size automatically.

The engine also supports margins, which can be used to add some extra space at the beginning and end of the scale. This can be useful to prevent ticks from being cut off at the edges of the scale.
