QmcDesc(3)

Paquete: pcp

QMCDESC(3) Manual de funciones de biblioteca QMCDESC(3)

NOMBRE

QmcDesc - contenedor para una descripción de métrica

SINOPSIS EN C++

#include <QmcDesc.h>

c++ ... -lpcp_qmc -lpcp

DESCRIPCIÓN

Un objeto QmcDesc es un contenedor para un descriptor de métrica (pmDesc, véase PMAPI(3)) y unidades.

CONSTRUCTORES Y DESTRUCTOR

~QmcDesc();
Destructor.
QmcDesc(pmID pmid);
Construye un contenedor para el descriptor de pmid. El descriptor se obtiene del contexto actual de PMAPI(3) usando pmLookupDesc(3).

DESCRIPCIÓN

int status() const;
Un estado menor que cero indica que el descriptor no pudo ser obtenido, el error de PMAPI(3) está codificado en el resultado.
pmID id() const;
Devuelve el pmID para este descriptor.
pmDesc desc() const;
Devuelve una copia del descriptor de métrica real.
const pmDesc *descPtr() const;
Devuelve un puntero al descriptor real para evitar usar un puntero a un objeto temporal.

UNIDADES

const QString &units() const;
La cadena completa de unidades para este descriptor.
const QString &shortUnits() const;
La cadena de unidades usando abreviaturas.
bool useScaleUnits() const;
Devuelve true si las unidades han sido establecidas por una llamada a QmcDesc::setScaleUnits.
const pmUnits &scaleUnits() const;
Devuelve las unidades de escalado para este descriptor.
void setScaleUnits(const pmUnits &units);
Establece las unidades de escalado para este descriptor.

DIAGNÓSTICOS

Los mensajes de error se generan usando pmprintf(3) pero no se vacían. Es responsabilidad del usuario llamar a pmflush(3) para mostrar cualquier mensaje.

Diagnósticos adicionales pueden ser activados añadiendo la opción pmc a la especificación de depuración global, como se describe en pmSetDebug(3).

VER TAMBIÉN

PMAPI(3), QMC(3), pmflush(3), pmLookupDesc(3) y pmprintf(3).
