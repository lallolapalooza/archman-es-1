Descripción Detallada

Una clase que representa una división de escala.

Una escala Qwt se define por sus límites y 3 listas para las posiciones de las marcas mayores, medianas y menores.

El upperBound() puede ser menor que el lowerBound() para indicar escalas invertidas.

Las divisiones de escala se pueden calcular a partir de un QwtScaleEngine.

Detailed Description

Scale division, which represents a linear scale division into intervals and ticks.

The scale division stores the boundaries of the scale and lists of tick marks. The ticks are organized in up to three types:

MinorTick
Tick marks between major ticks.
MediumTick
Tick marks between major ticks, but less frequent than minor ticks.
MajorTick
The most important tick marks, usually aligned with the grid.

The boundaries lowerBound() and upperBound() define the interval of the scale. For inverted scales the lower bound might be greater than the upper bound.

The methods setInterval() and setTicks() are intended for scale engines, that calculate the scale division from scratch. For interactive changes of the boundaries only setLowerBound() and setUpperBound() should be used.

The scale division itself doesn't know anything about the scale type (linear, logarithmic, date...). It only stores the numerical values.
