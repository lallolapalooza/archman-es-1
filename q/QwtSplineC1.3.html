DESCRIPCIÓN DETALLADA

Clase base para interpolaciones de spline que proporcionan una continuidad paramétrica de primer orden ( C1 ) entre curvas adyacentes.

Todas las interpolaciones con continuidad C1 se basan en reglas para encontrar la primera derivada en algunos puntos de control.

En el caso de splines no paramétricos, estos puntos son los puntos de la curva, mientras que para splines paramétricos el cálculo se realiza dos veces utilizando un valor de parámetro t.

NAME

QwtSplineC1 - Base class for C1 splines

SYNOPSIS 

    #include <qwt_spline.h>
    Inherits QwtSpline.

    class QwtSplineC1 : public QwtSpline
    {
      public:
        virtual ~QwtSplineC1();

        enum BoundaryCondition {
            Left,
            Right
        };

        virtual double boundaryValue(
            BoundaryCondition,
            const QVector< double >&,
            const QVector< double >&
        ) const = 0;

        virtual QVector< double > slopes( const QPolygonF& points ) const = 0;
    };

Detailed Description

This class is an abstract base class for splines, that are continuous and have a continuous first derivative.

virtual double QwtSplineC1::boundaryValue( BoundaryCondition bc, const QVector< double > & x, const QVector< double > & y ) const [pure virtual]

Calculate a boundary value for the spline interpolation.

The spline interpolation is often based on the solution of a system of linear equations. The boundary conditions are used to make the system well-defined.

For example, for a natural cubic spline, the second derivative at the boundaries is zero. If the spline is not guaranteed to be natural, a second boundary condition might be needed.

The simplest boundary conditions are clamping the first derivative. For a spline with control points p0, p1, ..., pn , the value for bc = Left is the value of the first derivative at p0 , and the value for bc = Right is the value of the first derivative at pn .

Parameters

bc Boundary condition to calculate
x x coordinates of the control points
y y coordinates of the control points

Returns

Value of the boundary condition
