Descripción Detallada

Una clase auxiliar para traducir una serie de puntos.

QwtPointMapper es una colección de métodos y optimizaciones para traducir una serie de puntos a coordenadas del dispositivo de dibujo. Es utilizado por QwtPlotCurve pero también podría ser útil para elementos de gráfico similares que muestran un QwtSeriesData<QPointF>.

enum QwtPointMapper::TransformationFlag

Banderas que afectan al proceso de transformación.

Ver también

setFlag(), setFlags()

Enumerador

RoundPoints
Redondea los puntos a valores enteros.
WeedOutPoints
Intenta eliminar puntos que se traducen a la misma posición.
WeedOutIntermediatePoints
Un algoritmo de eliminación aún más agresivo, que se puede usar en toPolygon().

Un bloque consecutivo de puntos que se mapean a la misma coordenada x se reduce a 4 puntos:

  • primer punto
  • punto con la coordenada y mínima
  • punto con la coordenada y máxima
  • último punto

En el peor de los casos (los puntos primero y último nunca son uno de los extremos), el número de puntos será 4 veces el ancho.

Como el algoritmo es rápido, se puede usar dentro de un ciclo de renderizado de polilíneas.

Member Enumeration Documentation

QwtPointMapper::FillFlags

Flags to control the mapping algorithms.

WeedOutPoints
All consecutive points that are mapped to the same screen position are filtered out.
RoundPoints
When mapping to QPolygonF all mapped points are rounded to the nearest integer coordinates.
WeedOutIntermediatePoints
Filter out points that are between two points that are already connected by a line segment. This can be useful for creating polygon representations of curves with many points, where the intermediate points do not change the visual appearance.
AlignPoints
Align points to pixel centers. This can help to avoid aliasing artifacts when drawing lines or points.

QPolygonF QwtPointMapper::toPolygonF (const QwtScaleMap & xMap, const QwtScaleMap & yMap, const QwtSeriesData< QPointF > * series, int from, int to) const

Translate a series of points into a QPolygonF. When the WeedOutPoints flag is enabled consecutive points, that are mapped to the same position will be one point.

When RoundPoints is set all points are rounded to integers but returned as PolygonF - what only makes sense when the further processing of the values need a QPolygonF.

When RoundPoints & WeedOutIntermediatePoints is enabled an even more aggressive weeding algorithm is enabled.
