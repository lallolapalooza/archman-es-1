Descripción detallada

Una transformación entre sistemas de coordenadas.

QwtTransform manipula valores al ser mapeados entre el sistema de coordenadas de la escala y el sistema de coordenadas del dispositivo de dibujo.

Una transformación consta de 2 métodos:

  • transform
  • invTransform

donde uno es la función inversa del otro.

Cuando p1, p2 son los límites de las coordenadas del dispositivo de dibujo y s1, s2 los límites de la escala, QwtScaleMap utiliza los siguientes cálculos:

  • p = p1 + ( p2 - p1 ) * ( T( s ) - T( s1 ) / ( T( s2 ) - T( s1 ) );
  • s = invT ( T( s1 ) + ( T( s2 ) - T( s1 ) ) * ( p - p1 ) / ( p2 - p1 ) );
