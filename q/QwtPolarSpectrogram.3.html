Descripción Detallada

Un elemento que muestra un espectrograma.

Un espectrograma muestra datos tridimensionales, donde la tercera dimensión (la intensidad) se muestra mediante colores. Los colores se calculan a partir de los valores utilizando un mapa de colores.

QImage QwtPolarSpectrogram::renderImage (const QwtScaleMap & azimuthMap, const QwtScaleMap & radialMap, const QPointF & pole, const QRect & rect) const [protected], [virtual]

Renderiza una imagen a partir de los datos y el mapa de colores. El área se traduce a un rectángulo del dispositivo de dibujo. Para cada píxel de este rectángulo, la intensidad se mapea a un color.

Parámetros

azimuthMap Mapea valores de azimut a valores relacionados con 0.0, M_2PI
radialMap Mapea valores de radio a coordenadas del pincel.
pole Posición del polo en coordenadas del pincel
rect Rectángulo de destino de la imagen en coordenadas del pincel

Devuelve

Un QImage::Format_Indexed8 o QImage::Format_ARGB32 dependiendo del mapa de colores.

QwtRasterData::intensity(), QwtColorMap::rgb(), QwtColorMap::colorIndex()
