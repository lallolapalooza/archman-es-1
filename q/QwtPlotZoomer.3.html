Descripción Detallada

QwtPlotZoomer proporciona zoom apilado para un widget de gráfico.

QwtPlotZoomer selecciona rectángulos de las entradas del usuario (ratón o teclado), los traduce a coordenadas del gráfico y ajusta los ejes a ellas. La selección está soportada por una banda elástica y, opcionalmente, mostrando las coordenadas de la posición actual del ratón.

El zoom se puede repetir tantas veces como sea posible, limitado solo por maxStackDepth() o minZoomSize(). Cada rectángulo se inserta en una pila.

La configuración predeterminada de cómo seleccionar rectángulos es una QwtPickerDragRectMachine con los siguientes enlaces:

  • QwtEventPattern::MouseSelect1
    El primer punto del rectángulo de zoom se selecciona con un clic del ratón, el segundo punto desde la posición donde se suelta el ratón.
  • QwtEventPattern::KeySelect1
    La primera pulsación de tecla selecciona el primer punto, la segunda pulsación selecciona el segundo punto.
  • QwtEventPattern::KeyAbort
    Descarta la selección en el estado donde se selecciona el primer punto.

Para recorrer la pila de zoom se utilizan los siguientes enlaces:

  • QwtEventPattern::MouseSelect3, QwtEventPattern::KeyUndo
    Retrocede una posición en la pila de zoom.
  • QwtEventPattern::MouseSelect6, QwtEventPattern::KeyRedo
    Avanza una posición en la pila de zoom.
  • QwtEventPattern::MouseSelect2, QwtEventPattern::KeyHome
    Ajusta el zoom a la base de zoom.

Las funciones setKeyPattern() y setMousePattern() pueden utilizarse para configurar las acciones del zoomer. El siguiente ejemplo muestra cómo configurar las teclas 'I' y 'O' para acercar y alejar una posición en la pila de zoom. La tecla 'Inicio' se utiliza para "deshacer el zoom" del gráfico.

zoomer = new QwtPlotZoomer( plot );
zoomer->setKeyPattern( QwtEventPattern::KeyRedo, Qt::Key_I, Qt::ShiftModifier );
zoomer->setKeyPattern( QwtEventPattern::KeyUndo, Qt::Key_O, Qt::ShiftModifier );
zoomer->setKeyPattern( QwtEventPattern::KeyHome, Qt::Key_Home );

QwtPlotZoomer está adaptado para gráficos con un eje x y un eje y, pero se permite adjuntar un segundo QwtPlotZoomer (sin banda elástica ni rastreador) para los otros ejes.

Nota

El ejemplo en tiempo real incluye una clase de zoomer derivada que añade barras de desplazamiento al lienzo del gráfico.

QwtPlotZoomer::QwtPlotZoomer (QWidget * canvas, bool doReplot = true) [explicit]

Crea un zoomer para el lienzo del gráfico. El zoomer se establece en los ejes x e y del gráfico padre del lienzo que están habilitados. Si hay uno o dos ejes x habilitados, el selector se establece en QwtAxis::XBottom. Si hay uno o dos ejes y habilitados, se establece en QwtAxis::YLeft.

El zoomer se inicializa con una QwtPickerDragRectMachine, el modo de rastreo se establece en QwtPicker::ActiveOnly y la banda elástica se establece en QwtPicker::RectRubberBand

Parámetros

canvas Lienzo del gráfico a observar, también el objeto padre
doReplot Llama a QwtPlot::replot() para el gráfico adjunto antes de inicializar el zoomer con sus escalas. Esto podría ser necesario cuando el gráfico está en un estado con cambios de escala pendientes.

QwtPlotZoomer

A zoomer for QwtPlots that supports a zoom stack.

This class introduces a zoom stack to navigate through different zoom states. It extends QwtPicker by adding methods to zoom in/out and to set the zoom base.

The zoomer can be configured by setting zoom policies and behaviour for key and mouse events.

Detailed Description

Plot zoomer with support for a zoom-stack.

This class implements a zoomer for QwtPlot plots, which supports a zoom-stack. The zoom-stack can be navigated using the left mouse button and the zoom() methods.

The zoomer can be configured to use different mouse buttons and modifiers for zooming. The default behaviour is:

  • Left Button + Ctrl: Select zoom rectangle
  • Left Button (repeatedly): Zoom in/out on the plot center
  • Right Button: Zoom out to the previous zoom level (if available)

The zoomer uses the same mouse events as QwtPlotPanner. It is recommended to use QwtEventBullet in combination with the zoomer to avoid conflicts between panning and zooming.

The zoomer supports a zoom-stack to navigate through zoom levels. The stack can be manipulated with the methods:

  • setZoomStack()
  • zoom()
  • zoomBase()
  • zoomRect()
  • zoomRectIndex()
  • zoomStack()

A zoomed() signal is emitted whenever the zoom level has been changed.

The zoomer also supports an optional tracker, which displays the coordinates of the mouse cursor within the plot area.
