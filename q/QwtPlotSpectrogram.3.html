Descripción detallada

Un elemento de gráfico, que muestra un espectrograma.

Un espectrograma muestra datos tridimensionales, donde la tercera dimensión (la intensidad) se muestra utilizando colores. Los colores se calculan a partir de los valores utilizando un mapa de colores.

En sistemas multinúcleo, el rendimiento de la composición de la imagen a menudo se puede mejorar dividiendo el área en secciones, cada una renderizada en un hilo diferente (ver QwtPlotItem::setRenderThreadCount()).

En el modo ContourMode, se pintan líneas de contorno para los niveles de contorno.

Detailed Description

This class displays raster data like an image, but where the colors are mapped according to the values. This allows to visualize 2D data where the Z dimension is represented by color. It can also render contour lines.

The base class QwtPlotRasterItem provides an interface to set the data and to specify the resolution.

The color mapping is done by a QwtColorMap object. The default map is a QwtLinearColorMap from blue to red.

The plot item can be rendered in several modes controlled by setDisplayMode():

ImageMode
The spectrogram is rendered as an image. The colors are calculated according to the values and the QwtColorMap.
ContourMode
Contour lines are rendered. The contour lines connect points of equal values.
HistoMode
A histogram is rendered. The histogram represents the distribution of values.

The default setting enables ImageMode.

For contour rendering, the contour levels can be set using setContourLevels(). The contour lines can be enabled/disabled using renderContourLines(). The appearance of the contour lines can be controlled by setDefaultContourPen() and contourPen().

The CONREC algorithm (used for contour line generation) has several options that can be controlled by setConrecFlag() and testConrecFlag().

setColorTableSize

Limit the number of colors being used by the color map

When using a color table the mapping from the value into a color is usually faster as it can be done by simple lookups into a precalculated color table.

Setting a table size > 0 enables using a color table, while setting the size to 0 disables it.

The default size = 0, and no color table is used.

Parameters

numColors Number of colors. 0 means not using a color table

Note

The colorTableSize has no effect when using a color table of QwtColorMap::Indexed, where the size is always 256.
