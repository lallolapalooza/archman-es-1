Descripción detallada

Un motor de escala para valores de fecha/hora.

QwtDateScaleEngine construye escalas a partir de intervalos de tiempo. Junto con QwtDateScaleDraw se puede utilizar para ejes según valores de fecha/hora.

Años, meses, semanas, días, horas y minutos se organizan en pasos con intervalos no constantes. QwtDateScaleEngine clasifica los intervalos y alinea los límites y las posiciones de las marcas según esta clasificación.

QwtDateScaleEngine soporta representaciones que dependen de las especificaciones Qt::TimeSpec. El rango válido para las escalas está limitado por el rango de QDateTime, que difiere entre Qt4 y Qt5.

Los valores de fecha/hora se esperan como el número de milisegundos desde 1970-01-01T00:00:00 Tiempo Universal Coordinado - también conocido como 'La Época', que se puede convertir a QDateTime usando QwtDate::toDateTime().

Alinea un valor de fecha/hora para un tamaño de paso

Para alineaciones de Qt::Day no hay un 'día 0 natural' - en su lugar se utiliza el primer día del año para evitar saltos en las posiciones de las marcas mayores al mover una escala. Para otras alineaciones (por ejemplo, según el primer día del mes) se debe sobreescribir alignDate().

Detailed Description

Scale engine for date/time values. This engine uses the QDateTime class for its internal representation of values and implements the necessary conversions between double and QDateTime.

The interpretation of the double values depends on the time specification set by setTimeSpec().

When using Qt::LocalTime or Qt::UTC the values are interpreted as seconds since the epoch (January 1, 1970, 00:00:00 UTC). For Qt::OffsetFromUTC the values are interpreted as seconds since the epoch plus the offset specified by setUtcOffset().

The range of valid dates is from minDate() to maxDate().

The default constructor initializes the scale engine with a default interval based on the current date and time and the system's local time specification.

The second argument sets the time specification. The default is Qt::LocalTime.
