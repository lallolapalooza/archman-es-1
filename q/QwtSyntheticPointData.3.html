Descripción Detallada

Datos de puntos sintéticos.

QwtSyntheticPointData proporciona un número fijo de puntos para un intervalo. Los puntos se calculan en pasos equidistantes en dirección x.

Si el intervalo no es válido, los puntos se calculan para el "rectángulo de interés", que normalmente es el área mostrada en el lienzo del gráfico. En este modo, se obtienen diferentes niveles de detalle al hacer zoom hacia adentro/afuera.

Ejemplo

El siguiente ejemplo muestra cómo implementar una curva sinusoidal.

#include <cmath>
#include <qwt_series_data.h>
#include <qwt_plot_curve.h>
#include <qwt_plot.h>
#include <qapplication.h>
  class SinusData: public QwtSyntheticPointData
  {
  public:
   SinusData():
       QwtSyntheticPointData( 100 )
   {
   }
   virtual double y( double x ) const
   {
       return qSin( x );
   }
  };
  int main(int argc, char **argv)
  {
   QApplication a( argc, argv );
   QwtPlot plot;
   plot.setAxisScale( QwtAxis::XBottom, 0.0, 10.0 );
   plot.setAxisScale( QwtAxis::YLeft, -1.0, 1.0 );
   QwtPlotCurve *curve = new QwtPlotCurve( "y = sin(x)" );
   curve->setData( new SinusData() );
   curve->attach( &plot );
   plot.show();
   return a.exec();
  }

Detailed Description

This is the abstract base class for the data structures of the parameterized plot items.

The difference to QwtPointSeriesData is that the y-values are calculated from the x-values. This is useful for functions and parameterized curves.

The virtual function y() has to be implemented by derived classes.

The x-values are calculated from the interval and the number of samples. If the interval is not valid, the rectangle of interest is used.
