Detailed Description

Abstract painter command for QwtPlotRasterItem.

A painter command encapsulates an operation that can be executed by a painter.

The painter commands are collected by a QwtPlotRasterItem while calculating its data. Afterwards the commands can be executed in the same order by calling QwtPainter::drawItems. This mechanism allows to render the same plot item multiple times using different painters (e.g. screen painter and PDF painter).

Member Enumeration Documentation

QwtPainterCommand::Type

The type of the painter command.

CmdInvalid
Invalid command.
CmdPaint
A paint command. The command is a meta call to draw an QwtGraphic. The QwtPlotRasterItem stores the graphic as argument.
CmdPixmap
A pixmap command. The command is a meta call to draw a QwtPlotRasterItem from a QPixmap. The QwtPlotRasterItem stores the pixmap and its drawing rectangle as arguments.
CmdState
A state command. The command is a meta call to change the painter device state (attributes like transform, clipping, brush, pen, etc.)
CmdText
A text command. The command is a meta call to draw a text label. The QwtPlotRasterItem stores the text, its bounding rectangle and alignment attributes.
