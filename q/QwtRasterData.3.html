Descripción Detallada

QwtRasterData define una interfaz para cualquier tipo de datos ráster.

QwtRasterData es una interfaz abstracta, utilizada por QwtPlotRasterItem para encontrar los valores en los píxeles de su ráster.

Los huecos dentro del rectángulo delimitador de los datos se pueden indicar mediante valores NaN (cuando WithoutGaps está deshabilitado).

A menudo, un elemento ráster se utiliza para mostrar valores de una matriz. En ese caso, la clase derivada de datos ráster necesita implementar algún tipo de remuestreo, que mapea el ráster de la matriz al ráster solicitado del elemento ráster (dependiendo de la resolución y las escalas del lienzo).

QwtMatrixRasterData implementa datos ráster, que devuelven valores de una matriz 2D dada.

Documentación de Enumeración de Miembros

enum QwtRasterData::Attribute

Atributos de datos ráster. Información adicional que se utiliza para mejorar el procesamiento de los datos.

Enumerador

WithoutGaps
El rectángulo delimitador de los datos está abarcado por el intervalo(Qt::XAxis) e interval(Qt::YAxis).

WithoutGaps indica que los datos no tienen huecos (valores desconocidos) en esta área y no es necesario verificar el resultado de value() en busca de valores NaN.

Habilitar este indicador tendrá un efecto positivo en el rendimiento de la representación de un QwtPlotSpectrogram.

La configuración predeterminada es false.

Nota

Los valores NaN indican un valor indefinido

Detailed Description

This class is an abstract base class for raster data. It defines the interface for data that can be rendered on a raster device.

The raster data is organized in a grid, where each cell represents a pixel. The class provides methods to access the data values at specific coordinates, to set and test attributes, and to retrieve information about the pixel geometry.

The interface is designed to be flexible and can be used with different data sources, such as images, matrices, or other numerical data. The default implementation of pixelHint() returns an empty rectangle, indicating that the data should be rendered at the target device's resolution.

By limiting the resolution of the raster data, it is possible to significantly improve performance and reduce memory usage when rendering images.

QRectF QwtRasterData::pixelHint (const QRectF & area) const

Pixel hint. pixelHint() returns the geometry of a pixel, that can be used to calculate the resolution and alignment of the plot item, that is representing the data.

Width and height of the hint need to be the horizontal and vertical distances between 2 neighbored points. The center of the hint has to be the position of any point ( it doesn't matter which one ).

An empty hint indicates, that there are values for any detail level.

Limiting the resolution of the image might significantly improve the performance and heavily reduce the amount of memory when rendering a QImage from the raster data.

The default implementation returns an empty rectangle recommending to render in target device ( f.e. screen ) resolution.

Parameters

area In most implementations the resolution of the data doesn't depend on the requested area.

Returns

Bounding rectangle of a pixel

Reimplemented in QwtMatrixRasterData.
