Descripción Detallada

Atributos de una entrada en una leyenda.

QwtLegendData es un contenedor abstracto (como QAbstractModel) para intercambiar atributos, que solo se conocen entre el elemento del gráfico y la leyenda.

Sobrescribiendo QwtPlotItem::legendData() se puede usar cualquier otro conjunto de atributos que pueda ser manejado por una implementación modificada (o completamente diferente) de una leyenda.

Ver también

QwtLegend, QwtPlotLegendItem

Nota

El ejemplo stockchart implementa una leyenda como un árbol con elementos seleccionables.

Name

QwtLegendData - Provides data for QwtLegend.

Description

The QwtLegendData class is used to store data that can be displayed in a QwtLegend. It holds a list of legend items, where each item can consist of an icon and a text label. This class is often used in conjunction with QwtPlot to create interactive legends for plots.

Public Members

The QwtLegendData class has the following public members:

  • QIcon icon: The icon associated with the legend item.
  • QString text: The text label for the legend item.

Example

Here's a simple example of how to create and use QwtLegendData:


#include <qwt_legend_data.h>
#include <qwt_legend.h>
#include <qapplication.h>
#include <qmainwindow.h>
#include <qicon.h>

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);

    QwtLegend legend;
    QwtLegendData data;

    // Create a legend item
    QwtLegendData::Item item;
    item.icon = QIcon(":/path/to/your/icon.png"); // Replace with a valid icon path
    item.text = "My Data Series";
    data.add(item);

    // Set the data for the legend
    legend.setData(data);

    // Show the legend (e.g., in a main window)
    QMainWindow window;
    window.setCentralWidget(&legend);
    window.show();

    return a.exec();
}
