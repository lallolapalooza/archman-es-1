Descripción Detallada

QwtPanner proporciona desplazamiento (panning) de un widget.

QwtPanner captura el contenido de un widget, que puede ser arrastrado en todas las direcciones. El desplazamiento entre la posición inicial y final se emite mediante la señal panned.

QwtPanner captura el contenido del widget en un pixmap y mueve el pixmap, sin iniciar ningún evento de repintado para el widget. Las áreas que no forman parte del contenido no se pintan durante el desplazamiento. Esto hace que el desplazamiento sea lo suficientemente rápido para widgets en los que los repintados son demasiado lentos para los movimientos del ratón.

Para widgets en los que los repintados son muy rápidos, podría ser mejor implementar el desplazamiento manualmente mapeando eventos del ratón en eventos de pintado.

QBitmap QwtPanner::contentsMask () const [protegido], [virtual]

Calcula una máscara para el contenido del widget desplazado. A veces, solo partes del contenido de un widget deberían ser desplazadas. Por ejemplo, para un widget con un fondo estilizado y bordes redondeados, solo el área dentro del borde debería ser desplazada.

Devuelve

Un bitmap vacío, indicando que no hay máscara
