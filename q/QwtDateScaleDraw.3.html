Descripción Detallada

Una clase para dibujar escalas de fechas y horas.

QwtDateScaleDraw muestra valores como etiquetas de fechas y horas. El formato de las etiquetas depende del alineamiento de los etiquetas de los tick principales.

Los formatos por defecto son:

  • Millisecond
    'hh:mm:ss:zzz\nddd dd MMM yyyy'
  • Second
    'hh:mm:ss\nddd dd MMM yyyy'
  • Minute
    'hh:mm\nddd dd MMM yyyy'
  • Hour
    'hh:mm\nddd dd MMM yyyy'
  • Day
    'ddd dd MMM yyyy'
  • Week
    'Www yyyy'
  • Month
    'MMM yyyy'
  • Year
    'yyyy'

Los formatos pueden modificarse usando setDateFormat() o individualmente para cada etiqueta de tick mediante la sobrescritura de dateFormatOfDate(),

La clase QwtDateScaleDraw suele usarse en combinación con QwtDateScaleEngine, que calcula escalas para intervalos de fechas y horas.

Detailed Description

This class is a scale draw for date/time values. It converts double values into QDateTime objects and formats them according to the specified timeSpec().

The double values are interpreted as Julian days since 0000-01-01T00:00:00 00:00:00 Local. (See also QwtDate).

The default time specification is Qt::UTC.
