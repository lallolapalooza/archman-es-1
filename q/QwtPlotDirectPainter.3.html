Descripción Detallada

Objeto de pintor intentando pintar incrementadamente.

Muchas aplicaciones quieren mostrar muestras mientras se colectan. Cuando hay demasiadas muestras, se requieren recálculos completos, lo que puede ser costoso en ciclos de colecta.

QwtPlotDirectPainter ofrece una API para pintar subconjuntos (por ejemplo, todos los puntos adicionales) sin borrar/reponer el lienzo de la gráfica.

En algunos entornos, puede ser importante calcular una región de corte adecuada antes de pintar. Por ejemplo, en Qt Embedded, solo la parte del fondo del almacenamiento de soporte que se ha cortado será copiada a un buffer de pantalla (probablemente no acelerado).

Advertencia

La pintura incremental solo ayudará cuando no se desencuente un recálculo por otra operación (como cambiar escalas) y nada necesita ser borrado.

Enumeradores

AtomicPainter
La inicialización de un QPainter es una operación cara de la memoria. Cuando se establece AtomicPainter, cada llamada a drawSeries() abre/cierra un QPainter temporal. De lo contrario, QwtPlotDirectPainter intenta utilizar el mismo QPainter por un tiempo prolongado.
FullRepaint
Al establecer FullRepaint, el lienzo de la gráfica se repinta explícitamente después de renderizar los muestras.
CopyBackingStore
Al habilitar QwtPlotCanvas::BackingStore, el pintor tiene que pintar al almacenamiento de soporte y al widget. En ciertos casos/situaciones/entornos puede ser más rápido pintar solo al almacenamiento de soporte y luego copiarlo al lienzo. Este flag también puede ser útil en configuraciones donde Qt llena el área de corte con el fondo del widget.

Detailed Description

Painter for direct painting, that bypasses the plot's off-screen paint device.

When a plot is updated frequently the overhead of the off-screen paint device can be significant. In these cases it is better to paint the plot directly onto the screen. The QwtPlotDirectPainter can be used to achieve this.

The plot has to be configured to use the direct painter.

    QwtPlot *plot = new QwtPlot();
    plot->setCanvas( new QwtPlotDirectPainter() );

The direct painter draws the plot elements (items, axes, etc.) in their usual order. This order is the same as when an off-screen paint device is used.

For painting plot items directly the plot needs to know the bounding rectangle of the area that needs to be updated. If the plot has no off-screen paint device, the bounding rectangle is calculated from the plot area and the scales.

When the plot is updated frequently, it is recommended to use QwtPlotDirectPainter::replot() instead of QwtPlot::replot(). The latter forces a full redraw of the plot, while the former optimizes the redraw by only repainting the necessary parts.
