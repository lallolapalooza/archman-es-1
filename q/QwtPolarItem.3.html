Descripción detallada

Clase base para elementos en un gráfico polar.

Un QwtPolarItem es 'algo que se puede pintar en el lienzo'. Está conectado al framework de QwtPolar mediante un par de métodos virtuales, que se implementan individualmente en las clases de elementos derivadas.

QwtPolar ofrece una implementación de los tipos más comunes de elementos, pero derivar de QwtPolarItem facilita la implementación de tipos adicionales de elementos.

QList< QwtLegendData > QwtPolarItem::legendData () const [virtual]

Return all information, that is needed to represent the item on the legend. Most items are represented by one entry on the legend showing an icon and a text.

QwtLegendData is basically a list of QVariants that makes it possible to overload and reimplement legendData() to return almost any type of information, that is understood by the receiver that acts as the legend.

The default implementation returns one entry with the title() of the item and the legendIcon().

Detailed Description

Base class for items on a polar plot.

A polar item is an abstract base class representing a graphical item on a QwtPolarPlot. The plot manages a dictionary of items and assigns an integer Z value to each item. Items with a higher Z value are painted on top of items with a lower Z value.

Item Attributes

The item attributes can be used to adapt the behavior of the item to different situations. For example the attribute Legend indicates that the item should be represented in a legend.

Render Hints

The render hints can be used to optimize the rendering process. For example the hint RenderAntialiased indicates that the item should be drawn with antialiasing.
