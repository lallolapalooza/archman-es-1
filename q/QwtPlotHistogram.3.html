Descripción detallada

QwtPlotHistogram representa una serie de muestras, donde se asocia un intervalo con un valor ( $y = f([x1,x2])$ ).

La representación depende del style() y de un opcional symbol() que se muestra para cada intervalo.

Nota

El término 'histograma' se utiliza de forma diferente en las áreas de procesamiento de imágenes digitales y estadística. Wikipedia introduce los términos 'histograma de imagen' y 'histograma de color' para evitar confusiones. Mientras que los 'histogramas de imagen' pueden ser mostrados por un QwtPlotCurve, todavía no hay un elemento de gráfico aplicable para un 'histograma de color'.

enum QwtPlotHistogram::HistogramStyle

Estilos de histograma. El estilo predeterminado es QwtPlotHistogram::Columns.

Ver también

setStyle(), style(), setSymbol(), symbol(), setBaseline()

Enumerador

Outline
Dibuja un contorno alrededor del área, que se construye con todos los intervalos utilizando el pen() y se rellena con el brush(). El estilo de contorno requiere que los intervalos estén en orden creciente y no se superpongan.
Columns
Dibuja una columna para cada intervalo. Si se ha establecido un symbol(), se utiliza ese símbolo; de lo contrario, la columna se muestra como un rectángulo liso utilizando el pen() y el brush().
Lines
Dibuja una línea simple utilizando el pen() para cada intervalo.
UserStyle
Los estilos >= UserStyle están reservados para clases derivadas que sobrescriben drawSeries() con formas adicionales específicas de la aplicación para mostrar un histograma.

void QwtPlotHistogram::setSymbol ( const QwtColumnSymbol * symbol )

Assign a symbol. In Column style an optional symbol can be assigned, that is responsible for displaying the rectangle that is defined by the interval and the distance between baseline() and value. When no symbol has been defined the area is displayed as plain rectangle using setPen() and setBrush().

See also:

style(), symbol(), drawColumn(), setPen(), setBrush()

Note:

In applications, where different intervals need to be displayed in a different way ( f.e different colors or even using different symbols) it is recommended to overload drawColumn().
