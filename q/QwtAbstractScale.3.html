Descripción detallada

Una clase base abstracta para widgets que tienen una escala.

La escala de un QwtAbstractScale está determinada por una definición QwtScaleDiv, que contiene los límites y las marcas de la escala. La escala se dibuja utilizando un objeto QwtScaleDraw.

La división de la escala puede asignarse explícitamente, pero normalmente se calcula a partir de los límites utilizando un QwtScaleEngine.

El motor de escala también decide el tipo de transformación de la escala (lineal, logarítmica, etc.).

NAME

QwtAbstractScale — Abstract base class for scales

SYNOPSIS

#include <qwt_abstract_scale.h>

Inherits from QwtObject.

class QwtAbstractScale : public QwtObject
{
  public:
    enum ScaleDiv;
    enum TickType;
    enum Orientation;

    virtual ~QwtAbstractScale();

    double lowerBound() const;
    double upperBound() const;
    void setLowerBound(double lower);
    void setUpperBound(double upper);
    void setScale(double lower, double upper);

    virtual ScaleDiv scaleDiv(
                int resolution = 0) const = 0;
    virtual void setScaleDiv(const ScaleDiv& scaleDiv) = 0;

    Orientation orientation() const;
    void setOrientation(Orientation);

    bool isInverted() const;
    void setInverted(bool);

    virtual void invalidateCache();

  protected:
    QwtAbstractScale(double lower, double upper, Orientation = Horizontal);
};

Detailed Description

This is an abstract base class for scales. Scales are used to display the relation between a value and a coordinate. Scales can be used to specify the coordinate system of the plot items.

The interface defines methods to set and get the scale's lower and upper bounds, to set and get the scale's orientation (horizontal or vertical), and to invert the scale.

The method scaleDiv() is pure virtual and must be implemented by derived classes. It returns the scale divisions (major and minor ticks) for a given resolution. The resolution is an optional parameter, which can be used to adapt the number of ticks to the target device's resolution (e.g. pixels).

The method setScaleDiv() is also pure virtual and allows to specify the scale divisions explicitly.
