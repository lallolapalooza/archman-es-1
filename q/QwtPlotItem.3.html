Descripción Detallada

Clase base para elementos en el lienzo del gráfico.

Un elemento del gráfico es "algo" que se puede pintar en el lienzo del gráfico, o que simplemente afecta a las escalas del widget del gráfico. Se pueden categorizar como:

•
Representador
Un 'Representador' es un elemento que representa algún tipo de datos en el lienzo del gráfico. Las diferentes clases de representadores están organizadas según las características de los datos:
•
QwtPlotMarker Representa un punto o una coordenada horizontal/vertical
•
QwtPlotCurve Representa una serie de puntos
•
QwtPlotSpectrogram ( QwtPlotRasterItem ) Representa datos rasterizados
•
...
•
Decoradores
Un 'Decorador' es un elemento que muestra información adicional, que no está relacionada con ningún dato:
•
QwtPlotGrid
•
QwtPlotScaleItem
•
QwtPlotSvgItem
•
...

Dependiendo de las banderas QwtPlotItem::ItemAttribute, un elemento se incluye en el escalado automático o tiene una entrada en la leyenda.

Antes de abusar de las clases de elementos existentes, podría ser mejor implementar un nuevo tipo de elemento de gráfico (no implemente una marca de agua como espectrograma). Derivar un nuevo tipo de QwtPlotItem significa principalmente implementar el método YourPlotItem::draw().

Ver también

El ejemplo cpuplot muestra la implementación de elementos adicionales del gráfico.

#include <qwt_plot_item.h>

Classe de base pour tous les éléments d'un tracé Qwt.

Les classes dérivées de QwtPlotItem implémentent des éléments visuels qui peuvent être ajoutés à un QwtPlot. Exemples : QwtPlotMarker, QwtPlotCurve, QwtPlotGrid.

Les objets QwtPlotItem peuvent être configurés avec des attributs qui changent leur comportement.

See also

QwtPlot, QwtPlotDict, PlotItemAttribute, ItemInterest, RenderHint, RttiValues

enum QwtPlotItem::PlotItemAttribute

Attributes of a Plot Item.

Enumerator

Legend
The item is represented on the legend.
AutoScale
The boundingRect() of the item is included in the autoscaling calculation as long as its width or height is >= 0.0.
Margins
The item needs extra space to display something outside its bounding rectangle.

QList< QwtLegendData > QwtPlotItem::legendData () const [virtual]

Devuelve toda la información necesaria para representar el elemento en la leyenda. Múltiples elementos se representan mediante una entrada en la leyenda mostrando un icono y un texto, pero por ejemplo QwtPlotMultiBarChart muestra una entrada por cada barra.

QwtLegendData es básicamente una lista de QVariants que hace posible sobreescribir y reimplementar legendData() para devolver casi cualquier tipo de información que entiende el receptor que actúa como la leyenda.

La implementación por defecto devuelve una entrada con el título del elemento y el icono legendIcon().

El valor por defecto es 1.

void QwtPlotItem::updateLegend(const QwtPlotItem *item, const QList<QwtLegendData> &data) [virtual]

Actualizar el ítem para cambios en la información de la leyenda. Los ítemes que desean mostrar una leyenda (no aquellos que quieran ser mostrados en una leyenda!) tendrán que implementar updateLegend().

updateLegend() se llama solo cuando la interés de la leyenda LegendInterest está activo. La implementación por defecto hace nada.

Parámetros

item Ítem a mostrar en una leyenda
data Cómo mostrar el ítem en la leyenda

Nota
