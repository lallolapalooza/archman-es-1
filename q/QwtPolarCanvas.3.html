Lienzo de un QwtPolarPlot.

El lienzo es el widget donde se pintan todos los elementos polares.

Nota

A diferencia de QwtPlot, todos los ejes se pintan en el lienzo.

Detalles de la clase

QwtPolarCanvas

Un lienzo para dibujar grafos polares.
El lienzo QwtPolarCanvas es un widget que se puede usar para dibujar grafos polares. El lienzo puede contener uno o más objetos QwtPolarPlotItem.
El QwtPolarCanvas gestiona el escalado y el desplazamiento de los gráficos polares. Los gráficos polares pueden ampliarse o reducirse pellizcando o desplazando el lienzo.
El lienzo también puede usarse para dibujar gráficos polares estáticos. En este caso, el lienzo se puede configurar para que no sea interactivo.
El QwtPolarCanvas tiene varias opciones de configuración que permiten personalizar la apariencia de los gráficos polares. Estas opciones incluyen la posibilidad de configurar el color de fondo, el color de la rejilla, el grosor de la rejilla y el estilo de la rejilla.
El QwtPolarCanvas también se puede usar para dibujar etiquetas y títulos para los gráficos polares. Estas etiquetas y títulos se pueden configurar para que tengan diferentes fuentes, tamaños y colores.
El QwtPolarCanvas es un widget muy versátil que se puede usar para crear una variedad de gráficos polares. El lienzo es fácil de usar y configurar, y es una gran opción para cualquiera que necesite dibujar gráficos polares.
