Descripción Detallada

QwtPlotPicker proporciona selecciones en un lienzo de gráfico.

QwtPlotPicker es un QwtPicker adaptado para selecciones en un lienzo de gráfico. Se configura con un eje x y un eje y y traduce todas las coordenadas de píxeles a este sistema de coordenadas.

Detailed Description

This class implements a plot picker item, which can be used to select points or regions in the plot canvas.

The selection can be done by clicking, rubber-banding or dragging. When a selection is finished the selected points or region is emitted by the signals:

  • selected(const QPointF&): emitted when a single point is selected.
  • selected(const QRectF&): emitted when a rectangle is selected.
  • selected(const QVector<QPointF>&): emitted when multiple points are selected.

In addition to the signals the plot picker can be configured to operate in different modes:

Selection Modes
  • SelectOnly: Only single points can be selected.
  • SelectLeftButton: Selection is done only with the left mouse button.
  • SelectVelvet: The selection can be interactively changed after it has been finished.
  • SelectCompound: Several selection modes can be combined.
Selection Actions
  • NoSelection: No selection is done.
  • ClickSelection: A single mouse click finishes the selection.
  • DragSelection: The selection is finished when the mouse button is released.
  • CornerRubberBand: A rectangle selection with a rubber band is started by pressing the mouse button and finished by releasing it.
  • ElifRubberBand: Similar to CornerRubberBand but the rubber band is drawn from corner to corner.
  • HLineRubberBand: A horizontal line is drawn.
  • VLineRubberBand: A vertical line is drawn.
Selection Filters
  • NoFilter: No filtering is done.
  • BelowPoints: The selection is only done below plot items.
  • FollowDigit: The selection can be interactively changed.

The default settings are:

    Filter: NoFilter
    Mode: Select | SelectLeftButton
    Action: ClickSelection | DragSelection | RectSelection

The axes can be set using the constructor or the setAxes() function.
