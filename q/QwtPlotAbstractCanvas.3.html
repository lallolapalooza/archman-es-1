Detailed Description

Base class for plot canvases. This class offers basic features like clipping, frame and focus indicator support.

The canvas is the area where plot items are rendered. It is usually derived from QwtPlot and the items are added to the plot.

Member Enumeration Documentation

FocusIndicator

Specifies the focus indicator for items.

NoFocus
No focus indicator is drawn.
Nearest
The nearest item to the mouse cursor gets a focus indicator.
Item
The item that has the keyboard focus gets a focus indicator.
Canvas
The canvas itself gets a focus indicator.
