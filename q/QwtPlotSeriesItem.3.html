QwtPlotSeriesItem(3)

NAME

QwtPlotSeriesItem - base class for plot items representing a series of data points

SYNOPSIS

#include <qwt_plot_seriesitem.h>

enum QwtPlotSeriesItem::ScaleInterest {
    NoScaleInterest = 0,
    ScaleInterest = 1
};

class QwtPlotSeriesItem : public QwtPlotItem

                        public:
                            explicit QwtPlotSeriesItem(const QwtText &title = "");
                            virtual ~QwtPlotSeriesItem();
                            
                            void setScaleInterest(ScaleInterest interest);
                            ScaleInterest scaleInterest() const;
                            
                            virtual void updateScaleDiv(const QwtScaleDiv &xScaleDiv, const QwtScaleDiv &yScaleDiv);
                            
                        protected:
                            void setRectOfInterest(const QwtDoubleRect &rect);
                            QwtDoubleRect rectOfInterest() const;
                            
                        };

Detailed Description

This class is the base class for plot items representing a series of data points like QwtPlotSpectrogram, QwtPlotHistogram, etc.

The main purpose of QwtPlotSeriesItem is to introduce the concept of the "region of interest" and to automatically update the plot item, when the axes scale division has changed.

QwtPlotSeriesItem::updateScaleDiv

[virtual] Update the item to changes of the axes scale division. Update the item, when the axes of plot have changed. The default implementation does nothing, but items that depend on the scale division (like QwtPlotGrid()) have to reimplement updateScaleDiv()

updateScaleDiv() is only called when the ScaleInterest interest is enabled. The default implementation does nothing.

Parameters

xScaleDiv Scale division of the x-axis
yScaleDiv Scale division of the y-axis
