Descripción detallada

template<typename T>

class QwtSeriesStore< T >" Clase para almacenar un objeto QwtSeriesData.

QwtSeriesStore y QwtPlotSeriesItem están pensados como clases base para todos los elementos de gráfico que iteran sobre una serie de muestras. Ambas clases comparten una clase base virtual ( QwtAbstractSeriesStore) para tender puentes entre ellas.

QwtSeriesStore ofrece la parte basada en plantillas para la API del elemento de gráfico, de modo que QwtPlotSeriesItem pueda derivar sin ningún problema con plantillas.
