PPI::Token(3) Documentación de Perl aportada por el usuario PPI::Token(3)

NOMBRE

PPI::Token - Un solo token de código fuente Perl

HERENCIA

PPI::Token
isa PPI::Element

DESCRIPCIÓN

"PPI::Token" es la clase base abstracta para todos los Tokens. En términos de PPI, un "Token" es un PPI::Element que representa directamente bytes de código fuente.

MÉTODOS

establecer_contenido $cadena

El método "establecer_contenido" te permite establecer/cambiar la cadena que representa el objeto "PPI::Token".

Devuelve la cadena a la que se estableció el Token.

agregar_contenido $cadena

El método "agregar_contenido" te permite agregar bytes adicionales de código al final del Token.

Devuelve la nueva cadena completa después de que se agregaron los bytes.

longitud

El método "longitud" devuelve la longitud de la cadena en un Token.
