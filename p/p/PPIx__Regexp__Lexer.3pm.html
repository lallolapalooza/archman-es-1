PPIx::Regexp::Lexer(3) Documentación de Perl contribuida por el usuario PPIx::Regexp::Lexer(3)

NOMBRE

PPIx::Regexp::Lexer - Ensambla la salida del tokenizador.

SINOPSIS

use PPIx::Regexp::Lexer;
use PPIx::Regexp::Dumper;
my $lex = PPIx::Regexp::Lexer->new('qr{foo}smx');
my $dmp = PPIx::Regexp::Dumper->new( $lex );
$dmp->print();

HERENCIA

"PPIx::Regexp::Lexer" es un PPIx::Regexp::Support.

"PPIx::Regexp::Lexer" no tiene descendientes.

DESCRIPCIÓN

Esta clase toma el flujo de tokens generado por PPIx::Regexp::Tokenizer y genera el árbol de análisis sintáctico (parse tree).

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

new

Este método instancia el analizador léxico (lexer). Toma como argumento un PPIx::Regexp::Tokenizer o el texto a analizar. En este último caso, el tokenizador se instancia a partir del texto.

Cualquier par nombre/valor opcional después del primer argumento se pasa al tokenizador, que los interpreta o no según sea el caso.

errstr

Este método devuelve la cadena de error del último intento de instanciar un "PPIx::Regexp::Lexer". Si el último intento tuvo éxito, el error será "undef".

failures

print $lexer->failures(), " fallos de análisis\n";

Este método devuelve el número de fallos de análisis sintáctico encontrados. Un fallo de análisis sintáctico es un fallo de tokenización (ver PPIx::Regexp::Tokenizer->failures()) o un error estructural.

lex

Este método analiza léxicamente los tokens del texto y devuelve la lista analizada de elementos.

strict

Este método devuelve verdadero o falso basándose en el valor del argumento 'strict' pasado a new().
