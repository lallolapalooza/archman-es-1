PPI::Token::Unknown(3) Documentación de Perl aportada por el usuario PPI::Token::Unknown(3)

NOMBRE

PPI::Token::Unknown - Token de tipo desconocido o aún no determinado

HERENCIA

PPI::Token::Unknown
isa PPI::Token
    isa PPI::Element

DESCRIPCIÓN

Los objetos del tipo "PPI::Token::Unknown" existen principalmente dentro del tokenizador, donde se crean temporalmente durante un tiempo muy corto para representar un token que podría ser de varios tipos.

Generalmente, solo existen por un carácter o dos, después de lo cual se resuelven y se convierten al tipo correcto. Se considera un error grave que un objeto de este tipo sobreviva al proceso de análisis.

Por favor, informe de cualquier "PPI::Token::Unknown" que encuentre en un objeto PPI::Document como un error.
