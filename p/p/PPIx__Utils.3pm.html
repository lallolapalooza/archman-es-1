NOMBRE

PPIx::Utils - Funciones de utilidad para PPI

SINOPSIS

use PPIx::Utils qw(:classification :language :traversal);

DESCRIPCIÓN

"PPIx::Utils" es una colección de funciones de utilidad para trabajar con documentos PPI. Las funciones están organizadas en submódulos y pueden ser importadas desde el submódulo correspondiente o a través de este módulo.

Estas funciones provenían originalmente de Perl::Critic::Utils y módulos relacionados, y se han extraído a esta distribución para su uso fuera de Perl::Critic.

MÓDULOS

La etiqueta de importación ":all" importará las funciones de todos los módulos listados a continuación.

PPIx::Utils::Classification

Funciones relacionadas con la clasificación de elementos PPI. Todas las funciones de este módulo pueden ser importadas con la etiqueta de importación ":classification".

PPIx::Utils::Language

Funciones relacionadas con el lenguaje Perl. Todas las funciones de este módulo pueden ser importadas con la etiqueta de importación ":language".

PPIx::Utils::Traversal

Funciones relacionadas con el recorrido de documentos PPI. Todas las funciones de este módulo pueden ser importadas con la etiqueta de importación ":traversal".
