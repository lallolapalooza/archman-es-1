PPI::Exception(3) Documentación de Perl contribuida por el usuario PPI::Exception(3)

NOMBRE

PPI::Exception - La clase base de excepciones de PPI

SINOPSIS

use PPI::Exception;

my $e = PPI::Exception->new( 'algo ocurrió' );
$e->throw;
PPI::Exception->new( message => 'algo ocurrió' )->throw;
PPI::Exception->throw( message => 'algo ocurrió' );

DESCRIPCIÓN

Todas las excepciones lanzadas desde dentro de PPI serán instancias o derivaciones de esta clase.

MÉTODOS

new $mensaje | mensaje => $mensaje, ...

Construye y devuelve un nuevo objeto "PPI::Exception".

Se puede pasar un mensaje para la excepción, ya sea como una cadena o como "message => $mensaje". El mensaje está disponible a través del método "message".

throw

Si se llama en un objeto "PPI::Exception", lanza el objeto. Si se llama en el nombre de la clase, utiliza los argumentos para construir un "PPI::Exception" y luego lanzarlo.

Cada vez que se lanza el objeto, se guarda información de la llamada Perl <caller(0)> y se pone a disposición a través del método "callers".

Este método nunca devuelve.

message

Devuelve el mensaje de la excepción pasado al constructor del objeto, o un mensaje predeterminado.

callers

Devuelve una lista referenciada, cada elemento de la cual es una lista referenciada de información de caller(0). La lista referenciada devuelta puede estar vacía.
