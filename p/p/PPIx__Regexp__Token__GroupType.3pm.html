PPIx__Regexp__Token__GroupType(3pm)

Paquete: perl-ppix-regexp

Licencias: PerlArtistic

PPIx::Regexp::Token::GroupType(3) Documentación de Perl contribuyente PPIx::Regexp::Token::GroupType(3)

NOMBRE

PPIx::Regexp::Token::GroupType - Representar un tipo de grupo de paréntesis.

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(?i:foo)}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Token::GroupType" es un "PPIx::Regexp::Token".

"PPIx::Regexp::Token::GroupType" es el padre de PPIx::Regexp::Token::GroupType::Assertion, PPIx::Regexp::Token::GroupType::Atomic_Script_Run, PPIx::Regexp::Token::GroupType::BranchReset, PPIx::Regexp::Token::GroupType::Code, PPIx::Regexp::Token::GroupType::Modifier, PPIx::Regexp::Token::GroupType::NamedCapture, PPIx::Regexp::Token::GroupType::Script_Run, PPIx::Regexp::Token::GroupType::Subexpression y PPIx::Regexp::Token::GroupType::Switch.

DESCRIPCIÓN

Esta clase representa cualquier secuencia de caracteres mágicos que puedan seguir a un paréntesis de apertura. Esta clase en particular está diseñada para ser abstracta.

MÉTODOS

Esta clase no proporciona ningún método público además de los proporcionados por su superclase.

__defining_string

my $string = $class->__defining_string();

Este método es privado del paquete "PPIx-Regexp" y está documentado solo para el beneficio del autor. Puede ser cambiado o revocado sin previo aviso.

Este método devuelve una matriz de cadenas que definen el tipo específico del grupo. Estas cadenas normalmente empiezan con '?'.

Opcionalmente, el primer elemento devuelto puede ser una referencia a un hash. La única clave soportada es "{suffix}", que es una cadena que se añade al final de cada expresión regular generada por "__make_group_type_matcher()" a partir de las definiciones de cadenas, dentro de "(?= ... )", por lo que no se incluye en el coincidencia.

Este método **debe** ser sobrescrito, a menos que "__make_group_type_matcher()" lo sea. La sobrescritura **debe** devolver lo mismo cada vez, ya que los resultados de "__make_group_type_matcher()" son cacheados.

__make_group_type_matcher

my $hash_ref = $class->__make_group_type_matcher();

Este método es privado del paquete "PPIx-Regexp" y está documentado solo para el beneficio del autor. Puede ser cambiado o revocado sin previo aviso.

Este método devuelve una referencia a un hash. Las claves son caracteres delimitadores de expresiones regulares que aparecen en las definiciones de cadenas del tipo de grupo. Para cada clave, el valor es una referencia a un array de objetos "Regexp", correctamente escapados para el carácter delimitador. La clave '' proporciona las expresiones regulares a utilizar si el delimitador de la expresión regular no aparece en ninguna de las definiciones de cadenas.

Si este método es sobrescrito por la clase derivada, el método "__defining_string()" no debe serlo, a menos que el sobrescrito "__make_group_type_matcher()" llame a "__defining_string()".

__match_setup

$class->__match_setup( $tokenizer );

Este método es privado del paquete "PPIx-Regexp" y está documentado solo para el beneficio del autor. Puede ser cambiado o revocado sin previo aviso.

Este método realiza la configuración necesaria una vez que se ha determinado que el tipo de grupo dado ha sido detectado. Este método se llama solo si la clase ha coincidido en la posición actual del texto que se está analizando. Debe realizar cualquier configuración adicional necesaria para la coincidencia. Devuelve nada.

Este método no debe ser sobrescrito. El valor predeterminado no hace nada.

__setup_class

$class->__setup_class( \%definition, \%opt );

Este método es privado del paquete "PPIx-Regexp" y está documentado solo para el beneficio del autor. Puede ser cambiado o revocado sin previo aviso.

Este método utiliza el hash %definition para crear los métodos "__defining_string()", explain(), perl_version_introduced() y perl_version_removed() para la clase invocada. Cualquiera de estos que ya exista no será reemplazado.

El hash %definition define todas las cadenas que especifican los tokens de la clase invocada. No puedes usar esta mecánica si necesitas una expresión regular para reconocer un token que pertenece a esta clase. Las claves del hash %definition son cadenas que especifican miembros de esta clase. Los valores son hashes que definen el miembro específico de la clase. Los valores soportados son:

{expl}
Esta es la explicación del elemento, que se devuelve por el método explain().
{intro}
Esta es la versión de Perl que introdujo el elemento, como una cadena. El valor predeterminado es el valor de la constante MINIMUM_PERL.
{remov}
Esta es la versión de Perl que eliminó el elemento, como una cadena. El valor predeterminado es "undef", lo que significa que el elemento todavía está presente en la versión más alta de Perl, independientemente de si es de desarrollo o producción.

El hash %opt es opcional y se comporta por defecto como una cadena vacía. Se utiliza básicamente para ad-hoc. Las claves soportadas son:

{suffix}
Si este elemento está definido, el primer elemento devuelto por el método generado _defining_string() es un hash que contiene esta clave y valor.
