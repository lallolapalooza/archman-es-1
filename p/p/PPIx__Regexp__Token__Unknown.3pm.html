PPIx::Regexp::Token::Unknown(3) Documentación de Perl contribuida por el usuario PPIx::Regexp::Token::Unknown(3)

NOMBRE

PPIx::Regexp::Token::Unknown - Representa un token desconocido

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'xyzzy' )
    ->print();

HERENCIA

"PPIx::Regexp::Token::Unknown" es un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Unknown" no tiene descendientes.

DESCRIPCIÓN

Este token representa algo que el tokenizador no pudo identificar. A veces el lexer puede arreglar estos problemas, pero la presencia de uno de estos en un parse finalizado representa algo en la expresión regular que no se entendió.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

is_matcher

Este método devuelve "undef" porque, dado que no pudimos identificar el token, no tenemos idea de si coincide con algo.

ordinal

Este método devuelve los resultados de la función incorporada `ord` sobre el contenido (lo que significa, por supuesto, el primer carácter del contenido). No se hace ningún intento de interpretar el contenido, ya que después de todo este es el token desconocido.
