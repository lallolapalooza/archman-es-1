NOMBRE

PPI::Token::Prototype - Un descriptor de prototipo de subrutina

HERENCIA

PPI::Token::Prototype
isa PPI::Token::Quote::Literal
    isa PPI::Token::Quote
        isa PPI::Token

SINOPSIS

sub ($@) prototype;

DESCRIPCIÓN

Aunque se parece un poco a una lista o condición, un prototipo de subrutina se parece mucho más a una cadena. Su trabajo es proporcionar pistas al compilador de perl sobre qué tipo de argumentos espera una subrutina particular, que el compilador utiliza para validar parámetros en tiempo de compilación y permite a los programadores utilizar las funciones sin paréntesis de parámetros explícitos.

Debido al auge de la programación orientada a objetos en Perl, que ignora estos prototipos, se utilizan sobre todo para permitir cosas similares a constantes y para "extender" el lenguaje y crear cosas que actúan como palabras clave y funciones principales.

# Crear algo que actúe como una constante
sub MYCONSTANT () { 10 }

# Crear la función principal "any"
sub any (&@) { ... }

if ( any { $_->cute } @babies ) {
      ...
}

MÉTODOS

Esta clase proporciona un método adicional más allá de los definidos por las clases padre PPI::Token y PPI::Element.

prototype

El accesor "prototype" devuelve el patrón real del prototipo, despojado de paréntesis circundantes y de todo espacio en blanco. Esto imita el comportamiento de la función incorporada de Perl "prototype".

Tenga en cuenta que despojar los paréntesis y los espacios en blanco significa que el retorno de "prototype" puede ser una cadena vacía.
