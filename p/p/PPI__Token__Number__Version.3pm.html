NOMBRE

PPI::Token::Number::Version - Clase de token para un número empaquetado en bytes

SINOPSIS

$n = 1.1.0;
$n = 127.0.0.1;
$n = 10_000.10_000.10_000;
$n = v1.2.3.4

HERENCIA

PPI::Token::Number::Version
isa PPI::Token::Number
    isa PPI::Token
        isa PPI::Element

DESCRIPCIÓN

La clase "PPI::Token::Number::Version" se utiliza para tokens que tienen múltiples puntos decimales. En realidad, estos no son tratados como números por Perl, pero se parecen a números para un analizador.

MÉTODOS

base

Devuelve la base para el número: 256.

literal

Devuelve el valor numérico de este token.

ERRORES

- No maneja correctamente el signo menos inicial. Debería traducirse a una Palabra con Guiones. Ver http://perlmonks.org/?node_id=574573

-95.0.1.0  --> "-_\000\cA\000"
-96.0.1.0  --> Argumento "`\0^A\0" no es numérico en negación (-)
