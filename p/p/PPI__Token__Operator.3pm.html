PPI__Token__Operator(3pm)

Paquete: perl-ppi

Licencias: PerlArtistic

PPI::Token::Operator(3) Documentación de Perl contribuida por el usuario PPI::Token::Operator(3)

NOMBRE

PPI::Token::Operator - Clase de token para operadores

INHERITANCE

PPI::Token::Operator
isa PPI::Token
    isa PPI::Element

SYNOPSIS

# Esta es la lista de operadores válidos
++   --   **   !    ~    +    -
=~   !~   *    /    %    x
<<   >>   lt   gt   le   ge   cmp  ~~
==   !=   <=>  .    ..   ...  ,
&    |    ^    &&   ||   //
?    :    **=  +=   -=   .=   *=   /=
%=   x=   &=   |=   ^=   <<=  >>=  &&=
||=  //=  <    >    <=   >=   <>   =>   ->
and  or   xor  not  eq   ne   <<>>

DESCRIPCIÓN

Todos los operadores en PPI se crean como objetos "PPI::Token::Operator", incluyendo los que superficialmente pueden parecer un objeto PPI::Token::Word.

MÉTODOS

No hay métodos adicionales más allá de los proporcionados por las clases padre PPI::Token y PPI::Element.
