NOMBRE

PPIx::Regexp::Token::Operator - Representa un operador.

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo|bar}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Token::Operator" es un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Operator" no tiene descendientes.

DESCRIPCIÓN

Esta clase representa un operador. En una clase de caracteres, representa los operadores de negación ("^") y rango ("-"). Fuera de una clase de caracteres, representa el operador de alternancia ("|").

MÉTODOS

Esta clase no proporciona métodos públicos más allá de los proporcionados por su superclase.

operación

Este método devuelve el nombre de la operación realizada por el operador. Esto depende no solo del operador en sí, sino de su contexto:

En una clase de caracteres entre corchetes
'-' => 'range',
'^' => 'inversion',
En una clase de caracteres extendida entre corchetes
'&' => 'intersection',
'+' => 'union',
'|' => 'union',
'-' => 'subtraction',
'^' => 'symmetric_difference',
'!' => 'complement',
Fuera de cualquier tipo de clase de caracteres entre corchetes
'|' => 'alternation',
