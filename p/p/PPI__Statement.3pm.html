PPI::Statement(3) Documentación contribuida por Perl PPI::Statement(3)

NOMBRE

PPI::Statement - Clase base para declaraciones de Perl

HERENCIA

PPI::Statement
isa PPI::Node
    isa PPI::Element

DESCRIPCIÓN

PPI::Statement es la clase raíz para todas las declaraciones de Perl. Esto incluye (de perlsyn) "Declaraciones", "Declaraciones simples" y "Declaraciones compuestas".

La clase PPI::Statement misma representa una "Declaración simple" como se define en la página man de perlsyn.

CLASES DE DECLARACIÓN

Nota: Las clases mencionadas aquí no están documentadas a menos que sean documentadas por sí mismas. Estas clases aún no están fijadas o finalizadas. El nombre puede variar ligeramente o ser agregado o eliminado.

PPI::Statement::Scheduled

Esta cubre todos los "bloques programados", fragmentos de código que se ejecutan por separado de la parte principal del código, en un momento específico. Esto incluye todos los "BEGIN", "CHECK", "UNITCHECK", "INIT" y "END".

PPI::Statement::Package

Una declaración de paquete, como se define en perlfunc.

PPI::Statement::Include

Un estado que carga o descarga otro módulo.

Esta incluye 'use', 'no' y 'require' estados.

PPI::Statement::Sub

Una declaración de subrutina nombrada, o declaración de subrutina

PPI::Statement::Variable

Una declaración de variable. Esto podría ser una declaración directa o también podría ser una expresión.

Esta incluye todas las declaraciones 'my', 'state', 'local' y 'our'.

PPI::Statement::Compound

Esta cubre toda la familia de "Declaraciones compuestas" como se describe en perlsyn.

Esta incluye todas las declaraciones que empiezan con 'if', 'unless', 'for', 'foreach' y 'while'. Nota: esto no incluye 'do', ya que se trata de un caso diferente.

Todas las declaraciones compuestas tienen un final implícito. Es decir, no terminan con un ';'.

PPI::Statement::Break

Una declaración que rompe una estructura.

Esta incluye todos los 'redo', 'goto', 'next', 'last' y 'return'.

PPI::Statement::Given

La clase de declaración introducida en Perl 5.10 que comienza con 'given'. Esta tiene un final implícito.

PPI::Statement::When

La clase de declaración introducida en Perl 5.10 que comienza con 'when' o 'default'. Esta también tiene un final implícito.

PPI::Statement::Data

Una declaración especial que abarca un bloque entero de "__DATA__", incluido el token inicial "__DATA__" y todo el contenido.

PPI::Statement::End

Una declaración especial que abarca un bloque entero de "__END__", incluido el token inicial "__END__" y todo el contenido, incluido cualquier token PPI::Token::POD que pueda estar dentro de él.

PPI::Statement::Expression

PPI::Statement::Expression es un poco más especulativo y está destinado a ayudar a representar las reglas especiales relacionadas con "expresiones" como en:

# Ejemplos de declaraciones de expresión

# Condicionales booleanos
if ( expresión ) { ... }

# Listas, como en argumentos
Foo->bar( expresión )

PPI::Statement::Null

Una declaración de tipo null es un caso especial donde nos encontramos con dos terminadores de instrucción consecutivos. ( ;; )

El segundo terminador recibe un estado completo de su propia, pero uno que no tiene propósito. Por lo tanto, es una declaración 'null'.

Teóricamente, suponiendo que se tenga una correcta interpretación del archivo Perl, todas las declaraciones 'null' son superfluas y deben poder eliminarse sin dañar el archivo.

Pero no lo hagas, en caso de que PPI haya interpretado algo incorrecto.

PPI::Statement::UnmatchedBrace

Dado que PPI está diseñado para usar cuando se parsea código incorrecto o incompleto, el problema de qué hacer con un cierre accidental de corchetes se presenta.

En lugar de morir, se le asigna su propio estado de "bracero no correspondiente", que realmente significa "corchete no correspondiente". Una corchete abierto al final de un archivo se convierte en un estructura con contenido vacío y sin cierre.

Si el documento cargado es intencionalmente correcto, encontrar un PPI::Statement::UnmatchedBrace en el PDOM generalmente indica un mal parseo.

PPI::Statement::Unknown

Este se usa temporalmente durante el parseo para almacenar las instrucciones que el lexer aún no puede determinar cuál clase debo asignar, generalmente debido a que hay insuficientes pistas o podría ser más de una cosa.

No deberías nunca encontrar estos en un árbol PDOM completamente parseado.

MÉTODOS

PPI::Statement mismo tiene muy pocos métodos. La mayoría del tiempo, trabajarás con métodos más generales de PPI::Element o PPI::Node, o con métodos específicos de clase.

label

Un factor común a muchas instrucciones es su capacidad de ser etiquetadas.

El método "label" devuelve la etiqueta de una instrucción, si ha sido definida, pero sin el colón final. Tomemos el ejemplo siguiente:

MYLABEL: while ( 1 .. 10 ) { last MYLABEL if $_ > 5 }

Para la instrucción mostrada, el método "label" devolvería 'MYLABEL'.

Devuelve false si la instrucción no tiene una etiqueta.

specialized

Indica si esta es una instrucción ordinaria o una que tiene más significado.

Devuelve true si la instrucción es una subclase de esta, false en caso contrario.

stable

Muchos como el método de PPI::Document del mismo nombre, el método ->stable convierte una instrucción en fuente y de vuelta para determinar si una instrucción modificada es todavía legal y no se interpretará de forma diferente.

Devuelve true si la instrucción es estable, false si no, o "undef" en caso de error.

PPI::Statement(3pm) — perl

NAME

PPI::Statement - The base class for statements in a Perl document

INHERITANCE

PPI::Statement is a subclass of PPI::Element.

DESCRIPTION

This is the base class for all statement objects within the PPI document tree. A statement is defined as a piece of Perl code that ends with a semicolon, or a block of code delimited by braces.

This class itself is never used. Instead, you'll be dealing with one of its subclasses. The most common are:

  • PPI::Statement::Simple - For statements ending in a semicolon.
  • PPI::Statement::Block - For blocks of code delimited by braces.
  • PPI::Statement::Include - For use and require statements.
  • PPI::Statement::Data - For __DATA__ and __END__ sections.
  • PPI::Statement::Null - For empty statements (like ;;).

See the documentation for each of these subclasses for details.
