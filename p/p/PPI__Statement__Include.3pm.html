Paquete: perl-ppi

PPI::Statement::Include(3) Documentación de Perl aportada por el usuario PPI::Statement::Include(3)

NOMBRE

PPI::Statement::Include - Declaraciones que incluyen otro código

SINOPSIS

# Todos los siguientes son includes
use 5.006;
use strict;
use My::Module;
use constant FOO => 'Foo';
require Foo::Bar;
require "Foo/Bar.pm";
require $foo if 1;
no strict 'refs';

HERENCIA

PPI::Statement::Include
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPCIÓN

A pesar de su nombre, la clase "PPI::Statement::Include" cubre una serie de tipos de declaraciones diferentes que abarcan todas las declaraciones que comienzan con "use", "no" y "require".

Pero básicamente, cubren tres situaciones.

En primer lugar, una dependencia de una versión particular de perl (para la cual el método "version" devuelve true), un pragma (para el cual el método "pragma" devuelve true), o la carga (y descarga mediante no) de módulos.

MÉTODOS

"PPI::Statement::Include" tiene una serie de métodos además de los métodos estándar de PPI::Statement, PPI::Node y PPI::Element.

tipo

El método "type" devuelve el tipo general de la declaración ('use', 'no' o 'require').

Devuelve el tipo como una cadena, o "undef" si el tipo no se puede detectar.

módulo

El método "module" devuelve el nombre del módulo especificado en cualquier declaración de inclusión. Esto incluye nombres de pragmas, ya que los pragmas se implementan como módulos. (Y seamos sinceros, la definición de un pragma puede ser difusa en el mejor de los casos en cualquier caso)

Esto cubre todos estos...

use strict;
use My::Module;
no strict;
require My::Module;

...pero no cubre ninguno de estos...

use 5.006;
require 5.005;
require "explicit/file/name.pl";

Devuelve el nombre del módulo como una cadena, o "undef" si la inclusión no especifica un nombre de módulo.

versión_módulo

El método "module_version" devuelve la versión mínima del módulo requerida por la declaración, si existe.

pragma

El método "pragma" comprueba el uso de una declaración de inclusión como pragma y lo devuelve si es así.

O al menos, eso afirma. En la práctica, es mucho más difícil decir exactamente qué es o qué no es un pragma, porque la definición es difusa.

La "intención" de un pragma es modificar la forma en que funciona el analizador. Esto se hace a través del uso de módulos que realizan diversos tipos de magia interna.

Por ahora, PPI asume que cualquier "nombre de módulo" que sea solo un conjunto de letras minúsculas (y quizás números, como "use utf8;"). Se espera que este comportamiento cambie, muy probablemente a algo que conozca los nombres específicos de los diversos "pragmas".

Devuelve el nombre del pragma, o false ('') si la inclusión no es un pragma.

versión

El método "version" comprueba una declaración de inclusión que introduce una dependencia de la versión de "perl" con la que el código es compatible.

Esto cubre dos declaraciones específicas.

use 5.006;
require 5.006;

Actualmente, la versión se devuelve como una cadena, aunque en el futuro la versión podría devolverse como un objeto de versión. Si desea una representación numérica, use version_literal(). Devuelve false si la declaración no es una dependencia de versión.

literal_versión

El método "version_literal" tiene el mismo comportamiento que version(), pero la versión se devuelve como un literal numérico. Devuelve false si la declaración no es una dependencia de versión.

argumentos

El método "arguments" le proporciona el resto de la declaración después del módulo/pragma y la versión del módulo, es decir, lo que se utilizará para construir lo que se pasa a la subrutina import() del módulo. Esto incluye el operador coma, etc., pero no incluye hijos directos no significativos ni ningún punto y coma final.

mods_característica

# `use feature 'signatures';`
my %mods = $include->feature_mods;
# { signatures => "perl" }
# `use 5.036;`
my %mods = $include->feature_mods;
# { signatures => "perl" }

Devuelve un hashref de las características identificadas como habilitadas por la inclusión, o undef si la inclusión no habilita características. El valor para cada característica indica el proveedor de la característica.
