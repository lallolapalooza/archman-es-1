PPIx::Regexp::Token::Quantifier(3) Documentación de Perl contribuida por el usuario PPIx::Regexp::Token::Quantifier(3)

NOMBRE

PPIx::Regexp::Token::Quantifier - Representa un cuantificador atómico.

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{\w+}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Token::Quantifier" es un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Quantifier" no tiene descendientes.

DESCRIPCIÓN

Esta clase representa un cuantificador atómico; es decir, uno de los caracteres "*", "+" o "?".

Nota que si ocurren dentro de una búsqueda hacia atrás de longitud variable, '?' implica una versión mínima de Perl de 5.29.9, y '+' y '*' se consideran errores de análisis y se vuelven a envolver en el token desconocido.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no están soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

could_be_quantifier

PPIx::Regexp::Token::Quantifier->could_be_quantifier( '*' );

Este método devuelve verdadero si la cadena dada podría ser un cuantificador; es decir, si es '*', '+', o '?'.
