PPIx::Regexp::Structure::Regexp(3) Documentación de Perl aportada por el usuario PPIx::Regexp::Structure::Regexp(3)

NOMBRE

PPIx::Regexp::Structure::Regexp - Representa la expresión regular de nivel superior

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Structure::Regexp" es un PPIx::Regexp::Structure::Main.

"PPIx::Regexp::Structure::Regexp" no tiene descendientes.

DESCRIPCIÓN

Esta clase representa la expresión regular de nivel superior. En el ejemplo dado en la "SINOPSIS", el "{foo}" será representado por esta clase.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no son compatibles en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

capture_names

foreach my $name ( $re->capture_names() ) {
    print "Capture name '$name'\n";
}

Este método devuelve los nombres de captura encontrados en la expresión regular.

max_capture_number

print "Highest used capture number ",
    $re->max_capture_number(), "\n";

Este método devuelve el número de captura más alto utilizado por la expresión regular. Si no hay capturas, el retorno será 0.
