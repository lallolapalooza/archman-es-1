NOMBRE

PPIx::QuoteLike::Constant - Constantes necesarias para PPIx-QuoteLike

SINOPSIS

Este paquete es privado para la distribución "PPIx-QuoteLike".

DESCRIPCIÓN

Este módulo es privado para el paquete "PPIx-QuoteLike". La documentación es para beneficio del autor, quien se reserva el derecho de cambiar o revocar cualquier cosa aquí presente, incluyendo el módulo completo, sin previo aviso.

Este módulo proporciona constantes de manifiesto importables utilizadas por múltiples módulos en el paquete "PPIx-QuoteLike". Nada se exporta por defecto.

CONSTANTES

Se proporcionan las siguientes constantes importables:

@CARP_NOT

Esta variable global contiene los nombres de todos los módulos del paquete. No es una constante en el sentido de "use constant", pero debe residir aquí por razones de herencia.

ARRAY_REF

Esta constante de manifiesto contiene el valor de "ref []", es decir, 'ARRAY'.

MINIMUM_PERL

La versión mínima de Perl entendida por este analizador, como una cadena. Actualmente está configurada en '5.000', ya que es la versión mínima de Perl accesible para el autor.

SUFFICIENT_UTF8_SUPPORT_FOR_WEIRD_DELIMITERS

Un valor booleano que es verdadero si la versión en ejecución de Perl tiene soporte UTF-8 suficiente para nuestros propósitos.

Actualmente eso significa 5.8.3 o superior, con los requisitos específicos de ser "use open qw{ :std :encoding(utf-8) }", "/\p{Mark}/", y la capacidad de analizar cosas como "qr \N{U+FFFF}foo\N{U+FFFF}".

VARIABLE_RE

Esta constante es un objeto de expresión regular que coincide con los nombres de variables de Perl, sin el sigilo inicial. No se captura nada.
