PPIx::Regexp::Token::Reference(3) Documentación de Perl aportada por el usuario PPIx::Regexp::Token::Reference(3)

NOMBRE

PPIx::Regexp::Token::Reference - Representa una referencia a una captura

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{\1}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Token::Reference" es un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Reference" es el padre de PPIx::Regexp::Token::Backreference, PPIx::Regexp::Token::Condition y PPIx::Regexp::Token::Recursion.

DESCRIPCIÓN

Esta clase abstracta representa una referencia a un búfer de captura, ya sea numerado o con nombre. Nunca debe ser instanciada, pero proporciona una serie de métodos a sus subclases.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

absoluto

print "La referencia absoluta es ", $ref->absolute(), "\n";

Este método devuelve el número absoluto del búfer de captura al que se hace referencia. Es lo mismo que número() para referencias numéricas sin signo. Si la referencia es a un búfer con nombre, se devuelve "undef".

es_con_nombre

$ref->es_con_nombre and print "referencia con nombre\n";

Este método devuelve verdadero si la referencia tiene nombre en lugar de ser numerada.

es_relativa

$ref->es_relativa()
    and print "referencia numerada relativa\n";

Este método devuelve verdadero si la referencia está numerada y es un número relativo (es decir, si está con signo).

es_coincidencia

Este método devuelve un valor verdadero porque, aunque no realizamos un análisis de la entidad referenciada, presuponemos que coincide con algo.

nombre

print "El nombre es ", $ref->nombre(), "\n";

Este método devuelve el nombre del búfer de captura al que se refiere. En el caso de una referencia a una captura numerada (es decir, si "es_con_nombre" devuelve falso), este método devuelve "undef".

número

print "El número es ", $ref->número(), "\n";

Este método devuelve el número del búfer de captura al que se refiere. En el caso de una referencia a una captura con nombre (es decir, si "es_con_nombre" devuelve verdadero), este método devuelve "undef".
