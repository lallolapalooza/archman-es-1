NOMBRE

PPI::Statement::Variable - Declaraciones de variables

SINOPSIS

# Todas las siguientes son declaraciones de variables
my $foo = 1;
my ($foo, $bar) = (1, 2);
our $foo = 1;
local $foo;
local $foo = 1;
LABEL: my $foo = 1;

HERENCIA

PPI::Statement::Variable
isa PPI::Statement::Expression
    isa PPI::Statement
        isa PPI::Node
            isa PPI::Element

DESCRIPCIÓN

La intención principal de la clase "PPI::Statement::Variable" es describir sentencias simples que declaran explícitamente nuevas variables locales o globales.

Tenga en cuenta que esto no la convierte exclusivamente en el único lugar donde se definen variables, y más adelante debería esperar que el método "variables" migre más abajo en el árbol, a PPI::Statement o PPI::Node, para reconocer este hecho, pero por ahora permanece aquí.

MÉTODOS

type

El método "type" comprueba y devuelve el tipo de declaración de la sentencia, que será uno de 'my', 'local', 'our' o 'state'.

Devuelve una cadena con el tipo, o "undef" si el tipo no se puede detectar (lo cual probablemente sea un error).

variables

Al igual que otros tipos de Elementos PDOM que pueden declarar variables, el método "variables" devuelve una lista de las formas canónicas de las variables definidas por la sentencia.

Devuelve una lista de las formas canónicas de cadena de las variables, o la lista nula si no puede encontrar ninguna variable.

symbols

Devuelve una lista de las variables definidas por la sentencia, como PPI::Token::Symbols.
