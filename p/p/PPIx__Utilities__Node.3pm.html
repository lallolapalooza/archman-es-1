PPIx::Utilities::Node(3) Documentación de Perl aportada por el usuario PPIx::Utilities::Node(3)

NOMBRE

PPIx::Utilities::Node - Extensiones de PPI::Node.

VERSIÓN

Este documento describe la versión 1.1.0 de PPIx::Utilities::Node.

SINOPSIS

use PPIx::Utilities::Node qw< split_ppi_node_by_namespace >;
my $dom = PPI::Document->new("...");
while (
    my ($namespace, $sub_doms) = each split_ppi_node_by_namespace($dom)
) {
    foreach my $sub_dom ( @{$sub_doms} ) {
        ...
    }
}

DESCRIPCIÓN

Esta es una colección de funciones para trabajar con PPI::Nodes.

INTERFAZ

No se exporta nada por defecto.

split_ppi_node_by_namespace($nodo)

Devuelve los sub-árboles para cada espacio de nombres en el nodo como una referencia a un hash de referencias a arrays de PPI::Nodes. Supongamos que tenemos el siguiente código:

#!perl
my $x = blah();
package Foo;
my $y = blah_blah();
{
    say 'Whee!';
    package Bar;
    something();
}
thingy();
package Baz;
da_da_da();
package Foo;
foreach ( blrfl() ) {
    ...
}

Llamar a esta función en un PPI::Document para lo anterior devuelve un valor que se parece a esto, utilizando literales de cadena multilínea para las partes de código reales en lugar de árboles PPI para facilitar la lectura:

{
    main    => [
        q<
            #!perl
            my $x = blah();
        >,
    ],
    Foo     => [
        q<
            package Foo;
            my $y = blah_blah();
            {
                say 'Whee!';
            }
            thingy();
        >,
        q<
            package Foo;
            foreach ( blrfl() ) {
                ...
            }
        >,
    ],
    Bar     => [
        q<
            package Bar;
            something();
        >,
    ],
    Baz     => [
        q<
            package Baz;
            da_da_da();
        >,
    ],
}

Tenga en cuenta que el valor de retorno contiene copias de los nodos originales, y no los nodos originales en sí, debido a la necesidad de manejar espacios de nombres que no están definidos a nivel de archivo. (Observe cómo el primer elemento para "Foo" arriba difiere del código original.)
