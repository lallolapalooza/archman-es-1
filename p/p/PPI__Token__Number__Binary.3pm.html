NOMBRE

PPI::Token::Number::Binary - Clase de token para un número binario

SINOPSIS

$n = 0b1110011;  # entero binario

HERENCIA

PPI::Token::Number::Binary
isa PPI::Token::Number
    isa PPI::Token
        isa PPI::Element

DESCRIPCION

La clase "PPI::Token::Number::Binary" se utiliza para tokens que representan números en base 2.

METODOS

base

Devuelve la base del número: 2.

literal

Devuelve el valor numérico de este token.
