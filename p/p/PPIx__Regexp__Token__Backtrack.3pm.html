NOMBRE

PPIx::Regexp::Token::Backtrack - Representar control de retroceso.

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(*ACCEPT)}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Token::Backtrack" es un PPIx::Regexp::Token.

"PPIx::Regexp::Token::Backtrack" no tiene descendientes.

DESCRIPCIÓN

Esta clase representa uno de los controles de retroceso.

MÉTODOS

Esta clase no proporciona métodos públicos más allá de los proporcionados por su superclase.

arg

Este método devuelve el argumento de control de retroceso especificado por el elemento. Este es el texto después de los dos puntos (':'), o la cadena vacía ('') si no se especificó ninguno.

verb

Este método devuelve el verbo de control de retroceso representado por el elemento. Este es el texto hasta pero sin incluir los dos puntos (':') si los hay. Si el elemento especifica '' o "'F"", este método devolverá 'MARK' o 'FAIL', respectivamente.
