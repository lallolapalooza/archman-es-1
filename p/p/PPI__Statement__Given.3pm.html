PPI::Statement::Given(3) Documentación de Perl aportada por el usuario PPI::Statement::Given(3)

NOMBRE

PPI::Statement::Given - Una declaración given-when

SINOPSIS

given ( foo ) {
    say $_;
}

HERENCIA

PPI::Statement::Given
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPCIÓN

Los objetos "PPI::Statement::Given" se utilizan para describir las declaraciones switch, como se describe en perlsyn.

MÉTODOS

"PPI::Statement::Given" no tiene métodos más allá de los proporcionados por los métodos estándar PPI::Structure, PPI::Node y PPI::Element.
