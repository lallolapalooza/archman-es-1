NAME

PPI::Structure - La clase base para estructuras de Perl con corchetes

INHERITANCE

PPI::Structure
isa PPI::Node
    isa PPI::Element

DESCRIPTION

PPI::Structure es la clase raíz para todas las estructuras de Perl con corchetes. Esto abarca todos los tipos de " [ ... ] ", " { ... } " y " ( ... ) " y incluye casos donde solo una parte de la pareja exista.

La clase PPI::Structure misma es completamente abstracta y no debe existir en ningún nodo del árbol.

Elementos vs Hijos

Un PPI::Structure tiene una existencia peculiar. A diferencia de un PPI::Document o un PPI::Statement, que ambos simplemente contienen otros elementos, una estructura tanto contiene como consiste en contenido.

Es decir, los corchetes no son considerados como hijos de la estructura, sino que son parte de ella.

En la práctica, esto significa que aunque los métodos ->elements y ->tokens (y relacionados) sí devolverán una lista con los corchetes al inicio y al final, el método ->children explícitamente no devolverá los corchetes.

CLASES DE ESTRUCTURA

Excluyendo el transitorio PPI::Structure::Unknown que existe brevemente dentro del parser, hay ocho tipos de estructura.

PPI::Structure::List

Esto cubre todos los corchetes redondos utilizados para argumentos de funciones, en bucles "foreach", listas literales y corchetes utilizados para el orden de precedencia.

PPI::Structure::For

Aunque no se utiliza para bucles "foreach", este sí se utiliza para el caso especial de un bucle de tres partes con corchetes redondos separados por punto y coma "for" (el estilo tradicional de bucle C).

PPI::Structure::Given

Esto es para la expresión que se corresponde en los casos de "switch".

PPI::Structure::When

Esto es para la expresión que se corresponde en los casos de sentencias "when".

PPI::Structure::Condition

Esta estructura de corchetes cubre los corchetes de condicional booleano, como para bloques "if" y "while".

PPI::Structure::Block

Esta estructura de corchetes y común se utiliza para todos los bloques de código. Incluye los bloques para "if", "do" y similares, así como los bloques para "grep", "map", "sort", "sub" y bloques de ámbito (etiquetados o anónimos).

PPI::Structure::Constructor

Esta clase cubre los corchetes utilizados para la construcción de referencias anónimas "ARRAY" y "HASH".

PPI::Structure::Subscript

Esta clase cubre los corchetes redondos y cuadrados utilizados después de un "-> para acceder al subíndice de un "ARRAY" o "HASH".

MÉTODOS

"PPI::Structure" tiene pocos métodos. La mayoría del tiempo, trabajarás con métodos más generales como los de PPI::Element o PPI::Node, o con métodos específicos de clase.

start

Para falta de mejores términos (como "open" y "close" que ya se usan en otros propósitos más importantes), los dos corchetes individuales para la estructura se conocen dentro de PPI como el "start" y "finish" (aunque en el contexto de métodos).

El método "start" devuelve el corchete de inicio para la estructura (es decir, el corchete de apertura).

Devuelve el corchete como un PPI::Token::Structure o "undef" si no tiene un corchete de inicio.

Normalmente, esto no debería ocurrir, pero puede ocurrir debido a la manipulación del árbol PDOM.

finish

El método "finish" devuelve el corchete de fin para la estructura (es decir, el corchete de cierre).

Devuelve el corchete como un PPI::Token::Structure o "undef" si no tiene un corchete de cierre. Esto puede ser bastante común si el documento no está completo (por ejemplo, desde un editor donde el usuario podría estar medio escribiendo una función).

braces

El método "braces" es un método de utilidad que devuelve el tipo de corchete, independientemente de si ambos o solo uno están definidos.

Devuelve uno de los tres strings '[]', '{}' o '()', o "undef" en caso de error (principalmente no tener un corchete de inicio, como mencionado anteriormente).

complete

El método "complete" es un método de conveniencia que devuelve verdadero si ambos corchetes están definidos para la estructura, o falso si solo uno está definido.

A diferencia del método de nivel superior "complete" que verifica la completitud en profundidad, el método "complete" de la estructura solo confirma la completitud de los corchetes y no recurre abajo.
