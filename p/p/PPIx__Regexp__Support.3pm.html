PPIx::Regexp::Support(3) Documentación de Perl aportada por el usuario PPIx::Regexp::Support(3)

NOMBRE

PPIx::Regexp::Support - Base para las clases de soporte de PPIx::Regexp

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Support" no desciende de ninguna otra clase.

"PPIx::Regexp::Support" es el padre de PPIx::Regexp::Dumper, PPIx::Regexp::Lexer y PPIx::Regexp::Tokenizer.

DESCRIPCIÓN

Esta clase abstracta proporciona métodos para las clases de soporte de "PPIx::Regexp".

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no admitidos en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

close_bracket

Este método toma un carácter como argumento. Si este carácter es un corchete de apertura, se devuelve el corchete de cierre correspondiente. De lo contrario, se devuelve "undef". Solo se consideran corchetes los caracteres de corchete ASCII: (), {}, [], y <>.

decode

Este método envuelve la subrutina Encode::decode. Si el objeto no especifica ninguna codificación o encode_available() devuelve falso, este método simplemente devuelve su cadena de entrada.

encode

Este método envuelve la subrutina Encode::encode. Si el objeto no especifica ninguna codificación o encode_available() devuelve falso, este método simplemente devuelve su cadena de entrada.

encode_available

Este método devuelve verdadero si el módulo Encode está disponible y falso en caso contrario. Si devuelve verdadero, el módulo Encode se ha cargado realmente.
