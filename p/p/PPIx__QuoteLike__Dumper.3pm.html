PPIx__QuoteLike__Dumper(3pm)

Paquete: perl-ppix-quotelike

PPIx::QuoteLike::Dumper(3) Documentación de Perl aportada por el usuario PPIx::QuoteLike::Dumper(3)

NOMBRE

PPIx::QuoteLike::Dumper - Volcar los resultados del análisis de elementos similares a comillas

SINOPSIS

use PPIx::QuoteLike::Dumper;
PPIx::QuoteLike::Dumper->new( '"foo$bar baz"' )
  ->print();

DESCRIPCIÓN

Esta clase genera una volcado formateado de un objeto PPIx::QuoteLike, o una cadena que puede convertirse en dicho objeto.

MÉTODOS

Esta clase soporta los siguientes métodos públicos. Los métodos no documentados aquí son privados y no soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

new

my $dumper = PPIx::QuoteLike::Dumper->new(
    '"foo$bar baz"',
    variables  => 1,
);

Este método estático instancia el volcado. Toma la cadena o el objeto PPIx::QuoteLike a volcar como primer argumento. Se pueden pasar argumentos adicionales opcionales como pares nombre/valor.

Se reconocen los siguientes argumentos opcionales:

encoding nombre
Este argumento es la codificación del objeto a volcar. Se pasa a PPIx::QuoteLike new() a menos que el primer argumento fuera un objeto PPIx::QuoteLike, en cuyo caso se ignora.
indent número
Este argumento especifica el número de espacios adicionales para indentar cada nivel de la jerarquía de análisis. Se ignora si el argumento "tokens" es verdadero.

El valor predeterminado es 2.

margin número
Este argumento es el número de espacios adicionales para indentar la jerarquía de análisis, además de los especificados por el margen.

El valor predeterminado es 0.

perl_version Booleano
Este argumento especifica si las versiones de perl introducidas y eliminadas se incluyen o no en el volcado.

El valor predeterminado es 0 (es decir, falso).

postderef Booleano
ESTE ARGUMENTO ESTÁ DESAPROBADO. Consulte el AVISO DE DESAPROBACIÓN en PPIx::QuoteLike para obtener detalles.

Este argumento especifica si las desreferencias postfijas se reconocen o no en las interpolaciones. Se pasa a PPIx::QuoteLike new() a menos que el primer argumento fuera un objeto PPIx::QuoteLike, en cuyo caso se ignora.

ppi Booleano
Este argumento especifica si se proporciona o no un volcado PPI para las interpolaciones.

El valor predeterminado es 0 (es decir, falso).

short Booleano
Si es verdadero, los prefijos 'PPIx::QuoteLike::' se eliminarán de los nombres de clase en la salida.
tokens booleano
Si es verdadero, este argumento provoca un volcado no estructurado de los tokens encontrados en el análisis.

El valor predeterminado es 0 (es decir, falso).

variables Booleano
Si es verdadero, este argumento provoca que se vuelquen todas las variables realmente interpoladas por cualquier interpolación.

El valor predeterminado es 0 (es decir, falso).

dump

print PPIx::Regexp::Dumper->dump( 'foo/bar.pl',
    variables => 1,
);

Este método estático devuelve una cadena que representa un volcado de su primer argumento. Toma los mismos argumentos opcionales que new(). Este método difiere de new() en su interpretación del primer argumento.

  • Si el primer argumento es el nombre de un archivo, o es una referencia SCALAR, se convierte en un PPI::Document y se vuelcan todas las cadenas del documento.
  • Si el primer argumento es un PPI::Node, se vuelcan todas las cadenas del nodo. Tenga en cuenta que un PPI::Document es un PPI::Node.

De lo contrario, el primer argumento se maneja igual que lo haría new().

El retorno es la representación en cadena del volcado.

Además de los argumentos opcionales aceptados por new(), se pueden especificar los siguientes:

none
Este argumento especifica una cadena a devolver si no se puede producir ningún volcado (normalmente porque el primer argumento no es ni un nombre de archivo ni texto reconocido por este paquete). Si no se especifica, o se especifica como "undef", no se devuelve nada en este caso.

La salida para un objeto individual similar a comillas difiere de la salida de string() en el mismo objeto en que va precedida por la cadena literal que se está volcando, y la información del archivo y la ubicación si se puede determinar.

list

print map { "$_\n" } $dumper->list();

Este método devuelve una matriz que contiene la salida del volcado, una línea por elemento. La salida no tiene margen izquierdo aplicado, ni saltos de línea finales. Es probable que haya saltos de línea incrustados si el argumento "ppi" se especificó al instanciar el volcado.

print

$dumper->print();

Este método simplemente imprime el resultado de "string" en la salida estándar.

string

print $dumper->string();

Este método agrega margen izquierdo y saltos de línea a la salida de "list", concatena el resultado en una sola cadena y devuelve esa cadena.
