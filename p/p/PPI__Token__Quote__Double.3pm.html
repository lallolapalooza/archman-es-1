NOMBRE

PPI::Token::Quote::Double - Un token de "comillas dobles" estándar

HERENCIA

PPI::Token::Quote::Double
isa PPI::Token::Quote
    isa PPI::Token
        isa PPI::Element

DESCRIPCIÓN

Un objeto "PPI::Token::Quote::Double" representa una cadena interpolada entre comillas dobles.

La cadena se trata como una entidad única, PPI no intentará comprender lo que hay dentro de la cadena durante el proceso de análisis.

MÉTODOS

Hay varios métodos disponibles para "PPI::Token::Quote::Double", además de los proporcionados por las clases padre PPI::Token::Quote, PPI::Token y PPI::Element.

interpolaciones

El método interpolations comprueba si las comillas dobles contienen realmente alguna variable interpolada.

Devuelve verdadero si la cadena contiene interpolaciones, o falso si no.

simplificar

Por diversas razones, algunas personas se ven obligadas a tener su código en la forma más simple posible.

El método "simplify", si es posible, modificará un token de cadena simple entre comillas dobles in situ, convirtiéndolo en la cadena equivalente entre comillas simples. Si el token se modifica, se re-bendecirá en el paquete PPI::Token::Quote::Single.

Dado que la longitud del contenido no cambia, no es necesario llamar al método "flush_locations" del documento.

El propio objeto se devuelve como una conveniencia.
