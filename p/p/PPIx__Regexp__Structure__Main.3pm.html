PPIx::Regexp::Structure::Main(3) Documentación de Perl aportada por el usuario PPIx::Regexp::Structure::Main(3)

NOMBRE

PPIx::Regexp::Structure::Main - Representa una expresión regular propia, o una sustitución

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Structure::Main" es un PPIx::Regexp::Structure.

"PPIx::Regexp::Structure::Main" es el padre de PPIx::Regexp::Structure::Regexp y PPIx::Regexp::Structure::Replacement.

DESCRIPCIÓN

Esta clase abstracta representa una de las estructuras de nivel superior en la expresión. Tanto PPIx::Regexp::Structure::Regexp como PPIx::Regexp::Structure::Replacement se derivan de ella.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no se admiten en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

delimiters

Este método devuelve una cadena que representa los delimitadores de una expresión regular o una cadena de sustitución. En el caso de algo como "s/foo/bar/", devolverá '//' tanto para la expresión regular como para el reemplazo.

interpolates

Este método devuelve verdadero si la expresión regular o el reemplazo se interpola y falso en caso contrario. Todo lo que realmente hace es comprobar si el delimitador final es una comilla simple.
