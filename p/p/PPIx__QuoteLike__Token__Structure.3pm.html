PPIx::QuoteLike::Token::Structure(3) Documentación de Perl aportada por el usuario PPIx::QuoteLike::Token::Structure(3)

NOMBRE

PPIx::QuoteLike::Token::Structure - Representa la estructura de la cadena.

SINOPSIS

Esta clase no debe ser instanciada por el usuario. Ver abajo para los métodos públicos.

HERENCIA

"PPIx::QuoteLike::Token::Structure" es un PPIx::QuoteLike::Token.

"PPIx::QuoteLike::Token::Structure" es el padre de PPIx::QuoteLike::Token::Delimiter.

DESCRIPCIÓN

Esta clase de Perl representa el token inicial en la cadena; es decir, el 'q', 'qq', 'qx' o (para here documents) '<<' , junto con cualquier espacio final. Para las cadenas que no tienen un token inicial (es decir, aquellas simplemente entre comillas) esta será la cadena vacía.
