PPIx__QuoteLike__Token(3pm)

Paquete: perl-ppix-quotelike

PPIx::QuoteLike::Token(3) Documentación de Perl contribuida por el usuario PPIx::QuoteLike::Token(3)

NOMBRE

PPIx::QuoteLike::Token - Representa cualquier token.

SINOPSIS

Esta es una clase abstracta y no debe ser instanciada por el usuario.

DESCRIPCIÓN

Este módulo Perl representa la base de la jerarquía de tokens.

HERENCIA

"PPIx::QuoteLike::Token" no desciende de ninguna otra clase.

"PPIx::QuoteLike::Token" es el padre de PPIx::QuoteLike::Token::Control, PPIx::QuoteLike::Token::Interpolation, PPIx::QuoteLike::Token::String, PPIx::QuoteLike::Token::Structure, PPIx::QuoteLike::Token::Unknown y PPIx::QuoteLike::Token::Whitespace.

MÉTODOS

Esta clase soporta los siguientes métodos públicos:

column_number

Este método devuelve el número de columna del primer carácter del elemento, o "undef" si no se puede determinar.

content

say $token->content();

Este método devuelve el texto que compone el token.

error

say $token->error();

Este método devuelve el texto del error. Será "undef" a menos que el token represente realmente un error.

line_number

Este método devuelve el número de línea del primer carácter del elemento, o "undef" si no se puede determinar.

location

Este método devuelve una referencia a un array que describe la posición del elemento en la cadena, o "undef" si la ubicación no está disponible.

El array es compatible con el método correspondiente de PPI::Element.

logical_filename

Este método devuelve el nombre lógico del archivo (teniendo en cuenta las directivas "#line") del archivo que contiene el primer carácter del elemento, o "undef" si no se puede determinar.

logical_line_number

Este método devuelve el número de línea lógico (teniendo en cuenta las directivas "#line") del primer carácter del elemento, o "undef" si no se puede determinar.

parent

my $parent = $token->parent();

Este método devuelve el padre del token, que será el objeto PPIx::QuoteLike que lo contiene.

next_sibling

my $next = $token->next_sibling();

Este método devuelve el token posterior al invocante, o nada si no hay ninguno.

perl_version_introduced

Este método devuelve la versión de Perl en la que se introdujo el elemento. Será al menos 5.000. Antes de 5.006 dependo de la documentación de perldelta, perlre y perlop, ya que no he podido compilar versiones anteriores de Perl. Como no he encontrado documentación anterior a 5.003, asumo que todo lo encontrado en 5.003 también está en 5.000.

Dado que todo esto depende de mi capacidad para leer y comprender masas de documentación, los resultados de este método deben ser vistos con cautela, si no directamente con escepticismo.

También hay casos que son ambiguos de diversas maneras. Para ellos, consulte "RESTRICCIONES" en PPIx::Regexp, y especialmente "Cambios en la sintaxis" en PPIx::Regexp.

perl_version_removed

Este método devuelve la versión de Perl en la que se eliminó el elemento. Si el elemento sigue siendo válido, la devolución es "undef".

Todas las advertencias para perl_version_introduced() se aplican aquí también, aunque quizás de forma menos severa ya que, aunque muchas características se han introducido desde 5.0, pocas se han eliminado.

previous_sibling

my $prev = $token->previous_sibling();

Este método devuelve el token anterior al invocante, o nada si no hay ninguno.

significant

$token->significant()
    and say 'significativo';

Este método booleano devuelve un valor verdadero si el token es significativo y un valor falso en caso contrario.

snext_sibling

my $next = $token->snext_sibling();

Este método devuelve el token significativo posterior al invocante, o nada si no hay ninguno.

sprevious_sibling

my $prev = $token->sprevious_sibling();

Este método devuelve el token significativo anterior al invocante, o nada si no hay ninguno.

statement

Este método devuelve la sentencia PPI::Statement que contiene este token, o nada si no se puede determinar la sentencia.

En general, este método devolverá algo solo bajo las siguientes condiciones:

  • El token está contenido en un objeto PPIx::QuoteLike;
  • Ese objeto fue inicializado desde un PPI::Element;
  • El PPI::Element está contenido en una sentencia.

top

Este método devuelve la parte superior de la jerarquía.

variables

say "Interpola $_" for $elem->variables();

TENGA EN CUENTA que este método no está recomendado y puede que sea obsoleto y eliminado. Tengo dos problemas con él. El primero es que devuelve nombres de variables en lugar de objetos PPI::Element, dejándote sin idea de cómo se utilizan las variables. El segundo es que no maneja correctamente cosas como "${^CAPTURE[0]}", y parece inviable que lo haga. Originalmente se escribió para el beneficio de Perl::Critic::Policy::Variables::ProhibitUnusedVarsStricter, pero ha resultado inadecuado para las necesidades de esa política.

Este método de conveniencia devuelve todas las variables interpoladas. Cada una se devuelve solo una vez y no se devuelven en ningún orden particular.

TENGA EN CUENTA que como esta clase no representa una interpolación, este método no devuelve nada.

visual_column_number

Este método devuelve el número de columna visual (teniendo en cuenta las tabulaciones) del primer carácter del elemento, o "undef" si no se puede determinar.
