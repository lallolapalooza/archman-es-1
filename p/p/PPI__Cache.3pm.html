NOMBRE

PPI::Cache - La capa de caché de documentos de PPI

SINOPSIS

# Establecer la caché
use PPI::Cache path => '/var/cache/ppi-cache';

# Crear una caché manualmente
my $Cache = PPI::Cache->new(
    path     => '/var/cache/perl/class-PPI',
    readonly => 1,
);

DESCRIPCIÓN

"PPI::Cache" proporciona la funcionalidad de caché predeterminada para PPI.

Se integra automáticamente con PPI. Una vez habilitado, cualquier intento de cargar un documento desde el sistema de archivos se almacenará en caché a través de la caché.

Tenga en cuenta que la creación de un PPI::Document a partir de código fuente en bruto u otro objeto **no** se almacenará en caché.

Uso de PPI::Cache

La forma más común de usar "PPI::Cache" es proporcionar parámetros a la sentencia "use" al principio de su programa.

# Cargar la clase pero no establecer una caché
use PPI::Cache;

# Usar una ubicación de caché bastante normal
use PPI::Cache path => '/var/cache/ppi-cache';

Cualquiera de los argumentos que se pueden proporcionar al constructor "new" también se puede proporcionar a "use".

MÉTODOS

new param => $value, ...

El constructor "new" crea un nuevo objeto de caché independiente.

Acepta varios parámetros para controlar la caché.

path
El parámetro "path" establece el directorio base para la caché. Debe existir y ser escribible.
readonly
El parámetro "readonly" es una bandera booleana que permite el uso de una caché existente por un usuario con privilegios menores (como el usuario web).

Los documentos existentes se recuperarán de la caché, pero los documentos nuevos no se escribirán en ella.

Devuelve un nuevo objeto "PPI::Cache", o falla si hay un error.

path

El accesor "path" devuelve la ruta en el sistema de archivos local que es la raíz de la caché.

readonly

El accesor "readonly" devuelve verdadero si los documentos no deben escribirse en la caché.

get_document $md5sum | \$source

El método "get_document" comprueba si un Documento está almacenado en la caché y lo recupera si es así.

store_document $Document

El método "store_document" toma un PPI::Document como argumento y lo agrega explícitamente a la caché.

Devuelve verdadero si se guardó, o "undef" (o falla) si hay un error.
