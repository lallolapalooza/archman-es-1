PPIx::QuoteLike::Utils(3) Documentación de Perl contribuida por el usuario PPIx::QuoteLike::Utils(3)

NOMBRE

PPIx::QuoteLike::Utils - Subrutinas de utilidad para PPIx::QuoteLike;

SINOPSIS

use PPIx::QuoteLike::Utils qw{ __variables };

say for __variables( PPI::Document->new( \'$foo' );

DESCRIPCIÓN

Este módulo Perl contiene código para PPIx::QuoteLike que no parecía encajar en ningún otro lugar.

SUBRUTINAS

Este módulo soporta las siguientes subrutinas públicas:

column_number

Esta subrutina/método devuelve el número de columna del primer carácter del elemento, o "undef" si no se puede determinar.

is_ppi_quotelike_element

Esta subrutina devuelve verdadero si su argumento es un Elemento PPI que este paquete es capaz de manejar. Es decir, uno de los siguientes:

PPI::Token::Quote
PPI::Token::QuoteLike::Backtick
PPI::Token::QuoteLike::Command
PPI::Token::QuoteLike::Readline
PPI::Token::HereDoc

Devuelve falso para referencias no bendecidas y para no-referencias.

line_number

Esta subrutina/método devuelve el número de línea del primer carácter del elemento, o "undef" si no se puede determinar.

logical_filename

Esta subrutina/método devuelve el nombre lógico del archivo (teniendo en cuenta las directivas "#line") del archivo que contiene el primer carácter del elemento, o "undef" si no se puede determinar.

logical_line_number

Esta subrutina/método devuelve el número lógico de línea (teniendo en cuenta las directivas "#line") del primer carácter del elemento, o "undef" si no se puede determinar.

__normalize_interpolation_for_ppi

A pesar de los guiones iniciales, esta subrutina exportable es pública y está soportada. Los guiones son para que no aparezca como código público para varias herramientas cuando se importa en otro código.

Esta subrutina toma como argumento una cadena que representa una interpolación. Elimina cosas como llaves alrededor de nombres de variables para convertirla en un Perl más normal -- es decir, un Perl que produce un parseo PPI más normal. Ejemplos de transformaciones son:

'${foo}'        => '$foo'
'@{[ foo() ]}'  => 'foo()'
'${\( foo() )}' => 'foo()'

NOTA que esto no está diseñado para la limpieza general de código. Específicamente, asume que su argumento es una interpolación y solo una interpolación. Alimentarla con cualquier otra cosa no está soportado, y probablemente no devolverá nada útil.

statement

Esta subrutina/método devuelve el `PPI::Statement` que contiene este elemento, o nada si no se puede determinar la sentencia.

En general, este método devolverá algo solo bajo las siguientes condiciones:

  • El elemento está contenido en un objeto `PPIx::Regexp`;
  • Ese objeto fue inicializado desde un `PPI::Element`;
  • El `PPI::Element` está contenido en una sentencia.

visual_column_number

Esta subrutina/método devuelve el número de columna visual (teniendo en cuenta las tabulaciones) del primer carácter del elemento, o "undef" si no se puede determinar.

__variables

say for __variables( PPI::Document->new( \'$foo' );

NOTA que esta subrutina está desaconsejada y podría ser deprecada y eliminada. Tengo dos problemas con ella. El primero es que devuelve nombres de variables en lugar de objetos `PPI::Element`, dejándote sin idea de cómo se usan las variables. El segundo es que no maneja correctamente cosas como "${^CAPTURE[0]}", y parece infactible hacer que lo haga. Originalmente fue escrita para el beneficio de `Perl::Critic::Policy::Variables::ProhibitUnusedVarsStricter`, pero ha demostrado ser inadecuada para las necesidades de esa política.

A pesar de los guiones iniciales, esta subrutina exportable es pública y está soportada. Los guiones son para que no aparezca como código público para varias herramientas cuando se importa en otro código.

Esta subrutina toma como único argumento un `PPI::Element`, y devuelve los nombres de todas las variables encontradas en ese elemento, sin orden particular. El ámbito no se tiene en cuenta.

Además de informar sobre variables analizadas como tales por PPI, y varios casos límite como "${]}" donde PPI no es consciente del uso de la variable, esta subrutina busca dentro de las siguientes clases PPI:

PPI::Token::Quote
PPI::Token::QuoteLike::Backtick
PPI::Token::QuoteLike::Command
PPI::Token::QuoteLike::Readline
PPI::Token::HereDoc

Si `PPIx::Regexp` está instalado, también buscará dentro de

PPI::Token::QuoteLike::Regexp
PPI::Token::Regexp::Match
PPI::Token::Regexp::Substitute

Desafortunadamente, no puedo hacer de "PPIx::Regexp" un requisito para este módulo, debido a la posibilidad de una dependencia circular.
