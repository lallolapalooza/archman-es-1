PPI::Token::Symbol(3) Documentación de Perl contribuida por el usuario PPI::Token::Symbol(3)

NOMBRE

PPI::Token::Symbol - Una clase de token para variables y otros símbolos

HERENCIA

PPI::Token::Symbol
isa PPI::Token
    isa PPI::Element

DESCRIPCIÓN

La clase "PPI::Token::Symbol" se utiliza para cubrir todos los tokens que representan variables y otras cosas que comienzan con un sigilo.

MÉTODOS

Esta clase tiene varios métodos además de los proporcionados por sus clases padre PPI::Token y PPI::Element.

La mayoría de los métodos están diseñados para ayudar a determinar lo que el objeto realmente está señalando, en lugar de lo que podría parecer que está señalando.

canonical

El método "canonical" devuelve una versión normalizada y canónica del símbolo.

Por ejemplo, convierte "$ ::foo'bar::baz" a $main::foo::bar::baz.

Esto no resuelve completamente el símbolo, sino que simplemente elimina las variaciones de sintaxis.

symbol

El método "symbol" devuelve el símbolo REAL al que se refiere este token.

Un token de $foo podría en realidad estar refiriéndose a @foo, si se encuentra en la forma $foo[1].

Este método intenta resolver estos problemas para determinar el símbolo real.

Devuelve el símbolo como una cadena.

raw_type

El método "raw_type" devuelve el tipo **aparente** del símbolo en forma de su sigilo.

Devuelve el sigilo como una cadena.

symbol_type

El método "symbol_type" devuelve el tipo **real** del símbolo en forma de su sigilo.

Devuelve el sigilo como una cadena.
