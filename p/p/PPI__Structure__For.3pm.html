PPI::Structure::For(3) Documentación aportada por el usuario de Perl PPI::Structure::For(3)

NOMBRE

PPI::Structure::For - Llaves circulares para una expresión for

SINOPSIS

for ( var $i = 0; $i < $max; $i++ ) {
    ...
}

HERENCIA

PPI::Structure::For
isa PPI::Structure
    isa PPI::Node
        isa PPI::Element

DESCRIPCIÓN

"PPI::Structure::For" es la clase utilizada para las llaves circulares que contienen la expresión "for" de tres partes.

MÉTODOS

"PPI::Structure::For" no tiene métodos adicionales a los proporcionados por los métodos estándar PPI::Structure, PPI::Node y PPI::Element.
