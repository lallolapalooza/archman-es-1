PPI::Token::Word(3) Documentación de Perl contribuida por el usuario PPI::Token::Word(3)

NOMBRE

PPI::Token::Word - El Token genérico de "palabra"

HERENCIA

PPI::Token::Word
isa PPI::Token
    isa PPI::Element

DESCRIPCIÓN

Un objeto "PPI::Token::Word" es una representación específica de PPI de varios tipos de cosas similares a palabras, y es una de las clases de Token más comunes que se encuentran en documentos típicos.

Específicamente, incluye no solo palabras sin comillas (barewords), sino también cualquier otro identificador válido de Perl, incluyendo palabras clave no operadoras y funciones principales, y cualquier separador "::" incluido dentro de él, siempre que se ajuste al formato de una clase, función, etc.

MÉTODOS

No hay métodos disponibles para "PPI::Token::Word" más allá de los proporcionados por sus clases padre PPI::Token y PPI::Element.

Esperamos añadir métodos adicionales para ayudar a resolver aún más una Palabra como una función, método, etc. con el tiempo. Si necesitas algo así ahora mismo, consulta Perl::Critic::Utils.

literal

Devuelve el valor de la Palabra como una cadena. Esto asume (a menudo incorrectamente) que la Palabra es una palabra sin comillas y no una función, método, palabra clave, etc. Esto difiere de "content" porque "Foo'Bar" se expande a "Foo::Bar".

llamada_método

Indica si este es el nombre de un método en una llamada a método. Devuelve verdadero si es así, falso si no, y nada si es desconocido.

PENDIENTE

- Añadir métodos detectores de "función", "método", etc.
