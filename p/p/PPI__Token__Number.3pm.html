PPI::Token::Number(3) Documentación aportada por el usuario en Perl PPI::Token::Number(3)

NOMBRE

PPI::Token::Number - Clase de token para un número

SINOPSIS

$n = 1234;       # entero decimal
$n = 0b1110011;  # entero binario
$n = 01234;      # entero octal
$n = 0x1234;     # entero hexadecimal
$n = 12.34e-56;  # notación exponencial (actualmente no funciona)

HERENCIA

PPI::Token::Number
isa PPI::Token
    isa PPI::Element

DESCRIPCION

La clase "PPI::Token::Number" se utiliza para tokens que representan números, en los diversos tipos que Perl soporta.

MÉTODOS

base

El método "base" es proporcionado por todas las subclases de ::Number. Es 10 para decimal, 16 para hexadecimal, 2 para binario, etc.

literal

Devuelve el valor numérico de este token.

ADVERTENCIAS

En comparación con Perl, el tokenizador de números es demasiado liberal al permitir guiones bajos en cualquier lugar. Por ejemplo, lo siguiente es un error de sintaxis en Perl, pero está permitido en PPI:

0_b10

POR HACER

- Tratar las v-strings como cadenas binarias o barewords, no como números de "base-256".

- ¿Dividir los enteros decimales en su propia subclase?

- Implementar literal()
