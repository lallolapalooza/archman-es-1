NOMBRE

PPI::Statement::Compound - Describe todas las sentencias compuestas

SINOPSIS

# Una sentencia if compuesta
if ( foo ) {
    bar();
} else {
    baz();
}
# Una sentencia de bucle compuesta
foreach ( @list ) {
    bar($_);
}

HERENCIA

PPI::Statement::Compound
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPCIÓN

"PPI::Statement::Compound" los objetos se utilizan para describir todas las formas actuales de sentencias compuestas, como se describe en perlsyn.

Esto cubre los bloques que usan "if", "unless", "for", "foreach", "while" y "continue". Tenga en cuenta que esto no cubre sentencias "simples" con condiciones finales. Tenga en cuenta también que "do" tampoco forma parte de una sentencia compuesta.

# Esto NO es una sentencia compuesta
my $foo = 1 if $condition;
# Esto tampoco es una sentencia compuesta
do { ... } until $condition;

MÉTODOS

"PPI::Statement::Compound" tiene una serie de métodos además de los métodos estándar de PPI::Statement, PPI::Node y PPI::Element.

tipo

El método "type" devuelve el tipo sintáctico de la sentencia compuesta.

Hay cuatro tipos básicos de sentencias compuestas.

El tipo 'if' incluye todas las variaciones de las sentencias if y unless, incluidas las partes 'elsif' o 'else' de la sentencia compuesta.

El tipo 'while' describe las sentencias while y until estándar, pero de nuevo no describe sentencias simples con un while final.

El tipo 'for' cubre los bucles estilo C, independientemente de si se declararon usando 'for' o 'foreach'.

El tipo 'foreach' cubre los bucles que iteran sobre colecciones, independientemente de si se declararon usando 'for' o 'foreach'.

Todos los compuestos son una variación de uno de estos cuatro.

Devuelve la cadena simple 'if', 'for', 'foreach' o 'while', o "undef" si el tipo no se puede determinar.
