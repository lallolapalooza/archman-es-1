PPIx::Regexp::Constant(3) Documentación de Contribución de Usuarios de Perl PPIx::Regexp::Constant(3)

NOMBRE

PPIx::Regexp::Constant - Constantes para el sistema PPIx::Regexp

SINOPSIS

use PPIx::Regexp::Constant qw{ TOKEN_UNKNOWN }
print "La clase de un token desconocido es TOKEN_UNKNOWN\n";

HERENCIA

"PPIx::Regexp::Constant" es un Exportador.

"PPIx::Regexp::Constant" no tiene descendientes.

DETALLES

Este módulo define constantes manifiestas para uso de los varios módulos de "PPIx::Regexp". Estas constantes deben considerarse privadas del sistema "PPIx::Regexp", y el autor se reserva el derecho de cambiarlas sin previo aviso.

Este módulo exporta las siguientes constantes manifiestas:

@CARP_NOT

Esta variable global contiene los nombres de todos los módulos del paquete.

ARRAY_REF

Este es el resultado de "ref []".

CODE_REF

Este es el resultado de "ref sub {}".

COOKIE_CLASS

El nombre de la cookie utilizada para controlar la construcción de clases de caracteres.

Esta cookie se establece en PPIx::Regexp::Token::Structure cuando se encuentra el corchete izquierdo, y se borra en el mismo módulo al encontrar un corchete derecho.

COOKIE_LOOKAROUND_ASSERTION

El nombre de la cookie utilizada para controlar el análisis de aserciones de ancho cero.

Esta cookie se establece en PPIx::Regexp::Token::GroupType::Assertion, y persiste hasta el final de la aserción.

COOKIE_QUANT

El nombre de la cookie utilizada para controlar la construcción de cuantificadores entre llaves.

Esta cookie se establece en PPIx::Regexp::Token::Structure cuando se encuentra una llave izquierda. Se solicita a sí misma que se borre al encontrar cualquier cosa que no sea una coma literal, un dígito literal o una interpolación, o si se encuentra más de una coma. Si sobrevive hasta que PPIx::Regexp::Token::Structure procesa la llave derecha, se borra allí.

COOKIE_QUOTE

El nombre de la cookie utilizada para controlar el análisis de literales entre comillas "\Q ... \E".

Esta cookie se establece en PPIx::Regexp::Token::Control cuando se encuentra un "\Q", y persiste hasta el siguiente "\E".

COOKIE_REGEX_SET

El nombre de la cookie utilizada para controlar los conjuntos de expresiones regulares.

FALSO

Un valor falso. El autor no se compromete a cuál es el valor exacto, solo que las operaciones booleanas lo verán como falso.

HASH_REF

Este es el resultado de "ref {}".

INFINITO

Este es el valor IEEE 754 de "Inf" si se puede generar, o un objeto sobrecargado opaco si no. Dado que el objeto no implementa (y creo que no puede) el comportamiento completo de "Inf" de IEEE 754, esta constante manifiesta solo debe usarse para la representación de cadena y la comparación numérica. Tenga en cuenta que la numificación del objeto debe ser la misma que su representación de cadena para mantener looks_like_number() satisfecho. Precaución al programar.

LLAVE_IZQUIERDA_LITERAL_PERMITIDA_ELIMINADA

La versión de Perl en la que se eliminaron las llaves izquierdas literales sin escapar permitidas. Esto puede tener más sentido si menciono que su valor es "undef".

LLAVE_IZQUIERDA_LITERAL_ELIMINADA_FASE_1

La versión de Perl en la que tuvo lugar la primera fase de eliminación de llaves izquierdas literales sin escapar. El valor de esta constante es '5.025001'.

LLAVE_IZQUIERDA_LITERAL_ELIMINADA_FASE_2

La versión de Perl en la que tuvo lugar la segunda fase de eliminación de llaves izquierdas literales sin escapar. El valor de esta constante es "undef", pero se le asignará un valor cuando se conozca el momento de la segunda fase.

LLAVE_IZQUIERDA_LITERAL_ELIMINADA_FASE_3

La versión de Perl en la que tuvo lugar la tercera fase de eliminación de llaves izquierdas literales sin escapar. Esta es la eliminación de llaves después de un paréntesis izquierdo. El valor de esta constante es "undef", pero se le asignará un valor cuando se conozca el momento de la segunda fase.

MINIMO_PERL

La versión mínima de Perl entendida por este analizador, como un flotante. Actualmente está establecida en 5.000, ya que es la versión mínima de Perl accesible para el autor.

SEMANTICA_COINCIDENCIA_GRUPO_MODIFICADOR

El nombre del grupo PPIx::Regexp::Token::Modifier utilizado para controlar la semántica de coincidencia.

MSG_BUSQUEDA_HACIA_ATRÁS_DEMASIADO_LARGA

Un mensaje de error apropiado para una entidad desconocida creada a partir de un cuantificador que haría que una aserción de búsqueda hacia atrás fuera demasiado larga. Esto se copia textualmente del mensaje de error de Perl.

MSG_PROHIBIDO_POR_ESTRICTO

Un mensaje de error apropiado para una entidad desconocida creada porque 'strict' estaba en efecto. Esto es una ad hocidad de rango, y más de lo habitual sujeta a cambios, sin ningún aviso en absoluto. Precaución al usuario.

NODO_DESCONOCIDO

El nombre de la clase que representa un nodo desconocido. Es decir, PPIx::Regexp::Node::Unknown.

NOMBRE_CAPTURA_RE

Una representación de cadena de una expresión regular que coincide con el nombre de un búfer de captura con nombre.

REFERENCIA_EXPRESION_REGULAR

Este es el resultado de "ref qr{}".

REFERENCIA_ESCALAR

Este es el resultado de "ref \0".

ESTRUCTURA_DESCONOCIDA

El nombre de la clase que representa una estructura desconocida. Es decir, PPIx::Regexp::Structure::Unknown.

SOPORTE_UTF8_SUFICIENTE_PARA_DELIMITADORES_RAROS

Este constante fue utilizada para determinar si la versión de Perl tenía suficiente soporte UTF-8 para permitir delimitadores no ASCII. Su valor es un booleano.

TRUE

Un valor verdadero. El autor no se compromete a cuál es el valor exacto, solo que las operaciones booleanas lo verán como verdadero.

UNKNOWN_TOKEN_CLASS

El nombre de la clase que representa un token desconocido. Es decir, PPIx::Regexp::Token::Unknown.

UNESCAPED_LEFT_CURLY_PHASE_1

La versión de Perl en la que se eliminaron las llaves izquierdas literales sin escapar. El valor de esta constante es '5.025001'.

UNESCAPED_LEFT_CURLY_PHASE_2

La versión de Perl en la que se espera que tenga lugar la segunda fase de la eliminación de llaves izquierdas literales sin escapar. El valor de esta constante es "undef", pero se le asignará un valor cuando se conozca el momento de la segunda fase.

UNESCAPED_LEFT_CURLY_PHASE_3

La versión de Perl en la que se espera que tenga lugar la tercera fase de la eliminación de llaves izquierdas literales sin escapar. Esta es la eliminación de llaves después de un paréntesis izquierdo. El valor de esta constante es "undef", pero se le asignará un valor cuando se conozca el momento de la segunda fase.

UTF8_SUPPORT_FOR_WEIRD_DELIMITERS

Esta constante fue utilizada para determinar si la versión de Perl tenía suficiente soporte UTF-8 para permitir delimitadores no ASCII. Su valor es un booleano.

CONSTANTES

PERL_VERSION

Un Booleano que es verdadero si la versión en ejecución de Perl tiene soporte UTF-8 suficiente para nuestros propósitos.

Actualmente eso significa 5.8.3 o mayor, con los requisitos específicos siendo "use open qw{ :std :encoding(utf-8) }", "/\p{Mark}/", y la habilidad de parsear cosas como "qr \N{U+FFFF}foo\N{U+FFFF}".

TOKEN_LITERAL

El nombre de la clase que representa un token literal. Es decir, PPIx::Regexp::Token::Literal.

TOKEN_UNKNOWN

El nombre de la clase que representa el token desconocido. Es decir, PPIx::Regexp::Token::Unknown.

TRUE

Un valor verdadero. El autor no se compromete a cuál es el valor exacto, solo que las operaciones booleanas lo verán como verdadero.

VARIABLE_LENGTH_LOOK_BEHIND_INTRODUCED

La versión en la que se introdujeron los look-behinds de longitud variable. Actualmente es '5.029009', e implica el lookbehind limitado introducido en o alrededor de esa versión.
