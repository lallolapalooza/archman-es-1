PPI::Statement::Unknown(3) Documentación de Perl aportada por el usuario PPI::Statement::Unknown(3)

NOMBRE

PPI::Statement::Unknown - Una sentencia desconocida o transitoria

HERENCIA

PPI::Statement::Unknown
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

DESCRIPCION

La clase "PPI::Statement::Unknown" se utiliza principalmente durante el proceso de análisis léxico para almacenar elementos que se sabe que son sentencias, pero para los cuales el "tipo" exacto de sentencia aún se desconoce y requiere tokens adicionales para resolver el tipo correcto.

No deberían existir en un documento válido completamente analizado, y si existe alguno, indica un problema en Document, o posiblemente (al permitir que se resuelva sin resolver) un error en PPI::Lexer.

MÉTODOS

"PPI::Statement::Unknown" no tiene métodos adicionales más allá de los predeterminados proporcionados por PPI::Statement, PPI::Node y PPI::Element.
