NOMBRE

PPI::Find - Versión orientada a objetos del método Element->find

SINOPSIS

# Crear el objeto Find
my $Find = PPI::Find->new( \&wanted );

# Devolver todos los Elementos coincidentes como una lista
my @found = $Find->in( $Document );

# ¿Podemos encontrar algún Elemento coincidente?
if ( $Find->any_matches($Document) ) {
      print "Se encontró al menos un Elemento coincidente";
}

# Usar el objeto como un iterador
$Find->start($Document) or die "No se pudo ejecutar la búsqueda";
while ( my $token = $Find->match ) {
      ...
}

DESCRIPCIÓN

PPI::Find es la clase principal de búsqueda PDOM en el paquete central de PPI.

Historial

Se hizo bastante obvio durante el desarrollo de PPI que muchos de los módulos que se construirían sobre él necesitarían un gran número de objetos de búsqueda guardados, almacenables o fácilmente creables que pudieran ser reutilizados varias veces.

Aunque el método interno ->find proporciona una capacidad básica para buscar, no es exhaustivo en absoluto. PPI::Find intenta resolver este problema.

Estructura y Estilo

PPI::Find proporciona una API similar al popular módulo File::Find::Rule para la búsqueda de archivos, pero sin la capacidad de ensamblar consultas.

La implementación de una subclase separada PPI::Find::Rule que sí proporciona esta capacidad se deja como ejercicio para el lector.

La función &wanted

En el núcleo de cada objeto PPI::Find se encuentra una función "wanted" a la que se le pasan varios argumentos y que devuelve un valor que controla el flujo de la búsqueda.

A medida que la búsqueda se ejecuta, cada Elemento se pasará a la función wanted en orden de profundidad primero.

Se le proporcionarán dos argumentos. El Elemento actual a probar como $_[0], y el Elemento de nivel superior de la búsqueda como $_[1].

Se espera que la función &wanted devuelva 1 (positivo) si el Elemento coincide con la condición, 0 (falso) si no coincide, y undef (indefinido) si la condición no coincide y la búsqueda Find no debe descender a ninguno de los hijos del Elemento actual.

Los errores deben ser reportados desde la función &wanted a través de die, que será capturada por el objeto Find y devuelta como un error.

MÉTODOS

new &wanted

El constructor "new" toma un único argumento de la función &wanted, como se describe anteriormente, y crea una nueva búsqueda.

Devuelve un nuevo objeto PPI::Find, o "undef" si no se le pasa una referencia CODE.

clone

El método "clone" crea otra instancia del mismo objeto Find.

La clonación se realiza de forma segura, por lo que si su objeto Find existente está en medio de una iteración, el objeto Find clonado no estará también en la iteración y podrá usarse de forma segura de forma independiente.

Devuelve un objeto PPI::Find duplicado.

in $Document [, array_ref => 1 ]

El método "in" inicia y completa una ejecución completa de la búsqueda.

Toma como argumento un único objeto PPI::Element que servirá como la parte superior del proceso de búsqueda.

Devuelve una lista de objetos PPI::Element que coinciden con la condición descrita por la función &wanted, o la lista nula en caso de error.

Debería comprobar el método ->errstr para cualquier error si se le devuelve la lista nula, lo que también puede significar simplemente que no se encontraron Elementos que coincidieran con la condición.

Debido a esta necesidad de comprobar explícitamente los errores, se proporciona un mecanismo de valor de retorno alternativo. Si pasa el parámetro "array_ref => 1" al método, devolverá la lista de Elementos coincidentes como una referencia a un ARRAY. El método devolverá falso si no se encontraron elementos, o "undef" en caso de error.

El método ->errstr todavía se puede usar para obtener el mensaje de error como de costumbre.

start $Element

El método "start" permite que el objeto Find actúe como un iterador. El método recibe el objeto PPI::Element padre como para el método "in", pero no acepta ningún parámetro.

Para simplificar el manejo de errores, toda la búsqueda se realiza a la vez, con los resultados almacenados en caché y proporcionados según se solicite.

Devuelve verdadero si la búsqueda se completa y falso en caso de error.

match

El método "match" devuelve el siguiente Elemento coincidente en la iteración.

Devuelve un objeto PPI::Element, o "undef" si no quedan Elementos por devolver.

finish

El método "finish" proporciona un mecanismo para finalizar la iteración si desea detenerla prematuramente. Restablece el objeto Find y permite que se reutilice de forma segura.

Un objeto Find se finalizará automáticamente cuando "match" devuelva falso. Esto significa que solo necesitará llamar a "finish" cuando detenga la iteración temprano.

Puede llamar a este método de forma segura incluso cuando no esté iterando y se devolverá sin errores.

Siempre devuelve verdadero

errstr

El método "errstr" devuelve los mensajes de error cuando un objeto PPI::Find dado falla alguna acción.

Devuelve una cadena o "undef" si no hay error.
