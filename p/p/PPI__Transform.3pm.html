PPI::Transform(3) Documentación de Perl contribuida por el usuario PPI::Transform(3)

NOMBRE

PPI::Transform - Clase base abstracta para clases de transformación de documentos

DESCRIPCIÓN

"PPI::Transform" proporciona una API para la creación de clases y objetos que modifican o transforman documentos PPI.

MÉTODOS

new

mi $transform = PPI::Transform->new(
    parametro1 => 'valor1',
    parametro2 => 'valor2',
);

El constructor "new" crea un nuevo objeto para tu subclase "PPI::Transform". Se te proporciona un constructor predeterminado que no toma parámetros y crea un objeto básico y vacío.

Si deseas que tu constructor de transformación acepte parámetros, estos **deben** estar en forma de una lista de pares clave/valor.

Devuelve un nuevo objeto compatible con "PPI::Transform", o devuelve "undef" en caso de error.

document

El método "document" debe ser implementado por cada subclase y toma un único argumento de un objeto PPI::Document, modificándolo **en el lugar** según corresponda a la clase de transformación particular.

Es así, este método **no clonará** y **no debe clonar** el objeto documento. Si no quieres que el original sea modificado, necesitas clonarlo tú mismo antes de pasarlo.

Devuelve el número de cambios realizados en el documento. Si la transformación no puede rastrear la cantidad (incluida la situación en la que no puede saber **SI** realizó un cambio) debería devolver 1. Devuelve cero si no se realizaron cambios en el documento, o "undef" si ocurre un error.

Por defecto, este error probablemente solo signifique que pasaste algo que no era un PPI::Document, pero puede incluir errores adicionales dependiendo de la subclase.

apply

El método "apply" se utiliza para aplicar la transformación a algo. El argumento debe ser un PPI::Document, o algo que pueda convertirse en uno y luego escribirse de nuevo.

Actualmente, esta lista se limita a una referencia de "SCALAR", aunque un proceso de registro de manejadores está disponible para que agregues soporte para tipos de objetos adicionales si lo deseas (consulta el código fuente de este módulo).

Devuelve verdadero si la transformación se aplicó, falso si hay un error en el proceso de transformación, o puede fallar si hay un error crítico en el manejador de aplicación.

file

# Leer de un archivo y escribir en otro
$transform->file( 'Entrada.pm' => 'Salida.pm' );

# Cambiar un archivo en el lugar
$transform->file( 'Cambio.pm' );

El método "file" modifica un documento Perl por nombre de archivo. Si se le pasa un solo parámetro, modifica el archivo en el lugar. Si se le proporciona un segundo parámetro, intentará guardar el archivo modificado en el nombre de archivo alternativo.

Devuelve verdadero en caso de éxito, o "undef" en caso de error.
