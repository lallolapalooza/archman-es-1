PPIx::Regexp::Dumper(3) Documentación de Perl contribuida por el usuario PPIx::Regexp::Dumper(3)

NOMBRE

PPIx::Regexp::Dumper - Volcar los resultados del análisis de expresiones regulares

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{foo}smx' )
    ->print();

HERENCIA

"PPIx::Regexp::Dumper" es un PPIx::Regexp::Support.

"PPIx::Regexp::Dumper" no tiene descendientes.

DESCRIPCIÓN

Esta clase genera un volcado formateado de un objeto PPIx::Regexp::Element (o cualquier subclase de este), un objeto PPIx::Regexp::Tokenizer, o una cadena que puede convertirse en uno de estos.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

new

my $dumper = PPIx::Regexp::Dumper->new(
    '/foo/', ordinal => 1,
);

Este método estático instancia el volcador. Toma la cadena, elemento PPI, elemento PPIx::Regexp o tokenizador PPIx::Regexp a volcar como primer argumento. Se pueden pasar argumentos adicionales opcionales como pares nombre/valor.

Se reconocen las siguientes opciones:

default_modifiers referencia_a_array
Este argumento es una referencia a una lista de modificadores predeterminados que se aplicarán a la declaración que se está analizando. Consulte new() de PPIx::Regexp para obtener detalles.
encoding nombre
Este argumento es el nombre de la codificación de la expresión regular. Si se especifica, se pasa a PPIx::Regexp->new(). También provoca una codificación "Encode::encode" del contenido analizado que se volca.
explain Booleano
Si es verdadero, esta opción hace que se vuelque la salida explain() de cada objeto.
indent número
Este argumento es el número de espacios adicionales para indentar cada nivel de la jerarquía de análisis. Esto se ignora si el argumento "test" o "tokens" es verdadero.

El valor predeterminado es 2.

margin número
Este es el número de espacios para indentar el nivel superior de la jerarquía de análisis. Esto se ignora si el argumento "test" es verdadero.

El valor predeterminado es cero.

ordinal Booleano
Si es verdadero, esta opción hace que se vuelquen los valores "ordinal" de los objetos PPIx::Regexp::Token::Literal.
perl_version Booleano
Si es verdadero, esta opción hace que se muestren los valores "perl_version_introduced" y "perl_version_removed" asociados a cada objeto volcado.
ppi Booleano
Si es verdadero, se volcará cualquier código Perl contenido en el objeto.
short Booleano
Si es verdadero, se eliminarán los 'PPIx::Regexp::' iniciales de los nombres de las clases en la salida.
strict Booleano
Esta opción se pasa al analizador, donde especifica si el análisis debe asumir que el pragma "use re 'strict'" está activo.

El pragm 'strict' se introdujo en Perl 5.22, y su documentación dice que es experimental, y que no hay compromiso de compatibilidad hacia atrás. Lo mismo se aplica al análisis producido cuando se afirma esta opción.

El valor predeterminado es falso.

significant Booleano
Si es verdadero, esta opción hace que solo se vuelquen los elementos significativos.

El valor predeterminado es falso.

test Booleano
Si es verdadero, esta opción hace que la salida se formatee como una prueba de regresión en lugar de como un volcado directo. La salida producida al afirmar esta opción no está documentada explícitamente, en el sentido de que el autor se reserva el derecho de cambiar la salida generada sin aviso de ningún tipo.

El valor predeterminado es falso.

tokens Booleano
Si es verdadero, esta opción hace que se genere un volcado de la salida del tokenizador en lugar de un análisis completo de la expresión regular. Esto se fuerza a verdadero si el volcado es de un PPIx::Regexp::Tokenizer.

El valor predeterminado es falso.

trace número
Si es mayor que cero, esta opción provoca un rastreo del análisis. Esta opción no está soportada en el sentido de que el autor se reserva el derecho de cambiarla sin previo aviso.

El valor predeterminado es cero.

verbose número
Si es mayor que cero, esta opción provoca que se proporcione información adicional sobre los elementos encontrados. Esta opción no está soportada en el sentido de que el autor se reserva el derecho de cambiarla sin previo aviso.

El valor predeterminado es cero.

width Booleano
Si es verdadero, esta opción hace que se vueque el ancho del objeto.

Si el elemento a volcar era una cadena, los argumentos no reconocidos se pasan a "PPIx::Regexp::Tokenizer->new()". De lo contrario, se ignoran.

list

print map { "$_\n" } $dumper->list();

Este método produce un array que contiene la salida del volcado, una línea por elemento. La salida no tiene margen izquierdo aplicado, ni saltos de línea.

print

$dumper->print();

Este método simplemente imprime el resultado de "string" en la salida estándar.

string

print $dumper->string();

Este método añade margen izquierdo y saltos de línea a la salida de "list", concatena el resultado en una sola cadena y devuelve dicha cadena.
