NOMBRE

PPIx::Utilities::Statement - Extensiones para PPI::Statement.

VERSIÓN

Este documento describe la versión 1.1.0 de PPIx::Utilities::Statement.

SINOPSIS

use PPI::Document qw< >;
use PPIx::Utilities::Statement qw<
    get_constant_name_elements_from_declaring_statement
>;
my $document = PPI::Document->new(\'Readonly::Scalar my $THINGY => 47.2;');
# Devuelve el PPI::Token::Symbol para "$THINGY".
my ($constant) = get_constant_name_elements_from_declaring_statement(
    $document->schild(0)
);

DESCRIPCIÓN

Esta es una colección de funciones para tratar con PPI::Statements.

INTERFAZ

No se exporta nada por defecto.

get_constant_name_elements_from_declaring_statement($statement)

Dada una PPI::Statement, si la sentencia es una declaración Readonly o Const::Fast o una sentencia "use constant", devuelve los nombres de las cosas que se están definiendo.

Dada

use constant 1.16 FOO => 'bar';

esto devolverá el PPI::Token::Word que contiene 'FOO'. Dada

use constant 1.16 { FOO => 'bar', 'BAZ' => 'burfle' };

esto devolverá una lista de los PPI::Tokens que contienen 'FOO' y 'BAZ'. De forma similar, dada

Readonly::Hash my %FOO => ( bar => 'baz' );

o

const my %FOO => ( bar => 'baz' );

esto devolverá el PPI::Token::Symbol que contiene '%FOO'.
