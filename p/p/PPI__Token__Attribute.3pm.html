PPI::Token::Attribute(3) Documentación de usuario aportada por la comunidad Perl PPI::Token::Attribute(3)

NOMBRE

PPI::Token::Attribute - Un token para un atributo de subrutina

HERENCIA

PPI::Token::Attribute
isa PPI::Token
    isa PPI::Element

DESCRIPCIÓN

En Perl, los atributos son una adición relativamente reciente al lenguaje.

Dado el código " sub foo : bar(something) {} ", la parte bar(something) es el atributo.

Un token "PPI::Token::Attribute" representa la totalidad del atributo, ya que las llaves y su contenido no se analizan en el árbol, y son tratados por Perl (y por lo tanto por nosotros) como una sola cadena.

MÉTODOS

Esta clase proporciona algunos métodos adicionales más allá de los proporcionados por sus clases padre PPI::Token y PPI::Element.

identificador

El atributo "identificador" devuelve la parte identificadora del atributo.

Es decir, para el atributo foo(bar), el método "identificador" devolvería "foo".

parámetros

El método "parámetros" devuelve la cadena de parámetros para el atributo.

Es decir, para el atributo foo(bar), el método "parámetros" devolvería "bar".

Devuelve los parámetros como una cadena (incluida la cadena nula '' para el caso de un atributo como foo()).

Devuelve "undef" si el atributo no tiene parámetros.
