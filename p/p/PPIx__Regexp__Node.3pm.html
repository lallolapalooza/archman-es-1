PPIx__Regexp__Node(3pm)

Paquete: perl-ppix-regexp

Licencias: PerlArtistic

PPIx::Regexp::Node(3) User Contributed Perl Documentation PPIx::Regexp::Node(3)

NOMBRE

PPIx::Regexp::Node - Representar un contenedor

SINOPSIS

use PPIx::Regexp::Dumper;
PPIx::Regexp::Dumper->new( 'qr{(foo)}' )->print();

HERENCIA

"PPIx::Regexp::Node" es un PPIx::Regexp::Element.

"PPIx::Regexp::Node" es el padre de PPIx::Regexp, PPIx::Regexp::Node::Range y PPIx::Regexp::Structure.

DESCRIPCIÓN

Esta clase representa un elemento estructural que contiene otras clases. Es una clase abstracta, no instanciada por el lexer.

MÉTODOS

Esta clase proporciona los siguientes métodos públicos. Los métodos no documentados aquí son privados y no soportados en el sentido de que el autor se reserva el derecho de cambiarlos o eliminarlos sin previo aviso.

child

my $kid = $node->child( 0 );

Este método devuelve el hijo en el índice dado. Los índices comienzan desde cero, y los índices negativos son desde el final de la lista, de modo que "$node->child( -1 )" devuelve el último hijo del nodo.

children

Este método devuelve los hijos del Nodo. Si se llama en contexto de escalar, devuelve el número de hijos.

contains

print $node->contains( $elem ) ? "yes\n" : "no\n";

Este método devuelve verdadero si el elemento dado está contenido en el nodo, o falso en caso contrario.

elements

Este método devuelve los elementos en el Nodo. Para un "PPIx::Regexp::Node" propiamente dicho, es lo mismo que children().

find

my $rslt = $node->find( 'PPIx::Regexp::Token::Literal' );
my $rslt = $node->find( 'Token::Literal' );
my $rslt = $node->find( sub {
    return $_[1]->isa( 'PPIx::Regexp::Token::Literal' )
        && $_[1]->ordinal < ord(' ');
    } );

Este método encuentra cosas.

Si se le da una cadena como argumento, se asume que es un nombre de clase (posiblemente sin el prefijo 'PPIx::Regexp::'), y se encuentran todos los elementos de la clase dada.

Si se le da una referencia de código, esa referencia de código se llama una vez por cada elemento, y se le pasa $self y el elemento. El código debe devolver verdadero para aceptar el elemento, falso para rechazarlo, y (para subclases de "PPIx::Regexp::Node") "undef" para prevenir la recursión en el nodo. Si el código lanza una excepción, no se obtiene nada de este método.

En cualquier caso, el retorno es una referencia a la lista de cosas encontradas, un valor falso (pero definido) si no se encontró nada, o "undef" si ocurrió un error.

find_parents

my $rslt = $node->find_parents( sub {
    return $_[1]->isa( 'PPIx::Regexp::Token::Operator' )
        && $_[1]->content() eq '|';
    } );

Este método de conveniencia toma los mismos argumentos que "find", pero en lugar de los objetos encontrados devuelve sus padres. Ningún padre aparecerá más de una vez en la salida.

Este método devuelve una referencia al array de padres si se encontraron algunos. Si no se encontraron padres, el retorno es falso pero definido. Si ocurrió un error, el retorno es "undef".

find_first

Este método tiene los mismos argumentos que "find", pero devuelve una referencia al primer elemento encontrado, un valor falso (pero definido) si no se encontraron elementos, o "undef" si ocurrió un error.

first_element

Este método devuelve el primer elemento en el nodo.

first_token

Este método devuelve el primer token en el nodo. Si no hay ninguno, no devuelve nada.

last_element

Este método devuelve el último elemento en el nodo.

last_token

Este método devuelve el último token en el nodo. Si no hay ninguno, no devuelve nada.

is_matcher

Este método devuelve un valor verdadero si alguno de los hijos del nodo lo hace. De lo contrario, devuelve "undef" si alguno de los hijos del nodo lo hace. De lo contrario, devuelve un valor falso (pero definido).

perl_version_introduced

Este método devuelve el valor máximo de "perl_version_introduced" devuelto por cualquiera de sus elementos. En otras palabras, devuelve la versión mínima de Perl bajo la cual este nodo es válido. Si no hay elementos, se devuelve 5.000, ya que es el valor mínimo de Perl soportado por este paquete.

perl_version_removed

Este método devuelve el valor mínimo definido de "perl_version_removed" devuelto por cualquiera de los elementos del nodo. En otras palabras, devuelve la versión más baja de Perl en la que este nodo "no" es válido. Si no hay elementos, o si ningún elemento tiene un "perl_version_removed" definido, se devuelve "undef".

schild

Este método devuelve el hijo significativo en el índice dado; es decir, "$node->schild(0)" devuelve el primer hijo significativo, "$node->schild(1)" devuelve el segundo hijo significativo, y así sucesivamente. Los índices negativos cuentan desde el final.

schildren

Este método devuelve los hijos significativos del Nodo. Si se llama en contexto de escalar, devuelve el número de hijos significativos.
