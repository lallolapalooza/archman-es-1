PPI::Dumper(3) Documentación de Perl aportada por el usuario PPI::Dumper(3)

NOMBRE

PPI::Dumper - Volcado de árboles PDOM

SINOPSIS

# Cargar un documento
my $Module = PPI::Document->new( 'MyModule.pm' );

# Crear el volcador
my $Dumper = PPI::Dumper->new( $Module );

# Volcar el documento
$Dumper->print;

DESCRIPCIÓN

Los árboles PDOM en PPI son bastante complejos, y obtener un volcado de su estructura para fines de desarrollo y depuración es importante.

Este módulo proporciona esa funcionalidad.

El proceso es relativamente sencillo. Crea un objeto volcador con un conjunto particular de opciones, y luego llama a uno de los métodos de volcado para generar el contenido del volcado.

MÉTODOS

new $Element, param => value, ...

El constructor "new" crea un volcador y toma como argumento un único objeto PPI::Element de cualquier tipo para servir como raíz del árbol a volcar, y una serie de parámetros clave-valor para controlar el formato de salida del Volcador. Los detalles de los parámetros se enumeran a continuación.

Devuelve un nuevo objeto "PPI::Dumper", o "undef" si el constructor no recibe un objeto raíz PPI::Element correcto.

memaddr
¿Debería el volcador imprimir las direcciones de memoria de cada elemento PDOM? Valor verdadero/falso, desactivado por defecto.
indent
¿Deberían las estructuras que se vuelcan estar indentadas? Este valor es numérico, donde el número representa la cantidad de espacios a usar al indentar la salida del volcador. Establecido en '2' por defecto.
class
¿Debería el volcador imprimir la clase completa para cada elemento? Valor verdadero/falso, activado por defecto.
content
¿Debería el volcador mostrar el contenido de cada elemento? Valor verdadero/falso, activado por defecto.
whitespace
¿Debería el volcador mostrar los tokens de espacio en blanco? Al no mostrar la gran cantidad de tokens de espacio en blanco, la estructura del código a menudo puede aclararse mucho. Valor verdadero/falso, activado por defecto.
comments
¿Debería el volcador mostrar los tokens de comentario? En situaciones donde tienes muchos comentarios, el código a menudo puede aclararse ignorando los tokens de comentario. Valor verdadero/falso, activado por defecto.
locations
¿Debería el volcador mostrar la ubicación de cada token? Los valores mostrados son [ línea, columna\_caracter, columna ]. Ver "location" en PPI::Element para una descripción de cuáles son realmente estos valores. Valor verdadero/falso, desactivado por defecto.

print

El método "print" genera el volcado y lo imprime en STDOUT.

Devuelve lo mismo que la función de impresión interna.

string

El método "string" genera el volcado y lo proporciona como una única cadena.

Devuelve una cadena o undef si hay un error al generar el volcado.

list

El método "list" genera el volcado y lo proporciona como una lista en bruto, sin saltos de línea finales.

Devuelve una lista o la lista nula si hay un error al generar el volcado.
