PPI::Document::Normalized(3) Documentación de Perl aportada por el usuario PPI::Document::Normalized(3)

NOMBRE

PPI::Document::Normalized - Un Documento de Perl normalizado

DESCRIPCIÓN

Un objeto "Documento Normalizado" es el resultado del proceso de normalización contenido en la clase PPI::Normal. Consulte la documentación de PPI::Normal para obtener más información.

El objeto contiene una marca de versión y una lista de funciones para la versión de PPI::Normal utilizada para crearlo, y un objeto PPI::Document procesado y desvinculado.

Típicamente, el objeto Document habrá sido modificado por el proceso de normalización de una manera que haría fatal intentar hacer algo con él.

En pocas palabras, nunca use el objeto Document después de la normalización. ¡SE LE HA ADVERTIDO!

El objeto está diseñado de esta manera para proporcionar un sesgo hacia los falsos negativos. Una comparación entre dos objetos ::Normalized solo devolverá verdadero si fueron producidos por la misma versión de PPI::Normal, con el mismo conjunto de funciones de normalización (en el mismo orden).

Puede obtener falsos negativos si está almacenando objetos en caché durante una actualización.

Tenga en cuenta que esto se hace con fines de seguridad, ya que hay muchos casos en los que es probable que la normalización de bajo nivel se realice como parte de un proceso de seguridad de código, y los falsos positivos podrían ser muy peligrosos.

MÉTODOS

new

El método "new" está destinado a ser utilizado solo por la clase PPI::Normal, y para obtener objetos ::Normalized, se recomienda encarecidamente que utilice ese módulo o el método "normalized" del propio objeto PPI::Document.

version

El accesor "version" devuelve la versión de PPI::Normal utilizada para crear el objeto.

functions

El accesor "functions" devuelve una referencia a una matriz de las funciones de normalización (en orden) que se llamaron al crear el objeto.

equal $Normalized

El método "equal" es el método de comparación principal, toma otro objeto PPI::Document::Normalized y comprueba su equivalencia.

El operador "==" también se sobrecarga para este método, de modo que pueda hacer algo como lo siguiente:

my $first  = PPI::Document->load('first.pl');
my $second = PPI::Document->load('second.pl');

if ( $first->normalized == $second->normalized ) {
      print "Los dos documentos son equivalentes";
}

Devuelve verdadero si los documentos normalizados son equivalentes, falso si no lo son, o "undef" si hay un error.
