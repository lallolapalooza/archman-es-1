NOMBRE

PDF::Builder::Resource::Font::BdFont - Módulo para usar Fuentes bitmap

Hereda de PDF::Builder::Resource::Font

SINOPSIS

#
use PDF::Builder;
#
$pdf = PDF::Builder->new();
$sft = $pdf->bdfont($archivo);
#

Esto crea una fuente bitmap a partir de un archivo .bdf (bitmap distribution font). Por defecto, utiliza elementos cuadrados, y el estilo puede cambiarse para usar puntos rellenos (pareciéndose más a una impresora de matriz de puntos). La fuente se incrustará en el archivo PDF.

Las fuentes bitmap son bastante rudas, de baja resolución y difíciles de leer, así que a menos que seas un sádico que quiera forzar a los lectores a volver a los viejos tiempos de las impresoras de matriz de puntos y los terminales X bitmap, intenta limitar el uso de una fuente así a efectos decorativos o de novedad, como títulos de capítulos y encabezados principales. ¡Ten piedad de tus lectores y usa una fuente real (TrueType, etc.) para el texto del cuerpo!

MÉTODOS

new

$fuente = PDF::Builder::Resource::Font::BdFont->new($pdf, $fuente, %opts)
Devuelve un objeto BmpFont.

Las opciones válidas (%opts) son:

estilo
Un valor de 'block' (el predeterminado) ensambla un carácter a partir de bloques cuadrados contiguos. Un valor de 'dot' ensambla un carácter a partir de círculos rellenos superpuestos, al estilo de una impresora de matriz de puntos.
