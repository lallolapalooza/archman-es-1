NOMBRE

PDF::Builder::Resource::XObject::Image::TIFF - Soporte de imagen TIFF

Hereda de PDF::Builder::Resource::XObject::Image

MÉTODOS

new

$res = PDF::Builder::Resource::XObject::Image::TIFF->new($pdf, $file, %opts)
Devuelve un objeto de imagen TIFF.

Si el paquete Graphics::TIFF está instalado, se utilizará la biblioteca TIFF_GT en lugar de la biblioteca TIFF. En tal caso, el uso de la biblioteca TIFF se puede forzar mediante la bandera "nouseGT" (ver documentación de Builder para image_tiff()).

Opciones:

'name' => 'string'
Este es el nombre que puede dar al objeto de imagen TIFF. El valor por defecto es Ixnnnn.

Recuerde que debe usar el método image_tiff de Builder.pm para mostrar un archivo TIFF.

usesLib

$mode = $tif->usesLib()
Devuelve 1 si Graphics::TIFF está instalado y se utiliza, 0 si no está instalado, o -1 si está instalado pero no se utiliza (opción nouseGT dada a "image_tiff").

Precaución: este método solo se puede usar *después* de que se haya creado el objeto de imagen. No puede decirle si Graphics::TIFF está disponible con antelación antes de usarlo realmente, en caso de que desee utilizar alguna funcionalidad disponible solo en TIFF_GT. Consulte la llamada LA_GT() de <PDF::Builder> si necesita saberlo con antelación.

tiffTag

$value = $tif->tiffTag($tag)
devuelve el valor de la etiqueta interna de tiff.

Etiquetas útiles:

imageDescription, imageId (cadenas de texto)
xRes, yRes (dpi; píxeles/cm si resUnit==3)
resUnit
