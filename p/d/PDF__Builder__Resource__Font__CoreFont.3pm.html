NOMBRE

PDF::Builder::Resource::Font::CoreFont - Módulo para usar las 14 fuentes integradas estándar de PDF (más 15 fuentes de Windows)

Hereda de PDF::Builder::Resource::Font

SINOPSIS

 #
 use PDF::Builder;
 #
 my $pdf = PDF::Builder->new();
 my $cft = $pdf->font('Times-Roman');
#my $cft = $pdf->corefont('Times-Roman');
 #
 my $page = $pdf->page();
 my $text = $page->text();
 $text->font($cft, 20);
 $text->translate(200, 700);
 $text->text("Hola, Mundo!");

$font = PDF::Builder::Resource::Font::CoreFont->new($pdf, $fontname, %options)

Tipos de letra soportados

Tipos estándar de PDF

Ver examples/020_corefonts para una lista de los glifos de cada fuente.

  • helvetica, helveticaoblique, helveticabold, helvetiaboldoblique

    Sans-serif, puede tener Arial sustituido en algunos sistemas (p. ej., Windows).

  • courier, courieroblique, courierbold, courierboldoblique

    Ancho fijo, puede tener Courier New sustituido en algunos sistemas (p. ej., Windows).

  • timesroman, timesitalic, timesbold, timesbolditalic

    Serif, puede tener Times New Roman sustituido en algunos sistemas (p. ej., Windows).

  • symbol, zapfdingbats

    Varios símbolos, incluyendo el alfabeto griego (en Symbol).

Tipos de letra principalmente de Windows

Ver examples/022_truefonts /Windows/Fonts/<name>.ttf para una lista de los glifos de cada fuente.

  • georgia, georgiaitalic, georgiabold, georgiabolditalic

    Serif proporcional.

  • verdana, verdanaitalic, verdanabold, verdanabolditalic

    Sans-serif proporcional con trazos simples.

  • trebuchet, trebuchetitalic, trebuchetbold, trebuchetbolditalic

    Sans-serif proporcional con trazos simples.

  • bankgothic, bankgothicitalic, bankgothicbold, bankgothicitalic

    Sans-serif proporcional con trazos simples. Las versiones gratuitas de Bank Gothic suelen ser solo de peso medio y redonda (bankgothic).

  • webdings, wingdings

    Varios símbolos, en la línea de Zapf Dingbats.

Tenga en cuenta que PDF::Builder solo proporciona las métricas de las fuentes (anchos); las fuentes en sí mismas son proporcionadas por la máquina del lector (a menudo empaquetadas con el sistema operativo o obtenidas por separado por el usuario). Para usar una fuente específica, es posible que necesite obtener uno o más archivos de alguna fuente.

Si una fuente (tipo de letra y variante) no está disponible en la máquina de un lector determinado, *puede* que se realice una sustitución automática. Por ejemplo, Helvetica normalmente no se incluye con las máquinas Windows, y Arial podría ser sustituido. Para la mayoría de los caracteres, los anchos de los glifos serán los mismos, ¡pero esto no se puede garantizar!

PDF::Builder utiliza actualmente los archivos [typeface].pm para mapear los nombres de los glifos a los puntos de código (solo codificaciones de un solo byte) y para buscar los anchos de los glifos para la colocación de caracteres. No hay garantía de que un archivo de fuente dado incluya todos los glifos deseados, ni de que los anchos sean absolutamente los mismos, incluso en diferentes versiones de la misma fuente.

Opciones

encode
Cambia la codificación de la fuente de su valor predeterminado. Tenga en cuenta que la codificación (y no toda la lista de glifos de la fuente) se muestra en un objeto PDF (registro), listando 256 glifos asociados con esta codificación (y que están disponibles en esta fuente).

Consulte el módulo Encode de Perl para ver los valores admitidos. Advertencia: solo se permiten codificaciones de un solo byte. Las codificaciones multibyte como 'utf8' están prohibidas.

dokern
Habilita el kerning si hay datos disponibles.

"kerning" es un nombre antiguo para esta opción, y todavía está disponible como una alternativa a "dokern".

pdfname
Cambia el nombre de referencia de la fuente de su valor predeterminado. El nombre de referencia normalmente se genera automáticamente y se puede recuperar a través de $pdfname=$font->name().
metrics
Si se proporciona, se espera que sea un hash anónimo de datos del archivo de fuente. Esto se usará en lugar de buscar el archivo $fontname.pm para obtener el ancho y otros datos. Es posible que necesite usar esta opción si la fuente instalada resulta estar desincronizada con el archivo de métricas de fuentes básicas integrado en PDF::Builder (por ejemplo, helveticabold.pm).

is_standard

$bool = $class->is_standard($name)
Devuelve verdadero si $name es una coincidencia exacta, sensible a mayúsculas y minúsculas, con uno de los nombres de fuente estándar que se muestran arriba.

loadallfonts

PDF::Builder::Resource::Font::CoreFont->loadallfonts()
"Requiere" todas las fuentes disponibles como corefonts.
