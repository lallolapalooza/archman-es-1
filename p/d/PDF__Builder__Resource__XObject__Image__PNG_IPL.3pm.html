NOMBRE

PDF::Builder::Resource::XObject::Image::PNG_IPL - Rutinas de soporte para la biblioteca de imágenes PNG (usando Image::PNG::Libpng)

Hereda de PDF::Builder::Resource::XObject::Image

MÉTODOS

new

$res = PDF::Builder::Resource::XObject::Image::PNG_IPL->new($pdf, $file, %opts)
Devuelve un objeto de imagen PNG. $pdf es el objeto PDF al que se está añadiendo, $file es el archivo PNG de entrada y el $name opcional del nuevo objeto de imagen padre por defecto es PxAAA.

Si el paquete Image::PNG::Libpng está instalado y su uso no está suprimido mediante la bandera "nouseIPL" (ver documentación de Builder para "image_png"), se utilizará la biblioteca PNG_IPL. De lo contrario, se utilizará la biblioteca PNG en su lugar.

opts:

'notrans' => 1
Sin transparencia -- ignora el chunk tRNS si se proporciona, ignora el canal Alfa si se proporciona.
'force8bps' => 1
Si la fuente PNG es de 16bps, indica a la biblioteca libpng que elimine todos los canales a 8bps, permitiendo su uso en salida PDF 1.4.
'name' => 'string'
Este es el nombre que puedes dar al objeto de imagen PNG. El valor por defecto es Pxnnnn.

Recuerda que necesitas usar image_png de Builder.pm para procesar imágenes PNG.

Tipos PNG soportados

(0) Escala de grises de profundidad de 1, 2, 4, 8 o 16 bits por píxel (2, 4, 16, 256 o 65536 niveles de gris). Se permite transparencia total (de un valor de gris de 16 bits) a través del chunk tRNS, a menos que la opción notrans especifique que se ignore.
(2) RGB verdadero color con 8 o 16 bits por muestra (3 muestras: 16.7 millones o 281.5 billones de colores). Se permite transparencia total (de un valor de color RGB de 3x16 bits) a través del chunk tRNS, a menos que la opción notrans especifique que se ignore.
(3) Color de paleta con 1, 2, 4 u 8 bits por píxel (2, 4, 16 o 256 entradas de tabla de colores/paleta). 16 bpp no está actualmente soportado por PNG o PDF. Se permite transparencia parcial (Alfa de 8 bits) para cada entrada de paleta a través del chunk tRNS, a menos que la opción notrans especifique que se ignore (todas las entradas totalmente opacas).
(4) Escala de grises de profundidad de 8 o 16 bits por píxel más canal Alfa de tamaño igual (256 o 65536 niveles de gris y 256 o 65536 niveles de transparencia). El canal Alfa se ignora si se da la opción notrans. El chunk tRNS no está permitido.
(5) RESERVADO para escala de grises vía paleta + canal Alfa
(6) RGB verdadero color con 8 o 16 bits por muestra, con canal Alfa de tamaño igual (256 o 65536 niveles de transparencia). El canal Alfa se ignora si se da la opción notrans. El chunk tRNS no está permitido.
(7) RESERVADO para verdadero color vía paleta + canal Alfa

En todos los casos, 16 bits por muestra fuerza la salida PDF 1.5 (o superior), a menos que proporciones la opción "force8bps", para "eliminar" muestras de 16 bits a 8 bits, y permitir salida compatible con PDF 1.4. La biblioteca libpng.a asume el orden de bits y bytes "de red" estándar (Big Endian), aunque podrían añadirse banderas para cambiar esto.

El chunk de transparencia (tRNS) especificará una entrada de nivel de gris o una entrada RGB que se tratará como transparente (Alfa = 0). Para color de paleta, se especifican hasta 256 entradas de paleta de valores Alfa de 8 bits (256 niveles de transparencia, de 0 = transparente a 255 = opaco).

Solo se maneja un número limitado de chunks: IHDR, IDAT (internamente), PLTE, tRNS e IEND (internamente). Todos los demás chunks se ignoran en este momento. Los filtros y la compresión aplicados a los datos son manejados internamente por libpng.a -- puede haber métodos no soportados.

usaLib

$mode = $png->usesLib()
Devuelve 1 si Image::PNG::Libpng está instalado y se usa, 0 si no está instalado, o -1 si está instalado pero no se usa (opción nouseIPL dada a "image_png").

Precaución: este método solo puede usarse *después* de que se haya creado el objeto de imagen. No puede decirte si Image::PNG::Libpng está disponible antes de usarlo realmente, en caso de que quieras usar alguna funcionalidad disponible solo en PNG_IPL. Consulta la llamada LA_IPL() de PDF::Builder si necesitas saberlo de antemano.
