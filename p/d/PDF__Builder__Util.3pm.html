TAMAÑOS DE PAPEL PREDEFINIDOS

Las dimensiones están en puntos.

paper_size

@box_corners = paper_size($x1,$y1, $x2,$y2);
Devuelve una matriz ($x1,$y1, $x2,$y2) (caja delimitadora completa).
@box_corners = paper_size($x1,$y1);
Devuelve una matriz (0,0, $x1,$y1) (media caja delimitadora).
@box_corners = paper_size($media_name);
Devuelve una matriz (0,0, ancho_papel,alto_papel) para el medio con nombre.
@box_corners = paper_size($x1);
Devuelve una matriz (0,0, $x1,$x1) (cuadrado único).

De lo contrario, se devuelve la matriz (0,0, 612,792) (dimensiones de carta estadounidense).

getPaperSizes

%sizes = getPaperSizes();
Devuelve un hash que contiene los alias de tamaño de papel disponibles como claves y sus dimensiones como una referencia de matriz de dos elementos.

Consulte el código fuente de PDF::Builder::Resource::PaperSizes para ver la lista completa.

CADENA A DIMENSIÓN

Convierte una cadena "número [unidad]" al valor en las unidades deseadas. Las unidades no distinguen entre mayúsculas y minúsculas (la entrada se convierte primero a minúsculas).

Unidades admitidas: mm, cm, in (pulgada), pt (punto grande, 72/pulgada), ppt (punto de imprenta, 72.27/pulgada), pc (pica, 6/pulgada), dd (punto Didot, 67.5532/pulgada) y cc (cícero, 5.62943/pulgada). Se pueden añadir más fácilmente. Las unidades no válidas son un error fatal.

str2dim

$value = str2dim($string, $type, $default_units);
$string contiene un número y, opcionalmente, una unidad. Los espacios entre el número y la unidad son opcionales. Por ejemplo, '200', '35.2 mm' y '1.5in' son todas cadenas de entrada válidas.

$type se utiliza para validar el valor numérico de la cadena de entrada $string. El primer carácter es i para un entero requerido (sin punto decimal), o f para otros números (de punto flotante). A continuación, hay una c opcional para indicar que un valor de entrada fuera de rango se recortará silenciosamente para que esté dentro del rango dado (el valor predeterminado es generar un error fatal). Finalmente, una expresión de rango opcional: {límite inferior,límite superior}. Los límites son números o * (para indicar +/- infinito (sin límite) en ese extremo del rango). { es [ para indicar que el límite inferior está incluido en el rango, mientras que ( indica que el límite inferior está excluido del rango. Del mismo modo, } es ] para el límite superior incluido y ) para el excluido. Los límites (y el recorte silencioso, o el error fatal si la entrada está fuera de rango) se aplican al valor de entrada, antes de la conversión a las unidades de salida.

Ejemplos de tipos:

'f(*,*)' sin límites (el valor predeterminado) -- todos los valores están bien
'i(0,*)' entero mayor que 0
'fc[-3.2,7.86]' un número entre -3.2 y 7.86, con el valor recortado para estar dentro de ese rango (incluyendo los puntos finales)

$default_units es una cadena requerida que indica las unidades a las que se convierte la entrada. Por ejemplo, si las unidades predeterminadas son 'pt' y la cadena de entrada es '2 in', el valor de salida sería '144'. Si la cadena de entrada no tiene unidades explícitas, se asume que está en las unidades predeterminadas (no se realiza ninguna conversión).
