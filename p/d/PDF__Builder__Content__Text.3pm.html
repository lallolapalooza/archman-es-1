NOMBRE

PDF::Builder::Content::Text - Métodos adicionales especializados relacionados con texto

Hereda de PDF::Builder::Content

Nota: Si has utilizado algunos de estos métodos en PDF::Builder con un objeto de tipo gráfico (por ejemplo, $page->gfx()->method()), es posible que tengas que cambiar a un objeto de tipo texto (por ejemplo, $page->text()->method()).

MÉTODOS

Líneas individuales de una cadena

text_left

$width = $content->text_left($text, %opts)
Alias de "text". Implementado por simetría, para aquellos que usan mucho "text_center" y "text_right", y desean un "text_left" correspondiente.

Añade texto a la página (justificado a la izquierda), en la posición actual. Ten en cuenta que no hay un ancho máximo, ¡y nada te impide desbordar la página física por la derecha! El ancho utilizado (en puntos) es lo que se **devuelve**.

text_center

$width = $content->text_center($text, %opts)
Igual que "text", pero **centrado** en el punto actual.

Añade texto a la página (centrado). El ancho utilizado (en puntos) es lo que se **devuelve**.

text_right

$width = $content->text_right($text, %opts)
Igual que "text", pero alineado a la derecha del punto actual.

Añade texto a la página (justificado a la derecha). Ten en cuenta que no hay un ancho máximo, ¡y nada te impide desbordar la página física por la izquierda! El ancho utilizado (en puntos) es lo que se **devuelve**.

text_justified

$width = $content->text_justified($text, $width, %opts)
Igual que "text", pero estira el texto usando "wordspace", "charspace" y (como último recurso) "hscale", para llenar el $width deseado (disponible). Ten en cuenta que si el ancho deseado es *menor* que el ancho natural ocupado por el texto, se **condensará** para ajustarse, utilizando las mismas tres rutinas.

Se **devuelve** el $width sin cambios, a menos que haya alguna razón para cambiarlo (por ejemplo, desbordamiento).

Opciones:

'nocs' => value
Si el valor de esta opción es 1 (predeterminado 0), **no** uses espaciado entre caracteres. Esto es útil para caracteres conectados, como fuentes para árabe, devanagari, escritura cursiva latina, etc. No quieres añadir espacio adicional entre caracteres durante la justificación, ya que los desconectaría.

Los valores de espaciado de *palabras* (entre palabras) (explícitos o predeterminados) se duplican si nocs es 1. Esto es para compensar la falta de espaciado entre caracteres añadido/restado.

'wordsp' => value
El porcentaje de un carácter de espacio (predeterminado 100) que es la cantidad máxima a añadir (a cada) espaciado entre palabras para expandir la línea. Si "nocs" es 1, duplica "value".
'charsp' => value
Si añadir espacio entre palabras no fue suficiente, el porcentaje de un em (predeterminado 100) que es la cantidad máxima a añadir (a cada) espaciado entre caracteres para expandir aún más la línea. Si "nocs" es 1, fuerza "value" a 0.
'wordspa' => value
Si añadir espacio entre caracteres no fue suficiente, el porcentaje de un carácter de espacio (predeterminado 100) que es la cantidad máxima *adicional* a añadir (a cada) espaciado entre palabras para expandir aún más la línea. Si "nocs" es 1, duplica "value".
'charspa' => value
Si añadir más espacio entre palabras no fue suficiente, el porcentaje de un em (predeterminado 100) que es la cantidad máxima *adicional* a añadir (a cada) espaciado entre caracteres para expandir aún más la línea. Si "nocs" es 1, fuerza "value" a 0.
'condw' => value
El porcentaje de un carácter de espacio (predeterminado 25) que es la cantidad máxima a restar (de cada) espaciado entre palabras para condensar la línea. Si "nocs" es 1, duplica "value".
'condc' => value
Si restar espacio entre palabras no fue suficiente, el porcentaje de un em (predeterminado 10) que es la cantidad máxima a restar (de cada) espaciado entre caracteres para condensar aún más la línea. Si "nocs" es 1, fuerza "value" a 0.

Si los cambios de espaciado entre palabras y caracteres para expansión (o reducción) no fueron suficientes para que la línea cupiera en el ancho deseado, se utiliza hscale() para terminar de expandir o condensar la línea para que quepa.

Múltiples líneas de una cadena

La cadena se divide en espacios regulares (espacios, x20) para encontrar la subcadena más larga que quepa en el $width. Si una sola palabra es más larga que $width, se desbordará. Para mantenerse estrictamente dentro de los límites deseados, establece la opción "spillover"=>0 para no permitir el desbordamiento.

Guionización

Si la guionización está habilitada, aquellos métodos que dividen una cadena en múltiples líneas (los métodos de "relleno de texto", párrafo y sección) intentarán dividir la palabra que se desborda de la línea, para empaquetar el texto aún más apretadamente (división de línea "codiciosa"). Hay una serie de controles sobre dónde se puede dividir una palabra, pero ten en cuenta que no hay nada específico del idioma (es decir, que siga las reglas de un idioma determinado para dividir una palabra). Esto se deja a otros paquetes.

Hay mínimos codificados de 2 letras antes de la división y 2 letras después de la división. Ver "Hyphenate_basic.pm". Ten en cuenta que ni la guionización ni la simple división de líneas intentan evitar viudas y huérfanas, evitar dividir la última palabra de una columna o página, o participar de alguna otra manera en una *configuración de párrafo* más deseable.

'hyphenate' => value
0: sin guionización (**predeterminado**), 1: guionización básica. Siempre permite dividir en un guion suave (\xAD). El guion Unicode (U+2010) y el guion de no división (U+2011) se ignoran como puntos de división.
'spHH' => value
0: **no** dividir en un guion duro (x\2D), 1: **se puede dividir** (**predeterminado**)
'spOP' => value
0: **no** dividir después de la mayoría de los signos de puntuación, 1: **se puede dividir** (**predeterminado**)
'spDR' => value
0: **no** dividir después de una secuencia de uno o más dígitos, 1: **se puede dividir** (**predeterminado**)
'spLR' => value
0: **no** dividir después de una secuencia de una o más letras ASCII, 1: **se puede dividir** (**predeterminado**)
'spCC' => value
0: **no** dividir en camelCase entre una letra minúscula y una mayúscula, 1: **se puede dividir** (**predeterminado**)
'spRB' => value
0: **no** dividir en un Espacio Requerido (&nbsp;), es el valor **predeterminado**. 1: **se puede dividir** en Espacio Requerido. ¡Intenta evitar esto; es un movimiento desesperado!
'spFS' => value
0: **no** dividir donde quepa *justo* (¡en medio de la palabra!), es el valor **predeterminado**. 1: **se puede dividir para que quepa justo en el espacio disponible**. ¡Intenta evitar esto; es un movimiento de súper desesperación, y la división probablemente no tendrá sentido lingüístico!
'min_prefix' => value
Número mínimo de letras *antes* del punto de división de la palabra (punto de guionización). El **predeterminado** es 2.
'min_suffix' => value
Número mínimo de letras *después* del punto de división de la palabra (punto de guionización). El **predeterminado** es 3.

Métodos

text_fill_left, text_fill

($width, $leftover) = $content->text_fill_left($string, $width, %opts)
Rellena una línea de 'width' con la mayor cantidad de texto que quepa, y la muestra justificada a la izquierda. Se **devuelven** el ancho realmente utilizado y el texto sobrante (que no cupo).
($width, $leftover) = $content->text_fill($string, $width, %opts)
Alias de text_fill_left().

Text Manipulation

text_fill_center

($width, $leftover) = $content->text_fill_center($string, $width, %opts)
Rellena una línea de 'width' con tanto texto como quepa, y lo muestra centrado. El ancho realmente utilizado y el texto sobrante (que no cupo) son devueltos.

Segmentos de Texto Más Grandes

paragraph

($overflow_text, $unused_height) = $txt->paragraph($text, $width,$height, $continue, %opts)
($overflow_text, $unused_height) = $txt->paragraph($text, $width,$height, %opts)
$overflow_text = $txt->paragraph($text, $width,$height, $continue, %opts)
$overflow_text = $txt->paragraph($text, $width,$height, %opts)
Imprime una única cadena en un área rectangular en la página, de ancho y altura máximos dados. La línea base de la primera (superior) línea se encuentra en la posición de texto actual.

Aplica el texto dentro del rectángulo y devuelve cualquier texto sobrante (si no cabía todo dentro del rectángulo). Si se llama en un contexto de matriz, también se devuelve la altura no utilizada (puede ser 0 o negativa si simplemente llenó el rectángulo).

$continue es opcional, con un valor por defecto de 0. Se puede proporcionar una lista de %opts después de los parámetros fijos, ya sea que $continue se proporcione explícitamente o no.

Si $continue es 1, la primera línea no recibe un tratamiento especial de indentación o salida de indentación, porque estamos imprimiendo la continuación del párrafo que fue interrumpido anteriormente. Si es 0, la primera línea puede ser indentada o desindentada.

Opciones:

'pndnt' => $indent
Proporciona la cantidad de indentación (positiva) o salida de indentación (negativa, para "colgante") para las primeras líneas del párrafo. Esta configuración se ignora para el texto centrado.
'align' => $choice
$choice es 'justified', 'right', 'center', 'left'; el valor por defecto es 'left'. Consulte la llamada "text_justified" para ver las opciones que controlan cómo se expande o condensa una línea si $choice es 'justified'. $choice puede abreviarse a la primera letra.
'last_align' => place
donde place es 'left' (por defecto), 'center' o 'right' (puede abreviarse a la primera letra) le permite especificar la alineación de la última línea mostrada, pero solo se aplica cuando "align" es 'justified'.
'underline' => $distance
'underline' => [ $distance, $thickness, ... ]
Si es un escalar, distancia debajo de la línea base, de lo contrario, una referencia de matriz con pares de distancia y grosor de línea.
'spillover' => $over
Controla si las palabras en una línea que exceden el ancho dado deben ser "desbordadas" los límites, o si se debe usar una nueva línea para esta palabra.

$over es 1 o 0, con el valor por defecto 1 (se desborda el ancho).

Ejemplo:

$txt->font($font,$fontsize);
$txt->leading($leading);
$txt->translate($x,$y);
$overflow = $txt->paragraph( 'párrafo largo aquí ...',
                             $width,
                             $y+$leading-$bottom_margin );

Nota: si necesita cambiar algún tratamiento de texto dentro de un párrafo (texto en **negrita** o *cursiva*, por ejemplo), esto no puede manejarlo. Solo texto plano (todo con la misma fuente, tamaño, etc.) se puede componer con paragraph(). Además, actualmente hay una división de líneas muy limitada (guionización) para ajustarse mejor a un ancho dado, y no se hace nada para los "viudas y huérfanos".

section, paragraphs

($overflow_text, $continue, $unused_height) = $txt->section($text, $width,$height, $continue, %opts)
$overflow_text = $txt->section($text, $width,$height, $continue, %opts)
El $text contiene una cadena con uno o más párrafos de ancho $width, comenzando en la posición de texto actual, con un salto de línea \n entre cada párrafo. Cada párrafo se muestra (ver "paragraph") hasta que se alcanza el límite de $height (un párrafo parcial puede estar en la parte inferior). Lo que no se mostró, será devuelto. Si se llama en un contexto de matriz, también se devuelven la altura no utilizada y la bandera de "continuación" del párrafo.

$continue es 0 para la primera llamada a section(), y luego usa el valor devuelto de la llamada anterior (1 si un párrafo fue cortado por la mitad) para evitar indentaciones o desindentaciones no deseadas de la primera línea que se está imprimiendo.

Para compatibilidad con cambios recientes en PDF::API2, paragraphs se acepta como un alias de "section".

Opciones:

'pvgap' => $vertical
Espacio vertical adicional (unidad: pt) entre párrafos (por defecto 0). Tenga en cuenta que este espacio también se añadirá después del último párrafo impreso.

Consulte "paragraph" para otras %opts que puede utilizar, como "align" y "pndnt".

Nombre alternativo: paragraphs

Esto es para compatibilidad con PDF::API2.

textlabel

$width = $txt->textlabel($x,$y, $font, $size, $text, %opts)
Coloca una línea de texto en una posición "[$x,$y]" arbitraria en la página, con varios ajustes de texto (tratamientos) especificados en la llamada.
$font
Una fuente creada previamente.
$size
El tamaño de la fuente (puntos).
$text
El texto a imprimir (una sola línea).

Opciones:

'rotate' => $deg
Rota $deg grados en sentido antihorario desde el este.
'color' => $cspec
Un nombre de color o una especificación permitida, como "#CCE840", para el relleno del carácter.
'strokecolor' => $cspec
Un nombre de color o una especificación permitida, como "#CCE840", para el contorno del carácter.
'charspace' => $cdist
Distancia adicional entre caracteres.
'wordspace' => $wdist
Distancia adicional entre palabras.
'hscale' => $hfactor
Modo de escala horizontal (porcentaje del normal, el valor por defecto es 100).
'render' => $mode
Modo de renderizado de caracteres (solo contorno, solo relleno, etc.). Consulte la llamada "render".
'left' => 1
Alinea a la izquierda en el punto dado. Este es el valor por defecto.
'center' => 1
Centra el texto en el punto dado.
'right' => 1
Alinea a la derecha en el punto dado.
'align' => $placement
Alternativa a left, center y right. $placement es 'left' (por defecto), 'center' o 'right'.

Se pueden usar otras opciones disponibles para "text", como el subrayado.

El ancho utilizado (en puntos) es devuelto.

Tenga en cuenta que textlabel() no fue diseñado para interoperar con otras operaciones de texto. Es una operación independiente y no deja una posición de "siguiente escritura" (ni ninguna otra configuración) para otra operación en modo "text". Una escritura posterior probablemente estará en "(0,0)", y no en la ubicación esperada.

textlabel() está destinado a ser una función de conveniencia "todo en uno" para líneas individuales de texto, como una etiqueta en algún gráfico, y no como parte de la colocación de múltiples piezas de texto. Es posible calcular la posición de una escritura posterior (ya sea "textlabel" o "text") sumando el ancho devuelto al valor *x* de la posición original (asumiendo posicionamiento justificado a la izquierda).

Salida de Columna Compleja con Marcado

column

($rc, $next_y, $unused) = $text->column($page, $text, $grfx, $markup, $txt, %opts)
Este método completa una columna de texto en una página, devolviendo cualquier porción no utilizada que no pudo ser ajustada, y dónde dejó de escribir en la página.

Los nombres de las etiquetas, las entradas CSS, el tipo de marcado, etc., distinguen entre mayúsculas y minúsculas (generalmente solo letras minúsculas). Por ejemplo, no puede proporcionar un párrafo <P> en HTML o un selector P en estilo CSS.

$page es el contexto de la página. Actualmente, su único uso es para anotaciones de página para enlaces ('md1' []() y 'html' <a>), por lo que si no los está utilizando, puede pasar cualquier cosa como "undef" para $page si lo desea.

$text es el contexto de texto, para que se puedan realizar diversas operaciones de fuente y salida de texto. A menudo, pero no necesariamente siempre, es el mismo que el objeto que contiene el método "column".

$grfx es el contexto de gráficos (gfx). Puede ser un valor ficticio (por ejemplo, undef) si no se van a dibujar gráficos, pero los elementos gráficos como el contorno de la columna ('outline' option) an

(regla horizontal) se utilizará. Actualmente, text-decoration underline (predeterminado para enlaces, 'md1') "[]()" y 'html' "") o line-through o overline utiliza el contexto del texto, pero en el futuro podría requerir un contexto gráfico válido. Las imágenes (cuando se implementen) requerirán un contexto gráfico.

$markup es información sobre el tipo de markup que se está utilizando para formato y disposición del texto de la columna:

'pre'
El material de entrada ya ha sido procesado y está en el formato deseado. $txt es un índice de lista de hashes. Este debe usarse cuando se llama a column() una segunda (o posterior) vez para obtener material restante de la primera llamada. También puede usarse cuando el aplicador de llamada ya ha procesado el texto en el formato adecuado y no se está usando otros tipos de markup.
'none'
Si se especifica 'none', no hay markup en uso. Como mucho, un espacio en blanco o un elemento de texto nuevo especifica un párrafo nuevo, y eso es todo. $txt puede ser un único string, o un array (lista) de strings.

El input txt es una lista (referencia de array anónimo) de strings, cada uno conteniendo uno o más párrafos y otro markup. También puede ser un único string. Un espacio en blanco entre párrafos puede usarse para separar los párrafos. Los párrafos no pueden abarcar elementos de array.

Hay otros tipos de markup, por lo que otros tipos de mdn pueden definirse en el futuro, como el POD de Perl código.

'md1'
Esta especifica un cierto tipo de Markdown compatible con Text::Markdown: 
* o _ itálicas, ** negritas, *** negrita + itálica;
    lista con viñetas *, lista numerada 1. 2. etc.;
    #, ## etc. encabezados y subencabezados;
    ---, ===, ___ regla horizontal;
    [etiqueta](URL) enlaces externos (a página HTML o dentro de este documento, ver 'a');
    ` (backticks) sección de código

HTML (ver abajo) puede mezclarse como se desee (aunque no dentro de bloques de código marcados por backticks, donde <, > y & se convierten en entidades HTML, desactivando las etiquetas intencionadas). El Markdown será convertido a HTML, que luego será interpretado en PDF. Nota: que Text::Markdown puede producir HTML para ciertos aspectos, que no están aún soportados por el procesamiento de HTML (ver sección 'html'). ¡Por favor, avisa si te necesitas tal característica!

El input txt es una lista (referencia de array anónimo) de strings, cada uno conteniendo uno o más párrafos y otro markup. Un único string también puede ser proporcionado. Según el formato Markdown, un espacio en blanco entre párrafos puede usarse para separar los párrafos. Los elementos de array separados se unirán primero en un único string antes de procesar, permitiendo que los párrafos abarquen elementos de array si se desea.

Hay otros tipos de Markdown, por lo que otros mdn pueden definirse en el futuro, como POD de código de Perl.

'html'
Esta especifica que se utilizará un subconjunto de markup HTML junto con algunos atributos y CSS. Actualmente, las etiquetas estándar de HTML: 
'i'/'em' (itálicas), 'b'/'strong' (negritas),
    'p' (párrafo),
    'font' (nombre de fuente - font-family, color, tamaño - font-size),
    'span' (necesita atributo style= con CSS para hacer algo útil),
    'ul', 'ol', 'li' (listas con viñetas, numeradas),
    'img' (TBD, imagen, vacío. hspace - margin-left/right, vspace - margin-top/bottom, width, height),
    'a' (enlace/hipervínculo, URL de página web o destino de este documento #p[-x-y[-z]],),
    'pre', 'code' (TBD, bloques de preformateado y código),
    'h1' a 'h6' (encabezados),
    'hr' (regla horizontal),
    'br' (TBD, saltos de línea, vacío),
    'sup', 'sub' (TBD, superíndice y subíndice),
    's', 'strike', 'del' (line-through),
    'u', 'ins' (underline),
    'blockquote' (cita de bloque)

y otras etiquetas HTML no estándar (extensiones).

'_marker' (permite modificar los marcadores de lista. si se proporciona, debe estar inmediatamente antes de una etiqueta 
  • . atributos: style). El texto del marcador se rellenará para ti (si está vacío o en blanco), y una caja de cierre es opcional si el texto del marcador está vacío.
'_move' (permite moverse a cualquier lugar en la base actual. útil para posicionar antes de centrar y alinear a la derecha con la propiedad text-align CSS. atributos: x = N número sin espacio (pts), Npt, o N% 0/0% = izquierda, 50% = centro, 100% = derecha, nueva posición relativa al inicio de la línea y al ancho de la línea.
   ¡advertencia: si te mueves al borde en cualquiera de las direcciones, los resultados serán impredecibles!
'_sl' (lista simple, como 'ul' pero sin marcador)
'_ovl' (TBD -- superíndice similar a subíndice/line-through)
'_k' (TBD -- desplazamiento de kerning izquierda/derecha. ¿arriba/abajo también?)

    • son soportados (total o parcialmente excepto 'TBD'), junto con CSS limitado para color, tamaño de fuente, nombre de fuente, etc.
