PDF::API2::Page(3) Documentación aportada por el usuario de Perl PDF::API2::Page(3)

NOMBRE

PDF::API2::Page - Métodos para interactuar con páginas individuales

SINOPSIS

my $pdf = PDF::API2->new();
# Añadir una página a un PDF nuevo o existente
my $page = $pdf->page();
# Establecer el tamaño de la página
$page->size('letter');
# Establecer los límites de página preimpresión
$page->boundaries(media => '12x18', trim => 0.5 * 72);
# Añadir una imagen
my $image = $pdf->image('/ruta/al/archivo.jpg');
$page->object($image, $x, $y, $w, $h);
# Añadir contenido textual
my $text = $page->text();
# Añadir contenido gráfico (trazos y formas)
my $canvas = $page->graphics();

MÉTODOS

size

# Establecer el tamaño de la página usando un nombre común
$page->size('letter');
# Establecer el tamaño de la página usando coordenadas en puntos (X1, Y1, X2, Y2)
$page->size([0, 0, 612, 792]);
# Obtener las coordenadas de la página en puntos
my @rectangle = $page->size();

Establece el tamaño físico de la página (también conocido como caja de medios) cuando se llama con un argumento. Consulte la sección "Tamaños de página" a continuación para ver los valores posibles. Devuelve el objeto $page.

Devuelve las coordenadas del rectángulo que encierra el tamaño físico de la página cuando se llama sin argumentos.

El método size es un atajo conveniente para establecer la caja de medios del PDF cuando no se requieren límites de página relacionados con la impresión. Es equivalente a lo siguiente:

# Establecer
$page = $page->boundaries(media => $size);
# Obtener
@rectangle = $page->boundaries->{'media'}->@*;

boundaries

# Establecer
$page->boundaries(
    media => '13x19',
    bleed => [0.75 * 72, 0.75 * 72, 12.25 * 72, 18.25 * 72],
    trim  => 0.25 * 72,
);
# Obtener
%boundaries = $page->boundaries();
($x1, $y1, $x2, $y2) = $page->boundaries('trim');

Establece o reemplaza todos los límites de página de preimpresión cuando se llama con un hash que contiene una o más definiciones de límites de página. Devuelve el objeto $page.

Devuelve los límites de página actuales si se llama sin argumentos. Devuelve las coordenadas del límite de página especificado si se llama con un argumento.

Límites de página

PDF define cinco límites de página. Al crear PDFs para imprentas, utilizará principalmente la caja de medios y la caja de corte. Las imprentas tradicionales también pueden usar la caja de sangrado al agregar marcas de impresión y otra información.

  • media

    La caja de medios define los límites del medio físico en el que se imprimirá la página. Puede incluir cualquier área extendida que rodee la página terminada para sangrado, marcas de impresión u otros fines similares. El valor predeterminado es una página tamaño carta de EE. UU. (8.5" x 11").

  • crop (corte)

    La caja de corte define la región a la que se recortarán los contenidos de la página (recortarán) cuando se muestren o impriman. El valor predeterminado es la caja de medios de la página.

    Este es un límite de página histórico. Probablemente querrá establecer las cajas de sangrado y/o corte en su lugar.

  • bleed (sangrado)

    La caja de sangrado define la región a la que se recortarán los contenidos de la página cuando se produzcan en un entorno de producción. Esto puede incluir cualquier área de sangrado adicional necesaria para acomodar las limitaciones físicas del equipo de corte, doblado y recorte. La página impresa real (caja de medios) puede incluir marcas de impresión que caen fuera de la caja de sangrado. El valor predeterminado es la caja de corte de la página.

  • trim (corte final)

    La caja de corte final define las dimensiones previstas de la página terminada después del recorte. Puede ser más pequeña que la caja de medios para permitir contenido relacionado con la producción, como instrucciones de impresión, marcas de corte o barras de color. El valor predeterminado es la caja de corte de la página.

  • art (arte)

    La caja de arte define la extensión del contenido significativo de la página (incluido el posible espacio en blanco) según lo previsto por el creador de la página. El valor predeterminado es la caja de corte de la página.

Tamaños de página

Los tamaños de página de PDF se almacenan como coordenadas de rectángulo. Para mayor comodidad, PDF::API2 también admite una serie de alias y atajos que son más fáciles de usar para los humanos.

Los siguientes formatos están disponibles:

  • un tamaño de papel estándar 
    $page->boundaries(media => 'A4');

    Los alias para los tamaños de papel más comunes están integrados (sin distinción de mayúsculas y minúsculas).

    EE. UU.: Letter, Legal, Ledger, Tabloid

    Métrico: 4A0, 2A0, A0 - A6, 4B0, 2B0, y B0 - B6

  • una cadena "AnxAl" en pulgadas 
    $page->boundaries(media => '8.5x11');

    Muchos tamaños de papel de EE. UU. se identifican comúnmente por su tamaño en pulgadas en lugar de por un nombre específico. Estos pueden pasarse como cadenas con el ancho y la altura separados por una "x".

    Ejemplos: "4x6", "12x18", "8.5x11"

  • un número (en puntos) que representa una reducción del siguiente cuadro más grande 
    # Nota: Hay 72 puntos por pulgada
$page->boundaries(media => '12x18', trim => 0.5 * 72);
# Equivalente
$page->boundaries(media => [0,        0,        12   * 72, 18   * 72],
                  trim  => [0.5 * 72, 0.5 * 72, 11.5 * 72, 17.5 * 72]);

    Este ejemplo muestra una hoja física de 12" x 18" que se reducirá a un tamaño final de 11" x 17" recortando 0.5" de cada borde. Se supone que el límite más pequeño está centrado en el más grande.

    El "siguiente cuadro más grande" sigue este orden, deteniéndose en el primer valor definido:

    art -> trim -> bleed -> media
crop -> media

    Esta opción no está disponible para la caja de medios ya que es, por definición, el límite más grande.

  • [$ancho, $alto] en puntos 
    $page->boundaries(media => [8.5 * 72, 11 * 7.2]);

    Para otros tamaños de página o límites, el ancho y el alto (en puntos) se pueden especificar directamente como una matriz.

  • [$x1, $y1, $x2, $y2] en puntos 
    $page->boundaries(media => [0, 0, 8.5 * 72, 11 * 72]);

    Finalmente, se pueden especificar las coordenadas brutas de las esquinas inferior izquierda y superior derecha de un rectángulo.

rotation

$page = $page->rotation($degrees);

Gira la página en sentido horario al mostrarse o imprimirse. $degrees debe ser un múltiplo de 90 y puede ser negativo para rotación en sentido antihorario.

El sistema de coordenadas sigue la rotación de la página. En otras palabras, después de girar la página 180 grados, [0, 0] estará en la esquina superior derecha de la página en lugar de la inferior izquierda, X aumentará hacia la derecha y Y disminuirá hacia abajo.

Para crear una página horizontal sin mover el origen, use "size".

graphics

my $canvas = $page->graphics(%options);

Devuelve un objeto PDF::API2::Content para dibujar trazos y formas.

Las siguientes opciones están disponibles:

  • prepend (booleano)

    Si es verdadero, coloca el dibujo al principio del flujo de contenido de la página en lugar de al final.

  • compress (booleano)

    Especifica manualmente si las instrucciones de dibujo deben comprimirse. Si no se especifica, se utilizará la configuración de compresión del PDF, que está activada por defecto.

text

my $text = $page->text(%options);

Devuelve un objeto PDF::API2::Content para incluir contenido textual.

Las opciones son las mismas que las del método "graphics".

object

$page = $page->object($object, $x, $y, $scale_x, $scale_y);

Coloca una imagen u otro objeto externo (también conocido como XObject) en la página en la ubicación especificada.

Si $x y $y se omiten, el objeto se colocará en "[0, 0]".

NAME

PDF::API2::Page - manipulate PDF pages

SYNOPSIS

    use PDF::API2;
    my $pdf = PDF::API2->new();
    my $page = $pdf->page();
    $page->size( 595, 842 ); # A4 size
    my $gfx = $page->graphics();
    $gfx->text("Hello, world!");
    # ... later
    $page->annotation();

METHODS

page

my $page = $pdf->page($page_number, $options);

Returns a PDF::API2::Page object for the given page number. If the page does not exist, it is created. Page numbers are 1-based.

The $options hash can contain:

size
Set the page size. You can use predefined constants like "A4", "letter", etc. (see "Page Sizes" in PDF::API2::Util) or specify an array ref like [ 595, 842 ] for the width and height in points (72 points per inch).
background
A string containing PDF content (e.g. created with "graphics") to be placed as a background on the page. This content will be drawn *before* any content you add later.
text
A string containing PDF content (e.g. created with "graphics") to be placed as a foreground on the page. This content will be drawn *after* any content you add later.

size

my ($width, $height) = $page->size();
$page->size( $width, $height );
$page->size( $alias );

Get or set the page size. See "Page Sizes" in PDF::API2::Util for a list of predefined page size aliases.

rotation

my $rotation = $page->rotation();
$page->rotation( $rotation );

Get or set the page rotation. Valid values are 0, 90, 180, 270.

boundaries

my $boundaries = $page->boundaries();
$page->boundaries( $boundaries );

Get or set the page boundaries (MediaBox, CropBox, BleedBox, TrimBox, ArtBox). The $boundaries argument should be an array reference, where each element is itself an array reference of 4 numbers representing the lower-left x, lower-left y, upper-right x, and upper-right y coordinates.

The order is: MediaBox, CropBox, BleedBox, TrimBox, ArtBox.

You can omit boundary types, e.g., [ $mediabox, $cropbox ]. If a boundary type is omitted, it is assumed to be the same as the MediaBox.

If $boundaries is omitted when getting, it returns the current boundaries.

If $boundaries is omitted when setting, it resets all boundaries to the MediaBox.

The MediaBox is mandatory. All other boxes are optional.

mediabox

my $mediabox = $page->mediabox();
$page->mediabox( $mediabox );

Get or set the MediaBox of the page. See "boundaries" for the format.

cropbox

my $cropbox = $page->cropbox();
$page->cropbox( $cropbox );

Get or set the CropBox of the page. See "boundaries" for the format.

bleedbox

my $bleedbox = $page->bleedbox();
$page->bleedbox( $bleedbox );

Get or set the BleedBox of the page. See "boundaries" for the format.

trimbox

my $trimbox = $page->trimbox();
$page->trimbox( $trimbox );

Get or set the TrimBox of the page. See "boundaries" for the format.

artbox

my $artbox = $page->artbox();
$page->artbox( $artbox );

Get or set the ArtBox of the page. See "boundaries" for the format.

graphics

my $gfx = $page->graphics();

Returns a PDF::API2::Graphics object, used for drawing on the page.

text

my $text = $page->text($font, $size);

Returns a PDF::API2::Text object, used for drawing text on the page.

If $font is omitted, it defaults to the PDF::API2 built-in font Helvetica.

If $size is omitted, it defaults to 12 point.

image

my $imageobj = $page->image($image_file, $x, $y, $scale_x, $scale_y);

Place an image onto the page. $image_file can be a file name, a filehandle, or a PDF::API2::Resource::Image object. $x and $y are the coordinates for the bottom-left corner of the image.

If $scale_x is omitted, it will default to 72 pixels per inch. If $scale_y is omitted, the image will be scaled proportionally based on the image dimensions.

For other external objects, the scale is a multiplier, where 1 (the default) represents 100% (i.e. no change).

If the object to be placed depends on a coordinate transformation (e.g. rotation or skew), first create a content object using "graphics", then call "object" in PDF::API2::Content after making the appropriate transformations.

annotation

my $annotation = $page->annotation();

Returns a new PDF::API2::Annotation object.
