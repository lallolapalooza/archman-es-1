NAME

PDF::Builder::Lite - Métodos ligeros de creación de PDF

SYNOPSIS

$pdf = PDF::Builder::Lite->new();
$pdf->page(595,842);
$img = $pdf->image('some.jpg');
$font = $pdf->corefont('Times-Roman');
$font = $pdf->ttfont('TimesNewRoman.ttf');

DESCRIPTION

Esta clase no está mantenida (desde 2007) y no debe usarse en nuevos códigos. Combina muchas de las metodologías de PDF::Builder y PDF::Builder::Content en una sola clase, pero no es realmente mejor para usar.

Hay muchas mejoras y clarificaciones en la distribución restante que no se reflejan aquí, así que el término "Lite" ya no aplica. Es solo para compatibilidad con código antiguo.

PDF::Builder::Lite - PDF Builder Lite

NAME

PDF::Builder::Lite - PDF Builder Lite

SYNOPSIS

use PDF::Builder::Lite;
my $pdf = PDF::Builder::Lite->new( -file => "test.pdf" );
# ... draw something ...
$pdf->close();

DESCRIPTION

This is a minimal implementation of PDF::Builder, providing only the basic drawing and text output methods.

See the original PDF::Builder documentation for a description of the methods, most of which are identical.

The major difference is that this module does not include support for pages, fonts, images, or much else beyond the absolute minimum for drawing basic shapes and text.

In particular, the new method has only one option: -file, which specifies the name of the PDF file to be created.

There is no support for named destinations, explicit page creation, font embedding, or anything else that might be considered advanced.

METHODS

The following methods are provided. Their functionality is identical to the corresponding methods in the full PDF::Builder module, except where noted.

arc

$pdf->arc($xc,$yc, $rx,$ry, $alpha,$beta, $move, $dir)
$pdf->arc($xc,$yc, $rx,$ry, $alpha,$beta, $move)
Dibuja un arco centrado en C[$xc,$yc], con radio x C[$rx] y radio y C[$ry], desde C[$alpha] grados hasta C[$beta] grados. Si C[$move] es true, no dibuje una línea hasta el inicio del arco. C[$dir] por defecto es 0 para un barrido en sentido antihorario, y puede ser establecido a 1 para un barrido en sentido horario.

ellipse

$pdf->ellipse($xc,$yc, $rx,$ry)
Dibuja una elipse centrada en C[$xc,$yc], con radio x C[$rx] y radio y C[$ry].

circle

$pdf->circle($xc,$yc, $r)
Dibuja un círculo centrado en C[$xc,$yc], de radio C[$r].

rect

$pdf->rect($x,$y, $w,$h)
Dibuja un rectángulo con la esquina inferior izquierda en C[$x,$y], ancho (+x) C[$w] y alto (+y) C[$h].

rectxy

$pdf->rectxy($x1,$y1, $x2,$y2)
Dibuja un rectángulo con esquinas opuestas C[$x1,$y1] y C[$x2,$y2].

poly

$pdf->poly($x1,$y1, ..., $xn,$yn)
Dibuja una polilínea (múltiples segmentos de línea) comenzando en (mover a) C[$x1,$y1] y continuando hacia C[$x2,$y2], ..., C[$xn,$yn].

close

$pdf->close()
Cierra una forma (dibuja una línea de regreso al inicio).

stroke

$pdf->stroke()
Traza (dibuja realmente) una forma cuya ruta ya ha sido definida, utilizando el "strokecolor" solicitado.

fill

$pdf->fill()
Rellena una geometría (ruta) cerrada, utilizando el "fillcolor" solicitado. La regla de devanado no cero se usa si la ruta se cruza.

fillstroke

$pdf->fillstroke()
Rellena (usando "fillcolor") y traza (usando "strokecolor") una ruta cerrada. La regla de devanado no cero se usa si la ruta se cruza.

image

$pdf->image($imgobj, $x,$y, $w,$h)
$pdf->image($imgobj, $x,$y, $scale)
$pdf->image($imgobj, $x,$y)
Tenga en cuenta: El ancho/alto o la escala dada están en coordenadas del espacio de usuario, que están sujetas a transformaciones que pueden haber sido especificadas de antemano.

Por defecto, esto tiene una resolución de 72 ppp, por lo que si desea que una imagen tenga una resolución de 150 o 300 ppp, debe especificar una escala de 72/150 (o 72/300) o ajustar el ancho/alto en consecuencia.

textstart

$pdf->textstart()
Fuerza el inicio del modo de texto mientras se está en gráficos.

textfont

$pdf->textfont($fontobj, $size)
Define la fuente actual como un objeto de fuente (ya definido) con el tamaño dado.

textleading

$txt->textleading($leading)
Establece el "interlineado" de línea base a línea base que se utilizará para las líneas de texto.

text

$pdf->text($string)
Aplica (escribe) el texto dado en la ubicación de texto actual, utilizando la fuente ya especificada.

nl

$pdf->nl()
Escribe un salto de línea (baja a la siguiente línea).

textend

$pdf->textend()
Fuerza el fin de la salida de texto y regresa a gráficos.

print

$pdf->print($font, $size, $x,$y, $rot, $just, $text)
Envoltorio de conveniencia para acortar la secuencia textstart..textend.

Entra en modo de texto, establece la fuente al objeto y tamaño, va a la ubicación, establece cualquier rotación, establece la justificación y escribe el array de texto. La justificación es 0 para izquierda, 1 para centro y 2 para derecha.
