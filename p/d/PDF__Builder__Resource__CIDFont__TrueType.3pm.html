NOMBRE

PDF::Builder::Resource::CIDFont::TrueType - Soporte para fuentes TrueType (ttfont)

Hereda de PDF::Builder::Resource::CIDFont

Generalmente también usable para fuentes OTF (Open Type)

MÉTODOS

new

$fuente = PDF::Builder::Resource::CIDFont::TrueType->new($pdf, $archivo, %opts)
Devuelve un objeto de fuente para fuentes TrueType y OpenType (desde la llamada ttfont()).

Las Opciones válidas (%opts) son:

encode
Cambia la codificación de la fuente desde su valor predeterminado (WinAnsiEncoding).

Tenga en cuenta que para una codificación de un solo byte (por ejemplo, 'latin1'), está limitado a 256 caracteres definidos para esa codificación. 'automap' no funciona con TrueType. Si desea más caracteres que eso, utilice la codificación 'utf8' con una cadena de texto codificada en UTF-8.

isocmap
Utiliza el Mapa Unicode ISO en lugar del Mapa Unicode MS predeterminado.
unicodemap
Si es 1 (predeterminado), genera un CMap ToUnicode para permitir la búsqueda de texto y lectores de pantalla. Establecer en 0 para ahorrar espacio no incluyendo el CMap ToUnicode, pero la búsqueda de texto y la lectura de pantalla no serán posibles.
dokern
Habilita el kerning si hay datos disponibles.

"kerning" todavía se acepta como una alternativa (más antigua) a "dokern".

noembed
Deshabilita la incrustación del archivo de fuente. ¡Tenga en cuenta que esto es potencialmente peligroso, ya que los glifos proporcionados en la máquina del lector de PDF pueden no coincidir con los utilizados en la máquina del escritor de PDF (la que ejecuta PDF::Builder)! Si sabe con seguridad que todos los lectores de PDF utilizarán el mismo archivo TTF u OTF que está utilizando con PDF::Builder; no incrustar la fuente puede ser aceptable, a cambio de un tamaño de archivo PDF menor. Tenga en cuenta que el Lector necesita saber dónde encontrar el archivo de fuente: no puede estar en cualquier lugar, pero normalmente debe figurar en una ruta que el Lector siga. De lo contrario, ¡no podrá renderizar el texto!

El único valor para la bandera "noembed" que se verifica actualmente es 1, lo que significa no incrustar el archivo de fuente en el PDF. Cualquier otro valor actualmente resulta en la incrustación del archivo de fuente (por defecto), aunque en el futuro, otros valores podrían tener significado (como verificar bits de permiso).

Algunos comentarios adicionales sobre la incrustación de archivos de fuente en el PDF: además de aumentar sustancialmente el tamaño del PDF (incluso si la fuente está subdividida, por defecto), PDF::Builder no verifica el archivo de fuente en busca de indicadores de licencias de fuentes e limitaciones de uso. Una fundición de fuentes puede no permitir la incrustación en absoluto, puede permitir que se incruste una subsección de la fuente, puede permitir que se incruste una fuente completa y puede especificar qué se puede hacer con una fuente incrustada (por ejemplo, puede o no ser extraída para su uso más allá de la visualización de este PDF). Cuando elige usar (e incrustar) una fuente, debe tener en cuenta cualquier problema de licencia.

nosubset
Deshabilita la subdivisión de una fuente TTF/OTF, cuando está incrustada. Por defecto, solo los glifos utilizados por un documento se incluyen en el archivo, y no la fuente completa. Esto puede resultar en un enorme ahorro en el tamaño del archivo PDF. Si tiene la intención de permitir que los usuarios editen el PDF, no tener el conjunto completo de glifos de fuente disponibles puede causar problemas, así que tenga esto en cuenta (y considere usar "nosubset => 1". Establecer esta bandera a cualquier valor resulta en que el conjunto completo de glifos de fuente se incruste en el archivo. Podría ser una buena idea usar solo el valor 1, en caso de que otros valores se asignen roles en el futuro.
debug
Si se establece en 1 (el valor predeterminado es 0), se genera información de diagnóstico sobre el procesamiento de CMap.
usecmf
Si se establece en 1 (el valor predeterminado es 0), la primera prioridad es hacer uso de uno de los cuatro archivos ".cmap" para fuentes CJK. Esta es la forma *antigua* de procesar archivos TTF. Si, después de todo, no se ha encontrado un CMap *interno* que funcione (para usecmf=>0), ttfont() recurrirá a usar un archivo ".cmap" si es posible.
cmaps
Esta bandera puede establecerse a una cadena que liste los pares Plataforma/Codificación a buscar de los CMaps internos en el archivo de fuente, en el orden deseado (primero la mayor prioridad). Si se da una lista (separada por comas y/o espacios), se usa tanto para plataformas Windows como no Windows (en las que se ejecuta PDF::Builder, *no* las del lector de PDF). Se pueden dar dos listas, separadas por un punto y coma ; , siendo la primera para una plataforma Windows y la segunda para no Windows. La lista predeterminada es "0/6 3/10 0/4 3/1 0/3; 0/6 0/4 3/10 0/3 3/1". Finalmente, en lugar de una lista P/E, se puede dar una cadena "find_ms" para indicar que simplemente llame al método find_ms() de Font::TTF para encontrar un CMap interno (preferiblemente de Windows). "cmaps" establecido en 'find_ms' emularía la forma *antigua* de buscar CMaps. Las fuentes de símbolos (3/0) siempre usan find_ms(), y la nueva búsqueda predeterminada es (si ".cmap" no se usa, ver "usecmf") intentar encontrar una coincidencia con la lista predeterminada para el sistema operativo apropiado. Si no se encuentra ninguna, se intenta find_ms(), y como último recurso se usa el ".cmap" (si está disponible), incluso si "usecmf" no es 1.

fontfile

$fuente->fontfile()
Devuelve el objeto del archivo de fuente (elemento ' ff'), para que se puedan invocar sus métodos.

fontobj

$fuente->fontobj()
Devuelve el objeto de fuente, para que se puedan usar sus métodos y propiedades.

wxByCId

$fuente->wxByCId($gID)
Devuelve el ancho de glifo sin escalar, dado el ID del glifo (CID).

haveKernPairs

$bandera = $fuente->haveKernPairs()
¿La fuente incluye datos de kerning? Invoca haveKernPairs() de fontfile. No está claro qué argumentos opcionales adicionales hay.

kernPairCid

$bandera = $fuente->kernPairCid($gID, $n)
Devuelve información de kerning para? No está claro qué argumentos adicionales hay. Invoca el método kernPairCid() de fontfile.

subsetByCid

$fuente->subsetByCid($gID)
Invoca el método subsetByCId() de fontfile() para colocar el glifo en la caché de fuente incrustada en el PDF.

subvec

$fuente->subvec($gID)
(Sin información) invoca el método subvec() de fontfile.

glyphNum

$contador = $fuente->glyphNum()
Número de glifos en la fuente.

outobjdeep

$fuente->outobjdeep()
(Sin información) salida a PDF
