PDF::API2::Basic::PDF::Name(3) Documentación de Perl contribuida por el usuario PDF::API2::Basic::PDF::Name(3)

NOMBRE

PDF::API2::Basic::PDF::Name - Objeto de nombre PDF de bajo nivel

MÉTODOS

PDF::API2::Basic::PDF::Name->desde_pdf($cadena)

Crea un nuevo objeto de cadena (aún no un objeto completo) a partir de una cadena dada. La cadena se analiza según los criterios de entrada, con el escape funcionando, particular para los Nombres.

$n->convertir ($cadena, $pdf)

Convierte un nombre en una cadena eliminando el '/' y convirtiendo cualquier codificación hexadecimal.

$s->como_pdf ($pdf)

Devuelve un nombre formateado como PDF. $pdf es opcional, pero debería ser el objeto de archivo PDF para el que se pretende el nombre si se proporciona.

PDF::API2::Basic::PDF::Name->cadena_a_nombre ($cadena, $pdf)

Codifica adecuadamente la cadena $cadena para su salida en el objeto de archivo $pdf (el formato exacto puede depender de la versión de $pdf).

PDF::API2::Basic::PDF::Name->nombre_a_cadena ($cadena, $pdf)

Decodifica adecuadamente la cadena $cadena tal como se lee del objeto de archivo $pdf (la decodificación exacta puede depender de la versión de $pdf). Principalmente, deshace la codificación hexadecimal para versiones de PDF > 1.1.
