Hereda de PDF::Builder::Basic::PDF::Objind

MÉTODOS

new

PDF::Array->new($parent, @values)
Crea un array con el padre de almacenamiento dado y una lista opcional de valores para inicializar el array.

outobjdeep

$a->outobjdeep($fh, $pdf)
Expone un array como un array de PDF al manejador de archivos dado. Es inusual necesitar llamar a este método desde código de usuario.

elementos

$a->elementos()
Devuelve el contenido del array.

agregar_elementos

$a->agregar_elementos(@elementos)
Añade los elementos dados al final del array. Un elemento solo se añade si está definido.

eliminar_elemento

$a->eliminar_elemento($elemento)
Elimina todas las ocurrencias de un elemento de un array.

val

$a->val()
Devuelve una referencia al contenido del array.

copiar

$a->copiar($pdf)
Copia el array con copia profunda en los elementos que no son objetos PDF completos con respecto a un contexto de salida de $pdf particular.
