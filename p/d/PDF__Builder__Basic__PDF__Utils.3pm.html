PDFString

PDFString($text, $usage)
Devuelve PDFStr($text) o PDFUtf($text), dependiendo de si $text ya está en UTF-8 y si $usage permite UTF-8. Si UTF-8 *no* está permitido, se aplicará "downgrade" a un $text formateado en UTF-8.

$usage es una cadena de un solo carácter que indica el uso para el cual se aplicará $text. Algunos usos permiten UTF-8, mientras que otros (actualmente) lo prohíben:

's'
Una cadena normal, donde se permite texto UTF-8.
'n'
Un destino nombrado, donde se permite texto UTF-8.
'o'
Un título de esquema, donde se permite texto UTF-8.
'p'
Un título de ventana emergente, donde se permite texto UTF-8.
'm'
metadatos, donde se permite texto UTF-8.
'f'
Una ruta y/o nombre de archivo, donde actualmente el texto UTF-8 **no** está permitido.
'u'
Una URL, donde actualmente el texto UTF-8 **no** está permitido.
'x'
Cualquier otro uso donde el texto UTF-8 **no** está permitido.
