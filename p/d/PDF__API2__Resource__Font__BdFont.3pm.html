PDF::API2::Resource::Font::BdFont(3) Documentación de Perl contribuida por el usuario PDF::API2::Resource::Font::BdFont(3)

NOMBRE

PDF::API2::Resource::Font::BdFont - Módulo para usar fuentes de mapas de bits.

SINOPSIS

#
use PDF::API2;
#
$pdf = PDF::API2->new;
$sft = $pdf->bdfont($file);
#

MÉTODOS

$font = PDF::API2::Resource::Font::BdFont->new $pdf, $font, %options
Devuelve un objeto BmpFont.

Las %options válidas son:

-encode ... cambia la codificación de la fuente de su valor predeterminado. Consulte Encode de Perl para ver los valores soportados.

-pdfname ... cambia el nombre de referencia de la fuente de su valor predeterminado. El nombre de referencia normalmente se genera automáticamente y se puede recuperar mediante $pdfname=$font->name.
