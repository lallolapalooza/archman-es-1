NOMBRE

PDF::API2::Basic::PDF::String - Objeto de cadena PDF de bajo nivel

MÉTODOS

PDF::API2::Basic::PDF::String->from_pdf($cadena)

Crea un nuevo objeto de cadena (aún no un objeto completo) a partir de una cadena dada. La cadena se analiza según los criterios de entrada con escapes funcionando.

PDF::API2::Basic::PDF::String->new($cadena)

Crea un nuevo objeto de cadena (aún no un objeto completo) a partir de una cadena dada. La cadena se analiza según los criterios de entrada con escapes funcionando.

$s->convertir($cadena)

Devuelve $cadena convertida según los criterios de entrada desde un archivo PDF.

$s->valor

Devuelve el valor de esta cadena (la cadena en sí).

$->como_pdf

Devuelve la cadena formateada para su salida como PDF para el objeto de archivo PDF $pdf.

$s->outobjdeep

Emite la cadena en formato PDF, completa con las conversiones necesarias.
