NAME

PDF::Builder::Outline - Manage outline lists (a.k.a. bookmarks)

Inherits from PDF::Builder::Basic::PDF::Dict

SYNOPSIS

# Get or create the outline tree
my $outlines = $pdf->outline();
# Add an item
my $item = $outlines->outline();
$item->title('First page');
$item->dest($pdf->open_page(1), fit-def);

METHODS

new

$outline = PDF::Builder::Outline->new($api, $parent)
$outline = PDF::Builder::Outline->new($api)
Returns a new outline item (called from $outlines->outline()).

By default, if $parent is omitted, the new outline item is placed at the end of any existing outline siblings. Otherwise it becomes a child of the $parent outline item.

Examine the Outline Tree

has_children

$boolean = $outline->has_children()
Returns true if the current item has children (children).

count

$integer = $outline->count()
Returns the count of visible children when the current item is open (expanded).

first

$child = $outline->first()
Returns the first child at the current outline tree level, if any.

last

$child = $outline->last()
Returns the last child at the current outline tree level, if any.

parent

$parent = $outline->parent()
Returns the parent of the current item, if it's not at the top level of the outline tree.

prev

$sibling = $outline->prev() # Get
$sibling = $outline->prev(outline_obj) # Set
Returns the previous item at the current outline tree level ("undef" if it's already the first item).

next

$sibling = $outline->next() # Get
$sibling = $outline->next(outline_obj) # Set
Returns the next item at the current outline tree level ("undef" if it's already the last item).

Modify the Outline Tree

outline

$child_outline = $parent_outline->outline()
Returns a new sub-outline item added to the end of the children of $parent_outline. If there are no children yet, it creates the first one.

insert_after

$sibling = $outline->insert_after()
Adds an outline item immediately after the $outline item.

insert_before

$sibling = $outline->insert_before()
Adds an outline item immediately before the $outline item.

delete

$outline->delete()
Deletes the current outline item from the outline tree. If the item has children, they will be deleted as well, since they are no longer linked.

is_open

$boolean = $outline->is_open() # Get
$outline = $outline->is_open($boolean) # Set
Get or set whether the outline item is open (expanded) or closed (collapsed). $boolean is 0/False to close (collapse children), or 1/True to open (expanding) and show children.

open

$outline->open()
Sets the outline item's state to open (expanded). This is an alternative method to using is_open(true).

closed

$outline->closed()
Sets the outline item's state to closed (collapsed). This is an alternative method to using is_open(false).

Set Outline Attributes

title

$title = $outline->title() # Get
$outline = $outline->title($text) # Set
Get or set the title of the outline item.

dest

$outline->dest($page_object, %position)
$outline->dest($page_object)
Set the destination page and optional position of the outline item.

%position can be any of those mentioned in "Page Fit Options" in PDF::Builder::Docs.

"xyz" is the default fit, with left and top position and zoom equal to the calling page.

$outline->dest($name, %position)
$outline->dest($name)

Connects the outline item to a "Named Destination" defined elsewhere, and optional position as described above.

Destination targets

uri, url

$outline->uri($url)
Define the outline item as a launch page with url $url, typically a web site.

Alternate name: "url"

You can use either "uri" or "url"; "uri" is compatible with PDF::API2.

launch, file

$outline->launch($file)
Define the outline item as a launch file with file path $file. This is typically a local program or file.

Alternate name: "file"

You can use either "launch" or "file"; "launch" is compatible with PDF::API2.

pdf, pdf_file, pdfile

$outline->pdf($pdffile, $page_number, %position, %args)
$outline->pdf($pdffile, $page_number)
Define the outline item's destination as a PDF file with file path $pdffile, on page $pagenum (defaults to 0), and $position (same as dest() method).

Alternate names: "pdf_file" and "pdfile"

You can use either "pdf" or "pdf_file" (or the older "pdfile"); "pdf" is compatible with PDF::API2.
