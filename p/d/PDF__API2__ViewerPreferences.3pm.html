PDF::API2::ViewerPreferences(3) Documentación de Perl contribuida por el usuario PDF::API2::ViewerPreferences(3)

NOMBRE

PDF::API2::ViewerPreferences - Cómo se debe mostrar o imprimir el PDF

MÉTODOS

$self = $class->new($pdf)
Crea un nuevo objeto ViewerPreferences a partir de un objeto PDF::API2.
%preferencias = $self->obtener_preferencias()
Devuelve un hash que contiene todas las preferencias del visor que están definidas en el PDF.
$valor = $self->obtener_preferencia($nombre)
Devuelve el valor de la preferencia del visor especificada si está presente, o "undef" si no.
$self->establecer_preferencias(%valores)
Establece una o más preferencias del visor, como se describe en la sección de preferencias a continuación.

PREFERENCIAS

Las Preferencias del Visor describen cómo se debe presentar el documento en pantalla o en impresión. No todos los visores de PDF respetarán estas preferencias.

Las preferencias booleanas tienen por defecto falso y aceptan (o devuelven) 0 o 1 como argumentos.

Las preferencias de cuadro delimitador aceptan (o devuelven) "media_box", "crop_box", "bleed_box", "trim_box", o "art_box".

ocultar_barra_herramientas (booleano)
Un indicador que especifica si se deben ocultar las barras de herramientas cuando el documento está activo.
ocultar_barra_menus (booleano)
Un indicador que especifica si se debe ocultar la barra de menús cuando el documento está activo.
ocultar_interfaz_ventana (booleano)
Un indicador que especifica si se deben ocultar los elementos de la interfaz de usuario en la ventana del documento (como las barras de desplazamiento y los controles de navegación), dejando solo se muestren los contenidos del documento.
ajustar_ventana (booleano)
Un indicador que especifica si se debe redimensionar la ventana del documento para que se ajuste al tamaño de la primera página mostrada.
centrar_ventana (booleano)
Un indicador que especifica si se debe posicionar la ventana del documento en el centro de la pantalla.
mostrar_titulo_documento (booleano)
Un indicador que especifica si la barra de título de la ventana debe mostrar el título del documento tomado de la entrada Título del directorio de información del documento. Si es falso, la barra de título debería mostrar en su lugar el nombre del archivo PDF que contiene el documento.
modo_pagina_no_pantalla_completa (nombre)
El modo de página del documento, que especifica cómo mostrar el documento al salir del modo de pantalla completa. Las opciones son las mismas que "modo_pagina" en PDF::API2, excepto que las opciones "adjuntos" y "pantalla_completa" no son compatibles.
dirección ('izq_a_der' o 'der_a_izq')
El orden de lectura predominante para el texto (de izquierda a derecha o de derecha a izquierda).

Esta entrada no tiene un efecto directo sobre el contenido del documento o la numeración de páginas, pero puede usarse para determinar el posicionamiento relativo de las páginas cuando se muestran una al lado de la otra o se imprimen en modo n-up.

area_vista (cuadro delimitador)
El nombre del límite de página que representa el área de una página que se mostrará al ver el documento en pantalla.
recorte_vista (cuadro delimitador)
El nombre del límite de página al que se recortarán los contenidos de una página al ver el documento en pantalla.
area_impresion (cuadro delimitador)
El nombre del límite de página que representa el área de una página que se renderizará al imprimir el documento.
recorte_impresion (cuadro delimitador)
El nombre del límite de página al que se recortarán los contenidos de una página al imprimir el documento.
escalado_impresion ('ninguno' o 'predeterminado_app')
La opción de escalado de página que se seleccionará cuando se muestre el cuadro de diálogo de impresión para este documento. "ninguno" representa sin escalado de página, y "predeterminado_app" representa el escalado de impresión predeterminado del lector.
dúplex ('simplex', 'duplex_corto', o 'duplex_largo')
La opción de manejo de papel que se utilizará al imprimir el archivo desde el cuadro de diálogo de impresión. Los valores de dúplex representan si la página debe voltearse por su borde corto o largo, respectivamente.
seleccionar_bandeja_por_tamano_pdf (booleano)
Un indicador que especifica si se debe utilizar el tamaño de página del PDF para seleccionar la bandeja de entrada de papel. Esta configuración solo influye en los valores preestablecidos utilizados para completar el cuadro de diálogo de impresión que presenta el lector.
rango_pagina_impresion (un array de pares de enteros)
Los números de página utilizados para inicializar el cuadro de diálogo de impresión cuando se imprime el archivo. El array contendrá un número par de enteros para ser interpretados en pares, con cada par especificando la primera y la última página en un sub-rango de páginas a imprimir. La primera página del archivo PDF se denotará con 1.
num_copias (entero)
El número de copias que se imprimirán cuando se abra el cuadro de diálogo de impresión para este archivo.
