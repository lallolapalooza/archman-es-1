PDF::API2::Basic::PDF::Pages(3) Documentación de Perl aportada por el usuario PDF::API2::Basic::PDF::Pages(3)

NOMBRE

PDF::API2::Basic::PDF::Pages - Objeto de árbol de páginas de bajo nivel

DESCRIPCIÓN

Un objeto Pages es el padre de otros objetos pages o de los propios objetos de página.

MÉTODOS

PDF::API2::Basic::PDF::Pages->new($pdf, $parent)

Esto crea un nuevo objeto Pages en un PDF. Nótese que $parent aquí no es el contexto del archivo para el objeto, sino el objeto pages padre para este objeto pages. Si estamos usando esta clase para crear un nodo raíz, entonces $parent debe apuntar al contexto del archivo, que se identifica por no tener un Type de Pages. $pdf es el objeto de archivo (o una referencia a un array de objetos de archivo) en el que se creará el nuevo objeto Pages.

$p->find_page($page_number)

Devuelve la página dada, utilizando los valores de recuento de páginas en el árbol de páginas. Las páginas comienzan en 0.

$p->add_page($page, $page_number)

Inserta la página antes del $page_number dado. $page_number puede ser negativo para contar desde el FINAL del documento. -1 es después de la última página. Del mismo modo, $page_number puede ser mayor que el número de páginas actualmente en el documento, para añadirla al final.

@objects = $p->get_pages()

Devuelve una lista de objetos de página en el documento en orden de página.

$p->find_prop($key)

Busca hacia arriba a través del árbol de herencia para encontrar una propiedad.

$p->add_font($pdf, $font)

Crea o edita el diccionario de recursos en este nivel de la jerarquía. Si la fuente ya es compatible, incluso a través de la jerarquía, entonces no se añade.

$p->bbox($xmin, $ymin, $xmax, $ymax, [$param])

Especifica el cuadro delimitador para esta y todas las páginas hijas. Si los valores son idénticos a los heredados, no se realiza ningún cambio. $param especifica el nombre del atributo para que otros 'cuadros delimitadores' puedan establecerse con este método.

$p->proc_set(@entries)

Asegura que el recurso actual contenga todas las entradas de los conjuntos de procedimientos listados. Si es necesario, crea un diccionario de recursos local para lograrlo.

$p->get_top

Devuelve la parte superior del árbol de páginas.
