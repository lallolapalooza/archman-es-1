PDF::Builder::NamedDestination(3) Documentación de Perl contribuida por el usuario PDF::Builder::NamedDestination(3)

NOMBRE

PDF::Builder::NamedDestination - Añadir destinos (vistas) con nombre a un PDF

Hereda de PDF::Builder::Basic::PDF::Dict

MÉTODOS

new

$dest = PDF::Builder::NamedDestination->new($pdf, ...)
Crea un nuevo objeto de destino con nombre. Cualquier argumento opcional adicional se pasará a "destination".

Tipos de destinos

dest

$dest->dest($page, %opts)
Un destino (dest) es una vista particular de un PDF, que consiste en un objeto de página, la ubicación de la ventana en esa página, y posibles argumentos de coordenadas y zoom. 
# La ubicación XYZ toma tres argumentos
my $dest1 = PDF::Builder::NamedDestination->new($pdf);
$dest->dest($pdf->open_page(1), 'xyz' => [$x, $y, $zoom]);
# La ubicación Fit no requiere argumentos, pero todavía se necesita uno
# para el array hash
my $dest2 = PDF::Builder::NamedDestination->new($pdf);
$dest->dest($pdf->open_page(2), 'fit' => 1);

Ver "Opciones de Ajuste de Página" en PDF::Builder::Docs para una lista de las ubicaciones disponibles y su sintaxis.

"xyz" es la configuración de ajuste predeterminada, con la posición (izquierda y superior) y el zoom iguales que los de la página de llamada.

Destinos de enlace

link, goto

$dest->link($page, %opts)
Una acción de ir a (link) cambia la vista a un destino especificado (página, ubicación y factor de magnificación).

Los parámetros se describen en "dest".

Nombre alternativo: "goto"

Originalmente este método era "link", pero recientemente PDF::API2 cambió el nombre a "goto". "goto" se añade para compatibilidad.

uri, url

$dest->uri($url)
Define el destino como lanzamiento de URL con la URI $url.

Nombre alternativo: "url"

Originalmente este método era "url", pero recientemente PDF::API2 cambió el nombre a "uri". "url" se conserva para compatibilidad.

launch, file

$dest->launch($file)
Define el destino como lanzamiento de archivo con la ruta $file y opciones de ajuste de página %opts. Se ejecuta la aplicación de destino. Tenga en cuenta que este **no** es un archivo PDF o un archivo del navegador; es una aplicación local.

Nombre alternativo: "file"

Originalmente este método era "file", pero recientemente PDF::API2 cambió el nombre a "launch". "file" se conserva para compatibilidad.

pdf, pdf_file, pdfile

$dest->pdf($pdf_file, $pagenum, %opts)
Define el destino como un archivo PDF con la ruta $pdf_file, en la página $pagenum, y opciones %opts (igual que dest()).

Nombres alternativos: "pdf_file" y "pdfile"

Originalmente este método era "pdfile", y anteriormente se había renombrado a "pdf_file", pero recientemente PDF::API2 cambió el nombre a "pdf". "pdfile" y "pdf_file" se conservan para compatibilidad. **Tenga en cuenta que** la información de posición y zoom todavía se proporciona como un elemento hash en PDF::Builder, mientras que PDF::API2 ha cambiado a una cadena de posición y un array de dimensiones.
