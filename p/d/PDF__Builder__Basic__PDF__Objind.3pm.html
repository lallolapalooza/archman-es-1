NOMBRE

PDF::Builder::Basic::PDF::Objind - Referencia a objeto indirecto PDF

También actúa como una superclase abstracta para todos los elementos de un archivo PDF.

VARIABLES DE INSTANCIA

Las variables de instancia difieren de las variables de contenido en que todas comienzan con un espacio.

' parent'
Para un objeto que es una referencia a un objeto en alguna fuente, esto contiene la referencia al objeto fuente, de modo que si la referencia tuviera que ser desreferenciada, sabríamos a dónde ir a buscar la información.
' objnum' (R)
El número de objeto en la fuente (solo para referencias de objeto)
' objgen' (R)
La generación del objeto en la fuente.

Existen otras variables de instancia que son utilizadas por el padre para el control de archivos.

' isfree'
Esto marca si el objeto está en la lista de libres y disponible para su reutilización como otro objeto en otra parte del archivo.
' nextfree'
Contiene una referencia directa al siguiente objeto libre en la lista de libres.

MÉTODOS

new

PDF::Builder::Basic::PDF::Objind->new()
Crea un nuevo objeto indirecto.

uid

$UID = $r->uid()
Devuelve un ID único para este objeto, creando uno si no lo tenía antes.

release

$r->release()
Libera TODA la memoria utilizada por este objeto indirecto, y todos sus objetos componentes/hijos. Este método es llamado automáticamente por '"PDF::Builder::Basic::PDF::File->release"' (así que no tiene que llamarlo usted mismo).

Nota: es importante que este método se llame en algún momento antes de la destrucción real del objeto. Internamente, los archivos PDF tienen una enorme cantidad de referencias cruzadas y esto causa referencias circulares dentro de nuestras propias estructuras de datos internas. Llamar a 'release()' fuerza a que estas referencias circulares se limpien y la estructura de datos interna completa se purgue.

val

$value = $r->val()
Devuelve el valor de este objeto o lee el objeto y luego devuelve su valor.

Tenga en cuenta que todas las subclases directas *deben* crear sus propias versiones de esta subrutina, de lo contrario, ¡podríamos caer en un bucle muy profundo!

realise

$r->realise()
Se asegura de que el objeto esté completamente leído, etc.

outobjdeep

$v = $r->outobjdeep($fh, $pdf)
Si realmente desea generar este objeto, primero debe leerlo. Esto también significa que todas las subclases directas deben heredar esta subrutina, ¡o entrarán en un bucle infinito!

outobj

$r->outobj($fh, $pdf)
Si es un objeto completo, genera una referencia al objeto; de lo contrario, llama a outobjdeep para generar el contenido del objeto en este punto.

elements

$s = $r->elements()
Relleno de función de superclase abstracta. Devuelve self aquí, pero debería devolver algo más útil si es un array.

empty

$s = $r->empty()
Vacía todo el contenido de este objeto para liberar memoria o para ser leído y pasar el objeto a la lista de libres. Simplifica la anulación de todas las variables de instancia que no sean el número de objeto y la generación.

merge

$o = $r->merge($objind)
Esto fusiona información de contenido en un marcador de posición de referencia de objeto. Esto ocurre cuando se lee una referencia de objeto antes de la definición del objeto y la información en los datos leídos debe fusionarse en el marcador de posición del objeto.

is_obj

$r->is_obj($pdf)
Devuelve si este objeto es un objeto completo con su propio número de objeto o si es puramente un subobjeto. $pdf indica de qué archivo de salida nos preocupamos que sea un objeto.

copy

$r->copy($pdf, $res)
Devuelve una nueva copia de este objeto. Se asume que el objeto es algún tipo de array asociativo y la copia es una copia profunda para los elementos que no son objetos PDF, de acuerdo con $pdf, y una copia superficial para aquellos que sí lo son. Observe que llamar a "copy" en un objeto fuerza al menos una copia de un nivel, incluso si es un objeto PDF. Sin embargo, el objeto devuelto pierde su estado de objeto PDF.

Si $res está definido, la copia va a ese objeto en lugar de crear uno nuevo. Es responsabilidad del llamador bendecir $res, etc. Tenga en cuenta que los elementos de $self no se copian en $res si ya existe una entrada para ellos en $res.
