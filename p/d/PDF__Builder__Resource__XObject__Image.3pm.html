NOMBRE

PDF::Builder::Resource::XObject::Image - Clase base para objetos de imagen ráster externos

Hereda de PDF::Builder::Resource::XObject

MÉTODOS

new

$imagen = PDF::Builder::Resource::XObject::Image->new($pdf, $nombre)
Devuelve un objeto recurso de imagen.

width

$ancho = $imagen->width()
Obtiene el ancho (en puntos) del objeto imagen.

Nota que esta función también tiene la capacidad de *establecer* el ancho, al darle el nuevo ancho (en puntos), pero parece que nunca funcionó correctamente. La capacidad de *establecer* ha sido **obsoleta**, y se planea eliminar en algún momento después de octubre de 2025. Si estás usando el método width() de alguna manera para *establecer* el ancho de la imagen, ¡por favor, háznoslo saber para que podamos planificar mantenerlo habilitado!

height

$alto = $imagen->height()
Obtiene la altura (en puntos) del objeto imagen.

Nota que esta función también tiene la capacidad de *establecer* la altura, al darle la nueva altura (en puntos), pero parece que nunca funcionó correctamente. La capacidad de *establecer* ha sido **obsoleta**, y se planea eliminar en algún momento después de octubre de 2025. Si estás usando el método height() de alguna manera para *establecer* la altura de la imagen, ¡por favor, háznoslo saber para que podamos planificar mantenerlo habilitado!

smask

$imagen->smask($xobject)
Establece la imagen de máscara suave (soft-mask).

mask

$imagen->mask(@rango_color)
$imagen->mask($xobject)
Establece la máscara a un objeto XObject de máscara de imagen o a un array que contenga un rango de colores que se aplicarán como máscara de clave de color.

colorspace

$imagen->colorspace($nombre)
$imagen->colorspace($array)
Establece el espacio de color utilizado por la imagen. Dependiendo del espacio de color, será solo el nombre del espacio de color, o será un array que contenga el espacio de color y cualquier parámetro requerido.

Si se pasa un array, los parámetros deben estar ya codificados como objetos PDF. El array en sí también puede ser un objeto PDF. Si no lo es, se creará uno.

bits_per_component

$imagen->bits_per_component($entero)
Establece el número de bits utilizados para representar cada componente de color.
