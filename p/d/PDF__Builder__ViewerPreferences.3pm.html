PDF::Builder::ViewerPreferences(3) Documentación de Perl contribuida por el usuario PDF::Builder::ViewerPreferences(3)

NOMBRE

PDF::Builder::ViewerPreferences - Cómo se debe mostrar o imprimir el PDF

MÉTODOS

Esto se ha separado de preferences() en PDF::Builder.

new

$self = $class->new($pdf)
Crea un nuevo objeto ViewerPreferences a partir de un objeto PDF::Builder.

get_preferences

%preferences = $self->get_preferences()
Devuelve un hash que contiene todas las preferencias del visor que están definidas en el PDF.

get_preference

$value = $self->get_preference($name)
Devuelve el valor de la preferencia del visor especificada si está presente, o "undef" si no lo está.

set_preferences

$self->set_preferences(%values)
Establece una o más preferencias del visor, como se describe en la sección de preferencias a continuación.

PREFERENCIAS

Las Preferencias del Visor describen cómo se debe presentar el documento en pantalla o al imprimir. No todos los visores de PDF respetarán estas preferencias.

Las preferencias booleanas tienen por defecto falso y toman (o devuelven) 0 o 1 como argumentos.

Las preferencias de Bounding Box toman (o devuelven) "media_box", "crop_box", "bleed_box", "trim_box", o "art_box".

hide_toolbar (booleano)
Una bandera que especifica si se deben ocultar las barras de herramientas cuando el documento está activo.
hide_menubar (booleano)
Una bandera que especifica si se debe ocultar la barra de menú cuando el documento está activo.
hide_window_ui (booleano)
Una bandera que especifica si se deben ocultar los elementos de la interfaz de usuario en la ventana del documento (como las barras de desplazamiento y los controles de navegación), dejando solo visible el contenido del documento.
fit_window (booleano)
Una bandera que especifica si se debe redimensionar la ventana del documento para que se ajuste al tamaño de la primera página mostrada.
center_window (booleano)
Una bandera que especifica si la ventana del documento se debe posicionar en el centro de la pantalla.
display_doc_title (booleano)
Una bandera que especifica si la barra de título de la ventana debe mostrar el título del documento tomado de la entrada Title del directorio de información del documento. Si es falso, la barra de título debería mostrar en su lugar el nombre del archivo PDF que contiene el documento.
non_full_screen_page_mode (nombre)
El modo de página del documento, especificando cómo mostrar el documento al salir del modo de pantalla completa. Las opciones son las mismas que "page_mode" en PDF::Builder, excepto que las opciones "attachments" y "full_screen" no son compatibles.
direction ('l2r' o 'r2l')
El orden de lectura predominante para el texto (de izquierda a derecha o de derecha a izquierda).

Esta entrada no tiene un efecto directo en el contenido del documento ni en la numeración de páginas, pero puede usarse para determinar la posición relativa de las páginas cuando se muestran una al lado de la otra o se imprimen en modo n-up.

view_area (bounding box)
El nombre del borde de la página que representa el área de una página que se mostrará al ver el documento en pantalla.
view_clip (bounding box)
El nombre del borde de la página al que se recortarán los contenidos de una página al ver el documento en pantalla.
print_area (bounding box)
El nombre del borde de la página que representa el área de una página que se renderizará al imprimir el documento.
print_clip (bounding box)
El nombre del borde de la página al que se recortarán los contenidos de una página al imprimir el documento.
print_scaling ('none' o 'app_default')
La opción de escalado de página que se seleccionará cuando se muestre el diálogo de impresión para este documento. "none" representa sin escalado de página, y "app_default" representa el escalado de impresión predeterminado del lector.
duplex ('simplex', 'duplex_short', o 'duplex_long')
La opción de manejo de papel que se utilizará al imprimir el archivo desde el diálogo de impresión. Los valores duplex representan si la página debe voltearse por su borde corto o largo, respectivamente.
pick_tray_by_pdf_size (booleano)
Una bandera que especifica si el tamaño de página del PDF se utilizará para seleccionar la bandeja de entrada de papel. Esta configuración solo influye en los valores preestablecidos utilizados para poblar el diálogo de impresión presentado por el lector.
print_page_rage (un array de pares de enteros)
Los números de página utilizados para inicializar el cuadro de diálogo de impresión cuando se imprime el archivo. El array contendrá un número par de enteros que se interpretarán en pares, con cada par especificando la primera y la última página en un subrango de páginas a imprimir. La primera página del archivo PDF se denotará con 1.
num_copies (entero)
El número de copias que se imprimirán cuando se abra el diálogo de impresión para este archivo.
