PDF::API2::Annotation(3) Documentación de Contribución de Usuarios de Perl PDF::API2::Annotation(3)

NOMBRE

PDF::API2::Annotation - Añadir anotaciones a un PDF

SINOPSIS

my $pdf = PDF::API2->new();
my $font = $pdf->font('Helvetica');
my $page1 = $pdf->page();
my $page2 = $pdf->page();
my $content = $page1->text();
my $message = 'Ir a la Página 2';
my $size = 18;
$content->distance(1 * 72, 9 * 72);
$content->font($font, $size);
$content->text($message);
my $annotation = $page1->annotation();
my $width = $content->text_width($message);
$annotation->rect(1 * 72, 9 * 72, 1 * 72 + $width, 9 * 72 + $size);
$annotation->link($page2);
$pdf->save('sample.pdf');

MÉTODOS

Tipos de Anotación

link

$annotation = $annotation->link($destination, $location, @args);

Enlazar la anotación a otra página de este PDF. $location y @args son opcionales y definen qué parte de la página se mostrará, como se define en "destination" en PDF::API2::NamedDestination.

$destination puede ser un objeto PDF::API2::Page o el nombre de un destino nombrado definido en otro lugar.

url

$annotation = $annotation->uri($uri);

Lanzar $uri — típicamente una página web — cuando se selecciona la anotación.

file

$annotation = $annotation->launch($file);

Abrir $file cuando se selecciona la anotación.

pdf

$annotation = $annotation->pdf($file, $dest, $location, @args);

Abrir el archivo PDF ubicado en $file al destino especificado. $location y @args son opcionales y definen qué parte de la página se mostrará, como se define en "destination" en PDF::API2::NamedDestination.

$dest puede ser un número de página o un destino nombrado prefijado con "#".

text

$annotation = $annotation->text($text);

Definir la anotación como una nota de texto con el contenido especificado.

movie

$annotation = $annotation->movie($filename, $content_type);

Incrustar y enlazar a la película ubicada en $filename con el tipo MIME especificado.

Atributos Comunes de Anotación

rect

$annotation = $annotation->rect($llx, $lly, $urx, $ury);

Definir el rectángulo alrededor de la anotación.

border

$annotation = $annotation->border($h_radius, $v_radius, $width);

Definir el estilo del borde. Por defecto es 0, 0, 0 (sin borde).

content

$annotation = $annotation->content(@lines);

Definir el contenido de texto de la anotación, si es aplicable.

open

$annotation = $annotation->open($boolean);

Establecer la anotación para que esté inicialmente abierta o cerrada. Solo relevante para anotaciones de texto.
