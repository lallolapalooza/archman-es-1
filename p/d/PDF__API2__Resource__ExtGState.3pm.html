PDF::API2::Resource::ExtGState - Soporte para diccionarios de estado gráfico

MÉTODOS

$egs = PDF::API2::Resource::ExtGState->new @parámetros
Devuelve un nuevo objeto extgstate (llamado desde $pdf->egstate).

$egs->strokealpha $alpha
La constante de trazo actual, que especifica el valor de forma constante u opacidad constante que se utilizará para las operaciones de trazo en el modelo de imagen transparente.
$egs->fillalpha $alpha
Igual que strokealpha, pero para operaciones de no trazo.
$egs->blendmode $nombreModoMezcla
$egs->blendmode $objetoFunciónMezcla
El modo de mezcla actual que se utilizará en el modelo de imagen transparente.
$egs->alphaisshape $booleano
La bandera de origen alfa (alfa es forma), que especifica si la máscara suave actual y la constante alfa se interpretarán como valores de forma (verdadero) u opacidad (falso).
$egs->textknockout $booleano
La bandera de anulación de texto, que determina el comportamiento de los glifos superpuestos dentro de un objeto de texto en el modelo de imagen transparente.
$egs->transparency $t
La transparencia gráfica, donde 0 es completamente opaco y 1 es completamente transparente. Este es un método de conveniencia que establece los valores apropiados para strokealpha y fillalpha.
$egs->opacity $op
La opacidad gráfica, donde 1 es completamente opaco y 0 es completamente transparente. Este es un método de conveniencia que establece los valores apropiados para strokealpha y fillalpha.
