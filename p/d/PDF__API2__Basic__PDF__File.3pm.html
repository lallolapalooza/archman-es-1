PDF::API2::Basic::PDF::File(3) Documentación de usuarios contribuidos en Perl PDF::API2::Basic::PDF::File(3)

NOMBRE

PDF::API2::Basic::PDF::File - Acceso al archivo PDF de nivel básico

SINTAXIS

$p = PDF::API2::Basic::PDF::File->open("filename.pdf", 1);
$p->new_obj($obj_ref);
$p->free_obj($obj_ref);
$p->append_file;
$p->close_file;
$p->release;       # ¡IMPORTANTE!

DESCRIPCIÓN

Esta clase mantiene el aspecto de directorio de un archivo PDF. Hay dos partes en el directorio: el directorio principal, que es el padre de todos los objetos, y una cadena de tablas de referencias cruzadas y diccionarios de tráiler correspondientes, comenzando con el directorio principal.

VARIABLES DE INSTANCIA

Dentro de esta jerarquía de clase, en lugar de hacer todo accesible a través de métodos, lo cual sería un gran trabajo, hay varias variables de instancia accesibles a través de referencias de diccionario. Para distinguir las variables de instancia de las variables de contenido (que pueden provenir del propio contenido del PDF), cada una de estas variables comenzará con un espacio.

Las variables que no empiezan con un espacio reflejan elementos de un diccionario PDF. En el caso de PDF::API2::Basic::PDF::File, los elementos reflejan los de un diccionario de tráiler.

Dado que algunas variables no están diseñadas para ser accedidas por usuarios, se marcan en la documentación con (R) para indicar que esta entrada solo debe usarse como información de solo lectura. (P) indica que la información es privada y no está diseñada para uso del usuario, pero se incluye en la documentación para garantizar que nadie intente usarla.

newroot
Esta variable permite crear una nueva entrada raíz para que aparezca en el diccionario de tráiler, que se genera cuando se escribe o se añade el archivo. Si deseas sobrescribir el elemento raíz del diccionario, usa esta entrada para indicar que no pierdas el elemento raíz actual. Ten en cuenta que newroot debe apuntar a un objeto de nivel PDF, no solo a un diccionario sin estado de objeto.
INFILE (R)
Contiene el manejador de archivo utilizado para leer esta información en este directorio PDF. Es un objeto IO.
fname (R)
Este es el nombre de archivo que se refleja en INFILE, o el objeto IO original que se pasó.
update (R)
Indica que el archivo leído se ha abierto para actualizar y que, en algún momento, se puede llamar a $p->appendfile() para actualizar el archivo con los cambios realizados en la representación en memoria.
maxobj (R)
Contiene el número de objeto más pequeño disponible por encima de cualquiera que haya aparecido en el archivo hasta ahora.
outlist (P)
Esta es una lista de Objind que se van a mostrar cuando se active appendfile o outfile.
firstfree (P)
Contiene el primer objeto libre en la lista de objetos libres. Los objetos libres se eliminan del frente de la lista y se añaden al final.
lastfree (P)
Contiene el último objeto libre en la lista de objetos libres. Puede ser el mismo que el firstfree si solo hay un objeto libre.
objcache (P)
Cada objeto se almacena en la caché para garantizar que un sistema solo tenga una instancia de cada objeto. En efecto, la clase objind actúa como una clase contenedora tipo clase para almacenar la estructura de objetos PDF, y sería inútil si hubiera varias ubicaciones idénticas flotando por un sistema.
epos (P)
La ubicación final del archivo leído.

Cada diccionario de tráiler contiene varias variables de instancia privadas que guardan la cadena de referencias.

loc (P)
Contiene la ubicación del inicio de la tabla de referencias cruzadas que precede al tráiler.
xref (P)
Contiene un array anónimo de cada entrada de la tabla de referencias cruzadas.
prev (P)
Un puntero a la tabla anterior. Ten en cuenta que esto difiere de la entrada Prev, que contiene la ubicación de la tabla de referencias cruzadas anterior.

MÉTODOS

PDF::API2::Basic::PDF::File->new

Crea un nuevo objeto de archivo vacío que pueda actuar como contenedor para otros objetos PDF. Como no tiene un archivo asociado, se asume que el objeto se creó en preparación para crear un nuevo archivo PDF.

$p = PDF::API2::Basic::PDF::File->open($filename, $update)

Abre el archivo y lee todos los tráilers y tablas de referencias cruzadas para construir un directorio completo de objetos.

$update indica si el archivo se abre para actualización y edición, o simplemente para lectura.

$filename puede ser un objeto IO.

$p->version($version)

Obtiene/define la versión del PDF (ejemplo: 1.4).

$version = $p->header_version($version)

Obtiene/define la versión del PDF guardada en el encabezado del archivo.

$version = $p->trailer_version($version)

Obtiene/define la versión del PDF guardada en el catálogo del documento.

$prev_version = $p->require_version($version)

Asegura que la versión del PDF sea al menos $version.

$p->release()

Libera toda la memoria utilizada por el documento PDF y todos sus componentes. Después de llamar a este método, no esperes que quede nada en el objeto "PDF::API2::Basic::PDF::File" (así que si necesitas guardar, hazlo antes de llamar a este método).

NOTA, es importante llamar a este método en cualquier objeto "PDF::API2::Basic::PDF::File" al desecharlo y liberar su memoria. Internamente, los archivos PDF tienen una gran cantidad de referencias cruzadas, lo que causa referencias circulares en las estructuras internas. Llamar a release() fuerza una limpieza forzada de las estructuras, liberando toda la memoria. Incluso si has llamado a este método, no esperes poder hacer nada más con el objeto "PDF::API2::Basic::PDF::File"; no tendrá estado interno alguno.

$p->append_file()

Añade los objetos para la salida al archivo y luego añade la tabla adecuada.

$p->out_file($fname)

Escribe un archivo PDF a un archivo con el nombre dado según la lista actual de objetos para la salida. Crea el diccionario de tráiler basándose en la información en $self.

$fname puede ser un objeto IO;

$p->create_file($fname)

Crea un nuevo archivo de salida (sin verificar si ya hay un archivo abierto) con el nombre u objeto IO dado. No

$p->new_page($dict)

Creates a new page object, appending it to the internal list of pages, and returns a new page object.

If $dict is provided, it's used as the page dictionary.

$p->get_page($n)

Returns the nth page object (1-based index).

$p->pages()

Returns an array of all page objects.

$p->open_file($fname)

Opens the given filename for output. This will overwrite any existing file. It sets up the internal file handle and writes the PDF header.

It is very important that $p->{' version'} is set correctly before calling this function.

$p->clone_file($fname)

Creates a copy of the input file at the specified filename and sets it as the output file for future writes. A file handle may be passed instead of a filename.

$p->close_file

Closes up the open file for output by outputting the trailer etc.

($value, $str) = $p->readval($str, %opts)

Reads a PDF value from the current position in the file. If $str is too short then read some more from the current location in the file until the whole object is read. This is a recursive call which may slurp in a whole big stream (unprocessed).

Returns the recursive data structure read and also the current $str that has been read from the file.

$ref = $p->read_obj($objind, %opts)

Given an indirect object reference, locate it and read the object returning the read in object.

$ref = $p->read_objnum($num, $gen, %opts)

Returns a fully read object of given number and generation in this file

$objind = $p->new_obj($obj)

Creates a new, free object reference based on free space in the cross reference chain. If nothing free then thinks up a new number. If $obj then turns that object into this new object rather than returning a new object.

$p->out_obj($objind)

Indicates that the given object reference should appear in the output xref table whether with data or freed.

$p->free_obj($objind)

Marks an object reference for output as being freed.

$p->remove_obj($objind)

Removes the object from all places where we might remember it

$p->ship_out(@objects)

Ships the given objects (or all objects for output if @objects is empty) to the currently open output file (assuming there is one). Freed objects are not shipped, and once an object is shipped it is switched such that this file becomes its source and it will not be shipped again unless out_obj is called again. Notice that a shipped out object can be re-output or even freed, but that it will not cause the data already output to be changed.

$p->copy($outpdf, \&filter)

Iterates over every object in the file reading the object, calling filter with the object and outputting the result. if filter is not defined, then just copies input to output.

MÉTODOS Y FUNCIONES PRIVADAS

Los siguientes métodos y funciones se consideran privados de esta clase. Esto no significa que no puedas usarlos si tienes una necesidad, solo que no están realmente diseñados para los usuarios de esta clase.

$offset = $p->locate_obj($num, $gen)

Devuelve un desplazamiento de archivo al objeto solicitado siguiendo la cadena de tablas de referencias cruzadas hasta que encuentra la que deseas.

update($fh, $str, $instream)

Sigue leyendo $fh en busca de más datos para asegurar que $str tenga al menos una línea completa para que "readval" funcione. En este punto, también aprovechamos para ignorar comentarios.

$objind = $p->test_obj($num, $gen)

Prueba la caché para ver si una referencia de objeto (que puede o no haber sido obtenida con getobj()) ha sido cacheada. La devuelve si es así.

$p->add_obj($objind)

Añade el objeto dado a la caché interna de objetos.

$tdict = $p->readxrtr($xpos)

Función recursiva que lee las tablas de referencias cruzadas y de remolque en secuencia hasta que no quedan más.

Devuelve un diccionario correspondiente a la cadena de remolque. Cada remolque también incluye la tabla de referencias cruzadas correspondiente.

La estructura del elemento privado xref en un diccionario de remolque es un hash anónimo de elementos de referencia cruzada por número de objeto. Cada elemento consta de un array de 3 elementos correspondientes a los tres elementos leídos [ubicación, número de generación, libre o usado]. Consulte la especificación de PDF para obtener detalles.

$p->out_trailer($tdict)

Genera el cuerpo y el remolque de un archivo PDF generando todos los objetos en la 'outlist' y luego generando una tabla xref para esos objetos y cualquier objeto liberado. Luego genera el diccionario de remolque y el código de remolque.

PDF::API2::Basic::PDF::File->_new

Crea un objeto de archivo PDF muy vacío (utilizado por new y open)
