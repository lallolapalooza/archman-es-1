PDF::API2::Basic::PDF::Filter(3) Documentación de Perl aportada por el usuario PDF::API2::Basic::PDF::Filter(3)

NOMBRE

PDF::API2::Basic::PDF::Filter - Superclase abstracta para filtros de flujo PDF

SINOPSIS

$f = PDF::API2::Basic::PDF::Filter->new;
$str = $f->outfilt($str, 1);
print OUTFILE $str;
while (read(INFILE, $dat, 4096))
{ $store .= $f->infilt($dat, 0); }
$store .= $f->infilt("", 1);

DESCRIPCIÓN

Un objeto Filter contiene información de estado para el proceso de salida y entrada de datos a través del filtro. La información de estado exacta almacenada depende del filtro particular y puede variar desde nada hasta objetos completos creados y destruidos.

Cada filtro almacena información de estado diferente para entrada y salida, y por lo tanto puede manejar un proceso de filtrado de entrada y un proceso de filtrado de salida al mismo tiempo.

MÉTODOS

PDF::API2::Basic::PDF::Filter->new

Crea un nuevo objeto de filtro con información de estado vacía, listo para procesar datos tanto de entrada como de salida.

$dat = $f->infilt($str, $isend)

Filtra los datos de salida a entrada. Nótese que $isend == 0 implica que hay más datos por venir y, por lo tanto, $f puede contener información de estado (generalmente debido al punto de interrupción de $str que no es limpio). Las llamadas subsiguientes incorporarán esta información de estado almacenada.

$isend == 1 implica que no habrá más datos a continuación. El estado final de $f será que la información de estado esté vacía. Es más probable que los mensajes de error ocurran aquí, ya que si hay información de estado requerida que deba ser almacenada después de estos datos, eso implicaría un error en los datos.

$str = $f->outfilt($dat, $isend)

Filtra los datos almacenados listos para la salida. Paralelo a "infilt".
