NOMBRE

PDF::Builder::Resource::XObject::Image::GIF - Rutinas de soporte para la biblioteca de imágenes GIF

Hereda de PDF::Builder::Resource::XObject::Image

Historial

Especificación GIF89a: https://www.w3.org/Graphics/GIF/spec-gif89a.txt

Una descripción bastante completa del formato GIF se puede encontrar en http://giflib.sourceforge.net/whatsinagif/bits_and_bytes.html.

Código originalmente de PDF::Create, PDF::Image::GIFImage - Soporte de imágenes GIF Autor: Michael Gross <mdgrosse@sboxtugraz.at>

Formatos Soportados

Se soportan las cabeceras GIF87a y GIF89a. El bloque de Imagen (x2C) está soportado.

El bloque de Extensión de Control Gráfico (x21 + xF9) está soportado para el control de transparencia. La animación no está soportada.

Los bloques de Extensión de Comentario (x21 + xFE), Extensión de Texto Plano (x21 + x01) y Extensión de Aplicación (x21 + xFF) se leen, pero se ignoran. Cualquier otro bloque o bloque de Extensión se marcará como un error.

Si se proporcionan, las Tablas de Color Locales se leen y se utilizan, supuestamente permitiendo más de 256 colores en general en la imagen (a pesar de la profundidad de la tabla de color de 8 bits).

Opciones

notrans
Cuando se define y no es 0, "notrans" suprime el uso de transparencia si está definida en el archivo GIF.
name => 'cadena'
Este es el nombre que se puede dar al objeto de imagen GIF. El valor por defecto es Gxnnnn.
multi
Cuando se define y no es 0, "multi" continúa procesando después del final del primer Bloque de Imagen. El comportamiento antiguo, que es ahora el valor por defecto, es detener el procesamiento al final del primer Bloque de Imagen.

MÉTODOS

new

PDF::Builder::Resource::XObject::Image::GIF->new()
Crea un objeto de imagen a partir de un archivo de entrada GIF. ¡Recuerda que esto debe ser invocado a través del método de Builder.pm!
