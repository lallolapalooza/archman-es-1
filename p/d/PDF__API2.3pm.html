NOMBRE

PDF::API2 - Crear, modificar y examinar archivos PDF

SINOPSIS

use PDF::API2;
# Crear un archivo PDF en blanco
$pdf = PDF::API2->new();
# Abrir un archivo PDF existente
$pdf = PDF::API2->open('alguno.pdf');
# Añadir una página en blanco
$page = $pdf->page();
# Obtener una página existente
$page = $pdf->open_page($numero_pagina);
# Establecer el tamaño de la página
$page->size('Letter');
# Añadir una fuente integrada al PDF
$font = $pdf->font('Helvetica-Bold');
# Añadir una fuente TrueType externa al PDF
$font = $pdf->font('/ruta/a/fuente.ttf');
# Añadir texto a la página
$text = $page->text();
$text->font($font, 20);
$text->position(200, 700);
$text->text('¡Hola Mundo!');
# Guardar el PDF
$pdf->save('/ruta/a/nuevo.pdf');

MÉTODOS DE ENTRADA/SALIDA

new

my $pdf = PDF::API2->new(%opciones);

Crea un nuevo PDF.

Las siguientes opciones están disponibles:

  • file

    Si va a guardar el PDF en disco y ya conoce el nombre del archivo, puede incluirlo aquí para abrir el archivo para escritura inmediatamente. "file" también puede ser un manejador de archivo.

  • compress

    Por defecto, la mayor parte del PDF se comprimirá para ahorrar espacio. Para desactivar esto (generalmente útil solo para pruebas o depuración), establezca "compress" en 0.

open

my $pdf = PDF::API2->open('/ruta/a/archivo.pdf', %opciones);

Abre un archivo PDF existente.

La siguiente opción está disponible:

•
compress

Por defecto, la mayor parte del PDF se comprimirá para ahorrar espacio. Para desactivar esto (generalmente útil solo para pruebas o depuración), establezca "compress" en 0.

save

$pdf->save('/ruta/a/archivo.pdf');

Escribe el PDF en disco y cierra el archivo. El nombre del archivo es opcional si se especificó al abrir o crear el PDF.

Como efecto secundario, la estructura del documento se elimina de la memoria al guardar el archivo, por lo que ya no será utilizable.

close

$pdf->close();

Cierra un archivo abierto (si es relevante) y elimina la estructura del objeto de la memoria.

PDF::API2 contiene referencias circulares, por lo que esta llamada es necesaria en procesos de larga ejecución para evitar quedarse sin memoria.

Esto se llamará automáticamente cuando guarde o convierta en cadena un PDF. Solo debería necesitar llamarlo explícitamente si está leyendo archivos PDF y no escribiéndolos.

from_string

my $pdf = PDF::API2->from_string($cadena_pdf, %opciones);

Lee un documento PDF contenido en una cadena.

La siguiente opción está disponible:

•
compress

Por defecto, la mayor parte del PDF se comprimirá para ahorrar espacio. Para desactivar esto (generalmente útil solo para pruebas o depuración), establezca "compress" en 0.

to_string

my $cadena = $pdf->to_string();

Devuelve el documento PDF como una cadena.

Como efecto secundario, la estructura del documento se elimina de la memoria al crear la cadena, por lo que ya no será utilizable.

MÉTODOS DE METADATOS

title

$titulo = $pdf->title();
$pdf = $pdf->title($titulo);

Obtener/establecer/borrar el título del documento.

author

$autor = $pdf->author();
$pdf = $pdf->author($autor);

Obtener/establecer/borrar el nombre de la persona que creó el documento.

subject

$asunto = $pdf->subject();
$pdf = $pdf->subject($asunto);

Obtener/establecer/borrar el tema del documento.

keywords

$palabras_clave = $pdf->keywords();
$pdf = $pdf->keywords($palabras_clave);

Obtener/establecer/borrar una cadena de palabras clave separadas por espacios asociada al documento.

creator

$creador = $pdf->creator();
$pdf = $pdf->creator($creador);

Obtener/establecer/borrar el nombre del producto que creó el documento antes de su conversión a PDF.

producer

$productor = $pdf->producer();
$pdf = $pdf->producer($productor);

Obtener/establecer/borrar el nombre del producto que convirtió el documento original a PDF.

PDF::API2 rellena este campo al crear un PDF.

created

$fecha = $pdf->created();
$pdf = $pdf->created($fecha);

Obtener/establecer/borrar la fecha de creación del documento.

El formato de la fecha es "D:AAAAMMDDHHMMSSOHH'mm", donde "D:" es un prefijo estático que identifica la cadena como una fecha PDF. La fecha puede truncarse en cualquier punto después del año. "O" es uno de "+", "-" o "Z", con las siguientes "HH'mm" representando un desplazamiento desde UTC.

Al establecer la fecha, se añadirá automáticamente "D:" si se omite.

modified

$fecha = $pdf->modified();
$pdf = $pdf->modified($fecha);

Obtener/establecer/borrar la fecha de modificación del documento. El formato de la fecha es como se describe en "created" anteriormente.

info_metadata

# Obtener todas las claves y valores
%info = $pdf->info_metadata();
# Obtener el valor de una clave
$valor = $pdf->info_metadata($clave);
# Establecer el valor de una clave
$pdf = $pdf->info_metadata($clave, $valor);

Obtener/establecer/borrar una clave en el diccionario de información del documento. Las claves estándar (título, autor, etc.) tienen sus propios accesores, por lo que esto está destinado principalmente a interactuar con metadatos personalizados.

Pase "undef" como valor para eliminar la clave del diccionario.

xml_metadata

$xml = $pdf->xml_metadata();
$pdf = $pdf->xml_metadata($xml);

Obtener/establecer el flujo de metadatos XML del documento.

version

$version = $pdf->version($nueva_version);

Obtener/establecer la versión del PDF (por ejemplo, 1.4).

is_encrypted

$booleano = $pdf->is_encrypted();

Devuelve verdadero si el PDF abierto está cifrado.

MÉTODOS DE FUNCIONALIDAD INTERACTIVA

outline

$esquema = $pdf->outline();

Crea (si es necesario) y devuelve el árbol de esquema del documento, que también se conoce como sus marcadores o tabla de contenido, dependiendo del lector de PDF.

Para examinar o modificar el árbol de esquema, consulte PDF::API2::Outline.

open_action

$pdf = $pdf->open_action($pagina, $ubicacion, @args);

COMPATIBILIDAD HACIA ATRÁS

Las siguientes opciones se implementaron para la compatibilidad hacia atrás.

  • "-bits": especifica el formato del código de barras "code2of5" en lugar de "code128".

  • "-mils": especifica el ancho de la barra en milésimas de pulgada. Esto requiere una conversión de milésimas de pulgada a puntos. La documentación de "bar_width" tiene un ejemplo de código para realizar la conversión.

  • "-ean": especifica "ean128" como formato de código de barras en lugar de "code128".
