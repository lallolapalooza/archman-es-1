Nombre

PDF::Builder::Anotación - Añadir anotaciones a un PDF

Hereda de PDF::Builder::Basic::PDF::Dict

Sintaxis

my $pdf = PDF::Builder->new();
my $font = $pdf->font('Helvetica');
my $page1 = $pdf->page();
my $page2 = $pdf->page();
my $content = $page1->text();
my $message = 'Ir a página 2';
my $size = 18;
$content->distance(1 * 72, 9 * 72);
$content->font($font, $size);
$content->text($message);
my $annotation = $page1->annotation();
my $width = $content->text_width($message);
$annotation->rect(1 * 72, 9 * 72, 1 * 72 + $width, 9 * 72 + $size);
$annotation->link($page2);
$pdf->save('sample.pdf');

Métodos

Nota: El manejo de anotaciones puede variar de lector a lector. El conjunto de iconos disponible puede ser mayor o menor que lo mostrado aquí, y algunos lectores activan una anotación al hacer clic con un solo botón, mientras que otros requieren un doble clic. No todas las funciones mencionadas aquí estarán disponibles en todos los lectores de PDF.

new

$annotation = PDF::Builder::Anotación->new()
Devuelve un objeto de anotación (llamado desde $page->annotation()).

Tipos de anotación

link

$annotation->link($page, %opts)
Define la anotación como un enlace a una página con número $page (dentro de este documento) y opciones %opts (rect, borde, color, fit: ver descripciones a continuación).

Nota que $page no es simplemente el número de página, sino un estructura de página como "$pdf->openpage(page_number)", o un destino nombrado definido de otro lugar.

pdf, pdfile, pdf_file

$annotation->pdf($pdffile, $page_number, %opts)
Define la anotación como un archivo PDF con ruta de archivo $pdffile, en la página $page_number, y opciones %opts (rect, borde, color, fit: ver descripciones a continuación). Esta difiere de la llamada "link" en que el destino se encuentra en un archivo PDF diferente, no en este documento.

$page_number es el número de página físico, comenzando en 1: 1, 2,...

Alternativas: "pdfile" y "pdf_file"

Originalmente este método se llamaba "pdfile", y luego "pdf_file", pero un cambio reciente en PDF::API2 lo ha convertido en "pdf". Para compatibilidad, se ha cambiado a "pdf", con "pdfile" y "pdf_file" aún disponibles como alias.

lanzamiento, archivo

$annotation->launch($file, %opts)
Define la anotación como un archivo de lanzamiento con ruta de archivo $file (un archivo local) y opciones %opts (rect, borde, color: ver descripciones a continuación). La forma en que el archivo se muestra depende del sistema operativo, el tipo de archivo y la configuración local o mapeo.

Alternativa: "archivo"

Originalmente este método se llamaba "archivo", pero un cambio reciente en PDF::API2 lo ha convertido en "lanzamiento". Para compatibilidad, se ha cambiado a "lanzamiento", con "archivo" aún disponibles como alias.

URI, URL

$annotation->uri($url, %opts)
Define la anotación como un enlace a una URL con URL $url y opciones %opts (rect, borde, color: ver descripciones a continuación). Esta página se abre generalmente en un navegador y puede ser remota.

Alternativa: "URL"

Originalmente este método se llamaba "URL", pero un cambio reciente en PDF::API2 lo ha convertido en "URI". Para compatibilidad, se ha cambiado a "URI", con "URL" aún disponibles como alias.

texto

$annotation->text($text, %opts)
Define la anotación como un nota de texto con contenido string $text y opciones %opts (rect, color, texto, abrir: ver descripciones a continuación). El $text puede incluir nuevos límites \n para múltiples líneas. La opción "border" se ignora, ya que se usa un ícono.

La opción "text" es el texto del popup, no confundir con el principal $text.

El ícono aparece en el rincón superior izquierdo del rectángulo de selección "rect", y su área clicable está fija por el ícono (no es igual al rectángulo). El tamaño del ícono es fijo, y su color se establece con "color".\n

Opciones adicionales:

icon => nombre_string
icon => referencia
Especifique el ícono a usar. El por defecto es específico de lectores (generalmente "Nota"), y otros pueden definirse por el lector. Las alternativas son "Comentario", "Clave", "Ayuda", "NuevaLínea", "Línea" y "Insertar" y están disponibles en todos los lectores de PDF. Debe tener en cuenta que el nombre mayúsculas debe coincidir exactamente. El ícono tiene tamaño fijo. Cualquier entrada AP sobre el ícono sobrescribirá la configuración del ícono.
opacity => valor
Define la opacidad (sin transparencia, opacidad) del ícono. El valor rango de 0.0 (transparente) a 1.0 (opaco), aplica a ambos el borde y el color del ícono. El valor por defecto es 1.0.

marca

$annotation->marca($text, $PointList, $highlight, %opts)
Define la anotación como un nota de texto con contenido string $text y opciones %opts (color, texto, abrir, opacidad: ver descripciones a continuación). El $text puede incluir nuevos límites \n para múltiples líneas.

"text" es el texto del popup, no confundir con el principal $text.

No hay ícono. En su lugar, el texto anotado por $PointList se resalta con una de las cuatro formas permitidas por $highlight.

$PointList => [ 8n números ]
Se dan uno o más conjuntos de coordenadas numéricas para definir un cuadrilátero (generalmente un rectángulo) alrededor del texto para resaltar y seleccionable (clickable, para abrir el texto de la anotación). Estas son cuatro conjuntos de "x,y" coordenadas, dadas (para texto de izquierda a derecha) como el límite superior izquierdo a superior derecho, seguido por el límite inferior izquierdo a inferior derecho. Nota: Esto es diferente de lo que se documenta erroneamente en la especificación del PDF! Es importante que las coordenadas se proporcionen en este orden.
$highlight => 'string'
Las siguientes efectos de resaltado son permitidos. El "string" debe estar escrito y en mayúsculas exactamente como se especifica:
Highlight
El texto se resalta con un fondo opaco de color sólido.
Outline
El texto se resalta con un borde de color sólido.
Push
El texto se resalta con un borde y un fondo de color sólido.
Invert
Los colores del texto se invierten.

rect

$annotation->rect($x1, $y1, $x2, $y2)
Establece el rectángulo de visualización de la anotación. Debe llamarse *antes* de llamar a link, pdf, pdfile, pdf_file, launch, URI, URL o text. El orden es x1,y1,x2,y2, donde (x1,y1) es la esquina inferior izquierda y (x2,y2) es la esquina superior derecha.

border

$annotation->border($w, $style)
Establece el borde de la anotación. $w es el ancho del borde, y $style es un estilo de borde. Los estilos soportados son "solid", "dashed", "underline", y "dotted". El valor por defecto es "solid".

color

$annotation->color($red, $green, $blue)
Establece el color de la anotación, incluyendo el borde o el fondo, si se aplica. Se especifican los valores RGB (0-255). El valor por defecto es negro (0,0,0).

fit

$annotation->fit($fit_type)
Aplica a las anotaciones de enlace de página (interna y externa). Especifica cómo la página de destino debe ser mostrada. Los tipos disponibles son "Fit", "FitH", "FitV", "FitR", "FitB", "FitBH", y "FitBV". Consulte la documentación de PDF para obtener más detalles.

text

$annotation->text($popup_text)
Establece el texto que aparece en el popup de la anotación. Para las anotaciones de tipo text, se debe usar el argumento principal de la función para el texto del popup.

abierto

$annotation->open($boolean)
Controla si la anotación debe aparecer abierta (visible) por defecto cuando el PDF se abre. Por defecto es falsa (cerrada).

VER TAMBIÉN

PDF::Builder, PDF::Builder::Basic::PDF::Dict

Resaltar
El efecto de un marcador translúcido "resaltador".
Ondulado
El efecto es un subrayado escrito de forma "ondulada".
Tachado
El texto está tachado con una línea recta.
Subrayado
El texto está marcado con un subrayado recto.
color => array de valores
Si no se proporciona "color" (un array de números en el rango 0.0-1.0), se utilizará gris medio por defecto. Los colores con nombre no son compatibles en este momento.
opacidad => valor
Define la opacidad (no transparencia, opacidad) del icono. Este valor varía de 0.0 (transparente) a 1.0 (completamente opaco), y se aplica tanto al contorno como al color de relleno. El valor por defecto es 1.0.

película

$anotacion->película($archivo, $tipoContenido, %opts)
Define la anotación como una película de $archivo con tipo de contenido (MIME) $tipoContenido y opciones %opts (rectángulo, borde, color, texto: ver descripciones a continuación).

El rectángulo "rect" también sirve como área donde se reproduce la película, por lo que debe tener un tamaño y una relación de aspecto utilizables. No utiliza un reproductor emergente separado. Se sabe que reproduce archivos .avi y .wav; otros no han sido probados. Usando Adobe Reader, no reproduce archivos .mpg (tipo no soportado). Probablemente se necesite más trabajo en este método de anotación.

adjunto_archivo

$anotacion->adjunto_archivo($archivo, %opts)
Define la anotación como un adjunto de archivo con el archivo $archivo y opciones %opts (rectángulo, color: ver descripciones a continuación). Tenga en cuenta que "color" se aplica al color de relleno del icono, no a un contorno de área seleccionable. El icono se redimensiona (incluyendo cambios en la relación de aspecto) basándose en el rectángulo seleccionable proporcionado por "rect", ¡así que preste atención a las dimensiones de su rectángulo!

El archivo, junto con su nombre, se incrusta en el documento PDF y puede ser extraído para su visualización con el visor adecuado.

Esto difiere del método "archivo" en que "archivo" busca y lanza un archivo ya existente en la máquina del lector, mientras que "adjunto_archivo" incrusta el archivo en el PDF y lo pone a disposición en la máquina del lector para acciones que el usuario elija.

Nota 1: algunos lectores solo pueden permitir una acción de "abrir" y también pueden restringir los tipos de archivo (extensiones) que se manejarán. Esto puede configurarse en los ajustes de seguridad de su lector.

Nota 2: el nombre de archivo que se muestra (pop-up durante el paso del ratón sobre el rectángulo objetivo) se proporciona con la ruta recortada (solo el nombre del archivo). Si desea que el nombre mostrado coincida exactamente con la ruta que se pasó a la llamada, incluida la ruta, proporcione la opción "sinrecortaruta".

Opciones:

icono => cadena_nombre
icono => referencia
Especifica el icono a utilizar. El valor por defecto depende del lector (normalmente "Chincheta"), y otros pueden ser definidos por el lector. Se supone que "Clip", "Gráfico" y "Etiqueta" también están disponibles en todos los lectores de PDF. Tenga en cuenta que el mayúsculas/minúsculas del nombre debe coincidir exactamente. "Ninguno" es un icono invisible personalizado definido por PDF::Builder. El icono se estira/aplasta para llenar el rectángulo objetivo definido, así que tenga cuidado al definir las dimensiones de "rect". Cualquier entrada de diccionario AP anulará la configuración del icono.

Se puede pasar una referencia a un icono en lugar de un nombre.

opacidad => valor
Define la opacidad (no transparencia, opacidad) del icono. Este valor varía de 0.0 (transparente) a 1.0 (completamente opaco), y se aplica tanto al contorno como al color de relleno. El valor por defecto es 1.0.
sinrecortaruta => 1
Si se proporciona, muestra la ruta completa y el nombre del archivo en el paso del ratón, en lugar de solo el nombre del archivo.
texto => cadena
Una etiqueta de texto para el pop-up (al pasar el ratón) que contiene el nombre del archivo.

Tenga en cuenta que, si bien PDF permite diferentes especificaciones (rutas) para versiones DOS/Windows, Mac y Unix (incluido Linux) de un archivo, y copias de diferentes formatos para incrustar, en este momento PDF::Builder solo permite incrustar un solo archivo (el formato de su elección). Si hay demanda de los usuarios para referenciar y/o incrustar múltiples formatos de archivo, podríamos considerar proporcionarlo, aunque las rutas de versiones de SO separadas pueden considerarse obsoletas.

Rutinas internas y opciones comunes

rectángulo

$anotacion->rectángulo($llx,$lly, $urx,$ury)
Establece el rectángulo (área de clic activa) de la anotación, proporcionado por la opción 'rectángulo'. Este es cualquier par de esquinas diagonalmente opuestas del rectángulo.

El área de clic por defecto es el propio icono.

Opción de definición. Tenga en cuenta que esta "opción" es en realidad obligatoria.

rectángulo => [LLx, LLy, URx, URy]
Establece el rectángulo de la anotación en "[LLx,LLy]" a "[URx,URy]" (coordenadas inferior izquierda y superior derecha). LL a UR es lo habitual, pero se permite cualquier diagonal.

borde

$anotacion->borde(@b)
Establece el estilo de borde de la anotación, si es aplicable, según lo proporcionado por la opción de borde. Hay tres entradas en el array: radios de esquina horizontal y vertical, y anchura del borde. Una cuarta entrada opcional (descrita a continuación) puede usarse para una línea discontinua o punteada.

Se utiliza un borde en anotaciones donde se introduce texto o algún otro material, y se define un rectángulo clickeable sobre él (rectángulo). No se muestra un borde cuando se está utilizando un icono para marcar el área clickeable.

Un Lector de PDF normalmente utiliza por defecto [0 0 1] (línea sólida de anchura 1, con esquinas rectas) si no se especifica ningún borde (). Manteniendo la compatibilidad con la práctica de larga data de PDF::API2, PDF::Builder utiliza por defecto ningún borde visible "[0 0 0]" (línea sólida de anchura 0, y por lo tanto invisible).

Opción de definición:

borde => [CRh, CRv, A]
borde => [CRh, CRv, A, [encendido, apagado...]]
Tenga en cuenta que los corchetes [ y ] están literalmente ahí, indicando un vector o array de valores. ¡No indican valores opcionales!

Establece el estilo de borde de la anotación de radios de esquina horizontal y vertical "CRh" y "CRv" (valor 0 para esquinas rectas) y anchura "A" (valor 0 para ningún borde). El valor por defecto de PDF::Builder es sin borde (mientras que un Lector de PDF típicamente usa por defecto sin borde ([0 0 0]), si no se proporciona ninguna entrada /Borde). Opcionalmente, se puede proporcionar un patrón de guiones (longitud "encendido", longitud "apagado", como uno o más pares). El valor por defecto es una línea sólida.

El vector de borde parece ignorar las dos primeras configuraciones (radios de esquina), pero el grosor de la línea funciona, en lectores básicos. Los radios de esquina pueden funcionar en algunos otros lectores.

contenido

$anotacion->contenido(@lineas)
Establece el contenido de texto de la anotación de texto(). Esta es una cadena de texto o un array de cadenas.

abierto

$anotacion->abierto($bool)
Muestra la anotación de texto() abierta o cerrada, si es aplicable.

Ambas son editables; la forma "abierta" muestra la página con el área de entrada ya abierta para edición, mientras que "cerrada" tiene que ser hacer clic en ella para editarla.

Opción de definición:

abierto => booleano
Si es verdadero (1), la anotación se marcará como inicialmente "abierta". Si es falso (0), o no se proporciona la opción, la anotación estará inicialmente "cerrada".

destino

$anotacion->destino($pagina, I<configuracion_ajuste>)
Para ciertos tipos de anotación ("enlace" o "archivo_pdf"), la configuracion_ajuste especifica cómo se debe ajustar el contenido de la página $pagina a la ventana, preservando su relación de aspecto. Estas configuraciones de ajuste se enumeran en "Opciones de Ajuste de Página" en PDF::Builder::Docs.

"xyz" es la configuración de ajuste por defecto, con posición (izquierda y superior) y zoom iguales a los de la página llamante ([indefinido, indefinido, indefinido]).

$anotacion->destino($nombre)
Conecta la Anotación a una "Destino Nombrado" definida en otro lugar, incluyendo el deseado ajuste opcional (por defecto: xyz indefinido*3).

Color

$anotacion->Color(@color)
Establece el color de relleno del icono. El color es un array de 1, 3 o 4 números, cada uno en el rango de 0.0 a 1.0. Si se da 1 número, es el valor de escala de grises (0 = negro a 1 = blanco). Si se dan 3 números, es un valor de color RGB. Si se dan 4 números, es un valor de color CMYK. Actualmente, los colores con nombre (cadenas) no se manejan.

Para anotaciones de enlace y URL, este es el color del borde del rectángulo (borde proporcionado con una anchura de al menos 1).

Si se proporciona una longitud de array o un valor numérico inválido, se utilizará un valor de gris medio ([0.5]), sin ningún mensaje. Si no se proporciona ningún color, el color de relleno habitual es negro.

NAME

PDF::Builder::Annotation - Anotaciones en un documento PDF

SYNOPSIS

 use PDF::Builder;

 my $pdf = PDF::Builder->new;
 $pdf->font('Times-Roman' => 'Times');
 $pdf->add_page;
 $pdf->text(100, 750 => 'Una anotación aquí:');

 # Anotación de texto
 $pdf->annotation(100, 700 => {
  text => 'Esta es una anotación de ejemplo.',
  color => [1, 0, 0], # Rojo
 });

 # Anotación de enlace
 $pdf->annotation(100, 650 => {
  url => 'https://metacpan.org/pod/PDF::Builder',
 });

 # Anotación de cuadro
 $pdf->annotation(100, 600 => {
  box => [100, 600, 200, 700], # x1, y1, x2, y2
  color => [0, 0, 1], # Azul
 });

 $pdf->save('annotation_example.pdf');

METHODS

annotation(x, y => \%hash)
Crea una anotación en la página actual en las coordenadas x, y. El hash \%hash especifica las propiedades de la anotación. Las claves admitidas son:
box => [ $x1, $y1, $x2, $y2 ]
Define el rectángulo de la anotación. Si no se proporciona, la anotación se vinculará a la posición x, y especificada en la llamada del método.
color => $color_arrayref

Establece el color de la anotación. Los colores nombrados (por ejemplo, 'black') no están disponibles en este momento.

color => [ ] o no 1, 3, o 4 números 0.0-1.0
Si se proporciona un color inválido, se utilizará un gris medio (valor 0.5).
color => [ g ]
Si g está entre 0.0 (negro) y 1.0 (blanco), el color de relleno será gris.
color => [ r, g, b ]
Si r (rojo), g (verde) y b (azul) están entre 0.0 y 1.0, el color de relleno será el color RGB definido. [ 0, 0, 0 ] es negro, [ 1, 1, 0 ] es amarillo, y [ 1, 1, 1 ] es blanco.
color => [ c, m, y, k ]
Si c (rojo), m (magenta), y (amarillo) y k (negro) están entre 0.0 y 1.0, el color de relleno será el color CMYK definido. [ 0, 0, 0, 0 ] es blanco, [ 1, 0, 1, 0 ] es verde, y [ 1, 1, 1, 1 ] es negro.
text => string

Especifique una etiqueta de texto opcional para la anotación. Este texto o comentario solo se mostrará como título en la ventana que contiene el archivo o el texto.

url => string
Define un enlace web para la anotación. La URL debe comenzar con 'http://' o 'https://'.
