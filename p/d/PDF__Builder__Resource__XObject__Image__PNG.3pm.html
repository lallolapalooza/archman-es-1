NOMBRE

PDF::Builder::Resource::XObject::Image::PNG - Rutinas de soporte para la biblioteca de imágenes PNG (usando código Perl puro)

Hereda de PDF::Builder::Resource::XObject::Image

MÉTODOS

new

$res = PDF::Builder::Resource::XObject::Image::PNG->new($pdf, $file, %opts)
Devuelve un objeto de imagen PNG. $pdf es el objeto PDF al que se está añadiendo, $file es el archivo PNG de entrada y el $name opcional del nuevo objeto de imagen padre tiene por defecto PxAAA.

Si el paquete Image::PNG::Libpng está instalado, se utilizará la biblioteca PNG_IPL en lugar de la biblioteca PNG. En tal caso, el uso de la biblioteca PNG puede forzarse mediante la bandera "nouseIPL" (ver documentación de Builder para image_png()).

opts:

'notrans' => 1
Sin transparencia - ignora el chunk tRNS si se proporciona, ignora el canal Alfa si se proporciona.
'name' => 'string'
Este es el nombre que puedes dar al objeto de imagen PNG. El valor por defecto es Pxnnnn.

Recuerda que debes invocar el método image_png de Builder.pm para usar esta funcionalidad.

Tipos PNG soportados

(0) Escala de grises de profundidad de 1, 2, 4 u 8 bits por píxel (2, 4, 16, o 256 niveles de gris). 16 bpp no es compatible actualmente (un PNG con 16 bpp es un error fatal). Se permite transparencia completa (de un valor de gris de 8 bits) a través del chunk tRNS, a menos que la opción notrans especifique que se ignore.
(2) RGB verdadero color de 24 bits con 8 bits por muestra (16.7 millones de colores). 16 bps no es compatible actualmente (un PNG con 16 bps es un error fatal). Se permite transparencia completa (de un valor de color RGB de 3x8 bits) a través del chunk tRNS, a menos que la opción notrans especifique que se ignore.
(3) Color de paleta con 1, 2, 4 u 8 bits por píxel (2, 4, 16 o 256 entradas de tabla de colores/paleta). 16 bpp no es compatible actualmente con PNG o PDF. Se permite transparencia parcial (Alfa de 8 bits) para cada entrada de paleta a través del chunk tRNS, a menos que la opción notrans especifique que se ignore (todas las entradas completamente opacas).
(4) Escala de grises de profundidad de 8 bits por píxel más canal Alfa de 8 bits (256 niveles de gris y 256 niveles de transparencia). 16 bpp no es compatible actualmente (un PNG con 16 bpp es un error fatal). El canal Alfa se ignora si se proporciona la opción notrans. El chunk tRNS no está permitido.
(6) RGB verdadero color de 24 bits con 8 bits por muestra (16.7 millones de colores) más canal Alfa de 8 bits (256 niveles de transparencia). 16 bps no es compatible actualmente (un PNG con 16 bps es un error fatal). El canal Alfa se ignora si se proporciona la opción notrans. El chunk tRNS no está permitido.

En todos los casos, no se implementan 16 bits por muestra. Se devolverá un error fatal si se proporciona una imagen PNG con datos de 16 bps. El código asume el orden de bits estándar "de red" (Big Endian). Las imágenes de visualización entrelazadas (progresivas) no son compatibles. Usa la versión PNG_IPL si necesitas soportar imágenes de 16 bps o entrelazadas.

El chunk de transparencia (tRNS) especificará una entrada de nivel de gris o una entrada RGB para que se trate como transparente (Alfa = 0). Para el color de paleta, se especifican hasta 256 valores Alfa de 8 bits por entrada de paleta (256 niveles de transparencia, de 0 = transparente a 255 = opaco).

Solo se maneja un número limitado de chunks: IHDR, IDAT (internamente), PLTE, tRNS e IEND (internamente). Todos los demás chunks se ignoran en este momento. Se manejarán ciertos filtros y compresiones aplicados a los datos, pero puede haber métodos no soportados.

usesLib

$mode = $png->usesLib()
Devuelve 1 si Image::PNG::Libpng está instalado y se usa, 0 si no está instalado, o -1 si está instalado pero no se usa (opción nouseIPL dada a "image_png").

Precaución: este método solo se puede usar *después* de que se haya creado el objeto de imagen. No puede decirte si Image::PNG::Libpng está disponible antes de usarlo realmente, en caso de que quieras usar alguna funcionalidad disponible solo en PNG_IPL. Consulta la llamada LA_IPL() de PDF::Builder si necesitas saberlo de antemano.
