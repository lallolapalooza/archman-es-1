NOMBRE

PDF::Builder::Resource::Glyphs - Información del archivo uniglyph.txt pre-analizado

SINOPSIS

Esta es una lista de nombres de glifos para muchos puntos Unicode (más de 9000 de ellos). Los datos de este archivo se generan a partir del archivo uniglyph.txt, incluido con PDF::Builder. Si debes cambiar ese archivo, usa _generate para crear nuevos hashes y pega la salida en este archivo.

Los datos en cuestión se consolidan de las especificaciones AGL/WGL4, XML, (X)HTML y SGML.
