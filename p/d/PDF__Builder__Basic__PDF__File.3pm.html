NOMBRE

PDF::Builder::Basic::PDF::File - Contiene los tráilers y las tablas de referencias cruzadas para un archivo PDF

SINOPSIS

$p = PDF::Builder::Basic::PDF::File->open("archivo.pdf", 1);
$p->new_obj($ref_obj);
$p->free_obj($ref_obj);
$p->append_file();
$p->close_file();
$p->release();       # ¡IMPORTANTE!

DESCRIPCIÓN

Esta clase realiza un seguimiento de los aspectos del directorio de un archivo PDF. Hay dos partes en el directorio: el objeto de directorio principal, que es el padre de todos los demás objetos, y una cadena de tablas de referencias cruzadas y diccionarios de tráiler correspondientes, que comienzan con el objeto de directorio principal.

VARIABLES DE INSTANCIA

Dentro de esta jerarquía de clases, en lugar de hacer que todo sea visible a través de métodos, lo que sería mucho trabajo, hay varias variables de instancia a las que se puede acceder mediante referencias a matrices asociativas. Para distinguir las variables de instancia de las variables de contenido (que pueden provenir del contenido del PDF), cada nombre de variable comenzará con un espacio.

Los nombres de variables que no comienzan con un espacio reflejan directamente los elementos de un diccionario PDF. En el caso de un "PDF::Builder::Basic::PDF::File", los elementos reflejan los del diccionario del tráiler.

Dado que algunas variables no están diseñadas para que las accedan los usuarios de la clase, las variables se marcan en la documentación con (R) para indicar que dicha entrada solo debe usarse como información de solo lectura. (P) indica que la información es privada y no está diseñada para el uso del usuario en absoluto, pero se incluye en la documentación para completar y para garantizar que nadie más intente usarla.

newroot
Esta variable permite al usuario crear una nueva entrada raíz que aparecerá en el diccionario del tráiler que se genera cuando se escribe o se anexa el archivo. Si desea anular el elemento raíz en el diccionario que tiene, use esta entrada para indicarlo sin perder la entrada Raíz actual. Tenga en cuenta que newroot debe apuntar a un objeto de nivel PDF y no solo a un diccionario, que no tiene estado de objeto.
INFILE (R)
Contiene el manejador de archivos utilizado para leer esta información en este directorio PDF. Es un objeto IO.
fname (R)
Este es el nombre del archivo que se refleja en INFILE, o el objeto IO original pasado.
update (R)
Esto indica que el archivo leído se ha abierto para actualización y que en algún momento, se puede llamar a "$p->appendfile()" para actualizar el archivo con los cambios realizados en la representación en memoria.
maxobj (R)
Contiene el primer número de objeto utilizable por encima de cualquiera que ya haya aparecido en el archivo hasta el momento.
outlist (P)
Esta es una lista de Objind que se generarán cuando ocurra el próximo appendfile() o outfile().
firstfree (P)
Contiene el primer objeto libre en la lista de objetos libres. Los objetos libres se eliminan del principio de la lista y se añaden al final.
lastfree (P)
Contiene el último objeto libre en la lista de libres. Puede ser el mismo que "firstfree" si solo hay un objeto libre.
objcache (P)
Todos los objetos se mantienen en la caché para garantizar que un sistema solo tenga una ocurrencia de cada objeto. En efecto, la clase objind actúa como una clase contenedora para mantener la estructura del objeto PDF, y sería desafortunado que hubiera dos marcadores idénticos flotando por un sistema.
epos (P)
La ubicación final del archivo leído.

Cada diccionario de tráiler contiene una serie de variables de instancia privadas que mantienen unida la cadena.

loc (P)
Contiene la ubicación del inicio de la tabla de referencias cruzadas que precede al tráiler.
xref (P)
Contiene una matriz anónima de cada entrada de la tabla de referencias cruzadas.
prev (P)
Una referencia a la tabla anterior. Tenga en cuenta que esto difiere de la entrada Prev, que está en PDF, que contiene la ubicación de la tabla de referencias cruzadas anterior.

No hay garantía de que ninguna corrección cambie el PDF a legítimo, ni de que no se encuentren otros problemas más adelante. Hay muchos archivos PDF circulando que, aunque no cumplen con los estándares de Adobe, parecen ser tolerados por los lectores de PDF. Por lo tanto, Builder no fallará en ellos, sino que simplemente comentará su existencia.

NAME

PDF::Builder::Basic::PDF::File - Handles the PDF file object.

SYNOPSIS

  use PDF::Builder::Basic::PDF::File;

  # Create a new PDF object
  $p = PDF::Builder::Basic::PDF::File->new(filename => "out.pdf");

  # Or open an existing PDF
  $p = PDF::Builder::Basic::PDF::File->open(filename => "in.pdf");

  # Set the PDF version
  $p->version(1.3);
  $prev_version = $p->version('1.4');

  # Ensure minimum PDF version
  $p->require_version('1.3');

  # Write out the PDF
  $p->out_file(); # Writes to default filename
  $p->out_file($new_filename);

  # Append to an existing PDF
  $p->append_file(); # Appends to default filename
  $p->append_file($existing_filename);

  # Release memory
  $p->release();

DESCRIPTION

The PDF::Builder::Basic::PDF::File object is the main object for manipulating PDF files. It is responsible for reading and writing PDF files, and for managing the objects that make up the PDF document.

METHODS

new

$p = PDF::Builder::Basic::PDF::File->new(%args)
Creates a new PDF object, ready to have objects written to it.

Optional arguments are:

filename
The filename for the output PDF. If not given, then the file will be written to STDOUT.
version
The PDF version to use. Defaults to 1.2.
compress
A boolean value to indicate whether to compress streams. Defaults to true.
encrypt
A boolean value to indicate whether to encrypt the PDF. Defaults to false.
owner_password
The owner password for encryption.
user_password
The user password for encryption.

open

$p = PDF::Builder::Basic::PDF::File->open(%args)
Opens an existing PDF file for reading and modification.

Optional arguments are:

filename
The filename of the PDF to open. Required.
obj_map
A hash reference to store object information in. If not supplied, a new hash will be created.
incremental
If true, then the PDF will be opened for incremental updates. This means that new objects will be appended to the end of the file, and the cross-reference table will be updated. Defaults to false.
compress
A boolean value to indicate whether to decompress streams when reading. Defaults to true.
pages_only
If true, only the page tree will be read. This can speed up opening large documents if you only need to manipulate pages. Defaults to false.
encrypted
A boolean value to indicate whether the PDF is encrypted. Defaults to false.
owner_password
The owner password for decryption.
user_password
The user password for decryption.

version

$p->version($version)
$prev_version = $p->version()
Gets or sets the PDF version. When setting, the version is formatted to two decimal places.

The PDF version is used to determine the PDF syntax level. The default PDF version is 1.2.

PDF version 1.3 or higher is required to utilize compressed streams. A PDF version of 1.4 or higher is required to utilize object streams.

It is not recommended to set the PDF version to 1.3 or lower if you are using features that require a higher version, or if you have already read in a PDF file with a higher version number.

If a PDF file is read in, its version is determined and returned. If the existing PDF is 1.3 or below, it returns undefined.

For compatibility with earlier releases, if no decimal point is given, assume "1." precedes the number given.

A warning message is given if you attempt to decrease the PDF version, as you might have already read in a higher level file, or used a higher level feature. This message is suppressed if the 'silent' option is given with any value.

require_version

$prev_version = $p->require_version($version)
Ensures that the PDF version is at least $version. Silently sets the version to the higher level.

release

$p->release()
Releases ALL of the memory used by the PDF document and all of its component objects. After calling this method, do NOT expect to have anything left in the "PDF::Builder::Basic::PDF::File" object (so if you need to save, be sure to do it before calling this method).

NOTE, that it is important that you call this method on any "PDF::Builder::Basic::PDF::File" object when you wish to destroy it and free up its memory. Internally, PDF files have an enormous number of cross-references, and this causes circular references within the internal data structures. Calling release() causes a brute-force cleanup of the data structures, freeing up all of the memory. Once you've called this method, though, don't expect to be able to do anything else with the "PDF::Builder::Basic::PDF::File" object; it'll have no internal state whatsoever.

append_file

$p->append_file()
Appends the objects for output to the read file and then appends the appropriate table.

out_file

$p->out_file($fname)
Writes a PDF file to a file of the given filename, based on the current list of objects to be output. It creates the trailer dictionary based on information in $self.

$fname may be a string or an IO object.

create_file

$p->create_file($fname)
Creates a new output file (no check is made of an existing open file) of the given filename or IO object. Note: make sure that "$p->{' version'}" is set correctly before calling this function.

close_file

$p->close_file()
Closes up the open file for output, by outputting the trailer, etc.

readval

($value, $str) = $p->readval($str, %opts)
Reads a PDF value from the current position in the file. If $str is too short, read some more from the current location in the file until the whole object is read. This is a recursive call which may slurp in a whole big stream (unprocessed).

Returns the recursive data structure read and also the current $str that has been read from the file.

read_obj

$ref = $p->read_obj($objind, %opts)
Given an indirect object reference, locate it and read the object returning the read-in object.

read_objnum

$ref = $p->read_objnum($num, $gen, %opts)
Returns a fully read object of given number and generation in this file

new_obj

$objind = $p->new_obj($obj)
Creates a new, free object reference based on free space in the cross reference chain. If nothing is free, then think up a new number. If $obj, then turns that object into this new object rather than returning a new object.

out_obj

$p->out_obj($obj)
Indicates that the given object reference should appear in the output xref table whether with data or freed.

free_obj

$p->free_obj($obj)
Marks an object reference for output as being freed.

remove_obj

$p->remove_obj($objind)
Removes the object from all places where we might remember it.

ship_out

$p->ship_out(@objects)
$p->ship_out()
Ships the given objects (or all objects for output if @objects is empty) to the currently open output file (assuming there is one). Freed objects are not shipped, and once an object is shipped it is switched such that this file becomes its source and it will not be shipped again unless out_obj is called again. Notice that a shipped out object can be re-output or even freed, but that it will not cause the data already output to be changed.

copy

$p->copy($outpdf, \&filter)
Iterates over every object in the file reading the object, calling "filter" with the object, and outputting the result. If "filter" is not defined, just copies input to output.

PRIVATE METHODS & FUNCTIONS

The following methods and functions are considered private to this class. This does not mean you cannot use them if you have a need, just that they aren't really designed for users of this class.

locate_obj

$offset = $p->locate_obj($num, $gen)
Returns a file offset to the object asked for by following the chain of cross reference tables until it finds the one you want.

update

update($fh, $str, $instream)
Keeps reading $fh for more data to ensure that $str has at least a line full for "readval" to work on. At this point we also take the opportunity to ignore comments.

test_obj

$objind = $p->test_obj($num, $gen)
Tests the cache to see whether an object reference (which may or may not have been getobj()ed) has been cached. Returns it if it has.

add_obj

$p->add_obj($objind)
Adds the given object to the internal object cache.

readxrtr

$tdict = $p->readxrtr($xpos, %options)
Recursive function which reads each of the cross-reference and trailer tables in turn until there are no more.

Returns a dictionary corresponding to the trailer chain. Each trailer also includes the corresponding cross-reference table.

The structure of the xref private element in a trailer dictionary is of an anonymous hash of cross reference elements by object number. Each element consists of an array of 3 elements corresponding to the three elements read in [location, generation number, free or used]. See the PDF specification for details.

See "open" for options allowed.

out_trailer

$p->out_trailer($tdict, $update)
$p->out_trailer($tdict)
Outputs the body and trailer for a PDF file by outputting all the objects in the ' outlist' and then outputting a xref table for those objects and any freed ones. It then outputs the trailing dictionary and the trailer code.

_new

PDF::Builder::Basic::PDF::File->_new()
Creates a very empty PDF file object (used by new() and open())

NAME

PDF::Builder::Basic::PDF::File - Un manejador de archivos PDF.

SYNOPSIS

use PDF::Builder::Basic::PDF::File;

my $file_handle = PDF::Builder::Basic::PDF::File->new(
    filename => 'mi_archivo.pdf',
    mode     => 'w'
);

# Escribe datos en el archivo
$file_handle->write("Hola, mundo!\n");

# Cierra el archivo
$file_handle->close;

DESCRIPTION

La clase PDF::Builder::Basic::PDF::File proporciona una interfaz simple para escribir datos en un archivo PDF. Se basa en el módulo Perl estándar IO::File.

INSTANCE VARIABLES

Esta clase no define variables de instancia adicionales más allá de las proporcionadas por IO::File.

METHODS

  • new( %args ): Constructor. Acepta los mismos argumentos que IO::File->new, como filename y mode.

  • write( $string ): Escribe la cadena dada en el archivo.

  • close(): Cierra el archivo.

PRIVATE METHODS & FUNCTIONS

Esta clase no expone métodos privados o funciones que deban ser llamados directamente por el usuario.
