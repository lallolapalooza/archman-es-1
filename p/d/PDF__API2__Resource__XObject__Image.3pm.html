PDF::API2::Resource::XObject::Image(3) Documentación de Perl contribuida por el usuario PDF::API2::Resource::XObject::Image(3)

NOMBRE

PDF::API2::Resource::XObject::Image - Clase base para objetos de imagen ráster externos

MÉTODOS

$image = PDF::API2::Resource::XObject::Image->new($pdf, $name)
Devuelve un objeto de recurso de imagen.
$width = $image->width($width)
Obtiene o establece el valor de ancho para el objeto de imagen.
$height = $image->height($height)
Obtiene o establece el valor de alto para el objeto de imagen.
$image->smask($xobject)
Establece el objeto de imagen de máscara suave.
$image->mask(@color_range)
$image->mask($xobject)
Establece la máscara en un objeto XObject de máscara de imagen o en una matriz que contiene un rango de colores para aplicar como máscara de clave de color.
$image->colorspace($name)
$image->colorspace($array)
Establece el espacio de color utilizado por la imagen. Dependiendo del espacio de color, será solo el nombre del espacio de color, o será una matriz que contenga el espacio de color y cualquier parámetro requerido.

Si se pasa una matriz, los parámetros ya deben estar codificados como objetos PDF. La matriz en sí también puede ser un objeto PDF. Si no lo es, se creará uno.

$image->bits_per_component($integer)
Establece el número de bits utilizados para representar cada componente de color.
