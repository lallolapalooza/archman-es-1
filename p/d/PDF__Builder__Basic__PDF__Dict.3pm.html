NOMBRE

PDF::Builder::Basic::PDF::Dict - Diccionarios y flujos PDF

Hereda de PDF::Builder::Basic::PDF::Objind

VARIABLES DE INSTANCIA

Hay varias variables de instancia especiales que se utilizan para gestionar, en particular, los flujos. Cada una comienza con un espacio:

' stream'
Contiene el contenido del flujo para su salida.
' streamfile'
Contiene el contenido del flujo en un archivo externo en lugar de en memoria. Esto no es lo mismo que un flujo de archivo PDF. Los datos se almacenan en su forma sin filtrar.
' streamloc'
Si ' stream' y ' streamfile' están vacíos, esto indica dónde comienza el flujo en el archivo PDF de origen.

MÉTODOS

new

$d = PDF::Builder::Basic::PDF->new()
Crea una nueva instancia de un diccionario. La práctica habitual es llamar a PDFDict() en su lugar.

type

$type = $d->type($type)
Obtiene/Establece la clave de Tipo estándar. Puede pasarse y devolverá un valor de texto en lugar de un objeto Nombre.

filter

@filters = $d->filter(@filters)
Obtiene/Establece uno o varios filtros que utiliza el flujo opcional adjunto al diccionario.

outobjdeep

$d->outobjdeep($fh, $pdf)
Saca el contenido del diccionario a un archivo PDF. Esta es una llamada recursiva.

También saca un flujo si el diccionario tiene un elemento de flujo. Si esto ocurre, este método calculará la longitud del flujo y la insertará en el diccionario del flujo.

read_stream

$d->read_stream($force_memory)
Lee un flujo de un archivo PDF. Si el flujo es mayor que "PDF::Dict::mincache" (por defecto 32768) bytes para ser almacenado, la acción por defecto es crear un archivo para él en algún lugar y usar ese archivo como caché de datos. Si se establece $force_memory, esta caché no se producirá y todos los datos se almacenarán en la variable $self->{' stream'}.

val

$d->val()
Devuelve el diccionario, que es él mismo.
