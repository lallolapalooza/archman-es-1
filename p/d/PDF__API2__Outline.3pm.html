PDF::API2::Outline(3) Documentación de Perl contribuida por el usuario PDF::API2::Outline(3)

NOMBRE

PDF::API2::Outline - Gestiona esquemas de PDF (también conocidos como marcadores)

SINOPSIS

# Obtener/crear el árbol de esquemas de nivel superior
my $outline = $pdf->outline();
# Añadir una entrada
my $item = $outline->outline();
$item->title('Primera Página');
$item->destination($pdf->open_page(1));

MÉTODOS

Examinar el árbol de esquemas

has_children

my $boolean = $outline->has_children();

Devuelve verdadero si el elemento de esquema actual tiene elementos hijos.

count

my $integer = $outline->count();

Devuelve el número de descendientes que son visibles cuando el elemento de esquema actual está abierto (expandido).

first

my $child = $outline->first();

Devuelve el primer hijo del nivel de esquema actual, si existe.

last

my $child = $outline->last();

Devuelve el último hijo del nivel de esquema actual, si existe.

parent

my $parent = $outline->parent();

Devuelve el padre del elemento actual, si no se está en el nivel superior del árbol de esquemas.

prev

my $sibling = $outline->prev();

Devuelve el elemento anterior del nivel actual del árbol de esquemas.

next

my $sibling = $outline->next();

Devuelve el elemento siguiente del nivel actual del árbol de esquemas.

Modificar el árbol de esquemas

outline

my $child = $outline->outline();

Añade un elemento de esquema al final de la lista de hijos del esquema actual.

insert_after

my $sibling = $outline->insert_after();

Añade un elemento de esquema inmediatamente después del elemento actual.

insert_before

$sibling = $outline->insert_before();

Añade un elemento de esquema inmediatamente antes del elemento actual.

delete

$outline->delete();

Elimina el elemento de esquema actual del árbol de esquemas. Si el elemento tiene hijos, estos se eliminarán efectivamente ya que ya no estarán enlazados.

is_open

# Obtener
my $boolean = $outline->is_open();
# Establecer
my $outline = $outline->is_open($boolean);

Obtiene/establece si el esquema está expandido o colapsado.

Establecer atributos de esquema

title

# Obtener
my $title = $outline->title();
# Establecer
$outline = $outline->title($text);

Obtiene/establece el título del elemento de esquema.

destination

$outline = $outline->destination($destination, $location, @args);

Establece la página de destino y la posición opcional del esquema. $location y @args son como se definen en "destination" en PDF::API2::NamedDestination.

$destination puede ser opcionalmente el nombre de un destino nombrado definido en otro lugar.

uri

$outline = $outline->uri($uri);

Lanza una URI —típicamente una página web— cuando se activa el elemento de esquema.

launch

$outline->launch($file);

Lanza una aplicación o archivo cuando se activa el elemento de esquema.

pdf

$outline = $outline->pdf($filename, $page_number, $location, @args);

Abre otro archivo PDF a un número de página específico (la primera página es cero, que también es el valor predeterminado). La página puede tener opcionalmente una posición si $location y @args están establecidos; consulta "destination" en PDF::API2::NamedDestination para ver las configuraciones posibles.
