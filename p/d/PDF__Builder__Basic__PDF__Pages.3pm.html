PDF::Builder::Basic::PDF::Pages(3) Documentación de Perl contribuida por el usuario PDF::Builder::Basic::PDF::Pages(3)

NOMBRE

PDF::Builder::Basic::PDF::Pages - elemento jerárquico de páginas PDF

Hereda de PDF::Builder::Basic::PDF::Dict

DESCRIPCIÓN

Un objeto Pages es el padre de otros objetos Pages o de objetos de página.

MÉTODOS

new

PDF::Builder::Basic::PDF::Pages->new($pdf, $parent)
Esto crea un nuevo objeto Pages en un PDF. Nótese que el $parent aquí no es el contexto del archivo para el objeto, sino el objeto Pages padre para estas páginas. Si estamos usando esta clase para crear un nodo raíz, $parent debe apuntar al contexto del archivo, el cual se identifica al *no* tener un Tipo de *Pages*. $pdf es el objeto de archivo (o una referencia a un array de *un* objeto de archivo [3.016 y posteriores, o múltiples objetos de archivo anteriores]) en el cual crear el nuevo objeto Pages.

find_page

$p->find_page($numero_pagina)
Devuelve la página dada, usando los valores de recuento de páginas en el árbol de páginas. Las páginas comienzan en 0.

add_page

$p->add_page($pagina, $numero_pagina)
Inserta la página antes del $numero_pagina dado. $numero_pagina puede ser negativo para contar hacia atrás desde el FINAL del documento. -1 está después de la última página. De manera similar, $numero_pagina puede ser mayor que el número de páginas actualmente en el documento, para agregar al final.

Este método solo garantiza proporcionar un árbol de páginas razonable si las páginas se agregan o se anteponen al documento. Las páginas insertadas en medio del documento pueden simplemente insertarse en la hoja apropiada en el árbol de páginas sin agregar nuevas ramas u hojas, dejándolo desequilibrado (rendimiento más lento, pero aún utilizable).

get_pages

@objetos = $p->get_pages()
Devuelve una lista de objetos de página en el documento, en orden de página.

find_prop

$p->find_prop($clave)
Busca hacia arriba en el árbol de herencia para encontrar una propiedad (clave).

add_font

$p->add_font($pdf, $fuente)
Crea o edita el diccionario de recursos en este nivel de la jerarquía. Si la fuente ya es compatible, incluso a través de la jerarquía, entonces no se agrega.

PRECAUCIÓN: si este método se usó en versiones anteriores, el código puede haber intercambiado el orden de $pdf y $fuente, requiriendo intercambios ad hoc de parámetros en el código del usuario, contrariamente a la definición de POD anterior. Ahora el código coincide con la documentación.

bbox

$p->bbox($xmin,$ymin, $xmax,$ymax, $param)
$p->bbox($xmin,$ymin, $xmax,$ymax)
Especifica el cuadro delimitador para esta y todas las páginas hijas. Si los valores son idénticos a los heredados, no se realiza ningún cambio. $param especifica el nombre del atributo para que otros 'cuadros delimitadores' puedan establecerse con este método.

proc_set

$p->proc_set(@entradas)
Asegura que el recurso actual contenga todas las entradas en los proc_sets listados. Si es necesario, crea un diccionario de recursos local para lograr esto.

get_top

$p->get_top()
Devuelve la parte superior del árbol de páginas.
