PDF::API2::Basic::PDF::Dict(3) Documentación de Perl aportada por el usuario PDF::API2::Basic::PDF::Dict(3)

NOMBRE

PDF::API2::Basic::PDF::Dict - Objetos de diccionario y flujo de bajo nivel

VARIABLES DE INSTANCIA

Existen varias variables de instancia especiales que se utilizan para la gestión, en particular, de los flujos. Cada una comienza con un espacio:

flujo
Contiene el contenido del flujo para la salida
archivodeflujo
Contiene el contenido del flujo en un archivo externo en lugar de en memoria. Esto no es lo mismo que un flujo de archivo PDF. Los datos se almacenan en su forma sin filtrar.
ubicaciondeflujo
Si ' flujo' y ' archivodeflujo' están vacíos, esto indica dónde comienza el flujo en el PDF de origen.

MÉTODOS

$tipo = $d->tipo($tipo)

Obtiene/Establece la clave estándar Type. Puede ser pasada y devolverá un valor de texto en lugar de un objeto Name.

@filtros = $d->filtro(@filtros)

Obtiene/Establece uno o más filtros que están siendo utilizados por el flujo opcional adjunto al diccionario.

$d->salidprofundidad($fh)

Saca el contenido del diccionario a un archivo PDF. Esta es una llamada recursiva.

También saca un flujo si el diccionario tiene un elemento de flujo. Si esto ocurre, este método calculará la longitud del flujo y la insertará en el diccionario del flujo.

$d->leer_flujo($forzar_memoria)

Lee un flujo de un archivo PDF. Si el flujo es mayor que "PDF::Dict::mincache" (por defecto 32768) bytes para ser almacenado, la acción por defecto es crear un archivo para él en algún lugar y usar ese archivo como caché de datos. Si $forzar_memoria está establecido, este almacenamiento en caché no ocurrirá y todos los datos se almacenarán en la variable $self->{' flujo'}.

$d->valor

Devuelve el diccionario, que es él mismo.
