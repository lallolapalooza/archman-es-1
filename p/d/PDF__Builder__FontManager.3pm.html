PDF::Builder::FontManager(3) Documentación de contribuciones de Perl PDF::Builder::FontManager(3)

NOMBRE

PDF::Builder::FontManager - Administrar la librería de fuentes para PDF::Builder

SINOPSIS

Estas rutinas se llaman desde la clase PDF::Builder (ver los métodos get_font(), add_font()).

# las fuentes core vienen precargadas
# Añadir una nueva familia de fuentes y variantes
my $rc = $pdf->add_font(
    'face' => $unique_face_name,  # familia de fuentes, ej. Times
    'type' => 'core',             # notar que las fuentes core vienen precargadas
    'style' => 'serif',           # también sans-serif, script (cursiva), y símbolo
    'width' => 'proportional',    # también constant
    'settings' => { 'encode' => $encoding },
    # notar que estos son los nombres reales de las fuentes core, no rutas de archivos
    'file' => { 'roman'       => 'Times-Roman',      
                'italic'      => 'Times-Italic',
                'bold'        => 'Times-Bold',
                'bold-italic' => 'Times-BoldItalic' },
            # para fuentes no core, estas serían las rutas de archivos
            # añadidas al principio de los caminos de búsqueda definidos
    );
$rc = $pdf->add_font(
    'face' => 'DejaVuSans',       # familia de fuentes sans serif de Deja Vu
    'type' => 'ttf',              # otf usa 'ttf'
    'style' => 'sans-serif',
    'width' => 'proportional',
    'settings' => { 'encode' => 'utf8' },
    # los caminos de búsqueda definidos se añadirán al principio
    'file' => { 'roman'       => 'DejaVuSans.ttf',
                'italic'      => 'DejaVuSans-Oblique.ttf',
                'bold'        => 'DejaVuSans-Bold.ttf',
                'bold-italic' => 'DejaVuSans-BoldOblique.ttf' }
);

Algunos de los datos globales, que pueden ser reiniciados usando el método font_settings():

* default-face: inicializado como Times-Roman (core), se usa si se inicia el texto sin especificar una familia
* default-serif: inicializado como Times-Roman (core), se usa si se quiere una familia de tipo serif genérica
* default-sansserif: inicializado como Helvetica (core), se usa si se quiere una familia de tipo sans-serif genérica
* default-constant: inicializado como Courier (core), se usa si se quiere una familia de tipo constante
* default-script: no inicializado (sin default), se usa si se quiere una familia de tipo script (cursiva) genérica
* default-symbol: inicializado como Symbol (core), se usa si se quiere una familia de tipo símbolo genérica
* font-paths: rutas para TTF en sistemas Windows (ej. C:/Windows/Fonts), otros tipos en rutas no estándar, y para no Windows, cualquier ruta

El uso de get_font() es para especificar la familia y variantes, y luego cada vez, especificar _italic_ y _bold_ para que sean on o off. Si el archivo deseado no está abierto aún, se abrirá y se devolverá el $font. Si la fuente ya fue creada anteriormente, se devolverá el $font guardado.

my $font = $pdf->get_font(
     'face' => 'Times',
     'italic' => 0,     # deseando Roman (recta)
     'bold' => 0,       # deseando peso medio
);
# si $font es undef, hay un problema...
$text->font($font, $font_size);
$text->...  # usar esta fuente (medio peso Times-Roman core)
$font = $pdf->get_font('italic' => 1);
$text->...  # cambiado a cursiva
$font = $pdf->get_font('italic' => 0);
$text->...  # vuelta a texto romano (recta)

MÉTODOS

new

PDF::Builder::FontManager->new(%opts)
Esto se llama desde Builder.pm's new(). Actualmente no hay opciones seleccionables. Se configurará el sistema de gestión de fuentes y se precargará con las fuentes core. Algunos valores por defecto se establecerán para la familia (Times-Roman core), la familia serif genérica (Times-Roman core), la familia sans-serif genérica (Helvetica core), la familia de anchura constante (fuentes de tipo fijo) (Courier core), y una fuente de símbolo (Symbol core). No hay valor por defecto para una fuente script (cursiva) hasta que se establezca con el método font_settings().

font_settings

@list = $pdf->font_settings()  # Obtener
$pdf->font_settings(%info)  # Establecer
Obtener o establecer información sobre fuentes, especialmente aquellas que se usan para "genéricas".

"Obtener" devuelve una lista (array) de la familia de nombre de fuente por defecto, la familia serif genérica por defecto, la familia sans-serif genérica por defecto, la familia de anchura constante por defecto, la familia símbolo genérica por defecto, y la familia script (cursiva) genérica por defecto. Es posible que un elemento sea indefinido (ej. la familia script genérica es "undef").

"Establecer" cambia una o más configuraciones por defecto:

'font' => familia a usar para la familia por defecto (inicializado como Times)
'serif' => familia a usar para la familia genérica de serif (inicializado como Times)
'sans-serif' => familia a usar para la familia genérica de sans-serif (inicializado como Helvetica)
'constant' => familia a usar para la familia genérica de anchura constante (inicializado como Courier)
'script' => familia a usar para la familia genérica de script (no inicializado)
'symbol' => familia a usar para la familia genérica de símbolo (inicializado como Symbol)

add_font_path

$rc = $pdf->add_font_path("una ruta de directorio", %opts)
Este método añade una ruta de búsqueda a la lista de rutas de búsqueda a considerar. En el método get_font(), cada ruta de búsqueda definida se añadirá al principio del "file" (excepto para fuentes core) en orden, hasta que se encuentre la fuente. Sin embargo, si el "file" se inicializa con / o ./ o ../, se usará por sí mismo. Una entrada de "file" que empieza con .../ se trata como un caso especial, que se convierte en ../ antes de añadir la ruta de búsqueda. Esto permite que puedas dar una ruta de búsqueda que se espera que se mueva uno o más directorios hacia arriba.

La lista de rutas de búsqueda de fuentes siempre incluye el directorio actual (.), y se inicializa en "Builder.pm" como @font_path. Para el sistema operativo Windows, "/Windows/Fonts" generalmente contiene varias fuentes TTF que vienen con Windows estándar, por lo que se agrega por defecto. Cualquier otra cosa, incluyendo todo Linux (y otros sistemas no Windows), tendrá que ser añadida según tu sistema particular. Algunas ubicaciones comunes son:

Windows (NOTA: ¡usa / y no \\ en las rutas de Windows!). Los sistemas Linux pueden o no manejar espacios en nombres de directorios de manera amigable.

/Windows/Fonts
/WinNT/Fonts
/Program Files/MikTex 2.9/fonts/type1/urw/bookman (URW Bookman para MikTex)
/Program Files (x86)/MikTex 2.9/fonts/type1/urw/bookman (versiones antiguas)
/Program Files/Adobe/Acrobat DC/Resource/CIDFont (fuentes de Adobe Reader)
GhostScript puede tener sus propios directorios

Nota: los nombres de directorios con espacios (ej. "/Program Files") pueden no funcionar bien con algunos sistemas Linux, por lo que no se incluyen por defecto.

Linux, etc.

/usr/share/fonts (base común)
/usr/local/share/fonts (base común)
/usr/share/fonts/dejavu-sans-fonts  (fuentes TTF específicas de Deja Vu Sans)
/usr/share/fonts/truetype/ttf-dejavu
/usr/share/fonts/truetype/dejavu
/usr/lib/defoma/gs.d/devs/fonts   (¿GhostScript?)
/usr/share/fonts/type1/gsfonts    (PS de GhostScript)
/usr/share/X11/fonts/urw-fonts    (PS de URW)

Instalaciones de aplicaciones de terceros, como Adobe Acrobat Reader, también pueden tener fuentes instaladas.

Un código de retorno de 0 indica que la ruta se añadió correctamente, mientras que 1 indica que se encontró un problema (y se emitió un mensaje).

No hay opciones definidas actualmente.

add_font

$rc = add_font(%info)
Añade una nueva entrada de fuente (por familia y variantes) a la lista de fuentes conocidas del Gestor de Fuentes.

add_font

@fonts = $pdf->add_font(type => string,
                       file => { ... },
                       settings => { ... },
                       style => string,
                       width => string,
                       %other_args)
Esta rutina se usa para añadir fuentes al gestor de fuentes para su uso posterior. Tiene la ventaja de poder ser llamada con diferentes tipos de fuentes, y puede ser utilizada para definir fuentes genéricas (como "serif", "sans-serif", etc.) o para hacer referencia a fuentes específicas de sistemas (como Arial, Times, etc.). Los argumentos son los mismos que se utilizan para la rutina font(), con la excepción de que aquí se pueden añadir más de una fuente, y que los argumentos style y width tienen un significado especial: se utilizan para definir las fuentes genéricas mencionadas.

Devuelve una lista de las fuentes que se han añadido correctamente. El gestor de fuentes mantiene internamente una lista de fuentes disponibles, y al llamar a esta rutina, tu código le está diciendo al gestor que añada las fuentes especificadas a esa lista.

Los tipos de fuentes son:

core
Esta es una fuente básica (core font), y se carga a través de la rutina CoreFont(). Ten en cuenta que las fuentes básicas se pre-cargan automáticamente (incluidas algunas adicionales en sistemas Windows), por lo que no deberías necesitar cargar explícitamente ninguna fuente básica (al menos, las 14 básicas). Todas las instalaciones de PDF deberían incluir estas 14 fuentes básicas, pero el tipo de archivo exacto puede variar entre instalaciones, y se pueden realizar sustituciones (siempre que las métricas coincidan). Actualmente, las fuentes básicas se limitan a codificaciones de un solo byte.

En sistemas Windows, hay 14 fuentes básicas adicionales que normalmente se cargan. Estas son las caras de fuente Georgia, Verdana, Trebuchet, Wingdings y Webdings. Usa precaución si haces uso de estas fuentes básicas adicionales, ya que los sistemas no Windows podrían no incluirlas sin una instalación manual explícita de estas fuentes. Estas fuentes pueden ser seguras de usar si sabes que todos tus lectores de PDF se ejecutarán en sistemas Windows.

ttf
Esta es una fuente TrueType (.ttf) o OpenType (.otf), cargada con ttfont(). Actualmente este es el único tipo que puede usarse con codificaciones multibyte (por ejemplo, utf8), así como con codificaciones de un solo byte como Latin-1. Es también el único tipo de fuente que puede usarse con HarfBuzz::Shaper. Muchos sistemas incluyen un número de fuentes TTF, pero a diferencia de las fuentes básicas, ninguna se carga automáticamente por el Gestor de Fuentes de PDF::Builder, y deben cargarse explícitamente a través de add_font().
type1
Esta es una fuente PostScript (Type1), cargada con psfont(), que solía ser bastante común, pero hoy en día se usa con poca frecuencia, habiendo sido mayormente suplantada por el formato TTF, más capaz. Algunos sistemas pueden incluir algunas fuentes Type1, pero Windows, por ejemplo, normalmente no viene con ninguna. Ninguna fuente Type1 se carga automáticamente por el Gestor de Fuentes de PDF::Builder, y deben cargarse explícitamente a través de add_font().

Se asume que el archivo de métricas de la fuente (.afm o .pfm) tiene el mismo nombre base que el archivo de glifos (.pfa o .pfb), se encuentra en el mismo directorio, y cualquiera de ellos puede funcionar con el otro. Si necesitas un directorio diferente, un nombre base diferente, o un archivo de métricas específico para acompañar a un archivo de glifos específico, háznoslo saber, para que podamos añadir tal funcionalidad. De lo contrario, necesitarás usar directamente el método psfont() para especificar tales rutas diferentes.

cjk
Esta es una fuente de tipo Asia Oriental (Chino-Japonés-Coreano), cargada con el método cjkfont(). Ten en cuenta que las fuentes CJK nunca han sido bien soportadas por PDF::Builder, y dependen de algunas características bastante antiguas (obsoletas) y archivos externos (.cmap y .data). Sugerimos que, en lugar de ir directamente a archivos CJK, primero intentes usar directamente los archivos TTF (generalmente), en formato TTF. Pocos sistemas vienen con fuentes CJK instaladas. Ninguna fuente CJK se carga automáticamente por el Gestor de Fuentes de PDF::Builder, y deben cargarse explícitamente a través de add_font().
bdf
Esta es una fuente Adobe Bitmap Distribution Format, cargada con el método bdfont(), un formato de mapa de bits muy antiguo que data de los primeros días del sistema X11. A diferencia de los contornos suaves y rellenos utilizados en la mayoría de las fuentes modernas, los BDF son una rejilla gruesa de píxeles encendidos/apagados. ¡Por favor, sé amable con tus lectores y usa este formato con moderación, como solo para títulos de capítulos o encabezados! Pocos sistemas vienen con fuentes BDF instaladas hoy en día. Ninguna fuente BDF se carga automáticamente por el Gestor de Fuentes de PDF::Builder, y deben cargarse explícitamente a través de add_font().
settings => { 'encode' => string, ... }
Esta es una colección de cualquier otra configuración, indicadores, etc. aceptados por este tipo de fuente en particular. Consulta el POD para "corefont", "ttfont", etc. (por tipo para las entradas permitidas. Una importante será la codificación, que necesitarás especificar, si usas caracteres que vayan más allá del ASCII básico.

Actualmente, todas las fuentes pueden usar cualquier codificación de un solo byte que desees (el valor predeterminado es CP-1252). Solo las fuentes de tipo TTF (que incluyen fuentes OTF y CJK) pueden especificar actualmente una codificación multibyte como utf8. No necesita decirse que los datos de texto que pases a las rutinas de texto deben ajustarse a la codificación dada. No estás obligado a usar la misma codificación para todas las fuentes definidas, pero si deseas mezclar y combinar codificaciones, ¡depende de ti definir tu texto que use la codificación especificada para la fuente en particular utilizada!

Nota en particular cuando uses entidades que (si son numéricas) se dan en el número Unicode. Cuando está fuera del rango de un solo byte (x00-xFF), los resultados son impredecibles si proporcionas una entidad que no cae dentro del rango de la codificación. ¡También comprueba los resultados de los puntos Unicode dentro del rango x80-xFF si estás usando codificación utf8.

style => 'styling'
Esto especifica el estilo de la fuente: serif, sans-serif, constant (ancho constante, o pitch fijo), script (cursiva), o symbol (no alfabético). No tiene efecto en cómo se carga o usa una fuente, pero puede ser útil para definir una fuente de estilo genérico.
width => 'relative widths'
Actualmente, se pueden especificar proportional (ancho variable) y constant (ancho constante). No tiene efecto en cómo se carga o usa una fuente, pero puede ser útil para definir una fuente de estilo genérico.
file => {anonymous hash of source files}
Esto le dice al Gestor de Fuentes dónde encontrar el archivo de fuente real. Para las fuentes básicas, es el nombre estándar, en lugar de un archivo (y recuerda, están pre-cargadas). Para todos los demás tipos, enumera de uno a cuatro de las siguientes variantes:
roman => 'path to Roman'
Esto especifica la variante de la fuente con postura "Roman" o "regular". Casi todas las fuentes disponibles incluyen una variante Roman (postura normal, vertical) con peso medio.
italic => 'path to Italic'
Esto especifica la variante de postura "Italic", "slanted" u "oblique" de la fuente. La mayoría de las fuentes disponibles incluyen una variante itálica con peso normal (medio).
bold => 'path to Bold'
Esto especifica la variante "Bold" o "heavy" de la fuente. La mayoría de las fuentes disponibles incluyen una variante negrita (peso pesado) con postura normal (Roman).
bold-italic => 'path to BoldItalic'
Esto especifica la variante "Bold" e "Italic" de la fuente. Muchas fuentes disponibles incluyen una variante negrita (peso pesado) con postura itálica.
symbol => 'path to Symbol'
Para fuentes de tipo símbolo (no alfabético), en lugar de arriesgarse a confusión reutilizando el término "roman", se usa el término "symbol" para especificar lo que suele ser la única variante de una fuente de símbolo. Es posible que existan variantes negrita, itálica e incluso negrita-itálica de un archivo de símbolo, pero si es así, actualmente no están soportadas.

Puedes proporcionar la ruta completa del archivo de origen de la fuente, en una ruta absoluta, si lo deseas. Sin embargo, normalmente se escribe menos usando add_font_path() para especificar una lista de directorios de fuentes a buscar, y solo proporcionar el nombre (y quizás un subdirectorio) para la ruta aquí en add_font().

get_font

@current = $pdf->get_font()  # Obtener
$font = $pdf->get_font(%info)  # Establecer
Si no se proporcionan parámetros ("@current = $pdf->get_font()"), se devuelve una lista (array) que da la configuración de la fuente actual: nombre de cara, indicador de cursiva 0/1, indicador de negrita 0/1, tipo ('core', 'ttf', etc.), una referencia a un hash de configuraciones, como la codificación ('utf8', etc.), valor de estilo, valor de ancho, y una referencia a un array (lista) de variantes (roman, bold, etc.). Si aún no se ha establecido explícitamente ninguna fuente, la fuente actual será la fuente predeterminada.

Si se proporciona al menos un parámetro (hash %info), el gestor de fuentes intentará descubrir la fuente apropiada (de la lista de fuentes), cargarla si no se ha hecho ya, y devolver el valor de $font. Si se devuelve undef, hubo un error.

Campos de %info:

face => face name string
Este es el nombre de familia (cara) de fuente cargado con las fuentes básicas (por ejemplo, Times), o a través de llamadas a "$pdf->add_font()". Además, se puede solicitar la cara de fuente actual o la cara predeterminada, la cara genérica serif, la cara genérica sans-serif, la cara genérica de ancho constante constant, o la cara genérica de escritura script (cursiva) (si está definida).

Si proporcionas la entrada "face", las otras configuraciones ("italic", "bold", etc.) no se restablecen, a menos que sea imposible usar la configuración existente. Si no proporcionas la entrada "face", la entrada actual se actualizará (negrita, cursiva activadas/desactivadas, etc.). Siempre puedes proporcionar explícitamente current para dejar claro en tu código que no quieres cambiar la cara.

MÉTODOS

italic => flag
Esto solicita el uso de la variante cursiva (inclinada) de la fuente, ya sea en la cara actual (si no se especifica "face" en esta llamada) o en la nueva cara. El valor es 0 o 1 para "apagado" (peso medio) y "encendido" (inclinado).
bold => flag
Esto solicita el uso de la variante negrita (peso pesado) de la fuente, ya sea en la cara actual (si no se especifica "face" en esta llamada) o en la nueva cara. El valor es 0 o 1 para "apagado" (peso medio) y "encendido" (peso pesado).
