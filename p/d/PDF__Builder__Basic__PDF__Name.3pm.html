NOMBRE

PDF::Builder::Basic::PDF::Name - Almacena nombres PDF (cosas que comienzan con /)

Hereda de PDF::Builder::Basic::PDF::String

MÉTODOS

from_pdf

$n = PDF::Builder::Basic::PDF::Name->from_pdf($cadena)
Crea un nuevo objeto de cadena (aún no un objeto completo) a partir de una cadena dada. La cadena se analiza según los criterios de entrada y el escapado funciona, de forma particular para los Nombres.

convertir

$n->convertir($cadena, $pdf)
Convierte un nombre en una cadena eliminando el / y convirtiendo cualquier ofuscación hexadecimal.

as_pdf

$s->as_pdf($pdf)
Devuelve un nombre formateado como PDF. $pdf es opcional pero debería ser el objeto del archivo PDF para el cual se pretende el nombre si se proporciona.

string_a_nombre

PDF::Builder::Basic::PDF::Name->string_a_nombre($cadena, $pdf)
Codifica adecuadamente la cadena $cadena para su salida en el objeto Archivo $pdf (el formato exacto puede depender de la versión de $pdf).

nombre_a_cadena

PDF::Builder::Basic::PDF::Name->nombre_a_cadena($cadena, $pdf)
Decodifica adecuadamente la cadena $cadena tal como se lee del objeto Archivo $pdf (la decodificación exacta puede depender de la versión de $pdf). Principalmente, deshace la codificación hexadecimal para las versiones de PDF > 1.1.
