NOMBRE

PDF::API2::Resource::Font::SynFont - Módulo para crear fuentes sintéticas.

SINOPSIS

my $pdf = PDF::API2->new();
my $base_font = $pdf->font('Helvetica');
# Crear una fuente sintética condensada
my $condensed = $pdf->synthetic_font($base_font, hscale => 80);
# Comparar las dos fuentes
my $text = $pdf->page->text();
$text->font($base_font, 18);
$text->distance(72, 720);
$text->text('¡Hola Mundo!');
$text->font($condensed, 18);
$text->distance(0, -36);
$text->text('¡Hola Mundo!');
$pdf->save('sample.pdf');

DESCRIPCIÓN

Este módulo permite crear una fuente personalizada basada en una fuente existente, ajustando la escala, el grosor del trazo, el ángulo y otras propiedades de cada glifo.

OPCIONES DE FUENTE

hscale

Un porcentaje para condensar (menos de 100) o expandir (más de 100) los glifos horizontalmente.

angle

Un número de grados para inclinar los glifos a la izquierda (ángulo negativo) o a la derecha (ángulo positivo).

bold

Un grosor de trazo, en milésimas de unidad de texto, para añadir al contorno del glifo, creando un efecto de negrita.

smallcaps

Establecer a verdadero para reemplazar los caracteres en minúscula con versiones pequeñas de sus glifos en mayúscula.

space

Espacio adicional, en milésimas de unidad de texto, para añadir entre glifos.
