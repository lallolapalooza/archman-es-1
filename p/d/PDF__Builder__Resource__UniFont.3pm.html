NOMBRE

PDF::Builder::Resource::UniFont - Soporte de fuentes Unicode

MÉTODOS

new

$fuente = PDF::Builder::Resource::UniFont->new($pdf, @especificaciones_fuente, %opts)
Devuelve un objeto de fuente uni.

ESPECIFICACIONES_FUENTE: las fuentes se pueden registrar utilizando la siguiente referencia hash:

{
    fuente   => $obj_fuente,     # la fuente a registrar
    bloques => $espec_bloques,   # los bloques unicode para los que se registra la fuente
    códigos  => $espec_códigos,    # los puntos de código unicode, etc.
}

ESPECIFICACIONES_BLOQUES:

[
     $bloque1, $bloque3,    # registrar fuente para bloque 1 + 3
    [$bloqueA, $bloqueZ],   # registrar fuente para bloques A .. Z
]

ESPECIFICACIONES_CÓDIGOS:

[
     $cp1, $cp3,          # registrar fuente para punto de código 1 + 3
    [$cpA, $cpZ],         # registrar fuente para puntos de código A .. Z
]

NOTA: si desea registrar una fuente para todo el espacio unicode (es decir, U+0000 .. U+FFFF), simplemente especifique un objeto de fuente sin la referencia hash.
