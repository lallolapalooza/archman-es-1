PR_SET_MM_EXE_FILE(2const) PR_SET_MM_EXE_FILE(2const)

NOMBRE

PR_SET_MM_EXE_FILE - modifica campos del descriptor del mapa de memoria del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_EXE_FILE, long fd, 0L, 0L);

DESCRIPCIÓN

Sustituye el enlace simbólico de /proc/pid/exe por uno nuevo que apunta a un nuevo archivo ejecutable identificado por el descriptor de archivo proporcionado en el argumento fd. El descriptor de archivo debe obtenerse con una llamada open(2) regular.

Para cambiar el enlace simbólico, es necesario mapear todas las áreas de memoria ejecutables existentes, incluidas aquellas creadas por el propio kernel (por ejemplo, el kernel generalmente crea al menos un área de memoria ejecutable para la sección .text de ELF).

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EACCES
El archivo no es ejecutable.
EBADF
El descriptor de archivo pasado en fd no es válido.
EBUSY
Este es el segundo intento de cambiar el enlace simbólico de /proc/pid/exe.

ARCHIVOS

/proc/pid/exe

ESTÁNDARES

Linux.

HISTORIA

Linux 3.5.

En Linux 4.9 y anteriores, la operación PR_SET_MM_EXE_FILE solo se podía realizar una vez en la vida de un proceso; intentar realizar la operación por segunda vez resultaba en el error EPERM. Esta restricción se aplicó por razones de seguridad que posteriormente se consideraron dudosas, y la restricción se eliminó en Linux 4.10 porque algunas aplicaciones de espacio de usuario necesitaban realizar esta operación más de una vez.

VER TAMBIÉN

prctl(2), PR_SET_MM(2const), proc_pid_exe(5)
