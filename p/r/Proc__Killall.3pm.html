Proc::Killall(3) Documentación de Perl aportada por el usuario Proc::Killall(3)

NOMBRE

killall - Terminar todas las instancias de un proceso buscando coincidencias en la línea de comandos

SINOPSIS

use Proc::Killall;
killall('HUP', 'xterm'); # SIGHUP a todos los xterms
killall('KILL', '^netscape$'); # SIGKILL a "netscape"

DESCRIPCIÓN

Este módulo proporciona una función, killall(), que toma dos parámetros: un nombre de señal o número (ver kill()) y un patrón de proceso. Este patrón se compara con la línea de comandos del proceso tal como la mostraría el comando "ps" (internamente no se usa "ps", sino un paquete llamado "Proc::ProcessTable").

"killall" busca en la tabla de procesos y envía esa señal a todos los procesos que coinciden con el patrón. El valor de retorno es el número de procesos a los que se les envió señal correctamente. Si alguna terminación falló, la variable $! se establecerá basándose en la última que falló (incluso si una terminación exitosa ocurrió después).
