Paquete: perl-probe-perl

Probe::Perl(3) Documentación de Perl aportada por el usuario Probe::Perl(3)

NOMBRE

Probe::Perl - Información sobre el intérprete de perl en ejecución

VERSIÓN

versión 0.03

SINOPSIS

use Probe::Perl;
$p = Probe::Perl->new();

# Versión de este perl como número de punto flotante
$ver = $p->perl_version();
$ver = Probe::Perl->perl_version();

# Convertir una cadena con múltiples puntos a un número de punto flotante
$ver = $p->perl_version_to_float($ver);
$ver = Probe::Perl->perl_version_to_float($ver);

# Comprobar si el perl dado es el mismo que el que se está ejecutando
$bool = $p->perl_is_same($perl_path);
$bool = Probe::Perl->perl_is_same($perl_path);

# Encontrar una ruta al intérprete de perl en ejecución
$path = $p->find_perl_interpreter();
$path = Probe::Perl->find_perl_interpreter();

# Obtener @INC antes de las adiciones en tiempo de ejecución
@paths = $p->perl_inc();
@paths = Probe::Perl->perl_inc();

# Obtener el tipo general de sistema operativo
$type = $p->os_type();
$type = Probe::Perl->os_type();

# Acceder a los valores de Config.pm
$val = $p->config('foo');
$val = Probe::Perl->config('foo');
$p->config('foo' => 'bar');  # Establecer localmente
$p->config_revert('foo');  # Revertir

DESCRIPCIÓN

Este módulo proporciona métodos para obtener información sobre el intérprete de perl en ejecución. Originalmente comenzó como código en el proyecto "Module::Build", pero se ha externalizado aquí para uso general.

MÉTODOS

new()
Crea un nuevo objeto Probe::Perl y lo devuelve. La mayoría de los métodos en los paquetes Probe::Perl están disponibles como métodos de clase, por lo que no siempre es necesario crear un nuevo objeto. Pero si desea crear una vista mutable de los datos de "Config.pm", es necesario crear un objeto para almacenar los valores.
config( $key [, $value] )
Devuelve el valor de "Config.pm" asociado a $key. Si también se especifica $value, entonces el valor se establece en $value para esta vista de los datos. En este caso, config() debe llamarse como un método de objeto, no como un método de clase.
config_revert( $key )
Elimina cualquier valor asignado por el usuario en esta vista de los datos de "Config.pm".
find_perl_interpreter( )
Devuelve la ruta absoluta de este intérprete de perl. Esto es en realidad algo difícil de descubrir a veces; en estos casos usamos perl_is_same() para verificar.
perl_version( )
Devuelve la versión de este intérprete de perl como un número de versión estilo perl usando perl_version_to_float(). Usa $^V si tu perl es lo suficientemente reciente, de lo contrario usa $].
perl_version_to_float( $version )
Formatea $version como un número de versión estilo perl como 5.008001.
perl_is_same( $perl )
Dado el nombre de un intérprete de perl, este método determina si tiene la misma configuración que el que representa la instancia de perl actual. Normalmente, esto significa que es exactamente el mismo.
perl_inc( )
Devuelve una lista de directorios en la ruta @INC de este perl, *antes* de que se agreguen las entradas de "use lib", $ENV{PERL5LIB}, o los modificadores "-I".
os_type( [$osname] )
Devuelve un tipo de SO genérico (por ejemplo, "Unix", "Windows", "MacOS") para el nombre de SO dado. Si no se proporciona ningún nombre de SO, utiliza el valor de $^O, que es el mismo que $Config{osname}.
