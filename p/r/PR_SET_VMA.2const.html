PR_SET_VMA(2const) PR_SET_VMA(2const)

NOMBRE

PR_SET_VMA - establece un atributo para áreas de memoria virtual

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_VMA, long attr, unsigned long addr, unsigned long size,
          const char *_Nullable val);

DESCRIPCIÓN

Establece un atributo especificado en attr para áreas de memoria virtual que comienzan en la dirección especificada en addr y que abarcan el tamaño especificado en size. val especifica el valor del atributo a establecer.

Tenga en cuenta que la asignación de un atributo a un área de memoria virtual podría impedir que se fusione con áreas de memoria virtual adyacentes debido a la diferencia en el valor de dicho atributo.

Actualmente, attr debe ser uno de:

PR_SET_VMA_ANON_NAME
Establece un nombre para áreas de memoria virtual anónimas. val debe ser un puntero a una cadena terminada en nulo que contenga el nombre. La longitud del nombre, incluido el byte nulo, no puede exceder los 80 bytes. Si val es NULL, se restablecerá el nombre de las áreas de memoria virtual anónimas apropiadas. El nombre solo puede contener caracteres ASCII imprimibles (isprint(3)), excepto '[', ']', '\', '$' y '`'.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
attr no es un atributo válido.
EINVAL
addr es una dirección inválida.

ESTÁNDARES

Linux.

HISTORIA

Linux 5.17.
