PR_MCE_KILL_GET(2const) PR_MCE_KILL_GET(2const)

NOMBRE

PR_MCE_KILL_GET - obtener la política de terminación por corrupción de memoria de comprobación de máquina

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de las constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_MCE_KILL_GET, 0L, 0L, 0L, 0L);

DESCRIPCIÓN

Devuelve la política de terminación de comprobación de máquina por proceso actual; ver PR_MCE_KILL_SET(2const).

VALOR DE RETORNO

En caso de éxito, esta llamada devuelve el valor no negativo descrito anteriormente. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.32.

VER TAMBIÉN

prctl(2), PR_MCE_KILL(2const), PR_MCE_KILL_SET(2const)
