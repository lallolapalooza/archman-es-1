PR_SVE_GET_VL(2const) PR_SVE_GET_VL(2const)

NOMBRE

PR_SVE_GET_VL - obtener la longitud del vector SVE del hilo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SVE_GET_VL);

DESCRIPCIÓN

Obtiene la configuración actual de la longitud del vector SVE del hilo.

Esta operación devuelve un valor no negativo que describe la configuración *actual*. Los bits correspondientes a PR_SVE_VL_LEN_MASK contienen la longitud del vector actualmente configurada en bytes. El bit correspondiente a PR_SVE_VL_INHERIT indica si la longitud del vector se heredará a través de execve(2).

VALOR DE RETORNO

En caso de éxito, PR_SVE_GET_VL devuelve los valores no negativos descritos anteriormente. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
SVE no está disponible en esta plataforma.

ESTÁNDARES

Linux. Solo arm64.

HISTORIA

Linux 4.15 (arm64).

ADVERTENCIAS

No hay forma de determinar si hay un cambio pendiente en la longitud del vector que aún no ha entrado en vigor.

VER TAMBIÉN

prctl(2), PR_SVE_SET_VL(2const)

Para más información, consulte el archivo fuente del kernel Documentation/arm64/sve.rst (o Documentation/arm64/sve.txt antes de Linux 5.3).
