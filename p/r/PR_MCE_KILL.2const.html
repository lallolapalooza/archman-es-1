PR_MCE_KILL(2const) PR_MCE_KILL(2const)

NOMBRE

PR_MCE_KILL - establecer la política de terminación por corrupción de memoria de comprobación de máquina

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_MCE_KILL, long op, ...);

DESCRIPCIÓN

Establece la política de terminación por corrupción de memoria de comprobación de máquina para el hilo que llama.

op es una de las siguientes operaciones:

PR_MCE_KILL_CLEAR
PR_MCE_KILL_SET

La política se hereda por los hijos.

VALOR DEVUELTO

Al éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
op no es un valor válido.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.32.

VER TAMBIÉN

prctl(2), PR_MCE_KILL_CLEAR(2const), PR_MCE_KILL_SET(2const), PR_MCE_KILL_GET(2const)
