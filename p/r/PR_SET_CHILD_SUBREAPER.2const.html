PR_SET_CHILD_SUBREAPER(2const) PR_SET_CHILD_SUBREAPER(2const)

NOMBRE

PR_SET_CHILD_SUBREAPER - establece/desestablece el atributo "subreaper de hijos" del proceso que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de las constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_CHILD_SUBREAPER, long set);

DESCRIPCIÓN

Si set es distinto de cero, establece el atributo "subreaper de hijos" del proceso que llama; si set es cero, desestablece el atributo.

Un subreaper cumple la función de init(1) para sus procesos descendientes. Cuando un proceso queda huérfano (es decir, su padre inmediato termina), ese proceso será reparentado al ancestro subreaper vivo más cercano. Posteriormente, las llamadas a getppid(2) en el proceso huérfano devolverán ahora el PID del proceso subreaper, y cuando el huérfano termine, será el proceso subreaper el que reciba una señal SIGCHLD y podrá wait(2) por el proceso para descubrir su estado de terminación.

La configuración del atributo "subreaper de hijos" no es heredada por los hijos creados mediante fork(2) y clone(2). La configuración se conserva tras execve(2).

Establecer un proceso como subreaper es útil en marcos de gestión de sesiones donde un grupo jerárquico de procesos es gestionado por un proceso subreaper que necesita ser informado cuando uno de los procesos—por ejemplo, un demonio creado con doble fork—termina (quizás para poder reiniciarlo). Algunos marcos de init(1) (p. ej., systemd(1)) utilizan un proceso subreaper por razones similares.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ESTNDARES

Linux.

HISTORIA

Linux 3.4.
