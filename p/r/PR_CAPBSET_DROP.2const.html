PR_CAPBSET_DROP(2const) PR_CAPBSET_DROP(2const)

NOMBRE

PR_CAPBSET_DROP - eliminar una capacidad del conjunto de límites de capacidad del hilo que realiza la llamada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de las constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_CAPBSET_DROP, long cap);

DESCRIPCIÓN

Elimina la capacidad especificada por cap del conjunto de límites de capacidad del hilo que realiza la llamada. Los hijos del hilo que realiza la llamada heredarán el conjunto de límites reducido.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
Las capacidades de archivo no están habilitadas en el kernel.
EINVAL
cap no especifica una capacidad válida.
EPERM
El llamador no tiene la capacidad CAP_SETPCAP.

VERSIÓNES

Una interfaz de nivel superior basada en esta operación se proporciona en la biblioteca libcap(3) en forma de cap_drop_bound(3).

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.25.

VER TAMBIÉN

prctl(2), PR_CAPBSET_READ(2const), libcap(3), cap_drop_bound(3)
