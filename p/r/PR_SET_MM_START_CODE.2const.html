PR_SET_MM_START_CODE(2const) PR_SET_MM_START_CODE(2const)

NOMBRE

PR_SET_MM_START_CODE, PR_SET_MM_END_CODE - modificar campos de descriptores de mapa de memoria del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_START_CODE, unsigned long addr, 0L, 0L);
int prctl(PR_SET_MM, PR_SET_MM_END_CODE, unsigned long addr, 0L, 0L);

DESCRIPCIÓN

PR_SET_MM_START_CODE
Establece la dirección por encima de la cual el texto del programa puede ejecutarse. El área de memoria correspondiente debe ser legible y ejecutable, pero no escribible ni compartible (ver mprotect(2) y mmap(2) para más información).
PR_SET_MM_END_CODE
Establece la dirección por debajo de la cual el texto del programa puede ejecutarse. El área de memoria correspondiente debe ser legible y ejecutable, pero no escribible ni compartible.

VALOR DE RETORNO

Al tener éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
addr es mayor que TASK_SIZE (el límite en el tamaño del espacio de direcciones del usuario para esta arquitectura).
EINVAL
Los permisos del área de memoria correspondiente no son los requeridos.

ESTANDARES

Linux.

HISTORIAL

Linux 3.3.
