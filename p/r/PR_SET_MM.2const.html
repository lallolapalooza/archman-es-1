PR_SET_MM(2const) PR_SET_MM(2const)

NOMBRE

PR_SET_MM - modificar los campos del descriptor del mapa de memoria del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, long op, ...);

DESCRIPCIÓN

Modifica ciertos campos del descriptor del mapa de memoria del kernel del proceso que llama. Usualmente estos campos son establecidos por el kernel y el cargador dinámico (ver ld.so(8) para más información) y una aplicación regular no debería usar esta característica. Sin embargo, hay casos, como programas auto-modificables, donde un programa podría encontrar útil cambiar su propio mapa de memoria.

El proceso que llama debe tener la capacidad CAP_SYS_RESOURCE. El valor en op es una de las opciones siguientes.

PR_SET_MM_START_CODE
PR_SET_MM_END_CODE
PR_SET_MM_START_DATA
PR_SET_MM_END_DATA
PR_SET_MM_START_STACK
PR_SET_MM_START_BRK
PR_SET_MM_BRK
PR_SET_MM_ARG_START
PR_SET_MM_ARG_END
PR_SET_MM_ENV_START
PR_SET_MM_ENV_END
PR_SET_MM_AUXV
PR_SET_MM_EXE_FILE
PR_SET_MM_MAP
PR_SET_MM_MAP_SIZE

VALOR DE RETORNO

Al éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
op no es un valor válido.
EPERM
El llamador no tiene la capacidad CAP_SYS_RESOURCE.

ESTÁNDARES

Linux.

HISTORIA

Linux 3.3.

Antes de Linux 3.10, esta característica solo está disponible si el kernel se compila con la opción CONFIG_CHECKPOINT_RESTORE habilitada.
