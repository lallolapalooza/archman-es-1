PR_GET_NO_NEW_PRIVS(2const) PR_GET_NO_NEW_PRIVS(2const)

NOMBRE

PR_GET_NO_NEW_PRIVS - obtener el atributo no_new_privs del hilo que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_NO_NEW_PRIVS, 0L, 0L, 0L, 0L);

DESCRIPCIÓN

Devuelve el valor del atributo no_new_privs para el hilo que llama. Un valor de 0 indica el comportamiento normal de execve(2). Un valor de 1 indica que execve(2) operará en el modo de restricción de privilegios descrito en PR_SET_NO_NEW_PRIVS(2const).

VALOR DE RETORNO

En caso de éxito, PR_GET_NO_NEW_PRIVS devuelve el valor booleano descrito anteriormente. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ARCHIVOS

/proc/pid/status
Desde Linux 4.10, el valor del atributo no_new_privs de un hilo puede verse a través del campo NoNewPrivs en este archivo.

ESTÁNDARES

Linux.

HISTORIA

Linux 3.5.

VER TAMBIÉN

prctl(2), PR_SET_NO_NEW_PRIVS(2const)
