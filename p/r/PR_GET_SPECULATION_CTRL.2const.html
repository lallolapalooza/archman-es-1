PR_GET_SPECULATION_CTRL(2const) PR_GET_SPECULATION_CTRL(2const)

NOMBRE

PR_GET_SPECULATION_CTRL - obtener el estado de una mala conducta de especulación para el hilo que realiza la llamada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_SPECULATION_CTRL, long misfeature, 0L, 0L, 0L);

DESCRIPCIÓN

Devuelve el estado de la mala conducta de especulación especificada en misfeature.

Actualmente, misfeature debe ser una de las siguientes:

PR_SPEC_STORE_BYPASS
Obtener el estado de la mala conducta de bypass de almacenamiento especulativo.
PR_SPEC_INDIRECT_BRANCH (desde Linux 4.20)
Obtener el estado de la mala conducta de especulación de ramificación indirecta.

El valor de retorno usa los bits 0-4 con el siguiente significado:

PR_SPEC_PRCTL
La mitigación se puede controlar por hilo mediante PR_SET_SPECULATION_CTRL(2const).
PR_SPEC_ENABLE
La característica de especulación está habilitada, la mitigación está deshabilitada.
PR_SPEC_DISABLE
La característica de especulación está deshabilitada, la mitigación está habilitada.
PR_SPEC_FORCE_DISABLE
Igual que PR_SPEC_DISABLE pero no se puede deshacer.
PR_SPEC_DISABLE_NOEXEC (desde Linux 5.1)
Igual que PR_SPEC_DISABLE, pero el estado se borrará en execve(2).

Si todos los bits son 0, entonces la CPU no se ve afectada por la mala conducta de especulación.

Si PR_SPEC_PRCTL está establecido, entonces el control por hilo de la mitigación está disponible. Si no está establecido, PR_SET_SPECULATION_CTRL(2const) para la mala conducta de especulación fallará.

VALOR DE RETORNO

En caso de éxito, PR_GET_SPECULATION_CTRL devuelve el valor no negativo descrito anteriormente. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

ENODEV
El kernel o la CPU no admiten la mala conducta de especulación solicitada misfeature.

ESTANDARES

Linux.

HISTORIA

Linux 4.17.

VER TAMBIÉN

prctl(2), PR_SET_SPECULATION_CTRL(2const)
