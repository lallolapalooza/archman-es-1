PR_SET_DUMPABLE(2const) PR_SET_DUMPABLE(2const)

NOMBRE

PR_SET_DUMPABLE - establece el atributo "dumpable" del proceso que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_DUMPABLE, long dumpable);

DESCRIPCIÓN

Establece el estado del atributo "dumpable", que determina si se generan volcados de núcleo (core dumps) para el proceso que llama al recibir una señal cuyo comportamiento predeterminado es producir un volcado de núcleo.

dumpable debe ser 0L (SUID_DUMP_DISABLE, el proceso no es volcable) o 1L (SUID_DUMP_USER, el proceso es volcable).

Normalmente, el atributo "dumpable" se establece en 1. Sin embargo, se restablece al valor actual contenido en el archivo /proc/sys/fs/suid_dumpable (que por defecto tiene el valor 0), en las siguientes circunstancias:

•
Se cambia el ID de usuario o grupo efectivo del proceso.
•
Se cambia el ID de usuario o grupo del sistema de archivos del proceso (véase credentials(7)).
•
El proceso ejecuta (execve(2)) un programa set-user-ID o set-group-ID, lo que resulta en un cambio del ID de usuario efectivo o del ID de grupo efectivo.
•
El proceso ejecuta (execve(2)) un programa que tiene capacidades de archivo (véase capabilities(7)), pero solo si las capacidades permitidas obtenidas exceden las ya permitidas para el proceso.

Los procesos que no son volcables no pueden ser adjuntados mediante ptrace(2) PTRACE_ATTACH; véase ptrace(2) para más detalles.

Si un proceso no es volcable, la propiedad de los archivos en el directorio /proc/pid del proceso se ve afectada como se describe en proc_pid(5).

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
arg2 no es ni SUID_DUMP_DISABLE ni SUID_DUMP_USER.

ARCHIVOS

/proc/sys/fs/suid_dumpable
/proc/pid/

ESTÁNDARES

Linux.

HISTORIA

Linux 2.3.20.

Entre Linux 2.6.13 y Linux 2.6.17, también se permitía el valor 2L, que hacía que cualquier binario que normalmente no se volcara fuera volcado legible solo por root; por razones de seguridad, esta característica ha sido eliminada. (Véase también la descripción de /proc/sys/fs/suid_dumpable en proc_sys_fs(5).)
