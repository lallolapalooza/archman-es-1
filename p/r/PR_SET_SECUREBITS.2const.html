PR_SET_SECUREBITS(2const) PR_SET_SECUREBITS(2const)

NOMBRE

PR_SET_SECUREBITS - establecer las banderas "securebits" del hilo llamador

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_SECUREBITS, unsigned long flags);

DESCRIPCIÓN

Establece las banderas "securebits" del hilo llamador al valor suministrado en flags. Ver capabilities(7).

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
flags no es un valor válido.
EPERM
El llamador no tiene la capacidad CAP_SETPCAP, o intentó desmarcar una bandera "bloqueada", o intentó establecer una bandera cuya bandera correspondiente "bloqueada" estaba establecida (ver capabilities(7)).

ESTANDARES

Linux.

HISTORIA

Linux 2.6.26.

VER TAMBIÉN

prctl(2), PR_GET_SECUREBITS(2const), capabilities(7)
