PR_PAC_RESET_KEYS(2const) PR_PAC_RESET_KEYS(2const)

NOMBRE

PR_PAC_RESET_KEYS - restablece las claves de autenticación de puntero del hilo de llamada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_PAC_RESET_KEYS, unsigned long keys, 0L, 0L, 0L);

DESCRIPCIÓN

Restablece de forma segura las claves de autenticación de puntero del hilo a nuevos valores aleatorios generados por el kernel.

El conjunto de claves que se restablecerán se especifica mediante keys, que debe ser un OR lógico de cero o más de los siguientes:

PR_PAC_APIAKEY
clave de autenticación de instrucciones A
PR_PAC_APIBKEY
clave de autenticación de instrucciones B
PR_PAC_APDAKEY
clave de autenticación de datos A
PR_PAC_APDBKEY
clave de autenticación de datos B
PR_PAC_APGAKEY
clave genérica de autenticación “A”.
(Sí, señoras y señores, efectivamente no hay una clave B genérica.)

Como caso especial, si keys es cero, entonces se restablecen todas las claves. Dado que se podrían agregar nuevas claves en el futuro, esta es la forma recomendada de limpiar las claves existentes al establecer un contexto de ejecución limpio.

No es necesario usar PR_PAC_RESET_KEYS como preparación para llamar a execve(2), ya que execve(2) restablece todas las claves de autenticación de puntero.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece la variable errno para indicar el error.

ERRORES

EINVAL
keys contiene bits establecidos que son inválidos o no compatibles en esta plataforma.

ESTÁNDARES

Linux. Solo arm64.

HISTORIA

Linux 5.0 (arm64).

ADVERTENCIAS

Debido a que el compilador o el entorno de ejecución pueden estar utilizando algunas o todas las claves, un PR_PAC_RESET_KEYS exitoso puede provocar la caída del proceso que realiza la llamada. Las condiciones para usarlo de forma segura son complejas y dependen del sistema. No lo use a menos que sepa lo que está haciendo.

VER TAMBIÉN

prctl(2)

Para más información, consulte el archivo fuente del kernel Documentation/arm64/pointer-authentication.rst (o Documentation/arm64/pointer-authentication.txt antes de Linux 5.3).
