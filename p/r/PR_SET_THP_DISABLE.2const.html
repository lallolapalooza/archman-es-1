PR_SET_THP_DISABLE(2const) PR_SET_THP_DISABLE(2const)

NOMBRE

PR_SET_THP_DISABLE - establece el estado del indicador "THP disable" para el hilo que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de las constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_THP_DISABLE, long flag, 0L, 0L, 0L);

DESCRIPCIÓN

Establece el estado del indicador "THP disable" para el hilo que llama. Si flag tiene un valor distinto de cero, el indicador se establece, de lo contrario se borra.

Establecer este indicador proporciona un método para deshabilitar las páginas grandes transparentes (THP) para trabajos cuyo código no puede ser modificado, y donde el uso de un hook de malloc(3) con madvise(2) no es una opción (es decir, datos asignados estáticamente). La configuración del indicador "THP disable" es heredada por un hijo creado a través de fork(2) y se conserva a través de execve(2).

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ESTÁNDARES

Linux.

HISTORIAL

Linux 3.15.
