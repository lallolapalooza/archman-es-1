Facilidades para imprimir excepciones e inspeccionar el stack de llamadas actual.

type t = exn = ..

El tipo de valores de excepción.

val to_string : exn -> string

Printexc.to_string e devuelve una representación de la excepción e como cadena.

val to_string_default : exn -> string

Printexc.to_string_default e devuelve una representación de la excepción e como cadena, ignorando todos los impresores registrados de excepciones.

Desde 4.09

val print : ('a -> 'b) -> 'a -> 'b

Printexc.print fn x aplica fn a x y devuelve el resultado. Si la evaluación de fn x genera una excepción, se imprime en la salida estándar el nombre de la excepción y se eleva de nuevo. El uso típico es capturar y reportar excepciones que escapan de una aplicación de funciones.

val catch : ('a -> 'b) -> 'a -> 'b

Desactivado. Esta función ya no es necesaria.

Printexc.catch fn x es similar a Printexc.print, pero termina el programa con código de salida 2 después de imprimir la excepción no capturada. Esta función está desactivada: el sistema de runtime ahora puede imprimir excepciones no capturadas con una precisión igual a Printexc.catch. Además, llamar a Printexc.catch hace más difícil seguir el lugar de la excepción usando el depurador o la facilidad de backtrace. Por lo tanto, no se debe usar Printexc.catch en nuevos programas.

val print_backtrace : out_channel -> unit

Printexc.print_backtrace oc imprime el backtrace de excepción en el canal de salida oc. El backtrace lista las ubicaciones del programa donde se lanzó la excepción más reciente y donde fue propagada a través de llamadas a funciones.

Si la llamada no está dentro de un manejador de excepción, el backtrace devuelto no está especificado. Si la llamada es después de algún código de captura de excepciones (antes del manejador o durante la coincidencia de la excepción en el manejador), el backtrace puede corresponder a una excepción posterior a la que fue manejada.

Desde 3.11

val get_backtrace : unit -> string

Printexc.get_backtrace () devuelve una cadena que contiene el mismo backtrace de excepción que Printexc.print_backtrace imprimiría. La misma restricción de uso que Printexc.print_backtrace.

Desde 3.11

val record_backtrace : bool -> unit

Printexc.record_backtrace b activa o desactiva el registro de backtraces de excepción. Por defecto, no se registran los backtraces, a menos que el parámetro b se indique a través de la variable de entorno OCAMLRUNPARAM.

Desde 3.11

val backtrace_status : unit -> bool

Printexc.backtrace_status() devuelve true si los backtraces de excepción están actualmente registrados, false si no.

Desde 3.11

val register_printer : (exn -> string option) -> unit

Printexc.register_printer fn registra fn como impresor de excepción. El impresor debe devolver None o lanzar una excepción si no sabe cómo convertir la excepción pasada, y Some con s si puede convertir la excepción pasada. Las excepciones lanzadas por el impresor se ignoran.

Cuando se convierte una excepción en una cadena, los impresores se invocan en el orden inverso de su registro, hasta que un impresor devuelva un valor Some s (si no existe tal impresor, el runtime usará un impresor genérico).

Cuando se usa este mecanismo, se debe tener cuidado de que un backtrace de excepción está asociado al hilo que vio la excepción, y no a la excepción misma. En realidad, eso significa que el código relacionado con fn no debe usar el backtrace si ha lanzado una excepción antes de sí mismo.

Desde 3.11.2

val use_printers : exn -> string option

Printexc.use_printers e devuelve None si no hay impresores registrados y Some s con s la cadena resultante de lo contrario.

Desde 4.09

Backtraces de raw

type raw_backtrace

El tipo raw_backtrace almacena un backtrace en un formato de bajo nivel, que puede ser convertido a una forma útil usando raw_backtrace_entries y backtrace_slots_of_raw_entry a continuación.

La conversión de backtraces a backtrace_slot es más lenta que la captura de los backtraces. Si un programa procesa muchos backtraces, puede ser útil usar raw_backtrace para evitar o retrasar la conversión.

Los backtraces de raw no pueden ser serializados. Si necesitas serialización, deberías usar el array devuelto por la función backtrace_slots de la sección siguiente.

Desde 4.01

type raw_backtrace_entry = private int

Un raw_backtrace_entry es un elemento de un raw_backtrace.

Cada raw_backtrace_entry es un entero opaco, cuyo valor no es estable entre diferentes programas, o incluso entre diferentes ejecuciones del mismo binario.

Un raw_backtrace_entry puede convertirse a una forma útil usando backtrace_slots_of_raw_entry. Debe notarse que, debido a la inlining, un solo raw_backtrace_entry puede convertirse en varios backtrace_slot. Dado que los valores de un raw_backtrace_entry no son estables, no pueden ser serializados. Si se deben convertir, la conversión debe realizarse por el proceso que los generó.

De nuevo debido a la inlining, puede haber múltiples valores distintos de raw_backtrace_entry que convergen en los mismos backtrace_slot. Sin embargo, si dos raw_backtrace_entry son iguales como enteros, representan los mismos backtrace_slot.

Desde 4.12

NAME

Printexc — exception printing and backtrace manipulation

Module

Printexc is available since 3.07.

The functions of the module Printexc are available in the Pervasives module from 4.00 onwards.

Documentation

This module provides functions to print exceptions and to manipulate raw backtraces.

The functions catch_break, register_printer, get_callstack, backtrace_of_channel, and record_backtrace are available since 3.07.

The functions convert_raw_backtrace_slot, exn_slot_id, exn_slot_name, get_raw_backtrace_slot, raw_backtrace_length, backtrace_slots, backtrace_slots_of_raw_entry, get_raw_backtrace_next_slot, convert_raw_backtrace, and get_raw_backtrace are available since 4.02.

The functions catch_break, get_callstack, get_raw_backtrace_next_slot, and convert_raw_backtrace_slot require the program to be compiled with the -g option for the backtrace information to be available.

Exception printing

val install_printer : (exn -> string option) -> unit

Installs a new exception printer. When an exception is printed, the installed printers are called in reverse order of installation, until one of them returns Some string. If no printer succeeds, the default printer is used.

Printers are uninstalled when the program exits.

Since 3.07

val default_printer : exn -> string option

The default exception printer, used if no user-defined printer succeeds.

Since 3.12

val print_exception : exn -> unit

Prints the given exception to the standard error channel.

Since 3.07

val to_string : exn -> string

Converts an exception to a string. This is equivalent to calling default_printer and returning the string, or raising an exception if the printer returns None (which should not happen for default_printer).

Since 3.12

val catch_break : bool -> unit

When true, Ctrl+C raises an exception Sys.Break. When false, Ctrl+C terminates the program.

The default value is true in interactive mode and false in compiled mode.

Since 3.07

val register_printer : (exn -> string option) -> unit

Register a function f that will be called when an exception is raised. If f returns Some s, then s is printed to standard error and the exception processing stops. If f returns None, the next printer is called. If all printers return None, the default printer is used. The printers are called in the reverse order of registration.

This function is intended to be used for debugging purposes. Printers are unregistered automatically when the program terminates.

Since 3.07

Backtrace manipulation

val get_callstack : int -> string array

Returns an array of strings representing the call stack. The argument specifies the maximum number of frames to capture. A value of 0 captures the entire stack. This function requires the program to be compiled with -g.

Since 3.07

val record_backtrace : bool -> unit

If called with true, enables recording of backtraces for all exceptions. If called with false, disables recording. The default is false. Recording backtraces has a performance overhead.

Since 3.07

val get_backtrace : unit -> raw_backtrace

Returns the raw backtrace associated with the current exception context. If no exception is being handled, or if backtraces are not recorded (see record_backtrace), an empty raw backtrace is returned. This function requires the program to be compiled with -g.

Since 4.02

val backtrace_of_channel : in_channel -> raw_backtrace

Returns the raw backtrace associated with the given input channel, if available. This is useful for debugging interactions between processes.

Since 4.02

val convert_raw_backtrace : raw_backtrace -> backtrace_slot array option

Converts a raw backtrace into an array of user-friendly backtrace slots. Returns None if the raw backtrace cannot be converted (e.g., if it was not compiled with debug information).

Since 4.02

val raw_backtrace_to_string : raw_backtrace -> string

Converts a raw backtrace to a string representation. This is primarily for debugging purposes.

Since 4.02

When fn is called all the functions registered with at_exit have already been called. Because of this you must make sure any output channel fn writes on is flushed.

Also note that exceptions raised by user code in the interactive toplevel are not passed to this function as they are caught by the toplevel itself.

If fn raises an exception, both the exceptions passed to fn and raised by fn will be printed with their respective backtrace.

Since 4.02

Manipulation of backtrace information

These functions are used to traverse the slots of a raw backtrace and extract information from them in a programmer-friendly format.

type backtrace_slot

The abstract type backtrace_slot represents a single slot of a backtrace.

Since 4.02

val backtrace_slots : raw_backtrace -> backtrace_slot array option

Returns the slots of a raw backtrace, or None if none of them contain useful information.

In the return array, the slot at index 0 corresponds to the most recent function call, raise, or primitive get_backtrace call in the trace.

Some possible reasons for returning None are as follow:

-none of the slots in the trace come from modules compiled with debug information ( -g )

-the program is a bytecode program that has not been linked with debug information enabled ( ocamlc -g )

Since 4.02

val backtrace_slots_of_raw_entry : raw_backtrace_entry -> backtrace_slot array option

Returns the slots of a single raw backtrace entry, or None if this entry lacks debug information.

Slots are returned in the same order as backtrace_slots : the slot at index 0 is the most recent call, raise, or primitive, and subsequent slots represent callers.

Since 4.02

Raw backtrace slots

type raw_backtrace_slot

This type is used to iterate over the slots of a raw_backtrace . For most purposes, backtrace_slots_of_raw_entry is easier to use.

Like raw_backtrace_entry , values of this type are process-specific and must absolutely not be marshalled, and are unsafe to use for this reason (marshalling them may not fail, but un-marshalling and using the result will result in undefined behavior).

Elements of this type can still be compared and hashed: when two elements are equal, then they represent the same source location (the converse is not necessarily true in presence of inlining, for example).

Since 4.02

val raw_backtrace_length : raw_backtrace -> int

raw_backtrace_length bckt returns the number of slots in the backtrace bckt .

Since 4.02

val get_raw_backtrace_slot : raw_backtrace -> int -> raw_backtrace_slot

get_raw_backtrace_slot bckt pos returns the slot in position pos in the backtrace bckt .

Since 4.02

val convert_raw_backtrace_slot : raw_backtrace_slot -> backtrace_slot

Extracts the user-friendly backtrace_slot from a low-level raw_backtrace_slot .

Since 4.02

val get_raw_backtrace_next_slot : raw_backtrace_slot -> raw_backtrace_slot option

get_raw_backtrace_next_slot slot returns the next slot inlined, if any.

Sample code to iterate over all frames (inlined and non-inlined):

      (* Iterate over inlined frames *)
      let rec iter_raw_backtrace_slot f slot =
        f slot;
        match get_raw_backtrace_next_slot slot with
        | None -> ()
        | Some slot' -> iter_raw_backtrace_slot f slot'
      (* Iterate over stack frames *)
      let iter_raw_backtrace f bt =
        for i = 0 to raw_backtrace_length bt - 1 do
          iter_raw_backtrace_slot f (get_raw_backtrace_slot bt i)
        done

Since 4.04

Exception slots

val exn_slot_id : exn -> int

Printexc.exn_slot_id returns an integer which uniquely identifies the constructor used to create the exception value exn (in the current runtime).

Since 4.02

val exn_slot_name : exn -> string

Printexc.exn_slot_name exn returns the internal name of the constructor used to create the exception value exn .
