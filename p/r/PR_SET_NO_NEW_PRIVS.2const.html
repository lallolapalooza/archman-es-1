PR_SET_NO_NEW_PRIVS(2const) PR_SET_NO_NEW_PRIVS(2const)

NOMBRE

PR_SET_NO_NEW_PRIVS - establecer el atributo no_new_privs del hilo llamante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_NO_NEW_PRIVS, 1L, 0L, 0L, 0L);

DESCRIPCIÓN

Establece el atributo no_new_privs del hilo llamante. Con no_new_privs establecido a 1, execve(2) promete no conceder privilegios para hacer nada que no se pudiera haber hecho sin la llamada execve(2) (por ejemplo, haciendo que los bits de modo set-user-ID y set-group-ID, y las capacidades de archivo no sean funcionales).

Una vez establecido, el atributo no_new_privs no se puede desactivar. El establecimiento de este atributo se hereda por los hijos creados por fork(2) y clone(2), y se conserva a través de execve(2).

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El segundo argumento no es igual a 1L.

FICHEROS

/proc/pid/status
Desde Linux 4.10, el valor del atributo no_new_privs de un hilo puede verse a través del campo NoNewPrivs en este archivo.

ESTANDARES

Linux.

HISTORIA

Linux 3.5.

VER TAMBIÉN

prctl(2), PR_GET_NO_NEW_PRIVS(2const), seccomp(2)

Para más información, consulte el archivo fuente del kernel Documentation/userspace-api/no_new_privs.rst (o Documentation/prctl/no_new_privs.txt antes de Linux 4.13).
