PR_GET_MDWE(2const) PR_GET_MDWE(2const)

NOMBRE

PR_GET_MDWE - obtener la máscara de protección de Memoria-Denegada-Escritura-Ejecución para el proceso llamante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_MDWE, 0L, 0L, 0L, 0L);

DESCRIPCIÓN

Devuelve la máscara de protección de Memoria-Denegada-Escritura-Ejecución del proceso llamante. Véase PR_SET_MDWE(2const) para obtener información sobre los bits de la máscara de protección.

VALOR DE RETORNO

En caso de éxito, se devuelve un valor no negativo. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 6.3.

VER TAMBIÉN

prctl(2), PR_SET_MDWE(2const)
