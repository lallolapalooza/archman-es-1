PR_SET_FPEXC(2const) PR_SET_FPEXC(2const)

NOMBRE

PR_SET_FPEXC - establece el modo de excepción de punto flotante

LIBRERÍA

Librería C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_FPEXC, unsigned long modo);

DESCRIPCIÓN

Establece el modo de excepción de punto flotante a modo. modo puede ser uno de los siguientes valores.

PR_FP_EXC_SW_ENABLE
Usar FPEXC para las habilitaciones de excepciones FP.
PR_FP_EXC_DIV
Usar FPEXC para división por cero en punto flotante.
PR_FP_EXC_OVF
Usar FPEXC para desbordamiento en punto flotante.
PR_FP_EXC_UND
Usar FPEXC para subdesbordamiento en punto flotante.
PR_FP_EXC_RES
Usar FPEXC para resultado inexacto en punto flotante.
PR_FP_EXC_INV
Usar FPEXC para operación inválida en punto flotante.
PR_FP_EXC_DISABLED
Usar FPEXC para excepciones FP deshabilitadas.
PR_FP_EXC_NONRECOV
Usar FPEXC para modo de excepción asíncrono no recuperable.
PR_FP_EXC_ASYNC
Usar FPEXC para modo de excepción asíncrono recuperable.
PR_FP_EXC_PRECISE
Usar FPEXC para modo de excepción preciso.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
modo no es un valor válido.

ESTANDARES

Linux. Solo PowerPC.

HISTORIA

Linux 2.4.21, 2.5.32. (PowerPC)

VER TAMBIÉN

prctl(2), PR_GET_FPEXC(2const)
