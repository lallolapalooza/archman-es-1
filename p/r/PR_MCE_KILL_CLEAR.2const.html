PR_MCE_KILL_CLEAR(2const) PR_MCE_KILL_CLEAR(2const)

NOMBRE

PR_MCE_KILL_CLEAR - borrar la política de finalización por corrupción de memoria MCE

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_MCE_KILL, PR_MCE_KILL_CLEAR, 0L, 0L, 0L);

DESCRIPCIÓN

Borra la política de finalización por corrupción de memoria del hilo y utiliza la política predeterminada a nivel de sistema.

VALOR DE RETORNO

Al éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ARCHIVOS

/proc/sys/vm/memory_failure_early_kill
Este archivo define el valor predeterminado a nivel de sistema.

ESTANDARES

Linux.

HISTORIA

Linux 2.6.32.

VER TAMBIÉN

prctl(2), PR_MCE_KILL(2const), proc_sys_vm(5)
