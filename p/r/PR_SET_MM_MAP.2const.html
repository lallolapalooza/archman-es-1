PR_SET_MM_MAP(2const) PR_SET_MM_MAP(2const)

NOMBRE

PR_SET_MM_MAP, PR_SET_MM_MAP_SIZE - modificar los campos del descriptor del mapa de memoria del kernel

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_MAP,
          struct prctl_mm_map *map, unsigned long size, 0L);
int prctl(PR_SET_MM, PR_SET_MM_MAP_SIZE, unsigned int *size, 0L, 0L);

DESCRIPCIÓN

PR_SET_MM_MAP
Proporciona acceso de una sola vez a todas las direcciones modificables con PR_SET_MM(2const) pasando una struct prctl_mm_map (como se define en <linux/prctl.h>). El argumento size debe proporcionar el tamaño de la estructura.
PR_SET_MM_MAP_SIZE
Devuelve (a través del argumento size) el tamaño de la struct prctl_mm_map que espera el kernel. Esto permite al espacio de usuario encontrar una estructura compatible.

Estas características solo están disponibles si el kernel está compilado con la opción CONFIG_CHECKPOINT_RESTORE habilitada.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El tercer argumento es una dirección inválida.

ESTÁNDARES

Linux.

HISTORIA

Linux 3.18.
