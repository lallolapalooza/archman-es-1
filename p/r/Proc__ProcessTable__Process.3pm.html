Proc::ProcessTable::Process(3) Documentación de Perl aportada por el usuario Proc::ProcessTable::Process(3)

NOMBRE

Proc::ProcessTable::Process - objetos de proceso de Perl

SINOPSIS

$proceso->kill(9);
$proceso->priority(19);
$proceso->pgrp(500);
$uid = $proceso->uid;
...

DESCRIPCIÓN

Este es un módulo stub para proporcionar acceso a atributos de proceso OO para Proc::ProcessTable. Los objetos Proc::ProcessTable::Process son construidos directamente por Proc::ProcessTable; no hay método constructor, solo accedentes.

MÉTODOS

kill
Envía una señal al proceso; solo un envoltorio estético para el kill de perl. Toma la señal (nombre o número) como argumento. Devuelve el número de procesos señalados.
priority
Accedente obtener/establecer; si se llama con un argumento numérico, intenta restablecer la prioridad del proceso a ese número usando la función <B>setpriority de perl. Devuelve la prioridad del proceso.
pgrp
Igual que lo anterior para el grupo de procesos.
todos los demás métodos...
son simples accedentes que recuperan los atributos del proceso para los que se nombran. Actualmente soportados son: 
uid         UID del proceso
gid         GID del proceso
euid        UID efectivo del proceso           (Solo Solaris)
egid        GID efectivo del proceso           (Solo Solaris)
pid         ID del proceso
ppid        ID del proceso padre
spid        ID sprod                           (Solo IRIX)
pgrp        grupo de procesos
sess        ID de sesión
cpuid       ID de CPU del procesador en el que se ejecuta     (Solo IRIX)
priority    prioridad del proceso
ttynum      número de tty del proceso
flags       flags del proceso
minflt      fallos de página menores           (Solo Linux)
cminflt     fallos de página menores del hijo            (Solo Linux)
majflt      fallos de página mayores           (Solo Linux)
cmajflt     fallos de página mayores del hijo            (Solo Linux)
utime       tiempo en modo usuario (1/100s de segundo) (Solo Linux)
stime       tiempo en modo kernel            (Solo Linux)
cutime      utime del hijo                        (Solo Linux)
cstime      stime del hijo                        (Solo Linux)
time        tiempo de usuario + sistema          
ctime       tiempo de usuario + sistema del hijo
timensec    parte de nanosegundos de usuario + sistema     (Solo Solaris)
ctimensec   parte de nanosegundos de usuario + sistema del hijo (Solo Solaris)
qtime       tiempo acumulado de cpu                (Solo IRIX)
size        tamaño de memoria virtual (bytes)
rss         tamaño del conjunto residente (bytes)
wchan       dirección de la llamada al sistema actual 
fname       nombre del archivo
start       hora de inicio (segundos desde la época)
pctcpu      porcentaje de cpu usado desde que se inició el proceso
state       estado del proceso
pctmem      porcentaje de memoria                     
cmndline    línea de comando completa del proceso
ttydev      ruta del tty del proceso
clname      nombre de la clase de planificación              (Solo IRIX)

Consulte los archivos "README.osname" en la distribución para obtener información más actualizada.
