Proc::ProcessTable(3) Documentación de Perl aportada por el usuario Proc::ProcessTable(3)

NOMBRE

Proc::ProcessTable - Extensión de Perl para acceder a la tabla de procesos de Unix

SINOPSIS

use Proc::ProcessTable;
my $p = Proc::ProcessTable->new( 'cache_ttys' => 1 ); 
my @fields = $p->fields;
my $ref = $p->table;

DESCRIPCIÓN

Interfaz de Perl a la tabla de procesos de Unix.

MÉTODOS

new
Crea un nuevo objeto ProcessTable. El constructor puede aceptar las siguientes banderas:

enable_ttys -- hace que el constructor utilice el código de determinación de tty, que es el comportamiento por defecto. Establecer esto a 0 deshabilita este código, evitando así que el módulo recorra el árbol de dispositivos, que en algunos sistemas puede ser bastante grande y/o contener rutas de dispositivo inválidas (por ejemplo, Solaris no limpia las entradas de dispositivo inválidas cuando se intercambian discos). Si esto se especifica con cache_ttys, se genera una advertencia y cache_ttys se anula para que sea falso.

cache_ttys -- hace que el constructor busque y utilice un archivo que almacene en caché un mapeo de nombres de tty a números de dispositivo, y que cree el archivo si no existe. Esta característica requiere el módulo Storable. Por defecto, el nombre del archivo de caché consiste en un prefijo /tmp/TTYDEVS_ y una etiqueta de orden de bytes. El nombre del archivo se puede acceder (y cambiar) a través de $Proc::ProcessTable::TTYDEVSFILE.

fields
Devuelve una lista de los nombres de campo compatibles con el módulo en la arquitectura actual.
table
Lee la tabla de procesos y devuelve una referencia a un array de objetos Proc::ProcessTable::Process. Los atributos de un objeto de proceso se devuelven mediante accesores con el nombre del atributo; por ejemplo, para obtener el uid de un proceso, simplemente haz:

$process->uid

Los métodos priority y pgrp también permiten establecer valores, ya que estos están directamente soportados por funciones internas de perl.

EJEMPLOS

# Una versión barata y sucia de ps
use Proc::ProcessTable;
my $FORMAT = "%-6s %-10s %-8s %-24s %s\n";
my $t = Proc::ProcessTable->new;
printf($FORMAT, "PID", "TTY", "STAT", "START", "COMMAND"); 
foreach my $p ( @{$t->table} ){
  printf($FORMAT, 
         $p->pid, 
         $p->ttydev, 
         $p->state, 
         scalar(localtime($p->start)), 
         $p->cmndline);
}
# Volcar toda la información de la tabla de procesos actual
use Proc::ProcessTable;
my $t = Proc::ProcessTable->new;
foreach my $p (@{$t->table}) {
 print "--------------------------------\n";
 foreach my $f ($t->fields){
   print $f, ":  ", $p->{$f}, "\n";
 }
}
