PR_TASK_PERF_EVENTS_DISABLE(2const) PR_TASK_PERF_EVENTS_DISABLE(2const)

NOMBRE

PR_TASK_PERF_EVENTS_DISABLE, PR_TASK_PERF_EVENTS_ENABLE - desactiva o activa los contadores de rendimiento adjuntos al proceso llamante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_TASK_PERF_EVENTS_DISABLE);
int prctl(PR_TASK_PERF_EVENTS_ENABLE);

DESCRIPCIÓN

PR_TASK_PERF_EVENTS_DISABLE
Desactiva todos los contadores de rendimiento adjuntos al proceso llamante, independientemente de si los contadores fueron creados por este proceso u otro. Los contadores de rendimiento creados por el proceso llamante para otros procesos no se ven afectados.
PR_TASK_PERF_EVENTS_ENABLE
Lo contrario de PR_TASK_PERF_EVENTS_DISABLE; activa los contadores de rendimiento adjuntos al proceso llamante.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y la variable errno se establece para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.31.

Originalmente llamado PR_TASK_PERF_COUNTERS_DISABLE y PR_TASK_PERF_COUNTERS_ENABLE; renombrado (conservando el mismo valor numérico) en Linux 2.6.32.

VER TAMBIÉN

prctl(2)

Para más información sobre contadores de rendimiento, consulta el archivo fuente del kernel de Linux tools/perf/design.txt.
