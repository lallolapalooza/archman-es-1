PR_FUTEX_HASH(2const) PR_FUTEX_HASH(2const)

NOMBRE

PR_FUTEX_HASH - configurar el hash privado de futex

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_FUTEX_HASH, unsigned long op, ...);

DESCRIPCIÓN

Configura los atributos para el hash subyacente utilizado por la familia de operaciones de futex(2). El kernel de Linux utiliza un hash para distribuir las solicitudes de futex(2) no relacionadas a diferentes estructuras de datos para reducir la contención de bloqueos. Las solicitudes no relacionadas son aquellas que no están relacionadas entre sí porque usan una palabra futex diferente. La estructura de datos contiene la representación en el kernel de la operación y realiza un seguimiento de los usuarios actuales que están en cola y esperan un despertar. También proporciona sincronización de los esperadores contra los despertadores. El tamaño del hash global se determina en el momento del arranque y se basa en el número de CPU en el sistema. Debido a colisiones de hash, dos solicitudes de futex(2) no relacionadas pueden compartir el mismo bucket de hash. Esto a su vez puede provocar retrasos en la operación de futex(2) debido a la contención de bloqueo al acceder a la estructura de datos. Estos retrasos pueden ser problemáticos en un sistema de tiempo real, ya que procesos aleatorios pueden compartir bloqueos en el kernel y no es determinista qué proceso estará involucrado.

Linux 6.17 implementa un hash privado por proceso que es utilizado por todas las operaciones de futex(2) que especifican la opción FUTEX_PRIVATE_FLAG como parte de la operación. Sin ninguna configuración, el kernel asignará 16 ranuras de hash una vez que se haya creado el primer hilo. Si el proceso continúa creando hilos, el kernel intentará redimensionar el hash privado basándose en el número de hilos y las CPU disponibles en el sistema. El kernel solo aumentará el tamaño y se asegurará de que no exceda el tamaño del hash global.

El usuario puede configurar el tamaño del hash privado, lo que también deshabilitará el redimensionamiento automático proporcionado por el kernel.

El valor en op es una de las siguientes opciones.

PR_FUTEX_HASH_GET_SLOTS
PR_FUTEX_HASH_SET_SLOTS

VALOR DE RETORNO

En caso de éxito, estas llamadas devuelven un valor no negativo. En caso de error, se devuelve -1 y se establece errno para indicar el error.
