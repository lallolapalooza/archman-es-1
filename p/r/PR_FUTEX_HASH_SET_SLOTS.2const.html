PR_FUTEX_HASH_SET_SLOTS(2const) PR_FUTEX_HASH_SET_SLOTS(2const)

NOMBRE

PR_FUTEX_HASH_SET_SLOTS - establece el tamaño del hash privado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_FUTEX_HASH, PR_FUTEX_HASH_SET_SLOTS,
          unsigned long size, unsigned long flags);

DESCRIPCIÓN

Establece el número de ranuras a utilizar para el hash privado.

size
Especifica el tamaño del hash privado a asignar.
0
Utiliza el hash global. Este es el comportamiento utilizado antes de Linux 6.17.
>0
Especifica el número de ranuras a asignar. El valor debe ser una potencia de dos, y el valor más bajo posible es 2. El límite superior depende de la memoria disponible en el sistema. Cada ranura requiere 64 bytes de memoria. Los núcleos compilados con CONFIG_PROVE_LOCKING consumirán más que eso.
flags
El argumento debe ser 0.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
Un argumento es inválido.
ENOMEM
Fallo al asignar memoria.
EBUSY
El hash global está en uso y no se puede cambiar.

ESTÁNDARES

Linux.

HISTORIA

Linux 6.17.

VER TAMBIÉN

prctl(2), PR_FUTEX_HASH(2const)
