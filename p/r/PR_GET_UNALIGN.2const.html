PR_GET_UNALIGN(2const) PR_GET_UNALIGN(2const)

NOMBRE

PR_GET_UNALIGN - obtener bits de control de acceso no alineado

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_UNALIGN, unsigned int *bits);

DESCRIPCIÓN

Devuelve los bits de control de acceso no alineado, en la ubicación apuntada por bits.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
bits es una dirección inválida.

ESTÁNDARES

Linux.

HISTORIA

Ver PR_SET_UNALIGN(2const).

VER TAMBIÉN

prctl(2), PR_SET_UNALIGN(2const)
