PR_TASK_PERF_EVENTS_DISABLE(2const) PR_TASK_PERF_EVENTS_DISABLE(2const)

NOMBRE

PR_TASK_PERF_EVENTS_DISABLE, PR_TASK_PERF_EVENTS_ENABLE - deshabilitar o habilitar contadores de rendimiento adjuntos al proceso que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_TASK_PERF_EVENTS_DISABLE);
int prctl(PR_TASK_PERF_EVENTS_ENABLE);

DESCRIPCIÓN

PR_TASK_PERF_EVENTS_DISABLE
Deshabilita todos los contadores de rendimiento adjuntos al proceso que llama, independientemente de si los contadores fueron creados por este proceso u otro. Los contadores de rendimiento creados por el proceso que llama para otros procesos no se ven afectados.
PR_TASK_PERF_EVENTS_ENABLE
Lo opuesto a PR_TASK_PERF_EVENTS_DISABLE; habilita los contadores de rendimiento adjuntos al proceso que llama.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ESTÁNDARES

Linux.

HISTORIA

Linux 2.6.31.

Originalmente llamado PR_TASK_PERF_COUNTERS_DISABLE y PR_TASK_PERF_COUNTERS_ENABLE; renombrado (manteniendo el mismo valor numérico) en Linux 2.6.32.

VER TAMBIÉN

prctl(2)

Para más información sobre los contadores de rendimiento, consulte el archivo de código fuente del kernel de Linux tools/perf/design.txt.
