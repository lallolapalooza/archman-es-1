PR_MCE_KILL_SET(2const) PR_MCE_KILL_SET(2const)

NOMBRE

PR_MCE_KILL_SET - establece la política de eliminación por corrupción de memoria de comprobación de máquina

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_MCE_KILL, PR_MCE_KILL_SET, long pol, 0L, 0L);

DESCRIPCIÓN

Utiliza una política de eliminación de corrupción de memoria específica del hilo.

pol define si la política es eliminación temprana (PR_MCE_KILL_EARLY), eliminación tardía (PR_MCE_KILL_LATE), o el valor predeterminado a nivel del sistema (PR_MCE_KILL_DEFAULT).

La eliminación temprana significa que el hilo recibe una señal SIGBUS tan pronto como se detecta corrupción de memoria de hardware dentro de su espacio de direcciones.

En el modo de eliminación tardía, el proceso se elimina solo cuando accede a una página corrupta. Consulte sigaction(2) para obtener más información sobre la señal SIGBUS.

VALOR DE RETORNO

Al éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
pol no es un valor válido.

ESTANDARES

Linux.

HISTORIA

Linux 2.6.32.

VER TAMBIÉN

prctl(2), PR_MCE_KILL(2const)
