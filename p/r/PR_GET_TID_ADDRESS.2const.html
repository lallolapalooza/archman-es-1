PR_GET_TID_ADDRESS(2const) PR_GET_TID_ADDRESS(2const)

NOMBRE

PR_GET_TID_ADDRESS - obtener la dirección de clear_child_tid

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_TID_ADDRESS, int **addrp);

DESCRIPCIÓN

Devuelve la dirección de clear_child_tid establecida por set_tid_address(2) y el flag CLONE_CHILD_CLEARTID de clone(2), en la ubicación apuntada por addrp.

Esta característica solo está disponible si el kernel está compilado con la opción CONFIG_CHECKPOINT_RESTORE habilitada.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
addrp es una dirección inválida.

ESTANDARES

Linux.

HISTORIAL

Linux 3.5.

ADVERTENCIAS

Tenga en cuenta que dado que la llamada al sistema prctl() no tiene una implementación de compatibilidad para las ABI x32 de AMD64 y n32 de MIPS, y el kernel escribe un puntero usando el tamaño de puntero del kernel, esta operación espera un buffer de espacio de usuario de 8 (no 4) bytes en estas ABI.

VER TAMBIÉN

prctl(2)
