PR_MPX_ENABLE_MANAGEMENT(2const) PR_MPX_ENABLE_MANAGEMENT(2const)

NOMBRE

PR_MPX_ENABLE_MANAGEMENT, PR_MPX_DISABLE_MANAGEMENT - habilitar o deshabilitar la gestión del núcleo de las extensiones de protección de memoria (MPX)

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
[[deprecated]] int prctl(PR_MPX_ENABLE_MANAGEMENT, 0L, 0L, 0L, 0L);
[[deprecated]] int prctl(PR_MPX_DISABLE_MANAGEMENT, 0L, 0L, 0L, 0L);

DESCRIPCIÓN

Habilita o deshabilita la gestión del núcleo de las tablas de límites de las extensiones de protección de memoria (MPX).

MPX es un mecanismo asistido por hardware para realizar comprobaciones de límites en los punteros. Consiste en un conjunto de registros que almacenan información de límites y un conjunto de prefijos de instrucciones especiales que indican a la CPU en qué instrucciones debe forzar los límites. Hay un número limitado de estos registros y cuando hay más punteros que registros, su contenido debe ser "desbordado" (spilled) en un conjunto de tablas. Estas tablas se denominan "tablas de límites" y las operaciones prctl() de MPX controlan si el núcleo gestiona su asignación y liberación.

Cuando se habilita la gestión, el núcleo se encargará de la asignación y liberación de las tablas de límites. Lo hace interceptando las excepciones #BR que resultan al usar por primera vez tablas de límites faltantes y, en lugar de entregar la excepción al espacio de usuario, asigna la tabla y pobla el directorio de límites con la ubicación de la nueva tabla. Para la liberación, el núcleo comprueba si hay tablas de límites presentes para memoria que no está asignada y las libera si es así.

Antes de habilitar la gestión de MPX usando PR_MPX_ENABLE_MANAGEMENT, la aplicación primero debe haber asignado un búfer de espacio de usuario para el directorio de límites y haber colocado la ubicación de dicho directorio en el registro bndcfgu.

Estas llamadas fallan si la CPU o el núcleo no soportan MPX. El soporte del núcleo para MPX se habilita a través de la opción de configuración CONFIG_X86_INTEL_MPX. Puede comprobar si la CPU soporta MPX buscando el bit CPUID mpx, por ejemplo con el siguiente comando:


cat /proc/cpuinfo | grep ' mpx '

Un hilo no puede entrar o salir del modo largo (64 bits) mientras MPX esté habilitado.

Todos los hilos de un proceso se ven afectados por estas llamadas.

El hijo de un fork(2) hereda el estado de la gestión de MPX. Durante execve(2), la gestión de MPX se reinicia a un estado como si se hubiera llamado a PR_MPX_DISABLE_MANAGEMENT.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

ENXIO
El núcleo o la CPU no soportan la gestión MPX. Compruebe que el núcleo y el procesador tengan soporte MPX.

ESTANDARES

Ninguno.

HISTORIA

Linux 3.19. Eliminado en Linux 5.4. Solo en x86.

Debido a la falta de soporte de la cadena de herramientas, PR_MPX_ENABLE_MANAGEMENT y PR_MPX_DISABLE_MANAGEMENT no son soportados en Linux 5.4 y posteriores.

VER TAMBIÉN

prctl(2)

Para más información sobre Intel MPX, consulte el archivo fuente del núcleo Documentation/x86/intel_mpx.txt.
