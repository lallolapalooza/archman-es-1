PR_GET_PDEATHSIG(2const) PR_GET_PDEATHSIG(2const)

NOMBRE

PR_GET_PDEATHSIG - obtener el número de señal por muerte del padre del proceso llamante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_PDEATHSIG, int *sig);

DESCRIPCIÓN

Devuelve el número de señal por muerte del padre del proceso llamante, en la ubicación apuntada por sig.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
sig es una dirección inválida.

ESTANDARES

Linux.

HISTORIAL

Linux 2.3.15.

VER TAMBIÉN

signal(2), PR_SET_PDEATHSIG(2const)
