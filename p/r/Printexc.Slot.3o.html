Desde 4.02

type t = Printexc.backtrace_slot

val is_raise : t -> bool

is_raise slot es true cuando slot se refiere a un punto de elevación en el código, y false cuando proviene de una simple llamada a función.

Desde 4.02

val is_inline : t -> bool

is_inline slot es true cuando slot se refiere a una llamada que se ha insertado en línea por el compilador, y false cuando proviene de cualquier otro contexto.

Desde 4.04

val location : t -> Printexc.location option

location slot devuelve la información de ubicación de la ranura, si está disponible, y None en caso contrario.

Algunas razones posibles por las que no se pudo devolver una ubicación son las siguientes:

-la ranura corresponde a una elevación insertada por el compilador

-la ranura corresponde a una parte del programa que no ha sido compilada con información de depuración ( -g )

Desde 4.02

val name : t -> string option

name slot devuelve el nombre de la función o definición que contiene la ubicación a la que se refiere la ranura.

name slot devuelve None si el nombre no está disponible, lo que puede ocurrir por las mismas razones que location devuelve None.

Desde 4.11

val format : int -> t -> string option

format pos slot devuelve la representación de cadena de slot tal como la formatearía raw_backtrace_to_string, asumiendo que es el elemento pos -ésimo de la traza inversa: el elemento 0 -ésimo se imprime de forma diferente a los demás.

Las funciones de impresión de trazas inversas completas también omiten algunas ranuras no informativas; en ese caso, format pos slot devuelve None.
