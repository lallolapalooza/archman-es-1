PR_SET_NAME(2const) PR_SET_NAME(2const)

NOMBRE

PR_SET_NAME, PR_GET_NAME - operaciones sobre un proceso o hilo

LIBRERÍA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_NAME, char name[16]);
int prctl(PR_GET_NAME, const char name[16]);

DESCRIPCIÓN

PR_SET_NAME
Establece el nombre del hilo que realiza la llamada, utilizando el valor en la ubicación apuntada por name.
El nombre puede tener hasta 16 bytes de longitud, incluyendo el byte nulo terminador. Si la longitud de la cadena, incluyendo el byte nulo terminador, excede los 16 bytes, la cadena se trunca silenciosamente.
PR_GET_NAME (desde Linux 2.6.11)
Devuelve el nombre del hilo que realiza la llamada, en el búfer apuntado por name. La cadena devuelta estará terminada en nulo.

Este es el mismo atributo que se puede establecer a través de pthread_setname_np(3) y recuperar usando pthread_getname_np(3).

VALOR DEVUELTO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EFAULT
name es una dirección inválida.

FICHEROS

/proc/self/task/tid/comm
El atributo también es accesible a través de este archivo (ver proc_pid_comm(5)), donde tid es el ID del hilo que realiza la llamada, tal como lo devuelve gettid(2).

ESTÁNDARES

Linux.

HISTORIA

PR_SET_NAME
Linux 2.6.9.
PR_GET_NAME
Linux 2.6.11.

VER TAMBIÉN

prctl(2), pthread_setname_np(3), pthread_getname_np(3), proc_pid_comm(5)
