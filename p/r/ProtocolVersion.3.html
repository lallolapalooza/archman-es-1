ARGUMENTOS

display
Indica la conexión al servidor X.
screen_number
Indica el número de pantalla adecuado en el servidor.
count_return
Devuelve el número de profundidades.

DESCRIPCIÓN

La macro AllPlanes devuelve un valor con todos los bits activos, adecuado para uso en un argumento de plano de una procedura.

La macro BlackPixel devuelve el valor del pixel negro para el número de pantalla especificado.

La macro WhitePixel devuelve el valor del pixel blanco para el número de pantalla especificado.

La macro ConnectionNumber devuelve el número de conexión para la pantalla especificada.

La macro DefaultColormap devuelve el ID del colormap por defecto para la asignación de la pantalla especificada.

La macro DefaultDepth devuelve la profundidad (número de planos) del ventana raíz por defecto para la pantalla especificada.

La función XListDepths devuelve la lista de profundidades disponibles en la pantalla especificada. Si el número de pantalla especificado es válido y hay memoria suficiente para la lista, XListDepths establece count_return a el número de profundidades disponibles. De lo contrario, no establece count_return y devuelve NULL. Para liberar la memoria utilizada en la lista de profundidades, use XFree。

La macro DefaultGC devuelve el GC por defecto para la ventana raíz de la pantalla especificada.

La macro DefaultRootWindow devuelve la ventana raíz de la pantalla por defecto.

La macro DefaultScreenOfDisplay devuelve el número de pantalla por defecto del display especificado.

La macro DefaultScreen devuelve el número de pantalla por defecto utilizado en la rutina XOpenDisplay。

La macro DefaultVisual devuelve el tipo visual por defecto para la pantalla especificada.

La macro DisplayCells devuelve el número de entradas en el colormap por defecto.

La macro DisplayPlanes devuelve la profundidad de la ventana raíz de la pantalla especificada.

La macro DisplayString devuelve la cadena que se pasó a XOpenDisplay cuando se abrió el display actual.

La función XMaxRequestSize devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) que el servidor no utiliza con codificación de protocolo extendida. Las solicitudes individuales a un servidor pueden no ser mayor que este tamaño, a menos que el servidor soporte una codificación de protocolo extendida. El protocolo garantiza que el tamaño sea no menor que 4096 unidades (16384 bytes). Xlib automáticamente divide los datos en múltiples solicitudes de protocolo cuando sea necesario para las funciones siguientes: XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, y XPutImage。

La función XExtendedMaxRequestSize devuelve cero si el display especificado no soporta una codificación de protocolo extendida; de lo contrario, devuelve el tamaño máximo de solicitud (en unidades de 4 bytes) que el servidor utiliza con la codificación de protocolo extendida. Las funciones Xlib XDrawLines, XDrawArcs, XFillPolygon, XChangeProperty, XSetClipRectangles, y XSetRegion usarán la codificación de protocolo extendida si el servidor lo soporta. El uso de la codificación de protocolo extendida en otras funciones de Xlib (por ejemplo, XDrawPoints, XDrawRectangles, XDrawSegments, XFillArcs, XFillRectangles, XPutImage) es permitida pero no obligatoria; una implementación de Xlib puede elegir dividir los datos en múltiples solicitudes más pequeñas.

La macro LastKnownRequestProcessed extrae el número de serial completo de la solicitud más reciente que ha sido procesada por el servidor X.

La macro NextRequest extrae el número de serial completo que se va a usar para la próxima solicitud.

La macro ProtocolVersion devuelve el número de versión principal (11) del protocolo X asociado con el display conectado.

La macro ProtocolRevision devuelve el número de revisión del protocolo secundario del servidor X.

La macro QLength devuelve la longitud de la cola de eventos para el display conectado.

La macro RootWindow devuelve la ventana raíz.

La macro ScreenCount devuelve el número de pantallas disponibles.

La macro ScreenOfDisplay devuelve un puntero a la pantalla del display especificado.

La macro ServerVendor devuelve un puntero a un string terminado en cero que proporciona algunos identificadores del propietario de la implementación de servidor X.

La macro VendorRelease devuelve un número relacionado con la versión de lanzamiento de la implementación de servidor X.
