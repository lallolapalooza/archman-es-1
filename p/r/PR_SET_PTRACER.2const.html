PR_SET_PTRACER(2const) PR_SET_PTRACER(2const)

NOMBRE

PR_SET_PTRACER - permitir que los procesos hagan ptrace(2) al proceso llamante

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_PTRACER, long pid);

DESCRIPCIÓN

Esto solo tiene sentido si el LSM Yama está habilitado y en modo 1 ("ptrace restringido", visible a través de /proc/sys/kernel/yama/ptrace_scope).

Cuando se pasa un "ID de proceso ptraceador" en pid, el llamante declara que el proceso ptraceador puede hacer ptrace(2) al proceso llamante como si fuera un ancestro de proceso directo.

Cada operación PR_SET_PTRACER reemplaza el "ID de proceso ptraceador" anterior.

El uso de PR_SET_PTRACER con pid establecido en 0 borra el "ID de proceso ptraceador" del llamante. Si pid es PR_SET_PTRACER_ANY, las restricciones de ptrace introducidas por Yama se deshabilitan efectivamente para el proceso llamante.

VALOR DE RETORNO

Al éxito, se devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
pid no es 0, PR_SET_PTRACER_ANY, ni el PID de un proceso existente.

ESTÁNDARES

Linux.

HISTORIA

Linux 3.4.

VER TAMBIÉN

prctl(2),

Para más información, consulte el archivo fuente del kernel Documentation/admin-guide/LSM/Yama.rst (o Documentation/security/Yama.txt antes de Linux 4.13).
