ioctl_kd(2) Manual de Llamadas al Sistema ioctl_kd(2)

NOMBRE

ioctl_kd - ioctls para terminal de consola y consolas virtuales

SINOPSIS

#include <linux/kd.h>  /* Definición de las constantes de operación */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones ioctl(2) específicas de Linux son soportadas para terminales de consola y consolas virtuales.

KDGETLED
Obtener el estado de los LEDs. argp apunta a un char. Los tres bits inferiores de *argp se establecen al estado de los LEDs, como sigue:
LED_CAP 0x04 led de bloq mayús
LED_NUM 0x02 led de bloq num
LED_SCR 0x01 led de bloq scroll
KDSETLED
Establecer los LEDs. Los LEDs se establecen para que correspondan a los tres bits inferiores del entero sin signo en argp. Sin embargo, si se establece un bit de orden superior, los LEDs vuelven a la normalidad: mostrando el estado de las funciones del teclado de bloq mayús, bloq num y bloq scroll.

Antes de Linux 1.1.54, los LEDs solo reflejaban el estado de las banderas correspondientes del teclado, y KDGETLED/KDSETLED también cambiaban las banderas del teclado. Desde Linux 1.1.54 los LEDs pueden ser hechos para mostrar información arbitraria, pero por defecto muestran las banderas del teclado. Los siguientes dos ioctls se usan para acceder a las banderas del teclado.

KDGKBLED
Obtener las banderas del teclado Bloq Mayús, Bloq Num, Bloq Scroll (no las luces). argp apunta a un char que se establece al estado de la bandera. Los tres bits de orden inferior (máscara 0x7) obtienen el estado actual de la bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) obtienen el estado por defecto de la bandera. (Desde Linux 1.1.54.)
KDSKBLED
Establecer las banderas del teclado Bloq Mayús, Bloq Num, Bloq Scroll (no las luces). argp es un entero sin signo que tiene el estado de bandera deseado. Los tres bits de orden inferior (máscara 0x7) tienen el estado de bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) tienen el estado por defecto de la bandera. (Desde Linux 1.1.54.)
KDGKBTYPE
Obtener el tipo de teclado. Devuelve el valor KB_101, definido como 0x02.
KDADDIO
Añadir puerto de E/S como válido. Equivalente a ioperm(arg,1,1).
KDDELIO
Eliminar puerto de E/S como válido. Equivalente a ioperm(arg,1,0).
KDENABIO
Habilitar E/S a la tarjeta de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Deshabilitar E/S a la tarjeta de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Establecer modo texto/gráfico. argp es un entero sin signo que contiene uno de:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtener modo texto/gráfico. argp apunta a un int que se establece a uno de los valores mostrados arriba para KDSETMODE.
KDMKTONE
Generar tono de longitud especificada. Los 16 bits inferiores del entero sin signo en argp especifican el período en ciclos de reloj, y los 16 bits superiores dan la duración en milisegundos. Si la duración es cero, el sonido se apaga. El control retorna inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especificaría el pitido normalmente asociado con un ctrl-G. (Desde Linux 0.99pl1; roto en Linux 2.1.49-50.)
KIOCSOUND
Iniciar o detener la generación de sonido. Los 16 bits inferiores de argp especifican el período en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En cualquier caso, el control retorna inmediatamente.
GIO_CMAP
Obtener el mapa de colores por defecto actual del kernel. argp apunta a un array de 48 bytes. (Desde Linux 1.3.3.)
PIO_CMAP
Cambiar el mapa de colores por defecto en modo texto. argp apunta a un array de 48 bytes que contiene, en orden, los valores Rojo, Verde y Azul para los 16 colores de pantalla disponibles: 0 es apagado, y 255 es intensidad completa. Los colores por defecto son, en orden: negro, rojo oscuro, verde oscuro, marrón, azul oscuro, púrpura oscuro, cian oscuro, gris claro, gris oscuro, rojo brillante, verde brillante, amarillo, azul brillante, púrpura brillante, cian brillante y blanco. (Desde Linux 1.3.3.)
GIO_FONT
Obtiene la fuente de pantalla de 256 caracteres en forma expandida. argp apunta a un array de 8192 bytes. Falla con el código de error EINVAL si la fuente cargada actualmente es una fuente de 512 caracteres, o si la consola no está en modo texto.
GIO_FONTX
Obtiene la fuente de pantalla y la información asociada. argp apunta a una struct consolefontdesc (ver PIO_FONTX). Al llamar, el campo charcount debe establecerse al número máximo de caracteres que cabrían en el buffer apuntado por chardata. Al retornar, charcount y charheight se llenan con los datos respectivos de la fuente cargada actualmente, y el array chardata contiene los datos de la fuente si el valor inicial de charcount indicó que había suficiente espacio; de lo contrario, el buffer no se modifica y errno se establece a ENOMEM. (Desde Linux 1.3.1.)
PIO_FONT
Establece la fuente de pantalla de 256 caracteres. Carga la fuente en el generador de caracteres EGA/VGA. argp apunta a un mapa de 8192 bytes, con 32 bytes por carácter. Solo los primeros N de ellos se usan para una fuente de 8xN (0 < N <= 32). Esta llamada también invalida el mapeo Unicode.
PIO_FONTX
Establece la fuente de pantalla y la información de renderizado asociada. argp apunta a un

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en la fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de escaneo por
                                  carácter (1-32) */
    char          *chardata;   /* datos de la fuente en
                                  forma expandida */
};

Si es necesario, la pantalla se redimensionará apropiadamente, y se enviará la señal SIGWINCH a los procesos adecuados. Esta llamada también invalida el mapeo Unicode. (Desde Linux 1.3.1.)
PIO_FONTRESET
Restablece la fuente de pantalla, el tamaño y el mapeo Unicode a los valores por defecto al arrancar. argp no se usa, pero debe establecerse a NULL para asegurar la compatibilidad con versiones futuras de Linux. (Desde Linux 1.3.28.)
GIO_SCRNMAP
Obtener el mapa de pantalla del kernel. argp apunta a un área de tamaño E_TABSZ, que se carga con las posiciones de fuente usadas para mostrar cada carácter. Es probable que esta llamada devuelva información inútil si la fuente cargada actualmente tiene más de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapa de pantalla Unicode completo del kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), que se carga con los Unicodes que representa cada carácter. Un conjunto especial de Unicodes, que comienza en U+F000, se usa para representar mapeos de "directo a fuente". (Desde Linux 1.3.1.)
PIO_SCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a símbolos de pantalla de consola. argp apunta a un área de tamaño E_TABSZ.
