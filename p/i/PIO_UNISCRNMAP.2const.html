NAME

ioctl_kd - llamadas de ioctl para terminales de consola y ventanas virtuales

SYNOPSIS

#include <linux/kd.h>  /* Definición de constantes de op */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPTION

Las siguientes operaciones ioctl(2) específicas de Linux son compatibles con terminales de consola y ventanas virtuales:

KDGETLED
Obtener el estado de los LEDs. argp apunta a un char. Los tres últimos bits de *argp se establecen en el estado de los LEDs, según lo siguiente:
LED_CAP 0x04 LED de caps lock
LED_NUM 0x02 LED de num lock
LED_SCR 0x01 LED de scroll lock
KDSETLED
Establecer los LEDs. Los LEDs se establecen para corresponder con los tres últimos bits de la entera no negativa en argp. Sin embargo, si un bit de orden superior está establecido, los LEDs se reversion a su estado normal: mostrando el estado de las funciones de teclado de caps lock, num lock y scroll lock.

Antes de Linux 1.1.54, los LEDs reflejaban el estado de las correspondientes flags de teclado, y KDGETLED/KDSETLED también cambiaban las flags de teclado. Desde Linux 1.1.54, los LEDs pueden mostrar información arbitraria, pero por defecto muestran las flags de teclado. Las siguientes dos llamadas de ioctl se utilizan para acceder a las flags de teclado:

KDGKBLED
Obtener el estado de las flags de teclado CapsLock, NumLock, ScrollLock (no LEDs). argp apunta a un char que se establece en el estado de la flag. Los tres bits más bajos (mascara 0x7) obtienen el estado actual de las flags, y los bits más bajos de los siguientes cuartetos (mascara 0x70) obtienen el estado por defecto de las flags. (Desde Linux 1.1.54).
KDSKBLED
Establecer las flags de teclado CapsLock, NumLock, ScrollLock (no LEDs). argp es un entero no negativo que tiene el estado deseado de las flags. Los tres bits más bajos (mascara 0x7) tienen el estado de las flags, y los bits más bajos de los siguientes cuartetos (mascara 0x70) tienen el estado por defecto de las flags. (Desde Linux 1.1.54).
KDGKBTYPE
Obtener el tipo de teclado. Este devuelve el valor KB_101, definido como 0x02.
KDADDIO
Añadir un puerto de I/O como válido. Equivalente a ioperm(arg,1,1).
KDDELIO
Eliminar un puerto de I/O como válido. Equivalente a ioperm(arg,1,0).
KDENABIO
Activar la I/O para el board de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Desactivar la I/O para el board de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Establecer el modo texto/gráficos. argp es un entero no negativo que contiene uno de los siguientes valores:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtener el modo texto/gráficos. argp apunta a un int que se establece en uno de los valores mostrados anteriormente para KDSETMODE.
KDMKTONE
Generar un sonido de longitud especificada. Los 16 bits más bajos de la entera no negativa en argp especifican la periodicidad en ciclos de reloj, y los 16 bits más altos indican la duración en milisegundos. Si la duración es cero, el sonido se apaga. El control se devuelve inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especifica el sonido normal asociado a un ctrl-G. (Por lo tanto, desde Linux 0.99pl1; roto en Linux 2.1.49-50).
KIOCSOUND
Iniciar o detener la generación del sonido. Los 16 bits más bajos de argp especifican la periodicidad en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En cualquier caso, el control se devuelve inmediatamente.
GIO_CMAP
Obtener el mapa de color actual del kernel. argp apunta a un array de 48 bytes. (Desde Linux 1.3.3).
PIO_CMAP
Cambiar el mapa de color por defecto en modo texto. argp apunta a un array de 48 bytes que contiene, en orden, los valores de rojo, verde y azul para los 16 colores disponibles en el modo texto: 0 es apagado, 255 es intensidad completa. Los colores por defecto son: negro, marrón, verde oscuro, marrón oscuro, azul oscuro, marrón profundo, azul profundo, cyan oscuro, gris claro, rojo brillante, verde brillante, amarillo, azul brillante, azul profundo, cyan brillante, blanco. (Desde Linux 1.3.3).
GIO_FONT
Obtener el fuente de pantalla de 256 caracteres en forma expandida. argp apunta a un array de 8192 bytes. Falla con el código de error EINVAL si el fuente actual es un fuente de 512 caracteres, o si el consola no está en modo texto.
GIO_FONTX
Obtener la fuente de pantalla y información asociada. argp apunta a un struct consolefontdesc (ver PIO_FONTX). Al llamar, el campo charcount debe ser establecido en el número máximo de caracteres que se pueden alinear en el buffer apuntado por chardata. En el retorno, los campos charcount y charheight contienen los datos correspondientes para el fuente actual. El array chardata contiene los datos de la fuente si el valor inicial de charcount indicó suficiente espacio; de lo contrario, el buffer no se modifica y errno se establece en ENOMEM. (Desde Linux 1.3.1).
PIO_FONT
Establecer la fuente de pantalla de 256 caracteres. Carga el fuente en el generador de caracteres EGA/VGA. argp apunta a un array de 8192 bytes con 32 bytes por carácter. Solo los primeros N de ellos se usan para una fuente de 8xN (0 N < 32). Esta llamada también invalida la mapeo de Unicode.
PIO_FONTX
Establecer la fuente de pantalla y información de renderizado. argp apunta a un

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en la fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de escaneo por carácter (1-32) */
    char          *chardata;   /* datos de la fuente en forma expandida */
};

Si es necesario, el pantalla se ajusta adecuadamente, y se envía el señal SIGWINCH a los procesos adecuados. Esta llamada también invalida el mapeo de Unicode. (Desde Linux 1.3.1).
PIO_FONTRESET
Resetea el mapa de fuente, tamaño y mapeo de Unicode a los valores por defecto al iniciar el sistema. argp no se usa, pero debería ser establecido a NULL para garantizar compatibilidad con futuras versiones de Linux. (Desde Linux 1.3.28).
GIO_SCRNMAP
Obtener el mapa de pantalla desde el kernel. argp apunta a un área de tamaño E_TABSZ, que se carga con las posiciones del fuente usadas para mostrar cada carácter. Esta llamada puede devolver información inútil si el fuente actual es mayor de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapa de pantalla completo en forma Unicode desde el kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), que se carga con las Unicodes representados por cada carácter. Una secuencia especial de Unicodes, empezando por U+F000, se usan para representar mapeos "directo a fuente". (Desde Linux 1.3.1).
PIO_SCRNMAP
Carga el mapa "definido por el usuario" (cuarto) en el kernel que mapea bytes a símbolos de pantalla. argp apunta a un área de tamaño E_TABSZ.

NAME

ioctl_console – operations on the console keyboard and screen

SYNOPSIS

#include <linux/kd.h>
#include <linux/vt.h>

int ioctl(int fd, unsigned long request, ...);

DESCRIPTION

The kernel console driver supports a variety of ioctl() requests to manipulate the keyboard and screen. These requests are defined in <linux/kd.h> and <linux/vt.h>.

PIO_UNISCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a Unicodes, los cuales se traducen a símbolos de pantalla según el mapa de Unicode a fuente actualmente cargado. Los Unicodes especiales que comienzan en U+F000 se pueden usar para mapear directamente a los símbolos de fuente. (Desde Linux 1.3.1.)
GIO_UNIMAP
Obtiene el mapeo de Unicode a fuente desde el kernel. argp apunta a un

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

donde entries apunta a un array de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Desde Linux 1.1.92.)
PIO_UNIMAP
Establece el mapeo de Unicode a fuente en el kernel. argp apunta a una struct unimapdesc. (Desde Linux 1.1.92)
PIO_UNIMAPCLR
Limpia la tabla, posiblemente informa al algoritmo hash. argp apunta a una

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si no hay opinión */
    unsigned short advised_hashstep;  /* 0 si no hay opinión */
    unsigned short advised_hashlevel; /* 0 si no hay opinión */
};

(Desde Linux 1.1.92.)
KDGKBMODE
Obtiene el modo actual del teclado. argp apunta a un long que se establece en uno de estos:
K_RAW 0x00 /* Modo Raw (scancode) */
K_XLATE 0x01 /* Traduce keycodes usando el keymap */
K_MEDIUMRAW 0x02 /* Modo Medium Raw (scancode) */
K_UNICODE 0x03 /* Modo Unicode */
K_OFF 0x04 /* Modo deshabilitado (desde Linux 2.6.39) */
KDSKBMODE
Establece el modo actual del teclado. argp es un long igual a uno de los valores mostrados para KDGKBMODE.
KDGKBMETA
Obtiene el modo de manejo de la tecla meta. argp apunta a un long que se establece en uno de estos:
K_METABIT 0x03 establecer bit de orden superior
K_ESCPREFIX 0x04 prefijo de escape
KDSKBMETA
Establece el modo de manejo de la tecla meta. argp es un long igual a uno de los valores mostrados anteriormente para KDGKBMETA.
KDGKBENT
Obtiene una entrada en la tabla de traducción de teclas (keycode a código de acción). argp apunta a un

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

con los dos primeros miembros llenos: kb_table selecciona la tabla de teclas (0 <= kb_table < MAX_NR_KEYMAPS), y kb_index es el keycode (0 <= kb_index < NR_KEYS). kb_value se establece al código de acción correspondiente, o K_HOLE si no existe tal tecla, o K_NOSUCHMAP si kb_table es inválido.
KDSKBENT
Establece una entrada en la tabla de traducción. argp apunta a una struct kbentry.
KDGKBSENT
Obtiene una cadena de tecla de función. argp apunta a un

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string se establece a la cadena (terminada en nulo) correspondiente al código de acción de la función de tecla kb_func.
KDSKBSENT
Establece una entrada de cadena de tecla de función. argp apunta a una struct kbsentry.
KDGKBDIACR
Lee la tabla de acentos del kernel. argp apunta a una

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

donde kb_cnt es el número de entradas en el array, cada una de las cuales es una

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lee una entrada de la tabla de keycodes del kernel (scancode a keycode). argp apunta a un

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode se establece para corresponder al scancode dado. (Solo 89 <= scancode <= 255. Para 1 <= scancode <= 88, keycode==scancode.) (Desde Linux 1.1.63.)
KDSETKEYCODE
Escribe una entrada de la tabla de keycodes del kernel. argp apunta a una struct kbkeycode. (Desde Linux 1.1.63.)
KDSIGACCEPT
El proceso que llama indica su disposición a aceptar la señal argp cuando se genera al presionar una combinación de teclas apropiada. (1 <= argp <= NSIG). (Ver spawn_console() en linux/drivers/char/keyboard.c.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique). En caso de fallo, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
argp es inválido.

ESTÁNDARES

Linux.

VER TAMBIÉN
