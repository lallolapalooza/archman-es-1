ioctl_kd(2) Manual de llamadas al sistema ioctl_kd(2)

NOMBRE

ioctl_kd - ioctls para terminal de consola y consolas virtuales

SINOPSIS

#include <linux/kd.h>  /* Definición de las constantes de operación */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

DESCRIPCIÓN

Las siguientes operaciones ioctl(2) específicas de Linux son soportadas para terminales de consola y consolas virtuales.

KDGETLED
Obtener el estado de los LEDs. argp apunta a un char. Los tres bits inferiores de *argp se establecen al estado de los LEDs, como sigue:
LED_CAP 0x04 led de Bloq Mayús
LED_NUM 0x02 led de Bloq Num
LED_SCR 0x01 led de Bloq Despl
KDSETLED
Establecer los LEDs. Los LEDs se configuran para corresponder a los tres bits inferiores del entero sin signo en argp. Sin embargo, si se establece un bit de orden superior, los LEDs vuelven a la normalidad: mostrando el estado de las funciones del teclado de Bloq Mayús, Bloq Num y Bloq Despl.

Antes de Linux 1.1.54, los LEDs solo reflejaban el estado de las banderas correspondientes del teclado, y KDGETLED/KDSETLED también cambiaban las banderas del teclado. Desde Linux 1.1.54 los LEDs se pueden hacer para mostrar información arbitraria, pero por defecto muestran las banderas del teclado. Los siguientes dos ioctls se utilizan para acceder a las banderas del teclado.

KDGKBLED
Obtener las banderas del teclado Bloq Mayús, Bloq Num, Bloq Despl (no las luces). argp apunta a un char que se establece al estado de la bandera. Los tres bits de orden inferior (máscara 0x7) obtienen el estado actual de la bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) obtienen el estado por defecto de la bandera. (Desde Linux 1.1.54.)
KDSKBLED
Establecer las banderas del teclado Bloq Mayús, Bloq Num, Bloq Despl (no las luces). argp es un entero sin signo que tiene el estado de bandera deseado. Los tres bits de orden inferior (máscara 0x7) tienen el estado de la bandera, y los bits de orden inferior del siguiente nibble (máscara 0x70) tienen el estado por defecto de la bandera. (Desde Linux 1.1.54.)
KDGKBTYPE
Obtener el tipo de teclado. Esto devuelve el valor KB_101, definido como 0x02.
KDADDIO
Añadir puerto de E/S como válido. Equivalente a ioperm(arg,1,1).
KDDELIO
Eliminar puerto de E/S como válido. Equivalente a ioperm(arg,1,0).
KDENABIO
Habilitar E/S a la placa de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
Deshabilitar E/S a la placa de video. Equivalente a ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
Establecer modo texto/gráfico. argp es un entero sin signo que contiene uno de:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
Obtener modo texto/gráfico. argp apunta a un int que se establece a uno de los valores mostrados anteriormente para KDSETMODE.
KDMKTONE
Generar tono de la longitud especificada. Los 16 bits inferiores del entero sin signo en argp especifican el período en ciclos de reloj, y los 16 bits superiores dan la duración en mseg. Si la duración es cero, el sonido se apaga. El control retorna inmediatamente. Por ejemplo, argp = (125<<16) + 0x637 especificaría el pitido normalmente asociado con un ctrl-G. (Por lo tanto, desde Linux 0.99pl1; roto en Linux 2.1.49-50.)
KIOCSOUND
Iniciar o detener la generación de sonido. Los 16 bits inferiores de argp especifican el período en ciclos de reloj (es decir, argp = 1193180/frecuencia). argp = 0 apaga el sonido. En cualquier caso, el control retorna inmediatamente.
GIO_CMAP
Obtener el mapa de colores predeterminado actual del kernel. argp apunta a un array de 48 bytes. (Desde Linux 1.3.3.)
PIO_CMAP
Cambiar el mapa de colores predeterminado en modo texto. argp apunta a un array de 48 bytes que contiene, en orden, los valores Rojo, Verde y Azul para los 16 colores de pantalla disponibles: 0 es apagado, y 255 es intensidad completa. Los colores predeterminados son, en orden: negro, rojo oscuro, verde oscuro, marrón, azul oscuro, púrpura oscuro, cian oscuro, gris claro, gris oscuro, rojo brillante, verde brillante, amarillo, azul brillante, púrpura brillante, cian brillante y blanco. (Desde Linux 1.3.3.)
GIO_FONT
Obtiene la fuente de pantalla de 256 caracteres en forma expandida. argp apunta a un array de 8192 bytes. Falla con el código de error EINVAL si la fuente cargada actualmente es una fuente de 512 caracteres, o si la consola no está en modo texto.
GIO_FONTX
Obtiene la fuente de pantalla y la información asociada. argp apunta a una struct consolefontdesc (ver PIO_FONTX). En la llamada, el campo charcount debe establecerse al número máximo de caracteres que cabrían en el buffer apuntado por chardata. Al retornar, charcount y charheight se rellenan con los datos respectivos para la fuente cargada actualmente, y el array chardata contiene los datos de la fuente si el valor inicial de charcount indicaba que había suficiente espacio; de lo contrario, el buffer no se modifica y errno se establece a ENOMEM. (Desde Linux 1.3.1.)
PIO_FONT
Establece la fuente de pantalla de 256 caracteres. Carga la fuente en el generador de caracteres EGA/VGA. argp apunta a un mapa de 8192 bytes, con 32 bytes por carácter. Solo los primeros N de ellos se usan para una fuente de 8xN (0 < N <= 32). Esta llamada también invalida el mapeo Unicode.
PIO_FONTX
Establece la fuente de pantalla y la información de renderizado asociada. argp apunta a una

struct consolefontdesc {
    unsigned short charcount;  /* caracteres en la fuente
                                  (256 o 512) */
    unsigned short charheight; /* líneas de escaneo por
                                  carácter (1-32) */
    char          *chardata;   /* datos de la fuente en
                                  forma expandida */
};

Si es necesario, la pantalla se redimensionará apropiadamente, y se enviará SIGWINCH a los procesos adecuados. Esta llamada también invalida el mapeo Unicode. (Desde Linux 1.3.1.)
PIO_FONTRESET
Restablece la fuente de pantalla, el tamaño y el mapeo Unicode a los valores predeterminados de arranque. argp no se utiliza, pero debe establecerse a NULL para garantizar la compatibilidad con versiones futuras de Linux. (Desde Linux 1.3.28.)
GIO_SCRNMAP
Obtener el mapa de pantalla del kernel. argp apunta a un área de tamaño E_TABSZ, que se carga con las posiciones de fuente utilizadas para mostrar cada carácter. Es probable que esta llamada devuelva información inútil si la fuente cargada actualmente tiene más de 256 caracteres.
GIO_UNISCRNMAP
Obtener el mapa de pantalla Unicode completo del kernel. argp apunta a un área de tamaño E_TABSZ*sizeof(unsigned short), que se carga con los Unicodes que representa cada carácter. Se utiliza un conjunto especial de Unicodes, comenzando en U+F000, para representar mapeos de "directo a fuente". (Desde Linux 1.3.1.)
PIO_SCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a símbolos de pantalla de consola. argp apunta a un área de tamaño E_TABSZ.

NAME

PIO_UNISCRNMAP, GIO_UNIMAP, PIO_UNIMAP, PIO_UNIMAPCLR, KDGKBMODE, KDSKBMODE, KDGKBMETA, KDSKBMETA, KDGKBENT, KDSKBENT, KDGKBSENT, KDSKBSENT, KDGKBDIACR, KDGETKEYCODE, KDSETKEYCODE, KDSIGACCEPT - console keyboard control ioctls

SYNOPSIS

Standard ioctl(2) system call.

PIO_UNISCRNMAP
Carga la tabla "definible por el usuario" (cuarta) en el kernel que mapea bytes a Unicodes, los cuales son luego traducidos a símbolos de pantalla según el mapa de Unicode a fuente actualmente cargado. Los Unicodes especiales que comienzan en U+F000 pueden usarse para mapear directamente a los símbolos de fuente. (Desde Linux 1.3.1.)
GIO_UNIMAP
Obtiene el mapeo de Unicode a fuente desde el kernel. argp apunta a una

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

donde entries apunta a un array de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Desde Linux 1.1.92.)
PIO_UNIMAP
Pone el mapeo de Unicode a fuente en el kernel. argp apunta a una struct unimapdesc. (Desde Linux 1.1.92)
PIO_UNIMAPCLR
Limpia la tabla, posiblemente avisando al algoritmo hash. argp apunta a una

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si no hay opinión */
    unsigned short advised_hashstep;  /* 0 si no hay opinión */
    unsigned short advised_hashlevel; /* 0 si no hay opinión */
};

(Desde Linux 1.1.92.)
KDGKBMODE
Obtiene el modo actual del teclado. argp apunta a un long que se establece a uno de estos:
K_RAW 0x00 /* Modo Raw (scancode) */
K_XLATE 0x01 /* Traduce keycodes usando el keymap */
K_MEDIUMRAW 0x02 /* Modo Medium raw (scancode) */
K_UNICODE 0x03 /* Modo Unicode */
K_OFF 0x04 /* Modo deshabilitado (desde Linux 2.6.39) */
KDSKBMODE
Establece el modo actual del teclado. argp es un long igual a uno de los valores mostrados para KDGKBMODE.
KDGKBMETA
Obtiene el modo de manejo de la tecla meta. argp apunta a un long que se establece a uno de estos:
K_METABIT 0x03 establecer bit de orden superior
K_ESCPREFIX 0x04 prefijo de escape
KDSKBMETA
Establece el modo de manejo de la tecla meta. argp es un long igual a uno de los valores mostrados anteriormente para KDGKBMETA.
KDGKBENT
Obtiene una entrada en la tabla de traducción de teclas (keycode a código de acción). argp apunta a una

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

con los dos primeros miembros llenos: kb_table selecciona la tabla de teclas (0 <= kb_table < MAX_NR_KEYMAPS), y kb_index es el keycode (0 <= kb_index < NR_KEYS). kb_value se establece al código de acción correspondiente, o K_HOLE si no existe tal tecla, o K_NOSUCHMAP si kb_table es inválido.
KDSKBENT
Establece una entrada en la tabla de traducción. argp apunta a una struct kbentry.
KDGKBSENT
Obtiene una cadena de tecla de función. argp apunta a una

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string se establece a la cadena (terminada en nulo) correspondiente al código de acción de la tecla de función número kb_func.
KDSKBSENT
Establece una entrada de cadena de tecla de función. argp apunta a una struct kbsentry.
KDGKBDIACR
Lee la tabla de acentos del kernel. argp apunta a una

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

donde kb_cnt es el número de entradas en el array, cada una de las cuales es una

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lee una entrada de la tabla de keycodes del kernel (scancode a keycode). argp apunta a una

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode se establece para corresponder al scancode dado. (Solo 89 <= scancode <= 255. Para 1 <= scancode <= 88, keycode==scancode.) (Desde Linux 1.1.63.)
KDSETKEYCODE
Escribe una entrada de la tabla de keycodes del kernel. argp apunta a una struct kbkeycode. (Desde Linux 1.1.63.)
KDSIGACCEPT
El proceso que llama indica su disposición a aceptar la señal argp cuando se genera mediante la pulsación de una combinación de teclas apropiada. (1 <= argp <= NSIG). (Ver spawn_console() en linux/drivers/char/keyboard.c.)

VALOR DE RETORNO

En caso de éxito, se devuelve 0 (excepto donde se indique). En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
argp es inválido.

ESTÁNDARES

Linux.

VER TAMBIÉN
