PTAINTERPOLATE(1) HERRAMIENTAS LIBPANO13 PTAINTERPOLATE(1)

NOMBRE

PTAInterpolate - Interpola imágenes intermedias entre fotos estéreo.

SINOPSIS

PTAInterpolate archivo_script [param2]

DESCRIPCIÓN

PTAInterpolate Interpola imágenes intermedias entre fotos estéreo.

Descripción: Este programa es una versión mejorada del programa original PTInterpolate de Helmut Dersch. El código fuente de PTInterpolate nunca fue liberado, por lo que este programa fue escrito desde cero. Se cree que este programa debería funcionar como sustituto del programa PTInterpolate original en la mayoría de las circunstancias. Las mejoras al programa PTInterpolate original incluyen:

1. Cuando se usa con el código fuente adjunto en la distribución original, la salida está en formato TIFF, no en PSD (con una extensión incorrecta).

2. Los archivos de salida producidos por este programa incluyen un valor numérico que indica la cantidad de la posición de interpolación entre las imágenes izquierda y derecha.

3. Si no se incluyen líneas "i" válidas en el script, este programa triangula las líneas "c" y sobrescribe el archivo de script.

Uso:

PTAInterpolate script.txt [param2]

Donde "param2" es un índice de imagen (0=izquierda, 1=derecha) que se usará al triangular, o un prefijo de nombre de archivo que se usará al interpolar.
