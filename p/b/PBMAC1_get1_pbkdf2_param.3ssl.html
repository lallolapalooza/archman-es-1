NOMBRE

PBMAC1_get1_pbkdf2_param - Función para manipular una estructura MAC PBMAC1

SINOPSIS

#include <openssl/x509.h>
PBKDF2PARAM *PBMAC1_get1_pbkdf2_param(const X509_ALGOR *macalg);

DESCRIPCIÓN

PBMAC1_get1_pbkdf2_param() recupera una estructura PBKDF2PARAM de una estructura X509_ALGOR.

VALORES DE RETORNO

PBMAC1_get1_pbkdf2_param() devuelve NULL en caso de que PBMAC1 utilice un algoritmo distinto de PBKDF2 o cuando se le pasan parámetros incorrectos, y un puntero a una estructura PBKDF2PARAM en caso contrario.

CONFORME A

IETF RFC 9579 (https://tools.ietf.org/html/rfc9579)

VER TAMBIÉN

openssl-pkcs12(1)

HISTORIA

La función PBMAC1_get1_pbkdf2_param se añadió en OpenSSL 3.4.
