PMIx_Init - Inicializa el Cliente PMIx

SINOPSIS

#include <pmix.h>
pmix_status_t PMIx_Init(pmix_proc_t *proc);

ARGUMENTOS

•
proc: Puntero a un objeto pmix_proc_t en el que se devolverán el espacio de nombres y el rango del cliente.

DESCRIPCIÓN

Inicializa el cliente PMIx, devolviendo el identificador del proceso asignado a la aplicación de este cliente en la estructura pmix_proc_t proporcionada. Se permite pasar un parámetro NULL para este parámetro si el usuario desea únicamente inicializar el sistema PMIx y no requiere la devolución del identificador en ese momento.

Cuando se llama, el cliente PMIx comprobará la información de conexión requerida del servidor PMIx local y establecerá la conexión. Si la información no se encuentra, o la conexión del servidor falla, se devolverá una constante de error apropiada.

Si la operación tiene éxito, la función devolverá PMIX_SUCCESS y rellenará la estructura proporcionada con el espacio de nombres y rango asignados por el servidor del proceso dentro de la aplicación.

Tenga en cuenta que la biblioteca cliente PMIx tiene un contador de referencias, por lo que se permiten múltiples llamadas a PMIx_Init. Por lo tanto, una forma de obtener el espacio de nombres y el rango del proceso es simplemente llamar a PMIx_Init con un parámetro no NULL.

VALOR DE RETORNO

Devuelve PMIX_SUCCESS en caso de éxito. En caso de error, se devuelve un valor negativo correspondiente a un errno de PMIx.

ERRORES

Los valores errno de PMIx se definen en pmix_common.h.
