Path::Class(3pm) Documentación de Perl contribuida por el usuario Path::Class(3pm)

NOMBRE

Path::Class - Manipulación de especificaciones de rutas multiplataforma

VERSIÓN

versión 0.37

SINÓPSIS

use Path::Class;

my $dir  = dir('foo', 'bar');       # Objeto Path::Class::Dir
my $file = file('bob', 'file.txt'); # Objeto Path::Class::File

# Se convierte en cadena como 'foo/bar' en Unix, 'foo\bar' en Windows, etc.
print "dir: $dir\n";

# Se convierte en cadena como 'bob/file.txt' en Unix, 'bob\file.txt' en Windows
print "file: $file\n";

my $subdir  = $dir->subdir('baz');  # foo/bar/baz
my $parent  = $subdir->parent;      # foo/bar
my $parent2 = $parent->parent;      # foo

my $dir2 = $file->dir;              # bob
# Trabajar con rutas externas
use Path::Class qw(foreign_file foreign_dir);
my $file = foreign_file('Mac', ':foo:file.txt');
print $file->dir;                   # :foo:
print $file->as_foreign('Win32');   # foo\file.txt

# Interactuar con el sistema de archivos subyacente:

# $dir_handle es un objeto IO::Dir
my $dir_handle = $dir->open or die "No se puede leer $dir: $!";

# $file_handle es un objeto IO::File
my $file_handle = $file->open($mode) or die "No se puede leer $file: $!";

DESCRIPCIÓN

"Path::Class" es un módulo para la manipulación de especificaciones de archivos y directorios (cadenas que describen sus ubicaciones, como '/home/ken/foo.txt' o 'C:\Windows\Foo.txt') de manera multiplataforma. Soporta prácticamente todas las plataformas en las que se ejecuta Perl, incluyendo Unix, Windows, Mac, VMS, Epoc, Cygwin, OS/2 y NetWare.

El conocido módulo File::Spec también proporciona este servicio, pero es algo incómodo de usar bien, por lo que la gente a veces lo evita, o lo usa de una manera que en realidad no funcionará correctamente en plataformas significativamente diferentes a aquellas en las que han probado su código.

De hecho, "Path::Class" utiliza "File::Spec" internamente, envolviendo todos los detalles desagradables para que puedas concentrarte en el código de tu aplicación. Mientras que "File::Spec" proporciona funciones para manipulaciones comunes de rutas, "Path::Class" proporciona un modelo orientado a objetos del mundo de las especificaciones de rutas y sus semánticas subyacentes. "File::Spec" no crea ningún objeto, y sus clases representan las diferentes formas en que las rutas deben ser manipuladas en varias plataformas (no es un concepto muy intuitivo). "Path::Class" crea objetos que representan archivos y directorios, y proporciona métodos que los relacionan entre sí. Por ejemplo, el siguiente código de "File::Spec":

my $absolute = File::Spec->file_name_is_absolute(
                 File::Spec->catfile( @dirs, $file )
               );

se puede escribir usando "Path::Class" como

my $absolute = Path::Class::File->new( @dirs, $file )->is_absolute;

o incluso como

my $absolute = file( @dirs, $file )->is_absolute;

Mejoras de legibilidad similares deberían ocurrir en todas partes al usar "Path::Class".

Usar "Path::Class" también puede ayudar a resolver problemas reales en tu código: por ejemplo, ¿cuántas personas tienen realmente en cuenta el "volumen" (como "C:" en Windows) al escribir código que usa "File::Spec"? Creo que no. Pero si usas "Path::Class", tus objetos de archivo y directorio sabrán a qué volúmenes se refieren y harán lo correcto.

El núcleo del código de "Path::Class" se encuentra en los módulos Path::Class::File y Path::Class::Dir, así que por favor consulta la documentación de esos módulos para obtener más detalles sobre cómo usarlos.

EXPORTACIÓN

Las siguientes funciones se exportan por defecto.

file
Un sinónimo de "Path::Class::File->new".
dir
Un sinónimo de "Path::Class::Dir->new".

Si deseas evitar su exportación, puedes pasar explícitamente una lista vacía a "use" de perl, es decir, "use Path::Class ()".

Los siguientes se exportan solo bajo demanda.

foreign_file
Un sinónimo de "Path::Class::File->new_foreign".
foreign_dir
Un sinónimo de "Path::Class::Dir->new_foreign".
tempdir
Crea una nueva instancia de Path::Class::Dir apuntando a un directorio temporal. 
my $temp = Path::Class::tempdir(CLEANUP => 1);

Un sinónimo de "Path::Class::Dir->new(File::Temp::tempdir(@_))".

Notas sobre Compatibilidad Multiplataforma

Aunque es mucho más fácil escribir código compatible con múltiples plataformas con este módulo que con "File::Spec", todavía hay algunos problemas a tener en cuenta.

•
En algunas plataformas, notablemente VMS y algunas versiones antiguas de DOS (creo), todos los nombres de archivo deben tener una extensión. Por lo tanto, si creas un archivo llamado foo/bar y luego solicitas una lista de archivos en el directorio foo, puedes encontrar un archivo llamado bar. en lugar del bar que esperabas. Por lo tanto, podría ser una buena idea usar una extensión en primer lugar.
