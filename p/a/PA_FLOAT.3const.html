DESCRIPCIÓN

Estas funciones sirven para extender y/o modificar el comportamiento de las funciones printf(3) de la familia.

registro_de_especificadores_de_conversión

Esta función registra un especificador de conversión personalizado para las funciones printf(3) de la familia.

espec
El carácter que se usará como especificador de conversión en la cadena de formato.
func
La función de callback que se ejecutará por las funciones printf(3) de la familia para formatear los argumentos de entrada en el flujo de salida stream.
stream
El flujo de salida donde se imprimirá el resultado del formateo. Este flujo se representa transparentemente incluso en los casos de funciones que escriben a una cadena.
info
La estructura que contiene la información de contexto, incluyendo los modificadores especificados en la cadena de formato. Contiene los mismos contenidos que en arginfo.
args
Array de punteros a los argumentos que se pasan a la función printf(3)-like.
arginfo
La función de callback que se ejecutará por las funciones printf(3) de la familia para saber cuántos argumentos deben ser parseados para el especificador de conversión personalizado y también sus tipos.
info
La estructura que contiene la información de contexto, incluyendo los modificadores especificados en la cadena de formato. Contiene los mismos contenidos que en func.
n
El número de argumentos restantes a parsear.
argtypes
Este array debe ser establecido para definir el tipo de cada uno de los argumentos que se van a parsear. Cada elemento en el array representa uno de los argumentos a parsear, en el mismo orden en que se pasan a la función printf(3)-like. Cada elemento debe ser establecido a un tipo base (PA_) del enum anterior, o un tipo personalizado, y opcionalmente ORado con un modificador de longitud (PA_FLAG_*).

El tipo se determina usando una de las siguientes constantes:

int.
PA_CHAR
int, convertido a char.
PA_WCHAR
wchar_t.
PA_STRING
const char *, una cadena de char terminada en \0.
PA_WSTRING
const wchar_t *, una cadena de wchar_t terminada en \0.
PA_POINTER
void *.
PA_FLOAT
float.
PA_DOUBLE
double.
PA_FINAL

size
Para tipos definidos por el usuario, también debe especificarse el tamaño del tipo (en bytes) a través de este array. De lo contrario, deje este array sin usar.

El arginfo se llama antes que func, preparando alguna información necesaria para llamar a func.

Callbacks_2

La callback de tipo función_de_conversión_printf debe devolver el número de caracteres escritos, o -1 en caso de error.

La callback de tipo función_de_tamaño_de_arginfo debe devolver el número de argumentos a parsear por este especificador. También pasa información sobre el tipo de esos argumentos a la llamada mediante argtypes. En caso de error, debe devolver -1.

ERRORES

El especificador no era un carácter válido.

DESCRIPCIÓN_2

Estas funciones sirven para extender y/o modificar el comportamiento de las funciones printf(3) de la familia.

NAME

register_printf_specifier - registrar un especificador para la función printf(3)

SYNOPSIS

#include <printf.h>
int register_printf_specifier(int c, printf_function *proc,
                              printf_arginfo_function *arginfo);
int unregister_printf_specifier(int c);

DESCRIPTION

La función register_printf_specifier() permite al usuario registrar un nuevo especificador de formato para su uso con funciones de impresión de formato como printf(3), sprintf(3), fprintf(3), snprintf(3), etc.

El argumento c es el carácter del especificador de formato que se registrará. Este carácter no debe ser un especificador de formato preexistente y debe ser imprimible.

El argumento proc es un puntero a la función que se llamará para manejar el especificador de formato registrado. La firma de esta función debe ser:

int printf_function(FILE *stream, const struct printf_info *info,
                    const void *const args[]);

El argumento arginfo es un puntero a una función que proporciona información sobre los argumentos que espera el especificador de formato. La firma de esta función debe ser:

int printf_arginfo_function(const struct printf_info *info, size_t n,
                              int argtypes[n], int size[n]);

La función unregister_printf_specifier() elimina un especificador de formato previamente registrado.

RETURN VALUES

Las funciones register_printf_specifier() y unregister_printf_specifier() devuelven 0 con éxito, o -1 si ocurre un error (por ejemplo, si el especificador ya está registrado o si la memoria no se puede asignar).

STANDARDS

GNU.

HISTORY

register_printf_function(3) es una función más antigua similar a register_printf_specifier(), y ahora está obsoleta. Esa función no puede manejar tipos definidos por el usuario.

register_printf_specifier() reemplaza a register_printf_function(3).

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Relleno con ' ' (alineado a la derecha) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Prefijo "0b"/"0B" */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Relleno con '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Imprimir número (incluyendo ceros iniciales para llenar la precisión) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Relleno con ' ' (alineado a la izquierda) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short y char se promocionan a int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Imprimir ceros iniciales para llenar la precisión */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Imprimir número */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
