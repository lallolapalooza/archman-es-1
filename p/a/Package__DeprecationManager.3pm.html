Package::DeprecationManager(3) Documentación de Perl aportada por el usuario Package::DeprecationManager(3)

NOMBRE

Package::DeprecationManager - Gestiona advertencias de deprecación para tu distribución

VERSIÓN

versión 0.18

SINOPSIS

package My::Class;
use Package::DeprecationManager -deprecations => {
    'My::Class::foo' => '0.02',
    'My::Class::bar' => '0.05',
    'feature-X'      => '0.07',
};
sub foo {
    deprecated( 'Do not call foo!' );
    ...
}
sub bar {
    deprecated();
    ...
}
sub baz {
    my %args = @_;
    if ( $args{foo} ) {
        deprecated(
            message => ...,
            feature => 'feature-X',
        );
    }
}
package Other::Class;
use My::Class -api_version => '0.04';
My::Class->new()->foo(); # advierte
My::Class->new()->bar(); # no advierte
My::Class->new()->bar(); # no advierte de nuevo

DESCRIPCIÓN

Este módulo te permite gestionar un conjunto de deprecaciones para uno o más módulos.

Cuando importas "Package::DeprecationManager", debes proporcionar un conjunto de "-deprecations" como referencia hash. Las claves son nombres de "característica" y los valores son la versión en la que se deprecó esa característica.

En muchos casos, puedes usar simplemente el nombre completamente calificado de una subrutina o método como nombre de característica. Esto funciona para casos en los que se deprecó toda la subrutina. Sin embargo, los nombres de las características pueden ser cualquier cadena. Esto es útil si no quieres deprecaciónar una subrutina completa, solo un uso específico.

También puedes proporcionar una referencia de matriz opcional en el parámetro "-ignore".

Los valores a ignorar pueden ser nombres de paquetes o expresiones regulares (creadas con "qr//"). Úsalo para ignorar paquetes en tu distribución que puedan aparecer en la pila de llamadas cuando se usa una característica deprecada.

Como parte del proceso de importación, "Package::DeprecationManager" exportará dos subrutinas a su llamador. Proporciona una sub import() para el llamador y una sub deprecated().

La sub import() permite a los llamadores de tu clase especificar un parámetro "-api_version". Si se suministra, las advertencias de deprecación solo se emitirán para deprecaciones con versiones de API anteriores a la especificada.

Debes llamar a la sub deprecated() en cada subrutina deprecada. Cuando se llama, emitirá una advertencia usando Carp::cluck().

La sub deprecated() se puede llamar de varias maneras. Si no pasas ningún argumento, generará un mensaje de advertencia apropiado. Si pasas un solo argumento, este se usará como el mensaje de advertencia.

Finalmente, puedes llamarla con argumentos nombrados. Actualmente, los únicos nombres permitidos son "message" y "feature". El argumento "feature" debe corresponder al nombre de característica pasado en el hash "-deprecations".

Si no especificas explícitamente una característica, la sub deprecated() usa caller() para identificar a su llamador, utilizando su nombre de subrutina completamente calificado.

Una advertencia de deprecación dada solo se emite una vez para un paquete dado. Este módulo realiza un seguimiento de esto basándose tanto en el nombre de la característica *como* en el propio mensaje de error. Esto significa que si proporcionas varios mensajes de error diferentes para la misma característica, aparecerán todos esos errores.

Otras subs import()

Este módulo funciona instalando una sub "import" en cualquier paquete que lo utilice. Si ese paquete *ya* tiene una sub "import", entonces esa "import" se llamará después de que se eliminen los argumentos pasados para "Package::DeprecationManager". Necesitas definir tu sub "import" antes de "use Package::DeprecationManager" para que esto funcione:

package HasExporter;
use Exporter qw( import );
use Package::DeprecationManager -deprecations => {
    'HasExporter::foo' => '0.02',
};
our @EXPORT_OK = qw( some_sub another_sub );
