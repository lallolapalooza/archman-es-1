DESCRIPCIÓN

Estas funciones sirven para extender y/o modificar el comportamiento de las funciones printf(3) de la familia.

register_printf_specifier()

Esta función registra un conversor de formato personalizado para las funciones printf(3) de la familia.

spec
El carácter que se usará como especificador de formato en la cadena de formato.
func
La función de callback que se ejecutará por parte de las funciones printf(3) para formatear los argumentos de entrada en el stream de salida.
stream
El stream de salida donde se imprimirá el resultado. Este stream representa transparentemente el resultado, incluso en los casos donde las funciones escriben a una cadena.
info
La estructura que contiene información contextual, incluyendo los modificadores especificados en la cadena de formato. Esto contiene los mismos contenidos que en arginfo.
args
Array de punteros a los argumentos que se pasan a la función printf(3)-like.
arginfo
La función de callback que se ejecutará por parte de las funciones printf(3) para saber cuántos argumentos deben ser parseados para el conversor de formato personalizado y también sus tipos.
info
La estructura que contiene información contextual, incluyendo los modificadores especificados en la cadena de formato. Esto contiene los mismos contenidos que en func.
n
El número de argumentos restantes por parsear.
argtypes
Este array debe ser establecido para definir el tipo de cada uno de los argumentos que se van a parsear. Cada elemento en el array representa un de los argumentos que se van a parsear, en el mismo orden que se pasan a la función printf(3)-like. Cada elemento debe ser establecido a un tipo base (PA_*) de la enum anterior, o un tipo personalizado, y opcionalmente OR'ado con un modificador de longitud (PA_FLAG_*).

El tipo se determina utilizando uno de los siguientes constantes:

PA_INT
int.
PA_CHAR
int, convertido a char.
PA_WCHAR
wchar_t.
PA_STRING
const char*, un string terminado en '\0'.
PA_WSTRING
const wchar_t*, un string terminado en L'\0'.
PA_POINTER
void*.
PA_FLOAT
float.
PA_DOUBLE
double.
PA_LAST
TODO.
size
Para tipos definidos por el usuario, también debe especificarse el tamaño de tipo (en bytes) a través de este array. De lo contrario, no lo use.

arginfo se llama antes de func y prepara información necesaria para llamar a func.

VALOR DE RETORNO

register_printf_specifier(), register_printf_modifier() y register_printf_type() devuelven 0 en caso de éxito, o -1 en error.

Callbacks

La callback de tipo printf_function debe devolver el número de caracteres escritos, o -1 en error.

La callback de tipo printf_arginfo_size_function debe devolver el número de argumentos a parsear por este especificador. También pasa información sobre los tipos de esos argumentos a la llamada mediante argtypes. En error, debe devolver -1.

ERRORES

EINVAL
El especificador no era un carácter válido.

NOMBRE

register_printf_specifier – registrar especificadores de formato para printf y funciones relacionadas

SINOPSIS

#include <stdio.h>

int register_printf_specifier(int c, printf_function handler, printf_arginfo_function arginfo);

DESCRIPCIÓN

La función register_printf_specifier registra un nuevo especificador de formato c para el manejo por la función handler. El especificador de formato c es un carácter que no está en uso por los especificadores de formato printf estándar (p. ej., s, d, x, etc.).

La función handler se llama cada vez que el especificador de formato c se encuentra en una cadena de formato para funciones como printf, fprintf, sprintf, snprintf, etc. La firma de la función handler debe ser:

int handler(FILE *stream, const struct printf_info *info, const void *const args[]);

El puntero stream es el flujo al que se escribe la salida. El puntero info contiene información sobre el especificador de formato encontrado, incluyendo el carácter del especificador (info->spec), el ancho de campo (info->width), la precisión (info->prec), las banderas (info->flags) y otras. El puntero args es un array de punteros a los argumentos que corresponden al especificador de formato. El primer argumento corresponde a args[0].

La función arginfo se llama para determinar los tipos de los argumentos esperados por el especificador de formato. La firma de la función arginfo debe ser:

int arginfo(const struct printf_info *info, size_t n, int argtypes[n], int size[n]);

El parámetro n es el número de argumentos que se espera que maneje el especificador de formato. El array argtypes debe ser poblado con los tipos de los argumentos esperados. Los tipos de argumentos se definen usando las siguientes macros:

  • PA_INT: Para tipos enteros.
  • PA_FLOAT: Para tipos de punto flotante.
  • PA_CHAR: Para tipos de caracteres.
  • PA_STRING: Para cadenas de caracteres (punteros a char).
  • PA_POINTER: Para punteros.
  • PA_LAST: Indica el final de la lista de tipos de argumentos.

Las siguientes banderas pueden ser combinadas con los tipos de argumentos:

  • PA_FLAG_LONG: Para argumentos long.
  • PA_FLAG_LONG_LONG: Para argumentos long long.
  • PA_FLAG_UNSIGNED: Para tipos enteros sin signo.
  • PA_FLAG_LONG_DOUBLE: Para argumentos long double.

El array size debe ser poblado con el tamaño del argumento en bytes. Si el tamaño del argumento no es relevante o no se puede determinar, debe ser establecido a 0.

La función register_printf_specifier devuelve 0 si el registro fue exitoso, y -1 si ocurrió un error (p. ej., si el especificador de formato c ya está registrado).

ESTÁNDARES

GNU.

HISTORIA

register_printf_function(3) es una función más antigua similar a register_printf_specifier(), y ahora está obsoleta. Esa función no puede manejar tipos definidos por el usuario.

register_printf_specifier() reemplaza a register_printf_function(3).

EJEMPLOS

El siguiente programa de ejemplo registra los especificadores 'b' y 'B' para imprimir enteros en formato binario, reflejando las reglas para otros especificadores de conversión sin signo como 'x' y 'u'. Esto se puede usar para imprimir en binario antes de C23.

#include <limits.h>

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/param.h>
#include <printf.h>
#define GROUP_SEP  '\''
struct Printf_Pad {
    char    ch;
    size_t  len;
};
static int b_printf(FILE *stream, const struct printf_info *info,
                    const void *const args[]);

                    size_t n, int argtypes[n], int size[n]);

                    const void *arg);

                    const struct printf_info *info, const void *arg);

                    ptrdiff_t min_len);
static size_t b_pad_len(const struct printf_info *info,
                    ptrdiff_t bin_len);

                    const struct printf_info *info);

                    ptrdiff_t min_len);
static ssize_t b_print_number(FILE *stream,

                    const char bin[UINTMAX_WIDTH],

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Relleno con ' ' (alineado a la derecha) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Prefijo "0b"/"0B" */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Relleno con '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Imprimir número (incluyendo ceros iniciales para llenar la precisión) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Relleno con ' ' (alineado a la izquierda) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short y char se promueven a int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Imprimir ceros iniciales para llenar la precisión */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Imprimir número */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
