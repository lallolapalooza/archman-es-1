NOMBRE

Pango - Diseña y renderiza texto internacional

SINOPSIS

my $surface = Cairo::ImageSurface->create ('argb32', 200, 100);
my $cr = Cairo::Context->create ($surface);
my $layout = Pango::Cairo::create_layout ($cr);
$layout->set_text ("\x{03A0}\x{03B1}\x{03BD}\x{8A9E}");
my $font = Pango::FontDescription->from_string ('Serif Bold 27');
$layout->set_font_description ($font);
Pango::Cairo::show_layout($cr, $layout);
$surface->write_to_png ('pango.png');

RESUMEN

Pango es una biblioteca para diseñar y renderizar texto, con énfasis en la internacionalización. Pango se puede utilizar en cualquier lugar donde se necesite diseño de texto, pero usar Pango junto con Cairo y/o Gtk2 proporciona una solución completa con manejo de texto y renderizado gráfico de alta calidad.

Módulos cargados dinámicamente manejan el diseño de texto para combinaciones particulares de scripts y backends de fuentes. Pango proporciona una amplia selección de módulos, incluyendo módulos para hebreo, árabe, hangul, tailandés y una serie de scripts indios. Prácticamente todos los principales scripts del mundo están soportados.

Además de las rutinas de renderizado de diseño de bajo nivel, Pango incluye Pango::Layout, un controlador de alto nivel para diseñar bloques completos de texto, y rutinas para ayudar en la edición de texto internacionalizado.

[Adaptado de http://www.pango.org/.]

DOCUMENTACIÓN

Pango intenta seguir muy de cerca el espíritu de la API C de la biblioteca pango subyacente. Por lo tanto, el manual disponible en http://library.gnome.org/devel/pango/stable/ también se aplica a este módulo. Además, los listados de API en formato POD se generan durante la compilación para cada uno de los submódulos. Un índice de esas páginas POD está disponible en Pango::index.

VER TAMBIÉN

perl, Glib, Cairo, Gtk2.

Pango::index lista los archivos pod de documentación de API autogenerados para Pango.

http://www.pango.org/ es la página principal de la biblioteca C pango. Su documentación de API está disponible en http://library.gnome.org/devel/pango/stable/.
