Path::Class::File(3pm) User Contributed Perl Documentation Path::Class::File(3pm)

NOMBRE

Path::Class::File - Objetos que representan archivos

VERSIÓN

versión 0.37

SINOPSIS

use Path::Class;  # Exporta file() por defecto
my $file = file('foo', 'bar.txt');  # Objeto Path::Class::File
my $file = Path::Class::File->new('foo', 'bar.txt'); # Lo mismo
# Se convierte en cadena como 'foo/bar.txt' en Unix, 'foo\bar.txt' en Windows, etc.
print "archivo: $file\n";
if ($file->is_absolute) { ... }
if ($file->is_relative) { ... }
my $v = $file->volume; # Podría ser 'C:' en Windows, cadena vacía
                       # en Unix, 'Macintosh HD:' en Mac OS
$file->cleanup; # Realiza limpieza lógica del nombre del archivo
$file->resolve; # Realiza limpieza física del nombre del archivo
my $dir = $file->dir;  # Un objeto Path::Class::Dir
my $abs = $file->absolute; # Transforma a ruta absoluta
my $rel = $file->relative; # Transforma a ruta relativa

DESCRIPCIÓN

La clase "Path::Class::File" contiene funcionalidad para manipular nombres de archivo de forma multiplataforma.

MÉTODOS

$file = Path::Class::File->new( <dir1>, <dir2>, ..., <file> )
$file = file( <dir1>, <dir2>, ..., <file> )
Crea y devuelve un nuevo objeto "Path::Class::File". Los argumentos especifican la ruta al archivo. También se puede especificar cualquier volumen como primer argumento, o como parte del primer argumento. Puedes usar sintaxis neutral a la plataforma: 
my $file = file( 'foo', 'bar', 'baz.txt' );

o sintaxis nativa de la plataforma:

my $file = file( 'foo/bar/baz.txt' );

o una mezcla de ambas:

my $file = file( 'foo/bar', 'baz.txt' );

Los tres ejemplos anteriores crean rutas relativas. Para crear una ruta absoluta, utiliza la sintaxis nativa de la plataforma para hacerlo:

my $file = file( '/var/tmp/foo.txt' );

o usa una cadena vacía como primer argumento:

my $file = file( '', 'var', 'tmp', 'foo.txt' );

Si la segunda forma parece extraña, es algo intencional: las rutas como "/var/tmp" o "\Windows" no son conceptos multiplataforma en primer lugar, por lo que no deberían aparecer en tu código si intentas ser multiplataforma. La primera forma está perfectamente bien, porque rutas como estas pueden venir de archivos de configuración, entrada del usuario, o lo que sea.

$file->stringify
Este método se llama internamente cuando un objeto "Path::Class::File" se usa en un contexto de cadena, por lo que lo siguiente es equivalente: 
$string = $file->stringify;
$string = "$file";
$file->volume
Devuelve el volumen (ej. "C:" en Windows, "Macintosh HD:" en Mac OS, etc.) del objeto, si lo tiene. De lo contrario, devuelve la cadena vacía.
$file->basename
Devuelve el nombre del archivo como una cadena, sin la porción del directorio (si la hay).
$file->components
Devuelve una lista de los componentes del directorio de este archivo, seguidos por el nombre base.

Nota: a diferencia de "$dir->components", este método actualmente no acepta ningún argumento para seleccionar qué elementos de la lista se devolverán. Podría hacerlo en el futuro. Actualmente lanza una excepción si hay tales argumentos presentes.

$file->is_dir
Devuelve un valor booleano indicando si este objeto representa un directorio. Como era de esperar, los objetos "Path::Class::File" siempre devuelven falso, y los objetos Path::Class::Dir siempre devuelven verdadero.
$file->is_absolute
Devuelve verdadero o falso dependiendo de si el archivo se refiere a un especificador de ruta absoluta (como "/usr/local/foo.txt" o "\Windows\Foo.txt").
$file->is_relative
Devuelve verdadero o falso dependiendo de si el archivo se refiere a un especificador de ruta relativa (como "lib/foo.txt" o ".\Foo.txt").
$file->cleanup
Realiza una limpieza lógica de la ruta del archivo. Por ejemplo: 
my $file = file('/foo//baz/./foo.txt')->cleanup;
# $file ahora representa '/foo/baz/foo.txt';
$dir->resolve
Realiza una limpieza física de la ruta del archivo. Por ejemplo: 
my $file = file('/foo/baz/../foo.txt')->resolve;
# $file ahora representa '/foo/foo.txt', asumiendo que no hay enlaces simbólicos

Esto realmente consulta el sistema de archivos para verificar la validez de la ruta.

$dir = $file->dir
Devuelve un objeto "Path::Class::Dir" que representa el directorio que contiene este archivo.
$dir = $file->parent
Un sinónimo del método dir().
$abs = $file->absolute
Devuelve un objeto "Path::Class::File" que representa $file como una ruta absoluta. Un argumento opcional, dado como una cadena o un objeto Path::Class::Dir, especifica el directorio a usar como base de la relatividad; de lo contrario, se usará el directorio de trabajo actual.
$rel = $file->relative
Devuelve un objeto "Path::Class::File" que representa $file como una ruta relativa. Un argumento opcional, dado como una cadena o un objeto "Path::Class::Dir", especifica el directorio a usar como base de la relatividad; de lo contrario, se usará el directorio de trabajo actual.
$foreign = $file->as_foreign($type)
Devuelve un objeto "Path::Class::File" que representa $file como se especificaría en un sistema de tipo $type. Los tipos conocidos incluyen "Unix", "Win32", "Mac", "VMS", y "OS2", es decir, cualquier cosa para la que exista una subclase de "File::Spec".

Cualquier objeto generado (subdirectorios, archivos, padres, etc.) también conservará este tipo.

$foreign = Path::Class::File->new_foreign($type, @args)
Devuelve un objeto "Path::Class::File" que representa un archivo como se especificaría en un sistema de tipo $type. Los tipos conocidos incluyen "Unix", "Win32", "Mac", "VMS", y "OS2", es decir, cualquier cosa para la que exista una subclase de "File::Spec".

Los argumentos en @args son los mismos que se especificarían en new().

$fh = $file->open($mode, $permissions)
Pasa los argumentos dados, incluido $file, a "IO::File->new" (que a su vez llama a "IO::File->open" y devuelve el resultado como un objeto IO::File. Si la apertura falla, "undef" es devuelto y $! se establece.
$fh = $file->openr()
Un atajo para 
$fh = $file->open('r') or croak "No se puede leer $file: $!";
$fh = $file->openw()
Un atajo para 
$fh = $file->open('w') or croak "No se puede escribir en $file: $!";
$fh = $file->opena()
Un atajo para 
$fh = $file->open('a') or croak "No se puede añadir a $file: $!";
$file->touch
Establece la hora de modificación y acceso del archivo dado a ahora, si el archivo existe. Si no existe, touch() lo hará existir, y - ¡SÍ! - establecerá su hora de modificación y acceso a ahora.

Path::Class::File(3pm)

NAME

Path::Class::File - represents a file.

VERSION

0.37

SYNOPSIS

  use Path::Class::File;
  my $file = Path::Class::File->new( 'some', 'path', 'to', 'a', 'file.txt' );
  # OR
  my $file = Path::Class::File->new( '/some/path/to/a/file.txt' );
  # OR
  my $file = Path::Class::File->new( $dir, 'file.txt' ); # $dir is a Path::Class::Dir object

  my $content = $file->slurp;
  $file->spew( $new_content );

  my $size = $file->size;
  my $mod = $file->mtime;

DESCRIPTION

Path::Class::File is a subclass of Path::Class::Entity. It provides an object-oriented interface to a file.

METHODS

new( @path_parts )

Creates and returns a new Path::Class::File object. The arguments are joined together with the system's path separator (see File::Spec->catfile) and then checked to make sure that the resulting path refers to a file (not a directory, symlink, etc). If it doesn't, or if the file doesn't exist, then new() will throw an exception.

You can also pass in a Path::Class::Dir object as the first argument (or any of the first $#path_parts arguments).

      my $file = Path::Class::File->new( $dir, 'foo.txt' );
      my $file = Path::Class::File->new( $dir, 'bar', 'baz.txt' );
$file->slurp( %options )

Reads the entire contents of the file into a scalar. If called in list context, it returns a list of the lines in the file. If the file can't be read, this method will throw an exception.

If you want chomp() run on each line of the file, pass a true value for the "chomp" or "chomped" parameters:

      my @lines = $file->slurp(chomp => 1);

You may also use the "iomode" parameter to pass in an IO mode to use when opening the file, usually IO layers (though anything accepted by the MODE argument of open() is accepted here). Just make sure it's a reading mode.

      my @lines = $file->slurp(iomode => ':crlf');
      my $lines = $file->slurp(iomode => '<:encoding(UTF-8)');

The default "iomode" is "r".

Lines can also be automatically split, mimicking the perl command-line option "-a" by using the "split" parameter. If this parameter is used, each line will be returned as an array ref.

      my @lines = $file->slurp( chomp => 1, split => qr/\s*,\s*/ );

The "split" parameter can only be used in a list context.

$file->spew( $content );
The opposite of "slurp", this takes a list of strings and prints them to the file in write mode. If the file can't be written to, this method will throw an exception.

The content to be written can be either an array ref or a plain scalar. If the content is an array ref then each entry in the array will be written to the file.

You may use the "iomode" parameter to pass in an IO mode to use when opening the file, just like "slurp" supports.

      $file->spew(iomode => '>:raw', $content);

The default "iomode" is "w".

$file->spew_lines( $content );
Just like "spew", but, if $content is a plain scalar, appends $/ to it, or, if $content is an array ref, appends $/ to each element of the array.

Can also take an "iomode" parameter like "spew". Again, the default "iomode" is "w".

$file->traverse(sub { ... }, @args)
Calls the given callback on $file. This doesn't do much on its own, but see the associated documentation in Path::Class::Dir.
$file->remove()
This method will remove the file in a way that works well on all platforms, and returns a boolean value indicating whether or not the file was successfully removed.

remove() is better than simply calling Perl's unlink() function, because on some platforms (notably VMS) you actually may need to call unlink() several times before all versions of the file are gone - the remove() method handles this process for you.

$st = $file->stat()
Invokes File::stat::stat() on this file and returns a File::stat object representing the result.
$st = $file->lstat()
Same as stat(), but if $file is a symbolic link, lstat() stats the link instead of the file the link points to.
$class = $file->dir_class()
Returns the class which should be used to create directory objects.

Generally overridden whenever this class is subclassed.

$copy = $file->copy_to( $dest );
Copies the $file to $dest. It returns a Path::Class::File object when successful, "undef" otherwise.
$moved = $file->move_to( $dest );
Moves the $file to $dest, and updates $file accordingly.

It returns $file is successful, "undef" otherwise.
