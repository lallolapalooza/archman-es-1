NOMBRE

Params::Classify - clasificación de tipo de argumento

SINÓPSIS

use Params::Classify qw(
    scalar_class
    is_undef check_undef
    is_string check_string
    is_number check_number
    is_glob check_glob
    is_regexp check_regexp
    is_ref check_ref ref_type
    is_blessed check_blessed blessed_class
    is_strictly_blessed check_strictly_blessed
    is_able check_able);
$c = scalar_class($arg);
if(is_undef($arg)) {
check_undef($arg);
if(is_string($arg)) {
check_string($arg);
if(is_number($arg)) {
check_number($arg);
if(is_glob($arg)) {
check_glob($arg);
if(is_regexp($arg)) {
check_regexp($arg);
if(is_ref($arg)) {
check_ref($arg);
$t = ref_type($arg);
if(is_ref($arg, "HASH")) {
check_ref($arg, "HASH");
if(is_blessed($arg)) {
check_blessed($arg);
if(is_blessed($arg, "IO::Handle")) {
check_blessed($arg, "IO::Handle");
$c = blessed_class($arg);
if(is_strictly_blessed($arg, "IO::Pipe::End")) {
check_strictly_blessed($arg, "IO::Pipe::End");
if(is_able($arg, ["print", "flush"])) {
check_able($arg, ["print", "flush"]);

DESCRIPCIÓN

Este módulo proporciona varias funciones de prueba de tipo. Estas están destinadas a funciones que, a diferencia de la mayoría del código Perl, se preocupan por el tipo de datos con los que están operando. Por ejemplo, algunas funciones desean comportarse de manera diferente según el tipo de sus argumentos (como las funciones sobrecargadas en C++).

Hay dos tipos de funciones en este módulo. Las funciones del primer tipo solo proporcionan clasificación de tipos, para permitir que el código discrimine entre tipos de argumentos. Las funciones del segundo tipo agrupan el tipo más común de discriminación de tipos: comprobar que un argumento es de un tipo esperado. Las funciones vienen en pares coincidentes, de los dos tipos, y por lo tanto las funciones de aplicación de tipo manejan solo los requisitos más simples para argumentos de los tipos manejados por las funciones de clasificación. La aplicación de tipos más complejos puede, por supuesto, construirse utilizando las funciones de clasificación, o puede ser más conveniente utilizar un módulo diseñado para la tarea más compleja, como Params::Validate.

Este módulo está implementado en XS, con una versión de Perl puro de respaldo para sistemas que no pueden manejar XS.

CLASIFICACIÓN DE TIPO

Este módulo divide los valores escalares en las siguientes clases:

  • undef
  • cadena (escalar ordinario definido)
  • typeglob (sí, los typeglobs caben en variables escalares)
  • expresión regular (objetos de expresión regular de primera clase en Perl 5.11 en adelante)
  • referencia a un objeto no bendecido (clasificado adicionalmente por el tipo de datos físico del objeto referenciado)
  • referencia a un objeto bendecido (clasificado adicionalmente por la clase en la que se bendijo)

Estas clases son mutuamente excluyentes y deberían ser exhaustivas. Esta clasificación se ha elegido como la más útil cuando se desea discriminar entre tipos de escalares. Son posibles otras clasificaciones. (Por ejemplo, las dos clases de referencia se distinguen por una característica del objeto referenciado; Perl no trata esto internamente como una característica de la referencia).

FUNCIONES

Cada una de estas funciones toma un argumento escalar (ARG) para ser probado, posiblemente con otros argumentos que especifican detalles de la prueba. Cualquier valor escalar es aceptable para el argumento a probar. Cada función "is_" devuelve un resultado de valor booleano simple, que es verdadero si y solo si ARG es del tipo que se está comprobando. Cada función "check_" devolverá normalmente si el argumento es del tipo que se está comprobando, o "morirá" (lanzará una excepción) si no lo es.

Clasificación

scalar_class(ARG)
Determina en cuál de las cinco clases descritas anteriormente cae ARG. Devuelve "UNDEF", "STRING", "GLOB", "REGEXP", "REF", o "BLESSED" en consecuencia.

El Valor Indefinido

is_undef(ARG)
check_undef(ARG)
Comprueba si ARG es "undef". is_undef(ARG) es precisamente equivalente a "!defined(ARG)", y se incluye por completitud.

Cadenas

is_string(ARG)
check_string(ARG)
Comprueba si ARG está definido y es un valor escalar ordinario (no una referencia, typeglob o expresión regular). Esto es lo que uno normalmente piensa como una cadena en Perl. De hecho, cualquier escalar (incluido "undef" y las referencias) puede ser forzado a una cadena, pero si estás tratando de clasificar un escalar, no quieres hacer eso.
is_number(ARG)
check_number(ARG)
Comprueba si ARG está definido y es un escalar ordinario (es decir, satisface "is_string" arriba) y es un número aceptable para Perl. Esto es lo que uno normalmente piensa como un número.

Tenga en cuenta que los escalares simples (que satisfacen "is_string") pueden tener valores numéricos y de cadena independientes, a pesar de la pretensión habitual de que tienen un solo valor. Dicho escalar se considera un número si *ya tiene un valor numérico* (por ejemplo, fue generado por un literal numérico o un cálculo aritmético) *o* su valor de cadena tiene una sintaxis aceptable para un número (por lo que puede ser convertido). Cuando un escalar tiene valores numéricos y de cadena separados (ver "dualvar" en Scalar::Util), es posible que tenga un valor numérico aceptable mientras que su valor de cadena *no* tenga una sintaxis numérica aceptable. Tenga cuidado de usar dicho valor solo en un contexto numérico, si lo está utilizando como número. "scalar_num_part" en Scalar::Number extrae la parte numérica de un escalar como un número ordinario. ("0+ARG" es suficiente para eso a menos que necesite preservar ceros flotantes con signo).

Un número puede ser un entero nativo o un valor de punto flotante nativo, y existen varios subtipos de valor de punto flotante. Para la clasificación y otros manejos de números en escalares, vea Scalar::Number. Para detalles sobre los dos tipos de datos numéricos, vea Data::Integer y Data::Float.

Esta función difiere de "looks_like_number" (ver "looks_like_number" en Scalar::Util; también "looks_like_number" en perlapi para una descripción de nivel inferior) en que excluye "undef", typeglobs y referencias. Por qué "looks_like_number" devuelve verdadero para "undef" o typeglobs es algo que cualquiera puede adivinar. Las referencias, si se tratan como números, se evalúan a la dirección de memoria que referencian; esto es útil para comparar referencias por igualdad, pero no es útil en otros contextos tratar referencias como números. Las referencias bendecidas pueden tener operadores numéricos sobrecargados, pero si es así, no necesariamente se comportan como números ordinarios. "looks_like_number" también se confunde con los dualvars: mira la parte de cadena del escalar.

Typeglobs

is_glob(ARG)
check_glob(ARG)
Comprueba si ARG es un typeglob.

NAME

Params::Classify - classify Perl values

SYNOPSIS

    use Params::Classify qw(
        is_regexp check_regexp
        is_ref check_ref ref_type
        is_blessed check_blessed blessed_class
        is_strictly_blessed check_strictly_blessed
        is_able check_able
    );

    my $re = qr/foo/;
    my $hashref = { };
    my $obj = bless { }, 'MyClass';

    if (is_regexp($re)) { ... }
    if (check_regexp($re)) { ... }

    if (is_ref($hashref)) { ... }
    if (check_ref($hashref)) { ... }
    if (check_ref($hashref, 'HASH')) { ... }
    my $type = ref_type($hashref); # Returns 'HASH'

    if (is_blessed($obj)) { ... }
    if (check_blessed($obj)) { ... }
    if (check_blessed($obj, 'MyClass')) { ... }
    my $class = blessed_class($obj); # Returns 'MyClass'

    if (is_strictly_blessed($obj, 'MyClass')) { ... }
    if (check_strictly_blessed($obj, 'MyClass')) { ... }

    if (is_able($obj, 'method1')) { ... }
    if (check_able($obj, ['method1', 'method2'])) { ... }
    if (check_able($obj, 'method1')) { ... }

DESCRIPTION

This module provides functions for classifying Perl values. It is particularly useful for validating arguments to a subroutine or method, allowing you to check if a value is of a particular type, or if it is a reference to a particular type of structure.

TYPE CLASSIFICATION

The functions provided by this module fall into three broad categories:

  • Checking for regular expression references.
  • Checking for references to unblessed data structures.
  • Checking for references to blessed objects.

The module provides two styles of checking function: "is_*" functions return a boolean value (true or false), while "check_*" functions behave identically except that they raise a fatal error if the check fails. The "check_*" functions are convenient for use in argument validation code where you want the program to die if it receives bad arguments.

In addition to the "is_*" and "check_*" functions, the module provides some helper functions such as "ref_type" and "blessed_class".

Regular Expression References

is_regexp(ARG)
Returns true if ARG is a regular expression reference.
check_regexp(ARG)
Returns true if ARG is a regular expression reference, otherwise dies.

References to Unblessed Objects

is_ref(ARG)
Returns true if ARG is a reference to an unblessed data structure. Note that this returns false for references to blessed objects.
check_ref(ARG)
Returns true if ARG is a reference to an unblessed data structure, otherwise dies.
ref_type(ARG)
Returns "undef" if ARG is not a reference to an unblessed object. Otherwise, determines what type of object is referenced. Returns "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", or "IO" accordingly.

Note that, unlike "ref", this does not distinguish between different types of referenced scalar. A reference to a string and a reference to a reference will both return "SCALAR". Consequently, what "ref_type" returns for a particular reference will not change due to changes in the value of the referent, except for the referent being blessed.

is_ref(ARG, TYPE)
Returns true if ARG is a reference to an unblessed object of type TYPE, as determined by "ref_type". TYPE must be a string. Possible TYPEs are "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", and "IO".
check_ref(ARG, TYPE)
Returns true if ARG is a reference to an unblessed object of type TYPE, as determined by "ref_type", otherwise dies. TYPE must be a string. Possible TYPEs are "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", and "IO".

References to Blessed Objects

is_blessed(ARG)
Returns true if ARG is a reference to a blessed object. If it is, then the class into which the object was blessed can be determined using "blessed_class".
check_blessed(ARG)
Returns true if ARG is a reference to a blessed object, otherwise dies.
is_blessed(ARG, CLASS)
Returns true if ARG is a reference to a blessed object that claims to be an instance of CLASS (via its "isa" method; see "isa" in perlobj). CLASS must be a string, naming a Perl class. This check includes objects blessed into subclasses of CLASS.
check_blessed(ARG, CLASS)
Returns true if ARG is a reference to a blessed object that claims to be an instance of CLASS, otherwise dies. CLASS must be a string, naming a Perl class. This check includes objects blessed into subclasses of CLASS.
blessed_class(ARG)
Returns "undef" if ARG is not a reference to a blessed object. Otherwise, returns the class into which the object is blessed.

"ref" (see "ref" in perlfunc) gives the same result on references to blessed objects, but different results on other types of value. "blessed_class" is actually identical to "blessed" in Scalar::Util.

is_strictly_blessed(ARG)
Returns true if ARG is a reference to a blessed object, identically to "is_blessed". This exists only for symmetry; the useful form of "is_strictly_blessed" appears below.
check_strictly_blessed(ARG)
Returns true if ARG is a reference to a blessed object, identically to "check_blessed". This exists only for symmetry; the useful form of "check_strictly_blessed" appears below.
is_strictly_blessed(ARG, CLASS)
Returns true if ARG is a reference to an object blessed into CLASS exactly. CLASS must be a string, naming a Perl class. Because this excludes subclasses, this is rarely what one wants, but there are some specialised occasions where it is useful.
check_strictly_blessed(ARG, CLASS)
Returns true if ARG is a reference to an object blessed into CLASS exactly, otherwise dies. CLASS must be a string, naming a Perl class. Because this excludes subclasses, this is rarely what one wants, but there are some specialised occasions where it is useful.
is_able(ARG)
Returns true if ARG is a reference to a blessed object, identically to "is_blessed". This exists only for symmetry; the useful form of "is_able" appears below.
check_able(ARG)
Returns true if ARG is a reference to a blessed object, identically to "check_blessed". This exists only for symmetry; the useful form of "check_able" appears below.
is_able(ARG, METHODS)
Returns true if ARG is a reference to a blessed object that claims to implement the methods specified by METHODS (via its "can" method; see "can" in perlobj). METHODS must be either a single method name or a reference to an array of method names. Each method name is a string. This interface check is often more appropriate than a direct ancestry check (such as "is_blessed" performs).
check_able(ARG, METHODS)
Returns true if ARG is a reference to a blessed object that claims to implement the methods specified by METHODS, otherwise dies. METHODS must be either a single method name or a reference to an array of method names. Each method name is a string. This interface check is often more appropriate than a direct ancestry check.
