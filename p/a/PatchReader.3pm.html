NOMBRE

PatchReader - Utilidades para leer y manipular parches y CVS

SINOPSIS

# Script que lee un parche (en cualquier formato conocido) e imprime
# alguna información sobre él. Otras operaciones comunes son
# la salida del parche en formato de diff unificado crudo, la salida de
# la información del parche a plantillas de Template::Toolkit, la adición
# de contexto a un parche de CVS, y la reducción del parche para
# aplicarlo solo a un archivo o conjunto de archivos.
use PatchReader::Raw;
use PatchReader::PatchInfoGrabber;
my $filename = 'filename.patch';
# Crear el lector que analiza el parche y el objeto que
# extrae información del flujo de datos del lector
my $reader = new PatchReader::Raw();
my $patch_info_grabber = new PatchReader::PatchInfoGrabber();
$reader->sends_data_to($patch_info_grabber);
# Iterar sobre el archivo
$reader->iterate_file($filename);
# Imprimir la salida
my $patch_info = $patch_info_grabber->patch_info();
print "Resumen de Archivos Modificados:\n";
while (my ($file, $info) = each %{$patch_info->{files}}) {
  print "$file: +$info->{plus_lines} -$info->{minus_lines}\n";
}

RESUMEN

Esta biblioteca perl te permite manipular parches programáticamente encadenando una variedad de objetos que leen, manipulan y generan información de parches:

PatchReader::Raw
Analiza un parche en cualquier formato conocido por este autor (unificado, normal, diff de cvs, entre otros)
PatchReader::PatchInfoGrabber
Obtiene información resumida para secciones de un parche en un hash útil
PatchReader::AddCVSContext
Agrega contexto al parche obteniendo los archivos originales de CVS
PatchReader::NarrowPatch
Reduce un parche para que solo se aplique a un conjunto específico de archivos
PatchReader::DiffPrinter::raw
Genera el parche analizado en formato diff unificado crudo
PatchReader::DiffPrinter::template
Genera el parche analizado a plantillas de Template::Toolkit (se puede usar para generar salida HTML o lo que se desee)

Además, está diseñado para que puedas conectar tus propios objetos que lean los datos analizados mientras se están analizando (sin necesidad de problemas de rendimiento o memoria que pueden surgir al leer todo el parche a la vez). Puedes hacerlo imitando uno de los lectores existentes (como PatchInfoGrabber) y sobrescribiendo los métodos start_patch, start_file, section, end_file y end_patch.
