Las siguientes funciones se pueden utilizar para analizar Longident de forma segura.

val longident : Lexing.lexbuf -> Longident.t

Se garantiza que la función longident analiza todas las subclases de Longident.t utilizadas en OCaml: valores, constructores, rutas de módulos simples o extendidas, y tipos o tipos de módulos.

Sin embargo, esta función acepta entradas que no son aceptadas por el compilador, porque combinan aplicaciones de funtores y operadores infijos. En sintaxis OCaml válida, solo los identificadores a nivel de valor pueden terminar con operadores infijos Foo.( + ) . Además, en los identificadores a nivel de valor, la ruta del módulo Foo debe ser simple ( M.x en lugar de M.N ): las aplicaciones de funtores solo pueden aparecer en identificadores a nivel de tipo. Como consecuencia, una ruta como F(X).( + ) no es un identificador OCaml válido; pero es aceptada por esta función.

Las siguientes funciones están especializadas para una subclase de Longident.t

val val_ident : Lexing.lexbuf -> Longident.t

Esta función analiza una ruta sintácticamente válida para un valor. Por ejemplo, x , M.x , y (+.) son válidas. Por el contrario, M.A , F(X).x , y true son rechazadas.

Longident para valores OCaml no puede contener aplicaciones de funtores. El último componente de Longident.t no está capitalizado, pero puede ser un operador A.Path.To.(.%.%.(;..)<-)

val constr_ident : Lexing.lexbuf -> Longident.t

Esta función analiza una ruta sintácticamente válida para un constructor de variantes. Por ejemplo, A , M.A y M.(::) son válidas, pero tanto M.a como F(X).A son rechazadas.

Longident para constructores de variantes OCaml no puede contener aplicaciones de funtores. El último componente de Longident.t está capitalizado, o puede ser uno de los constructores especiales: true , false , () , [] , (::) . Entre estos constructores especiales, solo (::) puede ser prefijado por una ruta de módulo ( A.B.C.(::) ).

val simple_module_path : Lexing.lexbuf -> Longident.t

Esta función analiza una ruta sintácticamente válida para un módulo. Por ejemplo, A y M.A son válidas, pero tanto M.a como F(X).A son rechazadas.

Longident para módulos OCaml no puede contener aplicaciones de funtores. El último componente de Longident.t está capitalizado.

val extended_module_path : Lexing.lexbuf -> Longident.t

Esta función analiza una ruta sintácticamente válida para un módulo extendido. Por ejemplo, A.B y F(A).B son válidas. Por el contrario, (.%()) o [] son ambas rechazadas.

El último componente de Longident.t está capitalizado.

val type_ident : Lexing.lexbuf -> Longident.t

Esta función analiza una ruta sintácticamente válida para un tipo o un tipo de módulo. Por ejemplo, A , t , M.t y F(X).t son válidas. Por el contrario, (.%()) o [] son ambas rechazadas.

En rutas para tipos y tipos de módulos, solo se rechazan operadores y constructores especiales.
