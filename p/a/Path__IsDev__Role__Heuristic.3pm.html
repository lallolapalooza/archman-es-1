Path::IsDev::Role::Heuristic(3) Documentación de Perl aportada por el usuario Path::IsDev::Role::Heuristic(3)

NOMBRE

Path::IsDev::Role::Heuristic - Rol base para cosas heurísticas.

VERSIÓN

versión 1.001003

ROL REQUIERE

"matches"

Las clases implementadoras deben proporcionar este método.

retorna : 1 / undef
         1     -> este directorio es un directorio de desarrollo según esta heurística
         undef -> este directorio no es un directorio de desarrollo según esta heurística
args : ( $class , $result_object )
    $class         -> el método se invocará en paquetes, no en objetos
    $result_object -> será un Path::IsDev::Result

Adicionalmente, las clases consumidoras deben establecer "$result_object->result( 1 )" antes de retornar verdadero.

Los roles compuestos deben también invocar "$result_object->add_reason( $self, $result_value, $descriptive_reason_for_result, \%contextinfo )".

Ver "Path::IsDev::Result" para detalles

MÉTODOS

"name"

Retorna el nombre a usar en la depuración.

Por defecto, se deriva del nombre de la clase eliminando el prefijo "PIDH":

Path::IsDev::Heuristic::Tool::Dzil->name()
→ "+ ::Tool::Dzil"

"heuristic_type"

Retorna una descripción del tipo general de heurística

heurística positiva
