Path::IsDev::Role::NegativeHeuristic(3) Documentación de Perl aportada por el usuario Path::IsDev::Role::NegativeHeuristic(3)

NOMBRE

Path::IsDev::Role::NegativeHeuristic - Rol base para cosas de heurística negativa.

VERSIÓN

version 1.001003

EL ROL REQUIERE

"excluye"

Las clases que implementan deben proporcionar este método.

retorna : 1 / undef
         1     -> este path no es un directorio de desarrollo según esta heurística
         undef -> este path es un directorio de desarrollo según esta heurística
args : ( $class , $result_object )
    $class         -> el método se invocará sobre paquetes, no sobre objetos
    $result_object -> será un Path::IsDev::Result

Adicionalmente, las clases que lo consumen deberían establecer "$result_object->result( undef )" antes de retornar verdadero.

Los roles que componen deberían también invocar "$result_object->add_reason( $self, $result_value, $descriptive_reason_for_result, \%contextinfo )".

Ver "Path::IsDev::Result" para detalles

MÉTODOS

"nombre"

Retorna el nombre a usar en la depuración.

Por defecto, este se deriva del nombre de la clase eliminando el prefijo "PIDNH":

Path::IsDev::NegativeHeuristic::IsDev::IgnoreFile->name()
→ "- ::IsDev::IgnoreFile"

"tipo_heuristica"

Retorna una descripción del tipo general de heurística

heurística negativa
