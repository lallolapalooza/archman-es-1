Path::FindDev::Object(3) Documentación de Perl aportada por el usuario Path::FindDev::Object(3)

NOMBRE

Path::FindDev::Object - Lógica orientada a objetos para FindDev

VERSIÓN

versión v0.5.3

SINOPSIS

require Path::FindDev::Object;
my $finder = Path::FindDev::Object->new();
my $dev = $finder->find_dev($path);

DESCRIPCIÓN

Este módulo implementa la lógica interna de "Path::FindDev", y solo se recomienda su uso si la "API" Exporter no es suficiente para sus necesidades.

MÉTODOS

"tiene_conjunto"

Determina si el atributo "conjunto" existe

"tiene_max_subir_nivel"

Determina si se proporciona el atributo "max_subir_nivel".

"encontrar_dev"

Encuentra un padre en, o por encima de $OtroCamino que se asemeje a un directorio "devel".

my $path = $object->encontrar_dev( $OtroCamino );

ATRIBUTOS

"conjunto"

(opcional)

La subclase "Path::IsDev::HeuristicSet" para las heurísticas deseadas.

"max_subir_nivel"

Si se proporciona, limita el número de iteraciones de "subir_nivel" realizadas.

(es decir, limita el número de veces que subirá en la jerarquía)

"reintentar_anidamiento"

El número de directorios "dev" a "ignorar" en la jerarquía.

Esto se proporciona en caso de que tenga un directorio "dev" dentro de otro directorio "dev", y desee resolver un directorio exterior en lugar de uno interior.

Por defecto, es 0, o "detenerse en el primer directorio "dev""

"esdev"

El objeto "Path::IsDev" que comprueba los nodos para ver si parecen "dev".

MÉTODOS PRIVADOS

"_id_instancia"

Un número de secuencia oportunista para ayudar con los mensajes de depuración.

Nota: No se garantiza que sea único por instancia, solo se garantiza que sea constante durante la vida del objeto.

Basado en "refaddr", y asignando nuevos IDs cuando se ven nuevos "refaddr".

my $id = $object->_id_instancia;

"CONSTRUIR"

"CONSTRUIR" es un detalle de implementación de "Moo"/"Moose".

Este módulo engancha "CONSTRUIR" para dar un autoinforme del objeto a *STDERR después de "->new" cuando está bajo $DEBUG

"_depurar"

La devolución de llamada del depurador.

export PATH_FINDDEV_DEBUG=1

para obtener información de depuración.

$object->_depurar($mensaje);

"_error"

La devolución de llamada para informar de errores.

$object->_error($mensaje);

"_paso"

Ruta de código interna del recorrido del árbol.

my ($niveles_dev, $niveles_subir ) = (0,0);
my $resultado = $object->_paso( camino($alguncamino), \$niveles_dev, \$niveles_subir );
$resultado->{tipo} eq 'stop'   # si el control de flujo debe terminar
$resultado->{tipo} eq 'next'   # si el control de flujo debe ascender al padre
$resultado->{tipo} eq 'found'  # si el control de flujo ha encontrado el directorio dev "final"
