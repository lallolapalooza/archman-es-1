PAM(8) Manual de Linux-PAM PAM(8)

NOMBRE

PAM, pam - Módulos de autenticación configurables para Linux

DESCRIPCIÓN

Este manual tiene la intención de ofrecer una introducción rápida a Linux-PAM. Para más información, se dirige al lector a la guía del administrador del sistema Linux-PAM.

Linux-PAM es un sistema de librerías que maneja las tareas de autenticación de las aplicaciones (servicios) en el sistema. La librería proporciona una interfaz de programación de aplicaciones (API) general y estable a la que los programas que otorgan privilegios (como login(1) y su(1)) recurren para realizar tareas de autenticación estándar.

La característica principal del enfoque de PAM es que la naturaleza de la autenticación es configurable dinámicamente. En otras palabras, el administrador del sistema es libre de elegir cómo las aplicaciones que proporcionan servicios autenticarán a los usuarios. Esta configuración dinámica se establece mediante el contenido del único archivo de configuración de Linux-PAM, /etc/pam.conf. Alternativamente y de forma preferida, la configuración puede establecerse mediante archivos de configuración individuales ubicados en un directorio llamado pam.d. La presencia de este directorio hará que Linux-PAM ignore /etc/pam.conf.

Los archivos de configuración de PAM proporcionados por el proveedor podrían instalarse en el directorio del sistema /usr/lib/pam.d/ o en un directorio específico del proveedor configurable en lugar del directorio de configuración de la máquina /etc/pam.d/. Si no se encuentra ningún archivo de configuración de máquina, se utiliza el archivo proporcionado por el proveedor. Todos los archivos en /etc/pam.d/ anulan los archivos con el mismo nombre en otros directorios.

Desde el punto de vista del administrador del sistema, para quien está proporcionado este manual, no es de importancia primaria entender el comportamiento interno de la librería Linux-PAM. El punto importante a reconocer es que los archivos de configuración definen la conexión entre las aplicaciones (servicios) y los módulos de autenticación configurables (PAMs) que realizan las tareas de autenticación reales.

Linux-PAM separa las tareas de autenticación en cuatro grupos de gestión independientes: gestión de cuenta; gestión de authenticación; gestión de contraseña; y gestión de sesión. (Resaltamos las abreviaturas utilizadas para estos grupos en el archivo de configuración).

En pocas palabras, estos grupos se encargan de diferentes aspectos de la solicitud típica de un usuario para un servicio restringido:

cuenta - proporciona tipos de servicio de verificación de cuenta: ¿ha caducado la contraseña del usuario?; ¿se le permite a este usuario acceder al servicio solicitado?

authenticación - autentica a un usuario y establece las credenciales del usuario. Típicamente, esto se realiza a través de una solicitud de desafío-respuesta que el usuario debe satisfacer: si eres quien dices ser, por favor introduce tu contraseña. No todas las autenticaciones son de este tipo, existen esquemas de autenticación basados en hardware (como el uso de tarjetas inteligentes y dispositivos biométricos), con módulos adecuados, estos pueden sustituirse sin problemas por enfoques más estándares para la autenticación, tal es la flexibilidad de Linux-PAM.

contraseña - la responsabilidad de este grupo es la tarea de actualizar los mecanismos de autenticación. Típicamente, dichos servicios están fuertemente acoplados a los del grupo auth. Algunos mecanismos de autenticación se prestan bien a ser actualizados con tal función. El acceso estándar basado en contraseñas de UN*X es el ejemplo obvio: por favor, introduce una contraseña de reemplazo.

sesión - este grupo de tareas cubre las cosas que deberían hacerse antes de que se conceda un servicio y después de que se retire. Estas tareas incluyen el mantenimiento de pistas de auditoría y el montaje del directorio personal del usuario. El grupo de gestión de sesión es importante ya que proporciona un gancho de apertura y cierre para que los módulos afecten los servicios disponibles para un usuario.

ARCHIVOS

/etc/pam.conf

el archivo de configuración

/etc/pam.d

el directorio de configuración de Linux-PAM. Generalmente, si este directorio está presente, el archivo /etc/pam.conf se ignora.

/usr/lib/pam.d

el directorio de configuración del proveedor de Linux-PAM. Los archivos en /etc/pam.d anulan los archivos con el mismo nombre en este directorio.

ERRORES

Típicamente, los errores generados por el sistema de librerías Linux-PAM se escribirán en syslog(3).
