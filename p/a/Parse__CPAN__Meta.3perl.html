Parse::CPAN::Meta(3perl) Guía de referencia del programador de Perl Parse::CPAN::Meta(3perl)

NOMBRE

Parse::CPAN::Meta - Analiza archivos de metadatos CPAN META.yml y META.json

VERSIÓN

version 2.150010

SINOPIS

#############################################
# En tu archivo
---
name: My-Distribution
version: 1.23
resources:
  homepage: "http://example.com/dist/My-Distribution"
#############################################
# En tu programa
use Parse::CPAN::Meta;
my $distmeta = Parse::CPAN::Meta->load_file('META.yml');
# Lectura de propiedades
my $name     = $distmeta->{name};
my $version  = $distmeta->{version};
my $homepage = $distmeta->{resources}{homepage};

DESCRIPCIÓN

Parse::CPAN::Meta es un analizador para archivos META.json y META.yml, utilizando JSON::PP y/o CPAN::Meta::YAML.

Parse::CPAN::Meta proporciona tres métodos: "load_file", "load_json_string" y "load_yaml_string". Estos leerán y deserializarán metadatos de CPAN, y se describen a continuación en detalle.

Parse::CPAN::Meta proporciona una API heredada de solo dos funciones, basadas en las funciones YAML del mismo nombre. Siempre que sea posible, se utilizan semánticas de llamada idénticas. Estas solo se pueden utilizar con fuentes YAML.

Todos los informes de errores se realizan mediante excepciones (die'ing).

Tenga en cuenta que se espera que los archivos META estén solo en codificación UTF-8. Al convertir datos de cadena, primero debe decodificarse desde UTF-8.

MÉTODOS

load_file

my $metadata_structure = Parse::CPAN::Meta->load_file('META.json');
my $metadata_structure = Parse::CPAN::Meta->load_file('META.yml');

Este método leerá el archivo nombrado y lo deserializará a una estructura de datos, determinando si debe ser JSON o YAML basándose en el nombre del archivo. El archivo se leerá utilizando la capa de E/S ":utf8".

load_yaml_string

my $metadata_structure = Parse::CPAN::Meta->load_yaml_string($yaml_string);

Este método deserializa la cadena YAML dada y devuelve el primer documento de ella. (Los archivos de metadatos de CPAN siempre deberían tener solo un documento). Si la fuente estaba codificada en UTF-8, la cadena debe decodificarse antes de llamar a "load_yaml_string".

load_json_string

my $metadata_structure = Parse::CPAN::Meta->load_json_string($json_string);

Este método deserializa la cadena JSON dada y el resultado. Si la fuente estaba codificada en UTF-8, la cadena debe decodificarse antes de llamar a "load_json_string".

load_string

my $metadata_structure = Parse::CPAN::Meta->load_string($some_string);

Si no sabe si una cadena contiene datos YAML o JSON, este método utilizará algunas heurísticas y adivinará. Si no puede decirlo, asume YAML.

yaml_backend

my $backend = Parse::CPAN::Meta->yaml_backend;

Devuelve el nombre del módulo del serializador YAML. Consulte "ENTORNO" para obtener detalles.

json_backend

my $backend = Parse::CPAN::Meta->json_backend;

Devuelve el nombre del módulo del serializador JSON. Si "CPAN_META_JSON_BACKEND" está configurado, será lo que sea que esté configurado. Si no, será JSON::PP o JSON. Si "PERL_JSON_BACKEND" está configurado, devolverá JSON, ya que la delegación adicional la maneja el módulo JSON. Consulte "ENTORNO" para obtener detalles.

json_decoder

my $decoder = Parse::CPAN::Meta->json_decoder;

Devuelve el nombre del módulo del decodificador JSON. A diferencia de "json_backend", no es necesariamente un módulo completo de estilo JSON, sino solo algo que proporcionará una subrutina "decode_json". Si "CPAN_META_JSON_DECODER" está configurado, será lo que sea que esté configurado. Si no, será lo que se haya seleccionado como "json_backend". Consulte "ENTORNO" para obtener más notas.

FUNCIONES

Para mayor claridad en el mantenimiento, no se exportan funciones por defecto. Estas funciones están disponibles solo por compatibilidad retroactiva y es mejor evitarlas en favor de "load_file".

Load

my @yaml = Parse::CPAN::Meta::Load( $string );

Analiza una cadena que contiene un flujo YAML válido en una lista de estructuras de datos de Perl.

LoadFile

my @yaml = Parse::CPAN::Meta::LoadFile( 'META.yml' );

Lee el flujo YAML de un archivo en lugar de una cadena.

ENTORNO

CPAN_META_JSON_DECODER

Por defecto, JSON::PP se utilizará para deserializar datos JSON. Si la variable de entorno "CPAN_META_JSON_DECODER" existe, se espera que sea el nombre de un módulo cargable que proporcione una subrutina "decode_json", que luego se utilizará para la deserialización. Confiar solo en la existencia de dicha subrutina permite la máxima compatibilidad, ya que esta API la proporcionan todos, incluidos JSON::PP, JSON::XS, Cpanel::JSON::XS, JSON::MaybeXS, JSON::Tiny y Mojo::JSON.

CPAN_META_JSON_BACKEND

Por defecto, JSON::PP se utilizará para deserializar datos JSON. Si la variable de entorno "CPAN_META_JSON_BACKEND" existe, se espera que sea el nombre de un módulo cargable que proporcione la API JSON, ya que el código descendente espera poder llamar a "new" en esta clase. Como tal, mientras que JSON::PP, JSON::XS, Cpanel::JSON::XS y JSON::MaybeXS funcionarán para esto, usar Mojo::JSON o JSON::Tiny para decodificar requiere configurar "CPAN_META_JSON_DECODER".

PERL_JSON_BACKEND

Si la variable de entorno "CPAN_META_JSON_BACKEND" no existe, y si la variable de entorno "PERL_JSON_BACKEND" existe, es verdadera y no es "JSON::PP", entonces se cargará el módulo JSON (versión 2.5 o posterior) y se utilizará para interpretar "PERL_JSON_BACKEND". Si JSON no está instalado o es demasiado antiguo, se lanzará una excepción. Tenga en cuenta que en el momento de escribir esto, los únicos valores útiles son 1, que le dirá a JSON que adivine, o JSON::XS; si desea utilizar un módulo JSON más reciente, consulte "CPAN_META_JSON_BACKEND".

PERL_YAML_BACKEND

Por defecto, CPAN::Meta::YAML se utilizará para deserializar datos YAML. Si la variable de entorno "PERL_YAML_BACKEND" está definida, entonces se interpreta como un módulo para usar para la deserialización. El módulo dado debe estar instalado, debe cargarse correctamente y debe implementar la función Load() o se lanzará una excepción.
