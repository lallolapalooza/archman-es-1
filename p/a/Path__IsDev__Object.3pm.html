Path::IsDev::Object(3) Documentación de Perl aportada por el usuario Path::IsDev::Object(3)

NOMBRE

Path::IsDev::Object - Lógica orientada a objetos para la exportación de IsDev

VERSIÓN

versión 1.001003

SINOPSIS

use Path::IsDev::Object;
my $dev = Path::IsDev::Object->new();
my $dev = Path::IsDev::Object->new( set => 'MySet' );
if ( $dev->matches($path) ){
    print "$path es de desarrollo";
}

DESCRIPCIÓN

Exportar funciones es útil para los usuarios finales, pero rápidamente se convierte en un gran dolor de cabeza cuando intentas encadenarlas.

Ejemplo: Si estás escribiendo un exportador tú mismo, y quieres envolver las respuestas de un símbolo exportado, al mismo tiempo que pasas la configuración del usuario => Gran dolor de cabeza.

Por lo tanto, la interfaz basada en exportadores está ahí para las personas que no necesitan nada especial, mientras que la interfaz orientada a objetos está ahí para las personas con requisitos más complejos.

MÉTODOS

"matches"

Determina si una ruta dada satisface el "set"

if( $o->matches($path) ){
    print "¡Tenemos una coincidencia!";
}

ATRIBUTOS

"set"

El nombre del "HeuristicSet::" a usar.

El valor predeterminado es "Basic", o el valor de $ENV{PATH_ISDEV_DEFAULT_SET}

"set_prefix"

El prefijo "HeuristicSet" a usar para expandir "set" a un nombre de módulo.

El valor predeterminado es "Path::IsDev::HeuristicSet"

"set_module"

El nombre del módulo completamente calificado.

Compuesto uniendo "set" y "set_prefix"

"loaded_set_module"

Un accesor que devuelve un nombre de módulo después de cargarlo.

MÉTODOS PRIVADOS

"_instance_id"

Un número de secuencia oportunista para ayudar con los mensajes de depuración.

Nota: No se garantiza que sea único por instancia, solo se garantiza que sea constante durante la vida del objeto.

Basado en "refaddr", y dando nuevos IDs cuando se ven nuevos "refaddr".

"_debug"

La función de devolución de llamada de depuración.

export PATH_ISDEV_DEBUG=1

para obtener información de depuración.

"_with_debug"

Envuelve llamadas a Path::IsDev::debug para tener un prefijo con un identificador de objeto.

$ob->_with_debug(sub{
    # Path::Tiny::debug ahora está localizado.
});

"BUILD"

"BUILD" es un detalle de implementación de "Class::Tiny".

Este módulo engancha "BUILD" para dar un auto-reporte del objeto a *STDERR después de "->new" cuando está bajo $DEBUG

"_matches"

my $result = $o->matches( $path );

$result aquí será un "Path::IsDev::Result" construido.

Tenga en cuenta que este método puede ser útil para depurar, pero aún debe llamar a "matches" para todo el código real.
