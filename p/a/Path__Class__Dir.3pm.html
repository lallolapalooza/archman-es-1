Path::Class::Dir(3pm) Documentación de Perl contribuida por el usuario Path::Class::Dir(3pm)

NOMBRE

Path::Class::Dir - Objetos que representan directorios

VERSIÓN

versión 0.37

SINOPSIS

use Path::Class;  # Exporta dir() por defecto

my $dir = dir('foo', 'bar');       # Objeto Path::Class::Dir
my $dir = Path::Class::Dir->new('foo', 'bar');  # Lo mismo

# Se convierte en cadena como 'foo/bar' en Unix, 'foo\bar' en Windows, etc.
print "dir: $dir\n";

if ($dir->is_absolute) { ... }
if ($dir->is_relative) { ... }

my $v = $dir->volume; # Podría ser 'C:' en Windows, cadena vacía
                      # en Unix, 'Macintosh HD:' en Mac OS

$dir->cleanup; # Realiza limpieza lógica del nombre de ruta
$dir->resolve; # Realiza limpieza física del nombre de ruta

my $file = $dir->file('file.txt'); # Un archivo en este directorio
my $subdir = $dir->subdir('george'); # Un subdirectorio
my $parent = $dir->parent; # El directorio padre, 'foo'

my $abs = $dir->absolute; # Transforma a ruta absoluta
my $rel = $abs->relative; # Transforma a ruta relativa
my $rel = $abs->relative('/foo'); # Relativa a /foo

print $dir->as_foreign('Mac');   # :foo:bar:
print $dir->as_foreign('Win32'); #  foo\bar
# Iterar con métodos de IO::Dir:
my $handle = $dir->open;
while (my $file = $handle->read) {
  $file = $dir->file($file);  # Convertir en objeto Path::Class::File
  ...
}

# Iterar con métodos de Path::Class:
while (my $file = $dir->next) {
  # $file es un objeto Path::Class::File o Path::Class::Dir
  ...
}

DESCRIPCIÓN

La clase "Path::Class::Dir" contiene funcionalidad para manipular nombres de directorios de forma multiplataforma.

MÉTODOS

$dir = Path::Class::Dir->new( <dir1>, <dir2>, ... )
$dir = dir( <dir1>, <dir2>, ... )
Crea y devuelve un nuevo objeto "Path::Class::Dir". Los argumentos especifican nombres de directorios que se unirán para crear un único objeto de directorio. También se puede especificar un volumen como primer argumento, o como parte del primer argumento. Puedes usar sintaxis neutral a la plataforma: 
my $dir = dir( 'foo', 'bar', 'baz' );

o sintaxis nativa de la plataforma:

my $dir = dir( 'foo/bar/baz' );

o una mezcla de ambas:

my $dir = dir( 'foo/bar', 'baz' );

Los tres ejemplos anteriores crean rutas relativas. Para crear una ruta absoluta, usa la sintaxis nativa de la plataforma para hacerlo:

my $dir = dir( '/var/tmp' );

o usa una cadena vacía como primer argumento:

my $dir = dir( '', 'var', 'tmp' );

Si la segunda forma parece extraña, es algo intencional: las rutas como "/var/tmp" o "\Windows" no son conceptos multiplataforma en primer lugar (muchas plataformas no Unix no tienen una noción de "directorio raíz"), por lo que probablemente no deberían aparecer en tu código si intentas ser multiplataforma. La primera forma es perfectamente natural, porque rutas como esta pueden venir de archivos de configuración, entrada del usuario o lo que sea.

Como caso especial, ya que de otra manera no tiene un significado útil y es conveniente definirlo de esta manera, "Path::Class::Dir->new()" (o dir()) se refiere al directorio actual ("File::Spec->curdir"). Para obtener el directorio actual como ruta absoluta, haz "dir()->absolute".

Finalmente, como otro caso especial, dir(undef) devolverá undef, ya que esto suele ser un accidente por parte del llamador, y devolver el directorio raíz sería una sorpresa desagradable que solo pediría problemas unas líneas más tarde.

$dir->stringify
Este método se llama internamente cuando un objeto "Path::Class::Dir" se usa en un contexto de cadena, por lo que lo siguiente es equivalente: 
$string = $dir->stringify;
$string = "$dir";
$dir->volume
Devuelve el volumen (ej. "C:" en Windows, "Macintosh HD:" en Mac OS, etc.) del objeto directorio, si lo hay. De lo contrario, devuelve la cadena vacía.
$dir->basename
Devuelve el último nombre de directorio de la ruta como una cadena.
$dir->is_dir
Devuelve un valor booleano que indica si este objeto representa un directorio. No es sorprendente que los objetos Path::Class::File siempre devuelvan falso, y los objetos "Path::Class::Dir" siempre devuelvan verdadero.
$dir->is_absolute
Devuelve verdadero o falso dependiendo de si el directorio se refiere a un especificador de ruta absoluta (como "/usr/local" o "\Windows").
$dir->is_relative
Devuelve verdadero o falso dependiendo de si el directorio se refiere a un especificador de ruta relativa (como "lib/foo" o "./dir").
$dir->cleanup
Realiza una limpieza lógica de la ruta del archivo. Por ejemplo: 
my $dir = dir('/foo//baz/./foo')->cleanup;
# $dir ahora representa '/foo/baz/foo';
$dir->resolve
Realiza una limpieza física de la ruta del archivo. Por ejemplo: 
my $dir = dir('/foo//baz/../foo')->resolve;
# $dir ahora representa '/foo/foo', asumiendo que no hay enlaces simbólicos

Esto en realidad consulta el sistema de archivos para verificar la validez de la ruta.

$file = $dir->file( <dir1>, <dir2>, ..., <file> )
Devuelve un objeto Path::Class::File que representa una entrada en $dir o uno de sus subdirectorios. Internamente, esto simplemente llama a "Path::Class::File->new( @_ )".
$subdir = $dir->subdir( <dir1>, <dir2>, ... )
Devuelve un nuevo objeto "Path::Class::Dir" que representa un subdirectorio de $dir.
$parent = $dir->parent
Devuelve el directorio padre de $dir. Ten en cuenta que este es el padre *lógico*, no necesariamente el padre físico. Realmente significa que simplemente eliminamos entradas del final de la lista de directorios hasta que no podemos eliminar más. Si el directorio es relativo, comenzamos a usar las formas relativas de los directorios padre.

El siguiente código demuestra el comportamiento en directorios absolutos y relativos:

$dir = dir('/foo/bar');
for (1..6) {
  print "Absoluto: $dir\n";
  $dir = $dir->parent;
}

$dir = dir('foo/bar');
for (1..6) {
  print "Relativo: $dir\n";
  $dir = $dir->parent;
}

Absoluto: /foo
Absoluto: /
Absoluto: /
Absoluto: /
Absoluto: /
Relativo: foo/bar
Relativo: foo
Relativo: .
Relativo: ..
Relativo: ../..
Relativo: ../../..
@list = $dir->children
Devuelve una lista de objetos Path::Class::File y/o "Path::Class::Dir" listados en este directorio, o en contexto de escalar el número de dichos objetos. Obviamente, es necesario que $dir exista y sea legible para poder encontrar sus hijos.

Ten en cuenta que los hijos se devuelven como subdirectorios de $dir, es decir, los hijos de foo serán foo/bar y foo/baz, no bar y baz.

Normalmente children() no incluirá las entradas self y parent "." y ".." (o sus equivalentes en sistemas no Unix), porque eso es como el negocio de "yo soy mi propio abuelo". Si quieres todas las entradas del directorio incluyendo estas especiales, pasa un valor verdadero para el parámetro "all":

@c = $dir->children(); # Solo los hijos
@c = $dir->children(all => 1); # Todas las entradas

Además, hay un parámetro "no_hidden" que excluirá todas las entradas normalmente "ocultas" - en Unix esto significa excluir todas las entradas que comiencen con un punto ("."):

@c = $dir->children(no_hidden => 1); # Solo entradas normalmente visibles

$dir->absolute
Devuelve un objeto "Path::Class::Dir" que representa $dir como una ruta absoluta. Un argumento opcional, dado como una cadena o un objeto "Path::Class::Dir", especifica el directorio a usar como base de relatividad - de lo contrario, se usará la carpeta de trabajo actual.
$rel = $dir->relative
Devuelve un objeto "Path::Class::Dir" que representa $dir como una ruta relativa. Un argumento opcional, dado como una cadena o un objeto "Path::Class::Dir", especifica el directorio a usar como base de relatividad - de lo contrario, se usará la carpeta de trabajo actual.
$boolean = $dir->subsumes($other)
Devuelve true si esta especificación subsume a la otra especificación, y false de lo contrario. Piensa de "subsumes" como "contiene", pero solo se analizan las especificaciones, no si $dir realmente contiene $other en el sistema de archivos.

El argumento $other puede ser un objeto "Path::Class::Dir", un objeto Path::Class::File o una cadena. En el caso de la cadena, asumimos que es un directorio.

# Ejemplos:
dir('foo/bar' )->subsumes(dir('foo/bar/baz'))  # True
dir('/foo/bar')->subsumes(dir('/foo/bar/baz')) # True
dir('foo/..')->subsumes(dir('foo/../bar))      # True
dir('foo/bar' )->subsumes(dir('bar/baz'))      # False
dir('/foo/bar')->subsumes(dir('foo/bar'))      # False
dir('foo/..')->subsumes(dir('bar'))            # False! Usa C<contains> para resolver ".."
$boolean = $dir->contains($other)
Devuelve true si esta carpeta realmente contiene $other en el sistema de archivos. $other no tiene que ser un hijo directo de $dir, solo tiene que estar subsumido después de que ambas rutas hayan sido resueltas.
$foreign = $dir->as_foreign($type)
Devuelve un objeto "Path::Class::Dir" que representa $dir como lo haría en un sistema de tipo $type. Tipos conocidos incluyen "Unix", "Win32", "Mac", "VMS" y "OS2", es decir, cualquier sistema para el cual existe una clase heredada de "File::Spec".

Los objetos generados (subdirectorios, archivos, padres, etc.) también mantendrán este tipo.

$foreign = Path::Class::Dir->new_foreign($type, @args)
Devuelve un objeto "Path::Class::Dir" que representa $dir como lo haría en un sistema de tipo $type. Tipos conocidos incluyen "Unix", "Win32", "Mac", "VMS" y "OS2", es decir, cualquier sistema para el cual existe una clase heredada de "File::Spec".

Los argumentos en @args son los mismos que en new().

@list = $dir->dir_list([OFFSET, [LENGTH]])
Devuelve la lista de strings que representan el estructura de esta carpeta. Cada elemento sucesivo de la lista se entiende como un elemento en el directorio anterior. Según la contract, "Path::Class->new( $dir->dir_list )" debe ser equivalente a $dir.

El sentido de este método es similar a los funciones Perl "splice" o "substr"; devuelven "LENGTH" elementos comenzando en "OFFSET". Si "LENGTH" está omitido, devuelve todos los elementos comenzando en "OFFSET" hasta el final de la lista. Si "LENGTH" es negativo, devuelve los elementos desde "OFFSET" hacia atrás, excepto los "-LENGTH" al final. Si "OFFSET" es negativo, se cuenta hacia atrás "OFFSET" elementos desde el final de la lista. Si "OFFSET" y "LENGTH" son ambos omitidos, devuelve toda la lista.

En contexto escalar, dir_list() con ningún argumento devuelve el número de entradas en la lista de directorios; dir_list(OFFSET) devuelve el elemento en ese índice; "dir_list(OFFSET, LENGTH)" devuelve el último elemento que se hubiera devuelto en un contexto de lista.

$dir->components
Es idéntico a dir_list(). Existe porque hay una método similar dir_list() en la clase "Path::Class::File" que también devuelve la cadena de nombre de archivo, así que este método permite llamar a components() sin importar si el objeto es un archivo o un directorio.
$fh = $dir->open()
Pasa $dir a "IO::Dir->open" y devuelve el resultado como un objeto IO::Dir. Si la apertura falla, se devuelve "undef" y se establece $!.
$dir->mkpath($verbose, $mode)
Pasa todos los argumentos, incluidos $dir, a File::Path::mkpath() y devuelve el resultado (una lista de todos los directorios creados).
$dir->rmtree($verbose, $cautious)
Pasa todos los argumentos, incluidos $dir, a File::Path::rmtree() y devuelve el resultado (el número de archivos eliminados exitosamente).
$dir->remove()
Elimina el directorio, que debe estar vacío. Devuelve un valor booleano indicando si o no se eliminó correctamente el directorio. Este método es principalmente proporcionado para mantener la consistencia con el método "remove()" de la clase "Path::Class::File".
$dir->tempfile(...)
Es una interfaz a la función tempfile() de File::Temp. Es similar a esa función; si se llama en contexto escalar, el valor devuelto es el handle de archivo y el archivo se elimina inmediatamente (en plataformas Unix-like). Si se llama en contexto de lista, los valores devueltos son el handle de archivo y el nombre del archivo.

El directorio dado se pasa como el parámetro "DIR".

A continuación, un ejemplo de uso práctico que no genera conflictos de lectura, no deja archivos temporales mal hechos en tu sistema de archivos, etc.:

my $fh = $dir->tempfile;
print $fh "Here's some data...\n";
seek($fh, 0, 0);
while (<$fh>) { do something... }

O en combinación con un "fork":

my $fh = $dir->tempfile;
print $fh "Here's some more data...\n";
seek($fh, 0, 0);
if ($pid=fork()) {
  wait;
} else {
  something($_) while <$fh>;
}
$dir_or_file = $dir->next()
Es una forma conveniente de iterar sobre los contenidos de un directorio. La primera vez que se llama a next(), abre el directorio y lee el primer elemento, devolviendo el resultado como un objeto "Path::Class::Dir" o Path::Class::File (dependiendo de su tipo real). Cada llamada posterior a next() itera sobre los contenidos del directorio, hasta que no haya más elementos, en que caso devuelve el valor undefined. Por ejemplo, para iterar sobre todos los archivos regulares en un directorio: 
while (my $file = $dir->next) {
  next unless -f $file;
  my $fh = $file->open('r') or die "Can't read $file: $!";
  ...
}

Si hay un error al abrir el directorio (por ejemplo, no existe o no es lecturado), next() lanzará una excepción con el valor de $!.

$dir->traverse( sub { ... }, @args )
Llama a la función de callback dada para la raíz, pasándole una función de continuación que, al ser llamada, llamará recursivamente a este método en cada uno de sus hijos. La función de callback debe ser de la forma: 
sub {
  my ($child, $cont, @args) = @_;
  # ...
}

Por ejemplo, para calcular el número de archivos en un directorio, puedes hacer esto:

my $nfiles = $dir->traverse(sub {
  my ($child, $cont) = @_;
  return sum($cont->(), ($child->is_dir ? 0 : 1));
});

o para calcular la profundidad máxima de un directorio:

my $depth = $dir->traverse(sub {
  my ($child, $cont, $depth) = @_;
  return max($cont->($depth + 1), $depth);
}, 0);

También puedes elegir no llamar a la callback en ciertos situaciones:

$dir->traverse(sub {
  my ($child, $cont) = @_;
  return if -l $child; # no seguir enlaces
  # hacer algo con $child
  return $cont->();
});
$dir->traverse_if( sub { ... }, sub { ... }, @args )
itera con una función de callback adicional "debería visitar este hijo". Es especialmente útil en caso de arboles examinados que contienen directorios inaccesibles.

Ejemplo canónico:

$dir->traverse_if(
  sub {
     my ($child, $cont) = @_;
     # hacer algo con $child
     return $cont->();
  }, 
  sub {
     my ($child) = @_;
     # procesar solo items lecturados
     return -r $child;
  });

La segunda callback devuelve un solo parámetro: el hijo. Solo los hijos para los cuales devuelve true en la primera callback se procesarán con la primera.

Los parámetros restantes se interpretan como en traverse, en particular "traverse_if(callback, sub { 1 }, @args" es equivalente a "traverse(callback, @args)".

$dir->recurse( callback => sub {...} )
Itera a través de este directorio y todos sus hijos, y todos sus hijos' hijos, etc., llamando la subrutina "callback" para cada entrada. Esto es bastante similar a lo que hace el módulo File::Find, y naturalmente "File::Find" funcionará bien en Path::Class.
Path::Class::Dir(3pm)

NAME

Path::Class::Dir - Directories.

VERSION

v0.37

SYNOPSIS

    use Path::Class;
    my $dir = dir('foo');
    $dir->mkpath;
    my $file = $dir->file('bar');
    $file->touch;
    my @files = $dir->children;
    my @dirs  = $dir->dirs;
    my @files = $dir->files;

DESCRIPTION

This class represents a directory on the filesystem. It is a subclass of Path::Class::Entity.

This class provides methods for creating directories, traversing them, and retrieving their contents.

METHODS

children
Returns a list of Path::Class objects representing all the files and directories within this directory. The order is arbitrary.

This method is equivalent to calling slurp() without arguments.

dirs
Returns a list of Path::Class objects representing only the directories within this directory. The order is arbitrary.
files
Returns a list of Path::Class objects representing only the files within this directory. The order is arbitrary.
mkpath
Creates this directory and any necessary parent directories. This is equivalent to File::Path::mkpath().
slurp
Equivalent to children(). Provided for consistency with Path::Class::File.
recurse
Recursively traverses the directory tree, calling a callback routine for each entry. The callback routine is passed the Path::Class object for the entry as its first argument.
recurse (callback => sub { ... })

The recurse() method is a convenient way to traverse a directory tree. It's similar to File::Find::find(), but it operates on Path::Class objects rather than just pathname strings.

The recurse() method requires a callback parameter specifying the subroutine to invoke for each entry. It will be passed the Path::Class object as its first argument.

recurse() also accepts two boolean parameters, depthfirst and preorder that control the order of recursion. The default is a preorder, breadth-first search, i.e. depthfirst => 0, preorder => 1. At the time of this writing, all combinations of these two parameters are supported except depthfirst => 0, preorder => 0.

callback is normally not required to return any value. If it returns special constant Path::Class::Entity::PRUNE() (more easily available as "$item->PRUNE"), no children of analyzed item will be analyzed (mostly as if you set "$File::Find::prune=1"). Of course pruning is available only in preorder, in postorder return value has no effect.

$st = $file->stat()
Invokes File::stat::stat() on this directory and returns a "File::stat" object representing the result.
$st = $file->lstat()
Same as stat(), but if $file is a symbolic link, lstat() stats the link instead of the directory the link points to.
$class = $file->file_class()
Returns the class which should be used to create file objects.

Generally overridden whenever this class is subclassed.
