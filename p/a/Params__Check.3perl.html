Params::Check(3perl) Perl Programmers Reference Guide Params::Check(3perl)

NOMBRE

Params::Check - Un mecanismo genérico de análisis/verificación de entrada.

SINOPSIS

use Params::Check qw[check allow last_error];
sub fill_personal_info {
    my %hash = @_;
    my $x;
    my $tmpl = {
        firstname   => { required   => 1, defined => 1 },
        lastname    => { required   => 1, store => \$x },
        gender      => { required   => 1,
                         allow      => [qr/M/i, qr/F/i],
                       },
        married     => { allow      => [0,1] },
        age         => { default    => 21,
                         allow      => qr/^\d+$/,
                       },
        phone       => { allow => [ sub { return 1 if /$valid_re/ },
                                    '1-800-PERL' ]
                       },
        id_list     => { default        => [],
                         strict_type    => 1
                       },
        employer    => { default => 'NSA', no_override => 1 },
    };
    ### check() returns a hashref of parsed args on success ###
    my $parsed_args = check( $tmpl, \%hash, $VERBOSE )
                        or die qw[Could not parse arguments!];
    ... other code here ...
}
my $ok = allow( $colour, [qw|blue green yellow|] );
my $error = Params::Check::last_error();

DESCRIPCIÓN

Params::Check es un mecanismo genérico de análisis/verificación de entrada.

Te permite validar la entrada a través de una plantilla. El único requisito es que los argumentos deben ser con nombre.

Params::Check puede hacer lo siguiente por ti:

  • Convertir todas las claves a minúsculas
  • Verificar si se han proporcionado todos los argumentos requeridos
  • Establecer los argumentos que no se han proporcionado a su valor predeterminado
  • Descartar los argumentos que no son compatibles y advertir sobre ellos al usuario
  • Validar los argumentos proporcionados por el usuario basándose en cadenas, expresiones regulares, listas o incluso subrutinas
  • Forzar la integridad del tipo si es necesario

La mayor parte del poder de Params::Check proviene de su plantilla, que discutiremos a continuación:

Plantilla

Como puedes ver en la sinopsis, basándose en tu plantilla, los argumentos proporcionados serán validados.

La plantilla puede tomar un conjunto diferente de reglas por clave que se utiliza.

Las siguientes reglas están disponibles:

default
Este es el valor predeterminado si el usuario no proporcionó ninguno. Este también es el tipo al que "strict_type" mirará al verificar la integridad del tipo (ver abajo).
required
Un indicador booleano que indica si este argumento era un argumento requerido. Si se marca como requerido y no se proporciona, check() fallará.
strict_type
Esto realiza una verificación ref() en el argumento proporcionado. El "ref" del argumento debe ser el mismo que el "ref" del valor predeterminado para que esta verificación sea exitosa.

Esto es muy útil si insistes en tomar una referencia de matriz como argumento, por ejemplo.

defined
Si esta clave de plantilla es verdadera, exige que si esta clave es proporcionada por la entrada del usuario, su valor esté "definido". Esto simplemente significa que al usuario no se le permite pasar "undef" como valor para esta clave y es equivalente a:
allow => sub { defined $_[0] && OTROS TESTS }
no_override
Esto te permite especificar "constantes" en tu plantilla. Es decir, las claves que no se pueden modificar por el usuario. Prácticamente te permite mantener todos tus datos "configurables" en un solo lugar; la plantilla de "Params::Check".
store
Esto te permite pasar una referencia a un escalar, en el que se almacenarán los datos: 
my $x;
my $args = check(foo => { default => 1, store => \$x }, $input);

Esto es básicamente una abreviatura para decir:

my $args = check( { foo => { default => 1 }, $input );
my $x    = $args->{foo};

Puedes alterar la variable global $Params::Check::NO_DUPLICATES para controlar si la clave "store" todavía estará presente en tu conjunto de resultados. Ver la sección "Variables Globales" abajo.

allow
Un conjunto de criterios utilizados para validar una pieza particular de datos si debe cumplir con reglas específicas.

Ver la función allow() para detalles.

Funciones

check( \%tmpl, \%args, [$verbose] );

Esta función no se exporta por defecto, por lo que tendrás que solicitarla a través de:

use Params::Check qw[check];

o usar su nombre completamente calificado en su lugar.

"check" toma una lista de argumentos, como sigue:

Plantilla
Este es una referencia de hash que contiene una plantilla como se explica en las secciones "SINOPSIS" y "Plantilla".
Argumentos
Esta es una referencia a un hash de argumentos con nombre que necesitan ser verificados.
Verbose
Un booleano para indicar si "check" debe ser verboso y advertir sobre lo que salió mal en una verificación o no.

Puedes habilitar esto en todo el programa estableciendo la variable de paquete $Params::Check::VERBOSE a un valor verdadero. Para detalles, ver la sección sobre "Variables Globales" abajo.

"check" devolverá cuando falle, o un hashref con claves en minúsculas de argumentos analizados cuando tenga éxito.

Así que una llamada típica a check se vería así:

my $parsed = check( \%template, \%arguments, $VERBOSE )
                or warn q[Arguments could not be parsed!];

Gran parte del comportamiento de check() puede ser alterado estableciendo variables de paquete. Ver la sección de "Variables Globales" para detalles sobre esto.

allow( $test_me, \@criteria );

La función que maneja la clave "allow" en la plantilla también está disponible para uso independiente.

La función toma como primer argumento una clave para probar contra, y como segundo argumento cualquier forma de criterios que también sean permitidos por la clave "allow" en la plantilla.

Puedes usar los siguientes tipos de valores para allow:

cadena
El argumento proporcionado DEBE ser igual a la cadena para que la validación sea exitosa.
expresión regular
El argumento proporcionado DEBE coincidir con la expresión regular para que la validación sea exitosa.
subrutina
La subrutina proporcionada DEBE devolver verdadero para que la validación sea exitosa y el argumento aceptado.

(Esto es particularmente útil para datos más complicados).

ref de matriz
El argumento proporcionado DEBE ser igual a uno de los elementos del ref de matriz para que la validación sea exitosa. Un ref de matriz puede contener todos los valores anteriores.

Devuelve verdadero si la clave coincidió con los criterios, o falso en caso contrario.

last_error()

Devuelve una cadena que contiene todas las advertencias y errores informados durante la última vez que se llamó a "check".

Variables Globales

Se pueden alterar las siguientes variables de paquete para cambiar el comportamiento de Params::Check:

$Params::Check::VERBOSE
Si se establece en verdadero, check() será más verboso y advertirá sobre problemas con los argumentos proporcionados. Por defecto, es falso.
$Params::Check::WARN
Si se establece en verdadero, check() emitirá una advertencia sobre argumentos no reconocidos. Por defecto, es verdadero.
$Params::Check::STRICT
Si se establece en verdadero, check() emitirá una advertencia sobre argumentos no reconocidos. Por defecto, es falso.
$Params::Check::NO_DUPLICATES
Si se establece en verdadero, la clave utilizada con la opción "store" no se incluirá en el hashref devuelto por check(). Por defecto, es falso.
$Params::Check::ALLOW_UNDEF
Por defecto, check() falla si un valor requerido o verificado es undef. Si esta variable se establece en verdadera, permitirá explícitamente que undef pase las verificaciones, excepto cuando se especifica explícitamente "defined => 1".

Params::Check(3perl) — Params::Check — Manual de Perl

NAME

Params::Check - A module for checking parameters passed to subroutines.

SYNOPSIS

    use Params::Check;
    my $check = new Params::Check( template );
    my $result = $check->check( args );
    # or
    my $result = Params::Check::check( template, args );

DESCRIPTION

Params::Check is a module that helps in checking the parameters passed to a subroutine. It allows you to define a template that specifies what parameters are expected, their types, and other constraints. It then checks the actual arguments passed to the subroutine against this template.

This module is useful for creating robust and user-friendly subroutines, as it can catch errors early and provide informative messages about incorrect arguments.

Template

The template is a hashref that defines the expected parameters. Each key in the hashref is a parameter name, and its value is another hashref containing the parameter's attributes. Some common attributes include:

"type"
Specifies the expected data type of the parameter (e.g., 'scalar', 'arrayref', 'hashref', 'coderef').
"default"
A default value to use if the parameter is not provided.
"required"
A boolean value indicating whether the parameter is mandatory.
"store"
If true, the value of the parameter will be stored in a scalar variable (passed as an argument to the check method).
"defined"
If true, the parameter's value must be defined (not undef).
"matches"
A regular expression that the parameter's value must match.

Example template:

    my $template = {
        name     => { type => 'string', required => 1 },
        age      => { type => 'integer', default => 0 },
        callback => { type => 'coderef' },
        options  => { type => 'hashref', default => sub { {} } },
    };

Functions

new

Creates a new Params::Check object with the given template.

    my $check = Params::Check->new( $template );

check

Checks the provided arguments against the template associated with the Params::Check object or a given template.

It returns a hashref containing the validated parameters. If validation fails, it returns false and an error message can be retrieved using Params::Check::last_error.

    my $result = $check->check( @args );
    # or
    my $result = Params::Check::check( $template, @args );

Options can be passed to the check method as a hashref before the arguments:

    my $result = $check->check( { strict_type => 1 }, @args );
"strict_type"
If true, performs stricter type checking. For example, it will reject integers for string parameters.
"allow_unknown"
If true, unknown parameters in the arguments will not cause an error and will be included in the returned hashref.
"strip_leading_dashes"
If true, leading dashes from parameter names will be removed (e.g., -key becomes key).
"no_duplicates"
If true, parameters marked with store in the template will be removed from the returned hashref.
"preserve_case"
If true, parameter names will not be converted to lowercase. This disables case-insensitive matching.
"only_allow_defined"
If true, all parameter values must be defined.
"sanity_check_template"
If true, the template itself will be checked for errors. This can slow down performance.

last_error

Returns the last error message encountered during a check operation. This is a static method.

    my $error = Params::Check::last_error();

carp

The carp method is called when a validation error occurs and the global variable $Params::Check::VERBOSE is set. It is exported upon request.

This is useful if you want to report then some other way than "carp"'ing when the verbose flag is on.

It is exported upon request.

Global Variables

The behaviour of Params::Check can be altered by changing the following global variables:

$Params::Check::VERBOSE

This controls whether Params::Check will issue warnings and explanations as to why certain things may have failed. If you set it to 0, Params::Check will not output any warnings.

The default is 1 when warnings are enabled, 0 otherwise;

$Params::Check::STRICT_TYPE

This works like the "strict_type" option you can pass to "check", which will turn on "strict_type" globally for all calls to "check".

The default is 0;

$Params::Check::ALLOW_UNKNOWN

If you set this flag, unknown options will still be present in the return value, rather than filtered out. This is useful if your subroutine is only interested in a few arguments, and wants to pass the rest on blindly to perhaps another subroutine.

The default is 0;

$Params::Check::STRIP_LEADING_DASHES

If you set this flag, all keys passed in the following manner:

function( -key => 'val' );

will have their leading dashes stripped.

$Params::Check::NO_DUPLICATES

If set to true, all keys in the template that are marked as to be stored in a scalar, will also be removed from the result set.

Default is false, meaning that when you use "store" as a template key, "check" will put it both in the scalar you supplied, as well as in the hashref it returns.

$Params::Check::PRESERVE_CASE

If set to true, Params::Check will no longer convert all keys from the user input to lowercase, but instead expect them to be in the case the template provided. This is useful when you want to use similar keys with different casing in your templates.

Understand that this removes the case-insensitivity feature of this module.

Default is 0;

$Params::Check::ONLY_ALLOW_DEFINED

If set to true, Params::Check will require all values passed to be "defined". If you wish to enable this on a 'per key' basis, use the template option "defined" instead.

Default is 0;

$Params::Check::SANITY_CHECK_TEMPLATE

If set to true, Params::Check will sanity check templates, validating for errors and unknown keys. Although very useful for debugging, this can be somewhat slow in hot-code and large loops.

To disable this check, set this variable to "false".

Default is 1;

$Params::Check::WARNINGS_FATAL

If set to true, Params::Check will "croak" when an error during template validation occurs, rather than return "false".

Default is 0;

$Params::Check::CALLER_DEPTH

This global modifies the argument given to caller() by Params::Check::check() and is useful if you have a custom wrapper function around Params::Check::check(). The value must be an integer, indicating the number of wrapper functions inserted between the real function call and Params::Check::check().

Example wrapper function, using a custom stacktrace:

sub check {
    my ($template, $args_in) = @_;
    local $Params::Check::WARNINGS_FATAL = 1;
    local $Params::Check::CALLER_DEPTH = $Params::Check::CALLER_DEPTH + 1;
    my $args_out = Params::Check::check($template, $args_in);
    my_stacktrace(Params::Check::last_error) unless $args_out;
    return $args_out;
}

Default is 0;
