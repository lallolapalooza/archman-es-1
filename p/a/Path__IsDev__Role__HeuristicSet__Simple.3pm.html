Path::IsDev::Role::HeuristicSet::Simple(3) Documentación de Perl contribuida por el usuario Path::IsDev::Role::HeuristicSet::Simple(3)

NOMBRE

Path::IsDev::Role::HeuristicSet::Simple - Conjunto simple de exclusiones/inclusiones

VERSIÓN

versión 1.001003

ROL REQUIERE

"heuristics"

Las clases consumidoras deben proporcionar este método y devolver una lista de Heurísticas abreviadas.

sub heuristics {
    return qw( MYMETA )
}

"negative_heuristics"

Las clases consumidoras deben proporcionar este método y devolver una lista de Heurísticas Negativas abreviadas.

sub negative_heuristics {
    return qw( IsDev::IgnoreFile )
}

MÉTODOS

"modules"

Devuelve la lista de nombres de módulos completamente calificados que componen esta heurística.

expande los resultados de "->heuristics" y "->negative_heuristics", con los negativos precediendo a los positivos.
