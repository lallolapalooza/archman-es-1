DESCRIPCIÓN

Estas funciones sirven para extender y/o modificar el comportamiento de la familia de funciones printf(3).

register_printf_specifier()

Esta función registra un especificador de conversión personalizado para la familia de funciones printf(3).

Función de devolución de llamada que será ejecutada por la familia de funciones printf(3) para formatear los argumentos de entrada en el flujo de salida stream.
stream
Flujo de salida donde se debe imprimir la salida formateada. Este flujo representa transparentemente la salida, incluso en el caso de funciones que escriben en una cadena.

Estructura que contiene información de contexto, incluyendo los modificadores especificados en la cadena de formato. Contiene los mismos contenidos que en arginfo.

VALOR DE RETORNO

register_printf_specifier(), register_printf_modifier(), y register_printf_type() devuelven cero en caso de éxito, o -1 en caso de error.

Callbacks (Funciones de devolución de llamada)

La devolución de llamada de tipo printf_function debe devolver el número de caracteres escritos, o -1 en caso de error.

La devolución de llamada de tipo printf_arginfo_size_function debe devolver el número de argumentos a analizar para este especificador. También pasa información sobre el tipo de esos argumentos al llamador a través de argtypes. En caso de error, debe devolver -1.

NAME

register_printf_specifier ― registrar un especificador de formato para printf

LIBRARY

Opciones de formato de printf (libprintf, -lprintf)

SYNOPSIS

#include <printf.h>

int register_printf_specifier(int c, printf_arginfo_t arginfo, printf_render_t render);

int register_printf_specifier_m(int c, printf_arginfo_mult_t arginfo, printf_render_mult_t render);

DESCRIPTION

Estas funciones registran un nuevo especificador de formato para el conjunto de funciones de impresión printf, sprintf, fprintf, etc. El carácter c es el especificador de formato que se registrará. Por ejemplo, para registrar el especificador 'b', se pasaría 'b'.

La función register_printf_specifier es una interfaz obsoleta que solo se puede usar para registrar manejadores de argumentos de un solo valor. La función register_printf_specifier_m es la interfaz preferida, ya que permite especificar el número de argumentos que consume un especificador y el tipo de esos argumentos.

El argumento arginfo es un puntero a una función que toma la estructura printf_info (que contiene información sobre el especificador de formato y los modificadores utilizados) y, para register_printf_specifier_m, un array argtypes. La función arginfo debe rellenar el array argtypes con los tipos de los argumentos que consume el especificador. Las constantes de tipo de argumento son PA_INT, PA_FLOAT, PA_STRING, PA_POINTER, PA_CHAR y PA_LAST. Se pueden combinar utilizando el operador OR bit a bit. También se pueden usar los flags PA_FLAG_LONG, PA_FLAG_LONG_LONG, PA_FLAG_LONG_DOUBLE, PA_FLAG_UNSIGNED y PA_FLAG_NEGATIVE.

Para register_printf_specifier_m, la función arginfo debe devolver el número de argumentos consumidos. Para register_printf_specifier, siempre se asume un solo argumento.

El argumento render es un puntero a una función que toma un puntero a FILE, la estructura printf_info y un array de punteros a los argumentos. La función render debe imprimir la representación formateada de los argumentos en el flujo FILE y devolver el número de caracteres escritos. Si ocurre un error, debe devolver EOF.

Las estructuras printf_info y printf_arginfo_mult contienen información sobre el especificador de formato y los modificadores utilizados, como el ancho, la precisión, el flag de alineación a la izquierda, el flag de signo, etc.

Estas funciones devuelven 0 si el registro es exitoso, y -1 si ocurre un error (por ejemplo, si el especificador ya está registrado).

STANDARDS

GNU.

HISTORY

register_printf_function(3) es una función más antigua similar a register_printf_specifier(), y ahora está obsoleta. Esa función no puede manejar tipos definidos por el usuario.

register_printf_specifier() reemplaza a register_printf_function(3).

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Relleno con ' ' (alineado a la derecha) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Prefijo "0b"/"0B" */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Relleno con '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Imprimir número (incluyendo ceros a la izquierda para completar la precisión) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Relleno con ' ' (alineado a la izquierda) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short y char se promocionan a int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Imprimir ceros a la izquierda para completar la precisión */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Imprimir número */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}

PA_DOUBLE

PA_DOUBLE - double precision floating point type

SECTION 3

PA_DOUBLE is a type alias for the double precision floating point type. It is defined in the `portaudio.h` header file.

LIBRARY

PortAudio

SYNOPSIS

typedef double PA_DOUBLE;

DESCRIPTION

PA_DOUBLE is a type alias for the `double` data type, which typically represents a double precision floating point number. This type is commonly used in PortAudio for representing audio sample data, especially when high precision is required.

RETURN VALUE

This type does not return a value. It is used for variable declarations and function parameter/return types.

ERRORS

There are no specific errors associated with the definition of PA_DOUBLE. Errors may arise from operations performed on variables of this type, such as floating-point exceptions, but these are not directly related to the type definition itself.

STANDARDS

The `double` type is part of the ANSI C and ISO C standards. PA_DOUBLE inherits its properties from the standard `double` type.

HISTORY

The `double` type has been a standard part of the C language since its early versions. PA_DOUBLE was introduced in PortAudio to provide a consistent and portable way to refer to double precision floating point numbers within the library.

EXAMPLES

#include <portaudio.h>

        int main() {
            PA_DOUBLE sample_value;
            sample_value = 0.5;

            // Use sample_value in audio processing...

            return 0;
        }
