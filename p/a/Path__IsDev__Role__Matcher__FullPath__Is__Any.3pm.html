Path::IsDev::Role::Matcher::FullPath::Is::Any(3) Documentación de Perl contribuida por el usuario Path::IsDev::Role::Matcher::FullPath::Is::Any(3)

NOMBRE

Path::IsDev::Role::Matcher::FullPath::Is::Any - Coincide si el directorio actual es el mismo que un directorio de una lista de rutas absolutas.

VERSIÓN

version 1.001003

MÉTODOS

"fullpath_is_any"

Nota, esto normalmente se invoca en directorios de todos modos.

if ( $self->fullpath_is_any( $result_object, '/usr/', '/usr/bin/foo' )) {
}

Coincide si alguna de las rutas proporcionadas "realpath" corresponde a "$result_object->path->realpath"

MÉTODOS PRIVADOS

"_fullpath_is"

$class->_fullpath_is( $result_object, $source_path, $comparison_path );

No coincide si $comparison_path no existe.

De lo contrario, compara $source_path con "$comparison_path->realpath" y devuelve si coinciden.
