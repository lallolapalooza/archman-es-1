Package::Stash::XS(3) Documentación de Perl aportada por el usuario Package::Stash::XS(3)

NOMBRE

Package::Stash::XS - Implementación más rápida y correcta de la API de Package::Stash

VERSIÓN

versión 0.30

SINOPSIS

use Package::Stash;

DESCRIPCIÓN

Este es un backend para Package::Stash, que proporciona la funcionalidad de una manera menos propensa a errores y mucho más rápida. Se utilizará por defecto si está instalado, y debería preferirse en todos los entornos con un compilador.

ERRORES CONOCIDOS

No se conocen errores (pero véase la sección BUGS en Package::Stash).

VER TAMBIÉN

Package::Stash
