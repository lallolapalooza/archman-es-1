PAGEMAP_SCAN(2const) PAGEMAP_SCAN(2const)

NOMBRE

PAGEMAP_SCAN - obtener y/o limpiar indicadores de página

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/fs.h>  /* Definición de constantes PAGE* y PM_* */
#include <sys/ioctl.h>
int ioctl(int pagemap_fd, PAGEMAP_SCAN, struct pm_scan_arg *arg);
#include <linux/fs.h>
struct pm_scan_arg {
    __u64  size;
    __u64  flags;
    __u64  start;
    __u64  end;
    __u64  walk_end;
    __u64  vec;
    __u64  vec_len;
    __u64  max_pages;
    __u64  category_inverted;
    __u64  category_mask;
    __u64  category_anyof_mask;
    __u64  return_mask;
};
struct page_region {
    __u64  start;
    __u64  end;
    __u64  categories;
};

DESCRIPCIÓN

Este ioctl(2) se utiliza para obtener y opcionalmente limpiar algunos indicadores específicos de las entradas de la tabla de páginas. La información se devuelve con granularidad PAGE_SIZE.

Para empezar a rastrear el estado de escritura (indicador) de una página o rango de memoria, el UFFD_FEATURE_WP_ASYNC debe estar habilitado por el ioctl(2) UFFDIO_API en userfaultfd y el rango de memoria debe registrarse con el ioctl(2) UFFDIO_REGISTER en modo UFFDIO_REGISTER_MODE_WP.

Indicadores de página soportados

Los siguientes indicadores de entrada de la tabla de páginas son soportados:

PAGE_IS_WPALLOWED
La página tiene protección de escritura asíncrona habilitada.
PAGE_IS_WRITTEN
La página ha sido escrita desde que se protegió contra escritura.
PAGE_IS_FILE
La página tiene respaldo de archivo.
PAGE_IS_PRESENT
La página está presente en la memoria.
PAGE_IS_SWAPPED
La página está paginada.
PAGE_IS_PFNZERO
La página tiene PFN cero.
PAGE_IS_HUGE
La página tiene respaldo THP o Hugetlb.

Operaciones soportadas

La operación de obtener siempre se realiza si se especifica el buffer de salida. Las otras operaciones son las siguientes:

PM_SCAN_WP_MATCHING
Protege contra escritura las páginas coincidentes.
PM_SCAN_CHECK_WPASYNC
Aborta el escaneo cuando se encuentra una página que no tiene habilitada la protección de escritura asíncrona de Userfaultfd.

El argumento struct pm_scan_arg

size
Este campo debe establecerse al tamaño de la estructura en bytes, como en sizeof(struct pm_scan_arg).
flags
Las operaciones a realizar se especifican en él.
start
La dirección de inicio del escaneo se especifica en él.
end
La dirección de fin del escaneo se especifica en él.
walk_end
El kernel devuelve la dirección de fin del escaneo en él. El walk_end igual a end significa que el escaneo se ha completado en todo el rango.
vec
La dirección del array page_region para la salida.
vec_len
La longitud del array de estructuras page_region.
max_pages
Es el límite opcional para el número de páginas de salida requeridas.
category_inverted
Las categorías PAGE_IS_* cuyos valores coinciden si 0 en lugar de 1.
category_mask
Omite las páginas para las cuales alguna categoría PAGE_IS_* no coincide.
category_anyof_mask
Omite las páginas para las cuales ninguna categoría PAGE_IS_* coincide.
return_mask
Las categorías PAGE_IS_* que se informarán en page_region.

VALOR DE RETORNO

En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

Los códigos de error pueden ser uno de los siguientes, pero no se limitan a ellos:

EINVAL
Argumentos inválidos, es decir, size del argumento inválido, flags inválidos, categories inválidos, la dirección start no está alineada con PAGE_SIZE, o se especifica vec_len cuando vec es NULL.
EFAULT
Puntero arg inválido, puntero vec inválido, o rango de direcciones inválido especificado por start y end.
ENOMEM
No hay memoria disponible.
EINTR
Se está esperando una señal fetal.
