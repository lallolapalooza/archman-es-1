Package::Stash::PP(3) Documentación de Perl Contribuida por el Usuario Package::Stash::PP(3)

NOMBRE

Package::Stash::PP - Implementación en perl puro de la API de Package::Stash

VERSIÓN

versión 0.40

SINOPSIS

use Package::Stash;

DESCRIPCIÓN

Este es un backend para Package::Stash implementado en perl puro, para aquellos que no tienen un compilador o que desearían usarlo en línea en scripts.

ERRORES

  • remove_symbol también reemplaza el globbo asociado

    Esto puede causar un comportamiento inesperado al manipular en tiempo de compilación: la eliminación de subrutinas aún permitirá que sean llamadas desde dentro del paquete como subrutinas (aunque no estarán disponibles como métodos). Esto puede considerarse una característica en algunos casos (así es como funciona namespace::clean, por ejemplo), pero no debe confiarse en ello: use "remove_glob" directamente si desea este comportamiento.

  • Algunas fugas de memoria menores

    La implementación en perl puro tiene un par de fugas de memoria menores (ver las pruebas TODO en t/20-leaks.t) que me están resultando difíciles de rastrear; estos pueden ser errores del núcleo de perl, es difícil saberlo.
