DESCRIPCIÓN

Estas funciones sirven para extender y/o modificar el comportamiento de la familia de funciones printf(3).

register_printf_specifier()

Esta función registra un especificador de conversión personalizado para la familia de funciones printf(3).

spec
El carácter que se utilizará como especificador de conversión en la cadena de formato.
func
Función de callback que será ejecutada por la familia de funciones printf(3) para formatear los argumentos de entrada en el stream de salida.
stream
Stream de salida donde se debe imprimir la salida formateada. Este stream representa transparentemente la salida, incluso en el caso de funciones que escriben en una cadena.
info
Estructura que contiene información contextual, incluyendo los modificadores especificados en la cadena de formato. Contiene el mismo contenido que en arginfo.
args
Array de punteros a los argumentos de la función tipo printf(3).
arginfo
Función de callback que será ejecutada por la familia de funciones printf(3) para saber cuántos argumentos deben ser analizados para el especificador personalizado y también sus tipos.
info
Estructura que contiene información contextual, incluyendo los modificadores especificados en la cadena de formato. Contiene el mismo contenido que en func.
n
Número de argumentos restantes por analizar.
argtypes
Este array debe configurarse para definir el tipo de cada uno de los argumentos que se analizarán. Cada elemento del array representa uno de los argumentos a analizar, en el mismo orden en que se pasan a la función tipo printf(3). Cada elemento debe configurarse con un tipo base (PA_*) de la enumeración anterior, o uno personalizado, y opcionalmente con un OR bit a bit con un modificador de longitud apropiado (PA_FLAG_*).

float.

double.

size
Para tipos definidos por el usuario, también se debe especificar el tamaño del tipo (en bytes) a través de este array. De lo contrario, déjelo sin usar.

arginfo se llama antes que func, y prepara cierta información necesaria para llamar a func.

VALOR DE RETORNO

register_printf_specifier(), register_printf_modifier(), y register_printf_type() devuelven cero en caso de éxito, o -1 en caso de error.

Callbacks

El callback de tipo printf_function debe devolver el número de caracteres escritos, o -1 en caso de error.

El callback de tipo printf_arginfo_size_function debe devolver el número de argumentos a analizar por este especificador. También pasa información sobre el tipo de esos argumentos al llamador a través de argtypes. En caso de error, debe devolver -1.

NAME

register_printf_specifier — registrar un especificador de formato de printf definido por el usuario

LIBRARY

Opciones de enlace de la biblioteca C (libc, -lc)

SYNOPSIS

#include <printf.h>

int register_printf_specifier(int c, printf_render_callback render, printf_arginfo_callback arginfo);

int register_printf_specifier_std(int c, printf_render_callback render, printf_arginfo_callback arginfo, void *closure);

DESCRIPTION

La función register_printf_specifier permite registrar un nuevo especificador de formato para las funciones de la familia printf. El carácter c especifica el carácter del especificador de formato que se registrará (por ejemplo, 'd', 's', 'i', etc.). El parámetro render es un puntero a una función de devolución de llamada que se llamará cuando se encuentre el especificador de formato registrado. Esta función es responsable de dar formato y escribir la salida en el flujo especificado. El parámetro arginfo es un puntero a una función de devolución de llamada que se llama para determinar el tipo y el tamaño del argumento esperado para el especificador de formato.

La función register_printf_specifier_std es similar a register_printf_specifier pero también acepta un parámetro closure adicional. Este parámetro se puede utilizar para pasar datos arbitrarios a las funciones de devolución de llamada render y arginfo.

Las funciones de devolución de llamada render y arginfo se definen de la siguiente manera:

typedef int (*printf_render_callback)(FILE *stream, const struct printf_info *info, const void *const args[]);
La función render recibe un puntero al flujo de salida (stream), una estructura printf_info que contiene información sobre el especificador de formato y sus modificadores, y una matriz de punteros a los argumentos (args). Debe devolver el número de caracteres escritos o EOF en caso de error.
typedef int (*printf_arginfo_callback)(const struct printf_info *info, size_t n, int argtypes[n], int size[n]);
La función arginfo recibe un puntero a la estructura printf_info, el número de argumentos que se esperan (n), y matrices para almacenar los tipos de argumento (argtypes) y sus tamaños (size). Debe devolver el número de argumentos que consume.

La estructura printf_info contiene los siguientes campos:

int alt
Bandera alternativa (por ejemplo, `#` para formato octal o hexadecimal).
int left
Bandera de alineación a la izquierda (por ejemplo, `-`).
int group
Bandera de agrupación (por ejemplo, `'` para usar separadores de miles).
int prec
Precisión del especificador de formato.
int width
Ancho del campo.
int is_long_double
Verdadero si el modificador de longitud es L (long double).
int is_long
Verdadero si el modificador de longitud es l (long).
int is_short
Verdadero si el modificador de longitud es h (short).
int is_char
Verdadero si el modificador de longitud es hh (char).
int is_size_t
Verdadero si el modificador de longitud es z (size_t).
int is_ptrdiff_t
Verdadero si el modificador de longitud es t (ptrdiff_t).
int is_intmax_t
Verdadero si el modificador de longitud es j (intmax_t).
char pad
Carácter de relleno (por ejemplo, `0` o espacio).
char spec
El carácter del especificador de formato.

STANDARDS

GNU.

HISTORY

register_printf_function(3) es una función más antigua similar a register_printf_specifier(), y ahora está obsoleta. Esa función no puede manejar tipos definidos por el usuario.

register_printf_specifier() reemplaza a register_printf_function(3).

static int
b_printf(FILE *stream, const struct printf_info *info,
         const void *const args[])
{
    char               bin[UINTMAX_WIDTH];
    size_t             min_len, bin_len;
    ssize_t            len, tmp;
    struct Printf_Pad  pad = {0};
    len = 0;
    min_len = b_bin_repr(bin, info, args[0]);
    bin_len = b_bin_len(info, min_len);
    pad.ch = pad_ch(info);
    if (pad.ch == ' ')
        pad.len = b_pad_len(info, bin_len);
    /* Padding with ' ' (right aligned) */
    if ((pad.ch == ' ') && !info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* "0b"/"0B" prefix */
    if (info->alt) {
        tmp = b_print_prefix(stream, info);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Padding with '0' */
    if (pad.ch == '0') {
        tmp = b_pad_zeros(stream, info, min_len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    /* Print number (including leading 0s to fill precision) */
    tmp = b_print_number(stream, info, bin, min_len, bin_len);
    if (tmp == EOF)
        return EOF;
    len += tmp;
    /* Padding with ' ' (left aligned) */
    if (info->left) {
        tmp = pad_spaces(stream, pad.len);
        if (tmp == EOF)
            return EOF;
        len += tmp;
    }
    return len;
}
static int
b_arginf_sz(const struct printf_info *info, size_t n, int argtypes[n],
            [[maybe_unused]] int size[n])
{
    if (n < 1)
        return -1;
    if (info->is_long_double)
        argtypes[0] = PA_INT | PA_FLAG_LONG_LONG;
    else if (info->is_long)
        argtypes[0] = PA_INT | PA_FLAG_LONG;
    else
        argtypes[0] = PA_INT;
    return 1;
}
static uintmax_t
b_value(const struct printf_info *info, const void *arg)
{
    if (info->is_long_double)
        return *(const unsigned long long *)arg;
    if (info->is_long)
        return *(const unsigned long *)arg;
    /* short and char are both promoted to int */
    return *(const unsigned int *)arg;
}
static size_t
b_bin_repr(char bin[UINTMAX_WIDTH],
           const struct printf_info *info, const void *arg)
{
    size_t     min_len;
    uintmax_t  val;
    val = b_value(info, arg);
    bin[0] = '0';
    for (min_len = 0; val; min_len++) {
        bin[min_len] = '0' + (val % 2);
        val >>= 1;
    }
    return MAX(min_len, 1);
}
static size_t
b_bin_len(const struct printf_info *info, ptrdiff_t min_len)
{
    return MAX(info->prec, min_len);
}
static size_t
b_pad_len(const struct printf_info *info, ptrdiff_t bin_len)
{
    ptrdiff_t  pad_len;
    pad_len = info->width - bin_len;
    if (info->alt)
        pad_len -= 2;
    if (info->group)
        pad_len -= (bin_len - 1) / 4;
    return MAX(pad_len, 0);
}
static ssize_t
b_print_prefix(FILE *stream, const struct printf_info *info)
{
    ssize_t len;
    len = 0;
    if (fputc('0', stream) == EOF)
        return EOF;
    len++;
    if (fputc(info->spec, stream) == EOF)
        return EOF;
    len++;
    return len;
}
static ssize_t
b_pad_zeros(FILE *stream, const struct printf_info *info,
            ptrdiff_t min_len)
{
    ssize_t    len;
    ptrdiff_t  tmp;
    len = 0;
    tmp = info->width - (info->alt * 2);
    if (info->group)
        tmp -= tmp / 5 - !(tmp % 5);
    for (ptrdiff_t i = tmp - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static ssize_t
b_print_number(FILE *stream, const struct printf_info *info,
               const char bin[UINTMAX_WIDTH],
               size_t min_len, size_t bin_len)
{
    ssize_t  len;
    len = 0;
    /* Print leading zeros to fill precision */
    for (size_t i = bin_len - 1; i > min_len - 1; i--) {
        if (fputc('0', stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4))
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    /* Print number */
    for (size_t i = min_len - 1; i < min_len; i--) {
        if (fputc(bin[i], stream) == EOF)
            return EOF;
        len++;
        if (!info->group || (i % 4) || !i)
            continue;
        if (fputc(GROUP_SEP, stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
static char
pad_ch(const struct printf_info *info)
{
    if ((info->prec != -1) || (info->pad == ' ') || info->left)
        return ' ';
    return '0';
}
static ssize_t
pad_spaces(FILE *stream, size_t pad_len)
{
    ssize_t  len;
    len = 0;
    for (size_t i = pad_len - 1; i < pad_len; i--) {
        if (fputc(' ', stream) == EOF)
            return EOF;
        len++;
    }
    return len;
}
