Path::FindDev(3) Documentación de Perl aportada por el usuario Path::FindDev(3)

NOMBRE

Path::FindDev - Encuentra una ruta de desarrollo en algún lugar de una jerarquía superior.

VERSIÓN

versión v0.5.3

DESCRIPCIÓN

Este paquete es principalmente una capa de conexión alrededor de "Path::IsDev" con algunos trucos de recorrido de directorios.

use Path::FindDev qw( find_dev );
if ( my $root = find_dev('/some/path/to/something/somewhere')) {
    print "raíz de desarrollo = $root";
} else {
    print "No hay raíz de desarrollo :(";
}

FUNCIONES

find_dev

my $result = find_dev('/some/path');

Si se encuentra un directorio "dev" en o por encima de "/some/path", se devolverá como un objeto "Path::Tiny".

Si pasas configuraciones para importar:

use Path::FindDev find_dev => { set => $someset };

Entonces el "find_dev" exportado pasará ese nombre de conjunto a "Path::IsDev".

Aunque solo deberías hacer esto si

  • el conjunto predeterminado es inadecuado para tu uso
  • no deseas que el conjunto sea anulado por %ENV

Adicionalmente, puedes llamar a find_dev directamente:

require Path::FindDev;
my $result = Path::FindDev::find_dev('/some/path');

Lo que, por diseño, inhibe tu capacidad de especificar un conjunto alternativo en código.

CASOS DE USO DE EJEMPLO

¿Alguna vez te has encontrado haciendo

use FindBin;
use lib "$FindBin::Bin/../../../tlib"

¿En una prueba?

¿Te has encontrado paranoico de las semánticas del sistema de archivos y has intentado

use FindBin;
use Path::Tiny qw(path)
use lib path($FindBin::Bin)->parent->parent->parent->child('tlib')->stringify;

¿Alguna vez has hecho alguna de las anteriores en una prueba, solo para descubrir que necesitabas mover la prueba a una jerarquía más profunda y, por lo tanto, necesitas reescribir toda tu resolución de rutas?

¿Alguna vez has tenido este problema para varios archivos?

¡Ya no más!

use FindBin;
use Path::FindDev qw(find_dev);
use lib find_dev($FindBin::Bin)->child('t','tlib')->stringify;

^ Debería funcionar, independientemente de en qué prueba lo coloques y de cuál sea $CWD cuando lo llames.
