NOMBRE

PAR::StrippedPARL::Base - Clase base para los paquetes de datos PARL de PAR

SINOPSIS

# Por favor, utiliza uno de los hermanos de esta clase en su lugar.
use base 'PAR::StrippedPARL::Base';

DESCRIPCIÓN

Esta clase es interna de PAR. No la utilices fuera de PAR.

Esta clase es básicamente un contenedor para un cargador binario estático de PAR que no incluye el código PAR como elparl oparl.exe al que estás acostumbrado. Si tienes mucha curiosidad, te diré que es solo una copia del archivomyldr/static (omyldr/static.exe).

Los datos se añaden durante la fase de"make" del proceso de compilación de PAR.

Si los datos binarios no se añaden durante el proceso de compilación, los dos métodos de clase devolverán la lista vacía.

MÉTODOS DE CLASE

write_parl

Toma un nombre de archivo como argumento. Escribe los datos binarios sin procesar del paquete en el archivo especificado e incrusta los módulos principales para producir un cargador PAR completo (parl).

Devuelve verdadero en caso de éxito o la lista vacía en caso de fallo.

get_raw

Devuelve los datos binarios adjuntos al paquete de datos.

Devuelve la lista vacía en caso de fallo.

write_raw

Toma un nombre de archivo como argumento y escribe los datos binarios en el archivo.

Devuelve verdadero en caso de éxito y la lista vacía en caso de fallo.

SUBCLASES

Las subclases deben implementar el método de clase"_data_pos" que devuelve el valor de"tell DATA" tal como estaba después de que la clase fuera cargada.
