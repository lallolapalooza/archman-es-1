NOMBRE

Params::Util - Funciones simples, compactas y correctas para la verificación de parámetros

SINOPSIS

# Importar algunas funciones
use Params::Util qw{_SCALAR _HASH _INSTANCE};

# Si eres perezoso, o necesitas muchas...
use Params::Util ':ALL';

sub foo {
    my $object  = _INSTANCE(shift, 'Foo') or return undef;
    my $image   = _SCALAR(shift)          or return undef;
    my $options = _HASH(shift)            or return undef;
    # etc...
}

DESCRIPCIÓN

"Params::Util" proporciona un conjunto básico de funciones importables que facilitan enormemente la verificación de parámetros.

Aunque pueden ser (y son) utilizadas en otros contextos, el objetivo principal de este módulo es que las funciones ambas hagan lo que quieres decir y hagan lo correcto, por lo que son más útiles cuando recibes parámetros en tu código de alguien y/o de otro lugar y no puedes confiar realmente en la calidad.

Por lo tanto, "Params::Util" es de mayor utilidad en los límites de tu API, donde los parámetros y los datos entran desde fuera de tu código.

Las funciones proporcionadas por "Params::Util" verifican de la manera más estrictamente correcta conocida, están documentadas de la forma más completa posible para que su comportamiento exacto sea claro, y están ampliamente probadas para asegurar que no son engañadas por datos extraños y cosas realmente malas.

Para usar, simplemente carga el módulo proporcionando las funciones que deseas usar como argumentos (como se muestra en la SINOPSIS).

Para ayudar al mantenimiento, "Params::Util" nunca exportará por defecto.

Debes nombrar explícitamente las funciones que deseas exportar, o usar el parámetro ":ALL" para que exporte todo (aunque esto no se recomienda si tienes funciones _FOO propias con las que futuras adiciones a "Params::Util" puedan colisionar)

FUNCIONES

_STRING $string

La función "_STRING" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es una cadena normal, verdadera, de longitud no cero.

Ten en cuenta que esto NO hará nada mágico para tratar el caso especial de falso '0', sino que lo devolverá.

# '0' no se considera dato válido
my $name = _STRING(shift) or die "Nombre incorrecto";

# '0' se considera dato válido
my $string = _STRING($_[0]) ? shift : die "Cadena incorrecta";

Por favor, ten en cuenta también que esta función espera una cadena normal. No soporta sobrecargas u otras técnicas mágicas para obtener una cadena.

Devuelve la cadena como una conveniencia si es una cadena válida, o "undef" si no lo es.

_IDENTIFIER $string

La función "_IDENTIFIER" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es una cadena que es un identificador válido de Perl.

Devuelve la cadena como una conveniencia si es un identificador válido, o "undef" si no lo es.

_CLASS $string

La función "_CLASS" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es una cadena que es una clase válida de Perl.

Esta función solo verifica que el formato sea válido, no que la clase esté realmente cargada. También asume la forma "normalizada" y no acepta nombres de clase como "::Foo" o "D'Oh".

Devuelve la cadena como una conveniencia si es un nombre de clase válido, o "undef" si no lo es.

_CLASSISA $string, $class

La función "_CLASSISA" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es una cadena que es una clase particular, o una subclase de ella.

Esta función verifica que el formato sea válido y llama al método ->isa en el nombre de la clase. No verifica que la clase esté realmente cargada.

También asume la forma "normalizada" y no acepta nombres de clase como "::Foo" o "D'Oh".

Devuelve la cadena como una conveniencia si es un nombre de clase válido, o "undef" si no lo es.

_CLASSDOES $string, $role

Esta rutina se comporta exactamente como "_CLASSISA", pero verifica con ->DOES en lugar de ->isa. Esto probablemente solo sea una buena idea usarlo en Perl 5.10 o posterior, cuando UNIVERSAL::DOES se haya implementado.

_SUBCLASS $string, $class

La función "_SUBCLASS" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es una cadena que es una subclase de una clase especificada.

Esta función verifica que el formato sea válido y llama al método ->isa en el nombre de la clase. No verifica que la clase esté realmente cargada.

También asume la forma "normalizada" y no acepta nombres de clase como "::Foo" o "D'Oh".

Devuelve la cadena como una conveniencia si es un nombre de clase válido, o "undef" si no lo es.

_NUMBER $scalar

La función "_NUMBER" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es un número. Es decir, está definido y Perl lo considera un número.

Esta función es básicamente un envoltorio al estilo Params::Util para la función "looks_like_number" de Scalar::Util.

Devuelve el valor como una conveniencia, o "undef" si el valor no es un número.

_POSINT $integer

La función "_POSINT" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es un entero positivo (de cualquier longitud).

Devuelve el valor como una conveniencia, o "undef" si el valor no es un entero positivo.

El nombre en sí se deriva de la restricción de esquema XML del mismo nombre.

_NONNEGINT $integer

La función "_NONNEGINT" está destinada a ser importada en tu paquete y proporciona una forma conveniente de verificar si un valor es un entero no negativo (de cualquier longitud). Es decir, un entero positivo o cero.

Devuelve el valor como una conveniencia, o "undef" si el valor no es un entero no negativo.

Al igual que con otras pruebas que pueden devolver valores falsos, se debe tener cuidado de probar mediante "defined" en contextos booleanos válidos.

unless ( defined _NONNEGINT($value) ) {
   die "Valor inválido";
}

El nombre en sí se deriva de la restricción de esquema XML del mismo nombre.

_ARRAY $value

La función "_ARRAY" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar una referencia "ARRAY" cruda y sin bendecir que contiene **al menos** un elemento de cualquier tipo.

Para una forma más básica que permite referencias ARRAY de longitud cero, consulte la función "_ARRAY0".

_ARRAY0 $value

Para una forma más básica de "Un array de algo" que también requiere al menos un elemento, consulte la función "_ARRAY".

Devuelve la referencia "ARRAY" en sí misma como una conveniencia, o "undef" si el valor proporcionado no es una referencia "ARRAY".

_ARRAYLIKE $value

La función "_ARRAYLIKE" prueba si un valor escalar dado puede responder a la desreferenciación de arrays. Si puede, se devuelve el valor. Si no, "_ARRAYLIKE" devuelve "undef".

_HASH $value

La función "_HASH" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar una referencia "HASH" cruda y sin bendecir con al menos una entrada.

Para una versión de esta función que permite que el "HASH" esté vacío, consulte la función "_HASH0".

Devuelve la referencia "HASH" en sí misma como una conveniencia, o "undef" si el valor proporcionado no es una referencia "HASH".

_HASH0 $value

La función "_HASH0" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar una referencia "HASH" cruda y sin bendecir, independientemente del contenido del "HASH".

Para una versión más simple de "Un hash de algo" que requiere al menos un elemento, consulte la función "_HASH".

Devuelve la referencia "HASH" en sí misma como una conveniencia, o "undef" si el valor proporcionado no es una referencia "HASH".

_HASHLIKE $value

La función "_HASHLIKE" prueba si un valor escalar dado puede responder a la desreferenciación de hash. Si puede, se devuelve el valor. Si no, "_HASHLIKE" devuelve "undef".

_CODE $value

La función "_CODE" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar una referencia "CODE" cruda y sin bendecir.

Devuelve la referencia "CODE" en sí misma como una conveniencia, o "undef" si el valor proporcionado no es una referencia "CODE".

_CODELIKE $value

El "_CODELIKE" es la versión más genérica de "_CODE". A diferencia de "_CODE", que verifica una referencia explícita "CODE", la función "_CODELIKE" también incluye elementos que se comportan como ellos, como objetos bendecidos que sobrecargan '&{}'.

Tenga en cuenta que en el caso de objetos sobrecargados con '&{}', casi siempre terminará probándolos también en contexto 'bool' en alguna etapa.

Por ejemplo:

sub foo {
    my $code1 = _CODELIKE(shift) or die "No se proporcionó parámetro de código";
    my $code2 = _CODELIKE(shift);
    if ( $code2 ) {
         print "Se recibió un parámetro de código secundario opcional";
    }
}

Como tal, lo más probable es que siempre quiera asegurarse de que su clase tenga al menos lo siguiente para permitir que se evalúe como verdadero en contexto booleano.

# Siempre evalúa como verdadero en contexto booleano
use overload 'bool' => sub () { 1 };

Devuelve el valor invocable como una conveniencia, o "undef" si el valor proporcionado no es invocable.

Nota: Esta función se conocía anteriormente como _CALLABLE pero ha sido renombrada para una mayor simetría con las otras funciones _XXXXLIKE.

El uso de _CALLABLE ha sido obsoleto. Continuará funcionando, pero con una advertencia, hasta finales de 2006, luego será eliminado.

Disculpas por cualquier inconveniente causado.

_INVOCANT $value

Esta rutina prueba si el valor dado es un invocante de método válido. Este puede ser una instancia de un objeto o un nombre de clase.

Si es así, se devuelve el valor en sí. De lo contrario, "_INVOCANT" devuelve "undef".

_INSTANCE $object, $class

La función "_INSTANCE" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar un objeto de una clase particular de manera estrictamente correcta.

Devuelve el objeto en sí como una conveniencia, o "undef" si el valor proporcionado no es un objeto de ese tipo.

_INSTANCEDOES $object, $role

Esta rutina se comporta exactamente como "_INSTANCE", pero comprueba con "->DOES" en lugar de "->isa". Probablemente solo sea una buena idea usar esto en Perl 5.10 o posterior, cuando UNIVERSAL::DOES se haya implementado.

_REGEX $value

La función "_REGEX" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar una expresión regular.

Devuelve el valor en sí como una conveniencia, o "undef" si el valor proporcionado no es una expresión regular.

_SET \@array, $class

La función "_SET" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar un conjunto de al menos un objeto de una clase particular de manera estrictamente correcta.

El conjunto se proporciona como una referencia a un "ARRAY" de objetos de la clase proporcionada.

Para una función alternativa que permite conjuntos de longitud cero, consulte la función "_SET0".

Devuelve la referencia "ARRAY" en sí misma como una conveniencia, o "undef" si el valor proporcionado no es un conjunto de esa clase.

_SET0 \@array, $class

La función "_SET0" está destinada a ser importada en su paquete y proporciona una forma conveniente de probar un conjunto de objetos de una clase particular de manera estrictamente correcta, permitiendo cero objetos.

El conjunto se proporciona como una referencia a un "ARRAY" de objetos de la clase proporcionada.

Para una función alternativa que requiere al menos un objeto, consulte la función "_SET".

Devuelve la referencia "ARRAY" en sí misma como una conveniencia, o "undef" si el valor proporcionado no es un conjunto de esa clase.

El NOMBRE La función `&_DRIVER`string es pretendida para ser importada en tu paquete, y proporciona un modo conveniente de verificar si un valor escalar único es un manejo de archivo. Aunque así, esta función es implementada o mejor que las otras detecciones de manejo de archivos existentes (y hemos tomado de las mejores). La función `&_DRIVER`string es pretendida para ser importada en tu paquete, y proporciona un modo conveniente de cargar y validar una clase de driver. El patrón más común cuando se le pasa una clase de driver es verificar que el nombre sea una clase (es decir, verificar contra `&_CLASS`), luego cargar la clase (si existe) y luego asegurar que la clase devuelva true para el método `isa` en algún nombre de driver base. Devuelve el valor como una conveniencia, o `&_undef` si el valor no es un nombre de clase, el módulo no existe, el módulo no carga, o la clase falla el test `isa`. SYNOPSIS ```perl use Params::Util '_DRIVER'; # Devuelve SCALAR si el valor es un manejo de archivo, undef en caso contrario. my $is_handle = _DRIVER( $value ); # Carga y valida una clase de driver. my $driver_object = _DRIVER( $value, 'My::Base::Driver' ); # Devuelve el objeto driver o undef si falla la validación. ``` DESCRIPCIÓN Esta función proporciona una manera conveniente y segura de determinar si un valor escalar es un manejo de archivo o de validar y cargar una clase de driver. FUNCIONES * `_DRIVER($value)`: Verifica si `$value` es un manejo de archivo. Devuelve el tipo de manejo de archivo (por ejemplo, `SCALAR`) si lo es, o `undef` en caso contrario. * `_DRIVER($value, $base_class)`: Intenta cargar y validar `$value` como una clase que se hereda de `$base_class`. Devuelve el nombre de la clase si es válido, o `undef` si falla la validación (no es una clase, el módulo no existe, no se carga, o no se hereda de `$base_class`).
