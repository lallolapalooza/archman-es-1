NOMBRE

Path::IsDev::Role::Matcher::Child::BaseName::MatchRegexp::File - Coincide si algún hijo tiene un nombre base que coincide con una expresión regular y son archivos

VERSIÓN

versión 1.001003

MÉTODOS

"child_basename_matchregexp_file"

$class->child_basename_matchregexp_file( $result_object, $regexp );

Dada una expresión regular $regexp, coincide si alguno de los "$result_object->path->children" coincide con la expresión regular dada, bajo la condición de que los que coinciden sean también archivos.

if ( $self->child_basename_matchregexp_file( $result_object, qr/^Change(.*)$/i ) ) {
    # result_object->path() contiene al menos un hijo que es un archivo y coincide con la expresión regular
}
