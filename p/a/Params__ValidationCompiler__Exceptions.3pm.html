Params::ValidationCompiler::Exceptions(3) Documentación de Perl contribuida por el usuario Params::ValidationCompiler::Exceptions(3)

NOMBRE

Params::ValidationCompiler::Exceptions - Define las excepciones que lanza Params::ValidationCompiler

VERSIÓN

versión 0.31

DESCRIPCIÓN

Este módulo define las siguientes excepciones:

Params::ValidationCompiler::Exception::BadArguments

Excepción lanzada cuando @_ no contiene un hash o hashref.

Params::ValidationCompiler::Exception::Named::Extra

Excepción lanzada cuando @_ contiene argumentos nombrados extra inesperados.

Params::ValidationCompiler::Exception::Named::Required

Excepción lanzada cuando no se pasa un parámetro nombrado requerido.

Params::ValidationCompiler::Exception::Positional::Extra

Excepción lanzada cuando @_ contiene argumentos extra inesperados.

Params::ValidationCompiler::Exception::Positional::Required

Excepción lanzada cuando no se pasa un parámetro posicional requerido.

Params::ValidationCompiler::Exception::ValidationFailedForMooseTypeConstraint

Excepción lanzada cuando falla la comprobación de restricción de tipo de Moose. Esta clase proporciona los siguientes métodos:

$e->parameter

Esto devuelve una cadena que describe el parámetro, algo como "El parámetro 'foo'" o "Parámetro #1".

$e->value

Este es el valor que falló la comprobación de restricción de tipo.

$e->type

Este es el objeto de restricción de tipo que no aceptó el valor.

SOPORTE

Los errores pueden enviarse en https://github.com/houseabsolute/Params-ValidationCompiler/issues.

FUENTE

El repositorio de código fuente de Params-ValidationCompiler se puede encontrar en https://github.com/houseabsolute/Params-ValidationCompiler.
