NOMBRE

Path::IsDev::NegativeHeuristic::IsDev::IgnoreFile - Una heurística explícita de exclusión de archivo

VERSIÓN

versión 1.001003

SINOPSIS

En un "::HeuristicSet":

sub negative_heuristics { return 'IsDev::IgnoreFile' }

Luego en tu sistema de archivos:

touch .path_isdev_ignore

Entonces la ubicación dada ya no será un candidato posible para ser considerada un directorio raíz "dev".

Sin embargo:

  • Sus padres aún pueden ser considerados directorios "dev"
  • Sus hijos aún pueden ser considerados directorios "dev"

MÉTODOS

"excluye_archivos"

Archivos válidos para activar esta heurística:

.path_isdev_ignore

"excluye"

Devuelve una exclusión si alguno de los archivos en "excluye_archivos" existe y son archivos.
