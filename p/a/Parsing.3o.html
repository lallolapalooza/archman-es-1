Módulo Parsing

DOCUMENTACIÓN

Módulo Parsing
: sig end

Biblioteca de tiempo de ejecución para analizadores generados por ocamlyacc.

val symbol_start : unit -> int

symbol_start y Parsing.symbol_end deben ser llamadas solo en la parte de acción de una regla de gramática. Devuelven el desplazamiento de la cadena que coincide con el lado izquierdo de la regla: symbol_start() devuelve el desplazamiento del primer carácter; symbol_end() devuelve el desplazamiento después del último carácter. El primer carácter en un archivo está en el desplazamiento 0.

val symbol_end : unit -> int

Ver Parsing.symbol_start.

val rhs_start : int -> int

Igual que Parsing.symbol_start y Parsing.symbol_end, pero devuelven el desplazamiento de la cadena que coincide con el n-ésimo elemento en el lado derecho de la regla, donde n es el parámetro entero para rhs_start y rhs_end. n es 1 para el elemento más a la izquierda.

val rhs_end : int -> int

Ver Parsing.rhs_start.

val symbol_start_pos : unit -> Lexing.position

Igual que symbol_start, pero devuelve una posición en lugar de un desplazamiento.

val symbol_end_pos : unit -> Lexing.position

Igual que symbol_end, pero devuelve una posición en lugar de un desplazamiento.

val rhs_start_pos : int -> Lexing.position

Igual que rhs_start, pero devuelve una posición en lugar de un desplazamiento.

val rhs_end_pos : int -> Lexing.position

Igual que rhs_end, pero devuelve una posición en lugar de un desplazamiento.

val clear_parser : unit -> unit

Vacía la pila del analizador. Llámala justo después de que una función de análisis haya devuelto, para eliminar todos los punteros de la pila del analizador a estructuras que fueron construidas por acciones semánticas durante el análisis. Esto es opcional, pero reduce los requisitos de memoria de los programas.

exception Parse_error

Se levanta cuando un analizador encuentra un error de sintaxis. También puede ser levantada desde la parte de acción de una regla de gramática, para iniciar la recuperación de errores.

val set_trace : bool -> bool

Controla el soporte de depuración para analizadores generados por ocamlyacc. Después de Parsing.set_trace true, el autómata de pila que ejecuta los analizadores imprime un rastro de sus acciones (lectura de un token, cambio de estado, reducción por una regla) en la salida estándar. Parsing.set_trace false desactiva este rastro de depuración. El booleano devuelto es el estado anterior del indicador de rastreo.
