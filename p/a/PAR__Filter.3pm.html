NOMBRE

PAR::Filter - Filtro de entrada para PAR

SINOPSIS

$codigo = 'use strict; print "Hola, Mundo!\n";';
$ref = PAR::Filter->new('PodStrip', 'Bleach')->apply(\$codigo);
print $codigo;    # código sin POD y ofuscado
print $$ref;    # lo mismo
$ref = PAR::Filter->new('PodStrip', 'Bleach')->apply('archivo.pl');
print $$ref;    # lo mismo, aplicado a archivo.pl

DESCRIPCIÓN

A partir de PAR 0.76, "pp -f" toma un nombre de filtro, como "Bleach", e invoca este módulo para transformar los programas con PAR::Filter::Bleach. De manera similar, "pp -F Bleach" aplica el filtro Bleach a todos los módulos incluidos.

Es posible pasar múltiples filtros de este tipo, los cuales se aplican en secuencia.

Se espera que la salida de cada filtro sea semánticamente equivalente a la entrada, aunque posiblemente ofuscada.

La lista predeterminada de filtros incluye:

  • PAR::Filter::Bleach

    El filtro ofuscador arquetípico.

  • PAR::Filter::Obfuscate

    Utiliza B::Deobfuscate para eliminar indentaciones y comentarios, así como para modificar los nombres de las variables.

  • PAR::Filter::PatchContent

    Corrige módulos incompatibles con PAR, aplicado a módulos por defecto.

  • PAR::Filter::PodStrip

    Elimina las secciones POD, aplicado a módulos por defecto.

  • PAR::Filter::Bytecode

    Utiliza B::Bytecode para eliminar indentaciones y comentarios. ¡Este filtro está obsoleto! Para ocultar el código fuente, echa un vistazo a PAR::Filter::Crypto y asegúrate de leer sus advertencias.
