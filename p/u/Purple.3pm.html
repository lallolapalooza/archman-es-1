NOMBRE

Purple - Extensión de Perl para la biblioteca de mensajería instantánea libpurple.

SINÓPSIS

use Purple;

RESUMEN

Este módulo proporciona la interfaz para usar scripts de perl como plugins en libpurple.

DESCRIPCIÓN

Este módulo proporciona la interfaz para usar scripts de perl como plugins en Purple. Con esto, los desarrolladores pueden escribir scripts de perl que pueden ser cargados en Purple como plugins. Los scripts pueden interactuar con mensajes instantáneos, chats, cuentas, la lista de amigos, señales de libpurple y más.

La API para la interfaz de perl es muy similar a la API C de Purple, la cual puede ser vista en http://developer.pidgin.im/doxygen/ o en los archivos de cabecera del árbol de fuentes de Purple.

FUNCIONES

@accounts = Purple::accounts
Devuelve una lista de todas las cuentas, en línea o fuera de línea.
@chats = Purple::chats
Devuelve una lista de todos los chats actualmente abiertos.
@connections = Purple::connections
Devuelve una lista de todas las conexiones activas.
@conversations = Purple::conversations
Devuelve una lista de todas las conversaciones, tanto de mensajes instantáneos como de chat, actualmente abiertas.
@conv_windows = Purple::conv_windows
Devuelve una lista de todas las ventanas de conversación actualmente abiertas.
@ims = Purple::ims
Devuelve una lista de todos los mensajes instantáneos actualmente abiertos.
